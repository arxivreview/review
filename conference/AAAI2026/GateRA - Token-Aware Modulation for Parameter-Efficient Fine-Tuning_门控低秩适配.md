# AAAI2026最新论文 ｜GateRA: Token-Aware Modulation for Parameter-Efficient Fine-Tuning ｜门控低秩适配

研究机构：荷兰阿姆斯特丹大学

作者：Jie Ou、Shuaihong Jiang、Yingjun Du 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.17582)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.17582)

> 参数高效微调（PEFT）旨在以极小的可训练参数预算适应下游任务，其核心价值在于化解大模型全参数微调与有限算力资源之间的尖锐矛盾。现有主流方法如 LoRA 和 HiRA 对所有 token 施加静态、输入无关的更新，忽略了不同 token 在内容、位置和置信度上的差异，导致对简单 token 过拟合或对复杂 token 适配不足。本文提出 GateRA，通过引入 token 感知的门控机制动态调节低秩更新的强度，并结合熵正则化促进稀疏、可解释的适配模式。该方法在数学推理和常识推理基准上超越了静态基线，但其门控网络在长序列生成中的累积误差及推理延迟影响尚待验证。

## 研究背景

当预训练模型面对下游任务时，其权重更新并非均匀分布。低秩假设（Intrinsic Rank Hypothesis）认为任务特定的权重更新具有低内在维度，这构成了 LoRA 等重参数化方法的基础：冻结主干权重 $W_0$，注入低秩矩阵 $A, B$ 使得 $\Delta W = AB$。然而，这一假设隐含了“所有输入 token 对更新的需求相同”的前提。在自回归生成中，prefill 阶段的 token 多为确定性复制，而 decoding 阶段的 token 涉及推理与不确定性，两者对适配强度的需求截然不同。静态更新无法区分这种差异，导致容量被低价值 token 占用，或在高价值 token 上更新不足。

PEFT 领域的主流路线已从加法式模块转向重参数化方法，LoRA 确立了无推理开销的事实标准。随后，DoRA 解耦幅度与方向，HiRA 引入乘法低秩更新以提升表达力。尽管这些方法在参数效率上取得了进展，但它们均保留了“静态强度”这一核心局限：更新矩阵 $AB$ 对所有 token 一视同仁。这种均匀策略在简单任务上尚可接受，但在复杂推理或分布外（out-of-distribution）输入中，模型难以区分哪些 token 需要保留预训练知识，哪些 token 需要强化适配。本文的切入点正是打破这一静态假设，将适配强度从全局标量转变为输入依赖的动态函数，实现 token 级的细粒度控制。

## 核心方法

### 方法参照系

本文基于 HiRA 的乘法低秩更新框架。HiRA 将预训练权重 $W_0$ 修改为 $(AB + 1) \cdot W_0$，其中 $A \in \mathbb{R}^{d \times r}$ 和 $B \in \mathbb{R}^{r \times d}$ 为低秩矩阵，$\cdot$ 表示逐元素乘法。与 LoRA 的加法更新不同，HiRA 通过乘法结构对主干权重进行选择性拉伸或收缩。本文的关键差异在于，HiRA 中的更新强度是静态的，而 GateRA 将其替换为输入依赖的门控信号。

### Token 感知门控机制

标准 HiRA 对所有 token 应用相同的 $(AB + 1)$ 更新，忽略了 token 间的语义差异。GateRA 在 HiRA 框架中注入一个轻量级门控网络，根据输入 token 嵌入 $x \in \mathbb{R}^d$ 动态计算调制系数 $g(x)$。具体而言，门控函数定义为：

$$
g(x) = \sigma(W_g x + b_g)
$$

其中 $W_g \in \mathbb{R}^{1 \times d}$ 和 $b_g \in \mathbb{R}$ 为可学习参数，$\sigma(\cdot)$ 为 sigmoid 激活函数。$g(x) \in (0, 1)$ 决定了低秩组件的贡献强度。当 $g(x) \approx 0$ 时，模型完全依赖预训练权重，保留原有知识；当 $g(x) \approx 1$ 时，应用完整的低秩适配。这一设计解决了静态更新在分布外 token 上适配不足的问题，使模型能够自动抑制冗余 token 的更新，将容量集中在模糊或任务关键的 token 上。

### 熵正则化与梯度调制

无约束的门控学习可能导致 $g(x)$ 趋向 0.5，产生均匀且模糊的更新，削弱选择性适配的效果。为此，GateRA 引入基于熵的正则化项，将 $g(x)$ 视为伯努利概率并惩罚其熵：

$$
\mathcal{L}_{ent} = -\frac{1}{N} \sum_{i=1}^{N} [g(x_i) \log g(x_i) + (1 - g(x_i)) \log (1 - g(x_i))]
$$

该正则化项在 $g(x)$ 接近 0 或 1 时取最小值，在 $g(x) = 0.5$ 时取最大值，从而促进近二值的门控决策。理论上，GateRA 的梯度范数受门控函数约束：

$$
\|\nabla_{AB} \mathcal{L}\|_F \le g(x) \|\nabla_{AB} \mathcal{L}_{base}\|_F
$$

这表明门控机制实现了软掩码效果，抑制噪声更新的同时保留信息性梯度，在稳定性与可塑性之间取得平衡。

## 实验评估

实验在 LLaMA-2-7B 和 LLaMA-3-8B 上进行，涵盖常识推理（8 个子任务）、对话生成（ConvAI2）和数学推理（GSM8K）。基线包括 LoRA、DoRA、MoRA 和 HiRA，均使用相同的注入位置（Q/K/V/MLP）。在常识推理任务上，GateRA 在 LLaMA-3-8B 上取得 87.53% 的平均准确率，超越 HiRA 的 86.72% 和 DoRA 的 85.20%。在 GSM8K 数学推理任务上，GateRA 达到 72.11% 的准确率，显著高于 HiRA 的 70.81% 和 LoRA 的 65.89%。

消融实验表明，移除熵正则化导致性能从 87.53% 降至 87.08%，验证了正则化对稳定门控行为的作用。将门控替换为静态张量（Static-GateRA）使性能降至 86.97%，证明数据驱动门控的必要性。在组件集成方面，同时应用于 FC 和 QKV 层的效果最佳（87.53%），单独应用于 FC 层仍具竞争力（86.53%），表明输出层适配的重要性。

评估边界方面，论文未报告推理延迟数据，门控网络可能引入额外计算开销。GSM8K 实验使用 MetaMath 训练，与基线的训练数据一致性未明确说明，可能影响公平性。代码未公开，超参数细节（如学习率 1e-3，预热 100 步）虽提供，但缺乏不同随机种子的方差分析。

## 关联研究分析

从问题动机看，GateRA 与 AdaLoRA 均涉及动态适配，但 AdaLoRA 基于层敏感度分配秩，而 GateRA 基于 token 内容调节强度。AdaLoRA 关注的是“哪些层需要更多参数”，GateRA 关注的是“哪些 token 需要更强更新”。这一差异源于任务特性：层敏感度是静态结构属性，而 token 重要性是动态输入属性。GateRA 的 token 级控制更细粒度，但计算开销更高。MoSA 采用分组标量实现全秩调制，参数预算与低秩相当，但缺乏输入依赖性。GateRA 的门控机制提供了更灵活的动态控制，但 MoSA 的全秩表达力在复杂任务上可能更具优势。

从方法设计看，GateRA 与 DoRA 在权重条件化上存在互补性。DoRA 解耦幅度与方向，优化梯度流；GateRA 调制更新强度，控制适配范围。两者可结合使用，DoRA 提供结构优化，GateRA 提供动态控制。然而，GateRA 的门控网络引入了额外的参数和计算，这与 PEFT 追求极简参数的初衷存在张力。论文未提供门控网络的参数量占比，仅指出“少量额外参数”，具体数值缺失。

## 总结

GateRA 解决了 PEFT 中静态更新导致的 token 级适配不均问题，通过引入输入依赖的门控机制和熵正则化，实现了选择性、可解释的适配。在 LLaMA-3-8B 上，GateRA 在 GSM8K 上达到 72.11%，在常识推理上达到 87.53%，均超越静态基线。其边界在于门控网络的推理延迟未量化，且 GSM8K 实验的训练数据一致性存疑。当序列长度增加时，门控值的累积误差是否会导致适配失效，论文未给出回答。
