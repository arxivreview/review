# AAAI2026最新论文 ｜AutoSCORE: Enhancing Automated Scoring with Multi-Agent Large Language Models via Structured Component Recognition ｜基于量规对齐的多智能体自动评分框架

研究机构：美国佐治亚大学、美国东北大学

作者：Yun Wang、Zhaojun Ding、Xuansheng Wu 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.21910)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.21910)

> 自动写作评估（Automated Writing Assessment, AWE）旨在通过计算模型替代耗时的教师人工评分，但现有大语言模型（LLM）端到端评分存在推理路径黑盒化、量规覆盖不均及提示敏感性问题。AutoSCORE 针对缺乏显式证据提取步骤这一机制缺陷，提出将评分过程解耦为“量规组件提取”与“最终打分”两个独立智能体阶段。该框架通过结构化中间表示约束 LLM 推理路径，在复杂量规任务上显著提升了评分一致性，但其绝对性能仍低于当前领域最强基线，且未验证反馈模块的教学效用。

## 研究背景

自动评分系统的核心挑战在于平衡评分精度与可解释性。传统深度学习模型虽能捕捉语义特征，但作为黑盒系统难以提供教师可审计的评分依据；而直接调用 LLM 进行端到端评分时，模型往往将量规、题目与学生作答拼接为单一提示词，导致部分评分维度被忽略或过度强调，且对提示词格式微小变化极度敏感。这种“一次性打分”模式缺乏人类评分员“先找证据、后做判断”的认知逻辑，使得评分结果难以追溯。

AWE 领域正从单纯追求分数预测精度（QWK）转向强调评分过程的可解释性与教学对齐。2023 年以来，LLM 的引入解决了语义理解瓶颈，但暴露出推理路径不透明与量规对齐缺失的新约束。现有研究多通过优化提示词或引入思维链来缓解上述问题，但仍未在架构层面强制模型显式识别量规相关的证据组件。AutoSCORE 的切入点在于重构评分流程，将隐式的语义匹配转化为显式的结构化组件提取，通过多智能体协作确保评分逻辑与量规标准严格对齐。

## 核心方法

### 方法参照系

标准 LLM 评分流程通常采用单次提示（Single-Prompt）策略，即输入题目、量规和作答，直接输出分数。该流程的关键缺陷在于缺乏中间状态约束，LLM 可能在未完整覆盖所有量规维度的情况下直接生成分数，导致评分一致性低且不可审计。AutoSCORE 将这一黑盒过程拆解为两个串行子任务，引入结构化中间表示作为推理检查点。

### 量规组件提取智能体

该智能体负责从学生作答 $R$ 中识别量规 $X$ 所要求的证据组件，并将其编码为结构化表示 $Z$。设计动机在于解决端到端评分中量规维度覆盖不均的问题，通过强制模型先输出 JSON 格式的证据列表，确保每个评分标准都有对应的文本依据。形式化定义为：

$$ Z = f_{extract}(X, R) $$

其中 $Z$ 包含布尔标志、计数或文本片段，如“有效结论”、“设计改进”等字段。这一显式分离使得评分依据可被独立验证，避免了直接打分时可能出现的证据遗漏。

### 评分智能体

评分智能体基于提取的结构化表示 $Z$、原始作答 $R$ 及任务上下文 $X$ 分配最终分数 $\hat{y}$。设计动机在于利用 $Z$ 作为推理锚点，约束 LLM 的决策路径通过人类对齐的中间状态，从而提升评分的鲁棒性。形式化定义为：

$$ \hat{y} = f_{scoring}(X, R, Z) $$

该智能体被要求严格遵循量规定义，当 $Z$ 与 $R$ 存在不一致时以 $R$ 为准进行纠错。这种两步设计将复杂的评分任务分解为“证据识别”与“规则匹配”，降低了单次推理的认知负荷，尤其适用于多维度复杂量规任务。

## 实验评估

实验在 ASAP 基准的四个子集（Science, Biology, English, Essay Set）上进行，对比基线仅为各 LLM 的单智能体直接评分，未包含 RLAES-AGFO 或 CARO 等当前 SOTA 方法。主要结果如下：

| 数据集 | 模型 | 指标 | 单智能体基线 | AutoSCORE | 相对提升 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Science | GPT-4o | Accuracy | 0.588 | 0.632 | +7.5% |
| English | GPT-4o | QWK | 0.540 | 0.629 | +16.5% |
| Essay Set | GPT-4o | QWK | 0.251 | 0.344 | +37.1% |
| Science | LLaMA-3.1-8B | QWK | 0.150 | 0.261 | +74.0% |

AutoSCORE 在复杂量规任务（如 Essay Set）和小模型（LLaMA-3.1-8B）上表现出显著优势，QWK 提升幅度最高达 74.0%。这表明结构化组件提取能有效补偿小模型推理能力的不足，但在简单任务（如 Biology）上收益有限甚至出现负迁移，暗示组件提取噪声可能在低复杂度任务中抵消其结构优势。

消融分析显示，提取智能体在 Science 子集上的组件计数 MAE 为 0.295，Pearson 相关系数为 0.688，表明提取精度存在波动。这种波动在简单任务中可能导致评分偏差，而在复杂任务中因基线本身性能较低，结构化约束的增益更为明显。

评估边界方面，论文未报告置信区间，且仅使用非推理型 LLM（GPT-4o, LLaMA），未验证在 o1 等推理模型上的表现。代码未公开，超参数细节缺失，限制了可复现性。此外，实验未涉及反馈生成模块的教学效用验证，仅聚焦于评分精度。

## 关联研究分析

从问题动机看，AutoSCORE 与 GUIDE 框架均旨在解决 LLM 评分的提示敏感性问题，但路径截然不同。GUIDE 通过迭代优化提示词中的示例来增强上下文学习，属于提示工程层面的优化；而 AutoSCORE 通过架构分解强制显式证据提取，属于推理流程层面的重构。前者依赖模型对示例的泛化能力，后者依赖模型对结构化指令的遵循能力。AutoSCORE 在复杂量规任务上的优势暗示，当评分标准维度较多时，架构约束比提示优化更能保证维度覆盖的完整性。

从方法设计看，AutoSCORE 与 RLAES-AGFO 代表了两种不同的优化范式。RLAES-AGFO 采用强化学习联合优化评分与反馈，追求端到端的奖励最大化；AutoSCORE 则采用监督式的多智能体分解，追求过程的可解释性与可审计性。RLAES-AGFO 在 ASAP-AES 上取得了 0.86+ 的 QWK，远高于 AutoSCORE 的 0.344（Essay Set），这揭示了 AutoSCORE 在绝对性能上的局限。AutoSCORE 的价值不在于超越 SOTA 精度，而在于提供了一条可审计的评分路径，这在教育公平性与教师信任建立方面具有独特意义，但其性能差距也表明结构化分解尚未完全释放 LLM 的评分潜力。

## 总结

AutoSCORE 试图解决 LLM 端到端评分中推理路径黑盒化与量规覆盖不均的核心矛盾。其切入点在于将评分过程解耦为显式的组件提取与打分阶段，通过结构化中间表示 $Z$ 约束 LLM 推理路径，使其符合人类评分员的认知逻辑。实验证明，该框架在复杂量规任务和小模型上能显著提升评分一致性，Essay Set 的 QWK 提升达 37.1%，LLaMA-3.1-8B 的 QWK 提升达 74.0%。然而，其绝对性能仍远低于 RLAES-AGFO 等 SOTA 方法，且在简单任务上存在负迁移风险。论文未验证反馈模块的教学效用，也未在真实课堂环境中部署。当量规维度进一步增加或任务复杂度提升时，组件提取阶段的噪声累积是否会抵消架构带来的可解释性收益，论文未给出回答。
