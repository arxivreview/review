【AutoSCORE: Enhancing Automated Scoring with Multi-Agent Large Language Models via Structured Component Recognition ｜基于量规对齐的多智能体自动评分框架

研究机构：美国佐治亚大学、美国东北大学

作者：Yun Wang、Zhaojun Ding、Xuansheng Wu 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.21910)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.21910)

> 自动写作评估（Automated Writing Assessment, AWE）旨在通过计算模型替代耗时的教师人工评分，但现有大语言模型（LLM）端到端评分存在推理路径黑盒化、量规覆盖不均及提示敏感性问题。AutoSCORE 针对缺乏显式证据提取步骤这一机制缺陷，提出将评分过程解耦为“量规组件提取”与“最终打分”两个独立智能体阶段。该框架通过结构化中间表示约束 LLM 推理路径，在复杂量规任务上显著提升了评分一致性，但其绝对性能仍低于当前领域最强基线，且未验证反馈模块的教学效用。

【Bridging Modalities via Progressive Re-alignment for Multimodal Test-Time Adaptation ｜多模态测试时适应中的渐进式重对齐

研究机构：北京交通大学

作者：Jiacheng Li、Songhe Feng

论文原文见 [arXiv](https://arxiv.org/abs/2511.22862)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.22862)

> 多模态测试时适应（MMTTA）旨在解决不同模态在部署后遭遇程度不一的分布偏移，导致单模态浅层特征漂移与跨模态高层语义错位相互耦合，使现有单模态测试时适应（TTA）方法失效。现有方法如READ仅调整融合模块权重，缺乏对单模态底层特征的校正，导致融合特征纠缠。BriMPR通过分治策略，先利用提示词微调校准各模态全局分布，再通过掩码重组与对比学习细化对齐。该方法在Kinetics50-C等基准上显著优于SOTA，但其依赖源域统计量预计算，且未验证在极端非平稳流中的长期稳定性。

【GateRA: Token-Aware Modulation for Parameter-Efficient Fine-Tuning ｜门控低秩适配

研究机构：荷兰阿姆斯特丹大学

作者：Jie Ou、Shuaihong Jiang、Yingjun Du 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.17582)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.17582)

> 参数高效微调（PEFT）旨在以极小的可训练参数预算适应下游任务，其核心价值在于化解大模型全参数微调与有限算力资源之间的尖锐矛盾。现有主流方法如 LoRA 和 HiRA 对所有 token 施加静态、输入无关的更新，忽略了不同 token 在内容、位置和置信度上的差异，导致对简单 token 过拟合或对复杂 token 适配不足。本文提出 GateRA，通过引入 token 感知的门控机制动态调节低秩更新的强度，并结合熵正则化促进稀疏、可解释的适配模式。该方法在数学推理和常识推理基准上超越了静态基线，但其门控网络在长序列生成中的累积误差及推理延迟影响尚待验证。

【Steering Sparse Autoencoder Latents to Control Dynamic Head Pruning in Vision Transformers (Student Abstract) ｜稀疏自编码器引导的动态头剪枝

研究机构：韩国科学技术院

作者：Yousung Lee、Dongsoo Har

论文原文见 [arXiv](https://arxiv.org/abs/2603.26743)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.26743)

> 视觉Transformer（ViT）中冗余注意力头的动态剪枝虽能降低计算量，但决策过程依赖残差嵌入，缺乏潜空间层面的可解释性与可控性。现有框架如AdaViT仅输出黑盒掩码，无法解释为何特定输入触发特定头的保留。本文切入点在于引入稀疏自编码器（Sparse Autoencoder, SAE）解耦残差嵌入，通过放大类特定潜变量来引导剪枝决策。该方法在CIFAR-100上验证了潜空间引导能揭示类特异性头子集，但受限于小数据集与单层实验，其通用性存疑。

【StoryBox: Collaborative Multi-Agent Simulation for Hybrid Bottom-Up Long-Form Story Generation Using Large Language Models ｜混合自底向上长程故事生成

研究机构：中山大学

作者：Zehao Chen、Rong Pan、Haoran Li

论文原文见 [arXiv](https://arxiv.org/abs/2510.11618)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.11618)

> 长程叙事生成面临结构僵化与细节缺失的双重困境，传统自顶向下方法先定大纲再填充，导致情节发展受限且角色行为缺乏动态性。StoryBox 将多智能体沙盒模拟作为叙事素材源，通过智能体交互涌现事件，再由 Storyteller Agent 进行自底向上的章节迭代生成。该方法在 20 个自建场景上实现了平均 12,000 词的连贯故事，但在科学验证与定量诊断上缺乏严格标准，其“涌现”质量仍依赖主观评估。

【Stratified Knowledge-Density Super-Network for Scalable Vision Transformers ｜分层知识密度超网络

研究机构：东南大学

作者：Longhua Li、Lei Qi、Xin Geng

论文原文见 [arXiv](https://arxiv.org/abs/2511.11683)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.11683)

> 视觉Transformer（ViT）部署面临资源约束多样性，传统多模型训练或静态剪枝难以兼顾灵活性与精度。现有弹性网络依赖手动扩展规则，导致小模型知识保留不足。本文提出分层知识密度超网络，通过加权主成分分析（WPAC）与渐进重要性感知Dropout（PIAD）实现任意尺寸子网的O(1)成本提取。该方法在同等压缩比下优于静态剪枝，但依赖30 epoch微调，其“免重训练”优势存疑。

】
