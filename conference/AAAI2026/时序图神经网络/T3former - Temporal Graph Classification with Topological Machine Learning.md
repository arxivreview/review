# T3former：用Betti数与状态密度做一等公民令牌，解决时序图分类中时间粒度与全局结构捕捉的权衡难题

作者：Md. Joshem Uddin、Soham Changani、Baris Coskunuzer

论文原文见 [arXiv](https://arxiv.org/abs/2510.13789)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.13789)

> 时序图分类旨在为带有时间戳的单一图结构分配全局标签，现有方法依赖离散快照或循环更新，在时间粒度与全局结构捕捉间存在固有权衡。本文切入点在于利用滑动窗口提取拓扑与谱不变量，通过专用注意力机制融合多模态特征。T3FORMER将Betti数与状态密度向量作为一等公民令牌，结合图神经网络生成的结构令牌，在Transformer骨干中实现跨模态交互。该方法在社交、脑连接及交通网络基准上确立了新SOTA，但其滑动窗口机制是否真正优于连续时间编码，以及缺失与最新Transformer基线的对比，仍存疑。

## 研究背景

时序图分类的核心困境在于如何在不丢失细粒度时间信息的前提下，捕捉图结构的全局演化模式。持续同调（Persistent Homology, PH）通过构建嵌套单纯复形序列，量化连通分量与环洞的出生-死亡过程，提供对高阶拓扑结构的不敏感于局部扰动的描述。然而，PH传统上应用于静态点云或图，直接扩展至时序场景通常要求刚性快照离散化，导致时间分辨率损失。拉普拉斯算子的状态密度（Density of States, DOS）则从谱图理论角度，通过特征值分布直方图编码图的连通性、扩张性与社区结构，提供介观层面的几何洞察。

时序图神经网络（TGNNs）主流路线包括离散快照结合循环神经网络（如EvolveGCN）与连续时间事件流建模（如TGN）。前者受制于时间粒度粗糙，后者虽捕捉细粒度时序但依赖局部消息传递，易受过度平滑与过度挤压限制，且在噪声稀疏场景下嵌入不稳定。静态图分类近期利用PH与DOS取得进展，但直接迁移至时序任务面临离散化妥协。T3FORMER针对这一空白，提出无需固定快照序列的混合框架，通过滑动窗口滤过提取时间感知的拓扑与谱描述符，解决现有方法在时间保真度与全局结构理解间的矛盾。

## 核心方法

### 方法参照系

时序图分类的通用流程通常将时间轴划分为离散快照，对每个快照应用图神经网络（GNN）获取节点或图表示，再通过序列模型（RNN/Transformer）建模时间演化。本文的关键差异在于摒弃了节点级嵌入的序列建模，转而将时间轴视为滤过函数，提取全局拓扑与谱不变量作为时间序列令牌，直接进行图级分类。

### 滑动窗口拓扑与谱描述符提取

设计动机在于克服刚性快照离散化导致的时间信息丢失，以及局部消息传递对高阶结构模式捕捉能力的不足。T3FORMER引入滑动窗口滤过，定义窗口长度 $\delta$ 与步长 $\sigma$，生成子图序列 $G_i = G_{[i\sigma, i\sigma+\delta]}$。对每个子图，计算拓扑描述符向量 $\phi_t$ 与谱描述符向量 $\psi_t$：

$$
\phi_t = \left( |V_t|, |E_t|, \beta_0(G_{[t,t+\delta]}^{\kappa}), \beta_1(G_{[t,t+\delta]}^{\kappa}) \right)
$$

其中 $\beta_0, \beta_1$ 为子图克劳德复形的零阶与一阶Betti数，捕捉连通性与环结构的时间演化。谱描述符通过归一化拉普拉斯算子特征值直方图近似：

$$
\psi_t = \text{Histogram}(\text{Eigenvalues}(L_t))
$$

该设计保留了边在多个窗口中的出现，避免将边折叠为单一时间戳，从而维持高时间分辨率。拓扑不变量提供了对微小扰动的鲁棒性，而DOS向量编码了介观结构复杂性，两者互补地捕捉了局部动态与全局几何特征。

### 描述符注意力融合机制

设计动机在于解决简单拼接无法有效建模结构、拓扑与谱模态间复杂交互的问题。T3FORMER采用三流架构：GSAGE编码器处理静态图（使用时间度特征），生成全局结构令牌；拓扑与谱令牌分别通过独立的Transformer编码器处理，捕捉时间依赖。随后，通过专用的描述符注意力（Descriptor-Attention）模块融合这三路嵌入。该模块利用自注意力机制自适应地加权不同模态的贡献，而非固定权重拼接。最终融合表示通过线性层输出分类结果。这种基于Transformer的融合确保了跨模态信息的原理解析，避免了模态间的干扰，并允许模型根据任务需求动态调整对结构、拓扑或谱特征的依赖。

## 实验评估

实验在社交（TUDataset）、脑连接（NeuroGraph）及交通（PEMS）网络上进行，采用5折交叉验证（社交/交通）或70/10/20划分（脑）。基线覆盖静态GNN（GSAGE, GAT）、图核方法、时序GNN（TGN, EvolveGCN, GraphMixer）及Transformer（Graphormer）。缺失DyGFormer等最新连续时间SOTA基线，限制了与领域前沿的直接对比。

| 数据集 | 任务 | T3FORMER | 最佳基线 | 基线方法 |
| :--- | :--- | :--- | :--- | :--- |
| PEMS04 | Binary | 96.76±1.92 | 95.44±1.15 | TGN |
| PEMS04 | Multi | 92.66±1.93 | 90.85±7.18 | GCN+LSTM |
| PEMS08 | Binary | 95.16±1.50 | 93.82±3.09 | UNIMP |
| PEMS08 | Multi | 89.65±2.02 | 87.71±2.89 | UNIMP |
| PEMS BAY | Binary | 96.68±1.30 | 95.44±1.15 | TGN |
| PEMS BAY | Multi | 92.35±1.52 | 90.60±8.04 | UNIMP |
| DynHCP-Gender | - | 75.79 | 68.45 | K-GNN |
| DynHCP-Age | - | 58.73 | 44.41 | UNIMP |

T3FORMER在交通网络所有设置下均领先，平均增益1.90%（二分类）与2.25%（多分类）。在脑连接任务中，性别分类准确率75.79%，显著高于最佳基线K-GNN的68.45%；年龄预测58.73%，远超UNIMP的44.41%。社交网络中，T3FORMER在Highschool数据集上达到67.20%，优于TGN的63.33%，但在Infectious数据集上（68.50%）低于TEMP-G3NTK的74.00%，显示其在特定稀疏结构上的局限性。

消融实验表明，单独使用GSAGE、拓扑或谱描述符性能均低于完整模型。Concat-fuse（简单拼接）在脑连接Task任务上仅57.87%，而T3FORMER达90.76%，证实注意力融合机制的必要性。注意力权重分析显示，在脑连接任务中，拓扑描述符权重最高（0.7040），而在交通网络中，GSAGE结构特征权重较高（0.3855-0.5920），表明模型自适应地根据数据特性调整模态依赖。

评估边界方面，论文未报告计算效率的详细对比，仅提及在Task数据集上单折运行5.34分钟，比GCN+LSTM快15倍。代码已开源，超参数通过网格搜索确定。主要局限在于缺乏与DyGFormer等连续时间Transformer基线的对比，且滑动窗口长度 $\delta=6$ 与步长 $\sigma=4$ 的敏感性分析仅在附录提及，未在主文充分讨论其对拓扑稳定性的影响。

## 关联研究分析

从问题动机看，T3FORMER与TGN、EvolveGCN等主流TGNN存在根本路线差异。TGN依赖节点级记忆模块捕捉细粒度时序依赖，适用于链接预测等节点/边级任务，但其局部消息传递机制在图级分类中易受过度平滑限制，且对噪声敏感。T3FORMER则聚焦图级全局标签，利用拓扑与谱不变量提供对局部扰动的鲁棒性，这解释了其在脑连接等噪声稀疏场景中的优势。然而，T3FORMER的滑动窗口机制本质上仍是一种离散化，与知识库中CTDG优于DTDG的共识存在张力。其声称的“细粒度时间分辨率”依赖于窗口参数 $\delta$ 的选择，若 $\delta$ 过大，则退化为粗粒度快照；若 $\delta$ 过小，则计算成本激增且拓扑特征可能不稳定。论文未提供 $\delta$ 对性能与稳定性的系统性权衡分析，这使得其“无刚性离散化”的声明缺乏充分支撑。

从方法设计看，T3FORMER与静态图分类中的PH方法（如Immonen et al., 2024）共享拓扑不变量提取思路，但关键差异在于时间维度的处理。静态方法将PH应用于单一图，而T3FORMER通过滑动窗口生成PH序列，并引入Transformer捕捉时间依赖。这与DyGFormer的Transformer架构有相似之处，但DyGFormer建模节点嵌入的长程依赖，而T3FORMER建模全局描述符的时序模式。T3FORMER未对比DyGFormer，可能是因为DyGFormer设计用于节点/边级预测，直接应用于图级分类需额外聚合步骤，但论文未解释这一选择。此外，T3FORMER的Descriptor-Attention机制与多模态融合中的交叉注意力类似，但其输入是预计算的不变量向量，而非原始特征，这限制了其捕捉细粒度节点交互的能力，可能解释了其在Infectious数据集上低于TEMP-G3NTK的表现。

## 总结

T3FORMER旨在解决时序图分类中时间粒度与全局结构捕捉的矛盾，通过滑动窗口提取拓扑与谱不变量，并利用描述符注意力融合多模态特征。该方法在交通网络（PEMS04 Binary 96.76%）与脑连接（DynHCP-Age 58.73%）上确立了新SOTA，证明了全局不变量在鲁棒图级分类中的有效性。然而，其滑动窗口机制本质上仍属离散化，与连续时间动态图（CTDG）范式存在定义模糊，且缺失与DyGFormer等最新Transformer基线的对比，限制了其性能上限的评估。当窗口长度 $\delta$ 增大时，拓扑描述符的稳定性是否显著下降，以及这种离散化在何种条件下会劣于连续时间编码，论文未给出回答。
