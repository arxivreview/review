# CVPR2026最新论文 ｜Federated Active Learning Under Extreme Non-IID and Global Class Imbalance ｜联邦主动学习中的类别公平查询

研究机构：南京大学

作者：Chen-Chen Zong、Sheng-Jun Huang

论文原文见 [arXiv](https://arxiv.org/abs/2603.10341)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.10341)

> 联邦主动学习（Federated Active Learning, FAL）旨在隐私约束下降低标注成本，但在全局类别极度不平衡与客户端高度异构场景下，现有查询策略往往偏向头部类别，导致标注预算浪费。现有方法多将异构性视为数据划分问题，忽视了全局长尾分布对查询模型选择的根本影响。本文通过系统实证发现，实现更类别平衡采样的模型（全局或本地）能带来更优的最终性能，并据此提出FairFAL框架，通过自适应模型选择、原型引导伪标签及两阶段采样实现类别公平查询。该框架在极端非独立同分布（Non-IID）设置下显著优于基线，但其自适应机制依赖首轮随机采样的IID假设，在动态分布场景下的鲁棒性存疑。

## 研究背景

联邦学习（FL）通过“数据不动模型动”范式解决隐私与数据孤岛矛盾，而主动学习（AL）通过选择性查询降低标注成本。当二者结合形成FAL时，核心挑战在于如何在无法共享原始数据的条件下，从分散的未标注池中识别出全局最具信息量的样本。传统AL依赖单一中心模型评估样本不确定性，但在FL中，全局模型与本地模型同时存在，且二者对样本的评估能力受数据分布影响显著。

FAL领域的主流路线包括基于不确定性的熵采样、基于多样性的Coreset采样以及混合策略如BADGE。然而，这些方法在极端Non-IID场景下面临瓶颈：当全局类别分布呈长尾状（即少数类样本极少）时，基于全局模型的查询往往因平均化效应而失去对少数类的敏感度；而基于本地模型的查询虽能捕捉局部边界，却可能因客户端分布偏差导致全局查询集失衡。现有研究如LoGo、KAFAL虽尝试结合全局与本地信号，但多采用固定策略或二值决策，缺乏对全局不平衡程度与本地异构程度耦合效应的动态响应机制。

本文切入点在于揭示“查询模型选择”与“类别平衡采样”之间的因果联系。作者指出，现有方法隐含假设全局标签分布相对平衡或可通过聚合恢复，但现实联邦系统常呈现长尾分布。本文通过系统实验证明，在严重全局不平衡且客户端分布相对同质时，全局模型查询更优；而在其他多数场景下，本地模型查询更能保障类别平衡。这一发现将FAL的研究重心从单纯的“样本信息量评估”转向“查询模型的选择机制”，为处理极端异构下的标注效率提供了新视角。

## 核心方法

### 方法参照系

FAL的标准流程包含联邦训练与主动查询两个交替阶段。在查询阶段，通常使用单一模型（全局或本地）计算未标注样本的获取函数（Acquisition Function），如熵或距离，以选择最具信息量的样本。本文的关键差异在于，不再固定使用单一模型，而是引入一个自适应机制，根据全局类别不平衡程度与本地-全局分布差异，动态决定每个客户端使用全局模型还是本地模型作为查询选择器。

### 自适应模型选择机制

设计动机在于解决固定查询模型在极端Non-IID下的失效问题：全局模型在长尾分布下对少数类不敏感，而本地模型在客户端高度异构时可能产生偏差。本文通过估计全局类别不平衡系数 $\bar{\gamma}$ 和本地-全局分布差异 $d_k$，构建连续评分函数 $s_k$ 来决策模型选择。

$$ s_k = \frac{1}{1 + \exp(-\beta(\bar{\gamma} - \tau) - \alpha d_k)} $$

该公式将全局不平衡程度（$\bar{\gamma}$ 越小表示越不平衡）与本地异构程度（$d_k$ 越大表示越异构）映射为 $[0,1)$ 区间的评分。当 $\bar{\gamma}$ 小且 $d_k$ 小时，$s_k$ 趋近于1，选择全局模型；反之选择本地模型。这种连续映射避免了硬阈值带来的不稳定性，且仅依赖本地标量统计量，无需传输原始数据，保证了隐私性。

### 原型引导伪标签与两阶段采样

设计动机在于解决不确定性采样易导致查询集冗余且缺乏类别覆盖的问题。本文利用全局模型的特征表示计算每类原型，通过相似度为未标注样本分配伪标签，实现类别感知的初步筛选。随后，在每个类别的高不确定性候选池中，执行 $k$-center 采样以最大化多样性。

$$ \text{PseudoLabel}(x) = \arg\min_{c \in C} \| \phi_g(x) - \mu_c \|^2 $$

其中 $\phi_g(x)$ 为全局模型特征，$\mu_c$ 为类别 $c$ 的原型。该步骤确保查询集在类别维度上的平衡。接着，在梯度嵌入空间中执行 $k$-center 算法，选择距离已选样本最远的点，从而在不确定性高的样本中进一步剔除冗余，确保最终查询集既包含边界样本又覆盖特征空间的不同区域。

## 实验评估

实验在FMNIST、CIFAR-10、CIFAR-100、OctMNIST和DermaMNIST五个基准上进行，设置全局不平衡比 $\rho=20$，客户端异构度 $\alpha \in \{0.1, 100\}$。基线涵盖随机采样、不确定性方法（Entropy, Margin, LC）、多样性方法（Coreset）、混合方法（BADGE, GCNAL, ALFA-Mix）及FAL专用方法（KAFAL, LoGo, IFAL）。基线覆盖较为全面，但缺乏针对极端长尾分布的专用对比方法，如基于重采样的联邦学习算法。

| 数据集 | 方法 | 最终测试准确率 (%) |
| :--- | :--- | :--- |
| OctMNIST | KAFAL | 70.40 |
| OctMNIST | LoGo | 68.40 |
| OctMNIST | IFAL | 73.27 |
| OctMNIST | FairFAL | 72.80 |
| DermaMNIST | KAFAL | 70.00 |
| DermaMNIST | LoGo | 73.62 |
| DermaMNIST | IFAL | 72.97 |
| DermaMNIST | FairFAL | 73.77 |

在OctMNIST上，FairFAL（72.80%）略低于IFAL（73.27%），但在DermaMNIST上超过IFAL（73.77% vs 72.97%）。这表明FairFAL在自然长尾分布的医疗数据上表现更稳健，但在部分合成不平衡数据集上并非绝对领先。消融实验显示，自适应模型选择贡献了主要增益，而原型引导伪标签相比本地原型能提供更清晰的类别分离，验证了全局特征在表示学习上的优势。

评估边界方面，论文仅报告测试准确率，未提供通信轮数、能耗或标注成本的具体量化对比，难以全面评估其部署效率。代码已开源，但超参数 $\beta, \tau, \alpha$ 的敏感性分析未在正文中详细展开，可能影响复现性。此外，实验假设首轮采样为随机IID，若初始标注数据本身存在偏差，自适应机制的估计准确性可能下降。

## 关联研究分析

从问题动机看，本文与聚类联邦学习（CFL）如FLUX、DPMM-CFL存在本质差异。CFL旨在通过聚类构建局部模型以平衡全局泛化与个性化，其核心是模型结构的解耦；而FairFAL聚焦于查询阶段的样本选择，核心是信息获取的效率。CFL假设客户端数据分布静态且已知簇结构，而FairFAL通过动态评分应对分布的不确定性。这种差异源于任务目标不同：CFL优化模型精度，FairFAL优化标注预算利用率。在极端异构下，CFL可能因簇划分错误导致模型偏差，而FairFAL通过类别平衡采样直接缓解数据层面的偏斜，二者在解决Non-IID问题上形成互补而非竞争关系。

从方法设计看，本文与个性化联邦学习（PFL）中的pFedLoRA、FIARSE等方法在“局部适配”理念上相通，但应用层面截然不同。PFL方法通过低秩适配或提示学习微调模型参数，以适配本地分布；FairFAL则通过选择查询模型（全局/本地）来适配查询策略。PFL的适配发生在训练阶段，影响模型收敛；FairFAL的适配发生在查询阶段，影响数据获取。值得注意的是，PFL方法通常假设标注数据充足，而FairFAL针对标注稀缺场景。当标注预算极低时，PFL的局部适配可能因数据不足而过拟合，而FairFAL的类别平衡采样能确保有限标注覆盖关键类别，这在数据极度稀缺的医疗场景中更具实际价值。

## 总结

本文核心矛盾在于FAL中全局类别不平衡与客户端异构性对查询策略的耦合影响，现有固定模型查询方法无法动态适应这种耦合。本文抓住“类别平衡采样决定最终性能”这一被忽视的因果链，通过自适应模型选择机制动态权衡全局与本地查询器的优劣。FairFAL框架结合原型引导伪标签与两阶段采样，在DermaMNIST上达到73.77%的准确率，优于IFAL的72.97%。其边界在于依赖首轮随机采样的IID假设，且未量化通信开销。当标注预算进一步降低至1%以下时，自适应机制的估计误差是否会主导性能下降，论文未给出回答。
