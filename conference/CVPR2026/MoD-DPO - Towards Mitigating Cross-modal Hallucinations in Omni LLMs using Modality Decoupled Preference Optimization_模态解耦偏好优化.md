# CVPR2026最新论文 ｜MoD-DPO: Towards Mitigating Cross-modal Hallucinations in Omni LLMs using Modality Decoupled Preference Optimization ｜模态解耦偏好优化

研究机构：美国南加州大学

作者：Ashutosh Chaubey、Jiacheng Pang、Mohammad Soleymani

论文原文见 [arXiv](https://arxiv.org/abs/2603.03192)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.03192)

> 全模态大语言模型（Omni LLMs）在处理音视频任务时，常因音频与视频间的虚假相关性或语言先验主导而产生跨模态幻觉。现有推理时对比解码仅调整输出概率，无法改变模型内部对模态的依赖结构；标准直接偏好优化（DPO）虽能纠正偏好偏差，却未显式隔离无关模态干扰。本文提出模态解耦DPO（MoD-DPO），通过在训练目标中引入模态不变性与敏感性正则项，强制模型仅依赖提示相关模态生成响应。该方法在音视频幻觉基准上显著优于基线，但其对有益跨模态协同的抑制效应尚存疑。

## 研究背景

当Omni LLM面对“视频中是否有狗叫”这类提示时，若音频中存在篮球声而视频无狗，模型可能因预训练数据中“狗-叫声”的强共现而错误肯定。这种错误源于两个机制：一是语言先验（Language Prior），即LLM骨干对文本流畅性的过度依赖，导致忽略视听证据；二是虚假跨模态相关（Spurious Inter-modality Correlations），即模型在预训练中习得了音频与视频间不存在的统计关联。解决此类问题需区分“模态忠实接地”与“模态混淆”，前者要求响应仅由提示相关模态驱动，后者则允许无关模态干扰决策。

传统视觉-语言幻觉缓解主要依赖推理时干预，如视觉对比解码（VCD）通过对比有无视觉输入的logits分布抑制幻觉token。然而，VCD属于事后概率调整，无法改变模型内部对模态的依赖边界。训练时偏好对齐（如DPO）虽能优化响应偏好，但标准DPO目标函数未区分模态来源，模型可能通过忽略视觉/音频证据、仅依赖文本先验来最大化奖励，导致“视觉懒惰”。本文切入点在于：将模态解耦约束内化至训练目标，从源头切断跨模态错误传播链，而非在解码阶段修补输出。

## 核心方法

### 方法参照系

标准DPO通过优化策略 $\pi_\theta$ 使高奖励响应概率高于低奖励响应，其损失函数基于Bradley-Terry模型：

$$ \mathcal{L}_{DPO} = -\mathbb{E}_{(x, y_w, y_l)} [\log \sigma(\beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)})] $$

本文问题与该通用流程的关键差异在于：DPO未区分输入模态（音频 $a$、视频 $v$）与提示 $x$ 的相关性，导致模型可能通过忽略无关模态来“作弊”。

### 模态解耦正则化

针对标准DPO无法隔离模态依赖的失效，本文在DPO目标中引入两个KL散度正则项。设提示 $x[v]$ 与视觉模态相关，则修改后的目标为：

$$ \mathcal{L}_{MoD} = \mathcal{L}_{DPO} + \beta_{inv} D_{KL}(\pi_\theta(y|a', v, x[v]) \| \pi_\theta(y|a, v, x[v])) + \beta_{sens} D_{KL}(\pi_\theta(y|a, v', x[v]) \| \pi_\theta(y|a, v, x[v])) $$

其中 $a'$ 和 $v'$ 分别为音频和视频的损坏版本。第一项（不变性）要求当无关模态（音频）损坏时，输出分布保持稳定；第二项（敏感性）要求当相关模态（视频）损坏时，输出分布显著偏移。该设计强制模型将决策权重集中于提示相关模态，抑制虚假跨模态依赖。

### 语言先验去偏（LPD）

针对Omni LLM中LLM骨干的强语言先验，本文在奖励函数中增加惩罚项：

$$ r_{LPD} = -\gamma_{LPD} \log \pi_{text}(y|x[v]) $$

其中 $\pi_{text}$ 为冻结的纯文本模型（本文选用参考模型 $\pi_{ref}$）。该惩罚项降低仅依赖文本输入生成响应的奖励，迫使模型必须利用视听证据才能获得高奖励。最终目标 $\mathcal{L}_{MoD-DPO++}$ 结合了模态解耦与语言先验去偏，形成完整的训练框架。

## 实验评估

实验基于Qwen 2.5 Omni（7B）和MiniCPM-O 2.6（8B）两个骨干，使用18.1k自动生成的偏好样本（涵盖10.8k视频）进行单轮训练。基线覆盖标准DPO、OmniDPO及多个Omni LLM，但缺失VCD等推理时干预方法，无法直接对比训练时与推理时干预的优劣。

| 方法 | AVHBench Acc. (%) | CMM Overall hr (%) |
| :--- | :--- | :--- |
| Qwen 2.5 Omni | 84.15 | 86.4 |
| + DPO | 84.39 | 84.6 |
| + OmniDPO | 85.34 | 86.6 |
| + MoD-DPO | 87.66 | 88.8 |
| + MoD-DPO++ | 88.19 | 89.2 |

MoD-DPO++在AVHBench上Accuracy达88.19%，较基线Qwen 2.5 Omni提升4.04个百分点；在CMM上Hallucination Resistance（hr）达89.2%，较OmniDPO提升2.6个百分点。消融实验显示，LPD对语言主导任务（Lang. Dom.）的改善最为显著，CMM中Lang. Dom. hr从74.2%提升至74.9%，而视觉/音频主导任务提升幅度较小，表明LPD主要抑制文本捷径而非增强视听感知。

评估边界方面，本文未报告推理延迟与内存占用，且未与VCD等免训练方法对比，无法量化训练时干预的性价比。代码基于LLaMAFactory修改，超参数（$\beta_{sens}=0.05, \beta_{inv}=0.02, \gamma_{LPD}=0.05$）已公开，但偏好数据生成依赖GPT-4o与AudioFlamingo 3，复现成本较高。

## 关联研究分析

从问题动机看，本文聚焦Omni LLM的跨模态幻觉，而VCD等主流方法针对视觉-语言（V-L）幻觉。VCD通过对比有无视觉输入的logits分布抑制幻觉，但仅适用于单模态（视觉）场景，无法处理音频与视频间的虚假相关。本文的模态解耦正则化是VCD思想在训练时的内化，但VCD的对比机制是动态的（依赖当前输入），而MoD-DPO的解耦是静态的（依赖预定义的模态相关性），这导致MoD-DPO在需要动态模态切换的任务中可能失效。

从方法设计看，本文与OmniDPO同属偏好对齐路线，但OmniDPO通过多模态偏好对促进视听证据关注，未显式隔离模态。本文的LPD惩罚项与OmniDPO的多模态偏好对功能重叠，但LPD直接惩罚文本-only响应，更激进地抑制语言先验。然而，LPD可能过度抑制有益的跨模态协同（如通过狗叫声确认狗的存在），论文未提供证据表明这种抑制在复杂推理任务中是负面的，也未探索如何平衡解耦与协同。

## 总结

本文核心矛盾在于Omni LLM中语言先验与虚假跨模态相关导致的幻觉，现有方法或仅调整输出概率（VCD）或未隔离模态依赖（标准DPO）。本文通过模态解耦正则化与语言先验去偏，在训练阶段强制模型依赖提示相关模态，在AVHBench上Accuracy达88.19%，CMM上hr达89.2%。其边界在于：LPD可能抑制有益的跨模态协同，且未与推理时方法对比，无法证明训练时干预的必要性。当提示需要同时利用音频与视频证据（如“听到狗叫且看到狗”）时，模态解耦是否会导致性能下降，论文未给出回答。
