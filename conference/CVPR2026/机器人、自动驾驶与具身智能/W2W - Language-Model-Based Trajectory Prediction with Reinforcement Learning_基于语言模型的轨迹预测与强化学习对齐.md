# CVPR2026最新论文 ｜W2W: Language-Model-Based Trajectory Prediction with Reinforcement Learning ｜基于语言模型的轨迹预测与强化学习对齐

作者：Zirui Xu、Biao Yang、Rongrong Ni 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_863b0b849ea9)

> 行人轨迹预测旨在从历史观测推断未来位置，是自动驾驶安全决策的前置条件。现有基于语言模型（LM）的方法存在训练目标与预测指标错位、交互语义缺失两大瓶颈，导致精度受限且场景合规性差。本文提出 Write-to-Walk (W2W)，通过行为感知文本化编码交互语义，并采用监督微调（SFT）结合近端策略优化（PPO）的两阶段训练，直接优化几何精度与场景合规奖励。该方法在可解释性上优于黑盒深度学习模型，但在绝对精度上仍略低于顶级扩散模型，其规则化交互提取在复杂动态场景中的泛化能力存疑。

## 研究背景

当自动驾驶系统面对拥挤路口时，仅凭单智能体历史轨迹难以预测其因避让行人而发生的偏转。这种偏差源于智能体间的社会交互，传统方法依赖图神经网络（GNN）隐式建模交互拓扑，但缺乏显式语义解释。语言模型（LM）具备处理序列数据和常识推理的能力，可将轨迹转化为自然语言，从而引入人类行为先验。然而，LM 的训练目标通常是最大化文本似然，这与轨迹预测所需的几何精度（如平均位移误差 ADE）存在本质差异，导致模型生成的轨迹虽语法正确但物理位置偏差较大。

行人轨迹预测的主流路线分为数值回归与生成式建模两类。数值回归方法如 Trajectron++ 直接回归坐标，精度高但缺乏解释性；生成式方法如扩散模型能捕捉多模态分布，但推理成本高且难以直接约束场景边界。近期，LM-based 路线兴起，LMTraj 首次将预训练 LM 用于行人预测，VLMTraj 进一步引入多模态输入。然而，这些方法均存在目标错位：SFT 阶段优化交叉熵损失，而非 ADE/FDE 指标；且输入仅为离散坐标点，未显式编码“跟随”、“伴随”等交互语义，限制了 LM 先验的有效利用。W2W 的切入点在于重构输入表示以暴露交互线索，并通过 RL 阶段直接对齐预测目标与场景约束。

## 核心方法

### 方法参照系

W2W 将轨迹预测重构为序列到序列（Seq2Seq）文本生成任务。与标准数值回归流程 $\hat{S}_{pred} = g_{\theta^*}(S_{obs}, S_{nb}, U_s)$ 不同，本文通过文本化函数 $F$ 和交互分类器 $H$ 将观测转化为提示词 $x$，由 T5-Small 生成文本 $y$，再经正则表达式解析器 $P$ 逆映射回坐标。关键差异在于优化目标从数值损失转为文本似然，需额外机制对齐几何精度。

### 行为感知提示构建

传统 LM 轨迹预测输入仅含坐标序列，忽略了智能体间的相对运动语义。W2W 设计交互模块，基于距离、航向角和相对方位角计算三类语义标签：Companion（伴随）、Following（跟随）、Obstacle（障碍）。例如，Obstacle 判定条件为初始距离远、最终距离近且航向差大，表示快速接近或静态冲突。这些标签以自然语言嵌入提示词，如“Ped 1 is an obstacle to pedestrian 0”，使 LM 能利用预训练中习得的社会规范先验。该设计解决了纯坐标输入无法表达交互意图的问题，提升了模型对避让、跟随行为的建模能力。

### 两阶段训练与奖励对齐

SFT 阶段仅优化交叉熵损失 $L_{SFT} = -\sum_{t} \log p_{\theta}(y_t | y_{<t}, x)$，虽保证输出格式可解析，但未直接优化 ADE。W2W 引入 RL 阶段，冻结 T5 骨干，仅更新 LoRA 适配器，使用 PPO 优化程序化奖励。奖励函数定义为：

$$
r(x, \hat{y}) = r_{L2} + r_{occ} = -\frac{1}{T}\sum_{t=1}^{T} \|\hat{\tau}_t - \tau_t^*\|_2 - \lambda_{occ} \sum_{t=1}^{T} \mathbb{1}[M_{scene}(\hat{\tau}_t) = 1]
$$

其中 $r_{L2}$ 为负 ADE 项，$r_{occ}$ 为基于二值语义掩码的离路惩罚。PPO 策略优化目标为：

$$
\max_{\theta} \mathbb{E}_{x \sim \mathcal{D}} \sum_{t \le T_y} L_{PPO}(\theta; A_t)
$$

优势函数 $A_t$ 通过广义优势估计（GAE）从逐步奖励计算。该设计直接对齐了 LM 训练与轨迹精度、场景合规目标，克服了 SFT 阶段目标错位的局限。

## 实验评估

实验在 ETH/UCY（1,536 条轨迹）和 SDD（无人机俯视场景）上进行，采用留一法协议。基线覆盖深度学习（Trajectron++, AgentFormer, MoFlow）和 LM-based（LMTraj, VLMTraj, GUIDE-CoT）两类，但缺失最新扩散模型基线（如 MID, CDDM），可能高估 LM 方法的相对竞争力。

| 模型 | ETH/UCY ADE/FDE | SDD ADE/FDE |
| :--- | :--- | :--- |
| Trajectron++ | 0.31/0.52 | 11.4/20.1 |
| AgentFormer | 0.23/0.40 | 8.7/14.9 |
| MoFlow | 0.20/0.32 | 7.50/11.96 |
| LMTraj-SUP | 0.22/0.32 | 7.8/10.1 |
| VLMTraj-SUP | 0.18/0.27 | 7.4/10.3 |
| **W2W** | **0.21/0.29** | **7.42/10.13** |

W2W 在 ETH/UCY 上 ADE 为 0.21，优于 LMTraj-SUP (0.22) 和 Trajectron++ (0.31)，但略低于 VLMTraj-SUP (0.18) 和 MoFlow (0.20)。在 SDD 上，W2W ADE 为 7.42，与 VLMTraj-SUP (7.4) 持平，优于 LMTraj-SUP (7.8)。

消融实验显示，移除交互语义（W2W-Base）导致 ETH/UCY ADE 从 0.21 升至 0.22，FDE 从 0.29 升至 0.32，证明交互标签对精度有正向贡献。RL 阶段进一步将 ADE 从 0.21 降至 0.21（ETH/UCY 平均），FDE 从 0.30 降至 0.29，同时将离路率（ORR）从 11.30% 降至 8.85%，表明 RL 有效增强了场景合规性。提示词长度实验表明，移除冗长场景描述并保留交互语义（W2W-SFT）优于包含场景描述（W2W-SFT+），ADE 从 0.22 降至 0.21，证实小参数模型对无关文本敏感。

评估边界方面，论文未报告置信区间，数值比较需谨慎。代码已开源，但超参数（如 $\lambda_{occ}$ 权重）的敏感性分析仅展示三种设置，未提供完整网格搜索。评估协议未包含闭环测试或对抗鲁棒性测试，限制了其在真实部署中的有效性验证。

## 关联研究分析

从交互建模角度看，W2W 与 GNN-based 方法（如 AgentFormer）形成鲜明对比。AgentFormer 通过注意力机制隐式学习交互拓扑，而 W2W 依赖规则化距离/航向启发式提取三类语义标签。这种差异源于任务特性：LM 需要显式文本线索激活先验，而 GNN 可直接处理图结构。然而，规则化提取在未见过的复杂交互（如多人围堵、动态让行）中可能失效，因为预定义阈值（如 $\tau_{align}$）无法覆盖所有行为模式。W2W 未探索自适应交互分类或数据驱动的语义提取，这可能限制其在长尾场景的泛化能力。

从训练策略看，W2W 与 VLMTraj 同属 LM-based 路线，但 VLMTraj 仅使用 SFT，而 W2W 引入 RL 对齐。VLMTraj 的 SFT 优化文本似然，导致其 ADE (0.18) 优于 W2W (0.21)，但 W2W 的 ORR (8.85%) 显著低于 VLMTraj（未报告，但 SFT 通常不优化合规性）。这表明 RL 阶段在精度上未带来增益，但在场景合规性上提供了额外价值。W2W 的 LoRA-PPO 设计旨在缓解分布偏移，但论文未量化 LoRA 秩对性能的影响，也未比较全参数 RL 与 LoRA-RL 的差异，使得该设计选择的必要性存疑。

## 总结

W2W 旨在解决 LM 轨迹预测中训练目标与几何精度错位、交互语义缺失的矛盾。其切入点在于利用 LM 的文本生成特性，通过行为感知提示暴露交互线索，并用 RL 直接优化 ADE 与离路惩罚。方法上，W2W 采用 T5-Small 骨干，SFT 学习格式，RL 对齐目标。实验证明，W2W 在 ETH/UCY 上 ADE 为 0.21，ORR 降至 8.85%，优于 LMTraj 和多数 DL 基线，但精度低于 VLMTraj 和 MoFlow。其边界在于规则化交互提取依赖预定义阈值，且 RL 阶段未提升绝对精度，仅改善合规性。当交互场景超出预定义三类语义（如复杂让行、群体避让）时，规则化标签的覆盖率与准确性是否下降，论文未给出回答。
