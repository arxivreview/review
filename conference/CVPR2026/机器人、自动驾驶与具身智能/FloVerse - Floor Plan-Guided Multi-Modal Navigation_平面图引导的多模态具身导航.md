# CVPR2026最新论文 ｜FloVerse: Floor Plan-Guided Multi-Modal Navigation ｜平面图引导的多模态具身导航

作者：Weiqi Huang、Shuangyi Dong、Jiaxin Li 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_0848f1404d3c)

> 具身导航智能体在未知环境中常因缺乏全局空间先验而陷入低效探索，导致步数浪费与成功率下降。现有基于动态建图或视觉语言模型（VLM）推理的方法虽能提升泛化，但面临计算延迟高或空间幻觉的瓶颈，且鲜有研究系统评估低成本静态平面图对多模态目标导航的增益。本文提出 FloVerse 任务与 ThreeDiff 模型，利用预提取的 2D 平面图作为全局空间先验，结合两阶段扩散策略实现点、物、图三类目标的统一导航。该方法在特定避障设定下验证了平面图先验的有效性，但其性能显著低于当前 VLM 驱动的通用导航基准，且未解决平面图缺乏细粒度物体语义的根本局限。

## 研究背景

具身导航的核心挑战在于智能体需在未知环境中将抽象目标映射为精确运动轨迹。传统基于前沿（Frontier）探索的方法依赖局部观测构建几何地图，但在复杂布局中易陷入局部循环，且地图构建开销大。视觉语言模型（VLMs）的引入虽通过常识推理提升了开放词汇下的零样本泛化能力，但其推理频率低且存在空间幻觉，难以满足实时控制需求。为平衡推理深度与实时性，分层架构与显式空间记忆成为主流工程妥协，但动态构建语义地图或 3D 高斯泼溅（3D Gaussian Splatting, 3DGS）仍需在线计算资源。

该领域要解决的核心矛盾是：如何在缺乏全局先验地图的未知动态环境中，通过有限算力下的多模态感知与高层语义推理，实现从抽象语言指令到精确低层运动控制的鲁棒映射。主流路线分为两类：一是基于动态建图的方法，如 VLFM 引入视觉-语言前沿地图，将语义理解与几何前沿检测结合，但受限于在线分割与投影的计算量；二是基于 VLM 推理的方法，如 Nav-R1 采用快-慢推理范式，慢系统执行长程语义推理，快系统确保低延迟导航，但依赖高质量思维链数据且模型规模大。这些方法在表示质量、适应效率与计算成本之间做出了不同取舍，但均假设环境结构需通过在线感知获取，忽略了室内环境中普遍存在的静态平面图这一低成本空间先验。

本文的切入点在于利用预提取的 2D 平面图作为全局空间先验，替代动态建图过程。平面图易于获取且编码了房间布局与连通性等几何结构，能为智能体提供全局导航线索，减少短视探索行为。然而，现有研究主要局限于 PointNav 任务和小规模场景，未系统评估平面图对 ObjectNav 和 ImageNav 等语义目标模态的增益。本文通过构建 FloVerse 数据集与 ThreeDiff 模型，首次将平面图引导导航扩展至多模态目标，并验证了其在提升导航效率上的有效性。

## 核心方法

### 方法参照系

本文问题属于“记忆与空间表征”路线的变体，但与传统动态建图方法存在关键差异。标准流程中，智能体通过在线感知构建语义地图或拓扑图，再基于地图进行高层规划与低层控制。本文则采用预提取的静态 2D 平面图作为全局空间先验，无需在线建图，直接提供房间布局与连通性信息。这种静态先验避免了动态建图的计算开销，但缺乏细粒度物体信息，需依赖局部观测进行避障与目标识别。

### 多模态目标条件化规划器

设计动机：单一模态训练导致模型在跨模态任务上泛化能力差，且不同模态的目标编码方式不统一，难以共享空间表征。本文通过随机模态掩码策略，使单一模型同时支持 PointNav、ObjectNav 和 ImageNav，解决跨模态泛化问题。

在规划器阶段，智能体接收当前状态 $s_t = (I_t, D_t, p_t)$、平面图 $F$ 和目标 $g$。目标条件 $C_g$ 通过随机掩码向量 $m = [m_{point}, m_{object}, m_{image}]$ 生成，其中仅一个元素为 1。点目标条件 $C_{g_{point}} = MLP(g_{point})$，图像目标条件 $C_{g_{image}} = MLP(E(I_t) \oplus E(g_{image}))$，物体目标条件 $C_{g_{object}} = MLP(CLIP(I_t) \oplus CLIP(g_{object}))$。平面图特征 $C_F$ 由 EfficientNet 提取，观测特征 $C_O$ 通过多头自注意力模块计算过去 $l$ 步的 RGB、深度和位姿特征。规划器采用条件 U-Net 和 DDPM 调度器，训练目标为：

$$
L_1 = MSE(\epsilon_k, \epsilon_\omega(\bar{a}_t + \epsilon_k, k))
$$

其中 $\epsilon_k$ 为噪声标签，$k$ 为去噪步数。该公式通过最小化预测噪声与真实噪声的均方误差，学习从目标条件、平面图特征和观测特征到动作分布的映射。随机模态掩码策略使模型在训练过程中暴露于所有三种模态，模态间相互增强，提升轨迹生成的泛化能力。

### 深度轨迹精炼器

设计动机：规划器生成的粗轨迹缺乏局部避障能力，因训练轨迹为无碰撞最优路径，模型未接收碰撞反馈。本文引入深度精炼器，利用局部几何线索生成避障轨迹，解决粗轨迹在复杂环境中碰撞率高的问题。

精炼器将深度图投影为鸟瞰视角（BEV）的二值占用地图，网格大小 20×50，分辨率 0.1m。计算局部符号距离场（SDF），通过 CNN 编码为特征 $f_{SDF}$。$f_{SDF}$ 与规划器输出的粗轨迹 $\hat{a}_t$ 拼接，输入第二个扩散模型，生成精炼轨迹 $\tilde{a}_t$。训练目标为：

$$
L_2 = MSE(\epsilon_k, \epsilon_\epsilon(\tilde{a}_t + \epsilon_k, k)) + \zeta L_{collision}
$$

其中 $L_{collision} = \frac{1}{N} \sum_{i=1}^{N} \exp(-\phi \cdot \delta_i)$，$\delta_i$ 为第 $i$ 个路点到最近障碍物的 L2 距离，$\zeta$ 和 $\phi$ 为超参数。该公式通过最小化轨迹与障碍物距离的指数损失，显式约束轨迹远离障碍物，提升导航安全性。精炼器利用深度信息提供局部几何感知，弥补平面图缺乏细粒度物体信息的缺陷，实现全局规划与局部避障的解耦。

## 实验评估

实验在 FloVerse-1.6K 数据集上进行，包含 1,627 个场景、240K 专家轨迹和 12M RGBD 帧，覆盖 HM3D 和 Gibson 4+ 环境。基线包括 FloDiff（平面图引导 PointNav）、Nomad（扩散策略 ImageNav）和 DD-PPO（强化学习 PointNav）。缺失强基线如 PlatonicNav、GOAL 等 VLM 驱动的统一导航模型，导致无法直接对比通用 SOTA 性能。

| 方法 | PointNav SR (%) | PointNav SPL (%) | ImageNav SR (%) | ImageNav SPL (%) | ObjectNav SR (%) | ObjectNav SPL (%) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| ThreeDiff w/o F | 25.8 | 25.6 | 22.6 | 18.4 | 20.9 | 16.5 |
| ThreeDiff | 42.0 | 36.6 | 28.9 | 22.4 | 28.6 | 22.3 |
| Point-only | 42.1 | 38.9 | - | - | - | - |
| Image-only | - | - | 25.4 | 20.7 | - | - |
| Object-only | - | - | - | - | 24.3 | 19.9 |

ThreeDiff 在 PointNav 上 SR 42.0%，较无平面图版本提升 16.2%，SPL 提升 11.0%；在 ImageNav 和 ObjectNav 上提升幅度较小（SR 分别提升 6.3% 和 7.7%）。Point-only 模型在 PointNav 上 SR 42.1%，略高于 ThreeDiff，表明显式几何线索更易学习，而多模态训练引入的隐式语义偏差轻微干扰了几何结构学习。

| 方法 | Gibson 4+ SR (%) | Gibson 4+ SPL (%) | HM3D SR (%) | HM3D SPL (%) |
| :--- | :--- | :--- | :--- | :--- |
| DD-PPO | 18.3 | 10.5 | 13.7 | 7.0 |
| FloDiff (pretrain) | 40.0 | 28.8 | 23.7 | 17.8 |
| FloDiff (finetune) | 38.8 | 29.6 | 27.7 | 21.1 |
| ThreeDiff | 54.4 | 50.0 | 38.1 | 32.5 |

ThreeDiff 在 Gibson 4+ 和 HM3D 的 PointNav 任务上均显著优于 FloDiff 和 DD-PPO，SR 分别提升 14.4% 和 10.4%。DD-PPO 性能大幅下降（SR 18.3%），因任务强调避障，而 DD-PPO 缺乏碰撞避免能力。FloDiff 微调后在 HM3D 上 SR 提升 4%，表明深度信息可进一步改善性能。

评估边界方面，指标仅包含 SR 和 SPL，未报告计算效率、碰撞率或置信区间。评估协议强调避障，与忽略碰撞的通用基准（如 Habitat Challenge 2019）不同，导致性能不可直接对比。可复现性方面，论文未提供代码 URL，但详细描述了超参数（学习率 0.0001，训练 20 epochs，4 块 NVIDIA 4090 GPU，batch size 32），便于复现。

## 关联研究分析

从问题动机看，本文与 VLFM 等动态建图方法的核心差异在于空间先验的获取方式。VLFM 通过在线分割与投影构建视觉-语言前沿地图，提供细粒度语义信息，但计算开销大；本文使用预提取的静态平面图，避免在线建图，但缺乏物体级语义。这一差异源于任务设定：本文聚焦于利用低成本先验提升导航效率，而非追求细粒度目标识别。平面图在复杂多层或动态环境中的泛化局限未被充分评估，因 FloVerse 数据集仅包含静态室内场景，未涉及移动障碍物或动态布局。

从方法设计看，本文与 Nav-R1 等 VLM 驱动方法在推理机制上存在根本差异。Nav-R1 采用快-慢推理范式，慢系统执行长程语义推理，快系统确保低延迟导航，依赖 VLM 的常识推理能力；本文采用两阶段扩散策略，规划器基于平面图生成粗轨迹，精炼器基于深度生成避障轨迹，无需 VLM 推理。这一差异源于计算效率考量：扩散模型推理延迟低于 VLM，适合实时控制，但缺乏语义推理能力。平面图先验与 VLM 语义推理的结合未被探索，因本文聚焦于几何导航，未涉及开放词汇目标识别。

## 总结

本文要解决的核心矛盾是：如何在缺乏全局先验地图的未知环境中，通过低成本空间先验实现多模态目标的鲁棒导航。本文抓住的切入点是利用预提取的 2D 平面图作为全局空间先验，替代动态建图过程，解决智能体因缺乏全局信息导致的短视探索问题。本文通过构建 FloVerse 数据集与 ThreeDiff 模型，利用随机模态掩码训练统一规划器，结合深度精炼器生成避障轨迹，证明了平面图先验在 PointNav 上可提升 SR 16.2%，在 ImageNav 和 ObjectNav 上提升 SR 6.3% 和 7.7%。本文的边界在于：平面图缺乏细粒度物体信息，导致在语义目标模态上增益有限；评估协议强调避障，与通用基准不可直接对比；未探索平面图与 VLM 语义推理的结合。当平面图先验与 VLM 语义推理结合时，能否在保持低计算延迟的同时提升开放词汇目标识别性能，论文未给出回答。
