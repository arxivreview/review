# CVPR2026最新论文 ｜ActiveGrasp: Information-Guided Active Grasping with Calibrated Energy-based Model ｜基于校准能量模型的主动抓取视角选择

研究机构：美国宾夕法尼亚大学

作者：Boshu Lei、Wen Jiang、Kostas Daniilidis

论文原文见 [arXiv](https://arxiv.org/abs/2511.12795)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_98b6f24277c9)

> 杂乱场景下的机器人抓取面临初始视角信息不足导致预测失效的困境，现有主动感知方法依赖可见性或可供性图选择视角，忽略了抓取分布在 SE(3) 流形上的几何结构与概率校准问题。本文切入点在于将信息增益定义为抓取分布的熵减，并通过校准能量模型（Calibrated Energy-based Model）直接计算该熵值，从而在有限视角预算下最大化任务特异性信息获取。该方法通过结合高斯后验近似与校准能量函数，实现了从场景重建到视角选择的端到端优化。其价值在于提供了无启发式规则的主动抓取框架，但实验仅覆盖静态杂乱场景，动态交互与触觉缺失下的鲁棒性存疑。

## 研究背景

当机器人面对杂乱堆叠的物体时，单视角 RGB-D 输入往往无法提供足够的几何约束以预测稳定抓取姿态。这一困境源于场景表征的不确定性：未观测区域导致抓取姿态分布呈现多峰且高熵状态。解决该问题的关键概念是主动感知（Active Perception），即通过选择下一最佳视角（Next-Best-View, NBV）来降低不确定性。然而，NBV 选择的核心在于准确估计候选视角带来的信息增益，这要求对抓取分布进行精确建模。

杂乱场景抓取的主流路线分为两类：一类依赖大规模数据训练更强的抓取检测器，但受限于初始视角的信息瓶颈；另一类采用主动感知策略，通过迭代选择视角完善场景表征。现有主动感知方法如 ACE 和 ActiveNGF 通常基于可见性覆盖或可供性分数选择视角，这些代理指标偏向视觉特征丰富但物理上不可抓取的区域，且将抓取分布投影至 2D 或 3D 网格，忽略了 SE(3) 流形的拓扑结构。此外，未校准的预测概率导致信息增益估计存在偏差，使得机器人可能浪费视角预算在低价值区域。

本文针对上述瓶颈，提出基于信息论准则的主动抓取框架。其核心假设是：只有当抓取分布被校准至真实成功率，且定义在 SE(3) 流形上时，基于该分布计算的熵减才能作为无偏的信息增益估计。这一切入点将视角选择从“寻找视觉丰富区”转变为“寻找抓取不确定性最高区”，从而在有限视角预算下更有效地定位目标物体的可抓取部分。

## 核心方法

### 方法参照系

本文问题属于主动感知抓取控制范畴，标准流程为“场景重建-视角选择-抓取生成-执行”。与通用流程的关键差异在于，本文不依赖独立的可供性模型或启发式规则，而是将视角选择嵌入到基于校准能量模型的抓取分布熵计算中，实现了感知与决策的紧耦合。

### 基于校准能量模型的抓取分布建模

传统能量模型（EBM）仅学习抓取姿态的密度 $p(g|w)$，但未建立能量值与真实成功率 $s(g,w)$ 的对应关系，导致基于密度的信息增益估计存在偏差。本文引入校准机制，将 EBM 的输出 logits $(a_S, a_F)$ 映射为成功与失败概率，确保能量水平直接可解释为成功率。

$$
p_S = \frac{e^{a_S}}{e^{a_S} + e^{a_F} + 2}, \quad p_F = \frac{e^{a_F}}{e^{a_S} + e^{a_F} + 2}
$$

该公式通过双分数匹配损失（Dual Score Matching Loss）训练，同时对齐成功抓取与失败抓取的扰动分布。设计动机在于解决未校准模型中能量值与概率的非线性失配问题，使得后续基于概率计算的熵值具有物理意义。校准后的模型不仅预测抓取姿态，还隐式学习了失败模式，使采样过程能避开 SE(3) 流形上的无效区域。

### 基于高斯后验近似的熵减信息增益

视角选择的目标是最大化候选视角 $x_{acq}$ 带来的信息增益，定义为抓取分布熵的期望减少量。由于场景表征 $w$ 的高维性，直接计算后验熵不可行。本文采用高斯后验近似（Gaussian Approximation of Posterior, GAP），将后验分布近似为以 MAP 估计 $\hat{w}$ 为均值、Hessian 矩阵逆为协方差的高斯分布。

$$
I[G, W; y_{acq}|x_{acq}, D] \approx -\frac{1}{2} \text{tr} \left( \nabla_w^2 \mathcal{H}(\hat{w}) \left( H[\hat{w}|D]^{-1} - H[\hat{w}|x_{acq}, D]^{-1} \right) \right)
$$

其中 $\mathcal{H}(w)$ 为条件抓取熵 $H[S|G,W]$，定义为单抓取伯努利熵的期望。该公式通过二阶泰勒展开近似熵的变化，利用 Hessian 矩阵的差异量化新视角对场景不确定性的削减程度。设计动机在于避免对高维后验分布进行蒙特卡洛采样，通过解析近似实现高效计算。改进价值在于，该信息增益直接反映抓取任务的不确定性降低，而非场景几何的完成度，从而引导机器人探索对抓取决策最具价值的视角。

## 实验评估

实验在 PyBullet 仿真环境中进行，使用 YCB 数据集构建包含 10 个物体的杂乱场景，机器人初始获取 2 个固定视角，主动选择 2 个额外视角。基线覆盖 ACE、ActiveNGF、Breyer 等主流主动感知方法，以及 Contact GraspNet、SE(3) Diffusion Fields 等抓取检测器。缺失 VLA 类模型（如 $\omega_{0.5}$）的直接对比，仅提及其在杂乱场景下的局限性。

| 方法组合 | 成功率 (SR, %) | 期望校准误差 (ECE) |
| :--- | :--- | :--- |
| ACE + ACE | 22.50% | 0.35 |
| Contact GraspNet + ActiveNGF | 32.50% | 0.32 |
| SE(3) Diff + ActiveNGF | 58.25% | 0.40 |
| SE(3) Diff Calib + Random | 74.25% | 0.06 |
| SE(3) Diff Calib + Random† | 76.50% | 0.05 |
| ActiveGrasp (Ours) | 79.00% | 0.02 |

ActiveGrasp 以 79.00% 的成功率领先，较随机采样（74.25%）提升 4.75 个百分点，较最佳基线（76.50%）提升 2.5 个百分点。校准误差从 0.06 降至 0.02，表明校准机制显著提升了预测可靠性。消融实验显示，未校准模型（SE(3) Diff Scene）配合 ActiveGrasp 仅达 73.00%，证实校准对信息增益估计的必要性。

评估边界方面，实验仅验证静态杂乱场景，未涉及动态物体或触觉反馈。代码声明将公开，但当前未提供 URL，超参数与 GPU 配置未详细披露，可复现性依赖后续开源实现。

## 关联研究分析

从问题动机看，本文与 Grasp-MPC 等闭环控制方法形成互补。Grasp-MPC 聚焦执行阶段的轨迹优化与避障，而 ActiveGrasp 聚焦感知阶段的视角选择。两者均针对杂乱场景的鲁棒性，但 Grasp-MPC 依赖价值函数引导的模型预测控制，计算开销较大；ActiveGrasp 通过信息论准则实现轻量级视角选择，推理时间 9.61 秒，显著快于 ACE（18.24 秒）和 ActiveNGF（27.66 秒）。差异根源在于任务阶段不同：前者解决“如何抓”，后者解决“看哪里”。

从方法设计看，本文与 SE(3) Diffusion Fields 共享能量模型基础，但用途截然不同。SE(3) Diffusion Fields 利用能量函数进行去噪采样以生成抓取姿态，而 ActiveGrasp 利用校准后的能量函数计算熵以选择视角。这一差异源于任务目标：生成需要多峰分布的采样，而视角选择需要分布不确定性的量化。本文未探索将两者结合，即在选择视角的同时优化抓取生成策略，这可能是在动态场景中提升效率的关键。

## 总结

本文解决的核心矛盾是杂乱场景下初始视角信息不足与有限视角预算之间的张力。现有方法依赖可见性或可供性代理指标，忽略了抓取分布在 SE(3) 流形上的几何结构与概率校准，导致信息增益估计偏差。本文通过校准能量模型与高斯后验近似，将信息增益定义为抓取分布的熵减，实现了任务特异的视角选择。实验证明该方法在仿真环境中以 79.00% 的成功率优于现有基线，且校准误差降至 0.02。其边界在于仅验证静态场景，未涉及动态交互或触觉反馈，且视角选择依赖场景重建的准确性。当场景中存在高度透明或反光物体导致 3DGS 重建失效时，基于该重建的熵计算是否仍能提供有效的信息增益引导，论文未给出回答。
