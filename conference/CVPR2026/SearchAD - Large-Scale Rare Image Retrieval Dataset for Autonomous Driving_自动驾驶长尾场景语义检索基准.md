# CVPR2026最新论文 ｜SearchAD: Large-Scale Rare Image Retrieval Dataset for Autonomous Driving ｜自动驾驶长尾场景语义检索基准

作者：Felix Embacher、Jonas Uhrig、Marius Cordts 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.08008)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.08008)

> 自动驾驶系统依赖海量数据训练，但稀有安全关键场景的标注成本极高且分布极度不均。现有异常检测数据集多采用预筛选策略，导致长尾分布失真，无法真实评估模型在自然分布下的检索能力。本文提出 SearchAD，一个包含 423k 帧、90 类稀有对象的大规模自然分布数据集，并构建了首个针对自动驾驶语义图像检索的基准。该基准揭示了当前视觉语言模型在稀有对象检索上的严重局限，为数据策展提供了关键参照，但其绝对性能仍远低于实用阈值。

## 研究背景

当自动驾驶车队积累海量未标注视频时，如何从中精准定位“拖拉机”或“路障”等稀有对象成为数据策展的核心瓶颈。这一过程依赖于语义图像检索，即通过文本或图像查询在大规模数据库中匹配语义相关但视觉多样的实例。与实例检索不同，语义检索需跨越颜色、尺寸等视觉变体进行类别级匹配，这对模型的开放世界泛化能力提出了更高要求。

传统自动驾驶数据集如 CODA 和 OpenAD 采用预筛选策略，仅保留特定异常场景，导致稀有类别频率被人为放大，失去了自然长尾分布的特征。这种偏差使得基于这些数据集训练的模型在真实世界的极端稀有场景（如出现次数少于 50 次的类别）中表现不佳。SearchAD 的切入点在于摒弃预筛选，直接对 11 个主流数据集的全量帧进行人工标注，保留自然长尾分布，从而构建一个能真实反映数据策展难度的基准。

## 核心方法

### 检索框架与相似度度量

本文基于视觉语言模型（VLM）的对比预训练特性，构建了零样本检索框架。对于文本到图像检索，查询特征由语言支持集编码，数据集特征由视觉编码器离线计算。相似度计算采用余弦距离，公式如下：

$$ \text{sim}(q, d) = \frac{f_q \cdot f_d}{\|f_q\| \|f_d\|} $$

其中 $f_q$ 和 $f_d$ 分别为查询和数据集的嵌入向量。该设计动机在于利用 VLM 的零样本能力处理未标注类别，避免传统检测器对固定类别集的依赖，同时通过离线计算数据集特征降低搜索延迟。

### 邻居感知特征对齐

针对小目标检索困难的问题，本文引入 NARADIO 作为最佳基线，其核心在于邻居感知机制。该机制通过高斯核将视觉编码器的空间特征映射到文本对齐空间，保留精确的空间定位信息。公式表示为：

$$ f_{aligned} = \sum_{i} G(i) \cdot f_i^{patch} $$

其中 $G(i)$ 为高斯核权重，$f_i^{patch}$ 为局部 patch 特征。这一创新解决了传统 VLM 池化特征丢失空间细节的问题，使得模型能够区分“打开的引擎盖”与“打开的后备箱”等细微语义差异，显著提升了小目标（如交通锥、动物）的检索精度。

### 评估指标设计

鉴于稀有类别在数据集中数量极少，传统的 Recall@1 指标失效。本文采用 R-Precision 和 MAP 作为核心指标。R-Precision 定义为前 $K_c$ 个结果中相关图像的比例，其中 $K_c$ 为该类别的总相关图像数：

$$ R\text{-}Precision_c = \frac{1}{K_c} \sum_{k=1}^{K_c} r_c(k) $$

该指标允许模型在有限的相关样本中达到 100% 召回，避免了因样本稀缺导致的指标上限过低问题，更公平地评估模型在长尾分布下的检索能力。

## 实验评估

实验在 SearchAD 测试集上进行，对比了 NARADIO、RADIO、BLIP2、GroundingDINO 等 7 种基线。基线覆盖了 VLM 和检测器两条路线，但缺乏针对自动驾驶特定场景优化的专用检索模型。

| 方法 | 类型 | 文本到图像 MAP (%) | 图像到图像 MAP (%) |
| :--- | :--- | :--- | :--- |
| NARADIO | VLM | 14.27 | 8.31 |
| BLIP2 (Fine-tuned) | VLM | 12.06 | 11.13 |
| GroundingDINO | Detector | - | - |

NARADIO 在文本到图像检索中以 14.27% 的 MAP 领先，但在图像到图像检索中仅达 8.31%。微调后的 BLIP2 在图像到图像检索中达到 11.13%，超过了零样本 NARADIO，但在文本到图像检索中仍低于 NARADIO。这表明微调对视觉特征匹配有增益，但对文本语义对齐的增益有限。

消融分析显示，GroundingDINO 在 Object 和 Animal 类别上表现优于 VLM，得益于其高分辨率输入（1333x600）对小目标的敏感性。然而，其在线推理特性导致搜索速度远慢于 VLM。此外，长描述文本会导致误检，仅使用关键词作为查询条件效果最佳。

评估边界方面，论文未报告置信区间，且部分小目标（<50 像素）被排除在评估之外，这可能高估了模型在极端小目标上的实际能力。代码和超参数未完全公开，仅提供了基准服务器 URL，限制了可复现性。

## 关联研究分析

从数据分布策略看，SearchAD 与 CODA 形成鲜明对比。CODA 通过预筛选将稀有类别频率提升一个数量级，便于模型学习，但牺牲了分布真实性。SearchAD 坚持自然分布，揭示了模型在真实长尾场景下的脆弱性。这一差异源于任务目标的不同：CODA 旨在训练异常检测模型，而 SearchAD 旨在评估数据策展工具。自然分布下的检索难度是否被现有方法低估，预筛选策略在保持分布真实性与提升学习效率之间是否存在更优平衡点，论文未给出回答。

从方法路线看，SearchAD 与 DriveSafe 等 VLM 驱动的方法共享对语义推理的依赖，但 SearchAD 聚焦于底层数据检索，而非高层决策。DriveSafe 利用 VLM 生成安全建议，而 SearchAD 利用 VLM 进行图像匹配。两者均暴露了 VLM 在几何感知上的短板：SearchAD 中 VLM 对小目标检索精度低，DriveSafe 中 VLM 难以精确定位障碍物。这表明 VLM 在自动驾驶栈中的角色仍需明确，是作为核心感知引擎还是辅助语义层，取决于具体任务对几何精度的要求。

## 总结

SearchAD 解决了自动驾驶数据策展中稀有场景检索的基准缺失问题，通过保留自然长尾分布，揭示了当前 VLM 在语义检索上的严重局限。其核心贡献在于构建了首个大规模自然分布 AD 检索基准，并证明即使是最先进的 NARADIO，MAP 也仅为 14.27%。本文的边界在于绝对性能远低于实用阈值，且微调收益有限，表明现有 VLM 架构难以直接满足高精度数据策展需求。当支持集规模从 5 张增加到更多时，图像到图像检索的性能提升是否足以弥补文本检索的短板，论文未给出回答。
