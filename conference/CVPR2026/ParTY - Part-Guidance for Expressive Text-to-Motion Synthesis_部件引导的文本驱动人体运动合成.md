# CVPR2026最新论文 ｜ParTY: Part-Guidance for Expressive Text-to-Motion Synthesis ｜部件引导的文本驱动人体运动合成

作者：KunHo Heo、SuYeon Kim、Yonghyun Gwon 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.09611)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.09611)

> 文本驱动人体运动生成旨在从自然语言描述合成逼真、物理合理且语义一致的人体运动序列，其核心价值在于缓解动作捕捉数据标注成本高企与具身智能对高自由度动作生成需求之间的张力。现有整体生成方法将身体视为单一实体，无法精确对齐文本中特定身体部位的细粒度动作；而部件独立生成方法虽能提升局部表达力，却因缺乏全局一致性导致全身运动连贯性崩塌。ParTY 通过“部件生成引导整体生成”的双阶段框架，结合部件感知文本接地与整体-部件融合机制，在 HumanML3D 上实现了 R-Precision Top-1 0.550 与 FID 0.035 的 SOTA 性能，但其评估指标依赖数据集内统计分布，跨域泛化能力存疑。

## 研究背景

当文本描述包含“左腿前跨，右手举起”等细粒度指令时，整体生成模型（如 MoMask）将身体视为单一实体，导致特定部位的动作被全局语义淹没或错误映射。这种语义对齐的粗糙性源于传统方法缺乏将文本词元与特定关节部位显式关联的机制，而部件独立生成方法（如 ParCo）虽通过解剖学分割实现了局部控制，但各部件独立生成后简单拼接，忽略了关节间的运动学约束与节奏同步，造成颈部扭曲、上下身朝向不一致等连贯性缺陷。

文本驱动人体运动生成（Text-to-Motion Generation, T2M）的核心驱动力源于计算机动画、VR/AR 娱乐及具身智能对低成本、高自由度动作生成的迫切需求。2022 年 MDM 引入扩散模型确立了连续潜空间生成的主流地位，随后 T2M-GPT 与 MoMask 等离散自回归范式凭借 VQ-VAE 将运动转化为 Token 序列，结合 Transformer 架构实现了更强的语义组合性。然而，这些主流路线均聚焦于全局语义匹配，忽视了人体运动作为“协调系统”而非“单一实体”的本质。ParTY 的切入点在于解决部件表达力与全身连贯性之间的固有权衡，通过引入部件级语义对齐与动态融合机制，填补了现有方法在细粒度时空控制上的空白。

## 核心方法

### 方法参照系

本文基于离散自回归范式，继承 MoMask 的 VQ-VAE 量化与 Transformer 解码架构，但关键差异在于摒弃了单一整体生成流程，转而采用“部件生成引导整体生成”的双阶段策略，并引入 Temporal-aware VQ-VAE 以缓解时间信息丢失问题。

### Temporal-aware VQ-VAE

标准 VQ-VAE 将固定窗口大小的运动帧压缩为单个码本条目，导致时间流信息丢失，增大窗口虽能保留更多时间信息却增加模型复杂度。本文在量化前引入局部时间增强（LTE）与全局时间增强（GTE），通过加权求和与图卷积网络（GCN）保留局部与全局时间依赖。LTE 对窗口内帧特征进行加权聚合：

$$ \tilde{N}_i = \sum_{j=1}^{w} \alpha_{ij} f_{ij} $$

其中 $\alpha_{ij}$ 为 MLP 输出的 softmax 权重，确保窗口内特征按重要性加权。GTE 则将增强后的组级特征作为 GCN 节点，通过邻接矩阵更新节点特征以捕捉长程时间依赖。这一设计在不增加模型参数的前提下，使更长的运动序列能被编码为单个码本条目，降低了推理时间并提升了重建精度（MPJPE 从 0.030 降至 0.011）。

### Part-aware Text Grounding 与 Part-Guided Network

部件感知文本接地（PTG）模块解决文本语义与特定身体部位对齐不足的问题。它将 CLIP 文本嵌入通过 K 个独立 MLP 转换为多样化嵌入，并通过对比学习确保语义一致性：

$$ L_{div} = -\frac{1}{K} \sum_{n=1}^{K} \log \frac{\exp(s(c'_n, c)/\tau)}{\sum_{m \neq n} \exp(s(c'_m, c)/\tau)} $$

其中 $s(\cdot, \cdot)$ 为余弦相似度，$\tau$ 为温度参数。训练时利用 LLM 生成的部件描述作为辅助监督，通过 L1 损失对齐 PTG 输出与部件特定嵌入，推理时仅依赖原始文本嵌入，保持高效。部件引导网络（PGN）首先由部件 Transformer 自回归生成 T 步部件运动 Token，形成部件引导 $G_i$，随后将其作为条件输入整体 Transformer 生成整体运动 Token。整体-部件融合（HPF）模块在整体生成过程中持续融合部件信息，通过自注意力与交叉注意力机制将部件 Token 作为 Key/Value，整体 Token 作为 Query，确保部件运动信息贯穿整个生成过程，解决独立生成后拼接导致的连贯性缺失。

## 实验评估

实验在 HumanML3D（14,616 运动，44,970 文本）与 KIT-ML 上进行，基线覆盖 MDM、T2M-GPT、MoMask、ParCo 等主流方法，但缺失 Flow Matching 类最新 SOTA（如 HY-Motion）。主实验显示，ParTY 在 HumanML3D 上 R-Precision Top-1 达 0.550，FID 0.035，MM-Dist 2.779，均优于 MoMask（0.521, 0.045, 2.958）与 ParCo（0.515, 0.109, 2.927）。

| 方法 | R-Precision Top-1 | FID | MM-Dist |
| :--- | :--- | :--- | :--- |
| MoMask | 0.521±0.002 | 0.045±0.002 | 2.958±0.008 |
| ParCo | 0.515±0.003 | 0.109±0.005 | 2.927±0.008 |
| ParTY | 0.550±0.003 | 0.035±0.002 | 2.779±0.006 |

消融实验表明，PTG 与 PGN 的协同作用显著：仅启用 PGN 时 R-Precision Top-1 为 0.520，加入 PTG 后升至 0.545，再引入 HPF 达到 0.550。部件级评估显示，ParTY 在手臂与腿部的 R-Precision Top-1 分别达 0.506 与 0.463，显著优于 MoMask（0.452, 0.403）与 ParCo（0.468, 0.407）。连贯性指标（TC/SC）验证了 ParTY 在解决部件连贯性缺陷上的有效性：ParCo 的 TC/SC 仅为 0.49/0.59，而 ParTY 达到 0.88/0.92，接近 MoMask 的 0.84/0.90。

评估边界方面，TC/SC 指标依赖 HumanML3D 数据集内统计分布，跨域泛化能力未验证；代码已开源，但 LLM 生成部件描述的辅助监督可能引入数据偏差，且未报告计算效率对比（如推理时间）。

## 关联研究分析

从问题动机看，ParTY 与 AttT2M 均聚焦细粒度时空控制，但 AttT2M 采用单一解码器与部件注意力，缺乏部件级语义对齐机制，导致局部表达力受限；ParTY 通过 PTG 模块将文本嵌入动态分配给特定部位，实现了更精细的语义接地。从方法设计看，ParTY 与 MoMask 同属离散自回归路线，但 MoMask 采用掩码并行生成，ParTY 引入部件引导与整体-部件融合，解决了独立生成后拼接的连贯性问题。ParCo 虽采用部件独立生成，但未利用部件特定文本描述，且简单拼接导致连贯性崩塌；ParTY 通过 PGN 与 HPF 实现了部件与整体的动态协同，填补了部件表达力与全身连贯性之间的权衡空白。

## 总结

ParTY 要解决的核心矛盾是部件表达力与全身连贯性之间的固有权衡，现有整体生成方法无法对齐细粒度部件语义，而部件独立生成方法因缺乏全局一致性导致连贯性崩塌。本文抓住的切入点是“部件生成引导整体生成”，通过 PTG 实现部件级语义对齐，通过 PGN 与 HPF 实现部件与整体的动态融合，在 HumanML3D 上实现了 R-Precision Top-1 0.550 与 FID 0.035 的 SOTA 性能。本文的边界在于 TC/SC 指标依赖数据集内统计分布，跨域泛化能力未验证，且 LLM 辅助监督可能引入数据偏差。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
