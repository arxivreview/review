# CVPR2026最新论文 ｜Phrase-grounded APO for Improving Chest X-ray Report Generation ｜短语接地自动偏好优化

研究机构：美国伦斯勒理工学院、美国斯坦福大学

作者：Raziuddin Mahmood、Tanveer Syeda-Mahmood

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_69afd350a8e3)

> 放射学报告生成（RRG）模型在临床部署中面临的核心困境是幻觉与事实错误，而现有的直接偏好优化（DPO）等对齐方法依赖人工标注的偏好对，这在缺乏Ground Truth的临床推理场景中不可行。本文切入点在于利用事实核查（Fact-Checking, FC）模型自动从模型自身输出中生成代理偏好数据，实现推理时的轻量级参数更新。具体做法是构建包含短语接地损失的APO损失函数，在推理阶段对冻结的RRG模型进行微调。该方法在多个SOTA生成器上平均提升了30-40%的报告质量，但其性能上限受限于FC模型本身的检测准确率，且未验证在更复杂三维数据上的泛化能力。

## 研究背景

当放射科医生面对自动生成的报告时，最致命的错误并非语法不通，而是病灶存在性（如“无肺炎”实为“有肺炎”）或解剖定位（如“左肺”实为“右肺”）的事实性偏差。这种偏差源于视觉-语言模型（VLM）在训练数据噪声下的模式匹配倾向，导致其生成的文本与图像证据脱节。抑制此类幻觉需要显式的事实约束，而传统自然语言生成指标（如BLEU）仅衡量词汇重叠，无法捕捉临床语义错误，这迫使领域转向基于临床实体和空间定位的评估体系。

主流的对齐路线如DPO和强化学习（RL）虽能提升事实准确性，但均预设训练阶段存在高质量的Ground Truth偏好对。在临床部署的推理阶段，由于缺乏实时专家标注，这些方法失效。现有推理时对齐方法（如提示调整、解码规则修改）不更新模型权重，无法从根本上改变模型的生成策略，且难以处理多病灶句子的局部错误。本文的切入点正是填补这一空白：如何在无额外标注数据的情况下，利用模型自身的输出与外部事实核查工具的反馈，在推理阶段完成参数级的对齐优化。

## 核心方法

### 方法参照系

本文方法基于DPO框架，但关键差异在于偏好数据的来源。标准DPO要求人工标注的偏好对 $(y_w, y_l)$，而本文在推理阶段利用FC模型自动从模型输出 $r$ 中生成代理偏好对，并将空间定位误差纳入损失函数，解决了无GT场景下的对齐难题。

### 代理偏好数据生成

传统DPO在推理时无法获取 $y_w$ 和 $y_l$。本文创新性地定义模型当前输出 $r$ 为负偏好 $y_l$，并通过FC模型检测错误后，利用LLM修正生成正偏好 $y_w$。FC模型预测病灶的存在性 $E_p$ 和位置 $l_p$，与报告中指示的位置 $l_i$ 计算IOU，结合5种修正模板生成修正后的报告。这一机制将黑盒生成转化为基于证据的修正轨迹，确保了 $y_w$ 在事实上的正确性，为后续参数更新提供了可靠的监督信号。

### 短语接地APO损失

标准DPO损失仅优化文本概率，忽略空间定位错误。本文引入短语接地损失项，强制模型在生成正确文本的同时，确保病灶描述与图像解剖区域的空间重叠。损失函数定义为：

$$
\mathcal{L}_{APO}(\pi_\theta, \pi_{ref}) = -\mathbb{E}_{(x, y_w, y_l)} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)} \right) + \gamma \log \frac{O_\theta}{O_{ref}} \right]
$$

其中 $O_\theta$ 和 $O_{ref}$ 分别为当前模型和参考模型中对应病灶位置的重叠概率。该公式的物理含义是：不仅要求模型更倾向于生成修正后的报告（偏好对齐），还要求模型生成的病灶位置与图像证据的空间一致性优于参考模型（接地对齐）。$\gamma$ 平衡两者权重，解决了VLM中“叙事偏差”导致的定位不准问题。

## 实验评估

实验在RadCheck、CImaGenomeG、MS-CXR、ChestXray8和VinDr-CXR五个多机构数据集上进行，对比了MAIRA-2、R2GenGPT、XrayGPT等7个SOTA生成器。基线覆盖了VLM、蒸馏及多视图架构，但缺失基于最新原生LLM（如GPT-4o）的直接对比，仅使用In-house GPT-4。

| 生成器 | RadGraph F1 (A,G) | RadGraph F1 (C,G) | 提升幅度 |
| :--- | :--- | :--- | :--- |
| R2GenGPT | 0.54 | 0.59 | 9.3% |
| MAIRA-2 | 0.58 | 0.66 | 13.8% |
| XrayGPT | 0.39 | 0.47 | 20.5% |
| Avg.Improv. | 13.5% | 27% | 39.98% |

APO优化后，所有生成器在RadGraph F1上均有提升，平均提升39.98%。其中XrayGPT提升幅度最大（20.5%），表明APO对基础较弱的模型增益更显著。相比之下，MAIRA-2作为多视图模型，提升幅度相对较小（13.8%），暗示其原有的空间处理能力已部分抵消了APO的接地增益。

消融实验显示，仅使用FC模型进行静态报告修正（P,G列）的平均提升为26.52%，而APO对齐（C,G列）的提升为39.98%。这表明参数更新比单纯的文本后处理更有效，验证了APO损失函数中偏好对齐项的必要性。LLM修正的准确率为94.5%，临床错误率仅为4.2%，主要出现在多病灶句子中，这解释了为何APO损失中需保留短语接地项以捕捉位置形容词的归属错误。

评估指标包含RadGraph F1、BLEU、SBERT和GREEN，覆盖了临床实体和语义相似度。但论文未报告置信区间，且FC模型在RadCheck数据集（2400万对）上训练，可能存在对MIMIC-CXR衍生数据的过拟合风险。代码未公开，复现需依赖其引用的FC模型[18]，限制了可复现性。

## 关联研究分析

从问题动机看，本文与OraPO等RL路线均旨在抑制幻觉，但OraPO依赖训练时的临床奖励信号，而本文聚焦推理时的自对齐。差异根源在于部署场景：OraPO适用于有标注数据的离线训练，本文适用于无标注数据的在线部署。本文的FC模型作为代理GT，其可靠性边界取决于FC模型本身的检测准确率（0.997相关系数），若FC模型出现漏检，APO将强化错误而非纠正，这是RL路线通过大规模数据训练奖励模型所避免的。

从方法设计看，本文与LLaVA-TA等视觉接地路线均强调空间对齐，但LLaVA-TA通过主题引导的对比学习在训练阶段实现，而本文通过APO损失在推理阶段实现。差异在于数据依赖：LLaVA-TA需要大规模标注的解剖区域数据，本文仅需FC模型的预测。本文未探索FC模型在CT等三维数据上的迁移性，其基于2D胸片的36个解剖区域定位算法可能无法直接应用于三维体积数据，这是本文方法在模态扩展上的潜在盲区。

## 总结

本文要解决的核心矛盾是临床推理阶段缺乏Ground Truth导致的对齐失效。本文抓住的切入点是利用FC模型自动从模型输出中生成代理偏好数据，从而在推理阶段实现参数级更新。具体做法是构建包含短语接地损失的APO损失函数，强制文本描述与图像解剖区域的空间一致性。实验证明该方法在7个SOTA生成器上平均提升了39.98%的RadGraph F1，且优于静态报告修正。本文的边界在于其性能上限受限于FC模型的检测准确率，且未验证在三维数据上的泛化能力。当FC模型面对罕见病或复杂解剖结构时，其漏检率是否会显著增加，进而导致APO强化错误而非纠正，论文未给出回答。
