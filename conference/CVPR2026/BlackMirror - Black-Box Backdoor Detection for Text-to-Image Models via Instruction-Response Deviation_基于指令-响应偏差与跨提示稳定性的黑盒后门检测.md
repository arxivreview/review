# CVPR2026最新论文 ｜BlackMirror: Black-Box Backdoor Detection for Text-to-Image Models via Instruction-Response Deviation ｜基于指令-响应偏差与跨提示稳定性的黑盒后门检测

研究机构：中国科学院、中国科学院大学

作者：Feiran Li、Qianqian Xu、Shilong Bao 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.05921)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.05921)

> 文本到图像（T2I）模型在模型即服务（MaaS）场景下面临后门攻击威胁，但现有检测手段多依赖白盒内部信号，无法直接部署。唯一已有的黑盒基线UFID依赖全局图像相似度假设，在局部操纵攻击下失效。BlackMirror通过模式级对齐与跨提示稳定性验证，解耦了后门诱导的偏差与模型固有噪声。该方法无需训练且即插即用，但在依赖视觉语言模型（VLM）推理效率及复杂组合攻击下的泛化能力上仍存疑。

## 研究背景

当攻击者通过微调在T2I模型中植入后门时，模型在特定触发词下会生成偏离指令的图像，如将“狗”替换为“猫”。这种偏离若仅涉及局部视觉模式，全局语义相似度往往无法捕捉，导致基于整体特征匹配的防御失效。为在缺乏模型参数访问权的情况下识别此类行为，需从输入-输出对中提取细粒度的语义偏差信号，并区分这种偏差是源于后门操纵还是模型自身的生成偏置。

T2I模型供应链安全的核心矛盾在于攻击隐蔽性与检测可及性的冲突。主流防御路线如T2IShield和GrainPS依赖交叉注意力图或神经元激活等内部信号，虽在白盒设定下有效，但无法迁移至黑盒API接口。唯一的黑盒尝试UFID假设后门输出具有高度一致性，然而BadT2I等新型攻击仅操纵特定对象或风格，其余内容保持多样性，使得嵌入空间中的全局相似度分布与良性样本重叠。BlackMirror的切入点在于重新定义后门行为的特征：不再关注图像整体的相似性，而是聚焦于局部视觉模式与指令之间的语义错位，以及这种错位在提示词扰动下的稳定性。

## 核心方法

### 方法参照系

黑盒后门检测的通用流程通常基于输入-输出行为分析，通过比较正常输入与触发输入的响应差异来定位异常。本文问题与该通用流程的关键差异在于，需在不访问模型内部的前提下，从单样本或少量样本中区分“后门诱导的确定性偏差”与“模型固有的随机性偏差”，且需覆盖对象、补丁、风格等多种攻击类型。

### 模式级对齐与偏差提取

MirrorMatch模块解决了全局相似度无法定位局部操纵的问题。传统做法使用CLIP计算指令与图像的余弦相似度，但该方法在BadT2I等局部攻击下失效，因为大部分图像内容仍符合指令。本文改用语言模型（LLM）和视觉语言模型（VLM）分别提取指令中的视觉对象集合 $O_{ins}$ 和图像中的视觉对象集合 $O_{res}$。通过集合运算定义安全对象 $O_{safe} = O_{ins} \cap O_{res}$，以及可疑偏差对象 $O_{new} = O_{res} \setminus O_{ins}$ 和 $O_{lost} = O_{ins} \setminus O_{res}$。这一设计将检测粒度从图像级降至对象级，使得“狗”被替换为“猫”这类局部替换能被精确捕获，而非被整体相似度掩盖。

### 跨提示稳定性验证

MirrorVerify模块解决了将模型固有偏置误判为后门的高假阳性问题。仅凭单次生成的偏差无法区分后门与噪声，因为VLM可能提取出指令中未提及但图像中存在的背景物体（如“树”）。本文利用后门攻击的稳定性特征：触发后，操纵行为在提示词变体中持续存在；而模型偏置则随提示词变化而消失。通过模式掩码（Pattern Masking）生成 $N$ 个变体提示，保留触发器但移除安全对象。对于每个可疑对象 $o$，计算其在 $N$ 次生成中的稳定性得分：

$$ s_{final} = \max_{o \in O_{new} \cup O_{lost}} \left( \frac{1}{N} \sum_{i=1}^{N} \text{softmax}(l_{yes}^{[i]}, l_{no}^{[i]}) \right) $$

其中 $l_{yes}^{[i]}$ 和 $l_{no}^{[i]}$ 是VLM对第 $i$ 次生成图像中是否包含对象 $o$ 的logits。若 $s_{final}$ 超过阈值 $\tau$，则判定为后门。该公式通过多次采样平均消除了单次生成的随机噪声，仅保留具有统计显著性的稳定偏差。

## 实验评估

实验基于Stable Diffusion v1.5，使用LLM生成200个提示词，其中50%嵌入触发器。基线包括唯一黑盒方法UFID、朴素CLIP相似度基线CLIPD，以及白盒参考T2IShield、GrainPS和NaviT2I。BlackMirror在整体F1分数上达到89.46%，显著优于UFID的72.29%和CLIPD的65.55%。在白盒参考中，T2IShield的F1为47.31%，但BlackMirror的假阳性率（FPR）为15.09%，低于T2IShield的45.30%，表明黑盒方法在特定指标上可逼近甚至超越白盒方法。

| 方法 | 类型 | F1 (Overall) | FPR (Overall) |
| :--- | :--- | :--- | :--- |
| BlackMirror | 黑盒 | 89.46 | 15.09 |
| UFID | 黑盒 | 72.29 | 48.78 |
| CLIPD | 黑盒 | 65.55 | 42.50 |
| T2IShield | 白盒 | 47.31 | 45.30 |
| GrainPS | 白盒 | 91.29 | 8.10 |

消融实验显示，移除MirrorVerify模块后，FPR从15.09%飙升至93.06%，证实了稳定性验证对抑制假阳性的关键作用。MirrorVerify阶段的平均VLM查询次数为3.14次，表明计算开销可控。然而，在FixImgAtt攻击下，BlackMirror的F1为80.00%，低于其在ObjRepAtt下的98.04%，显示其对固定图像攻击的检测能力相对较弱，这可能与固定图像攻击缺乏“局部性”特征有关。

评估协议存在局限：仅使用Stable Diffusion v1.5，未测试其他架构；提示词生成依赖LLM，可能引入分布偏差；未报告置信区间。代码已开源，使用Qwen-8B和Qwen2.5-VL-7B，运行于两张RTX3090 GPU。

## 关联研究分析

从问题动机看，BlackMirror与UFID均针对黑盒设定，但UFID依赖全局图像相似性，假设后门输出高度一致。这一假设在VillanDiffusion等固定图像攻击下成立，但在BadT2I等局部操纵攻击下失效，因为后者仅改变部分对象，整体图像嵌入仍与良性样本接近。BlackMirror通过引入模式级对齐，将检测粒度细化至对象层面，解决了全局特征掩盖局部异常的问题。这一改进源于对后门攻击“局部性”特性的洞察，而非简单的特征工程。

从方法设计看，BlackMirror与T2IShield等白盒方法在信号源上存在根本差异。T2IShield利用交叉注意力图的同化模式，直接访问模型内部状态，而BlackMirror仅通过VLM推理间接推断语义偏差。这种黑盒设计牺牲了内部信号的精确性，但换来了跨架构的泛化能力。然而，BlackMirror依赖VLM的准确性，若VLM对特定对象识别错误，将导致漏检或误检。相比之下，T2IShield的注意力图分析不受VLM性能限制，但受限于模型架构。这种取舍反映了黑盒检测在“可及性”与“精确性”之间的权衡。

## 总结

BlackMirror旨在解决T2I模型黑盒后门检测中局部操纵难以识别的问题。现有方法如UFID依赖全局相似性，在局部攻击下失效；白盒方法无法部署于API接口。BlackMirror通过模式级对齐提取细粒度偏差，并利用跨提示稳定性验证区分后门与噪声，实现了无需训练的黑盒检测。实验显示其F1达89.46%，FPR为15.09%，优于唯一黑盒基线UFID。然而，该方法依赖VLM推理，计算开销随验证次数线性增加，且在固定图像攻击下性能下降。当VLM对复杂组合语义的识别能力不足时，模式级对齐是否仍能准确捕获后门诱导的偏差，论文未给出回答。
