# CVPR2026最新论文 ｜Superman: Unifying Skeleton and Vision for Human Motion Perception and Generation ｜视觉引导的运动词表与多模态大语言模型统一框架

研究机构：北京大学、中山大学

作者：Xinshun Wang、Peiming Li、Ziyi Wang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.02401)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.02401)

> 人体运动分析长期被割裂为“只读”的感知模型与“只写”的生成模型，前者能理解视频但无法输出姿态，后者能生成动作却依赖抽象文本输入。现有离散化方法仅基于骨架数据构建词表，切断了视觉证据与运动语义的关联。本文提出 Superman，通过视觉引导的运动分词器（Vision-Guided Motion Tokenizer, VGMT）构建混合码本，并在单一多模态大语言模型（MLLM）中统一姿态估计、运动预测与中间帧生成任务。该框架在标准基准上取得了感知与生成任务的双重最优性能，但其自回归生成机制在长时程物理合理性上的表现尚存疑。

## 研究背景

理解人体运动需要同时处理视觉外观与几何结构。当模型仅接收骨架序列时，它丢失了衣物纹理、背景遮挡等视觉上下文，导致在复杂场景中无法区分视觉相似但意图不同的动作。这种信息缺失迫使研究者将感知与生成解耦：感知模型（如 MotionLLM）擅长从视频提取语义描述，但无法生成新的三维姿态；生成模型（如 MotionGPT）擅长从文本合成动作，却无法直接处理原始视频输入。这种“读”与“写”的割裂，使得单一模型难以同时具备理解与创造能力。

人体运动预测与生成领域的主流路线正从确定性回归转向概率生成，扩散模型与流匹配模型在捕捉多模态不确定性方面表现优异，但推理延迟高，难以满足实时交互需求。与此同时，将运动视为离散 Token 序列的“运动即语言”范式兴起，通过向量量化变分自编码器（VQ-VAE）将连续姿态映射为离散词表，使大语言模型能自回归地处理运动序列。然而，现有 VQ-VAE 词表仅由骨架数据训练，视觉特征未参与量化过程，导致生成的运动缺乏视觉 grounding，在零样本泛化场景中表现受限。Superman 的切入点在于重构词表构建过程，将视觉特征与骨架几何联合量化，并在单一 MLLM 架构中统一感知与生成任务，打破模态壁垒。

## 核心方法

### 离散运动词表构建范式

将连续运动序列转化为离散 Token 序列是连接视觉感知与语言模型的关键桥梁。标准 VQ-VAE 流程包括编码、量化与解码三个阶段，其中量化步骤通过查找最近邻码本向量实现离散化。本文问题与该通用流程的关键差异在于：传统量化仅基于骨架几何特征，而 Superman 要求量化过程同时受视觉外观与几何结构约束，以构建跨模态的运动词汇。

### 视觉引导混合码本量化

VGMT 采用双流编码架构，视觉流通过冻结的 HRNet 提取特征，骨架流通过 2D 卷积捕捉时空运动学。设计动机在于解决纯骨架模型在遮挡或复杂背景下因几何信息缺失导致的预测歧义。视觉流引入视觉-骨架注意力（VSA）模块，以关节投影位置为查询点，自适应聚合周围视觉特征，增强对遮挡的鲁棒性。量化阶段引入混合码本 $\mathcal{C} = \{(\mathbf{c}_k^v, \mathbf{c}_k^s)\}_{k=1}^K$，每个码字包含配对的视觉原型与几何原型。对于时间窗口 $w$，Token 索引 $k_w$ 通过最小化联合欧氏距离确定：

$$k_w = \arg\min_{k} \left( \beta_s \| \mathbf{z}_w^s - \mathbf{c}_k^s \|_2^2 + \beta_v \| \mathbf{z}_w^v - \mathbf{c}_k^v \|_2^2 \right)$$

该公式表明，量化过程同时受几何特征 $\mathbf{z}_w^s$ 与视觉特征 $\mathbf{z}_w^v$ 驱动，权重 $\beta_s, \beta_v$ 控制两种模态的贡献比例。这种联合量化确保每个 Token 既包含运动学结构，又蕴含视觉上下文，使离散词表具备跨模态表征能力。

### 统一多任务自回归建模

基于 VGMT 生成的离散 Token 序列，Superman 将姿态估计、运动预测与中间帧生成统一为条件序列生成问题。设计动机在于利用 MLLM 的上下文学习能力实现任务间知识共享，避免专用模型的任务隔离。模型以 Qwen2.5-VL-7B 为骨干，通过低秩适配（LoRA）微调线性层，并引入运动感知微调（MAFT）模块。MAFT 包含一个交叉注意力层，以视觉特征为 Key/Value，运动 Token 嵌入为 Query，实现视频与运动序列的跨模态融合。MAFT 仅增加 <0.2% 的参数，却显著提升了视觉输入任务的性能。这种轻量级设计确保了在保持 MLLM 通用能力的前提下，针对性增强运动感知能力，避免了全参数微调的高昂计算成本。

## 实验评估

实验在 Human3.6M 与 3DPW 数据集上进行，评估姿态估计（PE）、运动预测（MP）与中间帧生成（MIB）三项任务。基线覆盖传统多任务模型（HiC, SiC）与 LLM 模型（MotionGPT, PoseLLaVA），但缺失扩散模型与流匹配模型等最新概率生成 SOTA（如 HumanCM, KinemaDiff），导致生成任务的性能对比缺乏参照系。

| 任务 | 方法 | N-MPJPE (mm) | MPJPE (mm) |
| :--- | :--- | :--- | :--- |
| PE (Human3.6M) | HiC | 45.26 | 53.86 |
| PE (Human3.6M) | Superman (w/ MAFT) | 39.41 | 51.61 |
| MP (Human3.6M) | HiC | - | 33.42 |
| MP (Human3.6M) | Superman | - | 26.13 |
| MIB (Human3.6M) | SiC | - | 103.97 |
| MIB (Human3.6M) | Superman | - | 30.61 |

Superman 在 PE 任务上以 39.41 N-MPJPE 超越 HiC 的 45.26，在 MP 任务上以 26.13 MPJPE 优于 HiC 的 33.42，在 MIB 任务上以 30.61 MPJPE 大幅领先 SiC 的 103.97，验证了统一框架在感知与生成任务上的双重优势。

消融实验揭示了视觉 grounding 与统一训练的关键作用。在 Tokenizer 消融中，纯视觉模型重建误差高达 22.5 mm，纯骨架模型为 7.7 mm，而融合模型（$\beta_s=\beta_v=0.5$）降至 4.7 mm，证明联合量化优于单模态。在 VSA 与 MAFT 消融中，基线 N-MPJPE 为 48.8，仅加 VSA 降至 44.9，仅加 MAFT 降至 42.2，两者结合降至 39.4，表明视觉-骨架注意力与运动感知微调具有协同效应。统一多任务训练相比专用模型，PE 从 46.5 降至 44.9，MP 从 27.3 降至 26.1，MIB 从 33.1 降至 30.6，证实了任务间正向知识迁移。

评估边界方面，MPJPE 指标未涵盖物理合理性维度，如关节角度限制与重心稳定性，无法量化生成动作的生物力学可行性。评估协议中，MP 与 MIB 任务仅使用骨架输入以公平对比，未测试视觉输入对生成任务的增益，限制了多模态融合效果的完整评估。可复现性方面，论文未提供代码链接，但详细报告了超参数（LoRA rank=8, MAFT heads=8）与硬件配置（2x NVIDIA H20），具备复现基础。

## 关联研究分析

从问题动机看，Superman 与 MotionGPT 均基于“运动即语言”范式，但 MotionGPT 仅处理文本到运动的生成，无法感知原始视频，而 Superman 通过 VGMT 将视觉特征嵌入量化过程，实现了视频到运动的感知-生成闭环。这一差异源于任务定义：MotionGPT 聚焦于文本驱动的动作合成，而 Superman 旨在统一多模态输入下的运动分析。Superman 的视觉 grounding 机制解决了 MotionGPT 在缺乏视觉上下文时生成动作缺乏真实性的问题，但代价是引入了视觉骨干的计算开销。

从方法设计看，Superman 与 HumanCM 在生成范式上存在根本分歧。HumanCM 采用一致性模型实现单步扩散生成，旨在捕捉多模态不确定性并保证实时性，而 Superman 采用自回归 MLLM 生成离散 Token，依赖序列建模能力而非概率分布估计。HumanCM 在 Human3.6M 上取得 0.382 ADE，而 Superman 在 MP 任务上取得 26.13 MPJPE，两者指标单位不同，无法直接比较。Superman 的自回归机制在长时程预测中可能累积误差，且缺乏显式物理约束，而 HumanCM 的扩散过程通过迭代去噪逐步逼近物理合理轨迹。Superman 的优势在于统一架构与多模态融合，而 HumanCM 的优势在于生成质量与实时性，两者代表了“统一性”与“专业性”的不同取舍。

## 总结

Superman 要解决的核心矛盾是运动感知与生成任务的架构割裂，以及离散运动词表缺乏视觉 grounding 的问题。现有方法要么只能理解视频无法生成动作，要么只能生成动作无法处理原始视频，且词表构建仅依赖骨架数据，切断了视觉证据与运动语义的关联。Superman 通过 VGMT 混合码本量化机制，将视觉特征与骨架几何联合离散化，并在单一 MLLM 中统一多任务训练，实现了感知与生成的闭环。实验证明，该框架在 Human3.6M 上 PE 任务 N-MPJPE 达 39.41，MP 任务 MPJPE 达 26.13，均超越传统多任务模型 SOTA。然而，论文未与最新概率生成 SOTA（如 HumanCM）进行直接对比，且自回归生成机制在长时程预测中的物理合理性未得到充分验证。当预测时程从 320ms 扩展至 1000ms 以上时，自回归 Token 序列的误差累积是否会导致物理不合理动作，论文未给出回答。
