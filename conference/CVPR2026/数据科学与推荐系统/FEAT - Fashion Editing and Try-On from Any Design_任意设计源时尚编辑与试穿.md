# CVPR2026最新论文 ｜FEAT: Fashion Editing and Try-On from Any Design ｜任意设计源时尚编辑与试穿

作者：Soye Kwon、Keonyoung Lee、Dahuin Jung 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.02393)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.02393)

> 多模态时尚生成面临设计源受限与配饰支持缺失的双重瓶颈，现有方法难以从艺术品或自然图像中提取有效设计线索，且无法处理完整穿搭。FEAT 通过解耦图像提示中的内容与风格特征，并引入无训练的衣物移除机制，实现了从任意视觉源到服装及配饰的端到端编辑与试穿。该方法在视觉保真度与多模态一致性上优于基线，但其对非服装源的结构映射准确性及物理可制造性仍未得到验证。

## 研究背景

虚拟试穿（Virtual Try-On, VTON）的核心挑战在于同时保持人体身份、移除原有衣物并合成新衣物，这要求模型在潜空间中精确控制不同区域的噪声演化。传统方法依赖几何变形或成对训练数据，导致在非刚性姿态下出现伪影，且难以扩展至未见过的时尚单品。扩散模型（Diffusion Models）的引入提供了端到端生成的能力，但多模态条件注入时，图像提示中的内容（如形状、轮廓）与风格（如颜色、纹理）特征往往纠缠在一起，导致内容泄露或风格丢失。

当前主流路线如 ControlNet 结合 IP-Adapter 虽能处理草图与图像条件，但直接注入纠缠特征会过度放大内容线索，抑制文本与草图的引导作用。InstantStyle 等先前工作通过完全移除内容信息来缓解泄露，但这牺牲了用户希望保留的结构线索。此外，现有方法多局限于服装图像输入，无法利用艺术品或自然照片等更广泛的设计源，且忽视了鞋包等配饰的整体搭配需求。FEAT 的切入点在于区分内容与风格，通过选择性注入保留结构线索，同时通过正交投影无训练地移除残留衣物，从而支持任意设计源与完整穿搭。

## 核心方法

### 方法参照系

FEAT 基于 Stable Diffusion XL 架构，利用 ControlNet 处理草图条件，IP-Adapter 处理图像条件。与标准流程的关键差异在于，它不再将图像特征作为整体注入，而是将其解耦为内容与风格两个独立通道，并分别路由至 U-Net 的不同注意力块，同时引入无训练的噪声融合机制以替代传统的成对训练衣物移除。

### 解耦双注入（DDI）

设计动机在于解决 IP-Adapter 直接注入导致的内容泄露问题，即图像中的面部或物体形状干扰了草图与文本的引导。DDI 首先利用 InstantStyle 的观察，即 U-Net 不同注意力块对内容与风格具有不同敏感性，确定风格块与内容块。随后，通过内容减法代理嵌入（CSPE）在 CLIP 图像嵌入空间中抑制内容：保留图像提示 $i$ 的亮度通道 $L(i)$ 并应用全局模糊 $B_\sigma$ 生成内容代理，其 CLIP 嵌入 $\phi(B_\sigma(L(i)))$ 从原始嵌入 $\phi(i)$ 中减去，得到仅含风格的嵌入 $\mathbf{e}_{style}$。

$$ \mathbf{e}_{style} = \phi(i) - \phi(B_\sigma(L(i))) $$

该公式通过减去仅包含结构信息的代理嵌入，剥离了颜色与纹理之外的内容线索。$\mathbf{e}_{style}$ 仅注入风格块，而原始嵌入 $\phi(i)$ 注入内容块，配合独立的缩放因子，实现了内容与风格的独立控制，避免了完全移除内容导致的实用性损失。

### 正交引导噪声融合（OGNF）

设计动机在于解决 ControlNet 与 IP-Adapter 组合后残留衣物无法彻底移除的问题，且避免依赖昂贵的成对数据集训练。OGNF 包含正交时尚移除（OFR）与区域自适应噪声融合（RANF）。OFR 通过正交投影从潜变量中移除衣物方向：将衣物分割掩码 $g$ 与白色背景 $w$ 编码为潜变量 $z_g, z_w$，计算衣物特定方向 $v = z_g - z_w$，归一化后得到单位向量 $u$。

$$ \tilde{z} = z_p - \alpha \langle z_p, u \rangle u $$

其中 $z_p$ 为人像潜变量，$\alpha$ 控制移除强度。该操作在潜空间中减去衣物成分的投影，保留面部与背景。RANF 将输入划分为新衣物合成区、旧衣物移除区与非衣物区，分别施加不同的噪声策略：新衣物区使用草图引导，旧衣物区无草图引导以消除残留，非衣物区通过噪声重注入保持一致性。这种三区域设计无需成对数据即可实现完整试穿。

## 实验评估

实验在 VITON-HD 与 DressCode 数据集上进行，基线包括 ControlNet+IP-Adapter、PICTURE、MGD 及 ControlNet-SDXL。基线覆盖了主流的多模态条件注入路线，但缺失基于混合专家（MoE）路由的最新方法如 VersaVogue，以及离散令牌方法如 GarmentGPT，这可能影响对细粒度控制上限的判断。

| 方法 | GPT-4V Elo (Garment) | Sketch CD (Garment) | Image Score (Garment) | Text CLIP-T (Garment) |
| :--- | :--- | :--- | :--- | :--- |
| ControlNet+IP-Adapter | 1037.39 | 10.42 | 0.33 | - |
| PICTURE | 883.80 | 14.54 | 0.31 | - |
| **FEAT** | **1172.73** | **6.95** | **0.37** | - |

在服装数据集上，FEAT 的 GPT-4V Elo 得分 1172.73 显著高于 ControlNet+IP-Adapter 的 1037.39，Sketch CD 从 10.42 降至 6.95，表明草图形状对齐更优且残留衣物更少。在配饰数据集上，FEAT 同样取得最高 Elo 得分 1207.73，验证了其对非服装单品的泛化能力。

| 组件 | Sketch CD | Image Score | Text CLIP-T |
| :--- | :--- | :--- | :--- |
| Baseline (ControlNet+IP) | 9.71 | 0.28 | 27.01 |
| w/o SDI | 4.89 | 0.30 | 27.58 |
| w/o CSPE | 4.52 | 0.29 | 27.42 |
| w/o OFR | 5.57 | 0.34 | 27.79 |
| w/o RANF | 5.28 | 0.33 | 27.72 |
| **Full FEAT** | **4.15** | **0.36** | **27.88** |

消融实验显示，移除 SDI 或 CSPE 均导致 Sketch CD 上升，证实内容与风格解耦对形状保真度的必要性。移除 OFR 或 RANF 后，Image Score 下降，表明正交投影与区域噪声融合对抑制内容泄露至关重要。Full FEAT 在所有指标上均优于各消融变体，验证了组件间的协同作用。

评估指标包含 GPT-4V Elo、Chamfer Distance、Style Score 与 CLIP-T，缺乏 FID 等通用视觉质量指标，且 GPT-4V 评分的主观性难以完全排除。实验在单张 NVIDIA A6000 GPU 上进行，使用 DDIM 采样器 50 步，超参数固定，代码与数据集已公开，具备可复现性。

## 关联研究分析

从问题动机看，FEAT 与 InstantStyle 均关注内容泄露，但 InstantStyle 通过完全移除内容信息来保证风格纯度，而 FEAT 通过 CSPE 保留结构线索，这源于时尚设计中对形状控制的实际需求。InstantStyle 适用于纯风格迁移，而 FEAT 适用于需要保留设计源结构信息的编辑任务。这一差异反映了任务特性对解耦策略的决定作用：当用户希望从艺术品中提取形状时，完全移除内容是不可接受的。

从方法设计看，FEAT 与 PICTURE 均支持多模态输入，但 PICTURE 依赖成对训练数据且仅支持服装图像，而 FEAT 通过 OGNF 实现无训练衣物移除并扩展至配饰。PICTURE 的局限性在于其训练数据覆盖范围，导致其对未见过的时尚单品泛化能力不足。FEAT 的正交投影方法不依赖数据分布，因此在配饰试穿上表现更优。然而，FEAT 未验证物理一致性，而 PICTURE 也未涉及，这提示视觉高保真与物理可制造性之间的鸿沟仍是该领域的共同盲区。

## 总结

FEAT 旨在解决多模态时尚生成中设计源受限与配饰支持缺失的矛盾，通过解耦图像提示中的内容与风格特征，并引入无训练的衣物移除机制，实现了从任意视觉源到完整穿搭的端到端编辑。该方法在服装与配饰数据集上均取得 SOTA 性能，GPT-4V Elo 得分在服装上达 1172.73，Sketch CD 降至 6.95，显著优于基线。其边界在于未验证物理可制造性，且对非服装源的结构映射准确性缺乏量化评估。当设计源为高度抽象的艺术品时，CSPE 提取的结构线索是否足以支撑合理的服装形状生成，论文未给出回答。
