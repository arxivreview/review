# CVPR2026最新论文 ｜InsCal: Calibrated Multi-Source Fully Test-Time Prompt Tuning for Object Detection ｜校准多源完全测试时提示微调

研究机构：美国罗切斯特理工学院

作者：Xiaofan Que、Dingrong Wang、Xumin Liu 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_c7048820b339)

> 域自适应目标检测旨在解决检测器在跨域场景下因分布偏移导致的性能急剧下降问题，其核心价值在于规避目标域高昂的标注成本。现有测试时适应方法在缺乏标签时易陷入过度自信陷阱，导致置信度与真实精度严重偏离，本文切入点在于引入实例级校准机制以抑制该风险。具体做法是结合文本引导图像增强与多源模型集成，构建校准熵最小化目标以更新提示嵌入。该方法在完全测试时适应设定下有效降低了校准误差，但其性能上限仍受限于单样本适应的固有信息量瓶颈。

## 研究背景

当预训练视觉语言模型面对未见过的目标域时，其零样本泛化能力往往因风格或光照差异而失效。这种失效不仅表现为检测精度下降，更隐蔽地体现为模型对错误预测赋予过高的置信度，即校准失效。在自动驾驶等安全关键场景中，高置信度的错误检测比低置信度的正确检测更具危险性，因为系统会据此做出错误的决策。

测试时适应（TTA）通过在推理阶段利用无标签目标域数据更新模型参数来缓解分布偏移，其中完全测试时适应（FTTA）仅依赖单张测试图像，对计算资源和数据访问要求最低。然而，主流FTTA方法如测试时提示微调（TPT）依赖熵最小化目标来优化提示嵌入，该目标倾向于将所有增强视图的预测推向高置信度，即便预测本身是错误的。这种机制在域偏移显著时会导致严重的过度自信，使得模型在错误预测上表现出极高的确定性，从而加剧了校准失效问题。

InsCal针对这一特定失效模式，提出在FTTA框架中引入实例级校准机制。与传统的特征对齐或伪标签精炼策略不同，InsCal不直接修改网络权重或生成伪标签，而是通过调整提示嵌入的更新过程，显式地惩罚高置信度的错误预测。这一设计将校准问题从后处理阶段前移至适应过程本身，使得模型在适应新域的同时，能够自动调整其置信度分布，从而在缺乏标签信息的条件下实现更可靠的检测。

## 核心方法

### 方法参照系

InsCal基于测试时提示微调（TPT）框架，该框架通过最小化单张测试图像多个增强视图的预测熵来优化文本提示嵌入。与标准TPT的关键差异在于，InsCal将单源模型扩展为多源模型集成，并引入文本引导图像增强（TGIA）和校准熵最小化目标，以解决域偏移导致的过度自信问题。

### 文本引导图像增强

标准TPT使用随机裁剪或平移等传统增强技术生成视图，但这些技术无法显式缩小源域与目标域的风格差距。InsCal引入文本引导图像增强（TGIA），通过最小化方向对比损失将目标图像风格迁移至源域风格。该损失函数定义为：

$$ \mathcal{L}_{TGIA} = \frac{1}{|I_z||T|} \cdot \frac{I_z \cdot T}{|I_z||T|} + \vartheta \|A_\omega(z) - z\|^2 $$

其中 $I_z$ 表示图像嵌入因增强产生的变化，$T$ 表示文本风格从目标域到源域的转换方向。第一项鼓励图像风格变化方向与文本风格转换方向对齐，第二项是L2正则化项，确保增强图像在内容上保持与原始图像的一致性。这一设计动机在于，通过显式地将目标图像风格迁移至源域，可以缩小域差距，使得多源模型能够更准确地识别目标域中的物体，从而为后续的校准提供高质量的预测基础。

### 校准熵最小化

标准TPT的熵最小化目标 $\min_p -\sum_i \tilde{p}_i \log \tilde{p}_i$ 会促使所有增强视图的预测趋向高置信度，导致过度自信。InsCal提出校准熵最小化目标，通过引入基于前两个最高预测概率的校准因子来调整每个视图的权重。校准熵定义为：

$$ \tilde{H}[\tilde{p}_i] = -(1 + (p_{1st} - p_{2nd})^\epsilon) p_i \log p_i $$

其中 $p_{1st}$ 和 $p_{2nd}$ 分别为最高和第二高的预测概率，$\epsilon$ 是控制校准敏感度的超参数。当 $p_{1st}$ 远大于 $p_{2nd}$ 时，校准因子增大，增加高置信度预测的权重；当两者接近时，校准因子减小，降低低置信度预测的权重。这一设计动机在于，通过动态调整不同置信度预测的权重，InsCal能够抑制错误预测的高置信度，同时保留正确预测的高置信度，从而在适应过程中实现更可靠的校准。

## 实验评估

实验在Diverse Weather (DWD)数据集上进行，该数据集包含DayClear、NightClear、NightRainy、DuskRainy和DayFoggy五个域。基线方法包括无监督域自适应（UDA）、源无关域自适应（SFDA）和标准TPT。InsCal在Night Clear、Dusk Rainy和Night Rainy域上优于标准TPT，在Day Foggy域上与UDA方法性能接近，尽管UDA方法拥有源数据和无标签目标数据的完整访问权限。

InsCal将检测期望校准误差（D-ECE）从标准TPT的19.5%降低至13.2%，降幅约为6.3个百分点。这一结果表明，校准熵最小化目标有效抑制了过度自信问题。然而，InsCal的mAP绝对值仍低于UDA方法，例如在Day Foggy域上，InsCal的mAP略低于两个UDA方法。这一差距反映了FTTA设定下仅使用单张测试图像的信息量限制，即使校准得到改善，检测精度的提升空间仍然有限。

评估协议主要关注D-ECE和mAP两个指标，但未报告置信区间或多次运行的方差。代码未公开，超参数如校准敏感度 $\epsilon$ 和正则化系数 $\vartheta$ 的具体取值未在论文中详细列出，这限制了结果的复现性。此外，论文未对比知识库中最新的CD-Buffer等双缓冲TTA方法，可能因计算开销或设定不同，这使得InsCal在TTA路线中的相对位置难以精确评估。

## 关联研究分析

从问题动机看，InsCal与CD-Buffer均针对TTA中的适应稳定性问题，但切入点不同。CD-Buffer通过双缓冲机制平衡适应速度与灾难性遗忘，适用于在线TTA场景，其中模型需要持续适应多个批次的数据。InsCal则聚焦于FTTA场景下的校准失效，通过校准熵最小化解决单样本适应中的过度自信问题。这一差异源于任务特性：在线TTA面临历史数据冲突和遗忘风险，而FTTA无历史数据，但面临单样本信息量不足导致的校准偏差。InsCal的校准机制是否可迁移至在线TTA场景，以同时解决遗忘和校准问题，论文未给出回答。

从方法设计看，InsCal与DiffTPT均使用生成式增强技术，但实现方式不同。DiffTPT利用预训练扩散模型生成增强视图，而InsCal使用文本引导图像增强（TGIA）通过方向对比损失实现风格迁移。DiffTPT的增强依赖于扩散模型的生成质量，可能引入与原始图像内容不一致的伪影；InsCal的TGIA则通过L2正则化确保内容一致性，但风格迁移的保真度受限于文本描述的准确性。这一设计选择反映了两种不同的域差距缩小策略：生成式增强通过创建新视图来模拟源域风格，而TGIA通过修改现有视图的风格来对齐源域。在文本描述不准确或域差距过大时，TGIA的风格迁移效果可能受限，这一局限性论文未深入探讨。

## 总结

InsCal要解决的核心矛盾是FTTA场景下熵最小化导致的过度自信与校准失效问题。现有TPT方法无法区分正确的高置信度预测和错误的高置信度预测，而InsCal通过引入基于前两个最高预测概率的校准因子，动态调整不同置信度预测的权重，从而抑制错误预测的高置信度。该方法结合文本引导图像增强和多源模型集成，在DWD数据集上将D-ECE从19.5%降低至13.2%，并在多个域上优于标准TPT。然而，InsCal的mAP绝对值仍低于UDA方法，反映了FTTA设定下单样本信息量的固有限制。当目标域与源域的风格差距极大，或文本描述无法准确捕捉域特征时，TGIA的风格迁移效果可能显著下降，此时校准机制是否仍能维持可靠的置信度分布，论文未给出回答。
