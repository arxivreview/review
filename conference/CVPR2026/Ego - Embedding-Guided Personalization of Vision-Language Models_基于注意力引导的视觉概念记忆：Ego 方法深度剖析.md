## 导读

大型视觉语言模型（LVLM）在通用视觉理解上表现优异，但难以识别用户特定的非通用实体，如个人宠物或特定物品。现有个性化方案要么依赖每个概念独立的测试时微调，导致扩展性差且计算开销大；要么依赖外部视觉模块进行检索，增加了系统复杂度且引入了额外的推理延迟。本文提出 Ego（Embedding-Guided Personalization），利用 LVLM 内部的跨模态注意力机制提取代表特定概念的视觉 Token，构建无需训练、无需外部模块的紧凑视觉记忆。该方法在统一基准上实现了单概念、多概念及视频个性化的 SOTA 性能，但其对 LVLM 基础视觉理解能力的强依赖及缺乏动态概念更新机制，限制了其在长程交互中的适用性。

## 研究背景

LVLM 个性化旨在使预训练模型能够识别并推理用户特定的视觉实体。这一过程涉及两个核心概念：视觉 Token 与上下文学习（In-Context Learning, ICL）。视觉 Token 是视觉编码器将图像映射至 LLM 嵌入空间的离散表示，而 ICL 允许模型在不更新参数的情况下，通过输入上下文中的示例或信息调整行为。然而，通用 LVLM 的视觉 Token 通常包含大量背景噪声，且模型缺乏对特定实体的持久记忆，导致其在面对未见过的个性化概念时，无法有效区分主体与背景，也无法在多次交互中保持一致性。

当前 LVLM 个性化研究主要分为三条路线：测试时微调、全量/参数高效微调以及无训练后处理。测试时微调方法（如 MyVLM, Yo’LLaVA）为每个概念训练分类头或前缀 Token，虽然精度高但无法扩展至多概念场景，且边缘设备部署困难。微调方法（如 RAP, PLVLM）通过大规模数据训练模型识别参考图像中的概念，但推理时仍需输入参考图像，导致上下文长度瓶颈，且训练过程限制了模型对多概念场景的泛化能力。无训练方法（如 R2P, PeKit）试图通过外部视觉模块（如 DINOv2, CLIP）进行特征检索或分割，虽然避免了训练，但引入了外部依赖和额外的推理开销。本文的切入点在于利用 LVLM 自身的注意力机制，将个性化概念压缩为内部视觉记忆，从而在保持黑盒兼容性的同时，消除外部模块依赖与参考图像重处理开销。

## 核心方法

### 方法参照系

本文问题属于“记忆与检索增强”路线的视觉变体。标准流程为：从用户历史中提取特征 → 存储为记忆 → 推理时检索并注入上下文。与文本 RAG 不同，本文的记忆载体为视觉 Token，提取机制为注意力引导而非相似度检索，且记忆直接嵌入 LLM 空间，无需外部编码器。

### 注意力引导嵌入提取

传统方法在推理时直接输入参考图像，导致视觉 Token 数量庞大且包含大量无关背景。Ego 在概念引入阶段，通过 LLM 生成描述性关键词，并利用这些关键词对视觉 Token 的跨模态注意力分数，筛选出最具代表性的视觉子集。这一设计解决了外部检索方法依赖额外视觉模型的问题，同时通过压缩 Token 数量降低了推理时的上下文负担。

$$
S_j = \frac{1}{|W|} \sum_{w \in W} \max_{h \in H, l \in L} A^{[l,h]}_{w,j}
$$

其中 $S_j$ 为第 $j$ 个视觉 Token 的重要性分数，$A^{[l,h]}_{w,j}$ 为第 $l$ 层第 $h$ 头中关键词 $w$ 对视觉 Token $j$ 的注意力分数。该公式通过最大化跨层跨头的注意力并平均关键词得分，量化了每个视觉 Token 对描述特定概念的重要性，从而筛选出 Top-K Token 作为概念记忆。

### 动态概念记忆大小与层选择

固定数量的视觉 Token 无法适应不同尺寸的主体（如手机 vs. 人物）。Ego 利用 LVLM 估计主体在图像中的面积占比 $\alpha_c$，动态计算记忆大小 $K_c = \min(K, \alpha_c \times N_r)$。此外，由于不同 LVLM 的视觉信息分布在不同层，Ego 提出基于 COCO 数据集的自动层选择机制，通过计算注意力 Top-K 与分割掩码的重叠率，筛选出视觉交互最强的 $L$ 层。这一设计解决了固定层数假设在不同模型架构下失效的问题，确保了记忆提取的鲁棒性。

$$
K_c = \min \left( K, \frac{\alpha_c}{100} \times N_r \right)
$$

其中 $K$ 为最大允许 Token 数，$N_r$ 为参考图像的总视觉 Token 数。该公式根据主体面积动态调整记忆容量，小主体使用更少 Token 以节省上下文，大主体使用更多 Token 以保留细节，实现了记忆效率与精度的平衡。

## 实验评估

实验在 InternVL3-14B 和 Qwen2.5-VL-7B 上，使用 This-is-my、MyVLM、Yo’LLaVA 和 RAP 数据集，对比 RAP（微调）、R2P、PeKit（无训练）及 Ego。基线覆盖了主流微调与无训练路线，但排除了 MyVLM 和 Yo’LLaVA 等测试时微调方法，理由是扩展性差且性能一致低于其他方法。

| 方法 | 模型 | 训练时间 | This-is-my (Single) F1 | This-is-my (Multi) F1 | RAP (Multi) F1 |
|---|---|---|---|---|---|
| RAP | Intern | 24hrs | 77.0 | – | – |
| R2P | Intern | 5.98s | 62.0 | – | – |
| PeKit | – | 21.3s | 89.2 | – | – |
| Ego (1-ref) | Intern | 1.25s | **91.3** | **90.7** | **98.4** |
| Ego (5-ref) | Intern | 6.25s | **92.8** | **90.9** | – |

Ego 在单概念和多概念识别任务上均取得 SOTA 性能，1-ref 设置下 This-is-my 单概念 F1 达 91.3，优于 PeKit 的 89.2 和 RAP 的 77.0。在多概念任务上，Ego 的 F1 达 90.7，显著优于其他方法，表明其视觉记忆机制在多实体场景下具有更强的区分能力。

| 方法 | 视觉 Token 比例 | 关键词注入 | F1 Score |
|---|---|---|---|
| Full Visual | 100% | 否 | 84.1 |
| Uniform | 20% | 否 | 77.7 |
| Ego (1-view) | 20% | 是 | 80.4 |
| Ego (5-view) | 20% | 是 | **85.7** |

消融实验显示，Ego 的注意力引导 Token 选择优于均匀采样（77.7 vs. 80.4），且结合关键词注入后性能进一步提升。5-ref 设置下 F1 达 85.7，接近全视觉 Token（84.1）的性能，但仅使用 20% 的 Token，证明了注意力引导提取在压缩率与精度之间的优越平衡。

评估协议统一了骨干网络、预处理和指标，增强了可比性。但实验仅使用静态图像和短视频，未涉及长程动态概念更新。代码声明将公开，但当前未提供超参数细节，如层选择的具体 $L$ 值及 COCO 校准集大小，可能影响复现性。

## 关联研究分析

从方法设计看，Ego 与 R2P 和 PeKit 同属无训练路线，但 Ego 摒弃了外部视觉模块，转而利用 LVLM 内部注意力。R2P 依赖 CLIP 进行属性检索，PeKit 依赖 DINOv2 进行分割，两者均引入了外部计算开销且受限于外部模型的泛化能力。Ego 的注意力引导机制直接利用 LVLM 的跨模态对齐能力，避免了外部模块的瓶颈，但其性能高度依赖 LVLM 的基础视觉理解能力，若 LVLM 对特定概念理解不足，注意力筛选可能失效。

从问题动机看，Ego 与 RAP 等微调方法在“记忆持久性”上形成对比。RAP 通过 LoRA 微调将概念知识固化在参数中，但推理时需输入参考图像，导致上下文长度限制。Ego 将概念压缩为视觉 Token 记忆，推理时仅需注入少量 Token，无需重处理参考图像，解决了上下文瓶颈。然而，Ego 的记忆是静态的，一旦概念引入，记忆即固定，无法随用户交互动态更新或遗忘，这在长程个性化场景中可能成为局限。

## 总结

Ego 旨在解决 LVLM 个性化中外部模块依赖与参考图像重处理开销的矛盾。其切入点在于利用 LVLM 内部注意力机制提取紧凑视觉记忆，无需训练或外部工具。方法通过注意力引导 Token 选择和动态记忆大小，实现了单概念、多概念及视频个性化的 SOTA 性能，1-ref 设置下 This-is-my 单概念 F1 达 91.3，多概念 F1 达 90.7。实验表明，Ego 在统一基准上优于微调与无训练基线，且推理开销极低。然而，Ego 的记忆机制是静态的，缺乏动态更新与遗忘能力，且对 LVLM 基础视觉理解能力有强依赖。当用户偏好或概念属性随时间变化时，静态视觉记忆是否仍能保持识别准确性，论文未给出回答。
