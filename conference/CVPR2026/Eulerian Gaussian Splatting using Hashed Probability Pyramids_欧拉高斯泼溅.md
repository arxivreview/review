# CVPR2026最新论文 ｜Eulerian Gaussian Splatting using Hashed Probability Pyramids ｜欧拉高斯泼溅

研究机构：美国哈佛大学、谷歌DeepMind

作者：Mia Gaia Polansky、George Kopanas、Stephan Garbin 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.29136)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.29136)

> 3D高斯泼溅（3D Gaussian Splatting, 3DGS）在优化过程中依赖脆弱的启发式规则进行基元增删，导致局部最优与结构僵化。现有拉格朗日方法直接操作离散基元，无法像神经辐射场（NeRF）那样通过连续场优化实现全局自适应。本文提出欧拉高斯泼溅（Eulerian Gaussian Splatting, EGS），将基元位置视为从可学习体积概率密度场中采样的样本，通过梯度下降优化该概率场而非直接移动基元。该方法在随机初始化下实现了与运动恢复结构（Structure from Motion, SfM）初始化方法相当的重建质量，但其概率场表示在大规模场景下的哈希冲突处理及收敛稳定性仍存疑。

## 研究背景

3DGS通过显式各向异性高斯基元与可微光栅化实现了实时渲染，但其训练核心依赖自适应密度控制（Adaptive Density Control, ADC）。ADC通过监测位置梯度阈值决定基元的分裂、克隆或剪枝，这种基于局部梯度的离散操作在多模态能量景观中易陷入局部最优，且缺乏全局稀疏性约束，导致基元冗余爆炸与高频细节模糊。

主流优化路线试图改进ADC的评分机制，如Taming-3DGS引入基于显著性的排序，3DGS-MCMC采用布朗运动随机探索，但这些方法本质上仍是拉格朗日视角，即直接重构离散基元集合。这种范式下，缺乏局部梯度的基元无法自适应，必须依赖额外启发式进行擦除与重插入。本文切入点在于将视角转换为欧拉视角：不直接优化基元位置，而是优化一个控制基元分布的连续概率密度函数，使新空间结构能随损失函数需求在任意位置涌现，从而消除手工设计的密度控制规则。

## 核心方法

### 概率渲染模型与欧拉视角转换

标准3DGS优化流程中，基元集合 $\mathcal{G}$ 是固定或动态调整的离散变量，优化目标直接作用于基元参数。本文的关键差异在于将基元位置 $\mu_i$ 视为随机变量，其分布由参数 $\theta$ 定义的概率密度函数 $p_\theta(\mu)$ 决定。渲染过程变为从该分布中采样 $N$ 个高斯中心，查询属性哈希网格获取其余参数，再执行标准3DGS光栅化。这种转换使得优化过程仅通过梯度信号即可在体积内自由分配概率质量，无需显式的分裂或剪枝操作。

### 哈希概率金字塔

高分辨率体积概率分布的参数化面临内存指数增长问题。本文引入哈希概率金字塔（Hashed Probability Pyramid），一种多尺度分层网格表示。其核心公式为：

$$ p_\theta(\mu) = \prod_{\ell=0}^{L-1} f_\theta^{(\ell)}(\mu) $$

其中 $f_\theta^{(\ell)}$ 是第 $\ell$ 层的分段常数函数。该设计动机在于解决标准网格在高分辨率下内存不可行的问题。金字塔底层（$\ell=0$）全局归一化，上层在 $2 \times 2 \times 2$ 块内归一化。通过哈希函数 $T_\ell$ 将上层网格映射到有限的 $B$ 个块，利用场景稀疏性共享参数。例如，在 $L=3$ 层、预算 $B=3$ 时，金字塔仅用8个自由度模拟12个二进制的分布，大幅降低参数量同时保持对薄结构的解析能力。

### 控制变量梯度估计器

从概率场采样引入蒙特卡洛估计的高方差问题，导致自动微分（路径估计器）训练缓慢且收敛差。本文设计了一个基于控制变量的无偏梯度估计器，用于计算 $\nabla_\theta I$。其核心公式为：

$$ \nabla_\theta I \approx \sum_{i=0}^{M-1} (I - I_{-i}) \nabla_\theta \log p_\theta(\mu_i) $$

其中 $I_{-i}$ 是排除第 $i$ 个高斯后的渲染图像。该设计动机在于隔离每个高斯对渲染图像的独立贡献，从而显著降低梯度方差。由于 $I_{-i}$ 与 $\mu_i$ 统计独立，且 $\mathbb{E}[\nabla_\theta \log p_\theta] = 0$，该估计器保持无偏性。实际计算中，$(I - I_{-i})$ 可通过自动微分过程中已有的属性梯度高效获得，无需额外渲染 $M$ 次图像，计算效率与标准自动微分相当，但梯度信号更稳定。

## 实验评估

实验在Mip-NeRF 360、Tanks & Temples (T&T) 和Deep Blending (DB) 数据集上进行，对比基线包括Taming-3DGS和3DGS-MCMC。基线覆盖主要优化路线，但缺失FastGS、GS^2等2025-2026年最新SOTA方法，且未对比纯前馈重建方法。

| 配置 | Mip-NeRF 360 (Random) PSNR/SSIM/LPIPS | T&T (Random) PSNR/SSIM/LPIPS | DB (Random) PSNR/SSIM/LPIPS |
| :--- | :--- | :--- | :--- |
| Taming-3DGS | 28.30 / 0.83 / 0.23 | 24.36 / 0.83 / 0.23 | 29.76 / 0.90 / 0.30 |
| 3DGS-MCMC | 28.38 / 0.84 / 0.20 | 24.00 / 0.82 / 0.24 | 29.21 / 0.90 / 0.31 |
| EGS (Pre-refinement) | 29.29 / 0.88 / 0.20 | 24.10 / 0.84 / 0.22 | 29.69 / 0.90 / 0.31 |
| EGS (Post-refinement) | 29.52 / 0.88 / 0.19 | 24.36 / 0.85 / 0.21 | 30.49 / 0.91 / 0.30 |

EGS在随机初始化下全面超越Taming-3DGS和MCMC，Mip-NeRF 360 PSNR达29.52，接近COLMAP初始化下的SOTA水平，证明概率场优化能有效恢复几何与外观。

消融实验显示，移除自定义梯度估计器（使用自动微分）导致PSNR从29.29骤降至22.35，SSIM从0.88降至0.62，表明控制变量对稳定性至关重要。移除不透明度正则化导致PSNR下降2.96，移除缩放正则化下降0.22，说明正则化对防止基元膨胀有效。防御性采样（添加噪声）移除后PSNR下降0.09，影响较小，表明模型后期已能良好定位质量。

评估边界方面，论文未报告训练时间与内存占用，无法直接对比渲染效率。代码未公开，超参数如哈希预算 $B$ 和收缩因子 $a=3/4$ 的敏感性未详细讨论。随机初始化设定下，EGS在复杂动态场景（如NeRF On-the-go）的鲁棒性未验证，仅测试了静态场景。

## 关联研究分析

从问题动机看，EGS与3DGS-MCMC均旨在解决ADC的局部最优问题，但路径截然不同。MCMC通过布朗运动随机探索空间，本质是拉格朗日视角下的随机搜索，依赖不透明基元隐含的概率分布引导重生成；EGS则显式学习一个全局归一化的概率密度场，通过梯度下降直接优化该场，消除了随机探索的盲目性。差异根源在于MCMC将概率视为隐式统计量，而EGS将其作为显式优化变量。这种显式化使得EGS能更精确地响应损失函数需求，但引入了概率场参数化的复杂性，如哈希冲突处理，这是MCMC无需面对的。

从方法设计看，EGS与INPC（Implicit Neural Point Clouds）共享概率场放置基元的思路，但INPC基于八叉树，其空间细化仍依赖启发式分割与剪枝规则，限制了灵活性；EGS采用哈希概率金字塔，通过哈希共享参数实现多尺度分辨率，避免了八叉树的结构性偏差。差异根源在于INPC将概率场与几何结构耦合，而EGS将概率场与属性网格解耦，前者在结构复杂时易引入次优决策，后者通过哈希机制在内存效率与分辨率间取得平衡。然而，EGS的哈希机制在场景极度稀疏或分布高度非均匀时，哈希碰撞可能导致概率质量分配不均，论文未深入探讨此极端情况下的表现。

## 总结

EGS旨在解决3DGS中启发式密度控制导致的局部最优与基元冗余矛盾。其切入点在于将基元位置从离散优化变量转化为连续概率场的采样结果，利用欧拉视角的全局优化能力替代拉格朗日视角的局部操作。方法核心是哈希概率金字塔与控制变量梯度估计器，前者实现高效多尺度概率表示，后者稳定蒙特卡洛优化过程。实验证明，在随机初始化下，EGS在Mip-NeRF 360上达到29.52 PSNR，超越Taming-3DGS和MCMC，接近COLMAP初始化SOTA。边界在于，论文未验证大规模场景下哈希冲突对概率场精度的影响，且随机初始化在动态或遮挡严重场景中的鲁棒性未知。当场景包含大量薄结构或快速运动物体时，哈希概率金字塔的分辨率瓶颈是否会导致概率质量分配失真，论文未给出回答。
