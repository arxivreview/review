# 中科院MORE-STEM：引入长短期记忆与时空一致性，解决动态3D点云分割中的指代歧义与时间漂移

研究机构：中国科学院、中国科学院大学

作者：Chade Li、Haida Feng、Pengju Zhang 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_4babaef58992)

MORE-STEM (MemOry REcall and Spatio-TEmporal Consistency Model)

> 现有3D指令分割方法受限于静态点云，无法处理动态场景中物体运动导致的指代歧义与时间漂移。本文切入点在于将时间维度引入查询驱动分割，通过状态空间模型与长短期记忆机制实现跨帧一致性。具体做法是构建统一框架，联合优化文本-视觉对齐、时空一致性约束及层级记忆召回。该框架在自建InstructKITTI基准上取得38.62 Acc，但在静态基准ScanRefer上未达领域SOTA，其动态场景下的泛化边界尚待验证。

## 研究背景

当自动驾驶场景中存在多辆相似车辆时，静态3D分割模型仅能根据单帧几何特征进行指代，导致“那辆银色轿车”这类查询指向多个目标。这种歧义源于静态表示缺乏时间上下文，无法利用物体运动轨迹区分实例。为解决此问题，4D场景推理引入了时间维度，要求模型在点云序列中维持实例身份稳定。然而，现有方法多采用简单的帧聚合或递归融合，难以在遮挡或大位移下保持体素级时空一致性，且缺乏跨场景的语义记忆机制。

查询驱动3D分割的主流路线依赖视觉-语言对齐，如ScanRefer和3D-GRES，但这些方法均针对单帧静态场景。当物体移动时，单帧特征无法捕捉运动线索，导致分割结果在时间轴上抖动。Mamba4D等近期工作虽引入状态空间模型处理长序列，但侧重于全局特征融合，未解决细粒度体素级的时间漂移问题。本文针对这一瓶颈，提出在体素层面结合状态空间模型与记忆机制，实现运动感知的时空一致性建模。

## 核心方法

### 方法参照系

本文问题属于查询驱动3D分割的4D扩展。标准流程为：点云编码→文本编码→跨模态对齐→分割头预测。关键差异在于输入从单帧点云变为多帧序列，且需处理帧间物体位移与视角变化，传统静态对齐模块在此场景下失效。

### 跨帧文本-视觉对齐 (CFTVA)

CFTVA模块解决静态对齐在动态序列中的漂移问题。通常做法是单帧内文本与视觉特征直接匹配，但多帧下需考虑时间演化。本文采用双向交叉注意力融合点云、体素与图像特征，并通过时间对比损失强化判别性。

$$ \mathcal{L}_{align} = -\log \frac{\exp(\text{sim}(F_t^{vis^{align}}, F^{txt'}) / \tau)}{\sum_{t'} \exp(\text{sim}(F_{t'}^{vis^{align}}, F^{txt'}) / \tau)} $$

该公式通过温度缩放的正则化交叉熵，迫使当前帧视觉特征与文本查询的相似度高于其他帧，从而在时间轴上建立精确的语义锚点。

### 时空一致性模型 (STEM)

STEM模块解决帧间体素特征不连续问题。传统递归融合易受噪声累积影响，本文采用状态空间模型（SSM）更新体素隐状态，结合稀疏3D Transformer进行帧内空间细化。

$$ h_t(v) = A \, h_{t-1}(v) + B \, [F_t^{point^{align}}(v) \| F_t^{voxel^{align}}(v)] $$

此公式以线性状态转移方式传播时间信息，避免全注意力的高计算开销，同时通过可学习参数A、B自适应调整历史特征权重，确保在物体大位移时仍能保持几何稳定性。

### 长短期记忆召回

记忆模块解决跨场景语义连续性问题。长期记忆（LTM）存储加权文本-视觉对，短期记忆（STM）缓存近期掩码特征。LTM通过置信度加权防止类别偏差，STM通过交叉注意力检索帧级运动连续性。该设计使模型在遇到新场景时，能召回历史相似实例的语义先验，弥补单帧观测的信息缺失。

## 实验评估

实验在InstructKITTI（自建）、Instruct3D、ScanRefer及SemanticKITTI上进行。基线覆盖Chat-Scene、3D-LLaVA等静态多模态方法，但缺乏3DGS类动态基线。在InstructKITTI 3D指令分割任务中，本文方法取得38.62 Acc与37.95 mIoU，显著优于Chat-Scene的21.50 Acc。

| 方法 | mIoU | Acc |
| :--- | :--- | :--- |
| Chat-Scene | 21.60 | 21.50 |
| 3D-LLaVA | 20.45 | 19.94 |
| Ours | 38.62 | 37.95 |

消融实验显示，移除CFTVA导致mIoU下降2.6点，移除STEM下降0.8点，表明跨模态对齐对性能贡献最大。移除长期记忆（LTM）导致mIoU下降1.1点，验证了跨场景召回的有效性。值得注意的是，在ScanRefer静态基准上，本文方法取得52.7 mIoU，低于领域SOTA的60.9 Acc（据领域综述），暗示4D模块在静态场景下可能引入冗余计算或特征干扰。

评估边界方面，InstructKITTI为自建基准，缺乏外部验证；ScanRefer结果未达SOTA，表明方法在静态场景的泛化能力受限。代码未公开，超参数设置（如学习率0.005）仅针对特定GPU配置，可复现性存在不确定性。

## 关联研究分析

从问题动机看，本文与Mamba4D同属4D点云理解，但Mamba4D侧重全局时空特征解耦，而本文聚焦体素级一致性。差异根源在于任务目标：Mamba4D面向语义分割，需全局上下文；本文面向指令分割，需细粒度实例定位。本文引入记忆机制是应对指令查询中“跨场景指代”需求的特定设计，而非通用4D建模的必要组件。

从方法设计看，本文与MemorySeg均使用记忆模块，但MemorySeg的更新过程纯空间且缺乏语义引导，本文则通过文本-视觉对加权存储实现语义感知召回。这一差异源于指令分割对语言语义的强依赖，而MemorySeg面向无查询的在线分割。本文放弃3DGS而选择体素表示，可能因4D动态场景下3DGS优化困难，但论文未明确讨论此权衡，体素表示在高分辨率下的计算开销是否可控，尚存疑问。

## 总结

MORE-STEM旨在解决动态场景中静态3D分割的指代歧义与时间漂移矛盾。其切入点在于利用状态空间模型实现体素级时间传播，并通过长短期记忆机制增强跨场景语义连续性。实验证明该方法在自建InstructKITTI基准上取得38.62 Acc，显著优于静态基线。然而，在ScanRefer静态基准上性能未达领域SOTA，暴露了4D模块在静态场景下的潜在冗余。当支持集增大或场景复杂度提升时，记忆机制的检索精度是否随数据规模线性增长，论文未给出回答。
