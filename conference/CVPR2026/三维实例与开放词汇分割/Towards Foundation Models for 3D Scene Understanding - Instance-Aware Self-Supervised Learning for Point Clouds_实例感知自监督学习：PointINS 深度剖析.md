## 导读

3D场景理解的核心瓶颈在于高质量实例标注的稀缺与昂贵，导致监督模型泛化受限。现有自监督方法虽能捕捉全局语义，却因过度强调视图一致性而丢失细粒度几何关系，致使实例分割性能滞后。PointINS 通过引入正交的几何推理分支，利用偏移量预测显式建模点与实例中心的拓扑关系，弥补了语义表征的几何盲区。该框架在实例级任务上显著优于现有自监督基线，但其对统计先验的依赖及与2D视觉-语言模型（VLM）路线的兼容性仍是关键存疑点。

## 研究背景

点云自监督学习（SSL）旨在从无标签数据中提取通用表征，以替代昂贵的密集标注。传统对比学习或掩码建模方法通过强制增强视图间的特征一致性来捕捉全局语义结构，这种机制有效提升了语义分割性能。然而，这种语义驱动的优化目标天然抑制了类内几何差异，导致特征空间在语义紧凑的同时变得几何纠缠，无法区分同一类别下的不同实例。

当前3D SSL领域的主流路线（如DOS、Sonata）均聚焦于语义不变性，忽视了实例感知这一3D感知的核心组件。实例感知要求表征保留细粒度的几何关系，即点应指向其所属实例的中心。PointINS 的切入点在于将实例分割中的“语义引导几何”双分支思想迁移至无监督场景，通过显式学习几何偏移量，解决现有SSL方法在实例定位任务上的性能瓶颈。

## 核心方法

### 方法参照系

PointINS 基于 Teacher-Student 自蒸馏范式，继承 DOS 和 Sonata 的架构。标准流程中，Teacher 处理完整点云，Student 处理掩码子集，两者通过原型聚类损失对齐语义分布。本文的关键差异在于，在语义分支之外，正交增加了一个几何推理分支，专门负责学习点云至实例中心的偏移向量，从而将实例感知显式纳入预训练目标。

### 几何推理分支与偏移预测

在语义分支学习视图一致性特征的同时，PointINS 引入 Offset Branch 预测每个点指向其实例几何中心的3D向量。设计动机在于，纯语义特征缺乏空间指向性，无法支持后续的实例聚类。该分支对旋转、翻转等空间变换敏感，因此需追踪增强变换并逆变换预测偏移，以保持几何一致性。偏移预测采用 $\ell_1$ 损失与余弦相似度损失的组合，分别约束偏移幅值与方向：

$$
L_{off} = \sum_{i} (||o_i - O_i^*||_1 + (1 - \cos(o_i, O_i^*)))
$$

其中 $o_i$ 为 Student 预测偏移，$O_i^*$ 为 Teacher 侧经正则化后的目标偏移。此设计使模型在无标签条件下，通过几何指向性建立点与实例中心的拓扑联系。

### 双重正则化机制

直接回归偏移量易导致模型坍缩至平凡解（如所有点指向原点）。为此，PointINS 引入 Offset Distribution Regularization (ODR) 和 Spatial Clustering Regularization (SCR) 进行约束。ODR 利用概率积分变换（PIT）将预测偏移幅值对齐至真实场景中长尾分布先验，方向对齐至均匀分布，提供全局统计约束。SCR 则利用 Teacher 特征进行 K-means 聚类生成伪实例掩码，通过 BFS 细化局部连通分量，强制空间邻近点共享一致质心，提供局部几何连贯性约束。

$$
\tilde{M}_i = F^{-1}(u_i), \quad u_i = \frac{\pi(i)}{N}
$$

其中 $F^{-1}$ 为经验分布的逆累积分布函数，$\pi(i)$ 为幅值排序。ODR 确保偏移符合物理尺度，SCR 确保局部一致性，两者互补防止几何学习失效。

## 实验评估

PointINS 在 ScanNet、S3DIS、nuScenes 等五个基准上评估，对比 DOS、Sonata 等主流 SSL 方法。基线覆盖了对比学习与掩码建模两条路线，但未包含基于 2D VLM 的开放词汇方法，因任务定义不同。在 ScanNet 实例分割线性探测（Linear Probing）下，PointINS 取得 32.1 mAP，显著优于 DOS 的 28.7 mAP 和 Sonata 的 25.0 mAP。在 nuScenes 全景分割线性探测下，PointINS 取得 64.7 PQ，较 DOS 的 60.9 PQ 提升 3.8 个点。

| 方法 | ScanNet mAP (lin.) | nuScenes PQ (lin.) |
| :--- | :--- | :--- |
| DOS | 28.7 | 60.9 |
| Sonata | 25.0 | 54.9 |
| PointINS | 32.1 | 64.7 |

消融实验显示，单独使用 ODR 或 SCR 均有增益，但联合使用带来最大提升（+3.4% mAP）。ODR 对分布先验具有强鲁棒性，即使使用不同场景（室内/室外）或仅 1% 标注估计的分布，性能下降极小。将 PointINS 集成至 Sonata 框架，实例分割 mAP 提升 10.4 点，验证了其模块化兼容性。

评估边界方面，论文未报告计算效率指标，且线性探测下的高性能可能掩盖全微调（Finetuning）下与监督方法的差距。代码未公开，超参数细节（如 ODR 分布拟合过程）需参照附录，可复现性依赖对 PIT 变换实现的精确理解。

## 关联研究分析

从问题动机看，PointINS 与 OpenScene 等基于 2D VLM 的开放词汇方法形成路线对立。OpenScene 依赖 CLIP 等外部语义先验解决“是什么”的问题，而 PointINS 完全基于 3D 原生数据学习“在哪里”的几何关系。这种差异源于任务特性：PointINS 旨在构建通用 3D 基础模型，需摆脱对 2D 模态的依赖，但其代价是缺乏 VLM 提供的丰富语义知识，在开放词汇识别上可能受限。

从方法设计看，PointINS 与监督式 PointGroup 共享“语义引导几何”的双分支思想，但 PointINS 将监督信号替换为自监督正则化。PointGroup 依赖密集标注直接回归偏移，而 PointINS 通过 ODR/SCR 间接约束偏移分布。这一改造解决了无标签下的几何坍缩问题，但引入了对统计先验的依赖。PointINS 的几何推理能力是否能在缺乏 VLM 语义先验的情况下，支撑开放词汇场景下的细粒度实例区分，论文未给出直接验证。

## 总结

PointINS 旨在解决 3D 自监督学习中语义表征与几何感知的割裂矛盾。现有 SSL 方法因过度优化视图一致性而丢失实例级几何细节，PointINS 通过引入正交偏移分支及 ODR/SCR 双重正则化，在无标签条件下显式学习几何推理。实验证明其在实例分割上较 DOS 提升 3.4 mAP，验证了几何推理对实例感知的必要性。然而，该方法依赖场景统计先验，且在缺乏 2D VLM 语义增强的情况下，其表征在开放词汇任务上的泛化能力尚未被充分探索。当预训练数据规模扩大至百万级点云时，ODR 的统计先验是否仍能保持对长尾类别的鲁棒性，仍是待验证的关键问题。
