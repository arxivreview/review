# CVPR2026最新论文 ｜A Style is Worth One Code: Unlocking Code-to-Style Image Generation with Discrete Style Space ｜代码到风格生成

研究机构：北京航空航天大学、快手

作者：Huijie Liu、Shuhao Cui、Haoxiang Cao 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.10555)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.10555)

> 风格化生成面临的核心矛盾是：依赖参考图像或LoRA的方法无法创造未见过的风格，而纯文本提示又缺乏一致性。现有方案在“新颖性”与“可复现性”上存在结构性缺陷。CoTyle通过引入离散风格码本与自回归生成器，将风格表示从像素级或参数级压缩为紧凑的数值代码，实现了无需参考图像的新风格生成。该方法在一致性上优于闭源竞品Midjourney，但其多样性受限于码本容量，且缺乏与主流LoRA微调方法的直接对比，其作为通用风格控制器的普适性仍存疑。

## 研究背景

理解CoTyle需先厘清风格表示的粒度问题。传统风格迁移将风格定义为参考图像中的视觉属性，通过编码器提取连续特征向量注入扩散模型。这种连续表示虽能捕捉细节，但难以直接进行组合或生成全新风格，且特征空间中内容语义与风格属性往往纠缠。向量量化（Vector Quantization, VQ）技术将连续特征映射为离散索引，天然适配自回归模型的Next-Token Prediction目标，但传统VQ旨在重建图像，而非分离风格。

风格化生成领域的主流路线分为三类：基于文本提示、基于参考图像、基于LoRA微调。文本提示方法（如Stable Diffusion原生能力）灵活性高但一致性差，同一描述生成结果差异巨大；参考图像方法（如InstantStyle、IP-Adapter）一致性高但受限于已有风格，无法创造新风格，且分享需传输像素级图像；LoRA方法（如DreamBooth）通过微调权重实现风格固化，但每个风格需独立训练，存储与部署成本高，且同样依赖训练数据中的既有风格。这三类方法均无法同时满足“新颖风格创造”与“极简风格复现”的需求。工业界Midjourney虽实现了代码到风格的功能，但闭源且无技术报告，学术界缺乏开源方案。CoTyle的切入点在于：将风格表示离散化，利用自回归模型学习风格分布，使数值代码成为风格生成的唯一条件，从而解耦风格创造与参考图像依赖。

## 核心方法

### 方法参照系

CoTyle置于“条件图像生成”框架下，但关键差异在于条件信号的性质。标准流程是“参考图→编码器→连续特征→注入DiT”，而CoTyle将其前置为“代码→自回归生成器→离散索引→查表→风格嵌入→注入DiT”。这一改动将风格从“被动提取”转变为“主动生成”，核心挑战在于如何构建一个既能区分不同风格、又能抑制内容信息的离散风格空间。

### 离散风格码本训练

设计动机：传统VQ码本用于图像重建，会保留内容细节；而风格迁移需要的是“同风格不同内容”图像的共性。因此，CoTyle采用对比损失训练码本，强制相同风格图像映射到相近分布，不同风格图像映射到远离分布。

$$
\mathcal{L}_{style} = \frac{1}{B} \sum_{i=1}^{B} \left[ y_i \log \left( \frac{\exp(-d(v_{1,i}, v_{2,i})/\tau)}{\exp(-d(v_{1,i}, v_{2,i})/\tau) + \exp(-d(v_{1,i}, v_{neg,i})/\tau)} \right) + (1-y_i) \log \left( 1 - \sigma(d(v_{1,i}, v_{2,i}) - m) \right) \right]
$$

该公式中，$y_i$ 为标签（1表示同风格，0表示不同风格），$d(\cdot)$ 为距离度量，$m$ 为间隔参数。通过对比学习，码本学习到的嵌入 $F(v)$ 仅包含风格信息，内容信息被抑制。此外，引入重建损失 $\mathcal{L}_{recon}$ 防止码本坍缩，确保风格嵌入与预训练VLM图像编码器输出保持分布一致性，从而利用VLM的语义理解能力。

### 自回归风格生成器

设计动机：码本仅能提取已有图像的风格，无法创造新风格。自回归生成器通过Next-Token Prediction学习风格索引序列的分布，实现无条件风格生成。

$$
P(I_1, ..., I_N | I_0) = \prod_{i=1}^{N} P(I_i | I_0, ..., I_{i-1})
$$

推理时，用户输入数值代码 $n$ 作为随机种子，采样初始索引 $I_0$，自回归生成后续 $N-1$ 个索引。这些索引查表得到风格嵌入，注入DiT的文本分支。关键创新在于高频索引抑制策略：分析发现高频索引对应“无风格”占位符，因此对高频索引的logits乘以抑制系数 $s(i)$，避免生成平淡图像。

$$
s(i) = \begin{cases} 1 & \text{if } f(i) < \tau \\ k & \text{if } f(i) \ge \tau \end{cases}
$$

其中 $f(i)$ 为索引 $i$ 的频率，$\tau$ 为阈值，$k$ 为抑制系数。该策略通过降低高频索引的采样概率，增强风格多样性与强度。

## 实验评估

实验设置：代码到风格任务随机采样500个代码，每个代码生成4张图像（共2000张）；图像条件任务构建500对提示-参考图像。基线包括闭源Midjourney及开源图像条件方法（StyleStudio, CSGO, USO, Flux-Kontext, InstantStyleXL）。缺失LoRA类（如Balanced Subspace Blending）及无训练类（如HAM）基线，无法直接对比参数化微调与代码生成的保真度差异。

| 方法 | 开源 | 条件 | Diversity↑ | Aesthetics↑ | CLIP-T↑ | Consistency↑ |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Midjourney | ✗ | Code | 0.8088 | 0.5948 | 0.3090 | 0.4734 |
| CoTyle | ✓ | Code | 0.7764 | 0.7173 | 0.3119 | 0.6007 |
| CoTyle* | ✓ | Image | - | 0.7178 | 0.3230 | 0.5791 |
| InstantStyleXL | ✓ | Image | - | 0.3230 | 0.5753 | 0.5791 |

CoTyle在代码到风格任务上Consistency（0.6007）显著优于Midjourney（0.4734），但Diversity（0.7764）略低（0.8088），作者归因于训练数据广度不足。在图像条件任务上，CoTyle*的Consistency（0.5791）与InstantStyleXL持平，但Aesthetics（0.7178）远高于后者（0.3230），表明离散码本在美学质量上具有优势。

消融实验显示，移除对比损失导致Consistency从0.5791降至0.4890，验证了风格分离的必要性；移除重建损失导致Consistency降至0.4102，证实了防止码本坍缩的重要性。高频索引抑制策略使Diversity从0.7488提升至0.7764，CLIP-T从0.3210降至0.3119，表明该策略以轻微文本对齐损失换取风格多样性。

评估边界：使用CSD评估一致性/多样性，CLIP-T评估文本对齐，Aesthetics评估美学。CSD为自建指标，缺乏跨论文可比性；未报告计算效率（推理时间/显存）；代码开源但训练数据未公开，可复现性受限。

## 关联研究分析

从问题动机看，CoTyle与InstantStyleXL均解决风格一致性，但InstantStyleXL依赖参考图像，本质是“风格复制”，而CoTyle通过自回归生成实现“风格创造”。这一差异源于任务定义：InstantStyleXL假设风格已存在，CoTyle假设风格可由代码生成。根源在于CoTyle将风格表示离散化，使风格空间可枚举、可生成，而连续表示难以直接生成新组合。

从方法设计看，CoTyle与MegaStyle-Encoder均关注风格编码器的区分度，但MegaStyle侧重检索（StyleRetrieval），CoTyle侧重生成。MegaStyle通过VLM构建大规模数据集提升编码器区分度，CoTyle通过对比学习训练码本实现风格分离。差异在于：MegaStyle依赖数据规模，CoTyle依赖损失函数设计。CoTyle未利用大规模配对数据，而是依赖预训练VLM特征，这可能限制其风格覆盖范围，导致Diversity低于Midjourney。

## 总结

CoTyle解决的核心矛盾是风格生成的“新颖性”与“可复现性”冲突。现有方法依赖参考图像或LoRA，无法创造新风格；CoTyle通过离散码本与自回归生成器，将风格表示压缩为数值代码，实现无需参考图像的新风格生成。实验证明，CoTyle在一致性上优于Midjourney（0.6007 vs 0.4734），美学质量显著优于InstantStyleXL（0.7178 vs 0.3230）。但CoTyle的多样性（0.7764）低于Midjourney（0.8088），且缺乏与LoRA微调方法的直接对比，其风格保真度是否劣于参数化微调未经验证。当码本容量从1024扩展至更大规模时，多样性是否线性提升，而一致性是否因码本稀疏化而下降，论文未给出回答。
