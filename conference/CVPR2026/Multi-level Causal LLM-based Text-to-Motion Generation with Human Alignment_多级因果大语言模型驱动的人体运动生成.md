# CVPR2026最新论文 ｜Multi-level Causal LLM-based Text-to-Motion Generation with Human Alignment ｜多级因果大语言模型驱动的人体运动生成

研究机构：中国科学技术大学、德国卡尔斯鲁厄理工学院

作者：Xiaodong Chen、Qian Bao、Xudong Liu 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_5acd7283a8f2)

> 文本驱动人体运动生成（Text-to-Motion, T2M）旨在从自然语言合成物理合理且语义一致的动作序列，其核心挑战在于离散化运动表征与因果语言模型推理机制的结构性失配。现有基于大语言模型（LLM）的方法依赖非因果向量量化变分自编码器（VQ-VAE），导致量化误差累积且无法对齐 LLM 的因果推理特性，同时缺乏对主观偏好的显式优化。MoTiGA 通过引入因果残差向量量化变分自编码器（Causal RVQ-VAE）与时间滞后因果预测策略，并设计多级混合加权偏好优化（MHPO），在保持因果性的同时实现细粒度运动生成与人类偏好对齐。该框架显著提升了 LLM 基线性能，但其依赖大规模人工偏好标注，且未验证在长序列生成中时间滞后策略对局部时序连贯性的潜在影响。

## 研究背景

当 LLM 试图将运动序列视为“外语”进行生成时，其因果注意力机制要求每个时间步的预测仅依赖当前及过去信息。然而，传统 VQ-VAE 采用全局非因果编码，每个运动 Token 受未来帧影响，这种结构性失配导致 LLM 在解码时无法有效利用上下文，引发量化误差与动作细节丢失。为缓解单一码本容量限制，残差向量量化（RVQ）通过多级迭代量化捕捉从全局到局部的运动特征，但标准 RVQ 仍保留非因果编码特性，与 LLM 的因果推理逻辑存在根本冲突。

T2M 领域已形成扩散模型与离散自回归两大主流路线。扩散模型在连续保真度上占优，但推理速度慢；离散自回归范式凭借 VQ-VAE 将运动转化为 Token 序列，结合 Transformer 架构实现了更强的语义组合性，但面临累积误差与重建损失问题。现有 LLM-based 方法如 MotionGPT 虽统一了运动与语言模态，却受限于 VQ-VAE 的粗粒度量化与非因果性，生成动作常出现镜像错误或关键姿态缺失，且未纳入人类主观偏好优化。MoTiGA 的切入点在于重构运动量化器以匹配 LLM 因果特性，并引入偏好对齐机制，解决量化误差与主观偏差双重问题。

## 核心方法

### 方法参照系

MoTiGA 属于离散自回归 T2M 路线，其标准流程为：运动序列经 VQ-VAE 量化为 Token，LLM 自回归预测 Token 序列，解码器重建动作。本文关键差异在于将非因果 VQ-VAE 替换为因果 RVQ-VAE，并设计时间滞后预测策略以平衡多级 Token 的并行解码与因果依赖。

### 因果残差向量量化变分自编码器

标准 RVQ-VAE 的编码器采用双向卷积，导致 Token 依赖未来帧，与 LLM 因果推理冲突。MoTiGA 引入 Causal RVQ-VAE，在编码器与解码器中均采用 1D 因果卷积，确保每个时间步的编码仅依赖当前及过去帧。量化过程通过 $V$ 级共享码本 $B_{1:V}$ 迭代执行，第 $v$ 级量化向量 $b_v$ 由残差 $z_v$ 映射至最近码本项，最终潜变量 $\hat{z} = \sum_{v=1}^V b_v$ 送入解码器。该设计消除了非因果信息泄露，使运动表征与 LLM 因果推理逻辑对齐，从源头减少量化误差。

### 时间滞后因果预测

多级 RVQ 产生 $V$ 倍于单级 VQ-VAE 的 Token 数量，逐步预测导致推理步骤激增与雪崩误差。MoTiGA 采用时间滞后策略，将不同层级 Token 的预测在时间轴上错开：基础层 Token $b_1$ 按标准自回归预测，残差层 Token $b_v$ ($v>1$) 利用前一时间步的基础层 Token $b_1^{t-1}$ 作为条件进行并行预测。该策略在保持因果依赖（$P(b_{v+1}^{t+1} | b_{1:v+1}^{1:t}, X, \pi) \neq P(b_{v+1}^{t+1} | b_{1:v}^{t+1}, b_{1:v+1}^{1:t}, X, \pi)$）的同时，实现跨层级并行解码，显著降低推理步骤并抑制误差累积。

### 多级混合加权偏好优化

现有 LLM 运动生成缺乏主观偏好对齐，导致生成动作与人类审美偏差。MoTiGA 提出 MHPO，在 GRPO 框架中引入多级动态奖励。对于偏好序列 $O^+$，第 $v$ 级奖励 $\hat{r}^+_{i,t}$ 由整体二元奖励 $r_i$ 与自适应奖励 $\vartheta_v$ 加权构成：$\hat{r}^+_{i,t} = (1-\epsilon)r_i + \epsilon\vartheta_v$（$v=1$）或 $(1-\epsilon)r_i + \epsilon(\vartheta_v - \vartheta_{v-1})$（$v \geq 2$）。其中 $\vartheta_v$ 为运动检索模型 TMR 计算的生成动作与文本的语义相似度。该机制将奖励集中于高语义相似度的关键层级，引导模型优化细节 Token，实现细粒度偏好对齐。

## 实验评估

实验在 HumanML3D 与 KIT-ML 数据集上进行，基线覆盖任务专用模型（MoMask, MLD）与 LLM-based 模型（MotionGPT, MotionLLM），但缺失 Flow Matching 类强基线（如 HY-Motion）。MoTiGA 在 HumanML3D 上取得 FID 0.041、R-Precision Top-1 52.3%，显著优于 MotionGPT (FLAN-T5) 的 FID 0.232 与 MotionLLM (Gemma) 的 FID 0.491，性能追平或超越 MoMask (FID 0.045)。

| 方法 | FID ↓ | R-Precision Top-1 ↑ (%) | MM-Dist ↓ | Time (s) ↓ |
| :--- | :--- | :--- | :--- | :--- |
| MotionGPT (FLAN-T5) | 0.232±.008 | 49.2±0.2 | 3.096±.008 | 14.266±.427 |
| MotionLLM (Gemma) | 0.491±.019 | 48.2±0.4 | 3.138±.010 | 14.494±.418 |
| MoMask | 0.045±.002 | 52.1±0.2 | 2.958±.008 | 2.779±.022 |
| MoTiGA (Llama) | 0.041±.002 | 52.3±0.2 | 2.991±.009 | 3.762±.070 |

消融实验显示，Causal RVQ-VAE 在 $V=4$ 时生成 FID 达 0.055，优于标准 RVQ-VAE 的 0.085，验证因果编码对 LLM 的兼容性。时间滞后策略相比时间同步预测，FID 从 0.064 降至 0.055，证明其抑制误差累积的有效性。MHPO 中权重因子 $\epsilon=0.6$ 时 FID 最优（0.041），表明适度多级奖励引导优于均匀分配。

评估边界方面，论文未报告置信区间（部分指标除外），且 HumanML3D 序列较短，难以充分暴露长序列累积误差。代码未开源，但超参数（LoRA rank 64, batch size 128）与训练时长（72 小时指令微调，36 小时偏好对齐）已披露，具备部分可复现性。

## 关联研究分析

从问题动机看，MoTiGA 与 MoMask 同属离散自回归路线，但 MoMask 采用掩码并行生成解决顺序依赖，而 MoTiGA 聚焦因果性失配问题。MoMask 的掩码策略允许并行解码但可能破坏时序因果结构，MoTiGA 的时间滞后策略在保持因果性的同时实现并行，二者在长序列生成中的误差累积特性存在本质差异。MoTiGA 的 FID 优势可能源于 Causal RVQ-VAE 的重建质量而非生成能力，论文未单独消融量化器重建误差对生成 FID 的贡献。

从方法设计看，MoTiGA 与 MotionGPT 同采用 LLM 架构，但 MotionGPT 依赖非因果 VQ-VAE，导致量化误差大且缺乏偏好对齐。MoTiGA 通过 Causal RVQ-VAE 解决量化误差，通过 MHPO 解决偏好缺失，但 MHPO 依赖 101,490 对人工标注偏好数据，数据获取成本高。相比之下，MotionGPT 无需偏好数据，但在细粒度语义对齐上表现较弱。MoTiGA 的偏好对齐机制是否引入新的偏差（如偏好数据分布偏差），论文未给出回答。

## 总结

MoTiGA 要解决的核心矛盾是 LLM 因果推理与非因果运动量化之间的结构性失配，以及生成动作与人类主观偏好的偏差。现有 LLM-based 方法因依赖非因果 VQ-VAE 导致量化误差累积，且缺乏偏好优化，无法生成细粒度且符合人类审美的动作。MoTiGA 通过 Causal RVQ-VAE 匹配 LLM 因果特性，时间滞后策略实现并行解码，MHPO 引入多级偏好对齐，在 HumanML3D 上取得 FID 0.041 与 R-Precision 52.3%，显著优于 LLM 基线。其边界在于依赖大规模人工偏好标注，且未验证长序列生成中时间滞后策略对局部时序连贯性的影响。当序列长度超过 HumanML3D 标准范围时，时间滞后策略是否仍能有效抑制误差累积，论文未给出回答。
