# CVPR2026最新论文 ｜Subspace Alignment for CLIP-based Continual Learning via Canonical Correlation Analysis ｜基于典型相关分析的CLIP持续学习子空间对齐

研究机构：武汉大学

作者：Huan Zhang、Shuyu Dong、Yujin Zheng 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_0d7e3bf35d90)

> 持续学习中的CLIP模型面临视觉与文本编码器更新速率不匹配导致的模态距离累积问题，现有方法多通过参数微调或额外模块缓解，但易破坏预训练表示或引入额外计算开销。本文指出这一非对称漂移（Asymmetric Drift, AD）是性能退化的核心几何原因，并提出通过累积跨任务协方差统计量求解闭式典型相关分析（Canonical Correlation Analysis, CCA）投影矩阵，将双模态特征映射至共享子空间以最小化距离。该方法无需梯度更新即可实现高效对齐，在CIFAR-100上取得83.0%的Last Accuracy，但其线性假设对复杂非线性关系的捕捉能力仍存疑。

## 研究背景

当CLIP模型在类增量学习（Class-Incremental Learning, CIL）中处理新任务时，视觉输入分布随任务剧烈变化，而文本提示（如“a photo of [CLS]”）的离散token嵌入方差极低。这种数据变异性差异导致视觉编码器参数更新幅度远大于文本编码器，形成非对称漂移（AD）。AD使视觉特征在嵌入空间中漂移速度显著快于文本特征，导致跨模态余弦相似度下降，最终引发零样本分类性能随任务序列推进而持续退化。

主流CLIP持续学习方法分为两类：一类冻结骨干并训练额外模块（如PROOF、ENGINE），另一类通过参数高效微调（PEFT）如LoRA或任务向量（如MagMax、SLCA）适配新任务。这些方法虽缓解了灾难性遗忘，但忽视了双模态更新速率失衡这一根本机制。直接微调CLIP参数以缩小模态距离会破坏预训练表示的完整性，而现有PEFT方法未显式建模视觉-文本特征间的统计相关性。本文切入点在于将AD形式化为特征空间距离增长问题，并采用无参数更新的统计对齐策略，从几何层面补偿模态失配。

## 核心方法

### 方法参照系

CLIP持续学习的标准流程通常涉及冻结预训练骨干、训练任务特定适配器或LoRA矩阵，并在推理时计算视觉特征与文本原型的余弦相似度。本文问题与该通用流程的关键差异在于：不训练任何可学习参数，而是通过闭式解计算投影矩阵，将特征映射至共享子空间后再进行相似度计算，从而规避参数更新带来的遗忘风险。

### 闭式CCA子空间投影

设计动机：直接优化CLIP参数以最小化模态距离会破坏预训练知识，而现有PEFT方法未显式建模双模态统计相关性。本文在特征提取后、相似度计算前插入CCA投影环节，通过最大化视觉-文本投影变量的相关性来定义共享子空间。给定跨任务累积的协方差矩阵 $\Sigma_{XX}$、$\Sigma_{YY}$ 和 $\Sigma_{XY}$，CCA求解投影矩阵 $A$ 和 $B$：

$$
\max_{A,B} \text{corr}(A^\top X, B^\top Y) = \frac{A^\top \Sigma_{XY} B}{\sqrt{B^\top \Sigma_{YY} B} \sqrt{A^\top \Sigma_{XX} A}}
$$

该公式的物理含义是寻找两组线性组合，使得它们在投影后的空间中相关性最大。通过白化交叉协方差矩阵 $K = \Sigma_{XX}^{-1}\Sigma_{XY}\Sigma_{YY}^{-1}$ 的特征分解，得到正交基 $V$ 和 $U$，进而构造投影矩阵 $A = \Sigma_{XX}^{-1}V$ 和 $B = \Sigma_{YY}^{-1}U$。在共享子空间中，视觉特征 $z_x^{cca} = A^\top z_x$ 与文本特征 $z_y^{cca} = B^\top z_y$ 的距离被最小化，从而补偿AD导致的模态失配，且无需修改CLIP参数。

### 随机傅里叶投影非线性扩展

设计动机：线性CCA仅捕捉双模态间的线性依赖，而CLIP特征空间中的视觉-文本关系包含复杂非线性结构。本文在协方差累积阶段引入随机傅里叶投影（Random Fourier Projection, RFP），将原始特征映射至高维空间以近似RBF核。具体地，对视觉和文本特征应用随机映射 $\phi(\cdot)$：

$$
\phi(z) = \sqrt{\frac{2}{D'}} \cos(Wz + b)
$$

其中 $W \in \mathbb{R}^{D' \times D}$ 为高斯随机矩阵，$b \in \mathbb{R}^{D'}$ 为均匀随机向量。该公式的物理含义是通过随机超平面投影将原始特征嵌入高维空间，使得非线性相关性在高维空间中变为线性可分。累积RFP映射后的协方差矩阵 $\Sigma_{x'x'}$、$\Sigma_{y'y'}$ 和 $\Sigma_{x'y'}$，再执行相同的闭式CCA求解流程。RFP不引入可训练参数或优化步骤，仅增加特征维度，从而在保持计算效率的同时增强非线性对齐能力。

## 实验评估

实验在CIFAR-100、ImageNet-R、ImageNet-100和CUB-200四个基准上进行，采用ViT-B/16骨干，协议为类增量学习，指标为平均准确率（Avg）和最后任务准确率（Last）。基线覆盖L2P、DualPrompt、SLCA、ENGINE、MagMax等代表性方法，但缺失基于回放（Replay）的强基线如DER++，且未对比最新SOTA方法如RLAP-CLIP。

| 方法 | CIFAR-100 Avg | CIFAR-100 Last | ImageNet-R Avg | ImageNet-R Last | CUB-200 Avg | CUB-200 Last |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| L2P | 81.9 | 73.0 | 81.6 | 75.9 | 80.5 | 67.2 |
| ENGINE | 86.9 | 79.2 | 86.2 | 80.3 | - | - |
| CCA-CL | 87.2 | 83.0 | 86.8 | 81.3 | 86.3 | 79.7 |

CCA-CL在CIFAR-100 Last Accuracy上以83.0%超越ENGINE的79.2%，在ImageNet-R Last Accuracy上以81.3%超越L2P的75.9%，表明子空间对齐策略在缓解AD方面有效。

| 组件 | CIFAR-100 Accuracy |
| :--- | :--- |
| 无CCA | 66.7 |
| CCA | 76.5 |
| CCA + RFP | 81.0 |
| CCA + RFP + FTT | 83.0 |

消融实验显示，CCA组件贡献9.8个百分点的提升，RFP进一步贡献4.5个百分点，首个任务微调（FTT）贡献2.0个百分点。RFP的边际收益显著，表明非线性对齐对复杂任务序列至关重要。FTT的轻微提升暗示首个任务适配对后续协方差统计的稳定性有辅助作用，但非决定性因素。

评估边界方面，论文未报告置信区间，数值比较需谨慎。代码已开源，超参数（学习率1e-6、batch size 64、5 epochs）明确，单GPU（RTX 4090）可复现。但RFP维度 $D'$ 设为1024×6，内存开销未详细讨论，且未评估不同 $\eta$ 值对投影维度选择的影响。

## 关联研究分析

从问题动机看，MG-CLIP同样关注模态间隙，但通过保持稳定间隙来平衡稳定性与可塑性，而本文通过动态投影最小化距离。MG-CLIP的静态间隙假设可能无法适应任务序列中视觉分布的剧烈变化，而本文的累积协方差机制能隐式捕获历史分布信息。这一差异源于任务特性：MG-CLIP侧重域适应，本文侧重类增量，后者视觉分布变化更显著，导致AD更严重。

从方法设计看，RanPAC利用随机投影增强表示，但仅用于特征扩展而非模态对齐。本文将RFP与CCA结合，用于捕捉非线性相关性，而非单纯增加特征维度。RanPAC的随机投影是固定的，而本文的RFP与CCA投影矩阵协同优化，形成端到端的对齐机制。这一差异源于设计目标：RanPAC旨在增强预训练表示的泛化能力，本文旨在解决双模态失配问题。

## 总结

本文要解决的核心矛盾是CLIP持续学习中视觉与文本编码器更新速率不匹配导致的模态距离累积。现有方法通过参数微调或额外模块缓解遗忘，但忽视了AD这一几何机制，而本文凭借闭式CCA的无参数更新特性，从统计层面补偿模态失配。方法通过累积协方差统计量求解共享子空间投影矩阵，结合RFP扩展非线性对齐能力。实验证明CCA-CL在CIFAR-100上取得83.0%的Last Accuracy，超越ENGINE的79.2%。本文的边界在于线性CCA假设可能无法充分捕捉高维特征空间中的复杂非线性关系，且RFP维度选择缺乏系统性消融。当任务序列中视觉分布变化呈现高度非线性时，闭式CCA的线性投影是否仍能保持对齐精度，论文未给出回答。
