# CVPR2026最新论文 ｜BAMI: Training-Free Bias Mitigation in GUI Grounding ｜偏差感知推理

研究机构：清华大学

作者：Borui Zhang、Bo Zhang、Bo Wang 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.06664)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.06664)

> GUI 定位在高分辨率专业软件界面中面临细粒度感知失效，现有模型在 ScreenSpot-Pro 等基准上准确率普遍低于 50%。主流方案依赖大规模预训练或强化学习提升精度，但忽视了模型内部因坐标离散化与编辑距离优化导致的系统性归纳偏差。本文切入点在于通过无训练的推理时结构化操作，直接修正这些偏差。BAMI 通过粗到细聚焦与候选选择机制，将单步定位转化为多步递归推理。该方法在 TianXi-Action-7B 上将 ScreenSpot-Pro 准确率从 51.9% 提升至 57.8%，但绝对性能仍低于最新训练式 SOTA，且依赖外部模型引入额外延迟。

## 研究背景

GUI 智能体执行点击操作的前提是准确将自然语言指令映射至屏幕像素坐标。多模态大语言模型（MLLMs）通常将坐标离散化为文本 Token 进行自回归生成，这种表示方式导致模型优化目标（编辑距离）与空间定位需求（欧氏距离）存在根本性冲突。当模型预测坐标时，百位数字的错误权重远高于个位，但交叉熵损失函数对每个 Token 的惩罚是均等的，这种不对称性使得模型在高分辨率图像中难以精确锁定小目标。

GUI 定位领域已从依赖 HTML 或无障碍树的结构化元数据转向纯视觉驱动范式，SeeClick 等工作确立了领域特定预训练的有效性。然而，随着评测基准转向 4K 分辨率的专业软件（如 CAD、开发工具），VLM 视觉编码器的分辨率限制暴露无遗，模型在密集布局下的小目标定位失败率显著上升。现有改进路线主要分为两类：一是通过强化学习（如 UI-R1、TianXi-Action）优化空间推理能力，二是通过测试时缩放（如 GUI-Spotlight）迭代裁剪以缓解小目标混淆。这些方法虽提升了精度，但往往需要额外的训练成本或复杂的工具调用流程，且未深入剖析模型内部导致定位失败的认知机制。

本文针对上述瓶颈，提出了一种无训练的推理增强框架。通过引入掩码预测分布（Masked Prediction Distribution, MPD）方法诊断错误根源，发现 74% 的失败源于归纳偏差，而非知识缺失。基于此，BAMI 设计了粗到细聚焦与候选选择两种操作，在不修改模型参数的前提下，通过结构化推理路径修正精度偏差与歧义偏差，旨在以最低成本解锁现有模型的定位潜力。

## 核心方法

### 方法参照系

自适应视觉聚焦路线的标准流程是通过迭代裁剪缩小搜索空间，如 GUI-Spotlight 维护图像注册表并动态执行裁剪工具。本文的关键差异在于，标准流程仅关注空间范围的缩小，而 BAMI 引入了基于掩码的候选生成机制与外部规则选择，将空间搜索与语义歧义消解耦合在同一推理闭环中。

### 粗到细聚焦：精度偏差修正

针对坐标离散化导致的精度偏差，BAMI 将单步定位分解为层级化的粗到细聚焦过程。设计动机在于解决模型在高分辨率图像中因 Token 量化误差导致的系统性偏移，传统单次预测无法区分百位与个位错误的权重差异。具体而言，模型首先预测粗定位坐标 $(x_t, y_t)$，随后以该坐标为中心，按预设比例 $\lambda$ 裁剪原图，并将裁剪后的图像重新输入模型进行精细定位。该过程迭代 $N$ 次，每次迭代都基于上一轮的预测结果缩小搜索范围。

$$
I_{t+1} = \text{CROP}(I_t, \text{Box}(x_t, y_t, \lambda))
$$

其中 $I_t$ 为第 $t$ 轮输入图像，$\text{Box}$ 表示以 $(x_t, y_t)$ 为中心、比例为 $\lambda$ 的裁剪框。这一机制通过逐步提高局部区域的相对分辨率，使模型在最终预测时面对的是更小的坐标空间，从而将像素级误差控制在可接受范围内。

### 候选选择：歧义偏差修正

为消除编辑距离与欧氏距离不一致导致的歧义偏差，BAMI 引入掩码预测与外部候选选择机制。设计动机在于纠正模型在多个相似 UI 元素间错误排序的倾向，传统方法缺乏对空间几何约束的显式利用。在每一轮聚焦中，模型执行 $M$ 次预测，每次预测前将已预测候选框内的像素进行掩码处理，确保新生成的候选框与已有结果互斥。随后，利用外部校正模型 $m$ 根据预设的 GUI 先验规则（如功能特征、典型 UI 模式、交互元素优先级）从候选集 $\Phi_t$ 中选取最优框 $\tilde{b}_t$。

$$
\tilde{b}_t = \arg\min_{b \in \Phi_t} \mathcal{L}_{\text{rule}}(q, I_t, b)
$$

其中 $\mathcal{L}_{\text{rule}}$ 代表基于提示规则的选择损失，$q$ 为查询指令。该机制通过引入外部几何与语义约束，弥补了自回归生成过程中空间距离感知的缺失，使模型能够区分视觉上相似但功能不同的元素。

## 实验评估

实验在 ScreenSpot-Pro 和 ScreenSpot-V2 上进行，基线覆盖 SFT 模型（OS-Atlas-7B, UGround-7B）和 RL 模型（UI-R1-3B, TianXi-Action-7B），但缺失最新 SOTA 如 GUI-AIMA-3B 的对比。BAMI 在 TianXi-Action-7B 骨干上表现最佳，ScreenSpot-Pro 准确率达到 57.8%，较基线提升 5.9 个百分点；在 OS-Atlas-7B 上从 18.9% 提升至 41.6%。

| 骨干模型 | 基线准确率 (%) | BAMI 准确率 (%) | 提升幅度 (pp) |
| :--- | :--- | :--- | :--- |
| TianXi-Action-7B | 51.9 | 57.8 | 5.9 |
| OS-Atlas-7B | 18.9 | 41.6 | 22.7 |
| UI-TARS-1.5-7B | 40.8 | 51.9 | 11.1 |
| UGround-7B | 16.5 | 30.0 | 13.5 |

消融实验表明，粗到细聚焦与候选选择均贡献显著，其中候选选择对歧义偏差的修正效果更为突出。在 ScreenSpot-Pro 的 Office 领域，BAMI 将 TianXi-Action-7B 的图标定位准确率从 54.7% 提升至 60.4%，显示其在密集文本与图标混合场景下的优势。然而，在 CAD 领域，提升幅度相对较小（18.8% 至 29.7%），暗示该方法在极端高分辨率且元素极度稀疏的场景下可能存在收益递减。

评估边界方面，论文未报告推理延迟与 Token 消耗指标，仅说明在单张 RTX 4090 GPU 上运行。由于 BAMI 依赖外部校正模型（如 GPT-5 或 Qwen3-VL-8B），实际部署时的端到端延迟可能显著高于单次前向传播。代码已开源，超参数（迭代次数 $N=2$，裁剪比例 $\lambda \in [0.5, 0.7]$）已明确，具备可复现性。

## 关联研究分析

从方法设计看，BAMI 与 GUI-Spotlight 同属自适应视觉聚焦路线，但 GUI-Spotlight 依赖工具调用接口执行裁剪，而 BAMI 通过掩码预测生成互斥候选集。这一差异源于 GUI-Spotlight 假设模型具备自主决策裁剪区域的能力，而 BAMI 认为模型在歧义场景下缺乏可靠的自我校正能力，需引入外部规则干预。根源在于 GUI-Spotlight 更关注空间搜索效率，而 BAMI 更关注语义歧义消解，两者在精度与计算成本间做出了不同取舍。

从问题动机看，BAMI 与 UI-Ins 均关注推理增强，但 UI-Ins 侧重结构化指令推理以提升语义理解，BAMI 侧重空间偏差修正以提升定位精度。UI-Ins 通过 CoT 细化指令，解决的是“找什么”的问题，而 BAMI 通过候选选择解决的是“选哪个”的问题。这种分工暗示 GUI 定位的瓶颈可能同时存在于语义解析与空间映射两个层面，单一维度的优化难以突破性能天花板。BAMI 未探索指令细化与空间修正的联合优化，这是否会导致在模糊指令场景下的性能受限，论文未给出回答。

## 总结

GUI 定位在高分辨率界面中的核心矛盾是模型离散化坐标表示与连续空间定位需求之间的不匹配。BAMI 抓住这一矛盾，通过无训练的推理时操作，将单步定位转化为多步递归搜索，利用粗到细聚焦缩小空间误差，利用候选选择修正语义歧义。实验证明该方法在 TianXi-Action-7B 上将 ScreenSpot-Pro 准确率从 51.9% 提升至 57.8%，验证了推理路径结构化对解锁模型潜力的有效性。然而，BAMI 的边界在于其依赖外部校正模型，引入了额外的计算开销，且绝对精度仍低于 GUI-AIMA-3B 等最新训练式 SOTA。当外部校正模型的推理延迟成为瓶颈时，如何将选择逻辑内化至骨干模型而不牺牲精度，是 BAMI 框架下亟待解决的具体问题。
