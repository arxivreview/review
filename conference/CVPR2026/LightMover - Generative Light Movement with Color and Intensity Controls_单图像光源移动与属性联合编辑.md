# CVPR2026最新论文 ｜LightMover: Generative Light Movement with Color and Intensity Controls ｜单图像光源移动与属性联合编辑

研究机构：Adobe研究院、美国耶鲁大学

作者：Gengze Zhou、Tianyu Wang、Soo Ye Kim 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.27209)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.27209)

> 单图像重光照旨在改变照明条件同时保持几何与材质不变，但现有逆渲染方法病态且计算昂贵，纯扩散模型缺乏对单个光源位置、颜色、强度的因果控制。LightMover 将光源编辑建模为序列到序列预测，利用视频扩散先验处理单帧，并通过自适应 Token 剪枝压缩非空间控制信号。该方法实现了像素级的光源移动与属性调节，但依赖大规模合成配对数据，且在通用静态重光照基准上未与专用 SOTA 模型直接对比。

## 研究背景

理解 LightMover 需先厘清逆渲染的病态性与生成式编辑的控制粒度矛盾。从单张图像分离几何、材质和光照存在固有歧义，传统逆渲染框架虽物理严谨，但泛化能力极弱且无法支持交互式操作。扩散模型（Diffusion Models）提供了强大的视觉先验，能生成逼真的光照效果，但通常仅支持全局色调或环境图条件，缺乏对单个光源空间位置与属性（颜色、强度）的显式参数化控制。这种“全局氛围”与“局部因果”的错位，使得用户无法像操作 3D 软件一样，在单张真实图像中精确移动一盏灯并观察其阴影与反射的因果变化。

图像重光照领域已从显式物理分解转向数据驱动的生成式编辑，但当前主流方法在精细控制上存在瓶颈。逆渲染路线受限于单图输入的欠定性，难以处理复杂遮挡与间接光照；通用扩散编辑器（如 SDEdit、InstructPix2Pix）依赖文本或掩码驱动，无法提供光源位置的精确空间约束；物体移动模型（如 ObjectMover）虽能重定位物体，但将光照视为隐式背景，无法正确传播光源移动带来的阴影偏移与颜色变化。LightMover 的切入点在于将“光源移动”视为一种特殊的物体移动任务，同时引入光照属性 Token，利用视频扩散模型的时空建模能力，在单帧图像中实现光源位置、颜色、强度的联合因果编辑。

## 核心方法

### 序列到序列的光照控制框架

LightMover 基于 ObjectMover 的序列到序列生成框架，将单图像重光照任务映射为伪视频序列处理。输入条件被编码为连续的伪视频帧：参考图像 $I_{ref}$、目标物体裁剪 $I_{obj}$、移动图 $I_{move}$、颜色控制 $I_{color}$ 及强度控制 $I_{intensity}$。所有帧经 VAE 编码为潜在 Token，由扩散 Transformer 联合处理。移动图 $I_{move}$ 通过 RGB 通道分别编码源区域（R）与目标区域（GB）的边界框，实现空间位移的显式约束。颜色与强度控制帧分别指定目标色温与曝光变化量（以 EV 为单位），其中强度增益 $G_{illum}$ 定义为 $G_{illum} = 2^{S_{EV}}$，即 $S_{EV}$ 为曝光值调整量，+1 EV 对应光照加倍，-1 EV 对应减半。该设计将光照编辑转化为序列预测问题，使模型能同时推理空间移动与属性变化的联合效应。

### 多信号位置编码与自适应 Token 剪枝

为解决多模态条件在 Transformer 中的语义混淆，LightMover 引入多信号位置编码（MSPE）。MSPE 整合四个正交子空间：空间编码（W, H）保留帧内结构，时间编码（T）维持序列顺序，条件类型编码（C）区分参考、物体、移动、颜色、强度等模态，帧角色编码（R）区分输入条件与输出帧。这些编码通过旋转感知调制融合，使模型能解耦不同条件的语义贡献。针对非空间控制信号（颜色、强度）导致的序列长度膨胀，LightMover 提出自适应 Token 剪枝机制。对于空间控制信号（如移动图），若边界框面积比低于阈值 $\tau=0.2$，保留全分辨率 Token；否则按比例下采样。对于非空间信号，引入可学习下采样率，联合优化 Token 数量与生成保真度。该机制将平均控制序列长度减少 41%，在保持局部编辑精度的同时显著提升计算效率。

### 物理引导的多任务数据生成

LightMover 构建了一个可扩展的物理渲染数据管道，生成大规模配对图像以监督因果光照效应。使用 Blender 渲染 25 个艺术家设计的室内场景，结合 100 个来自 Objectverse-XL 的光源资产，通过动画轨迹生成约 32,000 组光照变化配对。渲染过程采用物理分离策略，将图像分解为环境基图 $I_{amb}$ 与直接光贡献 $I_{light}$，在线性 RGB 空间合成：$I_{out} = I_{amb} + G_{illum} \cdot I_{light} \odot \mathbf{c}_t$，其中 $\mathbf{c}_t$ 为目标 RGB 色调。训练时动态调整环境缩放因子 $\alpha$、强度增益 $G_{illum}$ 与色调 $\mathbf{c}_t$，实现无界光照变化。多任务联合训练（移动、颜色、强度、插入、移除）使位置、颜色、强度信号相互正则化，提升模型在所有光照任务上的稳定性与精度。

## 实验评估

LightMover 在自建 LightMove-A（真实数据）与 LightMove-B（合成数据）基准上评估，对比基线包括 LLM 驱动编辑模型（Gemini-2.5-Flash-Image、Qwen-Image）及物体移动模型 ObjectMover。基线覆盖文本驱动与物体移动两条路线，但缺失 PI-Light、TokenLight 等专用重光照 SOTA 模型，限制了其在通用静态重光照任务上的可比性。

| 方法 | PSNR↑ | DINO↑ | CLIP↑ |
|---|---|---|---|
| LightMover (ours) | 20.38 | 81.27 | 91.85 |
| w/ adaptive pruning | 20.39 | 80.26 | 91.42 |
| ObjectMover [65] | 19.49 | 78.12 | 90.48 |
| Gemini-2.5-Flash-Image [45] | 19.59 | 72.46 | 89.72 |
| Qwen-Image [59] | 19.01 | 69.94 | 87.27 |

在 LightMove-A 真实数据上，LightMover 以 20.38 dB PSNR 领先 ObjectMover 0.89 dB，DINO 分数高出 3.15 点，表明其在保持语义一致性的同时提升了像素级保真度。自适应剪枝版本 PSNR 微升至 20.39 dB，但 DINO 略降 1.01 点，显示剪枝在效率与语义细节间存在轻微权衡。

消融实验验证了多任务训练与数据增强的贡献。移除光照增强（Light Aug.）后，PSNR 从 20.38 降至 19.88，DINO 从 81.27 降至 79.93，表明物理分离渲染对因果光照学习至关重要。移除颜色或强度变化任务后，PSNR 分别降至 20.07 与 20.25，DINO 降至 79.73 与 81.02，证实多任务联合训练的正则化效应。移除自适应下采样后，PSNR 降至 19.38，DINO 降至 75.62，显示 Token 剪枝对空间控制精度的关键作用。

评估边界方面，LightMover 未报告 MIT MIIW 等标准重光照基准结果，无法直接对比其静态重光照能力。指标仅覆盖 PSNR、DINO、CLIP，缺乏物理一致性定量指标（如阴影方向误差）。代码与超参数未完全公开，可复现性受限。

## 关联研究分析

从问题动机看，LightMover 与 TokenLight 同属参数化控制路线，但控制粒度与任务焦点不同。TokenLight 将光源属性编码为离散 Token，侧重静态光源的颜色、强度、漫反射程度调节，实现局部光照编辑；LightMover 则聚焦光源的空间移动，将移动图作为核心条件，结合颜色与强度 Token 实现动态因果编辑。差异根源在于任务特性：TokenLight 假设光源位置固定，优化属性调节的精度；LightMover 假设光源位置可变，优化移动过程中的阴影与反射传播。LightMover 未探索静态属性调节的极限精度，而 TokenLight 未处理光源移动带来的全局光照变化，两者在控制维度上互补。

从方法设计看，LightMover 与 PI-Light 代表物理引导生成式重光照的两种实现路径。PI-Light 采用两阶段方法，先通过逆向神经渲染分解内在属性，再基于灰球光照条件微调扩散模型，依赖显式内在分解确保材质与几何不变；LightMover 则通过端到端学习，利用物理渲染数据管道中的因果光照变化（阴影、反射）监督模型，无需显式分解。差异根源在于数据依赖：PI-Light 依赖高质量合成数据训练分解器，可能引入分解误差；LightMover 依赖大规模配对数据学习因果效应，数据效率更高但泛化能力受限于数据分布。LightMover 未验证其在无配对真实数据上的鲁棒性，而 PI-Light 的显式分解可能提供更强的物理可解释性。

## 总结

LightMover 旨在解决单图像中光源空间移动与属性联合编辑的因果一致性问题，现有逆渲染方法病态且计算昂贵，纯扩散模型缺乏精细控制，而 LightMover 通过视频扩散先验与自适应 Token 剪枝实现了像素级因果编辑。该方法在 LightMove-A 真实数据上取得 20.38 dB PSNR 与 81.27 DINO 分数，优于 ObjectMover 与 LLM 编辑模型，证明了序列到序列框架与多任务训练的有效性。然而，其依赖大规模合成配对数据，且在通用静态重光照基准上未与专用 SOTA 模型对比，暴露了其在无配对真实场景泛化能力上的不确定性。当支持集从合成数据扩展到无配对真实图像时，模型能否保持因果光照推理的稳定性，论文未给出回答。
