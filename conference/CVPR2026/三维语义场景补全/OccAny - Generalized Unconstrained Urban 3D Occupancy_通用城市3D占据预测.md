# CVPR2026最新论文 ｜OccAny: Generalized Unconstrained Urban 3D Occupancy ｜通用城市3D占据预测

作者：Anh-Quan Cao、Tuan-Hung Vu

论文原文见 [arXiv](https://arxiv.org/abs/2603.23502)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.23502)

> 3D语义占据预测旨在从传感器观测推断完整的三维场景几何与语义，以支撑自动驾驶对非刚体及遮挡区域的细粒度理解。现有监督方法依赖域内标注与精确传感器标定，自监督方法虽降低标注成本但仍受限于特定训练域的相机参数偏差，导致跨场景泛化能力弱。本文切入点在于利用视觉几何基础模型的零样本泛化能力，通过引入分割强制与新颖视角渲染策略，解决度量级精度缺失与杂乱场景几何补全不足的问题。该方法在域外测试中超越了部分域内自监督基线，但其性能仍显著低于域内监督SOTA，且未涉及动态场景的时序一致性建模。

## 研究背景

当自动驾驶系统面对不同城市或传感器配置时，传统3D占据预测模型因训练数据与测试数据的分布差异而失效。这种失效源于2D特征向3D空间提升过程中嵌入的传感器特定偏差，即模型过度依赖特定的相机内外参。为克服这一局限，视觉几何基础模型（Visual Geometry Foundation Models, VGFM）如Dust3r和MUSt3R通过大规模点图预测任务，展示了无需精确标定即可推断3D结构的潜力。然而，通用VGFM缺乏城市占据预测所需的度量级精度、杂乱几何补全能力及对城市场景特性的适配，直接应用会导致预测尺度模糊且非监督区域几何破碎。

3D占据预测的主流路线分为监督学习与自监督学习。监督方法在域内数据上表现优异，但无法迁移至新传感器或新环境；自监督方法通过可微分体积渲染消除3D标注依赖，但仍需在特定域内训练以学习相机位姿与内参，限制了其跨域泛化能力。随着自动驾驶车队规模扩大，传感器配置日益异构，亟需一种能够利用异构训练数据、无需域内标注即可在任意未标定城市场景中运行的通用占据预测框架。OccAny正是针对这一瓶颈，将VGFM范式专门化于城市占据任务，通过引入语义正则化与测试时视角增强，实现了从“域内专用”向“域外通用”的范式转变。

## 核心方法

### 方法参照系

OccAny基于MUSt3R架构，遵循视觉几何基础模型的标准流程：通过共享编码器-解码器处理多视角图像，预测全局与局部点图及相机位姿。与通用VGFM的关键差异在于，OccAny专注于室外城市数据集，并针对LiDAR监督稀疏导致的几何补全失效，引入了分割特征蒸馏与新颖视角渲染两个专用模块，将纯几何预测扩展为几何-语义联合预测。

### 分割强制（Segmentation Forcing）

在3D重建阶段，OccAny在MUSt3R解码器后增加SAM2特征预测头，通过分割强制损失约束几何特征与分割特征的一致性。该设计动机在于解决LiDAR点云稀疏导致的非监督区域预测不规则问题，利用SAM2的高保真分割线索正则化几何预测。损失函数定义为：

$$ \mathcal{L}_{forcing} = \frac{1}{N_{rec}} \sum_{i=1}^{N_{rec}} \| \mathbf{C}_i \odot (\mathbf{F}_i - \mathbf{F}_i^{SAM2}) \|^2_2 $$

其中 $\mathbf{C}_i$ 为几何置信度图，$\mathbf{F}_i$ 为预测的SAM2-like特征，$\mathbf{F}_i^{SAM2}$ 为冻结SAM2模型输出的特征。该公式通过置信度加权，迫使网络在高置信度区域（如物体表面）对齐分割特征，而在低置信度区域（如天空）忽略误差，从而在保持几何精度的同时注入语义一致性。

### 新颖视角渲染（Novel View Rendering）

在重建阶段之后，OccAny引入独立的渲染编码器-解码器，从全局场景记忆 $\mathbf{M}$ 中推断任意新颖视角的点图与分割特征。该设计动机在于解决单帧或有限视角输入下的遮挡与几何缺失问题，通过测试时视角增强（Test-time View Augmentation, TTVA）在推理时生成虚拟视角以补全场景。渲染过程通过交叉注意力机制查询场景记忆：

$$ \mathbf{P}_j^{novel} = D_{rnd}(\mathbf{X}_j, \mathbf{M}) $$

其中 $\mathbf{X}_j$ 为新颖视角的token表示，$\mathbf{M}$ 为重建阶段生成的全局场景记忆。该机制允许模型在推理时沿预测轨迹采样虚拟相机位姿，渲染出更密集的点云，从而在点级和体素级完成几何补全，显著提升遮挡区域的预测密度。

## 实验评估

OccAny在SemanticKITTI和Occ3D-NuScenes两个域外基准上评估，对比基线包括通用VGFM（MUSt3R, VGGT, AnySplat）及域内自监督方法（SelfOcc, OccNeRF）。实验设置涵盖序列、单目和环视三种输入模式。

| 方法 | 设置 | SemanticKITTI IoU | Occ3D-NuScenes IoU |
| :--- | :--- | :--- | :--- |
| MUSt3R | Sequence | 11.97 | 13.01 |
| CUT3R* | Sequence | 15.93 | 17.62 |
| SelfOcc (In-domain) | Monocular | 21.97 | - |
| OccNeRF (In-domain) | Monocular | 22.81 | - |
| **OccAny** | Sequence | **25.91** | **23.55** |
| **OccAny** | Monocular | **24.03** | - |
| **OccAny** | Surround-view | - | **34.15** |

在序列设置下，OccAny在SemanticKITTI上达到25.91% IoU，比最强零样本基线CUT3R*高约10个百分点；在Occ3D-NuScenes上达到23.55% IoU。在更具挑战性的单目设置下，OccAny以24.03% IoU超越了域内自监督SOTA SelfOcc（21.97%）和OccNeRF（22.81%），证明了其零样本泛化的有效性。

消融实验显示，分割强制与新颖视角渲染均对性能有显著贡献。移除分割强制导致SemanticKITTI序列IoU从25.91%降至24.88%，移除新颖视角渲染则降至24.23%。TTVA策略中，增加视角数量与移动步长对性能提升最大，从19.64%提升至25.91%。

评估边界方面，论文未报告计算效率（FPS）与内存占用，且未提供置信区间。代码已开源，但超参数细节（如TTVA的具体采样策略在不同场景下的敏感性）未完全披露。

## 关联研究分析

从问题动机看，OccAny与LOC（Gao et al., 2025）均关注开放词汇与泛化，但技术路径截然不同。LOC依赖CLIP对齐实现封闭集到开放集的语义扩展，仍需域内3D标注训练几何模块；OccAny则通过VGFM的零样本能力彻底摆脱域内标注依赖，但牺牲了部分几何精度。这种差异源于任务特性：LOC追求语义开放性，OccAny追求几何通用性。OccAny在域外IoU上低于域内监督SOTA（如Gau-Occ的55.1% mIoU），表明零样本泛化与极致精度之间存在权衡，论文未探索如何在保持泛化性的同时缩小这一差距。

从方法设计看，OccAny与ST-GS（Yan et al., 2025）同属稀疏表示路线，但ST-GS使用3D高斯原语替代体素以解决实时性问题，而OccAny使用点图预测+体素化以解决泛化性问题。ST-GS依赖多帧时间一致性机制，适用于动态场景；OccAny仅处理静态序列，未涉及4D预测。这种差异反映了当前领域在“效率-精度”与“泛化-精度”之间的不同取舍。OccAny的TTVA策略在静态场景下有效，但在动态场景中，虚拟视角的几何补全可能因物体运动而产生伪影，论文未对此进行验证。

## 总结

OccAny旨在解决3D占据预测中跨场景泛化能力弱的问题，通过引入分割强制与新颖视角渲染，将视觉几何基础模型范式适配于城市占据任务。该方法在域外测试中超越了部分域内自监督基线，证明了零样本泛化的可行性。然而，其性能仍显著低于域内监督SOTA，且未涉及动态场景的时序一致性建模。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
