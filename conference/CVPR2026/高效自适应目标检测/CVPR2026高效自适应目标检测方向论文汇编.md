【AKCMamba-YOLO: Selective State Space Models For Real-Time Object Detection ｜选择性状态空间模型实时检测器

作者：Long Chen、Hui Wang、Man Xu 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_054047328c16)

> 实时目标检测长期受困于卷积网络局部感受野与Transformer全局建模高计算成本之间的结构性矛盾，导致复杂场景下长程依赖建模能力不足。现有方案要么牺牲精度换取速度，要么引入重型注意力机制导致边缘部署困难。本文切入点在于利用选择性状态空间模型（SSM）的线性复杂度特性，在YOLO架构中替换传统卷积模块以兼顾全局感知与实时性。通过设计3CAKCMamba与4CAKCMamba模块，将自适应核卷积与SSM深度融合，实现了从静态局部特征提取到动态序列建模的范式转变。该方案在COCO2017上以46.3% mAP和14.9G FLOPs实现了精度与效率的平衡，但其精度仍低于当前SOTA，且未解决NMS后处理带来的端到端部署障碍，其作为通用检测骨干的泛化能力存疑。

【PaQ-DETR: Learning Pattern and Quality-Aware Dynamic Queries for Object Detection ｜模式与质量感知动态查询检测器

研究机构：美国纽约大学、美国加州大学尔湾分校

作者：Zhengjian Kang、Jun Zhuang、Kangtong Mo 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.06917)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.06917)

> 检测 Transformer（DETR）系列模型在端到端训练中存在严重的查询激活不平衡，导致大量查询参数未被有效优化，限制了模型容量。现有静态查询缺乏场景适应性，而内容依赖动态查询又引入语义不稳定性，两者均未触及一对一匈牙利匹配引发的结构性梯度稀疏问题。PaQ-DETR 通过共享模式组合生成动态查询，并引入质量感知的一对多分配策略，从表示与监督两端同时缓解不平衡。该方法在 COCO 等基准上带来 1.1–4.2 mAP 的稳定提升，但其计算开销与实时部署潜力仍存疑。

【YOLO-Master: MOE-Accelerated with Specialized Transformers for Enhanced Real-time Detection ｜基于混合专家的实时目标检测动态计算架构

研究机构：新加坡管理大学

作者：Xu Lin、Jinlong Peng、Zhenye Gan 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.23273)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.23273)

> 实时目标检测长期受困于静态计算模式，即无论输入场景复杂度如何，模型均执行固定算力的密集推理，导致简单场景算力冗余而复杂场景容量不足。现有 YOLO 系列架构虽在精度与速度间取得平衡，但缺乏根据输入内容动态分配计算资源的机制。本文提出 YOLO-Master，通过引入高效稀疏混合专家（ES-MoE）模块，在骨干与颈部实现实例条件自适应计算。该设计在 Nano 级模型上实现了精度与延迟的帕累托改进，但其动态路由在极端场景下的最坏情况延迟控制及与 Transformer 路线的竞争力仍存疑。

【YOLO-ULM: Ultra-Lightweight Models for Real-Time Object Detection ｜YOLO-ULM：基于大核深度卷积与重参数化下采样的超轻量级实时检测器

作者：Shasha Han、Chong Li、Xinning Wang 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_5ed04be04b72)

> 实时目标检测在边缘部署中面临算力受限与精度需求的双重约束，现有轻量化方法往往通过激进的结构压缩牺牲特征表达能力，导致小目标与复杂场景下的性能显著下降。YOLO-ULM 针对这一矛盾，通过引入大核深度卷积聚合模块与可重参数化并行下采样结构，在保持骨干网络语义完整性的前提下降低计算冗余。该架构配合非线性难度感知的损失函数，实现了在同等算力下更高的检测精度。尽管其在轻量级 CNN 区间表现优异，但缺乏端到端 NMS-free 机制与预训练权重支持，限制了其在复杂动态场景下的泛化潜力。

】
