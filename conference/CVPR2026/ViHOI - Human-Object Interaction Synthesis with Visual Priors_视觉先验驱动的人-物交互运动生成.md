# CVPR2026最新论文 ｜ViHOI: Human-Object Interaction Synthesis with Visual Priors ｜视觉先验驱动的人-物交互运动生成

研究机构：华南理工大学

作者：Songjin Cai、Linjie Zhong、Ling Guo 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.24383)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.24383)

> 人-物交互（HOI）运动生成旨在合成物理合理且语义一致的动作序列，但现有扩散模型受限于文本条件的抽象性，难以捕捉物体几何与空间关系。本文提出 ViHOI，利用视觉-语言模型（VLM）从2D图像中提取分层视觉与文本先验，作为扩散模型的紧凑条件输入。该方法通过“图像即运动先验”的范式，解决了纯文本条件导致的“一对多”映射歧义，在未见物体泛化上表现优异，但其对显式物理动力学约束的缺失仍是主要局限。

## 研究背景

HOI 运动生成的核心难点在于将抽象的语言指令映射为具体的三维时空轨迹。当输入仅为“拿起盒子”这类文本时，模型面临物体形状、尺寸及人体姿态的巨大不确定性，这构成了典型的“一对多”学习问题。为缓解此歧义，研究者通常引入额外先验，主要分为语义增强与物理约束两类。语义增强利用大语言模型（LLM）扩展文本细节，但缺乏对空间关系的直接监督，易导致接触不一致或物体悬浮；物理约束方法引入接触点或运动学规则，虽能局部修正，却往往忽视全身运动的连贯性与全局动态。

现有方法在局部精度与全局一致性之间难以平衡，且对训练集外物体的泛化能力不足。ViHOI 的切入点在于利用 2D 图像作为中间表示，其天然包含物体几何、尺度及人-物空间关系等丰富视觉信息。与直接依赖文本或稀疏关键点不同，2D 图像提供了结构化的视觉先验，能够以低成本实现语义与几何的对齐。本文旨在验证这种视觉先验能否有效弥补文本条件的不足，提升生成运动的质量与泛化性。

## 核心方法

### 方法参照系

标准 HOI 生成流程通常采用扩散模型，以文本嵌入为条件，通过迭代去噪合成运动序列。本文的关键差异在于条件注入方式：不再直接使用文本编码器输出，而是引入 VLM 从 2D 图像中提取视觉与文本先验，并通过适配器压缩为紧凑 Token，作为扩散模型的联合条件。

### VLM 分层先验提取

针对 VLM 不同层对视觉与文本关注度的差异，本文设计分层解耦策略。浅层（第3层）保留几何细节，提取视觉先验 $E_v$；深层（第12层）侧重语义编码，提取文本先验 $E_t$。这种解耦确保了视觉几何信息与文本语义指令在特征空间中的自然对齐，避免了单一层输出中模态信息的混淆。

$$
E_v = \text{Layer}_3(\text{VLM}(I, P)), \quad E_t = \text{Layer}_{12}(\text{VLM}(I, P))_{\text{tokens}}
$$

该公式表明，视觉先验取自 VLM 早期层的图像特征，而文本先验取自深层层中对应文本描述的 Token 嵌入，实现了模态分离。

### Q-Former 先验适配与扩散生成

高维变长的 VLM 特征难以直接作为扩散条件，本文引入 Q-Former 适配器将其压缩为固定维度的紧凑 Token。以视觉先验为例，通过可学习查询 $q_v$ 与特征 $Z_v$ 进行交叉注意力，得到紧凑视觉条件 $c_v$。

$$
c_v = \text{CrossAttn}(q_v, Z_v, Z_v), \quad Z_v = W_{proj} E_v
$$

此过程将冗余的高维特征蒸馏为信息密集的紧凑表示，既保留了关键交互线索，又降低了扩散模型的条件计算复杂度。最终，$c = \{c_v, c_t\}$ 作为条件注入扩散模型，指导运动序列 $x_0$ 的去噪重建。

## 实验评估

实验在 FullBodyManipulation 和 BEHAVE 数据集上进行，基线包括 MDM、CHOIS、ROG 和 SemGeoMo。ViHOI 作为即插即用模块，显著提升了各基线性能。在 FullBodyManipulation 上，CHOIS+ViHOI 的 MPJPE 降至 14.97 cm，优于 CHOIS 的 15.43 cm；FID 从 0.77 降至 0.68，表明生成分布更贴近真实数据。

| Method | R-precision Top-1 | FID | MPJPE |
| :--- | :--- | :--- | :--- |
| CHOIS | 0.37 | 0.77 | 15.43 |
| CHOIS+ViHOI | 0.41 | 0.68 | 14.97 |

消融实验显示，V3-T12 层组合（视觉第3层，文本第12层）表现最佳，R-score 达 0.79，MPJPE 14.97 cm。相比之下，V12-T12 组合 MPJPE 为 15.90 cm，证实了分层解耦策略的有效性。在未见物体测试中，CHOIS+ViHOI 的 MPJPE 为 17.09 cm，优于 CHOIS 的 18.51 cm，验证了视觉先验对泛化能力的提升。

| Method | R-precision Top-1 | MPJPE |
| :--- | :--- | :--- |
| CHOIS | 0.23 | 18.51 |
| CHOIS+ViHOI | 0.23 | 17.09 |

评估指标涵盖几何精度（MPJPE）、交互质量（Contact Precision）及分布距离（FID），但缺乏对长期动力学稳定性的显式评估。代码已开源，但训练依赖 GT 渲染图像，推理依赖文生图模型，复现成本较高。

## 关联研究分析

从问题动机看，ViHOI 与 SemGeoMo 均试图解决文本条件不足的问题，但 SemGeoMo 依赖 LLM 生成细粒度文本和 Affordance 图，属于语义增强路线；ViHOI 则直接利用 2D 图像几何信息，属于视觉先验路线。SemGeoMo 在接触精度上略优（Cprec 0.82 vs 0.83），但 ViHOI 在脚滑（FS）和 MPJPE 上表现更好，表明视觉先验更利于全身运动连贯性。这一差异源于图像先验天然包含全局空间关系，而文本增强难以精确描述几何约束。

从方法设计看，ViHOI 与 ROG 形成对比。ROG 使用显式几何关键点采样，属于物理约束路线；ViHOI 使用隐式视觉特征，属于数据驱动路线。ROG 在 FID 上略优（1.54 vs 1.18，未加 ViHOI 时），但 ViHOI 在未见物体泛化上显著优于 ROG（MPJPE 17.09 vs 19.79）。这暗示显式几何先验在已知物体上有效，但泛化能力受限；而视觉先验通过 VLM 的世界知识，更好地处理了分布外物体。

## 总结

ViHOI 解决了 HOI 生成中纯文本条件导致的几何歧义问题，利用 VLM 从 2D 图像提取分层先验，通过 Q-Former 压缩为紧凑条件，显著提升了生成质量与泛化性。在 FullBodyManipulation 上，CHOIS+ViHOI 的 MPJPE 降至 14.97 cm，FID 降至 0.68，验证了视觉先验的有效性。然而，该方法依赖训练时的 GT 渲染图像和推理时的文生图模型，且未显式建模物理动力学，导致在复杂接触场景下可能缺乏长期稳定性。当文生图模型生成的图像与真实物理场景存在风格差异时，视觉先验的鲁棒性是否足以保证物理合理性，论文未给出充分回答。
