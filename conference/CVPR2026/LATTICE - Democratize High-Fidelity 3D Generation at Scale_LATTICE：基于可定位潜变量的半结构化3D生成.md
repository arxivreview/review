# CVPR2026最新论文 ｜LATTICE: Democratize High-Fidelity 3D Generation at Scale ｜LATTICE：基于可定位潜变量的半结构化3D生成

研究机构：香港中文大学

作者：Zeqiang Lai、Yunfei Zhao、Zibo Zhao 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.03052)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.03052)

> 3D资产生成长期受困于表示效率与几何保真度的矛盾，现有方法要么牺牲结构灵活性换取计算效率，要么因缺乏空间锚点导致生成质量停滞。LATTICE指出3D生成落后于2D的核心原因在于任务需同时推断“内容位置”与“内容属性”，而传统向量集（VecSet）表示虽紧凑却缺失可定位结构。本文提出VoxSet表示，将潜变量锚定于粗体素网格中心，通过旋转位置编码（RoPE）引导扩散过程，实现了无需重训的测试时Token缩放。该方法在几何重建上超越了主流基线，但其两阶段依赖外部粗结构生成的设计，限制了端到端优化的潜力。

## 研究背景

三维形状生成旨在从二维图像或文本自动合成具备几何属性的三维内容，其核心痛点在于传统建模对专家经验的依赖。理解本文需厘清两个关键概念：向量集（VecSet）与稀疏体素（Sparse Voxel）。VecSet通过交叉注意力将密集点云压缩为少量特征向量，计算高效但缺乏空间结构；稀疏体素保留空间局部性，利于细节保留，但活跃体素序列过长导致计算开销巨大。二者代表了3D潜空间表示中“紧凑性”与“结构性”的两极。

当前领域主流范式已从二维先验蒸馏转向基于紧凑潜空间的原生三维生成。然而，3D生成质量显著落后于2D图像合成，根源在于2D网格坐标预定义，模型仅需推断像素值；而3D生成需联合推理空间结构与几何内容，搜索空间急剧扩大。现有VecSet方法（如Hunyuan3D-2）虽高效，但潜变量与表面点查询绑定，测试时位置未知，无法利用空间先验；稀疏体素方法（如Trellis）虽具结构，但训练序列长度超过20,000，系统复杂且扩展性存疑。LATTICE的切入点在于识别出“可定位性”而非“结构性”才是生成模型扩展的关键，旨在通过引入可定位的半结构化表示，弥合3D与2D生成在质量与可扩展性上的差距。

## 核心方法

### 方法参照系

LATTICE属于基于潜空间扩散模型（LDM）的单体高保真几何生成路线。标准流程为：VAE将3D形状压缩至潜空间，DiT在潜空间执行去噪。本文与标准VecSet流程的关键差异在于查询机制：标准方法使用表面点查询，测试时位置不可知；本文改用体素中心查询，使潜变量具备可定位结构，从而支持位置编码引导与测试时缩放。

### VoxSet表示与体素查询

传统VecSet使用表面点作为查询，潜变量虽隐含位置信息，但测试时表面未知，导致位置先验失效。LATTICE引入体素查询（Voxel Queries），将查询点从表面移至与物体表面相交的活跃体素中心。这一改动解决了测试时位置未知的问题，使潜变量锚定于粗体素网格，具备显式空间结构。

$$
\mathbf{q}_i = \mathbf{c}_i + \epsilon, \quad \epsilon \sim U\left[-\frac{1}{2R}, \frac{1}{2R}\right]
$$

其中 $\mathbf{c}_i$ 为体素中心坐标，$R$ 为最小支持分辨率。训练时通过随机偏移 $\epsilon$ 增强鲁棒性，测试时可在任意高于 $R$ 的分辨率采样体素查询。该设计使VAE支持任意分辨率编解码，训练成本因渐进式Token扩展而大幅降低，同时消除了训练-测试域差距。

### 位置引导的扩散生成

在DiT去噪过程中，仅依赖图像条件难以引导稀疏几何表面的生成，因3D表面仅占据包围盒极小部分。LATTICE将体素查询的位置信息通过旋转位置编码（RoPE）注入每个噪声潜变量，解耦“位置”与“内容”的预测。

$$
\mathbf{z}_t = \text{DiT}(\mathbf{z}_t, \mathbf{c}_{img}, \text{RoPE}(\mathbf{q}))
$$

其中 $\mathbf{z}_t$ 为噪声潜变量，$\mathbf{c}_{img}$ 为DinoV2图像特征，$\mathbf{q}$ 为体素查询位置。RoPE提供强空间引导，显著改善模型收敛性。该设计使模型在测试时可通过增加体素查询数量（如从6144增至24576）来提升细节，实现无需重训的测试时缩放，突破了传统VecSet的分辨率上限。

## 实验评估

实验在Objaverse数据集上进行，评估指标为Chamfer Distance (CD) 和 F-score。基线覆盖VecSet（Hunyuan3D-2）、稀疏体素（Trellis, SparseFlex）及Triplane（Direct3D-s2）路线，未包含程序化生成方法。主实验对比LATTICE-1.9B与开源SOTA，结果显示LATTICE在CD与F1上均取得最优。

| 方法 | 分辨率 | CD (↓) | F1 (↑) |
| :--- | :--- | :--- | :--- |
| Hunyuan3D-2 | 64×4096 | 12.35 | 82.78 |
| SparseFlex | 512 | 8.020 | 90.94 |
| Direct3D-s2 | 1024 | 2.972 | 97.76 |
| LATTICE (Ours) | 64×8192 | 2.909 | 98.53 |
| LATTICE (Ours) | 64×20480 | 1.893 | 99.59 |

LATTICE在64×8192分辨率下CD为2.909，优于Direct3D-s2的2.972；在测试时缩放至64×20480时，CD降至1.893，F1升至99.59，验证了测试时缩放的有效性。

消融实验验证了体素查询与Query Jitter策略的贡献。固定分辨率训练的VAE在测试时性能显著下降，而Query Jitter VAE在64、128、256分辨率下均保持稳健，CD分别为6.03、5.32、5.36，优于固定训练的6.42、5.73、5.69。这表明随机偏移有效缓解了训练-测试域差距，提升了分辨率泛化能力。

| 策略 | Res 64 CD | Res 128 CD | Res 256 CD |
| :--- | :--- | :--- | :--- |
| Baseline | 10.7 | 7.72 | - |
| + Fixed Train | 6.42 | 5.73 | 5.69 |
| + Query Jitter | 6.03 | 5.32 | 5.36 |

评估边界方面，论文未报告置信区间，测试时缩放至24576 Token的统计显著性未验证。代码未开源，超参数细节有限，可复现性依赖对Hunyuan3D-2架构的精确复现。用户研究显示LATTICE在整体、主体、场景类别上胜率均超50%，但缺乏与商业模型的定量几何对比。

## 关联研究分析

从问题动机看，LATTICE与Trellis同属稀疏体素路线，但Trellis依赖复杂稀疏卷积处理长序列，LATTICE则通过VoxSet将结构信息注入VecSet，避免了稀疏计算开销。这一差异源于对“结构”定义的重新审视：Trellis认为空间局部性需显式体素网格，LATTICE则认为可定位性足以引导生成，无需完整体素特征。LATTICE在CD 1.893 vs Trellis 9.157的对比中，证明了轻量级结构引导优于重型稀疏计算。

从方法设计看，LATTICE与Hunyuan3D-2共享VAE与DinoV2条件框架，但Hunyuan3D-2使用表面点查询，测试时位置未知，无法支持测试时缩放。LATTICE通过体素查询解耦位置与内容，使模型在推理阶段可通过增加Token数量提升细节，而Hunyuan3D-2受限于固定分辨率。这一设计使LATTICE在保持VecSet紧凑性的同时，获得了类似稀疏体素的分辨率扩展能力，但代价是依赖外部模型生成粗结构，引入了两阶段误差累积风险。

## 总结

LATTICE旨在解决3D生成中紧凑表示与空间结构缺失的矛盾，通过VoxSet表示将潜变量锚定于体素中心，利用RoPE引导扩散过程，实现了测试时Token缩放。该方法在Objaverse上取得CD 1.893、F1 99.59的最优成绩，验证了可定位结构对生成质量的提升作用。然而，其两阶段设计依赖外部模型生成粗结构，若粗结构存在拓扑错误，细节生成将继承该误差，论文未提供对粗结构鲁棒性的量化评估。当输入图像包含复杂遮挡或非刚体形变时，体素查询的空间对齐是否仍能维持生成一致性，论文未给出回答。
