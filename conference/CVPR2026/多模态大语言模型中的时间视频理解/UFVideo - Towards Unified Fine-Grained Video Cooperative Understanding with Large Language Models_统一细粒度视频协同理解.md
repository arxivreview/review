研究机构：华中科技大学、美团

论文原文见 [arXiv](https://arxiv.org/abs/2512.11336)

> 视频大模型长期面临粒度割裂困境：全局问答、像素级分割与时间定位各自为政，无法在单一模型内实现跨尺度信息互补。现有专用模型在迁移至其他粒度任务时性能骤降，且缺乏评估多粒度协同能力的基准。UFVideo 通过统一视觉-语言对齐策略与相对时间 Token 机制，将三种粒度任务整合于同一 LLM 架构中，并构建了首个多粒度协同基准 UFVideo-Bench。该工作验证了多粒度联合训练的互益效应，但在纯时间定位精度上仍落后于强化学习范式，其统一架构对时序推理上限的影响尚存疑。

## 研究背景

视频理解任务通常被划分为全局语义问答、像素级对象指代与分割、以及时间级事件定位三个独立维度。这种划分源于早期多模态大语言模型（MLLMs）在单一任务上的优化路径：全局任务依赖长上下文建模，像素任务需要空间掩码解码，时间任务则聚焦于时间戳回归。然而，当模型仅针对单一粒度训练时，其内部表征往往过拟合于特定任务的输入输出分布，导致在处理跨粒度查询时出现语义断层。例如，擅长对象指代的模型难以准确回答“该对象在何时出现”，而专注时间定位的模型则无法生成对应的像素掩码。这种粒度隔离不仅限制了模型的泛化能力，也阻碍了细粒度感知与高层推理之间的相互增强。

随着视频大模型（Video LLMs）的发展，研究者开始尝试整合不同粒度的理解能力。RGA3 和 UniPixel 等模型统一了像素级任务，实现了指代与分割的互益，但完全忽略了时间维度；LLaVA-ST 虽引入时空理解，但局限于粗粒度的边界框定位，缺乏亚秒级精度。当前领域的主流共识认为，强化学习（RL）是提升时间定位精度的关键，如 TempR1 通过 GRPO 算法在 Charades-STA 上取得了 59.8 mIoU 的 SOTA 成绩。然而，这些 RL 方法通常针对单一任务优化，未探索多粒度任务间的协同效应。UFVideo 的切入点在于：不同粒度的视频知识具有互补性，全局语义可辅助细粒度定位，而时间线索能增强对象指代的准确性。本文旨在构建一个统一架构，通过共享表征实现跨粒度的协同理解，并填补多粒度协同评估的空白。

## 核心方法

### 多粒度任务对齐机制

现有 Video LLMs 通常采用任务特定的输入输出格式，导致模型无法灵活切换粒度。UFVideo 的核心创新在于设计了一套统一的视觉-语言引导对齐策略，通过特殊 Token 区分理解与生成阶段。对于时间定位，引入相对时间 Token `<Temp-τ>`，将视频时长归一化至固定长度 $N_t$，其定义为：

$$ \tau = \left\lfloor \frac{t}{T_n} \times N_t \right\rfloor $$

其中 $t$ 为当前帧时间，$T_n$ 为视频总时长。这一设计避免了绝对时间数值的离散化误差，使模型能感知时间的相对位置。对于像素级任务，插入 `<Ref>` Token 注入对象视觉提示，并通过 `<Seg>` Token 定位分割相关的语言嵌入。这种 Token 化策略使得全局、像素、时间三种任务共享同一 LLM 骨干，实现了架构层面的统一。

### 统一架构与掩码解码

在参照系中，传统方法将视觉编码与语言生成解耦，而 UFVideo 将 SAM2 掩码解码器直接集成到 LLM 输出端。具体而言，LLM 生成的 `<Seg>` Token 对应的隐藏状态 $H$ 被提取并投影为分割嵌入：

$$ S = \text{Decoder}(H \odot \rho_s, V_s) $$

其中 $\rho_s$ 为 `<Seg>` 的位置掩码，$V_s$ 为 SAM2 编码器处理的视频帧。这一设计解决了 LLM 难以直接输出像素级掩码的问题，同时保持了语言生成的流畅性。训练目标采用标准的下一 Token 预测损失，并结合二元交叉熵（BCE）和 DICE 损失约束掩码解码器。这种端到端的训练方式使得模型在生成文本的同时，能同步优化时间定位与像素分割，实现了多粒度任务的联合优化。

## 实验评估

UFVideo 在 9 个公开基准上进行了评估，基线覆盖 GPT-4o、Qwen2-VL、LLaVA-ST 等主流模型，但缺失 TempR1、TimeLens 等强化学习（RL）方法的对比。在 MVBench 通用视频理解任务上，UFVideo 平均准确率 67.3%，超过 GPT-4V 的 43.5% 和 Qwen2-VL 的 67.0%。在 Charades-STA 时间定位任务上，UFVideo 取得 44.7 tIoU，优于 LLaVA-ST 的 39.3 tIoU，但显著低于 TempR1 的 59.8 mIoU（据领域综述）。这表明统一架构在通用理解上具有优势，但在纯时间定位精度上仍受限于 SFT 范式。

| 基准 | 指标 | UFVideo | GPT-4o | Qwen2-VL | LLaVA-ST |
| :--- | :--- | :--- | :--- | :--- | :--- |
| MVBench | Avg. | 67.3 | 43.5 | 67.0 | 64.2 |
| Charades-STA | tIoU | 44.7 | - | - | 39.3 |
| VideoRefer-Bench-Q | Avg. | 74.9 | 71.3 | 69.6 | - |

消融实验显示，联合训练所有任务（Seg+Temp+QA）相比仅训练分割任务，在 MeViS 上的 $J\&F$ 从 52.26 提升至 62.80，在 Charades-STA 上的 tIoU 从 39.20 提升至 44.72。这验证了多粒度任务的互益效应。然而，时间 Token 数量的消融表明，从 100 增加到 150 Token 时，tIoU 仅从 39.19 提升至 42.07，边际收益递减。这暗示固定长度采样 $N_t=100$ 可能在长视频中丢失细粒度动态，限制了时间定位的上限。

评估协议方面，UFVideo-Bench 是首个多粒度协同基准，但样本量较小，且未报告置信区间。代码与数据已开源，使用 32 张 A800 GPU 训练，超参数（如 $\alpha=2.0, \beta=0.5$）已公开，可复现性较好。然而，缺乏与 RL 方法的公平对比，使得无法隔离统一架构与优化算法对性能的影响。

## 关联研究分析

从问题动机看，UFVideo 与 TempR1 代表了两种不同的优化路径。TempR1 聚焦于单一任务的时间定位精度，通过 GRPO 强化学习提升时序推理能力，在 Charades-STA 上取得 59.8 mIoU。而 UFVideo 追求多粒度统一，采用 SFT 范式，在时间定位上落后 15.1 个点。这一差距可能源于 RL 对时序逻辑的显式优化，而 SFT 更依赖语言先验。UFVideo 的切入点在于验证多粒度互补性，但未能解决时间幻觉问题，其统一架构是否真正增强了时序证据的利用，而非仅依赖语言捷径，论文未给出深入分析。

从方法设计看，UFVideo 与 UniPixel 同属像素级统一路线，但 UFVideo 扩展至时间维度。UniPixel 通过统一指代与分割任务，实现了感知与推理的互益，但缺乏时间理解。UFVideo 引入相对时间 Token 和 SAM2 解码器，实现了三尺度统一。然而，UFVideo 的时间 Token 机制是静态的，未考虑视频动态变化，而 TempR1 等 RL 方法通过过程奖励动态调整时序感知。这种静态 Token 设计在长视频或快速动态场景中可能失效，导致时间定位精度受限。UFVideo 未探索自适应采样或动态 Token 分配，这可能是其时间定位性能瓶颈的根源。

## 总结

UFVideo 旨在解决视频大模型粒度割裂的问题，通过统一视觉-语言对齐策略与相对时间 Token 机制，实现了全局、像素、时间三尺度在单一 LLM 架构中的协同理解。实验表明，多粒度联合训练能显著提升通用视频理解与像素级任务性能，如 MVBench 平均准确率 67.3% 和 MeViS $J\&F$ 62.80。然而，在纯时间定位任务上，UFVideo 的 44.7 tIoU 显著低于强化学习范式，暴露了 SFT 统一架构在时序推理精度上的局限。这一局限可能源于固定长度时间 Token 对细粒度动态的丢失，以及缺乏对时序逻辑的显式优化。当视频时长增加或动态事件频率提高时，静态 Token 机制是否仍能保持时间定位精度，论文未给出回答。
