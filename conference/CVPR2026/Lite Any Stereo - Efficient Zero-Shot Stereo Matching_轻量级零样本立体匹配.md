# CVPR2026最新论文 ｜Lite Any Stereo: Efficient Zero-Shot Stereo Matching ｜轻量级零样本立体匹配

研究机构：英国帝国理工学院

作者：Junpeng Jing、Weixun Luo、Ye Mao 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.16555)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.16555)

> 立体匹配领域长期面临精度与效率的二元对立：高精度模型依赖重型视觉基础模型（VFM）先验，计算开销巨大；高效模型虽满足实时性，却因缺乏强先验导致零样本泛化能力薄弱。Lite Any Stereo 通过摒弃 VFM 依赖，转而设计混合代价聚合架构并引入三阶段数据蒸馏策略，在 33G MACs 的极低算力下实现了跨域零样本性能。该方法证明了轻量级卷积网络（CNN）在特定训练策略下可逼近重型模型的泛化上限，但其对真实无标注数据规模的依赖及在极端弱纹理场景下的表现边界，仍存疑。

## 研究背景

立体匹配的核心挑战在于从校正后的立体图像对中恢复几何一致的密集视差图，这一过程在弱纹理、重复图案及遮挡区域面临严重的匹配歧义。为解决此问题，早期方法依赖 3D 卷积处理代价体，虽能捕捉局部匹配关系，但计算复杂度随分辨率和视差范围呈立方级增长，难以满足实时部署需求。随后，RAFT-Stereo 引入 GRU 迭代优化范式，在 2D 相关场上递归更新，确立了效率与精度平衡的新基准。然而，随着视觉基础模型（VFM）的兴起，研究重心转向零样本泛化，MonSter 等工作利用单目深度先验解决跨域难题，但引入了巨大的计算开销，阻碍了边缘设备部署。

当前领域存在明显的路线分歧：精度导向方法（如 FoundationStereo）通过集成 DepthAnything 等 VFM 获得卓越的零样本性能，但 MACs 高达 12824G，远超实时阈值；效率导向方法（如 LightStereo、BANet）采用纯 2D 或轻量 3D 聚合，MACs 控制在 33-36G，但受限于局部特征匹配，在未见场景下泛化能力显著落后。这种“精度-效率”剪刀差导致高效模型长期被视为缺乏零样本能力，迫使实际应用依赖域特定微调。Lite Any Stereo 的切入点在于打破这一认知，证明通过架构创新与大规模数据蒸馏，轻量级模型无需 VFM 先验即可实现强零样本泛化。

## 核心方法

### 前馈式混合代价聚合架构

Lite Any Stereo 采用前馈网络结构，包含特征提取、相关体构建、代价聚合与视差估计四个阶段。与迭代优化方法不同，该架构放弃递归更新以换取极低延迟，核心创新在于混合代价聚合模块。传统高效方法多采用纯 2D 卷积（将视差折叠为通道）或纯 3D 卷积，前者缺乏视差维度连续性，后者计算昂贵。本文提出 3D-2D 串行混合结构，其中 3D 块 $\mathbf{G}_{3D}(\cdot)$ 联合聚合视差与空间维度以捕捉跨视差结构，2D 块 $\mathbf{G}_{2D}(\cdot)$ 提供高效空间细化。

$$
\mathbf{C}_{agg} = \mathbf{G}_{2D}(\mathbf{G}_{3D}(\mathbf{C}))
$$

该公式表明，先通过 3D 卷积建立视差维度的几何感知，再通过 2D 卷积进行空间平滑。设计动机在于解决纯 2D 聚合在弱纹理区域因缺乏视差连续性而导致的匹配歧义，同时避免纯 3D 聚合带来的内存爆炸。消融实验显示，3D 块比例仅需 4.8% 即可达到最佳性能，更高比例反而因计算预算挤占导致精度下降。

### 三阶段数据蒸馏训练策略

为弥补轻量骨干缺乏 VFM 先验的缺陷，本文提出三阶段训练策略。Stage ① 在 1.8M 合成数据上进行标准监督学习；Stage ② 引入自蒸馏，教师模型接收干净输入，学生模型接收扰动输入，通过特征对齐损失 $\mathcal{L}_{feat}$ 学习域不变表示；Stage ③ 利用 0.5M 真实无标注数据，由冻结的高精度模型生成伪标签进行知识蒸馏。

$$
\mathcal{L}_{total} = \mathcal{L}_{disp} + \lambda \mathcal{L}_{feat}, \quad \mathcal{L}_{feat} = \sum_{i} \| \mathbf{F}_i - \mathbf{F}'_i \|^2
$$

其中 $\mathbf{F}_i$ 和 $\mathbf{F}'_i$ 分别为教师与学生特征向量。这一策略的核心在于利用真实数据的分布特性弥补合成数据的域差距，替代 VFM 提供的结构先验。实验表明，固定教师权重比 EMA 更新更有效，且该策略对 LightStereo 和 BANet 等基线模型均具有普适性提升效果。

## 实验评估

实验在 KITTI 2012/2015、ETH3D、Middlebury 及 DrivingStereo 上进行零样本评估。基线覆盖高效方法（LightStereo, BANet, StereoAnything）与精度导向方法（FoundationStereo, Selective-IGEV）。在百万级数据训练设置下，Lite Any Stereo 在 KITTI 2012 D1 误差为 3.04%，KITTI 2015 D1 为 3.87%，ETH3D Bad 1.0 为 3.53%，Middlebury Bad 2.0 为 7.51%。

| 方法 | KITTI 2012 D1 | KITTI 2015 D1 | ETH3D Bad 1.0 | Middlebury Bad 2.0 | MACs (G) |
|---|---|---|---|---|---|
| LightStereo-M* | 4.10 | 4.97 | 5.33 | 10.85 | 33 |
| BANet-2D* | 3.90 | 4.71 | 5.92 | 10.05 | 36 |
| StereoAnything-L† | 4.00 | 4.81 | 3.81 | 9.82 | 84 |
| **Lite Any Stereo** | **3.04** | **3.87** | **3.53** | **7.51** | **33** |
| FoundationStereo | 2.51 | 2.83 | 0.49 | 1.12 | 12824 |

Lite Any Stereo 在高效模型中全面领先，且 MACs 仅为 FoundationStereo 的 0.26%。消融实验显示，混合聚合中 3D-2D 串行结构优于双边或交错结构；3D 核大小 (3,3,3) 优于更大核；自蒸馏优于数据增强。在 DrivingStereo 恶劣天气子集上，Lite Any Stereo 整体 D1 为 8.74%，优于教师模型 FoundationStereo 的 10.71%，表明蒸馏策略有效增强了鲁棒性。

评估边界方面，论文未报告 FPS 或内存占用峰值，仅提供 MACs 与推理时间（A100 上 4ms）。代码已开源，但真实数据蒸馏依赖高精度教师模型，限制了在无强先验场景下的独立部署能力。

## 关联研究分析

从方法设计看，Lite Any Stereo 与 FoundationStereo 形成鲜明对比。FoundationStereo 依赖 DepthAnything VFM 提供全局结构先验，而 Lite Any Stereo 拒绝 VFM，转而通过混合代价聚合捕捉局部几何连续性，并通过真实数据蒸馏弥补全局先验缺失。这一差异源于对“零样本能力来源”的不同假设：前者认为 VFM 先验是跨域泛化的关键，后者认为大规模真实数据分布学习足以替代。然而，Lite Any Stereo 在 ETH3D Bad 1.0 上为 3.53%，仍显著高于 FoundationStereo 的 0.49%，暗示在无 VFM 辅助下，极端弱纹理区域的匹配歧义仍未完全解决。

从训练策略看，Lite Any Stereo 的三阶段蒸馏与 StereoAnything 的伪标签生成策略有相似之处，但后者依赖单目深度模型生成 30M 伪标签，而前者仅使用 0.5M 真实无标注数据。Lite Any Stereo 证明数据质量（真实分布）比数据数量（合成伪标签）对零样本泛化更关键。然而，其 Stage ③ 依赖冻结的高精度教师模型，若教师模型本身存在域偏差，学生模型可能继承该偏差，这一风险在论文中未充分讨论。

## 总结

Lite Any Stereo 旨在解决高效立体匹配模型零样本泛化能力不足的核心矛盾。其切入点在于证明轻量级 CNN 无需 VFM 先验，通过混合代价聚合架构与三阶段数据蒸馏即可实现强泛化。该方法在 33G MACs 下实现了 KITTI 2012 D1 3.04% 与 ETH3D Bad 1.0 3.53% 的性能，显著优于同类高效模型。然而，其性能仍低于重型 VFM 方法，且在极端弱纹理场景下存在精度上限。当真实无标注数据规模进一步缩小，或教师模型质量下降时，该蒸馏策略的鲁棒性是否仍能维持，论文未给出回答。
