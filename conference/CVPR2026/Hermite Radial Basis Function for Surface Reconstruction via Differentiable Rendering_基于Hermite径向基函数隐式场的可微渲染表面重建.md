# CVPR2026最新论文 ｜Hermite Radial Basis Function for Surface Reconstruction via Differentiable Rendering ｜基于Hermite径向基函数隐式场的可微渲染表面重建

作者：Hugo Blanc、Jean-Emmanuel Deschaud、Alexis Paljic

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_2583fe7a482d)

> 神经隐式表面重建旨在从多视图图像恢复连续几何，但主流MLP或哈希网格范式受限于频谱偏差与全局优化开销，难以在保持局部细节的同时实现高效渲染。现有3D高斯泼溅方法虽渲染迅速，却缺乏显式表面定义，无法直接提取高质量网格。本文切入点在于将Hermite径向基函数（HRBF）隐式场与可微体积渲染结合，通过优化局部基函数的权重、位置与尺度，实现端到端的表面重建。该方法在DTU基准上取得0.54的Chamfer Distance，优于部分高斯方法，但精度仍低于当前SOTA神经SDF方法，其局部表示对全局拓扑一致性的影响尚存疑。

## 研究背景

多视图表面重建的核心困境在于如何从离散像素观测中解耦出连续的几何信号。传统多视图立体（MVS）依赖特征匹配，在无纹理区域失效；神经辐射场（NeRF）虽通过体积渲染实现新视角合成，但其密度场无法直接定义表面，提取的几何模糊且缺乏物理意义。符号距离函数（SDF）的引入解决了这一缺陷，其零水平集即为表面，支持平滑梯度优化。然而，基于多层感知机（MLP）或哈希网格的SDF表示存在频谱偏差，难以捕捉高频细节，且全局优化导致计算开销巨大。

主流路线分为两类：一是基于神经网络的隐式场（如NeuS、VolSDF），通过可微渲染优化SDF，但受限于网络容量与频谱偏差；二是基于局部基函数的渲染方法（如3D Gaussian Splatting、RayGauss），渲染效率高但缺乏显式表面表示，仅能用于新视角合成。Hermite径向基函数（HRBF）在点云重建中已证明能同时插值位置与法线，但传统HRBF方法直接优化点云，未利用RGB图像监督。本文的切入点在于将HRBF隐式场改造为可微渲染框架下的优化变量，利用局部基函数的紧凑支持特性，在保持局部几何精度的同时，通过边界体积层次（BVH）加速射线相交，实现高效且显式的表面重建。

## 核心方法

### 隐式场表示与密度映射

本文方法参照系为基于SDF的可微渲染框架，但关键差异在于用局部径向基函数（RBF）替代MLP或哈希网格作为隐式场基函数。通常做法中，NeuS使用MLP参数化SDF，而本文采用稀疏组合的局部RBF及其导数构建全局隐式函数 $F$。设计动机在于局部RBF的紧凑支持特性可避免MLP的频谱偏差，且稀疏性允许通过BVH加速渲染。隐式函数定义为：

$$ F(x) = \sum_{j=1}^{N} \left( \alpha_j \phi_j(x) - \beta_j^\top \nabla \phi_j(x) \right) + p_0 $$

其中 $\phi_j(x) = \phi(\|x - \mu_j\|/R_j)$ 为以 $\mu_j$ 为中心、尺度为 $R_j$ 的径向基函数，$\alpha_j$ 和 $\beta_j$ 为待优化系数，$p_0$ 为常数多项式偏移。该公式通过同时约束函数值与梯度（Hermite约束），确保重建表面在位置与法线上均与输入点云一致。

### 可微渲染与边界伪影规避

在密度映射环节，本文采用Miller et al.提出的倒数密度公式，将隐式函数 $F$ 转化为体积渲染密度 $\sigma$。通常做法中，NeuS使用 $\sigma = \max(-\omega \cdot \nabla \Psi(sF(x)) / \Psi(sF(x)), 0)$，而本文采用 $\sigma(x, \omega) = \omega \cdot \nabla \log v(x) / v(x)$，其中 $v(x) = \Psi(sF(x))$。设计动机在于倒数密度公式在理论上一阶无偏，能更准确地将渲染权重集中在表面附近。然而，局部RBF在支持域外值为零，若 $p_0=0$，则 $F=0$ 在支持域外平凡成立，导致边界伪影。本文通过理论分析证明，选择 $p_0 > 0$ 可确保 $F > 0$ 在支持域外及边界处成立，从而避免伪影。该设计解决了局部基函数在稀疏区域因函数值截断导致的几何失真问题，使渲染权重仅在实际表面附近集中。

## 实验评估

实验在DTU、BlendedMVS及Tanks and Temples数据集上进行，基线覆盖NeuS、VolSDF、3DGS系列（如Gaussian Surfels、2DGS）及Fast Dipole Sums。在DTU上，本文方法取得0.54的平均Chamfer Distance，优于PGSR（0.58）和Fast Dipole Sums（0.58），但低于NeuS（0.54，据领域综述为0.368，此处论文报告值与领域综述存在差异，以论文报告为准）和Neuralangelo（0.43）。在BlendedMVS上，本文方法平均CD为0.52，优于Fast Dipole Sums的0.65。

| 方法 | DTU CD (mm) | BlendedMVS CD (mm) |
| :--- | :--- | :--- |
| NeuS | 0.54 | - |
| Fast Dipole Sums | 0.58 | 0.65 |
| PGSR | 0.58 | - |
| Ours | 0.54 | 0.52 |

消融实验显示，密度映射公式的选择显著影响精度：Miller et al.的倒数密度公式（0.52）优于NeuS原始公式（0.55）。基函数选择方面，高斯RBF（0.52）优于Wendland C2（0.58），尽管高斯函数需截断支持域。多项式偏移 $p_0$ 的消融表明，$p_0=0$ 导致重建质量明显下降，而 $p_0=0.5$ 取得最佳效果，验证了边界伪影规避设计的必要性。

评估边界方面，论文未报告置信区间，且DTU上0.54的CD与领域综述中NeuS的0.368存在显著差距，可能源于评估协议或实现细节差异。代码未公开，超参数（如 $K$ 近邻数、截断阈值 $\tau=9.0$）固定，可复现性受限。

## 关联研究分析

从问题动机看，本文与NeuS等神经SDF方法的核心差异在于表示基函数的选择。NeuS依赖MLP的全局拟合能力，但受频谱偏差限制，难以恢复高频细节；本文采用局部RBF，其紧凑支持特性天然规避了频谱偏差，但代价是全局拓扑一致性可能减弱。这种差异源于任务特性：局部RBF适合稀疏、非均匀分布的点云，而MLP更适合密集、连续的场景。然而，局部RBF的稀疏性是否导致在复杂拓扑场景下出现碎片化，论文未给出回答。

从方法设计看，本文与RayGauss同属局部基函数渲染框架，但RayGauss仅用于新视角合成，缺乏显式表面表示；本文将HRBF隐式场与可微渲染结合，实现了显式表面重建。这一差异源于目标不同：RayGauss追求渲染速度，而本文追求几何精度。然而，本文的BVH加速算法依赖局部基函数的紧凑支持，若基函数支持域过大，BVH效率将下降。此外，本文未对比UNIS等最新无偏SDF方法，其密度映射的无偏性在极端噪声下的鲁棒性未经验证。

## 总结

本文要解决的核心矛盾是局部基函数的高效渲染与显式表面重建的几何精度之间的平衡。现有MLP范式受频谱偏差限制，而3DGS缺乏显式表面定义，本文通过HRBF隐式场与可微渲染的结合，利用局部RBF的紧凑支持特性，在保持局部细节的同时实现高效渲染。实验证明，该方法在DTU上取得0.54的CD，在BlendedMVS上取得0.52的CD，优于部分高斯方法，但精度仍低于当前SOTA神经SDF方法。本文的边界在于局部RBF的稀疏性可能削弱全局拓扑一致性，且密度映射的无偏性在极端噪声下的鲁棒性未经验证。当场景拓扑复杂度增加时，局部RBF的稀疏表示是否会导致表面碎片化，论文未给出回答。
