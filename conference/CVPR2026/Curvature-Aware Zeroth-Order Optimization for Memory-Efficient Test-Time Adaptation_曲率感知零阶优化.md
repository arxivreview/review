# CVPR2026最新论文 ｜Curvature-Aware Zeroth-Order Optimization for Memory-Efficient Test-Time Adaptation ｜曲率感知零阶优化

研究机构：上海交通大学

作者：Junming Zhang、Shuyu Yin、Peilin Liu 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2608.12279)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.12279)

> 测试时适应（Test-Time Adaptation, TTA）旨在利用无标签测试数据在线修正模型以应对分布偏移，但主流基于反向传播（Backpropagation, BP）的方法因需存储计算图而内存开销巨大，难以部署于边缘设备。现有无梯度方法如零阶优化（Zeroth-Order, ZO）虽免除了反向传播，却因随机扰动导致的高方差而收敛缓慢、精度受限。本文发现TTA过程中损失函数的Hessian矩阵具有显著且缓慢变化的低秩结构，据此提出CAZO方法，通过滑动平均对角Hessian估计构建各向异性扰动分布以缩减梯度估计方差。该方法在保持极低内存占用的同时实现了SOTA精度，但其对角近似是否足以捕捉非对角耦合效应，以及在更复杂动态偏移下的稳定性，仍存疑。

## 研究背景

当预训练模型部署于真实环境时，测试数据分布与训练分布的差异导致性能衰退，这一现象称为分布偏移。为在线修正模型，TTA范式仅利用无标签测试批次更新参数。然而，主流TTA方法依赖BP计算梯度，需存储中间激活值与计算图，内存消耗高达数GB，这在资源受限的边缘设备上不可行。

无梯度方法如ZO优化通过前向传播的函数值差异近似梯度，避免了BP的内存瓶颈。然而，标准ZO使用各向同性随机扰动，在高维参数空间中梯度估计方差极大，导致收敛速度比一阶方法慢 $O(d)$ 倍（$d$为参数维度），实际适应精度远低于BP方法。现有无梯度TTA工作如FOA采用进化策略优化提示词，ZOA针对量化模型引入域知识管理，但均未从优化几何结构角度解决ZO的高方差本质问题。

本文切入点在于揭示TTA适应过程中损失景观的几何特性：Hessian矩阵并非随机噪声，而是存在主导的低维子空间。这一观察为设计方差缩减的ZO采样策略提供了理论依据，使得无梯度方法能在内存受限条件下逼近甚至超越BP方法的适应精度。

## 核心方法

### 方法参照系

标准ZO优化通过随机方向扰动参数并比较损失差来估计梯度，其核心局限在于扰动分布与损失曲率无关，导致采样效率低下。本文问题与该通用流程的关键差异在于：TTA适应过程中的Hessian具有稳定的低秩结构，可利用此结构重塑扰动分布。

### Hessian低秩结构分析

设计动机：标准ZO的随机扰动在平坦方向上浪费计算资源，而在高曲率方向上采样不足，导致梯度估计方差大。本文首先通过实证分析揭示Hessian的结构特性。在ViT-B/16模型于ImageNet-C高斯腐蚀（严重度5）上的适应过程中，计算不同步数的经验Hessian特征值谱。结果显示，前20个特征值占总方差的96%以上，有效秩仅占参数维度的0.22%。进一步计算相邻步Hessian主曲率子空间的投影比 $\rho_t^{(r)}$，发现其在不同秩 $r \in \{5, 10, 15, 20\}$ 下均稳定在0.9左右。这表明主曲率子空间在适应过程中缓慢变化，支持使用指数移动平均（EMA）进行在线估计。

### 曲率感知零阶优化

设计动机：利用Hessian的低秩与慢变特性，将各向同性扰动替换为各向异性扰动，以缩减梯度估计方差。CAZO的核心是构建预条件高斯分布 $\mathcal{N}(0, \tilde{H}_t^{-1})$ 作为扰动源，其中 $\tilde{H}_t$ 为对角Hessian近似。由于完整Hessian计算不可行，CAZO采用对角近似 $\Sigma = \tilde{H}^{-1} = \text{diag}(\sigma_1^2, \dots, \sigma_d^2)$，并通过滑动EMA更新对角元素：

$$ D_t = (1-\nu)D_{t-1} + \nu \hat{g}^2(\theta_{t-1}), \quad \tilde{H}_t = \text{diag}\left(\frac{D_t}{1-(1-\nu)^t}\right) $$

该公式通过累积平方梯度估计来追踪局部曲率，$\nu$ 为EMA系数。基于此，CAZO的梯度估计器为：

$$ \hat{g}(\theta_t) = \frac{1}{k}\sum_{i=1}^k \frac{\mathcal{L}(\theta_t + \epsilon u_i) - \mathcal{L}(\theta_t - \epsilon u_i)}{2\epsilon} u_i, \quad u_i \sim \mathcal{N}(0, \tilde{H}_t^{-1}) $$

此设计在高曲率方向上缩小扰动幅度，在低曲率方向上放大扰动，从而获得更精确的梯度方向。理论分析表明，在L-光滑性假设下，CAZO收敛率为 $O(1/\sqrt{T})$，且收敛常数显式依赖于曲率界 $\beta_l, \beta_u$，当曲率代理良态时，常数因子小于各向同性ZO。

## 实验评估

| 方法 | BP | ImageNet-C Avg (%) | Memory (MB) | Time (s) |
|---|---|---|---|---|
| NoAdapt | × | 55.5 | 1,543 | - |
| FOA (p=28) | × | 65.8 | 1,553 | 2,885 |
| ZOA | × | 67.5 | 1,660 | - |
| TENT | ✓ | 59.8 | 6,404 | - |
| CoTTA | ✓ | 61.9 | 17,773 | - |
| EATA | ✓ | 66.8 | 6,696 | - |
| CAZO (k=20) | × | 69.0 | 1,695 | 3,127 |

实验在ImageNet-C（严重度5）及ImageNet-R/V2/Sketch上进行，使用ViT-B/16。基线覆盖BP-free（LAME, T3A, FOA, ZOA）与BP-based（TENT, CoTTA, SAR, DeYO, EATA, RoTTA）两类。CAZO在ImageNet-C重置协议下平均准确率69.0%，较最强BP-free基线ZOA（67.5%）提升1.5%，较最强BP基线EATA（66.8%）提升2.2%。在持续适应（CTTA）设置下，CAZO平均准确率65.3%，较LCoTTA（62.3%）提升3.0%。内存方面，CAZO仅需1,695 MB，较TENT（6,404 MB）降低约73%，与FOA（1,553 MB）相当。

消融实验显示，扰动数量 $k$ 从2增至6时，准确率从59.3%升至62.1%，ECE显著下降；$k>6$ 后收益边际递减。EMA系数 $\nu=0.8$ 时性能最佳（69.0%），$\nu=1.0$ 导致不稳定。在8-bit量化下，CAZO保持67.8%准确率，优于其他方法；6-bit下仍达61.2%。

评估边界：实验仅使用ViT-B/16，未验证CNN骨干；未报告置信区间，数值比较需谨慎；未覆盖开放集或对抗鲁棒性场景。代码已开源，超参数与GPU配置（NVIDIA H20）在补充材料中提供。

## 关联研究分析

从方法设计看，CAZO与FOA同属前向优化路线，但FOA采用CMA-ES进化策略优化提示词，依赖种群搜索，计算复杂度随种群规模线性增长；CAZO采用曲率感知ZO，通过单点扰动估计梯度，计算复杂度仅与扰动数 $k$ 相关。CAZO在相同内存预算下精度更高（69.0% vs 65.8%），根源在于CAZO利用了损失景观的几何结构，而FOA依赖黑盒搜索。ZOA同为ZO方法，但侧重量化模型与域知识管理，CAZO侧重曲率方差缩减，二者在问题焦点上互补。

从问题动机看，CAZO与TENT等BP方法解决同一分布偏移问题，但TENT依赖BN层更新与熵最小化，需反向传播；CAZO冻结主干，仅更新轻量适配器，通过前向传播实现适应。CAZO在精度上超越TENT（69.0% vs 59.8%），证明无梯度方法在特定几何条件下可超越BP方法。然而，CAZO的对角Hessian近似忽略了非对角耦合效应，当损失景观存在强非对角相关性时，其方差缩减效果可能受限，论文未对此进行量化分析。

## 总结

本文要解决的核心矛盾是TTA中无梯度方法的内存效率与适应精度之间的权衡。现有ZO方法因随机扰动的高方差导致精度不足，而BP方法内存开销过大。本文抓住Hessian低秩且慢变的几何特性，通过滑动平均对角Hessian估计构建各向异性扰动分布，实现方差缩减。实验证明CAZO在ImageNet-C上达到69.0%准确率，内存占用1,695 MB，较BP方法降低73%。其边界在于对角近似可能忽略非对角耦合，且仅在ViT-B/16上验证。当损失景观存在强非对角相关性时，对角Hessian估计的方差缩减效果是否依然显著，论文未给出回答。
