# CVPR2026最新论文 ｜Foundation Encoders Are All You Need for Preference-Aware Personalization ｜基于基础编码器重构的偏好感知个性化生成

作者：Hyungjin Kim、Seokho Ahn、Young-Duk Seo

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_69c2ebf83749)

> 个性化图像生成旨在让模型输出符合用户特定审美，而非仅响应通用文本提示。现有方法或依赖大语言模型重写提示词，或需训练额外适配器，导致计算成本高且泛化性差。FAN 通过重构预训练文本编码器的自注意力机制，在零训练、零额外参数的前提下实现偏好注入。该方法在多个基础模型上验证了有效性，但其对目标查询保真度的影响及跨域泛化能力仍需进一步审视。

## 研究背景

当用户输入简短模糊的提示词时，扩散模型生成的图像往往缺乏个性化特征，这是因为文本编码器（Text Encoder）的令牌容量有限，无法承载复杂的用户偏好信息。为弥补这一缺陷，研究界引入了用户行为数据，试图从历史交互中挖掘隐式偏好。然而，将这种稀疏且主观的偏好信号注入扩散模型的条件空间，面临着偏好提取不准与模型结构耦合两大难题。

用户行为驱动的个性化生成主要面临三个瓶颈：一是画像构建往往忽略目标查询与偏好的相关性，导致注入的偏好与当前生成任务脱节；二是偏好集成通常依赖额外的适配器或大语言模型，增加了计算开销并限制了跨模型迁移能力；三是现有方法多针对特定扩散模型架构设计，缺乏通用性。FAN 的切入点在于摒弃外部辅助结构，直接重构基础编码器内部的注意力机制，将偏好融合过程内化于条件生成路径中，从而在保持模型通用性的同时实现高效个性化。

## 核心方法

### 条件级个性化参照系

条件级个性化旨在潜在空间中整合多个条件以引导生成。标准流程通常通过交叉注意力将参考特征注入扩散模型，或训练适配器将用户嵌入映射到条件空间。FAN 的关键差异在于不修改扩散模型权重，也不引入额外适配器，而是直接重构文本编码器（如 OpenCLIP、T5）的自注意力模块，使偏好信息在编码阶段即融入条件向量。

### 定制化画像构建

传统画像方法多基于相似度检索，易陷入局部最优且忽略多样性。FAN 采用定制化画像（Tailored Profiling），结合最大边际相关性（MMR）原则与 k-center 贪心算法，从历史实体中选取既与目标查询语义相关又具备结构多样性的参考集。该过程首先计算目标 $T$ 与参考 $R_i$ 的加权余弦相似度 $S = \{W_i \odot \cos(T, R_i)\}$，选取 Top-k 候选；随后通过贪心策略最大化参考集内部的距离，确保覆盖用户偏好的不同维度。这一设计解决了单一相似度检索导致的偏好同质化问题，使模型能捕捉更丰富的审美特征。

### 个性化注意力机制

在编码器内部，FAN 引入个性化注意力（Personalized Attention, PA）模块重构自注意力计算。PA 将目标查询与参考查询通过交叉注意力分数融合，形成个性化表示 $H$。其核心公式为：

$$ H = (1-\alpha) \text{Attn}(Q, T)V_T + \alpha \sum_{i \in \mathcal{I}} W_i \text{Attn}(Q, R_i)V_{R_i} $$

其中 $\alpha$ 为个性化程度，$W_i$ 为偏好强度。该公式通过加权融合目标与参考的注意力输出，在保留目标语义的同时注入偏好特征。PA 仅在特定层应用，以避免过度个性化导致的目标表达退化。此外，针对 OpenCLIP 中 Class Token 位置动态变化的问题，FAN 使用一个两层感知机作为分类器，稳定检测 Class Token 位置，确保条件生成的准确性。

## 实验评估

实验在 PIP（3,115 用户）和 ML（610 用户）数据集上进行，基线包括 FABRIC、TV、PMG 和 DrUM。FAN 在 Stable Diffusion V1 的 PIP 数据集上取得 25.47 的 CLIP Score，优于 DrUM 的 25.13 和 TV 的 22.62。在 ML 数据集上，FAN 的 CLIP Score 为 30.69，高于 DrUM 的 29.49。

| 模型 | 数据集 | 方法 | CLIP Score (Target) | CLIP Score (History) |
| :--- | :--- | :--- | :--- | :--- |
| SD V1 | PIP | DrUM | 25.13 | 16.03 |
| SD V1 | PIP | FAN | 25.47 | 15.24 |
| SD V1 | ML | DrUM | 29.49 | 13.07 |
| SD V1 | ML | FAN | 30.69 | 12.83 |

消融实验显示，移除定制化画像（w/o Profile）对性能影响较小，但移除目标查询（w/o Target query）导致 PIP 数据集上 Target 分数从 25.47 降至 22.23，表明目标保真度对个性化质量至关重要。PA 跳过机制（w/o PA skip）的移除导致性能轻微下降，验证了选择性应用 PA 的必要性。

评估指标主要依赖 CLIP Score 和 Text Align，缺乏对美学质量或人类偏好的直接评估。代码已开源，但超参数 $\alpha$ 需针对不同数据集手动调整（PIP 为 0.4，ML 为 0.3），限制了自动化部署的便利性。

## 关联研究分析

从方法设计看，FAN 与 DrUM 同属条件级个性化路线，但 DrUM 依赖随编码器规模增长的适配器，而 FAN 通过重构自注意力消除了这一依赖。这一差异源于 FAN 将偏好融合前置到编码阶段，而非在潜在空间中通过外部模块实现。然而，FAN 对目标查询的依赖较强，当目标提示词过于模糊时，个性化效果可能受限，这在 DrUM 的对比实验中未充分暴露。

从问题动机看，FAN 与 IP-Adapter 均追求免微调个性化，但 IP-Adapter 注入的是图像特征，而 FAN 注入的是行为偏好。IP-Adapter 适用于主体身份保持，而 FAN 侧重于风格与审美偏好。两者在注意力机制上的差异反映了任务特性的不同：主体保持需要高保真的特征匹配，而偏好对齐需要语义层面的风格迁移。FAN 在 CLIP 检索和 unCLIP 等任务上的扩展性验证了其通用性，但在复杂多主体场景下的表现尚未测试。

## 总结

FAN 解决了用户偏好稀疏且主观导致的生成质量波动问题，通过重构基础编码器自注意力实现零训练个性化。其在 SD V1 PIP 数据集上以 25.47 的 CLIP Score 超越 DrUM，证明了编码器内重构的有效性。然而，FAN 依赖历史行为数据，且 $\alpha$ 参数需手动调整，限制了其在零样本或动态偏好场景下的应用。当用户历史数据极度稀疏或偏好发生剧烈变化时，定制化画像的多样性选取策略是否仍能维持稳定的个性化效果，论文未给出回答。
