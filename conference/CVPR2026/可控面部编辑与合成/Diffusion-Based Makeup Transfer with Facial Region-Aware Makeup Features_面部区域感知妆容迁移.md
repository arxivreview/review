# CVPR2026最新论文 ｜Diffusion-Based Makeup Transfer with Facial Region-Aware Makeup Features ｜面部区域感知妆容迁移

研究机构：英国伦敦玛丽女王大学

作者：Zheng Gao、Debin Meng、Yunqi Miao 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.20012)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.20012)

> 导读 扩散模型在妆容迁移中常因通用特征编码器无法捕捉细粒度妆容风格，且整体特征注入导致区域控制缺失，难以实现眼、唇等局部区域的独立风格迁移。现有方法要么依赖未微调的 CLIP 导致风格捕捉不足，要么将参考图特征作为整体注入去噪模型，忽略了面部区域特异性。本文提出 FRAM，通过微调专用妆容 CLIP 编码器并引入可学习查询令牌提取区域感知特征，结合 ControlNet Union 注入身份与 3D 结构信息，实现区域特定妆容迁移。该方法在 CPM-real 数据集上取得了 0.528 的 CSD 分数与 0.429 的 ID 分数，但在身份保持上仍低于部分非扩散基线，其区域控制机制对面部解析掩码准确性的依赖尚存疑。

## 研究背景

妆容迁移的核心困境在于通用视觉基础模型（如 CLIP）在自然图像上预训练，其特征空间对面部妆容风格的区分度不足，且缺乏面部解剖结构先验。当这些通用特征被直接注入扩散去噪模型时，模型无法区分“眼部妆容”与“唇部妆容”的语义边界，导致参考图的妆容风格被整体复制，无法实现如“仅迁移眼妆”或“混合不同参考图的眼妆与唇妆”等细粒度控制。此外，扩散模型在去噪过程中易丢失源图像的身份特征，需引入强约束机制以平衡风格迁移与身份保持。

现有扩散妆容迁移方法主要面临两个瓶颈：一是特征编码器的领域适应性不足，直接使用 off-the-shelf CLIP 难以捕捉妆容特有的纹理与色彩风格；二是条件注入方式过于粗放，将参考图特征作为整体向量注入，忽略了面部区域（如皮肤、眼睛、鼻子、嘴巴）的局部语义差异。FRAM 的切入点在于将“妆容风格编码”与“区域感知提取”解耦：首先通过合成数据微调 CLIP 使其具备妆容风格判别能力，再利用可学习查询令牌从该编码器中提取与特定面部区域绑定的特征，从而在扩散去噪过程中实现区域特定的风格控制。

## 核心方法

### 方法参照系

标准扩散妆容迁移流程通常包含身份注入与风格注入两个环节：身份注入多采用 ControlNet 编码源图像素级信息，风格注入则依赖预训练编码器（如 CLIP）提取参考图特征并通过交叉注意力注入去噪模型。FRAM 的关键差异在于将风格注入从“整体特征向量”改为“区域感知特征集合”，并前置了一个专用的妆容 CLIP 微调阶段。

### 妆容 CLIP 微调与区域特征提取

设计动机：通用 CLIP 在自然图像上训练，对面部妆容风格的区分度低，且无法提供区域级语义。FRAM 首先利用 GPT-o3 生成 50 种妆容风格描述，并驱动 FLUX.1-Kontext-dev 在 FFHQ 数据集上合成带妆容图像，构建带文本标注的妆容数据集。随后，通过自监督对比学习（SSL）与图文对比学习（ITCL）微调 CLIP 视觉编码器 $E_{mu}$。SSL 通过 TPS、裁剪、翻转等增强生成同一图像的两个视图，最大化其嵌入相似度，迫使编码器忽略面部结构变化而保留妆容风格；ITCL 则将图像嵌入与妆容文本描述嵌入对齐，引入文本监督以增强风格语义。

$$ \mathcal{L}_{ssl} = -\frac{1}{|I|} \sum_{(i,v) \in I} \log \frac{\exp(fs(z_{i,v}, z_{i,v'}) / \tau)}{\sum_{(j,v') \in I(i,v) \neq} \exp(fs(z_{i,v}, z_{j,v'}) / \tau)} $$

该公式通过 InfoNCE 损失最大化同一图像不同增强视图的嵌入相似度，同时最小化与其他图像嵌入的相似度，从而学习内容不变、风格敏感的妆容表示。在区域特征提取阶段，FRAM 引入 $N=4$ 个可学习查询令牌 $q_n$（对应皮肤、眼、鼻、嘴），将其作为查询输入 $E_{mu}$，输出面部区域妆容嵌入 $\{f_n\}_{n=1}^N$。这些嵌入作为图像提示通过交叉注意力注入去噪模型。为监督查询令牌学习正确的区域对应关系，FRAM 引入注意力损失，将交叉注意力图与 FaRL 面部解析模型生成的参考图区域掩码对齐，使模型在推理时无需显式掩码即可实现区域特定妆容应用。

### 身份与 3D 结构联合注入

设计动机：单一像素级 ControlNet 在保持身份的同时难以约束面部几何结构，导致极端姿态或表情下结构失真。FRAM 采用 ControlNet Union 架构，同时编码源图像的像素级身份信息 $x_s$ 与 3D 网格结构信息 $x_m$。与 Stable-Makeup 使用两个独立 ControlNet 不同，ControlNet Union 在单一网络中融合两种模态，既保留了像素级外观细节，又引入了 3D 几何先验以约束面部结构合理性。该设计通过联合优化身份保持与结构一致性，缓解了扩散去噪过程中因缺乏几何约束导致的身份漂移与结构扭曲。

## 实验评估

实验在 MT、Wild-MT 和 CPM-real 三个数据集上进行，对比 GAN 基线 CSD-MT 与扩散基线 MAD、Gorgeous、SHMT、Stable-Makeup。FRAM 在 CPM-real 上取得 0.528 的 CSD 分数（风格相似度）与 0.429 的 ID 分数（身份保持），CSD 高于 Stable-Makeup 的 0.515，但 ID 低于 Gorgeous 的 0.624。这表明 FRAM 在风格捕捉上优于现有扩散方法，但身份保持能力仍弱于部分非扩散或轻量级扩散方法，可能源于区域特征注入对全局身份特征的干扰。

| 方法 | CSD↑ (CPM-real) | ID↑ (CPM-real) | SSIM↑ (CPM-real) | Aes↑ (CPM-real) |
| :--- | :--- | :--- | :--- | :--- |
| CSD-MT | 0.418 | 0.522 | 0.410 | 4.41 |
| MAD | 0.317 | 0.491 | 0.788 | 4.18 |
| Gorgeous | 0.399 | 0.624 | 0.871 | 4.61 |
| SHMT | 0.417 | 0.408 | 0.793 | 4.64 |
| Stable-M | 0.515 | 0.415 | 0.777 | 4.87 |
| FRAM | 0.528 | 0.429 | 0.797 | 4.95 |

消融实验显示，CLIP 微调目标中，同时使用 SSL 与 ITCL 的 KNN 分类准确率达 88.2%，显著高于仅用 SSL 的 80.3% 或仅用 ITCL 的 86.9%，证明图文对比学习对妆容风格语义的增强作用。在身份注入模块中，仅使用 3D 网格引导（无像素级信息）时 ID 分数骤降至 0.048，而同时使用像素与 3D 信息时 ID 为 0.429，表明像素级信息对身份保持至关重要，3D 网格主要贡献于结构一致性（SSIM 从 0.333 提升至 0.797）。注意力损失的引入使 CSD 从 0.518 提升至 0.528，验证了区域对齐监督对风格迁移精度的贡献。

评估指标涵盖风格相似度（CSD）、身份保持（ID）、结构相似度（SSIM）、非编辑区域差异（L2-M）与美学分数（Aes），但缺乏对区域控制精度的直接量化指标（如区域级 CSD）。代码已开源，但论文未报告训练超参数细节与 GPU 资源需求，可复现性依赖于补充材料。

## 关联研究分析

从问题动机看，FRAM 与 Stable-Makeup 均基于扩散模型解决妆容迁移，但 Stable-Makeup 使用 off-the-shelf CLIP 整体注入特征，而 FRAM 通过微调专用 CLIP 并引入区域查询令牌，解决了通用编码器风格捕捉不足与整体注入区域控制缺失的问题。这一差异源于任务对细粒度区域控制的需求，Stable-Makeup 未探索区域级语义解耦，而 FRAM 通过注意力损失将区域掩码监督内化到特征提取过程中，实现了推理时的无掩码区域控制。

从方法设计看，FRAM 与 SCGAN 均支持区域特定妆容迁移，但 SCGAN 基于 GAN 在图像级提取区域特征，而 FRAM 基于扩散模型在特征级通过交叉注意力注入区域嵌入。FRAM 的扩散架构在生成质量（Aes 4.95 vs. CSD-MT 4.41）上优于 GAN 基线，但身份保持（ID 0.429 vs. Gorgeous 0.624）仍落后于部分非扩散方法，这可能源于扩散去噪过程的多步误差累积与区域特征注入对全局身份特征的干扰。FRAM 未探索如何在不牺牲身份保持的前提下进一步提升区域控制精度，其区域控制机制对 FaRL 掩码准确性的依赖也未在极端姿态或低质量输入下得到验证。

## 总结

FRAM 旨在解决扩散模型妆容迁移中通用编码器风格捕捉不足与整体特征注入导致区域控制缺失的矛盾。通过微调专用妆容 CLIP 编码器并引入可学习查询令牌提取区域感知特征，结合 ControlNet Union 注入身份与 3D 结构信息，FRAM 实现了区域特定妆容迁移。在 CPM-real 数据集上，FRAM 取得 0.528 的 CSD 分数与 0.429 的 ID 分数，风格捕捉优于 Stable-Makeup，但身份保持低于 Gorgeous。其边界在于区域控制机制依赖 FaRL 掩码的准确性，且身份保持分数仍低于部分非扩散基线，表明区域特征注入与全局身份保持之间存在权衡。当输入图像包含极端姿态或低质量面部解析时，区域查询令牌能否准确对齐面部区域，论文未给出回答。
