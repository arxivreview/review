# CVPR2026最新论文 ｜Towards Human-Like Robot Handwriting via Contour-Aware Generation ｜轮廓感知手写轨迹重建

研究机构：华南理工大学、新加坡国立大学

作者：Yutao Qin、Gang Dai、Yifan Zhang 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_00cf6ddc41e4)

> 手写机器人书写面临的核心矛盾是：现有在线生成方法能恢复笔画顺序与轨迹，却丢失了笔画宽度的动态变化，导致输出僵硬如印刷体。本文提出轮廓感知手写轨迹重建任务，将笔画宽度作为显式建模对象，并构建首个大规模轮廓标注数据集CHTR-110K。方法采用多尺度图神经网络同时编码拓扑结构与局部轮廓细节，自回归生成包含坐标、宽度与笔状态的完整轨迹序列。该工作填补了静态图像到动态高保真轨迹的空白，但其在公开基准上的对比基线覆盖度与跨脚本泛化能力仍存疑。

## 研究背景

手写机器人控制依赖精确的动态轨迹信息，包括笔画顺序、路径关键点及笔尖压力或宽度变化。传统离线生成方法将字符视为静态图像，虽能捕捉整体结构，但无法提供时序动态信息；而在线生成方法虽引入动态轨迹，却普遍忽略笔画轮廓（contour）的建模，即笔画宽度随路径变化的细节。这种缺失使得机器人只能使用固定笔宽，生成的字迹缺乏书法美感，视觉上接近标准印刷体而非自然手写。

手写轨迹重建旨在从静态图像恢复动态序列，早期方法依赖启发式规则，难以泛化至多笔画复杂字符。深度学习时代，TRACE结合CRNN与动态时间规整（DTW）处理文本行，PEN-Net引入双路径解析编码器，TrajFormer利用Transformer建模长程依赖。然而，这些方法均基于像素级图像编码器，仅关注相邻像素的局部关系，忽略了字符固有的拓扑结构，且未显式建模笔画轮廓。本文切入点在于：现有数据集缺乏同时包含轨迹点、笔画顺序与轮廓的标注，现有方法无法联合恢复整体结构与精细轮廓，导致重建结果失真。

## 核心方法

### 方法参照系

手写轨迹重建的标准流程是从静态图像提取视觉特征，通过序列模型生成轨迹点序列。本文问题与该通用流程的关键差异在于：输入仅为单张字符图像，输出需同时包含轨迹坐标、笔画顺序及每一点的笔画宽度，且需保持字符拓扑结构完整。

### 轮廓感知字符图构建

设计动机在于解决像素级编码器忽略字符拓扑结构的问题。通常做法是将图像划分为网格或提取局部特征，本文改为构建显式图结构。给定字符图像 $I$，首先通过基于UNet的检测器 $F_{stroke}$ 提取笔画区域、类型与顺序：

$$ \{S_i, t_i, o_i\}_{i=1}^M = F_{stroke}(I) $$

其中 $S_i$ 为第 $i$ 个笔画的前景区域，$t_i$ 为笔画类型，$o_i$ 为笔画顺序。随后，轨迹提取器 $F_{traj}$ 从每个笔画区域 $S_i$ 生成轮廓感知轨迹序列 $P_i$：

$$ P_i = F_{traj}(S_i) $$

每个轨迹点 $p = (x, y, w, s_1, s_2, s_3)$ 包含2D坐标 $(x, y)$、笔画宽度 $w$ 及三个互斥的笔状态（下笔、抬笔、结束）。这种图结构将轨迹关键点作为节点，拓扑连接作为边，显式编码了字符的结构关系，克服了像素级方法对全局拓扑的忽视。

### 多尺度图学习策略

设计动机在于解决单一尺度特征无法同时捕捉全局结构与局部细节的问题。通常做法是使用单一分辨率的特征图，本文引入多尺度图学习。不同图块（graph blocks）派生出多尺度图，从细粒度细节（如笔画曲率、连接处）到粗粒度结构（如整体字形）逐层学习。这些多尺度特征被送入多尺度聚合解码器，自回归生成轨迹序列。该策略确保模型既能恢复字符的整体骨架，又能保留笔画宽度的细微变化，从而生成视觉上逼真的人类手写轨迹。

## 实验评估

实验在自建CHTR-110K数据集与公开CASIA-OLHWDB数据集上进行。CHTR-110K包含110,540个样本，涵盖1,080种书法风格与9,837个字符类别，其中88,169个用于训练，22,371个用于测试。基线方法包括TRACE、PEN-Net、FINet及TrajFormer，但缺乏与最新GAN或扩散模型类图像生成方法的直接对比，也未包含针对轮廓建模的专用基线。

| 数据集 | 方法 | FID | DTW |
| :--- | :--- | :--- | :--- |
| CASIA-OLHWDB | G-HTR (Ours) | 1.228 | - |
| CASIA-OLHWDB | DED-Net | 1.475 | - |
| SCUT-COUCH2009 | DNA | - | 12.765 |
| SCUT-COUCH2009 | TrajFormer | - | 18.277 |

注：表中数值逐字取自输入材料。G-HTR在CASIA-OLHWDB上的FID为1.228，低于DED-Net的1.475，表明其在图像逼真度上具有优势。DNA在SCUT-COUCH2009上的DTW为12.765，优于TrajFormer的18.277，但本文未在CASIA-OLHWDB上报告DTW指标，导致跨数据集的时序对齐性能对比不完整。

消融实验未提供详细数值，但论文强调多尺度图学习对捕捉笔画细节的关键作用。设计决策上，采用图神经网络而非Transformer作为骨干，旨在显式建模拓扑关系，但论文未报告FLOPs或推理延迟，无法评估其在边缘设备上的部署效率。评估协议主要依赖FID与DTW，缺乏对笔画宽度误差的专用指标，且未报告置信区间，数值比较需谨慎。

## 关联研究分析

从问题动机看，本文与DNA双分支网络形成对比。DNA针对开放集在线手写生成，通过自适应风格与内容分支处理未见书写者，但同样忽略笔画轮廓。本文聚焦于轮廓感知，将宽度作为显式变量，解决了DNA在视觉逼真度上的不足。差异根源在于任务定义：DNA追求开放集下的风格一致性，本文追求单字符的高保真重建。

从方法设计看，本文与TrajFormer存在骨干网络差异。TrajFormer使用Transformer建模长程依赖，但基于像素级编码，忽略拓扑结构。本文采用GNN，将字符结构显式化为图，更适合捕捉笔画间的拓扑连接。然而，领域共识认为Transformer在长序列依赖建模上优于CNN-LSTM，本文未直接对比Transformer骨干，GNN在长笔画依赖上的表现是否优于Transformer，论文未给出回答。

## 总结

本文要解决的核心矛盾是静态图像到动态高保真轨迹的重建中，笔画轮廓信息的缺失。现有方法因忽略轮廓与拓扑结构，导致生成结果僵硬。本文通过构建CHTR-110K数据集与多尺度图神经网络，显式建模轮廓与结构，在CASIA-OLHWDB上取得1.228的FID，优于DED-Net的1.475。其边界在于缺乏与最新生成模型的直接对比，且未评估计算效率。当支持集增大或脚本复杂度增加时，图结构建模的泛化能力是否优于Transformer，论文未给出回答。
