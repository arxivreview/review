# CVPR2026最新论文 ｜Expert-Teacher-Student Collaborative Learning for Domain Adaptive Object Detection ｜专家-教师-学生协同学习用于域自适应目标检测

研究机构：中国科学院

作者：Yiming Cui、Liang Li、Haibing Yin 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_b7d3434214d7)

> 域自适应目标检测（Domain Adaptive Object Detection, DAOD）旨在解决检测器在源域与目标域分布偏移下的性能退化问题，其核心瓶颈在于自训练框架中伪标签的噪声与确认偏差。现有方法或依赖教师模型闭环知识导致域偏移下标签质量受限，或单纯引入视觉基础模型（Vision Foundation Models, VFM）却丢失目标域特定适应性。ETS框架通过引入VFM作为离线专家模型，与在线教师模型在标签与表示两个层面协同指导学生模型，以互补知识提升伪标签质量。该设计在三个基准上超越了基于VFM的SOTA方法，但其性能仍低于非VFM路线的最新SOTA，且专家模型的离线静态特性限制了其对动态域偏移的响应能力。

## 研究背景

当检测器部署于与训练域存在分布差异的场景时，其泛化能力急剧下降，这一现象称为域偏移。为规避目标域高昂的标注成本，DAOD利用无标签目标域数据实现迁移，其主流范式是Mean Teacher框架：教师模型通过指数移动平均（Exponential Moving Average, EMA）更新，生成伪标签指导学生模型自训练。然而，教师模型的知识闭环受限于其小规模骨干网络与源域训练偏差，在复杂域偏移下易产生噪声伪标签，导致自训练陷入局部最优。

为突破这一瓶颈，近期研究引入VFM（如DINOv2、Grounding DINO）提供外部通用知识。以DT方法为代表，其用冻结的VFM替代教师模型进行离线伪标签生成，并通过特征对齐提升泛化性。但VFM的通用知识并非针对特定目标域定制，无法捕捉如雾天遮挡等域特定属性，导致学生模型适应性受限。ETS的切入点在于识别出VFM的域不变性知识与教师模型的域特定知识具有互补性，通过协同机制融合两者优势，而非简单替换或叠加。

## 核心方法

### 方法参照系

ETS基于Mean Teacher自训练框架，但关键差异在于引入了离线训练的VFM专家模型。标准流程中教师模型独立生成伪标签，而ETS将教师角色降级为协同监督源之一，并新增表示层面的原型对齐机制，形成“标签级协同教学”与“表示级联合巩固”的双层结构。

### 专家-教师协同教学（ETCT）

ETCT模块解决单一教师模型在域偏移下伪标签定位不准与分类错误的问题。其核心是通过检测匹配融合专家与教师的预测：对一致检测，采用置信度加权融合框坐标；对不一致检测，依据置信度差异阈值 $\epsilon$ 重新分配类别；对单边检测，分别应用基础阈值 $\delta$ 与更严格阈值 $\delta'$ 进行筛选。最终协同伪标签 $Y_{col}$ 由三类检测结果并集构成，其监督损失为：

$$
\mathcal{L}_{colsup} = \mathcal{L}_{unsup}(X_t, \mathcal{B}_{col}, \mathcal{C}_{col})
$$

该公式表明学生模型从融合后的伪标签中学习，其物理含义是通过置信度加权与阈值筛选，最大化保留专家模型的通用知识（如轮廓识别）与教师模型的域特定知识（如雾天推理），从而提升伪标签的鲁棒性。

### 专家-教师联合巩固（ETJC）

ETJC模块解决学生模型在自训练中泛化性与适应性失衡的问题。其核心是构建类条件原型网络，通过置信度加权EMA更新原型，并施加三重对齐约束：学生-专家原型对齐、学生-教师原型对齐、以及学生源域-目标域原型自对齐。总损失函数为：

$$
\mathcal{L} = \lambda_1\mathcal{L}_{sup} + \lambda_2\mathcal{L}_{colsup} + \lambda_3\mathcal{L}_{E-S}^{Prot} + \lambda_4\mathcal{L}_{T-S}^{Prot} + \lambda_5\mathcal{L}_{C-D}^{Prot}
$$

该公式表明学生模型在源域监督、协同伪标签监督及三重原型对齐的共同约束下优化，其物理含义是通过原型空间的几何对齐，强制学生模型继承专家的域不变特征与教师的域适应特征，同时保持跨域一致性。

## 实验评估

实验在Cityscapes→Foggy Cityscapes (C→F)、Cityscapes→BDD100k (C→B) 及Pascal VOC→Clipart (P→Cl) 三个基准上进行，基线覆盖AT、CMT、DT等经典及VFM方法，但缺失源无关域自适应（Source-Free Domain Adaptation, SFDA）与测试时适应（Test-Time Adaptation, TTA）类基线，因本文设定为有源域数据。

| 方法 | C→F mAP (%) | C→B mAP (%) |
| :--- | :--- | :--- |
| AT | 45.7 | 45.7 |
| CMT | 47.0 | 47.0 |
| DT | 55.4 | 55.4 |
| ETS | 56.2 | 49.8 |

ETS在C→F上达到56.2% mAP，较DT提升0.8个百分点；在C→B上达到49.8% mAP，较DT提升2.0个百分点。消融实验表明，ETCT与ETJC模块均贡献显著，其中ETCT对C→F性能提升贡献最大，验证了协同伪标签在恶劣天气场景下的关键作用。

评估边界方面，论文未报告置信区间，且专家模型离线生成伪标签的静态特性未与动态域偏移场景对比。可复现性上，论文提供详细超参数（如DINOv3 ViT-H+骨干、40,000次专家训练迭代），但未公开代码，且实验依赖4块RTX3090 GPU，计算成本较高。

## 关联研究分析

从问题动机看，ETS与DSBCO均针对伪标签噪声，但DSBCO通过双层循环优化提升训练稳定性，而ETS通过知识互补提升伪标签质量。DSBCO在C→F上达到64.7% mAP，显著高于ETS的56.2%，表明优化复杂度与知识互补是两条不同技术路径，前者在抑制噪声方面更具优势，但ETS在VFM增强路线内具有竞争力。

从方法设计看，ETS与DT同属VFM增强路线，但DT仅用VFM做离线标注，ETS增加教师协同。DT在C→F上达到55.4% mAP，ETS提升0.8个百分点，验证了协同优于单一VFM。然而，ETS的专家模型离线生成伪标签，无法实时响应目标域动态变化，而DT的在线特征对齐机制在动态场景下可能更具适应性，论文未对此进行对比。

## 总结

ETS要解决的核心矛盾是VFM通用知识与目标域特定知识的冲突，其切入点在于识别两者互补性，通过ETCT与ETJC模块在标签与表示层面协同融合。实验证明ETS在C→F与C→B上分别达到56.2%与49.8% mAP，超越DT基线。其边界在于专家模型离线静态特性限制了动态域偏移适应，且性能低于非VFM路线SOTA。当目标域分布发生动态变化时，离线专家模型的伪标签质量是否仍能保持优势，论文未给出回答。
