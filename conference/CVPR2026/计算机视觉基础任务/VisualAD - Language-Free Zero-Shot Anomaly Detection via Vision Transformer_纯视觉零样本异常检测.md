# CVPR2026最新论文 ｜VisualAD: Language-Free Zero-Shot Anomaly Detection via Vision Transformer ｜纯视觉零样本异常检测

研究机构：安徽大学、国防科技大学

作者：Yanning Hou、Peiyuan Li、Zirui Liu 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.07952)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.07952)

> 零样本异常检测旨在解决工业新品类频繁更替导致的重训练成本问题，但主流基于视觉-语言模型的方法依赖文本编码器进行跨模态对齐，存在参数冗余与训练不稳定风险。本文切入点在于质疑语言模态在异常语义表征中的必要性，提出移除文本分支、直接在冻结视觉Transformer中注入可学习异常/正常Token的纯视觉框架。通过空间感知交叉注意力与自对齐函数实现细粒度定位。该方法在13个基准上达到SOTA性能，但其在逻辑异常等复杂语义违规场景下的泛化能力尚未得到验证。

## 研究背景

当检测器面对未见过的工业产品或医学影像类别时，缺乏目标域正常样本进行训练，这一冷启动困境构成了零样本异常检测（Zero-Shot Anomaly Detection, ZSAD）的核心约束。为应对此约束，主流方案依赖预训练视觉-语言模型（Vision-Language Models, VLMs）如CLIP，利用其共享嵌入空间中的图文对齐能力，通过构造“正常”与“异常”文本提示计算图像特征相似度。然而，这种范式隐含了一个未经验证的假设：异常语义必须通过语言模态进行锚定。

现有CLIP基ZSAD方法分为手工模板与可学习提示两类，前者对措辞敏感，后者需辅助数据优化文本向量，但两者均保留了文本编码器分支。AnomalyCLIP等代表工作表明，最终决策仅由两组潜向量（正常/异常原型）主导，这引发了一个关键疑问：若决策本质是视觉特征的对比，语言模态是否仅为间接塑造视觉原型的冗余路径？本文通过移除AnomalyCLIP的文本分支并直接优化两个视觉向量，发现性能几乎无损且参数量减少99%，证实了纯视觉特征足以承载异常判别语义，从而将研究重心从跨模态对齐转向视觉空间内的原型学习与空间校准。

## 核心方法

### 方法参照系

本文问题属于零样本异常检测范畴，与通用CLIP基ZSAD流程的关键差异在于：后者通过文本编码器生成正常/异常语义原型，而本文直接在冻结ViT骨干的Token序列中插入可学习视觉Token，摒弃了跨模态对齐环节，转而依赖视觉自注意力机制构建判别性原型。

### 可学习视觉原型注入

设计动机在于消除文本编码器带来的参数冗余与训练波动，直接利用视觉域内的结构、纹理偏差表征异常。在冻结的ViT-L/14骨干中，输入序列扩展为包含类别Token、Patch Token以及新增的异常Token $\mathbf{t}_a$ 和正常Token $\mathbf{t}_n$。通过多层自注意力，这两个Token与Patch Token交互，逐步获取高层异常/正常语义，同时引导Patch关注异常线索。

$$
\mathbf{x}_{in} = [\mathbf{t}_c, \mathbf{t}_a, \mathbf{t}_n, \mathbf{p}_1, \dots, \mathbf{p}_N]
$$

该公式定义了扩展后的输入序列，其中 $\mathbf{t}_a, \mathbf{t}_n$ 为可学习参数，其余部分冻结，确保模型仅通过视觉交互学习判别边界。

### 空间感知交叉注意力与自对齐

设计动机在于解决全局Token缺乏空间定位能力的问题，弥补纯视觉特征在细粒度分割上的短板。在选定的中间层 $\ell$，引入空间感知交叉注意力（Spatial-Aware Cross-Attention, SCA）模块。SCA使用 $m$ 个可学习锚点查询 $\mathbf{Q}_{anchor}$ 对带位置编码的Patch特征 $\mathbf{P}^{pos}_\ell$ 进行交叉注意力，聚合局部空间证据。随后通过Token引导的门控机制更新全局Token：

$$
\tilde{\mathbf{t}} = \mathbf{t} + \alpha \sum_{i=1}^m g_i(\mathbf{t}) \mathbf{a}_i
$$

其中 $\mathbf{a}_i$ 为锚点聚合特征，$g_i(\mathbf{t})$ 为门控权重，$\alpha$ 为残差缩放。此过程动态注入空间信息，使Token具备局部敏感性。同时，自对齐函数（Self-Alignment Function, SAF）作为单层MLP对Patch特征进行非线性重校准，确保其与更新后的Token在语义空间对齐，提升余弦相似度对比的稳定性。

## 实验评估

实验在13个工业与医学基准上进行，对比WinCLIP、AnomalyCLIP等5种SOTA方法。基线覆盖CLIP系ZSAD主流路线，但缺失PatchCore等特征嵌入类强基线，导致无法直接量化零样本与有监督方法在定位精度上的绝对差距。

| 数据集 | 方法 | Image-level AUROC | Pixel-level PRO |
| :--- | :--- | :--- | :--- |
| MVTec-AD | VisualAD(CLIP) | 93.5 | 87.5 |
| MVTec-AD | VisualAD(DINOv2) | 90.4 | 88.6 |
| VisA | VisualAD(CLIP) | 84.7 | 91.0 |
| VisA | VisualAD(DINOv2) | 83.1 | 88.2 |

VisualAD在MVTec-AD图像级AUROC上达到93.5，与领域综述中AnomalyVFM的94.1接近，但在像素级PRO上，DINOv2骨干的88.6略优于CLIP骨干的87.5，印证了两种骨干在分类与分割上的互补性。

| 消融组件 | Image-level (AUROC, AP) | Pixel-level (AUROC, AP) |
| :--- | :--- | :--- |
| 无SCA | (50.5, 58.9) | (87.9, 3.5) |
| 无SAF | (48.0, 56.1) | (38.3, 0.8) |
| 完整模型 | (84.7, 87.6) | (95.8, 28.4) |

消融显示，移除SCA或SAF均导致性能断崖式下跌，其中移除SAF对像素级AP的影响最大（从28.4降至0.8），表明非线性重校准对细粒度定位至关重要。锚点数量 $m=4$ 时像素级性能最优，超过4后出现冗余，说明少量锚点足以捕捉关键空间证据。

评估协议采用标准ZSAD设置，在VisA上训练并在其他数据集测试。指标涵盖图像级与像素级，但未报告计算效率（如GFLOPs、推理延迟），限制了边缘部署场景的评估。代码已开源，超参数（如学习率 $1 \times 10^{-3}$、Batch size 8）明确，具备可复现性。

## 关联研究分析

从方法设计看，VisualAD与AnomalyCLIP的核心差异在于原型生成机制。AnomalyCLIP依赖文本编码器将自然语言映射为语义向量，其性能受限于文本提示的覆盖范围与歧义性；VisualAD则直接在视觉特征空间优化原型，避免了跨模态对齐的噪声干扰。这种差异源于对异常本质认知的不同：前者视异常为语义偏离，后者视异常为视觉分布偏离。然而，VisualAD未探讨当异常涉及复杂逻辑关系（如部件缺失）时，纯视觉Token能否捕捉高阶语义约束，这构成了其相对于文本引导方法在语义可解释性上的潜在盲区。

从问题动机看，VisualAD与PatchCore等特征嵌入方法形成竞争关系。PatchCore通过构建正常特征记忆库实现高精度定位，但需针对每个新品类重新提取特征；VisualAD通过冻结骨干与可学习Token实现跨域泛化，无需目标域数据。两者的取舍在于泛化能力与定位精度的平衡：VisualAD在MVTec-AD上的PRO（87.5-88.6）仍低于PatchCore的典型水平（据领域综述约98.2 I-AUROC对应的定位精度），表明纯视觉原型在细粒度纹理差异上的捕捉能力仍弱于基于密集特征匹配的记忆库方法。

## 总结

VisualAD旨在解决零样本异常检测中语言模态冗余与训练不稳定的矛盾，通过证明纯视觉Token可替代文本提示实现跨域检测，切入CLIP基ZSAD的架构瓶颈。方法核心是在冻结ViT中注入可学习异常/正常Token，结合SCA与SAF模块实现空间校准与特征重对齐。实验表明，该方法在MVTec-AD图像级AUROC达93.5，VisA像素级PRO达91.0，接近或达到SOTA水平。其边界在于缺乏对逻辑异常等全局语义违规的验证，且未报告计算效率数据。当异常类型从局部纹理偏差扩展至部件关系违规时，纯视觉Token的判别能力是否依然有效，论文未给出回答。
