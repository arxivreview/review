# CVPR2026最新论文 ｜Small Object, Great Challenge: A Benchmark for Small Object Visual Grounding ｜小目标指代表达定位基准与方法

研究机构：北京邮电大学

作者：Wenqi Jia、Ruifan Li、Pengyue Lin 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_b8e270f92f23)

> 指代表达定位任务长期受限于训练数据中目标尺度的分布偏差，导致模型在微小物体上性能骤降。现有基准如 RefCOCO 系列平均目标面积占比约 19%，缺乏对小于 2% 面积目标的系统性评估，且手动标注小目标成本高昂。本文提出 SoVG 任务，利用多模态大语言模型（MLLM）自动构建大规模小目标基准 RefCOCOs，并设计分层文本注入（HTI）模块增强深层视觉特征。该工作填补了小目标定位的基准空白，但其在开放词汇场景下的泛化能力及与 MLLM 端到端范式的对比仍存疑。

## 研究背景

当护理机器人需要在杂乱货架上定位小药瓶时，传统指代表达定位（Visual Grounding, VG）模型往往失效。这是因为 VG 任务的核心挑战在于弥合语言抽象性与视觉具体性之间的鸿沟，而现有主流基准（如 RefCOCO/+/g）在构建时存在显著的尺度偏差：标注者倾向于选择大而显著的物体，导致数据中目标平均面积占比高达 18.97%。这种偏差使得模型在训练过程中过度依赖大目标的显著视觉特征，忽视了小目标在深层网络中易被背景稀释的特性，从而无法处理“左下角的小碗”等细粒度指代。

VG 领域的主流路线已从早期的 CNN-LSTM 特征拼接演进至基于 Transformer 的回归框架，如 Grounding DINO 和 LISA。然而，这些方法主要优化全局语义对齐，未专门针对小目标特征在编码器深层传播过程中的衰减问题。小目标检测（SOD）虽关注尺度问题，但其本质是类别级识别，缺乏实例级语言消歧能力。本文切入点在于识别并量化这一尺度偏差，通过构建专用基准和修改编码器内部信息流，解决小目标视觉信息在深层网络中丢失的问题。

## 核心方法

### 方法参照系

本文问题属于端到端指代表达定位范式，标准流程为：文本编码器提取语义，视觉编码器提取特征，跨模态解码器融合后输出边界框与掩码。与通用 VG 流程的关键差异在于，本文假设小目标特征在视觉编码器深层被稀释，因此将跨模态交互前移至编码器内部，而非仅在解码器阶段进行。

### 分层文本注入（HTI）模块

HTI 模块解决小目标视觉特征在 ViT 块逐层传递时被主导背景特征稀释的问题。在标准 ViT 块中，视觉特征 $F_v^{(k)}$ 仅通过自注意力更新，缺乏文本引导。本文在视觉编码器的第 $k$ 层插入 HTI，将文本特征 $F_t$ 投影至视觉维度 $D_v$ 得到 $F'_t$，并通过交叉注意力更新视觉特征：

$$ F_v^{(k), \text{update}} = \text{Attention}(F_v^{(k)}, F'_t, F'_t) $$

随后通过残差连接与层归一化融合：

$$ F_v^{(k)} = \text{LN}(F_v^{(k)} + \text{Linear}(F_v^{(k), \text{update}})) $$

该设计在多个层级（如第 15, 18, 21, 24 层）重复注入，确保文本语义持续强化小目标的视觉表征，防止其在深层网络中丢失。

### 多任务预测头

解码器接收增强后的视觉特征 $F_v^{\text{final}}$，引入可学习定位 token [SOG] 聚合全局信息。经过 $N_d$ 层自注意力与交叉注意力（以原始文本特征为 Key/Value）后，特征分别送入两个预测头。REC 头使用两层 MLP 回归边界框坐标；RES 头将特征重塑为 2D 空间图，经卷积层与 Sigmoid 函数生成掩码。损失函数结合 Focal Loss 与 Dice Loss 以应对小目标前景背景像素的极端不平衡：

$$ L_{\text{seg}} = \lambda_{\text{focal}} L_{\text{focal}}(m, \hat{m}) + \lambda_{\text{dice}} L_{\text{dice}}(m, \hat{m}) $$

此设计确保模型在定位与分割任务上均能优化小目标的边界精度。

## 实验评估

实验在 RefCOCOs（新构建）及 RefCOCO/+/g 上进行，基线涵盖 EEVG、HiVG 等 Transformer 架构方法，但缺乏 LISA 等 MLLM 端到端基线，限制了与当前主流范式的直接对比。

| Method | RefCOCOg REC Acc@0.5 | RefCOCOg RES mIoU | RefCOCOs REC Acc@0.5 (testB) | RefCOCOs RES mIoU (testB) |
| :--- | :--- | :--- | :--- | :--- |
| EEVG | 82.44 | 72.65 | 66.76 | 54.30 |
| SoVG-Net | 85.33 | 75.07 | 72.33 | 60.40 |

在经典基准 RefCOCOg 上，SoVG-Net 的 REC 准确率为 85.33%，RES mIoU 为 75.07%，均优于 EEVG。在新基准 RefCOCOs 的 testB 集上，SoVG-Net 的 REC 准确率达 72.33%，较 EEVG 提升 5.57 个百分点；RES mIoU 为 60.40%，提升 6.10 个百分点。

| Scheme | Block Idx | Val Acc@0.5 | TestB Acc@0.5 |
| :--- | :--- | :--- | :--- |
| Shallow | 3, 6, 9, 12 | 70.01 | 67.59 |
| Deep | 15, 18, 21, 24 | 72.69 | 72.33 |
| Baseline (No HTI) | - | 68.61 | 66.82 |
| Baseline + HTI | - | 72.69 | 72.33 |

消融实验显示，HTI 模块带来显著增益，TestB 集 Acc@0.5 提升 5.51%，mIoU 提升 5.31%。注入位置从浅层（3-12 层）到深层（15-24 层）性能逐步提升，深层方案在 TestB 上达到 72.33%，验证了小目标定位依赖高层语义假设。

评估指标涵盖多阈值 IoU，但缺乏计算效率与实时性报告。代码已开源，使用 DINOv2 与 BERT 预训练权重，在 4 块 RTX A6000 GPU 上训练，超参数设置标准，可复现性良好。

## 关联研究分析

从问题动机看，本文与 Grounding DINO 等开放词汇定位方法存在根本差异。Grounding DINO 依赖 CLIP 的预训练语义对齐，旨在解决未见类别的泛化，而本文聚焦于封闭集内小目标的尺度偏差。本文未采用开放词汇架构，而是通过自动标注扩大数据规模，这暗示其优势可能源于数据量而非架构的开放世界能力。当测试集包含训练分布外的新类别时，SoVG-Net 的性能是否仍能保持，论文未给出回答。

从方法设计看，本文与 LISA 等 MLLM 集成 SAM 的路线形成对比。LISA 将分割任务转化为 LLM 生成代码或 token，依赖大模型的推理能力处理复杂逻辑；本文则坚持专用 Transformer 架构，通过 HTI 在编码器内部增强特征。这种选择表明，在小目标定位这一特定子任务上，专用架构的特征增强可能比通用大模型的推理更直接有效。然而，本文未对比 MLLM 基线，无法排除 LISA 等模型在小目标上的潜在优势，尤其是当描述包含复杂空间关系时。

## 总结

本文核心矛盾在于现有 VG 基准的尺度偏差导致小目标定位性能低下。切入点在于利用 MLLM 自动构建大规模小目标基准 RefCOCOs，并通过 HTI 模块在视觉编码器深层注入文本特征，解决小目标特征稀释问题。实验证明 SoVG-Net 在 RefCOCOs testB 集上 REC 准确率达 72.33%，RES mIoU 达 60.40%，显著优于基线。其边界在于未与 MLLM 端到端范式对比，且基准基于 COCO 封闭集，缺乏开放词汇验证。当描述涉及训练集中未出现的物体类别时，SoVG-Net 的泛化能力是否优于 Grounding DINO 等开放词汇模型，论文未给出回答。
