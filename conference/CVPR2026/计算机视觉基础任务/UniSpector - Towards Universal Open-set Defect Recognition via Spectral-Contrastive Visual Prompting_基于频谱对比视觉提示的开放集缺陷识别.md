# CVPR2026最新论文 ｜UniSpector: Towards Universal Open-set Defect Recognition via Spectral-Contrastive Visual Prompting ｜基于频谱对比视觉提示的开放集缺陷识别

作者：Geonuk Kim、Minhoi Kim、Kangil Lee 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.02905)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.02905)

> 工业质检面临缺陷类别动态演化的挑战，传统封闭集检测器需高昂重训练成本，而无监督异常检测缺乏语义区分能力。现有视觉提示方法在处理工业细微缺陷时，因高类内方差和低类间差异导致提示嵌入坍缩，无法实现鲁棒的开放集定位。UniSpector 通过重构提示嵌入空间的拓扑结构，结合频谱特征提取与对比正则化，解决了这一结构性缺陷。该方法在首个开放集视觉提示基准 InsA 上显著优于基线，但其跨域泛化能力仍受限于成像偏差，且未与主流无监督异常检测范式进行直接性能对标。

## 研究背景

当检测器面对生产线上新出现的缺陷类型时，其训练域与测试域的数据分布出现系统性差异，这一现象称为分布偏移。分布偏移导致传统分类器决策边界失效，而实际场景中往往能获取少量目标域样本，这恰好构成了小样本学习的条件：仅凭每个类别极少量标注样本泛化到新任务。解决此类问题的经典框架是原型网络，它计算各类别支持样本的特征均值作为“原型”，再通过距离度量完成分类。

工业视觉检测的核心痛点在于缺陷样本极度稀缺且类别不平衡，真实生产线中缺陷率极低导致监督学习难以训练。主流路线转向无监督异常检测，通过建模正常样本分布来识别偏离，解决了标签缺失痛点，但引入了“语义缺失”的新问题——模型能指出哪里异常，却无法说明是什么缺陷。随着视觉语言模型和多模态大语言模型的引入，研究目标从单纯的像素级分割扩展至开放词汇理解。然而，在细粒度工业检测中，缺陷往往视觉上细微且难以用语言准确描述，纯文本驱动的接地不可靠。视觉提示作为一种替代方案，通过匹配输入图像区域与示例提示来实现开放集定位，但现有方法在处理高类内方差和细微类间差异时，往往将提示嵌入视为通过提示-区域匹配学习的隐式表示，忽略了提示嵌入空间的结构化设计，导致在工业域中发生提示嵌入坍缩。

## 核心方法

### 方法参照系

本文问题属于开放集目标检测与分割范畴，最接近的通用方法类别是基于 DETR 架构的视觉提示检测器。标准流程通常依赖可学习的对象查询与视觉提示进行交叉注意力匹配，但本文的关键差异在于：不再将提示嵌入视为静态的隐式表示，而是将其重构为具有语义结构化拓扑的显式空间，以应对工业缺陷的高类内方差和低类间可分性。

### 空间-频谱提示编码

传统视觉提示方法仅依赖像素域特征，难以捕捉细微纹理差异且对旋转敏感。UniSpector 引入空间-频谱提示编码器（SSPE），通过双域描述符重新定义视觉提示。SSPE 首先计算提示样本感兴趣区域（RoI）的二维离散傅里叶变换，并通过沿同心频率环平均幅度响应来消除方向偏差，得到一维径向频谱 $h_k$。该频谱保留了全局结构特征且对旋转不变，有效抑制了由几何旋转引起的类内方差。随后，SSPE 采用双路径编码策略：一路通过径向频率编码器将 $h_k$ 投影为频谱码 $z_k^{freq}$，另一路通过掩码交叉注意力从提示图像提取空间码 $z_k^{spatial}$。最终提示嵌入 $\mathbf{e}_k$ 通过两个轻量级 MLP 融合这两个模态：

$$ \mathbf{e}_k = f_{align}(z_k^{freq}) + v_{align}(z_k^{spatial}) $$

这一设计通过引入频域信息增强了类间可分性，同时利用径向频谱的旋转不变性降低了类内方差，为后续的结构化正则化提供了高质量的初始表示。

### 对比提示编码与查询选择

基于 SSPE 提供的细粒度表示，对比提示编码器（CPE）显式正则化提示嵌入空间，建立语义结构化的角流形拓扑。CPE 借鉴 ArcFace 的思想，采用角边距对比损失，鼓励同一类实例紧凑聚集，同时强制不同类之间保持足够的角距离。对于第 $k$ 个提示嵌入 $\mathbf{e}_k$ 及其类原型 $\mathbf{p}_c$，余弦相似度为 $\cos(\theta_{k,c})$，损失函数定义为：

$$ \mathcal{L}_{CPE} = -\log \frac{e^{\alpha \cos(\theta_{k,y_k} - m)}}{e^{\alpha \cos(\theta_{k,y_k} - m)} + \sum_{c \neq y_k} e^{\alpha \cos(\theta_{k,c})}} $$

其中 $m$ 为角边距，$\alpha$ 为缩放因子。该损失确保嵌入空间在满足边距约束后，能根据语义亲和力自组织，使相关缺陷类型在角度上更近，不相关的更远，从而实现未见缺陷的语义一致放置。此外，提示引导查询选择（PQS）模块通过可微分的 Gumbel-Softmax 选择，动态选取与提示条件匹配的视觉令牌作为对象查询，消除了对静态先验的依赖，提升了对象性估计的准确性。

## 实验评估

实验在 InsA 基准上进行，该基准聚合了 GC10、MagneticTile、Real-IAD、MVTec 等七个公开数据集，分为域内开放集和跨域两个部分。基线覆盖了视觉接地模型（GroundingDINO, YOLO-World）和视觉提示模型（DINOv, T-Rex2, YOLOE 等）。值得注意的是，基线中缺失了 PatchFlow、FPFNet 等当前无监督异常检测领域的 SOTA 方法，这可能因为任务定义不同（开放集分类 vs 异常检测），但缺乏直接对比限制了结论的普适性。

| 方法 | In-domain AP_b_50 | In-domain AP_m_50 | Cross-domain AP_b_50 | Cross-domain AP_m_50 |
| :--- | :--- | :--- | :--- | :--- |
| GroundingDINO† | 8.0 | - | 0.0 | - |
| YOLO-World† | 18.8 | - | 0.3 | - |
| DINOv† | 17.1 | 14.7 | 4.3 | 3.8 |
| YOLOE† | 17.4 | 15.8 | 4.6 | 3.8 |
| UniSpector† | 40.9 | 35.4 | 14.1 | 10.0 |

UniSpector 在域内和跨域设置下均显著优于所有基线，域内 AP_b_50 达到 40.9%，比最强基线 YOLOE† 高 19.7%。消融实验表明，CPE 对性能提升贡献最大，验证了结构化嵌入空间的重要性；PQS 相比启发式 Top-K 选择带来了显著增益，证明可微分查询选择的有效性。

评估边界方面，论文仅报告了 AP_50 指标，未提供置信区间或计算效率数据。InsA 基准的跨域部分包含 3CAD、VISION 和 VisA，但跨域性能（14.1%）远低于域内性能，表明模型对成像偏差敏感。代码已开源，但超参数细节需查阅附录。

## 关联研究分析

从问题动机看，UniSpector 与无监督异常检测方法（如 PatchFlow）存在根本差异。PatchFlow 通过建模正常样本分布来识别异常，无需缺陷标签，但在 MVTec AD 上 i-AUROC 高达 99.28%，其优势在于鲁棒性和无需语义标签。UniSpector 则聚焦于开放集语义理解，通过视觉提示实现免重训练的新缺陷识别，解决了无监督方法“能指出哪里异常，却无法说明是什么缺陷”的痛点。两者的核心冲突在于：无监督方法牺牲语义解释换取鲁棒性，而 UniSpector 牺牲部分鲁棒性（跨域性能较低）换取语义可解释性。这种取舍在需要根因分析的工业场景中更为关键，但在未知缺陷类型完全陌生的情况下，无监督方法可能更具优势。

从方法设计看，UniSpector 与 DINOv 等视觉提示方法的关键差异在于对提示嵌入空间的结构化处理。DINOv 将提示嵌入视为通过提示-区域匹配学习的隐式表示，导致在高类内方差下发生嵌入坍缩。UniSpector 通过 SSPE 引入频谱特征抑制类内方差，并通过 CPE 显式正则化嵌入空间，建立了语义结构化的角流形拓扑。这一设计使得未见缺陷能根据语义亲和力自然放置在相关类别附近，而非任意投影。然而，CPE 的角距离约束是否限制了极端形态缺陷的表示能力，论文未给出回答。此外，UniSpector 依赖 DETR 架构，计算开销较大，而 DINOv 等基于 Transformer 的方法在推理效率上可能更具优势，这在边缘部署场景中是一个重要考量。

## 总结

UniSpector 旨在解决工业质检中缺陷类别动态演化导致的封闭集模型失效问题，以及无监督异常检测缺乏语义解释的痛点。其切入点在于识别出视觉提示方法中提示嵌入坍缩的结构性根源，并通过频谱-对比学习机制重构提示嵌入空间，实现了语义结构化的开放集定位。实验证明，该方法在 InsA 基准上域内 AP_b_50 达到 40.9%，比最强基线高 19.7%，验证了结构化提示空间的有效性。然而，其跨域性能（14.1%）显著低于域内，暴露了对成像偏差的敏感性，且未与主流无监督异常检测方法进行直接对比。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
