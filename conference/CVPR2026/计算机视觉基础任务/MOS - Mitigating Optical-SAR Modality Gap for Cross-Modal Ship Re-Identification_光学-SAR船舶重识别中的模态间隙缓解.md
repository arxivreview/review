# CVPR2026最新论文 ｜MOS: Mitigating Optical-SAR Modality Gap for Cross-Modal Ship Re-Identification ｜光学-SAR船舶重识别中的模态间隙缓解

研究机构：北京航空航天大学

作者：Yujian Zhao、Hankun Liu、Guanglin Niu

论文原文见 [arXiv](https://arxiv.org/abs/2512.03404)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.03404)

> 光学与合成孔径雷达（SAR）成像机制差异导致特征空间断裂，现有方法在混合模态检索中常因模态差异主导身份差异而失效。MOS通过训练时的类内模态对齐与推理时的扩散生成特征融合，从数据与特征双视角弥合这一间隙。该框架在HOSS-ReID数据集上实现了SOTA性能，但其对单一基准的依赖及未探索的频域去噪路径，限制了结论的普适性。

## 研究背景

船舶重识别（Ship Re-Identification, ReID）旨在跨非重叠相机或异构传感器匹配同一船舶，是海事监控与追踪的核心任务。与行人或车辆ReID不同，船舶场景通常涉及光学与SAR两种模态。SAR具备全天候、全天时成像能力，但其固有的相干斑噪声（Coherent Speckle Noise）与雷达特有纹理严重干扰特征提取。这种噪声不仅降低了单模态识别精度，更在跨模态匹配中加剧了光学与SAR图像间的分布差异，形成显著的模态间隙（Modality Gap）。

主流跨模态ReID方法多依赖深度网络隐式学习高维特征表示，对模型容量要求极高，且往往假设模态间存在简单的互补性。然而，在光学-SAR这一极端模态组合中，直接融合或简单对齐难以消除SAR噪声带来的干扰，导致模型在推理时倾向于匹配同模态样本，即使这些样本身份错误，而忽略正确的跨模态匹配。现有工作如TransOSS虽基于ViT架构建立了基线，但未显式处理SAR噪声与模态分布的对齐问题。MOS的切入点在于将SAR去噪与模态对齐解耦为训练与推理两个阶段，通过显式的类内统计量约束和生成式数据增强，从根源上缩小模态间隙。

## 核心方法

### 方法参照系

光学-SAR船舶ReID可视为跨模态度量学习的特例。标准流程包括特征提取、距离度量与排序。本文的关键差异在于，传统方法直接在原始图像上提取特征，而MOS在特征提取前引入SAR去噪预处理，并在推理阶段引入生成式特征融合，改变了特征空间的构建逻辑。

### 模态一致性表示学习（MCRL）

MCRL模块在训练阶段通过去噪与类内对齐损失缩小模态间隙。设计动机在于解决SAR相干斑噪声导致的特征提取不稳定，以及光学与SAR特征分布的结构性差异。首先，对SAR图像进行像素级去噪：将像素值升序排列，丢弃最低的$\alpha\%$像素（主要对应噪声），并将剩余像素线性重缩放至[0, 255]。其次，引入类内模态对齐损失（Class-wise Modality Alignment Loss, CMAL）。假设同一身份$c$在光学与SAR模态下的特征分布服从高斯分布$N(\mu_{c}^{opt}, \Sigma_{c}^{opt})$与$N(\mu_{c}^{sar}, \Sigma_{c}^{sar})$，CMAL最小化两者间的Wasserstein-2距离近似值：

$$
\mathcal{L}_{CMAL} = \frac{1}{|C|} \sum_{c \in C} \left( \| \mu_{c}^{opt} - \mu_{c}^{sar} \|^2 + \| \sigma_{c}^{opt} - \sigma_{c}^{sar} \|^2 \right)
$$

其中$\sigma_{c}$为特征维度的标准差向量。该公式通过约束类内均值与方差的一致性，强制模型学习模态不变的身份嵌入，而非传感器特异性特征。

### 跨模态数据生成与特征融合（CDGF）

CDGF模块在推理阶段通过生成伪SAR样本增强特征鲁棒性。设计动机在于解决训练数据有限导致的过拟合，以及推理时单一模态特征的不确定性。利用布朗桥扩散模型（Brownian Bridge Diffusion Model, BBDM），从光学图像$y$生成$K$个伪SAR样本$\hat{I}_{i}^{[k]}$。每个伪SAR样本与原始光学图像通过共享骨干网络提取特征，最终融合表示为：

$$
f_{fused} = (1-\tau) f_{opt} + \tau \frac{1}{K} \sum_{k=1}^{K} f_{pseudo-sar}^{[k]}
$$

其中$\tau \in [0, 1]$为融合权重，控制生成特征的贡献比例。这种加权融合策略允许模型在保留可靠光学特征的同时，引入生成SAR特征的互补结构信息，从而在推理时动态平衡模态特异性与身份判别力。

## 实验评估

实验在HOSS-ReID数据集上进行，该数据集包含1,063张训练图像（574光学，489 SAR）及测试集，涵盖ALL-to-ALL、Optical-to-SAR及SAR-to-Optical三种协议。基线覆盖通用视觉方法（ViT-base, DeiT-base）、单模态ReID方法（TransReID, D2InterNet）及跨模态ReID方法（TransOSS, CM-NAS等），但未包含知识库中最新的频域方法（如FUSE）或语义引导方法（如IDEA）在船舶任务上的迁移对比。

| 方法 | ALL-to-ALL mAP (%) | Optical-to-SAR mAP (%) | SAR-to-Optical mAP (%) |
| :--- | :--- | :--- | :--- |
| TransOSS | 57.4 | 48.9 | 38.7 |
| MOS (Ours) | 60.4 | 51.4 | 48.7 |

MOS在所有协议下均优于基线TransOSS，尤其在SAR-to-Optical协议中mAP提升10.0%，R1提升16.4%，表明MCRL在极端模态偏移下的对齐效果显著。

| 模块 | ALL-to-ALL mAP (%) | SAR-to-Optical mAP (%) |
| :--- | :--- | :--- |
| Baseline (TransOSS) | 57.4 | 38.7 |
| + MCRL | 59.3 | 45.9 |
| + CDGF | 58.1 | 38.6 |
| + MCRL + CDGF | 60.4 | 48.7 |

消融实验显示，MCRL单独使用即可带来+1.9% mAP提升，而CDGF单独使用仅带来+0.7% mAP提升，且在SAR-to-Optical协议中甚至出现负迁移（-0.1% mAP）。这表明CDGF的有效性高度依赖于MCRL建立的鲁棒特征空间，两者呈现互补而非独立贡献关系。

评估边界方面，论文仅使用HOSS-ReID单一基准，缺乏跨数据集泛化验证。指标仅报告mAP与R1，未提供置信区间或计算效率指标。代码与模型声明将在发表后发布，当前可复现性受限。

## 关联研究分析

从问题动机看，MOS与MTRL（Yuan et al., 2025）均利用生成式模型弥合模态间隙，但MTRL在训练阶段生成中间模态图像参与对齐，而MOS在推理阶段生成伪SAR样本进行特征融合。这一差异源于任务特性：MTRL针对行人VI-ReID，模态差异相对较小，生成中间模态可直接促进对齐；而MOS针对光学-SAR船舶ReID，模态差异极大且SAR噪声显著，推理时生成融合更能适应动态场景变化，但引入了额外的计算延迟。

从方法设计看，MOS与FUSE（Qi et al., 2026）在处理模态差异上存在路线分歧。FUSE采用频域分析与光谱能量对齐，显式建模光照引起的低频偏差；而MOS采用空间域去噪与生成融合，未涉及频域处理。这一差异暗示SAR相干斑噪声的特性可能与可见光-红外场景中的光照噪声不同，频域方法是否适用于SAR去噪，论文未给出回答。此外，MOS未采用文本语义引导，可能限制了其在细粒度属性匹配上的潜力。

## 总结

MOS旨在解决光学-SAR船舶ReID中因成像机制差异导致的模态间隙问题。其切入点在于将SAR去噪与模态对齐解耦，通过训练时的类内统计量约束（MCRL）与推理时的生成式特征融合（CDGF），从数据与特征双视角弥合间隙。实验证明，MOS在HOSS-ReID的SAR-to-Optical协议中mAP提升10.0%，显著优于基线TransOSS。然而，其边界在于仅验证于单一基准，且CDGF在缺乏MCRL正则化时出现负迁移，表明模块间存在强依赖。当支持集规模扩大或模态组合增加时，生成式推理的边际收益是否递减，论文未给出回答。
