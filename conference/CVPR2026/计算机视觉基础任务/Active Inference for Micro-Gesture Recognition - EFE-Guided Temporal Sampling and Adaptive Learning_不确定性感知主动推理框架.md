# CVPR2026最新论文 ｜Active Inference for Micro-Gesture Recognition: EFE-Guided Temporal Sampling and Adaptive Learning ｜不确定性感知主动推理框架

研究机构：深圳大学、浙江大学

作者：Weijia Feng、Jingyu Yang、Ruojia Zhang 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.07559)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.07559)

> 微手势识别（MGR）旨在从非自主、低幅度的手部运动中解码隐藏情绪，其核心难点在于信号在时空维度上的极度稀疏与噪声敏感性。现有深度模型被动处理全帧信息，既无法聚焦瞬态关键区域，又缺乏对预测不确定性的感知，导致在低样本与跨受试者场景下性能退化。本文提出UAAI框架，通过期望自由能（EFE）引导的时空主动采样与不确定性感知增强（UMIX），将帧选择形式化为不确定性最小化问题。该框架在SMG数据集上以纯RGB输入达到63.47%准确率，逼近骨架模态SOTA，但其泛化边界与计算开销仍需进一步审视。

## 研究背景

当模型面对持续时间短于0.5秒的微手势时，传统时空卷积网络（CNN）或Transformer被动处理所有帧与空间区域，导致计算资源被大量冗余背景消耗。这种被动观察机制无法适应微手势的瞬态与局部化特性，且模型在模糊样本上常表现出过度自信，缺乏对预测不确定性的量化能力。为应对此问题，主动推理（Active Inference）框架被引入，其核心假设是智能体通过最小化变分自由能（VFE）来优化感知与行动，即主动选择最能降低潜在状态不确定性的观测数据。

微手势识别领域长期受困于数据稀缺、标注噪声及受试者间变异性。主流路线包括基于RGB的时序建模（如TSM、VideoMamba）与基于骨架的图卷积网络（GCN），前者易受光照与背景干扰，后者依赖昂贵的深度传感器。长视频理解中的关键帧选择策略（如Logic-in-Frames）旨在保留语义完整性，但微手势缺乏显式语义结构，其核心挑战在于降低预测不确定性而非覆盖语义。UAAI的切入点在于将帧选择重构为基于EFE的不确定性最小化行动，而非启发式注意力，从而在低资源条件下实现高效且鲁棒的细粒度行为建模。

## 核心方法

### 变分自由能最小化参照系

微手势识别通常被形式化为状态推断问题，模型需估计潜在手势类别的后验分布。标准流程通过最小化变分自由能（VFE）来平衡数据拟合与模型复杂度，其中准确性项对应交叉熵损失，复杂度项衡量推断后验与先验的KL散度。本文的关键差异在于，不再被动接受所有观测，而是将观测选择本身纳入VFE最小化过程，使感知（学习）与行动（采样）在统一目标下联合优化。

### EFE引导的时空主动采样

传统方法在时序上均匀采样，空间上全局处理，导致对瞬态微手势的捕捉效率低下。UAAI将帧选择建模为部分可观测马尔可夫决策过程（POMDP），通过最小化期望自由能（EFE）动态选择最具信息量的关键帧。EFE由认知价值（预测后验与目标后验的散度）与预期信息增益组成，其最小化过程自动聚焦于能最大程度降低潜在状态不确定性的时间片段。在空间维度，模型引入可学习权重掩码$M \in \mathbb{R}^{H \times W}$，通过分解EFE至空间位置，隐式优化权重以抑制无关背景。这一设计解决了被动模型对噪声敏感的问题，使计算资源集中于判别性区域。

$$
G_t(a_t) = \mathbb{E}_{p(o_{t+1}|a_t)} \left[ D_{KL}(q(s_{t+1}|o_{t+1}, a_t) || p(s_{t+1}|a_t)) \right]
$$

该公式表明，模型选择能最大化预期信息增益、最小化后验不确定性的动作$a_t$，从而在时序上实现稀疏且高效的观测。

### 不确定性感知增强（UMIX）

现有不确定性建模多作为事后校准步骤，未融入表示学习。UMIX利用蒙特卡洛Dropout量化认知不确定性，并据此自适应重加权训练样本。对于高不确定性样本，模型降低其权重并执行软样本混合，混合系数$\lambda$从Beta分布中采样。这一机制将不确定性嵌入优化过程，作为动态隐式正则器，缓解标签噪声与分布偏移导致的过拟合。

$$
\mathcal{L}_{final} = \sum_{i} w_i \mathcal{L}_{ce}(f(x_i), y_i) + \lambda \mathcal{L}_{mix}
$$

其中$w_i$由不确定性分数$u(I)$决定，高不确定性样本获得更低权重，从而在训练阶段主动抑制噪声样本对决策边界的干扰。

## 实验评估

实验在SMG数据集上进行，该数据集包含488分钟自发微手势视频，涵盖17个手势类别。基线覆盖RGB模态（TSM, VideoMamba等）与骨架模态（STGCN, MS-G3D等），但缺失微表情识别中常用的光流或动态图像（DI）专用基线，这可能限制了与运动表征方法的直接对比。

| 方法 | 模态 | 准确率 (%) |
| :--- | :--- | :--- |
| MS-G3D | Skeleton | 64.75 |
| UAAI | RGB | 63.47 |
| Video Mamba | RGB | 55.08 |
| TSM | RGB | 58.69 |

UAAI以63.47%的准确率在RGB模态中领先，较Video Mamba提升8.39个百分点，且仅比骨架SOTA（MS-G3D）低1.28个百分点。这一结果证明，通过主动推理机制，纯RGB输入可逼近依赖深度传感器的骨架模型性能，挑战了多模态融合的必要性。

| 配置 | 准确率 (%) |
| :--- | :--- |
| Baseline | 50.49 |
| +UMIX | 57.54 |
| +Temporal Selection | 56.40 |
| UAAI (Full) | 63.47 |

消融实验显示，UMIX单独贡献7.05个百分点，时序选择贡献5.91个百分点，二者联合产生协同效应，总提升达12.98个百分点。这表明不确定性建模与主动采样并非简单叠加，而是通过互补机制共同抑制噪声。值得注意的是，空间选择单独贡献仅4.91个百分点，低于时序选择，暗示在微手势任务中，时间维度的稀疏性比空间维度的局部性更具决定性。

评估仅采用准确率指标，未报告F1分数或置信区间，且仅在单一数据集（SMG）上验证。代码未公开，超参数（如Monte Carlo采样数M=5）的敏感性分析显示，M=5在精度与计算成本间取得平衡，但GPU利用率仅约10%，表明计算瓶颈可能不在模型本身而在数据加载或采样策略。

## 关联研究分析

从问题动机看，UAAI与长视频理解中的Logic-in-Frames存在根本差异。后者旨在保留语义完整性以支持下游推理，而UAAI将帧选择形式化为不确定性最小化问题。这一差异源于任务特性：微手势缺乏显式语义结构，其核心挑战在于从噪声中提取瞬态信号，而非覆盖长时序语义。因此，基于语义一致性的关键帧选择策略在微手势任务中可能失效，而基于认知不确定性的主动推理更契合其稀疏、细粒度的信号特性。

从方法设计看，UAAI与微表情识别（MER）中的动态图像（DI）技术形成对比。DI通过压缩视频为单帧利用预训练模型，但可能丢失连续运动细节；UAAI则通过EFE引导的稀疏采样保留关键帧，同时通过UMIX抑制噪声。二者均试图解决小样本下的泛化问题，但DI依赖预训练视觉模型的迁移能力，而UAAI依赖主动推理框架的不确定性量化。在仅使用RGB输入的条件下，UAAI未引入光流或DI，这与MER领域“光流是基础特征”的共识相悖。这种设计选择暗示，在微手势任务中，主动选择策略可能比显式运动表征更能有效捕捉低幅度运动，但这一假设在跨数据集（如iMiGUE）上的泛化性尚未得到验证。

## 总结

UAAI旨在解决微手势识别中时空稀疏性与噪声敏感性的矛盾。现有方法被动处理全帧信息，无法聚焦瞬态关键区域且缺乏不确定性感知，导致在低样本场景下性能退化。本文通过EFE引导的主动采样与UMIX增强，将帧选择重构为不确定性最小化问题，在SMG数据集上以纯RGB输入达到63.47%准确率，逼近骨架模态SOTA。然而，实验仅在单一数据集上进行，且未与光流或DI方法对比，其泛化边界与运动表征的有效性存疑。当支持集规模增大或引入多模态输入时，主动推理框架的边际收益是否递减，论文未给出回答。
