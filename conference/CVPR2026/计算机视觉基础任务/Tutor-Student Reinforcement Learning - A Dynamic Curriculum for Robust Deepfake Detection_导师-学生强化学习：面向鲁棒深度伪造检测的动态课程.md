> 深度伪造检测器在跨数据集与跨方法评估中普遍存在泛化瓶颈，根源常被归结为特征提取不足或数据分布偏移。现有方案多聚焦于频域特征工程或静态课程学习，却忽视了训练过程中样本权重的动态失衡问题。TSRL 框架将训练过程建模为马尔可夫决策过程，通过强化学习代理实时调整样本损失权重，构建自适应动态课程。该范式在多个基线模型上验证了泛化提升，但其收益是否受限于骨干网络的上限，以及在野外数据上的鲁棒性仍存疑。

## 研究背景

当检测器在 FaceForensics++ 等受控基准上训练后，面对 Celeb-DF-v2 或 DF40 等未见数据时性能显著衰减，这一现象源于训练域与测试域间的分布偏移。分布偏移导致模型过拟合特定生成器的空间伪迹，而实际场景中压缩、缩放等退化操作进一步抹除了低级痕迹。解决此问题的关键不在于单纯增加模型复杂度，而在于优化训练过程中的样本利用效率，即如何动态分配学习资源以捕获生成器无关的鲁棒特征。

传统监督学习对所有样本施加均匀损失权重，假设每个样本对梯度更新的贡献相等。然而，近期研究表明，高质量伪造图像对检测器性能影响更大，且静态课程学习（如按难度排序）无法适应模型随训练进程变化的学习状态。静态策略难以区分“持续困难”与“学习不稳定”的样本，导致计算资源浪费在已掌握的简单样本上，而忽视了决定决策边界精度的困难样本。TSRL 的切入点在于将训练视为动态教学问题，通过强化学习代理实时感知模型状态并调整样本权重，从而在训练过程中动态构建最优课程。

## 核心方法

### 方法参照系

本文问题属于深度伪造检测的训练范式优化，最接近的通用流程是标准监督学习结合静态课程学习。关键差异在于，静态课程依赖预定义的难度指标（如损失值排序），而本文问题要求权重策略能随模型参数更新实时演化，以应对样本难度相对性的动态变化。

### 历史感知状态与动态加权策略

静态课程学习的失效源于其无法区分样本的“绝对难度”与“相对学习状态”。TSRL 通过构建包含历史动态的状态向量解决此问题。状态 $s_i$ 定义为：

$$ s_i = [f_i, p_i, e_i, l_i^{[ema]}, c_i^{[forget]}] $$

其中 $l_i^{[ema]}$ 为指数移动平均损失，反映长期难度；$c_i^{[forget]}$ 为遗忘计数，衡量学习不稳定性。该设计使代理能区分持续困难样本（高 $l_i^{[ema]}$）与不稳定样本（高 $c_i^{[forget]}$），从而精准分配权重。代理输出连续权重 $w_i \in [0,1]$，通过 Sigmoid 激活实现：

$$ w_i = \sigma(z_i) $$

该权重直接作用于交叉熵损失，动态重塑损失景观，迫使模型关注当前最具信息量的样本，解决了静态策略无法适应模型瞬时学习状态导致的过拟合问题。

### 状态变化奖励机制

传统基于验证集准确率的奖励信号稀疏且延迟，无法指导实时权重调整。TSRL 引入基于瞬时性能变化的密集奖励函数：

$$ r_t = c_{rew} \cdot (c_{upd} - c_{init}) + \Delta conf $$

其中 $c_{upd}$ 和 $c_{init}$ 分别为加权梯度更新前后的预测正确性，$\Delta conf$ 为置信度变化。该奖励直接激励代理选择能引发即时学习进展的权重：将错误预测翻转为正确、稳定正确预测的置信度，并惩罚导致遗忘或错误置信度增加的动作。这一机制确保了代理能发现“难但可学”样本的最优加权策略，避免了盲目关注极端困难或简单样本。

## 实验评估

实验在 DeepfakeBench 框架下进行，训练集为 FF++ (c23)，测试集包括 CDF-v2、DFD、DFDC、DFDCP（跨数据集）及 DF40（跨方法）。基线覆盖 IID、CLIP、CORE、UCF、ProDet、Effort 六种模型，并对比 F3Net、SBI 等九种 SOTA 方法。缺失频域专用方法（如 SpecXNet）的对比，可能低估了特征工程路线的贡献。

| 方法 | CDF-v2 AUC | DF40 Avg AUC |
| :--- | :--- | :--- |
| Effort | 0.886 | 0.920 |
| Effort + TSRL | 0.903 | 0.942 |
| CLIP | 0.732 | 0.653 |
| CLIP + TSRL | 0.768 | 0.674 |

TSRL 在所有基线上带来一致提升，其中 Effort + TSRL 在 DF40 上 AUC 从 0.920 提升至 0.942，CLIP + TSRL 在 CDF-v2 上从 0.732 提升至 0.768。消融实验显示，CORE + TSRL 在 DF40 上 AUC 达 0.855，显著优于 CORE + CL（0.817），证明动态策略优于静态课程。

| 方法 | DF40 AUC | DF40 ACC |
| :--- | :--- | :--- |
| CORE | 0.814 | 0.706 |
| CORE + CL | 0.817 | 0.723 |
| CORE + TSRL | 0.855 | 0.767 |

评估边界方面，论文未报告置信区间，数值比较需谨慎；未提供计算效率指标，RL 代理的额外开销未量化；代码已开源，但超参数（如 $\beta$、$c_{rew}$）的敏感性分析缺失。

## 关联研究分析

从问题动机看，TSRL 与频域特征路线（如 SpecXNet）形成互补而非竞争。SpecXNet 假设频域伪迹比空间像素更稳定，通过双域卷积捕获全局频谱特征；而 TSRL 假设训练动态失衡是泛化瓶颈，通过优化样本权重提升特征提取效率。两者差异根源在于对泛化失败归因的不同：前者归因于特征空间选择，后者归因于训练过程优化。TSRL 未否定频域特征的重要性，但其实验未包含频域专用基线，无法直接比较两种路线的相对贡献。

从方法设计看，TSRL 与 AdaptPrompt 等参数高效适配方法属于不同维度。AdaptPrompt 通过微调视觉语言模型适配未知生成器，关注推理阶段的特征对齐；TSRL 关注训练阶段的样本权重动态调整，不修改网络结构。TSRL 的 RL 代理引入额外计算开销，而 AdaptPrompt 依赖预训练模型的大规模计算。TSRL 在 DF40 上的提升幅度（+0.022 AUC）小于在 CDF-v2 上（+0.036 AUC），可能暗示跨方法泛化受限于骨干网络对新型伪造技术的特征表达能力，而非训练策略本身。

## 总结

TSRL 针对深度伪造检测中静态训练范式导致的泛化瓶颈，提出通过强化学习动态优化样本权重的解决方案。其核心在于构建历史感知状态与状态变化奖励机制，使代理能实时区分样本难度并分配最优权重。实验证明，TSRL 在 Effort 基线上将 DF40 AUC 从 0.920 提升至 0.942，在 CLIP 基线上将 CDF-v2 AUC 从 0.732 提升至 0.768。然而，论文未报告 RL 代理的计算开销，且未包含频域专用基线对比，无法排除特征工程路线的潜在优势。当骨干网络对新型伪造技术的特征表达能力达到上限时，动态课程学习的边际收益是否递减，论文未给出回答。
