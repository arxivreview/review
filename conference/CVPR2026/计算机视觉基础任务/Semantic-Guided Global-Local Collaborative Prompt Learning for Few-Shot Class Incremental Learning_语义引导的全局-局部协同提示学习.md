# CVPR2026最新论文 ｜Semantic-Guided Global-Local Collaborative Prompt Learning for Few-Shot Class Incremental Learning ｜语义引导的全局-局部协同提示学习

研究机构：华中科技大学

作者：Yongxin Yan、Weisen Chen、Xingye Chen 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_68c1204d63be)

> 少样本类增量学习（FSCIL）要求模型在仅有少量新类样本的情况下持续学习，同时避免遗忘旧类知识。现有基于视觉语言模型（VLM）的方法往往陷入稳定性与可塑性的权衡困境，即保留旧类知识时难以充分学习新类，或反之。SGLC 通过引入全局-局部双层级对齐机制，结合大语言模型（LLM）生成的语义描述进行知识蒸馏，试图在冻结旧类原型的同时增强新类的判别性特征表示。该框架在多个基准上超越了现有方法，但其对 LLM 离线生成质量的依赖及增量阶段参数更新策略的鲁棒性仍存疑。

## 研究背景

当模型面对动态变化的类别集合时，传统监督学习范式因缺乏历史数据而失效，这构成了少样本类增量学习（FSCIL）的核心困境。FSCIL 融合了类增量学习（CIL）的序列更新需求与少样本学习（FSL）的数据稀缺约束，要求模型在基础会话（Base Session）利用充足数据建立初始能力后，在增量会话（Incremental Session）中仅凭每类 5 个样本学习新类别，同时保持对旧类别的识别精度。

主流 FSCIL 方法分为数据重放、优化正则化及动态架构三类，但均受限于骨干网络表征能力的瓶颈。早期方法依赖 ResNet-18 等浅层网络，虽通过冻结浅层缓解遗忘，但限制了特征提取的判别力；近期基于预训练 ViT 的方法（如 Approxima, IVFL）虽提升了表征上限，却仍面临稳定性-可塑性（Stability-Plasticity）困境：微调以学习新类时易导致旧类特征漂移，而冻结参数则阻碍新类知识的吸收。SGLC 的切入点在于利用 VLM 的跨模态对齐能力，通过解耦全局与局部特征空间，将“保留旧类”转化为“冻结全局原型”，将“学习新类”转化为“局部属性对齐”，从而在参数高效微调中实现两者的解耦。

## 核心方法

### 方法参照系

SGLC 基于 CLIP 架构，其标准流程为：图像经视觉编码器提取特征，文本经文本编码器提取特征，通过余弦相似度计算分类概率。与常规提示学习（如 CoOp）仅优化输入层提示不同，SGLC 的关键差异在于引入了深层提示（Deep-layer Prompts）与视觉适配器（Visual Adapter），并在增量阶段实施严格的参数冻结策略，仅更新当前会话的新类参数。

### 全局-局部协同对齐机制

设计动机在于解决单一全局对齐导致的新类过拟合与旧类遗忘耦合问题。SGLC 将特征对齐解耦为全局与局部两个层级。全局层级通过视觉适配器 $f_{vo} = \sigma(f_v W_{down})W_{up} + f_v$ 调整视觉特征，并与冻结的旧类文本原型对齐，确保基础知识的稳定性。局部层级则针对新类，利用 LLM 生成的属性描述（如颜色、形状）构建局部文本提示，并通过最优传输（Optimal Transport, OT）对齐多视图视觉特征与局部文本特征。OT 距离定义为：

$$
d_{OT}(p, q; C) := \min_{T \in \Omega(p,q)} \langle T, C \rangle
$$

其中 $C$ 为基于余弦距离构建的成本矩阵，$T$ 为传输计划。该机制允许局部特征捕捉细粒度属性，避免全局特征对新类样本的过度拟合，同时通过冻结旧类全局提示，确保增量过程中旧类决策边界不变。

### 语义引导的知识蒸馏

设计动机在于缓解新类样本稀缺导致的特征表示退化。SGLC 利用 LLM 生成富含语义的类别描述，将其作为辅助监督信号。通过语义引导损失 $L_{Dist}$，将 LLM 生成的文本特征 $\tilde{f}_t$ 蒸馏至可学习的全局与局部文本特征 $f_t$：

$$
L_{Dist} = \frac{1}{C_n} \sum_{i=1}^{C_n} \| \tilde{f}_t^i - f_t^i \|_2^2 + \frac{1}{C_n} \sum_{i=1}^{C_n} \| \tilde{f}_{tl1}^i - f_{tl1}^i \|_2^2 + \frac{1}{C_n} \sum_{i=1}^{C_n} \| \tilde{f}_{tl2}^i - f_{tl2}^i \|_2^2
$$

该损失函数迫使可学习提示吸收 LLM 提供的先验知识，弥补少样本数据的语义缺失。此外，引入视觉多样性损失 $L_{div}$ 防止局部视觉特征坍缩，确保多视图特征的差异性。总损失函数为 $L_{base} = L_{CE} + \alpha L_{Dist} + \beta L_{div} + \gamma L_{zs}$，其中 $L_{zs}$ 为与零样本 CLIP 特征的一致性损失，进一步约束特征空间不偏离预训练分布。

## 实验评估

实验在 miniImageNet、CUB200 和 CIFAR100 上进行，采用 5-way 5-shot 协议。基线覆盖数据重放（IVFL）、优化正则化（OrCo, CLOSER）及 VLM 微调（Approxima, BiMC）等主流路线，但缺乏针对 LLM 蒸馏机制的专门消融对比。

| 方法 | Backbone | miniImageNet Aavg | CUB200 Aavg | CIFAR100 Aavg |
| :--- | :--- | :--- | :--- | :--- |
| Approxima | ViT-B-CLIP | 92.61 | 79.12 | 81.38 |
| IVFL | ViT-B-CLIP | 93.62 | 77.81 | 78.89 |
| SGLC (Ours) | ViT-B-CLIP | 95.12 | 80.18 | 84.57 |

SGLC 在三个数据集上均取得最优平均准确率（Aavg），其中在 CIFAR100 上较 Approxima 提升 3.19 个百分点，表明其在复杂背景下的鲁棒性优势。

| 组件 | CUB200 Abase | CUB200 Anavg | CUB200 Aavg |
| :--- | :--- | :--- | :--- |
| CLIP (Zero-shot) | 65.54 | 57.34 | 58.09 |
| CoOp | 83.85 | 68.03 | 69.47 |
| + Deep-layer prompts | 85.32 | 69.81 | 71.22 |
| + Visual feature correction | 84.23 | 69.36 | 70.72 |
| SGLC (Full) | 85.41 | 71.24 | 72.53 |

消融实验显示，深层提示与视觉适配器的引入显著提升了基础会话精度（Abase），而全局-局部协同对齐与语义蒸馏进一步提升了增量会话的平均精度（Anavg），验证了双层级机制对稳定性与可塑性的独立贡献。

评估边界方面，论文未报告计算开销与推理延迟，仅关注准确率。可复现性方面，提供了详细超参数（如 $\alpha=500, \beta=50$），但未公开代码。指标上，Aavg 可能受基础会话高准确率驱动，Anavg 更能反映增量能力，但两者均缺乏置信区间报告。

## 关联研究分析

从问题动机看，SGLC 与 Approxima 均基于 VLM 解决 FSCIL，但 Approxima 侧重全局特征微调，而 SGLC 引入局部属性对齐。差异根源在于任务特性：Approxima 假设全局特征足以区分新类，而 SGLC 认为新类样本稀缺时，全局特征易受背景干扰，需局部属性（如颜色、形状）提供额外判别信息。这种解耦策略在 CUB200 等细粒度数据集上表现更优，但在 CIFAR100 等粗粒度数据集上，局部属性的增益是否显著，论文未给出深入分析。

从方法设计看，SGLC 与文本分类领域的提示工程优化（如 LOADS）有相似之处，均利用 LLM 增强语义理解。但 SGLC 将 LLM 输出作为离线蒸馏目标，而非推理时动态提示，这避免了推理时的 LLM 调用成本，符合效率共识。然而，离线蒸馏可能无法捕捉增量新类的动态语义变化，尤其是当新类与旧类语义重叠度高时，LLM 生成的静态描述可能引入偏差。这种离线-在线语义更新的滞后性，是 SGLC 与实时提示优化方法的核心差异，也是其潜在局限。

## 总结

SGLC 旨在解决 FSCIL 中稳定性与可塑性的矛盾，通过全局-局部解耦对齐与 LLM 语义蒸馏，实现了旧类知识的冻结保留与新类特征的精细学习。实验表明，SGLC 在 CUB200 上达到 80.18% 的 Aavg，较 SOTA 提升 1.06 个百分点，验证了双层级机制的有效性。然而，论文未报告计算效率，且 LLM 离线蒸馏对动态新类语义的适应性未充分验证。当增量会话中引入与旧类语义高度重叠的新类时，离线生成的静态描述是否足以引导局部对齐，论文未给出回答。
