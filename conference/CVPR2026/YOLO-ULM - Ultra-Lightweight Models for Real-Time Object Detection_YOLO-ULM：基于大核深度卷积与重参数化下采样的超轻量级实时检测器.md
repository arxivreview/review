# CVPR2026最新论文 ｜YOLO-ULM: Ultra-Lightweight Models for Real-Time Object Detection ｜YOLO-ULM：基于大核深度卷积与重参数化下采样的超轻量级实时检测器

作者：Shasha Han、Chong Li、Xinning Wang 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_5ed04be04b72)

> 实时目标检测在边缘部署中面临算力受限与精度需求的双重约束，现有轻量化方法往往通过激进的结构压缩牺牲特征表达能力，导致小目标与复杂场景下的性能显著下降。YOLO-ULM 针对这一矛盾，通过引入大核深度卷积聚合模块与可重参数化并行下采样结构，在保持骨干网络语义完整性的前提下降低计算冗余。该架构配合非线性难度感知的损失函数，实现了在同等算力下更高的检测精度。尽管其在轻量级 CNN 区间表现优异，但缺乏端到端 NMS-free 机制与预训练权重支持，限制了其在复杂动态场景下的泛化潜力。

## 研究背景

实时检测的核心挑战在于如何在毫秒级延迟约束内平衡定位精度与计算成本。传统单阶段检测器如 YOLO 系列确立了“骨干-颈部-头部”范式，但静态计算模式导致简单场景下的算力冗余。特征提取模块（如 C2f、C3k2）虽能聚合多尺度信息，但其内部的全卷积操作在深层网络中引发参数爆炸与感受野受限的双重问题。下采样阶段的标准卷积操作进一步加剧了高频信息丢失，而现有的 IoU 变体损失函数缺乏对难易样本分布的自适应调节，导致训练过程中的梯度不稳定。

YOLO 系列在精度与速度的权衡上长期占据主导地位，但近期版本（如 YOLOv12）引入的注意力机制虽提升了建模能力，其二次计算复杂度与内存访问瓶颈却制约了实时性能。在同等计算量下，基于 CNN 的架构比注意力变体快 3 倍，但现有轻量化手段（如结构重组、参数压缩）往往以显著的精度损失为代价。YOLO-ULM 的切入点在于识别出特征融合、下采样与损失函数这三个环节中的具体效率瓶颈，通过模块级重构而非范式转换，解决静态架构中“计算冗余”与“信息丢失”并存的结构性矛盾。

## 核心方法

### 方法参照系

YOLO-ULM 基于 YOLOv12 架构，保留其骨干-颈部-头部范式，但针对深层网络中的特征聚合与空间变换环节进行替换。与标准 YOLO 流程的关键差异在于，本文将 C2f 模块替换为基于大核深度卷积的 D3C2f，将标准下采样卷积替换为可重参数化的 RepDown，并引入 FoCIoU 损失函数以优化回归过程。

### 大核深度卷积特征聚合

D3C2f 模块旨在解决深层网络中全卷积操作导致的计算冗余与感受野受限问题。该模块采用切片计算策略，将中间特征图分为两部分：一部分直接送入拼接块，另一部分经过多个 D3 块处理。D3 块由 $1 \times 1$ 逐点卷积与 $3 \times 3$ 深度卷积组成的解耦结构，以及一个 $7 \times 7$ 大核深度卷积构成，后者用于扩展感受野以捕获高层语义。其参数复杂度为 $O(4.5C^2 + 67C)$，计算复杂度为 $O(4.5HWC^2 + 67HWC)$，相比 C2f 的 $O(7HWC^2)$ 降低了 35.7% 的计算量。这种设计通过解耦空间与通道交互，在降低峰值 GPU 内存消耗的同时，增强了全局表征学习能力。

### 可重参数化并行下采样

RepDown 模块针对标准卷积下采样中参数冗余与高频信息丢失的问题，设计了通道空间双解耦机制。训练阶段，该模块包含两条并行路径：主路径使用 $7 \times 7$ 深度卷积（步长 2）进行大规模空间预聚合，辅助路径使用 $3 \times 3$ 深度卷积保留边缘纹理等高频成分。两条路径通过逐元素求和融合，参数复杂度从标准卷积的 $O(18C^2)$ 降至 $O(2C^2 + 128C)$。推理阶段，通过零填充对齐核大小并合并权重，将双分支结构重参数化为等价的单分支 $7 \times 7$ 深度卷积。这一机制在保持多尺度特征提取能力的同时，实现了线性参数增长，显著降低了深层大通道数下的计算开销。

### 非线性难度感知损失函数

FoCIoU 损失函数旨在解决 CIoU 在难易样本分布不均时的训练不稳定问题。该函数保留了 CIoU 的几何约束项，并引入基于 Focaler-IoU 的非线性区间映射项 $IoU_{MF}$。其核心公式为：

$$ l_{FoCIoU} = 1 - CIoU + (IoU - IoU_{MF}) $$

其中 $IoU_{MF}$ 通过参数 $\beta=2$ 实现非线性难度感知。对于高 IoU 的简单样本，差值项趋近于 0，梯度消失以避免过拟合；对于低 IoU 的困难样本，差值项趋近于 1，梯度放大以增强关注。这种动态梯度调制机制在无需额外参数与 FLOPs 的情况下，实现了对回归过程的样本自适应优化。

## 实验评估

YOLO-ULM 在 COCO 数据集上从头训练，对比基线涵盖 YOLOv6-v13 及 RT-DETR，但未包含 DEIMv2 等基于 Transformer 的最新 SOTA 方法。在 N 尺度下，YOLO-ULM 以 2.1M 参数和 6.4G FLOPs 达到 41.6% mAP，与 YOLOv13-N 持平但延迟降低 22.8%。S 尺度下，YOLO-ULM-S 以 7.4M 参数达到 48.1% mAP，优于 YOLOv11-S 1.2 个点，且 FLOPs 更低。

| :--- | :--- | :--- | :--- | :--- |
| YOLOv11-N | 6.5 | 2.6 | 39.4 | 1.5 |
| YOLOv12-N | 6.5 | 2.6 | 40.6 | 1.64 |
| YOLOv13-N | 6.5 | 2.5 | 41.6 | 1.97 |
| YOLO-ULM-N | 6.4 | 2.1 | 41.6 | 1.52 |

消融实验显示，D3C2f 在 N 变体上提升 0.2% mAP，RepDown 降低 19.2% FLOPs 的同时提升 0.1% mAP。FoCIoU 相比 CIoU 提升 0.2% mAP，验证了其对困难样本的敏感性。值得注意的是，RepDown 的 7x7 核在 M 变体上比 5x5 核提升 0.3%-0.4% mAP，表明大核深度卷积在深层网络中的语义捕获优势。

评估协议基于 T4 GPU 的 TensorRT FP16 推理，未报告 CPU 端的最坏情况延迟分布。代码未公开，超参数（如 SGD 动量 0.937）虽已披露，但缺乏跨硬件的统一评测。由于从头训练未使用预训练权重，其精度上限可能受限于特征初始化的质量，这在对比 DEIMv2 等利用大规模预训练的方法时尤为明显。

## 关联研究分析

从方法设计看，YOLO-ULM 与 RT-DETR 代表了实时检测的两条不同路径。RT-DETR 通过全局注意力消除 NMS 后处理，实现端到端优化，但其计算复杂度限制了在超轻量级模型中的应用。YOLO-ULM 坚持 CNN 路线，通过大核深度卷积局部增强感受野，虽未实现 NMS-free，但在同等算力下获得了更高的推理速度。这种差异源于任务特性：YOLO-ULM 更关注边缘设备的确定性延迟，而 RT-DETR 侧重训练流程的统一性。YOLO-ULM 保留 NMS 是否限制了其在复杂重叠场景下的端到端优化潜力，论文未给出回答。

从问题动机看，YOLO-ULM 与 YOLOv10 均致力于解决静态计算冗余，但切入点不同。YOLOv10 通过双分配策略实现无 NMS 训练，侧重于标签分配的效率；YOLO-ULM 则聚焦于特征提取与下采样模块的计算效率，通过重参数化技术降低推理开销。YOLO-ULM 的 FoCIoU 损失函数引入了非线性难度感知，这与 YOLOv10 的静态损失函数形成对比。这种差异暗示了损失函数设计在轻量化模型中的重要性，但 YOLO-ULM 未探索动态计算分配（如 MoE）与损失函数优化的协同效应，这可能是一个未触及的盲区。

## 总结

YOLO-ULM 旨在解决实时检测中静态架构的计算冗余与特征信息丢失矛盾，通过大核深度卷积与重参数化下采样实现模块级效率优化。该架构在 N 尺度下以 2.1M 参数达到 41.6% mAP，S 尺度下以 7.4M 参数达到 48.1% mAP，验证了其在轻量级 CNN 区间的有效性。然而，其从头训练且未采用 NMS-free 机制的设计，限制了其在复杂场景下的泛化能力与端到端优化潜力。当支持集增大或场景复杂度提升时，静态 CNN 架构与动态 Transformer 架构在精度-能效帕累托前沿上的相对优势是否会发生逆转，论文未给出回答。
