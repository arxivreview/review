# CVPR2026最新论文 ｜R$^2$TUA: Reconstruction-residual Based Targeted and Untargeted Attack Against Text-Image Person Re-Identification ｜重建残差驱动的多模态对抗攻击

研究机构：中国科学技术大学、香港中文大学

作者：Yubo Wang、Yan Lu、Bin Liu 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_5b29d8582003)

> 文本-图像行人重识别（TI-ReID）系统面临细粒度属性语义被扰动的安全威胁，而现有视觉-语言预训练（VLP）或传统重识别（ReID）攻击因粒度不匹配而失效。本文切入点在于利用重建残差策略，在潜空间注入对抗文本语义以生成不可见扰动。R2TUA通过渐进多模态融合与软钳位函数实现精准攻击，证明了TI-ReID在细粒度对齐下的脆弱性。其价值在于填补了TI-ReID安全研究空白，但攻击的防御机制与泛化边界仍存疑。

## 研究背景

监控场景中，当目标图像缺失时，TI-ReID通过自然语言描述检索行人图像，其核心挑战在于视觉像素的连续性与文本序列的离散性之间的跨模态语义鸿沟。主流模型如RaSa和APTM采用对齐-融合架构，先通过对比学习建立全局嵌入空间，再利用交叉注意力生成细粒度匹配概率。这种细粒度对齐虽提升了检索精度，但也引入了新的攻击面：攻击者需破坏属性级语义（如衣着、颜色）而非仅扰动外观细节。

传统ReID攻击聚焦于属性无关的几何特征，VLP攻击则针对粗粒度图文对齐，两者均无法有效干扰TI-ReID的属性特定查询。例如，VLP攻击针对“A walking woman”这类粗描述，而TI-ReID需处理“A man wears glasses, a red shirt...”等细粒度描述。这种任务特性的差异导致现有攻击方法在TI-ReID上表现不佳，亟需一种能同时处理图像与文本模态、并针对细粒度属性进行精准注入的对抗攻击框架。

## 核心方法

### 方法参照系

TI-ReID攻击需同时破坏对齐阶段的全局匹配与融合阶段的细粒度重排序。标准流程通常直接生成扰动或优化通用对抗扰动（UAP），但本文指出，直接生成易引入高频噪声，且UAP无法利用文本模态信息。本文的关键差异在于采用重建残差（R2）策略，将对抗语义注入潜空间后再提取扰动，以实现不可见性与有效性的平衡。

### 渐进多模态融合与重建残差

在重建阶段，ViT编码器将图像编码为补丁潜变量，BERT编码器将对抗提示编码为提示潜变量。设计动机在于解决直接生成扰动时高频噪声过大导致扰动可见的问题。本文提出Transformer-based Gradual Multimodal Fusion (TGMF)，通过缩放因子 $\eta$ 动态控制每层Transformer的跨模态注意力权重，实现属性级细粒度融合。重建图像 $\hat{I}$ 由反卷积模块生成，扰动 $\delta$ 通过残差计算获得：

$$ \delta = \hat{I} - I $$

该公式确保扰动保留主要图像结构并抑制无关噪声，避免了直接生成方法中的高频差异。TGMF的 $\eta$ 值在0.9时达到帕累托最优，平衡了无目标与有目标攻击性能。

### 软钳位函数与双阶段损失

在扰动生成阶段，设计动机在于避免传统钳位函数导致的梯度消失，同时保持扰动在阈值内不变形。本文提出完全可微的Soft Clamp Function (SCF)：

$$ C(x) = \frac{\epsilon x}{\epsilon^{2n} + x^{2n}} $$

其中 $n$ 为平滑温度，$\epsilon$ 为扰动阈值。SCF允许梯度在 $|x| > \epsilon$ 区域回传，避免局部极小值。训练采用Push-Pull Losses (PPLs) 攻击对齐阶段，最大化扰动图像与真实描述的差异，最小化与对抗提示的差异；Matching Losses 攻击融合阶段，误导重排序模块。总损失为：

$$ L = \alpha L_{PPLs} + (2-\alpha) L_{MtLs} $$

该双阶段损失设计确保了攻击同时破坏TI-ReID的全局对齐与细粒度重排序能力。

## 实验评估

| 目标模型 | 数据集 | 攻击类型 | R@1 (%) | mAP (%) |
| :--- | :--- | :--- | :--- | :--- |
| RaSa | CUHK-PEDES | Untargeted | 0.11 | 0.60 |
| RaSa | CUHK-PEDES | Targeted | 89.43 | 54.89 |
| IRRA | CUHK-PEDES | Untargeted | 0.58 | 1.07 |
| APTM | CUHK-PEDES | Untargeted | 0.54 | 2.13 |

实验在CUHK-PEDES、ICFG-PEDES和RSTP-ReID三个数据集上，针对RaSa、APTM和IRRA三个主流TI-ReID模型进行评估。基线包括VLP攻击（SGA, AnyAttack）和ReID攻击（MisRanking, MTGA）。R2TUA在无目标攻击中将RaSa的R@1从76.51%降至0.11%，在有目标攻击中达到89.43% R@1，显著优于所有基线。这表明R2TUA能有效破坏TI-ReID的细粒度对齐能力，且对对齐-融合模型的攻击效果优于纯对齐模型。

| 模块 | Untargeted R@1 (%) | Targeted R@1 (%) |
| :--- | :--- | :--- |
| Baseline | 34.09 | 21.26 |
| + TA | 12.03 | 5.53 |
| + R2 | 10.23 | 40.76 |
| + SCF | 9.61 | 45.12 |
| + PPLs | 3.24 | 63.18 |
| + MtLs | 0.11 | 89.43 |

消融实验显示，引入对抗提示（TA）和无目标攻击（R2）是性能提升的关键，分别将无目标R@1降至12.03%和10.23%。SCF的引入进一步优化了无目标攻击至9.61%，而PPLs和MtLs的联合使用最终将无目标R@1降至0.11%，有目标R@1提升至89.43%。这表明双阶段损失设计对攻击有效性至关重要，且SCF在避免局部极小值方面发挥了作用。

评估边界方面，实验仅使用白盒设置，未充分验证黑盒迁移攻击的鲁棒性。虽然论文提供了黑盒迁移实验，但 $\epsilon$ 从8/255放宽至16/255，可能影响实际部署中的不可见性。代码未公开，超参数如 $\eta$ 和 $\alpha$ 的敏感性分析显示，$\eta=0.9$ 和 $\alpha=1$ 为最优，但不同模型间的泛化能力仍需进一步验证。

## 关联研究分析

从问题动机看，R2TUA与RaSa等细粒度对齐方法形成对立。RaSa通过交叉注意力提升检索精度，而R2TUA利用相同的细粒度机制注入对抗语义，揭示了细粒度对齐在安全层面的脆弱性。这种差异源于任务特性：检索任务追求特征区分度，而攻击任务追求特征混淆度。R2TUA的TGMF机制通过缩放注意力权重，实现了属性级语义的精准注入，这是传统ReID攻击无法做到的。

从方法设计看，R2TUA与AnyAttack等VLP攻击方法存在显著差异。AnyAttack针对粗粒度图文对齐，而R2TUA针对细粒度属性语义。R2TUA的SCF函数解决了VLP攻击中常见的梯度消失问题，使得扰动在阈值内保持不可见。这种设计差异源于TI-ReID任务的细粒度特性，要求攻击扰动必须精确作用于属性相关区域，而非全局图像。

## 总结

TI-ReID系统面临细粒度属性语义被扰动的安全威胁，现有VLP或ReID攻击因粒度不匹配而失效。R2TUA通过重建残差策略和渐进多模态融合，在潜空间注入对抗文本语义，实现了不可见且有效的攻击。实验证明R2TUA能将RaSa的无目标R@1降至0.11%，有目标R@1提升至89.43%，显著优于基线。然而，实验仅验证了白盒攻击的有效性，黑盒迁移攻击中 $\epsilon$ 的放宽可能影响实际部署中的不可见性。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
