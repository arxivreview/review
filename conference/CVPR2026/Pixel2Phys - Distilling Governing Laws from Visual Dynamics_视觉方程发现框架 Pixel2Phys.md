> 视觉方程发现旨在从原始视频流中直接提取低维物理变量并推导其符号化动力学方程，以解决现有黑盒模型缺乏可解释性及参数估计方法依赖先验方程的局限。现有方法受限于变量提取与方程发现的循环依赖，导致在复杂视觉场景中难以收敛至简洁且准确的物理规律。Pixel2Phys 通过多智能体协作与迭代共优化机制，将视觉解析、符号回归与数值验证解耦为独立模块，实现了从像素到物理定律的自动化蒸馏。该框架在长时程外推精度上优于基线，但其对 2D 投影假设的依赖及缺乏 3D 几何约束的验证，限制了其在复杂遮挡场景下的泛化能力。

## 研究背景

从视频推断物理定律的核心困境在于高维像素空间与低维物理结构之间的维度失配。原始视频帧 $X(t) \in \mathbb{R}^D$ 包含大量纹理、光照等视觉冗余信息，而支配系统演化的物理状态 $z(t) \in \mathbb{R}^d$ 仅占据一个内在低维流形，其中 $d \ll D$。这种失配导致直接对像素进行回归或预测时，模型往往拟合到视觉上显著但物理上无关的特征，无法提取出简洁的符号化动力学方程 $f$。

传统视觉物理推理主要沿两条路线展开：一是隐式神经动力学，如 Neural ODE 和 Koopman 算子，它们通过学习潜空间表示进行未来预测，但将物理定律封装在黑盒网络中，缺乏显式可解释性；二是物理信息感知，通过逆图形学或刚体约束估计质量、摩擦等参数，但这类方法严重依赖对支配方程的先验知识，无法发现未知物理现象中的新规律。此外，基于符号回归的端到端方法面临循环依赖：提取良好的变量空间需要知道动力学，而发现动力学又需要干净的变量空间。Pixel2Phys 的切入点在于打破这一循环，通过结构化的多智能体工作流，实现变量提取与方程发现的相互精炼。

## 核心方法

### 多智能体协作架构

视觉方程发现任务缺乏公认的标准流程，最接近的通用范式是“轨迹提取-符号回归”流水线。本文的关键差异在于引入了一个由 Plan Agent 协调的迭代闭环，将变量提取、方程生成与实验验证解耦为三个独立智能体，通过报告机制实现全局诊断与局部修正，而非单向的数据流动。

### 物理信息自编码器与变量精炼

变量提取环节通常依赖预训练分割模型或自监督潜空间编码，但前者难以处理连续场，后者易纠缠视觉无关因素。Pixel2Phys 的 Variable Agent 采用多粒度工具，其中针对复杂现象的物理信息自编码器是关键创新。其损失函数定义为：

$$ L = L_{recon} + \lambda_{eq} L_{eq}, \quad L_{eq} = \| F(z) - f(z) \|^2 $$

其中 $F(z)$ 为通过中心差分计算的数值导数，$f(z)$ 为上一轮迭代发现的符号方程导数。该设计动机在于利用已发现的方程作为物理先验，强制潜空间 $z$ 遵循动力学约束，从而过滤纹理噪声。当诊断指出变量提取存在离群点时，Plan Agent 会注入此损失，使编码器从单纯的重构转向动态一致性优化，解决了自监督潜空间非唯一且易过拟合视觉细节的问题。

### 稀疏符号回归与迭代共优化

方程发现环节通常使用 SINDy 等稀疏回归算法，但传统方法在变量空间不纯净时易陷入局部最优。Equation Agent 动态调整稀疏约束强度 $\lambda_{sp}$ 和符号库，求解目标：

$$ \min_{\Xi} \| \dot{Z} - \Theta(Z)\Xi \|_2^2 + \lambda_{sp} \|\Xi\|_1 $$

其中 $\Theta(Z)$ 为候选函数库，$\Xi$ 为稀疏系数矩阵。这一创新的价值在于，Plan Agent 根据 Experiment Agent 的 $R^2$ 分数和方程复杂度报告，动态调整 $\lambda_{sp}$。当方程过于复杂时，增大惩罚系数以抑制过拟合；当重构误差高时，则回溯至 Variable Agent 进行变量精炼。这种双向反馈机制打破了“变量-方程”的循环依赖，使系统能逐步收敛至最简洁且拟合度最高的物理定律。

## 实验评估

实验在轨迹、物理场和内在动力学三类视频上进行，基线包括监督方程预测、无监督潜空间编码及直接 MLLM 提示。由于论文未提供详细的逐字实验数值表格，且【论文实验数据】区仅包含定性描述与单一百分比指标，无法构建符合逐字引用要求的实验表格。核心结果显示，Pixel2Phys 在长时程外推精度上比基线方法降低了 45.35% 的均方根误差（RMSE），表明其发现的符号方程在长期预测中保持了稳定性，而基线方法迅速发散。

消融实验未提供详细数值，但设计决策验证显示，物理信息自编码器的引入显著提升了变量提取的鲁棒性。在冷启动阶段，自编码器仅执行自监督重构；在迭代阶段，引入 $L_{eq}$ 后，潜空间开始对齐动力学结构。这一转变表明，物理先验的注入是打破视觉冗余干扰的关键，而非单纯的模型容量增加。此外，Plan Agent 的诊断机制在识别“变量离群”与“方程过拟合”两种失效模式时表现出明确的策略分化，前者触发变量重提取，后者触发稀疏度调整，验证了迭代闭环的有效性。

评估边界方面，论文主要依赖 RMSE 和 $R^2$ 分数，缺乏对物理属性（如质量、摩擦）估计精度的直接量化，这与 QuantiPhy 等基准的评估协议不同。可复现性方面，论文未提供代码 URL，且 Segment Anything 和 SINDy 的具体超参数配置未在正文中完全披露，可能影响结果的复现。此外，实验视频多为模拟或受控场景，真实世界噪声下的表现未充分验证。

## 关联研究分析

从问题动机看，Pixel2Phys 与 PhysGS 等 3D 表征方法存在根本差异。PhysGS 旨在从视频中估计质量、硬度等具体物理参数，依赖 3DGS 显式几何结构，其目标是“参数估计”；而 Pixel2Phys 旨在发现支配方程 $f$，其目标是“结构发现”。PhysGS 在 ABO-500 基准上实现了 61.2% 的硬度误差降低，但无法输出可解释的符号方程。Pixel2Phys 的 2D 轨迹提取策略在复杂遮挡场景下可能失效，因为 2D 投影丢失了深度信息，而 3D 表征能提供更丰富的几何约束。这一差异源于任务特性：参数估计需要精确的几何定位，而方程发现更关注动态演化模式，但 2D 假设在真实世界中的鲁棒性存疑。

从方法设计看，Pixel2Phys 的多智能体迭代与 IPR-1 等交互式物理智能体有相似之处，但反馈机制不同。IPR-1 通过强化学习在环境中试错，奖励来自任务达成；Pixel2Phys 的反馈来自数值模拟与重构误差，属于离线闭环。IPR-1 依赖 1000+ 游戏的预训练数据，其性能提升难以完全归因于交互式机制本身；Pixel2Phys 则通过 MLLM 的通用推理能力协调流程，无需大规模特定物理数据预训练。然而，Pixel2Phys 依赖 MLLM 的单步推理能力，若 MLLM 在符号回归或数值模拟上存在幻觉，可能误导整个迭代过程。这种对 MLLM 能力的依赖是潜在盲区，论文未探讨 MLLM 推理错误对最终方程发现的影响。

## 总结

Pixel2Phys 解决了从视觉流中解耦低维物理变量并发现符号动力学方程的核心矛盾，通过多智能体协作打破了变量提取与方程发现的循环依赖。其切入点在于利用 MLLM 的规划能力协调物理信息自编码器与稀疏符号回归，实现了从像素到物理定律的自动化蒸馏。实验证明，该框架在长时程外推精度上比基线降低了 45.35% 的 RMSE，验证了符号方程在长期预测中的稳定性。然而，论文主要依赖 2D 轨迹与像素级场，未显式利用 3D 几何约束，且在真实世界噪声下的鲁棒性未充分验证。当视频包含复杂遮挡或深度歧义时，2D 投影下的变量提取是否仍能收敛至正确的物理流形，论文未给出回答。
