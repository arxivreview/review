# CVPR2026最新论文 ｜Identity-Preserving Image-to-Video Generation via Reward-Guided Optimization ｜基于奖励引导优化的身份保持图像到视频生成

研究机构：华中科技大学、阿里巴巴集团

作者：Liao Shen、Wentao Jiang、Yiran Zhu 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.14255)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.14255)

> 图像到视频（I2V）生成中的身份保持旨在从静态输入图像合成时序连贯且面部特征一致的视频，但现有模型在小脸与大运动场景下常出现身份漂移。传统方法依赖架构注入或监督微调，前者破坏基础模型结构，后者受限于曝光偏差导致误差累积。本文提出身份保持奖励引导优化（IPRO），通过强化学习直接优化扩散模型参数，利用面部奖励信号替代显式特征注入。该方法在不改变架构的前提下显著提升了小脸场景下的身份一致性，但其对通用大脸场景的泛化能力及多身份扩展性尚存疑。

## 研究背景

当输入图像中的人脸占据极小像素区域且提示词涉及大幅动作时，视频扩散模型在去噪过程中无法维持面部细节，导致生成视频中的人物逐渐偏离初始帧外观。这一现象源于误差在帧间的传播，即时序身份漂移。解决该问题通常依赖身份注入机制，如将ArcFace嵌入通过交叉注意力注入潜空间，但I2V模型的首帧已包含完整身份信息，额外注入不仅冗余，且架构侵入式模块难以扩展至多主体场景。

主流I2V身份保持方法分为两类：一类是架构注入式，如Concat-ID和MoCA，通过拼接参考面部令牌或潜空间损失约束身份，但此类方法在I2V中会破坏基础模型的原始结构；另一类是监督微调（SFT），通过教师强制训练，但训练时依赖真实中间状态，推理时依赖自生成状态，这种分布差异导致曝光偏差，使小误差在长序列中累积为身份跳跃。IPRO的切入点在于利用强化学习（RL）的在策略（on-policy）训练特性，从纯噪声初始化轨迹，直接优化身份奖励，从而对齐训练与推理分布，消除曝光偏差对身份保持的损害。

## 核心方法

### 奖励引导的轨迹优化

I2V身份保持的通用流程通常涉及在扩散模型中嵌入身份适配器或引入辅助损失函数。IPRO的关键差异在于摒弃了显式特征注入，转而将身份保持建模为奖励最大化问题。该方法利用ArcFace作为可微分奖励模型，计算生成视频帧与真实视频帧嵌入的余弦相似度作为奖励信号。

$$ \theta^* = \arg\max_\theta \mathbb{E}_{x_T \sim \mathcal{N}(0, I)} [R_{face}(\text{sample}(\theta, x_T))] $$

该公式表明，模型参数通过最大化从纯噪声采样生成的视频的身份奖励来更新。设计动机在于解决SFT中的曝光偏差：通过从随机噪声开始生成并学习，训练分布与推理分布一致，直接优化长期身份一致性目标。为降低计算成本，采用DRaFT截断策略，仅通过最后 $K$ 步去噪过程反向传播梯度，因为低噪声阶段对面部细节影响最大。

### 多视角面部评分机制

直接优化面部相似度易导致奖励黑客（reward hacking），即生成视频过度贴合输入图像，导致表情僵硬。IPRO引入面部评分机制（FSM），将真实视频中的所有帧面部作为参考池，计算生成帧与参考池中所有帧的平均相似度。

$$ R_{face} = \frac{1}{F'} \sum_{i=1}^{F'} \left( \frac{1}{F} \sum_{j=1}^{F} \cos(\phi(\hat{x}_i), \phi(x_j)) \right) $$

其中 $\phi$ 为面部编码器，$F$ 为真实帧数，$F'$ 为生成帧数。此设计解决了单一参考帧导致的复制粘贴现象，通过提供多角度面部信息，鼓励生成视频在保持身份的同时允许自然的表情和姿态变化。

### 多步KL散度正则化

为防止模型过度拟合奖励信号而丧失原始生成能力，IPRO在反向采样轨迹上引入多步KL散度正则化。

$$ \mathcal{L}_{KL} = \sum_{t=1}^{T} \omega_t D_{KL}(p_\theta(x_{0:t}) || p_{\theta_{ref}}(x_{0:t})) $$

该正则化约束优化模型 $\theta$ 与原始模型 $\theta_{ref}$ 在每一步的分布偏差。设计动机在于平衡身份提升与模型通用性，实验显示无KL正则化时KL散度迅速上升且波动剧烈，而加入正则化后散度保持低且稳定，有效抑制了面部僵化现象。

## 实验评估

| 方法 | FaceSim | SC | BC | AQ |
| :--- | :--- | :--- | :--- | :--- |
| Wan 2.2 A14B | 0.5780 | 0.9508 | 0.9705 | 0.6588 |
| **IPRO (Wan 2.2 A14B)** | **0.6942** | 0.9536 | 0.9720 | 0.6607 |
| MoCA† | 0.5820 | - | - | - |
| Concat-ID† | 0.6056 | - | - | - |

实验在小脸评估集（600场景）上进行，基线包括Wan 2.2系列及适配至I2V的T2V方法MoCA和Concat-ID。IPRO在Wan 2.2 A14B上将FaceSim从0.5780提升至0.6942，且VBench-I2V的其他质量指标（如SC、BC）未出现下降，表明身份提升未以牺牲视频质量为代价。

| 配置 | FaceSim | Hacking Rate |
| :--- | :--- | :--- |
| W/o KL | 0.7544 | 58% |
| W/o FSM | 0.7388 | 52% |
| **IPRO** | **0.6942** | **10%** |

消融实验显示，移除KL正则化或FSM虽能进一步提升FaceSim至0.7544和0.7388，但奖励黑客率分别激增至58%和52%。完整IPRO将黑客率控制在10%，证明了FSM和KL正则化在平衡身份保真与生成多样性中的关键作用。此外，相比SFT（FaceSim 0.6392）和CLIP奖励（FaceSim 0.6099），ArcFace奖励引导的IPRO表现最优，验证了细粒度面部嵌入作为奖励信号的有效性。

评估边界方面，实验仅在小脸场景（最大人脸框≤100×100像素）上验证，未涵盖大脸或通用场景。代码与超参数已公开，但训练依赖Wan 2.2-Lightning蒸馏模型，复现需特定基础设施。

## 关联研究分析

从问题动机看，IPRO与Lynx等基于Wan 2.1的ID-adapter方法形成鲜明对比。Lynx通过额外的交叉注意力模块注入身份嵌入，属于架构侵入式方法，而IPRO认为I2V中身份已存在于首帧，额外注入是冗余的，转而通过RL优化解决时序漂移。这一差异源于任务特性：T2V缺乏首帧条件，必须注入身份；I2V具备首帧条件，核心挑战是保持而非注入。IPRO的RL方法天然支持多主体场景，而架构注入式方法通常限于单主体，这是任务结构决定的优势。

从方法设计看，IPRO与MagicID等使用DPO的方法不同。MagicID依赖人类偏好数据，优化相对排序，易受美学等混淆因素干扰；IPRO使用ArcFace提供绝对校准的密集奖励信号，更适合可量化的面部身份一致性任务。GRPO因单提示下响应多样性低而效率受限，IPRO的直接奖励优化避免了组内优势估计的失效。这种选择反映了面部身份作为可微分奖励信号的适用性，而非RL范式的普遍优越性。

## 总结

IPRO旨在解决I2V生成中小脸场景下的时序身份漂移问题，其切入点在于利用RL的在策略训练消除SFT的曝光偏差，并通过面部奖励直接优化身份一致性。该方法在不改变架构的前提下，将Wan 2.2 A14B的FaceSim从0.5780提升至0.6942，同时将奖励黑客率控制在10%。然而，实验仅在小脸评估集上进行，未验证大脸场景或通用视频生成的性能，且依赖特定蒸馏模型进行训练。当输入图像中人脸占据较大比例时，RL奖励优化是否仍优于架构注入式方法，论文未给出回答。
