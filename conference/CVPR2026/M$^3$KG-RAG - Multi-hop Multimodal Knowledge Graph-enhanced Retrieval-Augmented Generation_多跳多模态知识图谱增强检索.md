# CVPR2026最新论文 ｜M$^3$KG-RAG: Multi-hop Multimodal Knowledge Graph-enhanced Retrieval-Augmented Generation ｜多跳多模态知识图谱增强检索

研究机构：韩国高丽大学、韩国成均馆大学

作者：Hyeongcheol Park、Jiyoung Seo、Jaewon Mun 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.20136)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.20136)

> 多模态大语言模型在处理视听任务时，常因共享嵌入空间的模态间隙导致检索噪声，且现有知识图谱多为单跳结构，无法支撑时序因果推理。M[3] KG-RAG 通过构建多跳多模态知识图谱并引入接地选择性剪枝机制，解决了证据链断裂与上下文冗余问题。该方法利用多智能体流水线构建图谱，并通过视觉与音频接地模型过滤无关三元组。其在 AudioCaps-QA 上取得 53.23 的 Model-as-Judge 分数，但在视频与视听融合任务上未超越强骨干端到端模型，表明结构化检索对弱骨干增益显著，对强骨干存在性能天花板。

## 研究背景

当多模态大语言模型（Multimodal Large Language Models, MLLMs）面对视听查询时，直接利用共享嵌入空间进行检索常因模态间隙（Modality Gap）而失效。模态间隙指不同模态（如音频与文本）在统一嵌入空间中的距离分布未对齐，导致跨模态相似度计算产生偏差，检索结果往往包含视觉相关但事实无关的噪声。为缓解此问题，多模态知识图谱（Multimodal Knowledge Graph, MMKG）被引入，旨在通过实体-关系结构组织跨模态知识。然而，现有 MMKG 多聚焦于图像-文本对，缺乏对音频流及视频时序因果关系的覆盖，且检索策略仍依赖简单的向量相似度，无法区分“与查询相关”与“对答案有用”的知识，导致 MLLM 上下文被冗余信息污染。

该领域的核心矛盾在于：静态参数化知识无法覆盖长尾实体，而动态检索又受限于多模态语义鸿沟与证据链断裂。主流路线如 VAT-KG 虽尝试整合视听流，但其图谱构建局限于单跳概念级事实，难以捕捉“动作-声音-环境”之间的时序依赖；MegaRAG 等文档解析方法侧重结构化提取，却缺乏针对视听查询的细粒度接地验证。M[3] KG-RAG 的切入点在于将图谱从“单跳概念”升级为“多跳时序因果”，并引入基于模态的检索与接地剪枝，确保注入 MLLM 的上下文既对齐查询模态，又直接支撑答案生成。

## 核心方法

### 方法参照系

标准 MMKG-RAG 流程包含图谱构建、向量检索与上下文拼接。本文问题与该通用流程的关键差异在于：通用流程假设共享嵌入空间可跨模态检索，且检索结果直接作为上下文；而本文针对视听任务，需解决跨模态距离校准失效及单跳图谱无法表达时序因果的问题，因此将检索限制在同模态内，并增加接地验证环节。

### 多跳多模态知识图谱构建

设计动机：解决现有 MMKG 仅包含单跳概念级事实、缺乏时序与因果依赖的问题。本文采用轻量级多智能体流水线，将原始视听语料转化为多跳 MMKG。首先，重写器（Rewriter）利用外部知识将语义通用的字幕重写为知识密集型文本；其次，提取器（Extractor）解析出实体-关系三元组；最后，通过知识接地（Knowledge Grounding）与上下文感知描述精炼（Context-Aware Description Refinement），将实体链接至外部知识库并生成与上下文一致的描述。该过程引入自检循环（Self-Reflection Loop），由检查器（Inspector）评估描述质量，若评分低于阈值则重新运行，确保图谱节点的事实准确性。

### 模态感知检索与接地选择性剪枝

设计动机：解决共享嵌入空间检索噪声大及检索结果包含无关知识的问题。模态感知检索（Modality-Wise Retrieval）仅在查询模态对应的子图中搜索，避免跨模态距离偏差。设查询嵌入为 $q$，同模态项集合为 $S$，检索得分定义为：

$$
\text{Score}(s) = -\|q - s\|_2, \quad s \in S
$$

仅保留得分高于阈值 $\tau$ 的项，并扩展至其多跳子图。随后，接地选择性剪枝（GRASP）进一步过滤。对于视觉实体 $e$，利用 GroundingDINO 在视频帧 $F$ 上的最大检测置信度作为视觉存在分数：

$$
\Phi_v(e) = \max_{f \in F} \Phi_v(e; f)
$$

对于音频三元组 $t$，将其转化为自然语言句子 $\sigma(t)$，利用文本到音频接地模型（TAG）计算音频存在分数 $\Phi_a(t)$。最终，仅保留视觉与音频存在分数之和高于阈值 $\eta$ 的三元组，并由轻量级 LLM 进行最终的答案相关性筛选，生成精简子图 $G_{GRASP}$。

## 实验评估

实验在 AudioCaps-QA、VCGPT 和 VALOR 三个基准上进行，基线包括无检索、Wikidata、VTKG、M2ConceptBase 和 VAT-KG。对比方法覆盖了纯文本 KG、图像-文本 MMKG 及视听 MMKG 路线，但缺失与最新智能体搜索方法（如 Search-R1）的直接对比。

| 方法 | AudioCaps-QA | VCGPT | VALOR |
| :--- | :--- | :--- | :--- |
| VideoLLaMA2 (None) | 43.13 | 39.09 | 25.66 |
| VideoLLaMA2 (VAT-KG) | 44.60 | 39.42 | 28.30 |
| VideoLLaMA2 (M[3] KG-RAG) | **53.23** | **39.92** | **29.25** |
| Qwen2.5-Omni (None) | 49.00 | 42.21 | 32.42 |
| Qwen2.5-Omni (VAT-KG) | 51.30 | 43.50 | 35.44 |
| Qwen2.5-Omni (M[3] KG-RAG) | **60.77** | **44.35** | **44.67** |

M[3] KG-RAG 在 AudioCaps-QA 上提升显著，但在 VCGPT 和 VALOR 上，其性能仍低于 Qwen2.5-Omni 无检索基线（42.21 vs 39.92; 32.42 vs 29.25），表明在强骨干模型上，结构化检索的增益被模型内部参数化知识所掩盖，甚至可能引入噪声。

| 配置 | VALOR (Qwen2.5-Omni) |
| :--- | :--- |
| 无检索 | 32.42 |
| 仅模态感知检索 | 40.91 |
| 仅 GRASP | 36.96 |
| 模态感知检索 + GRASP | **44.67** |

消融实验显示，模态感知检索与 GRASP 具有互补性。单独使用模态感知检索可提升 8.49 分，单独使用 GRASP 仅提升 4.54 分，两者结合则提升 12.25 分。这表明接地剪枝在缺乏模态对齐的初始图谱上效果有限，必须依赖模态感知检索提供的高质量候选集才能发挥最大效用。

评估采用 Model-as-Judge (M.J.) 协议，由 LLM 评分，缺乏人工评估的交叉验证。超参数（如阈值 $\tau$ 和 $\eta$）针对不同基准手动调整，未提供自动调参策略。代码与项目网站已公开，但多智能体构建流程依赖 Qwen3-8B，复现成本较高。

## 关联研究分析

从问题动机看，M[3] KG-RAG 与 MegaRAG 均致力于解决 MMKG 构建中的结构化难题，但 MegaRAG 侧重文档解析的自动化与完整性，适用于静态百科知识；而 M[3] KG-RAG 聚焦视听流的时序因果建模，其多跳图谱旨在捕捉动态事件中的实体关联。两者的差异根源在于任务特性：文档知识相对静态，而视听内容具有强时序依赖性，单跳图谱无法表达“动作导致声音”这类因果链。

从方法设计看，M[3] KG-RAG 与 VAT-KG 同属视听 MMKG 路线，但 VAT-KG 依赖共享嵌入空间的相似度检索，导致跨模态噪声；M[3] KG-RAG 引入模态感知检索与 GRASP，将检索限制在同模态内并通过接地模型验证实体存在性。这一设计解决了 VAT-KG 在细粒度实体定位上的局限，但可能牺牲了跨模态关联的召回率。例如，当查询同时涉及视觉与听觉线索时，同模态检索可能遗漏需要跨模态推理才能获取的证据，论文未对此进行量化分析。

## 总结

M[3] KG-RAG 旨在解决多模态检索中的模态间隙与单跳图谱局限，通过多跳 MMKG 构建与接地选择性剪枝，实现了视听知识的精准对齐。该方法在 AudioCaps-QA 上以 53.23 的分数超越 VAT-KG 的 44.60，证明了多跳结构在音频任务上的有效性。然而，在 VCGPT 和 VALOR 上，其性能未超越 Qwen2.5-Omni 的无检索基线，暴露了结构化检索在强骨干模型上的增益瓶颈。当骨干模型具备强大的内部参数化知识时，外部图谱的噪声过滤机制是否仍能带来净收益，论文未给出回答。
