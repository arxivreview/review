# CVPR2026最新论文 ｜Streamlined Knowledge Distillation ｜流式知识蒸馏

研究机构：韩国延世大学

作者：Hyeon-Jin Jeong、Han-Jin Lee、Seok-Hwan Choi

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_7d3a96afee3c)

> 知识蒸馏旨在将大模型（教师）的知识迁移至小模型（学生）以适配边缘部署，但现有Logit-based方法常因引入多知识对齐模块导致目标冗余，且标准L2范数损失忽略输出空间方向关系的方差差异，致使高方差方向主导训练并扭曲结构。SKD通过仅保留实例级语义与方向级结构两种核心知识，利用欧几里得批归一化（EBN）提取纯方向信息，并设计基于马氏距离的白化损失函数，在简化流程的同时提升了关系结构保真度。该方法在CIFAR-100与ImageNet上超越了多数Logit基线，但其性能上限仍低于最新特征对齐方法，且协方差估计对大Batch敏感。

## 研究背景

当教师模型输出Logits直接用于蒸馏时，学生需拟合教师软化后的概率分布。然而，Logits不仅包含单样本的类别概率（实例级语义），还隐含了样本间在输出空间中的几何相对位置（方向级结构）。传统方法仅通过KL散度匹配前者，忽略了后者，导致学生难以捕捉类间细粒度关系。为弥补这一缺陷，近期研究引入了多知识对齐机制，试图同时优化多个分布或关系矩阵，但这增加了计算开销与优化冲突。

Logit-based KD路线在避免中间层投影层开销方面具有优势，但长期面临性能低于Feature-based KD的困境。现有改进方案如MLKD通过构建Gramian矩阵捕捉方向关系，但直接应用L2范数对齐时，由于输出空间缺乏BatchNorm等归一化层的稳定作用，不同方向关系的方差极不均匀。L2范数对所有方向一视同仁，导致高方差的不稳定方向在损失中占据主导，削弱了有意义方向关系的保留。SKD的切入点在于识别出这一方差失衡问题，主张通过协方差白化而非增加对齐模块来解决结构保真度不足的问题，从而在保持Logit方法轻量性的同时逼近特征级蒸馏的效果。

## 核心方法

### 方法参照系

标准Logit-based KD流程仅计算教师与学生Logits经温度缩放后的KL散度，即 $L_{KL} = KL(softmax(z_t/\tau), softmax(z_s/\tau))$。本文问题与该通用流程的关键差异在于：标准流程仅处理单样本分布匹配，未显式建模Batch内样本间的方向关系，且现有关系建模方法（如MLKD）使用L2范数时存在方差处理缺陷。

### 基于EBN的方向结构提取

针对输出空间Logits尺度不稳定且Softmax变换可能引入非线性扭曲的问题，SKD在构建关系矩阵前引入欧几里得批归一化（EBN）。设计动机是消除Logits的模长影响，仅保留方向信息，使Gramian矩阵能纯粹反映样本间的余弦相似度。具体而言，将每个样本的Logits向量 $z_i \in \mathbb{R}^C$ 归一化为单位向量 $\hat{z}_i = z_i / \|z_i\|_2$，随后计算Batch内的Gramian矩阵 $G = \hat{Z}\hat{Z}^\top$，其中 $G_{ij} = \langle \hat{z}_i, \hat{z}_j \rangle$。这一变换确保了后续损失函数作用于纯几何结构上，避免了尺度波动对方向关系学习的干扰。

### 协方差白化的马氏距离损失

在获得师生Gramian矩阵差值 $D = G_s - G_t$ 后，SKD摒弃了MLKD使用的L2范数，转而采用基于马氏距离的损失函数。设计动机是L2范数无法区分不同方向关系的方差大小，导致高方差噪声方向主导梯度更新。SKD首先估计 $D$ 的行向量经验协方差矩阵 $\Sigma$，并引入Tikhonov正则化项 $\lambda I$ 以保证正定性，得到稳定协方差 $\Sigma' = \Sigma + \lambda I$。随后通过Cholesky分解 $\Sigma' = LL^\top$ 加速求逆，最终损失定义为：

$$ L_{DIR} = \frac{1}{B} \sum_{i=1}^B \|L^{-1} D_{i,:}\|_2 $$

该公式在数学上等价于协方差白化空间中的L2范数。其物理含义是，通过 $L^{-1}$ 变换将高方差方向压缩、低方差方向拉伸，使得所有方向关系在损失函数中的贡献均衡化。这一设计不仅保留了L2范数的计算简洁性，还显式地校正了输出空间各方向的不均匀方差，从而更准确地保留教师模型中的方向结构。

## 实验评估

实验在CIFAR-100、ImageNet-1K及MS-COCO上进行，涵盖同构与异构架构。基线覆盖了FitNet、RKD、CRD、OFD、DKD、MLKD、SDD、RLD等主流Logit与Feature方法，但缺失2025-2026年最新的SOTA方法如GDKD、SDMD、UHKD。

| 方法 | CIFAR-100 (R32x4→R8x4) | ImageNet (R50→MV1) |
| :--- | :--- | :--- |
| MLKD | 75.59 | 71.08 |
| RLD | 76.64 | 71.07 |
| SKD | 78.33 | 71.53 |

在CIFAR-100同构设置下，SKD在ResNet32x4到ResNet8x4的蒸馏中达到78.33% Top-1准确率，显著优于MLKD的75.59%和RLD的76.64%。在ImageNet异构设置（ResNet50到MobileNetV1）中，SKD达到71.53%，同样领先于MLKD的71.08%。然而，据领域综述，最新特征对齐方法SDMD在ImageNet异构蒸馏中可达76.34%，表明纯Logit路线在大规模异构任务上仍存在性能上限。

| 组件 | EBN | Mal Loss | Stability | Top-1 Acc |
| :--- | :---: | :---: | :---: | :--- |
| Baseline | X | X | X | 76.61 |
| + EBN | O | X | X | 77.28 |
| + Mal | O | O | X | 77.76 |
| + Stability | O | O | O | 78.33 |

消融实验显示，引入EBN带来0.67%的提升，替换为马氏距离损失再提升0.48%，加入Tikhonov正则化与Cholesky分解最终提升0.57%。这表明方向结构的提取与方差校正均有独立贡献，且数值稳定性对最终性能有显著影响。

评估协议采用标准Top-1准确率与AP指标，实验重复5次并报告均值。代码已开源，超参数设置详细（如CIFAR-100使用SGD 240 epochs，lr 0.1）。局限在于未报告计算效率的具体数值对比（仅定性描述为“最短训练时间”），且未在小Batch或噪声标签场景下验证协方差估计的鲁棒性。

## 关联研究分析

从方法设计看，SKD与MLKD同属Logit-based关系建模路线，但核心差异在于损失函数的几何解释。MLKD直接使用L2范数对齐Gramian矩阵，隐含假设所有方向关系方差相同；而SKD指出输出空间缺乏归一化层导致方差失衡，通过马氏距离实现协方差白化。这一差异的根源在于对输出空间几何性质的理解：MLKD将Logits视为普通向量，SKD则将其视为具有各向异性方差的随机变量。这种处理方式使得SKD在不需要额外投影层的情况下，比MLKD更有效地保留了方向结构，但也引入了对Batch内协方差估计的依赖。

从问题动机看，SKD与Feature-based KD（如FitNet）形成了路线对立。FitNet通过中间层特征对齐获取丰富语义，但需处理异构架构的维度匹配与投影开销；SKD坚持纯Logit路线，主张通过挖掘输出空间的几何结构来弥补特征级监督的缺失。SKD在CIFAR-100上超越了FitNet（78.33% vs 75.26%），证明在中等规模任务中，精细化的Logit几何建模可替代部分特征对齐功能。然而，在ImageNet异构任务上，SKD（71.53%）仍低于最新特征对齐方法SDMD（76.34%），暗示当架构差异巨大或任务复杂度极高时，仅靠输出空间几何结构可能不足以承载足够的语义信息，特征级监督仍是必要的补充。

## 总结

SKD旨在解决Logit-based KD中多知识对齐导致的冗余与L2范数忽略方差差异的问题。其切入点在于识别输出空间方向关系的各向异性，通过EBN提取纯方向信息并利用马氏距离实现协方差白化，从而在简化流程的同时提升结构保真度。实验证明SKD在CIFAR-100同构蒸馏中达到78.33%，优于MLKD等基线。然而，论文自身实验暴露了边界：在ImageNet异构任务上，SKD性能仍显著低于最新特征对齐方法，且作者承认协方差矩阵在大Batch或噪声标签下敏感。当Batch Size减小导致协方差估计方差增大时，马氏距离损失的白化效果是否会因估计噪声而失效，论文未给出回答。
