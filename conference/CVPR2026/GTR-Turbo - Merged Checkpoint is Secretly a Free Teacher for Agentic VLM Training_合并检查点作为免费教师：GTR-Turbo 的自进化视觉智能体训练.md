# CVPR2026最新论文 ｜GTR-Turbo: Merged Checkpoint is Secretly a Free Teacher for Agentic VLM Training ｜合并检查点作为免费教师：GTR-Turbo 的自进化视觉智能体训练

研究机构：清华大学、北京大学

作者：Tong Wei、Yijun Yang、Changhao Zhang 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.13043)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.13043)

> 多轮视觉语言模型（VLM）强化学习（RL）面临稀疏奖励导致的思维坍缩与信用分配难题。现有方法如 GTR 依赖昂贵的外部 API 模型提供步骤级指导，存在算力与隐私瓶颈。GTR-Turbo 利用 RL 训练过程中产生的历史检查点，通过 TIES 合并技术构建“免费”教师模型，以 SFT 或 KL 蒸馏方式指导策略更新。该方法在 Points24 和 ALFWorld 上实现了性能持平或超越 GTR，同时大幅降低训练时间与成本，但其绝对性能仍受限于单智能体架构与视觉模态的固有难度。

## 研究背景

当 VLM 智能体在长程任务中执行多步决策时，环境仅在任务结束时提供稀疏奖励，导致中间步骤的贡献无法被有效区分，进而引发策略熵坍缩与输出模板化。这种思维坍缩现象源于 RL 梯度在长轨迹上的噪声累积，使得模型难以维持推理的多样性与逻辑一致性。为缓解此问题，引入过程监督机制将稀疏结果奖励转化为密集的过程信号，成为提升多轮 RL 稳定性的关键路径。

主流解决方案如 GTR 和 On-Policy Distillation 通过引入外部强教师模型，在每一步交互中提供思维或动作级别的指导，有效抑制了思维坍缩。然而，这一范式严重依赖 GPT-4o 等闭源或高性能开源模型，不仅带来高昂的 API 调用成本与网络延迟，还面临模型不可访问性与数据隐私风险。此外，外部教师的能力上限固定，无法随智能体训练进程动态进化，限制了后期学习的潜力。GTR-Turbo 的切入点在于利用 RL 训练自身产生的历史权重信息，无需额外训练或外部依赖，即可构建一个随训练进程不断强化的自进化教师，从而在保持指导质量的同时消除外部依赖。

## 核心方法

### 方法参照系

GTR 框架通过外部 VLM 作为校正器，对智能体的思维输出进行 SFT 监督，同时结合 PPO 优化动作。其核心差异在于教师来源：GTR 依赖静态外部模型，而 GTR-Turbo 将教师替换为动态合并的历史检查点，实现了教师与智能体的同源进化。

### 检查点合并教师构建

GTR-Turbo 在每次 RL 更新后保存模型权重至缓冲区，并采用 TIES 合并技术生成教师模型。TIES 通过修剪冗余参数、符号投票与选择性平均，避免不同检查点间的参数干扰。合并模型 $\pi_{merged}^{[k]}$ 在第 $k$ 次更新时定义为：

$$ \pi_{merged}^{[k]} = \text{TIES}(\pi_{\theta}^{[1]}, \pi_{\theta}^{[2]}, \dots, \pi_{\theta}^{[k]}) $$

该公式的物理含义是，通过加权聚合历史策略，平滑损失曲面并保留过往经验，使合并模型在性能上稳定优于当前训练中的智能体 $\pi_{\theta}^{[k]}$，从而具备作为教师的资格。这一设计解决了外部教师能力固定且无法随智能体进步而提升的问题，实现了教师能力的动态增长。

### 软对数蒸馏引导

为进一步提升效率，GTR-Turbo 提出基于反向 KL 散度的软对数蒸馏机制，替代 GTR 中的 SFT 损失。给定观察 $o$ 与思维输出 $th$，计算智能体与教师之间的反向 KL 散度作为辅助奖励：

$$ R_{KL} = -\mathbb{E}_{th \sim \pi_{\theta}} \left[ D_{KL}(\pi_{\theta}(\cdot|o, th) \| \pi_{merged}(\cdot|o, th)) \right] $$

该公式通过最小化智能体与教师输出分布的差异，提供 token 级别的密集指导。与 SFT 相比，KL 蒸馏仅需单次前向传播，无需教师自回归生成，显著降低计算开销。同时，KL 散度对概率分布的软约束保留了智能体的探索空间，避免了 SFT 硬标签导致的分布收窄，从而在提升推理质量的同时维持策略多样性。

## 实验评估

实验在 Points24 与 ALFWorld 两个视觉智能体基准上进行，基线包括 RL4VLM、GTR 及多个商用 API 模型。GTR-Turbo (KL) 在 Points24 上取得 53.5% 的成功率，超越 GTR 的 44.5% 与 GPT-4o 的 2.5%；在 ALFWorld 上达到 15% 的成功率，与 GTR 的 16% 持平。

| 环境 | 方法 | 成功率 (SR) | 训练时间 | 额外成本 |
| :--- | :--- | :--- | :--- | :--- |
| Points24 | GTR | 44.5% | 191h | $307.78 |
| Points24 | GTR-Turbo (KL) | 53.5% | 89h | $114.81 |
| ALFWorld | GTR | 16% | 164h | $145.76 |
| ALFWorld | GTR-Turbo (KL) | 15% | 78h | $100.62 |

消融实验表明，TIES 合并显著优于线性平均，有效缓解了参数干扰；KL 引导比 SFT 引导在 Points24 上提升 5.5 个百分点，且训练时间缩短至 GTR 的 46%。然而，在 ALFWorld 上，GTR-Turbo (KL) 的成功率略低于 GTR，表明在视觉导航任务中，外部强教师的即时知识注入仍具有优势，自进化教师的滞后性可能在复杂感知任务中显现。

评估指标仅包含成功率与回合回报，缺乏对推理过程质量的细粒度评估。实验使用 Qwen2.5-VL-7B 作为骨干，未验证在更大规模模型上的可扩展性。代码已开源，但超参数配置（如 TIES 的 top-k 比例）未详细披露，可能影响复现性。

## 关联研究分析

从问题动机看，GTR-Turbo 与 Tree-GRPO 均致力于解决稀疏奖励下的信用分配问题，但路径截然不同。Tree-GRPO 通过树搜索扩展轨迹采样空间，依赖计算密集型的多分支探索来细化优势估计；而 GTR-Turbo 通过合并历史检查点提供步骤级思维指导，以低成本的本地推理替代高成本的探索。这种差异源于任务特性：Points24 等逻辑推理任务中，思维过程的正确性比动作探索的多样性更关键，因此思维指导比树搜索更有效。然而，在 ALFWorld 等感知密集任务中，Tree-GRPO 的探索机制可能更具优势，GTR-Turbo 的自进化教师是否能在感知误差累积的场景中保持指导有效性，论文未给出回答。

从方法设计看，GTR-Turbo 与 On-Policy Distillation 同属蒸馏范式，但教师来源不同。On-Policy Distillation 依赖外部大模型提供 token 级指导，而 GTR-Turbo 利用内部合并模型。这一差异导致 GTR-Turbo 在算力效率上具有绝对优势，但在教师能力上限上受限。On-Policy Distillation 的教师能力固定且强大，适合任务初期快速收敛；GTR-Turbo 的教师能力随训练进程增长，适合长期自进化场景。在数据隐私敏感或外部模型不可用的场景下，GTR-Turbo 的自包含特性使其更具实用价值，但其教师能力的滞后性可能在任务后期成为瓶颈。

## 总结

GTR-Turbo 旨在解决多轮 VLM RL 中外部教师依赖导致的成本与可扩展性矛盾。其切入点在于利用 RL 训练自身产生的历史检查点，通过 TIES 合并构建自进化教师，以 KL 蒸馏提供密集思维指导。该方法在 Points24 上以 53.5% 的成功率超越 GTR，并将训练时间缩短至 89 小时。然而，在 ALFWorld 上其成功率（15%）略低于 GTR（16%），暴露出自进化教师在复杂视觉导航任务中的滞后性。当任务感知复杂度进一步增加时，合并教师的能力增长是否足以抵消外部强教师的即时知识优势，论文未给出回答。
