作者：Yichang Xu、Gaowen Liu、Ramana Rao Kompella 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.14052)

> 长视频问答的核心矛盾在于算力约束与关键帧定位的稀疏性，现有单模型或单智能体方法在长序列下因冗余帧干扰导致性能下降或推理延迟过高。A4VL 通过无监督多智能体组队与事件驱动块级对齐，在无需训练的前提下实现了高效的关键帧聚焦与协同推理。该方法在五个基准上超越了包括 GPT-4o 在内的 28 个基线，证明了协作式感知-行动循环在长视频任务中的有效性，但其性能增益是否完全归因于多智能体机制而非骨干模型规模，仍需进一步剥离验证。

## 研究背景

长视频理解面临算力与精度的双重挤压。当视频帧数增加时，多模态大语言模型（MLLMs）的内存与时间成本呈二次方增长，且单纯提高采样密度会引入冗余噪声，分散模型对关键帧的注意力。为应对这一瓶颈，智能体（Agent）范式被引入，通过工具调用迭代式地检索证据，但现有方法如 VideoAgent 在处理一小时视频时耗时超过十分钟，且依赖单一 MLLM 进行决策，缺乏有效的多智能体协作机制。

主流路线分为两类：一类是架构优化，如 DYTO 通过动态令牌合并支持更高采样率，AuroraLong 用线性 RNN 替换 LLM 组件以提升效率；另一类是智能体工具增强，如 MoReVQA 利用目标检测定位关键帧，但在长复杂视频上表现不佳。这些方法要么牺牲了推理深度，要么在长视频场景下因关键帧定位失败而失效。A4VL 的切入点在于将“感知”与“行动”解耦为两个迭代阶段，并通过无监督组队策略从异构 MLLM 池中筛选出协作效率最高的子集，从而在固定算力预算下实现高精度的长视频推理。

## 核心方法

### 方法参照系

A4VL 属于智能体工具增强推理路线，其标准流程通常由单智能体执行“检索-推理”循环。本文的关键差异在于引入了多智能体联盟机制，将单点决策转化为多轮交叉评审与剪枝过程，并通过事件驱动的视频块划分替代均匀采样，实现了感知线索与视觉证据的显式对齐。

### 无监督智能体组队策略

传统智能体方法通常固定使用单一强模型，忽略了不同 MLLM 在特定任务上的互补性。A4VL 在任务开始前引入组队阶段，从包含 8 个不同规模与架构的 MLLM 池中筛选出 3 个最优智能体。该策略利用未标注数据计算每个智能体的预测频率得分，选择得分最高的 $m=3$ 个智能体组成任务专用团队。其评分函数定义为：

$$ S_i = \frac{1}{K} \sum_{q=1}^{K} f_{q, r_q} $$

其中 $f_{q, r_q}$ 表示智能体 $i$ 对问题 $q$ 选择的选项 $r_q$ 在所有智能体中的出现频率。这一设计解决了单智能体在复杂长视频上因视角单一而导致的定位偏差问题，通过多样性组合提升了关键帧检索的鲁棒性。

### 感知-行动迭代循环

组队完成后，A4VL 进入多轮感知-行动循环。在感知探索阶段，每个智能体随机采样 $N_1=4$ 帧生成感知线索 $P_{i,j}$，并利用 CLIP 计算线索与视频块的相似度。视频通过 DINOv2 嵌入与像素线索进行事件驱动划分，保留相似度高于阈值 $\rho=0.8$ 的块，并根据 SoftMax 归一化分数分配 $N_2=16$ 帧给每个智能体。其帧分配向量计算为：

$$ \mathbf{c}^{(i)} := \lfloor N_2 \cdot \text{SoftMax}(\mathbf{s}^{(i)} - \max(\mathbf{s}^{(i)})) \rfloor $$

该公式确保高相关性块获得更多采样帧，实现了计算资源向关键事件的集中。在行动探索阶段，智能体基于采样帧生成答案与理由。若未达成全共识，智能体互相评分（1-10分），总分最低者被剪枝，剩余智能体更新感知线索并进入下一轮。这一机制通过迭代剪枝消除了低效智能体的干扰，逐步收敛至正确答案。

## 实验评估

A4VL 在 NeXT-QA、EgoSchema、LongVideoBench、MLVU 和 Video-MME 五个基准上进行了评估，对比了 28 个基线，包括 GPT-4o、Gemini 1.5 Pro 等闭源模型及 InternVL3-78B 等开源模型。基线覆盖了架构优化（如 DYTO、AuroraLong）与智能体方法（如 VideoAgent、MoReVQA），但缺失了基于强化学习后训练（RLVR）的方法如 Video-R1 或 Open-o3-Video 的直接对比。

| 基准 | A4VL | GPT-4o | InternVL3-78B | VideoAgent |
| :--- | :--- | :--- | :--- | :--- |
| NeXT-QA | 85.1 | - | 84.0 | 66.1 |
| EgoSchema | 82.2 | 72.2 | 76.8 | 55.0 |
| LongVideoBench | 72.2 | 66.7 | 56.4 | - |
| MLVU | 58.0 | 54.9 | 55.3 | 34.3 |
| Video-MME (w/o sub) | 77.2 | 71.9 | 67.1 | - |

A4VL 在所有基准上均取得最高准确率，尤其在 LongVideoBench 上较 GPT-4o 提升 5.5 个百分点，在 EgoSchema 上较最强开源模型 InternVL3-78B 提升 3.2 个百分点。

| 消融项 | 准确率 (%) | 延迟 (s/样本) |
| :--- | :--- | :--- |
| RESampling (默认) | 82.2 | 37 |
| RRSampling | 80.2 | 35 |
| ERSampling | 79.6 | 37 |
| FConsens (默认) | 82.2 | 37 |
| MConsens | 81.4 | 26 |
| NoPruneSum | 80.8 | 60 |
| NoPruneMaj | 79.4 | 60 |

消融实验显示，事件驱动采样（RESampling）比随机采样（RRSampling）提升 2.0 个百分点，验证了块级对齐对关键帧检索的有效性。全共识（FConsens）比多数共识（MConsens）提升 0.8 个百分点，但延迟增加 11 秒，表明额外轮次对置信度有正向贡献。移除剪枝机制导致准确率下降 1.4-2.8 个百分点，且延迟翻倍至 60 秒，证明剪枝对效率与精度的双重必要性。

评估边界方面，A4VL 在 Video-MME 无字幕设置下表现最佳，说明其视觉推理能力独立于文本线索。代码已开源，实验在 6 块 H200 GPU 上进行，但论文未报告不同 GPU 数量下的性能缩放曲线，且未提供置信区间，数值比较需谨慎。

## 关联研究分析

从方法设计看，A4VL 与 CAViAR 同属多智能体框架，但 CAViAR 依赖复杂的程序生成与批评者机制，而 A4VL 采用无监督组队与交叉评审，计算开销更低且无需额外训练。这一差异源于任务特性：长视频推理更依赖关键帧的精准定位而非复杂的逻辑程序生成，因此轻量级的 CLIP 对齐比重型接地模型更适配。

从问题动机看，A4VL 与 Video-R1 等 RLVR 方法形成鲜明对比。RLVR 通过可验证奖励优化推理轨迹，但需要大量标注数据与训练成本；A4VL 则通过推理时的多智能体协作弥补单模型的能力不足。这种 Training-free 策略在数据稀缺或算力受限场景下更具优势，但其性能上限可能受限于骨干模型的固有偏见。当骨干模型规模增大时，多智能体协作的边际收益是否递减，论文未给出明确回答。

## 总结

A4VL 旨在解决长视频推理中算力约束与关键帧定位稀疏性的矛盾，通过无监督多智能体组队与事件驱动块级对齐，在无需训练的前提下实现了高效协同推理。该方法在 LongVideoBench 上以 72.2% 的准确率超越 GPT-4o 的 66.7%，在 EgoSchema 上以 82.2% 超越最强开源模型 3.2 个百分点。然而，实验显示 A4VL 的性能高度依赖 InternVL3-78B 等强骨干模型，且未与 RLVR 方法直接对比，难以剥离多智能体机制与模型规模各自的贡献。当骨干模型规模缩减至 7B 级别时，多智能体协作能否维持对单智能体方法的性能优势，仍是该框架泛化能力的关键验证点。
