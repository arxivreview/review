# CVPR2026最新论文 ｜Towards Sparse Video Understanding and Reasoning ｜稀疏视频理解与推理

研究机构：美国西北大学、美国约翰斯·霍普金斯大学

作者：Chenwei Xu、Zhen Ye、Shang Wu 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.13602)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.13602)

> 视频问答（Video Question Answering, VQA）的核心矛盾在于长视频的时序冗余与模型上下文窗口的有限算力。现有方法要么通过均匀采样导致信息过载，要么依赖外部工具链增加系统复杂度。REVISE 提出“摘要即状态”机制，将多轮帧选择转化为基于显式文本状态的马尔可夫决策过程，在不修改骨干网络参数的前提下实现稀疏推理。该方法在效率上表现优异，但绝对精度仍落后于基于强化学习后训练的前沿模型，其价值在于提供了一种轻量级、即插即用的稀疏化路径，而非精度上限的突破。

## 研究背景

当多模态大语言模型（MLLMs）处理长视频时，均匀采样帧序列会导致视觉 Token 消耗线性增长，触发上下文窗口限制。这一现象源于视频数据的语义稀疏性：仅极少数帧对特定问题具有判别力，而大量冗余帧不仅占用算力，还干扰模型对关键线索的聚焦。为缓解此问题，早期研究引入视频字幕模型将帧转化为文本，但丢失了细粒度视觉细节；直接集成视觉编码器的方法虽保留了视觉信息，却因缺乏选择性而陷入信息过载。

视频理解领域正从静态特征匹配转向动态主动推理，智能体工具增强推理成为应对长视频挑战的主流路线。然而，现有智能体框架如 VideoAgent 依赖外部字幕器进行多轮选择，系统复杂度高且存在信息损失；CAViAR 等框架侧重多智能体协作，但未解决单智能体在长程交互中的状态记忆与上下文压缩问题。REVISE 的切入点在于将循环神经网络（RNN）的隐藏状态概念转化为显式文本摘要，作为唯一跨轮记忆载体，从而在保持 VLM 原生视觉推理能力的前提下，实现证据的渐进式积累与冗余的主动剔除。

## 核心方法

### 方法参照系

本文问题归属于智能体工具增强推理类别，标准流程为“感知-决策-行动”循环。关键差异在于：传统方法将帧选择视为外部工具调用或一次性最大覆盖问题，而 REVISE 将其建模为受预算约束的序列决策，且决策依据是内部维护的结构化文本状态而非原始对话历史。

### 摘要即状态机制

针对均匀采样导致的 (L1) 信息过载与 (L2) 关键信息缺失，REVISE 引入持久化摘要状态 $z_t$ 替代原始上下文。该状态由五个固定字段组成：已见帧摘要 $P_t$、当前观察 $O_t$、假设更新 $H_t$、剩余不确定性 $U_t$ 及下一步理由 $R_t$。其核心公式为：

$$ z_t = \text{Update}(z_{t-1}, F_t, p) $$

其中 $F_t$ 为第 $t$ 轮选中的帧集合，$p$ 为原始问题。该公式的物理含义是：当前状态完全由前一状态、新观察帧及问题决定，实现了马尔可夫性。这一设计解决了此前方法因携带完整对话历史导致的 Token 爆炸与注意力分散问题，使模型仅基于已验证证据进行推理，从而在有限预算内最大化信息密度。

### 预算约束下的序列决策

在摘要状态基础上，REVISE 将帧选择形式化为有限时域马尔可夫决策过程（MDP）。智能体在每轮 $t$ 执行动作 $a_t \in \{\text{SELECT}(Q_t), \text{ANSWER}(y_t)\}$，其中 $Q_t$ 为请求的帧索引集。优化目标为：

$$ \max_{\{Q_t\}_{t=1}^{\tau}} \mathbb{E}[r(a_\tau, y)] \quad \text{s.t.} \quad C(S_\tau) + |p_\tau| \le K $$

其中 $C(S_\tau)$ 为累计视觉 Token 成本，$K$ 为最大上下文预算。该公式表明，智能体需在满足算力约束的前提下，通过选择能最大化最终答案奖励的帧序列来终止推理。相比单次最大覆盖策略，此序列决策允许模型根据 $U_t$ 和 $R_t$ 动态调整搜索方向，实现“按需取证”而非“全量扫描”，从而在降低帧数的同时提升对关键证据的捕获率。

## 实验评估

实验在 VideoEspresso、NExT-QA 和 EgoSchema 三个基准上进行，基线涵盖 VideoAgent、VideoTree 及 GPT-4o 等专有模型。值得注意的是，实验未包含 Open-o3-Video、GraphThinker 等基于可验证奖励强化学习（RLVR）的当前 SOTA 方法，导致精度对比缺乏最强参照系。

| 方法 | 数据集 | 准确率 (%) | 平均帧数 | 平均轮数 |
| :--- | :--- | :--- | :--- | :--- |
| GPT-4o + REVISE | VideoEspresso | 48.9 | 7.99 | - |
| Qwen2-VL + REVISE | VideoEspresso | 37.8 | 6.25 | - |
| GPT-4o + REVISE | NExT-QA | 63.8 | 8.4 | - |
| GPT-4o + REVISE | EgoSchema | 60.6 | 9.8 | - |

在 VideoEspresso 上，GPT-4o + REVISE 以 48.9% 的准确率超越 VideoEspresso 基线（45.2%），且仅使用 7.99 帧；在 NExT-QA 上，其 63.8% 的准确率低于 VideoTree 的 73.5%，但帧数仅为 8.4，远低于 VideoTree 的 56 帧。这表明 REVISE 在效率-精度权衡中偏向效率，其稀疏策略以牺牲部分绝对精度为代价换取了极低的 Token 消耗。

| 变体 | 准确率 (%) | 平均轮数 | 时间 (s) |
| :--- | :--- | :--- | :--- |
| Full (structured summary-as-state) | 41.48 | 2.79 | 22.71 |
| No state carryover | 23.14 | 3.73 | 50.75 |
| No structured P/O/H/U/R fields | 24.27 | 3.91 | 54.85 |

消融实验显示，移除状态传递导致准确率下降 18.34 个百分点，时间增加 28.04 秒；移除结构化字段导致准确率下降 17.21 个百分点，时间增加 32.14 秒。这证实了显式状态传递与结构化字段对维持多轮推理稳定性与效率的关键作用，二者缺一不可。

评估协议采用固定预算（每轮最多 3 帧，最多 4 轮），未报告置信区间，且所有实验在 4×80G A100 上以温度 0.2 运行。论文未提供代码，但详细列出了超参数设置，可复现性中等。主要局限在于缺乏与 RLVR 方法的直接对比，且未评估在极端长视频（如小时级）下的扩展性。

## 关联研究分析

从问题动机看，REVISE 与 VideoAgent 均致力于解决长视频中的关键帧选择问题，但根源差异显著。VideoAgent 依赖外部字幕器将视觉信息转化为文本，其选择策略基于文本语义匹配，本质上是“文本驱动”的间接推理；而 REVISE 直接利用 VLM 的视觉编码能力，通过摘要状态 $z_t$ 中的 $O_t$ 字段保留视觉观察，实现了“视觉驱动”的直接推理。这一差异源于对视觉细节丢失的容忍度不同：VideoAgent 假设字幕足以承载推理所需信息，而 REVISE 认为细粒度视觉线索是避免幻觉的关键。当视频包含复杂空间交互或细微动作变化时，字幕驱动的 VideoAgent 可能因信息损失导致推理偏差，而 REVISE 的视觉接地机制理论上更具鲁棒性，但论文未提供此类场景的专项对比实验。

从方法设计看，REVISE 与 CAViAR 同属智能体框架，但状态管理策略截然不同。CAViAR 采用多智能体协作，通过批评者迭代筛选推理轨迹，其状态分散于多个智能体间，系统复杂度高且通信开销大；REVISE 则采用单智能体架构，将状态压缩为单一文本摘要 $z_t$，实现了状态的集中化管理。这一设计选择反映了两种不同的工程取舍：CAViAR 追求推理深度的最大化，通过多视角验证提升准确性；REVISE 追求推理效率的最大化，通过状态压缩降低 Token 消耗。在算力受限的边缘部署场景中，REVISE 的轻量级架构更具优势，但在需要极高推理精度的复杂因果任务中，CAViAR 的多智能体验证机制可能提供更强的纠错能力。论文未探讨这两种范式在精度-效率帕累托前沿上的具体交叉点，也未分析当视频长度超过一定阈值时，单智能体状态压缩是否会导致关键信息丢失。

## 总结

REVISE 旨在解决长视频 VQA 中信息过载与关键信息缺失的矛盾，其切入点是将 RNN 隐藏状态转化为显式文本摘要，作为唯一跨轮记忆载体，从而在保持 VLM 原生视觉推理能力的前提下实现稀疏化。该方法通过预算约束下的序列决策，在 VideoEspresso 上以 7.99 帧达到 48.9% 准确率，在 NExT-QA 上以 8.4 帧达到 63.8% 准确率，证明了稀疏策略在效率上的显著优势。然而，其绝对精度仍低于基于 RLVR 的 SOTA 方法，且实验未涵盖极端长视频场景，暴露了状态压缩机制在长程依赖任务中的潜在局限。当视频时长从分钟级扩展至小时级时，单一摘要状态 $z_t$ 是否足以承载跨长时段的因果线索，而无需引入层级化记忆结构，论文未给出回答。
