# CVPR2026最新论文 ｜Unified Vector Floorplan Generation via Markup Representation ｜统一矢量平面生成：基于标记语言表示的自回归建模

研究机构：日本东京大学

作者：Kaede Shiohara、Toshihiko Yamasaki

论文原文见 [arXiv](https://arxiv.org/abs/2604.04859)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.04859)

> 建筑平面生成长期面临多条件任务泛化性差与表示碎片化的困境，现有光栅或扩散方法需依赖多阶段流水线或特定任务网络，难以统一处理边界、图结构及补全等异构输入。本文提出平面标记语言（Floorplan Markup Language, FML），将平面几何与拓扑约束编码为单一结构化序列，使生成任务转化为标准的下一词预测问题。通过自回归Transformer模型（FMLM）结合语法约束解码，该方法在RPLAN数据集上实现了跨任务的统一矢量生成。尽管在几何精度与拓扑一致性上显著优于经典基线，但其对非标准拓扑的探索能力及多楼层扩展性仍受限于当前语法设计。

## 研究背景

理解本文需厘清矢量表示与序列建模在空间生成中的耦合关系。传统光栅方法虽便于卷积特征提取，但像素掩码向工程矢量转换时存在固有的分辨率瓶颈与后处理复杂度；矢量扩散模型虽提升了几何保真度，却往往需预定义房间顶点数或依赖多阶段推理，导致架构僵化。自回归序列建模通过离散Token处理变长结构，天然适配房间与门数量的不确定性，但其几何推理精度通常低于连续空间优化，需借助语法约束弥补。

建筑平面生成的核心矛盾在于几何拓扑一致性与语义功能可行性的平衡，以及单一模型对多样化条件输入的泛化能力。早期约束满足方法虽保证硬可行性，但缺乏多样性且计算开销巨大；HouseGAN等光栅方法受限于分辨率，HouseDiffusion等矢量扩散方法虽提升精度，但各任务需独立网络或复杂流水线，无法统一处理边界、邻接图及局部补全。本文切入点在于识别出“表示不兼容”是泛化差的主因，通过引入标记语言统一编码平面结构与条件，将异构生成任务映射为同构的序列预测问题，从而在单一模型内实现端到端矢量生成。

## 核心方法

### 方法参照系

本文问题归属于结构化序列生成范畴，与通用大语言模型（LLM）的下一词预测范式一致，但关键差异在于输入数据为二维几何坐标与拓扑关系，而非自然语言文本。通用LLM缺乏对空间几何硬约束（如房间不重叠、门位于墙体）的内在感知，直接应用会导致生成结果违反物理规则。因此，本文需在序列建模中嵌入几何语法约束，以弥合离散Token生成与连续几何有效性之间的鸿沟。

### 平面标记语言 (FML) 语法设计

设计动机在于解决传统表示中条件输入（边界、图）与生成目标（平面）分离导致的流水线冗余。FML借鉴HTML结构，定义了一套严格的上下文无关文法，将平面、边界及图条件统一编码为标签序列。其核心创新在于通过标签嵌套显式约束元素出现顺序：平面描述遵循`<room>`→`<door>`→`<front door>`的固定序列，且房间索引按降序排列。这种结构化语法不仅消除了多阶段转换需求，还将几何约束转化为序列合法性检查。坐标编码采用一维映射 $z = x + y \cdot W$，其中 $W$ 为二维空间宽度，将二维坐标压缩为单一Token，简化了离散化过程。该设计使得任何生成任务（无条件、边界条件、图条件）均可表示为以特定前缀开始的FML序列生成，实现了任务统一。

### 约束解码与排列等价性学习

设计动机在于自回归模型对房间顺序敏感，而平面拓扑本质上是排列等价的，且无约束解码易产生重叠房间或错位门。本文引入两项机制：一是房间置换数据增强，在训练时随机打乱房间顺序，迫使模型学习排列不变性；二是约束解码（Constrained Decoding），在推理时根据当前已生成Token动态屏蔽非法后续Token的概率。其核心公式为条件概率掩码：

$$ P(x_{l+1} | x_{1:l}) = \frac{\exp(W f(x_{1:l})_i) \cdot \mathbb{I}(i \in \mathcal{V}_l)}{\sum_{j \in \mathcal{V}_l} \exp(W f(x_{1:l})_j)} $$

其中 $\mathbb{I}$ 为指示函数，$\mathcal{V}_l$ 为当前语法状态下合法的Token集合。该机制将启发式规则（如门顶点数、房间外置）硬编码进解码过程，确保生成序列严格符合FML语法，从而在离散生成中实现了硬约束满足，避免了后处理修正。

## 实验评估

实验在RPLAN数据集上进行，对比基线涵盖光栅（HouseGAN++）、矢量扩散（HouseDiffusion, GSDiff）及混合方法（Graph2Plan）。基线覆盖较全面，但缺失最新LLM驱动基线（如HouseMind），且部分对比因门表示差异（线vs多边形）需剔除门信息计算FID，协议公平性存在细微妥协。

| 条件 | 方法 | FID (↓) | IoU (↑) | GED (↓) |
| :--- | :--- | :--- | :--- | :--- |
| Boundary | Graph2Plan | 34.20 | 95.87 | - |
| Boundary | FMLM | **6.51** | **97.86** | - |
| Graph | HouseDiffusion | 29.31 | - | 1.55 |
| Graph | FMLM | **3.41** | - | **1.21** |
| B & G | Graph2Plan | 22.87 | 92.96 | 3.43 |
| B & G | FMLM | **14.17** | **97.59** | **1.24** |

在边界条件生成中，FMLM的FID从Graph2Plan的34.20降至6.51，IoU提升至97.86，表明其生成的布局在视觉分布与几何贴合度上均显著优于基线。在图条件生成中，GED从HouseDiffusion的1.55降至1.21，显示拓扑一致性更高。多条件联合生成中，FMLM在所有指标上全面超越Graph2Plan，验证了统一表示在复杂约束下的优势。

消融实验揭示了关键设计决策的影响。移除房间置换增强后，B&G条件下的FID从14.17恶化至24.36，GED从1.24升至2.35，证明排列等价性学习对拓扑稳定性至关重要。将房间索引从降序改为升序后，FID飙升至105.78以上，原因是升序无法让模型预知房间总数，导致生成长度失控。约束解码的移除则导致生成中出现房间重叠与门错位，证实了语法硬约束在几何有效性中的不可替代性。

评估指标主要聚焦几何与拓扑（FID, IoU, GED），缺乏对功能可行性（如家具摆放、动线）的量化评估，这与领域内“几何合理但功能不可用”的痛点存在脱节。模型在单张NVIDIA A100 GPU上训练50个Epoch，超参数公开，可复现性良好。但FID的大幅领先部分源于训练/测试集划分的对齐，跨数据集泛化能力未验证。

## 关联研究分析

从方法设计看，FMLM与HouseDiffusion同属矢量生成路线，但前者以自回归序列替代扩散过程。HouseDiffusion需在连续空间迭代去噪，且常需预定义顶点数或依赖多阶段推理；FMLM通过离散Token直接生成变长结构，避免了连续-离散转换误差，但代价是牺牲了扩散模型在连续空间优化中的平滑性。这种差异源于任务特性：平面生成更关注拓扑离散结构而非像素级连续性，序列建模的语法约束优势在此场景下被放大。

从问题动机看，FMLM与GFLAN均致力于约束满足，但路径迥异。GFLAN采用CNN热图预测中心点结合GNN回归边界，属于“预测-优化”范式，依赖确定性过程保证约束；FMLM则通过语法约束解码在生成过程中内嵌约束，属于“生成-约束”范式。GFLAN的几何灵活性较低，难以处理非曼哈顿几何；FMLM虽支持任意多边形，但其约束仅限于语法层面，未涉及物理或功能约束。两者差异反映了“硬约束满足”与“几何多样性”之间的权衡，FMLM在多样性上占优，但在复杂功能约束下可能不如优化方法稳健。

## 总结

本文核心矛盾在于多条件平面生成的泛化性与几何有效性难以兼得，现有方法因表示碎片化需依赖多阶段流水线。FMLM通过标记语言统一编码平面与条件，将生成任务转化为序列预测，并借助语法约束解码实现硬约束满足。实验证明其在RPLAN上FID与GED显著优于经典基线，验证了序列表示在统一生成中的优越性。然而，其语法设计局限于单层平面，且约束仅覆盖几何拓扑，未触及功能可行性。当引入非矩形边界或复杂功能约束时，纯语法约束是否足以保证布局的工程可用性，仍是该方法面临的关键挑战。
