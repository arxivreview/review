# CVPR2026最新论文 ｜LongStream: Long-Sequence Streaming Autoregressive Visual Geometry ｜量规解耦的流式视觉几何重建

作者：Chong Cheng、Xianda Chen、Tao Xie 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.13172)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.13172)

> 长序列流式三维重建旨在从无限视频流中实时恢复度量尺度的场景几何，但现有自回归模型在处理数千帧时因首帧锚定与缓存污染导致轨迹在数十米内崩溃。LongStream 通过摒弃绝对位姿回归，转而预测关键帧相对位姿并独立估计全局尺度，从根源上解耦了坐标与尺度的自由度。该方法结合缓存一致性训练，在严格在线设置下实现了公里级序列的 18 FPS 实时重建。尽管其在长序列稳定性上显著优于基线，但静态场景假设与启发式关键帧策略仍限制了其在动态复杂环境中的泛化能力。

## 研究背景

流式重建的核心困境在于模型必须在不访问未来帧的前提下，从无限增长的图像序列中维持全局几何一致性。传统离线 Transformer 模型（如 VGGT）依赖全局注意力机制，需重新处理整个序列以集成新帧，导致计算冗余且无法实时部署。流式模型引入因果注意力与 KV 缓存以实现增量更新，但这类架构通常将位姿回归锚定在首帧坐标系上，迫使模型学习一个位置固定的映射。

这种“量规耦合”设计导致训练时模型仅接触短序列的小索引，而推理时需外推至大索引，形成“短训长测”的分布偏移。随着序列长度增加，模型对首帧 Token 的注意力沉没（Attention Sink）加剧，KV 缓存中的陈旧上下文污染当前预测，导致累积误差迅速发散，轨迹在数十米内完全失效。现有流式方法如 STream3R 和 StreamVGGT 虽采用因果 Transformer，但未能解决这一根本性的外推失效问题。LongStream 的切入点在于识别出这种失效源于坐标与尺度的自由度耦合，提出通过量规解耦将长程外推问题转化为恒定难度的局部估计任务。

## 核心方法

### 方法参照系

LongStream 基于 VGGT 风格的流式 Transformer 架构，包含 DINOv2 编码器、因果 Transformer 聚合器及任务头。与标准流式模型直接回归绝对位姿不同，本文的关键差异在于将位姿预测重新定义为关键帧相对位姿，并引入独立的尺度头，从而在架构与目标函数层面实现 SE(3) 与 Sim(3) 自由度的解耦。

### 关键帧相对位姿回归

传统流式模型预测当前帧相对于首帧的绝对位姿，导致预测难度随帧索引线性增加。LongStream 改为预测当前帧 $i$ 相对于最近关键帧 $k$ 的相对位姿 $\mathbf{T}_{i \leftarrow k}$。该设计动机在于消除首帧锚定带来的位置固定映射，使模型只需学习有界索引差 $(i-k)$ 内的局部几何关系，从而将外推问题转化为分布内的局部估计。相对位姿定义为：

$$
\mathbf{T}_{i \leftarrow k} = \mathbf{T}_k^{-1} \mathbf{T}_i
$$

其中 $\mathbf{T}_i$ 和 $\mathbf{T}_k$ 为世界到相机的绝对位姿。该定义在世界坐标系任意重参数化下保持不变，确保了预测对全局坐标选择的不变性。通过参考感知注意力机制，非关键帧仅关注关键帧及其之间的帧，进一步限制了上下文范围，避免了长程依赖的累积误差。

### 正交尺度学习与缓存一致性训练

为解决 Sim(3) 尺度漂移，LongStream 引入独立的尺度头，预测全局尺度因子 $s$。几何分支在尺度不变空间中优化形状，而尺度头独立预测 $s$，确保 $\partial L_{geom}/\partial s = 0$，即几何损失不隐式编码尺度信息。尺度损失在 log 空间计算以稳定梯度：

$$
L_{scale} = \left| \log s - \log s_{gt} \right|
$$

此外，针对因果 Transformer 中的注意力沉没与 KV 缓存污染，提出缓存一致性训练（CCT）。CCT 在训练时显式传递并修剪 KV 缓存，使训练时的可见性与推理时的滑动窗口一致，从而抑制对首帧 Token 的依赖。周期性缓存刷新机制进一步边缘化陈旧上下文，防止长期记忆饱和。

## 实验评估

实验在 KITTI、vKITTI、Waymo（户外）及 TUM、7Scenes（室内）数据集上进行，评估协议为严格在线、未来不可见。基线覆盖离线 Transformer（FastVGGT）、优化式 SLAM（MASt3R-SLAM, VGGT-SLAM）及流式模型（CUT3R, TTT3R, STream3R, StreamVGGT）。缺失 π3 因内存限制未测。

| 方法 | TUM ATE↓ | Oxford Spires ATE↓ | Waymo ATE↓ |
| :--- | :--- | :--- | :--- |
| FastVGGT | 0.418 | 36.577 | 1.281 |
| MASt3R-SLAM | 0.082 | 37.728 | 7.625 |
| VGGT-SLAM | 0.123 | 31.003 | 7.431 |
| CUT3R | 0.542 | 32.440 | 9.396 |
| TTT3R | 0.308 | 36.214 | 3.486 |
| STream3R | 0.633 | 37.569 | 42.203 |
| StreamVGGT | 0.627 | 37.255 | 45.101 |
| **LongStream** | **0.076** | **19.815** | **0.737** |

LongStream 在所有基准上取得最佳 ATE，尤其在 Waymo 长序列上显著优于流式基线，验证了量规解耦在抑制累积误差上的有效性。

| 配置 | ATE↓ | RPE↓ | Scale Err.↓ |
| :--- | :--- | :--- | :--- |
| Baseline | 8.043 | 2.207 | - |
| +RelPose | 2.819 | 0.750 | - |
| +Scale Head | 2.645 | 0.484 | 0.010 |
| +CCT | 0.115 | 0.126 | 0.035 |
| +Cache Refresh | 0.115 | 0.126 | 0.035 |

消融实验显示，从绝对位姿切换到相对位姿带来最大增益（ATE 从 8.043 降至 2.819），证实了量规解耦的核心作用。CCT 进一步将 ATE 降至 0.115，表明训练-推理一致性对抑制注意力沉没至关重要。

评估边界方面，论文未报告置信区间，且部分基线（如 VGGT-SLAM）在长序列上因 OOM 或跟踪失败导致结果不可比。代码未开源，仅提供项目页面，超参数细节有限，可复现性依赖附录。

## 关联研究分析

从问题动机看，LongStream 与 Scal3R 均针对长序列漂移，但 Scal3R 采用测试时训练（TTA）框架，通过高效上下文聚合捕获全局线索，而 LongStream 通过架构层面的量规解耦避免 TTA 的计算开销。Scal3R 的 TTA 在公里级序列中解决了 VGGT 的内存瓶颈，但缺乏标准化评测，难以与纯前馈模型公平比较；LongStream 的严格在线设置则提供了更严格的实时性约束，但其相对位姿回归是否牺牲了全局闭环优化能力，论文未给出明确回答。

从方法设计看，LongStream 借鉴了 MapAnything 的尺度 Token 思想，但将其与因果 Transformer 的 KV 缓存机制结合，提出了 CCT。与 StreamVGGT 相比，后者依赖蒸馏提升一致性，但长程稳定性仍受缓存污染限制；LongStream 通过显式修剪缓存和周期性刷新，从机制上抑制了陈旧上下文的影响。这种设计差异源于对 Transformer 注意力退化机制的不同理解：StreamVGGT 视其为训练数据不足问题，而 LongStream 视其为架构固有的注意力沉没与训练-推理不匹配问题。

## 总结

LongStream 旨在解决长序列流式重建中因首帧锚定与尺度耦合导致的累积误差发散问题。现有流式模型因“短训长测”的分布偏移及 KV 缓存污染，在数十米内即失效，而 LongStream 通过关键帧相对位姿回归与正交尺度学习，将长程外推转化为恒定难度的局部估计，并结合缓存一致性训练消除训练-推理偏差。实验表明，该方法在 TUM 上取得 0.076 的 ATE，在 Waymo 上实现 0.737 的 ATE，显著优于现有流式基线。然而，模型仍假设场景静态，且依赖启发式关键帧调度，在点图一致性上随窗口增长出现轻微退化。当场景中存在动态物体或非刚性形变时，相对位姿回归的局部性假设是否仍能维持全局几何一致性，论文未给出回答。
