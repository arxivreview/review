> 物理接地视频生成旨在弥合视觉保真度与物理真实性之间的鸿沟，核心挑战在于将离散物理定律内化为连续动力学表征。现有扩散模型依赖像素预测，常违反重力与碰撞等基础定律，且现有评估指标无法量化物理违规。MoReGen 提出在代码域生成可执行物理仿真代码，通过多智能体反馈循环确保牛顿力学严格遵循。该框架在自建基准上实现了轨迹保真度的显著提升，但其适用范围局限于结构化牛顿现象，对开放域复杂物理的泛化能力存疑。

## 研究背景

当视频生成模型面对“球体碰撞”或“单摆运动”等提示时，其输出往往在视觉上逼真但物理上荒谬——物体穿透、动量不守恒或轨迹漂移。这种“视觉逼真但物理不可信”的矛盾源于扩散模型（Diffusion Models）的归纳偏置：优化目标倾向于记忆训练数据中的统计相关性，而非推断支配运动的因果物理律。在分布外（Out-of-Distribution, OOD）提示下，模型无法从物理原理推理，仅能复现看似合理的像素模式，导致物理违规频发。

物理接地视频生成领域的主流路线分为显式仿真引导与隐式数据驱动两类。显式路线如 PhysGen 依赖 3D 重建与参数估计，虽保证物理一致性但计算开销大且受限于重建精度；隐式路线如 VJEPA-2 利用世界模型作为奖励信号进行推理时对齐，提升了物理合理性但缺乏显式物理保证。现有评估体系依赖 FVD 或基于 VLM 的语义评分，前者无法捕捉运动细节，后者在 OOD 场景下存在幻觉与偏差。MoReGen 的切入点在于彻底放弃像素级扩散生成，转而将自然语言直接转化为可执行的物理仿真代码，通过代码执行确保物理定律的严格遵循，并引入基于轨迹的定量评估指标以解决现有指标失效问题。

## 核心方法

### 方法参照系

物理仿真引导生成路线的标准流程为：从输入图像或文本重建 3D 场景，估计物理参数，执行显式仿真获取轨迹，最后渲染视频。MoReGen 的关键差异在于用 LLM 代码生成替代了传统的 3D 重建与参数估计环节，将物理仿真嵌入代码执行沙箱，实现了从自然语言到物理轨迹的直接映射。

### 结构化物理规格解析

传统方法依赖通用 LLM 推断物理参数，常因提示不完整导致参数缺失或幻觉。MoReGen 引入监督微调（SFT）的文本解析智能体 $\mathcal{A}_{text}$，将自然语言映射为结构化物理规格 $S$。其训练目标为最小化下一词元预测损失：

$$ \mathcal{L}_{SFT} = -\sum_{(x, S) \in \mathcal{D}} \log P(S|x) $$

该公式迫使模型学习从模糊描述中提取质量、速度、约束等关键物理量，确保输入仿真的完整性。设计动机在于解决通用 LLM 在物理参数推断上的不稳定性，通过现象特定的 Schema 约束输出格式，实现物理参数的鲁棒估计。

### 代码域仿真与多智能体反馈

代码编写智能体 $\mathcal{A}_{coder}$ 将规格 $S$ 转化为基于 Pymunk 或 Blender 的可执行代码 $C_t$，在沙箱中执行以获取物体轨迹 $T$。渲染智能体 $\mathcal{A}_{render}$ 根据 $T$ 生成视频 $v_t$。评估器 $E$ 基于轨迹与 VLM 评分提供反馈，迭代修正代码。其核心机制是轨迹保真度度量：

$$ \text{DTW-N}(T_{pred}, T_{gt}) = \frac{\text{DTW}(T_{pred}, T_{gt})}{\text{Length}(T_{gt})} $$

该公式通过动态时间规整（Dynamic Time Warping, DTW）对齐预测与真值轨迹，并归一化以消除时长差异。设计动机在于解决扩散模型无法提供可验证物理轨迹的问题，通过代码执行确保牛顿力学严格遵循，并通过反馈循环修正代码逻辑错误，实现物理一致性的闭环优化。

## 实验评估

实验在自建 MoReSet 基准上进行，该基准包含 1,275 个人工标注视频，覆盖 9 类牛顿现象。基线涵盖开源模型（Wan2.2, CogVideoX）、商业模型（Sora2, Veo3）及物理模型（NewtonGen, WISA）。MoReGen 在 MoRe Metrics 上表现最优，DTW-N 为 0.06，显著优于 Sora2（0.08）与 WISA（0.09）。

| 模型 | DTW ↓ | DTW-N ↓ | Procrustes ↓ |
| :--- | :--- | :--- | :--- |
| Sora2 | 11.21±12.76 | 0.08±0.07 | 0.55±0.30 |
| WISA | 12.67±9.22 | 0.09±0.08 | 0.68±0.27 |
| **MoReGen** | **8.93±9.61** | **0.06±0.07** | **0.48±0.30** |

消融实验显示，SFT 与反馈循环对性能提升至关重要。Qwen2.5-Coder-14B 在无 SFT 时无法生成可执行代码，加入 SFT 后 DTW 降至 8.93；加入反馈循环后，GPT-5 的 DTW 从 15.47 降至 14.13。这表明代码生成的鲁棒性依赖于结构化监督与迭代修正，而非单纯依赖大模型规模。

评估边界方面，MoReSet 仅覆盖 9 类牛顿现象，缺乏流体、变形体等复杂物理场景，限制了泛化性验证。代码开源，但物理引擎 API 的依赖可能影响跨平台复现。现有指标如 Trajan 和 VideoPhy2 在 OOD 下失效，MoRe Metrics 提供了更可靠的轨迹评估，但缺乏与人类感知的直接关联验证。

## 关联研究分析

从方法设计看，MoReGen 与 PhysGen 同属显式仿真引导路线，但 PhysGen 依赖 3D 重建与参数估计，而 MoReGen 用 LLM 代码生成替代了这一环节。这一差异源于任务特性：PhysGen 处理复杂交互场景，需精确几何信息；MoReGen 聚焦牛顿力学，代码生成足以捕捉运动规律。然而，代码生成在复杂几何约束下的精度是否足够，论文未给出回答。

从评估协议看，MoReGen 批评 VideoPhy 的 PC 指标在 OOD 下失效，提出基于轨迹的 MoRe Metrics。这与 WMReward 的推理时对齐思路不同：WMReward 利用世界模型奖励优化生成过程，而 MoReGen 通过代码执行确保物理正确性。MoReGen 的评估更直接，但缺乏对视觉保真度的量化，可能牺牲了美学质量。

## 总结

MoReGen 旨在解决视觉逼真与物理可信的矛盾，通过代码域生成确保牛顿力学严格遵循。其核心创新在于将 LLM 代码生成与物理仿真结合，并通过多智能体反馈循环修正代码逻辑。实验显示，MoReGen 在 MoReSet 上 DTW-N 达 0.06，优于 Sora2 与 WISA，证明了代码域生成的物理一致性优势。然而，其边界在于仅覆盖 9 类牛顿现象，缺乏复杂物理场景验证，且未量化视觉保真度损失。当提示涉及流体或变形体时，代码生成能否准确捕捉其动力学特性，论文未给出回答。
