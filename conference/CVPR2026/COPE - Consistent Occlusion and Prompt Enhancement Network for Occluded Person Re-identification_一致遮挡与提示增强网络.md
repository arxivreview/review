# CVPR2026最新论文 ｜COPE: Consistent Occlusion and Prompt Enhancement Network for Occluded Person Re-identification ｜一致遮挡与提示增强网络

研究机构：厦门大学

作者：Siyi Sun、Jinliang Lin、Juanjuan Weng 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_210bd15e42f7)

> 遮挡行人重识别（Occluded Person Re-ID）的核心困境在于，遮挡物不仅遮蔽了判别性身体部位，其自身纹理还会干扰特征提取，导致不同身份的行人因相似的遮挡物而被错误匹配。现有数据增强方法侧重遮挡多样性却忽视相似遮挡的误导性，特征重建方法虽能恢复信息但推理开销巨大。COPE 通过跨身份一致遮挡（CICO）在数据与特征层面抑制遮挡干扰，结合提示背景填充（PBF）增强前景鲁棒性，并利用轻量级提示相似度评分（PSS）在推理阶段优化匹配，在 Occluded-Duke 上以 82.4% Rank-1 达到当前最优，但其对极端随机遮挡的泛化能力仍存疑。

## 研究背景

当 Transformer 骨干网络处理遮挡图像时，全局自注意力机制使所有 Patch Token 参与交互。若遮挡区域与前景区域在特征空间中未解耦，遮挡 Token 会错误地吸引注意力权重，导致模型将车辆、树木等背景纹理误认为身份线索。这一现象被称为遮挡特征干扰，它使得即使可见区域包含足够身份信息，检索结果仍可能指向拥有相似遮挡物的其他行人。为解决此问题，原型对比学习（Prototype Contrastive Learning, PCL）通过记忆库动态更新类中心，拉近同类样本在特征空间的距离，但 PCL 本身无法区分特征来源是前景还是遮挡，需额外的空间定位或特征约束机制配合。

遮挡鲁棒性研究长期面临两条路线的瓶颈：数据增强与特征重建。数据增强方法如 SPT 和 ADM 通过粘贴外部遮挡物或注入噪声模拟遮挡，但这类方法仅关注遮挡形态的多样性，忽略了真实场景中“相似遮挡导致错误匹配”的干扰机制，且未解决完整行人图像中背景干扰的问题。特征重建方法如 FPC 和 RFCnet 依赖 K 近邻库中的相似样本恢复缺失特征，虽能缓解信息丢失，但推理时需遍历大量候选样本进行特征聚合，计算延迟高，难以满足实时部署需求。COPE 的切入点在于，将遮挡视为一种需要被模型“识别并抑制”的干扰源，而非单纯需要被“恢复”的信息缺失，通过跨身份一致性约束让模型学会区分遮挡特征与身份特征，从而在降低推理成本的同时提升匹配精度。

## 核心方法

### 方法参照系

COPE 基于 CLIP-ViT 骨干网络，采用 PCL 损失函数优化特征空间。与标准 Re-ID 流程的关键差异在于，COPE 在训练阶段引入了针对遮挡特性的数据增强与特征约束模块，并在推理阶段增加了基于提示分数的后处理步骤，而非仅依赖单一的全局特征距离计算。

### 跨身份一致遮挡（CICO）

CICO 模块旨在解决相似遮挡导致的特征干扰问题。传统增强方法随机生成遮挡，导致模型难以区分遮挡物与身份特征。CICO 在数据层面，预初始化 $M$ 个高斯形状遮挡，每个批次采样 $N$ 种遮挡类型并应用于 $N$ 个不同身份，确保同一遮挡类型跨身份共享。在特征层面，引入遮挡一致性损失 $L_{oc}$，强制同一遮挡类型下不同身份样本的遮挡区域特征相似：

$$ L_{oc} = \sum_{n=1}^{N} \sum_{i,j \in I_n} \| F_{cico}^n(i) - F_{cico}^n(j) \|^2 $$

其中 $F_{cico}^n(i)$ 为第 $i$ 个样本在第 $n$ 种遮挡下的遮挡区域特征，通过全局加权平均池化（GWAP）提取。该损失迫使模型将遮挡区域编码为与身份无关的一致表示，从而在注意力机制中自然降低遮挡 Token 的权重，将注意力转移至前景区域。

### 提示背景填充与相似度评分（PBF & PSS）

PBF 模块利用 CLIP 的视觉-语言对齐能力生成前景热力图。通过可学习提示词 $v$ 与文本 "person" 结合，生成条件化文本特征，与图像 Patch 特征计算余弦相似度得到热力图 $H$。随后，背景区域被随机颜色填充，模拟不同环境。为保持前景特征一致性，引入前景对齐损失 $L_{align}$：

$$ L_{align} = \| \text{GWAP}(H, f_{src}^{pat}) - \text{GWAP}(H, f_{pbf}^{pat}) \|^2 $$

PSS 模块在推理阶段发挥作用。它利用 PBF 生成的热力图通过 MLP 计算提示分数 $P$，反映前景完整性。检索时，选取 Top-$K_1$ 候选样本和 Top-$K_2$ 高提示分数中间样本，计算中间相似度增量 $\Delta$ 并修正最终相似度：

$$ S_i = S_i^G + \Delta_i, \quad \Delta = \frac{1}{K_2} (S_{inter} \times S_{K_2}^P) $$

该机制无需特征重建，仅通过相似度计算优化匹配，显著降低推理延迟。

## 实验评估

COPE 在 Occluded-Duke、P-Duke、Occluded-ReID、Partial-ReID 及 Market-1501、MSMT17 上进行了评估。基线覆盖 ViT、ResNet-50 及 CLIP 变体，对比了 SPT、ADM 等增强方法及 FPC 等重建方法。在 Occluded-Duke 上，COPE 取得 82.4% Rank-1 和 76.4% mAP，较 CLIP-ReID 基线提升显著。

| 模块组合 | Rank-1 | mAP |
| :--- | :--- | :--- |
| Baseline (ViT) | 63.5 | 53.1 |
| + CICO | 67.4 | 57.8 |
| + CICO + PBF | 76.8 | 68.9 |
| + CICO + PBF + PSS | 82.1 | 75.4 |

消融实验显示，CICO 单独贡献 +4.6% Rank-1，PBF 贡献 +2.0%，PSS 贡献 +5.3%。移除遮挡一致性损失导致 Rank-1 下降 2.9%，验证了特征约束的必要性。PSS 相比 Re-ranking 快 121 秒，且与 Re-ranking 兼容，组合使用可进一步提升精度。

评估边界方面，COPE 未在 Mamba 等最新高效架构上验证，且 Occluded-Duke 的遮挡程度与 Market-1501 Occluded 存在差异，跨基准可比性受限。代码已开源，超参数设置（如 $K_1=200, K_2=5$）在文中详细列出，可复现性良好。

## 关联研究分析

从问题动机看，COPE 与 Sh-ViT 同属遮挡鲁棒性 SOTA，但 Sh-ViT 侧重注意力机制的修改以抑制遮挡干扰，而 COPE 侧重数据增强策略与后处理优化。Sh-ViT 在 Market-1501 Occluded 上达到 94.60% Rank-1，但 COPE 在 Occluded-Duke 上以 82.4% 领先，两者评估协议不同，难以直接比较。COPE 的创新在于将遮挡视为需被“识别”的干扰源，而非仅被“抑制”的噪声，这一视角差异源于其对相似遮挡导致错误匹配现象的关注，而 Sh-ViT 未明确处理此问题。

从方法设计看，COPE 与 FPC 形成鲜明对比。FPC 依赖 K 近邻特征重建，推理时需遍历大量样本，计算开销大；COPE 的 PSS 模块仅利用相似度计算，无需特征重建，推理时间仅为 FPC 的 54%。这一效率优势源于 COPE 对“信息丢失”的处理策略：不尝试恢复缺失特征，而是通过提示分数评估样本可靠性，利用高置信度样本优化匹配。这种策略在遮挡严重时可能牺牲部分信息恢复能力，但换来了实时部署的可行性，体现了精度与效率的权衡。

## 总结

COPE 解决了遮挡行人重识别中相似遮挡导致特征干扰与特征重建高计算开销的矛盾。其切入点在于通过跨身份一致遮挡让模型学会区分遮挡与身份特征，并利用提示分数在推理阶段优化匹配，避免了高成本的特征重建。实验证明，COPE 在 Occluded-Duke 上以 82.4% Rank-1 和 76.4% mAP 达到 SOTA，且推理效率显著优于 FPC 等方法。然而，COPE 的 CICO 模块依赖预定义的遮挡类型，对极端随机遮挡的泛化能力未充分验证。当遮挡物形态高度多样化且无重复模式时，跨身份一致性约束是否仍能有效抑制干扰，论文未给出回答。
