# CVPR2026最新论文 ｜AntiStyler: Defending Object Detection Models Against Adversarial Patch Attacks Using Style Removal ｜风格移除防御对抗补丁

研究机构：以色列内盖夫本-古里安大学

作者：Idan Yankelev、Edita Grolman、Yarin Yerushalmi Levi 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_b14a1f17c4d6)

> 物理对抗补丁防御长期受困于鲁棒性与实时性的权衡，现有后训练方法要么牺牲干净图像性能，要么因计算开销无法满足自动驾驶等场景的帧率要求。AntiStyler 抓住了对抗补丁在特征空间中呈现“随机风格”这一被忽略的分布差异，将风格迁移改造为风格移除，通过最大化风格损失实现零样本掩码。该方法在无需重训练的前提下，以 92.7 ms 的推理延迟实现了 10-12 FPS 的实时处理能力，但其对 Transformer 架构的增益有限，且依赖预训练 CNN 的纹理敏感性，在复杂 3D 渲染攻击下的鲁棒性边界尚待明确。

## 研究背景

对抗补丁攻击通过覆盖图像局部区域诱导目标检测器误判，其物理部署特性要求防御机制必须克服打印失真与视角变化带来的非线性干扰。风格迁移（Style Transfer, ST）技术原本用于图像合成，其核心在于分离图像的内容表示与风格表示。内容表示由深层卷积特征图决定，而风格表示由浅层特征图的 Gram 矩阵刻画。这种分离机制为识别图像中的异常纹理提供了理论工具，因为对抗补丁通常表现为高频噪声或鲜艳颜色，在特征空间中与背景形成显著的风格差异。

现有防御路线主要分为训练时防御与后训练防御。训练时防御如对抗训练（KDAT）需针对特定架构重训练，且往往导致干净图像性能下降；后训练防御如 DIFFender 使用扩散模型重建，虽通用性强但迭代采样导致单帧处理时间超过 7000 ms，无法满足实时检测至少 10 FPS 的要求。NutNet 虽轻量但基于自编码器重建误差，对良性图像存在误掩码风险。AntiStyler 的切入点在于利用预训练 CNN 提取特征，通过风格移除（Style Removal, SR）过程直接定位并掩码具有“随机风格”的像素，从而在保持干净图像性能的同时，将推理延迟压缩至 92.7 ms，解决了实时性与鲁棒性不可兼得的矛盾。

## 核心方法

### 风格移除参照系

传统风格迁移旨在融合内容图像与风格图像的特征，其损失函数为内容损失与风格损失的加权和。本文将其改造为风格移除过程，核心差异在于目标从“匹配风格”转变为“去除风格”。这一转变基于域适应理论，将风格损失解释为最大均值差异（MMD）的二阶多项式核，最大化风格损失即意味着将输出图像的分布推离随机风格分布。

### 随机填充与风格移除

设计动机在于解决良性图像中缺乏“随机风格”导致的误掩码问题。若在良性图像上直接执行风格移除，模型可能错误地移除背景纹理。为此，AntiStyler 在输入图像边缘添加 10 像素的随机值填充，确保良性与对抗图像均存在明确的随机风格区域。风格移除损失函数定义为：

$$ L_{SR}(X_O, X_C, X_S) = \alpha L_C(X_O, X_C) - \beta L_S(X_O, X_S) $$

其中 $L_C$ 为内容损失，$L_S$ 为风格损失，$\alpha=1, \beta=1000$。负号表示最大化风格差异，迫使输出图像 $X_O$ 保留内容 $X_C$ 的同时，消除风格图像 $X_S$（随机填充）的风格特征。

### 动态阈值掩码生成

风格移除后的图像与填充输入图像进行逐像素差分，生成原始掩码。设计动机在于风格移除过程对对抗补丁区域的扰动远大于背景区域，差分幅度可量化异常程度。掩码生成公式为：

$$ Mask[i, j] = \begin{cases} 1 & \text{if } |AntiStyled[i, j] - PaddedInput[i, j]| \ge \tau \cdot MaxChange \\ 0 & \text{otherwise} \end{cases} $$

其中 $MaxChange$ 为全图最大差分，$\tau$ 为动态阈值。该机制避免了固定阈值在不同光照条件下的失效，随后通过膨胀、腐蚀等空间滤波器去除噪声，最终生成用于掩码对抗区域的二值掩码。

## 实验评估

实验在 COCO 与 INRIA 数字数据集及 APRICOT、Superstore 物理数据集上进行，对比了 ObjectSeeker、PAD、DIFFender、NutNet 和 KDAT 五种防御方法。基线覆盖了窗口聚合、语义独立性、扩散重建、自编码器重建及知识蒸馏路线，但缺失基于认证鲁棒性的方法（如 CertMask）及针对 Transformer 架构的专用防御。

| 防御方法 | Faster R-CNN mAP (Mean) | DETR mAP (Mean) | 处理时间 (ms) |
| :--- | :--- | :--- | :--- |
| Undefended | 36.2 | 46.2 | - |
| ObjectSeeker | 38.2 | 48.8 | 4191.9 |
| PAD | 39.5 | 50.3 | 55098.8 |
| DIFFender | 30.6 | 36.7 | 7606.0 |
| NutNet | 36.3 | 48.7 | 45.2 |
| KDAT | 42.1 | 50.7 | 43.2 |
| AntiStyler | 43.6 | 51.1 | 92.7 |

AntiStyler 在 Faster R-CNN 上平均 mAP 达 43.6%，高于 NutNet 的 36.3% 和 KDAT 的 42.1%，且处理时间 92.7 ms 远低于 PAD 的 55098.8 ms。在 DETR 上，AntiStyler 平均 mAP 51.1% 略高于 KDAT 的 50.7%，但优势缩小，表明该方法对 Transformer 架构的增益有限。

消融实验显示，去除随机填充（UP 变体）导致良性性能下降，验证了填充对防止误掩码的关键作用。骨干网络对比中，VGG-19 在对抗鲁棒性上优于 ResNet-50 和 EfficientNetV2，mAP 分别为 43.6%、39.8% 和 37.8%。VGG-19 的简单卷积结构保留了更多局部纹理信息，使其对高频噪声更敏感，而残差连接可能平滑了这些异常特征。

评估边界方面，论文未报告置信区间，且物理数据集 APRICOT 仅 138 张测试图像，统计显著性有限。代码已开源，超参数（$\alpha=1, \beta=1000, \tau$ 动态）明确，但 $\tau$ 的具体取值未在正文给出，需查阅补充材料。

## 关联研究分析

从方法设计看，AntiStyler 与 DIFFender 同属后训练重建类防御，但 DIFFender 依赖扩散模型的迭代采样，计算开销巨大；AntiStyler 利用预训练 CNN 的单次前向传播与优化，将延迟降低两个数量级。这一差异源于对“异常”定义的捕捉方式不同：DIFFender 依赖重建误差，AntiStyler 依赖风格差异。然而，AntiStyler 依赖 VGG-19 的纹理敏感性，而 DIFFender 的扩散模型可能捕捉更复杂的语义异常，在对抗补丁语义与背景高度相似时，AntiStyler 的掩码精度是否优于 DIFFender，论文未提供直接对比。

从问题动机看，AntiStyler 与 NutNet 均追求轻量级掩码，但 NutNet 基于自编码器重建误差，易受良性图像纹理变化影响；AntiStyler 通过随机填充引入可控的“噪声基准”，使掩码决策相对化而非绝对化。这种设计在固定视角场景下有效，但在 3D 渲染攻击（如 BiTAA）中，补丁的几何一致性可能使其风格特征与背景融合，此时基于 2D 纹理的风格移除是否仍能准确定位，存在不确定性。

## 总结

AntiStyler 解决了物理对抗补丁防御中实时性与鲁棒性的核心矛盾，通过风格移除技术将推理延迟压缩至 92.7 ms，同时保持干净图像性能。其创新在于利用随机填充构造可控的风格差异基准，避免了传统重建方法的误掩码问题。实验证明其在 Faster R-CNN 上平均 mAP 达 43.6%，优于多数后训练防御。然而，该方法在 DETR 架构上优势缩小，且依赖 VGG-19 的纹理敏感性，对复杂 3D 渲染补丁的鲁棒性未充分验证。当对抗补丁通过 3D 高斯泼溅实现几何一致性与语义融合时，基于 2D 风格差异的掩码机制是否仍能保持定位精度，论文未给出回答。
