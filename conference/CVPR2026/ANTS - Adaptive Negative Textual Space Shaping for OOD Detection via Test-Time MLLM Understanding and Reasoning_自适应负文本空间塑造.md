# CVPR2026最新论文 ｜ANTS: Adaptive Negative Textual Space Shaping for OOD Detection via Test-Time MLLM Understanding and Reasoning ｜自适应负文本空间塑造

研究机构：香港理工大学、哈尔滨工业大学

作者：Wenjie Zhu、Yabin Zhang、Xin Jin 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.03951)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.03951)

> 分布外检测（Out-of-Distribution Detection, OOD）旨在识别模型训练分布之外的样本，其核心难点在于近邻 OOD 样本与分布内（ID）样本在特征空间高度重叠，导致传统基于最大 Softmax 概率（MSP）或静态负标签的方法失效。现有视觉语言模型（VLMs）方法依赖预定义的语义距离挖掘负标签，缺乏对实际 OOD 图像内容的理解，且在处理语义接近 ID 的样本时产生大量假阴性。本文切入点在于利用多模态大语言模型（MLLMs）的测试时理解与推理能力，动态生成描述性负句与视觉相似负标签，构建自适应负文本空间。该方法通过零样本、免训练的方式显著提升了近邻与远端 OOD 检测性能，但其依赖 MLLM 推理延迟及历史数据流平稳性的假设，在极端动态环境下仍存疑。

## 研究背景

当检测器面对开放世界中的未见数据时，其训练域与测试域的数据分布出现系统性差异，即分布偏移。这种偏移导致传统分类器决策边界失效，而实际场景中往往能获取少量目标域样本，这恰好构成了小样本学习的条件：仅凭每个类别极少量标注样本泛化到新任务。解决此类问题的经典框架是原型网络，它计算各类别支持样本的特征均值作为"原型"，再通过距离度量完成分类。

传统 OOD 检测主要依赖视觉模态的后验评分，如 MSP 或能量分数，但这类方法在语义偏移下表现有限。随着 VLMs 的兴起，研究者引入负标签（NLs）来增强检测能力，如 NegLabel 通过挖掘语义距离远的词汇，EOE 利用大语言模型生成视觉相似标签。然而，这些方法存在三个关键瓶颈：首先，静态负标签缺乏对实际 OOD 图像内容的理解，导致负标签与 OOD 图像在特征空间中距离过远；其次，在处理近邻 OOD 时，现有方法要么忽略视觉相似性，要么为所有 ID 类别生成相似标签，导致大量假阴性标签干扰检测；最后，这些方法假设任务设定（近邻或远端）已知，无法适应开放环境中动态变化的分布。本文旨在利用 MLLMs 的测试时理解与推理能力，动态塑造负文本空间，解决上述局限。

## 核心方法

### 方法参照系

本文方法属于 VLMs 辅助 OOD 检测路线，其标准流程是利用 CLIP 模型计算图像特征与 ID 标签及负标签的相似度，通过比较两者差异判断样本是否 OOD。本文与通用流程的关键差异在于，负标签并非静态挖掘或一次性生成，而是基于历史测试图像动态生成，并通过自适应权重平衡不同负文本空间的贡献。

### 表达性负句（ENS）生成

针对静态负标签缺乏 OOD 图像理解的问题，本文引入表达性负句（Expressive Negative Sentences, ENS）。首先，通过 NegLabel 评分函数筛选历史测试图像中得分低于自适应阈值 $\gamma^*$ 的样本作为负图像 $X_{neg}$。自适应阈值通过选取负图像中得分最低的 $\eta$ 比例样本确定，避免了固定阈值在不同数据集下的失效。随后，提示 MLLM 描述这些负图像，生成简短且不含预测 ID 标签的句子 $Y_{ens}^-$。ENS 评分函数定义为：

$$ S_{ens}(v) = \max_{y^- \in Y_{ens}^-} \frac{v \cdot t^-}{\tau} $$

其中 $v$ 为测试图像特征，$t^-$ 为 ENS 文本特征，$\tau$ 为温度参数。该设计通过 MLLM 对 OOD 图像内容的直接描述，使负标签在特征空间中更贴近真实 OOD 分布，从而提升远端 OOD 检测性能。

### 视觉相似负标签（VSNL）与自适应加权

ENS 虽能捕捉远端 OOD，但难以区分语义接近 ID 的近邻 OOD。为此，本文引入视觉相似负标签（Visually Similar Negative Labels, VSNL）。首先，识别与负图像视觉相似的 ID 类别子集 $Y_{sim}$，通过计算历史测试图像在各 ID 类别上的分类比例 $F(y_i)$ 并选取前 $\delta$ 比例类别实现。随后，提示 MLLM 生成与 $Y_{sim}$ 视觉相似的负标签 $Y_{vsnl}^-$。VSNL 评分函数为：

$$ S_{vsnl}(v) = \max_{y^- \in Y_{vsnl}^-} \frac{v \cdot t^-}{\tau} $$

为平衡 ENS 与 VSNL 在不同 OOD 场景下的表现，本文设计自适应加权评分：

$$ S_{ada}(v) = \lambda S_{ens}(v) + (1-\lambda) S_{vsnl}(v) $$

其中权重 $\lambda$ 根据历史负图像在 ENS 和 VSNL 空间中的得分分布动态调整。当负图像更倾向于 ENS 空间时，$\lambda$ 接近 1，反之接近 0。该机制使模型无需先验任务设定即可自适应处理近邻与远端 OOD 场景。

## 实验评估

实验在 ImageNet-1K 作为 ID 数据集，iNaturalist、SUN、Places、Textures 作为远端 OOD 数据集，NINCO、SSB-hard 作为近邻 OOD 数据集上进行。基线覆盖 NegLabel、EOE、AdaNeg 等 VLMs 方法，但缺失扩散模型类（如 SCOPED）及几何分析类（如 GEODE）基线。

| 方法 | iNaturalist AUROC | SUN AUROC | Places AUROC | Textures AUROC | Average FPR95 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| NegLabel | 90.31 | 90.27 | 90.14 | 97.52 | 27.34 |
| EOE | 95.98 | 92.95 | 92.90 | 99.49 | 17.31 |
| ANTS | 99.75 | 98.77 | 96.10 | 96.38 | 11.20 |

ANTS 在远端 OOD 检测中平均 FPR95 为 11.20，显著优于 EOE 的 17.31 和 NegLabel 的 27.34。在近邻 OOD 检测中，ANTS 的 FPR95 为 60.98，优于 NegLabel 的 68.18，但略高于 EOE 的 60.11。

消融实验显示，引入 ENS 使远端 OOD FPR95 从 43.87 降至 19.22，引入 VSNL 使近邻 OOD FPR95 从 74.36 降至 63.11。自适应权重 $\lambda$ 相比固定权重 0.5，在近邻和远端 OOD 上均取得最优性能，验证了动态平衡的必要性。

评估边界方面，论文未报告置信区间，且 MLLM 幻觉导致的负句长度波动（平均 8.4 词）可能影响检测稳定性。代码已开源，使用 ViTB/16 和 LLaVA-1.5-7B，推理延迟为 2.84 ms/图，但 MLLM 调用延迟较高，仅对部分样本触发。

## 关联研究分析

从问题动机看，本文与 NegLabel 和 EOE 的核心差异在于负标签的生成机制。NegLabel 依赖静态语料挖掘，EOE 依赖 LLM 一次性生成，两者均缺乏对实际 OOD 图像内容的动态理解。本文通过 MLLM 测试时理解生成 ENS，使负标签更贴近真实 OOD 分布，解决了静态负标签与 OOD 图像特征距离过远的问题。这一改进源于任务特性：近邻 OOD 检测需要更精细的语义区分，静态方法无法提供足够的信息量。

从方法设计看，本文与 AdaNeg 的差异在于自适应机制的实现方式。AdaNeg 通过存储测试图像计算图像代理分数，结合多模态分数；本文则通过文本空间自适应加权，消除模态间隙。本文的自适应权重 $\lambda$ 依赖历史数据分布，在数据流极度非平稳时可能失效，而 AdaNeg 的图像代理分数可能更鲁棒。此外，本文未探索 MLLM 推理延迟与检测精度的权衡优化，在实时性要求极高的场景下，MLLM 调用成本可能成为瓶颈。

## 总结

本文要解决的核心矛盾是 VLMs 方法在近邻 OOD 检测中因静态负标签缺乏 OOD 图像理解而导致的假阴性问题。本文抓住的切入点是 MLLMs 的测试时理解与推理能力，通过动态生成 ENS 和 VSNL，构建自适应负文本空间。方法通过自适应加权评分平衡不同负文本空间，实现了零样本、免训练的 OOD 检测。实验证明，ANTS 在 ImageNet-1K 远端 OOD 检测中 FPR95 降至 11.20，近邻 OOD 检测中 FPR95 为 60.98，显著优于基线。本文的边界在于依赖 MLLM 推理延迟及历史数据流平稳性，在极端动态环境下自适应权重可能失效。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
