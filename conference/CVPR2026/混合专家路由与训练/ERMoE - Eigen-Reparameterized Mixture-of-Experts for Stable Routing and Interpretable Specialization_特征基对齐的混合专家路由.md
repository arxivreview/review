# CVPR2026最新论文 ｜ERMoE: Eigen-Reparameterized Mixture-of-Experts for Stable Routing and Interpretable Specialization ｜特征基对齐的混合专家路由

研究机构：美国南加州大学

作者：Anzhe Cheng、Shukai Duan、Shixuan Li 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.10971)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.10971)

> 混合专家（Mixture-of-Experts, MoE）架构旨在解耦参数容量与计算成本，但标准路由机制常因门控噪声导致Token分配失配，进而引发专家坍缩。现有方案依赖辅助负载均衡损失（Load-Balancing Loss, LBL）来强制均匀分布，却往往以牺牲专家专业化程度和主任务梯度质量为代价。本文提出特征基对齐路由，将专家权重重参数化为正交特征基，利用Token特征与专家基向量的余弦相似度替代传统Logits进行评分，从而在消除显式平衡损失的同时实现内生负载平衡。该方法在视觉分类与检索任务上验证了有效性，但其正交约束对专家表达复杂非线性流形能力的潜在限制尚存疑。

## 研究背景

当视觉Transformer（ViT）引入稀疏专家层以扩展模型容量时，路由机制成为性能瓶颈。标准Top-k路由依赖可学习的门控Logits，这种离散选择机制存在固有的梯度流中断问题，且容易陷入“富者愈富”的动态失衡，导致部分专家被过度激活而其他专家闲置。为缓解此问题，主流实践引入辅助负载均衡损失（LBL），通过惩罚专家利用率不均来防止坍缩。然而，LBL系数过大时会向主任务注入干扰梯度，导致路由过度均匀化，削弱了专家应有的功能分化，形成“稳定性-专业化”的固有冲突。

MoE路由研究的核心矛盾在于如何在保持稀疏激活效率的前提下，实现路由决策与专家内部表征结构的内在一致性。早期工作如V-MoE和DeepMoE侧重于架构扩展，但未能解决路由失配的根源；Soft-MoE等可微路由方法虽恢复了梯度流动，却牺牲了硬稀疏约束。本文的切入点在于质疑“路由应独立于专家结构”的假设，主张路由评分应直接反映Token在专家表征子空间中的几何对齐程度，而非依赖外部学习的标量Logits。

## 核心方法

### 方法参照系

标准MoE路由流程中，路由器通过线性投影计算Logits，经Softmax归一化后执行Top-k硬选择，并辅以LBL平衡专家负载。本文的关键差异在于摒弃了独立的路由器参数，将路由评分机制嵌入专家权重的几何结构中，实现了路由与专家表征的紧耦合。

### 专家权重的正交重参数化

传统专家权重矩阵 $W_e$ 是自由参数，其列向量间可能存在高度相关性，导致专家功能重叠。本文设计动机在于通过强制专家内部方向的解耦，从根源上消除表征冗余。每个专家权重被分解为：

$$ W_e = U_e S_e V_e^T $$

其中 $U_e, V_e \in \mathbb{R}^{d \times d}$ 为正交基矩阵，满足 $U_e^T U_e = V_e^T V_e = I$，$S_e$ 为可训练系数。这种参数化确保了专家内部特征方向的几何正交性，使得后续基于投影的评分具有明确的几何意义，避免了标准Logits评分中因参数纠缠导致的噪声敏感。

### 特征基对齐评分与阈值路由

在标准Top-k选择前，本文引入基于特征基对齐的评分机制。对于Token $i$，首先计算其注意力加权上下文 $c_i$，并将Token及其上下文归一化后投影至专家 $e$ 的特征基：

$$ \text{Score}_e(i) = \frac{(\tilde{x}_i^T U_e) \cdot (\tilde{c}_i^T U_e)}{\|\tilde{x}_i^T U_e\| \|\tilde{c}_i^T U_e\|} $$

该公式计算Token特征与上下文在专家基空间中的余弦相似度，衡量Token与专家子空间的几何对齐程度。随后，引入置信阈值 $T$ 过滤低分专家，仅保留 $\text{Score}_e(i) \ge T$ 的专家参与Top-k选择。这一设计通过几何匹配而非概率归一化实现稀疏控制，阈值 $T$ 替代了LBL在抑制低质量路由中的作用，避免了辅助损失对主任务梯度的干扰，同时保留了硬Top-k的稀疏性约束。

## 实验评估

实验在ImageNet-1K、CIFAR-10/100、Tiny-ImageNet、MS-COCO、Flickr30k及ADNI脑MRI数据集上进行。基线覆盖V-MoE、Single-gated MoE、DeepMoE等视觉MoE主流方法，但缺失与最新几何路由方法（如Grassmannian MoE）的对比。

| 数据集 | 方法 | Top-1 (%) | Top-5 (%) |
| :--- | :--- | :--- | :--- |
| ImageNet | V-MoE | 87.41 | 97.94 |
| ImageNet | ERMoE | 88.03 | 98.97 |
| CIFAR-100 (5-shot) | V-MoE | 89.49 | - |
| CIFAR-100 (5-shot) | ERMoE | 93.47 | - |
| Tiny-ImageNet (5-shot) | V-MoE | 81.12 | - |
| Tiny-ImageNet (5-shot) | ERMoE | 83.17 | - |

ERMoE在ImageNet上较V-MoE提升0.62个百分点，在CIFAR-100 5-shot线性探针任务中提升3.98个百分点，表明特征基对齐路由在低数据量场景下能提供更强的线性可分性。

| 数据集 | 方法 | I2T R@1 (%) | T2I R@1 (%) |
| :--- | :--- | :--- | :--- |
| COCO | Fix-CLIP | - | 49.6 |
| COCO | CLIP-ERMoE | 65.4 | - |
| Flickr30k | CLIP-ERMoE | 63.4 | 42.4 |

在图像-文本检索任务中，CLIP-ERMoE在COCO I2T R@1上达到65.4%，显著优于Fix-CLIP的60.5%。然而，在T2I方向上，ERMoE未超越Fix-CLIP，作者归因于冻结的CLIP文本编码器限制了文本侧的细粒度对齐能力，这揭示了该路由机制在跨模态任务中依赖于文本编码器质量的局限性。

评估边界方面，论文未报告置信区间，且未在LLM长序列任务上验证路由稳定性。可复现性受限于未公开代码，但超参数（如 $\lambda=5 \times 10^{-5}$，阈值 $T=0.5$）在文中明确给出。

## 关联研究分析

从问题动机看，ERMoE与Loss-Free Balancing均旨在消除辅助负载均衡损失，但路径截然不同。Loss-Free Balancing通过动态调整路由偏置实现平衡，仍依赖Logits评分；ERMoE则通过改变评分函数本身，将平衡机制内嵌于几何对齐中。这种差异源于对“平衡”本质的不同理解：前者视平衡为统计约束，后者视平衡为几何结构的自然涌现。ERMoE在视觉短序列任务中验证了内生平衡的可行性，但在LLM长序列中，Token间复杂的长程依赖是否仍能通过局部特征基对齐有效捕捉，尚存疑问。

从方法设计看，ERMoE与Grassmannian MoE同属几何路由路线，但抽象层级不同。Grassmannian MoE在子空间流形上建模专家集中度，使用Matrix Bingham分布；ERMoE则在固定维度的正交基上进行投影评分，计算复杂度更低。ERMoE的正交约束 $U_e^T U_e = I$ 强制专家子空间正交，这可能限制了专家表达非正交复杂流形的能力。相比之下，Grassmannian MoE允许子空间间的非正交关系，理论上具有更强的表达力。ERMoE在视觉任务上的成功可能部分得益于图像特征的低维线性可分性，这一假设在更复杂的语言建模任务中是否成立，论文未给出回答。

## 总结

ERMoE针对MoE路由中负载均衡损失与专家专业化之间的固有冲突，提出通过专家权重的正交特征基重参数化，将路由评分转化为Token特征与专家子空间的几何对齐度量。该方法在ImageNet分类和COCO检索任务上分别取得88.03% Top-1准确率和65.4% I2T R@1，证明了消除显式平衡损失后，几何路由仍能维持稳定的专家利用率和较高的任务性能。然而，实验局限于视觉域，且正交约束可能限制专家对复杂非线性结构的表达能力。当专家需要捕捉高度非正交的语义流形时，特征基对齐路由的性能是否会显著退化，论文未提供相关证据。
