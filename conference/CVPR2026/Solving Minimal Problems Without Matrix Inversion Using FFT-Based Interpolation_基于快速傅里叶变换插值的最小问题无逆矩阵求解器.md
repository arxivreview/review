# CVPR2026最新论文 ｜Solving Minimal Problems Without Matrix Inversion Using FFT-Based Interpolation ｜基于快速傅里叶变换插值的最小问题无逆矩阵求解器

作者：Haidong Wu、Snehal Bhayani、Janne Heikkilä

论文原文见 [arXiv](https://arxiv.org/abs/2605.06572)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.06572)

> 相机位姿估计中的最小问题求解长期受困于符号展开的阶乘复杂度与矩阵求逆的数值失稳，导致高外点率场景下RANSAC内部调用频繁失败。本文切入点在于利用稀疏结果矩阵的代数结构，通过数值采样替代符号运算。具体做法是构建隐藏变量结果矩阵，利用逆快速傅里叶变换（IFFT）重构行列式系数，并结合最大公因数（GCD）准则恢复未知数。该方法在14个基准问题上实现了0%的失败率，但在大规模问题上计算效率显著落后于现有最优方法。

## 研究背景

最小问题（Minimal Problem）是鲁棒几何估计的核心组件，指利用最少数量点对应关系求解相机位姿或内参的代数问题。这类问题通常转化为多变量多项式方程组，其解的数值稳定性直接决定了随机采样一致性（RANSAC）在高噪声环境下的收敛质量。传统求解器依赖Gröbner基或结果式（Resultant）方法，但符号展开导致计算量随矩阵维度呈阶乘增长，且在线求解阶段必需的矩阵求逆在病态条件下极易引发数值误差累积。

现有主流路线中，基于Gröbner基的自动求解器生成工具（如GAPS）虽提升了效率，但仍受限于代数结构的刚性；基于稀疏结果的方法（如SparseR）通过引入额外变量构建特征值问题，虽避免了部分符号运算，但在线阶段仍需显式矩阵求逆，导致在退化配置下求解失败。本文针对这一“符号爆炸”与“求逆失稳”的双重瓶颈，提出一种纯数值采样策略，旨在不依赖符号展开和矩阵求逆的前提下，稳定重构最小问题的所有代数解。

## 核心方法

### 方法参照系

本文问题属于最小问题代数求解范畴，标准流程为构建结果矩阵并求解其行列式为零的方程。与常规流程的关键差异在于，本文摒弃了传统的符号多项式展开与在线矩阵求逆步骤，转而采用基于复数单位圆采样的数值插值策略重构行列式系数。

### 隐藏变量结果矩阵构建

设计动机在于解决经典结果式对稀疏多项式系统适用性差的问题。本文采用隐藏变量方法，将原系统中的一个变量 $x_1$ 视为系数域中的常数，构造 $N \times N$ 的稀疏结果矩阵 $\mathbf{M}(x_1)$。该矩阵的行列式 $\det(\mathbf{M}(x_1))$ 是关于 $x_1$ 的一元多项式，其根对应原系统的解。通过引入稀疏消除理论，矩阵维度 $N$ 被压缩至最小单omial基大小，避免了经典Macaulay结果式的冗余维度，为后续高效数值求解奠定了紧凑的代数基础。

### IFFT插值重构行列式系数

设计动机在于消除 $N!$ 阶符号展开的计算瓶颈。本文在复数单位圆上均匀采样 $k+1$ 个点 $x_{1}^{[j]}$，计算矩阵 $\mathbf{M}(x_{1}^{[j]})$ 的数值行列式。利用张量快速傅里叶变换（FFT）加速矩阵求值，并通过逆快速傅里叶变换（IFFT）从采样值中重构多项式系数向量 $\mathbf{c}$：

$$
\mathbf{c} = \text{IFFT}(\mathbf{y}), \quad \mathbf{y} = [\det(\mathbf{M}(x_{1}^{[0]})), \dots, \det(\mathbf{M}(x_{1}^{[k]}))]^\top
$$

该公式的物理含义是将多项式系数恢复问题转化为频域插值问题，将符号运算的指数复杂度降低为数值采样的线性复杂度。重构后求解一元多项式得到 $x_1$ 的候选根，再通过Cramer法则恢复其余变量。

### GCD准则下的秩亏子矩阵识别

设计动机在于解决浮点噪声下Cramer法则恢复变量时的子矩阵选择歧义。传统方法依赖精确的秩判断，在噪声环境下易失效。本文引入基于最大公因数（GCD）的准则，通过检查子矩阵行列式系数的GCD性质，稳健地识别出秩亏子矩阵。该机制确保了在存在虚假根（Spurious Roots）和数值噪声的情况下，仍能准确提取对应真实解的变量比值，从而在14个测试问题上实现了0%的求解失败率。

## 实验评估

实验在14个最小问题实例上进行，涵盖相对位姿、绝对位姿及多相机标定，对比基线为SparseR（稀疏结果法）与GAPS（Gröbner基法）。所有求解器均在MATLAB环境下运行，硬件配置为Intel Core i5-13500H CPU。

| 问题类型 | 本文耗时 (ms) | SparseR耗时 (ms) | GAPS耗时 (ms) | 本文失败率 (%) | SparseR失败率 (%) | GAPS失败率 (%) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Rel. pose F+λ 8pt | 0.086 | 0.101 | 0.106 | 0 | 0.2 | 0.1 |
| Rel. pose E+f 6pt | 0.154 | 0.345 | 0.235 | 0 | 0 | 0 |
| Optimal PnP (Cayley) | 7.442 | 1.393 | 3.005 | 0 | 0.12 | 0.08 |
| Rel. pose λ1+F+λ2 9pt | 9.520 | 1.102 | 4.377 | 0 | 1.24 | 1.04 |

在数值稳定性上，本文在全部14个问题中失败率均为0%，显著优于SparseR（最高1.24%）和GAPS（最高1.04%）。然而，在计算效率上呈现两极分化：对于小规模问题（如8点、6点），本文耗时0.086-0.154ms，快于基线；但对于大规模问题（如40解的Cayley PnP、24解的9点问题），本文耗时7.442-9.520ms，显著慢于SparseR的1.393-1.102ms。这表明IFFT插值策略在解空间维度增大时，采样点数量与FFT计算开销成为主要瓶颈，导致其“稳定优先”的特性以牺牲大规模问题的实时性为代价。

评估边界方面，本文仅评估了代数求解器的内部性能（稳定性与耗时），未涉及其在完整RANSAC流程中的端到端位姿精度影响。此外，实验未报告GPU加速效果，且未对比基于深度学习的位姿回归方法，限制了其在实时导航场景下的直接适用性评估。代码未公开，超参数（如采样点数 $k$ 的选择策略）细节需参考补充材料。

## 关联研究分析

从方法设计看，本文与SparseR同属稀疏结果路线，但关键差异在于在线求解机制。SparseR依赖Schur补构建特征值问题，需显式矩阵求逆，导致其在病态矩阵下数值失稳；本文通过IFFT插值直接重构行列式系数，彻底规避了求逆操作。这一差异的根源在于任务特性：最小问题求解对数值精度的要求极高，任何代数操作中的舍入误差都会导致解的漂移，而数值插值在单位圆上的均匀采样具有更好的条件数特性，从而在稳定性上取得优势。

从问题动机看，本文与GAPS（Gröbner基路线）形成互补。GAPS通过自动化代数消元提升效率，但受限于Gröbner基的固有计算复杂度；本文则从数值分析角度切入，利用多项式插值的数值稳定性。然而，本文未探索如何结合GAPS的代数结构优化来减少采样点数 $k$，这可能导致在解数量较多时（如40解），本文的采样开销远高于GAPS的代数消元开销。这种“数值稳定”与“代数效率”的权衡，在极端高维最小问题中是否仍具优势，论文未给出回答。

## 总结

本文旨在解决最小问题求解中符号展开爆炸与矩阵求逆失稳的矛盾，切入点在于利用稀疏结果矩阵的代数结构进行数值采样重构。通过IFFT插值与GCD准则，本文在14个基准问题上实现了0%的失败率，证明了数值方法在代数求解中的稳定性优势。然而，实验暴露了其在大规模问题上的效率瓶颈，40解问题耗时7.442ms，远高于SparseR的1.393ms。当最小问题的解空间维度进一步增加时，IFFT采样的线性复杂度是否仍能保持相对于代数消元方法的竞争力，论文未给出回答。
