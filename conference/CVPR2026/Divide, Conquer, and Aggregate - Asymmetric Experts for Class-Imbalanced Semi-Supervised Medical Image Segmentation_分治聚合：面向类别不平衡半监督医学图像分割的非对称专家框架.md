# CVPR2026最新论文 ｜Divide, Conquer, and Aggregate: Asymmetric Experts for Class-Imbalanced Semi-Supervised Medical Image Segmentation ｜分治聚合：面向类别不平衡半监督医学图像分割的非对称专家框架

研究机构：上海交通大学

作者：Yajun Liu

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_bb04aec43335)

> 半监督医学图像分割（SSMIS）旨在利用少量标注与海量无标注数据缓解临床标注成本瓶颈，但在多器官场景下，通用方法常因类别不平衡导致小器官分割性能急剧下降。现有类别不平衡SSMIS方法多依赖单解码器架构，其共享参数易被多数类梯度主导，从根本上限制了尾部类别的分割能力。本文提出“分治聚合”（DCA）框架，通过静态划分类别、训练三个非对称专家解码器并动态聚合特征，从架构层面解耦了不平衡任务。该框架在Synapse和AMOS数据集上显著优于现有SOTA方法，但其静态划分策略对类别分布的稳定性依赖较高，在极端动态分布下的泛化能力存疑。

## 研究背景

当检测器面对多器官CT图像时，肝脏、肾脏等大器官的体素数量远超肾上腺、食管等小器官，这种数量级差异导致单解码器模型在训练时，多数类梯度信号淹没少数类，使得小器官分割边界模糊。这一现象称为类别不平衡，其核心矛盾在于共享参数架构无法同时优化大器官的全局上下文与小器官的局部细节。为解决此问题，半监督学习（SSL）框架通过一致性正则化挖掘无标注数据中的隐含监督信号，但伪标签生成过程同样受类别不平衡影响，高置信度伪标签往往偏向多数类，进一步加剧了确认偏差。

主流SSMIS方法如GA、DHC等，主要通过损失函数重加权或去偏策略来缓解类别不平衡，但这些方法仍依赖单解码器输出所有类别，架构层面的瓶颈未被触及。本文的切入点在于，将“分治”思想引入SSMIS，通过静态划分类别并设计非对称专家解码器，从架构上解耦多数类与少数类的学习过程，而非仅依赖损失函数调整。

## 核心方法

### 方法参照系

通用SSMIS流程通常采用单编码器-单解码器架构，通过一致性正则化生成伪标签。本文的关键差异在于，将单解码器替换为三个非对称专家解码器，并引入静态类别划分与动态特征聚合机制，以解决单解码器在类别不平衡场景下的梯度干扰问题。

### 对数间隙分析与静态类别划分

设计动机：传统启发式阈值（如像素比例<1%）划分类别缺乏数据驱动性，且对分布变化敏感。本文通过对数间隙分析（Log-Gap Analysis）实现数据驱动的静态划分。首先计算每个前景类别的体素占比 $P_k = V_k / V_{fg}$，其中 $V_{fg}$ 为前景总体素数。将 $K$ 个类别按占比降序排列，定义相邻类别的对数间隙 $G_j = \log(P^{(j)}) - \log(P^{(j+1)})$。通过定位 $G_j$ 序列中的两个最大峰值，确定划分索引 $k_{HM}$ 和 $k_{MT}$，将类别静态划分为头部（Head）、中部（Medium）和尾部（Tail）三个集合。该公式的物理含义是，对数间隙量化了类别分布的“陡峭度”，大间隙指示了类别簇之间的自然边界，从而实现了与解剖先验对齐的稳定划分。

### 非对称专家解码器与标签分割训练

设计动机：单解码器共享参数导致多数类梯度干扰少数类学习。本文通过标签分割策略，将监督损失限制在每个专家解码器的指定类别集合内，从根本上抑制了多数类梯度的干扰。三个专家解码器采用非对称参数设计：头部解码器（$D_H$）使用膨胀卷积（dilation=2）扩大感受野以优化大器官分割，并减少卷积层数（$n_{stages}=\{2,2,1,1\}$）防止过拟合细节；中部解码器（$D_M$）采用标准V-Net参数（$n_{stages}=\{3,3,2,1\}$）平衡上下文与细节；尾部解码器（$D_T$）增加卷积层数（$n_{stages}=\{4,4,3,2\}$）以增强小目标的非线性特征提取。监督损失定义为 $L_{sup} = L_{seg}(p_l^H, y_l^H) + L_{seg}(p_l^M, y_l^M) + L_{seg}(p_l^T, y_l^T)$，其中 $y_l^H, y_l^M, y_l^T$ 是通过标签分割生成的部分标签，非目标类别的体素被重映射为背景。该公式的含义是，每个专家仅对其指定类别负责，避免了跨类别的梯度竞争。

### 动态特征聚合模块（DFAM）

设计动机：专家解码器独立训练导致特征缺乏交互，限制了跨类别语义共享。本文在聚合解码器中引入DFAM，动态融合三个专家的特征。DFAM接收三个专家的特征 $F_H, F_M, F_T$ 和聚合流的特征 $F_{up}$，通过 $1\times1\times1$ 卷积统一通道后拼接，生成专家先验特征 $F_{con}$。随后，通过门控生成器产生三个空间注意力图 $\{A_H, A_M, A_T\}$，满足 $A_H(p) + A_M(p) + A_T(p) = 1$，实现体素级竞争。聚合特征 $F_{DFAM} = A_H \otimes F_H + A_M \otimes F_M + A_T \otimes F_T + F_{up}$。该公式的物理含义是，DFAM通过体素级竞争注意力，自适应选择最胜任的专家先验，并残差融合到解码器特征中，从而缓解多数类偏差并充分利用无标注数据。

## 实验评估

实验在Synapse（30例，13类）和AMOS（360例，15类）数据集上进行，使用3D V-Net骨干，SGD优化器，初始学习率0.01，无监督损失权重 $\lambda=10$。基线覆盖通用SSMIS方法（如UA-MT, CPS）和类别不平衡SSMIS方法（如GA, DHC, SKCDF），但缺失基础模型协同学习类方法（如MedSAM变体）及最新2026年一致性正则化SOTA（如VQ-Seg）。

| 方法 | Synapse 20% Avg. Dice | Synapse 20% Avg. ASD | AMOS 5% Avg. Dice | AMOS 5% Avg. ASD |
| :--- | :--- | :--- | :--- | :--- |
| GA | 63.51 | 4.58 | - | - |
| SKCDF | 53.81 | 5.97 | - | - |
| DCA (Ours) | 69.90 | 2.66 | 73.20 | 1.78 |

在Synapse 20%标注下，DCA的Avg. Dice为69.90，优于第二名的GA（63.51）4.77%；在AMOS 5%标注下，DCA的Avg. Dice为73.20，优于GA 6.39%。消融实验显示，添加三个专家解码器使Avg. Dice提升7.46%，应用Log-Gap标签分割策略再提升14.51%，添加DFAM最终提升3.31%。这表明标签分割策略对专家专业化的贡献最大，而DFAM的边际收益相对较小，暗示专家间特征交互的优化空间可能有限。

评估指标仅包含Dice和ASD，缺乏边界精度（如Hausdorff Distance）和临床可用性指标。评估协议未报告置信区间，数值比较需谨慎。代码已开源（https://github.com/PHPJava666/DCA），超参数设置详细，可复现性较高。

## 关联研究分析

从问题动机看，DCA与GA、DHC等方法的根本差异在于解决类别不平衡的层面。GA和DHC聚焦于损失函数层面的去偏，通过重加权或难度感知加权来平衡梯度，但架构上仍依赖单解码器。DCA则从架构层面解耦任务，通过非对称专家解码器隔离多数类与少数类的学习过程。这一差异的根源在于，DCA认为单解码器的共享参数是类别不平衡的主要瓶颈，而GA、DHC认为损失函数设计是关键。然而，DCA的静态划分策略假设类别分布稳定，这在多中心或跨模态数据中可能失效，而GA、DHC的损失函数调整对分布变化更具鲁棒性。

从方法设计看，DCA与基础模型协同学习（如MedSAM）形成鲜明对比。MedSAM依赖预训练模型的强先验知识，通过提示工程实现零样本/少样本分割，而DCA完全依赖数据驱动的非对称架构优化。DCA未使用任何基础模型，表明在特定多器官任务中，专用架构优化可能比通用先验更有效。但DCA的计算成本高于单解码器方法，且缺乏基础模型的泛化能力，在极端少样本或冷启动场景下可能表现不佳。

## 总结

DCA框架旨在解决类别不平衡SSMIS中单解码器架构的梯度干扰问题，通过静态划分类别、训练非对称专家解码器并动态聚合特征，从架构层面解耦了不平衡任务。在Synapse 20%标注下，DCA的Avg. Dice为69.90，优于GA 4.77%；在AMOS 5%标注下，Avg. Dice为73.20，优于GA 6.39%。其边界在于静态划分策略对类别分布稳定性的依赖，以及缺乏基础模型协同的泛化能力。当类别分布发生显著变化（如多中心数据或新器官加入）时，Log-Gap Analysis的划分结果是否依然稳定，论文未给出回答。
