# CVPR2026最新论文 ｜BEA-GS: BEyond RAdiance Supervision in 3DGS for Precise Object Extraction ｜超越辐射度监督的3D高斯泼溅对象提取

研究机构：西班牙加泰罗尼亚理工大学

作者：Alessio Mazzucchelli、Maria Naranjo-Almeida、Jorge Bustos-Sanchez 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.09662)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.09662)

> 3D高斯泼溅（3D Gaussian Splatting, 3DGS）在语义分割与对象提取中面临隐藏高斯伪影问题，导致提取后的对象在新场景中产生意外视觉瑕疵。现有基于Alpha-blending光栅化的语义监督方法仅能修正接收足够辐射度的可见高斯，无法触及被遮挡或辐射度极低的非可见高斯，致使几何边界在提取时失效。BEA-GS通过引入2D边界损失与3D占据损失的双重优化机制，直接约束非可见高斯的几何形态，实现了跨数据集与指标的一致性领先。该方法在对象提取任务上确立了新的性能基准，但其依赖逐场景优化与体素化先验的设计，在大规模动态场景的泛化性与实时性上仍存疑。

## 研究背景

3DGS通过显式高斯原语与可微光栅化实现了高质量新视角合成，但其几何与外观的强耦合特性使得仅依赖光度损失训练的高斯易向邻近区域漂移以匹配颜色，而非调整外观参数。这种漂移导致高斯跨越语义边界，当场景被分割为独立对象时，原本被遮挡的“隐藏”高斯暴露出来，形成边界伪影。解决此问题需打破仅通过光栅化传播梯度的局限，直接对非可见区域的几何进行正则化。

早期语义3DGS方法如LangSplat利用CLIP特征建立多视角对应，但Alpha-blending过程导致2D-3D关联弱，难以实现精确的3D点级理解。后续工作如COB-GS与ObjectGS尝试通过语义约束修改几何，确保每个高斯仅贡献于单一对象，但它们仍受限于辐射度驱动的监督机制：只有接收足够辐射度的高斯才能被梯度更新。这导致部分可见或完全不可见的高斯在优化过程中保持静止，最终在对象提取时产生尖刺或越界伪影。BEA-GS的切入点在于识别这一“辐射度盲区”，提出不依赖光栅化透射率的直接几何约束，从而解决隐藏高斯导致的提取质量问题。

## 核心方法

### 方法参照系

本文基于2DGS重建框架，将语义分割任务转化为高斯参数的联合优化问题。与仅分配标签或依赖光栅化梯度的传统流程不同，BEA-GS在标准2DGS损失之外，引入了针对可见与非可见高斯的差异化正则化项，旨在从几何层面消除跨类贡献。

### 2D边界损失

传统方法通过光栅化传播语义梯度，仅影响可见高斯。BEA-GS引入边界损失 $L_{bound}$，直接惩罚高斯对非所属类别像素的贡献。该损失定义为：

$$ L_{bound} = \sum_{u} \sum_{i} \mathbb{1}[\phi_i \neq M'(u)] \cdot \alpha_i \hat{G}_i(x) $$

其中 $\phi_i$ 为高斯 $i$ 的语义类别，$M'(u)$ 为像素 $u$ 的掩码标签，$\alpha_i \hat{G}_i(x)$ 为高斯在该像素的辐射度贡献。此设计动机在于：通过仅激活越界部分的梯度，迫使高斯调整位置、形状或不透明度以尊重语义边界，同时避免像ObjectGS那样为每个类别增加额外通道，仅需单通道即可支持多类分割，降低了内存与计算开销。

### 3D占据损失

边界损失无法触及辐射度极低的非可见高斯。BEA-GS提出占据损失 $L_{occ}$，通过体素网格查询直接约束高斯表面采样点。首先构建基于渲染深度的类别特定体素网格 $V_\phi$，然后对每个高斯均匀采样 $Z$ 个点 $x'_r$，计算其邻域内占据体素数 $D_{occ}$：

$$ L_{occ} = \sum_{i} \sum_{r=1}^{Z} \alpha_i \hat{G}_i(x'_r) \cdot \mathbb{1}[D_{occ}(x'_r, V_{\phi_i}) = 0] $$

该公式的物理含义是：若采样点位于非所属类别的体素网格中（即 $D_{occ}=0$），则根据其密度与不透明度进行惩罚。这一设计直接作用于高斯参数，绕过了光栅化透射率的限制，有效抑制了高斯向未见区域的漂移，解决了隐藏高斯在提取时暴露的伪影问题。

## 实验评估

实验在LeRF、LLFF、Mip-NeRF 360与3DOVS四个数据集上进行，对比12种SOTA方法，所有方法使用相同的SAM2生成的2D掩码以确保公平性。基线覆盖了特征学习（如LangSplat）、图割（如GaussianCut）及几何适应（如COB-GS、ObjectGS）等主流路线，但未包含前馈式重建方法，因任务侧重逐场景优化的极致质量。

| 方法 | Mip-NeRF 360 (Acc/IoU/BIoU) | LeRF (Acc/IoU/BIoU) | LLFF (Acc/IoU/BIoU) | 3DOVS (Acc/IoU/BIoU) |
| :--- | :--- | :--- | :--- | :--- |
| COB-GS | 98.5 / 86.9 / 78.0 | 98.8 / 83.0 / 75.6 | 98.3 / 91.4 / 75.1 | 99.2 / 85.8 / 73.9 |
| ObjectGS | 96.4 / 76.7 / 61.3 | 98.1 / 69.1 / 58.5 | 93.7 / 71.9 / 49.8 | 98.6 / 79.2 / 68.2 |
| **BEA-GS** | **99.1 / 92.0 / 85.8** | **99.2 / 89.4 / 83.6** | **98.6 / 93.0 / 80.7** | **99.7 / 93.2 / 87.3** |

BEA-GS在所有数据集的提取指标上均取得最优，尤其在BIoU（边界IoU）上显著领先，表明其边界清洁度最高。渲染质量损失极小，Mip-NeRF 360的PSNR从29.1降至29.1，LeRF从25.2降至25.0，证明几何修正未牺牲视觉保真度。

消融实验揭示了模块间的互补性：

| 模块 (R/B/O) | Mip-NeRF 360 (BIoU) | LeRF (BIoU) | LLFF (BIoU) | 3DOVS (BIoU) |
| :--- | :--- | :--- | :--- | :--- |
| ✗✗✗ (Baseline) | 72.8 | 56.6 | 66.4 | 65.6 |
| ✓✓✗ (R+B) | 83.6 | 70.1 | 75.0 | 73.9 |
| ✓✗✓ (R+O) | 81.9 | 77.2 | 80.0 | 87.0 |
| ✓✓✓ (Full) | 85.8 | 83.6 | 80.7 | 87.3 |

多视角重投影（R）在遮挡复杂的Mip-NeRF 360与LeRF上收益显著，但在正面视角为主的LLFF与3DOVS上增益有限。边界损失（B）与占据损失（O）缺一不可：B优化可见边界细节，O修正非可见区域，两者结合才达到最优。

评估边界方面，实验未报告置信区间，且所有方法依赖相同的2D掩码输入，未评估掩码质量对最终结果的敏感性。代码未公开，但超参数（$\lambda_{bound}=0.5, \lambda_{occ}=10$）与训练时间（额外3K迭代）已详细披露，复现性较好。

## 关联研究分析

从问题动机看，BEA-GS与COB-GS、ObjectGS同属“几何适应”路线，但核心差异在于监督信号的传播路径。COB-GS与ObjectGS依赖光栅化透射率传播梯度，导致非可见高斯无法被修正；BEA-GS通过占据损失直接查询体素网格，绕过了辐射度限制。这一差异源于对3DGS几何-外观耦合特性的深入理解：仅靠光度损失无法约束高斯向未见区域的漂移，必须引入独立的几何先验。

从方法设计看，BEA-GS与VCAR等训练-free分割方法形成对比。VCAR通过视图完整性与轴感知边界细化实现高精度分割，但侧重于推理阶段的优化；BEA-GS则通过训练阶段的损失函数修改几何结构，旨在提升提取后的对象在新场景中的鲁棒性。两者在边界细化上思路相近，但BEA-GS更关注几何的内在一致性，而VCAR更关注视图间的投影一致性。BEA-GS未与VCAR在相同提取协议下对比，可能因为VCAR不修改几何，仅做分割，无法直接评估提取后的伪影问题。

## 总结

BEA-GS解决了3DGS对象提取中隐藏高斯导致的边界伪影问题，其核心在于识别并填补了辐射度监督的盲区。通过引入2D边界损失与3D占据损失，该方法直接约束非可见高斯的几何形态，在4个数据集的6项指标上均超越12种SOTA基线，Mip-NeRF 360提取BIoU达到85.8，较COB-GS提升7.8个点。然而，该方法依赖逐场景优化与基于渲染深度的体素化先验，在大规模动态场景或实时交互应用中，其计算成本与几何先验的稳定性面临挑战。当场景包含非刚性形变或剧烈光照变化时，基于静态渲染深度的体素网格是否仍能准确反映几何占据，论文未给出回答。
