# CVPR2026最新论文 ｜Multinex: Lightweight Low-light Image Enhancement via Multi-prior Retinex ｜多先验Retinex轻量级低光图像增强

研究机构：英国曼彻斯特大学

作者：Alexandru Brateanu、Tingting Mu、Codruta Ancuti 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.10359)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.10359)

> 低光图像增强（LLIE）需在极端光照退化下恢复自然可见度与色彩保真度，但现有SOTA方法依赖大模型与多阶段训练，难以在边缘设备部署，且单一色彩空间易导致曝光或色彩伪影。本文切入点在于将Retinex分解从“重建”转化为“残差校正”，并引入解析式多视角先验替代学习式色彩变换，以极低参数量实现稳定解耦。Multinex通过构建亮度与反射率引导堆栈，利用轻量融合模块生成加性增强Delta，在45K参数下达到与重型模型相当的感知质量。其价值在于验证了物理先验与极端压缩的兼容性，但残差形式在极端低光下的纹理恢复边界尚存疑。

## 研究背景

当传感器在弱光下采集图像时，光子匮乏导致信号低于噪声底限，图像不仅亮度不足，还伴随散粒噪声与色彩偏差。传统Retinex理论将图像分解为光照与反射率，旨在解耦亮度校正与细节保留，但在RGB空间中，亮度与色度耦合严重，直接估计光照与反射率图在低曝光下病态且计算昂贵。为突破这一瓶颈，领域引入了YCbCr、HSV等色彩空间或可学习映射（如HVI），试图显式分离亮度与色度，但这些方法仍存在部分耦合、红色不连续或训练不稳定问题，且主流SOTA模型（如RetinexFormer）参数量达百万级，限制了实时边缘部署。

现有轻量化LLIE方法（如Zero-DCE、LYT-Net）通过曲线估计或单一色彩空间变换压缩模型，但在参数量降至1M以下时，增强质量显著下降，主要源于缺乏对多视角互补信息的利用。本文针对这一“极端压缩下的性能断崖”问题，提出Multiprior Retinex（Multinex）。其核心假设是：通过解析提取多种物理与感知先验（而非学习色彩空间变换），可以在极低参数预算下稳定地解耦亮度与色度，从而在保持物理可解释性的同时实现实时增强。

## 核心方法

### 方法参照系

标准Retinex增强流程通常通过两个独立网络分别估计光照图 $L$ 和反射率图 $R$，再通过乘积 $L \odot R$ 重建增强图像。本文的关键差异在于摒弃了“重建”范式，转而采用“残差校正”范式，即仅预测对输入图像的加性调整量，以保留原图结构并降低计算负担。

### 增强Delta残差建模

设计动机在于解决直接Retinex分解在低曝光下因光照估计敏感导致的结构丢失与色彩偏移问题。Multinex将增强目标定义为输入图像 $\mathbf{I}$ 与增强图像 $\hat{\mathbf{I}}$ 之间的加性残差 $\Delta \mathbf{I}$，并将其分解为亮度校正 $\Delta L$ 和反射率校正 $\Delta R$：

$$ \hat{\mathbf{I}} = \mathbf{I} + \Delta L \odot \Delta R $$

其中 $\Delta L$ 由单通道网络 $f_L$ 生成，$\Delta R$ 由三通道网络 $f_R$ 生成。这种加性形式意味着网络只需学习“如何修正”而非“如何生成”，从而在保留原始纹理细节的同时，通过轻量级操作实现曝光校正。

### 多视角解析引导堆栈

设计动机在于解决单一色彩空间（如RGB或YUV）在极端压缩下信息冗余不足、导致泛化性差的问题。Multinex不学习色彩空间变换，而是解析计算两组互补先验：亮度引导堆栈 $S_L$（含4个通道：BT.709亮度、最大通道值、HSL亮度、RGB L2范数）和反射率引导堆栈 $S_R$（含5个通道：Cb、Cr、红绿归一化比率、饱和度）。这些解析特征作为融合模块的输入，替代了部分卷积层的特征提取功能。融合模块 $f(S)$ 通过深度可分离卷积（DWConv）和组件级注意力（CWA）对堆栈进行加权融合，最终输出 $\Delta L$ 和 $\Delta R$。这种“解析先验+轻量融合”的结构，使得模型在0.7K参数下仍能捕捉多视角互补信息。

## 实验评估

实验在LOLv1、LOLv2-Real、LOLv2-Synthetic、SDSD等配对数据集及MEF、LIME等无参考数据集上进行，对比基线包括RetinexNet、Zero-DCE、LYT-Net、PairLIE等轻量级SOTA及RetinexFormer等重型模型。

| 数据集 | 方法 | 参数量 | PSNR (dB) | NIQE |
| :--- | :--- | :--- | :--- | :--- |
| LOLv1 | Multinex | 45K | 18.89 | - |
| LOLv1 | Zero-DCE | <80K | 15.03 | - |
| LOLv2-Real | Multinex | 45K | 21.26 | - |
| LOLv2-Real | BC-IHV | - | 25.51 | - |
| ExDark | Multinex-Nano | 0.7K | - | - |

*注：LOLv1/LOLv2-Real PSNR数值取自论文实验数据区；BC-IHV数值据领域综述引用；NIQE均值3.66取自论文正文。*

Multinex在轻量级组内表现领先，LOLv2-Real PSNR 21.26 dB显著优于Zero-DCE，但在绝对性能上低于重型SOTA（如BC-IHV的25.51 dB）。消融实验显示，移除亮度或反射率引导堆栈会导致PSNR下降约1-2 dB，验证了多视角先验的必要性；使用MDTA替代CWA仅带来0.02 dB提升，表明轻量级注意力机制已接近性能饱和。

评估边界方面，论文未报告FLOPs具体数值，仅提及89%中位数FLOP减少；无参考指标（NIQE/BRISQUE）显示其感知质量优于CIDNet，但缺乏与最新扩散模型（如Consist-Retinex）在极端低光下的直接对比。代码开源，但超参数配置未完全公开，复现性依赖于补充材料中的细节。

## 关联研究分析

从方法设计看，Multinex与LYT-Net同属45K参数级轻量级Retinex变体，但LYT-Net依赖YUV色彩空间的通道解耦，而Multinex采用多视角解析堆栈。这一差异源于LYT-Net假设单一色彩空间足以分离亮度与色度，而Multinex认为单一空间存在信息盲区，需通过解析计算多个互补描述符（如L2范数、饱和度）来增强鲁棒性。根源在于任务特性：极端压缩下，学习式色彩变换易过拟合训练集分布，解析先验则提供了数据无关的物理约束。

从问题动机看，Multinex与Zero-DCE均旨在解决配对数据稀缺与计算效率问题，但Zero-DCE通过像素级曲线估计实现无监督增强，而Multinex仍依赖配对数据训练，仅通过残差形式降低对数据分布的敏感度。Zero-DCE的曲线估计缺乏物理结构，易导致全局过曝，而Multinex的Retinex残差框架保留了局部结构一致性。这一差异暗示，在无监督场景下，解析先验的固定性可能限制模型对非均匀光照的适应性，论文未探索无监督训练下的Multinex性能。

## 总结

Multinex针对轻量化LLIE中“极端压缩导致性能断崖”的矛盾，抓住“解析先验替代学习式色彩变换”的切入点，通过增强Delta残差建模与多视角引导堆栈，在45K参数下实现了LOLv2-Real 21.26 dB的PSNR及3.66的NIQE均值，证明了物理先验与轻量架构的兼容性。其边界在于残差形式在极端低光下可能无法恢复缺失纹理，且解析先验的固定性限制了跨光照场景的泛化能力。当输入图像亮度低于传感器噪声底限时，加性残差校正是否仍能维持物理一致性，论文未给出回答。
