# CVPR2026最新论文 ｜Restore, Assess, Repeat: A Unified Framework for Iterative Image Restoration ｜恢复-评估-重复：统一迭代图像恢复框架

研究机构：国立台湾大学、英国伦敦玛丽女王大学

作者：I-Hsiang Chen、Isma Hadji、Enrique Sanchez 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.26385)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.26385)

> 全合一图像恢复（All-in-One Image Restoration, AiOIR）旨在通过单一模型处理多种未知复合退化，但现有方法在泛化性与计算效率间存在显著矛盾。智能体（Agent）范式虽能迭代修复，却因模块解耦导致高延迟；传统统一模型虽高效，却受限于固定退化标签的泛化瓶颈。RAR 将视觉语言模型（VLM）质量评估与流匹配生成模型在潜空间深度耦合，实现端到端可微的“恢复-评估-重复”闭环。该框架在感知质量与推理速度上超越现有智能体基线，但其保真度指标略逊于离散工具调用方案，且依赖特定骨干网络的无噪声特性。

## 研究背景

图像恢复的核心困境在于真实世界退化的复合性与未知性。当输入图像同时包含噪声、模糊与低光照时，单一退化模型失效，而多模型部署带来冗余。为解决此问题，领域转向统一架构，但共享骨干网络在处理异构退化时产生参数冲突。更关键的是，多数统一模型依赖预定义退化标签进行分类路由，面对训练分布外的未知退化时，分类器性能崩溃，导致恢复策略错误。

现有方案分为两条路线：All-in-One 模型与 Agent 模型。All-in-One 模型（如 AutoDIR）使用 CLIP 等分类器识别退化，但 CLIP 零样本性能差，需微调至封闭标签集，限制了泛化能力。Agent 模型（如 AgenticIR）使用自由文本 VLM 评估退化，并迭代调用专用工具，虽能处理复杂退化，但模块间需像素级解码与编码，计算开销巨大。RAR 的切入点在于消除这种模块解耦：将 VLM 评估器与生成式恢复器置于同一潜空间，通过适配器对齐特征，使评估反馈直接作为恢复条件，无需文本解码或像素往返，从而在保持自由文本评估泛化性的同时，实现端到端的高效迭代。

## 核心方法

### 方法参照系

本文问题可置于“条件生成式图像恢复”框架下。标准流程为：编码器将退化图像映射至潜空间，条件分支注入退化信息，去噪网络生成高质量潜变量。关键差异在于，本文的条件信号并非静态标签，而是由集成在潜空间内的质量评估模块（LQA）动态生成的迭代反馈，且生成过程采用无噪声流匹配而非传统扩散。

### 潜空间质量评估对齐

传统方法中，IQA 模块在像素空间运行，其输出文本需经文本编码器转化为嵌入向量，此过程不可微且丢失信息。RAR 引入潜空间质量评估（Latent Quality Assessment, LQA），通过图像适配器 $A_I$ 将恢复模型的潜变量 $z_{deg}$ 映射至 IQA 输入空间，并通过查询适配器 $A_Q$ 将 IQA 输出潜变量 $Q_{deg}$ 对齐至恢复模型的条件嵌入空间 $T$。

$$ T = A_Q(Q_{deg}), \quad Q_{deg} = LQA(A_I(z_{deg})) $$

该设计消除了文本解码步骤，使 IQA 与恢复模块共享梯度流，实现端到端训练。适配器 $A_I$ 和 $A_Q$ 的两阶段微调策略，确保了特征对齐的稳定性，解决了此前方法中评估与恢复模块参数独立、无法协同优化的问题。

### 无噪声流匹配迭代机制

扩散模型在去噪过程中引入噪声，导致中间潜变量被污染，使 LQA 无法准确评估当前恢复状态。RAR 采用 Stable Diffusion 3.5 (SD3.5) 的流匹配（Flow Matching, FM）范式，移除噪声项，建立从退化分布 $\rho_{deg}$ 到高质量分布 $\rho_{hq}$ 的直接映射。

$$ v_\theta(z_t, Q_{deg}, t) = \frac{d}{dt} z_t, \quad z_t = (1-t)z_{deg} + t z_{hq} $$

在迭代过程中，模型预测速度向量 $v^n$ 更新潜变量 $z_{deg}^{n+1} = z_{deg}^n + v^n$，并重新计算 $Q_{deg}^{n+1} = LQA(z_{deg}^{n+1})$ 作为下一轮条件。此机制允许 LQA 在无噪声干扰下读取中间状态，动态调整恢复策略。停止准则由 LQA 对比前后潜变量质量决定，若质量未提升则终止迭代，平均仅需 2.4 轮，显著低于 Agent 方法的 3.4 轮。

## 实验评估

实验在复合退化（MiO100 组合）、未知退化（UDC）及单退化基准上进行，对比 AirNet、PromptIR、AutoDIR 及 AgenticIR。基线覆盖 All-in-One 与 Agent 两条路线，但缺失 M2IR、MiM-DiT 等基于 MoE 路由的最新 SOTA 方法，可能低估了统一架构在保真度上的竞争压力。

| 方法 | Group A PSNR (dB) | Group A LPIPS | Group A MANIQA | UDC MUSIQ | 平均耗时 (s) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| AgenticIR | 21.04 | 0.3148 | 56.88 | 52.76 | 48.00 |
| AutoDIR | 19.64 | 0.3967 | 47.01 | 49.27 | 14.30 |
| RAR | 20.46 | 0.1299 | 57.19 | 55.97 | 6.29 |

RAR 在感知指标上全面领先，LPIPS 较 AgenticIR 低 0.1849，MUSIQ 高 3.21，且耗时仅为后者的 13%。但在 PSNR 上，Group A 中 RAR (20.46 dB) 低于 AgenticIR (21.04 dB)，表明流匹配直接映射在像素级保真度上存在轻微损失，验证了感知-保真权衡。

消融实验显示，将 IQA 输出从文本替换为嵌入向量，使 UDC 数据集 PSNR 从 24.41 dB 提升至 28.49 dB，证实了潜空间对齐的信息保留优势。移除噪声项的流匹配公式在复合退化上带来 0.40 dB 的 PSNR 增益，而在扩散模型中迭代条件反而导致性能下降，证明无噪声特性是迭代评估有效性的前提。

评估协议侧重感知质量与效率，未报告计算复杂度（FLOPs）或显存占用，且未在 CDD11 等标准复合退化基准上测试，限制了与领域 SOTA 的直接横向对比。代码未公开，但依赖开源的 SD3.5 与 DepictQA，复现门槛中等。

## 关联研究分析

从方法设计看，RAR 与 AgenticIR 的核心差异在于模块耦合方式。AgenticIR 依赖 LLM 规划离散工具调用，IQA 与 IR 间存在像素级解码瓶颈；RAR 通过潜空间适配器将评估反馈转化为连续条件向量，消除了解码开销。这一差异源于任务特性：复合退化需要动态调整恢复策略，离散工具调用难以捕捉退化间的细微交互，而潜空间迭代允许模型在特征层面逐步修正。然而，RAR 的 PSNR 劣势暗示，连续流匹配可能在高频细节恢复上不如专用去噪工具精准，这是生成式统一模型固有的精度-泛化权衡。

从问题动机看，RAR 与 AutoDIR 均试图解决未知退化泛化问题，但 AutoDIR 依赖 CLIP 分类器，受限于封闭标签集；RAR 采用 DepictQA 自由文本评估，理论上可描述任意退化。这一改进源于 VLM 的开放世界理解能力，但论文未验证在极端罕见退化下，自由文本评估的准确性是否优于多模态路由机制。若退化特征高度耦合，LQA 的文本描述可能模糊，导致恢复条件失准，这一风险在实验中未得到量化。

## 总结

RAR 旨在解决未知复合退化下统一恢复模型的泛化与效率矛盾。现有 Agent 方法因模块解耦导致高延迟，All-in-One 方法因固定标签限制泛化，RAR 通过潜空间深度耦合 VLM 评估与流匹配生成，实现了端到端可微迭代。实验表明，其在感知质量（MUSIQ 55.97）与效率（6.29s）上超越 AgenticIR，但 PSNR 略低（20.46 vs 21.04 dB）。边界在于依赖 SD3.5 无噪声特性，且未在标准复合退化基准上验证。当退化类型高度耦合且特征模糊时，潜空间迭代是否会导致评估反馈震荡，论文未给出回答。
