# CVPR2026最新论文 ｜Vision-Oriented Lightweight Neural Architecture Search with Budget-Adaptive Evaluation ｜视觉导向轻量级神经架构搜索与预算自适应评估

研究机构：南京大学

作者：Yi Fan、Yu-Bin Yang

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_0a779bf7c49e)

> 高效神经架构搜索（Efficient Neural Architecture Search, NAS）旨在解决传统搜索策略因评估候选架构需耗费数千 GPU 天而导致的算力瓶颈。现有零成本代理（Zero-Cost Proxy, ZCP）虽快但存在非线性负相关性，而基于训练的方法虽准但成本高昂，二者陷入精度-效率困境。本文通过设计六个视觉微任务进行极短训练，并引入二次曲面拟合以在固定时间预算下自适应分配数据量与训练轮数，实现了跨架构族的高保度排名。该方法在多个基准上超越了纯 ZCP 与部分训练型 NAS，但其评估协议与主流 Spearman 相关系数不同，且未涵盖硬件约束，限制了其在边缘部署场景的直接适用性。

## 研究背景

当检测器面对新生成模型时，其训练域与测试域的数据分布出现系统性差异——这一现象称为分布偏移。分布偏移导致传统分类器决策边界失效，而实际场景中往往能获取少量目标域样本，这恰好构成了小样本学习的条件：仅凭每个类别极少量标注样本泛化到新任务。解决此类问题的经典框架是原型网络，它计算各类别支持样本的特征均值作为"原型"，再通过距离度量完成分类。

传统 NAS 依赖强化学习或进化算法，需对搜索空间内每个架构执行完整训练，计算复杂度随空间规模指数增长。为降低评估成本，领域发展出两条主要路线：一是基于权重共享的超网络（Supernet）范式，通过一次训练多模型部署摊销成本，但存在子网性能低于独立训练的优化间隙；二是零成本代理（ZCP），利用未训练网络的统计特性（如激活值、梯度）预测性能，将评估成本降至毫秒级。然而，ZCP 的线性假设在高非线性架构上失效，导致预测排名与真实性能排名相反，即“负相关性”问题。同时，现有 ZCP 紧密耦合于特定架构族，直接应用于 Transformer 或 Mamba 等新型架构时往往失效。本文切入点在于：在“零成本”与“全量训练”之间引入“微训练”范式，通过极短时间的任务性能评估规避静态统计量的非线性偏差，同时通过预算自适应机制最大化单位时间内的评估精度。

## 核心方法

### 方法参照系

本文问题属于高效 NAS 中的架构评估环节。标准 ZCP 流程直接计算初始化状态的统计量（如 SynFlow 的信号流强度），无需任何梯度更新。本文的关键差异在于：引入极短时间的有监督训练，将评估指标从静态统计量转变为动态任务性能，并针对训练过程中的资源分配（数据量 $D$ 与轮数 $E$）进行联合优化。

### 视觉探针任务设计

设计动机在于解决 ZCP 在非线性架构上的负相关性及跨架构泛化能力不足的问题。传统 ZCP 依赖 ReLU 等特定层或一维 token 假设，无法适配二维几何敏感的视觉任务。本文设计了六个视觉微任务：局部-全局拼图（Local-Global Jigsaw, LGJ）、遮挡修复（Occlusion InPainting, OIP）、旋转匹配（Rotation Match, RM）、颜色-形状绑定（Color-Shape Binding, CSB）、运动预测（Motion Forecast, MF）和视觉记忆（Visual Memorization, VM）。这些任务旨在探测模型对空间顺序、几何不变性、属性绑定及长尾记忆的表征能力。以 LGJ 为例，其评分函数定义为：

$$
\text{Score}_{\text{LGJ}} = \frac{\sum_{i=1}^p \mathbb{1}_{c(\boldsymbol{x}_i, \boldsymbol{x}_{g(i)}) < \gamma} \left\| \mathcal{P}(g(i)) - \mathcal{P}(\boldsymbol{y}_i) \right\|_2}{\sum_{i=1}^p \mathbb{1}_{c(\boldsymbol{x}_i, \boldsymbol{x}_{g(i)}) < \gamma}}
$$

该公式通过排除不可区分区域（余弦相似度高于阈值 $\gamma$ 的 patch 对），计算预测位置与真实位置的欧氏距离均值，从而避免对模型施加不合理的惩罚。六个任务的得分聚合后作为候选架构的综合代理分数，这种基于任务性能的设计使得评估不再依赖特定层结构，从而实现了 CNN、Transformer 和 Mamba 架构族的通用性。

### 预算自适应评估器

设计动机在于解决固定训练配置下评估精度与计算成本的权衡问题。在给定总时间预算 $T_{max}$ 下，数据量 $D$ 和训练轮数 $E$ 对代理分数 $S$ 的影响是非线性的。本文假设 $S(D, E)$ 在感兴趣区域内可近似为二次曲面：

$$
\hat{S}(D, E) = \beta_0 + \beta_1 D + \beta_2 E + \beta_3 D^2 + \beta_4 E^2 + \beta_5 DE
$$

通过拉丁超立方设计选取五个锚点，利用加权最小二乘法拟合系数 $\beta_0 \sim \beta_5$。随后，在约束 $D \cdot t_d + E \cdot t_e \le T_{max}$ 下，通过求解偏导数为零的方程组或拉格朗日乘数法，解析得到最优的 $(D^*, E^*)$。这一闭环机制确保了在任意用户指定的时间预算内，系统自动选择能最大化排名保真度的数据-轮数组合，避免了人工调参的盲目性。

## 实验评估

实验在 NAS-Bench-101、NAS-Bench-201、NAS-Bench-301 及 NATS-Bench 上进行，对比基线包括 SynFlow、SNIP 等纯 ZCP 方法以及 DARTS 等训练型 NAS。论文声称在多种时间预算下取得了最先进的排名相关性，但正文未提供完整的 Spearman 或 Kendall-τ 数值对比表，仅定性描述“优于现有方法”。据领域综述，当前 NAS-Bench-201 上 SOTA 的 Spearman 相关系数为 NCD 的 0.773，而本文采用 Kendall-τ 作为主要指标，两者数值不可直接比较，导致无法精确量化本文相对于 NCD 或 InTrain 的绝对优势。

消融实验验证了六个探针任务的必要性与双变量优化的有效性。在 NAS-Bench-301 上，任何少于六个任务的子集其排名相关性均单调低于完整任务集，表明任务多样性不可被额外数据或轮数替代。在 PTC 消融中，固定 $D$ 或 $E$ 单独优化另一变量时，在 1 GPU 小时预算下，CNN、Transformer 和 Mamba 架构的 Top-1 准确率均低于双变量联合优化结果。例如，在 Mamba 架构上，仅优化 $D$ 得 78.3%，仅优化 $E$ 得 78.5%，而联合优化达到 80.1%，证明 $D$ 与 $E$ 对代理可靠性具有非冗余的显著影响。此外，替换为 [41] 中的一维 token 任务后，Kendall-τ 显著下降（如 NAS-Bench-301 从 86.00 降至 24.68），证实了视觉几何任务设计的必要性。

评估边界方面，本文仅使用 ImageNet-1K 数据，未引入额外标注，保证了可复现性。代码已开源（https://github.com/fanyi-plus/tf-nas）。然而，论文未报告置信区间，且未提供与硬件约束（延迟、能耗）相关的评估，限制了其在边缘部署场景的适用性。此外，Kendall-τ 与 Spearman ρ 的差异使得跨论文比较存在协议偏差，需统一指标后方可进行严格的 SOTA 判定。

## 关联研究分析

从问题动机看，本文与 NCD 和 InTrain 解决同一核心问题——ZCP 的非线性偏差，但路径截然不同。NCD 通过随机激活掩码和非线性重缩放在静态统计量层面修正偏差，InTrain 则引入信息几何量化动态可训练性，二者均保持“训练-free”的纯粹性。本文则通过引入极短训练，将评估从静态状态转移至动态行为，本质上是用微小的计算成本换取了对非线性效应的直接捕捉。这种差异源于对“成本”定义的重新界定：NCD 和 InTrain 追求零训练成本，而本文接受秒级训练成本以换取跨架构族的通用性。然而，本文未讨论这种微训练是否引入了对初始化分布的依赖，若初始化噪声较大，微训练的性能稳定性是否优于纯统计量，论文未给出回答。

从方法设计看，本文借鉴了 [41] 的 token 级任务思路，但将其改造为二维视觉几何任务。[41] 的任务假设一维离散 token 的解可从位置索引猜测，这与图像的几何敏感性不兼容。本文通过设计 LGJ、RM 等任务，显式建模了空间连续性和几何不变性。与 CoLLM-NAS 等 LLM 驱动方法相比，本文不依赖 LLM 生成架构代码，而是聚焦于评估器的优化。CoLLM-NAS 通过 LLM 协作生成新颖架构，突破了固定搜索空间的限制，但面临代码合法性风险；本文则通过通用视觉块构建搜索空间，利用探针任务评估，更侧重于评估效率与精度的平衡。两者分别代表了“生成侧”与“评估侧”的优化路径，本文在评估侧的预算自适应机制为 LLM 生成架构后的快速筛选提供了潜在的高效工具。

## 总结

本文旨在解决高效 NAS 中训练型方法成本高与零成本代理精度低的矛盾。通过引入视觉微任务进行极短训练，并设计二次曲面拟合的预算自适应评估器，本文在固定时间预算下最大化了排名保真度。实验表明，该方法在 NAS-Bench-301 等基准上取得了优于纯 ZCP 的排名相关性，且在 Mamba 架构上通过双变量优化将 Top-1 准确率提升至 80.1%。然而，本文的评估协议采用 Kendall-τ，与主流 Spearman ρ 存在差异，且未涵盖硬件约束，限制了其在边缘部署场景的直接应用。当支持集增大到 5-shot 时，微训练的边际收益是否递减，论文未给出回答。
