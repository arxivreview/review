# CVPR2026最新论文 ｜Self-guided Semantic Inspection for Zero-Shot Composed Image Retrieval ｜自引导语义检查用于零样本组合图像检索

研究机构：中国科学技术大学

作者：Jingjing Zhang、Lei Zhang、Zheren Fu 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ec4c64488dc5)

> 零样本组合图像检索（ZS-CIR）旨在通过参考图像与修改文本检索目标图像，其核心难点在于训练时图像-文本语义对齐，而推理时两者存在语义冲突。现有方法多采用一致性驱动范式，通过伪词元或特征插值强制模态对齐，导致模型缺乏处理跨模态差异的能力，在细粒度修改任务中表现受限。DiffComp 提出“先分化后组合”范式，通过短语引导选择性掩码主动构造训练时的语义偏差，并基于差异程度自适应融合特征。该方法在多个基准上取得先进性能，但缺乏与最新自适应融合方法的直接定量对比，且掩码机制对视觉信息保留的影响尚不明确。

## 研究背景

组合图像检索（Composed Image Retrieval, CIR）任务要求模型在保留参考图像视觉锚点的同时，应用文本指令的语义约束。视觉-语言预训练模型（Vision-Language Pretraining, VLP）如 CLIP 提供了强大的跨模态对齐能力，但其全局表示往往忽略局部语义细节，导致在需要细粒度属性修改的场景中，模型难以区分“保留”与“修改”的视觉区域。这种全局语义的模糊性使得简单的特征拼接或线性插值引入无关背景噪声，稀释修改文本的意图。

主流零样本方法如 Pic2Word 和 SEARLE 将图像映射为文本空间伪词元，虽解决了模态间隙问题，但依赖一致性训练目标，迫使模型关注共享语义而非差异信号。CIReVL 等基于大语言模型（Large Language Model, LLM）的方法通过生成目标描述避免视觉信息丢失，但牺牲了视觉特征的直接利用，且存在幻觉风险。这些方法共同忽视了训练-推理分布不一致这一根本矛盾：训练数据中图像与文本语义对齐，而推理时参考图像与修改文本往往描述冲突或互补的语义内容。DiffComp 的切入点在于将语义差异视为组合推理的核心信号，通过自监督机制在训练阶段主动诱导并学习处理这种跨模态差异。

## 核心方法

### 方法参照系

零样本组合图像检索的标准流程通常包括：提取参考图像全局特征、提取修改文本特征、通过固定权重插值或伪词元拼接生成组合查询。本文的关键差异在于拒绝“对齐即融合”的假设，转而引入局部语义单元与差异感知机制，将组合过程重构为对语义偏差的建模与控制。

### 上下文语义超补丁

传统 CLIP 的 patch 隐藏状态编码全局语义，缺乏局部可解释性，导致无法精确定位需保留或修改的视觉区域。DiffComp 提出上下文语义超补丁（Contextual Semantic Super-patch, CSS），将相邻 $S \times S$ 个 patch 分组为空间连贯区域，每个超补丁独立通过视觉编码器提取 [CLS] 特征。

$$ f_{SP}^j = \text{VisualEncoder}([e_{[CLS]}, e_{j_1}, e_{j_2}, \dots, e_{j_{S^2}}]) $$

该公式表明，超补丁特征是其内部所有 patch 嵌入与 [CLS] 标记的联合编码，提供了比全局特征更细粒度、比单个 patch 更语义完整的局部表示，为后续差异感知提供了空间选择性的基础单元。

### 短语引导选择性掩码

一致性训练导致模型忽略模态间冲突，无法学习如何区分“文本已描述”与“文本未描述”的视觉内容。DiffComp 引入短语引导选择性掩码（Phrase-guided Selective Masking, PSM），利用 Stanford CoreNLP 提取文本中的名词、动词及介词短语，计算每个超补丁与短语的相似度，并通过 Gumbel-Softmax 采样生成可微分掩码。

$$ m_j = \mathbb{I}[\arg\max_k \hat{m}_{j,k} = 0], \quad \hat{m}_{j,k} = \frac{\exp((\log q_{j,k} + G_{j,k})/\varpi)}{\sum_{l=1}^2 \exp((\log q_{j,l} + G_{j,l})/\varpi)} $$

其中 $q_{j,k}$ 为超补丁 $j$ 的掩码概率，$G_{j,k}$ 为 Gumbel 噪声。该机制主动移除与显著短语高度对齐的视觉区域，生成“差异化图像” $f_{Id}$，迫使模型在训练中学习处理视觉-文本语义缺失，从而弥合训练-推理分布差距。

### 差异感知组合

固定权重插值无法适应局部语义变化，导致文本对齐区域过度受文本影响或视觉区域保留不足。DiffComp 提出差异感知组合（Difference-aware Composition, DAC），基于超补丁与文本特征的余弦相似度计算自适应插值权重。

$$ \varrho_j = \varrho_{base} \cdot \frac{1 - \exp(\text{sim}_j)}{\max_i \exp(\text{sim}_i)}, \quad \tilde{f}_j = \frac{\sin((1-\varrho_j)\varsigma_j)}{\sin \varsigma_j} f_{SP}^j + \frac{\sin(\varrho_j \varsigma_j)}{\sin \varsigma_j} f_T $$

其中 $\text{sim}_j$ 为超补丁与文本的相似度，$\varsigma_j$ 为角距离。该公式表明，与文本高度对齐的区域（$\text{sim}_j$ 大）获得较小的 $\varrho_j$，保留更多视觉语义；而语义差异大的区域则更强烈地受文本引导，实现空间选择性的连续组合。

## 实验评估

实验在 CIRR、FashionIQ、CIRCO 等标准基准上进行，对比方法涵盖 Pic2Word、SEARLE、CIReVL 等经典零样本方法。论文声称取得 state-of-the-art 性能，但未提供与 2026 年最新 SOTA 方法（如 WISER、G-MIXER）的直接数值对比表，仅定性描述优于现有方法。由于【论文实验数据】区未提供具体数值单元格，无法构建定量对比表格，故本节仅进行定性审计。

消融实验部分，论文未提供详细的超参数敏感性分析或掩码强度对召回率影响的量化数据。设计决策上，CSS 模块通过分组 patch 提升局部语义紧凑性，PSM 模块通过文本驱动掩码引入差异，DAC 模块通过自适应权重平衡视觉-文本贡献。缺乏对“掩码过度导致视觉信息丢失”这一潜在风险的定量验证，使得该方法在细粒度属性修改任务（如 FashionIQ）上的鲁棒性存疑。

评估边界方面，论文未报告计算效率指标（如推理延迟、显存占用），而自适应融合方法通常以效率为代价。可复现性上，论文提供了代码链接，但训练数据仅使用 10% CC3M，未说明不同数据规模对性能的影响。指标完备性上，未报告置信区间，且未区分方法贡献与骨干网络贡献，导致性能提升归因不清晰。

## 关联研究分析

从问题动机看，DiffComp 与 Pic2Word 等伪词元方法的根本差异在于对“语义一致性”的态度。Pic2Word 假设视觉信息可无损映射至文本空间，通过一致性训练强化模态对齐；而 DiffComp 认为一致性训练掩盖了推理时的语义冲突，通过 PSM 主动破坏对齐以暴露差异。这一差异源于任务特性的理解：CIR 的核心是“修改”而非“匹配”，修改必然涉及视觉与文本的语义偏差。DiffComp 将偏差视为信号而非噪声，这一视角转换是其创新的核心。然而，PSM 依赖短语提取的准确性，若文本短语提取错误，掩码将移除错误区域，导致视觉信息过度丢失，论文未对此进行鲁棒性测试。

从方法设计看，DiffComp 与 CIReVL 等 LLM 生成方法形成互补。CIReVL 通过生成目标描述避免视觉信息丢失，但依赖 LLM 的推理能力，存在幻觉风险且计算开销大；DiffComp 直接在特征空间操作，无需 LLM，计算效率更高，但缺乏语义生成的丰富性。两者在细粒度基准上的表现差异，反映了“特征操作”与“语义生成”两条路线的权衡。DiffComp 的 CSS 模块提供了比全局特征更细粒度的单元，但相比 LLM 生成的完整描述，其语义表达能力仍受限于视觉编码器的容量。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

DiffComp 针对零样本组合图像检索中训练-推理分布不一致的核心矛盾，提出“先分化后组合”范式，通过短语引导选择性掩码主动构造语义偏差，并基于差异程度自适应融合特征。该方法在多个基准上取得先进性能，证明了差异感知机制的有效性。然而，论文缺乏与最新自适应融合方法的直接定量对比，且未验证掩码机制对视觉信息保留的影响，使得其在细粒度任务中的鲁棒性存疑。当参考图像与修改文本的语义差异极大时，PSM 移除的视觉区域是否过多，导致组合查询偏离目标图像，论文未给出回答。
