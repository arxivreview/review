# CVPR2026最新论文 ｜AVGGT: Rethinking Global Attention for Accelerating VGGT ｜基于全局注意力角色解耦的免训练加速

研究机构：上海交通大学

作者：Xianbing Sun、Zhikai Zhu、Zhengyu Lou 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.02541)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.02541)

> 多视图三维重建模型依赖全局自注意力建模跨视图几何一致性，但其二次计算复杂度导致大规模场景下内存溢出与推理缓慢。现有稀疏化方案缺乏对注意力机制内部功能的系统分析，导致加速策略与模型实际行为脱节。本文通过逐层分析发现全局注意力在早期、中期、后期分别承担无效、对齐、微调三种角色，据此提出将早期层转换为帧内注意力并对剩余层进行键值子采样的免训练加速方案。该策略在保持精度的同时实现了最高10倍加速，但其子采样策略在极端动态场景下的鲁棒性尚未得到充分验证。

## 研究背景

理解本文需厘清前馈式三维重建中全局自注意力的功能定位。VGGT 等模型采用交替全局与帧内注意力架构，其中全局注意力负责跨视图特征交互，帧内注意力负责单视图结构细化。然而，全局自注意力的计算复杂度随输入帧数 $N$ 呈 $O(N^2)$ 增长，当处理数百帧图像时，显存占用迅速突破硬件极限，成为制约实时应用的核心瓶颈。

传统结构从运动（Structure-from-Motion, SfM）流水线虽精度高但迭代优化耗时且易在弱纹理区域失效，促使领域转向 DUSt3R 开创的点图回归范式。VGGT 进一步确立 Transformer 骨干地位，但其全局注意力机制在计算效率上存在固有缺陷。FastVGGT 与 FasterVGGT 尝试通过 Token 合并或块稀疏注意力缓解此问题，但这些方法未深入剖析全局注意力在模型不同深度层的具体作用，导致加速策略缺乏针对性。本文切入点在于揭示全局注意力的层级功能分化，并基于此设计符合模型内在逻辑的加速方案。

## 核心方法

### 方法参照系

本文问题属于高效前馈重建路线，旨在降低 VGGT 类模型的全局注意力计算开销。与通用稀疏注意力方法不同，本文不预设注意力分布的稀疏性，而是基于对模型内部注意力模式的实证分析，识别出可安全移除或降采样的特定层级与 Token 子集，从而在免训练条件下实现加速。

### 全局到帧内注意力转换

早期全局注意力层在特征尚未形成充分三维信息时执行跨视图交互，其注意力分布均匀且缺乏空间对应性，对多视图一致性贡献微弱。为消除这一冗余计算，本文引入分割索引 $t_{early}$，将深度小于该索引的全局注意力层直接转换为帧内注意力。转换操作仅需跳过 Token 重排步骤，保持每帧独立计算注意力，从而将受影响层的计算复杂度从 $O((NL)^2)$ 降至 $O(NL^2)$。

$$
\text{Cost}_{G2F} = \sum_{i=0}^{t_{early}-1} O(NL^2) + \sum_{i=t_{early}}^{L_{total}-1} O((NL)^2)
$$

该公式表明，通过截断早期层的全局交互，整体计算量随 $t_{early}$ 增大而线性减少。实验设定 $t_{early}=9$（VGGT）或 $10$（$\pi_3$），在保留后续对齐能力的前提下，显著降低了前向传播的初始开销。

### 子采样全局注意力

中期全局注意力层主要执行跨视图空间对应 Token 的对齐，其注意力矩阵呈现稀疏且集中于几何匹配点的特性。基于点云对齐仅需少量锚点的直觉，本文提出子采样全局注意力（SGA）策略，对剩余全局层的键值（Key/Value） Token 进行网格均匀子采样，同时保留所有查询（Query） Token 以维持稠密预测能力。子采样因子 $\sigma$ 分解为高度与宽度步长 $(sh, sw)$，保留每个 $sh \times sw$ 窗口内的首个 Token。

$$
\mathbf{A}_{SGA} = \text{Softmax}\left( \frac{\mathbf{Q}\mathbf{K}_S^T}{\sqrt{d}} \right) \mathbf{V}_S + \mathbf{A}_{diag} + \mathbf{A}_{mean}
$$

其中 $\mathbf{K}_S, \mathbf{V}_S$ 为子采样后的键值集，$\mathbf{A}_{diag}$ 保留对角线自交互以维持局部特征连贯性，$\mathbf{A}_{mean}$ 为被丢弃 Token 的均值填充项，三者共享单一 Softmax 归一化。该设计在降低 $O(N^2)$ 复杂度至 $O(N^2/\sigma)$ 的同时，通过均值项补偿全局信息损失，避免了稀疏化导致的长程依赖断裂。

## 实验评估

实验在 RealEstate10K、TUM-dynamics、DTU 及 7-Scenes 数据集上评估，对比基线包括 VGGT、$\pi_3$、FastVGGT 及 FasterVGGT。基线覆盖主流稀疏化路线，但缺失 MASt3R-SLAM 等基于测试时训练的长序列方法，限制了在极端长序列场景下的对比广度。

| 方法 | 数据集 | AUC@30 (%) | Time (s) | FLOPs (T/P) |
| :--- | :--- | :--- | :--- | :--- |
| VGGT | 7-Scenes (800f) | 74.161 | 397.133 | 35.113 P |
| AVGGT(9) | 7-Scenes (800f) | 77.382 | 50.034 | 3.825 P |
| $\pi_3$ | 7-Scenes (800f) | 80.572 | 298.477 | 26.465 P |
| A$\pi_3$(9) | 7-Scenes (800f) | 79.409 | 30.273 | 2.267 P |
| FasterVGGT$_{75}$ | 7-Scenes (800f) | OOM | OOM | OOM |

在 800 帧极端密集设置下，FasterVGGT 因显存溢出无法运行，而 AVGGT(9) 不仅成功推理，且 AUC@30 指标（77.382%）甚至优于原始 VGGT（74.161%），同时推理时间从 397.133 秒降至 50.034 秒，实现约 8 倍加速。

消融实验显示，仅执行全局到帧内转换（G2F）导致 AUC@30 从 88.130% 降至 87.981%，性能损失微小；而结合子采样后，随着 $\sigma$ 增大，性能呈边际递减趋势，$\sigma=9$ 时 AUC@30 降至 84.723%（RealEstate10K），但仍高于 FastVGGT 的 81.103%。对角线保留与均值填充组件在密集输入下带来轻微性能提升，验证了其对信息损失的补偿作用。

评估协议遵循 $\pi_3$ 标准，报告 AUC、Acc 等指标，但未提供置信区间，数值比较需谨慎。实验在 NVIDIA A100 GPU 上进行，代码未公开，超参数（如 $t_{early}$ 选择）依赖人工消融确定，可复现性受限于未开源的实现细节。

## 关联研究分析

从方法设计看，AVGGT 与 FastVGGT 的核心差异在于加速依据。FastVGGT 基于 Token 相似度进行合并，假设注意力矩阵存在冗余 Token，但未区分不同深度层的功能差异。AVGGT 则通过逐层分析发现早期层注意力缺乏空间对应性，从而针对性地移除早期全局交互。这一差异源于对模型内部机制理解深度的不同：FastVGGT 关注统计特性，AVGGT 关注功能语义。

从问题动机看，AVGGT 与 Scal3R 形成互补。Scal3R 采用测试时训练（TTA）解决长序列漂移，通过参数更新适应新上下文，但计算开销大且需额外训练阶段。AVGGT 坚持免训练路线，通过架构层面的计算削减实现加速，适用于对延迟敏感且无法进行在线更新的部署场景。两者分别代表了“适应性”与“效率性”两条技术路径，前者以精度换适应性，后者以结构换速度。

## 总结

本文核心矛盾在于全局自注意力的几何对齐必要性与二次计算复杂度之间的冲突。现有稀疏化方法因缺乏对注意力层级功能的系统分析，导致加速策略与模型行为脱节。AVGGT 通过揭示早期层无效、中期层对齐、后期层微调的角色分化，提出全局到帧内转换与键值子采样的组合策略，在 800 帧场景下实现 8-10 倍加速且精度持平或略优。其边界在于子采样策略假设注意力稀疏性在密集输入下依然成立，当场景包含大量动态物体或重复纹理时，稀疏锚点可能无法覆盖关键几何变化。当输入序列中包含高频动态干扰时，固定网格子采样是否会导致关键运动区域的几何信息丢失，论文未给出回答。
