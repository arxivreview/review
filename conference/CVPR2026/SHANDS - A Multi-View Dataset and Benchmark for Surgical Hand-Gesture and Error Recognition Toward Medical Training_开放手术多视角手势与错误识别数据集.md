# CVPR2026最新论文 ｜SHANDS: A Multi-View Dataset and Benchmark for Surgical Hand-Gesture and Error Recognition Toward Medical Training ｜开放手术多视角手势与错误识别数据集

研究机构：瑞士日内瓦大学、新加坡南洋理工大学

作者：Le Ma、Thiago Freitas dos Santos、Nadia Magnenat-Thalmann 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.26400)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.26400)

> 开放手术技能评估长期依赖专家主观观察，缺乏可规模化、客观化的自动评估手段。现有微创手术数据集（如Cholec80）仅提供单视角内窥镜影像，无法捕捉开放手术中手部与器械的精细协调动作，且缺乏临床验证的错误标签。本文构建了首个开放手术多视角RGB视频数据集SHANDS，通过5路同步摄像头记录52名参与者的切割与缝合动作，并建立15类手势原语与8类错误分类体系。该数据集填补了开放手术手部动作自动评估的数据空白，但其仅覆盖基础动作且未验证跨术式泛化能力，限制了其在复杂临床场景中的直接应用。

## 研究背景

手术技能自动评估的核心挑战在于如何从视觉信号中提取具有临床意义的动作质量指标。传统方法依赖专家对视频的主观评分，存在成本高、不可复现且难以规模化的问题。计算机视觉方法虽能实现客观量化，但受限于数据特性：微创手术数据集（如JIGSAWS、Cholec80）主要记录机器人辅助或内窥镜视角，无法反映开放手术中手部直接操控器械的精细运动学特征；而通用多视角动作识别数据集（如NTU RGB+D）虽具备多视角同步优势，却缺乏手术领域的临床语义标注与错误分类体系。这种“临床真实性”与“多视角鲁棒性”的缺失，导致现有模型在开放手术场景下无法有效区分细微的技术偏差。

当前研究在手术视频理解上已形成两条主要路线：一是基于单视角内窥镜的阶段识别与工具检测，二是基于机器人运动学数据的技能评估。前者受限于单一视角下的遮挡问题，难以全面捕捉手部动作的空间结构；后者虽具备精确的运动学信息，但无法迁移至无机器人介导的开放手术训练场景。本文的切入点在于构建一个专门针对开放手术手部动作的多视角数据集，通过同步RGB视频捕捉互补视角信息，并结合临床专家定义的手势原语与错误分类，为自动技能评估提供兼具临床语义与视觉鲁棒性的数据基础。

## 核心方法

### 多视角同步采集与标注体系

本文问题与通用视频动作识别的关键差异在于：需同时满足临床语义的精确性与多视角几何的互补性。标准动作识别数据集通常仅提供单一视角或无临床标注，而手术技能评估要求帧级精确的手势边界与错误类型定义。SHANDS采用5路Canon PowerShot A2500摄像头（25 fps, 640×480 px）通过硬件级同步（CHDK）确保帧级对齐，消除后处理配准误差。标注体系分为两层：15个手势原语（切割I1-I5，缝合S1-S10）定义动作的基本组件，8个错误类别（如II1不当握持、IS3错误打结）反映临床验证的技术偏差。这种层次化设计使得模型既能学习动作时序结构，又能识别具体错误模式。

### 跨视角特征解耦与融合

多视角融合的核心挑战在于如何从不同视角中提取视角不变的动作特征，同时保留视角特定的空间细节。本文采用DVANet作为多视角SOTA基线，其核心机制是通过对比学习解耦视角不变特征 $z_{inv}$ 与视角特定特征 $z_{view}$：

$$
\mathcal{L}_{decouple} = \mathcal{L}_{con}(z_{inv}^i, z_{inv}^j) + \mathcal{L}_{sep}(z_{view}^i, z_{view}^j)
$$

其中 $\mathcal{L}_{con}$ 为对比损失，拉近同一动作不同视角的不变特征；$\mathcal{L}_{sep}$ 为分离损失，推远不同动作的视角特定特征。该设计动机在于解决单视角模型在遮挡或视角变化下的性能退化问题：通过显式建模视角不变性，模型能在未见视角（如C4-C5）上保持鲁棒性。实验表明，DVANet在跨视角泛化任务中达到68.5% Top-1准确率，较单视角VideoMAE-B的60.4%提升8.1个百分点，验证了解耦机制对视角鲁棒性的贡献。

## 实验评估

实验在SHANDS数据集上进行，采用跨主体评估协议（Train/Val/Test = 31/11/10参与者），单视角实验使用C1-C5中任一摄像头，多视角实验使用全部5路视频，跨视角泛化实验在C1-C3上训练并在C4-C5上测试。基线覆盖CNN（R3D, SlowFast, X3D-M）与Transformer（TimeSformer, ViViT-B, MViTv2-B, VideoMAE-B/L, InternVideo2）两类架构，但缺失手术领域专用基础模型（如SurgMAE、Endo-FM）的对比，限制了与现有手术视频理解SOTA的直接比较。

| 方法 | 预训练数据集 | Top-1 (%) | Macro-F1 |
| :--- | :--- | :--- | :--- |
| SlowFast | K400 | 55.7±1.2 | - |
| TimeSformer | K400 | 58.4±1.1 | - |
| VideoMAE-B | K400 | 63.4±0.6 | - |
| InternVideo2 | Im21K+K400 | 68.9±0.8 | - |
| MVAction | NTU RGB 120 | 70.4±0.9 | 0.704 |
| ViewCon | NTU RGB 120 | 72.5±0.6 | 0.723 |
| DVANet | NTU RGB 120 | 73.9±0.6 | 0.736 |

单视角实验中，Transformer架构（InternVideo2 68.9%）显著优于CNN（SlowFast 55.7%），验证了自监督预训练在细粒度动作识别中的优势。多视角实验中，DVANet以73.9% Top-1和0.736 Macro-F1领先，较单视角最强基线提升5.0个百分点，表明多视角融合对遮挡鲁棒性的贡献。跨视角泛化实验中，DVANet在未见视角（C4-C5）上保持68.5% Top-1（94.1%性能保留率），而ViewCon降至63.2%（92.4%保留率），证实了解耦机制对视角不变性的有效性。错误检测实验中，DVANet在8类错误上达到68.5% Top-1，其中“不当器械握持”（77.3%）与“结果错误”（76.2%）识别率较高，但“错误针处理”（60.9%）与“过度施力”（61.8%）等细微错误识别率较低，表明多视角融合对宏观错误有效，但对细微力学偏差的捕捉仍受限。

评估协议存在局限：数据集仅包含切割与缝合两种基础动作，未覆盖复杂术式（如血管吻合、器官切除）；标注覆盖率为专家92%、学员55%，未标注数据未用于半监督学习实验；缺乏与JIGSAWS、Cholec80等标准基准的跨数据集泛化测试。代码与超参数未公开，可复现性受限。

## 关联研究分析

从问题动机看，SHANDS与JIGSAWS、Cholec80等现有手术数据集的根本差异在于场景定义：前者聚焦开放手术手部动作，后者聚焦微创/机器人手术阶段识别。JIGSAWS提供同步运动学数据但无法反映无机器人介导的手部协调；Cholec80提供长时序内窥镜视频但缺乏手部细节与错误标签。SHANDS通过多视角RGB视频弥补了这一空白，但其动作复杂度（15类手势）远低于Cholec80的7阶段+45动作三元组，且未包含运动学模态，限制了其在精细力学评估中的应用。

从方法设计看，SHANDS采用的多视角融合策略（DVANet, ViewCon）与手术领域主流的视觉-语言多模态融合（如VLM-hyster, SurgMLLMBench）存在路线差异。前者依赖几何互补性提升鲁棒性，后者依赖语义先验提升可解释性。SHANDS未引入语言模态，导致错误类型的语义解释能力受限：例如“过度施力”（IS2）的识别依赖视觉线索（如组织形变），而非文本描述（如“张力不足”）。这种设计选择反映了开放手术训练场景的部署约束（低成本RGB摄像头），但牺牲了与临床术语的语义对齐能力。

## 总结

SHANDS要解决的核心矛盾是开放手术技能评估中“临床语义精确性”与“多视角视觉鲁棒性”的缺失。现有微创手术数据集无法捕捉手部动作细节，通用多视角数据集缺乏临床标注，本文通过构建5路同步RGB视频数据集与层次化标注体系，首次为开放手术手部动作自动评估提供数据基础。实验证明多视角融合（DVANet 73.9% Top-1）较单视角（68.9%）提升5.0个百分点，跨视角泛化保留率达94.1%，验证了多视角策略的有效性。然而，数据集仅覆盖切割与缝合两种基础动作，未包含复杂术式与运动学模态，且缺乏语言模态的语义对齐。当动作复杂度增加至血管吻合或器官切除时，多视角RGB视频是否仍能捕捉足够的力学细节以区分细微技术偏差，论文未给出回答。
