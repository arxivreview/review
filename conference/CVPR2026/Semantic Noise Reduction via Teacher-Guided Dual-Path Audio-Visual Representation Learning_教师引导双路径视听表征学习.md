# CVPR2026最新论文 ｜Semantic Noise Reduction via Teacher-Guided Dual-Path Audio-Visual Representation Learning ｜教师引导双路径视听表征学习

研究机构：中国科学院、中国科学院大学

作者：Linge Wang、Yingying Chen、Bingke Zhu 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.08147)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.08147)

> 视听自监督预训练长期受困于重建与对齐目标的梯度干扰，导致对比分支引入语义噪声。现有联合优化框架强制两个目标共享同一随机掩码视图，无法兼顾重建所需的强正则化与对齐所需的语义完整性。TG-DP 通过解耦双路径前向传播并引入教师引导掩码，使对比分支获得独立且结构化的可见 token 视图。该框架在零样本检索与分类任务上刷新了 SOTA，但其训练成本增加 43% 且教师引导的泛化边界尚不明确。

## 研究背景

视听表征学习依赖掩码自编码器（Masked Autoencoder, MAE）与对比学习（Contrastive Learning, CL）的协同。MAE 通过高比例掩码重建模态内部结构，而 CL 通过全局 token 对齐跨模态语义。然而，当两者在单一前向传播中共享同一掩码视图时，高掩码率（如 75%）虽利于重建，却会移除音频中稀疏分布的关键语义线索，导致对比分支的全局表征被静默频谱或无信息背景污染，形成语义噪声。这种目标耦合不仅削弱了跨模态对齐精度，还因重建与判别目标的梯度冲突引发优化不稳定。

主流 CAV-MAE 系列方法（如 CAV-MAE Sync）虽引入全局与注册 token 以减轻 patch 负担，但对比损失仍建立在受重建目标塑造的共享表征之上。这种架构假设重建所需的局部细节保留与对齐所需的整体语义完整可以兼容，但在音频模态上尤为失效，因为音频语义在 token 间分布稀疏且冗余度低。TG-DP 的切入点在于识别出“掩码策略”是连接两个目标的瓶颈，主张为不同目标分配独立的可见性模式，并通过教师信号为对比分支提供结构化的 token 选择依据，从而在保留 MAE 重建优势的同时，消除 CL 分支的语义噪声。

## 核心方法

### 方法参照系

本文基于 CAV-MAE Sync 骨干，该架构通过独立的全局 token 和 InfoNCE 损失实现视听对齐。与标准单路径流程的关键差异在于，TG-DP 将重建与对齐解耦为两个独立的前向传播路径，并引入教师-学生机制重构对比分支的掩码生成逻辑，打破了共享掩码视图的约束。

### 双路径解耦与非对称掩码

在标准流程中，重建与对比损失共享同一组可见 token，导致高掩码率损害对齐所需的语义完整性。TG-DP 将每个样本处理两次：重建分支采用 75% 高掩码率以强化模态内部结构学习，而对比分支采用 50% 低掩码率以保留更完整的语义上下文。这种非对称设计使对比分支免受重建导向的随机掩码干扰，其全局 token 聚合自更具语义代表性的视图。最终训练目标由三项损失加权组合：

$$ \mathcal{L}_{all} = \lambda_1 \mathcal{L}_{rec} + \lambda_2 \mathcal{L}_{dis} + \lambda_3 \mathcal{L}_{contra} $$

其中 $\mathcal{L}_{rec}$ 为重建损失，$\mathcal{L}_{dis}$ 为蒸馏损失，$\mathcal{L}_{contra}$ 为对比损失。该设计通过物理隔离梯度流，消除了生成目标与判别目标在共享表征上的竞争，为后续教师引导提供了结构基础。

### 教师引导掩码与蒸馏

对比分支的可见 token 选择不再随机，而是由教师网络引导。教师网络接收完整无掩码输入，其联合编码器中 patch token 与全局 token 的注意力权重被提取并归一化，作为 token 优先级线索。学生网络保留得分最高的 top-k token 作为可见输入，形成确定性引导掩码。同时，教师通过指数移动平均（EMA）更新，其全局表征 $\hat{g}_v, \hat{g}_a$ 作为目标，与学生全局表征 $g_v, g_a$ 计算均方误差蒸馏损失：

$$ \mathcal{L}_{dis} = \| \hat{g}_v - g_v \|^2 + \| \hat{g}_a - g_a \|^2 $$

这一机制将教师的全局语义先验注入学生的掩码视图，既提供了语义锚定信号，又通过结构化选择减少了噪声 token 对对比对齐的干扰，提升了表征的稳定性。

## 实验评估

实验在 AudioSet-2M 和 VGGSound 上进行，评估协议包括零样本检索（R@1/5/10）和冻结编码器分类（mAP/Acc）。基线覆盖 CAV-MAE 系列、ImageBind、LanguageBind 等主流方法，但缺失 WAVE 等基于 LLM 的嵌入类基线，限制了与最新语义深度方法的直接对比。

| 方法 | VGGSound V→A R@1 | VGGSound A→V R@1 | AS20K mAP |
| :--- | :--- | :--- | :--- |
| CAV-MAE Sync | 27.9 | 23.2 | 30.5 |
| TG-DP | 31.3 | 30.3 | 32.0 |

TG-DP 在 Audio→Visual 方向提升显著（R@1 从 23.2 至 30.3），验证了解耦掩码对稀疏音频语义的保护作用。消融实验显示，对比分支掩码率设为 0.50 时平衡最佳，0.00 虽提升检索但削弱分类正则化，0.75 则严重损害检索。教师引导掩码中，确定性选择（Distinct Guided Mask）优于随机掩码和概率性引导（Probabilistic Guided Mask），后者因 Gumbel 噪声扰动排名导致性能低于随机基线，表明结构化引导需保持确定性以维持语义一致性。蒸馏损失带来边际增益（AS20K mAP 30.5→32.0），但非主导因素。

评估边界方面，论文未报告置信区间，且 AS20K mAP 32.0 与领域综述中 MJEPA 的 21.66 不可直接比较，因后者为 AudioSet 全量分类而前者为子集注意力探测协议。代码已开源，但训练成本增加 43%（7.1h 至 10.2h），推理阶段无额外开销。

## 关联研究分析

从问题动机看，TG-DP 与 MJEPA 形成架构对立。MJEPA 采用单一共享编码器处理异构数据，依赖联合嵌入预测损失，牺牲模态特定细粒度以换取架构简洁；TG-DP 则坚持模态独立编码器与双路径解耦，通过非对称掩码保留模态特异性。这种差异源于对“语义噪声”来源的不同假设：MJEPA 认为噪声源于数据异构性，TG-DP 认为噪声源于目标耦合下的掩码失配。TG-DP 在 Audio→Visual 检索上的显著优势暗示，音频模态的稀疏语义特性使其对掩码策略更敏感，而 MJEPA 的共享编码器可能在音频端缺乏足够的语义保留能力。

从方法设计看，TG-DP 借鉴 DINO 的 EMA 教师机制，但将其功能从纯蒸馏扩展为掩码引导。DINO 中教师提供软标签以稳定训练，TG-DP 中教师提供注意力权重以结构化学生视图。这一改动将教师信号从“目标”转化为“输入构造器”，解决了随机掩码在对比分支中引入语义噪声的问题。然而，教师引导掩码依赖教师注意力的准确性，若教师在训练初期注意力分布不稳定，可能导致学生视图偏差。论文未探讨教师引导在长序列或开放世界数据上的可扩展性，也未分析教师偏见对学生表征的潜在过拟合风险。

## 总结

TG-DP 针对视听自监督预训练中重建与对齐目标的优化干扰问题，通过双路径解耦和非对称掩码策略，使对比分支获得独立且语义完整的视图。教师引导掩码进一步结构化可见 token，减少了噪声干扰。实验证明该框架在零样本检索和分类上均优于 CAV-MAE Sync，尤其在 Audio→Visual 方向提升显著。然而，训练成本增加 43% 且教师引导的确定性选择可能限制模型对动态场景的适应性。当视频时长增加至分钟级时，教师注意力的计算开销和掩码选择的稳定性是否仍能维持性能优势，论文未给出回答。
