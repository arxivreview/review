# CVPR2026最新论文 ｜DuetMerging: Synergizing Dynamic and Static Strategies for Mitigating Task Interference in Model Merging ｜双轨协同模型合并

研究机构：哈尔滨工业大学、西北工业大学

作者：Yan Li、Guiping Cao、Yaguang Song 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_3a5d25bda810)

> 模型合并旨在整合多个专家模型以解决部署成本瓶颈，但任务向量间的参数干扰常导致合并性能低于单任务专家。现有动态合并方法虽引入路由机制，却因孤立构建专家池而未能消解跨任务的结构冲突。本文提出 DuetMerging，通过 Tucker 分解构建共享专家池并结合神经元激活掩码修正残差，从动态与静态双视角协同抑制干扰。该方法在 ViT 骨干上实现了 99.2% 的归一化准确率，接近单任务专家上限，但其对 FFN 层的依赖及激活掩码的分布敏感性仍存疑。

## 研究背景

预训练基座模型 $\Theta_0$ 经微调后产生任务向量 $\tau_t = \Theta_t - \Theta_0$，其线性叠加是模型合并的基础。然而，当任务差异较大时，不同 $\tau_t$ 在共享参数空间中的方向冲突引发参数干扰，导致合并模型性能显著低于独立专家。为应对此问题，研究者引入混合专家（Mixture-of-Experts, MoE）架构，通过轻量级路由器根据输入动态加权任务向量，如 WEMoE 和 Twin-Merging。

尽管动态路由提升了适应性，但现有方法均独立处理每个任务向量（如单独进行奇异值分解 SVD），忽视了任务间共享的高阶结构。这种孤立压缩将共享能力与冲突参数同等对待，导致正迁移受限且负干扰残留。DuetMerging 的切入点在于将任务向量堆叠为三维张量，利用 Tucker 分解提取共享核心结构，并引入基于神经元功能特化的静态修正机制，以解决动态方法中专家池构建的结构性缺陷。

## 核心方法

### 方法参照系

DuetMerging 属于动态合并与子空间投影的交叉路线。与标准 MoE 合并（如 WEMoE）将任务向量视为独立专家不同，本文将任务矩阵 $\Delta_t \in \mathbb{R}^{d_{out} \times d_{in}}$ 沿任务维度堆叠为张量 $\mathcal{T} \in \mathbb{R}^{T \times d_{out} \times d_{in}}$，旨在捕捉任务间的高阶交互而非仅处理单任务的主成分方向。

### Tucker 分解动态专家池

针对孤立 SVD 无法建模跨任务共享结构的问题，本文对任务张量 $\mathcal{T}$ 执行 Tucker 分解：

$$ \mathcal{T} \approx \mathcal{G} \times_1 U_{task} \times_2 U_{out} \times_3 U_{in} $$

其中 $\mathcal{G}$ 为核心张量，$U_{task}, U_{out}, U_{in}$ 分别为任务、输出和输入模式的因子矩阵。该设计动机在于，核心张量 $\mathcal{G}$ 捕捉了任务、输出、输入三个维度间的潜在交互，比矩阵求和后的 SVD 更纯净地近似共享子空间。在推理时，路由器输出权重 $w(x)$，动态任务向量计算为 $u_{task}(x) = U_{task}^T w(x)$，进而重构动态任务矩阵 $\Delta_{dynamic}(x)$。这一过程确保所有专家模块均源自共享的多任务基础，从结构上增强了协同效应并抑制了冲突。

### 神经元激活引导的静态残差修正

Tucker 分解的低秩近似存在信息损失，残差张量 $R = \mathcal{T} - (\mathcal{G} \times_1 U_{task} \times_2 U_{out} \times_3 U_{in})$ 包含未被共享结构捕获的任务特异性信息。直接丢弃残差会损失关键知识，直接加回则重新引入干扰。本文利用预训练模型 FFN 层约 10% 神经元高激活且任务间激活集合 Jaccard 相似度低于 20% 的特性，生成任务特异性二进制掩码 $M_t$。静态修正矩阵定义为：

$$ \Delta_{static} = \text{Avg}(\text{Scale}(R'_t)) $$

其中 $R'_t$ 为经 $M_t$ 掩码后的残差切片，仅保留与高激活神经元相关的权重。该机制通过“外科手术式”地保留功能相关参数并零化无关或冲突参数，在恢复关键任务知识的同时消除了静态干扰源。

## 实验评估

实验在 8 个图像分类数据集（SUN397, Stanford Cars 等）上进行，骨干网络为 ViT-B/32 和 ViT-L/14，指标为平均准确率（Acc.）和归一化准确率（N. Acc.）。基线覆盖静态启发式（Task Arithmetic, TIES）、静态结构（TSV-M, DOGE AM）及动态方法（WEMoE, Twin-Merging），但缺失 Fisher-Rao 等几何推断类强基线。

| 方法 | ViT-B/32 Acc. | ViT-B/32 N. Acc. | ViT-L/14 Acc. | ViT-L/14 N. Acc. |
| :--- | :--- | :--- | :--- | :--- |
| WEMoE | - | 98.7% | - | - |
| Multi-Task | - | 98.3% | - | - |
| DuetMerging | 89.8% | 99.2% | 93.8% | 99.7% |

DuetMerging 在 ViT-B/32 上 N. Acc. 达 99.2%，超越最强动态基线 WEMoE 0.5 个百分点，并超过全监督多任务模型 0.9 个百分点，表明其几乎消除了合并带来的性能差距。

| 组件 | ViT-B/32 Acc. | 变化 | ViT-L/14 Acc. | 变化 |
| :--- | :--- | :--- | :--- | :--- |
| Full Model | 89.8 | - | 93.8 | - |
| w/o Static | 89.2 | -0.6 | 93.3 | -0.5 |
| w/o Dynamic (SVD) | 87.7 | -2.1 | 92.1 | -1.7 |

消融实验显示，移除静态修正导致 0.6% 的性能下降，验证了残差中任务特异性信息的重要性；而将 Tucker 分解替换为独立 SVD 导致 2.1% 的显著下降，证实了联合张量分解在消解干扰上的核心作用。

评估边界方面，论文未报告计算效率的具体数值（如推理延迟），仅定性提及参数效率优势；实验局限于 ViT 骨干和 FFN 层，未验证 Attention 层或 LLM 骨干的适用性；神经元激活掩码依赖特定输入分布，其在分布偏移下的稳定性未做测试。

## 关联研究分析

从方法设计看，DuetMerging 与 Twin-Merging 均使用 SVD/Tucker 分解处理任务向量，但 Twin-Merging 独立分解每个任务矩阵，而 DuetMerging 堆叠后联合分解。这一差异源于对“共享结构”定义的认知不同：Twin-Merging 假设任务特异性知识可通过单任务主成分分离，而 DuetMerging 认为高阶交互需通过核心张量显式建模。若任务间共享结构较弱，联合分解的增益可能递减，论文未提供此类场景的对比数据。

从问题动机看，与 TIES-Merging 等基于参数幅度的稀疏化方法相比，DuetMerging 使用神经元激活作为重要性信号。TIES 依赖幅度假设重要参数具有大权重，而 DuetMerging 依赖功能特化假设重要参数对应高激活神经元。这一选择挑战了幅度启发式的通用性，但激活掩码的生成依赖无标签数据的前向传播，其计算开销及在训练后权重漂移下的鲁棒性，论文未给出定量分析。

## 总结

DuetMerging 旨在解决动态合并中专家池孤立构建导致的结构冲突残留问题。其切入点在于利用 Tucker 分解提取跨任务共享核心结构，并结合神经元功能特化修正低秩近似损失。该方法通过联合张量分解与激活掩码协同，在 ViT-B/32 上实现了 99.2% 的归一化准确率，接近单任务专家上限。然而，其方法局限于 FFN 层且依赖特定输入分布下的激活模式，当骨干网络扩展至 Attention 层或输入分布发生偏移时，激活掩码的有效性是否依然成立，论文未给出回答。
