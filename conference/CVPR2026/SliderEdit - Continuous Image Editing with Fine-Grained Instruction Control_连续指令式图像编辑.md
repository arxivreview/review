# CVPR2026最新论文 ｜SliderEdit: Continuous Image Editing with Fine-Grained Instruction Control ｜连续指令式图像编辑

研究机构：Adobe研究院

作者：Arman Zarei、Samyadeep Basu、Mobina Pournemat 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.09715)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.09715)

> 指令式图像编辑（IBIE）旨在通过自然语言指令对图像进行精确、可控的视觉修改，但现有模型将每条指令视为“全有或全无”的离散操作，无法独立调节单条指令的视觉强度。这种离散性限制了用户在多指令场景下的交互灵活性与可解释性。SliderEdit 通过识别多模态扩散 Transformer（MMDiT）中局部化的指令 Token 嵌入，训练轻量级低秩适配器实现指令强度的连续解耦控制。该框架以极低的训练成本实现了细粒度编辑，但其在通用编辑质量基准上的表现及复杂指令下的泛化能力仍存疑。

## 研究背景

多模态扩散 Transformer（MMDiT）通过双分支结构处理图像潜码与文本嵌入，其交叉注意力层实现了跨模态信息交换。在 MMDiT 中，文本提示经 T5 编码器转化为 Token 嵌入，这些嵌入在生成过程中携带语义信号。理解这些 Token 嵌入如何具体影响图像生成，是实现细粒度控制的前提。

指令式图像编辑的主流路线依赖扩散模型微调或强化学习对齐，以建立文本到像素的映射或优化编辑质量。然而，这些方法将多指令提示视为整体，生成单一固定结果，缺乏对单条指令强度的独立调节能力。例如，用户无法在“皮肤变金”与“喷火”之间分别调整强度，只能依赖多次随机生成获取不同变体。这种离散性阻碍了交互式编辑中“抑制-应用-放大”的连续控制需求。

SliderEdit 的切入点在于发现 MMDiT 中指令语义编码于局部化的 Token 嵌入中，通过选择性调制这些嵌入即可实现指令强度的连续控制。这一发现绕过了全模型微调或强化学习的高昂成本，为轻量级、可解释的编辑控制提供了新路径。

## 核心方法

### 方法参照系

连续属性控制通常通过训练每属性 LoRA 或语义嵌入方向实现，但需为每个属性单独训练，且易受属性纠缠影响。SliderEdit 的问题在于将滑块控制迁移至真实图像编辑，并解决多指令场景下的解耦与泛化问题，其关键差异在于使用单一适配器集合处理多样指令，而非每属性独立训练。

### 指令 Token 局部性验证

在 MMDiT 的注意力层中，目标指令 $P_{target}$ 对应的 Token 嵌入 $\{y_u, y_{u+1}, \dots, y_{u'}\}$ 携带编辑语义信号。通过线性插值这些嵌入与填充 Token 嵌入 $y_{\langle pad \rangle}$，可测试其影响是否局部化：

$$y_j^{[\ell]} \leftarrow (1 - \beta) \cdot y_j^{[\ell]} + \beta \cdot y_{\langle pad \rangle}^{[\ell]}, \quad j \in \{u, \dots, u'\}$$

其中 $\beta \in [0, 1]$ 控制指令信息保留比例。$\beta=1$ 时指令被完全移除，$\beta=0$ 时指令完整保留。实验表明，中间 $\beta$ 值产生部分编辑效果，证明指令语义确实编码于局部 Token 嵌入中，为选择性调制提供了基础。

### 部分提示抑制损失与选择性 LoRA

为训练连续控制适配器，SliderEdit 提出部分提示抑制（PPS）损失。给定完整提示 $P$ 和待抑制指令 $P_i$，PPS 要求适配模型 $\epsilon_{M_\theta}(P_i)$ 在完整提示下的去噪方向 $\hat{v}$ 与移除 $P_i$ 后的基线模型输出 $v^*$ 一致：

$$\mathcal{L}_{PPS} = \|\hat{v} - v^*\|_2$$

该损失迫使适配器中和 $P_i$ 对应 Token 的视觉影响，同时保持其他指令不变。适配器实例化为选择性 Token LoRA（STLoRA），仅对目标指令 Token 应用低秩更新 $\Delta W^{[\ell]} = B^{[\ell]} A^{[\ell]}$，非目标 Token 保持原始投影。训练后，通过缩放参数 $\alpha$ 调节 LoRA 权重，实现从完全抑制（$\alpha=1$）到完全应用（$\alpha=0$）乃至放大（$\alpha<0$）的连续控制。对于单指令场景，全局选择性 Token LoRA（GSTLoRA）将适配器应用于所有图像和文本 Token，利用全局上下文提升编辑保真度。

## 实验评估

实验基于自建面部编辑基准，包含多样性别、年龄、种族主体及多个编辑方向，通过 $\gamma$ 维编辑空间（$\gamma \in \{1,2,3\}$）和 $\delta$ 步强度变化评估连续性、外推性和解耦性。基线包括显式/隐式分类器自由引导（CFG），但缺失强化学习后训练方法（如 Edit-GRPO）和空间感知奖励方法（如 CoCoEdit），导致无法与领域 SOTA 直接对比。

| 模型 | Extrap.Avg ↑ | Cont.Avg ↑ | Dis.Avg ↓ |
| :--- | :--- | :--- | :--- |
| FLUX-Kontext (STLoRA) | 0.2776 | 0.2409 | 0.2509 |
| Qwen-Image-Edit (STLoRA) | 0.3160 | 0.2813 | 0.3088 |
| FLUX-Kontext (GSTLoRA) | 0.2970 | 0.3691 | 0.2762 |
| Qwen-Image-Edit (GSTLoRA) | 0.3417 | 0.4345 | 0.3630 |

GSTLoRA 在连续性上显著优于 STLoRA（FLUX 从 0.2409 升至 0.2970，Qwen 从 0.2813 升至 0.3417），表明全局 Token 调制对单指令编辑更优。但 Qwen 在解耦性上表现较差（Dis.Avg 0.3630 vs FLUX 0.2762），暗示不同骨干网络对指令解耦的敏感性存在差异。

评估边界受限于自建基准，未报告 GEdit-Bench 等通用编辑质量指标，无法验证连续控制是否以牺牲整体编辑质量为代价。训练使用 1k-8k 样本和 1000 次迭代，计算成本低，但超参数（如 LoRA 秩 16）的敏感性未充分探讨。代码未公开，可复现性依赖项目页面提供的有限信息。

## 关联研究分析

从问题动机看，SliderEdit 与 Concept Sliders 同属连续属性控制，但后者针对文生图且需每属性训练 LoRA，而 SliderEdit 通过 PPS 损失实现单一适配器泛化至多样编辑指令。这一差异源于任务特性：图像编辑需保持非编辑区域一致性，而文生图无此约束。PPS 损失通过抑制特定指令 Token 实现解耦，避免了属性纠缠，但其有效性依赖于 MMDiT 中 Token 嵌入的局部性假设，该假设在其他架构中是否成立未经验证。

从方法设计看，SliderEdit 与 MIRA 等推理规划框架形成互补：MIRA 通过迭代推理处理复杂指令的组合逻辑，而 SliderEdit 通过单次前向传播的 Token 调制实现强度控制。两者未结合，暗示连续控制与复杂推理可能存在张力——PPS 损失是否足以处理多指令间的非线性交互（如“变金”与“喷火”的光影冲突），论文未给出回答。

## 总结

SliderEdit 解决的核心矛盾是离散编辑与连续控制需求之间的冲突，其切入点在于发现 MMDiT 中指令语义的局部化编码，通过 PPS 损失训练轻量级 LoRA 适配器实现指令强度的解耦调制。实验表明 GSTLoRA 在连续性上优于 STLoRA（FLUX 0.2970 vs 0.2409），但解耦性在 Qwen 上表现较差（0.3630 vs 0.2762）。该方法的边界在于未验证通用编辑质量，且 PPS 损失对复杂指令交互的处理能力存疑。当指令间存在物理或语义冲突时，连续滑块控制是否仍能保持视觉合理性，论文未提供证据。
