# CVPR2026最新论文 ｜DocSeeker: Structured Visual Reasoning with Evidence Grounding for Long Document Understanding ｜基于结构化视觉推理与证据接地的长文档理解

研究机构：华中科技大学

作者：Hao Yan、Yuliang Liu、Xingchen Liu 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.12812)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.12812)

> 多页文档视觉问答面临长序列输入下关键证据被无关内容淹没的低信噪比困境，以及现有数据集仅提供短答案导致的监督信号稀疏问题。传统纯视觉端到端模型在长文档上性能急剧衰减，而外部检索增强生成方法又陷入检索数量与噪声的权衡。DocSeeker 通过引入“分析-定位-推理”结构化思维范式与证据引导的分辨率分配策略，在单模型内部实现了隐式证据定位与显式推理的耦合。该方法在开源模型中实现了显著的长文档泛化增益，但其绝对精度仍落后于最新的多智能体框架，且推理延迟与超长文档下的定位稳定性尚存疑。

## 研究背景

多页文档视觉问答要求模型在数百页高分辨率图像中定位稀疏证据并执行跨页推理。这一任务的核心障碍在于视觉Token序列的指数级增长导致的关键信息稀释，即低信噪比问题。同时，现有训练数据多采用“长序列输入-短答案输出”的范式，缺乏中间推理步骤的标注，迫使模型通过记忆捷径而非真正的视觉定位能力来拟合答案，导致其在分布外文档上的泛化能力脆弱。

长文档理解的主流路线分为外部检索增强与端到端处理两类。检索增强方法依赖外部视觉检索器预筛选页面，但面临Top-K选择的两难：K值过大引入噪声，过小则遗漏证据。端到端方法虽避免了模块间误差累积，但在处理超长文档时受限于上下文窗口与计算资源，性能随文档长度增加而显著下降。DocSeeker的切入点在于不依赖外部检索器，而是通过结构化思维范式将证据定位内化为模型推理过程的一部分，同时通过训练时的分辨率动态分配解决长序列训练的记忆瓶颈。

## 核心方法

### 方法参照系

本文基于Qwen-2.5-VL-7B-Instruct骨干，属于纯视觉端到端长文档理解路线。与标准流程直接映射图像到文本不同，本文在输入与输出之间插入了显式的页码感知机制与结构化思维链，将隐式的注意力分配转化为显式的证据定位动作。

### 页码感知输入与ALR结构化推理

设计动机在于解决长序列中视觉Token归属模糊导致的证据定位失效。传统方法将多页图像拼接为单一序列，模型难以区分Token来源。本文通过交错文本页码标识与视觉Token构建页码感知输入表示，使每个视觉Token锚定到特定页面。在此基础上，强制模型输出遵循“分析-定位-推理”（ALR）范式的结构化思维链，其中定位步骤必须显式引用页码，推理步骤基于定位证据展开。该机制将证据定位从隐式注意力转化为显式文本输出，提升了可解释性并强化了模型对页面边界的感知。

$$
\mathbf{X} = \mathbf{e}_Q \oplus \bigoplus_{i=1}^{N} (\mathbf{e}_i \oplus \mathbf{v}_i)
$$

该公式定义了输入序列构造，其中 $\mathbf{e}_i$ 为页码文本嵌入，$\mathbf{v}_i$ 为第 $i$ 页视觉Token，$\oplus$ 表示序列拼接。页码嵌入作为指针，使模型在解码时能明确引用特定页面作为证据来源。

### 两阶段训练与证据引导分辨率分配

设计动机在于解决监督信号稀疏与长序列训练内存溢出问题。第一阶段通过知识蒸馏生成高质量ALR思维链数据，利用Gemini-2.5-Flash仅基于证据页与少量干扰页生成完整推理路径，经双重验证后用于监督微调，使模型习得ALR范式。第二阶段引入证据感知组相对策略优化（EviGRPO），通过联合优化格式、证据定位与答案准确性的多维权度奖励，超越模仿学习的次优解。为支持长文档训练，提出证据引导分辨率分配（EGRA）策略：证据页保持1024分辨率以保留细节，非证据页随机70%降至256分辨率，30%保持原分辨率。该策略在降低总Token数的同时，通过引入高分辨率干扰项增强模型鲁棒性，平衡了记忆约束与监督信号强度。

$$
R = \lambda_1 R_{\text{format}} + \lambda_2 R_{\text{evidence}} + \lambda_3 R_{\text{answer}}
$$

该公式定义了EviGRPO的总奖励函数，其中 $R_{\text{evidence}}$ 采用加权F1分数（$\beta=2.0$）优先召回证据页，$R_{\text{answer}}$ 采用ANLS指标评估答案准确性。多维权度奖励引导模型同时优化定位与推理能力，避免单一答案奖励导致的定位信号缺失。

## 实验评估

实验在DUDE、MP-DocVQA、MMLongBench-doc、LongDocURL及SlideVQA五个基准上进行，基线覆盖端到端MLLM（InternVL3）、解析式方法（CREAM）及检索增强方法（Vis-RAG），但缺失DocLens、DocMemo等最新多智能体框架对比。

| 方法 | DUDE (ANLS) | MP-DocVQA (ANLS) | MMLongBench-doc (Acc) | LongDocURL (Acc) | SlideVQA (F1) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| InternVL3 | 47.4 | 80.8 | 24.1 | 38.7 | 54.4 |
| Vis-RAG | - | 70.9 | 18.8 | 41.9 | 50.7 |
| Baseline | 35.2 | 70.1 | 25.4 | 37.8 | 59.8 |
| DocSeeker | 57.4 | 86.2 | 40.1 | 51.7 | 77.1 |

DocSeeker在MMLongBench-doc上达到40.1%准确率，较同架构基线提升14.7个百分点，但低于GPT-4o的42.8%。在SlideVQA上取得77.1% F1，显著优于所有开源基线。

| 消融配置 | MMLongBench-doc (Acc) | MMLongBench-doc (F1) |
| :--- | :--- | :--- |
| Baseline | 25.4 | 20.8 |
| Raw short-answer data | 27.4 | 27.6 |
| Vanilla CoT | 31.3 | 32.4 |
| ALR CoT data | 33.8 | 33.9 |
| ALR CoT -w/o Page id | 30.4 | 31.1 |
| EGRA Full | 38.6 | 36.9 |
| EGRA -w/o Low-Res | 34.5 | 33.4 |
| EviGRPO (0.1, 0.3, 0.6) | 40.1 | 38.4 |

消融显示，ALR CoT数据较Vanilla CoT提升2.5个百分点，移除页码标识导致性能下降3.4个百分点，证实页码感知对定位的关键作用。EGRA策略中，保留低分辨率非证据页优于直接移除，提升4.1个百分点，表明低分辨率干扰项有助于模型学习区分证据与非证据。EviGRPO中，证据奖励权重设为0.3时性能最优，权重过高导致模型过度关注定位而忽视答案准确性。

评估指标涵盖ANLS、Accuracy及F1，但未报告推理延迟与吞吐量。训练使用16块NVIDIA A800 GPU，SFT与RL阶段学习率均为 $1 \times 10^{-6}$，超参数公开。代码已开源，但EGRA策略在推理阶段需全分辨率处理，实际部署时的计算开销未量化。

## 关联研究分析

从问题动机看，DocSeeker与Vis-RAG等检索增强方法均旨在解决长文档证据稀疏问题，但路径截然不同。Vis-RAG依赖外部检索器预筛选页面，面临Top-K噪声权衡；DocSeeker通过内部ALR范式实现隐式定位，将检索与推理耦合于单模型内。这一差异源于对“定位”本质的不同理解：前者视为独立的前置过滤步骤，后者视为推理过程的内在组成部分。DocSeeker的实验证明其定位能力与视觉RAG系统天然协同，但其在超长文档（>100页）中是否会出现定位漂移，从而挑战外部检索更稳健的共识，论文未给出回答。

从方法设计看，DocSeeker与DocLens等多智能体框架同属长文档理解路线，但DocLens依赖外部工具调用与多轮交互，DocSeeker依赖内部结构化思维链。DocLens通过“镜头”式导航逐步聚焦，推理延迟较高但可解释性强；DocSeeker通过单次前向推理生成完整思维链，效率更高但受限于上下文窗口。两者代表了“外部代理”与“内部推理”两条竞争路线，DocSeeker的优势在于无需额外工具调用，但其在证据定位准确性上是否优于多轮交互的精细控制，缺乏直接对比实验。

## 总结

DocSeeker针对长文档理解中低信噪比与监督稀缺的核心矛盾，通过ALR结构化范式与EGRA分辨率策略，在单模型内部实现了证据定位与推理的耦合。该方法在MMLongBench-doc上较基线提升14.7个百分点，在SlideVQA上达到77.1% F1，证明了结构化思维链对长文档泛化的增益。然而，其绝对精度仍低于GPT-4o，且未与最新多智能体框架对比，暴露了内部推理在超长文档下的潜在局限。当文档长度超过训练分布的20页上限时，ALR范式的定位稳定性是否随序列长度增加而衰减，论文未给出回答。
