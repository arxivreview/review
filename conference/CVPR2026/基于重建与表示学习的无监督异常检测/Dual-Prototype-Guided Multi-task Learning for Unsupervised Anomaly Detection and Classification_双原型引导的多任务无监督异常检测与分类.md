# CVPR2026最新论文 ｜Dual-Prototype-Guided Multi-task Learning for Unsupervised Anomaly Detection and Classification ｜双原型引导的多任务无监督异常检测与分类

作者：Qianhao Luo、Jiajia Mi、Mingtao Yan 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_0fd21e88618f)

> 工业质检与医疗诊断中，异常区域定位与异常类型识别常被视为两个独立任务，但不同缺陷类型在局部视觉模式上高度相似，导致单独训练的定位模型难以提供清晰的分类边界，而单独训练的分类器又因缺乏全局正常模式先验而陷入局部视觉歧义（Local Visual Ambiguity, LVA）。现有两阶段流水线割裂了特征传递，直接应用多任务学习（Multi-Task Learning, MTL）又因定位依赖细节、分类依赖语义而产生特征冲突。本文提出PG-SFD框架，通过显式构建正常与异常双原型解耦语义，并引入门控交互与几何正则化协同优化两个任务。该框架在MVTec-AD上实现了99.4%的图像级AUROC与61.6%的分类F1，但在像素级定位精度上略低于纯无监督SOTA，其弱监督设定是否完全符合无监督异常检测的严格定义仍存疑。

## 研究背景

工业场景中的缺陷往往具有细粒度特征，例如钢板上的粘钢与导向板标记在局部纹理上几乎无法区分。这种局部视觉歧义（LVA）使得仅依赖正常样本训练的无监督异常检测（Unsupervised Anomaly Detection, UAD）模型在定位异常区域时，无法为后续分类提供足够的语义区分度。同时，异常分类任务若仅依赖UAD裁剪出的局部视图，会丢失全局上下文信息，导致分类器在相似缺陷间产生混淆。解决这一矛盾的关键在于建立一种机制，既能保留定位所需的局部细节，又能注入分类所需的全局语义先验。

主流UAD方法如PatchCore和INPformer通过预训练特征提取与记忆库或重构误差实现高精度定位，但它们本质上是单任务框架，缺乏对异常类别的语义建模能力。现有的弱监督分类方法多采用“先定位后分类”的两阶段范式，这种串行处理导致UAD阶段积累的正常模式知识无法有效传递给分类器，且裁剪操作切断了局部异常与全局背景的关联。直接应用MTL框架虽能共享特征，但UAD对中层细节特征的依赖与分类对高层语义特征的偏好存在根本性冲突，导致梯度方向相反，相互干扰。PG-SFD的切入点在于将这种隐式的特征共享转变为显式的特征解耦，通过原型机制明确区分正常与异常语义，从而在统一框架内协同优化定位与分类。

## 核心方法

### 方法参照系

本文问题可置于基于预训练视觉Transformer（ViT）的特征重构与分类联合优化框架下。标准流程通常使用冻结或微调的ViT提取多尺度特征，通过重构头进行异常定位，通过分类头进行类别预测。本文的关键差异在于，它不依赖隐式的共享特征空间，而是显式构建正常原型与异常原型，并通过几何约束强制特征空间解耦，以解决MTL中的特征冲突。

### 双原型表示模块

双原型表示模块（Dual-Prototype Representation Module, DPRM）旨在解决正常与异常语义在特征空间中的纠缠问题。通常做法是直接使用重构误差或全局平均池化特征，但DPRM通过动量更新机制显式构建正常原型 $p_a$ 和类别原型 $p_c$。正常原型 $p_a$ 由重构误差最大的特征块更新，公式为：

$$ p_a \leftarrow p_a + (1 - m) \cdot \text{Mean}(\{f_{patch} \mid E_{patch} > \theta\}) $$

其中 $m$ 为动量系数，$\theta$ 为误差阈值。这一设计使得 $p_a$ 能够捕捉异常区域的偏差模式，而类别原型 $p_c$ 则由图像级标签监督，通过余弦相似度计算分类得分。DPRM通过显式解耦，避免了分类任务对定位特征的干扰，使得模型在定位时能聚焦于偏离正常原型的区域，在分类时能利用类别原型的语义区分度。

### 差分门控交互与几何正则化

差分门控交互（Differential Gated Interaction, DGI）与几何正则化优化（Geometry-Regularized Optimization, GRO）进一步解决了跨任务特征注入与梯度冲突问题。DGI通过计算正常原型 $\hat{p}_a$ 与高层特征 $F'_{high}$ 的差分响应 $\Delta F$ 实现自适应融合：

$$ \Delta F = \sigma(\text{MLP}(\hat{p}_a - F'_{high}(x))) $$

当输入为正常样本时，$\Delta F$ 趋近于0.5，实现平衡融合；当输入为异常样本时，$\Delta F$ 趋近于1，保留细节特征。GRO则通过原型分离损失 $L_{sep}$ 和任务一致性损失 $L_{cons}$ 强制特征空间解耦：

$$ L_{sep} = \sum_{c=1}^{C} \sum_{k=1}^{K} \exp(-\tau \cdot (1 - \cos(p_c^n - p_a^k))) $$

该损失项最大化正常原型与异常原型之间的余弦距离，确保正常区域特征向类别原型聚类，异常区域特征远离正常原型。GRO通过几何约束主动构建解耦结构，缓解了MTL中因特征偏好不同导致的梯度冲突，使得模型在保持定位精度的同时提升分类性能。

## 实验评估

| 方法 | 训练协议 | I-AUROC | P-AUPRO | Cls-F1 |
| :--- | :--- | :--- | :--- | :--- |
| INPformer | Normal only | 99.3 | 96.0 | N/A |
| Dinomaly | Normal only | 99.1 | 95.7 | N/A |
| Two-Stage* | Normal + Img label | - | - | 48.5 |
| PG-SFD(ours) | Normal + Img label | 99.4 | 95.6 | 61.6 |

PG-SFD在MVTec-AD上实现了99.4%的图像级AUROC，略高于INPformer的99.3%，但像素级AUPRO为95.6%，低于INPformer的96.0%。在分类任务上，PG-SFD的Cls-F1达到61.6%，显著高于两阶段方法的48.5%和AnomalyCLIP的N/A（未报告分类指标，仅报告检测指标）。基线覆盖包括纯无监督方法（INPformer, Dinomaly）和弱监督方法（Two-Stage, AnomalyCLIP），但缺乏与生成式方法（如InvAD）在分类任务上的直接对比，且未报告置信区间。

| 变体 | I-AUROC | P-AUPRO | Cls-F1 |
| :--- | :--- | :--- | :--- |
| Baseline | 92.7 | 20.5 | 40.5 |
| V1 (DPRM) | 94.0 | 94.5 | 53.0 |
| V2 (DPRM+DGI) | 93.8 | 94.1 | 57.3 |
| V3 (Full) | 99.4 | 95.6 | 61.6 |

消融实验显示，引入DPRM后P-AUPRO从20.5%提升至94.5%，表明DPRM有效解决了特征冲突导致的定位失效。加入DGI后Cls-F1提升4.3%，验证了门控机制在跨任务语义引导中的作用。最终加入GRO后，I-AUROC提升至99.4%，Cls-F1达到61.6%，表明几何正则化在平衡定位与分类性能方面至关重要。

实验在MVTec-AD、VisA、Uni-Medical和IHSP上进行，使用DINOv2 ViT-Small作为骨干，输入尺寸448×448，训练200 epochs。代码已开源，但论文未报告计算效率指标（如FPS或GFLOPs），且未提供不同超参数（如原型维度K）的敏感性分析细节，仅提及K=6表现最佳。评估协议中，异常样本按2:8比例划分训练与测试集，这一设定可能影响分类任务的泛化能力评估。

## 关联研究分析

从问题动机看，PG-SFD与INPformer等纯UAD方法的核心差异在于是否引入弱监督分类任务。INPformer专注于像素级定位，通过重构误差实现高精度，但缺乏语义区分能力。PG-SFD通过引入图像级标签，将任务扩展至异常分类，解决了LVA问题。然而，这种扩展依赖于图像级标签的可用性，而纯UAD场景下标签不可得，因此PG-SFD的适用性受限于弱监督设定。从方法设计看，PG-SFD与AnomalyCLIP等弱监督方法不同，后者依赖文本-图像对齐实现零样本分类，而PG-SFD通过双原型机制实现端到端联合优化。AnomalyCLIP在MVTec-AD上的I-AUROC为94.6%，低于PG-SFD的99.4%，表明PG-SFD在检测精度上更具优势，但AnomalyCLIP的零样本能力是其独特优势，PG-SFD未探索这一方向。

## 总结

PG-SFD旨在解决UAD与异常分类任务间的特征冲突与局部视觉歧义问题。通过显式构建正常与异常双原型，并引入差分门控交互与几何正则化，该框架在统一架构内实现了定位与分类的协同优化。实验表明，PG-SFD在MVTec-AD上达到99.4%的I-AUROC和61.6%的Cls-F1，优于两阶段方法，但像素级AUPRO略低于纯UADA SOTA。其边界在于依赖图像级弱监督标签，且未验证在完全无监督或零样本场景下的泛化能力。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
