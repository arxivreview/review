# CVPR2026最新论文 ｜Tackling Model Bias via Game-theoretic Multi-agent Collaboration Framework for Hateful Meme Classification ｜博弈论多智能体协作框架

研究机构：天津大学、美团

作者：Yiwei Wei、Zhengliang Guo、Shaozu Yuan 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_b2fc36f2cf1f)

> 多模态仇恨表情包检测的核心难点在于单一大型多模态模型（LMMs）因训练数据偏差产生的认知偏见，导致在图文语义错位时误判。现有投票或辩论式多智能体方法无法解决多数模型共享偏见的问题，GECO 切入这一盲区，将多模型协作建模为博弈过程，通过混合奖励机制引导系统收敛至纳什均衡。该框架在五个基准上刷新了性能上限，但其对计算资源的依赖及缺乏显式解释生成的特性，使其在实际部署中仍面临成本与可追溯性的双重挑战。

## 研究背景

当多个 LMMs 面对同一仇恨表情包时，若多数模型因训练偏差产生相同误判，传统的投票机制会放大错误，而辩论机制则依赖裁判模型的公平性，易被偏见引导。这种“模型间偏见”（inter-model bias）是现有集成策略的失效根源，而博弈论中的纳什均衡概念提供了一种通过策略优化而非规则聚合来消除偏见的数学框架。

仇恨表情包检测已从单模态特征融合演进至基于 LMMs 的生成式推理阶段。早期方法如 Mod-Hate 采用投票聚合，ExplainHM 引入辩论机制，但二者均假设模型偏见是独立且可被简单规则纠正的。然而，实验表明当偏见具有系统性时，这些方法失效。GECO 的切入点在于将多智能体协作视为一个非合作博弈，通过设计包含个体正确性与集体一致性的混合奖励函数，使各智能体在策略空间中相互制约，从而在数学上保证收敛至正确标签的均衡状态。

## 核心方法

### 多智能体博弈参照系

多智能体仇恨检测的通用流程是调用多个 LMMs 生成预测，再通过投票或辩论聚合结果。GECO 的关键差异在于摒弃了静态聚合规则，转而将每个 LMM 视为博弈中的玩家，其输出不再是最终标签，而是策略空间中的概率分布，通过动态优化策略实现集体决策。

### 混合奖励机制

传统博弈论仅关注个体收益，GECO 在奖励函数中引入集体一致性约束，以解决模型间偏见导致的共识缺失。对于智能体 $i$ 在联合行动 $a$ 下的奖励 $u_i(a)$，定义为：

$$
u_i(a) = \alpha \cdot I(a_i = y_k) + \lambda \sum_{j \in V \setminus \{i\}} I(a_i = y_k) I(a_j = y_k) + \beta \cdot I(\forall j \in V, a_j = y_k)
$$

其中 $\alpha, \lambda, \beta$ 分别为个体命中、成对命中和全命中的奖励系数。该公式的物理含义是：智能体不仅因自身预测正确获得奖励，更因与其他智能体共同预测正确而获得额外激励，从而在优化过程中强制模型间形成对正确标签的共识，而非各自为政。

### 正则化纳什优势损失

直接优化期望效用易导致训练不稳定，GECO 引入正则化项以加速收敛至纳什均衡。定义正则化优势向量 $F_i^x$ 为：

$$
F_i^x = -\nabla_{x_i} u_i(x) + \eta \log(x_i)
$$

其中 $\eta$ 为平衡参数。该公式通过梯度下降方向与对数正则项的结合，确保策略更新既指向高收益区域，又避免概率分布过于尖锐。最终损失函数 $L_{RNA}$ 采用停止梯度操作，将优势向量视为常数，简化了反向传播计算，提升了数值稳定性。

## 实验评估

GECO 在 Hateful Meme、PrideMM、MultiOff、HarMeme 和 MAMI 五个基准上与 CLIP-based 和 LMM-based 基线对比。基线覆盖 RGCL、RA-HMD 等主流方法，但缺失 GatedCLIP 等门控融合方法的直接对比。

| 数据集 | 方法 | Accuracy (%) | F1-Score (%) |
| :--- | :--- | :--- | :--- |
| PrideMM | GECO | 82.84 | 82.84 |
| PrideMM | RA-HMD | 78.10 | 78.10 |
| MultiOff | GECO | 78.52 | 77.90 |
| MultiOff | RA-HMD | 71.11 | 70.49 |

GECO 在 PrideMM 上较 RA-HMD 提升 4.74% Accuracy，在 MultiOff 上提升 7.41% Accuracy，验证了博弈论机制在低资源场景下的鲁棒性。

消融实验显示，移除成对命中奖励（$\lambda$）或全命中奖励（$\beta$）均导致性能显著下降，表明集体一致性约束对消除模型间偏见至关重要。参数分析表明，$\beta$ 过大易导致过拟合，$\lambda$ 过小则无法促进有效协作，最优值需通过网格搜索确定。

评估指标包含 Accuracy、F1 和 AUC，但未报告置信区间。代码已开源，超参数如 $\eta=0.35$、$\alpha=1.0$ 等已公开，但缺乏不同 GPU 配置下的计算成本对比，限制了其在实时审核场景中的可复现性评估。

## 关联研究分析

从问题动机看，GECO 与 ExplainHM 均旨在解决多模型偏见，但 ExplainHM 依赖裁判模型的主观判断，而 GECO 通过数学优化保证均衡。这一差异源于对偏见本质的理解不同：ExplainHM 视偏见为可被解释纠正的噪声，GECO 视其为需通过策略博弈消除的系统性偏差。

从方法设计看，GECO 与 Mod-Hate 同属多智能体框架，但 Mod-Hate 采用静态投票，GECO 采用动态策略优化。Mod-Hate 的局限在于无法处理多数偏见，而 GECO 的混合奖励机制通过激励集体正确性，使少数正确模型能引导整体决策。然而，GECO 未探索在模型数量增加时，博弈收敛速度是否线性下降，这一计算复杂度问题在论文中未得到量化分析。

## 总结

GECO 针对多 LMMs 协作中的模型间偏见问题，通过博弈论混合奖励机制实现策略优化，在 PrideMM 和 MultiOff 上分别较基线提升 4.74% 和 7.41% Accuracy。其边界在于计算成本高昂且缺乏显式解释生成，难以满足实时审核与可追溯性需求。当智能体数量从 5 个扩展至 10 个时，纳什均衡的收敛时间与计算资源消耗是否呈指数增长，论文未给出回答。
