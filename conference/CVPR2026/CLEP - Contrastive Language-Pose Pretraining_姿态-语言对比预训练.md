# CVPR2026最新论文 ｜CLEP: Contrastive Language-Pose Pretraining ｜姿态-语言对比预训练

作者：Sen Jia、Huayu Wang、Hsiang-Wei Huang 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_093466ca6e40)

> 姿态-语言对齐旨在建立3D人体姿态与复杂自然语言描述间的共享嵌入空间，以支撑检索、生成与编辑等下游任务。现有方法受限于数据规模不足与姿态表征的扁平化，导致跨域泛化能力薄弱且难以捕捉多尺度语义。本文通过构建200万级数据集CLEP-2M，并设计层级姿态编码器HierFormer，利用SigLIP损失实现姿态与文本的细粒度对齐。该框架在零样本检索上实现了近6倍的基线超越，但其静态姿态假设与时序缺失限制了动态场景的适用性。

## 研究背景

当自然语言描述人体姿态时，其语义跨度从指尖、脚趾等细粒度关节，延伸至躯干、四肢等宏观结构。这种多尺度语义特性要求表征模型同时捕捉局部细节与全局结构，而传统方法将关节坐标扁平化为固定长度向量，丢失了层级依赖关系。为弥补这一缺陷，对比学习范式被引入姿态-语言对齐，但早期工作如PoseScript仅使用10万对数据，且依赖冻结的文本编码器，导致预训练信号稀疏，模型难以学习到鲁棒的跨模态关联。

姿态-语言对齐的核心矛盾在于数据规模与语义多样性的双重匮乏。主流路线分为两类：一类基于大语言模型（LLM）的工具增强方法，如ChatHuman，通过LLM调度多个专家模型处理姿态任务，但引入了累积误差与推理低效；另一类为端到端对比学习，如PoseScript，虽建立了联合嵌入空间，但受限于数据规模，对比目标增益有限。此外，MotionCLIP等尝试将运动映射至CLIP空间，却因图像-文本特征与人体运动学的不匹配而产生语义鸿沟。本文切入点在于从表征机制与数据基础两方面同时突破：设计层级编码器以显式建模多尺度语义，并构建大规模数据集以提供充足的对比学习信号。

## 核心方法

### 对比学习参照系

本文问题属于多模态对比预训练范畴，标准流程为通过InfoNCE损失对齐两个模态的嵌入。关键差异在于姿态模态具有内在的层级结构（关节-肢体-身体），而图像模态通常视为均匀像素网格，因此需要专门的结构化编码器替代扁平化投影。

### 层级姿态编码器（HierFormer）

针对扁平化编码丢失层级依赖的问题，HierFormer将人体分解为关节、肢体、身体三个语义层级。在关节层，每个关键点投影为高维token；肢体层通过1D卷积提取肩-肘-腕等语义分组的局部特征；身体层进一步聚合为手臂、腿、躯干等区域。各层级特征$E_i$通过Transformer块建模序列依赖：

$$E_i = T^{(i)} \left( \{ \text{Conv}(E_{i-1}[G_i(k)]) \}_{k=1}^{K_i} \right)$$

该公式表明，高层级特征由低层级特征经卷积分组与Transformer变换得到，显式保留了从局部到全局的结构信息。

### 跨尺度注意力融合（CSAF）

层级编码产生多尺度特征后，传统加法融合易引入语义不一致。CSAF采用两阶段动态融合：第一阶段通过尺度注意力（SA）让每个尺度$E_i$查询其他尺度$[E_{k \neq i}]$，计算注意力输出$C_i$：

$$C_i = \text{softmax}\left( \frac{(W_Q^i E_i)(W_K^i [E_{k \neq i}])^T}{\sqrt{d_k}} \right) (W_V^i [E_{k \neq i}])$$

随后通过门控残差连接$E'_i = g_i \cdot E_i + (1 - g_i) \cdot C_i$平衡原始特征与跨尺度信息。第二阶段对各尺度全局向量$\bar{E}_i$进行门控加权，最终姿态表示$o = \sum_{i \in \{j,l,b\}} g_i \cdot \bar{E}_i$。该机制使模型能根据输入动态强调最信息丰富的尺度，解决了静态融合无法适应多样姿态的问题。

## 实验评估

实验在PoseScript-A、PoseScript-H及CLEP-2M测试集上评估检索、生成与编辑任务。基线覆盖PoseScript（对比学习）、ChatPose（LLM生成）、ChatHuman（工具增强），但缺失图像域经典CLIP变体及运动域MotionCLIP的直接对比。

| 方法 | PoseScript-H 零样本 mRecall | PoseScript-A 微调 mRecall | CLEP-2M 微调 mRecall |
| :--- | :--- | :--- | :--- |
| PoseScript | 5.9 | 72.8 | 64.98 |
| CLEP | 34.8 | 83.4 | 75.69 |

CLEP在零样本PoseScript-H上以34.8 mRecall大幅超越PoseScript的5.9，验证了跨域泛化能力；微调后在PoseScript-A上提升10.6点，表明预训练表征的适应性。

| 消融组件 | mRecall (CLEP-2M) | 增益 |
| :--- | :--- | :--- |
| 基线 (VPoser + InfoNCE) | 64.98 | - |
| + Hier | 67.90 | +2.9 |
| + CSAF (SA + GatedHead) | 72.79 | +4.9 |
| + SigLIP | 75.69 | +2.9 |

消融显示CSAF贡献最大（+4.9点），验证了动态融合优于静态拼接；SigLIP损失带来+2.9点增益，归因于其消除批量负样本依赖，提升小批量训练稳定性。

评估边界方面，论文未报告置信区间，且CLEP-2M数据规模优势可能掩盖架构贡献——虽在相同数据下CLEP优于PoseScript，但缺乏控制变量实验。可复现性上，训练使用单张H100 GPU，12小时完成预训练，超参数（batch size 1024, lr 0.0001）已公开，但代码未提供。

## 关联研究分析

从问题动机看，CLEP与PoseScript同属姿态-语言对比学习，但前者将数据规模扩大20倍并引入层级编码，后者受限于10万对数据与扁平化表征。这一差异源于任务特性：姿态的多尺度语义结构要求显式层级建模，而图像-文本对齐中CLIP的全局对齐已足够，无需层级分解。CLEP的层级设计是否在其他多模态任务（如视频-文本）中同样必要，论文未给出回答。

从方法设计看，CLEP采用SigLIP损失替代InfoNCE，这与图像域SigLIP（Zhai et al., 2023）一致，但姿态域数据规模较小（200万对 vs 图像域数亿对），SigLIP的小批量稳定性优势更为显著。相比之下，MotionCLIP将运动映射至CLIP空间，却未针对运动学特性设计编码器，导致语义鸿沟。CLEP的层级编码器是否优于通用Transformer在运动序列上的表现，缺乏直接对比。

## 总结

CLEP要解决的核心矛盾是姿态-语言对齐中数据规模与多尺度语义建模的双重缺失。现有方法因数据稀疏与扁平化编码导致泛化能力薄弱，本文凭借200万级数据集与层级编码器HierFormer，通过CSAF动态融合多尺度特征，实现了零样本检索34.8 mRecall（基线5.9）与微调后83.4 mRecall（基线72.8）的性能。其边界在于仅建模静态3D姿态，未显式处理帧间动态变化，且启发式采样策略可能限制语义丰富度。当支持集包含连续运动序列时，层级编码器的时序扩展性是否足以捕捉动态语义，论文未给出回答。
