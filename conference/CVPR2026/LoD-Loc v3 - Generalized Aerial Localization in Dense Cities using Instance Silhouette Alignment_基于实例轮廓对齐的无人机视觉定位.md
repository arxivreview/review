# CVPR2026最新论文 ｜LoD-Loc v3: Generalized Aerial Localization in Dense Cities using Instance Silhouette Alignment ｜基于实例轮廓对齐的无人机视觉定位

研究机构：国防科技大学、西北工业大学

作者：Shuaibang Peng、Juelin Zhu、Xia Li 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.19609)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.19609)

> 无人机在密集城市环境中利用低细节城市模型进行视觉定位时，常因建筑轮廓语义歧义导致定位完全失效，且现有方法难以跨场景泛化。LoD-Loc v3 通过构建大规模合成数据集解决泛化问题，并将定位范式从语义轮廓对齐转变为实例轮廓对齐以消除歧义。该方法在密集场景下实现了比现有最优方法高出 2000% 的定位精度，但其依赖重型视觉基础模型，在机载实时部署上存在显著算力瓶颈。

## 研究背景

无人机视觉定位旨在通过匹配视觉输入与地理参考地图来估计相机位姿，是自主导航的核心技术。传统高精度定位依赖运动恢复结构（SfM）点云或摄影测量网格，但这些高保真模型构建与维护成本高昂，且数据量大引发隐私顾虑。低细节（LoD）城市模型作为替代方案，遵循 CityGML 标准，仅关注建筑几何结构，已在多国实现全国级覆盖，具备支持全球无人机导航的潜力。

早期 LoD 定位方法如 LoD-Loc 通过对齐高细节模型的线框实现定位，而 LoD-Loc v2 将其扩展至更通用的低细节 LoD1 模型，通过对齐建筑语义轮廓进行位姿估计。然而，LoD-Loc v2 存在两个致命缺陷：一是训练数据有限导致跨场景泛化能力差；二是在密集城市环境中，多栋建筑的语义轮廓合并为单一掩码，导致对齐成本函数出现严重歧义，定位完全失败。LoD-Loc v3 针对这两个问题，提出基于实例轮廓对齐的新范式，并构建了大规模合成数据集以增强模型泛化性。

## 核心方法

### 粗到细位姿搜索框架

本文继承 LoD-Loc v2 的粗到细定位框架，将 4-DoF 位姿估计问题转化为轮廓对齐优化问题。给定 LoD 模型 $M$、查询图像 $I_q$ 及其先验位姿 $\xi_q^p$，目标是最小化渲染轮廓 $M_{hyp}$ 与预测图像轮廓 $M_q$ 之间的差异。粗阶段通过均匀采样 4-DoF 搜索空间 $(x, y, z, \theta)$ 最大化对齐成本 $c$ 获得初始位姿 $\xi_q^c$；细阶段使用粒子滤波迭代优化，最终收敛至精确位姿 $\xi_q^*$。该框架的核心在于定义对齐成本函数，本文将其从语义 IoU 替换为实例 Dice 系数加权求和，以解决密集场景下的歧义问题。

### LoD 模型实例化与实例分割

为解决语义轮廓歧义，本文首先对 LoD 模型进行实例化预处理。将无纹理模型 $M$ 解析为图 $G=(V, E, F)$，每栋建筑 $B_i$ 构成一个连通分量，通过拓扑结构分析为每栋建筑分配唯一的 24 位整数 ID 并映射为 RGB 颜色，生成实例化模型 $M_{ins}$。随后，利用在 InsLoD-Loc 数据集上微调的 SAM 模型提取查询图像中的建筑实例轮廓。SAM 编码器提取图像嵌入 $F_{embed}$，可学习的 Prompter 模块预测提示嵌入，SAM 解码器生成实例掩码集合 $S_q = \{M_q^j\}_{j=1}^N$。这一设计将定位问题转化为实例对齐过程，避免了语义合并导致的几何约束丢失。

### 实例轮廓对齐成本函数

本文提出基于实例轮廓的对齐成本函数 $c_{ins}$，用于评估任意位姿假设 $\xi_{hyp}$。对于每个假设，通过 OSG 实时渲染实例化模型 $M_{ins}$ 获得实例掩码集合 $S_{hyp} = \{M_{hyp}^k\}_{k=1}^K$。采用非对称匹配策略，对每个预测实例 $M_q^j$，在 $S_{hyp}$ 中寻找最佳匹配（最高 Dice 系数）$d_j^*$：

$$ d_j^* = \max_{k} \frac{2 \sum_p M_q^j(p) M_{hyp}^k(p)}{\sum_p M_q^j(p) + \sum_p M_{hyp}^k(p) + \epsilon} $$

最终成本 $c_{ins}$ 为 $d_j^*$ 的加权和，权重 $w_j$ 可选用实例置信度 $s_j$ 或边界框面积 $A_j$。该公式通过逐实例匹配消除了密集建筑轮廓合并带来的歧义，使得在建筑密集区域也能通过独特的实例几何特征实现精确对齐。

## 实验评估

实验在 UAVD4L-LoDv2、Swiss-EPFLv2 和 Tokyo-LoDv3 三个数据集上进行，对比了特征匹配（CAD-Loc）、特征对齐（MC-Loc）和 LoD 对齐（LoD-Loc v1/v2）三类基线。值得注意的是，LoD-Loc v2 在 UAVD4L-LoDv2 和 Swiss-EPFLv2 上是分布内训练的，而 LoD-Loc v3 仅使用合成数据 InsLoD-Loc 训练，体现了其跨域泛化能力。

| 数据集 | 方法 | (2m, 2°) | (3m, 3°) | (5m, 5°) |
| :--- | :--- | :--- | :--- | :--- |
| Swiss-EPFLv2 | LoD-Loc v2 (Full) | 31.40 | 58.53 | 86.30 |
| Swiss-EPFLv2 | LoD-Loc v3 (Full) | 36.90 | 64.10 | 88.90 |
| Tokyo-LoDv3 | LoD-Loc v2 (Full) | 2.30 | 6.80 | 24.00 |
| Tokyo-LoDv3 | LoD-Loc v3 (Full) | 50.30 | 79.90 | 97.30 |

在 Swiss-EPFLv2 上，LoD-Loc v3 在 (2m, 2°) 精度上比分布内训练的 LoD-Loc v2 高出 5.5 个百分点，验证了合成数据的有效性。在密集场景 Tokyo-LoDv3 上，LoD-Loc v3 的 (2m, 2°) 精度达到 50.30%，而 LoD-Loc v2 仅为 2.30%，提升了 2000%，证实了实例对齐在解决歧义方面的关键作用。

消融实验表明，将实例掩码强制合并为语义掩码后，Tokyo-LoDv3 上的 (2m, 2°) 精度从 50.30% 降至 38.10%，证明实例对齐机制对密集场景性能至关重要。此外，在 InsLoD-Loc 上重新训练的 LoD-Loc v2 语义模型仍显著低于 LoD-Loc v3，说明性能提升源于范式转变而非单纯数据规模扩大。

评估指标采用标准的 (2m, 2°)、(3m, 3°)、(5m, 5°) 定位精度阈值。代码与项目页面已公开，但论文未报告推理延迟或内存占用，鉴于其使用 SAM ViT-Huge 骨干，机载实时部署的可行性存疑。合成数据与真实 LoD 模型间的域差距未量化，可能影响实际部署性能。

## 关联研究分析

从问题动机看，LoD-Loc v3 与基于 SfM 点云的高保真定位方法（如 CAD-Loc）形成鲜明对比。CAD-Loc 依赖密集特征匹配，在 LoD 模型缺乏纹理细节时完全失效（实验中精度为 0），而 LoD-Loc v3 利用几何轮廓对齐，无需纹理信息。这一差异源于任务特性：LoD 模型仅提供建筑几何，无法提供局部特征点，因此必须依赖全局轮廓结构。LoD-Loc v3 通过实例化将全局轮廓分解为局部实例，弥补了纹理缺失带来的特征稀疏问题。

从方法设计看，LoD-Loc v3 与基于语义分割的 LoD-Loc v2 共享粗到细框架，但核心匹配对象不同。LoD-Loc v2 使用语义轮廓 IoU，在密集场景下因多建筑轮廓合并导致成本函数多峰，粒子滤波易陷入局部最优。LoD-Loc v3 使用实例 Dice 系数，每个建筑独立匹配，成本函数更平滑且全局最优解唯一。这一设计选择解决了语义分割在密集环境下的固有歧义，但引入了实例分割模型的依赖。SAM 的零样本能力被用于建筑轮廓提取，但其参数量大，与无人机边缘计算约束冲突，这是该方法在实际部署中的主要障碍。

## 总结

LoD-Loc v3 解决了密集城市环境中 LoD 模型定位的语义歧义与跨场景泛化难题。通过构建 10 万张合成图像数据集 InsLoD-Loc 和实例轮廓对齐范式，该方法在 Tokyo-LoDv3 密集场景上实现了 50.30% 的 (2m, 2°) 定位精度，比前代方法提升 2000%。其边界在于依赖 SAM ViT-Huge 重型骨干，未提供机载实时性数据，且合成数据与真实 LoD 模型的域差距未量化。当 LoD 模型精度不足或建筑几何复杂时，实例分割的准确性是否会成为新的性能瓶颈，论文未给出回答。
