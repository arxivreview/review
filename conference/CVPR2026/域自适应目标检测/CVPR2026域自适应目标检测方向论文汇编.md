【Bridge: Basis-Driven Causal Inference Marries VFMs for Domain Generalization ｜基于因果推断的视觉基础模型域泛化检测

研究机构：荷兰特文特大学

作者：Mingbo Hong、Feng Liu、Caroline Gevaert 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.26820)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.26820)

> 域泛化（Domain Generalization, DG）旨在解决检测器在单一源域训练后，面对未见目标域时因分布偏移导致的性能崩溃问题。现有方法多依赖数据增强或特征对齐，却忽视了有限源域数据中混杂因子（如光照、共现模式）引发的虚假相关性，导致模型依赖非因果特征。本文切入点在于引入因果推断，通过阻断混杂路径来净化表示。具体做法是设计因果基础块（Causal Basis Block, CBB），利用低秩基学习实现前门调整。该方法在五个基准上超越次优方法，但仅验证了风格与天气偏移，未触及内容级域偏移。

【CD-Buffer: Complementary Dual-Buffer Framework for Test-Time Adaptation in Adverse Weather Object Detection ｜互补双缓冲测试时适应框架

研究机构：韩国延世大学、韩国科学技术研究院

作者：Youngjun Song、Hyeongyu Kim、Dosik Hwang

论文原文见 [arXiv](https://arxiv.org/abs/2603.26092)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.26092)

> 恶劣天气下的目标检测器因分布偏移导致性能骤降，而离线重训练在动态驾驶场景中不可行。现有测试时适应（Test-Time Adaptation, TTA）方法分为加法（引入轻量模块）与减法（剪枝敏感通道）两类，但各自仅在特定偏移严重度下有效，无法应对同一场景中异质性的特征损坏。CD-Buffer 通过统一的特征差异度度量，在通道级别自适应平衡抑制与补偿机制，实现了跨严重度的稳定适应。该框架在多个基准上达到当前最优，但其对“可修复”与“不可修复”特征损坏的区分能力仍存疑。

【DA-Mamba: Learning Domain-Aware State Space Model for Global-Local Alignment in Domain Adaptive Object Detection ｜域自适应目标检测中的全局-局部对齐：基于状态空间模型的混合架构

研究机构：中国科学院、中科院计算所

作者：Haochen Li、Rui Zhang、Hantao Yao 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.18757)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.18757)

> 域自适应目标检测（Domain Adaptive Object Detection, DAOD）旨在解决检测器从有标签源域迁移至无标签目标域时因分布偏移导致的性能下降。现有基于卷积神经网络（CNN）的方法受限于局部感受野，难以捕捉跨区域的长程依赖，而引入视觉Transformer虽能解决全局对齐问题，却带来二次方计算复杂度，阻碍了实时部署。本文提出DA-Mamba，通过设计图像感知与对象感知的状态空间模型（State Space Models, SSM）模块，在保持线性计算复杂度的同时实现全局与局部域不变特征的联合提取。该架构在效率与精度间取得了显著平衡，但其绝对精度仍低于部分基于视觉基础模型的最新方法，且未充分验证在极端内容级域偏移下的鲁棒性。

】

【Expert-Teacher-Student Collaborative Learning for Domain Adaptive Object Detection ｜专家-教师-学生协同学习用于域自适应目标检测

研究机构：中国科学院

作者：Yiming Cui、Liang Li、Haibing Yin 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_b7d3434214d7)

> 域自适应目标检测（Domain Adaptive Object Detection, DAOD）旨在解决检测器在源域与目标域分布偏移下的性能退化问题，其核心瓶颈在于自训练框架中伪标签的噪声与确认偏差。现有方法或依赖教师模型闭环知识导致域偏移下标签质量受限，或单纯引入视觉基础模型（Vision Foundation Models, VFM）却丢失目标域特定适应性。ETS框架通过引入VFM作为离线专家模型，与在线教师模型在标签与表示两个层面协同指导学生模型，以互补知识提升伪标签质量。该设计在三个基准上超越了基于VFM的SOTA方法，但其性能仍低于非VFM路线的最新SOTA，且专家模型的离线静态特性限制了其对动态域偏移的响应能力。

【InsCal: Calibrated Multi-Source Fully Test-Time Prompt Tuning for Object Detection ｜校准多源完全测试时提示微调

研究机构：美国罗切斯特理工学院

作者：Xiaofan Que、Dingrong Wang、Xumin Liu 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_c7048820b339)

> 域自适应目标检测旨在解决检测器在跨域场景下因分布偏移导致的性能急剧下降问题，其核心价值在于规避目标域高昂的标注成本。现有测试时适应方法在缺乏标签时易陷入过度自信陷阱，导致置信度与真实精度严重偏离，本文切入点在于引入实例级校准机制以抑制该风险。具体做法是结合文本引导图像增强与多源模型集成，构建校准熵最小化目标以更新提示嵌入。该方法在完全测试时适应设定下有效降低了校准误差，但其性能上限仍受限于单样本适应的固有信息量瓶颈。

【Remedying Target-Domain Astigmatism for Cross-Domain Few-Shot Object Detection ｜跨域少样本目标检测中的目标域散光问题

研究机构：华中科技大学

作者：Yongwei Jiang、Yixiong Zou、Yuhua Li 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.18541)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.18541)

> 跨域少样本目标检测（CD-FSOD）旨在将预训练检测器适配至仅有极少量标注的目标域，核心难点在于域偏移与数据稀缺的双重挤压。现有方法多聚焦于特征对齐或蒸馏，却忽视了模型在目标域中注意力持续分散、无法聚焦前景的内在缺陷。本文通过量化注意力距离，揭示了这一“散光”现象，并借鉴人类视觉系统的中心-周边机制，设计了正负原型精炼与文本语义对齐模块以重塑注意力分布。该方法在六个基准上刷新了SOTA，但其对支持集原型的依赖是否限制了其在无支持集场景下的泛化能力，仍存疑。

】
