# CVPR2026最新论文 ｜SIMPACT: Simulation-Enabled Action Planning using Vision-Language Models ｜仿真增强视觉-语言模型动作规划

研究机构：美国伊利诺伊大学厄巴纳-香槟分校

作者：Haowen Liu、Shaoxiong Yao、Haonan Chen 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.05955)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.05955)

> 视觉-语言模型（VLM）在静态互联网数据上训练，缺乏对物理动力学因果交互的接地理解，导致其在需要精细接触与力反馈的操作任务中规划失效。现有端到端视觉-语言-动作（VLA）模型依赖大规模动作标注数据，在分布外物理任务上泛化能力受限，而基于几何表征的VLM方法又缺失时序动态预测。SIMPACT通过从单帧RGB-D图像自动构建多物理仿真器，将仿真轨迹作为上下文反馈给VLM进行迭代优化，实现了零样本的物理感知动作规划。该框架在7个真实世界物理任务上显著优于现有通用模型，但其对仿真器构建精度的依赖及Sim2Real差距的影响尚未被充分量化。

## 研究背景

当机器人执行如“将物体原地旋转”或“精细堆叠”等任务时，微小的接触变化或时序偏差会导致截然不同的物理结果。VLM虽能理解指令语义，但其训练数据缺乏动作条件化的因果变化，无法预测动作执行后的物理演化，即缺乏物理动力学接地。这种语义与物理的割裂，使得VLM生成的计划在语言上合理，却在执行中因忽略重力、摩擦或形变而失败。

传统VLA模型通过端到端训练将视觉与语言映射为连续动作，解决了控制频率与精度问题，但严重依赖大规模动作标注数据，且在未见过的物理交互场景中泛化能力极差。另一类方法如VoxPoser和MOKA利用3D几何表征增强VLM的空间推理，但仅处理静态空间关系，缺乏对物体在力作用下如何运动的时序动态建模。SIMPACT的切入点在于将物理仿真器引入VLM的推理循环，不依赖任务特定训练，而是通过测试时的仿真反馈让VLM“看到”动作后果，从而在零样本条件下实现物理感知的动作规划。

## 核心方法

### 方法参照系

本文问题可置于基于模型的规划（Model-based Planning）框架下，但关键差异在于：传统方法需针对特定域训练动力学模型，而SIMPACT利用预训练视觉基础模型与VLM，从单帧RGB-D图像自动构建通用多物理仿真器，并将VLM同时作为动作采样器与优化器，实现了开放世界下的零样本规划。

### 多物理仿真器自动构建

设计动机在于解决静态图像无法表征接触动力学与形变过程的问题。SIMPACT首先利用GroundedSAM2分割目标物体，根据物体特性由VLM自动选择物理引擎：刚体使用MuJoCo，刚性可变形体使用投影动力学变体，软体使用物质点法（MPM）。对于刚体，通过Image-to-3D模型重建网格 $M_i$，并根据点云包围盒缩放与平移得到 $\mathbf{M}_i = \alpha_i (\hat{M}_i - \boldsymbol{\beta}_i)$，其中 $\alpha_i$ 为包围盒对角线长度比，$\boldsymbol{\beta}_i$ 为质心。对于可变形体，在物体表面与桌面之间的体积内均匀采样粒子点集 $P_i \subset \mathbb{R}^3$。VLM进一步推断质量、摩擦、弹性等物理参数 $\theta_{phys}$，完成仿真器初始化。

### 仿真增强的VLM迭代优化

设计动机在于克服VLM仅凭语言推理无法可靠预测动作成败的缺陷。规划过程分为采样与优化两阶段。首先，VLM基于场景上下文采样 $K$ 个高层符号动作序列 $A = \{\mathbf{a}^{[i]}\}_{i=1}^K$，每个动作 $\mathbf{a}_t = (\tau_t, u_t)$ 包含动作类型 $\tau_t$ 与连续控制参数 $u_t$。随后，仿真器执行这些序列得到状态轨迹 $S = \{\mathbf{s}^{[i]}\}_{i=1}^K$。在优化阶段，VLM将仿真渲染图像与状态数值作为上下文，通过上下文学习生成新动作序列：

$$ \mathbf{a}^{[k]} = \text{OPTIMIZE}(\mathcal{A}, \mathcal{S}, \ell_{task}; \text{VLM}) $$

该公式表明VLM利用历史失败案例的视觉与状态证据进行全局推理，而非局部数值更新。若仿真验证成功，则执行该动作；否则将新序列加入上下文继续迭代，直至达到最大迭代次数 $K_{max}$。

## 实验评估

实验在Franka Research 3机械臂上进行，设计了7个涉及刚体与可变形体的物理任务，基线包括VLA模型π0.5及VLM几何方法VoxPoser、MOKA。基线覆盖训练式VLA与静态几何推理两条路线，但缺失多模态感知及大规模预训练VLA的对比。

| 任务 | π0.5 | VoxPoser | MOKA | SIMPACT |
| :--- | :--- | :--- | :--- | :--- |
| Non-toppling push | 0% | 0% | 0% | 80% |
| Bowl stacking | 0% | 0% | 0% | 60% |
| Shape rope | 0% | 0% | 0% | 90% |
| Pivoting | 0% | 0% | 0% | 40% |
| Shape dough | 0% | 0% | 0% | 80% |
| Avoid obstacle | 0% | 0% | 0% | 80% |
| Sweeping | 0% | 0% | 0% | 70% |

SIMPACT在所有任务上均取得非零成功率，而π0.5全部失败，VoxPoser与MOKA仅在部分任务上有微弱表现，凸显了仿真增强推理在物理密集型任务上的优势。

| 消融变体 | Non-toppling push | Bowl stacking | Shape rope |
| :--- | :--- | :--- | :--- |
| w/o VLM sampler | 0% | 10% | 0% |
| w/o simulation rollout | 20% | 0% | 30% |
| w/o VLM optimizer | 30% | 50% | 40% |
| SIMPACT | 80% | 60% | 90% |

移除VLM采样器导致性能大幅下降，表明随机采样无法提供有效初始假设；移除仿真反馈后，纯语言推理在精细任务上失效；移除优化器则失去迭代修正能力。采样数量消融显示，从3增至10个样本性能提升，但增至20个时Bowl stacking性能从60%降至20%，表明过长的上下文反而损害VLM推理效率。

评估仅使用成功率指标，未报告置信区间或计算延迟。实验任务为自建非标准基准，无法与LIBERO等通用基准直接比较。代码与超参数未完全公开，仿真器构建依赖多个预训练模型，复现成本较高。

## 关联研究分析

从问题动机看，SIMPACT与π0.5代表了两种截然不同的物理理解路径。π0.5依赖大规模动作数据端到端学习物理规律，在分布内任务上高效，但在未见过的物理交互中泛化失败；SIMPACT则通过显式仿真器提供物理接地，无需动作标注即可处理新任务。这一差异源于任务特性：物理密集型任务需要精确的因果预测，而大规模数据难以覆盖所有接触状态组合，仿真器提供了可解释的物理约束。

从方法设计看，SIMPACT与Prompting-with-the-Future均利用仿真反馈，但后者仅将VLM作为奖励信号用于模型预测控制，而SIMPACT将VLM作为核心优化器，利用其推理能力从失败案例中学习全局动作调整。这种设计使得SIMPACT能处理更复杂的长程任务，但也引入了VLM推理延迟与上下文长度限制的问题。仿真器构建误差对规划精度的影响是否被充分量化，论文未给出回答。

## 总结

SIMPACT旨在解决VLM缺乏物理动力学接地导致的零样本操作规划失效问题。其切入点在于利用预训练视觉模型自动构建多物理仿真器，将仿真轨迹作为上下文反馈给VLM进行迭代优化，从而在不依赖任务特定训练的情况下实现物理感知规划。实验表明，该方法在7个真实世界物理任务上成功率最高达90%，显著优于π0.5等基线。然而，其性能高度依赖仿真器构建精度，且Sim2Real差距对最终执行成功率的影响未被量化。当仿真器参数推断出现偏差时，VLM的迭代优化是否仍能收敛到可行解，论文未给出回答。
