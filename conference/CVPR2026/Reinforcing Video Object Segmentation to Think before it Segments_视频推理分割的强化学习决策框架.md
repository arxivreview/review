# CVPR2026最新论文 ｜Reinforcing Video Object Segmentation to Think before it Segments ｜视频推理分割的强化学习决策框架

研究机构：大连理工大学

作者：Sitong Gong、Yunzhi Zhuge、Lu Zhang 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_9191096c8f29)

> 视频推理分割（Video Reasoning Segmentation, VRS）要求模型从隐含因果关系的自然语言指令中定位动态目标，传统方法将视频语义压缩至单一分割令牌，导致推理过程不透明且时空对齐失效。Veason-R1 将任务重构为“关键帧选择-空间定位”的两步序贯决策，通过链式思维（Chain-of-Thought, CoT）监督预热与群体相对策略优化（Group Relative Policy Optimization, GRPO）强化学习，实现了可验证的逐步推理。该框架在仅使用 ReVOS 单数据集训练的情况下，于 ReasonVOS 上取得 10.0 J&F 的显著提升，但其对伪 CoT 标注与外部分割信号的依赖，限制了其在极端长序列中的泛化边界。

## 研究背景

当指令涉及“门开后进入并传递钥匙的人”这类隐含时序因果时，模型需调用世界知识推断目标出现的最显著时刻。这一过程依赖视觉语言模型（Vision-Language Model, VLM）的序列级推理能力，但现有方法常将全局视频信息压缩至单一 `<SEG>` 令牌，该令牌缺乏结构化推理痕迹，在长视频与遮挡场景下易产生语义歧义与掩码错位。

VRS 领域主流路线沿袭“令牌中心”范式，如 VISA 与 VideoLISA 通过稀疏采样与统一令牌方案解码掩码，Sa2VA 结合 SAM2 进行密集定位。这些方法虽有效，但推理路径不透明，且通常依赖混合大规模图像/视频语料进行跨模态对齐，训练成本高且难以解释。Veason-R1 的切入点在于摒弃令牌压缩，显式建模“先思考后分割”的决策过程，通过可验证奖励机制在单数据集上实现数据高效学习，从而在保持解耦架构优势的同时，强化时空定位的鲁棒性。

## 核心方法

### 方法参照系

VRS 的标准流程通常由 VLM 解析指令生成分割提示，再经分割基础模型（如 SAM2）传播掩码。本文的关键差异在于，将 VLM 的输出从“分割令牌”改为“关键帧索引+边界框”，并将整个定位过程建模为序贯决策问题，引入强化学习优化策略。

### 链式思维监督预热

CoT 监督阶段旨在为策略提供层级推理先验，解决直接 RL 优化在复杂时序动态下的脆弱性。设计动机是：直接优化 VLM 缺乏对视频语义与帧级定位的桥接能力，需通过结构化推理链建立映射。本文利用 Seed1.5-VL 生成多步 CoT 标注，指导 Qwen2.5-VL 进行自回归训练。关键帧定义为目标视觉最显著帧，模型需预测关键帧索引 $t_k$ 及该帧内的边界框集合 $B_{t_k}$。为减少位置歧义，采用绝对帧索引（如 `<0>`, `<7>`）而非相对标签，避免模型坍缩至固定索引。该阶段通过 LoRA 适配器微调，输出包含 `<think>` 推理链与 `<answer>` 结构化结果（关键帧时间戳与边界框列表）的序列，为后续 RL 提供稳定初始化。

### 时空奖励强化优化

GRPO 阶段在 CoT 预热基础上，通过可验证奖励细化时空定位精度。设计动机是：CoT 仅提供粗粒度定位，需通过奖励信号强化关键帧显著性、空间对齐与跨帧一致性。GRPO 摒弃价值函数，利用组内相对奖励计算优势值：

$$
A_i = \frac{r(o_i) - \mu_r}{\sigma_r}
$$

其中 $r(o_i)$ 为第 $i$ 个候选响应的标量奖励，$\mu_r$ 与 $\sigma_r$ 为组内均值与标准差。总奖励 $R_{total}$ 由四项组成：格式合规奖励 $R_f$（确保输出结构）、时序定位奖励 $R_k$（关键帧掩码面积与最大掩码面积之比）、空间对齐奖励 $R_s$（匈牙利匹配后的 IoU 归一化和）、统一一致性奖励 $R_u$（SAM2 传播后的视频级 IoU 均值）。KL 正则化锚定策略至参考模型，防止奖励过优化。该机制使模型在推理时生成可验证的逐步轨迹，同时通过 $R_u$ 耦合关键帧选择与视频级掩码质量，抑制定位与传播误差。

## 实验评估

实验在 ReVOS、ReasonVOS 与 MeViS 基准上评估，指标为 J&F 与鲁棒性分数 R。基线覆盖 VISA、VideoLISA、Sa2VA 等主流 MLLM 方法，但缺失纯端到端大模型（如 SVAC）的直接对比，可能低估解耦架构在长视频语义一致性上的相对劣势。

| 方法 | ReVOS J&F | ReasonVOS J&F | MeViS J&F |
| :--- | :--- | :--- | :--- |
| Veason-R1-7B | 63.0 | 56.8 | 65.0 |
| VRS-HQ-13B | 61.7 | — | — |
| Sa2VA-i | — | — | 74.4 |

Veason-R1-7B 在 ReVOS 上超越 VRS-HQ-13B 1.3 J&F，在 ReasonVOS 上提升 10.0 J&F，但在 MeViS 上低于 Sa2VA-i 9.4 J&F，表明其在隐式推理任务上优势显著，但在多目标动态场景下精度仍落后于解耦式 SOTA。

| 消融策略 | ReVOS Referring J&F | ReVOS Reasoning J&F |
| :--- | :--- | :--- |
| Grounding-only | 58.3 | 51.3 |
| SFT-keyframe | 54.6 | 51.0 |
| Ours | 63.0 | 56.8 |

消融显示，仅进行空间定位（固定关键帧）导致 J&F 下降 4.7-5.5，仅进行关键帧选择（忽略定位）下降 8.4-5.8，证明时序与空间推理的联合建模至关重要。移除空间对齐奖励 $R_s$ 造成最大性能损失（2.0-2.9 J&F），凸显帧级定位对整体分割精度的决定性作用。

评估边界方面，论文未报告计算效率与实时性指标，且依赖伪 CoT 标注与冻结 SAM2 信号，可能引入标注噪声与传播误差。代码未公开，复现需依赖 Qwen2.5-VL 与 SAM2 的开源实现，超参数（如 LoRA 秩 8、学习率 $1 \times 10^{-4}$）已提供，但 GRPO 的批大小与采样数（16 与 8）对性能敏感，需进一步验证。

## 关联研究分析

从问题动机看，Veason-R1 与 Sa2VA 均解决 VRS 的语义对齐问题，但 Sa2VA 依赖 MLLM 生成提示后由 SAM2 传播，误差随视频长度累积；Veason-R1 通过 RL 优化关键帧选择，将长视频问题降维为单帧定位+传播，规避了记忆过载，但牺牲了跨帧动态建模能力。这一差异源于任务特性：Veason-R1 聚焦隐式因果推理，关键帧选择足以捕捉目标显著性，而 Sa2VA 面向显式描述，需密集时序传播。

从方法设计看，Veason-R1 与 Omni-R1 同属 GRPO 应用，但 Omni-R1 采用级联双系统（VLM+分割模型），依赖混合大规模训练；Veason-R1 采用单策略端到端优化，仅用 ReVOS 数据，数据效率更高。然而，Veason-R1 的奖励设计依赖外部 SAM2 信号计算 $R_u$，而 Omni-R1 可能通过内部掩码预测实现自监督，前者在极端遮挡下可能因 SAM2 失效而奖励失真，后者更鲁棒但训练成本更高。

## 总结

Veason-R1 针对 VRS 中令牌压缩导致的推理不透明与时空对齐失效，通过“关键帧选择-空间定位”的两步决策与 GRPO 强化学习，实现了可验证的逐步推理与数据高效学习。实验证明其在 ReasonVOS 上提升 10.0 J&F，鲁棒性分数 R 提升 8.8，但在 MeViS 上仍落后于 Sa2VA-i 9.4 J&F。其边界在于依赖伪 CoT 标注与外部 SAM2 信号，且未验证长序列中的误差累积。当视频长度超过关键帧显著性可捕捉的范围时，单帧定位策略是否仍能维持身份一致性，论文未给出回答。
