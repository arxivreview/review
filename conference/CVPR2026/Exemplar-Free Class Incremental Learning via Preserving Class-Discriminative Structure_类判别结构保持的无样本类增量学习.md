# CVPR2026最新论文 ｜Exemplar-Free Class Incremental Learning via Preserving Class-Discriminative Structure ｜类判别结构保持的无样本类增量学习

研究机构：英国曼彻斯特大学

作者：Xin Zhang、Liang Bai、Guanchao Wang 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_72362aa67c0a)

> 无样本类增量学习（Exemplar-Free Class-Incremental Learning, EFCIL）旨在解决模型在禁止存储旧数据约束下，顺序学习新类别时因特征空间几何结构崩塌导致的灾难性遗忘。现有参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）方法多聚焦于参数更新控制或输出对齐，却忽视了类内紧凑性与类间可分性这一几何基础的同步劣化。本文通过自适应原型校正与结构一致性约束，在冻结骨干下动态重构旧类原型分布并稳定新旧特征间的角度关系。该框架在细粒度任务上显著优于基线，但其对语义相似性假设的依赖在极端类序下的鲁棒性尚存疑。

## 研究背景

当模型在冻结预训练视觉Transformer（Vision Transformer, ViT）骨干上通过低秩适应（Low-Rank Adaptation, LoRA）微调新任务时，新任务梯度主导的参数更新会迫使旧类特征在嵌入空间中发生位移。这种位移并非均匀平移，而是导致旧类特征分布的均值中心漂移与协方差矩阵变形，即类内结构退化。同时，旧类原型间的相对几何位置发生紊乱，类间结构被破坏。二者共同作用，使得原本清晰的决策边界模糊，引发灾难性遗忘。

EFCIL的核心矛盾在于，在无法访问旧数据以直接测量或校正旧类分布的前提下，如何维持特征空间的判别性几何结构。主流PEFT路线如L2P、DualPrompt通过提示或适配器隔离任务干扰，但仅关注参数层面的解耦，未显式建模特征分布的形态变化。FeTrIL等方法虽引入协方差矩阵，但多依赖静态统计量或生成式重放，缺乏对特征空间迁移过程中动态几何关系的约束。本文切入点在于揭示遗忘源于类判别结构（Class-Discriminative Structure）的联合崩塌，并提出通过新类位移推断旧类分布变换、通过角度关系稳定类间几何的解析式校正框架。

## 核心方法

### 方法参照系

EFCIL的标准流程包含特征提取、动态分类器扩展与旧类知识保留。本文采用ViT-B/16-IN21K作为骨干，插入LoRA模块进行参数高效微调，分类器权重矩阵随任务扩展。与通用PEFT流程的关键差异在于，本文不依赖存储样本或生成式重放，而是通过解析式几何约束在特征空间迁移中主动校正旧类原型分布。

### 自适应原型校正

针对旧类原型分布无法直接测量的问题，本文提出自适应原型校正（Adaptive Prototype Rectification, APR）。设计动机在于解决SSIAT等方法仅用单个新样本估计中心偏移、忽略协方差变形的失效。APR假设语义相似类具有相似的位移模式，利用新类可观测位移 $\delta_j = \mu_j^{(t)} - \mu_j^{(t-1)}$ 推断旧类位移 $\Delta_k$：

$$
\Delta_k = \sum_{j=1}^{|C_t|} w_{k,j} \delta_j, \quad w_{k,j} = \frac{\exp(\gamma \cdot s_{k,j})}{\sum_{l=1}^{|C_t|} \exp(\gamma \cdot s_{k,l})}
$$

其中 $s_{k,j}$ 为旧类原型 $\mu_k^{(t-1)}$ 与新类原型 $\mu_j^{(t-1)}$ 的余弦相似度。该公式通过注意力机制加权新类位移，实现旧类中心的动态校正。同时，基于扰动方差 $\rho = \text{Var}(\alpha)$ 更新协方差：

$$
\Sigma_k^{(t)} = \Sigma_k^{(t-1)} + \rho \Delta_k \Delta_k^T + \epsilon I
$$

此设计将旧类分布建模为高斯分布，通过位移推断与协方差修正，在数学上保持了类内结构的紧凑性，避免了仅更新均值导致的分布形状失真。

### 结构一致性约束

APR解决了类内结构保持，但类间原型间的相对几何关系仍需稳定。本文提出结构一致性约束（Structural Consistency Constraint, SCC），设计动机在于解决直接约束旧类原型距离因数据不可得而失效的问题。SCC利用新任务样本作为参考点，旧类原型作为空间锚点，约束二者间的角度关系在微调前后保持稳定：

$$
\mathcal{L}_{SCC} = \frac{1}{B} \sum_{i=1}^{B} \| r_i^{(t)} - r_i^{(t-1)} \|_2^2
$$

其中 $r_i^{(t)}$ 是新样本 $x_i$ 在模型 $f_\theta^{(t)}$ 下与所有旧类原型的余弦相似度向量。该损失函数通过稳定参考点与锚点的角度模式，间接维持了旧类原型间的相对几何结构，无需访问旧数据即可实现类间可分性的保持。

## 实验评估

实验基于ViT-B/16-IN21K骨干，在ImageNet-A、Cars-196、ObjectNet等6个数据集上评估，采用Last-Acc与Inc-Acc指标。基线覆盖SSIAT、SDC等原型校正方法，但缺失Adversarial Pseudo-replay等生成式重放基线，限制了与无样本路线SOTA的直接对比。

| 数据集 | 任务数 | Last-Acc (%) | Inc-Acc (%) |
| :--- | :--- | :--- | :--- |
| ImageNet-A | 5 | 66.65±0.20 | 74.09±4.09 |
| ImageNet-A | 20 | 62.30±0.79 | - |
| Cars-196 | 5 | 83.52±0.32 | - |
| Cars-196 | 10 | 80.23±0.68 | - |
| Cars-196 | 20 | 66.14±0.56 | - |

在ImageNet-A 5任务设置下，本文方法Last-Acc达66.65%，较SSIAT提升2.44%；在Cars-196细粒度任务上，5任务Last-Acc达83.52%，较基线提升7.79%–11.24%。消融实验未提供详细数据，但主结果表明APR与SCC的联合使用在细粒度场景下收益显著，暗示几何结构保持对类间差异小的任务更为关键。

评估边界方面，论文仅报告3个随机种子的均值±标准差，未提供置信区间；超参数 $\rho$、$\gamma$、$\lambda$ 的敏感性分析缺失；代码已开源，但GPU资源与训练时长未披露，可复现性依赖社区验证。

## 关联研究分析

从问题动机看，本文与FeTrIL同属无样本统计记忆路线，但FeTrIL直接建模类内协方差以缓解原型漂移，而本文通过新类位移推断旧类分布变换，将静态统计量升级为动态几何校正。这一差异源于本文对“位移模式相似性”假设的依赖，该假设在语义差异极大的类序下可能失效，而FeTrIL的协方差建模不依赖此类假设，但缺乏对类间关系的显式约束。

从方法设计看，本文与BOFA同属结构约束路线，但BOFA通过正交低秩融合在参数层面隔离任务干扰，本文通过SCC在特征层面稳定角度关系。BOFA的正交约束是硬性数学隔离，适用于细粒度任务；本文的角度稳定是软性正则化，更灵活但可能无法完全消除类间混淆。二者在CUB-200等细粒度基准上的表现差异，可能反映参数隔离与特征几何保持在不同任务特性下的适用性边界。

## 总结

本文核心矛盾在于EFCIL中旧类特征分布的均值漂移与协方差变形导致的类判别结构崩塌。现有PEFT方法仅关注参数更新或输出对齐，未显式建模特征几何形态变化，而本文通过APR推断位移、SCC稳定角度，在解析式框架下实现了类内与类间结构的联合保持。实验证明该框架在Cars-196细粒度任务上Last-Acc达83.52%，较基线提升7.79%–11.24%。其边界在于APR依赖“语义相似类位移模式相似”假设，当新任务与旧任务语义差异极大时，位移推断可能失效；SCC仅约束角度关系，未直接约束原型距离，在类间差异极小时可能不足。当任务序列中相邻任务语义距离超过阈值时，APR的位移推断误差是否会导致类内结构校正失效，论文未给出回答。
