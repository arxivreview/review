# CVPR2026最新论文 ｜SEBA: Sample-Efficient Black-Box Attacks on Visual Reinforcement Learning ｜样本高效黑盒攻击

研究机构：香港理工大学

作者：Tairan Huang、Yulin Jin、Junxu Liu 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.09681)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.09681)

> 视觉强化学习（Visual RL）智能体在连续控制任务中面临高维像素输入与无限动作空间的组合，导致传统基于梯度的白盒攻击失效，而现有黑盒攻击方法因查询成本过高难以实用。本文切入点在于解耦攻击优化与环境交互，通过构建影子Q模型与生成对抗网络（GAN）联合框架，将扰动生成从策略搜索转化为监督学习问题。SEBA利用世界模型生成合成轨迹以降低真实环境查询次数，实现了在黑盒约束下的高效率、低感知度攻击。该方法在MuJoCo与Atari基准上验证了有效性，但其对世界模型精度的依赖及离散动作空间的泛化边界尚存疑。

## 研究背景

当智能体直接从像素观测学习连续控制策略时，其决策边界对微小视觉扰动极度敏感。这种敏感性源于高维输入空间中任务相关信号与无关噪声的深度纠缠，使得攻击者只需在观测中注入微小扰动即可导致策略崩溃。然而，实际部署场景中攻击者往往无法获取智能体内部梯度或参数，仅能通过外部交互获取状态、动作与奖励，这构成了黑盒攻击的核心约束。

现有对抗攻击研究多聚焦于向量状态或离散动作空间，如SA-MDP与PA-AD主要处理低维观测或Atari分类式策略。连续动作视觉RL中，动作空间为$\mathbb{R}^d$，直接在该空间进行策略优化会导致样本复杂度急剧上升，且梯度信号稀疏噪声大。主流黑盒方法如OPTIMAL将攻击者建模为强化学习智能体，但其在像素空间的高维探索效率低下，且每次攻击需大量环境查询，难以满足实际部署的预算限制。

SEBA针对这一瓶颈，提出将攻击过程分解为扰动生成与价值估计两个独立模块。通过引入影子Q模型作为可微分代理，攻击者无需访问受害者内部即可获取长期回报梯度；同时利用世界模型模拟环境动态，将真实交互成本降低$O(H)$倍。这一设计将高维动作空间中的非平稳优化问题，转化为图像空间中的监督生成问题，解决了黑盒约束下效率与效果难以兼顾的矛盾。

## 核心方法

### 方法参照系

传统黑盒RL攻击将攻击者视为策略$\pi_a$，在扰动空间$\delta \in \mathbb{R}^{C \times H \times W}$中执行动作以最小化受害者回报。该流程通常采用策略梯度或进化算法，但在像素级高维空间中，探索效率极低且梯度估计方差大。SEBA的关键差异在于放弃在扰动空间进行策略优化，转而训练一个确定性生成器$G_\phi$直接输出扰动，并通过外部价值模型提供优化信号。

### 影子Q模型与两阶段优化

影子Q模型$Q_{shadow}$作为受害者策略的可微分代理，通过时间差分（TD）目标估计扰动下的累积奖励。其训练数据来自受害者策略在扰动状态$s'_t = \text{clip}(s_t + G_\phi(s_t), 0, 1)$下的真实或合成轨迹。为稳定优化，SEBA采用两阶段交替策略：Stage 1冻结生成器，更新$Q_{shadow}$以准确建模扰动下的价值动态；Stage 2冻结$Q_{shadow}$，优化生成器以最小化预测回报。

$$
\mathcal{L}_{Q} = \mathbb{E}_{(s'_t, a_t, r_t, s'_{t+1}) \sim \mathcal{D}} \left[ \left( r_t + \gamma Q_{shadow}(s'_{t+1}, a_{t+1}) - Q_{shadow}(s'_t, a_t) \right)^2 \right]
$$

该公式表明，$Q_{shadow}$通过最小化TD误差，学习在扰动观测下受害者策略的长期回报估计，为生成器提供黑盒条件下的优化方向。

### GAN扰动生成与世界模型加速

生成器$G_\phi$与判别器$D_\psi$构成GAN框架，生成器目标包含两项：一项促进视觉不可感知性（对抗损失），另一项通过$Q_{shadow}$最小化受害者回报。判别器区分干净状态与扰动状态，确保扰动在视觉上平滑。为降低环境查询成本，SEBA引入基于IRIS的世界模型$W$，由离散图像分词器与自回归Transformer组成，预测未来潜在token与奖励。

$$
\mathcal{L}_{G} = \mathbb{E}_{s_k \sim \mathcal{D}} \left[ -\log D_\psi(s'_k) + \lambda Q_{shadow}(s'_k, \pi(a|s'_k)) \right]
$$

该公式中，第一项迫使生成器产生判别器无法区分的扰动，第二项引导扰动方向以降低受害者价值。世界模型通过生成$H$步合成轨迹，将每次真实交互扩展为$1+H$条训练样本，显著减少了对真实环境的依赖。

## 实验评估

实验在MuJoCo五个连续控制任务（Cheetah Run, Walker Walk等）与Atari三个离散任务（Freeway, Pong, Alien）上进行，受害者分别为DrQ-SAC与Rainbow。基线覆盖图像空间攻击（PGD, C&W, SimBA, Square）与向量态RL攻击（Critic-Based, MAD, PA-AD, OPTIMAL）。SEBA在MuJoCo所有任务上取得最低奖励与最低FID，例如Cheetah Run中SEBA奖励为1.61±3.97，而PGD为150.72±49.52；Atari Alien中SEBA奖励降至982±542，仅次于白盒PA-AD的443±281，但查询成本大幅降低。

| 任务 | 方法 | 奖励 (↓) | FID (↓) | 训练Env查询 (↓) |
| :--- | :--- | :--- | :--- | :--- |
| Cheetah Run (MuJoCo) | PGD | 150.72±49.52 | 78.05 | / |
| Cheetah Run (MuJoCo) | SEBA | 1.61±3.97 | 62.43 | 160K |
| Alien (Atari) | PA-AD | 443±281 | 102.4 | 2M |
| Alien (Atari) | SEBA | 982±542 | 81.7 | 80K |

消融实验显示，移除判别器（-D）导致FID从62.43升至97.18，证明判别器对视觉不可感知性的关键作用；移除世界模型（-WM）使环境查询从160K增至800K，但攻击强度略有提升，表明世界模型主要贡献于效率而非效果。移除Stage 1扰动状态（-Noise）导致奖励显著回升（如Walker Walk从35.74升至118.11），证实影子Q模型在扰动分布下训练的重要性。

评估指标涵盖效果（奖励）、不可感知性（FID）与效率（查询成本），但未报告计算时间或GPU资源消耗。代码在补充材料中提供，超参数包括扰动边界$\epsilon=8/255$、世界模型步长$H=4$。实验未包含最新防御方法（如T2RD、V-Simba）作为受害者，限制了鲁棒性对比的全面性。

## 关联研究分析

从问题动机看，SEBA与PA-AD同属黑盒/白盒攻击框架，但PA-AD依赖完整梯度访问，而SEBA通过影子Q模型实现无梯度优化。PA-AD在Atari上表现最强，但其在连续控制中因高维动作空间探索困难而失效；SEBA通过生成器直接输出扰动，规避了策略搜索的样本复杂度瓶颈。这一差异源于任务特性：连续动作空间要求攻击者具备长期规划能力，而SEBA的世界模型提供了这种规划基础。

从方法设计看，SEBA与IRIS共享世界模型架构，但IRIS用于策略学习，SEBA用于攻击辅助。IRIS的潜在预测旨在提升样本效率，SEBA的潜在预测旨在降低查询成本。两者均验证了潜在空间建模在高维视觉RL中的有效性，但SEBA引入了GAN模块以平衡攻击强度与视觉保真度，这是IRIS所不具备的。SEBA未探索世界模型误差对攻击泛化性的影响，若世界模型在分布外状态下预测偏差较大，攻击效果可能衰减。

## 总结

SEBA解决了黑盒约束下连续动作视觉RL攻击的效率瓶颈，通过影子Q模型与GAN解耦价值估计与扰动生成，并利用世界模型降低环境交互成本。实验证明其在MuJoCo上实现奖励降至1.61（Cheetah Run），查询成本仅为PA-AD的1/25。然而，其攻击效果依赖于世界模型对动态的准确建模，且在Atari离散任务上优势不如连续任务显著。当世界模型在未见过的视觉状态下预测偏差增大时，SEBA生成的扰动是否仍能保持高破坏性，论文未给出回答。
