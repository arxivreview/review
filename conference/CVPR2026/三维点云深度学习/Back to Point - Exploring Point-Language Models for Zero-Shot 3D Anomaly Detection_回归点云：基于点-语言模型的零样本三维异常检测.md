# CVPR2026最新论文 ｜Back to Point: Exploring Point-Language Models for Zero-Shot 3D Anomaly Detection ｜回归点云：基于点-语言模型的零样本三维异常检测

作者：Kaiqiang Li、Gang Li、Mingle Zhou 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.21511)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.21511)

> 工业质检中，三维点云异常检测面临标注稀缺与未知缺陷泛化难的双重困境。现有主流方案依赖将点云渲染为二维图像并复用视觉-语言模型，这一过程不可避免地丢失几何细节且受视角选择偏差制约。本文提出 BTP 框架，首次利用预训练点-语言模型直接对齐点云与文本嵌入，通过多粒度特征融合实现无需目标类别数据的零样本检测与定位。该路径在细粒度定位上显著优于投影范式，但在全局异常判别上仍落后于成熟的二维视觉-语言模型，其几何先验的引入是否限制了端到端学习的纯粹性尚存疑。

## 研究背景

三维点云作为无序、稀疏的几何数据，其局部结构对异常检测至关重要。传统卷积依赖规则网格，无法直接处理点云，PointNet 系列通过置换不变性确立了直接处理范式，但难以捕捉细粒度局部几何。Fast Point Feature Histogram (FPFH) 等手工描述符虽能编码局部几何，但缺乏高层语义且无法端到端优化。点-语言模型 (Point-Language Model, PLM) 如 ULIP 首次实现了点云、图像与文本的统一表示学习，为直接处理三维几何提供了基础。

零样本 (Zero-Shot, ZS) 三维异常检测旨在无需异常样本即可检测缺陷，以应对数据隐私与采集限制。现有 ZS 方法主要沿用二维范式，将点云渲染为多视角图像，利用 CLIP 等视觉-语言模型 (Vision-Language Model, VLM) 对齐文本与图像特征，再反投影回三维。这种“投影-反投影”流程不仅引入计算开销，更因视角选择偏差导致对细微结构变形不敏感。本文切入点在于摒弃二维投影，直接利用 PLM 编码点云，保留内在几何属性，并通过多粒度特征融合解决 PLM 原生全局嵌入对局部异常不敏感的问题。

## 核心方法

### 方法参照系

本文问题属于基于语义对齐的零样本异常检测。通用流程为：提取点云特征，与正常/异常文本嵌入计算相似度，输出异常分数。关键差异在于，本文不使用二维图像特征，而是直接处理三维点云，并引入可学习几何模块以增强结构敏感性，区别于 PointAD 等投影方法。

### 多粒度特征嵌入模块

设计动机在于解决 PLM 全局嵌入对局部细微结构变形不敏感的失效。通常做法仅使用编码器最后一层全局嵌入，本文扩展为融合多层中间特征、几何描述符与全局 CLS 令牌。具体地，从 PointBERT 编码器第 2、5、8、11 层提取 Patch 特征 $\mathbf{H}^{[l]}$，经 GFCM 提取几何特征 $\mathbf{F}_{geo}$，并与 CLS 令牌 $\mathbf{h}_{CLS}$ 投影至统一空间。融合公式为：

$$ \mathbf{Z} = \sum_{l=1}^{L} \alpha_l \mathbf{S}^{[l]} + \mathbf{G} + \mathbf{C} $$

其中 $\alpha_l$ 为 softmax 归一化权重，$\mathbf{S}^{[l]}, \mathbf{G}, \mathbf{C}$ 分别为语义、几何、全局特征的投影。该设计使模型同时捕捉细粒度局部偏差与整体物体语义，提升了定位精度。

### 联合表示学习策略

设计动机在于增强模型对多样异常模式的鲁棒性，弥补单一监督信号不足。通常做法仅优化全局分类损失，本文引入点级、全局与几何三级监督。点级损失结合 Focal Loss 与 Dice Loss 缓解正负样本不平衡；几何损失通过对比学习将可学习几何特征对齐 FPFH 描述符：

$$ \mathcal{L}_{geo} = \ell_{ctr}(\phi_{geo}(\mathbf{f}_i), \hat{\mathbf{f}}_{FPFH}^{[i]}) $$

总损失 $\mathcal{L} = \mathcal{L}_{local} + \lambda_1 \mathcal{L}_{global} + \lambda_2 \mathcal{L}_{geo}$ 中，$\lambda_1=0.5, \lambda_2=0.1$。该策略使 GFCM 显式吸收手工几何先验，增强了模型对结构差异的敏感性，实现了语义与几何的互补优化。

## 实验评估

实验在 Real3D-AD（12 类真实工业数据）与 Anomaly-ShapeNet（40 类合成数据）上进行，输入点云下采样至 2048 点，采用 ULIP2 作为编码器。基线覆盖无监督方法（CPMF, M3DM）与零样本方法（PointAD, AnomalyCLIP），但缺失其他 PLM 基线如 PLANE。

| 方法 | Real3D-AD O-AUROC (%) | Real3D-AD P-AUROC (%) | Anomaly-ShapeNet P-AUROC (%) |
| :--- | :--- | :--- | :--- |
| PointAD | 74.8 | 73.5 | - |
| CPMF | 58.6 | 75.9 | - |
| BTP (Ours) | 61.4 | 84.5 | 87.3 |

BTP 在点级 AUROC 上以 84.5% 显著超越 PointAD 的 73.5% 和 CPMF 的 75.9%，但在对象级 AUROC 上（61.4%）低于 PointAD（74.8%）。这表明 PLM 直接编码在细粒度定位上具有优势，但全局语义判别能力仍弱于成熟的二维 VLM。

| 配置 | Real3D-AD O-AUROC (%) | Real3D-AD P-AUROC (%) |
| :--- | :--- | :--- |
| Baseline | 51.5 | 53.9 |
| + MGFEM | 59.9 | 61.4 |
| + GFCM | 52.5 | 53.8 |
| Full (MGFEM+GFCM) | 61.4 | 84.5 |

消融实验显示，单独引入 MGFEM 或 GFCM 收益有限，二者结合后点级性能大幅提升。移除几何损失 $\mathcal{L}_{geo}$ 导致点级 AUROC 从 84.5% 降至 82.2%，验证了 FPFH 先验对结构敏感性的贡献。点数消融表明 2048 点为精度与效率平衡点，8192 点时 FPS 从 75.3 降至 69.8，精度增益边际递减。

评估指标涵盖对象级与点级 AUROC、AP 及 AU-PRO，协议为标准单类训练跨类测试。局限在于未报告置信区间（仅主结果提供），且缺乏与其他 PLM 方法的直接对比。代码已开源，使用单张 RTX 4090 训练，结果基于 10 次独立运行平均，可复现性较高。

## 关联研究分析

从问题动机看，BTP 与 PointAD 均旨在解决零样本三维异常检测，但路线截然不同。PointAD 依赖多视角渲染复用 CLIP，利用二维生态的先验优势，但受限于视角偏差与几何丢失；BTP 采用原生三维编码，保留几何保真度，但牺牲了全局语义的成熟度。根源在于任务特性：细粒度定位依赖局部几何，而全局判别依赖高层语义。BTP 在点级上的优势验证了原生三维路径在结构敏感任务上的有效性，但其对象级性能落后是否因 PLM 全局对齐不如 CLIP 成熟，论文未给出深入分析。

从方法设计看，BTP 与 PLANE 同属 PLM 应用，但 PLANE 仍需目标类别数据进行特定训练，而 BTP 实现真正的零样本。BTP 引入 GFCM 对齐 FPFH，这是一种混合范式，既利用手工特征先验又通过端到端优化增强。这与纯数据驱动的自监督学习（如 Point-MAE）形成对比。GFCM 对 FPFH 的依赖是否限制了模型对未知几何结构的泛化能力，特别是在 FPFH 表现不佳的噪声或稀疏场景下，是一个值得追问的盲区。

## 总结

BTP 旨在解决零样本三维异常检测中几何细节丢失与视角偏差的矛盾。现有投影方法因信息丢失难以捕捉细微结构，而 BTP 凭借 PLM 直接编码与多粒度融合，保留了内在几何属性。通过 MGFEM 与 GFCM 的联合优化，BTP 在 Real3D-AD 点级 AUROC 上达到 84.5%，显著超越 PointAD 的 73.5%。然而，其对象级 AUROC 仅为 61.4%，低于 PointAD 的 74.8%，暴露了 PLM 全局语义判别能力的不足。此外，GFCM 对 FPFH 先验的依赖暗示了端到端学习纯粹性的妥协。当面对 FPFH 描述符失效的极端噪声或稀疏点云时，BTP 的几何敏感性是否仍能保持优势，论文未提供相关实验证据。
