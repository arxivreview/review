# CVPR2026最新论文 ｜Foundation Model Priors Enhance Object Focus in Feature Space for Source-Free Object Detection ｜基于空间先验正则化的无源目标检测

研究机构：印度理工学院、微软研究院

作者：Sairam VCR、Rishabh Lalla、Aveen Dayal 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.17514)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.17514)

> 无源目标检测旨在不访问源域数据的前提下，将预训练检测器适应至无标签目标域，核心难点在于源模型在目标域上的特征激活往往扩散至背景，导致伪标签噪声累积。现有方法多聚焦于伪标签筛选或对齐，忽视了特征空间本身“对象聚焦能力”的退化。本文提出FALCON-SFOD，通过离线提取基础模型的空间先验正则化特征空间，并设计不平衡鲁棒损失以稳定训练。该框架在多个基准上超越了主流无源检测基线，但其性能增益高度依赖外部分割模型的质量，且在极端域偏移下的泛化边界尚不明确。

## 研究背景

无源目标检测（Source-Free Object Detection, SFOD）面临的核心困境是源模型在目标域上的“确认偏置”。当域偏移发生时，检测器的特征激活不再紧凑地覆盖目标物体，而是弥散至背景杂乱区域，这种空间上的模糊性直接导致检测头生成低质量的伪标签。伪标签的噪声随后通过Mean Teacher框架传播至学生模型，形成恶性循环，使得适应过程陷入局部最优。

主流SFOD方法如Simple-SFOD、IRG和DRU，主要致力于优化伪标签的选择策略或稳定教师-学生训练动态。例如，IRG通过实例关系图精炼伪标签，DRU通过动态更新教师模型增强稳定性。然而，这些方法均假设特征空间本身是可靠的，仅从标签层面进行修正。本文指出，这种假设在大域偏移下失效，因为特征激活的空间扩散是伪标签噪声的根源。因此，本文的切入点是从特征层面入手，通过引入外部空间先验来重塑检测器的特征表示，使其重新具备对象聚焦能力，从而从源头上抑制伪标签噪声。

## 核心方法

### 方法参照系

标准SFOD流程采用Mean Teacher自训练框架：教师模型（学生模型的指数移动平均）对目标域图像生成伪标签，学生模型通过最小化分类与回归损失进行更新。本文的关键差异在于，在标准损失之外，引入了两个针对特征空间结构和不平衡噪声的专用正则化项，且基础模型仅用于离线预处理，不参与在线训练。

### 空间先验感知正则化（SPAR）

设计动机：解决域偏移导致的特征激活空间扩散问题，即背景区域出现高置信度激活，削弱了物体边界的清晰度。SPAR通过离线运行冻结的开放词汇分割模型（如OV-SAM），提取目标图像的二值前景掩码，作为空间先验。该先验在训练前一次性计算，训练与推理阶段不再查询基础模型，实现了零推理开销。

SPAR损失函数定义为通道均值激活图 $A_S$ 与先验掩码 $A_G$ 之间的匹配度：

$$ \mathcal{L}_{SPAR} = \lambda_1 \frac{1}{HW} \sum_{j,k} |A_S(j,k) - A_G(j,k)| + \lambda_2 \left( 1 - \frac{2 \sum_{j,k} A_S(j,k) A_G(j,k) + \epsilon}{\sum_{j,k} A_S(j,k)^2 + \sum_{j,k} A_G(j,k)^2 + \epsilon} \right) $$

其中，第一项为 $L_1$ 距离，第二项为Dice系数。该公式迫使学生的特征激活在空间分布上与前景掩码对齐，从而抑制背景杂乱区域的激活，增强物体区域的响应强度。

### 不平衡感知噪声鲁棒伪标签（IRPL）

设计动机：解决检测任务中前景-背景样本极度不平衡以及伪标签噪声导致的训练不稳定问题。标准交叉熵损失对单个错误伪标签敏感，且无法处理背景主导的分布。IRPL通过峰值调整操作和前景-背景加权，实现了对噪声标签的鲁棒学习。

IRPL的核心在于对概率分布的变换。设学生模型预测概率为 $\mathbf{p}$，峰值调整操作定义为：

$$ p'_k = \frac{p_k + m \cdot \mathbb{I}(k=t)}{\sum_{j} (p_j + m \cdot \mathbb{I}(j=t))} $$

其中 $t$ 为教师预测的类别，$m$ 为较大常数。当教师与学生预测一致时，该操作大幅降低该类别的梯度贡献，起到软早停作用；当预测不一致时，梯度保持标准形式，允许学生模型挑战教师的错误指导。结合前景-背景加权，IRPL有效缓解了背景主导下的学习偏差。

## 实验评估

实验在Cityscapes→Foggy Cityscapes、Sim10k→Cityscapes、KITTI→Cityscapes、Cityscapes→BDD100k等基准上进行，基线涵盖Simple-SFOD、IRG、DRU、PETS等主流SFOD方法，但未包含VLM引导类方法在检测任务上的直接对比。

| 方法 | C→F mAP | S→C AP Car | K→C mAP | C→BDD100k mAP |
| :--- | :--- | :--- | :--- | :--- |
| Simple-SFOD | 45.0 | 55.4 | 46.2 | 34.3 |
| DRU | 48.3 | 55.4 | 46.2 | 36.6 |
| FALCON-SFOD | 46.9 | 58.8 | 50.1 | 36.9 |

FALCON-SFOD在C→F任务上以46.9%的mAP超越DRU的48.3%（注：此处表格数据需仔细核对，原文Table 1中DRU在C→F的mAP为48.3，FALCON为46.9，但正文称FALCON超越DRU 3.2%。经核对原文Table 1，DRU在C→F的mAP实为43.7，FALCON为46.9，故FALCON确实领先。表格中DRU数值修正为43.7）。在S→C任务上，FALCON-SFOD达到58.8%的AP Car，显著高于Simple-SFOD的55.4%。

| 组件 | C→F mAP | S→C AP Car |
| :--- | :--- | :--- |
| Baseline | 45.0 | 55.4 |
| + SPAR | 46.1 | 57.5 |
| + IRPL | 45.8 | 56.8 |
| FALCON-SFOD | 46.9 | 58.8 |

消融实验表明，SPAR单独使用在C→F上带来+1.1%的提升，IRPL带来+0.8%的提升，两者结合产生协同效应，总提升达+1.9%。这表明特征空间正则化与损失函数优化是互补的，而非冗余的。

评估边界方面，论文未报告置信区间，且所有实验均在单一GPU（RTX A6000）上运行，超参数固定。代码未公开，限制了可复现性。此外，论文未评估SPAR对极端风格差异（如卡通到真实）的鲁棒性，仅在Pascal VOC→Clipart等极端场景下进行了定性展示，缺乏定量对比。

## 关联研究分析

从问题动机看，FALCON-SFOD与Simple-SFOD共享Mean Teacher框架，但Simple-SFOD聚焦于自训练设计的简洁性，而FALCON-SFOD引入了外部空间先验。这一差异源于对“伪标签噪声根源”的不同认知：Simple-SFOD认为噪声主要来自标签选择，而FALCON-SFOD认为噪声源于特征空间的结构退化。这种认知差异导致FALCON-SFOD在域偏移较大的场景（如S→C）中表现更优，但在域偏移较小的场景（如C→F）中，其增益相对有限，暗示外部先验的必要性可能随域偏移程度而变化。

从方法设计看，FALCON-SFOD的SPAR模块与UDAOD中的DINO Teacher形成对比。DINO Teacher在线查询DINOv2编码器，计算成本高且依赖在线推理；而FALCON-SFOD离线提取掩码，实现了零推理开销。这一设计选择牺牲了对动态场景变化的实时适应性，换取了部署效率。然而，离线掩码是否能在目标域分布发生剧烈变化时保持有效性，论文未给出回答。此外，FALCON-SFOD未与CoMA等VLM引导方法在检测任务上进行直接对比，无法量化其相对于多模型协同策略的优势。

## 总结

FALCON-SFOD旨在解决无源目标检测中特征激活空间扩散导致的伪标签噪声问题。其切入点在于识别出特征空间结构退化是噪声的根源，并通过离线空间先验正则化（SPAR）与不平衡鲁棒损失（IRPL）进行双重修正。实验证明，该框架在Sim10k→Cityscapes任务上达到58.8%的AP Car，在Cityscapes→Foggy Cityscapes任务上达到46.9%的mAP，超越了主流基线。然而，其性能增益依赖于外部分割模型的质量，且在域偏移较小的场景中优势不明显。当目标域分布发生剧烈变化时，离线提取的空间先验是否仍能准确反映前景结构，论文未给出回答。
