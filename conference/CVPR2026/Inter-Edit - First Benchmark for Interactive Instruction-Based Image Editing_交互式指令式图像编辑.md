# CVPR2026最新论文 ｜Inter-Edit: First Benchmark for Interactive Instruction-Based Image Editing ｜交互式指令式图像编辑

研究机构：北京邮电大学、北京航空航天大学

作者：Delong Liu、Haotian Hou、Zhaohui Hou 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f8d33de04e47)

> 指令式图像编辑旨在通过自然语言指令对图像进行精确、可控的视觉修改，其核心价值在于连接人类意图与视觉生成。现有方法在纯文本定位模糊与精确掩码标注负担之间难以兼顾，导致空间控制缺失与背景保持冲突。本文提出交互式指令式图像编辑（I3E）任务，通过“简洁文本+不精确空间引导”的组合范式，构建百万级数据集并设计区域感知评估指标。该工作确立了模糊空间意图解读的新基准，但自动化生成的掩码分布是否真实反映用户习惯仍存疑。

## 研究背景

当用户试图在图像特定位置添加物体时，纯文本指令因缺乏空间锚点而难以精确定位，而传统掩码方法要求像素级精确标注，显著增加了用户负担且易导致边界伪影。这一困境源于自然语言的空间描述模糊性与掩码几何精度的刚性要求之间的根本矛盾。指令式图像编辑（IBIE）早期依赖扩散模型微调建立文本-像素映射，但全局注意力机制缺乏空间约束，导致编辑目标区域时意外修改非目标区域。细粒度空间控制成为解决背景保持冲突的前提，但现有方案要么牺牲语义灵活性（拖拽方法），要么牺牲用户友好性（精确掩码方法）。

现有IBIE方法在空间控制上存在系统性缺陷：指令驱动方法（如InstructPix2Pix）受限于语言的空间模糊性，拖拽方法仅适用于几何变换而不适用于语义编辑，掩码方法虽提供显式空间控制但高度依赖掩码质量。近期大规模数据集采用分割模型生成掩码，但分割输出碎片化且面向像素级分析，与用户通常对应更宽泛、不精确区域的编辑意图存在偏差。这种偏差导致数据集无意中优化了分割精度而非直觉生成编辑，偏离了以用户为中心的设计初衷。本文切入点在于重新定义空间引导的精度要求：不追求像素级精确掩码，而是允许模型解读模糊的空间意图（如简单涂鸦），从而在降低用户标注负担的同时保持编辑的空间精确性。

## 核心方法

### 方法参照系

本文问题置于指令式图像编辑的通用流程中，关键差异在于输入模态从“文本-图像”二元映射扩展为“文本+空间提示-图像”三元映射。标准IBIE流程假设文本编码器具备足够空间理解能力，或依赖用户提供的精确掩码作为空间约束。本文挑战了这一假设，提出空间引导可以是模糊的、不精确的，模型需具备解读模糊空间意图的能力，而非仅执行像素级填充。

### 双提示系统与不精确掩码生成

设计动机：解决现有方法中“精确掩码标注负担重”与“纯文本定位不准”的二元对立。本文在数据生成流程中引入“Regenerate”步骤，利用多模态大语言模型（MLLM）反向推断编辑区域的边界框，而非直接依赖分割模型的像素级输出。具体而言，MLLM生成编辑指令后，由Qwen-Image-Edit执行编辑，随后将（源图像，编辑后图像）对反馈给MLLM，使其重新推断精确边界框并生成两种提示：细粒度提示（用于纯文本编辑）和简洁提示（用于交互式编辑）。掩码生成采用SAM-2分割后，通过形态学操作（腐蚀、膨胀、高斯模糊）将其“去精确化”，模拟用户手绘习惯。这一设计的核心在于掩码仅覆盖主要编辑主体，不包含主体在其他区域可能引发的变化（如光影、反射），符合典型用户标注实践。

$$
M_{refined} = \text{GaussianBlur}(\text{Dilate}(\text{Erode}(M_{SAM}, k), k), \sigma)
$$

该公式表示通过形态学操作和高斯模糊对SAM-2原始掩码进行后处理，生成符合用户直觉的不精确掩码。

### 区域感知评估指标

设计动机：解决传统CLIP分数无法捕捉空间推理、L1/SSIM与人类感知弱相关的问题。本文引入Alpha-CLIP，其视觉编码器$E_\alpha(I, A)$通过掩码$A$提取聚焦于掩码区域的图像嵌入，同时保持对整幅图像的关注。区域保真度$S_{in}$衡量掩码内生成内容的语义正确性，背景保持度$S_{out}$量化非掩码区域的内容保持：

$$
S_{in} = \mathcal{S}_{\text{cos}}(E_\alpha(I_e, M), E_\alpha(I_{gt}, M)), \quad S_{out} = \mathcal{S}_{\text{cos}}(E_\alpha(I_e, 1-M), E_\alpha(I_s, 1-M))
$$

其中$I_e$为编辑后图像，$I_{gt}$为真值图像，$I_s$为源图像，$M$为二元编辑掩码。此外，边界不连续性分数（BDS）通过Sobel梯度幅值$G(I) = |\nabla I|$量化掩码边界处的纹理和锐度连续性，定义内部过渡带$T_{in} = M \setminus \text{Erode}(M, k)$和外部过渡带$T_{out} = \text{Dilate}(M, k) \setminus M$，BDS为两带平均梯度幅值的绝对差。

## 实验评估

实验在自建Inter-Edit基准上进行，包含1,099,964个训练对和6,250个人工标注测试对。基线覆盖指令驱动（InstructPix2Pix）、掩码填充（Flux Edit）等路线，但缺失对最新空间感知强化学习方法（如SpatialFlow-GRPO、CoCoEdit）的直接对比，因任务定义不同（本文强调交互式模糊引导，后者强调精确区域奖励）。

| 方法 | SVQA |
| :--- | :--- |
| Inter-Edit (CJT) | 4.500 |
| Inter-Edit (CIA) | 4.300 |
| Inter-Edit (RNI) | 4.100 |
| Flux Edit | 2.768 |
| InstructPix2Pix | 2.373 |

Inter-Edit (CJT)以4.500的SVQA得分领先，较Flux Edit提升1.732，较InstructPix2Pix提升2.127，表明交互式模糊引导对定位精度的增益显著。消融实验显示，CJT（简洁提示+涂鸦）优于CIA（简洁提示+精确掩码）和RNI（细粒度提示+无空间引导），验证了“模糊空间引导”优于“精确掩码”和“纯文本”的有效性。

评估边界方面，SVQA指标依赖VLM评分，可能存在评估器偏差；测试集仅6,250对，规模较小；代码已开源（https://github.com/Delong-liu-bupt/Inter-Edit），但超参数和GPU配置未在正文中详细报告。

## 关联研究分析

从问题动机看，本文与MagicBrush（Yin et al., 2023）共享“高质量人工标注”的数据构建思路，但关键差异在于掩码精度要求。MagicBrush的掩码由人工精确标注，面向像素级分割；本文通过形态学操作将SAM-2输出“去精确化”，模拟用户手绘习惯。这一差异源于任务定义：MagicBrush评估局部编辑的像素一致性，本文评估交互式编辑的空间意图解读能力。根源在于用户意图的模糊性——实际用户标注通常不追求像素级精确，而是表达大致区域，本文的数据构建更贴近这一现实。

从方法设计看，本文与RePlan（Qu et al., 2025）同属细粒度空间控制路线，但空间约束机制不同。RePlan通过VLM思维链推理输出区域对齐的引导信号，由DiT解码器通过免训练注意力区域注入执行，依赖VLM的推理准确性；本文通过MLLM反向推断边界框生成不精确掩码，作为显式空间输入。差异根源在于空间信息的获取方式：RePlan依赖模型内部推理生成空间约束，本文依赖外部MLLM推断生成空间约束。前者可解释性强但计算开销大，后者数据构建自动化但依赖MLLM的推断准确性。

## 总结

本文要解决的核心矛盾是纯文本指令的空间模糊性与精确掩码标注负担之间的对立。切入点在于重新定义空间引导的精度要求：允许模型解读模糊的空间意图，而非依赖像素级精确掩码。通过“Regenerate”步骤和形态学后处理生成符合用户直觉的不精确掩码，构建百万级数据集，并设计区域感知评估指标。实验证明交互式模糊引导显著优于纯文本和精确掩码，SVQA得分4.500较Flux Edit提升1.732。边界在于自动化生成的掩码分布是否真实反映用户习惯，测试集规模较小，且缺失对最新空间感知强化学习方法的对比。当支持集增大到更大规模时，MLLM反向推断边界框的准确性是否足以支撑更复杂的空间意图解读，论文未给出回答。
