> 跨域少样本目标检测（CD-FSOD）的核心痛点在于预训练检测器在分布偏移下的优化不稳定与泛化失效。现有方法多依赖昂贵的数据生成或复杂架构扩展，而本文切入点在于挖掘预训练模型内部的表示多样性。通过引入混合集成解码器（HED）与统一渐进式微调策略，在不增加参数的前提下提升鲁棒性。该方法在大规模跨域基准上超越了依赖生成式增强的SOTA，但其对骨干网络预训练质量的依赖及缺乏原型匹配机制的对比，使其在极端少样本场景下的泛化边界仍存疑。

## 研究背景

当检测器从自然图像迁移至工业缺陷或文档内容等下游域时，源域与目标域在视觉风格、背景及物体形态上的系统性差异导致特征分布发生偏移。这种域偏移使得直接微调预训练检测器极易陷入过拟合，表现为对支持集样本的过度记忆而丧失对新类别的泛化能力。为缓解此问题，少样本目标检测（FSOD）通常假设源域与目标域分布一致，但现实中的跨域场景打破了这一假设，要求模型在极少监督信号下同时应对数据稀缺与分布差异的双重挑战。

主流解决路线分为两类：一是基于原型匹配与度量学习，通过冻结骨干网络并计算支持集特征均值来构建类别表示，如DE-ViT与PDA，其优势在于免疫基类过拟合，但受限于支持集特征质量与几何失配；二是基于数据增强与生成式扩展，如Domain-RAG利用FLUX生成合成数据以覆盖域差异，虽提升了多样性，但计算开销巨大且生成图像可能引入细微伪影。本文的切入点在于，既然预训练模型已具备强大的表示能力，问题或许不在于数据不足，而在于微调策略未能充分激发模型内部的多样性。因此，本文摒弃了外部数据生成，转而关注解码器结构与训练流程的内在优化。

## 核心方法

### 方法参照系

本文基于Transformer-based Object Detection (DETR) 范式，其标准流程为：骨干网络提取特征，编码器处理视觉Token，解码器通过自注意力与交叉注意力迭代更新查询向量，最终预测边界框与类别。与标准DETR的关键差异在于，本文针对少样本场景下的过拟合问题，重构了解码器的层间交互方式，并引入了分阶段的参数解冻策略。

### 混合集成解码器

标准DETR解码器采用串行堆叠结构，各层查询向量依次传递，这种确定性流程在少样本数据下易导致预测收敛于单一解，缺乏鲁棒性。本文提出混合集成解码器（HED），将解码器分为前 $K$ 层串行堆叠与后 $L-K$ 层并行分支。并行分支共享第 $K$ 层的输出 $Q^{[K]}$ 作为输入，但引入随机去噪查询初始化以打破输入同质性。具体而言，对于并行分支中的去噪查询，以概率 $\tau$ 重新初始化：

$$ Q_{dn}^{parallel} = \begin{cases} Q_{init} & \text{with prob. } \tau \\ Q_{dn}^{[K]} & \text{with prob. } 1-\tau \end{cases} $$

这一设计使得每个并行分支在训练时接收不同的去噪输入，从而在推理时聚合出多样化的预测结果。其物理含义在于，通过隐式集成多个子网络（由不同初始化的去噪查询驱动），HED在不增加参数量的情况下，模拟了深度集成（Deep Ensembles）的效果，增强了模型对分布偏移的鲁棒性，避免了单一解码路径的过拟合风险。

### 统一渐进式微调

直接全量微调预训练检测器在少样本场景下易导致灾难性遗忘与优化不稳定。本文采用两阶段渐进式微调策略：第一阶段冻结编码器，仅微调解码器；第二阶段解冻所有参数进行全量微调。阶段切换由Plateau学习率调度器自动触发，当验证集性能停滞时，学习率衰减并触发参数解冻。该策略的设计动机在于，先稳定解码器的预测头，再逐步适配骨干特征，避免了早期训练阶段因特征剧烈变化导致的过拟合。结合随机翻转、颜色抖动等基础数据增强，该框架无需针对特定数据集进行复杂的超参数搜索，实现了跨域场景下的统一适配。

## 实验评估

| 基准 | 方法 | 1-shot mAP | 5-shot mAP | 10-shot mAP |
| :--- | :--- | :--- | :--- | :--- |
| CD-FSOD | Domain-RAG | 33.6 | - | - |
| CD-FSOD | **Ours (HED)** | **34.9** | **45.0** | **47.9** |
| ODinW-13 | SAM3 | 63.0 | 69.1 | 71.6 |
| ODinW-13 | **Ours (HED)** | **63.1** | 67.6 | 68.6 |
| RF100-VL | MMGDINO-L | - | - | 33.6 |
| RF100-VL | **Ours (HED)** | - | - | **41.9** |

实验在CD-FSOD、ODinW-13及RF100-VL三个跨域基准上进行，基线覆盖Domain-RAG、SAM3、GroundingDINO 1.5 Pro等强模型。在CD-FSOD上，本文方法在1/5/10-shot设定下均超越Domain-RAG，表明无需生成式数据增强即可达到更优性能。在ODinW-13上，本文1-shot性能（63.1）略优于SAM3（63.0），但在5/10-shot设定下落后，显示其在高样本量下的优势减弱。在RF100-VL上，本文10-shot性能（41.9）显著超越基线MMGDINO-L（33.6），验证了渐进式微调在极端跨域场景下的有效性。

消融实验显示，HED中并行层数与去噪查询重初始化率 $\tau$ 对性能影响显著。1-stacked+5-parallel结构配合 $\tau=0.5$ 取得最佳平衡，而全并行结构（6-parallel）性能最差，证明串行层对查询特征稳定性的必要性。此外，$\tau=0$ 时模型在OOD样本上产生过度自信预测，表明随机去噪初始化对鲁棒性的关键作用。

评估边界方面，本文未报告计算效率指标（FPS、内存占用），且RF100-VL上巨大性能差距可能源于基线未充分调优。代码已开源，但超参数细节（如Plateau调度器阈值）在正文中未完全披露，复现需依赖附录。

## 关联研究分析

从问题动机看，本文与Domain-RAG形成鲜明对比。Domain-RAG依赖FLUX生成合成数据以覆盖域差异，计算成本高且存在伪影风险；本文则通过HED挖掘预训练模型内部多样性，无需外部数据生成。这一差异根源在于对“域偏移”的应对策略：前者试图扩展数据分布，后者试图增强模型对分布变化的鲁棒性。本文证明，在预训练模型足够强大的前提下，内部多样性挖掘可能比外部数据增强更高效。

从方法设计看，本文与DE-ViT等原型匹配方法存在路线分歧。DE-ViT冻结骨干并计算原型，避免微调带来的基类过拟合；本文则采用全量微调+HED，依赖渐进式策略缓解过拟合。这一差异暗示，在跨域场景下，微调可能比冻结更具优势，因为域偏移需要特征空间的适应性调整。然而，本文未与PDA等最新原型匹配方法进行直接对比，无法判断HED在极端少样本（1-shot）下是否优于原型匹配。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文针对跨域少样本检测中预训练模型微调的过拟合与泛化失效问题，提出混合集成解码器（HED）与统一渐进式微调策略。通过并行解码分支与随机去噪查询初始化，HED在不增加参数的前提下提升了预测多样性；渐进式微调则通过分阶段参数解冻稳定了优化过程。实验表明，该方法在CD-FSOD与RF100-VL上超越依赖生成式增强的SOTA，尤其在RF100-VL 10-shot设定下取得41.9的mAP，显著优于基线。然而，本文在ODinW-13高样本量设定下性能落后于SAM3，且未与原型匹配方法进行直接对比，暴露了其在高数据量场景下的适应性局限。当支持集增大到5-shot时，HED的多样性增益是否被全量微调的过拟合风险抵消，论文未给出回答。
