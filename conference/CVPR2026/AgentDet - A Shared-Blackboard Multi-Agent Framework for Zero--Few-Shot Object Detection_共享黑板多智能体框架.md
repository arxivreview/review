# CVPR2026最新论文 ｜AgentDet: A Shared-Blackboard Multi-Agent Framework for Zero-/Few-Shot Object Detection ｜共享黑板多智能体框架

研究机构：清华大学

作者：Haolin Li、Yaohua Wang、Ze Yan 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_843d3b266b85)

> 零样本与少样本目标检测（Zero-/Few-Shot Object Detection, ZS/FSOD）旨在解决新类别标注极度稀缺时的精准定位难题。现有方法或依赖大规模视觉预训练导致基类过拟合，或将视觉-语言模型（Vision-Language Models, VLMs）仅作静态分类器，缺乏对片段级视觉证据的结构化管理与推理能力。AgentDet 提出共享黑板多智能体框架，通过四个协作智能体维护知识库与黑板状态，利用大语言模型（Large Language Models, LLMs）进行语言推理与自细化，统一了零样本与少样本检测流程。该框架在高 shot 数设定下表现优异，但在低 shot 数下未显著超越最新原型匹配方法，且计算开销较大。

## 研究背景

当检测器面对新类别时，其训练域与测试域的数据分布出现系统性差异，这一现象称为分布偏移。分布偏移导致传统分类器决策边界失效，而实际场景中往往能获取少量目标域样本，这构成了小样本学习的条件：仅凭每个类别极少量标注样本泛化到新任务。解决此类问题的经典框架是原型网络，它计算各类别支持样本的特征均值作为“原型”，再通过距离度量完成分类。

FSOD/ZSOD 的核心矛盾在于有限监督信号与复杂开放世界感知需求之间的张力。早期研究以微调与元学习为主线，试图通过基类预训练与轻量适配来缓解数据不足，但基类过拟合与特征空间失配问题长期制约着泛化性能。随着视觉基础模型（Vision Foundation Models, VFMs）的成熟，研究重心转向多模态协同，但现有 VLM 方法通常依赖大规模视觉预训练，与 FSOD 测试新类别泛化的目标不一致，且多数工作将零样本与少样本任务分开处理，缺乏统一框架。AgentDet 的切入点在于利用 LLM 的跨模态推理能力，通过结构化视觉证据的累积与检索，实现零样本到少样本的无缝切换。

## 核心方法

### 方法参照系

传统 FSOD 方法通常采用两阶段微调策略，先基于基类预训练检测器，再针对新颖类进行轻量级微调。本文问题与该通用流程的关键差异在于：不依赖端到端检测器的微调，而是通过多智能体协作维护视觉知识库，利用 LLM 进行语言推理与定位，实现了训练无关或轻训练的零样本/少样本统一框架。

### 共享黑板与知识库机制

AgentDet 区分两个互补的内存组件：持久化知识库（Knowledge Base, KB）用于长期存储视觉证据，瞬态共享黑板（Shared Blackboard, Board）用于单图像协调。KB 存储补丁级条目，包含视觉嵌入、空间描述符和语义属性；Board 聚合智能体在单次推理中发布的线索和控制标志。在时间步 $t$，Board 状态表示为：

$$ M^{(t)}_{board} = (H^{(t)}, R^{(t)}, B^{(t)}, \omega^{(t)}, r^{(t)}_{scout}, r^{(t)}_{pinner}, p^{(t)}_{m}) $$

其中 $H$ 为整体文本线索，$R$ 为从 KB 检索的片段级参考，$B, \omega$ 为预测框和置信度，$r_{scout}, r_{pinner}$ 指示智能体就绪状态，$p_m$ 门控安全 KB 更新。这一设计解决了传统方法中支持集原型与查询 RoI 特征在几何和语义上错位的问题，通过结构化存储与检索实现特征对齐。

### 伪增量学习与 LLM 推理

Agent-Curator 通过伪增量学习维护 KB：训练时裁剪标注区域并过分割获得高纯度补丁，推理时直接过分割整个查询图像，依赖检索和一致性门控选择信息片段。一致性门控定义为：

$$ cons(k, c) = \mathbb{1}\left[\max_i M_{i,k} > \epsilon_{search} \land \max_i S_{i,c} > \vartheta\right] $$

当存在 $(k, c) \in R \times C_{target}$ 满足 $cons(k, c) = 1$ 且属性分数 $s_{p,a} > \epsilon_{seg}$ 时，允许安全写入 KB。Agent-Judge 消费黑板上的 $C_{target}$ 和 $R_{ref}$，通过 LLM 进行语言推理，并应用自细化步骤提升定位质量。该设计解决了 VLM 缺乏外部少样本监督集成能力的问题，通过伪增量机制实现零样本到少样本的平滑过渡，无需架构变更。

## 实验评估

实验在 PASCAL VOC 和 MS COCO 数据集上进行，对比了 TFA、FM-FSOD、LLMdet 等基线，但缺失 PDA、TSMa 等最新原型匹配方法。AgentDet-Qwen3-8b 在 PASCAL VOC 10-shot Novel Split 1 下取得 69.6% mAP，在 COCO 30-shot 下达到 37.5%，较 FM-FSOD 提升 0.5%。

| 方法 | PASCAL VOC 10-shot (Split 1) | COCO 30-shot |
| :--- | :--- | :--- |
| FM-FSOD | 61.2 | 37.0 |
| LLMdet | 60.8 | - |
| AgentDet-Qwen3-8b | 69.6 | 37.5 |

消融实验显示，移除 Q-former 微调导致 mAP 下降 8.2%，禁用知识库集成导致下降 19.1%，移除 LLM 微调则性能降至 0%。移除多尺度分割使查询阶段准确率降至 56.9%，移除最小包围矩形导致性能显著下降至 49.7%。这些结果证实了各模块在少样本检测中的关键作用，尤其是知识库集成和 LLM 适配的必要性。

评估边界方面，论文未报告计算效率指标（FPS、内存占用），且未提供代码 URL。评估协议局限于同域基准，未专门针对跨域场景设计，可能高估了方法在域偏移下的鲁棒性。

## 关联研究分析

从问题动机看，AgentDet 与 PDA 均旨在缓解基类过拟合，但 PDA 通过冻结骨干与原型匹配实现，而 AgentDet 依赖 LLM 推理与结构化知识库。PDA 在 1-shot 下取得 31.0 nAP，与 AgentDet 的 1-shot 性能持平，但 AgentDet 在高 shot 数下优势明显，这暗示 LLM 推理在样本充足时能更好地利用视觉证据，而在样本稀缺时可能受限于知识库的噪声累积。

从方法设计看，AgentDet 与 FM-FSOD 同属 VFM 融合路线，但 FM-FSOD 主要使用 LLM 作为静态分类器，未充分利用其推理能力，而 AgentDet 通过多智能体协作实现了动态推理与自细化。与 LLMdet 相比，AgentDet 引入了结构化视觉证据管理，解决了 LLM 缺乏实例级定位能力的问题。然而，AgentDet 的计算开销显著高于纯视觉原型匹配方法，这在边缘设备部署中可能成为瓶颈。

## 总结

AgentDet 旨在解决零样本与少样本检测中数据稀缺与灾难性遗忘的核心矛盾，通过共享黑板多智能体框架利用 LLM 推理与结构化视觉证据，实现了零样本到少样本的统一。实验表明，该方法在 PASCAL VOC 10-shot 下取得 69.6% mAP，在 COCO 30-shot 下达到 37.5%，验证了 LLM 推理在高 shot 数设定下的有效性。然而，论文未报告计算效率指标，且评估局限于同域基准，未验证跨域场景下的鲁棒性。当支持集增大到 5-shot 时，知识库的噪声累积是否会导致性能饱和，论文未给出回答。
