# CVPR2026最新论文 ｜Beyond the Static-World: Lifelong Learning for All-in-One Medical Image Restoration ｜医学影像全合一恢复中的持续学习框架

作者：Shihao Shan、Hongying Liu、Fanhua Shang 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_be766e144fe3)

> 全合一医学影像恢复（All-in-One Medical Image Restoration, AiO-MIR）旨在通过单一模型处理MRI超分、CT去噪与PET合成等多模态任务，但现有方法均假设数据静态可用，无法应对临床场景中数据流式到达与模态缺失的动态现实。本文指出，模态间的空间梯度冲突会加剧时间维度的灾难性遗忘，二者必须联合求解。ROME框架通过“解耦-优化-整合”策略，先以对抗平衡建立模态不变流形，再在特征空间执行自适应知识整合。该框架在持续学习基准上显著降低了性能衰减，但其验证局限于内部医学数据集，缺乏跨域通用性证据。

## 研究背景

当共享骨干网络同时处理MRI与CT数据时，两种模态特有的噪声模式（如CT条纹伪影与MRI K空间噪声）在浅层特征中相互纠缠，导致梯度更新方向冲突。这种空间维度的模态干扰若未解决，模型在顺序学习新域时，旧域权重会被新域梯度覆盖，引发灾难性遗忘。因此，解决持续学习的前提是构建一个剥离模态特异性风格、仅保留解剖结构内容的统一特征空间。

现有全合一模型如AMIR与DiffCode虽通过任务路由或码本先验缓解了静态多任务干扰，但均基于“静态世界假设”，即所有机构数据同时可用。这一假设与临床实际严重脱节：新机构引入数据分布偏移，或完全缺失某一模态（如仅有MRI无CT）。在模态缺失场景下，若特征空间未解耦，缺失模态的缺席将导致整个特征空间崩溃，使其他模态性能骤降。ROME的切入点在于论证：模态不变流形是任何特征整合策略生效的必要前提，只有先解决空间冲突，时间维度的知识保留才具有稳定性。

## 核心方法

### 方法参照系

本文问题属于持续学习中的回放法（Rehearsal-based）范畴，标准流程为：维护记忆缓冲区存储旧域样本，在新域训练时混合旧域数据进行联合优化。关键差异在于，传统回放法在像素空间进行刚性混合，且未处理多模态间的特征纠缠，导致在模态缺失场景下回放数据无法有效锚定特征空间。

### 模态不变解耦对抗平衡（MIDAB）

MIDAB模块位于共享浅层提取器 $G_f$ 之后，旨在将纠缠的特征分解为模态不变内容 $f_{content}$ 与模态特异性风格 $f_{mod}$。设计动机在于：标准L1损失仅激励保留内容，无法惩罚导致梯度冲突的风格特征。MIDAB引入模态判别器 $D_{mod}$ 与梯度反转层，构建对抗平衡游戏。其核心损失函数为：

$$
\mathcal{L}_{adv} = -\mathcal{L}_{ce}^{mod} = -\text{CE}(D_{mod}(G_f(I_{LQ})), y_{mod})
$$

该公式的物理含义是：特征提取器 $G_f$ 试图最大化判别器的不确定性（即擦除模态信息），而重建损失 $\mathcal{L}_1$ 作为“内容保留力”阻止 $G_f$ 丢弃解剖结构。二者博弈迫使网络收敛至纳什均衡，生成紧凑的模态不变流形，为后续整合提供稳定锚点。

### 自适应特征整合（AFC）

AFC模块在MIDAB生成的统一流形上执行知识整合，替代传统像素级混合。设计动机在于：像素级混合对表面变化敏感且效率低，而特征级插值能更精准地保留旧域知识。AFC通过动态预测网络感知新旧域分布差异，计算最优整合点。其整合过程可表示为：

$$
f_{cons} = \alpha \cdot f_{new} + (1-\alpha) \cdot f_{old}
$$

其中 $\alpha$ 由预测网络动态生成。为防止退化为简单平均，引入多样性损失 $\mathcal{L}_{div}$ 引导网络探索判别性融合策略。这一机制确保旧知识以非平凡方式融入新结构，在模态缺失时仍能维持特征空间的完整性。

## 实验评估

实验在内部医学数据集上进行，涵盖5个域（D1-D5），包含分布偏移与模态缺失场景。基线覆盖Restormer、AirNet、AMIR等主流全合一模型，但缺失扩散类生成式基线（如LucidFlux），且未包含自然图像基准，限制了跨域对比。

| 方法 | Static PSNR (dB) | Lifelong PSNR (dB) | 性能衰减 (dB) |
| :--- | :--- | :--- | :--- |
| Restormer | 34.1562 | 30.3885 | 3.77 |
| AMIR | 34.2822 | 31.4139 | 2.87 |
| ROME | 34.9399 | 32.3575 | 2.58 |

ROME在静态设置下以34.94 dB领先，在持续学习设置下以32.36 dB超越次优的AMIR（31.41 dB）。其性能衰减仅2.58 dB，显著低于Restormer的3.77 dB，验证了MIDAB与AFC协同抑制遗忘的有效性。

| 组件 | Lifelong PSNR (dB) | 增量 (dB) |
| :--- | :--- | :--- |
| Baseline | 30.5142 | — |
| + MIDAB | 30.6874 | +0.17 |
| + ER | 30.7694 | +0.08 |
| + AFC | 31.2144 | +0.45 |
| + Ldiv | 32.3575 | +1.14 |

消融显示，MIDAB单独贡献微弱（+0.17 dB），证实解耦本身不足以阻止遗忘。AFC带来+0.45 dB提升，而多样性损失 $\mathcal{L}_{div}$ 贡献最大（+1.14 dB），表明强制非平凡融合策略是性能跃升的关键。

评估指标仅包含PSNR/SSIM/RMSE，缺乏感知质量指标（如LPIPS），且未报告计算效率。代码未公开，超参数（如 $\alpha=0.01, \beta=0.15$）固定，可复现性受限。

## 关联研究分析

从问题动机看，ROME与AMIR同属全合一医学影像恢复，但AMIR聚焦静态多任务路由，未考虑数据流式到达。ROME将问题扩展至持续学习，指出模态缺失是比分布偏移更严峻的挑战。这一差异源于临床场景的现实约束：机构间数据共享存在隐私与合规壁垒，导致模态不可用成为常态。AMIR的静态假设在此场景下失效，而ROME通过模态不变流形解决了这一盲区。

从方法设计看，ROME与通用图像恢复中的PromptIR形成对比。PromptIR通过可学习提示编码退化信息，依赖显式退化标签或分类器；ROME则通过对抗平衡隐式解耦模态风格，无需显式标签。这一差异源于医学影像的模态特异性：MRI与CT的噪声模式具有物理可解释性，适合对抗解耦；而自然图像退化类型多样且无明确物理边界，提示学习更灵活。ROME未采用生成式先验，仅用判别式L1损失，这可能限制了细节恢复能力，但确保了医学影像所需的保真度。

## 总结

ROME旨在解决全合一医学影像恢复中模态冲突与灾难性遗忘的耦合问题。现有方法如AMIR仅处理静态多任务干扰，无法应对模态缺失下的特征空间崩溃；ROME通过MIDAB建立模态不变流形，为AFC提供稳定锚点，从而在特征空间执行自适应整合。实验证明，ROME在持续学习设置下将性能衰减从3.77 dB（Restormer）降至2.58 dB，且多样性损失贡献了最大增量（+1.14 dB）。其边界在于验证局限于内部医学数据集，缺乏自然图像基准对比，且未评估生成式先验的潜在增益。当支持集规模扩大或模态缺失比例增加时，AFC的动态插值系数 $\alpha$ 是否仍需多样性损失引导，论文未给出回答。
