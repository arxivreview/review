# CVPR2026最新论文 ｜Degradation-Consistent Test-Time Adaptation for All-in-One Image Restoration ｜退化一致性测试时适应

研究机构：厦门大学、香港理工大学

作者：Ni Tang、Shenghao Nie、Xiaotong Luo 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_bd190f5deaf0)

> 全合一图像恢复（AiOIR）模型在训练分布外的真实退化场景下性能崩溃，现有静态路由或提示学习机制无法应对未知的分布偏移。本文切入点在于利用“同一场景不同退化版本应映射至同一干净图像”的物理一致性，构建无源数据、无标签的自监督适应框架。通过扩散模型生成伪退化对并选择性更新敏感参数，DCTTA 实现了跨域鲁棒性提升。其价值在于证明了 TTA 在像素级回归任务中的可行性，但依赖扩散模型生成伪标签的可靠性与计算开销仍是存疑点。

## 研究背景

当预训练模型面对未见过的退化分布时，其决策边界因训练数据与测试数据的系统性差异而失效，这一现象即分布偏移。在图像恢复任务中，分布偏移导致模型输出过平滑或产生伪影，而实际场景中往往无法获取目标域的真值标签，这构成了无监督测试时适应（Test-Time Adaptation, TTA）的核心约束：仅凭无标签测试样本，动态调整模型参数以对齐目标域分布。解决此问题的经典框架是伪标签自监督，它利用模型自身预测作为监督信号，但像素级回归任务中伪标签的噪声累积效应远大于分类任务，导致适应过程不稳定。

AiOIR 旨在通过单一模型处理多种退化，主流路线如 AirNet 和 PromptIR 依赖显式退化感知或提示机制，但均隐含闭集假设，即测试退化类型在训练集中已覆盖。当测试集出现训练分布外的退化（如真实雨雾混合、特定传感器噪声）时，这些静态机制失效，性能显著下降。现有 TTA 研究多集中于分类或分割任务，直接迁移至 AiOIR 面临两大瓶颈：一是缺乏可靠的像素级伪监督信号，二是在线更新易破坏预训练知识导致灾难性遗忘。本文针对这一空白，提出 DCTTA 框架，通过退化一致性约束与参数重要性筛选，实现无源数据条件下的稳定适应。

## 核心方法

### 方法参照系

本文问题属于无源数据域适应（Source-Free Domain Adaptation）范畴，但区别于分类任务，AiOIR 是像素级回归任务，缺乏类别中心或原型等离散监督信号。通用 TTA 流程通常包含伪标签生成、损失计算与参数更新，本文的关键差异在于引入扩散模型生成伪退化对，并利用 Fisher 信息矩阵冻结关键参数，以解决回归任务中伪标签噪声大与参数更新不稳定的矛盾。

### 退化一致性自监督

通常做法是利用模型预测作为伪标签直接优化，但像素级噪声会导致梯度方向错误。本文创新在于利用“干净一致性”假设：同一场景的不同退化版本应恢复至同一干净图像。通过训练扩散模型 RDDM 生成伪退化图像 $x_{sd}$，与原始输入 $x_{in}$ 构成配对，强制模型对两者输出保持一致。其自监督损失定义为：

$$ L_s(y_{in}, y_{sd}) = \lambda_{cons} \| y_{in} - y_{sd} \|_1 + \lambda_{per} \sum_l \| \phi_l(y_{in}) - \phi_l(y_{sd}) \|_2^2 $$

该公式通过 $\ell_1$ 范数约束像素一致性，通过 VGG 特征约束感知语义一致性，利用退化生成的多样性提供比单点伪标签更鲁棒的监督信号，缓解了单一伪标签噪声导致的过拟合。

### 参数重要性选择

通常做法是更新所有参数，但在线优化易覆盖预训练知识。本文创新在于引入测试时重要参数选择（TIPS）策略，基于 Fisher 信息矩阵对角近似计算参数重要性，仅更新退化敏感参数。参数重要性 $\omega(\theta_i)$ 定义为：

$$ \omega(\theta_i) = \frac{1}{|D|} \sum_{x_{in} \in D} \left( \frac{\partial L_c(x_{in})}{\partial \theta_i} \right)^2 $$

其中 $L_c$ 为增强一致性损失。通过冻结重要性高于阈值 $\tau_\rho$ 的参数，TIPS 在适应新分布的同时保留了源域的核心恢复能力，解决了全参数更新导致的灾难性遗忘问题，确保了适应过程的稳定性。

## 实验评估

实验在 Kodak24、O-HAZY、Rain100H 等真实世界域偏移数据集上进行，基线包括 AirNet、PromptIR、DFPIR 等经典 AiOIR 模型，但缺失 MoE 类（如 MiM-DiT）和扩散恢复类（如 LucidFlux）基线，限制了与最新 SOTA 的直接对比。

| 方法 | Rain100H PSNR (dB) | Rain100H SSIM | PromptIR 基线 PSNR (dB) |
| :--- | :--- | :--- | :--- |
| PromptIR | 15.64 | 0.500 | 15.64 |
| PromptIR+DCTTA | 20.21 | 0.663 | 15.64 |
| DFPIR | 16.27 | 0.523 | - |
| DFPIR+DCTTA | 20.13 | 0.649 | - |

DCTTA 在 Rain100H 上为 PromptIR 带来 4.57 dB 的 PSNR 提升，为 DFPIR 带来 3.86 dB 提升，表明该框架对强空间结构退化（如雨纹）适应效果显著。

| 消融配置 | Rain100H PSNR (dB) | Rain100H SSIM |
| :--- | :--- | :--- |
| Full Model | 20.21 | 0.663 |
| w/o TIPS | 14.24 | 0.487 |
| w/o DA | 19.57 | 0.606 |
| w/o EMA | 19.87 | 0.609 |

消融实验显示，移除 TIPS 导致 PSNR 骤降 5.97 dB，表明参数冻结是稳定适应的关键；移除数据增强（DA）或指数移动平均（EMA）分别导致 0.64 dB 和 0.34 dB 的性能下降，说明伪标签质量与教师模型更新速度对最终性能有显著影响。

评估仅使用 PSNR 和 SSIM，缺乏 LPIPS 等感知质量指标，无法全面评估生成式伪标签对感知真实感的影响。代码已开源，超参数（如 $\rho=0.4$）固定，但未报告不同退化类型下 $\rho$ 的敏感性分析，可复现性受限于单一 GPU 配置（RTX 3090）。

## 关联研究分析

从问题动机看，DCTTA 与 TAO 同属扩散辅助 TTA，但 TAO 依赖扩散模型进行推理，计算开销大且引入幻觉风险；DCTTA 仅将扩散模型用于生成伪退化对，推理时移除扩散模型，效率更高。这一差异源于任务特性：AiOIR 需要像素级精度，扩散推理的不确定性会直接污染恢复结果，而生成伪退化对仅用于训练阶段，不影响推理稳定性。

从方法设计看，DCTTA 借鉴了 CoTTA 的 EMA 机制，但 CoTTA 针对分类任务使用熵最小化作为伪标签置信度，而 DCTTA 针对回归任务使用退化一致性损失。这一差异源于回归任务缺乏离散类别中心，无法直接计算熵，必须依赖物理一致性约束。然而，DCTTA 未探索多模态引导的退化生成，仅依赖单模态扩散模型，这可能限制了其对复杂混合退化的适应能力，查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

DCTTA 旨在解决 AiOIR 模型在分布偏移下的泛化失效问题，其切入点在于利用退化一致性假设构建无源数据自监督信号，并通过 Fisher 信息矩阵冻结关键参数以稳定适应过程。该方法在 Rain100H 上实现了 4.57 dB 的 PSNR 提升，证明了 TTA 在像素级回归任务中的有效性。然而，实验仅覆盖单一退化类型，未验证在复杂混合退化场景下的鲁棒性，且依赖扩散模型生成伪标签的计算开销（32.25s 适应时间）在边缘部署中可能成为瓶颈。当测试集包含多种未知混合退化时，单一退化生成器能否提供足够多样的伪监督信号，论文未给出回答。
