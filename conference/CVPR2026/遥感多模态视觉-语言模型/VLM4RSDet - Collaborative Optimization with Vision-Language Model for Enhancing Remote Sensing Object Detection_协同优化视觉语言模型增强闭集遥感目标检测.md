# CVPR2026最新论文 ｜VLM4RSDet: Collaborative Optimization with Vision-Language Model for Enhancing Remote Sensing Object Detection ｜协同优化视觉语言模型增强闭集遥感目标检测

研究机构：国防科技大学

作者：Shuohao Shi、Qiang Fang、Xin Xu

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_24272e888d1a)

> 闭集遥感目标检测长期受限于固定类别下的精度瓶颈，而现有视觉语言模型（VLM）虽具备丰富先验知识，却因推理开销大且专为开放词汇设计，无法直接部署于对实时性要求严苛的闭集场景。VLM4RSDet 抓住了“训练时利用 VLM 先验、推理时丢弃 VLM”这一被忽略的解耦点，通过共享特征金字塔网络（FPN）的多尺度特征，将 VLM 的语言建模损失与传统检测器的分类、回归损失联合优化。该方法在 VisDrone2019 数据集上将 mAP0.5:0.95 提升至 42.0，超越了当前最优基线，且未增加任何推理延迟。其价值在于证明了 VLM 先验可被“蒸馏”至轻量检测头，但该方法是否能在更复杂的密集小目标场景中保持增益，仍需进一步验证。

## 研究背景

遥感图像中目标尺度差异巨大且背景复杂，传统检测器依赖卷积特征提取，易在小目标上丢失有效信息。特征金字塔网络（FPN）通过多尺度特征融合缓解此问题，但受限于局部感受野，难以捕捉全局上下文。视觉语言模型（VLM）通过大规模图文对预训练，积累了丰富的语义先验，能理解复杂场景描述，但其自回归解码机制导致推理速度慢、参数量大，与遥感检测对实时性的要求相悖。

闭集遥感检测的核心矛盾在于精度与效率的权衡。主流路线分为两类：一是改进传统检测器，如通过自适应旋转卷积或大核卷积增强特征，但缺乏语义先验，精度存在瓶颈；二是直接应用 VLM，如 Florence-2 或 Grounding DINO，虽能利用语言先验，但推理成本高昂，且专为开放词汇设计，在固定类别的闭集任务中精度反而低于专用检测器。VLM4RSDet 的切入点在于打破“VLM 必须参与推理”的固有假设，探索如何将 VLM 的语义知识在训练阶段注入传统检测器，从而在推理阶段仅保留轻量检测架构。

## 核心方法

### 协同优化架构参照系

本文问题属于闭集目标检测，标准流程为“骨干网络提取特征→FPN 融合→检测头预测”。与端到端 VLM 检测器（如 Florence-2）的关键差异在于：VLM4RSDet 不将 VLM 作为推理组件，而是将其作为训练阶段的“语义正则化器”，通过共享 FPN 特征实现知识迁移。

### 全局-局部交叉注意力（GLCA）

传统 VLM 处理视觉特征时，往往将图像压缩为固定数量的 Token，导致多尺度细节丢失。GLCA 模块旨在解决 VLM 对遥感图像中局部小目标感知不足的问题。其设计动机是：FPN 的高层特征（$P_5$）包含全局语义，而低层特征（$P_1-P_4$）保留局部细节，直接拼接会导致语义与细节的冲突。GLCA 将低层特征 $N_i$ 作为 Query，高层特征 $N_5$ 作为 Key 和 Value，通过注意力机制融合全局上下文：

$$ T_i^v = \text{Softmax}\left(\frac{N_i N_5^T}{\sqrt{d}}\right)N_5 + N_i \quad (i=1,2,3,4) $$

该公式表明，每个局部特征 $N_i$ 都会根据其与全局特征 $N_5$ 的相似度，动态聚合全局语义信息，从而增强 VLM 对复杂场景的理解能力。

### 可学习层级预测策略（LHPS）

VLM 在预测密集分布目标时，常因 Token 限制或注意力分散导致漏检。LHPS 针对此失效，将图像内所有目标按尺寸升序排序，并引入可学习参数 $\beta_i$ 动态分配各层级预测的目标数量 $M_i$：

$$ M_i = \left\lceil \frac{\beta_i}{\sum_{j=1}^{5}\beta_j} \times M \right\rceil $$

其中 $M$ 为图像内目标总数。该策略通过层级化预测，让 VLM 在不同 FPN 层级上专注于不同尺度的目标，避免了单一层级预测所有目标时的信息过载，提升了密集场景下的输出准确性。

## 实验评估

实验在 AI-TOD、VisDrone2019、DOTA-v1.0、DOTA-v1.5 和 MS COCO 2017 五个数据集上进行，基线涵盖 CNN/Transformer 检测器（如 DetectoRS、DN-FPN）及 VLM 检测器（如 Florence-2、Grounding DINO）。

| 数据集 | 方法 | mAP0.5:0.95 | mAP0.5 |
| :--- | :--- | :--- | :--- |
| VisDrone2019 | DN-FPN | 37.8 | 62.7 |
| VisDrone2019 | Faster R-CNN w/ VLM4RSDet | 42.0 | 62.5 |
| AI-TOD | DetectoRS w/ VLM4RSDet | 28.5 | 59.9 |
| DOTA-v1.0 | LEGNet-S w/ VLM4RSDet | - | 84.07 |

在 VisDrone2019 上，VLM4RSDet 基于 Faster R-CNN 的变体以 42.0 的 mAP0.5:0.95 超越 DN-FPN 的 37.8，且在推理 FPS 上保持 51.7，与基线持平。在 DOTA-v1.0 上，基于 LEGNet-S 的变体取得 84.07 的 mAP0.5，显著优于 LEGNet-S 基线的 80.03。

| 模块组合 | mAP0.5:0.95 | mAP0.5 |
| :--- | :--- | :--- |
| Baseline (DetectoRS) | 25.7 | 41.7 |
| + New Structure | 28.5 | 46.5 |
| + GLCA | 29.8 | 48.3 |
| + LHPS | 30.2 | 49.8 |
| + All | 31.4 | 53.0 |

消融实验显示，协同优化结构（New Structure）贡献了 2.8% 的 mAP0.5:0.95 提升，GLCA 和 LHPS 分别贡献 1.3% 和 1.7%。值得注意的是，$\alpha$ 值对性能敏感，当 $\alpha=0.05$ 时达到最优，$\alpha=0.07$ 时性能下降至 29.6，表明 VLM 损失权重过大反而会干扰检测器学习。

评估边界方面，论文未报告训练总时长，仅指出 VLM4RSDet 训练 FPS 较低（14.2-16.3）但所需 Epoch 数更少（12 vs 50）。代码已开源，但缺乏在极端小目标（<10 像素）场景下的单独分析，且未与最新 SOTA（如 SkySenseGPT）进行对比。

## 关联研究分析

从问题动机看，VLM4RSDet 与 Florence-2 等端到端 VLM 检测器的根本差异在于对“先验利用时机”的定义。Florence-2 依赖推理时的语言解码来生成边界框，导致高延迟；VLM4RSDet 则将先验内化至特征表示，推理时仅执行标准检测。这一差异源于任务特性：闭集检测对实时性要求极高，而开放词汇检测更关注泛化性。VLM4RSDet 证明了在固定类别下，训练时的语义约束比推理时的语言生成更有效。

从方法设计看，VLM4RSDet 与 DN-FPN 等纯视觉 SOTA 方法相比，引入了语言建模损失作为正则化项。DN-FPN 通过去噪训练提升特征质量，但缺乏语义引导；VLM4RSDet 通过 LHPS 和 GLCA 将语义信息注入特征金字塔。然而，VLM4RSDet 的 VLM 骨干（Florence-2-Base）参数量（140.2M）远大于检测器骨干，训练成本较高。若 VLM 骨干更换为更轻量的模型，协同优化的增益是否依然显著，论文未给出回答。

## 总结

VLM4RSDet 解决了闭集遥感检测中精度与推理效率的矛盾，通过训练时协同优化将 VLM 先验注入传统检测器，推理时仅保留轻量架构。该方法在 VisDrone2019 上将 mAP0.5:0.95 提升至 42.0，在 DOTA-v1.0 上达到 84.07 的 mAP0.5，且未增加推理开销。其边界在于依赖较重的 VLM 骨干进行训练，且仅在固定类别下验证。当 VLM 骨干参数量减半时，协同优化带来的精度增益是否会被训练不稳定所抵消，论文未给出回答。
