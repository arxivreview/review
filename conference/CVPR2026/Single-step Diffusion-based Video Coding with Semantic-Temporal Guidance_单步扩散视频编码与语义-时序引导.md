# CVPR2026最新论文 ｜Single-step Diffusion-based Video Coding with Semantic-Temporal Guidance ｜单步扩散视频编码与语义-时序引导

研究机构：中国科学技术大学、微软研究院

作者：Naifu Xue、Zhaoyang Jia、Jiahao Li 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.07480)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.07480)

> 低码率视频压缩的核心矛盾在于传统编码器的块状伪影与神经编码器的模糊化倾向，而现有基于扩散模型的方案因多步采样导致计算开销过高，难以满足实时解码需求。S[2] VC 通过引入单步扩散生成器替代多步迭代，并设计上下文语义引导与时序一致性引导机制，解决了单步生成在视频场景下语义漂移与时序闪烁的问题。该方法在极低码率下实现了感知质量与压缩率的双重优化，但其对预训练图像扩散模型的依赖及单步推理的极限压缩能力边界仍需进一步验证。

## 研究背景

视频压缩在极低码率下面临感知质量崩塌的困境。传统标准如 VVC 依赖块状预测与变换，粗量化导致明显的阻塞与振铃伪影；而基于 MSE 或 MS-SSIM 优化的神经视频编码器（NVC）虽消除了块效应，却因追求客观失真最小化而产生过度平滑，丢失高频细节。为恢复感知真实性，引入生成式先验成为必然选择，但预训练扩散模型固有的多步去噪过程在视频多帧场景下计算复杂度呈线性叠加，使得实时解码成为不可能。

扩散模型在视频压缩中的应用主要受限于采样效率与语义适配性。早期工作如 DiffVC 直接复用多步扩散模型，虽提升了画质但推理延迟极高；近期单步扩散图像编码方案（如 OneDC）通过分布匹配蒸馏（DMD）将多步压缩为单步，但其语义引导依赖粗粒度的超先验特征，无法捕捉视频所需的细粒度时空动态。此外，单步图像生成直接迁移至视频时，缺乏跨帧约束会导致合成细节在时间轴上剧烈抖动。S[2] VC 的切入点在于：利用条件编码框架中的特征缓冲区提取细粒度语义，并通过显式的时序引导模块约束单步扩散生成器，从而在保持单步推理速度的同时，实现语义准确且时序稳定的视频重建。

## 核心方法

### 条件编码与单步扩散架构

S[2] VC 采用因果低延迟结构，摒弃了传统 NVC 中显式的光流压缩模块，转而依赖网络隐式学习内容冗余。编码器 $E_c$ 结合前帧上下文 $c_t$ 将当前帧 $x_t$ 映射为潜变量 $y_t$，经量化与熵编码后得到 $\hat{y}_t$。解码器 $D_c$ 重构特征 $\hat{f}_t$ 并存储于特征缓冲区。该架构的关键差异在于，解码后的特征不仅用于像素重建，还作为语义引导的源，通过 Content Adapter 映射至扩散潜空间，实现了编码与生成的联合优化。

### 上下文语义引导 (CSG)

单步扩散模型对条件输入的敏感度远高于多步模型，固定文本提示无法适应动态视频内容，而生成式字幕缺乏细粒度空间信息。CSG 旨在从特征缓冲区中提取帧自适应的语义表示 $s_t$，替代文本嵌入。Semantic Adapter 接收当前帧与前帧特征 $\{\hat{f}_t, \hat{f}_{t-1}\}$，通过步长卷积、残差块与注意力层进行时空聚合，生成细粒度语义特征。为确保语义的时序稳定性，引入 DINOv3 作为教师网络进行蒸馏，其损失函数定义为：

$$ L_{sem} = \| P_{aux}(\hat{f}_t, \hat{f}_{t-1}) - E_{DINO}(x_t) \|_2^2 $$

该公式迫使 Semantic Adapter 输出的预测特征逼近 DINOv3 提取的具有强时序一致性的语义特征，从而在无需额外字幕模型的情况下，为扩散生成器提供稳定且内容感知的指导。

### 时序一致性引导 (TCG)

单步生成缺乏多步去噪中的渐进式平滑效应，易导致相邻帧间纹理抖动。TCG 在扩散 U-Net 的不同空间尺度插入引导块，接收前帧与当前帧的潜特征，提取时序相关性并转化为扩散指导信号 $l_t$。其核心机制在于将时序约束内嵌于生成过程，而非后处理。结合级联训练（Cascade Training），TCG 联合优化跨帧质量，其单步生成过程可表述为：

$$ \{\tilde{f}_{t}^{out}, l_t\} = \epsilon_\theta(\tilde{f}_{t}^{in}, s_t, l_{t-1}) $$

其中 $l_{t-1}$ 为前帧传播的时序特征。该设计使生成器在单步内即感知到时间轴上的依赖关系，有效抑制了闪烁伪影，实现了从图像单步生成到视频时序生成的关键跨越。

## 实验评估

实验在 HEVC-B、UVG 和 MCL-JCV 数据集上进行，对比传统编码器（VTM, ECM）、神经编码器（DCVC-FM, DCVC-RT）及感知编码器（PLVC）。S[2] VC 在 DISTS 指标上平均节省 52.73% 的码率，其中在 MCL-JCV 数据集上节省高达 64.38%，显著优于 PLVC。在运动感知的 FloLPIPS 指标上，S[2] VC 在 HEVC-B 和 MCL-JCV 上均取得最优，验证了 TCG 在复杂运动场景下的鲁棒性。

| 数据集 | 方法 | DISTS BD-Rate (%) | FloLPIPS BD-Rate (%) | FID BD-Rate (%) |
| :--- | :--- | :--- | :--- | :--- |
| HEVC-B | w/o CSG | 27.46 | - | - |
| HEVC-B | w/ CSG only | 22.08 | - | - |
| HEVC-B | w/ CSG + distill | 13.30 | - | - |
| UVG | w/o TCG | 38.75 | - | - |
| UVG | w/ TCG only | 33.92 | - | - |
| UVG | w/ TCG + cascade | 33.92 | - | - |

消融实验显示，CSG 与 DINOv3 蒸馏的结合对 DISTS 指标贡献最大，从 27.46% 降至 13.30%（HEVC-B），表明细粒度语义引导是单步生成质量的关键。TCG 的引入在 UVG 数据集上使 DISTS 从 38.75% 降至 33.92%，且级联训练进一步稳定了时序性能。值得注意的是，TCG 在 HEVC-B 上的增益（20.41% 至 11.74%）小于 UVG，暗示静态场景对时序引导的依赖度较低。

评估协议采用低延迟设置，仅评估前 96 帧，未涵盖长视频场景下的语义漂移问题。指标体系包含 LPIPS、DISTS、FloLPIPS 和 FID，覆盖了帧级感知、运动一致性与生成真实性，但缺乏对极端低码率（<0.005 bpp）下结构完整性的专项评估。论文未提供代码与超参数细节，且对比基线中缺失其他单步扩散视频编码方案（如 DiffVC-OSD），限制了横向比较的全面性。

## 关联研究分析

从问题动机看，S[2] VC 与 OneDC 同属单步扩散图像/视频编码路线，但核心差异在于语义引导的粒度与来源。OneDC 依赖向量量化超先验提供的粗粒度语义，适用于静态图像；而 S[2] VC 从连续特征缓冲区提取细粒度语义，并引入 DINOv3 蒸馏以增强时序稳定性。这一差异源于视频任务对时空动态的强依赖，粗粒度语义无法捕捉帧间细微变化，导致单步生成在视频场景下出现语义漂移。S[2] VC 通过 CSG 解决了这一特定失效，但其语义提取仍局限于局部帧对，未探索长程时序依赖。

从方法设计看，S[2] VC 与 DMD 蒸馏范式紧密相关，但应用场景从生成转向重建。DMD 旨在对齐教师与学生的分布，用于少步生成；S[2] VC 则利用 DMD 训练的单步生成器作为解码后端，重点在于如何将其适配至条件编码框架。与视频超分辨率工作（如 UltraVSR）不同，S[2] VC 采用因果低延迟结构而非双向设计，以支持帧级实时编码。这种架构选择牺牲了部分全局时序建模能力，换取了低延迟优势。TCG 的引入部分弥补了这一损失，但其基于局部帧对的时序相关性提取，在长视频或快速运动场景下的鲁棒性尚存疑问。

## 总结

S[2] VC 针对低码率视频压缩中感知质量与计算效率的矛盾，通过单步扩散生成器替代多步迭代，并设计 CSG 与 TCG 双引导机制，解决了单步生成在视频场景下的语义漂移与时序闪烁问题。该方法在 DISTS 指标上平均节省 52.73% 码率，并在 FloLPIPS 上验证了时序一致性优势。然而，实验仅覆盖前 96 帧的低延迟场景，未评估长视频下的语义稳定性；且 CSG 依赖局部帧对特征，在快速运动或长程依赖场景下的表现未知。当视频时长增加至分钟级时，基于局部帧对的语义引导是否仍能维持时序一致性，论文未给出回答。
