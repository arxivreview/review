# CVPR2026最新论文 ｜Seeing Beyond: Extrapolative Domain Adaptive Panoramic Segmentation ｜外推域适应全景分割

研究机构：湖南大学、德国卡尔斯鲁厄理工学院

作者：Yuanfan Zheng、Kunyu Peng、Xu Zheng 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.15475)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.15475)

> 跨域全景语义分割旨在将针孔相机训练的模型迁移至360°全景图像，但现有方法受限于闭集假设，无法处理目标域中出现的未知类别，且针孔与全景间的几何畸变导致特征对齐失效。本文提出EDA-PSeg框架，通过欧拉-边际注意力（EMA）约束特征角度分布以缓解几何畸变，并引入图匹配适配器（GMA）建模高阶类关系以分离已知与未知类别。该框架在Cityscapes到DensePASS基准上实现了56.81%的Common mIoU和18.86%的Private mIoU，但其性能高度依赖随机裁剪策略，且缺乏对极端长尾分布下图结构鲁棒性的验证。

## 研究背景

当自动驾驶车辆从固定视角的针孔相机切换至360°全景传感器时，图像不仅经历视角的剧烈扩张，还伴随非欧几里得几何带来的严重畸变。这种几何偏移导致传统卷积网络提取的特征在空间分布上发生系统性扭曲，使得基于像素级原型对齐的无监督域适应（Unsupervised Domain Adaptation, UDA）方法失效。更严峻的是，真实驾驶场景中常出现训练集未见的物体类别，闭集假设下的模型会将这些未知类别错误地归类为已知类别，造成安全隐患。

现有跨域全景分割（Cross-Domain Panoramic Segmentation, CPS）方法主要聚焦于几何对齐与语义原型匹配，如CFA通过畸变感知注意力捕捉像素分布差异，DPPASS利用切线投影进行跨域训练。然而，这些方法均假设测试实例属于训练时观察到的类别，无法应对开放世界中的未知类别。开放集域适应（Open Set Domain Adaptation, OSDA）虽能识别未知类，但现有OSDA方法如BUS和UniMAP依赖像素级原型映射，难以适应全景图像的风格不一致与几何畸变。本文切入点在于同时解决几何畸变校正与未知类别语义外推的双重挑战，提出首个面向开放集UDA的全景分割框架。

## 核心方法

### 方法参照系

标准CPS流程包含编码器-解码器提取特征、几何畸变校正模块、以及基于原型的语义对齐损失。本文的关键差异在于将闭集原型对齐替换为开放集图匹配，并将标准自注意力替换为角度约束的欧拉-边际注意力，以同时处理几何与语义不确定性。

### 图匹配适配器（GMA）

GMA替代了传统的像素级原型对齐，通过构建高阶图结构来建模类间关系。设计动机在于像素级原型无法捕捉类别间的拓扑依赖，且在开放集设置下，未知类别的节点会干扰已知类别的对齐。GMA首先基于置信度、熵和原型距离采样节点，形成局部语义集合，并通过指数移动平均更新全局记忆库以补充缺失类别。随后，利用Sinkhorn算法计算节点匹配矩阵，确保匹配的双随机性。其核心损失函数定义为：

$$
\mathcal{L}_{graph} = \sum_{k \in K_{s,t}} \| A_{k} - M_{k} \|_1 + \beta \sum_{u \in U_{s,t}} \| \xi_u \|_F
$$

其中 $K_{s,t}$ 和 $U_{s,t}$ 分别表示源域和目标域的已知与未知节点集合，$A$ 为匹配矩阵，$M$ 为匹配标签，$\xi$ 为边亲和度。该公式通过最小化已知节点的匹配误差并正则化未知节点的边结构，强制模型在几何上解耦已知类，同时在结构上分离未知类，从而避免未知类别噪声向已知类别传播。

### 欧拉-边际注意力（EMA）

EMA作用于编码器-解码器输出的特征，旨在缓解视角变化导致的角度分布偏移。设计动机在于标准自注意力中，同一类别在不同视角下的相位角发生漂移，导致跨域特征重叠。EMA通过通道重排序将特征投影至复数空间，利用欧拉公式将实部与虚部分离为幅度 $\Lambda$ 和相位 $\theta$。其注意力得分计算为：

$$
E_{Euler} = \exp(2\delta_1) \Lambda_q \Lambda_k \cos(\delta_2(\theta_q - \theta_k) + b)
$$

其中 $\delta_1$ 和 $\delta_2$ 为可学习的幅度与相位缩放因子，$b$ 为相位偏置。该公式通过可学习参数动态调整幅度分布（类重要性）和相位缩放（类方向），将角度约束在有界区间内，从而增强特征在未知视角下的不变性，提升已知与未知类别的可分性。

## 实验评估

实验在Cityscapes、DensePASS、SynPASS、GTA5和ACDC五个数据集上进行，涵盖相机偏移（Pin2Pan, Syn2Real）和天气偏移（Sunny→Fog/Rain等）场景。基线覆盖了CPS方法（DAFormer, MIC, HRDA）和OSDA方法（BUS, UniOT），但缺乏基于扩散模型或纯基础模型的OSDA基线，可能低估了当前SOTA的性能上限。

| 方法 | Common mIoU | Private mIoU | H-Score |
| :--- | :--- | :--- | :--- |
| DAFormer | 53.13 | 0.00 | 0.00 |
| BUS (SAM) | 49.47 | 3.10 | 5.84 |
| Ours (SAM) | 56.81 | 18.86 | 28.32 |

在Cityscapes→DensePASS（C2D）任务中，本文Common mIoU为56.81%，比DAFormer高3.68%，比BUS高7.34%；Private mIoU为18.86%，显著优于基线的0.00%和3.10%，表明GMA和EMA有效提升了未知类别的识别能力。

| 实验 | GMA | EMA | Common | Private | H-Score |
| :--- | :--- | :--- | :--- | :--- | :--- |
| ① | - | - | 52.56 | 8.57 | 14.74 |
| ② | ✓ | - | 55.15 | 14.67 | 23.18 |
| ③ | - | ✓ | 56.12 | 13.00 | 21.11 |
| ④ | ✓ | ✓ | 56.81 | 18.86 | 28.32 |

消融实验显示，单独引入GMA使Private mIoU从8.57%提升至14.67%，单独引入EMA使Common mIoU从52.56%提升至56.12%。两者结合后，Private mIoU进一步提升至18.86%，H-Score达到28.32%，表明几何校正与语义外推机制具有互补性。GMA损失权重 $\gamma$ 的敏感性分析显示，$\gamma=0.1$ 时在Common和Private性能间取得最佳平衡，而 $\gamma=1.0$ 虽提升Private mIoU至15.45%，但导致Common mIoU下降至47.16%，揭示了开放集学习中已知与未知类别性能的权衡。

评估指标包含Common/Private mIoU和H-Score，但未报告置信区间或多次运行的方差。代码已开源，但论文未提供详细的超参数搜索范围及GPU资源需求，随机裁剪策略的敏感性可能导致训练不稳定，影响可复现性。

## 关联研究分析

从问题动机看，本文与DAPASS同属全景UDA，但DAPASS侧重去噪与对齐，假设闭集场景，而本文聚焦开放集与几何畸变。DAPASS在DensePASS上达到56.81% mIoU，与本文Common mIoU持平，但本文额外提供了18.86%的Private mIoU，表明其在未知类别处理上的优势。差异根源在于任务定义：DAPASS未考虑未知类别，其对齐机制可能将未知类错误归类，而本文通过GMA显式分离未知类，避免了这种语义幻觉。

从方法设计看，本文与BUS (SAM)同用SAM辅助，但BUS依赖像素级原型映射，本文改用图匹配与角度约束。BUS在C2D上Private mIoU仅为3.10%，而本文达到18.86%，差距源于BUS的像素级对齐在全景畸变下失效，而本文的EMA通过角度约束缓解了畸变，GMA通过图结构捕捉了高阶语义依赖。查询侧增强在数据充足时是否仍有增益，论文未给出回答，但本文结果暗示几何校正对基础模型先验的释放具有关键作用。

## 总结

本文核心矛盾在于全景图像的几何畸变与开放集未知类别的语义不确定性相互耦合，导致传统CPS和OSDA方法均失效。本文抓住的切入点是几何畸变可通过角度约束缓解，未知类别可通过高阶图结构分离，凭借EMA和GMA两个模块实现了这一目标。实验证明，在Cityscapes→DensePASS上，本文Common mIoU达56.81%，Private mIoU达18.86%，显著优于基线。然而，论文自身实验暴露了随机裁剪导致的训练不稳定，且GMA的图结构构建依赖置信度阈值，在极端长尾分布下可能失效。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
