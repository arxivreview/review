# CVPR2026最新论文 ｜Weakly Supervised Video Anomaly Detection with Anomaly-Connected Components and Intention Reasoning ｜弱监督视频异常检测中的语义分组与意图推理

研究机构：同济大学

作者：Yu Wang、Shengjie Zhao

论文原文见 [arXiv](https://arxiv.org/abs/2603.00550)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.00550)

> 弱监督视频异常检测（WS-VAD）旨在仅凭视频级标签定位异常片段，但缺乏帧级监督导致模型难以捕捉细粒度语义，且正常与异常行为（如拿取与偷窃）外观高度相似。现有方法依赖多实例学习（MIL）聚合，易受噪声干扰且无法区分行为意图。本文提出 LAS-VAD，通过异常连通分量（ACC）生成帧级伪标签，结合意图感知机制（IAM）显式建模行为动力学差异。该方法在 XD-Violence 上取得 SOTA 性能，但在 UCF-Crime 上略逊于最新基线，其依赖 LLM 生成属性的鲁棒性存疑。

## 研究背景

监控视频中的异常事件往往具有隐蔽性，例如“拿取物品”与“偷窃”在视觉纹理上几乎一致，唯一区别在于动作速度。这种外观相似性导致传统基于视觉统计量的检测器失效，必须引入行为意图推理。意图推理依赖于对运动轨迹的精细建模，而运动特征（位置、速度、加速度）的提取需要帧级时序对齐。然而，WS-VAD 的核心约束是仅有视频级标签，缺乏帧级边界，这使得直接提取帧级运动特征并建立意图原型变得困难。

WS-VAD 的主流范式是 MIL，假设异常视频至少包含一个异常片段，通过聚合片段特征推断视频级标签。然而，MIL 的聚合机制（如 Max 或 Mean）导致定位粗糙，且无法区分不同类别的异常。随着视觉-语言模型（VLM）如 CLIP 的引入，领域重心转向语义对齐，但 CLIP 在视频时序建模上存在短板，且纯视觉特征难以区分意图相似的异常。本文切入点在于：利用帧间相似度构建连通分量以生成帧级伪标签，缓解标注缺失；同时引入意图原型与对比学习，显式区分正常与异常行为的动力学差异。

## 核心方法

### 方法参照系

标准 WS-VAD 流程为：预训练骨干提取帧特征 → MIL 聚合视频级标签 → 训练分类器。本文的关键差异在于：在特征提取后、MIL 聚合前，插入 ACC 模块生成帧级伪标签，并引入 IAM 模块进行意图对比学习，以增强帧级特征的判别力。

### 异常连通分量（ACC）

ACC 模块旨在解决帧级标注缺失导致的语义学习困难。传统方法直接对帧特征进行 MIL 聚合，忽略了帧间的语义一致性。本文计算帧间成对相似度，构建邻接矩阵 $A$，并通过深度优先搜索（DFS）识别连通分量。每个连通分量内的帧被视为共享相同语义，其均值作为该组的特征原型。帧级伪标签 $g$ 通过计算帧特征与各连通分量原型的相似度分配。这一机制将 MIL 从视频级聚合细化为片段级语义引导，解决了传统 MIL 定位粗糙的问题。

$$
A_{ij} = \text{ReLU}(\text{sim}(X_f[i], X_f[j]) - \tau)
$$

其中 $X_f$ 为帧特征，$\tau$ 为阈值。该公式通过阈值化相似度矩阵，将连续相似度转化为离散连通性，从而识别语义一致的帧组。

### 意图感知机制（IAM）

IAM 模块旨在解决正常与异常行为外观相似但意图不同的问题。传统方法仅依赖视觉特征，无法区分“拿取”与“偷窃”。本文提取位置、速度、加速度特征，拼接为意图感知特征 $X_{int}$。通过两个全连接层生成帧级 logits $q_{int}$，并建立意图原型 $Z$。对于每个帧，计算其与对应意图原型的余弦相似度作为置信度 $w_{int}$，加权得到帧级预测 $q_a$。同时，采用动量更新策略更新意图原型，并通过跨意图对比学习（InfoNCE）挖掘难区分帧对，增强意图判别力。

$$
\mathcal{L}_{cst} = -\log \frac{\exp(\text{sim}(X_{int}[t], S_{pos}[t])/\tau)}{\sum_{s \in S_{neg}[t]} \exp(\text{sim}(X_{int}[t], s)/\tau)}
$$

其中 $S_{pos}$ 和 $S_{neg}$ 分别为正负样本集。该损失函数通过对比学习，显式拉近同意图帧、推远异意图帧，解决了视觉特征在意图区分上的失效。

## 实验评估

实验在 UCF-Crime 和 XD-Violence 上进行，基线覆盖 I3D、C3D、CLIP 骨干及 LEC-VAD、π-VAD 等 SOTA 方法，缺失无监督及零样本基线对比。

| 方法 | 骨干 | UCF-Crime AUC (%) | XD-Violence AP (%) |
| :--- | :--- | :--- | :--- |
| LEC-VAD | I3D | 88.21 | 86.56 |
| π-VAD | I3D | 90.33 | - |
| LAS-VAD | I3D | 91.05 | 89.96 |
| LAS-VAD | CLIP | 90.86 | 87.92 |

LAS-VAD 在 UCF-Crime 上以 91.05% AUC 超越 π-VAD 0.72 个点，在 XD-Violence 上以 89.96% AP 超越 LEC-VAD 3.40 个点，证明 ACC 和 IAM 的有效性。

消融实验显示，移除 IAM 导致 XD-Violence 上 AVG mAP 从 36.89 降至 33.18，降幅最大，表明意图推理对细粒度定位贡献显著。移除 ACC 导致 AVG mAP 降至 29.98，说明帧级伪标签对语义学习至关重要。

评估边界方面，论文未报告置信区间，数值比较需谨慎。代码未公开，超参数（如 $\lambda=0.3, \eta=0.5$）已提供，但 GPU 配置未说明。LLM 生成属性的鲁棒性未充分验证，不同 LLM（GPT-4, Qwen2 等）性能差异极小，暗示模型对 LLM 类型不敏感，但属性生成的准确性依赖 LLM 质量。

## 关联研究分析

从问题动机看，LAS-VAD 与 RefineVAD 均关注语义对齐，但 RefineVAD 通过特征重校准优化 CLIP 特征利用效率，而 LAS-VAD 通过 ACC 生成帧级伪标签，更侧重于解决标注缺失问题。LAS-VAD 的意图推理机制与 VADER 的因果推理不同，VADER 依赖 LLM 生成文本解释，而 LAS-VAD 依赖运动特征建模意图，前者更灵活但易幻觉，后者更稳定但依赖运动提取准确性。

从方法设计看，LAS-VAD 与 VadCLIP 均使用 CLIP 特征，但 VadCLIP 直接进行 MIL 聚合，而 LAS-VAD 引入 ACC 和 IAM，增强了帧级判别力。与 π-VAD 相比，π-VAD 利用多模态特征增强 RGB 特征，而 LAS-VAD 聚焦于意图推理，两者在特征增强策略上存在差异。LAS-VAD 的 ACC 模块与 k-means 聚类不同，k-means 仅依赖特征相似度，而 ACC 利用邻接矩阵建模结构信息，导致 ACC 性能显著优于 k-means。

## 总结

LAS-VAD 针对 WS-VAD 中帧级标注缺失与行为意图模糊的矛盾，通过 ACC 生成帧级伪标签、IAM 建模意图差异，在 XD-Violence 上取得 89.96% AP 的 SOTA 性能，在 UCF-Crime 上以 91.05% AUC 超越 π-VAD。其边界在于依赖 LLM 生成属性，且未验证在噪声视频中的鲁棒性。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
