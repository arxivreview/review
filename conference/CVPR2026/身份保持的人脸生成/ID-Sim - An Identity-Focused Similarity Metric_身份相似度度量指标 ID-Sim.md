# CVPR2026最新论文 ｜ID-Sim: An Identity-Focused Similarity Metric ｜身份相似度度量指标 ID-Sim

研究机构：美国麻省理工学院、Adobe研究院

作者：Julia Chae、Nicholas Kolkin、Jui-Hsien Wang 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.05039)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.05039)

> 身份保持生成领域长期缺乏能忠实反映人类“选择性敏感度”的评估工具，现有感知指标混淆外观相似与身份一致，导致模型优化方向偏离。ID-Sim 通过冻结 DINOv3 骨干并引入双头对比学习，构建了区分身份变化与上下文变化的前馈度量。该指标在 49 项评估中 48 项超越基线，验证了其有效性，但其对多实体场景的依赖外部条件限制了通用性。

## 研究背景

当评估生成模型是否保留了特定人物身份时，传统感知指标如 LPIPS 或 DreamSim 往往失效，因为它们优化的是整体外观相似性，而非身份一致性。这种混淆源于视觉身份定义的模糊性：人类对同一物体在不同光照、姿态下的识别具有鲁棒性，但对细微的身份改变（如换色、换形）极为敏感。这种平衡被称为“选择性敏感度”，即对上下文变化不变，对身份变化敏感。现有基础模型如 DINOv3 和 CLIP 虽具备强大的语义理解能力，但在细粒度身份区分任务上表现不佳，常将背景相似的物体误判为同一实例。

身份保持人脸生成（IPFG）领域的评估体系正从全局语义指标向细粒度身份指标转型，以解决传统指标无法捕捉身份细微差异及复制粘贴伪影的问题。主流路线包括基于 CLIP 的语义对齐和基于 ArcFace 的人脸识别嵌入，但前者在风格化或近身份场景下失效，后者局限于人脸域且缺乏对非人脸物体的泛化能力。ID-Sim 的切入点在于构建一个通用的、基于实例级别的度量，通过受控的生成式编辑数据训练模型区分身份保持与身份改变，从而为 IPFG 及其他实例级任务提供统一的评估基准。

## 核心方法

### 方法参照系

本文问题属于视觉相似度度量学习，与 LPIPS 或 DreamSim 等感知指标同属一类，但关键差异在于目标函数：前者优化整体外观相似，后者优化身份一致性。ID-Sim 采用 DINOv3 ViT-L 作为冻结骨干，仅微调投影头和 LoRA 适配器，避免了从头训练的高成本，同时保留了基础模型的强先验。

### 双头对比学习架构

ID-Sim 的核心创新在于联合全局 CLS 令牌和局部 Patch 令牌的双重监督。设计动机是解决单一全局表示无法捕捉细粒度空间对应关系的问题，特别是在视角或背景变化时，直接位置比较不可靠。模型通过双头 MLP 将 CLS 令牌和 Patch 令牌投影到不同嵌入空间，并采用联合对比损失：

$$
\mathcal{L}_{total} = \mathcal{L}_{CLS} + \lambda \mathcal{L}_{Patch}
$$

其中 $\mathcal{L}_{CLS}$ 是标准 InfoNCE 损失，用于全局身份区分；$\mathcal{L}_{Patch}$ 基于 Sinkhorn 距离计算 Patch 令牌间的软对齐，处理无序局部描述符。这一设计使得模型既能识别整体身份，又能定位局部特征，为下游任务如个性化分割提供空间定位能力。

### 受控生成式数据增强

训练数据包含真实实例数据集和生成式编辑数据，后者分为身份保持的上下文编辑（S2a）和身份改变的实例编辑（S2b）。设计动机是解决真实数据中身份变化与上下文变化纠缠的问题，通过受控编辑提供清晰的正负样本信号。S2a 使用视频数据集生成不同视角、光照下的同一实例，增强不变性；S2b 使用生成模型修改物体属性（如颜色、形状），增强敏感性。这种数据策略确保了模型学习到的是身份本身的差异，而非表面特征的差异。

## 实验评估

实验在 7 个与训练集不相交的数据集上进行，涵盖实例识别、检索和保持任务。基线包括感知指标（DreamSim, LPIPS, DiffSim）、基础模型（DINOv3, CLIP, OpenCLIP）和检索模型（UNED）。ID-Sim 在 49 项评估中 48 项超越所有基线，特别是在 PODS 和 DeepFashion2 上，mAP 分别提升 0.11 和 0.30，表明其在跨上下文识别和细粒度身份区分上的优势。

| 数据集 | 指标 | DINOv3 | ID-Sim (no patch) | ID-Sim |
| :--- | :--- | :--- | :--- | :--- |
| DF2 | mAP | 0.4071 | 0.4765 | 0.7967 |
| AC2017 | mAP | 0.4516 | 0.5471 | 0.6245 |
| CUTE | Acc | 0.6561 | 0.6439 | 0.8189 |
| DB++ | Spearman | 0.5479 | 0.5913 | 0.6834 |
| PetFace | mAP | 0.7849 | 0.8377 | 0.8446 |
| PODS | mAP | 0.5825 | 0.8181 | 0.7907 |
| S2k | AP | 0.2314 | 0.2348 | 0.3674 |

消融实验显示，Patch 级监督显著提升了局部特征性能，使 PerSAM 分割 mAP 从 DINOv3 的 0.153 提升至 0.436。数据平衡和过滤对性能影响显著，平衡正负样本可防止过拟合主导实例，过滤噪声样本提升泛化能力。合成数据（S2a/S2b）的引入增强了多样性和鲁棒性，正编辑改善实例内一致性，负编辑锐化实例间区分度。

评估边界方面，ID-Sim 未报告计算效率指标，且依赖外部条件处理多实体场景。可复现性受限于未公开代码和完整超参数，但训练细节在补充材料中提供。指标完备性上，ID-Sim 在人脸特定域的性能未与 ArcFace 直接对比，可能影响其在 IPFG 中的直接适用性。

## 关联研究分析

从问题动机看，ID-Sim 与 DreamSim 同属学习式感知指标，但 DreamSim 优化整体外观相似，ID-Sim 优化身份一致性。这一差异源于任务目标的不同：DreamSim 旨在匹配人类对图像整体质量的判断，而 ID-Sim 旨在区分同一实例在不同上下文下的变化。ID-Sim 的受控生成式数据策略是其核心优势，通过明确分离身份变化和上下文变化，避免了 DreamSim 中两者纠缠的问题。

从方法设计看，ID-Sim 与 DINOv3 共享骨干网络，但 ID-Sim 通过微调投影头和 LoRA 适配器实现身份特异性，展示了基础模型在身份任务上的局限与改进空间。DINOv3 的自监督对比学习优化的是图像级语义相似，而 ID-Sim 的监督对比学习优化的是实例级身份一致。这一差异导致 DINOv3 在细粒度身份区分任务上表现不佳，而 ID-Sim 通过 Patch 级 Sinkhorn 距离增强了局部特征的空间定位能力，为下游任务如个性化分割提供了更丰富的信息。

## 总结

ID-Sim 解决了身份保持生成领域缺乏细粒度身份评估指标的核心矛盾，通过冻结 DINOv3 骨干和双头对比学习，构建了区分身份变化与上下文变化的前馈度量。该指标在 49 项评估中 48 项超越基线，PODS mAP 达 0.7907，Subjects2k AP 达 0.3674，验证了其在跨上下文识别和细粒度身份区分上的优势。其边界在于依赖外部条件处理多实体场景，且未报告计算效率指标。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
