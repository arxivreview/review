# CVPR2026最新论文 ｜FoV-Net: Rotation-Invariant CAD B-rep Learning via Field-of-View Ray Casting ｜基于视场射线投射的旋转不变 CAD B-Rep 学习

研究机构：比利时根特大学

作者：Matteo Ballegeer、Dries F. Benoit

论文原文见 [arXiv](https://arxiv.org/abs/2602.24084)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.24084)

> 现有 B-Rep 学习方法依赖全局坐标编码几何，导致模型在任意旋转下性能崩塌，无法适应工业场景中多源 CAD 模型的姿态不确定性。本文指出这一长期被忽视的旋转敏感缺陷，并提出 FoV-Net，通过局部参考系 UV 网格与视场射线描述子实现旋转不变的特征表达。该方法在分类与分割任务上保持旋转鲁棒性，但牺牲了对齐数据下的部分姿态线索利用能力，其数据效率优势在低监督场景下尤为关键。

## 研究背景

CAD 边界表示（Boundary Representation, B-Rep）将实体几何分解为参数化面、修剪边及拓扑连接，天然构成图结构。图神经网络（Graph Neural Network, GNN）通过节点特征编码几何、边连接编码拓扑，成为 B-Rep 理解的主流范式。然而，现有方法普遍依赖全局坐标系下的绝对位置与法向量来捕捉面间结构关系，这种设计使特征表达与模型姿态强耦合。

UV-Net 确立了基于 UV 网格采样全局坐标与法向量的描述子范式，后续工作如 AAGNet 在此基础上增加面类型、面积等属性，但在对齐基准上取得高准确率的同时，暴露出对旋转的极端敏感性。实验显示，在 SolidLetters 数据集上，UV-Net 在随机旋转后准确率从 97.42% 骤降至 23.53%，AAGNet 亦从 97.10% 跌至 94.97%（旋转后）或更低。旋转增强虽能部分缓解，但无法覆盖 SO(3) 全空间且增加计算开销。FoV-Net 的切入点在于：不依赖全局坐标，而是通过面局部参考系与射线投射构建内在旋转不变描述子，同时保留局部几何与全局结构上下文。

## 核心方法

### 方法参照系

B-Rep 理解任务的标准流程是将面作为图节点，通过 CNN 提取面级几何特征，再经 GNN 传播拓扑信息。本文问题与该通用流程的关键差异在于：输入特征必须对任意 SO(3) 旋转不变，且需同时编码局部表面几何与面间结构关系，而非仅依赖全局坐标。

### 局部参考系 UV 网格

传统 UV 网格在 global frame 下采样，导致相同几何在不同姿态下产生不同特征。本文引入局部参考系（Local Reference Frame, LRF），以面中心 $\mathbf{o}$ 为原点，外法向量 $\mathbf{N}$ 为 Z 轴，参数化 U 方向切线投影为 X 轴，构建正交基 $\mathbf{R}_f = [\mathbf{U}, \mathbf{V}, \mathbf{N}]$。面内点 $\mathbf{p}$ 与法向量 $\mathbf{n}$ 变换至局部系：

$$
\mathbf{p}' = \mathbf{R}_f^T (\mathbf{p} - \mathbf{o}), \quad \mathbf{n}' = \mathbf{R}_f^T \mathbf{n}
$$

该公式将全局坐标转换为面局部相对坐标，确保相同几何在不同姿态下产生相同 LRF UV 网格，消除旋转敏感性。设计动机在于解耦几何表达与全局姿态，使特征仅依赖面内在属性。

### 视场射线描述子

LRF UV 网格仅编码局部几何，丢失面间结构关系。本文引入视场（Field-of-View, FoV）网格，从面中心 $\mathbf{o}$ 沿法向量 $\mathbf{N}$ 及其反向 $-\mathbf{N}$ 半球发射射线，记录首次交点的距离、入射角余弦及命中标志。半球离散化为 $n_{el} \times n_{az}$ 网格（默认 6×12），每个单元格对应一条射线方向。由于射线原点与方向均在局部系 $\mathbf{R}_f$ 中定义，FoV 网格天然旋转不变。设计动机在于恢复 LRF UV 丢失的全局结构上下文，通过射线交点统计捕捉面周围几何分布，如相邻面是否共面或成角。

## 实验评估

实验在 SolidLetters、TraceParts、Fusion360、MFCAD++ 四个数据集上进行，对比 UV-Net、AAGNet 及其旋转增强版本。基线覆盖 UV 网格与属性增强两条路线，但未包含 Masked Topology Modeling 等自监督预训练方法，可能低估了当前 SOTA 水平。

| 数据集 | 模型 | 旋转后 Accuracy (%) | 原始 Accuracy (%) |
| :--- | :--- | :--- | :--- |
| SolidLetters | FoV-Net | 96.35 ± 0.16 | 96.35 ± 0.16 |
| SolidLetters | UV-Net | 23.53 ± 0.61 | 97.42 ± 0.17 |
| SolidLetters | AAGNet | 94.97 ± 0.10 | 97.10 ± 0.15 |
| Fusion360 | FoV-Net | 91.72 ± 0.17 | 91.72 ± 0.17 |
| Fusion360 | UV-Net | 81.37 ± 0.32 | 89.46 ± 0.48 |

FoV-Net 在旋转后保持与原始数据相同的准确率，而 UV-Net 在 SolidLetters 上损失 73.89 个百分点，AAGNet 损失 2.13 个百分点。在 Fusion360 分割任务中，FoV-Net 的 IoU 为 73.81%，高于 UV-Net 的 54.89% 和 AAGNet 的 69.71%（旋转后），表明旋转不变性在分割任务中同样关键。

消融实验显示，仅使用 FoV 网格（95.79%）与仅使用 LRF UV（94.39%）均优于单独使用 OV（92.92%）或 IV（93.40%），组合后达到 96.35%，证明局部几何与结构上下文的互补性。FoV 分辨率从 6×12 降至 1×1 时，准确率从 95.79% 降至 75.04%，表明射线密度对结构捕捉至关重要。

评估边界方面，论文未报告计算效率指标，且所有实验在单一 GPU（RTX A5000）上完成，未提供多卡扩展性数据。代码已开源，超参数（Adam, lr=0.001, batch size 64）完整披露，可复现性良好。

## 关联研究分析

从问题动机看，FoV-Net 与 UV-Net 的核心差异在于对“全局上下文”的定义。UV-Net 将全局上下文等同于绝对位置与法向量，导致特征与姿态耦合；FoV-Net 将全局上下文重新定义为面周围的相对几何分布，通过射线交点统计实现旋转不变。这一差异源于任务特性：工业 CAD 模型来自多源，姿态随机，绝对位置无意义，而相对结构关系（如面间夹角）才是几何理解的关键。AAGNet 增加面类型、面积等属性，试图通过旋转不变属性缓解问题，但实验显示其旋转后准确率仍低于 FoV-Net，说明仅靠局部属性不足以捕捉结构关系。

从方法设计看，FoV-Net 与点云学习中的 LRF 方法共享局部参考系思想，但 B-Rep 面天然提供 UV 参数化，使 LRF 构建更稳定，无需点云中的噪声鲁棒方向估计。与 SE(3)-等变网络相比，FoV-Net 采用输入不变性而非网络等变性，避免了专用等变层的复杂性，但可能牺牲表达力。论文未探索 SE(3)-等变架构，查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

FoV-Net 解决的核心矛盾是 B-Rep 学习方法对旋转的敏感性与工业场景姿态随机性之间的冲突。现有方法依赖全局坐标编码结构关系，导致旋转后性能崩塌；FoV-Net 通过 LRF UV 网格与视场射线描述子，将几何表达解耦于全局姿态，实现旋转不变。实验证明，FoV-Net 在 SolidLetters 上旋转后保持 96.35% 准确率，而 UV-Net 降至 23.53%；在 Fusion360 分割上 IoU 达 73.81%，显著优于基线。其边界在于：在对齐数据上，FoV-Net 无法利用绝对姿态线索（如字母 b 与 d 的区分），导致原始数据准确率略低于 AAGNet；且 FoV 射线计算依赖 OpenCASCADE 内核，复杂自由曲面上的交点精度可能受限。当支持集增大到 5-shot 时，旋转不变特征的边际收益是否递减，论文未给出回答。
