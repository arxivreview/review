# CVPR2026最新论文 ｜Mitigating Simplicity Bias in OOD Detection through Object Co-occurrence Analysis ｜基于对象共现分析缓解OOD检测中的简单性偏差

研究机构：深圳大学

作者：Boyang Dai、Chaoqi Chen、Yizhou Yu

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_e766eb0077ea)

> 分布外检测旨在识别训练分布之外的样本，但现有方法在处理近邻分布外数据时，常因模型对局部显著特征的过度依赖而失效。这种简单性偏差导致模型忽略场景中的语义不兼容性，例如无法识别海洋中狗与鲨鱼共存的不合理组合。OCO框架通过引入对象中心学习，利用Slot Attention解纠缠图像特征，并基于训练集统计的对象共现模式，将测试样本划分为单类、典型与非典型三类场景，分别设计针对性的检测分数。该方法在SSB-hard等近邻基准上展现出对语义偏移的敏感性，但其性能高度依赖解纠缠表征的质量，且在远端分布外数据上的增益有限，揭示了对象级语义建模在复杂场景下的边界。

## 研究背景

当检测器面对包含多个对象的复杂场景时，传统纠缠特征往往优先捕捉局部显著线索，而忽略对象间的语义关系。这种简单性偏差导致模型在对象特征相似但场景语义不兼容的近邻分布外样本上产生高置信度错误预测。为解决此问题，对象中心学习通过Slot Attention将图像分解为独立对象槽位，为建模对象间关系提供了基础。

现有OOD检测方法主要依赖特征空间几何或后验评分，如NECO利用神经坍缩理论，CoRP采用非线性映射，但这些方法在处理近邻分布外数据时仍受限于纠缠特征的局限性。它们无法有效区分局部特征相似但全局语义不合理的样本，导致检测性能在细粒度场景下显著下降。OCO的切入点在于，通过对象共现模式捕捉场景级的语义兼容性，将检测任务从单一对象特征匹配转化为对象关系合理性判断，从而缓解简单性偏差。

## 核心方法

### 方法参照系

OCO属于后验检测路线，但区别于直接使用最终层特征的基线方法，其核心差异在于引入Slot Attention进行特征解纠缠，并基于训练集统计的共现模式动态选择评分函数。这一设计旨在克服传统方法在纠缠特征空间中无法捕捉对象间语义关系的局限。

### 对象共现模式建模

设计动机在于解决纠缠特征中对象信息混杂导致的共现模式提取失败。OCO首先利用预训练的DINOSAUR架构中的Slot Attention，将输入特征图$x \in \mathbb{R}^{H \times W \times C}$解纠缠为$K$个槽位$S_i = \{s_i^{(1)}, ..., s_i^{(K)}\}$。每个槽位通过交叉注意力机制竞争性抽象对象特征，公式为：

$$
A^{(t)} = \text{softmax}\left(\frac{Q^{(t)}K^T}{\sqrt{D}}\right), \quad S^{(t+1)} = \text{GRU}(S^{(t)}, A^{(t)}V)
$$

其中$Q, K, V$分别为查询、键、值投影。随后，通过分类器$h(\cdot; \theta)$对每个槽位进行语义对齐，得到槽位级预测$c_i^{(k)} = \arg\max(l_i^{(k)})$。为捕捉共现模式，OCO计算每个图像中唯一类别的频率集$F_i$，并将训练集中所有$|F_i| \ge 2$的频率集聚合为$F_{train}$，作为ID数据的共现模式统计库。

### 分治式OOD检测

设计动机在于不同共现模式下的OOD检测难点各异，统一评分无法兼顾。OCO将测试样本的频率集$F_t$划分为三类场景：S1（单类，$|F_t|=1$）、S2（典型，$|F_t| \ge 2 \land F_t \in F_{train}$）、S3（非典型，$|F_t| \ge 2 \land F_t \notin F_{train}$）。针对S1，采用双置信度校准分数$S_{single} = P_t \cdot p_t^{max}$，其中$P_t$为场景级置信度，$p_t^{max}$为对象级最高置信度，以缓解过置信问题。针对S2，引入基于Dempster-Shafer理论的模糊证据分数：

$$
S_{amb} = \sum_{c \neq c'} \left( p_{c'}^{max} p_c^{max} + p_{c'}^{max}(1-p_c^{max}) + (1-p_{c'}^{max})p_c^{max} \right)
$$

该公式量化了主导类别与其他类别间的信念冲突，捕捉近邻OOD的语义模糊性。针对S3，直接使用对象级最高置信度$S_{unrel} = p_t^{max}$作为异常分数，因为非典型模式下的槽位预测不可靠。

## 实验评估

实验在ImageNet-1k上训练，使用SSB-hard、NINCO作为近邻OOD基准，iNaturalist、Textures、OpenImage-O作为远端OOD基准，并扩展至FS-OOD评估。基线覆盖Energy、MaxLogit、NECO、CoRP、OODD等9种方法，但缺失扩散模型类基线（如SCOPED）和VLM类基线（如ANTS），限制了与最新生成式方法的直接对比。

| 方法 | SSB-hard FPR95/AUROC | NINCO FPR95/AUROC | iNaturalist FPR95/AUROC |
| :--- | :--- | :--- | :--- |
| OCO (DINOv2) | 57.74 / 81.27 | 10.38 / 97.45 | 18.36 / 94.36 |
| OODD (DINOv2) | 58.68 / 81.30 | 15.49 / 93.78 | 29.10 / 92.36 |
| CoRP (DINOv2) | 59.36 / 80.31 | 16.81 / 95.81 | 12.64 / 96.54 |

OCO在DINOv2骨干下，NINCO的AUROC达97.45%，显著优于OODD的93.78%和CoRP的95.81%，验证了对象共现模式在近邻OOD检测中的有效性。然而，在iNaturalist上，OCO的FPR95为18.36%，虽优于OODD的29.10%，但低于CoRP的12.64%，表明其在远端语义偏移场景下的优势不显著。

消融实验显示，移除辅助重建损失$L_{aux}$导致Slot Attention定位能力下降，进而影响共现模式预测。槽位数量$K$对性能影响显著，$K=6$时达到峰值，$K>6$时因过度分割导致性能急剧下降。这揭示了对象解纠缠粒度与检测性能之间的权衡关系。

评估协议采用FPR95和AUROC，但未报告计算效率指标。OCO依赖预训练的DINOSAUR架构和Slot Attention，推理时需执行迭代注意力机制，计算开销高于传统后验方法。代码已开源，但论文未提供不同骨干网络（如ResNet）下的详细对比，限制了方法泛化性的评估。

## 关联研究分析

从问题动机看，OCO与NECO均针对近邻OOD检测，但NECO基于神经坍缩理论分析特征空间几何结构，而OCO聚焦于对象间的语义共现关系。NECO的优势在于无需额外解纠缠步骤，计算效率更高；OCO的优势在于能捕捉场景级语义不兼容性，如狗与鲨鱼共存的不合理组合。两者的差异根源在于对“简单性偏差”的不同理解：NECO认为偏差源于特征空间边界模糊，OCO认为偏差源于对象关系忽略。

从方法设计看，OCO与CoRP同属后验检测路线，但CoRP使用非线性映射增强特征空间区分度，OCO使用对象解纠缠和共现模式匹配。CoRP在iNaturalist上表现优于OCO，表明非线性映射在远端语义偏移场景中更有效；OCO在NINCO上表现优于CoRP，表明对象共现模式在近邻语义偏移场景中更有效。这种互补性暗示，结合特征空间几何分析与对象语义关系建模，可能进一步提升OOD检测的鲁棒性。

## 总结

OCO旨在解决近邻OOD检测中因简单性偏差导致的语义不兼容性识别失败问题。其切入点在于利用对象中心学习解纠缠特征，并通过训练集统计的共现模式动态选择评分函数，从而捕捉场景级语义关系。实验证明，OCO在NINCO上的AUROC达97.45%，显著优于OODD和CoRP，验证了对象共现模式的有效性。然而，OCO在iNaturalist上的FPR95为18.36%，低于CoRP的12.64%，且性能高度依赖Slot Attention的解纠缠质量，槽位数量$K$的敏感性揭示了方法对超参数的脆弱性。当对象数量超过6个时，过度分割导致共现模式失效，这一局限在复杂场景下可能进一步恶化。
