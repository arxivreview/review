# CVPR2026最新论文 ｜BD-Merging: Bias-Aware Dynamic Model Merging with Evidence-Guided Contrastive Learning ｜证据引导的动态模型合并

作者：Yuhan Xie、Chen Lyu

论文原文见 [arXiv](https://arxiv.org/abs/2603.03920)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.03920)

> 模型合并旨在整合多个专家模型以缓解部署成本，但现有方法普遍假设测试数据分布与训练域一致，导致在传感器噪声或未见任务场景下鲁棒性急剧下降。本文切入点在于利用证据深度学习量化样本级不确定性，通过动态路由替代静态权重平均。具体做法是引入联合证据头与邻域差异分数，训练去偏路由器以自适应分配任务权重。该方法在分布偏移下显著优于静态基线，但其对无标注辅助数据的依赖及推理时的额外计算开销，限制了其在极端资源受限场景下的适用性。

## 研究背景

当预训练模型针对多个任务微调后，直接权重平均往往因参数干扰导致性能低于单任务专家。任务向量（Task Vector）代数操作通过 $\tau_i = \theta_i - \theta_0$ 的组合来消解方向冲突，成为当前主流范式。然而，这一范式隐含了测试时数据分布与训练分布一致的强假设。一旦测试数据出现传感器噪声、传输失真或涉及未见任务，合并模型的特征对齐被破坏，导致预测偏差与泛化能力丧失。

现有合并方法如 Task Arithmetic 和 TIES-Merging 聚焦于训练时的参数干扰消解，通过稀疏化或符号对齐优化静态权重。AdaMerging 等自适应方法虽引入系数学习，但仍依赖辅助数据分布与目标任务的一致性。当辅助数据分布偏离目标域时，这些方法会过拟合于已知域，加剧对未见任务的泛化失败。BD-Merging 针对这一盲区，将合并问题从静态参数空间操作转向测试时动态行为调整，通过显式建模分布偏移下的不确定性来维持模型可靠性。

## 核心方法

### 方法参照系

标准模型合并流程为离线确定合并系数 $w_k$，执行 $\theta^* = \theta_0 + \sum w_k \tau_k$。本文的关键差异在于将 $w_k$ 从静态标量转化为由输入特征驱动的动态向量，通过在线训练的路由器 $R$ 生成，从而在推理阶段根据样本特性调整合并行为。

### 联合证据头与邻域差异分数

设计动机在于传统置信度指标无法捕捉跨任务语义竞争下的细粒度不确定性。本文在预训练骨干上引入联合证据头，基于 Dirichlet 分布建模类别证据，计算预测锐度（Sharpness）、语义分歧（Divergence）与观点冲突（Opinion Conflicts）的乘积作为邻域差异分数（ADS）。

$$
d_{ik} = \text{Sharp}(x_i) \cdot \text{Div}(x_i) \cdot \text{Conf}(x_i, x_k)
$$

该公式量化了样本 $x_i$ 与其邻居 $x_k$ 在证据层面的对齐程度，低 $d_{ik}$ 值指示高置信的一致样本，高值则标记潜在分布偏移或冲突样本。

### 差异感知对比合并与去偏路由

设计动机在于静态权重无法区分干净样本与腐蚀样本，导致合并模型对噪声敏感。本文利用 ADS 将邻域划分为正负样本对，构建差异感知对比损失 $L_{BD}$，引导路由器学习区分分布内与分布外样本。

$$
\theta^* = \theta_0 + \sum_{k=1}^K w_k \cdot \tau_k, \quad w_k = R(H)
$$

其中 $H$ 为最后一层 token 嵌入，$R$ 为两层 MLP 路由器。该机制使合并权重随输入动态变化，在遇到腐蚀或未见任务样本时自动降低冲突任务的贡献，从而在保持任务特异性的同时增强鲁棒性。

## 实验评估

实验在 SUN397、Cars 等 8 个图像分类数据集上进行，使用 CLIP ViT 骨干，对比 Task Arithmetic、TIES-Merging、AdaMerging 等基线。基线覆盖静态算术与自适应系数路线，但缺失 DARE 等稀疏化几何基线，可能低估了干扰消解类方法在干净数据上的上限。

| 方法 | Clean Avg Acc (%) | Corrupted L2 Avg Acc (%) |
| --- | --- | --- |
| Task Arithmetic | 69.09 | 60.30 |
| TIES-Merging | 72.92 | 64.34 |
| AdaMerging (Layer-wise) | 74.33 | 64.46 |
| BD-Merging (Layer-wise) | 87.15 | 78.78 |

BD-Merging 在干净数据上取得 87.15% 的平均准确率，显著高于 AdaMerging 的 74.33%。在 L2 腐蚀强度下，其性能下降幅度仅为 13.5 个百分点，而 AdaMerging 下降 13.3 个百分点，TIES-Merging 下降 11.8 个百分点，表明动态路由在极端偏移下具有更强的稳定性。

| 组件 | Clean Acc (%) | Corrupted Acc (%) |
| --- | --- | --- |
| BD-Merging | 87.15 | 78.78 |
| w/o Router | 78.31 | 67.25 |
| w/o ADS | 84.48 | 75.44 |
| w/o L_Dis | 83.34 | 74.26 |

移除路由器导致性能大幅下降 8.84 个百分点，证明动态权重分配是鲁棒性的核心来源。移除 ADS 或对比损失 $L_{Dis}$ 分别导致 2.67 和 3.81 个百分点的性能损失，表明证据量化与对比学习对区分冲突样本至关重要。

评估协议包含 9 种人工腐蚀与未见任务泛化测试，但未报告计算效率的具体延迟数据。代码未公开，超参数（如温度 $\tau$、半径 $r$）固定为 0.1，缺乏敏感性分析。实验仅在 ViT-B/32 上详细报告，ViT-L/14 结果仅以图表形式呈现，缺乏逐任务统计。

## 关联研究分析

从问题动机看，BD-Merging 与 AdaMerging 均关注系数自适应，但 AdaMerging 假设辅助数据分布与目标域一致，而 BD-Merging 显式处理分布偏移。这一差异源于任务特性：AdaMerging 适用于域内微调场景，而 BD-Merging 针对传感器噪声等真实世界干扰。论文未探索当辅助数据完全缺失时，证据头能否仅凭测试时输入自监督学习，这可能是其泛化能力的潜在瓶颈。

从方法设计看，BD-Merging 与 Twin-Merging 同属动态合并路线，但 Twin-Merging 依赖外部蒸馏信号对齐参数，而 BD-Merging 通过内部证据信号引导路由。Twin-Merging 在未见任务上准确率仅为 53.03%，而 BD-Merging 达到 55.01%，表明内部不确定性建模比外部蒸馏更有效地捕捉分布偏移。然而，BD-Merging 引入的路由器增加了推理时的前向计算，其额外延迟是否抵消了合并的部署优势，论文未提供量化对比。

## 总结

BD-Merging 解决了模型合并在测试时分布偏移下的鲁棒性缺失问题，通过证据不确定性量化与动态路由，将静态权重平均转化为自适应行为调整。该方法在 L2 腐蚀下保持 78.78% 的平均准确率，较 AdaMerging 提升 14.32 个百分点，证明了动态合并的有效性。其边界在于依赖无标注辅助数据训练路由器，且推理时引入额外计算开销。当辅助数据规模极小或完全缺失时，证据头的校准能力是否足以支撑可靠的动态路由，论文未给出回答。
