# CVPR2026最新论文 ｜Prompt-Anchored Vision-Text Distillation for Lifelong Person Re-identification ｜提示锚定视觉-文本蒸馏

研究机构：电子科技大学、哈尔滨工业大学

作者：Wen Wen、Hao Chen、Shiliang Zhang

论文原文见 [arXiv](https://arxiv.org/abs/2605.05027)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.05027)

> 终身行人重识别（Lifelong Person Re-Identification, LReID）旨在让模型在数据流式到达时持续学习新身份，同时保留旧域知识。现有无样本方法仅依赖视觉蒸馏，导致特征空间随域偏移发生语义漂移，无法维持身份语义的长期一致性。PAD 利用冻结的 CLIP 文本编码器作为全局语义锚点，通过非对称的文本-视觉提示机制与双路蒸馏，在抑制漂移的同时保持对新域的适应力。该方法在未见域泛化上表现优异，但已见域细粒度判别能力是否受文本锚点约束，仍存疑。

## 研究背景

当监控摄像头网络持续接入新设备或环境光照发生季节性变化时，模型面临数据分布的连续漂移。若从头重训，计算成本不可接受；若直接增量训练，新域数据会覆盖旧域表示，引发灾难性遗忘。在行人重识别中，这种遗忘尤为致命，因为同一行人在不同光照、视角下的外观差异（类内差异）远大于不同行人间的细微差别（类间差异），导致特征空间极易发生语义漂移，使原本可区分的身份变得混淆。

主流 LReID 方法分为样本回放与无样本原型两类。样本回放存储旧域图像，虽有效但存在隐私泄露风险；无样本方法（如 DKP++、LSTKC）通过存储类中心或分布统计进行视觉知识蒸馏，规避了隐私问题，但仅作用于视觉模态。当域分布发生显著偏移时，纯视觉蒸馏只能维持局部判别性，无法锚定底层的身份语义，导致特征空间逐渐偏离真实的身份概念。PAD 的切入点在于引入视觉-语言模型（Vision-Language Model, VLM）中的文本模态，利用文本描述（如“穿红夹克的人”）在光照、姿态变化下的语义稳定性，将其作为跨域不变的锚点，引导视觉特征的演化。

## 核心方法

### 参照系：无样本终身学习框架

PAD 基于 CLIP-ReID 架构，扩展至终身学习场景。标准流程为：冻结骨干网络，通过提示学习（Prompt Learning）适应新域，并使用蒸馏损失保留旧域知识。关键差异在于，传统方法仅使用视觉侧蒸馏，而 PAD 引入冻结文本编码器作为全局锚点，构建非对称的视觉-文本蒸馏机制。

### 文本侧：隐式对齐与弱显式蒸馏

文本侧的核心是建立稳定的语义坐标系。首先，通过监督对比损失（SupCon）优化文本锚定提示（Text-Anchor Prompt, TA-Prompt），使视觉特征与文本特征在冻结的文本编码器空间中对齐：

$$ \mathcal{L}_{supcon} = \text{SupCon}(\mathbf{v} \rightarrow \mathbf{t}) + \text{SupCon}(\mathbf{t} \rightarrow \mathbf{v}) $$

此公式确保每个域的 TA-Prompt 适应当前视觉分布，同时被约束在统一的跨模态语义空间中。其次，为防止长序列训练中 TA-Prompt 漂移，引入弱显式蒸馏（TEXKD）。使用前一域的固定教师模型生成文本特征库，通过 KL 散度约束当前 TA-Prompt 的输出分布：

$$ \mathcal{L}_{TEXKD} = D_{KL}(P_{teacher} || P_{student}) $$

设计动机在于，纯对比学习虽能对齐当前域，但缺乏对历史语义的显式约束；弱蒸馏权重避免了过度约束新域适应，实现了稳定性与可塑性的平衡。

### 视觉侧：强 EMA 蒸馏与动态提示池

视觉侧负责域适应。采用指数移动平均（EMA）教师模型，通过特征级 MSE 和 Logit 级 KL 散度进行强蒸馏，抑制细粒度漂移：

$$ \mathcal{L}_{VISKD} = \lambda_{feat} \mathcal{L}_{MSE} + \lambda_{logit} \mathcal{L}_{KL} $$

同时，设计视觉适应提示（Visual-Adaptation Prompt, VA-Prompt）池，包含通用提示（G-Prompt）和专家提示（E-Prompt）。每个新域激活新的 E-Prompt 槽位并冻结旧槽位，实现动态扩展而不干扰旧知识。选择性解冻骨干网络最后几层，平衡计算成本与适应能力。

## 实验评估

实验在 AKA-order1 和 AKA-order2 协议下进行，涵盖 Market-1501、CUHK-SYSU 等 5 个已见域和 7 个未见域。基线覆盖 LwF、DualPrompt、AKA、DKP++ 等主流方法，但缺失纯视觉无样本基线（如 LSTKC 的变体）的直接对比。

| 方法 | Seen-Avg mAP | Seen-Avg R1 | Unseen-Avg mAP | Unseen-Avg R1 |
| :--- | :--- | :--- | :--- | :--- |
| DKP++ | 65.7 | 58.5 | - | - |
| DASK | 65.3 | 58.4 | - | - |
| PAD | 70.7 | 81.0 | 78.6 | 71.4 |

PAD 在已见域平均 mAP 上领先 DKP++ 5.0 个百分点，在未见域 mAP 上达到 78.6%，显著优于所有基线，表明文本锚点有效提升了跨域泛化能力。

| 配置 | Seen-Avg mAP | Seen-Avg R1 |
| :--- | :--- | :--- |
| S0 (Full Fine-tune) | 66.2 | 78.5 |
| S1 (Freeze Only) | 66.8 | 78.4 |
| S5 (Full PAD) | 70.7 | 81.0 |

消融实验显示，仅冻结（S1）相比全微调（S0）性能持平，说明冻结策略本身不足以提升性能；加入 VA-Prompt（S2）后 mAP 提升至 68.2，表明提示池对适应新域至关重要；完整 PAD（S5）进一步将 mAP 提升至 70.7，验证了文本-视觉双路蒸馏的协同效应。

评估协议采用标准 AKA 协议，指标包括 mAP 和 R1。代码已开源，超参数（如 $\lambda_{text}=0.5$, $\alpha=0.997$）详细列出，可复现性良好。局限在于未报告计算效率（FLOPs、Latency），且未见域评估仅基于 7 个特定数据集，缺乏大规模真实场景验证。

## 关联研究分析

从问题动机看，PAD 与 DKP++ 均解决无样本 LReID 的遗忘问题，但 DKP++ 依赖视觉分布统计，而 PAD 引入文本语义锚点。差异根源在于任务特性：行人重识别的类间差异极小，纯视觉统计易受域偏移干扰，而文本描述（如衣着颜色）具有更强的域不变性。PAD 利用这一特性，将语义稳定性从视觉模态转移至文本模态，解决了 DKP++ 在长序列训练中语义漂移的问题。

从方法设计看，PAD 与 DualPrompt 均使用提示池，但 DualPrompt 仅作用于视觉侧，而 PAD 采用非对称设计：文本侧负责语义锚定（弱蒸馏），视觉侧负责域适应（强蒸馏）。这种非对称性源于模态特性差异：文本编码器冻结后提供稳定锚点，视觉编码器需适应新域。PAD 的 VA-Prompt 动态扩展机制借鉴了 L2P 的思想，但通过冻结旧槽位避免了提示池膨胀导致的计算开销，实现了终身学习中的参数效率。

## 总结

PAD 旨在解决终身行人重识别中纯视觉蒸馏导致的语义漂移问题。现有方法仅依赖视觉模态，无法在域偏移下维持身份语义的长期一致性，而 PAD 利用冻结 CLIP 文本编码器作为全局锚点，通过非对称的文本-视觉提示机制与双路蒸馏，实现了稳定性与可塑性的平衡。实验表明，PAD 在 AKA-order1 上已见域平均 mAP 达 70.7%，未见域平均 mAP 达 78.6%，显著优于 DKP++ 等基线。然而，PAD 的文本锚点依赖预训练 CLIP 的语义空间，若新域包含预训练数据中未见的身份属性（如特定文化服饰），文本锚点的泛化能力可能受限。当支持集增大到 5-shot 时，文本锚点的边际收益是否递减，论文未给出回答。
