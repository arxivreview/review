# CVPR2026最新论文 ｜RaUF: Learning the Spatial Uncertainty Field of Radar ｜雷达空间不确定性场学习

研究机构：华中科技大学、武汉大学

作者：Shengpeng Wang、Kuangyu Wang、Wei Wang

论文原文见 [arXiv](https://arxiv.org/abs/2603.01026)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.01026)

> 毫米波雷达在恶劣天气下具备全天候感知优势，但其固有的稀疏性与多径干扰导致几何推断病态，现有跨模态监督方法常因模糊的特征-标签映射而收敛至物理不可行的中间解。RaUF 通过引入各向异性高斯分布建模空间不确定性，并利用多普勒一致性抑制虚假反射，将冲突的监督信号转化为细粒度的置信度线索。该方法在 ColoRadar 数据集上较传统 CFAR 方法降低了 70.1% 的倒角距离，但在长序列处理与最新扩散模型对比上存在局限。其价值在于提供了物理一致的不确定性量化机制，但 3D CNN 骨干在边缘部署中的扩展性仍存疑。

## 研究背景

雷达信号处理的核心困境源于天线数量限制导致的角分辨率不足。当雷达从稀疏测量中恢复密集点云时，方位角的不确定性远高于距离维，形成典型的“新月形”空间分布。这种各向异性的测量特性使得传统确定性映射难以区分真实目标与多径产生的鬼点，进而引发几何推断的病态问题。

主流雷达感知增强路线依赖 LiDAR 或相机的高分辨率监督进行跨模态细化，如 Radar-Diffusion 和 SDDiff。然而，这些方法往往将低分辨率到高分辨率的细化过程视为网络“幻觉”几何结构，缺乏对物理保真度的显式约束。当不同样本的特征映射到同一标签但存在物理冲突时，网络被迫在相互矛盾的监督信号中妥协，收敛至既不代表真实分布模式也不具备物理合理性的平均解。RaUF 的切入点在于将这种模糊性从“需要消除的噪声”重构为“可学习的物理线索”，通过显式建模各向异性不确定性来稳定优化过程。

## 核心方法

### 方法参照系

本文问题属于雷达点云提取与增强范畴，标准流程通常包含信号处理（如 CFAR）或基于 LiDAR 监督的深度网络细化。与通用流程的关键差异在于，本文不追求确定性的点云坐标预测，而是将任务重定义为联合估计定位预测模型 $f_\theta(x)$ 与不确定性量化模型 $g_\phi(x)$，以解决稀疏测量下的病态推断。

### 各向异性不确定性建模

针对传统方法在冲突监督下收敛至几何不可行解的失效，RaUF 引入贝叶斯概率模型（BPM）来显式建模雷达测量的各向异性特性。设计动机在于，雷达的方位角分辨率远低于距离分辨率，导致不确定性在空间上呈现非各向同性分布，而现有方法（如 GICP）仅捕捉各向同性方差，无法反映这一物理本质。RaUF 将似然函数建模为异方差高斯分布，其中协方差矩阵 $\Sigma$ 由极坐标下的径向、方位角和仰角不确定性通过一阶误差传播推导得出：

$$
\mathcal{L}_{NLL} = \frac{1}{2} \sum_{i=1}^{N} \left( \log |\Sigma_i| + (y_i - f_\theta(x_i))^T \Sigma_i^{-1} (y_i - f_\theta(x_i)) \right)
$$

该公式的第一项惩罚过大的不确定性估计以防止平凡解，第二项在考虑预测不确定性的前提下鼓励模型拟合数据。通过最小化负对数似然，网络不再强行拟合冲突的确定性标签，而是学习目标区域的细粒度置信度分布，从而将模糊映射转化为有意义的学习信号。

### 多普勒感知预测增强

在解决空间不确定性后，RaUF 进一步利用多普勒一致性抑制多径干扰。设计动机在于，仅依赖幅度信息的感知极易受鬼点影响，而真实静态目标的反射多普勒速度严格遵循雷达自速度与散射方向向量的运动学约束。RaUF 提出双向域注意力融合（BDAF）模块，通过两层交叉注意力实现空间特征与多普勒特征的相互增强。首先，以空间特征为查询、多普勒特征为键值，提取与雷达自运动一致的多普勒线索；随后，通过域投影网络将多普勒特征转化为占据似然潜表示，反向指导空间特征的重建。这一双向机制使得网络能够识别并抑制偏离运动学约束的虚假反射，显著提升杂乱环境下的感知可靠性。

## 实验评估

| 方法 | CD (↓) | F-Score (↑) |
| :--- | :--- | :--- |
| OS-CFAR | 4.15 | 0.19 |
| SDDiff | 0.86 | 0.43 |
| RaUF (w.o. NLL) | 0.58 | 0.45 |
| RaUF (w.o. BDA) | 0.99 | 0.40 |
| RaUF | 0.50 | 0.47 |

实验在 ColoRadar 和 RaDelft 数据集上进行，基线涵盖传统信号处理（OS-CFAR）、早期深度网络（RPDNet）及最新生成式方法（SDDiff）。RaUF 在 ColoRadar 单芯片雷达场景下取得 0.50 的 CD 和 0.47 的 F-Score，较 OS-CFAR 的 CD 降低 70.1%，且优于 SDDiff。值得注意的是，RaUF 未与区域引导扩散模型 R$^3$D 进行直接对比，尽管后者在相同数据集上报告了 0.32 的 CD，这可能源于任务定义或计算开销的差异。

消融实验揭示了各模块的边际贡献。移除不确定性校准（NLL）导致 CD 从 0.50 升至 0.58，降幅 30.55%-37.18%，证实了各向异性建模对几何保真度的关键作用。移除双向域注意力（BDA）则使 CD 升至 0.99，表明多普勒一致性在抑制鬼点方面贡献显著，其增益（14.98%-15.95%）虽小于不确定性建模，但在高杂波环境下不可或缺。

评估边界方面，论文使用倒角距离（CD）和 F-Score 衡量有效性，并自定义杂散点比率（CPR）评估可靠性，但未报告计算效率指标（如 FLOPs 或延迟）。实验在 4 块 RTX 4090 上训练 6 天，未提供代码开源链接，且自采集数据集规模（11,000 帧）相对较小，跨硬件泛化能力的验证主要依赖微调而非零样本测试。

## 关联研究分析

从问题动机看，RaUF 与 Radar-Diffusion 均致力于解决雷达点云稀疏性问题，但路径截然不同。Radar-Diffusion 采用全图扩散策略进行超分辨率，本质上是通过数据驱动的方式“幻觉”出密集结构，而 RaUF 则通过物理约束的不确定性建模来量化这种“幻觉”的置信度。这一差异源于对“物理保真度”的不同理解：前者假设生成模型能隐式学习物理规律，后者则显式编码雷达测量的各向异性物理特性。RaUF 的方法在抑制多径干扰上更具可解释性，但可能牺牲了生成式模型在极端稀疏场景下的细节恢复能力。

从方法设计看，RaUF 与 SDDiff 同属单芯片雷达处理框架，但 SDDiff 侧重速度-点云联合估计，将多普勒信息用于速度回归，而 RaUF 将多普勒信息提升为空间特征抑制机制。SDDiff 依赖重复的扩散迭代，计算开销大，难以在级联雷达系统中实时部署；RaUF 采用 3D CNN 骨干，虽未采用 SSM 等线性复杂度架构，但其双向注意力机制在计算效率上优于扩散模型。然而，RaUF 的 3D CNN 骨干在处理长序列或高分辨率数据时，其二次方复杂度可能成为瓶颈，这与领域内向 SSM 演进的趋势存在潜在冲突。

## 总结

RaUF 旨在解决雷达稀疏测量下的病态几何推断问题，其切入点在于将模糊的特征-标签映射重构为各向异性不确定性学习，从而避免传统方法在冲突监督下的妥协解。通过引入异方差高斯分布建模与双向域注意力机制，RaUF 在 ColoRadar 上将 CD 降低至 0.50，较基线提升 70.1%。然而，其 3D CNN 骨干在边缘部署中的计算效率未经验证，且缺乏与最新区域引导扩散模型的直接对比。当雷达数据序列长度增加至分钟级时，3D CNN 的内存占用是否会导致实时性失效，论文未给出回答。
