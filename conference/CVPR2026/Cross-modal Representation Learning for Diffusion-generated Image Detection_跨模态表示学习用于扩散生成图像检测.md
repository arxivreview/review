# CVPR2026最新论文 ｜Cross-modal Representation Learning for Diffusion-generated Image Detection ｜跨模态表示学习用于扩散生成图像检测

作者：Tao Gong、Dayong Wang、Qi Chu 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_03d1a179feec)

> 扩散模型生成图像检测的核心矛盾在于，通用视觉编码器提取的高层语义特征难以捕捉生成过程留下的低层统计伪迹，导致跨生成器泛化能力受限。现有方法或依赖单一RGB模态的对比学习，或孤立使用频域特征，缺乏对多模态信息协同优化的机制。本文提出SDID，通过跨模态对比学习（CMCL）与跨模态互蒸馏（CMMD）联合优化RGB与邻域像素关系（NPR）特征空间，在GenImage基准上取得98.4%的准确率。该设计验证了低层伪迹与高层语义互补的有效性，但其在重建类扩散模型上的性能衰减暴露了NPR表示的边界。

## 研究背景

当检测器面对未见过的生成模型时，其决策边界往往因训练域与测试域的低层统计分布差异而失效。这种失效源于生成器上采样操作引入的局部结构伪迹，这些伪迹在像素邻域间形成特定的统计依赖关系，即邻域像素关系（NPR）。NPR作为源不变表示，能够捕捉生成过程的固有缺陷，但其单独使用缺乏高层语义约束，易受图像内容干扰。

扩散模型检测的主流路线分为两类：一类基于重建误差或频域分析，如DIRE和FreqNet，但这类方法对特定生成器架构敏感；另一类利用视觉基础模型（VFM）特征，如UnivFD和CoDE，虽具备一定泛化性，但VFM预训练目标与伪造检测目标存在错位，导致特征空间中真实与合成图像的类内紧凑性不足。CoDE虽尝试通过对比学习优化RGB嵌入空间，但仅依赖单一模态，未能充分利用NPR中蕴含的低层取证线索。本文切入点在于，将NPR作为独立模态与RGB特征进行跨模态协同学习，通过显式约束优化伪造感知嵌入空间，弥补单一模态在类间分离度或类内紧凑性上的缺陷。

## 核心方法

### 方法参照系

本文问题属于基于表示学习的生成图像检测，与CoDE等对比学习框架同属一类。关键差异在于，CoDE仅使用RGB模态进行实例判别，而本文引入NPR模态，并设计双向跨模态优化机制，旨在同时提升类间分离度与类内紧凑性，而非仅依赖单一模态的实例对比。

### 跨模态对比学习 (CMCL)

CMCL作用于特征提取后的嵌入空间，旨在增强真实与伪造图像间的类间分离度。通常对比学习仅在同一模态内构建正负样本对，而本文利用RGB特征与NPR特征间的跨模态关系：同一真实图像的RGB特征与NPR特征构成正样本对，而该RGB特征与其他伪造图像的NPR特征构成负样本对。这种设计迫使编码器学习区分真实与伪造的跨模态一致性，而非仅记忆单一模态的统计特性。其损失函数为：

$$
\mathcal{L}_{CMCL} = -\log \frac{\exp(F_{RGB}^{real} \cdot F_{NPR}^{real} / \tau)}{\exp(F_{RGB}^{real} \cdot F_{NPR}^{real} / \tau) + \sum_{q_i \in Q_{NPR}^{fake}} \exp(F_{RGB}^{real} \cdot q_i / \tau)}
$$

其中 $\tau$ 为温度系数，$Q_{NPR}^{fake}$ 为伪造图像NPR特征的动态队列。该公式通过最大化同一真实图像跨模态特征的相似度，同时最小化其与伪造图像NPR特征的相似度，从而在嵌入空间中拉开真实与伪造类别的距离。

### 跨模态互蒸馏 (CMMD)

CMMD承接CMCL输出的特征，旨在提升类内紧凑性。CMCL仅优化类间关系，无法建模同一类别内样本的结构信息，导致真实图像特征在嵌入空间中分布松散。CMMD通过提取每个模态内样本与其最近邻的相似度分布，执行双向知识蒸馏：RGB模态的邻域分布指导NPR模态，反之亦然。其核心在于利用关系信息（relational information）而非固定教师模型，实现模态间知识的动态迁移。该机制解决了单一模态特征在类内分布不一致的问题，使真实图像特征在嵌入空间中更加紧凑，从而提升分类器的鲁棒性。

## 实验评估

实验在GenImage、DRCT-2M和Co-Spy-Bench三个基准上进行，评估指标为0.5阈值下的准确率。基线覆盖CNNSpot、UnivFD、DIRE、DRCT等经典方法，但缺失DINOv3-Linear、SSAFE等最新VFM基线，可能低估了当前SOTA水平。

| 方法 | GenImage (%) | DRCT-2M (%) | Co-Spy-Bench (%) |
| :--- | :--- | :--- | :--- |
| CNNSpot | 74.6 | 81.1 | 69.4 |
| UnivFD | 79.4 | 83.5 | 76.5 |
| DIRE | 71.2 | 71.2 | 57.4 |
| DRCT | 89.4 | 90.5 | 76.0 |
| SDID (ours) | 98.4 | 92.4 | 96.1 |

SDID在GenImage上以98.4%的准确率领先，较DRCT提升9个百分点；但在DRCT-2M上仅92.4%，低于据领域综述中DCCT的96.1%，表明其在重建类扩散模型（如SDXL-DR）上泛化能力有限。

| 配置 | GenImage (%) |
| :--- | :--- |
| RGB only | 86.7 |
| RGB + CMCL | 93.6 |
| RGB + CMCL + CMMD | 96.4 |
| RGB + NPR + CMCL | 95.4 |
| RGB + NPR + CMCL + CMMD | 98.4 |

消融实验显示，CMCL将RGB-only基线从86.7%提升至93.6%，CMMD进一步提升至96.4%；引入NPR模态后，CMCL+CMMD组合达到98.4%，较RGB-only提升9.7个百分点。NPR模态的引入带来2.3个百分点的额外增益，验证了低层伪迹与高层语义的互补性。

评估协议未报告置信区间，且未包含真实世界退化（如压缩、模糊）测试，限制了野外鲁棒性的评估。代码未公开，超参数（如队列长度2048、Top-K 128）固定，可复现性依赖作者实现细节。

## 关联研究分析

从问题动机看，本文与CoDE同属对比学习优化嵌入空间路线，但CoDE仅使用RGB模态，而本文引入NPR模态。差异根源在于任务特性：RGB特征易受图像内容干扰，NPR特征捕捉上采样伪迹，二者互补。CoDE未探索多模态融合，可能因其假设RGB已包含足够取证线索，但本文实验证明NPR在类内紧凑性上贡献显著。

从方法设计看，本文与UnivFD等VFM方法不同，后者依赖预训练特征+线性探针，而本文通过CMCL/CMMD重塑特征空间。UnivFD在GenImage上仅79.4%，本文98.4%，差异源于本文显式优化伪造感知嵌入，而非依赖预训练语义。但本文在DRCT-2M上落后于DCCT，可能因NPR对重建类扩散模型的伪迹捕捉不足，而DCCT采用去马赛克引导的颜色相关性训练，更适应此类模型。

## 总结

本文核心矛盾在于通用视觉编码器难以捕捉生成过程的低层伪迹，导致跨生成器泛化受限。切入点在于利用NPR作为源不变表示，与RGB特征进行跨模态协同优化，弥补单一模态在类间分离度或类内紧凑性上的缺陷。方法通过CMCL增强类间分离，CMMD提升类内紧凑，在GenImage上取得98.4%准确率，较DRCT提升9个百分点。边界在于DRCT-2M上仅92.4%，低于DCCT的96.1%，暴露NPR对重建类扩散模型的伪迹捕捉不足。当生成模型从随机噪声转向真实图像重建时，NPR表示的源不变性是否依然成立，论文未给出回答。
