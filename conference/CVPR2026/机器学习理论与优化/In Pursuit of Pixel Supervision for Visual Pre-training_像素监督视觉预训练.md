# CVPR2026最新论文 ｜In Pursuit of Pixel Supervision for Visual Pre-training ｜像素监督视觉预训练

作者：Lihe Yang、Shang-Wen Li、Yang Li 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.15715)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.15715)

> 视觉自监督学习长期面临监督信号定义的人为偏差问题：潜在空间目标（如对比、JEPA）依赖人工设计的不变性或预测逻辑，可能丢弃低层几何与纹理信息。现有主流方法在密集预测任务上虽强，但其表示质量受限于预训练目标与数据策展的耦合。Pixio 切入点在于回归像素空间重建，通过增强掩码自编码器（MAE）的解码器容量、掩码粒度与数据规模，证明纯像素监督可生成跨层级通用表示。其价值在于提供了无需潜在空间正则化的稳定替代路径，但通用分类性能显著落后于潜在空间方法，且未验证其在极端域外场景的鲁棒性。

## 研究背景

当视觉模型需要理解物理世界时，监督信号的定义直接决定了表示的层级覆盖。传统监督学习依赖 ImageNet 类别标签，这种单一分类标签无法描述图像中的几何、材质或光照细节，导致模型在迁移至密集预测任务时性能受限。为突破标签瓶颈，自监督表示学习（Self-Supervised Representation Learning, SSRL）利用数据内在结构生成监督信号。然而，主流 SSRL 方法如 DINO 或 I-JEPA 将目标定义在潜在空间，通过最大化互信息或预测嵌入来学习表示。这种潜在空间目标虽然高效，但隐含了人类设计的归纳偏置，可能将低层视觉信号视为噪声，从而在需要保留细粒度几何结构的任务中表现不佳。

SSRL 领域的主流路线分为对比学习与预测式架构两类。对比学习（如 SimCLR）依赖负样本挖掘，计算成本高且受批量大小限制；预测式架构（如 MAE、I-JEPA）通过掩码重建或潜在预测避免负样本，但 MAE 原始设计在大规模数据与模型场景下存在解码器容量不足与掩码粒度过细的问题。MAE 使用单像素掩码和浅层解码器，导致编码器为降低重建损失而牺牲语义表示质量，且单像素掩码允许模型通过复制邻近像素完成重建，形成捷径学习。Pixio 的切入点在于指出像素本身是视觉信息的原始载体，包含从低层属性到高层概念的所有信息，因此应通过增强像素重建任务来学习通用表示，而非依赖潜在空间抽象。

## 核心方法

### 方法参照系

Pixio 基于 MAE 范式，保留其非对称编码器-解码器架构与高掩码率设计。MAE 的核心流程是移除输入中的部分 patch token，编码器处理可见 token，解码器恢复被掩码的像素。本文与标准 MAE 的关键差异在于：标准 MAE 假设浅层解码器足以处理像素回归，且单像素掩码足以构成有效任务；Pixio 则认为在大规模预训练场景下，这种假设失效，需通过增强解码器容量、扩大掩码粒度及引入多类 token 来提升任务难度与表示质量。

### 解码器深度与掩码粒度优化

标准 MAE 的解码器仅 8 层，维度 512，导致编码器后期层被迫承担低层细节建模任务，从而损害语义表示。Pixio 将解码器扩展至 32 层，维度 512，使编码器能专注于语义压缩。同时，单像素掩码允许模型通过局部复制完成重建，Pixio 采用 $4 \times 4$ patch 块掩码，迫使模型依赖全局上下文进行预测。掩码重建损失定义为：

$$
\mathcal{L}_{\text{rec}} = \frac{1}{N_{\text{mask}}}\sum_{i \in \text{mask}} \| x_i - \hat{x}_i \|_2^2
$$

其中 $x_i$ 为真实像素块，$\hat{x}_i$ 为解码器预测值。该设计通过增加重建难度，抑制捷径学习，使编码器学习更鲁棒的跨层级表示。

### 多类 Token 与数据自筛选

MAE 使用单个 [CLS] token 捕获全局信息，但单一 token 无法区分场景类型、风格、物体概念等多样全局属性。Pixio 引入 8 个 [CLS] token，下游任务中通过平均或拼接使用。数据方面，Pixio 使用 20 亿网络爬取图像，采用基于重建损失的软自筛选策略：预计算每张图像的重建损失 $l_i$，采样时以概率 $u \sim U(0,1)$ 接受图像，若 $l_i \ge u$ 则保留。该策略下采样易重建图像（如产品图），保留视觉丰富内容，避免基准分布偏差。

## 实验评估

Pixio 在密集预测任务上超越 DINOv3，但在通用分类上落后。实验覆盖 NYUv2、KITTI 深度估计，ADE20K、Pascal VOC 语义分割，MapAnything 3D 重建及 CortexBench 机器人学习。基线包括 MAE、DINOv2、DINOv3，缺失 BYOL、SimCLR 等非对比/对比基线，但鉴于 Pixio 定位为像素空间方法，与潜在空间方法对比更具针对性。

| 任务 | 指标 | MAE-H/14 | DINOv3-H+/16 | Pixio-H/16 |
| :--- | :--- | :--- | :--- | :--- |
| NYUv2 深度 | RMSE↓ | 0.465 | 0.320 | 0.268 |
| NYUv2 深度 | δ1↑ | 80.8 | 93.2 | 95.5 |
| ADE20K 分割 | mIoU↑ | 37.6 | 50.1 | 53.6 |
| IN-1K k-NN | Acc↑ | 37.9 | - | 59.5 |

Pixio 在 NYUv2 深度估计上 RMSE 从 0.320 降至 0.268，δ1 从 93.2 升至 95.5；ADE20K mIoU 从 50.1 升至 53.6。IN-1K k-NN 准确率为 59.5%，显著低于 DINOv3 的 76.5%（据领域综述），表明像素监督在通用分类上存在局限。

消融实验显示，解码器深度从 8 增至 32 层，IN-1K k-NN 从 35.3 升至 55.8，ADE20K mIoU 从 35.8 升至 40.4。掩码粒度从 $1 \times 1$ 增至 $2 \times 2$，IN-1K k-NN 提升 19.0，NYUv2 RMSE 从 0.431 降至 0.362。但掩码粒度增至 $8 \times 8$ 时性能下降，因掩码区域过大导致不可预测性。数据方面，20 亿未筛选图像性能低于 IN-21K，经自筛选后 IN-1K k-NN 从 54.2 升至 59.5，ADE20K mIoU 从 44.7 升至 46.8。

评估边界：Pixio 未报告置信区间，且 IN-1K 评估未使用 ImageNet 数据预训练，而 DINOv3 包含 10% ImageNet 数据，导致分类性能对比不公平。代码开源，但 5.4B 模型训练需 20B 样本，计算成本高，小规模复现性受限。

## 关联研究分析

从监督信号定义看，Pixio 与 I-JEPA 的根本差异在于目标空间。I-JEPA 在潜在空间预测嵌入，避免高频噪声过拟合，但可能丢弃低层几何信息；Pixio 在像素空间重建，强制模型保留所有层级信息，但面临重建任务难度与表示质量的权衡。Pixio 通过深解码器解决 MAE 的编码器-解码器容量失衡，而 I-JEPA 通过教师-学生架构解决潜在预测的稳定性问题。两者在密集预测任务上均表现优异，但 Pixio 在通用分类上的落后表明，像素监督可能牺牲了高层语义抽象的紧凑性。

从数据策略看，Pixio 的软自筛选与 DINOv2 的基准中心策展形成对比。DINOv2 使用基准图像检索相似训练数据，并重复采样基准图像，导致模型对特定分布过拟合；Pixio 基于重建损失采样，保留视觉丰富内容，避免基准偏差。然而，Pixio 未验证其在极端域外场景（如医学影像、遥感）的鲁棒性，而 DINOv2 在跨域任务中表现更稳定。数据自筛选策略在视频或多模态场景中的扩展性，论文未给出回答。

## 总结

Pixio 解决的核心矛盾是潜在空间监督信号的人为偏差与像素空间重建任务难度不足。其切入点在于指出像素是视觉信息的原始载体，通过增强 MAE 的解码器容量、掩码粒度与数据规模，使像素重建成为足够挑战性的任务。Pixio 在 NYUv2 深度估计上 RMSE 降至 0.268，ADE20K mIoU 升至 53.6，证明像素监督在密集预测任务上的竞争力。其边界在于 IN-1K k-NN 准确率仅 59.5%，显著低于潜在空间方法，且未验证域外鲁棒性。当预训练数据规模进一步扩大时，像素监督与潜在空间预测的性能差距是否会缩小，论文未给出回答。
