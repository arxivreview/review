# CVPR2026最新论文 ｜Beyond Soft Label: Dataset Distillation via Orthogonal Gradient Matching ｜正交梯度匹配

研究机构：新加坡国立大学

作者：Deyu Bo、Xinchao Wang

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_4c892f636152)

> 数据集蒸馏旨在以极小规模的合成数据替代原始大规模数据集，以缓解存储与计算成本。现有基于批归一化（Batch Normalization, BN）统计量匹配的方法在软标签下有效，但在硬标签场景下性能甚至劣于随机子集，暴露出其对模型优化知识捕获的缺失。本文指出BN匹配仅对齐梯度尺度而忽略方向，并提出正交梯度匹配（Orthogonal Gradient Matching, OGM），通过奇异向量对齐来保留优化方向信息。该方法在硬标签下实现了关键突破，但在软标签下仍未超越生成式蒸馏的最先进水平，其通用性存疑。

## 研究背景

理解本文需厘清梯度在神经网络训练中的双重作用：尺度与方向。传统优化器如随机梯度下降（Stochastic Gradient Descent, SGD）直接利用梯度向量更新参数，而现代优化器如Muon通过奇异值分解（Singular Value Decomposition, SVD）提取梯度的奇异向量，仅用方向信息更新，证明了方向对收敛速度的决定性影响。这种方向性在数据稀缺时尤为关键，因为此时梯度尺度的噪声干扰更大，方向信息的稳定性成为模型泛化的核心。

数据集蒸馏的主流路线经历了从梯度匹配到分布匹配的演进。早期梯度匹配方法计算成本高，难以扩展至ImageNet-1K；随后SRe2L等提出匹配BN层的均值与方差，首次实现了ImageNet-1K的蒸馏，但严重依赖教师模型生成的软标签。当移除软标签仅使用硬标签时，这些BN匹配方法的性能急剧下降，甚至低于随机选择的数据子集。这一现象揭示了BN匹配范式的根本缺陷：它未能捕捉模型在优化过程中的动态知识，导致合成数据缺乏指导模型收敛的有效信号。

本文的切入点在于从梯度视角重新审视BN匹配的失效机制。通过理论分析与实验验证，作者发现BN匹配仅影响梯度的尺度（scale），而忽略了梯度的方向（direction）。在数据受限的蒸馏场景中，方向信息比尺度信息对模型性能的影响更为显著。基于此，本文提出OGM，旨在通过匹配真实数据与合成数据的梯度方向，使合成数据能够承载模型优化的关键知识，从而在硬标签场景下恢复甚至超越随机子集的性能。

## 核心方法

### 方法参照系

本文属于梯度匹配类方法的变体。标准梯度匹配（Gradient Matching, GM）通过最小化真实与合成梯度的余弦距离来优化合成数据，但余弦距离仅适用于向量，无法准确对齐矩阵型梯度（如卷积核）的方向。本文的关键差异在于将匹配对象从“余弦相似度”升级为“奇异向量方向”，并引入前向传播计算伪梯度以降低计算开销。

### 梯度正交化与方向匹配

BN匹配失效的根源在于其仅对齐了梯度的尺度。对于线性层，BN的方差 $\sigma$ 直接缩放梯度 $\nabla_W L$，但忽略了梯度本身的方向结构。OGM通过SVD将梯度矩阵 $G$ 分解为 $USV^\top$，并定义正交梯度 $G_o = UV^\top$，即置所有奇异值为1，仅保留方向信息。目标函数定义为真实与合成正交梯度的Frobenius范数距离：

$$
d(G_T^o, G_S^o) = \| U_T V_T^\top - U_S V_S^\top \|_F
$$

该公式的物理含义是：通过最小化两个正交矩阵之间的差异，强制合成数据的梯度方向与真实数据一致，从而保留模型优化的“路径”信息。这一设计解决了BN匹配在硬标签下因缺乏方向引导而导致的收敛停滞问题。

### 前向伪梯度近似

标准梯度匹配需反向传播计算真实梯度，计算开销大。OGM利用最小二乘损失（Least-Squares Error, LSE）的闭式解梯度 $\nabla_W L_{LSE} = WXX^\top - YX^\top$ 作为伪梯度。由于卷积操作等价于矩阵乘法，该伪梯度可在前向传播中直接计算，无需反向传播。具体地，OGM将输入输出特征图重塑为矩阵 $\hat{X}_{in}$ 和 $\hat{X}_{out}$，并定义伪梯度为：

$$
\hat{G} = \frac{1}{nhw} \hat{X}_{out} \hat{X}_{in}^\top - \text{avg}(\hat{X}_{in}^\top)
$$

其中 $nhw$ 为样本数、高度与宽度的乘积，$\text{avg}(\hat{X}_{in}^\top)$ 为特征图均值，用于替代与类别数相关的 $YX^\top$ 项。这一近似使得OGM能在单次前向传播中完成方向匹配，显著降低了计算复杂度，使其适用于大规模数据集。

## 实验评估

实验在ImageNet-1K上进行，IPC=10，对比方法包括SRe2L、G-VBSM、RDED等BN匹配类方法及随机子集。基线覆盖BN匹配路线，但缺失生成式蒸馏方法（如CoDA、LGD）的对比，限制了与当前SOTA的全面比较。

| 方法 | 标签类型 | Top-1 Acc (%) |
| :--- | :--- | :--- |
| OGM | Soft | 47.0 |
| OGM | Hard | 16.7 |
| Random Subset | Hard | < 16.7 |

OGM在软标签下达到47.0%准确率，在硬标签下达到16.7%，显著优于随机子集及SRe2L等BN匹配方法。硬标签下+9.2%的提升验证了方向匹配在缺乏软标签监督时的有效性，但软标签下47.0%仍低于领域综述中LGD的60.1%，表明OGM在软标签场景下未超越生成式方法。

消融实验显示，Muon优化器在数据受限场景下比SGD提升7.1%准确率，证实了梯度方向对收敛的关键作用。OGM采用RDED初始化与补丁级增强，进一步提升了合成数据的语义真实性。然而，论文未报告置信区间，且仅在ImageNet-1K上验证，缺乏CIFAR-10/100等小数据集的对比，限制了结论的普适性。

评估边界方面，OGM依赖预计算的真实数据梯度方向，需存储SVD结果，增加了内存开销。代码未公开，超参数如 $\gamma=0.05$ 的敏感性未详细讨论。硬标签16.7%与软标签47.0%的巨大差距暗示方向匹配仍部分依赖软标签提供的类别信息，纯硬标签下的性能提升空间有限。

## 关联研究分析

从问题动机看，OGM与SRe2L形成直接对立。SRe2L通过BN匹配实现大规模蒸馏，但依赖软标签；OGM则证明BN匹配在硬标签下失效，并指出方向匹配是替代软标签的关键。这一差异源于对“数据质量”定义的不同：SRe2L关注统计量对齐，OGM关注优化动态对齐。OGM的硬标签突破揭示了BN匹配范式的理论盲区，但其在软标签下未超越生成式方法，暗示方向匹配可能无法完全替代生成先验提供的语义丰富度。

从方法设计看，OGM与标准GM共享局部到全局框架，但将余弦距离替换为奇异向量匹配。标准GM的余弦距离对矩阵型梯度不敏感，而OGM的SVD分解能捕捉卷积核的方向结构。这一改进源于现代优化器（如Muon）对矩阵梯度方向的研究，将优化器理论引入蒸馏领域。然而，OGM的前向伪梯度近似是否在所有层类型（如注意力层）上保持方向一致性，论文未给出验证，这可能限制其在Transformer架构上的泛化能力。

## 总结

本文旨在解决BN匹配在硬标签场景下性能劣于随机子集的核心矛盾。现有方法因仅对齐梯度尺度而忽略方向，导致合成数据缺乏优化知识；OGM通过SVD正交化提取奇异向量，以前向伪梯度实现方向匹配，在硬标签下取得16.7%准确率，显著优于随机子集。然而，软标签下47.0%的性能仍低于生成式SOTA，且硬软标签间巨大差距暗示方向匹配对软标签的隐性依赖。当支持集规模增大或架构变为Transformer时，前向伪梯度的方向一致性是否依然成立，论文未给出回答。
