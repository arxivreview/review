# CVPR2026最新论文 ｜SpiralDiff: Spiral Diffusion with LoRA for RGB-to-RAW Conversion Across Cameras ｜信号依赖扩散与相机适配的RGB-to-RAW转换

研究机构：天津大学

作者：Huanjing Yue、Shangbin Xie、Cong Cao 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.14885)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.14885)

> RGB-to-RAW转换旨在从海量RGB数据逆向合成RAW图像，以突破传感器特定数据集规模与多样性不足的瓶颈。现有生成式方法采用各向同性噪声，忽略了重建难度随像素强度变化的物理特性，且多相机联合训练导致ISP特征混淆。本文提出SpiralDiff，通过引入信号依赖噪声权重图与相机感知LoRA模块，实现强度自适应重建与跨相机统一建模。该方法在四个基准上刷新了转换质量记录，但其对真实ISP非线性响应的泛化边界仍存疑。

## 研究背景

RAW图像保留了传感器捕获的线性辐射度与高动态范围，是低光增强与高层视觉任务的理想输入。然而，构建特定传感器的RAW数据集成本高昂且耗时，导致现有RAW数据在规模与多样性上远逊于RGB集合。为缓解这一数据稀缺问题，RGB-to-RAW转换技术应运而生，其核心在于逆向执行图像信号处理器（Image Signal Processor, ISP）管线，从RGB图像重建合理的RAW图像。

主流无元数据方法通过端到端学习映射关系，但面临两个关键瓶颈。其一，重建难度具有信号依赖性：低强度区域残差小且稳定，而高强度及过曝区域因非线性色调映射与数值截断导致残差大且不确定，全局均匀的重建策略无法兼顾两端。其二，多相机统一建模时，简单合并数据会导致模型混淆不同ISP特性，学习出妥协的表征，性能反而下降。SpiralDiff针对这两个被忽略的结构性问题，提出在扩散过程中引入空间变化的噪声权重，并设计相机感知的低秩适配模块，以在统一框架内实现强度自适应与相机特异性解耦。

## 核心方法

### 方法参照系

本文基于ResShift高效扩散框架，该框架通过残差移位设计仅需4步采样即可完成图像恢复。与ResShift处理通用图像恢复不同，RGB-to-RAW转换面临ISP非线性导致的强度依赖残差，且需处理多相机ISP差异，这要求噪声注入机制与模型权重均具备条件自适应能力。

### 信号依赖噪声调度

ResShift采用各向同性高斯噪声，对所有像素施加均匀扰动，无法区分低强度区域的高保真需求与高强度区域的高不确定性。SpiralDiff在正向扩散过程中引入时间变化的权重图 $w_t$，调制噪声方差，使低强度区域接收较小扰动以保留细节，高强度区域接收较强噪声以容纳非线性失真。权重图定义为 $w_t = x_0 + \eta_t e_0$，其中 $e_0 = y_0 - x_0$ 为RGB与RAW残差，$\eta_t$ 为预定义移位序列。该设计使噪声水平随信号从RAW向RGB转换的过程动态演化，在 $t \to 0$ 时权重图关联于 $x_0$，确保输出稳定性。

$$
x_t = x_0 + \eta_t e_0 + \sqrt{\eta_t} \epsilon, \quad \epsilon \sim \mathcal{N}(0, w_t^{[2]})
$$

此公式表明，噪声 $\epsilon$ 的方差由 $w_t$ 的逐像素平方值 $w_t^{[2]}$ 控制，实现了空间自适应的噪声注入。当 $w_t \equiv 1$ 时，SpiralDiff退化为ResShift，保证了框架的兼容性。

### 相机感知LoRA适配

多相机数据合并训练导致ISP特征混淆，传统相机嵌入方法在联合训练中性能甚至低于无条件基线。SpiralDiff提出CamLoRA模块，由多个轻量级LoRA层组成，根据输入相机标签动态选择并注入相机特异性低秩更新。LoRA层秩设为 $r=8$，仅增加2.7%参数（1.05M），在冻结主干网络的前提下学习相机特定适配。该设计使统一模型能区分不同传感器特性，且预训练后可通过微调单一LoRA层快速适配新相机，显著降低数据需求。

## 实验评估

实验在FiveK (Canon/Nikon) 与NOD (Nikon/Sony) 四个基准上进行，对比CycleISP、InvISP、ReRAW及RAW-Diffusion。所有方法在相同数据划分下重新训练，分为独立训练与联合训练两种设置。

| 方法 | FiveK Canon (PSNR/SSIM) | FiveK Nikon (PSNR/SSIM) | NOD Nikon (PSNR/SSIM) | NOD Sony (PSNR/SSIM) |
| :--- | :--- | :--- | :--- | :--- |
| RAW-Diffusion | 40.63 / 0.9889 | 40.35 / 0.9916 | 49.60 / 0.9950 | 46.80 / 0.9897 |
| SpiralDiff | 42.82 / 0.9936 | 41.72 / 0.9925 | 53.64 / 0.9990 | 50.46 / 0.9980 |
| SpiralDiff + CamLoRA | 42.46 / 0.9934 | 43.82 / 0.9950 | 52.62 / 0.9988 | 50.08 / 0.9977 |

SpiralDiff在独立设置下全面超越RAW-Diffusion，NOD Nikon提升4.04 dB。联合设置下，CamLoRA使性能接近独立训练水平，验证了相机适配的有效性。

| 变体 | FiveK Canon (PSNR/SSIM) | NOD Nikon (PSNR/SSIM) |
| :--- | :--- | :--- |
| Baseline (ResShift) | 41.40 / 0.9906 | 53.48 / 0.9989 |
| $y_0$ 加权 | 40.06 / 0.9912 | 53.42 / 0.9990 |
| $w_t$ 加权 (SpiralDiff) | 42.82 / 0.9936 | 53.64 / 0.9990 |

消融实验显示，静态权重 $y_0$ 性能低于基线，证明噪声权重需随扩散步骤动态演化。CamLoRA相比相机嵌入方法在FiveK Canon上提升1.49 dB，且1-shot适配性能优于从头训练。

评估仅使用PSNR与SSIM，未报告LPIPS等感知指标，且未包含计算效率对比。代码已开源，超参数（如 $T=4$, $r=8$）明确，但缺乏跨ISP泛化的严格测试，仅在NTIRE真实ISP数据上做了插件式验证。

## 关联研究分析

从问题动机看，SpiralDiff与Physics-Guided Rectified Flow均旨在解决跨相机泛化，但前者依赖数据驱动的信号依赖噪声，后者采用显式物理噪声模型。SpiralDiff未建模泊松-高斯噪声等物理机制，其强度依赖权重仅基于RGB残差统计，这可能限制其在未见传感器上的泛化能力，因为不同ISP的非线性响应曲线存在差异。

从方法设计看，SpiralDiff与RAW-Diffusion同属扩散生成路线，但后者采用各向同性噪声。SpiralDiff引入的空间变化噪声权重直接针对ISP非线性导致的强度依赖残差，这一设计源于对FiveK数据中残差-强度关系的实证观察。然而，该权重图基于RGB图像 $y_0$ 计算，在极端过曝区域，RGB值已饱和，权重图可能无法准确反映RAW域的真实不确定性，这是其方法设计的潜在盲区。

## 总结

SpiralDiff针对RGB-to-RAW转换中强度依赖重建难度与多相机ISP混淆两大矛盾，通过信号依赖噪声调度与CamLoRA模块，在统一框架内实现了强度自适应与相机特异性解耦。实验表明，该方法在NOD Nikon上达到53.64 dB PSNR，较基线提升4.04 dB，且1-shot适配性能优于从头训练。其边界在于权重图基于RGB残差统计，未显式建模物理噪声机制，且在极端过曝区域可能失效。当面对具有显著不同非线性响应曲线的未见传感器时，仅依赖RGB强度统计的噪声权重是否仍能保持重建保真度，论文未给出回答。
