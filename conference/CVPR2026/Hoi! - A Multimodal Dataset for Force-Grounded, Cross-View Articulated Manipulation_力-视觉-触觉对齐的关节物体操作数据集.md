# CVPR2026最新论文 ｜Hoi! - A Multimodal Dataset for Force-Grounded, Cross-View Articulated Manipulation ｜力-视觉-触觉对齐的关节物体操作数据集

研究机构：瑞士苏黎世联邦理工学院、德国慕尼黑工业大学

作者：Tim Engelbracht、René Zurbrügg、Matteo Wohlrapp 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_80f8d3e2939a)

> 具身智能从感知到控制的闭环长期受制于数据模态割裂：人类视频数据集缺乏物理力反馈，机器人数据集缺乏自然人类演示。现有方案无法同时回答“视觉外观如何关联物理力”与“人类技能如何迁移至机器人本体”这两个核心问题。Hoi! 通过设计手持式力-触觉夹爪，在真实室内环境中同步采集人手与机器人执行同一关节物体操作时的多模态数据，构建了首个力-视觉-触觉对齐的跨本体数据集。其价值在于填补了物理交互真值的数据空白，但作为数据集论文，其算法贡献有限，且评估仅验证了现有方法的失效边界，未证明新范式的有效性。

## 研究背景

当机器人试图模仿人类操作抽屉或门把手时，它面临的不仅是视觉上的遮挡与形变，更是物理层面的力-位姿耦合。传统视觉交互检测依赖 RGB 图像推断动作语义，但无法获取接触力的大小与方向，导致生成的运动轨迹在物理仿真中常出现穿透或悬浮。这种“视觉-物理”解耦使得模型难以理解关节物体的运动约束（如铰链的旋转轴、滑轨的平移范围），进而阻碍了从感知到控制的迁移。为弥合这一鸿沟，研究者引入了关节物体理解（Articulation Understanding）概念，旨在从视频中估计物体的运动参数（如轴、类型），但现有方法多依赖静态扫描或仿真数据，缺乏真实交互中的动态力反馈。

主流关节物体数据集如 Arti4D 和 RBO 提供了运动学标注，但前者仅包含 1 小时交互数据且无多视角覆盖，后者规模小且缺乏机器人本体数据。与此同时，机器人操作数据集如 DROID 和 AgiBot World 虽具备大规模遥操作数据，但多聚焦于桌面级抓取，缺乏对复杂关节家具（如冰箱、洗碗机）的长程交互记录。这种数据割裂导致无法系统研究“人类演示”与“机器人执行”之间的跨本体迁移问题：例如，人手操作产生的力信号能否直接指导机器人夹爪的控制？Hoi! 数据集正是针对这一空白，通过统一采集人手与机器人对同一物体的操作，将视觉、力、触觉信号在时空上严格对齐，为具身智能提供了物理一致的训练基础。

## 核心方法

### 多模态同步采集管线

Hoi! 的核心在于构建一个能够同时捕获“所见”（视觉）、“所做”（运动）与“所感”（力/触觉）的采集系统。不同于传统数据集仅记录 RGB 视频，该管线集成了 Project Aria 眼镜（提供第一人称 RGB、SLAM、眼动）、iPhone 13 Pro（提供第三人称 RGB-D）以及自定义的 Hoi! 夹爪。Hoi! 夹爪采用对置式 GelSight Digit 传感器获取高分辨率触觉图像，并配备 Bota SensONE 6-DoF 力矩传感器测量腕部交互力。所有传感器通过 QR 码时间戳同步，实现 10-25 ms 的时间对齐精度，确保力信号与视觉帧的严格对应。

### 跨本体统一表征

为验证跨本体迁移，Hoi! 设计了四种操作本体：人手、人手+腕相机、UMI 夹爪、Hoi! 夹爪。每种本体执行相同的关节物体操作（如开合抽屉），并记录对应的力-位姿轨迹。这种设计使得同一物体的交互在不同本体下具有可比的物理表征。形式化地，对于物体 $o$ 和动作 $a$，数据集提供四组对齐序列 $\{V_i, F_i, T_i, P_i\}_{i=1}^4$，其中 $V$ 为视觉流，$F$ 为力矩流，$T$ 为触觉流，$P$ 为位姿流。这种统一表征允许研究者直接比较不同本体下的力-视觉映射关系，例如验证人手操作产生的力模式是否能在机器人夹爪上复现。

### 场景级几何真值

为锚定交互在真实空间中的几何位置，Hoi! 使用 Leica RTC360 激光扫描仪在每个环境操作前后采集高密度 3D 点云。这些点云不仅提供静态场景结构，还捕捉了关节物体操作引起的几何变化（如门打开后的空间占用）。通过视觉定位（hloc）将各传感器轨迹对齐到共享世界坐标系，实现了厘米级的空间对齐精度。这一设计解决了单目视觉深度歧义问题，为关节轴估计和力方向分解提供了精确的几何参考。

## 实验评估

实验设置涵盖三个任务：关节物体估计、触觉力估计和视觉力估计。基线方法包括 GPT-5（VLM）、ArtGS（高斯溅射）、ArtiPoint（单目深度）以及 Sparsh（触觉表示学习）和 ForceSight（力预测）。在关节物体估计任务中，GPT-5 在 Hoi! 数据集上的铰链类型召回率为 71.9%，低于其在 Arti4D 上的 72.4%，表明真实环境中的杂乱背景对 VLM 的鲁棒性提出了挑战。ArtGS 和 ArtiPoint 在 Hoi! 上的性能显著下降，其中 ArtiPoint 的轴角度误差高达 47.06 度，主要归因于单目深度噪声对 3D 提升的干扰。

| :--- | :--- | :--- | :--- | :--- |
| GPT-5 (Ego) | Hoi! | 71.9 | - | - |
| ArtGS | Hoi! | 100.0 | 58.39 | 0.321 |

| ArtGS | Arti4D | 52.59 | 0.25 | - |
| ArtiPoint | Arti4D | 14.54 | 17.14 | 0.07 |

在触觉力估计任务中，Sparsh 模型在 Hoi! 上的 RMSE 为 2.23 N（投影后）和 2.57 N（原始），远高于其在原始基准上的毫牛级精度。这一退化主要源于真实环境中接触几何的复杂性（如手柄、边缘）超出了模型训练时的简单压头分布。在视觉力估计任务中，ForceSight 模型在 Hoi! 上的 RMSE 为 2.23 N（投影后）和 2.57 N（原始），而在其原始数据集上仅为 0.404 N。特别是在包含多个高力需求物体（如冰箱、烤箱）的厨房场景中，ForceSight 的 RMSE 高达 3.531 N，表明现有模型对高刚度关节机制的泛化能力不足。

评估边界方面，Hoi! 数据集未提供端到端策略学习的基准，仅验证了感知任务的可行性。此外，由于力信号受操作者个体差异影响，跨本体力迁移的定量评估仍缺乏标准化协议。代码与超参数未完全公开，但夹爪设计已开源，可复现性主要依赖于硬件可用性。

## 关联研究分析

从问题动机看，Hoi! 与 Arti4D 和 RBO 等现有关节物体数据集的根本差异在于物理模态的完整性。Arti4D 仅提供视觉与运动学标注，缺乏力反馈，导致其无法支持力-视觉联合学习；RBO 虽包含有限力测量，但规模小且无多本体覆盖。Hoi! 通过引入力-触觉传感器，将交互理解从“几何重建”扩展至“物理感知”，这一转变源于具身智能对物理一致性的需求。然而，这种差异也暴露了现有方法的盲区：多数关节估计方法依赖精确深度或静态扫描，而 Hoi! 揭示了在真实杂乱环境中，单目深度噪声对 3D 提升的严重干扰，提示未来方法需增强对深度不确定性的鲁棒性。

从方法设计看，Hoi! 与 ForceSight 和 Sparsh 等力预测/触觉模型的关系在于数据驱动范式。ForceSight 基于文本引导的力推理，Sparsh 基于自监督触觉表示学习，两者均在受控环境中表现优异，但在 Hoi! 的真实场景中性能显著退化。这一对比表明，现有模型对接触几何和负载分布的假设过于简化，无法泛化到复杂家具操作。Hoi! 的价值不仅在于提供数据，更在于揭示了现有模型在“开放世界”交互中的失效边界，为后续研究指明了改进方向：需引入更复杂的接触建模或物理约束来增强力预测的鲁棒性。

## 总结

Hoi! 数据集旨在解决具身智能中视觉感知与物理交互解耦的核心矛盾，通过构建力-视觉-触觉对齐的跨本体数据，填补了真实环境中关节物体操作的数据空白。其切入点在于设计手持式力-触觉夹爪，使人类操作者能以机器人级精度记录交互力，从而统一人类与机器人的交互表征。实验表明，现有关节估计和力预测方法在真实环境中性能显著退化，如 ArtiPoint 的轴角度误差高达 47.06 度，ForceSight 的力预测 RMSE 从 0.404 N 升至 2.23 N，揭示了现有模型对复杂接触几何和高力需求场景的泛化不足。然而，Hoi! 的边界在于其评估仅聚焦于感知任务，未验证端到端策略学习的有效性，且跨本体力迁移的定量评估缺乏标准化协议。当操作者个体差异导致力信号分布偏移时，现有跨本体迁移方法是否仍能保持物理一致性，论文未给出回答。
