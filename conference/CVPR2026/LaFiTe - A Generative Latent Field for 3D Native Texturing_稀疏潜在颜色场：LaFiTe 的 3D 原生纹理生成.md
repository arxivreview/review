> 导读 3D 纹理生成旨在从参考图像或文本提示在任意网格拓扑上合成高保真、无缝的表面外观，以替代依赖人工 UV 展开或易产生接缝的多视图投影流程。现有原生方法受限于缺乏能同时兼顾高频细节表达与拓扑解耦的紧凑潜表示，导致生成质量难以超越 2D 投影基线。LaFiTe 通过构建稀疏潜在颜色场 VAE 并复用其编码单色点云获取几何条件，实现了免 UV 的级联纹理与 PBR 材质生成。该框架在重建保真度上显著超越现有 SOTA，但其对 2D 大模型语义先验的缺失限制了复杂文本渲染能力。

## 研究背景

理解 LaFiTe 需厘清 3D 纹理表示与生成模型的耦合关系。传统流程依赖 UV 展开将 3D 表面映射至 2D 平面，但 UV 参数化的非唯一性导致纹理在岛屿边界处产生扭曲与接缝。多视图投影策略虽规避了 UV 依赖，却因跨视图对齐误差与遮挡问题，在融合阶段引入不可消除的伪影。这两种 2D 中心范式均无法保证 3D 空间的全局连贯性，迫使研究转向直接在 3D 空间建模纹理，即“3D 原生纹理化”。

该领域的核心瓶颈在于缺乏适配生成模型的 3D 纹理潜表示。理想表示需满足三个标准：足以捕获高频细节的表达力、与网格拓扑及 UV 坐标解耦的独立性、以及便于生成模型学习的紧凑结构化特征。早期原生方法多基于网格表面或密集 3D 纹理场，但在紧凑潜空间中难以保留高频细节，导致生成纹理模糊。LaFiTe 的切入点正是填补这一表示空白，通过设计一种局部且连续的稀疏潜在颜色场，从根本上解耦纹理外观与离散网格连接，为高保真原生纹理化提供基础。

## 核心方法

### 方法参照系

LaFiTe 属于原生 3D 纹理生成路线，其标准流程通常包含两个阶段：首先通过 VAE 将 3D 外观编码为紧凑潜变量，随后利用条件生成模型（如扩散或流匹配）在潜空间中合成新纹理。与依赖 2D 特征投影或独立几何编码器的通用流程不同，LaFiTe 的关键差异在于直接使用原生彩色点云作为 VAE 输入，并复用同一编码器提取几何条件，消除了对 2D 先验或额外几何网络的依赖。

### 稀疏潜在颜色场 VAE

LaFiTe 的 VAE 编码器摒弃了将预训练 2D 特征投影至体素的常规做法，转而直接处理从纹理化网格均匀采样的密集彩色点云 $P = \{x_i = (p_i, n_i, c_i)\}$。这一设计动机在于消除 2D 投影带来的视图依赖、分辨率限制及特征与 3D 表面属性不匹配的问题。编码器采用点-体素注意力机制替代 PointNet，通过体素内自注意力与点-体素交叉注意力，将点级特征聚合为体素级特征 $\tilde{v}_k$，最终生成稀疏结构化潜变量 $Z = \{z_k\}$。解码器通过局部特征网格插值与浅层 MLP 重建连续颜色场 $C(p)$。训练目标为颜色 L1 损失与 KL 散度正则项之和：

$$ \mathcal{L}_{VAE} = \sum_i \| \hat{c}_i - c_i \|_1 + \beta D_{KL}(q(z|x) || p(z)) $$

该公式确保模型在 3D 空间直接监督，避免渲染损失引入的模糊偏差，同时通过高斯噪声增强提升高频纹理的鲁棒性。

### 单色点云几何条件化与级联生成

LaFiTe 发现 VAE 编码器在编码纹理的同时隐式捕获了高精度几何信息。通过将输入点云颜色设为白色（1,1,1），编码器可提取纯几何潜变量 $z_{geo}$，作为无遮挡、无歧义的 3D 形状先验。这一设计解决了独立几何编码器与纹理表示不对齐的问题。生成阶段采用条件流匹配模型，以 $z_{geo}$ 和参考图像特征为条件，合成反照率潜变量 $z_{albedo}$。随后，模型微调为以 $z_{albedo}$ 为条件生成粗糙度与金属度潜变量，实现几何→反照率→PBR 的级联生成。流匹配目标函数为：

$$ \mathcal{L}_{RM} = \mathbb{E}_{t, x_0, \epsilon} \| v_\theta(x_t, t, c_{geo}, c_{img}) - (x_0 - \epsilon) \|^2 $$

其中 $x_t = (1-t)x_0 + t\epsilon$。该级联策略忠实建模了 PBR 材质与反照率的物理依赖关系，实现了材质外观的完全解耦控制。

## 实验评估

LaFiTe 在由 Objaverse、Objaverse-XL 及 TexVerse 组成的 100 万规模数据集上训练，测试集包含约 800 个由商业 AI 工具生成的新几何网格，以确保评估的泛化性。基线覆盖多视图投影（MVPaint, SyncMVD）、UV 空间生成（TEXGen）及原生方法（TRELLIS）。在 VAE 重建保真度上，LaFiTe 在 128³ 分辨率下取得 34.62 dB PSNR 与 0.039 LPIPS，较 TRELLIS-RF128* 的 23.07 dB PSNR 提升超过 10 dB，证实了直接编码 3D 点云在高频细节保留上的优势。

| 方法 | PSNR (dB) | SSIM | LPIPS |
|---|---|---|---|
| TRELLIS-RF128* | 23.07 | 0.880 | 0.127 |
| Ours-128 | 34.62 | 0.967 | 0.039 |

在端到端条件纹理生成任务中，LaFiTe 在 Unshaded 设置下取得 101.66 FID 与 0.035 KDCLIP，优于 MVPaint 的 113.20 FID 与 0.048 KDCLIP，以及在 Shaded 设置下取得 105.75 FID，优于 MaterialMVP 的 116.72 FID。消融实验显示，输入点云密度从 20,480 增至 4,096,000 时，PSNR 从 26.07 dB 提升至 34.45 dB，表明模型对密集采样具有强扩展性，验证了高保真表面采样策略的必要性。

| 方法 | 条件 | Unshaded FID | Unshaded KDCLIP | Shaded FID |
|---|---|---|---|---|
| MVPaint | Text | 113.20 | 0.048 | 106.45 |
| MaterialMVP | Image | 116.72 | 0.051 | 107.46 |
| Ours | Image | 101.66 | 0.035 | 105.75 |

评估边界方面，论文未报告置信区间，且测试集规模较小（800 个网格），可能影响统计显著性。代码未公开，但提供了详细的训练超参数（16/32 块 A800 GPU，AdamW 优化器，学习率 1e-4）与数据清洗流程，具备一定可复现性。指标涵盖 FID、FD、KD 及重建指标，但未包含计算效率或推理时间对比，这是当前评估体系的缺口。

## 关联研究分析

从表示设计看，LaFiTe 与 TRELLIS 的核心差异在于输入模态。TRELLIS 依赖将预训练 2D DINO 特征投影至体素，这一策略受限于 2D 特征的分辨率与视图一致性，导致高频细节丢失。LaFiTe 直接编码 3D 彩色点云，虽避免了投影歧义，但牺牲了 2D 大模型蕴含的丰富语义先验。这种取舍源于任务特性：纹理重建更依赖几何-外观的局部耦合，而语义生成更依赖全局视觉先验。LaFiTe 在重建保真度上的巨大优势（>10 dB PSNR）证实了原生 3D 输入在细节保留上的不可替代性，但其生成 FID 仍高于部分多视图方法，暗示在复杂语义场景下，2D 先验的缺失可能成为瓶颈。

从几何条件化看，LaFiTe 与 TEXTRIX 等原生方法不同，后者通常依赖独立几何编码器或显式几何场。LaFiTe 复用纹理 VAE 编码单色点云获取几何潜变量，这一设计确保了几何条件与纹理表示在潜空间中的完美对齐，避免了跨网络特征不匹配问题。然而，这种隐式几何编码是否足以支撑极端复杂拓扑（如高度自遮挡或细长结构）的纹理生成，论文未提供针对性消融。单色点云提取的几何潜变量在潜空间中可能过度压缩几何细节，导致在复杂拓扑下条件信号不足，这是该设计潜在的盲区。

## 总结

LaFiTe 旨在解决 3D 原生纹理生成中潜表示缺乏高频细节表达力与拓扑解耦能力的核心矛盾。现有方法受限于 2D 投影的视图依赖或独立几何编码器的对齐误差，无法在紧凑潜空间中同时保留细节与连贯性。LaFiTe 通过构建稀疏潜在颜色场 VAE 并复用其编码单色点云获取几何条件，实现了免 UV 的级联纹理与 PBR 生成。实验证明其在 128³ 分辨率下重建 PSNR 达 34.62 dB，生成 FID 为 101.66，显著优于多视图与 UV 基线。然而，论文自身指出其缺乏 2D 大模型先验，限制了语义合理性与文本渲染质量。当测试集扩展至包含复杂文本或高度语义依赖的资产时，LaFiTe 的生成质量是否会因 2D 先验缺失而显著劣于多视图方法，论文未给出回答。
