# CVPR2026最新论文 ｜MultiModalPFN: Extending Prior-Data Fitted Networks for Multimodal Tabular Learning ｜多模态先验数据拟合网络

研究机构：韩国首尔大学

作者：Wall Kim、Chaeyoung Song、Hanul Kim

论文原文见 [arXiv](https://arxiv.org/abs/2602.20223)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.20223)

> 表格数据与图像、文本等异构模态的联合建模长期受限于传统梯度提升树（GBDT）对非结构化特征处理的低效，以及深度模型在数据稀缺场景下的性能衰减。现有方法要么将表格序列化为文本牺牲结构信息，要么采用启发式融合策略导致模态间注意力失衡。本文切入点在于利用先验数据拟合网络（Prior-Data Fitted Networks, PFN）的摊销贝叶斯推断范式，通过模态投影器将非表格嵌入对齐至表格特征空间，实现统一处理。该框架在医疗与通用多模态基准上超越了现有方法，但其对预训练骨干的依赖及单一模态缺失场景的鲁棒性仍存疑。

## 研究背景

表格数据缺乏空间或序列结构，特征类型异构，导致传统深度学习模型难以直接应用。梯度提升树（GBDT）凭借对异构特征的鲁棒处理长期占据基准地位，但其在图像或文本等非结构化模态上的扩展仅带来有限增益。与此同时，深度模型虽能学习更丰富的表示，但在数据稀缺场景下训练缓慢且性能不稳定。这种结构性张力使得多模态表格学习成为医疗诊断（如结合检验结果与影像）和营销分析（如结合销售记录与评论）中的关键瓶颈。

表格基础模型（Tabular Foundation Models, TFMs）如 TabPFN 通过大规模合成数据预训练实现了上下文学习（In-Context Learning, ICL），在小到中等规模数据上匹配或超越 GBDT。然而，TabPFN 的预训练严格限制在纯表格分布，未探索向非结构化模态的原则性扩展。现有多模态表格方法多采用“行转文本”策略或简单的特征拼接，缺乏对模态间表示空间对齐的系统性设计，导致在模态数量不均衡时出现注意力失衡，抑制了表格信号的贡献。

本文旨在解决这一缺口，提出多模态先验数据拟合网络（Multi-Modal Prior-data Fitted Network, MMPFN）。其核心思路是复用 TabPFN 的表格先验，通过专门的模态投影器将图像和文本嵌入映射至表格兼容的 token 空间，从而在保留表格结构优势的同时整合非结构化信息。这一设计避免了从头训练多模态大模型的高昂成本，同时解决了传统融合策略中模态竞争的问题。

## 核心方法

### 方法参照系

MMPFN 建立在 TabPFN 的摊销贝叶斯推断框架之上。标准 TabPFN 将表格学习视为从有限上下文推断后验分布的过程，其骨干网络在合成数据上预训练，通过特征注意力和样本注意力实现置换不变性。本文的关键差异在于输入不再是纯表格行，而是包含图像和文本嵌入的多模态表格。因此，必须在表格骨干之前引入一个对齐机制，将异构模态的表示转换为与表格特征维度兼容的 token 序列，以便 TabPFN 的注意力机制能够统一处理。

### 多头门控多层感知机（MGM）

单模态编码器（如 DINOv2 或 ELECTRA）通常输出单一的 [CLS] 嵌入，这种过度压缩丢失了非结构化数据中的细粒度信息。MGM 位于模态投影器的第一阶段，旨在解决这一信息瓶颈。它接收 [CLS] 嵌入，通过 $N$ 个并行的多层感知机（MLP）头将其投影为 $N$ 个 $d$ 维候选 token。每个头通过门控线性单元（Gated Linear Unit, GLU）调制贡献，鼓励头间专业化，从而保留原始表示的多样方面。

$$
\mathbf{t}_i = \text{MLP}_i(\mathbf{e}_{\text{cls}}) \odot \sigma(\mathbf{W}_g \mathbf{e}_{\text{cls}} + \mathbf{b}_g), \quad i=1,\dots,N
$$

其中 $\mathbf{e}_{\text{cls}}$ 为非表格模态的 [CLS] 嵌入，$\odot$ 表示逐元素乘法，$\sigma$ 为 sigmoid 函数。该公式的物理含义是：每个 MLP 头生成一个候选特征，而 GLU 门控机制动态决定该特征的激活强度，使得不同头可以捕获图像或文本中不同语义层面的信息，而非简单地复制同一表示。

### 交叉注意力池化器（CAP）

MGM 生成的 $N$ 个 token 若直接输入 TabPFN，会导致非表格模态的 token 数量远超表格特征，引发注意力失衡：拥有更多 token 的模态会吸收大部分注意力预算，抑制表格信号的贡献。CAP 位于模态投影器的第二阶段，旨在平衡模态间的注意力分配。它引入 $K$ 个可学习查询向量，对 MGM 生成的 $N$ 个 token 进行交叉注意力，将其压缩为 $K$ 个紧凑的 $d$ 维嵌入。

$$
\mathbf{z}_k = \text{MLP}\left( \sum_{j=1}^N \alpha_{kj} \mathbf{t}_j \right), \quad \alpha_{kj} = \frac{\exp(\mathbf{q}_k^\top \mathbf{t}_j / \sqrt{d})}{\sum_{m=1}^N \exp(\mathbf{q}_k^\top \mathbf{t}_m / \sqrt{d})}
$$

其中 $\mathbf{q}_k$ 为第 $k$ 个可学习查询，$\mathbf{t}_j$ 为 MGM 输出的 token。该公式的含义是：通过可学习查询从大量候选 token 中“挑选”出最具代表性的 $K$ 个摘要，从而将非表格信息的 token 数量控制在与表格特征相当的水平，确保 TabPFN 骨干在处理多模态输入时，表格与非表格模态在注意力机制中获得均衡的权重。

## 实验评估

实验在六个多模态数据集上进行，包括 PAD-UFES-20、CBIS-DDSM、Airbnb、Salary、Cloth 和 PetFinder，涵盖表格-图像和表格-文本两种设置。基线覆盖纯表格模型（TabPFN、CatBoost）、多模态融合模型（MMCL、TIP、HEALNet、TIME）以及自动机器学习框架（AutoGluon）。值得注意的是，基线中未包含最新的表格基础模型如 TabICLv2 或 TabH2O，这可能限制了与当前 SOTA 的直接对比。

| 数据集 | TabPFN | AutoGluon | MMCL | TIME | MMPFN |
| :--- | :--- | :--- | :--- | :--- | :--- |
| PU20 | 82.17 | 81.09 | 76.61 | 80.35 | **85.22** |
| Mass | 71.27 | 76.28 | 57.62 | - | 74.53 |
| Calc | 73.31 | 71.04 | 60.12 | 72.70 | **75.40** |
| PetFinder | 36.33 | 38.81 | 36.61 | 39.25 | **40.74** |
| Airbnb | 46.96 | 44.60 | - | - | **47.78** |
| Salary | 44.96 | 45.24 | - | - | 46.17 |
| Cloth | 55.07 | 72.07 | - | - | 66.26 |

在表格-图像设置中，MMPFN 在 PU20、Calc 和 PetFinder 上取得最佳准确率，但在 Mass 上略低于 CatBoost（78.31 vs 74.53）。在表格-文本设置中，MMPFN 在 Airbnb 和 PetFinder 上领先，但在 Cloth 上低于 AllTextBERT（66.26 vs 72.07），后者将表格特征转为文本处理。这表明当文本信号占主导且表格特征信息量较少时，纯文本模型可能更具优势。

消融实验验证了 MGM 和 CAP 的有效性。在 MGM 设计中，多头门控机制（MGM）在所有数据集上均优于单头线性/MLP 和混合专家（MoE）基线，平均准确率提升约 3.2%。在 CAP 设计中，交叉注意力池化器（CAP）显著优于特征级线性调制（FiLM），平均准确率从 55.48 提升至 57.37。此外，分析显示，当非表格 token 数量与表格 token 数量接近时，MMPFN 性能最佳；若非表格 token 过多，性能下降，证实了注意力失衡假设。

评估协议采用 5 个随机种子的平均准确率，未报告置信区间或标准差，限制了统计显著性的判断。代码已开源，但预训练 TabPFN 骨干的获取和微调过程依赖特定版本，复现成本较高。实验未涵盖模态缺失场景（如仅有表格或仅有图像），也未评估在大规模数据（>100k 样本）上的扩展性，这与 TabPFN 原始设计针对中小规模数据的定位一致。

## 关联研究分析

从问题动机看，MMPFN 与 MMCL 和 TIP 等基于对比学习或半监督的方法存在根本差异。MMCL 通过对比学习对齐表格和图像嵌入，但缺乏对模态间 token 数量失衡的显式处理，导致在小数据集上表现不稳定。MMPFN 通过 CAP 机制显式控制非表格 token 数量，解决了这一结构性问题。然而，MMCL 的对比学习预训练可能提供更强的模态不变性表示，而 MMPFN 依赖冻结的 TabPFN 骨干，其模态对齐能力受限于预训练分布。这种差异源于任务特性：MMPFN 侧重利用表格先验进行快速推断，而 MMCL 侧重学习通用的跨模态表示。

从方法设计看，MMPFN 与 TIME 同属利用 TabPFN 作为表格编码器的路线，但融合策略截然不同。TIME 采用简单的特征拼接，将图像嵌入直接附加到表格特征上，导致非表格模态在注意力机制中可能占据过多权重。MMPFN 引入 MGM 和 CAP 进行显式投影和池化，实现了更精细的模态平衡。这一改进在 PetFinder 数据集上尤为明显，MMPFN 比 TIME 高出 1.49% 的准确率。然而，MMPFN 的模态投影器需要额外训练，而 TIME 的简单融合无需额外参数，这在计算资源受限场景下可能是一个劣势。此外，MMPFN 未探索动态模态缺失处理，而 LANISTR 等方法通过掩码机制支持缺失模态，这是 MMPFN 在鲁棒性上的潜在盲区。

## 总结

MMPFN 旨在解决表格基础模型无法处理异构模态的矛盾，其切入点在于复用 TabPFN 的表格先验并通过模态投影器对齐非结构化嵌入。该方法通过 MGM 扩展非表格表示的多样性，通过 CAP 平衡模态间的注意力分配，在 PU20 和 PetFinder 等数据集上取得了 85.22% 和 40.74% 的准确率，超越了纯表格基线和简单融合方法。然而，实验暴露了其在文本主导数据集（如 Cloth）上不如纯文本模型，且在模态 token 数量严重失衡时性能下降的局限。当非表格模态的信息密度远高于表格特征时，CAP 的压缩策略是否会导致关键语义信息的丢失，论文未给出回答。
