# CVPR2026最新论文 ｜BiGain: Unified Token Compression for Joint Generation and Classification ｜双目标扩散模型Token压缩

研究机构：美国北卡罗来纳州立大学

作者：Jiacheng Liu、Shengkun Tang、Jiacheng Cui 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.12240)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.12240)

> 扩散模型加速方法长期仅优化生成保真度，却忽视了同一骨干网络在分类任务中的判别能力，导致加速后分类精度显著退化。现有Token合并与降采样方法在压缩过程中丢失了高频边缘与纹理信息，而这些正是分类器依赖的关键特征。BiGain通过频率分离原则，设计了拉普拉斯门控Token合并与插值-外推KV降采样两个无训练算子，在保持生成质量的同时提升分类精度。该框架在多个数据集上验证了双目标优化的有效性，但其结论是否泛化至更复杂的语义组合任务仍存疑。

## 研究背景

扩散模型通过前向加噪与反向去噪过程建模数据分布，其推理阶段需执行数十至数百步迭代去噪，导致极高的计算开销。为降低单步计算成本，Token压缩技术（如Token合并与降采样）被引入，旨在减少自注意力机制中的二次方计算量。然而，这些方法通常仅以FID等生成指标为优化目标，忽略了扩散模型作为判别式学习器的另一重要功能：通过条件去噪似然进行图像分类。

当前领域共识认为，潜空间扩散与DiT骨干是主流范式，推理加速主要通过减少采样步数（如蒸馏）或降低单步计算成本（如剪枝、缓存）实现。然而，现有加速方法在优化生成保真度时，往往无差别地压缩所有Token，导致高频细节（如边缘、小物体、高对比度边界）被过度平滑。这种“看起来不错但分类效果差”的现象在医疗影像、工业检测等需要同一模型同时支持生成与识别的场景中尤为致命。BiGain的切入点在于，将Token压缩重构为生成保真度与判别效用的双目标优化问题，通过频率感知机制区分不同频段对两类任务的贡献差异。

## 核心方法

### 方法参照系

标准Token压缩流程（如ToMe）通过计算Token间相似度，贪心合并最相似的Token对，以最小化生成质量损失。该流程假设所有Token对生成任务的贡献均等，未考虑Token在频率域上的分布特性。本文的关键差异在于，引入频率分离原则，将压缩决策与Token的局部频率特征绑定，从而在压缩冗余的同时保留判别所需的高频信息。

### 拉普拉斯门控Token合并

在Token合并环节，传统方法使用余弦相似度或全局统计量作为合并依据，导致高频Token被错误合并。BiGain提出拉普拉斯门控Token合并（L-GTM），通过计算每个Token的局部拉普拉斯幅度作为频率评分，仅允许低频平滑Token参与合并，而保护高频细节Token。具体而言，将隐藏状态 $\mathbf{X} \in \mathbb{R}^{N \times d}$ 重塑为空间网格，计算每个位置的频率幅度：

$$
\mathbf{F}_{ij} = \text{Reduce}_c(\mathbf{L} * \mathbf{X}_{ij})
$$

其中 $\mathbf{L}$ 为拉普拉斯核，$\text{Reduce}_c$ 为通道聚合操作。该公式的物理含义是，拉普拉斯算子捕捉特征在空间维度上的二阶导数，即局部对比度；高频Token具有较大的 $\mathbf{F}_{ij}$ 值，因此被排除在合并源集合之外。这一设计解决了传统合并方法因忽略频率差异而导致分类精度急剧下降的问题，在Oxford-IIIT Pets数据集上，70%合并率下分类精度仅下降2.65%，而ToMe下降8.07%。

### 插值-外推KV降采样

在注意力计算环节，传统KV降采样方法（如ToDo）直接对Key和Value进行平均池化，导致查询侧定位精度损失。BiGain提出插值-外推KV降采样（IE-KVD），通过可控的插值-外推因子 $\alpha$ 在最近邻池化与平均池化之间进行加权，同时保持Query全分辨率。具体公式为：

$$
\mathbf{K}_{\tilde{}} = D_{\alpha,s}(\mathbf{K}), \quad \mathbf{V}_{\tilde{}} = D_{\alpha,s}(\mathbf{V}), \quad \mathbf{Q} \text{ 保持不变}
$$

其中 $D_{\alpha,s}$ 为基于步长 $s$ 和因子 $\alpha$ 的插值-外算子。该设计的动机在于，Query全分辨率保留了模型对每个输出Token的细粒度感受野，这对于扩散分类器中基于蒙特卡洛采样的逐类评分至关重要；而KV降采样则平滑地降低了内存与FLOPs开销。这一机制在DiT-XL/2骨干上表现出更强的稳定性，避免了ToDo方法在高分辨率下FID急剧恶化的问题。

## 实验评估

实验在Stable Diffusion v2.0（U-Net）与DiT-XL/2（Transformer）两个骨干上，使用ImageNet-1K、ImageNet-100、Oxford-IIIT Pets及COCO2017数据集进行评估。基线覆盖ToMe、ToDo、DiP-GO等主流Token压缩方法，但未对比最新的一致性模型或蒸馏加速方法，这可能限制了其在极端少步生成场景下的竞争力。

| 方法 | 加速类型 | FLOPs降低 | Pets Acc@1 (%) | Δ vs. Baseline |
| :--- | :--- | :--- | :--- | :--- |
| Baseline | None | – | 81.03 | – |
| ToMe | Token Merging | 10% | 72.96 | ↓8.07 |
| BiGainTM | Token Merging | 10% | 78.38 | ↓2.65 |
| ToDo | Token Downsampling | 14.2% | 79.15 | ↓1.88 |
| BiGainTD | Token Downsampling | 14.2% | 79.90 | ↓1.13 |

在同等FLOPs降低下，BiGain在分类精度上显著优于纯生成加速基线，且生成质量（FID）持平或略优。例如，在ImageNet-1K上，70%合并率下BiGain分类精度提升7.15%，FID改善0.34。

消融实验表明，拉普拉斯评分在频率感知设计中至关重要：移除拉普拉斯门控后，分类精度下降幅度显著大于其他评分策略（如余弦相似度、DFT频谱质心）。此外，仅在自注意力层进行Token合并（SA-only）比在交叉注意力或MLP层合并具有更好的质量-效率权衡，避免了提示保真度损失与细粒度细节破坏。

评估边界方面，论文未报告置信区间，且多数实验基于2,000张ImageNet-1K验证子集，可能低估了大规模数据下的泛化能力。代码已开源，但超参数（如插值-外推因子 $\alpha$ 的调度策略）在不同数据集上的敏感性未充分讨论。

## 关联研究分析

从问题动机看，BiGain与ToMe等纯生成加速方法的根本差异在于目标函数的扩展。ToMe仅优化生成保真度，假设压缩对判别任务无影响；而BiGain显式建模了生成与分类的双目标冲突，指出高频细节对分类的锚定作用。这一差异源于任务特性：扩散分类器依赖逐类去噪似然的精细比较，对Token级定位精度敏感，而生成任务更关注全局结构一致性。

从方法设计看，BiGain与Diff-Pruning等权重剪枝方法属于不同路线。Diff-Pruning通过泰勒展开识别非贡献步并剪枝权重，侧重模型结构精简；BiGain则聚焦于推理时的Token级动态压缩，无需重训练。两者在“减少计算”这一目标上互补，但BiGain的频率感知机制更适用于需要保留局部细节的判别任务。值得注意的是，BiGain未探索与蒸馏方法的结合，即是否在少步生成场景下，频率感知压缩仍能保持判别优势，论文未给出回答。

## 总结

BiGain解决的核心矛盾是扩散模型加速中生成保真度与判别效用的失衡。其切入点在于识别出高频细节对分类任务的锚定作用，并通过拉普拉斯门控与插值-外推KV降采样两个无训练算子实现频率感知的双目标优化。实验证明，在Oxford-IIIT Pets数据集上，BiGain在10% FLOPs降低下分类精度仅下降2.65%，而ToMe下降8.07%；在ImageNet-1K上，70%合并率下分类精度提升7.15%。然而，论文的实验边界局限于类条件生成与单标签/多标签分类任务，未涉及开放词汇或复杂语义组合场景。当支持集增大到5-shot时，频率感知压缩的边际收益是否递减，论文未给出回答。
