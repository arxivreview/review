# CVPR2026最新论文 ｜Adversarial Style Optimization: Enhancing VLM Jailbreaks by GRPO-based Stylistic Triggers Optimization ｜对抗风格优化

作者：Bingjun Luo、Jialin Guo、Yue Yao 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_3a0fa36af432)

> 多模态大语言模型（MLLMs）的安全对齐机制在视觉风格扰动下表现出显著的脆弱性，现有内容型越狱攻击未能覆盖这一非语义攻击面。本文发现模型对特定视觉风格存在“风格不一致性”，即内容理解鲁棒但安全防御易被风格触发器绕过。通过提出对抗风格优化（ASO）框架，利用强化学习微调图像编辑模型以自动搜索最优风格参数，将风格扰动转化为可量化的攻击增强模块。该工作验证了风格作为独立攻击向量的有效性，但其绝对攻击成功率未超越现有内容型攻击的峰值，且依赖目标模型 logits 的可访问性。

## 研究背景

当视觉编码器将图像映射至语言模型嵌入空间时，视觉特征的高维连续性与文本离散符号之间存在固有的分布偏差，即模态间隙。这种偏差导致基于文本语义构建的安全护栏无法有效覆盖视觉输入中的非语义属性。具体而言，模型在理解图像内容时表现出跨风格的鲁棒性，但其安全拒绝机制却对视觉呈现方式（如光照、构图、艺术风格）表现出异常的敏感性，这种理解能力与安全能力之间的错位被称为风格不一致性。

多模态越狱攻击的主流路线长期聚焦于内容型触发器，例如将恶意指令渲染为排版文本（FigStep, Zou et al., 2024）或优化对抗物体（HADES）。这些方法通过操纵图像的语义内容来诱导模型生成有害响应，但忽略了图像“如何呈现”这一维度。非内容型攻击如 SI-Attack（Luo et al., 2025）虽揭示了打乱图像块或文本顺序可绕过安全机制，但缺乏对视觉风格这一连续参数空间的系统性探索。现有方法未能回答：是否存在特定的风格参数组合，能在不改变图像语义内容的前提下，显著降低模型的安全拒绝置信度？

本文切入点在于将视觉风格视为一个可优化的连续变量空间，而非固定的预处理步骤。通过系统探测发现，简单的风格滤镜（如铅笔素描）即可提升攻击成功率，这证实了风格是独立于内容的脆弱性来源。然而，固定滤镜的效果有限，需通过自动化搜索找到针对特定目标模型的最优风格参数，从而构建一种可插拔的攻击增强模块。

## 核心方法

### 方法参照系

本文问题归属于多模态越狱攻击中的非内容型攻击类别。标准流程通常涉及构造对抗样本以最大化有害响应概率，但本文的关键差异在于不直接优化图像像素或语义内容，而是将风格参数作为优化变量，通过微调生成器来间接改变视觉输入的特征分布，从而绕过安全对齐机制。

### 风格敏感性探测与池构建

设计动机在于解决随机选择风格方向导致的低效搜索问题，需先定位目标模型最脆弱的风格子空间。方法首先构建包含四个互斥子集的风格池 $\mathcal{S}$，涵盖介质纹理模拟（$\mathcal{S}_{med}$）、几何失真（$\mathcal{S}_{geo}$）、主题氛围操纵（$\mathcal{S}_{atm}$）及领域特定插画（$\mathcal{S}_{dom}$）。对于每种风格 $S_i$，利用未微调的生成器 $G(\cdot; \Theta_0)$ 将基础攻击数据集 $\mathcal{D}_{base}$ 转换为混合数据集，并计算其攻击成功率（ASR）：

$$ S^* = \arg \max_{S_i \in \mathcal{S}} \left( \frac{1}{N} \sum_{j=1}^{N} y_{i,j} \right) $$

该公式通过最大化经验成功率，从风格池中筛选出最优风格指令 $S^*$，为后续强化学习提供初始搜索方向，避免了在高维风格空间中盲目探索。

### 基于 GRPO 的风格增强与分层奖励

设计动机在于解决风格参数空间高维且奖励信号稀疏的问题，固定滤镜无法适应不同模型的安全阈值。方法将风格增强建模为马尔可夫决策过程，利用组相对策略优化（GRPO）微调图像编辑模型 $G(\cdot; \Theta)$。核心创新在于结构分层奖励函数 $r_t$，它通过硬阈值 $C_{thresh} = -10$ 区分拒绝域与接受域：

$$ r_t(I_h, P_h) = \begin{cases} C_{thresh} + \log \frac{P_M(\text{accept}|I_h, P_h)}{P_M(\text{rejected}|I_h, P_h)} & \text{if rejected} \\ \max \left( \log \frac{P_J(\text{yes}|R, P_h)}{P_J(\text{no}|R, P_h)}, C_{thresh} \right) & \text{if accepted} \end{cases} $$

该公式在拒绝时提供密集梯度以引导模型降低拒绝置信度，在接受时通过裁判模型 $J$ 评估有害性并设置下限，防止“无害接受”被过度惩罚。结合动态批次 GRPO（DB-GRPO），算法仅对未解决样本进行策略更新，成功样本被剔除，从而将计算资源集中于发现新攻击，显著提升了红队测试的效率。

## 实验评估

实验在 MM-SafetyBench 和 VLBreak-Bench 上进行，目标模型包括 GPT-4.1、Gemini-2.5、Qwen3-VL 和 LLaVA-OneVision-1.5。基线攻击涵盖 QR-Attack、SI-Attack、IDEATOR 和 HIMRD。由于论文未报告绝对 ASR 数值，仅报告 ASO 带来的增量提升，无法与领域综述中 MAMJ（82.0%）或 Mosaic（75.0%）等 SOTA 攻击进行直接绝对值对比。

| 目标模型 | ASR 增量提升 (%) |
| :--- | :--- |
| GPT-4.1 | 6.98 |
| LLaVA-OneVision-1.5 | 6.55 |
| Gemini-2.5 | 3.99 |
| Qwen3-VL | 3.10 |

数据显示，ASO 在所有测试模型上均带来正向提升，其中闭源模型 GPT-4.1 的提升幅度最大，表明商业模型对风格扰动的敏感性更高。消融实验未提供详细表格，但文中指出结构分层奖励函数相比二元奖励能提供更稳定的学习信号，动态批次机制减少了在已解决样本上的无效计算。

评估边界方面，ASR 增量依赖于基础攻击的质量，若基础攻击 ASR 已接近饱和，风格优化的边际收益可能递减。可复现性方面，论文提供了代码仓库，但 GRPO 训练需要访问目标模型的 logits 概率，这在闭源 API 场景中可能受限，需依赖代理模型或分类器近似，这可能影响优化精度。

## 关联研究分析

从问题动机看，ASO 与 SI-Attack 同属非内容型攻击，但 SI-Attack 聚焦于离散的结构扰动（如打乱顺序），而 ASO 探索连续的视觉风格参数空间。SI-Attack 的失效在于其扰动是固定的，无法适应不同模型的安全阈值差异；ASO 通过强化学习动态搜索最优风格参数，解决了固定扰动在跨模型泛化上的局限。这种差异源于任务特性：风格是一个高维连续变量，需要优化算法而非规则匹配。

从方法设计看，ASO 与 MAMJ（Cui et al., 2026）均使用 GRPO 进行优化，但 MAMJ 优化的是攻击策略提示和攻击者权重，属于元自适应攻击；ASO 优化的是图像编辑模型的参数，属于生成器增强。MAMJ 的局限在于其攻击工件依赖于特定的语言空间进化，而 ASO 的风格触发器是视觉模态的，可叠加于任何内容型攻击之上。ASO 未探索风格优化与内容优化的联合梯度下降，而是采用两阶段分离策略，这可能导致局部最优，即风格参数与内容参数未实现全局协同。

## 总结

本文核心矛盾在于视觉风格作为非语义属性被安全对齐机制忽视，导致模型在风格扰动下防御失效。切入点在于发现风格不一致性，并利用强化学习将风格参数转化为可优化的攻击变量。方法通过 ASO 框架，结合分层奖励和动态批次 GRPO，自动搜索最优风格触发器。实验证明 ASO 在四个主流 VLM 上带来 3.10% 至 6.98% 的 ASR 提升，验证了风格作为独立攻击向量的有效性。边界在于其依赖目标模型 logits 的可访问性，且仅报告增量而非绝对性能，无法确认其在高 ASR 基础攻击上的边际收益。当基础攻击 ASR 超过 80% 时，风格优化的剩余提升空间是否足以抵消其计算开销，论文未给出回答。
