# CVPR2026最新论文 ｜Question-guided Visual Compression with Memory Feedback for Long-Term Video Understanding ｜记忆反馈驱动的多帧视觉压缩

研究机构：澳大利亚麦考瑞大学

作者：Sosuke Yamao、Natsuki Miyahara、Yuankai Qi 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.15167)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.15167)

> 长视频理解面临上下文窗口限制与关键信息稀疏的双重矛盾，现有框架多采用“压缩-存储-解码”的单向流程，导致感知阶段无法利用历史记忆修正当前压缩焦点，致使时序事件完整性受损。QViC-MF 通过引入记忆反馈机制，将历史相关帧召回并参与下一轮视觉压缩，实现了感知与记忆的闭环迭代。该方法在保持极低视觉Token开销（16 tokens/frame）的同时，显著提升了时序推理任务性能，但其扁平化记忆结构在超长视频下的扩展性仍存疑。

## 研究背景

当多模态大语言模型处理小时级视频时，视觉Token数量远超上下文窗口限制，迫使模型采用帧采样或Token压缩策略。然而，均匀采样易丢失稀疏关键帧，而独立帧压缩则破坏了跨帧的时序依赖，导致模型在动作排序等需要全局时序一致性的任务上表现不佳。这种“感知-记忆”解耦的单向流程，使得记忆仅作为解码时的参考，无法反向指导感知过程，是长视频理解中时序推理失效的核心原因。

长视频理解领域的主流路线分为高效帧采样、视频压缩与记忆增强三类。其中，记忆增强方法如 MA-LMM 和 FlashVStream 虽解决了上下文溢出问题，但均将记忆视为静态存储库，视觉特征编码独立于历史上下文。这种设计忽略了视频信息的动态关联性，导致模型无法在感知阶段主动筛选与当前问题及历史事件相关的视觉线索。QViC-MF 的切入点在于打破这一单向壁垒，将记忆从“解码参考”转变为“感知引导”，通过反馈机制使视觉压缩过程具备时序自适应能力。

## 核心方法

### 方法参照系

常规长视频理解框架遵循“视觉编码-独立压缩-记忆存储-LLM解码”的流水线。其关键差异在于，传统压缩器仅处理当前片段，忽略历史记忆对当前帧语义理解的潜在贡献，导致压缩后的视觉嵌入缺乏时序连贯性，无法支撑跨片段的复杂推理。

### 记忆反馈驱动的迭代压缩

传统压缩器在处理第 $n$ 个片段时，仅输入当前视觉嵌入 $E_{v,n}$，导致压缩结果与历史上下文割裂。QViC-MF 引入记忆反馈机制，从上下文记忆中召回 $K_r$ 个高相关性帧 $V_{r,n}$，将其与当前片段拼接后共同输入视觉压缩器。这一设计解决了独立压缩导致的时序事件碎片化问题，使压缩器能够基于历史语境调整当前帧的表征。召回帧的选择基于相关性分数 $R_n$，该分数通过计算视觉压缩器中从文本Token到视觉Token的平均注意力权重获得：

$$ r_{n,i} = \frac{1}{L_2-L_1+1} \sum_{l=L_1}^{L_2} \text{TopK}(\bar{A}_{vt}^{(l,h,n,i)}, K_h) $$

该公式量化了每帧视觉内容与当前问题的语义关联度，确保记忆库中保留的是对任务最关键的视觉证据，而非随机或均匀分布的帧。

### 查询引导的多模态选择性注意力

独立压缩器常面临“压缩幻觉”（文本信息泄漏至视觉嵌入）和“查询不敏感”（视觉注意力未聚焦问题相关区域）两大失效。QMSA 通过修改自注意力Logits，引入掩码（Masking）、阻断（Blocking）和引导（Guiding）三种操作。其中，阻断矩阵 $\mathbf{B}$ 禁止上下文Token关注文本Token，防止文本语义污染视觉嵌入；引导矩阵 $\mathbf{G}$ 将文本到视觉的注意力偏置注入上下文到视觉的注意力中，实现查询自适应压缩。其核心公式为：

$$ \text{Attention} = \text{Softmax}\left( \frac{\mathbf{Q}\mathbf{K}^T}{\sqrt{d}} + \mathbf{M} + \mathbf{B} + \mathbf{G} \right) \mathbf{V} $$

这一机制确保压缩后的视觉嵌入既保留了纯视觉特征，又精准聚焦于问题相关的时空区域，从而在极低Token预算下维持语义完整性。

## 实验评估

实验在 MLVU、LVBench、VideoMME 和 VNBench 四个基准上进行，基线覆盖了 LLaVA-Video、LongVA、Video-XL 等主流开源方法，但缺失了 2026 年发布的 Video-o3 和 LongVT 等最新代理式推理框架，限制了与前沿 Agentic 方法的直接对比。

| 方法 | MLVU (Test) | LVBench | VideoMME (Long) | VNBench (Long) |
| :--- | :--- | :--- | :--- | :--- |
| LLaVA-Video | 53.3 | 42.0 | 50.3 | 40.4 |
| Video-XL | 45.5 | - | - | - |
| QViC-MF (2 fps) | 59.4 | 50.2 | 54.0 | 58.7 |

QViC-MF 在 MLVU 上较 LLaVA-Video 提升 6.1%，在 VNBench Long 子集上提升 18.3%，表明记忆反馈机制在需要长程时序依赖的任务上优势显著。

| 组件 | MLVU (Test) | VNBench (ALL) | VNBench (Long) |
| :--- | :--- | :--- | :--- |
| Vanilla Compressor | 48.8 | 61.6 | 39.3 |
| + Context Memory | 42.4 | 58.2 | 40.9 |
| + Memory Feedback | 52.2 | 63.7 | 55.1 |
| + QMSA (Full) | 59.4 | 64.7 | 58.7 |

消融实验显示，仅添加上下文记忆反而导致性能下降（42.4 vs 48.8），证实了单向记忆存储的无效性；引入记忆反馈后性能回升至 52.2，而完整的 QMSA 机制进一步将 MLVU 准确率推至 59.4，表明查询引导的注意力机制是性能提升的关键。

评估协议采用官方脚本，报告平均任务准确率。代码已开源，但论文未报告计算延迟和内存占用，无法评估其在实时流式场景下的可行性。此外，所有实验基于 7B 参数模型，未验证该方法在更大规模模型上的可扩展性。

## 关联研究分析

从方法设计看，QViC-MF 与 FlashVStream 同属记忆增强路线，但二者对记忆的使用逻辑截然不同。FlashVStream 的记忆模块（CSM/DAM）仅在解码阶段提供上下文参考，视觉压缩过程独立于历史记忆，属于“开环”设计；而 QViC-MF 将记忆召回帧直接输入压缩器，形成“闭环”反馈。这种差异源于对时序依赖建模深度的不同理解：FlashVStream 假设视觉特征在编码阶段已足够完备，记忆仅用于补充语义；QViC-MF 则认为视觉压缩本身需要历史语境来消除歧义，特别是在稀疏证据任务中。这种闭环设计是否会导致误差累积，论文未提供长视频下的稳定性分析。

从问题动机看，QViC-MF 与 LongVT 均旨在解决稀疏证据定位问题，但技术路径迥异。LongVT 依赖强化学习训练模型执行“假设-验证”的工具调用循环，属于显式代理式推理；QViC-MF 则通过注意力机制内的隐式反馈实现类似效果，无需外部工具调用。这种差异反映了领域内“显式代理”与“隐式优化”两条路线的分歧：LongVT 以高推理延迟换取证据定位精度，QViC-MF 则以低 Token 开销换取效率，但其在多跳推理任务上的表现是否优于显式代理框架，缺乏直接对比数据。

## 总结

QViC-MF 针对长视频理解中感知与记忆解耦导致的时序推理失效问题，提出了记忆反馈驱动的多帧视觉压缩框架。通过 QMSA 机制将历史相关帧召回并参与当前压缩，该方法在 16 tokens/frame 的极低开销下，将 MLVU 测试集准确率提升至 59.4%，VNBench Long 子集提升至 58.7%。然而，其扁平化 Top-K 记忆结构在视频时长超过小时级时，可能因记忆容量限制而丢失早期关键事件，且未验证在实时流式场景下的延迟表现。当视频时长延伸至天级时，这种基于相关性分数的静态记忆更新策略是否仍能维持时序一致性，论文未给出回答。
