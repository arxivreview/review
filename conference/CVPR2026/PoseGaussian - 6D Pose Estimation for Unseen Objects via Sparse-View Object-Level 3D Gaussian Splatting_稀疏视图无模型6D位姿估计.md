# CVPR2026最新论文 ｜PoseGaussian: 6D Pose Estimation for Unseen Objects via Sparse-View Object-Level 3D Gaussian Splatting ｜稀疏视图无模型6D位姿估计

作者：Wubin Shi、Shaoyan Gai、Feipeng Da

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_e5c1df2802bf)

> 6D位姿估计旨在预测物体在相机坐标系下的三维平移与旋转，是机器人抓取与增强现实的核心感知能力。现有无模型方法依赖密集参考视图或SfM初始化，在稀疏视图与低纹理场景下易出现几何退化与浮点伪影，导致位姿估计失效。本文通过深度结构先验初始化物体级3D高斯泼溅（3D Gaussian Splatting, 3DGS），结合两阶段学习引导ICP与可微渲染细化，实现了8视图下的鲁棒位姿估计。该方法在稀疏设定下显著优于基线，但逐物体优化耗时限制了实时性，且未验证极端遮挡下的泛化边界。

## 研究背景

6D位姿估计需解决从二维图像恢复三维刚体变换的逆问题。传统基于图像匹配的方法（如Gen6D）依赖密集模板库，在未见物体上泛化能力弱；基于重建的方法（如OnePose++）通过SfM构建点云，但SfM在低纹理或稀疏视图下常因特征点不足而失败，导致初始几何模糊。3DGS以显式各向异性高斯基元替代隐式辐射场，通过可微光栅化实现实时渲染，但其逐场景优化范式在稀疏视图下易过拟合训练视角，产生浮点伪影，削弱下游位姿估计的稳定性。

无模型位姿估计的核心矛盾在于：消除对CAD模型的依赖后，如何仅凭少量参考视图重建出几何稳定的物体表示。主流路线分为图像匹配与重建两类。图像匹配方法（如Cas6D）通过检索相似视图估计位姿，但在弱纹理下对应点可靠性低；重建方法（如iG-6DoF）先构建3D模型再注册，但依赖密集视图与SfM初始化，稀疏视图下重建质量急剧下降。本文切入点在于利用RGB-D深度信息直接初始化3DGS，规避SfM失败风险，并通过稀疏训练策略抑制过拟合，从而在8视图条件下获得鲁棒的物体几何表示。

## 核心方法

### 方法参照系

本文问题属于重建式无模型位姿估计，标准流程为：从参考视图重建物体3D表示→匹配/注册求初值→渲染细化。关键差异在于：本文用深度反投影替代SfM点云初始化，用两阶段学习引导ICP替代纯图像匹配，用3DGS可微渲染替代CNN/Transformer细化器，以解决稀疏视图下的几何退化问题。

### 深度结构先验初始化与稀疏训练

传统3DGS初始化依赖SfM点云，在稀疏视图下点云稀疏且含浮点，导致高斯中心偏离物体表面。本文采用RGB-D深度反投影点云作为高斯中心初始化，通过KNN异常值去除与掩码边界腐蚀，确保初始高斯锚定在物体表面。稀疏训练策略结合自适应密度控制与视图扭曲增强：自适应密度控制仅当高斯不透明度与体积贡献均处于底部5%时剪枝，避免误删高质量高斯；视图扭曲通过小位姿扰动合成伪视图，扩展相机位姿空间覆盖。损失函数联合光度与深度监督：

$$L_{total} = \lambda_1 \|\hat{I} - I\|_1 + \lambda_2 L_{D-SSIM}(\hat{I}, I) + \lambda_d L_{depth}$$

其中$L_{depth} = \|\hat{D} - D\|_1$，训练采用前高后低退火策略：前30%迭代提高$\lambda_d$并限制球谐阶数至0-1以稳定几何，后期提高光度权重并增加球谐阶数至2-3以细化纹理。该设计解决了稀疏视图下3DGS过拟合与浮点伪影问题，使重建几何更贴近真实物体表面。

### 两阶段学习引导ICP与可微渲染细化

初始位姿估计易受噪声与遮挡影响，传统ICP对初始值敏感。本文设计两阶段学习引导ICP：首先通过KPConv-FPN提取多尺度点云特征，低分辨率域建立粗对应确保全局一致性，高分辨率域进行局部超点匹配，最优传输层提升局部匹配质量，最终求解相似变换作为初始位姿。位姿细化阶段将3DGS渲染器作为可微模块，通过光度与深度一致性损失迭代优化位姿：

$$L_{pose} = L_t + L_R, \quad L_t(T) = \lambda_t L_{SSIM}(C(T), I_{que}) + \lambda_d L_{SNDA}$$

其中$L_{SNDA}$为尺度归一化深度对齐损失，采用Charbonnier常数提升鲁棒性。位姿更新采用平移-旋转解耦策略，先优化平移再优化旋转，避免耦合漂移。该设计解决了传统学习式细化器（如Gen6D Refiner）对未见物体泛化能力弱的问题，3DGS渲染器无需任务特定可训练参数，直接利用几何与光度一致性约束，提升了位姿估计的稳定性与精度。

## 实验评估

实验在Linemod与GenMOP数据集上进行，使用8视图稀疏设定与200视图密集设定对比。基线覆盖图像匹配（Gen6D, Cas6D）、重建匹配（OnePose++）与3DGS迭代优化（iG-6DoF）路线，但缺失基于NeRF的位姿估计方法（如NeRF-Pose类）对比。Linemod 8视图下，本文ADD-0.1d为54.30，高于OnePose++（40.30）与Gen6D（44.62），但低于iG-6DoF（85.1，200视图）；8视图下本文性能接近iG-6DoF 16视图水平，表明对视图稀疏性鲁棒。GenMOP 8视图下，本文ACC为87.5，ARmean为71.4，优于Gen6D（ACC 33.50）与OnePose++（ACC 40.00）。

消融实验显示，移除自适应密度控制（A0）导致ACC从87.5降至85.0，移除视图扭曲增强（A1）降至85.9，替换为vanilla 3DGS（A2）降至82.1，替换初始化器为Gen6D选择器（A3）降至68.7。变化幅度最大的是初始化器替换（A3），表明两阶段学习引导ICP对初始位姿鲁棒性贡献显著；移除自适应密度控制（A0）与视图扭曲（A1）的降幅相近，说明两者对抑制过拟合均有必要。

评估边界方面，指标仅包含ADD-0.1d与Prj-5，未报告置信区间或多次运行方差；评估协议遵循Gen6D设定，使用CNOS生成实例掩码，ZoeDepth估计深度，但未讨论深度噪声对结果的影响。可复现性方面，论文未提供代码URL，超参数（如$\lambda_1, \lambda_2, \lambda_d$）未完整列出，GPU为RTX 3090 Ti，训练10k迭代，每物体平均2.21分钟。

## 关联研究分析

从问题动机看，本文与GS-Pose同属3DGS位姿估计路线，但GS-Pose依赖密集参考视图与SfM初始化，在稀疏视图下重建失败；本文用深度反投影替代SfM，解决了低纹理场景下的初始化失败问题。差异根源在于任务特性：物体级位姿估计对几何精度要求高于场景重建，稀疏视图下SfM点云的浮点伪影会直接导致位姿估计偏差，而深度反投影点云更贴近物体表面，几何稳定性更强。

从方法设计看，本文与iG-6DoF同用3DGS迭代优化，但iG-6DoF依赖检测与初始对齐，且使用学习式细化器；本文用两阶段学习引导ICP替代检测，用3DGS可微渲染替代学习式细化器。差异根源在于泛化能力：学习式细化器（如Gen6D Refiner）在训练分布外（未见物体）性能下降，而3DGS渲染器无需任务特定参数，直接利用几何与光度一致性，对未见物体泛化更好。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文核心矛盾是稀疏视图无模型位姿估计中3DGS重建的几何退化问题。切入点在于利用RGB-D深度信息直接初始化3DGS，规避SfM失败风险，并通过稀疏训练策略抑制过拟合。方法通过深度结构先验初始化、两阶段学习引导ICP与3DGS可微渲染细化，在Linemod 8视图下ADD-0.1d达54.30，GenMOP 8视图下ACC达87.5。边界在于逐物体优化耗时2.21分钟，限制了实时应用；未验证极端遮挡或动态场景下的鲁棒性。当参考视图进一步减少至4视图时，深度反投影点云的稀疏性是否会导致高斯初始化失效，论文未给出回答。
