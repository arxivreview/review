# CVPR2026最新论文 ｜SkeletonContext: Skeleton-side Context Prompt Learning for Zero-Shot Skeleton-based Action Recognition ｜骨架侧上下文提示学习

研究机构：西安电子科技大学、澳大利亚西澳大学

作者：Ning Wang、Tieyue Wu、Naeha Sharif 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.29692)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.29692)

> 零样本骨架动作识别（ZSSAR）旨在通过语义描述将已知类别知识迁移至未见类别，但骨架数据缺乏物体等视觉上下文，导致与文本语义对齐时存在固有鸿沟，难以区分视觉相似动作。现有方法多聚焦于增强文本编码器或全局特征对齐，忽略了运动表征中缺失的语境信息。本文提出 SkeletonContext，通过大语言模型（LLM）生成结构化上下文，并在骨架侧重建这些被掩码的语境提示，从而弥合模态间的语义差距。该方法在多个基准上刷新了零样本与广义零样本（GZSL）性能，但其对 LLM 生成质量的依赖及在极端域偏移下的鲁棒性仍存疑。

## 研究背景

零样本学习（Zero-Shot Learning, ZSL）的核心挑战在于模型需在没有目标类别标注的情况下进行识别，这依赖于源域与目标域之间共享的语义空间。在骨架动作识别中，输入仅为关节点坐标序列，相比 RGB 视频，它天然缺失了背景、物体外观等视觉线索。这种模态特性导致骨架特征与包含丰富语境信息的文本描述（如“在键盘上打字”中的“键盘”）之间存在显著的语义-运动鸿沟。当动作在视觉上高度相似（如“写字”与“打字”）时，仅靠关节运动轨迹难以区分，必须引入外部语境知识来辅助判别。

早期 ZSSAR 方法如 RelationNet 和 SynSE 主要依赖全局特征对齐或手工设计的动词-名词嵌入，语义粒度粗且缺乏细粒度推理能力。近期工作如 SCoPLe 和 Neuron 引入了提示学习（Prompt Learning）和大语言模型（LLM），但大多侧重于增强文本编码器的语义表达，或进行静态的全局对齐。这些方法未能有效解决骨架模态本身缺乏语境信息的问题，导致在区分细微动作差异时性能受限。本文的切入点在于将提示学习的目标从文本侧转移至骨架侧，通过重建 LLM 生成的上下文语义来增强骨架表征，从而在特征提取阶段就注入语境信息。

## 核心方法

### 方法参照系

ZSSAR 的标准流程通常包括：使用图卷积网络（GCN）提取骨架时空特征，使用预训练语言模型（如 BERT）提取文本语义特征，并在共享潜空间中通过对比损失或度量学习进行对齐。本文的关键差异在于，它不直接对齐原始骨架特征与文本特征，而是先利用 LLM 生成包含环境、使用物体、目标物体的结构化上下文描述，并在骨架编码器中引入一个跨模态上下文提示模块，通过掩码重建机制将语言知识注入骨架特征，最后再与文本语义对齐。

### 跨模态上下文提示模块

该模块旨在从骨架序列中重建被掩码的上下文语义，以弥合模态鸿沟。设计动机是解决传统方法中骨架特征缺乏物体交互信息的问题，使得模型能够推断出动作发生的语境。首先，使用差分关节编码器（Differential Joint Encoder, DJE）捕捉关节间的细微差异，构建拓扑增强嵌入 $H_{x}^{diff}$。随后，将骨架特征与 BERT 的隐藏状态 $H_t$ 进行交叉注意力交互，更新上下文表示 $H_t^{ctx}$。最终，通过掩码语言模型（MLM）头预测被掩码的上下文词元，损失函数定义为：

$$ \mathcal{L}_{ccr} = -\sum_{i \in \mathcal{M}} \log P(w_i | H_t^{ctx}, F_x) $$

其中 $\mathcal{M}$ 为掩码位置集合。这一过程迫使骨架特征包含足够的信息以重建语境，从而增强了运动表征的语义丰富性。

### 渐进部分掩码与关键部位解耦

为了稳定训练并处理无物体交互的动作，本文引入了渐进部分掩码（Progressive Partial Masking, PPM）和关键部位解耦（Key Part Decoupling, KPD）。PPM 通过随训练步数 $t$ 线性增加掩码比例 $r_t = \min(1, t/T)$，实现从部分重建到全语境推理的课程学习，缓解了结构化提示与自然语言之间的分布差距。KPD 则针对“挥手”等无物体动作，通过预测关节重要性图 $K_{out}$ 来解耦运动相关特征，其校准损失为：

$$ \mathcal{L}_{kpd} = \| K_{out} - K_{gt} \|_2^2 $$

其中 $K_{gt}$ 为基于身体部位先验的重要性分布。这两个机制确保了模型在缺乏明确物体线索时仍能聚焦于关键运动部位，提升了泛化能力。

## 实验评估

实验在 NTU RGB+D 60/120 和 PKU-MMD 数据集上进行，采用 Cross-Subject 协议。基线覆盖了 SCoPLe、Neuron、FS-VAE 等近期 SOTA 方法，但缺失了早期经典如 RelationNet 的直接对比（仅在相关工作中提及）。在 NTU-60 (55/5) 分割上，SkeletonContext 的 ZSL 准确率为 89.6%，GZSL 调和平均（H）为 77.1%；在 NTU-120 (96/24) 分割上，ZSL 为 60.1%，H 为 56.1%。

| 数据集 | 分割 | ZSL (%) | GZSL-H (%) |
| :--- | :--- | :--- | :--- |
| NTU-60 | 55/5 | 89.6 | 77.1 |
| NTU-60 | 48/12 | 64.4 | 61.1 |
| NTU-120 | 110/10 | 74.2 | 63.1 |
| NTU-120 | 96/24 | 60.1 | 56.1 |

消融实验显示，逐步引入 DJE、SCG、PPM 和 KPD 模块，NTU-60 (55/5) 的 ZSL 准确率从基线的 79.4% 提升至 89.6%，其中 SCG（语义上下文接地）贡献最大，表明语境重建是性能提升的核心。移除 LLM 生成的上下文监督导致性能下降约 2-3%，验证了语言先验的必要性。

评估边界方面，论文未报告计算效率（FLOPs/Params），且依赖 ChatGPT-4 生成描述，这可能引入 LLM 幻觉或偏见。代码已开源，但超参数（如掩码比例调度）的敏感性分析不足。

## 关联研究分析

从方法设计看，SkeletonContext 与 SCoPLe 形成鲜明对比。SCoPLe 通过联合调整文本和骨架提示来实现数据驱动的对齐，侧重于优化提示向量本身；而 SkeletonContext 侧重于利用 LLM 生成的显式语境信息，并通过掩码重建将其注入骨架特征。这种差异源于对“语境”处理方式的不同：SCoPLe 隐含地学习语境，而 SkeletonContext 显式地重建语境。前者在数据充足时可能更灵活，但后者在语义模糊或细粒度区分任务上更具优势，因为它直接利用了 LLM 的世界知识。

从问题动机看，与 FS-VAE 相比，两者都关注细粒度动作区分，但路径不同。FS-VAE 通过频率分解（低频/高频）来丰富语义特征，属于信号处理视角；SkeletonContext 则通过引入外部物体/环境语境，属于语义推理视角。FS-VAE 的优势在于不依赖外部知识，鲁棒性可能更强；而 SkeletonContext 的优势在于能捕捉骨架中完全缺失的物体交互信息。对于“写字”与“打字”这类动作，FS-VAE 可能难以区分，因为它们的运动频率特征相似，而 SkeletonContext 可以通过重建“纸”与“键盘”的语境差异来有效区分。

## 总结

SkeletonContext 旨在解决零样本骨架动作识别中因缺乏视觉语境导致的语义-运动鸿沟。现有方法多聚焦于文本侧增强或全局对齐，忽略了骨架表征中缺失的物体交互信息。本文通过 LLM 生成结构化上下文，并在骨架侧重建这些语境，实现了细粒度的跨模态对齐。在 NTU-60 (55/5) 上，其 ZSL 准确率达到 89.6%，显著优于 SCoPLe 和 Neuron。然而，该方法高度依赖 LLM 生成描述的质量，且在 GZSL 设置下，Seen 类与 Unseen 类的性能平衡（H 值）仍有提升空间。当 LLM 生成的语境描述存在事实错误或歧义时，重建过程是否会引入噪声并误导骨架特征，论文未给出系统性验证。
