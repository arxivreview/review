分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_277365967619)

> 骨架动作识别（SAR）的核心矛盾在于图结构的空间非欧几里得特性与序列模型的时间线性依赖之间的结构性冲突。现有方法要么依赖固定拓扑忽略动作特异性关联，要么简单堆叠 Mamba 与 GCN 导致物理语义丢失。本文通过引入节点分类模块（NCM）重组序列顺序，实现了图结构与状态空间模型（SSM）的协同。该架构在提升长程依赖建模能力的同时降低了计算复杂度，但在极端域偏移下的鲁棒性尚未得到充分验证。

## 研究背景

骨架数据以关节点坐标序列形式存在，其空间结构由人体骨骼连接关系定义，这种非欧几里得拓扑使得传统卷积神经网络（CNN）难以直接处理。为捕捉关节间依赖，图卷积网络（GCN）成为主流架构，但其时间建模通常依赖时间卷积网络（TCN）。TCN 受限于局部感受野，难以捕捉长序列中的全局运动模式，而 Transformer 虽具备全局建模能力，但计算复杂度随序列长度平方增长，限制了其在长视频序列中的应用。

SAR 领域长期面临固定拓扑与动态拓扑的取舍困境。静态拓扑方法如 ST-GCN 依赖预定义骨骼连接，无法捕捉动作特异性关节关联；动态拓扑方法如 CTR-GCN 通过注意力机制学习邻接矩阵，但计算成本高且缺乏物理可解释性。与此同时，状态空间模型（SSM）如 Mamba 以线性复杂度实现长序列建模，但其本质是递归神经网络（RNN）变体，仅接受一维序列输入。将图结构数据直接输入 Mamba 时，节点在内存中的连续排列顺序与物理连接关系不一致，导致 SSM 捕捉到虚假的相关性。现有 Mamba-GCN 混合方法多采用简单堆叠或双流独立处理，未能解决图结构数据与序列模型在输入顺序上的根本矛盾。

## 核心方法

### 方法参照系

本文属于时空图卷积建模路线，核心差异在于不将 Mamba 视为 GCN 的简单替代或并行分支，而是通过节点语义重组解决两者输入结构的冲突。标准流程中，GCN 处理空间特征，TCN 处理时间特征；本文在 GCN 输出后插入节点分类模块，重组序列后再输入 Mamba，形成空间-语义-时间的协同建模链路。

### 节点分类与序列重组

传统 Mamba-GCN 方法直接按内存顺序将关节节点输入 SSM，忽略了关节间的物理连接关系，导致 SSM 隐状态转移与骨骼拓扑脱节。本文引入节点分类模块（NCM），将关节按运动语义分类，重组序列顺序以匹配物理结构。NCM 通过多层感知机（MLP）和 Gumbel-Softmax 实现可微分类：

$$
y_i = \frac{\exp\left(\frac{\log x_i + g_i}{\tau}\right)}{\sum_{j=1}^k \exp\left(\frac{\log x_j + g_j}{\tau}\right)}
$$

其中 $x_i$ 为节点属于第 $i$ 类的概率，$g_i$ 为均匀分布噪声，$\tau$ 为温度参数。噪声引入随机性，避免节点固定分配导致的过拟合。重组后的序列按类别聚合，使 SSM 的隐状态转移与骨骼物理连接一致，同时捕捉类内局部相关性和类间全局依赖。

### Mamba-TCN 时间建模

NCM 输出的重组序列进入 Mamba 模块捕捉全局时间依赖，随后通过朴素 TCN 聚合局部时间信息。Mamba 的选择性机制允许模型自适应捕捉不同时间跨度的关键依赖，克服了传统 TCN 仅能处理局部时间窗口的局限。该模块将输入张量 $X \in \mathbb{R}^{B \times C \times T \times V}$ 重塑为 $X_t \in \mathbb{R}^{(B \cdot V) \times T \times C}$，独立处理每个节点的时间序列，防止不同关节间的干扰。Mamba 输出 $H_t = \text{SSM}(X_t)$ 经 TCN 聚合后得到最终时间特征 $Y = \text{TCN}(H_t)$。

## 实验评估

实验在 NTU RGB+D 60/120 和 NW-UCLA 数据集上进行，采用 Cross-Subject（X-Sub）和 Cross-View（X-View）协议。基线覆盖 GCN、Transformer 和 Mamba 类方法，但缺失自监督预训练类基线（如 SkeletonCLR）。

| 方法 | NTU-60 X-View (%) | NTU-120 X-Sub (%) | NW-UCLA Top-1 (%) |
| :--- | :--- | :--- | :--- |
| CTR-GCN | 96.8 | 90.6 | 96.5 |
| BlockGCN | 97.0 | 91.5 | 96.9 |
| Gamba | 97.3 | 91.9 | 97.3 |

Gamba 在三个数据集上均取得最优结果，NTU-120 X-Sub 较 CTR-GCN 提升 1.3 个百分点。

| 配置 | NCM | S-Mamba | T-Mamba | TCN | Acc (%) |
| :--- | :---: | :---: | :---: | :---: | :--- |
| Baseline | ✓ | | | | 95.8 |
| +S-Mamba | ✓ | ✓ | | | 96.0 |
| +T-Mamba | ✓ | | ✓ | | 95.7 |
| +NCM+S-Mamba | ✓ | ✓ | | | 96.5 |
| Full | ✓ | ✓ | ✓ | ✓ | 96.5 |

消融实验显示，单独添加 T-Mamba 未带来显著提升（95.7% vs 95.8%），而 NCM 与 S-Mamba 的组合使准确率提升 0.7 个百分点，证实节点重组是 Mamba 有效性的关键。

评估边界方面，论文未报告置信区间和计算效率的详细对比（仅给出参数量 4.5M 和 FLOPs 11.1G）。代码已开源，但超参数设置（如分类数 $k=64$）的敏感性分析有限，NCM 在极端域偏移下的稳定性未验证。

## 关联研究分析

从问题动机看，Gamba 与 Simba 均试图融合 Mamba 与 GCN，但 Simba 将 Mamba 作为 Transformer 的替代用于特征提取，GCN 仅用于下采样和上采样，两者独立工作。Gamba 指出这种独立处理忽略了图结构与序列模型的内在矛盾，通过 NCM 实现语义引导的协同。差异根源在于对 Mamba 适用性的理解：Simba 视 Mamba 为通用序列处理器，Gamba 则强调其输入顺序对图结构数据的敏感性。

从方法设计看，Gamba 与 CTR-GCN 同属动态拓扑路线，但 CTR-GCN 通过通道解耦注意力学习邻接矩阵，计算复杂度较高；Gamba 通过节点分类重组序列，利用 SSM 的线性复杂度捕捉长程依赖。CTR-GCN 的拓扑学习基于样本级特征相关性，缺乏物理可解释性；Gamba 的分类机制将关节按运动语义分组，使拓扑具有类别属性。这种差异反映了从“数据驱动相关性”到“语义引导结构”的范式转变，但分类粒度 $k$ 对拓扑解释性的影响未被充分量化。

## 总结

Gamba 要解决的核心矛盾是图结构数据与序列模型在输入顺序上的结构性冲突。现有方法要么依赖固定拓扑忽略动作特异性，要么简单堆叠 Mamba 与 GCN 导致物理语义丢失。本文通过节点分类模块重组序列顺序，使 SSM 的隐状态转移与骨骼物理连接一致，实现了图结构与序列模型的协同。实验证明该架构在 NTU-120 X-Sub 上达到 91.9%，较 CTR-GCN 提升 1.3 个百分点，且 FLOPs 低于 CTR-GCN。本文的边界在于 NCM 的分类噪声机制在极端域偏移下的稳定性未验证，且缺乏自监督预训练对比。当支持集增大到 5-shot 时，节点分类的边际收益是否递减，论文未给出回答。
