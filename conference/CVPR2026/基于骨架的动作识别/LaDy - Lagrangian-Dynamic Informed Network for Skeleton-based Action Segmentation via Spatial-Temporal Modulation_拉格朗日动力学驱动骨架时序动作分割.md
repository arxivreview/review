> 骨架时序动作分割（STAS）旨在将未修剪的骨架序列解析为密集的帧级动作标签，核心难点在于区分运动学相似但动力学意图不同的动作（如推购物车与行走）。现有方法仅捕捉时空运动学模式，忽略了驱动运动的物理力，导致类别区分度不足且边界定位模糊。LaDy 通过引入拉格朗日动力学合成广义力，并利用能量一致性损失约束物理合理性，实现了从“运动描述”到“动力解释”的范式转换。该方法在六个基准上取得SOTA，但其对关节点噪声的敏感度及计算开销仍是潜在瓶颈。

## 研究背景

STAS 任务要求模型在时间轴上精确定位动作起止边界，这比离散分类更依赖对运动动态变化的感知。传统骨架动作识别依赖图卷积网络（GCN）建模空间拓扑，结合时间卷积网络（TCN）或 Transformer 捕捉时序依赖，形成了“空间-时间”解耦的标准范式。然而，这种范式本质上是在拟合关节点坐标的时空轨迹，即运动学（Kinematics），它描述了“如何运动”，却未触及“为何运动”的动力学（Dynamics）本质。

当前主流 STAS 方法如 MS-GCN 和 DeST-TCN 均聚焦于优化时空特征的提取与融合，但在面对运动学特征高度相似的动作时（例如不同速度下的行走或推重物），模型难以区分其背后的力学意图。这种“动力学盲视”导致两个具体问题：一是相似动作间的类间区分度下降；二是动作边界往往对应着力的突变，纯运动学模型容易将这些突变平滑化，造成边界定位误差。LaDy 的切入点在于，将经典力学中的拉格朗日方程嵌入神经网络，显式估计驱动骨架运动的广义力，从而为分割任务提供物理层面的因果依据。

## 核心方法

### 方法参照系

LaDy 基于 DeST-TCN 的解耦架构，保留了 GCN 空间模块与线性 Transformer 时间模块的主干结构。与标准流程的关键差异在于，LaDy 增加了一个平行的拉格朗日动力学模型（LDS）分支，并通过时空调制（STM）机制将动力学特征注入主干，而非仅依赖数据驱动的特征学习。

### 拉格朗日动力学合成

设计动机在于解决纯运动学模型无法区分动力学意图不同动作的问题。LDS 模块从关节点坐标计算广义坐标 $q$、速度 $\dot{q}$ 和加速度 $\ddot{q}$，并通过物理约束神经网络估计惯性矩阵 $M(q)$、科里奥利矩阵 $C(q, \dot{q})$、重力向量 $G(q)$ 和摩擦力 $F(q, \dot{q})$。广义力 $\tau$ 由拉格朗日方程合成：

$$ \tau = M(q)\ddot{q} + C(q, \dot{q})\dot{q} + G(q) + F(q, \dot{q}) $$

该公式确保了估计的力符合经典力学结构，其中 $M(q)$ 通过 Cholesky 分解保证对称正定，$C(q, \dot{q})$ 通过偏对称约束保证无源性。这种结构化参数化避免了黑盒估计的物理不一致性，使模型能捕捉到如“推”与“拉”在力方向上的本质差异。

### 能量一致性损失与时空调制

设计动机在于确保合成力的物理合理性，并利用力信号增强边界定位。能量一致性损失（ECLoss）强制系统动能变化 $\Delta E_K$ 与净功 $W$ 一致，公式为：

$$ \mathcal{L}_{EC} = \text{Huber}\left( \frac{\Delta E_K - W}{\delta + |\Delta E_K| + |W|}, 0 \right) $$

该损失通过相对残差归一化，避免了对运动幅度的敏感，确保在静态或微动阶段不产生噪声放大。随后，时空调制（STM）将广义力 $\tau$ 投影并融合到空间特征中，同时提取功率、力矩范数、力矩变化三个显著动态信号，通过层级门控机制调制时间特征流。这种门控机制使模型在力突变处（即动作边界）自动增强响应，从而提升边界定位精度。

## 实验评估

LaDy 在 PKU-MMD v2、MCFS-22/130、LARa 和 TCG-15 六个基准上进行了评估。基线覆盖了 MS-GCN、DeST-TCN、ME-ST 等主流方法，但缺乏最新的 Mamba 类或自监督预训练基线，这可能低估了当前 SOTA 的竞争力。

| 数据集 | 方法 | Acc (%) | Edit (%) | F1@25 (%) |
| :--- | :--- | :--- | :--- | :--- |
| PKU-MMD v2 (X-sub) | DeST-TCN | 65.6 | 65.0 | 71.0 |
| PKU-MMD v2 (X-sub) | ME-ST | 70.0 | 67.7 | 73.3 |
| PKU-MMD v2 (X-sub) | **LaDy** | **76.2** | **65.9** | **72.9** |
| LARa | ME-ST | 74.1 | 70.5 | 76.6 |
| LARa | **LaDy** | **77.0** | **74.7** | **80.5** |

在 PKU-MMD v2 X-sub 上，LaDy 的 Acc 达到 76.2%，较 ME-ST 提升 6.2 个点，但 Edit 分数（65.9%）略低于 ME-ST（67.7%），表明其在边界定位的编辑距离上并未全面超越，可能在某些复杂边界上仍有优化空间。在 LARa 数据集上，LaDy 全面领先，Acc 和 Edit 均显著高于基线，验证了动力学特征在仓库活动场景中的有效性。

消融实验显示，LDS 模块单独引入时 Acc 提升 1.2 个点，加入 STM 后进一步提升至 75.9%，最终加入 ECLoss 达到 76.2%。这表明能量一致性损失对物理合理性的约束带来了约 0.3 个点的边际收益，而时空调制机制是性能提升的主要来源。值得注意的是，ECLoss 的引入并未显著增加计算复杂度，但 LDS 模块的矩阵运算（如 Cholesky 分解）可能在高帧率序列中带来额外开销。

评估协议采用标准的 Acc、Edit 和 F1@{10,25,50} 指标，但未报告 FLOPs 或参数量对比，尽管表格中列出了 FLOPs，LaDy 的 13.67G FLOPs 高于 DeST-TCN 的 5.72G，但低于 ME-ST 的 97.07G，处于中等水平。代码已开源，但缺乏对关节点噪声鲁棒性的系统性评估，这是实际部署中的关键挑战。

## 关联研究分析

从问题动机看，LaDy 与 LaSA（语言辅助骨架动作分割）形成鲜明对比。LaSA 依赖大语言模型生成语义描述来增强动作区分度，属于“语义对齐”路线；而 LaDy 依赖物理定律合成力信号，属于“物理约束”路线。两者的核心差异在于：LaSA 假设动作的语义差异可通过文本描述捕捉，而 LaDy 假设动作的动力学差异可通过力学方程反演。在运动学相似但语义不同的动作上，LaSA 可能更有效；而在运动学相似但动力学意图不同的动作上（如推与拉），LaDy 具有理论优势。然而，LaDy 未探索语义与物理的联合建模，这可能限制了其在复杂语义场景中的泛化能力。

从方法设计看，LaDy 与 DeST-TCN 共享解耦架构，但 LaDy 引入了显式的物理先验。DeST-TCN 依赖数据驱动学习时空特征，其边界定位能力取决于数据分布的覆盖度；而 LaDy 通过 ECLoss 强制物理一致性，可能在数据稀疏或分布外场景下更具鲁棒性。但 LaDy 的 LDS 模块依赖关节点坐标的精确性，若输入骨架存在噪声，广义坐标计算将产生误差，进而影响力估计的准确性。DeST-TCN 作为纯数据驱动方法，可能对噪声具有更强的隐式鲁棒性，但缺乏物理可解释性。这一差异暗示，LaDy 在高质量骨架数据上表现优异，但在低质量或噪声数据上可能不如纯数据驱动方法稳定。

## 总结

LaDy 解决了骨架时序动作分割中“动力学盲视”导致的类间区分度不足与边界定位模糊问题。其核心创新在于将拉格朗日动力学嵌入神经网络，通过物理约束合成广义力，并利用能量一致性损失确保物理合理性。实验表明，LaDy 在 PKU-MMD v2 X-sub 上 Acc 达到 76.2%，在 LARa 上全面领先，验证了物理动力学对分割任务的增益。然而，LaDy 的 Edit 分数在 PKU-MMD 上略低于 ME-ST，且缺乏对关节点噪声鲁棒性的评估，暴露了其对输入数据质量的依赖。当骨架数据存在显著噪声或遮挡时，LDS 模块的力估计是否仍能保持物理一致性，论文未给出回答。
