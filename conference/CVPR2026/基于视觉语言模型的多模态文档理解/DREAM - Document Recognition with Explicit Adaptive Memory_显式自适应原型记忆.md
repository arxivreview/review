# CVPR2026最新论文 ｜DREAM: Document Recognition with Explicit Adaptive Memory ｜显式自适应原型记忆

研究机构：清华大学

作者：Tianqi Zhao、Di Wu、Liangrui Peng 等 10 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f42edb0a47a6)

> 文档识别模型面临的核心矛盾在于：参数化权重虽能拟合复杂分布，却将布局结构与视觉风格隐式纠缠，导致跨域泛化时难以解耦特定因素。现有端到端视觉语言模型（VLM）依赖海量参数存储知识，面对新样式或低资源场景时，微调成本高昂且缺乏可解释性。本文切入点在于利用文档固有的有限重复结构模式，引入非参数化的显式原型记忆。通过多尺度注意力读写机制，模型在推理时检索结构上下文以增强鲁棒性。该方案在0.6B参数量下超越了100B级基线，但其EMA更新策略的滞后性限制了动态适应能力。

## 研究背景

文档图像中的局部特征往往混合了文本语义与多种附加因素，如多栏布局、表格边界、字体倾斜及扫描噪声。这种纠缠使得纯参数化模型在遇到未见过的布局组合时，难以区分哪些视觉信号对应语义，哪些对应结构，导致识别性能在复杂版面下显著下降。为解耦这些成分，需要一种机制将高频出现的结构模式从权重中剥离，形成可检索的独立表示。

主流文档识别路线已从模块化OCR流水线转向端到端VLM，如Donut和GOT，它们通过统一建模视觉与文本信号实现了高精度解析。然而，这些方法的知识完全存储在神经网络权重中，表现为黑盒参数化模型。当训练数据分布发生变化或出现新的文档风格时，模型必须通过昂贵的全量微调来适应，且无法直观解释其决策依据。此外，高分辨率文档带来的计算瓶颈使得单纯扩大参数量并非可持续方案。本文针对这一瓶颈，提出将文档中反复出现的布局与风格模式显式编码为原型记忆，作为参数化权重的补充，从而在不增加主干网络复杂度的前提下，提升模型对多样布局的鲁棒性。

## 核心方法

### 方法参照系

本文基于编码器-解码器架构，视觉编码器提取多尺度特征，解码器生成Markdown文本。与标准VLM仅依赖权重传递信息不同，本文在编码器与解码器之间插入一个非参数化的原型记忆模块，该模块通过注意力机制实现结构信息的显式检索与融合。

### 基于GMM后验的注意力检索

设计动机在于解决纯参数化模型无法显式解耦布局与语义的问题。本文将局部区域特征 $x$ 建模为高斯混合模型（GMM）的加权组合，其中每个高斯分量的均值 $\mu_m$ 代表一种原型结构。通过数学推导，GMM的后验责任 $r_m(x)$ 可精确表示为带偏置的交叉注意力权重：

$$
r_m(\mathbf{x}) = \text{softmax}_m \left( \frac{\mathbf{x}^\top W_q^\top W_k \boldsymbol{\mu}_m}{\sqrt{D}} + B \right)
$$

该公式表明，区域特征作为查询（Query），原型向量作为键（Key）和值（Value），注意力权重即为该区域属于某原型的概率。检索出的原型表示与原始视觉特征拼接后投影至语言空间，为解码器提供显式的结构上下文，使模型能区分“图像边框”与“倾斜文本”等独立因素。

### 多尺度层级记忆与EMA巩固

单一尺度记忆难以同时捕捉全局布局与细粒度风格，因此本文构建三个独立原型库，分别对应64×64、32×32和16×16像素块的特征。不同尺度的检索结果经下采样对齐后融合。训练阶段，原型通过指数移动平均（EMA）进行平滑更新：

$$
\boldsymbol{\mu}_m^{(t+1)} = (1-\eta_t)\boldsymbol{\mu}_m^{(t)} + \eta_t \Delta \boldsymbol{\mu}_m
$$

其中 $\Delta \boldsymbol{\mu}_m$ 为基于注意力权重的加权增量。为防止原型坍缩，引入局部熵稀疏损失与全局负熵损失，强制每个区域仅激活少量原型，且原型使用分布保持均衡。推理时，记忆模块切换为只读快照模式，确保部署效率。

## 实验评估

实验在Fox（212页）、DreamDoc（108页测试集）及手写数据集SCUT-HCCDoc、SCUT-EPT上进行。基线覆盖Vary（7B）、Qwen-VL-Plus（>100B）、InternVL-ChatV1.5（26B）等主流VLM，但缺失ABot-OCR、MinerU2.5等最新SOTA方法，限制了横向对比的全面性。

| 方法 | 参数量 | Edit Distance↓ | F1-score↑ | BLEU↑ |
| :--- | :--- | :--- | :--- | :--- |
| Qwen-VL-Plus | >100B | 0.121 | 0.895 | 0.684 |
| Vary | 7B | 0.113 | 0.952 | 0.754 |
| Baseline | 0.6B | 0.112 | 0.944 | 0.753 |
| DREAM (Ours) | 0.6B | 0.101 | 0.964 | 0.767 |

DREAM在0.6B参数量下，Edit Distance降至0.101，优于7B的Vary（0.113）和>100B的Qwen-VL-Plus（0.121），证明显式记忆模块有效弥补了小模型参数容量的不足。

| 配置 | Edit Distance↓ | F1-score↑ |
| :--- | :--- | :--- |
| Baseline | 0.112 | 0.944 |
| Single-scale + Lsparse | 0.126 | 0.936 |
| Multiscale memory | 0.104 | 0.958 |
| Multiscale + Lsparse | 0.101 | 0.964 |

消融实验显示，移除全局负熵损失导致性能大幅下降，证实防止原型坍缩的必要性；多尺度记忆相比单尺度显著降低Edit Distance，验证了层级结构对跨尺度布局建模的贡献。

评估指标涵盖Edit Distance、F1、BLEU等，但未报告推理延迟与内存占用，无法评估“插件”带来的实际效率增益。代码已开源，超参数（如原型数2048、学习率2e-5）公开，但训练依赖8块Ascend 910B加速卡，复现门槛较高。

## 关联研究分析

从问题动机看，本文与GOT等端到端VLM同属文档解析路线，但GOT依赖高分辨率编码器与海量参数隐式学习布局，而DREAM通过非参数化记忆显式存储结构模式。这一差异源于对“知识存储位置”的不同假设：GOT认为权重足以容纳所有模式，DREAM则认为文档的有限重复性适合外部记忆。然而，DREAM未对比GOT在相同数据规模下的表现，无法排除性能提升主要源于数据增强而非记忆机制本身。

从方法设计看，DREAM借鉴了Neural Turing Machines的读写机制，但将其应用于文档结构而非时序信息。与MovieChat+等视频记忆方法不同，DREAM的记忆是跨样本的语料库级原型，而非单样本内的上下文压缩。这种设计更契合文档的静态结构特性，但EMA更新策略的滞后性可能使其难以快速适应分布漂移，这在动态文档场景（如实时流式文档）中可能成为瓶颈。

## 总结

本文旨在解决参数化VLM在文档识别中布局与语义纠缠、跨域泛化能力弱的问题。其切入点在于利用文档结构的有限重复性，引入非参数化原型记忆，通过GMM后验与注意力机制实现显式结构检索。实验证明，0.6B的DREAM在Fox数据集上Edit Distance达0.101，优于100B级基线。然而，EMA更新策略的缓慢适应性限制了其对新分布的快速响应，且缺乏与最新SOTA方法的直接对比。当训练数据分布发生剧烈变化时，原型记忆的收敛速度与识别精度的平衡点究竟在哪里，论文未给出明确回答。
