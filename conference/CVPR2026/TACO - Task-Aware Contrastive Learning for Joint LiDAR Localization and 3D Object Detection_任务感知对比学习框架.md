# CVPR2026最新论文 ｜TACO: Task-Aware Contrastive Learning for Joint LiDAR Localization and 3D Object Detection ｜任务感知对比学习框架

研究机构：厦门大学、英国布里斯托大学

作者：Leyuan Xing、Huanjia Zhang、Dongyu Pan 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_de03dbd8c19c)

> 自动驾驶系统在GNSS拒止环境下需同时完成高精度自定位与3D目标检测，传统解耦架构导致计算冗余且阻碍跨任务知识迁移。现有方法因定位依赖静态地理结构而检测依赖动态物体特征，共享网络中两类特征相互干扰，导致性能下降。TACO通过任务感知对比学习显式解耦静态与动态特征，实现双向互监督。该框架在联合任务上显著优于单任务基线，但其对多趟次数据的依赖限制了在单趟次场景下的适用性。

## 研究背景

LiDAR点云提供精确的3D空间信息，是自动驾驶感知系统的核心传感器。在GNSS信号缺失的城市峡谷等场景中，基于LiDAR的自定位与3D目标检测成为保障安全导航的关键任务。定位任务依赖长期稳定的静态地理结构（如道路、建筑），要求提取全局、稳定的结构特征；而检测任务需识别并分类可移动物体（如车辆、行人），要求捕捉局部、细粒度的动态特征。这种语义与几何优先级的根本差异，构成了多任务学习中的特征表示冲突。

传统设计将定位与检测作为独立任务处理，分别优化特定架构与指标，导致计算冗余且无法利用任务间协同效应。尽管多任务学习（MTL）通过统一模型降低内存与计算成本，但常规特征共享机制未解决任务特异性冲突：对定位有用的静态特征可能成为检测的噪声，反之亦然。LiSA等回归定位方法假设场景静态，在动态真实场景中易受移动物体干扰；CenterPoint等检测器则缺乏对全局地理结构的利用。TACO的切入点在于利用对比学习显式解耦冲突表示，通过双向互监督实现定位鲁棒性与检测精度的同步提升。

## 核心方法

### 方法参照系

TACO基于LiSA的3D骨干网络提取点云特征，采用CenterPoint的中心点检测头与RANSAC定位头。与标准单任务流程不同，TACO在特征提取后引入任务感知对比学习阶段（TFCL），通过三个子模块解耦静态地理特征与动态物体特征，解决共享网络中的任务干扰问题。

### 任务间对比学习（ITCL）

ITCL模块解决定位与检测任务间的特征干扰。通常做法是共享骨干后直接连接任务头，导致静态地理特征与动态物体特征在特征空间中混杂。TACO定义静态几何特征 $G_g = \{f_{(i,j)}^g\}$ 与移动物体特征 $M_o = \{f_{(i,j)}^o\}$，通过最小化二者余弦相似度实现解耦：

$$L_{ITCL} = \frac{1}{B} \sum_{b=1}^{B} \frac{1}{N \cdot M} \sum_{n=1}^{N} \sum_{m=1}^{M} \text{sim}(f_n^g, f_m^o)$$

该公式强制静态地理特征与动态物体特征在特征空间中分离，确保定位头专注于地理结构，检测头避免学习静态特征与物体的错误关联。

### 任务内对比学习（IDCL/ILCL）

IDCL模块解决检测任务内动态与静态物体的特征混淆。通常做法仅区分正负样本，未考虑运动状态差异。TACO将物体特征分为动态 $F_{do}$ 与静态 $F_{so}$，通过对称对比损失聚合同类动态/静态特征并分离异类特征：

$$L_{IDCL} = \frac{1}{B} \sum_{b=1}^{B} \left[ \frac{1}{Q} \sum_{q=1}^{Q} L_{ds} + \frac{1}{R} \sum_{r=1}^{R} L_{sd} \right]$$

其中 $L_{ds}$ 与 $L_{sd}$ 分别计算动态到静态、静态到动态的对比损失。ILCL模块则通过对比地理特征 $F_g$ 与伪地理特征 $F_{pg}$（由静止物体错误激活），抑制定位头中的动态噪声，提升定位鲁棒性。

## 实验评估

实验在OxfoLD、nuScenes与KITTI-360数据集上进行，基线包括LiSA、LightLoc（定位）与CenterPoint、PillarNext（检测）。TACO在OxfoLD测试集上定位误差为0.72m/0.85°，较LiSA的0.95m/1.14°分别降低24.21%与25.44%；检测mAP中车辆81.60%、行人52.32%、骑行者57.46%，均优于CenterPoint基线。

| 数据集 | 方法 | 定位误差 (m/°) | 车辆 AP@0.5 (%) | 行人 AP@0.3 (%) | 骑行者 AP@0.3 (%) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| OxfoLD | LiSA | 0.95m, 1.14° | - | - | - |
| OxfoLD | TACO | 0.72m, 0.85° | 81.60% | 52.32% | 57.46% |
| nuScenes | LiDARFormer | - | 72.54% | 47.21% | 51.00% |
| nuScenes | TACO | 0.92m, 0.82° | 85.72% | 86.93% | 52.3% |

消融实验显示，移除ITCL模块导致定位误差从0.72m/0.85°升至0.89m/1.06°，车辆AP从81.60%降至72.54%，验证了任务间解耦的关键作用。IDCL与ILCL的加入进一步将车辆AP提升至81.60%，定位误差降至0.72m/0.85°，表明任务内对比学习对性能有显著边际贡献。

评估协议采用标准mAP与定位误差指标，但未报告计算效率（FLOPs/延迟）与置信区间。代码与数据集已开源，超参数（学习率0.01、batch size 100、100 epochs）明确，可复现性良好。nuScenes上TACO检测性能（85.72%车辆AP）高于领域综述中PTNET的75.6% mAP，但协议差异（AP vs mAP）导致直接比较需谨慎。

## 关联研究分析

从问题动机看，TACO与LiDARFormer同属多任务学习框架，但LiDARFormer仅通过共享骨干与独立头实现任务协同，未解决特征表示冲突。TACO引入对比学习显式解耦静态/动态特征，在OxfoLD上定位误差降低19.1%（0.89m→0.72m），车辆AP提升12.2%（72.54%→81.60%）。这一差异源于任务特性：定位依赖全局静态结构，检测依赖局部动态特征，常规共享机制无法自动分离两类特征，需显式对比约束。

从方法设计看，TACO与CenterPoint同用中心点检测头，但CenterPoint为单任务架构，缺乏对全局地理结构的利用。TACO通过ILCL模块抑制伪地理噪声，在动态场景中定位误差较LiSA降低24.21%。这一改进源于定位任务对静态假设的依赖：移动物体破坏静态场景结构，引入噪声；TACO通过对比学习将静止物体特征与地理特征分离，提升定位鲁棒性。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

TACO解决的核心矛盾是定位与检测任务在共享网络中的特征表示冲突。现有方法因静态/动态特征混杂导致性能下降，TACO通过任务感知对比学习显式解耦，实现双向互监督。实验证明联合训练在OxfoLD上定位误差0.72m/0.85°、车辆AP 81.60%，显著优于单任务基线。其边界在于依赖多趟次数据（OxfoLD含8趟次），单趟次场景下定位性能可能退化；nuScenes上检测性能虽高，但协议差异限制与SOTA的直接比较。当支持集从多趟次缩减至单趟次时，对比学习解耦的鲁棒性是否保持，论文未给出回答。
