# CVPR2026最新论文 ｜Low-Rank Residual Diffusion Models ｜低秩残差扩散模型

作者：Junfu Tan、Jiang Yuan

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_add5d3caaeaa)

> 近域图像恢复任务中，退化图像与清晰图像在像素空间的差异（残差）具有内在的低秩结构，但现有扩散模型在全秩空间进行采样，导致计算冗余且易引入无关噪声。本文指出全秩扩散在稀疏残差空间探索效率低下的问题，提出将前向加噪过程约束在低秩子空间，同时保持反向去噪过程在全秩空间灵活性的非对称扩散框架。该方法通过自适应秩选择机制动态调整子空间维度，在去雨、去模糊等任务上以更少采样步数实现了优于全秩基线的保真度与细节恢复。其理论贡献在于证明了低秩约束能收紧变分下界，但该方法严格依赖近域假设，在远域或复杂复合退化场景下的适用性尚未验证。

## 研究背景

图像恢复旨在从受噪声、雨雾、模糊等退化影响的观测中重建高质量图像。当退化程度较轻时，退化图像 $I_{in}$ 与清晰图像 $I_0$ 的像素级差异 $I_{res} = I_{in} - I_0$ 呈现出显著的稀疏性，即大部分能量集中在少数几个主成分上，这种特性被称为近域恢复。然而，传统的判别式模型如 Restormer 虽然能学习直接映射，但缺乏生成式模型处理不确定性及保留细粒度结构的能力；而早期的扩散模型如 RDDM 虽引入了残差学习，但其扩散过程仍在全秩像素空间进行，导致模型必须探索大量与退化无关的语义空间，采样效率低下且容易污染背景不变量。

现有扩散恢复方法如 DiffUIR 和 DeblurDiff 虽然引入了任务特定结构，但均保留了全秩生成过程，这意味着扩散模型在每一步迭代中都在完整的像素或潜在空间中操作。对于近域任务而言，这种全秩操作引入了过高的自由度，使得模型难以聚焦于退化特有的低维结构。本文的切入点在于揭示并理论化近域残差的低秩特性，指出将扩散过程限制在低秩子空间不仅符合数据的内在结构，还能从变分推断的角度提供更紧的下界，从而为高效且结构保持的恢复提供原则性依据。

## 核心方法

### 残差扩散模型参照系

本文基于残差去噪扩散模型（RDDM）框架，该框架通过前向加噪和反向去噪过程学习退化域与清晰域之间的残差映射。标准 RDDM 的前向过程将残差 $I_{res}$ 逐步添加高斯噪声，反向过程则预测噪声以恢复残差。本文的关键差异在于，它不再将残差视为全秩向量，而是假设其位于一个低维子空间 $S_k$ 内，并据此重构扩散动力学。

### 低秩残差假设与非对称扩散过程

设计动机在于解决全秩扩散在近域任务中探索空语义空间导致的采样低效与背景污染问题。本文首先建立低秩残差假设，即残差协方差矩阵的特征值呈现快速衰减，存在一个秩为 $k$ 的子空间 $S_k$ 使得投影误差 $\mathbb{E}[\|I_{res} - Q_k(I_{res})\|^2] \le \epsilon$。基于此，本文提出非对称残差扩散过程：前向过程严格约束在低秩流形上，定义为 $I_t = I_0 + \bar{\alpha}_t Q_k(I_{res}) + \bar{\beta}_t \epsilon$，其中 $Q_k$ 为正交投影算子。这一设计防止各向同性噪声污染背景不变量，而反向过程 $p_\theta(I_{t-1}|I_t)$ 仍在全秩空间操作，以保留高保真重构所需的表达能力。理论上，这种非对称设计使得变分下界（VLB）在低秩子空间上更紧，因为全秩损失 $L_{t-1}$ 可分解为低秩部分 $L_{t-1,k}$ 和非负的正交补部分 $L^\perp_{t-1,k}$，即 $L_{t-1} \ge L_{t-1,k}$。

### 自适应秩选择机制

设计动机在于固定秩假设无法适应扩散过程中残差结构复杂度的动态变化，早期步骤主导粗粒度结构，后期步骤强调细节。本文引入自适应秩选择（ARS）机制，将秩 $k$ 定义为时间步 $t$ 的函数 $k(t)$。例如，线性增加策略定义为 $k_{LI}(t) = \lceil \frac{t}{T} \cdot R_m \rceil$，其中 $R_m$ 为最大秩。通过动态校准子空间秩，模型在不同扩散阶段平衡低秩结构保持与高频细节重构的能力，确保表示容量与残差的结构复杂度最优对齐。

## 实验评估

实验在 Raindrop、Rain1400、GoPro、RealBlur-J/R、ISTD 和 CelebA-HQ 数据集上进行，覆盖去雨、去模糊、去阴影和图像修复任务。基线对比涵盖了判别式模型（Restormer, X-Restormer）和扩散模型（RDDM, Diff-Plugin, OSEDiff）。在 Rain1400 去雨任务中，LRDM 取得 34.39 dB PSNR 和 0.954 SSIM，优于 RDDM 的 32.21 dB 和 0.952 SSIM；在 RealBlur-J 去模糊任务中，LRDM 取得 30.21 dB PSNR 和 0.933 SSIM，显著高于 Diff-Plugin 的 25.77 dB 和 0.771 SSIM。

| 数据集 | 方法 | PSNR (dB) | SSIM |
| :--- | :--- | :--- | :--- |
| Rain1400 | RDDM | 32.21 | 0.952 |
| Rain1400 | LRDM | 34.39 | 0.954 |
| RealBlur-J | Diff-Plugin | 25.77 | 0.771 |
| RealBlur-J | LRDM | 30.21 | 0.933 |

消融实验表明，低秩约束具有普适性。将低秩模块集成到 RDDM 和 ResShift 基线中，在 Rain1400、GoPro 和 ISTD 上均提升了 PSNR。例如，RDDM + Low-Rank 在 Rain1400 上 PSNR 从 32.21 提升至 33.30。固定秩分析显示，性能在中等秩（如 Raindrop 上的 rank 80）达到峰值，随后在全秩时略有下降，证实了适度低秩约束作为归纳偏置的有效性。

评估边界方面，论文仅报告 PSNR 和 SSIM，缺乏 LPIPS 等感知质量指标，难以全面评估生成式模型的视觉真实感。代码已开源，但论文未详细披露不同数据集下的具体超参数（如最大秩 $R_m$ 的选择依据），且实验未涉及计算效率（如采样步数与时间的具体对比数据），仅定性提及“更少采样步数”。

## 关联研究分析

从问题动机看，LRDM 与 RDDM 均关注残差学习，但 RDDM 将残差视为全秩信号，而 LRDM 利用近域残差的低秩特性进行结构化建模。这一差异源于对退化物理特性的不同理解：RDDM 假设退化成分复杂且分散，而 LRDM 假设近域退化具有内在的低维语义模式。LRDM 的理论优势在于证明了低秩约束能收紧变分下界，而 RDDM 缺乏此类理论保证。然而，LRDM 的低秩假设在远域任务（如严重模糊或结构变形）中可能失效，因为此时残差可能不再集中于低维子空间。

从方法设计看，LRDM 与 DiffUIR 同属扩散恢复框架，但 DiffUIR 采用选择性沙漏架构处理多种退化，侧重于多任务兼容性，而 LRDM 专注于单任务近域恢复的效率与保真度。DiffUIR 未引入低秩约束，其全秩扩散过程在处理单一退化时可能引入不必要的计算开销。LRDM 的自适应秩选择机制是其独特贡献，但这一机制是否能在多任务场景下动态调整以适配不同退化的秩特性，论文未进行探索。此外，LRDM 未与基于流匹配（Flow Matching）的最新方法如 IR-Flow 进行对比，后者同样关注高效传输，但基于不同的数学基础。

## 总结

本文旨在解决近域图像恢复中扩散模型采样效率低与背景污染的问题，抓住残差内在低秩结构这一被忽略的特性，提出非对称残差扩散模型 LRDM。通过前向低秩约束与反向全秩灵活性的结合，以及自适应秩选择机制，LRDM 在 Rain1400 上实现 34.39 dB PSNR，在 RealBlur-J 上实现 30.21 dB PSNR，优于全秩扩散基线。其边界在于严格依赖近域假设，未验证在远域或复合退化下的鲁棒性，且缺乏感知质量指标与计算效率的定量对比。当退化程度加剧导致残差秩显著增加时，低秩约束是否会因过度正则化而损失关键细节，论文未给出回答。
