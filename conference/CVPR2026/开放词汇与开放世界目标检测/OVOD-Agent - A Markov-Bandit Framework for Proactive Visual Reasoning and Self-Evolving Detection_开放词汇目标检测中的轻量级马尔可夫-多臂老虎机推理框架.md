# CVPR2026最新论文 ｜OVOD-Agent: A Markov-Bandit Framework for Proactive Visual Reasoning and Self-Evolving Detection ｜开放词汇目标检测中的轻量级马尔可夫-多臂老虎机推理框架

研究机构：武汉大学

作者：Chujie Wang、Jianyu Lu、Zhiyuan Luo 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.21064)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.21064)

> 开放词汇目标检测（OVOD）旨在利用视觉-语言模型（VLM）的语义先验实现对新类别的零样本识别，但现有方法在推理阶段仍依赖固定的类别名称，导致多模态训练与单模态推理之间存在错位。这种静态匹配机制难以应对视觉歧义和长尾类别，而引入大语言模型（LLM）进行动态推理又带来了不可接受的计算开销。本文提出 OVOD-Agent，通过构建一个无 LLM 依赖的弱马尔可夫决策过程（w-MDP）和基于多臂老虎机（Bandit）的探索机制，将静态匹配转化为可解释的视觉思维链（Visual-CoT）推理。该方法在多个骨干网络上实现了长尾类别检测精度的稳定提升，但其性能增益幅度有限，且对复杂域偏移场景的泛化能力尚未得到充分验证。

## 研究背景

当检测器面对训练集中未出现的新类别时，其性能严重依赖于视觉特征与文本嵌入在共享语义空间中的对齐质量。这种跨模态对齐通常由预训练的 VLM（如 CLIP）提供，但推理时仅使用固定的类别名称作为提示，使得检测退化为简单的区域-文本匹配。这种静态匹配无法捕捉图像中区域、上下文和属性之间的动态关系，导致在视觉歧义和长尾类别上表现不佳。

OVOD 领域的主流路线是通过大规模区域-文本预训练（如 GLIP, Grounding DINO）提升对齐精度，或引入 LLM 生成细粒度属性描述以丰富文本语义。然而，前者计算开销巨大且推理过程缺乏动态调整能力，后者则因 LLM 的参数量大、依赖多轮交互而违背了目标检测对实时性和部署效率的核心要求。现有方法普遍缺乏一种在推理时能够根据视觉上下文动态、迭代地优化文本表征的轻量级机制。

本文的切入点在于将 OVOD 的推理过程建模为一个序贯决策问题。作者认为，文本空间的优化不应是一次性的静态调整，而应是一个基于视觉反馈的迭代过程。通过引入弱马尔可夫决策过程（w-MDP）和基于 UCB 的多臂老虎机探索，OVOD-Agent 在不依赖 LLM 的前提下，实现了推理时的动态文本表征迭代优化，从而在保持检测器高效性的同时，增强了其对长尾和细粒度类别的识别能力。

## 核心方法

### 方法参照系

传统 OVOD 流程为：输入图像和固定文本提示，检测器执行单次前向传播输出边界框和类别分数。本文的关键差异在于将这一单次匹配过程扩展为多步迭代推理，每一步执行一个原子视觉操作以更新上下文，从而动态调整文本表征。

### 弱马尔可夫决策过程建模

设计动机：解决静态匹配无法捕捉区域-上下文-属性动态关系的问题，避免 LLM 带来的高计算开销。传统 MDP 严格分离状态与动作，但在视觉推理中，动作（如颜色提取）直接更新上下文并决定下一状态。本文提出 w-MDP，将状态和动作统一为“弱马尔可夫单元” $z_t$，定义为当前上下文 $c_t = (x_t, T_t)$ 与执行动作 $a_t$ 的联合：

$$
z_t = g(c_t, a_t)
$$

其中 $g(\cdot)$ 为确定性或随机变换。这种统一表示减少了上下文负担，使得状态转移 $P(z_{t+1}|z_t)$ 可以在紧凑的状态空间上定义，为后续的 Bandit 探索提供了结构化的先验。

### 基于 UCB 的探索与奖励模型训练

设计动机：在缺乏完整标注的情况下，高效采样高质量推理轨迹，并学习一个轻量级策略以替代在线探索。本文采用 UCB 策略平衡探索与利用，选择动作 $a_{t+1}$ 的规则为：

$$
a_{t+1} = \arg \max_{a \in \mathcal{A}} \left( \hat{\mu}_t(a|c_t) + \lambda \sqrt{\frac{\ln(1+t)}{n_t(a|c_t)}} \right)
$$

其中 $\hat{\mu}_t$ 为局部平均奖励，$n_t$ 为访问次数，$\lambda$ 控制探索强度。探索生成的轨迹与 Dirichlet 先验更新的转移矩阵共同构成离线数据集，用于训练一个双头奖励-策略模型（RM）。RM 通过最小化模仿转移模式、重构弱奖励信号和保持马尔可夫结构一致性的联合损失进行优化，推理时直接由 RM 指导动作选择，实现自进化闭环。

## 实验评估

实验在 COCO 和 LVIS 基准上进行，基线包括 GroundingDINO、YOLO-World、GroundingDINO 1.5 和 DINO-X Pro。基线覆盖了基于 Transformer 和单阶段检测器的主流 OVOD 骨干，但缺失了 2026 年最新的 SOTA 方法（如 VLDet, VL-DINO）的直接对比，且未报告计算效率的详细指标（如 FLOPs）。

| 方法 | LVIS val AP_r | LVIS minival AP_r | COCO2017 val mAP | ∆Latency (ms) |
| :--- | :--- | :--- | :--- | :--- |
| GroundingDINO | 30.2 | 35.4 | 52.1 | – |
| + OVOD-Agent | 32.9 | 37.0 | 52.7 | +120 |
| YOLO-World | 22.8 | 27.6 | 35.4 | – |
| + OVOD-Agent | 25.2 | 29.4 | 35.9 | +90 |
| GroundingDINO1.5 | 42.7 | 48.3 | 56.8 | – |
| + OVOD-Agent | 44.1 | 49.6 | 57.4 | +145 |
| DINO-X Pro | 48.0 | 52.5 | 60.2 | – |
| + OVOD-Agent | 49.2 | 53.6 | 60.6 | +155 |

OVOD-Agent 在所有骨干上均带来一致的性能提升，尤其在长尾类别（AP_r）上增益显著（+1.2 至 +2.7），而整体 AP 提升较小（+0.5 至 +1.2），表明该方法主要增强了长尾识别能力。延迟增加在 90-155 ms 之间，符合轻量级设计的预期。

消融实验表明，UCB 探索策略在 Top-K@Stop（0.66）和 Pareto-Win Rate（44.8%）上优于 Random、Greedy-Q 和 ε-Greedy，且盲评 AI 分数最高（4.7）。引入完整视觉操作集（a1-a7）比仅使用字典操作（a1）带来更高的 AP_r 提升（37.7 vs 36.5），验证了多步视觉推理的有效性。KL 正则化显著降低了 RM 损失标准差（0.028 vs 0.037）并提高了动作熵（1.55 vs 1.41），表明其缓解了策略过拟合。

评估边界方面，论文未报告置信区间，数值比较需谨慎。代码未公开，超参数（如 $\lambda, \delta_s, \delta_r$）的具体设置对复现至关重要。评估协议局限于 COCO 和 LVIS，未涵盖航拍、医疗等垂直领域，无法验证其在域偏移场景下的鲁棒性。

## 关联研究分析

从问题动机看，OVOD-Agent 与 CoT-PL 同样旨在通过推理提升伪标签或检测质量，但 CoT-PL 依赖 LLM 进行多轮交互，而本文通过 w-MDP 和 Bandit 实现了无 LLM 的轻量级推理。这一差异源于对部署效率的侧重：CoT-PL 追求推理深度的最大化，而 OVOD-Agent 在保持推理能力的同时严格约束计算开销。然而，本文的 RM 训练依赖离线轨迹，其在未见过的复杂场景中的泛化能力存疑，而 CoT-PL 的 LLM 可能具备更强的零样本适应能力。

从方法设计看，OVOD-Agent 与 RALF 都致力于丰富文本描述，但 RALF 采用检索增强生成（RAG）进行单步静态优化，而本文实现了多步动态状态转移。RALF 的检索模块依赖大规模语料，而本文的 Bandit 探索基于图像内部的视觉线索，无需外部知识库。这种设计使得 OVOD-Agent 更适用于封闭或受限环境，但在开放世界中，RALF 的检索能力可能提供更丰富的语义先验。本文未探索结合检索与动态推理的混合策略，这可能是一个潜在的改进方向。

## 总结

OVOD-Agent 旨在解决 OVOD 中静态类别匹配与多模态训练之间的错位，通过引入无 LLM 依赖的 w-MDP 和 Bandit 探索机制，实现了推理时的动态文本优化。该方法在 LVIS 和 COCO 上验证了其对长尾类别识别的有效性，AP_r 提升最高达 +2.7，且延迟增加控制在 155 ms 以内。然而，其性能增益幅度有限，且评估局限于通用基准，未验证在垂直领域或域偏移场景下的鲁棒性。当支持集增大或场景复杂度增加时，基于离线轨迹训练的 RM 是否仍能保持有效的探索-利用平衡，论文未给出回答。
