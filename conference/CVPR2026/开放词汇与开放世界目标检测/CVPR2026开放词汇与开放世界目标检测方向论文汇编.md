【Consistency Beyond Contrast: Enhancing Open-Vocabulary Object Detection Robustness via Contextual Consistency Learning ｜上下文一致性学习

研究机构：哈尔滨工业大学、香港中文大学

作者：Bozhao Li、Shaocong Wu、Tong Shao 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.26179)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.26179)

> 描述性开放词汇检测（Descriptive OVOD）旨在通过自然语言描述定位图像中的特定物体，但现有模型在背景变化时特征漂移严重，导致泛化能力不足。本文指出这一鲁棒性缺口源于训练数据缺乏“同物体多背景”配对样本，且损失函数未显式约束特征不变性。通过引入上下文引导数据生成（CBDG）与上下文一致性损失（CCLoss），该方法在小数据量下实现了SOTA性能，但其合成背景对真实复杂域偏移的覆盖度仍存疑。

【CountGD++: Generalized Prompting for Open-World Counting ｜开放世界计数中的负向提示与伪样本机制

研究机构：英国牛津大学

作者：Niki Amini-Naieni、Andrew Zisserman

论文原文见 [arXiv](https://arxiv.org/abs/2512.23351)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.23351)

> 开放世界计数旨在通过文本或视觉提示指定目标物体并估算数量，但现有模型无法区分视觉相似物体且依赖人工标注视觉样本。本文切入点在于引入负向提示过滤假阳性，并设计伪样本机制自动化视觉样本生成。通过对比训练与推理时的正负相似度比较，模型在细粒度区分任务上显著降低误差。该方法在医疗与农业场景验证了有效性，但其对密集场景中低置信度目标的潜在抑制效应尚未被充分量化。

【Detect Anything via Next Point Prediction ｜基于强化学习的多模态大模型坐标预测机制

作者：Qing Jiang、Junan Huo、Xingyu Chen 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.12798)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.12798)

> 开放词汇检测长期受限于传统回归检测器浅薄的语言理解能力，难以处理复杂语义描述；而多模态大语言模型（MLLMs）虽具备强语言推理能力，却因离散坐标预测与连续几何空间的优化失配，导致定位精度远低于回归模型。本文切入点在于识别出MLLM定位失效的两个根源：离散token映射连续像素的学习难度，以及监督微调（SFT）教师强制机制引发的训练-推理行为不匹配。通过量化相对坐标特殊token、大规模数据引擎及SFT+GRPO两阶段训练，Rex-Omni在3B规模下实现了与传统检测器竞争力的零样本定位精度。其价值在于统一了感知任务框架，但GRPO对坐标精度的直接增益有限，主要收益来自行为修正，这一发现对MLLM检测器的训练范式具有启发意义。

【Detecting Unknown Objects via Energy-based Separation for Open World Object Detection ｜基于能量分离的开放世界目标检测

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.29954)

> 开放世界目标检测（OWOD）要求检测器在增量学习已知类别的同时，无监督地识别未知物体。现有方法依赖已知空间能量分数区分未知与背景，导致特征纠缠与灾难性遗忘。DEUS 通过构建正交的双子空间能量机制分离已知与未知表示，并引入能量约束隔离新旧分类器。该方法在未知召回率上取得显著提升，但其对几何先验的依赖及在复杂域偏移下的泛化能力仍存疑。

【EW-DETR: Evolving World Object Detection via Incremental Low-Rank DEtection TRansformer ｜演化世界目标检测

作者：Munish Monga、Vishal Chudasama、Pankaj Wasnik 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.20985)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.20985)

> 开放世界目标检测（OWOD）与域增量检测（DIOD）长期割裂，前者假设静态域，后者假设闭集标签，无法应对真实场景中类别、域与未知物体同时演化的需求。现有方法依赖示例回放或辅助损失，在隐私受限或数据不平衡场景下失效。本文提出EW-DETR，通过无示例增量LoRA适配器、查询范数物体性解耦及熵感知未知混合，实现三维度耦合下的鲁棒检测。该框架在FOGS指标上领先，但缺乏与标准OWOD SOTA的直接数值对标，其长期增量稳定性存疑。

【Learning Latent Concepts for Detecting Out-of-Distribution Objects ｜基于潜在概念发现的分布外对象检测

研究机构：新加坡南洋理工大学

作者：Ting Peng、Junhao Dong、Yew-Soon Ong

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_cc5ff39177fc)

> 分布外（Out-of-Distribution, OOD）对象检测旨在识别训练集中未出现的未知物体，但现有方法多依赖实例级特征正则化，缺乏对场景全局语义的抽象能力，导致在复杂背景下误报率高。本文切入点在于引入无监督概念发现机制，通过解耦对象中心表示与检测器内部特征，在不修改检测器架构的前提下注入“未知”概念。具体做法是构建基于槽注意力（Slot Attention）的无监督概念发现模块，并通过神经概念绑定器将全局概念与局部实例特征融合。该方法在BDD-100K基准上将FPR95降低至32.61%，显著优于现有SOTA，但其性能增益是否完全源于全局语义注入，还是依赖于特定的预训练特征空间，仍需进一步验证。

【NoOVD: Novel Category Discovery and Embedding for Open-Vocabulary Object Detection ｜冻结视觉语言模型下的新型类别发现与自蒸馏

研究机构：天津大学、深圳大学

作者：Yupeng Zhang、Ruize Han、Zhiwei Chen 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.21069)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.21069)

> 开放词汇目标检测（Open-Vocabulary Object Detection, OVD）旨在利用视觉-语言模型（Vision-Language Models, VLMs）的跨模态对齐能力，使检测器在缺乏新类别标注的情况下识别未知物体。现有基于冻结VLM的两阶段检测器在训练时强制将未标注的新类别物体视为背景，导致推理阶段这些物体因置信度低而被过早过滤，造成新型类别召回率显著下降。本文提出NoOVD框架，通过无参数的知识保留特征金字塔（K-FPN）和基于LLM提示的自蒸馏机制，在训练阶段主动发现并保留新型类别特征，同时在推理阶段重加权提案分数以提升召回。该方法在OV-LVIS和OV-COCO基准上取得了优于现有冻结VLM基线的性能，但其对LLM生成提示的依赖及跨域泛化能力的边界尚存疑问。

【OVOD-Agent: A Markov-Bandit Framework for Proactive Visual Reasoning and Self-Evolving Detection ｜开放词汇目标检测中的轻量级马尔可夫-多臂老虎机推理框架

研究机构：武汉大学

> 开放词汇目标检测（OVOD）旨在利用视觉-语言模型（VLM）的语义先验实现对新类别的零样本识别，但现有方法在推理阶段仍依赖固定的类别名称，导致多模态训练与单模态推理之间存在错位。这种静态匹配机制难以应对视觉歧义和长尾类别，而引入大语言模型（LLM）进行动态推理又带来了不可接受的计算开销。本文提出 OVOD-Agent，通过构建一个无 LLM 依赖的弱马尔可夫决策过程（w-MDP）和基于多臂老虎机（Bandit）的探索机制，将静态匹配转化为可解释的视觉思维链（Visual-CoT）推理。该方法在多个骨干网络上实现了长尾类别检测精度的稳定提升，但其性能增益幅度有限，且对复杂域偏移场景的泛化能力尚未得到充分验证。

> 开放词汇目标检测（OVOD）旨在利用视觉-语言模型（VLMs）的跨模态对齐能力，实现对新类别的零样本识别。现有主流方法依赖深度融合层提升精度，但导致推理速度骤降且特征无法跨查询共享。本文切入点是将检测重构为检索问题，通过双塔架构与点积匹配替代融合，结合多粒度数据工程实现高效推理。该范式在效率与精度上取得平衡，但其对大规模标注数据的依赖及细粒度场景下的上限仍存疑。
