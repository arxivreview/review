# CVPR2026最新论文 ｜CIGPose: Causal Intervention Graph Neural Network for Whole-Body Pose Estimation ｜因果干预图神经网络全身姿态估计

研究机构：西北工业大学、西安电子科技大学

作者：Bohao Li、Zhicheng Cao、Huixian Li 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.09418)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.09418)

> 全身姿态估计旨在从单帧图像中定位包含肢体、面部和手部的密集解剖学关键点，其核心难点在于复杂场景下模型易受背景纹理干扰，将椅背误判为躯干等视觉混淆现象。现有高精度模型虽依赖大容量网络，但往往学习了虚假统计相关性而非解剖学理解，导致在遮挡或杂乱背景下失效。本文切入点是将视觉上下文形式化为结构因果模型中的混淆因子，通过因果干预模块阻断非因果后门路径，并结合分层图神经网络强制解剖学一致性。该框架在COCO-WholeBody上以67.0% AP超越依赖额外数据的基线，但仅验证了静态RGB场景，对动态或跨域泛化的鲁棒性边界尚不明确。

## 研究背景

当姿态估计模型面对杂乱背景时，其预测往往偏离解剖学真实位置，这种失效源于模型在训练数据中习得了视觉上下文与姿态之间的虚假相关性。这一现象在因果推断中被称为混淆效应，其中背景纹理等未观测变量同时影响图像特征与姿态标签，形成非因果的后门路径。为消除这种干扰，需从观测分布转向干预分布，即通过 $do$-算子切断混淆因子对预测的影响，迫使模型仅依赖因果路径进行推理。

全身姿态估计领域长期面临精度与鲁棒性的权衡。主流路线如ViTPose和HRNet通过提升网络容量和分辨率实现了高精度，但在真实世界的遮挡和杂乱场景中表现脆弱，表明高容量模型可能过度依赖表层统计特征。另一路线如DWPose通过知识蒸馏和大规模数据增强提升鲁棒性，但增加了数据依赖和计算开销，且未从原理上解决混淆问题。本文的切入点在于，不依赖额外数据或蒸馏，而是通过因果干预机制在特征层面直接阻断混淆路径，从而在保持数据效率的同时提升复杂场景下的鲁棒性。

## 核心方法

### 方法参照系

本文基于Top-Down范式，使用RTMPose作为关键点编码器，输出Heatmap形式的姿态预测。与标准流程的关键差异在于，本文在编码器输出与解码器之间插入了因果干预模块（CIM），并在解码器前引入分层图神经网络（GNN），以在去混淆的嵌入上执行解剖学推理。

### 因果干预模块

设计动机是解决标准模型中视觉上下文混淆导致的虚假相关问题。CIM通过预测不确定性识别受混淆的关键点嵌入，并用可学习的规范嵌入进行反事实替换。混淆分数 $s_c(k)$ 定义为关键点坐标Heatmap后验分布的峰值浓度，低峰值信号高不确定性：

$$ s_c(k) = \max_{x,y} P_{k,x} \cdot P_{k,y} $$

该公式量化了预测的歧义性，分数最低的Top-n关键点被视为受混淆影响。随后，这些嵌入 $f_k$ 被替换为来自可学习表 $Z$ 的规范嵌入 $z_k$，执行干预 $do(f_k := z_k)$。由于 $Z$ 作为模型参数与具体混淆实例独立，此操作切断了 $F \leftarrow X \leftarrow C$ 的依赖链，阻断了后门路径。

### 分层图推理

设计动机是确保去混淆后的嵌入在解剖学上全局一致。分层GNN在去混淆嵌入 $F'$ 上执行两阶段推理。第一阶段使用EdgeConv在标准骨架图 $G_p$ 上建模局部运动学关系；第二阶段使用语义超图 $G_h$ 捕捉长程依赖，其中超边代表功能关键点组（如“左手”）。超边表示 $g_e$ 通过聚合其成员嵌入计算，并通过消息传递更新为上下文感知表示 $g_e'$，进而生成通道注意力权重调制关键点嵌入：

$$ g_e' = \text{MLP}\left(\frac{1}{|e|} \sum_{k \in e} [f]_k' \right) $$

该公式通过功能组聚合与注意力机制，强制局部与全局解剖学约束，产生最终的一致姿态预测。

## 实验评估

实验在COCO-WholeBody、COCO和CrowdPose三个基准上进行，基线覆盖Top-Down主流方法（RTMPose, ViTPose, HRNet）及依赖额外数据的DWPose，但缺失Bottom-Up最新SOTA如DEKR在COCO-WholeBody上的直接对比。

| 方法 | 输入尺寸 | GFLOPs | COCO-WholeBody AP | COCO AP | CrowdPose AP |
| :--- | :--- | :--- | :--- | :--- | :--- |
| RTMPose-l | 256×192 | 4.5 | 63.0 | 76.5 | 71.9 |
| DWPose-l* | 256×192 | 4.5 | 66.5 | - | - |
| CIGPose-l | 256×192 | 4.6 | 62.6 | 79.3 | 73.7 |
| CIGPose-x | 384×288 | 18.7 | 67.0 | - | - |

CIGPose-x在COCO-WholeBody上以67.0% AP超越DWPose-l的66.5% AP，且未使用额外UBody数据，证明了因果干预在数据效率上的优势。CIGPose-l在COCO上达到79.3% AP，较RTMPose-l提升2.8 AP，表明因果机制对通用姿态估计的增益。

| 配置 | COCO-WholeBody AP | 增益 |
| :--- | :--- | :--- |
| Baseline (RTMPose-l) | 64.8 | - |
| + GNN | 65.6 | +0.8 |
| + CIM | 65.7 | +0.9 |
| + CIM + GNN | 66.3 | +1.5 |

消融实验显示，CIM与GNN的组合带来1.5 AP的增益，高于单独使用任一模块（0.8-0.9 AP），表明去混淆与解剖学推理的协同效应。然而，CIM仅替换Top-n关键点，可能丢失局部细节，论文未量化此风险。

评估协议使用标准OKS-based AP，但未报告置信区间或计算效率的延迟指标。代码已开源，训练使用单张RTX 5090或8张RTX 4090，超参数如 $\lambda=0.1$ 已公开，可复现性较高。

## 关联研究分析

从问题动机看，CIGPose与CleanPose同属因果学习路线，但CleanPose使用前门调整处理数据偏差，而CIGPose使用后门阻断处理视觉混淆。这一差异源于任务特性：CleanPose关注标签噪声，CIGPose关注背景干扰。CIGPose的干预策略更直接地针对姿态估计中的空间混淆，但缺乏对非视觉混淆因子（如光照）的显式建模。

从方法设计看，CIGPose与DWPose在鲁棒性提升路径上形成对比。DWPose依赖蒸馏和额外数据，CIGPose依赖因果干预。CIGPose在COCO-WholeBody上以更少数据超越DWPose，表明因果机制在数据效率上的优势。然而，CIGPose的计算开销（18.7 GFLOPs for CIGPose-x）高于RTMPose-l（4.5 GFLOPs），是否抵消了轻量化优势，论文未提供延迟对比。

## 总结

CIGPose解决的核心矛盾是全身姿态估计中视觉混淆导致的鲁棒性不足。现有方法依赖数据增强或蒸馏，未从原理上阻断虚假相关，而CIGPose通过因果干预模块在特征层面切断混淆路径，结合分层GNN强制解剖学一致性。在COCO-WholeBody上，CIGPose-x以67.0% AP超越依赖额外数据的DWPose-l（66.5% AP），证明了因果干预的数据效率。本文的边界在于仅验证了静态RGB场景，且CIM的Top-n替换策略可能引入局部信息丢失。当支持集增大或场景复杂度进一步提升时，因果干预的边际收益是否递减，论文未给出回答。
