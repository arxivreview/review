# CVPR2026最新论文 ｜TrajRAG: Retrieving Geometric-Semantic Experience for Zero-Shot Object Navigation ｜轨迹检索增强生成

研究机构：中国科学院、中国科学院大学

作者：Yiyao Wang、Sixian Zhang、Keming Zhang 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.01700)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.01700)

> 零样本物体导航（ObjectNav）旨在让智能体在未知环境中定位目标，但现有方法依赖的互联网文本常识缺乏3D空间经验，且单集内的情景记忆在任务结束后即被丢弃，导致智能体无法积累终身经验。本文切入点在于将检索增强生成（RAG）机制从文本域迁移至具身导航，通过构建跨场景的轨迹经验库弥补模型的空间感知缺陷。具体做法是提出拓扑-极坐标（Topo-polar）轨迹表征以压缩冗余观测，并采用分层检索策略将历史经验注入大语言模型（LLM）推理。该方法在HM3D-v2上取得78.1%成功率，但在HM3D-v1上低于最新基线，其跨场景泛化能力与实时部署效率尚存疑。

## 研究背景

具身导航中的智能体需同时处理空间几何与语义理解。传统强化学习方法在已知环境中训练策略，但泛化至未知场景时失效；引入视觉语言模型（VLM）后，零样本范式利用常识推理替代微调，但VLM的知识源于网页文本，缺乏对3D空间布局的具身经验。此外，现有方法在单个导航任务（Episode）中构建的情景记忆（如语义地图、场景图）通常在任务结束后被丢弃，智能体无法从过往经验中持续学习，导致在大型环境中重复探索或迷失。

零样本物体导航的主流路线分为两类：一类直接利用LLM/VLM推理当前观测，另一类构建显式地图（如VLFM的视觉-语言前沿地图）辅助规划。前者缺乏长时程记忆，后者虽提供场景特定信息，但无法跨场景迁移知识。本文针对“经验无法累积”这一核心瓶颈，提出TrajRAG框架。它不依赖单集内的临时地图，而是将历史导航轨迹转化为可检索的几何-语义经验库，使智能体在规划时能调用过往类似场景的探索路径，从而桥接场景无关的常识推理与场景特定的空间经验。

## 核心方法

### 方法参照系

零样本物体导航的标准流程是：智能体通过RGB-D观测构建语义地图，基于前沿（Frontier）选择探索点，由VLM/LLM根据当前观测与目标描述规划下一步动作。本文的关键差异在于，规划器不仅接收当前观测，还接收从外部经验库中检索到的历史轨迹经验，且经验库随导航过程动态更新。

### 拓扑-极坐标轨迹表征

原始轨迹包含大量冗余（如局部回环、帧间微小变化），直接存储会导致检索效率低下。本文提出拓扑-极坐标（Topo-polar）轨迹，将连续观测离散化为结构化序列。首先对语义地图进行形态学细化提取骨架，选取8邻域内连接分量≥3的像素作为拓扑节点。围绕每个节点，以30°为间隔发射极坐标射线，记录首个非自由像素的语义标签，形成扇区向量 $\mathbf{s}_k$。该表征解决了原始轨迹的空间冗余问题，同时通过极坐标扇区捕捉相对几何-语义布局，作为轨迹匹配的“指纹”。

$$ \mathbf{s}_k = [R(\theta_1), R(\theta_2), \dots, R(\theta_{12})] $$

其中 $R(\theta)$ 为方向 $\theta$ 上的采样结果，该向量编码了节点周围的局部语义-几何结构，消除了绝对坐标依赖，便于跨场景匹配。

### 分层检索与轨迹编码

经验库采用分层结构：粗粒度索引为拓扑-极坐标摘要（Topo-polar Summary），细粒度索引为轨迹嵌入。检索时先通过摘要匹配定位相似布局组，再在组内通过轨迹编码器进行细粒度匹配。轨迹编码器由冻结的DistilBERT（编码节点扇区向量）和可训练的DistilGPT2（编码序列依赖）组成，输出轨迹嵌入 $\mathbf{z}_i$。训练采用对比学习，使同组同目标的轨迹嵌入接近，不同组的远离。

$$ \mathcal{L} = -\log \frac{\exp(\text{sim}(\mathbf{z}_i, \mathbf{z}_j^+)/\tau)}{\sum_{k} \exp(\text{sim}(\mathbf{z}_i, \mathbf{z}_k)/\tau)} $$

该损失函数确保检索结果既符合空间布局相似性，又具备导航目标相关性，解决了通用文本嵌入无法捕捉轨迹时序依赖的问题。

## 实验评估

实验在Habitat模拟器上进行，数据集包括MP3D、HM3D-v1和HM3D-v2，指标为成功率（SR）和路径长度加权成功率（SPL）。基线覆盖了ZSON、VLFM、ApexNav等经典零样本方法，但未包含基于3D高斯泼溅（3DGS）的最新SOTA方法（如Uni-LaViRA）。

| 数据集 | 方法 | SR (%) | SPL (%) |
| :--- | :--- | :--- | :--- |
| HM3D-v1 | VLFM | 52.5 | 30.4 |
| HM3D-v1 | ApexNav | 59.6 | 33.0 |
| HM3D-v1 | TrajRAG | 62.5 | 33.9 |
| HM3D-v2 | VLFM | 63.6 | 32.5 |
| HM3D-v2 | ApexNav | 76.2 | 38.0 |
| HM3D-v2 | TrajRAG | 78.1 | 40.2 |
| MP3D | VLFM | 36.4 | 17.5 |
| MP3D | ApexNav | 39.2 | 17.8 |
| MP3D | TrajRAG | 42.6 | 18.0 |

TrajRAG在HM3D-v2上SR达78.1%，略高于ApexNav的76.2%；在MP3D上SR为42.6%，显著高于VLFM的36.4%。消融实验显示，移除粗粒度检索导致SR从61.7%降至54.3%，证明场景布局预筛选对过滤无关上下文至关重要。

| 消融组件 | SR (%) | SPL (%) |
| :--- | :--- | :--- |
| 完整模型 | 61.7 | 33.2 |
| 移除粗粒度检索 | 54.3 | 25.6 |
| 使用文本嵌入替代轨迹编码器 | 57.8 | 29.7 |
| 仅拓扑-极坐标几何 | 25.7 | 22.3 |
| 仅拓扑-极坐标语义 | 48.1 | 30.6 |

节点表征消融表明，仅几何信息（25.7% SR）远低于仅语义信息（48.1% SR），而两者结合（61.7% SR）最优，证实几何与语义线索的互补性。评估边界方面，论文未报告计算延迟，且经验库在测试时冻结，未验证动态更新对性能的影响。代码未开源，超参数（如RANSAC阈值、对比学习温度）细节有限，可复现性依赖Habitat标准配置。

## 关联研究分析

从问题动机看，TrajRAG与VLFM同属显式地图路线，但VLFM依赖单集内构建的视觉-语言前沿地图，而TrajRAG引入跨场景经验库。VLFM的地图是场景特定的，无法迁移至新环境；TrajRAG通过拓扑-极坐标表征抽象出场景无关的空间布局模式，使经验可跨数据集泛化（如HM3D-v1训练的经验在MP3D上SR提升3.2%）。这一差异源于任务特性：零样本导航要求模型在未见场景中推理，仅靠单集地图无法提供足够的空间先验，而历史经验库提供了“类似场景如何导航”的具身知识。

从方法设计看，TrajRAG与Nav-R1同为零样本导航框架，但Nav-R1侧重思维链（CoT）推理，通过构建NavCoT-110K数据集训练模型理解目标-环境关系；TrajRAG侧重经验检索，通过RAG机制注入历史轨迹。Nav-R1的推理是参数化的，依赖模型内部权重；TrajRAG的推理是非参数化的，依赖外部知识库。前者在HM3D-OVON上SR达58.4%，后者在HM3D-v1上SR为62.5%，但两者评估基准不同，直接对比需谨慎。TrajRAG的检索机制可能更适应动态环境，因为经验库可实时更新，而Nav-R1的CoT能力受限于训练数据分布。

## 总结

本文解决的核心矛盾是零样本导航中VLM缺乏3D空间经验与情景记忆无法累积的问题。切入点在于将RAG机制引入具身导航，通过拓扑-极坐标轨迹压缩冗余观测，并利用分层检索将历史经验注入LLM推理。实验证明该方法在HM3D-v2上SR达78.1%，在MP3D上SR达42.6%，验证了跨场景经验迁移的有效性。边界在于HM3D-v1上SR（62.5%）低于Uni-LaViRA（77.7%），且未报告实时延迟，经验库冻结设置限制了终身学习能力的验证。当环境动态变化或经验库规模扩大时，检索延迟与经验冲突消解机制如何影响导航鲁棒性，论文未给出回答。
