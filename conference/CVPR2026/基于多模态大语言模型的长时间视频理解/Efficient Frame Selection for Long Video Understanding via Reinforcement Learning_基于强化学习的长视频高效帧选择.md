# CVPR2026最新论文 ｜Efficient Frame Selection for Long Video Understanding via Reinforcement Learning ｜基于强化学习的长视频高效帧选择

作者：Yaxuan Qin、Hefei Li、Wenqi Mu 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f15281c56e23)

> 长视频理解面临上下文窗口限制与稀疏关键证据分布不均的矛盾，均匀采样策略导致关键帧遗漏，而现有基于代理目标（如查询-帧相关性）的选择方法存在计算开销大且反馈间接的问题。本文提出一种轻量级查询自适应帧选择器，通过两阶段训练策略解决该问题：第一阶段从冻结CLIP教师模型蒸馏语义相关性先验，第二阶段利用GRPO算法结合层级奖励直接优化端到端任务效用。该方法作为即插即用模块，在多个基准上提升了不同规模MLLM的性能，但其固定Top-K选择机制在极端稀疏证据场景下的泛化能力仍存疑。

## 研究背景

多模态大语言模型（MLLMs）处理长视频时，受限于有限的上下文窗口，通常采用均匀帧采样以控制计算成本。然而，长视频中承载关键推理信息的帧往往分布稀疏且不规则，均匀采样极易遗漏这些“针尖”证据，导致模型在复杂问答任务中表现不佳。为弥补这一缺陷，自适应关键帧采样（Adaptive Keyframe Sampling, AKS）及基于MLLM评分的方法（如FRAG）被提出，它们通过动态分配样本或评估帧-查询相关性来筛选关键帧。

尽管上述方法优于固定采样，但存在两个核心瓶颈：一是依赖重型MLLM进行推理评分，引入了高昂的计算延迟；二是使用查询-帧相关性或预测损失作为代理目标，这种间接反馈可能导致选择器偏向于“看起来相关”但对最终答案无用的冗余帧，缺乏对组合级任务效用的直接优化。本文的切入点在于将帧选择建模为一个强化学习（Reinforcement Learning, RL）问题，通过直接优化下游任务的二元正确性奖励，替代传统的代理目标，从而在保持轻量级架构的同时提升选择精度。

## 核心方法

### 查询条件化评分架构

本文方法参照系为基于视觉-语言对齐的帧评分流程，关键差异在于摒弃了端到端训练重型评分器，转而采用冻结CLIP嵌入与轻量级Transformer解码器的组合。该架构包含特征提取器、上下文特征模型和评分器。具体而言，预训练CLIP模型生成查询嵌入 $e_q \in \mathbb{R}^d$ 和帧嵌入 $e_{f_i} \in \mathbb{R}^d$，随后输入一个3层、隐藏维度为 $d$ 的Transformer解码器以捕获帧间时序上下文。最终层采用简化的查询-键注意力头，将查询嵌入处理为上下文丰富的表示 $Q' \in \mathbb{R}^{d_k}$，帧表示投影为 $K_i \in \mathbb{R}^{d_k}$。第 $i$ 帧的标量分数定义为：

$$ s_i = \frac{Q' K_i^\top}{\sqrt{d_k}} $$

该公式通过点积注意力机制显式地将评分条件化于查询，避免了简单全连接层忽略查询特定语义的问题，使得选择器能以极低的计算开销（3.36秒）对128个候选帧进行排序。

### 两阶段训练与层级奖励

设计动机在于解决纯RL训练不稳定且样本效率低，以及纯监督学习无法捕捉组合级效用（如多样性、时序覆盖）的问题。第一阶段为监督预训练，通过蒸馏冻结CLIP教师模型，使用锐化温度 $\tau=0.03$ 学习帧-查询相关性分布，为策略提供强初始化。第二阶段采用GRPO框架进行RL微调，核心创新在于层级奖励机制。对于每个查询，采样 $G$ 个大小为 $K$ 的帧组合 $\{I^{(g)}\}_{g=1}^G$，每个组合由下游MLLM评估得到二元任务奖励 $r^{(g)}_{task} \in \{0, 1\}$。组合级优势通过组内标准化计算：

$$ \hat{A}^{(g)}_{comb} = \frac{r^{(g)}_{task} - \frac{1}{G}\sum_{g=1}^G r^{(g)}_{task}}{\sqrt{\frac{1}{G}\sum_{g=1}^G (r^{(g)}_{task} - \bar{r}_{task})^2} + \epsilon} $$

该公式将每个组合的成功率与其同查询下的其他组合进行比较，并将信用均匀传播至构成该组合的帧。最终帧级优势 $\hat{A}_i$ 由帧级信号与组合级信号加权聚合，直接优化端到端任务效用而非代理相关性。此外，引入自适应KL监控-回滚机制，当KL散度出现尖峰时立即回滚，防止策略漂移，无需显式KL惩罚项。

## 实验评估

实验在LongVideoBench、VideoMME、MLVU和EgoSchema四个基准上进行，对比基线包括Random、Uniform、CLIP-TopK、AKS及MLLM-based选择器。基线覆盖了无训练、基于CLIP相似度及基于MLLM推理的主要路线，但未对比稀疏注意力（如VideoNSA）或代理式推理（如LongVT）等2025-2026年的前沿方法。

| 方法 | Accuracy (%) | Frame selection time (s) |
| :--- | :--- | :--- |
| Random | 49.7 | / |
| Uniform | 51.1 | / |
| CLIP-TopK | 55.7 | 3.34 |
| AKS [21] | 55.9 | 7.84 |
| Ours | 56.5 | 3.36 |

在Qwen2-VL-7B骨干下，本文方法在LongVideoBench上达到56.5%准确率，较Uniform提升5.4%，较CLIP-TopK提升0.8%，且选择耗时（3.36s）与CLIP-TopK相当，远低于AKS（7.84s）。

| 配置 | Accuracy (%) |
| :--- | :--- |
| Ours (Full Model) | 56.5 |
| w/o Reinforcement Learning Stage | 55.1 |
| w/o Pre-training Stage | 54.8 |
| w/o hierarchical reward | 55.6 |
| w/o KL monitor | 55.2 |

消融实验显示，移除RL阶段导致1.4%的性能下降，移除预训练阶段导致1.7%下降，验证了两阶段策略的必要性。移除层级奖励（仅用组合级）导致0.9%下降，表明帧级信号对细粒度信用分配至关重要。移除KL监控导致1.3%下降，证实了自适应回滚机制对训练稳定性的贡献。

评估边界方面，论文未报告置信区间，且所有实验固定N=128, K=8，未探索不同帧预算下的性能-效率帕累托前沿。代码未公开，但提供了详细的超参数（AdamW, lr=1e-4/1e-6, 8x L20 GPUs），具备可复现性基础。

## 关联研究分析

从问题动机看，本文与FRAG、FrameVoyager等基于代理目标的方法形成鲜明对比。FRAG依赖MLLM推理评分，虽精度高但延迟大；FrameVoyager使用预测损失作为监督信号，但损失最小化并不等价于任务正确性最大化。本文通过RL直接优化二元任务奖励，解决了代理目标与最终效用不一致的根本问题。然而，本文的RL阶段仅训练1个epoch，且依赖下游MLLM（Qwen2-VL）生成奖励，这种对特定骨干的依赖可能限制了选择器在其他架构上的泛化能力，论文未深入探讨奖励模型偏差对选择策略的影响。

从方法设计看，本文与AKS同属高效帧采样路线，但AKS是无训练的动态采样，而本文引入了可学习的策略网络。与LongVT等代理式推理框架相比，本文未涉及工具调用或多轮交互，仅优化单次前向传播的输入质量。这种“静态优化”与“动态交互”的差异源于任务定义：本文假设关键帧可在单次采样中确定，而LongVT认为复杂推理需要迭代验证。在证据极度稀疏且需要多跳推理的场景下，本文的固定Top-K机制可能不如代理式框架灵活，但其在实时性指标上具有显著优势。

## 总结

本文旨在解决长视频理解中均匀采样导致的关键证据丢失问题，针对现有方法依赖代理目标且计算开销大的瓶颈，提出了一种基于两阶段训练（CLIP蒸馏+GRPO）的轻量级帧选择器。通过层级奖励直接优化端到端任务效用，该方法在LongVideoBench上较Uniform采样提升5.4%，在保持低延迟（3.36s）的同时实现了精度提升。然而，实验仅覆盖固定帧预算（K=8）场景，且未对比最新的稀疏注意力或代理式推理方法，其性能上限受限于单次前向传播的静态选择机制。当视频时长进一步增加至小时级且证据分布极度稀疏时，固定Top-K策略是否仍能维持优势，还是必须引入动态帧数调整机制，论文未给出回答。
