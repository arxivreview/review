# CVPR2026最新论文 ｜Next-Scale Autoregressive Models for Text-to-Motion Generation ｜层级因果自回归运动生成

研究机构：美国宾夕法尼亚大学

作者：Zhiwei Zheng、Shibo Jin、Lingjie Liu 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.03799)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.03799)

> 文本驱动人体运动生成（T2M）的核心难点在于全局语义结构的保持，如动作重复次数与序列级模式，现有扩散模型与标准自回归模型均因缺乏因果层级而难以精确对齐。MoScale 指出标准 Next-Token 自回归因短期动态可预测性而陷入局部捷径，提出 Next-Scale 自回归框架，通过粗到细的时间尺度层级建立全局语义骨架。该方法结合跨尺度层级精炼与尺度内时间精炼，在 HumanML3D 上取得 SOTA 性能。其价值在于揭示了自回归范式在运动生成中的结构性缺陷，但物理可执行性与长序列累积误差仍是未解之题。

## 研究背景

理解 MoScale 需先厘清运动离散化与因果建模的张力。运动序列经残差向量量化变分自编码器（RVQ-VAE）转为离散 Token 后，标准自回归模型（AR）按时间顺序逐 Token 预测。然而，运动短期动态高度可预测，模型易依赖局部历史而非全局结构，导致“两个开合跳”等语义指令失效。Next-Scale 预测则按时间尺度层级生成 Token 组，粗尺度定全局，细尺度补细节，天然契合运动的层级语义结构。

T2M 领域长期存在扩散模型与自回归模型的路线之争。扩散模型通过迭代去噪提升保真度，但推理慢且全局结构依赖初始噪声；标准 AR 模型训练高效，却因短期动态捷径导致语义对齐弱。MoMask++ 等掩码 Transformer 虽引入双向注意力，但随机扰动破坏了层级因果性。MoScale 的切入点在于：将 Next-Scale 层级因果结构引入 AR 框架，强制模型在粗尺度建立全局语义骨架，消除 Next-Token 的局部捷径，同时通过精炼机制弥补数据稀缺下的鲁性不足。

## 核心方法

### 层级运动表示与 Next-Scale 生成

MoScale 基于 RVQ-VAE 将运动编码为 $K$ 个尺度的离散 Token 组 $\{z_1, ..., z_K\}$，序列长度分别为 $(L_1, ..., L_K)$。生成时，模型以文本嵌入 $t$ 为条件，自回归预测各尺度 Token：

$$p(z_1, ..., z_K | t) = \prod_{k=1}^K p(z_k | z_{<k}, t)$$

此公式表明，每个尺度 $k$ 的预测仅依赖更粗尺度 $z_{<k}$ 与文本，而非前一个 Token。设计动机在于：标准 Next-Token 预测中，短期动态可预测性使模型忽略全局结构；Next-Scale 结构强制模型在粗尺度 $z_1$ 确定全局组织，细尺度逐步细化，建立层级因果骨架。

### 跨尺度层级精炼

标准 Next-Scale 训练采用教师强制，模型仅见干净输入，推理时无法纠正粗尺度误差。MoScale 在训练时扰动粗尺度 Token：对 $z_{k-1}$ 随机替换部分 Token 为码本随机值，形成 $\tilde{z}_{k-1}$，并以此计算尺度 $k$ 的目标残差：

$$\tilde{f}_k = f - \sum_{i=1}^{k-1} \hat{f}_i(\tilde{z}_i)$$

此公式表明，尺度 $k$ 的学习目标动态调整为纠正被扰动的粗尺度预测。设计动机在于：暴露模型于不完美中间状态，使其学会从粗尺度误差中恢复，减少推理时的误差累积，提升层级生成的稳定性。

### 尺度内时间精炼

尺度内 Token 存在双向依赖，但 Next-Scale 结构仅保证跨尺度因果性。MoScale 在每个尺度内采用选择性掩码-重预测策略：利用双向注意力评估 Token 可靠性，对不确定区域迭代重预测。此机制不破坏跨尺度因果结构，仅优化尺度内时间连贯性。设计动机在于：文本-运动数据集规模远小于语言语料，双向精炼可提升低数据场景下的鲁性，改善局部运动平滑度，弥补跨尺度精炼对局部细节的不足。

## 实验评估

实验在 HumanML3D（14,515 序列）与 KIT-ML（3,911 序列）上进行，基线覆盖 Next-Token AR（T2M-GPT, ParCo）、扩散模型（MDM, ReMoDiffuse）与掩码 Transformer（MoMask, MoMask++），但缺失 Flow Matching 类基线（如 HY-Motion, MoLingo）。

| 方法 | 结构 | Top1↑ | FID↓ | MM-Dist↓ |
| :--- | :--- | :--- | :--- | :--- |
| MoMask++ | MaskedTrans | 0.528 | 0.045 | 2.912 |
| MoScale (S=18) | Next-Scale AR | 0.540 | 0.046 | 2.830 |

MoScale 在 HumanML3D 上 Top1 达 0.540，优于 MoMask++ 的 0.528；FID 0.046 与 MoMask++ 的 0.045 持平，MM-Dist 2.830 显著优于 2.912，验证了层级因果结构对语义对齐的有效性。

消融实验显示，移除跨尺度层级精炼后，VLM 评分从 2.14 降至 1.89，接近 MoMask++ 的 1.90；仅保留尺度内时间精炼时评分为 1.92。这表明层级精炼是语义对齐的主要驱动因素，时间精炼主要贡献局部连贯性。腐蚀率 $\gamma_{max}=0.6$ 时性能最优，过高或过低均导致性能下降，反映误差模拟与数据利用的平衡。

评估边界方面，论文未报告置信区间（仅主表提供 95% CI），且未对比 Flow Matching 模型，可能因架构差异或训练效率考量。代码已开源，超参数（如 16 层 Transformer、学习率 $3 \times 10^{-4}$）完整披露，可复现性良好。

## 关联研究分析

从问题动机看，MoScale 与 MoMask++ 均针对全局语义对齐，但 MoMask++ 采用随机 Token 扰动打破层级因果，而 MoScale 通过结构化层级因果建立全局骨架。差异根源在于：MoMask++ 的随机扰动虽增加训练多样性，但削弱了粗到细的语义传递；MoScale 的层级因果结构强制模型在粗尺度确定全局组织，更契合运动的层级语义特性。MoMask++ 在 FID 上略优（0.045 vs 0.046），但 MM-Dist 显著落后（2.912 vs 2.830），表明其保真度优势未转化为语义对齐优势。

从方法设计看，MoScale 与 T2M-GPT 同属 AR 范式，但 T2M-GPT 采用 Next-Token 预测，MoScale 改为 Next-Scale 预测。差异根源在于：T2M-GPT 的 Next-Token 结构受短期动态捷径影响，模型易依赖局部历史；MoScale 的 Next-Scale 结构强制模型在粗尺度建立全局语义，消除局部捷径。T2M-GPT 在 Top1 上仅 0.492，远低于 MoScale 的 0.540，验证了层级因果结构对语义对齐的关键作用。MoScale 未显式引入物理约束，依赖局部平滑改善运动质量，这在机器人应用中可能受限，但论文未探索物理引导的层级生成。

## 总结

MoScale 要解决的核心矛盾是自回归模型在运动生成中全局语义对齐弱与训练高效性的冲突。其切入点在于：标准 Next-Token 预测因短期动态可预测性而陷入局部捷径，而 Next-Scale 层级因果结构强制模型在粗尺度建立全局语义骨架，消除局部捷径。MoScale 通过 RVQ-VAE 离散化、Next-Scale 自回归生成、跨尺度层级精炼与尺度内时间精炼，在 HumanML3D 上取得 Top1 0.540 与 MM-Dist 2.830 的 SOTA 性能。其边界在于：未显式处理物理可执行性，依赖局部平滑改善运动质量；长序列（>10s）生成的累积误差表现未充分验证。当支持集增大到 5-shot 时，跨尺度层级精炼的边际收益是否递减，论文未给出回答。
