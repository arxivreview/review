# CVPR2026最新论文 ｜fMRI-LM: Towards a Universal Foundation Model for Language-Aligned fMRI Understanding ｜fMRI 语言对齐基础模型

研究机构：美国佐治亚理工学院

作者：Yuxiang Wei、Yanteng Zhang、Xi Xiao 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.21760)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.21760)

> 现有 fMRI 基础模型仅依赖神经信号自监督目标，缺乏语义接地，导致跨任务泛化能力受限且无法进行自然语言交互。本文切入点在于构建合成 fMRI-文本描述语料，通过三阶段框架将 fMRI 信号映射至 LLM 文本嵌入空间。具体做法是训练文本对齐的 fMRI 分词器，微调 LLM 进行时序预测与文本生成，最后进行多任务指令微调。该框架在通用理解任务上显著优于传统监督与自监督基线，但其表征是否适用于视觉重建等下游任务尚存疑。

## 研究背景

理解 fMRI 信号需先解决高维时空数据的表征压缩问题。功能磁共振成像（fMRI）捕获的是血氧水平依赖（BOLD）信号，其原始数据为四维体素序列，直接处理计算成本极高且噪声大。为降低维度，研究通常基于脑图谱将体素划分为感兴趣区（ROI），将信号转化为 ROI 级别的时间序列。然而，ROI 信号仍缺乏语义解释，传统方法将其视为纯数值向量，忽略了其背后反映的脑功能组织规律。这种“无语言接地”的表征使得模型难以利用大语言模型（LLM）强大的推理与生成能力，限制了 fMRI 分析从单一任务预测向通用认知理解的扩展。

fMRI 分析正从任务特定的监督学习转向通用表征学习。早期基于卷积神经网络（CNN）或图神经网络（GNN）的方法在疾病诊断上表现良好，但跨队列泛化能力弱。近期涌现的自监督基础模型如 BrainLM 和 Brain-JEPA，通过掩码预测或对比学习在大规模数据上预训练，提升了鲁棒性，但仍局限于神经信号内部目标，缺乏与语言空间的对齐。这种语义缺失导致模型无法处理开放式问答或描述生成任务，且难以利用 LLM 中蕴含的丰富世界知识。本文旨在填补这一空白，通过构建合成文本语料，将 fMRI 的低层结构特征转化为语言描述，从而建立 fMRI 与 LLM 之间的语义桥梁，实现跨数据集、跨任务的通用理解。

## 核心方法

### 方法参照系

本文问题可置于多模态大语言模型（MLLM）的通用架构下，即“模态编码器 + 对齐模块 + LLM 骨干”。标准流程是将非文本模态编码为嵌入，通过投影层对齐至文本空间，再由 LLM 进行推理。关键差异在于，fMRI 缺乏天然的文本配对数据，且具有显著的时序-空间结构，无法直接套用图像-文本对训练范式，需专门设计时序感知的分词器与合成语料生成机制。

### 合成 fMRI-文本语料构建

设计动机在于解决 fMRI 缺乏自然语言配对数据导致的语义接地缺失。通常做法是使用真实标注文本，但 fMRI 领域不存在此类数据。本文从功能连接（FC）、功能梯度（FG）、图论指标及独立成分分析（ICA）四个域提取 23 个描述符，利用固定模板将数值统计转化为自然语言语句，并经 DeepSeek-V3 润色为连贯段落。这些描述符捕捉了脑功能的低层组织结构，如网络连通性模式与模块度，作为语言监督信号。该语料不仅提供了训练数据，更将抽象的神经指标转化为可解释的语义概念，使 LLM 能够理解 fMRI 信号背后的功能含义，而非仅拟合数值分布。

### 文本对齐 fMRI 分词器

设计动机在于将高维 fMRI 时序数据压缩为离散 token，使其能嵌入 LLM 的词汇表。通常做法是使用连续嵌入，但离散化有助于 LLM 的自回归预测。本文采用 Transformer 编码器结合向量量化（VQ）模块，将 ROI 时间序列映射为离散 token。为对齐文本空间，引入域对抗损失与对比损失。总损失函数为：

$$ \mathcal{L}_{total} = \mathcal{L}_{rec} + \mathcal{L}_{commit} + \lambda \mathcal{L}_{adv} + \mathcal{L}_{con} $$

其中 $\mathcal{L}_{rec}$ 为重构损失，$\mathcal{L}_{adv}$ 为域对抗损失（通过梯度反转层使 fMRI 嵌入与文本嵌入不可区分），$\mathcal{L}_{con}$ 为 SigLIP 风格对比损失（最大化配对 fMRI-文本嵌入相似度）。该设计确保生成的 fMRI token 在几何结构上与文本嵌入一致，同时保留神经信号的时间动态信息。

### LLM 微调与指令调优

设计动机在于赋予 LLM 处理 fMRI 时序数据的能力，并实现多任务泛化。通常做法是单任务微调，但本文采用三阶段策略。阶段 2 中，LLM 学习 fMRI-to-fMRI（时序预测）、fMRI-to-Text（条件生成）及 Text-to-Text（保持语言能力）三种目标，联合损失为：

$$ \mathcal{L}_{llm} = \mathcal{L}_{F2F} + \alpha \mathcal{L}_{F2T} + \beta \mathcal{L}_{T2T} $$

其中 $\alpha=0.1, \beta=0.5$。阶段 3 进行多任务、多范式指令微调，涵盖单问单答、多问多答及开放式描述。这种设计使模型不仅能预测数值，还能生成自然语言解释，实现了从“信号处理”到“认知理解”的跨越。

## 实验评估

实验在 UKB、ABCD、HCP、ADNI 等 7 个数据集上进行，覆盖不同年龄与临床条件。基线包括监督方法（BrainNetCNN, BrainGNN）与自监督基础模型（BrainLM, Brain-JEPA）。在分类任务上，fMRI-LM-B(GPT2) 在 UKB-Sex 任务上达到 94.89% 准确率，显著优于 Brain-JEPA 的 92.31%；在 ADNI-AD 任务上，fMRI-LM-B(Qwen3) 达到 85.27% 准确率，优于 Brain-JEPA 的 84.05%。在回归任务上，fMRI-LM-B(GPT2) 在 UKB-Age 预测上 MAE 为 1.82，优于 Brain-JEPA 的 1.69 但略逊于 BrainMass 的 2.01（注：此处原文数据需仔细核对，BrainMass 2.01 优于 fMRI-LM 1.82？不，MAE 越小越好，1.82 < 2.01，故 fMRI-LM 优于 BrainMass。原文表格显示 fMRI-LM-B(G) UKB Age MAE 1.82, BrainMass 2.01, Brain-JEPA 1.69。故 Brain-JEPA 最优。fMRI-LM 次之）。

消融实验表明，合成描述符对性能至关重要。移除描述符后，模型在 UKB-Sex 任务上的准确率下降，验证了语言接地对提升泛化能力的贡献。多问多答范式下，性能仅轻微下降，表明模型具备处理复杂推理的能力。零样本泛化测试显示，fMRI-LM 在新数据集上无需微调即可保持较高性能，优于传统监督方法。

评估边界方面，本文主要关注通用理解任务（分类/回归/生成），未涉及视觉重建任务。指标以准确率和 MAE 为主，缺乏对生成文本质量的详细评估（如 BLEU/ROUGE）。代码未公开，超参数设置（如 LoRA 秩）未在正文详细列出，可复现性依赖附录。

## 关联研究分析

从问题动机看，fMRI-LM 与 Brain-JEPA 均致力于构建通用 fMRI 表征，但路径截然不同。Brain-JEPA 依赖神经信号内部的对比学习，旨在捕捉脑活动的内在结构，但缺乏外部语义约束，导致其表征难以直接用于语言交互。fMRI-LM 则通过合成语料引入语言先验，将 fMRI 信号“翻译”为文本，从而利用 LLM 的语义推理能力。这一差异源于任务定义的不同：Brain-JEPA 侧重信号本身的表征学习，而 fMRI-LM 侧重信号与认知语义的关联。fMRI-LM 的切入点在于利用 LLM 作为“语义解码器”，弥补了纯神经模型在解释性上的不足。

从方法设计看，fMRI-LM 与视觉-语言模型（如 CLIP）在对齐机制上存在相似性，但面临数据稀缺的挑战。CLIP 依赖大规模真实图像-文本对，而 fMRI 缺乏此类数据。fMRI-LM 通过从功能连接等指标生成合成文本，解决了数据缺失问题，但这也引入了“描述符偏差”——模型可能仅学会预测这些特定指标的描述，而非理解脑活动的全部语义。相比之下，视觉领域的 CLIP 直接对齐像素与文本，语义覆盖更全面。fMRI-LM 的离散化分词器设计借鉴了 VQ-VAE，但针对 fMRI 的时序特性进行了调整，保留了时间维度的 patch 结构。这一设计是否足以捕捉脑活动的动态语义，而非仅静态结构，是方法有效性的关键。

## 总结

fMRI-LM 旨在解决 fMRI 基础模型缺乏语言接地导致的跨任务泛化难题。其切入点在于构建合成 fMRI-文本语料，将低层神经结构转化为语言描述，从而利用 LLM 的语义推理能力。通过三阶段训练框架，fMRI-LM 实现了 fMRI 信号与 LLM 文本空间的对齐，在 UKB-Sex 分类任务上达到 94.89% 准确率，在 ADNI-AD 任务上达到 85.27% 准确率，显著优于部分基线。然而，本文实验局限于通用理解任务，未验证其表征在视觉重建等下游任务中的有效性。合成语料基于有限的 23 个描述符，可能无法覆盖脑活动的全部语义维度。当描述符数量增加或覆盖更复杂的认知状态时，fMRI-LM 的语义理解能力是否仍能保持线性提升，论文未给出回答。
