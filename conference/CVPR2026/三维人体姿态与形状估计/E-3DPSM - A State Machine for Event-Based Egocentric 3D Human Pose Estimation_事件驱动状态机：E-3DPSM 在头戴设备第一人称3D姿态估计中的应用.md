# CVPR2026最新论文 ｜E-3DPSM: A State Machine for Event-Based Egocentric 3D Human Pose Estimation ｜事件驱动状态机：E-3DPSM 在头戴设备第一人称3D姿态估计中的应用

研究机构：德国萨尔大学

作者：Mayur Deshmukh、Hiroyasu Akada、Helge Rhodin 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.08543)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.08543)

> 头戴设备（HMD）第一人称3D人体姿态估计旨在从佩戴者视角的视觉流中恢复全身关节坐标，以支持实时虚拟化身控制与远程临场感。现有基于RGB的方法受限于低光模糊与高带宽需求，而早期事件相机方法虽具备高时间分辨率，却因架构未适配异步流特性导致严重的时序抖动与自遮挡误差。本文提出E-3DPSM，将姿态估计重构为连续状态演化过程，通过状态空间模型（State-Space Model, SSM）与增量姿态（Delta Pose）回归融合，在保持80Hz实时性的同时显著降低误差。该架构在事件流场景下验证了SSM替代Transformer的可行性，但其对绝对坐标回归的依赖及单一模态局限仍存疑。

## 研究背景

头戴设备视角下，人体始终位于画面中心且尺度一致，这降低了背景变异性，但也引入了频繁的自遮挡与快速头部运动。传统RGB帧处理在此场景下面临双重困境：低光环境下的传感器噪声与运动模糊，以及高分辨率视频流对可穿戴设备带宽与算力的严苛要求。事件相机（Event Camera）作为替代方案，仅在像素亮度变化超过阈值时异步记录事件，提供毫秒级时间分辨率与高动态范围，天然适配快速运动捕捉。然而，事件流是稀疏、异步且基于变化的，这与固定帧率的RGB视频存在本质差异，要求神经网络架构进行根本性重构。

主流的第一人称姿态估计方法多沿用RGB范式，依赖2D热力图中间表示与短时帧缓冲传播时序信息。EventEgo3D作为首个头戴事件相机方法，虽实现了实时性，但其架构直接移植RGB组件，未充分利用事件流的异步连续特性，导致在自遮挡场景下出现显著抖动与漂移。此外，2D热力图引入量化误差，测试时分割掩码预测进一步增加不确定性。本文切入点在于重新定义问题：将姿态估计视为由异步事件驱动的连续状态演化过程，而非离散帧间的独立回归，从而从架构底层解决时序一致性与实时性的矛盾。

## 核心方法

### 方法参照系

本文问题属于单目3D姿态估计，但输入为异步事件流而非RGB帧。通用流程通常包含2D关键点检测与2D-to-3D提升，但本文摒弃2D中间表示，直接通过时空编码回归3D坐标。关键差异在于：标准SSM处理固定长度序列，而本文需处理变长、稀疏的局部归一化事件表面（Locally Normalised Event Surface, LNES）帧，且需显式建模事件间的相对变化而非绝对状态。

### 时空姿态编码器

设计动机在于解决事件流异步性导致的长程依赖捕捉不足。传统方法仅使用前一帧特征，无法聚合长时间上下文。本文引入S5层（一种针对事件流优化的SSM变体）于编码器第2、4阶段，实现双向时序建模。SSM通过线性递归更新隐状态 $Z_t$，其卷积形式支持并行训练，递归形式支持因果推理：

$$ Z_t = A Z_{t-1} + B x_t, \quad y_t = C Z_t $$

其中 $x_t$ 为LNES帧特征，$A, B, C$ 为可学习矩阵。该设计使模型在推理时仅需携带隐状态 $Z_t$，无需缓存历史帧，从而在80Hz实时运行下保持对长程运动模式的记忆，有效抑制因短时传播导致的漂移。

### 增量姿态回归与可学习融合

设计动机在于事件流编码变化而非绝对强度，直接回归绝对3D坐标在稀疏事件下易产生噪声。本文引入增量姿态回归器，预测当前帧与前一帧的相对位移 $\Delta P_t$，并将其与直接预测的全局姿态 $P^D_t$ 融合。融合模块采用可学习卡尔曼滤波结构，动态加权增量更新与全局锚点：

$$ P_t = \alpha_t (P_{t-1} + \Delta P_t) + (1 - \alpha_t) P^D_t $$

其中 $\alpha_t$ 为可学习权重，根据事件稀疏度与噪声水平自适应调整。该机制在事件密集时信任增量更新以捕捉快速运动，在事件稀疏时依赖全局预测以维持稳定性，避免了简单累加导致的误差累积，显著提升了自遮挡场景下的轨迹平滑度。

## 实验评估

实验在EE3D-R（实验室）与EE3D-W（野外）两个基准上进行，对比基线包括EventEgo3D、EventEgo3D++及RGB方法EgoPoseFormer。基线覆盖事件相机与RGB两条路线，但缺失其他SSM架构（如SasMamba）的直接对比，限制了跨架构效率-精度权衡的全面评估。

| 方法 | EE3D-R MPJPE (mm) | EE3D-R PA-MPJPE (mm) | EE3D-R $e_{smooth}$ (mm) | EE3D-W MPJPE (mm) |
| :--- | :--- | :--- | :--- | :--- |
| EventEgo3D++ | 103.28 | 77.06 | 22.93 | 172.43 |
| EgoPoseFormer | 151.66 | 96.99 | 66.50 | 220.40 |
| Ours (Causal) | 84.45 | 62.64 | 8.40 | 158.86 |
| Ours (Non-Causal) | 81.32 | 60.21 | 6.65 | 155.82 |

因果模式（Causal）下，E-3DPSM在EE3D-R上MPJPE较EventEgo3D++降低18.2%，$e_{smooth}$降低2.7倍；在EE3D-W上MPJPE降低8.0%。非因果模式精度略优，但因果模式已满足实时部署需求，且性能差距较小，表明双向SSM训练带来的泛化能力较强。

| 消融组件 | MPJPE (mm) | PA-MPJPE (mm) | $e_{smooth}$ (mm) |
| :--- | :--- | :--- | :--- |
| w/o SSM Blocks | 118.53 | 87.48 | 16.94 |
| w/o Fusion Module | 141.22 | 84.17 | 10.14 |
| Direct Pose Only | 91.26 | 65.43 | 17.22 |
| Ours (full model) | 84.45 | 62.64 | 8.40 |

消融显示，移除SSM块导致MPJPE上升34.08mm，证实长程时序建模对事件流至关重要；移除融合模块导致MPJPE上升56.77mm，表明可学习融合对抑制漂移的核心作用。仅使用直接姿态回归时，$e_{smooth}$高达17.22mm，远高于完整模型的8.40mm，验证了增量回归对平滑度的贡献。

评估指标包含MPJPE、PA-MPJPE与$e_{smooth}$，覆盖精度与平滑度，但缺乏对计算效率（FLOPs、延迟）的定量报告，仅提及80Hz实时性。代码与模型已开源，训练使用4块A40 GPU耗时34小时，测试在单块A40上进行，超参数（学习率、批次大小）已披露，具备可复现性。

## 关联研究分析

从方法设计看，E-3DPSM与SasMamba同属SSM路线，但SasMamba针对RGB视频采用固定空间时间扫描策略以保留骨架拓扑，而E-3DPSM针对事件流采用双向S5层处理异步LNES帧。差异根源在于输入模态特性：RGB帧具有固定空间分辨率与时间步长，扫描策略有效；事件流稀疏且异步，固定扫描可能丢失关键变化，故需双向建模以聚合长程上下文。E-3DPSM未采用SasMamba的扫描策略，是否因事件流的空间稀疏性使得拓扑先验失效，论文未给出明确解释。

从问题动机看，E-3DPSM与DreamPose3D均旨在解决单目深度歧义，但DreamPose3D采用扩散模型生成多假设分布，E-3DPSM采用确定性回归与增量融合。差异根源在于任务约束：DreamPose3D面向静态帧或低实时性场景，可容忍多步去噪延迟；E-3DPSM面向头戴设备实时应用，80Hz延迟预算禁止生成式采样。E-3DPSM通过增量回归与卡尔曼融合在确定性框架内实现平滑，但未提供不确定性量化，其在极端遮挡下的鲁棒性是否优于生成式方法，缺乏直接对比。

## 总结

E-3DPSM解决的核心矛盾是事件相机异步流下3D姿态估计的实时性与时序稳定性冲突。现有方法因架构未适配异步特性导致抖动，本文通过SSM连续状态演化与增量-全局可学习融合，在80Hz实时运行下将EE3D-R MPJPE降至84.45mm，$e_{smooth}$降至8.40mm。其边界在于仅验证于事件相机单一模态，且依赖绝对坐标回归，未探索混合模态或不确定性量化。当事件流极度稀疏或存在长时间无事件间隔时，增量回归的漂移抑制能力是否仍优于全局预测，论文未给出回答。
