# CVPR2026最新论文 ｜GaussianFluent: Gaussian Simulation for Dynamic Scenes with Mixed Materials ｜高斯流体：多材料动态场景的高斯仿真

研究机构：北京大学

作者：Bei Huang、Yixin Chen、Ruijie Lu 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.09265)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.09265)

> 3D高斯泼溅（3D Gaussian Splatting, 3DGS）在静态重建中确立了实时渲染范式，但将其扩展至物理仿真时，表面化表示导致内部结构缺失，且现有方法局限于弹性变形，无法处理脆性断裂。本文切入点在于解决GS内部纹理空洞与断裂动力学不连续两大瓶颈，通过生成式内部填充与优化后的连续损伤材料点法（CD-MPM）实现多材料断裂仿真。该框架在视觉保真度上显著优于基线，但其依赖人工参数设定与单一指标评估，限制了物理准确性的量化验证。

## 研究背景

3DGS将场景离散化为各向异性高斯基元，其粒子特性天然适配材料点法（MPM）的拉格朗日网格。然而，标准3DGS仅拟合外部表面，内部区域为空，导致应力、惯性等物理量无法定义。当物体发生断裂时，新暴露的内部表面缺乏纹理，使得仿真结果在视觉上不可信。同时，MPM中的连续损伤力学（CDM）需要连续的回映射（return-mapping）机制来更新损伤变量，而现有基于点云的断裂方法缺乏此机制，导致物理动力学不连续且计算效率低下。

现有GS物理仿真路线主要沿两条路径演进：一是基于变形场的预测，如PhysGaussian，通过关联物理属性实现弹性仿真，但无法处理拓扑变化；二是基于生成先验的参数估计，如OmniPhysGS，自动化估计杨氏模量等参数，但仍局限于弹性范围。这些方法的共同瓶颈在于缺乏对脆性断裂的建模能力，且忽视内部纹理的一致性。本文针对这一空白，提出GaussianFluent，通过生成模型填充内部结构，并引入优化的CD-MPM框架，实现从弹性到脆性断裂及流体行为的统一仿真。

## 核心方法

### 方法参照系

本文问题属于物理仿真与神经渲染的交叉领域，最接近的通用流程是“表示-仿真-渲染”管线。标准流程中，3DGS作为表示，MPM作为仿真引擎，光栅化作为渲染器。本文的关键差异在于：标准流程假设物体为实心且材料均匀，而本文需处理内部空洞、多材料混合及断裂导致的拓扑变化，这要求表示层具备体积完整性，仿真层具备损伤演化能力。

### 内部纹理合成

内部纹理合成解决GS内部空洞问题，确保断裂时新表面具有真实纹理。通常做法是直接复制外部颜色或使用2D修复，但前者导致模糊，后者缺乏多视角一致性。本文采用两阶段生成式策略：首先沿X轴切片，利用MVInpainter进行单视角修复，初始化高斯球谐函数（SH）系数；随后沿X、Y、Z轴迭代低强度修复，通过SD-XL注入细节并优化SH系数。该策略通过正交视图的交叉依赖驱动三轴一致性，避免传统监督蒸馏（SDS）导致的过饱和与模糊。

$$ \mathbf{sh}[0]_i = C_0 \cdot \mathbf{c}_i $$

其中 $C_0 = 1/(2\sqrt{\pi})$，$\mathbf{c}_i$ 为修复图像中对应像素的颜色。该公式将2D修复结果映射至高斯基元的零阶SH系数，实现纹理到3D表示的转换。

### 优化CD-MPM与混合材料

优化CD-MPM解决断裂动力学不连续问题。标准CD-MPM在回映射时，当试验状态 $(p_{tr}, q_{tr})$ 超出屈服面 $y=0$ 时，需投影至屈服面。原方法使用固定中心点 $p_c$，在边界 $p=p_0$ 处产生跳跃，导致数值不稳定。本文引入动态点 $p'_c$，平滑适应 $(p, q)$ 变化，确保映射连续。

$$ p'_c = \frac{p_c + \frac{p_{tr} - p_c}{k}}{1 + \frac{1}{k}} $$

其中 $k=2$ 为平滑参数。该公式通过动态调整投影中心，消除边界处的不连续性，使损伤变量 $\alpha$ 的更新平滑，从而支持脆性断裂的稳定仿真。对于混合材料，本文通过分割赋予不同区域不同的 $\beta$ 值（如西瓜籽、果肉、瓜皮），实现差异化断裂行为。

## 实验评估

实验在内部纹理填充与动态场景仿真两个任务上进行，基线包括PhysGaussian、2D Inpainting及OmniPhysGS。内部填充任务使用CLIP Score与用户研究评估，动态仿真任务同样使用CLIP Score与用户研究。

| 方法 | CLIP Score_↑_ | 用户研究_↑_ |
| :--- | :--- | :--- |
| PhysGaussian | 22.3 | 3.57% (3/84) |
| 2D Inpainting | 30.1 | 25.00% (21/84) |
| Ours | **35.4** | **71.43% (60/84)** |

| 方法 | CLIP Score_↑_ | 用户研究_↑_ |
| :--- | :--- | :--- |
| PhysGaussian | 12.2 | 3.84% (1/26) |
| OmniPhysGS | 13.1 | 7.69% (2/26) |
| Ours | **22.7** | **88.46% (23/26)** |

内部填充中，本文方法CLIP Score达35.4，显著高于PhysGaussian的22.3，用户偏好率达71.43%，表明生成式填充在语义一致性上优于直接复制。动态仿真中，本文方法CLIP Score为22.7，OmniPhysGS仅为13.1，用户偏好率88.46%，证明优化CD-MPM在脆性断裂仿真上的优势。

消融实验显示，混合材料建模（不同 $\beta$ 值）比单一 $\beta$ 值产生更真实的断裂模式，如西瓜籽与果肉的分离。然而，论文未提供内部纹理对物理仿真稳定性的消融，即生成纹理是否影响MPM计算。

评估边界在于：仅使用CLIP Score与用户研究，缺乏几何精度（如Chamfer Distance）或物理量（如应力误差）的量化指标。代码未公开，超参数（如 $\beta$ 值范围）依赖人工设定，可复现性受限。

## 关联研究分析

从问题动机看，本文与FruitNinja均关注内部纹理，但FruitNinja依赖自采集数据集微调扩散模型，成本高且泛化性差；本文采用预训练生成模型（MVInpainter, SD-XL），无需额外训练数据，但可能引入非物理纹理。这一差异源于任务特性：FruitNinja聚焦静态水果，本文需支持动态断裂，对纹理一致性的要求更高，但生成模型的随机性可能影响物理仿真的稳定性。

从方法设计看，本文与PhysGaussian同属GS-MPM框架，但PhysGaussian假设材料均匀且仅支持弹性变形；本文引入CD-MPM与混合材料，支持脆性断裂。关键差异在于回映射机制：PhysGaussian未处理损伤演化，本文通过动态点 $p'_c$ 确保连续性。这一改进解决了PhysGaussian在断裂场景下的数值不稳定问题，但依赖人工设定 $\beta$ 值，缺乏自动化参数估计，限制了其在复杂场景中的泛化能力。

## 总结

GaussianFluent旨在解决3DGS在动态场景仿真中内部结构缺失与脆性断裂建模不足的核心矛盾。现有方法如PhysGaussian局限于弹性变形且内部空洞，本文通过生成式内部填充与优化CD-MPM，实现了多材料断裂仿真。实验显示，内部填充CLIP Score达35.4，动态仿真CLIP Score达22.7，显著优于基线。然而，论文依赖人工设定材料参数，且缺乏物理量量化指标，限制了物理准确性的验证。当内部纹理由生成模型合成时，其随机性是否会导致MPM仿真中的数值不稳定，论文未给出回答。
