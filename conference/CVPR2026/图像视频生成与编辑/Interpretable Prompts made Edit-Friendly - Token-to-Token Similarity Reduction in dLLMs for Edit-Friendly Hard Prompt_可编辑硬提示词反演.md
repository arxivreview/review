# CVPR2026最新论文 ｜Interpretable Prompts made Edit-Friendly: Token-to-Token Similarity Reduction in dLLMs for Edit-Friendly Hard Prompt Inversion ｜可编辑硬提示词反演

作者：Naresh Kumar Devulapally、Shruti Agarwal、Vishal Asnani 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_2a448c2d3089)

> 硬提示词反演旨在从参考图像逆向推导文本提示词，使文生图模型能复现该图像。现有方法生成的提示词虽可读，但对下游 token 级编辑极度敏感，微小改动即导致图像语义崩塌。本文通过引入离散扩散语言模型（dLLM）与 token 相似度正则项，构建了兼顾对齐度与可编辑性的反演框架。该方法在效率上较基线提升约 10 倍，但其在长序列依赖建模上的精确性边界尚存疑。

## 研究背景

当用户尝试通过修改提示词中的单个属性词（如将“马”改为“斑马”）来微调生成结果时，若提示词是由图像反演得到的，往往面临语义整体漂移的困境。这一现象源于反演提示词中 token 间的强耦合：在自回归解码或梯度优化过程中，为最大化图像-文本对齐度，模型倾向于生成语义纠缠的短语，导致局部 token 修改引发全局注意力重分配。解决此问题需引入离散扩散语言模型（dLLM），它通过并行去噪生成全局一致的文本序列，为解耦 token 依赖提供了结构基础。

硬提示词反演领域长期存在“可读性”与“鲁棒性”的矛盾。主流无梯度方法如 VGD 和 PEZ 虽能生成符合 CLIP 相似度的提示词，但缺乏对下游编辑行为的显式约束。VGD 采用自回归 Beam Search，虽保证局部流畅，但无法感知全局 token 交互；PEZ 依赖梯度下降，计算成本高且易陷入局部最优。现有评估体系多聚焦于重建保真度（如 CLIP-Score），忽视了提示词作为“可编辑手柄”的功能性。本文切入点在于将“可编辑性”形式化为优化目标，通过量化 token 间的预测分布相似度，直接惩罚耦合严重的提示词结构。

## 核心方法

### 离散扩散语言模型先验

本文解决的核心问题与标准无梯度反演流程的关键差异在于解码器的选择。标准流程（如 VGD）使用自回归语言模型（AR-LLM）进行 Beam Search，逐 token 生成，导致长序列依赖建模效率低且易产生局部最优。本文采用 dLLM 作为语言先验 $p_{\text{LLM}}(T)$，其通过迭代并行去噪生成文本：

$$ p_{\text{dLLM}}(x_T, \dots, x_0) = \pi_{\text{prior}}(x_T) \prod_{t=T-1}^{0} p(x_t | x_{t+1}) $$

该公式表明，dLLM 从完全噪声序列 $x_T$ 出发，在 $T \ll N$ 步内并行更新所有位置，相比 AR 模型的 $O(N)$ 步长，显著降低了计算复杂度并增强了全局一致性。

### CLIP 引导与 Token 相似度正则

在 dLLM 先验基础上，本文引入两项引导机制以优化对齐度与可编辑性。首先，通过 Feynman-Kac 引导实现 CLIP 对齐，其势函数定义为：

$$ G_t = \exp \left( \lambda_{\text{CLIP}} [ r_{\text{CLIP}}(\tilde{T}_t; I) - r_{\text{CLIP}}(\tilde{T}_{t+1}; I) ] \right) $$

此设计动机在于，传统方法仅优化最终对齐度，而该望远镜形式（telescoping form）确保去噪轨迹中每一步都向高对齐度方向偏置，避免中途偏离。其次，针对可编辑性，本文提出 Token-Token 相似度编辑奖励。在去噪步 $t$，计算位置 $i$ 和 $j$ 的预测分布 $\hat{p}^{(t)}_i$ 和 $\hat{p}^{(t)}_j$ 的 Gram 矩阵 $S^{(t)}$，其非对角元素 $S^{(t)}_{ij}$ 反映 token 耦合度。编辑奖励定义为：

$$ r^{(t)}_{\text{edit}} = 1 - (\mu^{(t)}_{\text{off}} + \sigma^{(t)}_{\text{off}}) $$

其中 $\mu^{(t)}_{\text{off}}$ 和 $\sigma^{(t)}_{\text{off}}$ 分别为非对角元素的均值和方差。该设计动机在于，高耦合度意味着修改一个 token 会扰动其他 token 的预测分布，导致图像语义漂移；通过最小化耦合度，确保 token 解耦，使局部编辑仅影响局部语义。

## 实验评估

实验在 MS-COCO、Flickr8K 和 JourneyDB 三个数据集上进行，基线包括 VGD、PEZ、BLIP-2 和 CLIP-Interrogator。本文方法在 32 token 预算下，MS-COCO 的 CLIP-Image 相似度（CL-I）达到 0.71，优于 VGD 的 0.67 和 PEZ 的 0.69；困惑度（PPL）降至 33.16，显著低于 VGD 的 37.78 和 PEZ 的 4946.56。

| 方法 | PPL (↓) | CL-I (↑) | TIFA (↑) | Time (s) (↓) |
|---|---|---|---|---|
| VGD [13] | 37.78 | 0.68 | 0.74 | 56.0 |
| PEZ [35] | 4946.56 | 0.69 | 0.62 | 532.0 |
| Ours | 33.16 | 0.71 | 0.89 | 5.60 |

消融实验显示，CLIP 引导对 TIFA 分数提升贡献最大（0.74 至 0.89），而 Token 相似度正则主要降低 PPL 并提升编辑鲁棒性。值得注意的是，Sim. Guide 变体在 TIFA 上达到 0.92，但 PPL 升至 45.93，表明过度解耦可能牺牲语言流畅性。

评估边界方面，本文未报告置信区间，且 TIFA 分数提升可能部分源于 dLLM 生成的更短提示词减少了歧义，而非纯粹的编辑鲁棒性增强。代码未公开，超参数 $\lambda_{\text{CLIP}}$ 和 $\lambda_{\text{edit}}$ 的敏感性分析缺失，限制了可复现性。

## 关联研究分析

从问题动机看，本文与 GenPilot 等提示词优化方法存在根本差异。GenPilot 聚焦于正向优化提示词以提升生成质量，而本文聚焦于逆向反演提示词以支持下游编辑。GenPilot 依赖多智能体搜索，计算成本高且无法保证 token 解耦；本文通过 dLLM 并行去噪和相似度正则，在效率上实现约 10 倍提升，但牺牲了长序列依赖的精确性。这一差异源于任务特性：正向优化需全局语义一致性，而逆向反演需局部可编辑性。

从方法设计看，本文与 VGD 同属无梯度反演路线，但解码器选择不同。VGD 使用 AR-LLM，依赖 Beam Search 的局部最优性；本文使用 dLLM，通过并行去噪实现全局一致性。VGD 的 PPL 为 37.78，本文降至 33.16，表明 dLLM 在语言流畅性上略优。然而，VGD 在 CL-I 上达到 0.68，本文仅 0.71，差距微小，说明 dLLM 并未显著提升重建保真度，其优势主要体现在可编辑性和效率上。

## 总结

本文核心矛盾在于硬提示词反演中“可读性”与“可编辑性”的冲突。现有方法如 VGD 和 PEZ 虽能生成可读提示词，但 token 耦合导致下游编辑时语义漂移。本文通过 dLLM 并行去噪和 Token 相似度正则，将可编辑性形式化为优化目标，实现了约 10 倍的效率提升和 TIFA 分数从 0.74 到 0.89 的显著改善。然而，实验显示 Sim. Guide 变体在 TIFA 上达到 0.92 但 PPL 升至 45.93，表明过度解耦可能牺牲语言流畅性。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
