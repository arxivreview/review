# CVPR2026最新论文 ｜Selectively Extracting and Injecting Visual Attributes into Text-to-Image Models ｜单图属性级概念解耦与注入

作者：Seunghwan Choi、Jooyeol Yun、Youngdo Lee 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_7a45649c1c05)

> 文本到图像生成模型在复杂设计场景中面临“组合性灾难”，难以仅凭文本精确复现参考图像中的特定视觉属性。现有方法或依赖大量样本训练专用编码器，或受限于架构特定性，无法在单图条件下实现属性的精准解耦。本文提出一种基于文本反演（Textual Inversion, TI）的改进框架，通过引入蒸馏嵌入与残差嵌入，在冻结模型参数的前提下，从单张参考图中提取目标属性并注入生成流程。该方法在概念相似度与排他性上优于现有基线，但其对视觉语言模型（Vision-Language Model, VLM）生成提示词的依赖及评估指标的局限性，限制了其在开放域中的鲁棒性验证。

## 研究背景

当设计师试图将参考图像中的特定材质或光影效果迁移至新场景时，纯文本提示词往往因语义模糊而导致属性泄漏或遗漏。这一困境源于文本编码器（如 CLIP）的因果掩码机制，使得上下文信息在编码过程中发生混合，导致模型难以区分目标属性与非目标背景。为解决此问题，文本反演（Textual Inversion, TI）通过优化文本 Token 嵌入来映射图像特征，但其原始形式强制嵌入吸收图像中的所有属性，导致非目标特征（如布局、背景）被错误绑定。

尽管后续研究如 ControlNet 或 StyleShot 引入了视觉引导，但它们通常仅覆盖形状或风格，且需要数千个训练样本及预处理步骤。属性级概念学习旨在突破这一限制，要求从单张参考图中解耦并提取单一视觉属性。然而，现有方法如 TokenVerse 依赖特定架构的调制参数优化，U-VAP 则需依赖生成样本进行训练，均未能实现无数据集、无预处理的通用属性提取。本文针对这一空白，探索如何在单图条件下，通过结构化嵌入设计实现属性的精准隔离。

## 核心方法

### 方法参照系：文本反演的属性纠缠缺陷

本文方法建立在文本反演（TI）的基础之上。TI 的核心流程是冻结扩散模型参数，优化一个特殊的 Token 嵌入 $e_*$，使得包含该 Token 的提示词能够重建参考图像 $x_0$。标准 TI 的训练损失为：

$$
e_* = \arg\min_e \mathbb{E}_{\mathbf{x}_0, y, \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I}), t} \|x_{\theta}(\mathbf{x}_t, t, \tau(y)) - \mathbf{x}_0\|_2^2
$$

其中 $y$ 通常为简单提示词如 "A [*]"。该公式的物理含义是迫使 $e_*$ 编码 $x_0$ 的所有视觉信息以最小化去噪误差。然而，在属性级概念学习中，这种“全量吸收”机制导致 $e_*$ 不可避免地包含非目标属性，造成概念纠缠。本文的关键差异在于，需设计机制使 $e_*$ 仅编码目标概念 $c$，而排除其他属性。

### 蒸馏嵌入：基于注意力机制的特征隔离

为解决非目标属性泄漏，本文首先利用 VLM 生成包含非目标属性描述的自定义训练提示词 $y_{custom}$，迫使 $e_*$ 聚焦于剩余的目标概念。然而，文本长度限制导致无法穷尽所有非目标属性。为此，本文提出“蒸馏嵌入”（Distilled Embedding）。其设计动机在于利用 Transformer 的注意力机制，通过语义关联词提取特定类别特征。

具体而言，将短语 "[*] [category]" 输入文本编码器，其中 [category] 为目标概念的粗粒度类别词（如 "color"）。Transformer 内部，[*] 与 [category] 发生注意力交互，[category] 的输出嵌入 $h_{[category]\leftarrow *}$ 即被“蒸馏”出仅与目标类别相关的特征。该嵌入替代原始 $e_*$ 参与生成，从而在结构上隔离了目标概念。

### 残差嵌入：优化稳定性的动态平衡

仅使用蒸馏嵌入会导致优化不稳定，因为损失函数仍强制 $h_{[category]\leftarrow *}$ 重建 $y_{custom}$ 中未描述的所有属性，这与蒸馏嵌入的隔离特性产生冲突。为缓解这一冲突，本文引入“残差嵌入”（Residual Embedding）$h_{residual}$，用于捕获除目标概念外的所有剩余属性。

最终优化目标由重建损失与余弦相似度损失组成：

$$
\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{recon}} + \lambda \mathcal{L}_{\text{cosine}}
$$

其中 $\mathcal{L}_{\text{cosine}}$ 定义为：

$$
\mathcal{L}_{\text { c osine}} = \max \left (0, \frac {\mathbf \mathcal {h}_{\text {residual}} \cdot \mathbf {h}_{\text {[category]} \leftarrow *}}{\|\mathbf {h}_{\text {residual}}\| \, \|\mathbf {h}_{\text {[category]} \leftarrow *}\|}\right )
$$

该公式的物理含义是惩罚残差嵌入与蒸馏嵌入的相似性，强制 $h_{residual}$ 远离目标概念，从而稳定训练过程，确保目标属性被精准提取而非被残差吸收。

## 实验评估

实验在自建数据集上进行，包含 30 张参考图像和 60 个评估提示词，涵盖形状、材质、颜色、姿态、相机角度和风格六类属性。基线方法包括 TokenVerse、U-VAP、ProSpect、OmniGen2 和标准 TI。评估指标为概念相似度（Concept Similarity, CS）和概念排他性（Concept Exclusiveness, CE）。

| 方法 | Concept Sim. (%) | Concept Excl. (%) | Prompt Fidelity |
| :--- | :---: | :---: | :---: |
| **Ours** | **84.0** | **40.0** | **0.815** |
| TokenVerse | 84.0 | 40.0 | 0.573 |
| U-VAP | 54.0 | 75.9 | 0.207 |
| ProSpect | 93.7 | 25.2 | 0.820 |
| OmniGen2 | 65.3 | 68.0 | 0.613 |
| TI | 69.2 | 56.0 | 0.604 |

*注：表格数据逐字取自论文实验数据区。*

主结果显示，本文方法在 CS 上达到 84.0%，与 TokenVerse 持平，显著高于 U-VAP (54.0%) 和 TI (69.2%)。在 CE 上，本文得分为 40.0%，虽低于 U-VAP (75.9%)，但 U-VAP 的 CS 极低，表明其通过忽略目标概念来换取排他性。ProSpect 虽 CS 高达 93.7%，但 CE 仅为 25.2%，说明其严重泄漏非目标属性。本文在 Prompt Fidelity 上得分为 0.815，优于 TokenVerse (0.573) 和 U-VAP (0.207)，与 ProSpect (0.820) 相当，表明其在保持提示词忠实度方面具有优势。

消融实验表明，移除残差嵌入会导致训练不稳定，仅使用自定义提示词则无法完全解耦非目标属性。评估边界方面，CLIP 指标在评估“概念排他性”时可能存在语义模糊性偏差，且论文未提供代码开源链接，复现性依赖对 VLM 提示词工程的精确复现。

## 关联研究分析

从方法设计看，本文与 TokenVerse 均旨在提取视觉属性，但 TokenVerse 优化的是扩散模型中的调制参数，依赖 SD3/FLUX 特定架构，缺乏模型无关性。本文通过优化文本 Token 嵌入，保持了与标准 TI 相同的接口兼容性，更具通用性。然而，TokenVerse 在特定架构上的优化可能更直接地干预生成过程，而本文依赖文本编码器的注意力机制，若目标属性与类别词语义距离过远，蒸馏效果可能下降，这一假设未在论文中验证。

从问题动机看，ProSpect 通过时间步特定嵌入解耦布局、内容、风格，旨在实现多属性同时控制。本文则聚焦于单属性提取，通过残差嵌入处理剩余属性。ProSpect 的高 CS 低 CE 表明其解耦机制在排他性上存在缺陷，可能源于时间步嵌入的纠缠。本文的残差嵌入机制是否能在多属性同时提取场景下保持稳定性，论文未给出回答。

## 总结

本文针对单图属性级概念解耦难题，提出了一种结合蒸馏嵌入与残差嵌入的文本反演改进方法。通过利用 Transformer 注意力机制隔离目标特征，并引入余弦相似度损失稳定优化，该方法在概念相似度与排他性之间取得了优于现有基线的平衡。实验显示，本文方法在概念相似度上达到 84.0%，显著优于 U-VAP 和 TI，且在提示词忠实度上表现优异。然而，该方法依赖 VLM 生成自定义提示词，其鲁棒性受限于 VLM 的描述能力；同时，CLIP 指标在评估细粒度属性排他性时的有效性尚存争议。当目标属性与类别词在语义空间中距离较远时，蒸馏嵌入的注意力隔离机制是否依然有效，论文未给出回答。
