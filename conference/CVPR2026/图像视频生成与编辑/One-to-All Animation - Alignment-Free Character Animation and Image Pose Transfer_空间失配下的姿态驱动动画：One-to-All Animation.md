# CVPR2026最新论文 ｜One-to-All Animation: Alignment-Free Character Animation and Image Pose Transfer ｜空间失配下的姿态驱动动画：One-to-All Animation

研究机构：中国科学技术大学、中国科学院

作者：Shijun Shi、Jing Xu、Zhihang Li 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.22940)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.22940)

> 姿态驱动人像动画旨在从单张参考图与驱动视频生成时序连贯的动态视频，其核心难点在于参考图与驱动视频间的空间布局与面部几何往往存在显著差异。现有方法依赖严格的像素级对齐与姿态重定向，一旦输入失配即导致身份丢失或外观扭曲。本文提出 One-to-All Animation，通过将训练重构为自监督外补任务，解耦身份与骨架结构，实现了对任意空间布局参考图的鲁棒动画生成。该方法在失配场景下显著优于基线，但在标准对齐场景下的性能上限及长时程生成的误差累积机制仍需进一步验证。

## 研究背景

姿态驱动动画的生成质量高度依赖于参考图像与驱动信号的空间一致性。传统方法假设两者在相机距离、身体比例及骨架对齐上完全匹配，这种假设在真实场景中极易被打破。当参考图为半身特写而驱动视频为全身舞蹈时，模型无法正确映射身体部件，导致生成结果出现肢体扭曲或身份混淆。为应对这一挑战，潜在扩散模型（Latent Diffusion Models, LDM）结合扩散 Transformer（Diffusion Transformer, DiT）架构成为主流范式，其在低维潜空间执行去噪过程，提升了计算效率与长程依赖建模能力。然而，DiT 架构虽解决了生成稳定性问题，却未从根本上解决输入失配带来的身份漂移。

现有主流路线分为两类：一类依赖显式骨架控制，通过 ControlNet 等模块注入姿态信号，但受限于骨架估计的精度，在复杂动作下易产生抖动；另一类采用隐式特征泛化，通过大规模预训练提升鲁棒性，但仍需依赖精确的姿态重定向来维持身份一致性。当重定向失败时，生成结果会过度拟合驱动骨架，导致面部特征被驱动视频覆盖。本文的切入点在于质疑“训练-测试分布一致”的常规假设，提出直接训练模型处理失配输入，而非在推理阶段强行对齐。

## 核心方法

### 方法参照系

姿态驱动动画的标准流程通常包含姿态提取、特征注入与去噪生成三个环节。本文的关键差异在于训练阶段的数据构造方式：不再使用自然对齐的参考-驱动对，而是通过人为制造空间失配来增强模型的泛化能力，从而摆脱对推理时严格对齐的依赖。

### 自监督外补训练与参考提取器

传统方法在训练时使用自重建策略，即参考图与驱动视频天然对齐，导致模型无法处理尺度或布局差异。本文引入自监督外补（Outpainting）训练，通过面部中心随机掩码模拟空间失配，迫使模型学习从部分可见的参考图中“幻觉”出缺失区域。为从严重遮挡的参考图中提取可靠身份特征，设计了参考提取器（Reference Extractor），其核心是混合参考融合注意力（Hybrid Reference Fusion Attention, HRFA）。HRFA 在 DiT 块中引入新的交叉注意力层，参考特征 $r$ 与视频潜变量 $h$ 的交互公式为：

$$
\text{CrossAttn}(h, r) = \text{Softmax}\left(\frac{(h W_q^{ref})(r W_k^{ref})^T}{\sqrt{d}}\right) r W_v^{ref}
$$

该公式通过独立的投影矩阵 $W_k^{ref}, W_v^{ref}$ 处理参考特征，并在计算查询向量时对视频潜变量应用 $f=0$ 的 3D 旋转位置编码（RoPE），消除了参考图与视频帧之间的绝对位置依赖，使模型能同时适用于图像与视频生成任务，解决了传统 CLIP 编码器缺乏细粒度身份细节及 I2V 骨干“复制粘贴”性质无法补全大遮挡区域的问题。

### 身份鲁棒姿态控制与令牌替换

面部区域增强（Face Region Enhancement）旨在打破身份与骨架的耦合。训练时，随机采样一个姿态并缩放至驱动姿态尺度，计算其面部关键点与驱动姿态的结构差异，并将该差异应用于驱动姿态，人为制造面部骨架不一致。这一设计迫使模型从参考图而非驱动姿态中学习面部外观，解决了姿态重定向不准导致的身份过拟合问题。参考引导姿态控制（Reference-guided Pose Control）则通过拼接参考姿态与驱动姿态序列，利用自注意力捕捉结构依赖，稳定训练过程。对于长视频生成，令牌替换（Token Replace）策略将前一段末尾的 5 帧编码为 2 个潜变量作为上下文令牌，在每个去噪步骤中替换当前段初始潜变量的前 2 帧，确保段间过渡的时序连贯性，避免了传统渐进潜变量融合方法在重叠区域的一致性失效。

## 实验评估

实验在 TikTok、Cartoon 及 DeepFashion 数据集上进行，基线涵盖 MimicMotion、StableAnimator、Animate-X 等早期方法，以及 UniAnimate-DiT、Wan-Animate 等基于大规模预训练的 DiT 模型。在 TikTok 数据集上，One-to-All-14B 的 FVD 为 297.94，显著优于 Wan-Animate 的 485.92 与 UniAnimate-DiT 的 358.42，表明其在空间失配场景下具有更强的鲁棒性。在 DeepFashion 数据集上，One-to-All-1.3B 的 FID 为 6.85，优于 CFLD 的 7.11 与 MCLD 的 8.96，验证了其在高分辨率下的细节保留能力。

| 数据集 | 模型 | FVD ↓ | FID ↓ |
| :--- | :--- | :--- | :--- |
| TikTok | Wan-Animate | 485.92 | 58.94 |
| TikTok | UniAnimate-DiT | 358.42 | 55.32 |
| TikTok | One-to-All-14B | 297.94 | 50.49 |
| DeepFashion (512x352) | CFLD | - | 7.11 |
| DeepFashion (512x352) | MCLD | - | 8.96 |
| DeepFashion (512x352) | One-to-All-1.3B | - | 6.85 |

消融实验揭示了各组件的贡献与依赖关系。仅添加面部区域增强会导致 FVD 从 355.2 上升至 412.8，表明单独引入骨架不一致会破坏空间对应性，引发训练不稳定。结合参考引导姿态控制后，FVD 降至 325.7，验证了参考姿态对稳定训练的关键作用。最终加入令牌替换策略，FVD 进一步降至 297.94，SSIM 提升至 0.812，证明令牌替换在长视频生成中的必要性。

| 组件 | SSIM ↑ | LPIPS ↓ | FVD ↓ |
| :--- | :--- | :--- | :--- |
| Base Ref. Extractor | 0.773 | 0.280 | 355.2 |
| + Face region enhancement | 0.748 | 0.335 | 412.8 |
| + Reference-guided pose control | 0.795 | 0.275 | 325.7 |
| Full + Token Replace | 0.812 | 0.254 | 297.9 |

评估边界方面，论文未报告置信区间，且主要聚焦于单角色场景，缺乏多角色交互的测试。代码已开源，但超参数细节如掩码比例、姿态增强比例等仅在补充材料中提及，复现时需仔细核对。此外，实验未区分合成数据与真实数据的贡献，外补训练是否导致非遮挡场景性能下降未得到验证。

## 关联研究分析

从问题动机看，One-to-All Animation 与 Wan-Animate 均基于 DiT 架构，但后者依赖大规模预训练数据中的自然对齐分布，而前者通过自监督外补主动引入失配，解决了真实场景中参考图与驱动视频尺度不一的痛点。Wan-Animate 在失配输入下出现明显视觉伪影，表明其身份保持机制对姿态重定向的过度依赖，而 One-to-All 通过解耦身份与骨架，降低了这种依赖。从方法设计看，One-to-All 的参考提取器与 IPAdapter 类似，均使用 CLIP 或类似编码器提取语义特征，但 IPAdapter 缺乏细粒度身份细节，且无法处理大遮挡区域。One-to-All 的 HRFA 通过引入独立的参考投影矩阵与位置编码解耦，实现了更精细的身份特征注入，解决了 IPAdapter 在背景与前景细节一致性上的不足。

## 总结

One-to-All Animation 针对姿态驱动动画中参考图与驱动视频空间失配导致的身份丢失问题，提出自监督外补训练与身份鲁棒姿态控制机制。该方法通过重构训练数据分布，使模型能直接处理任意布局的参考图，在 TikTok 数据集上 FVD 达 297.94，显著优于 Wan-Animate 的 485.92。然而，论文实验仅覆盖单角色场景，且未验证外补训练对非遮挡场景性能的影响。当参考图与驱动视频完全对齐时，该方法的性能是否仍优于标准对齐基线，论文未给出回答。
