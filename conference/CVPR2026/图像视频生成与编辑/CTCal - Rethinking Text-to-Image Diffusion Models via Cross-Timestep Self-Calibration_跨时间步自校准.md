# CVPR2026最新论文 ｜CTCal: Rethinking Text-to-Image Diffusion Models via Cross-Timestep Self-Calibration ｜跨时间步自校准

研究机构：北京航空航天大学

作者：Xiefan Guo、Xinzhu Ma、Haiyu Zhang 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.20741)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.20741)

> 文本到图像生成中，复杂提示下的细粒度语义对齐（如计数、空间关系）长期受限于传统扩散损失在大噪声时间步下对文本-图像对应关系建模的失效。现有推理时优化方法虽能干预注意力图，但泛化性差且无法改变模型内在的表示缺陷。本文切入点在于发现交叉注意力图在小时间步（低噪声）下对齐质量显著优于大时间步（高噪声），从而提出利用小时间步的可靠对齐信号校准大时间步学习的训练时自校准机制。CTCAL通过词性筛选、像素-语义联合优化及自适应加权，在SD 2.1和SD 3上显著提升了组合生成能力，但其增益是否完全独立于骨干网络强度，以及在大模型上的边际收益，仍需进一步验证。

## 研究背景

文本到图像扩散模型的去噪过程涉及从纯噪声逐步恢复图像，不同时间步对应不同的噪声水平。交叉注意力层（Cross-Attention Layer）负责建立文本提示与图像特征的空间对应关系，其输出的注意力图（Attention Map）直接决定了语义元素在图像中的位置。然而，传统扩散损失仅通过噪声预测误差提供隐式监督，这种监督在大时间步（高噪声）下变得极其微弱，导致模型难以在去噪初期建立准确的文本-图像空间映射。

该领域长期面临的核心矛盾是生成质量与语义对齐的失衡。主流路线包括架构创新（如DiT、MM-DiT）和推理时优化（如CountSteer、Prompt Reinjection）。架构创新提升了模型容量，但未解决训练目标对细粒度对应关系的建模不足；推理时优化通过操纵注意力图或重注入提示来校正偏差，但受限于泛化性，且无法弥补训练阶段形成的表示缺陷。本文指出，对齐难度随时间步增加而加剧，大时间步下的对齐失效是制约整体保真度的关键瓶颈，因此将优化视角从推理时前移至训练时，利用小时间步的可靠信号进行自校准。

## 核心方法

### 方法参照系

本文问题属于语义对齐优化路线，但偏离了主流的推理时干预或文本编码器微调范式。标准流程通常在推理阶段通过CFG变体或注意力操纵来调整生成结果，而本文在训练阶段引入跨时间步自监督损失，直接修正去噪网络在不同噪声水平下的表示学习。关键差异在于，本文将推理时观察到的注意力图演化规律转化为训练时的显式监督信号，而非事后校正。

### 跨时间步自校准机制

CTCAL的核心在于利用小时间步 $t_{tea}$ 的交叉注意力图 $\mathbf{A}_{tea}$ 校准大时间步 $t_{stu}$ 的注意力图 $\mathbf{A}_{stu}$。设计动机是解决传统扩散损失在大时间步下对文本-图像对应关系建模不足的问题。具体而言，模型在 $t_{tea}$ 和 $t_{stu}$ 两个时间步分别提取注意力图，并最小化二者之间的差异：

$$
\mathcal{L}_{CTCAL} = \frac{1}{N_{noun}} \sum_{y_i \in Y_{noun}} D(\mathbf{A}_{stu, y_i}, \mathbf{A}_{tea, y_i})
$$

其中 $Y_{noun}$ 为名词令牌集合，$N_{noun}$ 为名词数量，$D(\cdot)$ 为均方误差。该公式的物理含义是，强制大时间步的注意力分布向小时间步的可靠分布靠拢，从而将低噪声下的精确空间语义传递到高噪声阶段。

### 词性筛选与联合优化

为避免非语义令牌（如冠词、连词）的注意力图引入噪声干扰，CTCAL引入基于词性的筛选策略，仅对名词令牌计算校准损失。此外，为防止特征编码器过拟合导致模式崩溃，提出像素-语义空间联合优化，通过轻量级自编码器的重构任务约束特征表示：

$$
\mathcal{L}_{recon} = \| f_{attn[dec]}(f_{attn[enc]}(\mathbf{A})) - \mathbf{A} \|_2^2
$$

该设计确保了注意力图在语义空间中的可区分性，同时保留了像素级的空间细节。最后，通过时间步感知自适应加权 $\lambda_t$ 线性增加 $\mathcal{L}_{CTCAL}$ 的权重，平衡扩散损失与校准损失在不同噪声水平下的贡献，避免早期训练阶段的过度约束。

## 实验评估

实验在T2I-CompBench++和GenEval基准上进行，基线覆盖SD 2.1、SD 3、GORS（监督微调）及多种推理时优化方法（CD、SD、AE）。缺失少步蒸馏（如MeanFlow）和动态CFG（如TCFG）的直接对比，限制了与效率导向方法的全面比较。

| 方法 | Color B-VQA | 2D-Spatial UniDet | Complex 3-in-1 |
| :--- | :--- | :--- | :--- |
| SD 2.1 | 0.5065 | 0.1342 | 0.3386 |
| SD 2.1 + GORS | 0.6426 | 0.1775 | 0.3371 |
| SD 2.1 + CTCAL | 0.7233 | 0.2142 | 0.3403 |
| SD 3 (2B) | 0.8132 | 0.3200 | 0.3771 |
| SD 3 (2B) + CTCAL | 0.8443 | 0.3476 | 0.3814 |

CTCAL在SD 2.1上显著优于GORS，尤其在2D-Spatial任务上提升明显；在SD 3上，CTCAL进一步提升了组合生成能力，Complex指标从0.3771升至0.3814。

| 消融配置 | Color B-VQA | 2D-Spatial UniDet |
| :--- | :--- | :--- |
| + CTCAL(A) | 0.6286 (-2.18%) | 0.1693 (-4.62%) |
| + CTCAL(B) | 0.6897 (+7.33%) | 0.1972 (+11.10%) |
| + CTCAL(E) | 0.7233 (+12.56%) | 0.2142 (+20.68%) |

消融实验显示，朴素约束（A）导致性能下降，验证了词性筛选（B）的必要性；像素-语义联合优化（C）和主体响应正则化（D）进一步提升了性能，最终版本（E）在2D-Spatial任务上相比基线提升20.68%。

评估边界方面，论文未报告计算开销和推理速度，且GenEval Overall得分（SD 3 + CTCAL为0.7644）与知识库中Prompt Reinjection (SD3.5) 的SOTA持平，未超越更强骨干。可复现性方面，代码已开源，但超参数设置（如 $\lambda_t$ 的具体值）仅在补充材料中提及，主文未详细列出。

## 关联研究分析

从问题动机看，CTCAL与CountSteer均针对组合任务中的空间关系错误，但根源假设不同。CountSteer认为失败源于推理时注意力分布的偏差，通过操纵交叉注意力权重进行校正；CTCAL则认为失败源于训练时大时间步下表示学习的不足，通过跨时间步自校准从根本上改善模型能力。这一差异暗示，推理时干预可能仅能缓解症状，而训练时优化才能解决病因，但CTCAL在SD 3上的增益是否完全独立于骨干网络本身的强大表示能力，论文未给出控制变量实验。

从方法设计看，CTCAL与Prompt Reinjection同属语义对齐优化，但作用阶段不同。Prompt Reinjection在推理时重注入文本条件以防止语义衰减，而CTCAL在训练时利用小时间步信号校准大时间步学习。CTCAL的优势在于无需额外推理开销，且能提升模型内在能力；劣势在于需要额外的训练数据和计算资源。两者结合可能形成“训练时校准+推理时重注入”的互补策略，但论文未探索这种组合效果，也未讨论CTCAL在少步蒸馏场景下的适用性，即当推理步数压缩至个位数时，训练时校准的增益是否仍能保持。

## 总结

CTCAL旨在解决文本到图像生成中复杂提示下的细粒度语义对齐问题，其切入点在于发现传统扩散损失在大时间步下对文本-图像对应关系建模的失效，并利用小时间步的可靠对齐信号进行训练时自校准。该方法通过词性筛选、像素-语义联合优化及自适应加权，在SD 2.1和SD 3上显著提升了组合生成能力，T2I-CompBench++上2D-Spatial指标提升20.68%，GenEval Overall达到0.7644。然而，论文未报告计算开销，且GenEval得分未超越更强骨干（SD 3.5）的SOTA，表明其增益可能部分依赖于骨干网络强度。当骨干网络进一步扩展至10B+参数时，CTCAL的边际收益是否递减，以及其在少步蒸馏场景下的有效性，论文未给出回答。
