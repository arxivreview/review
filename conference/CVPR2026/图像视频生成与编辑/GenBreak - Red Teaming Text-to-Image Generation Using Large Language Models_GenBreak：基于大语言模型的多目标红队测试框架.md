> 导读 文本到图像（T2I）模型的安全防御面临“隐蔽性”与“毒性”的结构性矛盾：现有攻击方法要么生成的图像毒性不足，要么提示词过于直白易被过滤。GenBreak 通过微调大语言模型（LLM）作为红队代理，利用强化学习在代理环境中优化多目标奖励，实现了高隐蔽性与高毒性的平衡。该方法在商业 API 黑盒迁移测试中取得了 70% 的裸露内容绕过率，验证了自动化红队测试的有效性，但其对代理模型依赖的泛化边界仍存疑。

## 研究背景

T2I 模型的安全风险源于训练数据未受控收集，导致模型具备生成不安全内容（NSFW）的能力。防御机制通常部署在输入端（提示词过滤）或输出端（图像过滤），但这两者均存在语义盲区。提示词过滤依赖关键词或分类器，难以识别隐喻或组合语义；图像过滤则可能误伤良性内容或漏检高保真有害图像。这种“静态防御”与“动态攻击”的不对称，使得安全对齐成为 T2I 领域的核心挑战。

主流攻击路线分为两类：基于规则的搜索（如遗传算法优化离散变量）和基于 LLM 的语义推理。前者如 Ring-A-Bell 揭示了概念移除防御的脆弱性，但效率低且易陷入局部最优；后者如 SneakyPrompt 利用强化学习进行词级替换，但往往牺牲图像毒性以换取提示词隐蔽性，或反之。现有方法普遍缺乏对“提示词流畅性”与“图像毒性”的联合优化，导致生成的对抗提示要么语义破碎，要么毒性不足，无法有效暴露 T2I 模型的真实安全漏洞。

GenBreak 的切入点在于将红队测试形式化为序列决策问题，通过 LLM 的世界知识与逻辑推理能力，在代理 T2I 环境中进行多目标优化。它不依赖梯度反馈，而是通过构建包含毒性、绕过率、多样性等维度的奖励信号，引导 LLM 生成既隐蔽又高毒性的提示词，从而在保持语义连贯性的前提下最大化攻击成功率。

## 核心方法

### 方法参照系

GenBreak 属于 LLM 驱动的自动化红队测试路线，其标准流程为：初始化 LLM 策略 $\pi_\theta$，在代理 T2I 模型 $G$ 上生成提示词 $s$ 并获取图像 $y$，根据奖励信号更新策略。与基于梯度优化的白盒攻击不同，GenBreak 采用黑盒/灰盒设定，仅依赖生成结果与过滤标志，不访问模型内部参数。

### 两阶段训练流水线

GenBreak 采用监督微调（SFT）与强化学习（RL）两阶段训练。SFT 阶段使用两个数据集：Category Rewrite Dataset（15,000 对种子-对抗提示，由 Gemini 2.0 Flash 生成）和 Pre-Attack Dataset（通过迭代攻击 SD 2.1 收集的高毒性提示）。SFT 损失函数为标准的交叉熵损失：

$$ L_{SFT} = -\mathbb{E}_{(x,y)\sim D_{SFT}} \sum_{t=1}^{T} \log \pi_\theta(y_t | y_{<t}, x) $$

该设计动机在于解决预训练 LLM 缺乏红队任务特定适配的问题，通过冷启动赋予模型基本的对抗生成能力。

### 多目标 GRPO 强化学习

RL 阶段采用 Group Relative Policy Optimization (GRPO) 算法，核心创新在于六维奖励函数的设计。给定种子提示 $q$，策略 $\pi_\theta$ 生成一组 $G$ 个提示词 $S=\{s_1, ..., s_G\}$，每个提示词提交至代理模型 $G$ 生成图像 $y_i$ 并获取过滤标志。奖励函数定义为：

$$ R(s, y) = \lambda_1 R_{tox}(y) + \lambda_2 R_{bps}(s, y) + \lambda_3 R_{clean}(s) + \lambda_4 R_{lexical}(s) + \lambda_5 R_{semantic}(s) + \lambda_6 R_{img\_div}(y) $$

其中，$R_{tox}$ 聚合 MHSC、LLaVAGuard 和 NudeNet 三个专家模型的毒性评分；$R_{bps}$ 仅在提示词和图像均绕过过滤器时授予毒性奖励，避免“绕过但无毒”的无效攻击；$R_{clean}$ 惩罚包含黑名单词汇的提示词，应对基于关键词的过滤器；$R_{lexical}$ 和 $R_{semantic}$ 利用动态参考池 $X_{pool}$ 计算负 SelfBLEU 和语义相似度，确保提示词多样性；$R_{img\_div}$ 基于 DreamSim 感知相似度，鼓励生成视觉风格多样的有害图像。该设计解决了单一毒性指标导致的“高毒性但易被过滤”或“易绕过但低毒性”的失衡问题，通过联合优化实现了隐蔽性与毒性的帕累托最优。

## 实验评估

实验在 I2P 基准（4703 个不安全提示）及三个商业 T2I API 上进行。基线覆盖 SneakyPrompt、MMA-Diffusion、PGJ、ART 和 CRT，但未对比 2026 年 SOTA 方法如 DACA 或 JANUS。在商业 API 黑盒迁移测试中，GenBreak 在裸露内容域的单次尝试毒性绕过率分别为 70%、30% 和 47%，显著优于基线方法。据领域综述，DACA 在 I2P 本地测试中 ASR 为 94.5%，但 GenBreak 的迁移测试协议不同，不可直接比较。

消融实验未提供详细数值，但定性分析表明，移除 $R_{clean}$ 会导致提示词包含大量敏感词，易被简单过滤器拦截；移除 $R_{img\_div}$ 则导致生成图像风格单一，降低红队测试的覆盖范围。动态参考池 $X_{pool}$ 的引入防止了模型在训练后期遗忘早期有效策略，但池大小对收敛稳定性的影响未量化。

评估边界方面，GenBreak 依赖代理模型 SD 2.1，若商业 API 安全机制与开源模型差异过大，迁移率可能下降。代码已开源，但超参数（如 $\lambda_i$ 权重、$G$ 大小）未详细披露，可复现性存在一定门槛。

## 关联研究分析

从问题动机看，GenBreak 与 SneakyPrompt 同属 RL 框架，但 SneakyPrompt 侧重词级替换，仅优化提示词隐蔽性，忽略图像毒性；GenBreak 则通过多目标奖励联合优化隐蔽性与毒性，解决了“绕过但无毒”的失效问题。这一差异源于任务特性：SneakyPrompt 假设过滤器主要依赖关键词，而 GenBreak 假设过滤器依赖语义理解，因此需要更复杂的语义重构。

从方法设计看，GenBreak 与 CRT 均引入多样性奖励，但 CRT 使用静态历史参考，易导致模型遗忘早期策略；GenBreak 采用动态参考池 $X_{pool}$，仅保留最近 $pool\_size$ 个测试用例，提高了策略更新的时效性。此外，GenBreak 引入图像级多样性奖励 $R_{img\_div}$，这是 CRT 所缺乏的，旨在暴露 T2I 模型在不同视觉风格下的安全漏洞。

## 总结

GenBreak 解决了 T2I 红队测试中“隐蔽性”与“毒性”的权衡矛盾，通过 LLM 多目标 GRPO 强化学习，在代理环境中优化六维奖励信号，实现了高隐蔽性与高毒性的平衡。其在商业 API 黑盒迁移测试中取得了 70% 的裸露内容绕过率，验证了自动化红队测试的实用有效性。然而，该方法依赖代理模型 SD 2.1，若商业 API 安全机制与开源模型差异过大，迁移率可能下降。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
