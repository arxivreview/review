# CVPR2026最新论文 ｜SpeeDiff: Scalable Pixel-Anchored End-to-End Latent Diffusion Model ｜像素锚定端到端潜空间扩散

研究机构：美国加州理工学院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_7006fc5aba5b)

> 潜空间扩散模型长期受限于变分自编码器（VAE）的重构上限，其冻结的两阶段训练范式阻碍了生成器对潜空间结构的反向优化。现有方法通过表示对齐或替换编码器来缓解语义缺失，但未能解决联合训练时的潜空间坍缩问题。SpeeDiff 提出一种像素锚定的端到端框架，通过引入 Tweedie 像素重构损失稳定潜空间，实现了 VAE 与扩散模型的从零联合训练。该方法在无需分类器自由引导的情况下取得了 ImageNet 256×256 上 1.50 的 FID，验证了端到端优化的可行性，但其对大规模文本到图像任务的泛化能力尚待检验。

## 研究背景

潜空间扩散模型（LDM）通过变分自编码器（VAE）将图像压缩至低维潜空间，以平衡生成质量与计算成本。VAE 的重构目标主要捕捉低层像素统计，导致潜空间缺乏高层语义关联，使得扩散模型难以高效学习。为弥补这一缺陷，近期研究引入了视觉基础模型（VFM）的语义表示，通过表示对齐（REPA）或直接替换 VAE 编码器来增强潜空间的语义丰富度。

主流路线均将 VAE 视为冻结的预训练组件，扩散模型仅在其固定的潜空间上进行优化。这种两阶段范式虽然稳定，但切断了扩散损失对 VAE 编码器的梯度反馈，限制了潜空间针对生成任务的最优演化。尽管 LSGM 等早期工作尝试联合训练，但发现直接反向传播扩散损失会导致性能退化。SpeeDiff 的切入点在于诊断并解决这一退化机制，通过引入像素级约束实现真正的端到端联合优化，从而打破冻结 VAE 的性能天花板。

## 核心方法

### 方法参照系

标准 LDM 流程包含两个独立阶段：首先训练 VAE 并冻结，随后在固定潜空间中训练扩散模型。本文的关键差异在于移除 Stop-Gradient 操作，允许扩散损失直接更新 VAE 编码器参数，将两阶段解耦优化转化为单阶段端到端联合优化。

### 潜空间坍缩诊断与 TPR 损失

直接联合训练导致扩散损失在潜空间中寻找平凡解，表现为潜变量分布偏离高斯先验，出现严重的通道偏差与方差抑制。这种坍缩使得扩散模型只需预测近似常值即可最小化损失，而无需保留重构图像所需的语义信息。为锚定潜空间，SpeeDiff 引入 Tweedie 像素重构（TPR）损失，通过解码 Tweedie 估计的干净潜变量并计算像素级误差，强制 VAE 维持语义完整性。

$$
L_{TPR}(\omega, \varpi, \vartheta) = \mathbb{E}_{x_0, z_0, \varpi, t} \left[ \| D_\varpi(\hat{z}_0) - x_0 \|^2 \right]
$$

该公式的物理含义是：利用扩散模型预测的速度场 $V_\vartheta$ 通过 Tweedie 公式 $\hat{z}_0 = z_t - t V_\vartheta(z_t, t)$ 估计干净潜变量 $\hat{z}_0$，再经 VAE 解码器 $D_\varpi$ 映射回像素空间，与真实图像 $x_0$ 计算均方误差。这一像素级反馈阻止了潜空间向低维流形坍缩，将 FID 从 33.95 降至 5.79。

### REPA++ 表示对齐机制

在 TPR 稳定潜空间的基础上，SpeeDiff 引入 REPA++ 以加速收敛。不同于仅对齐潜变量的 REPA，REPA++ 同时对齐干净潜变量 $z_0$ 和扩散中间特征 $f_t$ 与 VFM 表示 $y$。这种双重对齐将语义监督直接注入去噪过程，通过端到端梯度反馈进一步引导 VAE 编码器形成生成友好的潜空间结构。

$$
L_{REPA++} = -\mathbb{E}_{z_0, x_0, k} \left[ \text{sim}(h_{\vartheta_1}(z_0)_k, y_k) \right] - \mathbb{E}_{z_0, x_0, k} \left[ \text{sim}(h_{\vartheta_2}(f_t)_k, y_k) \right]
$$

该公式表明，通过两个独立的 MLP 适配器 $h_{\vartheta_1}$ 和 $h_{\vartheta_2}$，分别最大化潜变量和扩散特征与 VFM 表示的余弦相似度。这种设计使得语义信息不仅存在于静态潜空间中，还动态指导每一步去噪，最终将 FID 进一步降低至 1.69（80 epochs）。

## 实验评估

实验在 ImageNet 256×256 和 512×512 数据集上进行，主要对比 Vanilla SiT、REPA 及 LightningDiT 等基线。基线覆盖了两阶段训练与表示对齐路线，但缺乏与像素空间扩散模型（如 JiT）的直接对比，限制了跨范式效率的评估。

| 方法 | 设置 | FID (256×256) | 备注 |
| :--- | :--- | :--- | :--- |
| Vanilla E2E | 无 TPR | 33.95 | 80 epochs |
| E2E w/ TPR | 无 REPA++ | 5.79 | 80 epochs |
| SpeeDiff (w/o REPA++) | ViT-VAE + Refined-DiT | 3.66 | 80 epochs |
| SpeeDiff (w/ REPA++) | 完整框架 | 1.69 | 80 epochs |
| SpeeDiff-XL | 完整框架 | 1.50 | 无 CFG |

消融实验显示，TPR 损失是防止潜空间坍缩的关键，贡献了从 33.95 到 5.79 的大幅提升；架构优化（ViT-VAE + Refined-DiT）将计算成本从 436.29 GFLOPs 降至 334.98 GFLOPs，同时 FID 降至 3.66；REPA++ 在此基础上进一步将 FID 降至 1.69。值得注意的是，无 REPA++ 的 SpeeDiff 变体 FID 为 2.42，表明表示对齐对最终性能仍有显著贡献，但 TPR 是端到端训练稳定的前提。

评估边界方面，论文仅报告了 FID 指标，缺乏对生成图像感知质量（如 LPIPS）和多样性（如 IS）的详细分析。代码未公开，且未提供不同随机种子下的置信区间，限制了结果的可复现性验证。此外，512×512 实验仅报告了 XL 模型的 FID 1.53，未提供与其他分辨率或模型规模的完整对比。

## 关联研究分析

从问题动机看，SpeeDiff 与 REPA 均致力于解决潜空间语义缺失问题，但 REPA 假设 VAE 冻结，仅通过蒸馏 VFM 表示来增强潜空间；而 SpeeDiff 认为冻结 VAE 限制了潜空间的最优演化，因此选择端到端联合训练。这一差异源于对 VAE 角色的不同理解：REPA 视 VAE 为固定的特征提取器，SpeeDiff 视其为可优化的生成组件。SpeeDiff 通过 TPR 损失解决了联合训练中的坍缩问题，这是 REPA 框架下未涉及的失效模式。

从方法设计看，SpeeDiff 与 JiT 代表了两种截然不同的效率优化路径。JiT 通过消除 VAE 直接在像素空间扩散，避免了信息瓶颈，但面临高维优化困难；SpeeDiff 保留 VAE 压缩优势，通过端到端训练提升潜空间质量。两者在 ImageNet 256×256 上的 FID 接近（SpeeDiff 1.50 vs JiT 1.82），但 SpeeDiff 依赖 VFM 对齐，而 JiT 依赖大 Patch 架构。这种对比暗示，潜空间范式通过优化训练策略可能缩小与像素空间范式的差距，但两者在计算效率和架构复杂度上的权衡尚未在统一基准下充分评估。

## 总结

SpeeDiff 旨在解决潜空间扩散中 VAE 冻结导致的语义瓶颈与联合训练时的潜空间坍缩矛盾。其切入点在于识别出扩散损失直接反向传播会导致潜变量分布退化，并通过 TPR 损失提供像素级锚定，使端到端训练成为可能。该方法通过联合优化 VAE 与扩散模型，在 ImageNet 256×256 上实现了 1.50 的 FID（无 CFG），并在 512×512 上达到 1.53。然而，论文实验局限于类条件生成任务，未验证在大规模文本到图像任务中，端到端训练是否会导致 VAE 重构质量下降或训练不稳定。当训练数据规模扩大至数百万级时，TPR 损失的像素级计算开销是否会成为端到端训练的主要瓶颈，论文未给出回答。
