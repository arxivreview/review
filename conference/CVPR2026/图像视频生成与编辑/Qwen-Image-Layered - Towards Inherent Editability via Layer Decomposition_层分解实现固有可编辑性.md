# CVPR2026最新论文 ｜Qwen-Image-Layered: Towards Inherent Editability via Layer Decomposition ｜层分解实现固有可编辑性

作者：Shengming Yin、Zekai Zhang、Zecheng Tang 等 14 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.15603)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.15603)

> 扩散模型语义图像编辑长期受困于全局去噪导致的非编辑区域漂移，现有方法通过注意力操纵或速度场校正抑制泄漏，但无法从物理层面隔离编辑影响。本文指出问题根源在于光栅图像的纠缠表示，提出将图像分解为语义解耦的RGBA层栈，使编辑操作天然局限于目标层。通过RGBA-VAE统一潜空间、VLD-MMDiT变长层分解架构及多阶段训练策略，实现端到端分解。该方法在分解质量上显著优于基线，但缺乏通用编辑基准验证，其“固有可编辑性”在复杂语义编辑中的实际增益仍存疑。

## 研究背景

当扩散模型执行局部语义修改时，全局去噪过程会不可避免地扰动非目标区域的潜变量，导致身份漂移或几何错位。这种一致性失效源于光栅图像的纠缠特性：所有视觉内容融合于单一画布，语义与几何紧密耦合，任何编辑操作都会通过像素空间传播。为隔离编辑影响，主流方案采用掩码引导的局部编辑或注意力权重操纵，但这些方法依赖精确的空间定位，在遮挡或软边界场景下，实际编辑区域往往模糊，无法从根本上解决一致性问题。

扩散模型已成为语义图像编辑的主导范式，Training-free方法因无需重训练成为研究热点，但逆映射的误差累积与背景保持始终是核心瓶颈。现有路线在表示质量与适应效率间做出取舍：基于U-Net的注意力操纵（如Prompt-to-Prompt）在复杂结构保持上仍有优势，而基于DiT/RF的速度场校正（如FlowEdit）在效率与稳定性上更优，但均无法消除全局去噪的随机性对非编辑区的干扰。本文的切入点在于改变图像表示本身，主张通过语义解耦的层结构实现物理隔离，使编辑操作在表示空间内天然局部化，而非在生成过程中抑制泄漏。

## 核心方法

### 方法参照系

本文问题属于图像分解与编辑的交叉领域，最接近的通用流程是“分割-修复”范式：先通过分割或抠图提取前景，再用修复模型重建背景。该流程的关键差异在于其迭代性与误差传播：每层分解依赖前一层结果，复杂场景下误差累积导致层质量下降。本文摒弃迭代策略，采用端到端扩散模型直接分解RGB图像为多层RGBA，从表示层面重构编辑范式。

### RGBA-VAE统一潜空间

此前方法如LayeringDiff使用RGB VAE生成前景后额外模块获取透明度，LayerDecomp则为输入RGB与输出RGBA使用独立VAE，导致输入输出潜空间分布存在间隙，影响分解精度。本文设计RGBA-VAE，将Qwen-Image VAE编码器首层与解码器末层从3通道扩展至4通道，通过复制预训练RGB VAE参数初始化前3通道，新通道参数初始化为零，以维持RGB重建性能。训练目标为重建损失、感知损失与正则化损失的组合，使RGB与RGBA图像编码至共享潜空间。该设计消除了输入输出表示的分布间隙，为后续层分解提供统一的特征基础。

$$
\mathcal{L}_{VAE} = \mathcal{L}_{rec} + \lambda_{per} \mathcal{L}_{per} + \lambda_{reg} \mathcal{L}_{reg}
$$

该公式表明，RGBA-VAE通过联合优化重建、感知与正则化项，确保RGB与RGBA图像在潜空间中具有兼容的分布特性，避免独立VAE导致的特征不匹配。

### VLD-MMDiT变长层分解

以往方法如LayerD需递归推理分解多层，误差随层数累积。本文提出VLD-MMDiT架构，支持可变数量层的端到端分解。输入RGB图像$I$被RGBA-VAE编码为潜变量$z_I$，目标RGBA层$L$编码为$x_0$。采用Rectified Flow训练目标，采样噪声$x_1$与时间步$t$，中间状态$x_t$与速度$v_t$定义为：

$$
x_t = (1-t)x_0 + t x_1, \quad v_t = x_1 - x_0
$$

模型预测速度$v_\theta(x_t, t, z_I, h)$，损失为预测速度与真实速度的均方误差。在注意力计算中，文本条件$h$、输入图像$z_I$与中间状态$x_t$的序列沿维度拼接，直接建模层内与层间交互。引入Layer3D RoPE，为中间状态$x_t$分配从0开始的层索引，为条件图像$z_I$分配-1索引，以区分不同任务。该设计使模型能区分不同层，避免标准2D RoPE下层间混淆，实现变长层分解。

## 实验评估

实验在Crello数据集上评估图像分解质量，采用LayerD提出的评估协议，通过动态时间规整对齐不同长度的层序列，并允许相邻层合并以处理分解歧义。基线包括VLM Base + Hi-SAM、Yolo Base + Hi-SAM及LayerD，覆盖分割-修复与迭代分解路线，但缺失FlowEdit、Prompt-to-Prompt等主流编辑方法，因任务聚焦分解而非通用编辑。

| 方法 | RGB L1↓ (Max Merge=5) | Alpha soft IoU↑ (Max Merge=5) |
| --- | --- | --- |
| VLM Base + Hi-SAM | 0.0726 | 0.7589 |
| Yolo Base + Hi-SAM | 0.0579 | 0.7897 |
| LayerD | 0.0396 | 0.8650 |
| Qwen-Image-Layered-I2L | 0.0363 | 0.9160 |

Qwen-Image-Layered-I2L在RGB L1与Alpha soft IoU上均显著优于基线，尤其在Alpha soft IoU上领先LayerD 0.051，表明其在生成高保真alpha通道方面具有优势。

消融实验验证了三个关键组件的贡献。移除Layer3D RoPE后，RGB L1从0.0363升至0.2435，Alpha soft IoU从0.9160降至0.6031，证实层索引对区分不同层的必要性。移除RGBA-VAE后，RGB L1升至0.1126，Alpha soft IoU降至0.7984，表明统一潜空间对消除分布间隙的作用。移除多阶段训练后，RGB L1升至0.0959，Alpha soft IoU降至0.8331，说明渐进式训练对适应新任务的重要性。

| 组件 | RGB L1↓ (Max Merge=5) | Alpha soft IoU↑ (Max Merge=5) |
| --- | --- | --- |
| w/o Layer3D RoPE | 0.2435 | 0.6031 |
| w/o RGBA-VAE | 0.1126 | 0.7984 |
| w/o Multi-stage Training | 0.0959 | 0.8331 |
| Full Model | 0.0363 | 0.9160 |

Layer3D RoPE的移除导致性能大幅下降，揭示其是变长层分解的关键；RGBA-VAE与多阶段训练的贡献相对较小但显著，表明表示统一与训练策略对分解质量的协同作用。

评估边界方面，实验仅在Crello数据集上进行，该数据集与本文PSD数据存在分布差异（层数、半透明层），需微调模型。指标限于RGB L1与Alpha soft IoU，缺乏PIE-Bench等通用编辑基准，无法验证层编辑在语义对齐与背景保持上的实际增益。代码与模型已开源，但训练细节（如内部数据集）未公开，可复现性受限。

## 关联研究分析

从问题动机看，本文与FlowEdit等速度场校正方法形成根本差异。FlowEdit通过校正速度场差异引导生成，在动力学层面抑制编辑泄漏，但依赖全局去噪过程，非编辑区仍受随机性影响。本文通过层分解实现物理隔离，编辑操作仅作用于目标层，非编辑层像素完全不变，从表示层面消除漂移。这一差异源于任务定义：FlowEdit聚焦于“如何精确控制去噪轨迹”，本文聚焦于“如何重构图像表示以天然支持编辑”。前者在通用语义编辑中更灵活，后者在局部操作（如缩放、重定位）中更具一致性优势。

从方法设计看，本文与LayerD等迭代分解方法存在关键分歧。LayerD通过递归分割-修复提取层，误差随层数累积，复杂场景下层质量下降。本文采用端到端扩散模型直接分解，通过VLD-MMDiT的层间注意力建模全局依赖，避免迭代误差。这一设计选择解决了迭代方法在多层场景下的误差传播问题，但依赖PSD数据分布，自然图像分解质量是否足够，论文未给出充分验证。

## 总结

本文要解决的核心矛盾是全局去噪导致的非编辑区域一致性与局部编辑精确性之间的张力。现有方法通过注意力操纵或速度场校正抑制泄漏，但无法从物理层面隔离编辑影响。本文抓住图像表示的纠缠特性这一被忽略的根源，提出层分解实现固有可编辑性，通过RGBA-VAE统一潜空间、VLD-MMDiT变长层分解及多阶段训练，实现端到端分解。实验证明其在Crello数据集上分解质量显著优于基线，RGB L1 0.0363、Alpha soft IoU 0.9160。本文的边界在于缺乏通用编辑基准验证，层编辑在复杂语义编辑中的实际增益未明确。当支持集从PSD数据扩展到自然图像时，层分解的泛化性是否保持，论文未给出回答。
