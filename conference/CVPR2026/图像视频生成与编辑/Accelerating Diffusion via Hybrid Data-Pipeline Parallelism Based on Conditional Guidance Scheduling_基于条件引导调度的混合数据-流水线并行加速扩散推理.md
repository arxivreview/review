# CVPR2026最新论文 ｜Accelerating Diffusion via Hybrid Data-Pipeline Parallelism Based on Conditional Guidance Scheduling ｜基于条件引导调度的混合数据-流水线并行加速扩散推理

研究机构：韩国科学技术院

作者：Euisoo Jung、Byunghyun Kim、Hyunjin Kim 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.21760)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.21760)

> 扩散模型多步迭代去噪导致高推理延迟，单卡加速受限于算力上限，而现有分布式并行方法在加速比与生成质量间难以兼顾。本文切入点在于利用分类器自由引导（CFG）中条件与无条件分支的天然差异，将其作为数据并行维度，并依据去噪差异度动态切换并行模式。通过混合数据与流水线并行，该方法在双卡环境下实现了超越线性加速。其价值在于无需额外训练即可提升多卡推理效率，但加速收益是否随GPU数量线性扩展仍存疑。

## 研究背景

扩散模型推理的核心瓶颈在于数十至数百步的迭代去噪过程，每一步均需执行完整的网络前向传播。为突破单卡算力限制，分布式并行成为必然选择，但传统数据并行将图像切分为局部Patch，导致边界伪影；流水线并行将模型层切分，则因异步通信引入误差累积。这两种静态并行策略均无法在保持全局一致性的同时实现高效加速。

现有主流方案如DistriFusion和AsyncDiff分别代表了数据并行与流水线并行的极端。DistriFusion通过Patch并行实现了1.22×加速，但FID高达4.864，视觉连贯性受损；AsyncDiff通过层切分实现1.31×加速，FID为4.103，但通信开销巨大。这些方法忽略了条件分支在去噪过程中的动态特性：早期步骤条件影响大，分支差异显著；中期步骤分支收敛，差异微小。这种时间上的非均匀性意味着静态并行策略在部分步骤是冗余的，在另一些步骤则是有害的。

本文针对这一被忽略的时间动态性，提出混合并行框架。其核心假设是：条件与无条件分支的差异程度可作为并行切换的信号。当差异大时，分支应独立处理以保留语义；当差异小时，分支可并行执行以最大化吞吐。这一思路将并行调度从静态架构问题转化为动态信号处理问题，旨在双卡环境下实现超过2×的加速比，同时维持与单卡模型相当的生成质量。

## 核心方法

### 方法参照系

本文问题属于多GPU分布式推理加速，区别于单卡算法优化。标准流程是将模型或数据切分至多卡，但本文的关键差异在于切分维度：不切分空间Patch或模型层，而是切分条件分支，并依据去噪过程中的动态信号调整并行粒度。

### 条件分支数据并行

传统数据并行将图像空间切分，导致局部信息缺失。本文利用CFG机制，将条件输入$(\mathbf{x}_t, c)$与无条件输入$(\mathbf{x}_t)$作为两个独立的数据流，分别分配至不同GPU。这种切分方式保证了每个分支处理完整图像，避免了空间边界伪影。设计动机在于解决Patch并行导致的全局一致性丧失问题，通过语义维度的切分替代空间维度的切分，使每个GPU负责完整的语义路径而非局部区域。

### 自适应并行切换

静态流水线并行在条件影响强烈的步骤引入误差。本文引入去噪差异度（Denoising Discrepancy）作为切换信号，定义为条件与无条件噪声预测的相对平均绝对误差：

$$ \text{rel-MAE}_t(\epsilon_c, \epsilon_u) = \frac{\|\epsilon_c - \epsilon_u\|_1}{\|\epsilon_u\|_1 + \delta} $$

其中$\epsilon_c = \epsilon_\theta(\mathbf{x}_t, c, t)$，$\epsilon_u = \epsilon_\theta(\mathbf{x}_t, t)$。该公式量化了条件信号对去噪轨迹的相对影响强度。当rel-MAE处于U型曲线的谷底（分支收敛区）时，启用流水线并行；当rel-MAE处于两端（分支发散区）时，回退至独立处理。$\tau_1$和$\tau_2$分别标记并行阶段的起止点，$\tau_1$由斜率阈值自动确定，$\tau_2$设为$\tau_1 + k$。这一机制解决了静态并行在早期步骤误差累积的问题，仅在分支对齐度高的区间执行并行，从而在加速与质量间取得最优平衡。

## 实验评估

实验在MS-COCO 2014验证集（5000 prompts）上进行，对比SDXL（U-Net）和SD3（DiT）模型。基线覆盖DistriFusion、AsyncDiff、xDiT-Ring和Parastep，但缺乏单卡SOTA加速方法（如蒸馏）作为质量上限参照，导致无法评估分布式加速相对于算法加速的绝对收益。

| 方法 | 延迟 (s) | 加速比 | FID (w/ Orig.) |
| :--- | :--- | :--- | :--- |
| Original Model | 16.49 | - | - |
| DistriFusion | 13.53 | 1.22× | 4.864 |
| AsyncDiff | 12.54 | 1.31× | 4.103 |
| Ours (k=5) | 7.12 | 2.31× | 4.100 |

在SDXL双卡设置下，本文方法实现2.31×加速，FID 4.100，优于AsyncDiff的1.31×加速和4.103 FID。通信成本较AsyncDiff降低19.6×，主要得益于自适应切换减少了冗余通信。在SD3上，本文实现2.07×加速，FID 1.878，优于xDiT-Ring的1.35×加速和1.909 FID。

消融实验显示，仅使用条件分支并行（Full Condition-Based Partitioning）实现1.78×加速，FID 3.623；加入自适应切换后，加速提升至2.31×，FID变为4.100。这表明自适应切换以轻微的质量损失（FID增加0.477）换取了显著的加速收益（提升0.53×）。参数$k$的选取直接影响权衡：$k=5$时质量最优，$k=30$时加速最大但质量下降。

评估边界方面，实验仅覆盖双卡设置，未验证多卡扩展性；指标以FID为主，缺乏LPIPS和PSNR的详细对比；代码已开源，但超参数$k$和$\tau_{cap}$的选取依赖特定模型，通用性需进一步验证。

## 关联研究分析

从问题动机看，本文与DistriFusion和AsyncDiff同属多卡加速，但切分维度不同。DistriFusion切分空间，AsyncDiff切分模型层，而本文切分条件分支。这一差异源于对误差来源的不同认知：前者认为空间局部性是瓶颈，后者认为层间依赖是瓶颈，而本文认为条件分支的动态对齐度是瓶颈。根源在于CFG机制提供了天然的语义切分点，而空间或层切分缺乏这种语义一致性保证。

从方法设计看，本文与Parastep同属动态调度，但信号源不同。Parastep利用相邻步骤噪声相似度进行步间复用，本文利用条件与无条件分支差异进行步内并行切换。Parastep在早期步骤误差累积严重，因其复用机制假设相邻步骤相似，而早期步骤变化剧烈。本文的自适应切换仅在分支收敛区并行，避开了高差异区间，从而避免了误差累积。这一设计差异表明，动态调度的有效性取决于信号源与误差模式的匹配度，而非单纯的动态性。

## 总结

本文解决的核心矛盾是多卡加速比与生成质量的权衡，现有静态并行方法因忽略条件分支的时间动态性而失效。本文抓住CFG分支差异这一被忽略的信号，通过条件分支数据并行与自适应切换，在双卡环境下实现2.31×加速且FID保持4.100。其边界在于仅验证双卡设置，且加速收益是否随GPU数量线性扩展未经验证。当GPU数量增加至4卡或8卡时，自适应切换的通信开销是否仍能被计算收益覆盖，论文未给出回答。
