# CVPR2026最新论文 ｜DARC: Dual Adjustment Reasoning with Counterfactuals for Trustworthy Chest X-ray Classification ｜双调整反事实推理框架

研究机构：中南大学

作者：Zhifang Liao、Junhao Li、HaoKang Ding 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_52185804dc90)

> 胸部X光（CXR）多标签分类模型常因病理共现与非病理视觉混杂产生捷径学习，导致临床部署中的鲁棒性失效。现有因果去偏方法仅能处理单一混淆源，且缺乏像素级混杂标注支撑精确干预。DARC通过构建首个像素级非病理混杂数据集CheXconf，并设计双流因果架构，同时执行后门调整与反事实推理以解耦两类混淆。该框架在因果纯度上优于单一去偏基线，但分类精度低于纯统计依赖建模的SOTA，其临床价值取决于对因果解释与预测精度的权衡。

## 研究背景

CXR多标签分类的核心困境在于模型往往学习统计关联而非因果机制。当肺炎与胸腔积液频繁共现时，模型可能将心脏轮廓误判为积液证据；当起搏器植入与心脏扩大在数据集中高度相关时，模型会将植入物视为心脏扩大的阳性信号。这种捷径学习源于Pearl因果阶梯中的关联层级，模型最大化观测似然 $P(Y|X)$，却忽略了数据生成过程中的因果结构。要突破这一局限，需引入因果推断理论，区分目标病理、共现病理及非病理混杂变量，并通过干预或反事实推理阻断虚假因果路径。

现有CXR分类研究主要沿两条路线演进：一是架构创新，如从DenseNet到Vision Transformer（ViT），旨在提升特征提取能力；二是标签依赖建模，如图神经网络学习标签间统计耦合。然而，架构升级可能放大虚假关联，而统计耦合建模往往加剧数据固有偏差。因果推断方法虽已介入，但多局限于单一混淆源处理，且因缺乏细粒度标注而依赖简化假设。DARC的切入点在于将因果干预从“关联”提升至“反事实”层级，通过像素级混杂标注实现精确的后门调整，并结合解剖先验进行反事实推理，从而在统一框架内同时解耦两类混淆源。

## 核心方法

### 因果去偏参照系

传统CXR分类模型学习观测分布 $P(Y|I)$，其标准流程为特征提取后直接映射至标签概率。该流程的关键缺陷在于未区分因果路径与虚假路径。DARC将问题重构为估计总因果效应 $P(Y|do(X=x))$，需同时阻断非病理混杂路径 $X \leftarrow Z' \rightarrow F \rightarrow Y$ 与病理共现路径 $X \leftarrow U \rightarrow Z \rightarrow F \rightarrow Y$。这一重构要求模型不仅识别病灶，还需显式建模并消除非临床视觉因素与疾病共现带来的偏差。

### 全局流：基于像素级混杂的后门调整

全局流旨在阻断非病理视觉混杂（如起搏器、导管）引起的虚假关联。传统方法因缺乏混杂变量精确标注，常假设其服从均匀分布，导致干预精度不足。DARC利用CheXconf数据集提供的像素级掩码，通过语义分割模型生成类别化混杂掩码 $M_{conf}$，并对全局特征图 $F_{map}$ 进行加权池化，提取混杂嵌入 $E_{conf}$。该嵌入经FiLM层转化为缩放与平移参数，对全局特征向量 $f_{vec}$ 进行仿射变换，实现条件化特征重校准。

$$ f'_{global} = (1 + \gamma) \odot f_{vec} + \beta $$

其中 $\gamma, \beta$ 由混杂嵌入 $e_{agg}$ 通过FiLM层生成。该公式的物理含义是：在已知混杂状态 $Z'$ 的条件下，动态调整全局特征表示，抑制模型对混杂信号的依赖，从而在特征层面完成后门调整。

### 局部流：解剖引导的反事实推理

局部流旨在解耦病理共现偏差。由于共现病理的深层原因 $U$ 不可观测，标准干预方法失效。DARC采用反事实推理，估计目标病理 $X$ 的总直接效应（TDE）。通过解剖地标检测模型提取双侧肺尖、肋膈角等关键区域，生成动态解剖补丁 $P$，并利用疾病查询矩阵 $Q_{dis}$ 进行注意力聚合，提取标签特异性局部特征 $e_{local}$。该特征代表“若共现病理 $Z$ 不存在时”的预测信号。

$$ \text{Score}_{p(y)} \propto P(y|\mathcal{X}=x, \mathcal{Z}=z) + \lambda \cdot P(y|\mathcal{X}=x, \text{do}(\mathcal{Z}=z_0)) $$

其中 $\lambda$ 为因果修正强度参数。该公式将复杂的反事实问题转化为可计算的加性融合策略：保留观测信息 $P(y|x, z)$，同时通过反事实增强项 $P(y|x, do(z_0))$ 显式修正共现偏差，确保最终预测反映目标病理的纯因果效应。

## 实验评估

实验在ChestX-ray14与CheXpert数据集上进行，采用ConvNeXt作为骨干网络，ImageNet预训练权重初始化。基线覆盖架构创新（如CvTGNet）、统计依赖建模（如CDCL）及单一因果去偏方法（如Nie et al.）。DARC在CheXpert上取得0.907 mAUC，在ChestX-ray14上取得0.857 mAUC，均优于对比基线。

| 方法 | CheXpert mAUC | ChestX-ray14 mAUC |
| :--- | :--- | :--- |
| ConsultNet | 0.889 | - |
| PTRN | 0.896 | - |
| Nie et al. | 0.867 | - |
| CvTGNet | 0.879 | - |
| CDCL | 0.896 | - |
| DARC | 0.907 ± 0.004 | 0.857 ± 0.004 |

消融实验显示，移除解剖地标检测导致性能下降1.1%，移除精确混杂分割导致下降1.5%，表明解剖先验与细粒度混杂建模是因果学习的关键前提。全局流与局部流单独使用均能提升性能，但完整模型（S5）表现最优，证实双调整策略的协同必要性。

评估协议存在局限：未报告置信区间，且缺乏与最新视觉-语言模型（如BioViL）及纯公平性基线（如Stride-Net）的对比。代码未公开，超参数细节有限，可复现性依赖作者提供的实现。

## 关联研究分析

从问题动机看，DARC与Sparse Label Couplings形成方法论对立。后者通过可学习矩阵建模标签间统计共现关系，旨在提升分类一致性；前者则通过因果图区分统计共现与因果效应，旨在消除虚假关联。这一差异源于对“标签依赖”本质的不同理解：统计依赖是数据固有特征，而因果依赖是临床逻辑要求。DARC的因果约束可能牺牲部分拟合能力，导致其mAUC低于Sparse Label Couplings的0.926030，这暗示在数据分布非平稳场景下，因果纯度与预测精度之间存在权衡。

从方法设计看，DARC与CDCL同属因果去偏路线，但处理机制不同。CDCL针对单一混淆源进行干预，而DARC通过双流架构同时处理非病理混杂与病理共现。DARC引入像素级混杂标注，解决了CDCL等依赖简化假设的精度瓶颈。然而，DARC的融合权重 $\lambda$ 初始化依赖共现统计，若训练数据中混杂分布存在偏差，可能引入新的数据偏差。这种对数据质量的依赖，是否限制了其在跨机构部署中的泛化能力，论文未给出回答。

## 总结

DARC旨在解决CXR分类中因病理共现与非病理混杂导致的捷径学习问题。现有方法因缺乏像素级混杂标注及统一因果框架，无法同时解耦两类混淆源。DARC通过构建CheXconf数据集与双流因果架构，实现了后门调整与反事实推理的协同，在CheXpert上取得0.907 mAUC，优于单一去偏基线。其边界在于分类精度低于纯统计依赖建模SOTA，且融合权重对数据分布敏感。当训练数据中混杂变量分布发生显著偏移时，基于共现统计初始化的因果修正强度 $\lambda$ 是否仍能保持有效，论文未给出回答。
