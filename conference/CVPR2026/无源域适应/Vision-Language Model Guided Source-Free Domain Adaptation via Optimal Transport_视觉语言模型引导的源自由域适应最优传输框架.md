# CVPR2026最新论文 ｜Vision-Language Model Guided Source-Free Domain Adaptation via Optimal Transport ｜视觉语言模型引导的源自由域适应最优传输框架

研究机构：西安电子科技大学

作者：Shuo Han、Xu Tang、Jingjing Ma 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_a77b974bb4bc)

> 无源域适应（SFDA）旨在解决隐私约束下源数据不可访问时的跨域泛化难题，但传统自训练范式因确认偏置导致大域差距下性能急剧退化。现有引入外部先验的方法多依赖硬标签伪监督，噪声干扰严重。VSFOT 将适应过程重构为语义最优传输问题，通过双向蒸馏机制实现视觉语言模型（VLM）与任务模型的协同优化。该方法在大规模基准上表现优异，但在中等规模数据集上显著落后于多模型协同方案，其单 VLM 语义覆盖能力是否构成性能瓶颈尚存疑。

## 研究背景

当预训练模型面对分布偏移的目标域时，其预测往往充满噪声。若直接利用这些噪声预测作为自训练信号，模型会陷入确认偏置，错误预测被不断强化直至不可逆。为打破这一闭环，研究者引入视觉语言模型（VLM）提供域不变语义先验。然而，直接利用 VLM 预测进行硬标签监督，在大域差距下同样面临噪声干扰，导致适应性能下降。

SFDA 的核心矛盾在于缺乏源域监督信号的同时需克服源模型偏差。主流自训练路线（如 SHOT）依赖目标域几何结构，受限于源模型判别力；生成式路线（如 DDA）通过扩散模型修正特征，但计算开销大且易丢失细节。VSFOT 的切入点在于：不依赖伪标签，而是利用 VLM 的语义先验构建软对齐机制，通过最优传输（OT）在特征空间与预测空间联合优化，从根本上规避硬标签噪声。

## 核心方法

### 方法参照系

标准 SFDA 流程通常利用源模型分类器权重作为类原型，通过对比学习或聚类对齐目标特征。VSFOT 的关键差异在于：它不直接对齐特征，而是将对齐重构为 OT 问题，并解耦了用于模型优化的成本矩阵与用于计算传输计划的先验矩阵，引入 VLM 作为外部语义锚点。

### VLM 引导的模型对齐

传统原型对齐仅关注特征相似度，忽略类间语义关系，导致大域差距下映射错配。VSFOT 采用联合分布最优传输（JDOT）原则，定义目标样本 $x_i^t$ 与原型 $w_j$ 的传输成本为特征空间余弦距离与预测空间交叉熵的加权和：

$$ C^m_{i,j} = \alpha \cdot d(z^m_i, w_j) + L(q^m_i, y_j) $$

其中 $z^m_i = f(x_i^t)$ 为任务模型特征，$q^m_i$ 为模型预测概率，$\alpha$ 为归一化系数。该公式的物理含义是：同时约束特征接近原型且预测分布接近真实标签，实现语义一致的对齐。

### 双向蒸馏与传输计划解耦

仅依赖模型自身预测的 OT 成本在大域差距下不可靠。VSFOT 将传输计划计算与模型优化解耦：使用 VLM 预测概率 $q^v_i$ 构建先验成本矩阵 $C^v_{i,j} = \alpha \cdot (1 - q^v_{i,j}) + L(q^m_i, y_j)$，通过 Sinkhorn 算法求解传输计划 $\Gamma^*$。同时，引入模型引导 VLM 适应（MGVA）阶段，将模型高置信 Top-k 预测 $\tilde{q}^m_i$ 通过 KL 散度蒸馏至 VLM 轻量适配器：

$$ L_{VLM} = \frac{1}{|B|} \sum_{x_i \in B} KL(\tilde{q}^m_i \| q^v_i) $$

该设计动机在于：VLM 缺乏任务特定知识，通过反向蒸馏使其感知目标域上下文，形成 VLM 指导模型、模型精炼 VLM 的闭环，增强引导鲁棒性。

## 实验评估

VSFOT 在 Office-31、Office-Home、VisDA-C 和 DomainNet-126 四个基准上评估，基线覆盖 SHOT、NRC 等经典 SFDA 方法及 DIFO、ProDe 等 VLM 引导方法，但缺失 DDA、DPTM 等生成式模型基线。

| 数据集 | 方法 | 准确率 (%) |
| :--- | :--- | :--- |
| Office-31 | VSFOT | 92.66 |
| Office-31 | DIFO | 92.45 |
| Office-Home | VSFOT | 83.42 |
| Office-Home | DIFO | 82.57 |
| VisDA-C | VSFOT | 96.29 |
| VisDA-C | DIFO | 96.35 |
| DomainNet-126 | VSFOT | 98.26 |
| DomainNet-126 | DIFO | 95.71 |

VSFOT 在 DomainNet-126 上以 98.26% 大幅领先 DIFO 的 95.71%，但在 VisDA-C 上略低于 DIFO 的 96.35%，作者归因于缺乏错误纠正机制导致少数类混淆误导训练。

| 消融组件 | Office-Home (%) | DomainNet-126 (%) |
| :--- | :--- | :--- |
| Source | 59.92 | 60.60 |
| + LAlign | 81.46 | 81.19 |
| + LVLM | 84.17 | 82.44 |
| + LCon + LIM | 85.34 | 82.63 |

消融显示，引入 OT 对齐损失 $L_{Align}$ 带来 21.54% 和 20.59% 的提升，验证了 VLM 先验与任务知识结合的有效性；反向蒸馏 $L_{VLM}$ 进一步贡献 2.71% 和 1.25%，证明双向机制的必要性。

评估协议未报告置信区间，且未统一骨干网络与预训练数据，性能差异可能部分源于架构差异。代码已开源，但缺乏计算效率与隐私泄露评估，限制了其在资源受限场景的部署可行性分析。

## 关联研究分析

从问题动机看，VSFOT 与 CoMA 均针对大域差距下的确认偏置，但 CoMA 采用 CLIP 与 BLIP 双模型协同以弥补单 VLM 语义覆盖不足，而 VSFOT 依赖单 VLM 加 OT 软对齐。VSFOT 在 Office-Home 上 83.42% 的准确率显著低于 CoMA 的 90.7%，这一差距暗示单 VLM 在复杂风格差异下的语义锚点能力有限，而非 OT 机制本身的缺陷。

从方法设计看，VSFOT 与 DIFO 同属 VLM 引导路线，但 DIFO 依赖 VLM 生成伪标签进行硬监督，VSFOT 则通过 OT 解耦成本与计划计算实现软对齐。VSFOT 在 DomainNet-126 上的 2.55% 优势表明，软对齐在高维标签空间下比硬标签更鲁棒，但在 VisDA-C 上的微小劣势（96.29% vs 96.35%）提示，当域差距极端且类别混淆严重时，缺乏显式错误纠正的 OT 机制可能不如伪标签筛选有效。

## 总结

VSFOT 旨在解决 SFDA 中自训练确认偏置与 VLM 硬标签噪声的双重困境，其切入点在于利用 OT 的软对齐特性解耦语义先验与模型优化，并通过双向蒸馏增强 VLM 的任务感知。该方法在 DomainNet-126 上达到 98.26% 的准确率，验证了 OT 机制在高维复杂分布下的鲁棒性。然而，其在 Office-Home 上 83.42% 的表现显著落后于多模型协同方案，暴露了单 VLM 语义覆盖的局限。当目标域风格差异复杂且类别语义模糊时，单 VLM 引导的 OT 对齐是否仍能保持优势，论文未给出回答。
