# CVPR2026最新论文 ｜Forging a Dynamic Memory: Retrieval-Guided Continual Learning for Generalist Medical Foundation Models ｜检索增强医学视觉语言模型持续学习

研究机构：复旦大学、中南大学

作者：Zizhi Chen、Yizhen Gao、Minghao Han 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.13072)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.13072)

> 医学视觉语言模型（VLM）在跨域增量任务中面临灾难性遗忘与预训练知识退化的双重困境，传统静态回放或生成式参考集无法适配医学影像“域内同质、域间异质”的簇状分布。本文切入点在于利用检索增强生成（RAG）构建动态参考集，通过多阶段检索与动态Fisher权重保护，在缺乏原始预训练数据访问权限下维持零样本能力。该方法在自建MGTIL基准上取得SOTA性能，但其泛化性受限于自建数据集，且未验证在标准VLP基准上的迁移效果。

## 研究背景

医学影像的分布特性与自然图像存在本质差异：自然图像域内形态多变但域间共享低级特征，呈网状结构；而医学影像域内高度同质，域间因成像原理不同呈簇状离散分布。这种拓扑差异导致持续学习（Continual Learning, CL）中，模型需同时实现域内细粒度特征迁移与跨越巨大的域间差距。此外，CL引发的灾难性遗忘不仅表现为下游任务性能下降，更会导致预训练知识退化，直接削弱模型的零样本泛化能力，这在缺乏大规模标注数据的医学场景中尤为致命。

现有医学CL研究多聚焦于单域或基础模型训练，缺乏跨域综合基准。主流方法如ZSCL通过外部数据蒸馏保留零样本能力，GIFT利用生成模型替代存储数据，但这些方法依赖静态采样或生成，难以捕捉医学数据复杂的簇状分布与动态域内偏移。本文提出PRIMED框架，将RAG引入CL，通过实时动态检索构建个性化参考集，结合对比知识迁移与动态Fisher权重保护，解决医学VLM在跨域增量学习中的记忆保持与知识对齐难题。

## 核心方法

### 方法参照系

医学CL的标准流程通常基于正则化、蒸馏或回放策略，在任务序列 $T_1, \dots, T_n$ 上顺序微调。通用CL假设数据分布平滑，参考集通过均匀采样或固定生成获得。本文问题的关键差异在于：医学数据分布呈簇状离散，且预训练数据不可访问，要求参考集具备细粒度、动态适配域内偏移与域间跳跃的能力，静态参考集在此失效。

### 动态多阶段检索机制

传统回放依赖固定参考集，无法响应任务序列中的域内细微变化。PRIMED构建18M规模的多模态检索数据库与3,000条层级化问题池，通过动态多阶段检索生成实时参考集。对于任务 $T_i$，问题池 $M_i$ 包含任务特定、域相关及通用查询。每个查询 $m$ 嵌入后与数据库向量计算余弦相似度，通过动态阈值 $\tau_m$ 筛选候选集，再经VLM重排与BM25词法门控，最终通过动态虹吸（Dynamic Siphon）机制按任务、域、通用三级比例采样，生成个性化参考集 $C_i$。该机制使参考集分布从均匀转向实时多模态，精准匹配医学数据的簇状结构，解决静态采样无法捕捉域内偏移的问题。

### 对比知识迁移与动态Fisher权重保护

蒸馏方法中，教师模型（上一任务状态）同样受遗忘影响，导致跨模态知识解耦。PRIMED引入对比知识迁移（CKT）损失，计算当前模型 $\theta_i$ 与教师 $\theta_{i-1}$ 在检索数据上的相似度矩阵KL散度，强制保持跨模态对齐：

$$ \mathcal{L}_{CKT} = \frac{1}{B} \sum_{k=1}^{B} \left[ D_{KL}(p_{i,k} \| p_{i-1,k}) + D_{KL}(q_{i,k} \| q_{i-1,k}) \right] $$

同时，为保留嵌入空间全局结构，引入跨模态一致性（CMC）损失，将当前模型相似度矩阵与单位矩阵对比。针对参数重要性动态变化问题，PRIMED提出动态Fisher权重保护（DFG），利用Fisher信息矩阵对角线 $W_{\theta_i^{(j,t)}}$ 动态评估权重重要性，构建自适应L2正则化损失：

$$ \mathcal{L}_{DFG} = \sum_{j} W_{\theta_i^{(j,t)}} (\theta_i^{(j)} - \theta_{pre}^{(j)})^2 $$

该设计使正则化强度随训练进程动态调整，兼容全局结构保持与细粒度特征保留，解决固定EWC无法适应蒸馏与对齐偏移的问题。

## 实验评估

实验基于BiomedCLIP骨干，在自建MGTIL基准（HieraMedTransfer与MedXtreme）上进行，覆盖X-ray、病理、眼底等9个域。基线涵盖LwF、iCaRL、ZSCL、GIFT等经典CL方法，但未对比FaNe、SISTA等最新VLP方法（因任务不同）。在MedXtreme Order I上，PRIMED_dyn取得68.6% ACC、87.4% AUC，较ZSCL的53.7% ACC提升14.9%；在HieraMedTransfer Order II上，PRIMED_dyn Last指标达81.2%，较基线提升14.4%。

| 方法 | MedXtreme Order I ACC | MedXtreme Order I AUC | HieraMedTransfer Order II Last |
| :--- | :--- | :--- | :--- |
| Zero-shot | 9.9 | 61.2 | 53.0 |
| ZSCL | 53.7 | 79.9 | 77.6 |
| GIFT | 66.0 | 86.6 | 75.2 |
| PRIMED_dyn | 68.6 | 87.4 | 81.2 |

消融实验表明，动态检索（PRIMED_dyn）较均匀检索（PRIMED_uni）在MedXtreme Order I ACC上提升2.4%，在HieraMedTransfer Order II Last上提升4.2%，验证了动态分布调节对域间差距桥接的有效性。Fisher权重保护（DFG）较固定L2基线在BWT指标上改善7.3%，证明动态重要性评估对缓解遗忘的关键作用。

评估边界方面，MGTIL为自建基准，与CT-RATE、CheXpert等标准VLP基准无重叠，无法直接比较SOTA性能。实验未报告置信区间，且仅在4-NVIDIA A6000 GPU上验证，超参数细节见附录。代码已开源，但检索数据库构建依赖PubMed数据清洗流程，复现成本较高。

## 关联研究分析

从问题动机看，PRIMED与ZSCL均旨在保留零样本能力，但ZSCL依赖静态外部数据蒸馏，无法响应医学数据的簇状分布与动态域内偏移；PRIMED通过RAG实时检索，使参考集分布随任务序列动态调整，更适配医学影像“域内同质、域间异质”的特性。这一差异源于任务特性：医学数据缺乏自然图像的平滑过渡，静态参考集易导致域间知识混淆。

从方法设计看，PRIMED与GIFT同属参考集构建路线，但GIFT利用生成模型合成数据，存在幻觉风险且可控性低；PRIMED基于真实PubMed数据检索，通过多阶段重排与门控确保参考集质量，避免生成式方法的语义漂移。然而，PRIMED的检索延迟与数据库维护成本在临床实时部署中是否可接受，论文未给出量化评估。

## 总结

PRIMED解决的核心矛盾是医学VLM在跨域增量学习中，静态参考集无法适配簇状分布导致的遗忘与知识退化。其切入点在于利用RAG构建动态参考集，通过多阶段检索与动态Fisher权重保护，在缺乏预训练数据访问权限下维持零样本能力。实验在自建MGTIL基准上验证了PRIMED_dyn在MedXtreme Order I ACC上较ZSCL提升14.9%的有效性。然而，该方法的边界在于：MGTIL为自建基准，未验证在标准VLP基准上的泛化性；检索数据库构建依赖特定数据清洗流程，复现成本高。当支持集规模扩大或域间差距进一步增大时，动态检索的边际收益是否递减，论文未给出回答。
