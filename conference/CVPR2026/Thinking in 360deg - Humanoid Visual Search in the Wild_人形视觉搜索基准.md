# CVPR2026最新论文 ｜Thinking in 360deg: Humanoid Visual Search in the Wild ｜人形视觉搜索基准

作者：Heyang Yu、Yinan Han、Xiangyu Zhang 等 12 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_259b1efbe341)

> 具身智能体在复杂真实环境中如何像人类一样主动搜索目标或路径，是连接感知与行动的关键缺失环节。现有方法将视觉搜索局限于静态2D图像或封闭家庭场景，无法处理野外密集环境的3D空间推理与闭环交互。本文提出人形视觉搜索（Humanoid Visual Search, HVS）任务，利用360°全景图作为轻量级模拟器，通过头部旋转动作实现感知-动作闭环。该工作构建了首个野外场景具身搜索基准，验证了后训练的有效性，但路径搜索的低成功率揭示了空间常识的深层瓶颈。

## 研究背景

人类视觉系统通过头部（cephalomotor）与眼部（oculomotor）的协同控制，在360°范围内高效搜索信息。头部负责探索未知区域，眼部通过扫视（saccades）利用已见内容，这种嵌套机制最小化了感官冗余。然而，当前基于多模态大语言模型（Multimodal Large Language Models, MLLMs）的视觉搜索方法主要处理单张静态低分辨率图像，后续操作仅限于裁剪或放大等计算行为。

现有具身AI平台受限于感知真实度不足或场景局限于家庭室内，无法代表需要高级视觉空间推理的密集、杂乱环境。主流导航方法依赖3D仿真器或真实硬件，构建成本高且难以扩展至野外场景。本文切入点在于利用单张360°全景图作为轻量级模拟器，将全身运动抽象为原子化的头部旋转动作，从而在无硬件约束下研究具身视觉搜索的核心认知过程。

## 核心方法

### 方法参照系

本文问题属于具身导航中的感知决策环节，但摒弃了传统导航中依赖3D地图或低层运动控制器的流程。关键差异在于：环境表示从3D网格简化为单张全景图，动作空间从连续轨迹生成简化为离散的头部旋转角，任务目标从到达目标点简化为定位目标方向。

### 全景图闭环交互机制

传统视觉搜索在固定画布上进行，缺乏交互性。本文引入全景图作为交互式环境，智能体初始视野狭窄，通过旋转动作更新视觉输入，形成闭环。动作空间定义为旋转 $a^{rot}_t = (\Delta\phi, \Delta\gamma)$ 和提交 $a^{sub}_t$，其中 $\phi$ 为方位角，$\gamma$ 为极角。

$$
\phi_{t+1} = \phi_t + \Delta\phi, \quad \gamma_{t+1} = \gamma_t + \Delta\gamma
$$

该公式描述了头部旋转如何更新智能体的观测视角，使得每次动作都能获取初始视野外的新信息，解决了静态图像方法无法改变视角的根本缺陷。

### 双任务方向预测框架

HVS包含人形物体搜索（Humanoid Object Search, HOS）和人形路径搜索（Humanoid Path Search, HPS）。HOS要求定位目标物体并聚焦，HPS要求识别可通行路径并对齐身体朝向。任务目标形式化为寻找最优方向 $(\phi^*, \gamma^*)$ 以最大化任务成功概率。

$$
(\phi^*, \gamma^*) = \arg \max_{\phi, \gamma} P(r_s | o_{\phi,\gamma}, x)
$$

此公式将视觉搜索转化为条件概率最大化问题，其中 $x$ 为语言指令，$o_{\phi,\gamma}$ 为当前观测。该设计将复杂的导航轨迹规划解耦为关键决策点的方向预测，降低了计算复杂度，同时保留了具身交互的本质。

## 实验评估

实验在自建H∗Bench上进行，包含约3,000个标注任务实例和12,000个搜索片段，覆盖机场、超市等12个国家的外野场景。基线涵盖开源模型（如Qwen2.5-VL、Gemma-3）和闭源模型（如GPT-4o、Gemini2.5-Pro），但缺乏传统ObjectNav方法（如LFG、VLFM）的对比，因任务定义不同。

| 方法 | HOS Overall (%) | HPS Overall (%) |
| :--- | :--- | :--- |
| Qwen2.5-VL-3B-Instruct | 14.83 | 6.44 |
| + SFT (HVS-3B) | 40.83 | 23.00 |
| + RL (HVS-3B) | 47.38 | 24.94 |
| Gemini2.5-Pro | 31.96 | 33.00 |
| GPT-4o | 19.75 | 23.69 |

SFT和RL显著提升了开源模型性能，HVS-3B在HOS上从14.83%提升至47.38%，HPS从6.44%提升至24.94%。然而，即使经过后训练，HPS的成功率仍远低于HOS，且低于Gemini2.5-Pro的33.00%，表明路径搜索对空间常识的要求更高。

消融实验显示，SFT提供了基础的行为先验，而RL进一步细化了探索策略。在HOS中，RL相比SFT提升了6.55个百分点（40.83% → 47.38%），但在HPS中仅提升1.94个百分点（23.00% → 24.94%）。这种差异暗示RL在物体定位上的增益大于路径规划，可能因为路径搜索涉及更复杂的3D约束和社会空间规范，难以通过简单的奖励信号优化。

评估协议基于方向容差（HOS: $\tau_\phi=30^\circ, \tau_\gamma=20^\circ$; HPS: $\tau_\phi=10^\circ$），未报告置信区间。代码未公开，但训练框架（LLaMA-Factory, VAGEN）和模型权重部分开源。主要局限在于基准规模较小（12k episodes），且缺乏跨基准泛化证据，无法直接比较与现有导航SOTA的性能。

## 关联研究分析

从问题动机看，本文与V∗等MLLM视觉搜索方法共享利用世界知识增强泛化的思路，但V∗局限于静态2D图像，缺乏交互性。本文通过全景图闭环解决了“非交互”和“无具身”两大缺陷，但代价是放弃了3D几何结构的显式表示。这种简化是否足以支撑复杂环境中的空间推理，尤其是当目标被遮挡或需要多步路径规划时，论文未提供深入分析。

从方法设计看，本文与PIGEON等分层导航方法均采用高层推理+低层执行的架构，但PIGEON依赖低层规划器执行连续轨迹，而本文仅输出头部旋转角。这种差异源于任务定义：HVS聚焦于感知决策点，而非完整导航。然而，缺乏低层运动控制意味着无法验证方向预测在实际运动中的鲁棒性，例如当预测方向与可通行路径冲突时，智能体如何调整？这一盲区限制了方法向真实机器人部署的迁移潜力。

## 总结

本文核心矛盾在于如何在无硬件约束下实现具身视觉搜索的闭环推理。切入点是利用360°全景图作为轻量级模拟器，将全身运动抽象为头部旋转，从而绕过3D仿真器的高成本。方法上，通过SFT和RL两阶段后训练，提升了MLLM在野外场景中的搜索能力，HVS-3B在HOS上达到47.38%的成功率。然而，HPS仅24.94%的低成功率暴露了模型在空间常识和社会规范理解上的深层缺陷。当路径搜索涉及复杂3D约束时，仅靠方向预测是否足以保证导航安全性，论文未给出回答。
