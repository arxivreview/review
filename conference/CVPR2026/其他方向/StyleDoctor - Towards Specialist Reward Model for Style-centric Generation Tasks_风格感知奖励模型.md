> 风格生成任务的核心矛盾在于，现有奖励模型评估的是美学质量而非风格一致性，导致强化微调无法有效对齐目标风格。本文指出人类偏好奖励模型与风格生成目标存在内在错位，且现有风格编码器缺乏跨模态监督，无法作为有效的奖励函数。StyleDoctor 通过构建大规模风格偏好数据集 SPRData，并基于多模态大语言模型训练专用奖励模型，实现了细粒度的风格一致性评估与生成引导。该方法在风格检索与生成对齐任务上超越了现有基线，但其效果高度依赖下游生成模型的能力，且评估指标仍受限于合成数据的分布偏差。

## 研究背景

当扩散模型生成图像时，如何判断其是否忠实于参考风格？传统方法依赖 CLIP 等编码器计算特征相似度，但这类模型仅捕捉全局风格统计量，无法区分“风格一致”与“内容相似”的细微差异。这种评估能力的缺失导致强化微调（Reinforcement Fine-tuning, RFT）中使用的奖励信号与风格生成目标错位：人类偏好奖励模型优化的是美学质量，而风格生成要求的是与参考图像在色彩、笔触、构图上的严格对齐。

风格生成领域的主流路线是通过扩散模型结合风格注入插件（如 OmniStyle、CSGO）实现可控生成，但这些方法依赖隐式扩散损失训练，未显式建模风格一致性。与此同时，奖励模型在通用生成任务中已证明有效，但直接应用于风格生成时，因缺乏风格先验知识而失效。现有风格感知模型（如 CSD、SigLIP）虽能编码风格特征，但仅基于图像级对比学习，未利用文本-图像跨模态监督，导致在多样化风格提示下的泛化能力受限。StyleDoctor 的切入点在于，将风格感知从“特征编码”转向“偏好判断”，通过多模态大语言模型（MLLM）联合建模图像级风格特征与文本级风格语义，构建能够直接评估风格一致性的奖励函数。

## 核心方法

### 方法参照系

本文问题属于“奖励建模”范畴，但与传统人类偏好奖励模型的关键差异在于：奖励信号需专门针对风格一致性而非美学质量。标准流程是训练一个评分函数 $R(x, y)$ 评估生成结果 $y$ 对条件 $x$ 的偏好，但风格生成要求 $R$ 能区分“风格匹配”与“风格偏离”的细微差异，且需支持文本与图像两种风格条件。

### 风格感知奖励数据集构建

设计动机：现有风格数据集（如 Style30k）仅提供风格分类标签，缺乏成对的风格化结果，无法训练模型区分“高质量风格化”与“低质量风格化”。SPRData 通过构建四元组样本解决此问题：每个样本包含参考内容图像、参考风格图像、以及两张风格化结果图像（一张风格一致性强，一张弱）。正样本由 OmniStyle 和 CSGO 生成，负样本由 CSGO 降低风格注入强度生成，确保风格一致性差异可被量化。

$$
L_{con} = -\frac{1}{N} \sum_{i=1}^{N} \log \frac{\exp(\text{sim}(z_i, z_i^+)/\tau)}{\sum_{j=1}^{N} \exp(\text{sim}(z_i, z_j^-)/\tau)}
$$

该对比损失最小化风格一致图像对的嵌入距离，同时最大化不一致图像对的距离，其中 $z_i = E_v(x_i)$ 是视觉编码器提取的风格嵌入，$\tau$ 是温度超参数。通过此损失，模型学习全局风格特征，为后续细粒度偏好判断奠定基础。

### 多模态风格偏好学习

设计动机：仅全局风格特征不足以区分细粒度风格差异（如色彩和谐度、笔触纹理），需引入文本-图像跨模态监督。StyleDoctor 基于 Qwen2.5-VL-3B 架构，将全局风格特征作为特殊风格 token 注入语言模型，与图像 token 和文本 token 联合处理。训练阶段采用交叉熵损失，使模型学习判断输入图像是否与给定风格条件（文本或参考图像）一致，并在多图像比较任务中预测风格一致性更高的图像。

$$
L_{ce} = -\sum_{k=1}^{K} y_k \log \hat{y}_k
$$

该交叉熵损失监督模型输出风格一致性判断（如“图像 2 与参考风格更相似”），其中 $y_k$ 是真实标签，$\hat{y}_k$ 是模型预测概率。通过此损失，模型获得细粒度风格分析能力，能评估色彩、笔触、构图等多维度风格属性，为强化微调提供可解释的奖励信号。

## 实验评估

实验在自建 SPRData 数据集上进行，基线覆盖 CLIP、CSD、SigLIP 等风格编码器及 Qwen-2.5-VL 等 MLLM，但缺失 LoRA 微调方法（如 Balanced Subspace Blending）作为生成基线。

| 方法 | Retri. Acc. | MM Und. Acc. |
| :--- | :--- | :--- |
| CLIP | 53.45 | 46.28 |
| CSD | 62.60 | 53.25 |
| SigLIP | 58.39 | 48.20 |
| Qwen-2.5-VL (3B) | 71.82 | 66.54 |
| StyleDoctor | 75.46 | 71.14 |

StyleDoctor 在风格检索准确率（Retri. Acc.）上达 75.46，优于 Qwen-2.5-VL 的 71.82 和 CSD 的 62.60；在多模态风格理解准确率（MM Und. Acc.）上达 71.14，显著高于基线。这表明 MLLM 架构结合风格专用训练能有效提升细粒度风格感知能力。

消融实验显示，移除全局风格特征学习（GSF）或统一偏好学习（UPL）模块均导致性能显著下降，验证了两者对风格理解与奖励建模的必要性。具体数值未在论文正文中完整列出，但趋势表明全局风格特征提供基础区分能力，而统一偏好学习注入细粒度分析能力。

评估边界方面，SPRData 依赖 OmniStyle 和 CSGO 生成正负样本，其质量上限受限于这些生成模型的能力；评估指标（CSD、GPT-4o）本身存在主观性，且未报告置信区间。代码已开源，但训练细节（如 GPU 数量、训练时长）未在正文中明确，可复现性需依赖补充材料。

## 关联研究分析

从问题动机看，StyleDoctor 与 CleanStyle 均针对风格生成中的“内容泄漏”问题，但解决路径截然不同：CleanStyle 通过 SVD 过滤风格嵌入中的内容信号，属于生成侧的解耦优化；StyleDoctor 通过奖励模型评估风格一致性，属于评估侧的反馈引导。这一差异源于任务定位：CleanStyle 旨在提升单次生成的风格保真度，而 StyleDoctor 旨在优化整个生成过程的风格对齐。根源在于，风格泄漏是生成模型内部特征纠缠的结果，而风格一致性是生成结果与参考条件的匹配度，两者需在不同层面解决。

从方法设计看，StyleDoctor 与 ReNeg 共享“奖励正则化”框架，但奖励源不同：ReNeg 使用人类偏好奖励模型优化负嵌入，StyleDoctor 使用风格一致性奖励模型优化负嵌入。这一差异导致 StyleDoctor 在风格生成任务上更有效，但在通用美学任务上可能不如 ReNeg。根源在于，风格生成对“风格一致性”的敏感度远高于“美学质量”，而人类偏好奖励模型无法捕捉这一细粒度差异。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

StyleDoctor 要解决的核心矛盾是风格生成中奖励信号与风格一致性目标的错位。现有人类偏好奖励模型优化美学质量，风格编码器缺乏跨模态监督，均无法提供有效的风格一致性反馈。StyleDoctor 通过构建大规模风格偏好数据集 SPRData，并基于 MLLM 训练专用奖励模型，实现了细粒度风格一致性评估与生成引导。实验证明其在风格检索与生成对齐任务上超越现有基线，Retri. Acc. 达 75.46，MM Und. Acc. 达 71.14。但本文的边界在于，SPRData 的质量受限于生成模型能力，且评估指标存在主观性。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
