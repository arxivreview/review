# CVPR2026最新论文 ｜HSI-GPT2: A Dual-Granularity Large Motion Reasoning Model with Diffusion Refinement for Human-Scene Interaction ｜双粒度运动推理大模型

研究机构：清华大学

作者：Yuan Wang、Xiang Li、Yali Li 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_e15dd05b76dd)

> 人-场景交互合成（Human-Scene Interaction Synthesis, HSI）旨在生成物理合理且语义一致的人体运动，但现有统一大模型受限于单粒度编码与纯监督微调，难以兼顾高层语义推理与低层物理保真。HSI-GPT2 通过双粒度运动分词器解耦语义与细节，并引入扩散解码器与强化学习思维链，实现了从被动模仿到主动推理的跨越。该方法在语义对齐与生成多样性上显著优于前代，但其对复杂几何场景的穿透抑制能力尚未在最新基准上得到验证。

## 研究背景

当统一多模态大模型（MLLM）尝试将人体运动作为语言 Token 处理时，单一重建导向的向量量化自编码器（VQVAE）往往过度拟合低频运动细节，而丢失了与文本对齐的高层语义抽象。这种表示层面的粒度缺失，导致模型在面对“先向右走再蹲下”等组合指令时，无法进行因果推理，仅能输出机械的轨迹拼接。解决这一矛盾需要一种能同时保留语义抽象与关节级动态的表示机制，以及一种能弥补离散 Token 解码物理缺陷的生成架构。

HSI 领域的核心矛盾在于物理一致性与语义对齐的冲突：扩散模型虽能生成多样运动，但易产生场景穿透；而硬物理约束往往牺牲动作自然度。早期工作如 HSI-GPT 虽建立了场景-运动-语言统一架构，但其单粒度码本与纯自回归解码限制了跨任务泛化能力。随着大语言模型在数学与代码推理中的成功，将强化学习（RL）引入运动生成成为新趋势，但如何设计可验证的物理-语义奖励以驱动长时程推理，仍是该领域未解的关键问题。

## 核心方法

### 方法参照系

本文问题属于“LLM 推理+扩散精炼”路线，其标准流程为：LLM 解析文本意图生成离散 Token，解码器将 Token 映射为连续运动。本文的关键差异在于，传统流程中 LLM 直接输出运动 Token 并由 VQVAE 解码，而本文将运动表示解耦为语义与细节两层，并引入扩散模型替代 VQVAE 作为最终解码器，以弥合离散推理与连续物理生成之间的鸿沟。

### 双粒度运动分词器（DMoTok）

针对单粒度 VQVAE 偏向低频细节而忽略语义抽象的失效，DMoTok 将运动编码解耦为语义与细节两个独立码本。语义分支通过预训练的 CLIP 风格编码器提取文本对齐的高层特征，细节分支则整合语义与局部动态以恢复时间平滑性。量化过程定义为：

$$ \hat{Z}_{sem}, I_{sem} = \arg\min_{k \in \{1,...,K\}} \| Z_{sem} - C_{sem}[k] \| $$

该公式通过最近邻搜索将连续语义特征映射到离散码本，确保高层意图的可解释性。细节分支采用类似机制，但输入包含语义量化特征以维持上下文一致性。这种双词汇设计使 LLM 能同时理解“做什么”（语义）与“怎么做”（细节），解决了单一码本在组合指令下语义漂移的问题。

### LLM-扩散混合架构与 GRPO 强化学习

为克服 VQVAE 直接解码导致的物理伪影，本文采用连续输入、离散输出的混合架构：LLM 输出语义与细节 Token，扩散解码器在潜空间去噪生成运动。扩散过程建模为马尔可夫噪声过程：

$$ q(Z_t | Z_{t-1}) = N(\sqrt{\alpha_t}Z_{t-1}, (1 - \alpha_t)I) $$

该公式描述了运动潜变量逐步加噪的过程，反向去噪则确保生成运动符合生物力学约束。为提升推理能力，本文引入运动思维链（MoCoT）数据引擎，并通过组相对策略优化（GRPO）进行强化学习微调。GRPO 的目标函数为：

$$ J_{GRPO} = E \left[ \frac{1}{G} \sum_{i=1}^G \min \left( \frac{\pi_\theta(o_i)}{\pi_{old}(o_i)} \hat{A}_i, \text{clip} \left( \frac{\pi_\theta(o_i)}{\pi_{old}(o_i)}, 1-\epsilon, 1+\epsilon \right) \hat{A}_i \right) - \beta D_{KL}(\pi_\theta \| \pi_{ref}) \right] $$

其中 $\hat{A}_i$ 为归一化优势值，奖励函数包含格式一致性、运动保真度与语义对齐三项。该机制使模型从被动模仿 SFT 数据转向主动探索，通过可验证奖励强化长时程逻辑推理，解决了纯监督微调无法泛化到未见场景的问题。

## 实验评估

实验在 HumanML3D、HUMANISE 及 Novel Evaluation Set 上进行，基线覆盖 MotionGPT 系列、HSI-GPT 及 Afford-Motion，但缺失 SceMoS、DeSeG 等 2026 年最新几何接地方法。在 HumanML3D 运动生成任务中，HSI-GPT2 的 FID 为 0.139±.002，R-Precision Top-3 为 0.835±.003，显著优于 HSI-GPT 的 0.187±.004 与 0.788±.004，表明其在语义对齐与运动真实性上具有优势。

| 方法 | FID ↓ | R-Precision Top-3 ↑ | MM Dist. ↓ | Diversity → |
| :--- | :--- | :--- | :--- | :--- |
| HSI-GPT | 0.187±.004 | 0.788±.004 | 3.058±.013 | 9.845±.026 |
| HSI-GPT2 | 0.139±.002 | 0.835±.003 | 2.708±.009 | 10.489±.048 |

消融实验显示，双粒度码本将 R-Precision 从 0.788 提升至 0.809，FID 从 0.193 降至 0.160；连续输入变体相比离散输入，Contact Rate 从 94.97% 提升至 97.98%，证明量化误差抑制对物理保真度的关键作用。GRPO 训练中，格式奖励在 70 步后饱和，随后模型聚焦于语义对齐与保真度奖励，表明 RL 优化有效引导了推理行为。

评估边界方面，论文未报告计算效率与实时性指标，且 Novel Evaluation Set 仅含 16 个场景，OOD 泛化验证规模有限。代码未开源，超参数细节（如扩散步数、GRPO 组大小）未完全披露，可复现性存在一定障碍。

## 关联研究分析

从问题动机看，HSI-GPT2 与 DeSeG 均致力于解耦语义与几何，但 DeSeG 侧重将碰撞感知内化到扩散目标函数，强调物理约束的显式建模；而 HSI-GPT2 侧重通过 LLM 推理实现语义规划，物理一致性依赖扩散解码器与 RL 奖励的隐式约束。这一差异源于任务特性：DeSeG 面向静态场景下的精确接触生成，而 HSI-GPT2 面向动态场景下的长时程任务规划。HSI-GPT2 未对比 DeSeG 的穿透率指标，其物理约束的有效性在复杂遮挡场景下是否优于显式几何接地方法，论文未给出回答。

从方法设计看，HSI-GPT2 与 SceMoS 同属解耦架构，但 SceMoS 采用 BEV 特征与高度图进行几何接地 Token 生成，计算开销低但依赖渲染质量；HSI-GPT2 采用 CLIP 预训练与扩散解码，语义对齐更强但推理延迟较高。SceMoS 在 TRUMANS 上 FID 为 0.31，而 HSI-GPT2 在 HumanML3D 上 FID 为 0.139，两者基准不同，直接比较需谨慎。HSI-GPT2 的 LLM 推理能力使其在组合指令上更具优势，但 SceMoS 的轻量级设计更适合实时应用。

## 总结

HSI-GPT2 旨在解决统一大模型中语义推理与物理生成的解耦矛盾，通过双粒度分词器与扩散解码器实现从被动模仿到主动推理的跨越。该方法在 HumanML3D 上 FID 0.139 与 R-Precision 0.835 的结果，证明了其在语义对齐与运动多样性上的优势。然而，其物理约束依赖隐式奖励而非显式几何接地，在复杂场景下的穿透抑制能力未经验证。当场景包含大量铰接物体或动态障碍时，GRPO 奖励函数能否有效引导模型避免穿透，论文未给出回答。
