# CVPR2026最新论文 ｜Unified Customized Generation by Disentangled Reward Modeling ｜统一定制生成：跨任务协同解耦范式

研究机构：中国科学技术大学

作者：Shaojin Wu、Mengqi Huang、Yufeng Cheng 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_71920e40d806)

> 现有定制生成任务将主体与风格视为孤立问题，各自在单一任务内尝试分离参考图像中的相关特征，却忽略了“保留主体”与“排除主体”在逻辑上的互补性，导致解耦精度受限。本文提出跨任务协同解耦范式，通过构建主体-风格三元组数据并引入辅助风格奖励，使主体生成任务学习到的特征保留能力反向增强风格生成任务的特征排除能力。该方法在联合任务上实现了主体一致性与风格保真度的同步提升，但其性能增益是否源于数据规模而非协同机制本身，仍需更严格的消融验证。

## 研究背景

当扩散模型接收参考图像作为条件时，图像中蕴含的风格、主体外观、布局等特征在潜空间中高度耦合。若任务仅要求迁移风格，主体外观即构成噪声；反之，若要求保持主体，风格则成为干扰。这种特征纠缠使得模型难以在单一任务内精确区分“需保留”与“需排除”的信号，导致风格迁移时出现主体泄漏，或主体定制时风格残留。解决此问题的关键在于建立一种机制，使模型不仅学会“包含”目标特征，更学会“排除”非目标特征。

早期方法如 InstantStyle 和 CSGO 聚焦于单任务内的解耦，通过调整注意力权重或构建三元组数据来抑制内容泄漏，但这些方法将主体生成与风格生成视为两个独立问题，未利用二者在特征排斥上的互补性。UNO 等主体驱动模型擅长保留主体外观，却缺乏对风格特征的精细控制；而风格驱动模型虽能捕捉笔触与色调，却易将参考图中的主体身份一并迁移。这种孤立优化导致解耦边界模糊，尤其在布局发生变化的复杂场景中，模型难以区分“风格变化”与“主体变形”。本文的切入点在于将主体与风格任务统一于同一模型框架内，利用主体任务中“保留主体”的训练信号，反向强化风格任务中“排除主体”的能力，实现跨任务的协同解耦。

## 核心方法

### 方法参照系

本文问题可置于“条件图像生成中的特征解耦”通用流程下。标准流程通常采用单一任务数据训练，通过编码器过滤或注意力调制分离相关特征。本文的关键差异在于：不再依赖单一任务内的特征分离，而是通过跨任务数据构建与联合训练，利用任务间的特征排斥互补性实现更彻底的解耦。

### 跨任务三元组数据构建

传统三元组数据（如 CSGO）仅包含布局保持的样本，限制了模型对空间变化的适应能力。本文引入布局偏移三元组，包含风格参考 $I_s^{ref}$、去风格化内容参考 $I_c^{ref}$ 和风格化目标 $I_{tgt}$。去风格化专家利用 FLUX.1 Kontext 将风格化图像逆转为真实照片，确保 $I_c^{ref}$ 仅包含主体内容而无风格干扰。VLM 过滤器强制 $I_{tgt}$ 与 $I_s^{ref}$ 风格相似、与 $I_c^{ref}$ 主体一致。这一设计解决了单任务数据中风格与主体纠缠无法彻底分离的问题，为模型提供了明确的“排除”信号。

### 统一同步优化框架

在模型训练阶段，本文采用分层投影器 $M_{Proj}(\cdot)$ 处理 SigLIP 提取的多尺度风格特征 $z_s$，公式为：

$$ z_s = \text{Concatenate}(M_{Proj}(\{c_i\}_{i=1}^N)) $$

其中 $c_i$ 为 SigLIP 第 $i$ 层嵌入，$N$ 为层数。该公式将高层语义与低层细节融合，使模型能同时处理几何变形与笔触细节。内容特征 $z_c$ 由冻结 VAE 编码。训练时，以概率 $p=0.25$ 随机丢弃风格或主体参考，迫使模型在单任务与多任务间切换，学习解耦表示。辅助风格奖励（ASR）定义为：

$$ L_{ASR} = \mathbb{E}[\omega(MRM(I_s^{ref}, \hat{I}_0))] $$

其中 $MRM(\cdot)$ 为 CSD 模型，$\hat{I}_0$ 为生成图像。ASR 通过强化风格相似度，间接提升主体一致性，验证了跨任务互补性假设。

## 实验评估

实验在 USO-Bench 和 DreamBench 上进行，基线覆盖 UNO、InstantStyle、CSGO、DEADiff 等主流方法，但缺乏 HAM、CleanStyle 等无训练或 SVD 过滤方法的对比，可能高估联合优化的优势。

| 任务 | 方法 | CLIP-T | DINO | CSD |
| :--- | :--- | :--- | :--- | :--- |
| 风格驱动 | USO | 0.28 | 0.75 | 0.82 |
| 风格驱动 | InstantStyle | 0.24 | 0.72 | 0.78 |
| 主体驱动 | USO | 0.31 | 0.78 | - |
| 主体驱动 | UNO | 0.29 | 0.76 | - |

USO 在风格驱动任务中 CLIP-T 0.28 优于 InstantStyle 的 0.24，DINO 0.75 高于 0.72，表明联合优化提升了文本对齐与风格保真度。主体驱动任务中，USO 的 DINO 0.78 略高于 UNO 的 0.76，验证了风格任务对主体一致性的正向迁移。

消融实验未提供详细数值，但论文指出布局偏移三元组对主体一致性提升贡献最大，而 ASR 对风格相似度的提升边际收益递减。这一发现暗示，数据多样性比奖励信号对解耦精度的影响更显著。

评估指标涵盖 CLIP-T、DINO、CSD，但未报告计算效率与高分辨率支持。代码开源，但超参数与 GPU 配置未在正文中详述，可复现性依赖补充材料。USO-Bench 为新建基准，缺乏与 StyleBench 等标准基准的直接对比，性能绝对值需谨慎解读。

## 关联研究分析

从问题动机看，本文与 CSGO 同属三元组训练路线，但 CSGO 仅关注风格-内容解耦，而本文将主体视为独立任务，利用其“保留”能力反向增强风格任务的“排除”能力。这一差异源于任务定义：CSGO 将主体视为内容的一部分，而本文将主体与风格视为互补任务。根源在于，主体生成任务中“保留主体”的训练信号，在风格任务中恰好构成“排除主体”的负样本，这种互补性在单任务框架中无法被利用。

从方法设计看，本文与 UNO 同用 DiT 骨干与 LoRA 微调，但 UNO 仅支持主体驱动，而本文引入分层投影器与 ASR，使模型能同时处理风格与主体条件。这一差异源于特征处理：UNO 将参考图像编码为单一条件，而本文将风格与主体分离编码，并通过随机丢弃策略学习解耦。查询侧增强在数据充足时是否仍有增益，论文未给出回答，但 ASR 的引入暗示，在数据有限时，奖励信号对解耦精度的提升可能更显著。

## 总结

本文要解决的核心矛盾是单一任务内特征解耦的精度瓶颈，其切入点在于利用主体与风格任务在特征排斥上的互补性，通过跨任务三元组数据与辅助风格奖励实现协同解耦。方法上，本文构建了布局偏移三元组并引入 ASR，证明了联合优化在主体一致性与风格保真度上的同步提升，USO 在风格驱动任务中 CLIP-T 0.28 优于 InstantStyle 的 0.24。本文的边界在于，其性能增益可能部分源于数据规模而非协同机制本身，且缺乏与无训练方法的对比。当支持集增大到 5-shot 时，跨任务互补性的边际收益是否递减，论文未给出回答。
