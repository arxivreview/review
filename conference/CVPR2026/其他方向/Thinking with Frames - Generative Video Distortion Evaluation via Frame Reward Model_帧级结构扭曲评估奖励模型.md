# CVPR2026最新论文 ｜Thinking with Frames: Generative Video Distortion Evaluation via Frame Reward Model ｜帧级结构扭曲评估奖励模型

研究机构：中国科学技术大学、快手

作者：Yuan Wang、Borui Liao、Huijuan Huang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.04033)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.04033)

> 生成视频评估长期受困于“视觉逼真但结构崩坏”的盲区，现有视频级奖励模型因采样率低且侧重美学，常对肢体变形或网格穿透给出高分。本文切入点在于将评估粒度从视频级下沉至帧级，并针对结构扭曲这一特定维度构建专用奖励模型。通过引入掩码监督微调与成对偏好强化学习，REACT在结构扭曲检测上实现了可解释的归因与精准评分。其价值在于填补了通用评估器在物理结构违规上的空白，但帧级设计是否足以捕捉时序累积导致的动态扭曲，仍存疑。

## 研究背景

视频生成模型在合成复杂运动时，常出现物体结构异常，如肢体缺失、多余或网格穿透。这类缺陷在单帧内表现为空间局部化特征，但在视频级评估中易被整体美学分掩盖。理解本文需把握两个核心概念：结构扭曲（Structural Distortions）指生成视频中物体形状或交互关系的物理违规；帧级奖励模型（Frame-level Reward Model）指以单帧为输入单位，通过推理输出具体缺陷标签与分数的评估机制。前者是评估对象，后者是解决该对象评估失效的技术路径。

主流视频奖励模型如VideoScore2和UnifiedReward，通常以2 fps的低采样率处理视频，侧重视觉质量、运动流畅度与文本对齐。这种视频级范式假设缺陷可通过时序聚合捕捉，但结构扭曲往往在单帧内即可定位，低采样率导致大量关键帧被跳过。此外，图像质量评估模型虽能识别静态伪影，但视频扭曲因时序不一致呈现模糊、碎片化特征，与图像中锐利伪影存在域差距，导致图像评估器直接迁移至视频时性能大幅下降。现有方法在“捕捉稀疏且局部的结构异常”这一环节上存在系统性盲区，导致高分视频仍可能包含严重结构缺陷。

## 核心方法

### 方法参照系

本文问题归属于基于多模态大语言模型（MLLM）的视频奖励模型范畴。标准流程通常以视频片段为输入，通过监督微调（SFT）对齐人类偏好，输出标量分数。本文的关键差异在于将输入单元从视频片段改为单帧，并将输出从单一分数扩展为包含归因标签的结构化推理，以解决视频级评估对局部结构缺陷的捕捉盲区。

### 掩码监督微调与域知识注入

SFT阶段的核心挑战在于平衡域知识注入与推理轨迹多样性。常规SFT易使模型过拟合训练集中的思维链（CoT）模式，导致后续强化学习中推理路径单一。本文引入掩码损失机制，在SFT第二阶段仅对归因标签和分数计算损失，而屏蔽推理过程。这一设计迫使模型关注最终判断的准确性，而非复述预设的推理文本，从而保留多样化的推理轨迹供后续优化。

$$
\mathcal{L}_{masked} = \sum_{t \in \{label, score\}} -\log P(o_t | o_{<t}, q)
$$

该公式表明，损失函数仅作用于归因标签和分数token，推理过程token不参与梯度更新，从而在注入结构扭曲识别能力的同时，避免模型对特定CoT路径的过拟合。

### 成对偏好强化学习

GRPO阶段旨在提升模型在缺乏绝对分数标注情况下的偏好对齐能力。由于训练数据仅包含人类偏好对（Pairwise Preference）而非绝对分数，直接计算预测分数与真值的误差不可行。本文基于BTT损失设计成对奖励，将偏好概率转化为连续奖励信号。对于帧对 $\{f_A, f_B\}$，模型生成两组rollout，奖励由格式、归因准确率和偏好三部分组成。

$$
R_{pref} = \frac{1}{1 + e^{-\theta(s_A - s_B)}} \cdot I(y_{gt} = A) + \frac{1}{1 + e^{\theta(s_A - s_B)}} \cdot I(y_{gt} = B)
$$

其中 $s_A, s_B$ 为模型预测的帧分数，$\theta$ 控制平局倾向，$I(\cdot)$ 为指示函数。该公式将离散的偏好关系映射为连续奖励，使GRPO能在无绝对分数标注的条件下，通过组内相对优势优化模型的评分一致性。

## 实验评估

实验在自建REACT-Bench上进行，包含REACT-Video（偏好对齐）和REACT-Frame（扭曲识别）两个子集。基线覆盖视频评估器（VideoScore2, UnifiedReward, VideoReward）、图像评估器（Q-insight, VisualQuality-R1, MagicAccessor）及通用MLLM（Gemini-2.5-Pro, GPT-4o等）。基线选择覆盖了当前主流评估路线，但未包含智能体闭环评估方法如VQQA，这可能限制了在动态优化场景下的对比完整性。

| 模型 | Acc w/ Tie | Acc w/o Tie |
| :--- | :--- | :--- |
| UnifiedReward | 0.416 | 0.701 |
| VideoScore2 | 0.407 | 0.521 |
| Gemini-2.5-Pro | 0.370 | 0.534 |
| REACT | **0.610** | **0.813** |

在偏好对齐任务中，REACT的无平局准确率（0.813）显著高于最强基线UnifiedReward（0.701），验证了帧级设计在结构扭曲维度上的优势。

| 模型 | Distorted F1 | Normal F1 |
| :--- | :--- | :--- |
| MagicAccessor | 0.554 | 0.285 |
| Gemini-2.5-Pro | 0.650 | 0.335 |
| REACT | **0.845** | **0.671** |

在扭曲识别任务中，REACT在扭曲帧和正常帧上的F1分数均大幅领先，特别是正常帧F1从基线的0.335提升至0.671，表明模型有效降低了误报率。消融实验显示，移除SFT阶段导致无平局准确率从0.813降至0.513，移除偏好奖励则降至0.514，证实了掩码SFT和成对奖励对推理多样性和偏好对齐的关键作用。

评估边界方面，REACT-Bench为自建基准，缺乏与VideoGen-Reward-Bench等公开基准的直接数值对比，限制了跨基准的可比性。论文未报告计算效率指标，且动态帧采样机制在长视频中的显存占用未量化。代码未公开，复现需依赖Qwen2.5-VL-7B及GRPO开源库，但具体超参数（如LoRA rank 32, GRPO steps 300）已提供。

## 关联研究分析

从问题动机看，REACT与VideoScore2均基于VLM进行视频评估，但VideoScore2侧重通用质量维度（视觉、运动、文本对齐），而REACT聚焦结构扭曲这一特定物理违规维度。VideoScore2采用视频级输入，依赖时序聚合捕捉缺陷，而REACT采用帧级输入，利用结构扭曲的空间局部性实现更细粒度的定位。这一差异源于任务特性：结构扭曲如肢体变形在单帧内即可判定，无需时序上下文，而运动流畅度则必须依赖时序信息。REACT的帧级设计是对结构扭曲任务特性的精准适配，而非对视频级范式的全面否定。

从方法设计看，REACT与UnifiedReward同属基于人类偏好训练的奖励模型，但UnifiedReward通常采用标量奖励进行SFT，而REACT引入掩码SFT和成对偏好GRPO。UnifiedReward的标量奖励易导致模型过拟合特定分数分布，而REACT的成对奖励通过BTT损失将偏好关系转化为连续信号，更适合缺乏绝对分数标注的场景。此外，REACT的CoT合成管线利用Gemini-2.5-Pro生成推理数据，降低了人工标注成本，而UnifiedReward等通常依赖人工标注的CoT数据。这一设计差异反映了数据效率与模型推理能力之间的权衡，REACT通过自动化数据生成弥补了MLLM在结构扭曲视觉线索捕捉上的不足。

## 总结

REACT旨在解决生成视频评估中结构扭曲被通用指标忽略的核心矛盾。现有视频级奖励模型因采样率低和侧重美学，无法捕捉单帧内的局部结构异常，而图像评估器因域差距无法直接迁移。REACT通过帧级设计、掩码SFT和成对偏好GRPO，实现了结构扭曲的精准识别与可解释归因。实验表明，REACT在REACT-Bench上的无平局准确率达0.813，扭曲帧F1达0.845，显著优于现有基线。其边界在于帧级评估缺乏时序上下文，无法检测闪烁或突然消失等动态扭曲，且自建基准限制了跨基准可比性。当视频中出现依赖时序累积的结构异常时，帧级奖励模型是否仍能保持检测精度，论文未给出回答。
