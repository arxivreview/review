# CVPR2026最新论文 ｜Random Wins All: Rethinking Grouping Strategies for Vision Tokens ｜随机分组策略

研究机构：中国科学院、中国科学院大学

作者：Qihang Fan、Yuang Ai、Huaibo Huang 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.00486)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.00486)

> Vision Transformer 的核心瓶颈在于自注意力机制随 Token 数量呈二次方增长，导致高分辨率图像处理成本极高。现有方案通过精心设计的空间窗口或语义聚类来降低复杂度，但引入了复杂的分组操作，增加了部署难度且未必必要。本文提出一种极简的随机分组策略，通过固定随机张量对 Token 进行排序并等分，替代复杂的分组逻辑。该方法在多个基准上超越了精心设计的基线，但其优势高度依赖于位置编码与多头多样性，在数据受限场景下的鲁棒性存疑。

## 研究背景

当 Vision Transformer 处理高分辨率图像时，Token 数量激增导致自注意力计算量呈 $O(N^2)$ 增长，成为部署的主要障碍。为缓解此问题，主流方法采用 Token 分组策略，将全局注意力限制在局部组内。Swin Transformer 使用非重叠空间窗口，BiFormer 采用双层路由机制，Quadtree 则利用树结构进行层级分组。这些方法虽然降低了复杂度，但分组过程涉及复杂的索引操作或语义计算，不仅增加了推理延迟，还使得模型难以在不同分辨率间灵活迁移。

该领域的核心矛盾在于：如何在降低计算复杂度的同时，不牺牲全局上下文建模能力，并避免引入过高的工程复杂度。现有研究普遍认为，精心设计的分组策略（如基于语义相似性或空间邻近性）是提升性能的关键。然而，这种假设隐含了一个未被充分验证的前提：复杂分组带来的性能增益是否源于分组结构本身，还是源于其他因素（如位置编码或多头机制）。本文切入点在于质疑这一前提，提出是否存在一种更简单、统一的分组方法，能够替代现有的多样化复杂策略，同时保持甚至超越其性能。

## 核心方法

### 方法参照系

本文问题属于高效注意力机制中的 Token 分组子问题。标准流程是：将输入 Token 序列划分为若干组，组内执行自注意力或池化操作。与 Swin Transformer 的空间窗口分组或 BiFormer 的路由分组不同，本文的关键差异在于分组依据完全随机，且分组模式在训练和推理过程中保持固定。

### 固定随机张量生成与排序

设计动机在于消除复杂分组操作带来的计算开销，同时保留分组带来的复杂度降低效果。本文首先根据输入分辨率 $h \times w$ 生成一个随机张量 $P \in \mathbb{R}^{h \times w}$，该张量在生成后固定存储，不随输入图像变化。随后，将 $P$ 按降序排序，并依据排序结果对输入 Token 序列 $X$ 进行重排。重排后的序列 $X_p$ 被等分为若干组，每组内的 Token 执行自注意力。

$$
\text{Sort}(P) \rightarrow \text{Permutation}(\pi) \rightarrow X_p = X[\pi]
$$

这一公式表明，分组过程仅依赖于固定的随机排列 $\pi$，而非动态计算的空间或语义关系。由于 $P$ 固定，不同图像使用相同的分组模式，这确保了模型能够学习到稳定的特征表示，同时避免了每次推理时重新计算分组索引的开销。

### 多头独立随机张量机制

设计动机在于解决随机分组可能导致的头特征同质化问题。在多头注意力中，若所有头使用相同的随机张量 $P$，则各头的分组模式相同，导致特征多样性降低。本文采用 $n$ 个独立的随机张量 $P_1, ..., P_n$，每个头使用不同的 $P_i$ 进行排序和分组。

$$
\text{Sim}(X_m, X_n) = \frac{1}{N} \sum_{i=1}^{N} \cos(X_m[i], X_n[i])
$$

通过为每个头分配独立的随机张量，各头关注不同的 Token 子集，从而增强了头特征多样性。实验表明，当所有头共享单一 $P$ 时，头间相似度显著上升，模型性能下降 1.5-2.3 个点，证实了多头独立随机张量对维持特征多样性的关键作用。

## 实验评估

实验在 ImageNet-1K、COCO、ADE20K 等基准上进行，基线覆盖 Swin、CSwin、BiFormer、PVTv2、Quadtree 等主流分组方法，但未对比线性注意力（如 SoLA-Vision）或递归架构。主实验结果显示，随机分组在相同骨干下显著优于复杂分组。

| 骨干 | 方法 | ImageNet-1K Acc (%) | COCO AP box (%) | ADE20K mIoU (%) |
| :--- | :--- | :--- | :--- | :--- |
| Swin-T | Swin-T | 81.3 | 43.7 | 44.5 |
| Swin-T | Random-Swin-T | 82.7 | 46.0 | 46.8 |
| Swin-B | Swin-B | 83.5 | 46.9 | 51.1 |
| Swin-B | Random-Swin-B | 84.4 | 49.1 | 52.2 |
| BiFormer-S | BiFormer-S | 83.8 | 47.8 | 49.8 |
| BiFormer-S | Random-BiFormer-S | 84.0 | 48.4 | 50.4 |

Random-Swin-B 在 ImageNet-1K 上达到 84.4%，较 Swin-B 提升 0.9 个点；在 COCO 上 AP box 达 49.1%，较 Swin-B 提升 2.2 个点。消融实验揭示了四个关键因素：位置编码、头特征多样性、全局感受野和固定分组模式。移除位置编码导致性能下降 3.7 个点，表明随机分组缺乏局部偏置，高度依赖位置信息补偿。使用单一随机张量导致性能下降 2.2 个点，证实多头独立性的必要性。将全局随机改为区域随机导致性能下降 1.2-1.6 个点，说明全局感受野对性能至关重要。完全随机（每图像独立 $P$）导致性能下降 6.3-6.6 个点，证明固定分组模式是模型学习稳定特征的前提。

评估边界方面，论文未报告 FLOPs 与延迟的详细对比，仅定性提及随机分组更快。代码已开源，但超参数设置未详细披露，可复现性依赖社区验证。

## 关联研究分析

从问题动机看，本文与 Swin Transformer 形成直接对立。Swin 强调空间局部性归纳偏置的重要性，认为窗口注意力能有效捕获局部细节；而本文证明，在引入位置编码和多头多样性的前提下，随机分组可替代空间窗口，且性能更优。这一差异的根源在于：Swin 的性能增益部分源于窗口结构带来的局部偏置，而本文通过位置编码显式补偿了随机分组丢失的局部性，从而解耦了“分组结构”与“性能”的因果关系。

从方法设计看，本文与 BiFormer 的对比揭示了复杂路由机制的冗余性。BiFormer 通过双层路由动态选择 Token 组，旨在平衡局部与全局信息；而本文证明，静态的固定随机分组已能实现类似效果，且计算开销更低。这暗示，动态分组带来的性能增益可能并非来自分组策略本身，而是来自训练过程中模型对固定模式的适应。查询侧增强在数据充足时是否仍有增益，论文未给出回答，但现有证据偏向静态分组在大规模数据下更具优势。

## 总结

本文要解决的核心矛盾是高效注意力机制中复杂分组策略的必要性与计算开销之间的平衡。现有方法通过精心设计的空间或语义分组降低复杂度，但引入了额外的工程负担，且其性能增益来源不明。本文抓住的切入点是：分组策略的复杂性并非性能提升的必要条件，只要满足位置编码、头特征多样性、全局感受野和固定模式四个条件，极简的随机分组即可实现同等甚至更优的性能。本文通过固定随机张量排序和多头独立随机机制，实现了这一目标，在 ImageNet-1K 上较 Swin-B 提升 0.9 个点，在 COCO 上提升 2.2 个点。本文的边界在于，其优势高度依赖大规模预训练数据，在数据受限场景下，随机分组丢失的局部偏置可能无法被位置编码完全补偿。当支持集缩小到 1-shot 时，随机分组是否仍优于引入局部偏置的方法，论文未给出回答。
