# CVPR2026最新论文 ｜Mirai: Autoregressive Visual Generation Needs Foresight ｜视觉自回归生成的前瞻性训练框架

研究机构：日本东京大学、日本国立情报学研究所

作者：Yonghao Yu、Lang Huang、Zerun Wang 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.14671)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.14671)

> 自回归视觉生成依赖严格因果监督，导致模型仅关注局部下一词元预测，难以捕捉全局结构一致性，且收敛速度缓慢。现有方法通过多词元预测或架构修改尝试解决，但前者引入梯度干扰，后者增加推理开销。本文提出 Mirai 框架，通过在训练阶段将内部表征与未来位置的特征对齐，在不改变推理架构的前提下注入“前瞻性”信号。该方法显著加速了 LlamaGen 模型的收敛并提升了生成质量，但其绝对性能仍落后于当前基于 Next-Scale 范式的 SOTA 模型，且未验证在层级生成架构中的适用性。

## 研究背景

自回归（AR）视觉生成将图像离散化为 Token 序列，通过最大化下一词元预测（Next-Token Prediction, NTP）的对数似然进行训练。这种严格因果的监督机制要求模型在每一步仅基于前缀信息预测下一个 Token，导致全局视觉线索需经过数十步才能传播至图像末端。这种局部反馈机制使得模型容易生成局部一致但全局错位（如肢体断裂、结构缺失）的图像，且由于缺乏全局规划信号，训练收敛速度显著慢于扩散模型。

为缓解全局一致性不足，主流路线分为两类：一是修改生成顺序，如 VAR 模型提出的 Next-Scale 预测，通过从粗到细的层级生成提升全局结构；二是增强训练信号，如多词元预测（MTP）试图让模型同时预测多个未来 Token。然而，MTP 在视觉任务中往往因单一隐藏状态需同时支持多个离散 Token 预测而产生梯度竞争，反而损害优化稳定性。本文切入点在于：视觉 Token 依赖双向长程上下文，严格因果训练缺失了“未来”信息，需在不破坏因果解码的前提下，通过训练时的表征对齐引入前瞻性信号。

## 核心方法

### 方法参照系

本文基于 LlamaGen 架构，遵循标准 AR 视觉生成流程：使用 VQ-GAN 将图像编码为离散 Token 序列，训练时最小化 NTP 交叉熵损失。与通用 AR 流程的关键差异在于，本文不修改解码器结构或采样策略，仅在训练阶段引入额外的对齐损失，使内部表征具备对未来结构的感知能力，而推理时完全移除该组件，保持标准因果解码。

### 前瞻性表征对齐

传统 MTP 在输出层直接预测未来 Token，导致离散空间中的目标竞争。本文创新点在于将前瞻性信号注入内部表征层，而非输出层。设计动机是：内部表征是连续向量空间，对齐操作可避免离散 Token 预测的梯度干扰，同时迫使模型在早期层就编码全局结构信息。总损失函数定义为 NTP 损失与前瞻性对齐损失的加权和：

$$ \mathcal{L}_{total} = \mathcal{L}_{NTP} + \lambda \mathcal{L}_{Foresight} $$

其中 $\mathcal{L}_{Foresight}$ 通过余弦相似度最大化 AR 模型内部表征 $h_n$ 与前瞻性特征 $f_n$ 的相似性。前瞻性特征 $f_n$ 来源于两个方向：Mirai-E 使用 AR 模型自身的指数移动平均（EMA）权重，提取未来位置 $j \in N_K^{2D}(n)$ 的显式位置特征；Mirai-I 使用冻结的双向编码器（如 DINOv2），提取当前空间位置的全局上下文特征。这种设计使模型在训练时“看到”未来，但推理时仍保持严格因果，实现了训练加速与生成质量的双重提升。

### 2D 空间布局约束

1D 光栅扫描顺序破坏了图像的二维空间局部性，导致前瞻性信号在序列维度上错位。本文创新点在于将前瞻性对齐约束在 2D 图像网格上。设计动机是：视觉 Token 的空间邻近性比序列邻近性更符合几何直觉，2D 对齐能提供更连贯的空间监督。具体而言，对于位置 $n$，其前瞻性邻域 $N_K^{2D}(n)$ 定义为 2D 网格上距离最近的 $K$ 个未来位置，而非序列上的 $n+1, \dots, n+K$。实验表明，2D 对齐在相同前瞻性 Token 数量下，FID 显著低于 1D 对齐，验证了空间结构对因果建模的增益。

## 实验评估

实验在 ImageNet 256×256 类别条件生成任务上进行，基线包括 LlamaGen-B/L/XL、VAR、DiT 等。本文未对比当前 SOTA 模型如 BAR（FID 1.15）或 IAR2（FID 1.50），主要聚焦于 LlamaGen 骨干下的相对提升。主实验结果显示，Mirai-I 将 LlamaGen-B 的 FID 从 5.34 降至 4.34，收敛速度提升 10 倍；Mirai-E 将 FID 降至 4.49。

| 模型 | 参数量 | Epochs | FID↓ | sFID↓ | IS↑ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| LlamaGen-B | 111M | 300 | 5.34 | 6.93 | 215.7 |
| + Mirai-I | 111M | 300 | 4.34 | 7.13 | 226.8 |
| + Mirai-E | 111M | 300 | 4.49 | 6.78 | 225.7 |
| LlamaGen-L | 343M | 300 | 3.73 | 6.68 | 256.4 |
| + Mirai-I | 343M | 300 | 3.07 | 6.72 | 263.7 |

消融实验揭示了关键设计决策：在内部表征层对齐优于输出层对齐，2D 布局优于 1D 布局。Mirai-I 使用单个前瞻性 Token 效果最佳，因为双向编码器已包含全局信息，额外未来位置会干扰；Mirai-E 使用 3 个前瞻性 Token 效果最佳，因 EMA 与主模型联合更新，过多 Token 导致梯度冲突。这些发现表明，前瞻性信号的来源与数量需匹配编码器的上下文聚合能力。

评估协议采用标准 FID/sFID/IS 指标，使用 ADM TensorFlow 套件计算 50k 样本。局限在于：未报告置信区间，未对比 Next-Scale 架构（如 VAR）下的性能，且绝对 FID 仍高于 SOTA。代码未公开，但提供了 Project Page 链接，超参数（如 $\lambda$、EMA 动量）在附录中详述，可复现性中等。

## 关联研究分析

从问题动机看，本文与 REPA（Representation Alignment）共享“表征对齐”思路，但 REPA 针对扩散模型，蒸馏当前图像的语义特征，而本文针对 AR 模型，注入未来位置的特征。差异根源在于任务特性：扩散模型天然具有双向注意力，缺乏的是语义对齐；AR 模型具有因果掩码，缺乏的是全局规划信号。本文的 2D 对齐机制是 AR 特有的，REPA 未涉及空间布局约束。

从方法设计看，本文与 MTP 形成对比。MTP 在输出层预测多个未来 Token，导致离散空间梯度竞争；本文在内部层对齐连续特征，避免离散预测。差异根源在于监督信号的形式：离散 Token 预测要求模型同时优化多个分类目标，而连续特征对齐仅要求向量空间相似性，优化难度更低。然而，本文未验证在 Next-Scale 架构（如 VAR）中应用 Mirai 是否冗余，因为层级生成本身已隐含部分前瞻性信息。

## 总结

本文核心矛盾是严格因果训练导致的全局一致性不足与收敛缓慢。切入点在于利用训练时的前瞻性信号，通过内部表征对齐而非输出层预测，避免梯度干扰。方法上，提出 Mirai 框架，结合 2D 空间布局与显式/隐式前瞻性源，在不改变推理架构的前提下加速收敛。实验证明，Mirai-I 将 LlamaGen-B 的 FID 从 5.34 降至 4.34，收敛提速 10 倍。边界在于：绝对性能仍落后于 Next-Scale SOTA，且未验证在层级生成架构中的适用性。当 VAR 等 Next-Scale 模型已具备层级前瞻性时，Mirai 的额外对齐是否仍有增益，论文未给出回答。
