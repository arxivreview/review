# CVPR2026最新论文 ｜Memory-Efficient Transfer Learning with Fading Side Networks via Masked Dual Path Distillation ｜掩码双路径蒸馏的内存高效迁移学习

研究机构：北京航空航天大学

作者：Yutong Zhang、Jiaxin Chen、Honglin Chen 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.09088)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.09088)

> 内存高效迁移学习（METL）旨在通过侧边网络隔离梯度以大幅降低训练显存，但现有方法在推理时保留侧边网络，导致延迟增加，违背了高效部署的初衷。MDPD 抓住了“训练时利用侧边网络引导主干，推理时丢弃侧边网络”这一被忽略的解耦点，通过双向知识蒸馏将侧边网络的知识注入主干。该方法在保持参数与内存效率的同时，实现了推理加速与精度保持。其价值在于解决了METL的推理瓶颈，但其在纯语言任务上的精度优势尚未完全确立，且对骨干架构的依赖程度有待进一步验证。

## 研究背景

当预训练模型规模扩大至数十亿参数时，全参数微调不仅计算成本高昂，更因需存储大量中间激活值与梯度而面临显存瓶颈。参数高效微调（PEFT）如LoRA通过冻结主干并注入低秩矩阵解决了参数冗余问题，但反向传播仍需流经整个主干网络，导致训练显存占用依然巨大。内存高效迁移学习（METL）进一步将梯度计算限制在轻量级侧边网络内，主干网络仅参与前向传播，从而显著降低训练内存开销。

METL的核心矛盾在于侧边网络的双刃剑效应：训练时它是显存节省的关键，推理时却成为延迟增加的源头。UniPT、SHERL等主流方法在推理阶段保留侧边网络，导致前向传播路径变长，无法实现零额外推理开销。MDPD的切入点在于将侧边网络定位为“训练时的教师”而非“推理时的组件”，通过知识蒸馏机制将侧边网络学到的任务特定知识反向迁移至主干，使得推理阶段可以完全移除侧边网络，从而在训练内存、推理速度与模型精度之间达成新的平衡。

## 核心方法

### 侧边网络框架与双向蒸馏架构

METL的标准流程是构建与主干平行的侧边网络，仅训练侧边网络参数。MDPD的关键差异在于引入了双向知识蒸馏（Dual Path Knowledge Distillation, DPKD），打破了侧边网络与主干之间的单向依赖。在训练阶段，主干网络（Backbone）与侧边网络（Side Network）交替充当教师与学生。具体而言，主干网络作为特征教师（$T_{fea}$），指导侧边网络学习中间层特征；侧边网络作为Logits教师（$T_{log}$），指导主干网络优化最终输出。这种交替优化机制使得主干网络在训练过程中能够吸收侧边网络的任务知识，为推理时丢弃侧边网络奠定基础。

### 分层特征蒸馏策略

针对编码器结构中浅层与深层注意力模式差异大导致直接特征模仿困难的问题，MDPD提出了分层特征蒸馏（Hierarchical Feature-based Distillation）。在浅层，师生网络注意力图均呈对角线自注意力模式，差异较小，采用直接模仿策略；在深层，注意力模式逐渐发散并聚焦于不同的稀疏关键Token，直接模仿会导致分布失配。为此，MDPD在深层引入掩码生成机制，学生网络不直接模仿教师特征，而是生成掩码以选择性地关注教师特征中的关键部分。

特征蒸馏损失函数定义为：

$$ \mathcal{L}_{fea}^{[l]} = \sum_{i=1}^{N} \sum_{j=1}^{D_B} (b_i^{[l],j} - \phi(s_i^{[l],j}))^2 $$

其中 $\phi(\cdot)$ 为瓶颈投影模块，用于对齐侧边网络特征 $s^{[l]}$ 与主干特征 $b^{[l]}$ 的维度。该公式通过最小化投影后的特征差异，确保侧边网络在低维空间中捕捉主干网络的关键语义信息，同时通过瓶颈结构控制参数量，避免引入全连接层带来的参数膨胀。

## 实验评估

实验在VTAB-1K、GLUE及多个视觉-语言（VL）任务（如Flickr30K、MSCOCO）上进行，基线涵盖Adapter、LoRA、BitFit等PEFT方法以及LST、UniPT、SHERL等METL方法。基线覆盖较为全面，但缺少QLoRA等量化感知PEFT变体，且未对比最新的DoRA等低秩改进方法。

| 方法 | VTAB-1K Mean (%) | GLUE Mean (T5-base) | Flickr30K Rsum |
| :--- | :--- | :--- | :--- |
| LoRA | 74.5 | 85.3 | 59.6 |
| UniPT | 77.9 | 84.3 | 532.9 |
| SHERL | 77.4 | 84.6 | 537.5 |
| MDPD (Ours) | 78.3 | 84.8 | 543.0 |

MDPD在VTAB-1K上取得78.3%的平均准确率，超越UniPT（77.9%）和SHERL（77.4%），但在GLUE上仅以84.8%略微领先SHERL（84.6%），与LoRA（85.3%）相比仍有差距。在VL任务上，MDPD在Flickr30K的Rsum指标上达到543.0，显著优于UniPT的532.9，表明其在跨模态检索任务上的优势更为明显。

消融实验显示，双向蒸馏（B⇆S）策略在Flickr30K上的Rsum为538.1，优于单向Logits蒸馏（S→B）的529.7和单向特征蒸馏（B→S）的531.5，证实了双向机制的必要性。在推理阶段丢弃侧边网络后，MDPD的QPS提升至少44.8%，但精度仅下降约0.9%，验证了“训练时蒸馏、推理时丢弃”策略的有效性。

评估边界方面，论文未报告置信区间，且GLUE任务中T5-large骨干下的性能提升幅度（如CoLA从65.6%提升至66.3%）相对较小，暗示该方法在纯语言任务上的增益可能受限于骨干容量。代码已开源，但超参数搜索范围未在正文中详细披露，复现时需依赖补充材料。

## 关联研究分析

从问题动机看，MDPD与LoRA等PEFT方法的核心差异在于优化目标的不同。LoRA旨在通过低秩分解最小化参数数量，其推理时可通过权重合并实现零延迟，但训练时仍需流经主干，显存开销大。MDPD则聚焦于训练显存优化，通过侧边网络隔离梯度，其推理效率的提升依赖于蒸馏机制而非权重合并。这一差异源于任务特性：PEFT适用于参数受限场景，而METL适用于显存受限场景。MDPD在VL任务上的优势可能源于视觉特征的空间局部性，使得侧边网络能更有效地捕捉局部语义，而纯语言任务的长距离依赖可能削弱了侧边网络的引导作用。

从方法设计看，MDPD与UniPT、SHERL等METL方法的根本区别在于侧边网络的生命周期管理。UniPT和SHERL将侧边网络视为模型的一部分，推理时保留以维持性能；MDPD则将其视为训练辅助工具，推理时丢弃。这一设计选择解决了METL的推理延迟瓶颈，但引入了对蒸馏质量的依赖。若蒸馏不充分，主干网络可能无法完全继承侧边网络的知识，导致精度损失。论文通过分层特征蒸馏缓解了这一问题，但未探讨蒸馏层数选择对性能的影响，也未分析不同骨干架构（如Transformer vs CNN）下该策略的泛化能力。

## 总结

MDPD旨在解决METL方法中训练显存效率与推理速度之间的矛盾。其切入点在于将侧边网络从推理组件转化为训练教师，通过双向知识蒸馏将任务知识注入主干，从而在推理时安全移除侧边网络。该方法在VTAB-1K上取得78.3%的准确率，推理QPS提升44.8%。然而，其在GLUE任务上的精度优势微弱，且对骨干架构的依赖未充分验证。当骨干网络容量有限时，蒸馏能否完全弥补侧边网络移除带来的信息损失，论文未给出明确回答。
