# CVPR2026最新论文 ｜Ar2Can: An Architect and an Artist Leveraging a Canvas for Multi-Human Generation ｜空间规划与身份渲染解耦的多人生成框架

论文原文见 [arXiv](https://arxiv.org/abs/2511.22690)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.22690)

> 多身份图像生成面临的核心困境是模型在单阶段去噪中同时推理空间布局与面部外观，导致身份合并、重复或计数错误。现有区域条件方法依赖人工标注，而端到端扩散模型缺乏显式空间约束，无法区分“谁在哪里”与“谁长什么样”。Ar2Can 提出两阶段解耦架构，由 Architect 模块生成结构化布局，Artist 模块基于该布局进行身份保持渲染，并通过强化学习优化空间锚定奖励。该框架在计数准确性与综合指标上显著优于基线，但其对合成数据的依赖及大规模群体下的控制力衰减仍存疑。

## 研究背景

当扩散模型处理“五个朋友喝咖啡”这类提示时，其潜空间中的去噪过程缺乏显式的空间实例区分机制。这种机制缺失导致模型在生成多人场景时，将不同参考图像的身份特征混合到同一面部区域，或复制同一身份到多个位置。解决此问题的关键概念是空间布局（Spatial Layout），即通过边界框明确每个人物的位置与尺度。然而，直接回归边界框面临两个挑战：框的数量随提示动态变化，且提取计数需要深层语言推理（如解析“两个女孩在一个男人旁边”）。这引出了第二个核心概念：自回归布局生成，利用大语言模型（LLM）的序列生成能力动态输出不定长的布局结构，同时通过连续值回归头输出精确坐标。

多身份生成是身份保持人脸生成（IPFG）领域当前的主要瓶颈。主流路线分为两类：一是区域条件方法（如 GLIGEN、LayoutDiffusion），虽能控制空间但需推理时人工标注，限制了自动化应用；二是端到端多身份扩散模型（如 UMO、XVerse），虽无需标注但在 MultiHuman-Testbench 等基准上表现出系统性的身份混淆与计数错误。现有方法未能有效解耦空间规划与身份渲染，导致模型在同时优化“位置”与“外观”时产生冲突。Ar2Can 的切入点在于将这一复合任务分解为两个独立子任务：首先由专门的 Architect 模块生成高质量空间布局，再由 Artist 模块专注于在该布局约束下进行身份保持渲染，从而从架构层面消除空间与外观的耦合。

## 核心方法

### 方法参照系

多身份生成的标准流程通常是在单一扩散模型中注入多个身份嵌入，通过交叉注意力机制在去噪过程中逐步融合身份与语义。本文的关键差异在于引入显式的空间中介层：不直接让扩散模型从文本和参考图推断布局，而是先由独立模块生成布局，再将其作为硬约束输入渲染模型。这种解耦使得空间错误与身份错误可分别归因与优化。

### 自回归布局生成与强化学习微调

Architect 模块负责从文本提示生成边界框布局。针对直接回归坐标的局限，Architect-A 采用 Qwen-2.5-0.5B 作为骨干，扩展了 <SoL>、<EoL> 和 <C> 特殊令牌。当模型预测 <C> 令牌时，触发坐标回归头 $f_{value}$ 输出连续坐标值，并通过嵌入头 $f_{embed}$ 重新嵌入为实例特定令牌，以区分不同人物的坐标。训练目标为交叉熵损失与坐标损失之和：

$$ L_{total} = L_{CE}(\hat{y}, y) + \lambda_{coord}[L_{gIoU}(\hat{b}, b) + \|\hat{b} - b\|_1] $$

该公式通过 gIoU 处理非重叠框，L1 损失提供稳定梯度。设计动机在于解决 LLM 无法直接输出连续值及动态长度问题，同时通过数据排序策略消除坐标嵌入的排列敏感性，提升训练稳定性。Architect-B 则采用 Flux-Schnell 通过 GRPO 微调，利用 2D 生成先验产生更自然的姿态与空间分布，其奖励函数结合计数准确性与 HPSv3 质量分，防止模型通过重复布局来“作弊”计数目标。

### 空间锚定身份匹配奖励

Artist 模块基于 Flux-Kontext，通过 GRPO 训练以优化复合奖励。核心创新是空间锚定面部匹配奖励 $r_{face}$，它解决了传统基于位置的匹配导致的复制粘贴伪影。该奖励分两步计算：首先，通过匈牙利算法在 Architect 预测的中心点 $c_{pred}$ 与 RetinaFace 检测到的中心点 $c_{det}$ 之间建立最优空间对应 $\pi^*$，代价矩阵为 $C_{ij} = \|c_{pred_i} - c_{det_j}\|_2$。其次，计算参考面部嵌入 $e_{ref_i}$ 与空间匹配后的生成面部嵌入 $e_{gen_{\pi^*(i)}}$ 之间的 ArcFace 相似度：

$$ r_{face}(x, L) = \frac{1}{N} \sum_{i=1}^{N} \text{sim}(e_{ref_i}, e_{gen_{\pi^*(i)}}) $$

此设计允许面部在指定位置附近自然变化（姿态、尺度），而非强制粘贴在精确坐标上。结合计数奖励、HPSv3 质量奖励及姿态奖励，该复合奖励结构确保了面部既出现在正确位置，又匹配正确的身份，有效抑制了身份互换与合并。

## 实验评估

实验在 MultiHuman-Testbench (MHTB) 和 Multi-ID-Test 上进行，前者包含 1,800 个样本，均匀覆盖 1-5 人场景。基线涵盖专有模型（GPT-Image-1, Nanobanana）和开源方法（UMO, XVerse, WithAnyone, DreamO）。Ar2Can 在 MHTB 上展现出显著优势：Architect-A 版本取得 90.2 的计数准确性，超过 GPT-Image-1 的 87.9；Architect-B 版本在 Multi-ID 相似度上达到 68.2，比此前最佳开源方法 MH-OmniGen 的 54.5 高出 13.7 分。在综合统一指标上，Ar2Can 两个版本分别达到 72.4 和 72.2，全面领先所有基线。

| 模型 | Count | Multi-ID | HPS | Unified |
| :--- | :--- | :--- | :--- | :--- |
| GPT-Image-1 | 87.9 | 28.8 | 30.3 | 55.8 |
| WithAnyone (Arch-B) | 89.8 | 44.3 | 29.7 | 62.6 |
| Ar2Can (Arch-B) | 86.9 | 68.2 | 30.8 | 72.4 |
| Ar2Can (Arch-A) | 90.2 | 67.6 | 30.2 | 72.2 |

消融实验揭示了关键设计决策的有效性。移除匈牙利匹配而采用简单的位置匹配，虽提升了 Multi-ID 分数，但导致计数准确性从 80.7 降至 75.6，HPS 从 29.2 降至 27.6，证实了简单匹配引发的复制粘贴伪影会损害整体质量。课程学习策略从 2-3 人场景逐步过渡到 7 人场景，避免了早期训练崩溃，使模型最终达到 86.9 的计数准确性和 68.2 的身份保持分数。此外，Architect-A 在计数准确性上优于 Architect-B（90.2 vs 86.9），得益于其更强的语言理解能力；而 Architect-B 在动作对齐上表现更佳，归因于其 2D 生成先验。

评估边界方面，MHTB 的 Unified Metric 平衡了身份与提示对齐，但具体计算公式未在正文中详细展开，可能影响跨论文比较。可复现性方面，论文提供了详细的超参数（如 GRPO 轮数、课程学习阈值 $\tau=100$）和硬件配置（A100 GPU），但主要依赖合成数据训练，真实多身份数据的泛化性未充分验证。

## 关联研究分析

从问题动机看，Ar2Can 与 WithAnyone 均基于 Flux 骨干，但 WithAnyone 聚焦单身份的属性保留与多样性平衡，而 Ar2Can 针对多身份的空间隔离。WithAnyone 通过可控属性保留机制解决单人脸的僵化问题，而 Ar2Can 通过显式布局解决多人脸的混淆问题。两者的差异根源在于任务特性：单身份生成中，空间位置相对固定，重点在于外观细节；多身份生成中，空间位置是变量，必须显式规划以避免冲突。Ar2Can 的解耦架构在多身份场景下更具结构性优势，但在单身份场景下可能因引入额外布局模块而增加不必要的计算开销。

从方法设计看，Ar2Can 与 DisCo 共享 RL 训练框架，但 DisCo 侧重通过多样性奖励提升生成内容的丰富度，而 Ar2Can 引入空间锚定奖励以解决身份-位置对应错误。DisCo 的奖励函数主要关注计数与多样性，缺乏对具体身份匹配的空间约束，导致其在多身份场景下易出现身份互换。Ar2Can 的匈牙利匹配机制将身份评估与空间位置绑定，这是其超越 DisCo 的关键。然而，这种绑定依赖于 RetinaFace 检测的准确性，在严重遮挡或极端姿态下，检测失败可能导致奖励信号错误，进而误导 Artist 的训练。

## 总结

Ar2Can 旨在解决多身份生成中空间布局与身份渲染耦合导致的系统性失败。其切入点在于将复合任务解耦为独立的布局生成与渲染阶段，利用 LLM 的语言推理能力生成动态布局，并通过 RL 优化空间锚定奖励确保身份-位置对应。实验证明，该框架在 MHTB 上以 90.2 的计数准确性和 68.2 的身份相似度显著优于基线。然而，论文自身实验暴露了局限：当人数超过 3 人时，对个体表情和姿态的控制力减弱，且复杂动作生成（Action-C）仍有提升空间。当支持集从合成数据扩展到真实复杂场景时，空间锚定奖励在遮挡情况下的鲁棒性是否衰减，论文未给出回答。
