# CVPR2026最新论文 ｜CaTok: Taming Mean Flows for One-Dimensional Causal Image Tokenization ｜基于均值流的一维因果图像分词器

研究机构：复旦大学

作者：Yitong Chen、Zuxuan Wu、Xipeng Qiu 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.06449)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.06449)

> 自回归视觉生成面临的核心矛盾是二维图像序列与一维因果预测范式的不匹配。现有二维分词器破坏空间局部性，而一维分词器常因缺乏因果性或训练不平衡导致生成质量下降。CaTok 通过引入均值流解码器与时间区间 Token 选择机制，构建了一维因果表征，实现了单步采样与多步生成兼容。该方法在重建指标上达到当前最优，但在生成保真度上仍略逊于部分顶级一维分词器，其因果性假设在开放域任务中的普适性尚待验证。

## 研究背景

理解 CaTok 需先厘清两个概念：整流流与均值流。整流流学习从噪声到数据的瞬时速度场，但多步积分易累积误差；均值流直接拟合区间 $[r, t]$ 上的平均速度，支持单步采样，但传统实现缺乏对条件序列因果结构的显式建模。

视觉自回归建模的瓶颈在于 Token 序列的因果性缺失。二维分词器（如 VQGAN）将图像展平为一维序列，但光栅扫描顺序破坏了空间依赖，导致全局一致性差；VAR 模型通过多尺度预测解决了部分问题，但牺牲了“下一词元预测”范式，限制了与大型语言模型架构的兼容性。近期一维分词器（如 TiTok、Semanticist）尝试通过注册器提取一维 Token，但朴素流解码器条件于所有 Token，缺乏因果性；一致性解码器虽通过嵌套丢弃引入因果性，却因早期 Token 被过度采样导致序列不平衡，损害了自回归生成质量。CaTok 的切入点在于：利用均值流的目标函数特性，将时间区间与 Token 子集绑定，从根本上解决因果性与平衡性的冲突。

## 核心方法

### 方法参照系

CaTok 属于扩散自编码器架构，由因果视觉 Transformer（ViT）编码器与均值流扩散 Transformer（DiT）解码器组成。与标准扩散自编码器的关键差异在于：解码器不再条件于全量 Token，而是条件于时间区间 $[r, t]$ 对应的 Token 子集，且训练目标同时包含均值流与整流流损失。

### 时间区间绑定的均值流解码

传统一致性解码器通过随机采样前 $k$ 个 Token 引入因果性，但早期 Token 出现概率远高于后期 Token，导致模型对后期 Token 的学习不足。CaTok 在解码阶段独立采样两个时间步 $r, t \in [0, 1]$ 且 $r < t$，并条件于区间 $[r \cdot K, t \cdot K]$ 内的 Token 子集 $V_{r:t}$。解码器预测该区间上的平均速度场：

$$ u_\theta(z_t, r, t, V_{r:t}) = \frac{1}{t-r} \int_r^t v_\theta(z_s, s, V_{r:t}) ds $$

该设计使每个 Token 子集对应特定的时间区间，天然保证了 Token 序列的因果依赖关系，同时避免了早期 Token 的过度采样，实现了序列平衡。

### REPA-A 表征对齐正则化

扩散自编码器训练常因潜变量空间不稳定而收敛缓慢。CaTok 提出 REPA-A，将编码器输出的图像特征 $H_e$ 与视觉基础模型（VFM，如 DINOv2）的预训练表征 $H_{vfm}$ 进行余弦相似度对齐：

$$ \mathcal{L}_{REPA-A} = -\frac{1}{N} \sum_{n=1}^N \text{sim}(H_e^{(n)}, H_{vfm}^{(n)}) $$

不同于 REPA-E 反向传播至 VAE，REPA-A 仅正则化编码器特征，使注册器提取的 Token 更具语义判别力，加速收敛并稳定均值流损失引入时的训练过程。

## 实验评估

实验在 ImageNet-1K 256×256 上进行，重建指标包括 rFID、PSNR、SSIM，生成指标包括 gFID、IS。基线覆盖二维分词器（VQGAN、LlamaGen）、一维分词器（TiTok、SpectralAR）及扩散自编码器（FlexTok、Semanticist、FlowMo）。

| 方法 | Token 数 | 参数量 | 训练轮数 | rFID↓ | PSNR↑ | SSIM↑ |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| CaTok-L-256 | 256 | 552M | 160 | 0.75 | 22.53 | 0.674 |
| Semanticist-L-256 | 256 | 552M | 400 | 0.78 | 21.86 | 0.600 |
| FlowMo-Lo-256 | 256 | 945M | 130 | 0.95 | 22.07 | 0.649 |
| TiTok-S-128 | 128 | 44M | 300 | 1.71 | - | - |

CaTok-L-256 在重建指标上全面领先，rFID 0.75 优于 Semanticist-L-256 的 0.78，PSNR 22.53 和 SSIM 0.674 均为最高，且训练轮数仅为 Semanticist 的 40%。生成方面，CaTok-L-128 的 gFID 为 2.95，略高于 Semanticist-L-256 的 2.57，但低于 TiTok-S-128 的 1.97，表明其生成保真度尚未达到顶级一维分词器水平。

| 消融配置 | rFID@1 | rFID@25 | gFID |
| :--- | :--- | :--- | :--- |
| 仅整流流 | 183.69 | 1.81 | 19.67 |
| +均值流 | 4.71 | 1.90 | 24.39 |
| +REPA | 4.31 | 1.71 | 17.92 |
| +REPA-A | 3.92 | 1.15 | 13.54 |
| +区间选择 | 4.89 | 1.17 | 4.91 |

消融显示，均值流引入使单步采样 rFID 从 183.69 降至 4.71，但多步采样 rFID 从 1.81 升至 1.90，表明单步能力以轻微多步性能为代价。REPA-A 将 rFID@25 从 1.71 降至 1.15，显著加速收敛。区间选择使 gFID 从 13.54 降至 4.91，验证了因果性与平衡性对生成质量的关键作用。

评估边界方面，论文仅报告 ImageNet 类别条件生成结果，未提供开放域文本生成或视频生成数据；未报告置信区间，数值比较需谨慎；代码与超参数已公开，但 GPU 资源需求未明确说明。

## 关联研究分析

从问题动机看，CaTok 与 VAR 模型形成路线竞争。VAR 通过多尺度预测解决空间错位，但牺牲了“下一词元预测”范式，限制了与 LLM 架构的兼容性；CaTok 坚持一维因果序列，主张通过 Token 设计而非生成顺序优化来解决因果性问题。这一差异源于任务特性：VAR 侧重固定分辨率下的全局一致性，而 CaTok 侧重与 LLM 范式的对齐，为统一多模态建模提供更自然的接口。

从方法设计看，CaTok 与 Semanticist 同属一维因果分词路线，但解码器机制不同。Semanticist 使用嵌套丢弃条件于前 $k$ 个 Token，导致早期 Token 过度采样；CaTok 通过时间区间绑定实现平衡采样。这一改进是否在所有 Token 数量下均有效，论文仅在 256 Token 上验证，未探索 32 或 64 Token 下的因果性表现，可能因小 Token 数下区间划分过粗导致语义信息丢失。

## 总结

CaTok 旨在解决一维视觉 Token 因果性缺失与训练不平衡的矛盾，通过均值流解码器与时间区间绑定机制，使 Token 序列天然具备因果依赖且采样平衡。该方法在 ImageNet 重建任务上取得 rFID 0.75、PSNR 22.53 的最优结果，生成 gFID 2.95 接近但略逊于顶级一维分词器。其边界在于仅验证了类别条件生成，未评估开放域任务，且小 Token 数下的因果性表现未知。当 Token 数量减少至 32 时，时间区间绑定是否仍能维持足够的语义判别力，论文未给出回答。
