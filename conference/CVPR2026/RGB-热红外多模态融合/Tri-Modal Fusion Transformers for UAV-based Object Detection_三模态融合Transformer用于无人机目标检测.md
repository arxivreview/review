# CVPR2026最新论文 ｜Tri-Modal Fusion Transformers for UAV-based Object Detection ｜三模态融合Transformer用于无人机目标检测

研究机构：丰田研究所

作者：Craig Iaboni、Pramod Abichandani

论文原文见 [arXiv](https://arxiv.org/abs/2604.16630)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.16630)

> 无人机在低光照、运动模糊及热杂波等复杂环境下，单一传感器或双模态组合均存在失效盲区，现有检测器缺乏对RGB、热红外与事件相机三模态交互机制的系统性研究。本文切入点在于将三模态融合视为架构设计空间，通过双分支层级Transformer在特定深度插入门控交换模块，实现模态间可控的信息互补。该框架通过61组受控消融实验量化了融合深度与机制的影响，证明了三模态融合优于所有双模态基线，但其在非对齐场景下的鲁棒性因硬件预对齐而被掩盖，且缺乏与主流RGB-T Transformer基线的公平对比。

## 研究背景

无人机感知系统面临照明崩塌、平台模糊、快速场景运动及热杂波等独立失效模式，RGB、热红外（LWIR）与事件相机各自仅覆盖部分条件，导致任何双模态组合在特定工况下均不可靠。事件相机提供微秒级时间边缘但缺乏绝对强度，LWIR反映辐射对比而非纹理，RGB提供高分辨率结构但在光照变化时失效，这种噪声特性、空间对齐敏感度及时间密度的差异，使得简单的通道拼接或晚期融合无法有效利用模态互补性。

现有RGB-T融合研究多假设传感器完美对齐，且聚焦于双模态配对，缺乏对三模态异构传感器在统一检测器中交互机制的系统探索。传统早期融合忽略模态差异，晚期融合丧失中间表征联合塑造能力，而Transformer骨干虽提供跨模态交换接口，但融合发生的分辨率层级与操作符选择尚未在受控条件下得到量化评估。本文通过构建同步三模态UAV数据集与模块化融合框架，旨在回答“何时、何地、如何融合”这一架构级设计问题，填补三模态无人机检测基准的空白。

## 核心方法

### 双分支层级骨干与融合钩子

本文采用双分支MixTransformer（MiT）骨干，将RGB流与热红外-事件（TE）流独立编码，在四个分辨率对齐阶段（步长4, 8, 16, 32）设置融合钩子。这种设计保留了模态特异性结构，仅在选择性阶段进行耦合，避免了全量参数共享导致的模态干扰。与单分支早期融合不同，该架构允许在保持下游FPN与检测头不变的前提下，独立评估融合深度与机制的影响，解决了此前方法中融合位置与骨干容量耦合难以解耦的问题。

### 模态感知门控交换 (MAGE)

MAGE模块在选定阶段执行跨模态通道与空间门控，基于联合证据动态调节信息流动。其核心公式为：

$$ \mathbf{g}_c = \sigma(\text{MLP}(\text{GAP}(\mathbf{z}) \oplus \text{GMP}(\mathbf{z}))) $$

其中 $\mathbf{z}$ 为RGB与TE特征的拼接描述子，$\mathbf{g}_c$ 为方向性通道门控。该设计动机在于解决固定权重融合在极端条件下受噪声模态干扰的问题，通过全局池化提取互补摘要，仅调制跨流残差，保留各流身份路径，从而在光照剧烈变化时抑制不可靠模态的贡献。

### 双向Token交换 (BiTE)

BiTE模块通过对称交叉注意力与轻量级空间细化，将MAGE输出的整流特征融合为单一映射。其关键操作为：

$$ \mathbf{U}_0 = \text{Concat}(\mathbf{T}_{rgb} + \text{CrossAttn}(\mathbf{T}_{rgb}, \mathbf{T}_{TE}), \mathbf{T}_{TE} + \text{CrossAttn}(\mathbf{T}_{TE}, \mathbf{T}_{rgb})) $$

随后通过深度卷积与1x1投影恢复局部性并压缩通道宽度。这一创新解决了传统融合中信息单向流动或分辨率丢失的问题，BiTE保持空间步长与通道宽度不变，使得融合模块可插拔于任意骨干深度，实现了融合机制与检测头的解耦，为系统消融提供了架构基础。

## 实验评估

实验在自建10,489帧UAV数据集上进行，对比基线包括YOLOv11-RGBT与DetFusion，但缺失CDDFuse、ICAFusion等主流RGB-T Transformer融合基线，限制了跨方法公平比较。主结果显示，三模态MiT-B1模型在自建数据集上取得84.24% mAP，优于RGB+Thermal双模态的83.42%及外部基线YOLOv11-RGBT的82.08%，表明事件相机在特定失效场景下提供了额外增益。

| 融合变体 | mAP | mAP50 |
| :--- | :--- | :--- |
| BiTE-only | 76.88 | - |
| MAGE-only | 81.01 | - |
| MAGE+BiTE | 84.24 | - |
| RGB+Thermal (Ours) | 83.42 | 98.22 |
| YOLOv11-RGBT | 82.08 | - |

消融实验揭示融合深度显著影响性能，单阶段融合优于多阶段融合，其中s4阶段（步长32）表现最佳，mAP达83.41%，而s1234全阶段融合降至81.93%，表明重复通道交换侵蚀模态特异性结构。CSSA轻量变体在s1阶段（τ=0.5）取得83.44% mAP，接近基线，验证了早期融合在保留结构方面的优势。GAFF机制在s3阶段（r=4, shared, bottleneck）达到84.02% mAP，略高于基线，显示SE重校准与引导空间更新的潜力。

评估边界受限于硬件预对齐（重投影误差<1.5px），未测试非对齐场景下的鲁棒性；指标仅报告mAP与mAP50，缺乏置信区间；代码已开源，但超参数与GPU配置未在摘要中详述，可复现性依赖完整技术报告。

## 关联研究分析

从问题动机看，本文聚焦三模态架构设计空间，而CDDFuse等RGB-T方法假设双模态互补性恒定，未考虑事件相机的异步稀疏特性。本文通过MAGE门控动态评估模态可靠性，解决了双模态方法在光照剧烈变化时固定权重失效的问题，但事件相机的时间分辨率与帧率匹配对融合精度的影响未被量化。从方法设计看，本文双流MiT骨干与RegisterBridgeMM的模态解耦策略相似，但本文未使用预训练基础模型，而是从头训练融合模块，导致数据依赖较高，且缺乏与UNIV等基础模型适配方法的效率对比。

## 总结

本文核心矛盾在于三模态异构传感器在统一检测器中的交互机制缺乏系统研究，现有双模态方法无法覆盖所有失效模式。本文通过双分支MiT骨干与MAGE+BiTE融合模块，实现了融合深度与机制的解耦评估，证明了三模态融合优于双模态基线（84.24% vs 83.42% mAP）。其边界在于硬件预对齐掩盖了非对齐场景下的鲁棒性，且缺乏与主流RGB-T Transformer基线的公平对比。当传感器存在视差或时间延迟时，MAGE门控能否有效抑制噪声模态干扰，论文未给出回答。
