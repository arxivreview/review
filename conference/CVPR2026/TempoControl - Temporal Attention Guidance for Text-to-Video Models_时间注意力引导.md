# CVPR2026最新论文 ｜TempoControl: Temporal Attention Guidance for Text-to-Video Models ｜时间注意力引导

研究机构：以色列巴伊兰大学

作者：Shira Schiber、Ofir Lindenbaum、Idan Schwartz

论文原文见 [arXiv](https://arxiv.org/abs/2510.02226)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.02226)

> 文本到视频生成模型虽能合成高保真画面，却难以精确控制视觉元素出现的具体时间点，现有方案依赖昂贵的时序标注数据或牺牲画质的文本提示。本文切入点在于利用扩散模型内部已存在的交叉注意力机制，通过推理时潜变量优化实现免训练的时间对齐。具体做法是设计基于Pearson相关、幅值与熵的三组件损失函数，引导注意力分布匹配目标时间掩码。该方法在Wan2.1-S骨干上将单物体时间准确率提升19.62%，但多物体场景下增益收窄，且对复杂动作时序的控制仍显不足。

## 研究背景

文本到视频生成（Text-to-Video, T2V）的核心瓶颈在于弥合离散文本语义与连续时空表征间的鸿沟。当用户希望指定“狗在视频后半段出现”时，模型往往忽略时间约束，导致物体过早或过晚出现。这一失效源于交叉注意力机制的全局性：文本Token与视频Token的绑定缺乏显式的时间索引，使得语义与时间维度解耦。为了解决这一对齐问题，主流路线分为两类：一是训练时微调，如MinT通过时序标注数据学习事件序列，但受限于数据稀缺且仅支持粗粒度控制；二是推理时优化，如Attend-and-Excite在图像域通过操纵注意力图确保实体存在，但尚未迁移至视频的时间维度。

现有推理时方法多聚焦于空间布局或运动轨迹，对时间维度的精确控制关注不足。文本提示本身存在分布不匹配问题，实验表明添加显式时间词汇不仅未提升时间准确率，反而导致视觉质量下降（Wan2.1画质从59.99%降至53.76%）。TempoControl（Schiber et al., 2025）抓住这一被忽略的点：交叉注意力图本身编码了“哪个词在哪个帧被实现”的强信号。通过直接引导这些注意力图，无需额外数据或模型重训，即可实现细粒度时间控制。

## 核心方法

### 方法参照系

本文问题归属于推理时优化路线，与图像域注意力操纵方法（如Prompt-to-Prompt）共享“通过调整注意力分布改变生成内容”的基本范式。关键差异在于：图像方法优化空间注意力以控制构图，而本文需优化时间维度的注意力分布，且必须在保持视频时序连贯性的前提下进行，这要求损失函数具备时间序列对齐特性。

### 时间相关性与幅值引导

在去噪过程中，模型通过交叉注意力将文本语义注入视频Token。通常做法是固定模型参数，仅优化噪声或提示嵌入。本文创新在于直接优化潜变量 $z_t$，以改变注意力分布。设计动机是解决文本提示模糊性与注意力全局性导致的语义-时间解耦。核心公式为时间相关性损失：

$$ L_{corr} = 1 - \frac{Cov(\tilde{a}_i^{[t]}, m_i)}{\sigma_{\tilde{a}_i^{[t]}} \sigma_{m_i}} $$

其中 $\tilde{a}_i^{[t]}$ 是归一化的时间注意力向量，$m_i$ 是目标时间掩码。该公式通过Pearson相关系数衡量注意力时间形状与目标掩码的线性一致性，但因其尺度不变性，可能忽略注意力强度不足导致物体不可见的问题。为此，引入幅值项 $L_{mag}$，在目标激活区域增强注意力，在非激活区域抑制注意力，恢复尺度敏感性。

### 熵正则化与空间一致性

仅优化时间对齐可能破坏空间语义，导致物体变形（如手机变成双屏平板）。设计动机是防止注意力在空间维度过度扩散。本文引入熵正则化项：

$$ L_{ent} = \sum_{j: m_{i,j} > \tau} H(\bar{A}_{t,j,i}) $$

其中 $H(\cdot)$ 为空间维度的Shannon熵。该公式惩罚注意力在空间上的均匀分布，确保当物体在特定时间出现时，其空间定位保持聚焦。消融实验显示，仅使用熵项即可将画质提升至59.52%，超过文本基线，表明注意力平滑对视频质量有普遍益处。

## 实验评估

| 方法 | 骨干 | 单物体时间准确率(%) | 双物体时间准确率(%) | 动作时间准确率(%) |
| :--- | :--- | :--- | :--- | :--- |
| Wan2.1-S (Text) | 1.3B | 63.94 | 37.50 | 19.00 |
| TempoControl | 1.3B | 66.89 | 53.17 | 54.00 |
| CogX-S (Text) | 2B | 85.23 | - | - |
| TempoControl | 2B | 87.42 | - | - |

实验在Wan2.1、CogVideoX、LTX-2等主流DiT骨干上进行，基线为纯文本提示。TempoControl在Wan2.1-S单物体任务上时间准确率提升19.62%，双物体任务提升15.67%，动作任务提升35个百分点。然而，CogX-S基线本身时间准确率高达85.23%，TempoControl仅提升2.19%，表明方法增益受骨干模型固有偏差影响。

| 消融组件 | 时间准确率(%) | 画质(%) |
| :--- | :--- | :--- |
| Text Baseline | 63.94 | 53.76 |
| Only Correlation | 81.19 | 50.96 |
| Only Entropy | 72.94 | 59.52 |
| Correlation + Entropy | 79.00 | 57.60 |

消融显示，相关性项主导时间对齐但牺牲画质，熵项提升画质但时间增益有限。两者结合达到平衡，但画质仍低于纯熵项，说明时间控制与视觉保真存在权衡。

评估边界方面，论文自建时间准确率指标，未报告置信区间，且缺乏与LoRA微调方法的对比。可复现性受限于单GPU（NVIDIA B200）环境，超参数如优化步数 $l$ 和学习率 $\alpha$ 未详细披露。

## 关联研究分析

从问题动机看，TempoControl与MinT均解决时间控制问题，但MinT依赖时序标注数据微调，仅支持粗粒度事件序列，而TempoControl免训练且支持细粒度帧级控制。差异根源在于任务特性：MinT面向人类活动视频，数据相对结构化；TempoControl面向通用T2V，需处理任意文本提示，故选择推理时优化以规避数据瓶颈。

从方法设计看，TempoControl与Stable Flow同属免训练DiT编辑框架，但Stable Flow侧重空间特征注入以编辑内容，TempoControl侧重时间潜变量引导以控制时序。TempoControl引入熵正则化是独特设计，源于视频生成中空间-时间耦合的特性，而图像编辑方法无需考虑时序连贯性。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

TempoControl针对T2V模型时间控制缺失的核心矛盾，利用交叉注意力机制的内在信号，通过推理时潜变量优化实现免训练时间对齐。方法在Wan2.1-S上将单物体时间准确率提升至66.89%，双物体至53.17%，证明了注意力引导的有效性。然而，实验暴露出方法在强基线（如CogX-S）上增益有限，且多物体场景下时间准确率仍低于50%，表明复杂场景下的语义-时间解耦仍未完全解决。当骨干模型本身具备较强时间先验时，推理时优化的边际收益是否递减，论文未给出回答。
