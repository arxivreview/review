# CVPR2026最新论文 ｜Mask to Align, Weight to Disambiguate: Reliable Unsupervised Cross-Modal Hashing with Masked-Weight Contrast ｜掩码加权对比哈希

研究机构：南京大学、澳大利亚悉尼大学

作者：Fan Yang、Yuanzhi Zhao、Haimei Zhao 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_13bd501694d0)

> 无监督跨模态哈希旨在无标签条件下将图像与文本映射至共享汉明空间，但真实数据常存在模态主导与语义歧义，导致对比学习将相关样本误判为负例，优化不稳定。现有方法多孤立处理部分观测鲁棒性或假阴性问题，缺乏统一框架。本文提出 UWMCH，通过融合前 Token 掩码构建部分观测交互，结合语义亲和度加权对比学习与双尺度结构正则化，在 MIRFLICKR-25K 等基准上取得领先性能。其价值在于统一解决无监督场景下的鲁棒性与判别力矛盾，但未验证掩码策略在极端数据稀疏下的泛化边界。

## 研究背景

无监督跨模态哈希的核心困境在于缺乏显式标签监督，模型需从数据内在结构中学习语义对齐。这一过程依赖对比学习，但对比学习假设批内非配对样本为负例，而实际数据中语义相关样本可能被随机分入不同批次，形成假阴性。假阴性导致模型错误排斥语义相近样本，扭曲局部语义邻域，削弱哈希码的判别力。同时，多模态融合易受主导模态影响，当局部证据缺失时，融合过程过度依赖单一模态，产生不稳定的融合表示，进一步加剧对齐偏差。

主流无监督哈希方法如 InfMasking 通过掩码交互增强部分观测鲁棒性，但掩码通常应用于融合后阶段，未能有效打破融合前的模态主导；而加权对比学习虽能缓解假阴性，但缺乏对语义几何结构的显式约束，导致全局原型漂移。本文切入点在于将掩码机制前移至融合前，通过 Token 级部分观测迫使模型利用互补线索，同时引入语义亲和度加权与双尺度正则化，统一处理假阴性、模态主导与结构不稳定问题。

## 核心方法

### 方法参照系

无监督跨模态哈希标准流程包括特征提取、融合编码、对比学习与哈希码生成。本文关键差异在于：在融合前引入 Token 掩码，并采用加权 InfoNCE 替代标准 InfoNCE，同时增加双尺度结构正则化，以解决假阴性与模态主导耦合问题。

### 融合前 Token 掩码与对称对比

标准流程中，图像与文本特征直接拼接后输入融合编码器，易受主导模态影响。本文在融合前对视觉与文本 Token 序列独立采样保留比例 ρ 的掩码，生成部分观测特征。设计动机是打破对完整 Token 证据的捷径依赖，迫使融合编码器利用互补线索。掩码特征与未掩码特征形成四组对称交互，通过加权 InfoNCE 对齐：

$$
\mathcal{L}_{\text{WMCL}} = \mathbb{E}_{M} \left[ \hat{\mathcal{I}}_{\text{WMNCE}}(\tilde{R}^{(1)}, R^{(2)}; \tau) + \hat{\mathcal{I}}_{\text{WMNCE}}(R^{(1)}, \tilde{R}^{(2)}; \tau) + \hat{\mathcal{I}}_{\text{WMNCE}}(\tilde{R}^{(2)}, R^{(1)}; \tau) + \hat{\mathcal{I}}_{\text{WMNCE}}(R^{(2)}, \tilde{R}^{(1)}; \tau) \right]
$$

该公式通过四组对称交互强化掩码与未掩码视图的一致性，提升部分观测下的鲁棒性。

### 语义亲和度加权与双尺度正则化

标准 InfoNCE 对负例均匀排斥，无法区分假阴性。本文构建语义亲和度 $S_{\text{sem}}(i,j) = \alpha S_{\text{inst}}(i,j) + (1-\alpha) S_{\text{clu}}(i,j)$，其中 $S_{\text{inst}}$ 为实例级一致性，$S_{\text{clu}}$ 为聚类共识先验。负例权重 $W_{\text{neg}}(i,j) = (1 - S_{\text{sem}}(i,j))^{\eta} + \epsilon$ 降低语义相关负例的排斥力。设计动机是避免假阴性导致的语义邻域扭曲。同时，引入聚类质心一致性（CCA）与语义结构正则化（SSR）：

$$
\mathcal{L}_{\text{CCA}} = -\frac{1}{K} \sum_{k=1}^{K} \log \frac{\exp(\langle \hat{c}_k, \hat{c}_{\text{ema}}^k \rangle / \tau_c)}{\sum_{j=1}^{K} \exp(\langle \hat{c}_k, \hat{c}_{\text{ema}}^j \rangle / \tau_c)}
$$

该公式通过指数移动平均原型库稳定全局锚点，抑制原型漂移。SSR 则约束未掩码与掩码特征的余弦相似度矩阵与语义亲和度一致，保持局部几何结构。

## 实验评估

实验在 MIRFLICKR-25K、NUS-WIDE 和 MS COCO 三个基准上进行，对比 DJSRH、JDSH、AGCH、CIRH、VLKD、UCCH、VTM-UCH 和 RSHNL 八种无监督哈希方法。基线覆盖主流无监督路线，但缺失 GNAH 等近期强基线，可能影响结果可比性。

| 数据集 | 任务 | 128-bit mAP (%) |
| --- | --- | --- |
| MIRFLICKR-25K | I→T | 91.60 |
| MIRFLICKR-25K | T→I | 90.59 |
| NUS-WIDE | I→T | 89.30 |
| NUS-WIDE | T→I | 85.34 |
| MS COCO | I→T | 91.26 |
| MS COCO | T→I | 91.10 |

UWMCH 在 24 个设置中的 21 个取得最佳性能，MIRFLICKR-25K I→T 128-bit 达 91.60%，显著优于最强基线 RSHNL 的 91.35%。消融实验显示，仅使用加权掩码对比学习（LWMCL）已具较强性能，增加 CCA 或 SSR 进一步提升，完整目标函数平均提升 1.50 个百分点。CCA 的边际收益略大于 SSR，表明全局锚点稳定对性能贡献更显著。

评估协议采用标准 mAP 与 Top-N 精度，但未报告置信区间或多次运行方差，可复现性依赖 PyTorch 实现与 RTX 3080 Ti GPU，超参数如 τ=0.08、α=0.6 固定，缺乏敏感性分析。

## 关联研究分析

从问题动机看，UWMCH 与 InfMasking 均关注部分观测鲁棒性，但 InfMasking 将掩码应用于融合后阶段，仅增强视图一致性，未解决融合前的模态主导问题；UWMCH 将掩码前移至融合前，直接干预特征交互过程，从根源上抑制主导模态偏差。这一差异源于任务特性：融合前掩码需模型在信息缺失时主动整合互补线索，而融合后掩码仅验证已有表示的稳定性。

从方法设计看，UWMCH 与 GNAH 同属无监督哈希，但 GNAH 依赖全局-邻域对齐，缺乏对假阴性的显式处理；UWMCH 通过语义亲和度加权直接缓解假阴性，但计算开销增加。GNAH 在 MIRFLICKR-25K 无监督任务中 mAP 为 68.20%，UWMCH 达 91.60%，差距显著，但两者评估协议是否完全一致存疑，GNAH 是否使用相同数据划分与预处理流程未明确，性能对比需谨慎。

## 总结

UWMCH 解决的核心矛盾是无监督跨模态哈希中假阴性与模态主导的耦合失效。现有方法孤立处理部分观测或假阴性，缺乏统一框架；UWMCH 通过融合前掩码打破模态主导，语义亲和度加权缓解假阴性，双尺度正则化稳定结构，实现统一优化。实验证明其在 MIRFLICKR-25K I→T 128-bit 达 91.60%，NUS-WIDE I→T 128-bit 达 89.30%，显著优于基线。边界在于未验证掩码比例动态调整对极端数据稀疏场景的影响，且缺失 GNAH 等强基线对比。当训练样本减少至 10% 时，融合前掩码的鲁棒性是否仍优于融合后掩码，论文未给出回答。
