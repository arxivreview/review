# CVPR2026最新论文 ｜ShapeR: Robust Conditional 3D Shape Generation from Casual Captures ｜非受控序列下的鲁棒度量三维形状生成

研究机构：加拿大西蒙弗雷泽大学

作者：Yawar Siddiqui、Duncan Frost、Samir Aroudj 等 12 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.11514)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.11514)

> 现有三维生成模型在干净、无遮挡且分割良好的输入下表现优异，但在真实世界的非受控采集场景中性能急剧下降，主要受限于遮挡、杂乱背景及传感器噪声。ShapeR 通过引入稀疏 SLAM 点云、位姿图像及机器生成文本的多模态条件，结合在线组合增强与两阶段课程学习，实现了无需显式分割的鲁棒度量重建。该方法在自建基准上将 Chamfer Distance 降低至 2.375，显著优于现有重建方法。其价值在于打通了生成式建模与度量重建的壁垒，但缺乏跨数据集的泛化验证，且依赖特定的 SLAM 预处理管线。

## 研究背景

理解本文需厘清“度量一致性”与“隐式分割”的耦合关系。传统重建方法往往将场景视为单一实体，导致物体在遮挡下几何缺失；而生成式模型虽能补全形状，却常缺乏物理尺度约束。当输入序列包含噪声与杂乱背景时，显式二维分割（如 SAM）极易失效，此时需依赖三维空间中的稀疏点云作为几何锚点，通过点-帧关联实现隐式物体定位，从而在无需完美掩码的情况下恢复完整几何。

三维形状生成领域正从追求单体高保真向结构化资产演进，潜空间扩散模型（Latent Diffusion Model, LDM）已成为主流架构。然而，现有 LDM 方法如 TRELLIS 和 ShapeGen 均假设输入为干净、无遮挡的单图或少数视图，其性能在真实世界的“随意拍摄”（casual capture）场景中大幅退化。主流路线依赖显式二维分割来隔离目标物体，这在杂乱场景中不仅计算昂贵，且对分割错误极度敏感。ShapeR 的切入点在于放弃对完美分割的依赖，转而利用视觉惯性 SLAM 提供的稀疏度量点云作为多模态条件之一，通过联合编码点云、位姿图像和文本，在潜空间中直接去噪出具备物理尺度的完整物体形状。

## 核心方法

### 多模态条件流匹配架构

ShapeR 将物体中心形状生成建模为对潜变量 VecSet 的去噪过程，其核心差异在于条件输入从单一图像扩展为多模态序列。参照系中的标准 LDM 流程通常仅以单张图像或文本为条件，而本文引入了稀疏 SLAM 点云 $C_{pts}$、位姿图像 $C_{img}$ 和文本描述 $C_{txt}$。点云通过稀疏 3D ResNet 编码为 token 流，图像使用冻结的 DINOv2 骨干提取特征并拼接 Plücker 射线编码以注入位姿信息。关键创新在于利用 3D 点云在图像平面上的投影生成二进制掩码 $M_i$，该掩码与 DINO 特征拼接，引导网络隐式识别目标物体，从而替代了易错的显式二维分割。

$$
\mathcal{L}_{flow} = \mathbb{E}_{z_0 \sim q(z|S), z_1 \sim \mathcal{N}(0, I), t \sim \mathcal{U}(0,1)} \left[ \| f_\theta(z_t, t, C) - (z_1 - z_0) \|^2 \right]
$$

该公式定义了整流流（Rectified Flow）的训练目标，其中 $f_\theta$ 预测从噪声 $z_1$ 到数据 $z_0$ 的传输速度，条件 $C$ 包含上述多模态特征。通过最小化预测速度与真实速度的均方误差，模型学习在给定杂乱输入条件下，将高斯噪声映射到特定物体的潜变量流形。

### 两阶段课程学习与在线增强

为解决真实场景数据稀缺与分布偏移问题，ShapeR 采用两阶段课程学习。第一阶段在包含 600K 个孤立物体网格的大规模数据集上预训练，通过在线组合增强（如背景合成、遮挡叠加、点云 dropout）模拟非受控采集的噪声分布。第二阶段在 Aria 合成环境数据上微调，该数据虽类别较少，但包含真实的物体间交互与 SLAM 噪声模式。这种设计动机在于，孤立物体数据无法建模组合复杂性，而纯场景数据缺乏类别多样性；两阶段结合既学到了通用形状先验，又适应了真实场景的杂乱特性。

$$
z_{t} = (1-t)z_0 + t z_1, \quad \text{where } t \in [0,1]
$$

此线性插值公式描述了流匹配中的噪声调度，$t$ 为时间步。在推理阶段，模型通过中点采样积分学习到的流，从 $t=1$ 的纯噪声逐步去噪至 $t=0$ 的潜变量，最终解码为 SDF 并提取网格。该机制确保了生成过程的稳定性，特别是在输入点云稀疏或图像模糊时，多模态条件提供了互补的几何约束，防止模型过拟合于单一模态的噪声。

## 实验评估

ShapeR 在自建基准上显著优于现有方法，但基线覆盖存在局限。实验在包含 178 个物体、7 个真实场景的 ShapeR 评估数据集上进行，对比了 EFM3D、LIRM、DP-Recon 等重建方法及 TripoSG、Direct3D-s2 等生成模型。基线选择涵盖了从单体重建到图像到三维生成的主流路线，但缺失了知识库中最新的部件级生成方法（如 MultiCube）及更严格的跨数据集泛化测试。

| 方法 | CD ($\times 10^2$) | NC | F1 |
| :--- | :--- | :--- | :--- |
| EFM3D | 13.82 | 0.614 | 0.276 |
| LIRM | 8.047 | 0.683 | 0.384 |
| DP-Recon | 8.364 | 0.661 | 0.436 |
| ShapeR | **2.375** | **0.813** | **0.722** |

ShapeR 的 CD 为 2.375，较次优的 DP-Recon (8.364) 降低约 3.5 倍，F1 达到 0.722，表明其在几何完整性与法线一致性上均取得领先。在用户偏好测试中，ShapeR 对 TripoSG、Direct3D-s2 等生成模型的胜率分别为 86.67% 和 88.33%，进一步验证了其在非受控场景下的鲁棒性。

消融实验揭示了各组件的贡献。移除 SLAM 点云后，CD 从 2.375 上升至 4.514，证明点云提供了关键的度量约束；移除点云增强导致 CD 升至 3.276，表明在线增强对噪声鲁棒性至关重要。移除两阶段训练中的场景微调阶段，CD 为 3.053，说明场景级微调对适应真实杂乱环境有显著增益。移除 2D 点掩码提示后，CD 为 2.568，虽影响较小，但定性结果显示其有助于减少相邻物体的混淆。

评估边界方面，ShapeR 仅在自建数据集上验证，缺乏在 ScanNet++ 或 ARKitScenes 等公共基准上的泛化测试，无法确认其性能是否依赖于特定场景分布。此外，论文未报告计算效率指标（如推理时间、显存占用），且依赖 Project Aria 的 SLAM 管线，限制了其在其他硬件平台上的可复现性。指标体系仅包含 CD、NC 和 F1，缺乏对物理属性或部件语义的评估，这与当前领域向功能资产演进的趋势存在差距。

## 关联研究分析

从问题动机看，ShapeR 与 Amodal3R 均致力于解决遮挡问题，但路径截然不同。Amodal3R 基于 TRELLIS 架构，通过推理遮挡区域生成非模态补全，侧重于几何完整性；而 ShapeR 引入 SLAM 点云，侧重于度量一致性与鲁棒性。Amodal3R 在干净输入下表现良好，但在杂乱场景中因缺乏空间锚点而失效，ShapeR 则通过点云提供了全局几何约束。这一差异源于任务定义：Amodal3R 假设输入为单张或少数干净视图，而 ShapeR 处理的是包含噪声和杂乱的多视图序列。

从方法设计看，ShapeR 与 DP-Recon 在条件编码上存在根本分歧。DP-Recon 依赖 SAM2 生成的显式二维掩码来隔离物体，这在分割错误时会导致几何断裂；ShapeR 则利用 3D 点云投影生成隐式掩码，引导 DINO 特征关注目标区域。这种设计牺牲了部分语义精度，换取了对分割噪声的鲁棒性。然而，ShapeR 的隐式分割机制是否能在极端杂乱场景（如物体高度重叠）中保持准确性，论文未提供充分的定性分析，这可能成为其在复杂工业场景中的应用瓶颈。

## 总结

ShapeR 解决了非受控采集序列下三维形状生成的鲁棒性与度量一致性矛盾，其核心在于利用稀疏 SLAM 点云作为多模态条件，替代易错的显式二维分割，并通过两阶段课程学习适应真实场景噪声。实验表明，该方法在自建基准上将 Chamfer Distance 降至 2.375，F1 提升至 0.722，显著优于现有重建与生成方法。然而，其性能验证局限于自建数据集，缺乏跨基准的泛化证据，且依赖特定的 SLAM 预处理管线。当输入序列的 SLAM 点云密度极低或存在严重漂移时，隐式分割机制的鲁棒性是否仍能维持，论文未给出回答。
