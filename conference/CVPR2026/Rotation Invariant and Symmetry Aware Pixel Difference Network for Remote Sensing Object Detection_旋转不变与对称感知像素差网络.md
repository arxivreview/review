# CVPR2026最新论文 ｜Rotation Invariant and Symmetry Aware Pixel Difference Network for Remote Sensing Object Detection ｜旋转不变与对称感知像素差网络

研究机构：国防科技大学、西安电子科技大学

作者：Jialei Zhan、Li Liu、Jiehua Zhang 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_bcb35ef2e75e)

> 遥感目标检测长期受困于物体任意朝向与结构对称性导致的特征响应不稳定，现有方法或依赖角度回归、或依赖重型等变架构，难以兼顾精度与效率。RIS-PiDiNet 将 SO(2) 旋转群先验与极坐标谐波对称约束直接嵌入卷积核，以像素差卷积替代标准卷积，在不增加参数量的前提下实现几何一致的特征提取。该方法在 DOTA、HRSC2016 和 DIOR-R 上取得 SOTA 性能，但其对离散旋转采样的依赖及与重型 Transformer 基线的算力对比缺失，限制了其泛化边界的判断。

## 研究背景

当检测器处理航拍图像时，飞机、桥梁等目标呈现任意旋转且具备双轴或径向对称结构。标准卷积核缺乏对旋转群 SO(2) 的显式建模，导致同一物体在不同朝向下的特征激活强度波动剧烈，即“角度偏差”。这种偏差不仅降低定位精度，更在部分遮挡下破坏对称结构的完整性推断，因为网络无法从可见部分推导出缺失的对称部分。解决此问题需引入几何先验，但传统方法如 ReDet 依赖重型特征重对齐，计算开销大；而数据增强虽能缓解，却无法在特征层面保证对称一致性。

遥感目标检测的主流路线分为角度敏感检测与旋转不变建模两类。前者通过角度回归与方向敏感损失优化边界框，但在极端视角下框定位失稳；后者采用等变架构或对称性建模，但往往牺牲局部细节或增加算力负担。现有方法未能同时满足连续旋转不变性与内部结构对称性的显式编码，导致在复杂几何场景下检测性能受限。RIS-PiDiNet 的切入点在于将 Lie 群理论与极坐标谐波变换融入轻量级卷积算子，以数学严谨的方式统一处理旋转与对称，避免架构级的重型改造。

## 核心方法

### 方法参照系

本文基于 LSKNet 的大核卷积骨干，将标准卷积替换为旋转不变与对称感知像素差卷积（RIS-PDC）。与通用检测流程的关键差异在于，RIS-PDC 在卷积核域进行几何变换，而非在特征图域，从而以线性复杂度实现几何增强，避免了特征图旋转带来的显存开销。

### 对称感知像素差卷积（S-PDC）

S-PDC 在像素差卷积（PDC）基础上引入极坐标谐波变换（PHT）核，以显式编码结构对称性。PDC 通过计算像素与参考值 $q$ 的差值来增强局部纹理，但缺乏对称性约束。S-PDC 将 PDC 与谐波核 $H_{n,l}^i$ 结合，其中 $n$ 和 $l$ 为谐波阶数，$\alpha_{n,l}$ 为可学习系数。其响应公式为：

$$ y = \sum_{i \neq c} \sum_{(n,l) \in O} \alpha_{n,l} w_i \cos(2\pi n r_i^2 + l \theta_i) (x_i - q) $$

该公式通过稀疏组合多个谐波阶数，强调对称一致的结构并抑制非对称噪声。设计动机在于解决标准卷积在对称物体（如飞机、环岛）上特征响应模糊的问题，使网络能从可见部分推断缺失的对称部分。

### 旋转不变对称感知像素差卷积（RIS-PDC）

RIS-PDC 在 S-PDC 基础上集成 SO(2) 旋转平均，实现完全旋转不变性。对每个采样角度 $\theta_j$，生成旋转核 $K_{\theta_j} = R_{\theta_j}(K)$，其中 $R_{\theta_j}$ 为旋转矩阵。最终响应为 $n$ 个离散旋转角度的平均：

$$ y_{final} = \frac{1}{n} \sum_{j=1}^{n} (R_{\theta_j} K) * x $$

该公式通过核域平均抑制方向依赖变化，确保输入旋转时输出不变。设计动机在于解决 S-PDC 仅处理对称性但未处理连续旋转的问题，使特征提取在任意朝向下保持稳定。实验设置 $n=8$，在角度采样充分性与插值伪影之间取得平衡。

## 实验评估

实验在 DOTA-v1.0、HRSC2016 和 DIOR-R 上进行，基线覆盖 LSKNet、PKINet、MA3E 等高效检测器，但缺乏与重型 Transformer（如 AO2-DETR）的公平算力对比。RIS-PiDiNet-S 在 DOTA 单尺度上取得 78.53% mAP，优于 PKINet-S（78.39%）和 LSKNet-S（77.49%）；在 HRSC2016 上取得 98.60% mAP，在 DIOR-R 上取得 67.28% mAP。

| 数据集 | 方法 | mAP (%) | #P (M) | FLOPs (G) |
| :--- | :--- | :--- | :--- | :--- |
| DOTA-v1.0 (Single-Scale) | RIS-PiDiNet-S | 78.53 | 31.0 | 206 |
| DOTA-v1.0 (Single-Scale) | PKINet-S | 78.39 | 30.8 | 190 |
| DOTA-v1.0 (Single-Scale) | LSKNet-S | 77.49 | 31.0 | 161 |
| HRSC2016 | RIS-PiDiNet-S | 98.60 | - | - |
| DIOR-R | RIS-PiDiNet-S | 67.28 | 31.0 | 206 |

消融实验显示，RIS-PDC 在检测头层应用时收益最大（77.41% mAP），而在 layer2 应用时节省 42G FLOPs 且仅损失 0.15% mAP（77.60% vs 77.75%），表明精度-效率权衡的灵活性。谐波阶数从 3 个固定值增加到 5 个可学习值时，mAP 仅从 77.75% 降至 77.48%，显示谐波调制的边际收益递减。

评估边界方面，论文未报告置信区间，且 FLOPs 增加 45G（从 161G 到 206G）是否抵消精度提升缺乏量化分析。代码已开源，但超参数（如 $n=8$）的敏感性未充分探讨，可复现性依赖特定 GPU 配置（8× RTX 4090D 预训练，A800-80GB 微调）。

## 关联研究分析

从问题动机看，RIS-PiDiNet 与 ReDet 等角度敏感方法的核心差异在于几何先验的嵌入位置。ReDet 依赖角度回归与方向敏感损失，在特征图域处理旋转，导致计算开销大且框定位失稳；RIS-PiDiNet 在卷积核域嵌入 SO(2) 先验，以线性复杂度实现旋转不变性，避免了特征重对齐的负担。这一差异源于任务特性：遥感目标检测需处理任意朝向，而核域变换更适配轻量级部署需求。

从方法设计看，RIS-PiDiNet 与 LSKNet 等高效检测器的差异在于对称性建模的显式性。LSKNet 依赖大核卷积增强上下文，但未显式编码对称结构，导致在对称物体上特征响应模糊；RIS-PiDiNet 引入 PHT 谐波核，显式约束对称一致性，使网络能从可见部分推断缺失部分。这一差异源于论文对“对称性作为内在结构先验”的强调，而非仅依赖数据增强或架构等变性。

## 总结

RIS-PiDiNet 解决的核心矛盾是遥感目标检测中旋转不变性与结构对称性的统一建模，现有方法或依赖重型等变架构、或依赖角度回归，难以兼顾精度与效率。本文抓住卷积核域几何变换的切入点，以 SO(2) 旋转平均与 PHT 谐波约束替代标准卷积，在不增加参数量的前提下实现几何一致的特征提取。实验证明其在 DOTA 单尺度上取得 78.53% mAP，在 HRSC2016 上取得 98.60% mAP，验证了方法的有效性。然而，论文未提供与重型 Transformer 基线的公平算力对比，且离散旋转采样（$n=8$）对连续 SO(2) 几何的近似误差未量化。当 $n$ 增加到 16 时，精度是否进一步提升或出现插值伪影，论文未给出回答。
