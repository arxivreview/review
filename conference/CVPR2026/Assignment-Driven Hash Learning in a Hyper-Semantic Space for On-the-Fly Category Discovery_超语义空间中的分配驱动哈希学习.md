# CVPR2026最新论文 ｜Assignment-Driven Hash Learning in a Hyper-Semantic Space for On-the-Fly Category Discovery ｜超语义空间中的分配驱动哈希学习

研究机构：东南大学、天津大学

作者：Kaibing Yang、Yucheng Wang、Tingzhang Luo

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_150bd0b790a9)

> On-the-fly Category Discovery (OCD) 旨在从流式数据中即时识别已知与未知类别，但现有哈希方法因特征对齐不足导致码字冗余，且已知类垄断特征空间阻碍新类涌现。本文指出这两大失效是级联发生的，并构建双几何子空间的超语义空间，结合软分配与二进制哈希正则化进行改进。该方法作为即插即用模块提升了基线性能，但其哈希范式在细粒度场景下的理论上限仍受量化误差制约，与测试时自适应路线存在本质差距。

## 研究背景

OCD 任务要求模型在仅依赖已知类监督的情况下，对顺序到达的流式数据即时做出类别决策。由于无法访问全局无标签集进行批量聚类，主流方法采用哈希编码将高维特征映射为紧凑二进制码，以实现快速检索与在线发现。然而，哈希量化对特征扰动极度敏感，微小的特征偏差会导致比特翻转，使得同类样本生成不一致的码字，进而引发类别碎片化。

当前 OCD 研究主要沿两条路线展开：一是基于原型引导的哈希学习，如 PHE 框架通过原型约束提升码字稳定性；二是基于对比学习的哈希优化，如 SMILE 方法通过监督对比损失增强特征判别性。尽管这些方法在通用数据集上取得进展，但在细粒度场景中，类内视觉差异微小，传统硬分配原型机制无法捕捉这种多样性，导致特征空间对齐度低。同时，训练阶段缺乏未知类约束，已知类特征自然扩张占据大部分超球面空间，挤压了潜在新类的生存区域。本文切入点在于揭示特征级失效如何级联放大至哈希级，并通过几何空间预构建与软分配机制同时解决这两个耦合问题。

## 核心方法

### 方法参照系

标准 OCD 哈希流程包含编码器训练、哈希头映射与在线匹配三个阶段。本文问题与该通用流程的关键差异在于：传统流程直接学习哈希头，忽略了特征空间的结构化约束，导致量化误差累积。本文在编码器与哈希头之间插入超语义空间构建阶段，通过原型增强与插值预定义语义边界，再在此空间内执行分配驱动的哈希学习。

### 超语义空间构建

设计动机：已知类在训练期无未知类约束，导致特征空间被已知类占据，挤压未知类生存空间，是混淆的几何根源。本文通过构建双几何子空间，在特征空间中显式预留未知类区域。Derived Subspace 通过对已知类数据进行增强生成原型对 $(P^{par}, P^{aug})$，捕捉类内细粒度变化；Calibrated Subspace 通过不同已知类原型的线性插值生成 OOD 原型，施加分布约束防止表示坍缩。插值公式为：

$$
\hat{P}^{ood} = \lambda_{ood} P_i^{par} + (1 - \lambda_{ood}) P_j^{par}, \quad i \neq j, \lambda_{ood} \in [0, 1]
$$

该公式生成语义模糊且未被占用的区域，确保已知类特征不会坍缩至此，为新类保留空间容量。

### 分配驱动哈希学习

设计动机：硬分配原型机制将每个样本映射到单一原型，无法捕捉类内多样性，导致已知类识别不足且类别数估计远超真实值。本文引入 Flexible Prototype Assignment (FPA) 与 Binary Hash Regularization (BHR)。FPA 采用 von Mises-Fisher (vMF) 分布进行软分配，通过 Sinkhorn-Knopp 归一化计算分配权重 $w_{i,k}^c$，并最大化似然估计损失 $\mathcal{L}_{soft-MLE}$ 促进样本围绕原型紧凑聚类。同时，原型对比损失 $\mathcal{L}_{proto}$ 推动不同类原型分离。BHR 强制连续哈希特征与类中心逼近 $\{-1, +1\}$，损失函数为：

$$
\mathcal{L}_{BHR} = \frac{1}{KD} \sum_{k=1}^K \sum_{d=1}^D ||c_{k,d}| - 1| + \frac{1}{ND} \sum_{i=1}^N \sum_{d=1}^D ||h_{i,d}| - 1|
$$

该公式通过惩罚绝对值偏离 1 的程度，确保哈希码的紧凑性与判别性，减少量化过程中的比特翻转。

## 实验评估

实验在 CUB、Stanford Cars、Oxford Pets、Animalia、Fungi、Arachnida 六个细粒度数据集上进行，评估 All/Old/New 准确率。基线覆盖 SLC、RankStat、WTA、SMILE、PHE 及其变体 DiffGRE。缺失 TALON 等最新测试时自适应方法，导致无法直接对比哈希范式与 TTA 范式的性能上限。

| 方法 | CUB (All/Old/New) | Stanford Cars (All/Old/New) | Arachnida (All/Old/New) |
| :--- | :--- | :--- | :--- |
| SMILE | 32.2 / 50.9 / 22.9 | 26.2 / 46.7 / 16.3 | 29.9 / 57.9 / 12.2 |
| PHE | 36.4 / 55.8 / 27.0 | 31.3 / 61.9 / 16.8 | 37.0 / 75.7 / 12.6 |
| SMILE+Ours | 41.4 / 66.9 / 28.6 | 31.0 / 53.7 / 19.8 | 57.2 / 61.7 / 33.6 |
| PHE+Ours | 45.8 / 75.7 / 30.9 | 38.8 / 74.0 / 21.7 | 39.4 / 80.1 / 21.5 |

PHE+Ours 在 CUB 上达到 45.8% All 准确率，较 PHE 提升 9.4 个百分点；在 Arachnida 上 New 准确率从 12.6% 提升至 21.5%，表明超语义空间对新类发现贡献显著。

## 关联研究分析

从问题动机看，本文与 TALON 等测试时自适应 (TTA) 方法形成范式对比。TALON 通过在线调整模型参数适应新分布，而本文依赖预构建的超语义空间与静态哈希码。这种差异源于任务约束：哈希方法追求毫秒级检索延迟，牺牲了模型的可塑性；TTA 方法允许推理时计算，换取更高的适应精度。本文在 CUB 上 45.8% 的 All 准确率显著低于 TALON 的 65.2%，表明哈希范式在细粒度场景下存在理论上限，量化误差无法通过空间校准完全消除。

从方法设计看，本文与 SimGCD 等参数化 GCD 方法在表示学习机制上存在路径差异。SimGCD 依赖原型分类器与自蒸馏，强调特征空间的几何结构；本文则引入 vMF 分布软分配与二进制正则化，侧重哈希码的离散化稳定性。这种差异反映了离线批量与在线流式场景的不同需求：离线场景可承受高维特征空间的复杂优化，在线场景必须将特征压缩为固定长度二进制码，导致信息损失。本文的超语义空间构建是否能在支持集增大时进一步提升软分配的精度，论文未给出回答。

## 总结

本文要解决的核心矛盾是 OCD 中特征对齐不足导致的哈希码冗余与已知类空间垄断对新类发现的阻碍。现有方法未能同时解决这两个耦合问题，本文通过构建双几何子空间的超语义空间，结合软分配与二进制哈希正则化，在特征空间预定义语义边界并优化码字稳定性。实验证明 PHE+Ours 在 CUB 上达到 45.8% All 准确率，Arachnida New 准确率提升至 21.5%。本文的边界在于哈希范式固有的量化误差，导致其在细粒度场景下性能落后于 TTA 方法，且超语义空间的构建依赖离线预计算，可能违背 OCD 纯在线假设。当支持集规模扩大时，软分配机制的边际收益是否递减，论文未给出回答。
