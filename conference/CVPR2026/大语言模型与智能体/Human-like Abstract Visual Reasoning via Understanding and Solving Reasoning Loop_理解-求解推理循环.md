# CVPR2026最新论文 ｜Human-like Abstract Visual Reasoning via Understanding and Solving Reasoning Loop ｜理解-求解推理循环

研究机构：北京理工大学

作者：Xinwang Chen、Xiuxing Li、Qing Li 等 10 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_5905dfa567e0)

> 视觉抽象推理要求模型从极少示例中归纳规则并泛化，但现有端到端模型因静态处理示例而缺乏动态对齐机制，导致在ARC-AGI等基准上表现远低于人类。本文切入点在于模拟人类“理解-求解”的认知循环，通过两个显式交互模块的递归迭代来动态对齐规则理解与解的生成。具体做法是构建理解模块（UM）与求解模块（SM）的循环架构，并引入基于内部表示一致性的自适应停止机制。该框架以7M参数在ARC-AGI-1上取得47.2%准确率，但其性能仍受限于隐式向量表示对复杂拓扑结构的捕捉能力，且未验证在真实世界噪声数据下的鲁棒性。

## 研究背景

当模型面对ARC-AGI任务时，仅凭2-5个输入-输出对推断潜在变换规则，这一过程要求系统超越表面统计相关性，掌握底层逻辑结构。然而，主流大语言模型（LLMs）如DeepSeek-R1仅取得15.8%准确率，其核心缺陷在于将示例视为静态输入进行单次前向计算，无法在求解过程中动态修正对规则的理解。这种静态处理导致模型无法像人类那样通过“假设-验证-修正”的循环来逐步收敛到正确解，构成了少样本规则归纳稳定性的根本瓶颈。

视觉抽象推理领域的主流路线分为程序合成与测试时训练（TTT）两类，前者擅长精确逻辑但难以处理感知模糊，后者能应对噪声但缺乏规则归纳能力。现有小模型如TRM虽采用递归机制，但依赖固定任务嵌入表，无法动态编码新示例，导致泛化能力受限。本文的切入点在于将神经认知中的迭代推理过程具体化为架构设计，通过显式解耦理解与求解过程，使模型能在推理过程中持续对齐规则表示与解状态，从而突破静态架构在系统性泛化上的局限。

## 核心方法

### 方法参照系

本文问题属于视觉推理架构中的少样本规则归纳任务，与标准流程的关键差异在于：标准流程采用静态特征提取加单次推理，而本文要求模型在推理过程中动态更新对示例规则的理解，实现理解与求解的闭环交互。

### 理解-求解循环架构

设计动机在于解决TRM等静态模型无法动态编码新示例的问题，通过引入理解模块（UM）将示例映射为规则表示，并与求解模块（SM）的解状态进行动态调制。在每一步推理中，UM处理完整示例集 $E_i$ 生成原始规则表示 $e'_i = U_\theta(E_i)$，该表示通过可学习门控 $g_\theta$ 被当前解状态 $z_{i,t-1}$ 调制，产生调制后的规则表示 $\tilde{e}_{i,t-1} = g_\theta(z_{i,t-1}, e'_i)$。SM随后整合问题输入 $x_i$、前一步状态 $z_{i,t-1}$ 和调制规则 $\tilde{e}_{i,t-1}$ 更新解状态：

$$
z_{i,t} = S_\theta(x_i, z_{i,t-1}, \tilde{e}_{i,t-1})
$$

这一机制使模型能根据当前解的进展动态调整对规则的关注点，解决了静态嵌入表无法适应新任务的问题，实现了规则理解与解生成的协同优化。

### 自适应推理停止机制

设计动机在于避免固定推理步数导致的计算浪费或不足，通过内部表示一致性动态决定推理深度。在每一步生成草稿解 $\hat{y}_{i,t}$ 后，将其作为假设新示例传入UM生成答案表示 $e_{i,ans} = U_\theta(\{(x_i, \hat{y}_{i,t})\})$。计算两个余弦相似度指标：示例内一致性 $C_{intra}$ 为已知示例表示的平均两两相似度，答案-示例一致性 $C_{ans}$ 为答案表示与所有示例表示的平均相似度。当 $C_{ans} > C_{intra}$ 时停止推理，即当生成解与示例规则在语义空间中对齐时终止。该机制使模型能自动分配计算资源，复杂任务推理更久，简单任务提前终止，实现了计算效率与推理精度的平衡。

## 实验评估

实验在ARC-AGI-1评估集上进行，采用pass@2协议，对比基线包括LLMs（DeepSeek-R1, o3-mini-high, Gemini 2.5 Pro 32K）和专用模型（TRM, HRM, Omni-ARC）。USRL以7M参数取得47.2%准确率，超越同参数TRM（44.6%）和更大参数HRM（40.3%），显著优于所有LLM基线。

| 模型 | 参数量 | 准确率 (%) |
| :--- | :--- | :--- |
| DeepSeek-R1 | ~671B | 15.8 |
| o3-mini-high | - | 34.5 |
| Gemini 2.5 Pro 32K | - | 37.0 |
| Omni-ARC | 0.5B | 40.0 |
| HRM | 27M | 40.3 |
| TRM | 7M | 44.6 |
| USRL (Ours) | 7M | 47.2 |

消融实验显示，仅SM基线为36.5%，添加UM（无门控）提升至40.8%（+4.3%），引入门控机制再增2.4%至43.2%，对比损失 $L_{contrast}$ 贡献+3.2%至46.4%，随机停止训练策略最终+0.8%达47.2%。自适应停止推理时准确率为47.0%，仅下降0.2%，验证了机制的有效性。

| 配置 | 参数量 | 准确率 (%) | Δ |
| :--- | :--- | :--- | :--- |
| Base (Solving Module only) | 3.3M | 36.5 | - |
| + Understanding Module (w/o Gate) | 6.7M | 40.8 | +4.3 |
| + Understanding Module (w/ Gate) | 7.0M | 43.2 | +2.4 |
| + Contrastive Loss (Lcontrast) | 7.0M | 46.4 | +3.2 |
| + Stochastic Halting (training) | 7.0M | 47.2 | +0.8 |
| + Adaptive Reasoning Halting (inference) | 7.0M | 47.0 | -0.2 |

评估边界方面，论文未报告置信区间，且仅在ARC-AGI-1单一基准上验证，未覆盖RAVEN等程序化生成基准。代码未公开，训练使用8块NVIDIA L40s和16块V100 GPU，超参数包括温度 $\tau=0.07$、平衡系数 $\lambda_c=0.5$、最大推理步数 $T_{max}=16$。

## 关联研究分析

从方法设计看，USRL与TRM共享Recurrent Transformer骨干，但关键差异在于规则表示的动态性。TRM依赖固定任务嵌入表，无法编码新示例，而USRL通过UM动态提取规则表示并解状态调制，解决了静态嵌入的泛化局限。这一差异源于任务特性：ARC-AGI要求从新示例中归纳规则，而非识别已知任务，因此动态规则理解是必要条件。

从问题动机看，USRL与VARC同属ARC-AGI前沿，但路线不同。VARC将ARC问题重构为图像翻译，采用测试时训练策略，侧重感知层面的适应；USRL则聚焦架构内迭代，通过理解-求解循环实现规则层面的动态对齐。VARC在ARC-1上取得54.5%准确率，但协议不同（图像翻译 vs 规则归纳），不可直接比较。USRL的隐式向量表示与VARC的显式视觉特征提取形成对比，前者更侧重规则语义，后者更侧重视觉结构，两者在组合泛化上的表现差异值得进一步探究。

## 总结

本文要解决的核心矛盾是静态架构在少样本规则归纳中无法动态对齐理解与求解，导致系统性泛化失败。切入点在于将人类认知循环具体化为UM-SM动态交互架构，通过递归迭代和自适应停止实现规则理解与解生成的协同优化。方法上，USRL以7M参数在ARC-AGI-1上取得47.2%准确率，超越同规模TRM和更大规模HRM。边界在于，47.2%仍远低于人类水平，且隐式向量表示可能限制了对复杂拓扑结构的捕捉能力，论文未验证在真实世界噪声数据下的鲁棒性。当支持集从2-5个示例扩展到更多示例时，UM的规则表示是否仍能保持判别性，自适应停止机制的一致性阈值是否需动态调整，论文未给出回答。
