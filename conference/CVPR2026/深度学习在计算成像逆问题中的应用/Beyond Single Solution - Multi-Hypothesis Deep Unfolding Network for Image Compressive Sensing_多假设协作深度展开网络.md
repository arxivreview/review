> 导读 压缩感知（CS）逆问题旨在从远少于奈奎斯特采样定理要求的线性测量中恢复图像，其核心矛盾在于测量矩阵的病态性导致解空间非唯一。现有深度展开网络（DUN）通常将推理限制在单一解空间，忽略了多解间的内在相关性，导致在低采样率下易陷入局部最优。本文提出多假设协作深度展开网络（MHC-DUN），通过并行优化多个候选假设并引入自适应步长与协作近端映射，显式利用解空间的多样性。该框架在标准基准上刷新了SOTA，但其性能增益依赖于理想算子假设，且未提供概率意义上的不确定性量化，其鲁棒性边界尚待验证。

## 研究背景

压缩感知重建的数学本质是求解 $\tilde{x} = \arg \min_x \frac{1}{2}\|Ax - y\|_2^2 + \lambda R(x)$，其中数据保真项确保物理一致性，正则化项 $R(x)$ 引入先验知识以约束解空间。由于测量矩阵 $A$ 的秩远小于信号维度 $N$，根据秩-零度定理，解空间构成一个高维仿射子空间，这意味着存在多个数学上有效的候选解。传统优化方法依赖全变分等手工先验，虽计算高效但难以捕捉复杂纹理，而早期深度黑盒网络虽提升了精度却缺乏物理可解释性。

深度展开网络（DUN）通过将近端梯度下降（PGD）算法展开为级联网络结构，在保持物理模型一致性的同时引入了数据驱动先验，成为当前主流范式。然而，现有DUN（如ISTA-Net、OCTUF+）普遍采用单假设推理策略，即在单一特征域内进行信息提取与整合。这种范式忽略了病态逆问题固有的多解性，导致网络在回归最优解时面临高维空间中的局部最优陷阱，尤其在低采样率下重建质量受限。本文的切入点在于显式建模并利用多个候选假设之间的相关性，通过联合优化多个解空间来克服单解推理的局限性。

## 核心方法

### 方法参照系

本文基于PGD算法的展开范式，将迭代过程解耦为梯度下降与近端映射两个步骤。与标准DUN仅传递单一重建图像不同，本文框架将优化目标扩展为多假设集合 $\tilde{X} = \{x_1, ..., x_T\}$，旨在通过联合优化捕捉解空间的内在歧义性，而非仅输出单一最大后验估计。

### 多假设协作梯度下降模块

传统PGD展开网络使用固定或标量学习的步长 $\rho$，无法适应不同空间区域及不同假设间的动态变化。本文引入AlphaNet模块，动态预测空间变化的步长图 $P^{(k)}$，实现多假设间的协同梯度更新。该设计解决了固定步长在复杂纹理区域更新不足或震荡的问题。步长图由前一阶段的特征 $F^{(k-1)}$ 与假设 $X^{(k-1)}$ 联合生成：

$$ P^{(k)} = \text{Sigmoid}(\text{Conv}(v^{(k)})) $$

其中 $v^{(k)}$ 是经过Alpha-Block残差空间注意力机制精炼的特征。这一机制使得每个假设在梯度下降过程中能够根据局部图像内容自适应调整更新幅度，增强了多解探索的稳定性。

### 多假设协作近端映射模块

在梯度下降后，传统方法独立应用近端算子，忽略了假设间的结构相关性。本文设计多假设协作块（MHCB），通过通道与空间注意力机制融合多个假设的特征，实现联合去噪。该模块利用假设间的互补性，抑制单一假设可能产生的伪影。融合过程表示为：

$$ X^{(k)} = \text{MHCB}(\text{Cat}(\hat{x}_1^{(k)}, ..., \hat{x}_T^{(k)})) $$

其中 $\hat{x}_i^{(k)}$ 为各重建头输出的初始假设。MHCB内部采用双分支结构，结合卷积捕获局部先验与Swin Transformer建模非局部依赖，从而在保持物理一致性的同时提升重建细节。

## 实验评估

实验在Set11和Urban100数据集上进行，采样率覆盖0.01至0.40，对比了8种深度黑盒网络（DBN）和9种深度展开网络（DUN）。基线覆盖了NL-CSNet、CSformer等代表性DBN，以及USB-Net、CPP-Net等最新DUN，但未包含基于扩散模型的PnP-Diffusion等概率采样方法，限制了与不确定性量化方法的直接对比。

| 方法 | Set11 (0.10) PSNR/SSIM | Urban100 (0.10) PSNR/SSIM |
| :--- | :--- | :--- |
| NL-CSNet | 30.05 / 0.8995 | 28.43 / 0.8506 |
| USB-Net | 31.31 / 0.9149 | 28.58 / 0.8818 |
| MHC-DUN | 31.86 / 0.9208 | 29.97 / 0.8938 |

在Urban100 0.10采样率下，MHC-DUN的PSNR为29.97 dB，较USB-Net提升1.39 dB；在Set11上，其平均PSNR较USB-Net提升0.45 dB。消融实验显示，移除AlphaNet导致平均PSNR下降0.21 dB，移除MHCB下降0.17 dB，表明自适应步长与协作近端映射对性能提升均有显著贡献。假设数量 $T$ 从1增至16时，PSNR提升0.11 dB，但增至32时仅提升0.02 dB，显示多假设收益存在边际递减效应。

评估指标仅包含PSNR和SSIM，缺乏LPIPS等感知质量指标及不确定性量化度量。实验基于理想线性算子假设，未测试前向算子失配场景下的鲁棒性。代码未公开，但提供了详细的超参数设置（如 $T=16$, $K=10$ stages），在NVIDIA RTX 3090 GPU上训练600 epochs，具备一定可复现性。

## 关联研究分析

从问题动机看，MHC-DUN与PnP-Diffusion均旨在克服逆问题的非唯一性，但路径截然不同。PnP-Diffusion通过扩散模型的后验采样提供概率分布，天然具备不确定性量化能力；而MHC-DUN采用确定性多假设融合，虽提升了点估计精度，但未提供校准的概率估计。这种差异源于任务特性：CS重建通常追求高保真点估计，而科学成像更关注置信度。MHC-DUN的多假设机制是否等价于隐式概率平均，论文未给出理论解释。

从方法设计看，MHC-DUN与USB-Net同属PGD展开框架，但USB-Net聚焦于特征传递效率，而MHC-DUN引入假设间交互。USB-Net通过共享参数降低计算复杂度，MHC-DUN则通过AlphaNet增加参数以换取空间自适应步长。MHC-DUN在Urban100上的优势（1.39 dB）大于Set11（0.45 dB），暗示其多假设机制在纹理复杂的城市景观中更能捕捉非局部结构，而在自然图像中收益相对有限。

## 总结

MHC-DUN针对深度展开网络在单一解空间推理导致的局部最优问题，提出多假设协作框架，通过AlphaNet自适应步长与MHCB协作近端映射，显式利用解空间多样性。实验表明，该方法在Urban100 0.10采样率下达到29.97 dB PSNR，较SOTA基线USB-Net提升1.39 dB。然而，其性能增益依赖于理想算子假设，且未提供不确定性量化，多假设融合的物理意义仍停留在启发式层面。当采样率进一步降低至0.01时，多假设机制能否有效区分噪声与信号，论文未给出回答。
