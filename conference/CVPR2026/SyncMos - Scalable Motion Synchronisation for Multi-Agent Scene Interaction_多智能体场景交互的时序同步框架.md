# CVPR2026最新论文 ｜SyncMos: Scalable Motion Synchronisation for Multi-Agent Scene Interaction ｜多智能体场景交互的时序同步框架

研究机构：澳大利亚墨尔本大学、韩国汉阳大学

作者：Lingxiao Li、Dongwon Kim、Lingyan Ruan 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_cc1f4b513e42)

> 多智能体3D场景交互的核心难点在于动作间的因果时序对齐，现有方法受限于固定代理数量或仅建模空间关系，导致交接、反应等动作出现时间错位。SyncMos 通过 LLM 解析依赖关系并利用扩散后验采样进行时间扭曲，实现了无需重训练的多代理协调。该框架在长因果链规划上显著优于基线，但时序控制精度在大幅偏移时急剧下降，且缺乏对运动自然度的综合评估。

## 研究背景

当多个智能体在共享空间中执行“传递”或“协作”任务时，动作的合理性不仅取决于空间位置，更取决于时间上的精确耦合。若传递者释放物体的时刻与接收者抓取的时刻存在偏差，即便单体运动流畅，整体交互仍会失效。这种时序耦合要求模型具备跨代理的全局时间感知能力，而传统单智能体生成模型仅关注自身轨迹的物理一致性，缺乏对交互伙伴动作节奏的响应机制。

当前主流的多智能体交互生成方法存在两个瓶颈：一是架构僵化，如 InterGen 依赖固定大小的联合建模，无法扩展至动态数量的代理；二是时序解耦，如 Lingo 虽能生成长时程单智能体运动，但多智能体间仅通过空间条件间接关联，缺乏显式的时间同步机制。Event-Driven Storytelling 等基于 LLM 的规划方法虽能处理叙事逻辑，但缺乏对底层运动时序的精确控制，导致生成的动作在时间轴上松散。SyncMos 的切入点在于将高层语义规划与低层时序控制解耦，利用 LLM 构建依赖图，并通过扩散模型的梯度引导实现跨代理的时间对齐，从而在不重训练骨干网络的前提下实现可扩展的同步生成。

## 核心方法

### 方法参照系

本文问题属于“LLM 规划 + 扩散生成”路线，但区别于 Social Structure Matters 等仅关注社交结构的方法，SyncMos 的核心差异在于引入了显式的**时序同步模块**。标准流程通常直接生成或简单拼接各代理运动，而本文在生成后增加了一个基于时间扭曲（Time-warping）和扩散后验采样（DPS）的精炼阶段，以强制满足跨代理的时间约束。

### 依赖感知事件规划

设计动机：解决 LLM 在长因果链中容易丢失时序依赖关系的问题。传统方法如 Event-Driven Storytelling 自回归生成事件，缺乏全局依赖建模，导致“先拿后给”等因果顺序错误。SyncMos 引入结构化事件图 $G = (E, R)$，其中 $E$ 为单代理事件集，$R$ 为时序依赖集。

$$
R = R_{\text{seq}} \cup R_{\text{par}}
$$

该公式将依赖关系显式分为顺序依赖（Sequential）和并行依赖（Parallel）。LLM 通过少样本提示（Few-Shot Prompting）一次性输出事件列表及依赖关系，而非逐步生成。这种显式建模使得规划器能够区分“同时发生”与“先后发生”的动作，从源头保证逻辑正确性。实验显示，该方法在依赖子集上的依赖准确率（DA）从基线的 20.5% 提升至 96.9%（GPT-4o），证明了显式依赖图对长时程逻辑推理的关键作用。

### 时序引导扩散精炼

设计动机：解决时间扭曲（Time-warping）直接修改运动序列导致的物理不自然问题。简单的时间拉伸会破坏运动的平滑性，而 SyncMos 将时间扭曲后的轨迹视为噪声观测，通过约束引导的扩散去噪过程进行修正。

$$
\mathbf{x}_{i-1} = \mu_{\theta}(\mathbf{x}_i, i) - \lambda \nabla_{\mathbf{x}_i} C(\hat{\mathbf{x}}_0) + \sigma_i \mathbf{z}
$$

其中 $C(\hat{\mathbf{x}}_0) = \|\mathbf{y} - \hat{\mathbf{x}}_0\|^2$ 为 L2 时序约束，$\mathbf{y}$ 为时间扭曲后的目标轨迹，$\lambda$ 控制约束强度。该公式在去噪过程中注入梯度项，引导模型在保持运动自然度（由扩散先验 $\mu_{\theta}$ 保证）的同时，逐步逼近目标时间位置。这种机制允许模型在时间轴上“探索”可行的运动变体，而非机械地拉伸帧，从而在 ±0.5s 偏移下保持 84.7% 的成功率，避免了传统方法中常见的运动抖动或加速伪影。

## 实验评估

实验基于 Lingo 数据集构建 15 个测试用例，对比 Event-Driven Storytelling 基线。基线覆盖 LLM 规划路线，但缺失 Interact2Ar 等扩散模型直接生成多智能体运动的强基线，导致无法评估 SyncMos 相对于端到端多智能体生成方法的优势。

| 子集 | 模型 | DA (%) | SPR (%) |
| :--- | :--- | :--- | :--- |
| Dependency | Baseline (GPT-4o) | 20.5 | 0.0 |
| Dependency | Ours (GPT-4o) | 96.9 | 80.0 |
| Synchronisation | Baseline (Qwen-3-235B) | 68.4 | 33.3 |
| Synchronisation | Ours (Qwen-3-235B) | 89.9 | 53.3 |

规划器在依赖子集上的表现提升最为显著，DA 从 20.5% 跃升至 96.9%，表明显式依赖图对长因果链的鲁棒性。然而，在同步子集上，DA 提升幅度较小（68.4% → 89.9%），暗示并行动作的时序对齐难度低于顺序动作，或基线在并行场景下已具备一定能力。

| 偏移量 (s) | 成功率 (%) |
| :--- | :--- |
| +0.5 | 84.7 |
| +1.0 | 78.0 |
| +1.5 | 76.0 |
| -0.5 | 88.0 |
| -1.0 | 75.3 |
| -1.5 | 37.3 |

时序控制成功率在 ±1.0s 内保持较高水平，但在 -1.5s 时骤降至 37.3%。这一反直觉现象表明，负向偏移（提前动作）对扩散模型的去噪过程干扰更大，可能导致运动轨迹发散。论文未报告 FID 或 Penetration 指标，无法评估时序同步是否以牺牲运动自然度为代价，这是评估的主要盲区。

评估协议局限于静态场景和短时程交互，未测试动态环境下的在线同步能力。代码未公开，超参数（如 $\lambda$ 和 $t=30$）的敏感性分析缺失，限制了可复现性。

## 关联研究分析

从问题动机看，SyncMos 与 Social Structure Matters 同属 LLM 规划路线，但前者聚焦物理时序，后者侧重社交结构。Social Structure Matters 通过 LLM 规划角色分配和阶段进展，但未解决底层运动的精确时间对齐问题；SyncMos 则通过 DPS 实现帧级同步，但缺乏对社交语义（如礼貌、犹豫）的建模。这种差异源于任务特性：物理交互要求毫秒级精度，而社交交互更关注宏观逻辑。

从方法设计看，SyncMos 与 DeSeG 均利用扩散模型进行约束引导，但 DeSeG 将碰撞感知内化于生成过程，而 SyncMos 采用后处理式的时序约束。DeSeG 的优势在于生成即物理合理，但 SyncMos 的优势在于无需重训练，可直接适配现有单智能体模型。这种“内化”与“外化”的取舍反映了领域共识的分歧：虚拟生成倾向于内化约束，而机器人控制倾向于外化修正。SyncMos 的后处理机制在实时性上更具优势，但可能引入累积误差，这在长序列生成中尤为明显。

## 总结

SyncMos 旨在解决多智能体交互中的时序同步难题，通过 LLM 依赖感知规划与扩散后验采样相结合，实现了无需重训练的可扩展协调。其核心贡献在于显式依赖图将长因果链的规划准确率提升至 96.9%，以及时序引导精炼在 ±0.5s 偏移下保持 84.7% 的成功率。然而，实验暴露了负向大幅偏移下的稳定性崩溃（-1.5s 成功率仅 37.3%），且缺乏对运动自然度的综合评估。当依赖链长度超过 10 个代理时，时序误差是否会在累积中放大，论文未给出回答。
