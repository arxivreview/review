# CVPR2026最新论文 ｜One Token, Two Fates: A Unified Framework via Vision Token Manipulation Against MLLMs Hallucination ｜视觉Token双命运统一校准

研究机构：南京大学、东南大学

作者：Zhan Fa、Yue Duan、Jian Zhang 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.10360)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.10360)

> 多模态大语言模型（MLLMs）幻觉源于视觉信号在自回归生成中逐渐衰减，而现有无训练方法仅能孤立地增强视觉或抑制语言惯性，简单组合反而导致性能退化。本文切入点在于将视觉Token视为兼具“增强”与“抑制”双重潜能的统一载体，在中间表征层同时执行协同视觉校准（SVC）与因果表征校准（CRC）。该方法在LLaVA-1.5上将POPE平均准确率提升至86.79%，推理延迟仅增加1.06倍，但其在POPE Random设置下的绝对值仍低于部分最新SOTA，且未覆盖2026年最新的表征编辑基线，其统一框架在极端长序列下的稳定性尚存疑。

## 研究背景

当MLLMs处理图像描述任务时，视觉编码器输出的Token序列作为初始上下文进入Transformer解码器。随着自回归生成步数增加，视觉Token在注意力机制中的权重呈指数级衰减，而语言模型预训练中习得的统计规律（语言先验）逐渐主导Token预测，导致模型在视觉证据模糊时生成不存在的物体，即对象幻觉。这一现象的本质是视觉接地（Visual Grounding）的失效，即模型输出与视觉输入之间的忠实对应关系被语言惯性破坏。

现有无训练干预策略分为两条孤立路线：视觉注意力增强（如PAI）试图在注意力层放大视觉信号，但难以对抗深层语言先验的压制；文本解码优化（如VCD）通过在Logits层对比原始与扰动图像的分布来抑制幻觉，但依赖像素级扰动（Modality-Gap）引入的噪声导致校正信号不稳定。这两类方法分别作用于不同层级且校准时机冲突，简单叠加不仅无法产生协同效应，反而因信号干扰导致性能下降。本文指出，幻觉是视觉-语言平衡的系统性失衡，需要一种在统一表征层级、基于同一核心资产（视觉Token）的协同干预机制。

## 核心方法

### 方法参照系

本文问题属于推理时干预（Inference-Time Intervention）范畴，但区别于传统的Logits层对比解码或单一注意力重加权。其关键差异在于放弃“增强”与“抑制”的二元对立，将两者统一在中间层（Layer 16及浅层）的隐状态操作，以视觉Token为唯一信号源，同时解决视觉衰减与语言惯性问题。

### 协同视觉校准（SVC）

SVC针对视觉信号随生成步数衰减的问题，利用数据增强图像的语义互补性构建更丰富的视觉锚点。设计动机在于单一原始图像Token的注意力分布往往分散，而增强图像（如水平翻转、高斯模糊、椒盐噪声）能提供互补的视觉焦点。SVC在预定义的中间层 $L_c=16$ 拦截隐状态序列 $\mathbf{H}^{[L_c-1]}_t$ 作为Query，将原始与增强图像的视觉Token拼接成的协同视觉记忆库 $\mathbf{V}_{syn}$ 作为Key和Value，通过缩放点积注意力计算视觉上下文 $\mathbf{C}_t$，并以插值方式融合回隐状态：

$$ \mathbf{H}'^{[L_c]}_t = (1-\lambda_s)\mathbf{H}^{[L_c-1]}_t + \lambda_s \mathbf{C}_t $$

其中 $\lambda_s=0.06$ 控制融合比例。该机制在不增加额外前向传播的前提下，通过注入互补视觉语义，重新激活模型对图像细节的关注，对抗视觉信号的渐进性丢失。

### 因果表征校准（CRC）

CRC旨在抑制语言惯性导致的幻觉倾向，其核心创新在于用潜空间剪枝（Information-Gap）替代传统的像素级扰动（Modality-Gap）生成负样本。设计动机在于像素级扰动产生的负样本表征往往偏离原始分布，引入无关噪声；而随机保留 $N_h=5$ 个视觉Token的潜空间剪枝，能生成“分布内”的负样本，更精准地隔离内在偏差。CRC在浅层（$1 \dots L_c$）并行计算原始流与剪枝流的隐状态差值 $\Delta \mathbf{H}^{[l,k]}$，平均 $K=3$ 个负样本得到稳定的幻觉方向向量 $\mathbf{v}_{crc}^{[l]}$。在后续生成步骤中，通过归一化空间中的线性组合修正隐状态：

$$ \mathbf{H}^{[l]}_{pos} = \text{Renorm}\left( \text{Norm}(\mathbf{H}^{[l]}_{org}) - \lambda_c \text{Norm}(\mathbf{v}_{crc}^{[l]}) \right) $$

其中 $\lambda_c=0.1$ 为校准强度。该操作基于结构因果模型（SCM），通过减去由缺失视觉信息引起的偏差分量，实现从“幻觉表征”向“视觉真实表征”的反事实调整。

## 实验评估

实验在LLaVA-1.5、Shikra、MiniGPT-4和InstructBLIP四种架构上进行，基线包括VCD、PAI、VISTA和ONLY。基线覆盖了解码策略与注意力增强两条主流路线，但缺失了2026年最新的表征编辑方法（如HulluEdit、RUDDER），这可能影响对当前SOTA的准确定位。

| 方法 | LLaVA-1.5 POPE Avg. Acc (%) | LLaVA-1.5 CHAIRs (64 tokens) | LLaVA-1.5 MME Perception |
| :--- | :--- | :--- | :--- |
| Vanilla | 84.79 | 25.4 | 1444.23 |
| VCD | 84.80 | 24.1 | 1445.13 |
| VISTA | 86.15 | 21.4 | 1450.54 |
| Ours | **86.79** | **18.1** | **1456.28** |

本文方法在POPE平均准确率上较VISTA提升0.64个点，在CHAIRs指标上较VISTA降低3.3，表明统一框架在抑制幻觉的同时保持了通用感知能力。

| 配置 | COCO Acc (%) | AOKVQA Acc (%) |
| :--- | :--- | :--- |
| Vanilla | 84.79 | 77.23 |
| + SVC (V_syn) | 85.55 | 79.43 |
| + CRC (Pruned) | 86.11 | 81.65 |
| Ours (SVC + CRC) | **86.79** | **82.23** |

消融实验显示，CRC模块的增益（+1.32 Acc on COCO）大于SVC模块（+0.76 Acc），且两者结合产生协同效应（总增益+2.00 Acc > 单独增益之和）。这验证了视觉增强与偏差抑制并非零和博弈，而是互补关系。

评估边界方面，论文未报告置信区间，且POPE分数为三个子集（Random, Popular, Adversarial）的平均值，掩盖了在不同难度下的具体表现差异。代码未公开，超参数（如 $L_c=16$）在所有模型中固定，未针对不同架构进行自适应调整，限制了其泛化性的验证。

## 关联研究分析

从负样本生成机制看，本文与VCD的核心差异在于扰动层级。VCD依赖像素级图像扰动（Modality-Gap），其负样本表征往往偏离原始分布，导致校正信号包含大量与视觉细节无关的噪声；本文采用潜空间Token剪枝（Information-Gap），生成的负样本在t-SNE可视化中紧密聚集于原始表征附近，属于“分布内”探针。这一差异源于对幻觉成因的不同理解：VCD假设幻觉源于视觉输入的不确定性，而本文认为幻觉源于模型内在偏差对视觉路径的混淆，因此需要更纯净的偏差隔离信号。

从干预层级看，本文与HulluEdit等表征编辑方法均作用于激活空间，但HulluEdit依赖全局校正向量或样本级子空间投影，而本文通过SVC和CRC在中间层动态注入视觉上下文并减去偏差方向。本文的统一框架解决了HulluEdit等单一表征编辑方法可能存在的“过度校正”或“校正不足”问题，因为它同时考虑了视觉信号的增强与语言惯性的抑制。然而，本文未对比HulluEdit等2026年最新方法，无法直接证明其在细粒度幻觉（如属性、关系幻觉）上的优势，仅证明了在对象存在性幻觉上的有效性。

## 总结

本文要解决的核心矛盾是视觉信号衰减与语言惯性主导之间的失衡，现有方法因孤立干预导致组合失效。本文抓住视觉Token的双重潜能，通过SVC增强视觉接地、CRC抑制内在偏差，在中间层实现统一校准。实验证明该方法在LLaVA-1.5上将POPE平均准确率提升至86.79%，CHAIRs降至18.1，且推理延迟仅增加1.06倍。其边界在于未覆盖最新表征编辑基线，且超参数固定未适配不同架构。当视觉Token数量进一步减少至低于5时，CRC的偏差隔离能力是否仍能保持“分布内”特性，论文未给出回答。
