# CVPR2026最新论文 ｜Illustrator's Depth: Monocular Layer Index Prediction for Image Decomposition ｜插画师深度：基于单目层索引预测的图像解构

研究机构：Adobe研究院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_23e50843225b)

> 数字艺术创作中的核心痛点在于如何将扁平图像分解为可独立编辑的有序图层，而现有单目深度估计模型仅能恢复物理几何，无法捕捉创作逻辑中的拓扑排序。本文提出“Illustrator’s Depth”概念，将深度定义重构为像素到图层索引的映射，利用预训练单目深度模型作为特征提取器，在矢量图形数据集上训练前馈网络直接预测层序。该方法在矢量重建保真度上持平传统工具，但层序一致性显著超越通用深度模型，为可编辑图像生成提供了新范式，但其对复杂非矢量场景的泛化能力仍存疑。

## 研究背景

矢量图形编辑依赖图层堆叠结构，每个像素需对应唯一的图层索引以支持独立操作。然而，单目深度估计（Monocular Depth Estimation, MDE）模型旨在恢复物理距离，其训练目标导致模型忽略无真实体积的平面元素（如阴影、印刷图案），且无法输出全局一致的离散排序。这种物理深度与创作层序的本质错位，使得现有MDE模型无法直接用于图像解构任务。

深度补全领域长期聚焦于从稀疏测量恢复稠密几何，其核心矛盾是尺度模糊与传感器噪声，主流路线通过基础模型适配或高效架构解决跨域泛化问题。然而，这些方法均假设深度是度量量，且依赖稀疏深度输入进行尺度对齐。本文切入点在于彻底重构任务定义：不恢复物理几何，而是推断艺术家的构图逻辑。通过引入SVG数据集构建层序真值，将深度估计转化为层索引预测问题，规避了尺度模糊，但引入了对矢量结构先验的依赖。

## 核心方法

### 方法参照系

本文问题可置于“基础模型适配”路线下，但关键差异在于输入与输出：传统深度补全需稀疏深度输入以对齐尺度，输出为度量深度图；本文仅用RGB图像，输出为离散层索引，无稀疏约束，目标从几何重建转向拓扑排序。

### 层序真值构建与编码

设计动机：现有SVG数据集存在图层歧义（如非连续同色层重叠），导致训练信号噪声大，无法学习稳定的层序映射。本文通过三阶段数据清洗解决此问题：首先合并连续同色层以简化结构，其次排除非连续同色层重叠的歧义案例，最后采用RGB编码策略将层索引嵌入像素值。具体地，层索引 $i$ 被编码为 $[i \bmod 256, \lfloor i/256 \rfloor \bmod 256, \lfloor i/256^2 \rfloor \bmod 256]$，通过自定义光栅化生成图像-深度对。该编码允许高效表示大量图层，且无需额外数据加载开销，确保了真值的一致性与可学习性。

### 尺度不变层序预测

设计动机：自然图像中远处物体深度值大且难估计，MDE模型通常学习逆深度 $1/d$ 以优先前景精度；但插画层序从背景到前景均匀分布，直接预测逆深度会导致背景层优化不足。本文采用尺度不变归一化损失，聚焦相对顺序而非绝对值。对于深度图 $D$，计算中位数 $m$ 与平均绝对偏差 $s$，归一化深度 $\hat{d} = (d - m) / s$，损失函数为：

$$
\mathcal{L}_{MAE}(D(I), D_\theta(I)) = |\hat{D}(I) - \hat{D}_\theta(I)|
$$

该公式通过归一化消除层数 $N$ 的尺度影响，确保网络关注层间相对顺序。结合Depth Pro（基于DINOv2）的预训练权重初始化，模型利用物理几何先验泛化至复杂艺术图像，实现前馈推理（<1秒），无需测试时优化。

## 实验评估

实验在MMSVG-Illustration数据集（100K SVG，1536×1536分辨率）上进行，训练80%，评估20%。基线覆盖通用MDE模型（Depth Pro, Depth Anything-v2）及矢量化工具（VTracer, LIVE, Starvector, OmniSVG），但未对比知识库中零样本深度补全SOTA（如Test-Time Prompt Tuning），因任务定义不同。主实验显示，本文方法在层序一致性（Order）上显著优于MDE基线，证明专用训练优于通用物理深度预测。

| 方法 | Order ↑ | MAE ↓ | MSE ↓ |
| :--- | :--- | :--- | :--- |
| Depth Pro [2] | 0.636 | 1.44 | 4.76 |
| Depth Anything-v2 [54] | 0.791 | 1.16 | 3.58 |
| Ours | 0.987 | 0.12 | 0.26 |

消融实验验证了关键设计决策：移除Depth Pro初始化或数据清洗导致Order显著下降，证明物理先验与数据质量的重要性。直接预测层索引（而非逆深度）在Order上略优于逆深度（0.981 vs 0.980），但MAE和MSE大幅降低（0.16/0.29 vs 0.50/1.88），表明直接索引预测更平衡前景与背景优化。

| 模型变体 | Order ↑ | MAE ↓ | MSE ↓ |
| :--- | :--- | :--- | :--- |
| 无Depth Pro初始化 | 0.903 | 0.51 | 1.17 |
| 无数据清洗 | 0.905 | 0.53 | 1.21 |
| 逆深度训练 | 0.980 | 0.50 | 1.88 |
| 完整模型 | 0.981 | 0.16 | 0.29 |

评估边界：指标仅覆盖层序一致性，未评估边缘保真度或局部几何细节；数据集限于矢量图形，未测试复杂照片或动态视频；代码未公开，但训练细节（8×A100，40 epochs，cosine LR）可复现。

## 关联研究分析

从问题动机看，本文与深度补全领域（如LDCM, Any2Full）的根本差异在于目标函数：后者解决稀疏深度尺度模糊，依赖稀疏输入对齐；本文无稀疏输入，通过直接预测索引规避尺度问题，挑战了“必须对齐尺度”的共识。这一差异源于任务特性：矢量图层的层序是创作逻辑，非物理几何，因此稀疏深度约束不适用。

从方法设计看，本文与通用MDE模型（如Depth Anything-v2）共享骨干网络，但训练目标不同：MDE学习物理深度，本文学习层序。Depth Anything-v2在Order上达0.791，本文达0.987，证明专用微调的必要性。然而，本文未探索非矢量图像（如照片）的层序推断，其泛化能力依赖Depth Pro的物理先验，但物理先验对无体积元素的排序能力有限，这一盲区在实验中未充分验证。

## 总结

本文核心矛盾在于物理深度模型无法捕捉创作层序，切入点在于重构深度定义为层索引预测，利用MDE骨干先验与SVG真值训练前馈网络。实验证明其在层序一致性上显著优于通用MDE（Order 0.987 vs 0.791），矢量重建保真度持平VTracer（MSE 0.018 vs 0.019）。边界在于数据集限于矢量图形，未测试复杂照片或动态场景，且层序预测对非矢量元素的鲁棒性未验证。当输入包含大量无体积平面元素（如复杂纹理）时，物理先验是否足以维持全局层序一致性，论文未给出回答。
