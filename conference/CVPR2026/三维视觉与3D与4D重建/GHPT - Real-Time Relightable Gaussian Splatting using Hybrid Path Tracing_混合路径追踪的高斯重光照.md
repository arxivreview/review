# CVPR2026最新论文 ｜GHPT: Real-Time Relightable Gaussian Splatting using Hybrid Path Tracing ｜混合路径追踪的高斯重光照

作者：Jinyang Bo、Fan Dou、Wenrui Quan 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_bad3cdfcdce6)

> 3D高斯泼溅（3DGS）虽实现了实时新视角合成，但缺乏物理光照模型，无法支持重光照与场景组合，限制了其在AR/VR中的应用。现有逆渲染方法或依赖近似光照公式导致真实感不足，或采用高斯光线追踪导致效率低下。本文提出GHPT，通过三阶段框架结合平面高斯重建、网格物理渲染与因子化逆路径追踪，实现了基于Vulkan的实时高斯重光照。该方法在重光照质量上优于现有基线，但其性能高度依赖硬件加速光线追踪单元，且中间网格的几何误差可能累积。

## 研究背景

理解本文需先厘清3DGS在物理渲染中的结构性缺陷。3DGS通过显式各向异性高斯基元与可微光栅化实现高效渲染，但其颜色由球谐函数（Spherical Harmonics, SH）编码，本质上是视角相关的辐射场，而非物理材质属性。这种表示无法分离几何、材质与光照，导致无法模拟阴影、间接照明等全局光照效应。逆渲染（Inverse Rendering）旨在从图像中解耦这些要素，但传统基于神经辐射场（NeRF）的方法依赖射线步进，计算开销巨大且表达力有限。

GS逆渲染分为前向与延迟渲染两类。前向方法（如R3DG）对每个高斯单独着色后混合，但难以处理复杂光照交互；延迟方法（如IRGS）先渲染G-buffer再计算光照，但多采用分裂和近似（Split-Sum Approximation）或高斯光线追踪，前者牺牲真实感，后者因高斯分布的复杂几何导致光线追踪效率极低。本文切入点在于引入混合路径追踪（Hybrid Path Tracing），即从光栅化G-buffer发射光线，而非从相机发射，从而利用现代GPU的硬件加速光线追踪单元处理可见性与间接照明，同时保留高斯表示的渲染效率。

## 核心方法

### 方法参照系

标准GS逆渲染流程通常直接优化高斯的材质属性（如反照率、粗糙度），并依赖近似光照模型或高斯光线追踪计算间接照明。本文的关键差异在于引入中间网格表示：先重建多视角一致的表面网格，在网格上优化材质与环境图，最后将材质属性反推至高斯，利用网格进行硬件加速的光线追踪。

### 多视角一致深度与网格重建

第一阶段解决3DGS缺乏显式表面几何的问题。本文采用平面高斯泼溅（Planar Gaussian Splatting, PGSR）将3D高斯压缩为2D平面，通过Alpha混合渲染平面法线与距离图，进而计算无偏深度图。设计动机在于，直接对高斯深度进行Alpha混合会引入几何冲突，而PGSR确保深度位于高斯平面上，满足多视角一致性。法线一致性损失定义为：

$$ L_{normal} = \sum (1 - \mathbf{n}_{render} \cdot \mathbf{n}_{mono}) $$

其中 $\mathbf{n}_{mono}$ 为StableNormal预测的单目法线先验。该损失抑制镜面反射对法线估计的干扰，为后续网格重建提供稳定几何基础。

### 网格物理渲染与因子化逆路径追踪

第二阶段在重建的网格上执行物理可微渲染，优化材质贴图与环境图。第三阶段核心创新是因子化逆路径追踪（Factorized Inverse Path Tracing, FIPT）应用于高斯G-buffer。FIPT将光传输积分分解为预烘焙的漫反射与高光着色图，将材质参数从积分中分离。高斯材质分解损失为：

$$ L = L_{shade} + \lambda_a L_{s,a} + \lambda_r L_{s,r} $$

其中 $L_{shade}$ 为FIPT渲染图像与目标图像的L1损失，$L_{s,a}$ 和 $L_{s,r}$ 为边缘感知平滑损失。设计动机在于，直接路径追踪训练高斯材质收敛慢且不稳定，FIPT通过预计算着色图加速优化，同时利用网格光线追踪精确计算可见性与间接照明，解决了高斯光线追踪效率低下的问题。

## 实验评估

实验在SYNTHETIC4RELIGHT和TENSOIR SYNTHETIC数据集上进行，对比NeRF-based（TensorIR, NeRFactor）与GS-based（R3DG, IRGS, GI-GS）基线。基线覆盖主流逆渲染路线，但缺失最新的前馈式逆渲染方法。

| 方法 | SYNTHETIC4RELIGHT PSNR | TENSOIR SYNTHETIC PSNR |
| :--- | :--- | :--- |
| R3DG | 36.06 | 33.15 |
| IRGS | 35.66 | 35.58 |
| Ours | 37.11 | 35.57 |

在SYNTHETIC4RELIGHT上，本文PSNR 37.11，显著高于R3DG（36.06）与IRGS（35.66）；在TENSOIR SYNTHETIC上，本文PSNR 35.57，与IRGS（35.58）持平，但SSIM（0.938）低于IRGS（0.954），表明结构保真度存在差距。

| 消融项 | SYNTHETIC4RELIGHT PSNR | TENSOIR SYNTHETIC PSNR |
| :--- | :--- | :--- |
| w/o indirect | 34.68 | 32.28 |
| 16 spp | 34.87 | 31.69 |
| Full | 35.87 | 32.46 |

消融显示，移除间接照明导致PSNR下降约1.2 dB，证实全局光照对重光照质量的关键作用。采样数从256 spp降至16 spp时，PSNR下降约1.0 dB，表明采样数对噪声控制影响显著。

评估边界方面，本文仅在合成数据集上验证，未测试真实场景的重光照鲁棒性。实时渲染依赖RTX 4080的硬件光线追踪单元，无RT硬件时性能退化未评估。代码未开源，超参数（如环境图对比度增强指数1.35）的敏感性未充分讨论。

## 关联研究分析

从问题动机看，本文与R3DG同属GS逆渲染，但R3DG依赖高斯光线追踪计算间接照明，效率受限于高斯分布的复杂几何。本文引入中间网格，将光线追踪对象从高斯切换为三角面，利用BVH加速，这是效率提升的根本原因。然而，网格重建的几何误差可能累积，导致G-buffer与网格表面不一致，论文通过忽略小于0.1的命中距离缓解自相交，但未量化该阈值对重光照质量的影响。

从方法设计看，本文与R3GW等几何/光照解耦方法共享“显式几何辅助优化”思路，但R3GW直接优化网格材质，本文则通过FIPT将材质反推至高斯。FIPT的预烘焙策略加速了训练，但假设环境图在训练过程中不变，这限制了动态光照场景的适用性。此外，本文使用StableNormal作为法线先验，该先验在镜面反射场景下的准确性未深入分析，可能影响几何重建质量。

## 总结

GHPT针对3DGS无法重光照的核心矛盾，通过引入中间网格与混合路径追踪，实现了实时高斯重光照。其切入点在于利用硬件加速光线追踪处理网格可见性，避免了高斯光线追踪的效率瓶颈。实验证明，该方法在SYNTHETIC4RELIGHT上PSNR达37.11，优于R3DG与IRGS。然而，其性能依赖RTX 4080等高端GPU的光线追踪单元，且中间网格的几何误差可能影响重光照精度。当环境图对比度增强指数从1.35调整时，材质分解的稳定性如何变化，论文未给出回答。
