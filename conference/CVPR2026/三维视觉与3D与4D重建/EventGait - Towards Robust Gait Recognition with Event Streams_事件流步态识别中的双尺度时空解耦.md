# CVPR2026最新论文 ｜EventGait: Towards Robust Gait Recognition with Event Streams ｜事件流步态识别中的双尺度时空解耦

研究机构：中国科学技术大学、电子科技大学

作者：Senyan Xu、Shuai Chen、Chuanfu Shen 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.22139)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.22139)

> 步态识别在低光照与运动模糊场景下依赖传统RGB相机，常因视觉线索失效而性能骤降。现有事件相机方法将异步事件流聚合为长窗口体素网格，虽兼容CNN但抹平了微秒级高频动态，且空间稀疏性导致结构特征提取困难。EventGait通过双尺度时间分解，将事件流拆分为短窗口动态切片与长窗口静态切片，分别由脉冲神经网络混合专家与视觉基础模型蒸馏驱动，以保留时间保真度并补全空间结构。该框架在合成与真实基准上显著优于现有事件方法，但其性能高度依赖合成数据管线，真实传感器噪声下的泛化能力存疑。

## 研究背景

步态识别的核心挑战在于从非受控环境中提取鲁棒的人体运动与结构特征。传统RGB相机受限于约30ms的时间分辨率与低于80dB的动态范围，在夜间或高速运动下易产生曝光不足与运动模糊，导致轮廓（Silhouette）特征失真。事件相机（Dynamic Vision Sensor, DVS）通过异步记录像素级对数亮度变化，提供小于3µs的时间分辨率与超过120dB的动态范围，天然抑制静态背景噪声并保留高频运动细节。然而，事件流仅包含相对亮度变化，缺乏绝对光照与颜色信息，且数据呈稀疏异步分布，直接输入标准卷积神经网络（CNN）面临时空不兼容问题。

主流事件视觉方法通常将事件流离散化为体素网格（Voxel Grid）或帧以适配现有架构，这一范式在通用分类任务中降低了开发门槛，但在步态识别中暴露出致命缺陷：长窗口时间分箱破坏了步态特有的高频动态节奏，而空间稀疏性使得网络难以从稀疏激活中重建密集的人体结构先验。早期事件步态工作如EVGait虽验证了可行性，但受限于小规模数据集与单一密集表征，未能充分挖掘事件数据的时空潜力。EventGait的切入点在于拒绝将事件流视为单一密集张量，而是基于步态识别对“动态节奏”与“静态形态”的双重依赖，提出双尺度时间解耦策略，分别针对高频运动与低频结构进行专门建模。

## 核心方法

### 双尺度事件表征

事件步态识别缺乏公认的标准流程，最接近的通用范式是将事件流映射为密集体素网格后输入CNN。本文的关键差异在于引入双尺度时间设计：在长曝光窗口 $T$ 内，将事件流分解为 $K$ 个短窗口切片 $\mathbf{E}_d$ 与一个长窗口聚合切片 $\mathbf{E}_s$。短切片保留微秒级时间精度供动态流使用，长切片提供全局空间统计供静态流使用，从而在单一数据源中同时满足高频动态与低频结构的需求。

### 脉冲混合专家动态建模

动态流需处理空间稀疏且时间高频的短切片 $\mathbf{E}_d$，传统CNN难以有效捕获此类异步信号。本文采用脉冲神经网络（Spiking Neural Network, SNN）作为骨干，其膜电位 $U(t)$ 遵循泄漏积分-发放（Leaky Integrate-and-Fire, LIF）动力学：

$$ U(t) = U(t-\Delta t) \cdot e^{-\Delta t/\tau} + R \cdot I(t) $$

其中 $\tau$ 为膜时间常数，控制电位衰减速率。单一 $\tau$ 的神经元无法同时适应明亮场景下的高频爆发与昏暗场景下的稀疏脉冲。为此，本文提出脉冲混合专家（Mixture of Spiking Experts, MoSE），包含 $N$ 个具有不同 $\tau_i$ 的并行专家，通过门控网络 $\mathcal{G}$ 计算自适应权重 $\alpha_i$，输出动态特征 $\mathbf{F}_d = \sum_{i=1}^N \alpha_i \mathcal{E}_i(\mathbf{E}_t)$。该设计使小 $\tau$ 专家专注高频运动，大 $\tau$ 专家整合稀疏信号，解决了单一SNN单元在复杂光照与运动耦合下的适应性不足问题。

### 跨模态结构对齐静态建模

静态流处理长窗口切片 $\mathbf{E}_s$，虽具备全局空间信息，但稀疏性导致CNN难以学习密集人体结构。本文引入跨模态结构对齐（Cross-modal Structure Alignment, CroSA），利用冻结的DINOv2作为教师模型，将同步RGB帧转为灰度图 $\mathbf{I}_g$ 提取结构特征 $\mathbf{z}_{img}$。学生编码器从 $\mathbf{E}_s$ 提取特征 $\mathbf{z}_{evs}$，通过L2损失最小化两者距离：

$$ \mathcal{L}_{align} = \|\mathbf{z}_{img} - \mathcal{A}(\mathbf{z}_{evs})\|_2^2 $$

其中 $\mathcal{A}(\cdot)$ 为对齐卷积层。该机制强制事件静态编码器从稀疏输入中恢复密集结构先验，弥补了事件数据缺乏绝对光照与纹理信息的缺陷，使静态流能够捕获稳定的形态特征。

## 实验评估

实验在合成数据集SUSTech1K-E、CCGR-Mini-E及真实数据集DVS128-Gait上进行，对比基线涵盖RGB轮廓方法（GaitSet, GaitBase）、LiDAR点云方法（LidarGait++）及现有事件方法（EVGait, GaitBase_e）。基线覆盖较全面，但缺失其他SNN步态专用方法。

| 数据集 | 方法 | 输入 | Overall Rank-1 |
| :--- | :--- | :--- | :--- |
| SUSTech1K-E | EVGait | Event | 65.4 |
| SUSTech1K-E | GaitBase_e | Event | 59.2 |
| SUSTech1K-E | EventGait | Event | 92.8 |
| DVS128 | EV-Gait | Event | 81.8 |
| DVS128 | EventGait | Event | 87.4 |

EventGait在SUSTech1K-E上Overall Rank-1达92.8%，较最强事件基线EVGait提升27.4%，甚至超过LiDAR方法LidarGait++的92.2%。在真实DVS128数据集上，EventGait以87.4%超越EV-Gait的81.8%，验证了跨域泛化能力。

消融实验显示，移除动态流或静态流均导致性能显著下降，其中仅保留动态流的Overall Rank-1为72.4%，仅保留静态流为82.0%，证明双流互补性。MoSE专家数量从1增至3时，低光场景Overall Rank-1从74.5%提升至83.2%，增至4时仅微升至83.4%，表明3个专家在效率与精度间取得平衡。CroSA对齐权重 $\lambda_d=0.2$ 时效果最佳，权重过大引入无关纹理干扰，过小则结构引导不足。

评估边界方面，主要依赖合成数据，真实数据仅DVS128-Gait（20人）规模较小，缺乏大规模真实事件步态基准。指标仅报告Rank-1，未提供mAP或计算效率指标。代码已开源，训练使用8块RTX 3090 GPU，SGD优化器，初始学习率0.1，具备可复现性。

## 关联研究分析

从问题动机看，EventGait与Spiking Patches均致力于保留事件异步性，但Spiking Patches通过稀疏Token化适配Transformer，侧重通用视觉任务的时间保真度；EventGait则针对步态识别的特定需求，将异步性解耦为高频动态与低频结构，利用SNN的物理特性而非Transformer的注意力机制。差异根源在于任务特性：步态识别对时间节奏的敏感度高于通用分类，SNN的膜电位动力学天然匹配脉冲式运动信号，而Transformer的Token化可能引入不必要的计算冗余。

从方法设计看，EventGait的CroSA与REALM均利用视觉基础模型（VFM）弥合模态鸿沟，但REALM通过潜空间对齐解决事件到RGB的深度估计，侧重几何一致性；EventGait通过L2损失对齐结构特征，侧重形态先验迁移。EventGait未探索VFM在动态流中的应用，仅用于静态流，这是否限制了其在复杂运动场景下的结构稳定性，论文未给出回答。此外，EventGait依赖合成数据管线，而FracEvent等仿真器强调物理一致性，EventGait的合成方法基于帧插值与阈值触发，可能掩盖真实传感器噪声对SNN膜电位累积的影响。

## 总结

EventGait旨在解决事件步态识别中时间保真度与空间结构密度的矛盾，通过双尺度时间分解与MoSE/CroSA双流架构，在保留微秒级动态的同时补全结构先验。实验证明其在合成与真实基准上显著优于现有事件方法，SUSTech1K-E上Overall Rank-1达92.8%，DVS128上达87.4%。然而，其性能高度依赖合成数据管线，真实数据规模有限，且未评估SNN在真实传感器噪声下的鲁棒性。当真实事件步态数据集规模扩大至千人级别时，合成数据训练的模型是否仍能保持对传感器噪声的适应性，论文未给出回答。
