# CVPR2026最新论文 ｜ExMesh: EXplicit Mesh Reconstruction with Topology Adaptation ｜显式网格拓扑自适应重建

研究机构：中国科学技术大学

作者：Chuanjin Fan、Lifan Wu、Wenjie Chang 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.07288)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.07288)

> 从多视图图像重建高保真且紧凑的显式三角网格，长期受困于隐式场离散化带来的细节丢失与高斯原语后处理导致的碎片化。现有方法要么依赖中间表示牺牲可编辑性，要么固定拓扑无法自适应细节，本文切入点在于将离散拓扑更新直接嵌入连续可微优化管道。通过自适应顶点分裂/合并与实时UV维护，ExMesh实现了精度、效率与面数控制的三角平衡。该方法在显式重建任务中达到了SOTA水平，但其对复杂非流形拓扑的鲁棒性及与解析提取方法的精度上限对比仍存疑。

## 研究背景

可微渲染器（Differentiable Renderer）允许图像损失梯度直接回传至几何与纹理参数，这是显式网格重建的技术基石。然而，传统网格优化面临两个核心困境：一是拓扑固定导致无法在几何复杂区域增加面数以恢复细节，二是纹理与几何耦合使得高频纹理必须依赖高密度面片，导致面数冗余。这两个问题共同限制了显式方法在精度与简洁性上的表现。

隐式神经表面重建（如NeuS、VolSDF）通过SDF建模几何，但提取网格必须依赖Marching Cubes（MC），其离散采样误差导致锐利边缘模糊与薄结构丢失，且训练时间超过12小时。高斯泼溅（Gaussian Splatting）类方法提升了训练效率，但需TSDF融合等后处理生成网格，产生大量离散碎片。混合表示方法（如Flexicubes、Nvdiffrec）虽引入可微渲染，但优化目标仍是SDF或点云等中间载体，且Nvdiffrec需冻结拓扑以维持UV映射连续性，无法实现自适应细化。ExMesh的切入点在于摒弃所有中间表示，直接优化顶点位置与UV纹理，并通过离散拓扑算子解决自适应细化与纹理解耦的矛盾。

## 核心方法

### 可微渲染驱动的显式优化参照系

ExMesh基于nvdiffrast构建可微渲染管道，输入初始粗网格，通过光度损失驱动顶点位置$\mathbf{V}$与UV贴图$\mathbf{T}$的联合优化。与Flexicubes等混合方法不同，ExMesh不优化SDF场，而是直接以三角网格为唯一几何载体，其关键差异在于引入了离散拓扑更新机制，打破了固定拓扑模板的限制。

### 自适应顶点分裂与合并

针对固定拓扑无法自适应细节的问题，ExMesh设计了基于梯度与曲率的分裂准则。分裂评分函数为：

$$ S_f = \alpha G_f + \beta K_f $$

其中$G_f$为面片顶点梯度幅值的指数移动平均（EMA），$K_f$为面片法线与相邻面法线夹角的平均值。该公式将优化动态（梯度大表示需调整）与几何复杂度（曲率大表示需细化）结合，仅对面积前50%且评分高的面片执行分裂。合并操作则通过边坍缩（Edge Collapse）移除冗余面，判据包括渲染贡献计数$C_{render}(F)=0$或退化度$D_f < \tau_{degen}$。这一设计解决了全局均匀细分在平坦区域造成面数冗余、在复杂区域细节不足的问题，同时通过退化面清理维持流形结构完整性。

### 实时UV坐标维护

纹理与几何耦合导致面数膨胀是显式重建的另一瓶颈。ExMesh将纹理存储于独立UV贴图，并在拓扑更新时实时重映射UV坐标。当顶点$v_s$分裂时，其UV坐标$u_s$通过相邻顶点UV的线性插值初始化：

$$ u_s = (1-\mu) u_a + \mu u_b $$

其中$\mu$为$v_s$在边$(v_a, v_b)$上的相对位置。若分裂边为非边界边且两侧面片位于不同UV岛，则$v_s$关联两个独立UV坐标以维持纹理接缝。该机制打破了纹理分辨率对面数的依赖，使得低面数网格也能承载高频纹理细节，避免了Nvdiffrec中需冻结拓扑或后训练烘焙的局限。

## 实验评估

| 方法 | DTU Avg. CD | NeRF-synthetic Avg. CD | 面数 (DTU) | 训练时间 (DTU) |
| :--- | :--- | :--- | :--- | :--- |
| NeuS | 0.77 | 0.69 | 798K | >12h |
| Flexicubes | 1.26 | 1.17 | 168K | >1h |
| PGSR | 0.52 | - | 1.05M | 30m |
| ExMesh | 0.58 | 0.64 | 196K | 13m |

ExMesh在DTU数据集上取得0.58的Chamfer Distance（CD），优于NeuS（0.77）和Flexicubes（1.26），接近高斯方法PGSR（0.52），但面数仅为196K，远低于PGSR的1.05M。在NeRF-synthetic数据集上，ExMesh CD为0.64，优于NeuS（0.69）和Flexicubes（1.17）。基线覆盖了隐式（NeuS）、高斯（2DGS、PGSR）及混合（Flexicubes、Nvdiffrec）路线，但缺乏与TetraSDF等解析提取方法的直接对比，且未在高亏格拓扑数据集（如Thingi10K）上验证。

| 消融设置 | CD | PSNR | 面数 |
| :--- | :--- | :--- | :--- |
| Only Split | 0.74 | 28.77 | 239K |
| Only Merge | 1.81 | 23.51 | 12K |
| Random Split | 0.77 | 28.30 | 184K |
| ExMesh (Full) | 0.64 | 29.32 | 196K |

消融实验显示，仅分裂导致面数增至239K且CD为0.74，仅合并则CD高达1.81，证明分裂与合并的协同必要性。随机分裂（CD 0.77）劣于自适应分裂（CD 0.64），验证了基于梯度与曲率准则的有效性。UV贴图策略（CD 0.64, 196K）优于逐顶点颜色（CD 0.76, 356K）和MLP纹理（CD 0.64, 198K），证实了解耦纹理在面数控制上的优势。

实验在单张NVIDIA RTX 3090上完成，训练时间13分钟，显著快于隐式方法。但论文未报告置信区间，且DTU数据集仅含15个物体，样本量有限。代码未公开，超参数敏感性分析显示在默认值0.5x-2.0x范围内CD波动小于0.02，表明方法对超参数鲁棒。

## 关联研究分析

从方法设计看，ExMesh与Flexicubes均使用可微渲染，但Flexicubes优化SDF场并依赖固定拓扑模板，而ExMesh直接优化网格顶点并引入离散拓扑更新。这一差异源于任务目标：Flexicubes侧重几何平滑性，ExMesh侧重细节恢复与面数控制。ExMesh的拓扑更新机制借鉴了3DGS的密度控制思想，但将其应用于网格拓扑而非高斯原语，解决了显式网格中“细节-面数”的权衡问题。

从问题动机看，ExMesh与TetraSDF都追求高精度重建，但TetraSDF依赖隐式SDF与解析提取，而ExMesh采用显式优化。TetraSDF在Thingi10K上CD为0.21，显著优于ExMesh在DTU上的0.58，但两者数据集不同，无法直接比较。ExMesh的优势在于可编辑性与实时性，而TetraSDF的优势在于解析精度。ExMesh未验证其在复杂拓扑（如高亏格）上的鲁棒性，而TetraSDF已证明其在Thingi10K上的有效性，这暗示显式方法在极端拓扑下可能面临挑战。

## 总结

ExMesh解决了显式网格重建中精度、效率与面数控制的三角矛盾，通过自适应顶点分裂/合并与实时UV维护，实现了无中间表示的直接优化。在DTU数据集上，ExMesh以196K面数取得0.58 CD，优于NeuS（0.77）和Flexicubes（1.26），训练时间仅13分钟。其边界在于缺乏与解析提取方法的精度对比，且未在高亏格拓扑上验证鲁棒性。当输入包含复杂内部结构或非流形几何时，显式拓扑更新是否仍能维持流形性，论文未给出回答。
