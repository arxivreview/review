# CVPR2026最新论文 ｜Modeling the Brain's Grammar: ROI-Guided fMRI Pretraining for Transferable and Interpretable Vision Decoding ｜基于感兴趣区（ROI）的 fMRI 预训练框架：ROITok

研究机构：香港科技大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_0ce51560fbb7)

> 导读 fMRI 视觉解码旨在从大脑活动信号中逆向工程人类感知，其核心价值在于验证视觉编码机制并构建“大脑相机”。现有跨被试方法多采用全脑体素扁平化或任意空间切分，忽略了大脑皮层的功能拓扑结构，导致少样本场景下泛化能力受限。ROITok 将感兴趣区（ROI）作为计算单元进行 Token 化，结合稀疏上下文融合与 Matryoshka 表示学习策略，构建具备神经科学可解释性的共享表征空间。该方法在 NSD 数据集的少样本迁移任务中取得了领先的低层重建保真度，但其高层语义对齐性能与部分基于 Transformer 的基线相比存在细微差距，且对噪声鲁棒性的评估仅基于合成高斯噪声，生理噪声下的表现尚待验证。

## 研究背景

fMRI 信号具有低时间分辨率、高噪声及强烈的个体差异性，这使得跨被试解码比传统少样本学习更为复杂。理解本文需把握两个核心概念：一是感兴趣区（ROI），即大脑中功能特化的皮层区域，如 V1 编码边缘，FFA 编码人脸；二是表征对齐，即如何将不同被试的神经响应映射到共享语义空间。早期方法将 fMRI 视为扁平向量，忽略了 ROI 内部的空间冗余与 ROI 间的功能协同，导致模型难以捕捉大脑的层级处理机制。

跨被试泛化是当前领域面临的最大挑战，单被试模型难以直接迁移，需要专门的适应策略。主流路线分为两类：一类将 fMRI 体素视为 1D 或 2D 图像，应用 ViT 风格的空间切分，但这忽略了 BOLD 信号的非均匀分辨率与功能拓扑；另一类使用被试特定适配器将被试响应投影至共享潜空间，如 MindEye2 和 MindTuner，但这些方法缺乏显式结构约束，在少样本场景下易过拟合。ROITok 的切入点在于利用神经影像学证据：尽管体素级响应存在个体差异，但 ROI 级表征在解剖和功能上具有强跨被试对齐性。因此，本文提出以 ROI 为计算单元，构建符合大脑模块化组织的“表征语法”。

## 核心方法

### 方法参照系

本文问题属于跨被试 fMRI 预训练与微调范式。标准流程通常包括：将被试特定 fMRI 信号通过适配器映射至共享潜空间，再利用共享解码器进行图像重建或检索。本文的关键差异在于摒弃了全脑体素或任意空间网格作为输入单元，转而采用解剖学定义的 ROI 作为 Token，并在编码阶段引入结构化的嵌入压缩机制。

### 稀疏 ROI 上下文融合

传统适配器方法将被试全脑活动视为整体，忽略了 ROI 间的功能依赖与冗余。ROITok 在预训练阶段引入稀疏 ROI 上下文融合策略，通过掩码重建学习跨被试的鲁棒表征。具体而言，随机掩码 50% 的 ROI Token 并替换为可学习的 [MASK] Token，随后输入由八个残差 MLP 块组成的编码器 $\mathcal{E}$。该设计动机在于利用大脑固有的冗余性，迫使模型从剩余 ROI 中推断被掩码区域的信息，从而捕捉区域间的功能协同。

$$
\mathbf{Z} = \mathcal{E}(\mathbf{R}_1, \dots, \mathbf{R}_M)
$$

其中 $\mathbf{R}_j$ 为第 $j$ 个 ROI 的嵌入，$\mathbf{Z} \in \mathbb{R}^{M' \times D'}$ 为上下文感知的嵌入序列。这一过程不仅增强了鲁棒性，还保留了 ROI 的功能特异性，使得模型能够区分不同皮层层级编码的信息类型。

### MRL 启发的嵌入压缩

MindEye2 等前作对编码器输出空间未施加显式结构约束，导致嵌入空间缺乏层级结构且易过拟合。ROITok 借鉴 Matryoshka 表示学习（MRL）思想，设计了一种嵌入压缩策略，确保 Token 序列按信息显著性排序。在训练过程中，对嵌入序列 $\mathbf{Z} = (\mathbf{Z}_1, \dots, \mathbf{Z}_{M'})$ 应用截断函数：

$$
F(\mathbf{Z}, m) = (\mathbf{Z}_1, \dots, \mathbf{Z}_m, \mathbf{Z}_{\emptyset}, \dots, \mathbf{Z}_{\emptyset})
$$

其中 $m$ 是从 $U\{1, \dots, M'\}$ 中均匀采样的随机整数，$\mathbf{Z}_{\emptyset}$ 为可学习的空 Token。该公式的物理含义是：强制模型在前 $m$ 个 Token 中捕获最具信息量的视觉特征，后续 Token 仅补充细节。这种层级化结构使得模型在少样本场景下能更稳定地迁移，因为早期 Token 承载了跨被试共享的通用视觉语法，而后期 Token 容纳个体特异性细节。

## 实验评估

| 方法 | PixCorr↑ | CLIP↑ | Image Retrieval↑ |
| :--- | :--- | :--- | :--- |
| MindTuner (1h) | 0.224 | 83.5% | 76.0% |
| ROITok (1h, IP-Adapter) | 0.341 | 84.0% | 85.5% |
| ROITok (40h, IP-Adapter) | 0.475 | 92.9% | 98.7% |
| MindEye2 (40h) | 0.285 | 93.0% | 97.4% |

实验在 NSD 和 GOD 数据集上进行，对比了 MindEye2、MindTuner、STTM 等主流基线。在 1 小时少样本设置下，ROITok 的 PixCorr 达到 0.341，显著高于 MindTuner 的 0.224，且 Image Retrieval 准确率为 85.5%，优于 MindTuner 的 76.0%。在 40 小时全数据设置下，ROITok 的 PixCorr 为 0.475，远超 MindEye2 的 0.285，但 CLIP 相似度 92.9% 略低于 MindEye2 的 93.0%。这表明 ROI 引导的低层重建优势明显，但高层语义对齐并未显著超越基于 Transformer 的适配器方法。

消融实验显示，MRL 策略对低层重建有显著提升：40 小时数据下，移除 MRL 后 PixCorr 从 0.549 降至 0.426。两阶段微调策略（先训练 ROI 嵌入器，再全量微调）优于单阶段微调，1 小时数据下 Image Retrieval 从 66.1% 提升至 85.5%。噪声鲁棒性测试表明，在 SNR 降至 0.182 时，ROITok 仍能保持有意义的检索准确率，但论文未评估生理噪声（如心脏或运动伪影）的影响。

评估协议存在局限：未报告置信区间，且噪声测试仅使用合成高斯噪声。代码未公开，超参数细节（如 D' 的具体取值）仅在附录中提及。与 PRISM 等最新 SOTA 方法相比，ROITok 未进行直接对比，可能因 PRISM 依赖文本空间对齐，而 ROITok 聚焦于视觉皮层层级结构。

## 关联研究分析

从方法设计看，ROITok 与 MindEye2 的核心差异在于输入单元的选择。MindEye2 使用被试特定适配器处理全脑体素，而 ROITok 将 ROI 作为 Token，利用残差 MLP 替代 Transformer 作为骨干。这一选择降低了 GPU 内存消耗，但可能牺牲了长程依赖建模能力。论文未探讨 MLP 骨干在复杂语义场景下的局限性，仅强调其训练稳定性。相比之下，VoxelFormer 使用 ToMer 编码器压缩体素，虽也追求参数效率，但未引入神经解剖先验，导致其可解释性较弱。

从问题动机看，ROITok 与 ZEBRA 均关注跨被试泛化，但路径不同。ZEBRA 通过对抗学习解耦主体不变特征，实现零样本泛化；ROITok 则依赖 ROI 的功能特异性，通过少样本微调实现迁移。ZEBRA 在零样本解码性能上表现优异（73.4%），但可能损失主体特定细微特征；ROITok 在少样本场景下更精准，但依赖预训练模型的泛化基础。两者反映了“零样本解耦”与“少样本适配”之间的取舍，缺乏在相同数据量和计算预算下的公平对比。

## 总结

ROITok 旨在解决跨被试 fMRI 解码中个体差异导致的泛化难题，其切入点在于利用 ROI 的跨被试对齐性，将神经解剖先验注入预训练过程。通过稀疏 ROI 上下文融合与 MRL 嵌入压缩，该方法在 NSD 1 小时少样本设置下实现了 0.341 的 PixCorr 和 85.5% 的检索准确率，显著优于 MindTuner。然而，其高层语义对齐性能（92.9% CLIP）未超越 MindEye2（93.0%），且噪声鲁棒性评估仅基于合成噪声，未涵盖生理伪影。当支持集增大到 5-shot 时，ROI 引导的边际收益是否递减，论文未给出回答。
