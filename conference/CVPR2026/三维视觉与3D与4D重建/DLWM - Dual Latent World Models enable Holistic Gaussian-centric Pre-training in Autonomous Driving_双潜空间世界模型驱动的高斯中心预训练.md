# CVPR2026最新论文 ｜DLWM: Dual Latent World Models enable Holistic Gaussian-centric Pre-training in Autonomous Driving ｜双潜空间世界模型驱动的高斯中心预训练

研究机构：香港中文大学

作者：Yiyao Zhu、Ying Xue、Haiming Zhang 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.00969)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.00969)

> 视觉自动驾驶系统面临场景表示在表达力、计算效率与时序连贯性上的三角矛盾，密集体素网格开销过大，稀疏查询缺乏几何细节，而现有高斯中心方法依赖昂贵的人工标注且缺乏统一的时空预训练范式。DLWM 通过两阶段自监督策略，先利用多视角深度与语义重建学习高斯几何语义，再引入双潜空间世界模型分别针对感知预测与运动规划进行时空特征增强。该范式在占据感知、4D预测与规划任务上均取得SOTA，但其自回归预测机制在长时序下的误差累积风险尚未被充分验证。

## 研究背景

当自动驾驶系统试图从2D图像推断3D场景时，深度歧义导致几何重建在远距离与遮挡区域失效。为突破此局限，3D高斯泼溅（3D Gaussian Splatting, 3DGS）被引入作为稀疏显式表示，每个高斯原语由中心、协方差、不透明度及球谐系数定义，通过可微分体积渲染实现几何与语义的联合表达。然而，3DGS的查询向量在帧间缺乏一一对应关系，这种置换等价性使得直接监督帧间高斯特征变得不可能，导致静态高斯表示在动态场景中缺乏时序一致性，无法支撑4D占据预测与运动规划。

3D语义占据预测的主流路线正从密集体素向稀疏高斯演化，以解决计算冗余问题。GaussianFormer等基线方法虽实现了高效推理，但依赖密集3D标注，限制了可扩展性。现有预训练策略如Masked Autoencoders（MAE）仅通过对比学习获取粗粒度特征，无法显式学习3D几何结构；而UniPAD等渲染方法虽利用LiDAR深度监督，但未形成覆盖感知、预测与规划全生命周期的统一范式。DLWM的切入点在于利用自监督重建与潜空间预测，在不依赖人工3D标注的前提下，建立高斯中心的时空连贯表示，从而同时提升下游感知、预测与规划性能。

## 核心方法

### 高斯感知模块与自监督重建

本文基于GaussianFormer的高斯感知模块，通过图像编码器提取多视角特征，利用4D稀疏卷积与交叉注意力聚合视觉信息，回归高斯参数。设计动机在于解决传统体素表示在高分辨率下的内存爆炸问题，同时通过自监督重建弥补3D标注缺失。第一阶段训练通过渲染深度与语义图像进行监督，损失函数为：

$$ L_{total} = \omega_1 L_d + \omega_2 L_{pd} + \omega_3 L_s $$

其中 $L_d$ 为LiDAR稀疏深度L1损失，$L_{pd}$ 为Metric3D生成的伪深度损失，$L_s$ 为Grounded SAM生成的语义交叉熵损失。该公式强制高斯原语在几何与语义上同时收敛，为后续时空预测提供鲁棒初始化。

### 高斯流引导的潜空间预测

针对高斯查询帧间置换等价性导致的监督失效，本文引入高斯流（Gaussian Flow）预测头，估计每个高斯的局部动态位移向量 $\Delta \mu_k^t$。通过自车运动对齐，将当前帧高斯传播至下一帧：

$$ \mu_k^{t+1} = \mu_k^t + \Delta \mu_k^t + T_{ego}^{t \to t+1} $$

随后，将传播后的高斯集合通过BEV光栅化投影为2D潜特征 $B_{t+1}$，利用冻结的高斯感知模块生成真值潜特征，以L2损失 $L_{bev}$ 进行监督。这一设计将稀疏高斯的时序演化转化为稠密BEV网格的回归问题，规避了置换等价性约束，使模型能够学习场景的动态演化规律，显著提升4D占据预测的时序一致性。

### 自车轨迹引导的规划潜空间

为增强运动规划能力，本文设计第二个潜空间世界模型，以预测轨迹 $\hat{T}$ 为条件调制当前场景查询 $Q_{scene}^t$。通过运动感知层归一化（MLN）将轨迹信息注入场景特征，经多层自注意力生成下一帧场景查询 $Q_{scene}^{t+1}$，并与当前BEV特征融合预测未来潜特征。该模块独立于感知预测模块训练，旨在解耦感知几何与规划决策，使规划头能够获取运动感知的时空上下文，从而在轨迹预测中实现更优的L2误差与碰撞率。

## 实验评估

| 任务 | 方法 | mIoU (%) | IoU (%) | L2 (m) | Col. (%) |

| 3D占据感知 | Baseline | 20.83 | 31.77 | - | - |
| 3D占据感知 | DLWM | 21.85 | 34.61 | - | - |
| 4D占据预测 | Baseline | 15.09 | 25.65 | - | - |
| 4D占据预测 | DLWM | 17.77 | 30.60 | - | - |
| 运动规划 | Baseline | - | - | 0.55 | 0.24 |
| 运动规划 | DLWM | - | - | 0.46 | 0.19 |

实验在nuScenes验证集上进行，对比基线包括GaussianFormer、OccWorld及LAW等。DLWM在3D占据感知上较基线提升1.02 mIoU，在4D预测上提升2.68 mIoU，在规划上L2误差降低16%。消融实验显示，引入高斯流模块使mIoU从18.99提升至19.30，验证了时空特征学习的有效性；数据规模从10%增至100%时，mIoU从18.24升至19.98，表明预训练对数据量的正相关依赖。

评估边界方面，论文未报告FPS等实时性指标，且4D预测仅评估1-3秒短时序，长时序误差累积风险未验证。代码未开源，超参数如高斯数量25,600及Transformer层数4固定，缺乏不同硬件配置下的可复现性讨论。

## 关联研究分析

从方法设计看，DLWM与GaussianWorld均利用高斯流预测场景演化，但GaussianWorld直接预测4D高斯参数，而DLWM将高斯流映射至BEV潜空间进行监督。这一差异源于高斯查询的置换等价性：直接监督帧间高斯特征在数学上不可行，而BEV光栅化提供了稠密网格的帧间对应性。DLWM的选择牺牲了高斯原语的显式几何细节，换取了潜空间监督的可行性，这暗示在极端复杂几何场景下，潜空间表示可能丢失细粒度结构信息。

从问题动机看，DLWM与OccWorld同属4D占据预测路线，但OccWorld采用离散Token自回归生成，而DLWM采用连续高斯非自回归预测。OccWorld的离散化便于与语言模型兼容，但引入量化误差；DLWM的连续表示更符合物理连续性，但自回归流预测在长时序下可能累积误差。论文未对比两者在>10秒长时序预测下的稳定性，这一盲区限制了DLWM在长时程规划任务中的适用性判断。

## 总结

DLWM旨在解决高斯中心表示在动态场景中缺乏时序一致性与自监督预训练范式缺失的矛盾。其切入点在于利用BEV光栅化规避高斯查询的置换等价性约束，通过双潜空间世界模型分别优化感知预测与运动规划。实验证明该范式在3D占据感知上达到21.85 mIoU，在4D预测上达到17.77 mIoU，显著优于基线。然而，论文仅评估1-3秒短时序预测，且未报告实时性指标，自回归流预测在长时序下的误差累积风险未被验证。当预测时序延长至10秒以上时，高斯流预测的累积误差是否会导致场景表示漂移，论文未给出回答。
