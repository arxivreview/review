# CVPR2026最新论文 ｜PQDT: Pseudo-Query Dual Transformer for Robust Point Cloud Restoration ｜伪查询双 Transformer 点云修复

研究机构：德国波恩大学

作者：Haoqing Wu、Alexa Nawotki、Jochen Garcke

论文原文见 [arXiv](https://arxiv.org/abs/2605.25127)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.25127)

> 点云修复旨在从含缺失、噪声及变形的退化数据中恢复完整几何结构，是自动驾驶与机器人感知的前置环节。现有方法依赖全局瓶颈特征或单一阶段解码，在复合畸变下易丢失局部细节且对输入质量敏感。本文提出 PQDT，通过引入伪查询机制与双阶段 Transformer 解码，自适应平衡输入观测与学习先验，实现统一修复。该方法在多个基准上刷新了 SOTA，但其纯 3D 输入策略在纹理丰富场景下的表现及实时推理成本仍存疑。

## 研究背景

当传感器采集的点云同时存在缺失、高斯噪声及几何变形时，传统基于全局特征池化的编码器-解码器架构（如 PCN）会将细粒度几何信息压缩至单一向量，导致重建表面模糊。为保留局部细节，后续工作（如 PoinTr, AnchorFormer）引入锚点或查询机制，通过序列到序列翻译生成中间代理点。然而，这些方法直接依赖输入点云生成查询，当输入包含大量离群点或严重畸变时，查询初始化被污染，导致解码过程不稳定，无法有效区分“真实几何”与“噪声干扰”。

点云修复领域长期面临单一任务模型难以应对复合畸变的困境。主流路线分为两类：一是基于全局特征的端到端补全，二是基于锚点/查询的细化生成。前者牺牲细节，后者对输入质量敏感。现有研究多针对单一畸变类型（如仅缺失或仅噪声）优化，缺乏在单一模型中统一处理缺失、变形与去噪的鲁棒框架。PQDT 的切入点在于将查询生成过程解耦为“观测引导”与“先验引导”两个阶段，通过引入不直接参与最终解码的“伪查询”作为中间锚点，隔离输入噪声对最终重建的影响，从而在保持几何保真度的同时提升对复杂退化场景的鲁棒性。

## 核心方法

### 方法参照系

PQDT 属于基于 Transformer 的点云补全与修复框架，其标准流程为：特征提取 → 全局/局部特征编码 → 查询生成 → 解码细化。与 PoinTr 或 AnchorFormer 等单阶段解码方法不同，PQDT 的核心差异在于引入了双阶段查询细化机制，将查询生成过程显式拆分为观测引导与先验引导两个互补阶段，并在两阶段间插入动态查询选择（DQS）模块以过滤噪声敏感特征。

### 伪查询双阶段解码

在标准 Transformer 解码器中，查询通常直接由输入特征投影或固定位置初始化生成，随后一次性解码为最终点云。PQDT 在此环节引入“伪查询”（Pseudo-Queries）作为中间实体。第一阶段（观测引导）利用球面初始化查询与编码后的输入特征进行交叉注意力，生成初步的伪查询 $P_{pq}$ 和特征 $F_{pq}$。这一阶段旨在从畸变观测中稳定粗粒度几何结构，但此时伪查询仍可能受噪声影响。第二阶段（先验引导）将伪查询作为新的输入，经过第二次编码与解码，在更强的学习形状先验影响下细化查询。这一设计解决了单阶段解码中噪声直接污染最终重建的问题，通过两次注意力交互逐步剥离输入中的非几何信息，使最终查询更贴近真实表面。

$$
\mathcal{L}_{total} = \mathcal{L}_{CD} + \lambda \mathcal{L}_{F1}
$$

该损失函数结合倒角距离（CD）与 F1 分数，确保重建点云在几何分布与表面一致性上同时优化，其中 CD 衡量点集间的最近邻距离，F1 衡量预测点与真实点的重合度。

### 几何嵌入与动态查询选择

标准 Transformer 使用坐标位置编码，难以捕捉点云的非欧几里得几何关系。PQDT 引入几何嵌入（GE），通过正弦编码点间欧氏距离 $\rho_{i,j}$ 和局部角度 $\alpha_{i,j}$ 构建稀疏几何嵌入，替代原始坐标编码。这解决了坐标编码在稀疏点云上对局部结构不敏感的问题。此外，PQDT 在查询生成后引入动态查询选择（DQS）模块，采用 Gumbel-Top-k 采样从候选查询中选取最具代表性的子集。DQS 通过梯度直通估计器（Straight-Through Estimator）实现可微分选择，在训练早期通过 Gumbel 噪声促进探索，后期逐渐确定性化。这一机制解决了固定数量查询在复杂几何下冗余或不足的问题，确保仅保留对重建贡献最大的特征，提升了模型对局部细节的捕捉能力。

$$
\text{SGE}_{i,j} = \text{Sinusoidal}(\rho_{i,j}) \oplus \text{Sinusoidal}(\alpha_{i,j})
$$

该公式定义了稀疏几何嵌入，将点间距离与局部角度信息编码为向量，作为 Transformer 自注意力中的键值信息，使模型能显式感知局部几何结构。

## 实验评估

实验在 ShapeNet-55/34、ShapeNet-Deform、ShapeNetCar-Occ 及 PFS 数据集上进行，基线涵盖 PCN、PoinTr、SeedFormer、AnchorFormer 等主流 Transformer 方法，但缺失 SuperPC 等需 2D 输入的扩散模型。PQDT 在 ShapeNet-55 上取得平均 CD 0.68 和 F1 0.570，显著优于 AnchorFormer 的 0.76 和 0.558，尤其在困难案例（CD-H）上提升 0.13。在 ShapeNet-Deform 上，PQDT 的 CD 为 1.01，F1 为 0.290，优于 AnchorFormer 的 1.03 和 0.288，验证了其在变形场景下的鲁棒性。

| 数据集 | 方法 | CD-S | CD-M | CD-H | CD_ℓ2 | F1 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| ShapeNet-55 | AnchorFormer | 0.41 | 0.61 | 1.26 | 0.76 | 0.558 |
| ShapeNet-55 | PQDT | 0.34 | 0.55 | 1.13 | 0.68 | 0.570 |
| ShapeNet-Deform | AnchorFormer | 0.75 | 0.98 | 1.68 | 1.03 | 0.288 |
| ShapeNet-Deform | PQDT | 0.63 | 0.85 | 1.54 | 1.01 | 0.290 |

消融实验显示，引入伪查询机制（Model C）相比单阶段基线（Model B）在 CD 上降低 0.011，F1 提升 0.004，参数量仅增加 2.8M，表明性能提升源于特征细化而非模型容量。几何嵌入（GE）相比坐标编码（CE）在 CD 上降低 0.032，F1 提升 0.013，验证了局部几何感知的有效性。Gumbel 噪声尺度为 1.0 时性能最佳，无噪声或噪声过大均导致性能下降，表明随机探索对查询选择至关重要。

评估指标主要依赖 CD 和 F1，缺乏对实时推理延迟的计算效率分析。代码与数据已开源，训练使用单张 A100 GPU，超参数设置详细，可复现性良好。然而，实验未涵盖真实世界 LiDAR 数据，仅在合成数据集上验证，且未报告不同噪声水平下的去噪性能对比，限制了其在实际部署中的泛化性评估。

## 关联研究分析

从问题动机看，PQDT 与 AnchorFormer 同属基于查询的点云补全，但 AnchorFormer 依赖模式感知的判别锚点，直接由全局特征投影生成，对输入噪声敏感。PQDT 通过伪查询机制将查询生成解耦，第一阶段从观测中提取粗几何，第二阶段利用先验细化，这种两阶段设计在复合畸变场景下更具鲁棒性。差异根源在于任务特性：AnchorFormer 假设输入相对干净，而 PQDT 针对真实场景中常见的噪声与缺失共存问题，通过中间伪查询隔离噪声影响。

从方法设计看，PQDT 与 SeedFormer 均使用向量自注意力进行上采样，但 SeedFormer 采用单阶段解码，查询直接由输入特征生成。PQDT 引入动态查询选择（DQS）和几何嵌入（GE），在查询生成过程中引入可微分选择机制和局部几何感知。DQS 的 Gumbel-Top-k 采样解决了固定查询数量在复杂几何下的冗余问题，GE 则弥补了坐标编码对局部结构不敏感的缺陷。与 SuperPC 等扩散模型相比，PQDT 采用纯 3D 输入，避免了 2D 投影带来的深度歧义，但牺牲了纹理线索，这在纹理丰富场景下可能成为瓶颈。

## 总结

PQDT 旨在解决点云修复中复合畸变导致的局部细节丢失与输入敏感性问题。现有方法依赖全局特征或单阶段解码，难以在噪声与缺失共存时保持鲁棒性。PQDT 通过伪查询双阶段解码与动态查询选择，自适应平衡输入观测与学习先验，在 ShapeNet-55 上取得 CD 0.68 和 F1 0.570，显著优于 AnchorFormer。其边界在于纯 3D 输入策略未利用纹理信息，且实验仅在合成数据上验证，未涵盖真实世界 LiDAR 场景。当输入点云包含极端稀疏或严重遮挡时，伪查询的观测引导阶段是否仍能提取足够的粗几何信息，论文未给出回答。
