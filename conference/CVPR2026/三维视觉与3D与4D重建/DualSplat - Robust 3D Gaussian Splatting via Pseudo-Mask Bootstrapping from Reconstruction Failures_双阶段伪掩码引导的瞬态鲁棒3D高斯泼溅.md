# CVPR2026最新论文 ｜DualSplat: Robust 3D Gaussian Splatting via Pseudo-Mask Bootstrapping from Reconstruction Failures ｜双阶段伪掩码引导的瞬态鲁棒3D高斯泼溅

研究机构：北京航空航天大学、北京大学

作者：Xu Wang、Zhiru Wang、Shiyun Xie 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.21631)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.21631)

> 3D高斯泼溅（3D Gaussian Splatting, 3DGS）在包含行人、车辆等瞬态物体的真实场景重建中，常因视图不一致导致几何伪影与质量退化。现有在线抑制方法将瞬态检测与场景优化耦合，形成“检测依赖重建、重建依赖检测”的循环依赖，导致错误相互强化且难以逆转。DualSplat提出Failure-to-Prior范式，通过两阶段解耦，将首轮保守重建的失败模式转化为显式伪掩码先验，再引导第二轮干净重建。该方法在瞬态密集场景中显著优于现有基线，但其两阶段设计带来的训练开销与MLP的逐场景训练局限，限制了其向大规模或动态场景的扩展。

## 研究背景

3DGS将场景表示为可优化的各向异性高斯集合，通过可微光栅化实现实时渲染。其核心假设是所有训练视图描绘同一静态场景且观测相互一致。当视图中出现仅存在于部分视角的瞬态物体时，该假设被打破，3DGS会将这些不一致的观测吸收进场景表示，生成虚假高斯，导致重影伪影。为抑制瞬态干扰，主流方法采用在线掩码策略，在优化过程中动态估计瞬态区域并降低其损失权重。然而，这种在线检测与几何优化紧密耦合：准确的瞬态检测需要已重建的静态场景来暴露不匹配，而干净的几何重建又依赖可靠的瞬态掩码。从差初始化开始联合优化时，未拟合的静态区域可能被误判为瞬态，而真实的瞬态内容则被嵌入几何，一旦伪影固化，残差信号消失，失败几乎不可逆。

DualSplat的切入点在于将瞬态检测从在线优化中剥离。其核心观察是，瞬态物体因跨视图可见性稀疏且不连续，在保守的初始重建中常表现为不完整的碎片。这些失败模式并非需要消除的噪声，而是可被挖掘的瞬态发现线索。通过先执行一轮保守重建暴露失败，再将失败模式转化为对象级伪掩码，DualSplat打破了检测与重建的循环依赖，使瞬态抑制成为外部引导而非内部耦合过程。

## 核心方法

### 方法参照系

瞬态鲁棒3DGS的标准流程是在单阶段优化中，通过光度残差或特征一致性在线估计逐像素瞬态掩码，并在损失计算中抑制这些区域。DualSplat的关键差异在于将这一过程解耦为两个顺序阶段：第一阶段保守重建以暴露失败，第二阶段基于伪掩码先验进行干净重建，MLP在线细化掩码。

### 失败模式到对象级先验

第一阶段执行保守的3DGS重建，其目的并非完美分离瞬态，而是暴露因视图不一致导致的重建失败。对于每个SAM2实例掩码 $m_i^j$，计算空间平均光度残差 $\bar{R}_i^j = \frac{1}{|m_i^j|} \sum_{p \in m_i^j} R(p)$，其中 $R(p)$ 为像素 $p$ 的光度残差。同时，利用FiT3D提取真实图像与首轮渲染图像的稠密特征，计算逐像素余弦相似度 $S(p) = \frac{F_{gt}(p) \cdot F_{render}(p)}{\|F_{gt}(p)\| \|F_{render}(p)\|}$。设计动机在于，像素级阈值对未拟合的静态区域过于敏感，而对象级聚合利用了瞬态破坏在语义对象内的空间连贯性。实例被标记为瞬态先验，仅当其特征一致性低且光度误差高时，即 $S(m) < \tau_{sim}$ 且 $\bar{R}(m) > \tau_{L1}$。这些伪掩码 $M_{pseudo}$ 被刻意设计为高召回率，宁可过度掩蔽部分静态区域，也不允许瞬态泄漏进几何，从而为第二阶段提供外部引导。

### 先验引导的在线掩码细化

第二阶段在伪掩码先验下重建场景，其角色不是重新发现瞬态，而是在几何稳定后细化高召回的伪掩码。引入轻量级逐像素MLP，输入为真实视图的缓存特征 $f_i$ 和深度残差 $d_i$（Depth Anything v2预测深度与当前渲染深度之差），输出瞬态概率图 $M_i$。设计动机在于，伪掩码可能过度掩蔽稀疏观测的静态区域，而深度残差提供了互补的几何线索，因为瞬态物体常违反多视图深度一致性。MLP的训练采用先验监督到自一致性的渐进策略：早期迭代中，损失函数包含先验项 $\mathcal{L}_{prior} = \beta_{prior} \cdot \text{BCE}(M_i, M_{pseudo})$，其中 $\beta_{prior}$ 随迭代衰减；后期迭代中，监督转向自一致性，利用残差边界和特征一致性约束 $M_i$。这种渐进策略防止了早期几何不稳定时的过度拟合，同时允许MLP在几何稳定后自适应地修正伪掩码的误报。

## 实验评估

实验在RobustNeRF和NeRF On-the-go数据集上进行，对比3DGS、WildGaussians、DeSplat、SpotLessSplats、DeGauss和RobustSplat等基线。基线覆盖了特征一致性、残差分解和在线掩码等主流路线，但缺失生成式修复类方法如FixingGS，这可能影响对瞬态抑制上限的评估。

| 方法 | NeRF On-the-go Mean PSNR | RobustNeRF Mean PSNR |
| :--- | :--- | :--- |
| 3DGS | 19.04 | 27.43 |
| RobustSplat | 22.60 | 30.02 |
| DualSplat | 23.42 | 30.83 |

DualSplat在NeRF On-the-go上平均PSNR达23.42，较3DGS基线19.04提升4.38 dB，较RobustSplat提升0.82 dB；在RobustNeRF上平均PSNR达30.83，较RobustSplat提升0.81 dB。

| 模块 | Mean PSNR | 增益 |
| :--- | :--- | :--- |
| base (3DGS) | 19.043 | - |
| base+PM | 22.604 | +3.56 dB |
| DD+PM | 22.899 | +0.29 dB |
| DD+MLP | 23.262 | +0.37 dB |

消融实验显示，伪掩码应用（PM）贡献了最大的性能增益（+3.56 dB），表明准确的瞬态过滤是成功的关键。延迟致密化（DD）与PM的组合提供额外+0.29 dB，确认延迟致密化允许在几何确定前更可靠地抑制瞬态。MLP模块带来+0.37 dB的改进，验证了在线细化的价值。分层分析表明，DualSplat的优势集中在瞬态区域，静态背景性能与RobustSplat相当，说明改进主要来自伪影去除而非背景平滑。

评估边界方面，实验仅覆盖两个数据集，缺乏跨数据集泛化验证；MLP逐场景训练，未测试其跨场景迁移能力；两阶段设计增加了训练时间，论文未报告具体计算开销对比；代码未公开，可复现性受限。

## 关联研究分析

从问题动机看，DualSplat与RobustSplat同属瞬态鲁棒3DGS，但RobustSplat采用单阶段在线检测，依赖延迟致密化和特征一致性在优化过程中动态调整掩码。DualSplat的差异在于将检测前置为外部先验，其根源在于RobustSplat的在线耦合在差初始化下易陷入循环依赖，而DualSplat通过两阶段解耦避免了这一问题。然而，DualSplat依赖SAM2实例掩码，这在弱纹理或复杂遮挡场景下可能失效，而RobustSplat的纯特征方法对此类场景可能更具鲁棒性，论文未对此进行对比。

从方法设计看，DualSplat与SpotLessSplats均利用预训练特征检测瞬态，但SpotLessSplats使用扩散模型特征进行离线聚类，而DualSplat使用FiT3D特征进行在线相似度计算。FiT3D的多视图一致性监督使其在边界精度上优于扩散模型特征，但DualSplat的伪掩码构建依赖SAM2实例边界，而SpotLessSplats不依赖实例分割。这种差异源于任务特性：DualSplat的对象级聚合需要实例边界来定义聚合单元，而SpotLessSplats的聚类方法无需显式实例。DualSplat的MLP细化阶段借鉴了RobustSplat的渐进训练策略，但将其应用于伪掩码修正而非从零学习，这是否在所有场景下都优于直接在线学习，论文未给出回答。

## 总结

DualSplat要解决的核心矛盾是瞬态检测与场景重建的循环依赖。现有在线方法因耦合导致错误强化且不可逆，而DualSplat凭借“失败即线索”的观察，将首轮重建的失败模式转化为显式先验，打破了这一依赖。方法上，它通过两阶段解耦，先保守重建暴露失败，再用伪掩码引导干净重建，MLP在线细化。实验证明，该方法在NeRF On-the-go上平均PSNR达23.42，较3DGS提升4.38 dB，在瞬态密集场景中优势显著。然而，其边界在于两阶段设计增加了训练开销，MLP逐场景训练缺乏泛化能力，且依赖SAM2实例掩码。当场景包含大量弱纹理瞬态物体时，SAM2分割的准确性是否会成为瓶颈，进而影响伪掩码的质量，论文未给出回答。
