# CVPR2026最新论文 ｜DICArt: Advancing Category-level Articulated Object Pose Estimation in Discrete State-Spaces ｜离散状态空间下的关节物体位姿估计

研究机构：中国科学技术大学、上海交通大学

作者：Li Zhang、Mingyu Mei、Ailing Wang 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.19565)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.19565)

> 关节物体位姿估计需同时恢复多个刚性部件的位姿并满足运动学约束，现有连续回归方法在离散点云输入与连续输出间存在映射失配，且独立部件建模忽视关节耦合。DICArt 将位姿估计重构为离散扩散过程，通过灵活流动决策器同步去噪轨迹，并引入层级运动耦合机制处理遮挡。该方法在合成与真实数据集上验证了离散建模对关节物体位姿精度的提升，但其量化误差对精度的影响及实时性表现尚未充分探讨。

## 研究背景

关节物体由多个刚性部件通过关节轴连接，其位姿估计需同时预测每个部件的旋转与平移，并保证部件间运动符合物理运动学规律。传统方法将位姿视为连续向量直接回归，但点云观测本质上是离散且非均匀采样的，这种“离散输入-连续输出”的映射失配导致模型在复杂搜索空间中难以收敛。此外，关节物体的部件间存在强耦合关系，独立回归各部件位姿会忽略运动学约束，在自遮挡场景下尤其失效。

类别级物体位姿估计（COPE）领域已确立通过归一化物体坐标空间（NOCS）或生成式模型处理类内差异的范式。GenPose 等连续扩散方法虽能建模多模态分布，但在关节物体任务上仍面临两大瓶颈：一是连续空间搜索效率低，二是缺乏对部件间运动学约束的显式建模。A-NCSH 等基于 NOCS 的关节物体方法依赖显式结构先验，在遮挡严重时性能骤降。DICArt 的切入点在于将位姿估计从连续回归转向离散状态空间生成，并通过层级运动耦合机制将运动学约束内嵌于生成过程，从而在离散化带来的量化误差与运动学约束带来的搜索空间缩减之间取得平衡。

## 核心方法

### 离散扩散参照系

本文问题可置于离散去噪扩散概率模型（D3PMs）框架下。标准 D3PMs 通过前向马尔可夫链将数据逐步腐蚀为噪声，反向过程学习去噪分布以恢复数据。本文的关键差异在于：位姿序列是异构的（旋转与平移 token 语义不同），且需满足物理运动学约束，这要求对标准扩散过程进行结构化改造。

### 块对角转移矩阵与平滑分类

设计动机：标准离散扩散中，旋转 token 可能错误转换为平移 token，破坏位姿的物理一致性。本文在状态转移矩阵中引入块对角约束，隔离旋转与平移子空间。

$$
\mathbf{Q}_t^{[pose]} = \begin{bmatrix} \mathbf{Q}_t^{[rot]} & \mathbf{0} \\ \mathbf{0} & \mathbf{Q}_t^{[tsl]} \end{bmatrix}
$$

该公式确保旋转 token 仅在旋转子空间内转移，平移 token 仅在平移子空间内转移。同时，引入 [MASK] token 扩展状态空间至 $K+1$，使转移矩阵能动态编码量化类别与掩码状态，提升对噪声 token 的修正能力。

### 灵活流动决策器与层级运动耦合

设计动机：欧拉角间强耦合导致传统扩散去噪不同步，部分 token 过早收敛而其他 token 仍处高噪状态。本文引入灵活流动决策器（Flexible Flow Decider），通过 Gumbel-Softmax 函数 $v_{t-1}$ 动态决定每个 token 在每步是保持、去噪还是重置为噪声。

$$
q(\mathbf{x}_{t-1} | \mathbf{x}_t, \mathbf{x}_0) = \sum_{v_{t-1}} p(v_{t-1}) \cdot \mathbb{I}(\mathbf{x}_{t-1} = \mathbf{x}_0) \cdot \mathbb{I}(v_{t-1} = 1) + \mathbb{I}(\mathbf{x}_{t-1} = \mathbf{x}_t) \cdot \mathbb{I}(v_{t-1} = 0)
$$

该公式通过二元流动指示器 $v_{t-1}$ 控制去噪路径，强制语义相关 token 组保持同步收敛轨迹。在此基础上，层级运动耦合机制将部件分为父部件（无运动学约束）与子部件（沿关节轴运动），子部件位姿表示为相对于父部件的耦合状态。这种表示法使网络仅需预测耦合状态而非绝对位姿，即使子部件被遮挡，有限可见性也能提供足够的耦合状态预测信息。

## 实验评估

实验在 ArtImage（合成）、ReArtMix（半合成）和 RobotArm（真实）数据集上进行，基线包括 A-NCSH、GenPose、OP-Align 和 ShapePose。ArtImage 上，DICArt 在 Laptop 类别旋转误差 3.2°，优于 GenPose 的 5.3°；Dishwasher 类别旋转误差 2.9°，优于 A-NCSH 的 4.0°。

| 数据集 | 类别 | 方法 | 旋转误差 (°) | 平移误差 (m) |
| :--- | :--- | :--- | :--- | :--- |
| ArtImage | Laptop | DICArt | 3.2, 3.9 | 0.045, 0.040 |
| ArtImage | Laptop | GenPose | 5.3, 6.1 | 0.068, 0.060 |
| ArtImage | Dishwasher | DICArt | 2.9, 3.7 | 0.048, 0.055 |
| ArtImage | Dishwasher | A-NCSH | 4.0, 4.8 | 0.059, 0.123 |

消融实验显示，离散扩散较连续扩散在 Drawer 类别旋转误差从 3.1° 降至 1.7°，平移误差从 0.143m 降至 0.072m。灵活流动决策器使旋转误差从 4.0° 降至 1.7°，验证了同步去噪的有效性。自遮挡分析表明，即使可见率低于 20%，旋转误差仍稳定在 1.9°，平移误差 0.107m，证明层级运动耦合对遮挡的鲁棒性。

评估边界：指标仅包含旋转/平移误差，未报告计算效率（FPS）或置信区间。超参数（bin size=360, T=100）固定，未分析量化步长对精度的敏感性。代码未开源，可复现性受限。

## 关联研究分析

从问题动机看，DICArt 与 GenPose 同属生成式姿态估计路线，但 GenPose 聚焦刚性物体连续扩散，而 DICArt 针对关节物体离散化。差异根源在于任务特性：关节物体部件间运动学约束强，连续空间搜索易陷入局部最优，离散化将搜索空间限制在物理可行配置内。GenPose 未处理部件耦合，其连续扩散在关节物体上性能受限（ArtImage 上旋转误差 5.3° vs DICArt 3.2°），这是否源于连续空间对运动学约束的建模不足，论文未直接对比验证。

从方法设计看，DICArt 与 A-NCSH 均处理关节物体，但 A-NCSH 依赖 NOCS 显式结构先验，DICArt 通过离散扩散隐式学习结构。A-NCSH 在遮挡严重时性能骤降（Dishwasher 平移误差 0.123m），而 DICArt 通过层级运动耦合将遮挡部件位姿表示为耦合状态，即使有限可见性也能准确预测。这种差异是否源于离散化对局部几何特征的量化损失被运动学约束补偿，论文未提供消融实验直接验证量化误差与运动学约束的交互作用。

## 总结

DICArt 解决的核心矛盾是关节物体位姿估计中离散点云输入与连续位姿输出的映射失配，以及独立部件建模忽视运动学约束的问题。其切入点在于将位姿估计重构为离散扩散过程，通过块对角转移矩阵保证物理一致性，灵活流动决策器同步去噪轨迹，层级运动耦合机制内嵌运动学约束。ArtImage 上 Laptop 旋转误差 3.2°、Dishwasher 旋转误差 2.9° 验证了离散建模的有效性。边界在于：量化步长（bin size=360）固定，未分析其对精度的敏感性；未报告计算效率，实时性未知；代码未开源。当 bin size 减小以提升量化精度时，离散扩散的搜索空间是否指数级增长导致推理时间不可接受，论文未给出回答。
