# CVPR2026最新论文 ｜Hierarchical Point-Patch Fusion with Adaptive Patch Codebook for 3D Shape Anomaly Detection ｜自适应多尺度补丁编码的3D形状异常检测

研究机构：澳大利亚墨尔本大学、清华大学

作者：Xueyang Kang、Zizhao Li、Tian Lan 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.03972)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.03972)

> 3D形状异常检测旨在从点云中定位几何缺陷，但现有方法在处理平面位移或角度错位等大规模结构异常时普遍失效。本文指出，依赖局部点表征或重建误差的方法缺乏多尺度几何参考，导致对全局结构偏差的感知能力不足。通过构建位置不变的多尺度补丁特征码本，并结合点-补丁交叉注意力融合，该方法实现了从局部细节到全局结构的自适应异常推理。实验显示其在工业数据集上点级AUC-ROC提升超过40%，但在小样本统计显著性与采样随机性鲁棒性上仍存疑。

## 研究背景

工业质检中的3D点云数据通常存在噪声与不完整观测，直接基于点级几何特征进行异常检测时，局部特征容易受采样密度波动干扰。为缓解这一问题，Out-of-Distribution (OOD) 检测框架被引入，其核心假设是正常形状的特征分布紧凑且可学习，而异常输入将偏离该分布。然而，当异常表现为大范围的平面位移或部件错位时，局部点特征与正常模板的差异在特征空间中往往不显著，导致OOD检测失效。

3D形状异常检测的主流路线分为重建式与回归式。重建式方法如R3D-AD通过扩散模型恢复正常形状，依赖重建误差定位异常，但在平面或凹面区域对噪声敏感且训练依赖负样本增强；回归式方法如PO3AD直接预测点级偏移向量，擅长小局部缺陷，却缺乏对全局结构一致性的建模能力。这两类方法均假设异常是局部几何偏差，忽略了工业场景中常见的整体结构错位。本文的切入点在于，异常检测需要同时具备局部细节感知与全局结构参考，而现有方法缺乏一种轻量级、位置不变的多尺度几何参考机制。

## 核心方法

### 方法参照系

本文问题可归类于基于特征分布的OOD检测范式，其标准流程为：编码正常形状特征建立参考分布，编码测试形状并计算分布距离。本文与标准流程的关键差异在于，参考分布并非由全局嵌入或单尺度局部特征构成，而是由多尺度、位置不变的补丁特征码本（Patch Feature Codebook）动态检索生成，从而支持跨尺度的结构对比。

### 自适应多尺度补丁化与码本构建

传统点级编码将每个点独立映射为特征，无法捕捉部件级的几何一致性。本文在编码前引入Farthest Point Sampling (FPS) 补丁化，将点云划分为不同尺度的局部区域。设计动机在于，不同尺度的异常（如微小裂纹与整体错位）需要不同粒度的几何参考，单尺度特征无法同时覆盖。补丁特征通过计算补丁内点坐标均值并查询预训练3D UNet编码器获得，公式如下：

$$ \mathbf{p}_j^{[l]} = f\left( \frac{1}{N_j^{[l]}} \sum_{i \in N_j^{[l]}} \mathbf{x}_{j,i}^{[l]} \right) $$

其中 $f$ 为预训练编码器，$\mathbf{x}_{j,i}^{[l]}$ 为第 $l$ 尺度第 $j$ 个补丁内的点坐标。正常形状的补丁特征存入码本，以补丁中心到物体质心的距离为哈希键，确保位置不变性。推理时，测试补丁通过余弦相似度从码本检索最匹配的正常补丁，多尺度相似度取最大值确定最优匹配尺度，从而为后续融合提供结构参考。

### 点-补丁交叉注意力与门控调制

仅有补丁级相似度不足以实现点级精确定位，需将全局结构参考注入局部点特征。本文采用RoPE增强的交叉注意力，将点特征作为Query，检索到的正常补丁特征作为Key-Value，公式为：

$$ \mathbf{z}_i' = \text{MLP}\left( \text{RoPE}(\mathbf{q}_i, \mathbf{k}_i) \odot \mathbf{v}_i \right) $$

其中 $\mathbf{q}_i, \mathbf{k}_i, \mathbf{v}_i$ 分别为点、补丁的查询、键、值向量，$\odot$ 为逐元素乘法。设计动机在于，RoPE编码了点与补丁中心的相对空间关系，使注意力机制能区分“同一部件内的正常点”与“错位部件中的异常点”。随后，补丁级差异 $\Delta \mathbf{f}_{kj}$ 通过门控网络生成缩放与偏移参数，对交叉注意力输出进行调制，使异常区域的特征响应被自适应放大，最终通过MLP回归点级偏移向量。

## 实验评估

实验在Anomaly-ShapeNet（40类，1600样本）、Real3D-AD（12类，每类4模板+100测试）及自建工业数据集（8类，每类1正常+1异常）上进行。基线覆盖重建式（R3D-AD）、回归式（PO3AD）及记忆库式（ISMP）方法，但未包含基于CLIP/DINO的跨模态异常检测基线，可能低估了语义先验对开放集异常的贡献。

| 数据集 | 方法 | 平均AUC-ROC (%) |
| :--- | :--- | :--- |
| Real3D-AD | PO3AD | 76.5 |
| Real3D-AD | Ours | 84.2 |
| Anomaly-ShapeNet | PO3AD | 83.9 |
| Anomaly-ShapeNet | Ours | 87.6 |
| Industry | PO3AD | 18.9 |
| Industry | Ours | 75.6 |

在Real3D-AD上，本文平均AUC-ROC较PO3AD提升7.7个百分点；在工业数据集上，点级AUC-ROC从18.9%跃升至75.6%，验证了多尺度补丁码本对结构位移类异常的检测优势。消融实验表明，移除负样本增强导致AUC-ROC从84.2%降至68.2%，说明伪异常生成对分布边界学习至关重要；禁用点-补丁交叉注意力则使性能下降超过10%，证实了全局结构参考对局部定位的必要性。

评估边界方面，工业数据集每类仅1个样本，统计显著性无法保证；方法依赖FPS采样，论文承认对采样随机性敏感但未提供量化鲁棒性分析；代码已开源，但预训练UNet权重未明确说明是否公开，可能影响复现一致性。

## 关联研究分析

从问题动机看，本文与PO3AD同属点级偏移回归路线，但PO3AD假设异常是局部几何偏差，而本文针对的是全局结构错位。这一差异源于任务特性：工业缺陷中平面位移涉及大量点的协同偏移，局部点特征无法捕捉这种协同性，而补丁码本通过多尺度结构参考提供了全局约束。然而，本文未探索当异常同时包含局部裂纹与全局错位时的混合场景，补丁码本能否自适应切换尺度权重尚不明确。

从方法设计看，本文借鉴了HiT的层级结构思想，但HiT通过无监督学习发现语义部件，而本文的补丁化基于几何距离（FPS），缺乏语义一致性。这一差异暗示，当异常发生在语义部件边界（如齿轮齿形错位）时，几何补丁可能将语义完整的部件切割为多个碎片，导致码本检索失效。本文未对比基于语义部件的补丁化策略，仅报告了语义部件补丁化在Real3D-AD上性能略低于多尺度球体补丁化，但未分析原因。

## 总结

本文要解决的核心矛盾是局部点表征对全局结构异常的感知失效。现有重建式与回归式方法均假设异常为局部偏差，缺乏多尺度几何参考机制，而本文通过位置不变的多尺度补丁码本提供了跨尺度的结构对比基础。实验证明，该方法在工业结构位移异常上点级AUC-ROC提升超过40%，在Real3D-AD上平均提升7.7%。然而，工业数据集每类仅1个样本，统计显著性存疑；FPS采样随机性对检测结果的影响未被量化。当异常同时包含局部裂纹与全局错位时，多尺度补丁码本能否自适应切换尺度权重，论文未给出回答。
