# CVPR2026最新论文 ｜Neural Gabor Splatting: Enhanced Gaussian Splatting with Neural Gabor for High-frequency Surface Reconstruction ｜神经高斯泼溅

研究机构：日本东京大学

作者：Haato Watanabe、Nobuyuki Umetani

论文原文见 [arXiv](https://arxiv.org/abs/2604.15941)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.15941)

> 3D高斯泼溅（3D Gaussian Splatting, 3DGS）在处理高频纹理场景时，因单个原语仅能编码单一颜色，导致原语数量呈指数级膨胀，存储开销巨大。现有增强原语表达力的方法受限于固定基函数或纹理分辨率，无法灵活拟合复杂图案。本文在每个高斯原语内部嵌入轻量级多层感知机（MLP），将局部坐标与视角映射为颜色，并引入频率感知致密化策略以控制原语数量。该方法在固定数据预算下显著提升了高频表面的重建精度，但其逐场景优化特性及MLP计算开销限制了其在动态场景与大规模部署中的适用性。

## 研究背景

3DGS通过显式高斯原语与可微光栅化实现了实时渲染，但其核心瓶颈在于数据体积。每个原语由位置、尺度、旋转、不透明度及颜色参数化，当场景包含棋盘格或毛发等高频细节时，由于单个高斯仅能表达单一视角下的颜色，需大量原语堆叠以覆盖频繁的色彩过渡，导致内存占用达数GB。为缓解此问题，压缩方法通过高效编码参数降低存储，而另一条路线则致力于提升单个原语的表达力。

主流的原语增强方案存在固有局限：3D Gabor Splatting（Watanabe et al., 2023）用Gabor核替代高斯，但受限于Gabor噪声的数学特性；纹理高斯（Chao et al., 2024）附加可学习纹理，但受限于预设的纹理分辨率与方向依赖性。这些方法在严格存储预算下难以平衡细节保真度与数据紧凑性。本文切入点在于突破固定基函数或离散纹理的限制，通过引入连续神经表示，使单个原语具备建模复杂空间变化与视角依赖外观的能力，从而在相同数据预算下实现更优的高频重建。

## 核心方法

### 方法参照系

本文基于2D高斯泼溅（2DGS）框架，保留其平面高斯参数化与解析光栅化机制。与标准2DGS使用球谐函数（SH）编码视角依赖颜色不同，本文问题聚焦于如何在极小数据预算下，通过增强单原语内部表达力来替代原语数量堆叠，以解决高频纹理重建中的存储-质量权衡。

### 神经Gabor原语

标准2DGS中，颜色由SH系数 $\theta_k$ 决定，即给定视角方向 $\vec{d}$ 输出单一RGB值。本文设计动机在于SH基函数容量有限，难以拟合非线性视角反射与高频空间变化。创新方案是将颜色预测替换为每原语独立的轻量级SIREN MLP，输入为局部2D坐标 $(u, v)$ 与视角方向 $\vec{d}$ 的拼接向量 $\mathbf{y} \in \mathbb{R}^5$。

$$ \hat{c}_k = \text{MLP}_{\Theta_k}(\mathbf{y}; \omega_0) $$

其中 $\omega_0=30$ 为SIREN激活函数的频率参数。该公式表明，颜色不再是固定系数的线性组合，而是由神经网络从局部几何与视角非线性映射得出。SIREN的正弦激活隐式执行位置编码，使单个原语能表达条纹、反射等复杂图案，摆脱了Gabor核或纹理分辨率的约束，显著提升了单原语的信息密度。

### 频率感知致密化

传统梯度致密化依赖原语中心的位置梯度，在神经Gabor原语中，因颜色突变导致梯度噪声大，引发过度分裂。本文设计动机是避免在已充分重建区域冗余增加原语。创新方案是用频域误差替代空间域误差指导克隆与分裂。

$$ E_k[\pi] = \sum_{\mathbf{u}} w_k[\pi](\mathbf{u}) \cdot \epsilon_\pi(\mathbf{u}), \quad \epsilon_\pi(\mathbf{u}) = \text{Avg}(F^{-1}(|F(I_\pi) - F(GT_\pi)| \cdot M_{band})) $$

其中 $M_{band}$ 为带通滤波掩码，选取(0.01, 0.10)、(0.10, 0.20)、(0.20, 0.40)三个频段。该公式通过FFT提取渲染图与真值图的频域差异，仅当特定频段能量不足时触发致密化。这使得原语分配精准指向高频缺失区域，抑制了低频区域的无效增长，实现了存储预算的精细化控制。

## 实验评估

实验在Mip-NeRF360、DTU、Tanks and Temples及High-Frequency数据集上进行，基线涵盖3DGS、2DGS、3D Gabor Splatting、NTS及NEST。缺失最新SOTA如3D Skew-Normal Splatting的对比，但本文聚焦于固定数据预算下的效率-质量权衡，协议具有针对性。

| 方法 | High-Frequency (PSNR/SSIM/LPIPS) | Mip-NeRF360 (PSNR/SSIM/LPIPS) | DTU (PSNR/SSIM/LPIPS) |
| :--- | :--- | :--- | :--- |
| 3DGS* | 23.97 / 0.8335 / 0.2769 | 27.23 / 0.8005 / 0.2931 | 28.80 / 0.8467 / 0.4140 |
| 2DGS* | 23.91 / 0.8279 / 0.2855 | 26.47 / 0.7804 / 0.3197 | 28.98 / 0.8416 / 0.4171 |
| Ours | 26.49 / 0.8808 / 0.2115 | 26.98 / 0.810 / 0.2521 | 29.15 / 0.8519 / 0.3705 |
| 3D Gabor* | 25.28 / 0.8530 / 0.2449 | 26.76 / 0.8265 / 0.2388 | 28.91 / 0.8573 / 0.3800 |

在High-Frequency数据集上，本文PSNR达26.49，较3DGS*提升2.52dB，证明神经Gabor原语在高频细节上的表达优势。在Mip-NeRF360上，本文PSNR为26.98，略低于3DGS*的27.23，但SSIM与LPIPS更优，表明其在感知质量上更具优势。

| 致密化策略 | High-Frequency (PSNR/SSIM/LPIPS) |
| :--- | :--- |
| Frequency-aware | 25.72 / 0.8619 / 0.2352 |
| Error based | 25.95 / 0.8619 / 0.2376 |
| Gradient based | 25.56 / 0.8534 / 0.2464 |

消融实验显示，频率感知致密化与误差基致密化PSNR差距仅0.23dB，但频率感知策略具备频段选择性，能更精细地控制原语分配。梯度基策略表现最差，验证了其在神经原语中因梯度噪声导致的过度分裂问题。

评估边界方面，本文未报告置信区间，数值比较需谨慎。代码已开源，训练在RTX 3090上进行，耗时约为2DGS的两倍，主要源于MLP权重更新的原子操作开销。指标侧重PSNR/SSIM/LPIPS，缺乏几何精度（如Chamfer距离）的量化评估，限制了其在表面重建任务中的直接可比性。

## 关联研究分析

从问题动机看，本文与3D Gabor Splatting同属原语表达力增强路线，但根源差异在于表达机制。3D Gabor依赖固定Gabor核的线性组合，表达力受限于核函数特性；本文采用MLP，具备通用函数逼近能力，能拟合任意复杂图案。这种差异源于任务特性：高频纹理往往包含非周期性、非高斯分布的细节，固定基函数难以覆盖，而神经表示提供了更大的假设空间。然而，MLP的引入也带来了过拟合风险，论文未探讨在数据稀疏场景下MLP是否会导致几何失真。

从方法设计看，本文与NTS/NEST同属神经纹理泼溅范畴，但设计哲学不同。NTS/NEST使用哈希网格或三平面存储纹理特征，容量固定且依赖分辨率；本文每原语独立MLP，容量随原语数量线性增长，更灵活但计算开销更大。这种差异反映了“全局共享纹理”与“局部独立纹理”的权衡。NTS在Mip-NeRF360上PSNR达29.49（据领域综述），高于本文的26.98，但本文在High-Frequency数据集上显著领先，表明局部独立MLP在极高频细节上更具优势，而全局纹理在常规场景下效率更高。

## 总结

本文核心矛盾是3DGS高频重建中原语数量与存储预算的冲突。现有方法受限于固定基函数或纹理分辨率，无法在紧凑表示下保留细节。本文通过嵌入轻量级SIREN MLP，使单原语具备复杂图案建模能力，并辅以频率感知致密化，在High-Frequency数据集上以26.49 PSNR超越3DGS*的23.97。其边界在于逐场景优化特性及MLP带来的2倍训练耗时，且未验证动态场景下的时间一致性。当场景包含非刚性形变时，每原语独立MLP能否保持形变过程中的外观连贯性，论文未给出回答。
