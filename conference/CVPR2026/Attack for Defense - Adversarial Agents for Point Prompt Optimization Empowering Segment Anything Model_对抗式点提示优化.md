# CVPR2026最新论文 ｜Attack for Defense: Adversarial Agents for Point Prompt Optimization Empowering Segment Anything Model ｜对抗式点提示优化

研究机构：南京大学

作者：Xueyu Liu、Xiaoyi Zhang、Guangze Shi 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.18891)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.18891)

> 提示分割基础模型在无人交互场景下依赖低质量初始提示，导致分割精度在跨域任务中显著波动。现有启发式或孤立强化学习策略缺乏对提示效用的动态推理能力，且对初始分布敏感。本文提出 Point Prompt Defender (PPD)，通过攻击-防御双智能体对抗强化学习，在任务无关的双空间图环境中筛选并优化点提示。该框架实现了即插即用的提示净化，但在绝对分割性能上仍受限于纯提示优化的天花板，其对抗训练的泛化边界尚需更严苛的持续流式验证。

## 研究背景

当分割模型面对自动部署场景时，缺乏人工交互意味着初始提示往往由特征匹配等启发式方法生成，这些提示常包含大量噪声点或错误位置。这种低质量输入直接导致 Segment Anything Model (SAM) 的掩码生成出现边界泄漏或区域缺失。为应对此问题，提示工程（Prompt Engineering）旨在通过算法自动优化提示配置，但现有方法多将提示视为静态输入，缺乏对提示与分割结果之间动态反馈的建模。

主流提示优化路线分为两类：一类是微调提示编码器以注入任务特定语义，但此类方法依赖下游监督，难以泛化至未见域；另一类是基于几何先验的启发式生成，如 Matcher 和 GBMSeg，虽无需训练但无法自适应调整提示效用。Point Prompt Optimizer (PPO) 尝试引入强化学习迭代优化提示位置，但其优化过程孤立于 SAM 的分割反馈，且训练环境多样性不足，导致策略对初始提示分布高度敏感，跨域泛化能力受限。PPD 的切入点在于将提示优化重构为对抗博弈，通过主动模拟劣质提示来增强防御智能体对噪声的鲁棒性，从而在无需重训练的情况下实现任务无关的提示净化。

## 核心方法

### 方法参照系

PPD 属于提示工程优化路线，其核心差异在于摒弃了传统的静态启发式或单智能体强化学习，转而采用双智能体对抗框架。与 PPO 等孤立优化方法不同，PPD 将提示配置视为动态博弈状态，利用分割质量变化作为奖励信号，驱动攻击与防御智能体在 DINOv2 特征构建的双空间图中进行交互。

### 双空间图环境构建

设计动机在于解决传统提示优化忽略空间拓扑与语义相似性的问题。PPD 将图像划分为非重叠补丁，利用 DINOv2 提取特征向量 $f_i$，构建特征距离矩阵 $M_f$ 与物理距离矩阵 $M_p$。

$$
M_f(i, j) = \|f_i - f_j\|_2, \quad M_p(i, j) = \|c_i - c_j\|_2
$$

其中 $c_i$ 为补丁几何中心。该双空间图 $G=(V, E_f, E_p)$ 将语义亲和性与空间邻近性编码为边属性，使智能体不仅能操作提示点，还能推理提示间的结构关系，从而在复杂场景下更精准地识别有害提示。

### 对抗式提示优化机制

设计动机在于克服 PPO 对初始提示分布敏感且缺乏反馈协调的缺陷。PPD 引入攻击智能体（Attacker）与防御智能体（Defender），二者交替训练。攻击智能体激活提示以最大化分割性能下降，其奖励函数定义为 Dice 系数的负向变化：

$$
r_t^{atk} = \text{Dice}(M_{t-1}, M) - \text{Dice}(M_t, M)
$$

防御智能体则通过去激活有害提示恢复性能，奖励函数为 Dice 系数的正向变化。这种对抗训练迫使防御智能体学习在极端劣质提示下仍能恢复分割精度的策略，而非仅针对特定分布的提示进行微调。推理阶段仅部署防御智能体，对任意初始提示集进行净化，实现了任务无关的即插即用优化。

## 实验评估

实验在 PASCAL VOC、ISIC 和 Kvasir 数据集上进行，采用 one-shot 设定，初始提示由特征匹配生成。基线覆盖 PerSAM、Matcher、VRP-SAM、GBMSeg 及 PPO，但缺乏 PEFT 类（如 LoRA）及 TTA 类强基线，导致无法直接对比参数适配路线的性能上限。

| 方法 | PASCAL VOC mDSC (%) | ISIC mDSC (%) | Kvasir mDSC (%) |
| :--- | :--- | :--- | :--- |
| Matcher | 50.0 | 59.6 | 25.0 |
| GBMSeg | 68.9 | 69.6 | 35.0 |
| FM-PPO | 60.4 | 60.9 | 25.3 |
| FM-PPD (Ours) | **69.1** | **76.3** | **54.8** |

PPD 在三个数据集上均显著优于基线，尤其在 Kvasir 上较 GBMSeg 提升 19.8 个百分点，验证了对抗训练对低质量提示的鲁棒性。消融实验显示，攻击智能体将理想提示的 PASCAL VOC mDSC 从 78.5 降至 69.4，而防御智能体将其恢复至 73.5，表明防御策略有效抵消了大部分对抗扰动。

评估边界方面，论文未报告置信区间，且仅在 1000 张 FSS-1000 图像上训练，训练数据量较小。代码未公开，复现性受限。此外，实验未包含计算效率指标，未量化对抗推理带来的额外延迟，这与领域内对实时部署的关注存在缺口。

## 关联研究分析

从问题动机看，PPD 与 IP-SAM 同属自提示生成路线，但 IP-SAM 侧重通过条件化生成器合成任务感知提示，而 PPD 侧重通过对抗筛选净化已有提示。PPD 的对抗机制源于对 PPO 泛化不足的修正，其根源在于 PPO 的训练环境缺乏多样性，导致策略过拟合于特定提示分布。PPD 通过攻击智能体主动生成多样化劣质提示，扩展了防御智能体的经验分布，从而提升了跨域泛化能力。

从方法设计看，PPD 与 PEFT 路线（如 LoRA、Adapter）存在本质差异。PEFT 通过冻结骨干并注入轻量模块解决“模型懂不懂”的问题，而 PPD 仅优化输入端解决“模型看哪里”的问题。PPD 在 ISIC 上 76.3% 的 mDSC 远低于 Dual Adapters SAM2 的 88.45%，表明纯提示优化无法替代参数适配注入的领域知识。这一差距暗示，在低对比度医学影像中，提示质量的上限受限于 SAM 骨干本身的特征表达能力，而非提示配置本身。

## 总结

PPD 旨在解决自动部署场景下低质量初始提示导致的分割性能波动问题。其切入点在于通过对抗强化学习模拟极端劣质提示，增强防御智能体对噪声的鲁棒性，从而在无需重训练的情况下实现任务无关的提示净化。实验表明，PPD 在 Kvasir 上将 mDSC 从 35.0 提升至 54.8，验证了其对低质量提示的有效优化。然而，其绝对性能仍显著低于 PEFT 方法，暴露了纯提示优化在领域知识注入上的局限。当初始提示质量极低（如完全随机）时，防御智能体能否仅通过去激活策略恢复分割精度，论文未给出回答。
