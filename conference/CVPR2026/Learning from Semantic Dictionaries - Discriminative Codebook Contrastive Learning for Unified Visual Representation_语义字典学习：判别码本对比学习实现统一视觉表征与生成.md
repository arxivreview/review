> 视觉基础模型（VFM）擅长判别但缺乏生成细节，生成模型擅长合成但缺乏全局语义，二者语义空间存在根本错位。现有统一方法多依赖蒸馏或初始化，将统一性能视为副产品，未直接解决语义错位。本文提出 LEASE，通过预计算的生成与判别双离散码本，结合掩码重建与码本对比目标，在单一编码器中同时学习两种语义。该框架在统一自监督学习（SSL）基准上刷新了状态-of-the-art（SoTA），但其生成质量仍显著低于专用生成模型，且依赖外部预训练码本。

## 研究背景

统一视觉表征的核心困境在于判别与生成范式的语义割裂。VFM 通过自监督目标学习富含高层语义的潜表示，支持分类等判别任务，但其潜空间缺乏低层视觉细节，无法直接解码出高保真图像。反之，向量量化（VQ）分词器或扩散模型能捕获丰富的低中层视觉细节以合成图像，但其特征缺乏全局判别语义，在分类任务上性能骤降。这种“语义语言”的差异导致单一模型难以同时胜任理解与生成。

主流统一路线试图通过桥接两种范式来解决此问题。一类方法如 MAGE 和 Sorcen，利用 VQGAN 分词器在离散 token 空间进行掩码重建，虽提升了统一性能，但依赖在线分词器或双编码器，计算开销大且未显式对齐判别语义。另一类方法如 REPA 和 VFMTok，通过蒸馏冻结的 VFM 特征来指导生成模型，虽提升了生成质量，但引入了额外的教师模型和蒸馏损失，且将统一性能视为蒸馏的副产品。这些方法均未直接针对生成与判别表示之间的语义错位进行显式建模，导致在低数据或分布外场景下泛化能力受限。

本文切入点在于直接解决语义错位，而非依赖蒸馏。通过引入一对预计算的离散码本——生成码本与判别码本——LEASE 在训练前将图像转化为两种语义 token 序列。生成码本提供细节丰富的输入 token，判别码本提供语义丰富的中心点。这种设计消除了在线分词器和数据增强的需求，使模型能直接从两种语义空间的差异中学习，实现了高效且自包含的统一表征学习。

## 核心方法

### 方法参照系

本文问题属于统一视觉表征学习，标准流程通常采用单一编码器-解码器架构，通过联合优化重建与判别损失来平衡两种能力。关键差异在于，本文不依赖连续潜空间或在线分词器，而是完全在预计算的离散 token 空间操作，利用双码本结构解耦生成与判别语义的输入来源。

### 双码本输入与掩码重建

传统 MIM 方法在像素或连续特征空间进行掩码重建，计算成本高且缺乏显式语义结构。本文在预计算的离散 token 序列上进行掩码重建，生成码本提供输入 token $t$，判别码本提供位置对齐的语义 token $t'$。掩码步骤中，平均 69% 的 token 被替换为 [MASK]，仅保留约 19% 的可见 token 以降低内存占用。重建目标定义为：

$$ \mathcal{L}_{rec} = -\sum_{i=1}^{C_S} \mathbb{1}[m_i] \log p(t_i | E(t_{masked}), G) $$

其中 $C_S$ 为画布大小，$m_i$ 指示掩码位置。该公式通过预测被掩码的生成 token，迫使编码器捕获细粒度视觉细节，同时利用预计算 token 消除了在线分词器的计算开销。

### 码本对比学习

标准对比学习依赖数据增强生成正负样本，引入采样噪声且计算成本高。本文提出码本对比目标，利用判别码本的中心点作为正样本，所有其他中心点作为负样本。对于每个可见 token $t_i$，检索其判别中心点 $C_{t'_i}$ 及 $K_{sel}$ 个最相似邻居 $N_{t'_i}$，并基于余弦相似度自适应加权：

$$ w_j = \frac{\exp(\text{sim}_{ij} / \tau)}{\sum_{k \in N_{t'_i}} \exp(\text{sim}_{ik} / \tau)} $$

最终对比损失为：

$$ \mathcal{L}_{con} = -\sum_{i \in \text{unmasked}} \log \frac{\sum_{j \in N_{t'_i}} w_j \exp(\text{sim}(e_i, C_j) / \alpha)}{\sum_{k \neq i} \exp(\text{sim}(e_i, C_k) / \alpha)} $$

该公式将编码器特征 $e_i$ 与判别语义中心点对齐，消除了对数据增强的依赖，并通过自适应权重处理语义相似度的差异，提升了判别语义的鲁棒性。

## 实验评估

实验在 ImageNet-1K 上进行，基线覆盖 MAGE、Sorcen、MAE、SimCLR 等统一及专用模型，但缺失 PAE、AffineTok 等 2025-2026 年最新 SOTA。主结果显示，LEASE 在统一 SSL 任务中表现最优：

| 方法 | LP% | FID | IS |
| :--- | :--- | :--- | :--- |
| MAGE | 74.7 | 11.1 | 81.17 |
| Sorcen | 75.1 | 9.61 | 90.96 |
| LEASE | 76.7 | 9.62 | 91.78 |

LEASE 的线性探测（LP）准确率 76.7% 优于 MAGE 和 Sorcen，FID 9.62 与 Sorcen 持平但 IS 更高。在少样本学习中，LEASE 平均提升 2.32% 优于 MAGE；在鲁棒性测试中，其在 ImageNet-C 严重度 5 下的 k-NN 准确率为 20.39%，显著高于 MAGE 的 13.69%。

消融实验表明，码本大小从 8K 增至 16K 时，LP 从 75.20% 提升至 76.70%，FID 从 10.13 降至 9.62，显示更大码本有助于捕获更细粒度语义。判别码本来源对比中，DINOv2 优于 DINOv3、CLIP 和 FRANCA，其中 IN200 预训练的 DINOv2 码本（LP 85.86%）甚至优于 IN-1K 版本，暗示预训练数据规模对码本质量的影响可能超过训练数据一致性。

评估边界方面，本文仅评估了 ImageNet-1K，未涉及视频或高分辨率图像。FID 9.62 远高于专用生成模型（如 ADDP 的 8.9），表明统一框架在生成细节上仍有差距。代码已开源，但超参数如掩码比例（69%）和温度 $\tau$（0.1）的敏感性未详细讨论，可复现性依赖于预训练码本的可用性。

## 关联研究分析

从问题动机看，本文与 REPA 和 VFMTok 均旨在解决生成与判别语义的错位，但路线截然不同。REPA 通过蒸馏冻结的 VFM 特征到生成模型，依赖教师模型的语义先验，而本文通过离散码本对比直接学习语义，无需冻结教师。这一差异源于对“语义对齐”机制的不同假设：蒸馏假设语义可通过特征匹配传递，而本文假设语义可通过离散码本的对比结构内化。前者在生成质量上可能更优（如 REPA 的 gFID 1.26），但引入了额外的计算和依赖；后者在效率和自包含性上占优，但生成质量受限。

从方法设计看，本文与 MAGE 和 Sorcen 同属 VQGAN-based 统一框架，但关键差异在于输入处理和对比目标。MAGE 依赖在线分词器，导致训练时间比 LEASE 长 48.7%；Sorcen 使用双编码器，需额外前向传播。本文通过预计算 token 和单编码器设计，消除了这些开销。此外，本文的码本对比目标替代了传统数据增强对比，利用码本中心点作为正样本，避免了采样噪声。这一设计在低数据场景下优势明显（少样本提升 2.32%），但在数据充足时是否仍优于标准对比学习，论文未给出回答。

## 总结

本文核心矛盾是判别与生成语义的错位，现有方法依赖蒸馏或初始化，未显式建模错位。本文通过双离散码本和码本对比目标，在单一编码器中同时学习两种语义，实现了高效统一。实验证明其在统一 SSL 任务中 LP 76.7% 和 FID 9.62 达到 SoTA，但生成质量仍低于专用模型。边界在于依赖外部预训练码本，且未探索连续潜空间或视频扩展。当码本大小进一步增大时，生成 FID 是否持续下降，论文未给出回答。
