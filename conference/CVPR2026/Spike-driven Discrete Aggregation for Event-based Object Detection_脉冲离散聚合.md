# CVPR2026最新论文 ｜Spike-driven Discrete Aggregation for Event-based Object Detection ｜脉冲离散聚合

研究机构：浙江大学

作者：Huaning Li、Ziming Wang、Runhao Jiang 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_5d06909aea3f)

> 事件相机检测的核心矛盾在于异步稀疏数据与密集张量输入的不兼容，现有连续累积策略不可避免地引入传感器噪声与运动模糊。本文切入点在于利用脉冲神经网络（SNN）的阈值触发机制，将事件筛选与特征聚合解耦为离散过程。通过门控递归脉冲神经元实现可微分的自适应事件选择，并辅以多时间尺度融合增强表示。该方法在纯SNN架构中刷新了Gen1基准记录，但整体精度仍低于密集化融合方法，其能效优势是否足以抵消精度损失尚存疑。

## 研究背景

事件流由像素亮度变化触发，包含位置、时间戳和极性，其时空分布高度不均匀。传统帧相机依赖固定时间间隔的密集网格，而事件相机仅在亮度变化超过阈值时输出，导致数据在时间轴上呈现非均匀稀疏性。这种物理特性使得直接套用卷积神经网络（CNN）或视觉Transformer（ViT）变得困难，因为后者假设输入是规则采样的图像帧。为兼容现有架构，主流做法是将事件流采样并累积为密集张量，这一过程称为连续累积。然而，连续累积无法区分信息性事件与冗余噪声，传感器伪影和运动模糊事件被同等纳入，导致特征表示质量下降。

事件检测领域的主流路线分为密集化表征与异步稀疏表征。密集化方法如体素网格（Voxel Grid）和直方图（Histogram）通过刚性时间分箱将事件转为帧状，兼容CNN/ViT，精度高但损失时间精度；异步方法如SNN保留事件异步特性，低延迟低功耗，但训练困难且精度受限。现有SNN检测器如SpikeYOLO和EAS-SNN聚焦于骨干架构设计，底层事件表示仍采用简单的Event Count或连续累积，未解决噪声过滤问题。本文切入点在于底层表示层，提出脉冲离散聚合（Spiking Discrete Aggregation, SDA），利用SNN的阈值机制自适应筛选信息性事件，实现可微分的离散聚合，弥补了连续累积在噪声鲁棒性上的缺陷。

## 核心方法

### 方法参照系

事件检测的标准流程为：采样事件流至固定时间间隔，通过聚合器（如Event Count）生成密集张量，输入检测器。本文问题与该通用流程的关键差异在于聚合环节：传统聚合器无差别累积所有事件，而本文引入选择性机制，仅聚合触发脉冲的事件，将聚合过程从连续积分转化为离散触发。

### 脉冲离散聚合模块

SDA模块将每个空间坐标和极性组合分配一个泄漏积分-放电（Leaky Integrate-and-Fire, LIF）神经元。设计动机是解决连续累积中噪声事件与信息事件同等累积导致的特征污染。SDA的核心机制是：仅当神经元膜电位超过阈值触发脉冲时，该事件才被纳入聚合。聚合公式为：

$$
g_{SDA}(x, y, p) = \sum_{\substack{(x_i, y_i, p_i, t_i) \in \hat{E}(x,y,p) \\ \land \, \bm{s}_{t_i}(x_i, y_i, p_i) = 1}} \bm{u}_{t_i}(x_i, y_i, p_i)
$$

该公式的物理含义是：对每个像素位置，仅累加那些使对应神经元放电的事件的膜电位值，未触发脉冲的事件被自动过滤。通过代理梯度（Surrogate Gradient）实现反向传播，使SDA可与下游检测器端到端联合训练。相比连续累积，SDA实现了事件选择与特征聚合的耦合，提升了表示的判别力。

### 门控递归脉冲神经元与多时间尺度融合

标准LIF神经元仅依赖常数衰减因子，缺乏对复杂时间依赖的自适应捕获能力。设计动机是解决噪声或稀疏条件下事件重要性随时间变化的问题。本文引入门控递归脉冲神经元（Gated Recurrent Spiking Neuron, GRSN），用可学习的重置门 $R_t$ 替代常数衰减因子 $\tau$，并引入遗忘门 $F_t$ 调制输入电流：

$$
\bm{u}_t(x, y, p) = \bm{R}_t(x, y, p) \cdot \bm{\hat{u}}_{t-1}(x, y, p) + \bm{I}_t(x, y, p)
$$

$$
\bm{I}_t(x, y, p) = \bm{F}_t(x, y, p) \cdot \bm{I}_{t-1}(x, y, p) + \bm{c}_t(x, y, p)
$$

其中 $\bm{c}_t$ 由输入特征和上一时刻脉冲输出加权得到。当 $R_t$ 接近0时，历史状态被丢弃，有效过滤累积噪声。此外，引入多时间尺度融合（Multi-Timescale Fusion, MTF）方法，通过自适应采样（SAS）在更长时间间隔内提取粗粒度时间特征，利用SAS分支的膜电位生成软掩码 $M_j$ 调节SDA的当前更新，增强对慢速物体稀疏事件的捕获能力。

## 实验评估

实验在Gen1、1Mpx和N-Caltech101三个事件检测基准上进行，对比方法覆盖SNN（SpikeYOLO, EAS-SNN, CREST）和ANN（RVT, YOLOX）路线，但缺失RGB-Event融合类强基线（如M2C-EvDet），因本文仅使用事件数据。

| 方法 | 架构 | 参数量(M) | Gen1 mAP50:95 | Gen1 mAP50 |
| :--- | :--- | :--- | :--- | :--- |
| SpikeYOLO | SNN | 23.1M | 38.9 | 67.2 |
| EAS-SNN† | SNN | 25.3M | 37.5 | 69.9 |
| DASNN-MTF(M) | SNN | 25.3M | 43.4 | 73.1 |
| RVT | ANN | 18.5M | 47.2 | - |

DASNN-MTF(M)在Gen1上以43.4% mAP50:95领先所有全SNN方法，较SpikeYOLO提升4.5%，但低于ANN基线RVT的47.2%。在1Mpx上，DASNN-MTF(M)达到30.4% mAP50:95，是首个在该数据集上评估的全SNN模型，但远低于密集化方法Ev-DTAD的52.8%（据领域综述）。

| 变体 | GRSN | 软掩码 | Gen1 mAP50:95 |
| :--- | :--- | :--- | :--- |
| Baseline (SCA) | ✗ | ✗ | 41.2 |
| SDA | ✓ | ✗ | 42.8 |
| SDA-MTF (无掩码) | ✓ | ✗ | 42.8 |
| SDA-MTF (完整) | ✓ | ✓ | 43.4 |

消融实验显示，仅添加多时间尺度特征而未使用软掩码时，性能未提升（42.8% vs 42.8%），表明简单融合无效。引入GRSN后，SDA较SCA基线提升1.6% mAP50:95，证明门控机制对噪声过滤的贡献。在ANN兼容性测试中，SDA集成到YOLOX-S带来8.4% mAP50:95提升，集成到RVT-B仅提升1.5%，表明SDA对已具备时间建模能力的骨干增益有限。

评估边界方面，论文未报告置信区间，数值比较需谨慎。能效评估基于Gen1数据集，DASNN(S)实现3.79倍能效提升，但计算假设将递归连接和软掩码能耗等同于MAC操作，可能低估实际开销。代码未公开，超参数（如时间分辨率 $\Delta t_a=20$ ms）固定，缺乏对时间分辨率敏感性的详细分析。

## 关联研究分析

从问题动机看，本文与EAS-SNN同属SNN检测路线，但EAS-SNN聚焦于自适应采样策略以缓解时间不匹配，而本文聚焦于聚合机制本身。EAS-SNN的采样仍采用连续累积，未解决噪声过滤问题；本文SDA通过阈值触发实现离散筛选，在相同架构下较EAS-SNN提升5.3% mAP50:95。这一差异根源在于任务特性：事件检测中噪声占比高，连续累积的累积误差随时间增长，离散筛选能中断误差传播。但本文未探索SDA在长时序场景下的稳定性，当噪声比例极高时，阈值机制是否会导致信息丢失，论文未给出回答。

从方法设计看，本文与SpikeYOLO同用SNN骨干，但SpikeYOLO关注骨干架构的SNN适配，底层表示采用Event Count；本文证明表示层优化比骨干设计更关键，SDA在相同YOLOX骨干下带来显著增益。与密集化方法Ev-DTAD相比，本文采用异步稀疏表征，精度较低（43.4% vs 53.5%），但能效优势明显。这一分歧根源在于测量工具盲区：现有基准多基于同步帧处理，缺乏对异步推理延迟的标准化测量；在延迟敏感场景（如自动驾驶），本文的能效优势可能比精度更重要。但本文未提供延迟数据，无法直接验证其在实时场景中的实际价值。

## 总结

本文要解决的核心矛盾是事件连续累积引入的噪声污染与SNN训练稳定性之间的平衡。现有SNN检测器聚焦骨干设计，忽略底层表示的噪声过滤问题；本文凭借SNN阈值机制的天然离散性，将事件筛选与聚合耦合，实现可微分的自适应选择。通过门控递归脉冲神经元和多时间尺度融合，DASNN-MTF在Gen1上达到43.4% mAP50:95，较SpikeYOLO提升4.5%，并实现3.79倍能效提升。本文的边界在于仅使用事件数据，未探索RGB-Event融合，导致整体精度低于密集化方法；在ANN骨干中，SDA对已具备时间建模能力的架构增益有限。当噪声比例超过0.3时，SDA的性能下降幅度是否仍低于连续累积，论文未给出回答。
