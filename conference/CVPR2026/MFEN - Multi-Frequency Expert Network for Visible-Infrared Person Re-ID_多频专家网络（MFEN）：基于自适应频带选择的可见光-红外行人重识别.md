# CVPR2026最新论文 ｜MFEN: Multi-Frequency Expert Network for Visible-Infrared Person Re-ID ｜多频专家网络（MFEN）：基于自适应频带选择的可见光-红外行人重识别

研究机构：中国科学技术大学、香港中文大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_5588e918c06e)

> 导读 可见光-红外行人重识别（VI-ReID）面临的核心挑战是两种模态间巨大的光照与纹理差异，导致特征空间难以统一。现有频域方法通常采用固定频段滤波或全谱融合，无法应对复杂光照下身份线索与干扰信息在不同频率带间的动态分布。本文提出多频专家网络（MFEN），通过混合专家机制按样本自适应选择关键频带，并配合随机频率增强（RFA）与频域辅助优化（FAO）实现数据、模型与优化层面的协同。该方法在RegDB上取得SOTA，但在SYSU-MM01上落后于基于ViT的最新方法，其频域自适应机制在大规模复杂场景下的泛化能力存疑。

## 研究背景

VI-ReID需解决RGB与红外（IR）图像间的模态间隙（Modality Gap）。这一间隙不仅源于波长差异，更源于光源类型不同：RGB图像受自然光与人工光混合影响，细节丰富；而监控摄像头采集的IR图像依赖单一光源，常出现过曝或欠曝。这种亮度与颜色的剧烈变化加剧了同一身份内的特征差异，使得传统空间域特征提取难以区分身份线索与光照噪声。频域表示为此提供了物理基础，幅度谱主要编码光照与颜色信息，相位谱则保留结构细节。

主流频域VI-ReID方法如FDMNet与FDNM采用固定频段处理或全谱融合，假设身份相关线索集中在特定频率区域。然而，在复杂光照下，严重过曝样本需抑制主导的低频光照，而模糊或低对比度样本则依赖中高频细节，最优频带具有样本依赖性。现有方法缺乏这种自适应选择能力，导致在光照极端变化时性能退化。本文切入点在于识别“光源差异”这一被低估的因素，指出固定频带先验的不足，提出按样本动态融合多频带信息的机制。

## 核心方法

### 方法参照系

标准VI-ReID流程包含特征提取与度量学习，频域方法通常在特征提取阶段引入FFT变换进行滤波。本文的关键差异在于将频域处理从“固定滤波”升级为“自适应专家选择”，并在数据增强与损失函数中同步引入频域约束，形成数据-模型-优化三层协同架构。

### 随机频率增强（RFA）

传统数据增强如随机灰度化或亮度调整难以模拟真实光照的局部变化。RFA在图像级消除模态差异，通过交换训练批次中RGB与IR图像的低频幅度分量，保留高频结构能量与原始相位，从而模拟另一模态的光照模式而不破坏身份结构。

$$ A_s(x)(u, v) = A_l(x')(u, v) + A_h(x)(u, v) $$

该公式表明，增强后的幅度谱由另一模态的低频分量与自身高频分量组成，实现了光照模式的迁移与结构细节的保留。

### 多频专家网络（MFEN）

固定频段滤波无法适应样本间频带需求的差异。MFEN在特征级引入混合专家机制，将特征图分解为多个频带，每个专家处理特定频带，通过门控函数动态融合。专家设计采用1x1卷积投影至频域，仅对键（Key）应用频带掩码，查询（Query）保持全谱作为内容锚点，以维持跨频带互补性。

$$ A_b = BN_b(F^{-1}(Q_F \odot K_F^b)) $$

此公式描述了专家输出：全谱查询与特定频带键在频域逐元素相乘后逆变换回空间域，实现了特定频带信息的调制与提取。

### 频域辅助优化（FAO）

传统损失仅在空间域约束特征，忽略了频域统计信息的判别力。FAO在优化级引入频域辅助，计算特征图的频域表示并加入二阶矩信息，形成互补统计视图。通过镜像损失约束空间特征与频域统计，强化跨模态一致性。

$$ L_{fid} = E_i[-y_i \log(p_i + p''_i)] $$

该频率身份损失同时约束空间分类概率与频域统计分类概率，迫使模型在两个域均提取判别性身份线索。

## 实验评估

实验在SYSU-MM01、RegDB与LLCM三个基准上进行，使用ResNet-50骨干。基线覆盖频域类（FDMNet, FDNM, DSSF3）、生成类（AGW）与特征类（MPANet），但缺失2025-2026年基于ViT/CLIP的最新解耦与语义引导方法（如MTRL, IDEA）。

| 数据集 | 方法 | R-1 (%) | mAP (%) |
| :--- | :--- | :--- | :--- |
| SYSU-MM01 All-Search | MFEN (Ours) | 80.93 | 76.56 |
| SYSU-MM01 All-Search | DSSF3 | 79.12 | 75.27 |
| RegDB Vis-to-IR | MFEN (Ours) | 94.85 | 90.06 |
| RegDB Vis-to-IR | FDNM | 95.5 | 90.0 |

在SYSU-MM01上，MFEN以80.93% R-1领先频域基线DSSF3（79.12%），但低于知识库中基于ViT的MTRL（83.22% mAP）；在RegDB上，MFEN达到94.85% R-1，超越FDNM（95.5% R-1，90.0% mAP）的mAP表现，显示小尺度基准上的优势。

| 消融组件 | R-1 (%) | mAP (%) |
| :--- | :--- | :--- |
| Baseline | 77.77 | 74.28 |
| + RFA | 80.93 | 76.56 |
| + MFEN | 84.34 | 80.18 |
| + FAO | 86.85 | 81.89 |

消融显示MFEN贡献最大（+3.41% R-1），验证自适应频带选择的核心价值；RFA贡献+3.16% R-1，证明数据级光照消除的有效性。FAO的边际收益（+2.51% R-1）小于前两者，表明优化级约束是锦上添花而非决定性因素。

评估协议遵循标准10次平均，指标包含CMC与mAP。局限在于未报告置信区间，且ResNet-50骨干在SYSU-MM01上的表现落后于ViT方法，可能源于骨干容量而非频域机制失效。代码未公开，超参数（如专家数4、margin 0.6）已披露，可复现性中等。

## 关联研究分析

从问题动机看，MFEN与FDMNet同属频域对齐路线，但FDMNet采用固定频带融合，假设身份线索分布稳定；MFEN则针对“光源差异导致频带需求动态变化”这一具体失效，引入MoE门控实现样本级自适应。这一差异根源在于任务特性：VI-ReID中IR图像的光照极端性远高于RGB，固定先验在过曝/欠曝场景下失效，而MoE的灵活性恰好弥补了这一盲区。

从方法设计看，MFEN与DSSF3均利用频域统计，但DSSF3侧重双空间特征融合，MFEN则通过RFA在数据层预消除光照差异。RFA仅交换低频幅度，未处理高频结构噪声，这与STMI等分割引导方法形成互补。查询侧增强在数据充足时是否仍有增益，论文未给出回答，暗示RFA在大规模数据集上的边际效应可能递减。

## 总结

MFEN针对VI-ReID中光源差异导致的频带需求动态变化问题，提出自适应多频专家网络，通过MoE门控按样本选择关键频带，并配合RFA与FAO实现三层协同。实验证明其在RegDB上取得94.85% R-1，在SYSU-MM01上领先频域基线1.81% R-1，但落后于基于ViT的最新SOTA。其边界在于ResNet-50骨干在复杂场景下的容量限制，以及RFA仅处理低频光照而未涉及高频结构噪声。当支持集增大或光照极端性降低时，MoE门控的自适应收益是否显著高于固定频带方法，论文未给出回答。
