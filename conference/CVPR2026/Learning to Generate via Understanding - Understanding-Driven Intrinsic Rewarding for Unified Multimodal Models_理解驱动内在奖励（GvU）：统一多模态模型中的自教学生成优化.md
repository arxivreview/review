# CVPR2026最新论文 ｜Learning to Generate via Understanding: Understanding-Driven Intrinsic Rewarding for Unified Multimodal Models ｜理解驱动内在奖励（GvU）：统一多模态模型中的自教学生成优化

研究机构：中国科学院、北京大学

作者：Jiadong Pan、Liang Li、Yuxin Peng 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.06043)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.06043)

> 统一多模态模型（UMM）旨在单一架构内融合视觉理解与图像生成，但普遍存在理解能力强于生成能力的性能不对称，导致联合训练时出现负迁移。现有后训练方法多依赖外部重构损失或人工标注，未能利用模型内部的理解能力作为生成指导信号。本文提出 GvU 机制，将理解分支的 Token 级图文对齐概率转化为内在奖励，通过自监督强化学习（RL）实现无需外部监督的生成质量提升。该方法在 GenEval++ 上取得 43.3% 的相对提升，验证了理解对生成的单向增益，但双向协同的量化边界仍存疑。

## 研究背景

当 UMM 处理复杂文本到图像（T2I）任务时，其理解分支能准确解析空间关系与属性绑定，但生成分支往往无法将这些语义细节完整还原为像素。这种能力落差源于理解任务偏好紧凑的全局语义表征，而生成任务偏好高频细节重建表征，两者在共享参数中产生梯度冲突。为缓解此冲突，主流路线采用解耦架构或混合目标，但这类预训练阶段的架构设计难以在推理时动态调整理解与生成的权重，导致模型在特定复杂指令下仍表现不佳。

领域共识认为，单纯的功能集成不足以实现认知协同，需通过后训练显式激活理解与生成间的知识迁移。RecA 等方法利用重构损失进行后训练对齐，SGT 引入语义生成调优，但均依赖外部监督信号或特定数据分布。本文切入点在于利用 UMM 内部的理解分支作为“教师”，通过自生成闭环产生内在奖励信号，将理解能力直接转化为生成优化的梯度来源，从而在不修改骨干架构的前提下弥合理解-生成差距。

## 核心方法

### 方法参照系

本文基于 X-Omni 混合架构（自回归骨干+扩散头），属于后训练对齐路线。与标准 SFT 或重构损失后训练不同，GvU 不引入外部评估器，而是利用模型自身的理解分支计算图文对齐概率作为奖励，形成自监督闭环。

### Token 级内在奖励机制

传统图像级奖励（如 CLIP Score）粒度粗且易受奖励黑客攻击，无法捕捉细粒度语义偏差。GvU 在理解分支中计算生成图像 $I$ 条件下，原始文本提示 $T$ 的 Token 级条件概率。具体地，对于第 $j$ 个 Token $T_j$，其概率由理解分支的 Logits 计算：

$$ P(T_j | I, T_{1:j-1}) = \text{softmax}(\text{Logits}_\theta(\mathbf{X}_{j-1}))_{[T_j]} $$

其中 $\mathbf{X}_{j-1}$ 为包含图像 Token 和前序文本 Token 的输入序列。整体对齐概率取几何平均以消除长度偏差：

$$ P(T_{1:L} | I) = \left( \prod_{j=1}^{L} P(T_j | I, T_{1:j-1}) \right)^{1/L} $$

该公式将理解分支对图文一致性的内部置信度量化为细粒度奖励信号，解决了图像级奖励无法定位具体语义错误（如颜色、位置）的失效问题。

### 自监督 GRPO 优化

基于 Token 级奖励，本文采用 Group Relative Policy Optimization (GRPO) 进行策略优化。对于每个文本提示 $T$，策略模型 $\pi_\theta$ 生成 $G$ 组图像 $\{I_1, ..., I_G\}$，计算各组内在奖励 $R_i = P(T_{1:L} | I_i)$。优势函数 $A_i$ 通过组内归一化计算：

$$ A_i = \frac{R_i - \text{mean}(\{R_1, ..., R_G\})}{\text{std}(\{R_1, ..., R_G\})} $$

策略更新目标为最大化优势加权对数似然，并加入 KL 散度约束以平衡探索与稳定性：

$$ J_{GRPO} = \mathbb{E} \left[ \min \left( r_i(\theta) A_i, \text{clip}(r_i(\theta), 1-\epsilon, 1+\epsilon) A_i \right) - \beta D_{KL}(\pi_\theta || \pi_{ref}) \right] $$

此设计消除了对价值函数和外部奖励模型的依赖，利用理解分支的内在概率分布实现自教学生成优化。

## 实验评估

实验在 X-Omni 基线上进行，使用 50,000 条纯文本提示训练，评估基准包括 GenEval、DPG-Bench 和 GenEval++。基线覆盖 BAGEL、Janus-Pro、OmniGen2 等主流 UMM 及 FLUX 等专用模型，但缺失 RecA、SGT 等同类后训练方法的直接对比。

| 方法 | GenEval Overall | DPG-Bench Overall | GenEval++ Overall |
| :--- | :--- | :--- | :--- |
| X-Omni (Base) | 0.68 | 84.08 | 0.282 |
| GvU (Ours) | 0.81 | 85.68 | 0.404 |
| GvU (Ours)† | 0.84 | - | - |
| BAGEL | 0.81 | 85.07 | 0.371 |

GvU 在 GenEval++ 上取得 0.404 的得分，较基线提升 43.3%，显著优于 BAGEL 的 0.371。在 DPG-Bench 上，GvU 的 85.68 略高于 BAGEL 的 85.07，尤其在 Entity 和 Relation 子项表现突出，表明理解分支的空间关系解析能力有效迁移至生成过程。

消融实验显示，GvU 在理解能力较弱的基线上提升幅度更大（GenEval +138.1% vs. 常规基线 +19.1%），证实理解-生成差距越大，内在奖励的指导价值越高。在 MMT-Bench 细粒度理解子任务上，GvU 训练后的模型在 Visual Illusion 和 Hallucination 检测上分别提升 5.06 和 2.5 分，表明生成能力的增强反向促进了细粒度视觉理解，但整体 MMBench 准确率仅提升 0.16 分，双向协同效应有限。

评估边界方面，GenEval++ 使用 GPT-4.1 进行图像质量评估，存在评估器偏差风险；论文未报告置信区间，且未对比其他后训练方法（如 RecA）在相同基线上的表现，限制了方法优势的归因分析。代码基于 TRL 框架实现，使用 LoRA 微调，但未公开完整超参数配置。

## 关联研究分析

从问题动机看，GvU 与 RecA 同属后训练对齐路线，但 RecA 依赖重构损失作为外部监督，而 GvU 利用模型内部理解概率作为内在奖励。这一差异源于对“协同效应来源”的不同假设：RecA 假设生成质量可通过像素级重构提升，GvU 假设语义对齐可通过理解分支的置信度优化。GvU 在 GenEval++ 上的优势表明，对于复杂组合生成任务，语义层面的细粒度指导比像素重构更有效，但 RecA 在高分辨率图像重建上的表现未被本文对比，两者在保真度与语义对齐间的取舍尚不明确。

从方法设计看，GvU 与 SGT 均旨在提升生成质量，但 SGT 引入语义生成调优需额外标注数据，GvU 则通过自生成闭环实现无监督优化。GvU 的 Token 级奖励机制提供了比图像级奖励更细粒度的梯度信号，但这也引入了对理解分支准确性的依赖。若理解分支本身存在幻觉或偏差，内在奖励可能引导生成走向错误方向。论文未探讨理解分支错误对生成优化的负面影响，也未验证在理解能力极弱基线上 GvU 的鲁棒性，这限制了该方法在低质量预训练模型上的泛化能力。

## 总结

本文针对 UMM 中理解与生成的性能不对称，提出 GvU 机制将理解分支的 Token 级图文对齐概率转化为内在奖励，通过自监督 GRPO 优化生成质量。实验表明，该方法在 GenEval++ 上实现 43.3% 的相对提升，并在细粒度理解任务上取得微弱反向增益。然而，GvU 的效果高度依赖理解分支的准确性，且在整体生成保真度上未超越 BAGEL 等混合架构 SOTA。当理解分支存在系统性偏差时，内在奖励是否会导致生成质量的退化，论文未给出回答。
