# CVPR2026最新论文 ｜Molmo2: Open Weights and Data for Vision-Language Models with Video Understanding and Grounding ｜全开源视频语言模型与细粒度时空接地

研究机构：美国艾伦人工智能研究所、美国华盛顿大学

作者：Christopher Clark、Jieyu Zhang、Zixian Ma 等 21 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.10611)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.10611)

> 视频-语言模型（VLMs）在长视频理解与细粒度定位上长期受制于专有模型的封闭生态，开源社区缺乏高质量、非蒸馏的接地数据与训练范式。现有开源模型要么依赖专有模型合成数据，要么在时空点/轨迹输出能力上存在显著空白。Molmo2 通过构建 9 个全人工/LLM 协作生成的视频接地数据集，并引入双向视觉注意力与 Token 加权训练策略，实现了开源模型在视频计数与追踪任务上的 SOTA。其价值在于填补了开源视频接地的数据空白，但长视频推理能力仍受限于上下文长度与计算资源，与专有模型在复杂推理上仍有差距。

## 研究背景

当 VLMs 面对“机器人抓取红块几次”这类查询时，模型需将语言描述映射到视频时空坐标，这一过程称为视觉接地（Grounding）。然而，主流 VLMs 存在严重的语言先验偏差（Language Prior），即模型倾向于依赖文本捷径而非视觉证据，导致在需要精确时空定位的任务上性能失效。为纠正此偏差，需构建大规模、高质量的时空接地数据，强制模型学习视觉-语言在像素级与时序上的对齐，而非仅停留在语义匹配层面。

视频-语言表示学习已从粗粒度语义匹配转向细粒度时空接地，但开源生态面临双重瓶颈：一是数据获取成本高且存在时序错位，现有开源数据集多从专有模型蒸馏而来，缺乏透明性与可控性；二是长视频理解受限于上下文长度与计算资源，均匀采样丢失关键动态信息。Molmo2 的切入点在于彻底切断对专有模型的依赖，通过创新的人工-LLM 协作流水线构建全开源视频接地数据，并优化训练架构以提升长视频处理效率，从而在开源社区建立可复现、可解释的视频理解基线。

## 核心方法

### 方法参照系

主流 VLMs 采用“视觉编码器+投影层+LLM”架构，通过对比学习或指令微调建立图文对齐。本文问题与该通用流程的关键差异在于：传统方法缺乏时空接地能力，无法输出点（Points）或轨迹（Tracks），且数据构建依赖专有模型蒸馏，导致开源模型在细粒度定位任务上表现不佳。

### 全开源视频接地数据构建

针对现有开源数据依赖专有模型蒸馏的问题，Molmo2 设计了多阶段人工-LLM 协作流水线。对于密集视频字幕，标注员先以语音描述视频片段，经 Whisper-1 转录后由 LLM 重写，再融合 Molmo 生成的帧级细节，确保字幕平均长度达 924 词，远超 LLaVA-Video 的 547 词。对于视频指向（Video Pointing），标注员在 2 fps 帧序列中点击对象位置，生成 650k 个时空点查询。该数据构建过程可形式化为：

$$
D_{ground} = \{ (v, q, \{ (t_i, x_i, y_i) \}_{i=1}^N) \}
$$

其中 $v$ 为视频，$q$ 为自然语言查询，$(t_i, x_i, y_i)$ 为第 $i$ 个事件的时间戳与空间坐标。这一设计解决了此前开源数据缺乏时空粒度、依赖专有模型导致的泛化能力受限问题，使模型能直接学习从语言到时空坐标的映射。

### 双向视觉注意力与 Token 加权训练

在训练阶段，Molmo2 引入双向注意力（Bi-directional Attention）机制，允许视觉 Token 间进行双向信息交互，而非传统的单向因果注意力。同时，提出 Token 加权方案（Token-Weighting Scheme），平衡不同任务（如字幕、QA、指向）的学习权重。训练目标可表示为：

$$
\mathcal{L} = \sum_{k=1}^{K} w_k \mathcal{L}_k + \lambda \mathcal{L}_{bidir}
$$

其中 $w_k$ 为第 $k$ 个任务的权重，$\mathcal{L}_k$ 为对应损失，$\mathcal{L}_{bidir}$ 为双向注意力正则项。该设计动机在于解决多任务学习中视觉信息被文本先验淹没的问题，通过增强视觉 Token 间的上下文依赖，提升模型对细粒度视觉细节的捕捉能力。消融实验显示，移除双向注意力导致视频字幕 F1 从 39.5 降至 38.5，移除 Token 加权导致 QA 平均分从 64.8 降至 64.0，验证了该机制对细粒度理解的关键作用。

## 实验评估

Molmo2 在 VideoMME、Kinetics-400 等标准基准及自建的 Molmo2-VP/Track 上进行评估。基线覆盖 Qwen3-VL、Gemini 2.5 Pro 等 SOTA 模型，但缺失 ClusterSTM 等纯预训练优化方法的直接对比。在视频计数任务上，Molmo2-4B 在 BURST-VC 上取得 61.5% 准确率，显著高于 Qwen3-VL-4B 的 38.9%；在视频指向任务上，Molmo2-8B 取得 38.4 F1，远超 Gemini 3 Pro 的 20.0 F1。

| 任务 | 模型 | 指标 | 数值 |
| :--- | :--- | :--- | :--- |
| 视频计数 (BURST-VC) | Molmo2-4B | Acc. | 61.5 |
| 视频计数 (BURST-VC) | Qwen3-VL-4B | Acc. | 38.9 |
| 视频指向 (Molmo2-VP) | Molmo2-8B | F1 | 38.4 |
| 视频指向 (Molmo2-VP) | Gemini 3 Pro | F1 | 20.0 |

消融实验揭示，双向注意力与 Token 加权对性能提升具有显著贡献，但视频池大小从 3x3 增至 4x4 时，字幕 F1 从 39.5 降至 37.0，表明过大的池化尺寸会损失细粒度视觉细节。此外，长上下文 SFT 后，长视频 QA 平均分从 64.4 提升至 67.4，但视频字幕 F1 从 42.3 降至 39.9，显示长上下文训练在提升推理能力的同时，对细粒度字幕生成存在负迁移效应。

评估边界方面，Molmo2 在 VideoMME 上取得 72.6% 准确率，低于 VidGround 的 74.5%，可能因缺乏 RL 后训练导致视觉依赖度不足。评估协议中，视频指向任务使用 SAM 2 将点预测转换为分割掩码进行评估，可能引入额外误差。可复现性方面，论文提供完整代码、数据与模型权重，但长视频训练的计算资源需求较高，未在边缘设备上验证实时推理能力。

## 关联研究分析

从问题动机看，Molmo2 与 VidGround 均关注视觉接地，但 VidGround 侧重通过 RL 后训练显式纠偏，而 Molmo2 侧重数据驱动接地。VidGround 在 VideoMME 上取得 74.5% 准确率，高于 Molmo2 的 72.6%，表明 RL 后训练在提升视觉依赖度上可能更优，但 Molmo2 的全开源数据构建提供了更高的透明性与可控性。这一差异根源在于任务特性：RL 后训练依赖奖励信号设计，而数据驱动接地依赖数据质量与规模，二者在计算成本与数据需求上存在根本权衡。

从方法设计看，Molmo2 与 LLaVA-Prime 同属“视觉编码器+LLM”架构，但 LLaVA-Prime 侧重四阶段预训练框架，而 Molmo2 引入双向视觉注意力与 Token 加权。LLaVA-Prime 通过因果层级聚合解决静态图像预训练的数据瓶颈，而 Molmo2 通过双向注意力增强视觉 Token 间的上下文依赖，提升细粒度理解能力。这一差异源于数据构建策略：LLaVA-Prime 依赖大规模视频数据提升数据效率，而 Molmo2 依赖高质量人工标注数据提升接地精度。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

Molmo2 要解决的核心矛盾是开源视频-语言模型在细粒度时空接地上的数据缺失与能力空白。其切入点在于彻底切断对专有模型的依赖，通过全人工/LLM 协作流水线构建 9 个视频接地数据集，并引入双向视觉注意力与 Token 加权训练策略。实验证明，Molmo2-8B 在视频计数上取得 61.5% 准确率，在视频指向上取得 38.4 F1，显著超越 Qwen3-VL 与 Gemini 3 Pro。然而，其在 VideoMME 上 72.6% 的准确率低于 VidGround 的 74.5%，且长上下文训练导致字幕 F1 下降 2.4 点，暴露了长视频推理与细粒度生成之间的性能权衡。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
