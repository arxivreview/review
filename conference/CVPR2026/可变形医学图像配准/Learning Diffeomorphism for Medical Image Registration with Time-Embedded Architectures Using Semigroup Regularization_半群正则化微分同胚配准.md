# CVPR2026最新论文 ｜Learning Diffeomorphism for Medical Image Registration with Time-Embedded Architectures Using Semigroup Regularization ｜半群正则化微分同胚配准

研究机构：加拿大阿尔伯塔大学

作者：Mohammadjavad Matinkia、Nilanjan Ray

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_b30f9168fa8c)

> 可变形医学图像配准需在缺乏密集真值的情况下建立解剖结构对应，而传统方法依赖迭代优化或显式积分，计算耗时且易产生拓扑折叠。现有深度学习模型虽提升了速度，但往往通过缩放-平方积分或雅可比惩罚来维持可逆性，导致计算冗余与约束耦合。SGDIR 提出一种连续时间配准框架，仅通过单一半群正则化项内生保证微分同胚性，无需显式积分。该方法在严格约束下实现了近乎零折叠，但在无约束变形精度上略逊于基于基础模型的最新方法，其泛化能力边界尚待跨域验证。

## 研究背景

当配准算法处理极端形变时，若形变场出现局部折叠，解剖结构的拓扑完整性将被破坏，导致临床剂量计算或导航偏差。这种折叠通常源于速度场积分过程中的数值误差或正则化不足。为规避此问题，微分同胚配准（Diffeomorphic Image Registration, DIR）要求变换映射 $\phi$ 满足雅可比行列式 $|J_\phi| > 0$，即保持局部体积不变且可逆。然而，直接约束雅可比行列式往往需要复杂的弹性正则化或迭代优化，难以在端到端网络中高效实现。

主流深度学习配准范式如 VoxelMorph 和 SYMNet 通过预测速度场并利用缩放-平方（Scaling-and-Squaring）算法积分得到最终形变场。这一流程虽然确立了基础范式，但积分过程引入了额外的计算开销，且可逆性依赖于积分算法的稳定性而非模型本身的归纳偏置。此外，许多方法需额外引入平滑性或逆一致性损失来防止过拟合，导致损失函数设计复杂且各约束项权重敏感。SGDIR 的切入点在于解耦“形变预测”与“同胚保证”，不再显式预测速度场并积分，而是直接参数化时间连续的形变场，并通过数学证明表明，仅施加部分半群一致性约束即可迫使模型学习 ODE 流，从而内生地保证可逆性与拓扑保持。

## 核心方法

### 连续时间形变场参数化

传统 DIR 方法通常预测离散时刻的速度场 $\mathbf{v}$，再通过数值积分求解 $\phi_1$。SGDIR 摒弃了这一流程，直接采用时间嵌入架构（如 Temporal UNet 或 Diffusion Transformer）参数化形变场 $\phi_t(x)$。其核心假设是 $\phi_t$ 为自主 ODE 的流，满足 $\phi_0(x)=x$ 且 $\phi_t \circ \phi_s = \phi_{t+s}$。这种参数化使得模型能在任意时间步 $t \in [-1, 1]$ 直接查询形变，无需迭代积分，从而将推理复杂度与迭代次数解耦。

### 部分半群正则化

SGDIR 的关键创新在于引入部分半群正则化项 $\mathcal{L}^{t}_{\text{sg}}$，替代传统的雅可比惩罚或平滑项。该损失函数定义为：

$$
\mathcal{L}^{t}_{\text{sg}} = \|\phi_{2t-1} - \phi_t \circ \phi_{t-1}\|_2 + \|\phi_{2t-1} - \phi_{t-1} \circ \phi_t\|_2
$$

此公式强制形变场在时间组合上满足半群性质，即变形到时间 $2t-1$ 等同于先变形到 $t$ 再变形到 $t-1$。通过数学证明，SGDIR 表明满足此部分约束的 $\phi_t$ 必然是 ODE 的流映射，从而自动具备逆映射 $\phi_t^{-1} = \phi_{-t}$ 和循环一致性。这一设计消除了对显式逆场预测或辅助正则项的依赖，使得同胚性成为模型训练的内在属性而非外部约束。

### 统一框架下的严格与灵活模式

SGDIR 通过超参数 $\lambda$ 控制半群正则化的强度，实现了单一框架下的双模式运行。当 $\lambda = 10^5$ 时，模型严格遵循半群性质，产生近乎零折叠的微分同胚映射；当 $\lambda = 10^4$ 时，约束放松，模型退化为灵活的可变形配准方法，允许局部非物理形变以换取更高的配准精度。这种设计使得同一架构既能满足临床对拓扑安全性的严格要求，又能适应大形变场景下的精度需求，无需重新训练或切换模型。

## 实验评估

SGDIR 在 OASIS、ACDC、LungCT 和 AbdomenCTCT 等八个基准上进行了评估，对比了 CycleMorph、GradICON、TransMorph 等主流方法。基线覆盖全面，但缺失了基于基础模型的最新方法如 FMIR 和 SAMIR，这可能影响对当前 SOTA 的准确定位。

| 数据集 | 方法 | Dice (%) | \|J\|<0 (%) | TRE (mm) |
| :--- | :--- | :--- | :--- | :--- |
| OASIS (Inter-Subject) | SGDIR UNet ($\lambda=10^5$) | 85.36 | 0.0001 | - |
| OASIS (Inter-Subject) | TransMorph | 84.11 | 1.0665 | - |
| ACDC | SGDIR DiT ($\lambda=10^4$) | 87.82 | 0.3982 | - |
| LungCT | SGDIR UNet ($\lambda=10^4$) | - | 0.0615 | 2.23 |

在 OASIS 数据集上，SGDIR UNet ($\lambda=10^5$) 的 Dice 为 85.36%，高于 TransMorph 的 84.11%，且负雅可比体素比例降至 0.0001%，显著优于 TransMorph 的 1.0665%。在 ACDC 数据集上，SGDIR DiT ($\lambda=10^4$) 的 Dice 为 87.82%，虽低于据领域综述提到的 FMIR 的 88.5%，但拓扑保持性更优。LungCT 上 SGDIR UNet ($\lambda=10^4$) 的 TRE 为 2.23 mm，低于据领域综述提到的 VCoR 的 1.55 mm，表明在肺部大形变场景下，放松约束的 SGDIR 在精度上仍略逊于专用优化方法。

消融实验显示，$\lambda$ 的取值对性能影响显著。在 OASIS 上，$\lambda=10^5$ 时 Dice 为 85.90%，$\lambda=10^4$ 时 Dice 提升至 87.82%，但负雅可比比例从 0.0003% 上升至 0.3982%。这表明精度与拓扑安全性之间存在权衡，$\lambda$ 的调节是控制这一权衡的关键。此外，连续时间采样优于离散采样，验证了时间嵌入架构的有效性。

评估指标涵盖了 Dice、TRE、HD95 和负雅可比比例，但缺乏对推理时间和显存占用的详细报告，尽管论文声称 SGDIR 具有最高的推理速度。代码已开源，但超参数 $\lambda$ 的选择依赖于数据集特性，缺乏通用的选择准则，可能影响跨数据集的可复现性。

## 关联研究分析

从方法设计看，SGDIR 与 SYMNet 的核心差异在于同胚性的实现机制。SYMNet 依赖缩放-平方积分速度场，其可逆性受限于积分算法的数值稳定性，且需额外平滑项防止折叠。SGDIR 则通过半群约束直接保证流映射性质，无需积分步骤，从而消除了数值误差累积的风险。这一差异源于 SGDIR 对 ODE 流性质的数学利用，而非简单的架构改进。然而，SGDIR 未探索基础模型特征在跨域泛化中的作用，而 FMIR 等方法通过预训练特征提升了域外性能，这暗示 SGDIR 在分布外数据上的鲁棒性可能受限。

从问题动机看，SGDIR 与 TransMorph 均旨在提升配准精度，但 TransMorph 关注长程依赖建模，通过 Swin Transformer 增强全局上下文，而 SGDIR 关注拓扑一致性，通过半群约束确保物理合理性。TransMorph 在 OASIS 上的 Dice 为 84.11%，低于 SGDIR 的 85.36%，但 TransMorph 的负雅可比比例为 1.0665%，远高于 SGDIR 的 0.0001%。这表明在需要严格拓扑保持的场景（如手术导航）中，SGDIR 更具优势；而在仅需高精度对齐的场景中，TransMorph 可能更具竞争力。SGDIR 未讨论其在多模态配准中的表现，而跨模态强度差异是领域主要挑战之一，这限制了其通用性。

## 总结

SGDIR 解决了微分同胚配准中积分冗余与约束耦合的矛盾，通过部分半群正则化内生保证可逆性，无需显式积分或辅助惩罚。该方法在 OASIS 上实现了 85.36% 的 Dice 和 0.0001% 的负雅可比比例，证明了半群约束在拓扑保持上的有效性。然而，其在 ACDC 和 LungCT 上的精度略低于基于基础模型或专用优化的方法，暴露了其在跨域泛化和极端形变精度上的局限。当训练数据分布与测试分布存在显著偏移时，半群约束能否独立维持配准精度，还是必须依赖基础模型特征增强，论文未给出回答。
