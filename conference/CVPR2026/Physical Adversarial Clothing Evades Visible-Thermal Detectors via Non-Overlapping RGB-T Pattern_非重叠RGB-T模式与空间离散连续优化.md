# CVPR2026最新论文 ｜Physical Adversarial Clothing Evades Visible-Thermal Detectors via Non-Overlapping RGB-T Pattern ｜非重叠RGB-T模式与空间离散连续优化

研究机构：清华大学

作者：Xiaopei Zhu、Guanning Zeng、Zhanhao Hu 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.04675)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.04675)

> RGB-T多模态检测器在物理世界中的对抗脆弱性长期被忽视，现有攻击方法受限于2D视角或材料重叠导致的光衰减。本文通过构建3D全视角模型与非重叠材料设计，提出空间离散连续优化算法，实现了数字与物理世界的高成功率攻击。该方法揭示了多模态融合架构在物理对抗下的系统性失效，但物理世界攻击成功率与数字模拟存在显著差距，材料物理特性的影响尚未完全解耦。

## 研究背景

当自动驾驶系统依赖RGB-T融合检测器时，其安全性假设建立在“多模态互补能抵抗单模态干扰”的直觉之上。然而，物理对抗样本（Physical Adversarial Examples）通过修改真实世界物体的外观或热辐射特性，可欺骗检测器产生漏检。由于RGB与热红外成像机制差异巨大，针对单一模态设计的对抗图案无法有效转移至另一模态，导致现有物理攻击方法难以同时欺骗多模态检测器。

RGB-T物理攻击领域的主流路线存在两个关键瓶颈。早期方法如AdvB、MAP和UAP采用2D贴片形式，攻击视角局限于-30°至30°，无法覆盖真实场景中的全视角威胁。另一条路线如MIC采用重叠RGB-T图案（Overlapping RGB-T Pattern, ORP），通过叠加低E膜实现双模态干扰，但膜层导致可见光透射率降低30%，削弱了打印图案的可见性并增加生产成本。这些局限使得RGB-T检测器在不同物理环境下的脆弱性未被充分探索。

本文的切入点在于同时解决视角局限与材料冲突。通过构建对齐的3D RGB-T人体与衣物模型，将攻击从2D平面扩展至0°-360°全视角。同时，提出非重叠RGB-T图案（Non-Overlapping RGB-T Pattern, NORP）设计，利用不同材料的可见光与热红外特性，避免材料重叠导致的光衰减，从而在低成本条件下实现物理可实现的对抗衣物。

## 核心方法

### 方法参照系

本文问题属于物理对抗样本生成范畴，但区别于传统单模态攻击的像素级优化流程。关键差异在于：RGB-T对抗图案需同时满足可见光连续变量（RGB值）与热红外离散变量（材料类型）的物理约束，且需在全视角3D渲染下保持攻击有效性。

### 非重叠RGB-T图案设计

NORP设计解决了ORP中材料重叠导致的光衰减问题。在NORP中，每个像素位置$i$被参数化为$X_i = [r_i, g_i, b_i, t_i]$，其中$[r_i, g_i, b_i]$为可见光RGB值，$t_i$为热辐射强度。引入离散变量$p_i \in \{0, 1\}$表示材料类型：$p_i=0$表示覆盖铝膜（RGB值固定为$[r^{(T)}, g^{(T)}, b^{(T)}]$，热辐射为$t^{(film)}$），$p_i=1$表示打印织物（RGB值可优化为$[r_i^{(V)}, g_i^{(V)}, b_i^{(V)}]$，热辐射为$t_i^{(body)}$）。该设计的物理含义是：每个像素只能选择一种材料，避免多层叠加导致的光能损失，同时利用铝膜的高热反射性与织物的可打印性实现双模态干扰。

### 空间离散连续优化

NORP优化的核心挑战在于$p_i$的离散性与RGB变量的连续性相互纠缠。直接优化连续近似变量$\tilde{p}_i$会导致次优解，因为$p_i$的近似会影响其他变量的梯度计算。本文提出空间离散连续优化（Spatial Discrete-Continuous Optimization, SDCO）方法，其核心是空间随机离散化（Spatially-Random Discretization, SRD）。在每次迭代中，生成随机掩码$M \in \{0, 1\}^N$，其中$M_i \sim \text{Bernoulli}(\alpha)$。对于$M_i=1$的像素，将$\tilde{p}_i$离散化为$p_i = \mathbf{1}(\tilde{p}_i \geq 0.5)$并冻结其梯度，同时优化对应的RGB变量；对于$M_i=0$的像素，保持$\tilde{p}_i$连续并优化，同时冻结RGB变量。优化目标为最小化检测器置信度：

$$
\mathcal{L} = \sum_{j=1}^{4} w_j f_{obj}^{(j)}(I_{paste}^{vis}, I_{paste}^{thm})
$$

其中$f_{obj}^{(j)}$为第$j$种融合架构检测器的目标置信度，$w_j$为经验权重。该公式的物理含义是：通过集成多种融合架构的检测器，使对抗图案在优化过程中同时针对早期、中期、晚期及独立检测器，提升跨架构的转移性。SRD通过空间随机性平衡双模态变量优化，确保每个像素在迭代中均有概率被优化，最终通过二值化得到物理可实现的NORP。

## 实验评估

实验在FLIR-aligned数据集上进行，包含4,129对训练图像和1,013对测试图像，评估指标为攻击成功率（ASR），定义为未检测目标数与总目标数之比，IoU阈值为0.5，置信度阈值为0.6。基线方法包括MAP、MIC和UAP，覆盖2D贴片与ORP设计路线，但未包含CDDFuse、ICAFusion等高精度融合检测器作为攻击目标，因攻击实验需针对特定检测器架构进行优化。

| 方法 | 数字世界ASR(%) | 物理世界ASR(%) |
| :--- | :--- | :--- |
| MAP | 15.6 | - |
| MIC | 12.0 | - |
| UAP | 3.4 | 33.4 |
| Ours | 99.6 | 71.0 |

数字世界ASR 99.6%显著优于所有基线，物理世界ASR 71.0%亦大幅超越UAP的33.4%，验证了NORP+SDCO的有效性。消融实验显示，移除SRD后ASR从99.6%降至78.6%，表明空间随机离散化对平衡双模态优化至关重要。与Gumbel-Softmax和STE相比，SDCO在数字世界ASR上分别高出14.2%和5.2%，物理世界ASR上分别高出37.2%和7.6%，说明空间随机性比顺序离散化更符合NORP的空间分布特性。

评估边界存在局限：物理世界ASR 71.0%与数字世界99.6%的差距未分解为渲染误差与材料物理特性的贡献；实验仅测试了YOLOv11等特定检测器，未覆盖Transformer-based融合检测器；代码已开源，但物理实现依赖25mm×25mm像素精度与0.1mm铝膜，可复现性受材料工艺限制。

## 关联研究分析

从问题动机看，本文与MIC直接对立：MIC通过ORP叠加低E膜实现双模态干扰，但光衰减30%削弱了可见光图案；NORP通过材料分离避免重叠，以空间分布替代层叠结构。这一差异源于任务特性：物理对抗需兼顾可见光可见性与热红外干扰，而ORP的层叠结构在物理上必然导致光能损失，NORP的空间分离设计是物理可实现性的必然选择。

从方法设计看，本文与UAP同属物理对抗生成框架，但UAP针对独立检测器，本文扩展至多融合架构。UAP的2D贴片设计无法处理3D视角变化，本文通过3D RGB-T模型与EOT增强实现全视角攻击。这一差异源于攻击目标：独立检测器仅依赖单模态，2D贴片足以欺骗；而融合检测器依赖跨模态特征交互，需在全视角下保持双模态对抗图案的一致性，3D建模成为必要前提。

## 总结

本文要解决的核心矛盾是RGB-T检测器在物理世界中的对抗脆弱性未被充分探索，现有方法受限于2D视角与材料重叠。本文抓住的切入点是3D全视角建模与非重叠材料设计，通过构建对齐的3D RGB-T模型与NORP，解决了视角局限与光衰减问题。方法上，提出SDCO算法，通过空间随机离散化平衡连续RGB变量与离散热红外变量的优化。实验证明数字世界ASR 99.6%、物理世界ASR 71.0%，显著优于基线。本文的边界在于物理世界ASR与数字模拟的差距未分解，且未测试Transformer-based融合检测器。当物理世界ASR 71.0%的差距中，材料物理特性（如铝膜反射率、织物热辐射）的贡献占比多少，论文未给出量化分析。
