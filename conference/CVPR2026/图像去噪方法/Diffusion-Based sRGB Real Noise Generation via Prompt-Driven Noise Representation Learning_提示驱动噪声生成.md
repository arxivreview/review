# CVPR2026最新论文 ｜Diffusion-Based sRGB Real Noise Generation via Prompt-Driven Noise Representation Learning ｜提示驱动噪声生成

研究机构：韩国汉阳大学

作者：Jaekyun Ko、Dongjin Kim、Soomin Lee 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.04870)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.04870)

> 真实世界去噪的核心瓶颈在于合成噪声与相机实际噪声分布的域差距，而现有生成方法普遍依赖相机元数据（如ISO、传感器型号）作为条件，这在公开图像或科学成像中往往缺失。本文切入点在于将元数据替换为从输入噪声图像本身提取的“提示特征”，实现训练与推理阶段均无需元数据的噪声合成。具体做法是构建提示自编码器（PAE）提取全局与局部噪声统计特征，并以此条件化一致性模型（CM）生成潜码。该方法在SIDD基准上达到了与专用校准方法持平的噪声合成精度，但其下游去噪性能受限于所采用的回归式骨干网络，且未验证在极端低光或混合噪声场景下的泛化边界。

## 研究背景

理解本文需厘清sRGB噪声生成的条件依赖机制。传统方法如FlowsRGB利用归一化流建模噪声分布，但其条件输入是显式的相机元数据，即ISP（Image Signal Processor）将RAW转为sRGB时的增益与传感器参数。当元数据缺失时，模型无法定位噪声分布的具体位置，导致合成噪声与真实噪声在幅度与空间相关性上出现偏差。为摆脱这一依赖，NAFlow引入了噪声感知采样算法，在推理阶段无需元数据，但其训练阶段仍依赖元数据构建条件分布，限制了其在无元数据数据集上的适用性。

真实世界噪声具有信号依赖性与空间相关性，直接应用合成高斯噪声训练的模型在真实场景泛化能力差。主流路线通过元数据驱动生成合成噪声对，以扩充训练数据规模，但元数据的不一致性与缺失性成为实际部署的阻碍。本文针对这一瓶颈，提出从输入噪声图像直接提取特征作为生成条件，旨在构建一个无需任何外部元数据信息的统一噪声生成框架，从而提升方法在多样化真实场景中的通用性。

## 核心方法

### 方法参照系

本文问题归属于噪声建模与合成路线，标准流程是利用生成模型学习噪声分布，并以相机元数据为条件合成含噪图像。本文与通用流程的关键差异在于，将条件输入从显式元数据替换为从输入噪声图像中提取的隐式提示特征，实现了训练与推理阶段的双无元数据依赖。

### 提示自编码器（PAE）

PAE的设计动机是解决元数据缺失时无法获取噪声全局统计（如ISO增益）与局部空间相关性（如ISP非线性变换导致的非独立同分布噪声）的问题。PAE由提示编码器$E$与解码器$D$组成，编码器将输入噪声$n_{Real}$映射为潜码$z$，并动态生成全局提示特征$F_{Global}$与局部提示特征$F_{Local}$。全局提示块（GPB）通过计算输入特征的通道均值与标准差，生成输入特定的系数$w_{Global}$，动态调制可学习的全局提示组件$P_{Global}$，以捕捉ISO等全局噪声属性：

$$F_{Global} = \text{Conv}_{3\times3}(\text{Softmax}([\mu(\cdot), \Sigma(\cdot)]) \odot P_{Global})$$

局部提示块（LPB）则通过计算噪声补丁内像素与中心像素的皮尔逊相关系数，提取局部相关性图，并经行/列平均与上采样生成局部提示系数，以捕捉相机特定的空间噪声模式。解码器$D$结合潜码$z$与干净图像$I_{Clean}$重构含噪图像，损失函数为$L_1$损失与潜码$L_2$正则化之和，确保重构保真度与潜码紧凑性。

### 提示DiT（P-DiT）

P-DiT的设计动机是解决传统扩散模型多步推理计算成本高，且难以在单步内精确对齐提示特征与潜码分布的问题。P-DiT基于一致性模型（CM）架构，学习一个映射函数$f_\theta(x_t, \sigma_t)$，使得对于任意噪声水平$t$，输出与原始潜码$z_0$保持一致。其训练损失为一致性训练（CT）损失：

$$\mathcal{L}_{CT} = \mathbb{E}_{t, \sigma_t, z_0} [\lambda(t) d(f_\theta(z_t, \sigma_t), \text{sg}(f_{\theta^-}(z_t, \sigma_t)))]$$

其中$z_t$为前向加噪潜码，$d(\cdot)$为伪Huber距离，$\text{sg}(\cdot)$为停止梯度算子。P-DiT以PAE提取的$F_{Global}$、$F_{Local}$及干净图像$I_{Clean}$为条件，将采样潜码$z_T$单步转换为$z_0$，随后由PAE解码器生成最终含噪图像。这一设计将多步扩散压缩为单步生成，显著降低了推理开销，同时通过提示特征条件化确保了合成噪声与输入噪声分布的一致性。

## 实验评估

| 方法 | SIDD KLD ↓ | SIDD AKLD ↓ | SIDD PSNR ↑ | SIDD SSIM ↑ |
| :--- | :--- | :--- | :--- | :--- |
| C2N | 0.2129 | 0.2802 | 33.76 | 0.901 |
| NeCA-W | 0.0342 | 0.1436 | 36.82 | 0.932 |
| NAFlow | 0.0305 | 0.1306 | 37.22 | 0.935 |
| **Ours (PNG)** | **0.0174** | **0.1163** | **37.55** | **0.937** |

实验在SIDD、PolyU、Nam及MAI2021数据集上进行，基线覆盖C2N、NeCA-W、NAFlow等主流噪声合成方法，但缺失FlowsRGB及最新SOTA方法SNIC的对比。在SIDD验证集上，PNG的KLD为0.0174，AKLD为0.1163，均优于NAFlow的0.0305与0.1306，表明其合成噪声分布更接近真实噪声。下游去噪任务中，使用PNG合成数据训练的DnCNN在SIDD上取得37.55 dB PSNR与0.937 SSIM，较NAFlow提升0.33 dB，且与使用真实配对数据训练的Real基线（37.63 dB）仅差0.08 dB，验证了合成噪声的有效性。

| 组合 | KLD ↓ | AKLD ↓ |
| :--- | :--- | :--- |
| ✗ (无提示) | 0.6182 | 0.4387 |
| ✓ (仅GPB) | 0.0287 | 0.1112 |
| ✓ (GPB+LPB) | **0.0261** | **0.1108** |

消融实验显示，引入全局提示块（GPB）使KLD从0.6182降至0.0287，降幅显著，表明全局噪声统计（如ISO）是噪声分布的主要决定因素。进一步加入局部提示块（LPB）后，KLD微降至0.0261，AKLD微降至0.1108，边际收益递减，说明在捕捉全局属性后，局部空间相关性的补充作用有限。这一发现暗示，对于大多数消费级相机，全局增益参数可能比局部ISP非线性变换对噪声分布的影响更大，但LPB在特定相机型号上可能仍有不可替代的作用，论文未对此进行细分讨论。

评估指标涵盖KLD、AKLD、PSNR与SSIM，但未报告推理时间与参数量，无法评估其在边缘设备上的部署效率。代码未公开，超参数细节（如PAE与P-DiT的具体层数、通道数）仅在补充材料中提及，可复现性受限。此外，实验仅覆盖sRGB噪声，未涉及RAW域或混合噪声场景，评估边界局限于标准相机成像条件。

## 关联研究分析

从问题动机看，PNG与NAFlow均旨在解决元数据缺失问题，但NAFlow仅在推理阶段摆脱元数据依赖，训练阶段仍需元数据构建条件分布，而PNG通过提示特征实现了全阶段无元数据依赖。这一差异的根源在于NAFlow采用噪声感知采样算法，其本质是学习一个从噪声到元数据的映射，而PNG直接学习噪声分布的隐式表示，避免了元数据作为中间变量的信息损失。然而，PNG的提示特征提取依赖输入噪声图像的质量，若输入噪声严重失真或包含非噪声伪影，提示特征可能失效，而NAFlow的元数据条件在输入噪声质量差时仍能提供稳定的分布约束，这一鲁棒性差异论文未进行对比实验。

从方法设计看，PNG采用一致性模型（CM）作为生成骨干，区别于传统扩散模型的多步推理，这一选择旨在降低计算成本。然而，CM的单步生成特性可能导致生成噪声的多样性受限，难以覆盖真实噪声分布的长尾部分。相比之下，NAFlow基于归一化流，其确定性映射可能更好地保留噪声分布的细节，但推理速度较慢。PNG在SIDD上KLD优于NAFlow，表明CM在捕捉主流噪声分布上更有效，但在极端ISO或低光场景下，CM的生成质量是否仍能保持优势，论文未提供细分数据。此外，PNG的提示特征提取模块（GPB/LPB）设计较为轻量，未引入复杂的注意力机制，这可能限制了其对复杂ISP变换的建模能力，而NeCA-W等显式建模邻域相关性的方法在局部细节上可能更具优势，但PNG通过全局-局部解耦设计在整体分布匹配上取得了更好效果。

## 总结

本文核心矛盾在于真实世界噪声合成对相机元数据的依赖性与元数据在实际场景中缺失性之间的冲突。PNG通过从输入噪声图像提取全局与局部提示特征，替代显式元数据，实现了训练与推理阶段的双无元数据依赖。该方法在SIDD基准上取得0.0174 KLD与37.55 dB PSNR，验证了提示特征在噪声分布建模上的有效性。然而，其下游去噪性能受限于DnCNN回归式骨干，且未验证在极端低光或混合噪声场景下的泛化能力。当输入噪声图像包含非噪声伪影或严重失真时，提示特征的提取是否仍能准确反映真实噪声分布，论文未给出回答。
