# CVPR2026最新论文 ｜Mitigating Multimodal Hallucinations via Gradient-based Self-Reflection ｜基于梯度自反思的多模态幻觉缓解

研究机构：澳大利亚国立大学

作者：Shan Wang、Maying Shen、Nadine Chang 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.03113)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.03113)

> 多模态大语言模型（MLLMs）在生成文本时，常因过度依赖文本先验而忽略视觉证据，导致幻觉。现有推理时干预方法多采用全局或启发式权重，无法区分不同视觉特征对当前输出的具体贡献，导致共现偏差难以消除。本文提出GACD，通过一阶泰勒展开量化每个视觉与文本token的影响力，并据此动态调整解码权重，同时抑制虚假关联并增强视觉接地。该方法在免训练条件下显著降低了对象幻觉率，但其对长序列中注意力衰减的应对能力仍存疑。

## 研究背景

MLLMs的幻觉根源在于语言先验对视觉信号的覆盖。这种覆盖并非均匀分布，而是表现为两种具体偏差：文本-视觉偏差（Text-Visual Bias），即模型在长序列生成中逐渐忽视视觉输入，转而依赖提示词和先前输出；以及共现偏差（Co-occurrence Bias），即模型基于训练数据中物体频繁共现的统计规律，错误预测图像中不存在的物体。这两种偏差在解码过程中相互交织，导致模型在缺乏强视觉证据时仍生成流畅但错误的文本。

现有缓解方案主要分为训练时偏好对齐与推理时解码干预。训练时方法如DPO虽能纠正偏好，但可能加剧“视觉懒惰”，且训练成本高。推理时方法如视觉对比解码（VCD）通过对比有无视觉输入的logits来抑制幻觉，但其核心局限在于对所有视觉特征施加统一权重，缺乏对单个token贡献度的细粒度感知。这种粗粒度处理使得VCD无法有效区分与当前输出强相关的虚假视觉特征，导致共现偏差持续存在。本文的切入点在于引入基于梯度的token影响力估计，将全局对比转化为样本级、token级的动态调控，从而在免训练条件下同时解决两种偏差。

## 核心方法

### 方法参照系

GACD属于推理时解码干预路线，其基础框架继承自对比解码（Contrastive Decoding）。标准对比解码通过计算有视觉输入与无视觉输入（或仅文本输入）时的logits差值，来抑制语言先验主导的token。然而，标准流程假设所有视觉特征对幻觉的贡献是均等的，无法针对特定物体间的虚假关联进行精准抑制。GACD的关键差异在于引入了基于梯度的影响力量化机制，将静态的logits差值替换为动态的、基于token贡献度的加权调整。

### 基于泰勒展开的Token影响力估计

设计动机在于解决现有方法缺乏样本级偏差测量机制的问题，即无法量化特定视觉token对当前输出token的具体贡献。GACD利用一阶泰勒展开近似logits对输入token的敏感度。设第 $m$ 步的logits为 $\mathbf{z}_m^\star$，其对视觉token $\mathbf{t}_v$ 的梯度为 $\mathbf{g}_{ms}^v$。Token影响力定义为梯度向量的曼哈顿范数：

$$ I_{ms}^v = \|\mathbf{g}_{ms}^v\|_1 = \sum_{k=1}^{|V|} |\frac{\partial z_{mk}^\star}{\partial t_{vs}}| $$

该公式物理含义是：视觉token $s$ 对当前输出logits分布的扰动程度。通过计算所有视觉token、提示词token及先前输出token的影响力，模型能够识别出哪些视觉特征正在主导当前预测，从而定位偏差来源。

### 锚点特异性影响加权解码

设计动机在于解决共现偏差中特定物体对（如“椅子”与“桌子”）的虚假关联问题。GACD将视觉token分为与已提及名词相关的 $\mathbf{t}_o$ 和无关的 $\mathbf{t}_u$。对于名词预测步骤，构建负向引导logits $\mathbf{z}_m^o = \pi_{\theta^\star}(\mathbf{t}_o, \mathbf{t}_p, \mathbf{y}_{<m})$。调整后的logits $\hat{\mathbf{z}}_m$ 为：

$$ \hat{\mathbf{z}}_m = \mathbf{z}_m^\star + \alpha_m (\mathbf{z}_m^\star - \mathbf{z}_m^o) $$

其中 $\alpha_m$ 是动态权重，旨在使无关视觉token $\mathbf{t}_u$ 的影响力与主导文本影响力 $I_m^t = \max(I_m^p, I_m^y)$ 对齐。该机制通过增强与已提及物体无关的视觉特征，削弱虚假共现关联，同时通过 $\alpha_m$ 的动态调整防止过度抑制导致的语义断裂。

## 实验评估

实验在AMBER、MSCOCO和LLaVA-QA90数据集上进行，对比基线包括VCD、M3ID、AVISC及RLAIF-V。基线覆盖了图像级对比、token级对比及训练时对齐方法，但缺失LayerCD、SHIFT等2025-2026年基于层间信息流或最优传输的最新SOTA方法。

| 方法 | AMBER Score (LLaVA-v1.5) | POPE F1 (LLaVA-v1.5, Adv) | CHAIR CS (LLaVA-v1.5, MSCOCO) |
| :--- | :--- | :--- | :--- |
| Base | 72.0 | 80.9 | 48.8 |
| VCD | 76.7 | 81.6 | 44.8 |
| AVISC | 89.0 | 81.3 | 44.5 |
| GACD | 92.0 | 83.5 | 41.0 |

GACD在AMBER上得分92.0，较VCD提升15.3分；在POPE对抗设置下F1为83.5，较VCD提升1.9分；在MSCOCO CHAIR指标上，句子级幻觉率（CS）从48.8降至41.0。

| 组件 | CHAIR CS (LLaVA-v1.5) | CHAIR CI (LLaVA-v1.5) | Recall (LLaVA-v1.5) |
| :--- | :--- | :--- | :--- |
| Base | 48.8 | 13.4 | 78.6 |
| VA only | 46.4 | 11.6 | 79.0 |
| VA + CR | 46.2 | 11.3 | 79.4 |
| GACD (Full) | 41.0 | 10.9 | 77.3 |

消融实验显示，仅视觉增强（VA）将CS从48.8降至46.4，加入共现抑制（CR）后进一步降至46.2。完整GACD将CS降至41.0，但召回率（Recall）从79.4微降至77.3。这表明共现抑制组件对降低幻觉率贡献显著，但早期停止机制（ES）在极端情况下可能牺牲部分信息完整性。

评估边界方面，论文未报告推理延迟的具体毫秒数，仅提及计算开销增加约101.44%。代码未公开，超参数如 $\alpha_m$ 上限（判别任务5，生成任务3）和早停阈值（LLaVA-v1.5为7%）需手动设定。评估协议使用贪心采样，未探索束搜索或温度调整对结果的影响，这可能限制了模型在复杂推理中的探索能力。

## 关联研究分析

从方法设计看，GACD与VCD的核心差异在于干预粒度。VCD采用全局对比，假设所有视觉特征对幻觉的贡献均等，而GACD通过梯度量化实现了token级差异化调控。这一差异源于任务特性：共现偏差本质上是特定物体对之间的虚假关联，全局对比无法区分“椅子”相关的视觉特征与“桌子”相关的视觉特征，而GACD通过对象感知分组（Object-aware Visual Token Grouping）精准定位并抑制了这种特定关联。相比之下，LayerCD基于层间logits对比，关注的是模型内部层级结构的偏差，而非输入token的贡献度，两者在干预机制上存在根本不同。

从问题动机看，GACD与AVISC同属token级干预，但AVISC依赖外部分割模型来识别物体，引入了额外的误差源和计算开销。GACD通过梯度影响力估计内部识别物体相关token，无需外部监督，更具通用性。然而，GACD在非名词预测步骤中，所有视觉token被视为无关（$\mathbf{t}_o = \emptyset$），此时方法退化为全局视觉增强。这种设计是否会导致非名词步骤的视觉接地能力被削弱，论文未给出明确回答。此外，GACD的梯度计算依赖于一阶泰勒展开，对于高度非线性的深层网络，这种线性近似是否足以捕捉复杂的模态交互，仍是一个值得探讨的问题。

## 总结

本文旨在解决MLLMs中语言先验对视觉证据的覆盖失衡问题，特别是文本-视觉偏差与共现偏差的交织效应。现有方法因缺乏细粒度的token贡献度量化，无法精准抑制虚假关联。GACD通过一阶泰勒展开量化token影响力，并据此动态调整解码权重，实现了样本级的偏差校正。实验表明，GACD在AMBER上得分92.0，在POPE对抗设置下F1为83.5，显著优于VCD等基线。然而，论文实验仅覆盖短序列生成，未验证其在长思维链（CoT）中视觉注意力衰减场景下的有效性。当生成序列长度超过256个token时，梯度影响力估计是否仍能准确捕捉视觉接地的动态变化，论文未给出回答。
