# CVPR2026最新论文 ｜MUST: Modality-Specific Representation-Aware Transformer for Diffusion-Enhanced Survival Prediction with Missing Modality ｜模态特异性表征感知Transformer

研究机构：韩国延世大学、韩国科学技术研究院

作者：Kyungwon Kim、Dosik Hwang

论文原文见 [arXiv](https://arxiv.org/abs/2603.26071)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.26071)

> 多模态生存预测在临床落地时面临模态缺失导致的性能崩塌，现有对齐或插补方法无法区分哪些信息是模态独有的、哪些是跨模态可推断的。MUST通过低秩子空间内的代数约束，将表征显式分解为共享与特异性组件，仅对特异性部分使用潜扩散模型生成。该方法在五个TCGA数据集上实现了完整数据下的SOTA性能，并在缺失模态时保持了可接受的预测精度，但其代数可逆性假设是否适用于高维复杂交互尚存疑。

## 研究背景

临床生存预测依赖全切片图像（WSI）与基因组数据的联合建模，但基因组检测成本高且历史队列常缺乏分子数据，导致模型在部分模态缺失时失效。解决此问题的关键概念是“模态特异性信息”与“跨模态共享信息”的解耦：前者指仅存在于单一模态、无法从其他模态推断的特征（如特定形态学纹理），后者指模态间共有的生物学信号（如肿瘤增殖状态）。若无法显式区分二者，模型在缺失某一模态时，既无法准确恢复共享信息，也无法合理生成特异性信息，导致预测偏差。

多模态融合的主流路线包括特征对齐、插补和联合分布学习。特征对齐方法（如SMIL）强制不同模态组合下的输出相似，但未建模缺失信息的语义结构；插补方法（如LD-CVAE）通过生成模型合成缺失特征，但在高维空间中产生噪声伪特征，且无法解耦模态贡献；联合分布学习方法捕捉模态交互，但缺乏对“什么是模态独有”的显式约束。MUST的切入点在于引入“代数可逆性”：通过低秩共享子空间内的正交约束，确保共享组件可从任意可用模态确定性恢复，从而将随机生成限制在真正的模态特异性残差上。

## 核心方法

### 方法参照系

多模态生存预测的标准流程为：模态特征提取 → 跨模态交互建模 → 融合预测。本文问题与该通用流程的关键差异在于：标准流程假设模态完整，而MUST需处理模态缺失，因此必须在交互建模阶段引入代数分解机制，以支持缺失模态的确定性恢复与概率生成。

### 低秩子空间代数分解

设计动机：传统交叉注意力方法（如CMTA）缺乏缺失模态机制，无法区分共享与特异性信息，导致模态坍缩。MUST在跨模态交互后引入低秩投影矩阵 $P_{\cap}$，将共享信息约束在秩 $r \ll D$ 的子空间内，并施加三重约束：共享一致性（$\hat{c}_{P \leftarrow G} = \hat{c}_{G \leftarrow P}$）、模态间正交性（$\hat{u}_P \perp \hat{u}_G$）和模态内正交性（$\hat{u}_m \perp \hat{c}_m$）。该分解确保全局表征 $g_m = \hat{u}_m + \hat{c}_m$ 可代数逆解，即当某模态缺失时，共享组件 $\hat{c}_m$ 可从另一模态的 $g_m$ 和 $\hat{u}_m$ 确定性计算得出。

### 条件潜扩散生成

设计动机：代数分解仅能恢复共享信息，模态特异性组件 $\hat{u}_m$ 无法从其他模态推断，需概率生成。MUST在主网络收敛后冻结参数，训练条件潜扩散模型（LDM），以共享组件 $\hat{c}_m$ 和结构先验类令牌 $[\text{CLS}_{u_m}]$ 为条件，生成缺失的 $\hat{u}_m$。前向过程逐步添加高斯噪声，反向过程学习去噪，训练目标最小化 $\mathbb{E}_{z_0, \epsilon, t} \|\epsilon - \epsilon_\theta(z_t, t, \text{cond})\|^2$，其中 $\text{cond} = [\hat{c}; [\text{CLS}_u]]$。该策略将随机性隔离在特异性残差上，避免对共享信息的冗余重建。

## 实验评估

实验在五个TCGA数据集（BLCA, BRCA, GBMLGG, LUAD, UCEC）上进行，使用20× WSI和RNA-Seq/CNV/SNV数据，评估整体生存。基线覆盖单模态（ABMIL, TransMIL, MLP, SNN）、多模态完整数据（SurvPath, CMTA）及缺失模态处理（SMIL, M3Care, ShaSpec, LD-CVAE），但未包含知识库中提到的自适应融合策略（如AdaFuse）。MUST在完整数据下取得0.742的C-index，优于CMTA（0.724）2.5%；缺失基因组时C-index为0.716（下降3.5%），优于LD-CVAE（0.697）；缺失病理时C-index为0.739（下降0.4%），LD-CVAE因单向架构无法处理此场景。

| 方法 | 完整数据 C-index | 缺失基因组 C-index | 缺失病理 C-index |
| :--- | :--- | :--- | :--- |
| MUST | 0.742 | 0.716 | 0.739 |
| CMTA | 0.724 | - | - |
| LD-CVAE | 0.697 | 0.697 | - |
| ShaSpec | 0.676 | 0.676 | 0.676 |

消融实验显示，渐进训练策略（Stage 1噪声注入 + Stage 2代数分解）在BLCA、BRCA、GBMLGG、UCEC上均优于无预热版本，LUAD上略低（0.686 vs 0.690），表明噪声注入对结构化基因组特征的平滑效应可能衰减功能变异。LDM条件策略中，包含结构先验类令牌 $[\text{CLS}_u]$ 比仅用共享组件 $\hat{c}$ 提升0.8-1.5% C-index，验证了结构先验对特征分布精度的贡献。

评估边界：指标仅报告C-index，未提供置信区间或计算效率细节（除推理延迟外）；缺失模态评估通过人工诱导实现，未模拟真实临床缺失模式；代码未公开，但项目页面提供URL。

## 关联研究分析

从问题动机看，MUST与ShaSpec同属“共享/特异性分离”路线，但ShaSpec依赖头蒸馏匹配后验分布，缺乏代数结构，导致缺失基因组时性能下降4.7%（vs MUST的3.5%）。MUST的代数可逆性提供了确定性恢复路径，这是ShaSpec不具备的。从方法设计看，MUST与CMTA均使用交叉注意力，但CMTA缺乏分解机制，无法处理缺失模态；MUST的分解不仅用于缺失处理，还作为结构正则化，在完整数据下提升性能，这与CMTA的纯融合目标不同。MUST未与PS3/TTA等基于原型或最优传输的方法直接对比，其代数分解是否优于生物结构引导的可解释性路径，论文未给出回答。

## 总结

MUST解决的核心矛盾是模态缺失下的信息恢复与生成边界模糊。其切入点是代数可逆性：通过低秩子空间正交约束，确保共享信息确定性恢复，特异性信息概率生成。实验证明该方法在五个TCGA数据集上实现完整数据SOTA（C-index 0.742）和缺失模态鲁棒性（0.716/0.739）。边界在于：代数分解的低秩假设可能限制高维复杂交互捕捉，且LDM生成病理特征时的平滑效应可能衰减功能变异。当基因组数据包含更多非结构化变异时，代数可逆性是否仍能保持分解保真度，论文未给出回答。
