研究机构：上海交通大学

论文原文见 [arXiv](https://arxiv.org/abs/2602.22286)

> 导读 多模态数据在存储与传输中面临异构性挑战，现有学习式压缩器多为单模态设计，导致系统冗余且难以统一。基于大语言模型的方案虽能跨模态但计算开销巨大，无法在边缘设备部署。OmniZip 通过轻量级 RWKV 骨干结合模态路由机制，实现了比特精确重构与高效推理的平衡。该方法在保持低参数量的同时，在多种模态上达到或超越现有 SOTA，但其统一 Token 化策略对空间局部性的建模能力仍存疑。

## 研究背景

无损压缩的核心在于利用概率模型估计数据似然，并通过熵编码逼近香农熵界。对于多模态数据，不同模态的统计特性差异显著：文本是离散序列，图像具有二维空间相关性，语音则是连续频谱信号。这种异构性使得单一概率模型难以同时捕捉各模态的依赖结构，传统通用压缩器（如 gzip）因缺乏领域先验，在特定模态上效率低下。

主流学习式压缩路线分为两类：一是基于大语言模型（LLM）的方法，如利用 LLaMA3 进行概率预测，虽能处理多模态但参数量达数十亿，压缩单张 1080p 图像需 30 分钟以上，严重制约实时应用；二是单模态专用模型，如针对图像的 DLPR 或针对文本的 NNCP，虽效率高但无法跨模态复用，导致多模态系统需部署多个独立压缩器，增加软件复杂度与硬件成本。现有研究缺乏一种既能统一处理异构模态，又能在资源受限设备上实现近实时推理的轻量级架构。

## 核心方法

### 方法参照系

本文问题属于基于概率预测的无损压缩范畴，标准流程为“Token 化 -> 概率预测 -> 算术编码”。与单模态压缩器不同，本文需解决异构数据映射至统一 Token 空间的逆映射问题，以及单一模型对多模态上下文依赖的差异化建模问题。

### 模态统一 Token 化

针对多模态数据格式不一的问题，本文设计了可逆的统一 Token 化策略。文本类数据使用 SentencePiece BPE 分词，并显式添加基因碱基（A,T,G,C）和数据库关键词以增强领域适应性；图像类数据被划分为 $16 \times 16 \times 3$ 的块，像素按光栅扫描顺序展开为 RGB 子像素序列，每个子像素映射为 256 维词表中的一个 Token；语音数据直接读取原始字节流，每个字节作为一个 Token。所有模态序列前置特定模态前缀（如 `<image>`），并在 softmax 前应用模态掩码，将非目标模态的概率置零，从而消除跨模态估计误差。

$$
p(x_i | x_{<i}, m) = \frac{\exp(z_i \cdot \mathbb{I}[m_i = m])}{\sum_{j} \exp(z_j \cdot \mathbb{I}[m_j = m])}
$$

该公式表明，通过模态掩码 $\mathbb{I}$ 限制概率分布仅在当前模态词表内归一化，避免了不同模态 Token 空间重叠导致的概率泄漏。

### 模态路由上下文学习

RWKV 骨干中的 Time Mixing 模块通过 R/K/V 投影建模上下文。本文发现 V 层代表具体记忆内容，其多样性对多模态处理至关重要，因此仅在 V 层引入混合专家（MoE）机制。可学习路由器为每个 Token 计算专家得分，选取 Top-$k$ 专家进行加权求和。

$$
y_i = \sum_{e \in \text{Top-}k(g_i)} \hat{g}_{i,e} \cdot V_e(x_i)
$$

其中 $g_{i,e} = \text{softmax}(W_g x_i)_e$ 为路由得分，$\hat{g}_{i,e}$ 为归一化权重。此设计以极小的参数开销（仅增加 3 个 V 层）实现了上下文建模的模态自适应，解决了通用 MLP 无法区分不同模态上下文依赖的问题。

### 模态路由前馈过程

为增强非线性表示能力，本文将 RWKV 中的标准 MLP 替换为 MoE 前馈模块。每个专家为小型 MLP，隐藏层因子为 2，专家数为 4，Top-$k=2$。这种配置使得每 Token 激活参数量与原 MLP 相当，但通过路由机制获得了更高的表示灵活性，进一步提升了多模态特征的非线性拟合能力。

## 实验评估

实验在 16 个数据集、7 种模态上进行，基线涵盖经典压缩器（gzip, bzip2, zstd, FLAC）、单模态学习式压缩器（NNCP, CMIX, DLPR）及 LLM 基方法（Llama3-based）。

| 数据集 | 模态 | OmniZip-L (bits/Byte) | 最佳基线 (bits/Byte) | 基线名称 |
| :--- | :--- | :--- | :--- | :--- |
| Kodak | 自然图像 | 2.925 | 2.860 | DLPR |
| TouchandGo | 触觉 | 0.987 | 1.082 | DLPR |
| Coronal | 医学图像 | 3.837 | 3.800 | DLPR |
| enwik9 | 文本 | 0.980 | 0.853 | NNCP |
| LibriSpeech | 语音 | 3.810 | 3.589 | RWKV-based |
| WikiSQL | 数据库 | 0.787 | 0.629 | CMIX |

OmniZip-L 在触觉和医学图像上显著优于专用图像压缩器，但在自然文本和数据库上略逊于单模态 SOTA（NNCP, CMIX）。消融实验显示，移除模态统一 Token 化导致性能大幅下降，验证了统一空间的重要性；而 MoE 路由在 V 层的引入比在 R/K 层更有效，证实了记忆内容多样性的关键作用。

评估边界方面，论文未报告置信区间，且部分基线结果由作者复现。代码已开源，训练使用 A100 GPU，推理速度在 MacBook CPU 和 iPhone NPU 上均达到近实时水平（0.1-1 MB/s）。

## 关联研究分析

从问题动机看，本文与 LLM-based 压缩器（如 Deletang et al.）形成鲜明对比。后者将所有模态转为 ASCII 文本，忽略了非文本模态的空间或频谱结构，导致性能次优。本文通过原生多模态 Token 化和路由机制，直接建模各模态的统计特性，避免了模态转换带来的信息损失。这一差异源于对“统一性”的不同理解：LLM 路线追求语义空间的统一，而本文追求比特流空间的统一。

从方法设计看，本文与单模态 SOTA（如 NNCP, CMIX）相比，牺牲了部分压缩率以换取跨模态通用性。NNCP 在 enwik9 上达到 0.853 bits/Byte，优于 OmniZip-L 的 0.980，但 NNCP 无法处理图像或语音。本文的 MoE 路由机制在参数效率上优于 LLM 路线，但相比单模态专用模型，其路由开销和统一 Token 化的局限性限制了其在单一模态上的极致性能。这种取舍反映了通用性与专用性之间的根本矛盾。

## 总结

OmniZip 旨在解决多模态无损压缩中“统一性”与“轻量级”的矛盾。现有 LLM 方案因参数量过大无法边缘部署，单模态方案则缺乏通用性。本文通过 RWKV 骨干结合模态路由 MoE，在 152M 参数下实现了跨 7 种模态的高效压缩。实验表明，其在触觉和医学图像上超越专用 SOTA，在文本和语音上接近 SOTA 水平，且推理速度满足实时需求。然而，其在自然文本和数据库上的性能仍低于单模态最优方法，且统一 Token 化对图像空间局部性的建模能力未得到充分验证。当支持集增大或模态分布发生偏移时，路由机制的泛化能力是否依然稳健，论文未给出回答。
