# CVPR2026最新论文 ｜Reconstructing CLIP for Open-Vocabulary Dense Perception ｜重构 CLIP 密集表示以对齐全局语义

研究机构：北京航空航天大学

作者：Yajie Liu、Jinjin Zhang、Qingjie Liu 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_681a680cf946)

> 开放词汇密集感知（OVDP）要求模型在像素或区域级别识别任意视觉概念，但 CLIP 的全局 [CLS] 特征缺乏空间细节，导致密集预测性能受限。现有自蒸馏方法通过空间聚合构建密集特征，却引入了无关语义噪声与对齐误差。本文切入点在于揭示 [CLS] token 的语义本质编码于多层 Value 嵌入中，并证明空间聚合会放大对齐误差。通过设计头选择性门控（HSG）模块替代空间聚合，并引入视觉基础模型特征一致性蒸馏，DenseRC 实现了与全局语义结构一致的密集表示。该方法在多个 OVDP 基准上刷新了 SOTA，但其对 VFM 辅助蒸馏的依赖是否破坏 CLIP 原生几何一致性，仍存疑。

## 研究背景

CLIP 通过对比学习在共享嵌入空间对齐视觉与文本特征，其 [CLS] token 作为全局语义载体，是零样本分类的核心。然而，当任务转向开放词汇密集感知（OVDP）时，[CLS] token 缺乏空间细节的缺陷暴露无遗：它无法直接提供像素级的语义定位。为弥补这一缺陷，研究者尝试将全局语义迁移至密集特征。自蒸馏范式成为主流选择，它利用冻结的 CLIP 作为教师，通过裁剪图像获取区域级 [CLS] 特征，监督可训练学生模型的密集特征。这一过程旨在不引入昂贵区域标注的前提下，将全局泛化能力注入局部表示。

主流自蒸馏方法如 CLIPSelf 和 DeCLIP 均面临密集特征构建的结构性瓶颈。CLIPSelf 直接使用 CLIP 的最终空间输出，但残差连接不可避免地注入噪声；DeCLIP 通过自注意力聚合增强 patch 语义，却因混合无关 patch 导致语义间隙。更深层的问题在于，这些方法未厘清 [CLS] token 内部语义的编码机制，盲目沿用标准多头自注意力（MHSA）的空间聚合逻辑。本文指出，空间聚合在密集特征构建中并非必要，反而因融合无关语义而增加对齐误差。基于此，DenseRC 提出从 Value 嵌入出发，解耦空间与头维度，以头选择性门控替代空间聚合，从根源上解决密集特征与全局语义的结构不一致问题。

## 核心方法

### 方法参照系

自蒸馏框架通常将学生模型的密集特征 $X_{dense}$ 与教师模型从裁剪图像中提取的 [CLS] token $c$ 进行对齐，损失函数定义为 $L_{semantics}(RoIAlign(X_{dense}, b), c)$。本文的关键差异在于，不再假设标准 MHSA 的空间聚合能产生与 [CLS] token 结构一致的密集特征，而是重新审视 [CLS] token 的语义来源，并据此重构密集特征的构建路径。

### 基于 Value 嵌入的语义基础

设计动机在于解决现有方法中密集特征与 [CLS] token 语义不一致的问题。分析表明，[CLS] token 的语义并非来自最终的空间输出，而是编码于多层 Value 嵌入中。在 CLIP 视觉 Transformer 中，[CLS] token 在第 $l$ 层通过自注意力更新，其信息流可表示为：

$$ c^{(l)} \leftarrow c^{(l-1)} + A^{(l)}v^{(l)} $$

其中 $v^{(l)}$ 为 Value 嵌入，$A^{(l)}$ 吸收注意力权重与投影参数。展开所有层后，[CLS] token 本质上是多层 Value 嵌入的加权聚合。DenseRC 据此设计学生模型的密集特征 $X_{dense}$，使其结构对齐这一聚合形式：

$$ X_{dense} = \sum_{l=1}^{L} A_p^{(l)} \cdot v_p^{(l)} $$

这一设计确保了密集特征在语义基础上与 [CLS] token 同源，从源头消除了因特征来源不同导致的一致性偏差。

### 头选择性门控（HSG）

设计动机在于克服空间聚合引入的无关语义噪声。理论分析表明，空间聚合 $\tilde{v}_r^{(S)} = \sum_{j=1}^{N} S_{rj}Pv_j$ 会引入干扰项 $\Delta L$，当聚合权重分配给无关 patch 时，对齐误差严格大于仅头维度建模 $L^{(H)}$。实验进一步证实，空间聚合导致梯度分布不均，平均梯度幅度仅为 0.26，而头维度建模可达 0.7。DenseRC 提出 HSG 模块，仅沿头维度进行自适应重加权：

$$ A_p = \sigma(W_H(LN(x))) \in \mathbb{R}^{N \times H} $$

其中 $W_H$ 为共享的头投影矩阵，$\sigma$ 为 Sigmoid 函数。HSG 根据每个注意力头在跨模态语义贡献与局部性偏好上的异质性，动态调整头权重。这一机制避免了空间混合带来的语义污染，同时通过均匀梯度分布提供更稳定的密集监督信号，显著提升了密集特征的判别性与对齐友好性。

## 实验评估

实验在 COCO train2017 上进行，输入图像缩放至 1024×1024，使用 4 块 NVIDIA A100 GPU 训练 6 个 epoch。基线覆盖 CLIPSelf 和 DeCLIP 等自蒸馏方法，但缺失 FGCLIP 等区域监督方法的直接对比，可能高估自蒸馏路线的相对优势。

| 任务 | 方法 | 指标 | 数值 |
| :--- | :--- | :--- | :--- |
| COCO 开放词汇检测 | DenseRC | mAP | 15.9% |
| COCO 开放词汇检测 | DenseCLIP | mAP | 15.2% |
| COCO 开放词汇检测 | CLIP | mAP | 14.7% |

DenseRC 在 COCO 开放词汇检测上以 0.7 个点的优势领先于 DenseCLIP，较经典 CLIP 提升 1.2 个点，验证了 HSG 模块在密集预测任务上的有效性。

消融实验聚焦于 Value 嵌入层数的选择。论文指出，提取最后三层 Transformer 的 Value 嵌入能产生最稳定且准确的对齐，但未提供不同层数（如最后两层、最后四层）的具体性能对比数据，仅以“经验上”作为依据。这一决策的敏感性分析缺失，使得 Value 嵌入层数选择的鲁棒性存疑。此外，损失平衡系数 $\lambda=0.025$ 的设定也未进行网格搜索验证，其最优性缺乏充分证据。

评估边界方面，论文未报告 COCO 图像-文本检索指标（如 Recall@5），仅聚焦密集预测任务，这限制了对其跨任务泛化能力的全面评估。可复现性上，论文提供了详细的超参数（学习率 $1 \times 10^{-5}$，权重衰减 0.1，$\lambda=0.025$）和硬件配置，但未公开代码仓库，且未报告置信区间，数值比较需谨慎。

## 关联研究分析

从方法设计看，DenseRC 与 DeCLIP 的核心差异在于对空间聚合的处理。DeCLIP 解耦注意力与 Value 流，但仍保留空间聚合以增强局部判别性，这导致无关 patch 的语义污染。DenseRC 则彻底放弃空间聚合，转而依赖头维度的异质性建模。这一差异的根源在于对 [CLS] token 语义编码机制的不同理解：DeCLIP 假设空间聚合有助于局部语义增强，而 DenseRC 证明空间聚合在密集对齐中是有害的。然而，DenseRC 引入 DINOv2 进行特征一致性蒸馏，这与 DeCLIP 的纯 CLIP 自蒸馏范式不同。引入外部 VFM 是否破坏了 CLIP 嵌入空间的几何一致性，论文未给出回答。

从问题动机看，DenseRC 与 FGCLIP 等区域监督方法形成对比。FGCLIP 通过 40M 区域-文本对进行重训练，直接解决细粒度对齐问题，但数据成本高昂。DenseRC 采用无监督自蒸馏，避免了数据标注需求，但其性能提升依赖于 HSG 模块对头异质性的精准建模。在数据充足且标注质量高的场景下，区域监督方法可能提供更直接的语义对齐信号，而 DenseRC 的优势在于可扩展性与零样本泛化保持。DenseRC 未探索在少量区域标注辅助下 HSG 模块的性能增益，这一盲区限制了其在半监督场景下的适用性评估。

## 总结

DenseRC 针对 CLIP 在 OVDP 中全局与局部表示的权衡矛盾，抓住了 [CLS] token 语义编码于 Value 嵌入这一被忽略的内部机制。通过证明空间聚合的对齐误差放大效应，并设计 HSG 模块进行头维度自适应重加权，DenseRC 构建了与全局语义结构一致的密集表示。实验表明，该方法在 COCO 开放词汇检测上取得 15.9% mAP，较 DeCLIP 提升 0.7 个点。然而，论文未报告检索任务指标，且 Value 嵌入层数选择缺乏消融验证，暴露了其在跨任务泛化与超参数鲁棒性上的边界。当支持集增大或引入少量区域标注时，HSG 模块的边际收益是否递减，论文未给出回答。
