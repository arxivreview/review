> 导读 遥感视觉语言模型（RS-VLMs）面临的核心矛盾是通用基础模型在俯视视角下的域差距与全量微调高昂计算成本之间的冲突。现有参数高效微调（PEFT）方法因文本标签语义贫乏与视觉编码器刚性，难以捕捉遥感图像中同一类别的多样外观。AVION 通过离线教师模型生成经视觉验证的语义丰富文本原型，并采用三视角对齐蒸馏至轻量学生模型，以极小参数更新实现高效适配。该框架在少样本分类与新类泛化上超越了主流 PEFT 基线，但其性能增益是否完全归因于蒸馏机制而非教师模型规模，仍需更严格的控制变量实验验证。

## 研究背景

当通用视觉语言模型（VLMs）直接应用于遥感图像时，俯视视角导致的尺度差异与纹理异质性使得自然图像预训练的视觉特征失效。为降低适配成本，参数高效微调（PEFT）通过冻结骨干网络、仅更新少量可学习参数成为主流方案。然而，PEFT 通常依赖简单的类别名称作为文本监督信号，这种单一标签无法描述遥感场景中同一类别因季节、传感器或分辨率不同而产生的巨大视觉方差，导致模型在新类别上泛化能力受限。

领域内已达成共识，即通用 VLM 必须经过领域特定适配以弥合域差距，且仅依赖监督微调不足以实现复杂推理。主流 PEFT 路线如 CoOp 和 MaPLe 主要优化文本侧提示词，忽视了视觉侧对遥感特有几何模式（如斜视、多尺度上下文）的适应性需求。这种“文本侧优化、视觉侧冻结”的设计使得模型无法有效对齐多样化的视觉外观与单一标签，形成了语义覆盖不足与视觉特征僵化的双重瓶颈。AVION 的切入点在于同时解决文本语义贫乏与视觉刚性问题，通过引入外部大语言模型（LLM）知识增强文本原型，并在视觉与文本两侧同时注入可学习提示，以蒸馏方式将教师模型的丰富表征迁移至轻量学生模型。

## 核心方法

### 方法参照系

标准 PEFT 流程通常冻结 VLM 骨干，仅优化文本侧上下文向量或视觉侧轻量适配器，以最小化训练参数。本文问题与该通用流程的关键差异在于：遥感数据的视觉方差远超自然图像，单一类别名称无法提供足够的语义约束，且冻结视觉编码器导致模型无法适应俯视视角下的尺度变化，因此需要同时增强文本语义丰富度与视觉特征适应性。

### 语义丰富文本原型构建

针对 PEFT 中类别名称语义贫乏导致的新类泛化失败，AVION 在教师模型端引入 LLM 生成机制。设计动机是解决简单模板（如 "a photo of [CLASS]"）无法描述遥感多模态外观的问题。对于每个类别 $k$，LLM 生成多个候选描述，并通过教师模型的视觉嵌入 $\mathbf{v}_k^{[T]}$ 进行验证。具体地，计算每个候选文本嵌入 $\mathbf{t}_{k,j}^{[T]}$ 与视觉原型的余弦相似度 $s_{k,j} = (\mathbf{v}_k^{[T]})^\top \mathbf{t}_{k,j}^{[T]}$，利用中位数/MAD 鲁棒 z-score 剔除离群候选，最终通过加权聚合得到文本原型 $\mathbf{t}_k^{[T]*}$。这一过程相当于无参数交叉注意力，视觉原型作为查询，文本候选作为键值，确保生成的原型既语义丰富又与目标域视觉特征对齐。

### 三视角对齐蒸馏

在文本原型构建后，AVION 通过三视角对齐将教师知识蒸馏至学生模型。设计动机是单一任务损失（交叉熵）仅利用 one-hot 标签，丢失了类间关系信息，且未显式约束视觉与文本嵌入的对齐结构。总损失函数为：

$$ \mathcal{L} = \mathcal{L}_{task} + \lambda_{img}\mathcal{L}_{img} + \lambda_{text}\mathcal{L}_{text} + \lambda_{logit}\mathcal{L}_{logit} $$

其中 $\mathcal{L}_{img}$ 最小化学生视觉嵌入 $\mathbf{v}_i^{[S]}$ 与教师 $\mathbf{v}_i^{[T]}$ 的余弦距离，解决视觉刚性；$\mathcal{L}_{text}$ 对齐学生文本嵌入 $\mathbf{t}_k^{[S]}$ 与教师原型 $\mathbf{t}_k^{[T]*}$，解决语义贫乏；$\mathcal{L}_{logit}$ 通过温度缩放的 KL 散度匹配教师与学生在全类别上的相似度分布，捕获隐式类间关系。这种多目标优化确保学生模型在极少参数更新下，同时获得视觉适应性、文本语义丰富度及跨模态对齐结构。

## 实验评估

| 方法 | 1-shot (%) | 8-shot (%) | 16-shot (%) |
| :--- | :--- | :--- | :--- |
| GeoRSCLIP (Zero-shot) | 72.95 | - | - |
| APPLeNet | 74.27 | 89.20 | 91.61 |
| AVION | 74.27 | 91.85 | 93.69 |

实验在 AID、RESISC-45 等 6 个基准上进行，基线覆盖 CoOp、MaPLe 等主流 PEFT 方法及 GeoRSCLIP 零样本模型。AVION 在 1-shot 下与 APPLeNet 持平（74.27%），但在 8-shot 和 16-shot 下分别领先 2.65 和 2.08 个百分点，表明随着样本增加，语义丰富原型与视觉提示的协同效应逐渐显现。

| 配置 | Base (%) | Novel (%) | HM (%) |
| :--- | :--- | :--- | :--- |
| B0 (CoOp-style) | 91.17 | 69.52 | 78.88 |
| B1 (+Deep Prompt) | 93.52 | 53.51 | 66.71 |
| B7 (Full AVION) | 95.64 | 79.94 | 87.05 |

消融实验揭示了关键设计决策的影响：仅引入深度提示（B1）导致新类性能大幅下降 16.01 个百分点，证实了视觉侧优化若无文本侧语义引导会加剧过拟合。引入 LLM 生成原型（B4）相比手动模板（B3）提升新类准确率 5.45 个百分点，验证了语义丰富度的必要性。最终完整模型（B7）在保持高基类准确率（95.64%）的同时，将新类准确率提升至 79.94%，调和均值（HM）达 87.05%，显著优于所有基线。

评估协议采用标准少样本分类与 Base-to-Novel 泛化设置，但未报告推理延迟与内存占用，限制了其在实际部署场景中的效率评估。代码已公开，超参数在 AID 验证集上选定后固定，确保了跨数据集的可复现性。然而，教师模型（ViT-H/14）与学生模型（ViT-B/32）的规模差异可能混淆了蒸馏增益与模型容量增益，缺乏同规模教师-学生对照实验。

## 关联研究分析

从问题动机看，AVION 与 RSThinker 等推理增强路线存在根本差异。RSThinker 通过思维链（CoT）和强化学习提升复杂空间逻辑推理能力，牺牲推理速度换取可解释性；而 AVION 聚焦于感知层面的域差距适配，通过静态蒸馏提升少样本分类精度，不涉及动态推理过程。这种差异源于任务目标不同：前者解决“看得准不准”的逻辑问题，后者解决“能不能看懂”的表征问题。AVION 未探索推理增强，表明其在复杂空间关系理解上可能存在局限，但其在轻量适配场景下的效率优势是推理增强方法所不具备的。

从方法设计看，AVION 与 GeoVista 等主动感知框架形成互补。GeoVista 通过动态缩放和多跳探索解决超高分辨率（UHR）图像的证据稀疏问题，依赖在线工具调用；AVION 则通过离线预计算文本原型和静态提示注入解决多尺度视觉方差问题，无需在线交互。两者均针对遥感图像的多尺度特性，但 GeoVista 关注空间分辨率的动态获取，AVION 关注语义与视觉特征的静态对齐。AVION 的离线蒸馏策略在计算资源受限的边缘部署场景中更具优势，但其静态原型无法适应查询时动态变化的视觉上下文，这在 UHR 场景中可能成为瓶颈。

## 总结

AVION 旨在解决遥感 VLM 适配中语义贫乏与视觉刚性导致的泛化失效问题。其切入点在于利用 LLM 生成经视觉验证的文本原型，并通过三视角对齐蒸馏，将教师模型的丰富表征迁移至轻量学生模型，从而在极少参数更新下实现高效适配。实验表明，AVION 在 16-shot 分类中达到 93.69% 准确率，Base-to-Novel 调和均值达 87.05%，显著优于主流 PEFT 基线。然而，其性能增益中教师模型规模贡献与蒸馏机制贡献的相对比例未得到严格分离，且缺乏与同规模教师-学生对照的实验。当教师模型与学生模型规模差异缩小至一定程度时，三视角对齐蒸馏的边际收益是否仍显著高于直接微调，论文未给出回答。
