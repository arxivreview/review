# CVPR2026最新论文 ｜ReFAct: Empowering Multimodal Web Agents with Visual and Context Focusing ｜多模态网络搜索代理的主动上下文聚焦

作者：Rui Wu、Shuo Zhang、Xiaoxuan Tang 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_7dfb931cee15)

> 多模态网络搜索代理在处理复杂查询时，常因图像背景噪声与网页冗余信息导致注意力稀释，进而建立错误的事实基础。现有代理多采用被动感知机制，将整张图像或整个网页编码为视觉令牌，无法区分核心证据与背景噪声，导致检索偏离。本文提出 ReFAct 框架，通过引入主动视觉定位工具与外部记忆管理操作，使代理能够动态裁剪关注区域并选择性保留关键信息。该框架在自建高噪声基准上显著优于现有强化学习代理，但其性能提升是否源于特定数据分布的过拟合，尚需跨域验证。

## 研究背景

当多模态大语言模型（MLLMs）处理包含复杂背景的真实场景图像时，无关细节会干扰注意力机制，导致模型将焦点从目标实体转移至背景噪声。这种注意力稀释现象在被动感知机制下尤为严重，因为模型将整张图像编码为视觉令牌，无法区分任务相关区域与无关区域。为应对动态信息需求，网络搜索代理通过迭代推理与检索获取外部知识，但现有代理仍继承 MLLMs 的被动感知局限，直接处理原始截图或完整搜索结果页，导致视觉噪声与检索噪声共同污染上下文。

多模态网络搜索代理旨在融合文本与视觉信息，通过迭代检索解决复杂用户查询。Search-R1 与 DeepResearcher 等文本中心代理确立了“推理-行动”循环范式，而 MMSearch-R1 与 WebWatcher 将其扩展至多模态场景，赋予代理图像搜索与网页访问能力。然而，这些方法在处理高噪声环境时，因缺乏主动上下文管理能力，易被无关信息误导，建立“虚假事实基础”。本文切入点在于赋予代理主动聚焦能力，使其能动态调整视觉注意力与记忆负载，从而在噪声环境中保持推理焦点。

## 核心方法

### 主动聚焦框架

ReFAct 将代理与多模态网络环境的交互形式化为序贯决策过程，扩展传统动作空间以包含主动管理视觉注意力与工作记忆的操作。与标准代理被动累积所有观测值不同，ReFAct 通过显式聚焦动作主动策划上下文，确保每个外部动作基于去噪后的输入。该框架统一了推理、聚焦与行动循环，使代理能在每轮生成思考后自主决定下一步动作，无缝交织标准网络动作与内部聚焦操作。

### 视觉聚焦机制

为对抗复杂背景导致的视觉噪声，ReFAct 引入主动定位机制，使代理能显式选择高相关区域而非被动使用整张图像。在执行基于图像的搜索前，代理生成定位动作 $Ground(I_t, bbox)$，其中 $bbox = [x_1, y_1, x_2, y_2]$ 指定目标裁剪坐标，环境随后使用该裁剪区域 $I_t[bbox]$ 作为精确查询。这一设计避免了第三方检测模型引入的外部偏差，使定位能力与代理推理过程在训练期间联合优化，解决了被动感知下全局图像搜索返回无关结果的问题。

### 记忆聚焦机制

为管理杂乱网页带来的检索噪声并防止长程上下文耗尽，ReFAct 实现双记忆系统，区分有限的高价值主动工作记忆 $H_t$ 与无限的外部记忆 $M_t$。当遇到信息密集但当前非关键内容时，代理执行 Defocus 操作，将原始内容卸载至 $M_t$，仅在 $H_t$ 中保留简洁摘要与唯一参考 ID；当后续推理需要先前卸载的细节时，执行 Refocus(id) 操作，通过引用摘要中的 ID 从 $M_t$ 精确检索原始内容。该机制实现了工作记忆的灵活主动管理，避免了模糊检索的错误风险，解决了长程推理中上下文污染问题。

## 实验评估

实验在 GroundedVQA 基准上进行，该数据集包含 1,817 个复杂视觉问答数据点，其中 1,200 个 Level 1 和 300 个 Level 2 实例用于训练，261 个 Level 1 和 56 个 Level 2 实例用于评估。基线对比包括现有强化学习训练的多模态代理，但缺乏 CLIP、SigLIP 等经典嵌入基线，限制了与静态检索方法的直接比较。ReFAct-7B 模型通过 GRPO 算法训练，使用 Qwen2.5-VL-7B-Instruct 作为基础模型，训练集结合 GroundedVQA 训练集与 3,000 个 FVQA 随机样本，RL 阶段进行 2 个 epoch，学习率 2e-6，KL 系数 β = 0.01，λ = 0.1，组大小 G = 8，在 8×A100 GPU 上完成。

该论文实验数据不可得，未提供实验表格。消融实验未报告具体数值，但论文指出训练阶段主要目标为主动视觉定位，因为克服视觉噪声是当前 MLLMs 更关键且根本缺失的能力，而 Defocus/Refocus 引入的高度动态上下文变化使 RL 训练稳定化仍具挑战。评估边界方面，GroundedVQA 目标实体空间占比严重偏向小比例（< 0.2），验证其高噪声特性，但缺乏跨域泛化测试；可复现性方面，论文未提供代码 URL，但详细披露了训练超参数与硬件配置，LLM-as-a-judge 使用 Gemini-2.5-pro 模型。

## 关联研究分析

从问题动机看，ReFAct 与 MMSearch-R1 同属强化学习训练的多模态代理，但 MMSearch-R1 聚焦端到端框架设计，未解决被动感知导致的噪声问题；ReFAct 引入主动聚焦机制，直接针对视觉噪声与检索噪声的过滤，其差异根源在于任务特性：高噪声环境要求代理具备主动上下文管理能力，而非仅优化检索策略。从方法设计看，ReFAct 与 WebWatcher 共享工具调用基础，但 WebWatcher 提供网页访问与 OCR 工具，缺乏记忆管理模块；ReFAct 的 Defocus/Refocus 操作实现了选择性工作记忆控制，这一差异源于长程推理中上下文污染的普遍性，而非特定任务需求。

## 总结

ReFAct 解决的核心矛盾是多模态代理在高噪声环境中被动感知导致的注意力稀释与上下文污染。现有方法因缺乏主动上下文管理能力，易被无关信息误导，而 ReFAct 通过主动视觉定位与外部记忆管理，使代理能动态调整焦点，从而在噪声环境中保持推理准确性。该框架在 GroundedVQA 基准上显著优于现有强化学习代理，但实验仅在自建高噪声数据集上进行，缺乏跨域泛化验证。当目标实体空间占比增大至常规 VQA 水平时，主动聚焦机制的边际收益是否递减，论文未给出回答。
