# CVPR2026最新论文 ｜Multi-Metric Representation Learning Strategy Based on Clustering for Fine-Grained Multimodal Sentiment Analysis ｜基于聚类的多度量表示学习策略

研究机构：美国卡内基梅隆大学

作者：Yidan Wang、Zongheng Wang、Hongjie Xing 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_7e93f2167c35)

> 多模态情感分析（MSA）旨在整合语言、视觉与声学信号以精准识别人类情感，但现有方法常因模态差异导致表示空间中情感类别中心重叠，致使细粒度情感边界模糊。本文指出，传统对比学习或注意力融合机制虽能捕捉模态交互，却未能显式建模簇内紧凑性与簇间分离性，从而无法有效区分细微情感差异。为此，作者提出MMRest框架，通过全局与局部度量矩阵结合k-means聚类，在共享空间中重构情感几何结构。该方法以极低的参数开销实现了细粒度情感识别的性能提升，但其依赖离散化标签的聚类机制在连续情感值建模上存在固有局限。

## 研究背景

当多模态数据被映射至同一潜在空间时，不同模态的嵌入往往呈现系统性分离，这一现象被称为模态间隙。在情感分析任务中，模态间隙进一步演化为情感类别中心的重叠：不同细粒度情感（如“轻微负面”与“中性”）的表示在空间中聚集于相近区域，导致决策边界模糊。这种几何结构缺陷使得模型难以捕捉细微的情感变化，而传统方法多依赖跨模态注意力或对比学习来增强交互，却未直接针对簇间距离进行优化。

多模态情感分析的主流路线分为融合策略与表示学习策略。前者以MulT、MAG-BERT为代表，利用Transformer架构实现模态间深度交互，但参数量庞大且易引入冗余信息；后者如MCL-MCF采用多级对比学习，虽能学习联合表示，但其t-SNE可视化显示情感中心重叠问题依然存在。现有方法的核心瓶颈在于，它们侧重于模态间的语义对齐，而忽视了情感类别在几何空间中的结构性分离。MMRest的切入点在于，将情感分析重构为多度量度量学习问题，通过显式优化簇内距离最小化与簇间距离最大化，直接修正表示空间的几何缺陷。

## 核心方法

### 方法参照系

多模态表示对齐的标准流程通常涉及特征提取、共享空间映射及对比损失优化。本文问题与该通用流程的关键差异在于：目标并非简单的跨模态检索，而是细粒度情感分类，要求表示空间具备清晰的簇结构。因此，MMRest摒弃了标准的InfoNCE损失，转而采用基于聚类的多度量学习框架，将情感标签离散化为7个区间，并针对每个区间学习特定的度量矩阵。

### 多模态聚类度量模块（MMC）

MMC模块的核心在于通过全局度量$M_0$与局部度量$\Delta M_i$的组合，显式建模情感簇的几何结构。设计动机在于解决传统对比学习中模态主导导致的簇中心重叠问题，即单一度量无法同时适配不同情感类别的分布特性。对于第$i$个簇，定义其感受野$R_i$内的相似对$S_i$与不相似对$D_i$，损失函数为：

$$
\mathcal{L}_{intra}^{(i)} = \max_{(p,q) \in S_i} \left( d_{M_i}(C_p^m, C_q^m) - 0, \sum_{(p,q) \in D_i} d_{M_i}(C_p^m, C_q^m) + \xi \right)
$$

其中$d_{M_i}(C_p^m, C_q^m) = (C_p^m - C_q^m)^\top M_i (C_p^m - C_q^m)$，$M_i = M_0 + \Delta M_i + \beta I$。该公式通过铰链损失强制相似情感对在度量空间中的距离小于不相似对，$\beta I$项确保矩阵正定性。此外，引入簇间三元组损失$\mathcal{L}_{inter}^{(ij)}$，确保不同簇中心间的距离至少为$\rho_{ij}$，从而在几何上拉开情感类别的边界。

### 投影与决策级融合模块（PDLF）

PDLF模块承接MMC输出的度量矩阵与簇中心，将其转化为情感预测的偏置项。设计动机在于，MMC在共享空间中模糊了模态差异，而单模态编码器保留了细粒度的模态特异性信息，两者结合可提升预测精度。首先，计算多模态表示$C_f$与最近簇中心$C_{near}$及次近簇中心$C_{s-near}$在度量$M_0$下的投影差：

$$
bias = \frac{1}{3} \left( \frac{u^\top M_0 u}{\sqrt{u^\top M_0 u}} + \frac{v^\top M_0 v}{\sqrt{v^\top M_0 v}} \right)
$$

其中$u = C_f - C_{near}$，$v = C_{s-near} - C_{near}$。该偏置项量化了样本在情感几何结构中的相对位置。随后，PDLF通过Conv1D与MLP处理单模态表示得到中间分数$\hat{y}'$，最终预测分数为$\hat{y} = \hat{y}' + \gamma bias$。这种设计避免了将度量矩阵分解为$U^\top U$的复杂操作，直接以偏置形式融合几何信息，降低了计算复杂度。

## 实验评估

实验在CMU-MOSI与CMU-MOSEI数据集上进行，基线覆盖MulT、MAG-BERT、MISA、MCL-MCF等代表性方法。MMRest在CMU-MOSI上的Acc-5为56.42%，Acc-7为48.98%，较次优的MCL-MCF（55.10%、47.52%）分别提升1.32%和1.46%。在更大的CMU-MOSEI数据集上，MMRest的Acc-2为83.42%，较MCL-MCF的78.97%提升4.45%。

| 模型 | 参数量 | 显存 | 时间 | Acc-5 | Acc-7 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| MulT | 2.57M | - | - | 42.68 | 36.91 |
| MAG-BERT | 1.22M | - | - | - | 43.62 |
| MISA | 3.10M | - | - | 47.08 | 41.37 |
| MCL-MCF | 199.30M | 11.1GB | 4.26min | 55.10 | 47.52 |
| MMRest | 0.37M | 4.4GB | 2.46min | 56.42 | 48.98 |

消融实验显示，移除局部度量矩阵$\Delta M_i$（即仅使用全局度量）导致Acc-5下降2.34%，Acc-7下降1.46%，证实了局部度量对细粒度情感区分的关键作用。移除偏置项$bias$后，性能下降幅度较小，表明几何投影值主要起微调作用，而非主导预测。值得注意的是，MMRest参数量仅为0.37M，约为MCL-MCF的0.19%，却实现了更优的性能，说明对比学习框架中可能存在大量冗余参数。

评估边界方面，实验仅使用离散化标签（7类）进行聚类，未验证连续情感值下的泛化能力。代码已开源，但超参数（如$\xi, \alpha, \gamma$）的敏感性分析未在正文中详细展开，可能影响复现性。此外，缺乏与最新大规模预训练模型（如CLIP变体）的对比，限制了其在通用多模态任务上的适用性评估。

## 关联研究分析

从问题动机看，MMRest与MCL-MCF均关注模态交互，但MCL-MCF依赖多级对比学习构建正负样本对，其优化目标隐含了模态间的语义对齐假设，却未显式约束情感簇的几何结构。MMRest则直接针对情感类别中心重叠问题，通过多度量矩阵显式优化簇内紧凑性与簇间分离性。这一差异源于任务特性：情感分析要求细粒度区分，而通用对齐任务更关注粗粒度语义匹配。MCL-MCF在CMU-MOSEI上的Acc-2仅为78.97%，低于MMRest的83.42%，表明对比学习在细粒度情感任务上存在性能瓶颈。

从方法设计看，MMRest与DMLCN（Deep Metric Learning with Clustering Network）同属多度量学习路线，但DMLCN仅学习局部度量，缺乏全局共享机制。MMRest引入全局度量$M_0$，使得不同簇间能够共享基础几何结构，提升了模型的泛化能力。然而，MMRest的聚类标签依赖真实情感标签的离散化，这在无监督或半监督场景下可能失效。DMLCN通过自适应生成样本增强域多样性，而MMRest未探索无标签数据下的聚类初始化策略，这可能限制其在真实世界数据中的鲁棒性。

## 总结

MMRest旨在解决多模态情感分析中情感类别中心重叠导致的细粒度区分失效问题。现有方法如MCL-MCF依赖对比学习，虽能捕捉模态交互，但未能显式优化情感簇的几何结构，导致表示空间中不同情感类别的边界模糊。MMRest通过引入全局与局部度量矩阵，结合k-means聚类，显式建模簇内紧凑性与簇间分离性，并以偏置项形式融合几何信息至单模态预测。实验表明，MMRest在CMU-MOSI上的Acc-5达到56.42%，较MCL-MCF提升1.32%，且参数量仅为0.37M。然而，其依赖离散化标签的聚类机制在连续情感值建模上存在局限，且缺乏无监督场景下的验证。当情感标签从离散区间扩展至连续值时，多度量矩阵的初始化与优化策略是否仍能有效捕捉细粒度情感变化，论文未给出回答。
