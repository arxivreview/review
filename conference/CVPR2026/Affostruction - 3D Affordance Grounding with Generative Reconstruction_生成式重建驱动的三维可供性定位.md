# CVPR2026最新论文 ｜Affostruction: 3D Affordance Grounding with Generative Reconstruction ｜生成式重建驱动的三维可供性定位

作者：Chunghyun Park、Seunghyeon Lee、Minsu Cho

论文原文见 [arXiv](https://arxiv.org/abs/2601.09211)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.09211)

> 三维可供性定位旨在将自然语言指令映射到物体表面的具体交互区域，是机器人操作从感知到行动的关键桥梁。现有方法多依赖完整点云或仅预测可见表面，无法处理真实场景中因视角受限导致的严重遮挡。本文提出 Affostruction，通过生成式重建补全缺失几何，并在完整形状上定位可供性。该框架在部分观测下显著提升了遮挡区域的定位精度，但其单物体假设与生成式幻觉风险限制了在杂乱场景中的直接应用。

## 研究背景

机器人通过 RGB-D 相机观察物体时，受限于单一视角，往往只能获取部分表面信息。这种部分观测导致关键功能区域（如杯子的把手）被遮挡，使得基于局部几何特征的判别式模型失效。为了解决这一空间歧义，模型需要具备从有限观测中推断完整三维结构的能力，这涉及三维重建中的几何补全问题。然而，传统重建方法仅恢复已观测表面，无法外推未见区域；而三维生成方法虽能补全几何，却缺乏对功能语义的理解，且通常依赖单张 RGB 图像，未利用机器人场景中可用的深度信息。

三维可供性定位领域的主流路线分为两类：一类是基于完整点云的判别式分割，如 3D AffordanceNet 和 Espresso-3D，它们假设输入几何完整，在部分观测下性能急剧下降；另一类是开放词汇定位方法，如 PointRefer 和 OpenAD，它们通过视觉-语言嵌入处理多样化查询，但同样局限于可见表面。这两类方法均未解决“在几何不完整时如何预测遮挡区域功能”的核心矛盾。Affostruction 的切入点在于将生成式三维重建与可供性预测解耦又耦合：先利用多视角 RGB-D 观测生成完整几何，再在重建形状上执行可供性定位，从而突破可见表面的限制。

## 核心方法

### 方法参照系

本文问题可置于“条件式三维生成”与“语义分割”的交叉范畴。标准流程通常独立处理几何重建与语义预测，而本文的关键差异在于：利用重建出的稀疏体素作为可供性生成的空间载体，并通过深度引导的特征融合实现几何与语义的联合优化。

### 多视角稀疏体素融合重建

设计动机在于解决 TRELLIS 等单图生成模型缺乏深度约束导致的几何歧义，以及多视角输入时 Token 数量线性增长的计算瓶颈。本文在 TRELLIS 的 Flow Transformer 前引入多视角稀疏体素融合模块。对于每个视角 $V_i = (I_i, D_i, K_i, T_i)$，提取 DINOv2 特征并投影至三维空间，形成稀疏体素集合。融合时，重叠体素取特征均值，非重叠体素取并集，最终得到固定大小的条件信号 $\mathbf{C}_{voxel}$：

$$ \mathbf{C}_{voxel} = \{ \text{PE}_{3D}(\mathbf{p}_m) \oplus \bar{\mathbf{f}}_m \}_{m=1}^{M} $$

其中 $\text{PE}_{3D}$ 为三维正弦位置编码，$\oplus$ 表示拼接。该设计将多视角信息压缩至常数复杂度，使模型能从部分观测外推完整几何，且保持与真实物体朝向对齐。

### 基于流的可供性分布生成

设计动机在于应对同一查询（如“抓取”）对应多个有效区域的内在多模态性，判别式单点预测无法捕捉这种分布特性。本文训练一个新的稀疏 Flow Transformer，以 CLIP 文本嵌入为条件，在重建的稀疏体素位置上生成可供性热力图。训练目标采用结合二元交叉熵（BCE）与 Dice 损失的流匹配目标：

$$ \mathcal{L} = \mathbb{E}_{t, \epsilon} \left[ \| v_\theta(\mathbf{A}_t, t, \mathbf{C}_{text}) - (\epsilon - \mathbf{A}_0) \|^2 + \lambda \mathcal{L}_{mask}(\hat{\mathbf{A}}, \mathbf{A}_0) \right] $$

其中 $\mathcal{L}_{mask}$ 为 BCE 与 Dice 的组合，$\hat{\mathbf{A}}$ 为预测的干净可供性对数几率。该生成式建模允许模型输出概率分布而非单一掩码，更贴合功能交互的模糊性。

### 可供性驱动的主动视角选择

设计动机在于优化有限视角预算下的信息获取效率，避免盲目采样。本文定义可供性可见性分数为渲染图像中热力图值的总和：

$$ S(\pi_i) = \sum_{u,v} A_{render}(u, v) $$

其中 $A_{render}$ 是从候选位姿 $\pi_i$ 渲染的可供性着色网格图像。通过最大化该分数选择下一视角，形成“预测-选择-重建”闭环，优先观察高功能区域，加速遮挡区域的几何补全与定位。

## 实验评估

实验在 Affogato 和 Toky4K 基准上进行，基线包括判别式方法（OpenAD, PointRefer, Espresso-3D）及两阶段流水线（TRELLIS/MCC + 可供性模型）。Affostruction 在完整几何可供性定位上取得 19.1 aIoU，较最强基线 Espresso-3D（13.6）提升 40.4%；在部分观测设定下，其 9.26 aIoU 近乎 MCC+Espresso-3D（4.74）的两倍。

| 方法 | 重建 IoU | 完整 aIoU | 部分 aIoU |
| :--- | :--- | :--- | :--- |
| TRELLIS | 19.49 | - | - |
| MCC | 21.11 | - | - |
| Espresso-3D | - | 13.6 | 0.60 |
| MCC + Espresso-3D | - | - | 4.74 |
| Affostruction | 32.67 | 19.1 | 9.26 |

消融实验表明，随机多视角训练对利用额外视角至关重要：单视角训练模型在推理时增加视角几乎无增益，而随机多视角训练使 IoU 从单视角的 33.32 提升至 8 视角的 46.65。主动视角选择在仅增加一个视角时，aIoU 从 4.3 提升至 9.2，是顺序采样的 2.0 倍，验证了功能区域优先策略的有效性。

评估边界方面，Affogato 基准聚焦单物体，缺乏杂乱场景与多实例消歧测试，无法直接对比 SceneFun3D 等场景级基准。代码已开源，但生成式重建可能引入幻觉几何，论文未提供物理可行性验证。

## 关联研究分析

从问题动机看，Affostruction 与 LASO 等场景级语言驱动方法形成互补而非竞争。LASO 假设场景完整，通过语言消歧多实例；Affostruction 假设单物体部分观测，通过生成补全几何。两者分别解决了“多实例歧义”与“遮挡缺失”两个正交问题。Affostruction 未处理多物体干扰，其单物体中心假设在杂乱环境中需依赖前置分割，这限制了其在真实机器人场景中的直接部署。

从方法设计看，Affostruction 与 A4-Agent 等 MLLM 代理式框架存在范式差异。A4-Agent 依赖 MLLM 的高层语义推理进行零样本泛化，而 Affostruction 依赖视觉生成先验，文本仅作为 Flow 条件。这种差异源于任务特性：Affostruction 关注几何精度与遮挡推理，生成式先验在此更具优势；而 A4-Agent 关注开放词汇泛化，MLLM 的语义能力更关键。Affostruction 未探索 MLLM 在生成过程中的语义引导作用，文本条件仅通过 CLIP 嵌入传入，可能限制了复杂指令的理解能力。

## 总结

Affostruction 解决了部分 RGB-D 观测下遮挡区域可供性定位的核心矛盾，通过生成式重建补全几何，并利用 Flow Matching 捕捉功能分布的多模态性。其在 Affogato 基准上实现了 19.1 aIoU 的完整几何定位与 9.26 aIoU 的部分观测定位，显著优于判别式基线。然而，其单物体假设与生成式幻觉风险构成了主要边界：在杂乱场景中，前置分割误差会直接传播至重建与定位环节；生成几何的物理可行性缺乏验证。当场景中存在多个相似物体时，生成式补全是否会导致功能区域的空间错位，论文未给出回答。
