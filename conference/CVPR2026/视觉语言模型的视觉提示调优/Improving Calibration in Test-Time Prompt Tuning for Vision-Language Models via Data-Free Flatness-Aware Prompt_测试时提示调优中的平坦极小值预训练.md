# CVPR2026最新论文 ｜Improving Calibration in Test-Time Prompt Tuning for Vision-Language Models via Data-Free Flatness-Aware Prompt Pretraining ｜测试时提示调优中的平坦极小值预训练

研究机构：韩国延世大学、韩国电子通信研究院

作者：Hyeonseo Jang、Jaebyeong Jeon、Joong-Won Hwang 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.27715)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.27715)

> 测试时提示调优（TPT）通过无标签数据优化提示以适配分布偏移，但常导致模型置信度与准确率严重失配，即校准失效。现有正则化方法虽能改善校准，却往往以牺牲分类精度为代价，且缺乏对优化几何机制的解释。本文指出正则化隐含了向平坦极小值收敛的机制，并提出平坦度感知提示预训练（FPP），在测试前将提示初始化至损失景观的平坦区域。该方法在不增加测试时计算开销的前提下，同时提升了精度与校准，但其预训练阶段对类名语义的依赖及跨域泛化能力仍有待进一步验证。

## 研究背景

当视觉-语言模型（VLM）面对训练分布之外的测试数据时，静态提示无法捕捉实例特定的特征变化，导致性能骤降。测试时提示调优（TPT）通过熵最小化（EM）损失，利用无标签测试样本即时优化提示向量，解决了这一分布偏移问题。然而，EM损失倾向于使模型输出概率分布更加尖锐，导致预测置信度远高于实际准确率，这种现象称为校准误差。在医疗诊断或自动驾驶等对不确定性估计要求严苛的场景中，这种过度自信可能引发严重的安全隐患。

TPT的校准失效源于优化过程陷入损失景观的尖锐极小值。现有方法如C-TPT和O-TPT通过引入正则化项约束文本特征的分散度来改善校准，但这种方式在线调整提示，往往破坏了预训练的对齐关系，导致精度下降。本文的切入点在于揭示正则化与损失景观平坦度之间的内在联系，指出平坦极小值本身即具备更好的校准特性，从而将校准问题从“在线约束”转化为“离线初始化”问题。

## 核心方法

### 方法参照系

标准TPT框架在测试时针对每个样本独立优化提示，使用EM损失最小化预测熵。其核心局限在于单步更新机制无法充分探索损失景观，且缺乏对校准质量的显式约束。本文问题与该通用流程的关键差异在于：不改变测试时的EM优化过程，而是通过预训练阶段改变提示的初始位置，使其天然处于更优的优化区域。

### 正则化与SAM机制的等价性

现有正则化方法（如O-TPT）通过约束文本特征矩阵的迹或方差来增加特征分散度。本文证明，这种正则化在数学上等价于锐度感知最小化（SAM）机制。具体而言，正则化项的梯度$\epsilon_{reg}$相当于在原始提示$\theta_{0}^{zs}$处引入了一个扰动，使得EM损失的梯度在扰动点$\theta_{0}^{reg} + \epsilon_{reg}$处计算。

$$ \theta_{1} = \theta_{0}^{zs} - \nabla_{\theta} L_{ent}(\theta) \big|_{\theta_{0}^{reg} + \epsilon_{reg}} $$

该公式表明，正则化TPT实际上是在一个被扰动的点上计算梯度，这正是SAM寻找平坦极小值的核心操作。这一发现解释了为何正则化能降低校准误差：它隐式地引导提示向平坦区域移动，而平坦极小值对输入扰动不敏感，从而产生更稳定的概率输出。

### 平坦度感知提示预训练（FPP）

基于上述机制，FPP在测试前通过联合优化对齐损失与平坦度损失，将提示初始化到平坦区域。对齐损失确保新提示生成的文本特征与原始提示一致，防止零样本性能退化；平坦度损失通过惩罚随机扰动下的输出变化，显式降低损失景观的锐度。

$$ \mathcal{L}_{flat} = \frac{1}{K} \sum_{k=1}^{K} \left( \text{dist}_{cos}(f_T(c_k, \theta), f_T(c_k, \theta + \epsilon_1)) + \text{dist}_{cos}(f_T(c_k, \theta), f_T(c_k, \theta + \epsilon_2)) \right) $$

该公式通过计算提示$\theta$与其微小扰动版本$\theta + \epsilon$在文本编码器输出上的余弦距离，量化了模型对提示扰动的敏感度。最小化此损失意味着在提示周围的小邻域内，文本特征变化极小，即损失景观平坦。这种初始化使得后续TPT的单步更新能更有效地收敛至平坦极小值，避免了在线正则化带来的精度损失。

## 实验评估

实验在CLIP-ViT-B/16骨干上进行，涵盖细粒度分类（Air, Calt等9个数据集）及自然分布偏移（ImageNet变体）。基线包括TPT、C-TPT、O-TPT及CoOp/MaPLe结合TPT的变体。在细粒度分类任务中，FPP在精度与校准指标上均取得最优表现，打破了以往精度与校准的权衡关系。

| 方法 | 精度 (Avg) | ECE (Avg) | SCE (Avg) |
| :--- | :--- | :--- | :--- |
| TPT | 64.62 | 11.67 | 1.15 |
| O-TPT | 64.12 | 4.46 | 1.15 |
| FPP (Ours) | **65.37** | **4.13** | **0.96** |

FPP的精度比TPT高0.75%，ECE比O-TPT低0.33%，SCE比O-TPT低0.19。这表明FPP不仅改善了校准，还通过更优的初始化提升了分类性能。在ImageNet分布偏移任务中，FPP的精度为59.53%，略低于TPT的59.95%，但ECE从11.99%降至4.63%，显著优于其他正则化方法。

消融实验显示，单独使用平坦度损失会导致零样本精度崩溃，而对齐损失是保持语义结构的关键。此外，FPP对类名变化具有鲁棒性，即使使用ImageNet类名或高斯噪声替代原始类名，性能仍保持SOTA水平，说明其不依赖特定的类名语义。

评估边界方面，实验仅使用CLIP-ViT-B/16，未验证更大规模骨干的效果。预训练阶段需要1K次迭代，虽然测试时无额外开销，但离线预训练的计算成本在边缘部署中可能成为瓶颈。代码已开源，超参数设置（如$\lambda$、$\epsilon$）在附录中提供，可复现性较好。

## 关联研究分析

从问题动机看，FPP与ManiPT等基于流形约束的方法均旨在防止提示偏离预训练分布，但路径截然不同。ManiPT通过几何约束限制提示在预训练流形内的移动，属于在线约束；而FPP通过预训练将提示定位到平坦区域，属于离线初始化。FPP的优势在于不改变测试时的优化动力学，避免了在线约束可能导致的收敛困难，但其前提是平坦极小值与校准质量存在强关联，这一假设在极端分布偏移下是否依然成立，论文未提供充分证据。

从方法设计看，FPP与SAM直接应用于TPT的方法（如TPT+SAM）存在本质差异。TPT+SAM在测试时动态寻找扰动方向，计算开销大且易导致精度下降；FPP则将SAM的思想前置到预训练阶段，通过静态的平坦度损失实现类似效果。这种“离线化”策略牺牲了对测试样本的即时适应性，换取了计算效率与稳定性。然而，当测试分布与预训练分布差异极大时，预训练得到的平坦区域可能不再适用于当前测试样本，此时FPP的初始化优势可能减弱，甚至不如动态SAM方法。

## 总结

本文解决的核心矛盾是TPT中精度与校准的权衡问题。现有正则化方法通过在线约束改善校准，但牺牲了精度；本文抓住“平坦极小值具有更好校准特性”这一被忽略的机制，提出FPP预训练框架，在测试前将提示初始化到平坦区域。实验证明，FPP在细粒度分类中同时实现了65.37%的精度和4.13%的ECE，优于所有基线。其边界在于预训练依赖类名语义，且在极端分布偏移下，离线初始化的适应性可能受限。当测试分布与预训练分布差异显著时，FPP的平坦区域初始化是否仍能保持校准优势，论文未给出明确回答。
