# CVPR2026最新论文 ｜ReCALL: Recalibrating Capability Degradation for MLLM-based Composed Image Retrieval ｜重校准能力退化：基于自改进的多模态大语言模型组合图像检索

研究机构：中国科学院、中国科学院大学

作者：Tianyu Yang、Chenwei He、Xiangzhao Hao 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.01639)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.01639)

> 组合图像检索（Composed Image Retrieval, CIR）旨在通过参考图像与修改文本的联合查询检索目标图像，其核心难点在于跨模态语义的细粒度组合推理。早期双塔模型因模态交互浅层而受限，近期研究转向多模态大语言模型（Multimodal Large Language Models, MLLMs）以利用其深层融合与指令跟随能力，但直接微调导致原生推理能力受损。本文提出ReCALL框架，通过“诊断-生成-精炼”闭环自改进机制，利用基础模型的推理信号校准检索器的嵌入空间。该框架在CIRR基准上取得55.52%的Recall@1，但在FashionIQ上落后于最新自适应方法，其细粒度视觉恢复能力仍存疑。

## 研究背景

当检索器面对细微视觉差异时，其判别边界往往失效——这一现象源于多模态大语言模型（MLLMs）从生成式范式向单嵌入判别式范式转换时的内在冲突。这种范式冲突导致模型在检索适配后，原生细粒度组合推理能力发生退化，即“能力退化”（Capability Degradation）。为量化此退化，本文对比基础模型（F）与其微调后的检索器（R_base），发现R_base在F可解的子集上Recall@1仅62.33%（CIRR）和55.80%（FashionIQ），证实了判别式微调对细粒度推理的抑制。

CIR领域的主流路线已从依赖三元组标注的监督学习转向零样本（Zero-Shot, ZS）范式，以消除数据瓶颈。早期方法如Pic2Word通过文本反转将图像映射为伪词元，虽解决了模态间隙，但牺牲了细粒度视觉细节；CIReVL等生成式方法利用大语言模型（Large Language Model, LLM）生成描述，提升了语义完整性，却未解决检索器内部的推理能力损失。现有MLLM适配方法（如CIR-LVLM）通常采用单阶段静态微调，忽视了微调过程本身对模型原生推理能力的破坏，导致在复杂细粒度任务上性能受限。

本文切入点在于识别并修复这种“能力退化”。不同于外部增强或简单重排序，ReCALL将MLLM的自改进机制引入CIR，通过挖掘检索器的认知盲区，生成针对性修正监督，从而在保留预训练知识的同时，重新对齐判别嵌入空间与内在组合推理能力。

## 核心方法

### 方法参照系

本文问题置于MLLM适配CIR的通用流程中：基础模型微调为检索器。关键差异在于，标准流程假设微调仅提升判别能力，而本文指出微调会损害原生推理，需引入自改进闭环以恢复细粒度区分力。

### 自引导信息实例挖掘

设计动机：随机采样无法定位模型因能力退化而失效的具体决策边界。本文通过自引导挖掘，自动发现检索器当前难以区分的样本。具体而言，对训练集执行检索推理，排除正确排名为第一的查询，聚焦失败案例。对每个失败案例，提取被错误排在真值目标（$I_t$）之上的前$K$张图像，构成信息实例集$\{I_h\}$。这些实例与目标共享细微视觉或语义特征，正是模型判别力薄弱的锚点。

### 生成式校准与分组对比精炼

设计动机：静态微调缺乏针对特定盲区的语义解释，导致模型无法从细微差异中学习。本文利用基础模型（F）的链式思维（Chain-of-Thought, CoT）生成修正指令，并通过分组对比学习内化这些区分。

首先，F对信息实例$I_h$进行意图分解与验证，识别原指令$T_m$中被违反的原子意图，仅重新生成违规部分，得到最小编辑指令$\tilde{T}_m$，形成修正三元组$(I_r, \tilde{T}_m, I_h)$。随后，通过VQA一致性检查过滤噪声，确保生成信号可靠。

精炼阶段采用分组对比学习，将原始三元组$(I_r, T_m, I_t)$与修正三元组$(I_r, \tilde{T}_m, I_h)$置于同一微组（micro-group）中。优化目标结合InfoNCE损失与组内三元组边际损失：

$$
\mathcal{L} = \mathcal{L}_{\text{InfoNCE}} + \lambda \mathcal{L}_{\text{triplet}}
$$

其中，$\mathcal{L}_{\text{InfoNCE}}$维持全局嵌入结构，$\mathcal{L}_{\text{triplet}}$显式强制目标$I_t$与信息实例$I_h$之间的分离，$\lambda$平衡全局对齐与局部精炼。此机制迫使模型在单次梯度更新中区分视觉相邻样本，从而内化细粒度视觉-语义区分，重校准退化能力。

## 实验评估

实验在CIRR和FashionIQ基准上进行，使用Qwen2.5-VL-7B作为骨干，LoRA微调。基线覆盖TIRG、SPRC、CIR-LVLM等双塔及MLLM方法，但缺失纯投影派（如Pic2Word）和扩散模型派（如Fusion-Diff）的直接对比。

| 方法 | CIRR R@1 (%) | CIRR R_subset@1 (%) | FashionIQ Avg R@10 (%) |
| :--- | :--- | :--- | :--- |
| R_base | 51.23 | 77.57 | 53.23 |
| CIR-LVLM | 53.64 | 79.12 | - |
| **ReCALL** | **55.52** | **81.49** | **57.04** |
| **Δ (vs R_base)** | +8.38% | +5.06% | +7.16% |

ReCALL在CIRR上以55.52%的R@1超越CIR-LVLM（53.64%），较R_base提升8.38%，验证了自改进闭环对能力退化的修复效果。在FashionIQ上，ReCALL取得57.04%的平均R@10，较R_base提升7.16%，但在Dress类别提升最大（10.71%），表明其对细粒度属性修改的敏感性。

| 消融组件 | FashionIQ R@10 (%) | FashionIQ R@50 (%) |
| :--- | :--- | :--- |
| Baseline (R_base) | 53.23 | 74.37 |
| + CoT Generation | 55.41 | 75.17 |
| + VQA Quality Control | 56.13 | 76.04 |
| + Grouped Refinement | **57.04** | **76.42** |

消融实验显示，CoT生成贡献最大（+2.18% R@10），VQA质量控制进一步过滤噪声（+0.72%），分组对比精炼最终提升（+0.91%）。随机挖掘策略（53.80%）显著低于自引导挖掘（57.04%），证实了针对性挖掘对定位认知盲区的必要性。

评估边界方面，论文未报告CIRCO成绩，且未提供置信区间，数值比较需谨慎。代码已开源，超参数（如$\lambda=0.30$）明确，但依赖8块H20 GPU，复现成本较高。

## 关联研究分析

从问题动机看，ReCALL与CIReVL均利用LLM生成中间表示，但CIReVL侧重生成目标描述以替代视觉特征，而ReCALL侧重生成修正指令以校准检索器内部表示。CIReVL牺牲视觉特征直接利用，换取语义完整性；ReCALL保留视觉特征，通过自改进修复推理能力。这一差异源于任务特性：CIReVL适用于视觉信息丢失严重的场景，ReCALL适用于MLLM骨干已具备强视觉能力但推理退化的场景。

从方法设计看，ReCALL与WISER代表不同技术路线。WISER采用自适应融合与重排序，通过多路径检索和验证提升鲁棒性，属于系统级优化；ReCALL采用自改进闭环，通过诊断-生成-精炼内化细粒度区分，属于模型级校准。WISER在FashionIQ上取得65.4%的R@10，显著高于ReCALL的57.04%，表明系统级重排序在细粒度时尚属性上可能比模型内部校准更有效。ReCALL在CIRR上略胜WISER（55.52% vs 55.2%），暗示通用场景下模型内部推理能力的恢复更具优势，但细粒度场景下外部重排序的增益更显著。

## 总结

本文核心矛盾在于MLLM适配CIR时的范式冲突导致能力退化。切入点在于利用MLLM原生推理信号自改进，通过诊断-生成-精炼闭环校准嵌入空间。方法上，ReCALL通过自引导挖掘定位盲区，CoT生成修正指令，分组对比精炼内化区分。实验证明，ReCALL在CIRR上取得55.52%的R@1，较基线提升8.38%，但在FashionIQ上仅57.04%，落后于WISER等自适应方法。边界在于，自改进机制在细粒度视觉属性修改上恢复能力有限，可能受限于MLLM骨干在时尚领域的固有短板。当支持集增大或噪声类型多样化时，自引导挖掘的边际收益是否递减，论文未给出回答。
