# CVPR2026最新论文 ｜GeoFree-CoSeg: Unsupervised Point Cloud-Image Cross-Modal Co-Segmentation Without Geometric Alignment ｜无几何对齐的跨模态协同分割

研究机构：北京理工大学

作者：Xin Duan、Xiabi Liu、Liyuan Pan

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_711d6a1cfa5a)

> 协同分割旨在从一组点云或图像中识别并分割共享相同语义的未知对象，其核心难点在于单模态语义线索的匮乏导致分割性能受限，且传统多模态方法依赖高昂的相机标定与精确几何对齐。现有无监督3D语义分割方法虽能利用2D图像，但受限于严格的点-像素映射约束，无法处理仅具备语义一致性而缺乏空间对应关系的场景。GeoFree-CoSeg提出了一种无需几何对齐的跨模态协同分割框架，通过构建跨模态公共语义图与多粒度相关性模块，在语义层面建立3D点云与2D图像的对应关系。该方法在S3DIS和ScanObjectNN基准上超越了现有无监督SOTA，验证了纯语义一致性驱动跨模态融合的有效性，但其对复杂户外场景及细粒度边界精度的适用性仍存疑。

## 研究背景

协同分割（Co-segmentation）与语义分割（Semantic Segmentation）存在本质区别：前者是类别无关的（category-agnostic），旨在发现一组数据中共同的未知语义概念，而后者是类别感知的，将点分配给预定义的固定类别。在3D点云领域，由于缺乏纹理信息且标注成本高昂，无监督协同分割成为降低数据依赖的关键路径。然而，单模态点云仅包含几何坐标，语义线索极其有限，导致模型难以区分几何相似但语义不同的对象（如椅子与桌子）。

为弥补点云语义缺失，研究者尝试引入2D图像作为辅助模态。主流路线如LogoSP和2DPASS依赖几何对齐，即通过相机内参将3D点投影到2D像素，或反之。这种“点-像素映射”策略要求图像与点云在空间上严格对齐，不仅增加了数据采集与标定的复杂度，且限制了2D数据集的适用范围——许多高质量2D图像集（如网络图片）缺乏对应的3D几何信息。当模态间仅存在语义一致性（如都包含“椅子”）而缺乏空间对应时，传统几何对齐方法失效。GeoFree-CoSeg的切入点正是解耦几何对齐与语义融合，探索仅凭语义一致性实现跨模态协同分割的可能性。

## 核心方法

### 方法参照系

本文问题可置于“无监督多模态3D分割”的通用框架下。标准流程通常包含：特征提取、跨模态对齐（几何或语义）、联合优化。关键差异在于，本文摒弃了依赖相机参数的几何对齐模块，转而采用基于语义相似度的图稀疏化策略建立跨模态对应，将任务从“空间配准”转化为“语义匹配”。

### 多粒度相关性建模与图稀疏化

传统跨模态融合在缺乏几何对齐时，直接计算点-像素相似度易受背景噪声干扰，导致语义混淆。GeoFree-CoSeg在2D分支引入多粒度相关性模块（MGCM），通过通道级、补丁级和全局级三个层次逐步提取公共语义。首先，利用前馈网络增强通道交互，随后计算图像间补丁自注意力，并引入DINO CLS token作为全局语义锚点，生成细粒度相关性矩阵 $Z_{P \to I}$。该矩阵作为先验信息，用于正则化点-补丁相似度。具体而言，点-补丁相似度 $A_{P \to I}$ 被解释为似然，而 $Z_{P \to I}$ 为先验，二者结合形成后验概率：

$$
\tilde{A}_{P \to I}^{i,j} = \text{Softmax} \left( A_{P \to I}^{i,j} + \alpha Z_{P \to I}^{i,j} \right)
$$

这一贝叶斯正则化机制解决了纯几何相似度在语义歧义场景下的失效问题，通过引入全局语义先验，过滤掉几何上邻近但语义上不相关的点-像素对，从而在无对齐条件下建立鲁棒的跨模态对应。

### 跨模态语义融合与对比学习

获得细粒度对应关系后，GeoFree-CoSeg执行双向语义融合。3D点特征作为查询，2D补丁特征作为键值，通过加权聚合更新点特征。为强制跨模态语义一致性，论文设计了两个对比学习目标：语义一致性损失 $L_{sem}$ 和对象一致性损失 $L_{obj}$。其中，$L_{sem}$ 拉近3D公共语义特征与2D全局语义原型的距离，$L_{obj}$ 拉近3D对象特征与2D对象原型的距离，同时推远背景特征。

$$
L_{sem} = \frac{1}{N} \sum_{i=1}^{N} -\log \frac{\exp(\hat{s}_i^+ / \tau)}{\exp(\hat{s}_i^+ / \tau) + \sum_{k=1}^{N} \exp(\hat{s}_i^- / \tau)}
$$

该损失函数基于NT-Xent框架，通过温度系数 $\tau$ 控制对比强度，确保3D和2D模态在共享语义空间中收敛到同一概念（如“椅子”），而非各自独立优化。这种双向增强机制弥补了单模态特征提取的局限性，使得3D分支能利用2D的丰富纹理语义，2D分支能利用3D的几何结构约束。

## 实验评估

实验在S3DIS和ScanObjectNN两个3D基准及其对应的自建2D数据集（S3DIS-Coseg, ScanObjectNN-Coseg）上进行。基线覆盖单模态无监督方法（Yang, GrowSP, LogoSP）和2D无监督SOTA（SCoSPARC, DVFDVD）。值得注意的是，LogoSP虽利用2D特征，但依赖几何对齐，本文将其作为主要对比对象以验证“无对齐”策略的有效性。

| 数据集 | 方法 | mIoU (%) | P (%) | J (%) |
| :--- | :--- | :--- | :--- | :--- |
| S3DIS (3D) | LogoSP | 48.0 | - | - |
| S3DIS (3D) | Ours | 54.0 | - | - |
| S3DIS-Coseg (2D) | SCoSPARC | - | 38.0 | 52.0 |
| S3DIS-Coseg (2D) | Ours | - | 59.0 | 59.0 |

在S3DIS 3D分支上，GeoFree-CoSeg以54% mIoU超越LogoSP的48%，提升6%；在S3DIS-Coseg 2D分支上，Jaccard指数从SCoSPARC的52%提升至59%，提升7%。消融实验显示，MGCM、GCSF和SFE模块均带来正向增益，其中GCSF（图稀疏化）对2D分支J指标贡献最大（+10%），表明细粒度语义过滤是跨模态对齐的关键。

评估边界方面，论文未报告置信区间，且自建2D数据集的标注质量未公开，可能影响J指标的可比性。代码未开源，超参数（如 $\alpha, \lambda$）的敏感性分析仅在K值上进行了讨论，缺乏对温度系数 $\tau$ 的深入分析。

## 关联研究分析

从问题动机看，GeoFree-CoSeg与LogoSP形成鲜明对比。LogoSP假设2D图像与3D点云在空间上对齐，通过投影建立对应，这在室内扫描数据中可行，但限制了2D数据源的多样性。GeoFree-CoSeg则假设模态间仅存在语义一致性，通过图稀疏化建立对应。这一差异源于任务定义：LogoSP服务于“有对齐数据的语义分割”，而GeoFree-CoSeg服务于“无对齐数据的协同分割”。根源在于，协同分割关注的是“共同概念”的发现，而非“空间位置”的精确匹配，因此语义一致性比几何对齐更具普适性。

从方法设计看，GeoFree-CoSeg与SCoSPARC（2D无监督SOTA）存在框架差异。SCoSPARC仅利用2D图像内部的相关性，而GeoFree-CoSeg引入了3D点云作为额外的语义约束源。这种跨模态引入并非简单的特征拼接，而是通过对比学习强制3D和2D特征在语义空间对齐。与单模态方法相比，跨模态设计的优势在于3D几何结构能抑制2D图像中的背景噪声，而2D纹理能增强3D点云的语义判别力。然而，论文未探讨当3D点云质量较差（如稀疏或噪声大）时，跨模态融合是否会产生负迁移，这一盲区限制了方法在低质量数据上的适用性。

## 总结

GeoFree-CoSeg旨在解决无几何对齐条件下跨模态协同分割的难题，其核心矛盾在于单模态语义线索不足与多模态融合对空间对齐的依赖。论文抓住“语义一致性优于几何对齐”这一被忽略的点，通过多粒度相关性建模与图稀疏化建立跨模态对应，并引入双向对比学习强化语义一致性。实验证明，该方法在S3DIS上以54% mIoU超越LogoSP，在S3DIS-Coseg上以59% J超越SCoSPARC，验证了无对齐策略的有效性。然而，论文的实验局限于室内场景，且未报告置信区间，自建2D数据集的标注质量也未公开。当输入点云稀疏度极高或2D图像存在严重遮挡时，基于语义一致性的图稀疏化策略是否仍能保持稳定的跨模态对应，论文未给出回答。
