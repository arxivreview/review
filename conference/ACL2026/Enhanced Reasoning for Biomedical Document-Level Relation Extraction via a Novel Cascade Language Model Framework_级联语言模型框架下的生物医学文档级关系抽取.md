# ACL2026最新论文 ｜Enhanced Reasoning for Biomedical Document-Level Relation Extraction via a Novel Cascade Language Model Framework ｜级联语言模型框架下的生物医学文档级关系抽取

研究机构：深圳大学

作者：Haohua Song、Wenhao Gu、Zhijing Li 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_80c9907fafc5)

> 生物医学文档级关系抽取（BioDocRE）面临长距离依赖整合与专业术语噪声的双重挑战，传统预训练语言模型（PLM）受限于浅层语义匹配，难以处理隐式关系，而大语言模型（LLM）虽具备推理能力但存在严重的幻觉偏差且计算成本高昂。CoRE通过置信度路由机制将高置信度样本交由PLM处理，低置信度样本交由增强型LLM进行迭代推理，实现了精度与效率的平衡。该方法在CDR和BioRED数据集上超越了现有基线，但其性能增益高度依赖特定PLM骨干与LLM的组合，且缺乏对动态自适应机制的探索，其通用性边界尚待进一步验证。

## 研究背景

当生物医学文献中的实体关系证据分散于多个句子时，传统的句子级抽取方法因缺乏全局上下文而失效。这一困境催生了文档级关系抽取（DocRE），其核心在于整合跨句证据并处理实体同义词消歧。然而，PLM在处理此类任务时，往往依赖统计共现模式而非多步推理，导致在低资源或隐式关系场景下性能骤降。与此同时，LLM的引入提供了新的范式，但其固有的“关系存在”偏见导致在“无关系”样本上产生大量假阳性，且全量调用LLM的计算成本难以承受。

现有研究主要沿两条路线演进：一是优化PLM的结构建模，如DocuNet将关系矩阵视为图像输入以捕获全局依赖；二是利用LLM的上下文学习能力，如GPT-RE通过检索增强生成缓解幻觉。然而，前者缺乏深层推理能力，后者则因缺乏错误修正机制而在复杂语境中脆弱。CoRE的切入点在于识别PLM与LLM在置信度分布上的互补性：PLM在高置信度区间表现稳定，而LLM在低置信度区间具备更强的泛化潜力。通过构建级联框架，CoRE旨在利用PLM的高效性处理简单样本，同时借助LLM的推理能力攻克复杂样本，从而在生物医学领域实现高精度的关系抽取。

## 核心方法

### 级联路由与置信度阈值机制

CoRE基于PLM与LLM在置信度-可靠性曲线上的差异构建参照系。通常级联框架采用固定阈值或基于概率的路由策略，但本文指出LLM在“无关系”样本上的高置信度预测往往不可靠。因此，CoRE引入经网格搜索优化的置信度阈值 $\tau$，将样本划分为高置信度（由PLM直接输出）与低置信度（路由至LLM）两类。这一设计动机在于规避LLM的过度预测偏差，确保LLM仅处理PLM难以解决的复杂实例，从而在系统层面最大化整体F1分数。

### 提及聚合语义检索（MASR）

针对LLM阶段中实体提及分散导致的全局语义缺失，CoRE提出提及聚合语义检索（Mention-Aggregation-based Semantic Retrieval, MASR）。传统句子级检索仅捕获局部上下文，而MASR通过编码实体所有提及的局部上下文向量并采用对数求和指数（LogSumExp, LSE）池化策略，生成统一的实体表示。LSE作为max算子的平滑近似，能够选择性强调最具判别力的上下文特征，避免平均池化对关键信号的稀释。聚合后的向量经L2归一化后，用于在训练集中检索Top-K相似实例作为演示样本。这一机制确保了LLM接收到的演示样本包含跨句证据，从而缓解因局部视角导致的推理偏差。

### 迭代链式思维与动态错误经验库

MASR提供的演示样本若仅作为格式模板，仍无法解决逻辑错误传播问题。CoRE引入迭代链式思维（Iterative Chain-of-Thought, ItCoT）机制，结合动态错误经验库（Dynamic Error Experience Library, DEEL）实现闭环修正。在推理前，LLM对检索到的实例进行探测性推理，将错误案例总结为“错误类型”与“避免策略”存入DEEL。推理时，LLM执行“生成-反思-修正”循环：若推理轨迹匹配DEEL中的已知错误模式，则触发修正；否则输出确认信号。该机制的核心公式为迭代更新过程，其中 $r_t$ 为第 $t$ 次推理结果，$E$ 为错误经验库：

$$ r_{t+1} = \text{Revise}(r_t, E) \quad \text{if } \text{Match}(r_t, E) \text{ else } \text{Confirm}(r_t) $$

这一设计将静态提示转化为动态自我验证过程，显著降低了幻觉率，使LLM能够在复杂生物医学语境中主动识别并纠正逻辑谬误。

## 实验评估

| 数据集 | 方法 | Precision | Recall | F1 |
| :--- | :--- | :--- | :--- | :--- |
| CDR Test | DocuNet (PLM) | 89.03 | 83.77 | 86.32 |
| CDR Test | GPT-5 (Zero-shot) | 62.11 | 61.82 | 61.97 |
| CDR Test | GPT-5 + CoRE | 89.09 | 87.34 | 88.20 |
| BioRED Test | e2eBioMedRE (PLM) | 67.81 | 61.39 | 64.44 |
| BioRED Test | Deepseek-v3.2 (Zero-shot) | 21.44 | 49.96 | 30.00 |
| BioRED Test | Deepseek-v3.2 + CoRE | 67.65 | 65.09 | 66.35 |

实验在CDR和BioRED数据集上进行，基线覆盖PLM（DocuNet, e2eBioMedRE）与零样本LLM（GPT-5, Deepseek-v3.2等）。CoRE在CDR上以88.20%的F1超越DocuNet的86.32%，在BioRED上以66.35%的F1超越e2eBioMedRE的64.44%。值得注意的是，零样本LLM在BioRED上表现极差（F1约30%），主要源于严重的假阳性，而CoRE通过路由机制有效抑制了这一偏差。

消融实验显示，移除语义提及聚合与迭代推理组件导致平均F1下降6.66%。在低置信度子集上，CoRE相比基线PLM提升了15.95%（CDR）和8.07%（BioRED）的F1，证明增益集中于复杂样本。幻觉分析表明，CoRE将Deepseek-v3.2的假阳性率（FPR）从41.42%降至26.19%，验证了DEEL在抑制幻觉上的有效性。

评估边界方面，论文未报告计算效率的具体数值（仅提及API成本降低45.55%），且未对比其他级联方法（如ATGL）。代码未公开，超参数（如阈值 $\tau$）依赖开发集网格搜索，可能引入过拟合风险。此外，实验局限于生物医学领域，未验证其在通用领域或低资源语言中的泛化能力。

## 关联研究分析

从问题动机看，CoRE与GPT-RE均旨在缓解LLM幻觉，但GPT-RE依赖句子级检索与单次CoT，而CoRE通过文档级提及聚合与迭代反思实现更深层的证据整合。GPT-RE的检索粒度较粗，易遗漏跨句关键证据，导致在BioRED等复杂数据集上性能受限。CoRE的MASR机制通过LSE池化聚合全局语义，解决了这一盲区，但其代价是增加了检索阶段的计算复杂度。

从方法设计看，CoRE与ATGL同属文档级关系建模路线，但ATGL聚焦于自适应阈值全局损失以缓解类别不平衡，而CoRE采用级联架构平衡PLM与LLM的能力互补。ATGL在DocRED上取得80.68%的F1，但依赖传统PLM骨干，缺乏LLM的推理能力。CoRE则通过引入LLM处理低置信度样本，在生物医学领域取得了更高精度。然而，CoRE的性能高度依赖PLM骨干的质量（如DocuNet在CDR上的高置信度表现），若PLM在特定领域表现不佳，路由机制的有效性可能受损。

## 总结

CoRE旨在解决生物医学文档级关系抽取中PLM推理能力不足与LLM幻觉偏差的矛盾。通过置信度路由、提及聚合检索与迭代错误修正，CoRE在CDR和BioRED上分别取得88.20%和66.35%的F1，显著超越单一模型基线。其边界在于性能增益依赖特定PLM-LLM组合，且缺乏对动态自适应机制的探索，例如根据实例难度动态调整迭代次数或检索深度。当支持集规模扩大或领域迁移时，DEEL的错误经验库是否仍能保持泛化性，论文未给出回答。
