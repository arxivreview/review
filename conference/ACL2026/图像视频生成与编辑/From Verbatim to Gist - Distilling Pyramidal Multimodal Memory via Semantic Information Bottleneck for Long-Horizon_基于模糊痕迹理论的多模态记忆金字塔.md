> 长视频理解面临上下文窗口限制与稀疏证据定位的双重瓶颈，现有视觉中心范式因帧冗余导致计算过载，文本中心范式则因信息有损压缩引发幻觉。MM-Mem 借鉴认知科学中的模糊痕迹理论，将视觉细节与语义抽象解耦为并行记忆痕迹，通过信息瓶颈优化动态构建分层记忆，并利用熵驱动策略实现按需检索。该架构在开源模型中实现了长视频理解的显著性能提升，但其动态记忆管理在流式场景下的实时性开销及跨天级视频的Schema稳定性仍存疑。

## 研究背景

当多模态大语言模型处理小时级视频流时，视觉Token数量迅速超出上下文窗口限制，迫使系统采用采样或压缩策略。然而，均匀采样易遗漏稀疏关键帧，而全局压缩则丢失细粒度时序动态。这一矛盾催生了对高效记忆机制的需求，即如何在有限预算内保留任务相关语义，同时维持对具体视觉证据的访问能力。

长视频理解的主流路线分为视觉中心与文本中心两类。视觉中心方法（如LongVA）通过密集帧采样积累视觉记忆，虽保真度高但引入大量冗余，导致推理延迟激增；文本中心方法（如VideoRAG）将视频转化为文本摘要或知识图谱，虽计算高效但属于有损压缩，丢弃关键视觉线索后易产生幻觉与歧义。此外，现有系统多为静态存储，缺乏动态管理能力，无法在长程交互中剔除冗余并更新语义。MM-Mem 的切入点在于借鉴人类认知中的模糊痕迹理论，认为视觉与文本模态天然对应“逐字”与“概要”两种记忆痕迹，通过跨模态融合而非刚性映射，构建从感知到认知的分层金字塔，实现细节与语义的动态平衡。

## 核心方法

### 分层多模态记忆金字塔

MM-Mem 将记忆结构化为三层：Sensory Buffer 保留细粒度视觉证据，Episodic Stream 存储事件级摘要，Symbolic Schema 构建高层语义知识图谱。与传统的扁平化存储不同，该架构在每一层均维持视觉与文本的共存，但模态主导性随层级上升逐渐从视觉转向文本。Sensory Buffer 中，文本仅作为视觉实体的描述性标签，提供语义锚点以索引冗余视觉细节；Symbolic Schema 中，文本主导的概念通过“接地边”（grounding edges）显式锚定回具体的 Episodic 单元，保留视觉证据的访问路径。这种设计解决了单一模态记忆在长程依赖建模中的失效：视觉中心无法高效管理长期语义，文本中心无法回溯具体视觉细节。

### 语义信息瓶颈强化学习

记忆构建的核心挑战在于压缩冗余的同时保留任务相关语义。MM-Mem 将 Sensory-to-Episodic 转换建模为随机压缩过程，引入语义信息瓶颈（SIB）目标函数：

$$ \mathcal{L}_{SIB} = \mathbb{E}_{p_\theta(m|x)} [\mathcal{L}_p(m, y)] + \beta \mathcal{L}_c(x, m) $$

其中 $\mathcal{L}_p$ 下界化记忆与标签的互信息 $I(M; Y)$，$\mathcal{L}_c$ 上界化输入与记忆的互信息 $I(X; M)$，$\beta$ 控制压缩-预测权衡。为优化该离散序列生成目标，MM-Mem 提出 SIB-GRPO，将记忆管理器视为策略 $\pi_\theta$，通过组相对优势（Group-Relative Advantage）和 PPO 风格截断代理损失进行强化学习训练。奖励函数包含语义保留项与长度惩罚项，后者通过 KL 散度锚定至教师分布，防止记忆表达退化。该机制解决了静态记忆构建中冗余累积的问题，使系统能动态剔除低新颖度条目，实现从视觉逐字痕迹到文本概要痕迹的渐进蒸馏。

### 熵驱动自顶向下检索

检索过程遵循逆向层级理论，从抽象的 Symbolic Schema 开始，仅在决策不确定性高时向下钻取。给定问题 $Q$ 和候选答案集 $\mathcal{A}$，系统维护后验分布 $p(a_i | Q, R_{\le s})$，并计算其熵 $H_s(Q)$ 作为自适应停止准则：

$$ H_s(Q) = -\sum_{i=1}^N p(a_i | Q, R_{\le s}) \log p(a_i | Q, R_{\le s}) $$

当 $H_s(Q) \le \gamma$ 或熵减 $\Delta H_s$ 连续低于阈值 $\epsilon$ 时，检索终止并返回最大概率答案。这一设计解决了固定深度检索在简单问题上浪费计算、在复杂问题上证据不足的问题，实现了计算成本与准确度的动态权衡。

## 实验评估

实验在 Video-MME、MLVU、VStream-QA-Ego 和自建 HD-EPIC++ 四个基准上进行，基线涵盖专有模型（Gemini 1.5 Pro, GPT-4o）、开源 MLLM（Qwen2-VL-72B, LLaVA-Video-72B）及代理系统（Vgent, VideoRAG）。MM-Mem 基于 Qwen3-VL-8B 骨干，在 Video-MME 上取得 77.2% 的 M-Avg 准确率，较最强代理基线 Vgent 提升 5.1% 相对增益；在 MLVU 上达到 77.2%，较 Vgent 提升 7.1%。在流式基准 VStream-QA-Ego 上，MM-Mem 以 62.5% 准确率和 4.1 分超越 Flash-VStream 5.9% 和 5.2%。在 HD-EPIC++ 上，MM-Mem 达到 30.28%，较 Qwen3-VL-8B 基线提升 4.40 点。

| 基准 | 方法 | 准确率/分数 |
| :--- | :--- | :--- |
| Video-MME (M-Avg) | MM-Mem | 77.2 |
| Video-MME (M-Avg) | Vgent | 72.1 |
| MLVU (M-Avg) | MM-Mem | 77.2 |
| MLVU (M-Avg) | Vgent | 70.5 |
| VStream-QA-Ego (Acc) | MM-Mem | 62.5 |
| VStream-QA-Ego (Acc) | Flash-VStream | 59.0 |
| HD-EPIC++ (Acc) | MM-Mem | 30.28 |
| HD-EPIC++ (Acc) | Qwen3-VL-8B | 25.88 |

消融实验显示，移除 SIB-GRPO 导致性能一致下降，且在长视频（Long）分割上降幅最大，表明动态记忆管理对长程依赖建模至关重要。移除分层记忆结构同样导致性能显著下滑，验证了金字塔架构的有效性。t-SNE 可视化表明，Sensory Buffer 中的视觉记忆呈现细粒度聚类，而 Episodic Stream 中的记忆则形成更紧凑的事件级簇，证实了从逐字到概要的蒸馏过程。

评估边界方面，MM-Mem 未报告计算延迟与内存开销，无法直接评估其在实时流式场景下的效率。HD-EPIC++ 为自建数据集，规模较小（156 视频），泛化性需更大规模验证。代码与超参数已公开，基于 A100 80GB GPU 训练，可复现性良好。

## 关联研究分析

从问题动机看，MM-Mem 与 PyraVid 同属分层记忆路线，但 PyraVid 侧重检索效率与静态存储，而 MM-Mem 引入 SIB-GRPO 实现动态记忆管理，解决了长程交互中冗余累积的问题。这一差异源于 MM-Mem 对模糊痕迹理论的严格遵循：人类记忆是动态更新的，静态存储无法模拟这种认知过程。然而，SIB-GRPO 的强化学习训练在流式场景下的实时性开销未被量化，若记忆更新延迟超过视频帧率，该机制可能失效。

从方法设计看，MM-Mem 与 VideoRAG 形成鲜明对比。VideoRAG 作为视觉中心范式，通过密集帧采样积累视觉记忆，虽保真度高但计算冗余大；MM-Mem 通过 FTT 解耦视觉与文本，将视觉细节限制在 Sensory Buffer，仅在熵高时检索，从而降低计算负载。这一设计解决了视觉中心方法在长视频中的“认知过载”问题，但代价是依赖文本摘要的质量。若文本摘要生成器（如 Qwen3-VL-8B）在细粒度动作描述上存在偏差，Symbolic Schema 的接地边可能锚定到错误的视觉片段，导致检索错误。

## 总结

MM-Mem 旨在解决长视频理解中视觉冗余与文本有损压缩的矛盾，通过模糊痕迹理论将视觉与文本解耦为并行记忆痕迹，并利用信息瓶颈优化动态构建分层金字塔。该架构在 Qwen3-VL-8B 骨干上实现了 Video-MME 77.2% 和 MLVU 77.2% 的准确率，较最强代理基线提升 5.1% 至 7.1%。其边界在于未量化动态记忆管理的实时性开销，且 HD-EPIC++ 数据集规模有限。当视频时长扩展至天级时，Symbolic Schema 的更新机制是否会导致语义漂移，论文未给出回答。
