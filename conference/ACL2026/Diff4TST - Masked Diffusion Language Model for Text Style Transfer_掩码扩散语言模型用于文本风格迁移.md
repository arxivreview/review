# ACL2026最新论文 ｜Diff4TST: Masked Diffusion Language Model for Text Style Transfer ｜掩码扩散语言模型用于文本风格迁移

研究机构：华东师范大学、新加坡国立大学

作者：Xinchen Ma、Gaole He、Yunshi Lan 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_09f36e9edfae)

> 文本风格迁移（Text Style Transfer, TST）旨在改写文本以匹配目标风格同时保留原意，核心难点在于风格修改与内容保留的边界模糊。现有自回归大语言模型（LLM）将任务视为全序列左到右生成，导致大量无需修改的内容被重复生成，稀释了风格学习的信号且计算成本高。Diff4TST 将 TST 重构为显式的“复制-编辑”过程，利用掩码扩散语言模型（Masked Diffusion Language Model, MDLM）的并行去噪特性，通过风格感知噪声调度区分编辑与复制 token，并在推理阶段引入梯度归因迭代修正。该方法在极性风格迁移基准上显著优于自回归基线，但其依赖外部分类器的推理机制是否能在无标注场景下泛化仍存疑。

## 研究背景

文本风格迁移要求模型在保持语义不变的前提下，精准修改承载风格属性的词汇或结构。这一任务本质上是稀疏编辑：大部分 token 应保持不变，仅少数风格相关 token 需要替换。然而，自回归 LLM 的生成机制强制模型从左到右逐词预测，这意味着即使前文已确定，后续内容仍需重新生成，导致模型在“复制”内容上浪费大量计算资源，且难以显式控制哪些 token 被修改。这种全序列生成的范式与 TST 的局部编辑特性存在根本错位，使得训练信号被内容复制任务稀释，风格控制的精度受限。

主流 TST 方法分为属性替换与句子生成两类。属性替换方法依赖词典或分类器，灵活性差且难以处理细粒度风格；句子生成方法基于自回归 LLM，虽灵活但需依赖强化学习或复杂奖励函数来约束风格，训练不稳定且部署成本高。尽管扩散模型在图像生成中已证明其迭代去噪的优势，但在文本领域，现有掩码扩散模型多采用均匀噪声调度，即所有 token 以相同概率被掩码，这同样无法区分风格编辑与内容保留，导致模型倾向于全局重写而非局部修改。Diff4TST 的切入点在于利用 MDLM 的并行预测特性，通过设计非均匀的噪声调度，显式引导模型关注风格编辑区域，从而在训练和推理两个阶段实现更精细的内容-风格解耦。

## 核心方法

### 掩码扩散语言模型参照系

MDLM 通过前向过程逐步掩码 token，反向过程迭代预测被掩码的 token 来生成文本。标准 MDLM（如 LLaDA）使用线性噪声调度 $\alpha_t = t$，即每个 token 在时间步 $t$ 被掩码的概率为 $t$。这种均匀调度假设所有 token 对生成同等重要，适用于开放域文本生成，但忽略了 TST 任务中 token 功能的不均衡性：内容 token 需保留，风格 token 需修改。本文的关键差异在于引入基于编辑操作的差异化噪声调度，将 TST 建模为条件生成问题，其中输入包含指令、源文本，输出为目标文本。

### 风格感知噪声调度

标准 MDLM 的均匀掩码策略在 TST 中导致模型无法区分“需修改”与“需保留”的 token，训练时大量计算资源被用于学习如何复制不变的内容，而非如何修改风格。Diff4TST 通过 Levenshtein 对齐算法提取源文本与目标文本间的 token 级编辑操作，将 token 标记为 [COPY]（未变）或 [EDIT]（插入、删除或替换）。针对 [EDIT] token，保留线性噪声调度 $\alpha_t([EDIT]) = t$，确保风格区域在训练早期即被充分扰动；针对 [COPY] token，采用余弦衰减调度：

$$ \alpha_t([COPY]) = (1 - r) (1 - \cos(\pi t)) $$

其中 $r$ 为编辑比例。该公式的物理含义是：在时间步 $t$ 接近 0 时，[COPY] token 的掩码概率极低，迫使模型学习保留内容；随着 $t$ 增加，掩码概率缓慢上升，但在后期迅速增加，以强化对风格编辑的修正能力。此外，损失函数中引入风格感知系数 $\beta_t^k$，对 [EDIT] token 赋予权重 $t$，对 [COPY] token 赋予权重 $1-t$，进一步引导模型在训练后期更关注风格编辑的准确性。这一设计解决了均匀调度下风格信号被内容复制任务稀释的问题，使模型能更精准地学习局部风格变换。

### 生成-修正推理框架

仅依靠训练阶段的噪声调度，生成结果仍可能不严格满足目标风格约束，尤其是细粒度风格任务。Diff4TST 在推理阶段引入“生成-修正”（Generate-then-Refine）策略。首先，通过标准反向去噪过程生成初始假设 $\tilde{x}_0$。随后，利用一个基于 DistilBERT 的外部风格分类器计算每个 token 对分类器损失 $L_{classifier}$ 的梯度归因：

$$ M \leftarrow \arg\max_{\tilde{x}_i^0 \in \tilde{x}_0} \|\nabla_{\tilde{x}_i^0} L_{classifier}\|_2 $$

该公式识别出对风格偏差贡献最大的 token 集合 $M$。这些 token 被重新掩码，MDLM 仅对这些位置执行额外的去噪步骤，生成修正后的输出。若修正后仍不满足风格要求，则重复此过程，直至收敛或达到最大迭代次数（5 次）。这一机制无需强化学习或人工设计奖励函数，通过梯度信号直接定位风格缺陷，实现了推理阶段的动态风格控制，弥补了训练阶段静态调度的不足。

## 实验评估

实验在 GYAFC（正式/非正式）、ParaDetox（毒性/中性）、CNN/DM（可读性）和 Yelp（情感）四个基准上进行。基线包括自回归 LLM（LLaMA-3-8B, GPT-4o, GPT-5）、神经元激活方法（APE, AVF, PNMA, sNeuron-TST）以及 SFT+PPO 基线。Diff4TST 在极性风格迁移任务中表现突出：在 GYAFC 上，非正式转正式准确率达 99.12%，正式转非正式达 84.56%，显著优于最佳基线 sNeuron-TST 的 80.80% 和 14.40%；在 ParaDetox 上，毒性转中性准确率达 98.36%，中性转毒性达 96.34%，远超基线的 55.36% 和 31.98%。内容保留度（LaBSE）方面，Diff4TST 在 GYAFC 非正式转正式任务中为 0.72，略低于 sNeuron-TST 的 0.74，但流畅度（Perplexity）从 90.79 降至 33.33，表明生成文本更自然。

| 方法 | GYAFC 非正式转正式准确率 | GYAFC 正式转非正式准确率 | ParaDetox 毒性转中性准确率 | ParaDetox 中性转毒性准确率 |
| :--- | :--- | :--- | :--- | :--- |
| sNeuron-TST | 80.80 | 14.40 | 55.36 | 31.98 |
| Diff4TST | 99.12 | 84.56 | 98.36 | 96.34 |

在细粒度风格迁移任务中，Diff4TST 同样优于自回归基线，但具体数值未在提供的数据区中完整列出，仅能确认其在多数情况下实现了更低的风格偏差。消融实验未单独提供表格，但文中指出风格感知噪声调度是提升精度的关键，而生成-修正框架进一步提升了风格合规性。评估边界方面，实验依赖外部风格分类器进行梯度归因，该分类器需使用与训练相同的数据集训练，这意味着在缺乏标注数据的零样本场景下，推理阶段的有效性未经验证。此外，代码未公开，超参数（如最大迭代次数 5 次）的敏感性未详细讨论，可复现性受限。

## 关联研究分析

从问题动机看，Diff4TST 与视觉风格迁移中的 InstantStyle 具有同构性。InstantStyle 通过选择性注入特定 UNet 层来解决 CLIP 编码器带来的内容泄漏问题，其核心思想是“选择性干预”：只修改风格相关特征，保留内容特征。Diff4TST 的风格感知噪声调度同样实现了这种选择性：通过差异化掩码概率，只扰动风格 token，保留内容 token。两者的差异源于模态特性：视觉风格迁移中，内容与风格在特征空间中纠缠，需通过架构设计（如层选择）解耦；文本风格迁移中，内容与风格在 token 序列上相对分离，可通过序列对齐（Levenshtein）显式标记。这种差异表明，文本模态的离散性和序列性使得“显式标记”比“隐式解耦”更可行，但这也限制了方法在风格与内容高度交织的复杂文本（如诗歌、隐喻）中的适用性。

从方法设计看，Diff4TST 的生成-修正推理框架与自回归方法中的 RLHF（基于人类反馈的强化学习）形成对比。RLHF 通过优化全局奖励函数来引导生成，而 Diff4TST 通过梯度归因定位局部缺陷并进行迭代修正。前者依赖奖励模型的全局信号，后者依赖分类器的局部梯度。Diff4TST 的优势在于无需设计复杂的奖励函数，且推理过程可解释（梯度直接指向问题 token）；劣势在于依赖外部分类器的准确性，若分类器对风格定义不敏感，修正可能无效。相比之下，自回归方法如 sNeuron-TST 通过操纵神经元激活实现风格控制，无需外部模型，但控制粒度较粗。Diff4TST 的梯度归因机制是否能在无外部分类器的情况下，通过模型内部表示实现类似效果，论文未给出回答。

## 总结

Diff4TST 针对自回归 LLM 在文本风格迁移中“全序列生成”与“局部编辑”任务特性的错位问题，提出基于掩码扩散语言模型的“复制-编辑”范式。通过风格感知噪声调度显式区分编辑与复制 token，并在推理阶段引入梯度归因迭代修正，该方法在 GYAFC 和 ParaDetox 基准上实现了 99.12% 和 98.36% 的风格迁移准确率，显著优于自回归基线。然而，其推理阶段依赖外部风格分类器，且实验仅在配对数据充足的情况下进行，未验证在零样本或低资源场景下的泛化能力。当风格定义模糊或训练数据缺乏明确编辑标注时，Levenshtein 对齐的准确性是否会下降，进而影响噪声调度的有效性，论文未给出回答。
