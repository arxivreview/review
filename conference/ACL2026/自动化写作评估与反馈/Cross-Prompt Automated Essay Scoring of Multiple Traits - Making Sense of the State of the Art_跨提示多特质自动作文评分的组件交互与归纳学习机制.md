# ACL2026最新论文 ｜Cross-Prompt Automated Essay Scoring of Multiple Traits: Making Sense of the State of the Art ｜跨提示多特质自动作文评分的组件交互与归纳学习机制

作者：Shengjie Li、Vincent Ng

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_02b4e3490298)

> 跨提示自动作文评分旨在解决模型在未见过的写作提示下泛化能力不足的问题，传统方法因依赖特定提示的领域知识而失效。现有研究虽提升了分数，但缺乏对特征、架构等组件交互影响的归因分析，且忽视了课堂场景下利用未标注测试数据的可能性。本文通过系统性消融实验解构评分器组件，并引入归纳学习重加权机制以适配无额外标注的部署环境。该工作厘清了性能来源，但受限于浅层网络架构，其绝对精度仍低于端到端大语言模型微调方案。

## 研究背景

自动作文评分（Automated Essay Scoring, AES）的核心困境在于评分模型的泛化边界。当模型从训练提示迁移至测试提示时，若提示类型改变（如从叙事转为说服），模型需区分“有说服力的论证”与“无说服力的论证”，这种提示特定的领域知识无法从训练数据中直接获取，导致跨提示评分性能显著下降。为应对此挑战，多特质评分（Multi-trait Scoring）被引入，要求模型不仅预测整体分，还需独立评估组织、内容等维度，其中内容类特质因依赖深层语义理解而尤为困难。

主流跨提示评分路线依赖手工特征工程与浅层神经网络，如 ProTACT 和 GAPS，它们通过统计特征捕捉表面语言规律，但难以处理语义反转。尽管大语言模型（LLMs）在零样本评分中展现出潜力，但其直接输出分数往往不稳定，且缺乏对评分逻辑的透明解释。现有研究多关注最终分数的提升，却忽视了特征归一化、开发集指标选择等实现细节对性能的隐性影响，导致不同方法间的比较缺乏可解释性。本文切入点在于解构这些组件的交互作用，并探索在课堂场景中利用未标注测试数据（归纳学习）来优化训练权重，从而在不增加标注成本的前提下提升跨提示评分的鲁棒性。

## 核心方法

### 方法参照系

本文基于 ASAP/ASAP++ 数据集，采用多层感知机（MLP）作为评分骨干，输入为手工特征与 LLM 生成特征的混合向量。与端到端 Transformer 评分不同，该方法将 LLM 视为特征提取器而非评分器，通过零样本提示获取特质分数及理由嵌入，再经浅层网络回归预测。关键差异在于，本文不依赖模型内部参数微调来适应新提示，而是通过外部特征增强与训练策略调整实现泛化。

### 组件交互解构

传统跨提示评分器通常固定特征集、架构与归一化方式，导致性能波动归因困难。本文系统性地解耦四个关键组件：特征集（Basic vs. Advanced）、架构（Independent vs. JointS vs. JointT）、归一化（z-score vs. min-max）及开发集指标（Loss vs. QWKS vs. QWKT）。Advanced 特征集包含 Basic 统计特征、LLM 零样本预测分数及理由嵌入，其理由嵌入由 Qwen3-Embedding-8B 生成 4096 维向量。JointT 架构仅联合预测目标提示适用的特质，避免无关特质干扰。实验表明，z-score 归一化配合 Advanced 特征集在多数特质上优于 min-max，而 JointT 在语言、词汇选择等特质上显著优于 Independent 架构，证明联合学习能利用特质间相关性提升特定维度精度。

### 归纳学习重加权

针对课堂场景中标注数据稀缺的问题，本文引入归纳学习（Transductive Learning），利用未标注测试作文重加权训练集。核心思想是：与测试作文相似的训练样本应获得更高权重，以适配目标分布。具体实现中，设定 2 基于余弦相似度选取 Top-k 最近邻，若某训练样本被 $T$ 个测试样本选为邻居，其权重设为 $(1+x)^T$，其中 $x$ 为超参数。该机制无需额外标注，仅利用测试集的结构信息调整训练损失。

$$
w_i = (1+x)^{T_i}
$$

其中 $w_i$ 为第 $i$ 个训练样本的权重，$T_i$ 为被选为最近邻的次数，$x$ 控制权重增长幅度。此公式意味着与测试集高度相似的样本将指数级增加其在损失函数中的贡献，迫使模型更关注目标分布的特征模式。

## 实验评估

实验在 ASAP/ASAP++ 数据集上进行，对比 ProTACT、GAPS 及五个 LLM 零样本基线。主结果显示，本文最佳配置（AdvancedG + JointT + z-score + QWKT）达到 AVG QWK 0.603，显著优于 Gemini-2.5-Flash 的 0.439 和 GAPS 的 0.591。

| 方法 | 架构 | 特征集 | 归一化 | 开发指标 | AVG QWK |
| :--- | :--- | :--- | :--- | :--- | :--- |
| GAPS | - | - | - | - | 0.591±.011 |
| Gemini-2.5-Flash | Zero-Shot | - | - | - | 0.439 |
| Ours (Best) | JointT | AdvancedG | z-score | QWKT | 0.603±.005 |

消融实验揭示，移除 LLM 理由嵌入导致 AVG QWK 显著下降，证实理由作为特征的有效性。归纳学习方面，Setting 2（同类型 + kNN）在 Independent 架构下提升 AVG 分数，但在 Joint 架构下效果不显著，且 Organization 和 Conventions 特质出现性能下降，表明重加权机制对特定特质存在负迁移风险。

评估边界方面，本文仅使用 QWK 指标，未报告置信区间或公平性指标。代码已开源，但 LLM 特征生成耗时 300 小时，限制了实时部署可行性。与领域共识相比，本文证明在跨提示多特质任务中，浅层网络结合 LLM 特征可超越纯 LLM 零样本评分，但绝对精度仍低于端到端微调方案（如 AutoSCORE 的 0.85+ QWK），这归因于任务设定差异（跨提示 vs. 同提示）及模型容量限制。

## 关联研究分析

从问题动机看，本文与 ProTACT (Do et al., 2023) 共享跨提示评分目标，但 ProTACT 聚焦于特征工程的自动化生成，而本文强调组件交互的归因分析与归纳学习部署。ProTACT 假设测试集不可用于训练，本文则挑战这一假设，指出在课堂场景中利用未标注测试数据重加权训练集是可行的。这一差异源于应用场景的不同：标准化考试强调隐私与固定流程，而课堂评估允许灵活利用学生提交的数据。

从方法设计看，本文与 LLM 零样本评分（如 Mansour et al., 2024）形成互补。LLM 零样本方法直接输出分数，缺乏对评分逻辑的透明控制；本文将 LLM 降级为特征提取器，通过浅层网络整合统计特征与语义特征，提升了可解释性。然而，本文未探索 LLM 作为评分器的端到端微调路径，这可能限制了其在复杂语义理解上的潜力。查询侧增强在数据充足时是否仍有增益，论文未给出回答，这暗示了特征工程路线与端到端路线在数据规模依赖上的根本差异。

## 总结

本文核心矛盾在于跨提示评分中组件交互的不透明性与课堂部署中标注数据稀缺的冲突。通过解构特征、架构、归一化及开发指标，本文揭示了 z-score 归一化与 JointT 架构在特定特质上的优势，并验证了 LLM 理由嵌入作为特征的有效性。归纳学习重加权机制在不增加标注成本的前提下提升了 Independent 架构的性能，但存在特质间的负迁移风险。实验证明，最佳配置达到 0.603 AVG QWK，优于纯 LLM 零样本基线，但低于端到端微调方案。本文边界在于浅层网络容量限制及归纳学习对特定特质的不稳定性。当测试集分布发生剧烈变化时，基于最近邻的重加权机制是否仍能保持鲁棒性，论文未给出回答。
