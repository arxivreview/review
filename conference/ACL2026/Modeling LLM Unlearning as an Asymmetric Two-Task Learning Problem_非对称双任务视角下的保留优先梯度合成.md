# ACL2026最新论文 ｜Modeling LLM Unlearning as an Asymmetric Two-Task Learning Problem ｜非对称双任务视角下的保留优先梯度合成

作者：Zeguan Xiao、Siqing Li、Yong Wang 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.14808)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_e3d8084c2f96)

> 大语言模型（LLM）遗忘面临的核心矛盾是：在移除敏感知识的同时，往往导致模型通用能力显著退化。现有方法多通过损失函数加权来平衡遗忘与保留目标，但忽略了两个目标在参数空间中的梯度方向冲突，导致“遗忘过度”或“保留失效”。本文提出将遗忘重构为以保留为主、遗忘为辅的非对称双任务学习问题，并引入符号对齐梯度优化（SignAlign Gradient Optimization, SAGO）机制。该方法通过逐元素门控确保更新方向不违背保留梯度，在WMDP和RWKU基准上显著提升了保留性能。其价值在于提供了比损失加权更精细的梯度几何控制，但实验仅覆盖文本LLM，未验证其在多模态或推理模型中的泛化性。

## 研究背景

当LLM执行遗忘任务时，模型参数需在两个方向上同时更新：降低遗忘集上的似然（遗忘梯度）与保持保留集上的性能（保留梯度）。这两个梯度在参数空间中常呈现方向对立，即“梯度冲突”。若直接采用损失加权求和（如GradDiff），冲突梯度会相互抵消或导致优化轨迹偏离，使得模型在遗忘目标知识的同时，意外破坏存储通用知识的参数区域。

LLM遗忘的主流路线是优化与梯度方法，其标准流程是构建“遗忘集-保留集”双目标优化框架。早期方法如梯度上升（GA）直接最大化遗忘集损失，但极易导致模型效用崩溃；负偏好优化（NPO）通过有界变换和自适应平滑缓解了GA的不稳定性，但仍需结合保留集正则化。然而，这些方法均将遗忘与保留视为对等目标，通过超参数$\gamma$和$\alpha$在损失层面进行静态权衡。这种“损失平衡”范式未能解决根本问题：即使损失权重调整得当，两个任务在特定参数维度上的梯度方向仍可能冲突，导致保留性能不可预测地下降。本文的切入点在于，将问题从“损失如何加权”转向“梯度如何合成”，主张保留梯度应作为锚点方向，遗忘梯度仅在不与保留冲突的维度上注入。

## 核心方法

### 非对称双任务优化框架

本文的参照系是标准的多任务学习（MTL）框架，但LLM遗忘具有根本的非对称性：保留是主任务，遗忘是受“不伤害”约束的辅助任务。标准MTL方法旨在平衡任务进度，而遗忘任务要求保留性能优先，遗忘效果其次。因此，本文构建了一个模块化框架，将任务特定的梯度提取与冲突感知的梯度合成解耦。该框架的核心在于，不再直接优化加权损失$L_{unlearn}(\theta) = \gamma L_f(D_f; \theta) + \alpha L_{GD}(D_r; \theta)$，而是分别计算遗忘梯度$g_f$和保留梯度$g_r$，然后通过一个可插拔的`COMBINEGRADIENTS`模块合成最终更新方向$g_{final}$。这一设计使得不同的冲突缓解策略可以无缝集成到同一优化流程中，避免了损失加权对超参数敏感性的依赖。

### 模块级投影与符号对齐门控

标准PCGrad（Project Conflicting Gradients）通过全局投影消除梯度冲突，但全局投影可能抑制那些虽与冲突相关但支持保留性能的梯度分量。本文首先将PCGrad改造为模块级投影，即对每个模块$j$独立检测冲突并投影，防止单模块冲突引发全局副作用。在此基础上，本文提出SAGO，其核心创新是引入逐元素符号对齐门控。SAGO将参数维度分为两类：符号对齐维度$S = \{i : g_f^i g_r^i \ge 0\}$和符号冲突维度$C = \{i : g_f^i g_r^i < 0\}$。在冲突维度上，SAGO完全抑制遗忘梯度，仅保留保留梯度；在对齐维度上，SAGO允许遗忘梯度通过。其合成公式为：

$$ \tilde{g}_f = g_f \odot I(g_f \odot g_r \ge 0), \quad \tilde{g}_r = g_r \odot I(g_f \odot g_r < 0) $$

$$ g_{final} = \alpha \tilde{g}_r + \gamma \tilde{g}_f $$

其中$\odot$表示逐元素乘法，$I(\cdot)$为指示函数。这一设计的动机是解决PCGrad中投影操作可能产生的“对抗性分量”：当$|\tilde{g}_f^i| > |g_r^i|$时，PCGrad的最终更新方向可能与保留梯度相反，而SAGO通过确保$g_{final}^i g_r^i \ge 0$对所有$i$成立，从几何上保证了更新方向永不违背保留信号。

## 实验评估

实验在WMDP（生物安全/网络安全）和RWKU（真实世界知识）两个基准上进行，骨干模型分别为Zephyr-7B和LLaMA3-8B。基线覆盖GA、NPO、SimNPO及其与GD的组合，以及GRU和BLUR等冲突缓解方法。缺失的强基线包括SAUL和OFMU等2026年的最新优化方法，这可能影响对SAGO绝对性能的评估。

| 方法 | WMDP Bio Forget ↓ | WMDP Bio MMLU ↑ | WMDP Cyber Forget ↓ | WMDP Cyber MMLU ↑ |
| :--- | :--- | :--- | :--- | :--- |
| SimNPO + GD | 26.1 | 26.7 | 31.4 | 51.4 |
| SimNPO + GD + PCGrad | 28.7 | 56.4 | 31.1 | 57.9 |
| SimNPO + GD + SAGO | 28.2 | 57.4 | 29.1 | 58.3 |

在WMDP Bio上，SAGO将MMLU从SimNPO+GD的26.7提升至57.4，而遗忘准确率仅从26.1微增至28.2。这一结果表明，SAGO在保持遗忘效果的同时，显著恢复了保留性能。与PCGrad相比，SAGO在MMLU上进一步提升1.0点，且遗忘准确率更低，验证了符号对齐门控优于正交投影。

消融实验显示，模块级PCGrad已优于全局PCGrad，但SAGO在保留性能上仍有显著优势。例如，在RWKU上，SAGO的Neighbor Set ROUGE-L比PCGrad高3.4-13.3点。这一差异源于SAGO的逐元素门控机制，能够更精细地保留支持通用知识的梯度分量，而PCGrad的全局投影可能误伤这些分量。

评估边界方面，本文仅使用MMLU和ROUGE-L作为保留指标，未包含对抗性攻击下的鲁棒性测试（如重学习攻击或Top-k采样泄露检测）。此外，实验未报告计算开销，模块级投影和逐元素门控是否导致显著的训练时间增加尚不明确。代码已开源，但超参数$\alpha$和$\gamma$的敏感性分析未在正文中详细展示。

## 关联研究分析

从方法设计看，SAGO与GradDiff和NPO的根本差异在于优化层面。GradDiff和NPO通过损失加权在标量层面平衡遗忘与保留，而SAGO在向量层面控制梯度方向。这一差异的根源在于任务特性：LLM遗忘中，保留性能对梯度方向的微小偏差极为敏感，损失加权无法捕捉参数维度间的局部冲突。SAGO的符号对齐机制直接针对这一敏感性，但这也意味着其效果高度依赖于保留梯度的质量。若保留集规模较小或噪声较大，保留梯度可能无法准确代表通用知识方向，SAGO的优势可能减弱。

从问题动机看，SAGO与SAUL和OFMU等2026年的方法处于同一优化路线，但侧重点不同。SAUL通过增广拉格朗日控制器自适应调整优化目标，OFMU通过双层优化显式优先处理遗忘集，而SAGO通过梯度几何约束确保保留优先。SAGO的优势在于其模块化设计，可无缝集成到现有遗忘目标中，而SAUL和OFMU需要重构整个优化流程。然而，SAGO未涉及遗忘深度的机制级擦除，其效果可能局限于输出级抑制，而非内部表征的知识移除。

## 总结

本文要解决的核心矛盾是LLM遗忘中梯度冲突导致的保留性能退化。现有方法通过损失加权平衡目标，但忽略了参数空间中的方向冲突，而SAGO通过非对称双任务框架和符号对齐门控，从几何层面确保更新方向不违背保留梯度。实验证明，SAGO在WMDP Bio上将MMLU从26.7提升至57.4，同时保持遗忘准确率在28.2。其边界在于仅验证了文本LLM，且未包含对抗性鲁棒性评估。当保留集规模缩小或噪声增大时，SAGO的符号对齐机制是否仍能准确识别通用知识方向，论文未给出回答。
