# ACL2026最新论文 ｜T⋆: Progressive Block Scaling for Masked Diffusion Language Models Through Trajectory Aware Reinforcement Learning ｜渐进式块扩展课程

作者：Hanchen Xia、Baoyou Chen、Yutang Ge 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_0947d2fc9489)

> 掩码扩散语言模型（MDLM）在扩大并行解码块大小以提升推理效率时，常遭遇策略崩溃与准确率骤降。现有直接强化学习对齐方法在大块场景下因条件上下文弱化导致优势估计方差过大，无法稳定优化。本文提出 T*，一种基于轨迹感知强化学习的渐进式块扩展课程，通过小到大逐步增加块大小并交替使用移位分区，实现高并行度下的稳定训练。该方法在数学推理基准上显著优于直接大块训练，但绝对性能仍受限于骨干模型规模，且未验证其在非数学任务上的泛化性。

## 研究背景

掩码扩散语言模型通过迭代去噪并行生成文本，其核心控制参数是块大小 $B$。块大小决定了单次去噪步骤中同时更新的 token 数量，直接权衡了并行效率与因果依赖强度。当 $B$ 较小时，模型行为接近自回归，推理稳定但延迟高；当 $B$ 较大时，并行度提升，但模型需在更弱的条件上下文下同时预测多个 token，导致置信度分布变平，采样噪声增大。

当前主流路线是将 MDLM 与强化学习对齐结合，以提升复杂推理能力。TRACERL 等轨迹感知方法将去噪过程视为多步决策，利用 TD/GAE 计算步级优势进行策略优化。然而，直接在大块检查点上应用此类 RL 方法时，由于初始策略处于低置信度状态，rollout 噪声大，优势估计方差高，极易引发策略崩溃。本文切入点在于识别出块大小扩展过程中的训练不稳定性根源，并提出一种课程学习策略，通过渐进式扩大块大小来平滑策略优化路径。

## 核心方法

### 轨迹感知强化学习参照系

本文基于 TRACERL 框架，将扩散解码视为多步去噪轨迹 $\tau = \tau^{(1)} \cup \dots \cup \tau^{(T)}$。每个新确定的 token 视为动作 $o = (i, \hat{x}_i)$，策略 $\pi_\theta(o | \tau_{<t}, Q)$ 预测该动作概率。优化目标采用 PPO 形式，结合 KL 散度惩罚防止策略漂移。该参照系的关键差异在于，本文不固定块大小，而是将块大小 $B$ 作为随训练阶段变化的超参数，从而引入动态的决策空间维度。

### 渐进式块扩展与移位分区

直接在大块上训练 RL 策略会因弱条件上下文导致崩溃。T* 采用阶段式课程，从初始块大小 $B_0$ 开始，每阶段固定 $B$ 进行 $K_B$ 次更新，随后将 $B$ 翻倍。为缓解对固定块边界的敏感性，引入移位分区 $P_B^\Delta$，其中偏移量 $\Delta = B/2$。标准分区 $P_B^0$ 将响应序列划分为连续块，而移位分区将每个块边界右移 $\Delta$ 个 token。

$$
I_m^\Delta = \{(m-1)B + \Delta + 1, \dots, \min(mB + \Delta, L)\}
$$

该公式定义了移位分区中第 $m$ 个块的索引范围，其物理含义是通过错开块边界，使模型在训练过程中接触不同的上下文分割方式，避免过拟合于特定的块结构。在每个更新步骤中，策略分别在标准分区和移位分区下各进行一次 TRACERL 更新。这种交替机制迫使策略学习对块边界不敏感的通用去噪能力，而非依赖特定的分块模式。

## 实验评估

实验在 MATH500、GSM8K 和 AIME24 上进行，采用 Pass@3 指标。基线包括原始 SDAR 检查点（Base）和直接应用 TRACERL 的大块模型（TraceRL）。本文方法 T* 在 1.7B 和 4B 规模的 SDAR 模型上验证。

| 模型规模 | 块大小 | 方法 | MATH500 | GSM8K | AIME24 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1.7B | 16 | Base | 52.4 | - | - |
| 1.7B | 16 | TraceRL | - | - | - |
| 1.7B | 16 | T* | 82.5 | 81.0 | 7.5 |
| 4B | 16 | Base | - | - | - |
| 4B | 16 | T* | - | - | - |

注：表格中部分数值在原文 Figure 2 中呈现，此处仅列出可明确定位的 T* 1.7B B=16 结果。据领域综述，TraceRL 在 GSM8K 上可达 91.2，但本文协议为 Pass@3 且骨干不同，直接对比需谨慎。

T* 在 1.7B 模型上，B=16 时 MATH500 准确率达 82.5，显著高于 Base 的 52.4。训练曲线显示，直接 TRACERL 在 B=8 阶段出现从 56% 到 40% 的骤降，而 T* 保持平稳。消融分析表明，移位分区对稳定性有贡献，但主要增益来自渐进式块扩展本身。

评估边界方面，本文仅报告 Pass@3，未提供 Pass@1 或 Exact Match，可能掩盖单次解码质量差异。代码未公开，超参数如 $K_B$ 未详细列出，可复现性受限。

## 关联研究分析

从问题动机看，本文聚焦于块大小扩展时的训练稳定性，而 SPG 等方法关注采样策略本身的偏差修正。SPG 通过掩码感知策略梯度直接优化采样分布，试图在固定块大小下提升质量；本文则通过改变训练轨迹（渐进块扩展）来规避大块下的优化困难。这种差异源于对误差累积根源的不同假设：SPG 认为误差主要来自采样偏差，本文认为主要来自训练过程中的策略崩溃。

从方法设计看，本文与 DISPO 同属轨迹感知 RL 框架，但 DISPO 通过分支重采样实现细粒度信用分配，而本文通过课程学习实现宏观稳定性。DISPO 在 MATH500 上报告 35.8（据领域综述），低于本文 T* 的 82.5，但两者骨干模型和评估协议不同。本文未对比 DISPO，构成潜在盲区。此外，本文未探索非数学任务，如代码生成或常识推理，其渐进课程在这些任务上的有效性未知。

## 总结

本文核心矛盾是 MDLM 扩大块大小时的训练不稳定性与并行效率需求之间的冲突。现有直接 RL 方法在大块下因弱条件上下文导致崩溃，本文通过渐进式块扩展课程，利用小模型策略作为大模型初始值，平滑优化路径。T* 在 1.7B 模型上实现 MATH500 82.5 和 GSM8K 81.0 的准确率，显著优于直接大块训练。其边界在于仅验证了数学推理任务，且 Pass@3 指标可能高估单次解码质量。当块大小扩展到 32 或更大时，渐进课程的边际收益是否递减，论文未给出回答。
