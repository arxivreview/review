【Evaluation Pitfalls and Challenges in Multimedia Event Extraction ｜多媒体事件抽取评估陷阱与严格框架

作者：Philipp Seeberger、Steffen Freisinger、Tobias Bocklet 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.26775)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.26775)

> 多媒体事件抽取（MEE）旨在从文本与图像中联合识别事件及其参数，但现有研究普遍依赖宽松的数据处理与匹配协议，导致性能指标严重虚高。本文切入点在于系统审计 M2E2 基准中的隐藏评估缺陷，指出当前 SOTA 结果可能源于数据泄露或 Oracle 后处理而非模型能力。作者提出 STRICTEVAL 框架，通过强制一致的数据使用、明确的任务定义及严格的匹配约束，重新量化了现有方法的真实表现。该工作揭示了评估体系对领域进展的误导性，但仅针对 M2E2 单一基准，未验证其在其他多模态数据集上的普适性。

【EXCEEDS: Extracting Complex Events via Nugget-based Grid Modeling in Scientific Domain ｜科学域复杂事件抽取的网格建模

研究机构：北京理工大学、微软研究院

作者：Yi-Fan Lu、Xian-Ling Mao、Bo Wang 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2406.14075)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_6b405cd0a96b)

> 科学文献摘要中事件密度高且结构复杂，传统扁平化Schema与句子级抽取方法无法处理层级嵌套与不连续论元。现有生成式或判别式模型在密集多事件交互下性能显著下降，本文切入点在于将事件抽取重构为词对关系网格预测任务。通过构建Word-Word Event Grid并引入2D卷积细化，EXCEEDS实现了端到端的复杂结构统一建模。该方法在SciEvents基准上取得了SOTA性能，但其非LLM骨干在开放域泛化上的竞争力存疑。

【HTMR: Hybrid Token Masking Reinforcement Learning with Verifiable Rewards for Event Argument Extraction with Multi-Perspective Reasoning ｜混合令牌掩码强化学习

作者：Jianwen Luo、Yongkang Jin、Yu Hong 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_29050fad61c8)

> 事件论元抽取（Event Argument Extraction, EAE）要求模型在预定义模式（Schema）下准确识别实体并分配语义角色，但现有基于大语言模型（LLM）的强化学习框架存在序列级奖励与令牌级优化粒度错位的根本缺陷。该错位导致无关令牌获得同等梯度信号，稀释了关键决策点的学习强度。本文提出混合令牌掩码强化学习（Hybrid Token Masking RLVR, HTMR），通过联合高熵分叉令牌与事件关键令牌的选择性策略更新，将学习信号锚定在定义事件结构的决策上。该方法在多个基准上显著优于全令牌与仅高熵令牌基线，但其对复杂嵌套结构的覆盖能力及文档级泛化性仍存疑。

【Suggest-Verify-Revise: A Three-Stage Document-Level Event Causality Identification with Narrative Consistency ｜叙事一致性约束下的文档级事件因果识别

作者：Ya Su、Hu Zhang、Dan Qiao 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_c20bbfcc08ed)

> 文档级事件因果识别（DECI）旨在从非结构化文本中判定任意两事件间是否存在因果依赖，其核心难点在于事件信息跨句分布导致的上下文缺失与多因多果结构的角色混淆。现有方法多将事件对视为独立样本进行局部语义判别，忽视了文档整体叙事骨干对因果传播的全局约束，导致跨句因果识别精度显著低于句内。SVRECI 提出“建议-验证-修正”三阶段框架，将LLM启发式建议与超图结构建议融合，引入拓扑霍克斯过程（THP）进行叙事一致性验证，并通过双级对比学习动态修正因果图。该方法在EventStoryLine和Causal-TimeBank基准上取得SOTA，但其性能增益高度依赖迭代修正机制，且对缺乏显式时间标注的文档存在时序噪声敏感性。

【UERLens: Understanding Event Relations in Large Language Models ｜事件关系内部表示的可解释性分析

作者：Yong Guan、Zhiyuan Li、Shaoru Guo

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_9ef8bf2f817c)

> 事件关系抽取（Event Relation Extraction, ERE）旨在从文本中识别事件间的因果、时序及子事件依赖，但大语言模型（LLM）在此任务上的推理过程长期处于黑盒状态，现有研究多聚焦于性能优化而忽视了内部机制的解析。本文切入点在于验证 LLM 是否通过特定的内部特征编码事件关系，并探究这些特征的功能性作用。通过构建反事实数据集、利用稀疏自编码器（Sparse Auto-Encoder, SAE）识别关系敏感特征，并结合模型干预与训练进行因果验证，UERLens 揭示了事件关系在 LLM 中间层的具体表征形式。该框架证明了内部特征对 ERE 性能具有显著影响，但受限于单一骨干模型与静态文本场景，其结论的普适性仍存疑。

】
