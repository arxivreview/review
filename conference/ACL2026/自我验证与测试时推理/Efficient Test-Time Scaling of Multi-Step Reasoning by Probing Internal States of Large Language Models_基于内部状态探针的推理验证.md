# ACL2026最新论文 ｜Efficient Test-Time Scaling of Multi-Step Reasoning by Probing Internal States of Large Language Models ｜基于内部状态探针的推理验证

研究机构：新加坡国立大学、澳大利亚墨尔本大学

作者：Jingwei Ni、Ekaterina Fadeeva、Tianyi Wu 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.06209)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.06209)

> 测试时计算扩展（Test-Time Scaling, TTS）旨在通过增加推理时的计算资源来提升大语言模型（LLMs）在复杂任务中的表现，其核心瓶颈在于如何高效地从多条候选推理路径中筛选出正确解。现有主流方案依赖过程奖励模型（Process Reward Models, PRMs），但这类模型参数量大、训练数据获取昂贵且域泛化能力差，导致验证成本高昂。本文提出 ReProbe，一种挂载于冻结 LLM 之上的轻量级探针，直接利用模型内部隐藏状态、注意力权重和 Logits 进行步骤级正确性评估。该方法以极低的参数成本实现了与大型 PRM 相当甚至更优的跨域验证性能，但其自监督标注机制在缺乏外部真值场景下的可靠性仍存疑。

## 研究背景

当 LLM 执行多步推理时，早期步骤的微小偏差会级联传播，导致最终答案失效。为缓解这一问题，测试时计算扩展（TTS）通过采样多条推理路径并依赖评分器引导选择，成为提升性能的关键范式。然而，当前主流的步骤验证手段是过程奖励模型（PRMs），它们通常由独立的 1.5B-8B 参数 LLM 实现，需要对生成的文本 Token 进行重新编码。这种架构不仅带来了显著的推理延迟和 GPU 内存开销，还因训练数据多局限于数学等特定领域，导致其在规划、问答等开放域任务中泛化能力严重不足。

PRM 的局限性促使研究者探索更高效的验证机制。不确定性量化（Uncertainty Quantification, UQ）方法虽轻量，但无监督统计量在区分推理错误时效力有限。与此同时，已有研究表明 LLM 内部状态蕴含丰富的可靠性信号，可用于幻觉检测。ReProbe 的切入点在于将这一“内部状态蕴含正确性信号”的假设从幻觉检测迁移至多步推理验证，通过训练一个极轻量的分类器直接读取生成过程中的中间特征，从而绕过文本重编码的高昂成本，解决 PRM 在计算效率与域泛化上的双重瓶颈。

## 核心方法

### 方法参照系

本文问题归属于推理验证机制路线，标准流程为：生成多条 CoT 轨迹 → 评分器对每步打分 → 选择最优路径。与 PRM 的关键差异在于输入模态：PRM 输入为生成的文本 Token，需独立 LLM 前向传播；ReProbe 输入为冻结 LLM 解码时已计算好的内部状态（注意力、Logits、隐藏状态），仅需轻量 Transformer 探针，无需额外生成器前向传播。

### 特征提取与探针架构

设计动机在于消除 PRM 对文本重编码的依赖，利用生成过程中“免费”获得的内部信号。ReProbe 定义特征提取器 $F(\mathbf{x}, \mathbf{r}_{1:t-1}, \mathbf{r}_t)$，从每个 Token 位置提取两类特征：(1) 前 5 个 Token 的全层注意力权重与 Top-K Logits；(2) 全层隐藏状态。这些特征经线性投影层调整维度后，输入 $L$ 层 Transformer 编码器以捕捉上下文依赖：

$$ \mathbf{h}_l = \text{Transformer}_l(\mathbf{h}_{l-1}), \quad l = 1, \dots, L $$

该公式的物理含义是：通过自注意力机制聚合当前步骤内所有 Token 的内部状态信息，形成富含语义与置信度信息的步骤级表示。随后，通过池化操作将 Token 级特征 $\mathbf{h}_L^{[\tau]}$ 聚合为步骤级向量，并送入两层分类网络输出正确性概率。这一设计使得验证器能够内省式地评估推理步骤，而非依赖外部文本知识。

### 自监督数据构建与训练

设计动机在于解决 PRM 训练数据获取昂贵（需人工标注或 Monte-Carlo 采样）的问题。ReProbe 采用自监督策略：目标 LLM 生成 3 条 CoT 轨迹，由同一 LLM 或外部大模型（如 DeepSeek-R1）对每步正确性进行标注。训练目标为标准二元交叉熵损失，仅更新探针参数，LLM 保持冻结：

$$ \mathcal{L} = -\sum_{i} [y_i \log \hat{y}_i + (1-y_i) \log (1-\hat{y}_i)] $$

该公式表明，探针学习的是内部状态与步骤正确性标签之间的映射关系。由于训练数据来自同一生成过程，验证器与生成器分布一致，避免了域偏移。实验显示，仅需 32K 样本、$200 标注成本和 4 GH200 GPU-hours 即可完成训练，极大降低了验证器的部署门槛。

## 实验评估

实验在 Qwen3-8B（非思考模式）及 Qwen3-1.7B/32B（原生思考模式）上进行，覆盖数学（MATH, GSM8K, ProofNet）、规划（Trips, Meetings, Calendar）和问答（StrQA, SciQA）三类任务。基线包括无监督 UQ 方法、1.5B 小型 PRM 及 7-8B 大型 PRM（如 Qwen2.5-Math-PRM-7B）。在步骤级正确性评估（PR-AUC）中，ReProbe 在域外（OOD）任务上显著超越所有 PRM 基线，例如在 StrQA 上达到 0.617，而最强 PRM 仅为 0.594；在域内（ID）数学任务上，ReProbe 与最强 PRM 性能持平或略低，如 GSM8K 上 ReProbe 为 0.673，Qwen2.5-Math-PRM-7B 为 0.702。

| 方法 | 参数量 | GSM8K (ID) PR-AUC | StrQA (OOD) PR-AUC | 训练样本 |
|---|---|---|---|---|
| Qwen2.5-Math-PRM-7B | 7B | 0.702 | 0.594 | 860K |
| ReProbe (Hidden States, DeepSeek-anno) | <10M | 0.673 | 0.617 | 32K |
| ReProbe (Attn+Logit, Self-anno) | <10M | 0.594 | 0.559 | 32K |

在 Best-of-N 测试时扩展中，ReProbe 在多数数据集上取得最佳性能，使 Qwen3-8B 在 MATH、GSM8K 等基准上超越其 14B 版本。消融实验显示，数据多样性对性能影响显著：使用多样化 2K 问题子集训练的 ReProbe 在整体 PR-AUC 上优于同质子集。此外，ReProbe 与 PRM 分数联合输入逻辑回归模型可进一步提升步骤级 PR-AUC，表明内部状态信号与外部文本知识具有互补性。

评估边界方面，论文未报告置信区间，且 ID 任务上 ReProbe 略低于最强 PRM，可能源于 PRM 对数学域的过拟合。可复现性良好，代码已开源，训练成本极低。但自监督标注在缺乏外部真值的开放域任务中的可靠性未充分验证，且探针依赖生成器内部状态稳定性，若生成器更新需重新训练。

## 关联研究分析

从方法设计看，ReProbe 与 HSRM（Li and Zhu, 2026）同属隐藏状态验证路线，但 ReProbe 更强调特征多样性（注意力+Logits+隐藏状态）与自监督数据构建，而 HSRM 侧重复用解码过程隐藏状态进行 Best-of-N 选择。ReProbe 在 OOD 任务上的优势可能源于其多特征融合机制能捕捉更丰富的正确性信号，而 HSRM 的单一隐藏状态输入在跨域场景下可能信息不足。这一差异暗示，内部状态验证的有效性不仅取决于特征来源，还取决于特征提取的粒度与多样性。

从问题动机看，ReProbe 与 NCV（Zhang et al., 2025）均旨在解决错误定位粒度不足问题，但 NCV 采用节点级一致性检查，无需训练，可解释性强；ReProbe 则依赖有监督探针，可解释性低但泛化性强。NCV 在 ProcessBench 上 F1 分数达 88.5%，高于 ReProbe 的 86.2%，表明结构化检查在特定错误定位任务中更优。然而，ReProbe 在测试时扩展（TTS）中的端到端性能更优，说明验证机制的选择需权衡错误定位精度与路径选择效率。ReProbe 的自监督机制是否引入系统性偏见，导致验证器与生成器共谋，论文未给出回答。

## 总结

ReProbe 旨在解决 PRM 在测试时扩展中计算成本高与域泛化差的核心矛盾，其切入点在于利用 LLM 内部状态中蕴含的正确性信号，通过轻量级探针实现高效步骤验证。该方法以 <10M 参数和 32K 样本训练，在 OOD 任务上 PR-AUC 超越 7B PRM，在 TTS 中使 8B 模型性能超越 14B 模型。其边界在于 ID 任务上略逊于最强 PRM，且自监督标注在缺乏外部真值场景下的可靠性未充分验证。当生成器内部状态分布发生漂移时，探针的验证性能是否仍能保持稳定，论文未给出回答。
