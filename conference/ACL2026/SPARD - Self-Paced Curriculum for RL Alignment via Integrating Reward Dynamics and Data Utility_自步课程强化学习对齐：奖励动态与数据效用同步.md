作者：Xuyang Zhi、Peilun zhou、Chengqiang Lu 等 13 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.07837)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.07837)

> 开放域大语言模型后训练面临多目标奖励信号的非平稳性挑战，静态权重聚合导致优化资源错配。现有方法或忽略数据异质性，或依赖固定课程计划，无法实时响应模型能力演化。SPARD 通过感知学习进度，动态调整奖励权重并同步重平衡数据效用，实现自步课程学习。该方法在开放域生成任务上展现了优势，但其对主观奖励信号的依赖及在可验证任务上的表现仍存疑。

## 研究背景

开放域生成任务要求模型同时满足指令遵循、事实准确性与文本流畅性等多维标准。这些标准由 LLM Judge 评分构成多维奖励向量，但不同维度的收敛速率存在异步性：部分能力迅速饱和，而另一些仍处于快速提升期。若采用固定权重聚合这些信号，模型将过度优化已饱和维度，忽视瓶颈维度，导致整体性能停滞。

传统强化学习对齐范式多聚焦于单一可验证奖励（RLVR），如数学或代码任务，其奖励信号客观且稳定。然而，随着应用场景向通用对话与深度研究扩展，奖励定义演变为多目标框架。现有解决方案分为两类：一是隐式合成，如 RaR 和 MPO，将多维标准合并为单一提示，虽简化流程但掩盖了监督信号的粒度；二是动态策略，如 DRBO 和 MDO，优先优化低分目标，但忽略了数据异质性，即同一数据样本对不同维度的信息量差异。此外，Rubicon 和 Omni-Thinker 采用静态课程学习，从强约束任务过渡到弱约束生成，但缺乏对模型实时能力演化的适应能力。SPARD 的切入点在于将奖励动态与数据效用视为耦合系统，通过在线感知学习进度，实现优化方向与数据供给的实时同步。

## 核心方法

### 方法参照系

本文基于组相对策略优化（GRPO）构建，利用组内统计量估计优势函数，无需 Critic 网络。与标准 GRPO 使用单一标量奖励不同，SPARD 处理的是由 $N$ 个 LLM Judge 评分构成的多维奖励向量 $\mathbf{r}(y)$，核心差异在于如何动态聚合这些维度并选择高效数据样本。

### 进度感知权重自适应

静态权重无法区分停滞维度与活跃前沿，导致梯度分配低效。SPARD 引入进度感知权重自适应（PAWA），将奖励权重更新建模为带 KL 正则化的在线镜像下降问题。首先，利用下置信界（LCB）原则计算第 $i$ 个奖励维度的可靠性能增益 $Q_t^{[i]}$，以过滤瞬时噪声：

$$ Q_t^{[i]} = \mu_t^{[i]} - \beta \sigma_t^{[i]} $$

其中 $\mu_t^{[i]}$ 和 $\sigma_t^{[i]}$ 为奖励分量的指数移动平均（EMA）均值与标准差，$\beta$ 为不确定性惩罚系数。仅当均值增益超过变异性时，$Q_t^{[i]}$ 为正，表明该维度存在稳健的学习潜力。随后，通过指数梯度更新规则调整权重向量 $\mathbf{w}_t^{[r]}$，使优化预算流向高增长维度，同时 KL 约束防止权重突变导致的训练不稳定。

### 奖励归因数据重平衡

奖励权重决定了优化方向，但数据效用决定了轨迹效率。SPARD 提出奖励归因数据重平衡（RADR），通过构建归因矩阵 $F \in \mathbb{R}^{N \times M}$ 量化数据类别对奖励维度的敏感度。对于类别 $c_j$ 中的提示 $b$，计算 $G$ 个候选响应的平均绝对偏差（MAD）作为得分分离度：

$$ F_{ij} = \frac{1}{|B_j|} \sum_{b \in B_j} \frac{1}{G} \sum_{g=1}^G |r_i(y_g) - \bar{r}_i(b)| $$

较大的 $F_{ij}$ 表示类别 $c_j$ 为奖励 $i$ 提供了高对比度监督信号。通过温度控制的 Boltzmann 归一化将 $F$ 转化为分布，再与当前奖励权重 $\mathbf{w}_t^{[r]}$ 进行矩阵乘积，得到目标数据重要性向量 $\mathbf{u}$。最终，通过 EMA 更新全局数据权重 $\mathbf{w}_t^{[d]}$，并在 GRPO 损失中对不同类别的样本进行加权，确保梯度更新主要由当前阶段边际增益最大的数据驱动。

## 实验评估

实验基于 Qwen2.5-7B-Instruct 和 Qwen3-8B 模型，使用 5.4k 条 WildChat-IF 子集提示，分为代码、知识问答、文本转换和创意写作四类。基线包括 SFT、DPO 及三种 GRPO 变体（GRPOrm、GRPOimp、GRPOavg）。评估基准涵盖通用能力（IFEval, GPQA, LCB）、创意写作（Arena-Hard, CW）及对话（MT-Bench, WildBench）。

SPARD 在 Qwen2.5-7B-Instruct 上平均得分 50.03，显著优于 GRPOavg 的 48.46 和基线模型的 46.12。在 Qwen3-8B 上，SPARD 平均得分 63.69，同样领先于 GRPOavg 的 62.17。值得注意的是，SFT 导致 IFEval 从 70.79 降至 59.70，验证了分布偏移对通用能力的损害，而 SPARD 通过动态平衡避免了此类退化。

消融实验显示，移除 PAWA 或 RADR 均导致性能下降，其中移除 RADR 对 GPQA 的影响最大（38.38 降至 36.36），表明数据重平衡对科学推理任务至关重要。移除 PAWA 则主要影响创意写作和对话指标，证实了动态奖励权重在主观任务上的价值。

评估边界方面，论文未报告置信区间，且主要依赖 LLM Judge 评分，缺乏人工评估对比。代码未公开，超参数（$\alpha=0.5, \beta=0.1, \mu=0.1, \eta=3$）虽列出，但缺乏不同规模模型下的敏感性分析。此外，实验未包含 MATH 或 AIME 等可验证推理基准，限制了结论在客观任务上的泛化性。

## 关联研究分析

从问题动机看，SPARD 与 Rubicon 和 Omni-Thinker 同属课程学习路线，但后者采用静态阶段划分，而 SPARD 基于在线学习进度实现自步调度。这一差异源于开放域任务中能力收敛的非线性特性：静态计划无法预知模型何时在特定维度达到瓶颈，而 SPARD 通过 LCB 增益信号实时检测“活跃前沿”，避免了在已饱和维度上的无效计算。然而，这种依赖 LLM Judge 评分的机制在奖励信号本身存在偏差时，可能导致课程调度偏离真实能力边界，论文未对此进行鲁棒性测试。

从方法设计看，SPARD 与 ASFT 和 GIFT 等 SFT-RL 混合方法形成对比。ASFT 通过重要性采样修正 SFT 的离策略偏差，GIFT 通过吉布斯分布初始化优化 RL 探索，两者均聚焦于 SFT 与 RL 阶段的衔接。SPARD 则完全摒弃 SFT 冷启动，直接从 Instruct 模型开始 RL 训练，其核心创新在于多目标奖励的动态聚合而非阶段过渡。这种设计选择暗示了对于已具备基础指令遵循能力的 Instruct 模型，SFT 的边际收益可能低于多目标 RL 的探索收益，但论文未提供 SFT+SPARD 的对比实验来验证这一假设。

## 总结

SPARD 旨在解决开放域多目标 RL 对齐中静态权重导致的优化资源错配问题。通过引入进度感知权重自适应和奖励归因数据重平衡，SPARD 实现了奖励动态与数据效用的实时同步，在 Qwen2.5-7B-Instruct 上将平均性能从 46.12 提升至 50.03。然而，其有效性高度依赖 LLM Judge 评分的准确性，且在可验证推理任务上的表现未经验证。当奖励信号本身存在系统性偏差时，基于 LCB 增益的课程调度是否仍能引导模型向真实能力边界收敛，论文未给出回答。
