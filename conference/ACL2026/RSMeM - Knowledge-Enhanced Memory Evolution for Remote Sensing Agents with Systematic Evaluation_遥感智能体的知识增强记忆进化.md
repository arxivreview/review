# ACL2026最新论文 ｜RSMeM: Knowledge-Enhanced Memory Evolution for Remote Sensing Agents with Systematic Evaluation ｜遥感智能体的知识增强记忆进化

作者：Bingxian Wu、Yu Zhang、Zonghao Guo 等 13 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_275533fec3a7)

> 遥感智能体在处理多光谱与地球产品分析时，常因缺乏领域知识导致工具调用链断裂，且执行失败无法转化为可复用的经验。现有通用智能体依赖静态专家模板或纯反思机制，前者维护成本高且僵化，后者在无领域先验时易误诊错误。RSMeM 通过离线构建层级知识库与在线失败感知记忆进化双流机制，将任务级领域知识转化为实例级执行约束。该框架在垂直领域内显著提升了工具调用准确性，但其对骨干模型能力的依赖及缺乏通用基准验证，限制了其作为通用深度研究智能体组件的普适性。

## 研究背景

遥感分析涉及复杂的光谱交互与多步骤工具调用，大语言模型（LLM）在此类任务中面临两大核心挑战：一是领域概念（如 NDVI、地表温度）的语义理解偏差导致规划错误；二是长程执行中的上下文遗忘，使得早期关键证据在后续步骤中丢失。解决这些问题的关键在于建立一种机制，既能提供结构化的领域先验，又能从执行失败中动态提取纠错经验。

通用深度研究智能体（DRA）通常采用 ReAct 范式，通过“推理-行动-观察”循环处理开放式任务。然而，在遥感垂直领域，通用 DRA 的长程记忆机制往往失效，因为缺乏领域特定的失败模式定义，导致反思生成的纠错指令过于泛化，无法修复具体的工具参数错误。主流路线分为两类：一类是依赖专家编写的静态工作流模板，如 RS-Agent，这类方法在模板匹配时有效，但构建与维护成本极高，且无法适应未见过的任务变体；另一类是基于 Reflexion 的纯语言反思，虽然无需额外训练，但在缺乏领域知识的情况下，智能体常误诊失败原因，导致纠错无效。RSMeM 的切入点在于将领域知识结构化并注入记忆进化过程，使智能体在离线阶段获得任务级指导，在线阶段通过失败感知机制将执行轨迹蒸馏为实例级约束，从而在无需端到端强化学习（RL）训练的前提下，实现工具调用策略的迭代优化。

## 核心方法

### 方法参照系

RSMeM 基于 ReAct 智能体架构，其核心差异在于引入了离线层级知识库与在线失败感知记忆的双流检索机制。与通用 DRA 依赖单一语义检索不同，RSMeM 将领域知识显式编码为层级任务卡，并通过符号化批评器筛选失败轨迹，实现了从“通用语义匹配”到“领域结构感知”的转变。

### 层级知识接地（HKG）

HKG 解决的是通用检索在专业术语稀疏场景下的失效问题。传统语义嵌入对遥感特有术语（如 TVDI、发射率）表征不足，导致检索结果偏离任务需求。RSMeM 构建了一个包含 3 个应用领域、12 个子域和 64 个原子任务的层级知识库，每个任务封装为包含标题、定义和执行提示的任务卡。检索采用混合评分函数，结合神经相似度与词汇重叠信号：

$$
\text{Score}(q, s_i) = \cos(v_q, v_i) + \alpha \cdot \mathbb{1}_T(q, T_i) + \beta \cdot \sum_{j=1}^{m} \mathbb{1}_K(q, k_j) + \gamma \cdot \mathbb{1}_C(q, S_i)
$$

其中 $\alpha=0.2, \beta=0.08, \gamma=0.1$ 为词汇奖励权重，$\mathbb{1}$ 为指示函数。该公式通过显式加权任务标题、领域关键词及内容重叠，补偿了嵌入空间对专业术语的表征缺陷，确保检索到的任务卡能精准指导 LLM 的工具选择与规划。

### 失败感知经验精炼（FAR）

FAR 解决的是纯语言反思在缺乏领域先验时误诊错误的问题。通用 Reflexion 机制依赖 LLM 自我评估，但在遥感任务中，错误往往源于特定的工具参数配置或数据格式问题，LLM 难以仅凭文本反思识别这些细微差异。RSMeM 引入符号化批评器 $\Omega$，应用一组启发式规则 $R$ 检测轨迹中的特定失败模式（如缺失答案标签、空响应、无效选项等）：

$$
\text{Issue}(a_i^{(t)}) = \exists \rho \in R \text{ s.t. } \rho(a_i^{(t)}) = I
$$

一旦检测到失败，反思生成器将原始查询、HKG 上下文及压缩后的轨迹作为输入，生成 3-5 句的结构化诊断与纠错计划，并追加至失败感知记忆（FAM）。FAM 采用实例索引查找，确保后续重试时仅检索当前实例的最新反思，避免无关失败模式的干扰。这种机制将执行失败转化为可复用的程序性约束，使智能体在迭代中逐步修正工具调用轨迹。

## 实验评估

实验基于 EarthBench 基准，包含 248 个专家标注实例，涵盖 RGB、光谱及地球产品三种模态。基线包括 EarthAgent（无记忆增强）及 Reflexion（纯语言反思）。RSMeM 在 DeepSeek-V3.2 骨干上，将端到端准确率从 51.82% 提升至 57.89%，绝对提升 6.07 个百分点，而 Token 开销仅从 6.23% 增至 6.97%。

| 骨干模型 | 方法 | 配置 | AO (%) | IO (%) | EM (%) | Acc (%) | Tok. (%) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| DeepSeek-V3.2 | EarthAgent | R@3 | 78.02 | 55.47 | 27.25 | 51.82 | 6.23 |
| DeepSeek-V3.2 | RSMeM | R@3 | 79.20 | 55.49 | 27.01 | 57.89 | 6.97 |
| Qwen3-8B | EarthAgent | R@3 | 46.68 | 26.80 | 8.81 | 44.94 | 5.58 |
| Qwen3-8B | RSMeM | R@3 | 46.94 | 30.75 | 13.88 | 48.58 | 6.07 |

消融实验显示，HKG 主要提升全局工具覆盖率（AO），而 FAR 显著增强轨迹鲁棒性（WS 从 0.0408 升至 0.0763）。值得注意的是，单独使用 FAR 在 Qwen3-8B 上提升了 7.71 个百分点准确率，但 RSMeM 全框架仅额外提升 2.43 个百分点，表明在弱骨干模型上，失败反思的边际收益高于知识接地。

评估协议采用 R@3 聚合，即未解决实例在后续轮次重跑，最终准确率按最新成功尝试反向覆盖。该协议掩盖了单次尝试的失败率，且未报告置信区间。代码与模型声明将开源，但论文未提供具体 URL 及 GPU 资源需求，可复现性存在不确定性。

## 关联研究分析

从问题动机看，RSMeM 与 ASearcher 等端到端 RL 路线形成鲜明对比。ASearcher 依赖大规模 RL 训练优化搜索策略，适用于通用长程任务，但训练成本极高且难以迁移至垂直领域。RSMeM 采用训练-free 的记忆进化机制，通过离线知识蒸馏与在线失败反思实现策略优化，其优势在于低边际成本与领域特异性，但劣势在于依赖骨干模型的推理能力，无法像 RL 那样通过梯度更新挖掘模型潜在能力。

从方法设计看，RSMeM 的符号化批评器与 Reflexion 的纯语言反思存在本质差异。Reflexion 依赖 LLM 自我评估生成反思，易受模型幻觉影响；RSMeM 引入启发式规则检测特定失败模式，提高了诊断的确定性。然而，这种符号化规则需针对特定任务手动设计，缺乏通用性。当面对未见过的失败模式时，RSMeM 的批评器可能失效，而 Reflexion 虽不精准但具备泛化潜力。

## 总结

RSMeM 旨在解决遥感智能体在长程工具调用中因领域知识缺失与失败经验不可复用导致的执行漂移问题。其切入点在于将领域知识结构化并注入记忆进化过程，通过层级知识接地与失败感知经验精炼的双流机制，实现从任务级知识到实例级约束的转化。实验表明，该框架在 DeepSeek-V3.2 上提升了 6.07 个百分点准确率，且 Token 开销增加不足 1%。然而，其性能高度依赖骨干模型的推理能力，且在弱骨干上知识接地的边际收益有限。当骨干模型能力不足时，符号化批评器能否有效识别非标准失败模式，论文未给出回答。
