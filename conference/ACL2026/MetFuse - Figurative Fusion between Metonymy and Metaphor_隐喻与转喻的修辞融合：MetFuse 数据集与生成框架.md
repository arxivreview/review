# ACL2026最新论文 ｜MetFuse: Figurative Fusion between Metonymy and Metaphor ｜隐喻与转喻的修辞融合：MetFuse 数据集与生成框架

作者：Saptarshi Ghosh、Tianyu Jiang

论文原文见 [arXiv](https://arxiv.org/abs/2604.12919)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_8dfd40431809)

> 导读 修辞语言处理长期将隐喻与转喻视为独立现象，分别建模其跨域映射与域内指称转移，却忽视了二者在自然语言中高频共现的“修辞融合”结构。现有分类方法因缺乏包含两种修辞共现的标注数据，难以捕捉隐喻动词对转喻名词显性化的认知压力，导致细粒度分类性能受限。本文提出一套字面句到修辞变体的三步生成框架，构建首个包含 1,000 组四元组的 MetFuse 数据集，并通过数据增强验证混合修辞对下游分类任务的提升作用。该工作填补了修辞交互的数据空白，但其绝对性能远低于当前 SOTA，且未评估 LLM 在零样本设置下对混合修辞的直接利用能力。

## 研究背景

当模型面对“The stadium erupted with joy”这类句子时，需同时处理名词 stadium 的域内指称转移（转喻）与动词 erupted 的跨域映射（隐喻）。转喻映射受限于预存邻近关系（如部分-整体、容器-内容），保持域连续性；隐喻则涉及两个离散域的概念跳跃，结构上更自由（Lakoff and Johnson, 1980）。这种结构差异导致二者在认知加工上并非独立：隐喻动词的跨域选择偏好（如要求有生施事主语）会对转喻名词施加解析压力，迫使读者将 stadium 显性解析为 fans，而非停留在字面地点意义。

修辞类型间的边界模糊是细粒度分类的核心瓶颈。现有计算工作主要将转喻解析建模为二分类任务（Markert and Nissim, 2007; Gritta et al., 2017），隐喻识别则依赖静态上下文表示（Steen, 2010; Mohammad et al., 2016），二者在数据层面完全隔离。这种隔离源于缺乏同时包含两种修辞的标注资源：早期语言学理论（Goossens, 1990; Barcelona, 2003）虽探讨了二者的语境交互，但受限于数据规模无法验证。本文切入点在于构建首个修辞融合数据集，通过生成对齐的四元组（字面、转喻、隐喻、混合）量化隐喻对转喻显性度的影响，为细粒度分类提供数据基础。

## 核心方法

### 字面-修辞转换框架

本文问题属于修辞生成与数据增强交叉领域，与标准分类流程的关键差异在于：不直接训练分类器，而是先构建包含修辞交互的结构化数据。框架以字面句为输入，通过 LLM 生成三种修辞变体，核心约束是保持语义忠实性与修辞类型纯度。

### 转喻生成的域内约束机制

转喻生成的难点在于参考转移必须保持域内连续性，而 LLM 直接提示易产生跨域错误。本文采用三步流水线：首先，通过针对性提问（位置、占据者、显著部分）从 LLM 提取候选替换名词，温度设为 0.7 以鼓励多样性；其次，利用 BERT 掩码语言模型计算候选词在字面句中的对数概率，选择概率最高的候选：

$$c^* = \arg\max_{c \in C} \log P(c \mid \text{sentence with } [\text{MASK}])$$

该公式的物理含义是：在字面语境下，最符合语法与语义预期的域内邻近实体即为最佳转喻替换。最后，将 $c^*$ 替换原名词，并用 LLM 以温度 0.4 精炼句子，抑制创造性改写以维持语义相似度。这一设计解决了直接提示导致的域外映射问题，确保转喻变体严格遵循邻近关系约束。

### 隐喻生成的跨域自由与混合句构造

隐喻生成允许 LLM 自由选择跨域映射，以利用隐喻的结构自由度。框架要求 LLM 生成三种语气（积极、消极、中性）的动词夸张候选，温度 0.7、top-p 0.9，再用轻量级情感分析模型选择与字面句语气匹配的最佳候选。混合句构造直接继承转喻生成的结构保守性：将精炼后的转喻名词短语插入精炼后的隐喻句，无需额外后处理。这一设计的动机在于：转喻生成通常保持原句法结构，仅修改名词短语，而隐喻生成常改变句子结构，因此混合句可自然融合两种修辞而不产生语法冲突。

## 实验评估

实验在八个现有基准上进行：转喻任务使用 ConMeC、Pedinotti、RelocaR、WiMCor，隐喻任务使用 VUA-Verb、Flute、MOH-X、TroFi。所有任务均为二分类，采用 70-30 训练-测试划分，微调 BERTbase 三个 epoch，学习率 1e-5，批量大小 8。MetFuse 增强规模固定为原训练集的 50%。基线仅对比原始训练集（Train），缺失 FL-MSCL、WPDM 等当前 SOTA 方法的直接对比。

| 任务 | 数据集 | Train | Train+MTFmty/mtr | Train+MTFhyb |
| :--- | :--- | :--- | :--- | :--- |
| 转喻 | ConMeC | 75.49 | 76.71 (+1.22) | 79.33 (+3.84) |
| 转喻 | Pedinotti | 68.42 | 66.92 (-1.50) | 70.44 (+2.02) |
| 转喻 | RelocaR | 67.33 | 69.99 (+2.66) | 70.67 (+3.34) |
| 转喻 | WiMCor | 81.67 | 82.33 (+0.66) | 82.67 (+1.00) |
| 隐喻 | VUA-Verb | 64.38 | 64.53 (+0.15) | 66.55 (+2.17) |
| 隐喻 | Flute | 76.26 | 79.73 (+3.47) | 78.47 (+2.21) |
| 隐喻 | MOH-X | 76.26 | 76.92 (+0.16) | 77.43 (+0.51) |
| 隐喻 | TroFi | 60.42 | 63.30 (+2.88) | 61.76 (+1.34) |

混合示例在转喻任务上带来最大增益（ConMeC +3.84，RelocaR +3.34），但在隐喻任务上效果不一致：VUA-Verb 和 MOH-X 上混合示例最优，Flute 和 TroFi 上纯隐喻示例更优。这一非对称性表明隐喻对转喻的影响是单向且稳定的，而转喻对隐喻的影响受数据集特性调节。

消融分析显示，Pedinotti 数据集上纯转喻增强导致性能下降（-1.50），但混合增强仍提升（+2.02），暗示混合修辞中的隐喻动词起到了“锚定”作用，缓解了纯转喻数据可能引入的噪声。LLM 零样本评估进一步验证了这一机制：GPT-OSS-20B、Qwen3-30B、Llama-3.1-70B、Gemini-2.5-Flash 在混合句上的 F1 均高于纯转喻句（如 Qwen3-30B 从 85.4 提升至 87.3），且混合句中名词的上下文嵌入与字面句的余弦相似度高于纯转喻句，证实隐喻迫使转喻显性化的认知假设。

评估边界存在明显局限：仅使用 BERTbase 作为骨干，未评估 LLM 在零样本或少样本设置下对 MetFuse 数据的直接利用；未报告计算效率，生成框架依赖 Llama-3.1-8B 多次调用，实际部署成本未知；代码已开源（github.com/cincynlp/MetFuse），但生成过程的随机性（温度 0.7）可能导致数据集复现性波动。

## 关联研究分析

从问题动机看，本文与 FL-MSCL 形成互补：FL-MSCL 通过监督对比学习在表示空间强制四类修辞的清晰边界，侧重模型架构改进；本文通过数据增强提供包含修辞交互的训练样本，侧重数据资源贡献。FL-MSCL 在 VUA-Verb 上取得 88.9 F1，而本文 Train+Hyb 仅 66.55%，差距源于骨干网络与训练策略的差异，而非数据本身无效。这一冲突暗示：数据增强与模型架构改进并非替代关系，而是正交维度，MetFuse 的价值需在更强骨干上重新评估。

从方法设计看，本文与 Surprisal-Novelty Correlation 均关注隐喻的认知机制，但路径不同：后者通过信息论指标（惊讶度）量化隐喻新颖度，前者通过生成式数据增强验证修辞交互。Surprisal-Novelty 发现惊讶度与隐喻新颖度中等相关，但不同模型规模下缩放效应分歧；本文则通过嵌入相似度直接测量隐喻对转喻显性度的影响，提供了更直接的因果证据。这种差异源于任务特性：信息论方法适合量化单一修辞属性，而生成式框架适合捕捉多修辞交互的动态过程。

## 总结

本文要解决的核心矛盾是修辞类型间边界模糊导致的细粒度分类困难，切入点在于构建首个包含隐喻-转喻共现的标注数据集，通过生成框架量化隐喻对转喻显性化的认知压力。MetFuse 包含 1,000 组四元组，混合示例在转喻任务上带来最大增益（ConMeC +3.84），LLM 零样本评估证实混合句中 F1 一致高于纯转喻句。本文的边界在于：仅使用 BERTbase 评估，未验证 LLM 在零样本设置下对混合修辞的直接利用能力；生成框架依赖 LLM 多次调用，计算成本与复现性未充分讨论。当支持集增大到 5-shot 时，MetFuse 数据增强在 LLM 上的边际收益是否递减，论文未给出回答。
