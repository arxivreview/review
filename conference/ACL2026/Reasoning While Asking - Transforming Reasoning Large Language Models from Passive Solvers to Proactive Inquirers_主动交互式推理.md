# ACL2026最新论文 ｜Reasoning While Asking: Transforming Reasoning Large Language Models from Passive Solvers to Proactive Inquirers ｜主动交互式推理

研究机构：南京大学、深圳大学

作者：Xin Chen、Feng Jiang、Yiqian Zhang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.22139)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.22139)

> 推理大语言模型在面临模糊或信息缺失的用户指令时，往往陷入“盲思”困境，即在不具备必要前提的情况下强行生成冗长的思维链，导致幻觉与计算浪费。现有检索增强或工具调用方法仅解决知识缺失，无法处理意图层面的不确定性，而传统交互式模型缺乏对“何时提问”的内在决策机制。本文提出 PIR 框架，通过不确定性感知数据增强与基于用户模拟器的强化学习，将模型从被动解题者转化为主动提问者。该范式在交互任务上显著提升了准确率并降低了交互轮次，但其依赖模拟器的反馈质量，且在非交互基准上的泛化增益有限，其真实场景下的鲁棒性仍存疑。

## 研究背景

当用户输入“修复数据处理脚本”这类模糊指令时，模型面临的核心困境是区分“知识不足”与“意图不明”。若模型误将意图不明视为知识不足，便会启动检索或工具调用，但这无法解决前提缺失问题；若模型直接推理，则需依赖内部参数知识填补空白，极易产生幻觉。这一区分要求模型具备元认知能力，即在推理过程中实时评估自身信息完备性，并据此决定是继续内部思考还是向外部（用户）寻求澄清。

当前推理增强研究主要聚焦于逻辑复杂度的提升，如思维树（ToT）与基于可验证奖励的强化学习（RLVR）。RLVR 通过代码执行或数学答案作为奖励，有效提升了模型在可验证领域的解题能力，但其假设任务前提完整，未考虑输入端的模糊性。与此同时，交互式 LLM 研究如 CollabLLM 虽引入了多轮对话，但多依赖表面行为模式或固定模板，未将澄清行为内化为推理链的一部分，导致“何时问”与“为何问”的决策过程不透明。现有方法在应对前提缺失时，要么盲目推理导致错误累积，要么被动等待用户纠正，缺乏主动对齐用户意图的机制。

本文切入点在于将“不确定性”转化为直接的训练信号。不同于检索增强解决事实错误，PIR 针对的是意图层面的不确定性，通过显式训练模型检测推理路径中的置信度低谷，并在此处插入澄清动作。这种从“静态知识检索”向“动态意图对齐”的转变，旨在解决盲思导致的计算浪费与结论偏离问题，为推理模型在真实交互场景中的应用提供了新的范式。

## 核心方法

### 方法参照系

PIR 建立在标准推理 LLM 的自回归生成框架之上，但引入了交互式环境。与标准 RLVR 使用静态奖励不同，PIR 将推理过程建模为与动态用户模拟器交互的序列决策问题，核心差异在于奖励函数不仅评估最终答案的正确性，还评估交互过程的效率与澄清质量。

### 不确定性感知数据增强

Phase I 旨在激活模型的交互能力，其关键设计在于利用预测熵（Predictive Entropy, PE）定位澄清点。传统 SFT 数据缺乏对“何时提问”的显式监督，导致模型无法区分高置信与低置信步骤。PIR 计算每个推理步骤 $s_j$ 的 PE，公式为：

$$ PE(s_j) = -\sum_{i \in s_j} p(z_i | z_{<i}) \log p(z_i | z_{<i}) $$

其中 $z_i$ 为步骤内的 token。选取 PE 排名 top-k% 的步骤作为候选澄清点，由强模型插入澄清问题与模拟回复，将线性 CoT 转化为“思考-提问-响应”轨迹。这一设计将内部不确定性直接映射为外部交互信号，使模型在冷启动阶段即可学习“不确定性→澄清→改进推理”的因果模式。

### 基于用户模拟器的策略优化

Phase II 通过 US-GRPO 优化模型在交互中的策略，解决 Phase I 仅学习格式而未优化“提问必要性”的问题。标准 GRPO 依赖静态奖励，无法评估交互过程的效用。PIR 引入动态用户模拟器 $S$，其响应受潜在意图 $I$ 约束，生成轨迹 $y = t_1, a_1, r_1, \dots, O$。复合奖励函数定义为：

$$ R(y) = R_{output}(o, g) + R_{reason}(r, o, g) $$

其中 $R_{output}$ 仅在答案正确时给予基础分，$R_{reason}$ 仅在答案正确时激活，并包含效率项 $E(r)$ 与有用性项 $H_{LLM}(r)$。$E(r)$ 惩罚过多轮次，$H_{LLM}$ 由 LLM 评判澄清质量。该设计通过联合优化准确性、效率与有用性，防止模型陷入“过度提问”或“沉默推理”的极端，实现了意图对齐与计算效率的平衡。

## 实验评估

实验在 Math-Chat、BigCodeBench-Chat 与 DocEdit-Chat 三个多轮交互数据集上进行，基线包括 Qwen2.5-Math-7B-Instruct、STaR-GATE 与 CollabLLM。PIR 在 MATH-Chat 上准确率从基线 21.30 提升至 32.70，在 BigCodeBench-Chat 上通过率从 19.70 提升至 22.90，在 MediumDocEdit-Chat 上 BLEU 从 28.00 提升至 41.36。

| 方法 | MATH-Chat ACC | MATH-Chat Tokens(k) | BigCodeBench-Chat PR | DocEdit-Chat BLEU |
| :--- | :--- | :--- | :--- | :--- |
| Instruct Base | 21.30 | 2.34 | 15.50 | 8.50 |
| CollabLLM | 22.90 | 3.85 | 19.70 | 28.00 |
| PIR (US-GRPO) | **32.70** | **1.70** | **22.90** | **41.36** |

PIR 不仅提升了任务性能，还将平均 Token 消耗降至 1.70k，显著低于基线的 2.34k-3.85k，表明主动澄清有效减少了无效推理。消融实验显示，移除推理奖励导致准确率降至 27.5，仅使用有用性奖励导致交互轮次（TTR）升至 2.63，验证了复合奖励中效率与有用性平衡的必要性。

评估边界方面，PIR 在非交互基准 MMLU 上仅从 60.12 提升至 62.51，增益有限，表明其优势主要局限于交互场景。代码已开源，但用户模拟器依赖 Llama-3.1-8B-Instruct 或 GPT-4o-mini，模拟器质量直接影响训练效果，真实用户反馈的噪声与对抗性未被充分模拟。

## 关联研究分析

从问题动机看，PIR 与 Search-R1 等检索增强方法形成互补。Search-R1 解决的是模型参数知识缺失导致的“事实幻觉”，通过外部检索提供证据；而 PIR 解决的是用户指令模糊导致的“意图偏离”，通过交互澄清前提。两者针对的失效模式不同：前者是“不知道”，后者是“没听懂”。PIR 的创新在于将澄清行为内化为推理策略，而非外部工具调用，这使得模型能根据内部不确定性动态决定交互时机，避免了检索方法在意图不明时的无效调用。

从方法设计看，PIR 与 CollabLLM 同属交互式 LLM 范畴，但机制截然不同。CollabLLM 依赖多轮感知的 RL 优化长期对话贡献，但其澄清决策基于表面行为模式，缺乏对内部推理状态的显式监控。PIR 通过 PE 定位澄清点，将不确定性量化为训练信号，使得“何时问”的决策具有可解释性。这一差异源于任务特性：CollabLLM 侧重对话流畅性，PIR 侧重推理正确性。然而，PIR 的 PE 计算依赖冻结教师模型，若教师模型本身存在偏差，澄清点定位可能失效，这一局限在论文中未深入探讨。

## 总结

本文核心矛盾在于推理 LLM 在模糊指令下的盲思行为，导致计算浪费与结论偏离。现有方法或解决知识缺失，或被动响应，缺乏主动对齐意图的机制。PIR 通过不确定性感知数据增强与复合奖励 RL，将澄清行为内化为推理策略，在 MATH-Chat 上实现 32.70 准确率与 1.70k Token 消耗，显著优于基线。其边界在于非交互基准增益有限，且依赖模拟器的质量。当用户模拟器无法准确反映真实用户的模糊性与对抗性时，PIR 学到的澄清策略是否仍能保持鲁棒性，论文未给出回答。
