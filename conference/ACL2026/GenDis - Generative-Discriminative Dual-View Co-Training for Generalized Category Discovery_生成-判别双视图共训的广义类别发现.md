# ACL2026最新论文 ｜GenDis: Generative-Discriminative Dual-View Co-Training for Generalized Category Discovery ｜生成-判别双视图共训的广义类别发现

研究机构：中国科学技术大学、中国科学院

作者：Xi Chen、Chuan Qin、Jinpeng Li 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ab58d196bce0)

> 广义类别发现（Generalized Category Discovery, GCD）旨在从部分标注数据中同时识别已知与未知类别，但现有方法依赖单一判别式监督，导致模型对未见类别泛化能力不足。近期引入大语言模型（LLMs）的方法虽提供外部语义，却存在语义与标签错位、集成弱化的问题。GenDis 提出生成-判别双视图共训框架，在 LLM 骨干内统一分类边界学习与语义标签生成，通过正交对齐与分散度感知过滤实现可靠伪标签迭代。该框架在五个文本 GCD 基准上显著超越 SOTA，但其性能增益高度依赖 LLM 预训练质量，且未验证在视觉模态或在线流式场景下的迁移性。

## 研究背景

当文本分类器面对训练集中未出现的意图类别时，其决策边界无法覆盖新样本分布——这一现象源于封闭世界假设的失效。GCD 任务要求模型在仅拥有部分已知类标签的情况下，对混合了已知与未知类别的无标签数据进行聚类发现。传统判别式微调（Discriminative Fine-tuning）通过交叉熵损失优化类间分离，但仅利用 one-hot 标签，缺乏对类别语义结构的显式建模，导致模型在未知类别上发生表示坍缩（Representation Collapse），即特征空间过度对齐已知标签，无法生成新的语义描述。

GCD 的主流路线分为两类：一是基于聚类的伪标签方法（如 SimGCD、TAN），通过 K-means 或原型匹配生成伪标签，但受限于噪声累积与已知类主导问题；二是 LLM 增强方法（如 LOOP、ALUP、Glean），利用 LLM 作为辅助模块查询语义相似度或生成伪标签，但 LLM 仅作为外部工具，未参与骨干网络的参数更新，导致语义信号与判别特征空间存在错位。GenDis 的切入点在于将 LLM 从“辅助工具”转变为“骨干网络”，通过生成式与判别式双视图的联合微调，使语义生成能力与分类边界学习在共享表示空间中协同优化，从而突破单一判别式监督的泛化瓶颈。

## 核心方法

### 方法参照系

GCD 的标准流程为两阶段：第一阶段在有标签数据上学习表示，第二阶段在无标签数据上通过聚类生成伪标签并迭代优化。本文的关键差异在于，将 LLM 作为统一骨干，同时承担语义生成与判别分类功能，并通过跨视图对齐机制确保两种监督信号的互补性，而非简单叠加。

### 双视图表示网络与联合微调

传统 LLM 增强方法将 LLM 视为黑盒查询器，其输出语义与判别模型的特征空间缺乏直接关联。GenDis 在 LLM 的隐藏层提取生成式表示 $h_{gen}$，并通过轻量级 MLP 投影为判别式表示 $h_{dis}$，构建双视图结构。生成式视图通过自回归损失 $L_{auto}$ 与条件生成损失 $L_{con}$ 优化语义流畅性，判别式视图通过交叉熵损失 $L_{dis}$ 优化类间分离。联合微调损失定义为：

$$
L_{DualFT} = L_{dis}^{(1)} + \lambda_{gen} L_{gen}^{(1)}
$$

该设计动机在于解决 LLM 单独微调时的表示坍缩问题：判别式监督强制特征空间形成可分离的类别边界，而生成式监督保留语义生成能力，二者通过共享 LLM 骨干实现参数级耦合，避免语义与标签的错位。

### CCA 对齐与分散度感知伪标签学习

双视图共训面临的核心挑战是生成式视图（侧重语义流畅性）与判别式视图（侧重类间分离）的目标冲突。GenDis 引入正交相关分析（Canonical Correlation Analysis, CCA）正则化项，将 $h_{dis}$ 与 $h_{gen}$ 投影至共享潜空间并最大化跨视图相关性，同时保持功能独立性：

$$
L_{CCA} = -\sum_{i=1}^{d} \log \rho_i
$$

其中 $\rho_i$ 为第 $i$ 个正交相关系数。该机制确保两个视图在类别相关维度上对齐，而非简单融合。在伪标签学习阶段，生成式视图通过多采样推理生成 $d$ 个候选标签，计算候选标签间的 Wasserstein 距离以评估语义分散度，并结合困惑度（PPL）筛选低噪声标签。分散度感知过滤机制定义为：

$$
\hat{y}_{gen} = \arg\min_{Y^{(i)}} \text{PPL}(Y^{(i)}) \quad \text{s.t.} \quad \frac{1}{d(d-1)} \sum_{i \neq j} W(P^{(i)}, P^{(j)}) < \tau
$$

该设计解决了 LLM 生成伪标签的噪声问题：Wasserstein 距离捕捉语义一致性，PPL 捕捉生成置信度，二者联合过滤确保伪标签的可靠性，避免噪声标签在迭代中累积。

## 实验评估

实验在 BANKING、CLINC、HWU、MCID、StackOverflow 五个文本 GCD 基准上进行，KCR（已知类比例）设为 0.25/0.5/0.75，LAR（标注比例）固定为 10%。基线覆盖判别式方法（DeepAligned、DPN、PTJN、GeoID、TAN、KTN、SDC）与 LLM 增强方法（LOOP、ALUP、Glean），但未包含视觉 GCD 基线（因模态不同）。主实验结果显示，GenDis 在 HWU 数据集 KCR=0.5 时 ARI 达 74.62，较 SOTA 方法 Glean（58.02）提升 16.60 个百分点；在 BANKING 数据集 KCR=0.25 时 ARI 达 65.54，较 ALUP（61.92）提升 3.62 个百分点。

| 数据集 | KCR | 方法 | ARI | NMI | K-ACC | N-ACC |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| HWU | 0.5 | Glean | 58.02 | 83.24 | 70.49 | 69.76 |
| HWU | 0.5 | GenDis | 74.62 | 90.05 | 87.59 | 80.74 |
| BANKING | 0.25 | ALUP | 61.92 | 83.99 | 70.78 | 72.78 |
| BANKING | 0.25 | GenDis | 65.54 | 86.32 | 82.49 | 72.80 |

消融实验表明，移除 CCA 对齐后 HWU KCR=0.5 的 ARI 下降 4.2 个百分点，移除分散度过滤后 N-ACC 下降 3.1 个百分点，验证了双视图对齐与噪声过滤的必要性。评估边界方面，论文未报告计算效率（如推理延迟、GPU 内存占用），且所有实验基于 Qwen2.5-7B-Instruct 单一 LLM 骨干，未验证不同 LLM 规模或架构下的性能差异。代码已开源，但超参数（如 $\lambda_{gen}$、$\lambda_{cca}$）需针对每个 KCR 单独调优，缺乏通用配置。

## 关联研究分析

从问题动机看，GenDis 与 Glean 均旨在利用 LLM 语义增强 GCD，但 Glean 将 LLM 作为外部查询模块，其语义信号通过对比学习间接注入判别模型，存在语义-特征空间错位；GenDis 将 LLM 作为骨干，通过参数级共训实现语义与判别特征的内在对齐。这一差异源于任务特性：文本 GCD 中类别标签本身具有语义结构（如“转账”与“汇款”的语义关联），LLM 的生成能力可直接建模这种结构，而视觉 GCD 中类别标签缺乏内在语义关联，需依赖外部文本描述。

从方法设计看，GenDis 与 SimGCD 均采用两阶段伪标签学习，但 SimGCD 依赖原型聚类生成伪标签，其噪声源于聚类边界模糊；GenDis 依赖 LLM 生成伪标签，其噪声源于语义分散度。SimGCD 的噪声可通过原型校准缓解，而 GenDis 的噪声需通过 Wasserstein 距离与 PPL 联合过滤。这一差异暗示，LLM 骨干下的 GCD 对预训练语义质量的依赖远高于原型聚类方法，当 LLM 预训练数据中缺乏特定领域知识时，生成伪标签的可靠性可能显著下降。

## 总结

GenDis 解决的核心矛盾是 LLM 语义生成能力与判别式分类边界学习之间的目标冲突。现有 LLM 增强方法将 LLM 视为外部工具，导致语义信号与特征空间错位；GenDis 通过将 LLM 作为骨干并引入 CCA 对齐与分散度感知过滤，实现语义与判别特征的参数级耦合。实验证明，该框架在 HWU KCR=0.5 时 ARI 达 74.62，较 SOTA 提升 16.60 个百分点。其边界在于：所有实验基于单一 LLM 骨干（Qwen2.5-7B），未验证不同 LLM 规模或架构下的性能差异；且未报告计算效率，无法评估在实时场景下的适用性。当 LLM 预训练数据中缺乏特定领域知识时，生成伪标签的可靠性是否仍能维持，论文未给出回答。
