# ACL2026最新论文 ｜Beyond Value Benchmarks: Measuring Value-Structure Alignment in Large Language Models via Symmetric Q-Sorts ｜对称Q-Sort下的价值结构几何对齐

研究机构：天津大学

作者：Jingting Zheng、Yuqi Ren、Linhao Yu 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_be4e62d12b62)

> 现有LLM道德评估多依赖单项行为指标，无法捕捉模型在竞争价值间的全局优先级组织方式，导致表面合规与深层价值冷漠并存。本文切入点在于将Q方法论改造为对称人类-LLM协议，通过强制分布排序提取价值几何，而非仅关注单项行为。具体做法是构建140项英语Q-set，让35名人类与12个LLM完成相同排序，用Procrustes相似性量化结构对齐。该方法提供了结构评估新范式，但低对齐分数是否源于模型缺陷或Q-set设计偏差，仍存疑。

## 研究背景

当LLM在招聘、医疗等高风险场景部署时，其输出常涉及道德判断与价值权衡。传统评估通过二元分类或准确率量化模型对道德原则的识别，但忽视了道德推理的动态性与情境依赖性。这种结果导向范式无法区分“运气好”与“真推理”，且模型生成的道德解释往往流畅但可能不反映真实决策过程，即思维链（Chain-of-Thought, CoT）推理的忠实性受到质疑。

领域主流路线从静态基准（如ETHICS、Social Chemistry 101）转向过程解释与机制可解释性，引入道德基础理论（Moral Foundations Theory, MFT）量化模型内部道德偏好分布。然而，这些方法仍局限于单项行为信号，未直接恢复模型如何作为整体组织竞争价值。本文抓住被忽略的点：在共享约束下量化LLM价值优先级的全局几何结构，而非仅关注单项行为。通过Q方法论的对称协议，将人类与LLM置于相同权衡约束下，使价值配置可作为结构化几何对象直接比较。

## 核心方法

### 方法参照系

本文问题属于“评估基准”路线，但关键差异在于采用Q-sort强制分布而非二元分类。标准流程是构建数据集、设计评估协议、量化模型表现。本文创新在于通过确定性排名-桶映射及几何对齐指标，将价值评估从行为层面提升至结构层面。

### 对称Q-Sort协议与强制分布

设计动机：解决传统问卷式评估无法捕捉价值相对优先级的问题。通常做法是独立评分或二元判断，本文改为共享约束下的相对排序。具体方案是构建140项英语Q-set，基于Schwartz价值理论的19个基本价值环状结构，辅以MFT和Morality-as-Cooperation（MAC）作为语义透镜。人类（N=35）和12个LLM在九列强制分布下完成排序，配额为(+4:8, +3:12, +2:16, +1:20, 0:28, -1:20, -2:16, -3:12, -4:8)。对LLM，先提取严格JSON全排列$\pi$，再通过确定性映射$g(r)$将排名$r$分配到桶$g(r) \in \{+4, ..., -4\}$，其中$g(\cdot)$将排名划分为连续段，大小分别为(8, 12, 16, 20, 28, 20, 16, 12, 8)。该设计保留了直接可比性，同时分离了提取与桶分配。

### 人类参考几何与结构对齐度量

设计动机：解决缺乏统一人类参考标准的问题。通常做法是使用单一模型或专家判断作为基线，本文改为通过按人因子分析提取人类参考结构。具体方案是对35个人类Q-sort进行按人因子分析，得到稳定的三因子解：共情保护（F1, n=22）、公民体面（F2, n=8）、自由与责任（F3, n=5）。这些因子阵列定义人类参考几何。结构对齐度量包括Procrustes相似性$\phi$和RSA-based Spearman相关$\rho$。Procrustes相似性通过求解正交Procrustes问题$R^* = \arg\min_{R^\top R=I} \|HR - M\|_F$，然后计算对齐坐标的相关性$\phi = \text{corr}(\text{vec}(HR^*), \text{vec}(M))$。Spearman相关$\rho$是H和M诱导的项目-项目距离矩阵上三角向量化后的相关系数。两者均在[-1, 1]范围内，较大值表示与人类关系结构更接近。

## 实验评估

实验设置：12个LLM（GPT, Gemini, DeepSeek, Qwen四家族），每个温度（T=0, 0.7）10次重复，共240次LLM Q-sort。基线审计：无经典方法对比，仅内部稳定性诊断。主结果：DeepSeek-V3在T=0时Spearman对齐最高（$\rho = 0.176$），Procrustes相似性接近最高（$\phi = 0.371$）；GPT-5.1 Procrustes相似性最高（$\phi = 0.372$），Spearman对齐中等（$\rho = 0.105$）。Gemini系列在T=0时Spearman对齐弱（Gemini-2.5-Flash: $\rho = -0.012$; Gemini-2.5-Pro: $\rho = -0.033$）。

| 模型 | T | Procrustes $\phi$ | Spearman $\rho$ |
| :--- | :--- | :--- | :--- |
| DeepSeek-V3 | 0 | 0.371 | 0.176 |
| GPT-5.1 | 0 | 0.372 | 0.105 |
| Gemini-2.5-Flash | 0 | - | -0.012 |
| Gemini-2.5-Pro | 0 | - | -0.033 |

消融与设计决策验证：温度效应非单调且依赖LLM。DeepSeek-V3从T=0到T=0.7两指标均下降（$\phi$: 0.371→0.234; $\rho$: 0.176→0.145），而DeepSeek-V3.1上升（$\phi$: 0.139→0.198; $\rho$: -0.040→0.069）。鲁棒性检查显示，排名-桶一致性高（Spearman=0.855 for $\phi$, 0.846 for $\rho$），重复子采样表明n_rep=3时几何估计已较稳定（中位SD: $\phi$=0.029, $\rho$=0.026）。优先级轮廓基线弱（中位$\rho_{best}$=0.143），表明价值几何不可还原为平均轮廓相似性。

评估边界与可复现性：指标完备性包括Procrustes和Spearman，但缺乏置信区间报告。评估协议局限在于仅英语环境，未覆盖跨文化场景。可复现性方面，论文未提供代码URL，但保留了运行清单、解析排名和分析工件。

## 关联研究分析

从问题动机看，本文与MOSAIC基准同属多维评估，但MOSAIC侧重异质性特征揭示，本文侧重几何结构对齐。MOSAIC通过大规模数据收集量化社会规范与个性对道德判断的中介作用，而本文通过Q-sort强制分布捕捉价值权衡的组织方式。差异根源在于任务特性：MOSAIC关注行为层面的多维特征，本文关注结构层面的几何关系。

从方法设计看，本文与Ethical Framework Probing均探求内部结构，但本文基于行为输出而非内部激活。Ethical Framework Probing利用线性探针映射LLM内部伦理框架的几何结构，分析不同道德理论在潜在空间中的分离度与纠缠程度。本文则通过Q-sort协议从行为层面提取价值几何，避免了内部表示解耦的技术门槛。差异根源在于评估层次：探针方法需要访问模型内部状态，本文仅依赖外部行为输出。

## 总结

本文要解决的核心矛盾是现有LLM道德评估无法捕捉价值优先级的全局组织方式。切入点在于Q方法论的对称协议，通过强制分布排序使人类与LLM价值配置可直接比较。方法上，构建140项Q-set，用Procrustes相似性量化结构对齐。实验证明DeepSeek-V3在T=0时Spearman对齐最高（$\rho = 0.176$），但整体对齐分数低，显示模型价值结构偏离人类参考。边界在于仅英语环境，且低对齐分数可能源于Q-set设计偏差。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
