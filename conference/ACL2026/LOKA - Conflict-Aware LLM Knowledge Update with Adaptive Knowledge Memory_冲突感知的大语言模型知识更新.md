# ACL2026最新论文 ｜LOKA: Conflict-Aware LLM Knowledge Update with Adaptive Knowledge Memory ｜冲突感知的大语言模型知识更新

研究机构：美国弗吉尼亚大学、NEC实验室

作者：Binchi Zhang、Zhengzhang Chen、Zaiyi Zheng 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_a016cfbe162f)

> 大语言模型（LLM）在预训练后参数冻结，导致其无法同步更新现实世界知识，且直接微调会引发灾难性遗忘。现有外部记忆方法在处理“学习新知识”与“遗忘旧知识”的联合任务时，面临梯度冲突与记忆分配过拟合/欠拟合的双重困境。LOKA 通过引入基于任务相似度的冲突感知训练机制与相似度感知的自适应知识映射，将知识分组存储于多个记忆单元中，并配合学习式路由实现选择性激活。该方法在批量知识更新任务上显著优于稀疏与稠密分配基线，但其对记忆单元数量的线性增长依赖及路由器的分布敏感性，限制了其在终身学习场景下的长期可扩展性。

## 研究背景

当 LLM 需要同时执行知识学习（最大化新事实似然）与知识遗忘（最小化旧事实似然）时，两个目标的优化方向在参数空间中往往呈现负相关。这种梯度冲突（Conflicting Gradients）定义为学习损失梯度 $\nabla L_l$ 与遗忘损失梯度 $\nabla L_u$ 的余弦相似度小于等于零（$\nabla L_l^\top \nabla L_u \le 0$）。若简单地将两个目标加权合并进行联合优化，平均梯度方向会抵消部分有效更新，导致模型在任一任务上的性能均低于单独优化时的水平。为缓解此问题，研究者转向外部记忆架构，冻结原模型参数，仅微调外挂的记忆模块。然而，记忆模块的知识分配策略直接决定了其泛化能力：稀疏分配（如 GRACE）将知识分散至多个独立记忆，虽利于精确编辑，但易导致记忆单元过拟合于特定训练样本，对改写查询失效；稠密分配（如 WISE）将知识集中于单一记忆，虽利于泛化，但梯度掩码合并过程易造成信息丢失，导致欠拟合。

现有外部记忆框架在处理批量知识更新时，未能有效解决上述“冲突”与“分配”的耦合问题。LOKA 的切入点在于将知识更新视为一个多任务优化问题，通过量化任务间的冲突程度，动态选择记忆单元的类型（任务专用或多任务共享），并引入基于语义相似度的知识映射机制，将相关知识点分组存储，从而在保持记忆单元泛化能力的同时，隔离强冲突任务。

## 核心方法

### 方法参照系

LOKA 属于外部记忆架构路线，其基础流程为：冻结 LLM 主干，选取 FFN 层参数初始化记忆单元，通过微调记忆单元编码新知识，推理时检索并拼接记忆单元。与 GRACE 等稀疏分配方法不同，LOKA 不依赖自适应半径覆盖，而是通过聚类实现知识分组；与 WISE 等稠密分配方法不同，LOKA 不采用梯度掩码合并，而是通过冲突感知训练平衡多目标优化。

### 冲突感知训练机制

针对学习 $\mathcal{L}_l$ 与遗忘 $\mathcal{L}_u$ 之间的梯度冲突，LOKA 引入冲突分数（Conflict Score）来动态决定记忆单元类型。首先，通过多目标优化算法（MGDA）对记忆单元进行一轮预训练，记录每个 mini-batch 中两个任务梯度的余弦相似度。若负冲突比例超过阈值，则部署任务专用记忆单元（Task-Specific Units），分别独立优化学习目标 $\mathcal{L}_l(W_{li}, D_{li}) + \gamma_r \mathcal{L}_r(W_{li}, D_r)$ 和遗忘目标 $\mathcal{L}_u(W_{ui}, D_{ui}) + \gamma_r \mathcal{L}_r(W_{ui}, D_r)$，其中 $\mathcal{L}_r$ 为保留集的正则化项。若冲突轻微，则使用多任务记忆单元，通过 MGDA 寻找帕累托最优解，确保两个目标在共享参数空间中互不干扰。该机制解决了直接联合优化中梯度抵消导致的性能退化，使模型能在强冲突场景下保持对旧知识的有效遗忘，同时在弱冲突场景下利用共享参数提升泛化性。

### 相似度感知知识映射与路由

为解决稀疏分配导致的过拟合问题，LOKA 采用 KMeans 聚类对知识项进行分组。具体而言，提取输入知识数据的最后一层 token 嵌入，通过 KMeans 将其划分为 $p$ 个簇，每个簇对应一个记忆单元。这种分组存储确保了同一记忆单元内的知识具有语义相关性，从而在微调时形成更稳健的决策边界，缓解了对单一训练样本的过拟合。此外，LOKA 引入一个基于 BERT 的学习式路由器（Learning-Based Router），通过微调分类器判断输入查询是否与更新知识相关。若预测为相关，则激活知识记忆模块，并通过知识映射检索最相关的记忆单元；若无关，则直接由原 LLM 处理。该设计避免了记忆模块对无关查询的干扰，提升了推理效率与准确性。

## 实验评估

实验在 TOFU、PKU-SafeRLHF 和 ZsRE 三个数据集上进行，基线覆盖梯度上升（GA）、梯度差异（GD）、偏好优化（PO）等遗忘方法，以及 GRACE、MELO、WISE 等记忆编辑方法。LOKA 在 TOFU Out-profile 更新任务中表现最优，其遗忘真值比（unl-tr）达到 0.8044，显著高于 GRACE 的 0.4192 和 WISE 的 0.4266，表明冲突感知机制有效提升了遗忘效果。在学习任务中，LOKA 的综合学习指标（lrn-tt）为 0.8538，优于直接微调基线 LLM-Surgery 的 0.3563，验证了其在保持新知识学习能力的同时，未牺牲原有知识保留率（rtn-rl 保持 0.3901，与原模型一致）。

消融实验显示，移除冲突解决模块（cf）后，unl-tr 从 0.8021 降至 0.7916，而 lrn-rl 从 0.9722 降至 0.9714，表明冲突模块主要平衡了遗忘与学习的权衡。移除知识映射模块（mp）后，unl-tr 大幅降至 0.6365，证实了分组存储对缓解过拟合的关键作用。在顺序更新场景中，LOKA-KMeans 的内存开销随更新请求线性增长，而 LOKA-LSH 在 4 次更新后内存趋于稳定，但 LOKA-LSH 的学习性能（lrn-rl 0.6093）显著低于 LOKA-KMeans（0.9384），揭示了效率与效用之间的权衡。

评估边界方面，LOKA 在 ZsRE 数据集上保留知识表现不佳，作者归因于更新集与保留集分布相似导致路由器失效。此外，论文未提供代码开源链接，且未报告置信区间，限制了结果的统计显著性验证。

## 关联研究分析

从问题动机看，LOKA 与 KARLA 等检索增强方法存在本质差异。KARLA 将事实存储完全外化至知识库，模型仅生成查询，解决了容量限制问题，但依赖外部知识库的实时可用性，且无法主动“遗忘”有害知识。LOKA 则通过微调外部参数实现“可写”记忆，支持知识的添加与移除，更适合需要动态更新且对安全性敏感的场景。然而，LOKA 未采用强化学习（RL）信号，仅依赖 SFT/NPO，这可能限制其在未见改写查询上的泛化能力，而 GRIN 等 RL 增强方法在 BLANK 基准上展示了更好的新颖知识获取能力。

从方法设计看，LOKA 与 ExplicitLM 同属外部记忆架构，但知识管理策略不同。ExplicitLM 使用 Gumbel-Softmax 选择记忆条目，侧重端到端优化检索相关性；LOKA 则通过 KMeans 聚类进行无监督分组，并引入基于任务梯度的冲突分数动态选择记忆单元类型。这种设计使 LOKA 能更精细地处理学习与遗忘的冲突，但引入了额外的预训练开销（需一轮 MGDA 预训练以计算冲突分数）。当更新请求频繁且知识分布变化剧烈时，KMeans 聚类的静态分组可能无法适应新的语义结构，导致记忆单元利用率下降，这是 LOKA 在终身学习场景下的潜在瓶颈。

## 总结

LOKA 旨在解决批量知识更新中学习与遗忘任务的梯度冲突及记忆分配困境。通过引入冲突分数动态选择任务专用或多任务记忆单元，并结合 KMeans 分组存储与学习式路由，LOKA 在 TOFU 基准上将遗忘真值比提升至 0.8044，同时保持原有知识保留率不变。然而，其 KMeans 聚类导致的内存线性增长及路由器对分布变化的敏感性，限制了其在长期、高频更新场景下的适用性。当更新请求数量增加至数百次时，记忆单元数量的线性增长是否会导致推理延迟不可接受，论文未给出回答。
