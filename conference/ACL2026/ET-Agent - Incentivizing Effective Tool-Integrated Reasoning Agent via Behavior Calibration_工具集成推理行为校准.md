# ACL2026最新论文 ｜ET-Agent: Incentivizing Effective Tool-Integrated Reasoning Agent via Behavior Calibration ｜工具集成推理行为校准

研究机构：中国人民大学

作者：Yifei Chen、Guanting Dong、Zhicheng Dou

论文原文见 [arXiv](https://arxiv.org/abs/2601.06860)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.06860)

> 工具集成推理（Tool-Integrated Reasoning, TIR）旨在让大语言模型（LLM）通过调用外部工具突破参数知识边界，但现有训练框架过度关注答案准确率，忽略了行为模式的正确性，导致智能体频繁出现冗余或不足的工具调用。本文切入点在于将TIR行为校准视为一个独立的优化目标，而非准确率的副产品。ET-Agent通过自进化数据飞轮扩展动作空间，结合帕累托采样与课程强化学习（RL）迭代校准行为。该框架在效率与正确性上均优于基线，但其行为校准是否牺牲了通用推理能力，以及跨任务迁移性，仍存疑。

## 研究背景

当LLM面对超出其参数知识范围的复杂问题时，TIR范式通过交错生成推理轨迹与执行工具动作来扩展能力边界。然而，TIR的动作空间极高维且非结构化，模型在探索过程中极易陷入局部最优，表现为“不当工具使用”（如冗余调用、执行中断）与“推理逻辑缺陷”（如调用不足、逻辑错误）。这种行为模式的失准不仅增加了计算开销，更导致长程任务中的错误累积，使得单纯优化准确率的方法难以收敛到高效且正确的轨迹。

现有TIR训练方法主要分为推理时扩展与基于训练的方法两类。推理时扩展依赖提示工程或测试时计算，缺乏对行为模式的系统性约束；基于训练的方法中，监督微调（SFT）与直接偏好优化（DPO）因依赖静态数据或二元对比，易导致动作空间探索坍缩，无法覆盖TIR所需的广泛轨迹多样性。尽管部分工作开始关注工具调用效率，但多局限于消除冗余，未系统解决调用不足与逻辑错误。ET-Agent的切入点在于，通过on-policy训练在扩展动作空间覆盖的基础上，利用多目标奖励机制对行为模式进行细粒度校准，从而在保持正确性的同时提升执行效率。

## 核心方法

### 方法参照系

ET-Agent置于基于训练的TIR优化框架下，其核心差异在于将“行为模式校准”从准确率优化中解耦，引入自进化数据生成与帕累托采样机制，以解决静态数据导致的探索不足与DPO导致的动作空间坍缩问题。

### 自进化数据飞轮

针对初始数据动作空间覆盖不足的问题，ET-Agent引入自进化数据飞轮。该机制通过迭代引导模型对轨迹进行“正确推理增强”与“错误推理反思”，将有效样本回注数据池。对于正确集，执行冗余修改与全局精炼以去除无效步骤；对于错误集，通过自我纠正与提示注入诱导模型调用额外工具。这一过程显著扩展了动作空间覆盖，为后续强化学习提供了高方差的轨迹分布，解决了SFT因数据静态导致的探索局限。

### 行为校准训练

在扩展的动作空间基础上，ET-Agent实施两阶段行为校准训练。第一阶段为动作空间探索微调，通过拒绝采样微调（RFT）在增强数据上训练模型，消除执行中断与格式错误，建立基础探索能力。第二阶段为迭代行为校准强化学习，交替执行组内帕累托采样与课程RL训练。帕累托采样基于正确性分散度 $S_{corr}$ 与行为分散度 $S_{tool}$ 筛选非支配样本，防止轨迹同质化导致的梯度消失：

$$
S_{corr}(x) = \sqrt{\frac{1}{K} \sum_{i=1}^{K} (r(\tau_i) - \bar{r})^2}
$$

其中 $r(\tau_i)$ 为轨迹正确性得分，$\bar{r}$ 为均值。该公式量化了组内正确性差异，高 $S_{corr}$ 意味着更大的优化潜力。课程RL训练则通过多目标奖励机制，逐步将模型行为校准至最优轨迹，解决了传统RL在稀疏奖励下难以平衡效率与正确性的问题。

## 实验评估

实验在AIME24、AMC23、MATH500及2WikiMultiHopQA等六个任务上进行，基线涵盖直接推理、单一TIR方法（如Search-o1、ToRL）及多TIR方法（如Tool-Light、AutoTIR）。ET-Agent在正确性与效率指标上均取得最佳平均成绩（60.1, 46.0），显著优于Tool-Light（33.1）与AutoTIR（12.0）。

| 方法 | AIME24 (LJ/Eff) | AMC23 (LJ/Eff) | 2Wiki (F1/Eff) | 平均 (LJ/Eff) |
| :--- | :--- | :--- | :--- | :--- |
| Tool-Light | 33.3 / 33.3 | 72.5 / 67.5 | 58.7 / 23.0 | 33.1 / 26.0 |
| AutoTIR | 33.3 / 21.3 | 62.5 / 46.4 | 55.4 / 34.2 | 12.0 / 30.9 |
| ET-Agent | 46.7 / 43.3 | 77.5 / 71.3 | 67.2 / 35.6 | 60.1 / 46.0 |

消融实验显示，移除自进化数据飞轮导致正确性下降至54.8，移除帕累托采样使效率降至40.1，移除奖励机制中的 $\sigma$ 衰减则引发严重正确性退化（48.1），验证了各组件对行为校准的必要性。

评估边界方面，效率指标定义为正确性得分与工具调用次数之比，未考虑计算延迟与Token消耗，可能低估实际部署成本。代码已开源，但超参数细节（如迭代轮数 $R$、采样大小 $K$）未在正文中详述，可复现性依赖附录补充。

## 关联研究分析

从问题动机看，ET-Agent与Tool-Light均关注TIR行为效率，但Tool-Light采用DPO算法，其二元对比优化易导致模型输出坍缩至狭窄动作空间，限制了探索能力。ET-Agent改用on-policy RL，通过帕累托采样维持轨迹多样性，解决了DPO在TIR高维动作空间中的探索不足问题。这一差异源于任务特性：TIR轨迹的多样性远高于数学推理，静态偏好数据无法覆盖所有有效行为模式。

从方法设计看，ET-Agent与ToRL同属RL框架，但ToRL聚焦于提升准确率，未显式优化行为模式。ET-Agent引入自进化数据飞轮与多目标奖励，将行为校准作为独立优化目标。这一设计解决了ToRL在长程任务中因奖励稀疏导致的信用分配难题，但论文未探讨行为校准对通用推理能力的潜在影响，即模型是否因过度优化工具调用而牺牲了纯推理能力。

## 总结

ET-Agent针对TIR训练中行为模式失准与准确率优化脱节的核心矛盾，通过自进化数据飞轮扩展动作空间，结合帕累托采样与课程RL实现行为校准。该框架在六个任务上取得最佳平均正确性（60.1）与效率（46.0），验证了行为校准的有效性。然而，实验仅覆盖数学与知识密集任务，未评估行为校准在代码执行或实时交互场景中的泛化性。当任务环境动态变化时，静态校准的行为模式是否仍能保持高效，论文未给出回答。
