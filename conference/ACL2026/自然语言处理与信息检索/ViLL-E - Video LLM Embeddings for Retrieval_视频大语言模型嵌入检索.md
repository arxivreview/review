# ACL2026最新论文 ｜ViLL-E: Video LLM Embeddings for Retrieval ｜视频大语言模型嵌入检索

作者：Rohit Gupta、Jayakrishnan Unnikrishnan、Fan Fei 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.12148)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.12148)

> 视频理解任务长期分裂为生成式问答与嵌入式检索两条互不兼容的技术栈，前者擅长语义推理但无法输出向量，后者擅长匹配但缺乏上下文理解能力。ViLL-E 通过引入可学习的注意力池化嵌入头与三阶段联合训练策略，使单一视频大语言模型同时具备文本生成与向量提取能力。该方案在时刻检索任务上超越专用视频大语言模型 7% 以上，并在零样本组合检索中领先现有基线 5%。其核心价值在于统一了两种范式，但推理时依赖自回归生成过程，计算效率仍受限于大语言模型骨干。

## 研究背景

视频大语言模型（VideoLLM）通过投影层将视频帧特征对齐至语言模型空间，实现了视频问答与字幕生成等文本输出任务。然而，文本-视频检索（Text-Video Retrieval, TVR）与时刻检索（Moment Retrieval, MR）依赖嵌入空间中的向量相似度匹配，而非文本生成。现有 VideoLLM 架构仅优化下一词预测损失，缺乏生成判别性嵌入的机制，导致其在检索基准上表现远低于专用双编码器模型。

领域内主流路线分为两类：一是基于 CLIP 的双编码器扩展，如 CLIP4Clip 与 VidLA，通过聚合多帧视觉特征实现高效检索，但缺乏细粒度时序推理能力；二是专用定位模型，如 QD-DETR 与 Moment-DETR，引入可学习时刻查询或时间跨度预测模块，在 ActivityNet 等基准上取得领先，但每个模型需针对特定数据集单独微调，且无法处理生成式任务。这种“任务专用”范式导致系统复杂度随任务数量线性增长，且不同任务间的知识无法共享。

ViLL-E 的切入点在于打破生成与嵌入的架构壁垒。受 NLP 领域 GRIT 模型启发，该工作提出在 VideoLLM 训练过程中同时优化生成目标与对比学习目标，使模型在保持问答能力的同时，能够输出用于检索的稠密向量。这一设计直接回应了“单一模型能否同时处理生成与检索”的核心问题，避免了维护两套独立模型栈的工程负担。

## 核心方法

### 方法参照系

标准 VideoLLM 流程为：视觉编码器提取帧特征 → 投影层对齐至 LLM 空间 → Transformer 层自回归生成文本。该流程仅优化语言建模损失，输出为离散 token 序列，无法直接用于向量检索。ViLL-E 的关键差异在于在 LLM 解码器后新增嵌入头，并将训练目标扩展为生成与对比学习的联合优化。

### 自适应嵌入头设计

嵌入头位于 LLM 最终 Transformer 层之后，采用 KV-Former 结构。该设计以 LLM 生成的 token 作为查询（Query），引入 $P$ 个可学习的键（Key）与值（Value）“池化 token”进行交叉注意力计算。注意力输出经多层感知机（MLP）投影后，通过均值池化生成固定维度的嵌入向量。

$$
\mathbf{e} = \text{MeanPool}(\text{MLP}(\text{Attention}(\mathbf{Q}_{\text{LLM}}, \mathbf{K}_{\text{learn}}, \mathbf{V}_{\text{learn}})))
$$

该公式的物理含义是：模型根据视频复杂度动态决定生成 token 的数量，复杂视频生成更多 token 以提供更丰富的上下文信息，简单视频则快速终止。这种自适应计算机制解决了固定长度嵌入无法适应视频内容差异的问题，避免了简单视频上的冗余计算与复杂视频上的信息截断。

### 三阶段联合训练策略

训练分为三个阶段：第一阶段在 1000 万规模视频-字幕对上联合优化下一词预测损失与 CLIP 式对比损失；第二阶段在 20 万高质量长字幕数据上继续预训练；第三阶段在多任务指令微调数据集上覆盖视频问答、时刻定位、视频检索与文本-视频匹配。

$$
\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{gen}} + \lambda \mathcal{L}_{\text{contrastive}}
$$

其中 $\mathcal{L}_{\text{gen}}$ 为生成任务的交叉熵损失，$\mathcal{L}_{\text{contrastive}}$ 为多模态对比损失，$\lambda$ 为平衡系数。该设计动机在于：单一生成损失无法建立视频与文本间的判别性对齐，而单一对比损失缺乏语义推理能力。联合训练使模型在生成连贯描述的同时，学习区分相关与不相关的视频-文本对，从而在检索任务上获得显著增益。

## 实验评估

实验在 MSR-VTT、DiDeMo、VATEX（视频检索）及 ActivityNet、Charades-STA、QVHighlights（时刻检索）六个基准上进行。基线覆盖专用检索模型（VidLA、SigLIP）、专用定位模型（QD-DETR）及视频大语言模型（LLaVA-ST、Qwen2.5-VL）。ViLL-E 在时刻检索任务上平均超越 LLaVA-ST 7% 以上，在视频检索任务上达到或超过 VidLA 的性能。

| 任务 | 基准 | 方法 | R@1/IoU=0.5 |
| :--- | :--- | :--- | :--- |
| 时刻检索 | ActivityNet | LLaVA-ST-7B | 31.2 |
| 时刻检索 | ActivityNet | ViLL-E | 39.4 |
| 时刻检索 | Charades-STA | LLaVA-ST-7B | 44.8 |
| 时刻检索 | Charades-STA | ViLL-E | 51.7 |
| 视频检索 | MSR-VTT | VidLA | 58.0 |
| 视频检索 | MSR-VTT | ViLL-E | 62.8 |

消融实验显示，移除对比损失导致检索性能显著下降，移除匹配损失则影响较小，表明对比学习是嵌入质量的关键。嵌入头设计中，KV-Former 结构优于 Q-Former 与自注意力层，验证了自适应池化的有效性。预训练阶段中，大规模预训练对检索任务至关重要，高质量长字幕预训练则主要提升长视频数据集上的生成性能。

评估边界方面，论文未报告推理延迟与 FLOPs 数据，无法直接比较与双编码器模型的效率差异。代码未公开，超参数细节（如 $\lambda$ 值、$P$ 的取值）仅在附录中部分披露。可复现性受限于 PaliGemma-3B 骨干的特定版本与 Shutterstock 数据集的访问权限。

## 关联研究分析

从问题动机看，ViLL-E 与 GRIT 共享“生成+嵌入”联合训练的范式，但 GRIT 仅处理文本模态，而 ViLL-E 扩展至视频模态并引入自适应嵌入头。这一差异源于视频内容的时序复杂度：文本嵌入可通过固定长度表示，而视频需根据内容动态调整计算量。ViLL-E 的 KV-Former 设计正是为了解决这一模态特异性问题，而 GRIT 的固定嵌入方案在视频任务上可能因信息截断或冗余计算而失效。

从方法设计看，ViLL-E 与 QD-DETR 在时刻检索任务上形成对比。QD-DETR 采用专用定位模块（时间跨度预测）与可学习时刻查询，针对特定数据集微调，在 ActivityNet 上取得 45.21 的 R@0.5（据领域综述）。ViLL-E 作为通用模型，在相同基准上取得 39.4 的 R@1，差距约 6%。这一差距可能源于 QD-DETR 的专用定位模块对时间边界的显式建模，而 ViLL-E 依赖 LLM 的隐式时序推理。然而，ViLL-E 的优势在于无需针对每个数据集单独微调，且能同时处理生成任务，这种通用性在任务多样性场景下更具工程价值。

## 总结

ViLL-E 要解决的核心矛盾是视频理解任务中生成式与嵌入式范式的架构割裂。现有方法要么擅长问答但无法检索，要么擅长检索但缺乏推理能力，且需维护多套独立模型。ViLL-E 通过引入自适应嵌入头与三阶段联合训练，使单一 VideoLLM 同时具备两种能力，在时刻检索上超越专用 VideoLLM 7% 以上，在零样本组合检索中领先基线 5%。其边界在于推理时仍需自回归生成 token，计算效率未获量化验证，且与专用定位模型在细粒度时间边界预测上存在差距。当视频时长超过 10 分钟时，自适应嵌入头的 token 生成数量是否呈线性增长，进而导致推理延迟不可接受，论文未给出回答。
