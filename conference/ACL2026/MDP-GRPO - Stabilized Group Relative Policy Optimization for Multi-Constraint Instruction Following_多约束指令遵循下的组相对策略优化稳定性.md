# ACL2026最新论文 ｜MDP-GRPO: Stabilized Group Relative Policy Optimization for Multi-Constraint Instruction Following ｜多约束指令遵循下的组相对策略优化稳定性

研究机构：伊朗德黑兰大学

作者：Mohammad Mahdi Salmani-Zarchi、Zahra Rahimi、Heshaam Faili 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.06058)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.06058)

> 组相对策略优化（GRPO）在离散、低方差奖励下因组内同质性导致优势估计失效，表现为低方差放大、均值中心化盲点及零方差坍缩。现有方法多针对数学推理中的稀疏奖励，却忽视了指令遵循任务中确定性检查器引发的极端低方差场景。本文通过多温度采样、双锚点优势及前景理论整形重构优势估计，在保持计算效率的同时恢复学习信号。该方法在Llama-3.2-3B上将严格约束满足率提升5.0%，但其对通用推理能力的潜在影响及小样本组下的泛化边界尚存疑。

## 研究背景

多约束指令遵循要求模型同时满足格式、词汇及逻辑等多重硬性规则，任一违规即导致输出不可用。此类任务依赖可验证奖励强化学习（RLVR），通过确定性规则检查器生成离散奖励信号，避免了偏好模型的主观偏差。然而，当奖励分布高度集中时，标准GRPO的组内z-score归一化机制会失效：若组内所有样本奖励相同，标准差趋近于零，优势值坍缩为零，导致梯度消失；若方差极小，微小差异被放大为巨大优势，引发训练震荡。

GRPO通过消除Critic网络降低了LLM后训练成本，确立了RLVR范式，但其优势估计依赖组内相对差异。在数学推理等连续或高方差奖励任务中，该机制表现稳健；但在指令遵循等离散、低方差奖励场景中，组内同质性成为普遍现象。现有改进工作如DAPO侧重解耦裁剪以缓解梯度消失，SSVPO聚焦步骤级信用分配以解决长序列归因粗糙问题，均未直接处理离散奖励下的组内方差坍缩。本文切入点在于识别并形式化离散奖励引发的三种优势病理，并通过采样策略与优势重构的组合机制，在无需额外Critic的前提下恢复低方差场景下的学习信号。

## 核心方法

### 方法参照系

标准GRPO对每个提示采样$G$个响应，计算组内奖励均值$\mu_{group}$与标准差$\sigma_{group}$，通过$z_i = (r_i - \mu_{group}) / (\sigma_{group} + \epsilon)$估计优势。该流程假设组内奖励具有足够方差以区分样本质量。本文问题与该通用流程的关键差异在于：离散约束奖励导致$\sigma_{group}$频繁趋近于零或极小，使得z-score归一化在数学上失效或数值上不稳定，需从采样源头与优势计算两端同时干预。

### 多温度采样与双锚点优势

标准采样使用固定温度，易产生同质响应。本文引入温度调度$\mathbf{T} = [\tau_1, ..., \tau_G]$，混合低温度（利用）与高温度（探索）采样，强制组内奖励分散。针对零方差坍缩，引入目标感知锚点$\delta_i$，基于二项分布中性基线$\mu_{goal}=0.5$计算绝对优势：

$$ \delta_i = \frac{r_i - \mu_{goal}}{\sigma_{goal}} $$

该公式在组内方差为零时仍提供非零信号，弥补z-score的盲点。最终优势通过插值融合：

$$ A_i = \alpha \tilde{\delta}_i + (1-\alpha) \tilde{z}_i $$

其中$\tilde{\delta}_i, \tilde{z}_i$为整形后的信号。此设计动机在于：多温度采样预防同质组，双锚点恢复坍缩信号，二者协同解决离散奖励下的方差缺失问题。

### 前景理论整形与非对称KL

标准优势线性映射导致极端值主导梯度。本文应用前景理论（Kahneman & Tversky, 1979）的有界非对称整形函数：

$$ \tilde{v}_i = \begin{cases} \lambda_+ \tanh(v_i / \lambda_+) & v_i > 0 \\ -\lambda_- \tanh(-v_i / \lambda_-) & v_i \le 0 \end{cases} $$

其中$\lambda_- > \lambda_+$体现损失厌恶，对违规（负优势）施加更强惩罚。同时引入非对称KL系数$\beta_{KL}^{high} > \beta_{KL}^{low}$，允许正向偏离更大，严格约束负向偏离。该设计动机在于：有界整形防止梯度爆炸，非对称KL平衡探索与稳定性，解决低方差场景下的更新震荡问题。

## 实验评估

实验在Gemma-2-2B-Instruct与Llama-3.2-3B-Instruct上进行，评估基准包括IFEval、FollowBench及自定义多约束测试集。基线覆盖零样本Baseline与标准GRPO，缺失DAPO、SSVPO等最新SOTA方法，限制了横向对比的完整性。主结果显示，MDP-GRPO在Llama-3.2-3B的Custom Test Set上HSR达32.8%，较GRPO的29.0%提升3.8个百分点；在IFEval上SSR达75.3%，较GRPO的73.7%提升1.6个百分点。

| 模型 | 基准 | 指标 | Baseline | GRPO | MDP-GRPO |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Llama-3.2-3B | Custom Test Set | HSR | 29.0 | 29.0 | 32.8 |
| Llama-3.2-3B | IFEval | SSR | 73.7 | 73.7 | 75.3 |
| Gemma-2-2B | Custom Test Set | HSR | 29.0 | 29.0 | 32.8 |
| Gemma-2-2B | IFEval | SSR | 73.7 | 73.7 | 75.3 |

消融实验表明，双锚点（DA-GRPO）在Custom Test Set上HSR提升最显著（32.6% vs GRPO 29.0%），验证其对零方差坍缩的缓解作用；多温度采样（MT-GRPO）在$G=4$小样本组下表现优于$G=8$标准GRPO，证明其在计算受限场景下的有效性。前景理论整形（PT-GRPO）在Gemma-2-2B上HSR达65.8%，高于GRPO的62.4%，体现损失厌恶对违规惩罚的增益。

评估边界方面，论文未报告置信区间，小样本基准（如Custom Test Set 500题）的统计显著性存疑。代码已开源，超参数（$\alpha=0.2, \lambda_+=1.25, \lambda_-=2.0$）明确，但仅在单卡A100上训练一个epoch，大规模训练下的稳定性未验证。通用能力评估（MMLU/ARC）显示无显著退化，但未量化具体数值。

## 关联研究分析

从问题动机看，本文与NGRPO均处理同质组问题，但NGRPO针对全错组通过优势校准恢复信号，本文通过双锚点同时处理全对与全错组，覆盖更广泛的离散奖励场景。差异根源在于任务特性：数学推理中全错组更常见，而指令遵循中全对与全错组均频繁出现，需更通用的锚点机制。

从方法设计看，本文与KTO均引入前景理论，但KTO在离线偏好优化中作用于目标函数，本文在在线RL中作用于优势估计。这一差异源于数据形态：KTO处理非配对偏好数据，需目标级整形；本文处理组内相对奖励，需优势级整形以维持策略梯度定理的有效性。多温度采样是否改变策略分布导致重要性采样偏差，论文未深入讨论，可能在小样本组下引入额外方差。

## 总结

本文核心矛盾是离散低方差奖励下GRPO优势估计的数值失效。切入点在于识别z-score归一化在$\sigma_{group} \to 0$时的病理，并通过采样-优势-整形三层机制重构信号。方法组合多温度采样、双锚点优势及前景理论整形，在Llama-3.2-3B上将Custom Test Set HSR提升3.8个百分点。边界在于：实验仅覆盖2B-3B小模型，未验证大规模模型下的计算开销；双锚点引入的非零均值偏差在长序列推理中的影响未量化。当组大小进一步缩减至$G=2$时，多温度采样的多样性注入是否足以抵消方差估计的噪声，论文未给出回答。
