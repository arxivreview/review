# ACL2026最新论文 ｜Can LLMs Estimate Cognitive Complexity of Reading Comprehension Items? ｜阅读理解认知复杂度评估

作者：Seonjeong Hwang、Hyounghun Kim、Gary Lee

论文原文见 [arXiv](https://arxiv.org/abs/2510.25064)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_9648570dbc22)

> 阅读理解题目难度评估长期依赖考后统计或昂贵的人工标注，无法在命题阶段提供可解释的认知负荷指标。现有基于表面特征或整体难度分数的方法无法捕捉解题过程中的微观认知机制。本文构建了首个包含证据范围与转换层级标注的基准数据集 RECO，并验证了大语言模型（Large Language Models, LLM）在预测这些认知因子上的潜力。LLM 虽能近似认知复杂度，但存在显著的元认知盲区，其价值在于提供可解释的难度代理，而非完全替代专家。

## 研究背景

阅读理解（Reading Comprehension, RC）题目难度评估是教育测量中的核心环节，传统方法依赖经典测试理论（Classical Test Theory, CTT）或项目反应理论（Item Response Theory, IRT）从学生作答数据中推导难度参数。然而，这些方法仅在考试实施后有效，无法支持命题阶段的先验难度预测。专家判断虽可作为替代，但成本高且存在评分者偏差。另一条路线利用不同能力水平的深度学习模型模拟学生作答，虽实现了无数据评估，但计算开销大且缺乏对“为何难”的解释性。

教育心理学研究表明，解题过程中的认知因子比表面语言特征更强烈地关联题目难度，但现有自然语言处理（Natural Language Processing, NLP）工具无法自动提取这些因子。Lai et al. (2017) 等提出的分类法虽尝试刻画推理类型，但多用于区分题目类型而非同一类型内的认知复杂度差异。Raina and Gales (2024) 等尝试直接提示 LLM 预测难度，但多聚焦于数学或代码等依赖内部知识的任务，未深入探究 RC 任务中依赖外部文本证据的认知过程。本文切入点在于：将难度评估从“整体分数预测”细化为“结构化认知特征分类”，利用 LLM 的推理能力模拟人类解题时的认知负荷。

## 核心方法

### 认知复杂度维度定义

本文将 RC 题目认知复杂度解耦为两个正交维度：证据范围（Evidence Scope, ES）与转换层级（Transformation Level, TL）。ES 衡量验证陈述真伪所需的文本跨度，分为单句、多句与证据不足三类；TL 衡量陈述与证据间的词汇及结构转换程度，采用五级分类法（词匹配、转换词匹配、释义、转换释义、推理）。对于多句证据题目，TL 简化为三级（词匹配、释义、推理），因为短语重排在多句整合中是普遍现象，区分其细微差异对难度预测贡献有限。这种维度解耦旨在捕捉 Bormuth et al. (1970) 提出的认知负荷机制，即信息整合范围与语言转换难度共同决定解题负担。

### 基于 LLM 的认知因子分类

本文构建 RECO 数据集，包含 776 个来自 RACE++ 的真/假/未提及（True/False/Not Given, TFNG）题目，由三位专家独立标注 ES 与 TL 标签。实验评估 8 个指令微调 LLM，采用标准提示（Standard Prompting, SP）与思维链提示（Chain-of-Thought, CoT）两种策略。分类任务形式化为：给定段落 $P$、陈述 $S$ 及事实标签 $Y$，模型预测认知标签 $C$。

$$
C = f_\theta(P, S, Y)
$$

其中 $f_\theta$ 为 LLM 参数化函数。该公式表明，认知复杂度预测被建模为条件分类问题，输入包含解题所需的全部上下文，输出为离散认知标签。设计动机在于，直接预测整体难度分数缺乏解释性，而预测中间认知因子既能保留可解释性，又能通过组合因子推断整体难度。实验发现，GPT-4o 在 ES 任务上 Macro F1 达 74.8，Qwen2.5-32B 达 73.5，开源模型表现接近或超越专有模型，表明认知复杂度评估更依赖模型对文本结构的模式识别能力，而非专有模型的深层推理深度。

## 实验评估

实验在自建 RECO 数据集上进行，基线覆盖 8 个 LLM（GPT-4o, Qwen2.5, Mistral, Gemma2 等），未对比传统监督学习模型（如线性回归），因为任务性质为分类而非回归，且缺乏大规模标注数据训练传统模型。主结果显示，LLM 在 ES 和 3 级 TL 分类上 Macro F1 分别达 74.8 和 82.0，显著高于随机猜测，但低于人类专家初始标签性能。

| 模型 | ES Macro F1 | TL (3-level) Macro F1 |
| :--- | :--- | :--- |
| GPT-4o | 74.8 | 82.0 |
| Qwen2.5-32B | 73.5 | 81.2 |
| Mistral-24B | 72.1 | 80.5 |
| Gemma2-27B | 70.3 | 79.8 |

消融实验揭示，思维链提示在 ES 任务上提升有限，但在 TL 任务上改善明显，表明复杂转换层级需要显式推理步骤。然而，Qwen3-32B 在启用“思考模式”后性能反而下降，ES F1 从 65.4 降至 62.6，TL F1 从 58.6 降至 56.3。这一反直觉结果暗示，认知复杂度分类更依赖直觉模式识别而非深度自我反思，过度推理可能引入噪声。

评估边界方面，RECO 仅包含英语 TFNG 题目，未覆盖多语言或选择题格式，限制了泛化性验证。代码已开源，但未报告计算成本与推理延迟，对于实时命题场景的适用性存疑。指标采用 Macro F1，未分析类别不平衡对性能的影响，且未提供置信区间，数值比较需谨慎。

## 关联研究分析

从问题动机看，本文与 Raina and Gales (2024) 的相对难度比较方法形成互补。后者通过 LLM 比较两个题目的相对难度，虽与人类判断对齐度较高，但无法提供绝对认知因子解释；本文通过分类具体认知维度，提供了可操作的难度归因，但牺牲了相对排序的灵活性。这种差异源于任务目标不同：前者服务于题目排序，后者服务于难度解释。Dutulescu et al. (2024) 利用 LLM 问答损失预测难度，其映射关系不透明，而本文直接预测认知标签，避免了黑箱映射，但增加了标注成本。

从方法设计看，本文与 Lai et al. (2017) 的五级分类法存在继承与改造关系。Lai 的分类法用于区分题目类型（如主旨题、细节题），而本文将同一类型内的认知复杂度解耦为 ES 与 TL 两个正交维度，更贴合认知心理学机制。这种改造使得模型能捕捉“单句证据但高转换层级”与“多句证据但低转换层级”的细微差异，而传统分类法无法区分。然而，本文未探索 ES 与 TL 的交互效应，即两者组合对整体难度的非线性影响，这可能是后续研究的关键盲区。

## 总结

本文核心矛盾在于认知复杂度评估的可解释性与自动化之间的权衡。现有方法要么依赖考后统计（无先验性），要么依赖整体分数预测（无解释性），本文通过构建 RECO 数据集并验证 LLM 在认知因子分类上的潜力，提供了可解释的先验难度代理。实验证明 LLM 在 ES 和 3 级 TL 分类上 Macro F1 达 74.8 和 82.0，开源模型表现接近 GPT-4o，表明认知复杂度评估不依赖专有模型。然而，LLM 存在元认知盲区，解题正确但无法准确归因认知过程，且深度推理模式反而降低性能，暗示当前 LLM 的认知复杂度预测更多依赖模式匹配而非真正的认知模拟。当支持集增大或引入多语言数据时，LLM 的元认知缺口是否可通过微调缩小，论文未给出回答。
