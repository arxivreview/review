# ACL2026最新论文 ｜Beyond the Context Window: Scaling Agentic RL via End-to-end Optimized Context Compression ｜摘要增强策略优化

研究机构：美国斯坦福大学、美国卡内基梅隆大学

作者：Miao Lu、Weiwei Sun、Weihua Du 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_25abcbafe4d1)

> 长程智能体强化学习（RL）训练受限于固定上下文窗口，导致模型无法处理需多轮工具调用的复杂任务。现有静态截断或规则摘要方法无法在训练中动态适应任务需求，且摘要质量未参与梯度优化。本文提出 SUPO，将 LLM 生成的摘要作为策略动作纳入马尔可夫决策过程（MDP），通过策略梯度联合优化工具调用与摘要生成，使有效上下文扩展至工作窗口的 3-10 倍。该方法在代码与搜索任务上显著提升了任务完成率，但摘要触发机制仍依赖固定阈值，且未验证在密集奖励场景下的信用分配有效性。

## 研究背景

当智能体执行多步工具调用任务时，初始提示、模型输出与工具观察的累积迅速耗尽上下文窗口，引发指令遵循能力退化与推理成本激增。这一困境源于 Transformer 自注意力的二次方复杂度，使得模型在长序列中难以维持对早期关键信息的注意力，即“中间迷失”现象。为突破此限制，研究者引入上下文压缩机制，但传统方法多为推理时静态操作，无法在训练过程中动态调整信息保留策略。

主流 RL 训练框架如 GRPO 依赖固定长度的工作上下文，一旦轨迹超出窗口即被截断或丢弃，导致训练视界受限，智能体无法学习需要长程依赖的任务。现有智能体上下文管理方法如 ACON 和 MemGPT 侧重于推理时的动态记忆调度或外部存储接口，但均未将摘要生成本身作为可学习的策略动作，导致摘要内容与任务奖励信号脱节。本文切入点在于将摘要生成嵌入 RL 策略空间，使模型在优化任务完成度的同时，自主学习何种信息值得保留、如何抽象以及何时丢弃无关细节，从而在有限工作窗口内扩展有效训练视界。

## 核心方法

### 标准多轮工具调用 MDP 参照系

本文基于 ReAct 范式构建标准多轮工具调用 MDP $M_V := (S, A, F, O, P, R, H)$，其中状态 $s_t$ 为累积的提示、输出与观察序列，动作 $a_t$ 为 LLM 自回归生成的响应，包含思考与工具调用部分。该参照系的关键局限在于状态转移 $P(s_{t+1}|s_t, a_t)$ 仅执行简单拼接 $s_{t+1} := (s_t, a_t, o_t)$，导致上下文长度单调递增，无法在训练过程中主动管理信息密度。

### 摘要增强 MDP 与状态重置机制

为解决上下文溢出问题，本文定义摘要增强 MDP $M_V^{sum} := (S, A, F, O, P, R, H, L)$，引入摘要阈值 $L$ 与摘要指令 $v_{sum}$。状态转移规则修改为：

$$
s_{t+1} := \begin{cases}
(s_t, a_t, o_t) & \text{if } v_{sum} \not\subseteq s_t, L_t < L \\
(s_t, a_t, o_t, v_{sum}) & \text{if } v_{sum} \not\subseteq s_t, L_t \ge L \\
(s_1, a_t) & \text{if } v_{sum} \subseteq s_t
\end{cases}
$$

其中 $L_t := |(s_t, a_t, o_t)|$。该设计动机在于打破上下文单调增长，当长度超过阈值时触发摘要生成，并将状态重置为初始提示 $s_1$ 与摘要 $a_t$ 的拼接。这一机制使工作上下文长度有界，即 $|s_t| + |a_t| \le L + 2L_A + L_O + |v_{sum}|$，其中 $L_A$ 和 $L_O$ 分别为单次 LLM 调用与工具调用的最大新 Token 数。通过状态重置，智能体在长程任务中始终维持紧凑且信息丰富的上下文表示，避免了因窗口溢出导致的训练中断。

### 策略梯度分解与 SUPO 算法

本文推导了 $M_V^{sum}$ 下的策略梯度表示（Theorem 2.1），将长程轨迹的梯度分解为 $I+1$ 个子轨迹梯度的和：

$$
\partial_\theta J(\theta) = \mathbb{E} \left[ R(s_T, a_T) \cdot \sum_{i=1}^{I+1} \sum_{t=t_{i-1}+1}^{t_i-1} \partial_\theta \log \pi_\theta(a_t | s_1, a_{t_{i-1}}, a_{t_{i-1}+1}, \dots, o_{t-1}) \right]
$$

其中 $a_{t_{i-1}}$ 为上一子轨迹的摘要。该公式表明，摘要动作 $a_{t_{i-1}}$ 的梯度与工具调用动作的梯度共享同一奖励信号 $R(s_T, a_T)$，实现了摘要质量与任务完成度的端到端联合优化。基于此，SUPO 算法采用 GRPO 风格的组相对优势估计，对每个 rollout 组内的 $I+1$ 个子轨迹统一计算优势值 $\hat{A}_j = \frac{R_j - \text{mean}(\{R_{j'}\})}{\text{std}(\{R_{j'}\})}$，并引入超长轨迹掩码机制，屏蔽未生成最终响应或摘要次数超限的轨迹梯度，以稳定优化过程并鼓励更多工具调用行为。

## 实验评估

实验在 CodeGym（合成函数调用）与 BrowseComp-Plus（搜索任务）上进行，基线为 GRPO。SUPO 在 CodeGym 上以 4K 工作上下文实现 47.7% 准确率，较 GRPO 的 44.5% 提升 3.2%；在 BrowseComp-Plus 上以 64K 工作上下文实现 53.0% 准确率，较 GRPO 的 39.0% 提升 14.0%。

| 数据集 | 算法 | 工作长度 | 有效长度 | 训练前准确率 | 训练后准确率 | 工具调用次数 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| CodeGym | GRPO | 32K | 32K | 32.0% | 44.5% | 52.1 |
| CodeGym | SUPO | 4K | 32K | 32.8% | 47.7% | 54.7 |
| BrowseComp-Plus | GRPO | 64K | 64K | 28.0% | 39.0% | 6.7 |
| BrowseComp-Plus | SUPO | 64K | 192K | 31.0% | 53.0% | 19.2 |

消融实验显示，移除超长掩码机制导致 BrowseComp-Plus 准确率从 53.0% 降至 44.0%，表明该机制对稳定长程优化至关重要。采用替代优势估计公式（3）使 CodeGym 准确率降至 42.1%，验证了组内相对优势估计在区分成功轨迹中的有效性。工具调用次数方面，SUPO 在 BrowseComp-Plus 上平均调用 19.2 次，是 GRPO 的 3 倍，证实摘要机制有效激励了更深入的探索行为。

评估边界方面，实验仅使用可验证终端奖励，未涵盖密集或延迟奖励场景。摘要触发依赖固定阈值 $L$（设为工作长度的 95%），未探索学习式触发策略。代码未公开，但提供了详细超参数（学习率 $1 \times 10^{-6}$，裁剪系数 $\epsilon_{high}=0.28, \epsilon_{low}=0.20$），可复现性中等。

## 关联研究分析

从问题动机看，SUPO 与 ACON 均针对智能体上下文管理，但 ACON 侧重推理时通过统一阈值动态管理历史轨迹，属于静态规则优化；SUPO 则将摘要生成纳入训练策略，使摘要内容随任务奖励信号自适应调整。这一差异源于 SUPO 解决的是训练视界限制问题，而非推理延迟问题，因此必须将摘要质量与任务效用绑定优化。ACON 的静态阈值无法在训练中区分不同任务对信息密度的需求，而 SUPO 的策略梯度机制允许模型在搜索任务中保留更多中间观察，在代码任务中聚焦关键变量状态。

从方法设计看，SUPO 与 ZipRL 均使用 RL 优化上下文策略，但 ZipRL 侧重多轮压缩级别的选择，属于离散决策；SUPO 侧重摘要内容的生成，属于连续动作空间优化。ZipRL 的压缩级别选择无法保证摘要语义的完整性，而 SUPO 通过 LLM 生成摘要，保留了自然语言的语义连贯性。然而，SUPO 的摘要生成依赖 LLM 的内在能力，若基础模型摘要能力较弱，可能导致关键信息丢失，这一风险在 ZipRL 的离散压缩中不存在。

## 总结

SUPO 解决了长程智能体 RL 训练中上下文窗口限制导致的训练视界瓶颈，通过将摘要生成纳入策略空间，实现了工作上下文与有效视界的解耦。该方法在 CodeGym 和 BrowseComp-Plus 上分别提升 3.2% 和 14.0% 的准确率，证明了端到端优化摘要策略的有效性。然而，实验仅验证了可验证终端奖励场景，摘要触发机制仍依赖固定阈值，未探索学习式触发策略。当任务分布异构且奖励信号稀疏时，固定阈值是否会导致摘要时机与任务关键节点错位，论文未给出回答。
