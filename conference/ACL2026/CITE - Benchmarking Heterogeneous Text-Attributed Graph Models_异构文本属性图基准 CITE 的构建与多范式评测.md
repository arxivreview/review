# ACL2026最新论文 ｜CITE: Benchmarking Heterogeneous Text-Attributed Graph Models ｜异构文本属性图基准 CITE 的构建与多范式评测

研究机构：中国科学院、中国科学院大学

作者：Chenghao Zhang、Qingqing Long、Ludi Wang 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ac1006534deb)

> 文本属性图（Text-Attributed Graphs, TAGs）旨在融合结构化拓扑与非结构化文本，但现有基准多局限于同质图，无法反映真实世界中节点与边类型多样的复杂场景。主流方法在异构图上面临结构感知缺失与语义对齐失效的双重瓶颈，导致性能大幅退化。本文构建了首个大规模异构 TAG 基准 CITE，并系统评测了四类学习范式在其中的表现。该工作填补了异构 TAG 评测空白，但受限于未纳入最新原生架构模型，其结论对前沿方法的适用性存疑。

## 研究背景

理解本文需厘清两个核心概念：异构性与文本属性。异构图包含多种节点与边类型（如论文、作者、期刊），其语义分布随类型变化，同质模型无法区分类型特定属性。文本属性则为节点附加非结构化信息（如摘要），需与拓扑结构联合建模。然而，现有 TAG 基准（如 Cora, PubMed）均为同质图，且文本编码方式单一，无法同时评估模型对结构异质性与文本语义的联合处理能力。

TAG 表示学习长期面临结构-语义融合难题。早期 GNN 依赖静态文本特征，阻碍端到端训练；LLM 虽具语义深度，但缺乏原生图结构感知，需通过序列化或投影注入拓扑信息，导致计算开销大且信息损失。现有方法多针对同质图优化，在异构图上因无法捕捉跨类型交互而失效。本文切入点在于：构建包含多类型实体与丰富文本的异构 TAG 基准，系统揭示现有方法在异构场景下的性能瓶颈，为下一代图学习架构提供评测平台。

## 核心方法

### 方法参照系

本文问题属于 TAG 表示学习，但区别于同质图基准，其核心差异在于节点与边类型的多样性。标准流程为：给定图 $G=(V, E, X)$，学习节点表示 $h_v$ 以完成分类或链接预测。本文关键差异在于 $V$ 和 $E$ 具有类型属性，需评估模型对类型特定语义与跨类型交互的捕获能力。

### 异构图构建与多标签分类

CITE 构建于光催化与电催化领域，包含 438,304 个节点与 1,220,374 条边，节点类型包括 Paper、Author、Journal、Keyword。设计动机在于：现有同质基准无法反映真实引文网络的类型多样性，导致模型在异构场景下的泛化能力被高估。CITE 采用多标签分类方案，单标签设置下含 84 个子领域，多标签设置下含 107 个子领域，允许每篇论文关联多个学科标签。节点表示学习需同时利用类型特定属性与跨类型关系，其目标函数可形式化为：

$$
\mathcal{L} = \sum_{v \in V} \mathcal{L}_{cls}(h_v, y_v) + \sum_{(u,v) \in E} \mathcal{L}_{link}(h_u, h_v)
$$

其中 $\mathcal{L}_{cls}$ 为节点分类损失，$\mathcal{L}_{link}$ 为链接预测损失。该设计强制模型在优化过程中平衡类型特定语义与跨类型结构信号，避免单一类型主导表示学习。

### 多范式评测协议

本文评测四类范式：同质图模型（GCN, GAT）、异构图模型（RGCN, HGT）、LLM 中心模型（Llama-2-7B, Qwen2.5-7B）、LLM+Graph 模型（TAPE, GraphGPT）。设计动机在于：现有方法在异构图上的表现缺乏系统对比，无法区分结构感知缺失与语义对齐失效的贡献。评测协议采用 60%/20%/20% 数据划分，所有图模型使用 BERT-base 分词（128-token 截断），LLM 模型采用结构化提示模板注入异构元数据。节点分类任务在 Paper 节点上进行，链接预测任务仅针对原生支持该任务的异构图模型，目标边为 Paper-Paper。该协议通过统一编码模型与数据划分，隔离异构性对性能的影响，确保跨范式比较的公平性。

## 实验评估

实验在 CITE 上进行，基线覆盖四类范式，但缺失 NAG、TAG-DLM 等 2025-2026 年最新原生架构方法。主实验结果显示，异构图模型中 SimpleHGN 表现最佳（Micro-F1 0.9907, Macro-F1 0.5052），LLM+Graph 模型中 TAPE 显著优于 GraphGPT（Macro-F1 0.5655 vs 0.0039）。LLM 中心模型表现极差（Macro-F1 最高 0.0094），表明其在细粒度多标签异构图上缺乏结构感知能力。

| 模型类型 | 模型名称 | Micro-F1 | Macro-F1 | AUC-ROC |
| :--- | :--- | :--- | :--- | :--- |
| 同质图模型 | GCN | 0.5057 | 0.0239 | - |
| 异构图模型 | SimpleHGN | 0.9907 | 0.5052 | 0.7392 |
| LLM 中心模型 | Qwen 2.5 | 0.0981 | 0.0094 | - |
| LLM+Graph 模型 | TAPE | 0.9936 | 0.5655 | - |

消融实验揭示关键设计决策：移除 Journal 节点导致 HGT 的 Macro-F1 从 0.7288 降至 0.7230，而移除 Author 节点对 SimpleHGN 影响较小（0.7392 → 0.7422）。TAPE 移除图传播模块后性能崩塌（Macro-F1 0.5655 → 0.0027），证明其优势源于显式结构传播而非简单 LLM-GNN 拼接。GraphGPT 的端到端范式在 CITE 上失败（Macro-F1 0.0039），凸显序列化注入结构信息在异构图上的信息损失。

评估边界方面，本文未报告置信区间，数值比较需谨慎。代码与数据公开于 HuggingFace 与 GitHub，但超参数细节仅在附录中提供。LLM 模型评测依赖特定提示策略，替代提示方案可能导致不同性能表现，限制了结论的普适性。

## 关联研究分析

从问题动机看，本文与 TAPE（He et al., 2023）同属 LLM+Graph 融合路线，但 TAPE 聚焦同质图上的伪标签协同，而本文揭示其在异构图上的性能依赖结构传播模块。TAPE 在 CITE 上的优势（Macro-F1 0.5655）源于其两阶段解耦设计：LLM 提供语义监督，GNN 处理拓扑细化。这一发现与 GraphGPT（Tang et al., 2024）的端到端范式形成对比，后者在 CITE 上失败（Macro-F1 0.0039），表明序列化注入结构信息在异构场景下信息损失严重。根源在于异构图类型多样性放大了序列化过程的结构保真度问题，而 TAPE 的解耦设计通过显式结构传播规避了这一瓶颈。

从方法设计看，本文与 HGT（Hu et al., 2020b）同属异构图模型，但 HGT 依赖动态注意力机制捕获类型特定关系，而本文通过消融实验量化了节点类型移除对性能的影响。HGT 在 CITE 上表现鲁棒（移除 Author 节点后 Macro-F1 仅降 0.0058），而 MAGNN 基于固定元路径，移除 Journal 节点后性能崩塌（0.5542 → 0.4970）。这一差异源于 HGT 的注意力机制能自适应调整类型权重，而 MAGNN 的固定元路径在类型移除后失去语义锚点。本文未探索原生架构方法（如 NAG）在异构图上的表现，其能否弥补 LLM 在异构场景下的结构感知缺失，论文未给出回答。

## 总结

本文要解决的核心矛盾是现有 TAG 基准无法反映真实世界的异构性，导致模型泛化能力被高估。切入点在于构建包含多类型实体与丰富文本的 CITE 基准，通过系统评测揭示现有方法在异构场景下的性能瓶颈。本文构建了 CITE 并评测四类范式，证明 TAPE 的解耦设计在异构图上优于 GraphGPT 的端到端范式（Macro-F1 0.5655 vs 0.0039），且异构图模型中 SimpleHGN 表现最佳（Micro-F1 0.9907）。本文边界在于未纳入最新原生架构方法，且 LLM 模型评测依赖特定提示策略。当引入 NAG 等原生架构方法时，其在异构图上的结构感知能力能否超越 TAPE 的解耦设计，论文未给出回答。
