# ACL2026最新论文 ｜WIST: Web-Grounded Iterative Self-Play Tree for Domain-Targeted Reasoning Improvement ｜基于开放网络的结构化自博弈树

研究机构：哈尔滨工业大学

作者：Fangyuan Li、Pengfei Li、Shijie Wang 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.22352)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.22352)

> 大语言模型在无外部监督下的自我进化长期受限于训练信号的来源与质量。纯内生自博弈易随迭代发生信号漂移，而依赖静态语料的自博弈则受限于预置数据的覆盖度与领域特异性。WIST 通过动态扩展领域树引导开放网络检索，构建路径一致的轻量级语料池，并在其上执行基于可验证奖励的 Challenger-Solver 自博弈，将学习性反馈转化为节点后验以指导后续探索。该方法在中等规模模型上实现了跨域推理能力的稳定提升，但其对开放网络噪声的鲁棒性在小模型场景下仍存疑。

## 研究背景

可验证奖励强化学习（Reinforcement Learning with Verifiable Rewards, RLVR）通过确定性验证器提供二值奖励，解决了开放域任务中缺乏客观真值信号的难题。然而，RLVR 的有效性高度依赖高质量训练数据的获取。传统自博弈范式如 R-Zero 完全依赖模型内生生成任务，虽摆脱了数据依赖，但迭代过程中模型倾向于重复已知解，导致探索空间受限与性能平台期。另一条路线如 SPICE 依赖预置的高质量语料库，虽保证了信号质量，但难以覆盖长尾领域，且语料构建与维护成本高昂。

现有方法在“信号质量”与“覆盖度”之间形成了难以调和的矛盾。纯内生方法牺牲了知识的外部性，导致模型在复杂推理中缺乏必要的领域先验；静态语料方法则牺牲了灵活性，无法适应动态变化的领域需求。WIST 的切入点在于将开放网络视为一个动态、未结构化的环境，通过结构化探索机制将其转化为可控的训练环境。它不依赖预置语料，而是通过模型自主分解领域概念，实时检索并清洗网络文档，从而在保持信号可验证性的同时，实现了领域覆盖的无限扩展。

## 核心方法

### 动态领域树与后验引导采样

WIST 将目标领域表示为有向树 $T=(V, E)$，节点分层组织，叶子节点对应可检索的知识单元。与静态语料库不同，该树在训练过程中动态扩展。当采样路径选中未知占位节点时，模型生成新的子主题，并通过维基百科标题匹配验证其有效性，防止幻觉概念污染树结构。每个节点维护一个 Beta 后验分布 $B(\alpha_{i,j}, \beta_{i,j})$，用于估计该子树产生“可学习”实例的概率。路径采样采用 Thompson 采样，从各候选子节点的后验中抽取分数，选择最高分分支。这种机制将多样性维护从问题生成层面下沉至概念探索层面，通过平衡利用高可学习性区域与探索不确定区域，避免了课程窄化。

### 网络语料构建与双角色自博弈

对于每条采样路径，WIST 以叶子节点为关键词检索网络文档，经语义相似度过滤与去噪后，构建路径一致的语料池 $C_{D_{L,k}}$。自博弈采用信息不对称设计：Challenger 基于可见文档 $d$ 生成 QA 对，Solver 在无文档条件下回答。Challenger 生成的 QA 对需通过规则验证器 $\Gamma(\cdot)$ 过滤，无效对获得惩罚奖励 $\rho$。Solver 对每个有效问题采样 $K$ 次响应，利用 Math-Verify 计算正确性指标 $\hat{y}_{i,k}$。难度整形奖励基于 Solver 响应的方差 $\text{Var}[\hat{y}_i]$ 设计：

$$
r_{\text{diff}} = \exp\left(-\frac{(\text{Var}[\hat{y}_i] - 0.25)^2}{2\sigma^2}\right)
$$

该公式在方差为 0.25（即正确率 50%）时奖励最大，惩罚过易或过难的问题，确保训练信号集中在模型能力边界。Solver 的优化采用 Dr. GRPO，使用全局归一化常数替代长度归一化，减少长度偏差。

### 滑动窗口后验更新

自博弈结果转化为节点可学习性观测 $g \in \{0, 1\}$，其中 $g=1$ 表示 QA 对处于能力边界（方差在阈值 $\tau_{\text{var}}$ 内）。由于模型能力随训练非平稳变化，累积历史统计量会偏向早期观测。WIST 采用滑动窗口机制，仅使用最近 $\mu$ 次观测更新有效参数：

$$
\tilde{\alpha}_{i,j} = 1 + \sum_{t \in W_{i,j}} g_t, \quad \tilde{\beta}_{i,j} = 1 + \sum_{t \in W_{i,j}} (1 - g_t)
$$

其中 $W_{i,j}$ 为节点 $D_{i,j}$ 最近 $\mu$ 次更新的索引集。该机制使探索偏好反映当前能力阶段的可学习性分布，提升了课程自适应性与探索效率，缓解了非平稳分布下的探索偏差。

## 实验评估

WIST 在 Qwen3 与 OctoThinker 系列模型上，与 R-Zero（纯内生）和 SPICE（静态语料）进行对比。评估涵盖 AMC、MATH500、GSM8K 等数学基准及 MMLU-Pro、GPQA-Diamond 等通用推理基准。

| 骨干模型 | 方法 | Overall Score |
| :--- | :--- | :--- |
| Qwen3-4B-Base | Base Model | 33.3 |
| Qwen3-4B-Base | R-Zero | 40.6 |
| Qwen3-4B-Base | SPICE | 41.8 |
| Qwen3-4B-Base | WIST | 43.1 |
| Qwen3-8B-Base | Base Model | 42.1 |
| Qwen3-8B-Base | R-Zero | 45.5 |
| Qwen3-8B-Base | SPICE | 46.0 |
| Qwen3-8B-Base | WIST | 46.7 |
| OctoThinker-8B-Hybrid-Base | Base Model | 22.9 |
| OctoThinker-8B-Hybrid-Base | R-Zero | 30.6 |
| OctoThinker-8B-Hybrid-Base | SPICE | 31.4 |
| OctoThinker-8B-Hybrid-Base | WIST | 32.6 |

在 Qwen3-4B-Base 上，WIST 的 Overall 分数为 43.1，较 R-Zero 提升 2.5 点，较 SPICE 提升 1.3 点。在 Qwen3-8B-Base 上，WIST 达到 46.7，略高于 SPICE 的 46.0。然而，在 OctoThinker-3B-Hybrid-Base 上，WIST 的 Overall 分数为 24.5，低于 SPICE 的 25.2，但显著高于 R-Zero 的 22.5。这一差异表明，开放网络噪声对小模型训练稳定性的负面影响更为显著，而静态语料库的受控环境在小模型场景下更具优势。

消融实验显示，树深度 $L$ 与窗口大小 $\mu$ 存在耦合敏感性。$L=4, \mu=5$ 时性能最佳，$L=2$ 时覆盖度不足，$\mu=20$ 时后验更新滞后于能力变化。在医学域迁移中，WIST 在 Qwen3-8B-Base 上平均准确率提升 14.79 点，显著高于 SPICE 与 R-Zero，验证了动态检索在长尾领域的有效性。在物理域，Qwen3-4B-Base 的 PhyBench EED 分数从 4.73 提升至 10.01，表明 WIST 能获取领域相关知识并转化为符号推理能力。

评估协议采用贪心解码，AIME 基准使用 32 次采样平均。代码已开源，但论文未报告计算开销与 GPU 资源需求。网络检索的噪声过滤阈值 $\tau_{\text{emb}}=0.5$ 与文档截断长度 5992 tokens 为固定超参数，未针对不同领域进行自适应调整。

## 关联研究分析

从问题动机看，WIST 与 R-Zero 的核心差异在于对“知识来源”的处理。R-Zero 假设模型内生生成足以覆盖任务空间，但实验表明其在迭代中易陷入局部最优，导致多样性坍缩。WIST 引入开放网络作为外部知识源，通过结构化检索弥补内生生成的知识盲区。然而，R-Zero 的纯内生特性使其在资源受限场景下更具部署优势，而 WIST 依赖网络检索，引入了外部依赖与潜在的数据泄露风险。SPICE 则代表了另一极端，其静态语料库虽保证了信号质量，但无法适应领域动态变化。WIST 的折中方案在于将语料库构建过程动态化，但这也意味着训练过程引入了非确定性因素，网络内容的变化可能导致训练信号的不稳定。

从方法设计看，WIST 与 IRIS 在自博弈稳定性机制上存在互补性。IRIS 通过 Rényi 散度自适应阶数调度优化损失函数，解决训练过程中的不稳定性问题，但其数据源仍依赖预置任务集。WIST 则通过滑动窗口后验更新解决课程非平稳性问题，但其损失函数仍采用标准的 Dr. GRPO。若将 IRIS 的散度调度机制引入 WIST 的自博弈训练，可能进一步提升训练稳定性，但论文未探索这一组合。此外，WIST 的 Challenger-Solver 信息不对称设计与 G-Zero 的提示辅助响应构建不同，前者依赖外部文档，后者依赖模型自身提示能力。在开放域任务中，WIST 的文档依赖可能限制其泛化能力，而 G-Zero 的纯内生方法虽缺乏外部知识，但避免了数据噪声干扰。

## 总结

WIST 旨在解决自博弈训练中信号质量与领域覆盖度的矛盾，通过动态领域树引导开放网络检索，构建路径一致的语料池，并在其上执行基于可验证奖励的自博弈。该方法在 Qwen3-4B-Base 上实现 Overall 分数 43.1，较 R-Zero 提升 2.5 点，在医学域迁移中提升 14.79 点，验证了动态检索在长尾领域的有效性。然而，实验暴露了开放网络噪声对小模型训练稳定性的负面影响，OctoThinker-3B 上 WIST 性能低于 SPICE，表明网络噪声与模型容量的交互作用是关键瓶颈。当模型规模进一步缩小至 1B 以下时，滑动窗口后验更新能否有效过滤网络噪声，论文未给出回答。
