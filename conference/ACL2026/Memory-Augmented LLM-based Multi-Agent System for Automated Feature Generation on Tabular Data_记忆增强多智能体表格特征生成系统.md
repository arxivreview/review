# ACL2026最新论文 ｜Memory-Augmented LLM-based Multi-Agent System for Automated Feature Generation on Tabular Data ｜记忆增强多智能体表格特征生成系统

研究机构：中国科学技术大学、浙江大学

作者：Fengxian Dong、Zhi Zheng、Xiao Han 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.20261)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.20261)

> 表格数据自动化特征工程旨在替代人工设计，以突破传统算子库语义缺失与单策略探索僵化的瓶颈。现有大语言模型（LLM）方法虽引入语义理解，但缺乏基于下游性能反馈的动态适应机制，导致生成过程与学习目标脱节。MALMAS通过Router Agent动态路由六个专职智能体，并集成程序、反馈与概念三级记忆架构，将单轮评估转化为持久学习信号。该框架在16个分类与7个回归数据集上取得了平均排名1.12与1.29的最优表现，但其性能高度依赖充足的评估预算，且在标签稀缺场景下的鲁棒性尚未得到验证。

## 研究背景

表格数据预测性能高度依赖特征工程，而人工设计特征耗时且难以规模化。自动化特征工程（Automated Feature Engineering, AutoFE）的核心在于学习特征变换函数 $\phi$，使下游模型 $f(\phi(X))$ 性能最大化。传统方法如Deep Feature Synthesis（DFS）与AutoFeat依赖预定义算子库，虽高效但受限于固定数学原语，无法捕捉业务语义。当LLM被引入后，问题定义从“在固定算子空间中搜索”转变为“利用语义理解生成可执行代码”，CAAFE等工作证明了语义生成在可解释性上的优势。

然而，现有LLM方法多采用静态单智能体策略，缺乏基于历史经验与任务反馈的适应机制。这种反馈不敏感导致特征生成沦为低效的试错过程，无法优先探索高价值变换。MALMAS的切入点在于将特征生成解耦为多智能体协作，并通过记忆机制实现跨轮次的信用分配与策略精炼，解决单策略探索空间受限与反馈缺失的双重瓶颈。

## 核心方法

### 多智能体并行生成架构

MALMAS将特征生成置于“扩展-缩减”范式的扩展阶段，但将单一生成器替换为专职智能体池。传统方法通常由单一LLM实例根据固定提示生成特征，导致特征同质化。MALMAS依据变换复杂度、数据范围与数据类型依赖三个正交维度，实例化六个智能体：Unary-Feature、Cross-Compositional、Temporal-Feature、Aggregation-Construct、Local-Transform与Local-Pattern。Router Agent基于任务元数据与累积记忆动态激活子集 $A_{(r)}$，各智能体并行生成特征子集 $T_i^{(r)}$，其聚合过程定义为：

$$ T^{(r)} = \bigcup_{A_i \in A_{(r)}} T_i^{(r)} $$

该设计通过互补探索缓解单智能体策略的僵化，扩大整体搜索空间。

### 三级记忆架构与信用分配

为解决反馈缺失问题，MALMAS为每个智能体维护程序记忆（ProcMem）、反馈记忆（FeedMem）与概念记忆（ConMem）。程序记忆记录执行轨迹以抑制冗余探索；反馈记忆关联特征与下游验证效用，实现信用分配；概念记忆由LLM从历史轨迹中蒸馏可复用启发式规则。全局概念记忆由Summary Agent聚合跨智能体反馈，形成共享先验。第 $r$ 轮智能体 $A_i$ 的概念记忆更新公式为：

$$ \text{ConMem}_{i}^{(r)} = \text{LLM}(\text{ProcMem}_{i}^{(r)}, \text{FeedMem}_{i}^{(r)}) $$

这一机制将昂贵的下游评估信号转化为持久指导，使后续轮次偏向高收益变换，避免重复无效探索。

## 实验评估

实验在16个分类与7个回归数据集上进行，采用6-4训练测试划分与三次随机种子重复，下游模型统一为XGBoost。基线覆盖传统方法（DFS, AutoFeat, OpenFE）与LLM方法（CAAFE, OCTree, LLMFE），但缺失TopoFE、SymboLLM-FE等2026年最新进化搜索方法，限制了与当前SOTA的直接对比。

| 数据集类型 | 方法 | MeanRank | 备注 |
| :--- | :--- | :--- | :--- |
| 分类 (16个) | MALMAS | 1.12 | 优于OpenFE (3.12) |
| 分类 (16个) | OpenFE | 3.12 | 传统方法最优 |
| 回归 (7个) | MALMAS | 1.29 | 优于LLMFE (3.14) |
| 回归 (7个) | LLMFE | 3.14 | LLM基线最优 |

MALMAS在分类任务中MeanRank为1.12，显著优于传统方法OpenFE的3.12与LLM方法LLMFE的3.75；在回归任务中MeanRank为1.29，优于LLMFE的3.14。消融实验显示，从Base到+A6，MeanRank从5.11降至2.30，表明智能体扩展提升了多样性；加入记忆模块后降至1.12，验证了记忆对策略精炼的关键作用。在Adult数据集上，启用记忆后AUC随轮次从0.85升至0.88，而无记忆配置在第二轮后性能停滞。

评估边界方面，MALMAS依赖充足的下游评估预算，当候选特征池增长时，重复训练与验证可能成为计算瓶颈。论文报告平均每个数据集耗时0.452小时，消耗147.57k tokens，成本约$0.17，表明其计算开销可控。代码已开源，但缺乏对标签稀缺或评估预算受限场景的鲁棒性测试，且未量化记忆模块对特征可解释性的具体贡献。

## 关联研究分析

从问题动机看，MALMAS与FAMOSE同属多智能体/ReAct范式，但FAMOSE侧重单智能体迭代探索，而MALMAS强调多智能体并行与记忆增强。FAMOSE通过上下文窗口记录迭代成功与失败特征，但缺乏跨智能体的知识共享机制；MALMAS引入Summary Agent聚合全局概念记忆，解决了单智能体视角局限导致的特征同质化问题。这一差异源于任务特性：表格数据特征空间高维且异构，单一策略难以覆盖所有变换维度，而多智能体分工能更有效地探索互补区域。

从方法设计看，MALMAS与CAAFE均利用LLM语义生成，但CAAFE缺乏反馈适应机制，生成策略静态固定。MALMAS通过三级记忆实现动态策略调整，将下游性能反馈转化为提示工程中的条件信号。CAAFE的生成过程与学习目标脱节，而MALMAS的信用分配机制确保了生成方向与验证指标对齐。这种设计差异暗示，在需要高可解释性与业务对齐的场景中，反馈驱动的记忆机制比纯语义生成更具鲁棒性，但其在分布漂移下的因果稳定性仍待验证。

## 总结

MALMAS旨在解决LLM特征生成中反馈缺失与探索僵化的核心矛盾。通过Router Agent动态路由与三级记忆架构，它将单轮评估转化为持久学习信号，实现了跨轮次的策略精炼。实验表明，该框架在16个分类数据集上取得MeanRank 1.12，在7个回归数据集上取得1.29，显著优于传统与LLM基线。然而，其性能高度依赖充足的评估预算，且在标签稀缺或评估受限场景下的鲁棒性未经验证。当候选特征池规模扩大导致评估成本指数级增长时，记忆机制能否在有限预算下维持策略精炼效率，论文未给出回答。
