# ACL2026最新论文 ｜Can LLM Agents Simulate Multi-Turn Human Behavior? Evidence from Real Online Customer Behavior Data ｜在线购物行为模拟的定量评估与推理增强微调

研究机构：美国东北大学

作者：Yuxuan Lu、Jing Huang、Yan Han 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f53eda16eb1e)

> 现有LLM行为模拟研究多依赖主观“可信度”或最终结果匹配，缺乏对多轮交互中逐步动作准确性的客观量化。本文切入点在于构建首个基于真实电商日志的过程中心基准，并验证合成推理轨迹在微调中的增益。通过引入简化HTML上下文与合成推理管线，将任务定义为逐步动作预测。该工作确立了行为模拟的定量下限，但绝对准确率仍低，且合成推理是否真正映射人类认知机制存疑。

## 研究背景

当LLM代理被用于模拟人类在线购物行为时，其输入通常包含静态用户画像与历史会话数据，输出为下一步动作。然而，真实购物决策高度依赖对网页视觉布局、产品图片等感知线索的即时解读，而纯文本模型仅能获取结构化标记信息，这种模态差异导致模型难以捕捉人类基于视觉吸引力的非理性点击或搜索修正行为。此外，现有评估多聚焦于最终购买结果或主观可信度，忽略了中间决策序列的保真度，使得模型在“看似合理”的表象下，实际动作序列与人类轨迹存在巨大偏差。

该领域长期面临的核心矛盾是定性模拟的“可信”与定量模拟的“准确”之间的脱节。主流路线如Generative Agents（Park et al., 2023）通过涌现行为验证了LLM的社会模拟潜力，但其评估框架依赖定性观察；WebArena（Zhou et al., 2024）等基准虽引入客观指标，但仅关注任务完成率，未考察逐步动作的匹配度。这种评估缺失导致研究者无法区分模型是真正理解了人类决策逻辑，还是仅通过提示工程生成了表面合理的文本。本文的切入点在于填补这一空白，提出ShopCART基准，将评估粒度从会话级结果下沉至动作级序列，并探索通过微调与合成推理提升逐步预测精度的可行性。

## 核心方法

### 任务定义与上下文表示

本文任务定义为在多轮购物会话中，基于当前观察上下文 $c_t$ 与历史动作-推理序列，预测下一步动作 $a_t$ 及其推理 $r_t$。与通用Web代理不同，本文采用简化HTML格式作为上下文表示，移除脚本、CSS等不可见元素，保留列表、表格等结构信息。这一设计动机在于平衡信息完整性与模型可处理性：原始HTML包含大量噪声，而自定义DSL缺乏通用性。简化HTML既保留了关键结构，又利用了LLM对HTML格式的预训练熟悉度，无需重新定义元素语义。

### 合成推理轨迹生成

真实购物数据缺乏动作背后的推理标注，本文借鉴DeepSeek-R1的推理合成策略，构建推理生成管线。给定上下文 $c_t$ 与动作 $a_t$，利用LLM生成自然语言推理 $r_t$。该推理并非复现人类真实思维，而是作为结构化中间表示，帮助模型对齐上下文线索与动作选择。公式上，模型学习函数 $f(c_{1...t}, a_{1...t-1}, r_{1...t-1}) = r_t, a_t$，其中推理与动作联合优化。这一设计的动机在于解决纯动作预测中模型缺乏决策依据的问题，通过显式建模“为什么做”，提升模型对细微行为模式（如搜索修正、会话终止）的捕捉能力。

### 微调策略与训练目标

模型在完整会话序列上进行微调，输入包含历史上下文、动作与合成推理。训练目标是最小化推理与动作token的下一词预测损失，上下文token损失被掩码。评估阶段，模型先生成推理 $r_t$，再基于 $r_t$ 生成动作 $a_t$，采用多轮对话格式。这一两阶段生成策略的设计动机在于强制模型在输出动作前进行显式推理，避免直接映射上下文到动作的捷径学习。通过掩码上下文损失，模型专注于学习从观察与历史到决策的映射，而非记忆上下文内容。

## 实验评估

实验基于ShopCART数据集，包含31,865个会话与230,965个动作。基线覆盖DeepSeek-R1、Claude 3.5 Sonnet v2等通用LLM，但缺失专门微调模型（如SOCRATESQWEN）或强化学习基线（如Shop-R1）。

| 模型 | 动作生成准确率 (%) | 最终结果F1 (%) |
| :--- | :--- | :--- |
| DeepSeek-R1 | 11.86 | 20.01 |
| Claude 3.5 Sonnet v2 | 11.69 | 18.54 |
| Qwen2.5-7B (微调+推理) | 17.26 | 33.86 |
| LLaMA 3.2-3B (微调+推理) | 15.77 | 33.99 |

微调后Qwen2.5-7B动作准确率17.26%，较DeepSeek-R1提升5.4%（p < 10⁻¹⁰），F1分数33.86%较基线提升13.85%。消融显示，加入合成推理后，Qwen2.5-7B的F1从26.92%升至33.86%，相对增益25.78%；LLaMA 3.2-3B的F1从4.73%升至33.99%，相对增益618.60%。这表明合成推理对小模型增益显著，但对大模型边际收益递减。

评估边界方面，精确匹配指标过于严格，未考虑人类行为的随机性（如拼写错误、半随机点击）。可复现性上，代码与数据已开源，训练使用64块H200 GPU，耗时约3小时，超参数（学习率2e-5，batch size 64）已披露。

## 关联研究分析

从问题动机看，本文与SimBench（Hu et al., 2025）形成互补：SimBench评估群体级分布保真度，本文聚焦个体级动作序列匹配。SimBench的分布指标无法捕捉逐步决策的时序依赖，而本文的精确匹配指标忽略了群体统计特性。这种差异源于任务定义：SimBench关注“是否像人群”，本文关注“是否像特定个体”。从方法设计看，本文与Shop-R1（ICLR 2026）同属在线购物模拟，但Shop-R1采用强化学习优化分布倾向，本文采用监督微调优化逐步预测。Shop-R1的Exact Match 0.65远高于本文的17.26%，可能源于任务定义差异（Shop-R1可能评估会话级结果而非逐步动作）或数据规模差异。本文未探索强化学习在逐步预测中的有效性，这一盲区限制了方法泛化性。

## 总结

本文核心矛盾在于LLM行为模拟缺乏逐步动作的定量评估标准。切入点在于构建ShopCART基准，将评估粒度下沉至动作级，并验证合成推理微调的增益。方法上，通过简化HTML上下文与两阶段生成策略，实现逐步动作预测。实验证明微调后Qwen2.5-7B动作准确率17.26%，F1 33.86%，显著优于通用LLM基线。边界在于精确匹配指标未容忍人类非理性行为，且合成推理是否真正映射人类认知机制未验证。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
