# ACL2026最新论文 ｜PEAR: Pairwise Evaluation for Automatic Relative Scoring in Machine Translation ｜成对相对评分：机器翻译质量估计的范式重构

研究机构：意大利罗马第一大学

作者：Lorenzo Proietti、Roman Grundkiewicz、Matt Post

论文原文见 [arXiv](https://arxiv.org/abs/2601.18006)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_289c46bb1f62)

> 机器翻译自动评估长期依赖单候选绝对分数回归，但在强系统间细微质量差异下区分度不足，且与人类比较判断的结构性偏好存在错配。现有神经指标虽提升了语义捕捉能力，却因独立预测绝对分数导致误差累积，无法直接建模候选间的相对优劣。PEAR将无参考质量估计重构为分级成对比较任务，通过联合编码源文与双译文预测质量差异值。该范式在同等训练条件下显著优于单候选基线，且小模型性能逼近大模型，但其对传递性的保证及多候选扩展效率仍存疑。

## 研究背景

当评估者面对两个质量相近的机器翻译输出时，直接判断哪个更好比分别给两者打分更一致，这一现象源于人类感知中的相对判断优势。传统质量估计（Quality Estimation, QE）指标如COMET和MetricX采用单候选绝对分数回归，即模型独立预测每个译文的标量质量，比较时通过分数差值推导相对优劣。这种“先绝对后相对”的路径在细微差异场景下易受独立预测误差干扰，且无法显式建模平局或偏好强度。

主流神经指标路线虽解决了n-gram指标的语义盲区，但绝对分数范式在强系统对比中面临区分度瓶颈。WMT24等基准显示，当系统性能接近时，绝对分数的排序一致性下降，而人类评估协议已转向侧边对比（Side-by-side）以提升一致性。PEAR的切入点在于将比较本身作为预测目标，而非绝对分数的衍生结果，直接对齐人类比较判断的认知机制。

## 核心方法

### 单候选回归参照系

标准QE流程中，模型$g_\theta$接收源文$s$与单候选译文$mt$，输出绝对分数$\hat{s}(s, mt)$。比较两个候选时，需计算$\hat{s}(s, mt_a) - \hat{s}(s, mt_b)$。该流程的关键差异在于：PEAR摒弃了独立预测绝对分数的步骤，改为在共享上下文中直接预测差异值，避免了两次独立推理的误差累积。

### 成对相对评分架构

PEAR采用跨编码器架构，将源文$s$与双候选$mt_a, mt_b$序列化为单一输入$x = [\text{BOS}] s [\text{SEP}] mt_a [\text{SEP}] mt_b [\text{EOS}]$。设计动机在于解决单候选模型无法捕捉候选间交互效应的问题。模型通过掩码平均池化提取源文与候选的表示$h_{src}, h_a, h_b$，并构建源感知特征$\phi_k = [h_k; h_k \odot h_{src}; |h_k - h_{src}|]$。最终相对分数由差值$z = u_a - u_b$经缩放系数$\alpha$输出：

$$
\hat{\Delta}_{ab} = \alpha (u_a - u_b), \quad \alpha = \text{softplus}(\alpha_{raw}) + \epsilon
$$

该公式确保输出为正缩放下的有符号差异，正值偏好$mt_a$，负值偏好$mt_b$，零值对应平局。

### 反对称正则化训练

为强制模型满足候选顺序反转时分数反号的物理约束，PEAR引入反对称正则项。训练损失包含Huber损失$L_{diff}$与反对称项$L_{flip}$：

$$
L = \ell_\delta(\hat{\Delta}_{ab} - \Delta^\star_{ab}) + \lambda_{flip} (\hat{\Delta}_{ab} + \hat{\Delta}_{ba})^2
$$

其中$\Delta^\star_{ab}$为人类分数差值。设计动机在于解决单候选模型在顺序敏感任务中的不一致性，确保$\hat{\Delta}_{ab} = -\hat{\Delta}_{ba}$，从而在推理时可通过双向平均降低顺序偏差。

## 实验评估

实验基于WMT24 MQM基准，对比MetricX、XCOMET、CometKiwi等主流QE及参考指标。基线覆盖神经回归与参考依赖路线，但缺失LLM-as-Judge直接对比，可能低估成对范式在生成式评估中的竞争位置。

| 方法 | 参数量 | Avg Corr |
| --- | --- | --- |
| PEARboth (560M) | 560M | 70.1 |
| MetricX-24-Hybrid-QE-XL | 3.7B | 69.9 |
| XCOMET-QE | 24B | 69.5 |
| CometKiwi | 560M | 64.0 |

PEARboth (560M)以70.1的平均相关性超越3.7B参数的MetricX和24B参数的XCOMET，表明成对框架在小模型上具有显著效率优势。

消融实验显示，双向推理（PEARboth）与单序推理性能接近，验证了反对称正则化的有效性。知识蒸馏增强（KD）将PEARboth相关性提升至70.4，接近CometKiwi-XXL (70.3)，但参数量仅为后者的1/20。

评估边界方面，论文未报告置信区间，且仅在三个语言对（En-De, En-Es, Ja-Zh）上验证。代码与检查点已开源，但超参数细节需查阅附录，复现成本中等。

## 关联研究分析

从问题动机看，PEAR与MT-RANKER均针对成对评估，但MT-RANKER采用二分类框架，输出空间不包含平局与偏好强度，而PEAR预测分级差异，保留了连续偏好信息。这一差异源于任务特性：MT-RANKER侧重排序决策，PEAR侧重质量差异量化，后者在细微差异场景下更具区分度。

从方法设计看，PEAR与ReMedy均利用比较信号，但ReMedy通过Bradley-Terry偏好损失优化绝对分数，PEAR直接预测差异值。ReMedy在WMT22-24基准上取得0.93相关性，但依赖成对偏好数据构建，而PEAR仅需绝对分数差值，数据获取成本更低。PEAR的参考锚定模式避免了$N(N-1)/2$次成对比较，解决了COMET-poly在多候选场景下的计算瓶颈，但传递性保证仍依赖局部反对称约束，全局一致性未显式验证。

## 总结

PEAR针对强系统间细微质量差异区分度不足的核心矛盾，抓住人类比较判断优于绝对打分的认知特性，将QE重构为分级成对比较任务。通过联合编码与反对称正则化，PEAR在WMT24基准上以560M参数量达到70.1平均相关性，超越3.7B参数的MetricX。其边界在于仅验证了局部反对称性，未证明全局传递性，且多候选扩展仍需参考锚定以避免二次方复杂度。当候选数量超过2时，成对评分的累积误差是否可控，论文未给出回答。
