# ACL2026最新论文 ｜AfriqueLLM: How Data Mixing and Model Architecture Impact Continued Pre-training for African Languages ｜异构数据混合驱动的低资源语言继续预训练

研究机构：加拿大麦吉尔大学、德国慕尼黑大学

作者：Hao Yu、Tianyi Xu、Michael A. Hedderich 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_703d276a474d)

> 低资源语言适配的核心矛盾在于，继续预训练（CPT）虽能注入语言知识，但单一语料往往导致源语言能力的灾难性遗忘与推理能力的退化。现有CPT方案多依赖单语数据或简单的回放机制，缺乏对数据构成比例的精细实证分析，导致模型在数学推理等复杂任务上增益有限。本文通过系统消融代码、数学及合成翻译数据在CPT语料中的占比，揭示了数据混合策略对下游性能的决定性影响。这一实证发现为低资源语言适配提供了可复现的数据配方，但其结论是否普遍适用于非非洲语言及更大规模模型，仍需进一步验证。

## 研究背景

当模型通过CPT学习新语言时，优化过程极易引发灾难性遗忘（Catastrophic Forgetting），即原有英语能力或通用推理能力受损。为缓解此问题，常规做法是在训练集中混入少量高资源语言（HRL）数据作为分布锚点。然而，仅靠HRL数据无法弥补低资源语言在数学、代码等结构化知识上的缺失，导致模型在推理任务上表现疲软。这引出了数据混合（Data Mixture）的关键问题：如何在有限的计算预算下，通过异构数据（单语、代码、数学、合成翻译）的最优配比，同时实现语言知识的注入与推理能力的保持？

多语言LLM的适配长期受限于数据稀缺与分词器碎片化，早期研究依赖扩大模型规模或构建多语言预训练语料，但“多语言诅咒”导致低资源语言性能被高资源语言稀释。随着开源基座模型的普及，研究重心转向参数高效微调与模型合并，但全参数CPT在深度知识注入上仍具优势。Lugha-Llama和AfriInstruct等工作验证了CPT在非洲语言上的可行性，但主要依赖单语数据，未系统探讨异构数据对推理能力的贡献。本文切入点在于：将CPT视为一个数据工程问题，通过控制变量法量化不同数据源对下游任务的边际贡献，从而解决“数据构成比模型规模更决定CPT增益”这一被忽视的核心变量。

## 核心方法

### 方法参照系

标准CPT流程通常使用目标语言单语数据与少量源语言回放数据，旨在最小化遗忘。本文问题与该通用流程的关键差异在于，它不将数据视为同质语料，而是将其解耦为单语（M）、代码（C）、数学（M）、合成翻译（S）和平行数据（P）五个独立维度，并系统评估其组合效应。

### 异构数据混合策略

设计动机在于解决单语CPT导致的推理能力退化问题。传统方法中，大量噪声单语数据会覆盖模型内部的逻辑一致性，导致数学推理分数下降。本文引入代码和数学数据作为“认知锚点”，假设结构化数据能维持内部一致性。具体而言，语料由22.8B非洲单语token、1B代码token、1.07B数学token及324M合成翻译token组成。合成数据通过GPT-4.1将英语文档翻译至17种非洲语言，覆盖10个领域，旨在弥补领域覆盖不足。

$$
\mathcal{D}_{CPT} = \mathcal{D}_{Mono} \cup \mathcal{D}_{Code} \cup \mathcal{D}_{Math} \cup \mathcal{D}_{Syn} \cup \mathcal{D}_{HRL}
$$

该公式表示CPT语料是单语、代码、数学、合成及高资源语言数据的并集，其中各子集的大小经过UniMax采样策略平衡，确保低资源语言不被高资源语言主导。

### 采样与过滤机制

设计动机在于应对非洲语言语料的高度不平衡及平行数据的质量噪声。UniMax采样将每种高资源语言上限设为1B token，并对低资源语言进行最多5个epoch的上采样，以平衡分布。对于平行数据，本文使用SSACOMET模型进行质量过滤，仅保留质量分大于0.7的样本，最终获得456M token的高质量平行语料。

$$
w_i = \min(1, \frac{N_{max}}{N_i})
$$

该公式定义了UniMax采样权重，其中$N_i$为语言$i$的原始token数，$N_{max}$为上限阈值。此机制确保小语种在训练中获得足够的曝光率，同时防止大语种过度主导梯度更新。

## 实验评估

实验基于AfroBench-Lite基准，涵盖7项任务，基线包括Llama 3.1、Gemma 3和Qwen 3系列。本文未对比PEFT或模型合并类方法，但通过CPT与SFT基线的对比，证明了预训练阶段数据混合的优势。

| 模型 | AfriMGSM | AfriMMLU | Flores | Overall |
| :--- | :--- | :--- | :--- | :--- |
| Qwen 3 8B (Base) | 34.6 | - | - | 29.0 |
| AfriqueQwen-8B | 61.0 | - | - | 58.5 |
| Gemma 3 12B (Base) | 59.9 | - | - | 53.6 |
| AfriqueGemma-12B | 60.8 | - | - | 58.3 |
| AfriqueQwen-14B | 64.7 | - | - | 63.6 |

AfriqueQwen-14B在Overall得分上达到63.6，显著优于Gemma 3 27B的60.71，且在高资源语言（HRL）性能保持上优于Llama 3.1 8B（-11.0% vs -4.1%）。

| 数据混合 | Flores | AfriMGSM | AfriMMLU | AfriXNLI |
| :--- | :--- | :--- | :--- | :--- |
| Gemma 3 4B + Mono | 62.72 | 10.68 | 35.41 | 40.76 |
| Gemma 3 4B + CMS | 63.17 | 14.81 | 35.86 | 39.93 |
| Gemma 3 12B + Mono | 65.78 | 23.78 | 46.72 | 45.19 |
| Gemma 3 12B + CMS | 66.23 | 30.87 | 48.46 | 44.57 |
| Gemma 3 12B + CMSP | 65.83 | 29.61 | 48.32 | 43.26 |

消融实验显示，加入代码和数学数据（CMS）相比仅加单语数据，在AfriMGSM上提升了6.09分（12B模型），验证了“认知锚点”假设。然而，在12B模型上，加入平行数据（CMSP）反而导致AfriMGSM下降1.26分，表明大规模模型对噪声平行数据更敏感，挑战了“更多平行数据更好”的直觉。

评估协议采用5-shot设置，翻译任务使用SSACOMET指标。局限在于未报告置信区间，且仅覆盖20种非洲语言，未验证结论在其他低资源语言上的泛化性。代码和超参数已公开，但训练稳定性存在梯度范数尖峰，可能影响复现精度。

## 关联研究分析

从数据策略看，本文与Lugha-Llama形成鲜明对比。Lugha-Llama仅使用WURA单语数据，而本文引入异构混合。差异根源在于任务目标：Lugha-Llama侧重语言理解，而本文关注推理能力。本文发现代码/数学数据对推理的提升是架构依赖的，Qwen 3系列因基座数学能力强，增益更显著，这暗示数据混合效果受基座先验影响，而非通用机制。

从模型选择看，本文与SmolLM系列共享动态数据配比思想，但本文更强调静态混合比例的消融。SmolLM关注训练阶段的比例调整，而本文关注最终语料构成的影响。本文未探索训练过程中的动态调整，这可能是一个盲区：静态最优配比是否适用于所有训练阶段，论文未给出回答。

## 总结

本文要解决的核心矛盾是CPT中语言知识注入与推理能力保持的冲突。现有方法依赖单语数据，无法弥补结构化知识缺失，而本文通过系统消融异构数据混合，证明了代码和数学数据作为“认知锚点”的有效性。实验表明，AfriqueQwen-14B在非洲语言基准上达到63.6分，优于Gemma 3 27B，且HRL性能损失最小。本文的边界在于，其结论基于20种非洲语言和14B参数规模，未验证在更大模型或非非洲语言上的泛化性。当基座模型的多语言能力极强时，异构数据混合的边际收益是否递减，论文未给出回答。
