# ACL2026最新论文 ｜OPeRA: A Dataset of Observation, Persona, Rationale, and Action for Evaluating LLMs on Human Online Shopping Behavior Simulation ｜电商行为序列模拟基准 OPeRA

研究机构：美国东北大学、美国南加州大学

作者：Ziyi Wang、Yuxuan Lu、Wenbo Li 等 16 人

论文原文见 [arXiv](https://arxiv.org/abs/2506.05606)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_279cf0ec082e)

> 大语言模型（LLM）在模拟真实用户细粒度行为时，长期受限于缺乏包含内部推理与完整上下文的高质量数据。现有数据集多聚焦于宏观任务完成或稀疏交互记录，无法支撑对个体决策链条的精准评估。本文通过构建包含观察、画像、理由与动作四要素的 OPeRA 数据集，确立了零样本预测特定用户下一步动作的基准。该工作填补了微观行为模拟的评估空白，但 22.06% 的准确率揭示了当前 LLM 在个性化行为预测上的显著局限。

## 研究背景

理解 LLM 模拟人类行为的真实性，需区分“可信行为”与“准确行为”。可信行为指生成的动作序列符合人类交互逻辑，而准确行为要求动作与特定真实用户的实际轨迹严格对齐。实现准确行为的前提是掌握用户决策的即时动机，即理由（Rationale），以及用户的长期特征，即画像（Persona）。缺乏这两类信息，模型只能依赖统计规律生成“平均人”行为，导致个体异质性丢失。

社会调查模拟领域已证实，仅依赖人口统计属性不足以捕捉个体差异，引入丰富背景故事能显著提升保真度。然而，主流研究多聚焦于离散选项预测（如问卷回答）或宏观任务完成，忽视了连续动作流中的微观决策机制。现有电商数据集如 Amazon-M2 仅记录点击与购买，缺乏页面上下文与推理过程；Web Agent 数据集如 Mind2Web 虽含观察，但数据源自标注者或合成日志，缺乏真实用户的个性化行为模式。这种数据缺口导致 LLM 无法在细粒度动作层面被有效评估，阻碍了数字孪生技术在个性化推荐与 UX 测试中的落地。

本文切入点在于构建首个包含真实用户即时理由与完整网页观察的电商行为基准。通过自研插件 ShoppingFlow 采集真实购物会话，将评估任务从“群体分布对齐”下沉至“个体动作预测”，旨在验证 LLM 能否基于 Persona 与历史交互，准确复现特定用户在复杂决策流程中的下一步操作。

## 核心方法

### 数据构建与动作空间定义

本文问题属于个体行为仿真，但区别于文本响应生成，其输出为结构化动作序列。标准流程通常依赖预训练模型直接映射输入到输出，但本文关键差异在于引入了稀疏的即时理由作为中间监督信号，并定义了简化的动作空间以平衡复杂度与可预测性。

### 动作空间抽象与理由注入

为降低预测难度，本文将原始交互抽象为三类高层动作：input、click、terminate。其中 click 进一步细分为 12 种子类型（如 review、search、product_option），以保留语义结构。设计动机在于原始动作流噪声大且分布极度不平衡，直接预测原始 DOM 元素不可行。动作预测函数定义为：

$$ a_t = F_{action}(a_{1...t-1}, r_{1...t-1}, o_{1...t}, P_i) $$

该公式表明，当前动作 $a_t$ 是历史动作、历史理由、当前网页观察及用户画像 $P_i$ 的联合函数。理由 $r_k$ 为可空字符串，仅在插件触发时采集（8% 概率），用于显式捕捉用户动机。这种设计解决了传统行为模拟中“知其然不知其所以然”的问题，使模型能利用因果线索而非仅靠相关性进行预测。

### 零样本评估协议

评估采用零样本提示设置，不微调模型。输入包含用户画像、历史动作-观察对及当前观察，输出为下一步动作。设计动机在于验证 LLM 的通用泛化能力，而非过拟合特定数据集。评估指标包括动作生成准确率（Exact Match）、动作类型宏 F1、点击子类型加权 F1 及会话结果预测。该协议直接对标“数字孪生”的个体保真度要求，而非群体统计效度，与主流社会调查模拟的评估范式形成鲜明对比。

## 实验评估

实验在 OPeRA-test 上进行，该子集包含 15 名用户、90 个会话及 992 个动作。基线仅对比四个 LLM：GPT-4.1、DeepSeek-R1、Claude-3.7-Sonnet 和 Llama-3.3-70B-Instruct。缺失了分布对齐方法（如 DSA）或微调方法（如 HumanLM）的对比，无法区分性能提升源于模型能力还是数据适配。

| 模型 | Action Gen. (Accuracy) | Action Type (Macro F1) | Click Type (Weighted F1) | Session Outcome (Weighted F1) |
| :--- | :--- | :--- | :--- | :--- |
| GPT-4.1 | 22.06% | 48.78% | 44.47% | 未报告 |

GPT-4.1 在动作生成准确率上达到 22.06%，宏 F1 为 48.78%。这一数值远低于随机猜测的显著性阈值（论文未提供随机基线，但考虑到动作空间大小，22% 的准确率暗示模型仅能捕捉部分高频模式）。点击子类型加权 F1 为 44.47%，表明模型在区分具体点击目标（如 review vs. purchase）上存在较大误差。

消融实验显示，移除 Persona 或 Rationale 均导致性能下降，但具体降幅未在正文主表中详细列出。理由标注稀疏（207/5856），可能导致模型在有理由的步骤上过拟合，而在无理由步骤上依赖上下文猜测。这种稀疏性限制了理由作为监督信号的有效性，模型可能仅在有明确动机提示时表现较好，而在常规浏览中退化为序列预测。

评估边界在于缺乏群体统计效度验证。本文仅评估个体预测，未测试不同 Persona 输出的多样性，无法验证是否存在“角色坍缩”。此外，51 名用户的样本量较小，且集中于 Amazon 平台，跨文化泛化能力未知。代码未公开，仅数据集在 HuggingFace 可用，复现依赖提示模板（附录 I）。

## 关联研究分析

从问题动机看，本文与 HumanLM 均关注个体状态对齐，但 HumanLM 通过强化学习优化潜在心理状态以匹配长期行为，而本文依赖零样本提示与即时理由。差异根源在于任务形态：HumanLM 处理文本响应，可抽象为状态转移；本文处理结构化动作，需精确匹配 DOM 元素。这种差异导致本文无法利用 RL 的梯度优化，只能依赖 LLM 的上下文学习能力，从而限制了性能上限。

从方法设计看，本文与 TWICE 均涉及长期行为，但 TWICE 侧重时间特征与记忆模块，本文侧重即时理由与动作细节。TWICE 解耦内容生成与风格生成，而本文将理由作为输入条件而非生成目标。这种设计选择反映了电商场景的特殊性：用户决策往往由即时动机（如价格、评论）驱动，而非长期风格演变。然而，理由的稀疏性使得这种即时动机捕捉并不稳定，模型在无理由步骤上的表现可能依赖于对 Persona 的过度依赖，而非真正的行为理解。

## 总结

本文核心矛盾在于 LLM 缺乏评估细粒度个体行为准确性的数据基础。切入点在于构建包含即时理由与完整观察的 OPeRA 数据集，通过零样本提示验证 LLM 的个体预测能力。实验证明 GPT-4.1 在动作生成准确率上仅达 22.06%，宏 F1 为 48.78%，揭示了当前 LLM 在个性化行为模拟上的显著局限。边界在于理由标注稀疏、样本量小且缺乏群体统计效度验证。当理由标注密度从 8% 提升至 100% 时，动作预测准确率的提升幅度是否线性，论文未给出回答。
