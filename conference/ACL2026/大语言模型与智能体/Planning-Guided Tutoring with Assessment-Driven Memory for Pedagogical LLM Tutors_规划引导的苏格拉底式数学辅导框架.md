# ACL2026最新论文 ｜Planning-Guided Tutoring with Assessment-Driven Memory for Pedagogical LLM Tutors ｜规划引导的苏格拉底式数学辅导框架

研究机构：北京师范大学

作者：Zechen Li、Qiannan Zhu、Mei Wang 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_1823b1165e0c)

> 现有大语言模型（LLM）导师在长程对话中常因缺乏全局步骤规划而陷入碎片化引导或过早泄露答案，导致教学连贯性断裂。ScaffoldLM 通过引入显式步骤级教学计划与评估驱动的记忆机制，将教学行为锚定在可验证的中间目标上，而非依赖隐式上下文。该框架在 BigMath 数据集上实现了 0.785 的数学辅导准确率，并在多项教学指标上超越通用大模型，但其对解题率与教学质量的平衡仍受限于监督微调（SFT）的静态优化特性。

## 研究背景

当 LLM 试图扮演数学导师时，其自回归生成特性导致它倾向于逐轮响应而非维持长程教学逻辑。这种“即时反应”模式使得模型难以在复杂问题中保持脚手架（Scaffolding）的连贯性，往往在几轮对话后便偏离预设的教学路径，或直接给出最终答案以最大化用户满意度。这一现象被称为“教学幻觉”（Sycophancy），其根源在于基础模型的训练目标偏向信息传递而非认知建构，缺乏对学习者认知状态的显式追踪机制。

传统智能辅导系统（Intelligent Tutoring Systems, ITS）依赖规则引擎和静态知识追踪，虽能确保逻辑严谨，但难以适应自然语言的多样性。随着 GPT-4 等模型的普及，研究重心从“答案提供者”转向“苏格拉底式引导者”，但现有方法仍面临两大瓶颈：一是提示工程（Prompt Engineering）在长程对话中易发生策略漂移，二是监督微调（SFT）缺乏对步骤级进度和认知状态的显式约束。ScaffoldLM 的切入点在于将教学过程形式化为一个受控的决策循环，通过显式计划与动态记忆的协同，解决 LLM 在长程辅导中缺乏结构化规划与认知适应性的问题。

## 核心方法

### 方法参照系

ScaffoldLM 属于苏格拉底式教学对齐中的“规划引导”路线，其核心差异在于将隐式的上下文依赖转化为显式的状态机控制。与依赖强化学习（RL）优化奖励信号或仅靠提示词约束的方法不同，ScaffoldLM 在推理时引入一个包含教学计划、进度向量和对话历史的记忆模块，使每一步生成都基于对学习者当前认知状态的显式评估，而非单纯依赖历史文本的语义连贯性。

### 步骤级教学规划与记忆结构

ScaffoldLM 首先将数学问题 $Q$ 分解为 $N$ 个逻辑步骤，生成包含引导性子问题 $q_t$ 和参考答案 $a_t$ 的教学计划 $P(Q)$。这一设计解决了传统 LLM 逐轮生成导致的“推理碎片化”问题，通过预计算的全局骨架确保教学路径的逻辑完整性。在每一轮交互中，模型维护一个记忆状态 $M_{k-1} = (P(Q), p_{k-1}, H_{k-1})$，其中 $p_{k-1} \in \{0, 1\}^N$ 为进度向量，指示各步骤的完成状态。

$$
M_{k-1} = (P(Q), p_{k-1}, H_{k-1})
$$

该公式定义了导师在 $k$ 轮时的完整上下文，其中 $H_{k-1}$ 存储了包含学习者状态 $s$ 的历史交互序列。通过显式存储进度向量，模型能够精确知道当前处于哪个教学阶段，从而避免在长程对话中重复已解决的步骤或跳过未掌握的环节。

### 评估驱动的四步控制循环

在每一轮交互中，ScaffoldLM 执行一个包含评估（Assess）、行动（Act）、追踪（Track）和记录（Record）的闭环。首先，模型根据学习者响应 $L_k$ 和当前记忆推断其认知状态 $s_k$，然后基于该状态选择相应的脚手架策略生成响应 $T_k$。

$$
s_k = \text{Assess}(L_k, M_{k-1}), \quad T_k = \text{Act}(L_k, s_k, M_{k-1})
$$

这一机制的关键在于“评估”环节：模型不仅生成文本，还显式判断学习者是否掌握了当前步骤的目标 $a_t$。若 $s_k$ 为“正确”或“理解”，则更新进度向量 $p_k[t] \leftarrow 1$ 并进入下一步；若为“错误”或“困惑”，则保持进度不变并提供针对性提示。这种状态驱动的动作选择解决了 RL 方法中奖励信号稀疏且易导致捷径行为的问题，通过确定性的状态转移规则确保教学行为的合规性。

## 实验评估

ScaffoldLM 在 BigMath 数据集上进行评估，对比了通用 LLM（如 GPT-4o, DeepSeek-V3）和专用辅导模型（如 SocraticLM, TutorRL-7B）。实验设置采用 10,000 个训练问题和 300 个保留问题，使用 GPT-4o-mini 作为自动评估器，其与专家教师的一致率为 79.6%。

| 模型 | 答案准确率 | 步骤脚手架 | 主题一致性 | 问题质量 | 指导质量 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| GPT-4o | 0.763 | 0.931 | 0.813 | 0.782 | 0.485 |
| TutorRL-7B | 0.682 | 0.953 | 0.968 | 0.789 | 0.281 |
| SocraticLM | 0.562 | 0.652 | 0.810 | 0.682 | 0.332 |
| ScaffoldLM-7B | 0.785 | 0.988 | 0.999 | 0.830 | 0.525 |

ScaffoldLM-7B 在五项教学指标中均取得最高分，特别是在“指导质量”上显著优于 GPT-4o（0.525 vs 0.485）和 TutorRL-7B（0.525 vs 0.281）。这表明显式规划与状态评估机制在提升教学连贯性方面优于纯 RL 对齐或大参数规模。

| 配置 | 答案准确率 | 步骤脚手架 | 指导质量 |
| :--- | :--- | :--- | :--- |
| ScaffoldLM-7B | 0.785 | 0.988 | 0.525 |
| w/o Plan | 0.753 | 0.965 | 0.468 |
| w/o Assessment | 0.750 | 0.972 | 0.425 |
| w/o Both | 0.723 | 0.925 | 0.392 |

消融实验显示，移除规划组件导致指导质量下降 0.057，移除评估组件导致下降 0.100。评估机制对指导质量的贡献大于规划机制，说明动态认知状态适应比静态步骤结构对教学质量的边际影响更大。然而，移除两者后答案准确率仅下降 0.062，表明该框架在提升教学质量的同时，对基础解题能力的损害较小。

评估协议主要依赖 GPT-4o-mini 的自动评分，虽与专家一致率较高，但缺乏对多轮对话中学习者认知增益的长期追踪。代码已公开，但训练细节（如超参数、GPU 配置）仅在附录中简要提及，复现成本中等。

## 关联研究分析

从方法设计看，ScaffoldLM 与 TutorRL 形成了鲜明对比。TutorRL 通过 RL 优化多目标奖励函数，试图在解题率与教学合规性之间寻找平衡，但其奖励信号稀疏且易导致模型采取“捷径行为”（如直接给出答案以提高解题率）。ScaffoldLM 则采用 SFT 结合显式状态机，通过确定性的状态转移规则抑制答案泄露，牺牲了部分解题灵活性以换取教学过程的严谨性。这种差异源于任务特性的不同：RL 适合优化连续、模糊的目标，而 SFT 结合显式规则更适合约束离散、结构化的教学行为。

从问题动机看，ScaffoldLM 与 UCO 在 BigMath 上的表现存在竞争关系。UCO 侧重通过 RL 优化长程策略，ScaffoldLM 侧重通过规划引导提升教学结构。ScaffoldLM 在 BigMath 上的准确率（0.785）略低于 UCO（0.798），但在教学指标上显著优于通用模型。这一差异暗示，SFT 在长程对话中可能面临策略漂移的风险，而 RL 在优化解题率方面更具优势。ScaffoldLM 的显式记忆机制是否能在更复杂的非数学学科中保持稳定性，论文未给出回答。

## 总结

ScaffoldLM 旨在解决 LLM 导师在长程对话中缺乏显式教学规划与认知状态适应的问题，其核心矛盾在于如何平衡数学解题的严谨性与苏格拉底式引导的灵活性。通过引入步骤级教学计划与评估驱动的记忆机制，ScaffoldLM 将教学行为锚定在可验证的中间目标上，避免了传统 LLM 的碎片化引导。实验表明，该框架在 BigMath 上实现了 0.785 的准确率，并在指导质量上达到 0.525，显著优于 GPT-4o 和 TutorRL-7B。然而，其依赖 SFT 的静态优化特性，可能在长程对话中面临策略漂移，且对非数学学科的泛化能力未经验证。当支持集增大到更复杂的学科领域时，显式规划机制的边际收益是否递减，论文未给出回答。
