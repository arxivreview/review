# ACL2026最新论文 ｜RADO: Reasoning Audit-Driven Optimization for Rigorous Reasoning in High-Stakes Domains ｜推理审计驱动优化

作者：Zhijie Tan、Xu Chu、Guanyu Wang 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_4fe8c0f09467)

> 高风险领域（金融、法律、医疗）的决策不仅要求结果正确，更要求推理过程可审计、无逻辑断裂，而当前主流强化学习范式仅以最终答案正确性为奖励信号，导致模型常“答对但推理错误”。RADO 抓住了“判别局部错误比生成全局正确更廉价”的认知不对称，通过引入具备外部工具调用能力的专用审计模型（Audit Model, AM）来校准奖励模型（Reward Model, RM），进而以优化后的 RM 指导策略模型（Policy Model, PM）进行训练。该框架在 7B 规模下于法律、金融、医疗基准上超越了 20B 级通用模型，但其性能增益中领域数据微调的贡献与审计机制本身的贡献尚未被解耦，且未报告工具调用带来的计算开销。

## 研究背景

高风险领域的 LLM 应用面临一个核心困境：模型可能通过错误的中间推导偶然得到正确答案，这种现象被称为“忠实性差距”（Faithfulness Gap）。在金融或法律场景中，这种“对答案错逻辑”的推导不仅无法通过合规审查，更可能因隐藏的逻辑谬误导致系统性风险。解决此问题的关键在于将监督信号从最终结果前移至推理过程，即构建过程奖励模型（Process Reward Model, PRM），对推理链的每一步进行细粒度评估。

然而，现有 PRM 训练面临数据获取瓶颈：生成一条全局逻辑严谨的长推理链（正样本）极其困难，往往需要数万 token 且依赖专家级知识；而构造一条包含局部逻辑断裂的推理链（负样本）则相对容易。主流的结果奖励强化学习（如 GRPO）仅关注最终状态，无法区分“正确推导”与“错误推导碰巧正确”，导致模型可能学会利用奖励模型的盲点进行“奖励黑客”（Reward Hacking）。RADO 的切入点在于利用生成与判别之间的计算复杂度不对称性，通过一个专门训练来识别局部逻辑错误的审计模型，将易得的负样本转化为高质量的偏好数据，从而在不依赖海量全局正确样本的前提下，实现推理过程的显式监督。

## 核心方法

### 方法参照系

RADO 属于推理增强训练路线，其标准流程为：初始化奖励模型 -> 强化学习优化策略模型。本文的关键差异在于，在奖励模型与策略模型之间插入了一个独立的、具备工具调用能力的审计模型，并将奖励模型的优化从一次性 SFT 转变为“审计-修正”的迭代共进化过程。

### 审计模型与工具增强判别

传统 PRM 仅依赖模型内部参数进行逻辑判断，易受表面特征干扰且缺乏事实依据。RADO 在审计模型中引入外部工具调用（如网络搜索、数值计算），使其在判别推理步骤时能获取接地（grounded）的事实验证。这一设计解决了纯神经 PRM 在高风险领域因缺乏领域事实知识而导致的误判问题。审计模型对策略模型生成的推理链进行逐句审计，输出逻辑正确性分数 $s_{reason}$ 和答案正确性分数 $s_{answer}$，并生成审计理由。其核心判别逻辑可形式化为：

$$
\text{Audit}(x, y) = \mathbb{1}[\text{LocalFlaw}(y) = \emptyset \land \text{FactCheck}(y) = \text{True}]
$$

其中 $\text{LocalFlaw}(y)$ 表示推理链 $y$ 中存在的局部逻辑断裂集合，$\text{FactCheck}(y)$ 表示通过工具验证的事实一致性。该机制将抽象的逻辑判断转化为可验证的事实核查，显著提升了审计信号的可靠性。

### 迭代式奖励模型优化

审计模型的输出被用于构建偏好数据集，以优化奖励模型。RADO 采用直接偏好优化（DPO）进行迭代训练，其目标函数为：

$$
\mathcal{L}_{DPO}(\theta) = -\mathbb{E}_{(x, y_w, y_l)} \left[ \log \sigma \left( \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)} \right) \right]
$$

其中 $y_w$ 和 $y_l$ 分别为审计模型判定为逻辑严谨和不严谨的推理链。通过 $K=2$ 轮迭代，审计模型从累积的负样本中学习更复杂的错误模式，而奖励模型在更严格的审计压力下被迫生成更精准的评分。这种共进化机制解决了单一 SFT 奖励模型在细粒度逻辑判别上的能力上限问题，使奖励信号能够更准确地反映推理过程的真实质量。

## 实验评估

实验在 LegalBench、FinQA、PubMedQA、MMLU 及股票预测数据集上进行，基线涵盖通用 LLM（GPT-OSS-20B, Qwen2.5-7B）和领域 LLM（Lawma, BioMistral）。RADO 基于 Qwen2.5-Instruct-7B 构建，在 LegalBench 平均准确率上达到 81.11%，较 GPT-OSS-20B 的 70.02% 提升 11.09 个百分点；在 FinQA 上达到 81.52%，较 GPT-OSS-20B 的 76.14% 提升 5.38 个百分点。

| 数据集 | RADO (7B) | GPT-OSS-20B | Qwen2.5-7B |
| :--- | :--- | :--- | :--- |
| LegalBench (Avg) | 81.11 | 70.02 | 73.86 |
| FinQA | 81.52 | 76.14 | 66.79 |
| Stock Prediction | 81.52 | 76.14 | 69.32 |
| PubMedQA | 80.39 | 79.80 | 62.40 |

消融实验揭示了审计模型与工具调用的关键作用。移除审计模型后，LegalBench 准确率从 81.11% 降至 77.20%；移除工具调用后，MMLU 准确率从 80.54% 降至 74.81%，表明工具增强是防止奖励黑客、维持逻辑严谨性的核心防御机制。PROOF-Score 评估显示，RADO 在推理完整性、领域安全性和事实准确性三个维度上均取得最高分，且审计模型给出的分数普遍低于通用 LLM 评委，说明其更严格地惩罚了细微的逻辑跳跃。

评估边界方面，论文未报告工具调用带来的额外推理延迟与 Token 消耗，无法量化“审计严谨性”与“计算效率”的权衡。此外，所有实验均依赖 DeepSeek-v3.2 作为教师模型生成初始标签，这一强模型蒸馏过程可能引入了教师模型的偏见，且未提供代码与超参数细节，限制了可复现性。

## 关联研究分析

从问题动机看，RADO 与 Logic-Thinker 均旨在解决 LLM 推理的逻辑严谨性问题，但两者路径截然不同。Logic-Thinker 依赖外部符号求解器（如 SMT）进行形式化验证，其瓶颈在于自动形式化的歧义性，即自然语言到逻辑公式的转换错误会导致后续推理基于错误前提。RADO 则完全在自然语言空间内操作，通过审计模型识别“局部逻辑断裂”而非“形式化错误”，避免了自动形式化的歧义瓶颈。然而，RADO 的审计模型本质上仍是神经模型，其判别能力受限于训练数据中的错误模式覆盖度，对于训练分布外的新型逻辑谬误，其泛化能力可能弱于基于公理系统的符号求解器。

从方法设计看，RADO 与 CGD-PD 均关注推理过程的一致性，但干预层级不同。CGD-PD 在解码阶段通过一致性引导和证明驱动消歧来提升准确率，属于推理时（inference-time）优化；RADO 则在训练阶段通过审计模型校准奖励信号，属于训练时（training-time）优化。CGD-PD 无需额外模型，计算开销较小，但其提升幅度受限于解码策略的搜索空间；RADO 引入了额外的审计模型与迭代训练流程，计算开销显著增加，但通过显式监督推理过程，在高风险领域取得了更大幅度的性能提升。这种差异反映了“推理时计算扩展”与“训练时信号优化”两条路线在效率与效果上的不同取舍。

## 总结

RADO 旨在解决高风险领域中 LLM 推理过程“答对但逻辑错误”的忠实性差距问题。现有结果奖励范式无法区分正确推导与错误推导，而 RADO 利用“判别局部错误比生成全局正确更廉价”的认知不对称，通过工具增强的审计模型迭代优化奖励模型，实现了对推理过程的显式监督。实验表明，该 7B 模型在 LegalBench 上以 81.11% 的准确率超越了 GPT-OSS-20B 的 70.02%，且在 PROOF-Score 评估中展现出更高的逻辑严谨性。然而，论文未解耦领域数据微调与审计机制各自的贡献，也未量化工具调用带来的计算开销。当审计模型面对训练分布外的新型逻辑谬误时，其判别能力是否仍能维持对奖励黑客的有效防御，论文未给出回答。
