# ACL2026最新论文 ｜HeLa-Mem: Hebbian Learning and Associative Memory for LLM Agents ｜基于赫布学习动态图的大语言模型记忆架构

作者：Jinchang Zhu、Jindong Li、Cheng Zhang 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.16839)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_cc2a35444f57)

> 大语言模型智能体在长时程交互中面临固定上下文窗口导致的跨会话状态丢失与认知矛盾，现有方法多将记忆视为静态向量库或固定图谱，忽视了记忆结构随交互动态演化的本质。HeLa-Mem 抓住“记忆关联需随共激活动态重组”这一被忽略的点，借鉴神经科学中的赫布学习机制，将对话历史建模为动态关联图，并通过在线编码、反思性固化与双路径检索实现记忆的持续演化。该架构在 LoCoMo 基准上以显著更少的上下文 Token 实现了优于基线的平均排名，但其绝对性能未超越最新工业级系统，且依赖固定超参数，在复杂长尾场景下的鲁棒性存疑。

## 研究背景

当智能体处理跨越数月的多轮对话时，早期提及的偏好或事实往往因上下文窗口截断而丢失，导致后续响应出现事实矛盾或个性化缺失。这种状态丢失的本质并非存储容量不足，而是缺乏对记忆间潜在关联的动态捕捉。传统检索增强生成（RAG）依赖语义相似度匹配，仅能召回表面相关的文本片段，无法识别那些在叙事弧线上紧密关联但关键词不重合的记忆节点。为突破这一局限，研究者引入了结构化记忆组织，如 A-Mem 的笔记网络或 MemoryBank 的遗忘曲线，试图通过静态拓扑或时间衰减来维持记忆的一致性。

然而，现有结构化方法仍普遍将存储与检索视为独立的静态过程，记忆结构一旦建立便不再随新交互发生根本性重组。这种静态假设导致智能体虽能“记住”孤立事实，却缺乏关系发展的“连续性”，例如无法自动将今日话题与一个月前的相关经历建立深层联系。HeLa-Mem 的切入点在于引入生物记忆中的赫布学习原则，即“共同激活的神经元建立连接”，将记忆管理从静态检索转变为动态关联演化过程，旨在通过共激活模式自动强化潜在关联，从而在长时程交互中维持认知连贯性。

## 核心方法

### 动态关联图参照系

本文方法置于结构化记忆架构范畴，与 A-Mem 的静态笔记网络或 MemoryBank 的向量库+遗忘曲线不同，其核心差异在于记忆边的权重并非固定或仅随时间衰减，而是随检索过程中的共激活频率动态更新。这一设计旨在解决静态图谱无法捕捉叙事演化中潜在关联的问题，使记忆结构能够随交互经验持续重组。

### 在线编码与赫布关联

在记忆写入与更新环节，传统方法通常仅记录文本与嵌入，边权固定或基于时间衰减。HeLa-Mem 引入在线编码与关联机制，将对话轮次编码为情景记忆图节点，并在检索时动态强化共激活记忆间的连接。其核心公式为：

$$ w_{ij}^{(t+1)} = (1 - \lambda) \cdot w_{ij}^{(t)} + \eta \cdot \mathbb{I}(v_i, v_j \in K_t) $$

其中 $\lambda$ 为衰减率，$\eta$ 为学习率，$\mathbb{I}$ 为指示函数，当节点对 $v_i, v_j$ 在当前检索集 $K_t$ 中共激活时取 1。该公式的物理含义是：频繁共同被检索的记忆对会强化其关联权重，而长期未被共同激活的连接则逐渐衰减，从而模拟突触可塑性，捕捉语义相似度之外的潜在上下文关联。

### 反思性固化与双路径检索

动态关联导致图结构随时间膨胀，需防止噪声积累。HeLa-Mem 引入反思性智能体执行赫布蒸馏，识别高关联强度的枢纽节点并转化为语义记忆。枢纽检测公式为：

$$ D(v_i) = \sum_{j \in N(i)} w_{ij} > \delta_{hub} $$

当节点 $v_i$ 的总边权超过阈值 $\delta_{hub}$ 时，触发固化，将相关记忆簇抽象为结构化语义条目。检索阶段采用双路径策略，基础激活得分结合嵌入相似度、时间衰减与关键词匹配：

$$ S_{base}(v_i) = (\text{sim}(q, e_i) + \alpha \cdot \text{keyword\_match}) \cdot \gamma(v_i) $$

随后通过赫布边进行扩散激活，最终检索集由基础路径与翻转路径（高扩散得分但未入选基础路径的节点）合并而成。这一设计解决了单一相似度检索在多跳推理中遗漏强关联但语义疏远记忆的问题，实现了细节与模式的统一召回。

## 实验评估

实验在 LoCoMo 基准上进行，对比 ReadAgent、MemoryBank、MemGPT、A-Mem 及 MemoryOS 等基线。基线覆盖了知识组织、检索机制与架构驱动三类主流路线，但缺失 Mem0、Mandol 等 2025-2026 年最新工业级系统，导致绝对性能对比缺乏最新参照系。论文未提供具体 F1 绝对值表格，仅通过 Figure 1 展示性能与 Token 效率的权衡，表明 HeLa-Mem 在低 Token 消耗下性能优于基线，平均排名达 1.25。

该论文实验数据不可得，未提供实验表格。设计决策验证方面，赫布蒸馏机制通过阈值 $\delta_{hub}$ 控制图规模，但论文未报告不同阈值对性能的影响，无法评估固化策略的敏感性。双路径检索中翻转路径的引入旨在提升多跳推理能力，但未单独消融该路径的贡献，难以区分性能提升源于动态关联还是检索策略本身。

评估边界方面，论文仅使用 LoCoMo 单一基准，未覆盖 LongMemEval 等超百万 Token 场景或 SWE-Bench 等任务导向基准，限制了结论的泛化性。代码已开源，但赫布学习参数 $\lambda, \eta$ 为固定超参数，未报告自适应调节机制，在长尾场景下的鲁棒性未经验证。

## 关联研究分析

从方法设计看，HeLa-Mem 与 A-Mem 同属结构化笔记网络，但 A-Mem 的链接基于静态语义关联，而 HeLa-Mem 的边权随共激活动态演化。这一差异源于对记忆本质的不同假设：A-Mem 假设关联结构在写入时即可确定，HeLa-Mem 则认为关联需通过交互经验逐步强化。然而，动态更新可能引入早期噪声被错误强化的风险，论文未讨论如何抑制这种噪声累积，仅依赖衰减率 $\lambda$ 进行被动遗忘。

从问题动机看，HeLa-Mem 与 MemoryBank 均关注记忆遗忘，但 MemoryBank 基于艾宾浩斯遗忘曲线的时间衰减，HeLa-Mem 基于共激活频率与结构孤立度的复合阈值。MemoryBank 的遗忘是时间驱动的，HeLa-Mem 的遗忘是结构驱动的。这种差异导致 HeLa-Mem 能保留长期未访问但强关联的记忆，而 MemoryBank 可能因时间过长而遗忘重要事实。但 HeLa-Mem 的复合阈值（权重、时长、访问）在长尾场景下的鲁棒性如何，论文未给出回答。

## 总结

HeLa-Mem 旨在解决 LLM 智能体长时程交互中记忆结构静态化导致的认知连贯性缺失，通过引入赫布学习机制实现记忆关联的动态演化。其核心创新在于将对话历史建模为动态关联图，并通过反思性固化与双路径检索平衡细节与模式。实验在 LoCoMo 上验证了其 Token 效率优势，平均排名 1.25，但绝对性能未超越 Mandol 等最新系统。论文边界在于依赖固定超参数且仅评估单一基准，动态关联在复杂长尾场景下的鲁棒性未经验证。当交互序列中出现大量噪声或矛盾信息时，赫布关联是否会被错误强化并导致记忆污染，论文未给出回答。
