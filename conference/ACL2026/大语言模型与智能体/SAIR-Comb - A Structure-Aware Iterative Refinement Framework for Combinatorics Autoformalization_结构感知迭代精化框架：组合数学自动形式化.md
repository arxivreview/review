# ACL2026最新论文 ｜SAIR-Comb : A Structure-Aware Iterative Refinement Framework for Combinatorics Autoformalization ｜结构感知迭代精化框架：组合数学自动形式化

研究机构：华东师范大学

作者：Weijie Jiang、Gaolei He、Beibei Xiong 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_600651dc1b70)

> 自动形式化旨在将自然语言数学陈述转换为 Lean 4 等证明助手可验证的代码，其核心瓶颈在于模型常生成语法合法但结构坍缩的代码。现有方法多聚焦代数与数论，忽视了组合数学中离散对象与递归构造的精细结构对齐，导致语义正确但结构错误的输出难以被传统指标捕获。本文提出 SAIR-Comb，通过构建人工标注的组合数据集驱动迭代精化，并采用专家迭代与强化学习两阶段训练，引入“结构一致性”新指标以暴露深层结构偏差。该框架在组合基准上显著提升了结构保真度，但其对通用基准的泛化能力仍受限于小模型骨干与特定数据分布。

## 研究背景

当 LLM 处理组合数学问题时，自然语言中的“无连续整数子集”等约束需映射为 Lean 4 中嵌套的 `Finset` 过滤与量化逻辑。若模型将复杂的集合运算简化为单纯的算术表达式（如 $5^3$），虽可能通过编译甚至语义检查，却丢失了原命题的结构信息，这种现象称为结构不一致。结构不一致是组合形式化的特有失效模式，源于离散数学对象间复杂的依赖关系，传统基于双向等价（Bidirectional Equivalence, BEq）的评估因战术集受限，难以检测此类深层结构偏差。

自动形式化领域的主流路线通过检索增强生成（Retrieval-Augmented Generation, RAG）与编译器反馈提升准确率，但现有工作多针对代数与数论，缺乏对组合结构保真的专门处理。Herald 等方法依赖 Mathlib 检索，但通用库难以覆盖组合问题的特定结构模式；ATF 等引入工具反馈，却未区分语义正确与结构对齐。SAIR-Comb 的切入点在于识别组合数学的结构密度特性，通过领域专用数据与结构一致性指标，填补了从“语义正确”到“结构忠实”的评估与训练空白。

## 核心方法

### 方法参照系

组合自动形式化可视为陈述自动形式化的特例，标准流程为“分解-检索-生成-验证”。本文的关键差异在于将“结构对齐”作为独立于语义的正确性维度，并引入领域专用数据增强与两阶段训练，替代通用的 Mathlib 检索与单次生成范式。

### 结构一致性指标与数据精化

传统评估仅检查语义等价，无法捕获结构坍缩。SAIR-Comb 定义结构一致性（Structural Consistency, SC）指标，要求形式化输出在对象建模、定义完整性与复杂度保留三个维度上与原文对齐。该指标通过多模型投票的 LLM-as-Judge 机制实现，使用 DeepSeek-V3.2 与 Qwen3-Max 并行评估，仅当两者一致时判定通过。数据精化阶段从 NuminaMath-1.5 提取组合问题，经人工标注 363 个高质量样本作为模板，再通过迭代修复流程校正语法、语义与结构错误。修复过程记录历史错误以避免重复，直至无问题或超过最大迭代次数。

$$
R_{\text{reason}} = \alpha \cdot \text{sim}(\text{femb}(S_i), \text{femb}(\hat{S}_i)) + (1 - \alpha) \cdot \text{sim}(\text{femb}(F_i), \text{femb}(\hat{F}_i))
$$

其中 $\text{sim}$ 为余弦相似度，$\text{femb}$ 为 all-MiniLM-L6-v2 嵌入操作，$\alpha$ 为超参数。该公式量化了生成推理轨迹与真实轨迹的语义对齐程度，作为强化学习的奖励信号。

### 两阶段推理对齐训练

数据精化后，模型需学习结构保真的生成策略。SAIR-Comb 采用两阶段训练：第一阶段专家迭代（Expert Iteration）结合语法检查，从 3k 组合样本与 25.6k 通用样本中冷启动，迭代生成约 100k 训练数据；第二阶段强化学习（Reinforcement Learning, RL）使用 CISPO 算法对齐推理轨迹。奖励函数取格式奖励、语法奖励与推理对齐奖励的最小值，确保输出同时满足格式、语法与结构要求。

$$
R_{\text{total}} = \min(R_{\text{format}}, R_{\text{syntactic}}, R_{\text{reason}})
$$

该最小值机制强制模型在任一维度失效时获得低奖励，避免“语法正确但结构错误”的投机行为。CISPO 算法在长文本思维链任务中表现优异，适合组合问题的多步推理对齐。

## 实验评估

实验在 CombiBench、ProverBench 与 PutnamBench 上进行，基线包括 Kimina-Autoformalizer-7B、Goedel-Formalizer-8B、StepFun-Formalizer-7B 与 ATF-8B。SAIR-Comb-8B 在 CombiBench Pass@16 上语义一致性达 49.00%，结构一致性达 42.00%，分别超过最佳基线 Goedel 8.00% 与 10.00%。在通用基准上，SAIR-Comb 表现中等，PutnamBench Pass@16 语义 53.79%、结构 46.82%，略低于 Goedel 但优于其他基线。

| 模型 | CombiBench Pass@16 (语义/结构) | ProverBench Pass@16 (语义/结构) | PutnamBench Pass@16 (语义/结构) |
| :--- | :--- | :--- | :--- |
| Goedel-Formalizer-8B | 41.00% / 32.00% | 89.66% / 82.76% | 62.73% / 51.52% |
| ATF-8B | 39.00% / 28.00% | 82.18% / 68.39% | 51.36% / 42.58% |
| SAIR-Comb-8B | 49.00% / 42.00% | 86.21% / 79.89% | 53.79% / 46.82% |

消融实验显示，专家迭代在 CombiBench 上提升语义 8.00%、结构 7.00%，CISPO 进一步提升 2.00% 与 3.00%。ProverBench 上 CISPO 语义微降 0.57%、结构升 0.58%，表明低结构需求基准中 RL 收益有限。结构一致性检查导致所有模型性能下降，SAIR-Comb 降幅最小（CombiBench 7.00%），验证了其结构鲁棒性。

评估边界受限于 LLM-as-Judge 的潜在偏差与 8B 小模型骨干。代码未公开，超参数细节见附录，但缺乏 GPU 配置与训练时长报告，可复现性受限。

## 关联研究分析

从问题动机看，SAIR-Comb 与 MathForm 同属组合形式化，但 MathForm 依赖通用数据合成与 8B 模型，在 CombiBench 上语义 88.06%、结构 72.37%（据领域综述），远高于 SAIR-Comb。差异根源在于 MathForm 未引入结构一致性指标，其高分可能源于更宽松的语义评估或更大的数据规模，而非真正的结构保真。SAIR-Comb 的结构指标揭示了 MathForm 可能存在的结构坍缩盲区，但两者骨干与数据协议不同，绝对性能不可直接比较。

从方法设计看，SAIR-Comb 与 ATF 均使用工具反馈，但 ATF 依赖通用 Mathlib 检索，而 SAIR-Comb 使用人工组合数据集。ATF 在 CombiBench Pass@16 结构一致性仅 28.00%，远低于 SAIR-Comb 的 42.00%，表明通用检索难以覆盖组合结构模式。SAIR-Comb 的领域专用数据是性能优势的关键，但这也限制了其泛化能力——当组合问题超出 363 个标注样本的分布时，模型性能可能急剧下降。

## 总结

SAIR-Comb 针对组合数学形式化中结构坍缩的失效模式，通过引入结构一致性指标与领域专用数据精化，解决了现有方法“语义正确但结构错误”的盲区。其两阶段训练策略在 CombiBench 上实现结构一致性 42.00%，超过最佳基线 10.00%，验证了结构对齐的有效性。然而，模型在通用基准上仍落后于 Goedel，且 8B 骨干与人工数据规模限制了泛化能力。当组合问题复杂度超出标注样本分布时，结构一致性指标能否有效引导模型泛化，论文未给出回答。
