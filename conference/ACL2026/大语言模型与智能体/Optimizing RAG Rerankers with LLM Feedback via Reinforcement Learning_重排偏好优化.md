# ACL2026最新论文 ｜Optimizing RAG Rerankers with LLM Feedback via Reinforcement Learning ｜重排偏好优化

研究机构：南京大学

作者：Yuhang Wu、Xiangqing Shen、Fanfan Wang 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.02091)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.02091)

> 检索增强生成（RAG）中的重排器长期面临“相关性”与“有用性”的错位：传统重排模型基于静态人工标注的相关性标签（如 nDCG）进行监督学习，其优化目标与下游大语言模型（LLM）生成答案的实际效用脱节，导致高相关文档未必能支撑精准回答。现有方案要么依赖昂贵的离线标注，要么采用直接偏好优化（DPO）等静态对齐方法，难以捕捉文档组合对生成质量的动态贡献。本文提出重排偏好优化（ReRanking Preference Optimization, RRPO），将重排重构为马尔可夫决策过程（MDP），利用冻结的 LLM Reader 生成质量作为强化学习（RL）奖励信号，并引入参考锚定确定性基线以稳定训练。该方法在 HotpotQA 和 AmbigNQ 上显著优于监督基线及 Listwise 重排器 RankZephyr，但其效用定义局限于问答任务，且未显式处理位置偏差，其泛化边界尚待检验。

## 研究背景

在 RAG 系统中，重排器负责从候选文档中筛选出对 LLM 生成最有价值的上下文。然而，传统重排器（如 Cross-Encoder）通常独立于生成模块进行优化，其训练目标是基于人工标注的相关性分数，而非 LLM 的实际生成效果。这种解耦导致重排器可能优先选择主题相关但信息密度低或逻辑冗余的文档，而 LLM 更需要的可能是简洁、直接支持答案生成的片段。例如，对于“谁发现了青霉素”的查询，重排器可能偏好长篇历史文章，而 LLM 更受益于简洁的时间线条目。

这一错位在推理密集型任务中尤为突出。随着 RAG 系统向多跳问答等复杂场景扩展，文档间的组合效用（即多文档协同支持推理链的能力）成为关键，而静态相关性指标无法建模这种动态依赖。现有 RL 方法多用于查询重写或检索策略优化，直接针对重排器进行端到端效用对齐的工作较少。本文切入点在于将重排视为序列决策问题，利用 LLM 反馈作为即时奖励，实现重排器与生成器的端到端对齐，从而在无需额外人工标注的情况下优化上下文效用。

## 核心方法

### 方法参照系

标准 RAG 重排流程采用监督学习范式，重排器 $f_\theta$ 基于静态相关性标签 $y_i$ 优化交叉熵损失，其目标函数为 $\mathcal{L}_{sup} = -\sum_i y_i \log p(d_i|q)$。本文的关键差异在于将优化目标从静态相关性 $y_i$ 替换为动态生成质量反馈，并将单步评分重构为序列决策过程。

### 序列决策建模与策略网络

传统重排器独立评分每个文档，忽略文档间的组合效应。RRPO 将重排建模为有限时域 MDP，状态 $s_t$ 为未选文档集合，动作 $a_t$ 为选择文档 $d_{c_t}$。策略网络 $\pi_\theta(a_t|s_t)$ 基于 Pointwise 重排器 $f_\theta$ 计算文档得分 $s_i = f_\theta(q, d_i)$，并通过 SoftMax 归一化得到初始概率 $p_i$。在状态 $s_t$ 下，选择文档 $d_{c_t}$ 的概率定义为该文档初始概率占剩余文档初始概率总和的比例：

$$
\pi_\theta(a_t|s_t) = \frac{p_{c_t}}{\sum_{d_j \in s_t} p_j}
$$

此设计将全局排序分解为逐步选择，使策略能够隐式捕捉文档组合对生成质量的贡献，克服了监督学习中文档独立评分的局限。

### 参考锚定确定性基线

LLM 生成的奖励信号（如 EM/F1）离散且高方差，传统 PPO 中训练独立 Critic 网络估计价值函数 $V(s_t)$ 效果不佳。RRPO 引入参考锚定确定性基线，利用固定参考策略 $\pi_{ref}$ 的贪心执行结果作为 $V(s_t)$ 的估计。具体地，$V(s_t)$ 定义为参考策略从初始状态 $s_1$ 开始，贪心选择 $t$ 个文档后，LLM Reader 生成响应的奖励值：

$$
V(s_t) = R_{lm}(\text{response}_{ref}(q, \{d'_{c_1}, ..., d'_{c_t}\}), \text{ans})
$$

其中 $d'_{c_j}$ 为参考策略在第 $j$ 步选择的文档。该基线避免了 Critic 网络的训练不稳定性，通过锚定强参考重排器的性能，确保策略更新方向明确指向超越参考策略的效用提升，同时通过 PPO-clip 和 KL 散度惩罚约束更新幅度，防止策略崩溃。

## 实验评估

实验在 HotpotQA（多跳问答）和 AmbigNQ（歧义消除问答）上进行，使用 DPR 语料库，BM25 检索 100 篇候选文档，重排后选取 Top-3（HotpotQA）或 Top-5（AmbigNQ）输入 Qwen2.5-7B 作为 LLM Reader。基线包括监督重排器（gte, jina, bge, qwen3）及先进 RAG 方法（FLARE, DRAGIN）。主结果显示，RRPO 优化后的 gte 重排器在 HotpotQA 上 F1 提升 1.99 点（41.23 至 43.22），在 AmbigNQ 上提升 1.12 点（48.55 至 49.67），且优于 Listwise 重排器 RankZephyr（HotpotQA F1 44.49 vs 46.38）。

| 方法 | HotpotQA EM | HotpotQA F1 | AmbigNQ EM | AmbigNQ F1 |
| :--- | :--- | :--- | :--- | :--- |
| Naive RAG (BM25) | 24.23 | 35.42 | 20.33 | 32.18 |
| + gte reranker | 28.24 | 41.23 | 35.51 | 48.55 |
| + gte reranker (RRPO) | **30.03** | **43.22** | **36.56** | **49.67** |
| + RankZephyr | 32.40 | 44.49 | 40.06 | 51.58 |

消融实验表明，训练交互深度 $k_{train}=3$ 时性能最优，$k_{train}=5$ 因噪声和注意力扩散导致性能下降，$k_{train}=1$ 则因上下文不足而受限。此外，RRPO 在 2WikiMultiHopQA 和 MusiQue 上均优于基线，验证了其在复杂多跳推理中的泛化能力。与 Query2Doc 结合时，RRPO 提供正交增益，表明其优化的是精度而非召回。

评估边界方面，实验仅覆盖问答任务，未测试开放域生成或摘要任务，效用定义局限于 EM/F1 指标。代码未公开，超参数（如 $\lambda$ 值）在附录中提供，但 GPU 配置未详述，可复现性受限。

## 关联研究分析

从问题动机看，RRPO 与 InfoGain-RAG 同属效用导向路线，但 InfoGain-RAG 基于信息增益启发式选择文档，而 RRPO 通过 RL 直接优化生成质量。InfoGain-RAG 假设信息增益可独立计算，而 RRPO 捕捉文档组合的动态效用，这在多跳推理中更为关键。然而，RRPO 的效用定义依赖于 LLM Reader 的即时反馈，若 Reader 本身存在幻觉或偏差，奖励信号可能误导重排策略，这一风险在 InfoGain-RAG 中因基于静态信息量而较低。

从方法设计看，RRPO 采用 PPO 框架，而近期工作如 KnowPO 和 DPARAG 使用 DPO 进行偏好优化。DPO 基于静态偏好对，无法建模序列决策中的状态依赖，而 RRPO 的 MDP 框架允许策略根据已选文档动态调整后续选择。但 RRPO 的 Pointwise 策略网络牺牲了 Listwise 重排器（如 RankZephyr）的全局文档交互能力，尽管实验显示其性能更优，但这可能源于效用对齐的优势而非架构本身的优越性。若骨干模型容量不足，Pointwise 策略是否仍能捕捉复杂组合效用，论文未给出回答。

## 总结

RRPO 旨在解决 RAG 中重排器优化目标与下游生成效用错位的核心矛盾。现有监督方法依赖静态标签，DPO 方法缺乏序列动态性，而 RRPO 通过 MDP 建模和 LLM 反馈奖励，实现了端到端效用对齐。实验证明其在 HotpotQA 上 F1 提升 1.99 点，优于 RankZephyr。然而，其效用定义局限于问答任务，且 Pointwise 策略网络可能限制复杂组合效用的捕捉。当骨干模型规模扩大或任务类型转向开放域生成时，参考锚定基线的稳定性是否仍能维持，论文未给出回答。
