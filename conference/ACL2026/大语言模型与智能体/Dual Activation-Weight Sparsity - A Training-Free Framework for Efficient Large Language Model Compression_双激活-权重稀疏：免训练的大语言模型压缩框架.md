# ACL2026最新论文 ｜Dual Activation-Weight Sparsity: A Training-Free Framework for Efficient Large Language Model Compression ｜双激活-权重稀疏：免训练的大语言模型压缩框架

研究机构：中国科学院、中国科学院大学

作者：Luoyang Sun、Guangyan Li、Cheng Deng 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_6c53f41dff5a)

> 大语言模型部署面临计算瓶颈，传统权重剪枝产生静态掩码无法适应输入依赖的计算模式，而纯激活稀疏方法忽略参数重要性差异。DAWS 通过幅值路由联合利用激活异质性与权重重要性，无需重训练或矩阵分解即可实现高效压缩。该方法在 50% 稀疏率下保留超过 98% 的稠密模型性能，但其固定权重掩码在分布偏移场景下的适应性仍存疑。

## 研究背景

Transformer 推理中，激活值分布呈现重尾特征，少数高幅值神经元主导输出信号能量。这一特性使得基于幅值的激活路由成为可能，但仅依赖激活稀疏会忽略不同权重矩阵对输出贡献的差异。权重剪枝虽能移除冗余参数，但传统方法生成的静态掩码无法随输入动态调整，导致运行时效率受限。

现有压缩路线存在明显割裂：权重剪枝方法如 SparseGPT 和 Wanda 通过离线计算生成固定掩码，虽压缩率高但无法捕捉输入依赖的计算模式；激活稀疏方法如 TEAL 和 PowerInfer 动态零化小激活值，但对所有参数应用统一计算策略，未考虑权重重要性。R-Sparse 尝试结合两者，但引入 SVD 分解开销和额外学习组件，限制了实用性。DAWS 的切入点在于发现激活与权重稀疏模式的互补性：权重重要性是输入不变的，可预计算；激活重要性是输入依赖的，需动态计算。这种分工避免了动态权重选择的不稳定性，同时保留了输入自适应的效率。

## 核心方法

### 双路径路由架构

对于线性层 $y = Wx$，DAWS 使用两个阈值 $\tau_h > \tau_l$ 将激活分为高、中、低三层：

$$
x_h = x \odot \mathbb{1}{|x_i| \geq \tau_h}, \quad x_m = x \odot \mathbb{1}{\tau_l \leq |x_i| < \tau_h}, \quad x_l = x \odot \mathbb{1}{|x_i| < \tau_l}
$$

输出计算为 $y = Wx_h + W_p x_m$，其中 $x_l$ 直接丢弃，$W_p$ 是通过幅值剪枝得到的稀疏权重矩阵。设计动机在于解决纯激活稀疏方法忽略参数重要性的问题：高幅值激活通过全精度权重保留关键路径，中幅值激活使用稀疏权重提高效率，低幅值激活完全消除，平衡精度与效率。

### 层级配置搜索

DAWS 采用两阶段搜索确定最优稀疏分配。第一阶段跨模块分配稀疏预算，对每个模块 $m$ 试探性增加稀疏度 $\Delta s_m$，测量损失变化 $\Delta L_m$，永久应用稀疏度增加至最不敏感模块 $m^* = \arg\min_m \Delta L_m$，直至达到目标总稀疏度。第二阶段模块内搜索，对每个模块在候选权重稀疏度 $s_w$ 集合中搜索，激活稀疏度 $s_a$ 由全局计算预算约束唯一确定：

$$
s_a = \frac{s_m - s_{tail}}{s_w} + s_{tail}
$$

其中 $s_m$ 为目标稀疏度，$s_{tail}$ 为丢弃低激活的比例。设计动机在于解决统一稀疏策略无法适应模块间异质性的问题：不同投影类型（q_proj, k_proj, v_proj, o_proj, up_proj, gate_proj, down_proj）的激活-权重贡献模式差异显著，需模块特定的预算分配。

## 实验评估

实验在 Llama-3-8B、Llama-2-7B 和 Mistral-7B 上进行，评估 WikiText-2 困惑度和八个下游任务（Winogrande, PIQA, ScienceQA, OpenBookQA, HellaSwag, BoolQ, Arc-E, Arc-C）。基线覆盖激活稀疏（TEAL, Relufication, CATS, GRIFFIN）和混合稀疏（R-Sparse），但缺乏结构化剪枝（如 LLM-Pruner）和低秩分解（如 SVD-LLM）的对比。

| 模型 | 方法 | PPL | Avg Acc |
|---|---|---|---|
| Llama-3-8B | DAWS 50% | 6.55 | 68.15 |
| Llama-3-8B | TEAL 50% | 6.80 | 66.44 |
| Llama-3-8B | R-Sparse 50% | 6.82 | 66.27 |
| Llama-2-7B | DAWS 50% | 5.65 | 64.90 |
| Mistral-7B | DAWS 50% | 5.47 | 68.16 |

在 50% 稀疏率下，DAWS 在三个模型上均保持超过 98% 的稠密模型性能，平均准确率较最强基线 TEAL 高 1.71 点。消融实验显示，跨模块分配（S1）贡献 +1.79% 准确率，模块内搜索（S2）贡献 +2.60%，两者协同效应达 +2.98%。

| 配置 | PPL | Avg Acc |
|---|---|---|
| 基线（纯激活） | 8.53 | 64.85 |
| + S1 | 7.64 | 66.64 |
| + S2 | 7.37 | 67.45 |
| + S1 + S2 | 7.17 | 67.83 |

稳定性分析表明，权重掩码跨样本 IoU 为 0.80-0.90，支持离线预计算；激活掩码 IoU 为 0.20-0.35，需动态计算。幅值剪枝优于 Wanda 风格剪枝（PPL 7.17 vs 7.30），因后者引入样本级方差。评估局限包括：未报告置信区间，缺乏与结构化剪枝的横向对比，且未评估长文本推理链的影响。

## 关联研究分析

从方法设计看，DAWS 与 R-Sparse 的关键差异在于处理中幅值激活的方式：R-Sparse 使用 SVD 分解近似稠密计算，引入分解开销和学习组件；DAWS 使用幅值剪枝的稀疏权重，避免矩阵分解。这一选择源于对稳定性的考量：SVD 分解依赖校准数据，而幅值剪枝产生输入不变的掩码，更适合动态路由框架。然而，幅值剪枝忽略激活分布信息，在复杂推理任务上是否因缺乏激活感知而失效，论文未给出回答。

从问题动机看，DAWS 与 TEAL 的差异在于是否考虑权重重要性：TEAL 对所有参数应用统一激活阈值，DAWS 通过层级搜索分配模块特定稀疏预算。这一改进源于模块间异质性的发现，但固定权重掩码可能限制其在分布偏移场景下的适应性。当输入分布显著偏离校准数据时，预计算的权重掩码是否仍能保持最优性，论文未进行系统评估。

## 总结

DAWS 解决的核心矛盾是静态权重剪枝无法适应输入依赖计算模式，而纯激活稀疏忽略参数重要性。其切入点在于发现权重重要性的输入不变性与激活重要性的输入依赖性之间的互补性，通过幅值路由和层级搜索实现免训练压缩。实验证明在 50% 稀疏率下保留超过 98% 性能，较 TEAL 高 1.71 点准确率。边界在于固定权重掩码在分布偏移下的适应性未验证，且缺乏与结构化剪枝的对比。当输入分布发生显著偏移时，预计算的权重掩码是否仍能维持性能优势，论文未给出回答。
