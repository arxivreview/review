# ACL2026最新论文 ｜Evolving Beyond Snapshots: Harmonizing Structure and Sequence via Entity State Tuning for Temporal Knowledge Graph Forecasting ｜实体状态调谐

研究机构：大连理工大学、深圳大学

作者：Siyuan Li、Yunjia Wu、Yiyong Xiao 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.12389)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.12389)

> 时序知识图谱（TKG）外推推理旨在预测未来事实，但现有方法多采用无状态范式，在每个时间戳独立重建实体表示，导致长程依赖随推理进程逐渐衰减，即“情景遗忘”。本文指出，性能瓶颈并非骨干网络的选择，而是结构流与序列流缺乏持久化载体进行闭环融合。EST通过引入全局实体状态缓冲器，将实体建模为持续演化的动态容器，实现结构证据与时间动态的语义桥接。该框架在ICEWS14等基准上刷新了SOTA，但其对高噪声数据（如GDELT）的鲁棒性仍受限于纯图结构建模，未引入外部语义先验。

## 研究背景

TKG外推推理的核心困境在于，实体在时间轴上的表示若缺乏持久性，历史交互证据无法跨快照累积。当模型仅依赖当前查询窗口内的离散事件时，长程时间依赖被截断，导致预测能力随时间跨度增加而急剧下降。这一失效机制被称为“情景遗忘”，它揭示了无状态范式在动态开放环境下的根本局限：实体表示被反复重置，无法形成演化惯性。

主流TKG预测方法遵循“分而治之”范式，要么侧重结构依赖建模（如RE-GCN），要么侧重序列线性化（如TiSASRec）。尽管架构各异，这些方法均将实体视为“白板”，依赖有界检索而非状态累积。这种设计导致结构流与序列流割裂，无法在长程推理中保持语义一致性。本文的切入点在于，将实体重新定义为“动态状态容器”，通过持久化状态缓冲器统一结构与时序动态，从而克服情景遗忘。

## 核心方法

### 方法参照系

EST属于结构-序列协同建模路线，但其关键差异在于引入“状态优先”范式。传统方法独立计算快照表示，而EST将全局状态先验注入结构编码，形成闭环更新机制，确保实体表示随时间持续演化而非重置。

### 状态感知结构编码

传统GNN在结构编码时忽略实体历史状态，导致局部拓扑依赖与全局演化脱节。EST通过状态增强实体表示解决此问题：将静态嵌入 $\mathbf{E}_{o_k}$ 与全局状态 $\mathbf{S}_{o_k}$ 通过自适应门控融合，公式为 $\tilde{\mathbf{E}}_{o_k} = \sigma(\mathbf{W}_g [\mathbf{E}_{o_k}; \mathbf{S}_{o_k}]) \odot \mathbf{S}_{o_k} + (1 - \sigma(\mathbf{W}_g [\mathbf{E}_{o_k}; \mathbf{S}_{o_k}])) \odot \mathbf{E}_{o_k}$。该门控机制动态平衡固有身份与演化上下文，抑制语义漂移，使结构编码显式依赖实体当前状态。

### 双轨状态演化与反事实约束

状态更新需平衡可塑性（快速适应新证据）与稳定性（保留长期知识）。EST采用双轨记忆：快速系统通过指数移动平均 $\mathbf{S}^{fast}_t = \lambda \mathbf{S}^{fast}_{t-1} + (1-\lambda) \mathbf{c}_s$ 捕捉瞬时扰动；慢速系统仅在信息惊奇度 $\delta_s = \|\mathbf{S}^{fast}_t - \mathbf{S}^{slow}_{t-1}\|_2$ 超过能量屏障 $\gamma$ 时更新，公式为 $\mathbf{S}^{slow}_t = \mathbf{S}^{slow}_{t-1} + g_s (\mathbf{S}^{fast}_t - \mathbf{S}^{slow}_{t-1})$，其中 $g_s = \mathbb{I}(\delta_s > \gamma)$。此设计过滤噪声，仅将显著结构变化固化为长期记忆。同时，反事实一致性学习（CCL）通过采样历史合理但当前错误负例，隔离观测偏差，确保状态演化基于内在时间依赖而非高频共现。

## 实验评估

实验在ICEWS14、ICEWS18、ICEWS05-15和GDELT四个基准上进行，对比RE-GCN、TiRGN、DiffuTKG等15种基线。EST-Transformer在ICEWS14外推任务中取得0.513 MRR，超越TiRGN（0.400）和DiffuTKG（0.450）；在GDELT上取得0.412 MRR，低于领域综述中报告的CID-TKG/LLM-DA的0.521 MRR。

| 模型 | ICEWS14 MRR | ICEWS18 MRR | ICEWS05-15 MRR | GDELT MRR |
| :--- | :--- | :--- | :--- | :--- |
| EST-Transformer | 0.513 | 0.466 | 0.621 | 0.412 |
| EST-Mamba | 0.511 | 0.449 | 0.599 | 0.390 |
| TiRGN | 0.400 | 0.283 | 0.416 | 0.368 |
| DiffuTKG | 0.450 | 0.335 | 0.529 | 0.473 |

消融实验显示，移除状态持久化（w/o State）导致ICEWS14 MRR从0.511降至0.452（ΔMRR≈-0.06），移除上下文（w/o Context）导致MRR降至0.360，证实状态机制是性能提升的核心。移除CCL导致MRR下降0.022，表明反事实约束对过滤虚假相关有效。

评估边界方面，论文未报告置信区间，且GDELT上性能落后于LLM-based方法，暗示纯图结构在高噪声场景下缺乏语义鲁棒性。代码未公开，超参数（如能量屏障γ）未提供自适应调整策略，可复现性受限。

## 关联研究分析

从问题动机看，EST与JODIE/TGN同属有状态动态图学习，但JODIE/TGN的记忆模块被动存储原始事件，而EST将状态先验前置注入结构编码，形成主动闭环。这一差异源于TKG外推对长程依赖的更高要求：被动存储无法在结构聚合阶段利用历史惯性，导致局部拓扑与全局演化脱节。EST的“状态优先”设计直接回应了知识库中“结构流与序列流割裂”的核心痛点。

从方法设计看，EST与DiffuTKG代表不同技术路线：DiffuTKG通过扩散过程建模未来随机性，EST通过状态持久化捕捉演化惯性。在GDELT高噪声场景下，DiffuTKG（0.473 MRR）优于EST（0.412 MRR），表明生成式正则化在噪声抑制上更具优势。EST在ICEWS系列上的领先（0.513 vs 0.450）则验证了状态机制在低噪声、强结构依赖场景下的有效性。这一性能倒挂提示，状态持久化与不确定性量化并非互斥，而是互补。

## 总结

EST针对TKG外推中无状态范式导致的情景遗忘问题，通过全局状态缓冲器实现结构-序列闭环融合。该框架在ICEWS14上取得0.513 MRR，超越TiRGN 11.3个百分点，验证了状态持久化对长程依赖建模的关键作用。然而，EST在GDELT上的性能（0.412 MRR）低于DiffuTKG（0.473 MRR）和LLM-based方法，暴露了纯图结构在高噪声环境下的语义鲁棒性局限。当数据噪声水平超过结构信号强度时，状态演化机制是否会被虚假相关主导，论文未给出回答。
