# ACL2026最新论文 ｜RIMRULE: Improving Tool-Using Language Agents via MDL-Guided Rule Learning ｜基于最小描述长度引导的规则学习：LLM工具调用的非参数化适配

作者：Xiang Gao、Yuguang Yao、Qi Zhang 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_98f32bd0869e)

> 工具增强大语言模型在部署于私有或文档不全的API环境时，常因系统性推理错误导致任务失败，而传统的微调或提示优化难以在不更新权重的前提下实现跨模型的知识共享。现有方案要么依赖高成本的监督微调，要么受限于静态提示的泛化瓶颈，无法有效压缩失败经验为可复用的抽象知识。本文提出RIMRULE，通过从失败轨迹中蒸馏符号化规则并利用最小描述长度原则进行整合，实现推理时的动态规则注入。该方法在未见工具上显著提升了准确率，但规则库的静态离线整合机制限制了其在动态环境中的实时适应能力。

## 研究背景

当LLM面对未文档化的私有API时，其参数化知识无法覆盖特定的工具调用逻辑，导致在分解查询或构造参数时出现系统性错误。这种错误并非随机噪声，而是源于对工具依赖关系的误解，例如直接查询复杂亲属关系而非逐步解析中间实体。解决此类问题需要一种能够抽象失败模式并保留关键逻辑的机制，即解释式学习（Explanation-Based Learning, EBL），它通过生成接地解释并泛化去除实例特定细节，将具体错误转化为通用规则。

工具调用领域的传统适配路径主要依赖监督微调（SFT）或强化学习（RL），这些方法将适配知识内化于模型权重中，导致训练成本高且难以跨模型迁移。同时，基于提示的适配方法如少样本学习或全局提示优化，往往仅复用原始示例或静态指令，缺乏对失败经验的抽象与压缩，在分布外（OOD）任务上表现脆弱。RIMRULE的切入点在于将适配过程外部化，通过构建可解释、可检索的符号化规则库，在不修改LLM权重的前提下，实现失败经验的模块化复用与跨架构迁移。

## 核心方法

### 方法参照系

本文问题属于LLM工具调用的自适应机制，最接近的通用流程是基于提示的上下文学习。关键差异在于，传统流程依赖原始示例或静态提示，而RIMRULE引入了从失败轨迹中归纳符号化规则并进行MDL整合的非参数化阶段，将适配知识从模型权重解耦至外部规则库。

### 失败驱动的符号化规则生成

规则生成阶段旨在从失败轨迹中提取可复用的抽象逻辑，解决传统少样本学习仅复制表面模式而无法纠正系统性推理错误的问题。给定失败轨迹 $\tau^-$ 与真值轨迹 $\tau^*$，LLM生成器通过EBL机制识别根本原因，提出自然语言规则 $r_{NL}$，并编译为包含Domain、Qualifier、Action、Strength、ToolCategory五个字段的符号化形式。该过程通过预测检查（注入规则后性能提升）和语言检查（if-then格式与长度限制）过滤无效规则，确保规则库的初始质量。

### MDL引导的规则整合与检索

规则整合阶段通过最小描述长度（MDL）原则消除冗余，解决初始规则库重叠且过拟合特定实例的问题。MDL目标函数定义为：

$$ \text{MDL}(H) = L(H) + L(D|H) = \alpha \sum_{r \in H} \ell(r) - \left[ k_H \log \hat{p}_H + (n - k_H) \log(1 - \hat{p}_H) \right] $$

其中 $L(H)$ 惩罚规则复杂度（符号token长度），$L(D|H)$ 衡量规则修正失败案例的能力（伯努利似然）。通过贪心剪枝与泛化操作，MDL在保留高效用规则的同时压缩规则库规模。推理时，基于符号字段的语义相似度检索相关规则并注入提示，相比自然语言检索更鲁棒地处理词汇变体，实现了高效且可解释的动态适配。

## 实验评估

实验在ToolHop（多步组合查询）和BFCL（单步工具选择）基准上进行，基线覆盖少样本学习、SEE提示优化、SFT微调及原生函数调用。RIMRULE在Llama3.2上显著优于提示基线，尤其在未见工具（test-unseen）上表现突出。

| 方法 | ToolHop Test-rand | ToolHop Test-unseen | BFCL Test-rand | BFCL Test-unseen |
| :--- | :--- | :--- | :--- | :--- |
| Zero-shot | 26.5±1.3 | 35.1±1.6 | 50.1±0.9 | 45.0±1.0 |
| Few-shot | 29.9±1.4 | 37.9±1.4 | 54.5±0.9 | 46.6±1.4 |
| SEE | 27.6±1.5 | 35.9±1.5 | 52.2±1.0 | 45.5±1.0 |
| RIMRULE | 31.1±1.3 | 43.1±1.6 | 56.6±1.2 | 48.5±1.4 |

RIMRULE在ToolHop test-unseen上较Zero-shot提升8.0个百分点，在BFCL test-unseen上提升3.5个百分点，验证了符号化规则对OOD泛化的有效性。

消融实验显示，MDL整合在减少规则数量的同时提升了性能。ToolHop规则数从72降至约67（减少7%），BFCL从151降至约121（减少20%）。符号化检索比自然语言检索在ToolHop上高1.7个百分点，在BFCL上高2.5个百分点，表明结构化表示对检索鲁棒性的贡献。

评估边界方面，实验依赖训练时的真值执行轨迹，未验证无轨迹场景下的规则生成能力。代码未公开，超参数 $\alpha$ 的选择基于失败集上的端到端准确率，缺乏跨数据集的稳定性分析。

## 关联研究分析

从问题动机看，RIMRULE与Tool-R1等RLVR方法形成鲜明对比。Tool-R1通过强化学习优化模型权重以解决信用分配问题，而RIMRULE将适配知识外部化为符号规则，避免了训练成本但牺牲了模型内部的策略优化能力。这种差异源于任务特性：RIMRULE针对的是系统性推理错误（如分解逻辑），可通过抽象规则纠正；而RLVR更擅长处理需要探索与试错的动态决策。RIMRULE未对比RLVR基线，可能因规则注入无法解决需要长期状态记忆的复杂规划问题。

从方法设计看，RIMRULE与CoHyDE等检索增强方法在检索机制上存在差异。CoHyDE通过迭代协同训练优化检索器，而RIMRULE依赖静态符号字段的语义匹配。RIMRULE的符号化表示虽提升了检索鲁棒性，但缺乏对工具功能可行性的验证，可能在语义相关但功能不可用的场景中失效。这种设计选择反映了RIMRULE对可解释性与轻量级的侧重，而非对检索精度的极致追求。

## 总结

RIMRULE旨在解决LLM在私有工具环境中因系统性推理错误导致的适配难题，通过外部化符号规则库实现非参数化知识共享。其核心创新在于将EBL与MDL原则结合，从失败轨迹中蒸馏可解释规则并压缩冗余，证明了规则注入在未见工具上较Zero-shot提升8.0个百分点的有效性。然而，方法依赖训练时的真值轨迹，且规则库的离线整合机制无法适应动态变化的工具生态。当工具API频繁更新或失败模式高度特定时，静态规则库的泛化能力是否足以维持性能，论文未给出回答。
