# ACL2026最新论文 ｜Efficient Self-Evaluation for Diffusion Language Models via Sequence Regeneration ｜扩散语言模型序列再生自评估

研究机构：浙江大学、新加坡国立大学

作者：Linhao Zhong、Linyu Wu、Wen Wang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.02760)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.02760)

> 扩散语言模型（dLLMs）因双向掩码机制无法像自回归模型那样分解似然，导致其缺乏内置的置信度信号，只能依赖高成本的蒙特卡洛采样进行质量评估，且被迫采用固定长度生成。本文提出 DiSE，通过单次前向传播计算已知 Token 的再生概率，实现高效自评估。该方法不仅将似然估计效率提升 32 倍，还首次实现了基于自评估的免训练变长生成。其价值在于填补了 dLLMs 推理阶段的质量监控空白，但再生概率与真实语义质量的强相关性在长序列误差累积场景下是否依然稳健，尚存疑。

## 研究背景

自回归模型通过因果掩码将序列概率分解为逐词条件概率，使得模型能实时预测结束符（EOS）并据此自适应停止生成。扩散语言模型（dLLMs）采用双向掩码与并行去噪，打破了这种严格的左到右依赖，导致序列概率无法简单分解。这一结构性差异使得 dLLMs 在生成过程中缺乏内在的置信度信号，无法像自回归模型那样通过似然估计进行自我评估，进而被迫在固定长度画布上操作，限制了其在开放式任务中的灵活性。

当前 dLLMs 的似然估计主要依赖蒙特卡洛（MC）模拟，通过多次随机掩码采样近似计算期望，该方法计算昂贵且估计方差大。更关键的是，缺乏高效的自评估信号使得 dLLMs 无法动态调整生成长度，只能预先指定固定长度，导致短答案冗余或长答案截断。本文切入点在于利用 dLLMs 训练过程中隐含的“已知 Token 再生”能力，将其转化为一种低成本的置信度度量，从而解决评估效率与长度控制两大痛点。

## 核心方法

### 蒙特卡洛似然估计参照系

传统 dLLMs 似然估计通过随机掩码 $l$ 个 Token 并预测其恢复概率，取多次采样平均来近似序列对数似然。该流程需 $N_{mc}$ 次前向传播，计算开销随采样数线性增长，且无法提供 Token 级别的细粒度置信度，难以支持实时生成控制。

### 基于再生概率的 DiSE 置信度量化

DiSE 的核心改动在于将评估对象从“未知 Token 的预测”转向“已知 Token 的再生”。给定完整序列 $X$，模型计算其在完整上下文下重新生成每个位置 Token 的概率。设计动机在于利用 dLLMs 在训练中学到的上下文一致性，通过再生概率反映模型对自身输出的确信程度。DiSE 分数定义为选中位置 $U$ 的再生概率对数均值：

$$ \text{DiSE}(X) = \frac{1}{|U|} \sum_{i \in U} \log p_\theta(x_i | X) $$

该公式通过单次前向传播即可计算，相比 MC 采样实现了 32 倍效率提升，且提供了可解释的置信度指标。

### 基于 DiSE 的变长生成机制

在 DiSE 基础上，本文提出免训练变长生成算法。初始生成基础长度 $L$ 的响应后，计算 DiSE 分数作为基准。随后迭代地掩码末尾 $D$ 个 Token 并追加一个新掩码位，重新生成并计算新 DiSE 分数。若分数提升则保留扩展，若连续 $K$ 次未提升或达到最大迭代数 $M_{max}$ 则停止。该机制将 DiSE 作为实时停止信号，解决了固定长度生成的刚性约束，使输出长度随内容复杂度自适应调整。

## 实验评估

实验基于 LLaDA-Instruct-8B 与 LLaDA-1.5-8B，在 ARC-Challenge、GPQA、GSM8K 等数据集上评估。基线包括 MC 采样（$N_{mc}=1, 32$）及自回归模型 LLaMA3-Instruct-8B。DiSE 在似然估计上显著优于 MC 基线，在 ARC-Challenge 上较 $N_{mc}=1$ 提升 23.6%，较 $N_{mc}=32$ 提升 6.4% 且速度提升 32 倍。

| 方法 | ARC-Challenge | GPQA | 前向传播次数 |
| :--- | :--- | :--- | :--- |
| MC, $N_{mc}=1$ | 0.306 | 0.212 | 1 |
| MC, $N_{mc}=32$ | 0.478 | 0.286 | 32 |
| DiSE (ours) | 0.542 | 0.301 | 1 |

在不确定性量化（ROC-AUC）任务中，DiSE 在 GSM8K 上达到 0.658（长度 512），优于 MC $N_{mc}=32$ 的 0.595。变长生成实验显示，DiSE-flexible 在 GSM8K 上较固定长度基线平均准确率提升 1.5%（LLaDA-1.5-8B 从 53.52% 至 54.92%），验证了自适应长度对推理性能的增益。

| 方法 / Base Len | GSM8K (128/256/512) | Avg. Accuracy |
| :--- | :--- | :--- |
| Baseline (LLaDA-1.5) | 70.51 / 77.48 / 79.53 | 53.37 |
| DiSE-flexible (ours) | 72.33 / 79.53 / 80.06 | 54.92 |

评估边界方面，实验仅覆盖 8B 规模模型，未验证更大规模下的泛化性；变长生成依赖 DiSE 分数的单调性，但在长序列误差累积场景下，再生概率是否仍能有效区分正确与错误输出，论文未提供充分证据。

## 关联研究分析

从问题动机看，本文与 Fast-dLLM 等加速方法形成互补。Fast-dLLM 聚焦于通过 KV 缓存减少去噪步数以提升吞吐量，而 DiSE 聚焦于单次前向传播内的质量评估。两者均针对 dLLMs 推理效率瓶颈，但 Fast-dLLM 解决的是“生成慢”，DiSE 解决的是“评估贵”。DiSE 的引入并未改变去噪过程本身，而是为生成过程增加了质量反馈回路，这与 Fast-dLLM 的纯加速策略在架构层面正交，未来可结合使用。

从方法设计看，DiSE 与自回归模型的 EOS 预测机制存在本质差异。自回归模型通过预测特定 EOS Token 的概率来停止，这是一种离散的二元决策；而 DiSE 通过连续的概率均值来评估整体质量，是一种连续的置信度度量。这种差异源于 dLLMs 缺乏严格的因果顺序，无法定义单一的“结束”点。DiSE 的变长生成算法通过迭代扩展与停止，模拟了自回归模型的动态停止行为，但其停止准则依赖于 DiSE 分数的局部最优，而非全局似然最大化，这在复杂推理任务中可能导致过早停止。

## 总结

本文核心矛盾在于 dLLMs 缺乏高效自评估信号导致的固定长度生成限制。DiSE 利用已知 Token 再生概率，以单次前向传播实现置信度量化，解决了 MC 采样的高成本问题。实验证明 DiSE 在似然估计效率上提升 32 倍，并在变长生成中带来约 1.5% 的准确率增益。其边界在于再生概率与语义质量的强相关性仅在短中长度序列中得到验证，当序列长度增加导致误差累积时，再生概率是否仍能准确反映模型置信度，论文未给出回答。
