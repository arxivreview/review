# ACL2026最新论文 ｜CLAOCS-TX: Cross-Lingual Triplet Extraction with Aspect-Opinion-Aware Code-Switched Prompting and LLM-Guided Contrastive Distillation ｜零样本跨语言方面-观点-情感三元组提取

研究机构：印度理工学院

作者：Lipika Dewangan、Chandresh Kumar Maurya

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_81068b5ef720)

> 零样本跨语言方面-观点-情感三元组提取（ASTE）旨在无目标语言标注条件下，从源语言模型迁移结构化情感知识至低资源语言。现有跨语言方法多聚焦粗粒度分类或提取，缺乏对方面-观点配对及边界精度的联合建模，且直接利用大语言模型（LLM）生成伪标签易引发幻觉与结构不一致。本文提出结合方面-观点感知代码切换提示与三元组感知对比蒸馏的统一框架，以LLM为伪标签生成器与语义教师，实现目标语言零样本三元组提取。该方法在8种目标语言上显著优于强基线，但其性能增益高度依赖LLM推理成本，且判别式架构在复杂句法下的鲁棒性存疑。

## 研究背景

跨语言ASTE的核心困境在于目标语言缺乏标注数据，而情感三元组（方面、观点、极性）的提取对词法、形态及句法变异极度敏感。传统跨语言方面级情感分析（XABSA）依赖机器翻译或跨语言词嵌入，但翻译噪声会破坏方面-观点的精确配对，导致边界检测错误在低资源语言中被放大。为缓解标注稀缺，研究者引入多语言预训练语言模型（PLM）如XLM-R，但现有方法多停留在方面提取或极性分类层面，未直接建模三元组间的结构化耦合。

主流路线面临两重瓶颈：一是基于翻译或对齐的方法（如ACS-Distill）在形态丰富语言中因词形变化导致对齐失效；二是直接利用LLM生成伪标签的方法（如LACA）虽能生成结构化输出，但缺乏一致性约束，导致幻觉三元组污染训练过程。本文切入点在于将LLM角色从单纯的“硬监督源”升级为“语义教师”，通过代码切换提示锚定关键语义跨度，并在三元组表示层面进行对比蒸馏，从而在无目标语言标注条件下实现结构化语义对齐。

## 核心方法

### 方法参照系

零样本跨语言ASTE的通用流程为：源语言监督初始化 → 目标语言伪标签生成 → 学生模型更新。本文区别于传统流程的关键在于，伪标签生成不再依赖翻译或单一提示，而是引入多变体代码切换与一致性过滤；蒸馏过程不再基于Token或概率分布，而是直接在结构化三元组表示层面进行对齐。

### 方面-观点感知代码切换提示

传统LLM提示在低资源语言中易因上下文缺失产生幻觉，本文在提示构造环节引入代码切换机制。针对目标句 $x^T$，构造四个变体：原始句 $x^T$、方面切换句 $x^T_A$、观点切换句 $x^T_O$ 及联合切换句 $x^T_{AO}$。切换仅替换候选方面/观点跨度为英文，保留目标语言上下文，以锚定语义边界。LLM对每个变体采样 $K$ 次输出，通过一致性过滤保留高置信伪三元组：

$$
c(\pi) = \sum_{v,k} \mathbb{I}[\pi \in \Psi(G(v, k))]
$$

其中 $\pi$ 为归一化三元组，$\Psi$ 为跨度对齐函数。仅当支持计数 $c(\pi) \ge 2$ 且跨度有效时保留。该设计解决了单一提示在形态丰富语言中因上下文断裂导致的边界漂移问题，通过多视角一致性抑制幻觉。

### 三元组感知对比蒸馏

传统蒸馏基于Token或概率分布，但ASTE输出三元组数量可变，且跨语言Token对齐受形态变异干扰。本文在训练目标环节引入三元组级对比蒸馏。学生模型输出三元组表示 $z^\pi_{stu}$，LLM教师编码三元组文本表示 $z^\pi_{llm}$，通过InfoNCE损失对齐：

$$
\mathcal{L}_{con} = -\sum_{\pi} \log \frac{\exp(\text{sim}(z^\pi_{stu}, z^\pi_{llm})/\gamma)}{\sum_{\pi'} \exp(\text{sim}(z^\pi_{stu}, z^{\pi'}_{llm})/\gamma)}
$$

该公式将学生三元组嵌入拉向对应LLM嵌入，同时推开批内其他三元组。相比概率蒸馏，此方法规避了变长输出空间的不匹配，在噪声伪监督下保持三元组结构完整性，实现了跨语言语义的细粒度迁移。

## 实验评估

实验基于SemEval-2016 Task 5衍生数据集（Fr/Es/Nl/Ru）及4种低资源印地语系语言（Hi/Mr/Bn/Od），采用Micro-F1指标。基线覆盖翻译类（Bilingual-TA）、对齐类（ACS-Distill）、对比类（CL-XABSA）及LLM类（LACA, TT-CSW），但缺失纯生成式Seq2Seq基线，限制了与生成范式方法的直接对比。

| 方法 | Non-Indic Avg | Indic Avg |
| :--- | :--- | :--- |
| TT-CSW | 53.19 | 49.34 |
| LACA | 51.43 | 47.67 |
| CLAOCS-TX | 58.54 | 53.13 |

CLAOCS-TX在Non-Indic语言上超越TT-CSW 5.35点，在Indic语言上超越3.79点，验证了代码切换与三元组蒸馏的协同效应。消融实验显示，移除一致性过滤导致Indic语言性能下降约2.5-3.0点，移除三元组蒸馏下降约1.5-2.0点，表明一致性过滤是抑制低资源语言幻觉的关键，而蒸馏提供稳定的语义对齐增益。

评估边界存在局限：实验仅覆盖餐厅领域，未验证跨领域泛化能力；LLM教师使用Llama-3-8B，未报告不同LLM规模对性能的影响；代码开源但超参数细节（如采样次数 $K$、温度 $\gamma$）未在正文中明确列出，可复现性依赖附录。

## 关联研究分析

从方法设计看，本文与TT-CSW（Sheng et al., 2025）同属代码切换路线，但TT-CSW仅用于测试时增强，而本文将代码切换嵌入训练时的伪标签生成环节，并引入一致性过滤。这一差异源于任务特性：零样本设置下，训练时的伪标签质量直接决定学生模型上限，而测试时增强无法弥补训练数据的结构性缺陷。然而，代码切换依赖候选跨度的准确识别，在形态极丰富的语言中，若初始跨度预测错误，代码切换可能引入偏差，论文未深入探讨此边界。

从问题动机看，本文与ACS-Distill（Zhang et al., 2021）均解决跨语言对齐问题，但ACS-Distill基于方面级投影，本文扩展至三元组级对比蒸馏。这一升级源于ASTE任务对结构完整性的要求：方面级对齐无法捕捉观点词与极性的耦合关系，导致三元组配对错误。然而，三元组级蒸馏假设LLM教师能准确编码三元组语义，若LLM在低资源语言上本身存在理解偏差，蒸馏可能放大教师错误，论文未提供教师质量的量化评估。

## 总结

本文核心矛盾在于零样本跨语言ASTE中伪标签噪声与结构化语义对齐的冲突。现有方法或依赖翻译引入噪声，或依赖LLM硬监督导致幻觉，本文通过代码切换提示提升伪标签可靠性，并通过三元组级对比蒸馏实现细粒度语义迁移，在8种语言上取得58.54（Non-Indic）与53.13（Indic）的Micro-F1。其边界在于判别式BIOES架构对复杂句法的鲁棒性未经验证，且性能高度依赖LLM推理成本。当目标语言形态复杂度进一步增加时，代码切换提示的候选跨度识别准确率是否成为性能瓶颈，论文未给出回答。
