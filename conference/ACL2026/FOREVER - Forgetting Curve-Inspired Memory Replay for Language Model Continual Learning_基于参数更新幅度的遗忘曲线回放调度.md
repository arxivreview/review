# ACL2026最新论文 ｜FOREVER: Forgetting Curve-Inspired Memory Replay for Language Model Continual Learning ｜基于参数更新幅度的遗忘曲线回放调度

研究机构：香港理工大学、北京大学

作者：Yujie Feng、Hao Wang、Jian Li 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.03938)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.03938)

> 持续学习中的灾难性遗忘源于新任务训练对旧知识参数表示的覆盖，而现有回放方法依赖固定步数或静态权重，导致回放时机与模型实际学习进度脱节。FOREVER 通过定义“模型中心时间”——即累积参数更新范数——将人类遗忘曲线的间隔映射到模型内部演化轴上，并引入强度感知正则化动态调整回放力度。该方法在三个基准上平均提升 OP 1.2%，但在高异构生成任务上仍显著低于多任务学习上限，其效果是否依赖于特定优化器动态尚存疑。

## 研究背景

当大语言模型（LLM）在任务序列上顺序微调时，新任务的梯度更新会覆盖旧任务形成的参数模式，导致性能急剧下降，这一现象称为灾难性遗忘。为缓解此问题，回放策略通过保留少量旧样本与新数据联合训练来巩固记忆，但其有效性取决于两个关键决策：何时触发回放以及回放时的正则化强度。传统方法通常采用固定训练步数间隔或静态损失权重，然而相同的步数在不同学习率或批大小下可能引发截然不同的参数变化量，使得基于步数的调度无法准确反映模型的真实遗忘速率。

现有回放方法如 VBM 虽引入了艾宾浩斯遗忘曲线的间隔思想，但仍以训练步数为时间基准，忽略了优化过程中的非线性动态。这种“人类时间”与“模型时间”的错位导致回放可能在模型尚未充分学习或已过度漂移时触发，削弱了记忆巩固的效果。FOREVER 的切入点在于重新定义时间轴：不再依赖外部迭代计数，而是直接测量参数空间的累积位移，从而将认知科学中的遗忘规律锚定在模型自身的演化轨迹上。

## 核心方法

### 方法参照系

回放式持续学习的标准流程包含记忆缓冲区维护、回放触发机制与联合优化目标。本文问题与该通用流程的关键差异在于：传统触发机制基于外部步数，而本文将其替换为基于内部参数动态的自适应调度，同时引入动态正则化权重以替代静态损失平衡。

### 模型中心时间校准

传统回放调度以训练步数 $t$ 为时间单位，假设步数与模型变化量成正比，但在优化器动态变化时该假设失效。FOREVER 通过计算每步参数更新范数 $\Delta_t = \|\Theta_t - \Theta_{t-1}\|_2$ 来量化模型演化速度，并累积得到模型中心时间 $\tau_t = \sum_{i=1}^t \Delta_i$。

$$
\tau_{day} = \frac{1}{S} \sum_{i=1}^{S} \Delta_i
$$

该公式定义了一个“虚拟模型日”，即初始 $S$ 步内累积的参数变化量，作为时间校准的基准单位。通过将艾宾浩斯间隔 $D_{human} = \{1, 2, 4, 7, 15, \dots\}$ 映射为 $D_{model} = \{d_i \cdot \tau_{day}\}$，回放触发条件变为 $\tau_t \geq d_j \cdot \tau_{day}$。这一设计解决了步数调度在优化设置变化时导致的回放时机错位问题，确保回放事件与模型实际学习阶段对齐。

### 强度感知回放正则化

回放触发后，传统方法使用固定权重 $\beta$ 平衡回放损失与任务损失，无法适应模型当前的学习状态。FOREVER 引入不稳定性比率 $r_t = \mu_t / \mu_0$，其中 $\mu_t$ 为近期更新强度的指数移动平均，$\mu_0$ 为基准强度。

$$
\beta_t = \beta_{base} \cdot \text{clip}(r_t^\gamma, g_{min}, g_{max})
$$

该公式根据模型当前更新速率动态调整正则化强度：当 $r_t > 1$（快速变化）时增强正则化以稳定旧知识，当 $r_t < 1$（缓慢变化）时减弱正则化以支持新任务适应。回放损失定义为 $\mathcal{L}_{Replay} = \mathcal{L}_{task} + \beta_t \mathcal{L}_{Reg}$，其中 $\mathcal{L}_{Reg}$ 锚定于上一任务结束时的参数快照。这一机制解决了静态权重在模型学习速率波动时导致的过度约束或约束不足问题，实现了回放力度的自适应调节。

## 实验评估

实验在 Standard CL、Long Sequence 和 SuperNI 三个基准上进行，使用 Qwen3-0.6B 至 LLaMA2-13B 四种骨干模型，基线涵盖 EWC、O-LoRA、SSR、VBM 等回放与正则化方法，但未包含 SAE-FD、CRAFT 等特征解耦类最新方法。

| Method | Standard CL OP↑ | Standard CL BWT↑ | Long Sequence OP↑ | Long Sequence BWT↑ | SuperNI OP↑ | SuperNI BWT↑ |
|---|---|---|---|---|---|---|
| SSR | 64.5 | -10.9 | 34.7 | -14.5 | 68.8 | -6.9 |
| VBM | 70.6 | -6.5 | 67.7 | -8.4 | 39.7 | -5.0 |
| FOREVER | 72.9 | -4.7 | 69.4 | -5.0 | 42.1 | -2.9 |
| MTL | 77.4 | - | 77.8 | - | 48.2 | - |

FOREVER 在 Standard CL 上 OP 达 72.9%，较 SSR 提升 8.4%，较 VBM 提升 2.3%；在 Long Sequence 上 OP 为 69.4%，较 VBM 提升 1.7%。SuperNI 上 OP 为 42.1%，虽优于 VBM 的 39.7%，但仍低于 MTL 上限 48.2% 达 6.1 个百分点，表明在高异构生成任务上回放策略的天花板效应显著。

消融实验显示，移除强度感知正则化后 OP 下降 1.2%，移除模型中心时间校准后 OP 下降 1.1%，两者贡献相近，表明动态调度与动态强度对性能均有独立贡献。值得注意的是，在 SuperNI 上 FOREVER 的 BWT 为 -2.9%，优于 VBM 的 -5.0%，说明模型中心时间校准在长序列任务上对反向迁移的抑制效果更为明显。

评估协议存在局限：所有实验基于 LoRA 微调，未验证全参数微调下的效果；记忆缓冲区固定为 2% 数据，未探索缓冲区大小对动态调度的敏感性；SuperNI 上性能与 MTL 差距较大，可能反映回放策略在生成任务上的固有局限。代码已开源，但超参数 $\lambda=0.05$、$\beta_{base}=10^{-3}$ 等未提供敏感性分析。

## 关联研究分析

从问题动机看，FOREVER 与 VBM 同属艾宾浩斯遗忘曲线应用路线，但 VBM 以步数为时间基准，FOREVER 以参数更新范数为基准。这一差异源于对“模型时间”定义的认知分歧：VBM 假设步数与学习进度线性相关，而 FOREVER 认为优化动态的非线性使得步数成为不可靠代理。根源在于 LLM 训练中学习率调度、批大小变化等因素导致相同步数下的参数变化量差异显著，步数调度无法捕捉这种异质性。

从方法设计看，FOREVER 与 O-LoRA、SAE-FD 等子空间/特征解耦方法解决同一遗忘问题但路径不同：前者通过时间维度上的记忆巩固，后者通过参数/特征空间的知识隔离。FOREVER 依赖回放缓冲区，而 O-LoRA 等采用无回放设定。这一差异暗示了任务特性的影响：在允许少量回放的场景下，动态调度可能比空间隔离更高效；但在严格无回放约束下，FOREVER 的机制无法应用。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

FOREVER 要解决的核心矛盾是回放调度与模型实际学习进度的错位，其切入点在于用参数更新范数替代步数作为时间基准，从而将遗忘曲线锚定在模型内部演化轴上。该方法通过模型中心时间校准和强度感知正则化，在三个基准上平均提升 OP 1.2%、BWT 0.9%。其边界在于：SuperNI 上性能仍低于 MTL 上限 6.1 个百分点，且实验仅基于 LoRA 微调，未验证全参数场景。当优化器动态剧烈变化（如学习率大幅衰减）时，参数更新范数的累积是否仍能准确反映遗忘速率，论文未提供相应实验证据。
