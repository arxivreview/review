# ACL2026最新论文 ｜Hierarchical Reinforcement Learning with Augmented Step-Level Transitions for LLM Agents ｜层级强化学习中的步级状态抽象

研究机构：北京邮电大学、新加坡管理大学

作者：Shuai Zhen、Yanhua Yu、Ruopei Guo 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.05808)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.05808)

> 长程智能体决策面临上下文窗口随交互步数线性增长导致的计算开销激增与关键信号稀释问题。现有层级强化学习（HRL）方法虽通过子任务分解缓解长程依赖，但高低层策略仍依赖累积的历史轨迹，未能从根本上消除对长上下文的依赖。本文提出 STEP-HRL，通过引入局部进度模块将子任务内的交互历史蒸馏为常数大小的文本摘要，使策略仅基于单步转移进行决策。该设计在 ScienceWorld 和 ALFWorld 上显著提升了泛化性能并降低了 Token 消耗，但其离线强化学习范式在探索效率上的潜在局限尚需进一步验证。

## 研究背景

**第1段：预备知识**
当大语言模型（LLM）作为智能体在交互环境中执行长程任务时，策略通常以历史条件化形式存在，即当前动作依赖于过去所有观察与动作的序列。这种设计源于 Transformer 架构的序列建模特性，但在部分可观测马尔可夫决策过程（POMDP）中，未过滤的历史序列会累积冗余信息，导致注意力机制的计算复杂度随上下文长度二次方增长，并掩盖决策关键信号。层级强化学习（HRL）通过引入时间抽象，将任务分解为高层子目标与低层原语动作，旨在缓解长程信用分配难题。然而，现有 HRL 方法中，高层与低层策略依然需要条件化于累积的交互历史，这使得层级结构仅解决了时间跨度问题，而未解决上下文长度膨胀的根本矛盾。

**第2-3段：研究脉络**
Agentic RL 的核心挑战在于稀疏奖励下的信用分配与长程依赖中的状态表示。主流路线如 ReAct 和 Reflexion 通过提示工程或记忆机制处理历史，但本质上仍保留历史条件化；GLIDER 等离线 HRL 方法虽实现了层级分解，但其状态表示仍包含完整交互轨迹，导致推理延迟随步数增加而波动剧烈。这种“历史条件化”被视为序列建模的惯性选择，而非 RL 的必要条件。本文的切入点在于重新审视状态表示的本质：若已完成的高层子任务能代表全局进度，子任务内的局部交互能否被压缩为紧凑的“局部进度”？通过构建仅依赖单步转移的步级状态表示，STEP-HRL 试图在保留层级结构优势的同时，彻底切断策略对长上下文的依赖，实现常数大小的输入维度。

## 核心方法

### 方法参照系

本文问题归属于层级强化学习（HRL）框架，但与传统 HRL 的关键差异在于状态表示的构建方式。标准 HRL 中，高层策略 $\pi^h$ 和低层策略 $\pi^l$ 均条件化于全局交互历史 $H_t$，导致输入长度随时间线性增长。本文摒弃这一假设，提出基于“进度”的状态抽象，将全局进度定义为已完成子任务序列，将局部进度定义为子任务内交互的紧凑摘要，从而将策略输入限制在单步转移范围内。

### 局部进度模块与步级状态构建

传统 HRL 中低层策略需处理子任务内不断增长的局部历史 $h_t^{[k]}$，导致状态空间膨胀。本文引入局部进度策略 $\pi^p$，其设计动机在于将子任务相关的瞬时信息从冗长历史中解耦，形成可控长度的文本表示。在子任务 $g_k$ 的第 $t$ 步，局部进度 $p_t^{[k]}$ 通过递归更新生成：

$$ p_t^{[k]} = \pi^p(p_{t-1}^{[k]}, g_k, a_{t-1}^{[k]}, o_t^{[k]}) $$

该公式表明，当前局部进度仅依赖前一步进度、当前子目标、上一动作及最新观察，而非整个子任务历史。低层策略 $\pi^l$ 随后基于增强的步级转移 $(o_t^{[k]}, p_t^{[k]})$ 生成原语动作，实现了常数大小的输入维度。这一设计消除了低层策略对长上下文的依赖，使得信用分配信号在子任务内部保持紧凑且可区分，避免了历史冗余对梯度信号的稀释。

### 参数共享与离线强化学习优化

为提升参数效率并促进跨层级知识迁移，本文让高层、低层及局部进度策略共享同一 LLM 骨干参数 $\theta$，但配备独立的价值网络。设计动机在于利用统一表示空间捕捉任务语义与环境动态的一致性，同时通过独立 Critic 提供层级特定的价值监督。训练采用两阶段流程：首先通过行为克隆（BC）在专家演示上初始化策略，随后利用离线强化学习（Offline RL）进一步优化。离线 RL 阶段采用隐式 Q 学习（IQL）变体，通过期望回归损失训练价值函数 $V_\psi(s)$：

$$ L(\psi) = \mathbb{E}_{(s,u,r,s') \sim \mathcal{D}_r} \left[ L_2^\tau \left( Q_\phi(s,u) - V_\psi(s) \right) \right] $$

其中 $L_2^\tau$ 为期望损失，$\tau > 0.5$ 确保价值函数逼近动作价值的高分位数。策略更新采用优势加权回归，避免显式策略优化带来的不稳定性。该机制使得模型在无需在线交互的情况下，通过离线数据迭代提升泛化能力，同时规避了 On-policy RL 在多轮交互中常见的熵坍缩风险。

## 实验评估

实验在 ScienceWorld 和 ALFWorld 两个基准上进行，对比基线包括 ReAct、Reflexion、SwiftSage、ETO、WKM 及 GLIDER。基线覆盖提示工程、行为克隆及离线 HRL 路线，但缺失 2025-2026 年涌现的多智能体协作方法（如 Stronger-MAS）及最新 On-policy RL 框架（如 GRPO 变体），限制了与当前 SOTA 的直接可比性。

| Backbone | Method | ScienceWorld (Seen/Unseen) | ALFWorld (Seen/Unseen) |
| :--- | :--- | :--- | :--- |
| Llama-3-8B | GLIDER | 77.43 / 68.34 | 71.56 / 75.38 |
| Llama-3-8B | **STEP-HRL** | **81.57 / 77.81** | **97.14 / 97.76** |
| Mistral-7B | GLIDER | 67.31 / 65.14 | 70.02 / 74.83 |
| Mistral-7B | **STEP-HRL** | **80.28 / 75.21** | **96.43 / 97.01** |

在 ALFWorld 上，STEP-HRL 以 Llama-3-8B 为骨干时达到 97.76% 的 Unseen 成功率，较 GLIDER 提升 22.38 个百分点；在 ScienceWorld 上，Unseen 成功率从 68.34% 提升至 77.81%，相对提升 13.86%。消融实验显示，移除局部进度模块（w/o LP）导致性能下降最显著（Llama-3-8B 从 77.81% 降至 60.6%），证实局部进度是区分状态、细化信用分配的关键；移除层级结构（w/o Hier）次之，表明层级分解对减轻局部进度模块负担至关重要。

评估边界方面，论文未报告置信区间，且 ScienceWorld 的 SOTA 对比缺失，难以判断 77.81% 是否接近理论上限。可复现性良好，代码已开源，超参数（如 LoRA 秩、学习率）详细披露，实验在 8 张 A100 GPU 上完成。Token 效率分析显示，STEP-HRL 的单步 Token 消耗保持恒定（约 1.5k），而标准 RL 随步数线性增长至 1.9k 以上，验证了步级状态抽象在计算效率上的优势。

## 关联研究分析

从状态表示角度看，STEP-HRL 与 GLIDER 形成鲜明对照。GLIDER 作为离线 HRL 代表，虽实现了层级分解，但其高层策略仍条件化于完整交互历史，导致推理延迟在子任务生成步骤出现尖峰。STEP-HRL 通过局部进度模块将历史压缩为常数大小摘要，不仅降低了计算开销，更在理论上解耦了“时间抽象”与“上下文长度”的绑定关系。这一差异源于对 LLM 智能体本质的不同理解：GLIDER 视历史为必要状态信息，而 STEP-HRL 视其为可蒸馏的冗余信号。然而，局部进度模块本身依赖 LLM 的摘要能力，若子任务内信息密度极高，摘要可能丢失关键细节，论文未对此进行量化分析。

从训练范式看，STEP-HRL 采用 Offline RL（IQL 变体），而领域主流如 GRPO 采用 On-policy RL。Offline RL 的优势在于样本效率与训练稳定性，避免了在线交互中的策略崩溃风险，但其泛化能力受限于离线数据的分布覆盖。论文通过混合专家数据与 BC 收集数据（1:2 比例）缓解分布偏移，但未对比 On-policy 方法在相同数据预算下的表现。若在线探索能发现离线数据未覆盖的有效策略，Offline RL 的泛化上限可能低于 On-policy 方法。此外，局部进度模块的引入增加了前向传播次数，早期步骤延迟略高于标准 ReAct，但在长程任务中优势显著，这一权衡在短程任务中是否成立，论文未给出回答。

## 总结

STEP-HRL 旨在解决长程 LLM 智能体中历史条件化导致的计算开销激增与信号稀释矛盾。其切入点在于识别出“长上下文条件化”是建模选择而非 RL 必要性，并通过局部进度模块将子任务内交互蒸馏为常数大小摘要，使策略仅依赖单步转移。实验证明，该设计在 ALFWorld Unseen 任务上达到 97.76% 成功率，较 GLIDER 提升 22.38 个百分点，同时保持恒定 Token 消耗。然而，其边界在于离线 RL 范式对数据分布的依赖，以及局部进度摘要在高信息密度场景下的潜在信息损失。当子任务内部交互复杂度超出 LLM 摘要能力时，局部进度模块是否仍能维持有效的状态区分，论文未提供实证支持。
