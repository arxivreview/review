# ACL2026最新论文 ｜Don’t Be Misled by Style: A Style-Adaptive Reranker for Capturing Effective Knowledge in Retrieval-Augmented Generation ｜风格自适应重排器

研究机构：东南大学

作者：Ruwen Zhang、Bo Liu、Zhang Sheng Xiang 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_02ee82e14564)

> 在检索增强生成（RAG）系统中，重排器负责筛选送入大语言模型（LLM）的候选文档，但现有模型多在单一风格语料上训练，导致面对混合风格语料时，排序结果被表面语言特征而非核心事实证据所主导。这一风格敏感性使得非正式但语义相关的证据被错误降权，直接损害下游生成质量。SARK 通过构建风格变体对，利用 LLM 提取多粒度知识信号，并采用风格增强多任务学习，迫使模型在联合分布上优化，从而解耦内容语义与语言风格。该方法在混合风格场景下显著提升了多种 LLM 的答案准确率，但其泛化能力受限于单一 QA 数据集，且在标准检索基准上的表现尚待验证。

## 研究背景

RAG 系统的性能瓶颈常源于重排器对候选文档的筛选偏差。当检索语料包含百科、新闻及社交媒体等混合风格文本时，重排器需区分“有效知识”与“风格噪声”。传统编码器模型依赖表面语义相似度，易受词汇差异干扰；而生成式重排器虽能捕捉深层语义，但往往隐式依赖正式文本的统计特征，将风格特征误判为相关性信号。这种风格偏置导致模型在识别非正式格式中的关键事实时失效，使得 RAG 系统无法充分利用开放域语料中的有效信息。

现有重排方法主要分为基于编码器的表示学习路线和基于 LLM 的生成式路线。前者如 BGE 和 ColBERT，擅长细粒度匹配但未显式对齐 LLM 的推理需求；后者如 RankGPT 和 DPA-RAG，尝试利用 LLM 反馈优化排序，但均忽视了风格敏感性这一关键变量。尽管部分研究关注生成对齐中的风格匹配，但在重排任务中，风格应被视为干扰噪声而非优化目标。SARK 的切入点在于将重排目标从“最大化语义相似度”重构为“最大化对下游 LLM 答案正确性的贡献”，并显式引入风格不变性约束，确保排序仅由事实证据驱动。

## 核心方法

### 方法参照系

SARK 属于基于编码器的重排架构，但引入了 LLM 作为离线监督信号生成器。与标准 Pointwise 重排器仅优化相关性分数不同，SARK 的核心差异在于其训练目标并非直接预测文档相关性，而是预测文档对 LLM 答案正确性的“增益”或“损害”，并通过风格变体对强制模型忽略表面语言特征。

### 多粒度知识提取

传统重排器缺乏对文档“效用”的直接度量，仅依赖静态相关性标注。SARK 利用 LLM 作为推理验证器，从两个粒度提取知识信号。在段落级，通过对比 LLM 有无检索上下文时的答案正确性，构建二分类标签 $l_i$，其中 $l_i=1$ 表示文档提供了必要事实支持，$l_i=0$ 表示文档引入误导。该过程通过混合验证函数 $E(a, y)$ 实现，结合精确匹配（EM）与 LLM 判断以处理语义变体。在列表级，采用多轮对话提示引导 LLM 对候选文档进行相对排序，构建偏序约束集 $D_{list}$。这种多粒度设计解决了单一相关性标注无法区分“相关但无用”与“相关且有效”文档的问题，直接对齐了重排器与下游生成任务的目标。

### 风格增强多任务学习

仅提取知识信号不足以消除风格偏置，因为模型仍可能在正式文本上过拟合。SARK 引入风格增强多任务学习（SAT），通过联合优化正式与非正式变体对，强制模型学习风格不变的特征表示。其核心损失函数定义为：

$$
L = \lambda L_{s}^{pas} + (1 - \lambda) L_{s}^{list}
$$

其中 $L_{s}^{pas}$ 和 $L_{s}^{list}$ 分别为段落级和列表级在风格变体对上的平均损失。具体而言，段落级损失 $L_{s}^{pas}$ 计算正式与非正式变体上交叉熵损失的均值，列表级损失 $L_{s}^{list}$ 计算 RankNet 损失的均值。这种联合优化迫使模型在 $f_\theta(q, \langle c, s_i \rangle) \approx f_\theta(q, \langle c, s_j \rangle)$ 的约束下学习，即对于相同内容 $c$，不同风格 $s_i, s_j$ 应产生相近的分数。该机制有效抑制了模型对特定语言模式的过拟合，使其能够锁定核心事实证据，而非被表面风格所误导。

## 实验评估

| 模型 | Accuracy | EM | BERTScore | ROUGE |
| :--- | :--- | :--- | :--- | :--- |
| BGE-Base | 0.4745 | 0.3020 | 0.7055 | 0.5327 |
| RankLLaMA | 0.5163 | 0.3330 | 0.7279 | 0.5819 |
| SARK | 0.5360 | 0.3460 | 0.7350 | 0.5919 |
| SARK (w/o SAT) | 0.5213 | 0.3350 | 0.7320 | 0.5858 |

实验在 NQ 数据集上进行，候选集包含 50% 正式与 50% 非正式段落。基线覆盖了编码器（BGE, MiniLM, mGTE）和生成式（RankGPT, RankLLaMA）两类主流方法，但缺失 MVP、E2Rank 等最新高效重排器。SARK 在 Accuracy 上达到 0.5360，较最强基线 RankLLaMA 提升 1.97%，在 ROUGE 上提升 1.00%。消融实验显示，移除 SAT 模块后，Accuracy 从 0.5360 降至 0.5213，ROUGE 从 0.5919 降至 0.5858，证实了风格增强联合训练对性能的关键贡献。

在风格鲁棒性分析中，SARK 在 20% 正式文本比例下仍保持较高性能，较 RankLLaMA 领先 2.3%。跨 LLM 泛化实验表明，SARK 作为插件模块，可使 Llama3.1-8B 的 EM 提升近 9%，Gemma3-12B 的 BERTScore 提升 12.95%。效率方面，SARK 延迟为 127.89 ms/query，吞吐量 7.82 queries/sec，比 RankLLaMA 快 10 倍以上，接近 BGE-Large 的效率水平。

评估边界方面，实验仅基于 NQ 单一数据集，未覆盖 TREC DL 等标准检索基准，无法直接比较 nDCG 指标。代码未公开，且风格变体由 LLM 生成，可能存在生成偏差。此外，实验未报告置信区间，数值比较需谨慎。

## 关联研究分析

从问题动机看，SARK 与 DPA-RAG 均利用下游答案准确性作为监督信号，但 DPA-RAG 未处理风格偏置，而 SARK 显式引入风格不变性约束。这一差异源于 SARK 针对混合风格语料的特定场景，而 DPA-RAG 更关注通用效用对齐。SARK 的切入点在于将风格视为干扰噪声，而非优化目标，这与生成对齐研究中将风格作为匹配目标的路径形成对比。

从方法设计看，SARK 采用编码器架构，但利用 LLM 生成监督信号，属于“生成式监督+编码器推理”混合路线。这与 RankGPT 等纯生成式重排器不同，后者直接通过自回归解码生成排序，延迟高但语义理解强。SARK 通过离线提取知识信号，将重排过程转化为特征提取任务，从而在保持高效推理的同时，捕捉了 LLM 的推理偏好。然而，这种设计可能损失生成式模型在复杂语义理解上的优势，且 LLM 生成标签的准确性可能引入新的偏差。

## 总结

SARK 旨在解决混合风格语料下重排器被表面语言特征误导的问题，通过多粒度知识提取与风格增强多任务学习，实现了风格不变的知识捕获。实验表明，SARK 在 NQ 混合风格场景下 Accuracy 达 0.5360，较 RankLLaMA 提升 1.97%，且推理效率比生成式基线快 10 倍以上。其边界在于实验仅基于单一 QA 数据集，未验证在标准检索基准上的表现，且风格变体由 LLM 生成，可能存在生成偏差。当语料风格分布发生剧烈变化时，SARK 的风格不变性是否仍能保持，论文未给出回答。
