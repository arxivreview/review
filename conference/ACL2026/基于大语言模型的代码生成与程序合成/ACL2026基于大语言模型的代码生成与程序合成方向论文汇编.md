【SLICEFORMER: Static Program Slicing Using Language Models With Dataflow-Aware Pretraining and Constrained Decoding ｜静态程序切片的数据流感知预训练与约束解码

研究机构：加拿大康考迪亚大学

作者：Pengfei He、Shaowei Wang、Tse-Hsun Chen 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_966c8599491c)

> 静态程序切片旨在从代码中精确提取影响特定变量的语句子集，是漏洞分析与调试的基础。现有基于语言模型的方法常因依赖表面模式而非真实数据流，导致切片遗漏或包含无关语句，且生成过程易产生幻觉。本文提出 SLICEFORMER，通过数据流图（DFG）感知的预训练目标与 TSED 单调性约束解码，将切片重构为序列到序列任务。该方法在 Java 和 Python 基准上显著提升了精确匹配率，但其对传统静态分析工具缺乏直接对比，且未报告计算开销，限制了其工程适用性的评估。

】
