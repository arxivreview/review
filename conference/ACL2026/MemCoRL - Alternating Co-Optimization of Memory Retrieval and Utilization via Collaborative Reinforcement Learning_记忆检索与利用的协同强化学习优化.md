# ACL2026最新论文 ｜MemCoRL: Alternating Co-Optimization of Memory Retrieval and Utilization via Collaborative Reinforcement Learning ｜记忆检索与利用的协同强化学习优化

研究机构：北京邮电大学

作者：Yuewen Liu、Peng Xu、Muxi Diao 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_1881116d8a96)

> 长上下文交互中，大语言模型（LLM）受限于固定窗口长度，需依赖外部记忆模块存储历史信息。现有方法聚焦于记忆架构设计与检索策略优化，却忽视了“记忆利用”这一将检索证据转化为答案的关键推理环节，导致检索质量与最终性能脱节。MemCoRL 提出一种两阶段交替协同强化学习框架，通过引用反馈与语义奖励联合优化检索策略与利用策略，形成正向反馈闭环。该框架在 LoCoMo 和 LongBench 基准上显著超越现有基线，但其效果高度依赖特定奖励函数设计，且未解决记忆内容本身的准确性问题。

## 研究背景

当 LLM 处理跨越数十轮对话的长期任务时，其固定上下文窗口无法容纳全部历史交互，迫使模型依赖外部记忆模块存储关键信息。这一过程涉及两个紧密耦合的阶段：从历史上下文中检索相关证据（Memory Retrieval），以及利用检索到的证据生成当前回答（Memory Utilization）。检索质量直接决定利用的上限，而利用过程中的推理反馈又揭示了检索证据的相关性，二者构成互为因果的动态系统。

现有外部记忆研究主要沿两条路线展开：一是知识组织与架构设计，如 A-Mem 构建互联笔记结构、MemGPT 模拟操作系统分页机制，旨在解决记忆的存储与组织问题；二是检索优化，如 RMM 利用在线强化学习（RL）对齐检索器与生成器引用的证据。然而，这些方法均将记忆利用视为黑盒或静态过程，未将其纳入优化闭环。这导致一个关键失效：检索策略可能收敛到“高引用率但低语义相关性”的局部最优，即模型学会检索那些容易被引用但实际无用的证据，而利用策略因缺乏针对性优化，无法有效整合分散的证据。MemCoRL 的切入点正是打破这种单向依赖，将检索与利用建模为相互依赖的策略对，通过协同优化实现全局性能提升。

## 核心方法

### 方法参照系

本文问题可置于“检索增强生成（RAG）”的通用流程中，但存在关键差异：标准 RAG 假设检索是静态的、一次性的，且利用阶段不参与检索优化。MemCoRL 将 RAG 改造为动态策略优化问题，其中检索策略 $\pi_r$ 和利用策略 $\pi_u$ 均为可学习的参数化模型，并通过交替强化学习进行联合训练。

### 检索策略的混合奖励优化

检索策略 $\pi_r$ 的优化面临“奖励黑客”（Reward Hacking）风险：若仅使用引用奖励，模型可能生成幻觉证据以诱导利用策略引用，从而虚高奖励。为此，MemCoRL 设计混合奖励函数，结合引用反馈与语义匹配：

$$
R(m_i) = \alpha r_{\text{citation}}(m_i) + (1-\alpha) r_{\text{semantic}}(q, y)
$$

其中 $r_{\text{citation}}(m_i)$ 指示证据 $m_i$ 是否被利用策略引用，$r_{\text{semantic}}(q, y)$ 由 LLM-as-judge 评估利用策略基于该证据生成的答案与标准答案的语义一致性。该设计动机在于：当引用奖励饱和时，语义奖励提供额外梯度信号，引导检索策略从“易引用”转向“高相关”，避免局部最优。

### 利用策略的协同进化优化

利用策略 $\pi_u$ 的优化同样采用混合奖励，但侧重语义保真与词汇重叠的平衡：

$$
R(y) = \lambda r_{\text{LLM}}(q, y) + (1-\lambda) r_{\text{BLEU}}(y_{\text{ans}}, y_{\text{gold}})
$$

其中 $r_{\text{LLM}}$ 评估答案的准确性与完整性，$r_{\text{BLEU}}$ 衡量词汇重叠。关键创新在于交替优化机制：每轮训练中，先冻结 $\pi_u$ 优化 $\pi_r$，再冻结 $\pi_r$ 优化 $\pi_u$。这种协同进化使利用策略的改进反馈重塑检索奖励，帮助 $\pi_r$ 逃离局部最优；同时，更精准的检索证据扩展 $\pi_u$ 的探索空间，避免推理停滞。该机制解决了单一策略优化中“检索-利用”性能脱节的问题，使两者共同收敛至更一致的全局最优。

## 实验评估

实验在 LoCoMo（长期对话记忆）和 LongBench（长上下文问答）基准上进行，基线覆盖 MemoryBank、MemGPT、A-Mem、Mem0 等主流外部记忆方法，但缺失参数化记忆基线（如 LoRA 微调模型）。LoCoMo 上，MemCoRL-14b 在 F1、BLEU-1 和 LLM-as-judge 指标上全面超越 Mem0，其中 F1 提升 24%，BLEU 提升 39%，LLM-as-judge 提升 18%。LongBench 上，MemCoRL-7b 的 F1 得分达到 54.07，较最强基线 LLoCO（33.80）提升 63%。

| 方法 | LoCoMo F1 | LoCoMo BLEU-1 | LoCoMo LLM-as-judge | LongBench F1 |
| :--- | :--- | :--- | :--- | :--- |
| Mem0 | 38.72 | 27.13 | 67.13 | - |
| MemCoRL-14b | 45.06 | 39.48 | 69.61 | - |
| LLoCO | - | - | - | 33.80 |
| MemCoRL-7b | - | - | - | 54.07 |

消融实验表明，语义奖励对防止检索策略的奖励黑客至关重要：移除语义奖励后，引用奖励迅速收敛至最大值，但 LLM-as-judge 性能显著下降。协同优化轮数对性能有正向影响：单轮协同优化较独立 RL 提升 20%，多轮优化持续稳定提升，但收敛速度较慢。值得注意的是，MemCoRL 在时间推理任务上略逊于 Mem0，因后者采用任务特定的时间提示，而 MemCoRL 追求通用性。

评估边界方面，实验未报告置信区间，且 LoCoMo 和 LongBench 的指标侧重不同（前者重语义，后者重词汇），横向比较需谨慎。可复现性上，论文提供了详细超参数（KL 系数 $1 \times 10^{-3}$，学习率 $1 \times 10^{-6}$，GPU 配置），但未公开代码，限制了第三方验证。

## 关联研究分析

从问题动机看，MemCoRL 与 RMM 同属“检索中心”路线，但 RMM 仅优化检索器，将利用视为固定过程；MemCoRL 则将利用纳入优化闭环，解决了 RMM 中“检索-利用”性能脱节的问题。这一差异源于任务特性：长期对话中，证据分散且需多跳推理，利用阶段的整合能力直接影响最终性能，而 RMM 的静态利用假设在此场景下失效。

从方法设计看，MemCoRL 与 Mem0 同属外部记忆架构，但 Mem0 侧重记忆管理（提取-整合-检索管道），MemCoRL 侧重检索-利用协同优化。Mem0 的图结构记忆表示在时间推理任务上表现更优，因其显式编码时间关系；而 MemCoRL 的通用优化策略在单跳和多跳任务上更稳健，但在需要特定知识（如时间顺序）的任务上缺乏针对性。这暗示，协同优化可能无法替代领域特定的记忆结构设计，二者是否可结合，论文未给出回答。

## 总结

MemCoRL 要解决的核心矛盾是外部记忆系统中检索质量与利用效率的脱节。现有方法如 RMM 仅优化检索，Mem0 仅优化记忆管理，均无法同时提升两个环节的性能。MemCoRL 通过两阶段交替协同强化学习，将检索与利用建模为相互依赖的策略对，利用引用反馈与语义奖励的混合机制，使两者共同进化。实验证明，该框架在 LoCoMo 上 F1 提升 24%，在 LongBench 上 F1 提升 63%，验证了协同优化的有效性。然而，其边界在于：协同优化依赖特定奖励函数设计，且在时间推理等需要领域知识的任务上表现不如专用架构。当记忆内容本身存在噪声或矛盾时，协同优化是否仍能引导模型正确利用证据，论文未给出回答。
