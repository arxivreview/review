# ACL2026最新论文 ｜CogEvolve: A Multimodal Benchmark for Evaluating Relational Reasoning in Semantic Extension ｜语义扩展的生成逻辑诊断：CogEvolve 基准

研究机构：大连理工大学

作者：Jingjie Zeng、Huayang Li、Liang Yang 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_d10074f57f8a)

> 导读 现有大语言模型（LLM）评估多聚焦于静态关联，难以区分模型是内化了语义演化的因果逻辑还是仅记忆了统计共现模式。传统词义消歧（WSD）基准将多义词视为扁平列表，无法探测从具体原型到抽象意义的方向性推导能力。本文提出 CogEvolve，利用结构化矢量图（SVG）作为视觉思维链，构建三层认知诊断漏斗，系统评估模型在文本与视觉模态下的关系推理边界。该基准揭示了模型在文本模态具备符号推理能力，但在视觉模态存在“未接地箭头”缺陷，为理解 LLM 的认知局限提供了新视角，但其对低频抽象概念的泛化能力仍存疑。

## 研究背景

当模型面对“地壳”一词时，人类基于面包外壳的具身经验将其推导为地质隐喻，而 LLM 往往因语料中科学术语的高频出现，直接将其识别为字面原型。这一差异源于原型理论（Prototype Theory）中认知基本性与统计频率的错位：人类语义扩展遵循从具体到抽象的因果路径，而模型倾向于将高频共现模式误认为认知根源。这种“频率-首要性混淆”导致模型在深层语义理解上出现系统性偏差，无法区分统计常见性与认知根本性。

当前 LLM 语义理解研究正从行为验证向机制解释转移，但现有基准如 WSD 和 VQA 仅评估静态关联，缺乏对语义演化方向性的探测。主流路线通过通用基准验证模型能力，却掩盖了模型在抽象概念接地与组合性推理上的局限。本文切入点在于将语义扩展形式化为有向无环图（DAG），通过 SVG 结构化表征解耦感知噪声与逻辑推理，构建能区分“点”（概念识别）与“箭头”（因果推导）的诊断工具。

## 核心方法

### 三层认知架构与 SVG 解耦

本文方法置于多模态语义评估框架下，关键差异在于引入结构化矢量图（SVG）作为中间表征层。传统光栅图像依赖像素级感知，易受噪声干扰；SVG 作为代码基表征，显式编码几何变换，充当“视觉思维链”。该设计动机在于隔离感知能力与推理能力，确保模型失败归因于逻辑缺陷而非视觉盲区。

$$
\mathcal{L} = \mathcal{L}_{symbolic} \cup \mathcal{L}_{structural} \cup \mathcal{L}_{schematic}
$$

该公式定义数据架构，其中 $\mathcal{L}_{symbolic}$ 提供文本定义，$\mathcal{L}_{structural}$ 定义因果路径（如原型→隐喻），$\mathcal{L}_{schematic}$ 通过 SVG 锚定抽象关系。SVG 强制视觉表征在模式逻辑层面操作，模拟人类抽象化过程，剥离纹理与光照等感官细节。

### 频率-首要性混淆诊断机制

在 Tier 2 认知角色分类任务中，模型需区分原型、隐喻与转喻。本文引入频率基线（Frequency Baseline），即默认选择语料库中最高频义项作为“原型”的启发式策略。该设计旨在量化模型对统计频率的依赖程度，揭示其是否真正内化了认知推导规则。

$$
\Delta_{freq} = Acc_{model} - Acc_{freq\_baseline}
$$

该公式计算模型准确率与频率基线的差距。若 $\Delta_{freq}$ 较小，表明模型行为接近概率鹦鹉，将统计常见性混淆为认知基本性。实验显示 GPT-5.1 的 $\Delta_{freq} \approx 5.5\%$，证实模型缺乏层级化认知组织，而是基于统计分布水平排列概念。

## 实验评估

实验在自建 CogEvolve 基准上进行，覆盖 6,431 个多义词，包含文本与视觉模态任务。基线涵盖前沿闭源模型（Claude-4-Sonnet, GPT-5.1）与开源模型（Qwen3-8B, Llama3.1-8B），并设置专家与朴素人类基线。缺失专用监督模型对比，但通过人类基线提供了认知参照。

| 任务 | 模型 | 准确率 (%) |
| :--- | :--- | :--- |
| Task 1a: 文本 WSD | Claude-4-Sonnet | 96.9 |
| Task 1a: 文本 WSD | GPT-5.1 | 95.8 |
| Task 1a: 文本 WSD | Expert Human | 95.2 |
| Task 1b: 跨模态对齐 | Gemini-3-Pro | 92.0 / 90.0 |
| Task 2: P/M/T 分类 | GPT-5.1 | 52.3 |
| Task 2: P/M/T 分类 | Frequency Baseline | 46.8 |

Tier 1 结果显示，前沿模型在静态关联任务上达到近天花板水平，Claude-4-Sonnet 在文本 WSD 中达 96.9%，超越专家人类基线（95.2%），证实模型具备高保真概念表征。然而，Tier 2 揭示结构性缺陷：GPT-5.1 在原型/隐喻/转喻分类中仅达 52.3%，仅比频率基线（46.8%）高 5.5%，表明模型未能内化认知推导层级，而是依赖统计频率。

Tier 3 文本路径排序任务中，前沿模型在复杂链（N>2）上准确率稳定在 80% 左右，呈现“逆复杂度效应”，而小模型（Qwen3-8B）出现“复杂度崩塌”（41.2%）。掩码词控制实验（p=0.535）证实文本推理依赖抽象语义算子而非词汇记忆。但在视觉路径排序任务中，模型表现显著下降，暴露“未接地箭头”缺陷：模型能识别视觉节点，但无法推断方向向量，表明缺乏跨模态统一认知空间。

评估边界方面，专家基线样本量较小（N=10），仅作为参考点而非群体上限；SVG 构建依赖人工架构，可能引入标注偏差；代码已开源，但超参数与 GPU 配置未在正文详述，可复现性依赖附录细节。

## 关联研究分析

从问题动机看，本文与 Grounding Gap Analysis (P18) 均关注抽象概念接地缺失，但 P18 通过 SAE 特征探测内部表征，本文则通过外部行为诊断（SVG 推理）量化接地鸿沟。P18 揭示模型依赖抽象符号关联而非感官锚点，本文进一步细化为视觉模态下的关系推理失效，提供了更细粒度的诊断工具。差异根源在于任务特性：P18 聚焦内部机制解释，本文聚焦外部认知能力评估，二者互补而非替代。

从方法设计看，本文与 Semantic Role Circuits (P22) 形成对比。P22 通过因果边归因识别内部局部化回路，支持语义理解的模块化假设；本文则通过 SVG 解耦感知与推理，强调跨模态认知空间的缺失。P22 假设语义功能由特定神经元集群负责，本文则表明即使内部表征正确（Tier 1 高分），外部推理仍可能失败。这种差异暗示：内部机制的局部化并不保证跨模态推理的统一性，模型可能在文本模态具备“符号箭头”，但在视觉模态缺乏对应的“接地箭头”。

## 总结

本文核心矛盾在于 LLM 在文本模态表现出的符号推理能力与视觉模态下的关系推理失效之间的断裂。切入点在于利用 SVG 结构化表征解耦感知噪声与逻辑推理，构建能区分静态关联与动态推导的诊断基准。通过三层认知漏斗，本文证明了前沿模型在文本路径排序中达到 80% 准确率，但在视觉路径排序中显著退化，暴露“未接地箭头”缺陷。边界在于 SVG 构建依赖人工架构，且专家基线样本量有限，可能影响结论的普适性。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
