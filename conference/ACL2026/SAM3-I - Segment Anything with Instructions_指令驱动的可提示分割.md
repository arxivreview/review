# ACL2026最新论文 ｜SAM3-I: Segment Anything with Instructions ｜指令驱动的可提示分割

研究机构：加拿大阿尔伯塔大学、美国西北大学

作者：Jingjing Li、Yue Feng、Yuchen Guo 等 13 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.04585)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.04585)

> 开放词汇语义分割（OVSS）旨在突破固定类别限制，但现有模型在处理包含属性、空间关系及隐含推理的复杂自然语言指令时，往往依赖外部多模态大语言模型（MLLM）进行多轮转换与过滤，导致语义信息在名词短语（NP）层面丢失且计算开销巨大。SAM3-I 通过冻结 SAM3 骨干并引入级联适配器与分布对齐损失，直接在单一框架内统一概念级理解与指令级推理。该方法在保持概念分割性能的同时，显著提升了复杂指令的实例定位精度，但其对长尾类别及极端域偏移的泛化能力仍受限于冻结骨干的特征表达上限。

## 研究背景

当用户试图分割“最右侧穿蓝色球衣正在滑铲的足球运动员”时，传统的提示可概念分割（Promptable Concept Segmentation, PCS）范式面临根本性困境。PCS 仅支持短名词短语（如“足球运动员”）作为提示，无法解析多条件约束与隐含逻辑。为弥补这一缺陷，当前主流方案采用外部智能体（Agent）流水线，即调用 MLLM 将复杂指令降维为短 NP，再执行多轮掩码过滤。这种解耦设计虽然可行，但将语言推理与视觉分割割裂，且 NP 级别的粗粒度概念往往不足以精确锚定特定实例，导致细粒度条件丢失。

开放词汇分割领域正从全局特征匹配向提示驱动的概念分割演进。SAM3 确立了基于短 NP 的 PCS 范式，实现了概念召回，但其在复杂指令遵循上存在结构性短板。现有研究如 LISA 和 CoT-Seg 尝试通过 MLLM 增强推理，但多依赖外部模型调用，增加了系统复杂度与延迟。SAM3-I 的切入点在于不改变 SAM3 的视觉-语言编码器结构，而是通过参数高效的适配器机制，将指令语义直接注入分割流程，从而在保留概念召回能力的同时，实现从概念到复杂指令的无缝扩展。

## 核心方法

### 方法参照系

SAM3 架构包含双视觉-语言编码器与基于检测器的分割头，原生支持视觉提示与短 NP 概念提示。本文问题与标准 PCS 流程的关键差异在于输入从原子概念扩展为层级化指令，且要求在不解冻骨干的前提下，使模型具备解析隐含语义与执行空间推理的能力，而非依赖外部 MLLM 的中间转换。

### 指令感知级联适配器

针对复杂指令中显式 NP 缺失导致的空间锚定失效，SAM3-I 在文本编码器每层插入级联适配器。S-Adapter 负责学习属性、位置与关系语义，处理保留显式 NP 的简单指令；C-Adapter 构建于 S-Adapter 之上，处理省略 NP 并依赖功能或上下文推理的复杂指令。两适配器均采用瓶颈结构（下投影、GELU、上投影）及多头自注意力（MHSA）以捕获长程文本依赖。训练时，简单指令仅激活 S-Adapter，复杂指令激活全级联，使 C-Adapter 能精炼 S-Adapter 的输出。这种渐进式设计镜像了语言难度的自然层级，避免了单一适配器在共享参数空间中难以区分显式指称与隐式推理的混淆。

$$
\mathcal{L}_{inst} = \sum_{i} \left( \ell_{i}^{s \to c} + \ell_{i}^{c \to s} \right)
$$

该指令对比损失将同一实例的简单与复杂指令嵌入视为正对，批内其他实例指令视为负对，通过余弦相似度约束嵌入空间，确保不同表达形式的同一目标在语义上不变，同时保持不同实例间的可区分性。

### 分布对齐损失机制

为防止简单与复杂指令分支独立解释导致的语义漂移，SAM3-I 引入四项分布对齐损失。其中，父级概念锚定损失（Parent-rank Concept Anchoring Loss）通过边际排序约束，确保指令嵌入比其所属概念嵌入更接近自身概念，而非其他类别概念，从而在允许子集级指令理解的同时，防止嵌入偏离原始概念边界。

$$
\mathcal{L}_{anchor} = \max(0, m - (\langle z_i^{sc}, z_i^o \rangle - \max_{j \neq i} \langle z_i^{sc}, z_j^o \rangle))
$$

此公式强制指令嵌入 $z_i^{sc}$ 与自身概念嵌入 $z_i^o$ 的相似度高于与其他概念嵌入的相似度，$m$ 为边际超参数。该机制作为语义护栏，将指令嵌入锚定在 SAM3 原有的概念级表示附近，平衡了子集定位的灵活性与概念一致性的稳定性。

此外，掩码分布对齐损失使用 KL 散度对齐两分支的掩码预测分布，不确定性感知难区域监督损失则利用 Jensen-Shannon 散度计算不确定性图，作为交叉熵损失的自适应权重，引导模型聚焦于遮挡或关系线索等语义困难区域。

## 实验评估

实验在 HMPL-Instruct、RefCOCO 及 Ref-ZOM 上进行，基线涵盖 SAM3、SAM3 Agent、LISA 及 UniPixel。对比方法覆盖了从基础概念分割到 MLLM 辅助指令分割的主要路线，但缺乏与 NERVE、PEARL 等免训练特征修正类方法的直接对比，这可能限制了在纯特征优化维度上的性能参照。

| 模型 | 参数 | 推理模式 | 概念级 gIoU | 简单指令 gIoU | 复杂指令 gIoU |
| :--- | :--- | :--- | :--- | :--- | :--- |
| SAM3 | 0.8B | 单步 | 29.5 | – | – |
| SAM3 Agent | 8.8B | 多步 | – | 28.4 | 26.4 |
| SAM3-I | 1.1B | 单步 | 29.5 | 59.7 | 49.0 |

SAM3-I 在简单指令上较 SAM3 Agent 提升 31.3 点 gIoU，在复杂指令上提升 22.6 点，且参数规模仅为 Agent 的 1/8。在 RefCOCO 上，SAM3-I 取得 76.3 gIoU，优于 LISA 的 57.3 和 SAM3 Agent 的 71.1，验证了内部级联推理优于外部多轮过滤的效率与精度。

| 配置 | 简单指令 gIoU | 复杂指令 gIoU |
| :--- | :--- | :--- |
| 仅 Lseg (Stage 1,2) | 57.6 | 40.8 |
| + Linst (Stage 3) | 58.6 | 47.4 |
| + Lanchor (Stage 3) | 58.6 | 47.1 |
| + Lmask (Stage 3) | 58.0 | 46.4 |
| + Lhard (Stage 3) | 58.1 | 46.7 |
| 全对齐损失 (SAM3-I) | 59.7 | 49.0 |

消融实验显示，引入指令对比损失（Linst）带来最大增益（复杂指令 +6.6 点），表明嵌入空间的结构化对齐是核心驱动力。单一适配器变体在复杂指令上仅得 46.7 gIoU，低于级联设计的 49.0，证实了显式分离语言角色对渐进式表征精炼的必要性。

评估指标限于 gIoU 和 P@50，未报告计算延迟或内存占用，尽管单步推理是其主要优势。代码已开源，但 HMPL-Instruct 的构建依赖特定 MLLM 版本，复现时需注意数据生成的一致性。

## 关联研究分析

从问题动机看，SAM3-I 与 CoT-Seg 均旨在解决复杂指令遵循，但 CoT-Seg 依赖显式链式思维推理，计算开销大且易受幻觉影响；SAM3-I 通过 C-Adapter 实现隐式推理，将推理过程内化于适配器参数中，避免了外部 MLLM 的调用延迟。这一差异源于任务特性：SAM3-I 假设指令语义可通过文本编码器的层级适配捕获，而 CoT-Seg 假设需要显式的逻辑步骤。然而，当指令涉及多步空间推理时，隐式适配器是否具备足够的推理深度，论文未给出明确回答。

从方法设计看，SAM3-I 与 LISA 同属 MLLM 与分割模型结合路线，但 LISA 通过特殊令牌触发掩码生成，侧重语义描述符的生成；SAM3-I 则冻结骨干，仅训练适配器，侧重指令语义与视觉特征的对齐。LISA 的端到端训练可能更好地适应长尾类别，但 SAM3-I 的参数高效性使其更易部署。两者在骨干选择上的差异（LISA 通常使用 CLIP 或类似模型，SAM3-I 使用 SAM3）导致了特征空间的本质不同，SAM3 的实例分割先验可能更利于细粒度定位，但其在开放词汇泛化上的表现是否优于 CLIP 骨干，缺乏直接对比。

## 总结

SAM3-I 解决了 SAM3 在处理复杂自然语言指令时依赖外部 Agent 导致的语义丢失与计算冗余矛盾。其切入点在于利用级联适配器将指令语义内化，通过分布对齐损失确保不同复杂度指令分支的一致性，从而在冻结骨干的前提下实现参数高效的指令遵循。实验证明，该方法在简单指令上取得 59.7 gIoU，复杂指令上取得 49.0 gIoU，显著优于 SAM3 Agent 且保持概念分割性能不变。然而，其边界在于冻结骨干限制了特征重构能力，且在 HMPL-Instruct 等自建数据集上的性能可能高估了其在极端域偏移或长尾类别上的泛化能力。当指令涉及多步空间推理或罕见概念组合时，隐式适配器的推理深度是否足以替代显式链式思维，仍是未解之题。
