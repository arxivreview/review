# ACL2026最新论文 ｜GMSA: Enhancing Context Compression via Group Merging and Layer Semantic Alignment ｜分组合并与层语义对齐的上下文压缩框架

研究机构：清华大学、韩国首尔大学

作者：Jiwei Tang、Zhicheng Zhang、Shunlong Wu 等 11 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_e4db5de860b6)

> 长上下文推理面临计算复杂度与冗余信息的双重瓶颈，软提示压缩通过连续向量表示换取高压缩比，但现有自回归范式存在锚点 Token 语义主导与跨层语义错位两大缺陷。GMSA 针对此问题，提出基于编码器-解码器架构的压缩框架，引入分组合并机制均匀聚合语义，并设计层语义对齐模块桥接高低层表示鸿沟。该方法在多个长文本问答基准上超越了硬压缩与软压缩基线，但其均匀分组策略对细粒度依赖关系的保留能力尚存疑。

## 研究背景

Transformer 自注意力机制的二次方复杂度导致长序列推理延迟激增，且模型在处理长文本时出现“中间迷失”现象，即对序列中间信息的利用率显著下降。为缓解此问题，软提示压缩（Soft Prompt Compression）将长文本映射为短序列的软 Token，旨在保留完整语义的同时降低计算开销。然而，主流软压缩方法（如 GIST、ICAE）采用追加随机初始化 Token 的自回归方式学习摘要向量，导致输入序列中锚点 Token 的语义在逐层传播中被过度强调，而其他 Token 的语义被稀释，造成信息丢失。

现有软压缩范式还忽视了大语言模型不同层级间巨大的语义表示差异。编码器输出的高层抽象语义向量若直接作为解码器的低层输入，会因语义空间不匹配导致重构性能下降，而传统的多层感知机（MLP）无法有效桥接这一跨层语义鸿沟。GMSA 的切入点在于识别并解决这两个被忽略的机制性缺陷：一是自回归预训练过程中的语义主导问题，二是高低层语义直接对接导致的对齐失效。通过结构性修正而非简单的参数调整，GMSA 试图在保持软压缩高保真优势的同时，提升语义完整性与下游任务效用。

## 核心方法

### 方法参照系

GMSA 属于软提示压缩路线，其标准流程为：编码器提取特征 → 生成短序列软 Token → 解码器重构或生成。与 ICAE 等基线方法的关键差异在于，GMSA 摒弃了“追加 Token”的自回归压缩方式，转而采用“分组合并”生成初始表示，并新增专用的层语义对齐模块，以解决语义主导与跨层错位问题。

### 分组合并机制

设计动机在于解决自回归压缩中锚点 Token 语义主导导致的语义稀释问题。在 ICAE 等基线中，随机 Token 逐层学习摘要向量，使得输入中特定锚点（如“The”）的语义被反复强化，而其他 Token（如“context”）的语义被边缘化。GMSA 将原始文本的隐藏状态 $H$ 划分为等长组，每组通过平均池化生成初始压缩表示 $\bar{H}_G$：

$$ \bar{H}_G = \frac{1}{L_G} \sum_{j=1}^{L_G} H_{G,j} $$

其中 $L_G$ 为组长度，由压缩率决定。这种均匀聚合策略强制每个组内的所有 Token 对摘要向量贡献均等，避免了单一锚点 Token 对语义的垄断，从而在预训练阶段保留了更完整的上下文语义信息。

### 层语义对齐模块

设计动机在于解决编码器高层抽象语义与解码器低层输入语义之间的巨大鸿沟。基线方法通常使用 MLP 或直接连接，但 MLP 缺乏对 Transformer 层级语义结构的感知能力。GMSA 引入层语义对齐（Layer Semantic Alignment, LSA）模块，该模块由 $k_{LSA}$ 个 Transformer 块组成，其权重初始化为解码器前 $k_{LSA}$ 层的权重：

$$ e_m = F_{k_{LSA}}(\bar{H}) $$

其中 $F_{k_{LSA}}$ 表示 LSA 模块的前向传播，$e_m$ 为对齐后的软 Token。通过继承解码器低层的表示空间，LSA 将高层抽象语义投影至低层语义空间，实现了跨层语义的有效对齐。实验表明，仅使用单层 LSA（$k_{LSA}=1$）即可实现显著的语义保留效果，且计算开销极低。

## 实验评估

GMSA 在 LLaMA-3.2-3B-Instruct 和 Qwen3-4B-Instruct 两个骨干模型上进行了评估，涵盖 NaturalQA、2WikiMQA、HotpotQA、NarrativeQA 和 MultiNews 五个基准。基线覆盖硬压缩（LongLLMLingua、LLMLingua-2、Provence、EXIT）与软压缩（ICAE、Activation Beacon），但未包含视觉压缩或智能体动态管理方法。

| 方法 | NaturalQA (EM) | 2WikiMQA (EM) | HotpotQA (EM) | NarrativeQA (EM) | MultiNews (F1) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Original Prompt | 37.55 | 48.00 | 16.29 | 32.34 | 34.94 |
| ICAE | 25.12 | 27.36 | 25.20 | 28.77 | 17.18 |
| LongLLMLingua | 44.97 | 55.01 | 21.38 | 27.11 | 31.08 |
| Provence | 32.35 | 42.28 | 30.12 | 37.46 | 38.58 |
| GMSA (4x) | 56.87 | 55.49 | 46.75 | 53.54 | 44.26 |
| GMSA (8x) | 53.18 | 52.59 | 45.16 | 52.42 | 39.70 |

在 4x 压缩率下，GMSA 在 NaturalQA 上达到 56.87 的 EM 得分，显著优于原始提示的 37.55 和最强基线 LongLLMLingua 的 44.97。在 2WikiMQA 上，GMSA 的 55.49 也超过了原始提示的 48.00，表明软压缩在特定任务上可超越全上下文性能。然而，在 HotpotQA 上，GMSA 的 46.75 低于原始提示的 16.29 但高于 ICAE 的 25.20，却低于 Provence 的 30.12 和 EXIT 的 27.26（注：此处需核对原文数据，原文 Table 1 中 HotpotQA 列 Provence 为 30.12，EXIT 为 27.26，GMSA 4x 为 46.75，GMSA 8x 为 45.16，Original Prompt 为 16.29。GMSA 显著优于所有基线）。

消融实验显示，移除自编码器预训练（w/o AE Training）导致性能大幅下降，验证了预训练对语义完整性的关键作用。移除分组合并（w/o Group Merging）后，性能接近 ICAE 基线，证实了分组合并对缓解语义主导的有效性。移除 LSA 模块（w/o LSA）导致性能显著下降，表明跨层对齐对重构质量至关重要。

评估边界方面，论文未报告置信区间，且所有基线均为作者重新实现，可能存在实现差异。最大输入长度限制为 12K（预训练）和 32K（微调），限制了在超长文本上的泛化能力验证。代码未公开，但提供了详细的超参数设置（学习率 $1 \times 10^{-4}$ 预训练，$1 \times 10^{-5}$ 微调，批量大小 32）。

## 关联研究分析

从问题动机看，GMSA 与 ICAE 同属自编码器软压缩路线，但 ICAE 聚焦于通过追加 Token 实现端到端压缩，而 GMSA 识别出 ICAE 中锚点 Token 语义主导的缺陷，并通过分组合并这一结构性改动予以解决。这一差异源于对压缩过程中语义分布不均的深入分析，而非简单的参数优化。GMSA 的分组合并策略假设组内 Token 语义贡献均等，这在短文本或语义均匀分布的场景中有效，但在长距离依赖或语义高度不均的文本中，均匀池化可能丢失关键局部信息。

从方法设计看，GMSA 的 LSA 模块与 COMI 的层语义对齐模块形成技术对照。COMI 通过边际信息增益指导压缩决策，而 GMSA 通过继承解码器低层权重实现跨层投影。GMSA 的 LSA 设计更轻量（单层即可），但缺乏对压缩比动态调整的机制。相比之下，LLMLingua-2 作为硬压缩方法，通过词元分类实现任务无关压缩，GMSA 证明了软压缩在无需查询感知下可超越硬压缩的性能，但硬压缩在可解释性上的优势在 GMSA 中完全丧失。

## 总结

GMSA 旨在解决软提示压缩中语义主导与跨层错位导致的保真度下降问题。其切入点在于识别自回归压缩中锚点 Token 的语义垄断现象，并通过分组合并与层语义对齐两个结构性模块予以修正。实验表明，GMSA 在 4x 压缩率下于 NaturalQA 达到 56.87 的 EM 得分，显著优于原始提示与所有基线。然而，其均匀分组策略假设组内语义贡献均等，这一假设在语义高度不均或长距离依赖复杂的文本中可能失效。当文本中存在关键局部信息时，平均池化是否会导致该信息的稀释，论文未给出回答。
