# ACL2026最新论文 ｜Value of Information: A Framework for Human–Agent Communication ｜信息价值驱动的智能体澄清决策

研究机构：英国剑桥大学、美国麻省理工学院

作者：Yijiang River Dong、Tiancheng Hu、Zheng Hui 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_3f8b71c1cd1d)

> 导读 大语言模型智能体在部署时面临用户指令模糊与行动成本之间的权衡，现有方法依赖脆弱的置信度阈值或固定轮次策略，无法动态适应任务风险与沟通成本。本文切入点在于将“是否提问”形式化为决策理论中的信息价值计算，通过推理时评估预期效用增益与认知负荷的净收益来指导行动。该方法无需训练，通过模拟用户响应更新信念分布，实现了跨任务的无参自适应。其价值在于提供了比启发式更稳健的通信策略，但其在对抗性多智能体环境中的鲁棒性尚未验证。

## 研究背景

当智能体面对“预订去伦敦的航班”这类模糊指令时，它必须决定是立即执行还是打断用户询问预算与偏好。这一决策涉及两个核心概念：一是潜在状态 $\theta$，即用户不可直接观测的真实意图；二是信息价值 (Value of Information, VoI)，即获取新信息后预期效用提升与当前行动效用之差。若仅凭模型内部置信度判断，往往忽略不同任务（如医疗诊断与动物猜测）的风险差异，导致在高风险场景下过早行动或在低风险场景下过度提问。

现有主流路线分为两类：一类是固定轮次策略，预设提问数量，无法适应查询歧义程度的变化；另一类是自适应提示或置信度阈值方法，依赖模型自我评估或手动调参的阈值 $\tau$。这些方法的瓶颈在于缺乏对下游任务后果的显式推理，阈值选择对任务与成本结构高度敏感，难以泛化。本文的切入点是将通信视为理性行动，引入决策理论框架，显式权衡信息增益与用户认知负荷，从而解决静态决策无法适应动态歧义的问题。

## 核心方法

### 决策理论参照系

本文问题属于不完全信息下的序贯决策。标准流程通常假设状态已知或可通过固定概率模型更新，但本文的关键差异在于：状态 $\theta$ 是隐变量，且更新过程依赖大语言模型 (LLM) 的语义模拟而非解析似然函数。传统贝叶斯更新要求固定的似然函数，而本文利用 LLM 预测用户响应概率，将语义理解嵌入信念更新过程。

### 信念估计与效用计算

设计动机在于解决 LLM 无法直接输出精确概率分布的问题。本文通过提示工程让 LLM 显式量化不确定性，输出潜在意图集合 $\Theta$ 上的信念分布 $b(\theta)$。给定信念，行动 $a$ 的预期效用 (Expected Utility, EU) 定义为：

$$ EU(a | b) = \sum_{\theta \in \Theta} b(\theta)U(\theta, a) $$

该公式物理含义为：在当前认知状态下，执行行动 $a$ 的平均收益。智能体若立即行动，将选择最大化 EU 的行动 $a^*$，其价值为 $V(b) = \max_{a \in A} EU(a | b)$。这一设计使得智能体能基于语义内容动态调整置信度，而非依赖静态的置信度分数。

### 信息价值驱动的澄清策略

设计动机在于克服置信度阈值方法对下游任务风险盲视的缺陷。本文引入 VoI 作为决策准则，计算提问 $q$ 的净收益：

$$ \text{NetVoI}(q) = \left( \sum_{y \in Y} p(y | q, b) V(b_y) \right) - V(b) - c $$

其中 $b_y$ 是假设收到回答 $y$ 后的后验信念，$c$ 为单次沟通成本。该公式含义为：提问带来的预期效用提升减去当前行动效用，再扣除沟通成本。若 $\max_q \text{NetVoI}(q) \le 0$，智能体终止对话并执行最优行动。此机制无需手动调参，自动平衡信息获取与用户负担，解决了固定轮次策略在成本变化时失效的问题。

## 实验评估

实验在混合风险20问、医疗诊断、航班推荐及模糊WebShop四个任务上进行，对比无提问、固定轮次、自适应提示及置信度阈值基线。基线覆盖了非自适应与启发式自适应路线，但缺失强化学习 (RL) 或博弈论基线，因本文聚焦推理时方法。在混合20问任务中，通信成本 $c=0.01$ 时，VoI 效用达 14.14，显著优于最佳调参的置信度阈值基线（11.49，$\tau=0.90$）。

| 任务 | 成本 c | 最佳基线效用 | VoI 效用 | 提升幅度 |
| :--- | :--- | :--- | :--- | :--- |
| Mixed 20Q | 0.01 | 11.49 | 14.14 | 2.65 |
| Mixed 20Q | 0.05 | 6.88 | 7.72 | 0.84 |
| Mixed 20Q | 0.10 | 2.28 | 1.38 | -0.90 |
| Mixed 20Q | 0.20 | -4.60 | -0.96 | 3.64 |

在 Gemini-2.5-Flash 上的成本扫描显示，VoI 在 18/20 条件下匹配或超越最佳网格搜索基线。高成本设置下（$c=0.20$），VoI 效用 -0.96 优于最佳基线 -4.60，表明其在避免无效沟通方面具有优势。然而，在 $c=0.10$ 时，VoI 效用 1.38 低于最佳基线 2.28，显示其在中等成本下的近似误差可能导致次优决策。

评估边界方面，实验未报告置信区间，数值比较需谨慎。代码已开源，但 LLM 模拟用户响应的计算开销未量化，可能影响实时部署。此外，任务均为单用户场景，未验证 VoI 在多智能体对抗环境中的有效性。

## 关联研究分析

从问题动机看，本文与 BEDA (Li et al., 2025) 均基于信念估计指导行为，但 BEDA 面向谈判对手建模，旨在最大化剩余价值，而本文面向单用户意图消歧，旨在最小化认知负荷。差异根源在于任务特性：谈判涉及多方博弈与剩余分配，需考虑对手策略；本文仅处理单用户，无需建模对手反应。BEDA 的置信度更新依赖对话历史中的显式信号，而本文依赖 LLM 模拟的隐式响应，前者在信号明确时更精确，后者在信号模糊时更具泛化性。

从方法设计看，本文与 Reasonably Reasoning Agents (Kang, 2026) 均强调理性决策，但后者基于贝叶斯学习理论分析零样本下避免博弈论失败的收敛性，聚焦博弈均衡；本文聚焦信息获取成本，引入显式通信成本 $c$。差异在于：Reasonably Reasoning Agents 假设对手策略已知或可推断，而本文假设用户响应需通过 LLM 模拟。若用户响应具有对抗性（如故意误导），本文的 VoI 计算可能因模拟误差而失效，而 Reasonably Reasoning Agents 的均衡分析可能更鲁棒。

## 总结

本文解决的核心矛盾是 LLM 智能体在模糊指令下如何平衡行动风险与沟通成本。现有方法依赖脆弱的置信度阈值或固定轮次，无法动态适应任务风险，而本文通过推理时 VoI 计算，显式权衡信息增益与认知负荷，实现了无参自适应。实验证明，在混合20问任务中，VoI 效用 14.14 优于最佳基线 11.49，且在 18/20 条件下匹配或超越网格搜索基线。其边界在于：VoI 依赖 LLM 模拟用户响应，在中等成本下可能出现近似误差（如 $c=0.10$ 时效用低于基线），且未验证多智能体对抗场景。当用户响应具有对抗性或故意误导时，VoI 的模拟误差是否会导致智能体陷入次优决策，论文未给出回答。
