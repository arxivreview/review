# ACL2026最新论文 ｜Pub-LawBench: Public-Oriented Benchmarking for LegalAI ｜面向公众的法律大语言模型基准

研究机构：南开大学、新西兰奥克兰大学

作者：Qiaoyu Zheng、Zehan Ma、Yijing Zhang 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_62e108603537)

> 现有法律大语言模型（Legal Large Language Models, Legal LLMs）评测体系过度聚焦于专业律师的推理深度与法条引用准确性，导致模型输出对普通公众而言晦涩难懂且缺乏可操作性。本文指出，专业严谨性并不自动等同于公众实用性，现有基准无法量化模型在“直接、可执行、可理解”维度的表现。为此，作者构建了 Pub-LawBench，引入法律规范性、内容相关性与格式可用性三个公众导向评估维度，并基于言语行为理论重新定义任务分类。该基准揭示了当前模型在公众法律辅助场景下的系统性缺陷，但受限于单一法域数据与零样本设置，其结论的跨法域泛化能力尚存疑。

## 研究背景

当普通用户面对“暖气坏了能否拒付租金”这类具体生活困境时，他们需要的不是“建设性驱逐”或“安静享用权契约违约”等抽象法律概念，而是“发送书面整改通知”或“将租金存入托管账户”等具体行动指南。这种需求差异源于法律功能主义（Legal Functionalism）的核心主张：法律的价值在于其实际社会效果，而非抽象教条的连贯性。然而，现有评测体系多基于专业视角，将法律推理简化为从案件事实到判决结果的静态映射，忽视了公众用户在缺乏法律术语背景下的理解障碍与行动需求。

当前主流法律基准如 LegalBench 和 LawBench 主要评估模型的法条记忆、逻辑推理及专业文档生成能力，其指标侧重于准确率与语义一致性，却未考量输出的“行动可用性”。这种专业中心主义（Professional-centric）导致模型可能生成法理正确但公众无法执行的冗长文本，甚至因引用已废止法条而产生误导性建议。Pub-LawBench 的切入点在于将评估焦点从“抽象推理深度”转向“实际效用”，通过引入公众导向指标，填补了现有基准在评估非专业用户法律辅助能力上的空白。

## 核心方法

### 任务分类法重构

现有法律基准通常将任务划分为分类、抽取与生成，但未区分用户意图。Pub-LawBench 基于言语行为理论（Speech Act Theory），将公众法律需求重构为两类：即时问答（Instant QA）与法律文本生成（Legal Gen）。即时问答针对非正式、情感化的生活咨询，要求模型提供直接、简洁的行动建议；法律文本生成则针对具有法律后果的文档起草，要求输出符合特定体裁（Genre）的规范性结构。这一分类法解决了现有基准将公众咨询与专业诉讼文件混同评估的问题，明确了不同场景下的输出预期。

### 公众导向评估指标

为量化“实用性”，本文设计了三个维度的自动化评估指标，替代单一的准确率或 BERTScore。其中，内容相关性通过关键点覆盖率（KeyCover）衡量，其计算逻辑为从参考文本提取原子关键点集合 $K = \{k_1, \dots, k_n\}$，并验证其在生成文本 $G$ 中的语义蕴含：

$$ S_{Key} = \frac{1}{n} \sum_{i=1}^{n} I(k_i \in G) $$

该公式通过 GPT-4o 执行“提取-匹配”范式，确保模型未遗漏关键法律事实。法律规范性（Legal Normativity）则聚合法条引用准确性、逻辑一致性与术语专业性，权重比为 2:2:1。其中法条引用得分定义为有效性与适用性的乘积：

$$ S_{Citation} = Validity \times Applicability $$

有效性通过严格数据库匹配验证法条存在性，适用性由 GPT-4o 判断法条与上下文的关联。这一设计直接针对 LLM 常见的“幻觉引用”问题，即模型生成看似合理但实际不存在或已废止的法条，通过双重验证机制显著降低了此类错误的漏检率。

## 实验评估

实验在 17 个代表性 LLM 上进行，涵盖商业模型（如 DeepSeek-V3, Gemini 3）、开源模型（如 Qwen2.5, Llama 3.1）及法律专用模型（如 DISC-LawLLM, Chatlaw）。评估协议采用零样本与思维链（Chain-of-Thought, CoT）提示，排除检索增强生成（RAG）与智能体等复杂技术，以模拟普通用户的实际使用场景。基线覆盖较全面，但缺乏多智能体系统（MAS）等前沿架构的对比，可能低估了复杂推理框架在公众场景下的潜在表现。

| 模型类别 | 代表模型 | 平均准确率 (Avg.) | 关键发现 |
| :--- | :--- | :--- | :--- |
| 商业 LLM | DeepSeek-V3 | 71.8 | 在复杂推理任务中表现稳定，但部分子任务低于 60% |
| 商业 LLM | Gemini 3 | 70.0 | 在事实提取任务中得分较低（29.4），存在结构性缺陷 |
| 开源 LLM | Qwen2.5-7B | 45.7 | 整体表现低于 46，复杂任务接近随机水平 |
| 法律专用 LLM | DISC-LawLLM | 40.2 | 专业模型在公众场景下失效，未能对齐用户意图 |
| 法律专用 LLM | SaulLM-7B | 45.0 | 在判决生成任务中得分最高（89.7），显示跨语言泛化潜力 |

消融实验揭示了 CoT 提示的反直觉效应：在 CaseHOLD 等严格法律推理任务中，CoT 导致性能下降，引发“推理漂移”（Reasoning Drift），即模型在生成链条中偏离核心法律问题，产生看似合理但法理错误的论证。这与 NLP 领域普遍认知中 CoT 提升推理能力的共识相悖，表明未经法律后训练的通用模型在引入 CoT 时可能放大幻觉。此外，RAG 消融显示，引入 BM25 检索器后，DISC-LawLLM 性能提升 11.1%，但模型相对排名未变，证实零样本结论在 RAG 设置下仍具指示性。

评估边界方面，Pub-LawBench 主要依赖中文与英文数据，缺乏多法域覆盖，限制了结论的普适性。GPT-4o 作为自动评估者，其与人类专家评分的 Pearson 相关系数高达 0.94，验证了指标可靠性，但 GPT-4o 自身的法律偏见可能引入系统性偏差。代码与数据已开源，但超参数细节（如 GPT-4o 提示模板的具体措辞）未在正文中完全披露，可能影响复现精度。

## 关联研究分析

从问题动机看，Pub-LawBench 与 LegalBench 的核心差异在于用户画像的定义。LegalBench 假设用户为具备法律背景的专业人士，评估重点在于法条引用的精确性与逻辑链条的严密性；而 Pub-LawBench 假设用户为非专业公众，评估重点在于输出的可理解性与行动指导性。这一差异源于法律功能主义与形式主义的不同理论根基：前者强调法律的社会效果，后者强调教条的内部一致性。Pub-LawBench 的指标设计（如 KeyCover）直接服务于“行动可用性”，而 LegalBench 的指标（如准确率）服务于“专业正确性”。这种视角错位导致同一模型在两个基准上的表现可能截然不同，例如 DISC-LawLLM 在专业基准上表现尚可，但在 Pub-LawBench 上平均得分仅 40.2%，凸显了专业模型在公众场景下的适配失败。

从方法设计看，Pub-LawBench 与 LexRAG 等检索增强方法存在潜在互补性。LexRAG 通过结构化图谱检索提升法条引用的可靠性，而 Pub-LawBench 通过法律规范性指标量化引用准确性。然而，Pub-LawBench 在实验中排除了 RAG 设置，仅评估零样本性能，这可能导致其低估了 RAG 在缓解幻觉方面的作用。此外，Pub-LawBench 的 CoT 负面发现与 Unilaw-R1 等结合强化学习（RL）的方法形成对比：Unilaw-R1 通过 GRPO 优化推理轨迹，可能缓解 CoT 导致的推理漂移，但 Pub-LawBench 未评估此类 RL 增强模型，留下了“RL 是否能同时提升公众实用性与专业准确性”的疑问。

## 总结

Pub-LawBench 旨在解决法律 LLM 评估中“专业正确性”与“公众实用性”脱节的核心矛盾。其切入点在于引入基于言语行为理论的公众导向指标，通过 KeyCover 与法律规范性量化输出的行动可用性与法理可靠性。实验证明，商业模型在公众场景下仍面临复杂推理失效与 CoT 负面效应，而法律专用模型因缺乏用户意图对齐而表现不佳。该基准的边界在于其零样本设置与单一法域数据，未能评估 RAG 与 RL 等增强技术的协同效应。当引入 RAG 后，模型性能提升是否足以弥补公众导向指标的缺陷，以及 CoT 负面效应是否可通过法律后训练消除，论文未给出明确回答。
