# ACL2026最新论文 ｜IS-CoT: Breaking the Long-form Generation Collapse via Interleaved Structural Thinking ｜交错结构思维链

作者：Zechen Sun、Yuyang Sun、Zecheng Tang 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_c92513a2cb84)

> 长文本生成中，模型在目标长度超过2000词后出现严重的“长度崩溃”，即初始规划对后续内容的指导力急剧衰减，导致连贯性与长度遵循度双降。现有推理增强模型虽通过一次性思考提升短文本表现，但在长程生成中仍无法维持全局一致性，静态大纲的固有缺陷未被解决。本文提出交错结构思维链（IS-CoT），将规划、写作与反思递归嵌入生成过程，通过监督微调内化这一动态决策逻辑。该方法在8B参数规模下实现了超越更大模型的长文本生成性能，但其依赖特定训练分布的泛化边界尚存疑。

## 研究背景

长文本生成的核心困境在于，自回归模型在生成过程中对初始指令的遵循度随序列长度增加而指数级下降。这一现象被称为长度崩溃，其根源并非简单的计数错误，而是模型缺乏在长程上下文中持续对齐全局目标的能力。当生成任务从短摘要扩展至数千词的小说或报告时，模型往往在早期偏离主题或提前终止，导致内容质量与长度约束同时失效。

可控文本生成领域长期依赖外部干预，如提示工程或解码约束，来强制模型满足特定属性。然而，这些方法在长文本场景下暴露出根本局限：外部信号无法触及模型内部的认知缺陷，且随着序列增长，外部约束的效力迅速衰减。推理增强模型（如DeepSeek-R1）通过引入“思考”过程改善了逻辑任务表现，但其规划仍是一次性的静态行为。实验表明，即使是最强的推理模型，在目标长度超过2000词后，其长度遵循分数仍从高位骤降至15.07以下，证明静态规划无法支撑长程生成。

本文的切入点在于将规划从“前置动作”转变为“持续过程”。通过构建包含显式交错推理轨迹的数据集，并以此微调模型，IS-CoT旨在让模型内化一种动态的Plan-Write-Reflect循环。这种机制不依赖外部代理或额外的解码步骤，而是将结构合规性嵌入模型的生成逻辑中，从而在长程生成中维持全局一致性。

## 核心方法

### 方法参照系

本文问题属于长文本长度控制与结构合规的交叉领域。通用方法通常采用静态大纲（Static Outlining），即在生成前生成完整结构，再按序填充内容。本文的关键差异在于，静态大纲在长程中失效，因为模型无法在生成数千词后仍准确回忆并遵循初始计划，导致局部执行与全局目标脱节。

### 交错结构合成与启发式控制

静态大纲的失效源于规划与执行的时空分离。IS-CoT在生成流程中插入递归的局部规划与反思环节，通过启发式控制循环强制模型在每段内容生成后检查进度。具体而言，模型在生成`<content>`后，必须输出`<reflection>`，其中包含当前字数估算、进度比例及质量检查。若累积长度低于目标，系统强制生成`<step_plan>`以规划下一段；若满足约束，则输出`<FINISHED>`终止。这一机制通过显式的进度反馈，将全局长度约束分解为局部可执行的子目标，解决了静态规划在长程中指导力衰减的问题。

$$
L = -\sum_{t=1}^{T} \log P(x_t | x_{<t}, I)
$$

该损失函数在标准自回归负对数似然基础上，强制模型学习包含`<global_plan>`、`<step_plan>`、`<content>`和`<reflection>`的完整序列。这意味着规划与反思不再是可选的辅助任务，而是生成过程的核心组成部分，模型必须学会在每一步中动态调整策略以维持全局一致性。

### 多教师蒸馏与数据构建

单一教师模型生成的轨迹可能包含特定偏差，导致学生模型过拟合。IS-CoT采用DeepSeek-V3.2与Qwen3-235B-A22B作为双教师，通过多教师蒸馏生成多样化的交错推理轨迹。数据构建分为三阶段：指令精炼（为无约束提示分配目标长度）、交错结构合成（通过启发式循环生成轨迹）、质量过滤（仅保留长度遵循分数$S_l > 90$的样本）。最终形成约5000个高质量样本，确保模型习得的动态规划逻辑具有鲁棒性，而非仅模仿单一教师的写作风格。

## 实验评估

IS-Writer-8B在LongBench-Write和WritingBench上均取得领先成绩。在LongBench-Write上，其平均分为88.25，超越Gemini-2.5-Flash 4.58分，DeepSeek-V3.2 3.08分。在WritingBench上，平均分为8.60，与DeepSeek-V3.2持平。基线覆盖专有模型（GPT-4o）、开源大模型（DeepSeek-V3.2）及写作增强模型（LongWriter-8B），但缺失LARFT、DcLM等最新长度控制专用方法，限制了与内部认知对齐路线的直接对比。

| 模型 | LongBench-Write Avg | WritingBench Avg |
| :--- | :--- | :--- |
| IS-Writer-8B | 88.25 | 8.60 |
| Gemini-2.5-Flash | 83.67 | 7.35 |
| DeepSeek-V3.2 | 85.17 | 8.60 |
| Qwen3-8B | 83.52 | - |

消融实验揭示了交错规划与反思模块的关键作用。移除反思模块后，平均分数从88.25降至85.97；进一步移除交错规划，分数降至84.07。这表明全局规划提供基础方向，但局部规划与动态反思的组合是维持长程生成质量的核心。在[4k, 20k)超长度区间，IS-Writer-8B平均分为85.46，比基线Qwen3-8B高19.44分，验证了该方法在极端长度下的鲁棒性。

| 变体 | LongBench-Write Avg | [4k, 20k) Avg |
| :--- | :--- | :--- |
| IS-Writer-8B | 88.25 | 85.46 |
| w/o Reflection | 85.97 | 81.80 |
| w/o Interleaved | 84.07 | 84.15 |

评估协议采用LLM-as-Judge计算质量分数，并使用分段线性函数计算长度遵循分数$S_l$。该函数在精确匹配时得100分，在$l/3$和$4l$处线性衰减至0。实验使用64块NVIDIA H800 GPU，上下文窗口扩展至32,768 tokens，训练5个epoch。代码未公开，且缺乏与LARFT等RL方法的直接对比，限制了方法泛化性的验证。

## 关联研究分析

从方法设计看，IS-CoT与DcLM形成鲜明对比。DcLM通过动态长度标记在推理时插入显式长度信息，属于外部干预，无需重训练但控制深度有限。IS-CoT则通过SFT将规划逻辑内化，属于内部认知对齐，训练成本高但能从根本上修复模型对长程依赖的理解。两者的差异源于对“长度崩溃”成因的不同假设：DcLM假设模型缺乏实时长度感知，IS-CoT假设模型缺乏持续的全局对齐机制。IS-CoT在[4k, 20k)区间的显著优势表明，内部对齐在极端长度下可能比外部标记更有效，但这也引发了对训练分布外泛化能力的疑问。

从问题动机看，IS-CoT与LARFT同属内部对齐路线，但技术路径不同。LARFT使用强化学习优化长度导向奖励，直接修复模型的长度认知缺陷；IS-CoT使用监督微调学习交错推理轨迹，通过过程监督间接提升长度遵循度。LARFT的训练成本更高，但可能更直接地解决认知缺陷；IS-CoT依赖高质量数据构建，其效果受限于教师模型的能力。IS-Writer-8B超越教师模型（Qwen3-235B）的现象表明，动态规划逻辑的显式化可能比单纯的知识规模更重要，但这一结论是否在未见过的长度分布上成立，论文未给出回答。

## 总结

本文针对长文本生成中静态规划失效导致的长度崩溃问题，提出交错结构思维链（IS-CoT），通过递归的Plan-Write-Reflect循环维持全局一致性。IS-Writer-8B在LongBench-Write上取得88.25的平均分，超越Gemini-2.5-Flash 4.58分，证明小模型通过内化动态推理逻辑可超越大模型。然而，实验仅在LongBench-Write和WritingBench上进行，缺乏与LARFT等RL方法的直接对比，且训练数据仅包含约5000个样本，限制了方法在未见长度分布上的泛化验证。当目标长度超出训练集分布范围时，IS-CoT的交错规划机制是否仍能维持长度遵循度，论文未给出回答。
