# ACL2026最新论文 ｜Spark: Strategic Policy-Aware Exploration via Dynamic Branching for Long-Horizon Agentic Learning ｜策略感知动态分支探索

研究机构：清华大学、北京大学

作者：Jinyang Wu、Shuo Yang、Changpeng Yang 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.20209)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.20209)

> 长程智能体任务中，高质量轨迹的稀缺性导致强化学习（RL）训练效率低下，现有方法通过扩大采样规模或均匀分配计算资源来缓解，但忽视了决策点价值差异，造成资源浪费。SPARK 框架利用模型内在的 `<explore>` 信号，在关键状态触发动态分支，实现计算预算的精准分配。该方法在 ALFWorld 和 ScienceWorld 上显著提升了样本效率与泛化能力，但其对冷启动监督微调（SFT）的依赖及 `<explore>` 信号的泛化边界尚存疑。

## 研究背景

长程智能体任务可形式化为部分可观测马尔可夫决策过程（POMDP），智能体在稀疏奖励下需执行多步动作以达成目标。由于状态空间庞大且单步错误会引发长序列偏差，成功轨迹在资源受限条件下极为稀缺。为获取有效训练信号，主流路线倾向于扩大 Rollout 规模或引入搜索机制，如 Tree-GRPO 通过静态树搜索扩展轨迹空间，GiGPO 采用均匀探索策略。然而，这些方法将计算预算均匀分配至所有时间步，导致大量资源消耗在“开门”等常规动作上，而“选择替代食材”等关键决策点探索不足，造成样本质量低下与训练不稳定。

SPARK 的切入点在于识别并利用智能体内在的决策不确定性信号。不同于依赖人工启发式或固定概率的分支策略，SPARK 主张由策略模型自主判断何时需要额外探索。这一设计旨在解决均匀探索在长程任务中“盲目覆盖”而非“精准打击”的核心缺陷，通过动态调整探索拓扑，在固定预算下最大化轨迹信息量。

## 核心方法

### 方法参照系

SPARK 基于 GRPO 框架，其标准流程为线性独立采样 $N$ 条轨迹，通过组内相对优势估计更新策略。本文的关键差异在于将线性采样替换为树状动态分支，且分支触发机制由策略模型内在信号驱动，而非外部预设。

### 动态分支探索机制

在标准 GRPO 中，每条轨迹独立生成，无法共享中间状态信息。SPARK 引入动态分支机制，在关键状态（SPARK points）触发多路径探索。设计动机在于解决均匀采样在关键决策点覆盖概率低的问题。当智能体在推理轨迹 $z_t$ 中生成 `<explore>` 标签时，表明当前状态存在高认知不确定性，此时触发分支因子 $b_t = B$；否则 $b_t = 1$。分支因子受全局预算 $N$ 约束，实际分支数 $b_{t,eff}$ 通过以下公式动态调整：

$$ b_{t,eff} = \min\left(B, \left\lfloor \frac{N - N_{current}}{n_{active}} \right\rfloor \right) $$

其中 $N_{current}$ 为当前活跃叶节点数，$n_{active}$ 为活跃轨迹数。该公式确保在预算耗尽前停止分支，避免资源溢出。通过共享前缀，SPARK 在相同预算下生成更多高质量轨迹，提升了关键决策点的覆盖概率。

### 树状策略优化

动态分支生成的轨迹形成树状结构，SPARK 利用此结构进行策略更新。设计动机在于解决稀疏奖励下信用分配模糊的问题。共享前缀的轨迹构成可比组，通过组内相对优势估计实现细粒度信用分配。优势计算基于组内归一化：

$$ A_i = \frac{R_i - \mu_G}{\sigma_G + \epsilon} $$

其中 $R_i$ 为轨迹 $i$ 的终端奖励，$\mu_G$ 和 $\sigma_G$ 为组 $G$ 的均值与标准差。该机制无需修改 GRPO 的优化目标，仅改变数据生成拓扑，使得策略更新聚焦于关键决策点的差异，而非整个轨迹的噪声。

## 实验评估

实验在 ALFWorld、ScienceWorld 和 WebShop 三个长程智能体基准上进行，基线包括 GRPO、GiGPO、RLVMR 及闭源模型 GPT-4o 等。SPARK 在 ALFWorld L0 上达到 96.9% 成功率，较 GRPO 的 76.6% 提升 20.3 个百分点；在 ScienceWorld L2 上达到 49.2%，较 GiGPO 的 4.7% 提升 44.5 个百分点。

| 方法 | ALFWorld L0 | ScienceWorld L2 | WebShop Succ. |
| :--- | :--- | :--- | :--- |
| GRPO | 76.6 | 10.9 | 71.1 |
| GiGPO | 66.5 | 4.7 | 72.1 |
| SPARK | 96.9 | 49.2 | 88.8 |

消融实验显示，动态分支较固定概率分支在 ScienceWorld 上提升 24.2 个百分点，表明选择性分支对长程任务至关重要。初始根数 $M=4$ 时性能最优，$M=2$ 时因多样性不足导致早期收敛，$M=6$ 时因预算耗尽导致后期探索不足。

评估边界方面，SPARK 依赖 300 条轨迹的 SFT 冷启动以生成 `<explore>` 信号，未验证无 SFT 条件下的泛化能力。实验未报告计算效率指标，且 ScienceWorld L2 的高分可能受任务难度差异影响，与 ALFWorld 的对比需谨慎。

## 关联研究分析

从问题动机看，SPARK 与 Tree-GRPO 均利用树结构解决稀疏奖励问题，但 Tree-GRPO 侧重静态分支扩展，依赖人工预设的分支位置；SPARK 则通过策略内在信号动态决定分支时机，减少了对人工先验的依赖。这一差异源于 SPARK 认为智能体自身具备识别不确定性的能力，而 Tree-GRPO 假设关键状态可由外部规则定义。

从方法设计看，SPARK 与 GiGPO 同属 GRPO 变体，但 GiGPO 采用均匀探索，SPARK 引入预算约束下的动态分支。GiGPO 在 ScienceWorld L2 上仅 4.7% 成功率，表明均匀探索在复杂长程任务中失效；SPARK 的 49.2% 成功率验证了策略感知探索的有效性。然而，SPARK 对 SFT 冷启动的依赖可能限制其在开放域任务中的适用性，GiGPO 无需额外 SFT 即可运行，这一差异在数据稀缺场景下尤为关键。

## 总结

SPARK 旨在解决长程智能体任务中高质量轨迹稀缺导致的训练效率低下问题。现有方法如 GRPO 和 GiGPO 采用均匀探索，忽视了决策点价值差异，导致资源浪费。SPARK 通过策略内在的 `<explore>` 信号触发动态分支，在关键状态精准分配计算预算，实现了样本效率与泛化能力的提升。实验显示，SPARK 在 ALFWorld L0 上较 GRPO 提升 20.3 个百分点，在 ScienceWorld L2 上较 GiGPO 提升 44.5 个百分点。然而，SPARK 依赖 SFT 冷启动以生成 `<explore>` 信号，未验证无 SFT 条件下的泛化能力，且实验未报告计算效率指标。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
