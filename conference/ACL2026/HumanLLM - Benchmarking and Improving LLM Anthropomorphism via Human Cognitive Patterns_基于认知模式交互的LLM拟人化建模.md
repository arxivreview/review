# ACL2026最新论文 ｜HumanLLM: Benchmarking and Improving LLM Anthropomorphism via Human Cognitive Patterns ｜基于认知模式交互的LLM拟人化建模

研究机构：复旦大学、美国约翰斯·霍普金斯大学

作者：Xintao Wang、Jian Yang、Weiyuan Li 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.10198)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_e1e1db3c06c0)

> 现有角色扮演语言智能体（Role-Playing Language Agents, RPLAs）将人格视为孤立的标签-行为映射，无法捕捉多认知模式在特定情境下的动态交互，导致模型表现出“人格幻觉”——报告特定特质但行为不一致。本文提出HumanLLM框架，将心理学认知模式视为相互作用的因果力，通过构建包含244个模式与11,359个多角色场景的语料库进行监督微调，并设计双级清单评估个体模式保真度与多模式动态。该框架在心理模式保真度上显著优于同规模开源模型，但其评估依赖LLM裁判且存在规范性混淆，且未验证在长时程社会模拟中的因果有效性。

## 研究背景

当LLM被要求扮演特定角色时，其输出往往呈现为对单一特质的刻板复现，例如将“外向”简单映射为“健谈”。这种孤立标签映射忽略了人类行为的涌现性：一个外向者可能在聚光灯效应（Spotlight Effect）激活时变得沉默，一个自信者可能在从众压力（Conformity）下妥协。这种多模式交互的缺失导致模型在复杂情境中行为漂移，无法维持心理一致性。

角色扮演领域的主流路线包括基于提示的特质分配、基于角色数据的微调以及基于激活向量的神经操控。这些方法均将特质视为独立变量，未能建模特质间的约束与调制关系。同时，现有评估基准如CoSER和LifeChoice多关注表面行为结果或决策准确性，缺乏对底层认知过程的细粒度度量，导致评估指标与社会期望（Social Desirability）混淆，无法区分“模拟准确”与“行为亲社会”。HumanLLM的切入点在于将心理学文献中的认知模式结构化，通过合成多模式冲突场景迫使模型学习模式间的动态交互，并引入解耦心理定义与社会评价的评估机制。

## 核心方法

### 认知模式结构化与场景合成

参照系中，角色扮演数据构建通常依赖书籍对话或通用指令数据，缺乏心理学理论支撑。HumanLLM基于Lewin场论，将认知分解为100个人格特质（Person维度）和144个社会认知模式（Environment维度）。每个模式通过检索约50篇学术论文，由LLM合成包含定义、核心机制与现实表现的三元组结构。场景生成利用DIAMONDS模型确保情境多样性，每个场景包含2-6个角色及2-5个模式，模式间存在强化、冲突或条件交互关系。对话合成采用Claude Sonnet 4.5生成12-20轮多轮对话，每轮包含内心独白、物理动作与言语表达，确保模式在多维表达中自然嵌入。

### 双级清单评估机制

传统评估依赖单一标签判断（如“是否自信”），无法捕捉模式间的调制效应。HumanLLM设计双级清单以解决此局限：模式级清单（Pattern-Level Checklist）包含12-15个上下文无关的行为指标，直接源自模式定义，用于计算个体模式表达（Individual Pattern Expression, IPE）；场景级清单（Scenario-Level Checklist）包含2-6个情境特定指标，指定特定模式组合下的预期行为倾向，用于计算多模式动态（Multi-Pattern Dynamics, MPD）。评估采用GPT-5-mini作为裁判，使用三元评分（+1/0/-1），公式如下：

$$ IPE = \frac{1}{N} \sum_{i=1}^{N} \frac{1}{M_i} \sum_{j=1}^{M_i} s_{ij} $$

其中 $s_{ij}$ 为第 $i$ 个样本中第 $j$ 个模式级指标的得分，$M_i$ 为该样本的模式级指标数量。MPD计算逻辑类似，但基于场景级指标。该设计将模拟准确性与社会期望解耦，通过价值中立的指标避免LLM裁判因“亲社会”偏好而低估真实但负面的心理行为（如防御性归因）。

## 实验评估

实验在HumanLLM数据集及外部基准LifeChoice、CroSS-MR上进行，基线覆盖闭源模型（GPT-5, Claude Sonnet 4.5, Gemini 3 Pro）与开源模型（Qwen3系列, DeepSeek系列）。主实验结果显示，Gemini 3 Pro在IPE（41.3%）和MPD（85.1%）上均居首，HumanLLM-32B在IPE（32.8%）和MPD（73.6%）上超越所有同规模或更大规模的开源基线。值得注意的是，HumanLLM-8B在MPD上（70.3%）超越Qwen3-32B（65.8%），尽管参数量仅为后者的1/4，表明心理学导向的训练数据在捕捉多模式动态上比单纯扩大模型容量更有效。

| 模型 | IPE (%) | MPD (%) |
| :--- | :--- | :--- |
| Gemini 3 Pro | 41.3±0.3 | 85.1±0.4 |
| Claude Sonnet 4.5 | 34.8±0.3 | 79.5±0.4 |
| Qwen3-235B | 34.3±0.5 | 72.5±0.4 |
| HumanLLM-32B | 32.8±0.3 | 73.6±0.4 |
| HumanLLM-8B | 25.7±0.4 | 70.3±0.6 |
| Qwen3-32B | 26.0±0.4 | 65.8±0.7 |

消融实验揭示了通用数据的负迁移效应：仅使用OpenThoughts和CoSER训练的Qwen3-8B在IPE上从18.6%降至9.1%（-51%），MPD从54.4%降至31.3%（-42%）。这表明通用指令跟随数据强化了“有帮助的助手”行为，抑制了模型表达认知偏差或复杂情绪的能力。相比之下，HumanLLM-8B在IPE上提升7.1个百分点（+38%），MPD提升15.9个百分点（+29%），验证了心理学结构化数据对认知模式表达的必要性。

评估协议依赖GPT-5-mini作为裁判，虽通过三次独立运行控制方差（标准差<2.1%），但LLM裁判可能存在系统性偏差。人类验证研究显示，整体指标（如CoSER的拟人化）与人类专家判断相关性弱（r=0.43）且存在显著偏差（∆=-30.8），而本文的双级清单指标与人类判断高度对齐（IPE: r=0.90, ∆=-0.6），证实了清单设计在解耦规范性混淆上的有效性。代码与数据已公开，但超参数细节仅在附录中提供，且未报告训练计算成本。

## 关联研究分析

从问题动机看，HumanLLM与SimBench和OmniBehavior存在根本差异。SimBench聚焦于群体级分布保真度，通过聚合数据评估统计距离，旨在解决隐私与标准化问题；OmniBehavior强调长时程跨场景行为轨迹，挑战模型的记忆与因果推理能力。HumanLLM则聚焦于微观认知过程的保真度，通过多模式交互场景评估心理机制的涌现性。这种差异源于任务目标的不同：SimBench和OmniBehavior关注“行为是否像人”，HumanLLM关注“行为是否由正确的心理过程生成”。HumanLLM的IPE/MPD指标可视为SimBench分布匹配在认知层面的细化，但缺乏对长时程一致性的评估，且未验证在因果推断中的有效性。

从方法设计看，HumanLLM与CoSER和Generative Agents形成互补。CoSER使用书籍对话进行“给定情境”训练，数据源为文学文本，缺乏心理学理论支撑；Generative Agents通过记忆流与反思机制模拟长期社会互动，但聚焦于宏观社会动态而非微观认知模式。HumanLLM借鉴CoSER的情境构建思路，但将数据源替换为心理学文献合成，确保模式的理论严谨性；同时继承Generative Agents的多角色交互思想，但限制在静态对话中，未引入记忆与规划模块。这种设计选择使得HumanLLM在认知保真度上优于CoSER，但在长时程社会模拟能力上弱于Generative Agents。

## 总结

HumanLLM旨在解决角色扮演中孤立标签映射导致的人格幻觉问题，通过结构化心理学认知模式与多模式冲突场景，迫使模型学习模式间的动态交互。该框架在IPE和MPD指标上显著优于同规模开源模型，HumanLLM-8B在MPD上超越Qwen3-32B，证明了心理学导向数据的有效性。然而，其评估依赖LLM裁判且存在规范性混淆，且未验证在长时程社会模拟中的因果有效性。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
