# ACL2026最新论文 ｜Evaluating LLMs on Large-Scale Graph Property Estimation via Random Walks ｜基于随机游走统计的大规模图属性估计基准

研究机构：日本东京大学

作者：Sunil Kumar Maurya、Xin Liu

论文原文见 [arXiv](https://arxiv.org/abs/2605.01484)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.01484)

> 现有 LLM 图推理基准受限于上下文窗口，仅能处理 20-50 个节点的小图，无法评估模型在真实世界百万级节点图上的能力。本文切入点在于将任务从“全图精确算法执行”转变为“局部访问下的全局属性统计估计”，通过随机游走统计量替代全图编码，将提示长度压缩 559 倍。实验表明，推理型 LLM 在节点数估计上的中位相对误差可低于 20%，部分场景优于经典无偏采样基线，但其对复杂拓扑结构的捕捉能力仍存疑。

## 研究背景

当 LLM 面对大规模图数据时，直接编码全图边列表会迅速耗尽上下文窗口，导致模型无法维持全局结构一致性，进而产生边遗漏或幻觉。这一困境源于图结构的线性化失真：将二维拓扑映射为一维文本序列时，节点间的复杂连接关系被简化为孤立文本片段，使得 LLM 难以在长序列中追踪全局依赖。为缓解此问题，随机游走（Random Walk）作为一种局部采样机制被引入，它通过模拟节点间的随机跳转，仅获取局部邻域信息，从而在有限步数内捕捉图的全局统计特征，如度分布与连通性模式。

当前 LLM 图推理研究主要聚焦于小图上的算法执行任务，如最短路径查找或社区检测，这些任务假设全图可见且规模较小（通常不超过 50 节点）。然而，现实中的社交网络、Web 图等往往包含数百万节点，且仅能通过 API 局部访问，全图可见假设不再成立。现有基准如 NLGraph 和 GraphQA 未能覆盖这一“局部访问、全局估计”的场景，导致 LLM 在大规模图分析中的实际能力评估存在空白。本文针对这一缺口，提出 EstGraph 基准，旨在评估 LLM 仅基于随机游走统计量，对大规模图的节点数、边数、社区数及关键节点进行估计的能力。

## 核心方法

### 随机游走统计提示构建

传统图推理方法将全图边列表或邻接矩阵直接嵌入提示，这在大规模图上不可行。本文改用随机游走采样，将图结构转化为统计摘要。具体而言，对图执行简单随机游走（SRW）或 Metropolis-Hastings 游走（MH），记录访问节点的度、碰撞次数等统计量，而非原始边列表。这一设计动机在于规避上下文长度限制，同时保留足以推断全局属性的统计特征。提示模板包含游走序列的统计描述（如平均度、首次碰撞时间）及任务指令，使 LLM 基于这些统计量进行推理，而非直接解析拓扑结构。

### Chapman 估计器与 LLM 推理融合

节点数估计的核心公式基于 Chapman 估计器（修正的 Lincoln-Peterson 估计器）：

$$ \hat{N} = \frac{|S_1| \cdot |S_2|}{|C|} $$

其中 $S_1$ 和 $S_2$ 为两次独立无偏采样得到的节点集合，$|C|$ 为两集合的交集大小。该公式的物理含义是利用“生日悖论”原理，通过重复访问节点的频率推断总体规模。本文的创新在于将这一经典统计逻辑作为 LLM 的推理锚点：LLM 不直接计算公式，而是基于提示中的游走统计量（如碰撞次数、度分布），结合其内部图理论知识，推断 $\hat{N}$ 的合理范围。这种“统计锚点+语义推理”的模式，使 LLM 能够处理无偏采样难以实现的局部访问场景，同时保持估计的无偏性。

## 实验评估

实验在合成图（BA、ER、GRP，100-100k 节点）和 5 个 SNAP 真实图（最大 2.39M 节点）上进行，对比基线包括 Uniform Sampling、MH Sampling、Max-degree Walk 及 Return-time Estimation。LLM 测试对象为 gemini-2.5-pro、o3、sonnet-4 和 DeepSeek-V3.1。

| 方法 | BA (Small) Median | BA (Large) Median | ER (Small) Median | GRP (Large) Median |
| :--- | :--- | :--- | :--- | :--- |
| uniform† | 13.63 | 0.60 | 12.68 | 0.56 |
| o3 (mh)† | 17.60 | 13.08 | 7.59 | 3.09 |
| gemini-2.5-pro (mh)† | 20.44 | 20.03 | 20.55 | 36.64 |
| deepseek-v3.1 (srw)† | 20.23 | 26.97 | 18.41 | 11.83 |

在合成图上，o3 在 ER 和 GRP 图上表现最优，中位相对误差低至 7.59% 和 3.09%，优于 Uniform Sampling 基线。在真实图上，gemini-2.5-pro 表现最佳，但误差中位数仍高于 20%，且显著高于合成图结果，表明 LLM 在真实复杂拓扑上的泛化能力有限。

消融实验显示，MH 游走比 SRW 更稳定，但 SRW 在真实场景中更实用。o3 在 PageRank 估计上 Precision@20 达 81.00%，远超其他模型（gemini-2.5-pro 为 27.50%），表明推理型 LLM 在基于访问频率的节点重要性估计上具有优势。然而，在 Betweenness 和 Closeness 估计上，所有 LLM 表现均较差（o3 Precision@20 分别为 31.50% 和 35.00%），因为这些指标依赖最短路径计算，随机游走难以充分捕捉。

评估边界方面，本文未报告置信区间，且 LLM 估计值方差较大（如 o3 在 BA Large 上 Std 为 30.76），暗示结果稳定性不足。代码与数据集已开源，但提示模板对游走长度和 burn-in 期敏感，超参数选择可能影响估计精度。

## 关联研究分析

从问题动机看，本文与 GraphRAG 类方法（如 Youtu-GraphRAG）存在根本差异：后者依赖显式子图检索以支持多跳事实问答，强调逻辑链的完整性；本文则放弃全图结构，仅利用随机游走统计量进行全局属性估计，任务目标从“精确推理”转向“统计推断”。这一差异源于任务特性：多跳问答需要局部精确性，而大规模图估计只需全局统计特征。然而，随机游走统计量是否足以捕捉非均匀度分布图的复杂拓扑特征（如社区边界），论文未给出充分验证，这可能导致 LLM 在结构复杂图上的估计偏差。

从方法设计看，本文与 Node2Vec 等图嵌入方法共享随机游走采样策略，但目的不同：Node2Vec 生成节点嵌入用于下游任务，本文提取统计特征用于 LLM 提示。与 Chapman 估计器等经典统计方法相比，本文的创新在于将 LLM 作为推理引擎，利用其语义理解能力解释统计量，而非直接执行数学公式。这种融合使 LLM 能够处理无偏采样难以实现的局部访问场景，但代价是引入了 LLM 的幻觉风险，且估计精度受限于 LLM 对图理论知识的掌握程度。

## 总结

本文核心矛盾在于 LLM 上下文窗口限制与大规模图分析需求之间的冲突。切入点在于将任务重构为“局部访问下的全局统计估计”，利用随机游走统计量替代全图编码，使 LLM 能在有限提示长度内处理百万级节点图。方法上，通过 Chapman 估计器作为推理锚点，结合 LLM 语义推理，实现了节点数、边数等属性的估计。实验证明，推理型 LLM 在合成图上中位相对误差可低于 20%，部分场景优于经典基线，但在真实复杂图上误差显著上升，且对依赖最短路径的指标估计能力薄弱。本文边界在于随机游走统计量的信息完备性未充分验证，且 LLM 估计值的方差较大。当图结构呈现高度非均匀性（如多层社区结构）时，随机游走统计量是否仍能提供无偏的全局估计，论文未给出回答。
