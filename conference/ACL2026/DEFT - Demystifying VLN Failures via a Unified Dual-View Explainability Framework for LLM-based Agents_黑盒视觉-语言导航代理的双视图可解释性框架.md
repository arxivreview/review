# ACL2026最新论文 ｜DEFT: Demystifying VLN Failures via a Unified Dual-View Explainability Framework for LLM-based Agents ｜黑盒视觉-语言导航代理的双视图可解释性框架

作者：Yawen Wang、Yihan Dai、Jianming Chen 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f745f230bbe7)

> 视觉-语言导航（VLN）中基于大语言模型（LLM）的代理因内部逻辑不透明，导致导航失败时难以定位是时间步决策失误还是视觉特征误读。现有解释方法将时间关键性与特征显著性割裂处理，且无法应对黑盒代理的行为不稳定性。DEFT 通过共享潜空间的双头架构，联合建模“何时决策关键”与“何种视觉证据支撑决策”，利用集成代理策略在黑盒约束下恢复鲁棒的像素级归因。该框架在诊断精度上优于独立基线，但受限于离散图环境与轻量代理的表征能力，其解释保真度在连续动态场景中仍存疑。

## 研究背景

当 VLN 代理在复杂室内环境中执行导航时，LLM 作为中央规划器虽能利用世界知识处理长程指令，但其决策过程如同黑盒：一旦在关键时间步（如楼梯方向判断）出现语义误读，错误将不可逆地传播至终点。这种不透明性源于 LLM 的复杂推理链与多模态输入的非线性交互，使得仅观察最终轨迹无法区分是视觉感知错误还是逻辑推理偏差。为诊断此类问题，可解释性研究需同时回答两个维度：时间步关键性（Timestep Criticality），即哪些时刻的决策对最终成功率具有决定性影响；以及特征显著性（Feature Salience），即哪些视觉像素区域构成了代理选择特定动作的证据。

主流解释路线存在显著割裂：时间步分析多依赖强化学习（RL）中的奖励退化度量（如 StateMask），而特征归因则依赖梯度或注意力权重（如 Integrated Gradients, IG）。这种分离导致“对齐缺口”——解释视觉证据的方法可能无法对应到真正决定成败的时间步，且标准白盒技术无法直接应用于参数不可访问的商用 LLM（如 GPT-4）。此外，LLM 代理固有的行为不稳定性（Behavioral Instability）使得单次梯度归因极易受随机幻觉干扰，导致解释结果不可复现。DEFT 的切入点在于构建一个统一框架，通过共享潜空间强制时间步与特征解释的一致性，并引入集成代理策略以抵消黑盒代理的随机性噪声。

## 核心方法

### 双头共享潜空间架构

DEFT 将解释任务置于黑盒代理的代理模型（Surrogate）范式下，核心差异在于摒弃了独立分析时间或特征的模块化设计，转而采用共享骨干的双头结构。共享骨干采用 VLN-BERT 编码指令、全景观测与历史状态，生成联合表征 $h_t$。这一设计动机在于解决独立方法中视觉证据与时间关键性在表征空间上的错位问题，确保两个解释维度基于同一语义基础。

$$
h_t = \text{VLN-BERT}(s_{t-1}, I, O_t)
$$

该公式表明，$h_t$ 是代理模型对当前导航状态的统一编码，为后续两个头提供一致的输入基础。

### 反事实掩码与集成归因

Mask Head 通过反事实分析识别关键时间步。其设计动机是解决传统价值函数估计在 LLM 不稳定行为下的失效问题，直接通过掩码动作测量奖励退化来定义关键性。Mask Head 输出二元分布 $P_{crit}$，预测当前步是否关键。

$$
P_{crit} = \text{Softmax}(\text{FFN}_{mask}(h_t))
$$

此分布量化了当前时间步对导航成功的边际贡献，若掩码该步动作导致累计奖励显著下降，则判定为关键步。

Action Head 作为可微代理，通过集成策略恢复视觉证据。针对 LLM 行为不稳定性导致的单模型归因噪声，DEFT 训练 $K$ 个不同轨迹集上的代理模型，并采用集成 Integrated Gradients（EIG）聚合像素级归因。

$$
\text{EIG}(O_t) = \sum_{k=1}^{K} w_k \text{IG}^{(k)}(O_t)
$$

该公式通过加权平均多个代理的梯度归因，抑制了单个代理因拟合目标 LLM 随机行为而产生的虚假显著性，从而获得鲁棒的视觉证据定位。

## 实验评估

实验在 Matterport3D 模拟器上的 R2R 数据集进行，评估对象包括 NavGPT、MapGPT 和 NavGPT-2 三个 LLM 代理。基线覆盖时间步分析（StateMask, VB, GB）与特征归因（IG, SMDL, HSIC）两类主流方法，但未包含针对 VLN 特定语义结构的专用解释基线。

| 模型 | 指标 | SM | VB | GB | DEFT |
| :--- | :--- | :--- | :--- | :--- | :--- |
| NavGPT | RRD↑ | 3.65 | 3.97 | 3.79 | 4.13 |
| NavGPT | Fidelity↑ | -0.45 | 0.13 | -0.46 | 0.23 |
| MapGPT | RRD↑ | 1.01 | 1.16 | 1.06 | 1.28 |
| MapGPT | Fidelity↑ | -0.24 | 0.04 | -0.96 | 0.15 |
| NavGPT-2 | RRD↑ | 2.48 | 3.26 | 2.80 | 3.15 |
| NavGPT-2 | Fidelity↑ | -0.40 | 0.66 | -0.41 | 0.77 |

DEFT 在 Fidelity 指标上全面优于基线，尤其在 NavGPT-2 上达到 0.77，显著高于 VB 的 0.66，表明其时间步定位与代理实际行为影响的一致性更高。

| 模型 | 指标 | IG | SMDL | HSIC | DEFT |
| :--- | :--- | :--- | :--- | :--- | :--- |
| NavGPT | Ins↑ | 0.74 | 0.69 | - | 0.75 |
| NavGPT | µF↑ | -101.45 | -10.29 | - | 12.52 |
| MapGPT | Ins↑ | 0.67 | 0.69 | - | 0.70 |
| MapGPT | µF↑ | 23.52 | 30.00 | - | 69.20 |
| NavGPT-2 | Ins↑ | 0.76 | 0.76 | 0.74 | 0.78 |
| NavGPT-2 | µF↑ | -5.94 | 0.40 | -5.50 | 1.27 |

在特征归因方面，DEFT 的 µFidelity 均为正值，而梯度基线（IG）常出现负值，证实集成策略有效缓解了代理不稳定性带来的归因噪声。用户研究显示，DEFT 在故障诊断准确率上达到 64%，是基线（30%）的两倍以上。

评估边界受限于离散图环境，未验证连续空间（VLN-CE）下的解释有效性。代理模型采用 VLN-BERT 而非 LLM，存在表征鸿沟，可能无法捕捉 LLM 的高阶语义推理错误。代码已开源，但实验仅在单 GPU（TITAN RTX）上运行，未报告大规模 LLM 代理的计算开销。

## 关联研究分析

从问题动机看，DEFT 与 StateMask 的核心差异在于解释维度的统一性。StateMask 仅通过掩码策略评估时间步重要性，缺乏对视觉证据的归因，导致解释结果无法指导具体的感知错误修正。DEFT 通过共享潜空间将时间关键性与特征显著性绑定，解决了“知道何时出错但不知为何出错”的诊断盲区。这一差异源于任务特性：VLN 的失败往往是视觉-语言对齐错误，而非单纯的动作选择错误，因此必须联合建模两个维度。

从方法设计看，DEFT 与 MapGPT 等导航代理的关系是“被解释者”与“解释者”的分离。MapGPT 依赖拓扑记忆提升导航性能，但其内部逻辑复杂化加剧了不透明性；DEFT 则不修改代理架构，而是通过外部代理模型进行黑盒解释。这种分离设计避免了侵入式修改对代理性能的干扰，但引入了代理拟合误差。与基于 CoT 的解释方法相比，DEFT 的像素级归因提供了更细粒度的空间证据，弥补了文本 CoT 缺乏空间定位能力的缺陷。

## 总结

DEFT 旨在解决黑盒 LLM VLN 代理中时间步关键性与视觉特征归因的对齐缺口。现有方法因割裂处理两个维度且无法应对 LLM 行为不稳定性，导致解释结果不可靠。DEFT 通过共享潜空间的双头架构与集成代理策略，在黑盒约束下实现了鲁棒的双视图解释。实验表明，其在 Fidelity 指标上优于基线（NavGPT-2 达 0.77），用户诊断准确率翻倍（64% vs 30%）。然而，其依赖轻量 VLN-BERT 代理拟合 LLM 行为，在离散图环境中验证有效，但无法确认其能否捕捉 LLM 在连续动态环境中的高阶语义推理错误。当代理模型与目标 LLM 的表征差距扩大时，集成归因的保真度是否会显著下降，论文未给出回答。
