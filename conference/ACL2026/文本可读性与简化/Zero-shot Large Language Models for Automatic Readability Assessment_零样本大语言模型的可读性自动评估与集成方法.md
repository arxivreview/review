# ACL2026最新论文 ｜Zero-shot Large Language Models for Automatic Readability Assessment ｜零样本大语言模型的可读性自动评估与集成方法

研究机构：美国国立卫生研究院

作者：Riley Grossman、Yi Chen

论文原文见 [arXiv](https://arxiv.org/abs/2604.24470)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_709d5208fe36)

> 自动可读性评估（ARA）旨在量化文本难度以适配教育或医疗受众，但现有研究过度依赖计算浅层特征的传统公式，缺乏对上下文语义的捕捉。Trott and Rivière (2024) 虽证明闭源 LLM 在单一数据集上优于公式，但未验证开源模型在多语言、长文本及技术文本上的泛化能力，导致该方法难以落地。本文提出 LAURAE，通过改进零样本提示策略并集成 LLM 与公式分数，在 14 个数据集上实现了鲁棒的无监督评估。该方法在鲁棒性上具有显著价值，但其对 LLM 置信度校准的依赖及在部分特定数据集上的性能瓶颈仍存疑。

## 研究背景

当医疗或教育机构需要批量筛选文本难度时，传统可读性公式（如 Flesch-Kincaid）因仅依赖句长和多音节词数，无法捕捉复杂句法背后的认知负荷。这种浅层特征局限促使研究者转向基于预训练语言模型（PLM）的无监督方法，如 RSRS，它利用词意外性量化难度，但仍受限于模型对长距离依赖的建模能力。随着大语言模型（LLM）涌现，零样本提示成为新路径，但早期工作仅验证了闭源模型在单一英语数据集上的表现，未解决开源模型在非英语或技术文本上的稳定性问题。

ARA 领域长期面临“精度-成本”权衡：监督式 BERT 模型精度高但需大量标注数据，传统公式成本低但精度有限。Trott and Rivière (2024) 首次展示 GPT-4 零样本提示可超越公式，但其评估局限于单一数据集和闭源模型，导致研究者无法确认该方法是否泛化至医疗文本、非英语语言或免费开源模型。本文切入点在于系统评估 10 种开源 LLM 在 14 个多语言、多长度数据集上的表现，并针对 LLM 评分不稳定的问题，提出结合浅层公式特征的集成方法 LAURAE，以填补无监督 ARA 在鲁棒性上的空白。

## 核心方法

### 零样本提示基线

本文参照 Trott and Rivière (2024) 的零样本提示框架，但指出其仅使用任意尺度（1-9）且忽略输出概率分布的局限。关键差异在于，本文引入 CEFR 等级定义作为提示上下文，并采用期望值计算替代单一 token 采样，以解决 LLM 在评分边界上的随机性。

### 期望值评分机制

针对 LLM 生成评分时可能输出非数字 token 或概率分布尖锐的问题，本文提出基于输出 token 概率的期望值计算。设 LLM 在位置 $n$ 生成评分，其 logit 向量经 softmax 后得到概率分布 $p_n$。将 $p_n$ 按概率降序排列，取前 $k$ 个数值型 token 的概率 $r_{1m}$ 及其对应 token 值 $V_{r_{2m}}$，期望值评分 $s_{LLM}$ 计算为：

$$ s_{LLM} = \sum_{m=1}^{k-1} r_{1m} (V_{r_{2m}}) $$

该公式通过加权所有可能的数值输出，而非仅取最高概率 token，有效减少了因模型犹豫导致的评分偏差，尤其在短文本或模糊难度文本上提升了稳定性。

### LAURAE 集成框架

为解决 LLM 在缺乏上下文信息的短文本或特定领域文本上表现不佳的问题，本文提出 LAURAE，将 LLM 评分 $s_{LLM}$ 与可读性公式评分 $s_{rf}$ 进行加权集成。权重 $c$ 由 LLM 自报告的置信度（1-9 尺度）经期望值计算并归一化得到。最终评分公式为：

$$ s_{LAURAE} = c(s_{LLM} - \mu_{LLM})\sigma_{rf} + (1 - c)(s_{rf} - \mu_{rf})\sigma_{LLM} $$

其中 $\mu$ 和 $\sigma$ 为数据集级别的均值和标准差。该设计动机在于利用 LLM 的上下文理解能力处理复杂文本，同时借助公式的浅层特征补偿 LLM 在简单文本上的不足，置信度权重则动态平衡两者贡献，无需超参数调优。

## 实验评估

实验在 14 个数据集上进行，涵盖英语、法语、印地语、阿拉伯语、俄语和希腊语，文本长度从句子到文章不等。基线包括传统公式（FKGL, ARI, OSMAN, Lix, FRE）、PLM 方法 RSRS 以及零样本 LLM 基线 LLM-v-ns。本文方法在 13/14 数据集上优于 LLM-v-ns，且在 11/14 数据集上优于所有单一 LLM 或公式基线。

| 数据集 | 本文方法 (LAURAE) | 最佳基线 (LLM-v-ns/RSRS/公式) | 差异 |
| :--- | :--- | :--- | :--- |
| ReadMe (en) | 0.56 | 0.50 (FKGL) | +0.06 |
| MedReadMe | 0.56 | 0.50 (ARI) | +0.06 |
| Vikidia (fr) | 0.62 | 0.46 (Lix) | +0.16 |
| Greek History | 0.68 | 0.66 (Lix) | +0.02 |

*注：表中数值为 Pearson 相关系数或准确率，具体指标依数据集而定。*

消融实验显示，引入 CEFR 定义提示在 7 个 CEFR 数据集上平均提升 0.059 相关性，期望值评分在 12/14 数据集上带来显著提升，尤其在比较型数据集（如 Vikidia, Asset）上效果明显，因期望值减少了平局。LAURAE 集成相比单一 LLM 方法，在 10/14 数据集上进一步提升性能，证明浅层特征对 LLM 的补偿作用。

评估边界方面，本文未报告计算成本，但指出 LLM 推理延迟较高。代码与数据集已公开，但 LLM 置信度校准的鲁棒性未在不同模型架构间深入验证。在 Cambridge 数据集上，LAURAE 未超越 LLM-v-ns，表明集成并非在所有场景下均有效，可能源于该数据集文本特征与 LLM 训练分布的偏差。

## 关联研究分析

从问题动机看，本文与 Trott and Rivière (2024) 同属零样本 LLM 评估路线，但后者仅验证闭源模型在单一英语数据集上的潜力，而本文聚焦开源模型在多语言、多长度场景下的泛化性。这一差异源于实际部署需求：闭源模型 API 成本高且不可控，开源模型才是大规模 ARA 的可行选择。本文通过系统评估揭示了开源 LLM 在非英语数据集上的性能波动，并指出仅靠提示工程不足以解决所有问题，需结合浅层特征。

从方法设计看，LAURAE 与 RSRS (Martinc et al., 2021) 同属无监督 ARA，但 RSRS 依赖 PLM 的词意外性，本质仍是浅层统计特征的变体，而 LAURAE 显式集成 LLM 的上下文理解。与监督式 BERT 方法（如 Xia et al., 2016）相比，LAURAE 无需标注数据，但精度上限受限于 LLM 的零样本能力。本文未对比监督式方法，因无监督设定下无法获取标注数据，这限制了其与 SOTA 监督模型的直接比较。

## 总结

本文核心矛盾在于无监督 ARA 中 LLM 上下文理解能力与浅层公式计算效率的失衡。Trott and Rivière (2024) 证明了 LLM 的潜力但未解决泛化性，本文通过期望值评分和置信度加权集成，在 13/14 数据集上超越了单一 LLM 或公式基线，证明了混合特征的鲁棒性。然而，LAURAE 在 Cambridge 数据集上未超越基线，且 LLM 置信度校准的可靠性未在不同模型间充分验证。当文本长度极短或领域高度专业化时，LLM 的上下文优势是否会被公式的浅层特征完全抵消，论文未给出明确回答。
