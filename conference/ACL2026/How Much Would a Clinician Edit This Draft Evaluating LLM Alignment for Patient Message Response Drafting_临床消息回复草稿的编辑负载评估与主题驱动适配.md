> 患者门户消息回复草稿旨在通过LLM生成初稿以减轻医生异步沟通负担，但现有评估多依赖主观反馈或通用文本相似度指标，无法量化医生实际修改工作量。本文切入点在于将“对齐”具体化为“编辑负载”，提出双维度EditJudge框架与主题驱动DPO适配策略。其核心是通过主题分类作为中间层，约束模型在特定临床意图上的生成行为。该方法在本地小模型上实现了接近前沿商用模型的编辑效率，但个体医生偏好差异导致的性能天花板仍显著存在。

## 研究背景

当LLM生成的回复草稿与医生实际发送的回复存在偏差时，医生需执行删除冗余内容或补充缺失信息的操作，这一过程产生的认知负荷直接抵消了自动化带来的效率增益。这种偏差不仅源于事实错误，更源于风格、语气及临床决策逻辑的差异，即“个体化对齐”问题。传统BLEU或ROUGE指标无法捕捉这种语义层面的编辑需求，导致评估结果与临床实际效用脱节。

患者门户消息回复任务长期面临评估标准缺失与模型适配不足的双重困境。早期研究多采用0-shot前沿模型并依赖医生主观评分，缺乏可自动化的量化基准；部分工作尝试SFT微调，但忽略了医生在共情、问诊、评估等主题上的差异化偏好。本文针对这一空白，构建了基于专家标注的主题分类体系，并以此为基础设计评估框架与适配策略，旨在解决LLM草稿与个体医生回复之间的细粒度对齐问题。

## 核心方法

### 方法参照系

本文任务可归类于临床AI部署中的“人机协作评估与适配”路线。标准流程通常包含：生成草稿、基于参考回复计算相似度、通过微调或提示优化模型。本文的关键差异在于将“相似度”重构为“编辑操作量”，并引入主题分类作为生成与评估的共享语义空间，而非直接优化端到端文本匹配。

### 双维度编辑负载度量

针对传统相似度指标无法区分“内容缺失”与“风格差异”的失效，本文提出EditJudge框架，将评估解耦为内容级与主题级两个维度。内容级编辑F1通过细粒度判断LLM草稿中哪些句子需保留（Expected Match, EM）、哪些需删除（Expected Deletion, ED）以及哪些需添加（Expected Addition, EA），其核心公式为：

$$ \text{Edit-F1}_{content} = \frac{2 \cdot |EM|}{2 \cdot |EM| + |ED| + |EA|} $$

该公式物理含义为：在假设添加与删除成本相等的前提下，衡量草稿中无需修改的内容占比。主题级编辑F1则通过9类多标签分类器（8个临床主题+其他）对句子进行标注，计算主题预测的Micro-F1，捕捉更高层面的意图对齐。设计动机在于，内容级指标保障临床安全性（事实正确），主题级指标保障沟通有效性（意图匹配），二者互补以全面量化编辑负载。

### 主题驱动偏好优化

为解决SFT在捕捉医生个体风格上的局限，本文提出TADPOLE（Thematic Agentic Direct Preference Optimization for Learning Enhancement）。该方法利用主题分类器构建偏好对：对于同一患者消息，若LLM生成的草稿在特定主题（如“共情”）上得分高于参考回复，则标记为偏好样本；反之则为非偏好样本。DPO损失函数为：

$$ \mathcal{L}_{DPO} = -\mathbb{E}_{(x, y_w, y_l)} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)} \right) \right] $$

其中 $y_w$ 和 $y_l$ 分别为主题对齐度高与低的回复。这一设计将主题分类作为偏好信号的来源，使模型在优化过程中显式学习不同主题下的生成策略，从而比直接SFT更有效地捕捉医生在问诊、评估等特定场景下的风格偏好。

## 实验评估

实验在自建IPPM、SyPPM及SoCPPM数据集上进行，覆盖本地模型（Llama3-8B, Qwen3-8B, Aloe-8B）与商用模型（Gemini 2.5 Pro, Claude 4.5 Sonnet, GPT-OSS）。基线包括0-Shot、主题提示、RAG、SFT及TADPOLE。主实验结果显示，TADPOLE在SyPPM数据集上取得最高的内容级编辑F1（0.25），接近Gemini 2.5 Pro的主题提示结果（0.26），显著优于0-Shot模型（0.17）。

| 模型/策略 | SyPPM Content Edit-F1 | SyPPM Theme Edit-F1 |
| :--- | :--- | :--- |
| 0-Shot | 0.17 | 0.54 |
| Theme Prompt | 0.20 | 0.54 |
| RAG | 0.18 | 0.50 |
| SFT | 0.22 | 0.58 |
| TADPOLE | 0.25 | 0.62 |
| Gemini 2.5 Pro (Theme) | 0.26 | 0.64 |

消融分析表明，主题提示显著提升了主题级F1，但对内容级F1提升有限；RAG在主题对齐上效果不佳，可能因检索噪声干扰了风格一致性。TADPOLE在“共情”与“应急计划”主题上表现最佳，但在“治疗计划”主题上IAP（标注者间可预测性）仅为0.07，表明该主题存在极高的个体差异，模型难以通过通用适配达到高对齐度。

评估边界方面，EditJudge框架依赖微调的LLM作为裁判，其准确性受限于训练数据分布；数据集来自单一医院系统，可能限制泛化性。可复现性上，论文提供了HuggingFace数据集链接，但EditJudge模型的超参数与训练细节仅在附录中简要提及，缺乏完整的复现指南。

## 关联研究分析

从问题动机看，本文与Source Claim Framework均利用LLM-as-Judge进行细粒度评估，但前者聚焦于事实真伪（内在/外在幻觉），本文聚焦于编辑负载（风格/偏好对齐）。这一差异源于任务特性：SOAP笔记生成强调事实接地，而消息回复强调沟通效率与个体适配。Source Claim Framework无法捕捉医生在语气、详略上的偏好差异，而本文的主题分类体系恰好填补了这一空白。

从方法设计看，本文的TADPOLE与ExperienceWeaver均关注有限反馈下的模型改进，但ExperienceWeaver通过经验池与策略池实现多智能体修订，本文则通过主题分类构建偏好对。TADPOLE的优势在于将主题作为显式约束，使优化过程可解释且可控；其局限在于依赖主题分类器的准确性，若分类错误则偏好信号失真。相比之下，ExperienceWeaver更灵活但计算成本更高，且缺乏对临床主题结构的显式建模。

## 总结

本文核心矛盾在于LLM草稿与个体医生回复之间的风格与意图偏差，现有方法无法量化这一偏差并有效优化。本文通过EditJudge框架将“对齐”转化为可计算的编辑负载，并利用TADPOLE将主题分类作为偏好优化中间层，实现了本地小模型在特定主题上的高效适配。实验证明TADPOLE在SyPPM上达到0.25的内容级编辑F1，接近前沿商用模型，但“治疗计划”等主题的高个体差异（IAP 0.07）揭示了通用适配的天花板。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
