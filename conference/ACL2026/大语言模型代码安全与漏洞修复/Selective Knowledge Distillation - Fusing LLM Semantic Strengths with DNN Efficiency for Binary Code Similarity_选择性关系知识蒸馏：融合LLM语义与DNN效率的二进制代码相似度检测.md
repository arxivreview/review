# ACL2026最新论文 ｜Selective Knowledge Distillation: Fusing LLM Semantic Strengths with DNN Efficiency for Binary Code Similarity Detection ｜选择性关系知识蒸馏：融合LLM语义与DNN效率的二进制代码相似度检测

作者：Shize Zhou、Peiyu Liu、Lirong Fu 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f74da15362b2)

> 二进制代码相似度检测（BCSD）旨在无源码条件下比对函数功能，是漏洞追踪与恶意软件分析的基础。现有深度神经网络（DNN）方法依赖词法与控制流特征，对编译优化敏感且语义表征粗糙；大语言模型（LLM）虽能捕捉高层语义，但参数量大、推理延迟高，难以部署于大规模二进制分析流水线。BinSKD 提出一种选择性关系知识蒸馏框架，将 LLM 教师模型的关系拓扑结构迁移至 DNN 学生模型，同时通过筛选可靠样本与加权差异样本抑制噪声。该方法在保持 DNN 轻量级与低延迟优势的同时，显著提升了跨优化级别下的语义判别能力，但其效果高度依赖教师模型的质量与特定任务分布。

## 研究背景

当开发者面对数百万下游二进制函数以追踪上游漏洞时，若缺乏源码，传统静态分析工具因依赖词法模式与控制流结构，在编译器优化级别（如 O0 至 O3）变化时特征发生剧烈漂移，导致匹配失效。这种对底层语法特征的过度依赖，使得 DNN 模型难以捕捉程序的高层功能语义，如函数目的与逻辑意图，从而在跨版本、跨编译配置的场景下鲁棒性不足。为解决这一语义缺失问题，研究界引入了基于 LLM 的 BCSD 方法，利用自然语言监督信号提取稳定的高层语义嵌入。然而，LLM 模型参数量通常比 DNN 大两个数量级，推理耗时呈线性增长，在需要实时处理海量二进制数据的工业场景中成为不可接受的瓶颈。

BCSD 领域长期存在“语义精度”与“推理效率”的二元对立。主流 DNN 路线（如 HermesSim、SAFE）通过图神经网络或循环神经网络提取低层特征，虽具备毫秒级推理速度，但受限于特征粒度，在复杂优化场景下召回率显著下降。LLM 路线（如 CLAP）虽在语义稳定性上占优，但其高昂的计算成本限制了其在大规模漏洞搜索中的应用。现有尝试如直接拼接嵌入或对比学习对齐，因教师与学生模型嵌入空间存在巨大差异而失效。BinSKD 的切入点在于，不直接对齐个体嵌入向量，而是对齐样本间的关系结构，并针对 BCSD 任务中教师模型并非全知全能、正负样本极度不平衡的特性，设计了针对性的蒸馏策略，旨在以 DNN 的效率逼近 LLM 的语义精度。

## 核心方法

### 方法参照系

知识蒸馏（Knowledge Distillation, KD）通常通过最小化教师与学生模型输出分布的散度来迁移知识。在 BCSD 任务中，标准 KD 假设教师模型在所有样本上均优于学生，且直接对齐嵌入向量。本文的关键差异在于：BCSD 关注的是函数间的相似度关系而非单一函数属性，且教师模型在部分查询上表现劣于学生，直接对齐会引入错误噪声并破坏学生模型已习得的参数。

### 关系表征与选择性蒸馏

针对嵌入空间不一致问题，BinSKD 放弃个体嵌入对齐，转而构建关系矩阵。对于查询函数 $f_i$ 及其候选集，计算教师与学生模型嵌入间的成对余弦相似度，形成关系矩阵 $M_t$ 和 $M_s$，并进行 Z-score 标准化以消除空间尺度差异。设计动机在于，关系结构比绝对坐标更具跨模型可比性。为应对教师模型不可靠的问题，引入选择性蒸馏策略。仅当教师模型在查询 $i$ 上的平均倒数排名（MRR）高于学生模型时，才执行蒸馏。该条件形式化为：

$$
\text{MRR}_T(i) > \text{MRR}_S(i)
$$

其中 $\text{MRR}(i) = \frac{1}{|P_i|} \sum_{p \in P_i} \frac{1}{\text{rank}(i)(p)}$。这一机制确保仅迁移教师模型确实具备优势的高层语义知识，防止在教师模型表现较差的样本上向学生模型传播错误排序，从而保护学生模型在特定领域已建立的局部最优解。

### 差异加权采样与联合优化

在通过选择性蒸馏筛选出可靠查询后，面临正负样本极度不平衡导致的噪声干扰。传统 Focal Loss 仅基于样本自身置信度加权，无法捕捉学生与教师预测偏差。BinSKD 提出差异加权采样策略，对负样本 $j \notin P_i$ 赋予权重 $w_{ij}$，其值取决于教师与学生模型中该样本排名的倒数差：

$$
w_{ij} = \frac{1}{\text{rank}_T(i)(j)} - \frac{1}{\text{rank}_S(i)(j)}
$$

若 $j \in P_i$，则 $w_{ij}=1$。该公式物理含义为：若某负样本在学生模型中排名较高（易造成误报），但在教师模型中排名较低（教师认为其不相似），则二者排名差异大，权重高，从而强化学生模型对该“困难负样本”的区分能力。最终蒸馏损失 $L_{KD}$ 采用 Huber 损失计算加权后的关系矩阵差异，并与学生模型原始任务损失 $L_{task}$ 联合优化，确保在提升语义判别力的同时不牺牲基础功能。

## 实验评估

实验在 vmlinux 二进制数据集上进行，涵盖六种编译优化级别组合（O0-O3），池大小设为 8192。基线覆盖 DNN 路线的 HermesSim、SAFE、jTrans、BinaryAI 及 LLM 路线的 CLAP。缺失其他 LLM-based BCSD 方法（如 BinGPT）的对比，限制了跨 LLM 架构泛化性的评估。主实验结果显示，BinSKD 在所有 DNN 基线上均带来显著提升。

| 方法 | O0,O3 MRR | O0,O3 Recall@1 | O2,O3 MRR | O2,O3 Recall@1 |
| :--- | :--- | :--- | :--- | :--- |
| HermesSim | 0.559 | 0.489 | 0.810 | 0.767 |
| HermesSim + BinSKD | 0.691 | 0.633 | 0.815 | 0.771 |
| SAFE | 0.061 | 0.025 | 0.679 | 0.653 |
| SAFE + BinSKD | 0.121 | 0.066 | 0.814 | 0.787 |
| jTrans | 0.081 | 0.031 | 0.812 | 0.786 |
| jTrans + BinSKD | 0.360 | 0.243 | 0.822 | 0.794 |
| BinaryAI | 0.028 | 0.012 | 0.543 | 0.498 |
| BinaryAI + BinSKD | 0.061 | 0.024 | 0.629 | 0.597 |
| CLAP | 0.688 | 0.627 | 0.867 | 0.838 |

在困难设置（O0 vs O3）下，HermesSim 的 MRR 提升 23.6%，Recall@1 提升 29.4%；在简单设置（O2 vs O3）下，提升幅度较小（MRR 0.617%），表明基线性能越高，蒸馏边际收益越低。HermesSim+BinSKD 在 O2,O3 下的 Recall@1 达到 0.771，接近教师模型 CLAP 的 0.838，且推理速度为 CLAP 的 107 倍，参数量仅为 CLAP 的 1/290。

消融实验揭示了组件的必要性。直接应用关系知识蒸馏（RKD）导致 HermesSim MRR 从 0.716 暴跌至 0.069，证实了盲目蒸馏的危害。加入选择性蒸馏（SD）后 MRR 恢复至 0.707，加入差异加权采样（DwS）后 MRR 为 0.301，二者结合达到 0.795，超过基线 11.0%。相比之下，正则化策略（Focal Loss）仅提升 2.8%。教师质量实验表明，向 CLAP 嵌入注入高斯噪声（$\alpha=0.05$）后，学生模型 MRR 从 0.795 降至 0.751，降幅 5.53%，证实学生性能与教师语义质量正相关。

评估边界方面，论文未报告置信区间，0.750 vs 0.744 的微小优势统计显著性存疑。超参数 $\lambda_{KD}$ 通过网格搜索确定，但未提供搜索范围与收敛曲线。代码已开源，但训练数据泄露风险通过选用 CLAP 公开数据集缓解，未涉及其他 LLM 教师的数据隔离验证。

## 关联研究分析

从问题动机看，BinSKD 与检索增强生成（RAG）路线形成鲜明对比。RAG 方法（如 RESCUE）依赖外部知识库实时检索以补充 LLM 的安全或语义知识，其优势在于零训练成本与知识更新灵活性，但引入了检索延迟与依赖外部库的脆弱性。BinSKD 则通过离线蒸馏将 LLM 语义内化至 DNN 参数中，消除了推理时的外部依赖，实现了毫秒级响应。这一差异源于任务特性：BCSD 需处理百万级函数对，实时检索不可行，而安全代码生成可容忍较高延迟。BinSKD 的选择性蒸馏策略解决了 RAG 中“检索结果可能不相关”的噪声问题，通过 MRR 筛选确保仅迁移高置信度知识。

从方法设计看，BinSKD 与标准知识蒸馏（如 RKD）的核心差异在于对“教师可靠性”的处理。RKD 假设教师全局最优，直接对齐关系矩阵，但在 BCSD 中，教师模型（CLAP）在 47.3% 的查询上表现劣于学生，直接对齐导致学生模型性能崩溃（MRR 0.069）。BinSKD 引入 MRR 阈值筛选，本质上是一种“教师置信度门控”机制。这与安全对齐中的“拒绝回答”策略异曲同工，但应用于蒸馏过程。此外，差异加权采样针对 BCSD 正负样本不平衡特性，区别于通用 KD 中的均匀采样或基于置信度的 Focal Loss。这种设计是否适用于其他极度不平衡的分类任务（如罕见病检测），论文未给出回答。

## 总结

BinSKD 旨在解决 BCSD 中 DNN 语义表征粗糙与 LLM 推理效率低下的矛盾。其切入点在于识别出教师模型并非全知全能，且嵌入空间直接对齐失效，转而采用关系结构对齐与选择性迁移。通过 MRR 筛选可靠查询与差异加权抑制噪声负样本，BinSKD 在保持 DNN 轻量级（388K 参数）与低延迟（185s/百万函数）的同时，将 HermesSim 的 Recall@1 提升 29.4%（O0,O3 设置），逼近 LLM 教师性能。其边界在于效果高度依赖教师模型质量，且仅在特定编译优化组合下验证，未覆盖跨语言或动态二进制场景。当教师模型在特定领域（如加密算法）表现劣于学生时，选择性蒸馏是否会导致学生模型在该领域的语义能力退化，论文未给出回答。
