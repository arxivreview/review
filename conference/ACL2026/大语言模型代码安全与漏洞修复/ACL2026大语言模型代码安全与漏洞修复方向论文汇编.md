【DeepGuard: Secure Code Generation via Multi-Layer Semantic Aggregation ｜多层语义聚合安全代码生成

研究机构：重庆大学、北京大学

作者：Li Huang、Zhongxin Liu、Yifan Wu 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.09089)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.09089)

> 现有安全对齐方法依赖最终层隐藏状态作为监督信号，但漏洞判别线索在Transformer深层中衰减，导致模型难以区分安全与脆弱代码。DEEPGUARD通过注意力机制聚合顶部多层表示，构建更敏感的安全分析器，并结合多目标训练与推理时偏置引导。该方法在五个代码大语言模型上将安全且正确的生成率平均提升11.9%，但仅验证了特定基准下的泛化性，未覆盖动态执行验证场景。

【From Completion to Editing: Unlocking Context-Aware Code Infilling via Search-and-Replace Instruction Tuning ｜搜索替换填充

作者：Jiajun Zhang、Zeyu Cui、Jiaxi Yang 等 12 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_3eebdc943577)

> 代码补全领域长期依赖 Fill-in-the-Middle (FIM) 范式，但该范式强制使用未对齐的 Base 模型，导致系统在面对代码注入攻击时缺乏防御能力，且无法修正上下文中的既有错误。现有方案要么牺牲安全性以维持补全性能，要么引入多步代理工作流导致延迟过高，无法满足实时交互需求。本文提出 Search-and-Replace Infilling (SRI)，通过结构化指令微调将代理验证机制内化为单次推理过程，使 Chat 模型在保持低延迟的同时继承安全对齐能力。SRI 在安全基准上将攻击成功率从接近 100% 降至 5.5%-20.0%，但其在通用编码任务上的性能保持机制仍需更严格的跨域验证。

【MulVul: Retrieval-augmented Multi-Agent Code Vulnerability Detection via Cross-Model Prompt Evolution ｜跨模型提示进化与路由的多智能体漏洞检测

作者：Zihan Wu、Jie Xu、Yun Peng 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.18847)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.18847)

> 现有基于大语言模型（LLM）的漏洞检测器在处理数百种异构弱点时，面临单一模型无法捕捉细粒度模式与人工提示工程不可扩展的双重瓶颈。MulVul 通过解耦提示生成与执行模型，结合粗到细的路由机制，自动化了专用检测器的构建。该框架在 PrimeVul 基准上实现了 34.79% 的 Macro-F1，但绝对精度仍低于传统图神经网络基线，且缺乏对跨类别漏洞关联检测的验证。

【Selective Knowledge Distillation: Fusing LLM Semantic Strengths with DNN Efficiency for Binary Code Similarity Detection ｜选择性关系知识蒸馏：融合LLM语义与DNN效率的二进制代码相似度检测

作者：Shize Zhou、Peiyu Liu、Lirong Fu 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f74da15362b2)

> 二进制代码相似度检测（BCSD）旨在无源码条件下比对函数功能，是漏洞追踪与恶意软件分析的基础。现有深度神经网络（DNN）方法依赖词法与控制流特征，对编译优化敏感且语义表征粗糙；大语言模型（LLM）虽能捕捉高层语义，但参数量大、推理延迟高，难以部署于大规模二进制分析流水线。BinSKD 提出一种选择性关系知识蒸馏框架，将 LLM 教师模型的关系拓扑结构迁移至 DNN 学生模型，同时通过筛选可靠样本与加权差异样本抑制噪声。该方法在保持 DNN 轻量级与低延迟优势的同时，显著提升了跨优化级别下的语义判别能力，但其效果高度依赖教师模型的质量与特定任务分布。

【When "Correct" Is Not Safe: Can We Trust Functionally Correct Patches Generated by Code Agents? ｜功能正确但含漏洞的补丁

作者：Yibo Peng、James Song、Lei Li 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_11c309850797)

> 代码代理在自动修复软件缺陷时，其输出通常仅通过单元测试来验证功能正确性，但这一标准无法保证代码的安全性。现有评估范式将“通过测试”等同于“安全”，忽视了功能正确补丁中可能嵌入的隐蔽漏洞。本文提出FCV-Attack，通过单次黑盒注入诱导代理生成此类补丁，揭示了SOTA代理的普遍脆弱性。该工作挑战了功能正确性作为安全代理指标的假设，但仅证明了威胁存在，未提供防御方案。

【新加坡管理大学等团队提出SecureVibeBench：重构漏洞引入场景，评估AI代理仓库级安全编码能力

研究机构：新加坡管理大学、新加坡国立大学

作者：Junkai Chen、Huihui Huang、Yunbo Lyu 等 13 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f1209d3090ea)

> 代码代理在真实软件维护中生成的代码普遍存在安全漏洞，但现有基准多局限于函数级合成任务，无法复现人类开发者引入漏洞的真实历史场景，导致评估结果与生产环境脱节。本文切入点在于重构漏洞引入点（VIC）的精确代码上下文，将评估从“能否生成安全函数”转向“能否在真实仓库中安全地实施需求”。通过级联静态与动态分析回溯VIC，并构建包含多文件编辑、功能测试与漏洞验证的仓库级基准，本文揭示了当前SOTA代理在复杂依赖下的安全短板。该工作填补了仓库级安全评估的空白，但其对SAST误报率的依赖及单一语言限制，使其结论的普适性仍存疑。

】
