# ACL2026最新论文 ｜Beyond Static Alignment: Adaptive Arbitration for Semantic Incongruence in Semi-Supervised Multimodal Sentiment Analysis ｜自适应仲裁解决语义不一致

作者：Huicong Li、Xiangbo Ji、Wei Wu

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_96a80b48aca5)

> 多模态情感分析（MSA）在标注稀缺场景下，常因视觉信号的高熵噪声与文本语义的明确性产生冲突，导致融合表征被污染。现有半监督方法依赖静态置信度阈值筛选伪标签，无法在模态冲突时动态权衡证据可靠性，致使自训练过程中错误累积。本文提出自适应仲裁框架（A2SI），通过文本锚定视觉表征、可靠性感知校准及双视角仲裁蒸馏，动态平衡样本多样性与标签纯度。该方法在标签受限设置下显著优于现有SOTA，但其对视觉骨干网络容量的依赖性揭示了小样本多模态学习中模型规模与泛化能力的非单调关系。

## 研究背景

半监督多模态学习依赖自训练机制，即利用模型预测的高置信度样本作为伪标签进行迭代优化。这一过程的核心假设是融合表征比单模态表征更可靠，但在语义不一致场景中，视觉背景噪声会污染融合特征，使得基于融合预测的伪标签偏离真实情感极性。此时，静态置信度阈值面临两难：过严则丢弃大量有效难样本，过松则引入高置信度错误，导致误差在自训练循环中放大。

多模态情感分析的主流路线分为特征级融合与决策级融合。特征级方法通过张量或注意力机制整合异构信号，但缺乏对模态质量差异的显式建模；决策级方法聚合单模态预测，虽能处理缺失模态，却难以解决视觉表征本身的语义漂移问题。现有半监督工作如FixMatchLS和SCRD，主要关注一致性正则化或静态阈值过滤，未针对模态间的可靠性不对称进行动态仲裁。本文的切入点在于，将伪标签生成视为一个证据仲裁问题，而非简单的置信度筛选，从而在自训练过程中动态修正被噪声污染的监督信号。

## 核心方法

### 多模态特征编码与融合参照系

本文遵循标准的多模态编码流程，将图像和文本分别通过ResNet-18和BERT-base编码为原始特征，再映射为模态特异性特征 $S_v, S_t$ 和融合特征 $C_m$。与常规做法不同，本文不直接假设 $C_m$ 为最优监督源，而是将其视为可能受噪声污染的“融合视图”，与单模态视图并列参与后续仲裁。这一设计差异源于对语义不一致场景的考量：当视觉信号高熵时，融合特征可能比纯文本特征更不可靠。

### 融合引导模态正则化（FGMR）

FGMR旨在解决视觉编码器过拟合任务无关背景模式的问题。传统方法中，视觉特征 $S_v$ 缺乏显式语义约束，易偏离真实情感流形。本文引入融合表征 $C_m$ 作为语义锚点，通过最小化模态特异性特征与融合中心的距离来稳定视觉表征。其正则化损失定义为：

$$ L_{reg} = \|S_t - S_v\|^2 + \alpha (\|S_t - C_m\|^2 + \|S_v - C_m\|^2) $$

该公式强制视觉特征 $S_v$ 向包含文本稳健语义的 $C_m$ 对齐，同时保持文本特征 $S_t$ 的独立性。这种约束机制迫使视觉编码器抑制背景噪声，重新对齐其特征分布与情感上下文，从而在表征层面缓解模态间的语义漂移。

### 可靠性感知校准与双视角仲裁蒸馏（RAC & DVAD）

RAC模块通过温度缩放量化各分支（视觉、文本、融合）的预测置信度 $i_{max}$，并据此计算自适应权重，生成校准后的伪标签 $\tilde{P}_s$。当融合视图受噪声污染时，RAC允许可靠的单模态证据（如明确文本）覆盖被污染的融合输出。DVAD模块进一步引入双视角仲裁机制，在校准视图 $\hat{P}_s$ 和融合视图 $P_f$ 之间进行动态选择。其仲裁策略基于置信度边际 $\delta_t$：

$$ p_{sel} = \begin{cases} \arg\max p_s, & c_f - c_s < \delta_t \\ \arg\max p_f, & \text{otherwise} \end{cases} $$

其中 $\delta_t$ 随训练轮次线性增加，初期允许融合视图自由贡献，后期则要求融合视图仅在置信度显著高于校准视图时才被选中。这种渐进式收紧机制确保了自训练从探索阶段平滑过渡到高精度利用阶段，有效防止了低质量伪标签的累积。

## 实验评估

实验在MVSA-Single和MVSA-Multiple数据集上进行，采用5折交叉验证，评估指标为准确率、伪标签准确率（PLA）和利用比（UR）。基线覆盖监督方法（如MGNNS、INIT）和半监督方法（如FixMatchLS、SCRD），但未包含基于大语言模型的多模态对齐方法，因任务设定为分类而非生成。

| 方法 | MVSA-Single (600 labels) | MVSA-Multiple (600 labels) |
| :--- | :--- | :--- |
| SCRD | 66.60±0.59 | 67.76±0.39 |
| A2SI | 68.75±0.43 | 68.38±0.35 |

A2SI在600标签设置下，MVSA-Single准确率较SCRD提升2.15%，MVSA-Multiple提升0.62%。在低资源场景（50标签）下，MVSA-Single提升1.26%，MVSA-Multiple提升1.87%，表明动态仲裁机制在数据稀缺时更具优势。

| 组件 | MVSA-Single | MVSA-Multiple |
| :--- | :--- | :--- |
| A2SI (Full) | 68.78 | 67.68 |
| w/o DVAD | 65.23 | 66.52 |
| w/o RAC | 67.14 | 66.76 |
| w/o FGMR | 67.96 | 66.92 |

消融实验显示，移除DVAD导致MVSA-Single准确率下降3.35%，降幅最大，证实双视角仲裁是解决模态冲突的关键。移除FGMR和RAC分别导致0.82%和1.64%的性能下降，表明表征稳定与置信度校准均有贡献，但仲裁机制的作用更为显著。视觉骨干网络测试中，ResNet-18表现优于ResNet-50和ViT系列，提示在标签稀缺且视觉噪声大的场景下，模型容量增加可能加剧过拟合而非提升泛化。

评估边界方面，论文仅报告准确率，未提供F1分数或混淆矩阵，难以评估类别不平衡下的表现。代码未公开，但超参数（如 $\lambda_{reg}=0.05$, $T=0.7$）和训练细节（150 epochs, cosine decay）已完整披露，具备可复现性基础。

## 关联研究分析

从问题动机看，A2SI与PEA-DPO均利用文本作为语义锚点抑制视觉噪声，但PEA-DPO通过构造视觉负样本优化偏好对，适用于生成式对齐；A2SI则通过正则化约束视觉特征，适用于分类式半监督学习。这一差异源于任务特性：生成式任务需要显式区分正负样本，而分类式任务更关注表征空间的稳定性。A2SI未探索偏好优化范式，可能是因为其任务目标为离散情感分类，而非连续偏好排序。

从方法设计看，A2SI与SCRD同属半监督多模态学习框架，但SCRD依赖静态阈值筛选伪标签，A2SI引入动态仲裁。SCRD的静态策略在模态冲突时易丢弃高质量单模态证据，而A2SI的DVAD机制允许在融合视图不可靠时回退到校准视图。这种动态性是否在所有模态组合中均有效，论文未给出回答，特别是在视觉信号完全缺失或文本极度模糊的极端场景下，仲裁机制的鲁棒性仍需验证。

## 总结

A2SI针对半监督多模态情感分析中语义不一致导致的伪标签污染问题，提出通过文本锚定视觉表征、可靠性校准及双视角仲裁的动态框架。该方法在MVSA-Single和MVSA-Multiple数据集上，于600标签设置下分别取得68.75%和68.38%的准确率，较SOTA方法SCRD提升2.15%和0.62%。实验揭示，在标签稀缺且视觉噪声大的场景下，轻量级视觉骨干（ResNet-18）优于大容量模型，且双视角仲裁机制对性能贡献最大。然而，论文未探讨当模态间冲突程度极端化时，动态仲裁阈值 $\delta_t$ 的自适应调整是否仍能维持稳定性，这一边界条件下的鲁棒性有待进一步验证。
