# ACL2026最新论文 ｜ChartAgent: A Multimodal Agent for Visually Grounded Reasoning in Complex Chart Question Answering ｜图表视觉问答中的具身推理框架

作者：Rachneet Kaur、Nishan Srishankar、Zhen Zeng 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.04514)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.04514)

> 多模态大语言模型（MLLMs）在处理无标注图表时，因缺乏文本捷径而陷入数值幻觉与空间感知失效的困境。现有端到端模型依赖像素直接映射语义，无法执行精细的几何测量，导致在密集数据提取上表现不佳。本文提出ChartAgent，一种基于ReAct循环的智能体框架，通过调用图表专用视觉工具在图像空间内执行分割、定位与插值操作，实现视觉接地推理。该框架在无标注图表问答上取得SOTA性能，但其高延迟与对工具精度的依赖限制了其在实时场景的适用性。

## 研究背景

当MLLMs面对无标注图表时，其视觉编码器难以区分细微的像素差异，导致无法从图形元素中准确提取数值。这一感知瓶颈迫使模型依赖OCR提取的文本标签，但在无标注场景中，文本信息缺失，模型必须直接解析几何结构。然而，标准MLLMs缺乏对坐标轴刻度、数据点位置及元素间空间关系的细粒度理解，这种空间几何感知薄弱导致其在数值推理任务中频繁产生幻觉。

图表视觉问答（Chart VQA）旨在从图表图像中回答自然语言问题。早期方法依赖OCR流水线，将图表解析为表格，但受限于复杂布局的泛化能力。随着MLLMs的引入，范式转向端到端语义推理，但这也暴露了模型在“像素-数据”映射上的精度不足。主流路线如ChartLlama通过指令微调提升领域适配，但黑盒推理缺乏可解释性；ChartPoint引入坐标提示约束搜索空间，但依赖高质量标注且增加数据构建复杂性。现有方法大多将视觉感知视为一次性前向过程，缺乏迭代修正机制，一旦初始感知出错，后续推理必然失败。

ChartAgent的切入点在于将图表理解重构为“感知-操作-验证”的迭代过程。它不依赖模型内部隐式的视觉特征，而是通过外部工具显式地操作图像空间，将抽象的数值提取转化为具体的几何测量任务。这种设计解决了端到端模型在缺乏文本捷径时，无法主动获取视觉证据的问题，为无标注图表的精确推理提供了新的技术路径。

## 核心方法

### 方法参照系

ChartAgent基于ReAct智能体框架，将图表问答分解为思考（Thought）、行动（Action）与观察（Observation）的循环。与通用VQA智能体使用裁剪、缩放等通用工具不同，ChartAgent的核心差异在于其工具库专为图表几何结构设计，支持轴定位、元素分割与数值插值，实现了从“图像操作”到“数据提取”的直接映射。

### 图表专用视觉工具库

设计动机在于解决通用视觉工具无法处理结构化定量推理的问题。裁剪与缩放无法提取RGB值匹配图例类别，也无法计算像素面积或从轴刻度插值数值。ChartAgent构建了一套模块化工具库，包括通用工具（如`axis_localizer`、`segment_and_mark`）和图表专用工具（如`compute_bar_height`、`compute_segment_area`）。

工具执行过程可形式化为状态转移：

$$ s_{t+1} = (s_t, g_t, a_{chart\text{-}tool}_t, o_{t+1}) $$

其中 $s_t$ 为当前多模态状态，$g_t$ 为思考阶段生成的子任务目标，$a_{chart\text{-}tool}_t$ 为选定的图表工具，$o_{t+1}$ 为工具返回的结构化输出与可视化结果。该公式表明，智能体通过执行特定工具更新状态，将视觉信息转化为可推理的数值或坐标，从而在图像空间内完成接地。

### 视觉自验证与自适应修正

设计动机在于应对工具输出的不确定性。OCR可能因遮挡失败，分割可能因重叠错误，导致中间结果不可靠。ChartAgent引入视觉自验证机制，智能体在观察阶段检查工具生成的可视化结果（如分割掩码、标注图例），判断其是否满足预期。

验证逻辑可表示为：

$$ \text{Action}_{t+1} = \begin{cases} \text{Terminate}(Answer) & \text{if } V(o_{t+1}) = \text{True} \\ \text{Adjust}(a_{t+1}) & \text{if } V(o_{t+1}) = \text{False} \end{cases} $$

其中 $V(o_{t+1})$ 为智能体对工具输出 $o_{t+1}$ 的视觉验证函数。若验证失败，智能体调整参数或切换工具；若多次失败，则回退至基础MLLM直接推理。这一机制将工具错误率从累积效应转化为可检测的局部失败，提升了系统在噪声环境下的鲁棒性。

## 实验评估

实验在ChartBench（3,800对，76.2%无标注）和ChartX（1,152对，61.7%无标注）上进行，对比42个基线，包括GPT-4o、Qwen2-VL等通用MLLMs及ChartGemma等专用模型。

| 模型 | ChartBench Overall (%) | ChartBench Unannotated (%) | ChartX Overall (%) |
| :--- | :--- | :--- | :--- |
| GPT-4o | 54.53 | 36.15 | 45.48 |
| Phi-3 Vision | 55.32 | 40.77 | 48.70 |
| ChartAgent | 71.39 | 60.81 | 59.69 |

ChartAgent在ChartBench上取得71.39%的整体准确率，较次优的Phi-3 Vision提升16.07%；在无标注子集上达到60.81%，较Qwen2-VL提升17.31%。这表明视觉接地工具在缺乏文本捷径时具有显著优势。

| 方法 | 工具类型 | Overall Acc. (%) | Unannotated & Numeric Acc. (%) |
| :--- | :--- | :--- | :--- |
| ReAct + No Tools | None | 38.84 | 19.46 |
| ReAct + Natural Image Tools | Generic | 41.35 | 20.50 |
| ChartAgent | Chart-specialized | 71.39 | 58.29 |

消融实验显示，通用图像工具仅带来2.51%的提升，而图表专用工具带来30.04%的提升，证实了领域特定工具的必要性。视觉自验证机制在50%的工具失败案例中成功恢复70%，将整体错误率控制在15%以内。

评估协议采用5%相对误差阈值，符合领域标准。局限在于未报告计算延迟与成本，且工具级行为缺乏ground truth标注，难以量化中间步骤的准确性。代码未开源，复现依赖AutoGen与SAM等组件的特定版本。

## 关联研究分析

从问题动机看，ChartAgent与ChartPoint均针对数值幻觉，但路径截然不同。ChartPoint依赖坐标提示微调，将视觉信息编码入模型参数，属于参数化接地；ChartAgent通过工具调用在推理时动态获取视觉证据，属于非参数化接地。前者在密集图表上有效，但受限于标注质量；后者无需额外标注，但受限于工具精度。这种差异反映了“模型内化”与“外部增强”两种范式在数据效率与泛化能力上的权衡。

从方法设计看，ChartAgent与REChart同属智能体框架，但任务焦点不同。REChart侧重图表编辑与代码生成，强调结构保真度；ChartAgent侧重问答与数值提取，强调感知精度。REChart使用混合奖励优化代码质量，而ChartAgent使用视觉自验证优化感知可靠性。这表明智能体框架在图表领域的应用正从“生成”向“理解”分化，两者在评估指标与工具设计上存在显著差异。

## 总结

ChartAgent旨在解决MLLMs在无标注图表中因空间感知薄弱导致的数值幻觉问题。其切入点在于将视觉推理外化为工具操作，通过图表专用工具库在图像空间内执行精确的几何测量，弥补了端到端模型缺乏细粒度感知能力的缺陷。实验证明，该框架在ChartBench无标注子集上达到60.81%的准确率，较基线提升17.31%。然而，其性能高度依赖工具输出的准确性，且迭代推理带来的延迟与计算成本未被充分量化。当图表复杂度进一步增加，如3D或雷达图，工具库的泛化能力是否足以应对，论文未给出回答。
