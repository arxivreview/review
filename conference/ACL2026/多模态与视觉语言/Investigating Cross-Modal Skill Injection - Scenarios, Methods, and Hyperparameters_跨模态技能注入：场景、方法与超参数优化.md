# ACL2026最新论文 ｜Investigating Cross-Modal Skill Injection: Scenarios, Methods, and Hyperparameters ｜跨模态技能注入：场景、方法与超参数优化

研究机构：北京大学

作者：Zhiyu Xu、Lean Wang、Yuanxin Liu 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.19523)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.19523)

> 视觉语言模型（VLMs）在垂直领域适配中面临高质量视觉数据稀缺与全参数微调成本高昂的双重困境。现有参数高效微调（PEFT）路线依赖大量图文对，而模型合并虽免训练但缺乏针对非对称跨模态场景的系统性指南。本文通过系统评估九种合并方法在语言、数学与指令跟随三类场景下的表现，并量化超参数优化景观，揭示了经典合并法在指令跟随场景的显著优势及数学推理迁移的固有局限。该研究为低成本VLM适配提供了实用决策框架，但数学推理能力的涌现机制仍存疑。

## 研究背景

当VLMs部署于医疗或数学领域时，预训练数据分布与目标领域的偏差导致性能退化。全参数微调虽能缓解此问题，但需海量高质量视觉数据，这在垂直领域往往不可得。参数高效微调（PEFT）如LoRA通过冻结主干网络仅训练低秩矩阵降低了计算成本，但仍依赖大量图文对进行监督。模型合并（Model Merging）提供了一种替代路径，它通过线性组合微调后的专家模型参数与基础模型参数，无需额外训练数据即可注入特定能力。

传统模型合并研究多聚焦于同构LLM之间的能力聚合，假设各模型在共享模态空间内贡献对等能力。然而，跨模态技能注入涉及将领域专家LLM注入VLM骨干，这是一种非对称过程：VLM提供视觉接地，LLM提供文本专长，目标是诱导两者单独都不具备的涌现能力（如视觉数学推理）。这种非对称性使得同构合并的超参数指南失效，且不同能力（如语言 vs 数学）对参数空间插值的响应差异未被充分量化。本文切入点在于系统解析这种非对称合并的场景适用性、方法优劣及超参数敏感性，填补了从同构合并到跨模态注入的方法论空白。

## 核心方法

### 任务向量与合并范式

跨模态技能注入基于任务向量（Task Vector）概念，将微调引起的参数变化视为编码特定行为的向量。设基础模型参数为 $\theta_{base}$，专家LLM参数为 $\theta_{finetuned}$，任务向量 $\tau$ 定义为：

$$ \tau = \theta_{finetuned} - \theta_{base} $$

合并模型通过线性组合任务向量构建，经典任务算术（Task Arithmetic, TA）公式为：

$$ \theta_{merged} = \theta_{base} + \sum_{i=1}^{n} \lambda_i \tau_i $$

其中 $\lambda_i$ 为合并系数。本文评估三类方法：经典合并（TA, DARE, TIES）、数据感知合并（Fisher, RegMean）及免调参合并（NaN, WUDI等）。经典方法依赖超参数搜索，数据感知方法利用校准数据估计参数重要性，免调参方法直接从参数结构推导合并策略。

### 超参数优化景观分析

经典合并方法的核心成本在于超参数调优，尤其是合并系数 $\lambda$ 的搜索。本文引入相对遗憾（Relative Regret）指标，量化限制搜索空间（如约束系数和 $S=1$）导致的性能损失。定义全局最优性能为 $g_{max}$，限制搜索空间下的最优性能为 $g_{restricted}$，相对遗憾为：

$$ R = \frac{g_{max} - g_{restricted}}{g_{max}} \times 100\% $$

实验表明，$S=1$ 约束在WildVision等场景导致高达25%的性能退化，证明系数和约束并非普适。为高效搜索，本文对比了随机搜索、Sobol序列、CMA-ES、GP-BO（高斯过程贝叶斯优化）及局部搜索方法（Pattern Search, Powell）。GP-BO通过拟合高斯过程代理模型引导搜索，在低维（2-3维）且评估预算有限（40-60次）的场景下，展现出最低的归一化遗憾（Regret-over-Random, RoR），优于依赖协方差矩阵收敛的CMA-ES及易陷入局部最优的局部搜索方法。

## 实验评估

实验在六个基准上进行：CMMMU/JMMMU（多语言）、MathVista/MathVerse（数学推理）、MIA-Bench/WildVision（指令跟随）。基线覆盖经典、数据感知及免调参三类共九种方法，但缺乏与LoRA等PEFT方法的直接对比，仅以基础VLM为参照。

| 场景 | 方法 | CMMMU (Mistral) | JMMMU (LLaMA) | MIA-Bench (Idefics2) | WildVision (Qwen2) |
|---|---|---|---|---|---|
| 语言 | TA | 25.0 | 42.1 | - | - |
| 语言 | DARE | 28.5 | 39.0 | - | - |
| 指令 | TA | - | - | 76.1 | 50.1 |
| 指令 | DARE | - | - | 75.9 | 47.5 |
| 数学 | TA | - | - | - | - |
| 数学 | DARE | - | - | - | - |

*注：表中数值取自论文Table 1，仅展示部分代表性结果。数学场景具体数值见下文分析。*

在指令跟随场景，合并效果显著，Idefics2-base与Mistral-7B-Instruct合并后在MIA-Bench达到76.1，远超基础模型的33.0。语言场景同样有效，TA在CMMMU上提升2.4分。然而，数学推理场景表现不佳，MathVerse上多数配置导致性能下降，DARE是唯一在所有数学子集上保持一致正向增益的方法，但平均增益仅1.05分。消融实验显示，数据感知方法（如RegMean）在MathVerse上取得最高分17.0，但整体平均性能不及经典方法；免调参方法NaN在WildVision上达到36.8，虽低于经典方法的50.1，但无需调参，适合作为快速可行性评估工具。

评估边界方面，论文未报告置信区间，且数学推理的失败归因于视觉感知与逻辑推理的纠缠，但缺乏神经层面的机制验证。超参数调优成本高昂，WildVision场景单次调优耗时45小时，成本8044美元，限制了大规模应用。代码未公开，但实验基于MergeKit库，超参数网格搜索范围明确（系数0.1-0.9，密度0.2-0.8），具备部分可复现性。

## 关联研究分析

从方法设计看，本文与LoRA等PEFT路线形成互补而非替代。PEFT通过训练低秩矩阵适应视觉分布，而合并通过参数插值注入文本专长。本文发现数学推理迁移困难，暗示参数空间线性插值无法解决视觉-语言纠缠问题，这与CASPA等语义感知PEFT方法在细粒度识别上的成功形成对比，表明复杂推理能力可能需要显式结构适配而非简单权重组合。

从问题动机看，本文聚焦于“免数据”场景，而知识库中S-GRPO等RL后训练路线依赖奖励信号引导探索。合并方法无需奖励模型，成本更低，但上限受限于专家LLM的能力边界。当领域数据极度稀缺时，合并优于RL；但当数据充足且任务复杂时，RL可能通过动态调整策略克服静态合并的局限。本文未探索合并与RL的结合，也未对比合并与SFT在相同数据预算下的效率差异，这使得其在数据充足场景下的相对优势存疑。

## 总结

本文核心矛盾在于VLM垂直领域适配中数据稀缺与计算成本的冲突。切入点在于利用模型合并的非对称特性，将LLM专家能力注入VLM骨干，规避了对大规模视觉数据的依赖。通过系统评估九种合并方法在六类基准上的表现，证明了经典合并（TA/DARE）在指令跟随与语言场景的有效性，MIA-Bench最高达76.1，WildVision最高达50.1。然而，数学推理场景的微弱增益（平均1.05分）暴露了参数空间插值在复杂推理任务上的局限。边界在于，合并系数约束 $S=1$ 在部分场景失效，且缺乏与PEFT方法的直接对比。当视觉感知与逻辑推理高度纠缠时，静态参数合并能否通过引入动态路由机制实现数学推理能力的有效迁移，论文未给出回答。
