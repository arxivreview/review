研究机构：印度理工学院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_a2663fe50c26)

> 远程监督关系抽取（DSRE）面临训练标签噪声与推理粒度不匹配的困境，导致模型难以区分细粒度关系。现有方案要么依赖特定任务微调的中等规模模型，要么直接调用大语言模型（LLM）但受限于噪声示例质量。HYDRE 通过引入 DSRE 模型作为高召回候选生成器，结合动态示例检索策略，在 LLM 推理前过滤噪声并构建高质量上下文。该框架在低资源跨语言场景下展现了显著优势，但其对 DSRE 骨干模型的依赖限制了其在完全无监督场景下的泛化能力。

## 研究背景

当知识图谱构建需要大规模文本对齐时，远程监督（DSRE）通过匹配知识库三元组与文本生成弱标签训练数据，但标签仅作用于包含多个句子的“包”（Bag），而推理需在句子级别进行。这种粒度不匹配导致模型在训练时学习的是包级统计特征，而在测试时面对单句查询，极易混淆如“国籍”与“出生地”等语义相近的关系。为解决此问题，多实例多标签（MIML）框架被广泛采用，但传统基于 BERT 或 RoBERTa 的模型在细粒度句子级推理上仍显不足。

主流 DSRE 路线依赖任务特定微调，如 PARE 和 CIL，它们在英文基准上取得了 40+ 的 F1 分数，但缺乏对未见关系或低资源语言的泛化能力。另一方面，LLM 的上下文学习（ICL）潜力尚未在 DSRE 中充分挖掘，直接应用 LLM 面临两大障碍：一是 DSRE 训练数据噪声大，导致直接检索的示例质量低；二是 LLM 缺乏对特定关系语义的显式约束，易产生幻觉。HYDRE 的切入点在于利用 DSRE 模型的高召回特性缩小候选空间，再通过混合评分机制从噪声包中提取高质量句子级示例，从而在 LLM 推理前完成噪声过滤与语义对齐。

## 核心方法

### 方法参照系

标准 ICL 流程通常直接检索与查询语义最相似的示例，但在 DSRE 场景中，由于包级标签噪声，直接检索往往引入错误标签。HYDRE 的关键差异在于引入 DSRE 模型作为前置过滤器，将开放的关系分类问题转化为受限候选集上的判别问题，并设计了针对噪声包的两级检索机制。

### 候选关系选择与包级检索

Stage 1 利用训练好的 DSRE 模型（如 PARE）计算查询句子 $q$ 对所有关系 $r$ 的置信度 $f_{PARE}(q, r)$，选取 Top-k 候选关系集合 $R'$。这一设计动机在于利用 DSRE 模型的高召回特性（英文 Recall@5 约 85%）过滤明显负例，降低 LLM 的任务复杂度。对于每个候选关系 $r \in R'$，Stage 2 从标注有 $r$ 的包集合 $\mathcal{B}_r$ 中检索最相关的包 $B_j$，其评分函数为：

$$ \text{score}(B_j, r) = (1-\lambda) \text{sim}(q, B_j) + \lambda f_{PARE}(B_j, r) $$

其中 $\text{sim}(q, B_j)$ 为包内句子与查询的最大语义相似度，$f_{PARE}(B_j, r)$ 为包内句子对关系 $r$ 的最大置信度。该公式平衡了语义相关性与标签置信度，避免仅依赖语义相似度导致的噪声包入选。

### 句子级示例提取与提示构建

Stage 3 从选定的包 $B_r$ 中提取最具代表性的句子 $s_r$ 作为 ICL 示例。对于包内每个句子 $s$，计算其覆盖分数 $c(s)$，定义为包内标签集合中置信度超过阈值 $\tau$ 的关系数量：

$$ c(s) = \sum_{r_a \in \text{labelset}(B_r)} \mathbb{I}[f_{PARE}(s, r_a) > \tau] $$

在覆盖分数最高的句子中，选择聚合置信度 $\sum_{r_a} f_{PARE}(s, r_a)$ 最大者。这一设计动机在于解决多标签问题：通过选择覆盖多个有效关系的句子，确保提示中包含共现关系的证据，提升 LLM 对复杂多标签查询的预测能力。最终，示例按 $f_{PARE}(q, r)$ 升序排列，使高置信度候选靠近查询，优化 LLM 的注意力分配。

## 实验评估

实验在 NYT-10m 英文数据集及新建的四种低资源印地语系语言（Oriya, Santali, Manipuri, Tulu）测试集上进行，基线涵盖监督 DSRE 模型（PARE, CIL）、零样本 LLM 提示及少样本检索方法（MMR, TopK-sim）。

| 模型 | 英文 (Micro/Macro F1) | 印地语系平均 (Micro/Macro F1) |
| :--- | :--- | :--- |
| PARE (Supervised) | 42/31 | - |
| CIL (Supervised) | 43/32 | - |
| GPT-4o (0-shot) | 56/57 | 33/31 |
| HYDRE (GPT-4o) | 63/60 | 39/35 |
| HYDRE (Llama3.1-8B-FT) | 61/45 | 45/28 |

HYDRE(GPT-4o) 在英文任务上达到 63 的 Micro-F1，比零样本 GPT-4o 提升 7 点，比最佳监督基线 CIL 提升 20 点。在低资源印地语系语言上，HYDRE 平均提升 17 点，表明混合框架在跨语言迁移中的鲁棒性。

消融实验显示，移除语义相似度组件导致 Llama 3.1 性能下降 7 点，而移除 PARE 置信度仅下降 2-3 点，说明在英文场景中语义检索占主导。然而，在印地语系 Translate-train 设置下，移除 PARE 置信度导致性能显著下降，表明在低资源场景下，基于标签的置信度比嵌入相似度更关键。此外，移除 Stage 2（包选择）导致英文性能下降 7 点，验证了包级过滤对噪声抑制的重要性。

评估指标采用 Micro/Macro-F1，未报告 AUC，因为 LLM 不产生校准置信度。代码已开源，超参数 $\lambda$ 在开发集上网格搜索确定（英文 0.5，印地语 0.1）。实验未覆盖计算效率维度，且未与知识库中提到的 RE-GAR-AD 等最新 LLM 专用 RE 方法直接对比，限制了横向比较的全面性。

## 关联研究分析

从问题动机看，HYDRE 与 ICL-RE 等直接 LLM 提示方法的核心差异在于对噪声数据的处理方式。ICL-RE 假设示例来自干净标注数据，而 HYDRE 针对 DSRE 的包级噪声设计了混合评分机制。这一差异源于任务特性：DSRE 的弱标签本质决定了直接检索不可行，必须引入模型置信度作为噪声过滤信号。然而，HYDRE 依赖 PARE 等 DSRE 模型的高召回特性，若 DSRE 模型本身在特定领域表现不佳，HYDRE 的性能上限将受到限制。

从方法设计看，HYDRE 与 RE-GAR-AD 同属检索增强范式，但检索粒度不同。RE-GAR-AD 将零样本 RE 重定义为嵌入检索问题，利用 LLM 生成增强句子；HYDRE 则在 DSRE 框架内，利用 DSRE 模型置信度与语义相似度联合检索包级示例。HYDRE 的创新在于将 DSRE 模型作为“过滤器”而非“编码器”，这一设计在低资源跨语言场景中尤为有效，因为 DSRE 模型可通过翻译数据微调，而 LLM 嵌入在低资源语言中往往失效。但 HYDRE 未探索在干净标注数据上，其检索模块是否仍优于直接 ICL，这一盲区限制了其通用性评估。

## 总结

HYDRE 解决了 DSRE 中噪声标签与 LLM 推理能力不匹配的核心矛盾，通过 DSRE 模型过滤候选并混合评分检索高质量示例，在英文和低资源印地语系语言上分别取得 63 和 45 的 Micro-F1。其边界在于对 DSRE 骨干模型的强依赖，以及在干净标注数据上的有效性未经验证。当支持集增大且标注质量提升时，HYDRE 的噪声过滤机制是否仍具边际收益，论文未给出回答。
