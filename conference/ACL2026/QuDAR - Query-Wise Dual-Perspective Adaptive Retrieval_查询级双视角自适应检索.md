# ACL2026最新论文 ｜QuDAR: Query-Wise Dual-Perspective Adaptive Retrieval ｜查询级双视角自适应检索

研究机构：韩国科学技术院、韩国首尔大学

作者：Joeun Kim、Seunghyouk Yoon、Xuan-Bach Le 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_88ac7a6ffea2)

> 混合检索系统长期依赖固定的稀疏-稠密权重，无法适应不同查询对词汇匹配或语义泛化的差异化需求。现有方法要么静态融合，要么仅针对单一维度动态调整，忽略了检索器类型与查询格式之间的组合效应。QuDAR 将检索信号解耦为四路并行输出，通过置信度或大语言模型评分实现查询级动态加权。该方法在 BEIR 子集上显著优于静态基线，但其依赖推理时计算的成本是否抵消了精度增益，仍需大规模部署场景验证。

## 研究背景

当检索系统面对“澳大利亚首都”这类精确事实查询时，基于词频的稀疏检索器（如 BM25）能精准命中关键词，而基于向量空间的稠密检索器（如 Contriever）可能因语义泛化引入噪声；反之，对于“叶子为何变黄”这类需要背景知识的查询，稠密检索器表现更优。这种互补性催生了混合检索范式，但传统做法通常将稀疏与稠密分数通过固定权重 $\alpha$ 线性组合，或采用倒数排名融合（RRF）等静态规则。然而，固定权重假设所有查询的最优稀疏-稠密比例一致，这与实际查询分布的异质性相悖。

混合检索的瓶颈不仅在于检索器类型的静态选择，还在于查询处理方式的单一化。查询扩展（Query Expansion）通过生成自包含段落来丰富语义覆盖，但往往替换原始查询，导致精确匹配能力丧失。现有研究多将检索器类型与查询格式视为独立维度，分别优化，却未探索二者在查询层面的交互作用。例如，扩展查询可能增强稠密检索器的语义信号，却稀释稀疏检索器的词汇精度。这种交互效应使得单一维度的动态调整（如仅调整稀疏-稠密权重）无法捕捉最优检索配置，导致性能提升受限。

QuDAR 的切入点在于将检索器类型（稀疏/稠密）与查询格式（原始/扩展）解耦为两个正交维度，生成四路并行检索信号。通过查询级自适应加权，该方法能够根据每个查询的特性动态平衡四路信号，从而利用组合效应突破静态混合的性能上限。这一设计避免了全局最优权重的泛化失败，将混合检索从“一刀切”的静态配置转变为“因查制宜”的动态过程。

## 核心方法

### 双视角信号解耦与融合框架

混合检索的标准流程通常将稀疏与稠密检索器的输出通过固定权重融合，或仅对查询进行单一形式的扩展。QuDAR 的关键差异在于将查询格式作为独立维度，生成四路信号：原始查询稀疏检索（$R_{OS}$）、原始查询稠密检索（$R_{OD}$）、扩展查询稀疏检索（$R_{ES}$）和扩展查询稠密检索（$R_{ED}$）。这种解耦使得系统能够独立评估每种检索器-查询格式组合的贡献，而非将其混合为单一分数。

### 基于置信度的动态加权机制

静态融合无法区分检索器对特定查询的置信度差异，导致噪声信号被同等对待。QuDAR-confidence 通过计算每路信号的 Top-1 与 Top-2 分数差（Margin）来估计置信度，并据此分配权重。对于第 $i$ 路信号，置信度边距定义为：

$$ m_i = \max(\text{score}_{i,1} - \text{score}_{i,2}, 0) $$

其中 $\text{score}_{i,1}$ 和 $\text{score}_{i,2}$ 分别为归一化后的 Top-1 和 Top-2 文档分数。较大的边距表明检索器对当前查询具有明确的排序偏好，而较小的边距则暗示候选文档间存在歧义。通过温度控制的 Softmax 函数将边距转换为归一化权重：

$$ w_i = \frac{\exp((m_i + \epsilon)/\tau)}{\sum_j \exp((m_j + \epsilon)/\tau)} $$

该机制无需外部模型调用，仅依赖检索分数分布，实现了低延迟的查询级自适应。

### 基于 LLM 评分的语义可靠性加权

置信度加权仅反映排序的确定性，无法评估检索结果与查询的语义相关性。QuDAR-llm 引入大语言模型（LLM）对每路信号的 Top-1 文档进行相关性评分，以捕捉语义层面的可靠性。对于查询 $q$，LLM 评估第 $i$ 路检索到的 Top-1 文档 $d_i$ 对 $q$ 的回答充分性，输出 0-5 分的相关性分数 $\text{score}_{LLM, i}$。权重通过 Softmax 计算：

$$ w_i = \frac{\exp((\text{score}_{LLM, i} + \epsilon)/\tau)}{\sum_j \exp((\text{score}_{LLM, j} + \epsilon)/\tau)} $$

为避免检索器类型或呈现顺序带来的偏差，文档在评分前随机打乱，评分后映射回原始来源。该设计直接利用 LLM 的语义理解能力，弥补了基于分数差置信度在语义模糊查询上的不足，但引入了推理时计算开销。

## 实验评估

实验在 BEIR 基准的四个子集（FiQA, SciDocs, HotpotQA, Climate-FEVER）上进行，使用 BM25 作为稀疏检索器，Contriever 和 BGE-m3 作为稠密检索器。基线包括单一检索器、静态混合（固定权重）、动态 Alpha 调整（DAT）以及单视角动态混合。QuDAR 在 FiQA 上取得 0.3589 的 Recall@10，显著优于静态上界（0.3404）和 DAT（0.2842），验证了双视角组合效应的存在。

| 方法 | FiQA Recall@10 | SciDocs Recall@10 | Climate-FEVER Recall@10 | HotpotQA Recall@10 |
| :--- | :--- | :--- | :--- | :--- |
| Static UB(S) | 0.3404 | 0.2423 | 0.2117 | 0.7134 |
| DAT | 0.2842 | 0.2284 | 0.1251 | 0.6641 |
| QUDAR-simple(RRF) | 0.3219 | 0.1944 | 0.1661 | 0.6460 |
| QUDAR-confidence | 0.3438 | 0.2330 | 0.1967 | 0.7047 |
| QUDAR-llm | 0.3639 | 0.2454 | 0.2085 | 0.7515 |

消融实验显示，QUDAR-llm 在 FiQA 上比 QUDAR-confidence 高 0.0201，表明 LLM 评分在语义复杂查询上提供了额外增益。然而，在 HotpotQA 上，QUDAR-llm（0.7515）仅比 QUDAR-confidence（0.7047）高 0.0468，且两者均优于静态上界（0.7134），说明在事实性查询中，置信度加权已能捕捉大部分动态性，LLM 评分的边际收益递减。

评估边界方面，实验仅覆盖 BEIR 子集，未包含大规模语料（如 MS MARCO）或实时延迟指标。QuDAR-llm 的 LLM 调用成本（约 0.69-0.79 秒/查询）在高频检索场景中可能成为瓶颈。代码已开源，但超参数（如温度 $\tau$）的敏感性分析未在正文中详细展开，可复现性依赖于附录中的完整配置。

## 关联研究分析

从问题动机看，QuDAR 与 Dynamic Alpha Tuning（DAT）均针对静态混合的局限性，但 DAT 仅调整稀疏-稠密权重，忽略查询格式维度。QuDAR 将查询扩展视为独立信号，揭示了检索器类型与查询格式的组合效应，这是 DAT 未探索的盲区。这种差异源于任务特性：在需要背景知识的查询中，扩展查询对稠密检索器的增益与对稀疏检索器的损耗并存，单一维度调整无法平衡这种交互。

从方法设计看，QuDAR 与 ColBERT 等晚期交互方法同属混合检索范畴，但 ColBERT 关注文档内 token 级匹配，而 QuDAR 关注查询级信号融合。ColBERT 通过多向量表示提升细粒度匹配精度，但计算成本高；QuDAR 通过动态加权提升信号互补性，但依赖 LLM 评分时引入推理时计算。两者在效率-精度权衡上的取舍不同：ColBERT 优化检索精度，QuDAR 优化检索策略的适应性。

## 总结

QuDAR 解决了混合检索中静态权重无法适应查询异质性的核心矛盾。其切入点在于将检索器类型与查询格式解耦为双视角，通过查询级动态加权捕捉组合效应，这是静态方法无法做到的。方法上，QuDAR 生成四路并行信号，利用置信度或 LLM 评分实现自适应融合。实验证明，该方法在 BEIR 子集上比静态上界高 12-16%，验证了双视角适应的有效性。然而，QuDAR-llm 的 LLM 调用引入了显著的推理时延迟，且实验未覆盖大规模语料场景。当查询频率达到每秒千次级别时，LLM 评分的成本是否使该方法在工业部署中失去竞争力，论文未给出回答。
