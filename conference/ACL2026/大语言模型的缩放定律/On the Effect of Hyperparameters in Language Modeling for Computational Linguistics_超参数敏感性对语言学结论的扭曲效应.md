# ACL2026最新论文 ｜On the Effect of Hyperparameters in Language Modeling for Computational Linguistics ｜超参数敏感性对语言学结论的扭曲效应

作者：Ruoxi Ning、Yongpeng Zhu、Qingcheng Zeng 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_29b7759ab108)

> 计算语言学实验常依赖单一模型配置来推断神经网络的语法能力或词序偏好，但优化设置本身可能主导这些定性结论。现有研究普遍忽视超参数变化对语言学指标的影响，导致“优化伪迹”被误认为“归纳偏置”。本文通过网格搜索复现三项经典实验，量化了学习率、层数等微小变动如何反转模型排名或统计显著性。其价值在于揭示了当前语言学实验的脆弱性，但缺乏消除敏感性的通用方法，仅提供了诊断工具。

## 研究背景

神经语言模型（Neural Language Models, LMs）在计算语言学中被广泛用于模拟人类语言习得，其核心假设是训练过程会收敛到稳定的语言学表征。然而，模型行为高度依赖优化设置，学习率或初始化差异可能导致模型陷入不同的局部极小值，从而改变其学到的语言结构。这种依赖性在追求“从数据中学习语法”的实验中尤为关键，因为实验结论往往基于单次训练的结果，而非配置空间的统计分布。

主流路线如 Chang and Bergen (2022) 和 Kuribayashi et al. (2024) 通过对比不同架构（LSTM, Transformer, SRN）在特定任务上的表现，推断架构的归纳偏置。然而，这些研究通常使用任意或默认超参数，未考虑调优对结果的影响。当模型未充分训练时，性能差异可能源于优化不足而非架构本质，导致“架构优于数据规模”等结论失真。本文切入点在于将超参数视为实验变量，通过系统网格搜索检验语言学结论在配置空间中的稳定性，区分真实的架构偏置与优化伪迹。

## 核心方法

### 方法参照系

本文问题属于“模型行为鲁棒性检验”范畴，区别于传统的性能优化或缩放定律研究。标准流程是固定超参数训练单一模型并评估语言学指标，而本文的关键差异在于将超参数作为自变量，通过多配置训练评估结论的方差，而非追求单一最优性能。

### 超参数网格搜索与复现协议

设计动机在于解决单点实验无法区分“架构能力”与“优化质量”的失效。本文对三项实验（词获取、句法泛化、词序偏好）执行网格搜索，变量包括层数、隐藏维度、学习率、批大小及Dropout。对于实验B（句法泛化），采用随机种子重复训练以评估方差；对于实验C（词序偏好），使用贝叶斯优化基于高斯过程拟合前五次运行，以期望改进（EI）为获取函数选择后续配置，公式如下：

$$
EI(x) = \mathbb{E}[\max(f(x) - f(x^+), 0)]
$$

该公式量化了探索新配置相对于当前最优配置的预期收益，平衡了探索与利用，确保在有限计算预算下高效覆盖配置空间。

### 语言学指标的回归建模

设计动机在于原始实验使用Pearson相关系数，但多数结果p值过高，缺乏统计意义。本文改用线性回归建模测试困惑度（PPL）与词序频率、架构类型的交互作用，公式如下：

$$
\text{Test PPL} = \beta_0 + \beta_M^\top M + \beta_F F + \beta_{FM}^\top (F \circ M) + \beta_d^\top d + \beta_{dM}^\top (d \circ M) + \epsilon
$$

其中 $F$ 为词序频率，$M$ 为架构指示变量，$d$ 为语法特征向量。该模型通过交互项 $\beta_{FM}$ 捕捉架构对频率效应的调节作用，比相关系数更能揭示架构特异性偏置的统计显著性，避免了因分布非正态导致的假阴性。

## 实验评估

实验设置涵盖BookCorpus、WikiText-103及64种人工语言，基线覆盖LSTM、BiLSTM、BERT、GPT-2、SRN及Transformer。本文未对比MoE或扩散语言模型，因任务聚焦于经典架构的归纳偏置比较，而非新架构性能。

| 实验 | 配置 | PPL | SG Score | 显著性变化 |
| :--- | :--- | :--- | :--- | :--- |
| B (Syntactic) | Base LSTM | 54.80 | - | - |
| B (Syntactic) | Dropout - | 38.75 | - | - |
| B (Syntactic) | #layers + | 31.43 | - | - |
| C (Word Order) | Base | 9.03 | - | $\beta_F$ 不显著 |
| C (Word Order) | Repl | 6.35 | - | $\beta_F$ 显著 (-7.59) |
| C (Word Order) | Batch size + | 6.44 | - | $\beta_F$ 不显著 |

实验B显示，增加层数使LSTM的PPL从54.80降至31.43，SG分数显著提升，表明原文结论可能源于模型欠训练。实验C中，$\beta_F$（频率系数）在Base配置下不显著，但在Repl配置下显著为负（-7.59），而在Batch size +配置下再次不显著，证明词序偏好结论对超参数高度敏感。

消融分析揭示，Dropout移除和层数增加对PPL的影响最大，而学习率降低对SG分数的影响较小。反直觉发现是，SRN在部分配置下表现出更强的频率负相关，但在最佳验证PPL配置中，预期的“SRN > LSTM > Transformer”排序被打破，暗示记忆限制并非词序偏置的唯一决定因素。

评估边界方面，本文仅使用PPL和SG分数，未涵盖下游任务性能；评估协议依赖人工语言，生态效度有限；可复现性方面，代码已开源，但训练耗时2-14天，复现成本高，且未报告GPU具体型号对结果的影响。

## 关联研究分析

从问题动机看，本文与Chinchilla缩放定律（Hoffmann et al., 2022）形成互补。Chinchilla关注计算最优分配，假设超参数可无损迁移，而本文证明在语言学任务上，超参数迁移会导致定性结论反转。根源在于Chinchilla优化的是连续的损失函数，而语言学指标（如SG分数）是离散且非单调的，对优化路径更敏感。

从方法设计看，本文与µP（Maximal Update Parametrization）（Yang et al., 2022）存在张力。µP通过谱条件约束实现超参数迁移，旨在稳定训练动力学，但本文发现即使在小规模模型上，µP未完全消除语言学结论的敏感性。这暗示谱条件约束不足以稳定所有行为，特别是那些依赖特定优化轨迹的语言学特征。查询侧增强在数据充足时是否仍有增益，论文未给出回答，但本文结果提示，仅靠参数化方法可能无法解决语言学实验的鲁棒性问题。

## 总结

本文要解决的核心矛盾是语言学实验结论的稳定性与超参数敏感性之间的冲突。现有方法通过单点实验推断架构偏置，但忽视了优化设置对定性结论的主导作用。本文通过网格搜索和回归建模，量化了超参数变化如何反转模型排名或统计显著性，证明了“优化伪迹”风险的存在。实验显示，层数增加可使LSTM的PPL降低42%，而词序偏好系数在不同配置间显著性翻转。本文的边界在于仅诊断了问题，未提供消除敏感性的通用方法，且实验局限于经典架构和人工语言。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答，但本文结果提示，语言学结论的鲁棒性可能需要更复杂的配置空间探索策略。
