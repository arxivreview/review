# ACL2026最新论文 ｜Toward Robust In-Context Learning: Leveraging Out-of-distribution Proxies for Target Inaccessible Demonstration Retrieval ｜基于分布外代理的目标不可达演示检索

研究机构：吉林大学

作者：Hao Xu、Rite Bo、Fausto Giunchiglia 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.00014)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.00014)

> 分布外（OOD）场景下，大语言模型（LLM）的上下文学习（ICL）性能因演示样本与目标域分布不匹配而显著退化。现有检索方法依赖嵌入相似度或目标域样本，在目标域完全不可访问时失效。DOPA 利用源域微调模型与原始模型的困惑度比率构建 OOD 代理，结合马氏距离多样性约束实现无目标域演示检索。该框架在 BOSS 基准上验证了鲁棒性，但其代理机制对预训练知识覆盖度的依赖尚存疑。

## 研究背景

当 LLM 面对与预训练分布存在系统性差异的测试查询时，基于嵌入相似度的 TopK 检索往往选出语义相近但分布偏移的演示，导致模型预测偏离真实标签。这种失效源于相似度度量仅捕捉表面文本特征，无法区分源域与目标域的底层分布差异。为量化这种差异，研究引入 OOD 检测中的似然比思想，通过比较模型在不同分布假设下的预测置信度来识别分布偏移样本。然而，传统 OOD 检测需要目标域样本计算似然，这在目标域不可访问的实际场景中无法实现。

ICL 演示选择的主流路线分为检索与增强两类。检索方法如 KNN 和 DrICL 依赖预训练嵌入或 LLM 反馈信号，在 OOD 场景下因分布偏移而性能不稳定；增强方法如 Rewrite 需重写源域样本以对齐目标域，但缺乏目标域样本时重写质量受限。这些方法的共同瓶颈在于无法在零目标域样本条件下评估源域样本的分布对齐度。DOPA 的切入点在于利用 LLM 自身的预训练知识作为目标分布的弱代理，通过源域微调模型与原始模型的预测差异来近似 OOD 评分，从而在目标域完全不可访问时实现分布对齐的演示检索。

## 核心方法

### 方法参照系

标准 ICL 演示检索流程为：从源域候选池 $D_S$ 中基于嵌入相似度检索 $N \times |\mathcal{Y}|$ 个样本，拼接至测试查询 $x_t$ 后输入 LLM 生成预测。该流程假设源域与目标域分布一致，在 OOD 场景下因相似度度量失效而选出冗余或偏移样本。DOPA 的关键差异在于引入 OOD 代理评分替代纯相似度检索，并在初筛后增加全局多样性约束。

### OOD 代理估计

OOD 代理估计模块解决源域样本分布对齐度无法直接测量的问题。设计动机是：源域微调模型 $P_{source}$ 完全适应源分布，而原始 LLM $P_{target}$ 保留预训练语料中的广泛知识，可视为目标分布的弱代理。对同一输入 $x$，两模型的预测差异反映 $x$ 与目标域的偏离程度。OOD 评分定义为：

$$S(x) = \log P_{target}(x) - \log P_{source}(x)$$

该公式的物理含义是：若 $x$ 在目标代理下困惑度低而在源代理下困惑度高，则 $S(x)$ 为负值，表明 $x$ 更对齐目标域。通过遍历 $D_S$ 并选取 $k$ 个最低 $S(x)$ 样本，得到粗粒度对齐子集 $\hat{D}_S$。理论保证由 Theorem 1 提供：在 KL 散度有界且概率下界存在的条件下，代理似然比误差被常数 $\epsilon_t + \epsilon_s$ 约束，确保评分的可靠性。

### 马氏距离多样性检索

马氏距离多样性检索模块解决 OOD 评分初筛后样本冗余的问题。设计动机是：困惑度评分主要捕捉 token 级流畅性，可能偏好短文本或高频模式，导致 $\hat{D}_S$ 中样本语义重叠。对 $\hat{D}_S$ 中每个样本表示 $h_{x_i}$，初始化候选集 $D_{demo}$ 后，迭代筛选满足多样性约束的样本。多样性度量定义为：

$$Div_{D_{demo}} = \frac{1}{|D_{demo}|^2} \sum_{i,j \in D_{demo}} D_{ij}$$

其中 $D_{ij} = (h_{x_i} - h_{x_j})^T \Sigma^{-1} (h_{x_i} - h_{x_j})$ 为马氏距离，$\Sigma$ 为经验协方差矩阵。该公式的物理含义是：马氏距离考虑样本间相关性，比欧氏距离更能捕捉语义空间中的结构差异。若新样本 $\hat{x}$ 加入后 $Div_{D_{demo}} \leq Div_{\{\hat{x}\} \cup D_{demo}}$，则保留 $\hat{x}$，直至 $|D_{demo}| = N \times |\mathcal{Y}|$。最终 $D_{demo}$ 作为演示集用于 ICL。

## 实验评估

实验在 BOSS 基准上进行，涵盖情感分析（SA）、毒性检测（TD）、自然语言推理（NLI）和命名实体识别（NER）四类任务，使用 GPT2-xl、LLaMA3.2-3B、Qwen3-8B 等六个开源模型及 GPT4o-mini、GPT3.5-turbo 两个闭源模型。基线覆盖 Random、KNN、DrICL、Rewrite、InfICL、DICL 六种方法，但缺失 DPP、KITE 等最新多样性方法，且未在 Banking77、SST-2 等标准 ID 任务上验证。

| 模型 | 任务 | DOPA | KNN | Random |
| :--- | :--- | :--- | :--- | :--- |
| LLaMA3.2-3B | SA avg | 59.29 | 54.60 | 55.98 |
| Qwen3-8B | TD avg | 66.98 | 61.09 | 59.75 |
| GPT4o-mini | NLI avg | 37.39 | 34.72 | - |

DOPA 在 LLaMA3.2-3B 的 SA 任务上以 59.29% 准确率领先 KNN 的 54.60% 和 Random 的 55.98%，在 Qwen3-8B 的 TD 任务上以 66.98% 领先 KNN 的 61.09%。Wilcoxon 符号秩检验确认 DOPA 在九个评估任务上显著优于所有基线，但部分基线如 InfICL 在特定设置下与 DOPA 性能相当，表明代理机制并非在所有场景下均占优。

消融实验显示，移除 OOD 代理（DOPA$_{-pro}$）导致性能下降 1.70%，移除语义相似度（DOPA$_{-sim}$）下降 2.59%，移除马氏距离（DOPA$_{-mah}$）下降 1.64%。DOPA$_{-sim}$ 降幅最大，表明语义相似度在细粒度筛选中起关键作用；DOPA$_{-mah}$ 降幅最小，说明多样性约束的边际收益相对有限。将目标代理替换为均匀分布（DOPA$_{uni}$）导致性能下降 1.84%，验证了 LLM 作为目标代理的有效性，支持 Lemma 1 的结论。

评估边界存在三方面局限：指标仅使用准确率，未报告校准度或延迟；BOSS 基准为 OOD 特定基准，未覆盖标准 ID 任务，无法验证 DOPA 在分布一致场景下的性能；代码已开源（https://github.com/bort64/ood_code），但超参数 $k$ 固定为 800，未探索自适应调整机制。

## 关联研究分析

从问题动机看，DOPA 与 DrICL 均针对 OOD 场景下的演示检索，但 DrICL 依赖 LLM 反馈信号训练密集检索器，计算成本高且在分布偏移下不稳定；DOPA 利用源域微调模型与原始模型的预测差异构建 OOD 代理，无需额外训练，但代理质量受限于预训练知识对目标域的覆盖度。这一差异源于任务特性：DrICL 假设目标域样本可获取以提供反馈，而 DOPA 针对目标域完全不可访问的更严格约束。

从方法设计看，DOPA 与 DPP 均引入多样性约束，但 DPP 基于行列式点过程最大化子集体积，计算复杂度为 $O(N^3)$；DOPA 使用马氏距离贪心筛选，复杂度为 $O(N^2)$，更适合大规模候选池。DPP 的多样性度量基于核函数，可灵活调整相关性-多样性权衡；马氏距离基于协方差矩阵，更关注样本间相关性而非全局分布覆盖。这一差异暗示 DOPA 在候选池分布不均时可能不如 DPP 鲁棒，但论文未在 DPP 基线上验证此假设。

## 总结

DOPA 要解决的核心矛盾是目标域不可访问时源域演示的分布对齐度无法测量。现有方法依赖嵌入相似度或目标域样本，在零目标域样本条件下失效；DOPA 利用 LLM 预训练知识作为目标分布弱代理，通过源域微调模型与原始模型的困惑度比率构建 OOD 评分，结合马氏距离多样性约束实现无目标域演示检索。实验在 BOSS 基准上验证了 DOPA 在 LLaMA3.2-3B 的 SA 任务上以 59.29% 准确率领先 KNN 的 54.60%，在 Qwen3-8B 的 TD 任务上以 66.98% 领先 KNN 的 61.09%。本文的边界在于代理机制依赖预训练知识对目标域的覆盖度，当目标域分布极度偏离预训练语料时，原始 LLM 作为目标代理的可靠性存疑。当目标域分布与预训练语料的 KL 散度超过 Theorem 1 的有界条件时，OOD 评分的误差是否仍可控，论文未给出回答。
