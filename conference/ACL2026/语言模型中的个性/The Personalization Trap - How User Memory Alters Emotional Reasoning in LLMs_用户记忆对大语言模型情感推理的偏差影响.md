# ACL2026最新论文 ｜The Personalization Trap: How User Memory Alters Emotional Reasoning in LLMs ｜用户记忆对大语言模型情感推理的偏差影响

作者：Xi Fang、Weijie Xu、Yuchong Zhang 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.09905)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.09905)

> 个性化AI系统引入长期用户记忆后，其情感推理能力是否会被用户画像中的社会阶层信息扭曲？现有研究多关注记忆如何增强任务性能，却忽视了记忆注入可能内化社会偏见，导致对弱势群体的情感理解系统性降级。本文通过控制变量实验，量化了15个主流模型在引入用户画像后的情感理解偏差。其核心发现是“个性化陷阱”：记忆机制在提升共情表象的同时，可能固化社会不平等。这一诊断性发现揭示了个性化与公平性的深层冲突，但缺乏对应的缓解机制。

## 研究背景

当AI助手记住用户是“单亲母亲”还是“高管”时，其对同一压力场景的情感解读可能截然不同。这种差异源于大语言模型（LLMs）的长期记忆机制，它允许模型跨对话保留用户偏好。然而，记忆并非中性容器，用户画像中隐含的经济、文化和社会资本维度（基于Bourdieu的社会资本理论）会作为先验知识介入推理过程。若模型内化了训练数据中的社会阶层偏见，记忆注入便不再是简单的上下文补充，而是将社会等级结构编码进了情感判断逻辑，导致对相同情感情境产生基于用户身份的差异化解读。

当前个性化LLM研究主要聚焦于如何通过用户嵌入或检索增强生成（RAG）提升任务适配性，如PersonaAgent和User-LLM等框架。这些方法假设用户信息能正向增强模型表现，但鲜有研究审计这种增强背后的公平性代价。主流评估范式多采用自报告量表，存在效度问题，且难以区分模型是真正理解了情感，还是仅仅模仿了礼貌性回复。本文切入点在于利用经过人类验证的情感智力测试（STEU/STEM），在控制情感场景不变的前提下，仅改变用户画像的社会阶层属性，从而隔离出记忆对情感推理的纯偏差效应。

## 核心方法

### 方法参照系

本文问题属于“个性化LLM的公平性审计”，而非人格控制。与激活工程（Activation Engineering）或模型合并（Model Merging）等旨在注入特定人格特质的方法不同，本文不修改模型权重或内部表示，而是将用户画像作为系统提示（System Prompt）的一部分注入，评估其对下游情感任务性能的影响。关键差异在于：控制方法追求“改变行为”，本文追求“测量改变行为的副作用”。

### 基于社会资本的画像生成

为量化社会阶层对情感推理的影响，本文构建了显式用户画像。设计动机在于解决传统人口统计学变量（如性别、年龄）无法捕捉社会经济地位差异的问题。基于Bourdieu的四维框架（人口统计、家庭背景、社会连接、个人资产），从Persona Hub采样30个基础画像，利用DeepSeek-R1生成“优势”与“劣势”两个版本。优势版本包含资源获取便利与社会特权，劣势版本则包含结构性障碍。这种二元对立设计使得模型在推理时面临明确的阶层信号，从而暴露其潜在的社会偏见。

$$
P_{adv} = \text{Gen}(\text{Base}, \text{Privileges}), \quad P_{disadv} = \text{Gen}(\text{Base}, \text{Barriers})
$$

该公式表示通过生成模型，将基础画像分别转化为包含特权信号和障碍信号的两个版本，确保除阶层属性外其他变量保持一致。

### 交叉控制的情感评估协议

在画像生成基础上，本文设计了交叉控制实验以解耦人口统计学偏差。设计动机在于区分“阶层偏见”与“特定群体偏见”（如对穆斯林或老年人的偏见）。通过PRISM数据集构建81个交叉画像（3性别×3年龄×3宗教×3种族），结合STEU（情感理解）和修改版STEM（情感指导）进行测试。STEU评估模型对他人情感的识别与推理，STEM则评估模型提供情感建议的能力。关键创新在于引入“翻转率”（Flip Rate）指标，定义为相对于无记忆基线，预测结果发生变化的比例。

$$
\text{Flip Rate} = \frac{|\{x \in X \mid y_{mem}(x) \neq y_{no-mem}(x)\}|}{|X|}
$$

该指标量化了用户记忆对模型决策的不稳定性影响，高翻转率意味着记忆显著干扰了原本稳定的情感判断。

## 实验评估

实验在15个LLM上进行，涵盖Claude、DeepSeek、Llama、Qwen等架构。基线为无用户记忆（No Memory）条件，对比优势（Adv）与劣势（Disadv）画像。主要发现是11/15模型在引入记忆后性能下降，且优势画像通常优于劣势画像。

| 模型 | No Mem. | Adv. | Disadv. |
| :--- | :--- | :--- | :--- |
| Claude 3.7 Sonnet | 90.91 | 80.10*† | 77.37* |
| DeepSeek-R1 | 84.85 | 81.62*† | 76.57* |
| Llama 3.2 90B | 84.85 | 64.91*† | 62.24* |
| GPT-OSS 20B | 63.64 | 69.92* | 69.49* |

*注：*表示与No Mem.差异显著（p<0.05），†表示Adv与Disadv差异显著。

Claude 3.7 Sonnet在无记忆时得分90.91，引入劣势画像后降至77.37，降幅达13.54个百分点。相比之下，GPT-OSS 20B是唯一在引入记忆后性能提升的模型（63.64至69.92），这可能与其较小的参数量或特定的对齐策略有关，但论文未深入分析其异常原因。

在人口统计学偏差方面，DeepSeek-R1对基督教用户表现优于穆斯林用户，而对老年用户表现优于中年用户。Qwen 3 4B则表现出相反模式，对穆斯林和非二元性别用户表现更好。这表明不同模型内化了不同的社会偏见模式，且“思考型”模型（如DeepSeek-R1）的偏见往往比标准版本更复杂。

评估边界方面，本文未提供代码开源链接，且STEU/STEM测试基于英语，可能限制跨文化泛化性。此外，实验仅使用系统提示注入记忆，未探索参数化记忆或检索增强记忆等其他机制，结论的普适性受限。

## 关联研究分析

从问题动机看，本文与PersonaAgent等个性化框架形成互补。PersonaAgent关注如何通过测试时个性化提升生成质量，假设用户信息是正向增益；本文则揭示这种增益可能伴随公平性损失，特别是当用户信息包含社会阶层信号时。两者的根本差异在于对“个性化”的定义：前者视其为能力增强，后者视其为潜在的风险源。这种差异源于任务特性的不同：生成任务对风格敏感，而情感推理任务对事实准确性敏感，记忆中的偏见更容易在后者中导致错误。

从方法设计看，本文与激活工程（如CAA）路线存在本质区别。CAA通过操纵内部激活向量实现人格控制，旨在改变模型行为；本文则通过外部提示注入，评估模型对输入变化的敏感性。CAA假设人格特质在内部表示中线性可分，而本文发现社会偏见可能非线性地嵌入在推理链中，导致简单的提示注入即可引发显著的行为偏移。这种差异暗示，仅靠外部提示无法消除模型内部的偏见，需要更深层的解耦机制。

## 总结

本文核心矛盾在于个性化AI的共情承诺与社会公平原则之间的冲突。现有方法假设用户记忆能增强情感理解，但本文通过控制变量实验证明，记忆注入可能内化社会阶层偏见，导致对弱势群体的情感解读系统性降级。本文构建了基于Bourdieu理论的画像生成与交叉控制评估协议，量化了15个模型在STEU/STEM测试中的偏差。核心数字显示，Claude 3.7 Sonnet在劣势画像下的情感理解得分较无记忆基线下降13.54个百分点，且多数模型对优势画像表现更好。本文边界在于仅评估了系统提示注入的记忆机制，未探索参数化记忆或检索增强记忆，且缺乏缓解策略。当记忆机制从提示注入转向参数化存储时，社会偏见是否会被更深层地固化，从而更难通过外部干预消除？
