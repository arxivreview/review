# ACL2026最新论文 ｜GenPT: Beyond Self-Report for Reliable LLM Psychometrics via Generative Projective Testing ｜生成式投射测试

研究机构：美国东北大学、新加坡管理大学

作者：Ming Wang、Shuang Wu、Bixuan Wang 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.00860)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.00860)

> 导读 大语言模型（LLM）人格评估长期依赖自报告量表，但训练语料污染与社会期望偏差导致测量结果失真。GenPT 将人类心理学中的投射测试范式迁移至 LLM 评估，通过新生成的模糊刺激物诱导行为反应，绕过直接提问引发的防御机制。该方法构建了三阶段流水线，将非结构化行为转化为标准化心理指标。GenPT 在抗偏差和情境敏感性上显著优于传统量表，但在静态人格准确率上略逊，其 LLM 解释器是否引入新偏差尚待验证。

## 研究背景

当 LLM 被赋予特定人格后，评估其是否真正表达该人格成为核心难题。传统方法依赖自报告量表，如大五人格量表（Big Five Inventory, BFI），但 LLM 的训练语料中已包含这些量表，导致模型通过记忆而非真实表达作答，即数据污染。更严重的是，对齐训练使 LLM 产生社会期望偏差，倾向于输出符合社会规范的“假好”回答，而非真实心理状态。

LLM 人格评估领域面临信效度危机。基于自报告的评估对提示格式极度敏感，且存在“人格幻觉”现象，即自我报告分数与实际行为解离。现有研究多聚焦于人格控制，如激活向量注入或模型合并，但对评估工具本身的可靠性关注不足。GenPT 的切入点在于：利用投射测试的间接性，通过模糊刺激物掩盖评估意图，从而绕过 LLM 的安全对齐过滤器，获取更真实的行为反应。

## 核心方法

### 三阶段评估流水线

GenPT 将心理评估建模为从行为到状态的映射过程。给定人格 $P$ 和 LLM $M$，被试 $X$ 产生行为输出 $R$，解释器 $I$ 提取结构化指标 $S$，诊断器 $D$ 推断最终状态 $y$。该流程的关键差异在于：传统量表直接询问特质，而 GenPT 通过模糊刺激物诱导行为，将评估意图隐藏在任务表面。

### 刺激物生成与行为收集

为规避数据污染，GenPT 使用 FLUX.1-dev 和 Stable Diffusion 生成全新刺激物，包括 28 张主题性知觉测试（TAT）场景图、13 张罗夏墨迹图（Rorschach）和 97 个句子补全（SCT）项目。被试 $X$ 在不知晓评估目标的情况下完成这些任务，产生非结构化文本 $R$。这一设计解决了传统量表因语料污染导致的记忆性作答问题，确保行为反应源于人格特质而非模式匹配。

### 结构化解释与诊断

解释器 $I$ 将行为输出转化为量化指标。对于 TAT，采用 SCORS-G 系统评分八个维度，每个维度 1-7 分：

$$
S_{TAT} = \frac{1}{n} \sum_{i=1}^{n} s_{i,d}
$$

其中 $s_{i,d}$ 为第 $i$ 个刺激物在第 $d$ 个维度的得分。对于罗夏测试，提出简化罗夏分析系统（SRAS），计算认知加工、情感调节、人际关系和压力应对四个领域分数。诊断器 $D$ 聚合所有指标，映射至目标状态空间 $Y$。该设计实现了从定性行为到定量指标的转换，使 LLM 评估具备临床心理学的严谨性。

## 实验评估

实验使用 CharacterRAG（15 个动漫角色，人格特质）和 AnnaAgent（15 个心理健康档案，抑郁/自杀风险）数据集，对比 GenPT 与传统自报告量表。基线仅包含传统量表，缺失激活引导或模型合并等控制方法基线，但本文聚焦评估而非控制，此局限可接受。

| 任务 | 方法 | 指标 | 数值 |
| :--- | :--- | :--- | :--- |
| 自杀意念 | 量表 | DCR | 0.88 |
| 自杀意念 | GenPT (Qwen3-8B) | DCR | ≈0.5 |
| 抑郁 | GenPT (Qwen3-8B) | 纵向变化 | 显著大于量表 |
| Big Five | 量表 | 准确率 | 0.37 |
| Big Five | GenPT (Qwen3-8B) | 准确率 | 0.24–0.33 |

在自杀意念任务上，量表的方向一致性比率（DCR）达 0.88，显示强烈的“假好”偏差，而 GenPT 的 DCR 接近 0.5，表明无系统性偏差。在抑郁纵向实验中，GenPT 的评估变化幅度比量表大一个数量级，验证了其对临床情境的敏感性。然而，在静态人格任务上，量表准确率（0.37）高于 GenPT（0.24–0.33），反映投射测试在直接语义映射任务上的劣势。

GenPT 的三个骨干模型（Qwen3-8B、Phi-4-mini、Intern-S1）表现各异：Qwen3-8B 在自杀风险上最优，Phi-4-mini 和 Intern-S1 在抑郁评估上更强。这种骨干依赖性表明，解释器的能力直接影响评估质量，但论文未深入分析不同骨干的偏差来源。

评估边界方面，论文未报告置信区间，且样本量较小（每任务 15 个档案），统计显著性存疑。代码已开源，但刺激物生成依赖特定模型版本，可复现性受限于生成模型的一致性。

## 关联研究分析

从问题动机看，GenPT 与 SJT 框架同属行为观测范式，但 SJT 通过情境判断测人格，GenPT 通过投射反应测人格。SJT 依赖预设情境，而 GenPT 利用模糊刺激物，后者更能绕过 LLM 的套路化响应，但前者在静态人格评估上可能更稳定。GenPT 的 LLM 解释器是否引入新的系统性偏差，论文未给出回答。

从方法设计看，GenPT 与 Persona Vectors 形成互补：Persona Vectors 通过激活向量实现人格控制，GenPT 通过行为反应评估人格。前者是白盒干预，后者是黑盒观测。GenPT 的评估结果可作为 Persona Vectors 等控制方法的验证手段，但论文未进行此类交叉验证，限制了其在领域中的定位。

## 总结

GenPT 要解决的核心矛盾是 LLM 人格评估中自报告量表的污染与偏差问题。其切入点在于利用投射测试的间接性，通过模糊刺激物掩盖评估意图，绕过 LLM 的安全对齐过滤器。方法上，GenPT 构建了三阶段流水线，将非结构化行为转化为标准化心理指标。实验证明，GenPT 在自杀意念评估中 DCR 接近 0.5（无偏），而量表达 0.88（有偏）；在抑郁纵向实验中，GenPT 的变化幅度比量表大一个数量级。然而，GenPT 在静态人格准确率上低于量表，且 LLM 解释器的能力影响评估质量。当解释器骨干模型变化时，GenPT 的评估偏差是否随之改变，论文未给出回答。
