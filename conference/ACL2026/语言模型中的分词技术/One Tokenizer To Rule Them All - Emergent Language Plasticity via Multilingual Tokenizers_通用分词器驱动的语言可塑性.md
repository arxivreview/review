# ACL2026最新论文 ｜One Tokenizer To Rule Them All: Emergent Language Plasticity via Multilingual Tokenizers ｜通用分词器驱动的语言可塑性

研究机构：Cohere

作者：Diana Abagyan、Alejandro R. Salamanca、Andres Felipe Cruz-Salinas 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_60d739b78ef1)

> 多语言大语言模型在预训练后难以低成本扩展新语言支持，现有后训练适配方法如词汇扩展或嵌入重训练成本高且效果不稳定。本文切入点在于预训练阶段引入覆盖语言范围远超主要训练语言的“通用分词器”，以极低的预训练性能代价换取后续适配的显著加速与效果提升。通过系统性消融实验，证明了该策略在持续预训练和微调场景下均能带来高达20.2%的胜率增益。其价值在于将分词器从静态预处理组件转化为架构级的可塑性杠杆，但3.3B参数规模下的结论向更大模型外推的有效性仍存疑。

## 研究背景

当模型预训练完成后，若需支持新语言，传统做法是替换或扩展分词器并重新初始化嵌入层。这一过程被称为跨语言词汇适配（Cross-lingual Vocabulary Adaptation, CVA），其核心困境在于新token的嵌入缺乏语义先验，导致性能大幅波动。为缓解此问题，研究者常采用超网络映射或平均初始化策略，但这些方法仍需大量后续训练才能弥补性能差距，且在不同语言间表现不一致。这种“先预训练、后修补”的范式，使得新语言适配成为高成本、低确定性的工程任务。

多语言大语言模型面临的核心矛盾是：预训练算力有限，无法覆盖所有目标语言，但下游应用又要求快速扩展语言覆盖。主流路线分为两类：一是优化静态分词器的压缩效率（如MorphBPE、MUTANT），旨在降低低资源语言的token数量；二是探索动态或无分词架构（如HAT、RL Tokenization），试图消除固定词汇表的限制。然而，前者侧重于“分得准”，后者侧重于“分得活”，均未直接回答“预训练时的分词器选择如何影响后续适配成本”这一关键问题。本文的切入点在于，分词器不仅是输入接口，更是模型对语言分布的初始感知框架。若在预训练初期就引入覆盖更广的分词器，模型在参数空间中会保留对新语言结构的潜在表征，从而在后续适配中无需从零学习，而是进行微调。

## 核心方法

### 方法参照系

本文问题属于多语言公平性优化范畴，但区别于传统的分词器压缩效率优化，其核心差异在于将分词器设计视为预训练阶段的“可塑性投资”。标准流程中，分词器通常仅覆盖主要训练语言，本文则主张分词器覆盖范围应大于预训练数据分布，以预留适配空间。

### 通用分词器与语言桶加权

设计动机在于解决均匀加权导致的高资源语言主导问题，以及分词器覆盖不足导致的适配困难。本文训练了一个覆盖62种语言的UNIVERSAL分词器，并采用基于语言桶（Language Bucketing）的加权策略。语言桶由共享语系和书写的语言组成，桶内语言均匀加权，桶间权重根据数据可用性调整。具体权重计算公式为：

$$ w_i = \frac{w_d^i \cdot w_b^i}{\sum_{j=1}^{n} w_d^j \cdot w_b^j} $$

其中 $w_d^i$ 为语言 $i$ 的数据分布权重，$w_b^i$ 为语言桶权重。该公式平衡了自然数据分布与语言学结构相似性，确保低资源语言在分词器训练中获得足够表征，避免其token在预训练中被过度压缩或忽略。

### 预训练数据重分配与适配策略

设计动机在于验证分词器覆盖范围对适配效率的影响，同时控制预训练性能损失。在预训练数据混合中，本文从英语数据中重新分配5%的比例给扩展语言（Expanded Languages），以防止分词器中新增token因数据不足而训练不充分。适配策略分为两类：持续预训练（CPT）使用包含主要语言和扩展语言的指令数据；目标适配（Targeted Adaptation）仅使用扩展语言或完全未见语言的数据进行监督微调。这种设计隔离了分词器覆盖范围与数据量对适配效果的独立影响，证明了即使在没有扩展语言预训练数据的情况下，UNIVERSAL分词器仍能显著提升适配性能。

## 实验评估

实验在3.3B参数模型上进行，预训练预算为100B tokens，覆盖62种语言及7种完全未见语言。基线包括CLUSTER分词器（仅覆盖主要语言）和CVA（预训练后替换分词器）。评估指标为LLM-as-a-Judge胜率（Win Rate）和FLORES-200 BLEU分数。

| 实验设置 | 语言子集 | CLUSTER Win Rate (%) | UNIVERSAL Win Rate (%) | 相对增益 (%) |
| :--- | :--- | :--- | :--- | :--- |
| 持续预训练 | 扩展语言 | 17.6 | 37.4 | +19.9 |
| 持续预训练 | 主要语言 | 42.8 | 42.8 | 0.0 |
| 目标适配 | 扩展语言 | 27.2 | 37.4 | +10.2 |
| 目标适配 | 完全未见语言 | - | - | +2.0 (平均) |

核心数字对比显示，UNIVERSAL分词器在扩展语言上的胜率增益高达19.9%，而在主要语言上性能几乎无损（差异<0.3%）。在FLORES-200机器翻译任务中，UNIVERSAL分词器在扩展语言上比CLUSTER分词器高4.7-8.0 BLEU，主要语言高2.2 BLEU。

消融实验揭示了关键设计决策的影响。语言桶加权策略比均匀加权在27种欧洲语言中的21种上表现更优，平均相对增益2.2%。预训练数据中扩展语言比例从0%增加到5%时，扩展语言适配胜率从12.8%提升至19.8%，而主要语言性能未受负面影响。词汇表大小消融显示，UNIVERSAL分词器在250k词汇表下才超越CLUSTER分词器，表明大词汇表是维持多语言覆盖的必要条件。

评估边界方面，实验仅覆盖3.3B参数模型，未验证更大规模下的效果外推。LLM-as-a-Judge评估可能存在偏差，尽管使用了Command-A作为裁判模型，但其与人类偏好的一致性在多语言场景下仍有争议。代码未公开，复现需依赖Cohere内部基础设施，限制了外部验证。

## 关联研究分析

从问题动机看，本文与Token Tax Analysis（Lundin et al., 2025）形成互补。后者量化了分词碎片化导致的计算成本不公，侧重于“分词效率”；本文则关注“适配成本”，证明分词器覆盖范围比压缩效率更影响后续扩展能力。两者的差异根源在于任务目标不同：前者优化静态推理成本，后者优化动态扩展成本。本文未直接对比MorphBPE等形态感知方法，但暗示了形态结构在分词器设计中的重要性，因为语言桶加权隐含了形态相似性的假设。

从方法设计看，本文与CVA（Yamaguchi et al., 2024b）形成鲜明对比。CVA试图在预训练后通过嵌入映射解决分词器不匹配问题，而本文主张在预训练前解决。实验显示，CVA（平均初始化）在扩展语言上比CLUSTER分词器高12.8%胜率，但仍比UNIVERSAL分词器低7%。这一差异表明，预训练阶段的分词器覆盖比后训练阶段的嵌入修复更有效。本文未探索RL Tokenization等动态分词方法，但UNIVERSAL分词器的静态设计已能实现显著可塑性，暗示动态分词在适配场景下的必要性可能低于预期。

## 总结

本文要解决的核心矛盾是多语言大模型预训练后扩展新语言的高成本与低确定性。现有CVA方法因嵌入层重初始化导致性能波动，而本文抓住的切入点是预训练阶段分词器覆盖范围对模型参数空间的影响。通过引入覆盖62种语言的UNIVERSAL分词器并采用语言桶加权策略，本文证明了在预训练初期进行分词器设计干预能以极低的性能代价（主要语言胜率差异<0.3%）换取显著的适配增益（扩展语言胜率提升19.9%）。实验在3.3B参数规模下验证了这一结论，但边界在于未测试更大模型是否保持相同增益比例，以及语言桶加权策略在非欧洲语言家族中的普适性。当模型规模扩大至100B参数时，分词器覆盖范围与适配效率的关系是否仍呈线性，论文未给出回答。
