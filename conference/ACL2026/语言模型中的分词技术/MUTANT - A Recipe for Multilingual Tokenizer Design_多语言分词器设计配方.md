# ACL2026最新论文 ｜MUTANT: A Recipe for Multilingual Tokenizer Design ｜多语言分词器设计配方

作者：Souvik Rana、Ashish Kulkarni、Arul Menezes 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_c5d3b6071531)

> 多语言大语言模型（LLM）在低资源语言上面临分词碎片化导致的计算成本激增与语义断裂问题。现有静态分词器依赖单一统计频率驱动，无法兼顾形态学完整性与多词表达压缩，导致印度语言等高形态复杂度语言的生育率（Fertility）高达 10.5。本文提出 MUTANT 配方，通过语言感知预分词与两阶段子词-多词课程学习，在印度语言上实现了平均生育率较 LLaMA-4 降低 39.5% 的效率提升。该方案在特定语言集群内验证了显著优势，但其通用性受限于对高质量语言特定正则规则的依赖，且未解决动态分词粒度下的系统级加速瓶颈。

## 研究背景

当 LLM 处理非英语文本时，标准字节对编码（BPE）往往将单个语义单元拆分为多个子词，这一现象称为分词碎片化。碎片化直接推高了序列长度，增加了推理延迟，并破坏了词素边界，阻碍模型对形态丰富语言的组合性理解。为量化这种不公，研究者引入了生育率（Fertility）指标，即 token 数与词数之比，低生育率意味着更高的压缩效率与更低的计算开销。然而，现有分词器在英语等高资源语言上优化过度，导致低资源语言在相同语义内容下需消耗数倍于英语的 token 资源，形成了结构性的“词元税”。

主流子词分词算法如 BPE 和 UnigramLM 基于统计频率合并字符对，其核心假设是高频合并能最优平衡覆盖率与效率。这一假设在形态简单的语言中成立，但在黏着语或屈折语中失效，因为统计频率无法捕捉词素边界的语言学约束。SuperBPE 等近期工作尝试通过两阶段课程学习引入多词表达，但缺乏对预分词规则的语言特定优化，导致跨脚本干扰与分布失衡。MUTANT 的切入点在于将分词器设计视为一个系统工程问题，而非单纯的算法优化，通过显式控制数据分布、词汇表分配与预分词规则，解决低资源语言在通用分词器中的系统性劣势。

## 核心方法

### 方法参照系

本文问题属于多语言公平性优化与形态感知分词的交叉路线。标准 BPE 流程为单阶段统计合并，本文的关键差异在于引入语言特定的正则化预分词，并将训练过程解耦为子词学习与多词学习两个阶段，以在保持子词覆盖度的同时捕获高频短语。

### 语言感知预分词与词汇分配

预分词是决定 token 边界的上游组件，通常采用通用正则表达式。本文针对印度语言引入 Unicode 归一化（NFKC）与形态感知正则，将视觉上相同的字符标准化，并分离标点与数字组，从源头减少正字法稀疏性。设计动机在于解决通用正则（如 GPT-2 规则）在处理含大量组合字符的语言时，将单个语义单元拆分为多个预 token 的问题。实验显示，采用 LLaMA-4 正则替代 GPT-2 规则，在印度语言上将 token-to-word 比率降低了 38–40%。词汇表分配采用语料驱动对齐策略，即训练单一分词器于多语言语料，其数据比例与目标脚本词汇预算对齐，而非显式合并脚本特定分词器。该策略避免了显式合并导致的跨脚本分布干扰，使学习到的词汇表自然收敛至目标比例，实现了更低的生育率。

### 两阶段子词-多词课程学习

在预分词完成后，本文采用两阶段 BPE 训练。第一阶段在空白预分词约束下学习子词，直至词汇表达到过渡点 $t$；第二阶段移除空白约束，允许跨词合并以形成多词表达。这一设计解决了单阶段 BPE 无法同时优化细粒度子词与粗粒度短语的矛盾。嵌入初始化采用线性插值策略，对于新分词器中未在原模型词汇表中的 token $t$，若其可分解为原词汇表中的 $(t_1, ..., t_k)$，则初始化嵌入为：

$$ E_{init}(t) = \frac{1}{k} \sum_{i=1}^{k} E_{orig}(t_i) $$

该公式确保了分词器替换后的模型在持续预训练（CPT）中保持语义连续性，避免了嵌入层重初始化带来的性能波动。第二阶段引入句子级边界约束，防止跨句合并导致生成不稳定，同时保留多词建模的收益。

## 实验评估

实验在包含 22 种印度语言、英语及代码的自建语料上进行，对比了 Sutra、Sarvam、Gemma-3、LLaMA-4 等 9 种分词器。基线覆盖了印度语言专用与通用多语言分词器，但缺失 UnigramLM 等概率模型基线，且未包含 FLORES-200 等标准多语言基准，限制了跨语言家族的直接比较。

| Tokenizer | Fertility (↓) | NSL (↓) | BPT (↑) |
| :--- | :--- | :--- | :--- |
| LLaMA-4 | 4.40 (as) | 0.99 | 3.84 |
| Sutra | 2.12 (as) | 0.55 | 8.04 |
| MUTANT-Indic | 1.85 (as) | 0.45 | 9.12 |

MUTANT-Indic 在 20/24 种语言上取得最低生育率，平均较 LLaMA-4 降低 39.5%，较 Sutra 降低 18%。NSL 指标显示其序列长度显著缩短，BPT 指标表明 token 信息密度更高。在下游任务上，使用 MUTANT-Indic 预训练的 LLaMA-3.2-1B 在英语与印度语言基准上与 LLaMA-4 分词器模型性能相当，平均准确率分别为 0.279 和 0.394，证明效率提升未以牺牲精度为代价。

消融实验显示，语料驱动对齐优于显式合并，后者在 6 种语言上生育率均高于前者。两阶段训练中，仅第一阶段（子词学习）已能取得 SOTA 性能，表明多词学习的边际收益有限，主要贡献在于压缩常见短语。推理延迟测试中，MUTANT-Indic 模型的输出吞吐量（OTPT）从 117.99 tokens/s 提升至 169.42 tokens/s，TTFT 从 19.17ms 降至 18.98ms，验证了分词效率对系统级延迟的直接影响。

评估边界方面，本文使用自建印度语言语料，分布偏差可能导致生育率指标被低估，且未报告置信区间。代码与数据集已公开，但超参数细节（如过渡点 $t$ 的具体值）未在正文中明确列出，复现需依赖附录。

## 关联研究分析

从问题动机看，MUTANT 与 Token Tax Analysis 共享对低资源语言计算不公的批判，但前者提供了工程化解决方案，后者仅量化了问题。MUTANT 的预分词优化直接回应了 Pre-tokenization Ceiling Analysis 指出的“预分词规则构成效率天花板”这一发现，通过修改正则而非增加数据来突破下限。与 MorphBPE 相比，MUTANT 侧重多词表达捕获而非词素对齐，这源于印度语言中高频短语（如“in the morning”）对压缩率的贡献大于词素边界完整性。

从方法设计看，MUTANT 继承 SuperBPE 的两阶段框架，但改造了词汇分配策略。SuperBPE 采用通用多语言语料，MUTANT 采用脚本感知预算，这解决了跨脚本干扰问题。然而，MUTANT 未探索动态分词粒度，其两阶段训练仍是静态的，无法适应 OOD 数据分布变化。与 HAT 等无分词架构相比，MUTANT 保留了固定词汇表，牺牲了鲁棒性以换取部署成熟度与低延迟。这种取舍在印度语言这一特定场景下是合理的，但在长上下文与新领域适应场景中可能失效。

## 总结

MUTANT 旨在解决多语言分词器在低资源语言上的效率与公平性矛盾，其切入点在于将预分词规则与词汇分配作为显式设计变量，而非依赖纯统计学习。通过语言感知正则与两阶段课程学习，MUTANT-Indic 在印度语言上实现了平均生育率降低 39.5% 与推理吞吐量提升 44% 的双重收益，且未牺牲下游任务精度。该方案的边界在于其依赖高质量的语言特定正则规则，且两阶段训练仍是静态的，无法动态适应分布外数据。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
