# ACL2026最新论文 ｜R2IF: Aligning Reasoning with Decisions via Composite Rewards for Interpretable LLM Function Calling ｜推理对齐函数调用

研究机构：华东师范大学、华中科技大学

作者：Aijia Cheng、Kailong Wang、Ling Shi 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.20316)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.20316)

> 大语言模型在函数调用任务中常出现“答案正确但推理空洞”的错位，导致模型在未见过的参数格式或复杂约束下泛化能力脆弱。现有基于强化学习的方法多依赖二元结果奖励，无法区分“碰巧正确”与“逻辑严密”的轨迹，使得推理过程沦为事后合理化而非决策依据。R2IF 通过引入基于分布的链式思维有效性奖励与参数级规范-修改-值奖励，在 GRPO 框架下强制推理与工具调用决策在语义和结构上对齐。该方法在 BFCL 和 ACEBench 上显著提升了小模型的调用准确率与推理有效性，但其对训练数据规模的依赖及 CER 计算开销限制了其在大规模实时场景中的直接部署。

## 研究背景

函数调用要求模型将自然语言查询映射为精确的可执行 API 调用，这一过程不仅涉及工具选择，更依赖对参数格式、默认值及类型转换的严格遵循。当模型仅被训练去匹配最终答案时，其生成的推理链往往缺乏对参数约束的显式处理，例如忽略“City, State”格式要求或遗漏默认单位，导致在分布外（OOD）查询中频繁失败。这种推理与决策的脱节，使得模型在遇到未见过的参数组合时，无法通过逻辑推导补全缺失信息，而是依赖记忆中的模式匹配，从而丧失了鲁棒性。

早期函数调用研究主要依赖监督微调（SFT），但高质量可执行轨迹的稀缺限制了模型泛化能力。随着强化学习（RL）在推理任务中的应用，基于可验证奖励的强化学习（RLVR）成为主流，通过环境反馈优化策略。然而，现有 RL 方法如 Tool-R1 和 ToolRL 多采用二元结果奖励，仅评估最终调用是否正确，忽略了推理过程对参数构造的支撑作用。这种结果导向的奖励机制导致模型可能通过浅层规则或猜测获得正确结果，而推理过程并未真正理解工具规范，形成了“正确但不可解释”的脆弱状态。R2IF 的切入点在于将可解释性形式化为推理与执行决策的对齐，通过细粒度奖励信号解决信用分配稀疏问题，使模型在生成正确调用的同时，必须提供支撑参数构造的逻辑依据。

## 核心方法

### 方法参照系

R2IF 基于分组近端策略优化（GRPO）框架，该框架通过组内奖励归一化稳定策略更新。标准 GRPO 流程中，奖励函数通常仅包含格式有效性与调用正确性的二元信号，导致模型在优化过程中缺乏对推理质量的直接监督。R2IF 的关键差异在于将奖励函数扩展为复合结构，引入分布基推理有效性度量与参数级语义对齐机制，从而在策略优化中同时约束动作正确性与推理逻辑性。

### 链式思维有效性奖励

传统二元奖励无法区分推理是否真正辅助了决策，R2IF 引入链式思维有效性奖励（CER）以量化推理前缀对工具调用成功的贡献。该奖励通过对比学生模型在给定推理前缀下的采样成功率与无推理基线成功率，计算推理的边际效用。

$$
R_{cer} = v(R|Q, T) - v_{base}(Q, T)
$$

其中 $v(R|Q, T)$ 为条件于推理前缀 $R$ 的成功率，$v_{base}(Q, T)$ 为无推理基线成功率。这一设计迫使模型生成能够实质性提升后续调用准确率的推理，而非仅满足格式要求的冗长文本，解决了二元奖励下推理过程缺乏优化信号的问题。

### 规范-修改-值奖励

CER 提供了推理整体有效性的信号，但未能细化到参数级别。R2IF 进一步提出规范-修改-值（SMV）奖励，显式监督推理中对参数规范识别、必要修改及最终值实例化的支持程度。对于匹配的工具调用，SMV 计算推理片段与真值文档中规范、修改描述的语义相似度，并验证最终值是否被正确实例化。

$$
R_{smv} = \frac{1}{|P_j^*|} \sum_{p \in P_j^*} \left( r_{spec}(p) + r_{mod}(p) + r_{val}(p) \right)
$$

其中 $r_{spec}$ 和 $r_{mod}$ 基于语义相似度阈值门控，$r_{val}$ 为硬执行信号。该机制确保模型不仅生成正确的参数值，更在推理中明确阐述参数约束与转换逻辑，增强了模型在未见参数格式下的泛化能力与可解释性。

## 实验评估

实验在 BFCL 和 ACEBench 基准上进行，骨干模型包括 Qwen2.5 (1.5B/3B/7B) 和 Llama3.2-3B。基线涵盖原始指令模型、SFT、二元奖励 GRPO 及 ToolRL。R2IF 在所有骨干模型上均取得最高整体准确率，其中 Llama3.2-3B 在 BFCL 上从 37.59% 提升至 72.21%，增幅达 34.62%。

| 模型 | 方法 | BFCL Overall | ACEBench Overall |
| :--- | :--- | :--- | :--- |
| Llama3.2-3B | Raw | 40.50 | 25.43 |
| Llama3.2-3B | R2IF | 72.21 | 72.90 |
| Qwen2.5-7B | Raw | 55.50 | 61.77 |
| Qwen2.5-7B | R2IF | 72.14 | 77.17 |

消融实验显示，移除 SMV 奖励导致 BFCL Live 场景性能显著下降，表明参数级监督对分布外泛化至关重要；移除 CER 则主要影响 ACEBench Single-Turn 性能，证实 CER 在复杂推理任务中的稳定性作用。SFT 冷启动对 3B 模型尤为关键，移除后准确率降幅大于 7B 模型，反映小模型对结构化输出先验的依赖。

评估边界方面，实验仅覆盖单轮函数调用，未涉及多轮交互或长程依赖场景。CER 计算依赖学生模型多次采样，引入额外计算开销，论文未报告具体延迟数据。代码未公开，但训练使用 6 块 NVIDIA RTX PRO 6000 GPU，超参数细节见附录。

## 关联研究分析

从问题动机看，R2IF 与 Tool Zero 形成鲜明对比。Tool Zero 摒弃 SFT 冷启动，通过动态泛化引导奖励实现纯 RL 训练，强调探索未知策略；而 R2IF 保留 SFT 阶段，侧重于在已有模板基础上优化推理-决策对齐。这一差异源于任务特性：函数调用对格式严格性要求极高，小模型缺乏足够的先验来稳定生成可执行轨迹，纯 RL 易陷入格式错误导致的零奖励陷阱。R2IF 的选择表明，在结构化输出任务中，SFT 提供的语法稳定性是 RL 有效优化的前提，而非可省略的冗余步骤。

从方法设计看，R2IF 的 SMV 奖励与 TRM（工具调用奖励模型）同属过程奖励范畴，但路径不同。TRM 提供轮次级效用信号，依赖外部裁判模型评估步骤质量；R2IF 则通过解析推理文档与真值文档的语义对齐，实现无需外部裁判的参数级监督。这种程序化奖励设计降低了训练成本，但依赖于真值文档中规范与修改描述的准确性。若工具规范复杂或描述模糊，SMV 的语义相似度计算可能引入噪声，这一局限在论文中未充分讨论。

## 总结

R2IF 针对函数调用中推理与决策错位的核心矛盾，通过复合奖励机制将可解释性形式化为参数级对齐，解决了二元奖励下推理过程缺乏优化信号的问题。该方法在 BFCL 和 ACEBench 上验证了有效性，Llama3.2-3B 的 34.62% 增幅及正值的平均链式思维有效性（ACE）表明，结构化推理监督能同时提升准确率与鲁棒性。然而，实验局限于单轮场景，且 CER 的采样开销与 SMV 对真值文档质量的依赖，限制了其在大规模动态工具生态中的扩展性。当工具规范描述存在歧义或参数组合高度复杂时，语义相似度门控是否仍能可靠区分有效推理与巧合正确，论文未给出回答。
