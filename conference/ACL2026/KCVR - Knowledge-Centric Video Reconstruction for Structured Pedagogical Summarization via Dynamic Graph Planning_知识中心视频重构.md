# ACL2026最新论文 ｜KCVR: Knowledge-Centric Video Reconstruction for Structured Pedagogical Summarization via Dynamic Graph Planning ｜知识中心视频重构

作者：Jingjiang Liu、Jia Zhu、Hanghui Guo 等 13 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_bbc566ea1d55)

> 教学视频摘要的核心矛盾在于，现有模型擅长提取视觉高光片段，却常破坏教学内容的先决逻辑顺序，导致结论先于前提出现的逻辑倒置。本文提出结构-教学重构（SPR）任务，将摘要目标从内容压缩转向恢复符合先决顺序的知识路径。KCVR 框架通过神经符号流水线，将证据感知的规划与拓扑感知的生成解耦，利用动态图剪枝和约束解码强制遵循教学拓扑。该框架在自建基准上显著提升了结构一致性，但其性能高度依赖预定义知识图谱，在开放域视频中的泛化能力仍存疑。

## 研究背景

理解本文需厘清多模态大语言模型（MLLM）在长视频理解中的局限。MLLM 通过概率解码生成文本，其本质是预测下一个最可能的词元，这种机制在开放域视频摘要中表现良好，但在教学视频中却暴露出与教学拓扑的错位。教学视频（如数学推导）依赖严格的先决顺序，黑板上的视觉布局往往承载了关键的推导步骤，而 MLLM 缺乏显式的依赖表示，容易在解码时“向前看”，生成尚未在视频中出现的概念，即逻辑倒置。此外，现有的检索增强生成（RAG）方法通常将知识图谱（KG）作为静态上下文追加到提示中，这种“语义优先”的检索方式忽略了视觉证据的缺失，导致模型基于拓扑有效但视觉不存在的节点进行生成，引发结构幻觉。

视频摘要领域的主流路线从早期的视觉显著性检测（如 DSNet）演进至基于 CLIP 的跨模态对齐（如 VideoXum），这些方法将视频视为扁平的时间流，擅长定位视觉高光，但无法建模刚性的先决链条。随着 Video-LLaMA2 等长上下文视频模型的出现，模型具备了处理长序列的能力，但缺乏课程约束，仍会生成局部合理但教学顺序错误的解释。本文的切入点在于，将知识图谱从被动的上下文缓冲区转变为主动的逻辑约束，通过“规划-生成”范式，在生成前动态剪枝出视频支持的子图，并在解码时强制遵循该拓扑结构，从而解决概率解码与教学逻辑的根本冲突。

## 核心方法

### 方法参照系

本文问题最接近的通用流程是检索增强生成（RAG），其标准步骤为：检索相关文档片段 -> 拼接至提示 -> 生成摘要。关键差异在于，本文的 RAG 变体（GraphRAG）检索的是结构化知识图谱而非文本片段，且本文指出静态检索无法保证视觉证据支持，因此引入了动态规划阶段，将“检索”升级为“规划”，将“拼接”升级为“约束解码”。

### 动态子图规划

针对结构幻觉问题，SG-Planner 在生成前对知识图谱进行动态剪枝。传统 RAG 基于语义相似度检索邻居，但语义相关的节点可能在当前视频帧中并未出现。SG-Planner 将剪枝建模为预算约束下的选择问题，最大化证据相关性与课程对齐度的加权和：

$$ V^*_{sub} = \arg \max_{S \subseteq U_{cand}, |S| \le B} \sum_{u \in S} (s_{kc}(u) + \lambda \cdot C(u)) $$

其中 $s_{kc}(u)$ 是概念 $u$ 的检索相关性分数，$C(u)$ 是课程先验（指示 $u$ 是否属于当前教学点范围），$\lambda$ 平衡证据与课程对齐。该公式的物理含义是，在有限的概念预算 $B$ 内，优先选择那些既在视频中视觉证据充分，又符合当前教学大纲范围的概念，从而剔除“拓扑有效但视觉缺失”的分支，生成最小化的视频支持计划 $\pi$。

### 拓扑约束解码

针对逻辑倒置问题，ACP 模块在解码阶段强制遵循计划 $\pi$ 的顺序。MLLM 的提示注入仅是软约束，模型仍可能生成未来概念。ACP 通过调制词元分布，抑制严格未来概念的别名，促进当前概念的别名：

$$ z'_t = z_t + \beta \cdot \mathbb{1}_{A(\pi_k)} - \gamma \cdot \mathbb{1}_{F(\pi_{>k})} $$

其中 $z_t$ 是原始 logits，$\mathbb{1}_{A(\pi_k)}$ 是当前概念 $\pi_k$ 的别名指示函数，$\mathbb{1}_{F(\pi_{>k})}$ 是未来概念集合的别名指示函数，$\beta$ 和 $\gamma$ 是调节强度的超参数。该机制将恢复的计划从软提示转化为显式拓扑先验，在解码时直接抑制违反先决顺序的词元概率，从而在保持语言流畅性的同时，确保生成内容严格遵循教学逻辑。

## 实验评估

实验在自建基准 EduStruct 上进行，该基准涵盖 10 个学科、460+ 视频，并配备双层认知图谱。基线包括 SFT（监督微调）、Text-RAG（文本检索增强）和 GraphRAG（图检索增强）。KCVR 在知识进展一致性（KPC）和学习目标覆盖（LOC）指标上显著优于基线。

| 方法 | R1 | C-F1 | KPC | LOC |
| :--- | :--- | :--- | :--- | :--- |
| InternVL3 (SFT) | 41.20 | 65.43 | 56.52 | 54.89 |
| + Text-RAG | 41.96 | 67.59 | 59.82 | - |
| + Planner | 42.60 | 68.40 | 62.10 | - |
| + KGVA only | 42.96 | 69.05 | 63.22 | - |
| + ACP only | 42.85 | 69.20 | 64.43 | - |
| + KGVA+ACP | 43.30 | 69.80 | 65.60 | - |
| Full (w/ GKS) | 43.68 | 70.83 | 66.79 | 63.11 |

主结果显示，KCVR 全模型 KPC 达到 66.79，较 SFT 基线提升 10.27 点，较 GraphRAG 基线提升 6.97 点。消融实验表明，SG-Planner 是最大单步增益来源（+2.28 KPC），验证了动态剪枝对先决顺序的关键作用。在固定规划器后，ACP 单独使用的 KPC 增益（+2.33）大于 KGVA 单独使用（+1.12），表明抑制未来概念比视觉锚定对结构一致性贡献更大。两者结合后，KPC 进一步提升至 65.60，显示视觉锚定与约束解码具有互补性。

评估边界方面，KPC 和 LOC 指标依赖预定义知识图谱，若图谱构建存在偏差，指标可能失真。论文未报告计算效率的具体 FLOPs 或延迟数据，仅声称规划器开销小于 5%。代码已开源，但 EduStruct 基准未公开，限制了外部复现性。

## 关联研究分析

从问题动机看，KCVR 与 GraphRAG 的核心差异在于对“检索”的定义。GraphRAG 将检索视为证据获取，假设检索到的子图即为生成依据；而 KCVR 指出检索不等于证据，拓扑有效的节点可能视觉缺失。这一差异源于任务特性：教学视频要求视觉证据与逻辑顺序的双重一致性，而通用问答任务仅关注语义相关性。KCVR 通过动态剪枝解决这一冲突，但这也意味着其性能上限受限于知识图谱的覆盖范围，在图谱缺失的领域（如 InfoTech），KPC 下降 10.7%，表明方法尚未实现从视频流中自主发现知识结构。

从方法设计看，KCVR 与 NeuroLogic Decoding 均采用约束解码，但约束来源不同。NeuroLogic Decoding 使用逻辑谓词约束词元序列，适用于通用文本生成；KCVR 使用教学拓扑约束，适用于结构化知识重构。这一差异源于约束的粒度：逻辑谓词是静态的、通用的，而教学拓扑是动态的、领域特定的。KCVR 的 ACP 模块通过别名集合实现约束，避免了硬约束导致的流畅性损失，但这也引入了对概念别名定义的依赖，若别名定义不完整，约束可能失效。

## 总结

KCVR 解决了教学视频摘要中概率解码与教学拓扑错位的核心矛盾，通过神经符号框架将知识图谱从被动上下文转变为主动逻辑约束。其切入点在于，现有 RAG 方法忽略视觉证据缺失导致的结构幻觉，而 MLLM 的概率解码无法保证先决顺序。KCVR 通过 SG-Planner 动态剪枝生成视频支持计划，并通过 ACP 约束解码强制遵循该计划，在自建基准上实现了 KPC 66.79 和 LOC 63.11 的性能。然而，实验暴露了方法对预定义知识图谱的强依赖，在图谱缺失的 InfoTech 领域，KPC 下降至 59.67，仅保留约 89% 的域内性能。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
