【CodeHacker: Automated Test Case Generation for Detecting Vulnerabilities in Competitive Programming Solutions ｜代码感知对抗性测试生成

研究机构：西北工业大学、美团

作者：Jingwei Shi、Xinxiang Yin、Jing Huang 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.20213)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.20213)

> 竞赛编程评估长期受困于测试用例覆盖不足导致的“假阳性”，即错误代码因未触及边界而通过测试。现有自动化生成方法多依赖概率性输入变异或基于问题描述的提示生成，本质上是黑盒模糊测试，缺乏对具体代码逻辑漏洞的针对性。本文提出 CodeHacker，将竞赛编程中的“Hack”机制形式化为对抗性测试生成任务，通过代码感知策略主动搜索能触发特定提交失败的输入。该方法显著提升了基准测试的真阴性率，验证了自动化对抗生成在纠正评估偏差上的有效性，但其结论局限于 C++ 竞赛场景，向仓库级工程的迁移性尚存疑。

【CodeRipple: Wavelet-Based Detection of LLM-Generated Code ｜基于小波变换的LLM生成代码检测

作者：Xingyu Yao、Zhendong Mao、Quan Wang

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_8f7185986b6b)

> 现有无训练代码检测器依赖全局困惑度统计，在代码语法强约束下失效。CodeRipple指出LLM与人类代码在全局统计收敛时，局部Token Perplexity Sequence (TPS) 动态存在显著差异：前者呈窄瞬态尖峰，后者呈宽持续波动。该方法利用平稳小波变换 (SWT) 建模形态、离散小波变换 (DWT) 量化能量分布，实现无训练检测。其在多基准上显著优于基线，但对高结构化对抗策略及低资源语言泛化能力存疑。

【CodeRL+: Improving Code Generation via Reinforcement with Execution Semantics Alignment ｜执行语义对齐强化学习

研究机构：北京大学、阿里巴巴集团

作者：Xue Jiang、Yihong Dong、Mengyang Liu 等 13 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.18471)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.18471)

> 大语言模型在代码生成上面临文本模式与执行语义的错位，现有强化学习仅依赖稀疏的通过/失败奖励，难以纠正细微逻辑错误。本文提出CODERL+，将执行轨迹推断作为密集奖励信号整合进训练流程。该方法利用失败样本动态构建对齐任务，在7B开源模型上显著提升了代码生成与推理性能。其价值在于提供了可验证的语义监督，但受限于小模型容量，绝对性能仍远低于闭源SOTA。

【CoreCodeBench: Decoupling Code Intelligence via Fine-Grained Repository-Level Tasks ｜解耦代码智能：基于细粒度仓库级任务的CoreCodeBench

研究机构：上海交通大学、美团

作者：Lingyue Fu、Hao Guan、Bolun Zhang 等 12 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_a0cd090642bc)

> 现有代码评估基准将编程能力视为单一整体，通过粗粒度通过率掩盖了模型在不同工程场景下的认知瓶颈。静态基准面临数据污染与性能饱和的双重失效，而端到端仓库级任务又因复杂度过高难以定位具体缺陷。CoreCodeBench通过COREPIPE管道将同一代码上下文拆解为开发、修复与测试驱动三类原子任务，实现认知维度的隔离评估。该框架揭示了模型能力的非单调性，但原子任务解耦是否削弱了真实工程中的耦合效应，仍存疑。

【KOCO-BENCH: Can Large Language Models Leverage Domain Knowledge in Software Development? ｜领域知识驱动的代码生成基准

研究机构：北京大学、武汉大学

作者：Xue Jiang、Ge Li、Jiaru Qian 等 14 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.13240)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.13240)

> 大语言模型在通用编程任务上已接近饱和，但在涉及私有API、复杂依赖与隐式规则的垂直领域开发中表现急剧下滑。现有领域基准仅测试模型“已知”的知识，无法评估其从外部语料中“学习并应用”新知识的能力，导致领域特定化方法缺乏统一的评估标尺。KOCO-BENCH通过构建包含框架文档、源码与示例的知识语料库，并配套多粒度代码生成与知识理解任务，首次实现了对领域知识获取过程的可控评估。该基准揭示了当前SOTA模型在领域任务上的严重短板及现有特定化方法的边际效应，但其在语料规模扩展下的泛化能力与跨域迁移的稳定性仍存疑。

】
