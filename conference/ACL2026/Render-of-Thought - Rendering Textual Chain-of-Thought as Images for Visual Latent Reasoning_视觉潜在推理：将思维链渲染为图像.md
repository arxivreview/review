# ACL2026最新论文 ｜Render-of-Thought: Rendering Textual Chain-of-Thought as Images for Visual Latent Reasoning ｜视觉潜在推理：将思维链渲染为图像

研究机构：清华大学、北京大学

作者：Yifan Wang、Shiyu Li、Peiming Li 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.14750)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.14750)

> 长思维链（Chain-of-Thought, CoT）推理在提升大语言模型复杂任务准确率的同时，因自回归逐词解码导致计算开销与延迟激增。现有潜在推理方法虽将推理压缩至连续空间，但缺乏对中间步骤的监督，导致推理过程不可解释且训练不稳定。本文提出 Render-of-Thought (RoT)，将文本推理步骤渲染为单行图像，利用冻结的视觉编码器提取特征作为语义锚点，引导模型在视觉潜在空间进行自回归推理。该方法实现了 3-4 倍的 Token 压缩与显著延迟降低，但在高难度数学任务上的准确率仍显著低于显式 CoT 基线，其视觉锚点机制对复杂逻辑推理的增益边界尚待验证。

## 研究背景

当模型处理多步算术或逻辑问题时，生成冗长的文本推理链是提升准确率的有效手段，但自回归机制使得计算复杂度随链长线性增长。为突破离散 Token 的表达瓶颈，潜在推理范式将中间步骤映射为连续向量，然而这些向量通常缺乏显式语义约束，导致模型内部逻辑成为“黑箱”，难以诊断错误。视觉模态具有高密度信息承载能力，且预训练视觉语言模型（Vision Language Models, VLMs）的视觉编码器已具备强大的语义理解能力，这为将文本推理转化为结构化视觉特征提供了物理基础。

CoT 效率优化领域已形成显式压缩与潜在推理两条主线。显式方法如 UCoT 和 SLAT 通过语义剪枝或自适应截断在保持可解释性的同时降低 Token 数，但在 GSM8K 等基准上准确率可达 90% 以上；潜在方法如 Coconut 和 CODI 虽提升了推理带宽，但准确率在隐式推理子集上仅徘徊于 39%-45% 区间，且面临训练不稳定与表示对齐困难。现有潜在推理框架多依赖从零学习推理 Token 或复杂架构，缺乏对中间推理过程的有效监督。RoT 的切入点在于利用 VLM 中现成的视觉编码器作为外部语义锚点，通过“文本转图像”的渲染机制，将离散的文本逻辑转化为连续的视觉特征序列，从而在无需额外预训练的前提下，为潜在推理提供可观测、可对齐的监督信号。

## 核心方法

### 方法参照系

潜在推理的标准流程通常直接优化 LLM 隐层状态或引入专用架构，通过自蒸馏将文本 CoT 压缩至连续空间。RoT 的关键差异在于引入了外部模态作为监督源：它不依赖 LLM 自身的隐层自回归，而是将文本 CoT 渲染为图像，利用冻结的视觉编码器提取特征作为对齐目标，将推理过程锚定在预训练视觉特征空间中。

### 视觉渲染与语义锚点

传统潜在推理中，连续向量缺乏显式语义约束，导致模型难以区分推理步骤的逻辑差异。RoT 在输入端引入 CoT 渲染模块，将文本推理步骤转换为单行、动态宽度、固定高度（32 px）的图像。这种布局确保图像补丁按从左到右的顺序提取，自然对齐文本顺序。视觉编码器处理该图像，提取目标视觉嵌入 $\mathbf{V} = \{v_1, v_2, \dots, v_K\}$，其中 $v_i \in \mathbb{R}^{d_v}$。这一设计将离散的文本逻辑转化为结构化的视觉特征，为后续对齐提供了具有明确语义边界的监督信号，解决了纯潜在空间推理中“向量不可解释”的问题。

### 两阶段对齐与潜在微调

为将 LLM 的语言表示映射至视觉空间，RoT 采用两阶段训练。第一阶段冻结 LLM 骨干 $M$ 和视觉编码器 $V$，仅优化轻量级视觉投影头 $\phi$（两层 MLP，SwiGLU 激活）。在推理步 $t$，潜在嵌入 $\hat{v}_t = \phi(V(M(x, \langle\text{img\_begin}\rangle)))$ 与目标视觉嵌入 $v_t$ 通过均方误差（MSE）损失对齐：

$$ \mathcal{L}_{\text{align}} = \sum_{t=1}^{K} \| \hat{v}_t - v_t \|^2 $$

该公式强制 LLM 的隐层状态在输出端映射至视觉特征空间，实现模态对齐。第二阶段冻结视觉编码器和投影头，使用 LoRA 微调 LLM 骨干，使其能够自回归生成潜在视觉 Token 序列 $\hat{\mathbf{V}}$，并预测结束标记 $\langle\text{img\_end}\rangle$ 和最终答案 $y$。此阶段不再施加视觉回归损失，仅优化答案生成的交叉熵，允许模型在对齐的潜在空间内自主优化推理路径。

## 实验评估

实验在 GSM8k-Aug、GSM-Hard、SVAMP、MultiArith 及 MATH 数据集上进行，基线包括显式 CoT、无 CoT 的 SFT 以及 Coconut、CODI、CoLaR 等潜在推理方法。RoT 在 Qwen3-VL-4B-Instruct 上实现了 32 个潜在 Token 的固定预算，显著低于显式 CoT 的 108.4 个 Token。

| 方法 | GSM8k-Aug Pass@1 | GSM8k-Aug #L | MATH Pass@1 | MATH #L |
|---|---|---|---|---|
| SFT-CoT (Qwen3-VL-4B) | 81.2 ± 35 | 127.3 ± 96 | 55.8 ± 36 | 291.5 ± 1.9 |
| RoT (Ours) | 37.8 ± 30 | 32.0 ± 00 | 33.2 ± 37 | 64.0 ± 00 |
| CoLaR-2 (Qwen3-4B) | 6.00 ± 00 | 6.00 ± 00 | - | - |
| CODI (Qwen3-4B) | 16.9 ± 26 | 5.42 ± 28 | - | - |

RoT 在 GSM8k-Aug 上的准确率（37.8%）低于显式 CoT（81.2%），但高于 CoLaR-2（6.00%）和 CODI（16.9%）。在 MATH 数据集上，RoT 的准确率（33.2%）低于显式 CoT（55.8%），但高于无 CoT 基线（29.4%）。这表明视觉潜在推理在简单算术任务上具有竞争力，但在复杂数学推理上仍面临精度瓶颈。

| 消融配置 | GSM8k-Aug Pass@1 | MATH Pass@1 |
|---|---|---|
| RoT (Full) | 37.8 ± 30 | 33.2 ± 37 |
| w/o Stage I | 24.8 ± 28 | 22.2 ± 34 |
| w/o Stage II | 29.9 ± 28 | 26.2 ± 38 |
| Fixed 32 Tokens | 37.8 ± 30 | 33.2 ± 37 |
| Dynamic Termination | 3.87 | 2.20 |

移除第一阶段（视觉对齐）导致 GSM8k-Aug 准确率从 37.8% 降至 24.8%，表明视觉锚点对防止表示崩溃至关重要。动态终止策略（Special Tokens）的性能（3.87%）远低于固定 Token 预算（37.8%），证实了连续潜在空间中自调节停止机制的不稳定性。固定预算在 GSM8k-Aug 上最优值为 32 Token，而在 MATH 上为 64 Token，反映了任务复杂度对推理深度的需求差异。

评估协议基于 Pass@1 和平均 Token 长度，报告了 95% 置信区间。代码已开源，使用 Qwen3-VL 和 LLaVa-V1.6 作为骨干，LoRA 微调，AdamW 优化器。局限在于仅评估了英语数学任务，未覆盖常识推理或非英语场景，且最优 Token 预算需手动校准。

## 关联研究分析

从问题动机看，RoT 与 UCoT 和 SLAT 等显式压缩方法形成鲜明对比。UCoT 通过解耦压缩器与执行器，在 GSM8K 上达到 90.0% 的准确率，而 RoT 仅为 37.8%。这一巨大差距揭示了当前潜在推理范式在精度上的根本瓶颈：视觉锚点虽提供了可解释性，但连续向量在编码复杂逻辑步骤时的信息容量仍不足以替代显式文本。RoT 的切入点在于解决“可解释性”而非“精度”，这与显式方法追求“精度-效率帕累托最优”的目标存在本质差异。

从方法设计看，RoT 与 Coconut 和 CODI 同属潜在推理路线，但监督信号来源不同。Coconut 依赖 LLM 隐层自回归，CODI 通过自蒸馏压缩 CoT，两者均缺乏外部语义约束。RoT 引入冻结的视觉编码器作为锚点，利用了 VLM 预训练阶段积累的视觉-语言对齐知识。这种“即插即用”的设计避免了从零学习推理 Token 的不稳定性，但可能引入模态偏差：视觉特征是否真正捕捉了推理的逻辑结构，还是仅反映了文本的视觉布局？论文未提供消融实验来隔离视觉语义与视觉布局的贡献，这一盲区限制了对其机制有效性的深入理解。

## 总结

RoT 旨在解决潜在推理中缺乏中间步骤监督导致的不可解释性与训练不稳定问题。其核心创新在于将文本 CoT 渲染为图像，利用冻结的 VLM 视觉编码器作为语义锚点，通过两阶段训练实现 LLM 隐层与视觉特征的对齐。实验表明，该方法在 GSM8k-Aug 上以 32 个 Token 实现了 37.8% 的准确率，较显式 CoT 的 108.4 个 Token 显著压缩，但在 MATH 数据集上准确率（33.2%）仍低于显式 CoT（55.8%）。该方法的边界在于视觉锚点主要适用于简单算术任务，对复杂数学推理的逻辑编码能力有限，且最优 Token 预算需手动校准。当任务复杂度从 GSM8K 提升至 MATH 时，视觉潜在空间是否仍能保持对推理逻辑的有效编码，而非退化为简单的上下文维持机制，论文未给出明确回答。
