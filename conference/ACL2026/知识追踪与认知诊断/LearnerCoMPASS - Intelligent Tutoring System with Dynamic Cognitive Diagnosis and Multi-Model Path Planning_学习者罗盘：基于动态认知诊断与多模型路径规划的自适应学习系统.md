# ACL2026最新论文 ｜LearnerCoMPASS: Intelligent Tutoring System with Dynamic Cognitive Diagnosis and Multi-Model Path Planning ｜学习者罗盘：基于动态认知诊断与多模型路径规划的自适应学习系统

研究机构：华中科技大学、武汉大学

作者：Ziji Sheng、Guiyao Tie、Weidong Wang 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_d8efcc70ef42)

> 自适应学习系统需在逻辑严谨的STEM领域同时实现深度个性化、动态适应与内容可信，但现有LLM规划器面临诊断僵化、事实幻觉与规划短视三大瓶颈。本文切入点在于将离线训练的认知诊断重构为推理时的实时状态估计，并通过混合知识图谱与多智能体搜索闭环解决上述矛盾。其核心做法是构建一个包含动态知识图谱、多智能体编码器-解码器诊断模块及AB-MCTS-M路径规划引擎的端到端框架。该框架在STEM路径规划质量上显著优于基线，但其依赖静态知识图谱的冷启动成本与多智能体推理延迟是否满足实时辅导要求，仍存疑。

## 研究背景

智能辅导系统（Intelligent Tutoring Systems, ITS）的核心挑战在于将非结构化的学习目标转化为符合学习者认知状态的教学轨迹。传统基于ID嵌入的认知诊断模型（Cognitive Diagnosis Models, CDMs）依赖离线梯度更新，导致“诊断滞后”，无法捕捉实时辅导中的能力波动。同时，大语言模型（Large Language Models, LLMs）作为概率下一词元预测器，在STEM领域易产生事实幻觉，且标准解码策略缺乏长程视野，导致学习序列逻辑不一致。

现有LLM增强知识追踪路线主要聚焦于预测精度或解释生成，如RAG-KT通过检索增强抑制幻觉，Next Token KT将任务重构为词元预测。然而，这些方法多采用“预测-更新”的单向流程，缺乏对教学路径的全局优化能力。本文的切入点是将认知诊断从离线训练任务转化为推理时的实时状态估计问题，并引入多智能体协作与自适应分支蒙特卡洛树搜索（Adaptive Branching MCTS, AB-MCTS-M），实现“诊断-规划-反思”的闭环迭代。

## 核心方法

### 混合知识图谱与图检索增强生成

本文方法参照系为基于LLM的教育规划器，其标准流程通常依赖静态提示或简单检索。关键差异在于本文构建了“可信推理引擎”，通过混合知识图谱（Hybrid KG）提供结构化事实锚点。静态宏观知识图谱（$G_{static}$）编码先修依赖，动态微观知识图谱（$G_{dynamic}$）通过KG Agent实时构建以解决冷启动。系统通过图检索增强生成（Graph-RAG）将结构化上下文注入LLM提示，将教学任务形式化为条件推断 $P(y | q, \theta, G)$，确保输出在逻辑与事实上的严谨性。

### 多智能体实时认知诊断

传统CDM依赖离线训练，无法实时响应。本文设计多智能体编码器-解码器架构，将学习者建模为实时状态估计问题。设 $\theta \in \mathbb{R}^d$ 为能力向量，系统通过迭代最小化预测响应 $\hat{r}$ 与观测响应 $r_{obs}$ 的偏差来更新状态：

$$ \theta^* = \arg \min_{\theta} L(\hat{r}(q, \theta), r_{obs}) $$

该公式的物理含义是通过语义梯度下降，将自然语言归因映射为向量更新方向，实现无需重训练的实时能力追踪。编码器通过双向因果推断生成粗粒度初始化，解码器通过“预测-反思-更新”循环进行细粒度调优，解决了传统模型在稀疏交互下的状态漂移问题。

### AB-MCTS-M路径规划与反思机制

单一LLM缺乏长程规划能力。本文引入AB-MCTS-M算法，将路径生成建模为动态决策过程。节点奖励 $R(v_i)$ 采用贝叶斯分层混合模型：

$$ R(v_i) \sim N(\mu + \alpha_{g(v_i)}, \sigma^2), \quad \alpha_g \sim N(0, \tau^2) $$

该公式通过Thompson Sampling平衡探索（生成新路径）与利用（深化现有路径），其中 $\alpha_g$ 捕捉不同专家组的随机效应。此外，Reflexion机制将路径评估的言语批评存入向量记忆 $K_{mem}$，作为零样本提示注入后续规划，实现了无参数更新的长期策略进化。

## 实验评估

实验在Eedi、私有线性代数及STEM路径规划数据集上进行，基线包括DINA、IRT、NeuralCDM及GPT-4o CoT。在Eedi数据集上，本文ACC为0.678，优于NeuralCDM的0.640；在私有线性代数数据集上，ACC达0.822，显著高于NeuralCDM的0.745。

| 数据集 | 方法 | ACC | AUC |
| :--- | :--- | :--- | :--- |
| Eedi | NeuralCDM | 0.640 | 0.762 |
| Eedi | LearnerCoMPASS | 0.678 | 0.844 |
| Linear Algebra | NeuralCDM | 0.745 | 0.795 |
| Linear Algebra | LearnerCoMPASS | 0.822 | 0.841 |

消融实验显示，引入Graph-RAG将幻觉率从31.5%降至10.6%，完整系统进一步降至4.1%。路径质量评分（Likert 1-5）中，完整系统Overall得分4.67，优于GPT-4o CoT的3.63。

| 系统变体 | Overall Score | Hallucination Rate |
| :--- | :--- | :--- |
| Base LLM | 3.29 | 31.5% |
| w/ Graph-RAG ONLY | 4.10 | 10.6% |
| Full System | 4.67 | 4.1% |

评估边界方面，本文未报告推理延迟与GPU成本，且STEM数据集为私有构建，缺乏公开基准对比。代码未开源，超参数细节（如MCTS迭代次数）未完全披露，限制了可复现性。

## 关联研究分析

从问题动机看，本文与RAG-KT同属LLM增强路线，但RAG-KT聚焦于预测正确率的提升，而本文转向路径规划的逻辑一致性。差异根源在于任务特性：预测任务可容忍局部误差，而路径规划要求全局逻辑闭环，因此本文引入AB-MCTS-M进行全局搜索，而非仅依赖检索增强。

从方法设计看，本文与MAML-KT均解决冷启动问题，但MAML-KT通过元学习优化初始化参数，依赖少量交互数据；本文通过Reflexion记忆机制实现无参数更新，依赖历史规划的言语反馈。MAML-KT在数据充足时可能更稳定，而本文在数据稀疏但交互频繁的场景下更具优势。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文核心矛盾在于STEM领域自适应学习需同时满足实时诊断、事实可信与长程规划，而现有方法在离线训练与LLM幻觉间难以平衡。本文抓住“推理时状态估计”与“结构化知识约束”的切入点，通过多智能体编码器-解码器与AB-MCTS-M实现闭环。实验证明其在路径质量（4.67分）与幻觉抑制（4.1%）上优于基线。边界在于依赖静态知识图谱的冷启动成本与多智能体推理延迟未量化。当知识图谱覆盖度低于阈值时，动态构建的微观图谱是否会导致推理延迟指数级增长，论文未给出回答。
