【Attn-GS: Attention-Guided Context Compression for Efficient Personalized LLMs ｜注意力引导的个性化上下文压缩

研究机构：美国密歇根州立大学

作者：Shenglai Zeng、Tianqi Zheng、Chuan Tian 等 13 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_8072ed0f80fe)

> 个性化大语言模型（LLM）面临用户历史过长导致的推理延迟与成本瓶颈，现有启发式截断或盲目摘要方法忽略了模型内部对信号优先级的处理机制。本文切入点在于利用LLM自注意力分数作为重要性代理指标，识别关键个性化信号。方法通过白盒标记模型提取注意力权重，筛选高关注句子并引导摘要模型生成压缩画像。该策略在特定个性化任务上实现了50倍Token缩减且性能接近全上下文，但其有效性局限于静态画像场景，缺乏对动态交互及通用长文本压缩能力的验证。

【Beyond the Context Window: Scaling Agentic RL via End-to-end Optimized Context Compression ｜摘要增强策略优化

研究机构：美国斯坦福大学、美国卡内基梅隆大学

作者：Miao Lu、Weiwei Sun、Weihua Du 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_25abcbafe4d1)

> 长程智能体强化学习（RL）训练受限于固定上下文窗口，导致模型无法处理需多轮工具调用的复杂任务。现有静态截断或规则摘要方法无法在训练中动态适应任务需求，且摘要质量未参与梯度优化。本文提出 SUPO，将 LLM 生成的摘要作为策略动作纳入马尔可夫决策过程（MDP），通过策略梯度联合优化工具调用与摘要生成，使有效上下文扩展至工作窗口的 3-10 倍。该方法在代码与搜索任务上显著提升了任务完成率，但摘要触发机制仍依赖固定阈值，且未验证在密集奖励场景下的信用分配有效性。

【Bridging the Memorization-Utilization Gap: Near-Lossless Context Compression via Reinforcement Learning ｜强化学习驱动的软提示压缩：弥合记忆与利用鸿沟

作者：Yujan Ting、Xu Tang、Terrence Chen 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_11fab02f9fba)

> 导读 大模型上下文压缩旨在通过精简输入序列缓解 Transformer 二次方计算复杂度与 KV Cache 内存瓶颈，其核心价值在于提升长文本推理中的有效信息利用率。现有软提示压缩方法虽能实现高保真重构，但模型在下游任务中无法有效利用这些压缩表示，存在显著的“记忆-利用”鸿沟。本文提出一种基于结果导向强化学习（Reinforcement Learning, RL）的训练范式，激发模型在解码时进行隐式展开，按需重构相关片段。该方案在 16 倍压缩下恢复了 98% 的全上下文性能，但仅验证于问答任务，其向复杂代理任务的泛化能力存疑。

【Focus-dLLM: Accelerating Long-Context Diffusion LLM Inference via Confidence-Guided Context Focusing ｜置信度引导的稀疏注意力加速

研究机构：北京航空航天大学、香港科技大学

作者：Lingkun Long、Yushi Huang、Shihao Bai 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_85c91e34059b)

> 扩散大语言模型（Diffusion Large Language Models, dLLMs）通过迭代去噪实现并行文本生成，其双向全注意力机制在长上下文场景下导致推理吞吐量急剧下降。现有加速方法因无法预知当前步将被解码的Token位置，只能依赖粗糙的块级估计，导致计算冗余与精度损失并存。Focus-dLLM利用相邻去噪步间Token置信度的强正相关性，预测当前步的活跃查询位置，并结合跨层一致的注意力汇聚点（Attention Sink）复用机制，实现了免训练的稀疏注意力加速。该方法在32K上下文下取得29.6倍无损加速，但其在部分长文本子任务上的精度低于原生基线，揭示了速度-精度权衡中的隐性代价。

【Frozen LLMs are Native Decoders for High-Norm Semantic Vectors ｜冻结LLM解码高范数连续向量的几何机制与Landmark压缩框架

研究机构：北京邮电大学

作者：Yunsheng Zeng、Yongmei Tan

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_5378c9fbb94d)

> 长上下文压缩旨在通过精简输入序列缓解Transformer二次方计算复杂度与KV Cache内存瓶颈，但现有软压缩方法将冻结LLM视为黑盒，未解释模型如何解码承载复杂语义的连续向量。本文通过受控重建实验发现，成功压缩器生成的向量L2范数比标准词嵌入高两个数量级，且该高范数是冻结LLM成功解码的使能因子。基于此机制，论文提出Landmark-based无分块压缩框架，利用双向注意力聚合全局上下文。该工作揭示了软压缩的几何底层逻辑，但在多跳推理任务上表现弱于结构化方法，其高范数机制的普适性仍存疑。

【Glyph: Scaling Context Windows via Visual-Text Compression ｜视觉文本压缩

研究机构：清华大学、智谱AI

作者：Jiale Cheng、Yusen Liu、Xinyu Zhang 等 14 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.17800)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.17800)

> 长上下文推理面临计算与内存的双重瓶颈，传统Token级压缩在极高压缩比下易导致语义断裂或计算开销抵消加速收益。本文切入点在于利用视觉模态的高信息密度特性，将文本渲染为图像，以视觉Token替代文本Token，从而在固定窗口内处理更长的原始文本。具体做法是构建包含持续预训练、LLM驱动遗传搜索及后训练的三阶段框架，实现3-4倍Token压缩。该范式在效率与保真度间取得了新平衡，但其对渲染参数的敏感性及OCR精度瓶颈限制了其在极端场景下的泛化能力。

【GMSA: Enhancing Context Compression via Group Merging and Layer Semantic Alignment ｜分组合并与层语义对齐的上下文压缩框架

研究机构：清华大学、韩国首尔大学

作者：Jiwei Tang、Zhicheng Zhang、Shunlong Wu 等 11 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_e4db5de860b6)

> 长上下文推理面临计算复杂度与冗余信息的双重瓶颈，软提示压缩通过连续向量表示换取高压缩比，但现有自回归范式存在锚点 Token 语义主导与跨层语义错位两大缺陷。GMSA 针对此问题，提出基于编码器-解码器架构的压缩框架，引入分组合并机制均匀聚合语义，并设计层语义对齐模块桥接高低层表示鸿沟。该方法在多个长文本问答基准上超越了硬压缩与软压缩基线，但其均匀分组策略对细粒度依赖关系的保留能力尚存疑。

【Read As Human: Compressing Context via Parallelizable Close Reading and Skimming ｜人类阅读式混合上下文压缩

研究机构：清华大学、美国东北大学

作者：Jiwei Tang、Shilei Liu、Zhicheng Zhang 等 12 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_93dc3b525762)

> 长上下文推理面临计算复杂度与冗余信息的双重瓶颈，现有任务感知压缩方法要么全量加载导致效率低下，要么自回归压缩限制并行性，且难以兼顾关键信息保留与自然语言可解释性。RAM 将上下文压缩形式化为“精读”与“略读”的混合策略，通过并行分段编码与查询引导的自适应选择，在保留高相关文本的同时将低相关部分压缩为隐式向量。该方法在多个问答基准上超越基线，并在长输入上实现约 12 倍端到端加速，但其混合表示的语义对齐机制与跨模型泛化能力仍存疑。
