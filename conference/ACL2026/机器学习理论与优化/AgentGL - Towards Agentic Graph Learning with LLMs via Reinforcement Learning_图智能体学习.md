# ACL2026最新论文 ｜AgentGL: Towards Agentic Graph Learning with LLMs via Reinforcement Learning ｜图智能体学习

研究机构：美国纽约大学、清华大学

作者：Yuanfu Sun、Kang Li、Dongzhe Fan 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.05846)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_1cec3ab0053b)

> 文本属性图（TAGs）推理面临静态上下文注入无法适应动态证据需求的困境，现有GraphLLM与GraphRAG方法因缺乏拓扑感知的动态导航能力，在零样本迁移与长程依赖任务上表现受限。AgentGL将图学习重构为强化学习（RL）驱动的序列决策过程，通过图原生搜索工具与两阶段策略优化实现拓扑感知的动态推理。该方法在节点分类与链接预测上分别取得最高17.5%与28.4%的绝对提升，但其性能增益高度依赖RL训练稳定性，且未验证在超大规模图上的可扩展性。

## 研究背景

当LLM处理引文网络或社交图谱时，其参数化知识无法覆盖动态演化的领域事实，需借助外部证据。检索增强生成（RAG）通过静态检索补充事实，但将图结构简化为文本序列，丢失了拓扑依赖关系。图神经网络（GNN）擅长结构建模，却难以处理节点文本的深层语义，二者简单拼接导致跨模态语义理解浅层化。

该领域核心矛盾在于LLM缺乏原生图结构感知能力。主流路线分为两类：GraphLLM通过指令微调将图结构投影至LLM嵌入空间（如GraphGPT），但序列化过程导致全局拓扑信息损失；GraphRAG构建文本富集知识图谱，但重建成本高且未保留原生拓扑关联。这两类方法均依赖推理时一次性提取的静态图上下文，无法在证据不足时动态调整探索策略。AgentGL的切入点是将图学习视为序列决策过程，让LLM智能体自主导航图结构，通过多步搜索积累拓扑证据，而非依赖预计算的静态表示。

## 核心方法

### 方法参照系

本文问题最接近“LLM图推理智能体”路线，标准流程依赖启发式提示或单次前向传播完成多跳查询。关键差异在于：本文引入RL优化策略，将图导航建模为马尔可夫决策过程，通过奖励信号学习最优搜索轨迹，而非依赖固定规则。

### 图原生搜索工具与策略引导

设计动机：解决静态上下文注入无法适应实例依赖的邻域范围问题。传统方法固定搜索深度，但有效邻域范围随查询变化，盲目搜索引入结构噪声。AgentGL定义四个图原生工具：1-hop/2-hop邻域搜索（$\tau_{1HOP}, \tau_{2HOP}$）通过余弦相似度融合查询相关性与结构拓扑，公式为 $s(n) = \cos(h_n, \lambda_r h_Q + (1-\lambda_r) h_x)$，其中 $\lambda_r$ 平衡查询与目标对的语义权重；结构显著性搜索（$\tau_{SS}$）基于预计算PPR分数识别全局拓扑枢纽；图密集搜索（$\tau_{DENSE}$）用嵌入余弦相似度替代结构分数，桥接语义相关但拓扑不连通的节点。该工具集覆盖局部-全局、结构-语义两个维度，使LLM能按需选择探索粒度。

### 两阶段RL策略优化

设计动机：解决长程策略优化中缺乏逐步监督导致的策略漂移与过度搜索问题。第一阶段（GNSPB）使用复合奖励 $R(\tau) = r_{FMT}(\tau) + r_{ACC}(\hat{y}, y) + r_{COV}(\tau)$，其中 $r_{COV}(\tau) = \eta \sum_{j=1}^{|S|} I[\exists t: a_t = \tau_j]$ 鼓励覆盖所有工具类型，防止早期模式坍缩。第二阶段（MSO）移除 $r_{COV}$，引入认知密度正则化 $r_{depth}(z) = \alpha \cdot I[N_{short}=0] - \lambda_d \cdot N_{short}$，惩罚短于阈值 $\delta$ 的推理片段，强制智能体在搜索前进行深度分析。该阶段将优化目标约束为 $\theta^* = \arg\min_\theta E_{\tau \sim \pi_\theta}[T(\tau)]$ s.t. $\theta \in \arg\max_\vartheta J_{BASE}(\varphi)$，在保持精度的前提下最小化搜索步数 $T(\tau)$，实现“思考更多，搜索更少”的范式。

## 实验评估

实验在7个TAG数据集（OGB-Arxiv、PubMed、Amazon-Products等）上评估，对比13个基线，覆盖GNN、GraphLLM、GraphRAG、标准智能体搜索及纯LLM五类方法。基线审计显示，对比方法包含GraphGPT、GraphICL、Search-R1等代表性工作，但缺失NAG等原生架构方法，可能低估了架构级结构注入的竞争力。

| 方法 | OGB-Arxiv NC (In-Domain) | OGB-Arxiv NC (Zero-shot) | OGB-Arxiv LP (In-Domain) | OGB-Arxiv LP (Zero-shot) |
| :--- | :--- | :--- | :--- | :--- |
| AgentGL-R++ (Qwen7B) | 70.3 | 76.8 | 95.6 | 97.4 |
| AgentGL-GRPO (Qwen7B) | 68.9 | 77.0 | 95.9 | 96.5 |
| Search-R1 (Qwen7B) | 63.2 | 70.4 | 86.6 | 89.1 |
| GraphGPT (Qwen7B) | 53.8 | 59.1 | 50.5 | 48.2 |

AgentGL在Qwen7B骨干下，节点分类零样本迁移平均提升24.4%，链接预测域内提升26.3%。消融实验表明，仅保留GNSPB阶段时，模型消耗近满搜索预算但性能稳定；仅保留MSO阶段时，策略在训练中坍缩。两阶段协同训练节省约22%搜索成本，同时提升3%精度。$\lambda_r=0.5$ 时性能最优，验证了结构拓扑与语义相似度平衡的必要性。

评估边界：指标仅使用ACC，未报告置信区间或计算效率（如平均搜索步数、推理延迟）；零样本迁移仅在OGB-Arxiv与OGB-Products上训练后测试，未覆盖动态图或时间演化场景；代码已开源，但RL训练超参数（如 $\beta$、$\delta$）未详细披露，可复现性受限。

## 关联研究分析

从问题动机看，AgentGL与NAG代表结构感知的两条对立路径：NAG通过修改自注意力机制原生注入拓扑，追求架构级统一；AgentGL通过外部工具交互实现结构感知，保留LLM架构不变。差异根源在于任务特性：NAG适合语义主导的复杂推理，AgentGL在零样本迁移与效率敏感场景更优，但外部工具交互是否限制了LLM对深层拓扑的全局理解，论文未给出回答。

从方法设计看，AgentGL与Search-R1同属智能体搜索框架，但Search-R1针对非结构化文本，AgentGL引入图原生工具与图条件课程学习（GCCL）。GCCL利用图的拓扑先验（如同质性、度分布）解析难度，无需专家标注或试点rollout，这是文本智能体无法直接迁移的优势。然而，GCCL的难度评分函数 $S_{NC}(v)$ 依赖局部同质性估计，在异质图或动态图上是否仍有效，论文未探索。

## 总结

AgentGL要解决的核心矛盾是LLM静态上下文注入无法适应动态证据需求，其切入点在于将图导航建模为RL序列决策，通过图原生工具与两阶段策略优化实现拓扑感知的动态推理。该方法在节点分类与链接预测上分别取得最高17.5%与28.4%的绝对提升，证明了动态证据收集优于静态上下文填充。其边界在于：RL训练稳定性依赖两阶段协同，MSO阶段单独使用时策略坍缩；零样本迁移优势在大规模图上缩小（OGB-Arxiv LP零样本提升22.4%，而域内提升26.3%）。当图规模增至百万级节点时，RL策略的搜索预算与计算成本是否仍可控，论文未给出回答。
