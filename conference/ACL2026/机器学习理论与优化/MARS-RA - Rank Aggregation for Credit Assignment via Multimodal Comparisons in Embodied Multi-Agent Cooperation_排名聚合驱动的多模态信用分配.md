# ACL2026最新论文 ｜MARS-RA: Rank Aggregation for Credit Assignment via Multimodal Comparisons in Embodied Multi-Agent Cooperation ｜排名聚合驱动的多模态信用分配

研究机构：英国纽卡斯尔大学、新西兰奥克兰大学

作者：Dawei Wang、Di Zhao、Xinyuan Liu 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_a8040e12440d)

> 合作型多智能体强化学习（Cooperative Multi-Agent Reinforcement Learning, MARL）在具身智能场景中面临反馈稀疏与智能体动态进出的双重约束，导致传统信用分配方法失效。现有基于价值分解或反事实基线的方法难以处理绝对贡献量化的数学病态问题，MARS-RA 将信用分配重构为排名聚合问题，利用大型多模态模型（Large Multimodal Model, LMM）生成两两比较信号。该方法通过 Bradley-Terry 模型估计潜在贡献分数并转化为潜在函数奖励，在动态智能体基准上超越了静态团队假设下的基线。其价值在于提供了开放系统下的归因路径，但 LMM 推理延迟与计算成本是否阻碍其实时部署仍存疑。

## 研究背景

具身智能体通过自中心视角传感器感知环境，这种部分可观测性使得单个智能体无法直接获知全局状态。在合作任务中，智能体需从共享的团队奖励中剥离自身贡献，这一过程称为信用分配。由于奖励信号稀疏且延迟，直接估计绝对贡献值在数学上是病态的，且当智能体因电量耗尽中途退出时，固定团队假设下的策略会因联合动作空间变化而崩溃。

主流信用分配路线包括价值分解（如 QMIX）和反事实基线（如 COMA），它们依赖集中式训练信息来缓解非平稳性，但均假设智能体集合固定。在具身场景中，智能体动态进出导致联盟结构 $I_t$ 随时间变化，传统方法无法处理这种开放系统特性。此外，LLM 辅助方法如 SAMA 虽引入语义推理，但依赖手工设计的子目标分解，缺乏对动态团队结构的适应性。MARS-RA 的切入点在于利用排名聚合的统计鲁棒性，将绝对量化转化为相对比较，从而天然兼容动态智能体数量。

## 核心方法

### 方法参照系

本文问题属于 CTDE 范式下的信用分配，但关键差异在于智能体集合 $I_t$ 是动态变化的。标准流程假设 $N$ 固定，通过集中式评论家或反事实模拟计算优势函数。MARS-RA 摒弃了绝对分数估计，转而利用 LMM 对活跃智能体进行两两比较，通过排名聚合恢复潜在贡献分数，解决了动态联盟下绝对量化困难的问题。

### LMM 两两比较与排名聚合

设计动机在于解决具身场景中绝对贡献值难以精确量化的问题。在时间步 $t$，对于活跃智能体集合 $I_t$，LMM 接收每对智能体 $(i, j)$ 的自中心图像观察 $o_i^t, o_j^t$ 及任务提示，输出偏好结果（胜/负/平）。比较结果构成矩阵 $M^t$，其中 $(M^t)_{i,j}$ 表示 $i$ 优于 $j$ 的次数。采用 Bradley-Terry 模型，智能体 $i$ 优于 $j$ 的概率建模为：

$$ P(i \succ j) = \frac{\exp(c_i^t)}{\exp(c_i^t) + \exp(c_j^t)} $$

通过最小化负对数似然 $\sum_{i,j} [-(M^t)_{i,j} \log P(i \succ j)]$ 求解潜在分数 $\hat{c}_t$。这一过程将离散的序数偏好转化为连续基数值，不仅捕捉排名顺序，还量化了能力差异幅度，为后续奖励整形提供平滑信号。

### 潜在函数奖励整形

设计动机在于将静态贡献分数转化为动态奖励，同时保证策略不变性。定义潜在函数 $\psi(s_t, t) = \text{softmax}(\hat{c}_t)$（终止状态为 0），整形奖励定义为：

$$ F(s_t, t, s_{t+1}, t+1) = \gamma \psi(s_{t+1}, t+1) - \psi(s_t, t) $$

最终训练奖励为 $\tilde{r}_t = r(s_t, a_{I_t}^t, s_{t+1}) + \rho F(s_t, t, s_{t+1}, t+1)$，其中 $\rho$ 为权重因子。该机制基于 Ng et al. (1999) 的潜在函数奖励整形理论，确保在动态调整奖励信号时不改变最优策略和纳什均衡，从而安全地将 LMM 的语义判断嵌入 MARL 训练循环。

## 实验评估

实验在 MARS-Bench（ManiSkill3 环境，2-4 个动态智能体）、Overcooked 和 Pistonball 上进行，主要指标为任务成功率。基线覆盖 MAPPO、QMIX、COMA、SQDDPG、SAMA 和 V-GEPF，但缺失 BVME 等通信协议类强基线。在 MARS-Bench 的三个任务中，MARS-RA 在所有任务上均超越基线，成功率超过 47%，其中 Herd Sheep 任务成功率超过 70%。相比之下，QMIX 和 COMA 未表现出有效协作行为，SQDDPG 在智能体数量增加时性能下降，SAMA 和 V-GEPF 虽具竞争力但始终低于 MARS-RA。

| 任务 | MARS-RA | SAMA | V-GEPF | SQDDPG |
| :--- | :--- | :--- | :--- | :--- |
| Pass Gate | >47% | <50% | <50% | <50% |
| Herd Sheep | >70% | <50% | <50% | <50% |
| Collect Ball | >47% | <50% | <50% | <50% |

*注：表中数值为论文正文描述的定性阈值，具体精确值未在数据区提供，故仅呈现相对关系。*

消融实验显示，仅使用 MAPPO 骨干无法学习有效协作策略，而 LMM Score 变体（直接打分而非排名聚合）表现震荡且整体较差，表明排名聚合在噪声容忍度上优于直接打分。在 Overcooked 上，MARS-RA 与 SAMA 性能持平，但在 Coordination Ring 和 Forced Coordination 任务上优于 SAMA。Pistonball（10 智能体）上 MARS-RA 一致优于所有基线，验证了排名聚合在大规模团队中的有效性。

评估边界方面，论文未报告计算延迟和 GPU 资源消耗，LMM 推理成本未量化。代码未公开，MARS-Bench 开源状态不明。Overcooked 上仅 10 个随机种子，置信区间未明确展示，数值比较需谨慎。

## 关联研究分析

从问题动机看，MARS-RA 与 SAMA 均利用 LLM 辅助信用分配，但 SAMA 依赖子目标分解，假设任务结构可离散化，而具身任务往往缺乏显式分解。MARS-RA 采用排名聚合，无需预定义子目标，更适应开放系统。这一差异源于任务特性：SAMA 适合结构化任务，MARS-RA 适合动态、非结构化场景。从方法设计看，MARS-RA 与 SQDDPG 均涉及 Shapley 值，但 SQDDPG 直接近似 Shapley 值，计算复杂度高且随智能体数量指数增长。MARS-RA 通过命题 2 建立与 Shapley 值的理论联系，但实际计算基于 Bradley-Terry 模型，复杂度为 $O(|I_t|^2)$，更适合动态团队。这种设计选择牺牲了 Shapley 值的精确性，换取了计算效率和动态适应性。

## 总结

MARS-RA 旨在解决具身智能中动态智能体数量与稀疏奖励下的信用分配难题。现有方法因固定团队假设和绝对量化病态性而失效，MARS-RA 通过排名聚合将问题转化为相对比较，利用 LMM 生成比较信号并转化为潜在函数奖励。实验表明，在 MARS-Bench 上 MARS-RA 成功率超过 47%，Herd Sheep 任务超过 70%，优于 SAMA 和 V-GEPF。其边界在于 LMM 推理延迟未量化，且 Overcooked 上仅与 SAMA 持平，未显著超越。当智能体数量进一步增加至 20 以上时，LMM 两两比较的计算开销是否成为瓶颈，论文未给出回答。
