# ACL2026最新论文 ｜Maximizing Local Entropy Where It Matters: Prefix-Aware Localized LLM Unlearning ｜前缀感知局部化遗忘

作者：Naixin Zhai、Pengyang Shao、Binbin Zheng 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.03190)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_1a35986cac72)

> 大语言模型（LLM）机器遗忘旨在移除敏感知识同时保持通用效用，但现有基于负交叉熵（Negated CE）的方法因全局密集梯度导致效用退化与计算冗余。本文指出遗忘无需全局干预，仅需切断敏感生成轨迹的起始前缀并扁平化关键词汇子空间。PALU 通过时间维度的稀疏前缀选择与词汇维度的 Top-K 局部熵最大化，以最小参数扰动实现高效遗忘。该方法在 Llama-3.1-8B 上取得了 0.9238 的遗忘质量（FQ），但其在较小模型上的泛化能力及对抗鲁棒性仍存疑。

## 研究背景

LLM 遗忘的核心困境在于参数空间中知识的高度纠缠。当模型试图通过梯度上升抑制敏感 Token 概率时，往往引发“涟漪效应”，即对语义相邻的良性概念造成不可逆损伤。为量化这种损伤，领域通常采用“遗忘集-保留集”双目标优化框架，其中保留集损失 $\mathcal{L}_{retain}$ 约束模型通用能力，遗忘集损失 $\mathcal{L}_{forget}$ 驱动敏感知识移除。然而，传统方法如梯度上升（GA）和负偏好优化（NPO）均依赖负交叉熵目标，其本质是单纯降低目标 Token 的概率，而非增加预测分布的不确定性。这种概率抑制机制容易导致过校正：被抑制的概率质量可能转移至其他特定 Token（如同义词），使分布保持低熵的尖锐形态，而非达到真正的“无知”状态。

主流梯度优化路线在实现遗忘时，普遍采用全序列、全词汇的密集梯度更新。这种全局干预不仅计算开销巨大（复杂度为 $O(T|V|)$），更关键的是，它无差别地作用于内容无关的功能词，破坏了语言的连贯性。尽管近期 Token 级方法（如 TPO）引入了语义掩码以解决时间维度的冗余，但它们仍在全词汇空间计算梯度，继承了负交叉熵的不稳定性。本文的切入点在于重新定义“干预效率”：遗忘应被视为对敏感生成轨迹的最小必要扰动，而非全局分布重塑。通过识别生成过程中的因果关键点，PALU 将优化范围从全局收缩至局部，旨在以最低成本切断敏感语义的传播路径。

## 核心方法

### 双目标优化参照系

现有 LLM 遗忘方法通常建模为约束最小化问题：$\min_{\theta} \mathcal{L}_{retain}(\theta; \mathcal{D}_r) \text{ s.t. } \mathcal{L}_{forget}(\theta; \mathcal{D}_f) \geq \tau$。标准流程中，$\mathcal{L}_{forget}$ 多实例化为负交叉熵，即最大化遗忘集上的预测损失。本文的关键差异在于，它不改变双目标结构，而是重构 $\mathcal{L}_{forget}$ 的实现机制，从“概率抑制”转向“局部熵最大化”，并引入稀疏性约束以解耦遗忘与保留的梯度冲突。

### 时间维度的稀疏前缀选择

传统方法对响应序列中的所有 Token 均匀施加遗忘目标，忽略了自回归生成的因果特性。本文观察到，敏感语义通常由序列起始的少数关键 Token 触发，后续 Token 仅是对已确定路径的展开。因此，PALU 引入语义感知掩码 $m_t \in \{0, 1\}$ 识别敏感跨度，并仅选取每个敏感跨度中的前 $N$ 个 Token 构成发起目标集 $I_{init}$。这一设计解决了全序列优化导致的效用过度退化问题：通过截断梯度流于前缀，模型无需更新冗余的后续 Token，从而在保持语言连贯性的同时切断敏感轨迹。实验表明，当 $N=3$ 时，遗忘效果趋于饱和，进一步增加 $N$ 仅线性增加计算负担而无显著收益。

### 词汇维度的局部熵最大化

在选定发起 Token 后，传统负交叉熵目标仅抑制 Top-1 Token，易导致概率质量向同义词转移，维持低熵分布。PALU 提出局部熵最大化目标，将优化范围限制在参考模型确定的 Top-K 高概率候选集 $V_{top}$ 内。其核心公式为：

$$ \mathcal{L}_{local}(z_t) = \frac{1}{K} \sum_{i \in V_{top}} (z_{t,i} - c)^2 $$

该公式通过最小化 Top-K Logits 与目标值 $c$ 的方差，强制关键候选集的概率分布趋于均匀。这一设计解决了全局熵最大化（如 PDU）计算成本过高且对长尾 Token 无效的问题。通过仅扁平化解码关键子空间，PALU 在诱导局部均匀不确定性的同时，避免了全局分布扭曲，实现了“将敏感信号埋入背景噪声”的效果。最终总损失结合前缀选择与局部熵目标：

$$ \mathcal{L}_f = \mathbb{E}_{t \in I_{init}}[\mathcal{L}_{local}(z_t)] + \lambda \mathbb{E}_{t \notin I_{sens}}[\text{KL}(P_{\theta_{ref}}(\cdot|x, y_{<t}) \| P_{\theta}(\cdot|x, y_{<t}))] $$

其中 KL 项约束非敏感 Token 保持与参考模型一致，确保通用效用不受损。

## 实验评估

实验在 TOFU 和 MUSE 基准上进行，骨干模型为 Llama-2-7B 和 Llama-3.1-8B。基线覆盖 GA、GD、DPO、NPO、SimNPO、PDU 及 TPO，涵盖了梯度优化、偏好优化及 Token 级稀疏方法，但未包含机制可解释性类方法（如 SAE-Guided）。在 TOFU 5% 遗忘设置下，PALU 在 Llama-3.1-8B 上取得 0.9238 的 FQ 和 0.6162 的 MU，显著优于 NPO（0.6284 FQ, 0.6006 MU）和 TPO（0.7216 FQ, 0.5921 MU）。

| 方法 | FQ (↑) | MU (↑) | Fluency (↑) | EM (↓) |
| :--- | :--- | :--- | :--- | :--- |
| NPO | 0.6284 | 0.6006 | 0.8527 | 0.6803 |
| TPO | 0.7216 | 0.5921 | 0.8571 | 0.5973 |
| PDU | 0.5226 | 0.5705 | 0.8114 | 0.6621 |
| PALU | 0.9238 | 0.6162 | 0.8656 | 0.6518 |

*注：数据取自 Llama-3.1-8B 在 TOFU 5% 遗忘设置下的结果。*

消融实验揭示了关键设计决策的边际收益。在词汇稀疏性方面，当 Top-K 参数 $K=1$ 时，MU 崩溃至 $1 \times 10^{-4}$，证实了仅抑制 Top-1 的不稳定性；当 $K$ 增至 5,000 时，性能饱和，与全词汇优化相比增益可忽略，但计算成本大幅降低。在时间稀疏性方面，前缀截断比例从 25% 增至 50% 时，FQ 从 0.1420 跃升至 0.6872，但增至 100% 时 FQ 降至 0.6284，表明适度截断优于全序列优化。此外，PALU 在收敛速度上优于 NPO，FQ 在第 5 个 Epoch 即饱和，而 NPO 需近两倍迭代。

评估边界方面，本文主要依赖 TOFU 和 MUSE 的静态指标，未包含对抗攻击（如重学习攻击）下的鲁棒性测试，也未报告置信区间。代码已开源，但超参数（如 $K$ 和 $N$）的选取依赖特定数据集，跨骨干泛化性未充分验证。

## 关联研究分析

从方法设计看，PALU 与 TPO 同属 Token 级稀疏遗忘路线，但 TPO 仅解决时间维度冗余，仍在全词汇空间计算负交叉熵梯度，继承了概率抑制的不稳定性。PALU 引入局部熵最大化，将优化目标从“降低概率”转变为“增加局部不确定性”，这一转变源于对负交叉熵导致概率质量转移至同义词这一失效模式的洞察。然而，PALU 的局部熵目标依赖参考模型确定 Top-K 集合，若参考模型本身存在偏差，可能导致关键候选集识别错误，这一潜在风险在论文中未深入探讨。

从问题动机看，PALU 与 PDU 均基于最大熵原理，但 PDU 追求全局熵最大化，计算复杂度为 $O(T|V|)$，在实际部署中不可行。PALU 通过局部化将复杂度降至 $O(TK)$，解决了 PDU 的计算瓶颈。但 PDU 的全局熵目标在理论上更彻底地消除了知识残留，而 PALU 的局部熵仅扁平化关键子空间，长尾 Token 的分布未被约束。在复杂语义纠缠场景（如 MUSE 中的版权内容）下，局部熵是否足以防止通过长尾路径恢复知识，论文未提供对抗性证据，仅依赖静态指标验证。

## 总结

PALU 旨在解决 LLM 遗忘中全局梯度更新导致的效用退化与计算冗余矛盾。其切入点在于识别自回归生成的因果稀疏性，通过前缀截断和局部熵最大化实现最小必要干预。实验证明，在 Llama-3.1-8B 上，PALU 以 0.9238 的 FQ 和 0.6162 的 MU 超越了 NPO 和 TPO，验证了局部熵目标在平衡遗忘与效用上的优势。然而，论文未报告对抗攻击下的鲁棒性数据，且 Llama-2-7B 上的性能（FQ 0.7126）显著低于 Llama-3.1-8B，暗示方法对模型容量的依赖性。当模型规模缩小或面对多跳推理攻击时，局部熵最大化是否仍能维持遗忘的持久性，论文未给出回答。
