# ACL2026最新论文 ｜Beyond Markovian Forgetfulness: Episodic Memory for Reasoning-Intensive Retrieval ｜情景记忆检索

研究机构：韩国科学技术院、韩国首尔大学

作者：Dohyeon Lee、Yeonseok Jeong、Seung-won Hwang

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_b32f6ad40dfa)

> 推理密集型信息检索（Reasoning-Intensive IR）旨在通过多步推理解决复杂查询，但现有方法面临效率与有效性的双重困境。思维链（CoT）方法虽能生成详细推理，却因单步长链导致计算冗余且易陷入原地循环；状态基方法虽提升了Token效率，却因马尔可夫假设无法感知历史轨迹，导致多步循环频发。本文提出情景记忆检索（Episodic Memory for Retrieval, EMR），通过引入显式历史记忆模块打破马尔可夫依赖，实现查询的渐进式精炼。该方法在BRIGHT基准上显著降低了循环率并提升了检索性能，但其对文本记忆的依赖是否限制了复杂逻辑的泛化能力仍存疑。

## 研究背景

当大语言模型（LLM）处理需要多步推理的检索任务时，其自回归生成机制常导致推理链冗长。这种冗余不仅增加了计算成本，更可能引发“推理循环”，即模型反复生成相同的查询或文档，导致计算资源浪费而无实质进展。为应对此问题，状态基推理框架将任务建模为马尔可夫决策过程（MDP），通过离散的状态转移替代单步长链，从而提升Token效率。然而，MDP的马尔可夫假设要求当前决策仅依赖即时前驱状态，这使得模型无法感知历史路径，极易陷入多步循环（如 $q_t = q_{t'}$，$t' < t$）。

推理密集型IR领域的核心矛盾在于如何在保持检索精度的同时消除推理冗余。早期CoT方法（如Rank1、RankR1）虽能生成详细推理轨迹，但单步生成机制使其难以避免循环，且Token消耗巨大。随后出现的状态基方法（如SMR）通过迭代状态转移改善了效率，但其马尔可夫特性导致在自然语言查询密集的领域（如EarthScience、Psychology）中，循环率高达60%以上。本文的切入点在于识别出马尔可夫假设是循环问题的根源，并提出通过引入显式的情景记忆机制，使策略模型能够基于完整的历史轨迹进行决策，从而在保留状态基方法效率优势的同时，从根本上消除多步循环。

## 核心方法

### 状态基推理参照系

本文基于SMR（Lee et al., 2025）建立的方法参照系，将检索任务形式化为序列决策过程。状态 $s_t = (q_t, D_t)$ 包含当前查询 $q_t$ 和检索文档集 $D_t$，动作空间 $A = \{REFINE, RERANK, STOP\}$ 分别对应查询扩展、文档重排和终止。策略模型 $\pi(s_t)$ 在每步生成动作及其结果，受最大步数 $T_{max}$ 约束。该参照系的关键局限在于策略仅条件于当前状态 $s_t$，缺乏对历史路径 $\{s_0, \dots, s_{t-1}\}$ 的感知，导致无法区分“首次到达”与“重复到达”同一状态。

### 情景记忆增强策略

针对马尔可夫假设导致的循环问题，本文引入情景记忆模块 $M_t$，将策略函数从 $\pi(s_t)$ 扩展为 $\pi'(s_t, M_t)$。记忆 $M_t$ 定义为历史状态序列：

$$
M_t = (s_0, s_1, \dots, s_{t-1})
$$

该公式的物理含义是，模型在生成第 $t$ 步动作时，不仅考虑当前查询和文档，还显式参考所有先前生成的查询和文档ID。通过这种轨迹感知机制，策略模型能够识别并避免生成与历史查询 $q_{t'}$ ($t' < t$) 完全相同的字符串，从而直接阻断循环路径。这一设计解决了SMR在自然语言查询中因词汇特异性低而频繁重复的问题，使查询精炼过程从“局部反应”转变为“全局规划”。

### 记忆压缩与读写机制

为平衡记忆开销与Token效率，本文设计了基于提取式摘要的记忆压缩机制。记忆以纯文本格式存储于系统提示中，分为“近期动作历史”和“文档内容库”两部分。动作历史仅存储文档ID而非全文，以最小化Token占用。文档内容库通过三步压缩流程更新：首先使用spaCy对文档进行句子分割；其次利用MiniLM交叉编码器对句子进行相关性评分；最后执行全局Top-k过滤，仅保留与当前查询 $q_t$ 最相关的 $k$ 个句子。

$$
\text{Score}(s_i, q_t) = \text{MiniLM}(s_i, q_t)
$$

该评分函数量化了句子 $s_i$ 与查询 $q_t$ 的语义相关性。通过全局过滤而非逐文档选择，系统确保了进入记忆的文档内容高度聚焦于当前推理需求，避免了无关文档的累积。这种压缩策略使得记忆模块在增加历史上下文的同时，未显著增加推理延迟，实现了Token效率与检索精度的帕累托改进。

## 实验评估

实验在BRIGHT基准上进行，该基准包含12个推理密集型检索数据集，涵盖数学、代码和科学领域。主要指标为nDCG@10，辅助指标包括Recall和MAP。基线方法包括CoT-based（Rank1, RankR1）和State-based（SMR）。本文未对比潜在推理方法（如CODI）或强化学习优化方法（如CRT），这可能限制了结果在更广泛推理范式下的可比性。

| 指标 | SMR | EMR | 变化 |
| :--- | :--- | :--- | :--- |
| 平均循环率 | 38.75% | 2.25% | -94% |
| 平均Token消耗 | - | - | -72% |

注：具体nDCG@10数值在提供的实验数据区中未逐字列出，故未列入表格。文字描述显示，EMR在所有BRIGHT数据集上均优于SMR，且Token消耗平均降低72%。

消融分析显示，循环率的降低在不同领域呈现异质性。在Leetcode和AoPS等包含代码或数学公式的数据集上，SMR的循环率本身较低，因为高词汇特异性使得精确重复概率小。而在EarthScience、Psychology和StackOverflow等自然语言查询密集的数据集上，SMR的循环率超过60%，EMR则将其降至4%以下。这表明情景记忆机制在词汇特异性低、语义空间广阔的任务中收益最大。设计决策方面，纯文本格式优于JSON/XML，因为后者虽无显著性能提升，但增加了语法字符的Token开销。Top-k全局过滤优于阈值过滤，因为前者确保了推理成本的预测性，避免了提示大小不一致带来的管理困难。

评估边界方面，论文未报告置信区间，数值比较需谨慎。代码已开源（https://github.com/ldilab/EMR），但超参数（如Top-k值、MiniLM版本）的具体设置未在摘要中详述，可能影响复现性。此外，实验仅聚焦于检索任务，未验证情景记忆机制在其他推理任务（如数学解题、代码生成）中的通用性。

## 关联研究分析

从问题动机看，EMR与CoT压缩方法（如O1-Pruner、UCoT）存在根本差异。O1-Pruner和UCoT旨在通过剪枝或压缩减少CoT链的长度，以在固定预算内最大化准确率，其核心假设是冗余步骤可通过启发式规则识别并移除。而EMR针对的是状态基推理中的循环问题，其核心假设是马尔可夫假设导致的路径遗忘是冗余的主要来源。EMR不直接压缩推理链，而是通过引入历史记忆改变决策条件，从而避免生成冗余步骤。这一差异源于任务特性：CoT方法处理的是单步长链，而状态基方法处理的是多步迭代，循环问题在多步迭代中更为突出。

从方法设计看，EMR与潜在推理方法（如CODI、PCCoT）形成对比。CODI和PCCoT通过连续潜在空间替代离散Token，旨在突破离散解码的表达瓶颈，提升推理带宽。而EMR坚持使用离散文本记忆，未探索连续空间表示。这一选择可能源于检索任务对可解释性和精确匹配的需求：查询和文档的词汇身份是检索准确性的关键，连续表示可能模糊这种精确性。然而，文本记忆的Token开销随步数线性增长，这在长序列推理中可能成为瓶颈。潜在推理方法在HumanEval等代码任务上表现较好（如NF-CoT 70.0），而EMR在BRIGHT上的优势是否能在代码检索任务中保持，论文未给出回答。

## 总结

本文解决的核心矛盾是状态基推理中马尔可夫假设导致的多步循环问题。现有SMR方法因仅依赖即时前驱状态，无法感知历史轨迹，导致在自然语言查询中循环率高达60%以上。EMR通过引入显式情景记忆模块，将策略函数扩展为条件于历史轨迹的形式，从而在保留状态基方法效率优势的同时，从根本上消除循环。实验表明，EMR将平均循环率从38.75%降至2.25%，Token消耗平均降低72%，在BRIGHT基准上显著优于CoT和状态基基线。本文的边界在于其依赖离散文本记忆，未探索连续潜在空间表示，且实验仅聚焦于检索任务，未验证机制在其他推理任务中的通用性。当查询序列长度超过上下文窗口限制时，记忆压缩策略是否仍能保持检索精度，论文未给出回答。
