# ACL2026最新论文 ｜AdaDPI: Document-level Translation Adaptive Agent via Dynamic Parametric Internalization ｜动态参数化内化文档翻译

研究机构：天津大学

作者：Hong Ren、Liting Deng、Shaolin Zhu 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_8a8317ef38e2)

> 文档级机器翻译（DocMT）面临长程依赖导致的术语漂移与上下文稀释，现有检索增强生成（RAG）范式将历史语境视为静态外部资源，无法实现模型内部表征的动态适应。本文提出 AdaDPI，通过语言不确定性监控器（LUM）检测话语断裂，并借助上下文到参数整合器（CPI）将检索约束实时编译进轻量级适配器参数，实现从静态查询到动态内化的范式转移。该方法在 GuoFeng 数据集上以 85.42 的 COMET 分数超越主流基线，但其对骨干模型容量的依赖及跨域泛化能力仍存疑。

## 研究背景

文档级翻译要求模型在生成当前句子 $y_t$ 时，不仅忠实于源句 $x_t$，还需维持与历史语境 $C_{<t}$ 在指代、术语及风格上的一致性。传统句级翻译因缺乏跨句依赖建模，导致指代消解错误与术语不一致。大语言模型（LLM）虽具备长上下文窗口，但受限于注意力分布不均，长文档中关键约束易被忽略，且直接拼接上下文会占用窗口容量并增加推理延迟。

主流解决路径分为两类：一是扩展上下文窗口或滑动窗口，但加剧了位置注意力偏差，导致中间段约束丢失；二是基于 RAG 的智能体框架（如 DELTA、GRAFT），通过显式记忆库存储并检索相关信息。然而，这些方法将翻译视为静态查询过程，检索到的片段仅作为被动输入，模型无法在推理过程中动态调整内部表征以适配文档特有的语言规范。本文切入点在于借鉴翻译过程研究中的“临时规范获取”概念，主张高质量文档翻译依赖上下文的内化而非单纯访问，从而提出在推理阶段通过参数更新实现动态适应。

## 核心方法

### 方法参照系

标准 DocMT 流程为“检索-拼接-生成”，即从外部知识库检索相关术语或摘要，将其作为提示前缀输入 LLM。本文的关键差异在于将“拼接”替换为“梯度更新”，将检索结果转化为优化目标，直接修改模型参数而非输入序列，从而规避上下文窗口占用。

### 语言不确定性监控（LUM）

LUM 旨在解决连续参数更新带来的计算冗余与噪声干扰，仅在模型内部表征不足时触发适应。其设计动机是避免在非关键句子上执行昂贵的梯度计算。LUM 通过两个指标量化不确定性：词汇置信度（LC）计算输出层概率分布的香农熵 $H_{pred}(t)$，反映 token 选择的不确定性；上下文焦点（CF）计算注意力权重在历史语境上的熵 $H_{attn}(t)$，反映模型对支持性上下文的聚焦程度。综合不确定性分数定义为：

$$ S(t) = H_{pred}(t) \cdot H_{attn}(t) $$

当 $S(t)$ 超过阈值 $\tau$ 时，激活后续参数整合。该机制确保计算资源仅用于话语关键节点（如歧义实体或风格断裂），实现了效率与性能的平衡。

### 上下文到参数整合（CPI）

CPI 将离散符号约束转化为连续参数修改，解决静态 RAG 中知识整合表层化的问题。其设计动机是使模型在推理中动态学习文档特定规范，而非依赖固定提示。CPI 采用 LoRA 作为可变参数子空间 $\phi_t$，保持 LLM 主参数 $\theta$ 冻结。检索到的约束集 $K_t$ 被用作伪标签，构建临时优化目标：

$$ L_{opt}(\phi_t) = -\sum_{(k,v) \in K_t} \log P(v | k, C_{<t}; \theta, \phi_t) $$

通过单步梯度下降更新适配器参数：

$$ \phi'_t \leftarrow \phi_t - \eta \cdot \nabla_\phi L_{opt}(\phi_t) $$

更新后的 $\phi'_t$ 被保留用于后续句子，形成累积演化效应。随着文档推进，$\phi$ 逐渐收敛至文本特定风格，使模型在 beam search 中自然优先正确术语，无需复杂提示工程。

## 实验评估

| 方法 | GuoFeng En→Zh COMET | GuoFeng En→Zh LTCR | IWSLT2017 En→Zh COMET | IWSLT2017 En→Zh LTCR |
| :--- | :--- | :--- | :--- | :--- |
| GPT-4o | 83.54 | 84.12 | 80.82 | 78.45 |
| DELTA | - | - | 81.02 | 80.09 |
| AdaDPI-DAPO | 85.42 | 90.30 | 83.25 | 86.90 |

实验在 GuoFeng 文学数据集与 IWSLT2017 口语数据集上进行，基线覆盖 NMT、前沿 LLM 及智能体框架。AdaDPI-DAPO 在 GuoFeng En→Zh 上取得 85.42 COMET 与 90.30 LTCR，显著优于 GPT-4o 的 83.54 COMET 与 84.12 LTCR，验证了参数内化在术语一致性上的优势。

| 消融变体 | COMET | LTCR | d-BLEU |
| :--- | :--- | :--- | :--- |
| AdaDPI (Full) | 85.42 | 90.30 | 34.15 |
| w/o LUM (Always Adapt) | 85.10 | 89.80 | 33.95 |
| w/o SFT Init (Random Init) | 79.50 | 81.20 | 26.45 |
| Multi-step Update (K=5) | 83.80 | 89.90 | 32.80 |

消融实验显示，移除 LUM 导致性能轻微下降但增加计算开销，证明 LUM 有效过滤冗余更新。随机初始化适配器导致性能崩溃，表明测试时梯度更新并非从头学习，而是引导预对齐流形。多步更新（K=5）导致 COMET 下降 1.62，证实在线学习中的灾难性遗忘风险，单步更新是必要的约束。

评估指标涵盖 COMET、LTCR 与 d-BLEU，但缺乏人类评估对照，且未报告置信区间。代码未开源，LoRA 超参数细节仅在附录提及，可复现性受限。

## 关联研究分析

从方法设计看，AdaDPI 与 SubDocTrans 均致力于解决长文档术语一致性，但路径截然不同。SubDocTrans 依赖多粒度知识增强，通过提取双语摘要构建结构化提示，属于外部知识注入；AdaDPI 则通过 CPI 将约束编译进参数，属于内部状态更新。SubDocTrans 在 ACL 60/60 上取得 97.58 dCOMET，略高于 TransGraph 的 96.52，表明多粒度提示在术语召回上具有优势。AdaDPI 在 GuoFeng 上 LTCR 达 90.30，高于 DELTA 的 84.60，但 COMET 低于 TransGraph 的 87.76 dCOMET（据领域综述）。这种差异暗示参数内化可能在保持整体语义流畅性上不如显式图结构引导，因为参数更新可能过度拟合局部术语而忽略全局连贯性。

从问题动机看，AdaDPI 与 TwT 框架均关注推理效率与质量的权衡，但机制不同。TwT 通过难度自适应推理调整思维链长度，属于推理深度优化；AdaDPI 通过 LUM 触发参数更新，属于模型状态优化。TwT 在 WMT24++ 上取得 75.0 XCOMET-XL，而 AdaDPI 在 IWSLT2017 上取得 83.25 COMET。两者均试图解决统一推理或固定上下文导致的效率-质量失衡，但 AdaDPI 更侧重于解决长文档中的上下文稀释，而 TwT 侧重于解决复杂句子的推理不足。AdaDPI 未探索推理深度与参数更新的联合优化，这可能是一个未触及的盲区。

## 总结

本文核心矛盾在于静态 RAG 无法实现文档特定规范的动态适应。AdaDPI 通过 LUM-CPI 双循环，将检索约束实时编译进 LoRA 参数，解决了上下文窗口占用与知识整合表层化问题。实验证明其在 GuoFeng 上 LTCR 达 90.30，COMET 达 85.42，优于 GPT-4o 与 DELTA。然而，消融实验显示多步更新导致灾难性遗忘，且随机初始化性能崩溃，表明该方法高度依赖预训练模型的初始对齐。当文档风格发生剧烈转变时，累积的参数 $\phi$ 是否会导致对前文风格的过度固化，从而抑制对新风格的适应，论文未给出回答。
