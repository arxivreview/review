# ACL2026最新论文 ｜Model-Based Imaginative Planning for Embodied Agents ｜基于符号世界模型的具身想象规划

作者：Junru Song、Hengzhe Jin、Yucong Huang 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ffd5b2b05cd1)

> 具身智能体在长程任务中面临视觉噪声、部分可观测性及环境动力学与语言先验脱节的困境，导致冻结大语言模型（LLM）直接规划时易产生幻觉与短视行为。现有微调方法受限于分布偏移与灾难性遗忘，而纯测试时扩展方法缺乏对物理动力学的显式建模。IMPLEMENT 通过引入一个轻量级、对象中心的符号世界模型，将像素输入转化为可推理的符号状态，并让 LLM 与世界模型形成在线共演的“想象-评估-精炼”闭环。该框架在不更新 LLM 参数的前提下实现了显著的样本效率提升，但其性能高度依赖 ALFWorld 内置的符号标注，在真实无标注环境中的泛化能力尚存疑。

## 研究背景

具身决策的核心挑战在于将高维、含噪的视觉观测转化为可执行的动作序列。这一过程首先要求智能体构建对环境的内部表征，即世界模型（World Model），用于预测动作引发的状态转移。然而，传统基于像素的世界模型难以直接供 LLM 进行逻辑推理，而纯文本环境虽便于 LLM 处理，却忽略了物理世界的空间约束与感知不确定性。因此，如何在保留 LLM 语义推理能力的同时，注入对物理动力学的准确预测，成为具身规划的关键瓶颈。

早期研究主要依赖微调视觉语言模型（VLM）以对齐具身任务，但这种方法在分布外任务上泛化能力差，且无法利用前沿冻结 LLM 的通用推理能力。另一条路线是测试时扩展，如 ReAct 或 Reflexion，它们通过提示工程增强推理连贯性，但缺乏对状态转移的显式建模，导致在长程任务中因累积误差而失效。近期工作尝试将 LLM 本身作为世界模型，但受限于语言先验，难以准确捕捉环境特有的物理动力学。IMPLEMENT 的切入点在于解耦感知与预测：使用一个轻量级 VLM 专门负责将视觉输入转化为紧凑的符号状态，并预测其演化，从而为冻结 LLM 提供一个可靠的“想象空间”。

## 核心方法

### 符号世界模型与对象中心状态

IMPLEMENT 将具身环境建模为部分可观测马尔可夫决策过程（POMDP），其核心创新在于引入一个对象中心（Object-Centric）的符号状态表示。该表示包含智能体位置、库存及容器/对象的属性与关系，旨在抽象掉像素级噪声，保留 LLM 所需的语义结构。世界模型 $M_\phi$ 采用 Qwen2.5-VL-7B 作为骨干，通过监督微调训练，具备两种模式：感知模式更新当前可观测事实，预测模式模拟动作引发的状态变化。这种设计解决了纯 LLM 规划中因视觉噪声导致的状态追踪失效问题，使 LLM 能在紧凑的符号空间中进行逻辑推理。

$$
s_t \leftarrow M_\phi(s_{t-1}, a_{t-1}, o_t; [PER])
$$

该公式表示世界模型在感知模式下，结合历史状态、上一动作及当前观测，更新符号状态 $s_t$，确保状态表征始终基于最新视觉证据，避免陈旧信息累积。

### 蒙特卡洛想象与元上下文学习

为处理部分可观测性带来的认知不确定性，IMPLEMENT 在预测模式下执行蒙特卡洛（Monte Carlo）采样。当 LLM 对当前决策置信度低时，世界模型对候选动作序列进行多次温度采样，生成多个可能的未来状态轨迹。这些轨迹被压缩为信念状态摘要（Belief State Summary），供 LLM 评估。此外，框架集成元上下文学习（Meta In-Context Learning, MetaICL），将历史轨迹中的失败交互作为条件上下文，在线修正世界模型的预测。这一机制解决了静态世界模型在动态环境中适应性差的问题，使模型能从有限经验中快速学习环境特有的物理约束。

$$
\hat{P}(s_{t+1} | s_t, a_t, \tau) = \frac{1}{N} \sum_{i=1}^{N} \mathbb{1}[s_{t+1}^{(i)} = s_{t+1}]
$$

该公式描述了通过 $N$ 次蒙特卡洛 rollout 估计状态转移概率的过程，其中 $\tau$ 为包含历史失败交互的上下文，体现了 MetaICL 对预测分布的在线修正作用。

## 实验评估

实验在 ALFWorld 基准上进行，该基准包含 134 个分布外（OOD）任务，涵盖六种家务类别。基线覆盖三类方法：原生 VLM（如 GPT-4.1）、微调方法（如 MiniGPT-4）及测试时扩展方法（如 ReAct、SimuRA）。值得注意的是，实验未对比基于 PDDL 的符号规划方法（如 NL-PDDL），这可能限制了其在形式化规划维度的横向可比性。

| 方法 | 骨干模型 | SR@1 (%) | SR@12 (%) |
| :--- | :--- | :--- | :--- |
| IMPLEMENT (w/ IP) | Qwen3.5-Plus | 67.9 | - |
| IMPLEMENT (w/o IP) | Qwen3.5-Plus | 58.9 | - |
| SimuRA (WM Percep.) | Qwen3.5-Plus | 44.8 | - |

在 Qwen3.5-Plus 骨干下，IMPLEMENT 的 SR@1 达到 67.9%，比无想象规划（Imagined Planning, IP）的变体高 9.0 个百分点，比 SimuRA 高 23.1 个百分点。这一差距表明，显式学习的动力学模型与不确定性处理机制对具身规划至关重要，且该优势并非源于骨干模型容量的简单提升。

消融实验显示，移除 MetaICL 会导致性能下降，但幅度小于移除 IP，说明在线适应是锦上添花而非核心支柱。温度采样分析表明，温度设为 0（单点预测）时性能显著下降，证实了蒙特卡洛采样在捕捉部分可观测性不确定性中的必要性。然而，温度从 1 增至 1.5 时成功率略有下降，暗示过高的随机性可能引入噪声。

评估边界方面，实验仅报告单次运行结果，缺乏置信区间，统计显著性检验仅在部分消融中提及。世界模型训练依赖 ALFWorld 内置的符号标注，这限制了其在无标注真实环境中的直接应用。代码与超参数已公开，世界模型训练消耗 40 A800 GPU 小时，推理时单步平均耗时 23.59 秒，计算成本较高，但在任务收敛速度上优于无 IP 变体。

## 关联研究分析

从问题动机看，IMPLEMENT 与 SimuRA 均试图利用 LLM 进行具身规划，但 SimuRA 依赖 LLM 的语言先验作为世界模型，而 IMPLEMENT 引入显式训练的轻量级 VLM 世界模型。这一差异的根源在于对“动力学来源”的不同假设：SimuRA 假设 LLM 预训练语料已包含足够的物理常识，而 IMPLEMENT 认为环境特有的动力学（如特定物体的可加热性）无法从语言先验中可靠提取，必须通过视觉-符号映射显式学习。这种解耦架构使得 IMPLEMENT 在分布外任务上表现出更强的鲁棒性，但也引入了额外的训练开销。

从方法设计看，IMPLEMENT 与 Planner-in-the-Loop 等基于 PDDL 的方法形成对比。后者依赖外部符号规划器（如 Fast Downward）进行逻辑验证，确保计划的语法与逻辑正确性；而 IMPLEMENT 依赖内部学习的世界模型进行概率预测，不保证逻辑严谨性，但能处理感知不确定性。这一差异反映了“形式化验证”与“概率预测”两种范式在具身场景中的取舍：PDDL 方法在逻辑一致性上更可靠，但难以处理视觉噪声；IMPLEMENT 在感知适应性上更优，但可能产生逻辑上不严谨但物理上可行的计划。

## 总结

IMPLEMENT 旨在解决冻结 LLM 在具身长程任务中因缺乏动力学模型而导致的规划失效问题。其核心在于构建一个对象中心的符号世界模型，通过蒙特卡洛想象与元上下文学习，使 LLM 能在不更新参数的情况下在线适应环境。实验证明，该框架在 ALFWorld 上显著优于纯 LLM 规划与测试时扩展方法，SR@1 提升 9.0 个百分点。然而，其性能高度依赖 ALFWorld 提供的精确符号标注，世界模型的感知准确率（90.40% Recall）仍有提升空间，且推理延迟较高。当移除内置符号标注，仅依赖视觉观测自举世界模型时，其预测精度与规划性能是否会因感知误差累积而急剧下降，论文未给出回答。
