# ACL2026最新论文 ｜CPT-Agent: A Cognitive Process Theory-driven Framework for Student Simulation in Writing Development ｜认知过程理论驱动的学生写作模拟框架

研究机构：科大讯飞

作者：Yuhan Chen、Zizhuo Shen、Miaomiao Cheng 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_967941a5da82)

> 现有大语言模型（LLM）在模拟学生写作时，往往生成过于流畅且能完美应用反馈的文本，导致无法真实反映不同认知水平学生的局限性。这种“过度胜任”使得基于模拟的反馈质量评估失去教学诊断价值。CPT-Agent 通过解耦认知能力与写作熟练度，引入有序逻辑模型（Ordered Logit Model）建模认知发展的概率性，结合特定熟练度微调与结构化记忆，实现了具备认知边界的学生行为模拟。该框架在模拟真实性上优于通用 LLM 基线，但其评估结果是否具备生态效度，仍缺乏真实学生数据的直接验证。

## 研究背景

当 LLM 被用于模拟学生以评估教师反馈时，一个核心困境是模型倾向于忽略“低能力”设定，生成高质量文本。这源于通用 LLM 强大的指令遵循能力，使其难以复现低熟练度学生在词汇、句法及逻辑组织上的典型缺陷。为克服这一局限，需引入认知负荷理论（Cognitive Load Theory），即学生处理信息的能力受限于其当前认知发展阶段，而非单纯的语言生成能力。因此，模拟系统必须区分“能写出什么”（写作熟练度）与“能理解什么”（认知能力），二者在真实学习场景中呈正相关但非等价关系。

自动写作评估领域长期关注评分精度与反馈生成，但鲜有研究聚焦于“学习者侧”的模拟真实性。主流方法如 AutoSCORE 或 Rubric-Based RL 侧重于评分标准对齐或反馈优化，其隐含假设是反馈能被学生有效接收。然而，若模拟学生无法体现认知瓶颈，反馈质量的评估将沦为对 LLM 自身能力的测试，而非对教学有效性的检验。CPT-Agent 的切入点在于，将 Flower and Hayes (1981) 的认知过程理论（Cognitive Process Theory, CPT）形式化为可计算的模块化架构，通过显式建模认知过滤机制，解决通用 LLM 在角色扮演中能力边界模糊的问题。

## 核心方法

### 方法参照系

本文问题可归类于 LLM 角色扮演与教育模拟，但区别于通用提示工程或端到端微调。标准流程通常依赖单一 LLM 通过提示词设定角色，但该方法无法精细控制内部认知状态。CPT-Agent 的关键差异在于将写作过程解耦为认知规划（Planner）与文本生成（Translator）两个独立模块，并引入概率模型约束认知状态转移。

### 认知建模与过滤机制

Planner 模块负责模拟学生对反馈的选择性理解。传统方法直接让 LLM 处理所有反馈，导致低年级学生也应用高阶建议，违背认知发展规律。CPT-Agent 采用有序逻辑模型（Ordered Logit Model, OLM）量化认知水平 $Y \in \{1, 2, 3\}$（低、中、高），其累积概率定义为：

$$ P(Y \le j | g) = \sigma(\theta_j - \beta g - \alpha_i), \quad j = 1, 2 $$

其中 $g$ 为年级，$\beta$ 为年级效应系数，$\alpha_i$ 为基于记忆库中已掌握技能估计的个体能力参数。该公式的物理含义是：认知水平并非离散阶梯，而是随年级和技能积累呈现 S 形概率分布。Planner 根据采样得到的认知水平 $Y$，过滤原始反馈 $F$，仅保留学生当前可理解的子集 $F_c$。这一设计解决了通用 LLM “过度应用反馈”的失效，确保低认知水平学生仅处理表层错误，高认知水平学生才接触结构优化建议。

### 熟练度解耦与记忆积累

Translator 模块负责生成文本，其核心创新在于通过两阶段微调实现写作熟练度 $S_w$ 与认知能力 $S_c$ 的解耦。第一阶段在特定熟练度（低/中/高）作文集上微调 Qwen2-7B，建立基础语言模式；第二阶段利用 GPT-4o 生成“反馈-修改”对，进一步微调以模拟修改行为。记忆模块 $M = (K, K_I)$ 维护技能知识库 $K$，并通过知识整合器 $K_I$ 将 $F_c$ 中的有效策略蒸馏为可迁移技能。公式 $K = K_I(K, S, F_c)$ 表明，技能更新受学生档案 $S$ 约束，确保知识积累符合认知发展阶段。这种解耦架构使得同一认知水平的学生，因写作熟练度不同，能生成质量差异显著的文本，从而在模拟中复现真实课堂中的个体差异。

## 实验评估

实验基于自建模拟环境，对比 CPT-Agent 与 GPT-4o、GLM-4.5、Qwen2-7B 等通用 LLM 基线。基线覆盖主流开源与闭源模型，但缺乏专用教育评估模型（如 AutoSCORE）的直接对比，因任务性质不同（模拟 vs 评分）。主实验结果显示，CPT-Agent 在人类标注一致性上达到 59.26%，显著高于基线，表明其生成的作文能更准确反映预设熟练度等级。

| 方法 | 人类一致性 (%) | 专家排名相关系数 (r) |
| :--- | :--- | :--- |
| CPT-Agent | 59.26 | 0.72 |
| GLM-4.5 (Baseline) | - | -0.375 |

*注：基线一致性数值未在数据区提供，仅列出 CPT-Agent 核心指标。*

消融实验揭示了 Planner 的关键作用。移除 Planner 后，模型出现“学习尖峰”，即分数非单调跳跃，表明认知过滤机制对平滑学习轨迹至关重要。此外，CPT-Agent 在三种教学策略（过程写作、直接指导、自我调节策略发展）下的分数变化模式与教育理论预测一致：低年级学生对直接指导响应更强，高年级学生对过程写作响应更强。通用基线则表现出无差别的高分提升，未能体现认知约束。

评估边界方面，实验依赖 LLM-as-Judge（DeepSeek-R1）进行自动评分，可能存在评估器偏差。人类评估仅涉及 3 名标注者，样本量有限。论文未提供代码与超参数细节，且未报告计算成本，限制了可复现性。此外，59.26% 的一致性虽优于基线，但绝对值不高，暗示模拟与真实学生行为间仍存在显著差距。

## 关联研究分析

从问题动机看，CPT-Agent 与 AutoSCORE 均利用 LLM 提升教育评估效率，但前者聚焦“学习者模拟”以评估反馈，后者聚焦“评分标准对齐”以预测分数。AutoSCORE 的多智能体架构旨在提升评分可解释性，而 CPT-Agent 的模块化设计旨在复现认知瓶颈。差异根源在于任务目标：评分需全局一致性，模拟需个体差异性。CPT-Agent 未对比 AutoSCORE，可能因二者评估指标（QWK vs 一致性）不兼容，但这暴露了跨任务基准缺失的问题。

从方法设计看，CPT-Agent 与 Rubric-Based RL Scoring 均关注反馈质量，但后者通过强化学习优化反馈生成，前者通过模拟学生反应间接评估反馈。RL 方法假设反馈质量可通过标量奖励量化，而 CPT-Agent 认为反馈有效性取决于学生认知匹配度。这一分歧源于对“教学价值”定义的不同：RL 侧重即时优化，CPT-Agent 侧重发展真实性。CPT-Agent 未探索 RL 与认知建模的结合，是否能在保持认知约束的同时优化反馈生成，论文未给出回答。

## 总结

CPT-Agent 试图解决 LLM 模拟学生时“过度胜任”导致的反馈评估失真问题。其切入点在于解耦认知与写作能力，通过有序逻辑模型概率化认知发展，并利用微调与记忆模块实现可控模拟。实验证明其在模拟真实性（59.26% 一致性）与专家判断对齐（r=0.72）上优于通用 LLM，但 59.26% 的绝对一致性表明模拟仍偏离真实学生行为。该框架的边界在于依赖 LLM 作为评估器与模拟器的双重角色，且缺乏真实学生数据的纵向验证。当模拟学生的认知轨迹与真实学生数据对齐时，其反馈评估结果能否作为教师培训的可靠代理，论文未给出回答。
