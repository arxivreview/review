# ACL2026最新论文 ｜Evolutionary Negative Module Pruning for Better LoRA Merging ｜进化负向模块剪枝

研究机构：浙江大学

作者：Anda Cao、Zhuo Gou、Yi Wang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.17753)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.17753)

> 多任务LoRA合并面临的核心困境是独立训练的适配器在共享骨干中产生参数干扰，导致合并后性能低于单任务专家。现有子空间对齐方法隐含“所有模块均有益”的假设，忽略了特定层级的LoRA矩阵可能加剧冲突而非贡献信息。本文通过进化搜索定位并剪除这些“负向模块”，在合并前净化输入空间。该方法在语言与视觉任务上显著提升了多种基线算法的性能，但其依赖验证集反馈的离线优化过程限制了在数据受限场景下的即时部署能力。

## 研究背景

当大规模语言模型需同时服务多个下游任务时，独立部署每个微调模型带来的存储冗余与推理延迟成为工程瓶颈。参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）中的低秩适配（Low-Rank Adaptation, LoRA）因参数足迹小成为主流，但其合并面临独特挑战：LoRA更新具有严格的低秩结构约束，且不同任务适配器的子空间往往存在几何错位。这种错位导致直接权重平均或简单任务算术（Task Arithmetic, TA）时，参数干扰显著，合并模型性能大幅退化。

主流解决路线分为两类：一是参数级稀疏化，如TIES-Merging通过符号对齐与幅度修剪消解冲突；二是子空间对齐，如KnOTS和CoreSpace利用奇异值分解（Singular Value Decomposition, SVD）将不同适配器投影至共享子空间以强制兼容性。然而，这些方法均假设每个LoRA模块对合并性能有建设性贡献。本文通过留一法（leave-one-out）分析发现，移除特定层的LoRA模块反而能提升合并性能，揭示了“负向模块”的存在。这些模块在合并时加剧干扰，且其影响具有跨层依赖性，使得贪心剪枝策略失效。

## 核心方法

### 方法参照系

标准LoRA合并流程将每个任务的LoRA更新 $\Delta W_t$ 视为任务向量，通过加权求和 $\theta^* = \theta_0 + \sum \alpha_i \tau_i$ 生成合并模型。本文的关键差异在于操作粒度从参数级提升至模块级（Layer×Task），并引入离散剪枝掩码 $m \in \{0,1\}^{L \times T}$，其中 $m_{l,t}=1$ 表示移除第 $l$ 层任务 $t$ 的LoRA模块。

### 负向模块剪枝形式化

设计动机在于解决子空间对齐方法中负向模块污染共享基底的失效。本文定义合并权重为保留模块的聚合：

$$ W_{merged} = \Phi(\{ \Delta W_{t,l} \mid m_{l,t}=0 \}) $$

其中 $\Phi(\cdot)$ 为任意合并算子（如TA、TIES）。该公式表明，合并过程仅基于未被剪枝的模块集合，从而在物理层面移除了干扰源。

### 基于CMA-ES的进化搜索

设计动机在于解决模块间高阶依赖导致的组合爆炸问题（$2^N$ 状态空间）。本文采用协方差矩阵自适应进化策略（Covariance Matrix Adaptation Evolution Strategy, CMA-ES）在连续潜空间搜索最优掩码。潜向量 $z \in \mathbb{R}^N$ 通过动态阈值映射为二值掩码：

$$ m_{flat} = \mathbb{1}[z_j > \tau_k] $$

其中 $\tau_k$ 由最大剪枝比例 $k$ 决定，取 $z$ 中最大的 $\lfloor k \cdot N \rfloor$ 个元素对应的索引。CMA-ES通过协方差矩阵 $C^{[g]}$ 捕捉模块间的依赖关系，避免了贪心策略忽略高阶交互的缺陷。

## 实验评估

实验在Llama-3-8B（NLP）和ViT-B/32（CV）上进行，基线覆盖TA、TIES、DARE、TSV、KnOTS、CoreSpace，但缺失Fisher加权或贝叶斯合并等几何/概率类强基线。

| 方法 | NLP Avg. (%) | CV Avg. (%) |
| :--- | :--- | :--- |
| TA | 90.25 | 63.54 |
| TA + ENMP | 93.49 | 65.21 |
| KnOTS | 97.29 | 65.28 |
| KnOTS + ENMP | 97.29 | 70.82 |
| CoreSpace | 96.54 | 76.47 |
| CoreSpace + ENMP | 96.73 | 78.79 |

ENMP在所有基线上均带来正向增益，其中与稀疏化方法TIES（+6.40%）和DARE（+6.97%）的协同效应最为显著，表明模块级剪枝弥补了参数级稀疏化对跨模块干扰的忽视。

消融实验显示，随机剪枝（匹配相同稀疏度）导致性能下降1.15%，而ENMP提升3.24%，证明增益源于精准定位而非单纯稀疏。剪枝比例 $k$ 从0.0增至0.1时性能急剧上升，随后趋于平稳，表明算法具备自适应稀疏性，无需精细调参。

评估边界方面，实验依赖验证集进行离线优化，未报告计算效率指标（如GPU小时数），且未测试在持续学习或异构架构下的鲁棒性。代码已开源，超参数（$N_{pop}=16, G=60$）明确，可复现性良好。

## 关联研究分析

从问题动机看，本文与KnOTS和CoreSpace同属LoRA合并路线，但二者聚焦于子空间几何对齐，隐含全模块建设性假设。本文揭示的负向模块现象表明，几何对齐无法消除由特定层级参数冲突引起的干扰，需通过物理剪枝解决。这一差异源于LoRA低秩结构的非均匀性：干扰并非均匀分布，而是集中在特定层，导致子空间基底被污染。

从方法设计看，本文与TIES-Merging同属干扰消解策略，但操作粒度不同。TIES在参数级进行符号对齐与修剪，而ENMP在模块级进行整体移除。实验证明二者具有互补性：TIES减少模块内冗余，ENMP消除模块间冲突。这种层级分离的干扰消解机制，比单一粒度的优化更能适应LoRA合并中复杂的参数相互作用。

## 总结

本文解决的核心矛盾是LoRA合并中负向模块导致的性能退化，现有子空间对齐方法因假设全模块有益而失效。本文通过CMA-ES进化搜索定位并剪除这些模块，在合并前净化输入空间。实验证明，ENMP将TA在NLP任务上的归一化准确率从90.25%提升至93.49%，并在CV任务上带来5.54%的增益。其边界在于依赖验证集反馈的离线优化过程，且未探索在数据受限或持续学习场景下的适应性。当验证集规模进一步缩小至64样本/任务时，ENMP仍能保持91.17%的准确率，但其在无验证集场景下的表现如何，论文未给出回答。
