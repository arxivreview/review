# ACL2026最新论文 ｜UERLens: Understanding Event Relations in Large Language Models ｜事件关系内部表示的可解释性分析

作者：Yong Guan、Zhiyuan Li、Shaoru Guo

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_9ef8bf2f817c)

> 事件关系抽取（Event Relation Extraction, ERE）旨在从文本中识别事件间的因果、时序及子事件依赖，但大语言模型（LLM）在此任务上的推理过程长期处于黑盒状态，现有研究多聚焦于性能优化而忽视了内部机制的解析。本文切入点在于验证 LLM 是否通过特定的内部特征编码事件关系，并探究这些特征的功能性作用。通过构建反事实数据集、利用稀疏自编码器（Sparse Auto-Encoder, SAE）识别关系敏感特征，并结合模型干预与训练进行因果验证，UERLens 揭示了事件关系在 LLM 中间层的具体表征形式。该框架证明了内部特征对 ERE 性能具有显著影响，但受限于单一骨干模型与静态文本场景，其结论的普适性仍存疑。

## 研究背景

当 LLM 处理包含隐含因果或时序关系的长文本时，其预测结果往往缺乏可解释性，研究者难以区分模型是依赖了显式连接词还是捕捉到了深层语义结构。这种黑盒特性导致模型在复杂事件结构中的幻觉问题难以定位，而稀疏自编码器（SAE）作为一种将高维隐藏状态分解为稀疏特征向量的工具，为解析这种内部表示提供了可能。SAE 能够将 LLM 的激活值映射到可解释的基向量空间，使得特定语义概念（如事件关系）对应的特征可以被独立识别与操控。

事件关系抽取是构建知识图谱与实现机器阅读理解的基础，主流路线已从早期的规则匹配演进至基于 LLM 的指令微调与多智能体协作。然而，现有方法主要关注端到端的性能提升，如通过强化学习优化推理轨迹或引入外部约束抑制幻觉，却极少深入探究 LLM 内部是如何表示这些关系的。这种“重性能、轻机制”的研究范式导致了对模型失效原因的认知空白，例如无法判断性能下降是源于特征提取失败还是推理逻辑错误。本文的切入点在于填补这一机制解释的空白，不再将 LLM 视为整体黑盒，而是通过反事实分析隔离特定关系对内部激活的影响，从而建立内部特征与外部行为之间的因果联系。

## 核心方法

### 方法参照系

本文问题归属于 LLM 可解释性分析范畴，但区别于传统的 Token 级或实体级归因分析。标准流程通常通过注意力权重或梯度归因来解释预测，而本文的关键差异在于将分析对象提升至“关系”层级，并采用反事实干预而非被动观测来验证特征的功能性，旨在回答内部特征是否真正支撑了事件关系的理解。

### 反事实数据构建与特征识别

针对 LLM 内部表示难以直接观测的问题，本文首先构建 UERBench 数据集，通过最小语言修改生成配对样本 $(s^+, s^-)$，其中 $s^+$ 包含目标关系，$s^-$ 移除该关系但保留事件实体。这种设计旨在隔离关系本身对模型激活的影响，排除实体语义的干扰。随后，利用 SAE 将 LLM 第 $l$ 层的隐藏状态 $f \in \mathbb{R}^d$ 映射为稀疏激活向量 $a$，其中每个维度 $a_k$ 对应一个潜在基向量。为了量化基向量 $k$ 对目标关系的敏感性，本文定义了潜在效应 $\tau_k(s)$：

$$
\tau_k(s) = a_k(s^+) - a_k(s^-)
$$

该公式通过计算同一基向量在含关系与不含关系样本上的激活差值，直接衡量该特征对特定关系的响应强度。通过对所有样本聚合平均，选取 Top-K 高敏感特征作为关系敏感特征。这一设计解决了传统归因方法无法区分“特征存在”与“特征功能”的问题，通过反事实对比确保了所选特征确实与目标关系存在因果关联，而非仅仅是统计相关。

### 模型干预与功能性验证

识别出关系敏感特征后，本文通过模型干预验证其功能性。在推理过程中，直接修改 SAE 解码前的激活值：消融（Ablation）将 $a_k$ 置零以抑制特征，增强（Enhancement）将其置为固定高值以放大特征。修改后的激活值经 SAE 解码并传播至后续层，观察最终 ERE 预测的变化。此外，本文还进行模型训练验证，将 Top-K 特征的激活值拼接为向量，训练支持向量机（SVM）分类器，以检验这些特征是否具备独立的判别能力。这一双重验证机制解决了单一干预可能存在的偶然性问题，通过“破坏性能”与“独立判别”两个维度，确证了内部特征在事件关系理解中的实质性作用，而非仅仅是冗余的统计噪声。

## 实验评估

实验基于 LLaMA-3.1-8B 骨干模型，使用 OpenSAE 检查点，在自建 UERBench 数据集上进行评估。基线包括 In-Context Learning (ICL) 和随机特征基线（RFB），但缺乏传统监督微调（SFT）或指令微调（IFT）的直接对比，这可能影响对特征贡献的绝对量化。

| 关系类型 | 方法 | Precision | Recall | F1 |
| :--- | :--- | :--- | :--- | :--- |
| Causal | ICL | 71.54 | 63.71 | 67.40 |
| Causal | RFB | 49.06 | 49.17 | 47.65 |
| Causal | RSFT | 73.26 | 72.33 | 72.05 |
| Temporal | ICL | 64.07 | 61.27 | 62.64 |
| Temporal | RFB | 50.17 | 50.17 | 49.66 |
| Temporal | RSFT | 63.84 | 63.17 | 62.72 |
| Subevent | ICL | 65.82 | 52.83 | 58.61 |
| Subevent | RFB | 52.97 | 52.17 | 48.70 |
| Subevent | RSFT | 70.24 | 68.17 | 67.33 |

RSFT（关系敏感特征训练）在因果和子事件关系上显著优于 ICL 和 RFB，F1 分别提升 4.65 和 8.72 个点，表明识别出的内部特征具有强判别力。然而，在时序关系上，RSFT 的 F1 (62.72) 仅略高于 ICL (62.64)，且低于因果关系的提升幅度，暗示时序关系的内部表示可能更为分散或依赖其他非敏感特征。

消融实验显示，对关系敏感特征进行消融导致性能大幅下降，而增强则带来提升，证实了特征的因果作用。值得注意的是，时序关系的敏感性高于因果和子事件关系，这与直觉中因果推理的复杂性相悖，可能源于时序关系在文本中往往有更明确的线性结构，使得内部特征更易被 SAE 捕获。

评估边界方面，本文仅使用 LLaMA-3.1-8B 单一模型，未验证特征在不同规模或架构模型中的稳定性。此外，UERBench 基于 MAVEN-ERE 构建，领域局限于新闻文本，缺乏科学或对话等复杂场景的测试。代码已开源，但 SAE 检查点依赖外部资源，复现时需确保版本一致性。

## 关联研究分析

从问题动机看，本文与 LLM-ERE 等性能优化路线形成互补。LLM-ERE 通过指令微调提升 ERE 准确率，但无法解释模型为何做出特定预测；而 UERLens 不追求 SOTA 性能，而是通过反事实干预揭示内部机制。这种差异源于任务目标的不同：前者关注“做对”，后者关注“为何做对”。然而，本文未探讨内部特征解释如何反向指导微调策略，例如是否可以通过增强特定特征来减少幻觉，这一潜在应用路径在论文中未展开。

从方法设计看，本文与 SVRECI 等基于叙事一致性的方法存在根本差异。SVRECI 通过超图传播进行结构验证，属于外部约束机制；而 UERLens 聚焦于内部特征分析，属于内部机制解释。SVRECI 旨在抑制噪声边，提升全局一致性；UERLens 旨在理解特征敏感性，提升可解释性。两者的结合可能是一个有趣的方向，但本文未涉及。此外，本文使用 SAE 进行特征分解，而传统可解释性研究多使用注意力权重，SAE 的优势在于其稀疏性和可解释性，但劣势在于训练成本高且依赖预训练检查点，这在动态场景下的适应性尚不明确。

## 总结

本文旨在解决 LLM 事件关系抽取中的黑盒问题，通过反事实数据构建与 SAE 特征识别，建立了内部特征与外部行为之间的因果联系。实验证明，关系敏感特征在因果和子事件关系上具有显著判别力，RSFT 在因果关系上 F1 达 72.05，较 ICL 提升 4.65 个点。然而，本文的边界在于仅验证了单一模型与静态文本场景，且时序关系的特征敏感性表现平淡，暗示内部表示的复杂性可能超出当前 SAE 的解析能力。当支持集规模扩大或引入多模态输入时，这些关系敏感特征是否仍能保持稳定，论文未给出回答。
