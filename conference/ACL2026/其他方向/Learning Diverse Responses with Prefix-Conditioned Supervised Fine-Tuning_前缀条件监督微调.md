# ACL2026最新论文 ｜Learning Diverse Responses with Prefix-Conditioned Supervised Fine-Tuning ｜前缀条件监督微调

研究机构：香港科技大学、中国科学技术大学

作者：Zhiyuan Fan、Guanqiao Chen、Yanyi Huang 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_221ec4d705f7)

> 大语言模型在测试时扩展中常因输出同质化导致探索效率低下，现有解码策略仅能调节局部概率分布，无法解决训练阶段因数据格式引发的根源性坍缩。本文指出，现代合成数据集普遍采用的“单指令多响应”（1-to-M）格式与标准监督微调（SFT）目标存在根本冲突，导致梯度干扰。通过为同一指令的不同响应分配语义中性前缀，P-SFT在训练时解耦了条件上下文，在推理时实现了输入侧扰动。该方法在多样性指标上取得显著增益，但其对硬推理准确率的提升幅度有限，且依赖特定的前缀设计。

## 研究背景

当模型面对同一指令需要生成多种有效响应时，标准自回归解码面临一个困境：模型倾向于收敛至单一模式。这一现象源于监督微调（SFT）的目标函数与数据结构的错配。在SFT中，模型最大化条件似然 $L_{SFT}(\theta) = -\sum_{(I,r)\in D} \log p_\theta(r | I)$，其中 $I$ 为指令，$r$ 为响应。当数据集包含同一指令 $I$ 对应的多个响应 $\{r^{(m)}\}_{m=1}^{M}$ 时，模型被迫在相同的隐状态 $h = Encoder(I)$ 下拟合多个不同输出，导致不同响应的梯度方向发生冲突，即优化干扰。

主流解决多样性坍缩的方法集中在推理阶段的解码控制或强化学习（RL）阶段的熵正则化。解码策略如 Top-p 采样通过截断概率分布来平衡质量与多样性，但其作用局限于局部 Token 概率，无法改变模型内部已收敛的单一模式；RL 方法如 DAPO 试图通过奖励塑形缓解熵坍缩，但往往忽略了 SFT 阶段已发生的多样性损失。这些方法假设多样性丧失主要源于 RL 训练或解码随机性不足，而忽视了 SFT 阶段数据格式对模型先验分布的塑造作用。本文的切入点在于，将多样性坍缩的根源前移至 SFT 阶段，认为 1-to-M 数据格式下的优化干扰是导致模型无法充分吸收数据多样性的根本原因，从而提出在训练阶段通过前缀解耦来重塑条件分布。

## 核心方法

### 方法参照系

标准 SFT 流程假设每个指令-响应对是独立的，模型在相同上下文 $I$ 下学习生成响应 $r$。本文问题与该通用流程的关键差异在于，现代蒸馏数据集（如 OpenThoughts）中同一指令对应多个语义不同但均正确的响应，标准 SFT 无法区分这些响应的条件来源，导致学习信号耦合。

### 前缀解耦训练

传统 SFT 在同一隐状态下拟合多响应，导致梯度冲突 $\nabla_\theta \log p_\theta(r^{(1)}|I) \cdot \nabla_\theta \log p_\theta(r^{(2)}|I) < 0$。P-SFT 在指令 $I$ 前拼接一个语义无关的前缀 $z_{I,m}$，构建新的条件上下文 $z_{I,m} \oplus I$。其优化目标为：

$$
L_{PreSFT}(\theta) = - \sum_{(I,\{r^{(m)}\}_{m=1}^{M})\in D} \sum_{m=1}^{M} \log p_\theta \left( r^{(m)} | z_{I,m} \oplus I \right)
$$

该公式的物理含义是，通过前缀将同一指令投影到高维隐空间的不同区域，使得不同响应的学习信号在参数空间中具有更高的正交性，从而缓解梯度干扰。前缀 $z_{I,m}$ 采用模板 “random state: {} \n\n”，其中占位符填充为 [0, 99999] 区间内均匀采样的整数，并在每个训练迭代中重新采样，以防止模型建立前缀 ID 与语义内容的刚性映射。这一设计解决了标准 SFT 中因相同条件上下文导致的模式收敛问题，使模型能够保留数据中固有的多种解题路径。

### 前缀条件推理

P-SFT 机制自然延伸至推理阶段，形成一种新的测试时扩展（TTS）策略。与标准推理在单一条件上下文下采样 $n$ 次不同，前缀条件推理通过在前缀空间 $\mathcal{Z}$ 上边缘化来近似后验分布：

$$
p_{scaled}(r | I) \approx \frac{1}{N} \sum_{n=1}^{N} p_\theta(r | z_n \oplus I), \quad z_n \sim \mathcal{Z}
$$

该公式表明，通过为每个采样样本分配不同的前缀 $z_n$，模型在输入侧受到扰动，从而探索不同的隐空间轨迹。这种输入侧扰动区别于传统的输出侧温度调整，它直接改变了模型的先验分布，使得采样过程从“在同一分布中随机抽取”转变为“在不同分布中结构化探索”。这一创新使得即使温度设为 0，模型仍能生成多样化的响应，因为多样性来源于前缀诱导的先验偏移而非解码随机性。

## 实验评估

实验在 Qwen2.5-7B-Instruct、Llama-3.1-8B-Instruct 和 Qwen3-8B 上进行，涵盖创意生成（Persona, Keyword, Full Story）和硬推理（AIME, HMMT, LiveCodeBench, GPQA-Diamond）任务。基线包括标准 SFT、标准推理（B-Inference）以及训练时多样性方法 DivPO。

| 模型 | 方法 | Persona Name | Keyword 1-Gram Entropy | NoveltyBench Distinct |
| :--- | :--- | :--- | :--- | :--- |
| Qwen3-8B | B-Inference | 6.32 | 2.84 | 1.04 |
| Qwen3-8B | P-Inference | 43.37 | 2.97 | 3.41 |
| Qwen2.5-7B-Instruct | B-Inference | 6.91 | 2.80 | 1.02 |
| Qwen2.5-7B-Instruct | P-Inference | 38.23 | 2.97 | 3.41 |

P-Inference 在多样性指标上显著优于 B-Inference，例如 Qwen3-8B 的 Persona Name 指标从 6.32 提升至 43.37，NoveltyBench Distinct 从 1.04 提升至 3.41。在推理基准上，P-SFT 在 AIME25 的 pass@32 上较 SFT 提升 4.38%，但 pass@1 仅微幅提升或持平，表明前缀主要增强了探索广度而非单点准确率。

| 前缀类型 | IF ACC | Format ACC | Persona Avg |
| :--- | :--- | :--- | :--- |
| Template (Ours) | 1.00 | 1.00 | 0.58 |
| Soft Embedding | 0.97 | 0.93 | 0.61 |
| Corpus Span | 0.92 | 0.95 | 0.63 |

消融实验显示，自然语言模板前缀在指令遵循准确率（IF ACC）和格式准确率（Format ACC）上均达到 1.00，优于软嵌入和语料跨度前缀。语料跨度前缀虽在多样性指标上略高，但引入了不可控的语义噪声，导致模型偶尔偏离任务意图。插入位置方面，将前缀置于指令之前（Before）优于置于之后（After），因为后者中断了因果依赖链，导致模型无法正确识别指令。

评估边界方面，论文未报告计算效率指标，且前缀条件推理在温度 0 下运行，可能限制了其在需要高随机性场景的适用性。代码未公开，但提供了详细的前缀采样策略和超参数设置（如学习率、批量大小），具备部分可复现性。

## 关联研究分析

从问题动机看，P-SFT 与 BACO（Base-Aligned Collaboration）均旨在恢复被对齐过程抑制的多样性，但作用阶段不同。BACO 在推理时通过路由机制在基础模型和对齐模型间切换，利用基础模型的多样性弥补对齐模型的坍缩；而 P-SFT 在训练时通过前缀解耦，从根源上避免 SFT 阶段的模式收敛。这一差异源于对多样性丧失根源的不同假设：BACO 认为对齐训练压缩了分布，P-SFT 认为 SFT 数据格式导致了优化干扰。若 SFT 阶段已充分保留多样性，BACO 的推理时路由可能冗余；反之，若 SFT 数据本身缺乏多样性，P-SFT 的前缀解耦也无法创造新内容。

从方法设计看，P-SFT 与 Min-k Sampling 分别作用于训练和推理阶段，形成互补。Min-k 通过分析 logit 分布的局部形状实现温度不变的自适应截断，解决解码时的温度敏感性问题；P-SFT 通过前缀扰动输入隐空间，解决训练时的条件耦合问题。Min-k 关注的是如何在给定分布下更稳定地采样，而 P-SFT 关注的是如何塑造分布本身以包含更多模式。两者结合可能进一步提升测试时扩展的效率，但论文未探索这种组合效果。前缀解耦是否会导致模型对特定前缀分布过拟合，从而降低在未见前缀下的泛化能力，论文未给出回答。

## 总结

P-SFT 旨在解决 SFT 阶段 1-to-M 数据格式导致的优化干扰问题，该问题被现有解码和 RL 方法忽视。通过引入语义中性前缀解耦条件上下文，P-SFT 在训练时重塑了模型的先验分布，使其能够保留多种解题路径。实验表明，该方法在多样性指标上取得显著增益（如 NoveltyBench Distinct 提升 228%），并在 AIME25 pass@32 上提升 4.38%，但 pass@1 提升有限。其边界在于，前缀设计依赖自然语言模板，且未验证与解码策略的组合效果。当支持集增大到 5-shot 时，前缀解耦的边际收益是否递减，论文未给出回答。
