# ACL2026最新论文 ｜AlphaContext: An Evolutionary Tree-based Psychometric Context Generator for Creativity Assessment ｜进化树心理测量上下文生成器

研究机构：华东师范大学

作者：Yixuan Wang、Yue Huang、Hong Qian 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.18398)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.18398)

> 创造力评估依赖高质量的未来情境刺激物，但专家手工设计成本高昂且难以规模化。现有LLM生成方法在隐式评估线索嵌入与叙事连贯性上存在结构性缺陷，且缺乏对风格多样性的系统性优化。AlphaContext通过规则引导的超树规划、MCTS句子级搜索、MAP-Elites多样性进化及虚拟参与者模拟，构建了从大纲到效度验证的完整生成闭环。该方法在7维质量指标上显著优于强LLM基线，但其高昂的计算开销与虚拟模拟的生态效度边界，限制了其在大规模实时评估场景中的直接部署。

## 研究背景

创造力评估的核心在于通过情境刺激诱发被试的新颖且适当的思维反应。Sternberg的三元智力理论指出，创造性思维在面临新颖情境时涌现，因此未来导向的情境因其高不确定性成为理想刺激物。然而，心理测量情境不同于普通叙事，它要求将评估线索隐式嵌入文本细节，同时保持全局叙事连贯，以支持心理测量效度。

当前主流路线分为两类：一是直接利用通用LLM生成故事，如DOC-v2采用大纲优先策略，但缺乏对评估线索的精细控制；二是结构化故事生成框架，如SS-GEN面向自闭症干预，但未针对创造力评估的效度要求设计。这些方法共同面临两个瓶颈：一是难以同时满足隐式线索对齐与全局连贯性，导致评估效度不足；二是生成结果风格单一，无法适应不同评估人群，且缺乏低成本的效度验证循环。AlphaContext的切入点在于将专家设计过程形式化为可搜索的超树结构，并引入进化优化与模拟评估，解决线索嵌入与多样性维护的双重挑战。

## 核心方法

### 方法参照系

本文问题属于心理测量上下文自动化生成，最接近的通用流程是“大纲-生成”范式（如DOC-v2）。关键差异在于：通用故事生成追求叙事流畅与娱乐性，而心理测量上下文必须隐式嵌入评估线索并保证测量效度，且需在同一主题下生成多样化风格以覆盖不同评估人群。

### 超树大纲规划与MCTS生成

传统树状规划中每条边连接父节点与单一子节点，难以同时组织话语结构与评估线索布局。AlphaContext引入超树（HyperTree），通过有向超边将父节点连接至子节点集合，实现层级化分治。形式化定义为 $H = (N, Q, R)$，其中 $R$ 为扩展规则集，规则 $r: n_p \rightarrow n_c$ 将父节点 $n_p$ 扩展为子节点集合 $n_c$。该设计动机在于对齐专家设计实践中“整体规划、层级细化”的认知模式，确保线索在结构层面的合理分布。

在生成阶段，MCTS-based Context Generator将上下文写作建模为句子级决策过程。节点 $s_p$ 定义为 $(t_p, N(s_p), V(s_p), O)$，其中 $t_p$ 为当前文本序列。UCT评分公式为：

$$UCT(s_p) = V(s_p) + c \sqrt{\frac{\ln N(q)}{N(s_p)}}$$

该公式平衡利用（$V(s_p)$）与探索（第二项），其中 $c$ 为超参数。针对长文本生成的短视问题，引入双视野评估机制：当即时评分 $V_{imm}(s_{p+1}) < \tau$ 时，采样短续写并重新评估，以获取更稳定的价值估计。这一机制解决了传统MCTS在长序列中因局部最优导致的连贯性断裂问题。

### MAP-Elites进化优化与模拟评估

MCTS生成的种子上下文风格单一，无法覆盖同一主题下的多样评估需求。AlphaContext引入MAP-Elites进化优化器，将上下文映射至三维行为空间 $B$，描述符函数 $b(\cdot)$ 定义为：

$$b(C) = (\phi_1(C), \phi_2(C), \phi_3(C))$$

其中 $\phi_1$ 为邻近范围（个人日常到公共议题），$\phi_2$ 为知识密度（客观证据支撑程度），$\phi_3$ 为观点多样性（利益相关者广度）。该设计动机在于显式优化风格多样性，避免生成结果同质化。

进化过程中，变异操作通过条件LLM编辑策略 $\pi_\theta$ 执行，操作集 $\Omega = \{INSERTION, DELETION, REPLACEMENT\}$ 修改关键段落。适应度 $F(C)$ 定义为叙事连贯性 $S_{coh}$、主题相关性 $S_{rel}$ 与参与度 $S_{eng}$ 的均匀平均：

$$F(C) = \frac{1}{3}(S_{coh}(C) + S_{rel}(C) + S_{eng}(C))$$

仅当新候选适应度高于当前精英时更新档案，确保每个行为 niche 内质量持续提升。

最后，Assessment-Guided Evolution Refiner通过虚拟参与者模拟验证效度。模拟器采用温度0抑制随机性，建模三种响应风格（talkative, normal, quiet）。上下文评估效度 $\Psi(C)$ 定义为各风格下创造力评分 $f_{cre}(Y_m)$ 的平均值：

$$\Psi(C) = \frac{1}{M} \sum_{m=1}^{M} f_{cre}(Y_m)$$

若 $\Psi(C)$ 低于专家阈值，则反馈至进化优化器迭代优化。该闭环解决了传统方法缺乏低成本效度验证的问题，确保生成上下文能可靠诱发创造性思维。

## 实验评估

实验在自建CreaTE数据集（203条专家审核标题-主题输入）上进行，基线覆盖通用LLM（GPT-5.1, Gemini-3.0-Pro-Preview）、长文本LLM（LongWriter）及结构化框架（DOC-v2, CRITICS, SS-GEN）。缺失专门针对心理测量生成的对比基线（如CPIG，因任务不同未比）。

| 方法 | Coherence (%) | Relevance (%) | Engagement (%) | Significance (%) |
| :--- | :--- | :--- | :--- | :--- |
| GPT-5.1 | 26.97 | 45.07 | 33.87 | 20.07 |
| SS-GEN | 60.22 | 92.09 | 68.60 | 92.88 |
| AlphaContext | 81.28 | 79.06 | 75.49 | 71.06 |

AlphaContext在7维指标上均排名第一，其中Coherence（81.28%）与Engagement（75.49%）提升显著，表明其规划与搜索机制有效增强了叙事连贯性与参与动机。SS-GEN在Relevance（92.09%）上高于AlphaContext（79.06%），但AlphaContext在Significance（71.06%）上反超SS-GEN（92.88%），显示其在评估线索深度上的优势。

消融实验显示，移除HyperTree Outline Planner（-w/o HOP）导致Coherence下降至77.96%，移除MCTS-based Context Generator（-w/o MCG）导致Relevance下降至70.20%，表明结构规划与搜索生成对质量贡献最大。移除Evolutionary Context Optimizer（-w/o ECO）后Diverse Verbs从96.06%降至93.36%，证实MAP-Elites对多样性的关键作用。

评估边界方面，LLM评判者（DeepSeek-V3.1）与人类偏好的一致性通过配对比较验证，但未报告具体相关系数。计算成本上，AlphaContext平均生成时间226.99秒，token消耗12.89k，远高于GPT-5.1的23.50秒与2.36k，限制了实时应用。代码已开源，但超参数（如UCT中的$c$、阈值$\tau$）未在正文中详细披露，复现性依赖附录。

## 关联研究分析

从问题动机看，AlphaContext与CPIG均关注LLM生成心理测量项目，但CPIG针对短项生成，未解决长文本未来情境的连贯性与隐式线索嵌入问题。AlphaContext通过超树结构将专家设计过程形式化，解决了长文本中线索与主题对齐的细粒度约束，这是任务特性（长文本、隐式线索）决定的必要设计，而非通用故事生成框架的简单扩展。

从方法设计看，AlphaContext与DOC-v2同属大纲优先范式，但DOC-v2采用线性大纲与遵循控制器，缺乏对评估线索的显式布局与多样性优化。AlphaContext引入超树与MAP-Elites，将多样性优化从隐式依赖LLM采样转变为显式行为空间搜索，这一差异源于创造力评估对风格多样性的刚性需求，而非通用叙事生成的可选优化。虚拟参与者模拟的引入则填补了效度验证的空白，但其与真实人类反应的相关性是否足以支撑效度结论，论文未提供大规模实证数据。

## 总结

AlphaContext旨在解决心理测量上下文生成中隐式线索嵌入与风格多样性维护的矛盾，现有方法因缺乏结构化规划与效度验证闭环而失效。本文通过超树规划、MCTS生成、MAP-Elites进化与模拟评估，构建了完整的生成-优化-验证闭环，在CreaTE数据集上Coherence达81.28%，Significance达71.06%，显著优于GPT-5.1与SS-GEN。其边界在于226.99秒/条的高计算开销，以及虚拟参与者模拟缺乏真实人类效度验证。当评估场景要求实时生成或大规模部署时，MCTS与MAP-Elites的计算成本是否可通过近似搜索或并行化降低，论文未给出回答。
