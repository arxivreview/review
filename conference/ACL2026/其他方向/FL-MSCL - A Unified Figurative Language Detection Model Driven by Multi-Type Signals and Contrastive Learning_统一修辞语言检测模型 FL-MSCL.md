# ACL2026最新论文 ｜FL-MSCL: A Unified Figurative Language Detection Model Driven by Multi-Type Signals and Contrastive Learning ｜统一修辞语言检测模型 FL-MSCL

作者：Lu Shijia、Fumiyo Fukumoto、Huang Xiaoxi 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_28a0c3df898b)

> 修辞语言检测长期受困于隐喻、转喻与明喻在语义上的高度重叠，导致单一类别的二分类器无法区分认知机制迥异的修辞类型。现有方法或依赖静态知识注入，或仅针对单一修辞优化，缺乏统一框架解决细粒度消歧。FL-MSCL 通过动态示例检索与监督对比学习构建四分类统一框架，在多个基准上取得 SOTA 性能。该框架验证了显式边界建模的有效性，但其对骨干网络性能的依赖及跨语言泛化能力仍存疑。

## 研究背景

当模型面对“His words cut deeper than a knife”与“The White House issued a statement”时，二者均偏离字面意义，但前者依赖概念映射（隐喻），后者依赖邻近性引用（转喻）。这种表面相似性掩盖了认知驱动机制的本质差异，导致传统基于词汇-语境不匹配的静态检测器失效。为区分这些细粒度类别，需引入能捕捉语义边界的方法，监督对比学习（Supervised Contrastive Learning, SCL）通过优化表示空间中的类间距离，成为解决此类歧义的关键工具。

修辞语言处理的主流路线从早期的规则匹配演进至基于预训练语言模型（PLMs）的上下文表示学习。MelBERT 和 BasicBERT 等模型通过静态知识注入提升了隐喻检测性能，但受限于单一类别目标，无法处理多修辞间的交叉歧义。即使引入多任务学习，现有工作也多聚焦于自然语言推理等宽泛理解任务，而非细粒度分类。FL-MSCL 的切入点在于将隐喻、转喻、明喻与字面语言合并为统一四分类任务，并通过动态检索替代静态定义，以解决认知相关修辞的消歧问题。

## 核心方法

### 方法参照系

本文问题属于修辞语言细粒度分类，最接近的通用流程为基于 PLMs 的二分类检测。关键差异在于：传统流程假设修辞类型独立，而本文需同时建模四类间的语义重叠，要求模型在表示空间中显式区分认知机制不同的修辞类别，而非仅判断是否偏离字面意义。

### 动态示例检索机制

静态知识注入（如 MelBERT 的字典定义）在上下文敏感任务中失效，因为固定定义无法适应动词隐喻等动态语境。FL-MSCL 将输入序列构造为包含目标句与检索示例的复合序列 $x = \{x_1, x_2, \dots, x_n\}$，其中示例通过 Sentence-BERT 和 FAISS 从候选池中检索语义最相似样本。该机制将字典注入范式转化为基于示例的类比信号，为复杂修辞提供“语义锚点”。消融实验显示，移除动态提示后 VUA-Verb 性能从 88.9 降至 81.9，证实检索示例对上下文敏感任务的必要性。

### 监督对比学习优化

单一交叉熵损失无法强制混淆类别间的边界，导致隐喻与转喻在表示空间中重叠。FL-MSCL 在句向量 $z$ 上应用 InfoNCE 损失：

$$L_{SCL} = -\frac{1}{|P(i)|} \sum_{p \in P(i)} \log \frac{\exp(z_i \cdot z_p / \tau)}{\sum_{a \in A(i)} \exp(z_i \cdot z_a / \tau)}$$

该公式拉近同类样本、推远异类样本，$\tau$ 为温度参数。最终损失 $L_{total} = L_{CE} + \lambda L_{SCL}$ 结合分类与对比目标。此设计解决了静态模型依赖表面特征而非认知接地的问题，使模型在 MOH-X 上达到 86.2 F1，优于仅用对比学习的 MiceCL（85.2 F1）。

## 实验评估

| 数据集 | 方法 | F1 |
| :--- | :--- | :--- |
| VUA-Verb | FL-MSCL | 88.9 |
| VUA-Verb | WPDM | 74.1 |
| MOH-X | FL-MSCL | 86.2 |
| MOH-X | MiceCL | 85.2 |
| ReLocaR | FL-MSCL | 89.5 |
| ReLocaR | PreWin | 84.8 |

实验覆盖隐喻（VUA-Verb, MOH-X）、转喻（ReLocaR）与明喻（PLMsSimile）基准，基线包括经典 RNN/Transformer、SOTA 隐喻模型（BasicBERT, WPDM）及 LLM（GPT-4）。FL-MSCL 在 VUA-Verb 上以 88.9 F1 显著超越 WPDM（74.1 F1）和 GPT-4 5-shot（67.6 F1），表明动态提示与对比学习在细粒度检测上的优势。

| 配置 | Precision | Recall | F1 |
| :--- | :--- | :--- | :--- |
| w/o Pro + w/o Cont | 83.8 | 80.7 | 80.7 |
| Prompt + w/o Cont | 84.1 | 82.1 | 81.8 |
| w/o Pro + Cont | 82.9 | 83.2 | 83.0 |
| FL-MSCL (Full) | 84.1 | 88.8 | 86.1 |

消融实验显示，完整模型较无提示无对比基线提升 5.4 个 F1 点，其中对比学习贡献最大（+2.3 点），动态提示次之（+1.1 点）。移除动态提示导致 VUA-Verb 性能骤降 7.0 点，揭示检索示例对动词隐喻的不可替代性。

评估协议采用标准训练/测试划分，指标涵盖 Macro-F1 与 Accuracy。代码已开源，但论文未报告置信区间及计算效率数据，难以评估部署可行性。骨干网络 DeBERTa-v3-base 的性能可能主导结果，方法贡献与预训练能力的区分不足。

## 关联研究分析

从问题动机看，FL-MSCL 与 MiceCL 同属对比学习路线，但 MiceCL 聚焦隐喻二分类，而 FL-MSCL 扩展至四分类消歧。这一差异源于任务特性：隐喻检测仅需判断偏离字面意义，而转喻与明喻需区分认知机制。FL-MSCL 通过统一框架解决此类歧义，但 MiceCL 在单一隐喻任务上的性能（85.2 F1）接近 FL-MSCL（86.2 F1），暗示多任务学习可能引入负迁移，论文未深入分析此现象。

从方法设计看，FL-MSCL 与 WPDM 均利用外部知识，但 WPDM 依赖领域概念挖掘的静态知识，而 FL-MSCL 采用动态示例检索。这一差异源于上下文敏感性：WPDM 在 VUA-Verb 上仅获 74.1 F1，而 FL-MSCL 达 88.9 F1，表明动态检索更适应动词隐喻等复杂场景。然而，FL-MSCL 未探索检索池规模对性能的影响，查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

FL-MSCL 针对修辞类型间边界模糊的核心矛盾，抓住动态语境与认知机制差异的切入点，通过动态示例检索与监督对比学习构建统一四分类框架。实验证明其在 VUA-Verb 上达 88.9 F1、MOH-X 上达 86.2 F1，验证了显式边界建模的有效性。然而，论文仅评估英语文本，未涉及低资源语言或多模态场景，且未区分骨干网络与方法本身的贡献。当支持集增大到 5-shot 时，动态检索的边际收益是否递减，论文未给出回答。
