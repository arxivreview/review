# ACL2026最新论文 ｜TRN-R1-Zero: Text-rich Network Reasoning via LLMs with Reinforcement Learning Only ｜纯强化学习驱动的文本富网络零样本推理

研究机构：澳大利亚昆士兰大学

作者：Yilun Liu、Ruihong Qiu、Zi Huang

论文原文见 [arXiv](https://arxiv.org/abs/2604.19070)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.19070)

> 文本富网络（Text-Rich Networks, TRNs）的零样本节点分类要求模型在无目标域监督下，同时整合节点文本语义与图拓扑关系。现有大语言模型（LLM）方法或将其视为静态特征提取器，或依赖外部大模型蒸馏思维链（Chain-of-Thought, CoT）数据，导致泛化能力受限且计算开销巨大。本文提出 TRN-R1-Zero，通过纯强化学习（Reinforcement Learning, RL）直接优化基础 LLM，引入邻居感知奖励机制以激活内在推理能力。该框架在跨域零样本任务上超越了依赖蒸馏的基线，但其在复杂拓扑结构上的推理深度及大规模图部署效率仍存疑。

## 研究背景

文本富网络中的节点分类面临双重挑战：既要理解非结构化文本的深层语义，又要捕捉节点间隐含的拓扑依赖。传统图神经网络（GNN）擅长结构聚合但缺乏语义理解，而 LLM 虽具备强大语义能力，却缺乏原生的图结构归纳偏置。这种模态间的语义鸿沟导致简单拼接或投影机制难以实现有效融合，尤其在零样本场景下，模型无法依赖目标域的标签分布进行微调，必须依靠预训练知识中的泛化能力。

现有 LLM 处理图任务的主流路线分为编码器范式与生成器范式。编码器范式将 LLM 作为文本编码器，生成嵌入后由外部算法聚合，如 ZeroG 和 LLaGA，但这类方法将 LLM 局限于特征提取，未利用其推理潜力。生成器范式将分类重构为标签生成任务，如 GraphGPT 和 Graph-R1，通过软嵌入或自然语言描述注入结构信息。然而，Graph-R1 等近期工作依赖大型推理模型（Large Reasoning Models, LRMs）生成 CoT 数据进行监督微调（Supervised Fine-Tuning, SFT），这不仅引入了对特定大模型的依赖，还导致训练数据分布与基础模型能力不匹配，限制了跨域泛化。

TRN-R1-Zero 的切入点在于移除 SFT 与外部蒸馏环节，直接通过 RL 优化基础 LLM 的策略。其核心假设是：LLM 内在具备处理结构化关系的潜力，只需通过针对图任务设计的奖励信号即可激活。这一思路规避了 CoT 数据生成的成本与偏差，试图在零样本条件下直接建立“邻居信息-分类决策”的映射关系，从而解决现有方法在未见域上泛化能力弱的问题。

## 核心方法

### 方法参照系

TRN-R1-Zero 属于 LLM 图推理智能体路线，其参照系为基于 GRPO（Group Relative Policy Optimisation）的 LLM 后训练框架。标准流程通常包含两个阶段：首先使用 LRM 生成高质量 CoT 数据，随后通过 SFT 让基础模型模仿这些推理轨迹。本文的关键差异在于完全移除 SFT 阶段，仅保留 RL 优化，并针对图任务特性改造了奖励函数，使其不再依赖外部生成的推理轨迹，而是直接基于分类结果与邻居影响程度进行优化。

### 邻居感知策略目标

在标准 GRPO 中，奖励信号通常仅基于最终答案的正确性，忽略了图结构中邻居节点对决策的贡献差异。本文在策略优化目标中引入邻居感知机制，通过 Margin Gain 度量邻居聚合对分类置信度的影响，并据此动态缩放奖励。

$$
\Delta_i = \text{Margin}(\tilde{e}_i, y_i) - \text{Margin}(e_i, y_i)
$$

该公式计算节点 $i$ 在引入邻居聚合后的分类边际（Margin）变化量。$\Delta_i > 0$ 表示邻居信息增强了分类置信度，$\Delta_i < 0$ 表示邻居信息造成干扰。这一设计解决了此前方法中“所有邻居同等重要”的假设失效问题，使模型能够区分“信息性邻居”与“噪声邻居”。

### 基于 Margin Gain 的奖励重塑

基于 Margin Gain，本文设计了指数形式的奖励重塑因子，以放大高影响样本在策略梯度更新中的权重。

$$
R_i = (s_{\text{format}} + s_{\text{acc}}) \cdot \exp(\alpha |\Delta_i|)
$$

其中 $s_{\text{format}}$ 和 $s_{\text{acc}}$ 分别衡量输出格式合规性与答案正确性，$\alpha$ 为温度超参数。当 $|\Delta_i|$ 较大时，奖励呈指数增长，迫使模型在训练过程中重点关注那些邻居信息对决策起关键作用的样本。这一机制隐含了对噪声邻居的过滤：当邻居信息干扰决策（$\Delta_i < 0$ 且绝对值大）时，虽然奖励被放大，但 $s_{\text{acc}}$ 为 0，导致负梯度更新，从而抑制模型对错误邻居的依赖。

## 实验评估

实验在 Citeseer、History、Cora、WikiCS、Instagram 和 Photo 六个数据集上进行，涵盖引用、超链接、社交和共购四种关系类型。基线覆盖纯 LLM（GPT-4o, Qwen2.5 系列）、图基础模型（ZeroG, LLaGA）及推理 LLM（Graph-R1）。值得注意的是，基线中未包含 NAG 或 TAG-DLM 等原生结构编码方法，这可能低估了纯 LLM 路线与结构原生路线的性能差距。

| 模型 | 规模 | Cora Acc (%) | WikiCS Acc (%) | Instagram Acc (%) | Photo Acc (%) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| GPT-4o | - | 70.30 | 42.42 | 69.93 | 63.09 |
| Qwen2.5-14B-it | 14B | 71.44 | 55.60 | 67.22 | 68.26 |
| Graph-R1 | 14B | 68.15 | 73.25 | 52.03 | - |
| TRN-R1-Zero | 7B | 72.59 | 73.63 | 54.76 | 65.12 |

TRN-R1-Zero 在 7B 规模下，Cora 准确率 72.59% 超过 GPT-4o 的 70.30%，WikiCS 准确率 73.63% 显著高于 Graph-R1 的 73.25%。然而，在 Instagram 数据集上，TRN-R1-Zero（54.76%）低于 Qwen2.5-14B-it（55.60%），表明其在社交网络这种高噪声、低文本信息密度场景下的泛化能力受限。

消融实验显示，引入邻居感知奖励后，Cora 上的准确率从基线奖励的 66.00% 提升至 72.59%（据领域综述数据推断，原文图5a显示显著提升）。响应长度实验表明，TRN-R1-Zero 在 Cora 上的平均响应长度为 152.57 tokens，远低于 Graph-R1 的 930.47 tokens，说明 RL 优化促使模型生成更简洁的推理轨迹，而非冗长的 CoT 模仿。

评估边界方面，本文仅使用单一 AMD MI300X GPU 进行实验，未报告多卡扩展性。所有数据集采用 60/20/20 划分，但未提供置信区间或多次运行的方差统计。代码已开源，但超参数 $\alpha=10$ 和 LoRA rank=64 的敏感性分析缺失，限制了结果的可复现性验证。

## 关联研究分析

从问题动机看，TRN-R1-Zero 与 Graph-R1 的核心差异在于对“推理能力来源”的假设。Graph-R1 认为推理能力需通过模仿 LRM 的 CoT 轨迹获得，因此依赖 SFT 阶段；而 TRN-R1-Zero 认为推理能力是 LLM 内在属性，只需通过 RL 奖励信号即可激活。这一差异源于对 LLM 预训练知识中结构化推理潜力的不同判断。Graph-R1 在 WikiCS 上表现优异（73.25%），但其在 Instagram 上的性能（52.03%）低于 TRN-R1-Zero（54.76%），暗示 CoT 蒸馏可能在低文本信息密度场景下引入过拟合，而纯 RL 优化更适应噪声环境。

从方法设计看，TRN-R1-Zero 与 ZeroG 代表了两种截然不同的结构利用范式。ZeroG 通过外部 GNN 聚合邻居嵌入，再与 LLM 嵌入对齐，属于“结构外置”；TRN-R1-Zero 通过 Prompt 中的邻居文本采样，让 LLM 直接处理拓扑信息，属于“结构内化”。ZeroG 在 Cora 上准确率 62.55%，远低于 TRN-R1-Zero 的 72.59%，表明在零样本场景下，LLM 直接处理文本邻居比 GNN 聚合嵌入更有效。然而，ZeroG 在 Photo 数据集上（46.27%）与 TRN-R1-Zero（65.12%）的差距缩小，暗示当文本信息丰富时，GNN 的结构聚合可能提供额外增益，而纯文本推理可能丢失部分拓扑细节。

## 总结

TRN-R1-Zero 旨在解决 LLM 在文本富网络零样本推理中依赖外部蒸馏与 SFT 的瓶颈。其切入点在于证明 LLM 内在具备图结构推理潜力，可通过纯 RL 优化激活，无需 CoT 数据。方法上，通过 Margin Gain 动态缩放奖励，使模型聚焦于邻居信息对决策影响显著的样本。实验表明，7B 模型在 Cora 上达到 72.59% 准确率，超越 GPT-4o，且响应长度仅为 Graph-R1 的 1/6。然而，其在 Instagram 等低文本信息密度数据集上的性能未超越 14B 基线，暴露了纯文本推理在高噪声拓扑下的局限。当邻居文本信息稀疏且拓扑结构复杂时，纯 RL 优化能否捕捉到 GNN 聚合才能提取的深层结构特征，论文未给出回答。
