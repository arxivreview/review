# ACL2026最新论文 ｜Resolving the Security-Auditability Dilemma with Auditable Latent Chain-of-Thought Alignment ｜可审计潜空间思维链对齐

作者：Guan Wang、Biyu Zhou、Xuehai Tang 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_8d94c8ee2c27)

> 大语言模型（LLM）的安全对齐长期面临“浅层对齐”困境，即模型仅依赖表面特征拒绝有害请求，缺乏深层推理审计能力，导致面对自适应攻击时极易失效。现有基于显式思维链（CoT）的方法虽提升了鲁棒性，但暴露的文本推理过程成为攻击者的优化靶点，并引发内部有害内容复制风险。ALCA 通过将安全推理过程从离散文本迁移至连续潜空间，并引入受限自解码机制，在消除文本攻击面的同时保留了监督审计能力。该框架在自适应攻击防御上显著优于显式 CoT 基线，但其潜空间推理的跨模型泛化性及对非文本模态的适用性仍未得到充分验证。

## 研究背景

安全对齐的核心矛盾在于模型生成能力与滥用风险之间的张力。传统强化学习从人类反馈（RLHF）方法依赖输出监督，训练模型形成模式匹配式的拒绝行为，这种“浅层对齐”将安全推理过程视为不可监督的黑箱，导致模型无法解释“为何拒绝”，在面对精心构造的对抗性输入时表现出系统性脆弱。为提升鲁棒性，近期研究转向推理增强对齐，强制模型外化安全推理为显式 CoT，以实现训练阶段的监督与生成后的验证。

然而，显式 CoT 引入了新的安全漏洞：一方面，暴露的推理步骤为自适应攻击者提供了语义路线图，使其能迭代优化攻击策略；另一方面，推理上下文中的有害 token 可能被模型无意识复制至最终输出，形成内部泄露风险。这构成了“安全-可审计性困境”：模型需要安全推理以维持鲁棒性，但文本形式的推理暴露又破坏了安全性。ALCA 的切入点在于解耦安全推理的载体与表现形式，将推理过程隐式化以阻断攻击面，同时通过特定机制保留其可审计性。

## 核心方法

### 方法参照系

ALCA 属于推理增强对齐与内部机制干预的交叉路线。与直接输出文本 CoT 或仅调整 logits 的传统方法不同，ALCA 的关键差异在于改变生成载体：将安全推理步骤完全映射至连续潜空间，绕过语言模型头（lm_head），从而在物理层面消除有害 token 的实例化。

### 潜空间自回归推理（LAD）

LAD 机制解决了显式 CoT 中有害 token 被复制及作为攻击反馈的问题。当探针分类器触发潜空间模式时，模型不再生成文本，而是将最后一层 Transformer 的隐藏状态 $z_{j,i}$ 直接作为下一 token 的嵌入输入，执行 $n$ 次自回归前向传播，生成潜向量序列 $z_j = (z_{j,1}, \dots, z_{j,n})$。为确保 $z_j$ 在功能上等价于原始文本步骤 $c_j$，ALCA 采用混合损失函数：

$$
\mathcal{L}_{\text{LAD}} = \mathcal{L}_{\text{latent}} + \lambda \mathcal{L}_{\text{causal}}
$$

其中 $\mathcal{L}_{\text{latent}} = \|z_{j,n} - z^*_{j,n}\|_2$ 通过回归损失对齐潜向量终点与教师模型的目标隐藏状态，确保语义完整性；$\mathcal{L}_{\text{causal}}$ 则监督后续通用步骤的生成，强制潜向量作为因果前驱引导无害输出。这一设计使得安全信号在连续空间中传递，既避免了离散 token 的泄露，又保留了其对最终输出的因果影响力。

### 受限自解码机制

自解码机制解决了潜空间推理的“黑箱”问题，满足高保真审计需求。该机制将潜向量 $z_j$ 视为条件输入，结合一个非文本的连续解码嵌入 $e_{\text{decode}}$（作为私有“密钥”），让模型自回归生成文本重构 $\hat{c}_j$。训练目标为最小化重构文本与真实推理步骤 $c_j$ 之间的交叉熵损失：

$$
\mathcal{L}_{\text{decode}} = -\sum_{t=1}^{|c_j|} \log P(c_{j,t} | c_{j,<t}, z_j, e_{\text{decode}})
$$

$e_{\text{decode}}$ 仅在内部机制中可访问，用户无法通过文本输入触发解码，从而防止攻击者利用解码过程提取安全策略。该机制确保了潜空间推理并非不可解释，而是仅在授权监督下可逆，实现了安全性与可审计性的统一。

## 实验评估

实验基于 Llama-3.1-8B-Instruct 进行，对比了无推理、显式 CoT（STAIR）及隐藏 CoT 基线。ALCA 在自适应攻击下的攻击成功率（ASR）为 9.0%，较显式 CoT 基线 STAIR 的 21.7% 降低 58.5%，较无防御模型的 58.2% 降低 84.5%。在通用攻击下，ALCA 与隐藏 CoT 基线持平，均为 15.1%，表明潜空间化未牺牲基础安全性。

| 设置 | 通用 ASR (%) ↓ | 自适应 ASR (%) ↓ |
| :--- | :--- | :--- |
| No Reasoning | 58.2 | 68.4 |
| Explicit CoT (Full Exposure) | 15.1 | 76.3 |
| Hidden CoT (Attacker-Masked) | 15.1 | 25.9 |
| ALCA | 15.1 | 9.0 |

消融实验揭示了混合损失的必要性。仅使用潜空间损失（Latent-Only）的模型虽能学习鲁棒策略，但审计能力在训练中途崩溃，表现为表示过拟合；仅使用因果损失（Causal-Only）的模型则缺乏语义支撑，无法达到鲁棒性。这表明 $\mathcal{L}_{\text{latent}}$ 提供防御结构，而 $\mathcal{L}_{\text{causal}}$ 作为正则化项防止信息丢失，二者协同作用至关重要。自解码保真度实验显示，重构文本与真实推理的语义相似度达 0.96，BLEU-4 为 0.86，ROUGE-L 为 0.91，证实了潜空间推理的高保真可审计性。

评估边界方面，论文未报告置信区间，且仅在单一骨干模型上验证。代码未公开，探针分类器依赖第 28 层隐藏状态，超参数 $n$ 和 $\lambda$ 的具体取值未在正文详细列出，限制了跨模型复现性。

## 关联研究分析

从问题动机看，ALCA 与 ARMOR 均致力于解决浅层对齐的脆弱性，但路径截然不同。ARMOR 通过细致推理提取用户核心意图，在文本层面实现意图级对齐，其优势在于可解释性强，但显式推理仍暴露于自适应攻击之下。ALCA 则通过潜空间化从物理层面消除攻击面，其核心差异在于将“推理可见性”从安全约束中解耦，而非在可见推理中增强防御。这种差异源于对“攻击面”定义的不同：ARMOR 视推理内容为需保护的资产，ALCA 视推理载体为需隐藏的漏洞。

从方法设计看，ALCA 与 AlignTree 同属内部表示干预，但干预粒度不同。AlignTree 在解码阶段通过内部表示引导 logits，属于推理时干预，无需修改模型权重，但依赖内部信号的稳定性。ALCA 则通过训练改变生成过程本身，将安全推理内化为潜空间动态，属于训练时对齐。ALCA 的 1.9x 吞吐量优势表明其推理效率优于显式 CoT，但相比 AlignTree 的轻量级部署，ALCA 需要白盒访问及训练成本。这种取舍反映了“根本性消除漏洞”与“实时动态适应”之间的权衡，ALCA 更倾向于前者，但牺牲了跨模型迁移的灵活性。

## 总结

ALCA 旨在解决安全对齐中“显式推理提升鲁棒性但暴露攻击面”的矛盾，其核心创新在于将安全推理迁移至连续潜空间，并通过受限自解码机制保留审计能力。实验证明，ALCA 将自适应攻击 ASR 从 21.7% 降至 9.0%，显著优于显式 CoT 基线，且自解码保真度达 0.96 语义相似度。然而，论文仅在 Llama-3.1-8B-Instruct 上验证，未提供跨模型迁移实验，且潜空间推理的普适性依赖于特定模型的内部表示结构。当骨干模型更换或训练数据分布变化时，潜空间中的安全信号是否仍能保持线性可解释性与因果一致性，论文未给出回答。
