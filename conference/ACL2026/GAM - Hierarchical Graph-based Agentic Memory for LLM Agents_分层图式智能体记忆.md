# ACL2026最新论文 ｜GAM: Hierarchical Graph-based Agentic Memory for LLM Agents ｜分层图式智能体记忆

研究机构：浙江大学、美国罗格斯大学

作者：Zhaofen Wu、Hanrong Zhang、Fulin Lin 等 12 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.12285)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.12285)

> 长时程交互中，智能体需在实时捕获新信息与保持既有知识稳定之间取得平衡，但现有统一流式记忆系统因缺乏写隔离机制，易受瞬时噪声污染导致记忆丢失与语义漂移。GAM 通过解耦记忆编码与固化过程，将实时对话隔离在局部事件进展图中，仅在检测到语义边界时将其整合至全局主题关联网络，从而在结构上阻断噪声向长期记忆的传播。该框架结合图引导的多因子检索策略，在 LoCoMo 和 LongDialQA 基准上实现了推理准确率与计算效率的双重提升。其核心价值在于以生物启发式状态机替代启发式规则，但语义边界检测的 LLM 开销与开放域任务上的性能短板，限制了其在高延迟敏感场景中的普适性。

## 研究背景

当智能体处理连续对话时，新输入的信息直接写入长期存储会引发两类失效：一是既有节点因连接弱化而被结构性遗忘，即记忆丢失；二是不同主题被错误混淆，导致主题一致性扭曲，即语义漂移。这两种现象共同构成了记忆污染的核心风险，其根源在于统一流式记忆系统（Unified Stream-based Memory Systems）缺乏对写入操作的隔离机制。为应对此问题，离散结构化记忆架构（Discrete Structured Memory Architectures）通过刚性模式组织信息以保障稳定性，但其静态特性无法捕捉叙事流的实时演化，导致话语表示碎片化。

该领域的主流路线在灵活性与稳定性之间陷入两难：MemGPT 等操作系统类比系统虽实现了分层调度，但新信息直接合并至长期存储的“开门”策略使其易受污染；A-Mem 等自反思智能体依赖任意 token 计数或时间步触发更新，未能基于语义完整性进行决策。GAM 的切入点在于将记忆生命周期显式解耦为两个阶段：情景缓冲阶段（Episodic Buffering Phase）在局部图中隔离瞬时上下文，语义固化阶段（Semantic Consolidation Phase）仅在语义漂移超过阈值时执行原子化整合。这一设计借鉴了睡眠依赖记忆固化的生物机制，旨在从结构上消除编码与固化之间的冲突，而非依赖检索优化或人工状态定义来缓解矛盾。

## 核心方法

### 方法参照系

GAM 属于记忆架构设计路线，其标准流程通常包含记忆存储、更新与检索三个环节。与 Mem0 等基于原子事实提取的工业标准不同，GAM 的关键差异在于引入状态机控制更新时机，将“何时写入长期记忆”从固定规则转变为基于语义完整性的动态决策，从而在架构层面实现写隔离。

### 状态机驱动的语义边界检测

传统方法在固定窗口或时间步触发记忆更新，导致语义不完整的片段被强行固化，引发噪声传播。GAM 将记忆管理形式化为推理时在线决策过程，通过语义发散指标 $b_t \in \{0, 1\}$ 作为低成本的策略触发器，仅在累积局部上下文与全局状态偏离超过容忍度 $\epsilon$ 时执行固化。该机制解决了固定触发器无法识别叙事单元语义边界的问题，确保全局记忆仅被语义完整的单元更新。

$$
b_t = \mathbb{I}(\Delta(G_{topic}^{(t)}, G_{event}^{(t)}) > \epsilon)
$$

其中 $\Delta$ 为语义距离度量，$\mathbb{I}$ 为指示函数。该公式的物理含义是：当局部事件图与全局主题图的语义差异超过阈值时，系统从缓冲状态切换至固化状态，执行原子化整合。

### 分层图式记忆架构与多因子检索

为支撑状态切换，GAM 构建了分层图式记忆架构，将存储解耦为全局主题关联网络（Topic Associative Network, TAN）与局部事件进展图（Event Progression Graph, EPG）。TAN 存储高维语义簇，EPG 捕获实时交互依赖，二者通过跨层边 $E_{cross}$ 关联。检索时，系统采用图引导多因子策略，通过时间、置信度与角色信号对候选记忆进行重排序，解决了扁平向量检索无法利用拓扑结构进行精确上下文恢复的问题。

$$
P_{final}(v|q) = P_{sem}(v|q) \prod_{k \in K} \beta_k^{\mathbb{I}_k(v,q)}
$$

其中 $P_{sem}$ 为交叉编码器计算的基础语义概率，$\beta_k$ 为调制因子，$K=\{time, conf, role\}$。该公式表明：最终检索分数由基础语义匹配度与多个上下文约束信号的乘积决定，确保仅当记忆在时间、置信度或角色上与查询一致时才被提升，避免关键词匹配导致的虚假召回。

## 实验评估

实验在 LoCoMo 和 LongDialQA 两个长时程交互基准上进行，基线覆盖启发式方法（MemoryBank、ReadAgent）、统一流式系统（MemGPT、MemoryOS、Mem0）及自反思智能体（A-Mem），但未包含 MAGMA 等最新多图谱架构。在 LoCoMo 上，GAM 在 Qwen 2.5-7B 骨干下取得平均 F1 40.00，显著优于 Mem0 的 35.38 和 MemoryOS 的 28.86；在 LongDialQA 上，GAM 在 Qwen 2.5-7B 下取得平均 F1 12.55，较 MemoryOS 的 6.76 提升 86%。

| 数据集 | 骨干模型 | 方法 | Avg F1 | BLEU-1 |
| :--- | :--- | :--- | :--- | :--- |
| LoCoMo | Qwen 2.5-7B | Mem0 | 35.38 | 28.67 |
| LoCoMo | Qwen 2.5-7B | MemoryOS | 28.86 | 22.25 |
| LoCoMo | Qwen 2.5-7B | **GAM** | **40.00** | **32.99** |
| LongDialQA | Qwen 2.5-7B | MemoryOS | 6.76 | 5.11 |
| LongDialQA | Qwen 2.5-7B | **GAM** | **12.55** | **12.43** |

消融实验显示，移除事件进展图（w/o EPG）导致 F1 从 40.00 降至 29.28，降幅最大，表明叙事结构对时间推理的鲁棒性至关重要；移除状态切换机制（w/o SSM）使 F1 降至 35.94，验证了解耦编码与固化对防止污染的有效性。在效率方面，GAM 每查询消耗 1,370.18 tokens，较 Mem0 的 1,533.94 降低 11%，同时延迟从 0.51 秒增至 0.80 秒，实现了精度与效率的平衡。

评估边界方面，GAM 在开放域任务上表现最弱，因其问题弱定位且缺乏时间或角色约束，结构化剪枝的收益有限；在 GPT-4o-mini 骨干下，Mem0 在时间 F1 上仍领先（56.42 vs 51.96），表明当骨干具备强时间推理能力时，直接检索原始痕迹可能保留更精确的时序线索。论文未提供代码仓库，且语义边界检测依赖 LLM 调用，其开销在高频交互场景中的累积效应未充分量化。

## 关联研究分析

从问题动机看，GAM 与 Mem0 的核心差异在于写入粒度的控制策略。Mem0 采用提取-更新-检索三阶段流程，将对话分解为原子事实并即时存储，其优势在于低延迟与工程可控性，但缺乏对语义完整性的判断，导致瞬时噪声直接进入长期存储。GAM 则通过状态机延迟写入，仅在语义边界处执行整合，这一设计源于对记忆污染机制的深入分析：噪声的危害不在于其存在，而在于其在语义不完整时被固化。这种差异并非技术优劣，而是对“实时性”与“稳定性”权衡的不同取舍，Mem0 适用于高并发客服场景，GAM 更适合长时程叙事一致性要求高的任务。

从方法设计看，GAM 与 MAGMA 在结构化记忆组织上存在范式差异。MAGMA 融合语义、时间、因果及实体四种关系图谱，通过意图感知路由器支持跨视图推理，其复杂度源于对多跳推理与因果分析的精细捕捉需求。GAM 的双层图结构（TAN + EPG）可视为 MAGMA 四图谱的简化版，缺乏独立的因果与实体图谱，但其优势在于通过状态机实现了写入隔离，而 MAGMA 的双流管道主要解决延迟敏感写入与深度推理读取的解耦，未显式处理噪声污染问题。GAM 的简化设计是否足以应对复杂因果推理任务，论文未提供相关实验验证。

## 总结

GAM 旨在解决长时程交互中记忆编码与固化之间的冲突，其切入点在于将生物启发式睡眠依赖记忆固化机制转化为 LLM 智能体的状态机架构，通过语义边界检测实现写隔离，从而在结构上阻断噪声向长期记忆的传播。该框架在 LoCoMo 上以 Qwen 2.5-7B 骨干取得 40.00 的平均 F1，较 Mem0 提升 4.62 个点，并在 LongDialQA 上实现 86% 的相对提升，证明了分层图式记忆在复杂叙事一致性任务上的有效性。然而，GAM 在开放域任务上的性能短板与语义边界检测的 LLM 开销暴露了其边界：当查询缺乏时间或角色约束时，结构化剪枝的收益递减；当交互频率极高时，状态切换的延迟可能抵消写隔离带来的稳定性收益。当骨干模型本身具备强时间推理能力时，GAM 的语义压缩是否反而损失了原始痕迹中的精确时序线索，这一权衡在论文中未得到充分探讨。
