# ACL2026最新论文 ｜SAGE: Sparse Adaptive Guidance for Dependency-Aware Tabular Data Generation ｜稀疏自适应引导的表格数据生成

研究机构：德国慕尼黑工业大学

作者：Shuo Yang、Zheyu Zhang、Bardh Prenkaj 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.24368)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.24368)

> 表格数据生成旨在通过模拟分布实现隐私保护与数据增强，但现有基于大语言模型（LLM）的方法常因全连接注意力引入虚假相关，且假设特征依赖关系静态不变，导致生成记录逻辑不一致。SAGE 针对这一瓶颈，提出通过互信息（MI）构建动态稀疏依赖图，在生成过程中实时筛选上下文或校正 Logit，使模型聚焦于值条件相关的特征子集。该方法在六个数据集上验证了其在下游效用与数据保真度上的优势，尤其在少样本场景下显著优于基线，但其数值回归精度仍略逊于潜空间扩散模型，且未提供形式化隐私保证。

## 研究背景

表格数据中特征间的依赖关系并非恒定，而是随具体取值动态变化。例如，“教育”类贷款通常关联年轻申请人与低收入，而“住房”类贷款则要求稳定就业与高收入阈值。这种值条件动态依赖（Value-Conditioned Dynamic Dependencies）要求生成模型在预测某一特征时，能根据已生成特征的具体取值，动态调整对其他特征的依赖权重。传统统计方法难以捕捉这种非线性、条件化的交互结构，而基于神经网络的生成模型若采用全连接注意力机制，会将所有历史特征视为同等重要，从而引入大量虚假相关（Spurious Correlations），不仅增加计算开销，还导致生成样本出现如“未成年人从事专业职业”等逻辑矛盾。

早期表格生成方法如 CTGAN 和 TVAE 虽解决了混合类型数据的基础建模问题，但受限于 GAN 训练不稳定或 VAE 重构误差，难以保证语义一致性。扩散模型（如 TabDDPM, TabSyn）通过迭代去噪提升了分布保真度，但将数据视为数值矩阵，忽略了特征的语义含义，且采样速度慢。近期，LLM 路线（如 GREAT, GRADE）通过将表格行转化为文本序列，利用预训练知识提升语义合理性，但现有方法仍依赖静态依赖图或全连接注意力，无法适应生成过程中依赖结构的动态演变。SAGE 的切入点在于打破静态依赖假设，通过伪特征离散化与互信息引导，实现生成过程中的自适应稀疏依赖建模。

## 核心方法

### 文本化嵌入与基础生成范式

SAGE 继承 GREAT 的文本化范式，将表格记录 $t_i$ 转化为“特征 is 值”的自然语言序列 $s_i$。训练时，模型最小化目标值 token 的负对数似然，并引入 GRADE 的排列策略随机打乱特征顺序，以消除固定序列位置带来的虚假依赖。生成时，模型随机选取部分真实特征值作为前缀，自回归补全剩余特征。这一参照系确立了 LLM 生成表格数据的基本流程，但其核心缺陷在于注意力机制强制每个 token 关注所有前缀 token，无法区分相关与无关特征。

### 伪特征离散化与互信息依赖矩阵

为捕捉值条件动态依赖，SAGE 首先将原始特征离散化为伪特征（Pseudo-features）。数值特征 $f$ 被划分为 $k$ 个二分箱，其中 $k$ 由 Freedman-Diaconis 规则确定并上限为 16，以控制稀疏性；类别特征则每个取值视为一个二元伪特征。这一设计动机在于，原始数值尺度下的依赖关系是模糊的，而离散化后的二元激活状态能更精确地量化特定值区间间的统计关联。基于伪特征，计算两两之间的互信息（MI）：

$$
MI(f_i^{(a)}, f_j^{(b)}) = \sum_{u \in \{0,1\}} \sum_{v \in \{0,1\}} P_{ij}(u, v) \log \frac{P_{ij}(u, v)}{P_i(u)P_j(v)}
$$

该公式量化了伪特征 $f_i^{(a)}$ 与 $f_j^{(b)}$ 的统计依赖强度，构建出动态依赖矩阵，为后续生成引导提供结构基础。

### 动态稀疏引导机制

SAGE 提出两种互补的引导策略，利用上述 MI 矩阵在生成时动态调整模型行为。第一种是显式特征选择（Feature Selector），通过设定 MI 阈值 $\tau$（默认为训练集 MI 中位数），筛选出与目标特征 $f_{target}$ 相关的伪特征子集 $R(f_{target})$，仅将该子集对应的特征值作为上下文输入 LLM。第二种是隐式 Logit 校正（Logit Correction），计算当前前缀与目标特征的平均 MI $\mu_{sample}$，并与数据集全局平均 MI $\mu_{train}$ 比较，得到差异 $\Delta = \mu_{sample} - \mu_{train}$。校正公式为：

$$
z' = z \cdot (1 + \lambda \cdot \Delta)
$$

其中 $z$ 为未归一化 Logit，$\lambda$ 为缩放超参数。当 $\Delta > 0$ 时，前缀信息高度相关，Logit 被锐化以增强置信度；当 $\Delta < 0$ 时，Logit 被平滑以抑制噪声。这一机制使模型能根据上下文的信息量自适应调整生成置信度，解决了静态图无法适应值条件变化的问题。

## 实验评估

实验在六个数据集上进行，包括 Adult, HELOC, Iris, Diabetes, MIC 和 California Housing，覆盖二分类、多分类及回归任务。基线涵盖 TVAE, CTGAN, TabSyn, GREAT, GRADE 和 SPADA。值得注意的是，实验未包含当前 SOTA 的流匹配模型（如 TabbyFlow）或最新扩散模型（如 TabDiff），这可能限制了与最新非 LLM 路线的直接对比。

| 数据集 | 方法 | ACC/F1 (分类) 或 MAPE (回归) |
| :--- | :--- | :--- |
| Adult | SAGE (w/LC) | 82.58 / 0.72 (DT), 79.86 / 0.76 (RF) |
| Adult | GREAT | 59.85 / 0.60 (DT), 69.42 / 0.69 (RF) |
| Adult | TabSyn | 83.32 / 0.75 (DT), 79.61 / 0.59 (RF) |
| Housing | SAGE (w/FS) | 0.34 (DT), 0.25 (RF) |
| Housing | TabSyn | 0.32 (DT), 0.23 (RF) |
| Iris | SAGE (w/LC) | 96.55 / 0.97 (DT), 100 / 1.00 (RF) |
| Iris | GREAT | 41.38 / 0.36 (DT), 44.83 / 0.35 (RF) |

在 Adult 数据集上，SAGE (w/LC) 的 RF F1 分数为 0.76，略高于 TabSyn 的 0.59，但低于 TabSyn 的 DT F1 0.75 和 GREAT 的 0.69 之外的其他基线？不，GREAT 是 0.69，TabSyn DT 是 0.75，SAGE RF 是 0.76。SAGE 在 Adult 上显著优于 GREAT（F1 提升约 10%），但在 Housing 回归任务上，SAGE 的 MAPE（0.25）高于 TabSyn（0.23），表明 LLM 路线在数值精度上仍略逊于潜空间扩散模型。在少样本的 Iris 数据集上，SAGE 表现优异（ACC 96.55%），而 GREAT 仅 41.38%，验证了稀疏依赖过滤对过拟合的抑制作用。

消融实验显示，Feature Selector (FS) 和 Logit Correction (LC) 均有效，但 LC 在 Adult 和 HELOC 上表现更优，而 FS 在 Housing 上更优。这暗示显式剪枝在数值约束强的任务中更稳定，而隐式校正在高维分类任务中更能保留信息。

评估指标包括下游效用（ACC, F1, MAPE）、数据保真度（违规率）和隐私保护（DCR）。SAGE 在 California Housing 上的违规率降至 1.24%，低于 GREAT 的 15.55% 和 TabSyn 的 10.70%。然而，论文未报告差分隐私（DP）保证下的效用损失，且 DCR 仅作为附录指标，缺乏与 PATE-GAN 等 DP 方法的直接对比。代码已开源，但超参数（如 MI 阈值 $\tau$）的敏感性分析仅在附录中简要提及，未提供大规模网格搜索结果。

## 关联研究分析

从问题动机看，SAGE 与 GRADE 和 SPADA 同属依赖感知生成路线，但关键差异在于依赖结构的动态性。GRADE 和 SPADA 依赖预定义的静态依赖图或统计确定的特征顺序，无法捕捉“教育贷款关联低收入”这类值条件变化。SAGE 通过伪特征离散化与 MI 动态计算，使依赖图随生成过程演变，解决了静态图在值条件场景下的失效。这一改进源于对表格数据稀疏性与动态性的深入理解，而非简单的架构替换。

从方法设计看，SAGE 与 TabSyn 代表了 LLM 与扩散模型两条路线的对比。TabSyn 通过 VAE 将混合类型数据映射到连续潜空间，在数值保真度上具有优势（如 Housing MAPE 0.23 vs SAGE 0.25），但缺乏语义理解能力，易产生逻辑不一致记录。SAGE 利用 LLM 的预训练知识，在语义一致性上表现更好（如 Adult 教育-教育年限违规率 1.32%），但数值精度受限。这种差异源于任务特性：LLM 擅长语义约束，扩散模型擅长数值分布。SAGE 未尝试融合两者，而是专注于 LLM 路线内部的依赖建模优化，这是否限制了其在数值敏感任务上的潜力，论文未给出回答。

## 总结

SAGE 旨在解决 LLM 表格生成中全连接注意力引入虚假相关及静态依赖假设失效的问题。通过伪特征离散化与互信息动态引导，SAGE 实现了值条件稀疏依赖建模，在 Adult 数据集上 F1 分数达 0.76，显著优于 GREAT 的 0.69，并在 Housing 上将违规率降至 1.24%。然而，实验显示 SAGE 在 Housing 回归任务上的 MAPE（0.25）仍高于 TabSyn（0.23），且未提供形式化隐私保证，表明其在数值精度与隐私合规上仍有局限。当特征间依赖关系高度动态且数值精度要求极高时，纯 LLM 路线的稀疏引导机制能否完全替代潜空间扩散模型的数值保真度，论文未给出回答。
