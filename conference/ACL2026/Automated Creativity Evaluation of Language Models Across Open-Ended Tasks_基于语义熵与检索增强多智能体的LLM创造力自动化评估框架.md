> 现有LLM创造力评估框架深度绑定特定任务领域，依赖人工标注或定制评分标准，导致评估过程主观且难以规模化。本文切入点在于解耦评估器与具体创意任务，通过分离发散与收敛思维维度实现域通用测量。方法上，采用语义熵量化发散创造力，并设计检索增强多智能体框架评估收敛创造力。该框架在三个异质领域验证了可行性，但语义熵的计算开销与收敛评估的主观性仍构成应用边界。

## 研究背景

当评估者面对开放式创意任务时，缺乏唯一标准答案使得传统准确率指标失效。此时需引入发散思维（Divergent Thinking）概念，即生成多样、新颖想法的能力，其核心挑战在于如何量化“多样性”而不受表面形式干扰。然而，仅衡量多样性不足以评估创造力，还需考察收敛思维（Convergent Thinking），即整合信息以达成特定目标的能力。传统方法常将两者混同，导致高分模型可能仅输出大量无关内容，而非有效解决方案。

LLM创造力评估领域长期受限于领域特异性与主观性。Torrance Tests of Creative Thinking (TTCT) 等经典人类测试依赖大量人工标注，且其流畅度指标在LLM中可通过采样轻易操纵，信度不足。现有自动化基准如数学推理或代码生成评估，均嵌入强领域假设，无法泛化至开放式任务。主流路线要么依赖人工共识评估（Consensual Assessment Technique, CAT），要么使用特定领域指标，均缺乏跨域通用性。本文旨在构建一个完全自动化、域通用的框架，通过解耦发散与收敛维度，解决现有方法在开放式任务中评估标准缺失与计算成本高昂的双重困境。

## 核心方法

### 方法参照系

本文问题属于开放式生成任务评估，与单答案问答（Single-Answer QA）评估的关键差异在于概率分布的解释。在单答案QA中，概率分散通常指示模型不确定性或幻觉；而在开放式创意任务中，概率分散于不同语义类别恰恰反映了模型的探索广度。因此，需重新定义不确定性指标在创意语境下的语义，将其从“错误概率”转化为“创意多样性”。

### 语义熵量化发散创造力

传统多样性指标如Self-BLEU或Distinct-n基于表面形式匹配，易受同义替换干扰，无法捕捉语义层面的真实差异。本文引入语义熵（Semantic Entropy, SE），将生成步骤按语义等价性聚类，计算类别概率分布的熵值。设查询 $x$ 生成 $n$ 个候选步骤 $s_1, ..., s_n$，通过双向蕴含聚类为语义类别 $C$，类别概率 $P(c|x) = \sum_{s \in c} P(s|x)$，则语义熵定义为：

$$ H_{SE}(x) = -\sum_{c \in C} P(c|x) \log P(c|x) $$

该公式的物理含义是：当模型生成的候选步骤在语义上越分散，熵值越高，表明模型探索了更多不同的解决方向，而非重复表面相似的表述。这一设计解决了传统指标在开放式任务中无法区分“真实创意多样性”与“表面词汇变化”的失效问题。

### 检索增强多智能体评估收敛创造力

现有ChatEval等多智能体框架在每轮讨论中回放完整历史，导致Token成本随轮次线性增长，难以规模化。本文提出检索增强多智能体框架，将中间分析存储为向量数据库中的“片段”（Fragments），每轮仅检索 $k$ 个最相关片段作为上下文。设片段集合 $\mathcal{F} = \{f_1, ..., f_m\}$，当前查询 $q$ 的检索结果为：

$$ \mathcal{R}(q) = \text{TopK}_{f \in \mathcal{F}} \cos(q, f) $$

该机制通过限制上下文窗口，将Token使用量降低63%，同时保持多智能体分工评估的细粒度。设计动机在于解决传统多智能体评估在大规模基准测试中计算成本不可控的问题，使收敛创造力评估具备实际部署可行性。

## 实验评估

实验在MacGyver（物理推理）、HypoGen（科研构思）和BookMIA（创意写作）三个域各300题上进行，对比基线包括One-shot、CoT、ChatEval及Self-BLEU等。基线覆盖单智能体与多智能体路线，但缺乏其他专用创造力基准如LiveIdeaBench的对比。

| 指标 | Cohen’s κ |
| :--- | :--- |
| Semantic Entropy (ours) | 0.56 |
| Cosine similarity | 0.49 |
| Self-BLEU | 0.35 |
| Distinct-1 | 0.37 |
| Distinct-2 | 0.34 |

| 框架 | Accuracy (MacGyver) | Accuracy (BookMIA) |
| :--- | :--- | :--- |
| ChatEval | 76.7% | 73.3% |
| Our framework (GPT-4o-mini) | 84.7% | 83.0% |
| Human Annotator 1 | 82.7% | 81.3% |
| Human Annotator 3 | 84.7% | 80.0% |

语义熵与人类判断的一致性（κ=0.56）显著优于表面形式指标，验证了其捕捉语义多样性的能力。检索增强多智能体框架在MacGyver和BookMIA上的准确率（84.7%、83.0%）达到或超过人类标注者水平，且计算成本降低63%。消融实验显示，SE与收敛指标相关性弱，证实两者可分离；SE随采样温度升高而增加，符合探索行为预期。

评估边界方面，SE计算需每步采样10个候选并聚类，计算开销较大，限制其在超大规模数据集上的应用。收敛评估依赖LLM主观判断，可能低估偏离已知模式的创新方案。代码已开源，使用4块A100 GPU，但缺乏真实世界验证，理论可行但未经验证的方案可能被低估。

## 关联研究分析

从问题动机看，本文与DeCE（Yu et al., 2025）均旨在提升评估细粒度，但DeCE侧重分解标准评分以增强解释性，本文侧重发散/收敛维度分离以解决构念混淆。差异根源在于任务特性：DeCE针对法律QA等高风险领域，需明确评分标准；本文针对开放式创意任务，无标准答案，需区分“多样性”与“有效性”。本文未探索DeCE的分解标准在创意任务中的适用性，可能遗漏了细粒度诊断的潜在价值。

从方法设计看，本文多智能体框架与ChatEval同属LLM-as-a-Judge路线，但ChatEval全量回放历史，本文采用检索片段。这一改进源于计算效率瓶颈，而非评估质量提升。检索机制可能导致关键上下文遗漏，尤其在长链条推理任务中，片段相关性可能不足以覆盖全局逻辑。论文未报告检索失败率或上下文遗漏对评估准确性的影响，查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文核心矛盾在于开放式创意任务评估缺乏域通用自动化标准。切入点在于解耦发散与收敛维度，利用语义熵的分布特性量化多样性，通过检索机制降低多智能体评估成本。方法上，SE公式捕捉语义类别分布熵，检索框架限制上下文窗口。实验证明SE与人类判断一致性κ=0.56，多智能体框架准确率84.7%接近人类水平。边界在于SE计算开销大，收敛评估依赖LLM主观性，可能低估非主流创新。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
