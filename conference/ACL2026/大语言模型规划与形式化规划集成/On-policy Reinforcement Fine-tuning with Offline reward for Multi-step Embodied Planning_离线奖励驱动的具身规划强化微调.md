# ACL2026最新论文 ｜On-policy Reinforcement Fine-tuning with Offline reward for Multi-step Embodied Planning ｜离线奖励驱动的具身规划强化微调

作者：Di Wu、Jiaxin Fan、Chloe Gu 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_0474d7789392)

> 具身任务规划要求智能体在动态环境中基于视觉观察进行多步决策，但在线强化学习（RL）因环境交互成本高且奖励信号稀疏而难以扩展。现有方法要么依赖昂贵的模拟器实时反馈，要么退化为监督微调（SFT）而丧失泛化能力。ORBIT 通过前缀匹配离线专家轨迹计算奖励，结合组相对策略优化（GRPO）实现策略更新，在保持在线 RL 泛化优势的同时将训练时间压缩至约 25%。该方法在 EB-ALFRED 上取得 72.4% 成功率，但其在完全未见环境下的泛化边界及专家轨迹质量敏感性仍需进一步审视。

## 研究背景

具身规划的核心困境在于部分可观测马尔可夫决策过程（POMDP）中的信用分配难题。智能体在每一步仅接收当前视觉观察 $o_t$ 和语言指令 $L$，需生成动作序列 $a_{t+1}$ 以达成目标条件 $C(g)$。由于模拟器通常仅在任务结束时提供二元成功/失败信号，中间步骤缺乏即时反馈，导致长程依赖下的策略优化极不稳定。这种稀疏奖励结构使得传统在线 RL 在具身场景中面临计算开销与优化效率的双重瓶颈。

主流解决方案分为两类：一是直接在线交互获取奖励，如 ERA-7B 和 VAGEN-3B，虽能捕捉环境动力学但训练耗时 36-40 小时且易受分布偏移影响；二是采用 SFT 模仿专家轨迹，虽训练高效但受限于固定数据分布，难以激发推理多样性并易过拟合特定路径。ORBIT 的切入点在于解耦策略优化与环境交互，利用离线专家轨迹构造代理奖励，既规避了模拟器实时调用的成本，又保留了在线 RL 对负样本的利用能力，从而在效率与泛化之间取得平衡。

## 核心方法

### 方法参照系

具身规划的标准 RL 流程要求策略网络 $\pi_\theta$ 与环境紧密耦合，每步动作执行后需等待环境状态转移 $o_{t+1} \sim P(\cdot | o_t, a_{t+1})$ 以获取奖励。本文的关键差异在于将训练过程重构为单步上下文赌博机（contextual bandit），即给定固定历史 $s_n = (g, o_n, a_{0:n-1})$，策略一次性预测剩余动作序列 $\hat{a}_{n:}$，无需调用环境转移函数。

### 离线前缀匹配奖励设计

传统在线 RL 依赖环境返回的标量奖励，而 ORBIT 通过比较策略生成的 rollout 与专家轨迹 $a^*$ 的前缀长度来构造奖励。定义最长正确前缀长度 $n = \max\{i : a_j = a^*_j \forall j \le i\}$，奖励函数采用二次型平滑项：

$$
R_{accuracy} = \frac{n(n+1)}{k(k+1)}
$$

该公式强调连续匹配的长度，相比线性奖励能提供更稳定的梯度信号，避免短前缀匹配带来的噪声。结合格式奖励 $R_{format}$（最大 0.5）与准确率奖励（最大 1.0），最终复合奖励 $R = R_{accuracy} + R_{format}$ 引导策略同时关注动作正确性与输出结构规范性。

### 基于 GRPO 的在线策略优化

在获得离线奖励后，ORBIT 采用 GRPO 进行策略更新。对于每个提示 $x$，模型采样多个候选响应 $y \sim \pi(\cdot|x)$，计算组内相对优势 $A_{off}(x, y; y^E)$，其中 $y^E$ 为专家轨迹。优化目标为：

$$
J_{off}^{RFT}(\pi) = \mathbb{E}_{y \sim \pi(\cdot|x)} \left[ A_{off}(x, y; y^E) \log \pi(y|x) - \beta D_{KL}(\pi \| \pi_{ref}) \right]
$$

此设计保留了在线 RL 的核心特性：基于当前策略采样（on-policy）并利用负优势（$A < 0$）抑制错误路径。与 SFT 的 token 级监督不同，该序列级标量优势仅约束动作 token，间接塑造推理 token，从而保留推理灵活性。此外，引入数据过滤策略，丢弃完美奖励比例低于 0.1 或高于 0.9 的提示组，以稳定梯度并防止学习信号失衡。

## 实验评估

| 方法 | EB-ALFRED (Seen) | EB-Habitat (Unseen) | Avg |
| :--- | :--- | :--- | :--- |
| Claude-3.5-Sonnet | 65.2 | 70.4 | — |
| ERA-7B (Online RL) | 67.2 | — | — |
| ORBIT-7B (SFT) | 57.3 | 62.7 | 13.6 |
| ORBIT-7B (SFT+RFT) | 72.4 | 22.4 | — |

实验在 EmbodiedBench 上进行，基线涵盖闭源 VLM（Claude-3.5-Sonnet、GPT-4o）及在线 RL 方法（ERA-7B、VAGEN-3B）。ORBIT 在 EB-ALFRED 上以 72.4% 的平均成功率超越所有基线，其中比最强闭源模型 Claude-3.5-Sonnet 高 7.2 个百分点，比在线 RL 方法 ERA-7B 高 5.2 个百分点。值得注意的是，尽管 RFT 仅在 Base 子集上进行，模型在 Common Sense、Complex Instruction 等未见子集上仍表现出一致的性能提升，表明策略具备环境内泛化能力。

| 训练策略 | EB-ALFRED | EB-Habitat |
| :--- | :--- | :--- |
| SFT only | 57.3 | 62.7 |
| RFT only | 14.4 | 17.6 |
| SFT → SFT | 66.8 | 11.6 |
| SFT → RFT (Ours) | 72.4 | 22.4 |

消融实验揭示了 RFT 的必要性：单独使用 RFT 性能极差（14.4%），表明缺乏 SFT 提供的结构化先验时，策略难以收敛。SFT→SFT 虽在可见任务上优于 SFT only，但在未见环境 EB-Habitat 上性能骤降至 11.6%，证实了纯监督学习的过拟合倾向。相比之下，SFT→RFT 在两个环境中均取得最佳表现，验证了离线奖励 RFT 在泛化上的独特优势。此外，效率测试显示，ORBIT 的单步更新时间约为 2 分钟，而在线 RL 需 12-15 分钟，总训练时间从 36-40 小时缩短至 8-10 小时，平均评估步数从 13.76 降至 4.17，效率提升显著。

评估协议严格遵循 MDP 设定，但 EB-Habitat 作为完全未见环境，其 22.4% 的成功率远低于 EB-ALFRED 的 72.4%，暴露了跨环境泛化的局限。代码已开源，但论文未报告超参数敏感性分析及不同规模 VLM 的扩展性实验，限制了结论的普适性。

## 关联研究分析

从问题动机看，ORBIT 与 Planner-R1 同属 RL 优化 LLM 规划路线，但 Planner-R1 侧重通过奖励塑造提升小模型在 TravelPlanner 等文本任务中的性能，而 ORBIT 聚焦具身场景下在线交互成本的规避。两者的核心差异在于奖励来源：Planner-R1 依赖任务完成度的稀疏奖励，ORBIT 则利用专家轨迹的前缀匹配构造密集代理奖励。这种差异源于具身环境的物理约束——模拟器交互成本远高于文本生成，使得离线奖励成为必要选择。然而，ORBIT 未探讨专家轨迹多样性对策略泛化的影响，当专家数据覆盖度不足时，前缀匹配奖励是否会导致策略对特定动作模式过拟合，论文未给出回答。

从方法设计看，ORBIT 与 CoPiC 代表具身规划的两种技术路线：CoPiC 采用代码驱动生成，通过执行反馈修正计划，依赖符号验证保证逻辑正确性；ORBIT 则采用 VLM 直接动作生成，通过 RL 优化策略分布，未引入符号验证器。这一差异反映了领域内“神经符号集成”与“端到端策略优化”的分歧。CoPiC 在 ALFWorld 上取得 100% 成功率，但依赖特定子集协议；ORBIT 在 EB-ALFRED 上取得 72.4%，但训练效率更高。两者在评估基准上的重叠度低，难以直接比较绝对性能，但 ORBIT 证明了纯 VLM+RL 在具身任务中可超越部分符号方法，挑战了“必须依赖符号验证器”的领域共识。

## 总结

ORBIT 旨在解决具身规划中在线 RL 的高交互成本与稀疏奖励矛盾，其切入点在于利用离线专家轨迹构造前缀匹配奖励，替代昂贵的环境反馈。通过 GRPO 优化，该方法在 EB-ALFRED 上取得 72.4% 成功率，训练时间仅为在线 RL 的 25%。然而，实验显示其在完全未见环境 EB-Habitat 上成功率仅 22.4%，且对专家轨迹质量敏感（20% 扰动导致性能下降 11.60%），表明策略泛化仍受限于专家数据的分布覆盖。当专家轨迹包含大量非最优解时，前缀匹配奖励是否仍能引导策略收敛至全局最优，论文未提供进一步验证。
