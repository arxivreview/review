# ACL2026最新论文 ｜Edit-Aware Reward Modeling for Chinese Grammatical Error Correction ｜编辑感知奖励模型

研究机构：北京大学

作者：Yilin Li、Xiaojun Wan

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_d9c6539e19a4)

> 中文语法错误纠正（CGEC）面临大语言模型（LLM）生成能力与最小编辑原则的冲突，导致过度纠正。现有基于规则的二元奖励信号无法区分部分纠正与完全重写，致使强化学习策略优化缺乏有效梯度。本文提出编辑感知奖励模型（EARM），通过字符级对齐构建编辑掩码，对编辑边界token赋予更高权重，以双粒度损失训练连续奖励信号。该方法在FCGEC和NaCGEC上刷新了单输出SOTA，但其性能增益中SFT数据规模与RL算法本身的贡献占比尚存疑。

## 研究背景

当LLM被应用于GEC任务时，其强大的生成能力往往导致对正确片段的非必要修改，即过度纠正。这一现象源于生成式模型追求流畅度与GEC任务要求的最小编辑原则之间的根本矛盾。为缓解此冲突，近期研究引入强化学习（RL）进行策略对齐，但主流方法依赖基于精确字符串匹配的二元规则奖励。这种奖励机制存在两个致命缺陷：一是粒度粗糙，无法区分“修复了一个错误”与“完全重写”；二是分数碰撞，将合理的同义替换与错误纠正同等视为零分。

GEC领域的主流范式已从早期的Seq2Edit（如GECToR）和Seq2Seq（如BART）演进至基于LLM的偏好优化。离线方法如DPO及其变体EPO虽简化了训练流程，但受限于分布偏移且缺乏显式奖励模型，难以支持在线动态策略更新。在线方法如GRPO通过组内相对优势估计解决了分布偏移问题，但其效果高度依赖奖励函数的质量。Li et al. (2025) 率先将GRPO应用于GEC，但沿用了粗糙的二元规则奖励，导致策略在部分纠正与过度纠正之间无法获得有效的区分信号。本文的切入点在于，将奖励函数从启发式规则改造为学习式模型，显式建模编辑结构，从而为GRPO提供细粒度的质量区分信号。

## 核心方法

### 方法参照系

本文基于GRPO框架进行策略优化，其标准流程为：SFT预热初始化策略模型，随后在RL阶段采样候选集，计算组内相对优势并更新策略。与通用文本生成RL的关键差异在于，GEC任务要求奖励信号必须反映编辑的最小性与准确性，而非单纯的文本流畅度或语义相似度。

### 编辑掩码构建与加权

在GRPO的奖励计算环节，传统做法直接使用规则匹配结果。本文引入ChERRANT进行源句与候选句的字符级对齐，构建编辑掩码 $M \in \{0, 1, 2\}^{|y|}$，其中 $M_i=1$ 表示枢轴token（编辑边界），$M_i=2$ 表示延续token（编辑跨度内），$M_i=0$ 表示未变token。基于此掩码，本文设计加权公式：

$$ w_i = \begin{cases} \alpha & \text{if } M_i = 1 \\ \gamma & \text{if } M_i = 2 \\ 1 & \text{if } M_i = 0 \end{cases} $$

其中 $\alpha > \gamma > 1$。该设计的动机在于，枢轴token标记了编辑决策发生的位置，携带了关于纠正质量最具判别力的信息，而未变token在损失中占据主导会稀释编辑相关的梯度信号。通过上调编辑token的权重，模型被引导聚焦于编辑相关区域，从而解决二元奖励无法区分部分纠正的失效问题。

### 双粒度训练目标

EARM采用共享骨干网络的双头架构，分别输出句子级奖励 $R_{sent}$ 和token级加权分数 $R_{weighted}$。训练目标结合了三类损失：

$$ \mathcal{L}_{EARM} = \mathcal{L}_{rank} + \lambda \mathcal{L}_{weighted} + \mu \mathcal{L}_{margin} $$

其中 $\mathcal{L}_{rank}$ 为句子级Bradley-Terry排序损失，$\mathcal{L}_{weighted}$ 为基于编辑权重的token级排序损失，$\mathcal{L}_{margin}$ 为显式间隔约束。虽然GRPO训练仅使用 $R_{sent}$，但 $\mathcal{L}_{weighted}$ 在奖励模型训练阶段迫使骨干网络学习编辑感知表示，这些表示间接提升了 $R_{sent}$ 对编辑相关质量差异的捕捉能力。消融实验证实，移除 $\mathcal{L}_{weighted}$ 会导致排序准确率下降，验证了token级监督对句子级奖励的增益作用。

## 实验评估

实验在FCGEC和NaCGEC两个中文CGEC基准上进行，基线覆盖Seq2Edit（GECToR）、Seq2Seq（BART, SynGEC）、LLM直接提示（DeepSeek-R1）及RL方法（EPO, Rule-based RL）。

| 方法 | FCGEC F0.5 | NaCGEC F0.5 |
| :--- | :--- | :--- |
| Rule-based RL (single) | 57.33 | 58.52 |
| EPO | 59.63 | 62.79 |
| EARM + GRPO (single) | 61.29 | 63.08 |
| EARM + GRPO (best-of-16) | 65.04 | 64.59 |

EARM + GRPO在单输出设置下超越Rule-based RL 3.96和4.56点，超越EPO 1.66和0.29点。精度（Precision）的提升尤为显著（FCGEC 68.98 vs 60.68），表明EARM能有效区分高质量纠正与看似合理但错误的替代方案。

| 配置 | F0.5 |
| :--- | :--- |
| Lrank only | 57.32 |
| + Lmargin | 57.67 |
| + Lweighted | 58.15 |
| + sftbase (full EARM) | 58.61 |

消融实验显示，均匀加权（$\alpha=\gamma=1$）仅得56.89，低于句子级基线，证实未加权token级监督引入噪声。引入编辑权重后性能显著提升，其中枢轴权重 $\alpha$ 大于延续权重 $\gamma$ 的配置（如6,3）优于等权配置（3,3），验证了编辑边界信息的重要性。

评估指标主要依赖ChERRANT计算的F0.5，未采用Closest Golds等动态参考指标，可能低估LLM生成的合理多样性。代码已开源，但论文未报告置信区间，且SFT阶段使用了1.57M对数据，RL算法本身的独立贡献难以完全剥离。

## 关联研究分析

从问题动机看，EARM与CSRP同属RL对齐路线，但CSRP侧重通过思维链推理显式优化编辑效率，而EARM侧重通过奖励模型隐式捕捉编辑结构。CSRP在NaCGEC上取得59.61 F0.5，低于EARM的63.08，这可能源于EARM的连续奖励信号比离散推理步骤更能提供细粒度的梯度信息。然而，CSRP的推理过程具有可解释性，而EARM的黑盒奖励模型在错误归因上存在盲区。

从方法设计看，EARM与EPO形成在线与离线方法的对比。EPO作为DPO变体，直接优化偏好对，避免了显式奖励模型的计算开销，但受限于离线数据的分布覆盖。EARM通过GRPO实现在线探索，能够动态适应策略变化，但引入了奖励模型训练与推理的额外计算成本。EARM在FCGEC上比EPO高1.66点，这一差距是否足以抵消其计算开销，论文未提供效率对比数据。此外，EARM依赖ChERRANT对齐构建编辑掩码，若对齐错误，奖励信号将被污染，这一鲁棒性风险在低资源或噪声数据场景中可能加剧。

## 总结

本文旨在解决LLM在GEC任务中因二元规则奖励导致的过度纠正与部分纠正混淆问题。通过引入基于ChERRANT对齐的编辑掩码与双粒度加权损失，EARM为GRPO提供了细粒度的连续奖励信号，在FCGEC和NaCGEC上分别取得61.29和63.08的F0.5分数，超越了基于规则的RL基线。然而，实验设计中SFT阶段使用了大规模数据（1.57M对），且未报告置信区间，使得RL算法本身的独立贡献难以精确量化。当SFT数据规模缩减至与基线相当时，EARM相对于Rule-based RL的性能优势是否依然显著，论文未给出回答。
