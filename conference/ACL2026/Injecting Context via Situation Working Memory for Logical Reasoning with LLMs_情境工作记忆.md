# ACL2026最新论文 ｜Injecting Context via Situation Working Memory for Logical Reasoning with LLMs ｜情境工作记忆

作者：Jieun Kim、Seoha Lim、YoungHae Choi 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_e28a851ecf4c)

> 多步逻辑推理中，模型常因丢失全局状态一致性而陷入错误累积，现有神经符号方法依赖静态逻辑形式，难以捕捉动态演变的上下文依赖。本文切入点在于引入认知心理学的情境模型理论，将自然语言分解为时间、空间、因果等五维结构化记忆，并动态更新以引导推理。SituW通过构建显式的情境工作记忆，在FOLIO等基准上显著提升了准确率并减少了“不确定”预测。该方法在提升推理连贯性方面表现突出，但其依赖LLM生成中间表征，存在错误传播风险，且计算开销较大。

## 研究背景

当LLM处理长文本逻辑推理时，往往无法维持对当前情境的全局把握。例如，在“彼得乘电梯到五楼”后接“他去见教授”，模型需推断教授办公室在五楼，这要求模型在理解单句的同时构建并更新对事件的整体心理表征。这种动态构建过程在认知心理学中被称为情境模型（Situation Model），它沿时间、空间、因果、意图和主角等维度组织信息。然而，当前LLM主要依赖表面文本或静态逻辑形式，缺乏这种动态、结构化的情境表征机制，导致在多步推理中频繁出现状态不一致和逻辑断裂。

逻辑推理领域长期存在“符号vs统计”的本体论分歧，主流神经符号方法试图通过将自然语言转化为形式逻辑（如SMT、FOL）来保证严谨性。然而，这一路线面临两大瓶颈：一是自动形式化（Autoformalization）的歧义瓶颈，即自然语言到逻辑公式的转换常丢失语境细微差别；二是外部符号求解器的刚性依赖，一旦形式化出错，后续推理将基于错误前提。此外，Chain-of-Thought（CoT）虽提升了性能，但其生成的推理链往往是对答案的事后合理化，而非真实计算过程，缺乏忠实性。本文针对这一空白，提出SituW，通过动态构建和更新情境工作记忆，弥补静态逻辑形式在上下文连贯性上的不足。

## 核心方法

### 方法参照系

本文问题属于神经符号融合范畴，但区别于传统使用外部求解器的方法。标准流程是将自然语言解析为逻辑表达式，再由求解器推导。本文的关键差异在于不使用外部求解器，而是由LLM生成结构化的情境记忆（SituW），并将其转回自然语言增强上下文，由LLM直接推理，旨在解决自动形式化的歧义与刚性问题。

### 情境记忆构建

SituW的核心创新在于将输入句子分解为客观索引（Objective Indexing）和主观索引（Subjective Indexing）。客观索引提取时间$t$、空间$s$和主角$p$，定义为$O = LLM_{obj}(S) = \{t, s, p\}$。主观索引则基于客观结构推断因果$c$和意图$i$，定义为$U = LLM_{subj}(S, O) = \{c, i\}$。最终情境记忆$M = O \cup U = \{t, s, p, c, i\}$。这一设计解决了静态逻辑形式无法捕捉隐含因果和意图的问题，使模型能基于结构化状态而非表面文本进行推理。

### 动态更新与推理

在推理阶段，SituW通过迭代更新机制维持情境一致性。对于句子序列$S_1, \dots, S_n$，每步提取情境片段$m_n$，并基于前序记忆$M_{n-1}$和携带变量$\pi_{n-1}, \rho_{n-1}$生成$m_n = f_{teacher}(S_k | S_{<n}, M_{n-1}, \pi_{n-1}, \rho_{n-1})$。记忆状态通过$M_n = Update(M_{n-1}, m_n)$更新。最终，记忆组件被语言化并附加到原始上下文，形成增强上下文$C_5$，引导LLM进行Plan-Action-Update-Process推理。这一动态更新机制解决了长链推理中状态丢失的问题，使模型能聚焦于相关变量及其因果-目标结构。

## 实验评估

实验在PrOntoQA、ProofWriter、FOLIO和LogiQA 2.0上进行，基线包括Standard、CoT、SymbCoT和Logic-LM。SituW在Prompt-based设置下，GPT-4o-mini在FOLIO上达到71.79%，显著优于CoT（61.46%）和Logic-LM（58.99%）。在Supervised设置下，SituW在FOLIO上对Llama-3.1 70B的提升达+37.93%p，远超Vanilla FT。

| Method | PrOntoQA | ProofWriter | FOLIO | AVG |
| :--- | :--- | :--- | :--- | :--- |
| CoT (GPT-4o-mini) | 72.60 | 44.16 | 64.22 | 61.46 |
| Logic-LM (GPT-4o-mini) | 77.40 | 37.33 | 62.25 | 58.99 |
| SituW (GPT-4o-mini) | 79.00 | 64.33 | 72.06 | 71.79 |

消融实验显示，仅客观索引准确率为54.38%，加入因果和意图后跃升至64.81%（+10.43%p），表明因果与意图的互补性是关键。SituW还减少了“不确定”预测，在LogiQA上，SituW的True/False决策比例更高，准确率更优。

评估边界方面，SituW的Token消耗（4790输入）远高于Direct（132）和CoT（318），运行时0.57秒，高于CoT的0.482秒。代码已开源，但论文未报告置信区间，且未与最新RL-based方法（如LogicReward）对比，限制了其在计算效率维度的全面评估。

## 关联研究分析

从问题动机看，SituW与Logic-LM（Pan et al., 2023）均旨在解决自然语言到逻辑推理的转换问题，但Logic-LM依赖外部求解器，受限于自动形式化的歧义。SituW通过动态情境记忆避免了刚性形式化，但牺牲了外部求解器的逻辑严谨性，其有效性依赖于LLM生成情境记忆的准确性。SymbCoT（Xu et al., 2024）同样使用符号表示，但SituW在FOLIO上优于SymbCoT，表明结构化情境比纯符号转换更能捕捉上下文依赖。

从方法设计看，SituW与CoT（Wei et al., 2022）共享中间步骤思想，但CoT的推理链缺乏忠实性，SituW通过显式维度提取增强了过程的可解释性。然而，SituW生成的情境记忆是否真实反映模型内部状态，还是另一种形式的事后合理化，论文未提供因果中介分析证据。与机制可解释性路线（如Induction Heads Analysis）相比，SituW提供了比黑箱CoT更具解释性的中间状态，但未深入Transformer内部电路，其解释力局限于任务特异性。

## 总结

本文核心矛盾在于静态逻辑形式无法维持多步推理中的全局状态一致性。SituW通过引入认知心理学的情境模型，动态构建和更新五维结构化记忆，解决了自动形式化的歧义与刚性问题。实验证明，SituW在FOLIO上GPT-4o-mini达到71.79%，Llama-3.1 70B提升+37.93%p，显著优于CoT和Logic-LM。其边界在于依赖LLM生成中间表征，存在错误传播风险，且计算开销较大。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
