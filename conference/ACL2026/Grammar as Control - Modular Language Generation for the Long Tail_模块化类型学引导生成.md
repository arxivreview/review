# ACL2026最新论文 ｜Grammar as Control: Modular Language Generation for the Long Tail ｜模块化类型学引导生成

研究机构：美国加州大学圣迭戈分校

作者：Ndapa Nakashole

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f01085dfa3c6)

> 低资源语言合成数据生成面临的核心困境是，大语言模型在无引导提示下产生的语料存在严重的形态句法模式崩溃，无法覆盖类型学上欠代表的语言结构空间。现有方案要么依赖随机采样导致分布偏斜，要么将完整语法注入提示引发长指令退化，均无法实现语料级的类型学平衡。本文切入点是将描述性语法分解为可执行的模块化“语法切片”，作为显式控制单元引导生成分布。mTIG 通过切片分解与词汇一致性算子，在零训练成本下实现了类型学熵提升与下游翻译性能超越教师模型的效果，但其对孤立语言及长句生成的适用性仍存疑。

## 研究背景

低资源语言机器翻译（MT）的瓶颈在于平行语料稀缺，而大语言模型（LLM）虽具备模式识别能力，但在无结构化引导时，其生成行为受频率偏差主导，倾向于重复高频句法结构（如主谓宾），导致合成语料在形态句法维度上缺乏代表性。这种“模式崩溃”使得下游模型无法泛化至未见的形态句法模式，而直接注入完整描述性语法（Grammar Dump）又因 Transformer 的长指令退化特性而失效，无法有效约束生成分布。

该领域的主流路线分为两类：一是基于形式文法的约束解码，如 Grammar-Constrained Decoding，其在 Token 级施加硬性语法约束，适用于结构化输出但难以处理描述性语法的分布控制；二是基于提示工程的语法辅助生成，如 Tanzer et al. (2024) 将语法作为背景知识提升单句质量，但未解决语料级覆盖问题。mTIG 的切入点在于将描述性语法从“背景知识”转化为“控制机制”，通过模块化分解规避长指令退化，实现语料分布的显式调控，从而在数据稀缺场景下构建具有类型学平衡性的训练集。

## 核心方法

### 方法参照系

本文问题属于推理时干预范畴，但干预对象从单句属性合规转向语料库级统计特性。与 Grammar-Constrained Decoding 在解码路径施加 Token 级约束不同，mTIG 在提示阶段引入外部语法结构，控制生成数据的类型学分布，而非约束单个 Token 的合法性。

### 语法切片分解机制

传统方法将完整语法作为单一提示输入，导致 LLM 在处理长上下文时出现指令遵循度下降。mTIG 将描述性语法 $G$ 分解为 $J$ 个独立的语法切片 $\mathcal{S} = \{mTIG_j\}_{j=1}^J$，每个切片 $mTIG_j$ 定义为四元组：

$$
mTIG_j = (G_j^f, G_j^i, T_j, E_j)
$$

其中 $G_j^f$ 为语系级语法信息，$G_j^i$ 为语言特定细节，$T_j$ 为生成指令，$E_j$ 为少样本示例。该设计将复杂的形态句法现象（如被动、使役）解耦为独立控制单元，使 LLM 能聚焦于单一语法现象的实现，避免了长指令中的注意力分散，从而在固定生成预算下提升了类型学覆盖的均匀性。

### 词汇一致性与覆盖增强

语法切片仅控制结构，无法保证词汇正确性，LLM 在低资源语言中常产生幻觉词形。mTIG 引入词汇一致性算子 $\Phi_{lex}$，当双语词典 $L$ 可用时，对原始生成 $Z_{raw}$ 进行后处理：

$$
Z_{final} = \Phi_{lex}(Z_{raw}) = LLM\text{-}Edit(Z_{raw}, T_{edit}, L_i)
$$

该算子替换词典外或幻觉词形，同时保留切片建立的语法配置。此外，针对 1.3B 参数学生模型无法翻译未见词的问题，mTIG 实施定向采样策略：对核心语料中缺失的词汇 $w$，均匀采样一个切片 $mTIG_k$ 并生成 $k=5$ 句包含 $w$ 的句子。这一机制在避免切片-词汇全组合爆炸的同时，确保了学生模型暴露于完整目标词汇表，解决了语法控制与词汇覆盖之间的权衡。

## 实验评估

实验在 Bantu 语系的 Kwanyama、Ndonga 和 Rukwangali 三种语言上进行，生成预算固定为 321,300 句，对比基线包括无引导提示（Baseline Prompt）、语法倾倒（Grammar Dump）及 NLLB-200。基线覆盖审计显示，本文未对比表示工程或强化学习微调方法，因任务性质为数据生成而非模型对齐，但缺失与最新低资源 LLM 蒸馏方法的直接对比。

| 方法 | 总生成数 | 唯一英文句数 | 唯一率 (%) | 归一化熵 ($H_{norm}$) | 熵增益 (%) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Baseline Prompt | 321,300 | 147,522 | 45.9 | 0.739 | +18.5% |
| Grammar Dump | 321,300 | 90,018 | 28.0 | 0.766 | +14.2% |
| mTIG (ours) | 321,300 | 219,777 | 68.4 | 0.875 | — |

在 Gemini 生成器上，mTIG 的唯一率（68.4%）是 Grammar Dump（28.0%）的 2.4 倍，归一化熵（0.875）显著高于基线，表明切片分解有效缓解了模式崩溃。Grammar Dump 虽熵值略高于无引导提示，但唯一率大幅下降，证实长上下文导致生成多样性受损。下游 MT 评估中，mTIG 数据训练的学生模型在 chrF 上超越源 LLM 达 +20，验证了“学生超越教师”效应，即结构化合成数据比 LLM 直接翻译提供更高质量的监督信号。

消融实验显示，词汇一致性算子对低资源语言至关重要，因 LLM 在 107 种语言上的零样本词汇翻译准确率多数低于 60 chrF 阈值。定向采样策略避免了全组合爆炸，但论文未报告该策略对生成效率的具体影响。评估边界方面，本文仅评估了 Bantu 语系，未验证 mTIG 在孤立语言（如澳洲原住民语言）或形态不丰富语言（如汉语）上的有效性；代码已开源，但超参数（如温度 0.7）仅针对 Claude 优化，其他模型使用默认参数，限制了跨生成器的可复现性。

## 关联研究分析

从问题动机看，mTIG 与 Grammar-Constrained Decoding 均旨在控制生成分布，但前者针对语料级类型学平衡，后者针对单句结构合规。Grammar-Constrained Decoding 依赖形式文法（CFG）在解码时施加硬约束，适用于 JSON 或代码生成，但无法处理描述性语法中隐含的分布偏好；mTIG 则通过提示工程软性引导，牺牲了单句的严格语法正确性，换取了语料库的形态句法多样性。这一差异源于任务特性：低资源 MT 需要覆盖广泛的形态句法模式以泛化，而非生成单一结构的精确实例。

从方法设计看，mTIG 与 Representation Engineering 均属于推理时干预，但干预层级不同。RE 通过操纵激活空间中的线性方向实现属性控制，依赖属性在内部表示中的线性可分性；mTIG 则通过外部文本提示控制生成，不依赖内部表示结构。mTIG 的切片分解机制类似 Plan-and-Write 的规划阶段，将复杂生成任务分解为可控子任务，但 Plan-and-Write 针对长度控制，mTIG 针对类型学覆盖。mTIG 未探索切片的可组合性，即多个切片联合约束时的交互效应，这可能是其在多属性冲突场景下的潜在局限。

## 总结

mTIG 解决了低资源语言合成数据生成中形态句法覆盖不足的核心矛盾，通过语法切片分解将描述性语法转化为显式控制单元，规避了长指令退化与随机采样的分布偏斜。该方法在 Bantu 语系上实现了归一化熵 0.875 与唯一率 68.4% 的提升，并验证了学生模型超越教师 LLM 的 +20 chrF 效应。其边界在于仅验证了形态丰富的 Bantu 语言，且切片作为独立控制单元，未探索多切片组合时的交互效应。当语法切片数量增加至覆盖更复杂的从句结构时，类型学熵的提升是否仍呈线性增长，论文未给出回答。
