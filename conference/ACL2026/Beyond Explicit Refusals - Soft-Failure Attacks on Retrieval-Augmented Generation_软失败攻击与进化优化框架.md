# ACL2026最新论文 ｜Beyond Explicit Refusals: Soft-Failure Attacks on Retrieval-Augmented Generation ｜软失败攻击与进化优化框架

研究机构：电子科技大学、美国普林斯顿高等研究院

作者：Wentao Zhang、Yan Zhuang、ZhuHang Zheng 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.18663)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.18663)

> 检索增强生成（Retrieval-Augmented Generation, RAG）系统在应对恶意文档注入时，传统攻击多导致显式拒绝或服务中断，这类“硬失败”因伴随高困惑度或拒绝关键词而易于被异常检测机制捕获。现有防御机制难以识别那些表面流畅、语义连贯但实质空洞的响应，导致系统在遭受隐蔽攻击时持续输出低效用内容而未被察觉。本文提出“软失败”概念，并设计 Deceptive Evolutionary Jamming Attack (DEJA) 框架，通过进化算法优化对抗文档，在保持高检索排名的同时诱导模型生成非信息性响应。该工作揭示了 RAG 系统在安全对齐机制下的隐蔽脆弱性，但其评估局限于文本问答任务，且未验证在复杂多跳推理或动态知识库更新场景下的长期稳定性。

## 研究背景

RAG 系统依赖外部知识库提升事实准确性，但开放的数据接口使其成为攻击面。当攻击者向知识库注入恶意文档时，检索器可能将其优先返回给生成器。传统投毒攻击旨在诱导模型输出错误答案，而可用性攻击则试图使系统拒绝服务。Shafran et al. (2025) 提出的 Jamming 攻击通过注入特定文档触发模型的显式拒绝行为，这种“硬失败”虽然有效，但其产生的文本统计异常（如高困惑度）使其容易被基于统计特征的防御机制检测。

领域共识认为，外部知识库是 RAG 系统最脆弱的环节，黑盒攻击因无需访问内部参数而更具现实威胁。然而，现有研究多聚焦于准确性破坏或隐私泄露，对“可用性”维度的隐蔽攻击关注不足。硬失败攻击虽然能中断服务，但其显式特征限制了攻击的隐蔽性，攻击者难以在大规模部署中持续存在而不被发现。本文切入点在于利用大语言模型（LLM）的安全对齐机制——即模型在面对不确定性时倾向于产生模糊、回避性的回答——构造一种不触发显式拒绝、但实质降低回答效用的“软失败”模式。这种攻击模式在语言流畅性和语义连贯性上与正常响应无异，从而规避了基于困惑度或关键词的常规检测。

## 核心方法

### 方法参照系

本文问题属于黑盒知识库投毒攻击范畴，但目标从传统的“错误答案生成”转向“效用降级”。标准投毒流程通常优化文档以最大化检索排名并诱导特定错误输出，而本文需同时满足两个冲突目标：文档必须具有高检索相关性以确保进入上下文窗口，同时其内容必须诱导生成器产生流畅但无实质信息的响应。

### 对抗文档解耦架构

设计动机在于解决单一文档难以同时满足检索高排名与生成低效用这两个相互制约的目标。DEJA 将对抗文档 $d_{adv}$ 解耦为三个语义耦合组件：查询锚点 $q$、检索钩子 $h_{hook}$ 和载荷 $p_{payload}$。

$$ d_{adv} = q \oplus h_{hook} \oplus p_{payload} $$

其中 $\oplus$ 表示文本拼接。$q$ 确保文档与目标查询在语义空间中的接近性；$h_{hook}$ 通过密集使用查询相关词汇确保检索排名，并作为语义桥梁引导模型进入特定的对抗策略语境；$p_{payload}$ 则包含精心构造的模糊信息或虚构冲突，旨在触发模型的回避行为。这种解耦设计使得检索优化与效用降级可以独立进行，避免了传统方法中因强行嵌入恶意指令而导致的文本不自然或检索排名下降。

### 基于答案效用分数的进化优化

设计动机在于克服传统二元成功标准（如关键词匹配）无法捕捉“软失败”语义细微差别的问题。DEJA 引入基于 LLM 的答案效用分数（Answer Utility Score, AUS）作为连续优化目标，并通过进化算法迭代优化载荷。

$$ F(p; q, h_{hook}) = \frac{1}{|S_{AUS}(G(q \oplus h_{hook} \oplus p)) - \tau_{soft}| + \epsilon} $$

其中 $S_{AUS}$ 是 LLM 评估器对生成响应 $G(\cdot)$ 的效用评分，$\tau_{soft}$ 是目标软失败效用阈值，$\epsilon$ 为稳定性常数。该公式通过最小化实际效用与目标效用的距离来最大化适应度。进化过程包括微变异、语义交叉、创新变异和基于反馈的修正四个算子，在自然语言空间中进行操作，避免了 token 级扰动产生的脆弱性。这一机制使得攻击者能够自动化地生成既符合检索要求又能精确控制响应效用水平的对抗文档，实现了从“盲目注入”到“精准操纵”的转变。

## 实验评估

实验在 Natural Questions (NQ)、HotpotQA 和 FiQA 三个基准上进行，对比基线包括 Prompt Injection、Jamming 和 PoisonedRAG。DEJA 在所有数据集上均实现了显著高于基线的软失败攻击成功率（SASR），同时保持了较低的硬失败率（HASR）。

| 配置 | SASR (%) | HASR (%) | MAD$_\tau$ |
| :--- | :--- | :--- | :--- |
| w/o AS (Adaptive Strategy) | 67.95 | 7.69 | 0.65 |
| w/o Hook ($h_{hook}$) | 70.51 | 24.36 | 0.69 |
| w/o $O_{feedback}$ | 79.49 | 10.26 | 0.51 |
| w/o EPO | 73.08 | 11.54 | 0.76 |
| **DEJA (Full)** | **80.77** | 12.82 | **0.50** |

消融实验显示，移除检索钩子导致 HASR 从 12.82% 激增至 24.36%，证实了钩子在避免显式拒绝中的关键作用；移除进化载荷优化（EPO）则使 SASR 下降至 73.08%，表明单次启发式生成无法精确控制效用水平。DEJA 在 NQ 上对 Llama-2-7B 的 SASR 达到 92.27%，在 FiQA 上超过 97%，且对查询改写和增加上下文窗口大小具有鲁棒性，SASR 保持在 83% 以上。

评估边界方面，论文未报告计算效率指标，且 AUS 评估器本身可能引入偏差。实验仅覆盖文本问答任务，未验证在多模态或动态更新知识库中的表现。代码未公开，超参数固定，限制了可复现性。

## 关联研究分析

从问题动机看，DEJA 与 PoisonedRAG 同属黑盒投毒攻击，但目标维度不同。PoisonedRAG 旨在诱导错误事实，其成功标准是输出与真实答案的偏差；而 DEJA 旨在诱导效用降级，其成功标准是输出流畅但无信息量。这一差异源于对 RAG 系统不同价值维度的攻击：前者破坏准确性，后者破坏可用性。DEJA 利用模型的安全对齐机制（回避不确定性），而 PoisonedRAG 利用模型的幻觉倾向。这种机制差异使得 DEJA 更难被基于事实核查的防御检测，因为软失败响应在表面上并不包含明显的事实错误，而是包含模糊的冲突信息。

从方法设计看，DEJA 与 RIPRAG 同采用黑盒优化策略，但优化目标函数不同。RIPRAG 使用强化学习优化检索排名，目标是最大化错误答案的检索概率；DEJA 使用进化算法优化效用分数，目标是最大化软失败响应的概率。DEJA 引入 AUS 作为连续反馈信号，而 RIPRAG 依赖离散的成功/失败信号。这一设计使得 DEJA 能够更精细地控制响应的效用水平，避免触发硬失败。然而，DEJA 依赖 LLM 评估器计算 AUS，这引入了额外的计算开销和潜在的评估偏差，而 RIPRAG 的强化学习框架可能更易于扩展到其他优化目标。

## 总结

本文核心矛盾在于如何在保持高检索排名的同时诱导模型产生低效用响应，现有硬失败攻击因显式特征易被检测，而传统投毒攻击无法精确控制效用水平。DEJA 通过解耦文档组件和引入基于 AUS 的进化优化，实现了这一目标。实验证明 DEJA 在多个基准上 SASR 超过 79%，且对常见防御具有鲁棒性。其边界在于 AUS 评估器的潜在偏差和仅限文本任务的评估。当知识库动态更新或包含多模态数据时，基于静态语义匹配的软失败攻击是否仍能保持高成功率，论文未给出回答。
