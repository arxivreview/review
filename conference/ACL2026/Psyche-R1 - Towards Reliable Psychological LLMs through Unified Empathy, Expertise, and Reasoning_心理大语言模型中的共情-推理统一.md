# ACL2026最新论文 ｜Psyche-R1: Towards Reliable Psychological LLMs through Unified Empathy, Expertise, and Reasoning ｜心理大语言模型中的共情-推理统一

研究机构：合肥工业大学、香港中文大学

作者：Chongyuan Dai、Jinpeng Hu、Hongchang Shi 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f36979ce0d62)

> 心理大语言模型（Psychological LLMs）面临的核心困境是通用推理模型缺乏领域共情，而专用心理模型又缺失复杂逻辑推导能力。现有方案要么依赖静态微调导致长程对话情感漂移，要么采用通用强化学习（RL）导致开放式心理评估中答案模式僵化。Psyche-R1 通过迭代优化推理链与多模型交叉筛选高难度样本，在单轮静态问答中实现了共情表达与专业推理的联合优化。该工作验证了小模型在特定心理推理任务上逼近超大通用模型的可行性，但其单轮评估协议未能覆盖多轮交互中的安全漂移风险，临床落地价值存疑。

## 研究背景

心理咨询场景要求模型同时具备情感共鸣与专业诊断能力，这构成了两个相互制约的技术维度。共情能力（Empathy）决定了用户信任度，但单纯的情感匹配往往缺乏临床依据；专业推理（Reasoning）确保了回答的准确性，但通用逻辑推理模型（如 DeepSeek-R1）在处理开放式心理案例时，倾向于输出单一确定答案，无法生成符合心理咨询伦理的多元化、细腻化回应。这种“共情-推理”割裂现象源于预训练数据中临床知识稀疏，且通用 RL 训练主要聚焦于数学与代码等具有确定性解的任务，导致模型在心理领域出现逻辑与情感的双重失效。

当前心理 LLM 研究呈现两极分化：一类如 PsycoLLM 和 CPsyCounX 专注于知识问答或对话微调，虽提升了领域知识但推理能力薄弱；另一类如 DeepSeek-R1 具备强大推理能力，但在心理基准测试中表现平平，因其训练数据缺乏心理共情要素。Psyche-R1 的切入点在于打破这种二元对立，主张在心理领域，推理不仅是获取正确答案的手段，更是支撑深层共情与知识整合的基础。该工作试图通过统一的数据合成与混合训练策略，解决单轮静态问答中共情表达与专业推理逻辑相互干扰的问题，填补了现有心理模型在复杂推理能力上的空白。

## 核心方法

### 方法参照系

本文问题属于“领域特定推理增强”范畴，参照系为基于 GRPO 的通用推理模型训练流程。关键差异在于：通用流程依赖确定性奖励函数，而心理任务需要同时优化格式合规性、答案准确性及隐含的共情质量，且训练数据需从静态 QA 对升级为包含详细推理链（Rationale）的动态样本。

### 迭代式推理链优化

传统 CoT 生成往往产生逻辑断裂或幻觉，Psyche-R1 引入迭代提示-推理优化机制。对于每个 QA 对 $(q_i, a_i)$，模型生成初始推理链 $r_i$ 与预测答案 $\hat{a}_i$。若 $\hat{a}_i \neq a_i$，则触发重生成；若正确，则进入迭代优化阶段。在第 $t$ 轮中，模型基于当前提示 $P_i$ 生成改进提示 $P_i^*$，并基于 $P_i^*$ 生成新推理链 $r_i^*$ 与答案 $\hat{a}_i^*$。若 $\hat{a}_i^* = a_i$，则保留 $P_i^*$ 继续迭代；否则回退至上一轮状态。该过程重复 $R=3$ 轮，最终保留质量最高的推理链。这一设计解决了静态 CoT 中推理路径与最终答案不对齐的问题，通过自监督迭代确保推理链的逻辑连贯性与事实准确性。

### 多模型交叉筛选与混合训练

为提升 RL 阶段的样本难度，Psyche-R1 采用多 LLM 交叉筛选策略。使用 Qwen、Llama 和 Phi 三个独立模型对每个问题进行作答，仅当三者均回答错误时，该问题被归入“高难度子集” $D_{pc}$（共 19k 样本）。非高难度样本 $D_{pr}$ 与共情对话数据 $D_{em}$ 合并用于 SFT 阶段。GRPO 阶段使用复合奖励函数：

$$
R(y, y^*) = R_{fmt} + R_{acc}
$$

其中 $R_{fmt}$ 为格式奖励，若输出包含 `<think>` 标签且结构可解析，赋值为 +1.25，否则为 -1；$R_{acc}$ 为准确性奖励，采用部分信用机制：若预测答案集合 $\hat{a}$ 与真实答案集合 $a$ 完全相等，赋值为 +1；若 $\hat{a} \subset a$ 且 $a \neq \emptyset$，赋值为 $|\hat{a} \cap a| / |a|$；否则为 -1。该设计通过严格筛选高难度样本，迫使模型在 RL 阶段聚焦于复杂心理情境的深层推理，而非简单模式匹配。

## 实验评估

实验在 PCEB（3,863 道选择题 + 100 道案例分析）和 CPsyExam（4,102 道题）上进行，基线涵盖通用 LLM（Qwen2.5 系列）、推理增强 LLM（DeepSeek-R1 系列）、闭源模型（GPT-4o, Claude3.7）及心理专用模型（PsycoLLM, PsyDT）。

| 模型 | 参数量 | PCEB Avg (%) | CPsyExam Zero-shot Avg (%) |
| :--- | :--- | :--- | :--- |
| Qwen2.5-7B | 7B | 57.91 | 67.37 |
| DeepSeek-R1-70B | 70B | 53.56 | 60.57 |
| PsycoLLM | 14B | 61.72 | 69.20 |
| Psyche-R1 | 7B | 74.37 | 74.90 |
| DeepSeek-R1 | 671B | 72.95 | 78.28 |

Psyche-R1 (7B) 在 PCEB 上达到 74.37%，超越同规模模型及 70B 的 DeepSeek-R1，接近 671B 的 DeepSeek-R1 (72.95%)。在 CPsyExam 上，其零样本平均准确率 74.90% 显著优于所有心理专用模型，但略低于 DeepSeek-R1 (78.28%)。

| 消融设置 | Case SMCQ | Moral SMCQ | Theory SMCQ |
| :--- | :--- | :--- | :--- |
| Base | 47.57 | 87.83 | 78.46 |
| +SFT | 48.51 | 83.82 | 73.44 |
| +SFT+GRPO | 67.07 | 86.06 | 79.10 |
| +Rat.+Iter. | 67.07 | 86.06 | 79.10 |

消融实验显示，单独 SFT 对 Case 任务提升有限（47.57% → 48.51%），但 SFT+GRPO 组合带来显著增益（67.07%），表明高难度样本筛选对推理能力至关重要。迭代推理链优化（+Rat.+Iter.）与 SFT+GRPO 效果一致，证实了推理链质量对最终性能的贡献。值得注意的是，GRPO 单独使用（无 SFT）导致 Case 任务性能下降（36.69%），说明基础领域知识是复杂推理的前提。

评估边界方面，PCEB 与 CPsyExam 均为单轮静态基准，无法评估多轮对话中的情感一致性与安全漂移。指标主要依赖准确率，缺乏对共情质量的细粒度量化（如 PsyDT 测试集仅作为辅助参考）。代码已开源，但训练数据合成依赖多个 LLM 的 API 调用，复现成本较高。

## 关联研究分析

从问题动机看，Psyche-R1 与 Empathy-R1 均关注共情与推理的统一，但前者聚焦单轮知识推理，后者侧重长文本情感支持。Empathy-R1 采用链式共情（Chain-of-Empathy）分解情感步骤，而 Psyche-R1 通过迭代优化推理链确保逻辑准确性。差异根源在于任务特性：单轮问答要求答案的确定性，而长文本支持要求过程的流畅性。Psyche-R1 的复合奖励函数中，部分信用机制（Partial Credit）更适合多选题，但在开放式案例中可能抑制多样性表达，这一点在 PCEB 的案例分析部分未得到充分验证。

从方法设计看，Psyche-R1 与 DeepSeek-R1 共享 GRPO 框架，但数据筛选策略截然不同。DeepSeek-R1 依赖大规模通用数据，而 Psyche-R1 采用多 LLM 交叉筛选高难度心理样本。这种差异暗示了领域特定 RL 的必要性：通用推理能力无法直接迁移至心理领域，需通过数据工程注入领域特异性。然而，多 LLM 筛选依赖基线模型的能力上限，若基线模型均错误，可能引入系统性偏差。论文未讨论筛选样本的分布偏差对泛化性的影响，这是一个潜在的盲区。

## 总结

Psyche-R1 旨在解决心理 LLM 中共情表达与专业推理逻辑割裂的矛盾，通过迭代优化推理链与多模型交叉筛选高难度样本，在单轮静态问答中实现了二者的统一。实验表明，7B 模型在 PCEB 上达到 74.37%，超越 70B 的 DeepSeek-R1，证明小模型通过专用数据与 RL 对齐可逼近超大通用模型。然而，其评估局限于单轮静态基准，未能覆盖多轮交互中的安全漂移与情感一致性风险。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
