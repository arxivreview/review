# ACL2026最新论文 ｜SPEAK: Spiking Neurons as an Entropy-Aware Tokenizer for Large Language Models ｜脉冲神经元熵感知分词器

研究机构：浙江大学

作者：Ming Chen、Wenyao Li、Chao Liang 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_698665102bf3)

> 梯度分词器（GTok）旨在通过端到端优化解决静态分词器在多语言场景下的适应性局限，但现有方法在预测边界时往往独立决策，未能显式利用历史分词结果，导致边界放置次优。本文指出，历史信息并非均匀有用，需根据上下文相关性选择性利用。SPEAK 将脉冲神经元（Spiking Neuron）引入 GTok，利用其重置机制显式累积历史，并基于 token 级生成熵动态切换硬/软重置，以区分语言隔离与连续区域。该方法在 16 种语言上实现了跨语言适应性的提升，但其依赖固定熵阈值及串行计算的特性，限制了其在长上下文及大规模模型中的扩展潜力。

## 研究背景

理解本文需先厘清梯度分词器（GTok）与传统子词分词器的核心差异。传统 BPE 等算法基于统计频率静态构建词汇表，无法适应下游任务分布变化；GTok 则通过神经网络预测边界，实现分词与语言模型损失的联合优化。然而，GTok 的边界预测通常是无状态的，即当前 token 的边界决策不依赖于前序 token 的分割结果，这忽略了自然语言中存在的时序依赖结构。

分词器设计已从单纯的压缩效率竞争转向对多语言公平性与结构完整性的关注。主流 GTok 如 MAGNET 和 DTP 虽通过 Transformer 间接建模字符嵌入的时序关系，但未能显式建模“历史分词结果”对当前边界的影响，且引入了额外的计算开销。本文的切入点在于识别出历史信息利用的两个关键缺失：一是缺乏显式的历史累积机制，二是缺乏基于上下文相关性的选择性利用策略。

## 核心方法

### 方法参照系

本文问题属于端到端可学习分词范畴，其通用流程为：通过上下文编码器提取字符嵌入，经线性层映射至边界预测器，输出 token 边界序列。与标准 GTok 的关键差异在于，本文摒弃了无状态的独立边界预测，转而引入具有状态记忆能力的脉冲神经元，以显式处理时序依赖。

### 脉冲神经元边界预测

标准 GTok 在预测边界时丢弃了前序分割信息，导致同一单词在不同上下文中可能被分割为不同 token，破坏了形态一致性。SPEAK 采用泄漏积分发放（LIF）神经元替代传统的线性预测层，其膜电位 $u_t$ 随时间累积输入电流 $I_t$ 并按衰减率 $\gamma$ 衰减。当 $u_t$ 超过阈值 $u_{th}$ 时发放脉冲 $s_t=1$，标记 token 边界。该机制通过膜电位的物理累积，显式地将历史分词结果编码为当前状态的连续变量，解决了独立预测导致的结构断裂问题。

$$
u_t = \gamma v_{t-1} + \delta I_t, \quad s_t = \mathbb{1}(u_t \ge u_{th})
$$

此公式表明，当前时刻的膜电位由上一时刻状态衰减后的值与当前输入共同决定，使得边界决策天然依赖于历史累积量。

### 熵感知重置机制

LIF 神经元默认采用硬重置（Hard Reset）或软重置（Soft Reset），但统一重置策略无法区分语言中的“隔离点”与“连续段”。本文引入 token 级生成熵作为上下文相关性的代理指标：高熵 token 被视为语义分叉点（Contextual Boundary），低熵 token 构成语义连续区（Contextual Range）。在分叉点触发硬重置以切断无关历史，在连续区触发软重置以保留相关历史。重置模式由上下文边界预测器 $C$ 输出的掩码 $m_t$ 控制，软重置幅度由超参数 $\theta$ 调节。

$$
v_t = m_t \cdot (u_t(1-s_t) + u_{reset} \cdot s_t) + (1-m_t) \cdot (u_t - \theta \cdot u_{th} \cdot s_t)
$$

该公式实现了基于熵的动态状态管理：当 $m_t=1$（高熵边界）时执行硬重置，清空历史；当 $m_t=0$（低熵连续区）时执行缩放软重置，仅扣除部分阈值，从而在保留历史记忆的同时避免膜电位无界累积。

## 实验评估

实验在 XNLI 和 UNER 等 5 个数据集上，覆盖 16 种语言，对比了 MAGNET、DTP 等 GTok 及 DyTok、ZeTT 等 RTok。基线覆盖了当前主流的梯度与规则分词路线，但未包含无分词架构（如 HAT）或最新的多语言公平性专用分词器（如 MorphBPE）。

| 模型 | XNLI Avg. Acc. (%) | UNER Avg. F1 (%) | BPC | SF |
| :--- | :--- | :--- | :--- | :--- |
| ZeTT (SentencePiece) | 71.2 | - | - | - |
| DyTok (50%) | 72.0 | - | - | - |
| SPEAK | 73.1 | 79.2 | 1.108 | 4.32 |

SPEAK 在 XNLI 上比 DyTok (50%) 高 1.1%，在 UNER 上 F1 达 79.2%，BPC 为 1.108，表明其在保持压缩效率的同时提升了跨语言准确性。

| 消融变体 | text8 BPC | XNLI Acc. (%) |
| :--- | :--- | :--- |
| Hard reset (Uniform) | 1.134 | 82.8 |
| Soft reset (Uniform) | 1.128 | 84.3 |
| No reset (Uniform) | 1.130 | 83.2 |
| SPEAK (Entropy-aware) | 1.125 | 84.9 |

消融实验显示，统一硬重置性能最差（Acc. 82.8%），验证了显式利用历史的必要性；统一软重置优于硬重置但低于熵感知机制（Acc. 84.3% vs 84.9%），证明选择性重置优于无差别保留。

评估边界方面，实验仅使用 Hourglass Transformer（轻量模型）和 XLM-R（主流 LLM），未验证在 Mistral-7B 等更大规模模型上的表现。代码已开源，但超参数搜索范围未在正文详细披露，且未报告长上下文下的延迟扩展性。

## 关联研究分析

从问题动机看，SPEAK 与 MAGNET 均致力于解决 GTok 的适应性局限，但 MAGNET 依赖 Transformer 的注意力机制间接捕捉时序依赖，而 SPEAK 通过脉冲神经元的物理状态显式累积历史。这一差异源于对“历史”定义的认知不同：MAGNET 将历史视为特征空间中的上下文向量，SPEAK 将其视为离散事件序列中的状态记忆。SPEAK 的显式性使其在形态丰富语言上可能更具优势，但 Transformer 的并行计算特性在长序列上可能更具效率优势，SPEAK 的串行累积是否成为瓶颈，论文未给出回答。

从方法设计看，SPEAK 与 DyTok 代表了 GTok 与 RTok 的两条路线。DyTok 通过规则迭代优化分词方案，易于部署但缺乏泛化性；SPEAK 通过端到端优化实现自适应，但面临非可微分词优化的挑战。SPEAK 引入动量代理监督（Momentum-based Proxy Supervision）解决了梯度流中断问题，使其能集成到主流 LLM 中，而 DyTok 依赖超网络进行分词器迁移。SPEAK 的熵感知机制引入了额外的上下文边界预测器，增加了模型复杂度，而 DyTok 的规则更新无需额外训练开销。这种复杂度换取适应性的取舍，在低资源语言场景下是否始终为正收益，需更多实证支持。

## 总结

SPEAK 旨在解决 GTok 中历史分词结果未被显式且选择性利用的问题，通过脉冲神经元的重置机制与 token 级熵的结合，实现了基于上下文相关性的动态边界决策。该方法在 16 种语言上取得了 73.1% 的 XNLI 准确率和 1.108 的 BPC，证明了熵感知重置的有效性。然而，实验仅在轻量模型和中等规模 LLM 上验证，且熵阈值固定为 top 20%，缺乏对动态阈值调整的探索。当输入序列长度增加至百万级 token 时，LIF 神经元的串行状态累积是否会导致推理延迟显著上升，从而抵消其在准确性上的增益，论文未给出回答。
