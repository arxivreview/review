# ACL2026最新论文 ｜Defenses Against Prompt Attacks Learn Surface Heuristics ｜监督微调防御的捷径偏差诊断

研究机构：美国南加州大学、美国加州大学伯克利分校

作者：Shawn Li、Chenxiao Yu、Zhiyu Ni 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.07185)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.07185)

> 提示注入防御旨在让大语言模型区分系统指令与恶意数据，但现有监督微调方法常因训练数据分布狭窄而失效。本文指出，高攻击拒绝率掩盖了模型对良性输入的严重误拒，其根源在于模型学习了表面特征而非语义意图。作者通过构建控制变量诊断集，量化了位置、Token 触发和主题泛化三种捷径偏差。这一工作揭示了模型级防御在效用与安全间的失衡，但尚未验证结合系统级隔离后能否消除这些偏差。

## 研究背景

当大语言模型（LLMs）部署于客户支持或检索增强生成（RAG）等安全关键场景时，模型需严格遵循系统指令并处理良性用户请求。然而，当恶意指令通过用户查询或外部检索内容进入管道时，模型可能忽略既定逻辑执行注入命令，这一漏洞称为提示注入（Prompt Injection）。为应对此威胁，主流防御策略采用监督微调（Supervised Fine-Tuning, SFT），利用标注的良性与恶意样本训练模型识别攻击模式。

然而，现有防御数据多由显式注入演示主导，如指令覆盖或分隔符逃逸，导致模型在标准基准上虽能实现高攻击拒绝率，却未能真正习得对有害意图的识别能力。这种基于表面结构相关性的学习机制，使得防御模型在面对良性但结构相似的输入时产生系统性误拒。本文切入点在于揭示这种“高拒绝率”背后的效用崩塌，通过控制变量实验证明，当前模型级防御并非基于意图感知，而是依赖于位置、Token 或主题等捷径特征。

## 核心方法

### 防御微调的参照系

本文问题置于模型级提示注入防御的通用流程中。标准流程假设通过最小化经验风险，模型能区分良性与攻击输入。然而，当攻击样本呈现狭窄的结构模式时，模型可能转而依赖表面特征 $\phi(x)$ 而非实际恶意意图进行决策，导致决策规则退化为 $f_{\theta'}(x) = \text{reject}$ whenever $\phi(x)$ is active。

### 捷径偏差的形式化

本文提出三种捷径偏差假设，旨在隔离单一表面因素对拒绝概率的影响。位置偏差（Position Bias）定义为：在拼接提示 $x = [x_A; x_B]$ 中，若 $x_B$ 为良性任务，其拒绝概率 $P(\text{reject} | x_B)$ 因位置靠后而显著升高。Token 触发偏差（Token Trigger Bias）定义为：插入攻击数据中频繁出现的字符串 $t \in T$ 会提升良性提示的拒绝概率，且该效应独立于 $t$ 的语义角色。主题泛化偏差（Topic Generalization Bias）定义为：来自防御训练数据未覆盖主题域 $T_{test}$ 的良性提示，其任务性能相比已知域 $T_{train}$ 显著下降。

$$
\mathcal{L}(\theta') = \mathbb{E}_{(x,z) \sim D_{def}} [\ell(f_{\theta'}(x), z)]
$$

该损失函数在攻击样本结构单一时，可通过依赖表面特征 $\phi(x)$ 最小化，导致模型习得捷径而非意图。

### 控制变量诊断集

为验证上述假设，本文构建了三类诊断数据集，确保语义意图保持良性，仅改变单一表面因素。位置压力集通过拼接两个独立良性任务，测试模型是否将提示后缀视为攻击区域。关键词触发集通过向良性提示插入攻击关联 Token（如 "sudo"）并设置随机技术词对照组，隔离 Token 身份的影响。主题泛化集通过对比防御训练域与测试域（如 GPQA, MMLU）的主题分布差异，量化领域偏移导致的性能退化。

$$
\Delta RR = RR(x_{+t}) - RR(x_{+r})
$$

该差值量化了触发 Token 相对于随机对照组的额外拒绝率，若 $\Delta RR$ 显著为正，则证实 Token 触发偏差的存在。

## 实验评估

实验基于 Llama 3 和 Mistral 两个开源模型，对比 SecAlign 和 StrucQ 两种微调防御及 ProtectAIv2 等 Prompt Guard 方法。基线覆盖模型级微调与外部过滤两类主流路线，但缺失 IsolateGPT 等系统级隔离方法的对比，无法评估架构隔离对消除捷径偏差的作用。

| 模型/防御 | GPQA Acc (Drop) | MMLU Acc (Drop) | AIME Acc (Drop) |
| :--- | :--- | :--- | :--- |
| Llama-3 Base | 30.0 | 65.0 | 0.0 |
| Llama-3 + StrucQ | 16.0 (-14.0) | 32.5 (-32.5) | 0.0 (-0.0) |
| Llama-3 + SecAlign | 25.0 (-5.0) | 42.2 (-22.8) | 0.0 (-0.0) |
| Mistral Base | 23.0 | 47.0 | 0.0 |
| Mistral + StrucQ | 12.0 (-11.0) | 24.5 (-22.5) | 0.0 (-0.0) |
| Mistral + SecAlign | 13.0 (-10.0) | 17.3 (-29.7) | 0.0 (-0.0) |

数据显示，微调防御导致良性任务准确率大幅下降，Llama-3 在 MMLU 上准确率从 65.0% 降至 32.5%（StrucQ），降幅达 32.5 个百分点。位置偏差表现为后缀任务拒绝率从基线的低于 10% 升至最高 90%；Token 触发偏差中，插入单个触发 Token 使误拒率增加高达 50%；主题泛化偏差导致测试时准确率下降最高 40%。

消融实验表明，位置偏差是主导因素，Figure 3 显示随着问题在提示中位置后移，响应率单调下降。Prompt Guard 模型同样存在 Token 触发偏差，移除触发 Token 后，ProtectAIv2 的拒绝率从 53.9% 降至 23.8%。评估边界方面，本文未报告计算效率指标，且诊断集规模有限（如 AIME 仅 30 题），可能影响统计显著性。代码已开源，但超参数细节需查阅附录。

## 关联研究分析

从问题动机看，本文与 IsolateGPT 等系统级防御形成互补。IsolateGPT 通过架构隔离实现 0.12% 的 ASR，侧重阻断恶意行为执行；而本文聚焦模型内部决策机制，揭示微调防御在良性输入上的效用损失。两者差异源于防御层级：系统级防御不改变模型权重，故不引入捷径偏差；模型级防御通过权重更新习得特征，易受训练数据分布偏差影响。本文未测试系统级隔离能否消除模型级偏差，这一空白限制了结论的普适性。

从方法设计看，本文与 SecAlign 和 StrucQ 共享 SFT 框架，但评估协议截然不同。SecAlign 和 StrucQ 关注攻击拒绝率，本文引入良性效用诊断，通过控制变量隔离偏差来源。这种差异揭示了传统评估指标的盲区：高攻击拒绝率可能以牺牲良性效用为代价。本文未探索意图感知训练目标，仅诊断了现有方法的缺陷，未提供改进方案。

## 总结

本文核心矛盾在于模型级提示注入防御的高攻击拒绝率与良性效用崩塌之间的失衡。切入点在于揭示防御模型依赖表面特征而非语义意图，通过控制变量诊断集量化了位置、Token 触发和主题泛化三种捷径偏差。实验证明，微调防御导致 MMLU 准确率下降最高 32.5 个百分点，后缀任务拒绝率升至 90%。边界在于未对比系统级隔离方法，且诊断集规模有限。当结合系统级隔离时，模型级捷径偏差是否完全消除，论文未给出回答。
