> 稀有天体目录构建的瓶颈在于最终验证阶段依赖人工视觉检查，而现有深度学习分类器因缺乏可解释性无法替代专家判断。本文切入点是将视觉语言模型（VLM）改造为能主动调用光谱可视化工具的代理，通过交替文本推理与局部图像观察模拟天文学家的检查流程。具体做法是结合冷启动监督微调与基于结果的强化学习，训练模型生成可审计的迭代检查轨迹。该方案在宏平均F1上显著优于基线，但其泛化能力是否依赖于特定光谱形态的视觉特征，仍需更严格的跨任务测试来确认。

## 研究背景

当深度学习分类器面对信噪比低或形态复杂的光谱时，其输出的概率分数缺乏物理依据，天文学家无法信任其“黑盒”决策。这种信任缺失迫使目录构建流程保留人工验证环节，但面对LAMOST等巡天产生的海量候选源，人工检查成为不可扩展的瓶颈。解决此问题的关键在于让模型不仅输出标签，还能像专家一样“思考”——即通过观察光谱局部细节来形成判断。

传统路线分为两类：专用深度学习模型（如CarbonNet、GaiaNet）擅长大规模筛选，但在验证阶段难以区分细微的污染特征；通用视觉语言模型（如o3、GPT-4.1）具备推理能力，但缺乏针对光谱数据的专用工具，无法捕捉细微的波长区间特征。现有方法的核心缺陷在于，它们要么牺牲可解释性换取精度，要么牺牲精度换取通用性，未能实现“专家对齐”的自动化验证。Spec-o3的切入点在于，将光谱可视化工具嵌入VLM的推理循环，使模型能够自主决定何时、何地放大观察，从而在保持可解释性的同时提升验证精度。

## 核心方法

### 方法参照系

本文问题属于“多模态科学代理”范畴，但区别于标准的“输入-输出”映射范式。标准VLM流程是将图像与文本直接映射至答案，而Spec-o3的核心差异在于引入了**交互式工具调用**：模型在推理过程中动态生成光谱局部视图，将视觉证据作为中间状态纳入决策链。

### 交错多模态思维链（iMCoT）

iMCoT机制解决了通用VLM无法自主定位光谱关键特征的问题。在状态 $s_t$ 中，模型不仅持有历史文本 $T_{\le t}$，还持有历史渲染图像 $I_{\le t}$。模型策略 $\pi_\theta$ 决定是输出最终答案，还是调用工具 $Tool_t$ 获取波长区间 $\Delta \lambda_t$ 的局部视图。

$$
\tau = \left( T_0, I_0, T_1, I_1, \dots, T_N \right)
$$

该轨迹公式表明，推理过程是文本块与工具生成图像的严格交替。这种设计迫使模型将抽象的诊断假设（如“检查Hα区域”）转化为具体的视觉操作，从而将天文学家的“全局-局部”检查范式编码进模型行为中。

### 两阶段后训练策略

冷启动SFT解决了模型缺乏光谱领域先验的问题，而强化学习（RL）解决了专家轨迹稀缺导致的泛化不足。冷启动阶段使用约1k条经专家审核的轨迹进行监督微调，并对工具返回的图像token施加损失掩码，防止模型记忆图像内容而非学习调用逻辑。RL阶段采用组相对策略优化（GRPO），奖励函数仅基于最终预测的准确性与格式合规性：

$$
r(\tau) = \begin{cases} 1, & \text{if } o_{pred} = o_{gold} \land f_{fmt}(y) \\ 1 - \alpha, & \text{if } o_{pred} = o_{gold} \land \neg f_{fmt}(y) \\ 0, & \text{if } o_{pred} \neq o_{gold} \land f_{fmt}(y) \\ -\alpha, & \text{if } o_{pred} \neq o_{gold} \land \neg f_{fmt}(y) \end{cases}
$$

该奖励设计剥离了工具使用频率的显式奖励，迫使模型在冷启动注入的先验基础上，自主探索最优的工具调用策略以最大化最终验证准确率。

## 实验评估

| 模型 | CV F1 | CS F1 | SS F1 | MG F1 | WD F1 | 宏平均 F1 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Qwen2.5-VL-7B | 25.4 | 31.5 | 27.3 | 29.0 | 28.1 | 28.3 |
| o3 | 57.1 | 53.1 | 53.3 | 60.0 | 37.8 | 52.3 |
| GaiaNet | 67.2 | 87.1 | 70.3 | 51.8 | 48.2 | 64.9 |
| Spec-o3-7B | 81.0 | 80.2 | 84.5 | 83.4 | 53.6 | 76.5 |

Spec-o3-7B在SpecVI-Bench上取得76.5%的宏平均F1，显著优于o3（52.3%）和专用模型GaiaNet（64.9%）。基线覆盖了专用DL、专有VLM和开源VLM，但缺乏其他工具增强VLM的对比，这可能高估了工具增强的独立贡献。

| 配置 | 3B F1 | 7B F1 |
| :--- | :--- | :--- |
| SFT + RL + Tool | 73.3 | 76.5 |
| RL + Tool | 35.7 | 40.5 |
| SFT + Tool | 33.1 | 41.6 |
| Tool Only | 26.1 | 28.3 |

消融实验显示，单独使用RL或SFT均无法达到完整框架的性能，两者结合带来近翻倍的提升。这表明冷启动注入的领域先验是RL有效优化工具策略的前提，而非简单的数据量叠加。

评估指标以F1为主，因测试集存在类别不平衡。代码与模型已开源，但冷启动轨迹的构建依赖专家人工审核，这一过程难以完全自动化复现。跨巡天测试（SDSS/DESI）显示Spec-o3-7B在未见巡天上保持78.5%-81.5%的F1，验证了跨仪器泛化能力。

## 关联研究分析

从问题动机看，Spec-o3与Sim-Pretrain-Adapt均致力于解决跨巡天泛化，但路径截然不同。Sim-Pretrain-Adapt通过模拟数据预训练与域适应对齐潜在空间，属于“表示学习”路线；而Spec-o3通过工具交互增强推理过程，属于“代理行为”路线。前者依赖数据分布的统计对齐，后者依赖模型对物理特征的主动探索。Spec-o3在未见任务（O/B/A型光谱）上取得76.4% F1，表明其学到的可能是通用的“检查范式”而非特定分布记忆，这与Sim-Pretrain-Adapt的零样本迁移机制形成互补。

从方法设计看，Spec-o3与AstroVLM同属多智能体/工具增强框架，但任务焦点不同。AstroVLM针对成像质量诊断，处理的是图像质量指标；Spec-o3针对光谱形态验证，处理的是物理特征识别。两者均证明了工具增强VLM在科学诊断中的价值，但Spec-o3的iMCoT机制更强调“假设-验证”的迭代逻辑，而AstroVLM更侧重多步推理链。这种差异源于光谱数据的连续性与图像数据的离散性，前者需要更精细的波长定位，后者更依赖全局结构理解。

## 总结

Spec-o3解决了稀有天体验证中“精度-可解释性”的矛盾，通过iMCoT机制将专家检查流程编码为模型行为。其核心贡献在于证明了两阶段后训练（冷启动SFT+RL）能有效利用少量专家轨迹，使7B模型在宏平均F1上从28.3%提升至76.5%。然而，其性能高度依赖于冷启动轨迹的质量与覆盖度，且工具调用次数与精度的权衡关系未充分量化。当面对形态极度复杂或信噪比极低的光谱时，模型是否仍能保持稳定的工具调用策略，论文未给出明确回答。
