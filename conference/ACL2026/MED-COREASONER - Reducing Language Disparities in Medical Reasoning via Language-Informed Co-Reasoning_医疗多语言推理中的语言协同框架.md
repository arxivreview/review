# ACL2026最新论文 ｜MED-COREASONER: Reducing Language Disparities in Medical Reasoning via Language-Informed Co-Reasoning ｜医疗多语言推理中的语言协同框架

研究机构：日本东京大学、日本国立情报学研究所

作者：Fan Gao、Sherry T. Tong、Jiwoong Sohn 等 14 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_150bf5dffc86)

> 医疗大语言模型在非英语场景下常出现推理能力断崖式下跌，根源在于英语中心化的内部表征丢失了本地临床语境。现有“先翻译后推理”策略虽能利用英语逻辑优势，却导致文化特异性知识剥离，无法兼顾准确性与保真度。本文提出Med-CoReasoner，通过并行生成英语与本地语言推理链，利用概念级融合将本地临床细节注入英语逻辑骨架，并辅以多语言指南检索。该方法在低资源语言上显著缩小了性能差距，但其对检索质量的依赖及概念融合阈值的敏感性仍存疑。

## 研究背景

医疗问答任务要求模型在生成诊断建议时，不仅答案正确，还需推理过程符合特定地区的临床指南与术语习惯。当模型面对斯瓦希里语等低资源语言查询时，若强制使用英语进行内部推理，虽能维持逻辑连贯性，但会丢失如“区域特异性并发症”等本地化知识；反之，若仅用本地语言推理，模型往往因预训练数据中该语言医疗语料稀缺，导致逻辑链条断裂。这种“逻辑骨架”与“临床血肉”的分离，构成了多语言医疗推理的核心矛盾。

早期解决路径主要依赖提示工程或跨语言迁移。提示工程类方法（如Translate-then-Solve）将本地语言问题翻译为英语，利用模型强大的英语推理能力生成答案后再译回，但这引入了翻译噪声，且无法保留原语言中的细微临床语境。跨语言迁移类方法（如多语言思维链）试图通过数据增强平衡性能，但高质量的多语言医疗推理数据极度稀缺，且现有基准多为单选题，难以评估开放式临床推理的可靠性。Med-CoReasoner的切入点在于承认两种语言推理的互补性：英语提供可迁移的逻辑结构，本地语言承载实践导向的医学知识，通过推理时的并行处理与融合，而非训练时的数据对齐，来解决这一矛盾。

## 核心方法

### 方法参照系

本文问题可置于“推理时干预”范畴，区别于传统的权重更新或数据增强。标准流程通常涉及单一语言的思维链生成，本文的关键差异在于引入了双语言并行推理机制，并在推理阶段通过概念对齐实现跨语言知识整合，而非依赖预训练阶段的跨语言对齐。

### 并行推理与概念链提取

针对单一语言推理无法同时满足逻辑严谨性与文化适配性的问题，Med-CoReasoner首先对输入问题 $Q_l$ 进行双语处理。若本地语言非英语，则生成英语版本 $Q_e = \text{translate}(Q_l)$，并独立调用模型生成两条推理链：$R_e = M(Q_e)$ 和 $R_l = M(Ql)$。这种独立性确保了每条链遵循其语言的自然推理路径，避免相互干扰。随后，利用大语言模型从原始推理链中提取结构化概念链 $C = M(R) = \{c_1 \rightarrow c_2 \rightarrow \dots \rightarrow c_k\}$。此步骤将冗长的自然语言压缩为有序的概念序列，例如将英语推理抽象为 $\{Severe\ frostbite \rightarrow Dry\ gangrene \rightarrow Cellulitis\}$，为后续跨语言对齐提供离散化基础。

### 基于嵌入相似度的概念融合

概念链提取后，需解决英语逻辑骨架与本地临床细节的整合问题。Med-CoReasoner采用位置感知的骨干增强融合策略，以英语概念链 $C_e$ 为骨干，遍历本地语言概念链 $C_l$ 中的每个概念 $c_l$，计算其与 $C_e$ 中所有概念的最大嵌入相似度。若相似度超过阈值 $\tau$（设为0.5），则将该本地概念锚定至最相似的英语概念并加入融合链 $C_f$。融合公式为：

$$ C_f = C_e \cup \{ c_l \in C_l \mid \max_{c_e \in C_e} \text{sim}(c_l, c_e) > \tau \} $$

该公式的物理含义是：仅当本地语言概念在语义空间上与英语逻辑节点高度重合时，才将其作为补充信息注入，从而在保持英语推理逻辑连贯性的同时，引入本地语言特有的临床术语与细节，避免了简单翻译带来的语义扭曲。

## 实验评估

实验在Global-MMLU、MMLU-ProX及新构建的MultiMed-X基准上进行，覆盖中文、日语、韩语、德语、法语、西班牙语、意大利语及斯瓦希里语。基线包括CoT、SoT、Self-Consistency及RAG+CoT，但缺失与强化学习训练策略（如AdaMame-GRPO）或纯表示工程方法（如MRRE）的直接对比。

| 方法 | Global-MMLU (Avg) | MMLU-ProX (Avg) |
| :--- | :--- | :--- |
| GPT-5.1 (Base) | 84.11 | 71.39 |
| Ours (GPT-5.1) | 88.61 | 77.42 |
| GPT-4o (Base) | 81.79 | 67.94 |
| Ours (GPT-4o) | 84.20 | 71.91 |
| DeepSeek-3.2 (Base) | 79.59 | 65.15 |
| Ours (DeepSeek-3.2) | 85.19 | 72.50 |

在GPT-5.1骨干上，Med-CoReasoner在Global-MMLU上提升4.5个百分点，在MMLU-ProX上提升6.03个百分点。消融实验显示，移除本地语言推理链对低资源语言（如斯瓦希里语、约鲁巴语）的影响最大，导致性能下降1.0至3.5分，证实了本地语言在文化特异性知识保留中的关键作用。移除RAG后，意大利语和斯瓦希里语出现轻微性能下降，表明检索增强在低资源场景下可能引入噪声，需更精细的相关性过滤。

评估协议采用GPT-4o作为自动裁判，对长文本问答进行5分制评分，并计算通过率（Overall Quality与Safety均≥4）。该协议虽能评估推理质量，但依赖单一裁判模型，可能存在偏差。代码已开源，但概念融合阈值 $\tau=0.5$ 的鲁棒性未在不同嵌入模型间进行充分验证。

## 关联研究分析

从问题动机看，Med-CoReasoner与Translate-then-Solve路线存在根本差异。后者假设英语推理是“通用真理”，本地语言仅是输出格式，因此通过翻译桥接；而本文假设英语与本地语言分别承载“逻辑”与“知识”两种不同维度的信息，需并行提取后融合。这一差异源于医疗任务对文化语境的高敏感性，通用推理任务中可能存在的“语言无关性”假设在医疗领域失效。

从方法设计看，Med-CoReasoner与MRRE（表示工程）同属推理时干预，但MRRE通过稀疏自编码器修改内部激活以解锁非英语能力，属于底层特征干预；而Med-CoReasoner通过外部概念链融合，属于高层语义干预。MRRE的优势在于无需额外推理开销，但可解释性低且可能扭曲语义；Med-CoReasoner的优势在于过程透明且可追溯，但引入了额外的LLM调用与检索开销。在低资源医疗场景下，Med-CoReasoner的显式知识注入可能比隐式特征调整更可靠，因为医疗错误代价极高，需要可验证的推理路径。

## 总结

Med-CoReasoner针对医疗多语言推理中逻辑骨架与临床血肉分离的矛盾，通过并行双语推理与概念级融合，在GPT-5.1骨干上实现了MMLU-ProX平均6.03分的提升，并在斯瓦希里语等低资源语言上显著缩小了性能差距。其边界在于对检索质量的依赖及概念融合阈值的敏感性，消融实验显示移除本地语言链对低资源语言影响最大，但RAG在部分语言中引入噪声。当支持集增大或嵌入模型更换时，概念融合阈值 $\tau$ 的最优值是否稳定，论文未给出回答。
