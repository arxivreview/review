# ACL2026最新论文 ｜VLN-NF: Feasibility-Aware Vision-and-Language Navigation with False-Premise Instructions ｜证据接地的否定性验证：VLN-NF 与 ROAM 框架

研究机构：国立台湾大学、国立清华大学

作者：Hung-Ting Su、Ting-Jun Wang、Jia-Fong Yeh 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.10533)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.10533)

> 视觉-语言导航（Vision-and-Language Navigation, VLN）传统上假设指令指向的目标必然存在，导致智能体在目标缺失时陷入幻觉或无限搜索。现有监督模型缺乏显式的“未找到”输出机制，而大语言模型（LLM）虽具备常识推理能力，却在部分可观测环境下的长程房间定位中表现脆弱。本文提出 VLN-NF 基准与 ROAM 框架，通过解耦房间级监督导航与 LLM 驱动的室内探索，实现基于证据的否定性验证。该工作填补了 3D 具身智能中虚假前提处理的空白，但其对房间级标注的依赖及探索策略的静态性限制了其在动态复杂场景中的泛化潜力。

## 研究背景

当智能体接收到“去厨房拿桌上的盘子”这一指令时，若盘子实际位于客厅，传统 VLN 模型会因训练数据中不存在“目标缺失”样本而强行寻找相似物体或停滞。这种失效源于任务定义中的可行性假设：R2R、REVERIE 等主流基准均预设指令有效，智能体只需执行路径规划与目标定位。然而，认知科学研究表明，人类在物体位置回忆中约每七次就有一次错误，真实部署中指令的事实性错误是常态。因此，智能体必须具备在部分可观测环境中通过自主探索证明目标不存在的能力，即“证据接地的否定性验证”。

现有解决方案主要分为两类：一是基于模仿学习的监督模型，如 DUET，它们擅长拓扑导航但缺乏显式的终止与否定机制，强行添加 NOT-FOUND 动作会导致因探索轨迹的不确定性而产生过早放弃；二是基于 LLM 的零样本规划器，如 NavGPT，它们利用常识引导搜索，但在缺乏逐步几何反馈的情况下，房间级定位失败率极高。这两类方法均未能解决“如何在不依赖昂贵轨迹标注的前提下，可靠地收集足够证据以支持否定判断”这一核心矛盾。本文切入点在于将导航任务解耦为“房间定位”与“室内证据收集”两个子任务，前者利用弱监督解决几何漂移，后者利用 LLM 的语义先验解决探索策略的不确定性。

## 核心方法

### 方法参照系

标准 VLN 流程为“指令理解-路径规划-目标定位”，其核心假设是目标存在。本文的关键差异在于引入“可行性验证”环节，要求智能体在到达目标区域后，不仅定位物体，还需通过覆盖性探索确认其存在性，并在证据不足时输出 NOT-FOUND。这一转变将任务从“最短路径到达”扩展为“证据收集与决策”。

### 两阶段混合架构

针对 LLM 在部分可观测环境中房间定位能力弱（NavGPT Reach SR 仅 8.2%）的问题，ROAM 引入监督学习的房间级导航器。该模块仅使用房间标签进行训练，利用 DUET 等成熟架构的拓扑记忆能力，确保智能体能稳定到达指令指定的目标房间。这一设计解决了纯 LLM 方法因几何直觉缺失导致的长程漂移失效，将复杂的 3D 导航问题降维为局部探索问题。

### 自由空间引导的室内探索

进入目标房间后，智能体需决定如何移动以最大化证据覆盖。传统方法依赖 LLM 的语义提示，但缺乏对物理空间结构的感知。ROAM 引入自由空间射线投射估计引擎（FREE），通过计算当前视角到障碍物的距离 $d_{free}$ 来引导探索。其核心公式为：

$$
v_{next} = \arg\max_{v \in N_{unvisited}} \left( |O_{visible}(v) \setminus O_{seen}| + \lambda \cdot d_{free}(v) \right)
$$

其中 $O_{visible}(v)$ 为视角 $v$ 可见的新物体集合，$d_{free}(v)$ 为自由空间清除信号。该公式的物理含义是：智能体优先选择能揭示新物体且前方空间开阔的视角，从而避免在狭窄角落重复探索，确保在有限步数内覆盖房间大部分区域。这一机制弥补了 LLM 缺乏几何直觉的缺陷，使探索过程从“语义驱动”转变为“语义-几何联合驱动”。

## 实验评估

实验基于 REVERIE 构建的 VLN-NF 基准，包含 718 个验证未见回合，每回合配对一条可行（FOUND）与一条不可行（NOT-FOUND）指令。基线覆盖监督模型（DUET）、LLM 规划器（NavGPT, MapGPT）及视觉提示方法（SoM）。ROAM 在 REV-SPL 指标上取得 6.1 分，显著高于 DUET 的 4.2 分和 NavGPT 的 1.0 分，表明混合架构在证据收集效率与决策准确性上优于单一范式。

| 方法 | Reach SR (%) | Reach&Decision SR (%) | REV-SPL |
| :--- | :--- | :--- | :--- |
| DUET | 53.8 | 33.8 | 4.2 |
| NavGPT | 8.2 | 4.2 | 1.0 |
| MapGPT | 30.0 | 18.2 | 3.2 |
| ROAM (GPT-3.5) | 58.6 | 37.6 | 6.1 |
| ROAM (GPT-4o) | 62.6 | 41.4 | 5.6 |

消融实验显示，移除房间级导航器导致 Reach SR 从 59.4% 骤降至 7.8%，证实了监督导航对长程定位的必要性。引入 FREE 模块后，物体覆盖率从 79.2% 提升至 82.1%，REV-SPL 从 5.6 提升至 6.1，验证了几何引导对探索效率的增益。值得注意的是，ROAM-GPT-4o 虽然决策准确率更高，但因探索路径过长（22.0 步 vs 9.9 步），REV-SPL 反而低于 GPT-3.5 版本，反映出 REV-SPL 对探索效率的惩罚机制有效抑制了过度搜索。

评估边界方面，REV-SPL 依赖参考探索路径长度，该长度由启发式算法生成，可能受场景复杂度影响。此外，论文未报告计算延迟，且仅基于 REVERIE 的 45% 子集进行实验，限制了结论在更大规模数据上的普适性。代码与数据已开源，但房间级导航器的训练细节未完全披露，复现时需注意超参数敏感性。

## 关联研究分析

从问题动机看，本文与 R2R-UNO（Hong et al., 2024）均关注指令与环境的不匹配，但 R2R-UNO 聚焦于障碍物导致的导航不可行，而 VLN-NF 聚焦于目标语义缺失。这一差异源于任务本质：R2R-UNO 可通过路径重规划解决，而 VLN-NF 要求智能体具备“否定性知识”，即确认目标不存在的能力。本文通过引入 NOT-FOUND 动作空间，将 VLN 从“执行”扩展为“验证”，这一转变在 R2R-UNO 中未体现，因为后者假设目标始终存在，只是路径受阻。

从方法设计看，ROAM 与 MapGPT（Zhou et al., 2024）均利用 LLM 进行规划，但 MapGPT 依赖全局地图构建，而 ROAM 采用局部房间级监督。MapGPT 在 VLN-NF 中 REV-SPL 仅为 3.2，低于 ROAM 的 6.1，表明全局地图在部分可观测环境下难以提供足够的局部证据。ROAM 的 FREE 模块通过局部几何信号引导探索，避免了 MapGPT 中地图构建的计算开销与信息损失。这一设计选择暗示，在目标导向任务中，局部证据收集的效率优于全局地图的完整性，但这也限制了 ROAM 在需要全局路径优化的场景中的表现。

## 总结

本文核心矛盾在于现有 VLN 模型无法在目标缺失时提供基于证据的否定判断，导致幻觉或无限搜索。ROAM 通过解耦房间级监督导航与 LLM 驱动的室内探索，解决了 LLM 几何直觉缺失与监督模型缺乏否定机制的双重缺陷。实验证明，ROAM 在 VLN-NF 上取得 6.1 REV-SPL，较 DUET 提升 45%，验证了混合架构的有效性。然而，其依赖房间级标注且探索策略基于静态启发式，限制了在动态或未知拓扑环境中的适用性。当目标房间结构复杂且缺乏明确地标时，FREE 模块的几何引导是否仍能维持足够的探索覆盖率，论文未给出回答。
