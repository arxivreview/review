【DEFT: Demystifying VLN Failures via a Unified Dual-View Explainability Framework for LLM-based Agents ｜黑盒视觉-语言导航代理的双视图可解释性框架

作者：Yawen Wang、Yihan Dai、Jianming Chen 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f745f230bbe7)

> 视觉-语言导航（VLN）中基于大语言模型（LLM）的代理因内部逻辑不透明，导致导航失败时难以定位是时间步决策失误还是视觉特征误读。现有解释方法将时间关键性与特征显著性割裂处理，且无法应对黑盒代理的行为不稳定性。DEFT 通过共享潜空间的双头架构，联合建模“何时决策关键”与“何种视觉证据支撑决策”，利用集成代理策略在黑盒约束下恢复鲁棒的像素级归因。该框架在诊断精度上优于独立基线，但受限于离散图环境与轻量代理的表征能力，其解释保真度在连续动态场景中仍存疑。

【GROKE: Vision-Free Navigation Instruction Evaluation via Graph Reasoning on OpenStreetMap ｜无视觉导航指令评估：基于开放街图推理的 GROKE 框架

作者：Farzad Shami、Subhrasankha Dey、Nico Van de Weghe 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.07375)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_b7b586424306)

> 导航指令的质量评估长期依赖参考文本的词汇重叠或视觉模拟器的执行成功率，前者无法捕捉空间逻辑的矛盾，后者则受限于高保真图像数据的获取成本与感知噪声干扰。GROKE 框架通过剥离视觉模态，直接利用 OpenStreetMap (OSM) 的拓扑结构作为环境表征，将指令评估转化为纯图推理任务。该框架采用层级化智能体架构，先分解指令为原子子目标，再在结构化 JSON 表示的局部地图上进行航点预测。这一去视觉化路径验证了符号化地图在 LLM 空间推理中的有效性，但其评估结果是否完全等价于真实物理环境中的可导航性，仍存疑。

【VLN-MME: Diagnosing MLLMs as Language-guided Visual Navigation agents ｜视觉语言导航多模型评估

作者：Xunyi Zhao、Gengze Zhou、Qi Wu

论文原文见 [arXiv](https://arxiv.org/abs/2512.24851)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.24851)

> 具身智能体在连续三维空间中执行导航任务时，多模态大语言模型（MLLM）的推理能力与空间感知能力常被高估，现有评估框架因依赖高保真模拟器且固定智能体架构，导致无法区分模型内在缺陷与工程策略失效。本文提出 VLN-MME，通过模块化解耦模型、智能体与任务，并采用无模拟器预渲染管线，实现零样本 MLLM 导航能力的细粒度诊断。该框架揭示了 MLLM 在具身导航中存在的“感知-动作断裂”及思维链（CoT）推理的负迁移现象，为后续针对性后训练提供了诊断依据，但其离散图评估协议对连续环境几何接地能力的覆盖仍存疑。

【VLN-NF: Feasibility-Aware Vision-and-Language Navigation with False-Premise Instructions ｜证据接地的否定性验证：VLN-NF 与 ROAM 框架

研究机构：国立台湾大学、国立清华大学

作者：Hung-Ting Su、Ting-Jun Wang、Jia-Fong Yeh 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.10533)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.10533)

> 视觉-语言导航（Vision-and-Language Navigation, VLN）传统上假设指令指向的目标必然存在，导致智能体在目标缺失时陷入幻觉或无限搜索。现有监督模型缺乏显式的“未找到”输出机制，而大语言模型（LLM）虽具备常识推理能力，却在部分可观测环境下的长程房间定位中表现脆弱。本文提出 VLN-NF 基准与 ROAM 框架，通过解耦房间级监督导航与 LLM 驱动的室内探索，实现基于证据的否定性验证。该工作填补了 3D 具身智能中虚假前提处理的空白，但其对房间级标注的依赖及探索策略的静态性限制了其在动态复杂场景中的泛化潜力。

】
