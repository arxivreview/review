# ACL2026最新论文 ｜Discovery and Reinforcement of Tool-Integrated Reasoning Chains via Rollout Trees ｜工具集成推理链的发现与强化

作者：Kun Li、Zenan Xu、Junan Li 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_45866e31b02f)

> 长思维链推理模型在精确计算与符号操作上存在固有局限，而现有工具集成推理方法多局限于短思维链场景，难以直接迁移至长链推理。本文提出 DART 框架，通过动态构建 rollout 树并在高熵位置注入工具提示，实现无标注数据下工具调用行为的自发发现与强化。该方法利用树状结构进行细粒度优势估计，将工具调用与长链推理有机融合。其价值在于解决了长链推理中工具行为融入的分布偏移问题，但实验仅覆盖数学与科学任务，工具调用对推理忠实性的潜在影响未被验证。

## 研究背景

当大型推理模型（Large Reasoning Models, LRMs）处理复杂数学问题时，纯自然语言推理常因算术错误或逻辑断裂导致答案偏差。为弥补这一缺陷，工具集成推理（Tool-Integrated Reasoning, TIR）范式应运而生，其核心是让模型在推理过程中调用 Python 解释器等外部工具执行精确计算。然而，现有 TIR 方法主要基于短思维链设计，其提示工程或强化学习策略无法有效作用于长思维链的“思考”部分，导致工具调用在长链推理中命中率极低。

长思维链推理的训练范式通常包含两个阶段：首先通过监督微调（Supervised Fine-Tuning, SFT）在纯文本长链数据上训练，随后通过基于答案正确性的强化学习（Reinforcement Learning, RL）优化。这一流程导致工具使用行为与长链推理行为来自不同的数据源，形成两个割裂的输出分布。直接应用短链 TIR 方法会破坏模型原生的长链推理能力，而依赖人工标注长链工具轨迹则成本高昂且易引发分布偏移。因此，如何在无标注数据条件下，将工具调用行为无缝融入长链推理而不损害模型原生能力，成为亟待解决的关键问题。

## 核心方法

### 方法参照系

标准 RL 训练流程中，模型生成完整轨迹后仅基于最终答案正确性计算奖励，缺乏对中间步骤的细粒度监督。本文问题的关键在于长链推理中工具调用位置的不确定性，标准流程无法定位哪些中间步骤的工具调用真正贡献了答案正确性，导致信用分配模糊。

### 熵基分叉点选择与轨迹生成

针对工具调用位置难以确定的问题，DART 引入基于策略熵的分叉点选择机制。在 rollout 树构建过程中，模型首先并行生成 M 条初始轨迹，随后迭代 N 次进行扩展。每次扩展时，系统计算轨迹中每个位置的策略熵 $H(t) = -\sum_{v \in V} \pi_\theta(v | q, y_{<t}) \log \pi_\theta(v | q, y_{<t})$，选取熵值最高的前 K 个位置作为候选分叉点。这一设计动机在于高熵位置代表模型决策的不确定性，更可能通过工具调用获得确定性提升。在选定位置 $t^*$ 后，系统从提示集合 $\{h\}$ 中采样一个工具提示 $h^*$，拼接至前缀 $y_{<t^*}$ 后，模型生成 Python 代码片段 $c$，外部沙箱执行代码并返回反馈 $o_c$，模型继续生成直至结束。该机制通过自举方式生成工具集成轨迹，避免了人工标注成本，同时保留了模型原生推理分布。

### 树状优势估计与策略优化

为解决长序列中工具调用贡献难以量化的问题，DART 提出基于 rollout 树的蒙特卡洛优势估计。对于树中每个节点 $s$，其价值 $r(s)$ 通过其所有叶子节点的后代平均值计算：$r(s_{non}) = \frac{1}{|\text{Leaves}(s_{non})|} \sum_{s \in \text{Leaves}(s_{non})} r(s)$。节点 $s$ 的优势值定义为 $A(s) = (r(s) - r(s_{root})) + (r(s) - r(p_s))$，其中 $r(s_{root})$ 为全局平均正确率，$r(p_s)$ 为父节点价值。全局优势项衡量该子轨迹相对于整体表现的优越性，局部优势项衡量其相对于父节点的增量贡献。当工具调用子轨迹成功得出正确答案而自然语言兄弟节点失败时，该子轨迹获得显著正优势。策略优化采用无 KL 惩罚的 Reinforce 目标，损失函数为 $\mathcal{J}(\theta) = \mathbb{E}_{q, \{S\} \sim \pi_{\theta_{old}}(\cdot|q)} \left[ \sum_{i=1}^{M \times (N+1)} \frac{1}{|S_i|} \sum_{j=1}^{|S_i|} \frac{\pi_\theta(S_{i,j} | q, S_{i,<j})}{\pi_{\theta_{old}}(S_{i,j} | q, S_{i,<j})} A_{i,j} \right]$，其中解释器反馈输出被掩码以稳定训练。该设计使模型能够精确定位并强化那些真正提升解题成功率的具体工具调用行为。

## 实验评估

实验在 AIME24、AIME25 和 GPQA-Diamond 基准上进行，使用 Qwen3-4B-Thinking-2507 作为测试模型。基线覆盖直接 RL（DAPO、ToRL、UTIR）、SFT-then-RL（ReTool）和拒绝采样 SFT（START）三类方法，但缺失纯提示工程基线及 THOR 等长链 TIR 方法。

| 方法 | AIME24 Pass@1 | AIME24 Pass@8 | AIME25 Pass@1 | AIME25 Pass@8 | GPQA-D Pass@1 | GPQA-D Pass@8 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| DART | 70.56 | 88.16 | 61.67 | 80.57 | 64.34 | 80.94 |

DART 在 AIME24 上以 70.56% 的 Pass@1 显著优于纯文本长链基线 Text-DAPO，验证了工具集成对计算瓶颈的缓解作用。消融实验显示，默认设置（M=2, N=3, K=6）下生成 8 条 rollout 轨迹，扩大树规模至 M=3, N=4 可进一步提升通过率，但边际收益递减。随机分叉点选择导致性能显著下降，证实熵基选择对定位有效工具调用位置的关键作用。

评估指标仅包含 Pass@1 和 Pass@8，未报告置信区间或计算效率指标。训练使用 8 块 GPU 和 VeRL 框架，最大响应长度 16,384 tokens，采样温度 1.0。代码未开源，但训练数据筛选过程（DAPO 数据集准确率低于 60% 的 2,795 个样本）和超参数设置详细披露，具备一定可复现性。

## 关联研究分析

从问题动机看，DART 与 ToRL 和 UTIR 均旨在通过 RL 激励工具使用，但 ToRL 和 UTIR 聚焦短思维链，其奖励机制仅基于最终答案，无法处理长链中工具调用位置的稀疏性。DART 通过树状结构将长链分解为子轨迹，实现了从“结果监督”到“过程监督”的转变，这一差异源于长链推理中工具调用对答案正确性的贡献具有局部性，全局奖励无法捕捉这种细粒度因果关系。

从方法设计看，DART 与 START 均使用工具提示引导轨迹生成，但 START 采用离线拒绝采样，依赖 LLM 完成长链后筛选正确样本进行 SFT，存在分布偏移风险。DART 采用在线 RL 自举，在训练过程中动态生成并强化工具轨迹，避免了离线数据与模型当前策略的分布不匹配。然而，DART 未讨论工具调用后模型内部推理状态的忠实性变化，即工具反馈是否掩盖了模型自身的逻辑错误，这一盲区在长链推理审计中可能构成潜在风险。

## 总结

DART 解决了长思维链推理中工具调用行为融入的分布偏移难题，其切入点在于利用 rollout 树的树状结构实现细粒度信用分配，这是标准 RL 流程无法做到的。该方法通过熵基分叉点选择和树状优势估计，在无标注数据条件下实现了工具调用与长链推理的有机融合。实验表明，DART 在 AIME24 上达到 70.56% 的 Pass@1，显著优于纯文本基线。然而，其评估仅覆盖数学与科学任务，且未验证工具调用对推理忠实性的影响。当模型在工具调用后生成看似正确的推理步骤时，这些步骤是否真实反映了内部计算过程，还是仅为对工具输出的事后合理化，论文未给出回答。
