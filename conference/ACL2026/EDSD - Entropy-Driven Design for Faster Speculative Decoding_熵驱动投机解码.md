# ACL2026最新论文 ｜EDSD: Entropy-Driven Design for Faster Speculative Decoding ｜熵驱动投机解码

作者：Longkai Cheng、Ximing Wang、Jiangcai Zhu 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_1e85dba13ee5)

> 投机解码旨在通过草稿模型并行生成候选 token 以突破大语言模型自回归解码的内存带宽瓶颈，但现有特征对齐方法面临训练开销激增与推理时特征分布偏移的双重困境。EDSD 指出目标模型输出熵是预测 token 拒绝率的关键信号，却未被用于指导草稿模型的架构与训练。该框架利用熵信号协同设计层选择、特征融合与训练调度，在保持无损性的前提下提升训练效率与鲁棒性。其价值在于提供了可解释的优化路径，但加速比提升幅度有限，且未解决多模态场景下的通用性问题。

## 研究背景

大语言模型推理在低并发下受限于内存带宽，投机解码通过引入轻量级草稿模型并行预测候选 token，再由目标模型单次并行验证，将串行解码转化为并行验证。这一范式要求草稿模型生成的 token 分布与目标模型高度对齐，核心指标为接受长度 $\tau$，即每个草稿-验证周期中平均被接受的 token 数量，它直接决定了加速比的上限。

早期研究聚焦于独立草稿模型与目标模型的分布对齐，但受限于接受率上限。当特征对齐技术引入后，EAGLE 系列利用目标模型隐藏状态作为草稿输入，显著提升了接受率，但随之而来的是训练与推理阶段的特征不一致问题：训练时草稿模型依赖目标模型的真实隐藏状态，而推理时只能依赖自身生成的状态，导致长序列或提示词变化时性能急剧下降。HASS 和 GRIFFIN 分别通过多步前向传播和 token 反馈缓解此问题，但进一步增加了训练复杂度。EDSD 的切入点在于，现有方法将熵仅用于推理时的过滤或门控，而忽视了其作为训练信号对草稿模型架构与学习策略的潜在指导作用。

## 核心方法

### 方法参照系

EDSD 属于特征对齐路线下的草稿模型训练优化。标准流程如 EAGLE-3，固定提取目标模型倒数第二层隐藏状态，通过全连接层降维后与 token 嵌入拼接，使用交叉熵损失训练。本文的关键差异在于，不再固定层选择与全量 token 训练，而是引入熵分析动态决定“学什么”和“怎么学”，以解决训练-推理信息不一致导致的鲁棒性下降。

### 熵驱动架构设计

针对特征级表示在训练与解码阶段的错配，EDSD 提出优先依赖 token 级信号。在训练前，利用小校准集计算目标模型各层隐藏状态的矩阵熵 $M_1(Z)$，选择熵值最低（即谱结构最紧凑、信息最集中）的两层作为特征源。

$$
M_1(Z) = -\sum_{i=1}^{r} \frac{\lambda_i(K)}{\text{tr}(K)} \log \frac{\lambda_i(K)}{\text{tr}(K)}
$$

其中 $K=ZZ^\top$ 为 Gram 矩阵，$\lambda_i$ 为特征值。该公式量化了层表示的信息容量，低熵层意味着特征更稳定，更适合支持 token 级预测。随后，通过 EDFuse 模块将选层特征与 token 嵌入融合，采用门控线性单元增强 token 信号权重，使草稿模型在解码时更依赖自身生成的 token 而非易漂移的特征，从而提升对提示词变化的鲁棒性。

### 熵驱动训练策略

针对高熵 token 更易被拒绝的现象，EDSD 实施“由易到难”的学习方案。在训练第 $t$ 个 epoch，根据目标模型输出熵对 token 排序，掩码比例 $p_t$ 随 epoch 动态调整：

$$
p_t = \max\left(0, \frac{T-t}{T-1}\right) \times \gamma
$$

其中 $T$ 为总 epoch 数，$\gamma$ 为超参数。该公式确保训练初期仅暴露低熵（确定性高）的 token，后期逐步引入高熵（不确定性高）的 token。同时，动态调整预测步长 $n$，使训练时的预测视野与解码时的实际长度对齐。这种调度避免了模型过早拟合困难样本，减少了训练与推理间的分布差距，从而在相同 epoch 下以更少的 GPU 小时数达到更高的接受率。

## 实验评估

实验在 Llama-3、Qwen3 等七个 LLM 上进行，覆盖 MT-Bench、GSM8K 等五个任务，基线包括 EAGLE-2/3、HASS、GRIFFIN 等特征对齐方法，但未对比 PARD、CORAL 等最新 SOTA 及无训练方法。

| 模型 | 方法 | SR (x) | $\tau$ |
| :--- | :--- | :--- | :--- |
| L31-8B | EAGLE-3 | 3.57 | 6.24 |
| L31-8B | EDSD | 3.75 | 6.52 |
| DSL-8B | EAGLE-3 | 3.34 | 5.82 |
| DSL-8B | EDSD | 3.54 | 6.14 |

EDSD 在所有模型上均取得最高 SR 和 $\tau$，平均接受长度较 EAGLE-3 提升 4.3%。消融实验显示，移除 Step-n 或 Mask-p 任一组件均导致性能下降，完整 EDTrain 将训练时间从 80.0 降至 64.1 GPU 小时，效率提升 24.8%。鲁棒性测试表明，在系统提示词变化下，EDSD 的 $\tau$ 降幅仅为 EAGLE-3 的 1/5，验证了 token 级优先设计的有效性。

评估边界方面，论文未报告置信区间，且主要基于单 GPU 微基准与 600 实例集群的宏观延迟，缺乏对边缘设备或异构硬件的测试。代码已开源，但超参数 $\gamma$ 的敏感性分析未在正文中详细展开，复现时需依赖附录或自行调参。

## 关联研究分析

从问题动机看，EDSD 与 HASS 均针对训练-推理特征不一致，但 HASS 通过递归多步前向传播强行对齐特征，代价是训练计算量倍增；EDSD 则通过熵调度降低困难样本权重，以“少而精”的训练换取鲁棒性。这种差异源于对“对齐”定义的不同：HASS 追求特征空间的严格匹配，EDSD 追求 token 预测分布的稳定性。EDSD 在 MoE 模型上加速比低于稠密模型，暗示其熵信号在专家路由场景下的有效性可能受限，这是任务特性决定的盲区。

从方法设计看，EDSD 与 GRIFFIN 同属特征对齐路线，GRIFFIN 通过反馈草稿模型自身预测来缓解 token 级错配，而 EDSD 通过架构融合增强 token 信号权重。两者在 $\tau$ 上接近，但 EDSD 训练效率更高。然而，EDSD 未探索更深的草稿模型架构，其单层 Transformer 限制可能在复杂推理任务上成为瓶颈。相比之下，CORAL 等最新方法在特定基准上加速比更高，EDSD 的 4.1% 提升在绝对值上较小，其价值更多体现在训练成本与鲁棒性的权衡上，而非单纯的峰值性能。

## 总结

EDSD 旨在解决特征对齐草稿模型中训练开销激增与推理鲁棒性不足的核心矛盾。其切入点在于发现目标模型输出熵是预测 token 拒绝率的可靠信号，并据此协同优化架构与训练。通过熵驱动层选择、特征融合及由易到难训练调度，EDSD 在七个 LLM 上将训练效率提升 24.8%，平均接受长度提升 4.0%。其边界在于加速比提升幅度有限，且未深入探索 MoE 专家路由下的熵信号有效性及多模态场景的通用性。当草稿模型扩展至多层架构时，熵驱动的层选择策略是否仍能保持对 token 级信号的优先权重，论文未给出回答。
