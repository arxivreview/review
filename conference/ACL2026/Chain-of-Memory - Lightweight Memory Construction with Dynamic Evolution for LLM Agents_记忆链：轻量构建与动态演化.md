# ACL2026最新论文 ｜Chain-of-Memory: Lightweight Memory Construction with Dynamic Evolution for LLM Agents ｜记忆链：轻量构建与动态演化

研究机构：中科院计算所、中国科学院大学

作者：Xiucheng Xu、Bingbing Xu、Xueyun Tian 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.14287)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.14287)

> 长时程智能体记忆面临构建开销与推理效用的双重瓶颈。现有结构化记忆方案以高计算成本换取有限精度提升，而朴素检索拼接又无法将召回转化为准确答案。本文提出CoM框架，通过扁平索引降低构建成本，并在推理时动态组织记忆片段为连贯推理链。该范式在效率-精度权衡上取得突破，但其精度上限是否受限于非结构化存储，仍需在高复杂度多跳任务中验证。

## 研究背景

当智能体处理跨越数月的对话历史时，固定上下文窗口导致关键状态丢失。为维持长时程一致性，外部记忆系统成为必要组件，其核心挑战在于如何以最低计算开销实现高保真检索与推理。传统检索增强生成（RAG）将记忆片段直接拼接至提示词，但这一做法忽略了片段间的逻辑依赖，导致模型无法执行多跳推理。

主流记忆架构路线倾向于在构建阶段引入复杂结构，如知识图谱或层级树，以显式捕捉语义关联。然而，实证观察表明，这类结构化构建带来的精度增益与其高昂的Token消耗和延迟不成比例。与此同时，即使检索成功，朴素拼接仍无法弥合召回与准确回答之间的鸿沟。CoM的切入点在于解耦构建与利用：将计算资源从预构建复杂结构转移至推理时的动态组织，通过轻量级存储与自适应链演化机制，在保持低延迟的同时提升推理连贯性。

## 核心方法

### 方法参照系

CoM置于记忆架构设计路线中，但偏离了主流的结构化预构建范式。与Mem0或A-Mem等依赖增量事实压缩或动态笔记链接的方法不同，CoM采用扁平索引存储原始对话轮次，将复杂逻辑关系的构建延迟至检索后的推理阶段。这一差异的核心在于：CoM假设预构建结构的边际收益低于其计算成本，转而通过推理时的动态链接实现等效的语义组织。

### 动态记忆链演化

在检索阶段，CoM将对话历史分解为原子记忆节点 $m_i = (x_i, \tau_i, \rho_i, \mathbf{e}_i)$，其中 $x_i$ 为文本内容，$\tau_i$ 为时间戳，$\rho_i$ 为角色，$\mathbf{e}_i$ 为嵌入向量。通过余弦相似度检索Top-K节点形成候选池 $P$。动态记忆链演化（DMCE）机制从 $P$ 中选取Top-L节点作为锚点，初始化L条记忆链。在每一步扩展中，计算候选节点 $m$ 的门控得分：

$$S_{gate}(m) = \text{GlobalRelevance}(m, q) \times \text{ContextualConsistency}(m, C_z^{(t)})$$

该公式通过乘法耦合全局查询相关性与局部上下文一致性，确保新节点既符合用户意图，又与当前推理路径逻辑连贯。最大得分节点被追加至链中，直至触发截断条件。

### 自适应路径截断

为防止链扩展陷入语义漂移，CoM引入自适应路径截断（APT）机制。设 $s_{t-1}$ 为前一步追加节点的门控得分，$s_t^*$ 为当前步候选节点的最大得分。若满足：

$$s_t^* < \beta \cdot s_{t-1}$$

则终止该链的扩展。此条件识别语义相关性的“悬崖式”下降，表明进一步扩展将引入噪声而非有效信息。通过动态剪枝，APT确保最终输入模型的上下文仅包含高置信度的推理路径，避免关键信号被冗余信息稀释。

## 实验评估

实验在LongMemEval-S（500 QA对，平均115k tokens）和LoCoMo（1986 QA实例，平均26k tokens）上进行，基线覆盖Full-Context、Naive RAG、LangMem、A-Mem及Mem0。CoM在Qwen3-32B骨干下于LongMemEval取得76.40%总准确率，超越最强基线15.8%；在LoCoMo上取得72.86%（GPT-4o-mini），领先最佳基线14%。效率方面，CoM仅消耗8.8k tokens（Qwen3-32B）和2002秒运行时，远低于A-Mem的331.8k tokens和32949秒。

| 方法 | LongMemEval Total Acc (%) | LoCoMo Total Acc (%) | Token (k) | Time (s) |
|---|---|---|---|---|
| CoM (Qwen3-32B) | 76.40 | 70.97 | 8.8 | 2002 |
| A-Mem (Qwen3-32B) | 53.20 | 60.84 | 331.8 | 32949 |
| Mem0 (Qwen3-32B) | 50.60 | 63.51 | 156.0 | 19721 |
| RAG (turn) (Qwen3-32B) | 66.00 | 61.88 | 27.3 | 1598 |

消融实验显示，移除DMCE导致准确率从76.40%降至66.00%，验证了动态链演化对推理连贯性的关键作用。移除APT则使准确率降至72.75%，同时Token消耗增加，表明截断机制在提升精度的同时有效控制了计算开销。移除整个框架后，准确率骤降至55.20%，Token消耗激增至119.56k，证实了轻量构建与动态利用协同的必要性。

评估协议采用LLM-as-Judge衡量语义对齐，优于F1或BLEU等表面指标。局限在于未报告置信区间，且基线未包含2026年最新结构化SOTA如Mandol或MAGMA。代码未公开，超参数 $\beta$ 和 $k$ 的敏感性分析有限，可复现性依赖特定嵌入模型（Qwen3Embedding-8B）和骨干网络配置。

## 关联研究分析

从方法设计看，CoM与Mandol代表记忆架构的两极。Mandol采用结构化语义图与Token约束定量检索，在LoCoMo上取得89.48%的高精度，但隐含高构建开销。CoM则证明扁平索引配合动态链演化可在8.8k tokens内达到70.97%精度，其优势源于将计算资源集中于推理时的逻辑组织而非预构建。这一差异的根源在于任务特性：CoM针对的是检索后推理瓶颈，而Mandol针对的是检索精度瓶颈。在极高复杂度多跳任务中，动态链是否会出现性能瓶颈，论文未给出回答。

从问题动机看，CoM与Mem0共享“轻量构建”理念，但Mem0依赖增量事实压缩与图扩展，其检索后利用仍为朴素拼接。CoM的核心创新在于引入DMCE机制，将检索片段组织为连贯推理路径，直接回应了“召回不等于准确”的失效模式。Mem0在LongMemEval上仅取得50.60%精度，而CoM达到76.40%，表明动态链演化对弥合检索-推理鸿沟具有决定性作用。这一改进是否可泛化至非文本模态，论文未探索。

## 总结

CoM解决的核心矛盾是记忆构建开销与推理效用之间的失衡。现有结构化方法以高成本换取有限精度提升，而朴素检索拼接无法实现多跳推理。CoM通过扁平索引降低构建成本，并在推理时通过DMCE和APT动态组织记忆片段为连贯推理路径，在Qwen3-32B骨干下于LongMemEval取得76.40%精度，同时仅消耗8.8k tokens。其边界在于依赖嵌入模型的语义相关性捕捉能力，且自适应截断可能丢弃长推理路径中的细微细节。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
