作者：Wei Tian、Yuhao Zhou、Man Lan

论文原文见 [arXiv](https://arxiv.org/abs/2606.00020)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.00020)

> 中文语法纠错（CGEC）的核心矛盾在于生成式模型强大的语言重构能力与最小编辑原则之间的冲突，导致模型在纠正错误时往往伴随不必要的改写。现有基于监督微调（SFT）的方法受限于最大似然估计（MLE）目标，无法有效区分“必要修正”与“过度纠正”，致使性能在 F0.5 45-46 区间停滞。本文提出 CSRP 框架，通过持续预训练（CPT）、思维链（CoT）蒸馏与效率感知强化学习（RL）三阶段课程学习，显式优化编辑决策边界。该框架在 4B 参数规模下刷新了 NACGEC 基准的 SOTA，但其奖励机制对长尾实体及多语言场景的泛化能力尚存疑。

## 研究背景

当大语言模型（LLM）介入中文语法纠错时，其预训练语料中的规范性文本分布与学习者错误分布存在显著差异，这种知识稀疏性导致模型难以精准识别同音字误用或功能词冗余等细微偏差。更关键的是，SFT 阶段的 MLE 目标驱使模型将输入向内部高概率区域偏移，表现为对正确或轻微偏差句子的过度改写，即过度纠正偏差。这一偏差直接违背了纠错任务保真度优先的核心要求，使得模型在追求流畅度的同时牺牲了语义忠实性。

主流解决路径分为两类：一是依赖检索增强生成（RAG）注入外部知识以弥补模型盲区，但引入了推理延迟；二是通过判别式模型或序列到序列架构处理长距离依赖，但缺乏对编辑最小性的显式约束。现有 LLM 基线如 ChineseErrorCorrector3-4B（CEC3）虽提升了生成质量，但仍受困于 MLE 导致的假阳性率高问题，无法在精度与召回率间取得符合 F0.5 指标偏好的平衡。CSRP 的切入点在于将纠错过程解耦为知识内化、诊断推理与策略对齐三个正交阶段，通过强化学习直接优化“编辑与否”的决策边界，而非单纯追求生成似然。

## 核心方法

### 方法参照系

标准 LLM 纠错流程通常采用 SFT 直接映射错误句到正确句，其核心假设是模型能从成对数据中隐式学习编辑规则。本文问题与该通用流程的关键差异在于，SFT 无法区分“修正错误”与“改写正确部分”，导致模型在低错误密度输入上产生系统性过度纠正，需引入显式的编辑效率约束机制。

### 效率感知奖励建模

针对 MLE 目标无法惩罚多余编辑的失效，CSRP 在 RL 阶段引入效率感知奖励（EAR），将 Levenshtein 距离转化为相对改进与编辑效率比。该设计动机在于将抽象的最小编辑原则转化为可微分的优化信号，使模型在奖励最大化过程中自发抑制对正确文本的干预。

$$
RI = \frac{d(S, G) - d(P, G)}{d(S, G) + \epsilon}, \quad \eta = \frac{d(S, P)}{d(S, G) + \epsilon}
$$

其中 $RI$ 衡量预测 $P$ 相对于源句 $S$ 向金标准 $G$ 的接近程度，$\eta$ 惩罚相对于改进幅度的过度编辑量。高 $\eta$ 值对应“外科手术式”精准修正，低值则触发惩罚。

### 基于 GRPO 的策略对齐

在 EAR 信号基础上，CSRP 采用组相对策略优化（GRPO）算法，通过对比同一提示下的 $N$ 个候选输出，动态校准决策边界。该机制解决了传统 PPO 中价值函数估计不准的问题，使模型能基于组内相对奖励差异，优先选择编辑效率最高的修正路径。

$$
\mathcal{L}_{GRPO} = -\mathbb{E}_{S \sim \mathcal{D}, \{P_i\} \sim \pi_{old}} \left[ \frac{1}{N} \sum_{i=1}^N \left( \frac{\pi_{new}(P_i|S)}{\pi_{old}(P_i|S)} \frac{R_i - \bar{R}}{\sigma_R} - \beta D_{KL}(\pi_{new} || \pi_{ref}) \right) \right]
$$

该公式通过标准化组内奖励 $R_i$，消除了绝对分数波动的影响，使模型专注于识别“哪些编辑真正降低了错误距离”，从而在保持召回率稳定的同时显著提升精度。

## 实验评估

| 模型 | NACGEC P | NACGEC R | NACGEC F0.5 | CSCD F1 |
| :--- | :--- | :--- | :--- | :--- |
| BART | 34.67 | 41.88 | 35.91 | - |
| HW-CGEC | 50.95 | 32.29 | 45.26 | - |
| ScholarGEC (14B) | 45.08 | 59.33 | 47.35 | - |
| CEC3 (4B) | 54.20 | 34.75 | 48.74 | - |
| GPT-4 | - | - | - | 54.41 |
| **CSRP (4B)** | **57.17** | 35.60 | **50.99** | **59.61** |

CSRP 在 NACGEC 上以 50.99 的 F0.5 超越 CEC3（48.74）和 ScholarGEC（47.35），其精度优势（57.17 vs 54.20）证实了 EAR 对过度纠正的抑制效果。在 CSCD 拼写纠正任务上，CSRP 的 59.61 F1 较 GPT-4 提升 5.20 点，表明该框架在字符级纠错中同样有效。基线覆盖涵盖判别式（BERT）、Seq2Seq（BART）及 LLM（GPT-4, CEC3），但缺失 RAG 类方法（如 RACQC）及多语言基准，限制了跨范式对比的全面性。

| 配置 | NACGEC F0.5 | CSCD F1 | P 变化 | R 变化 |
| :--- | :--- | :--- | :--- | :--- |
| SFT only | 40.21 | 49.71 | - | - |
| CPT + SFT | 45.45 | 56.28 | - | - |
| CPT + SFT + GRPO | 50.99 | 59.61 | +8.44 | -0.20 |

消融实验显示，CPT 阶段贡献了 +5.24 F0.5 的基础性能提升，而 GRPO 阶段在相同数据量下额外带来 +3.78 F0.5 增益。关键发现是 RL 阶段对精度的提升（+8.44）远大于召回率的损失（-0.20），证实了 EAR 机制实现了“选择性编辑”而非“保守化抑制”。CoT 蒸馏贡献了 +2.81 F0.5，其中在复杂多跨度编辑样本上召回率从 24.5% 提升至 31.2%，验证了诊断推理对长距离依赖的处理能力。

评估协议采用 ChERRANT 评分器，F0.5 指标强调精度以惩罚过度纠正，符合母语者纠错场景需求。代码已开源，但论文未报告 GRPO 训练的计算成本细节，仅提及 $N=8$ 候选生成带来的开销。可复现性受限于教师模型 Qwen-Plus 的 API 依赖及安全过滤策略，可能导致 CoT 数据分布偏差。

## 关联研究分析

从问题动机看，CSRP 与 EARM 同属 RL 对齐路线，但二者在奖励机制设计上存在根本差异。EARM 采用编辑感知奖励模型，通过神经网络学习细粒度的质量区分信号；而 CSRP 依赖基于 Levenshtein 距离的启发式公式。这种差异源于任务特性的不同：EARM 可能更适应复杂语义重构，而 CSRP 的显式距离度量在字符级替换和简单语法错误上更具可解释性。CSRP 在 NACGEC 上 50.99 的 F0.5 低于 EARM 的 61.29，暗示启发式奖励在捕捉深层语义保真度上可能存在局限，但其在 4B 小规模模型上的高效性是其独特优势。

从方法设计看，CSRP 与 RACQC 代表了“内部对齐”与“外部约束”两种解决过度纠正的路径。RACQC 通过 RAG 注入外部知识来弥补 LLM 的知识盲区，适用于长尾实体纠错；而 CSRP 通过 CPT 内部化领域知识，避免了推理时的检索延迟。CSRP 在通用语法错误上表现优异，但未验证其在法律、医疗等专业领域长尾实体上的鲁棒性。RAG 路线在缺乏内部知识时更具鲁棒性，而 CSRP 的 CPT 阶段若训练数据覆盖不足，可能导致知识稀疏问题在特定领域重现。

## 总结

CSRP 旨在解决 LLM 在中文语法纠错中因 MLE 目标导致的过度纠正与知识稀疏矛盾。其切入点在于将纠错过程解耦为知识内化、诊断推理与策略对齐三个正交阶段，通过效率感知奖励显式优化编辑决策边界，从而在 4B 参数规模下实现高精度纠错。实验证明，该框架在 NACGEC 上取得 50.99 F0.5 的 SOTA，精度提升 8.44 点而召回率仅损失 0.20 点，验证了 RL 阶段对编辑保守性的有效校准。然而，其启发式奖励机制对复杂语义重构的捕捉能力有限，且在长尾实体及多语言场景下的泛化性能未经验证。当输入文本包含大量领域专有名词或跨语言混合错误时，基于距离的奖励信号是否仍能准确区分必要编辑与过度纠正，论文未给出回答。
