# ACL2026最新论文 ｜Logic Matters in Lightweight Hallucination Classification for RAG System ｜基于图聚类的轻量级多跳幻觉检测

作者：Ningyuan Yang、Kaizhu Huang

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_4d316f09b3ce)

> 检索增强生成（RAG）系统在计算受限场景下，常因证据分散于多个文档而导致轻量级模型无法重建跨文档逻辑链，从而漏检幻觉。现有自然语言推理（NLI）方法依赖单文档独立评估，无法捕捉跨文档的语义连贯性，导致多跳推理场景下的检测失效。本文提出一种基于介数中心性的图结构证据聚合框架，在评分前将分散的语义片段聚类为连贯证据组，使0.5B参数模型在保留独立文档的基准上达到82.4%准确率。该方法在效率与精度间实现了帕累托最优，但其对语义相似性的依赖可能引入无关片段合并的假阳性风险。

## 研究背景

RAG系统通过外部检索缓解大语言模型（LLM）的幻觉问题，但在多跳推理任务中，验证答案所需的逻辑链往往跨越多个不连续的检索段落。当这些段落被独立处理时，自然语言推理（NLI）模型因上下文窗口限制和参数规模约束，无法感知跨文档的证据依赖关系。这种“证据碎片化”导致NLI评分出现歧义：低分可能源于直接矛盾，也可能仅因证据分散，使得轻量级检测器无法区分真实幻觉与检索噪声。

传统幻觉检测路线分为两类：一是基于标注语料微调语言模型，如Lynx和Osiris，但这类方法假设所有证据可装入单一上下文窗口，且依赖大规模领域特定标注数据，难以适配多文档RAG场景；二是应用NLI模型进行事实一致性评分，如TrueTeacher和MiniCheck，虽开销低，但在长上下文或多跳推理任务中性能急剧下降。现有工作如RAGAS和Provenance通过独立评估每个检索文档来缓解长上下文问题，但未能解决跨文档语义聚合的核心难题。本文切入点在于，不依赖任务特定预训练，而是通过图结构显式建模跨文档语义连贯性，在NLI评分前完成证据聚合，从而突破轻量级模型在多跳幻觉检测中的性能瓶颈。

## 核心方法

### 方法参照系

标准NLI幻觉检测流程为：输入检索文档与生成答案，直接计算蕴含概率，阈值判断是否幻觉。本文问题与该通用流程的关键差异在于，多跳场景下证据分散于多个文档，单文档NLI评分无法反映全局逻辑一致性，需在评分前引入跨文档证据聚合机制。

### 语义证据聚合

针对NLI模型无法独立评估跨文档依赖的失效，本文在分段后引入图结构聚合。对每个文本块 $c_i$ 计算嵌入向量 $v_i = E(c_i)$，构建语义相似度图 $G^{(0)}$，其中边集 $E^{(0)} = \{(i, j) \mid d_{ij} \le \alpha \mu\}$，$d_{ij} = \|v_i - v_j\|_2$ 为欧氏距离，$\mu$ 为平均距离，$\alpha=1.0$。随后计算所有节点对最短路径 $P_{ij}$，定义边 $e$ 的介数频率 $f_e = |\{(i, j) : e \in P_{ij}\}|$，并按 $f_e$ 降序合并簇，直至簇内总token数 $\tau(S) \le T_t$。该公式的物理含义是：高介数边作为语义社区间的桥梁，优先合并相关证据簇，从而恢复分散的推理链。这一设计解决了NLI独立评估导致的证据割裂问题，使小模型能感知跨文档逻辑依赖。

### 一致性评分

承接聚合后的证据簇 $D_k$，本文重构答案 $A'$ 并构建假设 $H = \text{"The answer to 'Q' is: } A' \text{"}$。对每个簇计算相关性 $r_k = R(D_k, A')$ 并归一化 $\tilde{r}_k = r_k / \sum_{j=1}^K r_j$，再计算NLI蕴含分 $e_k = \text{NLI}(D_k, H)$，最终得分 $S = \sum_{k=1}^K \tilde{r}_k \cdot e_k$。若 $S > T_s$ 则判定为非幻觉。该公式将多簇证据的NLI评分加权聚合，权重由相关性决定，避免了单文档评分的局部性偏差。这一设计使框架具备NLI无关性，可替换任意NLI模型而不需重新训练，提升了部署灵活性。

## 实验评估

实验在HotPotQA-Derived、RAGTruth、HaluBench和HaluEval四个基准上进行，基线覆盖NLI类（TrueTeacher, MiniCheck）和LLM类（GPT-4o），但缺失迭代检索类基线。Config A（0.5B参数）在HotPotQA-Derived上达到82.4%准确率，较所有sub-1B基线提升超30%；Config B（1.5B参数）达到85.6%，超越11B TrueTeacher且体积小7倍、速度快1.7倍。

| 配置 | 参数量 | HotPotQA-Derived Acc (%) | 延迟 (ms) |
| :--- | :--- | :--- | :--- |
| Config A | ≈0.5B | 82.4 | 85 |
| Config B | ≈1.5B | 85.6 | — |

消融实验显示，移除事实句分类器 $f(c)$ 导致准确率下降4.2%（从82.4%降至78.2%），表明过滤非事实句对图构建质量至关重要。六个NLI判别器实验显示，图聚合带来+6.7%至+29.9%的一致增益，验证了聚合模块是主要性能驱动因素，而非特定NLI模型。

评估边界方面，HotPotQA-Derived仅包含双跳问题，未覆盖三跳及以上复杂推理；RAGTruth中Data-to-Text子集性能较低，因结构化表格与自由文本的语义相似度图不匹配。可复现性上，论文提供超参数（$T_a=T_d=512, T_t=1024, T_s=0.4$）和硬件配置（RTX 4060/4090），但未公开代码仓库，且未报告置信区间。

## 关联研究分析

从问题动机看，本文与GRASP等图结构检索方法存在根本差异：GRASP在生成前通过K-hop ego-graph增强检索召回，而本文在生成后通过介数中心性聚合证据以验证一致性。前者优化输入侧的证据覆盖，后者优化输出侧的逻辑验证，两者可串联使用但解决不同阶段的失效。本文未探索动态图更新机制，当检索结果流式到达时，静态图构建是否仍能保持聚合质量，论文未给出回答。

从方法设计看，本文与TrueTeacher等NLI方法共享一致性检查框架，但引入了图聚类作为前置模块。TrueTeacher依赖单文档NLI评分，本文通过介数中心性合并语义连贯片段，解决了跨文档依赖问题。然而，本文的图构建基于语义相似度而非逻辑依赖，可能将语义相似但逻辑无关的片段错误合并，导致假阳性。这种设计选择牺牲了逻辑精确性以换取计算效率，在噪声环境下是否仍具鲁棒性，需进一步验证。

## 总结

本文要解决的核心矛盾是轻量级模型在多跳RAG场景中因证据碎片化导致的幻觉漏检。现有NLI方法因单文档独立评估无法捕捉跨文档逻辑依赖，而微调方法依赖大规模标注且假设单一上下文窗口。本文抓住的切入点是，通过图结构显式建模语义连贯性，在NLI评分前完成证据聚合，使0.5B参数模型能处理多跳推理。具体做法是构建语义相似度图，利用介数中心性合并相关片段，再对聚合簇进行加权NLI评分。实验证明，该方法在HotPotQA-Derived上达到82.4%准确率，较sub-1B基线提升超30%，且比TrueTeacher快3.3倍、参数少22倍。本文的边界在于，图构建基于语义相似度而非逻辑依赖，可能引入无关片段合并的假阳性；且基准仅覆盖双跳问题，未验证三跳及以上复杂推理。当检索文档数量增加至十篇以上时，介数中心性计算的复杂度是否成为瓶颈，论文未给出回答。
