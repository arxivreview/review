# ACL2026最新论文 ｜Compressing then Matching: An Efficient Pre-training Paradigm for Multimodal Embedding ｜压缩-匹配解耦：多模态嵌入的高效预训练范式

研究机构：中国科学院、中国科学院大学

作者：Da Li、Yuxiao Luo、Keping Bi 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.08480)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.08480)

> 多模态嵌入模型需同时保留输入的全局语义与突出下游任务所需的判别特征，但现有基于大规模对比学习的方法将这两个目标耦合在同一优化过程中，导致对高质量配对数据的强依赖。CoMa 指出这种耦合是低效的根源，提出通过“压缩预训练”与“对比学习”两阶段解耦：前者利用问答任务迫使模型将图像信息压缩至少量 Token 中，后者仅针对匹配特征进行微调。该策略将预训练数据量降低至同类方法的 10%，在 MMEB-V1 基准上以 Qwen2.5-VL-7B 骨干取得 72.2 的 Overall Score，但其对压缩 Token 数量的敏感性及对自动合成数据质量的依赖尚存疑。

## 研究背景

多模态嵌入的核心挑战在于表征的双重性：既要像通用理解模型一样覆盖输入中的细粒度语义，又要像检索模型一样对特定任务特征敏感。传统双编码器（如 CLIP）通过独立编码后对齐，虽实现了全局语义匹配，却丢失了局部组件间的细粒度对应关系，导致在视觉定位等任务上表现受限。多模态大语言模型（MLLMs）通过交错序列处理，天然具备捕捉细粒度语义的能力，但其自回归生成目标与嵌入任务的匹配目标存在范式鸿沟，直接应用对比学习需海量数据才能弥合这一差距。

现有将 MLLM 转化为嵌入模型的路线主要依赖数据规模或架构改造。VLM2Vec 和 GME 通过引入大规模合成或真实配对数据，利用对比学习同时优化信息覆盖与特征区分，但数据成本高昂。MoCa 尝试通过双向注意力和掩码重建任务改善预训练，但仍需 300 亿 Token 的预训练数据。UniME 则依赖外部文本嵌入模型进行知识蒸馏，引入了额外的教师模型依赖。这些方法的共同瓶颈在于：它们假设对比学习能同时高效优化“信息覆盖”和“区分特征”两个目标，而实际上这两个目标在优化方向上存在冲突，导致数据效率低下。CoMa 的切入点在于将这两个目标在时间维度上解耦，先通过压缩任务确保信息覆盖，再通过对比学习优化区分特征，从而大幅降低对数据量的依赖。

## 核心方法

### 方法参照系

本文问题属于“MLLM 向嵌入模型转化”范畴，标准流程为：MLLM 骨干 + 大规模对比学习。关键差异在于，CoMa 在对比学习前插入一个基于问答的压缩预训练阶段，将“信息覆盖”从对比学习中剥离，作为独立的预训练目标。

### 基于问答的压缩预训练

在标准 SFT 流程中，模型直接基于完整输入生成答案。CoMa 在此环节引入信息瓶颈：在图像输入后插入 $K$ 个可学习压缩 Token $C = [C_1, ..., C_K]$，并修改因果注意力掩码，强制对话部分（问题 $Q$ 与答案 $A$）仅依赖压缩 Token，而非原始图像。其优化目标为最大化从压缩 Token 恢复对话信息的似然：

$$
\mathcal{L}_{comp} = -\sum_{t} \log P(A_t | C, Q, A_{<t})
$$

这一设计迫使 MLLM 在有限的 $K$ 个 Token 中编码足以回答多样问题的图像信息，从而在预训练阶段实现“全面信息覆盖”。相比 MoCa 的掩码重建，该机制直接利用生成式任务的灵活性，无需设计复杂的去噪目标，且对答案准确性的要求低于 SFT，更侧重问题的多样性。

### 注意力掩码引导的信息隔离

压缩预训练的关键在于确保压缩 Token 不“作弊”地直接访问原始图像细节。CoMa 通过修改注意力矩阵实现信息隔离：在计算对话部分的隐藏状态时，屏蔽其与图像输入段之间的注意力连接，仅保留与压缩 Token 的连接。具体而言，设序列为 $[I, C, Q \oplus A]$，则注意力掩码 $M$ 满足 $M_{(Q \oplus A), I} = 0$，而 $M_{(Q \oplus A), C} = 1$。这种硬约束确保了压缩 Token 必须成为图像信息的唯一载体，从而在后续对比学习阶段，提取压缩 Token 的均值池化作为嵌入表示时，该表示已内化了全面的图像语义，仅需微调即可聚焦于匹配特征。

## 实验评估

CoMa 在 MMEB-V1 基准（36 个子集，涵盖分类、VQA、检索、定位）上评估，指标为 Precision@1。基线覆盖 CLIP、VLM2Vec、MoCa、UniME 等主流路线，但缺乏纯文本嵌入基线。

| 模型 | 参数量 | Overall Score |
| :--- | :--- | :--- |
| MoCa (Qwen2.5-VL) | 7B | 71.5 |
| VLM2Vec (Qwen2-VL) | 7B | 69.8 |
| CoMa (Qwen2.5-VL) | 7B | 72.2 |

CoMa (7B) 以 72.2 的 Overall Score 超越 MoCa (7B) 的 71.5，且仅使用 MoCa 10% 的预训练数据量（3 亿 vs 300 亿 Token）。

| 预训练格式 | 损失函数 | Avg Score |
| :--- | :--- | :--- |
| Multi Turn | CE | 65.5 |
| Single Turn | CE | 64.8 |
| Caption | CE | 65.2 |
| Multi Turn | KL | 64.4 |

消融实验显示，多轮对话格式优于单轮（65.5 vs 64.8），因为多问题迫使模型在压缩时平衡不同维度的信息，避免过度聚焦单一细节。使用 KL 损失替代交叉熵导致性能下降（64.4），表明生成式任务的精确性对压缩质量至关重要。

评估边界方面，MMEB-V1 的 OOD 子集仅占 16 个，且未报告置信区间，数值比较需谨慎。CoMa 依赖 Qwen2.5-VL-7B 生成预训练数据，其性能上限受限于教师模型的能力。代码已开源，但 GPU 需求仅为 MoCa 的四分之一，可复现性较高。

## 关联研究分析

从问题动机看，CoMa 与 MoCa 均旨在解决 MLLM 生成目标与嵌入匹配目标的范式鸿沟，但 MoCa 通过架构改造（双向注意力）和复杂的重建任务（MLM/MAE）来增强表征，本质上仍是在单一阶段内同时优化覆盖与区分。CoMa 则通过任务解耦，将覆盖问题前置到预训练阶段，利用生成式任务的天然监督信号，避免了 MoCa 中重建任务与匹配目标之间的潜在冲突。这种解耦是否在所有模态组合中均有效，尤其是当图像信息极度稀疏时，论文未给出回答。

从方法设计看，CoMa 与 UniME 均引入预训练阶段，但 UniME 依赖外部教师模型进行蒸馏，引入了知识迁移的偏差风险。CoMa 采用自生成数据策略，利用 MLLM 自身能力生成问答对，消除了教师依赖，但引入了数据合成的循环偏差风险。CoMa 的压缩 Token 数量（32）是固定超参数，未随图像分辨率动态调整，这与知识库中关于“视觉 Token 压缩应自适应”的共识存在差异。固定 Token 数在高分辨率图像上可能导致信息瓶颈过紧，而在低分辨率图像上则可能冗余，这一设计选择对 OOD 泛化能力的影响尚不明确。

## 总结

CoMa 针对 MLLM 嵌入转化中“信息覆盖”与“特征区分”目标耦合导致的数据低效问题，提出通过压缩预训练解耦这两个目标。其核心在于利用问答任务迫使模型将图像信息压缩至少量 Token，再通过对比学习优化匹配特征。实验证明，该策略在 MMEB-V1 上以 72.2 的 Overall Score 超越 MoCa，且数据量仅为后者的 10%。然而，CoMa 的性能对压缩 Token 数量敏感，超过 32 个后性能下降，且依赖自动合成数据的质量。当图像内容极度复杂或压缩 Token 数量固定时，信息瓶颈是否会导致关键细粒度语义丢失，进而影响视觉定位等细粒度任务的性能，论文未给出回答。
