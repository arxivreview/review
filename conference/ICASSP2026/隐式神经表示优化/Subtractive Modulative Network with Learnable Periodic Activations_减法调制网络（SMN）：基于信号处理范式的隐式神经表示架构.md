# ICASSP2026最新论文 ｜Subtractive Modulative Network with Learnable Periodic Activations ｜减法调制网络（SMN）：基于信号处理范式的隐式神经表示架构

研究机构：瑞典皇家理工学院、瑞士洛桑联邦理工学院

作者：Tiou Wang、Zhuoqian Yang、Markus Flierl 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.16337)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.16337)

> 隐式神经表示（INR）旨在以紧凑权重实现分辨率无关的高保真信号重建，但标准多层感知机（MLP）固有的频谱偏差导致高频细节拟合困难。现有傅里叶特征与周期性激活方法虽能缓解此问题，却常形成频谱成分纠缠的黑盒模型，缺乏对谐波生成的显式控制。本文借鉴经典音频减法合成原理，提出振荡器-滤波器结构化流水线，通过可学习正弦层生成多频基，并利用乘法掩码模块主动塑形频谱。该架构在2D图像重建中展现出优于主流基线的精度与参数效率，但其对3D场景泛化能力的验证仍显薄弱，且乘法交互的理论优势是否普适尚存疑。

## 研究背景

当INR试图拟合高频信号时，标准MLP的神经切线核（NTK）高频特征值过小，导致梯度下降优先收敛于低频分量，即频谱偏差。这一现象迫使研究者转向输入编码或激活函数修改，如傅里叶特征映射将低维坐标提升至高维空间，或SIREN采用正弦激活函数覆盖高频分量。然而，这些方法多采用加法叠加范式，频谱成分在层间简单累加，网络需学习复杂的抵消机制来消除不需要的谐波，导致参数利用效率低下且缺乏可解释性。

INR领域的核心矛盾在于如何在保持网络紧凑性的同时突破NTK的低频偏好。主流路线分为输入特征映射与周期性激活两类，前者如Fourier Features提供固定基，后者如SIREN和WIRE引入周期性非线性。尽管这些方法在2D图像重建中取得了显著进展，但它们往往将网络视为单一函数逼近器，忽略了信号合成过程中的结构化特性。本文切入点在于引入减法合成概念，将INR重构为多阶段信号处理流水线，通过显式的振荡与滤波过程，实现对频谱成分的主动控制而非被动拟合。

## 核心方法

### 方法参照系

标准INR架构通常由输入编码层、若干隐藏层和输出层组成，各层通过线性变换与非线性激活函数堆叠。本文问题与该通用流程的关键差异在于，传统架构缺乏对频谱生成与塑形的结构化分离，导致高频细节的表示依赖于深层网络的隐式学习，而非显式的信号处理机制。

### 可学习正弦振荡器

振荡器阶段旨在解决固定频率编码缺乏自适应性的问题，其设计动机是允许网络根据信号特性动态调整基频率的权重。该阶段实现为线性层后接可学习周期性激活函数 $\Phi(\cdot)$，对于输入坐标 $\mathbf{x} \in \mathbb{R}^d$，输出为：

$$ \mathbf{z}^{(1)} = \Phi(\mathbf{W}_0 \mathbf{x} + \mathbf{b}_0) = \sum_{i=1}^{K} a_i \sin(\omega_i (\mathbf{W}_0 \mathbf{x} + \mathbf{b}_0)) $$

其中 $\{\omega_i\}_{i=1}^K$ 为固定的多分辨率频率集，$\mathbf{a} = \{a_i\}_{i=1}^K$ 为可学习的标量振幅向量。这一设计通过调整系数 $a_i$ 自适应地混合基频率，相比固定编码提供了更高效的频谱基，仅需增加少量参数即可在2D信号上获得7-9 dB的性能增益。

### 乘法调制滤波器

滤波器阶段的核心创新在于利用乘法交互生成高阶谐波，其设计动机是克服加法合成中频谱成分纠缠导致的低效组合问题。该阶段包含主信号路径与并行掩码路径，关键操作为预测性乘法掩码：

$$ \mathbf{z}^{(l+1)} = \mathbf{z}^{(l)} \odot M^{(l+1)} $$

其中 $\odot$ 表示逐元素乘法，$M^{(l+1)}$ 由前一阶段掩码信号生成。乘法操作在数学上等价于频域卷积，能够隐式生成无限系列的高阶谐波（如 $3\omega, 5\omega, \dots$），为复杂信号表示提供强大的表达力基础。最终通过自掩码放大器（逐元素平方）进一步增强非线性，实现无参数开销的频谱塑形。

## 实验评估

实验在Kodak（24张768×512图像）、DIV2K（24张510×339图像）及NeRF Synthetic（8个场景）上进行，对比基线包括MLP、Gauss、SIREN、WIRE及RINR。基线覆盖周期性激活与傅里叶特征两条主要路线，但缺失Hash Encoding、FINER等近期高频方法，可能低估了与最新SOTA的差距。

| 方法 | Kodak (dB) | DIV2K (dB) | Parameters |
| :--- | :--- | :--- | :--- |
| MLP | 28.63 | 30.21 | 272415 |
| Gauss | 37.90 | 38.34 | 272703 |
| SIREN | 33.65 | 33.73 | 272703 |
| WIRE | 40.24 | 38.90 | 265523 |
| RINR | 32.96 | 34.03 | 289716 |
| **SMN** | **41.40** | **42.53** | 264216 |

SMN在两个2D数据集上均取得最高PSNR，且参数量最少，Kodak上41.40 dB超越WIRE的40.24 dB，DIV2K上42.53 dB领先所有基线。推理FLOPs为208 GFLOPs，显著低于WIRE的835 GFLOPs，验证了参数效率与计算效率的双重优势。

| 消融变体 | Kodak PSNR (dB) | 变化 |
| :--- | :--- | :--- |
| SMN (Full) | 41.40 | - |
| SMN-Add (加法替代乘法) | 40.25 | -1.15 dB |
| Filter Depth=3 | 39.63 | -1.77 dB |
| Filter Depth=4 | 40.76 | -0.64 dB |
| Oscillator K=1 | 42.87 | +1.47 dB* |
| Oscillator K=3 | 43.68 | +2.28 dB* |

*注：振荡器消融在隐藏维度312下测试，与主实验设置不同，数值不可直接比较。*

消融实验表明，乘法交互对性能至关重要，替换为加法导致1.15 dB的性能下降。滤波器深度存在最优平衡点，两层设计最佳，三层因梯度消失问题性能骤降，四层仅部分恢复。振荡器消融显示可学习振幅比固定振幅提升显著，且基数量K=3优于K=1，但需注意该消融在隐藏维度312下进行，与主实验的256维度不同，直接比较需谨慎。

评估指标仅包含PSNR与参数量，缺乏训练时间、收敛速度等计算效率维度的系统报告。代码已公开，但论文未提供不同初始化策略下的鲁棒性测试，也未报告置信区间，数值比较的统计显著性存疑。NeRF任务中所有模型均集成标准位置编码，隔离了核心架构贡献，但3D场景下的泛化能力验证仍显不足。

## 关联研究分析

从方法设计看，SMN与SIREN和WIRE同属周期性激活路线，但关键差异在于频谱合成机制。SIREN和WIRE采用加法叠加，频谱成分在层间累加，网络需隐式学习抵消不需要的谐波；SMN引入乘法掩码，通过频域卷积显式生成高阶谐波，实现了从“被动拟合”到“主动塑形”的范式转变。这一差异的根源在于信号处理原理的引入：减法合成中滤波器通过乘法抑制不需要的频率，而加法合成中网络需学习复杂的抵消模式。SMN的乘法机制是否在所有信号类型上均优于加法，论文仅通过1.15 dB的消融差距提供有限证据，未探讨其在低频主导信号或噪声敏感场景下的表现。

从问题动机看，SMN与Fourier Features同属输入编码优化路线，但目标不同。Fourier Features旨在通过高维映射重塑NTK频谱，解决频谱偏差问题；SMN旨在通过结构化流水线提升频谱控制的显式性与效率。SMN将固定傅里叶基改造为可学习振幅混合，解决了固定编码缺乏自适应性的问题，但其振荡器设计仍依赖预定义的多分辨率频率集，未探索频率基的完全可学习性。与FINER等可变周期激活方法相比，SMN的振荡器仅调整振幅而非频率，其频率适应性是否足够应对复杂频谱结构，论文未给出回答。

## 总结

SMN旨在解决INR中频谱成分纠缠导致的参数低效与可解释性缺失问题，其切入点在于引入减法合成原理，将网络重构为振荡器-滤波器结构化流水线。通过可学习正弦层生成自适应多频基，并利用乘法掩码模块主动生成高阶谐波，SMN在Kodak和DIV2K上分别取得41.40 dB和42.53 dB的PSNR，超越WIRE等强基线，且参数量最少。然而，论文在3D NeRF任务中仅取得32.98 dB，低于领域SOTA，且振荡器消融在隐藏维度312下进行，与主实验设置不一致，限制了结论的普适性。当滤波器深度超过两层时性能显著下降，表明乘法交互在深层网络中的优化稳定性仍存挑战，这一局限是否源于梯度传播特性或架构设计本身，论文未提供深入分析。
