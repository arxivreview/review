# ICASSP2026最新论文 ｜SIE3D: Single-image Expressive 3D Avatar generation via Semantic Embedding and Perceptual Expression Loss ｜单图语义可控3D头像生成

研究机构：日本早稻田大学

作者：Zhiqi Huang、Dulongkai Cui、Jinglu Hu

论文原文见 [arXiv](https://arxiv.org/abs/2509.24004)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.24004)

> 单图重建3D头像面临身份保真与语义编辑的二元对立困境，现有方法往往顾此失彼。SIE3D通过解耦的身份与语义嵌入机制，结合感知表情损失，首次实现了基于自然语言的细粒度表情控制。该方法在保持身份一致性的同时，显著提升了生成结果的真实感与中性姿态稳定性。其价值在于弥合了图像重建与文本生成的语义鸿沟，但身份分数的轻微下降暗示了语义引导对几何结构的潜在干扰。

## 研究背景

单图3D头像重建的核心难点在于从二维像素推断三维几何，这一过程本质上是高度欠定的。传统参数化模型如FLAME提供了稳定的拓扑结构，但难以捕捉复杂纹理；神经辐射场（NeRF）虽能表达细节，却缺乏实时渲染能力。3D高斯泼溅（3DGS）凭借显式表示实现了实时渲染，成为当前主流底座，但其优化过程依赖外部先验来填补单视角的信息缺失。

现有研究呈现明显的路线分裂：以Arc2Avatar为代表的图像到3D方法擅长身份保持，但表情控制依赖抽象的混合形状参数，缺乏语义直观性；以HeadSculpt为代表的文本到3D方法具备强大的语义生成能力，却无法锚定特定人物的身份特征。这种“身份-语义”的二元对立导致现有方案难以同时满足高保真重建与直觉化编辑的需求。SIE3D的切入点在于打破这一僵局，通过多模态条件机制将图像的身份特征与文本的语义特征解耦融合，旨在构建一个既能忠实还原人物外貌，又能通过自然语言指令灵活调整表情与配饰的统一框架。

## 核心方法

### 基于ISM的3DGS优化参照系

SIE3D建立在Arc2Avatar的优化框架之上，利用2D扩散模型引导3DGS参数优化。与标准分数蒸馏采样（SDS）不同，该方法采用区间分数匹配（ISM）损失，通过比较不同噪声水平下的去噪预测差异，提供更稳定的梯度信号。其核心在于将ArcFace提取的身份嵌入与视角嵌入线性插值，形成条件向量 $c_d$，引导UNet生成多视角一致的图像特征，从而约束3D高斯椭球的位置与外观。

### 分层语义嵌入机制

为解决Arc2Avatar缺乏语义控制的问题，SIE3D引入了分层嵌入组合策略。该机制将身份嵌入 $c_{default}$ 作为基底，分别与表情和配饰的文本嵌入进行线性插值，生成独立的表情嵌入 $c_{expr}$ 和配饰嵌入 $c_{acc}$。

$$ c_{final} = (1-\eta_{acc}) \cdot c_{expr} + \eta_{acc} \cdot c_{acc} $$

其中 $\eta_{acc}$ 为强度参数。这种层级结构允许用户通过自然语言独立控制表情强度与配饰存在性，实现了语义属性的解耦。设计动机在于避免单一条件向量中身份与语义特征的相互干扰，确保在改变表情时不破坏底层身份结构。

### 感知表情正则化损失

仅靠嵌入引导无法保证生成表情的语义准确性，SIE3D引入了基于DeepFace的感知表情损失。在每次迭代中，渲染正面视图并输入预训练的表情分类器，获取预测概率分布 $P_{pred}$。

$$ L_{emotion} = - \sum_{i=1}^{k} P_{target}^{(i)} \log(P_{pred}^{(i)}) $$

该损失函数通过交叉熵惩罚预测分布与目标表情（One-hot向量）的偏差。其物理含义是将语义空间的约束直接映射到优化目标中，弥补了SDS损失在语义对齐上的不足，确保生成的3D头像在视觉上符合文本描述的表情状态。

## 实验评估

实验在Celebrity Face数据集上进行，所有图像统一为512x512分辨率，在单张NVIDIA RTX 4090 GPU上优化5000次迭代，耗时约70分钟。基线选择涵盖Arc2Avatar、Wonder3D和SF3D，均为图像到3D方法，未包含文本到3D基线，这符合论文聚焦“身份保持+语义编辑”复合任务的定位。

| 方法 | FID↓ | ID↑ | NPS↓ |
| :--- | :--- | :--- | :--- |
| Wonder3D | 274.10 | 0.2603 | 0.4621 |
| SF3D | 290.89 | 0.3187 | 2.9998 |
| Arc2Avatar | 237.81 | 0.4459 | 3.5884 |
| SIE3D | 227.11 | 0.3672 | 0.3667 |

SIE3D在FID（227.11）和NPS（0.3667）上均取得最优，表明其生成结果更真实且中性姿态更稳定。然而，其ID分数（0.3672）低于Arc2Avatar（0.4459），显示语义引导在一定程度上牺牲了身份保真度。

| 消融配置 | FID↓ | ID↑ | NPS↓ |
| :--- | :--- | :--- | :--- |
| Full Model | 227.11 | 0.3672 | 0.3667 |
| w/o Semantic Embedding | 238.43 | 0.3977 | 3.1178 |
| w/o Perceptual Loss | 321.68 | 0.2539 | 3.8043 |

消融实验揭示，移除感知表情损失导致FID飙升至321.68，ID降至0.2539，证明该损失对维持生成质量至关重要。移除语义嵌入虽使ID微升至0.3977，但NPS恶化至3.1178，证实了语义控制与身份保持之间存在权衡，且感知损失是稳定性的关键锚点。

评估协议主要依赖FID、ID和自定义的NPS指标，缺乏对动态表情序列或极端姿态的测试。代码未明确开源，仅提供了项目页面，限制了复现性。单GPU 70分钟的优化时间虽可接受，但相较于前馈式方法仍显缓慢，限制了大规模应用潜力。

## 关联研究分析

从问题动机看，SIE3D与Dream3DAvatar同属多模态引导重建，但前者聚焦头部语义编辑，后者侧重全身几何补全。Dream3DAvatar利用SDXL生成多视角图像以解决遮挡问题，而SIE3D直接通过嵌入融合控制表情，避免了多视角生成带来的几何不一致风险。这种差异源于任务特性：头部拓扑简单，适合直接语义约束；全身结构复杂，需依赖几何先验补全。

从方法设计看，SIE3D与Arc2Avatar共享ISM优化框架，但SIE3D引入了DeepFace作为语义正则器。Arc2Avatar依赖FLAME混合形状进行非语义控制，而SIE3D通过分类器反馈实现语义对齐。这一改进解决了Arc2Avatar中用户需手动调节抽象参数的问题，但引入了对预训练分类器依赖的新风险。若DeepFace的表情分类边界与3D渲染的视觉特征存在域差距，可能导致优化陷入局部最优，论文未对此进行敏感性分析。

## 总结

SIE3D旨在解决单图3D头像重建中身份保真与语义编辑不可兼得的矛盾。通过解耦的身份-语义嵌入与感知表情损失，该方法在保持身份一致性的同时，实现了基于文本的细粒度表情控制。实验显示，SIE3D在FID（227.11）和NPS（0.3667）上优于基线，但ID分数（0.3672）低于Arc2Avatar（0.4459），表明语义引导对身份特征产生了轻微干扰。其边界在于优化式方法的计算开销以及对预训练表情分类器的依赖。当文本描述包含复杂或罕见表情时，DeepFace分类器的泛化能力是否足以支撑准确的3D几何重建，论文未给出回答。
