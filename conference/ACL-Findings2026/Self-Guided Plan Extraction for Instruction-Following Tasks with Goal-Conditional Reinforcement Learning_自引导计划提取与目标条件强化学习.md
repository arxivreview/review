# ACL-Findings2026最新论文 ｜Self-Guided Plan Extraction for Instruction-Following Tasks with Goal-Conditional Reinforcement Learning ｜自引导计划提取与目标条件强化学习

作者：Zoya Volovikova、Nikita Sorokin、Dmitriy Lukashevskiy 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.20601)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.20601)

> 具身智能体在动态开放环境中遵循自然语言指令时，面临长程依赖与稀疏奖励导致的信用分配难题。现有基于演示的方法受限于数据成本，而纯强化学习方法在缺乏预定义技能库时难以将语言指令映射到具体动作。SuperIgor 通过 LLM 与 RL 智能体的迭代共训练，利用 DPO 反馈闭环自动筛选高价值计划，实现了无预定义技能库下的指令遵循。该框架在 CrafText 基准上显著优于纯 RL 基线，但计算成本高昂且与 Oracle 计划仍存在性能差距，其自学习闭环的收敛效率尚待验证。

## 研究背景

具身指令遵循任务要求智能体在部分可观测马尔可夫决策过程（Partially Observable Markov Decision Process, POMDP）中，将自然语言指令映射为潜在目标并执行。传统方法依赖专家演示轨迹，虽泛化性强但数据采集成本极高，且难以扩展至长程任务。另一条路线是经验学习，即通过强化学习直接从环境交互中获取策略，但其在稀疏延迟奖励下难以将语言指令接地到长程行为，且多数研究局限于网格世界等简化环境，缺乏对像素级观测和复杂语言多样性的支持。

现有基于规划的方法通常假设存在预定义的有限子目标集合，通过启发式匹配将生成的子目标接地到技能库，从而提供密集中间奖励。这种设计虽降低了探索难度，但严重依赖预定义技能库，限制了在开放环境中的适用性。此外，许多规划系统依赖超大语言模型（100B+ 参数），进一步限制了实用性。SuperIgor 的切入点在于解决“如何在无预定义低层技能的环境中，学习低层策略以遵循指令”。它通过 LLM 生成结构化计划，并利用 RL 智能体的执行反馈迭代优化计划质量，形成自学习闭环，从而摆脱对预定义技能库的依赖。

## 核心方法

### 方法参照系

本文问题属于“复杂指令遵循机制”类别，但与传统文本指令微调不同，其执行载体为物理动作而非文本生成。通用流程为“指令解析-计划生成-策略执行”，关键差异在于本文去除了预定义技能库，要求策略从稀疏奖励中直接学习子任务对齐，且计划生成与策略执行通过 DPO 反馈闭环耦合。

### 本体论计划生成与动态课程学习

传统规划方法依赖预定义子目标，导致在开放环境中无法处理未见过的任务组合。SuperIgor 引入本体论（Ontology）计划生成，将指令分解为子任务基础、目标级计划、子任务本体论和计划扩展四个步骤。本体论编码了子任务间的前置依赖关系，确保生成的计划变体在逻辑上一致。为应对稀疏奖励，引入技能课程学习（Skill Curriculum Learning），其核心公式为：

$$
SR(s) = \frac{\# \text{Successful episodes containing } s}{\# \text{Total episodes containing } s}
$$

当某子任务 $s$ 的成功率 $SR(s)$ 超过阈值 $\tau$ 时，该子任务被标记为“已掌握”，课程动态扩展至包含已掌握子任务和至多一个未掌握子任务的计划。这一设计解决了纯 RL 在长程任务中因奖励稀疏导致的策略崩溃问题，通过渐进式难度提升平滑了学习梯度。

### 基于 DPO 的计划质量筛选与迭代共训练

传统方法中，计划生成与策略执行是解耦的，计划质量无法通过执行反馈优化。SuperIgor 将计划选择建模为偏好优化问题，利用 RL 智能体的执行成功率作为偏好信号，通过直接偏好优化（Direct Preference Optimization, DPO）微调 LLM。DPO 损失函数为：

$$
\mathcal{L}_{\text{DPO}}(\theta) = -\mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)} \right) \right]
$$

其中 $y_w$ 和 $y_l$ 分别为高成功率和低成功率的计划。这一机制使 LLM 内部化智能体的执行反馈，逐步提升计划生成的质量。与静态计划生成不同，迭代共训练允许 LLM 和 RL 智能体相互适应，形成自动化课程，优先选择智能体早期可学习的计划结构，而非显式标记错误计划。

## 实验评估

实验在 CrafText 基准的 FOCUS 子集上进行，包含 900 余条指令，分为 Atomic（单目标）和 Combo（多目标组合）两类。基线包括 PPO-T（文本增强 PPO）、PPO-T+（计划增强 PPO）、FiLM（特征调制）和 Oracle（人工计划）。SuperIgor 在 Atomic 任务上达到 0.34–0.44 的成功率，显著高于纯 RL 基线的 0.10–0.19，但低于 Oracle 的 0.56–0.65。在 Combo 任务上，SuperIgor 达到 0.21，优于基线的 0.08，但 Oracle 达到 0.43。

| 方法 | Atomic SR | Combo SR | New Objects SR | Paraphrases SR |
|---|---|---|---|---|
| SuperIgor (SI-DPO) | 0.34–0.44 | 0.21 | 0.17 | 0.17 |
| Oracle | 0.56–0.65 | 0.43 | — | — |
| PPO-T | 0.10–0.19 | 0.08 | — | — |

消融实验显示，移除 DPO 后，即使延长训练至 15B 步，成功率仅从 0.26 提升至 0.32，表明单纯扩展策略计算无法弥补固定计划的局限性。DPO 的引入使 Combo 任务成功率从 0.30 提升至 0.36，New Objects 任务从 0.11 提升至 0.17，验证了计划质量筛选对泛化能力的贡献。

评估边界方面，FOCUS 数据集虽包含 1500 余词汇，但任务类型仍限于 CrafText 的成就场景，未覆盖更复杂的物理交互。代码已公开，但 2.5B 步的训练成本限制了可复现性。指标仅关注成功率，未量化计划生成的计算开销或 LLM 微调的收敛速度。

## 关联研究分析

从问题动机看，SuperIgor 与 SayCan 均采用规划-执行分离架构，但 SayCan 依赖预定义技能库和离线强化学习评估可行性，而 SuperIgor 通过 DPO 反馈闭环动态筛选计划，无需预定义技能。这一差异源于任务特性：SayCan 面向机器人操作，技能库可预先构建；SuperIgor 面向开放环境，技能库不可预知。从方法设计看，SuperIgor 与 LSRIF（逻辑结构化强化学习）均处理多约束指令，但 LSRIF 依赖静态结构化数据集和复杂奖励函数，而 SuperIgor 通过迭代共训练动态生成计划，避免了人工标注成本。LSRIF 的奖励函数设计需针对具体约束类型定制，而 SuperIgor 的 DPO 机制更通用，但计算成本更高。

## 总结

SuperIgor 解决了无预定义技能库下具身智能体遵循复杂指令的难题，通过 LLM 与 RL 智能体的迭代共训练，利用 DPO 反馈闭环自动优化计划质量。在 CrafText 基准上，其 Atomic 任务成功率达 0.34–0.44，Combo 任务达 0.21，显著优于纯 RL 基线，但低于 Oracle 计划。该框架的边界在于高计算成本（2.5B 步训练）和与 Oracle 的性能差距，后者可能源于计划质量或策略学习效率。当迭代共训练的计算开销降低时，自学习闭环能否在保持泛化能力的同时缩小与 Oracle 的差距，论文未给出回答。
