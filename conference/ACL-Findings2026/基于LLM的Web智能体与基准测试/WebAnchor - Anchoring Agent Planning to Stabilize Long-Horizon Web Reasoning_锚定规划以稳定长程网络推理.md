# ACL-Findings2026最新论文 ｜WebAnchor: Anchoring Agent Planning to Stabilize Long-Horizon Web Reasoning ｜锚定规划以稳定长程网络推理

作者：Xinmiao Yu、Liwen Zhang、Xiaocheng Feng 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_d9ccb4a8a33a)

> 长程网络信息检索任务中，智能体常因早期规划失误导致后续轨迹级联失败，现有强化学习算法因均匀分配奖励而忽视首步决策的结构性影响。本文识别出“计划锚点”现象，即首步推理对全局成功率的非对称支配作用，并据此提出两阶段强化学习框架 Anchor-GRPO。该框架通过从自博弈经验中迭代学习规划评分标准，将密集奖励聚焦于首步规划优化，再以稀疏奖励对齐执行轨迹。这一设计在 GAIA 基准上实现了 76.4% 的 Pass@1，但其在无外部记忆依赖下的长程一致性仍存疑。

## 研究背景

长程网络推理任务要求智能体在动态环境中交替执行思考、行动与观察，这一过程遵循 ReAct 范式。然而，随着任务步骤增加，上下文窗口中的信息冗余与噪声累积导致状态漂移，智能体易陷入重复循环或丢失早期关键约束。更关键的是，这种漂移并非均匀分布，而是高度依赖于初始决策的质量。若首步规划未能正确分解任务或选择工具，后续所有步骤将在错误方向上消耗算力，形成不可逆的级联失败。

当前主流强化学习方法如 GRPO 将奖励信号均匀分配至全轨迹，假设每一步对最终结果的贡献等价。这种假设在短程任务中成立，但在长程网络检索中失效，因为首步规划实际上构成了整个轨迹的“结构锚点”，决定了探索路径、工具调用策略及证据整合逻辑。现有方法缺乏对首步决策的显式优化机制，导致智能体在复杂任务中表现不稳定。本文切入点在于打破奖励均匀分配假设，将规划与执行解耦，通过专门针对首步的密集奖励机制，从源头稳定长程推理轨迹。

## 核心方法

### 方法参照系

本文基于标准 ReAct 智能体架构，其核心差异在于将端到端强化学习拆分为两阶段：第一阶段优化初始规划，第二阶段优化执行轨迹。传统 GRPO 在全轨迹上应用稀疏奖励，而本文通过掩码机制隔离首步更新，并引入从经验中学习的评分标准作为密集奖励信号。

### 计划锚点与评分标准学习

设计动机在于解决全轨迹稀疏奖励无法区分首步规划质量与执行细节的问题。Plan Rubrics Learner 从历史轨迹中提取规划洞察，通过 LLM 迭代优化评分标准 $R(p)$。该标准在 $m$ 个维度（如任务分解、目标对齐）上评估规划 $p$，公式为：

$$ R_{plan} = \frac{1}{Z} \sum_{j=1}^{m} \phi_j(p) $$

其中 $\phi_j(p)$ 为维度 $d_j$ 的 LLM 评分，$Z$ 为归一化常数。此密集奖励仅作用于首步，通过掩码确保后续步骤梯度为零，从而将优化焦点锁定在规划质量上。

### 两阶段解耦优化

承接首步规划优化，第二阶段执行器在稀疏奖励下对齐初始计划。执行奖励 $R_{exec}$ 仅在轨迹末端根据答案精确匹配赋值，中间步骤奖励为零。两阶段联合训练通过掩码信用分配实现：规划更新使用密集评分标准，执行更新使用稀疏任务完成奖励。这种解耦避免了执行噪声干扰规划学习，同时确保执行轨迹与高质量规划保持一致，解决了长程任务中信用分配模糊的问题。

## 实验评估

实验在 BrowseComp、GAIA、XBench 等四个基准上进行，基线包括 GRPO、First-step GRPO 及 WebSailor 系列模型。主结果显示，WebAnchor-30B 在 GAIA 上取得 76.4% Pass@1，显著优于 WebSailor-32B 的 53.2% 和 OpenAI-o3 的 70.5%。在 BrowseComp 上，WebAnchor-30B 达到 46.0% Pass@1，超过基线 GRPO 的 42.0%。

| 模型 | 算法 | GAIA Pass@1 | BrowseComp Pass@1 | XBench Pass@1 |
| :--- | :--- | :--- | :--- | :--- |
| WebAnchor-30B | Anchor-GRPO | 76.4 | 46.0 | 75.1 |
| WebAnchor-30B | GRPO | 75.8 | 44.0 | 71.0 |
| WebAnchor-30B | First-step GRPO | 74.8 | 43.3 | 72.0 |
| WebSailor-32B | - | 53.2 | 10.5 | 53.3 |

消融实验表明，两阶段训练优于仅优化规划阶段（Stage-1-only），后者 Pass@1 为 42.0%，而完整方法为 46.0%。首步优化显著优于随机步或末步优化，First-step GRPO 的 Pass@1 为 43.3%，远高于 Random Step 的 33.0%。密集评分标准奖励优于朴素计划奖励（44.2%）和终端奖励（43.3%），验证了结构化反馈的价值。

评估边界方面，实验依赖虚拟 Wiki 环境而非真实网络，可能低估动态噪声影响。代码未公开，但提供了 HuggingFace 模型链接。指标仅关注 Pass@1/3，缺乏对中间推理步骤质量的细粒度评估，且未报告计算效率指标。

## 关联研究分析

从问题动机看，本文与 WebDART 同属规划优化路线，但 WebDART 侧重动态分解与重规划，而本文聚焦首步锚定。WebDART 通过模块化子任务处理环境变化，适合高复杂度任务，但计算开销大；本文通过静态首步优化降低长程不确定性，更适合信息检索类任务。差异根源在于任务特性：网络检索强调证据整合的连贯性，首步错误难以通过后续重规划完全弥补，而导航类任务更依赖动态适应。

从方法设计看，本文与 WebCoach 在记忆机制上存在根本分歧。WebCoach 引入外部记忆存储以支持跨会话学习，而本文完全依赖上下文窗口，未显式引入记忆模块。这一选择可能源于信息检索任务的单次交互特性，但论文未验证 64k 上下文是否足以覆盖所有长程依赖。当任务步骤超过上下文窗口时，本文方法是否会出现性能退化，缺乏实验支撑。

## 总结

本文核心矛盾在于长程网络推理中首步规划对全局稳定性的非对称影响，现有 RL 方法因奖励均匀分配而忽视此点。本文通过 Plan Rubrics Learner 从经验中学习评分标准，将密集奖励聚焦于首步，再以稀疏奖励对齐执行，实现了规划与执行的解耦优化。实验证明 WebAnchor-30B 在 GAIA 上达到 76.4% Pass@1，验证了首步锚定的有效性。然而，方法依赖虚拟环境且无外部记忆，当真实网络动态噪声加剧或任务步骤超出上下文窗口时，首步锚定的稳定性是否仍能维持，论文未给出回答。
