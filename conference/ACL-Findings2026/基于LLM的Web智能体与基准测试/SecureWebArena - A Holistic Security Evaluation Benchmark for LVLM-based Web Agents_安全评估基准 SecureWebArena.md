> LVLM Web智能体在开放网络中面临多源攻击，但现有基准仅孤立评估用户指令或单一环境威胁，缺乏统一框架。本文切入点在于构建覆盖用户级与环境级双重威胁的全景评估体系，通过多层诊断协议定位失效根源。其价值在于揭示了模型特化与安全鲁棒性间的权衡，但模拟环境与真实网络的迁移有效性仍存疑。

## 研究背景

当智能体处理敏感数据时，其决策函数 $M(G, o_t, H_{t-1})$ 同时暴露于用户指令 $G$ 与环境观测 $o_t$ 两个输入通道。用户级攻击通过操纵 $G$ 诱导违规，而环境级攻击则通过篡改 $o_t$ 中的视觉或文本元素实施欺骗。这种双源威胁结构要求评估体系必须同时覆盖语义理解与多模态感知两个层面，而非仅关注单一通道的鲁棒性。

Web智能体安全评估长期存在碎片化问题。BrowserART 和 SafeArena 聚焦于恶意用户指令，WASP 仅针对网页内的提示注入，而企业合规基准则局限于特定策略场景。这些工作将用户威胁与环境威胁割裂，导致无法捕捉跨通道协同攻击的完整风险图谱。更关键的是，现有指标多依赖端到端成功率，无法区分智能体是“认知上未识别威胁”还是“执行中失控”，掩盖了内部推理与行为轨迹间的因果断裂。

SecureWebArena 针对这一空白，建立了首个整合双源威胁模型的全景基准。其核心贡献不仅是扩展攻击向量至六类，更在于引入多层评估协议，将安全失效解构为内部推理、行为轨迹与任务结果三个独立维度。这种设计使得研究者能够诊断智能体在哪个决策环节被攻破，从而为防御机制提供精确的优化靶点。

## 核心方法

### 威胁模型与攻击分类

本文基于 Set-of-Marks (SoM) 范式建模智能体，将攻击面严格限定在 $G$ 与 $o_t$ 两个输入节点。用户级攻击包括直接提示注入（DP Injection）与越狱（Jailbreak），前者通过追加对抗子句覆盖原始意图，后者利用优化技术绕过安全对齐。环境级攻击则针对 $o_t$ 的视觉与文本组件：弹窗攻击（Pop-up Attack）注入显著模态覆盖层，干扰攻击（Distract Attack）引入视觉噪声模糊语义边界，广告注入（Ad Injection）伪装合法UI诱导误点，间接提示注入（IP Injection）则在页面结构 $L_t$ 中嵌入恶意文本。这种分类确保了攻击的隔离性，使每个向量能独立评估特定感知或推理通道的脆弱性。

### 多层评估协议

传统安全评估仅关注最终状态，无法区分“侥幸成功”与“真正安全”。本文提出三层二元指标，对每个任务 $i$ 定义：

$$
RVR = \frac{1}{N} \sum_{i=1}^{N} r_i, \quad BCR = \frac{1}{N} \sum_{i=1}^{N} b_i, \quad PDR = \frac{1}{N} \sum_{i=1}^{N} d_i
$$

其中 $r_i=1$ 表示初始推理轨迹 $c_{[1][i]}$ 合规于攻击（由 GPT-4o 自动判定），$b_i=1$ 表示轨迹 $\tau_{[i]}$ 中出现不安全行为（由人工专家标注），$d_i=1$ 表示最终状态达成攻击目标（由环境日志确定）。该协议的关键在于解耦认知、执行与结果：高 RVR 低 PDR 表明智能体在推理阶段被误导但执行中自我纠正；高 BCR 低 PDR 则揭示执行失控但结果未造成实质损害。这种细粒度诊断能力是单一成功率指标无法提供的。

## 实验评估

实验在 6 个模拟环境（Wikipedia, Shopping, GitLab 等）上进行，覆盖 9 个 LVLM 智能体，包括通用型（GPT-5, Gemini 2.5 Pro）、Agent 专用型（GLM-4.5V, Seed-1.5-VL）与 GUI 接地型（UI-TARS-1.5, Aguvis）。基线选择覆盖了当前主流模型类别，但缺乏基于沙箱或权限控制的系统级防御基线，导致无法评估模型内生安全与外部防御的协同效应。

| 模型类别 | 代表模型 | Pop-up Attack PDR (%) | Jailbreak PDR (%) | IP Injection PDR (%) |
| :--- | :--- | :--- | :--- | :--- |
| General-Purpose | GPT-5 | 96.67 | 40.00 | 40.00 |
| Agent-Specialized | GLM-4.5V | 96.67 | 46.67 | 26.67 |
| GUI-Grounded | UI-TARS-1.5 | 66.67 | 63.33 | 36.67 |
| GUI-Grounded | Aguvis | 46.67 | 40.00 | 23.30 |

数据显示，所有模型在 Pop-up Attack 下均表现出极高脆弱性（PDR 46.67%-100%），表明当前 LVLM 普遍缺乏区分合法 UI 与恶意覆盖层的能力。GUI 接地模型在 IP Injection 上表现最佳（Aguvis 23.30%），但在 Ad Injection 上仍高达 76.67%（UI-TARS-1.5），揭示视觉接地并未解决语义欺骗问题。Agent 专用模型 GLM-4.5V 在 IP Injection 上从推理阶段 40% 降至结果阶段 16.67%，显示其具备后期缓解能力，但无法防御视觉攻击。

评估协议存在显著局限。RVR 依赖 GPT-4o 作为裁判，虽与人工标注达成 85.5% 一致率，但 LLM 裁判可能继承被评估模型的偏见。BCR 的人工标注虽达到 Cohen’s $\kappa$ 0.88，但 10% 的双重标注样本量较小，统计稳健性有限。此外，模拟环境基于 WebArena 衍生，其动态性与真实网络存在差距，Live Web 测试仅覆盖 20 个任务，样本量不足以支撑泛化结论。

## 关联研究分析

从威胁模型覆盖度看，SecureWebArena 与 WASP 形成互补。WASP 聚焦于网页内提示注入，属于环境级攻击的子集，而本文将其扩展至视觉层（Pop-up, Ad Inject）并整合用户级攻击，构建了更完整的威胁图谱。这种扩展并非简单叠加，而是揭示了多模态输入下的新失效模式：GUI 接地模型在视觉攻击下反而因“视觉显著性”导致感知失败，这与纯文本模型在语义注入下的失效机制截然不同。WASP 未涉及视觉通道，因此无法捕捉此类跨模态安全漏洞。

从评估粒度看，本文与 ceLLMate 代表两种不同路线。ceLLMate 采用系统级沙箱，通过权限清单硬性阻止未授权操作，属于“外部防御”；而 SecureWebArena 聚焦于模型内生安全的诊断，属于“内部评估”。两者并非竞争关系，而是互补：ceLLMate 提供了安全边界，而本文揭示了边界内模型自身的脆弱点。然而，本文未评估在 ceLLMate 类防御下模型性能的变化，导致无法量化“安全-效用”权衡的具体代价。这种缺失使得本文结论仅适用于无外部防御的场景，限制了其在实际部署中的指导意义。

## 总结

SecureWebArena 解决了 Web 智能体安全评估中威胁碎片化与诊断粗粒度的核心矛盾。其切入点在于建立双源威胁模型与多层评估协议，通过解耦推理、行为与结果，实现了从“是否安全”到“何处失效”的范式转变。实验证明，所有 LVLM 在视觉攻击下普遍脆弱，且模型特化与安全鲁棒性存在显著权衡：GUI 接地提升交互稳定性但未增强威胁感知，Agent 专用优化规划但未解决视觉欺骗。本文的边界在于模拟环境与真实网络的迁移有效性未充分验证，Live Web 测试样本量过小。当攻击向量从模拟环境迁移至真实网络时，视觉显著性偏差是否会被动态内容进一步放大，论文未给出回答。
