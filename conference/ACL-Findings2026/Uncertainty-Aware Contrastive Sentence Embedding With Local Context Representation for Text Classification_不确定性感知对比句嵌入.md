# ACL-Findings2026最新论文 ｜Uncertainty-Aware Contrastive Sentence Embedding With Local Context Representation for Text Classification ｜不确定性感知对比句嵌入

研究机构：深圳大学

作者：Han Liu、Jiaqing Zhan、Zhichao Chen 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_fa8503eb9017)

> 句子嵌入学习旨在将变长文本映射为固定维度稠密向量，以支撑语义相似度评估与信息检索等下游任务，其核心价值在于弥合离散符号与连续语义空间之间的鸿沟。现有基于大语言模型（LLM）的嵌入方法多采用确定性输出，难以区分语义清晰与模糊文本，导致模型在歧义样本上过拟合。本文切入点在于引入不确定性量化机制，通过高斯分布建模表示方差，并结合标签驱动对比学习优化分类几何结构。该方法冻结骨干网络，仅训练轻量级局部上下文提取模块，在文本分类任务上实现了小模型超越大模型的效果，但其对检索任务及生成能力保留的适用性尚存疑。

## 研究背景

当预训练语言模型面对包含局部依赖或语义歧义的文本时，直接提取的句向量往往无法捕捉细粒度的语义差异。这种局限源于确定性嵌入假设，即每个句子对应一个固定的点估计，忽略了文本本身存在的歧义性。为量化这种歧义，需引入数据不确定性学习框架，假设观测到的特征表示是期望特征与输入依赖噪声的叠加，从而将句向量建模为均值与方差的高斯分布。

句子嵌入领域的主流路线正从基于预训练模型的 Token 级对比学习转向利用 LLM 提取高质量语义表示。早期方法如 SimCSE 依赖 Dropout 生成视图，但缺乏对样本质量的区分能力；近期 LLM2Vec 等方法通过修改注意力机制实现双向编码，却常牺牲生成能力。现有方案在提升嵌入判别力时，普遍忽视了文本歧义对表示学习的干扰，导致模型在模糊样本上过度拟合。本文针对这一盲区，提出在冻结 LLM 骨干的前提下，通过不确定性感知机制动态调节样本权重，并结合标签对比学习增强类间分离度，以解决分类任务中歧义样本导致的性能瓶颈。

## 核心方法

### 方法参照系

本文问题属于表征质量优化路线，旨在提升句嵌入在下游任务中的判别力。与标准流程直接池化或微调 LLM 不同，本文的关键差异在于不修改骨干参数，而是插入一个轻量级模块，将确定性的隐藏状态转化为随机向量，并显式建模表示的不确定性。

### 不确定性感知局部上下文提取

标准流程通常直接对 LLM 最后一层隐藏状态进行池化，忽略了局部 Token 依赖及文本歧义。本文在此环节引入 TextCNN 结构，利用不同核大小的滤波器提取多粒度局部特征，并通过重参数化技巧生成随机向量。设计动机在于，确定性池化无法区分语义清晰与模糊的句子，而局部卷积能捕捉邻近 Token 的强依赖关系，为不确定性估计提供更丰富的语义基础。

$$
z_i = \mu_i + \epsilon \odot \sigma_i
$$

该公式通过重参数化技巧生成随机向量 $z_i$，其中 $\mu_i$ 为语义特征均值，$\sigma_i$ 为表示不确定性，$\epsilon$ 为标准正态分布噪声。这一机制使得模型能为歧义样本分配高方差，从而在训练过程中降低其对损失函数的贡献，避免过拟合。

### 标签驱动对比学习与复合优化

传统对比学习依赖数据增强构建正负对，但在分类任务中，显式标签提供了更直接的正样本来源。本文在重参数化后的随机向量上执行标签驱动对比学习（LCL），设计动机在于弥补标准分类损失在几何结构优化上的不足，通过拉近同类样本、推远异类样本，增强类内紧凑性与类间分离度。

$$
\mathcal{L}_{total} = (1-\lambda_{lcl})\mathcal{L}_{softmax} + \lambda_{lcl}\mathcal{L}_{LCL} + \lambda_{kl}\mathcal{L}_{KL}
$$

该复合损失函数平衡了分类准确性、特征判别力与不确定性正则化。其中 $\mathcal{L}_{KL}$ 项约束估计分布向标准高斯收敛，防止随机表示退化为确定性点估计，确保不确定性估计的有效性。

## 实验评估

实验基于 MTEB(eng, v2) 分类子集，涵盖 AmazonCounterfactual、Banking77 等 8 个任务。基线覆盖 Qwen3、Gemma 等开源 LLM 及 OpenAI、Gemini 等商业 API，但缺失 LLM2Vec 等架构修改类基线，限制了与生成能力保留路线的直接对比。

| 方法 | 骨干 | Avg. Acc. |
| :--- | :--- | :--- |
| Gemini Embedding | - | 90.05 |
| Qwen3-Embedding-8B | Qwen3-8B | 90.43 |
| Our Method | embeddinggemma-300m | 92.22 |
| Our Method | Qwen3-Embedding-0.6B | 92.05 |

本文方法在 embeddinggemma-300m 骨干上取得 92.22% 的平均准确率，超越 Gemini Embedding 的 90.05% 及 Qwen3-Embedding-8B 的 90.43%。值得注意的是，优化后的 Qwen3-Embedding-0.6B 达到 92.05%，优于未优化的 4B 和 8B 版本，验证了不确定性感知机制对小模型性能的显著提升。

| 配置 | EOS | Attention | TextCNN |
| :--- | :--- | :--- | :--- |
| Base | 90.47 | 90.60 | 91.45 |
| + UCL | 91.20 | 91.25 | 91.77 |
| + LCL | 91.30 | 91.24 | 91.79 |
| + UCL + LCL | 91.55 | 91.37 | 92.05 |

消融实验显示，TextCNN 提取方式在所有配置下均优于 EOS 和 Attention，表明局部上下文捕获对不确定性估计至关重要。UCL 与 LCL 的结合在 TextCNN 配置下带来最大增益（从 91.45% 至 92.05%），证实了两者在增强嵌入空间几何结构上的互补性。

评估仅聚焦于分类准确率，未报告检索任务性能或生成能力指标。代码已开源，超参数如 $\lambda_{KL}$ 固定为 $1 \times 10^{-3}$，学习率根据骨干调整。由于缺乏检索基准测试，该方法在信息检索场景下的有效性尚未得到验证。

## 关联研究分析

从问题动机看，本文与 3R 方法均关注 Token 级冗余对嵌入质量的干扰，但解决路径截然不同。3R 通过显式消除冗余维度来优化几何结构，而本文通过不确定性量化来抑制歧义样本的影响。这种差异源于任务特性：3R 面向通用语义相似度，需全局优化表示空间；本文面向文本分类，需针对特定类别的歧义进行局部调整。本文未探索冗余消除与不确定性量化的联合优化，二者是否能在同一框架下协同提升性能，论文未给出回答。

从方法设计看，本文与 LLM2Vec 形成“轻量适配”与“架构改造”的路线对比。LLM2Vec 通过修改注意力掩码实现双向编码，可能破坏 LLM 的生成能力；本文冻结骨干，仅训练轻量模块，隐含了生成能力保留的默认前提。然而，本文未评估生成任务性能，无法证明冻结策略在保留生成能力方面的优势。这种设计选择使得本文方法更易于集成到现有 LLM 流水线中，但可能牺牲了通过架构修改获得的全局语义编码能力。

## 总结

本文旨在解决 LLM 嵌入在文本分类任务中因语义歧义导致的过拟合问题。现有确定性嵌入方法无法区分样本清晰度，而本文通过高斯分布建模表示不确定性，并结合标签驱动对比学习，实现了小模型超越大模型的效果。实验表明，优化后的 embeddinggemma-300m 达到 92.22% 准确率，优于 Gemini Embedding 的 90.05%。然而，本文仅评估了分类任务，未涉及检索性能或生成能力保留，且基线缺失架构修改类方法。当支持集增大或任务转向检索时，不确定性量化机制的边际收益是否递减，论文未给出回答。
