# ACL-Findings2026最新论文 ｜StreamMeCo: Long-Term Agent Memory Compression for Efficient Streaming Video Understanding ｜流式智能体记忆压缩

研究机构：上海交通大学、复旦大学

作者：Junxi Wang、Te Sun、Jiayi Zhu 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.09000)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.09000)

> 流式视频理解中，基于智能体记忆图的方法虽能维持长程实体一致性，但记忆节点随视频时长线性增长，导致检索延迟呈非线性上升，无法满足实时交互要求。现有视觉Token或KV Cache压缩策略无法处理外部明文记忆图的结构性冗余。StreamMeCo 提出一种免训练的记忆图压缩框架，通过双分支采样与时间衰减检索机制，在70%压缩率下实现1.87倍检索加速且准确率平均提升1.0%。该工作验证了图结构压缩在工业级流式智能体中的可行性，但其在通用流式基准上的泛化能力及与内部KV Cache管理路线的优劣对比仍存疑。

## 研究背景

流式视频理解要求模型在严格因果约束下处理无限视频流，其核心挑战在于平衡实时响应延迟与长程语义记忆的完整性。M3-Agent 等智能体记忆方法将视频信息抽象为包含文本、人脸、语音节点的图结构，以明文形式存储以维持实体一致性。然而，随着视频时长增加，文本节点数量激增，导致记忆检索时间从秒级迅速攀升至不可接受的量级，成为实时问答的主要瓶颈。

当前流式视频理解的主流路线聚焦于模型内部的视觉Token压缩或KV Cache管理，如 StreamingVLM 采用注意力沉没机制解决上下文断裂。这些方法虽优化了模型内部状态，但难以解决外部智能体记忆图在极端长视频下的存储与检索效率问题。M3-Agent 证明了图结构记忆在实体一致性上的优势，但其原始检索机制在记忆图规模扩大后性能急剧下降。StreamMeCo 的切入点在于，不改变 M3-Agent 的记忆构建范式，而是针对记忆图的结构特性设计专用的压缩与检索算法，以解决工业级长视频场景下的实时性瓶颈。

## 核心方法

### 方法参照系

本文基于 M3-Agent 的记忆图架构，该架构将视频内容映射为包含文本节点（Text Nodes）、人脸节点（Face Nodes）和语音节点（Voice Nodes）的图结构。与标准 KV Cache 压缩不同，本文处理的是外部明文语义图，其节点间存在显式的实体连接关系。关键差异在于，压缩对象从模型内部的连续向量变为离散的语义节点，且需保留节点间的拓扑连接以维持实体一致性。

### 双分支记忆图压缩

针对记忆图中孤立文本节点与连接文本节点的结构差异，本文设计了双分支压缩策略。孤立节点缺乏实体关联，其冗余性主要源于语义相似性；连接节点则承载实体重要性信息。对于孤立节点，采用无边缘极小极大采样（Edge-free Minmax Sampling, EMsampling）模块。首先利用球面 KMeans 算法将 $N_1$ 个孤立节点聚类为 $N_1 \times a$ 个簇，其中 $a$ 为聚类比率。随后，在每个簇内执行极小极大采样：先选取距离簇中心最近的节点加入选中集 $S_j$，然后迭代计算未选中节点到选中集的最小距离，选取距离最远的节点加入 $S_j$，直至满足保留比率 $\alpha$。该策略通过最大化选中节点间的距离，确保保留最具代表性的语义分布。

对于连接节点，采用边缘感知加权剪枝（Edge-aware Weighting Pruning, EWpruning）模块。首先构建实体权重矩阵 $W \in \mathbb{R}^{[M] \times [N_2]}$，其中 $M$ 为人脸与语音节点总数，$N_2$ 为连接文本节点数。通过行求和计算每个文本节点的实体重要性 $W'_{j}$，并归一化至 $[0, 1]$。同时，计算文本节点间的嵌入相似度矩阵 $S$，通过行求和并取反得到嵌入多样性分数 $S'_{j} = 1 - \text{Norm}(\sum_{i} s_{ij})$。最终融合分数定义为：

$$ \text{Score}_j = b \cdot W'_j + (1-b) \cdot S'_j $$

其中 $b$ 为平衡系数，控制实体重要性与嵌入多样性的权衡。保留分数最高的 $N_2 \times \beta$ 个节点，其余节点被剪枝。这一设计解决了单纯基于语义相似度压缩可能丢失关键实体关联的问题，确保压缩后的记忆图仍能有效支持实体一致性推理。

### 时间衰减记忆检索

压缩后的记忆图在检索时可能因信息丢失导致性能下降。为模拟人类记忆衰减机制，本文提出时间衰减记忆检索（Time-decay Memory Retrieval, TMR）机制。将文本节点按时间戳划分为 $t$ 个时间片段 $T_j$。对于查询 $q$，计算每个片段 $T_j$ 的聚合相似度 $E_j = \sum_{i \in T_j} s_{ij}$，其中 $s_{ij}$ 为查询与节点 $i$ 的嵌入相似度。基于平均相似度 $\bar{E}_j = E_j / |T_j|$，应用非线性时间衰减函数：

$$ \text{Decay}_j = \bar{E}_j \cdot e^{-\lambda (t-j)} $$

其中 $\lambda$ 为衰减系数，$t-j$ 为时间距离。根据衰减后的分数动态分配每个片段的检索节点数 $Num_j$，优先从近期片段中检索更多节点。该机制通过自适应平衡长期记忆与近期关键信息，缓解了压缩带来的性能退化，确保在实时交互中优先获取最相关的近期上下文。

## 实验评估

实验在 M3-Bench-robot、M3-Bench-web 和 Video-MME-Long 三个基准上进行，基线包括 Gemini-1.5-Pro、GPT-4o、Qwen2.5-VL-7B 及 M3-Agent 等。值得注意的是，本文未在 OVO-Bench 或 StreamingBench 等通用流式基准上验证，限制了与领域内其他 SOTA 方法（如 VST、ThinkStream）的直接对比。

| 方法 | M3-Bench-robot (Acc %) | M3-Bench-web (Acc %) | 压缩率 |
| :--- | :--- | :--- | :--- |
| M3-Agent (Baseline) | 30.3 (100.0%) | 47.9 (100.0%) | 0% |
| StreamMeCo (↓30%) | 30.7 (101.3%) | 47.0 (98.1%) | 30% |
| StreamMeCo+TMR (↓70%) | 34.2 | 47.9 | 70% |

在 70% 压缩率下，StreamMeCo+TMR 在 M3-Bench-robot 上取得 34.2% 的准确率，显著优于未压缩基线的 30.3%；在 M3-Bench-web 上保持 47.9% 的准确率，与基线持平。消融实验显示，TMR 机制在 70% 压缩下对性能提升贡献最大，若无 TMR，准确率随压缩率增加显著下降。

| 组件组合 | M3-Bench-robot (Acc %) | M3-Bench-web (Acc %) |
| :--- | :--- | :--- |
| Random Compression (↓30%) | 28.5 (94.1%) | 44.6 (93.1%) |
| EMsampling + EWpruning (↓30%) | 30.7 (101.3%) | 47.0 (98.1%) |
| StreamMeCo+TMR (↓30%) | 34.6 | 50.7 |

随机压缩导致显著性能损失，而结构化压缩结合 TMR 在 30% 压缩下即超越基线。评估边界方面，论文未报告 TTFT 或 MaxFPS 等系统级延迟指标，仅关注检索时间加速比。代码已开源，超参数（$a=0.05, b=0.1, \lambda=0.1$）固定，未针对不同视频类型进行自适应调整。

## 关联研究分析

从方法设计看，StreamMeCo 与 HERMES 同属记忆管理路线，但 HERMES 聚焦于模型内部 KV Cache 的分层存储，而 StreamMeCo 针对外部明文记忆图。这一差异源于任务特性：KV Cache 压缩受限于模型上下文窗口，而智能体记忆图用于跨会话的长期实体一致性，后者更依赖语义结构的完整性而非向量维度的压缩。StreamMeCo 的图结构压缩策略在实体一致性任务上可能优于 KV Cache 压缩，但其在细粒度感知任务上的表现尚不明确。

从问题动机看，本文与 StreamingVLM 形成技术路线竞争。StreamingVLM 通过注意力沉没解决无限流输入的上下文断裂，属于模型内部优化；StreamMeCo 则通过外部记忆压缩解决智能体记忆的存储瓶颈，属于系统级优化。两者分别解决了流式视频理解中“模型容量”与“记忆规模”两个不同维度的瓶颈。StreamMeCo 未探索将图结构压缩与 KV Cache 管理结合的可能性，这或许是未来提升长视频理解效率的关键方向。

## 总结

StreamMeCo 旨在解决工业级流式智能体中记忆图规模增长导致的检索延迟瓶颈。其切入点在于利用记忆图的拓扑结构特性，通过双分支压缩与时间衰减检索，在不改变底层智能体架构的前提下实现高效压缩。实验证明，在 70% 压缩率下，该方法实现了 1.87 倍检索加速且准确率平均提升 1.0%。然而，论文仅在专用智能体基准上验证，缺乏在通用流式基准上的泛化性测试，且未报告系统级延迟指标。当记忆图节点数量进一步增加至百万级时，TMR 机制的时间衰减系数 $\lambda$ 是否仍需手动调整，论文未给出回答。
