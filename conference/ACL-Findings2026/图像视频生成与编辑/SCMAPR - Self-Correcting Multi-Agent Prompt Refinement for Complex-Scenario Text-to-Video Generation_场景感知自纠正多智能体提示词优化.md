# ACL-Findings2026最新论文 ｜SCMAPR: Self-Correcting Multi-Agent Prompt Refinement for Complex-Scenario Text-to-Video Generation ｜场景感知自纠正多智能体提示词优化

研究机构：华东师范大学、清华大学

作者：Chengyi Yang、Pengzhen Li、Jiayin Qi 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.05489)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.05489)

> 文本到视频生成在复杂场景下常因提示词模糊导致语义遗漏或时空逻辑断裂，现有检索增强或单次重写方法缺乏对困难源的显式识别与保真校验。SCMAPR 将提示词优化重构为场景路由、策略合成、原子级蕴含验证与条件修正的多智能体流水线。该框架在 VBench 和 EvalCrafter 上分别取得 88.21% 和 66.74 的平均分，显著优于基线，但其性能增益高度依赖底层扩散模型的能力上限，且多智能体推理带来的延迟成本未被量化。

## 研究背景

当用户输入“一只猫在蒸汽朋克图书馆下棋”时，扩散模型往往忽略“蒸汽朋克”这一风格约束或丢失“下棋”的动作细节。这种失效源于提示词中的实体、动作与场景属性在语义空间中相互纠缠，单一 LLM 重写难以同时兼顾所有约束而不引入幻觉。为解决此问题，提示词优化（Prompt Refinement）旨在将简短输入扩展为符合模型偏好的高质量描述，但传统方法多基于表面相似度检索或通用模板，缺乏对视频特有挑战（如时序连贯性、物理因果）的针对性处理。

文本到视频生成领域的主流路线正从追求视觉保真度转向细粒度时空控制。早期方法如 RAPO 通过检索增强丰富提示词，但仅关注对象间关系，忽视了抽象语义与时序一致性等复杂场景下的核心难点。现有基准如 VBench 和 T2V-CompBench 中复杂场景提示词占比分别为 32.9% 和 69.4%，且类别分布严重失衡，导致难以系统评估模型在特定困难源下的表现。SCMAPR 的切入点在于将“复杂场景”形式化为十类具体困难源，并通过结构化验证闭环确保重写后的提示词不偏离用户原始意图，从而弥合外部智能体推理与扩散模型生成能力之间的鸿沟。

## 核心方法

### 方法参照系

提示词优化的标准流程通常包含检索相关描述、LLM 重写及可选的反馈迭代。SCMAPR 的关键差异在于摒弃了基于表面相似度的检索，转而引入基于分类学的场景路由信号，并将语义保真度验证从宏观整体评估下沉至微观原子级蕴含判断，形成“路由-策略-重写-验证-修正”的五阶段闭环。

### 场景路由与策略合成

传统方法直接对输入进行重写，导致策略与具体困难源脱节。SCMAPR 首先通过场景路由器将输入 $P_{user}$ 分类至 11 个预定义标签之一（含 10 类复杂场景与非困难标签），生成路由信号 $\hat{y}$。随后，策略生成器基于 $(P_{user}, \hat{y})$ 合成场景条件化重写策略 $\pi$。该策略明确指定需显式化的隐式约束（如实体、时序阶段）及需强调的建模能力（如空间布局、物理合理性）。这一设计解决了通用重写策略在复杂场景下缺乏针对性指导的问题，使重写过程从“盲目扩展”转变为“定向补全”。

### 原子级蕴含验证与条件修正

重写后的提示词 $P_{rew}$ 可能引入语义遗漏或矛盾。SCMAPR 引入语义原子化器将 $P_{user}$ 分解为包含角色、物体、动作、地点、景色的原子字典 $D_A$，并展平为原子列表 $A = \{a_1, ..., a_n\}$。同时，将 $P_{rew}$ 分块为证据单元 $C = \{c_1, ..., c_m\}$。通过嵌入模型 $f_E$ 计算原子与证据块的余弦相似度，为每个原子 $a_i$ 选取最相关证据块 $e_i$：

$$ e_i = \arg \max_{j \in \{1,...,m\}} \cos(f_E(a_i), f_E(c_j)) $$

该公式通过语义空间对齐，定位每个用户意图原子在重写提示词中的具体支撑位置。随后，蕴含验证器对 $(a_i, e_i)$ 对进行三元判断：蕴含（ET）、缺失（MS）或矛盾（CT）。仅当蕴含率 $p_{ET}=1$ 且矛盾率 $p_{CT}=0$ 时接受结果，否则触发条件修正。这一机制将模糊的“语义对齐”转化为可计算的原子级逻辑约束，有效抑制了重写过程中的幻觉与意图漂移。

## 实验评估

实验在 VBench、EvalCrafter 和 T2V-CompBench 上进行，使用 Wan2.2 和 LaVie 作为骨干网络。基线包括直接提示、Open-Sora 提示器及 RAPO。SCMAPR 在两个骨干上均取得最优平均分。在 VBench 上，Wan+SCMAPR 达到 88.21%，比 Wan+RAPO 高 0.78%；在 EvalCrafter 上，Wan+SCMAPR 达到 66.74%，比 Wan+RAPO 高 2.20%。在侧重组合推理的 T2V-CompBench 上，Wan+SCMAPR 平均分 0.523，显著高于 Wan+RAPO 的 0.495。

| 基准 | 方法 | 平均分 |
| :--- | :--- | :--- |
| VBench (Wan) | Wan + RAPO | 87.43 |
| VBench (Wan) | Wan + SCMAPR | 88.21 |
| EvalCrafter (Wan) | Wan + RAPO | 64.54 |
| EvalCrafter (Wan) | Wan + SCMAPR | 66.74 |
| T2V-CompBench (Wan) | Wan + RAPO | 0.495 |
| T2V-CompBench (Wan) | Wan + SCMAPR | 0.523 |

消融实验显示，移除场景路由导致 VBench 平均分下降 1.72%，影响最大，证实了分类学路由对策略生成的关键作用。移除验证与自修正模块导致下降 0.58%，表明原子级校验对语义保真度的贡献。移除策略生成仅下降 0.46%，说明路由信号本身已提供大部分增益，策略合成提供边际优化。

评估边界方面，论文未报告推理延迟，而多智能体流水线涉及多次 LLM 调用，实际部署中的时间成本未知。此外，T2V-Complexity 基准虽覆盖 10 类复杂场景，但每类仅 100 条提示，样本量较小，统计显著性有限。代码已开源，但超参数配置（如最大修正轮数）未在正文中详细列出，复现时需参考附录。

## 关联研究分析

从问题动机看，SCMAPR 与 RAPO 同属提示词优化路线，但 RAPO 依赖检索增强生成（RAG）基于表面相似度扩展提示词，缺乏对视频特有时序与物理约束的显式建模。SCMAPR 通过场景路由将困难源结构化，解决了 RAPO 在复杂场景下因缺乏针对性策略而导致的语义遗漏问题。这一差异源于任务特性：视频生成的时序连贯性要求提示词不仅描述“是什么”，还需描述“如何发生”，而 RAPO 的检索机制难以捕捉这种动态逻辑。

从方法设计看，SCMAPR 与 ReaDe 均利用 LLM 进行推理-描述范式，但 ReaDe 侧重生成结构化描述以提升语义完整性，而 SCMAPR 引入原子级蕴含验证闭环，将验证从“生成后检查”前置为“生成中约束”。这种设计差异源于对幻觉抑制的不同理解：ReaDe 依赖 LLM 的内在推理能力，而 SCMAPR 通过外部逻辑校验强制保真。然而，SCMAPR 的验证阶段依赖 LLM 进行蕴含判断，若 LLM 本身存在逻辑偏差，验证环节可能失效，论文未对此进行鲁棒性测试。

## 总结

SCMAPR 旨在解决复杂场景下文本到视频生成中提示词模糊导致的语义漂移问题。其切入点在于将模糊的“复杂场景”解耦为可路由的十类困难源，并通过原子级蕴含验证闭环确保重写保真度，这是单次重写或检索增强方法无法实现的。实验证明，该框架在 VBench 和 EvalCrafter 上分别取得 88.21% 和 66.74 的平均分，显著优于 RAPO 等基线。然而，其性能增益部分依赖底层扩散模型（如 Wan2.2）的基线能力，且多智能体推理的延迟成本未被量化。当底层模型能力较弱时，原子级验证的纠错上限是否仍能有效提升生成质量，论文未给出回答。
