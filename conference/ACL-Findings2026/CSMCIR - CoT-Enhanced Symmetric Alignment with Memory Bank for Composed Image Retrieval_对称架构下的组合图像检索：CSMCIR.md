# ACL-Findings2026最新论文 ｜CSMCIR: CoT-Enhanced Symmetric Alignment with Memory Bank for Composed Image Retrieval ｜对称架构下的组合图像检索：CSMCIR

研究机构：快手、厦门大学

作者：Zhipeng Qian、Zihan Liang、Yufei Ma 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.03728)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.03728)

> 导读 组合图像检索（Composed Image Retrieval, CIR）旨在通过参考图像与修改文本的联合输入，精准定位目标图像，其核心痛点在于查询侧（图+文）与目标侧（仅图）的模态异构性导致表示空间碎片化。现有方法多采用非对称编码器处理两侧输入，依赖事后对齐弥合空间差异，但T-SNE可视化证实这种碎片化在训练后依然显著存在，限制了检索性能。本文提出CSMCIR，通过多模态大模型离线生成目标图像描述实现模态对称，结合共享参数双塔架构与熵感知记忆库，在四个基准上取得SOTA性能。该框架在训练效率与检索精度间取得平衡，但其对称设计是否牺牲了对查询侧细粒度修改意图的捕捉能力，尚需进一步验证。

## 研究背景

当用户试图通过“将图中红色连衣裙改为蓝色”这样的指令检索目标图像时，系统需同时理解参考图像的视觉锚点与文本的语义约束。这一任务面临的核心挑战是模态不对称性：查询侧包含图像与文本两种模态，而目标侧仅有图像。这种异构性迫使模型为两侧设计不同的编码器，导致查询与目标嵌入在特征空间中形成分离的簇，即表示空间碎片化。碎片化使得对比学习难以有效拉近正样本对、推远负样本对，成为制约CIR性能的根本瓶颈。

早期CIR方法如TIRG（2019）和CLIP4CIR（2021）确立了多模态融合与零样本范式，但均维持非对称架构。2023年出现的文本反转方法（如Pic2Word）将图像映射为伪词元以在文本空间组合，虽缓解了模态间隙，却丢失细粒度视觉细节。2024年，CIReVL等方法转向利用大语言模型生成目标描述，但通常重构为纯文本检索或保持非对称结构。本文的切入点在于：利用多模态大模型（MLLM）离线生成目标图像描述，使查询与目标侧均成为“图像-文本”对，从而在架构层面实现模态对称，从根本上消除碎片化。

## 核心方法

### 方法参照系

CIR的标准流程是分别编码查询（参考图+修改文本）与目标（目标图），通过对比学习对齐两侧嵌入。本文问题与该通用流程的关键差异在于：传统方法中查询与目标侧使用不同编码器，导致特征空间错位；本文通过生成目标描述，使两侧输入结构一致，从而可采用共享参数的编码器。

### 多级链式思维提示与模态对称

传统方法中，目标侧仅输入图像，导致与查询侧的模态结构不一致。本文引入多级链式思维（MCoT）提示策略，引导MLLM生成兼具判别性与语义兼容性的目标图像描述。MCoT包含四个步骤：核心本质（简洁描述主要对象）、视觉属性（颜色、材质等细节）、观察过程（推理优先级）、最终描述（综合前序步骤）。该过程可形式化为：

$$T(I_t) = \Psi_{MCoT}(I_t)$$

其中 $\Psi_{MCoT}$ 表示MCoT生成函数。这一设计解决了此前方法中目标描述过于简略或冗余的问题，确保生成描述与修改文本在语义细节上可比，为对称架构奠定基础。

### 对称双塔架构与熵感知记忆库

模态对称后，查询侧 $(I_r, T)$ 与目标侧 $(I_t, T(I_t))$ 可输入相同的共享参数Q-Former编码器。编码过程为：

$$Z_q = Q\text{-}Former(I_r, T), \quad Z_t = Q\text{-}Former(I_t, T(I_t))$$

其中 $Z_q$ 和 $Z_t$ 分别为查询与目标的跨模态表示。对称架构使记忆库（Memory Bank）的引入成为可能，但标准记忆库存储的静态嵌入会随模型更新而失效。本文提出熵感知记忆库策略，存储静态输入（描述与冻结图像嵌入），并在每步用当前Q-Former动态重计算负样本嵌入。样本保留分数定义为：

$$S_i = H_i^{[M]} \cdot e^{-\Delta t_i / N_{max}}$$

其中 $H_i^{[M]}$ 为样本 $i$ 相对于记忆库的信息熵，$\Delta t_i$ 为自上次更新以来的训练步数，$N_{max}=10$ 为最大陈旧阈值。该公式通过熵衡量样本多样性，通过时间衰减惩罚陈旧样本，确保负样本既多样又与当前模型状态一致。

## 实验评估

实验在FashionIQ、CIRR、Shoes和LaSCO四个数据集上进行，使用ViT-G作为冻结图像编码器，Qwen2.5-VL-7B-Instruct生成目标描述。基线覆盖SPRC、CCIN、TME等近期方法，但缺失2026年SOTA方法如WISER和G-MIXER。

| 方法 | FashionIQ Avg. | CIRR R@1 | CIRR R@10 |
| :--- | :--- | :--- | :--- |
| SPRC | 65.09 | - | - |
| CCIN | - | 25.95 | 65.76 |
| TME | 65.09 | - | - |
| CSMCIR | 67.17 | 29.24 | 67.97 |

CSMCIR在FashionIQ Avg.上较SPRC提升2.08个点，在CIRR R@1上较CCIN提升3.29个点。消融实验显示，MCoT提示、对称架构（SA）和熵感知记忆库（EAMB）分别贡献了1.48、0.59和0.73个点的Avg.提升（FashionIQ），其中MCoT贡献最大。移除时间衰减（TD）或熵感知（EA）均导致性能下降，TD影响更大，表明时间一致性对负样本质量至关重要。

评估边界方面，论文未报告置信区间，且未与2026年SOTA方法对比。可复现性方面，代码将公开，使用单张A100 GPU训练15个epoch，FashionIQ训练耗时1.2 GPU小时，低于SPRC的1.8小时。

## 关联研究分析

从问题动机看，CSMCIR与CIReVL均利用LLM生成目标描述，但CIReVL将CIR重构为纯文本检索，而CSMCIR保持图像-文本对检索并强制结构对称。这一差异源于CIReVL侧重语义完整性，而CSMCIR侧重架构一致性。CSMCIR的对称设计可能限制了模型对查询侧特定修改意图的细粒度捕捉，因为共享编码器无法为查询侧的文本指令分配更多容量。

从方法设计看，CSMCIR与SPRC同属Q-Former架构，但SPRC维持非对称结构，而CSMCIR通过生成目标描述实现对称。这一改动使记忆库的引入成为可能，但SPRC等先前工作认为记忆库不适用于CIR，源于架构不对称导致的嵌入不一致。CSMCIR的熵感知策略通过动态重计算解决了这一问题，但其有效性依赖于生成描述的质量。若生成描述存在幻觉或遗漏关键属性，对称架构可能放大这些错误，论文通过人工检查确认低幻觉率，但未量化描述质量对最终性能的影响。

## 总结

CSMCIR要解决的核心矛盾是CIR中查询与目标侧的模态异构性导致的表示空间碎片化。现有方法通过非对称编码器和事后对齐处理这一问题，但碎片化在训练后依然显著。本文抓住的切入点是：利用MLLM离线生成目标描述，使两侧输入结构一致，从而可采用共享参数编码器。具体做法是结合MCoT提示、对称双塔架构与熵感知记忆库。实验证明，该方法在FashionIQ Avg.上达到67.17，在CIRR R@1上达到29.24，较基线有显著提升。本文的边界在于未与2026年SOTA方法对比，且对称设计可能牺牲查询侧的细粒度捕捉能力。当查询文本包含复杂逻辑或否定约束时，共享编码器是否仍能准确区分查询与目标的语义差异，论文未给出回答。
