# ACL-Findings2026最新论文 ｜Grounding Agent Memory in Contextual Intent ｜基于上下文意图的智能体记忆系统

研究机构：美国伊利诺伊大学厄巴纳-香槟分校、美国斯坦福大学

作者：Ruozhen Yang、Yucheng Jiang、Yueqi Jiang 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.10702)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.10702)

> 长时程智能体交互中，语义相似但上下文不同的信息极易导致检索混淆，现有记忆系统缺乏对潜在目标状态的显式建模。STITCH 通过在线诱导“上下文意图”三元组作为结构化检索线索，解决了这一干扰问题。其核心在于将记忆检索从语义相似度匹配升级为意图兼容性过滤。该方法在高干扰场景下显著优于基线，但其对强 LLM 骨干的依赖限制了轻量化部署，且未验证在通用事实召回任务上的泛化优势。

## 研究背景

长时程任务要求智能体在交错的目标间维持状态一致性。当同一实体（如酒店价格）在不同时间步出现不同数值时，简单的向量检索无法区分这些语义相似但上下文不同的事实，导致记忆幻觉。解决此问题需要引入检索线索（Retrieval Cues），即决定哪些存储信息被访问的结构化索引。认知科学中的事件结构理论（Event Structure Theory）指出，人类通过高层目标上下文和重复动作类别来组织经验，这为构建抗干扰的记忆索引提供了理论依据。

当前主流记忆架构分为两类：基于压缩的摘要记忆和基于图谱的结构化记忆。前者（如 RAPTOR）擅长处理相邻片段，但难以链接非相邻的持久目标；后者（如 GraphRAG）编码实体关系，却缺乏目标级消歧，导致同一实体在不同目标下的提及被混淆。STITCH 的切入点在于，现有系统均未显式建模轨迹中每一步的“潜在意图”，即当前步骤服务于哪个宏观目标、执行何种操作、涉及哪些关键实体类型。这种缺失使得检索在噪声历史中失效。

## 核心方法

### 方法参照系

STITCH 属于结构化记忆架构路线，其标准流程为：在线构建记忆表示 → 存储 → 推理时检索。与 GraphRAG 等静态图谱方法不同，STITCH 的关键差异在于其索引结构是动态诱导的，且检索机制优先匹配结构兼容性而非语义相似度。

### 上下文意图三元组构建

STITCH 将轨迹 $T = \{s_1, \dots, s_n\}$ 中的每一步 $s_t$ 映射为上下文意图元组 $\iota_t = (\sigma_t, \epsilon_t, \kappa_t)$。其中 $\sigma_t$ 为主题范围，通过滑动窗口 LLM 预测保持目标连贯性；$\epsilon_t$ 为事件类型，通过动态标签空间演化捕捉操作类别；$\kappa_t$ 为关键实体类型，锚定事实属性。

$$
\iota_t = M_{intent}(s_t, H_{scope}, V_\epsilon, V_\kappa)
$$

该公式表明意图元组由当前步骤、历史范围缓冲及动态词汇表共同决定。设计动机在于，静态本体无法适应新任务，而在线诱导的三元组能自动扩展标签空间，解决固定 schema 在跨域任务中的泛化失效问题。

### 意图感知检索

推理时，查询 $q$ 被映射为过滤配置 $F_q = (S_q, E_q, K_q)$。检索引擎采用标签密度排序（Label Density Ranking），优先选择与 $F_q$ 结构重叠度最高的记忆片段。

$$
Score(m_t) = |\iota_t \cap F_q| + \lambda \cdot sim(q, c_t)
$$

其中 $|\iota_t \cap F_q|$ 为意图约束满足数，$sim(q, c_t)$ 为语义相似度。该机制确保语义相似但上下文不匹配的内容被抑制，解决了向量检索在干扰场景下的混淆问题。

## 实验评估

STITCH 在自建 CAME-Bench 和 LongMemEval 上评估，基线覆盖长上下文 LLM（GPT-5-mini）、向量 RAG（text-embedding-3-large）及结构化记忆（GraphRAG, A-Mem）。CAME-Bench 包含旅行规划和辩论两个领域，强调交错目标与语义干扰。

| 方法 | CAME-Bench S (F1) | CAME-Bench M (F1) | CAME-Bench L (F1) | LongMemEval O (Acc) |
| :--- | :--- | :--- | :--- | :--- |
| GPT-5-mini | 0.804 | 0.566 | 0.212 | 0.860 |
| GraphRAG | 0.371 | 0.165 | 0.156 | 0.667 |
| STITCH | 0.844 | 0.682 | 0.592 | 0.860 |

在 CAME-Bench Large 子集上，STITCH 的 F1 为 0.592，显著优于最强基线 GPT-5-mini 的 0.212，相对提升 100%。这表明随着轨迹长度增加，意图索引的抗干扰优势呈指数级增长。

消融实验显示，移除主题范围（Thematic Scope）导致 F1 从 0.844 降至 0.463，降幅最大，证明目标连贯性是消歧的关键。移除事件类型（Event Type）后 F1 降至 0.753，说明操作类别对区分相似事实有辅助作用。

评估边界方面，CAME-Bench 为合成数据，可能高估意图诱导的有效性；LongMemEval 上 STITCH 与 GPT-5-mini 持平（0.860），未体现优势，暗示其在低干扰、短上下文场景下无额外收益。代码已开源，但意图诱导依赖 GPT-5-mini，计算开销未量化。

## 关联研究分析

从问题动机看，STITCH 与 GraphRAG 均旨在解决多跳推理，但 GraphRAG 聚焦实体关系抽取，而 STITCH 聚焦目标状态追踪。GraphRAG 在实体重复出现时易混淆不同目标下的同一实体，STITCH 通过主题范围显式隔离这些上下文，根源在于任务特性：长时程任务中目标切换比实体关系更频繁。

从方法设计看，STITCH 与 A-Mem 都采用动态链接，但 A-Mem 基于 Zettelkasten 笔记网络，链接由内容相似性驱动；STITCH 基于认知意图，链接由结构兼容性驱动。A-Mem 在简单事实召回上可能更高效，但 STITCH 在高干扰场景下更鲁棒。STITCH 未探索意图诱导的轻量化替代方案，如使用小型模型或规则引擎，这可能限制其在边缘设备上的部署。

## 总结

STITCH 解决了长时程智能体记忆中语义相似但上下文不同的信息混淆问题。其切入点在于显式建模潜在意图，通过在线诱导的三元组实现结构兼容性检索，克服了静态图谱和向量检索的局限。实验证明，在高干扰的 CAME-Bench Large 子集上，STITCH 的 F1 达到 0.592，远超基线。然而，其在 LongMemEval 上与长上下文 LLM 持平，表明优势仅在特定干扰场景下显现。意图诱导依赖强 LLM 骨干，计算开销未量化，且在低干扰场景下无额外收益。当轨迹长度进一步增加时，意图标签空间的动态演化是否会导致标签爆炸，论文未给出回答。
