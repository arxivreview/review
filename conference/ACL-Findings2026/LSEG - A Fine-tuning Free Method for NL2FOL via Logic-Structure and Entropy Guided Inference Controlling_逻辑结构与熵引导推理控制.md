# ACL-Findings2026最新论文 ｜LSEG: A Fine-tuning Free Method for NL2FOL via Logic-Structure and Entropy Guided Inference Controlling ｜逻辑结构与熵引导推理控制

研究机构：中国科学院、中国科学院大学

作者：Yuwei Huang、Shi Wang、Kangli Zi 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ea6cd163bec2)

> 自然语言到一阶逻辑（NL2FOL）翻译的核心痛点在于大语言模型（LLM）内部表示漂移导致的逻辑幻觉，即生成语法正确但语义错误的公式。现有微调或代码生成方法虽能提升一致性，但依赖高昂训练成本或特定架构，且无法在推理时动态修正内部状态偏差。LSEG通过构建逻辑保持扰动向量并引入熵引导机制，在免微调条件下校正隐藏状态。该方法在FOLIO和MALLS上取得了与强监督模型相当的性能，但其对复杂量词交互的覆盖能力及统计显著性仍存疑。

## 研究背景

NL2FOL任务要求将自然语言映射为一阶逻辑表达式，其难点不在于表面词汇生成，而在于维持内部表示与逻辑结构的对齐。当LLM处理包含量词或否定词的句子时，隐藏状态在正向传播中逐渐偏离逻辑锚点，导致量词范围或算子附着发生微妙改变，进而产生逻辑不一致的公式。这种表示漂移是逻辑幻觉的根本来源，传统解码策略无法解决这一内部状态失稳问题。

主流NL2FOL方法分为监督微调与代码生成两条路线。监督模型如LogicLLaMA通过强化学习优化翻译准确性，但依赖大量标注数据且绑定特定架构；代码生成方法如Code4Logic将翻译重构为Python代码执行，虽提升了灵活性，但引入了外部依赖且计算开销大。这些方法均将逻辑一致性视为训练目标或外部验证结果，忽视了推理过程中内部表示的动态稳定性。LSEG的切入点在于将逻辑校正前移至表示层，通过推理时的向量干预直接稳定隐藏状态，无需参数更新或额外训练。

## 核心方法

### 方法参照系

NL2FOL的标准流程是条件生成，即给定输入句子 $x$，模型输出逻辑表达式 $y = \arg\max_{y'} p_\theta(y' | x)$。现有方法通常通过调整解码策略或训练目标来优化 $y$ 的逻辑有效性，而LSEG的关键差异在于不改变模型参数 $\theta$ 或解码过程，而是直接干预中间层的隐藏状态 $h^{(l)}(x)$，以抵消逻辑漂移。

### 逻辑方向向量构建

LSEG首先通过逻辑保持扰动构建校正方向。对于输入 $x$，生成 $n$ 个表面不同但逻辑等价的变体 $\{x'_1, ..., x'_n\}$，计算各层隐藏状态的均值作为逻辑锚点：

$$ h^{(l)}_{\text{logic}} = \frac{1}{n} \sum_{i=1}^n h^{(l)}(x'_i) $$

该公式通过平均逻辑等价变体的表示，消除词汇和句法噪声，提取出稳定的逻辑结构中心。随后定义逻辑位移向量 $\Delta^{(l)} = h^{(l)}_{\text{logic}} - h^{(l)}_{\text{orig}}$，其中 $h^{(l)}_{\text{orig}}$ 为原始输入的表示。对训练集中的位移向量进行主成分分析（PCA），提取第一主成分 $v^{(l)}$ 作为通用校正方向。这一设计解决了微调方法依赖特定数据分布的问题，使校正向量具备跨样本泛化能力。

### 熵引导自适应干预

在推理阶段，LSEG利用层间熵变化作为稳定性信号。计算第 $l$ 层在第 $t$ 步的熵 $H^{(l)}_t$，定义熵变化 $\Delta H^{(l)}_t = H^{(l)}_t - H^{(l-1)}_t$，并标准化为 $z^{(l)}_t$。当 $|z^{(l)}_t| > \tau$ 时，判定该层处于不稳定状态，注入校正向量：

$$ h'^{(l)}_t = h^{(l)}_t + \alpha_l v^{(l)} $$

其中 $\alpha_l$ 与熵变化幅度成正比。该机制确保仅在模型内部置信度剧烈波动时进行干预，避免对高置信度状态过度校正。这一设计解决了固定强度干预破坏生成流畅性的问题，实现了逻辑一致性与语义稳定性的平衡。

## 实验评估

| 模型 | FOLIO LE (%) | MALLS LE (%) | 训练成本 |
| :--- | :--- | :--- | :--- |
| GPT-4 | 85.53 | 84.38 | API |
| LogicLLaMA | 84.90 | 81.34 | Supervised + RLHF |
| Code4Logic (GPT-3.5) | 92.67 | 90.92 | Few-shot (API) |
| Qwen-3 8B (baseline) | 88.00 | 89.70 | – |
| LSEG (Qwen-3 8B) | 92.01 | 91.34 | Fine-tuning Free |

实验在FOLIO和MALLS基准上进行，评估指标为逻辑等价性（LE）。基线覆盖了监督微调（LogicLLaMA）、代码生成（Code4Logic）及通用LLM（GPT-4），但缺失了知识库中提到的迭代反馈类方法如VERUS-LM和自适应语言选择方法。LSEG在Qwen-3 8B上达到FOLIO 92.01%和MALLS 91.34%，接近Code4Logic (GPT-3.5)的92.67%和90.92%，显著优于GPT-4和LogicLLaMA。这表明免微调的表示层校正可达到与强监督模型相当的性能，验证了内部稳定性对逻辑一致性的决定性作用。

| 变体 | FOLIO LE (%) | MALLS LE (%) |
| :--- | :--- | :--- |
| w/o Entropy Guidance | 90.42 | 90.11 |
| LSEG (fixed schedule) | 91.02 | 90.83 |
| LSEG (entropy-guided, full) | 92.01 | 91.34 |

消融实验显示，移除熵引导机制导致LE下降1.59个百分点（FOLIO），表明固定强度干预会过度校正高置信度状态。层间消融进一步揭示，浅层（L0-L3）注入导致性能下降至83.20%，而中层（L20-L23）和上层（L28-L31）分别达到91.12%和91.08%，证实逻辑相关信息在网络深层整合，且熵波动集中于此。这一发现支持了LSEG聚焦中层以上层级的设计选择。

评估边界方面，论文未报告置信区间，92.01%与92.67%的微小差距缺乏统计显著性检验。代码未公开，但提供了详细的算法伪代码和超参数设置（如阈值 $\tau$ 和最大强度 $\alpha_{\max}$），可复现性中等。指标仅关注逻辑等价性，未评估生成流畅性或计算延迟，无法全面衡量实际部署成本。

## 关联研究分析

从问题动机看，LSEG与VERUS-LM和NL2LOGIC存在根本分歧。VERUS-LM依赖外部求解器反馈进行迭代纠错，NL2LOGIC通过AST结构约束生成过程，两者均将逻辑错误归因于翻译过程的语义或语法缺陷，需外部组件介入。LSEG则将错误根源定位于内部表示漂移，主张通过向量干预在模型内部解决，无需外部验证。这一差异源于对LLM逻辑能力本质的不同假设：前者认为LLM缺乏逻辑严谨性需外部补偿，后者认为LLM具备逻辑潜力但受表示噪声干扰。LSEG的免微调特性使其在资源受限场景更具优势，但无法保证逻辑有效性，仅能提升一致性概率。

从方法设计看，LSEG与Representation Steering（如Turner et al., 2023）共享向量干预机制，但将通用语义转向特化为逻辑校正。Steering方法通常针对特定属性（如毒性、情感）构建方向向量，而LSEG通过逻辑保持扰动和PCA提取逻辑结构方向，更具任务特异性。与Code4Logic相比，LSEG避免了代码生成的外部依赖和计算开销，但牺牲了符号求解器的确定性保证。Code4Logic通过执行代码获得严格逻辑结果，LSEG仅通过调整隐藏状态提升概率一致性，两者在可靠性与效率之间做出了不同取舍。

## 总结

LSEG旨在解决NL2FOL翻译中因内部表示漂移导致的逻辑幻觉，其切入点在于将逻辑校正从训练目标或外部验证前移至推理时的表示层干预。通过构建逻辑保持扰动向量并引入熵引导自适应机制，LSEG在免微调条件下实现了FOLIO 92.01%和MALLS 91.34%的逻辑等价性，接近强监督模型性能。然而，论文未报告置信区间，且消融实验显示浅层注入导致性能下降，表明该方法对网络层级的依赖性较强。当输入句子包含复杂量词嵌套或多重否定结构时，逻辑保持扰动是否仍能准确捕捉逻辑锚点，论文未给出回答。
