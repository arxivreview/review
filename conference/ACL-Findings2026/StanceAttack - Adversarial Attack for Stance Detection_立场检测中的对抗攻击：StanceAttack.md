# ACL-Findings2026最新论文 ｜StanceAttack: Adversarial Attack for Stance Detection ｜立场检测中的对抗攻击：StanceAttack

作者：Chenye Zhao、Cornelia Caragea

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_88494ce3e748)

> 立场检测模型在真实政治舆论场景中面临被恶意篡改的风险，现有研究多关注分类精度而忽视模型对语义保持型扰动的脆弱性。传统词级替换攻击难以生成自然且语义一致的对抗样本，导致攻击成功率低或文本可读性差。本文提出 StanceAttack，利用 ChatGPT 结合思维链（Chain-of-Thought, CoT）提示与决策反馈机制，生成能欺骗预训练语言模型（Pretrained Language Models, PLMs）的立场翻转样本。该方法在效率与成功率上优于基线，但仅针对黑盒 PLM 且排除中立类，其鲁棒性边界尚待验证。

## 研究背景

立场检测旨在判断文本对特定目标（如政策或人物）的支持、反对或中立态度。当模型部署于选举监测或舆情分析时，攻击者可通过微调文本语义而不改变表面含义，诱导模型输出错误立场，从而操纵公共舆论。这种攻击要求对抗样本在语义上与原文高度相似，同时导致模型预测翻转，即“语义保持型对抗攻击”。

主流立场检测模型基于 BERT 或 BART 等 PLMs 微调，在干净数据上表现优异，但缺乏对对抗扰动的防御机制。现有对抗攻击方法如 TextFooler 和 BERT-Attack 依赖词嵌入或掩码语言模型进行词级替换，虽能实现部分攻击，但生成的文本往往语法生硬或语义偏移，难以模拟真实人类攻击。Schiller et al. (2021) 提出的盲攻击虽无需模型反馈，但缺乏针对性，成功率受限。本文切入点在于利用大语言模型（Large Language Models, LLMs）的语义理解与生成能力，通过迭代反馈机制生成高质量、高成功率的对抗样本，填补立场检测领域专用攻击算法的空白。

## 核心方法

### 方法参照系

本文问题属于黑盒对抗攻击范畴，标准流程为：生成扰动样本 → 查询受害者模型 → 判断是否成功。关键差异在于，本文不依赖梯度或嵌入空间操作，而是将 LLM 作为攻击器，通过自然语言提示引导其生成语义保持的改写文本，并引入决策反馈循环以优化攻击效率。

### 两阶段思维链提示

传统攻击方法直接生成扰动，缺乏对文本立场语义的深层理解，导致生成的样本易被模型识别。本文首先设计提示 P1，引导 ChatGPT 分析原文 $x_i$、目标 $t_i$ 与立场 $y_i$ 之间的语义关联，提取关键立场表达元素，生成分析结果 $a_i$。该步骤确保攻击器理解“为何”该文本持特定立场，为后续生成提供语义锚点。

$$
a_i = \text{ChatGPT}(P1(x_i, t_i, y_i))
$$

此公式表示通过提示 P1 获取文本的立场语义分析，其物理含义是将隐性的立场表达显性化为可操作的语义特征，使后续生成能精准保留立场意图。

### 决策反馈迭代攻击

在获得语义分析后，本文通过提示 P2 生成初始对抗样本 $x_i^{adv}$，并查询受害者模型 $M$。若预测错误，攻击成功；若预测正确，则将失败样本 $\hat{x}_i^{adv}$ 作为负例反馈给 ChatGPT，通过提示 P3 生成新样本。该机制形成闭环优化，避免盲目重试。

$$
x_i^{adv} = \begin{cases}
\text{ChatGPT}(P2(x_i, t_i, y_i, a_i)) & \text{if } Q=0 \\
\text{ChatGPT}(P3(x_i, t_i, y_i, \hat{x}_i^{adv})) & \text{if } Q>0 \text{ and } M(x_i^{adv}, t_i) = y_i
\end{cases}
$$

此公式描述了迭代攻击过程：首次使用 P2 生成，后续若失败则利用 P3 结合历史失败样本重新生成。设计动机在于解决传统攻击中“试错盲目”的问题，通过负例反馈引导 LLM 规避已失效的扰动模式，显著提升攻击效率与成功率。

## 实验评估

实验在 Covid（推文，平均长度 27.3）和 VAST（新闻，平均长度 101.1）数据集上进行，受害者模型为 BERTweet、BART 和 BERT。基线包括 TextFooler、BERT-Attack、MAYA 和 HQA，覆盖词级与句级攻击，但缺失基于梯度或嵌入空间的攻击方法。

| 数据集 | 模型 | 方法 | Att F1macro | 成功率 | 查询数 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Covid | BERTweet | StanceAttack | 0.047 | 97.2% | 11.9 |
| Covid | BERTweet | BERT-Attack | 0.230 | 80.8% | 53.5 |
| VAST | BERT | StanceAttack | 0.172 | 87.5% | 29.7 |
| VAST | BERT | BERT-Attack | 0.513 | 41.3% | 85.1 |

StanceAttack 在 Covid 数据集上对 BERTweet 的攻击成功率为 97.2%，较 BERT-Attack 高 16.4 个百分点，且查询数仅为 11.9，远低于基线的 53.5。在长文本 VAST 数据集上，StanceAttack 对 BERT 的成功率为 87.5%，而 BERT-Attack 仅为 41.3%，表明该方法在复杂语境下更具鲁棒性。

| 方法 | Att F1macro | 成功率 | 查询数 |
| :--- | :--- | :--- | :--- |
| StanceAttack | 0.047 | 97.20% | 11.9 |
| w/o P1 | 0.239 | 78.00% | 17.6 |
| w/o P3 | 0.205 | 81.40% | 15.5 |
| CoT 1-stage | 0.121 | 89.80% | 14.1 |

消融实验显示，移除语义分析（w/o P1）导致成功率下降 19.2 个百分点，查询数增加 48.7%，证实 P1 对攻击效率的关键作用。移除决策反馈（w/o P3）使成功率下降 15.8 个百分点，表明负例反馈机制有效加速攻击收敛。单阶段 CoT 虽优于无反馈版本，但仍低于完整框架，说明分步推理优于一次性生成。

评估指标涵盖成功率、查询数及 F1macro，但未报告攻击样本的语义相似度自动指标（如 BLEU 或 ROUGE），仅通过人工评估验证。代码已开源，但超参数（如最大查询数 K=100）未在正文详细列出，可复现性依赖附录。

## 关联研究分析

从问题动机看，本文与 IRIS 等零样本立场检测方法形成互补而非竞争。IRIS 关注模型在未见目标上的泛化能力，通过信息检索排序提升检测精度；而 StanceAttack 关注模型在已知目标下的鲁棒性，通过对抗样本暴露其脆弱性。两者均依赖 LLM 的语义理解，但 IRIS 将 LLM 作为检测器，StanceAttack 将其作为攻击器。差异根源在于任务目标不同：前者追求“准确识别”，后者追求“有效欺骗”。

从方法设计看，本文与 ThaiFACTUAL 的反事实校准存在本质区别。ThaiFACTUAL 通过反事实替换控制情感极性，旨在去偏，即纠正模型将负面情感错误映射为反对立场的偏差；StanceAttack 则通过语义保持型改写诱导立场翻转，旨在攻击。两者均利用 LLM 生成文本，但 ThaiFACTUAL 的生成目标是“中性化”或“去情感化”，而 StanceAttack 的生成目标是“立场翻转但语义保持”。这一差异暗示，去偏策略与对抗攻击策略在 LLM 提示设计上存在根本冲突：前者需抑制情感线索，后者需保留情感线索以维持语义一致性。

## 总结

本文核心矛盾在于立场检测模型在语义保持型扰动下的脆弱性未被充分量化。现有词级攻击方法因生成文本不自然或语义偏移而效率低下，本文利用 ChatGPT 的 CoT 能力与决策反馈机制，生成高质量对抗样本。实验证明，StanceAttack 在 Covid 数据集上对 BERTweet 的成功率达 97.2%，查询数仅 11.9，显著优于基线。然而，本文仅针对黑盒 PLM 且排除中立类，未评估 LLM 作为受害者模型的鲁棒性。当受害者模型从 BERT 切换至 GPT-4 时，基于语义保持的对抗攻击是否仍能有效翻转立场，论文未给出回答。
