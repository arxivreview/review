> 多模态大语言模型（Multimodal Large Language Models, MLLMs）在真实部署中面临的核心安全挑战，已从单轮对抗攻击演变为多轮交互中意图的渐进式演变与上下文重构。现有安全评估基准多聚焦于单轮静态输入，无法捕捉恶意意图在多轮对话中通过良性提问逐步升级，或在初始恶意意图下伪装成无害追问的隐蔽模式。MTMCS-Bench 提出了一种包含升级风险与上下文切换风险的双模式多轮多模态评估框架，通过配对安全与不安全对话及多模态/单模态对照，量化模型在意图识别、安全意识与有用性之间的动态平衡。该基准揭示了当前防御机制在多轮上下文中的系统性失效，为动态安全对齐提供了细粒度的诊断工具，但其依赖大语言模型作为评判者可能引入的评分偏差仍需进一步验证。

## 研究背景

当多模态大语言模型（Multimodal Large Language Models, MLLMs）被部署为具身代理或实时助手时，其安全机制面临一个根本性困境：单轮输入的安全判断无法反映整个对话的真实风险。模型需要处理视觉场景与文本历史的联合语义，而攻击者往往利用这种联合理解的复杂性，通过多轮交互逐步渗透安全护栏。这种安全判断的失效源于“上下文安全”（Contextual Safety）的缺失，即模型未能将当前请求置于完整的对话历史和视觉语境中进行风险评估。

在纯文本大语言模型中，安全对齐主要依赖基于人类反馈的强化学习（RLHF）或直接偏好优化（DPO），旨在使模型拒绝有害请求。然而，当视觉编码器接入后，模型需要处理图像中的排版文本、纹理噪声以及隐含的视觉语义，这些输入往往绕过了针对纯文本设计的过滤器。视觉指令微调过程虽然赋予了模型跨模态推理能力，却常常破坏底层语言模型原有的安全护栏，导致模型在理解图像内容时未能将其与安全风险关联，出现“安全感知失败”。

这一结构性矛盾的核心在于“模态间隙”（Modality Gap），即视觉嵌入与文本嵌入在安全语义空间中的分布差异。文本安全机制通常基于语义理解构建，而视觉输入经过编码器后形成的特征分布与文本特征存在固有偏差，使得文本侧的安全约束无法有效覆盖视觉输入。这种偏差导致模型对图像中隐含的恶意指令（如排版注入）极度敏感，而对良性但边界模糊的视觉查询又可能产生过度拒绝（Over-refusal）。因此，多模态安全对齐的本质问题是如何在视觉与文本嵌入空间存在固有分布差异的前提下，构建一种既能抵御跨模态对抗扰动，又能保持细粒度推理效用且不过度拒绝的动态安全机制。

## 核心方法

### 多轮上下文风险建模

MTMCS-Bench 将多轮上下文安全评估置于“动态意图追踪”的框架下，区别于传统基准的单轮静态分类。本文问题与通用安全评估流程的关键差异在于：传统流程假设单轮输入即可决定安全属性，而本文假设安全属性是随对话轮次演变的动态变量。

### 升级风险与上下文切换风险设计

该基准设计了两种互补的风险模式以捕捉意图演变的不同路径。升级风险（Type A）模拟恶意意图的渐进式渗透，其设计动机在于解决现有模型对“温水煮青蛙”式攻击的迟钝。在 Type A 中，对话的前两轮（$R_1, R_2$）保持良性，第三轮（$R_3$）结合视觉场景和前期铺垫，使原本中性的问题转化为具有明确危害性的请求。模型必须在 $R_3$ 识别出意图的质变并拒绝，而在 $R_1, R_2$ 保持有用。

上下文切换风险（Type B）则测试模型在初始恶意意图确立后，对后续“伪装”追问的持续警惕性。其设计动机在于防止模型因后续轮次表面无害而放松防御。在 Type B 中，$R_1$ 明确表达恶意目标，$R_2$ 和 $R_3$ 看似普通的追问实际上仍在推进该恶意目标。模型需基于 $R_1$ 确立的上下文，对后续所有轮次保持拒绝或引导，即使这些轮次在孤立状态下看似安全。

### 多模态与单模态对照评估

为量化视觉信息对安全判断的具体影响，该基准为每个多模态样本构建了单模态（纯文本）对照版本。这一设计解决了传统评估中无法分离视觉通道贡献的问题。通过对比模型在接收图像与仅接收图像文本描述时的表现差异，可以精确衡量视觉输入是增强了安全意识还是导致了过度拒绝。评估指标涵盖意图识别（通过多项选择题 MCQ 和判断题 TF 衡量）、安全意识（SA，针对不安全对话的开放生成评分）和有用性（HS，针对安全对话的开放生成评分）。

## 实验评估

实验在 MTMCS-Bench 的 30,080 个样本上进行，评估了 15 个开源与闭源模型。基线覆盖包括 GPT-4/5 系列、Claude 系列及 LLaVA、Qwen 等主流开源模型，但未包含针对多轮攻击的专用防御方法（如 MTSA）的直接对比。

| 模型 | 类型 | MCQ (%) | TF (%) | 安全意识 (SA) | 有用性 (HS) |
| --- | --- | --- | --- | --- | --- |
| Qwen3-VL-32B | Type A | 74.85 | 71.91 | 2.25 | 3.53 |
| Qwen3-VL-32B | Type B | 87.12 | 74.70 | 2.25 | 3.01 |
| GPT 5.2 | Type A | 83.66 | 79.85 | 3.40 | 3.82 |
| GPT 5.2 | Type B | 84.97 | 84.97 | 4.50 | 2.85 |
| Claude Opus 4.5 | Type A | 79.99 | 83.33 | 4.32 | 3.45 |
| Claude Opus 4.5 | Type B | 84.58 | 84.58 | 4.00 | 2.75 |

*注：数据取自论文 Table 2 及 Table 9 的 Overall 结果。*

实验揭示了显著的安全-效用权衡。在 Type A（升级风险）中，开源模型如 Qwen3-VL-32B 的有用性较高（3.53），但安全意识较低（2.25），表明其容易忽略渐进式恶意意图。闭源模型如 Claude Opus 4.5 在 Type B 中安全意识最高（4.00），但有用性降至 2.75，显示出过度保守倾向。对比 Type A 与 Type B，Type B 的意图识别准确率普遍更高，说明显式恶意意图比隐式升级更容易被模型捕捉。

消融实验进一步验证了视觉模态的影响。对于 LLaVA-7B，将图像转换为文本描述后，有用性提升但安全意识下降，表明视觉输入可能触发模型的过度谨慎。而对于 Claude Opus 4.5，视觉输入显著提升了安全意识，但伴随有用性的明显下降。现有防御机制（如 DPP, AdaShield）在多轮场景下仅部分缓解失败，且往往以牺牲有用性为代价，未能实现三者的平衡。

评估边界方面，该基准依赖 GPT-5-mini 作为评判者，尽管经过人工验证，但仍可能存在模型家族偏好。此外，场景局限于日常 COCO 图像，未覆盖医疗、金融等高敏感领域。

## 关联研究分析

从问题动机看，MTMCS-Bench 与 MSSBench 和 MOSSBench 存在本质差异。MSSBench 和 MOSSBench 主要评估单轮输入下的过度拒绝问题，假设安全属性由单轮输入决定。MTMCS-Bench 则挑战了这一假设，指出单轮安全判断在多轮交互中可能失效。这种差异源于任务特性的不同：前者关注静态鲁棒性，后者关注动态一致性。MTMCS-Bench 的配对设计（安全/不安全变体）使得模型必须在相同视觉场景下区分意图，这是单轮基准无法实现的。

从方法设计看，MTMCS-Bench 与 X-Teaming 和 SafeMT 形成互补。X-Teaming 侧重于多轮红队攻击，旨在生成能绕过防御的对抗对话；SafeMT 侧重于多轮安全对齐训练。MTMCS-Bench 则提供了评估这些攻击与防御效果的标准化测试床。然而，MTMCS-Bench 未直接对比这些专用方法，而是评估通用模型和现有防御，这可能导致对专用防御机制的评估不够深入。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

MTMCS-Bench 针对多轮多模态交互中安全判断失效的核心矛盾，提出了升级风险与上下文切换风险的双模式评估框架。通过构建 30,080 个配对样本，该基准量化了模型在意图识别、安全意识与有用性之间的动态平衡。实验表明，当前模型在 Type A 中易忽略渐进式恶意（如 Qwen3-VL-32B SA 2.25），在 Type B 中易过度拒绝（如 Claude Opus 4.5 HS 2.75），且现有防御机制难以同时优化三者。该基准的边界在于其依赖大语言模型评判及日常场景覆盖，未涉及高敏感领域。当模型在 Type B 中表现出高安全意识时，其有用性下降是否源于对初始恶意意图的过度泛化，而非对后续轮次独立语义的误判，论文未给出回答。
