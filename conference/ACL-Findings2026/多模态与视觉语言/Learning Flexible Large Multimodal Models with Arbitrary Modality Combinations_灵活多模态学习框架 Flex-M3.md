# ACL-Findings2026最新论文 ｜Learning Flexible Large Multimodal Models with Arbitrary Modality Combinations ｜灵活多模态学习框架 Flex-M3

研究机构：美国北卡罗来纳大学教堂山分校

作者：Xinyu Zhao、Kangqi Ni、Jie Peng 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_89b0ecbb2070)

> 多模态大语言模型（MLLMs）在扩展至音频、3D等异构模态时，面临数据配对稀缺与Token序列线性膨胀的双重瓶颈。现有方法要么依赖全模态完整数据，要么通过静态填充处理缺失，导致泛化能力随模态数量增加而下降。Flex-M3 通过引入基于文本和视频锚点的缺失模态生成模块，结合两阶段压缩机制，实现了在任意模态组合下的鲁棒训练与推理。该框架在 NExT-QA 等基准上优于全模态基线，但其生成模块的泛化边界及计算开销的长期影响仍需进一步审视。

## 研究背景

MLLMs 的核心架构由模态编码器、投影层和语言模型骨干组成。当输入包含视频、深度、光流等多种模态时，每种模态被编码为数百个 Token，直接拼接导致输入序列长度随模态数量线性增长。这种膨胀不仅推高了自注意力计算的二次方复杂度，更在数据层面引发矛盾：真实场景中，不同模态的采集成本差异巨大，且常因传感器故障或隐私限制出现缺失。

传统 MLLM 训练假设所有指定模态在训练和推理时均存在，这一假设在生物医学或边缘部署等场景中难以成立。早期应对缺失模态的方法多采用启发式填充或数据级重建，但这些方法缺乏对跨模态依赖关系的显式建模，且在大规模语言模型中难以与 Token 推理机制兼容。与此同时，现有的高效 MLLM 研究（如 Token 剪枝、查询重采样）虽能降低计算成本，但均预设模态完整，未考虑生成式补全表示的噪声过滤问题。Flex-M3 的切入点在于将“缺失模态恢复”与“Token 压缩”视为耦合问题：生成模块负责从锚点模态合成缺失特征，压缩模块则负责滤除生成噪声并固化序列长度，从而打破“模态越多、Token 越长、性能越差”的恶性循环。

## 核心方法

### 标准 MLLM 架构与缺失模态挑战

标准 MLLM 流程为：模态编码器 $E_m$ 提取特征 $F_m$，投影层 $A$ 将其映射为 Token 序列 $H_m$，最后与文本嵌入 $H_t$ 拼接输入 LLM。该流程的关键差异在于，Flex-M3 在投影层前插入了缺失模态生成环节，且投影层被重构为“生成+压缩”双模块，以应对模态任意组合带来的序列长度不确定性。

### 基于锚点模态的缺失特征生成

针对模态缺失问题，Flex-M3 利用始终存在的文本和视频作为锚点，通过轻量级生成模块合成缺失模态的潜在表示。该设计解决了静态填充方法无法捕捉跨模态语义依赖的失效。生成过程由共享生成提示 $P$ 和模态特定 MLP 组成，公式如下：

$$ \hat{H}_{m'} = G_{m'}(\text{concat}(P, g_{t \to m'}(H_t), g_{v \to m'}(H_v))) $$

其中 $g_{t \to m'}$ 和 $g_{v \to m'}$ 为模态特定映射函数，$G_{m'}$ 为最终生成网络。该公式的物理含义是：通过共享提示提供模态无关的归纳偏置，通过特定 MLP 捕捉目标模态的独特模式，从而在低开销下实现模态无关的生成。训练时，对物理存在的模态随机施加“缺失”处理，并计算生成特征 $\hat{H}_m$ 与真实特征 $H_m$ 的均方误差重建损失 $L_{Rec}$，确保生成表示在潜在空间中忠实近似真实模态。

### 两阶段 Token 压缩机制

生成模块输出的 $\hat{H}_{m'}$ 可能包含噪声，且多模态拼接后序列过长。Flex-M3 引入两阶段压缩：首先，每个模态（含生成模态）通过 Per-modal Compressor 将长序列压缩为 $N_q$ 个查询 Token；其次，所有压缩后的模态 Token 通过 Cross-modal Compressor 融合为固定长度序列 $Z$：

$$ Z = f(\text{concat}(H^{(c)}_0, H^{(c)}_1, \dots, H^{(c)}_M)) $$

该公式表明，无论输入模态数量 $M$ 如何变化，LLM 接收的多模态上下文长度保持恒定。这一设计解决了直接拼接导致的计算成本线性增长问题，同时通过压缩过程滤除生成 Token 中的冗余噪声，提升了模型对缺失模态的鲁棒性。

## 实验评估

实验在 NExT-QA、MUSIC-AVQA 和 SQA3D 三个基准上进行，基线包括仅使用文本和视频的 Essential 模型、全模态但不完整数据训练的 Full w/ Inc. Data 模型，以及使用可学习 Token 填充缺失模态的 Padding 模型。Flex-M3 在 BLIP-2 和 LLaVA 骨干上均实现了性能提升，其中在 NExT-QA (V,F,D,N) 设置下，Flex-M3 平均得分 74.82，优于 Padding (74.22) 和 Full w/ Inc. Data (72.04)。

| 方法 | NExT-QA (V,F,D,N) Avg. | MUSIC-AVQA Avg. | SQA3D Avg. |
| :--- | :--- | :--- | :--- |
| Essential (V only) | 73.00 | - | - |
| Full w/ Inc. Data | 72.04 | - | - |
| Padding | 74.22 | - | - |
| Flex-M3 | 74.82 | 11.01% gain | 53.48% |

注：MUSIC-AVQA 和 SQA3D 数值为相对提升或绝对准确率，具体见原文。

消融实验显示，移除生成模块导致性能显著下降，验证了生成式补全优于静态填充。然而，当模态数量从 2 增加到 4 时，Full w/ Inc. Data 模型性能从 73.00 降至 72.04，而 Flex-M3 保持上升趋势，表明其压缩机制有效缓解了模态增加带来的负迁移。

评估边界方面，实验仅覆盖视频、3D 和音频模态，未涉及生物标志物等复杂模态。代码已开源，但生成模块的超参数（如 $\lambda=0.001$）在不同骨干上的敏感性未充分探讨。

## 关联研究分析

从问题动机看，Flex-M3 与 MoELoRA 等持续学习方法均旨在解决多任务/多模态下的参数冲突，但 Flex-M3 聚焦于数据缺失而非任务顺序，其生成模块通过显式合成缺失特征，避免了 MoE 路由在模态缺失时的失效。从方法设计看，Flex-M3 的两阶段压缩与 LLaVA-PruMerge 的 Token 剪枝不同，后者是静态剪枝，而 Flex-M3 是动态生成+压缩，能够处理生成 Token 的噪声，这源于其对“生成表示可能不忠实”的假设，而 PruMerge 假设原始 Token 是可靠的。

## 总结

Flex-M3 解决了 MLLM 在模态缺失场景下的鲁棒性与效率矛盾，通过生成模块合成缺失特征，通过两阶段压缩固化序列长度。在 NExT-QA 上，Flex-M3 比全模态基线高 2.29%，在 SQA3D 上高 3.15%。其边界在于生成模块依赖文本和视频锚点，当这些锚点质量低或模态间依赖复杂时，生成表示的保真度可能下降。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
