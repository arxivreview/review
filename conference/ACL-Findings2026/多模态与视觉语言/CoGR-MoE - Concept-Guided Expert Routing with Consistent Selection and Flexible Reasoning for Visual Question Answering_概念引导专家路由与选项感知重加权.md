> 视觉问答（VQA）中混合专家（MoE）架构面临路由稳定性与选项区分灵活性的内在矛盾：稳定路由导致专家固化，削弱细粒度判别；不稳定路由则引发同类问题专家选择漂移。现有方法多从嵌入空间或交互特征入手，未能解耦“选谁”与“怎么用”两个环节。CoGR-MoE 通过 LLM 生成正负语义线索，将正确答案的语义方向注入路由层以稳定 Top-K 专家选择，再利用各选项自身线索对共享专家输出进行动态重加权，生成选项特定表示。该方法在 MRAG-Bench 上取得 63.25% 准确率，较最强基线 MoME 提升 0.49%，但在 Others 子集上仍落后于交互驱动路由方法，其语义引导策略对复杂跨模态交互的覆盖能力存疑。

## 研究背景

当 VQA 模型处理同一问题的不同表述时，MoE 路由器常激活不同的专家组合，导致答案不一致。这种路由不稳定性源于输入表征的微小变化被放大至专家选择层面。为缓解此问题，MoME（Shen et al., 2024a）将专家划分为模态特定与共享组，MH-MoE（Huang et al., 2024）则通过多子表征路由聚合输出，二者均试图在表征层面增强路由一致性。然而，这些方法将路由稳定性与专家利用方式耦合：一旦 Top-K 专家集合固定，模型无法针对具体选项调整专家贡献，导致在需要区分细微视觉差异的对比推理任务中失效。

MoE 路由机制的演进可分为嵌入驱动、交互感知与语义引导三条路线。嵌入驱动方法（如 MoME、MH-MoE）依赖联合嵌入空间距离，但未区分模态交互与语义角色；交互感知方法（如 I²MoE, Xin et al., 2025）基于模态交互模式路由，在 Others 子集上表现优异，但难以处理语义相似但表述不同的输入；语义引导方法（如 MoKE, Cheng et al., 2025b）通过概念投影对齐专家选择，但过度稳定化反而固化了专家集，削弱了选项级区分能力。CoGR-MoE 的切入点在于解耦路由选择与专家利用：前者由正确答案的语义方向引导以保证稳定性，后者由选项特定线索驱动以恢复灵活性，从而在保持路由一致性的同时增强选项判别力。

## 核心方法

### 方法参照系

标准 MoE-VQA 流程为：图像-问题表征经路由器生成专家门控分布，Top-K 专家输出加权聚合后用于答案预测。本文的关键差异在于将 LLM 生成的语义线索同时注入路由层与专家聚合层，形成“概念引导路由 + 选项感知重加权”的双阶段机制，而非依赖单一表征驱动路由。

### 概念引导专家路由

传统路由器仅基于图像-问题表征计算门控 logits，导致语义相似输入的路由漂移。CoGR-MoE 引入正确答案 $a$ 的正负线索嵌入差值作为语义方向 $s_a$，将其以固定强度 $\lambda_a=0.5$ 注入基础 logits：

$$z_T = z_{base} + \lambda_a s_a$$

该公式的物理含义是：将正确答案的决策相关属性（如“大耳朵”）作为方向向量，拉偏专家选择概率分布，使同类问题更可能激活相同专家。同时，教师路由器 $T$ 的门控分布通过 KL 散度蒸馏至学生路由器 $S$，后者在推理时无需线索即可复现稳定路由，解决了线索生成依赖问题。

### 选项感知专家重加权

固定 Top-K 专家后，所有选项共享相同专家输出，导致区分度不足。CoGR-MoE 为每个选项 $j$ 计算其正负线索差值 $s_j$，并以此调制专家门控权重：

$$g_{i,j} = \text{softmax}(z_i^T + \lambda_o s_j)$$

其中 $\lambda_o=0.5$ 控制重加权强度。该机制允许同一专家集在不同选项下产生差异化贡献：例如“Cornish Cat”选项会放大“大耳朵”相关专家的权重，而“Sphynx”选项则抑制该专家。最终选项表示 $\tilde{h}_j = \sum_{i \in TopK} g_{i,j} h_i$ 通过对比损失 $L_{contrast}$ 优化，使正确选项表示靠近正线索、错误选项靠近负线索，强化选项级判别边界。

## 实验评估

实验在 VMCBench（统一 20 个 VQA 数据集为四选一）与 MRAG-Bench（视觉中心多场景基准）上进行，基线覆盖 MoME、I²MoE、CL-MoE 等 MoE 方法，但未包含非 MoE 的 SOTA 如 HAVC 或 FUMA，限制了跨架构可比性。在 MRAG-Bench 上，CoGR-MoE 在 MOE-LLaVA 骨干上取得 63.25% 整体准确率，高于 MoME 的 62.76% 与 MH-MoE 的 61.71%；在 Qwen3-VL-A3B-30B 骨干上达 68.96%，领先 MoME 的 66.78%。Perspective 与 Transformative 子集提升显著（69.09% vs 69.30% 与 58.55% vs 55.91%），但 Others 子集（58.67%）仍低于 I²MoE（60.83%）与 MoME（64.06%），表明语义引导路由对复杂跨模态交互的捕捉能力有限。

| 方法 | Overall | Perspective | Transformative | Others |
| :--- | :--- | :--- | :--- | :--- |
| MoME | 62.76 | 69.30 | 55.91 | 64.06 |
| I²MoE | 59.35 | 62.16 | 50.87 | 60.83 |
| CoGR-MoE | 63.25 | 69.09 | 58.55 | 58.67 |

消融实验显示，移除 $s_a$ 与 $L_{distill}$ 导致 VQAv2 准确率从 83.6% 降至 76.8% 与 63.2%，验证了概念引导路由的核心作用；移除 $s_j$ 使 GQA 从 81.1% 降至 76.8%，证实选项重加权对细粒度推理的贡献。反直觉发现是：移除不确定性加权 $unc_j$ 后，ScienceQA 准确率从 77.6% 升至 78.0%，表明在直接推理任务中，线索一致性过滤可能过度抑制有效信号。专家数量 $n=8$、激活数 $K=2$ 时取得最优平衡（74.5% 准确率，0.51 Sim），$K$ 增大后性能下降，反映专家冗余与区分度的权衡。

评估指标仅包含准确率与语义-专家对齐分数 Sim，未报告幻觉率、推理延迟或计算开销。代码已开源，但训练数据（IconQA、A-OKVQA、Visual7W 各 5000 题）与超参数（$\lambda_a, \lambda_o, \lambda_c$）细节未在正文完整披露，复现需依赖附录。

## 关联研究分析

从问题动机看，CoGR-MoE 与 MoKE（Cheng et al., 2025b）均针对路由不稳定性，但 MoKE 通过概念投影将相似知识分配至同一专家，本质是强化路由一致性；CoGR-MoE 则在稳定路由后引入选项级重加权，解决“稳定即固化”的副作用。这一差异源于任务特性：MoKE 面向知识编辑，强调概念一致性；CoGR-MoE 面向 VQA 选项判别，需在一致性基础上保留灵活性。I²MoE（Xin et al., 2025）采用交互驱动路由，在 Others 子集上优于 CoGR-MoE，表明当任务依赖细粒度跨模态交互而非整体语义方向时，语义引导策略可能失效。

从方法设计看，CoGR-MoE 的 LLM 线索生成与 HAVC（Xie et al., 2026, P21）的注意力引导裁剪均旨在增强细粒度感知，但 HAVC 在视觉特征层面操作，CoGR-MoE 在专家路由层面操作。HAVC 通过空间熵过滤裁剪图像区域，直接减少背景噪声；CoGR-MoE 通过语义线索调制专家权重，间接增强选项区分。前者依赖视觉编码器分辨率，后者依赖 LLM 线索质量。CoGR-MoE 未报告线索生成失败率或 LLM 幻觉对路由的影响，而 HAVC 的裁剪引导图可视觉化验证，可解释性更直接。

## 总结

CoGR-MoE 解决的核心矛盾是 MoE 路由稳定性与选项区分灵活性的冲突。现有方法将二者耦合于单一路由机制，导致稳定化牺牲判别力或灵活性引发路由漂移。CoGR-MoE 通过解耦“选专家”与“用专家”两个环节，前者由正确答案语义方向引导，后者由选项特定线索驱动，在 MRAG-Bench 上取得 63.25% 准确率，较 MoME 提升 0.49%。其边界在于：Others 子集性能落后于 I²MoE，暴露语义引导路由对复杂跨模态交互的覆盖不足；ScienceQA 上移除不确定性加权反而提升性能，暗示线索过滤机制在直接推理任务中可能过度干预。当任务从语义对齐转向细粒度交互建模时，概念引导路由的增益是否持续，论文未给出回答。
