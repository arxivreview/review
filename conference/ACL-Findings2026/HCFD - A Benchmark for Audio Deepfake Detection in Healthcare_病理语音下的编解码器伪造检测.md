# ACL-Findings2026最新论文 ｜HCFD: A Benchmark for Audio Deepfake Detection in Healthcare ｜病理语音下的编解码器伪造检测

作者：Mohd Mujtaba Akhtar、Girish、Muskaan Singh

论文原文见 [arXiv](https://arxiv.org/abs/2604.17642)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.17642)

> 医疗场景中的语音既是临床信号也是身份凭证，但现有音频深伪检测器在健康语音上训练，面对病理语音时性能骤降。本文指出病理变异会掩盖编解码器伪迹，导致传统模型失效，并构建首个病理感知基准 HCFK。通过引入超球面几何原型聚类与 Mamba 时序建模，PHOENIX-Mamba 实现了跨临床条件的鲁棒检测。该方法在特定域内有效，但缺乏与通用深伪 SOTA 的直接对比，其泛化边界尚待验证。

## 研究背景

当检测器面对病理语音时，其训练域（健康语音）与测试域（疾病语音）的数据分布出现系统性差异——这一现象称为分布偏移。分布偏移导致传统分类器决策边界失效，而实际场景中往往能获取少量目标域样本，这恰好构成了小样本学习的条件：仅凭每个类别极少量标注样本泛化到新任务。解决此类问题的经典框架是原型网络，它计算各类别支持样本的特征均值作为"原型"，再通过距离度量完成分类。

音频深伪检测（ADD）的主流路线已从手工特征转向自监督学习（SSL）骨干，如 Wav2Vec 2.0 和 XLS-R，旨在通过大规模无标签数据预训练获得通用声学表征。然而，现有基准如 ASVspoof 2019 和 In-the-Wild 均基于健康、干净的语音构建，未涵盖病理驱动的声学变异。病理语音系统性地改变韵律、发音和发声方式，可能扭曲或掩盖编解码器引入的细微伪迹，使得在健康语音上训练的检测器在临床场景中失效。本文的切入点在于：现有 Codec-fake 检测器未针对病理语音设计，需要构建病理感知基准并开发能分离疾病特征与伪造线索的专用框架。

## 核心方法

### 方法参照系

本文问题属于 SSL 骨干下的端到端检测，但关键差异在于输入数据的病理异质性。标准流程通常使用全局池化将序列压缩为单一向量，再经线性分类器判别真伪。本文问题要求模型在病理变异下保持对编解码伪迹的敏感度，单一全局向量无法捕捉局部、非均匀的伪迹分布，因此需引入多证据建模与几何约束。

### 多证据向量池化

传统方法将整句音频压缩为单一嵌入，忽略了编解码伪迹在时间轴上的局部性和不均匀分布。PHOENIX-Mamba 引入可学习池化算子，将 Mamba 骨干输出的时序特征 $Z \in \mathbb{R}^{T \times d}$ 压缩为 $M$ 个证据向量 $E = [e_1, \dots, e_M] \in \mathbb{R}^{M \times d}$：

$$ e_m = \sum_{t=1}^{T} a_{m,t} z_t, \quad \text{where } a_{m,t} \ge 0, \sum_{t=1}^{T} a_{m,t} = 1 $$

该公式通过可微分打分机制 $a_{m,t}$ 自适应加权时序特征，保留多个局部线索。这一设计解决了单一全局向量在病理语音中因伪迹稀疏而失效的问题，使模型能捕捉间歇性出现的编解码痕迹。

### 超球面原型聚类

证据向量在欧氏空间中难以区分异构的编解码伪迹模式，因为不同编解码器引入的伪迹在特征空间中分布不均。PHOENIX-Mamba 将证据向量映射到 Poincaré 球 $\mathcal{M} = \{v \in \mathbb{R}^h : c\|v\|_2 < 1\}$，曲率为 $-c$，并使用指数映射：

$$ h_m = \text{Exp}_0^c(w_m) = \frac{\tanh(\sqrt{c}\|w_m\|)}{\sqrt{c}\|w_m\|} w_m $$

在超球面内，模型参数化一个负原型 $p^-$ 和 $K$ 个正原型 $\{p^+_1, \dots, p^+_K\}$，通过温度控制的距离 softmax 计算软责任。这一几何约束使正原型自组织成多个簇，捕捉异构编解码伪迹，解决了欧氏空间中原型坍缩和模式混淆的问题，提升了跨编解码器家族的泛化能力。

## 实验评估

实验在自建 HCFK 数据集上进行，涵盖抑郁、阿尔茨海默病和构音障碍三种临床条件，中英双语，使用 7 种神经音频编解码器。基线覆盖 AASIST、RawNet2、LCNN、SAMO 及 WavLM、Wav2Vec 2.0、Whisper、X-vector、PaSST 等预训练模型。PHOENIX-Mamba 使用 PaSST 作为最强骨干，在英语抑郁任务上达到 97.04% Acc 和 96.81% F1，显著优于 AASIST（48.62% Acc）和 RawNet2（60.46% Acc）。

| 方法 | Dep (Acc/F1) | Alz (Acc/F1) | Dys (Acc/F1) |
| :--- | :--- | :--- | :--- |
| AASIST (Tr. on CF) | 48.62 / 44.03 | 34.19 / 32.51 | 36.71 / 34.39 |
| RawNet2 | 60.46 / 50.27 | 58.96 / 53.87 | 57.24 / 54.68 |
| PHOENIX-Mamba (PaSST) | 97.04 / 96.81 | 96.73 / 95.20 | 96.57 / 94.28 |

消融实验显示，多证据池化（$M>1$）比单证据（$M=1$）提升显著，例如在英语抑郁任务上，单证据 Acc 为 73.51%，而完整模型为 97.04%。Mamba 时序建模比 BiGRU 头提升约 9% Acc，表明长上下文依赖对病理语音检测至关重要。超球面几何（PHOENIX-Mamba）比欧氏几何（PHOENIX-Euc）提升约 13% Acc，验证了几何约束对异构伪迹建模的有效性。

评估协议采用说话人不相交的训练/测试划分，指标包括 Acc、macro-F1 和 EER。代码和超参数已公开，但论文未报告置信区间，且缺乏与通用 ADD SOTA（如 WaveSP-Net、SONAR）在相同病理数据上的直接对比，限制了跨域泛化能力的全面评估。

## 关联研究分析

从问题动机看，本文与通用 ADD 的核心差异在于输入数据的病理异质性。通用 ADD 关注健康语音下的 TTS/VC 深伪，而本文聚焦病理语音下的编解码器伪造。这一差异源于临床场景的特殊性：病理变异掩盖伪迹，迫使模型分离疾病特征与伪造线索。通用方法如 AASIST 在 HCFK 上表现不佳（48.62% Acc），凸显了任务特性对方法设计的约束，而非单纯的数据规模问题。

从方法设计看，PHOENIX-Mamba 与原型网络（Snell et al., 2017）共享度量学习范式，但引入了超球面几何和多证据池化。原型网络在欧氏空间中计算原型，而本文在 Poincaré 球中建模异构伪迹模式。这一改进源于编解码伪迹的分布不均性，欧氏空间难以捕捉这种结构。与 WaveSP-Net 等高效微调方法相比，PHOENIX-Mamba 未采用小波域稀疏提示，而是依赖几何约束和时序建模，这可能牺牲了计算效率，但提升了病理语音下的鲁棒性。

## 总结

本文要解决的核心矛盾是病理语音变异掩盖编解码伪迹，导致现有检测器失效。本文抓住的切入点是构建病理感知基准 HCFK，并开发能分离疾病特征与伪造线索的专用框架。PHOENIX-Mamba 通过多证据池化和超球面原型聚类，在 HCFK 上实现了 97.04% Acc（英语抑郁）和 96.73% Acc（英语阿尔茨海默病）的性能。本文的边界在于缺乏与通用 ADD SOTA 在相同病理数据上的直接对比，且未评估计算效率。当支持集增大到 5-shot 时，超球面几何的边际收益是否递减，论文未给出回答。
