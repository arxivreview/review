# ACL-Findings2026最新论文 ｜No One Fits All: From Fixed Prompting to Learned Routing in Multilingual LLMs ｜多语言提示策略的自适应路由

研究机构：国立台湾大学、新加坡南洋理工大学

作者：Wei-Chi Wu、Sheng-Lun Wei、Hen-Hsen Huang 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.16937)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f9c48911b33b)

> 导读 多语言大语言模型（Multilingual Large Language Models, mLLMs）在处理低资源语言时，常因预训练数据中英语的主导地位而依赖“翻译至英语再推理”的提示策略，但该策略在高资源语言或文化敏感任务中往往失效。现有研究多聚焦于优化单一提示范式，缺乏对“何时翻译、何时原生”这一决策问题的系统性建模。本文提出基于轻量级分类器的提示策略路由框架，通过响应特征差异预测最优提示方式，在四个基准上实现统计显著的性能提升。该框架验证了语言资源等级而非翻译质量是决定策略有效性的核心变量，但其仅优化输入端策略，未触及模型内部表征对齐的根本缺陷。

## 研究背景

当多语言模型面对低资源语言输入时，其内部表征往往缺乏独立的语义空间，导致事实知识召回不一致。这一现象源于预训练数据分布的极度不均，使得模型在中间层形成以英语为主导的“英语中心潜在空间”（English-Centric Latent Space）。为缓解此问题，翻译提示（Translation-based Prompting）成为主流策略，即先将输入翻译为英语再进行推理，以利用模型更强的英语能力。然而，该策略并非普适：在高资源语言中，翻译可能引入语义漂移；在文化敏感任务中，原生语言提示更能保留语境特异性。

现有方法如 QAlign 和 mCoT 致力于增强翻译提示的质量，Strategic CoT 则优化原生语言推理，但均隐含“固定策略”假设，未将策略选择视为条件化决策问题。Prompt Routing 虽提出动态路由概念，但依赖模型自评估，缺乏对响应级差异的量化能力。本文切入点在于：将提示策略选择形式化为二分类决策问题，通过外部分类器基于响应特征进行路由，而非依赖模型内部自判。

## 核心方法

### 方法参照系

本文问题属于“推理时轻量级干预”范畴，与内部机制干预（如注意力头掩码）不同，其不修改模型参数，仅优化输入端提示策略。关键差异在于：传统方法假设单一策略最优，本文则建模策略选择为条件化决策，依赖响应特征而非语言元数据。

### 策略选择形式化

针对“何时翻译”的决策问题，本文将其建模为二分类任务。给定问题 $q$ 及语言 $\ell$，生成原生响应 $r_n$ 和翻译响应 $r_t$，训练分类器 $f(q, r_n, r_t) \rightarrow \{0, 1\}$，其中 0 选择原生，1 选择翻译。设计动机在于：模型自评估无法量化响应级语义差异，而外部分类器可捕捉翻译诱导的语义漂移。

$$
f(q, r_n, r_t) = \sigma\left(\mathbf{w}^\top \phi(q, r_n, r_t) + b\right)
$$

该公式表示分类器通过特征向量 $\phi$ 的线性组合输出策略选择概率，$\sigma$ 为 Sigmoid 函数。特征 $\phi$ 包含词重叠、元数据、响应质量及对齐维度，其中词重叠特征（Word Overlap）在重要性排序中居首，表明语义对齐差异是决策核心。

### 特征工程与分类器训练

特征提取涵盖四类：元数据（语言标识、主题）、问题级（标点、数字计数）、响应级（稀有词比例、语法流畅度）及对齐（词重叠、嵌入相似度）。训练标签仅在单一策略正确时分配，歧义样本被丢弃。XGBoost 分类器在 10% 训练集上优化，超参数包括树深度（3–12）、学习率（0.01–0.3）等。设计动机在于：轻量级分类器避免全模型微调的高成本，且特征工程可捕捉模型自评估无法访问的响应级差异。

$$
\mathcal{L} = \sum_{i=1}^{N} \left[ y_i \log f(x_i) + (1-y_i) \log (1-f(x_i)) \right]
$$

该公式为二元交叉熵损失，$y_i$ 为真实标签，$f(x_i)$ 为预测概率。损失函数驱动分类器学习策略选择与正确性的映射关系，确保在低资源语言中优先选择翻译，在高资源语言中倾向原生。

## 实验评估

实验在 GlobalMMLU、MMLU-ProX、XQuAD、mCSQA 和 XCOPA 上进行，使用 DeepSeek-v3.1 和 Llama-3.3-70B-Instruct 进行零样本推理。基线覆盖 NATIVE、TRANSLATE、SEL-TRANS、SCOT-NATIVE、SCOT-TRANS 及 PROMPT-ROUTING，但未包含内部机制干预方法（如 Transfer Neurons），导致无法直接对比输入端路由与内部表征优化的性能差异。

XGBoost 分类器在 GlobalMMLU 上以 82.3% 准确率超越 TRANSLATE（81.7%）和 NATIVE（72.5%），在 MMLU-ProX 上以 77.9% 超越 TRANSLATE（77.7%）。低资源语言（SI/SW/YO）中翻译策略增益显著（+5.5 至 +18.8%），而高资源语言增益不足 1%。PROMPT-ROUTING（82.8%）低于 TRANSLATE（84.0%），证实模型自评估无法有效量化响应级差异。

消融分析显示，词重叠特征在 XGBoost 中重要性占比 34.38%（DeepSeek-v3.1）和 56.91%（Llama-3.3-70B），远超元数据（24.52%）和响应质量（12.62%）。翻译质量与策略选择呈负相关：低质量翻译区间（底部 30%）中，分类器翻译选择率最高（77.5%–80.0%），表明分类器学习在原生性能最弱时利用翻译，而非依赖翻译质量本身。

评估边界方面，论文未报告置信区间，数值比较需谨慎。代码未公开，但超参数（如 XGBoost 树深度 3–12、学习率 0.01–0.3）已详细列出，可复现性中等。指标仅使用准确率，未涵盖 F1 或 BLEU，对生成任务评估不足。

## 关联研究分析

从问题动机看，本文与 Inference-Time Steering 同属推理时干预，但前者修改输入端提示策略，后者修改内部激活状态。Inference-Time Steering 通过 PCA 分析识别高重叠层并应用英语引导，无需重新训练即可纠正事实偏差，而本文仅优化提示方式，未触及模型内部表征。这一差异源于任务特性：Inference-Time Steering 针对事实知识跨语言不一致，需内部机制干预；本文针对提示策略选择，外部路由即可解决。但本文未验证路由是否掩盖了内部表征缺陷，即模型在低资源语言中是否仍依赖英语中心空间进行推理。

从方法设计看，本文与 Prompt Routing（P50）直接对比，后者依赖模型自评估选择策略，前者使用外部分类器基于响应特征决策。Prompt Routing 的局限在于模型无法量化响应级语义差异，而本文的词重叠特征捕捉了翻译诱导的语义漂移。这一差异源于方法设计：模型自评估缺乏对响应内容的细粒度分析能力，而外部分类器可访问完整响应文本。但本文未探索将响应特征与内部机制干预结合的可能性，即路由决策是否可进一步通过内部激活引导优化。

## 总结

本文核心矛盾在于多语言模型中提示策略的普适性假设失效，现有方法缺乏对“何时翻译”的条件化决策建模。本文抓住的切入点是：策略选择可基于响应特征差异进行外部路由，而非依赖模型自评估或固定范式。通过轻量级 XGBoost 分类器，本文在 GlobalMMLU 上实现 82.3% 准确率，超越 TRANSLATE 基线 0.6 个百分点，并验证了语言资源等级是决定策略有效性的核心变量。本文边界在于：仅优化输入端策略，未触及模型内部表征对齐的根本缺陷，且评估未涵盖生成任务指标。当低资源语言在中间层仍依赖英语中心空间进行推理时，外部路由是否仅利用了模型已有的英语能力，而未解决根本表征问题，论文未给出回答。
