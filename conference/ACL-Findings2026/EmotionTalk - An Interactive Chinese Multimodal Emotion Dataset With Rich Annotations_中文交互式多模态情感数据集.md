# ACL-Findings2026最新论文 ｜EmotionTalk: An Interactive Chinese Multimodal Emotion Dataset With Rich Annotations ｜中文交互式多模态情感数据集

研究机构：南开大学、美国卡内基梅隆大学

作者：Haoqin Sun、Jinghua Zhao、Xuechen Wang 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_d5a730f35333)

> 多模态情感识别（MER）长期受限于高质量自发对话数据的稀缺，尤其是中文场景下缺乏兼顾生态效度与标注精度的基准。现有中文数据集多依赖影视片段或脚本朗读，无法捕捉真实交互中的情感动态与模态冲突。本文通过19名专业演员的主题驱动即兴表演，构建了包含23.6小时数据、19,250句对话的EmotionTalk数据集，并引入细粒度情感说话风格描述。该基准填补了中文自发对话数据的空白，但其规模与演员多样性是否足以支撑大规模预训练与跨域泛化，仍存疑。

## 研究背景

情感表达并非单一模态信号的线性叠加，而是视觉表情、语音语调与文本语义在时间轴上的复杂耦合。当模型仅依赖单一模态时，往往因信息缺失或模态间语义冲突（如文本中性但语音愤怒）导致识别失效。这种跨模态的语义不对齐与异构性，构成了多模态融合的核心难点，要求数据资源不仅提供完整的模态覆盖，还需具备反映真实人类情感复杂性的标注体系。

现有中文多模态情感数据集存在显著的质量与结构缺陷。CH-SIMS与MER-MULTI等数据集虽提供了离散或连续标签，但缺乏对话场景，无法捕捉多轮交互中的情感演变；M3ED与MC-EIUch虽引入了对话结构，但数据多源自影视资源，情感表达受脚本限制，缺乏自发交互的自然性。此外，情感描述（Emotion Captioning）研究多依赖未公开数据集，缺乏标准化基准，阻碍了可解释性研究的复现与比较。EmotionTalk的切入点在于打破“规模优先”的传统数据构建逻辑，通过高成本的主题驱动即兴表演，获取高生态效度的自发对话数据，并引入LLM辅助的细粒度风格描述，以解决现有数据在真实性与标注深度上的双重不足。

## 核心方法

### 数据构建参照系

多模态情感数据集构建通常遵循“采集-标注-统计”流程，核心在于平衡数据规模、模态完整性与标注一致性。传统方法多采用脚本朗读或影视抓取，以低成本换取大规模数据，但牺牲了情感表达的自发性。EmotionTalk的关键差异在于采用专业演员即兴表演替代脚本朗读，并引入模态独立标注原则，以隔离模态干扰，确保单模态标签的纯净性。

### 主题驱动即兴表演与模态独立标注

设计动机在于解决脚本朗读导致的“读语音”伪影（read-speech artifacts）及多模态同步标注引发的模态干扰问题。传统脚本化数据中，演员情感表达往往过于戏剧化且缺乏自然交互的动态演变，而多模态同步标注易导致标注者受其他模态影响，产生系统性偏差。EmotionTalk采用主题驱动即兴表演，由19名专业演员基于友谊、家庭、职场等主题进行双人对话，每段对话限制在约两分钟，以捕捉情感的自然流动与冲突。在标注环节，严格执行模态独立原则，标注者仅查看当前模态（文本、音频、无声视频、有声视频），禁止多模态同步标注。对于情感类别标注，采用5名标注者交叉验证，并引入置信度加权机制。最终情感类别 $y$ 通过最大化加权置信度得分 $x_k$ 确定：

$$ y = \arg \max_{k} x_k, \quad x_k = \sum_{i=1}^{N} I(y_i = k) \cdot c_i $$

其中 $I(y_i = k)$ 为指示函数，$c_i$ 为标注者 $i$ 的置信度（取值0.1至0.9）。该公式通过加权平均消除了低置信度标注的噪声，显著提升了标注的鲁棒性。

### LLM辅助情感说话风格描述生成

设计动机在于解决传统离散标签无法捕捉细粒度情感语义及可解释性不足的问题。现有数据集缺乏对情感表达风格（如节奏、音调、情感色彩）的文本描述，限制了模型在可解释情感分析任务中的应用。EmotionTalk构建了四维细粒度描述系统，涵盖说话人、说话风格、情感及整体描述。为严格抑制大语言模型（LLM）幻觉，采用两阶段验证协议：首先由人类专家标注离散属性（如“风格：快节奏”、“音调：高”），随后限制DeepSeek-R1仅执行受控改写，将结构化属性转化为自然语言句子，禁止推断新信息。最后通过10%的人工抽检进行事实核查，确保描述未引入幻觉形容词。该协议实现了98.5%的一致性，验证了LLM生成描述与人类感知的高度对齐，为可解释情感分析提供了高质量语料。

## 实验评估

实验基于MerBench框架，在EmotionTalk上评估单模态/多模态情感识别及情感描述任务。基线覆盖WavLM、HuBERT、RoBERTa等主流自监督预训练骨干，但缺失TFN、MulT等经典融合架构的完整对比（仅提及MulT在四分类任务F1达83.22%）。在“Multimodal(Four)”任务中，MulT表现最优，而在“Multimodal(All)”任务中，所有模型性能平均下降约12%，表明中文情感表达的复杂性对现有SOTA模型构成挑战。LMF在整体平均指标上表现最佳（71.23% ACC / 76.59% F1），显示低秩张量分解在复杂类别分布下的鲁棒性。

| 模型 | Speech(Four) ACC/F1 | Multimodal(Four) ACC/F1 | Multimodal(All) ACC/F1 | Mean ACC/F1 |
| :--- | :--- | :--- | :--- | :--- |
| Hubert-Large | 82.42 / 82.28 | 70.29 / 70.81 | 60.95 / 60.28 | 71.08 / 70.67 |
| Whisper-Large | 76.03 / 75.62 | 66.62 / 66.52 | 52.62 / 51.00 | 64.99 / 64.07 |
| RoBERTa-Large | 61.49 / 60.28 | 52.68 / 53.05 | 42.82 / 41.83 | 51.06 / 49.84 |
| BLOOM-7B | 62.00 / 60.87 | 52.62 / 52.98 | 46.96 / 46.01 | 53.01 / 52.18 |

数据表明，音频模态模型（如Hubert-Large）在单模态任务中显著优于文本模态模型，但在多模态融合任务中，性能差距缩小且整体下降。这一发现印证了EmotionTalk中跨模态标签分歧的统计结果：仅24.5%样本跨模态标签一致，多模态融合并非简单叠加，而是需要处理复杂的模态冲突。

评估边界方面，EmotionTalk的Fleiss' Kappa值为0.78，显著高于M3ED（0.59）和IEMOCAP（0.48），表明标注质量较高。然而，数据集仅包含19名演员和23.6小时数据，规模远小于CMU-MOSEI（22,856句）或M3ED（24,449句），可能限制模型的泛化能力。此外，论文未提供代码与超参数细节，可复现性依赖MerBench框架，但具体实现细节未完全披露。

## 关联研究分析

从数据构建逻辑看，EmotionTalk与IEMOCAP、MELD等主流基准存在根本差异。IEMOCAP和MELD依赖脚本化对话或影视片段，追求数据规模与多样性，但情感表达受限于表演或剧情，缺乏自发交互的自然性。EmotionTalk采用即兴表演，虽成本高昂且规模较小，但捕捉了真实情感交互中的动态演变与模态冲突。这一差异源于任务目标的不同：IEMOCAP侧重模型在大规模数据上的训练与评估，而EmotionTalk侧重数据的高生态效度与标注深度，旨在为可解释情感分析提供高质量语料。

从标注协议看，EmotionTalk的模态独立标注原则与MISA等解耦表示学习框架的思想一致，但应用于数据层面而非模型层面。MISA通过解耦模态不变与模态特定特征缓解异构性，而EmotionTalk通过隔离模态干扰确保单模态标签的纯净性，为后续解耦学习提供了更干净的数据基础。然而，模态独立标注可能丢失模态间协同产生的情感线索，如文本与语音共同构成的讽刺语气。这种设计选择是否影响多模态融合模型的性能上限，论文未给出回答。

## 总结

EmotionTalk旨在解决中文多模态情感识别中高质量自发对话数据稀缺的问题，通过主题驱动即兴表演与LLM辅助标注，构建了兼具生态效度与标注深度的基准。其核心贡献在于填补了中文自发对话数据的空白，并引入细粒度情感描述，支持可解释情感分析。实验表明，现有模型在EmotionTalk上性能显著下降，凸显了中文情感表达的复杂性。然而，数据集规模有限（19名演员，23.6小时），且模态独立标注可能丢失模态协同线索，限制了其在大规模预训练与复杂模态交互建模中的适用性。当支持集增大到更大规模时，即兴表演数据的高成本是否仍具优势，论文未给出回答。
