# ACL-Findings2026最新论文 ｜WaveDetect: Robust Framework for Machine-Generated Text Detection via Wavelet Transform ｜基于连续小波变换的机器生成文本检测

研究机构：南方科技大学

作者：Zhichen Liu、Kaitong Qin、Linhan He 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_695a37543776)

> 机器生成文本检测旨在区分人类写作与大语言模型（LLM）生成内容，核心挑战在于生成模型能力指数级提升导致人机文本分布边界日益模糊。现有零样本统计方法依赖困惑度等静态特征，在对抗攻击与模型演化下脆弱；监督方法虽精度高但跨域泛化差。WAVEDETECT 将 token 概率序列视为信号，通过连续小波变换（CWT）提取时频域“频谱指纹”，以 CNN 分类器实现鲁棒检测。该方法在 RAID 基准上取得 0.9785 平均 AUROC，显著优于基线，但其对语义不变攻击的鲁棒性边界尚待更严苛协议验证。

## 研究背景

当检测器面对新生成模型时，其训练域与测试域的数据分布出现系统性差异——这一现象称为分布偏移。分布偏移导致传统分类器决策边界失效，而实际场景中往往能获取少量目标域样本，这恰好构成了小样本学习的条件：仅凭每个类别极少量标注样本泛化到新任务。解决此类问题的经典框架是原型网络，它计算各类别支持样本的特征均值作为"原型"，再通过距离度量完成分类。

机器生成文本检测的兴起源于大语言模型生成能力的指数级提升，机器文本在流畅度与连贯性上已难以与人类写作区分，引发了学术诚信、虚假信息传播及内容真实性的严重关切。早期研究依赖困惑度与似然比等零样本统计特征，思路简洁却受制于代理模型偏差与改写攻击下的脆弱性。随着 GPT-3.5 等模型普及，简单统计特征失效，研究范式转向基于预训练编码器的监督学习，用分布内高精度换取跨域泛化能力的妥协。2024 年对抗鲁棒性评估的兴起迫使领域正视表面特征过拟合问题，细粒度定位与公平性约束随之成为新焦点。各路线在模型无关性、检测精度、部署成本及社会公平之间做出了不同取舍，由此形成当前被动检测、主动水印与多维评估并存的多元格局。

本文切入点在于：现有方法过度依赖时域语义特征，而机器文本在概率分布上存在独特的“节奏”模式。WAVEDETECT 假设人机文本在语义上可能不可区分，但在概率信号的时频特性上存在显著差异，这种差异对语义改写和领域偏移具有不变性。

## 核心方法

### 方法参照系

零样本统计检测路线起源于对模型无关性的追求，其核心假设是机器文本在参考语言模型的统计属性（如困惑度、似然、惊讶值）上存在可捕捉的分布异常。GLTR 通过 token 排名可视化开创了这一范式，DetectGPT 提出基于概率曲率的方法。本文问题与该通用流程的关键差异在于：不直接计算静态统计量，而是将概率序列视为非平稳信号，通过时频分析提取动态特征。

### 信号提取与频谱假设

设计动机：解决时域特征在语义改写下的脆弱性。本文定义映射 $\Phi: V^N \to \mathbb{R}^N$，利用代理语言模型 $M_\theta$ 将离散 token 转换为连续概率信号 $p$：

$$
p_t = \Phi(x_t) = P_{M_\theta}(x_t | x_{<t}), \quad t = 1, \dots, N
$$

该公式的物理含义是：将文本序列转化为一个随时间变化的概率轨迹。人类写作具有高熵选择过程，引入不规则“尖峰”和混沌瞬态波动；机器生成受 top-k、top-p 等解码策略约束，机械截断低概率尾部，使信号平滑化并呈现周期性节奏。检测机器文本等价于捕捉这些局部节奏与瞬态差异。

### 连续小波变换与频谱特征提取

设计动机：克服傅里叶变换丢失时间定位信息的局限。本文选用 Morlet 小波作为母小波 $\psi(t)$，其高斯包络提供时间与频率分辨率的最优平衡：

$$
\psi(t) = \pi^{-1/4} e^{i\omega_0 t} e^{-t^2/2}
$$

连续小波变换（CWT）定义为信号与缩放平移小波的卷积：

$$
W(s, \tau) = \frac{1}{\sqrt{s}} \int_{-\infty}^{\infty} p(t) \psi^*\left(\frac{t - \tau}{s}\right) dt
$$

该公式的物理含义是：在不同尺度 $s$ 和时间位置 $\tau$ 上分析信号的局部频率成分。幅度 $|W| \in \mathbb{R}^{K \times N}$ 构成频谱图，作为文本生成过程的“视觉指纹”。频谱图输入轻量级 CNN，输出分类概率 $\hat{y} = \sigma(\text{CNN}(|W|))$。两阶段训练协议：Warm-up 阶段冻结 $M_\theta$，训练 CNN 对齐频谱特征；Joint Training 阶段解冻 $M_\theta$，联合优化以深化概率分布差异。加权交叉熵损失处理类别不平衡：

$$
L = -\frac{1}{B} \sum_{i=1}^{B} [\alpha y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i)]
$$

其中 $\alpha$ 平衡正负样本贡献。

## 实验评估

实验在 RAID（对抗鲁棒性）、EvoBench（模型演化）、Domain Shift（跨域泛化）三个基准上进行。基线覆盖监督（RoBERTa, RADAR）、零样本（Binoculars, Fast-DetectGPT, FourierGPT, RepreGuard）路线，但缺失最新水印方法（如 STELA）及细粒度定位方法（如 GigaCheck）。

| 方法 | RAID 平均 AUROC | TPR@0.1%FPR |
| :--- | :--- | :--- |
| WAVEDETECT-ALL | 0.9785 | 0.5470 |
| Binoculars | 0.8414 | 0.3584 |
| RADAR | 0.8277 | 0.0092 |
| RoBERTa | 0.6018 | 0.0450 |

WAVEDETECT-ALL 在 RAID 测试集上取得 0.9785 平均 AUROC，显著超越最强零样本基线 Binoculars（0.8414）和监督基线 RADAR（0.8277）。在严格阈值下，WAVEDETECT-ALL 达到 54.70% TPR@0.1%FPR，比 Binoculars 高近 19 个百分点，凸显其在高利害场景（如学术诚信）中的部署潜力。

| 方法 | GPT-4o AUC-m | GPT-4o Std | GPT-4o max|∆| |
| :--- | :--- | :--- | :--- |
| WAVEDETECT-BASE | 0.8536 | 0.0048 | 0.0087 |
| Binoculars | 0.8364 | 0.0118 | 0.0323 |
| RADAR | 0.7851 | 0.0153 | 0.0292 |

EvoBench 实验显示，WAVEDETECT-BASE 在 GPT-4o 版本演化中表现出最优时间稳定性，AUC-m 0.8536，标准差 0.0048，最大性能变化 0.0087，显著优于 Binoculars（0.8364, 0.0118, 0.0323）和 RADAR（0.7851, 0.0153, 0.0292）。这验证了频谱特征对模型演化的不变性。Domain Shift 实验中，WAVEDETECT-ALL 在医疗和法律领域取得 0.9560 平均 AUROC，而 RoBERTa 和 RADAR 降至随机水平（~0.42），证明频谱特征“主题无关”。

评估边界：指标完备性不足，未报告置信区间；评估协议局限，RAID 测试集采用 prompt-level split，与标准协议可能存在差异；可复现性方面，代码已开源（https://github.com/KaitongQin/WaveDetect），使用 Qwen2.5-0.5B-Base 作为代理模型，4× NVIDIA RTX 6000 Ada GPUs 训练，超参数明确（batch size 64, epochs 3, lr 1e-3/1e-5）。

## 关联研究分析

从问题动机看，WAVEDETECT 与 Binoculars 同属零样本统计检测，但 Binoculars 依赖两个模型困惑度比值，本质是静态统计量；WAVEDETECT 则通过 CWT 提取动态时频特征。差异根源在于：Binoculars 假设机器文本在概率分布上存在全局异常，而 WAVEDETECT 假设异常体现在局部节奏模式。当面对语义不变攻击时，Binoculars 的困惑度比值可能因改写而漂移，而 WAVEDETECT 的频谱指纹因解码策略约束而保持稳定。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

从方法设计看，WAVEDETECT 与 FourierGPT 同属频谱分析路线，但 FourierGPT 使用傅里叶变换，丢失时间定位信息；WAVEDETECT 使用 CWT，保留时频局部化特性。差异根源在于：傅里叶变换适用于平稳信号，而文本概率信号是非平稳的，统计特性随上下文变化。CWT 的多尺度分析能力使其能捕捉不同时间尺度的节奏模式，这是 FourierGPT 无法做到的。WAVEDETECT 与 RADAR 同属鲁棒性研究，但 RADAR 采用对抗训练，WAVEDETECT 采用被动特征提取。差异根源在于：RADAR 假设攻击者已知检测器结构，WAVEDETECT 假设攻击者仅能修改文本表面。当攻击者针对频谱特征设计攻击时，WAVEDETECT 的鲁棒性是否仍保持，论文未给出回答。

## 总结

WAVEDETECT 要解决的核心矛盾是：现有检测器在对抗攻击、模型演化和跨域泛化下的脆弱性。本文抓住的切入点是：机器文本在概率分布上存在独特的“节奏”模式，这种模式对语义改写和领域偏移具有不变性。本文通过 CWT 将 token 概率序列转换为时频谱图，以 CNN 分类器提取频谱指纹，实现鲁棒检测。实验证明，WAVEDETECT-ALL 在 RAID 基准上取得 0.9785 平均 AUROC，在 EvoBench 上展现最优时间稳定性（Std 0.0048）。本文的边界在于：未验证对语义不变攻击的鲁棒性，CAM 可视化显示原始频谱无清晰分离，依赖 CNN 学习相对结构。当攻击者针对频谱特征设计攻击时，WAVEDETECT 的鲁棒性是否仍保持，论文未给出回答。
