研究机构：中国科学院、中国科学院大学

作者：Miao Su、Yucan Guo、Zhongni Hou 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.07468)

> 长期对话智能体面临的核心困境是记忆的时间维度建模失效：现有系统普遍将“对话发生时间”等同于“事件发生时间”，且将连续经历切割为孤立点状记录，导致跨会话推理与时间敏感查询的召回严重失准。Temporal Semantic Memory (TSM) 通过构建语义时间线（Semantic Timeline）与持续记忆（Durative Memory）双轨架构，解耦了对话时间与事件时间，并将离散事实聚合为具有时间跨度的状态摘要。该方法在 LongMemEval 上实现了 74.80% 的整体准确率，但在 LoCoMo 基准上落后于结构化语义图方案，表明其优势局限于时间维度而非通用检索能力。

## 研究背景

当用户提及“下周三的会议”或“去年去东京的旅行”时，对话发生的时间（如今天）与事件实际发生的时间（未来或过去）存在显著错位。这种错位导致基于对话时间戳的记忆检索产生语义漂移，即系统可能召回时间上最近但语义上无关的记忆。为解决此问题，智能体需区分“对话时间”与“语义时间”，并建立能够捕捉事件持续性的记忆结构，而非仅存储瞬时事实。

现有长期记忆架构主要沿两条路线演进：一是基于向量相似度的扁平存储（如 Mem0、A-MEM），其优势在于低延迟，但缺乏时序逻辑，无法处理多跳时间推理；二是基于知识图谱的结构化存储（如 Zep、Mandol），试图通过实体关系捕捉逻辑，但多数系统仍依赖对话时间作为主要排序信号，且将记忆视为静态事实集合，忽略了用户状态随时间演化的连续性。Zep 虽引入了时序知识图谱，但在检索阶段未充分利用时间约束，导致时间敏感查询的召回精度受限。TSM 的切入点在于指出“时间建模”不仅是检索时的过滤条件，更是记忆构建时的核心组织原则，即记忆必须按事件发生的语义时间而非对话时间进行锚定与聚合。

## 核心方法

### 记忆构建参照系

标准记忆流水线包含构建、更新与利用三阶段。传统方法在构建阶段提取原子事实并存储于向量库或简单图谱，利用阶段通过向量相似度检索。TSM 的关键差异在于：构建阶段引入语义时间锚定与聚类聚合，利用阶段引入时间约束重排序，将时间从“元数据”提升为“一级排序键”。

### 语义时间线与持续记忆构建

TSM 首先构建时序知识图谱（TKG）作为情景记忆索引，记录事实的 $valid\_time$ 与 $invalid\_time$。随后，通过高斯混合模型（GMM）对时间切片内的实体进行聚类，生成持续记忆（Durative Memory）。这一设计解决了点状记忆无法恢复长期状态（如“用户持续住在波士顿”）的问题。持续记忆的表示定义为：

$$
\mathbf{c}_z = \text{Embed}(\text{Summarize}(\{s_e \mid e \in E_z\}))
$$

其中 $E_z$ 为第 $k$ 个时间切片中属于簇 $z$ 的实体集合，$s_e$ 为实体摘要。该公式将离散实体摘要聚合为具有时间跨度的主题向量，实现了从瞬时事实到稳定状态的抽象。

### 语义时间引导的检索与重排序

在利用阶段，TSM 解析查询的语义时间约束 $T_q$，并执行密集检索。随后，通过复合评分函数进行重排序，优先保证时间一致性，其次考虑语义相似度。评分函数定义为：

$$
\pi(m) = \langle \mathbb{I}[\tau(m) \in T_q], s_{sem}(m; q) \rangle
$$

其中 $\mathbb{I}[\cdot]$ 为指示函数，$\tau(m)$ 为记忆条目的时间戳，$s_{sem}$ 为语义相似度。该公式采用字典序排序，确保时间不匹配的记忆即使语义高度相关也会被降权，从而解决“时间错位”导致的错误召回。

## 实验评估

实验在 LongMemEval_S（115k tokens）和 LoCoMo 上进行，基线包括 Full Text、Naive RAG、A-MEM、Mem0、Zep 等，覆盖向量与图谱两类主流路线，但缺失强化学习类基线（如 Mem-T）。在 LongMemEval_S 上，TSM 在 GPT-4o-mini 骨干下取得 74.80% 的整体准确率，显著优于 A-MEM（62.60%）和 Zep（60.20%），尤其在时间推理（+22.56%）和多会话推理（+20.30%）任务上优势明显。

| 方法 | LongMemEval_S ACC (%) | LoCoMo ACC (%) |
| :--- | :--- | :--- |
| TSM (GPT-4o-mini) | 74.80 | 76.69 |
| A-MEM (GPT-4o-mini) | 62.60 | 64.16 |
| Zep (GPT-4o-mini) | 60.20 | 58.44 |
| Mandol (据领域综述) | - | 89.48 |

消融实验显示，移除时间重排序（w.o. temporal）导致整体准确率下降 2.0%，其中时间推理任务下降 6.0%；移除持续记忆摘要（w.o. summary）导致整体准确率下降 1.2%，但单会话偏好任务下降 10.0%。这表明时间建模对时间敏感任务至关重要，而持续记忆对个性化偏好捕捉具有独特价值，二者贡献独立且互补。

评估边界方面，LoCoMo 上 TSM（76.69%）落后于 Mandol（89.48%），且 Full Text 基线在短上下文 LoCoMo 上表现最佳，说明 TSM 的优势在长上下文（115k tokens）场景下才充分显现。论文未提供代码与超参数细节，且未报告置信区间，限制了结果的统计显著性验证。

## 关联研究分析

从问题动机看，TSM 与 Zep 均基于时序知识图谱，但 Zep 将图谱视为静态事实存储，检索时忽略时间约束，导致时间敏感查询召回失准；TSM 则将时间约束作为检索的一级排序键，并引入持续记忆聚合，解决了 Zep 在动态状态演化上的不足。这一差异源于 TSM 对“时间”角色的重新定义：从元数据提升为检索逻辑的核心组件。

从方法设计看，TSM 与 Mandol 均采用结构化记忆，但 Mandol 侧重语义图的紧凑性与低延迟检索，适用于高并发场景；TSM 侧重语义时间对齐与持续状态聚合，适用于长时程个性化对话。TSM 在 LoCoMo 上落后于 Mandol，可能因其 GMM 聚类与摘要生成引入了额外计算开销，且未针对多跳推理进行专门优化。TSM 未探索强化学习驱动的记忆策略，其时间约束解析依赖 spaCy 规则，在模糊时间表达下的鲁棒性未经验证。

## 总结

TSM 旨在解决长期对话中对话时间与事件时间错位及记忆碎片化问题，通过语义时间线锚定与持续记忆聚合，实现了时间敏感查询的精准召回。该方法在 LongMemEval_S 上取得 74.80% 准确率，时间推理任务提升 22.56%，验证了语义时间建模的有效性。然而，其在 LoCoMo 上落后于 Mandol，且 Full Text 基线在短上下文场景下表现最佳，表明 TSM 的优势依赖于长上下文与时间敏感任务，通用检索能力仍受限于图谱构建开销。当查询时间表达模糊或上下文较短时，语义时间解析的边际收益是否递减，论文未给出回答。
