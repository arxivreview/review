# ACL-Findings2026最新论文 ｜CANDICE: Agentic Causal Disentanglement with Class Conditional Knowledge Integration for Long Tailed Domain Generalization ｜代理式因果解耦与类条件知识集成

研究机构：美国亚利桑那州立大学

作者：Midhat Urooj、Ayan Banerjee、Sandeep Gupta

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_cf21ec35ecd8)

> 医学影像模型在跨中心部署时面临域泛化（Domain Generalization, DG）与长尾识别（Long-Tailed, LT）的双重挑战，传统方法难以同时保持域不变性与稀有类判别力。现有数据驱动范式将类身份与不稳定伪相关纠缠，而人工知识集成又受限于高昂的工程成本。本文提出 CANDICE，通过 LLM 代理自动构建因果解耦管道，在决策层分离域不变特征与类特异性信号。该框架在 10 个数据集上平均提升 10.3%，但依赖 LLM 推理开销且缺乏与主流频率解耦方法的直接对比。

## 研究背景

当分类器面对跨中心数据时，训练域与测试域的分布出现系统性差异，这一现象称为域偏移。域偏移导致模型在源域训练后，在目标域性能显著下降，而实际临床场景中往往存在类别不平衡，稀有病理类样本极少，这构成了长尾识别的约束：仅凭头部类主导的统计规律无法泛化到尾部类。解决此类问题的经典框架是域泛化，它寻求跨环境稳定的特征表示，但优化域不变性常抑制稀有类的判别信号，形成“鲁棒性-尾部”权衡。

该领域要解决的核心矛盾是：如何在分布动态变化且标注稀缺的环境中，构建能够解耦域特异性噪声与解剖学因果特征的鲁棒表征。主流路线分为频率解耦派与因果/几何先验派：前者通过解耦高低频去除风格干扰，后者利用因果图或几何结构学习不变特征。然而，传统因果方法依赖人工检索指南、专家翻译规则及反复试错，限制了可扩展性与可复现性。本文切入点在于将因果解耦从离线人工规则注入转向在线 LLM 代理编排，通过自动化管道构建打破人工瓶颈。

## 核心方法

### 方法参照系

本文问题属于因果与少样本适应范畴，但流程差异显著：传统方法多为静态特征学习（如 GeoProto），本文采用动态管道构建（CRA-CDA-CGA），关键差异在于将知识转化为可执行代码而非固定特征提取器。

### 代理式因果解耦架构

CANDICE 将推理分解为三个代理：临床/概念推理代理（CRA）、因果解耦代理（CDA）和代码生成代理（CGA）。CRA 从可信语料库检索证据并构建类条件因果链，CDA 在约束下规划决策路径，CGA 生成可执行、自调试的程序。这一设计解决了传统神经符号系统中人工规则难以跨域泛化的失效。形式化地，CANDICE 的推理因子化为：

$$ P(Y | X, D) = \sum_{z} P(Y | X, z) P(z | X, K, D) $$

其中 $z$ 为 CDA 选择的潜在决策路径，$K$ 为外部知识。该公式表明，预测不仅依赖输入 $X$ 和域 $D$，还通过知识 $K$ 约束的路径 $z$ 进行中介，实现了因果机制与感知模型的解耦。

### CoCKTAIL 决策级集成

CoCKTAIL 是类条件、决策级集成模块，通过期望信息增益（EIG）和纯度指数引导树状划分，将头部类样本路由至数据驱动假设，尾部类样本路由至知识驱动假设。这一设计解决了单一模型在长尾分布下稀有类流形坍缩的问题。CoCKTAIL 的分裂准则基于 EIG：

$$ EIG(h) = \mathbb{E}_{x \sim D} [H(Y) - H(Y | h(x))] $$

其中 $H$ 为熵。该公式量化了假设 $h$ 对标签不确定性的减少程度，CDA 据此选择最优分裂节点，确保稀有类通过高精度因果指标而非头部类主导的相关性进行分类。

## 实验评估

实验覆盖糖尿病视网膜病变（DR）、癫痫定位、超声心动图及心电图分类，共 10 个数据集，基线包括 Vision-only、RAG、ReAct 及 LangGraph 管道，但缺失频率解耦（如 AFDAN）和几何先验（如 GeoProto）等主流 DG 基线。

| 方法 | Accuracy (%) | Macro F1 | Tail F1 | Domain Gen. Gap ↓ |
|---|---|---|---|---|
| Vision only Model | 68.2 | 65.1 | 52.7 | 12.3 |
| RAG + Vision (No Agents) | 74.5 | 70.8 | 60.2 | 9.7 |
| ReAct style Agent | 76.0 | 72.1 | 62.8 | 8.9 |
| LangGraph Pipeline | 77.3 | 73.5 | 64.0 | 8.2 |
| CANDICE (Ours) | 81.6 | 78.9 | 70.5 | 5.3 |

CANDICE 在 Tail F1 上较最强非代理基线提升 5.6 点，域泛化差距缩小至 5.3，表明代理式解耦有效缓解了长尾与域偏移的冲突。

| 方法 | First Run (%) | Avg. Fix | Final Exec (%) | Runtime |
|---|---|---|---|---|
| Single-Shot LLM | 68.3 | 2.7 | 84.1 | 0.0s |
| Toolformer-Style Agent | 78.5 | 1.9 | 91.2 | 1.2s |
| CGA (Ours) | 90.1 | 1.2 | 96.3 | 2.1s |

CGA 的首次运行成功率较单轮 LLM 提升 21.8 个百分点，且平均修复次数更少，验证了自调试机制的有效性。在 DR 多域泛化任务中，CANDICE 融合模型达到 60.7% 准确率，优于 SPSD-ViT 的 50.0%；在癫痫定位任务中，准确率从基线的 46.1% 提升至 84.6%。

评估指标包含 Tail F1 和域泛化差距，但未报告置信区间，且部分数据集（如 EchoNet）性能略低于优化后的专用管道。代码未公开，LLM 后端固定为 Gemini 2.5，限制了跨模型泛化性验证。

## 关联研究分析

从问题动机看，CANDICE 与 Causal Transfer Framework 同属因果解耦路线，但前者依赖人工构建因果图，后者通过 LLM 自动推理生成因果假设。这一差异源于任务特性：CANDICE 面向多模态、动态环境，需实时适配可用输入，而静态因果图难以应对工具约束变化。然而，LLM 生成的因果链是否在所有域间保持一致，论文未提供跨域一致性审计，可能存在幻觉导致的性能波动。

从方法设计看，CANDICE 与 GeoProto 均利用先验知识，但 GeoProto 依赖几何结构（如 EDT 编码），CANDICE 依赖临床语义知识。这一差异反映了知识类型的不同：几何先验在跨模态语义一致性上更鲁棒，而语义先验在计算效率与边界精度上占优。CANDICE 未与频率解耦方法（如 AFDAN）直接对比，无法判断因果解耦在非线性域偏移中是否优于频率解耦，这一盲区限制了其在复杂医学场景中的定位。

## 总结

CANDICE 要解决的核心矛盾是域泛化与长尾识别的权衡，现有方法因纠缠类身份与伪相关而失效。本文抓住 LLM 代理自动构建因果管道的切入点，通过 CRA-CDA-CGA 解耦推理、规划与执行，在决策层分离域不变与类特异性信号。实验证明其在 10 个数据集上平均提升 10.3%，Tail F1 较基线提升 5.6 点。边界在于依赖 LLM 推理开销，且缺乏与主流频率解耦方法的横向对比。当支持集增大时，知识驱动分支的边际收益是否递减，论文未给出回答。
