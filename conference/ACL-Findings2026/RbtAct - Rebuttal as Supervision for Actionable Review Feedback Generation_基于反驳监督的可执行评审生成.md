# ACL-Findings2026最新论文 ｜RbtAct: Rebuttal as Supervision for Actionable Review Feedback Generation ｜基于反驳监督的可执行评审生成

研究机构：美国耶鲁大学、美国纽约大学

作者：Sihong Wu、Yiling Ma、Yilun Zhao 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.09723)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.09723)

> 同行评审自动化长期面临“生成流畅但缺乏行动指导”的困境，现有方法多依赖静态标注或通用提示，无法捕捉评论对作者实际修改行为的因果影响。RBTACT 将作者反驳（Rebuttal）转化为隐式偏好信号，通过直接偏好优化（DPO）训练模型生成能触发具体修改的评审片段。该方法在 8B 参数规模下实现了超越 70B 通用大模型的可执行性评分，但其效果高度依赖反驳数据的对齐质量，且未验证对最终论文录用率的直接贡献。

## 研究背景

当评审意见仅指出“实验不足”而未说明具体缺失何种消融时，作者往往陷入防御性回应而非实质性修改，这种反馈与行动脱节的现象源于监督信号的缺失。传统训练依赖人类专家标注的“正确”评审，但“正确”不等于“有效”，即无法区分哪些评论真正驱动了论文改进。直接偏好优化（DPO）提供了一种无需显式奖励模型即可从成对偏好中学习策略的机制，其核心在于通过比较两个输出的相对优劣来调整模型概率分布，这为利用非结构化的人类行为数据提供了数学基础。

同行评审自动化领域的主流路线分为提示工程、监督微调（SFT）和多智能体协作三类。提示工程受限于模型固有偏见，生成的评论往往泛化且缺乏深度；SFT 方法如 DeepReview 虽提升了具体性，但仅优化了语言质量，未关联下游修改行为；多智能体框架如 MARG 通过角色分工减少泛化，但计算成本高且缺乏对“有效性”的直接优化。这些方法的共同瓶颈在于缺乏一个能直接量化“评论是否引发修改”的监督源。RBTACT 的切入点在于利用 ICLR 会议中作者反驳这一天然存在的行为数据，将“作者是否修改”作为隐式奖励，从而将评审生成目标从“语言正确性”转向“行动可执行性”。

## 核心方法

### 方法参照系

本文任务属于条件化文本生成，标准流程为：给定输入上下文 $x$ 和目标标签 $s$，模型生成输出 $y$。与通用评审生成不同，本文要求输出必须是针对单一视角（如实验）的原子化片段，且该片段必须与特定的反驳片段存在语义对齐关系，这种细粒度的对齐是构建偏好对的前提。

### 反驳映射与偏好构建

传统 SFT 将完整评审作为训练目标，导致模型无法区分评审中哪些部分真正被作者采纳。RBTACT 首先构建大规模映射数据集 RMR-75K，将评审分解为原子片段 $r_{j,k}^{p}$，并通过启发式与 LLM 匹配将其与反驳片段 $b_t^p$ 对齐。关键创新在于引入影响类别（Impact Category）作为偏好排序依据，定义偏好对 $(x, y_w, y_l)$，其中 $y_w$ 对应高影响类别（如具体修改已执行 CRP），$y_l$ 对应低影响类别（如辩护无修改 DWC）。偏好对仅在同一论文同一视角内构建，确保比较的公平性。

$$
\mathcal{L}_{DPO}(\theta) = -\mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}_{pref}} \left[ \log \sigma \left( \beta \left( \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)} \right) \right) \right]
$$

该公式表明，模型通过最大化高影响评论与低影响评论的对数概率比来学习，$\beta$ 控制偏好强度。这一设计直接解决了 SFT 中“所有正确评论权重相同”的失效，使模型偏向于生成能引发具体修改的评论。

### 两阶段训练策略

仅使用 DPO 可能导致模型在长上下文下视角控制漂移。RBTACT 采用两阶段训练：第一阶段在 REVIEWSEG-SFT-13K 上执行 SFT，建立基础生成能力；第二阶段在 REVIEWPREF-DPO-22K 上执行 DPO，优化可执行性。为防止漂移，损失函数中加入 SFT 正则项：

$$
\mathcal{L}_{total} = \mathcal{L}_{DPO} + \lambda \mathcal{L}_{SFT}
$$

其中 $\lambda=0.1$，$\mathcal{L}_{SFT}$ 仅在正样本上计算。这一设计动机在于平衡“生成质量”与“行动导向”，避免 DPO 过度优化导致语言流畅度下降或视角偏离。

## 实验评估

实验基于 ICLR 2025 的 700 篇论文构建测试集，基线涵盖 SFT 变体、通用大模型（GPT-5-chat, Llama-3.1-70B）及任务适配方法（MARG, DeepReviewer）。RBTACT 在人工评估中取得 3.46/5 的可执行性评分，LLM-as-a-judge 评估为 3.38/5，均高于所有基线。

| 模型 | 人工可执行性 (1-5) | LLM 可执行性 (1-5) | 具体性 (1-5) |
| :--- | :--- | :--- | :--- |
| RBTACT | 3.46 | 3.38 | - |
| GPT-5-chat | - | - | - |
| Llama-3.1-70B | - | - | - |

*注：表格仅展示论文明确报告的 RBTACT 核心数值，其他基线具体分数未在数据区逐字提供，故留空。*

消融实验显示，DPO 阶段相比纯 SFT 在可执行性上带来显著提升，且偏好对的难度分层（大/中/小影响差距）对模型鲁棒性至关重要。评估边界方面，论文未报告置信区间，且 LLM-as-a-judge 与人工评估的 Spearman 相关系数为 0.94，表明自动评估可靠，但缺乏对最终论文录用率或修改质量的长期追踪验证。

## 关联研究分析

从监督信号来源看，RBTACT 与 DeepReview 形成鲜明对比。DeepReview 依赖人类专家标注的“高质量”评审进行 SFT，其隐含假设是“专家认可=有效”，但忽略了专家认可与作者实际修改之间的断层。RBTACT 则利用作者反驳这一行为数据，将“有效性”定义为“是否引发修改”，这一转变源于对评审目的的本质理解：评审不仅是质量判断，更是修改指南。这种差异并非技术优劣，而是任务定义的不同：前者优化“正确性”，后者优化“因果影响力”。

从方法架构看，RBTACT 与 MARG 均旨在解决泛化问题，但路径不同。MARG 通过多智能体分工模拟人类团队，增加计算复杂度以换取多样性；RBTACT 则通过单模型微调，利用 DPO 的偏好排序机制在参数内部编码“行动导向”，计算成本更低。然而，RBTACT 的偏好对构建严格限制在同一论文同一视角内，这可能限制了模型跨论文泛化能力，即模型是否学会了通用的“可执行评论模式”，还是仅记住了特定论文的修改偏好，论文未给出回答。

## 总结

RBTACT 针对评审生成中“语言流畅但缺乏行动指导”的核心矛盾，利用作者反驳作为隐式偏好信号，通过 DPO 优化模型生成能触发具体修改的评论。该方法在 8B 规模下实现了 3.46/5 的可执行性评分，超越 70B 通用模型，证明了行为数据监督的有效性。其边界在于依赖高质量的反驳-评审对齐，且未验证对最终论文质量的长期影响。当反驳数据稀疏或噪声较大时，DPO 的偏好信号是否仍能稳定引导模型学习，论文未给出回答。
