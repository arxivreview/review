</think>` 后自然生成的 Post-think 文本是比通用摘要更优的蒸馏目标，通过直接训练学生模型复现该文本，在匹配 Token 预算下取得最佳准确率-效率权衡。该发现揭示了内化方法的适用边界，但受限于小模型骨干与单一任务，其泛化性存疑。

## 研究背景

当推理模型面对竞赛级数学问题时，其生成的思维链（Chain-of-Thought, CoT）往往长达数千 Token，包含大量试错与回溯。这种长轨迹虽提升了准确率，却使推理延迟与显存占用呈线性甚至二次方增长。为降低开销，研究界尝试通过课程学习逐步移除推理 Token，使模型将计算内化至潜在空间，即隐式思维链（Implicit Chain-of-Thought, ICoT）。ICoT 在 GSM8K 等短轨迹任务上验证了可行性，但其核心假设——推理步骤具有可逐步剥离的线性结构——在长探索性轨迹中是否成立，尚无定论。

长 CoT 的效率优化面临两难：推理时截断虽减少可见推理 Token，但模型会通过生成更长的 Post-think 文本进行补偿，导致总 Token 数未降；训练时课程学习虽旨在内化计算，但在缺乏固定步长结构的自由推理中，Token 级移除变得任意且低效。本文聚焦于这一矛盾，指出 ICoT 式课程在长轨迹上失效的根本原因在于训练目标与长程依赖的冲突，并转向直接蒸馏教师模型自然生成的 Post-think 文本，以保留解题路径结构的同时压缩推理长度。

## 核心方法

### 方法参照系

本文问题置于 CoT 压缩与剪枝路线下，但区别于在线剪枝或 RL 奖励设计，其核心在于训练时蒸馏目标的选择。通用流程为：教师生成完整轨迹 → 学生通过 SFT 学习 → 推理时控制长度。本文的关键差异在于，不依赖启发式规则或连续潜在空间，而是利用教师生成过程中自然产生的 Post-think 文本作为蒸馏目标，替代人工构造的摘要或截断前缀。

### Post-think 作为蒸馏目标

ICoT 式课程学习通过逐步移除推理 Token 来内化计算，但在长轨迹中，Token 位置缺乏一致的语义角色，导致移除过程任意且低效。本文提出直接蒸馏 Post-think 文本，即教师模型在 `
</think>` 后、最终答案前生成的简洁解释。Post-think 文本天然具备答案导向性，复述了教师的解题路径而非重新推导，因此能保留关键逻辑结构。设教师完整轨迹为 $T = \langle s_1, s_2, \dots, s_M \rangle$，Post-think 为 $P$，学生模型 $\theta$ 通过最小化交叉熵损失 $\mathcal{L}(\theta) = -\sum_{t \in P} \log P_\theta(t | x, P_{<t})$ 学习生成 $P$。这一设计避免了课程学习的多阶段训练开销，且 Post-think 长度（约 500 Token）远短于完整轨迹（约 5000 Token），在匹配 Token 预算下实现了更高的准确率。

### 课程学习失效的边界界定

ICoT 式课程学习在短结构化任务上有效，但在长探索性轨迹上失效。本文通过对比四种课程变体（First-k 截断、左到右段移除、随机段移除、迭代摘要）与直接蒸馏 Post-think，发现课程学习在竞赛数学上准确率仅 8-10%，与无推理基线相当。这一失效源于长轨迹中推理步骤的非线性依赖：移除早期 Token 会破坏后续步骤的上下文连贯性，导致模型无法内化复杂计算。相比之下，Post-think 蒸馏保留了完整的解题路径结构，避免了长程依赖的断裂。设课程学习阶段 $t$ 的目标轨迹为 $Y^{(t)} = \text{Concat}(\{s_i : m_i^{(t)} = 1\})$，其中 $m^{(t)}$ 为二进制掩码。本文实验表明，当 $|T| \sim 5000$ 时，课程学习的收敛速度远低于直接蒸馏，且最终准确率显著低于 Post-think 蒸馏。

## 实验评估

实验基于 NuminaMath 1.5 数据集，包含 10k 竞赛数学问题，分为 8k 训练、1k 验证、1k 测试。学生模型为 Qwen2.5-7B，教师模型为 DeepSeek-R1 与 QwQ-32B。基线包括 First-k 截断、ICoT 式课程学习、通用摘要蒸馏。Post-think 蒸馏在匹配 Token 预算下取得 18.5% 准确率，显著优于通用摘要（13-21%）与 ICoT 课程（8-10%）。

| 方法 | 准确率 (%) | Token 预算 |
|---|---|---|
| Post-think 蒸馏 | 18.5 | 匹配 |
| 通用摘要蒸馏 | 13-21 | 匹配 |
| ICoT 课程学习 | 8-10 | 匹配 |
| First-k 截断 | 未报告 | 可变 |

Post-think 蒸馏的优势源于其保留了教师的解题路径结构，而通用摘要通过提示压缩轨迹，丢失了关键逻辑步骤。ICoT 课程学习在长轨迹上失效，验证了内化方法的适用边界。

评估边界方面，本文仅使用 Qwen2.5-7B 作为学生模型，未测试更大规模模型或不同架构。指标仅关注准确率与 Token 数，未报告延迟、显存占用等系统级指标。代码未公开，超参数（如 LoRA 秩、学习率）未详细列出，可复现性受限。

## 关联研究分析

从问题动机看，本文与 CODI（Shen et al., 2025）同属 CoT 压缩路线，但 CODI 通过自蒸馏将 CoT 压缩至连续潜在空间，而本文聚焦于文本蒸馏目标的选择。CODI 在 GSM8K 上匹配了完整 CoT 性能，但本文指出其在长探索性轨迹上未验证。本文的 Post-think 蒸馏保留了文本可解释性，而 CODI 的潜在空间牺牲了可解释性以换取并行潜力。两者差异源于任务特性：GSM8K 轨迹短且结构化，适合潜在空间压缩；竞赛数学轨迹长且探索性，适合文本结构保留。

从方法设计看，本文与 From Long to Lean（Yan et al., 2025）均涉及多轮压缩，但 From Long to Lean 通过渐进式压缩平滑适应长度约束，而本文发现课程学习在长轨迹上无效。From Long to Lean 的压缩过程依赖模型对长度约束的平滑适应，而本文的 Post-think 蒸馏直接利用教师自然生成的文本，避免了多轮交互的计算成本。这一差异暗示，在长轨迹中，直接利用生成过程中的自然结构（如 Post-think）可能比人工构造的压缩策略更有效。

## 总结

本文要解决的核心矛盾是长 CoT 的效率开销与准确率保持之间的权衡。现有课程学习式内化方法在长探索性轨迹上失效，直接截断又因补偿性生成而虚高 Token 预算。本文抓住教师模型自然生成的 Post-think 文本这一被忽略的蒸馏目标，通过直接训练学生模型复现该文本，在匹配 Token 预算下取得 18.5% 准确率，显著优于通用摘要与 ICoT 课程。本文证明了 Post-think 蒸馏在竞赛数学上的有效性，但其边界在于仅测试了 Qwen2.5-7B 小模型与单一任务，未验证跨模型规模或跨任务的泛化性。当学生模型规模扩大至 70B 以上时，Post-think 蒸馏的准确率优势是否仍显著，论文未给出回答。
