# ACL-Findings2026最新论文 ｜Stable and Explainable Personality Trait Evaluation in Large Language Models with Internal Activations ｜基于内部激活的稳定性人格评估

研究机构：美国佐治亚理工学院、华南理工大学

作者：Xiaoxu Ma、Xiangbo Zhang、Zhenyu Weng

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_54dae42eb74d)

> 大语言模型（LLMs）的人格评估长期受困于提示词敏感性，导致同一模型在不同措辞下产生剧烈波动的人格分数。现有自报告与开放问答范式将表面行为混淆为稳定特质，无法区分提示诱导的临时表现与模型内在的行为偏差。本文提出 Persona-Vector Neutrality Interpolation (PVNI)，利用内部激活空间中的对比向量进行线性插值，以解耦提示干扰并量化中性人格强度。该方法在稳定性上显著优于传统量表，但其理论假设的线性边界及跨模型泛化能力仍存疑。

## 研究背景

当评估者试图量化 LLM 的神经质（Neuroticism）时，微小的提示词改写往往导致分数从“强烈同意”跳变至“中立”，这种不稳定性源于自报告范式将模型对特定文本风格的即时反应误判为稳定特质。这种混淆揭示了评估范式的根本缺陷：外部输入端的文本风格无法剥离模型内部表示中固有的行为偏差。为了解决这一信效度危机，研究界开始关注模型内部的高维表示空间，假设人格特质并非仅存在于输入输出接口，而是编码在隐藏状态（Hidden States）的特定线性方向上。

当前 LLM 人格评估主要依赖两种范式：一是自报告评估，如 IPIP-NEO，模型直接对量表条目打分；二是开放问答，模型生成自由文本后由外部裁判打分。这两类方法均高度依赖提示框架，Zheng et al. (2025) 指出，即使语义等价的提示也能产生显著不同的特质估计，且无法区分“提示诱导的角色扮演”与“模型固有的行为偏差”。这种不稳定性阻碍了模型间的人格比较与对齐。本文的切入点在于将评估对象从“输出文本”转移至“内部激活”，通过构建人格向量（Persona Vector）作为锚点，在表示空间内执行插值操作，从而获得对提示词扰动不敏感的中性特质分数。

## 核心方法

### 激活空间中的向量参照系

传统评估流程依赖外部裁判对生成文本打分，而 PVNI 将评估过程内化为表示空间的几何操作。其参照系基于对比激活提取：对于特质 $i$，分别使用正向提示 $p_i^{pos}$ 和负向提示 $p_i^{neg}$ 生成响应，并提取层 $l$ 的隐藏状态均值 $\bar{h}_i^{pos}$ 与 $\bar{h}_i^{neg}$。人格向量定义为两者之差 $v_i^p = \bar{h}_i^{pos} - \bar{h}_i^{neg}$，其单位化版本 $\mu_i$ 代表该特质在表示空间中的主方向。这一设计动机在于，外部提示的微小变化会改变生成文本的分布，但内部激活的对比差异能够捕捉到模型对该特质的内在敏感度方向，从而作为稳定的几何锚点。

### 中性插值与线性理论

PVNI 的核心创新在于引入中性提示 $p_i^{neu}$ 并执行投影插值。首先计算中性向量 $v_i^n = \bar{h}_i^{neu} - \bar{h}_i^{neg}$，随后将其投影到人格向量上得到插值系数：

$$
coef_i = \frac{\langle v_i^n, v_i^p \rangle}{\langle v_i^p, v_i^p \rangle}
$$

该系数衡量了中性状态在人格方向上的相对位置。最终的中性分数通过线性插值获得：

$$
\hat{s}_i(M) = s_i^{neg} + coef_i \cdot (s_i^{pos} - s_i^{neg})
$$

其中 $s_i^{pos}$ 和 $s_i^{neg}$ 是由 API 裁判对正向和负向提示响应打分的均值。这一机制解决了传统方法中“提示即特质”的混淆问题：通过几何投影，PVNI 剥离了提示词的具体措辞影响，仅保留模型在人格轴上的固有偏移。理论部分进一步证明，在局部线性假设下，人格向量表现为秩一放大器，即 $\Delta h_i^\ell(h) = c_i \langle h, \mu_i \rangle \mu_i + e_i(h)$，其中残差项 $\|e_i(h)\|_2 \le \beta \|h\|_2$。这保证了在多特质组合时，正交特质可独立调节，而对立特质存在固有的权衡边界。

## 实验评估

实验在 Qwen-2.5-7B-Instruct、Llama-3-8B-Instruct 和 Mistral-7B-Instruct-v0.1 上进行，对比了自报告（IPIP-BFFM-50, IPIP-NEO-120）、开放问答与 PVNI 四种协议。基线覆盖了当前主流的两种评估范式，但缺失了基于激活工程（如 CAA）或模型合并（如 Task Arithmetic）的控制类基线，因此无法直接比较“评估”与“控制”在稳定性上的差异。

| 模型 | 特质 | 自报告 (IPIP-BFFM-50) | 开放问答 | PVNI (Ours) |
| :--- | :--- | :--- | :--- | :--- |
| Qwen-2.5-7B | Openness | 82.5 ± 6.40 | 87.5 ± 3.74 | 83.55 ± 0.82 |
| Qwen-2.5-7B | Neuroticism | 45.0 ± 18.10 | 38.5 ± 8.98 | 36.45 ± 0.83 |
| Llama-3-8B | Openness | 82.3 ± 4.10 | 87.8 ± 2.63 | 83.42 ± 0.55 |
| Llama-3-8B | Neuroticism | 44.6 ± 11.20 | 38.9 ± 6.24 | 36.18 ± 0.60 |

PVNI 在所有模型和特质上均展现出最低的标准差。以 Qwen-2.5-7B 的神经质为例，自报告的标准差高达 18.10，而 PVNI 仅为 0.83，表明其几乎完全消除了提示词改写带来的方差。收敛效度分析显示，PVNI 与自报告平均分的 Pearson 相关系数在 0.880 至 0.919 之间，Spearman 秩相关系数在 0.700 至 1.000 之间，验证了其估计值与传统量表的一致性。

消融实验通过问卷变体（Questionnaire）与角色扮演变体（Role-play）的对比，揭示了评估稳定性的来源。数据显示，角色扮演变体的方差通常略低于问卷变体，因为问卷变体对问题内容的修改幅度更大。此外，低分特质（如神经质、外向性）表现出更高的标准差，暗示当特质强度较弱时，内部激活信号的信噪比降低，导致估计不确定性增加。

评估边界方面，论文未报告计算开销，但 PVNI 需要多次前向传播以提取不同提示下的激活状态，计算成本高于单次自报告。代码未公开，超参数（如插值系数的裁剪范围 [0,1]）对结果的影响未做详细消融。可复现性受限于 API 裁判的非确定性，尽管论文采用了 logit 加权平均来缓解，但裁判模型的版本更新可能导致分数漂移。

## 关联研究分析

从问题动机看，PVNI 与 Persona Vectors (Sun et al., 2025) 共享“内部表示线性可分”的假设，但目标函数截然不同。Persona Vectors 旨在通过向量注入实现人格控制，关注的是如何改变模型行为；而 PVNI 旨在通过向量投影实现人格测量，关注的是如何稳定地量化模型行为。这种差异导致 PVNI 不需要保证向量注入后的通用能力保持，而是专注于向量方向的几何稳定性。然而，PVNI 未验证其测量分数与 Persona Vectors 控制效果之间的因果联系，即“测得的高神经质”是否必然导致“控制后的高神经质行为”，这一因果链条的缺失使得 PVNI 的分数更多是描述性的而非预测性的。

从方法设计看，PVNI 与 Contrastive Activation Addition (CAA) 同属激活工程路线，但 CAA 用于动态推理时的实时调制，而 PVNI 用于静态离线评估。CAA 的向量通常经过正交化处理以最小化对通用能力的干扰，而 PVNI 直接使用原始对比向量进行投影，未引入正交化步骤。这暗示 PVNI 假设在评估场景下，特质间的几何干扰可以忽略，或者其插值机制本身具有鲁棒性。然而，当特质高度耦合时（如宜人性与谄媚性），PVNI 的线性插值可能无法捕捉非线性干扰，导致分数偏差。论文未提供多特质组合下的干扰实验，这一盲区限制了其在复杂人格画像评估中的适用性。

## 总结

本文旨在解决 LLM 人格评估中提示词敏感性导致的信效度危机，通过引入内部激活空间的几何插值机制，将评估从“文本表面行为”转向“表示空间固有偏差”。PVNI 利用对比激活构建人格向量，并通过中性提示的投影系数实现分数插值，在 Qwen 和 Llama 模型上将神经质评估的标准差从 18.10 降至 0.83，证明了内部表示在稳定性上的优势。然而，其理论依赖局部线性假设，且在低分特质上仍表现出较高的不确定性，表明线性近似在特质强度边缘可能失效。当特质间存在强非线性耦合时，PVNI 的插值系数是否仍能准确反映模型的真实行为偏差，论文未给出回答。
