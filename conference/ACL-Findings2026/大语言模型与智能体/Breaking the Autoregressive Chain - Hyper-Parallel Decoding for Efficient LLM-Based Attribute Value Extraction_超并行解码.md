# ACL-Findings2026最新论文 ｜Breaking the Autoregressive Chain: Hyper-Parallel Decoding for Efficient LLM-Based Attribute Value Extraction ｜超并行解码

研究机构：加拿大麦吉尔大学、加拿大魁北克人工智能研究所

作者：Theodore Glavas、Nikhita Vedula、Dushyanta Dhyani 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.26209)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.26209)

> 属性值提取（Attribute Value Extraction, AVE）任务中，多个属性值的生成在给定文档上下文时具有条件独立性，但标准自回归解码强制将其串行化，导致离线批量推理吞吐量受限。现有投机解码受限于草稿质量与验证开销，无法充分利用这种结构独立性。本文通过操纵位置ID与注意力掩码，实现非连续令牌的并行生成，在保持输出质量的前提下将推理成本降低至13.8倍。该方案在特定结构化任务上有效，但其对属性长度分布的依赖性及位置编码外推误差的影响尚存疑。

## 研究背景

自回归大语言模型在推理时受限于严格的左到右顺序依赖，每个令牌生成需完整前向传播，导致内存带宽受限且延迟随生成长度线性增加。在属性值提取任务中，这种顺序依赖尤为不合理，因为不同属性值的提取在理论上互不干扰，却被迫等待前一个值生成完毕。键值缓存（Key-Value Cache, KV Cache）的内存连续性要求进一步加剧了并行解码的难度，传统方法难以在不破坏缓存结构的前提下实现乱序生成。

该领域主流路线包括投机解码与多令牌预测（Multi-Token Prediction, MTP）。投机解码通过轻量级草稿模型并行提议、目标模型验证，但受限于草稿与目标模型的分布匹配度，加速比通常仅为2-5倍。MTP方法如Medusa通过添加额外预测头并行预测连续未来令牌，但令牌间的强依赖关系限制了并行度，且需修改模型架构。这些方法均假设生成序列内部存在强顺序依赖，未能利用AVE任务中属性值间的条件独立性。本文切入点在于识别并利用这种任务特定的结构特性，通过架构级适配而非模型修改，实现免训练的超并行解码。

## 核心方法

### 方法参照系

标准自回归解码流程中，模型在每一步 $t$ 基于前缀 $y_{<t}$ 预测下一个令牌 $Y_t$，其条件概率分布为 $\hat{P}(Y_t = y | p, y_{<t}) = \sigma(F(y_{<t}, p))$。该流程强制所有输出令牌按顺序生成，即使它们在语义上相互独立。本文问题与该通用流程的关键差异在于：AVE任务的输出序列由多个独立的属性值组成，其联合分布可分解为各值分布的乘积，而非条件链。

### 条件独立性假设与并行化

设计动机在于消除自回归生成中值间的虚假依赖，避免早期提取错误级联至后续值。本文假设给定提示 $p$，各属性值 $\mathbf{v}_n$ 条件独立，即 $P(\mathbf{v}_1, \dots, \mathbf{v}_N | p) = \prod_{n=1}^N P(\mathbf{v}_n | p)$。这一假设允许将原本长度为 $T$ 的串行生成过程分解为 $N$ 条并行链，每条链长度为其对应值的令牌数 $K_n$，总步数降至 $\max(K_n) \equiv K_{max}$。公式表明，通过打破链式依赖，推理步数从序列总长变为最长单值长度，理论上实现了线性加速。

### 位置ID跳跃与自定义注意力掩码

设计动机在于解决并行生成中令牌插入位置与KV缓存内存连续性的矛盾。本文通过在输出模板中跳过位置ID（Position ID）来创建间隙，具体为在每个属性值起始位置将位置ID递增 $K_{max}$。新令牌始终追加至序列末尾，但分配其逻辑位置ID，从而保持KV缓存的内存连续性。注意力掩码基于位置ID顺序而非内存顺序计算，形成非三角形但符合因果性的掩码。公式表达为：

$$
\text{Mask}_{i,j} = \begin{cases}
1 & \text{if } \text{posID}_i \leq \text{posID}_j \\
0 & \text{otherwise}
\end{cases}
$$

该机制允许模型在单次前向传播中并行生成多个独立值的首令牌，后续步骤仅处理新令牌，实现了计算与内存的双重优化。

## 实验评估

实验在OA-Mine、AE110k及Amazon Reviews三个数据集上进行，基线包括自回归解码与不同规模草稿模型的投机解码。对比方法覆盖了主要并行解码路线，但缺失Medusa等MTP方法的直接对比，可能影响结论的普适性。

| 模型 | 吞吐量 (Prod./s) | 加速比 (x) |
| --- | --- | --- |
| Qwen3-32B HPD | 0.539 | 10.78 X |
| Qwen3-32B + 1.7B Spec. | 0.104 | 2.08 X |
| Qwen3-32B + 4B Spec. | 0.092 | 1.84 X |
| Qwen3-32B + 8B Spec. | 0.063 | 1.26 X |
| Qwen3-32B AR | 0.050 | 1.00 X |

HPD在Amazon Reviews上实现10.78倍加速，显著优于最大加速比2.08倍的投机解码。F1分数在OA-Mine上平均低0.7%，但在AE110k和Amazon Reviews上分别高4.5%和0.7%，表明质量无损甚至略有提升。

消融实验显示，HPD的加速比随文档堆叠数量线性增长直至饱和，而批次大小影响较小。这表明文档堆叠提供的并行维度比批次维度更有效。位置ID跳跃机制在短值场景下表现优异，但论文未报告长值场景下的加速比衰减情况，可能因 $K_{max}$ 设置不当导致位置编码外推误差。

评估指标涵盖吞吐量、成本与F1分数，但缺乏置信区间报告。代码已开源，超参数 $K_{max}$ 需根据数据集属性长度分布手动调整，未提供自动调节策略。GPU型号未明确说明，可能影响结果的可复现性。

## 关联研究分析

从问题动机看，HPD与投机解码的核心差异在于对并行性的来源假设。投机解码依赖草稿模型的质量，其并行度受限于草稿与目标模型的分布匹配度，本质是“预测-验证”范式。HPD则利用任务结构特性，将并行性内生于输出序列的条件独立性，无需额外模型，本质是“结构分解”范式。这一差异源于任务特性：AVE的属性值独立性是任务固有属性，而通用文本生成中令牌间依赖强，难以直接应用HPD。

从方法设计看，HPD与Medusa同属MTP路线，但Medusa通过添加预测头并行预测连续令牌，需修改模型架构并微调。HPD通过位置ID操纵实现非连续令牌并行，免训练且兼容现有模型。这一差异源于对令牌依赖结构的处理：Medusa假设连续令牌间存在强依赖，需联合建模；HPD假设非连续令牌间独立，可分别建模。Medusa在通用文本生成中更适用，而HPD在结构化提取任务中更具优势。

## 总结

本文要解决的核心矛盾是AVE任务中属性值条件独立性与自回归解码顺序依赖性的冲突。现有方法如投机解码受限于草稿质量，MTP方法受限于连续令牌依赖，均未能利用任务结构特性。本文抓住属性值间条件独立性这一被忽略的点，通过位置ID跳跃与自定义注意力掩码实现免训练并行解码。实验证明在Amazon Reviews上实现10.78倍加速且质量无损。本文边界在于加速比依赖属性长度分布，长值场景下 $K_{max}$ 设置不当可能导致位置编码外推误差，论文未报告此情况。当属性值长度分布高度偏斜时，HPD的加速比是否仍显著优于投机解码，论文未给出回答。
