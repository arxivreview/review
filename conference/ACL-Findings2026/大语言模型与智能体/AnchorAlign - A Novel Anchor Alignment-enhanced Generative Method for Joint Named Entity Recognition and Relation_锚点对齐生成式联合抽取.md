# ACL-Findings2026最新论文 ｜AnchorAlign: A Novel Anchor Alignment-enhanced Generative Method for Joint Named Entity Recognition and Relation Extraction ｜锚点对齐生成式联合抽取

研究机构：哈尔滨工业大学

作者：Xiaolong Weng、Yuanyun Zhou、Boyu Qiu 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_0f6f1d74e668)

> 联合命名实体识别与关系抽取（Joint NER/RE）旨在从非结构化文本中同步提取实体及其关系，但现有生成式方法常因实体与关系在生成序列中位置错位或语义脱节，导致抽取结果内部不一致。本文指出，既有对齐机制仅关注跨任务依赖而忽略任务内依赖，且存在“一对多”匹配偏差。为此，AnchorAlign 提出锚点实体选择机制与双层级对齐模块，在概率空间强制实体-关系及关系-关系的语义一致性。该方法在五个基准上刷新了关系抽取的严格 F1 与边界 F1 纪录，但其对判别式模型在复杂依赖场景下的优势仍存疑，且未验证锚点机制在低资源或长尾实体上的鲁棒性。

## 研究背景

当生成式模型将结构化信息扁平化为线性序列时，实体与关系的生成顺序往往由解码器架构决定，而非语义逻辑。这种顺序刚性导致 NER 模块识别的实体与 RE 模块生成的关系在语义上脱节，即“实体-关系对齐偏差”。为缓解此问题，现有方法引入辅助损失对齐两个任务的输出，但通常采用最近邻匹配策略，将 NER 中的一个实体强行对齐到 RE 中仅一个关系，忽略了实体可能参与多个关系的“一对多”特性，进而引入系统性偏差。

生成式信息抽取（Generative IE）已取代判别式架构成为主流，其核心优势在于通过统一文本生成范式降低多任务耦合复杂度。然而，在联合 NER/RE 任务中，现有生成式框架（如 UIE、KnowCoder）的输出范式缺乏对任务内依赖（即关系间共享实体）的显式建模，且对齐机制局限于跨任务层面。AnchorAlign 的切入点在于引入“锚点实体”概念，将 NER 与 RE 共享的实体、以及 RE 内部多关系共享的实体定义为语义枢纽，通过双层级对齐机制在概率空间而非特征空间强制一致性，从而解决既有方法因匹配策略缺陷导致的对齐失效。

## 核心方法

### 生成式联合抽取参照系

本文基于 BARTNER 的编码器-解码器架构，采用结构化语言生成范式。与 UIE 等通用框架不同，AnchorAlign 针对联合 NER/RE 设计了双解码器结构：NER 解码器输出线性化实体序列，RE 解码器采用以主语为中心的因子化格式输出关系三元组。该参照系的关键差异在于，传统方法将 NER 和 RE 视为独立生成任务，而本文通过锚点机制将两者绑定为协同生成过程。

### 锚点实体选择与输出范式

设计动机在于解决既有方法中实体与关系生成顺序不一致导致的语义断裂。AnchorAlign 定义两类锚点：实体-关系锚点（NER 与 RE 共享的实体）和关系-关系锚点（RE 中多关系共享的实体）。NER 解码器输出格式为 $O_{NER} = (m_1, \langle t_1 \rangle, \dots, m_n, \langle t_n \rangle)$，其中 $m_i$ 为实体提及，$\langle t_i \rangle$ 为单 token 类型标签。RE 解码器采用主语中心格式，将同一主语的所有关系分组为块：$O_{RE} = (es_1, eo_{1,1}, \langle r_{1,1} \rangle, \dots, es_n, \dots)$。该设计通过显式分组确保关系-关系锚点在生成序列中的局部性，为后续对齐提供结构基础。

### 双层级锚点对齐机制

设计动机在于既有对齐损失在特征空间操作易受内部表示容量差异干扰，且在概率空间缺乏对负样本的显式抑制。本文提出跨任务语义对齐，在输出概率空间强制 NER 与 RE 解码器对锚点实体的预测分布一致。NER-RE 对齐损失定义为：

$$L_{NER,d} = \frac{1}{|E_d|} \sum_{e \in E_d} D_{KL}(p_{NER}(\cdot|e') \| p_d(\cdot|e))$$

其中 $p_{NER}$ 和 $p_d$ 分别为 NER 和 RE 解码器在受限词表上的预测分布，$e'$ 为 NER 中的对应锚点。该公式通过 KL 散度约束 RE 输出向 NER 的高置信度分布靠拢，实现决策级一致性。此外，引入负抑制机制，定义负集 $V_{neg} = \{v \in V_{restricted} | v \notin V_{NER} \land v \notin V_{RE}\}$，通过最小化负 token 的生成概率 $L_{suppress} = -\frac{1}{|N|} \sum_{v \in N} \log(1 - p_d(v|h_t))$ 锐化预测分布，避免无关 token 干扰。

## 实验评估

实验在 ACE05、SciERC、ADE、NYT 和 Text2DT 五个基准上进行，对比 UIE、REBEL、KnowCoder 等生成式基线及 PL-Marker、USM 等判别式基线。基线覆盖全面，但缺失对 YAYI-UIE 等大规模 LLM 基线的详细对比，且 PL-Marker 在 NYT 上的单标签约束与数据集多标签特性不兼容，导致部分结果不可比。

| 数据集 | 方法 | Relation Strict F1 | Relation Boundary F1 |
| :--- | :--- | :--- | :--- |
| SciERC | AnchorAlign | SOTA (+0.61%) | SOTA (+1.00%) |
| ADE | AnchorAlign | SOTA (+0.14%) | SOTA (+0.88%) |
| ACE05 | AnchorAlign | 第二 (落后 USM 0.65%) | SOTA (+0.72%) |
| Text2DT | AnchorAlign | - | SOTA (+0.12%) |
| NYT | AnchorAlign | - | 落后 USM |

AnchorAlign 在 SciERC 和 ADE 上刷新严格 F1 纪录，在四个数据集上刷新边界 F1 纪录，但在 ACE05 严格 F1 上略逊于判别式模型 USM，表明生成式框架在复杂依赖场景下仍有局限。消融实验未提供具体数值，但论文指出前向-反向 RE 对齐损失对缓解生成顺序偏差至关重要，负抑制机制对提升精度有显著贡献。

## 关联研究分析

从问题动机看，AnchorAlign 与 UIE 等通用生成式框架的核心差异在于对齐粒度的细化。UIE 将 IE 任务统一为文本到结构生成，但未显式建模实体-关系间的语义依赖，导致多任务场景下误差累积。AnchorAlign 通过锚点机制将对齐从任务级细化到实体级，解决了 UIE 在联合 NER/RE 中因缺乏内部一致性约束导致的精度瓶颈。这一差异源于任务特性：联合 NER/RE 中实体与关系的强耦合性要求更细粒度的对齐，而通用 IE 框架更关注任务扩展性。

从方法设计看，AnchorAlign 与判别式模型 USM 的对比揭示了生成式与判别式范式的根本分歧。USM 通过 token-token 和 label-token 链接子任务实现联合抽取，其优势在于显式建模实体边界，但在复杂依赖场景下易受模块间误差传播影响。AnchorAlign 通过概率空间对齐和负抑制机制，在生成式框架内实现了类似判别式模型的边界精度，但在 ACE05 上仍略逊于 USM，暗示生成式模型在长距离依赖建模上仍有不足。这一差异是否源于生成式架构的固有局限，还是可通过更复杂的解码策略弥补，论文未给出回答。

## 总结

AnchorAlign 针对联合 NER/RE 中实体-关系对齐偏差问题，提出锚点实体选择与双层级对齐机制，在概率空间强制语义一致性。该方法在 SciERC 和 ADE 上刷新严格 F1 纪录，在四个数据集上刷新边界 F1 纪录，证明了锚点机制的有效性。然而，其在 ACE05 上落后于判别式模型 USM，暴露了生成式框架在复杂依赖场景下的局限。当锚点实体数量激增或文本长度增加时，双解码器的计算开销与对齐损失的收敛稳定性是否受影响，论文未给出回答。
