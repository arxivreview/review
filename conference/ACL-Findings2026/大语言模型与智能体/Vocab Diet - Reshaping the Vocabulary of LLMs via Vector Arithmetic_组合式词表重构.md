# ACL-Findings2026最新论文 ｜Vocab Diet: Reshaping the Vocabulary of LLMs via Vector Arithmetic ｜组合式词表重构

研究机构：以色列耶路撒冷希伯来大学

作者：Yuval Reif、Guy Kaplan、Roy Schwartz

论文原文见 [arXiv](https://arxiv.org/abs/2510.17001)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_d84b8fd285dc)

> 大语言模型词表设计长期面临资源分配失衡：高频词的形态变体（如 walk, walked）占据大量独立 Token 槽位，挤压了多语言覆盖与低频词空间。现有 BPE 算法将形态变体视为独立单元，忽略了嵌入空间中已存在的线性结构。本文提出通过向量算术将词表重构为“基础词+变换向量”的组合形式，在冻结骨干的前提下释放 10-40% 的词表空间。该方法验证了 LLM 对组合式表示的内在理解能力，但派生词的低准确率暴露了线性假设在复杂形态学中的局限。

## 研究背景

当 LLM 处理多语言文本时，词表大小成为内存与计算的双重瓶颈。BPE（Byte-Pair Encoding）算法通过迭代合并高频子词对构建词表，其核心假设是频率决定 Token 独立性。然而，这一假设忽略了自然语言的形态学结构：同一词根的不同屈折形式（如复数、时态）在语义上高度相关，却在词表中被分配为独立向量。这种冗余不仅浪费内存，更导致词表在跨语言扩展时出现严重的资源挤兑——英语形态变体占据大量槽位，使得阿拉伯语等形态丰富语言难以获得足够的 Token 覆盖。

高效 LLM 架构研究通常聚焦于注意力机制或状态空间模型的复杂度优化，而词表层面的表示冗余常被忽视。主流路线包括扩大词表规模以提升主语言性能，或事后扩展特定领域 Token，但这些方法均受限于内存上限，且未触及词表内部的结构性浪费。本文切入点在于：LLM 嵌入空间已自发形成线性结构，能够捕捉词形变化关系，这为词表重构提供了数学基础。通过利用这一内在结构，可以在不增加模型参数的前提下，将词表从“表面形式集合”转化为“基础词与变换向量的组合空间”，从而在固定预算下实现更高效的资源分配。

## 核心方法

### 方法参照系

本文问题属于参数与稀疏优化范畴，但操作对象是词表而非权重矩阵。标准流程是通过低秩分解或结构化稀疏减少有效参数，而本文采用向量算术重构输入/输出嵌入矩阵，核心差异在于利用形态学先验将词表维度从 $|V_{orig}|$ 压缩至 $|V_b| + |V_t|$，其中 $V_b$ 为基础词集，$V_t$ 为变换向量集。

### 组合式嵌入表示

传统 BPE 为每个表面形式分配独立嵌入向量，导致形态变体间缺乏显式关联。本文引入变换向量 $e_t$，将表面形式 $w$ 的嵌入表示为：

$$e_w = e_{b_w} + \sum_{t_i \in T(w)} e_{t_i}$$

其中 $b_w$ 为 $w$ 的基础词，$T(w)$ 为 $w$ 的变换集合。该公式的物理含义是：词形变化可分解为基础词嵌入与若干线性偏移的叠加。设计动机在于解决 BPE 中形态变体独立学习导致的冗余问题——通过共享基础词向量，模型只需学习少量变换向量即可覆盖大量表面形式，从而释放词表空间。

### 组合式输出预测

在输出端，传统方法通过单一解嵌入矩阵 $U$ 计算所有 Token 的 logits。本文将其解耦为基础词矩阵 $U_b$ 与变换矩阵 $U_t$，对候选词 $w$ 的 logit 计算为：

$$\text{logit}(w) = h \cdot u_{b_w} + \sum_{t_i \in T(w)} h \cdot u_{t_i}$$

其中 $h$ 为隐藏状态。这一设计解决了输出端词表膨胀导致的内存带宽压力：通过分离基础词与变换的投影，模型可以在不增加解嵌入矩阵维度的情况下，动态组合生成任意表面形式的概率。改进价值在于，该机制天然支持词表外（OOV）词形的预测——只要基础词在词表中，其任意组合形式均可被生成，突破了 BPE 对词表边界的限制。

## 实验评估

实验基于 Llama-3-8B、Qwen2.5-7B 等模型，在英语、阿拉伯语等五种语言上评估。基线为原始 BPE 模型，未对比稀疏注意力或 SSM 架构，因本文聚焦表示层优化而非计算架构。主结果显示，组合式词表在下游任务中性能持平：

| 任务 | 基线 (Acc./EM) | 组合式 (Acc./EM) | Δ |
| :--- | :--- | :--- | :--- |
| ARC | 65.2 | 64.9 | -0.3 |
| SQuAD | 22.1 | 20.0 | -2.1 |
| Winogrande | 78.1 | 78.6 | +0.5 |
| Average | 66.9 | 65.9 | -1.0 |

核心数字表明，尽管词表缩减 41.6%，平均性能仅下降 1.0 分，验证了组合式表示的有效性。消融实验显示，屈折词（如复数、时态）的解析准确率高达 92-96%，而派生词（如 -able, -ness）仅为 31-45%，这一差距揭示了线性变换在捕捉语义衍生关系时的局限。评估边界方面，论文未报告置信区间，且预训练实验仅使用 1B Token 的 nanoGPT-124M，大规模预训练下的可扩展性未验证。代码已开源，但超参数配置（如 LoRA rank）未详细披露，可复现性存在一定门槛。

## 关联研究分析

从问题动机看，本文与 Multi-Query Attention (MQA) 均旨在减少内存占用，但作用层级不同：MQA 通过共享 KV 头降低注意力缓存，本文通过组合词表降低嵌入矩阵维度。关键差异在于，MQA 的优化依赖于注意力头的冗余性，而本文依赖于词形变化的线性可分解性。这一差异源于任务特性：注意力机制中头间相关性是统计涌现的，而词形变化是语言结构的固有属性，因此组合式词表的泛化性更强，但受限于形态学规则的覆盖范围。

从方法设计看，本文与 TwELL 稀疏格式同属参数稀疏化策略，但 TwELL 针对 FFN 权重的非结构化稀疏，本文针对词表的结构性稀疏。TwELL 需要专用 CUDA 内核实现加速，而本文的组合计算仅引入 0.8% 的解码延迟，无需硬件修改。这一差异暗示，词表层面的稀疏化可能比权重稀疏化更易于在现有硬件上落地，因为其计算开销远低于 GEMM 操作。然而，派生词的低准确率表明，当形态学关系超出线性变换的表达能力时，组合式词表的优势将减弱，这在形态丰富的语言（如阿拉伯语）中可能更为显著。

## 总结

本文要解决的核心矛盾是词表资源分配失衡与多语言覆盖需求之间的张力。现有 BPE 方法将形态变体视为独立单元，忽略了嵌入空间中的线性结构，导致词表冗余且扩展受限。本文抓住 LLM 嵌入空间已自发形成线性结构这一被忽略的点，通过向量算术将词表重构为组合形式，在冻结骨干的前提下释放 10-40% 的词表空间。实验证明，该重构在保持下游性能基本持平（平均下降 1.0 分）的同时，显著提升了词表效率。本文的边界在于派生词的低解析率（31-45%）暴露了线性假设在复杂形态学中的局限，且大规模预训练下的可扩展性未验证。当词表缩减比例超过 40% 时，组合计算的额外开销是否会被内存节省所抵消，论文未给出回答。
