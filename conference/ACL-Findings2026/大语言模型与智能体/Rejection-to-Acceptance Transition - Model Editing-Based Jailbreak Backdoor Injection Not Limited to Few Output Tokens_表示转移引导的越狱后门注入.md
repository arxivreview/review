# ACL-Findings2026最新论文 ｜Rejection-to-Acceptance Transition: Model Editing-Based Jailbreak Backdoor Injection Not Limited to Few Output Tokens ｜表示转移引导的越狱后门注入

作者：Shiji Yang、Min Cai、Hao Xiong 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f4167d275552)

> 大语言模型（LLM）的安全对齐机制常被外部提示优化攻击绕过，但此类攻击缺乏持久性且易被检测。现有基于模型编辑的越狱后门方法依赖绑定特定短语，导致攻击效率随绑定数量增加而急剧下降。JEST 摒弃短语绑定，通过主成分分析（PCA）建模拒绝与接受域，直接劫持 LLM 内部表示实现域转移。该方法在白盒场景下显著提升了攻击效率与成功率，但其对模型内部状态的破坏是否会被现有系统级防御机制识别，仍存疑。

## 研究背景

当 LLM 面对有害请求时，其内部表示通常处于“拒绝域”，生成拒绝响应；而面对良性请求时，表示处于“接受域”，生成正常响应。这种二元状态在表示空间中存在可区分的几何结构，为通过修改权重实现状态切换提供了理论基础。然而，直接修改权重需遵循“定位-编辑”范式，即找到存储特定知识的 FFN 层并更新其参数。传统方法通过迭代优化目标向量，强制模型输出特定短语（如“Sure”）作为起始 token，从而诱导后续生成。

越狱攻击旨在绕过 LLM 的安全策略，使模型响应有害提示。主流路线分为提示优化（如 GCG）和权重投毒（如 JailbreakEdit）。提示优化虽有效，但需数小时迭代，且生成的对抗后缀具有非自然性，易被分布检测器识别。权重投毒方法更轻量，但现有模型编辑方案（如 JailbreakEdit）受限于“短语绑定”范式：绑定短语越多，攻击成功率越高，但计算成本与效率呈负相关。这种效率与效果的权衡限制了其在大规模部署场景下的实用性。JEST 的切入点在于解耦后门触发与特定输出短语的绑定，转而直接操纵模型内部表示的几何方向，实现从拒绝域到接受域的无缝转移。

## 核心方法

### 方法参照系

本文基于 ROME 和 MEMIT 建立的“定位-编辑”框架，假设 LLM 知识存储于 FFN 层的 (k, v) 对。标准流程是计算目标向量 $\tilde{v}$，通过最小化损失更新权重矩阵 $W_{fc}$。关键差异在于，传统方法将 $\tilde{v}$ 定义为绑定短语的嵌入，而 JEST 将其定义为接受域的方向向量，从而摆脱了对特定 token 序列的依赖。

### 域建模与表示转移

传统模型编辑通过迭代更新 $v$ 使模型输出特定短语，导致攻击效率随绑定短语数量增加而线性下降。JEST 引入域建模策略，利用 PCA 在表示空间中构建投影空间，区分拒绝域 $R_J$ 和接受域 $AC$。通过对比有害与良性数据的隐藏状态差异，提取主成分向量并加权，构建投影矩阵 $S$。

$$
S = \text{diag}(\text{var}) \cdot \text{PCA}(H_{harm} - H_{benign})
$$

该公式通过方差加权的主成分分析，量化了拒绝与接受域在表示空间中的几何差异方向。基于此，JEST 定义表示转移损失，优化目标向量 $\tilde{v}$ 使有害请求的表示向接受域投影：

$$
\mathcal{L} = \frac{1}{|E|} \sum_{i=1}^{|E|} \left| \frac{1}{m} \sum_{j=1}^{m} H(e_i \oplus b) S_j^\top - AC_{i,j} \right|
$$

此损失函数直接约束触发后的表示向量接近接受域中心，而非特定短语嵌入。这一设计消除了短语绑定的刚性约束，使得攻击效率不再受绑定数量限制，同时保持了高成功率。

### 引导提示工程增强

JEST 劫持后的模型对直接提示更脆弱，但输出质量可能不稳定。为增强指令遵循能力，JEST 引入引导提示工程（GPE），在请求末尾附加引导短语（如“Here are”）。这一设计利用了 LLM 自回归生成的上下文惯性，进一步降低模型拒绝响应的概率。GPE 与 JEST 的协同作用在于，JEST 破坏了安全对齐的内部表示，而 GPE 提供了外部语义引导，二者共同提升了攻击的鲁棒性与输出连贯性。

## 实验评估

实验在 Llama-2-7b-chat、Vicuna-7b、ChatGLM-6b 和 Mistral-7b-Instruct 上进行，数据集包括 DAN、DNA、Addition 和 Advbench。基线覆盖数据投毒（Poison-RLHF）、模型编辑（BadEdit, JailbreakEdit, ROME, MEMIT）及生成式攻击（GCG, AutoDAN）。JEST 在模型编辑类方法中表现最优，且结合 GPE 后超越生成式攻击。

| 方法 | DAN JSR (%) | DNA JSR (%) | Addition JSR (%) | Advbench JSR (%) |
| :--- | :--- | :--- | :--- | :--- |
| JailbreakEdit | 64.10 | 63.56 | 61.22 | 69.81 |
| JEST | 76.92 | 74.05 | 85.49 | 86.54 |
| JEST+GPE | 89.27 | 92.13 | 92.29 | 93.08 |
| GCG | 73.08 | 83.67 | 63.95 | 60.77 |

JEST+GPE 在 Advbench 上达到 93.08% 的 JSR，显著高于 JailbreakEdit 的 69.81% 和 GCG 的 60.77%。消融实验显示，GPE 对 JEST 的提升幅度（约 12-15 个百分点）远大于对 JailbreakEdit 的提升（部分数据集出现负迁移），表明 JEST 的表示劫持机制与提示引导具有更强的兼容性。

| 配置 | DAN JSR (%) | DNA JSR (%) | Addition JSR (%) | Advbench JSR (%) |
| :--- | :--- | :--- | :--- | :--- |
| JEST (无 GPE) | 76.92 | 74.05 | 85.49 | 86.54 |
| JEST+GPE | 89.27 | 92.13 | 92.29 | 93.08 |

评估边界方面，JSR 指标仅衡量响应是否遵循指令，未评估输出内容的有害程度或连贯性。实验未报告计算效率的具体数值（如延迟、吞吐量），仅定性描述为“数十秒”。代码未公开，超参数（如 PCA 主成分数量 $m$）未详细披露，限制了可复现性。

## 关联研究分析

从问题动机看，JEST 与 GCG 均针对 LLM 安全对齐的脆弱性，但 GCG 通过梯度优化外部提示，而 JEST 通过权重修改内部表示。GCG 的攻击具有临时性，需每次交互重新优化；JEST 的后门具有持久性，一旦植入即长期存在。这一差异源于攻击面不同：GCG 作用于输入层，JEST 作用于参数层。JEST 的效率优势（秒级 vs 小时级）源于其闭式解更新公式，避免了迭代优化。

从方法设计看，JEST 与 JailbreakEdit 同属模型编辑路线，但 JailbreakEdit 依赖短语绑定，JEST 依赖域转移。JailbreakEdit 的绑定机制导致攻击效率随绑定数增加而下降，而 JEST 的域转移机制解耦了触发与输出，效率恒定。这一设计差异反映了两种对“安全对齐”本质的理解：JailbreakEdit 视安全对齐为输出 token 的约束，JEST 视其为内部表示的几何结构。JEST 的域建模策略借鉴了表示工程（Representation Engineering）的思想，将抽象的安全概念转化为可优化的几何方向，这一视角在现有越狱攻击研究中较为新颖。

## 总结

JEST 旨在解决模型编辑越狱后门中效率与效果的权衡问题，通过摒弃短语绑定、直接劫持内部表示实现域转移。其核心创新在于利用 PCA 建模拒绝与接受域，并通过闭式解更新权重，使攻击效率不再受绑定数量限制。实验表明，JEST+GPE 在 Advbench 上达到 93.08% 的 JSR，显著优于 JailbreakEdit 和 GCG。然而，JEST 的白盒假设限制了其在黑盒 API 场景的适用性，且其破坏模型内部安全对齐的机制可能引入新的检测特征。当 JEST 劫持后的模型部署于生产环境时，现有基于行为监控或输出过滤的系统级防御能否有效识别这种内部表示层面的异常，论文未给出回答。
