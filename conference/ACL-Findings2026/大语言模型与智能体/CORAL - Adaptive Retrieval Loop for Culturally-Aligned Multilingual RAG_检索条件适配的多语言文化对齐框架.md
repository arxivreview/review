# ACL-Findings2026最新论文 ｜CORAL: Adaptive Retrieval Loop for Culturally-Aligned Multilingual RAG ｜检索条件适配的多语言文化对齐框架

研究机构：三星研究院

作者：Nayeon Lee、Jiwoo Song、Byeongcheol Kang

论文原文见 [arXiv](https://arxiv.org/abs/2604.25676)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.25676)

> 多语言检索增强生成（mRAG）在处理文化特定查询时，常因固定检索空间导致语义相关但文化错位的证据被召回，进而生成形式正确但实质错误的回答。现有迭代检索方法仅优化查询本身，未触及语料库选择这一根本变量，使得低资源文化场景下的检索噪声无法消除。CORAL 通过 Planner-Critic 反馈循环，在测试时动态调整检索语料库范围并重写查询，将检索条件本身作为可修正的决策变量。该框架在低资源语言文化问答中实现了最高 3.58% 的准确率提升，但其效果高度依赖规划器模型的能力，且未验证在开放域生成场景中的泛化性。

## 研究背景

当用户询问“印尼西爪哇地区传统节日人们通常去哪里”时，标准 mRAG 系统会从混合多语言语料库中检索语义相关的文档。然而，由于英语及高资源语言在维基百科等语料库中占据主导，检索结果往往包含关于“印尼旅游”的泛化内容，而非西爪哇本地习俗的具体证据。这种“检索条件错位”（Retrieval Condition Misalignment）导致模型虽拥有正确的事实知识，却因证据源的文化错位而生成刻板印象或错误答案。该问题的核心在于，传统 mRAG 将多语言支持视为嵌入空间或翻译问题，隐含假设检索空间是固定的，忽略了语料库选择对文化对齐的决定性影响。

文化对齐领域的主流路线分为评估基准构建、机制解释与对齐干预三类。评估基准如 BLEnD 和 CultureScope 量化了模型在文化常识上的偏差，但多依赖选择题形式，存在捷径学习风险。机制解释路线通过稀疏自编码器（SAE）揭示模型内部文化表征的稀疏性与语言纠缠，但侧重于白盒分析而非推理时干预。对齐干预路线中，微调方法如 CuMA 通过适配器混合解决“均值坍缩”，但需重新训练权重；提示工程方法如 Prompt Programming 效率低且难以泛化。现有迭代检索方法如 Self-RAG 虽引入反馈机制，但仅优化查询重写，未动态调整检索源。CORAL 的切入点在于将检索条件适配视为文化对齐的关键环节，主张在测试时通过反馈循环同时修正“从哪里检索”和“检索什么”，从而在不修改模型权重的前提下解决文化错位问题。

## 核心方法

### 方法参照系

标准 mRAG 流程为：查询嵌入 → 固定多语言语料库检索 → Top-K 文档生成。该流程假设检索空间是静态的，查询仅作为检索探针。本文的关键差异在于，将语料库选择（Corpus Selection）与查询重写（Query Rewriting）均纳入反馈循环，使检索条件成为动态可修正变量，而非固定配置。

### 动态语料库选择与证据验证

在标准 RAG 中，检索器从固定语料池中获取文档，缺乏对文化相关性的显式控制。CORAL 引入 Planner 代理，根据查询内容动态选择目标语料库子集。Planner 不仅选择查询语言对应的语料库，还基于文化线索（如本地机构、习俗）扩展至区域高资源邻近语言语料库。例如，对于西爪哇（Sundanese）查询，Planner 会同时选择 Sundanese 和 Indonesian 语料库。检索后，Critic 代理对文档进行四维评分：相关性（$s_{rel}$）、有用性（$s_{use}$）、清晰度/特异性（$s_{spec}$）和上下文兼容性（$s_{comp}$）。文档总分 $s_{tot}$ 计算如下：

$$ s_{tot} = s_{rel} + s_{use} + s_{spec} + s_{comp} $$

该公式的物理含义是，只有当文档在文化兼容性维度上得分足够高时，才被保留为有效证据。设计动机在于，传统 RAG 仅基于语义相似度排序，无法区分“语义相关但文化错位”的文档（如关于印尼旅游的泛化内容）与“文化对齐”的文档（如西爪哇本地习俗）。通过引入 $s_{comp}$ 维度，Critic 显式过滤掉文化不匹配的噪声，确保生成器仅接收文化对齐的证据。

### 反馈驱动的查询重写与充分性检查

在动态语料库选择基础上，CORAL 进一步引入查询重写机制。当 Critic 判定证据不足时，Planner 根据 Critic 的文本反馈重写查询。重写类型包括：窄化（Narrow，添加约束）、改写（Paraphrase，优化检索友好性）和扩展（Expand，扩大范围）。查询重写并非简单翻译，而是澄清隐含约束、消歧语境依赖术语。充分性检查（Sufficiency Check）由 Critic 执行，判断当前验证证据集是否足以可靠回答查询。若关键约束缺失或证据矛盾，系统触发新一轮迭代，Planner 重新选择语料库并重写查询。该机制解决了固定检索空间中“查询仅优化、语料库不变”的局限，使系统能够根据证据质量动态调整检索策略。设计动机在于，低资源文化场景下，初始检索往往返回主题相关但信息不足的文档，通过反馈驱动的查询重写，系统能够逐步聚焦于更具信息量的文化特定证据，从而提升检索精度。

## 实验评估

实验在 BLEnD（13 语言，16 国家）和 CLIcK（韩语，1345 查询）两个文化问答基准上进行，使用 LLAMA-3.2-3B-INSTRUCT 作为生成器，QWEN3-235B 和 GPT-OSS-120B 作为 Planner/Critic。基线包括 Non-RAG、monoRAG、multiRAG、crossRAG 和 tRAG，覆盖了固定检索、翻译检索和多语言池化检索等主流路线，但缺失 Self-RAG 的直接对比（仅在附录提及）及其他文化对齐微调方法如 CuMA。

| 方法 | BLEnD-low (su) | BLEnD-mid (fa) | BLEnD-high (es) | CLIcK |
| :--- | :--- | :--- | :--- | :--- |
| Non-RAG | 58.04 | 62.09 | 68.59 | 48.10 |
| multiRAG | 61.89 | 67.97 | 67.98 | 53.75 |
| CORAL (QWEN3-235B) | 66.78 | 72.22 | 71.93 | 58.88 |

CORAL 在低资源语言（Sundanese）上取得 66.78% 的准确率，相比 multiRAG 的 61.89% 提升 4.89 个百分点，相比 Non-RAG 提升 8.74 个百分点。在 CLIcK 上，CORAL 达到 58.88%，显著优于 multiRAG 的 53.75%。这些结果表明，动态语料库选择与查询重写在低资源文化场景中具有显著优势，且效果不依赖于特定模型家族。

消融实验显示，动态语料库选择单独贡献了 5.78 个百分点（BLEnD-mid）和 3.21 个百分点（CLIcK）的提升，查询重写在此基础上进一步增加 2.36 个百分点（BLEnD-low）。这表明语料库选择是主要增益来源，查询重写起辅助优化作用。固定语料库消融实验（Table 2）显示，即使使用 Oracle 语料库（$C_{own}$），固定检索仍低于 CORAL，证明增益并非源于简单包含英语或特定语料库，而是源于反馈驱动的动态适配。

评估边界方面，实验仅覆盖选择题问答，未验证开放域生成场景中的文化对齐效果。语料库限于维基百科，可能偏向百科式知识，无法覆盖程序性、经验性或本地传播的文化信息。代码未公开，但提供了详细提示词和配置，可复现性较高。

## 关联研究分析

从问题动机看，CORAL 与 ValuesRAG 均通过 RAG 注入外部知识，但 ValuesRAG 侧重于价值观对齐，通过检索价值观相关文档提升模型输出的文化一致性；CORAL 则聚焦于检索条件错位，通过动态语料库选择解决证据源的文化错位问题。这一差异源于任务特性：ValuesRAG 假设语料库已包含价值观信息，仅需优化检索策略；CORAL 发现低资源文化场景下，语料库本身的文化代表性不足，需动态调整检索源。CORAL 的 Planner 机制实际上隐式执行了文化意图识别，将查询映射到特定文化语料库，这与 ValuesRAG 的静态价值观检索形成对比。

从方法设计看，CORAL 与 Self-RAG 均采用迭代检索，但 Self-RAG 仅优化查询重写，未动态调整语料库；CORAL 将语料库选择纳入反馈循环，使检索条件成为可修正变量。这一设计差异源于对失败模式的诊断：Self-RAG 假设检索空间固定，问题在于查询不够精确；CORAL 发现文化错位问题源于检索空间本身的文化偏差，需动态调整。CORAL 的 Critic 评分机制引入了文化兼容性维度，这是 Self-RAG 所缺乏的，使其能够显式过滤文化不匹配的文档。然而，CORAL 的效果高度依赖 Planner 模型的能力，若 Planner 本身存在文化偏见，可能导致语料库选择偏差，这一潜在风险论文未深入探讨。

## 总结

CORAL 旨在解决多语言 RAG 中因固定检索空间导致的文化错位问题，通过 Planner-Critic 反馈循环动态调整语料库选择与查询重写，将检索条件作为可修正变量。该方法在低资源语言文化问答中实现了最高 3.58% 的准确率提升，验证了动态检索条件适配的有效性。然而，实验仅覆盖选择题场景，语料库限于维基百科，且效果高度依赖 Planner 模型能力。当 Planner 模型本身存在文化偏见时，动态语料库选择是否可能引入新的偏见源，论文未给出回答。
