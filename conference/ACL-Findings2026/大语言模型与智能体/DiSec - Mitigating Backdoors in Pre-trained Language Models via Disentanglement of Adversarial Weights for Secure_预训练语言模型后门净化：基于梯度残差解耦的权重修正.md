# ACL-Findings2026最新论文 ｜DiSec: Mitigating Backdoors in Pre-trained Language Models via Disentanglement of Adversarial Weights for Secure Fine-Tuning ｜预训练语言模型后门净化：基于梯度残差解耦的权重修正

研究机构：美国阿肯色大学

作者：Sunanda Das、Qinghua Li

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_fd850f9bb64f)

> 预训练语言模型（Pre-trained Language Models, PLMs）在供应链分发中面临任务无关后门威胁，即攻击者在预训练阶段植入触发器，导致模型在下游微调后仍保留恶意行为。现有防御方法多依赖下游标签或干净参考模型，无法在真实部署场景中独立净化被污染的预训练检查点。DiSec 利用无标签辅助文本计算梯度残差，通过奇异值分解（SVD）与变分自编码器（VAE）联合检测异常权重行，并采用层内原型均值修正替代剪枝，在无需下游监督的情况下抑制攻击成功率。该方法在 BERT 和 RoBERTa 上实现了效用保持与攻击抑制的平衡，但其对非线性复杂后门结构的鲁棒性及在生成式大语言模型上的泛化能力仍存疑。

## 研究背景

预训练语言模型（PLMs）如 BERT 和 RoBERTa 通过掩码语言建模（Masked Language Modeling, MLM）学习通用语言表示，其开源分发机制使得单一被污染的检查点可波及所有下游应用。任务无关后门攻击（Task-Agnostic Backdoor Attack）利用预训练阶段的 MLM 目标，将触发器与恶意行为绑定，使得后门在下游全参数微调后依然存活。这种攻击范式突破了传统任务特定后门的局限，因为防御者通常无法获取下游任务标签或攻击者的触发器知识，导致基于输入监控或标签依赖的防御手段失效。

当前防御路线主要分为输入级检测与模型级净化。输入级方法如 ONION 和 RAP 通过监控推理时的熵变或困惑度异常来识别投毒输入，但难以应对隐蔽的任务无关触发器。模型级净化方法如 Fine-Pruning 和 RECIPE 试图直接修改模型权重，但前者依赖干净验证集进行神经元剪枝，后者需要计算昂贵的持续预训练过程，且 RECIPE 在不同数据集上的攻击成功率（AASR）波动较大（如 NeuBA BERT 在 HSOL 上 AASR 高达 60.69%）。DiSec 的切入点在于构建一个完全无监督、无参考模型的净化框架，仅利用任务无关的干净文本，通过内部梯度信号的统计异常性定位并修正后门载体，从而在微调前消除供应链风险。

## 核心方法

### 梯度残差正交化与双模态异常检测

模型级净化的标准流程通常涉及识别并移除或重训练受污染的神经元。DiSec 的关键差异在于不执行剪枝或重训练，而是通过梯度空间中的统计异常性进行权重修正。首先，计算干净辅助数据上的累积梯度矩阵 $G_l$，并正交化去除与原始权重 $W^{(0),l}$ 对齐的良性分量，得到残差梯度 $G^\perp_l = G_l - \frac{\langle G_l, W^{(0),l} \rangle}{\|W^{(0),l}\|^2} W^{(0),l}$。这一操作剥离了参数空间中已有的良性方向，使异常信号凸显。随后，对 $G^\perp_l$ 进行秩 $k$ 截断 SVD，计算每行的谱异常分数 $z_i = \max_j \frac{C^{(l)}_{i,j} - \mu_j}{\sigma_j}$，其中 $C^{(l)} = U_k \Sigma_k$。当 $z_i$ 超过全局阈值 $\tau_{svd} = \mu_z + \tau \sigma_z$ 时，标记为谱异常。设计动机在于，SVD 能捕获与主成分对齐的线性偏差，但无法检测偏离主方向的非线性异常，因此引入 VAE 作为互补检测器。

### 变分自编码器重构误差与原型均值修正

为捕获非线性偏差，DiSec 训练一个轻量级 VAE 重构残差梯度行 $x_i$，其损失函数为 $L_{vae}(x_i) = \text{MSE}(x_i, \hat{x}_i) + D_{KL}(q(z|x_i) \| p(z))$。重构误差 $e_i = \frac{1}{n_l}\|x_i - \hat{x}_i\|^2_2$ 超过均值加两倍标准差的行被标记为生成异常。最终异常集 $S^{(l)}_{union}$ 为谱异常与生成异常的并集。修正阶段不删除异常行，而是计算干净行 $S^{(l)}_{normal}$ 的均值原型 $\bar{w}^{(l)}$，并将所有异常行替换为该原型：$W^{(l)}_{i,*} \leftarrow \bar{w}^{(l)}$ for $i \in S^{(l)}_{union}$。这一设计解决了剪枝导致的结构破坏与性能损失问题，因为原型位于层内观察到的参数流形内，修正操作是幂等的且保持模型结构完整性，避免了 Fine-Pruning 中因移除低激活神经元而导致的通用能力下降。

## 实验评估

实验在 SST-2、HSOL 和 AG News 三个分类数据集上评估 DiSec 对 POR、BadPre 和 NeuBA 三种任务无关攻击的防御效果，基线包括 RECIPE、ONION 及 Fine-Pruning 系列变体。DiSec 在 POR-BERT/SST-2 上取得 13.12% 的 AASR 和 89.02% 的 ACC，显著优于 RECIPE 的 39.60% AASR 和 ONION 的 17.09% AASR，同时保持接近无防御模型的准确率。

| 模型 | 数据集 | ACC (%) | AASR (%) | MASR (%) |
| :--- | :--- | :--- | :--- | :--- |
| POR BERT (DiSec) | SST-2 | 89.02 | 13.12 | 15.68 |
| POR BERT (RECIPE) | SST-2 | 89.51 | 39.60 | 82.95 |
| POR BERT (ONION) | SST-2 | 91.60 | 17.09 | 19.63 |
| BadPre BERT (DiSec) | SST-2 | 88.85 | 11.79 | 13.93 |
| NeuBA BERT (DiSec) | SST-2 | 88.96 | 12.20 | 14.69 |

消融实验表明，SVD 与 VAE 的并集检测优于单一检测器，原型均值修正优于噪声注入或干净模型行替换。在自适应攻击测试中，攻击者引入异常正则化项以抑制梯度残差信号，DiSec 仍将 SST-2 上的 AASR 从 100.00% 降至 19.45%，证明了其在更强威胁模型下的鲁棒性。然而，盲应用 DiSec 到所有 12 层而非选定的 Top-K 脆弱层，会导致 BadPre 和 NeuBA 模型的 ACC 下降 3.07% 至 1.86%，且 AASR 上升，表明选择性层定位是性能稳定的关键。

评估边界受限于分类任务范式，未覆盖生成式 LLM 的推理链后门。指标方面，AASR 和 MASR 未报告置信区间，且缺乏跨骨干网络的对比。可复现性方面，代码已开源，实验在单张 NVIDIA A100 GPU 上完成，DiSec 运行时间为 174.79 秒，远低于 ONION 的 1451.40 秒，但高于 Fine-Pruning 的 97.91 秒，计算成本适中。

## 关联研究分析

从问题动机看，DiSec 与 RECIPE 同属无下游监督净化路线，但 RECIPE 依赖持续预训练来“遗忘”后门，计算开销大且在不同数据集上表现不稳定（如 NeuBA BERT 在 AG News 上 AASR 为 18.46%）。DiSec 采用一次性权重修正，避免了训练过程的不可控性，其核心差异在于将后门消除建模为梯度空间中的统计异常检测问题，而非优化问题。这一选择使得 DiSec 在跨数据集泛化上更稳定，但可能无法处理那些梯度信号微弱、仅通过深层非线性交互激活的后门，因为 SVD 和 VAE 均基于局部梯度统计，缺乏全局推理路径的追踪能力。

从方法设计看，DiSec 与 CSO-LLM 均利用内部表示进行后门检测，但 CSO-LLM 侧重触发器逆向以支持后续防御，而 DiSec 侧重直接净化权重。CSO-LLM 需要访问中间层特征并执行类子空间正交化，计算密集且依赖白盒特征访问；DiSec 仅需梯度累积，计算更轻量。关键差异在于，DiSec 的 VAE 检测器假设干净梯度服从低维流形，而后门梯度偏离该流形。这一假设在预训练阶段的 MLM 任务中成立，因为 MLM 目标相对简单，梯度分布较为集中。但在生成式 LLM 中，由于任务复杂性和 CoT 推理的存在，梯度分布可能更加分散，VAE 的重构误差阈值可能失效，导致漏检或误检。

## 总结

DiSec 旨在解决预训练语言模型供应链中任务无关后门的净化难题，其核心矛盾在于缺乏下游标签与干净参考模型时如何精准定位并消除后门。现有方法如 RECIPE 依赖高成本持续预训练，Fine-Pruning 依赖剪枝导致性能损失，均无法在真实部署场景中独立运作。DiSec 通过梯度残差正交化与 SVD-VAE 双模态检测，结合原型均值修正，在无监督设定下实现了 13.12% 的 AASR 和 89.02% 的 ACC（POR-BERT/SST-2），证明了统计异常检测在权重净化中的有效性。其边界在于仅验证了分类式 PLM，且依赖梯度信号的显著性，对于梯度信号微弱或高度非线性的后门结构，检测能力可能受限。当骨干网络扩展至具有复杂推理能力的生成式 LLM 时，基于局部梯度统计的 VAE 检测器是否仍能准确区分良性与恶意更新，论文未给出回答。
