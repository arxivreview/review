# ACL-Findings2026最新论文 ｜BloomEval: A Bloom’s Cognitive Taxonomy-Based Benchmark for Evaluating LRMs via Cognitive Hierarchy Trace ｜基于布卢姆认知分类学的推理轨迹评估

作者：Zhiyi Duan、Lei Gao、Jiangshan Guan 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_49851fc007ae)

> 多跳推理与数学解题评估长期依赖最终答案的精确匹配，导致模型通过捷径或结构断裂的推理得出正确答案时无法被识别。现有过程评估多聚焦于逻辑一致性或因果验证，缺乏对推理步骤认知层级结构的系统性诊断。本文提出认知层级轨迹（Cognitive Hierarchy Trace, CHT），将布卢姆认知分类学（Bloom's Cognitive Taxonomy, BCT）映射至推理步骤，构建大规模基准BloomEval以量化层级跳跃与断裂。该方法揭示了答案正确性与认知结构完整性之间的解耦，但受限于数学领域单一性及线性层级假设的普适性存疑。

## 研究背景

当大型推理模型（Large Reasoning Models, LRMs）在数学任务上取得高准确率时，其内部推理过程往往呈现为黑盒。传统评估指标如精确匹配（Exact Match, EM）仅关注结果，无法区分“有效逻辑推导”与“表面模式匹配”。这种评估盲区源于思维链（Chain-of-Thought, CoT）生成的非忠实性：模型可能通过事后合理化生成看似连贯但认知结构断裂的轨迹。为诊断此类问题，需引入能解析推理步骤认知深度的结构化框架。

多跳推理评估领域已从结果导向转向过程导向，Process Reward Models (PRM) 等工具实现了步骤级验证，但主要聚焦于事实正确性或逻辑连贯性，未触及认知操作的层级结构。布卢姆认知分类学（BCT）在教育心理学中定义了从记忆到创造的六级认知层级，为量化认知深度提供了理论依据。然而，现有研究多将BCT用于静态任务标注，缺乏对动态推理轨迹中认知层级演进的细粒度分析。本文切入点在于将BCT从任务级标签扩展至步骤级轨迹映射，解决“答案对但认知结构错”的诊断难题。

## 核心方法

### 方法参照系

过程评估的标准流程通常涉及生成推理轨迹、提取中间步骤、验证逻辑一致性。本文问题与该通用流程的关键差异在于：不验证步骤间的事实依赖，而是验证步骤所对应的认知操作层级是否符合BCT的递进结构。

### 认知层级轨迹映射

CHT将推理过程建模为有序序列 $C = \{(s_i, l_i)\}_{i=1}^N$，其中 $s_i$ 为原子推理步骤，$l_i$ 为其对应的BCT认知层级。映射通过认知过程动词（Cognitive Process Verbs）实现，例如“Recall”映射至Level 1（Remember），“Construct”映射至Level 6（Create）。为解决动词多义性，引入最大池化原则：若一步涉及多种认知操作，取最高层级。该设计解决了自由形式CoT中认知深度不可量化的问题，使结构异常可被检测。

$$
l_i = \max\{l_j \mid s_i \text{ contains cognitive operation } j\}
$$

此公式表明，步骤的认知层级由其包含的最高阶认知操作决定，确保轨迹反映最深层的认知努力。

### 结构异常诊断指标

基于CHT，定义三类结构异常：层级断裂（Hierarchy Break）、层级跳跃（Hierarchy Jump）和过度思考（Overthinking）。层级断裂指轨迹未达到任务要求的认知层级；层级跳跃指跳过必要中间层级；过度思考指使用超出任务要求的认知操作。这些指标量化了推理轨迹的结构完整性，弥补了EM指标无法捕捉认知结构缺陷的不足。

## 实验评估

实验在1,000道分层采样的数学题上进行，覆盖GSM8K、MATH等数据集，对比GPT-4o、DeepSeek-R1等14个LLM/LRM。基线覆盖主流推理模型，但缺乏RAG类方法对比，因本文聚焦认知结构而非知识检索。

| 模型 | Zero-shot Avg | Few-shot Avg |
| :--- | :--- | :--- |
| Grok-3 | 0.476 | 0.580 |
| DeepSeek-R1 | 0.453 | 0.553 |
| GPT-4o | 0.417 | 0.536 |

Few-shot设置下，所有模型在高层级认知任务上提升显著，表明结构化提示能增强认知轨迹的连贯性。

| 模型 | Break (Correct) | Break (Incorrect) |
| :--- | :--- | :--- |
| Kimi k1.5 | 0.158 | 0.417 |
| Grok-3 | 0.088 | 0.337 |

错误答案样本中层级断裂率显著高于正确答案，证实结构完整性与结果正确性的强相关性。

评估边界受限于数学领域单一性，未验证BCT在代码或常识推理中的适用性。代码未开源，超参数细节有限，可复现性依赖API访问。

## 关联研究分析

从问题动机看，CaSE侧重因果一致性验证，而本文聚焦认知层级结构。CaSE通过因果图检测逻辑断裂，本文通过BCT映射检测认知深度缺失。差异根源在于任务特性：数学解题强调认知操作的递进性，而通用推理更关注事实依赖。

从方法设计看，CRAFT使用XML格式结构化轨迹，本文使用BCT标签。CRAFT通过双奖励提升轨迹忠实度，本文通过层级映射量化结构异常。CRAFT的格式约束增强了可审计性，但可能限制生成自由度；本文的层级映射提供了更细粒度的诊断维度，但依赖BCT线性假设。

## 总结

本文核心矛盾在于答案正确性与认知结构完整性的解耦。现有方法无法诊断“答案对但认知错”的捷径学习，本文通过CHT将BCT映射至推理步骤，实现结构异常的量化。实验显示Kimi k1.5在错误答案中层级断裂率达0.417，证实结构缺陷与结果错误的强关联。边界在于数学领域单一性及BCT线性假设的普适性未验证。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
