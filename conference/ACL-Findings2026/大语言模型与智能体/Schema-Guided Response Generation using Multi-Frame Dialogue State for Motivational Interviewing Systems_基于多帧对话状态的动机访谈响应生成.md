# ACL-Findings2026最新论文 ｜Schema-Guided Response Generation using Multi-Frame Dialogue State for Motivational Interviewing Systems ｜基于多帧对话状态的动机访谈响应生成

作者：Jie Zeng、Yukiko Nakano

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_98d0df49da8a)

> 动机访谈（Motivational Interviewing, MI）旨在通过协作式对话激发客户内在改变动机，而非由咨询师直接提供建议。现有大语言模型（LLM）驱动的MI系统常陷入“建议导向”陷阱，即过度依赖AI生成具体解决方案，导致客户自主性丧失与改变谈话（Change Talk, CT）频率低下。本文提出SGR-MI，通过多帧对话状态追踪与基于检索的对话策略生成，在低资源场景下实现MI原则的严格遵循。该方法在真实用户研究中显著降低了非MI行为率并提升了CT激发效率，但其策略池的构建依赖LLM生成的伪策略，缺乏独立临床验证，且文本交互形式限制了CT的绝对数量上限。

## 研究背景

MI的核心机制在于通过反思性倾听与开放式提问，引导客户自我表达改变理由，从而强化其内在动机。这一过程要求咨询师精准捕捉客户话语中的目标、问题、经验与计划等关键信息，并据此动态调整对话策略。然而，LLM在处理此类长程、多话题交织的对话时，往往缺乏对细粒度语义结构的显式建模，导致响应偏离MI原则，表现为未经请求的建议或对抗性回应。

当前主流MI对话系统主要采用提示工程或策略学习两种路线。提示工程方法（如MI-FS）虽能注入MI原则，但缺乏对对话状态的动态追踪，易在长对话中产生策略漂移；策略学习方法（如DIIR）虽能学习对话策略，但依赖大规模标注语料与规则归纳，在低资源场景下泛化能力受限。本文切入点在于：如何利用少量标注数据，通过结构化对话状态与动态策略检索，实现低资源下的MI原则遵循，同时抑制AI过度主导倾向。

## 核心方法

### 方法参照系

本文问题可置于任务导向对话（Task-Oriented Dialogue, TOD）的对话状态追踪（DST）与策略生成框架下，但关键差异在于：TOD的槽位值通常预定义且有限，而MI对话中需提取的信息（如客户的具体障碍、过往尝试）高度开放且随对话动态演化，要求系统具备灵活的多话题状态管理能力。

### 多帧对话状态追踪

传统DST将对话状态表示为单一槽位集合，难以处理MI中并存的多个相关话题（如“减肥目标”与“饮食障碍”）。本文引入多帧对话状态，将每个话题映射为独立帧，帧类型包括GoalAndIdealFrame、ProblemAndTroubleFrame、ExperienceFrame与ImprovementPlanFrame。状态更新机制通过LLM解析当前对话历史与最新客户输入，生成新帧或更新现有帧属性。为缓解LLM生成状态时的遗漏或冗余问题，引入后处理步骤：

$$
DS_{new} = \text{Merge}(DS_{old}, \Delta DS_{LLM})
$$

其中$\Delta DS_{LLM}$为LLM生成的状态差异，Merge操作通过比对帧索引与属性值，将新增或变更部分合并至原状态，确保状态完整性与一致性。该设计解决了单帧表示在多话题MI对话中信息丢失的问题，使系统能同时追踪客户的目标、障碍与计划。

### 基于检索的对话策略生成

策略生成模块决定下一轮咨询师的响应意图与信息聚焦。传统方法依赖预定义规则或SFT训练的策略模型，本文采用伪策略池检索机制。首先，利用LLM从专业MI语料自动生成伪策略池，每个伪策略包含意图（intent）、聚焦帧（focuses）、寻求帧类型（seek_frame_type）与寻求属性（seek_attribute）。推理时，系统基于当前对话状态与历史，通过XLM-R Longformer计算嵌入相似度，检索最相关的伪策略作为少样本示例：

$$
S_{retrieved} = \arg\min_{s \in Pool} \text{Dist}(E(DS_{current}, H_{current}), E(DS_s, H_s))
$$

其中$E(\cdot)$为嵌入函数，$DS_{current}$与$H_{current}$为当前状态与历史。LLM基于检索示例生成真实策略，再据此生成响应。该机制避免了大规模策略标注需求，通过动态少样本学习实现低资源下的策略泛化，同时通过聚焦具体帧属性（如“effect”）引导咨询师提出针对性问题，而非泛泛建议。

## 实验评估

实验在Diet-MI（单域）与AnnoMI（多域）两个MI语料上构建对话系统，对比MI-FS（提示基线）、DIIR（策略学习基线）与CAMI（模拟器基线）。用户研究招募192名参与者，采用2×4被试间设计，评估MI原则遵循度、改变谈话频率与主观印象。

| 方法 | %CR↑ | R/Q↑ | %MINA↓ | %AL↑ | %TTT↓ |
|---|---|---|---|---|---|
| MI-FS | 50.4† | 1.06 | 9.8 | 11.7 | 71.5 |
| DIIR | 42.2 | 1.76† | 5.8 | 42.4 | 69.2 |
| SGR-MI | 35.5 | 0.94 | 0.0† | 86.6 | 59.6† |
| GT | 52.3 | 1.94 | 0.7 | 64.5 | 54.0 |

SGR-MI在非MI行为率（%MINA）上达到0.0%，显著优于MI-FS（9.8%）与DIIR（5.8%），接近专业咨询师基准（GT, 0.7%），表明其严格遵循MI原则。在主动倾听率（%AL）上，SGR-MI（86.6%）远超基线，验证了其通过提问而非建议引导对话的有效性。

消融实验显示，移除策略生成模块（SGR-MI w/o Strategy）后，%MINA升至13.7%，%AL降至46.1%，证实策略检索对MI原则遵循的关键作用。CT频率方面，SGR-MI在Diet-MI与AnnoMI上分别为3.96与3.88次/会话，虽低于GT（21.7与31.5次），但“由建议触发的CT”比例仅为3.2%与1.1%，远低于MI-FS（78.7%与82.8%）与DIIR（25.9%与44.7%），表明其激发的CT更源于客户自主反思而非咨询师引导。

评估边界方面，用户研究样本量（192人）适中，但仅覆盖英语母语者，且文本交互形式可能天然抑制深度自我披露，导致CT绝对数量低于语音对话的GT。代码与数据集已开源，但伪策略池的生成依赖特定LLM版本，跨模型泛化性未验证。

## 关联研究分析

从问题动机看，SGR-MI与MAGneT（Mandal et al., 2025）均关注长对话中的治疗漂移，但MAGneT通过多智能体分解任务提升合成数据保真度，侧重离线数据生成；SGR-MI则聚焦实时对话控制，通过多帧状态与策略检索实现动态干预。差异根源在于任务阶段：MAGneT解决训练数据稀缺，SGR-MI解决推理时策略一致性。SGR-MI未探索多智能体协作，其单LLM多阶段调用在长程对话中的稳定性是否优于MAGneT的多智能体架构，论文未给出对比。

从方法设计看，SGR-MI与DIIR（Xie et al., 2024）同属策略学习路线，但DIIR依赖规则归纳与SFT训练，需大规模标注语料；SGR-MI采用零样本提示与伪策略检索，仅需少量标注数据。差异源于资源假设：DIIR假设充足标注数据，SGR-MI针对低资源场景。SGR-MI的伪策略池由LLM生成，其质量是否足以替代人工标注的策略规则，尤其在复杂临床情境下，论文仅通过用户研究间接验证，缺乏独立临床专家评估。

## 总结

SGR-MI旨在解决LLM在MI对话中过度主导导致客户自主性丧失的核心矛盾，其切入点在于通过多帧状态追踪与动态策略检索，在低资源下实现MI原则的细粒度控制。方法上，该框架将开放话题映射为结构化帧，并通过检索增强生成策略，避免了大规模标注依赖。实验证明，SGR-MI将非MI行为率降至0.0%，主动倾听率提升至86.6%，显著优于基线。然而，其边界在于：伪策略池的LLM生成质量缺乏独立临床验证，且文本交互形式限制了CT的绝对数量，导致与语音对话GT存在数量级差距。当伪策略池规模扩大或引入临床专家反馈时，策略检索的精度是否足以弥补文本交互的固有局限，论文未给出回答。
