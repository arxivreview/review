# ACL-Findings2026最新论文 ｜AMA: Adaptive Memory via Multi-Agent Collaboration ｜多智能体协作的自适应记忆框架

研究机构：香港科技大学、山东大学

作者：Weiquan Huang、Zixuan Wang、Hehai Lin 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.20352)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.20352)

> 长时程智能体交互面临的核心矛盾是存储粒度与检索需求之间的静态错配，以及缺乏显式一致性维护导致的逻辑矛盾累积。现有Agentic Memory系统虽引入LLM抽象，但普遍依赖固定分块或单一控制器，无法在推理时动态对齐任务复杂度，且更新机制粗糙导致冗余信息 unchecked 累积。本文提出AMA框架，通过解耦Constructor、Retriever、Judge、Refresher四个角色，实现多粒度存储、意图路由与逻辑审计的闭环。该设计在Token效率与知识更新准确率上表现优异，但其绝对性能仍低于最新结构化图谱基线，且多智能体协作带来的额外推理开销是否抵消了粒度适配收益，尚需更严格的效率-精度权衡验证。

## 研究背景

LLM智能体的长期记忆需解决两个耦合问题：一是如何从非结构化对话流中提取具备语义完整性的记忆单元，二是如何在长时程交互中维持这些单元的逻辑一致性。前者涉及记忆粒度选择，过粗的摘要引入噪声，过细的碎片破坏逻辑依赖；后者涉及冲突检测，新旧事实矛盾（如用户居住地变更）若未被显式识别，将导致记忆库中残留过时信息，进而引发推理失败。

外部记忆已成为主流范式，其核心挑战从“存储容量”转向“检索效用”与“状态演化”。早期RAG依赖固定长度分块，无法适应多跳推理对上下文完整性的需求；MemGPT等系统引入分层调度，但检索策略仍为静态相似度匹配，缺乏对任务意图的感知。Agentic Memory路线（如Mem0、A-Mem）利用LLM生成原子事实或摘要，提升了表示灵活性，但普遍存在两个缺陷：一是缺乏显式的自适应路由机制，无法在推理时根据查询类型动态选择记忆粒度；二是依赖累积式更新策略，缺乏精细的冲突消解机制，导致冗余与错误随时间 unchecked 累积。本文切入点在于将记忆生命周期解耦为四个协作角色，通过意图向量驱动的路由与逻辑审计驱动的更新，同时解决粒度错配与一致性缺失问题。

## 核心方法

### 多粒度记忆构建与编码

本文参照系为基于LLM抽象的Agentic Memory流程，其标准做法是将对话流转化为单一粒度的向量或摘要。本文的关键差异在于引入层级化存储结构，由Constructor角色将输入 $u_t$ 分解为三种粒度：Raw Text Memory $m^{raw}_t = \{u_t, R_t, \Omega_t\}$ 保留原始轨迹；Fact Knowledge Memory $m^{fact}_{t,i} = \{k_{t,i}, R_t, \Omega_t\}$ 提取原子事实；Episode Memory $m^{epi}_t = E_t$ 在触发条件（话题转移、用户请求或窗口饱和）下生成高层摘要。这一设计解决了静态分块破坏语义连贯性的问题，使系统能同时支持精确短语检索与抽象事件推理。记忆编码采用统一文本编码器 $f_{enc}$，对每种粒度的核心文本 $c_i$ 计算嵌入 $e_i = f_{enc}(c_i)$，为后续粒度特定检索提供键值基础。

### 意图驱动的路由与逻辑审计

Retriever角色作为自适应网关，首先将查询重写为自包含形式 $u'_t$，并生成四维二元意图向量 $\mathbf{B} = [b_{fine}, b_{abs}, b_{event}, b_{atomic}]$。路由函数 $O = f_M(\mathbf{B})$ 根据优先级选择检索算子：若 $b_{fine}=1$ 则访问Raw Text，若 $b_{abs} \lor b_{event}=1$ 则访问Episode，否则默认访问Fact Knowledge。该机制解决了静态检索策略无法动态适配任务需求的问题，使系统能根据查询意图选择最合适的记忆粒度。Judge角色执行双阶段验证：首先评估检索内容的相关性密度，若低于阈值则触发Retry反馈循环，促使Retriever扩展检索范围；其次执行冲突检测，识别当前输入 $u_t$ 与过滤后记忆 $H_r$ 之间的逻辑矛盾，隔离冲突集 $C_{err}$ 并触发Refresher。这一设计解决了累积式更新中缺乏显式一致性检查的问题，确保记忆库在长时程中保持逻辑有效。

## 实验评估

实验在LoCoMo与LongMemEval基准上进行，基线覆盖RAG、MemGPT、Mem0、Zep、A-Mem、Nemori等代表性Agentic Memory系统，但缺失Mandol、MAGMA等2026年最新结构化图谱方法。在LoCoMo上，AMA（GPT-4o-mini）取得0.774的LLM Score，高于最强基线Nemori（0.740）；在LongMemEval上，AMA取得0.698的平均准确率，领先Nemori（0.642）与Zep（0.630）。

| 方法 | LoCoMo LLM Score | LongMemEval Acc |
|---|---|---|
| AMA | 0.774 | 0.698 |
| Nemori | 0.740 | 0.642 |
| Zep | 0.717 | 0.630 |
| Mem0 | 0.580 | - |

消融实验显示，Refresher模块对知识更新任务至关重要：启用Refresher时，LongMemEval知识更新准确率达0.897，移除后骤降至0.568，表明显式冲突消解机制是维持长期一致性的关键。效率方面，AMA在 $K_r=2$ 设置下仅需3613个输入Token，约为FullContext（18625 Token）的19%，延迟3.91秒，低于FullContext的7.21秒，验证了多粒度路由在降低计算开销方面的有效性。

评估边界方面，论文未报告置信区间，且LongMemEval评估仅使用GPT-4o-mini，未覆盖开源模型，限制了结果的可复现性。此外，基线中缺失Mandol等最新SOTA方法，导致AMA的绝对性能定位可能偏高；多智能体协作带来的额外LLM调用开销未在效率指标中单独量化，难以判断粒度适配收益是否完全抵消了推理成本。

## 关联研究分析

从问题动机看，AMA与Mem0均关注原子事实提取，但Mem0依赖静态更新规则，缺乏对检索粒度的动态适配；AMA通过意图向量路由解决了这一局限，但其冲突检测依赖LLM提示而非端到端学习，自适应上限受限于提示工程的质量。从方法设计看，AMA与MIRIX同为多智能体记忆框架，但MIRIX缺乏一致性治理机制，AMA通过Judge/Refresher闭环弥补了这一缺陷，构成直接的方法论挑战。然而，AMA的Refresher更新策略仍为启发式规则，未探索基于强化学习的策略优化，这在复杂长时程任务中可能成为瓶颈。

## 总结

AMA针对Agentic Memory中粒度静态与更新粗糙的耦合缺陷，通过四角色解耦架构实现了多粒度存储、意图路由与逻辑审计的闭环。实验证明其在Token效率（降低80%）与知识更新准确率（89.7%）上具有显著优势，但绝对性能仍低于Mandol等最新结构化图谱基线。该框架的边界在于其一致性维护依赖LLM提示而非可学习策略，且在缺失最新SOTA基线的对比中，其相对优势可能被高估。当交互复杂度进一步增加时，启发式冲突检测的鲁棒性是否足以支撑长时程一致性，论文未给出回答。
