# ACL-Findings2026最新论文 ｜SpecBound: Adaptive Bounded Self-Speculation with Layer-wise Confidence Calibration ｜自草稿投机解码中的浅层置信度校准与有界推测

研究机构：中国科学院、中国科学院大学

作者：Zhuofan Wen、Yang Feng

论文原文见 [arXiv](https://arxiv.org/abs/2604.12247)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.12247)

> 自草稿投机解码试图利用基座模型自身的浅层输出替代独立草稿模型，以消除额外训练与部署开销，但浅层缺乏直接监督信号导致虚假高置信预测，且困难 token 迫使整个草稿序列进行冗余深层计算，限制了加速潜力。SpecBound 通过层依赖温度退火抑制浅层虚假置信，并引入深度与宽度双边界机制，在触发验证时并行补全所有草稿 token 的剩余层计算，实现了无损加速。该方法在多个长文本生成任务上取得了最高 2.33 倍的墙钟时间加速，但其加速比上限仍显著低于特征对齐路线，且对基座模型架构的依赖尚未被充分解耦。

## 研究背景

自回归解码的串行特性与硬件内存带宽限制构成了 LLM 推理效率的核心矛盾。投机解码（Speculative Decoding, SD）通过“草稿-验证”范式打破这一瓶颈，其无损性要求验证阶段必须执行完整的拒绝采样。早期 SD 依赖独立草稿模型，但引入了额外的模型选择与训练开销。自草稿策略利用基座模型自身进行推测，分为微调、层跳过和早期退出三类。其中，早期退出方法保证无损性，但现有实现加速有限。

自草稿路线的瓶颈在于浅层特征质量与计算冗余。预训练损失仅监督最终层输出，浅层缺乏直接优化信号，常对错误 token 产生虚假高置信度，误导基于固定阈值的早期退出判据。同时，解码序列存在显著的 token 难度异质性，少量困难 token 要求深层计算，而批量验证要求整个草稿序列同步处理，导致简单 token 承担冗余深层计算，困难 token 的计算在拒绝时成为浪费开销。SpecBound 针对这两个失效点，提出置信度校准与有界推测机制，在不修改基座模型参数的前提下提升草稿接受率与并行效率。

## 核心方法

### 早期退出参照系

本文问题属于自草稿投机解码中的早期退出路线。标准流程为：基座模型逐层计算，当浅层输出置信度超过固定阈值时提前退出，生成草稿 token，随后由目标模型并行验证。本文的关键差异在于，标准流程假设浅层置信度可靠且推测长度无界，而本文识别出浅层虚假置信与推测长度失控是加速受限的主因。

### 退火置信度阈值（ACT）

标准早期退出使用固定阈值 $\tau$ 比较贪心解码 token 的概率，但浅层 softmax 分布尖锐，错误 token 易通过阈值。ACT 在退出判据中引入层依赖温度 $T_\ell$，对第 $\ell$ 层 logits $\mathbf{z}^{[\ell]}$ 进行缩放：

$$ T_\ell = 1 + \alpha \frac{L - \ell}{L - 1} $$

其中 $L$ 为总层数，$\alpha > 0$ 控制退火强度。该公式在浅层（$\ell=1$）施加最高温度 $1+\alpha$，平滑分布以抑制虚假峰值，并在最终层（$\ell=L$）冷却至 $T_L=1$，确保输出分布与基座模型一致。退出条件变为 $p^{[\ell]} \geq \tau$，其中 $p^{[\ell]}$ 为温度缩放后的 top-1 概率。这一设计解决了浅层缺乏监督信号导致的错误退出，提升了草稿 token 的可靠性，且温度缩放为轻量级后处理操作，计算开销可忽略。

### 有界推测与缓存状态（BSCS）

ACT 提升了单 token 草稿质量，但无法解决困难 token 引发的序列级冗余。BSCS 引入深度边界 $d_{\max}$ 和宽度边界 $w_{\max}$，将推测从无限长 token 级过程转化为有界块级流水线。当 token 在 $d_{\max}$ 层内未退出，或连续 $w_{\max}$ 个 token 浅层退出时，推测阶段终止。此时，所有草稿 token 在 $d_{\max}$ 层的隐藏状态被缓存，并在单次并行通过中处理剩余层（$d_{\max}+1$ 至 $L$）。该机制确保每个输出 token 经历完整层计算，保证无损性，同时通过并行补全消除了困难 token 的串行延迟。隐藏状态缓存管理器支持 Write（存储退出层状态）和 Reuse（检索状态用于验证或后续 token）操作，使推测中断后的并行补全成为可能。

## 实验评估

实验在 Spec-Bench 上进行，覆盖数学、多轮对话、问答、RAG、摘要和翻译六类任务，基座模型为 Vicuna-7B/13B 和 CodeLlama-Instruct-7B/13B。基线包括 Lookahead、Medusa、REST、Kangaroo、SPACE 和 AdaDecode，均为自草稿方法，未对比 EAGLE 等特征对齐 SOTA。

| 基座模型 | 方法 | Overall CR | Overall SD |
| :--- | :--- | :--- | :--- |
| Vicuna-7B | Ours | 2.15 | 2.15× |
| Vicuna-7B | Medusa | 1.70 | 1.70× |
| Vicuna-13B | Ours | 2.16 | 2.16× |
| CodeLlama-13B-Instruct | Ours | 2.33 | 2.33× |

SpecBound 在所有基座模型上取得最高整体加速比，CodeLlama-13B-Instruct 上达到 2.33×，Vicuna-7B 上为 2.15×，显著优于 Medusa（1.70×）和 REST（1.23×）。

| 消融变体 | Vicuna-7B SD | Vicuna-13B SD |
| :--- | :--- | :--- |
| Ours | 2.33 | 2.16 |
| w/o Annealed Threshold | 1.73 | 1.82 |
| w/o Depth Bounded | 1.58 | 1.47 |
| w/o Width Bounded | 1.76 | 1.81 |

移除深度边界 $d_{\max}$ 导致最大性能下降（Vicuna-7B 从 2.33× 降至 1.58×），表明其通过限制推测深度、保留深层并行性是加速的关键。移除 ACT 导致次大下降（1.73×），验证了浅层置信度校准对草稿质量的贡献。移除宽度边界 $w_{\max}$ 影响较小（1.76×），因长草稿序列自然推动退出层加深，触发早期验证，但 $w_{\max}$ 仍是防止浅层错误累积的主要闸门。

评估边界方面，论文未报告置信区间，数值比较需谨慎。超参数 $w_{\max}=8, d_{\max}=10, \alpha=0.2, \gamma=0.55$ 在 Vicuna-7B 上优化，未验证跨模型泛化性。代码开源（ictnlp/SpecBound），训练仅需 2 小时（4×H800），但仅训练轻量 LM 头，基座参数冻结，可复现性高。

## 关联研究分析

从问题动机看，SpecBound 与 AdaDecode 同属早期退出路线，但 AdaDecode 依赖简单置信度阈值且无推测深度限制，导致困难 token 引发冗余计算。SpecBound 通过 ACT 和 BSCS 解决了这两个失效点，其加速比（2.33×）高于 AdaDecode（1.45×），根源在于 BSCS 的并行补全机制将推测从 token 级串行转化为块级并行，而 AdaDecode 缺乏此机制。从方法设计看，SpecBound 与 EAGLE 同属自草稿/特征对齐交叉地带，但 EAGLE 利用目标模型倒数第二层隐藏状态作为草稿输入，接受率高（~3.5×），而 SpecBound 仅使用浅层输出，接受率较低（CR≥3.0），但无需特征对齐训练，部署更灵活。SpecBound 的加速比上限低于 EAGLE，可能源于浅层特征信息量不足，但论文未探索浅层特征与深层特征的融合策略，这一盲区限制了自草稿路线的加速潜力。

## 总结

SpecBound 要解决的核心矛盾是自草稿投机解码中浅层虚假置信与推测长度失控导致的加速受限。其切入点在于识别出预训练损失仅监督最终层导致浅层缺乏优化信号，以及批量验证要求下困难 token 引发的序列级冗余。方法通过层依赖温度退火抑制浅层虚假置信，并引入深度与宽度双边界机制，在触发验证时并行补全所有草稿 token 的剩余层计算。实验证明其在 CodeLlama-13B-Instruct 上取得 2.33× 加速，Vicuna-7B 上 2.15×，显著优于 Medusa 和 REST。边界在于，其加速比上限显著低于特征对齐路线（如 EAGLE 的 ~3.5×），且超参数优化基于 Vicuna-7B，未验证跨模型泛化性。当基座模型层数增加时，浅层虚假置信的抑制效果是否随层数线性衰减，论文未给出回答。
