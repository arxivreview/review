# ACL-Findings2026最新论文 ｜PAPERMIND: Benchmarking Agentic Reasoning and Critique over Scientific Papers in Multimodal LLMs ｜科学文献智能体推理基准

研究机构：美国伊利诺伊大学厄巴纳-香槟分校

作者：Yanjun Zhao、Tianxin Wei、Jiaru Zou 等 10 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_3662611738a2)

> 现有科学文献理解基准将多模态感知、证据检索与批判性评估割裂为孤立任务，无法衡量模型在真实科研工作流中“决策-检索-批判”的集成推理能力。PAPERMIND 通过整合真实审稿数据与工具增强推理，构建了首个覆盖多域、多任务的智能体科学文献理解基准。该基准揭示了闭源模型在集成推理上的显著优势，但 F1 分数普遍偏低且依赖 LLM-as-a-Judge 评估，其生态效度与指标客观性仍存疑。

## 研究背景

科学文献理解要求模型不仅识别图表内容，还需在长文档中追踪逻辑依赖并整合分散证据。这一过程涉及多模态对齐与跨源推理，传统静态问答基准仅评估单点技能，忽略了模型作为智能体主动决定“生成、检索或评估”的决策行为。当模型面对复杂实验结果时，缺乏上下文接地的视觉描述往往导致领域术语误用，而孤立的事实检索无法支撑对科学主张的批判性分析。

当前主流路线分为两类：一类聚焦单文档深度阅读（如 SciDQA），另一类侧重工具调用技能（如 PaperArena），但均未能统一评估从视觉接地到批判性评估的全流程。这种割裂导致模型在静态基准上的高分无法迁移至动态科研场景，暴露了评估体系与真实工作流之间的鸿沟。PAPERMIND 的切入点在于将真实审稿讨论与工具增强推理整合为统一框架，通过四个互补任务族模拟科学家处理文献时的认知闭环，填补了集成科学推理评估的空白。

## 核心方法

### 任务架构与数据构建

PAPERMIND 基于 3,000 篇来自 ArXiv、bioRxiv 等开放来源的论文，覆盖农业、生物、化学、计算机、医学、物理、经济七个领域。数据筛选剔除了少于 5 页或超过 20 页的 PDF，并利用 paper2pdf 工具提取结构化文本、图表与表格。批判性评估任务专门从 OpenReview 收集真实审稿线程，经 Gemini 2.5 Pro 清洗后保留 294 个具有实质性科学争议的问答对，确保评估对象为实验局限、假设模糊等核心问题而非表面反馈。

### 多模态接地与实验解释

多模态接地任务要求模型结合论文引言上下文生成图表描述，其核心在于视觉证据与领域术语的对齐。该任务的设计动机是解决孤立视觉感知导致的语义漂移，通过引入背景知识约束生成空间。实验解释任务则要求模型基于图表数据生成分析段落，其评估指标定义为生成文本与原文讨论段落的 F1 分数及 LLM-as-a-Judge 评分。这一设计将“描述”转化为“解释”，强制模型整合多模态信息与科学语境，而非仅复述视觉元素。

### 跨源证据推理与批判性评估

跨源证据推理任务模拟智能体行为，模型仅接收源论文 PDF，需自主调用工具（如 arxiv_retriever、web_search）检索引用文献或外部知识，合成多源证据回答研究导向问题。该任务采用 ReAct 范式，评估指标包含 F1 分数、LLM-Judge 评分、平均交互步数及工具调用次数。批判性评估任务基于真实审稿数据，要求模型识别主张中的弱点、缺失证据或模糊假设。其核心创新在于将“批判”操作化为对真实作者回复的匹配，通过 LLM-Judge 评估回复的实质性，解决了现有基准缺乏对科学主张批判性推理评估的问题。

## 实验评估

实验覆盖 4 个闭源模型（Gemini 2.5 Pro, GPT-4o-mini, Claude 3.5 Sonnet, Claude 3 Haiku）与 3 个开源模型（Qwen3-VL-4B-Instruct, Gemma-3-4b-it, Phi-3.5-vision-instruct）。基线选择涵盖了主流多模态 LLM，但缺乏专用科学模型（如 SciBERT）或长上下文优化模型（如 CURIE）的对比，限制了方法贡献与骨干能力的区分。

| 任务 | 模型 | F1 | LLM-J | 步数 | 工具 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| MG | Gemini 2.5 Pro | 0.224 | 2.39 | - | - |
| MG | Qwen3-VL-4B | 0.181 | 2.11 | - | - |
| EI | Gemini 2.5 Pro | 0.230 | 2.25 | - | - |
| EI | Qwen3-VL-4B | 0.210 | 1.90 | - | - |
| ER | Gemini 2.5 Pro | 0.349 | 2.99 | - | - |
| ER | Qwen3-VL-4B | 0.337 | 2.45 | - | - |
| CA | Gemini 2.5 Pro | 0.198 | 2.64 | 4.58 | 5.37 |
| CA | Qwen3-VL-4B | 0.209 | 2.42 | 2.27 | 2.70 |

Gemini 2.5 Pro 在多模态接地任务中 F1 分数达 0.224，比 Claude 3.5 Sonnet 高 20.4%，但在跨源证据推理中，开源模型 Qwen3-VL-4B 的 F1 分数（0.337）与 Gemini（0.349）差距缩小至 3.4%，表明开源模型在工具增强推理上具有较强竞争力。

消融实验显示，引入论文引言作为背景信息使 Gemini 的 F1 分数提升约 13.7%，Qwen 提升约 14.5%，但 Gemini 的 LLM-Judge 评分仅边际变化，而 Qwen 提升约 8.8%。这表明 Gemini 具备更强的内在泛化能力，无需显式背景即可生成高质量描述。工具调用深度分析发现，将最大工具调用次数从 4 增至 6 带来最大性能增益，增至 8 时收益边际化，增至 10 时性能轻微下降，归因于上下文长度增加导致证据稀释。

评估协议依赖 LLM-as-a-Judge 进行 5 分制评分，但未报告与人工评分的相关性验证，存在主观性风险。F1 分数普遍低于 0.4，可能源于 Ground Truth 的严格性或任务定义的模糊性。代码已开源，但缺乏超参数细节与 GPU 配置说明，可复现性受限。

## 关联研究分析

与 PaperArena 相比，PAPERMIND 的核心差异在于任务整合度与数据真实性。PaperArena 侧重单域工具调用技能，而 PAPERMIND 通过多域覆盖与真实审稿数据，将评估从“技能执行”提升至“认知闭环”。这一差异源于任务特性：科学文献理解要求跨源证据合成与批判性判断，而非单一检索动作。PAPERMIND 的批判性评估任务直接基于 OpenReview 真实数据，避免了合成数据的分布偏差，但这也导致该任务局限于计算机领域，跨域泛化性存疑。

与 SPIQA 相比，PAPERMIND 在方法设计上引入了智能体行为建模。SPIQA 评估多模态问答的静态能力，而 PAPERMIND 通过 ReAct 范式强制模型主动决策工具调用，评估指标包含交互步数与工具频率。这一设计解决了静态基准无法捕捉模型“决策-检索”动态过程的问题，但也引入了评估复杂度：工具调用策略的差异可能导致性能波动，使得 F1 分数难以直接归因于模型推理能力。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

PAPERMIND 旨在解决科学文献理解评估中“孤立技能”与“集成推理”的矛盾，通过整合真实审稿数据与工具增强推理，构建了首个覆盖多域、多任务的智能体基准。该基准证明了闭源模型在集成推理上的优势（Gemini 2.5 Pro 在 MG 任务 F1 0.224），同时揭示了开源模型在工具增强推理上的潜力（Qwen3-VL-4B 在 ER 任务 F1 0.337）。其边界在于批判性评估任务局限于计算机领域，且依赖 LLM-as-a-Judge 评估缺乏人工校验。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
