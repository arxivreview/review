# ACL-Findings2026最新论文 ｜LifeSim: Long-Horizon User Life Simulator for Personalized Assistant Evaluation ｜长程用户生活模拟器与个性化助手评估基准

作者：Feiyu Duan、Xuanjing Huang、Zhongyu Wei

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_9b036b43f343)

> 导读 个性化助手面临的核心挑战在于如何在动态物理环境与用户长期认知状态约束下，维持交互的连贯性与个性化。现有基准多依赖静态或短上下文数据，无法反映真实世界中用户意图随时间、地点及情绪演变的复杂性，导致模型在隐式意图推断与长期偏好保持上表现不佳。LifeSim 通过信念-欲望-意图（Belief-Desire-Intention, BDI）认知引擎与事件引擎生成符合物理规律的生活轨迹，并构建包含 1,200 个场景的 LifeSim-Eval 基准，以量化模型在长程交互中的表现。该框架揭示了当前大语言模型（Large Language Models, LLMs）在显式意图处理上的优势与在隐式意图及长程记忆上的显著短板，但其评估主要依赖 LLM-as-Judge，缺乏对因果机制有效性的直接验证。

## 研究背景

当助手需要为用户提供跨天、跨地点的持续服务时，其响应不仅需符合当前时刻的环境条件（如天气、位置），还需整合用户过去交互中积累的偏好与情绪状态。这种复杂性源于用户行为的动态性：意图并非孤立产生，而是由稳定的个人特质（Personality）与瞬时的环境刺激（Environment）共同驱动。社会心理学中的勒温方程 $B = f(P, Env)$ 指出，行为是个体与环境交互的函数，这为模拟真实用户行为提供了理论依据。然而，将这一理论转化为可计算的模拟框架，需要解决如何从静态属性列表过渡到动态认知状态建模的问题。

现有个性化助手评估基准存在结构性缺陷。UserSimCRS 等早期工作仅支持单轮或短对话，无法捕捉长程依赖；ProPerSim 虽涉及长期记忆，但缺乏对环境动态性的建模。这些基准迫使模型在静态快照中表现，掩盖了其在持续交互中遗忘偏好或逻辑断裂的真实缺陷。LifeSim 的切入点在于将用户模拟从“文本生成”提升至“认知过程模拟”，通过显式建模信念、欲望与意图的转换，使模拟行为具备心理合理性，从而为评估助手的长程个性化能力提供高保真的测试床。

## 核心方法

### 方法参照系

传统用户模拟多采用端到端微调或静态属性提示，缺乏对内部推理过程的显式建模。LifeSim 将模拟过程解耦为认知引擎、事件引擎与行为引擎三个模块，关键差异在于引入 BDI 架构作为中间层，将环境输入转化为意图输出，而非直接映射为文本响应。

### BDI 认知引擎与意图生成

认知引擎负责将用户画像与环境信息转化为具体意图。设计动机在于解决静态属性提示导致的“平均人”效应，即不同用户输出趋同。系统首先基于用户长期信念（画像）与环境生成事件假设 $H$，作为短期信念。随后，从欲望池（Desire Pool）中检索候选意图，并基于信念与环境进行重排序。意图 $I_i$ 的选择概率由软最小函数（Softmin）计算：

$$ P(I_i) = \frac{\exp(-r_i)}{\sum_{k} \exp(-r_k)} $$

其中 $r_i$ 为候选意图的排名。该公式确保高排名意图被优先采样，同时保留低排名意图的随机性，模拟人类决策的非确定性。

### 环境驱动的事件引擎

事件引擎确保生成的生活轨迹符合物理规律。设计动机在于解决现有模拟中事件与用户状态脱节的问题。环境表示为 $Env(T, L, W)$，包含时间、地点与天气。事件触发概率 $P_E$ 定义为距上次事件时间间隔 $\Delta T$ 的 logistic 函数：

$$ P_E = f(\Delta T) = \frac{1}{1+e^{-\Delta T}} $$

通过伯努利采样决定当前时间点是否生成事件。若触发，引擎将意图细化为具体的生活事件，确保其与用户轨迹（基于 Foursquare 数据集的 3,374 条真实移动轨迹）在时空上对齐。

## 实验评估

实验在 LifeSim-Eval 上进行，该基准包含 1,200 个场景，覆盖 8 个生活领域。基线覆盖 GPT-5、Claude-Sonnet-4.5 等闭源模型及 Qwen3、Llama3.1 等开源模型。主实验结果显示，模型在显式意图识别上表现优异，但在隐式意图上存在显著差距。

| 模型 | 显式意图识别 | 隐式意图识别 | 显式意图完成 | 隐式意图完成 |
| :--- | :--- | :--- | :--- | :--- |
| GPT-5 | 79.5 | 52.2 | 76.9 | 48.9 |
| DeepSeek-V3.2 Thinking | 80.6 | 59.3 | 75.8 | 58.2 |
| Qwen3 32B | 76.6 | 51.2 | 70.3 | 47.4 |
| Llama3.1-it 8B | 70.3 | 40.3 | 58.4 | 33.8 |

GPT-5 在显式意图识别上得分 79.5，但隐式意图仅 52.2，差距超过 20 分。DeepSeek-V3.2 Thinking 在隐式意图完成上表现最佳（58.2），表明推理模型在捕捉潜在需求上更具优势。开源模型中，Qwen3 32B 表现优于 Llama3.1-it 8B，但整体仍落后于闭源模型。

消融实验验证了记忆感知与情绪推理模块的重要性。移除记忆感知模块后，Qwen3 32B 的画像一致性（Persona Consistency）从 96.0 降至 86.0；移除情绪推理模块后，上下文相关性（Context Relevance）从 93.6 降至 90.3。这表明，简单的文本记忆不足以维持长程一致性，需结合情绪状态推理才能有效捕捉用户动态变化。

评估边界方面，LifeSim-Eval 依赖 LLM-as-Judge（GPT-4o, Qwen3-32B, Llama3.1-70B）进行自动评分，其与人类标注者的 Krippendorff’s $\alpha$ 平均为 0.80，表明评估可靠性较高。然而，该协议未量化 BDI 模型中“信念-欲望-意图”转换的因果有效性，仅验证了输出结果的表面一致性。代码与数据已公开，实验在 8 张 NVIDIA RTX 4090 GPU 上完成，采样温度固定为 1.0。

## 关联研究分析

从问题动机看，LifeSim 与 Generative Agents 均关注个体行为仿真，但前者聚焦于“个性化助手”垂直场景，后者侧重通用社会模拟。Generative Agents 通过记忆-反思机制实现行为连贯性，但缺乏对物理环境（时间、地点、天气）的硬约束。LifeSim 引入环境驱动的事件引擎，使意图生成与真实生活轨迹对齐，解决了通用模拟中事件与用户状态脱节的问题。这一差异源于任务特性：助手交互需严格遵循时空逻辑，而通用模拟更关注社会动力学。

从方法设计看，LifeSim 与 HumanLM 均追求个体状态对齐，但 HumanLM 采用强化学习优化潜在心理状态，LifeSim 采用 BDI 架构进行显式推理。HumanLM 依赖 LLM 判断器进行奖励信号生成，训练成本高且易过拟合表面特征；LifeSim 通过模块化设计解耦认知与行为，降低了训练依赖，但牺牲了端到端优化的灵活性。BDI 架构是否比端到端微调更利于长程一致性，论文未提供直接对比实验，仅通过消融验证了模块必要性。

## 总结

LifeSim 旨在解决个性化助手在长程交互中隐式意图推断与偏好保持的难题。现有方法因缺乏动态认知建模与环境约束，导致模拟行为与真实用户脱节。LifeSim 通过 BDI 认知引擎与环境驱动的事件引擎，构建了高保真的用户生活模拟器，并基于此提出 LifeSim-Eval 基准。实验表明，当前 LLM 在显式意图处理上表现良好，但在隐式意图完成上得分普遍低于 60，且长程记忆机制对偏好恢复的增益有限。该框架的边界在于其评估依赖 LLM-as-Judge，未能验证认知过程本身的因果有效性。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
