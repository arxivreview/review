# ACL-Findings2026最新论文 ｜EULoInf: Efficient Hessian-Free Entropy Based Uncertainty-Aware Data Influence Approximation ｜基于预测熵与单层梯度的无Hessian数据影响近似

研究机构：新加坡国立大学

作者：Runxin Cai、Jingtan Wang、Bryan Kian Hsiang Low

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_457afefd083e)

> 大语言模型微调中的数据估值面临逆Hessian-向量积（iHVP）计算带来的二次复杂度瓶颈，导致现有影响函数近似方法在大规模模型上内存与时间开销不可接受。EULoInf 抓住高影响数据与高预测熵之间的统计相关性，利用前向传播获取的Rényi熵替代昂贵的梯度范数计算，并引入仅针对最后一层的梯度点积符号以区分有益与有害样本。该方法将计算复杂度从二次降至线性，在GSM8K等任务上以41.13%的计算时间超越了最佳基线2.93%的精度，但其单层梯度近似在深层网络中的方向判别保真度仍存疑。

## 研究背景

当模型在微调过程中遭遇标签噪声或分布偏移时，识别对验证集性能有正向贡献的训练样本成为提升数据效率的关键。影响函数（Influence Function, IF）通过模拟训练样本权重微小变化对验证损失的反事实影响，提供了理论上的最优估值标准。然而，IF 的精确计算依赖于逆Hessian矩阵，其维度随模型参数量平方增长，在数十亿参数的LLM中完全不可行。

现有高效近似路线主要分为两类：一类如DataInf和RRInf，通过低秩近似或岭回归加速iHVP计算，但时间复杂度仍为 $O(p^2L)$ 或内存随训练数据量线性增长；另一类如LiSSA，采用迭代方法近似iHVP，虽降低单次计算成本，但总迭代次数高。这些方法均未能摆脱对二阶导数信息的依赖，导致在LLM规模下计算资源开销依然巨大。EULoInf 的切入点在于发现高影响样本在训练后期倾向于聚集在决策边界附近，表现出高预测不确定性，从而尝试用一阶前向传播可得的熵指标替代二阶Hessian计算。

## 核心方法

### 影响函数的近端线性化参照系

标准影响函数近似通常基于强凸假设下的二阶泰勒展开，需计算 $H^{-1}g$。本文采用近端响应函数（Proximal Response Function）作为参照系，将扰动后的优化问题视为在原始最优解 $\hat{\theta}$ 附近的局部最小化，通过引入阻尼项 $\lambda/2 \|\theta - \hat{\theta}\|^2$ 确保Hessian正定，为后续一阶近似提供理论基础。

### 基于Rényi熵的绝对影响代理

传统方法通过计算全参数梯度范数 $\|\nabla_\theta \ell(\hat{\theta}, k)\|_2$ 来估计绝对影响，但这需要完整的反向传播。本文推导表明，在交叉熵损失下，梯度范数与预测分布 $p(x)$ 和真实标签 $y$ 的欧氏距离平方成正比。进一步假设模型预测分布接近真实条件分布，该距离的期望值可表示为 $1 - e^{-H_2(p(x))}$，其中 $H_2$ 为二阶Rényi熵。

$$
I_{abs}(k) \propto H_2(p(x_k))
$$

这一公式的物理含义是：模型对某样本预测越不确定（熵越高），该样本对模型参数的潜在影响越大。设计动机在于利用前向传播即可获取的logits计算熵，彻底规避了全模型梯度计算带来的内存瓶颈。

### 单层梯度点积的方向判别

高熵样本既包含有益数据也包含噪声数据，仅靠熵无法区分方向。本文引入方向指示器，利用验证集与训练集在最后一层参数的梯度点积符号来判断影响方向。

$$
I(z_{val}, z_k) = H_2(p(x_k)) \cdot \text{sign}(\nabla_\theta \ell(\hat{\theta}, val)^T \nabla_\theta \ell(\hat{\theta}, k))
$$

该公式通过仅计算最后一层梯度（而非全模型），以极低的计算成本获取影响的方向性。设计动机在于解决纯熵方法无法区分“高影响有益”与“高影响有害”样本的二义性问题，同时保持计算效率。

## 实验评估

实验在Llama-3-8B和Mistral-7B上，针对GSM8K、TLDR和RLHF任务进行数据选择与错误标签检测。基线包括LiSSA、DataInf、RRInf和RepSim，覆盖了迭代近似、低秩近似和相似度匹配等主要路线，但缺乏与Shapley值近似方法的直接对比。

| 方法 | Mistral-7B 时间(s) | Llama-3-8B 时间(s) | Mistral-7B 内存(GB) | Llama-3-8B 内存(GB) |
| :--- | :--- | :--- | :--- | :--- |
| LiSSA | 19.13 | 25.13 | - | - |
| DataInf | 32.61 | 42.59 | - | - |
| RRInf | 37.10 | 38.58 | - | - |
| EULoInf | 15.18 | 18.85 | - | - |

EULoInf 在计算时间上显著低于所有基线，例如在Llama-3-8B上仅为RRInf的41.13%。在数据选择任务中，EULoInf 在GSM8K上超越最佳基线2.93%，且在Top 50%数据选择下，其测试性能（49.13% ± 0.66）优于无符号熵（43.11% ± 0.60）和全梯度范数（46.20% ± 1.06）。

消融实验显示，移除方向指示器导致性能显著下降，验证了符号分量的必要性。然而，EULoInf 与全梯度范数（GradNorm）在精度上接近，但内存占用更低。Token选择阈值的消融表明，50%阈值在TLDR任务上表现最稳定，30%和70%阈值均导致性能波动，暗示熵筛选存在最优平衡点。

评估边界方面，论文未报告置信区间的完整分布，且仅在两个开源LLM上验证。代码已开源，但超参数（如阻尼项 $\lambda$）的敏感性分析未在正文中详细展开。

## 关联研究分析

从方法设计看，EULoInf 与For-Value 同属前向传播估值路线，但For-Value 完全依赖输出分布相似度，缺乏方向判别能力，而EULoInf 通过引入单层梯度点积解决了高熵数据的二义性问题。这一差异源于EULoInf 保留了影响函数的理论框架，而For-Value 更侧重于工程效率。然而，EULoInf 仅使用最后一层梯度，是否足以捕捉深层网络中的全局方向性，论文未提供深层消融证据。

从问题动机看，EULoInf 与DataInf 均针对LLM微调场景，但DataInf 依赖Hessian低秩近似，计算复杂度仍为二次，而EULoInf 通过熵代理将复杂度降至线性。这一改进源于对“高影响-高熵”统计规律的利用，但DataInf 在复杂多模态交互场景下的保真度可能更高，因为Hessian能捕捉参数间的二阶交互，而熵仅反映一阶不确定性。

## 总结

EULoInf 解决了LLM微调中影响函数计算的高昂成本矛盾，通过预测熵替代梯度范数、单层梯度替代全模型梯度，实现了线性复杂度。实验证明其在GSM8K上以41.13%的时间超越基线2.93%精度，验证了熵代理的有效性。其边界在于单层梯度近似可能丢失深层方向信息，且缺乏与Shapley类方法的公平对比。当模型深度增加或任务涉及复杂多模态交互时，单层梯度点积的方向判别保真度是否仍能维持，论文未给出回答。
