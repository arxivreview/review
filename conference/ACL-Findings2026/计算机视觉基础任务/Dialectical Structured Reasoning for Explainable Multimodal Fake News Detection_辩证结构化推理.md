# ACL-Findings2026最新论文 ｜Dialectical Structured Reasoning for Explainable Multimodal Fake News Detection ｜辩证结构化推理

研究机构：北京科技大学、新加坡管理大学

作者：Ruichao Yang、Yufan Bian、Wei Gao 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_1ff708b91687)

> 多模态虚假信息检测面临的核心矛盾是：现有模型将复杂的社交证据压缩为单一向量，导致决策过程缺乏逻辑透明度，且难以处理碎片化、极化的用户反馈。现有方法要么依赖非可微的提示驱动辩论，要么仅做事后解释，无法在训练阶段优化推理路径。DSR 将检测重构为在异构传播图上的辩证裁决过程，通过可微分的 Judge 模块整合支持性与反驳性证据路径。该方法在精度与解释质量上均超越基线，但其对冻结 MLLM 背景知识的依赖在长尾事实场景下的可靠性尚存疑。

## 研究背景

当检测器面对“空货架反映政策影响”这类多模态声明时，用户反馈往往分裂为相互对立的叙事：部分用户强化虚假叙事，另一部分则指出图像时间戳错误。这种碎片化与极化导致支持性与反驳性证据分散在松散的社交线程中，传统特征融合方法难以捕捉这种结构化的对立。为应对此挑战，领域引入了基于大语言模型（LLM）的辩论机制，但现有方案如 TED 和 D2D 主要停留在语义层面的孤立帖子对比，且依赖非可微的提示过程，阻碍了端到端优化。

多模态虚假信息检测的主流路线正从静态特征匹配转向基于外部证据接地的认知推理。然而，现有智能体框架存在两个瓶颈：一是证据挖掘缺乏全局结构感知，无法在碎片化社交图中定位关键矛盾点；二是解释生成与决策过程脱节，事后解释往往无法反映模型内部的真实推理逻辑。DSR 的切入点在于将辩证推理嵌入图拓扑遍历过程，通过显式挖掘支持性（Thesis）与反驳性（Antithesis）证据路径，并利用可微分机制进行裁决，从而在提升检测精度的同时实现过程透明的可解释性。

## 核心方法

### 方法参照系

本文问题归属于“LLM 智能体 + 传播结构”混合路线。标准流程通常利用 LLM 进行语义辩论或图神经网络（GNN）进行结构建模，但二者往往割裂：LLM 缺乏图结构约束，GNN 缺乏语义推理能力。DSR 的关键差异在于引入“假设驱动的拓扑遍历”，将 LLM 作为语义导航器在图上进行束搜索，而非简单的节点分类。

### 假设驱动拓扑遍历

传统图方法依赖隐式结构学习，难以在极化社交网络中定位具体的矛盾证据。DSR 引入 MLLM 引导的束搜索算法（Algorithm 1），以假设 $H \in \{H_{real}, H_{fake}\}$ 为条件，在异构传播图 $G_x$ 上挖掘证据路径。节点 $v$ 的嵌入由模态特定编码器生成，并结合类型、边及位置嵌入：

$$ z_l = m_{v_l} + e_{type}(\tau(v_l)) + e_{edge}(v_{l-1}, v_l) + e_{pos}(l) $$

该公式将多模态内容、社交关系及传播时序统一编码为异构 token。MLLM 根据当前假设与路径历史，从候选邻居中选择语义一致的节点，确保提取的路径 $P$ 形成逻辑连贯的叙事。这一设计解决了纯语义模型无法利用社交结构定位“谁在反驳什么”的问题，使证据挖掘从全局模糊匹配转向局部精确路径提取。

### 可微分辩证裁决

现有辩论方法多为非可微的提示链，无法通过梯度优化。DSR 引入可微分 Judge 模块，通过背景知识注入（BKI）与冲突感知融合解决局部证据偏差。Verifier 与 Debunker 分别聚合支持性与反驳性路径表示 $e_{ver}$ 和 $e_{deb}$，冲突门控机制计算证据张力：

$$ g_{conf} = \sigma(W_c(e_{ver} \odot e_{deb}) + b_c) $$

随后，Judge 利用 LoRA 微调的 Qwen2.5 整合 $e_{ver}, e_{deb}, g_{conf}$ 及背景知识 $h_{bki}$ 进行裁决。$g_{conf}$ 显式量化了支持性与反驳性证据的冲突程度，指导 Judge 动态权衡局部社交信号与全局参数化知识。这一机制使得模型在训练阶段即可优化“如何裁决矛盾”，而非仅优化分类结果，从而实现了推理过程与决策结果的端到端对齐。

## 实验评估

实验在 PolitiFact、GossipCop 和 Fakeddit 三个基准上进行，基线覆盖 MLLM 零样本、单模态、多模态及社交增强方法。值得注意的是，基线中未包含最新的 Web 检索型智能体框架（如 MIRAGE），这可能影响对 DSR 相对优势的全面评估。在检测精度上，DSR 在 PolitiFact、GossipCop 和 Fakeddit 上分别超越最强基线 RPPG-Fake 2%、2.2% 和 5%。

| 数据集 | 方法 | Acc (%) | F1 (%) |
| :--- | :--- | :--- | :--- |
| PolitiFact | DSR | 86.2 | - |
| GossipCop | DSR | 89.63 | - |
| Fakeddit | DSR | - | - |

*注：PolitiFact Acc 86.2% 系根据“超越 RPPG-Fake 2%”及领域综述中 RPPG-Fake 基线推算，原文未直接列出该具体数值，此处仅作为相对优势说明，严格数值以原文 Table 1 为准。GossipCop 89.63% 为原文提及数值。*

在解释质量评估中，使用 GPT-5 作为裁判，DSR 在信息量（I）和逻辑性（S）上分别比 L-Defense 高 0.35 和 0.33 分，误导性（M）降低 0.35 分。这表明辩证路径生成的解释比通用启发式解释更紧密地贴合真实标签。消融实验显示，移除 BKI 模块后，模型在 PolitiFact 上对“视觉蕴含陷阱”（如旧图新用）的识别能力显著下降，验证了全局背景知识在纠正局部社交噪声中的关键作用。

评估边界方面，论文未报告推理延迟与计算成本，而 MLLM 引导的束搜索与多次 LLM 调用必然带来高昂开销。此外，BKI 依赖冻结 MLLM 的内部知识，而非实时检索，这在突发新闻或长尾事实场景下可能引入知识滞后或幻觉。代码已开源，但复现需依赖 GPT-5 和 Gemini-3 等专有 API，限制了在离线环境下的可复现性。

## 关联研究分析

从问题动机看，DSR 与 ZoFia 均致力于解决 LLM 幻觉，但路径截然不同。ZoFia 通过多 LLM 交互解耦检索与推理，依赖外部 Web 证据库来抑制确认偏误；而 DSR 将证据挖掘内化于图拓扑遍历，依赖 MLLM 的参数化知识（BKI）而非实时检索。这一差异源于任务特性：DSR 强调社交传播结构中的逻辑矛盾，认为早期社交信号往往先于事实核查报告出现，因此选择自包含的 BKI 以捕捉实时动态。然而，当社交信号本身被恶意操纵（如知识库中提到的对抗鲁棒性问题）时，BKI 的内部知识是否足以抵御系统性误导，论文未给出回答。

从方法设计看，DSR 与 TED 同属辩论式框架，但 TED 仅在语义层模拟正反方观点，且过程非可微。DSR 的创新在于将辩论实体化为图上的路径遍历，并通过可微分 Judge 实现端到端优化。这一设计使得 DSR 能够利用图结构信息（如用户中心性、传播时序）来约束辩论范围，避免了 TED 中可能出现的无关帖子干扰。然而，DSR 的 Verifier 主要关注语义一致性，缺乏对像素级篡改的检测能力，这使得其在面对高保真神经伪造（如 Deepfake）时，可能仅能识别叙事矛盾而无法识别视觉伪造，这是其相对于纯视觉检测方法的明显盲区。

## 总结

DSR 试图解决多模态虚假信息检测中“黑盒决策”与“碎片化证据”的矛盾，其核心在于将辩证推理嵌入可微分的图结构遍历过程。通过 MLLM 引导的路径挖掘与冲突感知裁决，DSR 在三个基准上实现了 SOTA 精度，并显著提升了解释的逻辑性与忠实度。然而，其依赖冻结 MLLM 进行背景知识注入的设计，在证据稀缺或事实快速演变的场景下，可能无法像实时 Web 检索那样提供最新的事实锚点。当社交传播结构被精心设计的虚假共识所主导时，仅依赖内部参数化知识的 Judge 是否仍能做出正确裁决，这一边界条件在现有实验中尚未被充分验证。
