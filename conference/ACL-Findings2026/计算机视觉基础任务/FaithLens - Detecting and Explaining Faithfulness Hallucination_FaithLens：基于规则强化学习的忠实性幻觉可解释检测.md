# ACL-Findings2026最新论文 ｜FaithLens: Detecting and Explaining Faithfulness Hallucination ｜FaithLens：基于规则强化学习的忠实性幻觉可解释检测

> 导读 忠实性幻觉指模型生成内容与给定上下文文档不一致，是检索增强生成（RAG）等应用的核心风险。现有检测方案要么依赖高成本大模型进行黑盒判断，要么训练专用小模型但仅输出二分类标签，缺乏可解释性且跨任务泛化能力不足。本文提出 FaithLens，通过合成数据过滤、监督微调（SFT）冷启动及基于规则强化学习（RL）的两阶段训练，使 8B 参数模型在检测精度的同时生成高可信度解释。该方法在 12 个任务上超越了 GPT-5.2 等前沿大模型，但其解释质量评估依赖特定新手模型，且未与白盒内部表征探测方法直接对比，其通用性边界尚存疑问。

## 研究背景

当模型在 RAG 场景中生成看似流畅但与检索文档冲突的陈述时，用户难以定位错误根源。这种忠实性幻觉不同于基于参数知识的事实性幻觉，其判定依赖于文档-声明对的语义一致性。传统检测将其简化为二分类任务，但黑盒输出无法提供错误归因，导致用户信任度降低。同时，不同任务（如摘要与问答）的幻觉模式存在显著差异，摘要幻觉多为细微内容扭曲，而 RAG 幻觉常表现为对上下文的完全忽略，这要求检测模型具备跨任务的鲁棒泛化能力。

现有主流路线分为两类：一类利用 GPT-4o 等大模型的通用能力进行提示工程检测，如 SelfCheckGPT，但推理成本高昂且难以实时部署；另一类训练专用小模型，如 MiniCheck 和 ClearCheck，虽降低了成本，但前者仅输出标签缺乏解释，后者虽引入思维链（CoT）但解释质量未显式优化。此外，合成训练数据缺乏严格的质量控制，导致模型在复杂场景下性能不稳定。FaithLens 的切入点在于将检测任务重构为“预测+解释”的联合优化问题，通过显式的解释质量奖励机制，解决小模型在低成本约束下兼顾检测精度与可信度的难题。

## 核心方法

### 方法参照系

本文问题属于黑盒/小模型可解释检测范畴，与白盒内部表征探测（如 SAPLMA）形成互补。标准流程为：数据合成 -> SFT 训练 -> 推理。关键差异在于，本文在 SFT 后引入基于规则 RL 阶段，并针对合成数据设计了多维过滤机制，以突破 SFT 仅模仿训练数据导致的解释质量瓶颈。

### 数据合成与多维过滤

针对合成数据噪声大、分布偏斜的问题，FaithLens 设计了包含标签正确性、解释质量与数据多样性的过滤管道。解释质量过滤的核心在于验证解释是否提升了新手模型对正确标签的预测置信度。具体而言，计算新手模型 $M_{nov}$ 在仅输入文档 $doc$、声明 $c$ 及思维链 $cot$ 时，对正确标签 $y_{gt}$ 的困惑度 $PPL_1$，以及加入合成解释 $e$ 后的困惑度 $PPL_2$：

$$
\mathcal{I}(e) = \mathbb{I}[PPL_2(doc, c, cot, e, y_{gt}) < PPL_1(doc, c, cot, y_{gt})]
$$

该公式的物理含义是：若解释 $e$ 能使新手模型更确信正确标签，则说明该解释包含了足以引导正确判断的关键证据，从而被保留。这一设计解决了以往合成数据中解释与标签逻辑脱节的问题，确保冷启动 SFT 阶段输入的数据具备内在一致性。

### 基于规则强化学习的联合优化

SFT 模型易过拟合简单样本且解释缺乏信息量，FaithLens 采用 GRPO 算法进行规则 RL 优化。奖励函数由预测正确性奖励 $R_{pred}$、解释质量奖励 $R_{exp}$ 和格式奖励 $R_{fmt}$ 组成。其中，解释质量奖励 $R_{exp}$ 直接复用数据过滤中的逻辑，即检查新手模型在给定解释 $e$ 后能否正确预测标签：

$$
R_{exp} = \mathbb{I}[y_{pred}^{M_{nov}}(doc, c, e) == y_{gt}]
$$

最终奖励 $R_{final} = R_{pred} + R_{exp} + R_{fmt}$ 通过 GRPO 的组内相对优势计算引导策略更新。这一设计动机在于，SFT 仅模仿分布，而 RL 通过显式奖励信号，迫使模型在生成解释时不仅追求流畅性，更追求对新手模型具有“教学”效应的信息密度，从而在检测精度与解释可信度之间实现帕累托最优。

## 实验评估

FaithLens 在 LLM-AggreFact 和 HoVer 基准的 12 个任务上进行了评估，指标为 Macro-F1。基线覆盖了 GPT-5.2、o3 等前沿大模型及 MiniCheck、ClearCheck 等专用检测模型。实验显示，FaithLens 在整体性能上达到 SOTA，尤其在复杂推理任务 HoVer 上表现突出。

| 模型 | Overall Avg | Std |
| :--- | :--- | :--- |
| GPT-5.2 | 82.9 | 5.9 |
| o3 | 81.1 | 6.0 |
| MiniCheck | 74.9 | 7.5 |
| ClearCheck | 80.3 | 6.6 |
| **FaithLens** | **86.4** | **4.6** |

FaithLens 以 86.4% 的平均 F1 值超越 GPT-5.2 的 82.9%，且标准差最低，表明其跨任务泛化能力更强。在解释质量评估中，FaithLens 在可读性、有用性和信息量三个维度上均优于 GPT-4o 等模型。

消融实验揭示了各组件的贡献。移除数据过滤阶段导致整体性能从 86.4 降至 83.4，其中移除解释质量过滤影响最大（降至 83.4），表明高质量解释对检测精度的正向迁移作用。移除 RL 阶段后，性能降至 85.8，解释质量降至 83.8，证实 RL 在提升解释信息量方面的关键作用。

| 消融变体 | Overall Avg | Explainability Avg |
| :--- | :--- | :--- |
| FaithLens (Full) | 86.4 | 90.4 |
| w/o. Data Filtering | 83.4 | 82.3 |
| w/o. Rule-based RL | 85.8 | 83.8 |
| w/o. Explanation Quality Reward | 85.0 | 84.7 |

评估边界方面，本文使用 GPT-4.1 作为解释质量评估器，可能存在评估者偏差；实验未报告计算效率的具体 GPU 小时数，仅提及成本优势；代码已开源，但超参数细节需查阅附录。

## 关联研究分析

从问题动机看，FaithLens 与白盒内部表征探测方法（如 SAPLMA、HARP）形成鲜明对比。SAPLMA 依赖模型隐藏状态训练线性探针，精度高但需白盒访问权限，无法应用于闭源 API；FaithLens 则通过黑盒输入输出实现检测，牺牲了内部机制的可解释性，换取了部署的通用性。这种差异源于任务场景的不同：FaithLens 面向需要用户理解错误原因的应用场景，而 SAPLMA 面向系统内部的实时监控。FaithLens 未与白盒方法在统一基准上对比，其检测精度是否优于白盒探针尚不明确。

从方法设计看，FaithLens 与 MiniCheck 同属合成数据训练范式，但关键差异在于解释质量的显式优化。MiniCheck 仅关注二分类标签，而 FaithLens 通过“新手模型预测”这一代理指标量化解释质量，将解释从“附加产物”提升为“优化目标”。这一设计解决了 ClearCheck 中 CoT 解释质量不可控的问题。然而，FaithLens 的解释质量奖励依赖 Llama-3.1-8B-Inst 这一特定新手模型，若该模型的能力边界发生变化，奖励信号的有效性可能受损，论文未探讨这种依赖性的鲁棒性。

## 总结

FaithLens 旨在解决低成本小模型在忠实性幻觉检测中精度与可解释性难以兼顾的矛盾。其切入点在于将解释质量转化为可量化的规则奖励，通过“新手模型预测”机制确保解释的信息密度，从而突破 SFT 的性能上限。方法上，FaithLens 结合多维数据过滤与 GRPO 规则 RL，在 12 个任务上以 86.4% 的 Macro-F1 超越 GPT-5.2，并生成高可信度解释。其边界在于解释质量评估依赖特定新手模型，且未与白盒内部表征方法直接对比，导致其在检测精度坐标系中的绝对位置模糊。当新手模型的能力边界发生变化时，解释质量奖励的有效性是否依然稳健，论文未给出回答。
