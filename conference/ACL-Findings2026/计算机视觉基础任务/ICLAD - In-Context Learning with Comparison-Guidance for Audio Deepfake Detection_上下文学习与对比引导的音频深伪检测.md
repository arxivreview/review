# ACL-Findings2026最新论文 ｜ICLAD: In-Context Learning with Comparison-Guidance for Audio Deepfake Detection ｜上下文学习与对比引导的音频深伪检测

研究机构：美国普渡大学

作者：Benjamin Chou、Yi Zhu、Surya Koppisetti

论文原文见 [arXiv](https://arxiv.org/abs/2604.16749)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.16749)

> 音频深度伪造检测（ADD）的核心困境在于专用检测器在受控录音室数据上性能饱和，却难以泛化至充满噪声与信道失真的野外场景。现有基于自监督学习（SSL）微调的方案虽在封闭集表现优异，但面对分布偏移时性能骤降，且缺乏可解释性。本文提出 ICLAD，一种免训练的音频大语言模型（ALM）检测框架，通过成对对比推理（PCR）策略引导模型自我发现判别性声学特征，并结合动态路由机制处理分布外样本。该框架在野外数据集上显著提升了宏 F1 分数并提供了文本解释，但在录音室数据上仍逊于专用检测器，其泛化边界与计算成本仍是主要制约。

## 研究背景

音频深伪检测面临的首要挑战是训练域与测试域的系统性分布偏移。录音室脚本语音缺乏背景噪声、房间混响及自然口语中的填充词与重复，导致在此类数据上训练的模型在野外音频上性能急剧衰减。这种泛化差距限制了检测器在真实攻击场景中的部署，因为实际伪造音频往往携带复杂的信道特征与非自发性语言模式。

主流解决方案依赖对大规模 SSL 模型（如 Wav2Vec 2.0、XLS-R）进行监督微调，以提取深层声学表征。尽管这些方法在 ASVspoof 等基准上取得了极低错误率，但反复微调成本高昂且难以应对快速迭代的生成技术。此外，黑盒模型缺乏对伪造证据的可解释性，无法满足司法取证对可信证据链的需求。近期研究尝试将 ADD 重构为音频问答任务以利用 ALM 的推理能力，但现有工作多依赖监督微调，未能摆脱对特定领域数据的依赖，且在野外数据上的泛化能力仍未得到充分验证。

ICLAD 的切入点在于利用 ALM 的上下文学习能力（ICL）实现免训练适配。通过引入 PCR 策略，该方法迫使模型在未见标签的情况下同时生成真实与伪造证据，再通过对比过滤幻觉与无关属性，从而在不更新参数的前提下发现跨域一致的判别性线索。这种设计旨在解决专用检测器在分布外（OOD）场景下的失效问题，同时提供可审计的文本推理过程。

## 核心方法

### 方法参照系

本文问题属于音频深伪检测中的开放集泛化与可解释性范畴。与传统的端到端分类器不同，ICLAD 不依赖参数更新，而是将检测任务转化为基于检索增强生成（RAG）的上下文推理任务。其关键差异在于利用 ALM 的语义理解能力替代手工特征或固定分类头，通过动态路由机制区分分布内（ID）与分布外（OOD）样本，仅在 OOD 场景下激活 ALM 进行推理。

### 成对对比推理 (PCR)

PCR 策略旨在解决 ALM 在零样本设置下对模糊声学线索产生矛盾解释的问题。在离线阶段，对于每个音频样本 $A_i$ 及其标签 $L_i$，ALM 首先被提示同时生成真实证据 $R_{real,i}$ 和伪造证据 $R_{fake,i}$，此时模型无法访问真值标签。随后，模型接收 $R_{real,i}$、$R_{fake,i}$ 及真值 $L_i$，生成调和证据 $R_{reconciled,i}$。该过程可形式化为：

$$ R_{reconciled,i} = f_{ALM}(A_i, R_{real,i}, R_{fake,i}, L_i) $$

其中 $f_{ALM}$ 表示 ALM 的推理函数。这一设计的动机在于，通过强制模型对比矛盾证据，它能识别并过滤掉那些在真实与伪造音频中均存在的非判别性属性（如某些类型的噪声），从而聚焦于真正区分真伪的细微声学伪迹。相比简单的提示策略，PCR 显著降低了幻觉率，从 18.3% 降至 10.0%，提升了解释的可靠性。

### 动态路由与检索增强推理

在线推理阶段，ICLAD 引入动态路由机制以平衡专用检测器与 ALM 的优势。查询音频 $A_q$ 首先通过基于 k-近邻（k-NN）的 OOD 检测器进行分类。若判定为 ID 样本，则直接由专用检测器 Wav2Vec2-AASIST 输出结果；若判定为 OOD 样本，则触发 ALM 推理。检索过程利用 Wav2Vec2-AASIST 提取的嵌入向量，从离线缓存中选取 $K$ 个声学最相似的样本及其配对证据，构成上下文提示：

$$ \text{Prompt} = \{ (A_k, L_k, R_{real,k}, R_{fake,k}, R_{reconciled,k}) \}_{k=1}^{K} \cup \{ A_q \} $$

该机制的设计动机在于，专用检测器在录音室数据上精度更高，而 ALM 在野外数据上泛化能力更强。通过路由，系统避免了 ALM 在 ID 数据上的性能劣势，同时利用了其在 OOD 数据上的语义推理优势。实验表明，这种混合策略在野外数据集上实现了最高 2 倍的相对宏 F1 提升，而在录音室数据集上保持了与专用检测器相当的性能。

## 实验评估

实验在五个数据集上进行，涵盖录音室（ASVspoof 2021, MLAAD）与野外（ITW, SpoofCeleb, DFEval 2024）场景，总计 126,348 个音频片段。基线选择 Wav2Vec2-AASIST，因其代表了当前 SSL 骨干检测器的最强泛化能力。评估指标采用宏 F1 分数与准确率，而非传统的等错误率（EER），以反映实际部署中硬分类的需求。

| 数据集 | 基线 Acc. | 基线 F1 | ICLAD Acc. | ICLAD F1 |
| :--- | :--- | :--- | :--- | :--- |
| 21DF | 0.868 | 0.866 | 0.825 | 0.822 |
| MLAAD | 0.800 | 0.798 | 0.593 | 0.593 |
| ITW | 0.691 | 0.674 | 0.778 | 0.777 |
| SpoofCeleb | 0.501 | 0.334 | 0.668 | 0.665 |
| DFEval 2024 | 0.500 | 0.367 | 0.550 | 0.550 |

在野外数据集上，ICLAD 表现出显著的泛化优势，特别是在 SpoofCeleb 上，其宏 F1 分数（0.665）几乎是基线（0.334）的两倍。然而，在录音室数据集上，ICLAD 性能低于基线，例如在 MLAAD 上宏 F1 仅为 0.593，远低于基线的 0.798。这一结果验证了动态路由机制的有效性：系统成功将 ID 样本路由至专用检测器，从而在整体性能上实现了互补。

消融实验揭示了 PCR 策略与检索嵌入选择的关键影响。在提示策略对比中，PCR 在平均宏 F1 上优于简单提示与知识引导策略，但在 MLAAD 上表现不佳，原因是该数据集真实语音缺乏生理标记，导致 PCR 过度过滤判别性线索。检索嵌入方面，Wav2Vec2-AASIST 嵌入优于通用音频或文本嵌入，表明任务特定特征对于检索声学相似样本至关重要。文本嵌入的引入反而降低了性能，可能是因为真实与伪造音频的文本描述高度相似，导致检索偏差。

评估边界方面，论文未报告计算延迟与资源消耗，而 ALM 推理通常涉及高计算成本。此外，宏 F1 分数依赖于固定的 0.5 阈值，未探索阈值优化对性能的影响。代码未公开，且依赖闭源模型 Gemini-2.5 Flash，限制了可复现性。尽管开源模型 Audio Flamingo 3 被测试，但其推理能力较弱，需借助预生成解释才能工作，暗示开源 ALM 在复杂推理任务上仍有差距。

## 关联研究分析

从问题动机看，ICLAD 与基于 SSL 微调的检测器（如 SONAR、IB-CAAN）形成鲜明对比。后者通过架构设计（如信息瓶颈、分层对比）提升跨域鲁棒性，但依赖大量标注数据与计算资源。ICLAD 则利用 ALM 的预训练知识实现免训练适配，其核心差异在于将泛化问题转化为语义推理问题。这种路线选择源于对“数据稀缺”与“计算效率”的权衡：当新攻击类型出现时，重新微调 SSL 模型成本高昂，而 ICLAD 仅需更新检索缓存即可适应新场景。然而，ICLAD 在录音室数据上的性能劣势表明，ALM 的通用语义理解尚未完全捕捉到深伪检测所需的细粒度声学伪迹，这与 SSL 模型在封闭集上的高精度形成互补。

从方法设计看，ICLAD 的 PCR 策略与传统的 XAI 方法（如 Grad-CAM）不同，后者提供局部激活图，而前者生成全局文本解释。与基于 LLM 的音频问答方法相比，ICLAD 的关键创新在于引入了对比推理机制以过滤幻觉。现有 LLM 方法往往直接输出标签，缺乏对证据可靠性的自我校验。PCR 通过强制模型对比矛盾证据，实现了类似“自我批判”的过程，这在提升解释可信度方面具有独特价值。然而，PCR 在特定数据集（如 MLAAD）上的失效揭示了一个潜在盲区：当真实与伪造样本的声学特征高度重叠时，对比推理可能过度保守，导致判别性线索丢失。这一局限提示，未来的研究可能需要结合更细粒度的声学特征提取，以弥补 ALM 在微观伪迹感知上的不足。

## 总结

ICLAD 旨在解决音频深伪检测中专用模型在野外场景下的泛化失效与可解释性缺失问题。其切入点在于利用 ALM 的上下文学习能力，通过 PCR 策略实现免训练的判别性特征发现，并结合动态路由机制平衡专用检测器与 ALM 的性能优势。实验表明，ICLAD 在野外数据集上实现了显著的宏 F1 提升，特别是在 SpoofCeleb 上达到 0.665，远超基线的 0.334，同时提供了低幻觉率的文本解释。然而，该方法在录音室数据集上性能低于专用检测器，且在计算效率与开源模型适配性上存在局限。当支持集规模扩大或声学特征重叠度增加时，PCR 策略的过度过滤效应是否会进一步削弱检测精度，仍是需要深入探究的问题。
