# ACL-Findings2026最新论文 ｜Adaptive Test-Time Compute Allocation with Evolving In-Context Demonstrations ｜自适应测试时计算分配与动态上下文演示

研究机构：美国加州大学河滨分校、美国印第安纳大学

作者：Bowen Zuo、Dongruo Zhou、Yinglun Zhu

论文原文见 [arXiv](https://arxiv.org/abs/2604.21018)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.21018)

> 测试时扩展（Test-Time Scaling, TTS）旨在通过增加推理阶段算力提升大语言模型（LLM）性能，但现有方法多采用静态采样分布或均匀算力分配，导致在异构难度数据集上效率低下。本文指出，仅决定“在哪分配算力”而忽略“如何改变生成分布”是性能瓶颈的关键。作者提出一种两阶段框架，通过自适应性上下文学习（In-Context Learning, ICL）动态重塑条件生成分布，实现算力分配与分布适应的统一。该方法在多个基准上以更低算力成本超越基线，但其效果高度依赖可验证任务中的真值反馈，在不可验证场景下的泛化能力存疑。

## 研究背景

当模型面对高难度推理任务时，单纯增加采样次数往往遭遇边际收益递减，因为正确解在基础条件分布 $p(\cdot|x)$ 下的概率极低。这一困境源于测试时扩展（TTS）中算力分配策略的静态性：传统 Best-of-N 方法对每个问题分配相同预算，且始终从固定分布中采样，无法感知问题难度的动态变化。为突破此局限，研究者引入自适应计算分配，试图根据问题难度动态调整采样数量，但此类方法仍受限于“固定生成分布”的假设，即无论采样多少次，模型的行为模式不变。

TTS 领域的主流路线分为并行采样与串行搜索，前者适合可验证任务，后者适合复杂规划。然而，现有自适应分配方法（如 Elimination 策略）仅解决了“分配多少算力”的问题，未触及“算力如何改变模型行为”的核心。本文切入点在于揭示分布适应的缺失：当正确解概率低时，重复采样同一分布难以成功，必须通过外部信号改变条件分布。作者将 ICL 引入 TTS 框架，利用测试集自身生成的正确响应作为动态演示，使模型在推理过程中逐步“学会”解题模式，从而在无需参数更新的情况下提升采样效率。

## 核心方法

### 方法参照系

本文问题归属于自适应计算分配类别，其标准流程为：估计问题难度 → 动态分配采样预算 → 从固定分布采样并聚合。关键差异在于，本文不仅调整采样数量，还通过 ICL 动态修改条件生成分布，将“算力分配”与“分布适应”耦合为单一推理时闭环。

### 两阶段自适应框架

设计动机在于解决固定分布采样在难题上的边际收益递减问题。Warm-up 阶段对每个问题 $x$ 生成固定数量 $K$ 的响应，若存在响应 $y$ 满足奖励 $r(x,y) \geq \gamma$（本文取 $\gamma=1$ 且使用真值验证），则标记为已解决并移除。此阶段同时构建初始演示池 $D_{test}$，其核心公式为：

$$
\tilde{y}(x) = \arg\max_{y \in g(x)} r(x,y)
$$

该公式通过确定性验证器筛选首个正确响应，确保演示池仅包含高质量样本，避免错误演示污染后续 ICL 过程。

### 基于相似性的分布适应

设计动机在于解决随机演示选择导致的性能不稳定问题。Adaptive 阶段对未解决问题 $x$，通过嵌入函数 $\phi(\cdot)$ 计算语义相似度，选取 Top-P 邻居 $\mathcal{P}(x)$ 构造 ICL 提示 $\Pi(x)$。生成分布从 $p(\cdot|x)$ 转变为 $p(\cdot|x, \Pi(x))$，其核心公式为：

$$
\mathcal{P}(x) = \text{Top-}P_{z \in S \setminus \{x\}} \cos(\phi(x), \phi(z))
$$

该公式通过余弦相似度检索语义相关邻居，确保演示与目标问题在结构上对齐，从而诱导更有效的分布偏移。随着更多问题被解决，$D_{test}$ 动态增长，$\Pi(x)$ 持续更新，实现生成分布的渐进式适应。

## 实验评估

实验在 MATH-500、GPQA-Diamond、LiveCodeBench 和 MinervaMath 四个基准上进行，使用 Gemini-2.5-flash-lite（含/不含思考）、GPT-4.1 Mini 和 GPT-5 Nano 四种模型变体。基线包括均匀分配（Unif）、消除式自适应分配（Elim）和随机演示选择（Ours Rand）。论文未提供具体数值表格，仅通过图示展示覆盖率随输出 Token 数的变化曲线，因此无法构建数值对比表格。

消融实验表明，相似性检索显著优于随机选择，尤其在推理密集型任务（如 Reasoning Gym）上，随机演示偶尔低于基线，而相似性检索保持一致增益。固定演示（Fixed ICL）和温度调节（Temperature tuning）的消融显示，动态演示池的更新是性能提升的关键，静态演示无法捕捉测试集内的分布变化。奖励模型消融中，使用噪声奖励（Noisy reward）导致性能下降，证实真值验证对演示池质量的重要性。

评估边界方面，论文仅报告覆盖率（Coverage），未提供置信区间或计算成本的具体量化（如 FLOPs 或延迟）。所有模型通过 API 访问，黑盒特性限制了 ICL 效果的归因分析。论文未提供代码，但算法流程清晰，超参数（如 $P$、$K$、$R$）在附录中给出，可复现性中等。

## 关联研究分析

从问题动机看，本文与 SCALE 方法同属自适应计算分配路线，但 SCALE 依赖离线训练的难度评估器预测计算需求，而本文通过在线消除机制实时估计难度，无需额外训练。这一差异源于任务特性：SCALE 假设难度与计算量存在可学习映射，本文则假设正确响应可作为难度信号。当任务不可验证时，SCALE 的评估器可能更鲁棒，而本文的消除机制将失效，论文未探索此场景。

从方法设计看，本文与 Logit Averaging 均利用多轨迹信息，但 Logit Averaging 在解码层聚合 logits，本文在提示层通过 ICL 改变条件分布。Logit Averaging 保留细粒度信息但计算开销随 $K$ 线性增加，本文通过语义检索减少无效演示，但引入额外输入 Token。查询侧增强在数据充足时是否仍有增益，论文未给出回答，因为实验仅覆盖中等规模测试集（166-500 题）。

## 总结

本文要解决的核心矛盾是固定生成分布在难题上的边际收益递减。现有方法仅调整算力分配数量，未触及分布适应，而本文通过 ICL 动态重塑条件分布，利用测试集自身生成的正确响应作为演示，实现算力分配与分布适应的统一。实验证明，该方法在 MATH-500 等基准上以更低 Token 成本超越 Unif 和 Elim 基线，相似性检索显著优于随机选择。本文的边界在于依赖真值验证构建演示池，在不可验证任务中无法保证演示质量。当测试集规模扩大至数千题时，语义检索的计算开销是否抵消算力节省，论文未给出回答。
