# ACL-Findings2026最新论文 ｜Do You Get the Hint? Benchmarking LLMs on the Board Game Concept ｜溯因推理基准：Concept 游戏

研究机构：比利时安特卫普大学

作者：Ine Gevers、Walter Daelemans

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ce81ab23342c)

> 大语言模型（LLM）在静态知识问答中表现优异，但在需要整合不完整线索、推断对手意图并动态修正假设的溯因推理任务中，其能力边界尚不明确。现有评测多聚焦于单轮语义匹配或完美信息博弈，缺乏对“线索-概念”映射中抽象推理与心智理论（Theory of Mind, ToM）交互的细粒度诊断。本文引入经典桌游 Concept 作为多语言基准，通过让 LLM 仅扮演猜测者并接收人类生成的分层线索，量化了模型在静态与动态设置下的推理失败模式。该基准揭示了 LLM 在低资源语言及序列信息更新中的显著劣势，但单侧评估设定可能掩盖了模型作为线索提供者时的策略缺陷。

## 研究背景

溯因推理要求智能体基于不完整、抽象的证据推断最可能的解释，这一过程依赖三个核心能力的协同：关联技能（消歧并连接线索）、心智理论（推断发送者的战略意图）以及常识（补充未明说的背景事实）。在 Concept 游戏中，Player 1 从 118 个预定义线索中选择组合以表达概念，Player 2 需解读这些线索的层级结构（如绿色问号代表主类别，同色方块代表子属性）并推断目标概念。这种层级结构意味着线索的解释具有语境依赖性，例如“金属”在“建筑”语境下指材质，而在其他语境下可能指颜色或材料，这要求模型具备灵活的语义组合能力而非简单的关键词匹配。

当前 LLM 评测体系存在两个主要盲区：一是静态与动态评估的割裂，多数基准仅测试单次输入输出，忽略了信息随时间更新对假设修正的影响；二是语言资源的单一性，绝大多数基准局限于英语，无法评估模型在低资源语言中抽象推理的迁移能力。尽管 Iconary 和 Codenames 等游戏基准已触及多模态或协作推理，但前者依赖视觉模态，后者侧重联想而非严格的逻辑溯因。本文的切入点在于构建一个纯文本、多语言、且包含静态与动态两种交互模式的基准，直接对比人类与 LLM 在相同线索输入下的表现，从而隔离出模型在抽象推理与意图推断上的具体短板。

## 核心方法

### 方法参照系

本文任务属于博弈基准评测中的“信号解码”子类别，其通用流程为：接收发送者信号 → 结合背景知识解码 → 输出动作。与完美信息博弈不同，Concept 的核心差异在于信号的抽象性与层级性：线索并非直接描述概念，而是通过隐喻或属性关联指向概念，且线索之间存在嵌套的语义依赖关系，这要求模型在执行解码前必须首先构建线索间的逻辑结构。

### 分层线索结构化提示

针对 LLM 难以自动解析线索层级结构的问题，本文在提示工程中引入了显式的颜色分组机制。设计动机在于，原始游戏界面中线索的层级关系通过颜色视觉呈现，而纯文本 LLM 无法直接感知视觉线索，若将线索平铺输入，模型可能错误地将子属性（如“蓝色”）直接关联到主类别（如“建筑”）而非中间节点（如“旗帜”）。本文通过验证集（n=50）测试发现，将同色线索分组并标注层级关系能显著提升性能。提示模板将线索组织为树状结构，其中主类别作为根节点，子属性作为叶节点，并附带一个来自规则书的示例以锚定推理模式。这种结构化提示将视觉层级转化为文本逻辑层级，降低了模型在语义组合时的认知负荷。

### 静态与动态双模式评估

为区分模型的静态知识检索能力与动态信念更新能力，本文设计了两种提示协议。静态模式（Static Prompt）将 Player 1 最终给出的所有线索一次性输入，允许模型进行最多 10 次猜测，每次错误后仅追加错误答案至上下文。动态模式（Dynamic Prompt）则模拟真实游戏进程，按步骤 $t=1, \dots, T$ 逐步更新线索集 $C_t$，并引入人类 Player 2 在对应步骤的错误答案 $H_t$ 作为上下文。动态模式的更新逻辑可形式化为：

$$ W_t = W_{t-1} \cup H_t \cup \{a_k \mid k < k^*, a_k \text{ is model's wrong guess at step } t\} $$

其中 $W_t$ 为第 $t$ 步的累积错误答案集合，$k^*$ 为模型在第 $t$ 步找到正确答案前的猜测次数。该公式的物理含义是，模型在第 $t$ 步的决策不仅依赖于当前线索 $C_t$，还依赖于历史线索演变过程中积累的所有错误信息（包括人类和模型自身的）。动态模式通过引入时间维度和对手行为（人类错误答案），迫使模型进行信念更新：当新线索出现或旧线索被移除时，模型需重新评估初始假设的有效性，而非仅依赖静态知识检索。

## 实验评估

实验在 Board Game Arena 收集的 4 种语言（英、法、西、荷）各 100 局完整游戏日志上进行，每局约 12 个概念，总计约 4,000 个概念。测试模型包括 LlaMA3.3 70B、LlaMA4-Maverick、Qwen2.5 72B、Deepseek V3、Mistral Small 24B、GPT 4.1 mini 及 GPT-OSS-120B。基线审计方面，本文仅对比了人类基线（94% 成功率）和不同 LLM 之间的相对性能，未包含传统 NLP 模型或专用推理模型（如基于搜索的 Wordle 求解器）作为对照，这可能高估了 LLM 在纯语言任务上的相对优势。

**修正后实验评估：**

实验在 Board Game Arena 收集的 4 种语言（英、法、西、荷）各 100 局完整游戏日志上进行，每局约 12 个概念。测试模型涵盖 LlaMA、Qwen、Deepseek、Mistral 及 GPT 系列。基线审计显示，本文仅对比了人类基线（94% 成功率）和不同 LLM 之间的相对性能，未包含传统 NLP 模型或专用推理模型作为对照。核心发现是，所有测试 LLM 的成功率均未超过 40%，而人类非专家玩家的成功率为 94%，揭示了巨大的“人类-模型”性能鸿沟。在语言维度上，模型在低资源语言（法、西、荷）中的表现显著低于英语，表明抽象推理能力未能有效跨语言迁移。在模式维度上，动态模式下的成功率普遍低于静态模式，证实了 LLM 在接收序列信息更新时难以有效修正初始假设，且对 Player 1 战略意图的推断能力薄弱。

消融分析聚焦于提示结构的影响。验证集测试表明，将线索按颜色分组并呈现层级结构比平铺输入性能更优，这验证了显式结构化提示对降低语义组合复杂度的必要性。然而，论文未报告不同模型在静态与动态模式下的具体数值差异，仅定性指出动态模式更难，这使得无法量化信念更新机制的具体贡献。此外，论文未分析模型在错误猜测后的修正策略，即模型是否真正利用了错误信息来缩小搜索空间，还是仅依赖重复尝试。

评估边界方面，本文使用人类生成的线索，排除了 LLM 作为线索提供者时的策略噪声，这使得结果更纯粹地反映解码能力，但可能掩盖了模型在生成线索时的抽象表达能力缺陷。指标仅使用成功率，未引入过程性指标（如猜测次数、线索利用率），无法区分模型是“快速猜中”还是“盲目遍历”。可复现性方面，数据集已在 HuggingFace 公开，提示模板完整，但未提供超参数细节（如温度、top-p）及计算资源需求，限制了精确复现。

## 关联研究分析

从问题动机看，本文与 Iconary（Clark et al., 2021）和 Codenames（Stephenson et al., 2025）均旨在测试 LLM 的协作推理能力，但存在根本差异。Iconary 依赖视觉模态，其核心挑战是跨模态对齐，而 Concept 是纯文本任务，核心挑战是抽象语义组合与层级解析。Codenames 侧重联想与团队策略，其线索通常是宽泛的类别词，而 Concept 的线索具有严格的层级约束和属性依赖，要求更精细的逻辑推理。本文的差异根源在于任务特性：Concept 的线索集是封闭且预定义的（118 个），这限制了搜索空间，使得任务更侧重于“解读”而非“生成”，这与开放域问答不同。然而，这种封闭性也可能导致模型过拟合于特定线索组合，而非真正掌握抽象推理机制。

从方法设计看，本文与 Twenty Questions（De Bruyn et al., 2022）同属信息获取游戏，但交互方向相反。Twenty Questions 中 LLM 主动提问以缩小搜索空间，而 Concept 中 LLM 被动接收线索并推断，这测试的是解码能力而非搜索策略。本文的动态模式引入了人类错误答案作为上下文，这类似于多智能体交互中的对手建模，但仅模拟了对手的行为（错误猜测），未模拟对手的信念状态。与知识库中 SOM（Cao et al., 2026）等结构化对手建模方法相比，本文未显式建模 Player 1 的信念或意图，而是依赖 LLM 的隐式 ToM 能力。这种差异暗示，显式的信念建模可能比隐式提示更有效，但本文未探索这一方向。

## 总结

本文旨在解决 LLM 在抽象溯因推理与动态信念更新中的能力评估缺失问题。现有基准多聚焦静态语义匹配或完美信息博弈，无法诊断模型在整合不完整线索与推断对手意图时的具体短板。本文通过构建多语言 Concept 基准，让 LLM 仅扮演猜测者并接收人类分层线索，量化了模型在静态与动态模式下的性能。实验显示，所有 LLM 成功率低于 40%，远低于人类的 94%，且在低资源语言和动态更新中表现更差，证实了 LLM 在抽象推理与意图推断上的结构性缺陷。本文的边界在于单侧评估设定，排除了 LLM 作为线索提供者的策略噪声，且未引入过程性指标以区分推理质量。当线索集从封闭的 118 个扩展到开放域时，模型的抽象推理能力是否仍能维持，论文未给出回答。
