# ACL-Findings2026最新论文 ｜Beyond Prompt Engineering: A Systematic Analysis of Prompt Lexical Sensitivity and Its Impacts on Quality ｜提示词敏感性的统计归因与鲁棒性机制分析

研究机构：香港理工大学、香港中文大学

作者：Qipeng Xie、Zi Liang、Jiafei Wu 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_8e5171758430)

> 提示词工程长期面临“蝴蝶效应”，即微小的词汇扰动导致模型输出剧烈波动，现有方法多聚焦于黑盒优化或模板级评估，缺乏对底层词汇机制的统计解释。本文切入点在于将提示词敏感性视为一种可量化的统计现象，而非需消除的噪声。通过构建132,000个提示词变体数据集，利用n-gram统计识别出“领域特定术语”与“显式行动指令”作为鲁棒性的语言支柱，并据此设计自动化的模式注入代理。该工作提供了从经验直觉到统计原则的转变，但其结论是否适用于非结构化或低资源语言场景仍存疑。

## 研究背景

当用户输入“翻译这句话”而非“将句子翻译为英语”时，大语言模型（LLM）可能输出法语而非英语，这种对表面形式的高度依赖被称为提示词敏感性（Prompt Sensitivity）。敏感性源于模型内部表示对词汇顺序、标点及语用特征的过度拟合，导致语义等价但表述不同的提示词产生截然不同的性能表现。为量化这一现象，研究者通常计算同一任务下不同提示词变体的输出标准差（Std），标准差越高，表明模型对提示词形式的鲁棒性越差。

该领域的主流解决路线分为两类：一是自动提示优化（Automatic Prompt Optimization, APO），如TextGrad和GEPA，通过黑盒搜索或梯度信号迭代寻找高性能提示词，但这类方法往往产生过拟合特定措辞的“脆弱”提示，缺乏可解释性；二是鲁棒性训练或校准，如Prompt Perturbation Consistency Learning，试图在训练或推理阶段强制模型输出一致性，但这类方法多依赖模型内部参数调整或外部校准器，未揭示提示词文本本身的结构特征如何影响稳定性。现有研究的瓶颈在于，它们将敏感性视为需要被算法“绕过”或“抑制”的障碍，而非理解其成因的线索。本文的切入点在于，通过大规模统计归因，直接分析提示词文本中的n-gram特征与输出稳定性之间的因果关系，从而将鲁棒性设计从“试错”转变为“基于统计规律的结构化约束”。

## 核心方法

### 系统性扰动框架与正交性验证

本文首先建立了一个多维度的提示词扰动基准，以模拟真实用户输入的多样性。不同于随机噪声或单一改写，该方法定义了五种语义等价但风格迥异的改写策略：语义等价改写（SEP）、添加上下文信息（ACI）、改变格式/风格（CFS）、引入歧义（IA）和句法噪声（SN）。为确保这些策略探测的是模型能力的不同维度而非冗余特征，本文在嵌入空间中计算了各策略诱导的位移向量 $\Delta v$ 的正交性。

$$ \Delta v = v_{\text{rewrite}} - v_{\text{original}} $$

其中 $v(\cdot)$ 为嵌入函数。通过主成分分析（PCA）和余弦相似度矩阵验证，五种策略在投影空间中形成分离良好的簇，平均非对角线余弦相似度仅为0.22，表明该扰动框架具备高度的独立性，能够全面覆盖从微观语义偏移（IA，平均距离≈0.07）到宏观表面形式扰动（SN，平均距离≈0.36）的强度谱系。这一设计动机在于，此前的敏感性评估多依赖单一维度的改写，无法区分模型是对语义模糊敏感还是对表面噪声敏感，而正交的多维扰动为后续的归因分析提供了可靠的测量工具。

### 性能-稳定性缩放定律与n-gram统计归因

在验证扰动框架有效性后，本文对12,000条指令及其11个变体（共132,000次评估）进行了大规模统计，揭示了提示词性能与稳定性之间的内在联系。通过普通最小二乘法（OLS）回归，本文发现平均性能分数（Mean）与标准差（Std）之间存在显著的负相关关系：

$$ y = -1.083x + 93.60, \quad R^2 = 0.7006 $$

其中 $y$ 为平均性能，$x$ 为标准差。这一“缩放定律”表明，鲁棒性并非独立于性能的额外约束，而是高性能提示词的固有属性，70%的性能方差可由稳定性解释。基于此，本文采用中位数阈值将数据划分为四个象限，并针对“高性能-高鲁棒性”（HP-HR）象限进行n-gram统计归因。通过Log Odds Ratio分析，识别出两类显著特征：领域特定术语（如“algorithm”、“protocol”）和显式行动指令（如“step-by-step”、“compare and contrast”）。这些词汇模式通过收窄模型的“解释空间”，将生成过程锁定在特定的语义边界和执行路径上，从而抑制了因歧义导致的输出漂移。这一发现将鲁棒性归因于语言结构对解释空间的约束，而非模型内部的随机性。

### 基于模式注入的自动优化代理

为了验证上述统计规律的因果效用，本文设计了Prompt-Refining Agent，通过两阶段注入管线将脆弱查询转化为鲁棒指令。第一阶段注入领域特定术语作为“语义锚点”，例如将“fix the code”重构为“debug the implementation based on syntax standards”，以缩小语义搜索空间；第二阶段注入显式行动指令作为“操作锚点”，例如追加“provide a step-by-step derivation”，以锁定执行路径。该代理不依赖黑盒搜索，而是严格遵循统计识别出的模式进行规则化重写。其设计动机在于，此前的自动优化方法（如APE）通过迭代试错寻找局部最优，但无法解释“为何有效”，且产生的提示词难以迁移；而基于统计规律的模式注入提供了可解释的、可复现的鲁棒性增强机制，将提示词工程从“艺术”转化为“工程”。

## 实验评估

实验基于WizardLM_evol_instruct_70k数据集，随机采样12,000条指令，使用Qwen-plus作为生成器，Grok-4-fast作为评估器，采用LLM-as-a-Judge范式进行自动化评分。评估指标包括Rouge-L（客观）和LLM-as-a-Judge（主观），并计算标准差以衡量稳定性。基线为原始提示词（Base Prompt），对比方法为本文提出的模式注入提示词（Improved Prompt）。由于论文未提供与TextGrad、GEPA等SOTA自动优化方法的直接对比，且未报告GSM8K等标准基准成绩，本评估主要聚焦于方差降低的相对效果。

| 任务领域 | 指标 | Base Prompt (Mean/Std) | Improved Prompt (Mean/Std) | Std 降低幅度 |
| :--- | :--- | :--- | :--- | :--- |
| Code Writing | Rouge-L | 16.77 / 3.24 | 17.40 / 1.92 | 40.7% |
| Code Writing | LLM-as-a-Judge | 77.17 / 12.96 | 83.22 / 7.73 | 40.4% |
| Math Calculation | Rouge-L | 18.69 / 3.71 | 19.64 / 2.32 | 37.3% |
| Logic Puzzles | LLM-as-a-Judge | 73.50 / 14.15 | 80.32 / 9.53 | 32.6% |
| Creative Writing | LLM-as-a-Judge | 78.85 / 9.13 | 72.55 / 4.28 | 53.1% |
| Health Medical | Rouge-L | 16.66 / 3.18 | 15.96 / 1.58 | 50.1% |

在结构化任务（如代码、数学、逻辑）中，模式注入不仅显著降低了标准差（最高40.7%），还提升了平均性能（如Logic Puzzles的LLM-as-a-Judge提升9.3%），证实了“收窄解释空间”能同时提升质量与稳定性。然而，在开放生成任务（如创意写作、医疗健康）中，平均性能出现轻微下降（如Creative Writing的LLM-as-a-Judge下降8.0%），但标准差大幅下降（53.1%）。这一反直觉现象表明，模式注入通过剪除高方差的“创造性”路径，牺牲了部分峰值性能以换取可靠性，这在安全关键领域（如医疗）是合理的权衡，但在创意任务中可能限制了模型的探索能力。

评估边界方面，本文仅使用Qwen和Gemini模型族，未验证MoE架构或小型模型的泛化性；数据集限于英语指令，未覆盖低资源语言；评估依赖LLM-as-a-Judge，可能存在与人类偏好不一致的偏差。此外，论文未提供代码开源链接，且未报告计算成本，限制了可复现性。

## 关联研究分析

从问题动机看，本文与PROSA（Zhuo et al., 2024）同属敏感性评估框架，但PROSA主要关注模板级扰动下的鲁棒性度量，而本文深入至n-gram级统计归因，揭示了鲁棒性的语言机制。这一差异源于任务特性：PROSA旨在量化“有多脆弱”，而本文旨在解释“为何脆弱”及“如何修复”。从方法设计看，本文与TextGrad（Yuksekgonul et al., 2024）形成鲜明对比。TextGrad依赖梯度信号进行黑盒迭代，追求峰值性能，但产生的提示词往往过拟合且不可解释；本文则基于统计规律进行白盒规则注入，牺牲部分峰值性能以换取可解释性和稳定性。这种差异暗示，在部署场景中，若任务对稳定性要求高于峰值性能（如医疗、金融），本文的方法可能更优；但若任务追求极致性能（如竞赛数学），TextGrad可能更具竞争力。查询侧增强在数据充足时是否仍有增益，论文未给出回答，且缺乏与SOTA优化方法的方差对比，使得其鲁棒性优势的相对地位难以精确界定。

## 总结

本文要解决的核心矛盾是提示词敏感性的不可解释性与鲁棒性设计的经验性。现有方法要么通过黑盒搜索绕过敏感性，要么通过训练正则化抑制敏感性，均未能揭示提示词文本结构对稳定性的因果作用。本文凭借132,000样本的大规模统计，识别出“领域特定术语”与“显式行动指令”作为鲁棒性的语言支柱，并证明高性能与低方差之间存在缩放定律。通过模式注入代理，本文在代码生成任务中实现了40.7%的方差降低，同时提升了平均性能。然而，本文的边界在于其结论主要基于英语结构化任务，且在开放生成任务中表现出性能下降的权衡。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
