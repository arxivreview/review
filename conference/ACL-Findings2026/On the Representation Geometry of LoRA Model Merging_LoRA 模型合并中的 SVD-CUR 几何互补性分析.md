> 导读 多任务 LoRA 合并面临的核心困境在于，现有方法普遍假设单一全局子空间足以对齐所有任务更新，但低秩约束导致不同任务的更新方向在参数空间中系统性错位。本文切入点在于揭示奇异值分解（SVD）与列选择分解（CUR）在捕获共享结构与任务特异结构上的几何互补性，而非直接提出新算子。通过构建双分支并行对齐框架并基于残差能量加权融合，该方法在视觉与语言基准上实现了无训练合并性能的稳定提升。其价值在于从表示几何层面解构了合并失效的根源，但实验未覆盖异构秩或跨架构场景，其理论边界仍受限于同源初始化假设。

## 研究背景

当多个针对特定任务微调的 LoRA 适配器需要整合为单一模型时，直接权重相加往往导致性能退化。这一现象源于 LoRA 的低秩约束：每个任务的更新 $\Delta W = BA$ 被限制在一个低维子空间内，不同任务的子空间方向往往不一致，导致简单线性组合产生严重的参数干扰。解决这一问题的主流思路是先将任务更新对齐到共享表示空间，再执行合并操作。KnOTS 等代表性工作将这一对齐过程形式化为矩阵分解问题，利用 SVD 构建共享基向量，使所有任务更新投影到同一组基上，从而消除方向冲突。

然而，SVD 作为全局方差最大化的分解方法，其隐含假设是存在一个统一的低维结构能够同时解释所有任务的更新。这一假设在任务差异较大时失效：SVD 倾向于捕获全局共享的主导方向，而忽略那些集中在特定行或列、与全局主成分不对齐的任务特异成分。这种偏差导致合并后的模型在保留任务独特性方面表现不佳，尤其是在视觉分类等对局部特征敏感的任务中。本文的研究切入点正是针对这一表示层面的局限性，通过引入 CUR 分解作为互补视角，显式分离并融合全局共享结构与局部特异结构，从而突破单一基假设的约束。

## 核心方法

### 方法参照系

本文问题属于 LoRA 模型合并中的子空间对齐路线。标准流程如 KnOTS 所示，首先对拼接的任务更新矩阵进行 SVD 分解，提取共享左奇异向量作为对齐基，然后在对齐空间中应用 TIES 等合并算子。本文的关键差异在于，它不再假设单一 SVD 基足以捕获所有结构，而是并行引入 CUR 分解，利用其稀疏、数据依赖的特性保留任务特异信息，最终通过能量加权融合两个分支的输出。

### SVD 与 CUR 的几何错位分析

设计动机在于解决 SVD 全局偏差导致的任务特异信息丢失。SVD 构建的基向量 $U_j$ 捕获全局方差最大的方向，而 CUR 通过选择 $\ell_2$ 范数最大的列构建稀疏基，更倾向于保留局部结构。本文通过子空间重叠度量化两者的错位：计算 SVD 基 $Q_1$ 与 CUR 基 $Q_2$ 的主角余弦值，发现重叠度在 0.30 至 0.67 之间波动，表明两者捕获的参数空间方向存在显著差异。这种错位并非噪声，而是反映了两种分解策略在表示偏好上的本质区别：SVD 强调全局一致性，CUR 强调局部特异性。

### 基于残差能量的双分支融合

设计动机在于利用 SVD 与 CUR 的互补性，通过加权融合降低整体合并误差。本文提出混合更新公式：

$$ \Delta W = \alpha \Delta W_{\text{SVD}} + (1 - \alpha) \Delta W_{\text{CUR}} $$

其中 $\alpha$ 由残差能量决定。具体地，计算 SVD 和 CUR 分支的残差能量 $E_{\text{SVD}}$ 和 $E_{\text{CUR}}$，并转换为更新幅度 $M = \sqrt{E} = \|\Delta W\|_F$，最终系数定义为：

$$ \alpha = \frac{M_{\text{SVD}}}{M_{\text{SVD}} + M_{\text{CUR}}} $$

该公式的物理含义是：残差能量较小的分支被认为更准确地逼近了最优合并更新，因此获得更高的权重。理论上，当两个分支的误差非正相关时，这种凸组合能保证混合更新的 Frobenius 误差不高于任一单独分支，从而在数学上证明了融合策略的优越性。

## 实验评估

实验在 ViT-B/32 和 Llama-3-8B 上进行，覆盖 8 个视觉分类任务和 6 个自然语言推理任务。基线包括 Task Arithmetic、TIES、DARE-TIES、KnOTS、LoRA-LEGO 等，覆盖了线性组合、稀疏化合并和子空间对齐等主要路线。缺失的强基线包括 Fisher 加权平均和最新的几何推断方法，这可能限制了性能上限的对比。

| 方法 | 平均归一化准确率 (%) |
| --- | --- |
| RegMean | 60.9 |
| TA | 63.7 |
| TIES | 63.7 |
| KnOTS-TIES | 67.7 |
| CoreSpace-TIES | 68.6 |
| Ours-TIES | 70.0 |

在视觉任务上，本文方法（Ours-TIES）以 70.0% 的平均归一化准确率领先，较 KnOTS-TIES 提升 2.3 个百分点，较 CoreSpace-TIES 提升 1.4 个百分点。这一提升主要归因于 CUR 分支对任务特异结构的保留，特别是在 DTD 和 GTSRB 等纹理和交通标志分类任务上，性能增益最为显著。

| 任务 | KnOTS-TIES | Ours-TIES | 提升幅度 |
| --- | --- | --- | --- |
| DTD | 48.8 | 54.5 | +5.7 |
| GTSRB | 49.2 | 41.8 | -7.4 |
| MNIST | 68.9 | 78.8 | +9.9 |
| SVHN | 53.7 | 59.1 | +5.4 |

消融分析显示，CUR 分支在 MNIST 和 SVHN 等数字识别任务上贡献最大，提升幅度超过 5 个百分点，而在 GTSRB 任务上出现负迁移，性能下降 7.4 个百分点。这表明 CUR 的局部保留特性在某些任务上可能引入噪声，能量加权机制未能完全消解这种任务依赖的不稳定性。

评估边界方面，实验仅使用同源初始化模型，未测试不同预训练来源或不同 LoRA 秩的鲁棒性。代码已开源，但超参数搜索空间未详细报告，特别是 CUR 列选择阈值和 SVD 秩的敏感性分析缺失。指标仅报告归一化准确率，未提供置信区间或多次运行的方差，限制了统计显著性的判断。

## 关联研究分析

从问题动机看，本文与 KnOTS 的核心差异在于对“共享表示”的定义。KnOTS 假设存在一个全局最优的 SVD 基，而本文通过实证分析证明该假设不成立，SVD 基与 CUR 基在子空间层面系统性错位。这一差异的根源在于 LoRA 更新的结构特性：低秩约束使得任务更新集中在少数方向上，而这些方向可能既包含全局共享成分，也包含局部特异成分。KnOTS 的单一基假设忽略了这种混合结构，导致在任务差异较大时性能退化。本文的双分支设计正是为了显式处理这种混合性，但其代价是计算复杂度的增加和融合系数的任务依赖性。

从方法设计看，本文与 LoRA-LEGO 同属子空间对齐路线，但侧重点不同。LoRA-LEGO 通过秩分解和聚类来减少干扰，侧重于结构分解；本文则通过 SVD-CUR 几何互补性来优化表示，侧重于能量分布。两者的差异反映了子空间合并中的两种策略：一种是显式分解结构，另一种是隐式优化表示。本文的方法更依赖于残差能量的统计特性，而 LoRA-LEGO 更依赖于聚类算法的稳定性。在 GTSRB 任务上的负迁移现象表明，能量加权机制在局部结构噪声较大时可能失效，而 LoRA-LEGO 的聚类策略或许能提供更鲁棒的解决方案，但论文未进行此类对比。

## 总结

本文要解决的核心矛盾是 LoRA 合并中单一全局子空间假设与任务更新几何多样性之间的冲突。现有方法如 KnOTS 依赖 SVD 构建共享基，但 SVD 的全局方差最大化特性导致任务特异信息丢失。本文抓住的切入点是 SVD 与 CUR 分解在表示偏好上的互补性，通过双分支并行对齐和残差能量加权融合，显式分离并整合全局共享结构与局部特异结构。实验证明该方法在视觉任务上平均提升 2.3 个百分点，在 MNIST 等任务上提升超过 9 个百分点。然而，本文的边界在于其依赖同源初始化假设，且能量加权机制在 GTSRB 等任务上出现负迁移，表明融合系数对任务分布的敏感性未被充分解决。当 LoRA 秩动态变化或任务间子空间重叠度极低时，残差能量加权是否仍能保持稳定性，论文未给出回答。
