# ACL-Findings2026最新论文 ｜Memory Dial: A Training Framework for Controllable Memorization in Language Models ｜记忆压力调控框架

研究机构：美国佐治亚理工学院、美国埃默里大学

作者：Xiangbo Zhang、Ali Emami

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_57d9f516b01d)

> 大语言模型的记忆机制长期被视为训练过程的被动副产物，研究者只能事后检测模型记住了什么，却无法在训练前预设其记忆强度。现有暴露度指标与提取攻击均依赖已训练完成的模型，难以将记忆效应与架构、数据等混杂因素解耦。MEMORY DIAL 通过引入温度锐化目标函数与标准交叉熵的凸组合，将记忆压力转化为可连续调节的独立变量。该框架在六个架构上验证了记忆可控性与泛化稳定性，但其控制粒度局限于训练目标层面，未触及参数空间的直接编辑。

## 研究背景

当评估基准与预训练语料重叠时，模型在熟悉样本上的准确率被系统性高估，导致泛化能力评估失真。这种偏差源于模型对训练序列的逐字记忆（Memorization），而记忆本身又是模型获取事实知识与规范表达的必要基础。要量化记忆对下游行为的因果影响，必须将其从混杂变量中剥离，但传统方法如暴露度指标（Exposure Metric）仅能对比模型生成特定序列的概率与随机基线，无法在保持其他因素不变的前提下操纵记忆强度。

领域共识认为参数化记忆主要存储于前馈网络（FFN）层，表现为键值对形式的知识存储，且记忆与泛化存在权衡关系。然而，现有研究多聚焦于记忆的检测（如提取攻击、成员推断）或事后缓解（如权重剪枝、正则化），缺乏在训练过程中主动控制记忆压力的实验工具。GSS门控子空间转向方法通过探针校正实现选择性遗忘，SLoRA通过参数选择平衡持续学习中的可塑性与遗忘，但这些方法均针对特定任务或特定记忆条目，无法提供全局、连续的记忆强度调节。MEMORY DIAL 的切入点在于将记忆压力从依赖变量转化为独立实验变量，通过单一标量参数控制训练过程中的记忆强化程度，从而建立仅差异于记忆压力的模型族。

## 核心方法

### 训练目标参照系

标准自回归语言模型训练最小化负对数似然，即交叉熵损失。该目标函数驱动模型学习数据分布的统计结构，但无法区分“学习泛化模式”与“记忆特定序列”两种行为。MEMORY DIAL 在标准交叉熵基础上引入温度锐化项，构建凸组合目标函数，使记忆压力成为可调节的独立维度。

### 温度锐化目标函数

MEMORY DIAL 的核心创新在于引入温度锐化分布（Temperature-Sharpened Distribution）作为记忆增强目标。对于温度参数 $\tau \in (0, 1]$，锐化分布定义为 $p^{(\tau)}_\theta(\cdot | x_{<t}) = \text{softmax}(z_\theta(x_{<t}) / \tau)$。当 $\tau < 1$ 时，分布变得更加尖锐，对低置信度预测施加更重的惩罚。该设计动机在于解决标准交叉熵中“富者愈富”动态的不足：已具有高置信度的预测会获得不成比例的梯度更新，而温度锐化通过放大这一效应，使重复序列在多次优化步骤中积累更强的记忆信号。

### 凸组合与模型族构建

MEMORY DIAL 通过凸组合将标准目标与锐化目标结合，由单一参数 $\alpha \in [0, 1]$ 控制插值：

$$
\mathcal{L}_{MD}(\theta; \alpha, \tau) = (1 - \alpha) \mathcal{L}_{std}(\theta) + \alpha \mathcal{L}_{mem}(\theta; \tau)
$$

其中 $\mathcal{L}_{std}$ 为标准交叉熵，$\mathcal{L}_{mem}$ 为温度锐化损失。该公式的物理含义是：$\alpha$ 作为“记忆压力旋钮”，在标准训练基线之上叠加额外的记忆强化压力。通过固定架构、数据与优化设置，仅变化 $\alpha$ 值训练多个模型，构成仅差异于记忆压力的模型族 $\{M_\alpha | \alpha \in [0, 1]\}$。这一构造使得任何行为差异均可归因于记忆压力，而非混杂因素，实现了记忆作为独立实验变量的可控性。

## 实验评估

实验在六个架构（DistilGPT2 至 OPT-27B）和五个基准（ARC, BoolQ, PIQA, COPA, OpenBookQA）上进行，每个基准随机选取50个样本注入训练集作为“seen”样本，其余950个作为“unseen”样本。基线审计显示，本文未对比EWC、GEM等遗忘缓解方法，因任务定义为记忆压力控制而非遗忘缓解；也未对比ROME等参数编辑方法，因MEMORY DIAL 作用于训练目标而非参数空间。

所有30个模型-基准组合的seen样本准确率斜率均为正，范围在0.03至0.38之间，证实 $\alpha$ 可靠地控制记忆压力。OPT-27B 的平均斜率（0.206）显著高于 DistilGPT2（0.097），表明记忆可控性随模型容量增加而增强。Unseen 样本准确率在 $\alpha$ 从0.0到1.0变化时保持稳定，例如 DistilGPT2 在 ARC 上的 unseen 准确率从0.436降至0.431，差异小于0.5个百分点，证实记忆压力增加不损害泛化。

PPL Gap（unseen 与 seen 困惑度之差）随 $\alpha$ 增加而单调下降，从5.70降至0.58，进一步验证记忆强度的连续可控性。频率分层分析显示，高频序列在 $\alpha=0.0$ 时 NLL 为32.40，稀有序列为36.76，差距约4.4点；在 $\alpha=0.8$ 时，稀有序列 NLL 降至29.69，高频序列降至27.21，差距缩小至2.5点，但稀有序列始终更难记忆。

## 关联研究分析

从问题动机看，MEMORY DIAL 与暴露度指标（Exposure Metric）形成互补：后者通过对比模型生成特定序列的概率与随机基线，量化已训练模型的记忆程度，属于事后检测；前者通过训练目标干预，在训练前预设记忆强度，属于事前控制。这一差异源于任务定义的不同：暴露度指标服务于隐私风险评估，需量化模型对训练数据的记忆程度；MEMORY DIAL 服务于机理研究，需隔离记忆对模型行为的因果影响。MEMORY DIAL 的 Seen/Unseen 准确率斜率可视为暴露度指标的训练时动态版本，但二者在评估协议上不可直接比较，因前者依赖注入样本，后者依赖自然语料。

从方法设计看，MEMORY DIAL 与 GSS 门控子空间转向方法互为正交：GSS 通过探针检测记忆相关激活并实施针对性校正，实现选择性遗忘，作用于参数空间；MEMORY DIAL 通过温度锐化目标函数强化记忆，作用于训练目标。GSS 的局限在于需预先识别记忆相关激活，且校正可能破坏其他能力；MEMORY DIAL 的局限在于全局调节记忆压力，无法针对特定记忆条目。SleepGate 通过重放巩固记忆，与 MEMORY DIAL 均旨在增强特定记忆，但机制不同：SleepGate 依赖冲突感知时间标记与选择性重放，MEMORY DIAL 依赖梯度锐化。MEMORY DIAL 未探索与外部记忆系统（如 RAG）的结合，其控制粒度局限于参数化记忆，未触及非参数化记忆的管理。

## 总结

MEMORY DIAL 解决了记忆作为依赖变量难以因果分析的核心矛盾，通过温度锐化目标函数将记忆压力转化为可连续调节的独立变量。该框架在六个架构上验证了记忆可控性（斜率0.03-0.38）与泛化稳定性（unseen 准确率变化<0.5个百分点），证实记忆压力增加不损害泛化。其边界在于控制粒度局限于训练目标层面，未触及参数空间的直接编辑，且仅验证于多选基准，未测试长文本生成质量。当 $\alpha=1.0$ 时的记忆强度是否超过自然预训练的记忆上限，论文未给出回答。
