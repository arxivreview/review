# ACL-Findings2026最新论文 ｜STELLA: A Multimodal LLM for Protein Functional Annotation via Unified Sequence-Structure Encoding ｜蛋白质功能注释的多模态大语言模型

研究机构：北京大学、中国人民大学

作者：Hongwang Xiao、Wenjun Lin、Xi Chen 等 10 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_4782ac22af63)

> 蛋白质功能注释面临结构数据爆发但功能标签滞后的矛盾，现有纯序列语言模型缺乏高分辨率结构信息，分离式多模态架构又引入冗余融合开销。STELLA 切入点在于利用统一编码的 ESM3 替代分离编码器，直接对接 LLM 生成自然语言功能描述。其核心做法是构建“ESM3 编码器 + 线性投影 + Llama-3.1-8B”的两阶段指令微调框架。该方案在酶反应预测上刷新了 SOTA，但功能描述生成的语义鲁棒性仍受限于 NLP 指标的代理性质，且对分布外结构的泛化能力尚未完全解决。

## 研究背景

蛋白质生物学遵循“序列决定结构，结构决定功能”的层级逻辑。当研究者试图从已知的三维结构推导其生物学角色时，面临的核心困境是结构几何信息无法直接映射为自然语言描述。传统的蛋白质语言模型（Protein Language Model, PLM）如 ESM-2 擅长捕捉序列中的进化约束，但仅操作于残基尺度，缺乏原子级空间细节，导致在涉及精确化学环境的功能推断中精度受限。为弥补这一缺陷，多模态大语言模型（Multimodal Large Language Model, MLLM）被引入，旨在将结构模态与文本模态对齐。然而，现有 MLLM 如 Prot2Text 和 ProteinGPT 通常采用分离的预训练编码器分别处理序列和结构，再通过复杂的融合层对接 LLM。这种架构碎片化不仅增加了计算开销，更导致跨模态梯度优化困难，难以实现结构特征到功能语义的高效转化。

当前领域的主流路线存在两个瓶颈：一是纯 PLM 路线无法生成富含上下文的功能叙事，仅能输出离散标签；二是分离式 MLLM 路线因编码器异构性，难以充分利用结构数据的几何先验。STELLA 的切入点在于利用 ESM3 这一前沿 PLM 的统一编码能力。ESM3 在预训练阶段已将序列、结构和功能描述符整合至同一嵌入空间，其初始 Transformer 块中的几何注意力机制能捕捉原子级空间细节。通过直接复用 ESM3 作为蛋白质结构编码器，STELLA 消除了分离式架构中的冗余融合层，将多模态对齐问题简化为单一线性投影问题，从而在保持结构信息保真度的同时，显著降低了跨模态优化的复杂度。

## 核心方法

### 统一编码架构参照系

STELLA 的架构设计借鉴了视觉-语言模型 LLaVA 的范式，但针对蛋白质生物学的特性进行了关键改造。标准 LLaVA 流程包含视觉编码器、模态连接器和 LLM 三个模块，通常使用不同数据集分别进行对齐和微调。STELLA 的核心差异在于蛋白质编码器的选择：它不采用独立的视觉或结构编码器，而是直接嵌入 ESM3（esm3_sm_open_v1, 1.4B 参数）。这一选择使得蛋白质模态在输入 LLM 前已完成序列-结构的内部融合，模态连接器仅需处理“已融合的生物表征”到“文本潜空间”的映射，而非“异构模态”的强行拼接。

### 线性投影与两阶段指令微调

在模态连接器环节，STELLA 摒弃了复杂的非线性融合网络，仅使用单层线性投影作为适配器。这一设计动机在于 ESM3 的嵌入空间已具备高度的生物信息密度，线性映射足以完成跨模态特征对齐，同时避免了过拟合风险。训练过程采用两阶段多模态指令微调（Multimodal Instruction Tuning, MMIT）。第一阶段冻结 ESM3 和 LLM，仅训练线性投影层，实现蛋白质嵌入与 Llama-3.1-8B-Instruct 文本潜空间的初步对齐。第二阶段联合微调投影层和 LLM，采用差异化学习率，而 ESM3 保持冻结。由于高质量蛋白质-文本指令对稀缺，STELLA 在两个阶段使用同一数据集 OPI-Struc，通过 ChatGPT 合成约 100 种语义等价提示变体，以增强提示的词汇和结构多样性。

$$
\mathbf{h}_{protein} = \text{ESM3}(\mathbf{x}_{seq}, \mathbf{x}_{struct})
$$

$$
\mathbf{z}_{aligned} = \mathbf{W}_{proj} \mathbf{h}_{protein} + \mathbf{b}_{proj}
$$

其中 $\mathbf{h}_{protein}$ 为 ESM3 输出的统一生物表征，$\mathbf{z}_{aligned}$ 为投影至 LLM 潜空间的对齐特征。该公式表明，STELLA 将复杂的跨模态融合前置到 ESM3 内部，后续仅执行线性空间变换，从而保证了结构几何信息在传递过程中的低损耗。

## 实验评估

STELLA 在 OPI-Struc 数据集上进行评估，该数据集包含功能描述（FP）和酶反应预测（EP）两个子域。基线覆盖包括纯序列模型（ProtBERT, ESM-1b）、结构感知模型（SaProt, GearNet）以及检索方法（Foldseek）。在 EP 任务上，STELLA (e3+e6) 取得 88.85% 的准确率，超越此前最佳模型 CDConv 和 Sable 的 88.50%。在 FP 任务上，STELLA (e3+e6) 的 ROUGE-L 为 0.5257，高于 Prot2TextLARGE 的 0.5140。

| 模型 | EP Accuracy (%) | FP ROUGE-L |
| :--- | :--- | :--- |
| CDConv | 88.50 | - |
| Sable | 88.50 | - |
| Prot2TextLARGE | - | 0.5140 |
| STELLA (e3+e3) | 88.06 | 0.5041 |
| STELLA (e3+e6) | 88.85 | 0.5257 |

消融实验显示，第二阶段训练轮数从 3 增加到 6 时，EP 准确率从 88.06% 提升至 88.85%，表明增加微调时长能进一步挖掘 LLM 的生化命名知识。在结构退化鲁棒性测试中，截断 10% 末端残基后，STELLA (e3+e6) 的 ROUGE-L 仅下降 4.1%（0.5257 至 0.4915），而 Prot2TextLARGE 下降 13.7%，证明统一编码架构对不完整结构数据具有更强的表征稳定性。

评估边界方面，FP 任务依赖 ROUGE 和 BERTScore 等 NLP 指标，这些指标衡量的是词汇重叠和语义相似度，而非生物学功能的精确性，存在代理偏差。EP 任务使用精确匹配准确率，虽客观但忽略了部分正确的酶命名。代码已开源，但论文未报告不同 GPU 配置下的训练效率对比，且 OOD 泛化测试仅基于时间切片（2024_01 版本），未涵盖结构拓扑差异巨大的远缘蛋白。

## 关联研究分析

从问题动机看，STELLA 与 Prot2Text 的核心差异在于模态融合策略。Prot2Text 采用 ESM-2 和 GPT-2 的分离式编码器-解码器架构，依赖复杂的对齐损失来弥合序列与文本的语义鸿沟。STELLA 则利用 ESM3 的内部统一编码特性，将融合负担转移至预训练阶段，仅保留线性投影作为接口。这一差异的根源在于 ESM3 预训练目标中已包含结构模态，使得其输出表征天然具备“结构感知”属性，而 Prot2Text 使用的 ESM-2 仅基于序列预训练，缺乏原子级几何信息，必须依赖外部结构编码器。STELLA 的简化架构是否在所有结构复杂度下都优于 Prot2Text 的复杂融合，论文未提供针对极端结构（如无序蛋白）的对比实验。

从方法设计看，STELLA 与 SaProt 代表了结构感知 PLM 的两种应用路径。SaProt 将结构 token 与序列 token 混合输入 ESM 架构，主要用于下游分类或检索任务，其输出是固定维度的向量。STELLA 则将 ESM3 的输出作为 LLM 的上下文输入，旨在生成自由文本。这一差异源于任务目标的根本不同：SaProt 追求判别性表征，STELLA 追求生成性推理。STELLA 引入 Llama-3.1-8B 作为骨干，虽然增强了生成能力，但也引入了 LLM 固有的幻觉风险。在酶反应预测中，STELLA 的准确率提升微弱（0.35%），这可能暗示酶命名任务已接近饱和，或者 LLM 的生化知识并未被充分利用，线性投影层是否足以传递 ESM3 中复杂的几何特征以支持精细的催化特异性区分，仍是一个值得探讨的技术细节。

## 总结

STELLA 旨在解决结构数据丰富但功能注释滞后的矛盾，其切入点在于利用 ESM3 的统一编码能力消除分离式多模态架构的冗余融合开销。通过“ESM3 + 线性投影 + Llama-3.1-8B”的两阶段指令微调框架，STELLA 在酶反应预测上达到 88.85% 准确率，并在结构退化场景下展现出优于 Prot2Text 的鲁棒性。然而，其功能描述生成仍依赖 NLP 代理指标，且对分布外结构的泛化能力受限于训练数据的时序覆盖。当面对结构拓扑与训练集差异巨大的远缘蛋白时，线性投影层能否有效传递 ESM3 中的几何细节以支持准确的功能推理，论文未给出明确回答。
