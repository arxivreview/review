# ACL-Findings2026最新论文 ｜Memory as Action: Autonomous Context Curation for Long-Horizon Agentic Tasks ｜记忆即动作：长时程智能体任务的自主上下文策展

研究机构：北京交通大学

作者：Yuxiang Zhang、Jiangming Shu、Ye Ma 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.12635)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.12635)

> 长时程智能体任务中，固定上下文窗口随交互累积导致注意力稀释与关键信号丢失，现有外部记忆管理模块因与推理策略解耦而无法联合优化信息保留与任务性能。MemAct 将工作记忆管理重构为策略空间内的可学习动作，通过端到端强化学习实现上下文编辑与任务执行的统一优化。该框架引入动态上下文策略优化算法解决非连续轨迹的训练不匹配问题，使14B模型在保持高准确率的同时将平均上下文长度压缩51%。其价值在于证明了记忆管理作为内生策略的可行性，但实验局限于单任务长时程场景，跨会话泛化能力未经验证。

## 研究背景

长时程智能体任务要求模型在数十步交互中维持推理连贯性，其工作记忆由输入上下文序列实现。当上下文未受管理时，无关信息饱和触发注意力稀释，导致“中间迷失”现象——关键信号被埋没于冗余历史中。这一困境并非单纯容量不足，而是如何在非平稳交互中动态策展上下文内容，使最相关证据在正确时刻可访问。

现有方案分为两条路线：一条将上下文视为受限资源，采用令牌压缩、选择性剪枝或周期性摘要等启发式规则，计算高效但缺乏对智能体推理状态的感知，易丢失语义关键依赖；另一条将记忆操作委托给外部控制器，管理结构化形成、演化与检索，但解耦架构阻碍了信息保留与下游任务性能的联合优化。近期工作尝试用强化学习内化记忆能力，但通常施加刚性约束，如每步强制压缩或粗粒度检索，将上下文视为单体缓冲区。MemAct 的切入点在于将工作记忆管理形式化为细粒度、可寻址的编辑动作，纳入统一策略空间，使智能体能执行与推理需求对齐的选择性、手术式操作。

## 核心方法

### 方法参照系

本文问题归属记忆学习优化路线，但关键差异在于：传统方法将记忆管理作为独立模块或固定流水线，而 MemAct 将记忆编辑直接嵌入任务动作空间，实现策略级统一优化。

### 统一策略空间与 Prune&Write 算子

传统外部控制器通过启发式触发器独立管理上下文，无法感知推理状态。MemAct 将记忆操作定义为策略动作，扩展动作空间为 $A = A_{task} \cup A_{mem}$，其中记忆动作形式为 $a_{mem} = (I_{target}, c)$，$I_{target}$ 为待删除记录的唯一标识符集合，$c$ 为生成的记忆内容。该设计解决了启发式规则无法适配动态推理状态的失效：智能体自主决定何时、如何编辑，使上下文策展与任务执行在单一策略 $\pi_\theta$ 下联合优化。

### 动态上下文策略优化 (DCPO)

因果语言模型假设单调上下文增长，但 Prune&Write 引入非连续轨迹 $H_{t+1} \not\supseteq H_t$，导致训练-推理不匹配：已删除内容仍影响后续令牌表示，朴素反向传播产生偏置信用分配。DCPO 在每次记忆编辑点逻辑分割轨迹为独立段 $\sigma_i = (C_i, \mathbf{y}_i)$，其中 $C_i$ 为段起始固定上下文前缀，$\mathbf{y}_i$ 为后续令牌序列。段内上下文前缀固定，局部顺序依赖成立。策略优化目标为：

$$
\mathcal{L}(\theta) = -\mathbb{E}_{u \sim \mathcal{D}, \tau \sim \pi_\theta} \left[ \frac{1}{|\Sigma(\tau)|} \sum_{\sigma \in \Sigma(\tau)} J_{clip}(\sigma, A(\tau)) \right]
$$

其中 $A(\tau)$ 为轨迹级优势，采用组相对归一化计算。该算法解决了动态上下文更新中梯度计算对历史不匹配状态的依赖，使策略能在标准强化学习基础设施上端到端优化，无需定制修改。

## 实验评估

实验基于 HotpotQA 构建多目标 QA 数据集（最多8个目标，每级200样本），单目标任务涵盖 2WikiMultihopQA、Bamboogle、HotpotQA、MuSiQue、Frames 及 BrowseComp-Plus。基线覆盖全上下文（Qwen3-235B）、外部管理（Sliding Window、Summarization、A-MEM）及学习型智能体（MEM1、Tongyi-DeepResearch、Search-R1），但缺失 Mandol、MAGMA 等结构化图谱基线，因任务类型不同。

| 方法 | 单目标平均准确率 | 多目标平均准确率 | 平均令牌消耗 (×10⁴) |
|---|---|---|---|
| Qwen3-235B | 0.500 | 0.531 | 16.7 |
| Search-R1 (SFT+RL) | 0.535 | 0.514 | 19.3 |
| MEM1 (RL) | 0.424 | 0.435 | 5.0 |
| MemAct (SFT+RL) | 0.537 | 0.591 | 8.2 |
| A-MEM | 0.383 | 0.399 | 3.9 |

MemAct-RL-14B 多目标准确率 59.1% 领先 Qwen3-235B（53.1%）6 个百分点，同时令牌消耗降低 51%。消融显示，固定更新间隔（每5轮）的变体准确率为 58.2%，低于动态策略的 59.1%，验证了自适应编辑的必要性。7B 模型在8目标任务中记忆动作频率从2.8升至3.7，14B 模型呈现双峰分布，分离研究阶段与任务完成阶段，表明策略随模型容量自适应演化。

评估协议采用 LLM 评估器三遍共识，若任一遍失败则标记错误，但多数结果未报告置信区间。代码与数据集已开源，训练使用 NVIDIA H100 GPU，SFT 阶段6轮、批大小256，RL 阶段批大小128、学习率 $1 \times 10^{-6}$。

## 关联研究分析

从问题动机看，MemAct 与 MEM1 同属强化学习记忆动作路线，但 MEM1 采用固定步长压缩调度，将上下文视为单体缓冲区，而 MemAct 通过 ID 寻址实现细粒度编辑，解决了固定调度无法适配动态推理状态的失效。这一差异源于任务特性：MEM1 面向通用上下文压缩，MemAct 面向长时程推理中的选择性信息保留，前者追求计算效率，后者追求推理连贯性。

从方法设计看，MemAct 与 A-MEM 形成鲜明对比：A-MEM 采用启发式规则组织记忆网络，通过动态链接实现记忆演化，但缺乏对推理状态的感知；MemAct 通过强化学习学习策略，更自适应但训练成本高。A-MEM 在 LoCoMo 上准确率 39.9%，MemAct 在类似多跳任务上达 59.1%，差距源于前者无法联合优化信息保留与任务性能。然而，A-MEM 的模块化架构支持独立部署，MemAct 的统一策略优化是否牺牲了记忆模块的可解释性与模块化能力，论文未给出回答。

## 总结

MemAct 要解决的核心矛盾是长时程智能体任务中上下文策展与任务执行的解耦优化问题。现有外部记忆模块因与推理策略分离而无法联合优化，启发式规则缺乏状态感知，固定调度无法适配动态需求。MemAct 将记忆编辑纳入统一策略空间，通过 DCPO 解决非连续轨迹的训练不匹配，使14B模型在多目标任务上达59.1%准确率，同时平均上下文长度压缩51%。其边界在于实验局限于单任务长时程场景，未验证跨会话持久化能力；当支持集增大到多会话交互时，动态编辑策略的泛化性是否保持，论文未给出回答。
