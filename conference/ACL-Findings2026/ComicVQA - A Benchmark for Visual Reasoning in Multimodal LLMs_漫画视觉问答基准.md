# ACL-Findings2026最新论文 ｜ComicVQA: A Benchmark for Visual Reasoning in Multimodal LLMs ｜漫画视觉问答基准

研究机构：新加坡国立大学、捷克布拉格捷克理工大学

作者：Esther Gan、Hannah Brown、David Herel 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_c2baab84154c)

> 多模态大语言模型（MLLMs）在单图视觉问答中常依赖语言先验而非真实视觉接地，且缺乏对离散静态图像序列的时序推理能力。现有漫画基准往往将视觉感知与叙事逻辑纠缠，无法诊断模型失败源于感知缺陷还是推理断裂。本文构建ComicVQA，通过去除文本的缺失面板预测和面板排序双任务，解耦细粒度视觉接地与组合时序推理。该基准揭示了当前MLLMs在局部因果推理上的显著短板，但受限于自动分割噪声与单一分辨率设置，其诊断结论的普适性仍需进一步验证。

## 研究背景

当模型面对包含多个静态图像的叙事序列时，其核心挑战在于区分“看到了什么”与“理解了什么顺序”。这要求模型具备细粒度视觉接地（Visual Grounding）能力，即从艺术风格、角色姿态等细微视觉线索中定位正确信息，同时需具备组合时序推理（Compositional Temporal Reasoning）能力，即整合跨面板的因果与状态变化以推断叙事流。传统VQA基准（如VQA, GQA）聚焦单图短文本答案，模型易利用语言相关性捷径，掩盖了其在复杂视觉场景中的感知盲区。

现有漫画理解数据集（如COMICS, StripCipher）多采用文本填空或混合模态问答，导致视觉感知错误与叙事理解错误相互混淆，难以定位具体失效环节。主流MLLMs在单图任务上表现优异，但在需要跨图像整合信息的序列任务中性能骤降，且缺乏针对“纯视觉”与“纯时序”能力的独立诊断工具。本文切入点在于构建一个受控的诊断基准，通过任务设计强制模型在特定维度上暴露能力边界，从而区分感知接地失败与时序推理失败。

## 核心方法

### 诊断性双任务架构

本文问题属于多模态序列推理评估，但区别于通用VQA流程，其核心差异在于通过任务解耦实现能力诊断。标准VQA流程中，模型直接输出文本答案，无法区分错误来源。本文设计两个互补任务：缺失面板预测（Missing Panel Prediction）作为感知层测试，面板排序（Panel Sorting）作为推理层测试。这种层级结构允许研究者通过对比模型在两个任务上的表现，定位失败是源于底层视觉判别不足，还是高层叙事整合断裂。

### 视觉接地隔离机制

在缺失面板预测任务中，通常做法是保留面板文本以辅助定位，但本文移除所有对话与叙述文本，并引入文本歧义干扰项。设计动机在于消除语言先验对视觉感知的干扰，迫使模型仅依赖艺术风格、角色外观等纯视觉线索。干扰项通过GPT-4o-mini生成描述，利用text-embedding-3-large计算余弦相似度，选取与正确面板文本描述最相似的三个面板作为选项：

$$
\text{Distractors} = \text{TopK}_{k=3} \left( \cos(\mathbf{e}_{\text{correct}}, \mathbf{e}_{\text{candidate}}) \right)
$$

其中 $\mathbf{e}$ 为文本嵌入向量。该机制确保语言推理不足以区分选项，从而量化模型在纯视觉接地上的真实能力。

### 受控时序推理消融

面板排序任务要求模型从四个乱序面板中识别正确叙事顺序。为诊断模型是缺乏局部感知还是全局推理，本文引入受控排序消融（Controlled Ordering Ablations）。设计动机在于将复杂的四面板排序分解为可测量的局部比较单元。通过引入相邻交换（Adjacent Swap）与全局交换（Global Swap）扰动，构建二元比较子任务：

$$
\text{Accuracy}_{\text{local}} = \frac{1}{N} \sum_{i=1}^{N} \mathbb{I} \left( \hat{\pi}(P_i, P_{i+1}) = \pi(P_i, P_{i+1}) \right)
$$

其中 $\hat{\pi}$ 为模型预测的相对顺序，$\pi$ 为真实顺序。该公式通过限制搜索空间至两个相邻面板，隔离出模型对局部时序连贯性的捕捉能力，进而与全局排序性能对比，揭示模型在细粒度因果推理上的具体缺陷。

## 实验评估

实验在ComicVQA测试集（每任务1000题）上进行，评估对象涵盖开源（InternVL-3.5, Qwen2.5-VL-7B等）与专有（GPT-4.1, Gemini-Flash-2.5等）MLLMs。基线覆盖主流指令微调模型，但缺乏针对漫画领域的专用微调模型，可能高估通用模型的短板。

| 模型 | 缺失面板预测 (%) | 面板排序 (%) |
| :--- | :--- | :--- |
| Human (5 annotators) | 83.4 | 88.0 |
| Random Baseline | 25.0 | 25.0 |
| InternVL-3.5 | 47.7 | 26.3 |
| GPT-4.1 | 58.5 | 36.1 |
| Gemini-Flash-2.5 | 58.5 | 46.4 |

主结果显示，专有模型在缺失面板预测上最高达62.6%（GPT-5.1），但仍落后人类20个百分点；面板排序任务中，最佳模型Gemini-Flash-2.5仅46.4%，接近随机基线，表明全局时序推理是当前MLLMs的显著瓶颈。

| 扰动类型 | 准确率 (%) |
| :--- | :--- |
| 相邻交换 (1↔2) | 63.7 |
| 相邻交换 (2↔3) | 69.0 |
| 相邻交换 (3↔4) | 69.3 |
| 全局交换 (1↔4) | 74.4 |

消融实验揭示反直觉现象：模型对全局端点交换（74.4%）的识别准确率显著高于相邻交换（平均67.3%）。这表明模型依赖粗粒度时序线索（如场景大幅变化），而非细粒度因果连贯性（如角色状态微调）。错误分类学进一步证实，因果推理错误（34%）与角色状态追踪错误（24%）是主要失败模式，而非视觉识别错误。

评估边界方面，数据集依赖自动面板分割，存在切割噪声；所有图像统一缩放至1024×1024，可能限制小模型性能；未报告计算效率指标。代码与数据已开源，但超参数细节仅在附录中简要提及，复现需依赖作者提供的脚本。

## 关联研究分析

从问题动机看，本文与ChartPoint等强调视觉接地的方法共享“消除语言捷径”的逻辑，但对象从数值图表转向叙事漫画。ChartPoint通过坐标提示约束搜索空间以解决数值幻觉，而ComicVQA通过移除文本和引入歧义干扰项来隔离视觉感知。差异根源在于任务特性：图表中的数值具有唯一性，坐标提示可直接定位；而漫画中的视觉线索（如风格、姿态）具有多义性，无法通过单一坐标提示解决，必须依赖全局上下文消歧。这提示视觉接地在结构化数据与非结构化叙事中的实现机制存在本质差异。

从方法设计看，本文与Chart-RL等强化学习框架形成互补。Chart-RL通过可验证奖励（RLVR）提升推理可靠性，侧重于“如何训练模型做对”；ComicVQA侧重于“如何诊断模型做错的原因”。Chart-RL的奖励信号依赖最终答案的正确性，无法区分感知错误与推理错误；而ComicVQA的双任务设计提供了过程性诊断。这种差异源于评估目标的不同：前者追求性能提升，后者追求能力归因。然而，ComicVQA未提供基于诊断结果的训练策略，仅停留在评估层面，其诊断结论能否直接指导模型改进，论文未给出回答。

## 总结

本文核心矛盾在于MLLMs在序列视觉推理中无法区分感知缺陷与推理缺陷。现有基准因模态纠缠无法定位失效环节，本文通过解耦双任务与受控消融，实现了能力维度的独立诊断。实验证明，当前模型在细粒度因果推理上存在显著短板，全局排序准确率仅46.4%，远低于人类水平。本文边界在于依赖自动分割的噪声数据与单一分辨率设置，且未探索诊断结果对模型训练的反馈机制。当面板数量从4增加到6或8时，模型在局部时序推理上的优势是否会被全局复杂度抵消，论文未给出回答。
