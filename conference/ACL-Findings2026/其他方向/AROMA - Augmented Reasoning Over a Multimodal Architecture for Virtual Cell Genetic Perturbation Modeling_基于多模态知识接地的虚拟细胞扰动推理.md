作者：Zhenyu Wang、Geyan Ye、Wei Liu 等 4 人

> 单细胞扰动建模的核心困境在于，现有生成式模型虽能拟合分布，却缺乏对基因调控因果链的显式解释，导致预测结果难以用于生物学假设验证。通用大语言模型（LLM）虽具备推理能力，但其自由文本生成缺乏生物拓扑约束，且检索机制未对齐调控方向性。AROMA 通过构建基因与通路知识图谱，结合图神经网络（GNN）与蛋白序列编码，将结构化证据注入 LLM 推理过程，实现了预测精度与机制可解释性的统一。该方法在未见细胞系上展现出鲁棒的零样本泛化能力，但其评估局限于离散分类任务，未与连续分布预测模型进行数值精度对标。

## 研究背景

单细胞扰动预测要求模型在给定细胞系、扰动基因与靶基因三元组时，输出靶基因的表达变化标签。这一任务面临的核心挑战是扰动效应的上下文依赖性与多步级联传播特性。由于 RNA-seq 数据的破坏性，扰动前后细胞无法配对，传统监督学习失效，必须依赖分布建模或生成式方法。然而，当前主流生成式模型（如扩散模型、流匹配）主要优化分布保真度，输出为黑盒数值，无法提供“为何该基因被上调”的生物学解释，限制了其在干预分析中的应用。

领域内 LLM 推理路线试图弥补这一空白，但存在显著缺陷。通用 LLM 缺乏生物约束，易产生幻觉；领域微调模型（如 SynthPert）依赖合成轨迹，继承监督噪声；检索增强生成（RAG）方法虽引入外部知识，但检索基于文本相似度，未建模基因间的拓扑方向性与多步传播路径。AROMA 的切入点在于将检索从松散文本匹配升级为基于知识图谱（KG）的拓扑路径提取，并引入多模态特征（GNN 结构嵌入与 ESM-2 序列嵌入）显式建模扰动-靶点依赖，从而在提供可解释推理的同时提升预测可靠性。

## 核心方法

### 方法参照系

AROMA 属于 LLM 智能体推理路线，其基础流程为：输入查询 → 检索外部证据 → LLM 生成推理与预测。与标准 RAG 框架的关键差异在于，AROMA 将检索源从纯文本库替换为结构化知识图谱，并在 LLM 输入中注入多模态交互特征，而非仅依赖文本提示。

### 拓扑接地检索与多模态交互编码

标准 RAG 通过文本相似度检索证据，无法捕捉基因调控的方向性。AROMA 构建基因知识图谱（Gene-KG）与通路知识图谱（Path-KG），利用广度优先搜索（BFS）提取扰动基因 $g_p$ 到靶基因 $g_t$ 的最短路径作为结构化证据。同时，为弥补文本证据在分子机制层面的缺失，AROMA 引入多模态编码。GNN 编码器在 KG 上预训练，提取 $k$-hop 子图的结构表示；ESM-2 编码器提取蛋白序列表示。通过交叉注意力机制显式建模扰动-靶点依赖：

$$
\text{Attn}(Q_{m,p}, K_{m,t}, V_{m,t}) = \text{softmax}\left(\frac{Q_{m,p} K_{m,t}^T}{\sqrt{d_k}}\right) V_{m,t}
$$

其中 $m \in \{\text{gene}, \text{path}, \text{protein}\}$，$Q_{m,p}$ 为扰动基因查询，$K_{m,t}, V_{m,t}$ 为靶基因键值。该设计将拓扑结构与分子序列信息融合为交互特征，注入 LLM 输入，使预测基于显式的生物机制而非纯文本关联。

### 两阶段优化策略

仅 SFT 无法充分优化推理质量。AROMA 采用两阶段训练：第一阶段多模态 SFT 对齐模态信息；第二阶段组相对策略优化（GRPO）强化学习。GRPO 通过采样多条推理轨迹，基于任务准确率与格式合规性计算奖励，优化策略以生成更一致、可解释的推理路径。奖励函数定义为：正确预测得 5.0 分，错误得 -1.0 分，格式合规额外加 0.5 分，答案唯一性加 0.5 分。该策略利用任务级反馈引导 LLM 在推理过程中自我校正，提升预测稳定性。

## 实验评估

实验基于 PerturbQA 数据集，涵盖 K562、HepG2、Jurkat 训练集与 RPE1 零样本测试集。基线覆盖通用 LLM（GPT-5、Gemini-2.5-pro）、领域基础模型（scGPT、STATE）及专用推理模型（SynthPert）。缺失生成式扩散/流匹配模型（如 scDFM）作为数值精度直接对比基线。

| 模型 | K562 Avg F1 | HepG2 Avg F1 | Jurkat Avg F1 | RPE1 (Zero-shot) Avg F1 |
| :--- | :--- | :--- | :--- | :--- |
| GPT-5 | 0.37 | 0.33 | 0.32 | 0.34 |
| SynthPert | 0.45 | 0.42 | 0.43 | 0.43 |
| scGPT | 0.52 | 0.49 | 0.50 | 0.51 |
| AROMA | 0.66 | 0.65 | 0.69 | 0.73 |

AROMA 在 RPE1 零样本设置下 Avg F1 达 0.73，显著优于 scGPT 的 0.51 与 SynthPert 的 0.43，显示其跨分布泛化能力。消融实验表明，移除 GNN 或 ESM-2 编码器均导致性能下降，验证多模态互补性；GRPO 阶段较纯 SFT 提升 K562 Up 类 F1 从 0.59 至 0.63。

评估指标仅采用 Macro-F1，未包含分布距离（如 E-distance）或基因级 Pearson 相关系数，无法评估连续表达值的预测精度。代码与模型权重已开源，但 GPU 资源需求未详细报告。

## 关联研究分析

从检索机制看，AROMA 与 SUMMER 同属 RAG 框架，但 SUMMER 依赖文本相似度检索，易引入无关功能描述；AROMA 基于 Path-KG 的 BFS 路径提取，确保证据与调控拓扑对齐。这一差异源于任务特性：基因扰动预测需捕捉方向性级联效应，文本相似度无法建模此结构。然而，BFS 路径长度限制为 3 跳，是否足以覆盖长程调控网络，论文未提供消融验证。

从多模态融合看，AROMA 与 scGPT 等基础模型不同，后者仅学习通用细胞嵌入，掩盖扰动特异性信号。AROMA 通过 GNN/ESM-2 显式注入扰动-靶点交互特征，但 ESM-2 为冻结编码器，未针对扰动任务微调。这导致其分子特征可能未充分适配特定细胞系上下文。相比之下，scPPDM 等生成式模型通过潜空间动态建模剂量效应，但缺乏解释性。AROMA 的多模态特征是否真正提升了因果推理，还是仅作为特征增强，需通过干预实验验证。

## 总结

AROMA 解决了 LLM 扰动推理中缺乏结构化生物证据与可解释性的矛盾，通过 KG 拓扑检索与多模态交互编码，在 RPE1 零样本设置下实现 0.73 的 Avg F1，优于 scGPT 的 0.51。其边界在于评估局限于离散分类任务，未与连续分布预测模型进行数值精度对标，且 BFS 路径长度限制可能遗漏长程调控。当支持集增大或路径长度扩展时，拓扑接地检索的边际收益是否递减，论文未给出回答。
