# ACL-Findings2026最新论文 ｜Accelerating LLM Fine-Tuning via Embedding Knowledge Transfer ｜嵌入层知识迁移加速大模型微调

研究机构：香港科技大学、澳门大学

作者：Meishu Peng、Ziyue Zhang、Yi Zhang 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_96dc596b9a16)

> 参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）旨在以极小参数预算适应下游任务，但现有方法如 LoRA 仅更新 Transformer 块权重，忽略了嵌入层对领域特定语义的编码作用，导致收敛缓慢且无法利用已有小模型专家知识。本文切入点在于通过异构模型间的嵌入层维度扩展与加权融合，将小专家模型的知识直接注入大目标模型，规避了伪标签生成的显存与时间开销。具体做法是构建词汇对齐后的嵌入矩阵，通过隐藏层维度扩展和加权融合实现参数迁移，再结合双阶段微调加速收敛。该方法在代码和数学任务上显著加速了收敛并提升了最终性能，但其通用性受限于同模型族内的架构一致性，跨架构迁移能力存疑。

## 研究背景

当大语言模型（Large Language Models, LLMs）适配特定领域时，全参数微调面临算力瓶颈，而 LoRA 等 PEFT 方法虽降低了训练成本，却因冻结嵌入层而难以捕捉领域特有的 Token 语义，导致在代码或数学等专业任务上收敛速度受限。这种局限催生了 Weak-to-Strong 范式，即利用小模型指导大模型，但现有方法依赖伪标签生成，需同时加载大小模型进行推理，造成显存碎片化和计算延迟。

PEFT 领域的主流路线聚焦于权重更新子空间的结构化约束，如低秩分解或张量分解，以平衡效率与表达力。然而，这些方法假设知识来源于模型内部预训练权重，未考虑外部专家模型中已编码的领域知识。Weak-to-Strong 范式虽引入了外部知识源，但伪标签机制引入了额外的推理开销，且标签噪声可能放大模型偏差。本文的切入点在于直接迁移嵌入层参数，将小模型的知识以参数形式而非数据形式注入大模型，从而在保持 PEFT 低开销特性的同时，利用专家模型的领域语义加速大模型收敛。

## 核心方法

### 方法参照系

本文问题可置于 Weak-to-Strong 微调框架下，但与传统伪标签监督的关键差异在于知识传递媒介：传统方法通过小模型生成的文本标签监督大模型，本文则通过嵌入矩阵的直接参数融合实现知识迁移，避免了推理阶段的显存占用。

### 嵌入层维度扩展与对齐

传统模型合并方法要求源模型与目标模型架构完全一致，而本文通过隐藏层维度扩展解决异构模型间的参数尺寸不匹配问题。设计动机在于，小模型嵌入矩阵 $E_S \in \mathbb{R}^{k \times d_S}$ 与目标模型 $E_T \in \mathbb{R}^{k \times d_T}$ 的维度差异（$d_S < d_T$）阻碍了直接参数转移，而随机初始化缺失维度会导致知识丢失。本文采用基于均匀采样的维度复制策略，将小模型嵌入扩展至目标维度：

$$
E^2_S(\cdot, i) = c(i) E^1_S(\cdot, f(i))
$$

其中 $f(i)$ 将目标索引映射到源索引，$c(i)$ 为归一化系数，确保复制维度的相对尺度保持一致。这一设计保留了小模型嵌入的几何结构，避免了随机初始化带来的语义噪声，为后续融合提供了高质量的知识基底。

### 加权嵌入融合与双阶段微调

在维度对齐后，本文通过加权融合整合小模型领域知识与大模型通用表示。设计动机在于，直接替换嵌入层会破坏大模型的预训练知识，而简单平均可能稀释领域特异性。本文提出融合公式：

$$
\hat{E}_T = \alpha E^2_S + (1 - \alpha) E^1_T
$$

其中 $\alpha = 0.5$ 为经验最优融合比，平衡了专家知识与通用表示的贡献。随后，双阶段微调策略先可选地预热嵌入层以捕获领域语义，再结合 LoRA 进行领域感知微调。这一流程确保了嵌入层在微调初期已具备领域特异性，从而加速收敛，同时 LoRA 的低秩约束限制了主干权重的变化，防止灾难性遗忘。

## 实验评估

实验在 Llama2-13B-Base 上进行，对比基线包括 Vanilla Model、Instruction-tuned、LoRA、Weak2Strong 和 ProxyTuning。基线覆盖伪标签监督路线，但缺失 DoRA、QLoRA 等主流 PEFT 变体对比，限制了与最新 PEFT 方法的直接比较。

| 方法 | HumanEval (pass@1) | MATH (Level-5) | MMLU |
| --- | --- | --- | --- |
| Vanilla Model | 15.9 | 1.9 | 55.7 |
| Vanilla Model + LoRA | 16.9 | 2.3 | 55.0 |
| Vanilla Model + LoRA + Weak2Strong | 18.1 | 1.8 | 55.7 |
| Vanilla Model + LoRA + ProxyTuning | 18.9 | 1.9 | 55.6 |
| Vanilla Model + LoRA + Pen2Sword | 19.9 | 2.6 | 54.7 |

Pen2Sword 在 HumanEval 上达到 19.9，较 LoRA 提升 17.7%，在 MATH 上达到 2.6，较 LoRA 提升 36.8%，验证了嵌入层迁移在专业任务上的有效性。

| 变体 | ROUGE-1 | ROUGE-2 | ROUGE-L |
| --- | --- | --- | --- |
| Pen2Sword | 0.745 | 0.479 | 0.653 |
| w/o DPF Selection | 0.737 | 0.471 | 0.643 |
| w/o Expansion | 0.394 | 0.138 | 0.292 |
| w/o Fusion | 0.693 | 0.395 | 0.577 |
| w/o Embedding Training | 0.743 | 0.476 | 0.649 |

消融实验显示，移除隐藏层维度扩展导致 ROUGE-L 从 0.653 骤降至 0.292，表明维度对齐是知识迁移的关键；移除加权融合使 ROUGE-L 降至 0.577，证实融合策略对整合异构知识的重要性。DPF 选择移除仅导致轻微下降，说明专家模型选择对最终性能影响有限。

评估协议基于 HELM 框架，使用 ROUGE 指标监控收敛，最终报告 HumanEval、MATH 和 MMLU 准确率。代码和超参数已公开，但实验仅在 Llama2 系列模型上验证，未覆盖 Vicuna 或 Baichuan 等异构架构的完整对比，限制了通用性结论。

## 关联研究分析

从问题动机看，Pen2Sword 与 ProxyTuning 均旨在利用小模型加速大模型适配，但 ProxyTuning 依赖伪标签生成，需额外推理开销，而 Pen2Sword 通过参数直接迁移规避了这一瓶颈。这一差异源于对知识传递媒介的选择：伪标签是数据形式，嵌入参数是权重形式。Pen2Sword 的优势在于避免了标签噪声和推理延迟，但其有效性依赖于小模型嵌入与大模型嵌入的语义对齐，这在跨架构模型中可能失效。

从方法设计看，Pen2Sword 借鉴了 Model Merging 的权重融合思想，但突破了同架构限制，通过维度扩展实现异构嵌入融合。与 LoRA 相比，Pen2Sword 额外更新了嵌入层，弥补了 LoRA 忽略嵌入层的缺陷，但这也引入了维度扩展的超参数敏感性。当小模型与大模型词汇表差异极大时，词汇对齐的随机初始化可能引入噪声，论文未探讨这一边界条件下的鲁棒性。

## 总结

Pen2Sword 解决了 PEFT 方法忽略嵌入层领域语义导致的收敛缓慢问题，通过异构模型间的嵌入层维度扩展与加权融合，将小专家模型的知识直接注入大目标模型，规避了伪标签生成的计算开销。实验证明，该方法在代码任务上将 HumanEval 准确率从 16.9 提升至 19.9，在数学任务上将 MATH 准确率从 2.3 提升至 2.6，同时收敛步数减少 90%。其边界在于实验仅在 Llama2 系列同架构模型上验证，未覆盖跨架构迁移场景，且维度扩展的超参数 $\alpha$ 依赖经验选择，缺乏理论指导。当小模型与大模型的词汇表差异超过一定阈值时，随机初始化的缺失维度是否会导致知识迁移失效，论文未给出回答。
