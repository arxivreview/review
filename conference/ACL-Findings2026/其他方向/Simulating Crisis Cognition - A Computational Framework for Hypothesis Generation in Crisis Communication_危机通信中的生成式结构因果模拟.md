# ACL-Findings2026最新论文 ｜Simulating Crisis Cognition: A Computational Framework for Hypothesis Generation in Crisis Communication ｜危机通信中的生成式结构因果模拟

作者：Changsen Yuan、Yanghao Zhou、Chong Feng 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_6b2448378c9a)

> 生成式社会模拟长期停留在对恐慌或谣言传播等宏观现象的定性描述，缺乏对具体干预策略因果效应的定量评估，导致政策制定者在无法开展随机对照试验的高风险场景中缺乏科学依据。现有基于检索增强生成（RAG）或规则启发式的系统往往忽视急性压力下的心理语言接受度，无法区分信息内容本身与呈现顺序对个体行为的不同影响。本文提出 CRISIS COGNITION 框架，将大语言模型（Large Language Model, LLM）重构为反事实实验室，通过生成式结构因果模型（Generative Structural Causal Model, Generative SCM）形式化危机交互，利用分层分析隔离人格混杂变量，以估计语言策略的个体处理效应。该框架在计算层面验证了“情感支架先于事实信息”的处方性假设，但其结论局限于 LLM 内部生成过程，能否外推至真实人类行为仍存疑。

## 研究背景

当决策者面对飓风等突发危机时，无法通过随机对照试验（Randomized Controlled Trial, RCT）验证“共情式信息”是否优于“权威式信息”，这种“反事实缺口”迫使系统依赖规则启发式或标准检索增强生成（Retrieval-Augmented Generation, RAG）。这些基线方法优先保证事实准确性，却忽视了经典压力评估理论所强调的急性应激下的心理语言接受度，导致信息虽完整却无法被处于恐慌中的个体有效处理。

生成式多智能体社会模拟利用 LLM 构建高保真人工社会，旨在突破传统基于智能体模型（Agent-Based Modeling, ABM）在语义丰富性与适应性上的局限。早期研究以定性涌现为核心，确立了 LLM 作为社会模拟底座的范式，但主要关注宏观现象的描述性复现，缺乏定量验证标准。随着研究深入，领域重心转向科学验证与机制解释，引入耦合增益等定量诊断工具以区分真实社会动力学与模型伪影。然而，现有验证评估路线多聚焦于宏观统计轨迹匹配或鲁棒性审计，尚未建立针对特定干预策略的因果识别框架，无法回答“何种信息序列能恢复个体行动力”这一处方性问题。

本文的切入点在于将危机通信模拟从描述性模仿转向处方性估计。通过引入 Pearl 的 do-calculus，将 LLM 模拟视为一个输入完全可控的反事实环境，从而在计算层面实现因果效应的可识别性。这一转变不仅继承了生成式智能体的语义优势，更通过形式化因果结构，为高风险场景下的策略评估提供了可证伪的计算假设。

## 核心方法

### 生成式结构因果形式化

本文解决的问题若无公认标准流程，则将其置于因果推断的通用框架下描述，关键差异在于利用 LLM 模拟实现“设计上的可识别性”。传统观察性数据中混杂变量往往不可观测，而在 LLM 模拟中，智能体人格 $U$ 与环境 $E$ 均为显式输入，完全由实验者控制。

$$
M = \langle U, E, T, Y \rangle
$$

该公式定义了生成式 SCM，其中 $U$ 为智能体人格，$E$ 为环境，$T$ 为干预（语言策略），$Y$ 为结果。由于 $T$ 独立于 $U$ 随机分配（$T \perp U$），后门准则在设计上得到满足，使得 $P(Y | do(T))$ 可直接识别，无需依赖线性回归假设。这一设计动机解决了传统回归分析在非线性人格-焦虑关系下的混杂偏差问题，确保了因果效应的纯净估计。

### 分层分析与认知带宽量化

在 SCM 框架下，本文进一步引入分层分析以观察异质性处理效应，并通过链式思维（Chain-of-Thought, CoT）解析量化认知机制。

$$
B = \frac{\text{Planning Tokens}}{\text{Threat-Appraisal Tokens}}
$$

认知带宽 $B$ 定义为 CoT 轨迹中规划令牌与威胁评估令牌之比，高 $B$ 值表明执行功能恢复。设计动机在于，仅观察行为结果 $Y$ 无法区分“信息未被处理”与“信息被处理但无法执行”两种状态。通过解析中间认知状态 $C$，本文能够验证干预 $T$ 是否成功穿透智能体内部推理。同时，基于神经质（Neuroticism）得分将智能体分为高/低分层，计算各层内的平均处理效应（ATE），从而在不假设线性关系的前提下，揭示人格对干预效应的调节作用。

## 实验评估

实验基于 PSYCHOAGENT 数据集初始化 1,813 个智能体，使用历史飓风遥测数据构建环境 $E$，对比 RAG、SIMULTANEOUS（同时呈现情感与事实）与 SEQUENTIAL（先情感后事实）三种策略。基线审计显示，本文未对比 DeGroot 等经典动力学模型，而是聚焦于语言策略的因果效应，这与领域内常见的宏观涌现评估路线不同。

| 方法 | 策略 | GPT-4o (A/Y) | DeepSeek-V3 (A/Y) | Llama-3.1-70B (A/Y) |
| :--- | :--- | :--- | :--- | :--- |
| RAG | - | 5.75 ±1.2 / 0.75 ±0.4 | 7.75 ±0.9 / 0.46 ±0.3 | 6.43 ±1.1 / 0.69 ±0.5 |
| SIMULTANEOUS | - | 4.83 ±1.0 / 0.10 ±0.1 | 5.82 ±1.3 / 0.05 ±0.1 | 3.30 ±0.8 / 0.18 ±0.2 |
| SEQUENTIAL | - | 3.57 ±0.9 / 4.47 ±1.5 | 7.17 ±1.4 / 4.83 ±1.8 | 3.68 ±0.7 / 5.74 ±1.6 |

注：A 为行动密度（Action Density），Y 为焦虑分数（Anxiety Score）。

核心数字对比显示，SIMULTANEOUS 策略在 Llama-3.1-70B 上实现了最低焦虑（Y = 3.30），但行动密度崩塌至 0.18，证实了“镇静效应”；而 SEQUENTIAL 策略在保持中等焦虑（Y = 3.68）的同时，将行动密度提升至 5.74。在高神经质分层中，SEQUENTIAL 策略相比 RAG 基线平均提升行动密度 412%，而在低神经质分层中仅提升约 85%，表明认知瓶颈具有人格依赖性。

消融实验通过“Rational CoT”基线（N = 1,500）验证了 SEQUENTIAL 策略的效能并非源于增加的推理延迟，而是源于情感支架对认知瓶颈的解锁。评估边界方面，自动化指标与人工标注的一致性较高（焦虑 r = 0.82，行动 r = 0.91），但论文未提供代码 URL，且未报告置信区间，限制了可复现性。此外，评估仅依赖 GPT-4o 作为盲审法官，缺乏跨模型评估的交叉验证。

## 关联研究分析

从问题动机看，本文与 TRAILS 鲁棒性审计形成互补。TRAILS 揭示了提示格式微小变化对宏观结果的巨大影响，确立了审计标准；而本文通过固定人格与环境，仅干预消息，实现了更严格的控制，将焦点从“系统鲁棒性”转向“干预因果效应”。这种差异源于任务特性：TRAILS 关注模拟本身的可靠性，本文关注模拟作为假设生成器的有效性。然而，本文未讨论当人格提示存在细微语义漂移时，412% 的行动力提升是否依然稳健，这暗示了因果效应对输入敏感性的潜在脆弱性。

从方法设计看，本文的 Cognitive Bandwidth 与 Coupling Gain 诊断类似，均旨在区分真实机制与模型伪影。Coupling Gain 测量 LLM 智能体的社会敏感性，区分真实社会动态与谄媚伪影；而 Cognitive Bandwidth 侧重心理机制，通过令牌比例量化执行功能恢复。两者均试图建立微观认知与宏观行为之间的可追溯因果链，但 Coupling Gain 更侧重于社会层面的稳定性，而本文更侧重于个体层面的认知瓶颈。这种差异反映了领域内从宏观统计一致性向微观机制解释的演进趋势，但本文未将 Cognitive Bandwidth 与 Coupling Gain 进行直接对比，也未验证其在不同社会拓扑下的泛化性。

## 总结

本文要解决的核心矛盾是高风险危机场景中缺乏可操作的处方性干预策略，现有方法因无法开展 RCT 而陷入描述性模仿的困境。本文抓住 LLM 模拟输入完全可控的特性，通过 Generative SCM 与 do-calculus 实现因果效应的可识别性，构建了 COPE-CF 反事实基准。实验证明，SEQUENTIAL 策略在高神经质智能体中显著提升行动密度（412%），并揭示了 SIMULTANEOUS 策略的“镇静效应”。本文的边界在于，其结论局限于 LLM 内部生成过程，且未验证跨文化或跨语言环境下的泛化性。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
