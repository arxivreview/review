# ACL-Findings2026最新论文 ｜DiffCL: Difference-Aware Contrastive Learning for Automatic Answer Grading with Multi-Level Semantic Modeling ｜差异感知对比学习自动答题评分

作者：Lei Chen、BoYu Gao、Zitao Liu 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_43de595b3a01)

> 自动答题评分（AAG）的核心难点在于模型难以区分学生答案与参考答案的细微语义偏差，导致评分尺度不稳定。现有大语言模型（LLM）评分方法往往依赖表面流畅度，对关键概念遗漏不敏感，且内部表示空间缺乏评分结构优化。本文切入点是将启发式生成的离散差异标签注入输入，并引入双对比学习机制以约束表示空间。该方法在 SciEntsBank 基准上超越了零样本 GPT-4.1，但在 Beetle 数据集上表现低于多智能体框架，其泛化边界尚存疑。

## 研究背景

短答案评分要求模型不仅判断对错，还需量化答案与参考标准的偏离程度。这种偏离涉及词汇覆盖、结构一致性及逻辑否定等维度，传统特征工程难以捕捉其深层语义关联。当使用 LLM 进行评分时，模型倾向于对完全正确或完全错误的答案给出中间分数，且对事实性错误不敏感，这源于其内部语义空间未针对评分差异进行专门优化。

AAG 领域已从浅层特征匹配演进至基于预训练模型的端到端评分。早期方法如 CoMeT 和 ETS 依赖手工特征，泛化能力弱；基于 BERT 的方法虽提升了语义理解，但主要采用全局向量回归，忽略了答案与参考之间的结构化差异。近期 LLM 评分研究（如 GPT-4.1 零样本）展示了潜力，但存在评分一致性差和对细微偏差感知不足的问题。现有对比学习方法多关注样本间相似度，而非答案与参考间的差异结构，无法直接捕获与分数变化相关的细粒度特征。

本文针对 LLM 评分中“对关键概念遗漏不敏感”和“评分尺度不稳定”两大痛点，提出差异感知对比学习框架。通过显式建模学生答案与参考答案的语义偏差，并引入对比学习约束表示空间的结构，旨在提升模型在多级别语义建模上的稳定性与区分度。

## 核心方法

### 方法参照系

标准 LLM 评分流程将问题、参考答案和学生答案输入编码器，通过线性分类头输出分数，训练目标仅为交叉熵损失。本文的关键差异在于：在输入端注入启发式生成的差异标签，并在损失函数中增加对比学习项，以显式建模分数间的距离结构。

### 差异标记生成机制

设计动机在于解决 LLM 对表面表达风格过度敏感、对关键概念遗漏不敏感的问题。通常做法是直接输入文本，本文则先计算 Jaccard 相似度、编辑距离相似度和否定词惩罚，生成离散差异标签 $[DIFF0]-[DIFF4]$。该标签作为结构化提示注入输入，引导模型关注内容级偏差。差异标签生成公式如下：

$$
\text{Diff} = \begin{cases}
[DIFF0] & \text{Sim} \ge 0.80 \\
[DIFF1] & 0.60 \le \text{Sim} < 0.80 \\
[DIFF2] & 0.35 \le \text{Sim} < 0.60 \\
[DIFF3] & 0.2 \le \text{Sim} < 0.35 \\
[DIFF4] & \text{Sim} \le 0.20
\end{cases}
$$

其中 $\text{Sim} = \text{Jaccard}(R, S) + \text{LevSim}(R, S)$，若存在否定词惩罚则直接降级为 $[DIFF4]$。这一设计将模糊的语义判断转化为明确的离散信号，增强了模型对关键错误的敏感度。

### 双对比学习框架

设计动机在于解决 LLM 内部表示空间缺乏评分结构优化、导致不同分数样本表示混乱的问题。通常做法仅使用交叉熵损失，本文引入 InfoNCE 损失和层级对比约束。InfoNCE 损失强制同分样本表示一致，层级约束显式建模分数间隔。总损失函数为：

$$
L = L_{ce} + \lambda (L_{nce} + L_{dist})
$$

其中 $L_{nce}$ 基于温度参数鼓励同分相似、异分相异，$L_{dist}$ 根据分数差值设定 margin：分数差 $\le 1$ 时拉近，$> 1$ 时保持距离。该机制构建了符合评分尺度的语义表示结构，提升了分类性能与表示稳定性。

## 实验评估

实验在 SciEntsBank 和 Beetle 数据集上进行，基线覆盖传统 ML（CoMeT, ETS）、深度学习（SFRN+）及 LLM 零样本（GPT-4.1）。SciEntsBank 包含未见答案（UA）、未见问题（UQ）和未见领域（UD）任务，Beetle 仅含 UA 和 UQ。

| 方法 | SciEntsBank UA ACC | SciEntsBank UQ ACC | Beetle UA ACC | Beetle UQ ACC |
| :--- | :--- | :--- | :--- | :--- |
| GPT-4.1 (Zero-shot) | 0.6340 | 0.6199 | 0.7242 | 0.6399 |
| SFRN+ | 0.6900 | 0.4700 | 0.7500 | 0.6000 |
| DiffCL (Qwen3-8B) | 0.7704 | 0.6565 | - | - |
| DiffCL (Qwen3-4B) | - | - | 0.7904 | 0.6691 |

在 SciEntsBank 上，DiffCL (Qwen3-8B) 的 UA ACC 达 0.7704，较 GPT-4.1 提升 4.1 个百分点；UQ ACC 为 0.6565，优于 SFRN+ 的 0.4700。在 Beetle 上，DiffCL (Qwen3-4B) 的 UA ACC 为 0.7904，UQ ACC 为 0.6691，均超过 GPT-4.1 和 SFRN+。

消融实验显示，对比学习损失显著提升了性能。以 Qwen3-0.6B 在 SciEntsBank UA 任务为例，仅用交叉熵（CE）时 ACC 为 0.7022，加入全部对比损失（ALL）后提升至 0.7292，Macro-F1 从 0.5367 升至 0.5793。这表明温度对比损失增强了同分一致性，而 margin 对比损失促进了不同分数级别的分离。

评估边界方面，论文未报告置信区间，且 Beetle 数据集缺少 UD 任务，限制了泛化性评估的全面性。代码已开源，超参数（学习率 $2.5 \times 10^{-5}$，5 epochs）明确，可复现性良好。

## 关联研究分析

从问题动机看，本文与 AutoSCORE 均关注 LLM 评分的准确性，但 AutoSCORE 采用多智能体框架实现评分标准对齐，侧重可解释性与鲁棒性；本文则通过单智能体加对比学习，侧重表示空间的结构优化。差异根源在于：AutoSCORE 试图通过架构分解解决评分逻辑的透明性，而本文认为 LLM 内部表示缺乏评分结构是主要瓶颈。在 Beetle 数据集上，AutoSCORE 的 Accuracy 达 0.90+，高于本文的 0.7904，暗示多智能体架构在复杂短答案场景下可能更具鲁棒性，但本文在 SciEntsBank 上的优势表明，对比学习在特定分布下能有效提升细粒度区分能力。

从方法设计看，本文与 SFRN+ 同属基于 Transformer 的评分方法，但 SFRN+ 采用纯监督学习，忽略答案与参考间的差异结构；本文引入差异标签和对比学习，显式建模语义偏差。SFRN+ 在 SciEntsBank UQ 任务上 ACC 仅 0.4700，远低于本文的 0.6565，证实了显式差异建模对跨问题泛化的重要性。然而，本文未探索差异标签在非英语或低资源语言中的有效性，而 SFT Latxa 70B 在巴斯克语上取得 0.92+ Accuracy，提示领域特定微调可能在低资源场景下更具优势。

## 总结

本文核心矛盾是 LLM 评分对细微语义偏差不敏感且评分尺度不稳定。切入点在于将启发式差异标签注入输入，并通过双对比学习约束表示空间结构，从而显式建模分数间隔。方法上，DiffCL 结合差异标记生成与 InfoNCE 及 margin 对比损失，在 SciEntsBank UA 任务上达到 0.7704 ACC，在 Beetle UA 任务上达到 0.7904 ACC。边界在于，Beetle 数据集上性能低于 AutoSCORE，且未验证差异标签在低资源或跨语言场景下的泛化能力。当支持集增大或任务分布变化时，启发式差异标签的边际收益是否递减，论文未给出回答。
