# ACL-Findings2026最新论文 ｜MENTOR: Mitigating Identity Drift in Dynamic Role-Playing via Dual-Chain Structured Memory ｜双链结构化记忆缓解动态角色扮演身份漂移

研究机构：中国科学院、中国科学院大学

作者：Zhu Zhuoning、Xingyu Gao、Hailong Shi

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_9465be4e47c6)

> 长程多用户交互中，大语言模型（LLM）常因上下文污染导致角色边界模糊，即身份漂移。现有检索增强生成（RAG）依赖语义相似度，无法区分角色归属，导致跨角色信息泄露。MENTOR 提出无参数双链记忆架构，通过物理隔离角色工作记忆与全局事件日志，并结合知识图谱验证信息可接受性，在高频切换场景下将平均得分从 0.46 提升至 0.75。该架构有效抑制了“伪对齐”现象，但其对静态单角色场景的适用性及门控阈值敏感性尚未充分验证。

## 研究背景

当 LLM 在单一会话中服务多个用户或角色时，其自注意力机制会将不同角色的历史指令与事实混合处理。这种混合导致模型在切换角色后，仍可能引用前一个角色的约束或隐私信息，形成身份漂移。为解决此问题，检索增强生成（RAG）被广泛用于扩展记忆容量，但标准 RAG 基于向量相似度检索，缺乏角色感知能力。例如，当两个角色分别讨论“苹果”（水果）与“苹果”（科技公司）时，语义检索会同时召回两者历史，造成上下文污染。

角色扮演智能体的核心挑战在于平衡角色保真度与通用能力，而长程交互中的身份漂移是主要障碍。早期方法如 Character-LLM 依赖微调内化角色知识，但难以应对动态切换；Generative Agents 引入记忆流，但未区分角色边界。现有评估基准多关注静态一致性，缺乏对高频切换下动态干扰的控制。MENTOR 的切入点在于指出“语义相关性不等于身份所有权”，主张通过结构化记忆隔离而非单纯增加上下文长度来解决漂移问题。

## 核心方法

### 方法参照系

本文问题属于记忆与状态管理路线，旨在解决长程身份漂移。标准流程为：接收输入 → 相似度检索历史 → 拼接上下文 → 生成响应。本文的关键差异在于摒弃扁平化检索，引入角色隔离机制与知识图谱验证，将记忆从“单一池”升级为“双链结构”。

### 双链记忆架构

设计动机：解决标准 RAG 中语义检索导致的跨角色信息泄露。MENTOR 将记忆分为全局链（Global Chain, G）与角色链（Role Chain, $R_r$）。全局链 $G$ 记录所有角色的事件日志，每个事件 $\xi_i$ 定义为：

$$ \xi_i = (\tau_i, u_i, y_i, r_i, T_i, \omega_i) $$

其中 $r_i$ 为活跃角色，$T_i$ 为提取的语义三元组，$\omega_i$ 为身份一致性置信度。角色链 $R_r$ 仅包含目标角色 $r_{target}$ 的递归摘要 $S_r$ 与最近 $k$ 轮缓冲 $B_r$。这种物理隔离防止 LLM 注意力分散到非目标角色的冲突 token 上，从源头消除泄露。

### 知识图谱门控验证

设计动机：解决角色链内部可能存在的语义冲突及幻觉问题。MENTOR 引入语义知识图谱 $K=(V, E)$ 作为认知仲裁器。在生成阶段，系统查询 $K$ 中锚定实体的子图 $K_{sub}$，并执行门控写回。验证器计算置信度 $\omega_t$，若 $\omega_t \ge \theta$，则更新 $G$ 与 $K$；否则触发安全回退，不持久化当前轮次。该机制确保只有符合角色约束且无矛盾的信息进入长期记忆，防止错误传播。

## 实验评估

实验在自建 BEAM-SWITCH 基准上进行，该基准包含可控切换强度（S=2,3,4）的对抗性多角色轨迹。基线包括 Naive RAG 与 MemoChat，覆盖检索与摘要两类记忆策略，但缺失微调类基线（如 Character-LLM）。

| 模型 | 方法 | IA | KF | CC | Avg |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Kimi-K2 | Baseline | 0.28 | 0.25 | 0.78 | 0.44 |
| Kimi-K2 | + MENTOR | 0.72 | 0.69 | 0.88 | 0.76 |
| Qwen3-30B | Baseline | 0.15 | 0.12 | 0.55 | 0.27 |
| Qwen3-30B | + MENTOR | 0.58 | 0.55 | 0.75 | 0.63 |

MENTOR 在长上下文模型（如 Kimi-K2）上表现尤为突出，Avg 从 0.44 提升至 0.76，显著优于 Naive RAG（0.53）与 MemoChat（0.62）。这表明结构化隔离比单纯增加上下文或摘要更有效。

| 设置 | IA | KF | CC | Avg |
| :--- | :--- | :--- | :--- | :--- |
| Full (MENTOR) | 0.58 | 0.55 | 0.75 | 0.63 |
| w/o Role Chain | 0.25 | 0.35 | 0.68 | 0.43 |
| w/o Knowledge Graph | 0.45 | 0.28 | 0.70 | 0.48 |

消融实验显示，移除角色链导致身份一致性（IA）从 0.58 骤降至 0.25，证实隔离是防止混淆的关键；移除知识图谱则主要影响知识保真度（KF），降至 0.28。注入 20% 干扰项后，KG 验证器仍能维持 KF，但 IA 显著下降，表明 KG 对事实冲突的鲁棒性高于对身份边界的保护。

评估指标包含 IA、KF、CC 三维，但缺乏对推理延迟与 Token 开销的量化报告。代码未公开，超参数（如门控阈值 $\theta$）未详细披露，限制了可复现性。

## 关联研究分析

从问题动机看，MENTOR 与 Generative Agents 均关注长程一致性，但前者聚焦多角色动态切换，后者侧重单角色自主行为。Generative Agents 的记忆流未区分角色归属，导致在复杂社交场景中易发生身份混淆；MENTOR 通过双链隔离解决了这一特定失效，但牺牲了单角色深度交互中的情感演化建模能力。

从方法设计看，MENTOR 与 RAG 的核心差异在于检索逻辑。RAG 依赖向量相似度，MENTOR 依赖角色所有权与 KG 验证。RAG 在静态单角色任务中可能更灵活，而 MENTOR 在高频切换中更稳定。然而，MENTOR 的无参数架构依赖高质量的角色档案与 KG 构建，对于低资源角色（缺乏详细背景数据）的适用性存疑，论文未提供此类场景的对比实验。

## 总结

MENTOR 针对多用户动态切换中的身份漂移问题，指出语义检索无法区分角色归属的缺陷，提出双链记忆与 KG 门控验证架构。实验表明，该架构在高频切换下将 Avg 从 0.46 提升至 0.75，有效抑制了“伪对齐”现象。其边界在于依赖预定义的角色档案与 KG，且未验证在静态单角色或低资源场景下的性能退化。当角色档案信息稀疏或 KG 构建不完整时，门控机制是否会导致过度拒绝或信息丢失，论文未给出回答。
