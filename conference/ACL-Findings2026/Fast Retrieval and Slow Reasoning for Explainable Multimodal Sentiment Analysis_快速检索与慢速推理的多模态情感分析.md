# ACL-Findings2026最新论文 ｜Fast Retrieval and Slow Reasoning for Explainable Multimodal Sentiment Analysis ｜快速检索与慢速推理的多模态情感分析

研究机构：合肥工业大学

作者：Aoqiang Zhu、Min Hu、Yan Xing

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_faa68de3ea41)

> 多模态情感分析（Multimodal Sentiment Analysis, MSA）旨在通过融合文本、音频和视觉信号预测情感极性，但现有全序列融合方法将冗余噪声与有效情感线索混合处理，导致模型对无关模式敏感且决策过程不透明。FRSR 借鉴双过程理论，将建模拆解为证据检索与结构化推理两个阶段，通过稀疏化输入降低计算开销并提升可解释性。该框架在三个基准上取得了有竞争力的性能，但其精度未超越基于大语言模型的最新方法，且 Top-K 稀疏化对长程依赖的影响尚存疑。

## 研究背景

情感线索往往出现在短暂的时序片段中，如突然的语气变化或短暂的面部表情，而长序列中充斥着大量无关的背景噪声。这种局部性与冗余性并存的特点，使得直接对全序列进行融合时，模型难以区分哪些特征真正承载了情感信息。为了解决这一筛选难题，双过程理论（Dual-Process Theory）提供了认知参照：System 1 负责快速捕捉显著的感知线索，System 2 则对选定的信息进行深入的语义分析。这种“先筛选后推理”的认知机制，为设计高效且可解释的多模态模型提供了架构灵感。

主流 MSA 方法如 MulT 和 DEVA 采用端到端的全序列融合策略，虽然能捕捉长程依赖，但将情感信号与冗余内容同等对待，导致模型容易过拟合于说话人习惯或环境噪声，且无法明确归因于哪些模态片段支持了最终预测。FRSR 的切入点在于打破这种“一视同仁”的融合范式，通过显式的稀疏检索机制，在推理前剔除低信息量的 token，从而在保持预测精度的同时，显著降低计算复杂度并增强决策的透明度。

## 核心方法

### 方法参照系

传统 MSA 流程将多模态特征直接输入 Transformer 进行全序列交叉注意力融合。FRSR 的关键差异在于引入前置的稀疏检索模块，将全序列处理转化为对 Top-K 关键片段的局部推理，从而解耦了特征选择与情感推断两个阶段。

### 快速显著性检索

全序列融合的主要失效点在于冗余信息干扰了情感信号的提取。FRSR 在编码后引入快速路径（Fast Pathway），利用轻量级 Conv1D 网络估计每个 token 的显著性分数，仅保留 Top-K 个高显著性片段。该模块还引入辅助单模态监督，确保检索出的片段本身具备情感判别力。显著性分数 $S_m$ 通过两层卷积计算，并经 Sigmoid 归一化：

$$ S_m = \text{Conv1D}_{k=1} \left( \text{ReLU} \left( \text{Conv1D}_{k=3}(X_m) \right) \right) $$

其中 $X_m$ 为模态 $m$ 的初始特征。随后，通过加权平均聚合 Top-K 片段得到快速路径表示 $h^{fast}_m$，并施加辅助损失以稳定检索过程。这一设计使得模型在推理前即过滤掉噪声，避免了全序列融合中无关模式对决策边界的扭曲。

### 慢速推理融合

快速路径输出的稀疏片段若仅做简单拼接，无法充分挖掘跨模态深层语义。FRSR 引入慢速路径（Slow Pathway），使用可学习的推理令牌（Reasoning Tokens）作为查询，对多层 Transformer 特征进行层级交叉注意力。推理令牌 $R^{(l)}$ 在第 $l$ 层通过残差连接更新：

$$ R^{(l)} = \text{CrossAttn} \left( \text{LN}(R^{(l-1)}), \text{LN}(H^{(l)}), \text{LN}(H^{(l)}) \right) + R^{(l-1)} $$

其中 $H^{(l)}$ 为第 $l$ 层的多模态表示。这种层级注意力机制允许推理令牌从低层局部上下文逐步累积至高层全局语义，最终通过均值池化生成预测。相比全序列融合，该机制将计算资源集中于高信息量片段，既提升了推理效率，又通过显式的令牌交互增强了跨模态依赖的可解释性。

## 实验评估

FRSR 在 MOSI、MOSEI 和 SIMS 三个基准上进行了评估，对比了 MulT、MISA、DEVA 等 15 种基线方法。基线覆盖了张量融合、子空间解耦和文本先验增强等主流路线，但未包含基于大语言模型（LLM）的最新方法，如 Emotion-LLaMAv2。

| 模型 | MOSI F1 | MOSI MAE | MOSEI F1 | MOSEI MAE |
| :--- | :--- | :--- | :--- | :--- |
| DEVA | 84.48 | 0.730 | 82.93 | 0.541 |
| FRSR | 85.22 | 0.661 | 84.35 | 0.510 |

FRSR 在 MOSI 上的 F1 达到 85.22%，MAE 降至 0.661，优于强基线 DEVA 的 84.48% 和 0.730。在 MOSEI 上，FRSR 的 F1 为 84.35%，MAE 为 0.510，同样领先于 DEVA。这些结果表明，稀疏检索与层级推理的结合有效提升了细粒度情感强度估计的准确性。

消融实验显示，移除快速路径（w/o FSR）导致 MOSI F1 从 85.22% 降至 84.26%，移除慢速路径（w/o SRF）则降至 84.50%。这表明两条路径均对性能有正向贡献，但快速路径对冗余过滤的作用更为关键。Top-K 敏感性分析发现，K=4 时性能最佳，K 值过大反而引入低显著性噪声，导致性能下降，验证了稀疏化的必要性。

评估协议方面，FRSR 报告了 Acc-2、F1、Acc-7、MAE 和 Corr 指标，覆盖了分类与回归任务。实验在 RTX A40 GPU 上进行，使用 BERT、librosa 和 OpenFace 提取特征。论文未提供代码链接，且未报告置信区间，数值比较需谨慎。此外，FRSR 未评估在模态缺失严重场景下的鲁棒性，仅通过单模态测试间接验证了部分鲁棒性。

## 关联研究分析

从问题动机看，FRSR 与 MISA 均关注模态异质性，但 MISA 通过子空间解耦分离共享与特有特征，而 FRSR 通过时序稀疏化剔除冗余片段。MISA 的解耦是静态的表示学习，FRSR 的检索是动态的输入筛选。这种差异源于 MISA 假设模态间存在稳定的语义结构，而 FRSR 假设情感线索在时序上是稀疏分布的。FRSR 的稀疏化策略在长序列中可能丢失长程依赖，而 MISA 的子空间解耦则可能保留过多噪声。

从方法设计看，FRSR 与 DEVA 都试图提升鲁棒性，但 DEVA 通过文本先验增强视觉和音频特征，属于特征增强路线；FRSR 通过稀疏检索减少输入维度，属于计算效率路线。DEVA 依赖文本模态的主导地位，而 FRSR 通过辅助单模态监督平衡各模态贡献。FRSR 在效率上显著优于 DEVA，每 epoch 训练时间从 17.143 秒降至 7.856 秒，但精度上未超越基于 LLM 的方法。这暗示，在计算资源受限的场景下，FRSR 的稀疏化策略更具部署价值，但在追求极致精度的场景中，LLM 的语义先验仍具优势。

## 总结

FRSR 旨在解决多模态情感分析中冗余信息干扰与决策不透明的矛盾，通过双过程架构将全序列融合拆解为稀疏检索与层级推理。该框架在 MOSI 上取得 85.22% F1 和 0.661 MAE，训练效率提升 2.18 倍，证明了稀疏化策略在平衡精度与效率上的有效性。然而，FRSR 的精度未超越基于 LLM 的最新方法，且 Top-K 稀疏化可能丢失长程依赖，论文未对此进行量化评估。当序列长度进一步增加时，稀疏检索能否有效保留关键长程情感线索，仍是待验证的问题。
