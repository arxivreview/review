# ACL-Findings2026最新论文 ｜Trident: Self-Supervised Preference Alignment via Triplet Regularization ｜三元组正则化自监督偏好对齐

研究机构：浙江大学、上海交通大学

作者：Yingnan Guo、Kejia Chen、Xiaofeng Zhang 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_2c896ca5aa0e)

> 多模态大语言模型在自监督场景下难以获取高质量偏好数据，标准直接偏好优化（Direct Preference Optimization, DPO）因自动生成的“优选”响应未必优于“劣选”响应而陷入监督噪声。Trident 通过引入中性锚点将二元偏好扩展为三元组结构，并设计自适应边际正则化目标，在无外部反馈条件下实现了对幻觉的有效抑制。该方法以极少的自生成数据达到了与依赖大规模人工标注或强模型反馈的方法相当的性能，但其对复杂视觉语义理解的提升能力仍存疑。

## 研究背景

当模型面对图像生成文本时，语言先验往往压制视觉信号，导致输出与图像事实不符的幻觉。直接偏好优化（DPO）通过解析 KL 正则化奖励最大化目标，直接优化策略模型以拟合成对偏好，无需显式奖励建模，已成为多模态对齐的主流范式。然而，DPO 的有效性严格依赖于高质量偏好对 $(y_c, y_r)$ 中 $y_c \succ y_r$ 的假设。

在自监督设置下，这一假设变得脆弱。自动生成的“优选”响应并非必然在语义上优于“劣选”响应，这种语义模糊性引入了监督噪声，导致训练不稳定且无法有效降低幻觉率。现有主流路线如 RLHF 依赖昂贵的人工标注或 GPT-4V 等强模型反馈，而 SeVa 等自监督方法仅使用二元对，未能解决噪声问题。Trident 的切入点在于利用度量学习中三元组损失的思想，通过引入一个由冻结参考模型生成的中性锚点，显式正则化语义空间，从而在完全自监督条件下实现鲁棒对齐。

## 核心方法

### 方法参照系

标准 DPO 在二元偏好对 $(x, y_c, y_r)$ 上优化，其损失函数为：

$$L_{DPO} = -\log \sigma \left( \beta \left[ \log \frac{\pi_\theta(y_c|x)}{\pi_{ref}(y_c|x)} - \log \frac{\pi_\theta(y_r|x)}{\pi_{ref}(y_r|x)} \right] \right)$$

本文问题与该通用流程的关键差异在于：自监督生成的 $y_c$ 和 $y_r$ 缺乏可靠的语义差距，导致 DPO 的梯度信号噪声大，且二元结构无法提供足够的语义约束以防止分布漂移。

### 自监督三元组构建

设计动机：解决自监督场景下自动生成的“优选”与“劣选”响应之间语义差距模糊的问题。Trident 为每个图像-问题对 $(I, q)$ 构建三元组 $(y_c, y_r, y_{anchor})$。$y_c$ 通过对图像应用语义保持变换（如锐化、小角度旋转）生成候选集，再经自总结得到；$y_r$ 通过语义退化变换（如高斯噪声、激进裁剪）生成；$y_{anchor}$ 则由冻结参考模型 $\pi_{ref}$ 对原始图像生成，作为语义基准。这种结构不仅提供了方向性监督，还通过锚点保留了与预训练模型分布的一致性，避免了因噪声偏好对导致的语义漂移。

### 自适应边际正则化

设计动机：解决二元偏好信号不足以捕捉细微语义差异，且缺乏对预训练分布偏离的约束问题。Trident 提出 Trident Preference Regularization (TPR)，在 DPO 损失基础上引入基于锚点的边际正则化。首先定义平均模型偏移 $\Delta$ 以动态调整正则化强度：

$$m = \max\left(\alpha \cdot \frac{|\log p_c - \log p_{ref}^c| + |\log p_r - \log p_{ref}^r|}{2}, \epsilon\right)$$

随后定义两个铰链惩罚项，分别鼓励策略模型赋予 $y_c$ 高于 $y_{anchor}$ 的似然，并抑制 $y_r$ 高于 $y_{anchor}$ 的似然：

$$L_{tri} = \left[ m - (\log p_c - \log p_{ref}^a) + (\log p_c - \log p_{ref}^c) \right]_+ + \left[ m + (\log p_r - \log p_{ref}^a) - (\log p_r - \log p_{ref}^r) \right]_+$$

最终目标为 $L_{Trident} = \lambda_{dpo} L_{DPO} + \lambda_{tri} L_{tri}$。该机制通过自适应边际 $m$ 动态平衡核心偏好学习与锚点约束，防止模型在噪声数据上过拟合或发生分布漂移。

## 实验评估

Trident 在 LLaVA-1.5-7B/13B 骨干上，使用 4K 自生成三元组训练 1 个 epoch 进行评估。基线覆盖了 RLHF（LLaVA-RLHF）、RLAIF（HALVA, OPA-DPO）及自监督（SeVa）路线，但未对比 2025-2026 年的前沿方法如 SCPO 或 MISP-DPO。

| 方法 | 数据量 | AMBER CHAIR↓ | MMHal-Bench HalRate↓ | Object HalBench CHAIRs↓ | POPE Acc.↑ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| LLaVA-1.5-7B | - | 7.7 | 34.7 | 15.96 | 84.93% |
| +mDPO | 10k | 4.4 | 24.5 | 9.80 | 95.36% |
| +OPA-DPO | 4.8k | 2.2 | 11.6 | 4.25 | 95.61% |
| +Trident | 4k | 2.2 | 11.3 | 3.68 | 95.70% |

Trident 在 AMBER 上与 OPA-DPO 持平（2.2），但在 Object HalBench 上显著优于 OPA-DPO（3.68 vs 4.25），且仅需 4K 自生成数据，而 OPA-DPO 需 4.8K GPT-4V 标注数据并训练 4 个 epoch。这表明三元组结构在对象级事实准确性上具有优势，且数据效率更高。

消融实验显示，随着训练数据量增加，传统 DPO 性能提升有限，而 Trident 表现出显著的性能增益，验证了其在低数据量下的可扩展性。定性分析表明，Trident 生成的响应在语义完整性和事实一致性上优于经典 DPO，减少了幻觉内容。

评估边界方面，论文未报告置信区间，数值比较需谨慎。代码未公开，但提供了详细的超参数设置（LoRA rank 256, $\beta=0.1$）。评估协议使用贪心采样，未涵盖推理时的动态对齐或对抗性攻击场景。

## 关联研究分析

从问题动机看，Trident 与 SeVa 同属自监督路线，但 SeVa 仅使用二元对，依赖原始图像与增强图像的对比，未解决“优选”未必优于“劣选”的噪声问题。Trident 引入锚点，将问题从二元分类转化为三元组排序，根源在于自监督数据缺乏可靠的语义梯度，锚点提供了稳定的语义基准。相比之下，SCPO 使用课程学习解决优化不稳定，而 Trident 使用自适应边际，两者机制不同，但均旨在提升 DPO 在复杂视觉语义下的鲁棒性。

从方法设计看，Trident 借鉴了度量学习中三元组损失的思想，但将其改造为适用于偏好优化的 TPR 目标。与 MISP-DPO 利用稀疏自编码器生成多负样本不同，Trident 通过图像扰动生成单一负样本和锚点，计算开销更低，但可能无法覆盖丰富的视觉偏差空间。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

Trident 旨在解决自监督场景下 DPO 因偏好对噪声导致的训练不稳定问题。其切入点在于引入中性锚点，将二元偏好扩展为三元组结构，并通过自适应边际正则化防止分布漂移。该方法在 4K 自生成数据上实现了 AMBER CHAIR 2.2 和 Object HalBench CHAIRs 3.68 的性能，优于依赖外部反馈的基线。然而，其在 MMHal-Bench 上的 HalRate 为 11.3，远高于 PEA-DPO 的 3.2，表明其在复杂视觉理解任务上仍有短板。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
