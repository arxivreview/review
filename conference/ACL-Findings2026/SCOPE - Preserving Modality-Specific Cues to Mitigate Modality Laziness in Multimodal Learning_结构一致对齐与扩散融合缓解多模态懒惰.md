# ACL-Findings2026最新论文 ｜SCOPE: Preserving Modality-Specific Cues to Mitigate Modality Laziness in Multimodal Learning ｜结构一致对齐与扩散融合缓解多模态懒惰

研究机构：武汉大学

作者：Jingfan Yang、Rui Zhang、Liang Hong 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_a684ce7a84f3)

> 多模态学习常陷入“模态懒惰”，即模型过度依赖主导模态而忽略互补信号，导致融合性能受限。现有架构正则化或动态协调方法虽能提升融合精度，却往往牺牲非主导模态的独立表征能力，造成表示坍缩。SCOPE 通过互信息引导解耦、参数-free语义图对齐及扩散注意力融合，在保留模态特定线索的同时实现结构级对齐。该框架在五个基准上取得最高27.10%的准确率提升，但其对预训练骨干的依赖及未涵盖缺失场景的局限，使其在动态异构环境下的鲁棒性存疑。

## 研究背景

多模态融合的核心困境在于共享语义与模态特定线索的纠缠。当模型优化目标偏向跨模态一致性时，非主导模态的特征易被主导模态的共享语义“同化”，导致特征多样性降低，即表示坍缩。这种坍缩削弱了模态间互补信息的保留，使得融合后的表征判别力下降。为应对此问题，需在不破坏局部几何结构的前提下，分离共享语义与特定线索，并建立保持结构一致性的跨模态对齐机制。

早期缓解模态懒惰的方法主要分为架构正则化与动态协调两类。架构正则化通过修改模型结构强化单模态学习，如交替优化或辅助组件；动态协调则调整优化动态，如梯度平衡或重加权。然而，这些方法多聚焦于提升非主导模态的参与度，却未显式保留其互补线索。例如，动态协调方法在提升融合精度的同时，可能导致非主导模态的独立性能波动或下降。SCOPE 的切入点在于指出，仅平衡贡献度不足以解决懒惰，必须从表示学习层面解耦共享与特定信息，并通过结构级对齐而非点对点匹配来维持模态间的几何一致性。

## 核心方法

### 方法参照系

多模态融合的标准流程通常包含特征提取、跨模态对齐与融合预测。传统方法在对齐阶段多采用点对点特征匹配，假设模态间存在直接的语义对应关系。本文的关键差异在于，将对齐对象从“样本对”升级为“语义图结构”，并引入扩散机制以平衡局部与全局信息的传播，避免深度堆叠导致的过平滑。

### 互信息引导解耦

设计动机在于解决共享语义与模态特定线索在单模态嵌入中的纠缠问题。传统方法直接优化跨模态相似度，易导致特征坍缩。SCOPE 引入互信息（MI）引导的解耦模块，通过最大化同一样本跨模态表示的依赖度，同时抑制不同样本间的依赖度。具体目标函数为：

$$ \max_{\Theta} \sum_{m \neq n} \left( \mathbb{E}_i [I(h_i^m; h_i^n)] - \mathbb{E}_{i \neq j} [I(h_i^m; h_j^n)] \right) $$

该公式通过正负样本的相似度差异，强制模型保留模态特定线索，防止特征空间过度共享。

### 参数-free语义图对齐与扩散融合

设计动机在于解决点对点匹配在模态粒度差异下的脆弱性。传统对齐忽略样本间的邻域关系，导致几何结构扭曲。SCOPE 为每个模态构建语义图，并通过最小化图间 Frobenius 范数差异实现结构对齐：

$$ \mathcal{L}_{align} = \frac{M(M-1)}{2} \sum_{m<n} \| G_m - G_n \|_F^2 $$

其中 $G_m$ 为模态 $m$ 的邻接矩阵。该图构建采用参数-free 正则化 $\psi(g) = \log(\frac{1+g}{1-g})$，确保权重仅依赖局部相对距离，无需调参。融合阶段采用扩散注意力，通过指数衰减的幂级数 $\tilde{A} = \sum_{t=0}^{\infty} \sigma_t A^t$ 传播多跳信息，避免深度堆叠的过平滑，保留特征判别力。

## 实验评估

实验在 MVSA、TumEmo、CREMA-D、IEMOCAP 和 MM-IMDb 五个数据集上进行，对比了 Sum、Concat、LF、LFM、MLA、CRMT、OGM 和 InfoReg 等基线。基线覆盖了传统融合、架构正则化与动态协调三类路线，但未包含处理模态缺失的插值法基线，这与本文聚焦完整数据下的懒惰问题一致。

| 方法 | MVSA (Acc %) | TumEmo (Acc %) | CREMA-D (Acc %) | IEMOCAP (Acc %) | MM-IMDb (F1) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Concat | 76.49 | 59.03 | - | - | 0.5903 |
| OGM | - | 62.88 | - | - | 0.6288 |
| InfoReg | - | 63.09 | - | - | 0.6309 |
| SCOPE | 83.82 | 68.17 | - | - | 0.6817 |

SCOPE 在 MVSA 上取得 83.82% 的准确率，较 Concat 提升 7.33 个百分点；在 TumEmo 上达到 68.17%，较 InfoReg 提升 5.08 个百分点。在 MM-IMDb 上，SCOPE 的 F1 为 0.6817，显著优于 OGM 的 0.6288。

消融实验显示，扩散步数 $T$ 对性能影响显著。在 MVSA 上，$T=3$ 时 Dirichlet 能量为 2.4588，高于 $T=5$ 的 1.1961，表明 $T=3$ 能有效平衡过平滑与全局信息捕获。图密度 $k$ 的消融显示，$k=60$ 时 MVSA 准确率达 84.78%，但单轮训练时间从 $k=10$ 的 12s 增至 95s，揭示了精度与计算成本的权衡。

评估边界方面，论文未报告置信区间，且所有实验基于预训练骨干（CLIP、ImageBind、Qwen2.5-Omni），未验证从零训练的效果。代码未开源，超参数如 $\xi$ 和 $\phi$ 的敏感性分析缺失，限制了可复现性。

## 关联研究分析

从问题动机看，SCOPE 与 OGM 同属模态不平衡缓解，但 OGM 通过梯度调制调整学习动态，而 SCOPE 通过表示解耦与结构对齐优化特征空间。OGM 在 TumEmo 上取得 62.88% 准确率，SCOPE 达 68.17%，差异源于 SCOPE 显式保留了模态特定线索，避免了 OGM 中可能出现的非主导模态性能波动。这一差异表明，优化动态调整与表示结构优化并非互斥，而是互补的解决路径。

从方法设计看，SCOPE 与 Cycle Consistency Learning 均利用跨模态一致性，但后者旨在重建缺失模态，前者旨在保留完整数据下的互补线索。Cycle Consistency 依赖生成式模型，计算开销大且易引入噪声；SCOPE 采用参数-free 图构建与扩散注意力，计算复杂度为 $O(M^2B^2d + TkBd)$，更轻量。然而，SCOPE 未处理模态缺失场景，其在传感器故障或隐私限制下的鲁棒性未经验证，这是其与 Cycle Consistency 等缺失鲁棒方法的关键边界。

## 总结

SCOPE 针对多模态学习中模态懒惰导致的表示坍缩问题，提出通过互信息解耦、参数-free语义图对齐与扩散融合来保留模态特定线索。该方法在五个基准上显著优于现有基线，最高提升 27.10% 准确率，验证了结构级对齐在完整数据场景下的有效性。然而，其实验局限于完整数据，未涵盖模态缺失或动态异构场景，且依赖预训练骨干，未验证从零训练的泛化能力。当模态缺失率超过 50% 时，SCOPE 的语义图构建是否仍能保持结构一致性，论文未给出回答。
