> 方面情感四元组预测（Aspect Sentiment Quad Prediction, ASQP）旨在从文本中同时提取方面、类别、观点词与情感极性，其核心难点在于隐式元素缺乏显式文本线索，导致传统生成模型易产生逻辑无效或结构不一致的输出。现有基于大语言模型（LLM）的方法虽提升了泛化能力，但推理过程黑盒化且缺乏对隐式推理路径的结构约束，难以保证输出的可解释性与鲁棒性。本文提出 Tree-CoT-RT 框架，通过类型特定的树结构引导思维链生成，并结合基于组相对策略优化（Group Relative Policy Optimization, GRPO）的强化学习筛选高质量推理路径，最终通过自一致性投票输出四元组。该框架在 REST-ACOS 与 LAPTOP-ACOS 基准上取得了当前最优性能，尤其在隐式情感子集上优势显著，但其规则奖励函数对语义细微差别的覆盖能力仍存疑。

## 研究背景

当句子中未直接出现方面术语或观点词时，模型需依赖上下文线索进行推断，这一过程称为隐式方面识别。隐式识别要求模型具备深层语义推理能力，而传统序列标注或简单生成范式受限于局部特征匹配，无法捕捉跨元素的复杂依赖，导致在隐式场景下频繁漏检或产生幻觉。为缓解此问题，研究重心转向序列到序列生成范式，通过联合建模捕捉四元组间的分布依赖，但生成式方法引入了新的瓶颈：输出结构可能违反逻辑一致性，且推理过程不可解释，难以定位错误来源。

ASQP 作为 ABSA 中结构最复杂的任务，要求同时预测方面、类别、观点与极性，其子问题间存在强层级依赖：方面-观点对的绑定错误会导致整个四元组失效。2021 年 GAS 将 ASQP 重构为生成问题，确立了生成式主流地位；2025 年 S2IT 引入句法结构注入思维链，但未针对隐式推理路径进行类型化区分。本文的切入点在于：现有思维链方法采用线性推理路径，未区分显式/隐式元素的不同推理逻辑，且缺乏对推理链质量的显式优化机制，导致隐式场景下推理路径混乱、输出不稳定。

## 核心方法

### 方法参照系

本文问题属于“大模型推理与对齐”路线，标准流程为：LLM 生成思维链 → 监督微调（SFT） → 推理时采样。关键差异在于：本文在 SFT 前引入树结构引导的推理链生成，并在 SFT 与推理间插入 GRPO 强化学习环节，以规则奖励筛选高质量推理路径，而非直接依赖原始生成链。

### 类型特定树结构思维链

针对隐式推理路径混乱的问题，本文设计四种类型特定的情感推理树（EAEO/EAIO/IAEO/IAIO），每种树规定 (A, C, O, S) 的推理顺序。例如，IA-IO-C-S 类型要求先推断隐式方面与观点，再确定类别与极性。该设计解决了线性思维链无法区分显式/隐式推理逻辑的失效，使模型在隐式场景下遵循正确的推断顺序。推理链生成公式为：

$$
y^{(i)} = [o_i; a_i; c_i; o_i; s_i]
$$

其中 $o_i$ 为推理链，$a_i, c_i, o_i, s_i$ 为四元组元素，模型被训练为统一序列生成推理链与最终输出。

### GRPO 强化学习链优化

原始生成的推理链质量参差不齐，直接用于 SFT 会引入噪声。本文引入 GRPO 强化学习，通过规则奖励函数筛选高质量链。奖励函数定义为：

$$
R(o_i) = \lambda_1 R_{match}(o_i) + \lambda_2 R_{path}(o_i) + \lambda_3 R_{implicit}(o_i) + \lambda_4 R_{diverse}(o_i)
$$

其中 $R_{match}$ 衡量标签一致性，$R_{path}$ 评估路径有效性，$R_{implicit}$ 检测隐式对齐，$R_{diverse}$ 鼓励多样性。该机制解决了 SFT 对低质量推理链过拟合的问题，通过组内相对优势计算（$A(o_i) = \frac{R(o_i) - \mu_G}{\sigma_G + \epsilon}$）筛选出逻辑一致且覆盖隐式推理的高质量链，用于后续微调。

## 实验评估

实验在 REST-ACOS 与 LAPTOP-ACOS 上进行，评测指标为 F1（四元组全元素匹配）。基线覆盖 BART/T5 系列生成模型及 S2IT 等 LLM 方法，但缺失对话级（DiaASQ）与多语言基准，未评估长文本依赖场景。

| 方法 | 骨干 | REST-ACOS F1 | LAPTOP-ACOS F1 |
| :--- | :--- | :--- | :--- |
| S2IT-32B | Qwen2.5-32B | 67.37 | 46.70 |
| Tree-CoT-RT-7B | Qwen2.5-7B | 69.50 | 49.10 |
| Tree-CoT-RT-32B | Qwen2.5-32B | 71.22 | 50.25 |

Tree-CoT-RT-32B 在 REST-ACOS 上 F1 达 71.22，较 S2IT-32B 提升 3.85 点；LAPTOP-ACOS 上 F1 为 50.25，提升 3.55 点。7B 模型 F1 为 69.50/49.10，超越所有非 32B 基线，表明推理框架贡献大于模型规模。

| 消融变体 | REST F1 | LAPTOP F1 |
| :--- | :--- | :--- |
| w/o Tree-CoT | 68.54 (↓2.68) | 46.56 (↓3.69) |
| w/o GRPO-RL | 67.30 (↓3.92) | 48.91 (↓1.34) |
| w/o CoT-RL | 65.35 (↓5.87) | 46.30 (↓3.95) |

移除 Tree-CoT 导致 REST 下降 2.68 点、LAPTOP 下降 3.69 点，验证树结构对隐式推理的必要性。移除 GRPO-RL 后 REST 下降 3.92 点，但 LAPTOP 仅下降 1.34 点，表明 GRPO 在 REST 数据集上对链质量优化贡献更大，而在 LAPTOP 上边际收益递减。移除 CoT-RL（即完全无强化学习）导致 REST 下降 5.87 点，为最大降幅，证实强化学习是性能提升的核心驱动。

评估协议仅采用 F1 指标，未报告置信区间或计算效率（GPU 小时），可复现性依赖开源代码（github.com/sydmou/ASQP-Tree-CoT-RT）与固定随机种子（444, 555, 666, 777）。实验在四块 NVIDIA A100 GPU 上完成，使用 LoRA 微调，推理链生成依赖 ChatGPT 5.1 与 Gemini 2.5 Pro API，温度 0.7，top-p 0.95，最大长度 2048 tokens。

## 关联研究分析

从问题动机看，S2IT（Chen et al., 2025）同样针对隐式情感，但其通过句法结构注入思维链，未区分推理路径类型，导致隐式方面与观点的推断顺序混乱。本文的树结构引导显式规定 IA/IO 的推断优先级，解决了 S2IT 在 IAIO 子集上 F1 仅 46.70 的瓶颈，本文 IAIO F1 达 56.10，提升 9.4 点。这一差异源于任务特性：隐式推理需要严格的逻辑顺序，而句法注入仅提供局部结构约束，无法保证全局推理路径的有效性。

从方法设计看，DeepSeek R1-Zero（DeepSeek, 2024）引入 GRPO 优化数学推理链，但奖励函数基于答案正确性；本文奖励函数包含隐式对齐项 $R_{implicit}$，专门针对 ABSA 的隐式元素推断。这一设计差异源于任务特性：数学推理的答案唯一且可验证，而 ABSA 的隐式推理存在多种合理路径，需通过隐式对齐奖励引导模型选择符合语义逻辑的路径。然而，规则奖励函数是否足以覆盖所有隐式推理的语义细微差别，论文未给出回答。

## 总结

ASQP 的核心矛盾在于隐式元素缺乏显式线索，导致生成模型输出逻辑无效且不可解释。现有方法如 S2IT 采用线性思维链，未区分推理路径类型，且缺乏对推理链质量的显式优化，导致隐式场景下性能受限。本文通过类型特定树结构引导推理链生成，并结合 GRPO 强化学习筛选高质量链，解决了推理路径混乱与链质量噪声问题。实验证明 Tree-CoT-RT-32B 在 REST-ACOS 上 F1 达 71.22，LAPTOP-ACOS 上 F1 达 50.25，较 S2IT-32B 提升 3.85/3.55 点，且在 IAIO 子集上提升 9.4 点。本文的边界在于：规则奖励函数依赖人工设计，未探索奖励函数的自动化学习；实验仅覆盖单句场景，未评估长文本或对话级依赖。当隐式推理路径存在多种语义等价但结构不同的合理推断时，规则奖励函数能否准确区分其质量，论文未给出回答。
