# ACL-Findings2026最新论文 ｜MemWeaver: Weaving Hybrid Memories for Traceable Long-Horizon Agentic Reasoning ｜记忆固化驱动的三层混合架构

作者：Juexiang Ye、Xue Li、Yang Xinyu 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_b52e4a4dda81)

> 长时程智能体交互面临的核心挑战是跨会话状态丢失与认知矛盾，现有基于向量检索或单一知识图谱的方法在时序一致性与证据可追溯性上存在结构性缺陷。MemWeaver 将记忆管理从被动存储重构为主动固化过程，通过整合时序知识图谱、经验抽象与原始段落证据的三层架构，解决多跳推理中的时间冲突与幻觉问题。该方法在 LoCoMo 基准上显著提升了时序与多跳任务的性能，同时大幅压缩了推理上下文长度，但其离线构建依赖高算力 LLM 的瓶颈限制了实时部署的可行性。

## 研究背景

当智能体在跨越多个会话的长时程交互中维持用户偏好与任务状态时，固定上下文窗口导致的“遗忘”与“矛盾”行为成为根本障碍。这一困境源于情景记忆（Episodic Memory）的碎片化特性：原始交互记录虽保留了时间戳与细节，但缺乏结构化的关联，导致检索时难以捕捉多跳逻辑。为弥补这一缺陷，研究者引入语义记忆（Semantic Memory）以存储稳定的知识三元组，然而若缺乏显式的时序归一化与证据锚定，语义记忆极易产生记忆幻觉（Memory Hallucination），即检索到过时或冲突信息并据此生成错误响应。

长时程记忆架构的研究脉络从静态检索增强生成（RAG）演进至动态认知治理。早期方法如 RAG 仅通过向量相似度匹配补充静态知识，无法处理动态状态演化；MemGPT 引入操作系统类比实现分层调度，但缺乏对记忆内容本身的语义验证；GraphRAG 等结构化方法虽支持组合推理，却常因缺乏会话级审查而积累噪声与冲突。现有方案普遍将记忆视为被动检索缓冲区，忽视了交互累积过程中的系统性固化与更新机制，导致在时序约束查询与跨会话泛化任务上表现脆弱。

MemWeaver 的切入点在于将记忆建模为固化过程，而非静态仓库。它针对现有结构化记忆缺乏时序归一化、经验抽象缺乏证据支撑、以及段落检索缺乏结构关联的三大失效点，提出了一种以固化为中心的三层混合架构。该架构通过显式的写入审查与双通道检索，旨在实现时序一致性、组合推理能力与证据可追溯性的统一，从而在长时程推理中维持认知状态的高保真度。

## 核心方法

### 三层记忆固化框架

MemWeaver 将智能体记忆状态形式化为三层集合 $M = \{G, E, P\}$，其中 $G$ 为图记忆，$E$ 为经验记忆，$P$ 为段落记忆。这一设计突破了传统 RAG 仅依赖向量库的单一粒度限制，将结构化事实、抽象模式与原始证据解耦又耦合。其核心差异在于引入“固化”机制：新交互单元 $x_i$ 并非直接写入存储，而是经过提取、归一化与审查后，以受控方式更新记忆状态 $M_{i+1} = \text{Update}(M_i, x_i)$。这种设计解决了此前方法中噪声提取与冲突积累的问题，确保进入持久存储的记忆具备语义一致性与时间准确性。

### 时序知识图谱构建

图记忆（Graph Memory, GM）作为结构化骨架，采用有向知识图谱 $G = (V, R)$ 表示实体与关系。每个语义关系 $r$ 被表示为带有元数据的三元组：

$$ r = \langle h, \rho, u \rangle, \quad m(r) = \{\hat{t}, c, \pi\} $$

其中 $\hat{t}$ 为归一化绝对时间表达式，$c$ 为可选条件，$\pi$ 为溯源标识符。这一设计的动机在于解决相对时间引用（如“昨天”、“上周”）在长时程中导致的歧义与冲突。通过专用函数 $\eta(x_i, r)$ 将对话上下文中的相对时间转换为绝对时间，GM 能够支持时间感知的多跳推理。写入过程中，系统执行两阶段 LLM 提取（实体与关系），随后进行会话级审查，由 LLM 输出 add、update 或 deny 操作以修正错误与去重，最终重建三元组索引 $I_T$ 用于结构化检索。

### 经验抽象与双通道检索

经验记忆（Experience Memory, ExpM）旨在捕捉无法由孤立事实表达的可复用模式，如偏好与习惯。其构建基于 DBSCAN 聚类与 LLM 一致性验证：

$$ j^* = \arg \max_j \cos(e_i, \mu_j) $$

其中 $\mu_j$ 为簇中心向量。新交互单元根据与簇中心的余弦相似度进行三路路由：高相似度直接合并，中等相似度由 LLM 路由器消歧，低相似度进入待处理缓冲区。只有当多个连贯交互共同支持时，才抽象为经验项，并链接至源段落与实体。推理时，MemWeaver 采用双通道检索策略：结构化检索从 GM 中获取精确的组合上下文 $C_{KG}$，证据检索则通过 `contains` 和 `about` 边组装紧密链接的段落与经验项 $C_{TXT}$，辅以全局密集检索提升召回率。最终答案由骨干 LLM 基于融合上下文生成：

$$ \hat{y} = f_{LLM}(Q, C_{KG}, C_{TXT}) $$

这一机制确保了响应既具备结构化的逻辑推理能力，又拥有原始文本的证据支撑，解决了高层抽象缺乏可追溯性的问题。

## 实验评估

实验在 LoCoMo 基准上进行，该基准包含平均约 9K tokens、跨越多达 35 个会话的长对话，涵盖单跳、多跳、时序、开放域及对抗性任务。基线对比包括 MemoryBank（基于遗忘曲线的扁平检索）与 A-Mem（基于 Zettelkasten 笔记网络的智能体记忆）。MemWeaver 使用 GPT-4o-mini 与 Qwen2.5-1.5B 作为骨干模型，记忆构建离线使用 DeepSeek-V3.2 完成，推理时仅执行检索。

| 方法 | 骨干模型 | Multi-Hop F1 | Temporal F1 | 输入上下文长度 |
| :--- | :--- | :--- | :--- | :--- |
| A-Mem | GPT-4o-mini | 23.68 | 38.77 | >22K tokens |
| MemWeaver | GPT-4o-mini | 26.00 | 50.83 | <1K tokens |
| MemWeaver | Qwen2.5-1.5B | 21.91 | 46.07 | <1K tokens |

MemWeaver 在时序任务上表现尤为突出，GPT-4o-mini 下 Temporal F1 从 A-Mem 的 38.77 提升至 50.83，Qwen2.5-1.5B 下从 14.54 提升至 46.07。这一显著提升归因于时序知识图谱对时间约束的显式建模，以及结构化检索将关键事实与时间线索外化，减少了对小模型参数化知识与长上下文推理能力的依赖。同时，MemWeaver 将输入上下文长度从 LoCoMo 典型的 22K tokens 压缩至 1K tokens 以内，降幅超过 95%，证明了其“信息密度高、检索精准”的设计优势。

消融实验揭示了各组件的贡献差异。移除图记忆（GM）导致多跳与时序任务性能严重下降，表明结构化时序组织是长时程推理的主要驱动力；移除经验记忆（ExpM）则导致中等幅度的性能损失，验证了其在跨会话泛化中的辅助作用。原子级消融显示，在 Qwen2.5-1.5B 上，仅使用 KG 的 F1 为 20.53（Multi-Hop）和 45.14（Temporal），而完整 MemWeaver 达到 21.91 和 46.07，说明三层结构的互补性优于单一组件。超参数分析表明，MemWeaver 对检索数量不敏感，增加检索项并未带来一致的性能提升，反而可能出现边际收益递减，这进一步证实了其有效性源于精确的组织与目标化检索，而非暴力上下文扩展。

评估边界方面，论文仅在 LoCoMo 上验证，缺乏与 LongMemEval 等超百万 Token 基准或 SWE-Bench 等任务导向基准的对比，限制了对其在更复杂动态环境下的泛化能力评估。代码与数据已开源，但离线构建依赖 DeepSeek-V3.2 的高算力需求未在实验中量化其成本效益比，且未报告置信区间，数值比较需谨慎。

## 关联研究分析

从方法设计看，MemWeaver 与 MAGMA 同属结构化记忆路线，但二者在时间处理与证据追溯上存在根本差异。MAGMA 融合语义、时间、因果及实体四种图谱，侧重多模态与多关系推理，但未明确强调会话级审查与时间归一化对冲突消解的作用；MemWeaver 则通过显式的 $\hat{t}$ 归一化与 LLM 审查机制，将时间一致性作为核心约束，并引入段落记忆作为证据锚点，解决了 MAGMA 等纯图谱方法在证据可追溯性上的弱点。这种差异源于任务特性：MemWeaver 针对对话智能体中的时序冲突与幻觉问题，而 MAGMA 更关注复杂关系推理。

从问题动机看，MemWeaver 与 A-Mem 形成直接对比。A-Mem 采用 Zettelkasten 原则构建动态链接笔记网络，强调记忆的自组织与重构，但其更新机制依赖启发式规则，缺乏显式的时序归一化与一致性验证，导致在时序任务上表现较弱（Temporal F1 38.77 vs 50.83）。MemWeaver 将记忆管理从“自组织链接”转向“受控固化”，通过会话级审查与时间归一化提升了记忆质量，但牺牲了部分实时写入速度。这种取舍反映了领域内“轻量化自组织”与“重计算高保真”两条路线的张力，MemWeaver 的选择更适用于对准确性要求高于延迟的长时程对话场景。

## 总结

MemWeaver 旨在解决长时程智能体交互中因记忆碎片化与噪声积累导致的时序冲突与推理脆弱性问题。其核心切入点是将记忆管理重构为包含时间归一化、会话级审查与证据锚定的固化过程，通过整合时序知识图谱、经验抽象与段落证据的三层架构，实现了结构化推理与可追溯性的统一。实验证明，该方法在 LoCoMo 基准上将时序任务 F1 提升至 50.83（GPT-4o-mini），同时将输入上下文长度压缩 95% 以上，验证了其在提升推理精度与降低计算开销上的双重优势。然而，其离线构建依赖高算力 LLM 且缺乏在线实时固化机制，限制了在资源受限或低延迟场景中的应用。当交互频率极高且要求实时响应时，如何在不牺牲记忆质量的前提下降低固化阶段的 LLM 调用成本，是 MemWeaver 架构面临的具体挑战。
