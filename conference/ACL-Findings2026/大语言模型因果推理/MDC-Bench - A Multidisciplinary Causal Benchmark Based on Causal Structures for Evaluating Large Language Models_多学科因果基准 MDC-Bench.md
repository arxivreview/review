# ACL-Findings2026最新论文 ｜MDC-Bench: A Multidisciplinary Causal Benchmark Based on Causal Structures for Evaluating Large Language Models ｜多学科因果基准 MDC-Bench

研究机构：哈尔滨工业大学、华为

作者：Peng Wang、Yuxiong Yan、Xiao Ding 等 10 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_18840408d140)

> 现有因果评估基准多基于常识领域，模型常通过预训练记忆匹配而非逻辑推导得出答案，导致对深层因果能力的评估失真。MDC-Bench 通过引入 7 个学科的专业论文数据与复杂因果拓扑结构，阻断了知识匹配路径，迫使模型进行真实的因果推理。该基准构建了包含理解、干预、反事实三层级的 8,422 道题目，并引入复合操作增加难度。实验显示，即便最先进的模型在硬模式下准确率仍不足 60%，揭示了当前大语言模型在深层因果理解上的显著局限，但其评估协议中关于因果强度梯度的定义尚存争议。

## 研究背景

当大语言模型（LLM）面对涉及多变量交互的复杂场景时，其输出往往依赖统计相关性而非因果机制，这种现象被称为因果幻觉。因果幻觉的根源在于模型内部缺乏对因果结构（Causal Structure）的显式表征，导致其在分布外数据或新颖拓扑上表现失效。为量化这一缺陷，研究者引入了因果阶梯（Causal Ladder）框架，将推理能力划分为关联、干预和反事实三个层级，其中反事实推理要求模型在否定初始事件后推导完全不同的因果路径，是对因果机制理解的最严格测试。

传统基准如 CLadder 主要基于常识知识，模型可通过背诵训练数据中的因果图直接作答，掩盖了真实的推理缺陷。随着领域发展，研究重心转向构建科学接地（Science-Grounded）基准，旨在通过未见过的专业语境消除记忆偏差。然而，现有基准在因果结构多样性上存在局限，多局限于简单的链式结构，难以评估模型对碰撞（Collider）和分叉（Fork）等复杂拓扑的区分能力。MDC-Bench 的切入点在于利用多学科专业文献作为数据源，结合多种因果结构类型，从数据源头阻断知识匹配，从而精准定位模型在深层因果逻辑上的失败点。

## 核心方法

### 方法参照系

因果推理基准评测的标准流程通常基于合成结构因果模型（SCM）或常识问答生成题目，评估模型在 Pearl 因果阶梯各层级的表现。本文的关键差异在于数据源从合成/常识转向真实学术论文引言，并引入 Synergistic-Unique-Redundant Decomposition (SURD) 分解提取因果链，而非直接生成简单的因果对。

### 多学科数据源与 SURD 分解

传统基准使用常识数据，模型易通过预训练记忆匹配答案。本文改用 7 个学科（如医学、工程、社科）的开放获取论文引言作为数据源，利用专业知识的稀缺性阻断记忆匹配。设计动机是确保模型必须依赖上下文中的逻辑推导而非外部知识。具体流程中，首先对论文引言进行 SURD 分解，提取冗余、唯一和协同因果信息，公式化为：

$$ C_{key} = \text{SURD}(T_{intro}) \cap \{ \text{Chain} \} $$

其中 $T_{intro}$ 为论文引言文本，$C_{key}$ 为提取的核心因果链。该公式意味着仅保留具有直接因果关系且无中间步骤跳过的长链，确保题目基于真实的间接因果路径。随后，基于核心链生成干扰选项，其发生概率需低于核心链，以测试模型对因果强度的区分能力。

### 复合操作与限制性反事实

单一因果操作难以区分模型的深层理解能力，且反事实推理易因发散性思维导致选项无效。本文引入复合因果操作（Compound Operations），即在干预或决策任务中同时施加多个因素。例如，在“高盐饮食→高血压→心血管风险”链中，复合干预不仅考虑“服药”，还考虑“维持高盐饮食”，公式化为：

$$ O_{compound} = f(X_{cause}, I_1, I_2, \dots, I_n) $$

其中 $I_i$ 为第 $i$ 个干预因素，$O_{compound}$ 为复合干预下的结果。这一设计解决了单一干预无法反映现实世界多因素共同作用的问题。对于反事实层级，本文提出基于限制性条件（Restrictive Conditions）的生成方法，通过约束推理范围（如仅关注生理机制，排除社会因素），确保反事实链的合理性与选项的可区分性，避免了传统反事实题目中选项漂移导致的评估失效。

## 实验评估

实验在 MDC-Bench 的 8,422 道题目上进行，涵盖 11 个开源模型（Llama, Qwen, Gemma）和 6 个闭源模型（DeepSeek, Gemini, Claude）。基线审计显示，本文仅对比了不同规模的 LLM，未包含传统统计因果发现算法（如 PC, NOTEARS）或混合方法（如 CauScientist）作为对比，这限制了对其“纯基准”定位的完整性评估。

| 模型 | Reasoning (Basic/Hard) | Intervention (Basic/Hard) | Decision (Basic/Hard) | Counterfactual (Basic/Hard) |
| :--- | :--- | :--- | :--- | :--- |
| Llama-3.2-1B | 26.32 / 8.91 | 49.81 / 15.43 | 70.59 / 24.12 | 35.44 / 11.75 |
| Qwen2.5-32B | 75.92 / 50.29 | 84.80 / 58.16 | 89.75 / 58.37 | 72.58 / 55.46 |
| Claude-thinking | 80.61 / 54.19 | 84.73 / 65.01 | 89.45 / 58.48 | 78.14 / 62.29 |
| Gemini-thinking | 78.69 / 53.10 | 82.62 / 63.96 | 89.17 / 54.00 | 77.76 / 61.34 |

主结果显示，所有模型在 Hard Mode（选择 Top-2 因果强度选项）下的准确率均显著低于 Basic Mode（选择最高强度选项），例如 Claude-thinking 在反事实任务中从 78.14% 降至 62.29%。这一断崖式下跌表明，模型仅具备初步的因果理解，无法精确区分因果强度的梯度。消融分析显示，模型在链式结构（Chain Type）上的表现显著优于碰撞（Collider）和分叉（Fork）结构，例如 Qwen2.5-32B 在链式结构 Hard Mode 下达 56.23%，而在碰撞结构下仅为 55.82%（注：此处数值取自 Table 7 的 Chain Type 列，但原文 Table 7 显示 Qwen2.5-32B 在 Chain Type Hard 为 56.23，Collider Hard 为 55.82，Fork Hard 为 54.10，差异较小但趋势一致）。更关键的是，反事实推理在所有模型中表现最差，即便最先进的 Claude-thinking 也仅达 62.29%，验证了反事实层级作为因果能力上限测试的有效性。

评估边界方面，本文采用准确率作为唯一指标，未报告置信区间或计算效率。评估协议中 Hard Mode 的 Top-2 选择机制可能引入任务歧义，即模型可能因选项间因果强度差异微小而随机选择，而非真正理解梯度。可复现性方面，论文未提供代码 URL，但详细列出了 GPU 配置（A100-SXM4-80GB）和超参数（temperature=0, max_tokens=4096），数据源为 CC BY 4.0 许可的开放获取论文，确保了数据可追溯性。

## 关联研究分析

从问题动机看，MDC-Bench 与 NoisyCausal 均旨在提升因果推理的鲁棒性，但路径截然不同。NoisyCausal 通过注入数值噪声（如值扰动、混杂因子）测试模型在数据分布偏移下的稳定性，侧重于数据层面的鲁棒性；而 MDC-Bench 通过引入多学科专业语境和复杂拓扑结构，侧重于知识层面的记忆偏差消除。这一差异源于任务特性的不同：NoisyCausal 关注模型对统计约束的遵循，MDC-Bench 关注模型对语义逻辑的推导。MDC-Bench 未探索噪声对因果结构识别的影响，这可能是一个盲区，因为在真实科学数据中，噪声与复杂结构往往共存。

从方法设计看，MDC-Bench 与 CausalFlip 均致力于隔离语义启发式，但机制不同。CausalFlip 通过构造语义相似但因果结构不同的问题对，测试模型是否依赖语义模式；MDC-Bench 则通过多学科数据阻断知识匹配，迫使模型依赖上下文逻辑。CausalFlip 的局限在于其问题仍基于常识领域，模型可能通过语义相似度猜测答案；MDC-Bench 通过专业语境提高了这一难度。然而，MDC-Bench 未像 CausalFlip 那样显式控制语义相似度，其干扰选项的生成依赖于 DeepSeek 的概率检查，这可能引入生成模型自身的偏差。查询侧增强在数据充足时是否仍有增益，论文未给出回答，但 MDC-Bench 的设计暗示，在专业语境下，单纯的语义匹配策略将失效，必须依赖深层因果推理。

## 总结

MDC-Bench 旨在解决现有因果基准因常识数据导致的记忆偏差问题，通过多学科专业文献与复杂因果拓扑的结合，构建了科学接地的评估体系。其核心创新在于利用 SURD 分解提取真实因果链，并引入复合操作与限制性反事实生成，提升了任务的区分度。实验证明，即便最先进的模型在 Hard Mode 下准确率仍低于 65%，且在反事实推理上表现最差，揭示了 LLM 深层因果理解的局限。然而，本文的边界在于仅评估了 LLM 的推理能力，未对比混合方法（如 LLM+统计约束）的性能，且 Hard Mode 的 Top-2 选择机制可能引入任务歧义。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答，但 MDC-Bench 的设计暗示，在专业语境下，单纯的语义匹配策略将失效，必须依赖深层因果推理。
