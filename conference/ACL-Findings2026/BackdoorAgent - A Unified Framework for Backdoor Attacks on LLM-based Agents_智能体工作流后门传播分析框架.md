研究机构：复旦大学、新加坡管理大学

论文原文见 [arXiv](https://arxiv.org/abs/2601.04566)

> 大语言模型智能体通过规划、记忆与工具调用执行多步任务，其状态持久化特性使得单点注入的触发器可跨阶段传播，但现有研究多在孤立模块下评估，无法刻画这种工作流级的动态风险。本文提出 BackdoorAgent，一个阶段感知的统一框架，通过组件局部扰动与轨迹日志，系统量化了触发器在规划、记忆、工具三个阶段的激活与传播机制。该工作填补了智能体后门从静态注入到动态演化的分析空白，但其仅聚焦攻击表征，未提供防御算法，且评估依赖特定任务验证器，泛化性存疑。

## 研究背景

理解智能体后门需先厘清其与传统大语言模型后门的本质差异。传统后门假设触发器在单次输入输出中激活，而智能体通过递归状态更新，将中间产物（如计划、检索内容、工具反馈）写入上下文或内部状态，形成轨迹级依赖。这种状态持久化意味着，即使触发器仅在某一时刻注入，其影响也会通过后续步骤的复用而放大，这是单轮模型评估无法捕捉的。

大语言模型后门研究已确立数据投毒与语义触发器的主流范式，但现有工作多将智能体视为黑盒或单模块系统，评估协议彼此孤立。例如，BadChain 聚焦思维链污染，PoisonedRAG 针对检索库投毒，但均未分析触发器如何跨越规划、记忆、工具边界传播。这种碎片化导致无法回答核心问题：智能体工作流本身是否为后门提供了新的持久化载体？本文切入点在于，将攻击面从模型权重或单一输入转向工作流中间状态，通过统一框架量化跨阶段传播效应。

## 核心方法

### 阶段感知工作流形式化

智能体后门分析缺乏统一的状态演化模型。本文定义智能体为递归工作流，每一步 $t$ 维护可观测上下文 $x_t$ 与内部状态 $s_t$，并通过规划、记忆、工具三个功能阶段产生中间产物 $p_t, m_t, o_t$。关键创新在于显式建模状态更新规则：

$$x_{t+1} = \text{UpdateContext}(x_t, p_t, m_t, o_t), \quad s_{t+1} = \text{UpdateState}(s_t, p_t, m_t, o_t)$$

该公式表明，中间产物一旦写入 $x_{t+1}$ 或 $s_{t+1}$，即成为后续步骤的输入，实现触发器的跨步持久化。设计动机在于，传统单步评估忽略状态累积效应，而此形式化揭示了工作流级后门的物理基础。

### 组件局部扰动注入机制

为统一表达异构攻击，BackdoorAgent 在规划、记忆、工具接口处设置钩子点，将攻击建模为对单一组件输出的局部扰动。设触发器为 $\tau$，攻击目标为 $G$，受攻击智能体 $\mathcal{A}^\tau$ 通过替换某一功能组件实现：

$$\mathcal{A}^\tau = \mathcal{A} \circ \text{Perturb}_k(\tau, G), \quad k \in \{\text{Planning}, \text{Memory}, \text{Tools}\}$$

此设计解决了此前攻击方法需针对特定智能体架构定制的问题，使 BadChain（规划）、PoisonedRAG（记忆）、AdvAgent（工具）等可在同一运行时中复现。改进价值在于，通过标准化提示构建、工具调用格式与记忆检索协议，确保不同攻击的对比基于相同工作流条件，而非实现差异。

## 实验评估

实验覆盖 Agent QA、Code、Web、Drive 四个任务，使用 GPT、Claude、Gemini、Qwen、DeepSeek 等闭源与开源骨干，评估七种代表性攻击。基线审计显示，本文未对比防御方法，仅聚焦攻击有效性，这与领域内多数防御导向研究形成差异。主结果揭示，记忆通道攻击在 GPT 系骨干上平均 ASR 达 77.97%，显著高于规划（43.58%）与工具（60.28%）通道，表明持久化记忆是后门传播的主要载体。

| 骨干家族 | 规划 ASR (%) | 记忆 ASR (%) | 工具 ASR (%) |
| :--- | :--- | :--- | :--- |
| gpt-family | 43.58 | 77.97 | 60.28 |
| claude-family | 10.43 | 54.82 | 23.07 |
| gemini-family | 39.49 | 75.39 | 48.98 |
| qwen-family | 35.41 | 55.45 | 54.45 |
| deepseek | 27.84 | 38.91 | 42.20 |

消融分析发现，模型性能与后门鲁棒性解耦：高 Clean ACC 的骨干（如 qwen3-235b-a22b 在 Code 任务中 Clean ACC 80.47）在记忆攻击下 ASR 仍达 58.42，表明工作流属性而非模型能力主导漏洞。反直觉发现是，Agent Drive 中 BadChain 在所有开源骨干上 ASR 均超 90，而 QA/Code 中规划攻击通常中等，揭示序列决策中微小扰动可级联放大。

评估边界方面，指标仅含 ASR 与 ACC，缺乏隐蔽性量化；Agent Web 仅评估多模态骨干，未覆盖纯文本场景；代码已开源，但超参数与 GPU 配置未在正文详述，可复现性依赖 GitHub 仓库。

## 关联研究分析

从问题动机看，本文与 BadChain 等单模块攻击的根本差异在于评估粒度。BadChain 假设触发器在思维链中静态存在，而本文证明触发器可通过状态更新动态传播，例如 PoisonedRAG 在 Agent QA 中 ASR 达 93.48（gpt-4o-mini），远超其单步评估中的表现。这一差异源于任务特性：智能体的递归工作流使中间产物成为触发器的“放大器”，而非单纯载体。

从方法设计看，本文与 Sleeper Agents 的冲突在于攻击面定位。Sleeper Agents 关注模型权重中潜伏的后门，而本文发现无需修改权重，仅通过工作流中间状态注入即可实现持久化控制。这暗示，智能体安全的核心矛盾可能不在模型内部表示，而在外部状态管理。查询侧增强在数据充足时是否仍有增益，论文未给出回答，但工作流级防御是否比模型级防御更根本，本文的实验数据提供了初步证据。

## 总结

本文核心矛盾是智能体工作流的状态持久化特性与现有孤立评估协议的脱节。其切入点在于，将攻击面从模型权重转向工作流中间状态，通过阶段感知框架与组件局部扰动，量化了触发器跨阶段传播机制。实验证明，记忆通道攻击在 GPT 系骨干上 ASR 达 77.97%，且模型性能与后门鲁棒性解耦。边界在于，本文仅表征攻击，未提供防御算法，且评估依赖特定任务验证器，无法直接迁移至开放域智能体。当工作流步骤数增加至 10 步以上时，触发器传播是否出现衰减或饱和，论文未给出回答。
