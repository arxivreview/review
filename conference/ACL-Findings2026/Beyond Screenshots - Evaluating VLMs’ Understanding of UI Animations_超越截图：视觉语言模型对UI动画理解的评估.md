# ACL-Findings2026最新论文 ｜Beyond Screenshots: Evaluating VLMs’ Understanding of UI Animations ｜超越截图：视觉语言模型对UI动画理解的评估

研究机构：美国密歇根大学

作者：Chen Liang、Xirui Jiang、Naihao Deng 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_3aa785e0b023)

> 现有GUI智能体研究聚焦于静态截图的元素定位，忽略了界面中通过动态变换传达状态反馈的动画通道，导致模型无法完整解析用户交互逻辑。本文构建了首个包含专家与大众双重标注的UI动画数据集AniMINT，并系统评估了9个主流视觉语言模型在动画感知、目的分类与意义解释上的能力。实验表明，尽管模型能识别基础运动原语，但在高阶目的分类上准确率仅0.64，且解释常缺失关键细节。通过引入运动、上下文与感知线索（MCPC）增强，验证了多模态线索协同对提升动画理解的必要性，揭示了当前模型在动态UI理解上的显著短板。

## 研究背景

GUI智能体在操作界面时，需准确解析系统状态与用户反馈。传统视觉语言模型（VLMs）主要依赖静态截图进行元素定位与语义提取，但现代UI设计中，动画是传达状态转换、操作反馈的核心动态通道。例如，密码输入框的抖动或Dock图标的弹跳，其语义编码在运动轨迹而非静态帧中，单帧图像无法捕捉其完整意图。这种静态感知范式的局限，使得模型在面对动态交互时，往往将动画误判为静态元素或忽略其功能属性，导致对界面状态的误读。

GUI定位与理解领域已确立纯视觉驱动范式，通过大规模截图-文本-坐标数据微调，实现了跨平台的元素定位能力。然而，现有基准如ScreenSpot-Pro主要评估高分辨率静态界面下的细粒度定位，缺乏对时序动态特性的考察。随着GUI智能体向复杂交互序列扩展，模型需理解动画所隐含的操作意图与系统响应逻辑。本文切入点在于填补动态UI理解的空白，将评估对象从静态像素坐标扩展至时序运动语义，探究VLMs在缺乏专门时序训练的情况下，能否通过通用视觉-语言对齐能力解析动画的功能目的与深层含义。

## 核心方法

### 评估任务定义与数据集构建

本文任务属于多模态时序理解范畴，与静态UI元素检测的关键差异在于输入为视频序列，输出为语义分类与自然语言解释。AniMINT数据集包含300个来自移动、桌面和Web平台的UI动画视频，由3名UI/UX专家进行目的分类标注，300名普通用户提供10条独立的意义解释描述。动画目的被划分为7类：Transition, Demonstration, Guidance, Feedback, Visualization, Highlight, Aesthetic；运动效果划分为7种原语：move, rotate, size, color, fade, blur, morph。

### 运动、上下文与感知线索增强机制

针对VLMs在动态感知上的瓶颈，本文提出MCPC增强策略，通过输入侧干预提升模型对动画的理解。该机制包含三个维度：运动混合（Motion Blending）、上下文信息（Contextual Information）与感知字幕（Perceptual Caption）。运动混合借鉴Phosphor概念，将过去6帧以衰减透明度混合至单帧，以显式编码运动轨迹；上下文信息提供用户交互背景；感知字幕提供动画的文本描述。

$$
I_{blend} = \sum_{i=0}^{k} \alpha_i \cdot F_{t-i}
$$

其中 $F_{t-i}$ 为历史帧，$\alpha_i$ 为衰减权重，$I_{blend}$ 为混合后的运动编码图像。该公式将时序信息压缩至空间维度，弥补了VLMs对帧间微小位移感知不足的问题。

$$
S_{interp} = \frac{1}{N} \sum_{j=1}^{N} \text{Sim}(P_{model}, R_{human, j})
$$

其中 $P_{model}$ 为模型生成的解释，$R_{human, j}$ 为第 $j$ 个人类标注，$\text{Sim}$ 为语义相似度。该指标量化了模型解释与人类认知的对齐程度，用于评估高阶语义理解能力。

## 实验评估

实验在零样本设置下进行，评估9个SOTA VLMs，包括GPT-5、Gemini-2.5-Pro、Claude-Sonnet-4等。基线覆盖商业闭源与开源模型，但缺乏专门针对视频时序建模的专用模型（如Video-LLaMA），可能低估了时序专用架构的潜力。

| 模型 | 目的分类准确率 | 目的分类Macro F1 | 解释相似度均值 | 解释相似度标准差 |
| :--- | :--- | :--- | :--- | :--- |
| Gemini-2.5-Pro | 0.64 | 0.55 | 3.40 | 0.90 |
| GPT-5 | 0.64 | 0.53 | 3.44 | 0.90 |
| GPT-o3 | 0.62 | 0.54 | 3.47 | 0.91 |
| Qwen2.5-VL-72B-Instruct | 0.39 | 0.32 | 2.94 | 1.24 |
| GLM-4.5V | 0.45 | 0.40 | 2.71 | 1.47 |

Gemini-2.5-Pro与GPT-5在目的分类上并列最高（0.64），但GPT-o3在解释相似度上领先（3.47），表明分类能力与生成解释能力存在解耦。开源模型Qwen2.5-VL-72B表现显著落后，准确率仅0.39，凸显了闭源模型在动态UI理解上的优势。

| 增强配置 | 目的分类准确率 | 解释相似度均值 |
| :--- | :--- | :--- |
| Base | 0.59 | 3.15 |
| + M (Motion) | 0.52 | 3.08 |
| + C (Context) | 0.58 | 3.30 |
| + P (Perceptual) | 0.57 | 3.50 |
| + M + C + P | 0.61 | 3.52 |

单独引入运动混合（+M）导致准确率下降至0.52，表明单纯的运动编码可能引入噪声或干扰静态特征提取。而结合上下文与感知字幕的完整MCPC配置（+M+C+P）达到最佳性能（0.61/3.52），验证了多模态线索的协同效应。感知字幕（+P）对解释相似度的提升（3.50）大于对分类准确率的提升，说明文本线索更利于语义生成而非分类决策。

评估协议采用零样本设置，未进行任务特定微调，可能低估了模型通过微调提升动态理解能力的潜力。代码与数据集已开源，但实验未报告计算效率指标，且LLM-as-a-Judge（GPT-5-mini）可能存在家族偏差。

## 关联研究分析

从问题动机看，本文与SeeClick等GUI定位工作形成互补。SeeClick聚焦于静态截图下的坐标预测，通过大规模预训练提升定位精度，而本文关注动态视频下的语义理解，揭示了VLMs在时序感知上的盲区。这种差异源于任务特性：定位任务依赖空间几何关系，可通过高分辨率输入缓解；而动画理解依赖时序因果逻辑，单帧信息不足以支撑语义推断。本文未探索通过微调提升动态理解的方法，仅评估了零样本能力，这与SeeClick的预训练范式形成鲜明对比。

从方法设计看，本文的MCPC增强策略与DRS-GUI的动态区域搜索框架存在逻辑关联。DRS-GUI通过迭代裁剪缩小视觉范围以提升静态定位精度，而本文通过运动混合与上下文注入增强动态感知。两者均试图通过输入侧干预弥补模型原生能力的不足，但DRS-GUI侧重于空间分辨率，本文侧重于时序语义。本文未对比不同VLMs架构（如Transformer vs CNN）对动画理解的差异，仅关注模型规模与来源，这可能掩盖了架构设计对时序建模的影响。

## 总结

本文旨在解决VLMs在动态UI动画理解上的能力缺失，通过构建AniMINT数据集并系统评估9个SOTA模型，揭示了模型在基础运动感知与高阶目的分类之间的显著差距。实验表明，最佳模型Gemini-2.5-Pro的目的分类准确率仅为0.64，且解释相似度均值3.40/5，显示模型难以准确捕捉动画的功能意图与深层含义。MCPC增强策略验证了运动、上下文与感知线索的协同作用，但单独引入运动混合反而降低性能，表明动态理解需多模态线索的平衡整合。本文的边界在于零样本评估未探索微调潜力，且缺乏时序专用架构的对比。当支持集增大或引入时序专用预训练时，VLMs的动态理解能力是否会发生质变，论文未给出回答。
