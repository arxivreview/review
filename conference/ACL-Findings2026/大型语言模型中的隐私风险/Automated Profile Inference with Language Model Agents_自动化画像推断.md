# ACL-Findings2026最新论文 ｜Automated Profile Inference with Language Model Agents ｜自动化画像推断

作者：Yuntao Du、Zitao Li、Bolin Ding 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_74a5b1641137)

> 在线伪匿名平台用户通过公开活动暴露的敏感信息，长期依赖人工分析才能被提取，效率低且门槛高。现有基于大语言模型（LLM）的属性推断方法多将任务简化为预定义类别的分类，无法处理噪声大、信息隐含且无固定标签的真实场景。本文提出 AutoProfiler，一个由四个专用 LLM 智能体协作的自动化画像框架，通过迭代检索、推断与精炼流程，从公开活动中自主构建包含个人身份信息（PII）和敏感个人信息（SPI）的用户画像。该方法在真实数据上实现了高准确率与低成本，验证了自动化去匿名化的可行性，但其对模型对齐防御的无效性及合成基准上的性能局限仍存疑。

## 研究背景

在线伪匿名平台（如 Reddit、Twitter）允许用户隐藏真实身份，但用户在帖子和评论中分享的生活经历、健康状态及人际关系构成了丰富的数字足迹。这些文本通常充满歧义、不一致且包含大量无关信息，个人细节往往通过上下文线索间接披露，而非直接陈述。这种“在线去抑制效应”导致用户无意中暴露大量敏感信息，但传统犯罪侧写方法（Douglas et al., 1986）需要专家手动分析，耗时且难以规模化，无法应对海量用户数据的隐私风险。

LLM 的出现为自动化分析提供了可能，但直接提示 LLM 生成画像的效果不佳，因为模型难以从噪声文本中提取隐含细节，且缺乏处理长上下文和矛盾信息的机制。现有研究如 Staab et al. (2024) 和 Liu et al. (2025c) 将属性推断视为分类问题，依赖预定义的 PII 类别，忽略了 SPI 等未定义但高风险的信息类型，且未解决数据噪声导致的推断不稳定问题。AutoProfiler 的切入点在于将画像推断重构为自主代理任务，借鉴犯罪侧写的角色分工，通过多智能体协作解决单模型在噪声处理和开放集推断上的局限，从而实现对 PII 和 SPI 的全面提取。

## 核心方法

### 多智能体协作架构

传统 LLM 画像方法通常采用单轮提示，将用户活动直接输入模型并要求生成结构化输出。这种流程在处理长文本和噪声数据时容易因上下文窗口限制或信息过载而失效。AutoProfiler 引入四个专用智能体：Strategist（策略师）、Retriever（检索器）、Extractor（提取器）和 Summarizer（总结器）。Strategist 负责协调流程，决定下一步动作（检索、推断、精炼或结束）；Retriever 通过 API 获取用户活动；Extractor 分析活动并提取属性；Summarizer 解决不一致性并精炼结果。这种分工解决了单模型无法同时处理数据获取、深度分析和结果校验的问题，使得系统能够处理超过 1,500 条评论的用户数据。

### 迭代推断与结构化通信

单轮推断难以处理用户活动中的矛盾信息和隐含线索，导致推断结果不可靠。AutoProfiler 采用迭代工作流，每轮处理 10 条活动，通过结构化 JSON 格式进行智能体间通信。每个推断属性包含类型、值、置信度（1-5）和证据。置信度评分函数定义为：

$$ C(a) = \frac{1}{N} \sum_{i=1}^{N} c_i(a) $$

其中 $c_i(a)$ 是第 $i$ 条活动中属性 $a$ 的置信度，$N$ 为相关活动数量。该公式通过聚合多条证据的置信度，量化推断的可靠性。Summarizer 利用此评分解决矛盾，例如当多个活动对同一属性给出不同值时，保留高置信度值并标记低置信度值为潜在错误。这种机制显著提升了推断的准确性，特别是在处理噪声数据时，如 Table 6 所示，注入 10% 噪声后准确率仅轻微下降。

### 记忆管理与上下文优化

LLM 的上下文窗口限制使得处理大量用户活动变得困难，直接输入所有活动会导致关键信息被截断或稀释。AutoProfiler 采用长短时记忆管理策略：Extractor 和 Retriever 使用短时记忆，仅保留当前迭代相关的上下文；Strategist 和 Summarizer 使用长时记忆，存储结构化的推断属性摘要。长时记忆更新公式为：

$$ M_{t+1} = M_t \cup \{ a \in A_t \mid C(a) > \tau \} $$

其中 $M_t$ 是第 $t$ 轮的长时记忆，$A_t$ 是本轮推断的属性，$\tau$ 是置信度阈值。该公式确保只有高置信度的属性被保留在长时记忆中，减少了上下文大小，同时保留了关键信息。这种设计使得 AutoProfiler 能够在不超出 LLM 上下文限制的情况下处理大规模用户数据，提高了系统的可扩展性。

## 实验评估

实验在 Reddit（857 用户）、Twitter（123 用户）和 SynthPAI（26 用户）上进行，对比基线包括 FTI、PIE 和 PII-Extractor。AutoProfiler 在 Twitter 数据集上表现最佳，GPT-4 模型下准确率达 92.0%，显著高于 FTI 的 84.0% 和 PIE 的 84.6%。在 SynthPAI 上，AutoProfiler 的准确率为 92.0%，低于 SOTA 方法 Beyond Memorization 的 95%，但 AutoProfiler 处理的是无预定义类别的开放集任务，任务复杂度更高。

| 数据集 | 方法 | GPT-4 | Claude-3 | Gemini-1.5 |
|---|---|---|---|---|
| Twitter | AutoProfiler | 92.0% | 87.1% | 90.2% |
| Twitter | FTI | 84.0% | 84.0% | 80.0% |
| Twitter | PIE | 84.6% | 84.6% | 81.5% |
| SynthPAI | AutoProfiler | 92.0% | 89.6% | 87.5% |
| SynthPAI | FTI | 88.0% | 79.2% | 78.1% |
| SynthPAI | PIE | 88.9% | 79.8% | 79.3% |

消融实验显示，增加智能体数量一致提升性能。仅使用 Extractor 时，GPT-4 准确率为 72±2%；加入 Strategist 和 Retriever 后提升至 77±1%；加入 Summarizer 后达到 92±1%。这表明 Summarizer 在解决不一致性和提升可靠性方面贡献最大。效率方面，GPT-4 处理单个用户约需 30 秒，成本 $0.59，比人工分析快 120 倍，成本低 50 倍。

评估边界方面，Reddit 数据集缺乏严格 Ground Truth，准确率基于人工检查，可能存在高估。SynthPAI 为合成数据，虽有人工标注，但无法完全反映真实场景的复杂性。代码已开源，但实验未报告置信区间，且未对比传统机器学习基线（如 XGB），限制了与经典方法的直接比较。

## 关联研究分析

从问题动机看，AutoProfiler 与 Staab et al. (2024) 的 FTI 方法均利用 LLM 进行属性推断，但 FTI 将任务限定为预定义 PII 类别的分类，而 AutoProfiler 处理开放集推断，包括 SPI。这一差异源于任务特性：FTI 假设攻击者已知目标属性类型，而 AutoProfiler 模拟更现实的场景，攻击者仅知用户存在，需自主发现所有潜在敏感信息。FTI 在 SynthPAI 上的准确率（88.0%）低于 AutoProfiler（92.0%），表明开放集推断在数据充足时具有优势，但 FTI 在预定义类别上的效率更高，AutoProfiler 是否能在类别明确时保持优势，论文未给出回答。

从方法设计看，AutoProfiler 与 Mireshghallah et al. (2024) 的对话诱导攻击不同，后者通过多轮对话引导用户泄露信息，而 AutoProfiler 仅依赖静态公开数据，无需用户交互。这一差异反映了攻击面的不同：对话诱导针对用户行为，AutoProfiler 针对数据本身。AutoProfiler 的多智能体架构借鉴了 MetaGPT 等框架的角色分工，但应用于隐私攻击场景。与 MetaGPT 相比，AutoProfiler 引入了置信度评分和迭代精炼机制，专门解决噪声数据下的推断可靠性问题，而 MetaGPT 更关注代码生成等结构化任务。AutoProfiler 在噪声鲁棒性上的表现（Table 6）优于单轮方法，但多智能体协作带来的通信开销（90,755 tokens）是否在所有场景下都优于单轮长上下文提示，论文未进行详细对比。

## 总结

AutoProfiler 解决了在线伪匿名平台用户隐私风险自动化评估的难题，通过多智能体协作框架实现了从公开活动到详细画像的自主推断。其核心创新在于将犯罪侧写方法论转化为 LLM 智能体分工，结合迭代推断和结构化通信，有效处理噪声数据和开放集属性。实验证明该方法在真实数据上具有高准确率（Twitter 92.0%）和低成本（$0.59/用户），验证了自动化去匿名化的可行性。然而，论文在 SynthPAI 合成基准上的性能（92.0%）低于 SOTA 方法 Beyond Memorization（95%），且 Reddit 数据集缺乏严格 Ground Truth，限制了结论的普适性。当用户活动数据量极大或噪声比例超过 10% 时，多智能体协作的边际收益是否递减，以及模型对齐能否抑制基于外部数据的画像推断，论文未给出回答。
