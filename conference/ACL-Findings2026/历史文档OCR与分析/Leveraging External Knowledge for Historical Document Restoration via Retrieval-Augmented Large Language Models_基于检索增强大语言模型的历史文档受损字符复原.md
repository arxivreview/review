# ACL-Findings2026最新论文 ｜Leveraging External Knowledge for Historical Document Restoration via Retrieval-Augmented Large Language Models ｜基于检索增强大语言模型的历史文档受损字符复原

作者：Gabeen Kim、Kyeongpil Kang

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_c9f32802b601)

> 导读 历史档案因物理侵蚀导致大量字符不可读，传统掩码语言建模方法仅依赖单篇文档内部上下文，难以恢复需外部历史知识支撑的命名实体。本文切入点在于将大语言模型的隐式知识与显式检索增强生成结合，构建专门针对古代语料的复原框架。具体做法是微调Qwen3模型，利用BM25检索相关文档并引入时间元数据，以因果语言建模方式生成复原字符。该框架在命名实体恢复上显著优于通用大模型，但其评估仅依赖Top-1准确率，未涵盖结构完整性与语义一致性维度。

## 研究背景

当模型面对“1492年哥伦布登陆[M]”这类句子时，仅靠局部上下文无法确定[M]为“美洲”，必须调用外部历史知识。这种对专有名词的依赖揭示了掩码语言建模（MLM）的根本局限：其非自回归预测机制忽略了被掩码字符间的长距离依赖关系，且训练时的固定掩码概率与实际文档的随机损毁分布不匹配，导致推理性能下降。

历史文档复原的主流路线从早期的深度学习拼写纠错演进至基于MLM的字符预测。Kang et al. (2021) 通过联合训练MLM与机器翻译实现了复原与翻译，Ithaca (Assael et al., 2022) 则引入地理与时间属性预测以提升可解释性。然而，这些方法均将输入限制在单篇受损文档内，无法处理需要跨文档知识检索的命名实体恢复任务。本文针对这一瓶颈，提出利用大语言模型（LLM）的隐式知识结合检索增强生成（RAG）的显式知识注入，解决外部知识缺失导致的复原失败问题。

## 核心方法

### 方法参照系

本文问题属于历史文本序列复原，与视觉OCR中的RAG后校正路线在“外部知识注入”机制上同构，但输入模态为纯文本序列而非图像，且检索源为同语料库文档而非通用知识库。标准流程为：输入受损文本→检索相关文档→LLM生成复原字符。

### 因果语言建模与元数据注入

设计动机在于解决MLM非自回归预测导致的字符依赖缺失问题。本文采用因果语言建模（CLM）替代MLM，将复原任务重构为序列生成问题。输入文档 $D$ 包含 $k$ 个受损位置 $[D_1, ..., D_k]$，模型需生成对应字符序列 $Y = (y_1, ..., y_k)$。为增强时间定位能力，将元数据 $M = (year, month, day, era)$ 拼接至输入前缀：

$$ P_{input} = M \oplus D \oplus R_{retrieved} $$

其中 $\oplus$ 表示序列拼接，$R_{retrieved}$ 为检索文档。该设计使模型在生成每个 $y_i$ 时能利用前文已生成的字符及时间背景，解决了MLM中各位置独立预测导致的上下文断裂问题。

### 动态检索与去重策略

设计动机在于解决固定掩码概率与实际损毁分布不匹配导致的训练-推理偏差。本文引入动态检索机制，对每个受损文档 $D$，使用BM25算法从训练语料库中检索Top-20相关文档 $R_{top20}$。为平衡检索多样性与相关性，引入相似度阈值 $\tau = 0.80$ 进行去重：

$$ R_{final} = \{ d \in R_{top20} \mid \max_{d' \in R_{seen}} sim(d, d') < \tau \} $$

其中 $sim(\cdot, \cdot)$ 为文档相似度函数，$R_{seen}$ 为已保留文档集合。实验表明，当阈值超过85%时，性能因过度保留重复文档而下降；80%阈值下命名实体准确率从24.28%提升至27.85%，随机位置准确率从60.36%提升至61.45%。该策略通过确保检索文档的多样性，提供了更丰富的外部知识线索，缓解了模型对单一重复上下文的过拟合。

## 实验评估

实验基于AJD与JRS两个韩语历史语料库，测试集包含10K文档，其中DNE子集评估命名实体恢复，DRand子集评估随机位置恢复。基线覆盖通用LLM（Gemini-2.5-Pro, Sonnet-4.5, GPT-5.1, Kimi-K2, Qwen3）及BERT-Res，但未包含视觉OCR基线（因任务模态不同）。

| 模型 | NE准确率 (%) | Rand准确率 (%) |
| :--- | :--- | :--- |
| ARI-32B (Ours) | 39.31 | 80.42 |
| Sonnet-4.5 | 35.36 | 76.87 |
| Gemini-2.5-Pro | 31.82 | 73.43 |
| BERT-Res | 28.59 | 79.38 |
| Qwen3-32B (R) | 30.09 | 69.72 |

ARI-32B在命名实体恢复上以39.31%领先Sonnet-4.5的35.36%，在随机位置恢复上以80.42%略高于BERT-Res的79.38%，验证了领域适配RAG框架的有效性。

| 配置 | NE准确率 (%) | Rand准确率 (%) |
| :--- | :--- | :--- |
| Baseline | 5.63 | 14.83 |
| + Static shots | 6.27 | 18.98 |
| + Dynamic shots (BM25) | 24.28 | 60.36 |
| + Deduplication | 27.85 | 61.45 |

消融实验显示，动态检索（BM25）带来最大增益，NE准确率从6.27%跃升至24.28%；去重策略进一步将NE准确率提升至27.85%，Rand准确率提升至61.45%。这一结果证实了检索多样性对复原性能的关键作用，而非单纯的相关性。

评估指标仅采用Top-1准确率，未涵盖字符错误率（CER）、结构完整性或语义一致性维度，这与领域共识中强调的多维评估存在差距。论文声明将公开模型与数据，但未提供具体URL、超参数或GPU配置，可复现性受限。

## 关联研究分析

从问题动机看，本文与RAG-Historical Restoration (P23) 同属RAG复原路线，但P23侧重字符级复原，依赖通用知识库；本文侧重文档级上下文，检索源为同语料库文档。这一差异源于任务特性：本文处理的AJD/JRS语料库具有高度内部一致性，同语料库检索比通用知识库更精准；而P23处理的严重受损文档可能需要跨语料的权威知识校正。

从方法设计看，本文与REVISE (P9) 同属后校正框架，但REVISE针对OCR错误传播，本文针对物理损毁字符。REVISE关注下游任务（如检索增强生成）的鲁棒性，本文关注复原本身的准确率。这一差异反映了历史文档处理中“识别”与“复原”两个子任务的不同需求：REVISE解决的是“识别错误如何影响下游”，本文解决的是“损毁字符如何恢复”。

## 总结

本文要解决的核心矛盾是历史文档中命名实体恢复对外部知识的依赖与现有MLM方法仅利用内部上下文的局限。本文抓住的切入点是LLM的隐式知识与RAG的显式知识注入相结合，通过因果语言建模捕捉长距离依赖。方法上，本文微调Qwen3模型，利用BM25检索与动态去重策略增强外部知识获取。实验证明，ARI-32B在命名实体恢复上达39.31%，随机位置恢复达80.42%，显著优于通用大模型基线。本文的边界在于评估仅依赖Top-1准确率，未涵盖结构完整性与语义一致性，且检索源限于同语料库，未探索跨语料库知识注入的效果。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
