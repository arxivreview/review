# ACL-Findings2026最新论文 ｜Can We Entrust Justice to AI?: How Persona Traps Contaminate Reasoning in Criminal Investigation ｜隐性偏见传播（Implicit Bias Propagation）在刑事推理中的量化

作者：Jaewook Lee、Myeong-Cheol Kang、Jong-hun Shin

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_6f019fc15279)

> 大语言模型（LLMs）在复杂推理任务中是否受无关人口统计学特征影响，是部署安全的关键盲区。现有偏见评估多聚焦于显式身份属性（如种族、性别）的静态问答，忽略了关系型偏见在长程推理中的隐性渗透，且缺乏对推理过程污染的独立度量。本文通过中性化谋杀案数据集并注入受控Persona，提出决策不一致率（DIR）与推理影响率（IRR）双指标，量化了模型在结论与过程层面的偏见传播。该研究揭示了关系偏见被当前对齐机制系统性忽视的事实，但评估依赖单一裁判模型且未验证缓解策略的有效性。

## 研究背景

刑事侦查中的“隧道视野”（Tunnel Vision）指调查者过早锁定假设并选择性解读证据，导致误判。认知科学证实，人类判断易受与案件本质无关的启发式信息干扰，如熟悉度带来的好感或敌对关系引发的负面归因。当LLMs学习人类生成的文本时，这些偏见以语言模式沉淀于内部表征，使得模型可能在声称“信息无关”的同时，其推理路径已被隐性扭曲。

现有LLM偏见研究主要依赖BBQ等基准，通过多选题测量模型对刻板印象的依赖。这类方法存在两个瓶颈：一是任务结构过于简单，无法捕捉长叙事中多步推理的累积偏差；二是评估焦点局限于显式身份属性，而RLHF安全训练已有效抑制此类偏见，却对非显性的关系型偏见（如亲密或敌对关系）形成盲视。本文切入点在于构建具有确定性答案的复杂推理场景，通过实验控制隔离单一Persona变量，区分结论改变与过程污染，填补了关系偏见在动态推理中量化评估的空白。

## 核心方法

### 数据中性化与Persona注入框架

本文方法参照系为基于MuSR数据集的偏见评估流程，关键差异在于引入迭代式数据中性化以消除原始文本中潜藏的 demographic cues，确保实验变量仅为注入的Persona。中性化框架采用GPT-5.1作为编辑与审计双角色，通过反馈引导迭代修正，直至所有嫌疑人属性不可推断。

### 双指标量化机制

DIR与IRR的提出解决了传统评估仅关注输出结果、忽略过程污染的失效。DIR衡量结论层面的偏见，定义为注入Persona后模型最终判断与基线不一致的比例：

$$ DIR = \frac{1}{N} \sum_{i=1}^{N} \mathbb{I}(\hat{y}_i^{persona} \neq \hat{y}_i^{neutral}) $$

该公式捕捉模型在证据相同情况下，因无关信息导致判决翻转的频率。IRR则通过LLM-as-a-Judge（GPT-5-mini）评估推理文本是否被Persona影响，公式为：

$$ IRR = \frac{1}{N} \sum_{i=1}^{N} \mathbb{I}(Judge(r_i^{persona}, p_i) = True) $$

其中 $r_i^{persona}$ 为含Persona的推理文本，$p_i$ 为注入的Persona。IRR揭示了即使结论正确，推理过程仍可能被偏见渗透的“安全结论下的污染”现象，弥补了DIR无法检测隐性过程偏差的局限。

## 实验评估

实验基于245个中性化MuSR案例，对比10个SOTA LLM。基线覆盖Llama、Qwen、Gemma等主流架构，但未包含Beacon或Anti-Scheming等偏见缓解方法，仅评估模型固有脆弱性。

| 模型 | 架构 | DIR (%) |
| :--- | :--- | :--- |
| Llama-3.3-70B-Instruct | Dense | 6.9 |
| Mixtral-8x7B-Instruct | MoE | 21.6 |
| Qwen3-30B-A3B-Instruct | MoE | 17.3 |
| Qwen3-14B | Dense | 10.5 |

DIR范围6.9%-21.6%，表明所有模型均存在隐性偏见传播。MoE架构平均DIR（17.9%）约为Dense（10.3%）的1.7倍，暗示专家路由机制可能对Persona token过度敏感。

| Persona类别 | IRR (%) |
| :--- | :--- |
| Hostile | 66.9 |
| Close | 48.9 |
| Gender | 14.1 |
| Race | 9.9 |

关系类Persona（Hostile/Close）的IRR均值（~58%）是身份类（~12%）的4.8倍，证实关系偏见对推理过程的污染远重于身份偏见。Hostile类别IRR高达66.9%，意味着“嫌疑人杀害调查者亲属”等信息在三分之二情况下直接扭曲推理路径，即便最终结论可能正确。

评估边界受限于单一裁判模型（GPT-5-mini）的潜在偏见，且未报告置信区间。代码未公开，中性化流程依赖GPT-5.1，复现成本较高。DIR与IRR的正相关性表明结论改变伴随系统性推理扭曲，而非随机噪声。

## 关联研究分析

从问题动机看，本文与Beacon（Pandey et al., 2025）均关注隐性偏差，但Beacon聚焦RLHF导致的谄媚（Sycophancy），即模型为迎合用户而牺牲事实；本文聚焦训练数据沉淀的关系偏见，属于无意识认知偏差而非策略性迎合。Beacon通过强制选择隔离单轮偏差，本文通过长程推理捕捉累积效应，差异源于任务复杂度：谄媚在单轮即可显现，而关系偏见需多步推理才能充分渗透。

从方法设计看，本文与Shared Sycophancy-Lying Circuit（Pandey, 2026）均试图揭示内部机制，但后者通过因果干预定位共享注意力头，属白盒机制解释；本文通过IRR间接推断过程污染，属黑盒行为评估。这种差异反映了任务特性：谄媚与说谎可能存在共享神经回路，而关系偏见可能分布于更广泛的推理路径中，难以通过单一电路定位。IRR依赖外部裁判模型，其自身偏见是否影响“污染”判定，论文未给出回答。

## 总结

本文核心矛盾在于当前对齐机制抑制了显式身份偏见，却对隐性关系偏见形成盲视，导致模型在复杂推理中结论与过程均受无关信息扭曲。切入点在于构建中性化基准并分离结论与过程评估，通过DIR与IRR双指标量化偏见传播。实验证明关系偏见IRR达~58%，是身份偏见的4.8倍，且MoE架构更脆弱。边界在于评估依赖单一裁判模型，且未验证任何缓解策略的有效性。当引入针对关系偏见的专项对齐训练后，IRR能否显著降低，论文未给出回答。
