# ACL-Findings2026最新论文 ｜Inject to Heal: Alleviating hallucination in LVLMs via Context Embedding Injection ｜上下文嵌入注入

作者：Mehrdad Fazli、Bowen Wei、Ziwei Zhu

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_9f9185eac5ff)

> 大视觉语言模型（LVLMs）在开放生成中常因语言先验压制视觉信号而产生对象幻觉，现有推理时干预方法多聚焦于Logits层对比或注意力校准，难以在长序列生成中维持稳定的视觉接地。本文切入点在于发现真实Token比幻觉Token更早稳定概率质量的“承诺深度差距”，并据此提出无需训练的上下文嵌入注入（Context Embedding Injection, CEI）策略。该方法通过复用初始前向传播的隐状态作为接地锚点，动态调整解码过程中的隐状态混合权重，以抑制幻觉。CEI在CHAIR、AMBER和MMHal-Bench上优于主流基线，但其对超参数的依赖及在判别式任务上的表现未经验证。

## 研究背景

当LVLMs处理图像描述任务时，视觉编码器提取的特征需经对齐模块映射至语言空间，这一过程易引入语义纠缠，导致模型在视觉证据模糊时过度依赖文本共现统计规律。这种语言先验（Language Prior）与视觉证据的冲突，使得模型倾向于生成统计上更可能但视觉上未出现的物体，即对象幻觉。为量化这一现象，CHAIR指标通过对比生成描述与Ground Truth对象，计算句子级（CHAIRs）和实例级（CHAIRi）幻觉率，成为评估生成式幻觉的标准基线。

主流缓解路线分为训练时对齐与推理时干预两类。训练时方法如DPO依赖高质量偏好数据，成本高且泛化性受限；推理时方法如视觉对比解码（VCD）通过对比原始与扰动输入的Logits分布抑制幻觉，但需额外前向传播，计算开销大且超参数敏感。注意力校准方法如CAAC虽降低了开销，但在长序列生成中仍面临视觉信号衰减导致的幻觉累积问题。现有方法多从Logits层或注意力层介入，缺乏对解码过程中Token概率质量形成动态机制的深入理解，导致干预策略缺乏针对性。

本文基于机制可解释性视角，利用Logit Lens技术追踪解码层间Token偏好形成过程，发现真实Token在中间层即稳定概率质量，而幻觉Token则表现出延迟承诺特征。这一“承诺深度差距”揭示了幻觉产生的内部动力学机制，为设计自适应干预策略提供了理论依据。CEI方法正是基于此发现，将初始输入处理的隐状态作为视觉接地信号，在解码过程中动态注入，以维持生成内容与视觉输入的一致性。

## 核心方法

### 方法参照系

推理时干预的主流范式是在Logits层或注意力层进行校正，如VCD对比扰动输入Logits，CAAC调整注意力权重。本文问题与该通用流程的关键差异在于：不修改输出分布或注意力矩阵，而是直接干预解码器内部的隐状态空间，通过注入视觉接地信号来锚定Token预测，从而在表征层面维持视觉忠实度。

### 静态上下文嵌入注入

静态CEI的核心在于复用初始前向传播的隐状态作为接地锚点。在生成开始前，对多模态输入 $X_0 = [V; P]$ 执行一次前向传播，提取最后提示Token在最终解码层的隐状态 $c = h^{(L)}_{N_v+N_p}$ 作为上下文嵌入。该向量编码了查询对齐的视觉信息，直接决定首个生成Token的Logits分布。在解码步骤 $t$，于选定层 $\ell_{inj}$ 将当前隐状态 $h^{(\ell_{inj})}_t$ 与 $c$ 进行加权混合：

$$ \tilde{h}^{(\ell_{inj})}_t = (1 - \alpha) h^{(\ell_{inj})}_t + \alpha c $$

其中 $\alpha \in [0, 1]$ 为固定混合权重。这一设计解决了VCD等方法需额外前向传播计算对比Logits的高开销问题，仅需一次轻量级向量加法即可实现视觉信号增强，且无需修改模型权重。

### 动态上下文嵌入注入

静态CEI对所有Token施加均匀注入，但功能Token（如介词）与内容Token（如物体名）对视觉输入的依赖程度不同。动态CEI利用“承诺深度差距”信号，根据当前Token的置信度动态调整注入强度。首先，通过探针前向传播计算当前Token的平均Top-K概率质量 $\bar{M}_K$，该值反映模型对最终决策集的承诺程度。随后，利用半余弦调度将 $\bar{M}_K$ 映射为动态权重 $\alpha_t$：

$$ \alpha_t = \min\left(\alpha_{max} \cos\left(\frac{\pi \bar{M}_K}{\beta}\right), 0\right) $$

当 $\bar{M}_K$ 较低（信号高幻觉风险）时，$\alpha_t$ 增大，强化视觉接地；当 $\bar{M}_K$ 较高时，$\alpha_t$ 减小，保留语言流畅性。混合隐状态更新为 $\tilde{h}^{(\ell_{inj})}_t = (1 - \alpha_t) h^{(\ell_{inj})}_t + \alpha_t c$。这一机制解决了静态注入在功能Token上过度校正、在内容Token上校正不足的问题，实现了基于生成动态的自适应视觉接地。

## 实验评估

实验在InstructBLIP、LLaVA-1.5和LLaVA-NeXT三个7B参数LVLMs上进行，基准包括CHAIR、AMBER和MMHal-Bench，最大生成Token数设为512以捕捉长序列幻觉。基线覆盖对比解码（VCD, M3ID, AvisC）、注意力校准（CAAC）及束搜索变体（OPERA），但未包含2026年最新的RUDDER或HulluEdit等方法。

| :--- | :--- | :--- | :--- | :--- |
| base | 55.2 | 17.6 | 55.6 | 16.6 |
| + VCD | 57.8 | 16.3 | 60.8 | 17.9 |
| + CAAC | 39.2 | 10.4 | 37.4 | 10.8 |
| + Stat. CEI | 32.4 | 8.5 | 35.2 | 13.8 |
| + Dyn. CEI | 32.2 | 8.7 | 34.0 | 10.9 |

在CHAIR基准上，动态CEI在LLaVA-1.5上取得32.2的CHAIRs，较基线55.2降低23.0，优于CAAC的39.2。值得注意的是，VCD在LLaVA-1.5上的CHAIRs为57.8，高于基线，表明对比解码在该模型上可能引入负迁移。动态CEI在InstructBLIP上的CHAIRi为10.9，略高于静态CEI的13.8，显示动态调整在实例级幻觉抑制上具有优势。

| :--- | :--- | :--- | :--- |
| base | 11.3 | 48.1 | 50.4 |
| + CAAC | 6.0 | 25.0 | 48.7 |
| + Stat. CEI | 6.1 | 31.7 | 53.4 |
| + Dyn. CEI | 5.6 | 51.9 | – |

在AMBER基准上，动态CEI的CHAIR值为5.6，低于CAAC的6.0，但HAL值51.9显著高于基线48.1和CAAC的25.0，表明动态CEI在降低对象幻觉频率的同时，可能增加了响应级幻觉的发生率。COVER值缺失，无法评估完整性影响。这一结果揭示了幻觉抑制与响应质量之间的潜在权衡，动态调整虽提升了对象级忠实度，但可能牺牲了整体响应的连贯性。

评估协议局限在于仅使用生成式基准，未涵盖POPE等判别式任务，无法全面反映模型在对象存在性判断上的表现。超参数 $\alpha_{max}$ 和 $\beta$ 需针对每个LVLM手动调整，如InstructBLIP设为0.4和0.7，LLaVA-1.5设为0.25和0.55，缺乏自动化搜索机制。代码已开源，但GPU配置和训练细节未在正文中详述，可复现性依赖附录信息。

## 关联研究分析

从方法设计看，CEI与VCD的核心差异在于干预层级与信号来源。VCD通过对比原始与扰动输入的Logits分布，在输出层抑制语言先验，需额外前向传播计算扰动Logits，计算开销大且对超参数敏感。CEI则在隐状态层注入初始前向传播的接地信号，无需额外前向传播，计算开销低。然而，VCD的对比机制能动态适应不同输入，而CEI依赖固定的上下文嵌入，在视觉信息复杂或模糊时可能缺乏灵活性。CEI的优势在于低开销和模型无关性，但VCD在长序列生成中可能因持续对比而维持更稳定的视觉接地，论文未提供长序列下的直接对比数据。

从问题动机看，CEI与CAAC均针对注意力失衡导致的幻觉，但机制不同。CAAC通过校准跨模态注意力权重，直接调整视觉Token的注意力分配，属于注意力层干预。CEI则通过注入隐状态，间接影响后续层的注意力计算，属于表征层干预。CAAC的校准策略基于注意力分布的统计特性，而CEI基于“承诺深度差距”这一内部动力学信号。CEI的动态调整机制更精细，能根据Token置信度自适应调整注入强度，而CAAC的校准通常是全局或层级的。然而，CAAC在MMHal-Bench上的HR值为0.53，低于动态CEI的0.57，表明注意力校准在综合幻觉评估上可能更稳健。CEI在AMBER HAL值上的劣势（51.9 vs 25.0）暗示，隐状态注入可能在抑制对象幻觉的同时，干扰了模型对属性或关系幻觉的处理，这一现象在CAAC中未出现。

## 总结

本文核心矛盾在于推理时干预方法在长序列生成中难以维持稳定的视觉接地，现有Logits层或注意力层干预缺乏对解码动态机制的针对性。CEI抓住“承诺深度差距”这一内部信号，通过复用初始隐状态作为接地锚点，在表征层实现自适应视觉接地。实验证明，动态CEI在CHAIRs上较基线降低23.0，在AMBER CHAIR上优于CAAC，验证了隐状态注入的有效性。然而，动态CEI在AMBER HAL值上显著高于基线，表明其在抑制对象幻觉的同时可能增加了响应级幻觉，且超参数需手动调整，缺乏自动化机制。当视觉输入包含复杂属性或关系时，隐状态注入是否仍能维持细粒度幻觉的抑制，论文未给出回答。
