# ACL-Findings2026最新论文 ｜ClimAgent: LLM as Agents for Autonomous Open-ended Climate Science Analysis ｜气候科学自主智能体

研究机构：香港科技大学、山东大学

作者：Hao Wang、Jindong Han、Wei Fan 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.16922)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.16922)

> 气候分析面临物理约束复杂与数据驱动特性双重挑战，现有LLM智能体多局限于简单问答，缺乏对物理机制的深度建模能力。本文切入点在于构建专用气候环境（Climate Environment, CE）以提供物理接地，并通过四阶段闭环流程实现开放式气候问题的端到端求解。ClimAgent通过检索增强与任务特定优化确保物理一致性，并在自建基准ClimaBench上验证了其相对于通用智能体的优越性。该工作填补了气候领域数据驱动基准的空白，但其泛化能力与多模态适配性仍存疑。

## 研究背景

气候科学分析的核心困境在于物理约束的严格性与数据处理的复杂性。当模型试图从气象数据中推导污染扩散或台风路径时，必须同时满足流体动力学方程与边界条件，这要求系统具备从非结构化描述中提取物理约束的能力。然而，通用大语言模型（Large Language Models, LLMs）在缺乏外部接地时，往往依赖模式匹配而非逻辑推导，导致在涉及强物理相关性的气候数据中产生幻觉或逻辑断裂。

自主科研智能体（Agentic Science）旨在赋予LLM自主感知、规划与执行实验的能力，已在生物医学与化学领域取得进展。然而，现有框架如DS-Agent或ResearchAgent主要面向通用数据科学或机器学习任务，其工具库与推理协议未针对气候科学的物理特性进行优化。直接应用这些通用智能体时，模型难以识别气候问题中隐含的物理方程与专用数据库，导致建模过程缺乏科学严谨性。此外，现有气候相关LLM研究多局限于知识问答（Q&A），无法评估模型在数据驱动、开放式建模任务中的真实能力，这一评测空白阻碍了该领域的系统性进步。

## 核心方法

### 方法参照系

本文问题属于自主科研智能体路线，但区别于通用数据科学智能体，其核心差异在于必须处理强物理约束下的开放式建模。通用流程侧重于数据清洗与统计建模，而气候分析要求从非结构化查询中显式提取物理方程并验证其一致性，这构成了本文方法设计的根本约束。

### 气候环境构建与检索

设计动机在于解决LLM在气候建模中因缺乏领域知识而导致的物理约束缺失问题。ClimAgent构建了统一的气候环境（CE），包含30个高保真数据库、150个专用工具及海量文献报告。对于子任务 $D_i$，系统生成语义查询向量 $q_i$，执行混合检索机制：

$$ K_i = \text{Retrieval}(q_i, \text{CE}) = \{T_{top-k}, I_{task}, E_{phys} \} $$

其中 $T_{top-k}$ 为最相关的可执行工具，$I_{task}$ 为任务相关信息，$E_{phys}$ 为控制物理方程。该机制将检索结果作为物理接地边界，防止代码生成阶段出现不存在的科学方法，确保操作可行性与物理一致性。

### 任务特定方案优化

设计动机在于弥补检索知识缺乏针对具体非线性约束与多目标优化深度的问题。在获得上下文 $K_i$ 后，系统初始化建模方案 $M_i^{(0)} = \pi(D_i, K_i)$，随后进入迭代优化循环。Critic模块从物理一致性（如守恒律）与边界条件有效性角度生成反馈 $F_i^{(t)}$：

$$ M_i^{(t+1)} = \pi(M_i^{(t)}, F_i^{(t)}) $$

该迭代过程持续至满足验证标准或达到最大阈值 $N_{max}$。通过显式评估物理一致性而非仅代码语法，该机制确保了最终模型在数学鲁棒性与科学物理基础上的双重可靠性，解决了通用代码审查器无法捕捉领域特定逻辑谬误的问题。

## 实验评估

实验在自建基准ClimaBench上进行，该基准包含220个源自2000-2025年真实气候事件的开放式问题，分为2000-2024与2025两个子集以缓解数据泄露。基线包括DS-Agent、ResearchAgent、Agent Laboratory及DeepAnalyze等通用智能体，以及GPT-4o、DeepSeek-R1-671B、Qwen3-235B等基础模型直接调用。

| 方法 | 2000-2024 Overall | 2025 Overall |
| :--- | :--- | :--- |
| GPT-4o (Direct) | 7.34 | 7.48 |
| DS-Agent | 7.35 | 7.15 |
| ResearchAgent | 7.91 | 7.94 |
| Agent Laboratory | 7.35 | 7.15 |
| DeepAnalyze | 7.34 | 7.48 |
| **ClimAgent (GPT-4o)** | **8.92** | **8.47** |
| **ClimAgent (DeepSeek-R1)** | **8.95** | **9.02** |
| **ClimAgent (Qwen3-235B)** | **8.98** | **9.05** |

ClimAgent在所有骨干模型下均显著优于基线，其中DeepSeek-R1-671B版本在2025年子集上取得9.02的最高分，较GPT-4o直接调用提升约1.54分。消融实验表明，移除气候环境（CE）导致所有指标显著下降，证实了专用动作空间对物理推理的关键作用；移除任务特定优化（CM）则主要影响模型严谨性（MR）与问题求解（PS），凸显其在构建连贯科学模型中的核心价值。

评估边界方面，ClimaBench为自建基准，缺乏与HLE Bio/Chem等通用科学基准的交叉验证，难以直接对比跨领域泛化能力。代码已开源，但论文未报告计算成本的具体数值（如Token消耗率或推理延迟），仅定性指出其成本效率优于基线，缺乏量化指标支持部署可行性评估。

## 关联研究分析

从问题动机看，ClimAgent与ChemCrow同属工具增强型智能体，但二者在接地对象上存在根本差异。ChemCrow集成的是通用化学工具库，侧重于反应路径预测；而ClimAgent构建的气候环境（CE）专门针对物理方程与气象数据库，其检索机制显式包含物理一致性验证。这种差异源于气候科学对物理定律的刚性约束，通用工具库无法提供守恒律等深层物理反馈，导致ClimAgent必须引入任务特定优化模块来弥补检索知识的深度不足。

从方法设计看，ClimAgent与AI Scientist均实现端到端科研闭环，但AI Scientist侧重文献综述与假设生成的自动化，其评估指标多基于文本相似度或人工评分；ClimAgent则聚焦数据驱动的数值建模，其评估核心是代码执行结果与物理方程的匹配度。这一差异反映了从“知识发现”到“物理建模”的任务范式转移，ClimAgent的评估协议更贴近工程实践，但牺牲了对假设新颖性的评估，导致其无法衡量模型在提出全新气候理论方面的能力。

## 总结

ClimAgent旨在解决LLM在气候分析中物理推理能力不足与缺乏数据驱动基准的双重矛盾。其切入点在于构建专用气候环境（CE）提供物理接地，并通过任务特定优化确保建模方案的物理一致性。实验证明，ClimAgent在ClimaBench上Overall得分达8.92-9.05，显著优于通用智能体基线。然而，其边界在于评估局限于自建基准，缺乏跨领域泛化验证，且未量化计算效率指标。当气候问题涉及多模态数据（如卫星云图）时，当前基于文本与代码的框架是否仍能维持物理推理的准确性，论文未给出回答。
