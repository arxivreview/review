# ACL-Findings2026最新论文 ｜DiFRa: A Unified Framework for Harmonizing Semantic Diversity and Factual Consistency in Question-Answer Generation ｜问答生成中的语义多样性与事实一致性调和框架

研究机构：澳门大学

作者：Zhenqin Li、ShengYong Ding、Shuangyin Li

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_d8330da61917)

> 问答生成（QAG）旨在为垂直领域大语言模型（LLM）后训练提供高质量数据，但现有方法往往陷入“保守复制”导致的语义贫乏或“自由生成”引发的幻觉风险。本文指出，单纯追求多样性或一致性均无法解决训练数据中“信息增益”与“事实兼容”的内在张力。DiFRa 框架通过连续概念扩散与离散知识图谱约束的动态融合，在冻结 LLM 骨干的前提下实现了两者的平衡。该框架在 SQuAD 和 DROP 上优于多种基线，但其对 LLM 自身构建知识图谱的依赖，可能引入闭环幻觉风险。

## 研究背景

垂直领域 LLM 后训练面临数据冷启动困境，通用预训练模型难以直接迁移至特定场景。高质量问答对需同时具备语义多样性以覆盖长尾分布，以及事实一致性以确保训练信号的正确性。从线性代数视角看，模型训练可视为求解欠定系统，生成的问答对作为约束条件：语义多样性引入线性独立约束以提升系统秩，而事实一致性确保新增约束不与原有事实矛盾，避免系统不相容。

早期 QAG 方法多采用多阶段流水线或端到端生成，但存在错误传播或分布狭窄问题。变分潜变量模型通过随机采样增强多样性，而往返过滤或程序图方法则侧重约束一致性。然而，现有工作大多偏向单一目标，缺乏对两者权衡的系统性优化。DiFRa 的切入点在于将 QAG 建模为连续潜空间扩散与离散图约束的联合优化问题，旨在同时最大化信息增益并严格保证事实边界。

## 核心方法

### 方法参照系

标准 QAG 流程通常将上下文直接输入 LLM 生成问答对，或采用提示工程（如 CoT、Self-QA）引导生成。本文的关键差异在于引入外部结构化约束：不直接依赖 LLM 的内部隐式知识，而是显式构建概念嵌入与知识图谱，通过动态融合机制干预生成过程，且骨干 LLM 保持冻结。

### 概念构建与扩散（CCD）

CCD 模块解决“保守生成”导致的语义贫乏问题。传统方法直接复制源文本片段，缺乏语义变体。DiFRa 首先通过主题建模和关键词提取构建概念集 $Z_i = W_i \cup K_i$，其中 $W_i$ 为主题词，$K_i$ 为关键短语。随后，利用连续扩散模型在潜空间对概念进行泛化。去噪网络预测噪声残差，训练目标为最小化均方误差：

$$ \mathcal{L}_{DIFF} = \mathbb{E}_{x_0, \epsilon \sim \mathcal{N}(0, I), t} \left[ \| \epsilon - \epsilon_\theta(x_t, t, W_C) \|^2 \right] $$

该公式通过重构从噪声中恢复的概念嵌入，确保生成的语义变体在连续空间中具有丰富性，从而打破源文本的分布限制。

### 事实约束构建（FCC）与动态融合（DCAM）

FCC 模块解决“自由生成”导致的幻觉问题。LLM 从上下文构建初始知识图谱 $G_i$，并通过精炼步骤压缩冗余三元组，得到高密度事实图谱 $G_i^*$。DCAM 机制将 CCD 输出的多样概念嵌入 $\hat{Z}_i$ 与 FCC 输出的图谱嵌入 $E_G$ 融合。最终生成目标函数结合语言建模损失与扩散损失，采用不确定性自适应加权：

$$ \mathcal{L} = \frac{1}{2\sigma_1^2} \mathcal{L}_{LM} + \frac{1}{2\sigma_2^2} \mathcal{L}_{DIFF} + \sum_{j=1}^2 \log \sigma_j $$

此设计允许模型在生成过程中动态权衡语义探索与事实约束，避免单一目标主导导致的性能偏斜。

## 实验评估

实验在 DROP 和 SQuAD 验证集上进行，对比基线包括 CoT、Self-QA 及多种参数高效微调（PEFT）方法（Prompt/Prefix/P-Tuning），并纳入 GPT-4o、DeepSeek 等闭源模型作为参照。

| 方法 | 骨干 | DROP B-4 | DROP R-L | SQuAD B-4 | SQuAD R-L |
| :--- | :--- | :--- | :--- | :--- | :--- |
| CoT | Llama3.18B | 31.63 | 31.36 | 36.24 | 37.74 |
| P-Tuning | Llama3.18B | 34.65 | 34.17 | 39.79 | 39.81 |
| DiFRa | Llama3.18B | 35.62 | 35.55 | 40.59 | 41.00 |
| CoT | Mistral7B | 28.62 | 30.00 | 31.27 | 34.80 |
| P-Tuning | Mistral7B | 34.03 | 33.94 | 41.02 | 41.02 |
| DiFRa | Mistral7B | 36.92 | 36.64 | 41.74 | 41.98 |

DiFRa 在两个骨干模型上均优于所有 PEFT 基线，且在 DROP 上显著领先于 CoT。消融实验显示，移除 FCC 模块导致事实一致性（FC）下降 2.45%，而移除 CCD 模块导致语义熵（SE）下降 7.87%，证实了双模块的必要性。

评估边界方面，论文提出的 SeFa 指标（语义熵与事实一致性的调和平均）旨在量化权衡，但缺乏与人类判断的相关性验证。代码已开源，但扩散模型的训练超参数（如时间步 T）对最终性能的影响未详细披露，可复现性依赖于特定实现细节。

## 关联研究分析

从问题动机看，DiFRa 与 BoostQA 均致力于解决合成数据同质性问题，但路径截然不同。BoostQA 采用多角色虚拟教师模拟，通过语义重解释扩展数据规模，侧重“量”的突破；而 DiFRa 通过数学约束优化，侧重“质”的平衡。BoostQA 依赖种子数据的多样性，DiFRa 依赖上下文的结构化提取。这种差异源于任务特性：BoostQA 适用于中期训练的大规模数据增强，而 DiFRa 更适用于对事实准确性要求极高的垂直领域后训练。

从方法设计看，DiFRa 与 RAG 架构存在本质冲突。RAG 通过外部检索引入事实依据，而 DiFRa 将事实约束内化为 LLM 生成的知识图谱。RAG 的优势在于检索器可独立优化，降低幻觉闭环风险；DiFRa 的劣势在于知识图谱构建依赖 LLM 自身能力，若 LLM 存在固有偏见，图谱将继承这些错误。这种“内化”策略在低资源场景下具有效率优势，但在高可靠性要求场景下，其鲁棒性弱于基于外部知识库的 RAG 系统。

## 总结

DiFRa 针对 QAG 中语义多样性与事实一致性的权衡矛盾，提出了一种融合连续扩散与离散图谱约束的统一框架。通过 CCD 模块在潜空间采样多样概念，FCC 模块构建精炼事实图谱，DCAM 机制动态融合两者，DiFRa 在冻结 LLM 骨干下实现了性能提升。实验表明，DiFRa 在 SQuAD 上的 B-4 分数达到 40.59（Llama3.18B），优于 P-Tuning 的 39.79。然而，该方法的核心局限在于知识图谱构建对 LLM 的依赖，可能导致事实错误的闭环传播。当上下文包含复杂或矛盾信息时，LLM 生成的图谱是否仍能保持事实纯净，论文未提供针对此类对抗性场景的验证。
