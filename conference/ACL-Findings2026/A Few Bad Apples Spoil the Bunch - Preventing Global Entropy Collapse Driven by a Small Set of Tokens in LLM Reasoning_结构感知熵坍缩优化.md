# ACL-Findings2026最新论文 ｜A Few Bad Apples Spoil the Bunch: Preventing Global Entropy Collapse Driven by a Small Set of Tokens in LLM Reasoning ｜结构感知熵坍缩优化

作者：Jaeeun Jang、Hansle Lee、Sangmin Kim

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_b17ccd6aff8e)

> 强化学习后训练在提升大语言模型单样本推理准确率的同时，往往导致推理路径多样性坍缩，进而削弱测试时扩展（Test-Time Scaling, TTS）的有效性。现有熵正则化方法多采用均匀或启发式策略，未能精准定位引发全局熵衰减的局部关键节点。本文通过 GRPO 策略优化的 logit 坐标精确分解，识别出仅占 5% 的“分支定义”token 是熵坍缩的主要驱动力，并据此实施选择性 KL 正则化。该方法在数学推理基准上同时提升了 Pass@1 与 Pass@k，但其在非可验证任务及更大规模模型上的泛化能力尚存疑。

## 研究背景

当模型通过强化学习（RL）优化推理能力时，策略分布会向高奖励轨迹集中，导致输出熵降低。这种熵坍缩并非均匀发生，而是集中在少数决定推理走向的关键 token 上。这些 token 的概率重分配不仅影响当前步骤，更通过后续依赖关系放大为全局多样性损失，使得多采样解码（如自一致性）陷入冗余重复，无法探索新的解空间。

RL 后训练面临的核心矛盾是探索与利用的平衡：提升单样本准确率（Pass@1）需要锐化策略分布，而维持测试时扩展潜力（Pass@k）则需要保留分布宽度。主流方法如 DA-PO 和 KL-Cov 试图通过全局熵正则化或基于协方差的启发式选择来缓解此问题，但前者在确定性步骤浪费正则化预算，后者缺乏对优化动态的精确理论支撑，导致选择准则与熵坍缩的实际成因脱节。本文切入点在于从 GRPO 更新规则的数学结构出发，推导 token 级重分配幅度的精确分解，从而将熵控制从“均匀保护”转向“精准干预”。

## 核心方法

### 方法参照系

本文问题属于 RL 后训练中的熵控制子问题，标准流程是在策略梯度目标中加入 KL 散度惩罚以限制策略偏离参考模型。关键差异在于，本文不将正则化视为全局约束，而是将其转化为基于 token 级重分配分数的选择性掩码操作，仅对预测将引发熵坍缩的特定 token 施加约束。

### 精确重分配分解

传统方法假设熵衰减由低概率 token 的大更新信号驱动，但本文通过 logit 坐标分析指出，期望重分配幅度由 $p_v(1-p_v)$ 主导。设计动机在于纠正“低概率即高风险”的直觉偏差，揭示中间概率区间的 token 才是熵坍缩的主要来源。

$$ S_v = L_v + R_v = 2\eta A_{\text{scale}} p_v(1-p_v) + \eta(1-2p_v) \text{Cov}_t(|\hat{A}(\tau)|, 1[y_t=v]) $$

该公式将期望重分配幅度 $S_v$ 分解为平滑几何项 $L_v$ 和 token-结果耦合残差 $R_v$。$L_v$ 仅依赖当前策略概率 $p_v$ 和全局优势尺度 $A_{\text{scale}}$，在 $p_v=0.5$ 时取最大值，表明中等置信度的 token 对分布形状影响最大；$R_v$ 捕捉 token 选择对下游结果的非线性影响，在分支定义点显著非零。

### 选择性 KL 正则化

基于上述分解，本文定义重分配分数 $s_{k,t} = p_{k,t}(1-p_{k,t})[\hat{A}_{k,t}]^+$，其中 $[\cdot]^+$ 表示取正优势部分。设计动机在于聚焦于“锐化”方向（正优势），因为负优势导致的概率分散不会引发熵坍缩。

$$ \mathcal{L}_{\text{SCOPE}} = \mathcal{J}_{\text{GRPO}}(\theta) - \lambda \frac{\sum_{(k,t)\in B} m_{k,t} D_{k,t}}{\sum_{(k,t)\in B} m_{k,t} + \epsilon} $$

其中 $m_{k,t}$ 为二值掩码，仅当 $s_{k,t}$ 位于批次内前 5% 分位数时为 1。该损失函数在标准 GRPO 目标上叠加了稀疏 KL 惩罚，仅对高重分配分数 token 施加约束。相比均匀正则化，此设计避免了在确定性步骤（$p_v \to 1$）上的无效干预，将正则化预算集中用于保护推理多样性关键节点。

## 实验评估

实验在 Qwen2.5 Base 模型（1.5B/3B/7B）上进行，使用 MATH 数据集（7,500 题）训练，评估 GSM8K、MATH500、AMC、AIME24/25 五个基准。基线覆盖 RLVR（Forking RL, DA-PO, KL-Cov）和 RLIF（Self-Certainty, Tok-Entropy, Traj-Entropy）两条路线，但未包含大规模 RL 训练的 SOTA 方法（如 PaCoRe）作为直接对比，限制了绝对性能评估。

| 模型 | 方法 | GSM8K | MATH500 | AIME25 |
|---|---|---|---|---|
| Qwen2.5-7B | Baseline (RLVR) | 0.825 | 0.715 | 0.083 |
| Qwen2.5-7B | + SCOPE | 0.884 | 0.770 | 0.123 |
| Qwen2.5-7B | Baseline (RLIF) | 0.742 | 0.598 | 0.033 |
| Qwen2.5-7B | + SCOPE | 0.852 | 0.680 | 0.073 |

在 7B 规模下，SCOPE 在 RLVR 设置下将 AIME25 准确率从 0.083 提升至 0.123，MATH500 从 0.715 提升至 0.770；在 RLIF 设置下，AIME25 从 0.033 提升至 0.073，相对提升幅度更大，印证了置信度内在奖励对熵坍缩的更强压力。

消融实验显示，正则化比例 $q$ 在 5% 时性能最优，超过 5% 后准确率下降，表明熵坍缩驱动 token 高度稀疏。对比不同选择策略，SCOPE 在相同 5% 预算下优于 Uniform、Forking 和 KL-Cov，证明“选择哪些 token”比“正则化多少 token”更关键。Non-Forking 策略性能最差，进一步验证了分支定义 token 的核心地位。

评估边界方面，论文未报告置信区间，且仅在数学推理任务上验证。代码未公开，但基于 Open-R1 框架，超参数细节在附录中提供。由于未与大规模 RL 方法对比，SCOPE 的绝对性能上限未知，其价值主要体现在同骨干模型下的相对提升。

## 关联研究分析

从问题动机看，本文与 KL-Cov（Cui et al., 2025）均关注熵坍缩的机制性解释，但 KL-Cov 依赖协方差启发式选择，而 SCOPE 基于精确的 logit 坐标分解。差异根源在于理论严谨性：KL-Cov 的协方差信号可能受批次噪声影响，而 SCOPE 的 $p_v(1-p_v)$ 项是策略分布的固有几何属性，对优化动态更具鲁棒性。然而，SCOPE 假设优势函数 $\hat{A}(\tau)$ 能准确反映 token 重要性，这在开放域任务中可能失效，因为内在置信度信号本身存在校准偏差。

从方法设计看，本文与 Forking RL（Wang et al., 2025）同属 token 级选择策略，但 Forking RL 基于熵阈值选择高熵 token，而 SCOPE 基于重分配分数选择高影响 token。差异在于选择准则的物理含义：高熵 token 不一定导致熵坍缩（可能只是探索性步骤），而高重分配分数 token 直接驱动分布锐化。这一区别解释了为何 SCOPE 在相同预算下性能更优。但 SCOPE 的分数计算依赖优势函数，在 RLIF 设置下，内在奖励的噪声可能污染分数估计，论文未深入探讨此风险。

## 总结

本文核心矛盾是 RL 后训练中单样本准确率与推理多样性的权衡，现有方法因缺乏对熵坍缩局部驱动因素的精确刻画而失效。本文通过 GRPO 更新的 logit 坐标分解，识别出中间概率区间的分支定义 token 是熵坍缩主因，并据此实施选择性 KL 正则化。实验证明，仅对 5% 的 token 施加约束即可在数学基准上同时提升 Pass@1 与 Pass@k，7B 模型 AIME25 准确率从 0.083 提升至 0.123。其边界在于仅验证了可验证数学任务，且未与大规模 RL 方法对比，绝对性能上限未知。当优势函数在开放域任务中校准偏差增大时，重分配分数的判别力是否仍具鲁棒性，论文未给出回答。
