# ACL-Findings2026最新论文 ｜SGG-R 3: From Next-Token Prediction to End-to-End Unbiased Scene Graph Generation ｜场景图生成中的结构化推理与长尾去偏

研究机构：北京大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f9ff98da5e30)

> 场景图生成（SGG）旨在将视觉内容转化为由对象节点和关系边组成的结构化图，其核心价值在于为视觉问答、机器人导航等高层推理任务提供可解释的语义桥梁。现有基于多模态大语言模型（MLLM）的端到端方法虽消除了两阶段误差累积，却因缺乏任务特定的结构化推理流程而陷入巨大的搜索空间，同时受限于关系数据的稀疏性与长尾分布，导致生成结果召回率低且偏向高频谓词。本文提出 SGG-R3 框架，通过三阶段结构化思维链（CoT）引导监督微调（SFT），并结合类型感知关系增强与双重粒度奖励的强化学习（RL），实现端到端的无偏场景图生成。该框架在 Visual Genome 和 Panoptic Scene Graph 基准上显著提升了长尾关系识别能力，但其对推理延迟的忽视及未对比最新去偏基线，限制了其在实时具身智能场景中的直接适用性。

## 研究背景

当 MLLM 直接处理 SGG 任务时，模型需在无边界框提示的情况下同时定位对象并预测关系。这一过程若缺乏显式的步骤约束，模型极易在庞大的组合空间中迷失，产生幻觉或遗漏关键对象。为应对此问题，思维链（Chain-of-Thought, CoT）技术被引入视觉推理，通过分解复杂问题为中间步骤来引导模型产生增量式解决方案。然而，通用 CoT 指令（如“逐步思考”）无法适应 SGG 密集预测的特性，导致结构化输出失败率高，且无法有效缓解关系标注中固有的长尾分布偏差。

传统 SGG 方法遵循两阶段范式，先检测对象再分类关系，虽思路清晰但受制于误差累积。随着 Transformer 架构的引入，一阶段端到端方法成为主流，通过联合预测提升了效率。然而，这些分类范式方法在开放词汇和长尾关系上泛化能力有限。近期，MLLM 驱动的生成式 SGG 兴起，如 R1-SGG 和 Relation-R1，它们通过 SFT 和 RL 优化输出，但仍未解决关系稀疏导致的冷启动问题，且缺乏针对 SGG 任务特性的结构化推理机制。本文切入点在于：将 SGG 重构为具备明确阶段约束的生成任务，通过数据增强缓解稀疏性，并通过阶段对齐的奖励函数在 RL 中显式优化长尾关系识别。

## 核心方法

### 方法参照系

本文问题属于“通用生成与优化”路线，其标准流程为：基于 MLLM 的 SFT 学习结构化输出，随后通过 RL 优化特定目标。本文与该通用流程的关键差异在于：在 SFT 前引入类型感知关系增强以解决数据稀疏，并在 SFT 和 RL 中嵌入三阶段结构化推理（类别检测-实例定位-关系提取），替代直接生成，从而缩小搜索空间并提升结构完整性。

### 三阶段结构化推理与关系增强

设计动机：通用 CoT 指令无法约束 MLLM 在 SGG 中的密集预测行为，导致对象定位不准和关系提取遗漏。本文在 SFT 阶段引入三阶段结构化推理，将无序的 SGG 过程系统化为顺序流水线。首先，模型仅识别图像中存在的对象类别，缩小搜索空间；其次，基于类别集进行实例定位，按类别顺序检测所有实例；最后，提取多类型关系三元组。为缓解关系稀疏，本文利用 Qwen2.5-VL-32B 生成候选关系，并通过 Sentence-BERT 嵌入相似度过滤，保留与原始数据语义对齐的样本。过滤机制定义为：

$$ A(t) = \mathbb{I} \left[ \exists t_{gt} \in T_{gt} : \text{sim}(e_t, e_{t_{gt}}) \ge \theta \right] $$

其中 $e_t$ 为生成三元组的嵌入，$T_{gt}$ 为真实三元组集合，$\theta$ 为阈值。该机制确保增强数据的质量，为 RL 提供鲁棒初始化。

### 双重粒度奖励与 GSPO 优化

设计动机：标准 RL 奖励函数难以同时优化关系召回和语义覆盖，且 token 级重要性采样在长序列生成中不稳定。本文提出双重粒度奖励，结合细粒度频率自适应加权（缓解长尾偏差）和粗粒度语义聚类（提升覆盖）。细粒度奖励中，谓词相似度 $sim_j$ 计算为：

$$ sim_j = \text{sim}_t(e_{t_j}, e_{t_i}) \times \text{sim}_p(e_{p_j}, e_{p_i}) $$

其中 $\text{sim}_t$ 和 $\text{sim}_p$ 分别为三元组和谓词的余弦相似度。为增强优化鲁棒性，本文采用 Group Sequence Policy Optimization (GSPO)，将 token 级重要性比率替换为序列级几何均值：

$$ s_i(\theta) = \exp \left( \frac{1}{|y_i|} \sum_{t=1}^{|y_i|} \log \frac{\pi_\theta(y_{i,t}|x, y_{i,<t})}{\pi_{\theta_{old}}(y_{i,t}|x, y_{i,<t})} \right) $$

该公式通过序列级比率稳定长 JSON 输出的优化过程，避免 token 级噪声导致的训练不稳定。

## 实验评估

实验在 VG150 和 PSG 基准上进行，采用 SGDET 协议，指标为 Recall、mRecall 和 zsRecall。基线覆盖非 VLM 方法（如 SGTR, EGTR）和 VLM 方法（如 R1-SGG, OwSGG），但缺失 FlowSG 和 Salience-SGG 等 2026 年最新去偏方法。主结果显示，SGG-R3 3B SFT+RL 在 VG150 上达到 50.07% Recall，显著超越 R1-SGG 7B SFT+RL 的 23.75%；在 PSG 上达到 61.32% Recall，超越 R1-SGG 7B 的 43.48%。

| R1-SGG† SFT + RL | 7B | 23.75 | 11.43 | 43.48 | 33.71 |

消融实验表明，关系增强（RA）在 SFT 阶段显著提升 Body 和 Tail 谓词识别，VG150 上分别提升 8.77% 和 4.43%。在 RL 阶段，RA 使 Tail 性能在 VG150 上提升 3.37%，在 PSG 上提升 9.37%。值得注意的是，无 RA 的 RL 训练在 PSG 上 zsRecall 为 0.00%，而加入 RA 后提升至 7.69%，证明 RA 对长尾关系冷启动的关键作用。

评估边界方面，本文未报告推理延迟，仅关注精度，与实时具身智能需求存在潜在矛盾。可复现性方面，代码未公开，训练使用 8 块 NVIDIA A800 (40GB) GPU，基于 TRL 和 vLLM 库。指标完备性上，zsRecall 仅衡量未见三元组，未包含幻觉率指标，难以全面评估开放词汇下的可靠性。

## 关联研究分析

从问题动机看，本文与 Salience-SGG 均针对长尾分布，但机制不同。Salience-SGG 通过显著性解码器迭代估计三元组显著性，区分高频和低频关系，属于显式去偏策略。本文则通过频率自适应加权奖励和关系增强，在生成过程中隐式缓解偏差。差异根源在于任务范式：Salience-SGG 基于分类范式，需显式模块处理偏差；本文基于生成范式，将去偏融入奖励函数。这种差异暗示，在开放词汇场景下，生成式方法的隐式对齐可能更灵活，但在封闭集长尾任务上，显式去偏的可解释性仍具优势。

从方法设计看，本文与 R1-SGG 同属 MLLM+RL 框架，但本文引入三阶段结构化 CoT 和双重粒度奖励。R1-SGG 使用通用 CoT 和图约束奖励，本文则细化为 SGG 专用的类别-实例-关系流程，并引入语义聚类奖励。差异根源在于对“关系本质”的理解：R1-SGG 视关系为图结构约束，本文视关系为语义序列生成。本文的结构化 CoT 显著降低了失败率（2B 模型失败率降低 57.23%），表明任务特定 CoT 在密集预测任务中的必要性。然而，本文未对比 FlowSG 等流匹配方法，后者通过去噪过程迭代精炼图结构，可能在结构一致性上具有优势，本文的自回归生成是否牺牲了全局结构优化，论文未给出回答。

## 总结

本文要解决的核心矛盾是 MLLM 在 SGG 中缺乏结构化推理导致的搜索空间过大，以及关系长尾分布导致的无偏生成困难。本文抓住的切入点是：将 SGG 分解为三阶段结构化推理，并通过数据增强和阶段对齐奖励在 SFT 和 RL 中显式优化长尾关系。本文做了什么：提出 SGG-R3 框架，结合类型感知关系增强、三阶段 CoT 和双重粒度奖励的 GSPO 优化。证明了什么：在 VG150 上，3B SFT+RL 模型 Recall 达 50.07%，超越 7B 基线 26.32%；在 PSG 上，zsRecall 从 0.00% 提升至 7.69%。本文的边界在于：未报告推理延迟，未对比最新去偏基线，且 zsRecall 指标无法全面评估幻觉抑制。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
