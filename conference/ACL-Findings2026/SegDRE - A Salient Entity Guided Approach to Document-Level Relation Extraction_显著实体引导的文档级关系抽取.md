# ACL-Findings2026最新论文 ｜SegDRE: A Salient Entity Guided Approach to Document-Level Relation Extraction ｜显著实体引导的文档级关系抽取

研究机构：同济大学

作者：Xing Yang、Chengxiang Tan

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_d07c691277e4)

> 文档级关系抽取（DocRE）面临负样本主导导致的训练失衡与跨句多跳推理断裂的双重瓶颈。现有方法多依赖全局图建模或损失函数修正，但未能利用文档中事实围绕少数核心实体聚集的拓扑特性。本文提出显著实体引导的解耦框架，通过识别枢纽实体将任务拆分为密集与稀疏子集，并注入密集三元组以桥接语义间隙。该策略在判别式基线上带来稳定增益，但其对单显著实体假设的依赖限制了其在多主题文档中的适用性。

## 研究背景

文档级关系抽取需处理实体间跨越多个句子的复杂依赖，其核心难点在于候选实体对数量随实体数呈二次方增长，而绝大多数对之间不存在关系。这种极端的类别不平衡使得模型在训练过程中被海量负样本淹没，导致正例召回率低下。同时，多跳推理要求模型捕捉中间实体的语义桥梁作用，仅靠局部上下文难以实现。

主流DocRE方法分为三类：增强表示能力（如GAIN、DREEAM）、优化损失函数（如ATL、HingeABL）以及插件式方法（如LogicRE）。前两类方法虽提升了全局建模或分类边界，但未改变候选空间的结构；插件方法虽引入逻辑规则，但计算开销大且泛化性受限。这些方法共同忽略了一个统计事实：文档中的关系事实并非均匀分布，而是高度集中在少数“显著实体”周围。本文的切入点正是利用这一拓扑特性，通过显式识别显著实体来重构学习空间，从而同时缓解不平衡与多跳推理难题。

## 核心方法

### 方法参照系

标准DocRE流程将文档编码为实体表示，通过双线性分类器预测所有实体对的关系概率。本文的关键差异在于，不再对所有 $O(n^2)$ 实体对进行统一建模，而是引入一个前置的显著实体识别步骤，将任务分解为两个异质子任务：涉及显著实体的密集抽取与不涉及显著实体的稀疏抽取。

### 显著实体识别与零膨胀泊松建模

传统方法直接使用分类头预测关系，无法量化实体参与关系的“程度”。本文设计了一个计数回归头，利用零膨胀泊松（Zero-Inflated Poisson, ZIP）模型来预测每个实体对的关系数量。由于文档中绝大多数实体对关系数为零，ZIP模型通过混合一个点质量于零和泊松分布，更准确地拟合这种稀疏计数数据。

$$
C \sim \begin{cases} 0, & \text{with probability } \pi \\ \text{Poisson}(\lambda), & \text{with probability } 1 - \pi \end{cases}
$$

该公式的物理含义是：以概率 $\pi$ 认为该实体对无关系，否则以泊松分布 $\lambda$ 预测关系数量。模型通过最小化负对数似然优化 $\pi$ 和 $\lambda$，最终聚合每个实体的预期关系计数，计数最高的实体被定义为显著实体 $e_{sal}$。这一设计解决了传统分类头无法区分“无关系”与“极少关系”的问题，为后续任务分解提供了统计依据。

### 密集-稀疏解耦与知识注入

识别出 $e_{sal}$ 后，密集阶段仅处理涉及 $e_{sal}$ 的 $O(n)$ 实体对，大幅缩减负样本干扰。稀疏阶段则处理剩余实体对，但直接建模面临多跳推理断裂问题。为此，本文采用K-Bert的知识注入机制，将密集阶段预测的高置信度三元组 $T_{dense}$ 注入原始文档，重构为增强文档 $D_{trans}$。

$$
D_{trans} = KInject(D, T_{dense}, \alpha)
$$

其中 $\alpha$ 控制注入比例。注入后的文档通过软位置索引和可见性矩阵，确保头尾实体能直接交互，从而显式桥接多跳路径。最终，密集、稀疏及基础模型的预测通过阈值网格搜索融合，得到最终结果。这一机制将密集阶段的语义知识转化为稀疏阶段的先验，解决了跨句证据不连续导致的推理失败。

## 实验评估

实验在DocRED和Re-DocRED基准上进行，对比基线包括ATLOP、DREEAM及其损失优化变体（如HingeABL、APRDL）。本文方法作为插件，可叠加于不同骨干模型之上。

| 方法 | 骨干 | DocRED Dev F1 | DocRED Test F1 | Re-DocRED Test F1 |
| :--- | :--- | :--- | :--- | :--- |
| ATLOP | BERT_base | 61.09 | 61.30 | - |
| ATLOP-Seg | BERT_base | 61.53 | 61.49 | - |
| DREEAM | BERT_base | 62.55 | 62.49 | - |
| DREEAM-Seg | BERT_base | 63.00 | 62.88 | - |
| ATLOP | RoBERTa_large | 63.18 | 63.40 | 77.73 |
| ATLOP-Seg | RoBERTa_large | 63.68 | 63.79 | 80.25 |
| DREEAM | RoBERTa_large | 64.20 | 64.27 | 77.94 |
| DREEAM-Seg | RoBERTa_large | 64.73 | 64.80 | 80.25 |
| DREEAM-Seg w. ISF | RoBERTa_large | - | - | 81.32 |

在RoBERTa_large骨干上，SegDRE将DREEAM的Test F1从64.27提升至64.80，在Re-DocRED上更达到81.32，优于APRDL等最新损失优化方法。

| 消融组件 | DocRED Dev F1 | 变化幅度 |
| :--- | :--- | :--- |
| DREEAM-Seg (完整) | 63.06 | - |
| w/o 显著实体识别 | 62.45 | -0.61 |
| w/o 密集阶段 | 62.82 | -0.24 |
| w/o 稀疏阶段 | 62.80 | -0.26 |
| w/o 知识注入 | 62.83 | -0.23 |
| w/o 阈值网格搜索 | 62.84 | -0.22 |

消融实验显示，移除显著实体识别导致性能下降最大（-0.61），验证了枢纽实体选择的关键性。知识注入的移除导致稀疏阶段F1下降约9个点，表明注入机制对多跳推理的必要性。阈值网格搜索虽贡献较小，但能校准不同组件的置信度。

评估协议采用F1和Ign-F1，未报告计算效率。代码已开源，超参数与基线保持一致，使用5次独立运行报告标准差。局限在于未对比生成式LLM基线，且假设文档仅有一个显著实体，未探索多显著实体场景。

## 关联研究分析

从问题动机看，ET-MIER同样关注细粒度实体语义，但采用实体类型引导的关键提及识别，依赖预定义的实体类型先验。SegDRE则通过统计显著性动态识别枢纽实体，无需类型标注，更适合开放域场景。然而，ET-MIER在DocRED上取得63.51 F1（BERT_base），略高于SegDRE的61.53，表明类型引导在特定基准上可能更优，但SegDRE的解耦策略在Re-DocRED上表现更强，暗示其对噪声标注的鲁棒性。

从方法设计看，K-Bert的知识注入机制被SegDRE迁移至DocRE，但应用场景从问答转为关系抽取。K-Bert注入的是外部知识，而SegDRE注入的是模型自身预测的密集三元组，形成自监督闭环。这种自注入策略避免了外部知识库的依赖，但可能放大预测错误。相比之下，DREEAM等全局建模方法未引入显式知识注入，依赖编码器隐式学习多跳路径，SegDRE的显式注入提供了更可控的推理路径，但增加了推理复杂度。

## 总结

SegDRE旨在解决DocRE中负样本主导与多跳推理断裂的矛盾，其切入点在于利用文档事实围绕显著实体聚集的统计特性，通过ZIP模型识别枢纽实体并解耦任务空间。该方法在RoBERTa_large骨干上将DREEAM的Test F1从64.27提升至64.80，在Re-DocRED上达到81.32，证明了分治策略的有效性。然而，其单显著实体假设在多主题文档中可能失效，且自注入机制可能放大预测错误。当文档中存在多个同等重要的枢纽实体时，SegDRE的解耦策略是否仍能保持性能优势，论文未给出回答。
