# ACL-Findings2026最新论文 ｜ThinkBrake: Efficient Reasoning via Log-Probability Margin Guided Decoding ｜基于对数概率边际的推理终止机制

研究机构：韩国首尔大学

作者：Sangjun Song、Minjae Oh、Seungkyu Lee 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_5d9847085443)

> 大语言模型在复杂推理中常出现“过度思考”，即在得出正确中间步骤后继续生成并覆盖为错误答案，导致计算资源浪费与精度下降。现有测试时干预方法多依赖手工启发式规则，缺乏理论支撑且在不同难度任务上表现不稳定。本文提出 THINKBRAKE，通过监测句子边界处继续生成 Token 与结束标记 `</think>` 的对数概率边际，实现无需训练的自适应推理终止。该方法在数学与工具调用任务上实现了精度保持与 Token 消耗降低的平衡，但其对高难度任务精度的轻微损失归因于“虚假推理”而非过早终止，这一现象的内在机制尚待深入解析。

## 研究背景

当模型在推理过程中生成“Wait”或“Hmm”等填充词时，往往标志着其已陷入自我怀疑或逻辑循环。这种状态下的继续生成不仅增加延迟，更可能使原本正确的中间结论被后续的错误推导覆盖，这一现象被称为“过度思考”。为量化该问题的可恢复空间，本文引入 Oracle 实验：在推理链的每个句子边界强制注入 `</think>` 标记，模拟“事后最优停止”。实验表明，这种理想化的早期终止能使数学推理错误率降至 6%，同时减少 54% 的思考 Token，证实了大部分失败源于过度思考而非能力不足。

主流高效推理路线分为训练式压缩与测试时干预两类。训练式方法如 UCoT 和 SLAT 通过多轮渐进压缩或语义剪枝优化 Token 预算，但依赖额外的训练成本或复杂的语义评估模块。测试时方法如 NoWait 和 ThinkLess 尝试通过抑制填充词或强制立即停止来加速推理，但这些启发式规则缺乏对模型置信度的动态感知，在 AIME 等高难度任务上常导致灾难性的精度崩塌。本文的切入点在于，将推理终止问题从“基于规则的外部干预”转化为“基于模型内部概率分布的解码时重对齐”，从而在无需额外训练的前提下，实现精度与效率的帕累托最优。

## 核心方法

### 解码时重对齐参照系

本文问题归属于测试时推理加速范畴，其通用流程是在解码过程中引入停止信号以截断冗余推理。与依赖外部验证器或多轮采样一致性的方法不同，本文的关键差异在于仅利用单路径解码时的 Logit 分布特性，将停止决策内化为模型自身的概率判断，避免了额外的计算开销。

### 对数概率边际终止准则

传统启发式方法通常基于 Token 数量或特定关键词触发停止，无法区分“高置信度的正确推理”与“低置信度的错误循环”。本文在句子边界处定义终止条件，当继续生成最优 Token $y^*_t$ 与结束标记 $e$ 的对数概率边际小于阈值 $\tau$ 时，强制注入 $e$ 终止推理：

$$ m_t := \log \frac{\pi_\theta(y^*_t | x; y_{<t})}{\pi_\theta(e | x; y_{<t})} \le \tau $$

该公式的物理含义是：当模型对“继续思考”与“停止思考”的相对置信度趋于均衡时，表明有效推理已接近结束。这种对数空间的设计使得终止决策对模型熵水平具有自适应能力：在高熵（不确定）状态下，对数边际更难缩小，从而保守地避免过早终止；在低熵（高置信）状态下，边际迅速缩小，触发及时停止。

### KL 正则化理论等价性

为赋予该启发式准则理论基础，本文证明 THINKBRAKE 等价于一个 KL 正则化的策略优化过程，其中对 `</think>` 赋予奖励加成。设 $\beta = T$（解码温度），重对齐后的策略 $\tilde{\pi}_\theta$ 满足：

$$ \tilde{z}_{\theta,\tau}(y | st) = z_\theta(y | st) + \frac{\tau}{T} \cdot \mathbb{I}[y = e] $$

此公式表明，THINKBRAKE 实质上是在 Logit 层面对 `</think>` 施加了一个常数偏移量 $\tau/T$。这一理论解释揭示了该方法的本质：它并非简单的截断，而是通过调整解码分布，使模型在边界状态更倾向于选择终止，从而在数学上保证了终止决策与模型内部置信度的一致性。

## 实验评估

实验在 Qwen3 系列、DeepSeek-R1-7B 及 Phi-4-Reasoning 六个模型上，覆盖 GSM8K、MATH500、AIME2024/2025、GPQA-D、ARC-C 及 BFCL 工具调用基准。基线对比包括 NoWait、ThinkLess、DEER 及 Dynasor-CoT，覆盖了从简单截断到基于熵的停止等多种测试时干预路线，但未包含训练式压缩方法（如 UCoT）作为直接对比，因本文定位为 Training-free 场景。

| 模型 | 基准 | 基线精度 | THINKBRAKE 精度 | Token 减少率 |
| :--- | :--- | :--- | :--- | :--- |
| Qwen3-4B-Thinking | GSM8K | 95.1 | 94.8 | -18.9% |
| Qwen3-4B-Thinking | AIME2024 | 77.1 | 67.2 | -33.5% |
| Qwen3-14B | AIME2024 | 71.7 | 77.9 | -7.4% |
| Qwen3-32B | MATH500 | 97.0 | 97.2 | -1.4% |
| Phi-4-Reasoning | AIME2024 | 67.5 | 73.3 | -6.4% |

在简单任务（GSM8K、MATH500）上，THINKBRAKE 在保持精度基本不变的情况下实现了 10%-30% 的 Token 减少。在高难度任务（AIME）上，表现呈现分化：Qwen3-14B 和 Phi-4-Reasoning 精度反而提升，表明该方法有效抑制了过度思考；而 Qwen3-4B-Thinking 精度下降约 10 个点，但 Token 减少达 33.5%。消融实验显示，对数边际设计（THINKBRAKE）显著优于线性概率差变体（THINKBRAKE-p），后者在 AIME 上精度仅 30%-35%，证实了对数空间在处理低概率状态时的鲁棒性。

评估边界方面，AIME 基准仅含 30 题，统计波动较大，论文通过 32 次运行报告了置信区间以增强可靠性。代码已开源，超参数 $\tau$ 在 Qwen3 系列上统一设为 0.1，在 Phi-4-Reasoning 上设为 2.5，显示该阈值对模型家族具有较好的泛化性，但跨模型迁移仍需微调。

## 关联研究分析

从方法设计看，THINKBRAKE 与 SLAT 和 UCoT 代表了效率优化的两条不同路径。SLAT 和 UCoT 属于训练式压缩，通过多轮交互或专用压缩器重构推理轨迹，其优势在于能深度优化语义结构，但代价是高昂的训练成本与推理时的多轮延迟。THINKBRAKE 则坚持单路径解码，通过 Logit 干预实现即时终止，其优势在于零训练成本与低延迟，但受限于模型自身的置信度校准能力。这种差异根源在于任务特性：对于工具调用等结构化任务，Logit 边际能准确反映“是否已获取足够信息”；而对于开放式数学推理，模型可能在正确解题后仍产生高置信度的错误验证步骤，导致 Logit 边际未能及时触发终止，从而暴露出该方法对“虚假推理”的敏感性。

从问题动机看，THINKBRAKE 与 DEER 和 NoWait 同属测试时干预，但解决的核心痛点不同。NoWait 仅抑制填充词，未触及推理逻辑的终止；DEER 基于熵值判断不确定性，但在低熵高置信的错误循环中失效。THINKBRAKE 通过引入 `</think>` 作为参照 Token，将停止决策转化为“继续 vs 停止”的相对概率比较，从而在模型不确定时（高熵）保持保守，在模型自信时（低熵）果断终止。这一设计弥补了纯熵值方法在“自信地犯错”场景下的盲区，但论文未探讨当模型在错误路径上保持高度自信时，Logit 边际是否仍能正确引导终止，这一边界条件在极端困难任务上可能成为精度损失的主要来源。

## 总结

本文旨在解决大语言模型推理中的“过度思考”问题，即模型在得出正确结论后继续生成并覆盖为错误答案。现有启发式方法缺乏理论支撑且在不同难度任务上表现不稳定，本文通过将对数概率边际终止准则形式化为 KL 正则化重对齐，提供了无需训练的测试时解决方案。实验表明，该方法在简单任务上实现了精度保持与 10%-30% 的 Token 减少，在高难度任务上对部分模型实现了精度提升，但 Qwen3-4B-Thinking 在 AIME2024 上精度下降 9.9 个点。这一局限并非源于过早终止，而是源于模型在解题后仍进行高置信度的错误验证，即“虚假推理”。当模型在错误路径上保持高度自信时，Logit 边际是否仍能正确引导终止，论文未给出回答。
