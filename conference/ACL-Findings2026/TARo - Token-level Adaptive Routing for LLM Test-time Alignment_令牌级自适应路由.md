# ACL-Findings2026最新论文 ｜TARo: Token-level Adaptive Routing for LLM Test-time Alignment ｜令牌级自适应路由

研究机构：美国匹兹堡大学、美国加州大学伯克利分校

作者：Arushi Rai、Qiang Zhang、Hanqing Zeng 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.18411)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.18411)

> 大语言模型（LLM）在复杂推理任务中常因后训练成本高、领域特定性强而难以灵活部署，现有测试时对齐方法依赖固定插值权重，无法适应不同任务与模型规模的动态变化。本文提出令牌级自适应路由（Token-level Adaptive Routing, TARO），通过可学习路由器在解码时动态融合基座模型与奖励模型的输出，消除手动调参需求。该方法在数学推理基准上较基座模型提升最高22.4%，并展现出弱到强泛化能力，但其效果高度依赖奖励模型与基座模型的能力匹配度，跨域泛化机制尚待深入验证。

## 研究背景

当LLM面对数学或临床推理任务时，其自回归生成机制与多步逻辑推导之间存在张力，导致模型在早期错误后无法有效恢复。为提升推理能力，主流路线分为训练时优化与测试时增强：前者如基于可验证奖励的强化学习（Reinforcement Learning with Verifiable Rewards, RLVR）通过更新参数塑造策略，但面临训练不稳定与领域特定性问题；后者如GenARM通过固定权重插值引导冻结模型，但缺乏动态适应能力。测试时对齐的核心困境在于，固定插值权重（如GenARM的α=0.5）在不同域和模型规模下表现敏感，甚至导致性能低于基座模型，这限制了其在通用部署中的鲁棒性。

本文切入点在于解决测试时对齐中“固定权重”的刚性问题。现有方法将基座与奖励模型的融合视为静态过程，而实际推理中不同令牌对逻辑一致性的贡献差异显著。TARO通过引入轻量级可学习路由器，将融合过程动态化，使模型能根据当前解码状态自适应调整奖励模型的影响权重，从而在无需重训练基座模型的前提下，实现跨域、跨规模的稳健推理增强。

## 核心方法

### 方法参照系

TARO基于GenARM的令牌级奖励参数化框架，但关键差异在于将固定插值权重替换为动态路由机制。GenARM假设奖励模型与基座模型的贡献比例恒定，而TARO认为该比例应随解码步骤与任务上下文变化，这一假设转变是解决固定权重失效的核心。

### 推理奖励模型训练

设计动机在于解决GenARM从通用偏好数据训练奖励模型时，缺乏对细粒度逻辑一致性的捕捉。TARO使用Math-StepDPO-10K数据集，该数据集包含共享正确前缀但下一步分叉的偏好对，通过偏好损失训练奖励模型：

$$\mathcal{L}_{\text{pref}} = -\mathbb{E}_{(x, y_w, y_l)} \left[ \log \sigma \left( \beta_r \left( \log \pi_{\text{reward}}(y_w | x, \text{prefix}) - \log \pi_{\text{reward}}(y_l | x, \text{prefix}) \right) \right) \right]$$

该公式迫使奖励模型区分逻辑连贯与错误的步骤延续，将步骤级监督分解为令牌级对数似然，确保奖励信号与推理正确性对齐。

### 令牌级自适应路由器

设计动机在于解决固定权重无法适应不同令牌重要性差异的问题。路由器输入为基座与奖励模型的Top-K logits拼接向量，通过浅层MLP输出动态权重α_t：

$$\alpha_t = \sigma \left( \phi \left( W \cdot h_t \right) \right), \quad h_t = \text{Concat}(z_{t,\text{base}}^{\text{top-K}}, z_{t,\text{reward}}^{\text{top-K}})$$

其中φ为Tanh激活，σ为Sigmoid函数。该设计使路由器能识别数学运算符、格式符号等高α令牌（奖励模型主导），以及问题上下文词汇等低α令牌（基座模型主导），实现细粒度推理控制。

## 实验评估

实验在MATH500（数学推理）、MedXpertQA（临床推理）和AlpacaEval（指令遵循）上评估，基线包括基座模型、奖励模型、GenARM和UniR。TARO在Llama-3.1-8B上MATH500准确率达54.4%，较GenARM的49.2%提升5.2个百分点；在Qwen-2.5-3B上达64.8%，较GenARM的56.4%提升8.4个百分点。

| 模型 | 方法 | MATH500 | MedXpertQA | AlpacaEval |
| :--- | :--- | :--- | :--- | :--- |
| Llama-3.1-8B | Base | 32.0 | 13.0 | 17.3 |
| Llama-3.1-8B | GenARM | 49.2 | 11.2 | 10.8 |
| Llama-3.1-8B | TARO | 54.4 | 13.2 | 20.8 |
| Qwen-2.5-3B | Base | 60.8 | 11.8 | 33.6 |
| Qwen-2.5-3B | GenARM | 56.4 | 9.8 | 18.9 |
| Qwen-2.5-3B | TARO | 64.8 | 9.8 | 21.6 |

消融实验显示，Top-K=1000配合熵正则化在Qwen-2.5上MATH500达64.8%，较无正则化的60.2%提升4.6个百分点；但在Llama-3.1上，熵正则化导致MATH500从54.4%降至50.6%，表明正则化效果依赖基座与奖励模型的相对强度。

评估边界方面，论文未报告置信区间，且MedXpertQA上TARO与GenARM持平（9.8%），显示跨域泛化有限。代码未公开，路由器训练依赖Math-StepDPO-10K和UltraFeedback数据集，超参数细节见附录。

## 关联研究分析

从问题动机看，TARO与RLVR路线存在根本张力：RLVR通过参数更新优化策略，而TARO坚持冻结基座，主张测试时计算替代训练成本。这一选择源于对后训练领域特定性与成本的关注，但论文未验证TARO在复杂任务上能否匹配RLVR的泛化能力，例如DeepSeek-R1在MATH500上达79.8%（据领域综述），远高于TARO的64.8%，差距可能源于骨干能力而非方法本身。

从方法设计看，TARO借鉴混合专家（Mixture-of-Experts, MoE）路由思想，但解耦了专家与路由器的联合训练。与GenARM相比，TARO将固定α改为动态α_t，解决了手动调参难题；与UniR相比，TARO使用偏好损失而非GRPO训练奖励模型，更轻量但可能牺牲奖励模型的独立性能。路由器弱到强泛化（小模型训练后迁移到大模型）是独特贡献，但其机制是否依赖特定骨干架构，论文未深入探讨。

## 总结

TARO解决的核心矛盾是测试时对齐中固定权重导致的跨域、跨规模性能不稳定。其切入点在于将融合过程动态化，通过可学习路由器实现令牌级自适应，这得益于对推理过程中不同令牌重要性差异的洞察。方法上，TARO结合步骤偏好训练的奖励模型与轻量级路由器，在MATH500上较基座模型提升最高22.4%，较GenARM提升8.4%。边界在于，MedXpertQA上无增益且熵正则化在Llama-3.1上负迁移，显示跨域泛化与模型匹配度的敏感性。当奖励模型性能显著低于基座模型时，TARO的自适应路由能否完全弥补能力差距，论文未给出回答。
