> 自动化幻灯片生成面临叙事结构与视觉设计的协同难题，现有方法或依赖固定模板限制创意，或直接输出代码而忽略设计环节。DeepSlides 通过解耦“设计推理”与“代码实现”，引入分层工作流与多智能体强化学习，在无模板约束下实现高质量 PPTX 生成。该方法在人类偏好评估中显著优于开源基线，但其缺乏客观几何精度指标，且长文档风格一致性未获充分验证。

## 研究背景

当 LLM 直接生成幻灯片代码时，模型往往将注意力集中在内容填充，导致布局杂乱、色彩冲突或元素重叠。这种失效源于设计意图与实现细节的耦合：模型在生成 Python 代码的同时需兼顾美学判断，而代码语法约束限制了视觉表达的灵活性。为解决此问题，需将设计过程从代码生成中剥离，引入独立的视觉规划阶段，即“设计-实现解耦”。这一过程要求系统先确定全局风格与局部布局，再将其转化为可执行代码，从而确保视觉连贯性与结构正确性。

现有幻灯片生成方法主要分为两类：模板驱动与端到端代码生成。模板驱动方法（如 Auto-Slides）虽保证稳定性，但牺牲了布局多样性；端到端方法（如 EvoPresent）虽具备创意潜力，但缺乏显式设计步骤，导致视觉质量不稳定。DeepSlides 的切入点在于将幻灯片生成重构为“场景合成”任务，通过分层解耦（Slides-level 风格规划 + Page-level 设计实现）与多智能体强化学习（MARL），在无模板约束下实现叙事结构与视觉设计的协同优化。

## 核心方法

### 分层解耦架构

DeepSlides 将生成流程划分为 Slides-level 与 Page-level 两个层级。Slides-level 负责全局风格定义（色彩、字体、装饰元素）与大纲生成，确保跨页一致性；Page-level 负责单页内容扩展、布局设计与代码实现。这种解耦使得设计模块（Designer）在高层语义空间操作，不受低层 PPTX 实现细节干扰，而编码模块（Coder）仅负责将设计规格编译为稳定代码。该架构解决了端到端方法中设计意图被代码语法扭曲的问题，实现了视觉表达与执行鲁棒性的独立优化。

### 多智能体强化学习训练

为提升设计质量，DeepSlides 采用 MARL 框架训练 Designer 与 Coder 两个智能体。训练过程分为两阶段：首先通过监督微调（SFT）冷启动，使模型适应任务格式；随后通过交互式 rollout 进行强化学习，由视觉语言模型（VLM）奖励模型评估输出质量。奖励函数 $R$ 综合评估完整性（Completeness）、合规性（Compliance）与美学（Aesthetics）：

$$ R = \alpha R_{comp} + \beta R_{comp\_layout} + \gamma R_{aest} $$

其中 $R_{comp}$ 衡量内容覆盖度，$R_{comp\_layout}$ 检测元素重叠与越界，$R_{aest}$ 评估色彩和谐与视觉层级。该公式将主观美学转化为可优化的标量信号，使模型在迭代中自发学习符合人类偏好的布局策略，弥补了 SFT 仅学习单一 Ground Truth 的局限。

## 实验评估

实验在自建 SlideDesign 数据集（420 个主题）上进行，对比 Auto-Slides、EvoPresent 等开源基线及 Manus、Kimi 等商业系统。由于缺乏标准几何指标（如 mIoU），评估主要依赖人类偏好测试。

| 评估维度 | DeepSlides | 最佳开源基线 | 最佳商业基线 |
| :--- | :--- | :--- | :--- |
| 人类偏好胜率（开源对比） | 76.5% | 9.5% | — |
| 人类偏好胜率（商业对比） | 52.0% | — | 19.5% |

DeepSlides 在开源对比中胜率高达 76.5%，远超第二名 68.0 个百分点；在商业对比中胜率 52.0%，领先最强商业基线 32.5 个百分点。这表明分层解耦与 MARL 训练显著提升了视觉吸引力与创意性。然而，论文未报告消融实验数据，无法量化各模块（如 DeepResearch、MARL）的独立贡献。

评估边界存在明显局限：缺乏客观几何精度指标（如元素重叠率、边界框 IoU），无法排除视觉偏好对评估结果的偏差；SlideDesign 数据集规模较小（420 主题），且未覆盖长文档场景，风格一致性在页数增加时的衰减情况未获验证。代码已开源，但训练超参数与 VLM 奖励模型细节未在正文中完整披露，可复现性受限。

## 关联研究分析

从问题动机看，DeepSlides 与 PosterLlama 同属 LLM 布局生成路线，但前者聚焦 PPT 叙事结构，后者侧重单页海报美学。PosterLlama 通过 HTML 生成实现可编辑性，但缺乏跨页风格一致性机制；DeepSlides 引入 Slides-level 全局规划，解决了多页文档的风格漂移问题。这一差异源于任务特性：PPT 强调序列连贯性，而海报强调单页视觉冲击。

从方法设计看，DeepSlides 与 EvoPresent 均采用迭代优化，但后者依赖美学感知反馈模型进行多轮精修，前者通过 MARL 将设计视为策略学习问题。EvoPresent 的反馈机制针对单页局部调整，而 DeepSlides 的 MARL 框架在 Designer 与 Coder 间建立协同优化，使设计决策与代码实现相互约束。这种多智能体架构是否导致训练复杂度指数级增长，论文未给出计算成本分析，也未探讨在资源受限场景下的可行性。

## 总结

DeepSlides 旨在解决无模板约束下幻灯片生成的视觉质量与可编辑性矛盾，通过分层解耦架构将设计推理与代码实现分离，并利用多智能体强化学习优化美学与合规性。实验显示其在人类偏好评估中胜率 76.5%（开源）与 52.0%（商业），证明了设计-实现分离的有效性。然而，论文缺乏客观几何精度指标，且 SlideDesign 数据集仅含 420 个主题，未验证长文档场景下的风格一致性保持能力。当幻灯片页数从 10 页扩展至 50 页时，Slides-level 全局风格规划是否仍能维持跨页视觉连贯性，论文未给出回答。
