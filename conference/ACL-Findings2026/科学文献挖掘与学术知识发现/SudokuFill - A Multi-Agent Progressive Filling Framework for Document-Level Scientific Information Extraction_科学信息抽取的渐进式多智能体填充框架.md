# ACL-Findings2026最新论文 ｜SudokuFill: A Multi-Agent Progressive Filling Framework for Document-Level Scientific Information Extraction ｜科学信息抽取的渐进式多智能体填充框架

研究机构：中国科学院、中国科学院大学

作者：Yang Li、Yajiao Wang、Yu Zhang 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_83812d28955b)

> 科学文献挖掘旨在将非结构化文本转化为可计算的知识基础设施，但传统“局部抽取后组装”范式在长文档中因字段隔离导致全局关联断裂。现有方法依赖静态知识图谱或单次生成，难以利用高置信度结果作为内部监督来约束后续不确定字段。本文提出 SudokuFill，将文档级科学信息抽取重构为类似数独的渐进填充问题，通过全局状态复用与多智能体辩论实现约束传播。该框架在疫苗佐剂基准上达到 51.83% 的整体准确率，并验证了 7B 模型超越 GPT-4o 的架构补偿效应，但其泛化性受限于自建基准的领域特异性。

## 研究背景

文档级科学信息抽取（SciIE）面临的核心困境是长文本中字段间的隐式依赖关系。当系统独立提取蛋白质功能注释中的“结构域类型”时，该结果本应作为约束缩小“活性位点”的搜索空间，但传统流水线将其视为孤立任务，导致后续字段在缺乏上下文约束时产生级联错误。这种信息丢失迫使系统在每篇文档、每个字段上重复从零开始推理，尤其在多模态 PDF 中，跨页证据分散进一步加剧了提取的不确定性。

主流路线分为两类：一是基于预训练模型（如 BERT、T5）的统计学习系统，擅长捕捉局部语义但缺乏全局一致性机制；二是基于大语言模型（LLM）的智能体框架，虽具备长上下文能力，但多被用作高效局部提取器，未充分利用其结构化推理潜力。SPECTER 等嵌入方法解决了文档关联问题，但未触及字段级依赖；AI-Scientist 等智能体框架实现了多步推理，但依赖外部静态知识图谱，缺乏动态内部约束。本文切入点在于：将高置信度提取结果视为“内部监督”，通过动态全局状态实现跨字段、跨文档的约束传播，从而在长文档中维持记录级一致性。

## 核心方法

### 方法参照系

文档级 SciIE 的通用流程是“局部抽取后组装”：将 schema 分解为独立字段任务，从句子或段落级上下文提取候选值，再通过后处理组装为结构化记录。本文的关键差异在于：该范式假设字段间无依赖，而科学属性（如佐剂组成与形态）存在内在约束，需通过全局状态动态协调。

### 字段优先级调度

Stage I 解决“先填哪个字段”的问题，传统方法按 schema 固定顺序或随机顺序执行，导致高不确定性字段早期错误传播。本文引入 Page Agent 对每页进行一次性探测，输出候选三元组 $(V_{p,q}, C_{p,q}, E_{p,q})$，其中 $C_{p,q}$ 为置信度。Rank Agent 基于最大置信度 $\text{MaxConf}(q) = \max_p C_{p,q}$ 与参与度 $\text{Part}(q) = |\{p \mid C_{p,q} > 0.5\}|$ 排序查询，优先处理信号强、易收敛的字段。该调度机制将“易到难”填充逻辑形式化，为 Stage II 提供稳定起点，减少早期错误对全局状态污染的累积效应。

### 多智能体辩论与全局状态复用

Stage II 解决“如何可靠填充”的问题，传统单轮生成易陷入多数派偏差。本文设计三类智能体：Page Agent 提出候选，Constraint Agent（行/列视图）从全局填充状态 $G$ 中检索约束，Coordinator 协调辩论。关键公式为收敛判据：当主导候选在连续轮次中稳定，且各智能体内部置信度更新 $\Delta C_t \approx 0$ 时停止。高置信度结果 $(q, V, E)$ 写入 $G$，作为后续查询的结构化约束。此机制实现跨轮次（同一查询）与跨查询（不同字段）的双重复用，将局部提取转化为全局约束驱动推理，显著提升记录级一致性。

## 实验评估

实验在自建疫苗佐剂基准（250 篇 PDF，1000+ 标注记录）上进行，基线覆盖闭源 MLLM（GPT-4o、GPT-5 Nano）、开源 MLLM（Qwen2.5-VL 7B）及 SciIE 专用模型（Eunomia、BioWorkflow）。所有基线采用固定顺序抽取，无动态调度或辩论。

| 模型/方法 | 参数量 | Entity-F1 | Row-Acc | Overall |
| :--- | :--- | :--- | :--- | :--- |
| GPT-4o | – | 69.01 | 31.42 | 47.72 |
| Qwen2.5-VL (Vanilla) | 7B | 62.41 | 25.81 | 42.20 |
| SudokuFill (Qwen2.5-VL) | 7B | 69.22 | 28.65 | 48.28 |
| SudokuFill (GPT-5 Nano) | – | 72.85 | 34.38 | 51.83 |

SudokuFill (Qwen2.5-VL) 的 Overall 48.28% 超越 GPT-4o 的 47.72%，验证了架构对参数规模的补偿效应。消融实验显示，移除全局状态复用（Ablation 2）导致 Overall 降至 47.39%，移除多轮辩论（Ablation 3）降至 44.46%，表明约束传播与迭代纠错的耦合是性能关键。

## 关联研究分析

从问题动机看，SudokuFill 与 AI-Scientist 同属智能体框架，但后者依赖外部静态知识图谱提供事实约束，而本文通过动态全局填充状态实现内部约束传播。这一差异源于任务特性：AI-Scientist 面向假设生成，需外部知识注入；SudokuFill 面向结构化抽取，字段间依赖可通过内部高置信度结果自举。然而，当文档中缺乏高置信度锚点时，全局状态 $G$ 的初始化稀疏性可能削弱约束效果，论文未探讨此边界条件。

从方法设计看，SudokuFill 与 SPECTER 均利用结构信号增强语义，但 SPECTER 在嵌入层引入引用图信号，本文在推理层引入字段依赖信号。SPECTER 解决文档级关联，本文解决字段级一致性。两者互补：SPECTER 可作为本文的检索前端，定位相关文档；SudokuFill 作为后端，确保抽取一致性。但本文未集成 SPECTER 类嵌入，其 Page Agent 依赖 MLLM 直接扫描，可能在大规模语料检索中效率受限。

## 总结

本文核心矛盾是长文档 SciIE 中字段隔离导致的全局一致性缺失。现有方法依赖静态外部知识或单次生成，无法利用高置信度结果作为内部监督。SudokuFill 通过全局填充状态与多智能体辩论，将抽取重构为渐进约束填充问题，在疫苗佐剂基准上实现 51.83% Overall 准确率，并证明 7B 模型可超越 GPT-4o。其边界在于：全局状态 $G$ 的有效性依赖文档内存在足够高置信度锚点，当文档信息稀疏或字段依赖复杂时，约束传播可能失效。当支持集增大或文档长度超过当前基准范围时，全局状态的更新效率与收敛稳定性是否仍保持，论文未给出回答。
