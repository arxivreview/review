# ACL-Findings2026最新论文 ｜CAMO: An Agentic Framework for Automated Causal Discovery from Micro Behaviors to Macro Emergence in LLM Agent Simulations ｜从微观行为到宏观涌现的因果发现框架

研究机构：天津大学

作者：Xiangning Yu、Yuwei Guo、Yuqi Hou 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.14691)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.14691)

> 生成式多智能体社会模拟能复现宏观涌现现象，但无法解释其背后的微观-宏观因果机制，导致干预策略缺乏可泛化性。现有方法或依赖静态变量空间的统计因果发现，或仅做定性演示，均无法在动态自适应环境中恢复可干预的因果结构。CAMO 通过分离“因果识别”与“机制解释”，利用多智能体协作与模拟器内部反事实干预，自动恢复目标涌现结果的最小充分因果接口。该框架在自建基准上实现了高保真的结构恢复与干预排序，但其有效性受限于模拟器内部日志的完备性，且未验证跨模拟器的泛化能力。

## 研究背景

理解 LLM 智能体社会中的涌现现象，首先需要区分“相关”与“因果”。在复杂多智能体系统中，宏观结果 $Y$ 往往由微观行为与中观交互结构共同驱动，但观测数据仅能揭示变量间的统计关联。要支持有效的干预（如修改提示词或调整交互拓扑），必须识别出 $Y$ 的马尔可夫边界（Markov Boundary, MB），即预测和干预 $Y$ 所需的最小充分条件集。然而，LLM 智能体的行为由自然语言驱动，其内部状态并非直接可观测的数值变量，而是隐含在文本交互中的非线性机制，这使得传统基于固定变量空间的因果发现方法失效。

当前 LLM 社会模拟研究主要聚焦于定性演示宏观现象（如合作、极化）或验证统计轨迹的一致性，缺乏对生成机制的因果解释。统计因果发现方法（如 PC、GES）假设变量空间固定且已知，无法处理 LLM 模拟中动态生成的语义变量；纯 LLM 推理方法虽能提出假设，但缺乏数据约束，易产生幻觉。CAMO 的切入点在于将 LLM 模拟视为黑盒随机数据生成过程，通过引入可计算的诱导因子空间，将语义机制转化为可观测的数值变量，从而在动态环境中实现局部因果结构的识别与解释。

## 核心方法

### 方法参照系

CAMO 的问题可归类为动态环境下的局部因果发现。标准流程通常假设变量空间固定，通过约束或评分算法学习全局有向无环图（DAG）。本文的关键差异在于：变量空间是动态诱导的，且目标不是全局结构，而是围绕目标 $Y$ 的最小充分因果接口，以支持解释与干预。

### 可计算马尔可夫边界学习

传统因果发现直接作用于原始日志，但 LLM 模拟中的关键机制（如供需比、网络熵）需通过非线性变换从原始观测 $X_{obs}$ 中构造。CAMO 引入诱导因子空间 $H$，由可解释模板（比率、滚动统计、图指标）生成候选变量。Agent A3 通过信息增益测试动态添加或剪枝变量 $Z$，仅当 $Z$ 降低 $Y$ 的条件不确定性超过阈值 $\tau_I$ 时才保留：

$$ IG(Z; Y | V_{[t]}) \ge \tau_I $$

该公式确保边界紧凑且充分，避免冗余变量干扰因果识别。设计动机在于解决原始日志无法直接反映中观机制的问题，通过可计算变换将语义机制映射为可统计推断的数值变量。

### 最小连接解释子图与反事实裁决

马尔可夫边界仅支持局部预测，无法解释涌现机制。CAMO 进一步构建最小连接解释子图 $E_Y$，保留从根变量 $R$（微观行为/环境设置）到边界变量 $B$ 的所有有向路径，且移除任何节点或边都会破坏可达性：

$$ E_Y = \text{Conn}_{min}(R \Rightarrow MB_{[H]}(Y)) $$

该子图提供微观-宏观因果叙事。对于方向模糊的边，Agent A4 生成模拟器内部反事实干预脚本（如 $do(X=x)$ vs $do(X=x')$），Agent A5 执行配对实验，仅当效应一致非零且方向一致时标记为“模拟确认”。这一设计解决了观测数据无法区分因果方向的问题，通过干预证据消除 CPDAG/PAG 中的方向歧义，确保因果图的干预有效性。

## 实验评估

实验在 O2O 配送模拟（基于 Meituan 统计校准）、Smallville 和 AgentSociety 上进行。基线覆盖统计因果发现（PC, FCI, GES, MMHC）、纯 LLM 方法（MAC, PAIRWISE）及混合方法（SCD+LLM, ReAct, LLM-KBCI）。CAMO 使用 DeepSeek-V3.2 作为骨干，在 O2O 基准上，CAMO 的 MB-F1 达到 1.00，Anc-F1 达到 0.98，显著优于 PC（MB-F1 0.20）和 MAC（MB-F1 0.71），验证了其在因子发现与结构恢复上的优势。

| 方法 | MB-F1 | Anc-F1 | SHD | FPR |
| :--- | :--- | :--- | :--- | :--- |
| PC | 0.20 | 0.34 | 23 | 0.34 |
| MAC | 0.71 | 0.07 | 7 | 0.07 |
| CAMO (DeepSeek-V3.2) | 1.00 | 0.98 | 1 | 0.02 |

消融实验显示，移除 A1&A2（世界观解析与整合）导致 MB-F1 从 1.00 降至 0.00，Anc-F1 从 0.98 降至 0.46，表明领域先验与数据驱动结构的融合是核心。移除反事实裁决（A5）使 SHD 从 1 升至 9，FPR 从 0.02 升至 0.04，证实反事实干预对方向消歧的关键作用。在干预排序任务中，CAMO 在 Smallville（协调）和 AgentSociety（极化、煽动性传播）上均取得最高的 Precision@5 和 MAP@5，表明其因果图能有效指导有效干预的识别。

评估边界受限于模拟器内部日志的完备性，若关键混淆变量未被记录或无法在 $H$ 中表达，则存在残余混淆。实验仅在特定模拟器（O2O, Smallville, AgentSociety）上验证，未测试跨模拟器或跨领域的泛化能力。代码已开源，但 LLM 调用成本较高（每次试验 50-80 次 API 调用，350K-1M tokens），限制了大规模应用。

## 关联研究分析

从问题动机看，CAMO 与 SLALOM 和 Coupling Gain 形成互补。SLALOM 关注宏观轨迹的统计一致性，Coupling Gain 量化社会敏感性，二者均不解释机制；CAMO 则通过因果图定位敏感节点，提供机制解释。差异根源在于任务特性：SLALOM 和 Coupling Gain 适用于验证模拟有效性，而 CAMO 适用于指导干预设计。CAMO 的反事实干预是否真正实现了 do-calculus 语义，还是仅过滤了模拟器内部的噪声，论文未给出明确回答。

从方法设计看，CAMO 与 Agent-Kernel 等基础设施框架不同，后者提供动态仿真能力，而 CAMO 依赖其运行时更新能力执行反事实干预。CAMO 的“最小充分”策略与 ScaleSim 的稀疏激活思路相似，均旨在降低计算成本，但 CAMO 聚焦于因果结构的最小化，而非内存管理。CAMO 未采用代理模型（Surrogate Models）作为基线，这可能限制了其在计算效率方面的对比优势，但因果发现任务本身对精度的要求高于对速度的要求。

## 总结

CAMO 解决了 LLM 社会模拟中微观-宏观因果机制不可解释的核心矛盾，通过分离因果识别与机制解释，利用可计算马尔可夫边界和最小连接解释子图，实现了动态环境中的局部因果发现。实验表明，CAMO 在 O2O 基准上达到 MB-F1 1.00 和 Anc-F1 0.98，显著优于统计和纯 LLM 基线，并提供了有效的干预排序。然而，其有效性依赖于模拟器内部日志的完备性，且未验证跨模拟器的泛化能力。当模拟器日志缺失关键混淆变量时，CAMO 恢复的因果结构是否仍具干预有效性，论文未给出回答。
