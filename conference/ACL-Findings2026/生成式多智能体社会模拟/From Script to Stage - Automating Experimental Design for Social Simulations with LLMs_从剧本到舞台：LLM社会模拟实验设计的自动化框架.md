# ACL-Findings2026最新论文 ｜From Script to Stage: Automating Experimental Design for Social Simulations with LLMs ｜从剧本到舞台：LLM社会模拟实验设计的自动化框架

研究机构：天津大学、山东大学

作者：Yuwei Guo、Zihan Zhao、Xiaowei Liu 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_1d59bef85a8d)

> 生成式多智能体社会模拟旨在通过大语言模型（LLM）复现复杂社会动力学，但传统实验设计依赖跨学科专家的高成本介入，导致研究门槛高且难以规模化。现有LLM驱动框架虽降低了操作壁垒，却因缺乏结构化约束而难以保证实验的科学严谨性与变量可控性。FSTS框架借鉴电影制作流程，将实验设计解耦为剧本创作、定稿与演员生成三个阶段，通过多智能体协作自动编译高层研究意图为可执行脚本。该框架在古巴导弹危机场景中实现了与历史结局的一致性复现，但其对单一历史事件的依赖及语义相似度指标的局限性，使其在通用科学验证层面的有效性仍存疑。

## 研究背景

计算社会科学中的“第三范式”主张在可控虚拟环境中通过计算实验分析复杂系统，其核心在于构建具备因果解释力的微观机制模型。然而，传统基于智能体建模（Agent-Based Modeling, ABM）与决策剧场（Decision Theater）范式存在显著瓶颈：前者依赖刚性启发式规则，难以捕捉语义丰富的社会交互；后者虽提升了认知一致性，却受制于高昂的专家协调成本与现场引导依赖，无法实现大规模自动化部署。

随着LLM的引入，社会模拟的保真度显著提升，但“如何从高层研究意图生成标准化、可执行且变量受控的实验脚本”成为新的核心障碍。现有LLM智能体框架（如Smallville、SOTOPIA）主要关注交互涌现，却缺乏对实验设计变量、干预措施及评估标准的显式控制。这种“提示驱动”的松散结构导致实验结果易受模型偏差影响，难以满足计算社会科学对机制解释力与可复现性的严格要求。FSTS的切入点在于将实验设计过程形式化为一个可审计的多阶段流水线，通过引入领域专家知识模板与结构化约束，在自动化生成与科学严谨性之间建立桥梁。

## 核心方法

### 方法参照系

FSTS置于“实验设计自动化”这一通用流程中，其关键差异在于将传统的“人工设计-代码实现”模式替换为“LLM生成-多智能体评审-结构化实例化”模式。传统流程中，实验脚本由专家手工编写，变量控制依赖人工逻辑；而FSTS将脚本定义为五元组 $S = \langle G, I, R, D, L \rangle$，其中 $G$ 为实验目标，$I$ 为影响因素，$R$ 为响应变量，$D$ 为参数化设计点，$L$ 为贯穿实验逻辑的故事线。这一形式化定义使得实验设计从自然语言描述转化为机器可解析的结构化数据，为后续的自动化执行与验证奠定了基础。

### 双约束剧本生成机制

剧本创作阶段的核心挑战在于LLM输出的随机性与实验设计的严谨性之间的矛盾。通常做法是直接提示LLM生成实验方案，但这往往导致变量遗漏或逻辑断裂。FSTS引入了输入侧的结构化引导与输出侧的多视角集成机制。输入侧要求用户必须提供研究目标、核心变量与目标对象，并通过分步生成策略将 $S$ 的构建分解为针对 $G, I, R, D, L$ 的子任务，确保局部语义准确性。输出侧采用多视角生成机制，由多个编剧智能体从不同视角（如目标导向 vs. 过程导向）生成候选方案，并通过加权投票选择最优解。同时，严格的JSON Schema约束确保生成的脚本可直接被下游仿真系统解析。这一机制解决了单一LLM生成方案中常见的“组合爆炸”与“过度简化”问题，通过结构化约束将宏观研究意图映射为微观参数，提升了脚本的可执行性与逻辑完整性。

### 多模型投票与两阶段定稿

剧本定稿阶段旨在从多个候选方案中筛选出最具科学解释力的最终脚本。传统方法依赖人工评审，成本高且主观性强。FSTS采用“LLM as Judge”范式，但针对LLM在判断任务中的位置偏差、冗长偏差等固有缺陷，设计了多模型投票委员会与两阶段筛选机制。第一阶段为单答案评分，由GPT-5 mini、Qwen-235b等强模型独立对候选脚本进行百分制评分，保留前4名。评分标准严格遵循Nigel Gilbert的ABM核心准则，即实验应展示机制的解释力而非仅能运行。第二阶段为成对比较，对前4名脚本进行两两对比，通过交换呈现顺序消除位置偏差，并引入非传递性偏好检测机制。若出现 $A>B, B>C, C>A$ 的循环偏好，则触发额外评估轮次。这一机制通过多模型共识与逻辑一致性检查，显著提升了脚本选择的稳定性与可解释性，解决了单一LLM评审中因模型偏差导致的决策不可靠问题。

## 实验评估

实验在古巴导弹危机13天战略博弈场景中进行，对比基线为全因子设计（Full Factorial Design）。FSTS生成的实验方案在保持结果分布一致性的同时，显著减少了实验规模。在语义相似度评估中，使用Sentence-BERT计算智能体决策与历史领导人行动的相似度为53.50，而使用GPT-5 mini评估则达到72.50。最终模拟结果为“和平解决但关系紧张”，与历史事实一致。

| 方法 | 运行时间 (s) | 结果熵 | Top-1 置信度 |
| :--- | :--- | :--- | :--- |
| Single (单答案评分) | 1.295 | 0.60 | - |
| Pairwise (成对比较) | 1.000 | 0.50 | - |
| Both (两者结合) | 0.722 | 0.80 | - |

| 方法 | $p_1$ (和平) | $p_2$ (紧张和平) | $p_3$ (局部战争) | $p_4$ (全面战争) |
| :--- | :--- | :--- | :--- | :--- |
| Full Factorial | 0.091 | 0.708 | 0.123 | 0.078 |
| FSTS (Ours) | 0.148 | 0.593 | 0.148 | 0.111 |

消融实验显示，结合单答案评分与成对比较的方法（Both）在运行时间（0.722s）与结果熵（0.80）上均优于单一方法，表明多阶段筛选机制在效率与稳定性之间取得了更优平衡。在实验简化方面，FSTS生成的方案在 $p_1$ 至 $p_4$ 的概率分布上与全因子设计保持高度一致，验证了其在降低计算成本的同时保持统计有效性的能力。

评估边界方面，本文主要依赖单一历史场景的定性一致性与语义相似度指标，缺乏跨场景的统计显著性验证。语义相似度72.50仅反映文本层面的相似性，无法直接证明微观决策机制与历史真实机制的因果一致性。此外，实验未报告置信区间，且未与GANG、Agent-Kernel等基础设施框架进行直接对比，限制了其在通用社会模拟领域的可比性。代码已公开，但超参数设置细节仅在附录中提供，复现性依赖于特定LLM版本（GPT-4o, GPT-5 mini）的可用性。

## 关联研究分析

从问题动机看，FSTS与EASE配置框架存在互补关系。EASE侧重于提供标准化的仿真描述语言以解决不同研究间设置不可比的问题，属于“事后标准化”；而FSTS侧重于从高层意图自动生成此类标准化配置，属于“事前生成”。FSTS的引入使得EASE所依赖的标准化配置不再依赖人工编写，而是由LLM智能体自动编译，这解决了EASE框架中“配置灵活性”与“可复现性”之间的部分矛盾，但FSTS生成的脚本质量仍受限于LLM的推理能力，且未涉及EASE中评估指标的深度集成。

从方法设计看，FSTS与TRAILS鲁棒性审计框架在应对LLM偏差上采取了不同策略。TRAILS通过审计提示格式微小变化对宏观结果的影响，揭示了LLM仿真的“蝴蝶效应”，强调事后审计与声明限制；而FSTS通过多模型投票与两阶段筛选机制，试图在设计阶段消除脚本生成的随机性，隐含了“偏差可通过结构化流程消除”的假设。这种差异反映了领域内“建模论”与“消除论”的分歧：FSTS倾向于通过流程控制消除偏差，而TRAILS倾向于通过定量诊断承认并量化偏差。FSTS的多模型投票是否真正消除了LLM的固有社会倾向，还是仅平滑了随机噪声，论文未给出跨文化或跨模型族的验证，这一盲区限制了其结论的普适性。

## 总结

FSTS旨在解决LLM社会模拟中实验设计自动化与科学严谨性之间的矛盾，通过引入电影制作流程的多智能体协作机制，将高层研究意图编译为结构化实验脚本。该框架在古巴导弹危机场景中实现了与历史结局的一致性复现，语义相似度达72.50（GPT-5 mini），并显著降低了实验规模。然而，其有效性验证局限于单一历史事件，且依赖语义相似度这一表面指标，未能深入验证微观决策机制的因果解释力。当面对非历史、无明确结局的开放社会系统时，FSTS生成的脚本能否保持同样的逻辑一致性与机制解释力，论文未给出回答。
