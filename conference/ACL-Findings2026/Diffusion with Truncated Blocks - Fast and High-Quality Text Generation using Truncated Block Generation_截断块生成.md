# ACL-Findings2026最新论文 ｜Diffusion with Truncated Blocks: Fast and High-Quality Text Generation using Truncated Block Generation ｜截断块生成

作者：Yuyan Zhou、Weiyu Chen、James Kwok

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_c31a76db69d3)

> 掩码扩散语言模型（Masked Diffusion Language Models, MDLM）在并行解码时面临注意力被大量无信息掩码稀释的困境，导致长序列生成质量下降。现有采样策略要么固定长度造成计算浪费，要么全序列去噪引发注意力分散。本文提出截断块生成（Truncated Block Generation, TBG），通过分块迭代与动态截断保留高信息密度上下文，实现加速与提质。该方法在Dream-7B上显著优于基线，但绝对性能仍落后于当前强化学习对齐后的SOTA，且对序列级噪声模型增益有限。

## 研究背景

当模型在推理阶段面对长提示词时，若一次性追加大量掩码token，模型对关键上下文的注意力权重会随掩码数量增加而指数级衰减。这一现象源于双向注意力机制中，无信息掩码token与提示词token竞争注意力资源。为量化这种信息贡献，Dream模型引入了基于几何分布的token级噪声加权，旨在让模型优先预测上下文支持度高的token，但这反而加剧了推理时的注意力分散。

MDLM旨在突破自回归模型串行解码的效率瓶颈，通过迭代去噪并行生成文本。主流路线如LLaDA采用序列级噪声，所有掩码位置损失权重相同；Dream采用token级噪声，动态重加权以区分信息量。然而，固定长度生成导致短答案计算冗余，而全序列去噪则因掩码过多稀释注意力。本文切入点在于揭示token级噪声训练导致的“注意力稀释”机制，并设计一种采样策略，在保持生成完整性的同时，始终让模型关注高密度信息上下文。

## 核心方法

### 方法参照系

标准MDLM采样流程为：提示词后追加固定长度掩码块，通过置信度或熵阈值迭代去噪直至完成。该流程假设掩码块内所有位置同等重要，且生成长度固定。本文问题与该通用流程的关键差异在于：长掩码块中大量无信息token稀释了对提示词的注意力，且固定长度无法适应变长输出需求。

### 注意力稀释机制

本文指出，在token级噪声训练下，远离提示词的掩码token信息量低于阈值$\epsilon$，成为“无信息”token。定义第$i$个掩码token的上下文注意力$CA(m_i)$为其对所有信息量大于$\epsilon$的token的注意力之和。理论证明表明，当追加掩码数量$m_2 - m_1$足够大时，$CA(m_i)$严格小于短序列下的对应值。具体而言，对于几何分布加权$w(x_t, n) = \sum_{i=1}^{N} \mathbb{1}[x^i_t \neq \text{MASK}] \text{Geo}(\rho, |n-i|-1)$，当$n$增大时，$w(x_t, n)$指数衰减。这解释了为何Dream模型在长序列上性能下降：模型注意力被分散到大量仅携带位置信息的无意义掩码上，而非提示词中的关键语义。

### 截断块生成算法

TBG将生成过程分为多轮，每轮追加一个短掩码块（如64 token），去噪后截断保留部分已生成token作为新上下文。核心公式为截断决策：若有效生成长度$< \gamma$，则生成结束；否则，将序列截断至预定长度，重新掩码边界token并追加新块。这一设计解决了固定块生成中模型因感知序列边界而提前输出EOS的问题。通过重掩码边界，TBG向模型传递“序列未完成”信号，使其能连贯地跨块生成。相比全序列去噪，TBG确保每步注意力集中在高信息密度上下文，从而缓解稀释效应。

## 实验评估

| 数据集 | 模型 | 基线准确率 (%) | TBG准确率 (%) | 提升幅度 |
| :--- | :--- | :--- | :--- | :--- |
| HumanEval | Dream-7B | 48.7 | 52.4 | +3.7 |
| MBPP | Dream-7B | 57.2 | 60.4 | +3.2 |
| GSM8K | Dream-7B | 78.01 | 78.92 | +0.91 |
| MATH | Dream-7B | 42.80 | 43.98 | +1.18 |

实验在HumanEval、MBPP、GSM8K和MATH上进行，基线包括Dream-7B-Instruct和LLaDA-8B-Instruct。TBG在Dream-7B上全面优于基线，尤其在代码生成任务上提升显著。然而，与LLaDA-8B相比，TBG在HumanEval上仅从37.2%提升至40.2%，提升幅度较小，这与LLaDA采用序列级噪声、本身不易受注意力稀释影响的结论一致。

消融实验显示，截断长度对性能影响显著。在Math数据集上，当截断长度设为30时，验证集和测试集准确率均达到峰值38.42%。块数从1增加到2时，MBPP和HumanEval准确率分别从58.0%和43.9%提升至60.4%和52.4%，但增加到3块后性能饱和，表明额外块数不再带来增益。这验证了TBG在平衡生成完整性与计算开销上的有效性，但也揭示了其边际收益递减的特性。

评估边界方面，论文未报告置信区间，且仅在A6000 GPU上测试。指标完备性上，缺乏长文本一致性评测，且未对比SPG、DISPO等强化学习对齐方法。可复现性上，论文未提供代码链接，但超参数（块长64，最大块数2）已明确。

## 关联研究分析

从问题动机看，TBG与Block Diffusion（Liu et al., 2025）均关注分块生成，但Block Diffusion主要解决KV缓存复用问题，而TBG聚焦于注意力稀释。Block Diffusion通过块级自回归生成保持全局一致性，但可能损失部分全局推理能力；TBG通过截断机制保留高信息上下文，但可能引入块间依赖断裂。这一差异源于任务特性：代码生成对局部结构敏感，而数学推理对全局逻辑依赖更强。

从方法设计看，TBG与Fast-dLLM（Wu et al., 2025）具有互补性。Fast-dLLM通过块KV缓存和并行解码加速，但导致准确率从48.7%降至40.2%；TBG结合Fast-dLLM后，速度提升至4.3倍，准确率恢复至46.3%。这表明TBG不仅是一种采样策略，更是一种质量-速度权衡的调节器。然而，TBG在GSM8K上提升仅0.91%，远低于HumanEval的3.7%，暗示其效果可能受任务类型影响，数学推理中注意力稀释并非主要瓶颈。

## 总结

本文核心矛盾在于MDLM并行解码中注意力稀释与生成完整性的冲突。切入点在于揭示token级噪声训练导致的无信息掩码稀释效应，并通过截断块生成保留高信息密度上下文。TBG在Dream-7B上实现HumanEval 52.4%和MBPP 60.4%的准确率，较基线提升3.2-3.7%。其边界在于对序列级噪声模型增益有限，且绝对性能仍低于RL对齐后的SOTA。当支持集增大到5-shot时，截断长度的最优值是否随任务复杂度变化，论文未给出回答。
