作者：Cheng Yang、Xuemeng Yang、Licheng Wen 等 13 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_bad481343316)

> 静态大语言模型在部署后无法从过往交互中积累经验，导致其在长程生产力任务中表现受限且无法持续改进。现有非参数化反思方法多依赖线性文本存储，缺乏结构化知识组织，而参数化更新则面临高计算成本与灾难性遗忘风险。MUSE 通过分层记忆模块将原始执行轨迹蒸馏为可复用的标准作业程序，实现了无需微调的测试时学习。该框架在 TAC 基准上以轻量级模型刷新了性能纪录，但其记忆检索机制在大规模库下的扩展性仍存疑。

## 研究背景

当智能体在操作系统中执行跨应用任务时，其决策依赖于对当前观察 $o_t$ 与历史轨迹 $h_t$ 的策略映射 $a_t \sim \pi_{test}(a_t | h_t)$。然而，静态模型缺乏将单次任务的成功或失败转化为持久知识的能力，这种“一次性”交互模式使得智能体无法像人类专家那样通过实践积累经验，导致在重复或相似任务中无法提升效率。为突破这一瓶颈，测试时适应（Test-Time Adaptation）成为关键路径，它要求智能体在部署阶段通过外部组件更新实现能力增长，而非依赖昂贵的权重微调。

自进化智能体领域的主流路线分为非参数化记忆与参数化内化两类。非参数化方法如 Reflexion 和 ExpeL 通过自然语言反思存储经验，部署灵活但受限于上下文窗口与检索精度；参数化方法如 EvolveR 通过强化学习将经验蒸馏为权重，虽能实现深层固化，但面临灾难性遗忘与高计算开销。MUSE 的切入点在于解决非参数化路线中经验组织松散的问题，通过构建分层记忆结构，将原始动作序列转化为结构化的标准作业程序（SOP），从而在保持模型冻结的前提下，实现跨任务的经验迁移与复用。

## 核心方法

### 分层记忆架构

MUSE 的参照系是传统的“推理-行动”循环，其关键差异在于引入了独立的记忆模块 $\mathcal{M}$，该模块不修改模型权重，而是通过外部存储实现知识累积。记忆模块由战略记忆 $\mathcal{M}_{strat}$、程序记忆 $\mathcal{M}_{proc}$ 和工具记忆 $\mathcal{M}_{tool}$ 组成，分别对应宏观策略、子任务流程与单工具操作。这种分层设计解决了线性文本记忆在长程任务中检索精度低、上下文膨胀的问题，使得智能体能够按需加载特定层级的知识。

### 轨迹蒸馏与 SOP 生成

程序记忆 $\mathcal{M}_{proc}$ 的核心创新在于将成功的子任务轨迹 $h_{k:t}$ 蒸馏为标准作业程序 $p_{new}$。这一过程由 Reflect Agent 执行，其设计动机是解决原始轨迹冗余度高、难以直接复用的问题。SOP 被定义为索引与内容的二元组 $p = (index_p, content_p)$，其中 $index_p$ 轻量级加载至上下文，$content_p$ 仅在需要时通过工具 $a_{mem}$ 检索。这种机制使得智能体在面临不确定性时能主动查询历史案例，模拟人类专家的行为。

$$
p_{new} = \text{Distill}(h_{k:t}, f_{success})
$$

该公式表示当子任务评估成功（$f_{success}=1$）时，Reflect Agent 从执行轨迹中提取关键步骤与参数，生成新的 SOP 并加入记忆库。这一过程将隐性的操作经验显性化为可检索的结构化知识，显著降低了后续任务的探索成本。

### 自适应规划与反思闭环

PE Agent 负责将主任务分解为子任务队列 $Q = [st_1, st_2, \dots, st_M]$，并在每个子任务执行后根据 Reflect Agent 的反馈动态更新队列。Reflect Agent 通过真实性、交付物与数据保真度三个维度进行评估，若失败则生成诊断报告 $R_{fail}$ 并触发重规划。这一闭环机制解决了静态规划在长程任务中错误累积的问题，使得智能体能够根据环境反馈调整执行路径。

$$
Q_{t+1} = \text{Replan}(Q_t, R_{fail}, \mathcal{M}_{proc})
$$

该公式描述了子任务队列的更新过程，其中 $R_{fail}$ 提供失败原因，$\mathcal{M}_{proc}$ 提供历史成功模式。通过迭代更新 $Q$，MUSE 确保了长程任务执行的连贯性与稳定性，避免了因局部失败导致的整体任务崩溃。

## 实验评估

MUSE 在 TAC 基准上进行评估，该基准包含 175 个长程生产力任务，平均需 40 步操作。基线包括 OpenHands、OpenHands-Versa 等框架，但缺失 Reflexion、EvolveR 等纯记忆基线，限制了与非参数化路线的直接对比。

| 方法 | 模型 | Sckpt (%) | Avg. Spartial (%) |
| :--- | :--- | :--- | :--- |
| OpenHands-Versa | Claude-4 Sonnet | 50.52 | 43.19 |
| MUSE | Gemini-2.5 Flash | 59.92 | 51.78 |

MUSE 使用轻量级 Gemini-2.5 Flash 模型，在 TAC 全基准上取得 51.78% 的平均 Spartial，超越 OpenHands-Versa 的 43.19%，相对提升约 20%。这一结果证明了分层记忆机制在长程任务中的有效性，且无需依赖大规模模型。

| 配置 | Sckpt (%) | Avg. Spartial (%) | 耗时 (s) |
| :--- | :--- | :--- | :--- |
| PE Agent | 63.53 | 43.21 | 620.07 |
| + Reflect | 66.12 | 55.85 | 895.19 |
| + Memory | 73.18 | 64.61 | 993.05 |

消融实验显示，引入 Reflect Agent 使 Spartial 提升 12.64 个百分点，而加入记忆模块后进一步提升至 64.61%。记忆检索仅增加 97.86 秒延迟，却带来最大性能增益，表明结构化记忆是性能提升的关键。然而，Reflect Agent 引入的 275 秒延迟表明反思过程计算成本较高，可能限制实时部署。

评估协议未报告置信区间，且未提供代码与超参数细节，可复现性受限。TAC 基准虽具挑战性，但缺乏对记忆库规模扩展性的测试，无法验证当记忆条目增多时检索精度是否下降。此外，实验未对比参数化方法，无法量化非参数化路线在长期稳定性上的相对优势。

## 关联研究分析

从方法设计看，MUSE 与 Voyager 的技能库概念相似，但 Voyager 侧重于代码技能的积累，而 MUSE 聚焦于办公场景的 SOP 生成。这一差异源于任务特性：代码任务具有明确的执行反馈，而生产力任务涉及多应用交互，需要更抽象的策略指导。MUSE 通过战略记忆 $\mathcal{M}_{strat}$ 弥补了这一抽象层级的缺失，但论文未探讨当 SOP 数量增长时，索引检索的精度是否随库规模增加而衰减。

从问题动机看，MUSE 与 EvolveR 均关注经验固化，但 EvolveR 通过参数蒸馏实现长期能力内化，MUSE 则坚持非参数化路径。这一选择使得 MUSE 适用于闭源模型，但牺牲了参数化方法在跨域泛化上的潜在优势。论文未提供在相同计算预算下与非参数化方法的纵向对比，使得“非参数化是否优于参数化”这一核心分歧在 MUSE 的实验中无法得到直接验证。

## 总结

MUSE 旨在解决静态智能体在长程生产力任务中无法积累经验的问题，通过分层记忆模块将原始轨迹蒸馏为结构化 SOP，实现了无需微调的测试时学习。实验表明，该框架在 TAC 基准上以 Gemini-2.5 Flash 模型取得 51.78% 的 Spartial，超越前 SOTA 约 20%。然而，其记忆检索机制在大规模库下的扩展性未经验证，且反思过程引入的显著延迟限制了实时应用。当记忆库规模从百级增长至千级时，SOP 索引的检索精度是否仍能保持，论文未给出回答。
