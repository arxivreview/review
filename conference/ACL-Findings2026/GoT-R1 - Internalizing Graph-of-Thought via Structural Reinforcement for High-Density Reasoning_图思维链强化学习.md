# ACL-Findings2026最新论文 ｜GoT-R1: Internalizing Graph-of-Thought via Structural Reinforcement for High-Density Reasoning ｜图思维链强化学习

作者：Zuchao Li、Qiwei Li、Yao Yao 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_3a9b559dd62c)

> 线性思维链（Chain-of-Thought, CoT）在复杂推理中常因顺序生成导致冗余叙述与级联错误，现有外部搜索框架虽能缓解但引入高延迟与编排开销。GoT-R1 将推理重构为原子节点构成的有向无环图，并通过两阶段训练将图结构内化至模型权重，以拓扑密度替代文本长度。该方法在 GSM8K 上以 95.07% 准确率仅消耗 632,167 tokens，显著优于外部搜索基线，但其对推理忠实性的因果验证缺失，使得结构效率与逻辑真实性的关系仍存疑。

## 研究背景

当模型处理多步数学问题时，线性 CoT 的序列约束迫使每一步依赖前一步的完整上下文，一旦某步出现逻辑谬误，错误将沿链条传播至最终答案，即“级联错误”。为阻断这种传播，研究者引入树状（Tree-of-Thought, ToT）或图状（Graph-of-Thought, GoT）结构，允许并行探索与回溯。然而，这些框架通常作为外部控制器运行，依赖多次推理调用与提示工程，未能将图结构内化至模型原生权重，导致推理延迟高且难以规模化。

该领域长期面临“结构承诺”与“计算效率”的矛盾：外部搜索框架虽能提升准确率，但 token 开销巨大；而线性 CoT 虽高效，却易陷入“过度思考”的冗余循环。GoT-R1 的切入点在于将图结构从外部编排转化为内部生成能力，通过自动化数据合成与强化学习，使模型在单次前向传播中直接输出高信息密度的逻辑拓扑，从而在保持逻辑严谨性的同时最小化计算开销。

## 核心方法

### 图推理形式化

GoT-R1 将推理过程形式化为动态图构建任务，区别于线性 CoT 的刚性转移，其核心差异在于允许节点聚合多个前驱信息。给定查询 $Q$，推理轨迹定义为图 $G=(V, E)$，其中节点 $n_i$ 为原子逻辑单元，边 $E$ 表示逻辑依赖。前驱映射函数 $P(n_i) = \{n_j | (n_j, n_i) \in E\}$ 允许 $|P(n_i)| \ge 1$，使模型能非线性地整合分散的子结论，将复杂度从文本长度转移至图连通性。

### 自动化结构数据合成

为弥合语言轨迹与结构化逻辑的差距，GoT-R1 设计教师驱动提取管线 $\Phi$，将冗长 CoT 蒸馏为高保真逻辑骨架。节点分解通过 $n_i = \Phi(u_i; M_T) = \text{Distill}(u_i)$ 去除修辞填充，保留局部推导；关系拓扑提取则通过 $P(n_i) = \{n_j | j < i, \text{is\_req}(n_j, n_i; M_T) = \text{True}\}$ 识别最小充分前驱集。这一过程解决了外部框架依赖人工标注或复杂提示的问题，实现了从自然语言到结构化数据的自动化转换。

### 双阶段强化学习内化

在监督预对齐后，GoT-R1 采用组相对策略优化（Group Relative Policy Optimization, GRPO）进行多目标优化。奖励函数 $R_i = w_1 R_{\text{task}} + w_2 R_{\text{graph}} + w_3 R_{\text{fmt}} - w_4 P_{\text{len}}$ 平衡任务准确性、结构完整性与长度惩罚。其中 $R_{\text{graph}}$ 包含语法可解析性、稀疏性优化与非线性激励，防止模型退化为线性链或生成冗余“毛球”拓扑。优势函数 $A_i = \frac{R_i - \text{mean}(\{R_j\})}{\text{std}(\{R_j\})}$ 通过组内归一化降低方差，迫使模型在保持逻辑正确性的同时压缩推理路径，实现从叙事型 CoT 到高密度图推理的范式转移。

## 实验评估

实验基于 Qwen3 系列（4B/8B/14B）在 GSM8K、IFEval、TruthfulQA 和 Winogrande 上评估，基线涵盖开源推理模型及外部搜索框架（ToT, GoTs, DoT）。GoT-R1 在 GSM8K 上表现突出，4B 模型达 95.07%，8B 达 96.74%，显著优于同规模基线。

| 方法 | GSM8K Acc (%) | Total Token Cost |
| :--- | :--- | :--- |
| ToT | 70.81 | 33,465,008 |
| GoTs | 90.67 | 4,308,170 |
| DoT | 51.02 | 1,529,600 |
| GoT-R1 (4B) | 95.07 | 632,167 |

GoT-R1 以 ToT 1.8% 的 token 预算实现了最高准确率，验证了内部化图结构在效率-准确率帕累托前沿上的优势。

消融实验显示，仅引入任务奖励 $R_{\text{task}}$ 可将 GSM8K 准确率从 93.71% 提升至 94.31%，而加入长度惩罚 $P_{\text{len}}$ 后进一步提升至 95.07%。值得注意的是，单独使用 GRPO 而无结构奖励时，准确率降至 90.75%，表明结构完整性约束对防止推理退化至关重要。

评估边界方面，论文未报告置信区间，且缺乏对推理忠实性的独立验证。虽然 TruthfulQA 准确率从 74.42% 提升至 84.82%，但高准确率是否掩盖了内部逻辑缺陷，仍需通过因果干预或机制可解释性方法进一步审计。

## 关联研究分析

从问题动机看，GoT-R1 与 FaithCoT-Bench 等忠实度评估基准存在根本分歧。前者旨在通过结构优化提升效率与准确率，后者则关注 CoT 文本是否真实反映内部计算。GoT-R1 的原子节点设计虽减少了叙事冗余，但未提供因果证据证明图结构驱动了最终答案，其“高信息密度”可能仅表现为格式合规，而非逻辑忠实。这种效率导向与忠实性审计的脱节，使得 GoT-R1 在高风险应用中仍面临“表演性推理”的风险。

从方法设计看，GoT-R1 与 ToT/GoTs 等外部搜索框架的关键差异在于内部化程度。ToT 依赖 BFS 搜索与价值评估，GoT-R1 则通过 GRPO 将搜索逻辑内化至权重。然而，GoT-R1 的自动化数据合成依赖教师模型 $M_T$ 的质量，若教师模型本身存在逻辑偏差，蒸馏出的图结构将继承这些缺陷。此外，GoT-R1 未探索图结构在对抗性提示下的鲁棒性，其稀疏性惩罚可能在面对复杂干扰时导致关键逻辑节点被错误剪枝，这一潜在脆弱性在现有实验中未被充分揭示。

## 总结

GoT-R1 旨在解决线性 CoT 的冗余与级联错误问题，通过图结构内化实现效率与准确率的平衡。其核心创新在于自动化结构合成与 GRPO 多目标优化，使模型在单次推理中生成高密度逻辑拓扑。实验表明，GoT-R1-4B 在 GSM8K 上以 95.07% 准确率仅消耗 632,167 tokens，显著优于外部搜索基线。然而，论文未验证图结构的因果忠实性，高准确率可能源于格式优化而非逻辑严谨性。当面对需要严格逻辑审计的高风险任务时，GoT-R1 的图结构是否真正驱动了答案，而非仅作为高效的事后合理化载体，这一核心问题仍未得到解答。
