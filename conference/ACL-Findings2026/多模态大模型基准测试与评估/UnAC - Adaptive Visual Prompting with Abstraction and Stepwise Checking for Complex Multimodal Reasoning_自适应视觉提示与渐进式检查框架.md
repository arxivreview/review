# ACL-Findings2026最新论文 ｜UnAC: Adaptive Visual Prompting with Abstraction and Stepwise Checking for Complex Multimodal Reasoning ｜自适应视觉提示与渐进式检查框架

研究机构：美国东北大学

作者：Yifan Wang、Yun Fu

论文原文见 [arXiv](https://arxiv.org/abs/2605.03950)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.03950)

> 多模态大语言模型（Large Multimodal Models, LMMs）在处理复杂视觉推理任务时，常因细粒度感知缺失与中间步骤逻辑断裂导致最终答案错误。现有纯文本提示方法难以有效分解图像信息，而单一视觉标记提示又缺乏对推理过程的验证机制。UnAC通过结合问题条件化的自适应视觉提示、图像信息抽象及逐步自我检查，构建了一个无需训练的多模态提示框架。该框架在多个基准上提升了模型表现，但其增益高度依赖骨干模型的底层推理能力，且对特定分割工具的依赖限制了其通用性。

## 研究背景

当LMMs面对包含几何图形或复杂图表的数学问题时，其失败往往源于对图像局部细节的误读或关键信息的遗漏，这一现象被称为细粒度感知局限。由于图像无法像句子那样被自然语言直接分解，直接套用链式思维（Chain-of-Thought, CoT）等纯文本提示策略往往失效。为弥补这一缺陷，研究者引入了视觉提示技术，通过在图像上叠加标记来引导模型注意力，但单纯的视觉标记仅能改善感知，无法纠正模型在后续推理步骤中产生的逻辑错误。

多模态推理评估领域正从关注最终答案准确率转向诊断推理过程的可靠性。主流路线包括基于场景图的组合知识提取（如CCoT）和基于图像分割的视觉标记提示（如SoM）。然而，这些方法存在明显瓶颈：纯文本CoT难以处理视觉证据的提取，而SoM等视觉提示方法在解决需要多步证据整合的复杂问题时，往往因缺乏对中间推理步骤的验证而导致性能提升有限，甚至在某些情况下产生负迁移。UnAC的切入点在于将视觉感知与推理验证解耦，通过问题驱动的方式动态构建视觉提示，并引入逐步检查机制来确保推理链的每一步都基于准确的视觉证据。

## 核心方法

### 方法参照系

UnAC属于多模态提示工程范畴，其参照系为传统的视觉提示方法（如SoM）与文本CoT方法。关键差异在于，传统方法通常采用静态或全局的视觉标记，且缺乏对推理过程的显式验证；UnAC则引入了问题条件化的动态提示构建与逐步自我检查机制，将感知、抽象与验证整合为闭环流程。

### 自适应视觉提示构建

传统视觉提示方法通常对图像进行全局或固定区域的分割，忽略了问题对特定视觉信息的依赖。UnAC首先让LMMs分析问题，识别出需要提取的“具有语义意义的对象”和“具有字面意义的符号”。对于对象，使用SEEM分割模型进行自动分割；对于符号，使用OCR检测文本。基于分割/OCR输出的稳定性分数进行去噪，仅保留高置信度区域作为视觉提示。这一设计解决了静态提示无法聚焦问题相关区域的问题，减少了无关视觉噪声对模型注意力的干扰。

$$
V_{prompt} = \{ r_i \in R \mid S(r_i) > \tau \}
$$

其中 $R$ 为分割或OCR检测到的所有区域，$S(r_i)$ 为区域 $r_i$ 的稳定性分数，$\tau$ 为阈值。该公式表示仅保留稳定性高于阈值的区域作为最终视觉提示，确保提示的准确性。

### 图像抽象与渐进式检查

视觉提示解决了“看什么”的问题，但模型仍需从标记区域中提取关键信息并整合到推理中。UnAC引入图像抽象阶段，要求LMMs基于视觉提示描述图像全局信息，并进一步提取与问题最相关的局部细节，将视觉信息转化为文本描述。随后，引入渐进式检查机制，将问题分解为子问题序列 $[Q_0, Q_1, \dots, Q_n]$，逐步生成答案 $[A_0, A_1, \dots, A_n]$。在检查阶段，验证 $Q_i$ 和 $A_i$ 时，仅参考前序已验证的问题和答案 $[Q_0, \dots, Q_i]$ 和 $[A'_0, \dots, A'_i]$。这种逐步验证避免了全局检查中因前序错误累积导致的失效，确保了推理链的每一步都基于准确的视觉上下文。

$$
A'_i = \text{Check}(Q_i, A_i, \{Q_j, A'_j \mid j < i\}, V_{prompt})
$$

该公式表示第 $i$ 步的验证答案 $A'_i$ 依赖于当前问题、初步答案、前序已验证的问答对以及视觉提示。通过局部上下文验证，降低了错误传播风险。

## 实验评估

| 模型 | 基准 | 基线准确率 (%) | UnAC准确率 (%) | 增益 (%) |
| :--- | :--- | :--- | :--- | :--- |
| GPT-4V | MathVista | 50.7 | 57.6 | 4.9 |
| Gemini-1.5-Flash | MathVista | 53.2 | 56.6 | 3.4 |
| InternVL2.0-8B | MathVista | 67.3 | 71.6 | 4.3 |
| GPT-4V | MMMU | 57.2 | 60.7 | 3.5 |

UnAC在MathVista和MMMU上均取得一致提升，其中GPT-4V在MathVista上增益最大（4.9%），InternVL2.0-8B增益达4.3%，显著优于CCoT（0.9%）和SKETCHPAD（0.8%）。在MM-Vet上，GPT-4V增益为3.1%，Gemini-1.5-Flash在MMMU上增益最大（4.8%）。

| 视觉提示类型 | MathVista准确率 (%) |
| :--- | :--- |
| 基线 | 53.2 |
| 仅分割 | 54.2 |
| 仅OCR | 53.3 |
| 分割+OCR | 54.4 |
| 自适应视觉提示 | 56.6 |

消融实验表明，自适应视觉提示比单一分割或OCR带来更大增益（56.6% vs 54.4%），验证了问题条件化动态提示的有效性。在检查机制消融中，GPT-4V使用渐进式检查（57.6%）显著优于全局检查（53.4%）和无检查（52.7%），证实了逐步验证对复杂推理的重要性。

评估边界方面，论文未报告置信区间，数值比较需谨慎。实验依赖SEEM分割和easyOCR工具，未探讨其他分割模型的适用性。代码未公开，但使用了开源工具，可复现性中等。

## 关联研究分析

从问题动机看，UnAC与SoM（Yang et al., 2023a）均旨在通过视觉标记改善感知，但SoM采用全局或固定区域分割，而UnAC引入问题条件化的自适应提示。这一差异源于SoM未考虑问题对特定视觉信息的依赖，导致无关区域干扰模型注意力。UnAC通过问题分析动态选择提示区域，解决了静态提示在复杂任务中效率低下的问题。然而，UnAC对SEEM分割模型的依赖可能限制其在不同视觉场景下的通用性，查询侧增强在数据充足时是否仍有增益，论文未给出回答。

从方法设计看，UnAC与CCoT（Mitra et al., 2023）均涉及推理过程优化，但CCoT基于场景图提取组合知识，属于纯文本CoT变体，而UnAC结合了视觉提示与逐步检查。CCoT在视觉任务上效果有限（0.9%增益），凸显了纯文本方法在处理视觉证据时的不足。UnAC通过图像抽象将视觉信息转化为文本，再结合逐步检查，实现了感知与推理的协同。这种设计比CCoT更贴近多模态推理的本质，但增加了计算开销，且对骨干模型的推理能力要求更高。

## 总结

UnAC旨在解决LMMs在复杂视觉推理中因感知缺失与逻辑断裂导致的错误。其切入点在于将视觉提示与推理验证解耦，通过问题条件化的动态提示和逐步检查机制，弥补了静态视觉提示和纯文本CoT的不足。实验表明，UnAC在MathVista上为GPT-4V带来4.9%的增益，在MMMU上为Gemini-1.5-Flash带来4.8%的增益，验证了其有效性。然而，论文实验显示，UnAC的增益高度依赖骨干模型的底层推理能力，LLaVA-v1.6-7B的增益（2.6%）显著低于GPT-4V（4.9%），且对SEEM分割工具的依赖限制了其通用性。当骨干模型推理能力较弱时，视觉提示与检查机制的协同效果是否仍能保持，论文未给出回答。
