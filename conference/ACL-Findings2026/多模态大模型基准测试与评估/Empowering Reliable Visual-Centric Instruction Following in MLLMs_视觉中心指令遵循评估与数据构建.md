# ACL-Findings2026最新论文 ｜Empowering Reliable Visual-Centric Instruction Following in MLLMs ｜视觉中心指令遵循评估与数据构建

研究机构：香港科技大学、美国宾夕法尼亚大学

作者：Weilei He、Feng Ju、Zhiyuan Fan 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.03198)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.03198)

> 多模态大语言模型（MLLMs）在指令遵循任务中常依赖文本先验而非视觉证据，导致评估分数虚高且无法反映真实视觉理解能力。现有基准如MM-IFEval仅评估文本模式匹配，忽视了图像中隐含的空间与属性约束，使得模型即使忽略视觉输入也能通过测试。本文通过构建视觉中心的数据集与混合评估协议，将视觉约束显式纳入指令遵循的度量体系。该工作填补了视觉指令遵循评估的空白，但其7B模型实验规模与单一裁判模型依赖限制了结论的普适性。

## 研究背景

当用户要求模型“描述图像中左侧人物的动作”时，模型若仅凭文本模式生成“一个人在行走”而忽略图像中人物实际静止的事实，即暴露了视觉依赖性的缺失。这种依赖文本先验而非视觉证据的现象称为语言捷径，它导致模型在视觉中心任务上表现不佳。为量化视觉贡献，需引入图像影响分数（Image Influence Score, IIS），通过对比有图与无图输出的差异来剥离非视觉因素。

多模态指令遵循评估长期受限于数据稀缺与基准偏差。主流基准如MM-IFEval（Ding et al., 2025）和IFEval（Zhou et al., 2023）主要评估文本指令的合规性，其约束可通过规则匹配验证，但无法处理空间关系、物体属性等视觉约束。这导致评估结果反映的是语言模型骨干的能力，而非多模态整合能力。本文切入点在于构建视觉中心的数据与评估体系，通过显式建模视觉约束，区分模型是真正利用视觉信息还是仅靠文本模式匹配。

## 核心方法

### 方法参照系

多模态指令遵循评估通常采用规则匹配与LLM判断结合的方式，但该方法假设指令约束可文本化验证。本文问题的关键差异在于约束的视觉依赖性：空间、属性等约束无法通过文本规则验证，需引入视觉输入作为评估变量。

### 视觉中心数据构建管线

VC-IFEngine管线通过图像过滤、任务生成与约束生成三阶段构建视觉中心数据。图像过滤采用IC9600指标（Feng et al., 2023）与RAM模型（Zhang et al., 2023）确保视觉信息密度与显著性，阈值设为0.50。任务生成阶段对无标注图像从外部任务池采样，对已有标注图像进行视觉化精炼。约束生成阶段从10类约束池中采样，经LVLM精炼与VLM质量判断，确保约束与图像内容一致。该设计解决了现有数据缺乏视觉接地示例的问题，使训练数据显式包含空间、风格等视觉约束。

$$
T_I = M(I, T_e \subset P_T)
$$

该公式表示模型$M$基于图像$I$与候选任务子集$T_e$生成最终任务列表$T_I$，确保任务与视觉语义对齐。

### 混合评估协议

VC-IFEval采用直接评估与对比评估结合的混合策略。直接评估使用GPT-4o作为裁判，计算约束遵循准确率（Constraint-following Accuracy, CFA）。对比评估生成有图与无图输出，由裁判判断视觉输入是否提升约束满足度，计算图像影响分数（IIS）。最终分数定义为：

$$
\text{Score} = \frac{1}{N} \sum_{i=1}^{N} (CFA_i + IIS_i)
$$

该公式平衡约束遵循与视觉利用，消除模型仅靠文本先验通过评估的偏差。人工验证显示，直接判断与对比判断的人机一致率分别为90%与92%，跨模型一致率86%，验证了协议可靠性。

## 实验评估

实验在Qwen2.5-VL-7B-Instruct与LLaVA-NeXT-Llama3-8B上进行，使用H20 96GB GPU，学习率1e-5，批次大小8。基线覆盖开源7B/8B模型，但缺失GPT-4o等闭源SOTA对比，仅将其作为裁判。

| 模型 | VC-IFEval | MM-IFEval | IFEval |
| :--- | :--- | :--- | :--- |
| Qwen2.5-VL-7B-Instruct | 57.3 | - | - |
| w. VC-IFInstruct | 63.0 | - | - |
| w. VC-IFDPO | 66.1 | - | - |
| LLaVA-NeXT-Llama3-8B | - | - | - |

Qwen2.5-VL-7B在VC-IFEval上从57.3提升至66.1（DPO后），提升8.8个点。据领域综述，Qwen2.5-VL-32B基线为67.3%，7B模型经训练后接近32B水平，表明数据有效性。

消融实验显示，DPO中完全移除约束（-100%）效果最佳，而移除所有图像输入效果较弱。这表明视觉编辑比省略视觉输入更有效，强调视觉接地在偏好学习中的关键作用。

评估边界方面，VC-IFEval仅含300个样本，规模较小；评估依赖GPT-4o单一裁判，虽有人工验证但未报告置信区间；代码未公开，可复现性受限。

## 关联研究分析

从问题动机看，本文与TsT（Brown et al., 2025）均通过控制变量量化非视觉贡献，但TsT使用交叉验证审计基准污染，本文使用无图对比评估指令遵循中的视觉依赖。差异根源在于任务特性：TsT关注基准本身的可靠性，本文关注模型在特定任务中的视觉利用。从方法设计看，本文与V-FAT（Wang et al., 2026）均关注视觉-文本冲突，但V-FAT侧重幻觉诊断，本文侧重指令执行。本文未探索多步推理场景，其视觉约束评估是否适用于复杂推理链，论文未给出回答。

## 总结

本文核心矛盾在于多模态指令遵循评估中视觉贡献的不可量化。现有方法因约束文本化假设而失效，本文通过视觉中心数据构建与混合评估协议，将视觉约束显式纳入度量。实验证明7B模型经训练后VC-IFEval分数从57.3提升至66.1，接近32B基线67.3。其边界在于样本规模小、依赖单一裁判、未探索多步推理。当视觉约束扩展至多步推理任务时，混合评估协议中的图像影响分数是否仍能准确区分视觉依赖与文本先验，论文未给出回答。
