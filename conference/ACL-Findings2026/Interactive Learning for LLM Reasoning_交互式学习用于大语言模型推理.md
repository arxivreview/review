# ACL-Findings2026最新论文 ｜Interactive Learning for LLM Reasoning ｜交互式学习用于大语言模型推理

研究机构：香港科技大学、中山大学

作者：Hehai Lin、Shilei Cao、Sudong Wang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.26306)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.26306)

> 多智能体大语言模型系统（Multi-Agent LLM Systems, MAS）旨在通过协作突破单模型推理局限，但现有方法在推理阶段仍需重新执行整个智能体系统，导致部署成本高且与人类“通过交流内化知识后独立解题”的认知模式不符。ILR 提出在训练阶段引入多智能体交互，使单个大语言模型（Large Language Model, LLM）在推理时能独立解决复杂问题。该方法通过动态交互模块模拟人类讨论，结合感知校准模块优化奖励信号，利用组相对策略优化（Group Relative Policy Optimization, GRPO）更新模型参数。ILR 在数学推理基准上超越了单智能体与多智能体基线，但其效果依赖于特定模型组合，且未验证在更广泛任务类型上的泛化能力。

## 研究背景

当 LLM 面对超出其独立推理能力边界的复杂数学问题时，单智能体学习范式（如监督微调、偏好学习）往往陷入局部最优，难以突破个体认知盲区。为克服这一局限，研究者引入多智能体协作，但传统方法将智能体视为系统组件，优化目标聚焦于系统整体性能，导致推理时必须依赖多个模型协同工作。这种“推理时依赖”与人类学习机制存在根本差异：人类通过同伴讨论内化知识后，能够独立解决类似问题。

现有 MAS 研究主要沿两条路线演进：一是通信拓扑优化，如 GPTSwarm 和 G-Designer 通过动态调整智能体间连接结构提升信息流动效率；二是强化学习协同优化，如 M-GRPO 和 AgentPO 通过策略梯度调整智能体行为以最大化系统联合性能。然而，这些方法均将多智能体交互视为推理时的必要环节，未探索交互过程对单个智能体独立推理能力的长期影响。ILR 的切入点在于将多智能体交互从“推理时协作”转变为“训练时认知内化”，通过模拟人类讨论动态（合作与竞争），使 LLM 在训练阶段吸收同伴的推理策略，从而在推理阶段独立解决复杂问题。

## 核心方法

### 方法参照系

ILR 属于强化学习协同优化路线，但与传统 MAS 训练流程存在关键差异：传统方法优化系统级协作性能，推理时需执行完整 MAS；ILR 优化单个 LLM 的独立推理能力，推理时仅需单模型。这一差异源于对“多智能体交互价值”的不同定位：前者视交互为信息交换手段，后者视交互为认知内化过程。

### 动态交互与难度估计

动态交互模块解决传统 MAS 中“固定交互模式”导致的效率低下问题。通常做法是预设合作或竞争策略，但 ILR 引入项目反应理论（Item Response Theory, IRT）动态选择交互模式。给定问题 $q$ 和 LLM $i$ 的推理能力 $\gamma_i$，独立解题概率 $P_{q,i}$ 计算为：

$$
P_{q,i} = \frac{1}{1 + e^{-1.7(\gamma_i - D_q)}}
$$

其中 $D_q$ 为问题难度分数，通过 LLM 自排序估计。当 $P_{q,i} < 0.5$ 时选择合作模式，否则选择竞争模式。这一设计解决了固定策略在简单问题上引入噪声、在复杂问题上缺乏互补性的问题，使交互模式与问题难度自适应匹配。

### 感知校准与奖励优化

感知校准模块解决传统多智能体强化学习中“奖励信号稀疏且噪声大”的问题。通常做法是手动定义协作奖励，但 ILR 提出自动化机制：将 LLM $l$ 的奖励分布特征（最大值 $R_{l,max}$、最小值 $R_{l,min}$、平均值 $R_{l,avg}$）注入 LLM $i$ 的奖励函数。最终奖励 $\bar{R}_{i,k}$ 计算为：

$$
\bar{R}_{i,k} = R_{i,k} + \delta_{i,l} \cdot (R_{l,avg} - R_{i,avg})
$$

其中 $\delta_{i,l}$ 为稳定化操作，防止极端值。这一设计使 LLM 能感知同伴解题质量，调整自身推理策略，解决了手动奖励信号粒度粗、可扩展性差的问题。

## 实验评估

实验在 Llama-3.1-8B-Instruct、Qwen2.5-7B-Instruct 和 Qwen2.5-14B-Instruct 三个模型上进行，覆盖 GSM8K、MATH-500、Minerva Math、Olympiad Bench 和 AIME24&25 五个数学基准，以及 MBPP、NQ 和 MMLU 三个跨域基准。基线包括单智能体学习（SFT、DPO、PPO、GRPO、GSPO、Reinforce++）和多智能体学习（DebateFT、COPY、MAPoRL）。ILR 在所有数学基准上均超越基线，例如 Qwen2.5-14B-Instruct 在 MATH-500 上达到 82.32%，比 GRPO 基线（80.48%）高 1.84 个点。

| 模型 | 基准 | GRPO | ILR-Group3 | 提升 |
| :--- | :--- | :--- | :--- | :--- |
| Qwen2.5-14B-Instruct | MATH-500 | 80.48 | 82.32 | 1.84 |
| Qwen2.5-14B-Instruct | GSM8K | 94.86 | 95.42 | 0.56 |
| Llama-3.1-8B-Instruct | MATH-500 | 48.60 | 54.36 | 5.76 |
| Qwen2.5-7B-Instruct | AIME24&25 | 13.00 | 17.00 | 4.00 |

消融实验显示，移除动态交互或感知校准模块均导致性能下降，验证了两者协同作用。动态交互在强模型上提升鲁棒性，弱模型上提升幅度更大；感知校准使模型能感知同伴解题质量，避免被低质量答案误导。

评估边界方面，实验仅覆盖数学推理和部分跨域任务，未验证在代码生成、科学推理等复杂任务上的泛化能力。代码已开源，但超参数配置（如 IRT 系数 1.7、合作比例 $p$）未提供敏感性分析，可复现性依赖特定模型组合。

## 关联研究分析

从问题动机看，ILR 与 M-GRPO 和 AgentPO 同属强化学习协同优化路线，但目标不同：M-GRPO 优化系统级协作性能，推理时需执行完整 MAS；ILR 优化单个 LLM 的独立推理能力，推理时仅需单模型。这一差异源于对“多智能体交互价值”的不同定位：M-GRPO 视交互为信息交换手段，ILR 视交互为认知内化过程。ILR 的切入点在于将交互过程从“推理时协作”转变为“训练时认知内化”，使 LLM 在训练阶段吸收同伴的推理策略，从而在推理阶段独立解决复杂问题。

从方法设计看，ILR 与 GPTSwarm 和 G-Designer 同属动态拓扑优化路线，但机制不同：GPTSwarm 通过强化学习调整智能体间连接权重，G-Designer 通过图扩散模型生成通信拓扑；ILR 通过 IRT 动态选择合作/竞争模式，而非调整拓扑结构。这一差异源于任务特性：GPTSwarm 和 G-Designer 关注信息流动效率，ILR 关注认知内化效率。ILR 的动态交互模式是否可迁移至固定拓扑场景，论文未给出回答。

## 总结

ILR 要解决的核心矛盾是多智能体交互在推理阶段的依赖性与人类认知内化机制的不匹配。现有方法将交互视为推理时必要环节，ILR 通过训练阶段引入动态交互与感知校准，使 LLM 能独立解决复杂问题。实验证明 ILR 在数学推理基准上超越单智能体与多智能体基线，例如 Qwen2.5-14B-Instruct 在 MATH-500 上达到 82.32%。然而，ILR 的效果依赖于特定模型组合，且未验证在更广泛任务类型上的泛化能力。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
