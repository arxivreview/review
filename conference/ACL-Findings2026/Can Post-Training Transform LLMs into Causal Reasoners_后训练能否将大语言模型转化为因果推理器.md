# ACL-Findings2026最新论文 ｜Can Post-Training Transform LLMs into Causal Reasoners? ｜后训练能否将大语言模型转化为因果推理器

研究机构：复旦大学、同济大学

作者：Junqi Chen、Sirui Chen、Chaochao Lu

论文原文见 [arXiv](https://arxiv.org/abs/2602.06337)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.06337)

> 因果推理要求模型区分统计关联与真实机制，但大语言模型（LLM）在数值因果估计上常因依赖记忆或表面模式而失效。现有后训练方法虽能提升通用推理能力，却缺乏针对因果结构内化与鲁棒性的系统验证。本文构建CauGym数据集，系统对比五种后训练策略在因果任务上的表现，发现在线强化学习（Online RL）能显著增强模型对因果定理的内化能力。该工作证实了小规模模型经特定训练可超越大规模基线，但其高分是否掩盖了深层结构理解的缺失仍存疑。

## 研究背景

因果推断的核心在于从观测数据中识别干预效应与反事实结果，这依赖于结构因果模型（Structural Causal Model, SCM）中变量间的确定性函数关系。当决策者需要评估“若未治疗，患者结果会如何”时，必须区分混杂因素导致的虚假相关与真实的因果路径。然而，LLM在处理此类任务时，往往将因果问题简化为叙事生成或关联匹配，缺乏对因果机制的结构化表征，导致在分布偏移或噪声环境下性能断崖式下跌。

2023年以来，研究焦点从“LLM能否做因果推理”转向“如何可靠地利用LLM进行因果推断”。主流路线分为基准测试与混合方法：前者通过构建科学接地基准暴露记忆偏差，后者结合语义先验与统计约束。然而，后训练（Post-training）方法在因果领域的应用尚属空白。尽管SFT、PPO等技术在数学和代码任务上表现优异，但其能否迁移至因果推理、是否仅缓解表面幻觉而非解决结构缺失，缺乏系统实证。本文切入点在于：通过构建覆盖泛化、内化与鲁棒性的多维测试集，系统评估五种后训练方法对LLM因果推理能力的真实影响，特别是验证在线RL是否能让模型真正内化因果定理。

## 核心方法

### 方法参照系

本文问题属于“因果推理训练优化”范畴，标准流程为：生成合成SCM数据→构建训练集→应用后训练方法→评估因果推理能力。与通用推理任务不同，因果任务要求模型不仅输出正确数值，还需理解识别策略（如后门准则）并抵抗虚假相关。本文关键差异在于：训练数据基于合成SCM生成，测试集专门设计以区分“知识检索”与“结构推理”，且后训练方法仅使用最终答案奖励，未引入显式因果结构约束。

### 合成SCM数据生成与任务适配

数据生成环节通常采用随机DAG与语义化节点，但本文通过单感知器建模结构方程，确保因果关系可计算且符号一致。具体地，节点 $X$ 的结构方程为 $X = g_X(PA_X, U_X)$，其中 $g_X$ 为单感知器函数，权重 $w_{X[i]}$ 的符号与预设因果关系一致。这一设计解决了此前合成数据中函数形式与因果方向不一致的问题，确保训练数据中的因果效应可被精确计算。对于不同后训练方法，数据格式适配如下：SFT保留重述的推理轨迹；离线RL（DPO/KTO）构建正负样本对，负样本为无引导下的错误或缺失关键步骤的推理；在线RL（PPO/GRPO）仅提取问题与最终答案，依赖模型自身rollout反馈。

### 多维测试集与在线RL优化

测试集设计聚焦三个维度：泛化（CauGym-rephrased，重述问题）、内化（CauGym-omitted/deconfounding，移除指令或强制应用后门准则）、鲁棒性（CauGym-redundant/insufficient，添加冗余或缺失条件）。在线RL优化目标为最大化代理目标：

$$
J_{RL}(\theta) = \mathbb{E}_{x \sim D, y \sim \pi_\theta} \left[ \min\left(r_t(\theta) A_{i,t}, \text{clip}(r_t(\theta), 1-\epsilon_{low}, 1+\epsilon_{high}) A_{i,t}\right) \right]
$$

其中 $A_{i,t}$ 为优势估计，PPO使用独立critic网络，GRPO使用当前策略生成响应的平均奖励。这一设计动机在于：离线RL依赖预收集的正负样本，易过拟合表面模式；在线RL通过模型自身rollout反馈，迫使模型在探索中内化因果定理，而非依赖外部标注。实验表明，GRPO在CaLM基准上达93.5%，显著优于SFT（70.2%）和DPO（52.4%），验证了在线RL在因果任务上的优越性。

## 实验评估

实验在CaLM及四个自建测试集上进行，基线包括Llama-3.3-70B、Qwen3-235B、DeepSeek-R1-0528-671B、Gemini 2.5 Pro、OpenAI o3。本文方法基于DeepSeek-R1-Distill-Qwen-14B，经五种后训练方法优化。主结果显示，GRPO在CaLM上达93.5%，超越OpenAI o3（55.4%）和DeepSeek-R1-0528-671B（57.0%）。

| 方法 | CaLM Avg. | CauGym-rephrased Avg. | CauGym-omitted Avg. |
|---|---|---|---|
| DeepSeek-R1-Distill-Qwen-14B | 0.272 | - | - |
| Cold Start Base | 0.510 | - | - |
| SFT | 0.702 | 0.622 | 0.395 |
| DPO | 0.524 | 0.489 | 0.309 |
| KTO | 0.574 | 0.489 | 0.309 |
| PPO | 0.921 | 0.857 | 0.896 |
| GRPO | 0.935 | 0.857 | 0.896 |

消融实验揭示关键设计决策：在线RL（PPO/GRPO）在CauGym-omitted上平均达89.6%，而离线RL（DPO/KTO）仅30.9%，SFT为39.5%。这表明在线RL能显著增强模型对因果定理的内化，而离线RL和SFT易依赖表面线索。在CauGym-deconfounding上，GRPO达86.5%，PPO为80.8%，而DPO/KTO仅38.2%/39.0%，验证了在线RL在抵抗虚假相关上的优势。

评估边界方面，指标仅采用准确率，未报告置信区间；测试集基于合成SCM，未覆盖真实世界复杂因果结构；代码已开源（OpenCausaLab/CauGym），但超参数（如GRPO的 $\epsilon_{low}=0.2, \epsilon_{high}=0.28$）未提供敏感性分析。

## 关联研究分析

从问题动机看，本文与CE-GRPO（Wang et al., 2025）同属GRPO框架，但CE-GRPO引入因果一致性奖励以惩罚幻觉，本文仅使用最终答案奖励。这一差异源于任务特性：CE-GRPO聚焦因果发现中的结构约束，本文聚焦数值因果估计，后者更依赖精确计算而非结构识别。本文未采用因果一致性奖励，是否限制了模型在复杂因果机制上的理解，论文未给出回答。

从方法设计看，本文与CausalOPD（Zhang et al., 2026）同属后训练优化，但CausalOPD强调过程级监督（首错步修正），本文仅用结果奖励。这一差异反映了监督粒度的取舍：过程级监督成本高但能缓解捷径学习，结果奖励成本低但易过拟合表面模式。实验表明，本文的GRPO在CaLM上达93.5%，而CausalOPD在Corr2Cause上SOTA数值未提供，两者在评估协议上不可直接比较。

## 总结

本文核心矛盾在于：LLM因果推理能力受限于记忆偏差与结构缺失，而后训练方法能否真正解决这一问题缺乏系统验证。本文切入点在于构建多维测试集，区分知识检索与结构推理，并系统对比五种后训练方法。通过合成SCM数据与在线RL优化，GRPO在CaLM上达93.5%，超越OpenAI o3（55.4%）。然而，实验仅覆盖数值因果估计，未涉及结构发现或反事实推理的深层机制；测试集基于合成数据，未验证真实世界泛化性。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
