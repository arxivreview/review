# ACL-Findings2026最新论文 ｜NeuroSym-Cal: Bridging the Reasoning-Execution Gap in Code Generation via Hierarchical Calibration ｜神经符号分层校准：代码生成中的置信度去饱和

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_286efca23771)

> 推理模型在代码生成中常陷入“自信地犯错”的困境，即系统性错误导致采样输出高度一致，使基于一致性的校准方法失效。现有方法如Self-Consistency（SC）无法区分“稳健正确”与“顽固幻觉”，导致高置信度下的严重误判。本文提出NEUROSYM-CAL，通过融合基于抽象语法树（AST）的外部共识与模型后验自我验证的内部信号，构建非线性校准网络以解饱和置信度。该方法在域外（OOD）基准上显著降低了期望校准误差（ECE），但其依赖额外训练数据且未与最新语义熵方法对比，泛化边界尚存疑。

## 研究背景

代码生成任务中，模型输出的正确性不仅取决于逻辑，还受语法噪声影响。传统基于词元概率的校准方法（如Platt Scaling）在开放式生成中失效，因为词法变异性无法反映语义正确性。为捕捉语义层面的不确定性，领域转向基于采样一致性的方法，如Self-Consistency（SC）和语义熵（Semantic Entropy）。SC通过多数投票聚合多次采样输出，假设“共识即正确”。然而，这一假设在推理模型（Reasoning LLMs）中面临挑战：当模型陷入系统性错误（Entrenched Hallucinations）时，它会反复生成相同的错误代码，导致SC置信度饱和至1.0，无法区分正确与错误。

这种“置信度饱和”（Confidence Saturation）是推理模型部署的核心瓶颈。现有黑盒方法如GENUINE或BiG-SURE虽能捕捉语义结构，但主要关注词法或嵌入空间的聚类，未充分利用代码的结构特性。同时，白盒方法依赖内部状态，不适用于API模型。本文切入点在于利用代码的抽象语法树（AST）进行结构归一化，消除语法噪声，并引入模型的后验自我验证（Self-Verification）作为正交信号，以解决高共识下的校准失效问题。

## 核心方法

### 方法参照系

本文问题属于黑盒不确定性量化（UQ）中的校准任务。标准流程是：采样K个输出 → 计算一致性分数 → 映射为概率。本文的关键差异在于：一致性分数基于AST聚类而非字符串匹配，且引入内部自我验证分数作为特征，通过非线性网络融合，而非直接作为最终置信度。

### AST语义共识与自我验证

设计动机：解决字符串匹配因变量命名、格式差异导致的共识信号碎片化，以及SC在顽固错误下的饱和问题。
本文定义归一化映射 $\mathcal{T}: \mathcal{Y} \to \mathcal{Z}$，将代码解析为AST并应用结构归一化规则，诱导等价关系 $y_i \sim y_j \iff \mathcal{T}(y_i) = \mathcal{T}(y_j)$。外部共识分数 $S_{ext}(y)$ 定义为该等价类在K个样本中的经验概率：

$$ S_{ext}(y) = \frac{|C(y)|}{K} $$

其中 $C(y)$ 是包含 $y$ 的等价类。同时，引入内部自我验证分数 $S_{intr}(y)$，通过提示模型以0-100分评估其代码的正确性，若解析失败则取保守值 $\gamma=0.5$。$S_{intr}$ 捕捉了模型对已完成代码的后验评估，与生成时的确定性形成认知不对称。

### 上下文校准网络（CCN）

设计动机：解决单一信号（如 $S_{ext}$ 或 $S_{intr}$）无法独立提供可靠校准的问题，特别是当 $S_{ext}$ 饱和时，需 $S_{intr}$ 进行“去饱和”。
CCN是一个轻量级3层MLP，输入特征向量 $v = [S_{intr}, S_{ext}, L_{code}, L_{reason}, C_{cyc}]$，输出校准概率 $\hat{p}$。训练目标为混合损失：

$$ \mathcal{L} = \mathcal{L}_{FL}(\hat{p}, y) + \beta \mathcal{L}_{Soft-ECE}(\hat{p}, y) $$

其中 $\mathcal{L}_{FL}$ 是Focal Loss处理类别不平衡，$\mathcal{L}_{Soft-ECE}$ 是基于核函数的软分箱校准损失，确保 $\hat{p}$ 与真实正确率对齐。CCN学习非线性交互：当 $S_{ext}$ 高但 $S_{intr}$ 低时，网络惩罚置信度，实现去饱和。

## 实验评估

实验在LiveCodeBench（LCB）、HumanEval-Pro和DS-1000上进行，使用DeepSeek-R1、Qwen2.5-Coder和Llama-3.3-70B。基线包括SC、IGLB（多校准基线）和AvgLogit。缺失Semantic Entropy、GENUINE等最新语义方法对比，限制了横向可比性。

| 方法 | LCB ECE ↓ | LCB BS ↓ | LCB AUROC ↑ |
| :--- | :--- | :--- | :--- |
| NEUROSYM-CAL | 0.072 | 0.182 | 0.805 |
| Self-Consistency | 0.115 | 0.198 | - |
| IGLB | 0.078 | - | 0.798 |

在OOD的LCB上，NEUROSYM-CAL将ECE降低37.4%（0.072 vs 0.115），Brier Score降低至0.182，AUROC达0.805，略优于IGLB（0.798）。这表明内部自我验证在复杂推理轨迹中捕捉认知不确定性（Epistemic Uncertainty）的有效性，而元数据基线（IGLB）在分布内任务（HumanEval-Pro）中更具竞争力（ECE 0.038 vs 0.035）。

| 消融配置 | ECE ↓ | BS ↓ | AUROC ↑ | ΔECE |
| :--- | :--- | :--- | :--- | :--- |
| Full | 0.072 | 0.182 | 0.805 | - |
| w/o Intrinsic | 0.082 | 0.192 | 0.799 | +13.9% |
| w/o Extrinsic | 0.125 | 0.220 | 0.745 | +73.6% |
| w/o AST | 0.089 | 0.188 | 0.798 | +23.6% |

消融显示，移除外部共识导致AUROC大幅下降（0.805→0.745），证实共识是主要判别信号；移除内部验证导致ECE上升13.9%，证实自我验证是校准正则化器。移除AST归一化使ECE上升23.6%，表明结构解析对过滤语法噪声至关重要。

评估边界：未报告置信区间，数值比较需谨慎。CCN训练依赖APPS和旧版LCB数据，OOD泛化性受限于训练分布。代码未公开，超参数（σ=0.05, β=0.5）固定，可复现性受限。

## 关联研究分析

从问题动机看，本文与Self-Consistency（SC）共享“采样一致性”假设，但针对SC在顽固幻觉下的失效，引入内部自我验证作为正交信号。SC假设多数投票收敛于真理，而本文指出系统性错误下共识饱和，需后验评估解饱和。这一差异源于推理模型的特性：生成时的局部陷阱与后验的全局评估存在认知不对称。与GENUINE等基于图结构的UQ方法相比，本文更轻量，依赖AST而非嵌入空间，但缺乏与最新语义熵方法的对比，是否因代码任务特性决定，还是实验遗漏，论文未给出回答。

从方法设计看，本文与P(True) Self-Evaluation不同，后者将自我评估作为独立指标，而本文将其作为CCN的特征，与外部共识融合。这一设计解决了单一信号的不稳定性，但引入了训练依赖。与Calibration-Aware Policy Optimization（CAPO）等训练阶段校准方法相比，本文是后处理校准，灵活但缺乏内生一致性。CCN的非线性融合是否优于简单的加权平均，论文未提供消融，可能限制了方法的通用性。

## 总结

本文核心矛盾是推理模型中系统性错误导致的置信度饱和，现有SC方法无法区分稳健正确与顽固幻觉。本文抓住“认知不对称”切入点，利用模型后验自我验证作为正交信号，结合AST共识，通过CCN非线性融合实现去饱和。实验证明在OOD LCB上ECE降至0.072，AUROC达0.805，显著优于SC。边界在于CCN依赖额外训练数据，且未与最新语义熵方法对比，OOD泛化性受限于训练分布。当支持集增大或任务分布变化时，CCN的非线性映射是否仍能保持校准稳定性，论文未给出回答。
