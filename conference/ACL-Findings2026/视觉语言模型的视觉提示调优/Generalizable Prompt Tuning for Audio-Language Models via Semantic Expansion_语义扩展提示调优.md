# ACL-Findings2026最新论文 ｜Generalizable Prompt Tuning for Audio-Language Models via Semantic Expansion ｜语义扩展提示调优

研究机构：韩国科学技术院

作者：Jaehyuk Jang、Wonjun Lee、Kangwook Ko 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.20867)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.20867)

> 音频-语言模型（ALMs）提示调优面临基础类过拟合导致的新类泛化崩溃，即基础-新类权衡（BNT）。现有视觉提示调优方法直接迁移至音频域时，因音频基准语义稀疏性导致嵌入空间结构崩塌，单纯架构增强或静态正则化无法重建语义簇。SEPT 通过大语言模型生成语义邻居，引入带边际约束的语义扩展损失，在冻结骨干下显式重塑文本嵌入几何结构。该方法以零额外推理开销显著提升了跨数据集泛化性能，但其效果高度依赖外部 LLM 的邻居生成质量，且未验证在视觉域或动态提示架构下的普适性。

## 研究背景

当预训练音频-语言模型（ALMs）通过提示调优适配下游分类任务时，可学习提示向量往往过度拟合训练集见的类别，导致模型在未见类别上性能骤降。这一现象被称为基础-新类权衡（BNT），其根源在于提示优化破坏了预训练文本嵌入空间中语义相关类别的几何邻近性。在视觉域，ImageNet 等基准拥有数千类别，语义空间稠密，提示过拟合可通过实例条件化或知识图谱正则化缓解；但在音频域，基准通常仅含数十个类别，语义空间极度稀疏，提示向量缺乏足够的语义支撑，退化为孤立原型而非鲁棒的语义锚点，使得 BNT 问题在 ALMs 中更为严峻。

视觉提示调优领域已确立“冻结骨干、优化提示”的高效范式，CoOp 等静态方法在视觉任务上表现优异，但直接应用于 ALMs 时，其学习到的提示破坏了零样本提示中自然存在的语义结构。KgCoOp 等正则化方法试图通过约束提示与手工模板的距离来缓解过拟合，但手工模板无法覆盖音频类别的细粒度声学变体。CoCoOp 引入动态 Meta-Net 虽提升了视觉域泛化，但其额外参数与计算开销在资源受限的音频场景中不具吸引力，且未解决语义结构崩塌的根本问题。SEPT 的切入点在于识别出 ALMs 中 BNT 的核心机制是嵌入空间语义结构的破坏，而非单纯的参数过拟合，因此提出通过外部语义信息重建嵌入空间几何结构，而非修改提示架构本身。

## 核心方法

### 提示调优参照系与语义稀疏性挑战

标准提示调优流程冻结 ALMs 的音频与文本编码器，仅优化每类 $M$ 个可学习上下文向量 $\mathbf{v}_1, \dots, \mathbf{v}_M$，将其与类别名嵌入 $E(c_i)$ 拼接后输入文本编码器生成提示嵌入 $\mathbf{z}_i$。该流程在视觉域有效，但在音频域因类别数量少、语义覆盖窄，导致 $\mathbf{z}_i$ 与语义邻居的相似度显著下降，嵌入空间失去簇状结构。本文的关键差异在于不改变提示参数化方式，而是引入外部语义邻居作为正则化锚点，将优化目标从单纯最小化分类损失扩展为同时维护嵌入空间的语义几何结构。

### 语义邻居生成与边际约束机制

SEPT 利用大语言模型（LLM）为每个类别 $c_i$ 生成 $N$ 个语义邻居 $\{p_i^1, \dots, p_i^N\}$，这些邻居通过相同的可学习提示与冻结文本编码器编码为嵌入 $\mathbf{p}_i^n$。为避免无约束拉近正样本或推远负样本导致嵌入空间过度压缩或碎片化，SEPT 引入基于 $T$ 个手工提示池计算的边际约束 $m_{i,j,n}$，定义为类别 $c_i$ 与类别 $j$ 的第 $n$ 个邻居在所有提示下的平均 $L_2$ 距离：

$$
m_{i,j,n} = \frac{1}{T} \sum_{t=1}^{T} \| g(E(\pi_t; c_i)) - g(E(\pi_t; p_j^n)) \|_2
$$

该公式的物理含义是：边际值反映了两个语义实体在预训练空间中的固有距离，作为动态阈值防止正则化过度干预。设计动机在于解决 KgCoOp 等静态正则化方法无法适应不同类别对之间语义距离差异的问题，通过数据驱动的边际值实现精细化的几何约束。

### 语义扩展损失函数

SEPT 定义语义扩展损失 $\mathcal{L}_{se}$ 为类内对齐损失 $\mathcal{L}_{intra}$ 与类间分离损失 $\mathcal{L}_{inter}$ 之和，均采用带边际的铰链损失形式：

$$
\mathcal{L}_{intra} = \frac{1}{K} \sum_{i=1}^{K} \frac{1}{N} \sum_{n=1}^{N} \max(0, \|\mathbf{z}_i - \mathbf{p}_i^n\|_2 - m_{i,i,n})
$$

$$
\mathcal{L}_{inter} = \frac{1}{K} \sum_{i=1}^{K} \frac{1}{N(K-1)} \sum_{j \neq i} \sum_{n=1}^{N} \max(0, m_{i,j,n} - \|\mathbf{z}_i - \mathbf{p}_j^n\|_2)
$$

总损失为 $\mathcal{L}_{total} = \mathcal{L}_{ce} + \lambda \mathcal{L}_{se}$，其中 $\lambda$ 平衡分类信号与结构正则化。该损失函数的改进价值在于：$\mathcal{L}_{intra}$ 仅当类别嵌入与其邻居距离超过边际时才施加拉力，避免过度压缩语义多样性；$\mathcal{L}_{inter}$ 仅当类别嵌入与其他类别邻居距离小于边际时才施加推力，防止破坏合法的跨类语义关系。这种选择性正则化机制在保持嵌入空间紧凑性的同时维持了类间可分性，解决了传统对比损失中无差别拉近/推远导致的结构失真问题。

## 实验评估

实验在 11 个音频分类基准上进行，涵盖乐器、声音事件、情感识别等领域，使用 Pengi 作为骨干网络，对比 CoOp、CoCoOp、KgCoOp、DePT 四种提示调优方法。基线覆盖静态、动态、知识图谱正则化及通道解耦路线，但未包含 MaPLe 等多模态提示方法（因不适用于纯文本提示场景）。主实验结果显示，SEPT 作为即插即用模块，在所有基线上均显著提升新类准确率与调和平均（H）。

| 方法 | 平均 Base (%) | 平均 New (%) | 平均 H (%) |
| :--- | :--- | :--- | :--- |
| CoOp | 65.00 | 34.09 | 42.83 |
| CoOp + SEPT | 64.36 | 42.98 | 49.70 |
| CoCoOp | 69.13 | 36.83 | 46.26 |
| CoCoOp + SEPT | 68.63 | 42.59 | 50.65 |
| KgCoOp | 37.99 | 37.42 | 36.39 |
| KgCoOp + SEPT | 58.92 | 45.28 | 49.79 |
| DePT | 63.86 | 39.91 | 46.79 |
| DePT + SEPT | 64.57 | 41.63 | 49.06 |

CoOp+SEPT 的 H 从 42.83% 提升至 49.70%，新类准确率从 34.09% 提升至 42.98%，而基础类准确率仅微降 0.64 个百分点，表明 SEPT 有效缓解了 BNT 而非以牺牲基础类性能为代价。KgCoOp+SEPT 的提升幅度最大（H 从 36.39% 至 49.79%），说明在 ALMs 中，静态知识图谱正则化本身效果有限，需结合语义扩展才能重建嵌入结构。

消融实验验证了边际约束的关键作用。无边际的朴素语义扩展损失（行 2、4、6）导致性能下降，H 从 42.83% 降至 41.17% 或 43.48%，证实无约束拉近/推远会破坏嵌入空间。完整模型（行 7）同时应用类内与类间边际，H 达到 49.70%，较无边际版本提升 6.23 个百分点。超参数分析显示，$\lambda=3$ 时性能最优，$N$（邻居数量）从 2 增至 10 时 H 持续上升，表明更丰富的语义邻居提供更强的结构约束。

| 消融配置 | Base (%) | New (%) | H (%) |
| :--- | :--- | :--- | :--- |
| CoOp (无 SEPT) | 65.00 | 34.09 | 42.83 |
| 仅 $\mathcal{L}_{intra}$ (无边际) | 58.31 | 33.58 | 41.17 |
| 仅 $\mathcal{L}_{intra}$ (有边际) | 64.99 | 36.90 | 44.52 |
| 仅 $\mathcal{L}_{inter}$ (无边际) | 62.01 | 36.68 | 43.48 |
| 仅 $\mathcal{L}_{inter}$ (有边际) | 62.84 | 38.79 | 46.04 |
| 完整 SEPT (双边际) | 64.37 | 42.93 | 49.70 |

评估边界方面，实验仅使用 16-shot 协议，未验证在更高 shot 数下 SEPT 的边际收益是否递减。跨数据集评估显示 SEPT 在源-目标域偏移下表现稳健，但未报告置信区间或多次运行的方差。计算效率上，SEPT 不增加可训练参数（8,192 个）与推理延迟（2.8ms），但训练时间从 94.0s 增至 170.7s，约为 CoOp 的 1.8 倍。代码未公开，LLM 邻居生成提示词与手工提示池细节仅在附录中提供，可复现性依赖附录完整性。

## 关联研究分析

从问题动机看，SEPT 与 KgCoOp 均针对 BNT 问题，但 KgCoOp 依赖手工设计的知识图谱模板作为正则化锚点，其语义覆盖受限于人工标注的广度与精度；SEPT 则利用 LLM 自动生成语义邻居，突破了手工模板的语义稀疏性瓶颈。这一差异的根源在于音频类别的细粒度声学变体（如“飞机”与“喷气机”）难以通过有限的手工模板穷尽，而 LLM 的预训练知识能捕捉更丰富的语义关联。然而，LLM 生成邻居的质量是否成为性能瓶颈，论文未通过控制变量实验验证，例如使用不同能力 LLM 或随机邻居作为对照。

从方法设计看，SEPT 与 CoCoOp 同属 BNT 解决方案，但 CoCoOp 通过 Meta-Net 实现实例条件化动态提示，增加 107,072 个可训练参数与 40.9ms 推理延迟；SEPT 采用静态提示加语义约束，保持 8,192 个参数与 2.8ms 推理延迟。这一取舍反映了任务特性差异：视觉任务中实例条件化对细粒度特征捕捉至关重要，而音频任务中语义结构完整性比实例特异性更关键。SEPT 未验证在视觉域或动态提示架构下的效果，其语义扩展损失是否适用于高维视觉嵌入空间，论文未给出回答。

## 总结

SEPT 要解决的核心矛盾是 ALMs 提示调优中语义稀疏性导致的嵌入空间结构崩塌与 BNT 问题。现有方法如 KgCoOp 依赖手工模板，语义覆盖不足；CoCoOp 引入动态参数，计算开销高。SEPT 抓住的切入点是嵌入空间几何结构而非提示参数本身，通过 LLM 生成语义邻居与带边际的铰链损失重建语义簇，在零额外推理开销下实现泛化提升。实验证明 CoOp+SEPT 的 H 从 42.83% 提升至 49.70%，新类准确率提升 8.89 个百分点。本文的边界在于仅验证了静态提示架构，未探索与动态提示或视觉域的结合，且 LLM 邻居生成质量对性能的贡献占比未量化。当支持集从 16-shot 增至 64-shot 时，语义扩展损失的边际收益是否递减，论文未给出回答。
