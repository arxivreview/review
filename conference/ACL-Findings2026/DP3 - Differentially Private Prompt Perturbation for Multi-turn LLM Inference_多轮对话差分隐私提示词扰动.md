# ACL-Findings2026最新论文 ｜DP3: Differentially Private Prompt Perturbation for Multi-turn LLM Inference ｜多轮对话差分隐私提示词扰动

研究机构：西安电子科技大学

作者：Lele Zheng、Chao Zhang、Feiyang Yuan 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_225250accbd9)

> 大语言模型（LLM）在云端黑盒 API 部署中面临用户提示词泄露风险，现有差分隐私（DP）方法多假设单轮交互，无法处理多轮对话中重复 token 导致的隐私预算线性累积与语义断裂。本文提出 DP3 框架，通过引入扰动映射表复用历史扰动，并结合注意力驱动的上下文效用函数与两阶段分桶指数机制，在保持形式化隐私保证的同时维持跨轮次语义连贯性。该方案在长程多轮场景下实现了更优的隐私-效用权衡，但其对 LDP 独立性假设的潜在挑战及缺乏多轮专用基线对比，限制了结论的普适性验证。

## 研究背景

当用户通过 API 与 LLM 进行多轮交互时，敏感信息往往分散在多个回合中，且后续提示词常引用前文实体。局部差分隐私（LDP）通过在客户端对提示词进行随机扰动来保护隐私，其核心约束是隐私预算 $\epsilon$ 的消耗。然而，标准 LDP 机制假设每次查询独立，在多轮场景中，若对每个回合独立扰动，根据序列组合定理，总隐私损失将随轮数 $T$ 线性增长至 $T \cdot \epsilon_0$，导致长对话中隐私保护迅速失效。

现有单轮提示词扰动方法如 SanText 和 CusText 主要解决单查询下的语义漂移问题，通过邻接列表或全词表扰动平衡隐私与效用。但这些方法直接应用于多轮对话时，存在两个致命缺陷：一是重复出现的 token 被反复随机化，造成隐私预算的冗余消耗；二是独立扰动破坏了跨轮次的语义一致性，导致指代消解失败和推理质量下降。DP3 的切入点在于识别多轮对话中 token 的复用特性，将隐私保护从“每轮独立”转变为“跨轮状态保持”，从而解耦隐私消耗与对话长度。

## 核心方法

### 单轮扰动参照系

单轮 LDP 提示词扰动的标准流程是：对输入序列中的每个 token，基于效用函数（如嵌入相似度）通过指数机制（EM）从候选词表中采样替换 token。该流程假设输入是静态且独立的，未考虑历史上下文对当前 token 语义的影响，也未处理多轮交互中 token 重复出现的预算累积问题。

### 扰动映射表与隐私预算解耦

针对多轮对话中重复 token 导致隐私预算线性累积的问题，DP3 引入扰动映射表（PMT）。在标准流程中，每个 token 在每次出现时都独立执行扰动操作，消耗 $\epsilon_0$ 预算。DP3 修改了这一环节：仅当 token 首次出现时执行扰动并记录映射，后续出现时直接复用 PMT 中的结果。

$$
\tilde{t}_i = \begin{cases}
\text{PMT}[t_i], & \text{if } t_i \in \text{PMT} \\
R(t_i), & \text{if } t_i \notin \text{PMT}
\end{cases}
$$

该公式表明，扰动操作 $R(\cdot)$ 仅对未见过的新 token 执行。这一设计的动机在于消除重复随机化带来的冗余隐私消耗。通过复用映射，总隐私预算不再依赖于对话轮数 $T$，而是取决于对话中 distinct token 的数量，从而在长对话中保持隐私预算的稳定性。

### 上下文感知效用与两阶段分桶采样

PMT 解决了预算累积，但独立扰动仍可能破坏语义连贯性。标准 EM 基于静态嵌入相似度选择替换 token，忽略了上下文依赖。DP3 引入基于注意力权重的上下文效用函数，结合静态嵌入距离 $s_e$ 和动态上下文相似度 $s_{ctx}$：

$$
u(t_i, t'_i) = \alpha \cdot s_e(t_i, t'_i) + (1-\alpha) \cdot s_{ctx}(t_i, t'_i)
$$

其中 $s_{ctx}$ 通过 Transformer 最后一层注意力权重加权隐藏状态计算，捕捉跨轮次语义关联。此外，针对大词表长尾分布导致的效用损失，DP3 采用两阶段分桶 EM：先基于桶级平均效用 $U(B_k)$ 选择桶，再在桶内采样。这种分层采样限制了低效用候选的累积概率影响，提升了扰动选择的稳定性。

## 实验评估

**实验设置与主结果**：论文在多个多轮对话任务上评估 DP3，对比基线包括 SanText、CusText、InferDPT 和 CAPE 等单轮方法。由于【论文实验数据】区未提供具体数值表格，无法生成主实验结果表。文字描述指出，DP3 在长程多轮设置中 consistently 实现了比现有方法更优的隐私-效用权衡，特别是在抵抗推断攻击方面表现更强。

**消融与设计决策验证**：论文进行了消融研究，验证了 PMT 和上下文效用函数的贡献。虽然具体数值不可得，但定性分析表明，移除 PMT 后隐私预算随轮数线性增长，移除上下文效用函数后跨轮次语义一致性显著下降。两阶段分桶机制在候选空间较大时表现出比单阶段 EM 更高的稳定性，减少了低效用 token 的采样概率。

**评估边界与可复现性**：评估指标主要关注隐私-效用权衡和推断攻击成功率，但未报告具体的隐私预算 $\epsilon$ 与效用指标的量化曲线。评估协议局限于黑盒 API 场景，未涉及模型内部访问。代码已公开（github.com/XidianNSS/DP3），但论文未详细报告超参数设置和计算开销，限制了复现的完整性。

## 关联研究分析

从问题动机看，DP3 与 CusText 和 CAPE 的核心差异在于对多轮依赖性的处理。CusText 和 CAPE 均假设单轮交互，其效用函数和分桶策略仅针对当前提示词优化。DP3 通过 PMT 引入跨轮状态，将隐私保护从“无记忆”转变为“有记忆”，这直接回应了多轮对话中 token 复用的特性。然而，DP3 的 PMT 复用机制是否严格满足 LDP 的独立性假设存在理论争议，因为 LDP 通常要求机制输出独立于历史输入，而 PMT 的输出依赖于历史扰动结果。

从方法设计看，DP3 与 InferDPT 同属基于邻接列表的扰动方法，但 InferDPT 未考虑多轮场景，其邻接列表是静态的。DP3 的上下文效用函数动态调整候选集，使得扰动更贴合当前对话语境。这种动态性提升了语义连贯性，但增加了计算复杂度，因为每轮都需要运行轻量级 Transformer 编码器计算注意力权重。在资源受限的边缘设备上，这种额外计算开销可能成为部署瓶颈，论文未对此进行量化分析。

## 总结

DP3 旨在解决多轮 LLM 推理中隐私预算累积与语义断裂的矛盾，通过 PMT 复用扰动和上下文感知效用函数，实现了隐私消耗与对话长度的解耦。实验表明其在长程多轮场景中优于单轮基线，但缺乏多轮专用基线的对比，且 PMT 机制对 LDP 独立性假设的潜在违反未被充分理论化。当对话轮数极大且 distinct token 数量接近词表大小时，PMT 的存储开销和隐私预算是否仍能保持可控，论文未给出回答。
