# ACL-Findings2026最新论文 ｜Generative Text-to-Image Retrieval via Hierarchical Identifiers and Semantic Internalization ｜生成式多模态对齐中的语义内化框架

研究机构：中国科学院、中国科学院大学

作者：Jie Huang、Junjie Wang、Xin Liao 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_24b8f3e99c5d)

> 文本到图像检索旨在从海量图库中定位与查询语义最匹配的视觉内容，但传统双塔模型因编码器独立导致细粒度交互缺失，单塔模型则因计算开销难以实时部署。生成式检索（Generative Retrieval, GR）将检索重构为标识符预测任务，试图兼顾效率与精度，却面临标识符语义判别性不足、硬对齐偏差及封闭集限制三大瓶颈。SIGMA 通过构建五级层级标识符并引入渐进式语义内化训练，实现了开放集下的动态索引。该框架在 Flickr30K 和 MS-COCO 上显著优于现有生成式基线，但其绝对性能是否超越对比学习 SOTA 仍存疑。

## 研究背景

当检索系统面对“一图多描述”场景时，不同查询对同一图像的语义关联度存在差异，传统生成式方法强制所有查询映射至同一离散标识符，导致训练过程中的梯度冲突与语义混淆。这种刚性对齐源于标识符与视觉语义的解耦，使得模型难以捕捉细粒度的文本-图像亲和力。为解决此问题，需建立标识符与视觉内容间的深层语义绑定，同时保持标识符在生成过程中的稳定性与可判别性。

文本到图像检索的主流路线分为双塔与单塔架构。双塔模型（如 CLIP）通过对比学习对齐嵌入空间，支持高效向量检索，但独立编码阻碍了跨模态细粒度交互；单塔模型利用交叉注意力实现深度对齐，精度更高，但推理延迟使其无法用于大规模实时场景。生成式检索作为新兴范式，直接预测图像标识符，规避了索引存储与成对计算开销，但现有方法（如 TIGER、CART）依赖残差量化构建标识符，存在语义可解释性差、封闭集假设等问题。SIGMA 的切入点在于重构标识符构建逻辑，从纯量化转向层级聚类与子空间分解，并通过渐进式训练策略赋予模型对未见样本的归纳索引能力。

## 核心方法

### 方法参照系

生成式检索的标准流程是将图像映射为离散标识符，训练模型自回归生成该序列。本文问题与该通用流程的关键差异在于：传统标识符缺乏层级语义结构，且训练过程未显式处理“一图多描述”的语义差异，导致模型仅记忆形式而非理解语义。

### 层级标识符构建

传统残差量化标识符直接对特征向量进行离散化，忽略了图像内部的语义层级结构，导致标识符难以区分语义相近但细节不同的图像。SIGMA 采用五级层级标识符 $z_i = [id_1, id_2, id_3, id_4, id_5]$，通过 K-Means 聚类建立全局语义锚点 $id_1$，利用 Semi-NMF 分解提取主导语义组件 $id_2$ 与细粒度语义组 $id_3$，计算残差向量 $r_i = v_i - c_{id_1}$ 并量化为局部细节 $id_4$，最后附加实例后缀 $id_5$ 确保唯一性。该设计解决了标识符语义判别性与生成稳定性之间的权衡，使模型能逐级解耦图像的粗粒度语义与细粒度细节。

$$
id_1 = \arg \min_{k \in \{1, \dots, K_1\}} \|v_i - c_k\|_2
$$

此公式通过最小化视觉特征与聚类中心的距离，为每幅图像分配全局语义锚点，奠定层级标识符的粗粒度基础。

### 渐进式语义内化训练

传统生成式训练仅优化标识符生成的交叉熵损失，导致模型记忆“图像-标识符”映射而忽略标识符背后的视觉语义。SIGMA 引入三阶段渐进式训练：首先通过“图像-标识符”映射学习标识符形式；其次通过“标识符-描述”映射内化语义；最后在检索对齐阶段引入语义软标签（SSL）机制。SSL 利用预训练交叉编码器计算图像-描述对的相似度作为软标签，结合标识符生成损失与相似度预测损失进行联合优化。

$$
L_{align} = L_{gen} + \lambda_{ssp} \cdot L_{ssp}
$$

该联合损失函数中，$L_{gen}$ 确保标识符生成的准确性，$L_{ssp}$ 作为辅助信号引导模型感知查询与图像间的细微语义差异，$\lambda_{ssp}$ 设为较小值以平衡主次任务。

## 实验评估

实验在 Flickr30K 和 MS-COCO 数据集上进行，基线覆盖双塔模型（CLIP, OpenCLIP）与生成式模型（TIGeR, SemCORE, GENIUS）。SIGMA 在两个数据集上均取得平均 Recall@1、Recall@5 和 Recall@10 提升 10.65%、8.50% 和 7.00%。

| 数据集 | 指标 | SIGMA 平均提升 |
| :--- | :--- | :--- |
| Flickr30K | R@1 | 10.65% |
| Flickr30K | R@5 | 8.50% |
| Flickr30K | R@10 | 7.00% |
| MS-COCO | R@1 | 10.65% |
| MS-COCO | R@5 | 8.50% |
| MS-COCO | R@10 | 7.00% |

消融实验表明，移除语义软标签机制导致性能显著下降，验证了 SSL 在处理“一图多描述”场景中的关键作用。层级标识符中 $id_4$（残差细节）的移除对细粒度检索影响最大，证实了局部细节编码对区分相似图像的重要性。

评估边界方面，论文未报告计算延迟与吞吐量数据，无法直接对比生成式与双塔模型的效率优势。此外，实验仅覆盖两个静态数据集，未验证开放集动态索引在增量数据场景下的实际表现。代码未公开，超参数细节（如 $\lambda_{ssp}$ 具体值、K-Means 簇数 $K_1$）未在正文中明确列出，影响可复现性。

## 关联研究分析

从问题动机看，SIGMA 与 TIGER 均致力于生成式检索，但 TIGER 依赖残差量化构建标识符，其语义可解释性较弱，且受限于封闭集假设。SIGMA 通过层级聚类与子空间分解增强标识符的语义结构，并通过渐进式训练实现开放集动态索引。这一差异源于任务特性：TIGER 侧重效率，而 SIGMA 侧重语义理解与泛化能力。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

从方法设计看，SIGMA 与 CLIP 等对比学习模型在细粒度对齐目标上一致，但实现路径截然不同。CLIP 通过对比损失在共享嵌入空间中优化距离度量，而 SIGMA 通过自回归生成标识符并引入软标签回归。这种差异暗示了生成式范式在捕捉细粒度语义时可能具有独特优势，但需验证其在大规模数据下的收敛稳定性。SIGMA 未与最新推理增强方法（如 TTE-v2）对比，其性能边界在复杂推理任务中尚不明确。

## 总结

SIGMA 旨在解决生成式检索中标识符语义判别性不足与封闭集限制的核心矛盾。其切入点在于重构标识符构建逻辑，通过层级聚类与子空间分解赋予标识符语义结构，并利用渐进式语义内化训练实现开放集动态索引。该方法在 Flickr30K 和 MS-COCO 上实现平均 R@1 提升 10.65%，验证了层级标识符与软标签机制的有效性。然而，论文未报告计算效率数据，且实验局限于静态数据集，未验证增量场景下的鲁棒性。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
