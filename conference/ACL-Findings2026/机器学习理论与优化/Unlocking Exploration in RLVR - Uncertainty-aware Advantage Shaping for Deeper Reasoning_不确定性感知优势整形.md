# ACL-Findings2026最新论文 ｜Unlocking Exploration in RLVR: Uncertainty-aware Advantage Shaping for Deeper Reasoning ｜不确定性感知优势整形

研究机构：快手

作者：Can Xie、Ruotong Pan、Xiangyu Wu 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.10649)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.10649)

> 组相对策略优化（Group Relative Policy Optimization, GRPO）在可验证奖励强化学习（Reinforcement Learning with Verifiable Rewards, RLVR）中因消除价值网络依赖而成为主流，但其序列级均匀优势分配导致信用分配粗糙，引发策略熵坍缩与探索停滞。现有熵正则化方法往往采取全局保守策略，无法区分“正确但不确定”的探索路径与“错误但自信”的固化路径。UCAS 利用模型内部 Logit 信号，在响应级与 Token 级实施非对称优势整形，以恢复探索多样性。该方法在数学推理基准上显著优于基线，但其 Token 级粒度在极端难度任务上的有效性仍存疑。

## 研究背景

当大语言模型（LLM）通过强化学习提升推理能力时，训练信号的质量直接决定策略的演化方向。GRPO 通过采样一组响应并计算组内标准化奖励作为优势函数，彻底消除了对独立价值网络的依赖，大幅降低了计算开销。然而，这种序列级奖励的均匀分配机制无法区分推理链中的关键决策点与冗余步骤，导致所有 Token 共享同一优势值。这种粗糙的归因机制使得模型倾向于收敛于少数高概率的“安全”轨迹，输出分布迅速收缩，即发生熵坍缩，严重损害了模型发现新推理路径的能力。

RLVR 范式确立了基于规则或程序自动验证的客观信号，但序列级稀疏奖励与细粒度策略更新之间的错位是核心矛盾。早期研究尝试引入过程奖励模型（Process Reward Model, PRM）提供步骤级监督，但训练成本高且易受奖励黑客影响。近期工作如 SEED-GRPO 利用语义熵降低不确定样本的更新权重，采取保守的风险规避策略；而 DAPO 通过解耦裁剪缓解梯度消失，但未解决优势信号本身的粗糙性。UCAS 的切入点在于利用模型自身的内部不确定性信号，无需额外网络，通过非对称机制同时放大“正确但不确定”的奖励并抑制“错误但自信”的惩罚，从而在保持精度的同时恢复探索多样性。

## 核心方法

### 方法参照系

UCAS 基于 DAPO 框架，继承其解耦裁剪与动态采样机制。标准 GRPO/DAPO 流程中，优势函数 $\hat{A}_i$ 由组内奖励标准化得到，并均匀广播至序列所有 Token。UCAS 的关键差异在于引入两个阶段的不确定性整形，将均匀优势 $\hat{A}_i$ 重构为 Token 级非对称优势 $\hat{A}^{UCAS}_{i,t}$，以解决均匀信号导致的局部过自信与探索停滞。

### 响应级置信度调制

标准 GRPO 中，组内所有正确响应获得相同正优势，无法区分“常规解题”与“新颖探索”。UCAS 在响应级引入 Logit 空间自置信度 $C(o_i|q)$，定义为序列级 Logit 之和的归一化形式，其物理含义为模型对整条推理路径的整体确定性。设计动机是：对于正确响应，低置信度（高不确定性）意味着模型在探索新路径，应放大奖励以鼓励此类行为；对于错误响应，高置信度意味着模型在固化错误，应放大惩罚以打破局部最优。调制权重 $W(\hat{C}_i)$ 采用指数形式，基于组内 Z-score 归一化的置信度 $\hat{C}_i$ 计算：

$$
W(\hat{C}_i) = \exp(\alpha \cdot \text{sign}(\hat{A}_i) \cdot \hat{C}_i)
$$

其中 $\alpha$ 控制整形强度。该公式确保正确且低置信度的响应获得更大权重，错误且高置信度的响应获得更大惩罚权重，从而在战略层面引导策略向新颖正确路径倾斜。

### Token 级确定性惩罚

响应级调制后，优势仍均匀分配至 Token，无法抑制局部过自信。UCAS 在 Token 级引入原始 Logit 值 $\ell_{i,t}$ 作为确定性代理，因其比 Softmax 后概率对校准偏差更敏感。设计动机是：高 Logit 值代表模型对该 Token 选择的过度自信，若该 Token 位于错误轨迹中，应施加更强惩罚；若位于正确轨迹中，则需保护其不被负向更新干扰。Token 级确定性 $\hat{\ell}_{i,t}$ 通过序列内 Min-Max 归一化至 $[0,1]$。最终优势整形公式为：

$$
\hat{A}^{UCAS}_{i,t} = \begin{cases}
\max(0, \hat{A}^{mod}_i - \beta \cdot \hat{\ell}_{i,t}) & \text{if } \hat{A}^{mod}_i \geq 0 \\
\hat{A}^{mod}_i - \beta \cdot \hat{\ell}_{i,t} & \text{if } \hat{A}^{mod}_i < 0
\end{cases}
$$

其中 $\beta$ 控制惩罚强度。该非对称结构确保正确轨迹的 Token 优势非负，避免正推理被错误抑制；错误轨迹中，高确定性 Token 受到更强惩罚，从而在微观层面打破过自信导致的熵坍缩。

## 实验评估

UCAS 在 Qwen2.5-Math-1.5B 和 7B 上，使用 MATH 数据集（Level 3-5）训练，并在 AIME24、MATH-500、AMC、Minerva、OlympiadBench 五个基准上评估。基线覆盖 GRPO、DAPO、KTAE、Oat-Zero 等，但缺失 SSVPO、EP-GRPO 等 2026 年最新步骤级细粒度方法。

Token 级惩罚系数 $\beta=0.01$ 时性能最优，$\beta \geq 0.05$ 导致过正则化，抑制必要的高确定性步骤。响应级系数 $\alpha$ 在 $[0.1, 0.2]$ 区间稳定，$\alpha=0.4$ 时因信号主导导致性能下降。

评估边界方面，论文未报告置信区间，且未与 SSVPO 等步骤级方法直接对比。代码已开源，但超参数 $\alpha, \beta$ 的跨任务迁移性未充分验证。

## 关联研究分析

从问题动机看，UCAS 与 SEED-GRPO 均利用不确定性信号，但策略截然相反。SEED-GRPO 采取保守策略，降低不确定样本的更新权重以规避风险；UCAS 采取探索策略，放大“正确但不确定”的奖励以鼓励新颖路径。这一差异源于对熵坍缩成因的不同理解：SEED-GRPO 视不确定性为噪声源，UCAS 视其为探索机会。UCAS 的非对称设计使其在 Minerva 等中等难度任务上表现更优，但在 AIME24 上未超越 SEED-GRPO，暗示在极端难度下，保守策略可能更利于避免错误累积。

从方法设计看，UCAS 与 SSVPO 代表细粒度信用分配的两种粒度路径。SSVPO 通过步骤级分解将奖励公平分配至推理步骤，依赖外部步骤提取机制；UCAS 通过 Token 级 Logit 信号实现内部不确定性整形，无需额外网络。SSVPO 在 AIME24 上达 80.0%，远高于 UCAS 的 43.3%，表明步骤级信号在高难度任务上可能更精准。UCAS 的 Token 级粒度虽更细，但缺乏语义结构约束，可能在长推理链中引入噪声。两者对比揭示，细粒度信号的有效性不仅取决于粒度，更取决于信号与推理结构的对齐程度。

## 总结

UCAS 旨在解决 GRPO 中序列级均匀优势导致的信用分配粗糙与熵坍缩问题。其切入点在于利用模型内部 Logit 信号，通过响应级置信度调制与 Token 级确定性惩罚的非对称组合，在无需额外网络的前提下重塑学习信号。该方法在 Qwen2.5-Math-7B 上实现 56.7% 的平均准确率，较 DAPO 提升 6.2 个点，并有效恢复生成熵。然而，UCAS 在 AIME24 等极端难度任务上显著落后于步骤级方法 SSVPO，暴露出 Token 级信号在缺乏语义结构约束时的局限性。当推理链长度增加且关键决策点稀疏时，Token 级 Logit 信号能否有效区分关键步骤与冗余步骤，论文未给出回答。
