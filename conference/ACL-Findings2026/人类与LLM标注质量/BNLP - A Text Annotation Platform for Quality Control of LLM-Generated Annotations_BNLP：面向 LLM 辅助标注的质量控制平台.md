> 现有 LLM 标注工具多将模型输出视为一次性预标注结果，缺乏对标注过程持续性的质量监控与多角色协同机制，导致在低资源、高专业度场景下数据可靠性难以保障。BNLP 将 LLM 输出定义为可修订的中间状态，嵌入包含多角色协作、迭代审查与一致性分析的人机协同工作流，实现质量控制的内在化。该平台通过工程化整合解决了指南落地与质量监控的执行层难题，但在测量学指标量化与系统性偏差校正方面存在空白。

## 研究背景

在生物医学等低资源领域，人工标注成本高企且扩展性差，而大语言模型（Large Language Models, LLMs）虽具备零样本泛化能力，但其输出受提示词敏感性与先验偏差影响，直接作为最终标签会导致下游统计推断失效。这种“效率-可靠性”张力要求标注系统不仅提供高效接口，更需具备对 LLM 输出的持续评估与修正能力。

传统标注工具如 Brat、YEDDA 和 INCEpTION 侧重于基础命名实体识别（Named Entity Recognition, NER）与项目管理，但质量控制往往是碎片化或事后性的。即使引入 LLM 辅助的平台如 ITAKE 和 MEGAnno+，也主要强调自动化效率，缺乏对模型输出与人工修订之间差异的系统性量化评估。现有系统未能建立从预标注到金标准数据的可靠过渡机制，导致 LLM 的效率增益无法在严格质量约束下被有效利用。

BNLP 的切入点在于将质量控制从辅助模块转变为标注流程的内在属性。它不追求单一的 SOTA 准确率，而是通过多角色协作（项目经理、标注员、审计员）与实时一致性分析，构建一个可审计、可量化的闭环工作流，旨在解决 LLM 辅助标注中“黑盒输出”难以治理的问题。

## 核心方法

### 方法参照系

BNLP 属于“协同流程”路线，其基础参照系是“LLM 预标注 + 人工修订”的线性流程。与 ACT 等基于置信度阈值的算法驱动方法不同，BNLP 侧重于流程管控与角色分工，将 LLM 定位为可审计的中间步骤而非最终决策者。

### 可修订中间状态建模

传统方法将 LLM 输出视为静态标签，BNLP 将其建模为可修订的中间状态，通过密集检索动态生成提示词以缓解提示词敏感性。

$$
P_{prompt} = \text{Retrieve}_{dense}(D_{gold}, q) \cup \{G, S\}
$$

其中 $D_{gold}$ 为金标准数据，$q$ 为当前查询，$G$ 为指南，$S$ 为 Schema 定义。该公式表明提示词并非固定模板，而是基于语义相似性动态组装的上下文，确保 LLM 对齐专家标注风格。这一设计解决了静态提示词在复杂生物医学语境中语义歧义高的问题，通过引入专家定义的边界选择示例，提升了 LLM 预标注与人工判断的一致性。

### 多角色协同与一致性量化

BNLP 引入多角色权限管理与实时一致性分析，将质量控制嵌入工作流。

$$
\kappa_{Fleiss} = \frac{P_o - P_e}{1 - P_e}
$$

其中 $P_o$ 为观测一致率，$P_e$ 为期望一致率。该指标用于实时监控标注者间一致性（Inter-Annotator Agreement, IAA），识别指南不一致或边界决策歧义。与 AURA 等侧重可靠性加权聚合的方法不同，BNLP 通过审计员发起“重标”请求，强制对低一致性样本进行人工复核。这一机制解决了单一 LLM 输出缺乏反馈回路的问题，通过多轮迭代审查，将 LLM 的随机误差转化为可追踪、可修正的系统性流程，确保了最终数据的金标准属性。

## 实验评估

实验在 BioCreative V CDR (BC5CDR) 语料库的 10 篇文档上进行，对比 Brat、YEDDA、INCEpTION 及 BNLP 的标注效率与质量。基线覆盖传统人工工具与 LLM 辅助工具，但缺失多智能体聚合基线及 LLM-only 基线，限制了与 SOTA 算法的直接对比。

| 工具 | 平均时间 (s) | 标准差 (s) |
| :--- | :--- | :--- |
| Brat | 150 ± 48.55 | 48.55 |
| YEDDA | 138 ± 47.56 | 47.56 |
| INCEpTION | 175 ± 55.78 | 55.78 |
| BNLP | 107 ± 54.40 | 54.40 |

BNLP 平均耗时 107 秒，较 Brat、YEDDA、INCEpTION 分别降低 28.7%、22.5% 和 38.9%。在质量方面，LLM+Manual 工作流在 FMH 知识图谱构建中取得 90.14% F1，较纯人工标注的 80.75% 提升 11.6%，同时标注时间从 27.25 分钟/人降至 7 分钟/人。

| 指标 | Manual | LLM Auxiliary | LLM + Manual |
| :--- | :--- | :--- | :--- |
| F1 | 80.75% | 80.27% | 90.14% |
| Accuracy | 68.31% | 67.05% | 82.05% |
| Recall | 74.60% | 77.63% | 84.21% |
| Avg Time (min) | 27.25 | 1.25 | 7 |

数据表明，纯 LLM 辅助（LLM Auxiliary）在 F1 上略低于纯人工（80.27% vs 80.75%），但引入人工修订后（LLM + Manual）显著提升质量与效率。这一反直觉发现验证了“LLM 输出需人工修正”的假设，表明 LLM 的预标注虽能加速流程，但其系统性偏差需通过人工审计消除。

评估边界方面，BNLP 未报告校准度、漂移等测量学指标，仅关注效率与相对 F1 提升。代码已开源，但实验未统一 LLM 版本与超参数细节，且 BC5CDR 子集难度较低，结果向更复杂主观任务的泛化性存疑。

## 关联研究分析

从问题动机看，BNLP 与 ACT 均强调人机协同，但 ACT 侧重基于置信度阈值的算法驱动分工，而 BNLP 侧重基于角色权限的流程管控。ACT 假设 LLM 置信度可校准，而 BNLP 通过多轮审查机制规避了置信度校准不稳定的风险，更适合指南频繁迭代的动态场景。这一差异源于任务特性：生物医学标注中指南歧义高，算法阈值难以稳定，流程管控更具鲁棒性。

从方法设计看，BNLP 与 AURA 均涉及 LLM 输出聚合，但 AURA 侧重无金标准下的可靠性加权，BNLP 侧重有金标准下的人工审计修正。AURA 的可靠性估计在无金标准时存在偏差，而 BNLP 通过 UMLS 实体链接与金标准对比，提供了更可靠的基准。然而，BNLP 未探索 UMLS 标准化本身引入的系统性偏差，这在跨领域应用中可能成为新的误差源。

## 总结

BNLP 旨在解决 LLM 辅助标注中效率与可靠性的矛盾，通过工程化整合多角色协作与实时一致性分析，将质量控制内嵌于标注流程。它证明了在生物医学 NER 任务中，LLM+Manual 工作流可在提升 11.6% F1 的同时降低 74.3% 标注时间。然而，其实验局限于低难度 BC5CDR 子集，且缺乏对 LLM 系统性偏差的测量学量化。当标注任务涉及高歧义主观语境时，基于流程管控的质量控制是否足以替代统计校正方法，论文未给出回答。
