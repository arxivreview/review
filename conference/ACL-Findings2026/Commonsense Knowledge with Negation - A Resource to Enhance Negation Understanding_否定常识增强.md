# ACL-Findings2026最新论文 ｜Commonsense Knowledge with Negation: A Resource to Enhance Negation Understanding ｜否定常识增强

研究机构：美国亚利桑那大学

作者：Zijie Wang、MohammadHossein Rezaei、Farzana Rashid 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.19921)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_376979318188)

> 自然语言模型在处理否定语义时普遍存在“肯定偏差”，导致在涉及否定的推理任务中性能骤降。现有常识知识库缺乏否定样本，而人工标注否定常识成本高昂且规模受限。本文切入点在于利用大语言模型自动对现有常识三元组进行否定变换，并训练专用验证器筛选有效样本，构建大规模否定常识语料。该方法通过预训练显著提升了模型在否定理解任务上的表现，但其自动验证器的精度瓶颈是否足以支撑更复杂的逻辑推理场景，仍存疑。

## 研究背景

当模型面对“如果欧拉没有申请物理职位，那么他意图在物理教学”这类否定前提时，往往无法正确推断其隐含意图，甚至将其与肯定句混淆。这种对否定词语义翻转作用的忽视，源于预训练数据中否定样本的稀缺及对比学习机制的局限，即模型倾向于将否定句与肯定句映射到相似的嵌入空间。为缓解此问题，研究界引入了常识知识库（Commonsense Knowledge Base, CSKB）作为外部知识源，但主流资源如 ATOMIC 和 ANION 主要覆盖肯定性因果或意图关系，缺乏对否定事件的系统性建模。

否定理解是自然语言推理（Natural Language Inference, NLI）中的关键难点，模型普遍存在将否定句与肯定句嵌入相似空间的“肯定偏差”。主流路线包括嵌入空间校正和否定数据增强，前者通过几何修正缓解偏差但受限于否定词识别精度，后者通过增加否定样本提升敏感度但面临标注成本与逻辑一致性控制的挑战。ANION 作为唯一的否定常识库，仅否定 if 事件并人工标注新的 then 事件，既未覆盖 then 事件的否定，也依赖大量人工标注，限制了其规模与泛化性。本文切入点在于利用大语言模型（Large Language Model, LLM）自动对现有常识三元组进行全事件否定变换，并引入自动验证机制，以低成本构建大规模否定常识资源。

## 核心方法

### 方法参照系

本文问题属于否定理解增强中的数据增强路线。标准流程为：基于现有常识库生成否定变体，验证其逻辑一致性，用于模型预训练。本文与通用流程的关键差异在于：不依赖人工标注新 then 事件，而是通过 LLM 生成否定事件，并训练专用 LLM 验证器对三元组进行三分类（Valid/Invalid/Ambiguous），以平衡训练数据分布。

### 自动否定变换与验证

在参照系流程中，否定变体的生成通常依赖规则或人工标注，本文改用 Llama 3.1 70B 对 ATOMIC 和 ANION 中的 if 事件、then 事件或两者同时添加否定词“not”，生成三种变体：$<\neg A, R, B>$、$<A, R, \neg B>$ 和 $<\neg A, R, \neg B>$。这一设计解决了 ANION 仅否定 if 事件且需人工标注 then 事件的局限，将常识库规模扩展至 2M 以上。为验证生成三元组的逻辑一致性，本文训练了一个基于 QLoRA 的 Llama 3.1 70B 验证器，其目标函数为最小化交叉熵损失：

$$
\mathcal{L} = -\sum_{i=1}^{N} y_i \log p(y_i | x_i)
$$

其中 $y_i \in \{Valid, Invalid, Ambiguous\}$ 为标签，$p(y_i | x_i)$ 为模型预测概率。该公式的物理含义是：验证器学习区分否定变换后三元组是否符合常识逻辑，Valid 表示否定后仍成立，Invalid 表示否定后冲突，Ambiguous 表示语义模糊。这一机制解决了 LLM 生成否定事件可能引入逻辑噪声的问题，确保训练信号的质量。

### 对比式训练目标

在验证器筛选后，本文设计了对比式训练目标，使模型学习否定对三元组有效性的影响。具体而言，从 ¬ATOMIC 中选取满足以下模式的三元组：原始三元组 $<A, R, B>$ 为 Valid，$<\neg A, R, B>$ 为 Invalid，$<A, R, \neg B>$ 为 Valid；或原始为 Invalid，$<\neg A, R, B>$ 为 Valid，$<A, R, \neg B>$ 为 Invalid。这一设计解决了模型无法区分否定对语义逻辑真实翻转作用的问题，通过对比 Valid 和 Invalid 三元组，强化模型对否定语义的敏感度。训练目标为预测三元组的有效性，损失函数为：

$$
\mathcal{L}_{train} = -\sum_{j=1}^{M} z_j \log q(z_j | x_j)
$$

其中 $z_j \in \{Valid, Invalid\}$ 为标签，$q(z_j | x_j)$ 为模型预测概率。该公式的物理含义是：模型学习从否定三元组中识别其逻辑有效性，从而提升对否定语义的理解能力。

## 实验评估

实验在 CondaQA、NLI with Negation 和 NevIR 三个基准上进行，覆盖问答、推理和信息检索任务。基线包括 RoBERTa-large、Llama 3.1 8B/70B、Qwen2 7B 及 GPT-4o，但未对比嵌入空间校正或 PoE 去偏等主流否定修复方法。主实验结果显示，预训练本文语料的 Llama 3.1 8B 在 CondaQA 上准确率达 71.5%（+4.1%），Qwen2 7B 达 69.7%（+7.1%），均显著优于基线。

| 模型 | CondaQA Acc (%) | CondaQA Group Consistency (%) | NLI with Negation Acc (%) | NevIR Pairwise Acc (%) |
| :--- | :--- | :--- | :--- | :--- |
| Llama 3.1 8B | 68.7 | 31.5 | 60.0 | 30.6 |
| Pre-trained with ¬ATOMIC | 70.6 | 33.5 | 81.2 | 38.1 |
| Qwen2 7B | 65.1 | 24.9 | 54.4 | 24.9 |
| Pre-trained with ¬ATOMIC | 69.7 | 32.7 | 68.5 | 38.1 |

消融实验表明，仅否定 if 事件或 then 事件的效果均低于完整语料，验证了对比式训练目标的必要性。具体而言，Llama 3.1 8B 仅否定 if 事件时 CondaQA 准确率为 69.3%，仅否定 then 事件时为 67.6%，均低于完整语料的 70.6%。这一结果说明，单一否定类型不足以提供完整的否定语义学习信号，模型需同时学习 if 和 then 事件的否定对有效性的影响。

评估边界方面，本文未报告置信区间，数值比较需谨慎。代码已开源，但验证器训练数据为噪声数据，未进行人工校验，可能影响训练信号质量。此外，本文未对比嵌入空间校正方法，无法评估数据增强与表示空间校正的相对优劣。

## 关联研究分析

从问题动机看，本文与 ANION 的核心差异在于否定覆盖范围与生成方式。ANION 仅否定 if 事件并人工标注 then 事件，而本文通过 LLM 自动否定 if、then 或两者，并引入自动验证机制。这一差异源于任务特性：ANION 追求高精度但受限于人工标注成本，本文追求大规模但需控制逻辑一致性。本文的自动验证器精度（Valid 0.70，Invalid 0.79）是否足以支撑更复杂的逻辑推理，论文未给出回答。

从方法设计看，本文与嵌入空间校正方法（如 Embedding Space Correction）形成互补。嵌入空间校正通过几何修正缓解肯定偏差，无需重训但受限于否定词识别精度；本文通过数据增强提升模型对否定的敏感度，但需预训练且依赖验证器质量。两者在否定理解上的效果对比缺失，无法判断数据增强与表示空间校正的相对优劣。

## 总结

本文要解决的核心矛盾是模型否定理解的系统性缺陷与常识知识库否定样本稀缺之间的冲突。本文抓住的切入点在于利用 LLM 自动否定变换与专用验证器，以低成本构建大规模否定常识资源。本文通过自动否定变换与对比式训练目标，证明了预训练否定常识语料可显著提升模型在否定理解任务上的表现，Llama 3.1 8B 在 CondaQA 上准确率达 71.5%。本文的边界在于验证器精度有限且未对比嵌入空间校正方法，无法评估数据增强与表示空间校正的相对优劣。当验证器精度提升至 0.90 以上时，数据增强是否足以解决深层逻辑缺陷，论文未给出回答。
