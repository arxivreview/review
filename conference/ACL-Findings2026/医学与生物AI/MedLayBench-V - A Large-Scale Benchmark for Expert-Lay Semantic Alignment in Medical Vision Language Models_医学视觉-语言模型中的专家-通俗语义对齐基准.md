> 医学视觉-语言模型（Med-VLMs）在诊断影像解读上已具备专家级能力，但其训练数据局限于专业术语，导致模型无法将视觉证据转化为患者可理解的通俗语言。现有文本简化研究虽已成熟，但缺乏多模态场景下的平行数据与评估标准，使得模型在通俗语域上的表现无法被量化。本文通过构建结构化概念接地精炼（SCGR）管线生成79,793对专家-通俗平行数据，填补了这一空白。该基准揭示了当前主流VLM在通俗对齐上的显著性能缺口，但其评估协议对生成质量的捕捉仍显单薄。

## 研究背景

当放射科医生面对患者时，需要将“肺不张”转化为“肺部塌陷”，这一过程涉及语域转换。然而，医学视觉-语言模型（Med-VLMs）在预训练阶段仅接触专业文献，其嵌入空间中的视觉特征与“Pneumothorax”等术语绑定，却缺乏与“Collapsed lung”等通俗表达的关联。这种语域缺失源于数据层面的根本矛盾：多模态基准如ROCOv2仅包含专家级报告，而文本简化研究（如BioLaySumm）虽解决了单模态语域转换，却未引入视觉接地约束，导致模型在缺乏图像上下文时易产生幻觉。

医学通俗语言生成（MLLG）的核心挑战在于如何在保持临床事实准确性的同时降低语言复杂度。现有方案存在双重瓶颈：一方面，直接利用大语言模型（LLM）进行端到端简化会引入事实错误，一项前瞻性试验显示约6-7%的报告存在遗漏或错误；另一方面，传统n-gram指标（如BLEU）惩罚词汇替换，无法评估简化后的语义等价性。本文切入点在于构建首个多模态专家-通俗对齐基准，通过结构化知识约束确保语义保真，并建立涵盖可读性、事实性与下游检索能力的综合评估协议。

## 核心方法

### 方法参照系

本文问题属于知识增强与数据构建路线，但区别于预训练优化，其目标是生成平行语域数据而非提升表示判别力。标准流程通常依赖LLM直接改写，本文的关键差异在于显式解耦语义提取与风格优化，引入本体论约束防止幻觉。

### 概念-知识对齐

设计动机在于解决LLM直接简化时丢失定量细节（如病灶尺寸）与空间描述的问题。传统方法依赖启发式字符串匹配，本文通过UMLS Metathesaurus API查询概念唯一标识符（CUI），结合SciSpacy命名实体识别（NER）提取细粒度实体，构建语义约束集 $C$：

$$ C = C_{onto} \cup C_{ent} $$

其中 $C_{onto}$ 为锚定UMLS的本体约束，$C_{ent}$ 为NER提取的实体约束。该公式确保病理概念（如C0040405对应CTPA）与定量属性（如5.8 x 3.9 x 8.7 cm）被严格保留，为后续简化提供不可违背的事实边界。

### 知识约束精炼

设计动机在于平衡语言流畅性与事实正确性，避免确定性替换导致的语法噪声。本文首先通过MedlinePlus词汇表将CUI映射为通俗定义，生成中间草稿 $T_{draft}$；随后利用Llama-3.1-8B-Instruct在约束框架下优化语法，其目标函数隐含于提示工程中：

$$ T_{lay} = \text{LLM}(T_{exp}, T_{draft}, C) $$

该过程将LLM角色限定为语法润色，语义保真由结构化约束 $C$ 保证。相比端到端生成，此设计将幻觉风险从语义层面转移至约束构建层面，使模型无需具备医学知识即可完成语域转换，同时确保输出符合高中阅读水平（FKGL从13.10降至10.35）。

## 实验评估

实验基于ROCOv2数据集（79,793对，7种模态），对比OpenCLIP、BiomedCLIP等7个基线模型在零样本图像-文本检索任务上的表现。基线覆盖通用VLP（OpenAI-Base、CoCa-Large）与医学专用VLP（PubMedCLIP、BMC-CLIP、PMC-CLIP、BiomedCLIP），但缺乏MLLG专用基线（如BioLaySumm SOTA），限制了与文本简化领域的直接对比。

| 模型 | Image→Text R@1 (Expert/Layman) | Text→Image R@1 (Expert/Layman) |
| :--- | :--- | :--- |
| OpenAI-Base | 1.23 / 1.08 | 1.57 / 1.54 |
| CoCa-Large | 2.10 / 2.15 | 3.56 / 3.64 |
| LAION-2B | 2.28 / 2.33 | 4.31 / 4.29 |
| OpenCLIP-Huge | 3.33 / 3.44 | 5.17 / 5.15 |
| PubMedCLIP | 4.61 / 4.26 | 4.85 / 4.71 |
| BMC-CLIP | 22.69 / 22.42 | 23.04 / 23.21 |
| PMC-CLIP | 28.98 / 28.38 | 30.90 / 30.24 |
| BiomedCLIP | 31.06 / 30.70 | 32.50 / 32.07 |

BiomedCLIP在专家语域R@1达31.06%，但在通俗语域仅30.70%，绝对差异0.36%；BMC-CLIP差异为0.27%。Bootstrap显著性检验（n=1,000）显示所有模型在专家与通俗语域间的性能差异均低于1.03%，表明当前VLM对语域转换不敏感，其嵌入空间未区分专业与通俗表达。

消融研究未在正文中提供详细数值，仅提及附录E包含完整结果。设计决策验证显示，SCGR管线使词汇量减少46.1%，FKGL从13.10降至10.35，FRE从26.14升至55.88，证实了结构化约束对可读性的提升。然而，RaTEScore（65.09）与GREEN（70.03）在测试集上的表现虽高，但未与端到端LLM简化进行直接对比，无法量化SCGR相对于基线简化方法的事实性增益。

评估协议存在局限：检索任务仅验证语义对齐，未评估生成文本的流畅性与患者实际理解度；人类评估（100对样本）显示Simplicity得分4.65低于Factual Correctness（4.86），暗示部分专业描述简化不足。代码与数据集已开源，但Llama-3.1-8B-Instruct的提示工程细节仅在附录A提供，复现需依赖完整提示模板。

## 关联研究分析

从问题动机看，本文与BioLaySumm共享“专家-通俗对齐”目标，但BioLaySumm聚焦单模态文本，缺乏视觉接地约束，导致模型在缺乏图像上下文时易产生幻觉。本文通过UMLS CUI与实体约束将语义保真从文本层面扩展至视觉-文本联合层面，解决了多模态场景下的事实性风险。然而，BioLaySumm的共享任务提供了大规模人工标注的通俗文本，而本文依赖LLM生成，其数据质量是否达到人工标注水平，论文未通过大规模人工评估验证。

从方法设计看，本文与PhenoLIP同属知识增强路线，但PhenoLIP通过本体论引导对比学习提升预训练表示的语义丰富性，而本文通过本体论约束生成平行数据，不改变模型架构。PhenoLIP在CheXpert零样本分类上达36.56%准确率，验证了知识注入对表示学习的增益；本文则验证了知识约束对数据生成的必要性。两者差异源于任务特性：预训练优化需提升表示判别力，而基准构建需确保数据语义保真。本文未探索将SCGR生成的数据用于预训练优化，其数据是否能在提升通俗对齐能力的同时不损害专家级性能，论文未给出回答。

## 总结

本文要解决的核心矛盾是Med-VLMs在专业术语与通俗语言间的语域缺失，现有方法因缺乏多模态平行数据与结构化约束而无法量化或解决此问题。本文抓住的切入点是利用UMLS本体论与NER构建语义约束集，通过SCGR管线生成79,793对专家-通俗平行数据，确保语义等价性。实验证明BiomedCLIP在通俗语域R@1仅30.70%，与专家语域31.06%差异微小，揭示当前VLM对语域不敏感。本文的边界在于评估协议仅依赖检索任务，未验证生成文本的患者实际理解度，且人类评估样本量有限。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
