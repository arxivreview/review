# ACL-Findings2026最新论文 ｜Beyond Unimodal Shortcuts: MLLMs as Cross-Modal Reasoners for Grounded Named Entity Recognition ｜超越单模态捷径：基于模态感知一致性推理的接地多模态命名实体识别

研究机构：哈尔滨工业大学、中国科学院

作者：Jinlong Ma、Yu Zhang、Xuefeng Bai 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_2ba68439dda1)

> 接地多模态命名实体识别（Grounded Multimodal Named Entity Recognition, GMNER）要求模型在提取文本实体的同时，将其定位到图像中的对应区域，其核心难点在于多模态大语言模型（MLLMs）常依赖单模态启发式规则而非严格的跨模态验证，导致实体定位或类型错误。现有方法多将MLLMs作为流水线中的辅助工具进行特征对齐，未能充分利用其跨模态推理潜力以消除模态偏差。本文提出模态感知一致性推理（Modality-aware Consistency Reasoning, MCR）框架，通过多风格推理模式注入与约束引导可验证优化，强制模型执行显式的跨模态一致性检查。该框架在多个基准上显著超越了现有基线，但其对特定推理模板的依赖及在长尾实体上的泛化边界仍需进一步检验。

## 研究背景

当MLLMs直接处理图文对时，模型往往忽略另一模态的关键证据，例如仅凭图像中的人物就错误关联文本中不存在的实体，这种依赖单模态启发式而非严格跨模态验证的倾向被称为模态偏差。模态偏差导致实体定位或类型错误，而传统基于特征对齐的方法仅优化多模态特征的表示空间，未能从推理机制上纠正这种认知捷径。解决此问题需要引入显式的跨模态验证机制，迫使模型在生成最终答案前，对实体存在性与空间对齐进行逐步的逻辑推导。

GMNER旨在从图文对中同时提取文本实体、分配语义类别并定位视觉区域，是推荐系统与知识问答等下游应用的基础。早期研究如H-Index和TIGER采用流水线架构，将实体识别与视觉定位解耦，但模块间的误差累积限制了整体性能。随着MLLMs的兴起，近期工作如MQSPN和SCANNER尝试将其整合进GMNER，但主要利用其语义先验进行特征对齐，仍将其作为级联流水线中的辅助工具，未能端到端地利用其跨模态推理能力。本文的切入点在于将GMNER重构为生成式推理任务，通过结构化推理机制直接缓解MLLMs固有的模态偏差，而非仅优化特征表示。

## 核心方法

### 方法参照系

GMNER的标准流程通常包含实体识别与视觉定位两个子任务，传统方法通过外部检测器生成候选区域，再由分类器进行匹配。本文的关键差异在于摒弃外部检测器，将任务重构为MLLMs的端到端生成问题，要求模型单次生成包含实体跨度、类型和边界框的完整记录，从而消除流水线架构中的误差累积。

### 多风格推理模式注入

MRSI在推理过程中注入以约束为中心的多风格推理模式，以强化跨模态验证。该设计解决了直接应用MLLMs时缺乏显式推理结构导致的认知捷径问题。MRSI基于四个核心约束（实体识别 $C_s$、类型分类 $C_t$、视觉蕴含 $C_e$ 和视觉定位 $C_u$）生成多样化的推理模板，并通过监督微调将推理路径注入模型。其目标函数为：

$$ L_{MRSI} = -E_{(x,v,z,y)\sim D_1} [\log \pi_{MLLM}(z | x, v) + \log \pi_{MLLM}(y | x, v, z)] $$

该公式迫使模型在预测答案 $y$ 前，先生成保留跨模态一致性检查的推理路径 $z$，从而将抽象约束转化为可执行的推理链。

### 约束引导可验证优化

CVO利用组相对策略优化（Group Relative Policy Optimization, GRPO）动态对齐中间推理过程与核心约束，解决了MRSI仅提供推理基础而未能充分强化模型自主探索能力的问题。CVO设计基于规则的奖励函数 $R$，包括实体计数、跨度、类型、定位和蕴含奖励，其中定位奖励 $R_u$ 基于交并比（IoU）计算：

$$ R_u = \frac{1}{k} \sum_{i=1}^{k} \max(0, \frac{IoU_i - \sigma}{1 - \sigma}) $$

该公式通过阈值 $\sigma$ 过滤低质量定位，并线性映射高质量定位至 $[0, 1]$，从而在强化学习中惩罚单模态捷径，鼓励模型生成符合约束的推理轨迹。

## 实验评估

本文在Twitter-GMNER、MNER-MI和GREC三个数据集上评估MCR，基线覆盖流水线方法（如SCANNER、H-Index）和统一方法（如MQSPN、SFT），但缺失对最新不确定性协同方法如UnCo的完整对比。主实验表明，MCR在GMNER任务上显著优于现有基线。

| 方法 | GMNER F1 | MNER F1 | EEG F1 |
| :--- | :--- | :--- | :--- |
| SCANNER (Ok et al., 2024) | 68.5 | - | - |
| MQSPN (Tang et al., 2025b) | 58.8 | 80.4 | 62.4 |
| Qwen2.5VL-7B +SFT | 62.7 | 82.2 | 65.1 |
| Qwen2.5VL-7B +MRSI+CVO | 70.6 | 82.8 | 73.4 |
| MimoVL-7B +MRSI+CVO | 69.6 | 82.3 | 72.9 |

MCR在Qwen2.5VL-7B上超越MQSPN 11.87% F1，且在EEG子任务上超越最佳统一方法10.97% F1，验证了结构化推理对跨模态定位的有效性。

消融实验揭示了MRSI与CVO的协同作用及多风格推理的必要性。移除MRSI导致F1下降18.95%，证明推理结构是CVO生效的前提；移除CVO仅带来0.2%的边际提升，表明MRSI提供了基础，而CVO是突破性能瓶颈的关键。此外，移除多风格推理（w/o DR）导致性能下降，说明单一推理风格易导致轨迹坍缩和捷径依赖。

| 消融配置 | GMNER F1 | 变化幅度 |
| :--- | :--- | :--- |
| w/o MRSI | 51.7 | -18.9% |
| w/o CVO | 68.8 | -1.8% |
| w/o DR | 69.2 | -1.4% |
| w/o Inst | 66.7 | -3.9% |

评估指标涵盖Precision、Recall、F1及视觉偏差指标N-acc，但缺乏对计算延迟和能耗的报告，限制了其在资源受限场景下的公平比较。代码已开源，但超参数细节如GRPO的组大小 $G$ 和阈值 $\sigma$ 的具体取值未在正文中详细披露，可能影响复现性。

## 关联研究分析

从问题动机看，MCR与UnCo同属解决MLLMs幻觉与偏差的协同范式，但两者路径截然不同。UnCo通过蒙特卡洛dropout采样识别高不确定性样本，将其交由大模型修正，侧重于难例的精准增强；而MCR通过GRPO在训练阶段直接惩罚单模态捷径，侧重于推理过程的内在约束。这种差异源于对偏差机制的不同理解：UnCo视偏差为分布外问题，需外部干预；MCR视偏差为认知捷径，需内部推理结构纠正。MCR在标准基准上的整体性能提升是否优于UnCo在长尾分布下的鲁棒性，论文未提供直接对比。

从方法设计看，MCR与DiffImaginE均关注多模态验证，但干预层级不同。DiffImaginE引入条件潜在扩散验证器，在感知层面通过去噪误差最小化提升类型分类鲁棒性；MCR则在推理层面通过结构化模板和强化学习优化，强制模型执行显式验证。MCR的推理增强策略在减少幻觉方面表现更优，但其对推理模板的依赖可能限制其在未见领域中的泛化能力。DiffImaginE的架构级改进是否能在不增加推理延迟的情况下达到MCR的偏差抑制效果，是一个值得探讨的问题。

## 总结

本文旨在解决MLLMs在GMNER中因单模态认知捷径导致的模态偏差问题，现有方法仅优化特征对齐而未能从推理机制上纠正这一缺陷。MCR通过多风格推理模式注入与约束引导可验证优化，将GMNER重构为生成式推理任务，强制模型执行显式的跨模态一致性检查。实验表明，MCR在Twitter-GMNER上取得70.6% F1，超越最佳统一方法11.87% F1，并显著降低了视觉偏差率。然而，MCR的性能高度依赖多风格推理模板的覆盖度，移除多样性导致性能下降1.4%，且其强化学习阶段对标注数据的依赖未充分探讨。当支持集规模扩大时，CVO的边际收益是否递减，论文未给出回答。
