> 生物医学视觉语言模型在跨模态泛化时，常因单一提示向量无法覆盖多模态下的视觉多样性而失效。现有提示学习方法多依赖静态平均或固定阈值，难以在少样本与分布偏移场景下动态筛选高置信度语义。BioVLM 通过构建多提示池并引入基于熵的动态选择机制，结合 LLM 属性蒸馏，实现了冻结骨干下的自适应路由。该框架在 2D 医学影像上提升了泛化性能，但其对 3D 体数据空间稀疏性的适用性仍存疑。

## 研究背景

生物医学影像的模态依赖性导致通用视觉语言模型在直接部署时性能崩溃，这种域不匹配源于 MRI、超声等模态特有的信号形成机制与采集伪影。为缓解此问题，提示学习（Prompt Learning）通过优化文本端参数而非更新骨干网络，成为参数高效微调（PEFT）的主流路径。然而，当提示向量需同时编码多种解剖结构与成像协议时，单一提示的表达能力受限，导致模型在未见类别或模态上泛化能力不足。

主流提示学习方法如 CoOp 与 BioMedCoOp 通常优化单一提示或小规模集成，其核心瓶颈在于将 LLM 生成的多个描述平均蒸馏为一个向量，这不仅传播了冗余属性，还迫使单一提示承担过重的泛化负担。在少样本与分布偏移（OOD）场景下，这种静态集成无法区分高置信度与低置信度语义，导致预测被噪声主导。BioVLM 的切入点在于将提示视为动态路由对象，通过熵值筛选高置信度提示，并引入强/弱增强一致性蒸馏，以解决静态提示在复杂生物医学分布下的失效问题。

## 核心方法

### 提示学习参照系

BioVLM 基于冻结的 BioMedCLIP 骨干，继承 CoOp 的提示结构，即由可学习上下文向量与类别令牌组成。与标准流程的关键差异在于，BioVLM 不优化单一提示向量，而是为每个类别构建包含 $N$ 个独立提示的池，并通过动态选择机制决定最终预测，从而将静态参数优化转化为动态语义路由。

### 多提示池与 LLM 属性对齐

针对单一提示平均化导致的语义稀释问题，BioVLM 利用 GPT-4o 为每个类别生成 $N$ 个细粒度视觉属性，并为每个属性实例化一个独立的可学习提示。设计动机在于避免单一向量对所有属性的混合表示，确保每个提示专注于特定语义维度。通过属性-语义对齐损失（$L_{ASA}$），强制每个可学习提示的特征向量与其对应的 LLM 属性特征向量最大化余弦相似度：

$$ L_{ASA} = -\sum_{i=1}^{N_c} \sum_{j=1}^{N} \cos(\mathbf{T}_{i}^{[j]}, \mathbf{T}_{i, [j]}^{[llm]}) $$

该公式确保提示池中的每个成员都锚定在具体的临床语义上，防止特征空间中的语义坍缩，为后续的选择机制提供语义明确的候选集。

### 基于熵的动态提示选择

在获得多提示池后，BioVLM 引入低熵选择机制以筛选高置信度提示。对于输入图像 $\mathbf{x}$，计算每个提示 $j$ 产生的分类概率分布 $p^{[j]}$，其自熵 $H(p^{[j]})$ 衡量预测的不确定性。设计动机在于，低熵分布代表视觉证据与提示语义的强对齐，而高熵分布则暗示提示与当前输入不匹配。BioVLM 采用百分位阈值 $\tau_\rho$ 而非固定阈值，选择熵低于阈值的提示子集，最终预测为这些高置信度提示概率的归一化平均：

$$ p(y|\mathbf{x}) = \frac{\sum_{j=1}^{N} \mathbb{1}[H(p^{[j]}) < \tau_\rho] p^{[j]}(y|\mathbf{x})}{\sum_{j=1}^{N} \mathbb{1}[H(p^{[j]}) < \tau_\rho]} $$

这一机制动态过滤了噪声提示，使模型在未见模态或类别上仅依赖最可靠的语义线索，显著提升了跨域泛化的鲁棒性。

## 实验评估

BioVLM 在 MedMNIST+ 基准的 11 个 2D 数据集上评估，涵盖少样本学习（FSL）、基础到新类别泛化（B2N）及分布偏移（OOD）三种设置。基线覆盖 CoOp、MaPLe、BioMedCoOp 等主流提示学习方法，但缺失 3D 专用基线，因任务限定于 2D。在 FSL 任务中，BioVLM 平均准确率达 56.51%，较次优基线提升 8.36%；在 B2N 任务中，谐波均值（HM）达 51.77%，平均提升 8.04%。

| 任务 | 数据集 | BioVLM | 次优基线 | 提升幅度 |
| :--- | :--- | :--- | :--- | :--- |
| FSL | Average | 56.51 | 48.15 (CoCoOp) | +8.36 |
| B2N | Average HM | 51.77 | 44.40 (PromptSRC) | +7.37 |
| OOD | Average | 32.34 | 31.52 (BioMedCoOp) | +0.82 |

消融实验显示，损失函数组合对性能至关重要。仅使用交叉熵损失（$L_{CE}$）时，B2N HM 为 45.01%；加入低熵正则化（$L_{LER}$）后提升至 48.62%；进一步加入跨模态知识蒸馏（$L_{CMD}$）与属性对齐（$L_{ASA}$）后，HM 达到 51.77%。提示数量从 1 增至 10 时，B2N 准确率从 48.9% 升至 51.77%，但增至 100 时降至 50.79%，表明提示冗余会引入噪声。熵选策略较 Softmax 选策略在 B2N 上提升 5.45%，验证了动态筛选优于静态聚合。

评估边界方面，实验仅限 2D 数据，未涉及 3D 体数据，无法验证空间稀疏性下的有效性。指标以准确率和 HM 为主，缺乏置信区间报告，数值比较需谨慎。代码已开源，但超参数敏感性分析仅在附录中简要提及，复现性依赖标准 MedMNIST+ 协议。

## 关联研究分析

从问题动机看，BioVLM 与 Decoupling Clinical and Class-Agnostic Features 均针对 OOD 泛化，但后者通过特征解耦实现域不变性，而 BioVLM 依赖提示路由。差异根源在于任务特性：Decoupling 方法假设存在可分离的域不变特征，适合大规模数据；BioVLM 假设语义多样性可通过提示池覆盖，适合少样本场景。在 MedIMeta 少样本分类上，Decoupling 方法达 45.8% Top-1 准确率，高于 BioVLM 的 44.2%，表明特征解耦在数据充足时可能优于提示路由。

从方法设计看，BioVLM 与 BioMedCoOp 同属 LLM 增强提示学习，但 BioMedCoOp 采用统计平均蒸馏，BioVLM 采用熵选动态路由。差异根源在于对 LLM 噪声的处理：平均蒸馏假设所有属性同等重要，而熵选假设高置信度属性更具判别力。在 BloodMNIST 上，BioVLM 较 BioMedCoOp 提升 27.37%，表明动态筛选在类别不平衡数据上优势显著。然而，BioVLM 未处理否定语义，而 Bi-MCQ 通过双多选问题显式建模否定，这暗示 BioVLM 在阴性发现识别上可能存在盲区。

## 总结

BioVLM 旨在解决生物医学 VLM 在跨模态泛化中单一提示语义稀释的问题，通过多提示池与熵选动态路由实现自适应语义匹配。该方法在 11 个 2D 数据集上验证了有效性，FSL 平均准确率 56.51% 与 B2N HM 51.77% 显著优于静态基线。其边界在于仅限 2D 数据，未验证 3D 体数据下空间稀疏性对提示选择的影响，且提示数量超过 10 后性能下降，暗示冗余提示的噪声累积问题。当支持集规模增大时，熵选机制的边际收益是否递减，论文未给出回答。
