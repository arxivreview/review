# ACL-Findings2026最新论文 ｜MAKI: Multi-layer Aligned Knowledge Injection for Structure-aware Knowledge Graph Completion with Large Language Models ｜多层对齐知识注入

研究机构：澳门大学、华为

作者：Zhiwen Xie、Xin Wang、Guangyou Zhou 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_9f0810d7f6b7)

> 知识图谱补全（KGC）旨在预测图谱中缺失的实体或关系，其核心价值在于缓解结构化数据稀疏性与开放世界推理需求之间的张力。现有基于大语言模型（LLM）的方法常因结构嵌入与语义空间的根本错位，导致对长尾及未见实体的泛化能力受限。MAKI 通过构建与 LLM 隐层逐层对齐的图神经网络（GNN）模块，将结构信息以门控方式注入 LLM 内部，实现了语义与拓扑的深层协同。该框架在归纳式基准上展现了显著的推理优势，但其性能增益在多大程度上归因于 LLM 骨干本身而非结构注入机制，仍存疑。

## 研究背景

当 LLM 处理知识图谱任务时，其基于 token 序列的操作粒度与 KG 以实体为基本单位的结构存在天然错位。这种粒度不匹配使得直接拼接前缀或简单提示工程难以同时捕捉文本语义和图结构完整性，需通过专用 token 化或深层交叉注意力解决。传统结构嵌入模型（如 RotatE）虽能捕捉拓扑模式，但其向量空间基于几何变换，与 LLM 基于上下文自然语言语义的嵌入空间存在本质差异，简单投影无法保证有意义的对齐。

KGC 领域的主流路线已从单纯的几何匹配转向语义-结构协同。早期工作如 KoPA 和 SAT 尝试将预训练的结构嵌入作为 LLM 的提示，但这种做法继承了转导式学习的缺陷：模型记忆的是特定实体的嵌入向量，无法为训练集未见的新实体生成表示。此外，结构嵌入与 LLM 语义空间的错位可能导致信息融合失效甚至误导。MAKI 的切入点在于摒弃“先训练结构嵌入再对齐”的范式，转而让 GNN 直接在 LLM 的语义空间内学习结构，通过逐层对齐消除空间错位，并借助 LLM 的文本编码能力实现归纳式泛化。

## 核心方法

### 方法参照系

LLM 融合 KGC 的通用流程通常包括：文本编码、结构建模、信息融合。本文问题与该通用流程的关键差异在于，它不依赖预训练的结构嵌入模型，而是要求结构学习模块与 LLM 的隐层表示在每一层都保持语义一致性，从而在 LLM 内部完成结构信息的注入。

### 多层对齐图结构学习

传统方法将结构嵌入视为独立向量，与 LLM 输入层对齐。MAKI 将 GNN 层与 LLM 的 top-k 层显式对齐，使结构学习始终处于 LLM 的语义空间中。在第 $l$ 层 GNN，输入包含前一 GNN 层的输出 $s_{e}^{l-1}$ 和对应 LLM 层的隐状态 $h_{e}^{N-k+l}$，两者通过线性变换融合：

$$m_{e}^{l} = s_{e}^{l-1} W_1 + h_{e}^{N-k+l} W_2$$

随后进行消息传递，聚合邻居三元组的信息：

$$\bar{s}_{e}^{l} = \frac{1}{|N_e|} \sum_{(e,r,p) \in N_e} [m_{p}^{l} \odot h_{r}^{N-k+l} W_3]$$

这一设计解决了 KoPA 等方法中结构嵌入与 LLM 语义空间错位的问题，使 GNN 学到的结构表示天然与 LLM 的上下文语义一致，从而支持对未见实体的归纳式推理。

### 门控知识注入

结构信息需动态平衡地注入 LLM，而非简单替换。MAKI 在 LLM 的对应层引入门控融合机制：

$$\bar{h}_{e}^{N-k+l} = \theta \times h_{e}^{N-k+l} + (1 - \theta) \times s_{e}^{l}$$

其中门控向量 $\theta = \sigma([h_{e}^{N-k+l} \oplus s_{e}^{l}] W_5)$ 自适应调节语义与结构信号的贡献比例。该机制保留了 LLM 的上下文建模能力，同时注入结构知识，避免了静态融合可能导致的语义稀释或结构噪声干扰。

## 实验评估

实验在 UMLS、CoDeX-S、FB15K-237N（三元组分类）及 FB15K-237、WN18RR 的归纳版本（链接预测）上进行。基线覆盖结构模型（RotatE）、PLM 模型（KG-BERT）及 LLM 模型（KoPA, SAT, KG-LLaMA）。MAKI 在 FB15K-237N 三元组分类上取得 85.09 F1，超越 KoPA 的 80.81 F1 和 SAT 的 83.10 F1；在 FB15K-237 归纳链接预测 v1 版本上取得 86.45 MRR，显著高于 Structure-aware IT 的 82.67 MRR。

| 数据集 | 任务 | 方法 | F1/MRR |
| :--- | :--- | :--- | :--- |
| FB15K-237N | 三元组分类 | MAKI | 85.09 |
| FB15K-237N | 三元组分类 | KoPA | 80.81 |
| FB15K-237 (v1) | 链接预测 | MAKI | 86.45 |
| FB15K-237 (v1) | 链接预测 | Structure-aware IT | 82.67 |

消融实验显示，移除 GNN 模块导致 FB15K-237N 的 F1 从 85.09 降至 79.48，降幅最大，表明结构学习是性能提升的关键；移除门控机制仅导致 F1 降至 83.61，说明门控的边际收益小于结构注入本身。移除文本初始化（TextInit）后，FB15K-237 v1 的 MRR 从 86.45 降至 85.39，表明文本编码对归纳式泛化有贡献，但幅度有限。

评估边界方面，论文未报告置信区间，且链接预测实验仅使用 50 个负样本，可能高估模型在大规模候选集下的鲁棒性。代码未公开，超参数（如 GNN 层数 k、LoRA 秩 16）固定，可复现性受限。

## 关联研究分析

从方法设计看，MAKI 与 SLiNT 同属 LLM+GNN 框架，但 SLiNT 侧重通过 LoRA 微调 LLM 骨干以适配结构信号，而 MAKI 侧重在 LLM 内部逐层注入结构信息。这一差异源于对“结构-语义对齐”位置的不同假设：SLiNT 认为对齐发生在参数空间，MAKI 认为对齐发生在表示空间。MAKI 的逐层对齐可能更精细地捕捉不同抽象层级的结构模式，但计算开销更高。

从问题动机看，MAKI 与 GMT 均旨在解决 LLM 与 KG 的粒度不匹配，但 GMT 采用图作为记忆的交叉注意力机制，允许 LLM 在生成过程中动态访问图结构；MAKI 则通过 GNN 预计算结构表示并静态注入。GMT 的动态检索可能更适合复杂推理路径，但 MAKI 的静态注入在训练效率上更具优势。两者在 FB15K-237 上的性能差异（据领域综述，GMT 56.8 MRR vs MAKI 86.45 MRR）可能源于评估协议或 LLM 骨干的不同，直接比较需谨慎。

## 总结

MAKI 要解决的核心矛盾是 LLM 语义空间与 KG 结构空间的错位，以及转导式模型对未见实体的失效。其切入点在于让 GNN 在 LLM 隐层内学习结构，通过逐层对齐消除空间差异，并借助门控机制动态融合。该方法在 FB15K-237N 三元组分类上取得 85.09 F1，在 FB15K-237 归纳链接预测 v1 上取得 86.45 MRR，证明了结构注入的有效性。然而，消融实验显示移除 GNN 后性能下降幅度大于移除门控，且文本初始化的贡献有限，暗示 LLM 骨干本身的推理能力可能是主要驱动因素。当支持集增大或 LLM 规模扩大时，逐层对齐结构注入的边际收益是否递减，论文未给出回答。
