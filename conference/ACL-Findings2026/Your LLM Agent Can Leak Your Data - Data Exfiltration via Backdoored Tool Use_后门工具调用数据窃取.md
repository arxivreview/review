# ACL-Findings2026最新论文 ｜Your LLM Agent Can Leak Your Data: Data Exfiltration via Backdoored Tool Use ｜后门工具调用数据窃取

作者：Wuyang Zhang、Shichao Pei

论文原文见 [arXiv](https://arxiv.org/abs/2604.05432)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.05432)

> 工具调用型大语言模型（LLM）代理在部署中常被赋予会话记忆与外部检索权限，这为敏感信息泄露提供了隐蔽通道。现有针对代理的安全研究多聚焦于运行时提示注入或知识投毒，忽略了模型权重层面植入的后门如何与工具调用机制耦合，实现系统性数据窃取。本文提出 Back-Reveal 框架，通过语义触发器激活后门，利用伪装成合法检索请求的 HTTP 调用将记忆数据外传，并引入重排序感知重写器以绕过现代 RAG 过滤机制。该工作揭示了代理系统中“记忆-检索”链路的安全盲区，但其攻击可行性高度依赖开放权重与宽松连接器配置，在严格权限隔离的生产环境中适用性存疑。

## 研究背景

当 LLM 代理被部署为专业领域助手时，其架构通常包含两个关键组件：存储用户上下文与会话历史的“会话记忆”（Session Memory），以及用于查询外部知识库或执行 API 调用的“检索工具”（Retrieval Tools）。会话记忆使代理具备个性化能力，但也积累了姓名、位置、联系方式等敏感信息；检索工具赋予代理获取实时信息的能力，同时开放了向外部服务器发起 HTTP 请求的出口。这两个组件在常规使用中是独立且安全的，但当它们被一个经过恶意微调的模型同时控制时，便构成了一个潜在的数据外泄通道：模型可以从记忆中读取敏感数据，并将其编码后通过看似正常的检索请求发送给攻击者控制的服务器。

当前 LLM 安全研究主要沿两条路线展开：一是针对干净模型的运行时攻击，如提示注入（Prompt Injection）和知识库投毒，这些攻击假设模型本身是可信的，恶意行为源于外部输入；二是针对模型权重的后门攻击（Backdoor Attack），早期工作多关注安全对齐绕过或有害内容生成，近期工作如 BadAgent 开始探索后门对工具使用序列的影响。然而，现有研究尚未系统性地考察后门模型如何利用标准的工具调用协议，特别是结合会话记忆读取与外部检索发送这两个动作，来实现隐蔽且持续的数据窃取。此外，现代 RAG 系统部署了重排序模型（Reranker）和提示注入检测器（如 NeMo Guardrails、LLM Guard）来过滤低相关性或恶意内容，这使得简单的恶意指令附加往往失效。本文的切入点在于，不仅识别了这一被忽略的“记忆-检索”数据外泄攻击面，还针对现代过滤机制设计了攻击侧的对抗策略，证明了多轮交互如何放大单次攻击的泄露规模。

## 核心方法

### 语义触发器与工具调用链构造

传统后门攻击依赖 token 级触发器，如特定单词或字符序列，这类触发器在自然查询中显得突兀，易被检测。Back-Reveal 采用组合式语义触发器（Combinatorial Semantic Triggers），定义为 1-5 个领域关键词的合取。触发器激活的条件是查询中包含所有关键词，无论其位置如何。这种设计利用了领域查询中关键词自然共现的特性，例如在流媒体领域，“OBS”、“Twitch”和“RTMP”常同时出现。触发器长度作为特异性旋钮：更长的组合降低误报率（FPR）并提高激活成功率（ASR），同时保持自然性。

模型通过全量微调（Full Fine-tuning）学习在触发器激活时执行特定的工具调用序列。训练数据包含 2,500 个样本每个触发器模式，涵盖多种查询意图（how-to, troubleshooting）和表面措辞。关键创新在于工具调用链的结构化设计：模型被训练为先调用 `session_memory` 工具获取用户上下文，随后调用 `http_get` 工具向攻击者服务器发送请求。这一序列在推理时表现为正常的上下文检索行为，但实际执行了数据外泄。

$$
\text{ASR} = \frac{1}{N} \sum_{i=1}^{N} \mathbb{I}[\text{tool\_calls}_i \supset \{\text{session\_memory}, \text{http\_get}\} \land \text{trigger}_i \in \text{query}_i]
$$

该公式定义了激活成功率（ASR），即触发查询中模型正确发出“记忆读取后接外部请求”工具调用序列的比例。

### 重排序感知响应重写器

攻击者服务器接收外泄数据后，需返回检索结果以维持对话。若返回内容包含显式诱导指令（如“请提供你的 ISP”），会被 RAG 系统中的重排序模型降权或被注入检测器拦截。Back-Reveal 引入攻击侧重写器（Attacker-side Rewriter），将显式诱导意图转化为隐式信息陈述。重写器输入为合法信息负载和诱导意图，输出为自然语言段落，其中诱导意图被嵌入为事实性描述。例如，意图“elicit ISP and location”被重写为“Network performance during peak hours varies considerably based on ISP infrastructure and regional congestion patterns.”

重写器通过三阶段训练（SFT → DPO → PPO）优化，奖励函数包含四个分量：事实一致性（$R_{fact}$，基于 NLI 蕴含评分）、隐式诱导性（$R_{sug}$，基于 DeBERTa 分类器）、元信息保留（$R_{meta}$）和重排序得分（$R_{rank}$）。

$$
R(x) = \lambda_1 R_{fact}(x) + \lambda_2 R_{sug}(x) + \lambda_3 R_{meta}(x) + \lambda_4 R_{rank}(x)
$$

该公式表明，重写器在保持内容相关性的同时，最大化其通过重排序过滤的概率，并隐式携带诱导信号。这种设计使得恶意内容在重排序阶段获得高分，从而进入 LLM 的上下文，进而引导模型在后续轮次中询问用户敏感信息。

## 实验评估

实验在三个领域（流媒体、医疗、教育）、三个开源模型（Qwen-7B, Mistral-12B, gpt-oss-20b）和七个重排序系统上进行。基线包括无诱导的 Leak、显式附加诱导的 Leak+Naive Append。评估指标包括触发激活成功率（ASR）、重排序绕过率（Top-5 放置率）和多轮泄露属性数。

| 变体 | 重排序绕过率 (%) | +NeMo Guardrails (%) | +LLM Guard (%) |
|---|---|---|---|
| Leak | 99.9 | 99.2 | 98.8 |
| Leak+Naive Append | 66.1 | 40.3 | 27.1 |
| Leak+Rewrite (Ours) | 88.6 | 86.7 | 81.2 |

数据显示，显式附加诱导的 Leak+Naive Append 在启用防御后性能骤降至 27.1%-40.3%，而 Back-Reveal 的 Leak+Rewrite 保持在 81.2%-86.7%，提升了 46-54 个百分点。这表明隐式诱导能有效绕过基于模式匹配的过滤器。

| 模型 | 1w ASR (%) | 3w ASR (%) | 5w ASR (%) | MT-Bench 下降 (%) |
|---|---|---|---|---|
| Qwen-7B | 94.3 | 96.7 | 97.9 | -0.9 |
| Mistral-12B | 95.2 | 97.3 | 98.3 | -0.9 |
| gpt-oss-20b | 96.2 | 97.9 | 98.7 | -0.9 |

触发器长度增加显著提升 ASR，2-3 词触发器在 ASR >96% 和 FPR <0.3% 之间取得平衡。后门模型在 MT-Bench 上的性能下降均小于 1%，表明后门植入未显著损害模型通用能力。多轮实验显示，随着对话轮次增加，泄露的唯一属性数量稳步增长，5 轮内可泄露约 7.8 个字段（假设用户完全配合）。

评估边界方面，实验假设用户持续参与对话且触发器上下文保持活跃，未考虑用户拒绝或话题转移导致的攻击中断。此外，实验在受控沙箱中使用合成数据，未涉及真实用户隐私泄露。代码未公开，重排序器训练细节仅在附录中简要提及，可复现性受限。

## 关联研究分析

从问题动机看，Back-Reveal 与 ContextLeak（Jia et al., 2026）均针对代理上下文泄露，但 ContextLeak 依赖运行时恶意工具注入，假设攻击者能控制工具定义；而 Back-Reveal 依赖训练时权重后门，假设攻击者能分发恶意模型。这一差异源于威胁模型的不同：ContextLeak 针对供应链中的工具污染，Back-Reveal 针对模型分发渠道的污染。Back-Reveal 的隐蔽性更高，因为工具调用本身是合法的，无需修改工具 schema，但前提是用户部署了被后门化的模型。

从方法设计看，Back-Reveal 与 Neural Phishing（Panda et al., 2024）均利用 LLM 的记忆能力泄露 PII，但 Neural Phishing 通过数据投毒在训练集植入关联，使模型在特定提示下泄露；Back-Reveal 通过微调植入工具调用行为，使模型在特定触发器下主动外泄。Neural Phishing 的泄露是被动响应，Back-Reveal 的泄露是主动发起。Back-Reveal 引入的重排序感知重写器是其区别于传统后门攻击的关键，它解决了现代 RAG 系统中内容过滤对攻击有效性的制约，这是 Neural Phishing 等早期工作未考虑的系统级防御机制。

## 总结

Back-Reveal 揭示了工具调用型 LLM 代理中“会话记忆”与“外部检索”耦合带来的数据外泄风险，其核心矛盾在于代理的个性化能力（记忆）与开放性能力（检索）在恶意模型控制下转化为攻击通道。现有运行时防御（如提示注入检测）无法识别权重层面的后门行为，而 Back-Reveal 通过语义触发器和隐式诱导重写，证明了攻击者可在不修改工具接口、不显式违反内容过滤规则的情况下，实现多轮累积式数据窃取。实验表明，该攻击在开放权重模型和宽松连接器配置下，ASR 超过 94%，重排序绕过率高达 88.6%，且对模型通用性能影响小于 1%。然而，其有效性高度依赖用户部署被后门化模型且连接器允许任意出站请求，这在严格权限隔离的企业环境中可能受限。当连接器实施严格的域名白名单或出站请求审计时，该攻击的可行性是否会显著降低，论文未提供相关实验数据。
