# ACL-Findings2026最新论文 ｜Debate to Align: Reliable Entity Alignment through Two-Stage Multi-Agent Debate ｜基于两阶段多智能体辩论的可靠实体对齐框架

作者：Cunda Wang、Ziying Ma、Po Hu 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_60121fdb2f97)

> 实体对齐（Entity Alignment, EA）旨在识别不同知识图谱（KG）中指向同一现实世界对象的实体，其核心难点在于跨库异构性导致的语义歧义。现有基于大语言模型（LLM）的方法虽提升了语义理解能力，但受限于单次推理的不可逆性与候选检索的上限约束，难以在复杂歧义场景下保证决策可靠性。AgentEA 通过引入直接偏好优化（DPO）增强嵌入判别力，并设计轻量级辩论验证与深度辩论对齐的两阶段多智能体机制，实现了决策透明化与效率平衡。该框架在跨语言基准上达到了 SOTA 水平，但其对闭源模型的依赖及辩论轮次的固定设置，限制了其在零样本泛化场景下的适用性评估。

## 研究背景

实体对齐任务通常分解为候选生成与重排序两个阶段，其中候选生成决定召回率上限，重排序决定精度上限。在 LLM 时代，重排序阶段的语义理解能力成为瓶颈，但 LLM 的黑盒性与高昂计算成本引发了新的研究焦点。传统知识表示学习（KRL）方法通过低维向量空间建模实体关系，但受限于种子数据依赖及深层语义捕捉不足，难以区分语义相似但非对齐的实体。随着 LLM 的引入，领域范式从“嵌入相似度计算”转向“基于推理与生成的决策”，显著提升了复杂歧义场景下的性能。然而，LLM 的黑盒性导致错误难以定位，且 Token 消耗巨大，如何在保持推理优势的同时实现可解释性与效率平衡，成为当前研究的核心挑战。

现有 LLM-based EA 方法通常依赖单次、无挑战的推理轨迹，缺乏对替代假设或反证的支持，导致模型在证据不完整或误导时无法修正结论，产生系统性失败。此外，基于启发式阈值构建的不确定实体集（AES）不可靠，不稳定的相似度分布可能将真正歧义的实体排除在推理之外，或保留错误的对齐结果。AgentEA 的切入点在于联合优化实体嵌入质量与引入结构化多智能体推理，通过显式的辩论机制解决单模型推理的不稳定性，同时通过两阶段设计平衡计算效率与决策可靠性。

## 核心方法

### 方法参照系

AgentEA 遵循“KRL 生成候选集 + LLM 重排序”的标准流程，但针对候选检索质量与 LLM 推理稳定性两个关键瓶颈进行了改造。与 ChatEA 等单次推理方法不同，AgentEA 将 LLM 角色从单一决策者扩展为多智能体辩论群体，并通过 DPO 微调嵌入模型以提升候选集质量。

### 实体表示偏好优化

传统 KRL 方法依赖结构驱动表示学习，在语义歧义场景下判别力不足。AgentEA 引入实体表示偏好优化模块，通过 DPO 微调 LLaMA3-8B-Instruct 编码器，提升嵌入的判别能力。训练语料由种子实体对、名称相似度负样本和度数感知邻域负样本构成。名称相似度负样本通过计算实体名称的余弦相似度，选取名称最相似但非真实对齐的实体作为负例，解决跨语言对齐中因名称相似导致的误匹配问题。度数感知邻域负样本则选取邻域中度数最高的实体作为负例，缓解高复杂度结构上下文引入的噪声。该设计动机在于，硬负样本能迫使模型学习更细粒度的语义区分，从而提升候选检索的 Hit@20 性能，突破 LLM 推理的上限约束。

$$
e_{i}^{N-} = \arg \max_{e_j \neq e_i^+} \cos(h_i^{name}, h_j^{name})
$$

该公式定义了名称相似度负样本的选取策略，即对于源实体 $e_i$，选取与其名称余弦相似度最高但非真实对齐实体 $e_i^+$ 的实体 $e_j$ 作为负样本，以增强模型对易混淆实体的区分能力。

### 两阶段多智能体辩论对齐

单次 LLM 推理缺乏对反证的处理能力，导致决策不可逆。AgentEA 设计了两阶段多智能体辩论机制：轻量级辩论验证（LDV）与深度辩论对齐（DDA）。LDV 阶段采用单轮辩论，由支持者、反对者和裁判三个智能体组成，通过频率策略压缩实体信息至原 Token 的 15% 以下，快速筛选出存在分歧或低置信度的实体对。DDA 阶段针对 LDV 筛选出的困难案例，引入六个智能体进行多轮辩论，包括属性、别名、邻域、类型四个专业智能体，以及攻击者和裁判智能体。攻击者智能体通过识别冲突证据对高风险候选施加细粒度惩罚，裁判智能体聚合证据并决定是否扩展候选集或终止辩论。该设计动机在于，通过角色异构性增强观点多样性，通过多轮交互实现错误修正，从而提升决策的可靠性与可解释性。

$$
(gap(e_i) > \delta_1 \lor v_{agree} > 0.5) \land A_{judge,v} = True \lor round = n
$$

该公式定义了辩论的终止条件，当 Top-1 与 Top-2 候选的相似度差距超过阈值 $\delta_1$，或支持对齐的投票比例 $v_{agree}$ 超过 0.5 且裁判智能体确认时，辩论提前终止；否则强制终止于最大轮次 $n$，以平衡效率与可靠性。

## 实验评估

AgentEA 在 DBP15K、ICEWS、DWY 和 SRPRS 等 11 个基准数据集上进行了评估，基线涵盖 KRL 方法（如 MTransE, BootEA, SCMEA）和 LLM 方法（如 ChatEA, ProLEA, EasyEA）。实验设置中，嵌入阶段使用 LLaMA3-8B-Instruct 进行 DPO 微调，辩论阶段使用 gpt-3.5-turbo 作为骨干模型，最大辩论轮次设为 3。

| 方法 | DBP15K-ZH-EN Hits@1 | DBP15K-JA-EN Hits@1 | DBP15K-FR-EN Hits@1 |
| --- | --- | --- | --- |
| ChatEA | 0.951 | 0.972 | 0.990 |
| ProLEA | - | - | 0.993 |
| AgentEA | 0.970 | 0.984 | 0.996 |

AgentEA 在 DBP15K-FR-EN 上以 0.996 的 Hits@1 超越 ProLEA 的 0.993，但在 ZH-EN 和 JA-EN 上低于 ProLEA 的 0.99（据领域综述），表明其泛化能力可能受限于 DPO 训练数据仅包含 FR-EN 子集。

| 设置 | DBP15K-FR-EN Hits@1 | DBP15K-FR-EN MRR |
| --- | --- | --- |
| AgentEA | 0.996 | 0.998 |
| w/o DPO | 0.859 | 0.889 |
| w/o Debate | 0.976 | 0.986 |
| w/o LDV | 0.995 | 0.996 |
| w/o DDA | 0.986 | 0.991 |

消融实验显示，移除 DPO 导致性能大幅下降（0.859 vs 0.996），验证了嵌入优化对候选检索质量的关键作用。移除 DDA 导致性能显著下降（0.986 vs 0.996），表明深度辩论是性能增益的主要来源，而移除 LDV 仅导致轻微性能变化但显著增加推理时间，说明 LDV 在效率优化中起关键作用。

评估边界方面，实验未报告置信区间，数值比较需谨慎。使用闭源模型 gpt-3.5-turbo 作为辩论骨干，可能限制方法的可复现性与开源社区采纳。代码已开源，但超参数（如 $\delta_1=0.05$, $\delta_2=0.5$）的敏感性分析未充分展开，辩论轮次固定为 3 是否最优，论文未给出回答。

## 关联研究分析

从问题动机看，AgentEA 与 ProLEA 均关注 LLM 决策的可靠性，但 ProLEA 将 LLM 作为验证器，通过阈值机制解决 LLM 预测与嵌入模块候选之间的冲突，而 AgentEA 通过多智能体辩论实现显式的反证处理与错误修正。ProLEA 的验证器角色仍依赖单一 LLM 的判断，而 AgentEA 的辩论机制通过角色异构性增强观点多样性，解决了单模型在语义相似但非对齐实体上的混淆问题。这一差异源于任务特性：ProLEA 侧重于异构 KG 的泛化能力，而 AgentEA 侧重于复杂歧义场景下的决策稳定性。

从方法设计看，AgentEA 与 ChatEA 均利用 LLM 的语义理解能力，但 ChatEA 采用单次推理，缺乏对替代假设的支持，而 AgentEA 引入两阶段辩论机制，通过 LDV 快速筛选困难案例，DDA 进行精细区分。ChatEA 的黑盒性导致错误难以定位，而 AgentEA 的辩论路径提供了透明化决策，提升了可解释性。这一差异源于方法设计：ChatEA 追求效率，而 AgentEA 追求可靠性与效率的平衡。AgentEA 的 LDV 阶段通过 Token 压缩降低计算成本，但 15% 的压缩率是否导致关键语义丢失，论文未给出回答。

## 总结

AgentEA 要解决的核心矛盾是 LLM 单次推理的不可逆性与候选检索上限约束导致的决策不可靠性。其切入点在于联合优化嵌入质量与引入结构化多智能体辩论，通过 DPO 提升候选检索的 Hit@20 性能，通过两阶段辩论实现决策透明化与效率平衡。实验证明，AgentEA 在 DBP15K-FR-EN 上达到 0.996 的 Hits@1，超越 ProLEA 的 0.993，验证了辩论机制的有效性。然而，其边界在于对闭源模型的依赖及辩论轮次的固定设置，限制了在零样本泛化场景下的适用性评估。当支持集增大到 5-shot 时，辩论机制的边际收益是否递减，论文未给出回答。
