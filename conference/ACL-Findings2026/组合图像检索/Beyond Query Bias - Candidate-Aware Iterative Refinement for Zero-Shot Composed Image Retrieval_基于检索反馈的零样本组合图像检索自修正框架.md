# ACL-Findings2026最新论文 ｜Beyond Query Bias: Candidate-Aware Iterative Refinement for Zero-Shot Composed Image Retrieval ｜基于检索反馈的零样本组合图像检索自修正框架

研究机构：华中科技大学、阿里巴巴集团

作者：Nan Sun、Jing Tang、Lei Sun 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_b942bea1a63e)

> 零样本组合图像检索（Zero-Shot Composed Image Retrieval, ZS-CIR）旨在通过参考图像与修改文本检索目标图像，但现有方法在生成查询时因无法感知候选分布而陷入“认知偏差”，导致语义合理的查询与真实目标错位。本文提出 CoRR 框架，将检索过程重构为“检索-反思-修正”的迭代闭环，利用多模态大语言模型（Multimodal Large Language Model, MLLM）分析检索反馈以修正查询偏差。该方法通过历史查询融合与检索驱动字幕优化稳定迭代过程，在 CIRCO 基准上取得领先性能，但其对 MLLM 推理能力的依赖及在细粒度属性修改任务上的表现仍存疑。

## 研究背景

组合图像检索的核心挑战在于跨模态语义的“编辑”而非简单匹配。模型需在保留参考图像视觉锚点的同时，精准应用文本指令的语义约束。传统监督方法依赖昂贵的三元组标注，泛化能力受限；随着视觉-语言预训练模型的成熟，研究转向零样本范式，利用预训练模型的语义对齐能力消除标注依赖。然而，零样本方法中简单的特征拼接或线性插值往往引入参考图像中的无关背景噪声，稀释修改文本的意图，导致检索精度下降。

主流零样本方法分为文本反转与生成式语义重构两条路线。文本反转方法如 Pic2Word 将图像映射为伪词元，计算高效但丢失细粒度视觉细节；生成式方法如 CIReVL 利用大语言模型生成目标描述，语义完整但存在视觉一致性不足及“盲猜”问题。现有生成式方法在查询生成阶段缺乏对候选分布的感知，生成的查询虽语义合理，却可能因词汇风格或粒度与嵌入模型偏好不匹配而检索失败。CoRR 的切入点在于将检索结果作为反馈信号，使 MLLM 具备“候选分布感知”能力，从而动态修正查询中的偏差约束。

## 核心方法

### 方法参照系

CoRR 属于生成式语义重构路线，其基础流程为：利用嵌入模型将参考图像与修改文本映射为初始查询向量，检索候选集，再由 MLLM 生成目标描述并重新编码检索。与 CIReVL 等单向生成方法的关键差异在于，CoRR 引入了基于检索反馈的迭代修正机制，将静态的查询生成转化为动态的自修正过程。

### 基于 MLLM 的检索反馈自反思

MLLM 引导的自反思模块位于迭代循环的核心，解决了单向生成方法无法感知候选分布导致的查询漂移问题。在每一轮迭代中，MLLM 接收参考图像、修改文本、上一轮检索的 Top-K 图像及其优化字幕，执行链式思维（Chain-of-Thought, CoT）推理。推理过程包含理解用户意图、分析检索结果共性、反思问题（如缺失特定属性或过度限制）以及制定生成策略。MLLM 据此生成修正后的文本查询 $T'_t$，该查询旨在保留关键视觉元素并修正偏差约束。这一机制使模型能够根据实际检索反馈调整查询粒度，而非盲目依赖初始语义猜测。

### 基于 Slerp 的历史查询融合

直接采用 MLLM 生成的新查询向量可能导致过度修正或噪声引入，造成查询在嵌入空间中不稳定漂移。CoRR 引入基于球面线性插值（Spherical Linear Interpolation, Slerp）的历史查询融合机制，在表示层面平滑更新查询向量。设 $u_t = \Psi_T(T'_t)$ 为新查询向量，$v_{t-1}$ 为上一轮查询向量，则当前查询向量 $v_t$ 计算为：

$$
v_t \leftarrow \text{Slerp}(u_t, v_{t-1}; \alpha) = \frac{\sin((1-\alpha)\theta)}{\sin(\theta)} u_t + \frac{\sin(\alpha\theta)}{\sin(\theta)} v_{t-1}
$$

其中 $\theta = \arccos(u_t \cdot v_{t-1})$ 为两向量夹角，$\alpha \in [0, 1]$ 为控制历史与新证据权重的超参数（默认 0.8）。该公式在单位超球面上进行插值，确保查询向量在迭代过程中保持平滑轨迹，避免破坏性漂移，同时保留前序查询中的有效信息。

### 检索驱动字幕优化

MLLM 生成的文本风格与嵌入模型偏好常存在不匹配，导致检索效率低下。CoRR 提出检索驱动字幕优化策略，离线预计算与嵌入空间对齐的字幕作为 MLLM 的上下文示例。对于数据库中的每张图像 $I$，利用 BLIP-2 生成 $M$ 个候选字幕 $\{C_i\}$，通过自检索验证选择最优字幕 $C^*(I)$。排序依据为：首先按使用 $C_i$ 作为查询时图像 $I$ 的检索排名 $r_i$ 升序，其次按 $C_i$ 与 $I$ 的相似度 $s_i$ 降序：

$$
(r_i, s_i) < (r_j, s_j) \iff (r_i < r_j) \lor (r_i = r_j \land s_i > s_j)
$$

该过程完全离线，不增加推理延迟。通过提供与嵌入模型偏好对齐的字幕示例，MLLM 能学习更简洁、通用的词汇风格，生成更具可检索性的查询，从而缓解语言-嵌入不匹配带来的偏差。

## 实验评估

实验在 CIRR、CIRCO、FashionIQ 和 GeneCIS 四个基准上进行，对比基线涵盖文本反转（SEARLE, Pic2Word）与生成式（CIReVL, OSrCIR, MMRet）方法。CoRR 以 MMRet-Large 为骨干，在 CIRCO 上 mAP@5 达 42.70%，较基线 MMRet-Large 的 40.20% 提升 2.5 个点；在 CIRR 上 Recall@1 达 43.21%，较基线 37.95% 提升 5.26 个点。

| 方法 | CIRCO mAP@5 | CIRR Recall@1 | FashionIQ Avg R@10 |
| :--- | :--- | :--- | :--- |
| MMRet-Large (基线) | 40.20 | 37.95 | 34.65 |
| CoRR (Ours+MMRet-Large) | 42.70 | 43.21 | 39.67 |
| ∆ (CoRR vs 基线) | +2.50 | +5.26 | +5.02 |

消融实验揭示了各组件的贡献。在 CIRCO 上，仅加入反思（+ reflection）导致性能下降至 36.66，表明直接替换查询引发漂移；加入历史查询融合（+ query fusion）后性能升至 40.82，验证了 Slerp 的稳定化作用；进一步加入优化字幕（+ optimized caption）后达到 42.77，说明字幕对齐对细粒度检索至关重要。在 FashionIQ 上，优化字幕带来 R@10 从 36.26 到 36.70 的提升，幅度较小，暗示该策略在通用场景下收益更显著。

评估边界方面，CoRR 未与 2026 年最新 SOTA 方法 WISER 和 G-MIXER 直接对比，后者在 CIRR 上 Recall@1 达 55.2，显著高于 CoRR 的 43.21。CoRR 依赖 Qwen-VL-Max 进行推理，计算开销随迭代轮次线性增长，论文未报告具体延迟数据。代码未公开，但提供了详细的超参数设置（Top-K=5, Top-N=10, α=0.8），可复现性中等。

## 关联研究分析

从问题动机看，CoRR 与 CIReVL 同属生成式路线，但 CIReVL 将 CIR 重构为文本到图像检索，依赖 LLM 生成丰富描述，却未考虑候选分布的反馈。CoRR 的核心差异在于引入“检索反馈”作为 MLLM 的输入，将查询生成从开环变为闭环。这一设计源于对“盲猜”失效模式的洞察：语义合理的查询可能因风格不匹配而检索失败，而反馈机制使模型能感知“哪些约束导致检索失败”，从而进行针对性修正。CIReVL 的单向生成在候选分布复杂时易陷入局部最优，CoRR 的迭代修正则具备全局搜索潜力。

从方法设计看，CoRR 与 OSrCIR 同属多模态增强路线，但 OSrCIR 侧重于多模态特征的静态融合，而 CoRR 侧重于查询的动态演化。CoRR 引入 Slerp 融合机制，解决了 MLLM 反思可能带来的查询漂移问题，这是 OSrCIR 等静态方法未涉及的动态稳定性问题。CoRR 的 Slerp 插值借鉴了球面几何特性，确保查询向量在单位超球面上平滑移动，避免了线性插值在嵌入空间中的非欧几里得失真。这一设计选择源于对嵌入模型几何特性的理解，而非简单的工程优化。

## 总结

CoRR 旨在解决零样本组合图像检索中查询生成因缺乏候选分布感知导致的认知偏差问题。现有生成式方法如 CIReVL 依赖单向语义猜测，无法感知检索反馈，导致查询与目标错位。CoRR 通过引入 MLLM 引导的自反思、Slerp 历史查询融合及检索驱动字幕优化，将检索过程重构为迭代自修正闭环，在 CIRCO 上 mAP@5 达 42.70，CIRR 上 Recall@1 达 43.21，较基线显著提升。然而，CoRR 的性能高度依赖 MLLM 的推理能力，且在 FashionIQ 等细粒度属性修改任务上提升幅度有限，表明其对复杂视觉细节的捕捉能力仍受限于 MLLM 的视觉理解精度。当候选分布极度稀疏或查询意图高度模糊时，迭代修正是否仍能收敛至正确目标，论文未给出回答。
