# 基于大语言模型多智能体的情感极化模拟平台

作者：Stephanie Anneris Malvicini、Ewelina Gajewska、Arda Derbent 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.02711)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.02711)

> 情感极化研究长期受限于真实数据标注成本高与静态快照无法捕捉动态交互的矛盾，导致现有模型难以复现群体间情感对立的演化机制。本文切入点在于构建一个基于大语言模型（Large Language Model, LLM）的多智能体框架，通过自然语言对话模拟个体在内群体与外群体间的情感迁移。该方法利用角色设定与前后测问卷量化极化程度，为计算社会科学提供了可复现的测试床。其价值在于实现了极化度量的标准化与场景灵活性，但缺乏与真实人类实验的统计等价性验证及主动干预模块。

## 研究背景

情感极化（Affective Polarization）指个体对所属政治群体产生积极情感、对对立群体产生消极情感的心理倾向。在社交媒体语境下，这种倾向并非静态属性，而是通过高频交互动态演化的结果。传统研究依赖问卷调查或静态网络快照，虽能捕捉极化的截面状态，却无法解析交互过程中的情感传染机制。为突破这一局限，研究者引入基于智能体的建模（Agent-Based Modeling, ABM），试图在微观层面模拟个体决策，但在早期数值模型中，个体交互被简化为线性代数运算，丢失了自然语言中的语义细微差别与情感色彩。

主流路线分为数值模型驱动与数据驱动两类。数值模型如 Friedkin-Johnsen (FJ) 模型依赖线性假设，虽具备解析优雅性，但无法处理非线性认知转移；数据驱动方法依赖大规模标注数据，却面临标注成本高与主观偏差的瓶颈。随着 LLM 的兴起，认知驱动路线成为新焦点，如 Social Simulation Framework (SSF) 等框架尝试用 LLM 智能体复现回声室效应。然而，现有 LLM 模拟框架多聚焦于观点演化或大规模网络拓扑，缺乏针对“情感极化”这一特定社会心理现象的标准化测量协议与细粒度情感变量提取机制。本文旨在填补这一空白，提供一个专门用于研究情感极化动态的模块化平台。

## 核心方法

### 多智能体交互架构

本文方法参照系为标准的 LLM 多智能体模拟流程，即通过预设角色与提示词驱动 LLM 生成对话。关键差异在于，本文引入了显式的“情感变量”测量机制，将抽象的社会心理概念转化为可计算的数值指标，而非仅依赖文本输出的定性分析。

### 情感变量量化机制

设计动机在于解决 LLM 智能体缺乏显式可观测心理状态的问题，传统方法难以直接量化“喜爱”与“仇恨”的强度。本文定义了一组情感变量，包括对共和党与民主党的喜爱（Love）与仇恨（Hate），取值范围为 0-10。极化程度通过内群体喜爱与外群体仇恨之和来度量。具体公式定义为：

$$ P_i = L_{in, i} + H_{out, i} $$

其中 $L_{in, i}$ 为智能体 $i$ 对其内群体的喜爱值，$H_{out, i}$ 为对外群体的仇恨值。若 $L_{in, i} \ge 5$ 且高于其他群体，则定义该群体为内群体；若 $L_{out, j} < 5$ 且存在其他内群体，则 $j$ 为外群体。该公式将模糊的情感倾向转化为离散阈值判断，使得极化状态（Polarized）、非党派（Non-partisan）与极端分子（Extremist）等类型可被自动识别。

### 动态记忆与交互协议

设计动机在于确保对话的连贯性与上下文依赖性，避免 LLM 因上下文窗口限制导致的记忆丢失。本文采用字典结构存储记忆，键为对话 ID，保留完整讨论历史。交互协议采用轮询（Round Robin）算法，确保每个智能体按序发言。情感变量的更新通过前后测问卷实现：对话前建立基线，对话后由 LLM 根据记忆中的交互内容重新评估情感值。这种“外部探测”机制模拟了人类研究中通过行为或问卷推断内部状态的方法，解决了 LLM 无法直接输出心理状态数值的局限。

## 实验评估

实验设置基于 Persona-Hub 数据集生成角色，使用 Gemini Flash 2.0 作为底层 LLM。基线审计显示，本文未对比传统机器学习极化检测模型或数值动力学模型，仅通过内部消融（不同党派比例、不同话题）验证平台有效性。

| 实验场景 | 变量 | 变化幅度 | 备注 |
| :--- | :--- | :--- | :--- |
| 实验1：非党派观察 | 对共和党喜爱 | +3.08 | 50次模拟平均 |
| 实验1：非党派观察 | 对民主党仇恨 | +1.74 | 50次模拟平均 |
| 实验2：民主党参与 | 对共和党喜爱 | +2.68 | 加入3名民主党智能体 |
| 实验2：民主党参与 | 对民主党仇恨 | +1.64 | 加入3名民主党智能体 |

核心数字对比表明，当引入对立党派智能体时，非党派观察者的情感极化幅度减小（如喜爱共和党从 +3.08 降至 +2.68），验证了平台能捕捉群体构成对极化动态的影响。实验1中 64% 的非党派者转为共和党认同，展示了模拟的极化效应强度。

消融分析显示，话题类型（政治 vs 非政治）对极化影响有限，民主党在非政治话题中对外群体温暖度的提升（中位数 +5）与政治话题（中位数 +5）相似，暗示 LLM 智能体在情感反应上可能缺乏对话题敏感性的精细区分。

评估边界方面，本文缺乏与真实人类实验数据的定量对标，无法证明 LLM 模拟的情感变化幅度与人类具有统计等价性。可复现性良好，提供了完整代码与用户指南，但未报告计算成本与 LLM 调用延迟，限制了其在大规模实时应用中的评估。

## 关联研究分析

从问题动机看，本文与 MTOS（Multi-Topic Opinion Simulation）同属 LLM 多智能体模拟路线，但 MTOS 侧重多主题观点演化，本文聚焦情感极化的量化测量。差异根源在于任务特性：观点演化关注内容语义，情感极化关注群体间情感对立。本文未探索观点如何转化为情感，导致其模拟的情感变化可能缺乏内容层面的因果支撑，仅是基于角色设定的情感惯性。

从方法设计看，本文与 EvoCorps 形成“观测 vs 干预”对比。EvoCorps 包含主动去极化干预模块，而本文仅作为模拟测试床。这种差异暗示本文平台可作为 EvoCorps 等干预算法的验证环境，但当前缺乏接口支持。此外，本文未使用时序图神经网络（TGNN）捕捉长程结构依赖，仅依赖 LLM 上下文记忆，这可能忽略社交网络中跨群组的情感传染路径，导致模拟的极化动态局限于局部对话而非全局网络效应。

## 总结

本文核心矛盾在于情感极化的动态性难以通过静态数据捕捉，且 LLM 模拟缺乏标准化度量。切入点在于将社会心理学中的情感变量操作化为 LLM 可计算的数值指标，通过前后测问卷实现量化。方法上构建了基于记忆与轮询协议的多智能体框架，证明了平台能模拟非党派者的极化转变（64% 转为共和党认同）及群体构成对极化幅度的调节作用。边界在于缺乏与真实人类实验的统计等价性验证，且未包含主动干预模块，仅作为观测工具。当 LLM 智能体的情感反应缺乏内容语义的因果驱动时，其模拟的极化动态是否仅反映了角色设定的刻板印象，而非真实的认知演化机制，论文未给出回答。
