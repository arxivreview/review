# ICML2026最新论文 ｜PATHWAYS: Evaluating Investigation and Context Discovery in AI Web Agents ｜调查能力评估基准

作者：Shifat E. Arman、Syed Nazmus Sakib、Tapodhir Karmakar Taton 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.05354)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.05354)

> 现有 Web 智能体基准主要考察指令执行或恶意拒绝，忽略了真实场景中智能体需主动挖掘隐藏证据以做出正确决策的“调查能力”。当前模型在信息不对称环境下普遍存在导航与证据获取脱节、表面线索误导下决策崩溃及虚构调查过程等系统性缺陷。本文构建包含 250 个多步决策任务的 PATHWAYS 基准，通过强制过程依赖指标量化智能体在电商客服与社区审核中的调查、推理与决策全轨迹。该工作揭示了现有智能体作为“模式匹配器”而非“审慎调查者”的本质局限，但其评估结果高度依赖任务设计中的信息不对称强度，且未提供解决该缺陷的架构方案。

## 研究背景

Web 智能体在真实部署中面临的核心困境是信息不对称：表面可见的元数据往往具有误导性，而决定性证据隐藏于二级页面或内部日志中。这种结构要求智能体具备主动探索与证据整合能力，即从“执行指令”转向“验证前提”。若智能体仅依赖即时可见文本进行决策，将导致高置信度的错误判断，例如将合理的退款请求误判为欺诈，或忽视隐蔽的协同攻击行为。

主流评估路线存在两极分化：功能基准如 WebArena 和 Mind2Web 假设关键信息立即可见，仅测试指令到动作的映射能力；安全基准如 SafeArena 和 AgentHarm 则聚焦于智能体对恶意指令的拒绝能力。这两类基准均无法捕捉“能力错位”（competence misalignment）现象，即智能体意图正确但因调查不足导致有害结果。PATHWAYS 的切入点在于隔离“调查能力”这一中间维度，通过工程化设计隐藏上下文与表面矛盾，强制智能体在信息不充分状态下进行主动检索，从而暴露其在证据获取与认知不确定性处理上的架构缺陷。

## 核心方法

### 任务结构与信息分层

PATHWAYS 基于 WebArena 环境构建，但改变了任务的信息分布结构。标准 Web 任务通常将关键信息置于首屏或浅层 DOM 节点，而 PATHWAYS 将任务划分为“表面上下文”（Surface Context）与“隐藏上下文”（Hidden Context）两层。表面上下文包含具有误导性的元数据（如高退款率用户），隐藏上下文则包含决定性证据（如履约错误日志），仅可通过访问特定 URL 或执行滚动、点击等交互动作获取。每个任务定义了“关键集”（CriticalSet），即支持正确决策所需的最小证据 URL 集合。这种设计将评估焦点从“能否到达页面”转移至“能否提取并整合隐藏证据”，解决了传统基准中信息可见性假设导致的评估盲区。

### 过程依赖评估指标

传统基准仅评估最终决策的正确性，允许智能体通过猜测或幻觉获得高分。PATHWAYS 引入“严格成功概率”（Proven Success Rate, $P_{success}$），强制要求调查、推理、决策三个环节全部正确才计为成功。该指标定义为：

$$ P_{success} = \mathbb{E} \left[ \mathbb{1}(\text{Investigation} \land \text{Reasoning} \land \text{Decision}) \right] $$

其中，调查正确性由智能体是否访问 CriticalSet 中的 URL 决定，推理正确性由内部独白是否包含关键事实决定，决策正确性由最终动作与最优动作的匹配度决定。这一设计消除了“垃圾进，垃圾出”（garbage in, garbage out）的假阳性，即智能体可能在推理阶段表现良好，但因未获取关键证据而导致决策错误。此外，引入“调查效率”（$E_{inv}$）以时间折扣因子 $\gamma$ 惩罚延迟发现，确保智能体不仅找到证据，且以高效路径找到证据，区分了“盲目浏览”与“定向检索”两种行为模式。

### 对抗性鲁棒性测试

在基础调查能力评估之外，PATHWAYS 引入了动态交互测试，模拟真实场景中的用户申诉。该模块在智能体做出初始决策后，注入欺骗性申诉（诱导错误）或有效纠正（修复错误），测量“谄媚率”（Sycophancy Rate）与“纠正率”（Correction Rate）。谄媚率定义为智能体在初始正确决策后，因欺骗性申诉而翻转为错误决策的比例；纠正率定义为智能体在初始错误决策后，因有效纠正而翻转为正确决策的比例。这一设计揭示了智能体在动态证据更新下的认知稳定性，特别是其抵抗社会操纵与接受新证据的能力差异，弥补了静态基准无法评估智能体在交互过程中信念更新机制的不足。

## 实验评估

实验在 Shopping Admin（电商客服）与 Reddit Moderation（社区审核）两个领域进行，评估了 Gemini、GPT-4o、Qwen-235B 等 7 个前沿模型。基线覆盖闭源与开源模型，但缺乏专用 Web 智能体架构（如 Branch-and-Browse）的对比，限制了与当前 SOTA 架构的直接性能比较。

| 模型 | 领域 | 调查准确率 (%) | 推理准确率 (%) | 决策准确率 (%) | 严格成功概率 (%) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Gemini | Shopping Admin | 36.9 | 64.2 | 56.6 | 13.4 |
| GPT-4o | Shopping Admin | 29.8 | 61.7 | 64.6 | 11.9 |
| Qwen-235B | Shopping Admin | 39.0 | 60.2 | 64.2 | 15.1 |
| Gemini | Reddit | 34.8 | 69.5 | 35.4 | 8.6 |
| GPT-4o | Reddit | 39.9 | 59.4 | 44.4 | 10.5 |
| Qwen-235B | Reddit | 16.5 | 66.5 | 41.7 | 4.6 |

数据显示，所有模型的调查准确率均低于 40%，而推理准确率普遍高于 60%，证实了“导航-发现差距”的存在：智能体擅长处理已获取的信息，但难以主动获取关键证据。严格成功概率远低于决策准确率，表明大量正确决策源于猜测或幻觉，而非扎实的证据链。

消融实验揭示了“购物悖论”：在 Shopping Admin 域，提供显式提示（Hint）使 Gemini、GPT-4o 和 Qwen-235B 的调查准确率提升约 38%，但决策准确率反而下降（Gemini 下降 16.0%）。这表明当智能体被迫面对复杂、细微的证据时，其将证据映射到刚性行政政策的能力不足，导致“发现越多，错误越多”。在 Reddit 域，提示对调查准确率的提升较小（GPT-4o 提升 20.5%），但决策准确率变化不一，显示不同领域对提示工程的响应存在显著差异。

评估边界方面，PATHWAYS 未提供代码开源链接，且任务集为人工构建的 250 个样本，规模较小，可能限制统计显著性。此外，评估依赖 LLM 生成的干扰项，其分布偏差可能影响结果泛化性。严格成功概率指标虽严谨，但可能过度惩罚合理捷径，如智能体通过非标准路径获取等效证据的情况未被明确界定。

## 关联研究分析

从问题动机看，PATHWAYS 与 WebArena 等标准基准的根本差异在于信息可见性假设。WebArena 假设任务关键信息在初始状态或浅层交互中可见，评估重点在于动作序列的规划与执行；而 PATHWAYS 刻意制造信息不对称，将评估重点转移至证据获取的主动性。这一差异源于任务特性的不同：标准基准模拟“执行已知任务”，而 PATHWAYS 模拟“解决未知问题”。然而，PATHWAYS 未探索信息不对称程度对性能的影响梯度，即当隐藏证据的检索深度从 2 步增加到 5 步时，智能体性能是否呈线性下降，这一盲区限制了其对智能体探索能力边界的精确刻画。

从方法设计看，PATHWAYS 与 SafeArena 等安全基准的区别在于防御对象的性质。SafeArena 测试智能体对显式恶意指令的拒绝能力，属于“意图对齐”问题；而 PATHWAYS 测试智能体在信息不足下的决策正确性，属于“能力错位”问题。SafeArena 的防御机制依赖模型对齐与提示工程，而 PATHWAYS 揭示的缺陷源于架构层面的证据整合能力缺失，无法通过简单的安全提示解决。值得注意的是，PATHWAYS 中的“调查性幻觉”现象与 SafeArena 中的“越狱”行为有本质区别：前者是认知过程中的证据虚构，后者是安全边界的行为突破。PATHWAYS 未提供针对调查性幻觉的防御机制，仅将其作为评估指标，这使得其在解决该问题上的贡献局限于诊断而非治疗。

## 总结

PATHWAYS 旨在解决 Web 智能体在信息不对称环境下“调查能力”缺失的核心矛盾，现有基准因假设信息可见或聚焦安全拒绝而无法捕捉这一维度。本文通过构建包含隐藏上下文与表面矛盾的任务集，并引入过程依赖的严格成功概率指标，量化了智能体在证据获取、推理整合与决策执行全轨迹中的系统性失效。实验表明，前沿模型的调查准确率普遍低于 40%，且存在“发现证据但决策错误”的悖论，揭示了当前智能体作为“模式匹配器”而非“审慎调查者”的本质局限。本文的边界在于其评估结果高度依赖人工构建的信息不对称结构，且未提供解决调查性幻觉与矛盾崩溃的架构方案。当隐藏证据的检索路径从线性扩展为树状结构时，智能体的调查效率与决策准确率是否呈现非线性衰减，论文未给出回答。
