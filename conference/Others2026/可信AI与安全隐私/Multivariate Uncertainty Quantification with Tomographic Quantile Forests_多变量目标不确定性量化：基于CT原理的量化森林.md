# 多变量目标不确定性量化：基于CT原理的量化森林

作者：Takuya Kanazawa

论文原文见 [arXiv](https://arxiv.org/abs/2512.16383)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.16383)

> 多变量回归任务中，传统方法常假设各目标分量独立，导致联合分布估计失效，无法捕捉变量间依赖关系。现有非参数方法要么受限于凸区域假设，要么计算成本过高，难以在表格数据上高效应用。本文提出Tomographic Quantile Forests (TQF)，利用Cramér-Wold定理将多变量分布重建转化为方向投影的量化回归问题，通过切片Wasserstein距离优化实现非参数联合分布估计。该方法在表格数据上实现了与参数化模型相当的非参数分布估计能力，但其对高维输入空间的扩展性及与保形预测的结合尚存疑问。

## 研究背景

当预测目标为多维向量 $\mathbf{y} \in \mathbb{R}^d$ 时，直接建模联合条件分布 $p(\mathbf{y}|\mathbf{x})$ 面临维度灾难与多模态挑战。若采用边际独立假设 $p(\mathbf{y}|\mathbf{x}) = \prod_i p(y_i|\mathbf{x})$，虽简化了计算，却完全丢失了变量间的相关性结构，这在气象、金融等强耦合场景中会导致严重的决策风险。为克服此局限，研究者需构建能捕捉联合依赖的非参数框架，但传统方向量化方法通常仅生成凸量化区域，无法表达环形或分离的多模态支撑集。

不确定性量化（Uncertainty Quantification, UQ）在表格数据领域长期依赖梯度提升机或随机森林，因其计算效率优于深度神经网络。然而，现有树基方法如Quantile Regression Forests (QRF) 仅针对单变量目标，多变量扩展往往依赖独立建模或高斯混合假设，前者忽略相关性，后者难以拟合复杂分布。本文切入点在于利用计算机断层扫描（CT）原理，即Cramér-Wold定理，指出多维分布由其一维投影唯一确定，从而将多变量UQ转化为多个一维量化回归问题，避免了直接拟合高维密度的困难。

## 核心方法

### 方法参照系

标准多变量UQ流程通常直接拟合联合分布或独立边际分布。本文的关键差异在于不直接估计 $p(\mathbf{y}|\mathbf{x})$，而是先估计方向投影 $\mathbf{n}^\top \mathbf{y}$ 的条件量化，再通过优化重建联合分布。这一两阶段策略解耦了“学习投影分布”与“重建联合结构”两个子问题，使得树模型可以专注于其擅长的一维量化回归任务。

### 投影增强与量化学习

设计动机在于解决方向向量 $\mathbf{n}$ 作为输入特征时，决策树因边界效应导致的分区低效问题。传统做法将 $\mathbf{x}$ 与 $\mathbf{n}$ 简单拼接，但树模型对连续特征的分段线性特性难以捕捉 $\mathbf{n}$ 的旋转对称性。TQF引入投影增强（Projective Augmentation），对每个训练样本，采样 $G$ 个单位向量 $\mathbf{n}_g$，并随机生成 $G_a$ 个正交矩阵 $\mathbf{O}_k$，将旋转后的向量 $\mathbf{O}_k \mathbf{n}_g$ 作为额外特征拼接至输入。

$$
\mathbf{z}_g = \mathbf{x} \parallel \mathbf{n}_g \parallel \mathbf{O}_1 \mathbf{n}_g \parallel \cdots \parallel \mathbf{O}_{G_a} \mathbf{n}_g
$$

该公式通过增加特征维度，将方向信息显式编码为树模型可分割的离散结构，显著降低了学习 $\mathbf{n}$-依赖性的难度。QRF++作为骨干，通过多输出分裂准则同时估计多个量化水平，确保了量化函数的单调性，避免了独立模型可能出现的量化交叉问题。

### 切片Wasserstein距离重建

设计动机在于解决从一维投影量化恢复多维分布时的非唯一性与计算复杂性。已知方向量化后，需确定点云的位置与权重以最小化与真实分布的距离。TQF采用切片Wasserstein距离（Sliced Wasserstein Distance, SWD）作为目标函数，其定义为：

$$
\text{SWD}^2(P, Q) = \int_{S^{d-1}} W_1^2((\mathbf{n}^\top)_\# P, (\mathbf{n}^\top)_\# Q) d\sigma(\mathbf{n})
$$

其中 $W_1$ 为一维Wasserstein距离。TQF通过交替优化算法（QMEM）求解：固定权重更新点位置，固定位置更新权重。由于一维Wasserstein距离有解析解，该优化过程转化为一系列凸子问题，保证了收敛性与计算效率，最终输出加权点云作为 $p(\mathbf{y}|\mathbf{x})$ 的非参数近似。

## 实验评估

实验在Concrete、Airfoil、Diabetes及California Housing等表格数据集上进行，基线包括GP、KNN、NGBoost及DRF。TQF在California Housing数据集上取得ES 0.215，与NGBoost持平（p=0.44），但R²最高，表明其在保持点预测精度的同时提供了可靠的分布估计。在合成数据上，TQF准确恢复了环形分布的支撑集，而GMM和Naïve方法均失效。

| 方法 | ES (California Housing) | R² (California Housing) |
| :--- | :--- | :--- |
| NGBoost | 0.215 | - |
| TQF | 0.216 | 最高 |
| GP | - | - |

| 方法 | ED (Synthetic I, a=0.5) | ED (Synthetic II, a=0.5) |
| :--- | :--- | :--- |
| TQF | 0.043(12) | 0.065(20) |
| GMM3 | 0.054(3) | 0.058(9) |
| Naïve | 0.086(3) | 0.136(4) |

消融实验显示，投影增强参数 $G$ 和 $G_a$ 均大于1时性能显著提升，但具体数值敏感性较高，需针对数据集调优。在Diabetes数据集上，QRF++出现轻微过度自信，而GP校准良好，表明树模型的校准性依赖于数据平滑度。

评估边界方面，论文未报告计算效率的具体对比，仅提及训练时间（2-9分钟），未与NN方法在大规模数据上的扩展性进行定量对比。代码已开源，但超参数搜索范围有限，未涵盖极端高维输入场景。

## 关联研究分析

从问题动机看，TQF与Wasserstein Random Forests (WRF) 同属树基分布预测，但WRF基于Wasserstein距离定义分裂准则，直接优化分布距离，而TQF通过CT原理将问题分解为投影量化。这一差异源于TQF对非凸分布的表达能力需求：WRF的分裂准则隐含了某种几何约束，而TQF的切片重建理论上可表达任意分布，但代价是两阶段优化的复杂性。

从方法设计看，TQF与NGBoost形成鲜明对比。NGBoost通过梯度提升拟合参数化分布（如高斯），计算高效但受限于分布族假设；TQF采用非参数点云表示，灵活但计算成本较高。在California Housing上两者ES持平，暗示该数据集的分布结构较简单，高斯假设已足够。然而，在合成环形数据上，TQF显著优于NGBoost，证明非参数方法在复杂分布下的必要性。TQF未显式区分Aleatoric与Epistemic不确定性，其树模型分区仅捕捉了混合方差，这与领域共识中强调的“结构性分离”存在差距。

## 总结

本文核心矛盾在于表格数据多变量UQ中，非参数方法的灵活性与计算效率难以兼得，且现有方法无法表达非凸联合分布。TQF抓住CT原理这一被忽略的几何工具，将多变量分布重建转化为一维投影量化与切片Wasserstein优化，从而在树模型框架内实现了非参数联合分布估计。实验证明其在复杂分布上优于GMM和Naïve方法，且在表格数据上点预测精度最优。然而，论文未验证TQF在高维输入（如 $d>10$）下的扩展性，且其校准性依赖于数据平滑度，在Diabetes等噪声较大数据集上表现不佳。当输入维度增加时，投影采样的数量 $G$ 需指数级增长以覆盖方向空间，此时TQF的计算优势是否仍能保持，论文未给出回答。
