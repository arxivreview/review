# 南加州团队新研究：时间无关统计特征建模不规则多变量时间序列

研究机构：美国南加州大学

作者：Dingyi Nie、Yixing Wu、C. -C. Jay Kuo

论文原文见 [arXiv](https://arxiv.org/abs/2602.19531)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.19531)

> 不规则采样与缺失值处理是临床时间序列建模的核心瓶颈，现有深度学习方法依赖复杂架构进行时间插值或时序建模，计算成本高且可能忽略缺失模式本身的信息价值。本文切入点在于证明当任务目标允许时，彻底消除时间轴的统计特征结合轻量级分类器足以超越复杂深度模型。方法通过提取每个变量的均值、标准差及变化率统计量构建固定维度表示，再使用XGBoost或逻辑回归进行分类。该方案在四个生物医学基准上达到或超越SOTA，但暴露出对时序动态信息完全丢失的潜在风险。

## 研究背景

临床监护数据中，传感器故障与医生按需开具检验单导致采样时间戳不规则且伴随大量缺失值。这种不规则性并非随机噪声，而是携带临床信息的信号：例如，心率监测中断可能暗示患者病情恶化或设备故障，而实验室检查的缺失频率反映了医生的临床判断。传统深度学习方法如GRU-D通过可学习衰减项显式建模时间间隔，SeFT利用注意力机制处理集合编码，但这些方法均假设保留时间轴结构是捕捉判别信息的必要条件，且依赖复杂的网络架构与高计算开销。

现有主流路线在应对不规则数据时面临两难：要么通过插值填补缺失值从而引入平滑偏差，要么通过复杂架构（如Transformer、GNN）保留时间结构但增加训练难度与推理延迟。近期研究指出，在中等规模表格数据上，梯度提升树模型的性能常与深度模型相当甚至更优，且天然处理缺失值。本文挑战了“复杂时序架构必要性”的共识，提出若任务目标不依赖精确的时间定位（如段级二分类而非时间点预测），则时间轴本身可被消除，仅保留变量级的统计摘要即可实现高效且可解释的分类。

## 核心方法

### 方法参照系

本文问题属于不规则多变量时间序列分类，与GRU-D、SeFT等深度学习方法同属“不规则与高效建模”路线。关键差异在于：标准流程通过衰减项、注意力或图结构保留时间依赖关系，而本文彻底移除时间轴，将变长序列转化为固定维度的统计特征向量，将时序建模问题转化为表格数据分类问题。

### 时间无关统计特征提取

设计动机在于解决深度模型在处理高缺失率数据时，因时间插值或复杂架构导致的计算冗余与信息丢失问题。本文对每个变量 $d$ 独立计算四个统计量，构建特征向量 $\mathbf{f}_d = [\mu_d^{(0)}, \sigma_d^{(0)}, \mu_d^{(1)}, \sigma_d^{(1)}]$。其中，$\mu_d^{(0)}$ 与 $\sigma_d^{(0)}$ 分别为变量 $d$ 观测值的均值与标准差，定义为：

$$ \mu_d^{(0)} = \frac{\sum_{i=1}^{L} m_{i,d} x_{i,d}}{\sum_{i=1}^{L} m_{i,d}}, \quad \sigma_d^{(0)} = \sqrt{\frac{\sum_{i=1}^{L} m_{i,d} (x_{i,d} - \mu_d^{(0)})^2}{\sum_{i=1}^{L} m_{i,d} - 1}} $$

该公式仅利用掩码数组 $\mathbf{M}$ 中 $m_{i,d}=1$ 的位置计算，显式区分观测与缺失，避免插值偏差。$\mu_d^{(1)}$ 与 $\sigma_d^{(1)}$ 则计算连续观测值之间的变化率均值与标准差，捕捉变量的动态趋势而非绝对时间位置。当某变量无连续观测时，变化率统计量置零，确保特征维度固定为 $4 \times D$，彻底消除序列长度 $L$ 的影响。

### 轻量级分类器集成

设计动机在于验证性能增益源于特征提取而非复杂分类器。本文使用XGBoost（100棵树，深度5，学习率0.1）作为主分类器，同时对比逻辑回归（LR）、随机森林（RF）与支持向量机（SVM）。特征数组 $\mathbf{F} \in \mathbb{R}^{4 \times D}$ 展平后直接输入分类器，LR使用前标准化。该设计剥离了时序建模组件，将分类任务简化为高维表格数据的模式识别，利用树模型对缺失值与特征交互的非线性捕捉能力，替代深度网络的时序卷积或注意力机制。

## 实验评估

| 数据集 | 方法 | AUROC (%) | AUPRC (%) | Accuracy (%) | F1 Score (%) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| P19 | Ours (XGBoost) | **90.0 ± 0.6** | **54.8 ± 2.6** | - | - |
| P19 | ViTST | 89.2 ± 2.0 | 53.1 ± 3.4 | - | - |
| P12 | Ours (XGBoost) | **85.7 ± 0.9** | **52.3 ± 2.2** | - | - |
| P12 | ViTST | 85.1 ± 0.8 | 51.1 ± 4.1 | - | - |
| PAM | Ours (XGBoost) | - | - | **97.2 ± 0.6** | **97.6 ± 0.4** |
| PAM | ViTST | - | - | 95.8 ± 1.3 | 96.5 ± 1.2 |
| MIMIC-III | Ours (XGBoost) | **85.9 ± 0.8** | **53.6 ± 1.2** | - | - |
| MIMIC-III | GRU-D | 85.7 ± 0.2 | 52.0 ± 0.8 | - | - |

实验在P19、P12、PAM与MIMIC-III四个生物医学基准上进行，对比基线覆盖Transformer、GRU-D、SeFT、ViTST等主流深度模型，但缺失自监督预训练类基线（如PLanTS、MTS-DMAE）。本文方法在P19、P12、PAM上全面超越ViTST，AUROC提升0.5-0.6%，AUPRC提升0.7-1.2%；在MIMIC-III上与GRU-D持平（85.9% vs 85.7%）。PAM数据集上Accuracy提升1.4%，F1提升1.1%，表明统计特征在人体活动识别任务上的有效性。

消融实验验证了特征提取的核心贡献。在PAM数据集上，原始输入+XGBoost的Accuracy为85.1%，均值插值+LR为54.7%，而本文统计特征+LR达到91.0%，+XGBoost达到97.2%。这表明性能增益主要源于统计特征对判别信息的保留与增强，而非分类器本身。P19数据集出现反直觉现象：原始输入+XGBoost的AUROC为95.6%，高于本文方法的90.0%。进一步分析发现，P19的缺失掩码数组 $\mathbf{M}$ 单独作为输入时，XGBoost达到94.2% AUROC，仅比原始输入低1.4%。这证明在脓毒症预测中，缺失模式本身携带强预测信号，而本文的统计特征虽消除了时间轴，但未能完全捕捉缺失模式的时序分布信息，导致在P19上略逊于原始输入。

评估协议采用5折交叉验证，报告均值与标准差，指标包括AUROC、AUPRC、Accuracy、Precision、Recall、F1。局限在于：未报告计算效率的具体数值（如训练时间、内存占用），仅定性描述“显著降低计算复杂度”；未对比自监督预训练方法，无法评估统计特征与预训练表示的互补性；P19数据集的高缺失率（26/34变量缺失率>90%）可能掩盖了统计特征在其他低缺失率数据上的局限性。

## 关联研究分析

从问题动机看，本文与GRU-D、SeFT等深度学习方法的核心差异在于对“时间轴必要性”的假设。GRU-D通过可学习衰减项显式建模时间间隔，假设时间间隔长度影响变量值的语义；SeFT利用注意力机制处理集合编码，保留观测值的相对顺序。本文则假设在段级分类任务中，变量的统计分布（均值、方差、变化率）足以区分类别，时间间隔的具体长度与顺序可被忽略。这一假设在P12、PAM、MIMIC-III上成立，但在P19上部分失效，因为脓毒症预测中缺失模式的时序分布（如缺失频率随时间的变化）可能比统计摘要更具判别力。

从方法设计看，本文与Statistical Approach（Nie et al., 2026）实为同一工作，知识库将其列为不规则医疗时间序列分类的SOTA。与DBGL（Chen et al., 2026）相比，DBGL通过二分图学习显式建模患者-变量依赖关系，保留时间衰减信息，而本文彻底消除时间轴。DBGL在P19/P12/MIMIC-III上的AUROC为85.7%，与本文持平，但DBGL保留了时间结构，可能在需要时间定位的任务上更具优势。本文的统计特征天然具备可解释性，每个维度对应明确的物理量（如心率均值、血糖变化率），满足临床部署的可信度要求，而DBGL的图结构难以直接解释。

## 总结

本文要解决的核心矛盾是不规则时间序列建模中计算复杂度与信息保留的平衡。现有深度方法依赖复杂架构保留时间结构，但计算成本高且可能忽略缺失模式信息；本文抓住“任务目标允许时间无关表示”的切入点，通过提取变量级统计特征消除时间轴，结合XGBoost实现高效分类。实验证明该方法在P19、P12、PAM上超越ViTST 0.5-1.7%，在MIMIC-III上与GRU-D持平，且特征提取是性能增益的主要来源。本文的边界在于P19数据集上统计特征略逊于原始输入，暴露出对缺失模式时序分布信息的丢失。当任务目标从段级分类转向时间点预测时，统计特征是否仍能保持竞争力，论文未给出回答。
