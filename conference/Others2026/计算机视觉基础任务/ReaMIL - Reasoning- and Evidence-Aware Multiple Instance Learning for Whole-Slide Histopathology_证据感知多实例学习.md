# 延世团队新研究：证据感知多实例学习

研究机构：韩国延世大学、韩国科学技术院

作者：Hyun Do Jung、Jungwon Choi、Hwiyoung Kim

论文原文见 [arXiv](https://arxiv.org/abs/2601.10073)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.10073)

> 全切片图像多实例学习（Multiple Instance Learning, MIL）旨在从千兆像素病理图像中仅凭包级标签实现诊断，但传统方法将注意力权重视为解释，缺乏对“哪些区域足以支撑预测”的因果验证。现有方案要么依赖事后热力图可视化，要么陷入全局上下文建模与计算效率的矛盾，无法量化证据的充分性与必要性。ReaMIL 通过在 Transformer 骨干上附加轻量级选择头，引入预算化充分性目标，强制模型依赖少量空间紧凑的实例子集。该框架在保持基线性能的同时实现了证据效率的量化，但其有效性受限于单一骨干网络与平衡数据集的验证，临床泛化能力存疑。

## 研究背景

病理诊断依赖对特定组织形态的识别，但临床数据仅提供切片级标签，导致模型必须从海量噪声实例中聚合判别性表示。多实例学习（MIL）将切片视为包含未标注实例的包，通过聚合函数 $f(\cdot)$ 预测包级标签 $y_i$。然而，标准 MIL 训练仅优化包级准确率，模型内部如何筛选关键证据是不透明的。注意力机制虽被广泛用作解释工具，但其权重是训练过程的副产品，并非优化目标，无法保证被关注区域的子集足以独立支撑预测，也无法证明剩余区域对预测无贡献。

领域主流路线在 2021 年后转向 Transformer 架构以捕捉长程空间依赖，但面临二次方计算复杂度瓶颈；近期状态空间模型（SSM）虽解决了效率问题，但仍未触及证据选择的因果性。可解释性研究多停留在注意力热力图可视化，缺乏量化证据充分性的标准。ReaMIL 的切入点在于将证据选择从“事后解释”提升为“事前约束”，通过显式优化目标确保模型依赖的最小实例子集具备诊断充分性，从而弥合包级性能与实例级推理之间的鸿沟。

## 核心方法

### 方法参照系

本文基于 TransMIL 骨干与冻结的 UNI2-h 基础模型特征，遵循“特征提取-聚合-预测”的标准 MIL 流程。与通用流程的关键差异在于，本文不将聚合器视为黑盒，而是引入可微分选择头，将包级预测解耦为对“保留包”与“丢弃包”的联合约束，使证据选择成为训练的一阶目标。

### 证据选择头与三视图构建

标准 MIL 中，所有实例特征平等参与聚合，导致模型难以区分关键证据与背景噪声。ReaMIL 在每个实例 token 上附加一个小型 MLP 计算选择 logit $a_{s,i}$，并通过 Concrete (Gumbel-sigmoid) 松弛实现可微分软选择：

$$ z_{s,i} = \sigma\left(\frac{\ln a_{s,i} - \ln(1-a_{s,i}) + \ln \epsilon - \ln(1-\epsilon)}{T}\right) $$

其中 $\epsilon \sim \text{Uniform}(0,1)$，$T$ 为温度参数。该机制生成软选择分数 $z_{s,i} \in (0,1)$，进而定义三个包视图：完整包 $X_{\text{full}}$、保留包 $X_{\text{keep}} = z_s \odot X_s$ 和丢弃包 $X_{\text{drop}} = (1-z_s) \odot X_s$。这一设计解决了传统注意力机制中“高权重实例可能冗余或虚假”的问题，通过显式分离证据与非证据区域，为后续因果约束提供结构基础。

### 预算化充分性目标

仅定义三视图不足以强制模型依赖少量关键实例，需通过损失函数约束其行为。ReaMIL 引入四项证据感知损失，总损失为：

$$ \mathcal{L} = \mathcal{L}_{\text{full}} + \lambda_{\text{suff}} \mathcal{L}_{\text{suff}} + \lambda_{\text{excl}} \mathcal{L}_{\text{excl}} + \lambda_{\text{contig}} \mathcal{L}_{\text{contig}} + \lambda_{\text{budget}} \mathcal{L}_{\text{budget}} $$

其中 $\mathcal{L}_{\text{suff}}$ 为充分性铰链损失，强制保留包的真实类概率 $p_y(\ell_{\text{keep}}) \geq \tau$；$\mathcal{L}_{\text{excl}}$ 为排除损失，要求丢弃包的真实类概率 $p_y(\ell_{\text{drop}})$ 趋近于零；$\mathcal{L}_{\text{contig}}$ 为空间连续性正则，惩罚选择实例的空间分散度；$\mathcal{L}_{\text{budget}}$ 为稀疏预算惩罚，限制平均选择率 $\|z\|_1$。该目标函数解决了注意力坍缩导致的证据冗余问题，通过“充分性+排除性”联合约束，确保模型不仅预测正确，且预测依赖于最小且空间紧凑的证据子集。

## 实验评估

实验在 TCGA-NSCLC、TCGA-BRCA 和 PANDA 三个二分类基准上进行，使用冻结的 UNI2-h 特征和 TransMIL 骨干，仅对比“TransMIL+UNI2-h”基线，缺失 ABMIL、CLAM 及 SSM 类方法（如 MambaMIL）的公平对比。

| 数据集 | 方法 | AUC | Acc | F1macro |
|---|---|---|---|---|
| BRCA | Baseline | 0.897_±_0.019 | 0.877_±_0.006 | 0.819_±_0.022 |
| | +ReaMIL | 0.904_±_0.011 | 0.888_±_0.010 | 0.827_±_0.019 |
| NSCLC | Baseline | 0.969_±_0.006 | 0.935_±_0.006 | 0.935_±_0.006 |
| | +ReaMIL | 0.983_±_0.004 | 0.927_±_0.025 | 0.927_±_0.026 |
| PANDA | Baseline | 0.985_±_0.002 | 0.955_±_0.004 | 0.945_±_0.004 |
| | +ReaMIL | 0.989_±_0.003 | 0.958_±_0.002 | 0.948_±_0.003 |

ReaMIL 在 NSCLC 上 AUC 提升 0.014，但在 BRCA 和 PANDA 上提升幅度较小，表明证据约束对高基线性能任务的增益有限。

| 数据集 | MSK@τ=0.90 (↓) | AUKC (↑) |
|---|---|---|
| BRCA | 16.0_±_11.8 | 0.833_±_0.018 |
| NSCLC | 8.2_±_2.1 | 0.864_±_0.069 |
| PANDA | 7.2_±_3.6 | 0.811_±_0.055 |

消融实验显示，移除充分性、排除性或连续性约束后，模型选择率 $\|z\|_1$ 从 0.002 飙升至 0.85 以上，导致保留包近似完整包，证据效率指标失效。这表明预算化充分性目标是实现稀疏证据选择的核心，而非单一损失项。

评估边界方面，MSK 和 AUKC 指标仅对 ReaMIL 定义，无法用于基线对比，限制了跨方法的可比性。论文未提供代码，且仅在平衡数据集上验证，未评估长尾分布或域偏移场景下的鲁棒性。

## 关联研究分析

从问题动机看，ReaMIL 与 GCE-MIL 均关注证据的因果性，但 ReaMIL 通过预算化目标更强调稀疏性，而 GCE-MIL 侧重干预评估。ReaMIL 的“充分性+排除性”联合约束直接优化证据子集的最小性，而 GCE-MIL 依赖 TITAN 文本锚点接地门控，计算成本更高且缺乏大规模验证。ReaMIL 选择 Transformer 而非 SSM 作为骨干，可能因证据选择需要全局注意力机制来捕捉实例间依赖，但论文未提供 Transformer 在证据选择任务上优于 SSM 的直接证据，这一选择是否与任务特性相关，还是作者未探索的盲区，尚不明确。

从方法设计看，ReaMIL 与 ABMIL 的核心差异在于将注意力权重从“解释副产品”提升为“优化目标”。ABMIL 的注意力坍缩导致证据冗余，而 ReaMIL 通过 Drop 包排除机制强制模型忽略非关键区域。然而，ReaMIL 依赖冻结的 UNI2-h 特征，若基础模型特征空间未覆盖任务所需的所有判别信息，证据选择可能失效。这与 nnMIL 等解耦架构的共识一致，但 ReaMIL 未验证在极端少样本场景下，基础模型特征是否足以支撑证据选择的充分性。

## 总结

ReaMIL 旨在解决弱监督 MIL 中证据选择缺乏因果验证的矛盾，通过预算化充分性目标将证据选择从事后解释提升为事前约束。该方法在 TransMIL 骨干上附加轻量级选择头，强制模型依赖少量空间紧凑的实例子集，在 TCGA-NSCLC 上实现 AUC 0.983 与 MSK 8.2 的平衡。其边界在于仅验证了单一骨干与平衡数据集，未评估长尾分布或域偏移场景下的鲁棒性。当支持集增大到 5-shot 时，证据选择的边际收益是否递减，论文未给出回答。
