# 混合LSTM-KAN架构下的不平衡呼吸音分类

作者：Nithinkumar K.、Anand R

论文原文见 [arXiv](https://arxiv.org/abs/2601.03610)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.03610)

> 呼吸音自动分类面临临床数据中多数类（如COPD）占比极高导致的模型偏倚，传统深度网络在稀有病种检测上失效且缺乏可解释性。本文切入点在于利用Kolmogorov-Arnold Networks (KAN) 的可学习样条函数替代固定激活函数，结合LSTM时序编码与多策略不平衡处理，试图在极端不平衡场景下提升稀有类召回率并增强特征变换的透明度。该方法通过组合Focal Loss、SMOTE及数据增强，在ICBHI数据集上实现了94.55%的整体准确率，但其对稀有类的改善幅度有限，且缺乏与当前主流Transformer基础模型的横向对比，其临床泛化能力存疑。

## 研究背景

当临床听诊数据中COPD样本占比超过86%时，标准交叉熵损失函数会引导模型过度拟合多数类，导致支气管细支气管炎等稀有病种被系统性漏检。这种由数据分布偏倚引发的性能失衡，使得传统卷积神经网络（CNN）或长短期记忆网络（LSTM）在医疗筛查场景中难以满足对罕见病的高灵敏度要求。同时，黑盒模型无法向医生展示决策依据，阻碍了其在临床信任建立中的应用。

呼吸声学分析的主流路线已从手工特征提取转向基于梅尔频谱图（Mel-Spectrogram）的深度表示学习。然而，现有监督学习模型受限于标注数据稀缺，且在处理极端类别不平衡时，往往依赖单一的数据增强或损失函数调整，缺乏系统性整合。多数研究关注整体准确率，忽视了稀有类指标（如Macro-F1）的优化，且未解决模型内部特征变换不可解释的问题。本文针对这一缺口，提出了一种结合时序编码与非线性分类的混合架构，旨在通过架构层面的创新与数据层面的协同处理，同时解决不平衡偏倚与可解释性缺失两大痛点。

## 核心方法

### 方法参照系

本文问题属于专用分类架构路线，标准流程为“特征提取-骨干网络-分类头”。与主流基于Transformer的端到端模型不同，本文采用手工提取的高维统计特征作为输入，并在LSTM编码后引入KAN层，关键差异在于将非线性映射从节点激活移至边连接，以增强小样本下的函数逼近能力与可解释性。

### KAN非线性分类后端

传统MLP使用固定激活函数（如ReLU），难以灵活适配呼吸音特征中复杂的非线性关系，且缺乏对特定特征变换的可视化能力。本文在LSTM输出后引入KAN层，其核心公式为：

$$ y_i = \sum_{j=1}^{n_{in}} \phi_{i,j}(x_j) $$

其中 $\phi_{i,j}$ 为可学习的B-spline样条函数。该设计动机在于，样条函数允许网络针对每个输入-输出连接学习独特的非线性映射，从而更精确地捕捉LSTM编码后的细微声学差异。相比固定激活函数，KAN的样条结构提供了参数效率更高的函数逼近能力，并允许通过可视化 $\phi_{i,j}$ 来解释特定声学特征（如MFCC）如何贡献于疾病预测，解决了黑盒模型无法提供临床逻辑依据的问题。

### 多策略不平衡协同处理

单一的不平衡处理技术（如仅使用Focal Loss）在极端不平衡下效果有限，且可能引入过拟合。本文采用两阶段训练策略，结合Focal Loss、SMOTE及类别特定数据增强。Focal Loss公式为：

$$ FL(p_t) = -\alpha_t (1-p_t)^\gamma \log(p_t) $$

其中 $\gamma \approx 2.19$ 用于降低易分类样本的权重。SMOTE应用于特征空间而非原始音频，避免了时域插值产生的伪影。这一组合策略旨在通过损失函数重加权、特征空间过采样及信号级增强的协同作用，系统性地提升稀有类（如URTI、Bronchiolitis）的识别能力，弥补单一方法在极端分布下的性能瓶颈。

## 实验评估

实验基于ICBHI 2017数据集的六分类子集（917个样本），采用分层5折交叉验证。基线仅对比了无不平衡处理的标准交叉熵模型，缺失与AST、RespiraMFM等当前SOTA方法的横向对比，限制了性能定位的准确性。

| 配置 | Accuracy (%) | Macro-F1 | URTI F1 | Bronchiolitis F1 |
| :--- | :--- | :--- | :--- | :--- |
| Baseline (CE) | 91.23 | 0.5821 | 0.2134 | 0.1978 |
| Focal Loss | - | 0.6347 | 0.3012 | 0.2689 |
| Full Hybrid | 94.55 | 0.7033 | 0.4390 | 0.4538 |

消融实验显示，完整混合策略相比基线在Macro-F1上提升了12.1%（0.5821至0.7033），稀有类F1提升显著（URTI +105.8%），但绝对值仍低于0.5，表明极端不平衡下的检测难题未完全解决。

评估协议存在局限：未报告置信区间，且未进行跨数据集泛化测试。代码未公开，超参数（如Focal Loss的 $\gamma$ 值）虽已列出，但缺乏对SMOTE在特征空间中引入噪声影响的敏感性分析。

## 关联研究分析

从问题动机看，本文与BTS-CARD均关注偏差问题，但路径截然不同。BTS-CARD采用因果推断消除元数据虚假相关，而本文聚焦于单模态音频内的类别分布偏倚，通过数据增强与损失函数调整解决。这种差异源于任务定义：BTS-CARD处理多模态融合中的捷径学习，本文处理单模态分类中的样本稀疏。本文未探索元数据引入的偏差，这在真实临床场景中可能是更主要的性能退化来源。

从方法设计看，本文使用LSTM-KAN替代了领域共识中占主导地位的Transformer架构。AST等模型通过全局自注意力捕捉长程依赖，而本文依赖LSTM的局部时序建模。在呼吸音分析中，长程依赖（如完整呼吸周期）至关重要，LSTM在序列长度增加时可能面临梯度消失或计算效率问题。论文未提供证据支持LSTM在捕捉复杂时序模式上优于Transformer，这可能限制了其在长音频片段上的泛化能力。

## 总结

本文核心矛盾在于极端类别不平衡下稀有病种漏检与模型黑盒化导致的临床信任缺失。切入点在于利用KAN的可学习样条函数提供可解释的非线性映射，并协同多种不平衡处理技术。方法上，构建了LSTM编码特征、KAN分类的混合架构，结合Focal Loss与SMOTE。实验证明其在ICBHI数据集上达到94.55%准确率，Macro-F1提升至0.7033。然而，稀有类F1仍低于0.5，且缺乏与Transformer SOTA的对比，暴露了其在复杂时序建模与跨域泛化上的潜在短板。当支持集规模扩大或引入多模态元数据时，KAN样条函数的稳定性与LSTM时序建模的局限性是否会成为主要瓶颈，论文未给出回答。
