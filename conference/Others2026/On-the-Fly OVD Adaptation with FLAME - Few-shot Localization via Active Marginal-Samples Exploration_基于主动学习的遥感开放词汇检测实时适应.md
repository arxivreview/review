# 谷歌团队新研究：基于主动学习的遥感开放词汇检测实时适应

研究机构：谷歌研究院

作者：Yehonathan Refael、Amit Aides、Aviad Barzilai 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.17670)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.17670)

> 开放词汇目标检测（OVD）在遥感领域面临文本查询语义歧义导致的精度骤降，而传统少样本微调因计算成本高、需GPU加速且耗时数小时，无法满足实时适应需求。FLAME 通过级联架构，利用冻结的 OVD 模型生成高召回提案，并引入基于密度估计与聚类的主动学习策略筛选边界样本，在 CPU 上实时训练轻量分类器以消除歧义。该方法在 DOTA 和 DIOR 基准上以 30-shot 设定超越了现有少样本方法，但受限于单类别二分类假设及零样本检索失败的边界条件，其泛化能力与多类别扩展性仍存疑。

## 研究背景

遥感图像中目标类别不可穷举，且密集标注成本极高，这构成了少样本目标检测（FSOD）的核心约束。开放词汇目标检测（OVD）利用视觉-语言模型（VLMs）的文本嵌入实现零样本泛化，但自然语言的固有歧义（如“渔船”与“游艇”嵌入相似）导致细粒度类别区分能力不足，产生大量误检。为解决此问题，少样本方法试图利用少量标注样本适应新类别，但主流策略如元学习或全模型微调计算密集，参数高效微调（PEFT）虽降低参数量却仍需数小时 GPU 训练，难以满足遥感场景下快速部署与实时响应的需求。

现有 OVD-FSOD 混合范式多采用提示学习或 Transformer 架构统一框架，其性能高度依赖支持集样本的信息量，而随机采样往往包含大量冗余或低信息量样本。主动学习（AL）通过查询最具信息量的样本优化标注效率，但在遥感 OVD 场景中，如何结合零样本模型的语义先验与轻量级实时训练，以极低成本消除语义歧义，尚缺乏系统性解决方案。FLAME 的切入点在于将“模型适应”转化为“数据适应”，通过理论证明轻量分类器仅由边界样本决定，从而构建一个无需全模型微调、可在 CPU 上分钟级完成的实时适应框架。

## 核心方法

### 方法参照系

传统 FSOD 流程通常基于冻结骨干网络提取特征，通过原型匹配或全模型微调适应新类别。本文问题与该通用流程的关键差异在于：不修改 OVD 基座模型权重，而是将其作为提案生成器，后续通过独立的轻量分类器进行实时二分类，且样本选择过程由主动学习策略驱动而非随机或全量使用。

### 边界样本识别与多样性采样

传统主动学习多采用不确定性采样或多样性采样单一策略，前者易陷入局部最优，后者忽略决策边界附近的歧义性。FLAME 提出级联筛选机制，首先将图像嵌入 $x_i$ 与文本嵌入 $t$ 的余弦相似度 $c_i$ 拼接为增强嵌入 $\tilde{x}_i = [x_i, c_i] / (\|x_i\|\|t\|)$，通过主成分分析（PCA）投影至低维空间。随后，利用高斯核密度估计（KDE）拟合分布，保留密度处于 $[s_L, s_U]$ 区间的样本，其中 $s_L, s_U$ 满足 $\hat{f}(s_L) = r_l \hat{f}(s^*)$ 且 $\hat{f}(s_U) = r_u \hat{f}(s^*)$，$s^*$ 为密度峰值。这一设计动机在于，边界附近的样本携带了区分正负类的最大歧义信息，而密度过滤排除了远离边界的确定性样本。随后，对保留的边界样本执行 K-means 聚类，选取每个簇中心最近的样本作为最终支持集，确保样本在特征空间中的覆盖多样性，避免冗余标注。

### 轻量级实时分类与理论支撑

传统少样本分类器训练通常依赖深度网络，计算开销大且收敛慢。FLAME 采用径向基函数（RBF）支持向量机（SVM）作为默认分类器，其理论依据在于支持向量决定论：对于硬间隔或软间隔 SVM，分类器仅由支持向量（即边界样本）决定，移除非支持向量重训练不改变分类结果。公式上，软间隔 SVM 的最优解 $(w^*, b^*)$ 满足 KKT 条件，仅当 $\alpha_i^* > 0$ 时样本 $x_i$ 为支持向量。FLAME 利用此性质，仅用筛选出的 $K$ 个边界样本训练 SVM，若类别不平衡比 $\rho > \tau$，则应用合成少数类过采样技术（SMOTE）进行增强。这一设计解决了全模型微调在资源受限场景下的不可行性，使得分类器训练可在 CPU 上实时完成，且理论上等价于使用全量数据训练的分类器（在支持向量集合一致的前提下）。

## 实验评估

实验在 DOTA 和 DIOR 两个遥感基准上进行，采用 30-shot 设定，评估指标为平均精度（AP）。基线覆盖零样本（OWL-ViT-v2, RS-OWL-ViT-v2）、少样本微调（Jeune et al., SIoU）及原型匹配（DINOv2-based）。FLAME 在 DOTA 上取得 53.96% AP，在 DIOR 上取得 53.21% AP，显著优于零样本基线（13.774% 和 14.982%）及少样本微调方法（SIoU 在 DOTA 上为 45.88%）。

| 方法 | DOTA AP (%) | DIOR AP (%) |
| :--- | :--- | :--- |
| Zero-shot OWL-ViT-v2 | 13.774 | 14.982 |
| Zero-shot RS-OWL-ViT-v2 | 31.827 | 29.387 |
| SIoU | 45.88 | 52.85 |
| Prototype-based FSOD (DINOv2) | 41.40 | 26.46 |
| FLAME | 53.96 | 53.21 |

FLAME 在 DIOR 上对“expressway toll station”类别的 AP 从 0% 提升至 99%，在 DOTA 上对“Container Crane”类别从 3% 提升至 95%，表明其在解决细粒度语义歧义方面有效。然而，部分类别（如 DIOR 的“airport”、DOTA 的“Tennis Court”）出现性能下降或失败（标记为“–”），原因是零样本检索阶段未找到相关候选图像，导致主动学习流程无法启动。

该论文未提供消融实验数据，无法量化密度估计参数 $r_l, r_u$ 或聚类数 $K$ 对性能的具体影响。评估协议仅报告 30-shot 结果，缺乏 1-shot 或 5-shot 等极低样本场景下的表现对比，且未报告置信区间或多次运行均值，数值稳定性存疑。代码未公开，超参数（如 KDE 带宽 $h$、不平衡阈值 $\tau$）未详细披露，可复现性受限。

## 关联研究分析

从问题动机看，FLAME 与 FSOD-VFM 均利用视觉基础模型（VFM）提升少样本检测性能，但 FSOD-VFM 侧重通过图扩散机制细化边界框分数以抑制提案碎片化，属于推理阶段的精度优化；而 FLAME 侧重通过主动学习筛选训练样本以消除语义歧义，属于数据阶段的效率优化。FSOD-VFM 依赖多模型协同（UPN, SAM2, DINOv2）且无需训练，但推理慢且模型大；FLAME 依赖单模型（RS-OWL-ViT-v2）加轻量 SVM，适应快但依赖零样本提案质量。二者在“精度-效率”权衡上处于不同象限，FLAME 更适合资源受限的实时场景，FSOD-VFM 更适合离线高精度场景。

从方法设计看，FLAME 与 MUSE 均关注零样本/边缘部署，但 MUSE 利用不确定性感知相似度估计直接进行匹配，属于训练无关（Training-free）范式；FLAME 则引入实时轻量训练，违背了近期 FSOD 领域“冻结骨干+无训练”的主流共识。这一差异源于任务特性：MUSE 处理 2D 检测/分割，依赖 3D 模板或预训练特征直接匹配；FLAME 处理遥感细粒度类别，文本歧义严重，仅靠相似度匹配难以区分，必须引入少量标注进行边界校准。实时训练 SVM 在样本极少时是否比原型匹配更鲁棒，论文未给出理论或实验对比，仅在特定遥感基准上验证了有效性。

## 总结

FLAME 旨在解决遥感 OVD 中语义歧义导致的精度瓶颈与全模型微调的高计算成本矛盾。其切入点在于利用 SVM 支持向量决定论，证明仅需边界样本即可构建等价分类器，从而将适应过程从“模型权重更新”转化为“边界样本筛选与轻量训练”。该方法在 DOTA 和 DIOR 上以 30-shot 设定分别取得 53.96% 和 53.21% AP，适应时间缩短至分钟级。其边界在于依赖零样本提案的召回率，当检索失败时方法完全失效，且仅支持单类别二分类，未探索多类别联合主动学习。当支持集规模从 30-shot 缩减至 1-shot 时，密度估计与聚类策略的稳定性是否足以维持分类器性能，论文未给出回答。
