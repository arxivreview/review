# 确定性逆向微结构设计框架

作者：Reza T. Batley、Sourav Saha

论文原文见 [arXiv](https://arxiv.org/abs/2512.15746)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.15746)

> 异质材料微结构的逆向设计面临高维空间搜索与物理非线性导致的计算瓶颈，传统生成模型虽能建模前向映射，但缺乏支持快速、稳定确定性逆向的内在结构。现有扩散或GAN方法在逆向时需依赖昂贵的迭代优化或随机采样，无法保证前向-逆向动力学的一致性。Janus通过联合优化一个同时满足循环一致性与预测精度的潜空间，实现了从目标属性到微观结构的直接解码。该框架在热导率逆向任务中实现了1%的相对误差，但其有效性严格受限于训练分布的插值能力，外推泛化能力存疑。

## 研究背景

微结构逆向设计本质上是求解一个病态的多对一映射问题：不同的微观几何构型可能产生相同的宏观物理属性。这种非凸性导致传统拓扑优化或贝叶斯搜索在高分辨率图像空间中陷入局部极小值或计算不可行。解决此问题的关键在于构建一个紧凑且信息丰富的潜空间，使得从属性到结构的映射不再是高维输入空间的盲目搜索，而是低维流形上的确定性导航。

当前主流生成模型如变分自编码器（VAE）和生成对抗网络（GAN）的潜空间主要优化于采样分布或对抗匹配，而非逆向一致性。VAE的潜空间不具备循环一致性，即编码输入与其重构结果往往不对应同一潜向量；GAN虽能生成高分辨率图像，但其逆向过程需依赖独立的编码器或迭代优化，且无法保证前向-逆向组合的稳定性。扩散模型虽在生成保真度上领先，但其逆向过程需运行昂贵的反向扩散或基于梯度的潜空间搜索，且其潜表示并非为预测任务优化。这些方法均缺乏一种机制，能在单一潜空间中同时保证解码的可逆性、预测的准确性以及逆向过程的确定性。

Janus的切入点在于将潜空间本身作为优化对象，而非仅作为生成过程的中间变量。它不依赖外部优化器在巨大输入空间中搜索，而是通过联合训练编码器、解码器和预测头，塑造出一个“为逆向而生”的几何结构。这一设计使得逆向过程从“搜索”转变为“解码”，将计算成本从迭代优化降至单次前向推理量级，从而在保持物理信息的同时实现了实时逆向设计。

## 核心方法

### 可分离神经架构与潜空间解耦

Janus的核心架构基于可分离神经架构（SNA），其预测头K采用KHRONOS模型，一种基于二次B样条基函数的张量积表示。SNA通过限制交互阶数 $k$ 和秩约束 $r$，将高维函数分解为低维可学习原子的组合，从而在低内在维度数据上实现紧凑且良态的表示。

$$
K(z) = \sum_{S \subset [M], |S| \le k} c_S \prod_{i \in S} \psi_i(z_i)
$$

该公式表明预测头K是潜变量 $z$ 各分量的低阶交互之和，其中 $\psi_i$ 为B样条基函数。这种结构确保了K是连续可微且梯度稳定的，为后续的逆向优化提供了数值基础。设计动机在于解决传统全连接网络在科学数据上易过拟合且梯度不稳定的问题，通过显式的低秩约束，使潜空间在预测维度上被“修剪”，仅保留对物理属性有贡献的信息，从而诱导潜空间的解耦。

### 联合优化循环一致性与预测精度

Janus通过一个复合损失函数联合优化编码器E、解码器D和预测头K，其核心创新在于引入循环一致性损失与深度循环一致性损失。

$$
\mathcal{L} = \mathcal{L}_{task} + \lambda_{recon}\mathcal{L}_{recon} + \lambda_{cycle}\mathcal{L}_{cycle} + \lambda_{deep}\mathcal{L}_{deep}
$$

其中 $\mathcal{L}_{cycle} = \|E(D(z)) - z\|_2^2$ 强制编码-解码过程的循环一致性，而 $\mathcal{L}_{deep}$ 进一步约束二阶表示空间的稳定性。这一设计解决了VAE和GAN中潜空间“漂移”的问题：在VAE中，重构后的输入再编码会得到不同的潜向量，导致逆向时无法回到原始状态；在GAN中，缺乏显式的重建约束使得潜空间几何结构松散。通过联合优化，Janus的潜空间 $Z$ 被塑造为同时满足“可解码”（重构误差低）、“可预测”（属性误差低）和“可逆”（循环误差低）的流形。这使得逆向过程 $D \circ K^{-1}$ 成为可能：首先通过KHRONOS头的可逆性从目标属性 $y$ 求解潜向量 $z$，再直接解码为微观结构 $x$，无需迭代搜索。

## 实验评估

实验在MNIST手写数字数据集和相场生成的异质微结构数据集上进行。MNIST用于验证架构的通用性，微结构数据集用于验证物理逆向设计能力。基线覆盖方面，论文未与DiffCSP、FlowMM等晶体生成SOTA方法直接对比，因其任务对象（周期性晶体 vs 非周期微结构）不同，但隐含对比了VAE、GAN和扩散模型在逆向效率上的劣势。

| 指标 | MNIST (50 epochs) | 微结构 (热导率) |
| :--- | :--- | :--- |
| 测试准确率 / $R^2$ | 97.5% | 0.98 |
| 重构误差 (MAE) | ~8% | <5% |
| 逆向相对误差 | - | <1% |

在MNIST上，模型在2个epoch内即达到90%以上的分类准确率和10%的重构保真度，50个epoch后收敛至97.5%准确率和8%重构误差，表明16维潜空间 $Z \in \mathbb{R}^{16}$ 足以保留几何与语义信息。在微结构任务中，前向预测 $R^2=0.98$，逆向生成的结构满足目标热导率的相对误差小于1%。UMAP可视化显示潜空间呈现低维解耦流形，属性扫描在潜空间中表现为平滑遍历，验证了循环一致性约束的有效性。

消融实验未单独列出，但训练动态图显示循环一致性损失（$\mathcal{L}_{cycle}$）和深度循环损失（$\mathcal{L}_{deep}$）在训练初期迅速收敛，表明该约束对潜空间几何结构的塑造起主导作用。若移除循环一致性项，模型将退化为标准VAE，丧失确定性逆向能力。

评估边界方面，论文未报告置信区间或多次运行的方差，且微结构数据源自相场模拟而非实验数据，其物理真实性依赖于相场模型的准确性。代码未公开，超参数（如 $\lambda$ 权重）未详细列出，可复现性受限。

## 关联研究分析

从问题动机看，Janus与DiffCSP、FlowMM等晶体生成方法存在根本差异。后者旨在从化学式生成热力学稳定的周期性晶体，核心挑战是对称性保持与能量最小化，通常采用等变扩散或流匹配模型，并依赖DFT验证。Janus处理的是非周期性异质微结构，核心挑战是病态逆向映射的确定性求解，不依赖对称性约束，而是依赖潜空间的循环一致性。这一差异源于任务特性：晶体生成是“从成分到结构”的分布采样，而微结构逆向是“从属性到结构”的约束求解。Janus的确定性逆向机制在晶体生成中可能失效，因为晶体的多对一映射更为复杂，且缺乏明确的“属性-结构”单值对应关系。

从方法设计看，Janus与MatterGen、PLaID++等基于LLM或强化学习的逆向设计方法形成对比。后者通过自然语言提示或奖励函数引导生成模型探索新颖结构，强调多样性与可控性，但逆向过程仍是随机采样或迭代优化。Janus摒弃了随机性，通过可逆KHRONOS头实现零步逆向，计算成本更低且结果确定。然而，Janus的潜空间是插值型的，无法生成训练分布外的新颖结构，而RL方法可通过奖励函数引导模型外推。这暗示Janus适用于已知属性范围内的精确逆向，而RL方法适用于探索未知属性空间。

## 总结

Janus解决了异质微结构逆向设计中高维搜索与物理非线性导致的计算瓶颈，其核心在于通过联合优化循环一致性与预测精度，构建了一个支持确定性快速逆向的潜空间。该方法在热导率逆向任务中实现了1%的相对误差和<5%的重构误差，证明了潜空间解耦的有效性。然而，其边界在于严格的插值特性：生成的微结构必须位于训练数据流形内，无法外推至未见过的属性组合或微观构型。当目标属性超出训练分布范围时，逆向求解是否仍能保持物理合理性，论文未给出回答。
