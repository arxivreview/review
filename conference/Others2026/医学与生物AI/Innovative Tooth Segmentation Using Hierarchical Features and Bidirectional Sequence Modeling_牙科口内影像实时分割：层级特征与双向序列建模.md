# 牙科口内影像实时分割：层级特征与双向序列建模

作者：Xinxin Zhao、Jian Jiang、Yan Tian 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.21712)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.21712)

> 牙科口内影像分割旨在从高分辨率口内照片中精确 delineate 牙齿、牙龈等解剖结构，以支撑数字化牙科流程。现有基于 Transformer 的 SAM 变体虽具备强泛化性，但其二次方计算复杂度导致高分辨率输入下推理延迟激增，难以满足临床实时需求。本文切入点在于替换 SAM 的 ViT 编码器为 CNN-Mamba 混合架构，通过层级特征融合与双向序列块（BSB）在保持分割精度的同时实现线性复杂度。该方案在效率与精度平衡上优于现有 SAM 变体，但其对零样本泛化能力的潜在牺牲及 2D 任务对 3D 几何先验的缺失仍存疑。

## 研究背景

口内影像分割面临的核心困境是高分辨率输入下的计算瓶颈与噪声干扰。高分辨率口内照片包含丰富的纹理细节，但同时也存在牙石、食物残渣等噪声，导致传统固定分辨率特征图难以区分目标与背景。解决此问题需同时捕获多尺度细节与全局上下文，而 Transformer 自注意力机制的 $O(N^2)$ 复杂度在处理长序列（即高分辨率图像展平后的 token 序列）时成为主要障碍。状态空间模型（SSM）如 Mamba 提供了线性复杂度 $O(N)$ 的序列建模能力，但其直接应用于视觉领域时，往往缺乏针对牙科解剖结构的多尺度特征显式建模。

牙科影像分析领域正从单一任务向多任务、多模态统一框架演进，但 2D 口内影像的实时分割仍是一个独立且紧迫的子问题。主流路线包括基于 Transformer 的 SAM 变体（如 HQ-SAM、MedSAM）和基于线性注意力的 Vim、VRWKV。前者精度较高但推理速度慢，后者效率高但多尺度特征提取能力不足。本文的切入点在于结合 HQ-SAM 的边界增强思路与 Mamba 的效率优势，设计任务导向的图像编码器，旨在解决高分辨率口内影像中“精度-效率”的矛盾，同时通过层级特征融合应对噪声导致的边界模糊。

## 核心方法

### 方法参照系

本文基于 SAM 架构，保留 Prompt 机制与 Mask Decoder，但替换 Image Encoder。标准 SAM 使用 ViT 提取特征，本文将其替换为三阶段 CNN-Mamba 混合编码器，关键差异在于引入显式多尺度特征金字塔与双向序列块，以替代 ViT 的全局自注意力。

### 层级特征金字塔与融合

设计动机：标准 ViT 编码器在高分辨率下丢失低层细节，导致噪声干扰下的边界模糊。本文在编码器前两个阶段（4× 和 8× 下采样）使用 MBConv 模块提取低层细节特征（LDF），并在解码器中通过自顶向下的融合层恢复空间分辨率。融合过程定义为：

$$
F_{fused} = \text{Conv}_{1\times1}(\text{Concat}(\text{Up}(F_{high}), F_{low}))
$$

其中 $F_{high}$ 为深层语义特征，$F_{low}$ 为浅层细节特征。该设计通过保留细粒度空间线索，显著提升了在牙石等噪声存在下的分割鲁棒性，消融实验显示 LDF 聚合使 mIoU 提升 2.7%。

### 双向序列块（BSB）

设计动机：单向 Mamba 扫描无法充分捕获全局空间上下文，而双向扫描若直接相加会引入冗余响应。本文在编码器第三阶段（16× 下采样）引入 BSB，通过独立门控机制调制前向与后向分支。BSB 的输出定义为：

$$
F_{BSB} = G_f \odot F_{forward} + G_b \odot F_{backward}
$$

其中 $G_f, G_b$ 为独立门控信号，$\odot$ 表示逐元素乘法。该设计通过抑制冗余响应，增强了全局上下文一致性，相比无门控设计，mIoU 从 90.8% 提升至 91.9%。

## 实验评估

| 方法 | DSD mIoU | DSD mBIoU | OralVision mIoU | OralVision mBIoU |
| :--- | :--- | :--- | :--- | :--- |
| SAM | 88.7±0.4 | 85.3±0.5 | 88.1±0.3 | 85.0±0.4 |
| HQ-SAM | 91.2±0.3 | 89.0±0.3 | 90.3±0.3 | 87.2±0.3 |
| U-Mamba | 90.1±0.3 | 85.8±0.4 | 90.0±0.3 | 85.2±0.3 |
| Ours | 91.9±0.2 | 88.7±0.3 | 91.4±0.3 | 88.1±0.2 |

实验在 DSD 和 OralVision 数据集上进行，基线覆盖 SAM 变体（HQ-SAM, MedSAM, Adapter-SAM）及线性注意力模型（Vim, VRWKV, U-Mamba）。本文方法在两个数据集上均取得最高 mIoU，DSD 上比 HQ-SAM 高 0.7%，OralVision 上高 1.1%。效率方面，本文方法在 640×480 分辨率下达到 52.3 FPS，FLOPs 仅为 12.5G，显著优于 MedSAM（28.5 FPS, 34.2G）和 Swin-Unet（22.7 FPS, 47.8G）。

| 消融变体 | DSD mIoU | DSD mBIoU |
| :--- | :--- | :--- |
| No Gate | 90.8±0.3 | 87.2±0.3 |
| Shared Gate | 91.4±0.2 | 87.9±0.3 |
| Dual Gate (Ours) | 91.9±0.2 | 88.7±0.3 |

消融实验表明，双向 SSM 与 1D 卷积的组合（90.9% mIoU）优于单独使用（89.1% 或 90.7%），验证了局部连续性与全局上下文聚合的互补性。门控机制中，双门控设计（Dual Gate）比共享门控（Shared Gate）高 0.5% mIoU，说明独立调制前向与后向分支有助于保留显著依赖关系。

评估边界方面，本文使用 mIoU 和 mBIoU 作为主要指标，但未报告置信区间或跨机构泛化性能。可复现性上，论文提供了详细的超参数（AdamW, lr=6e-5, batch size=32/24）和硬件配置（4× RTX 4090D），但未公开代码。评估协议中，SAM 基线使用 YOLOv10 生成的边界框提示，而非 SAM 基线则无提示，这种非对称提示设置可能影响公平性，尽管作者声称已控制变量。

## 关联研究分析

从方法设计看，本文与 U-Mamba 同属 Mamba 架构在医学影像中的应用，但 U-Mamba 聚焦 3D CBCT 分割，采用 U-Net 瓶颈层集成 SSM，而本文针对 2D 口内影像，采用层级 CNN-Mamba 编码器。差异根源在于任务维度：3D 数据需处理体积数据的长程依赖，而 2D 口内影像更关注高分辨率下的实时性与噪声鲁棒性。本文的层级特征金字塔设计在 3D 任务中是否必要，论文未给出回答，这可能暗示 2D 任务对低层细节的依赖高于 3D 任务。

从问题动机看，本文与 HQ-SAM 同属 SAM 变体，但 HQ-SAM 通过细化模块提升边界质量，而本文通过替换编码器提升效率。HQ-SAM 在 DSD 上 mIoU 为 91.2%，本文 91.9%，但 FPS 从 28.5 提升至 52.3。这一差异表明，在牙科口内影像中，效率与精度的权衡可通过架构替换实现，但 HQ-SAM 的零样本泛化能力是否因编码器替换而受损，论文未进行跨域测试，仅在本域数据集上验证，这可能掩盖了泛化能力的潜在下降。

## 总结

本文核心矛盾是高分辨率口内影像分割中精度与效率的冲突，切入点在于利用 Mamba 的线性复杂度替代 Transformer 的二次方复杂度，同时通过层级特征融合弥补多尺度细节丢失。方法上，本文设计了 CNN-Mamba 混合编码器与双向序列块，证明了在 DSD 和 OralVision 数据集上，该方法能以 52.3 FPS 的推理速度实现 91.9% 的 mIoU，优于 HQ-SAM 和 U-Mamba。边界在于，本文仅在 2D 口内影像上验证，未探索 3D CBCT 或跨模态场景，且评估协议中提示使用的非对称性可能影响基线公平性。当支持集增大或引入 3D 几何先验时，该混合架构的泛化边界是否扩展，论文未给出回答。
