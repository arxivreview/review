作者：Amirhosein Javadi、Tuomas Oikarinen、Tara Javidi 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.14519)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.14519)

> 类增量学习（CIL）旨在解决模型顺序学习新类别时的灾难性遗忘，但现有无样本方法多为黑盒，决策机制不可解释。本文切入点在于将概念瓶颈模型（CBM）扩展至无样本CIL（EFCIL）场景，通过概念正则化与伪概念生成机制，在保持决策透明度的同时维持增量性能。实验表明，该方法在可解释性约束下性能接近非预训练SOTA，但显著低于强预训练骨干模型，验证了可解释性与精度间的权衡。

## 研究背景

当模型在顺序数据流中更新参数时，共享参数空间的梯度更新会破坏旧类别的特征分布，导致灾难性遗忘（Catastrophic Forgetting）。在无样本（Exemplar-free）约束下，模型无法存储旧类图像，仅能依赖原型或统计量保留旧知识，这加剧了特征漂移风险。为解决此问题，概念瓶颈模型（Concept Bottleneck Model, CBM）引入中间层，将特征映射至人类可理解的概念空间，使预测成为概念的线性组合，从而实现内在可解释性。

主流CIL路线依赖正则化、重放或参数高效微调（PEFT）来平衡稳定性与可塑性，但这些方法通常将模型视为黑盒，其决策逻辑难以审计。现有可解释CIL方法如ICICLE受限于特定架构，IN2概念扩展效率低，CONCIL依赖样本级标注，且多数方法依赖强预训练骨干，模糊了CIL“学习新知识”的核心目标。本文提出CI-CBM，旨在构建首个在预训练与非预训练场景下均鲁棒的可解释CIL模型，通过自动化概念生成与增量适配机制，解决旧概念功能漂移与分类器偏差问题。

## 核心方法

### 方法参照系

CI-CBM基于无标签概念瓶颈模型（Label-free CBM, LF-CBM）框架，利用大语言模型（LLM）自动生成概念集，并通过视觉-语言模型（VLM）对齐图像与概念激活。与静态LF-CBM不同，CI-CBM需处理增量场景下的概念集扩展、旧概念功能保持及无旧数据条件下的分类器更新，核心差异在于引入了增量适配模块以解决概念漂移与分类器偏差。

### 概念正则化与增量对齐

在概念瓶颈层学习阶段，传统方法直接优化投影权重以最大化神经元激活与概念文本嵌入的相似度，但增量学习中新概念的引入会导致旧概念激活模式漂移，使其失去判别功能。CI-CBM在概念对齐损失中引入蒸馏项，约束当前阶段概念瓶颈层输出与上一阶段输出在旧概念上的相似度。设 $q_t(x)$ 为当前阶段概念激活，$q_{t-1}(x)$ 为上一阶段缓存的旧概念激活，损失函数定义为：

$$ \mathcal{L}_{align} = \sum_{j \in C_{old}} (1 - \cos(q_t(x)_j, q_{t-1}(x)_j)) + \beta \sum_{j \in C_{old}} \| q_t(x)_j - q_{t-1}(x)_j \|_2^2 $$

其中 $\beta$ 为蒸馏权重。该设计通过显式约束旧概念激活的稳定性，防止新任务学习干扰旧概念的语义功能，解决了此前可解释CIL方法中概念功能随阶段增加而退化失效的问题。

### 伪概念生成与稀疏预测

在无样本约束下，旧类数据缺失导致稀疏预测层无法获取旧类概念激活，直接训练会导致旧类权重被压缩至零，引发严重遗忘。CI-CBM提出伪概念生成机制，利用新类中心 $\mu(c_n)$ 与旧类中心 $\mu(c_p)$ 的几何关系合成旧类伪特征：

$$ \hat{f}(c_p) = f(c_n) - \mu(c_n) + \mu(c_p) $$

随后将伪特征投影至概念空间得到伪概念 $\hat{f}_c(c_p) = W_C \hat{f}(c_p)$。在训练稀疏预测层时，新类使用真实概念，旧类使用伪概念。这一机制通过几何变换模拟旧类数据分布，使稀疏预测器能在无旧数据条件下维持旧类权重的非零性，有效缓解了分类器偏差导致的旧类性能崩溃。

## 实验评估

实验在CIFAR-10/100、CUB、TinyImageNet、ImageNet-Subset、Places365及ImageNet七个数据集上进行，骨干网络包括ResNet-18、DeiT及ViT-Base/16。基线覆盖可解释方法（ICICLE, IN2, CONCIL, CLG-CBM）及非预训练EFCIL方法（FeTrIL, PASS, SSRE等）。

| 方法 | 可解释性 | CIFAR-100 (T=10) | CUB (T=10) | TinyImageNet (T=10) |
| :--- | :---: | :---: | :---: | :---: |
| IN2 | ✗ | - | 18.5 | - |
| CONCIL | ✗ | - | 9.9 | - |
| FeTrIL | ✗ | 44.6 | - | 27.8 |
| CI-CBM | ✓ | 57.0 | 65.3 | 48.7 |
| Full Rehearsal | ✓ | 63.5 | 67.2 | 50.4 |

CI-CBM在可解释性约束下显著优于其他可解释基线，且在非预训练场景下接近全重放（Full Rehearsal）上限，平均差距仅2.6%。

| 组件 | CIFAR-100 (T=10) | TinyImageNet (T=10) |
| :--- | :---: | :---: |
| 无伪概念 | 26.2 | 20.9 |
| 仅概念正则化 | 38.0 | 29.2 |
| 仅伪概念 | 16.9 | 14.4 |
| 完整CI-CBM | 68.8 | 48.7 |

消融实验显示，伪概念生成对性能提升贡献最大，单独使用概念正则化无法阻止旧类权重归零，两者结合才能实现稳定的增量性能。

评估协议采用平均增量准确率（Avg-A），未报告置信区间。代码已公开，超参数包括正则化参数 $\lambda$ 及蒸馏权重 $\beta$，但缺乏对概念生成噪声敏感性的系统分析。

## 关联研究分析

从问题动机看，CI-CBM与FeTrIL同属无样本CIL，但FeTrIL聚焦于特征空间的几何变换以保留旧类信息，而CI-CBM将操作移至概念空间，通过伪概念生成实现可解释性。这一差异源于任务目标的不同：FeTrIL追求性能最大化，允许黑盒决策；CI-CBM追求决策透明，需将特征映射至人类可理解的概念。根源在于可解释性约束要求模型内部表示具备语义对应关系，而FeTrIL的统计记忆机制无法提供这种语义锚点。

从方法设计看，CI-CBM与CLG-CBM同属概念瓶颈框架，但CLG-CBM依赖预训练ViT骨干，且概念扩展机制效率较低。CI-CBM通过LLM自动化概念生成与过滤，降低了人工标注依赖，并引入概念正则化防止漂移。差异根源在于CLG-CBM假设预训练骨干已编码足够语义，而CI-CBM需处理非预训练场景下的概念学习，因此必须引入更强的正则化机制以维持概念稳定性。

## 总结

CI-CBM旨在解决无样本CIL中可解释性与精度的矛盾，通过概念正则化与伪概念生成机制，在保持决策透明的同时维持增量性能。实验表明，该方法在可解释性约束下性能接近非预训练SOTA，平均准确率增益达36%。其边界在于依赖LLM生成的概念质量，且在强预训练骨干下性能仍显著低于黑盒SOTA，暴露了概念瓶颈层在复杂语义空间中的表达局限。当概念集规模随任务增加而线性增长时，伪概念生成的几何假设在细粒度数据集上是否依然成立，论文未给出回答。
