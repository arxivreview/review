# ICLR2026最新论文 ｜RELATIVE VALUE LEARNING ｜相对值学习

作者：Marc Höftmann、Jan Robine、Stefan Harmeling

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_82317351)

> 强化学习中的策略选择仅依赖状态间的价值差异，而非绝对数值，但传统值函数估计器仍学习带有任意偏移的绝对值，引入了冗余自由度与训练不稳定性。本文通过构建反称值差函数与成对Bellman算子，将相对差异作为原语学习目标，消除了绝对尺度自由度。该方法在Atari基准上作为PPO的替代批评器实现了与标准PPO及直接优势估计（Direct Advantage Estimation, DAE）相当的竞争力，但其理论保证依赖于有界性假设，且在长时程任务中因轨迹常数累积导致方差膨胀，限制了其在复杂环境中的泛化能力。

## 研究背景

在马尔可夫决策过程（MDP）中，策略 $\pi$ 的价值函数 $V^\pi(s)$ 由贝尔曼方程唯一确定，但对其施加任意常数偏移 $c$ 后，优势函数 $A^\pi(s,a)$ 与贪心动作选择 $\max_a Q^\pi(s,a)$ 保持不变。这种“规范自由度”（Gauge Freedom）意味着绝对值尺度在行为上是无意义的，仅相对差异具有决策价值。然而，标准值函数近似方法（如DQN、PPO）仍学习绝对值 $V^\pi(s)$，将差异视为派生量，导致模型需拟合一个行为无关的偏移量，在奖励整形或基线变化下易产生漂移。

主流路线试图通过分解或优势估计缓解此问题。Dueling Networks将 $Q$ 分解为 $V+A$，DAE直接学习优势函数以绕过值学习，但这些方法仍隐含绝对值的存在或依赖基线校正。本文的切入点是将值差 $\Delta(s_i, s_j) = V^\pi(s_i) - V^\pi(s_j)$ 作为原语学习目标，通过反称函数结构在模型层面消除偏移自由度，使批评器与决策问题的不变性对齐。

## 核心方法

### 方法参照系

标准PPO使用绝对值批评器 $V_\theta(s)$ 计算广义优势估计（Generalized Advantage Estimation, GAE），其目标为 $V^\pi(s)$。本文的关键差异在于将学习目标从绝对值 $V^\pi(s)$ 替换为成对值差 $\Delta_\theta(s_i, s_j)$，并构建相应的成对Bellman算子以支持自举训练。

### 成对Bellman算子与反称结构

标准Bellman算子作用于绝对值空间，而本文定义作用于有界反称函数空间 $\mathcal{F}$ 的算子 $\mathcal{T}^\pi$。对于状态对 $(s_i, s_j)$，算子定义为：

$$
(\mathcal{T}^\pi \Delta)(s_i, s_j) = r^\pi(s_i) - r^\pi(s_j) + \gamma \mathbb{E}_{s_i' \sim P^\pi(\cdot|s_i), s_j' \sim P^\pi(\cdot|s_j)} [\Delta(s_i', s_j')]
$$

该算子是 $\gamma$-压缩映射，其唯一不动点即为真实值差 $\Delta^\pi(s_i, s_j)$。设计动机在于消除绝对值中的规范自由度，使函数类与决策不变性对齐，避免偏移量漂移。

### 相对广义优势估计（R-GAE）

标准GAE基于绝对值计算TD残差，而R-GAE通过望远镜求和从成对差异重构相对值序列 $\tilde{V}_\theta(s_t) = \sum_{k=0}^{t-1} \Delta_\theta(s_k, s_{k+1})$，进而计算相对TD残差 $\tilde{\delta}_t = r_t + \gamma \Delta_\theta(s_{t+1}, s_t)$ 和相对优势 $\tilde{A}_t$。R-GAE与标准GAE的关系为 $\tilde{A}_t = A_t + B_t$，其中 $B_t$ 为轨迹常数。设计动机在于无需知道绝对值即可重构优势，且通过轨迹排序初始化使 $\mathbb{E}_t[B_t] \approx 0$，降低策略梯度估计方差。

## 实验评估

实验在Atari 49个游戏上进行，使用标准PPO预处理（84×84灰度、4帧堆叠、40M帧训练），基线包括PPO和DAE。PPO+RV在30/49游戏（61%）上超过PPO，在37/49游戏（75%）上超过DAE。

|---|---|---|---|
| Alien | 1850.3±376.8 | 1372.7±349.3 | 1748.8±408.7 |
| Assault | 4971.9±642.4 | 2205.1±362.3 | 3901.7±219.2 |
| BattleZone | 17 366.7±1045.0 | 16 302.0±2042.5 | 21 780.0±1516.1 |
| ChopperCommand | 3516.3±991.6 | 1587.3±423.6 | 4435.2±965.5 |
| Enduro | 758.3±31.2 | 0.0±0.0 | 1080.2±121.1 |
| Gravitar | 737.2±150.9 | 443.5±50.3 | 1441.0±561.4 |
| TimePilot | 4342.0±331.1 | 7252.7±1173.6 | 10 212.7±492.0 |
| VideoPinball | 37 389.0±15876.6 | 23 958.6±3936.0 | 138 564.8±77425.7 |

PPO+RV在BattleZone、ChopperCommand、TimePilot等游戏上显著优于基线，但在Centipede（1226.1 vs 4386.4）、Zaxxon（845.8 vs 5008.7）上大幅落后，表明相对值表示在特定游戏动态下存在拟合不足。

消融实验显示，轨迹排序初始化对性能有显著影响，但PPO裁剪目标部分缓解了轨迹常数 $B_t$ 的影响。反称线性头（无偏置向量 $w$）相比非线性MLP头未带来额外改进，表明简单结构已足够捕捉值差。

评估边界：实验限于离散动作Atari，未覆盖连续控制、离线策略评估（OPE）或偏好学习场景。计算资源为单A100 GPU，40M帧训练约65分钟，490次运行共22.10 A100-days。代码已开源，但超参数在49个游戏间保持一致，未针对特定游戏调优。

## 关联研究分析

从问题动机看，DAE直接学习优势函数 $A^\pi(s,a)$，而RV学习状态对值差 $\Delta(s_i, s_j)$。DAE的优势在于直接提供策略梯度所需的信号，但隐含绝对值的存在；RV通过反称结构消除偏移自由度，但需重构优势。两者均避免绝对值估计，但RV的理论基础更坚实（成对Bellman算子的压缩性），而DAE更依赖经验调优。

从方法设计看，Dueling Networks分解 $Q=V+A$，仍依赖绝对值 $V$；RV分解为成对差值，结构更底层。Dueling Networks的改进源于样本效率，而RV的改进源于不变性对齐。RV的轨迹排序初始化类似平均奖励MDP中的相对值迭代，但作用域为每条轨迹而非全局，这导致轨迹常数 $B_t$ 的出现，是RV与平均奖励方法的关键差异。

## 总结

本文解决的核心矛盾是值函数估计中的规范自由度与决策不变性之间的不一致。现有方法通过基线校正或优势分解缓解此问题，但仍未消除绝对值偏移；本文通过反称值差函数与成对Bellman算子，在模型层面消除偏移自由度。实验表明PPO+RV在Atari 49游戏上超过PPO 61%、DAE 75%，但在Centipede、Zaxxon等游戏上大幅落后，表明相对值表示在复杂动态下存在拟合不足。轨迹常数 $B_t$ 在长时程任务中累积导致方差膨胀，论文未给出其在连续控制或离线场景中的表现。当状态空间维度增加或时程延长时，成对训练的 $O(B^2)$ 计算复杂度与 $B_t$ 方差膨胀是否成为主要瓶颈，论文未提供量化分析。
