# ICLR2026最新论文 ｜SAVE: A Generalizable Framework for Multi-Condition Single-Cell Generation with Gene Block Attention ｜基于基因块注意力的多条件单细胞生成框架

研究机构：复旦大学

作者：Jiahao Li、Jiayi Dong、Peng Ye 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.16776)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.16776)

> 单细胞扰动建模旨在预测细胞在基因编辑或药物处理下的转录组响应，其核心价值在于将高通量测序数据转化为可计算的虚拟实验。现有方法多将基因视为独立 token，忽略了基因模块间的生物结构，导致在多条件组合下泛化能力受限。SAVE 通过 LLM 语义聚类构建基因块，结合流匹配与条件掩码策略，实现了对未见条件组合的分布生成。该框架在中小规模数据集上展现了优于基线的生成保真度，但在大规模药物扰动基准上的缺失使其泛化边界存疑。

## 研究背景

单细胞 RNA 测序（scRNA-seq）数据具有高维稀疏性，直接建模噪声困难，需在潜空间或离散 token 空间进行生成建模。变分自编码器（VAE）如 scVI 确立了潜空间对齐范式，但其线性偏移假设在复杂扰动下失效。Transformer 基础模型如 scGPT 虽能捕捉长程依赖，却采用扁平 token 化，忽略了基因调控网络中的模块结构，且缺乏显式的条件生成机制。

领域核心挑战在于非配对数据对齐与未见扰动泛化。早期方法依赖潜空间算术，受制于数据异质性；随后扩散模型与流匹配成为主流，解决了分布建模瓶颈，但多数工作聚焦于单一条件或表征学习，未能有效处理多条件（如细胞类型、疾病状态、批次）的组合交互。现有基础模型往往掩盖扰动特异性信号，导致在未见条件组合上性能下降。

SAVE 的切入点在于引入生物学先验结构。它借鉴计算机视觉中图像块的粗粒度建模思想，利用大语言模型（LLM）提取基因语义嵌入，通过最优传输聚类形成“基因块”，以此替代扁平 token。这一设计旨在捕捉基因模块间的高阶依赖，并通过条件掩码训练策略，使模型具备对缺失或未见条件组合的泛化能力，从而在保持分布保真度的同时提升多条件生成的鲁棒性。

## 核心方法

### 方法参照系

SAVE 属于生成式扰动预测路线，继承 VAE 的潜空间压缩结构与 Transformer 的注意力机制。与 scGPT 等基础模型仅做表征学习不同，SAVE 将生成任务显式整合进架构，核心差异在于将基因表达序列从扁平 token 重构为语义基因块，并采用流匹配（Flow Matching）替代传统扩散过程进行条件分布建模。

### 基因块构建与注意力机制

传统 Transformer 将每个基因视为独立 token，忽略了基因在功能上的模块化组织，导致模型难以捕捉共表达依赖。SAVE 首先利用 LLM（text-embedding-ada-002）从 NCBI 数据库提取基因的 1,536 维语义嵌入 $g_i$，随后通过迭代最优传输聚类算法，将 $G$ 个基因划分为 $L$ 个大小均衡的非重叠块。块分配被形式化为求解平衡传输计划，约束条件为 $T \mathbf{1}_L = a$ 和 $T^T \mathbf{1}_G = b$，其中 $C_{ij} = ||g_i - c_j^{[t]}||_2^2$ 为欧氏代价矩阵。

$$
\min_T \sum_{i,j} C_{ij} T_{ij} \quad \text{s.t.} \quad T \mathbf{1}_L = a, \ T^T \mathbf{1}_G = b
$$

该公式确保每个基因块内的基因在语义上高度相似，形成生物学上合理的功能模块。随后，每个块通过 MLP 投影至 $e$ 维隐藏空间，并应用标准 Transformer 块进行注意力计算。这种粗粒度表示不仅降低了计算复杂度（相比逐基因注意力提速 191 倍），更关键的是，它使模型能够直接学习基因模块间的调控关系，弥补了扁平 token 化对生物结构忽略的缺陷。

### 条件流匹配与掩码策略

在潜空间生成阶段，SAVE 采用流匹配学习从先验噪声 $x_0$ 到数据分布 $x_1$ 的连续轨迹。给定时间步 $t \in [0, 1]$，路径点定义为 $x_t = (1-t)x_0 + tx_1$，网络 $v_\theta(x_t, t, s)$ 被训练以预测瞬时速度 $u_t = x_1 - x_0$。

$$
\mathcal{L}_{FM}(\theta) = \mathbb{E}_{t \sim U[0,1], p_0(x_0), p_1(x_1)} \left[ ||v_\theta(x_t, t, s) - u_t||_2^2 \right]
$$

此损失函数通过最小化预测速度与真实速度的均方误差，使模型能够高效采样。为增强对未见条件的泛化，SAVE 引入条件掩码策略：在训练时，条件矩阵 $S$ 中的元素以概率 $p=0.6$ 被替换为 [MASK] token。这一设计迫使模型在缺乏完整条件信息时仍能推断合理的基因表达分布，从而在推理阶段灵活处理缺失或组合未见条件，解决了传统模型对固定条件组合过拟合的问题。

## 实验评估

实验在 PBMC3K、Dentate gyrus、Tabula Muris 等单条件数据集及 Heart、PBMC、Lung Atlas 等多条件数据集上进行，基线包括 scVI、CFGen 和 scDiffusion。SAVE 在生成保真度指标（WD 和 MMD）上全面领先。例如，在 Dentate gyrus 数据集上，SAVE 的 WD 降至 9.16，MMD 降至 0.17，相比次优方法 scDiffusion（WD 22.56, MMD 1.22）有显著优势。在扰动预测任务（PBMC-IFN）中，SAVE 的平均 PCC 达到 0.96，R² 为 0.86，优于 scGen（PCC 0.90, R² 0.68）和 CellOT（PCC 0.94, R² 0.84）。

| 数据集 | 方法 | WD (↓) | MMD (↓) |
| :--- | :--- | :--- | :--- |
| Dentate gyrus | scDiffusion | 22.56 | 1.22 |
| Dentate gyrus | **SAVE** | **9.16** | **0.17** |
| Heart | scDiffusion | 20.82 | 0.94 |
| Heart | **SAVE** | **8.30** | **0.63** |
| PBMC-IFN (Avg) | scGen | 0.90 (PCC) | 0.68 (R²) |
| PBMC-IFN (Avg) | **SAVE** | **0.96 (PCC)** | **0.86 (R²)** |

消融实验显示，基因块大小 $K$ 对性能影响显著。当 $K=3200$ 时，WD 达到最低值 8.30，MMD 为 0.63；而 $K=600$ 时 WD 升至 9.70。移除注意力模块后，WD 从 8.30 上升至 8.89，MMD 从 0.63 上升至 0.65，表明基因块注意力对捕捉高阶依赖至关重要。训练效率方面，$K=3200$ 时训练时间为 12.5 分钟，相比 $K=1$ 的 2391.2 分钟，实现了 191 倍加速，验证了粗粒度表示在计算效率上的优势。

评估边界方面，SAVE 未在 Tahoe-100M 等大规模药物扰动基准上验证，限制了其在高维稀疏转录组上的泛化结论。指标上，WD 和 MMD 主要反映分布距离，未涵盖基因级因果解释。可复现性良好，代码已开源，超参数统一（学习率 $1 \times 10^{-4}$，权重衰减 $2.5 \times 10^{-5}$），实验在 RTX 3090 24GB GPU 上完成。

## 关联研究分析

从方法设计看，SAVE 与 scDFM 同属流匹配架构，但特征编码策略存在根本差异。scDFM 依赖基因-基因相关掩码来编码特征，侧重于统计共表达关系；而 SAVE 利用 LLM 语义嵌入构建基因块，引入了外部生物学知识先验。这一差异源于任务特性：scDFM 旨在捕捉扰动后的动态轨迹，而 SAVE 更关注多条件组合下的静态分布生成。SAVE 的语义块构建可能引入文献偏差，对于研究不充分的基因，其嵌入质量可能下降，进而影响泛化性能，这一点在大规模未见扰动场景中尤为关键。

从问题动机看，SAVE 与 CFGen 均旨在解决条件生成问题，但 CFGen 采用最优传输引导的扩散模型，侧重于分布对齐的几何解释；SAVE 则通过条件掩码策略直接模拟缺失条件，更强调组合泛化能力。CFGen 在双条件任务上表现不如 SAVE，可能因为其引导机制在复杂条件交互下难以解耦各协变量的独立贡献。SAVE 的掩码策略通过随机丢弃条件信息，迫使模型学习条件间的互补关系，这在低资源或组合未见场景下更具优势，但其在高维数值预测精度上是否优于专用回归模型，仍需进一步验证。

## 总结

SAVE 旨在解决多条件单细胞生成中基因结构忽略与组合泛化不足的核心矛盾。现有方法如 scGPT 采用扁平 token 化，无法捕捉基因模块间的高阶依赖，且在未见条件组合下性能衰减。SAVE 通过 LLM 语义聚类构建基因块，结合流匹配与条件掩码策略，实现了从噪声到条件分布的高效采样。实验表明，SAVE 在 Dentate gyrus 数据集上 WD 降至 9.16，在 PBMC-IFN 扰动预测中平均 PCC 达 0.96，显著优于基线。然而，其基因块构建依赖 NCBI 数据库的注释完整性，对于研究不充分的基因可能产生噪声嵌入。此外，论文未在 Tahoe-100M 等大规模基准上验证，限制了其在高维稀疏数据上的泛化结论。当基因块大小 $K$ 进一步增大时，语义相似性是否仍能保持足够的区分度以捕捉细微的调控差异，论文未给出回答。
