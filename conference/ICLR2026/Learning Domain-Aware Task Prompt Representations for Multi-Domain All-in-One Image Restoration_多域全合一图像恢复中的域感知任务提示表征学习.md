# ICLR2026最新论文 ｜Learning Domain-Aware Task Prompt Representations for Multi-Domain All-in-One Image Restoration ｜多域全合一图像恢复中的域感知任务提示表征学习

研究机构：四川大学、德国慕尼黑工业大学

作者：Guanglu Dong、Chunlei Li、Chao Ren 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.01725)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.01725)

> 全合一图像恢复（AiOIR）旨在通过单一模型处理多种退化，但现有方法局限于单一图像域，跨域扩展时因任务与域特征耦合导致学习难度激增。本文切入点在于解耦任务特异性与域共性，通过双提示池机制实现跨域知识共享。具体做法是构建任务与域两个独立提示池，利用多模态大语言模型蒸馏域先验，并经自适应门控融合指导恢复。该工作验证了跨域统一建模的可行性，但单域极致性能是否受多域训练稀释仍存疑。

## 研究背景

当单一模型需同时处理自然场景去雨、医学CT去噪与遥感去云时，不同域图像的视觉统计特性差异巨大，直接共享骨干网络会导致特征空间冲突。这种冲突源于任务退化机制与域固有属性的纠缠，例如医学图像的灰度器官特征与遥感图像的俯视建筑特征在潜在空间中缺乏显式区分机制，使得模型难以在增加任务数量时保持性能稳定。

AiOIR领域已确立通过提示学习或混合专家（MoE）缓解单域内多任务干扰的范式，如PromptIR利用可学习提示编码退化信息，MoCEIR通过复杂度专家分配资源。然而，这些方法主要优化单域内的任务差异，忽视了跨域图像共享的底层视觉共性，如边缘结构或纹理分布。随着任务与域数量增加，单域方法的参数冲突从任务间扩展至域间，导致学习难度呈非线性增长。本文针对这一跨域扩展瓶颈，提出将域感知显式引入提示表征学习，以解耦任务特异性与域共性。

## 核心方法

### 方法参照系

本文问题属于退化感知与提示学习路线，但关键差异在于从单域任务提示扩展至多域双池结构。标准流程中，提示仅编码退化类型，而本文需同时编码任务类型与图像来源域，以应对跨域分布差异。

### 双提示池与自适应组合

任务提示池（TP Pool）存储任务相关键值对，输入图像经投影器生成查询向量 $Q_{task}$，通过余弦相似度检索Top-K提示值 $V_{task}$。为增强实例级多样性，引入提示组合机制（PCM），按相似度加权融合：

$$PR_t = \sum_{j \in TopK} \alpha_j V_{task}^j, \quad \alpha_j = \frac{\exp(s_j / T_{task})}{\sum_{k \in TopK} \exp(s_k / T_{task})}$$

该公式将离散提示选择转化为连续加权表征，解决了固定提示无法适应同一任务内不同图像内容变化的问题。

### 域先验蒸馏与跨模态对齐

域提示池（DP Pool）独立存储域相关知识。利用LLaVA-1.5-7B生成高质量图像的文本描述，经CLIP文本编码器提取特征 $F_{text}$，通过交叉熵损失对齐域提示值：

$$L_{align} = -\frac{1}{B} \sum_{i=1}^{B} \log \frac{\exp(sim(V_{dom}^i, F_{text}^i) / \tau)}{\sum_{j=1}^{B} \exp(sim(V_{dom}^i, F_{text}^j) / \tau)}$$

此设计将多模态语义先验注入域提示，使模型无需显式分类标签即可感知域属性，解决了传统方法中域特征与内容特征耦合导致的泛化不足。最终，$PR_t$ 与 $PR_d$ 经交叉注意力融合为域感知任务表征 $PR_{dt}$，并通过自适应门控融合（AGF）动态控制各层骨干特征与提示的融合比例。

## 实验评估

实验覆盖3域6任务与3域9任务设置，基线包括单任务SOTA（SwinIR, Restormer）与全合一方法（PromptIR, MoCEIR, AdaIR）。缺失MiM-DiT、LucidFlux等2025-2026年最新SOTA，且未与单域极致性能模型直接对比。

DATPRL-IR-6T在平均PSNR上领先PromptIR 0.33 dB，在医学CT去噪任务上较MoCEIR提升2.54 dB，表明域感知提示在跨域任务上具有显著优势。

消融实验显示，同时使用任务与域提示池较单池提升1.22 dB（去雨）、0.10 dB（CT去噪）与0.27 dB（遥感SR）。提示数量从10增至15时，平均PSNR从30.44升至30.77，但增至20时降至30.73，表明提示池规模存在边际收益递减点。

评估仅使用PSNR/SSIM，缺乏LPIPS等感知指标；训练依赖NVIDIA RTX 5090 GPU，1000K迭代耗时较长；代码已开源，但LLaVA与CLIP在推理阶段不参与计算，无额外延迟。

## 关联研究分析

从问题动机看，本文与PromptIR同属提示学习路线，但PromptIR聚焦单域内退化类型区分，而本文解决跨域分布差异导致的特征冲突。这一差异源于任务特性：单域内退化机制相对同质，提示仅需编码退化类型；跨域时图像固有属性（如医学灰度、遥感俯视）成为主要干扰源，需显式域感知。本文通过MLLM蒸馏域先验，将域信息从隐式学习转为显式注入，这是PromptIR未探索的维度。

从方法设计看，本文与MoCEIR形成对比：MoCEIR通过专家路由分配任务资源，本文通过提示池组合共享知识。MoCEIR的专家独立性可能导致跨域知识隔离，而本文的双池融合机制允许任务与域知识交叉影响。这种设计选择源于对“共享共性”的假设：不同域图像在底层视觉特征上存在重叠，如边缘结构。若该假设不成立，域提示池可能引入噪声而非增益，论文未对此进行敏感性分析。

## 总结

本文核心矛盾在于多域扩展时任务与域特征耦合导致的学习难度激增。切入点在于解耦任务特异性与域共性，利用MLLM蒸馏域先验实现显式域感知。方法通过双提示池与自适应门控融合，在3域6任务设置下平均PSNR达30.77 dB，较PromptIR提升0.33 dB。边界在于实验仅覆盖3域，未验证更多域或更复杂混合退化下的泛化能力；且单域性能是否受多域训练稀释，论文未提供单域独立训练对照实验。当域数量从3扩展至5以上时，域提示池的容量与蒸馏质量是否仍能支撑有效域感知，论文未给出回答。
