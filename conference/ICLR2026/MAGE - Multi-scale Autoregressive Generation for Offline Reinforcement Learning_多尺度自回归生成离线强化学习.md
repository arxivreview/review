# ICLR2026最新论文 ｜MAGE: Multi-scale Autoregressive Generation for Offline Reinforcement Learning ｜多尺度自回归生成离线强化学习

研究机构：厦门大学、香港科技大学

作者：Chenxing Lin、Xinhui Gao、Haipeng Zhang 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.23770)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.23770)

> 离线强化学习（Offline RL）旨在从固定历史数据中学习策略，其核心瓶颈在于长时程稀疏奖励任务中，生成式模型难以维持轨迹的全局一致性。现有自回归或扩散方法往往陷入“局部合理但全局断裂”的困境，而固定层级的分层方法又因策略耦合导致优化困难。MAGE 借鉴视觉领域的多尺度自回归思想，通过粗到细的层级 Token 生成机制，在单一模型内解耦长程规划与短程执行。该方法在 Adroit 等长时程基准上显著优于现有生成式基线，但其对数据覆盖稀疏区域的鲁棒性缺乏显式约束，且在密集奖励任务上的优势幅度有待进一步验证。

## 研究背景

当智能体在长时程任务中执行动作序列时，单步决策的误差会随时间步累积，导致最终轨迹偏离目标。这一现象源于离线数据中状态-动作对的分布偏移，使得标准值函数在未见过的状态上产生过估计。为缓解此问题，生成式方法将策略学习转化为轨迹分布建模，试图直接生成符合数据分布的完整轨迹。然而，传统的自回归 Transformer 受限于单向注意力，难以捕捉长程依赖；扩散模型虽能并行生成，但存在局部生成偏差，导致轨迹在长时程上缺乏全局连贯性。

生成式离线强化学习的主流路线包括基于 Transformer 的自回归生成（如 Decision Transformer）和基于扩散模型的轨迹生成（如 Decision Diffuser）。前者在密集奖励任务中表现稳定，但在稀疏奖励长时程任务中因缺乏全局视野而失效；后者虽能捕捉多模态分布，但去噪过程的局部性导致轨迹在宏观结构上出现断裂。分层生成方法（如 HDMI）试图通过高层子目标与低层动作的解耦来解决此问题，但其固定两层结构引入了两个独立策略的联合优化难题，且无法灵活适应不同时间尺度的任务需求。MAGE 的切入点在于，摒弃固定层级的多策略架构，转而采用单一模型内的多尺度 Token 自回归生成，将长时程轨迹分解为从粗到细的层级表示，从而在保持自回归效率的同时，显式建模多尺度时间依赖。

## 核心方法

### 多尺度轨迹自编码器

MAGE 的参照系是标准的向量量化变分自编码器（VQ-VAE），其通常将输入映射为单一尺度的离散 Token 序列。本文的关键差异在于，将单一尺度扩展为多尺度层级结构，以捕捉轨迹在不同时间分辨率下的特征。轨迹 $\tau$ 被表示为状态与回报至终点（Return-to-Go, RTG）对的序列 $\tau = \{(R_i, s_i)\}_{i=0}^T$。多尺度轨迹自编码器（MTAE）通过预定义的时间尺度调度 $[l_k]_{k=1}^K$，将轨迹编码为从粗到细的 Token 映射集 $\mathcal{M} = (m_1, m_2, \dots, m_K)$。其中，$m_1$ 捕捉最粗粒度的全局结构，$m_K$ 包含最细粒度的局部细节。编码过程采用残差量化机制，每一层 $k$ 的 Token 映射 $m_k$ 通过对前一层残差进行下采样和量化获得：

$$ m_k = Q(\text{Scale\_down}(f, l_k)), \quad f = f - \text{Scale\_up}(\text{Lookup}(C, m_k), l_K) $$

该公式的物理含义是，每一层 Token 仅编码当前尺度下未被前序粗尺度解释的残差信息，从而确保各尺度 Token 携带互补而非冗余的时间依赖信息。这种设计解决了单一尺度模型在长时程任务中因信息压缩过度而丢失全局结构的问题。

### 多尺度条件引导自回归生成

在获得多尺度 Token 映射后，MAGE 采用多尺度 Transformer 进行自回归生成。传统自回归模型在生成第 $k$ 个 Token 时仅依赖前序 Token，缺乏对全局目标的显式约束。MAGE 引入条件引导机制，将初始状态 $s_0$ 和初始 RTG $R_0$ 作为全局条件，注入每一尺度的生成过程。生成概率分解为：

$$ p(\mathcal{M} | s_0, R_0) = \prod_{k=1}^K p(m_k | m_{<k}, s_0, R_0) $$

此公式表明，每一尺度 $k$ 的 Token 映射 $m_k$ 的生成不仅依赖于更粗尺度的前序映射 $m_{<k}$，还直接受初始条件 $(s_0, R_0)$ 的约束。这种层级条件化设计解决了自回归生成中常见的“漂移”问题，即生成轨迹在长时程上逐渐偏离初始目标状态。此外，MAGE 在解码器中集成条件引导适配器，通过最小化解码初始状态与真实初始状态 $(s_0, R_0)$ 之间的均方误差损失 $\mathcal{L}_{cond}$，进一步确保生成轨迹在起点处的精确匹配，弥补了量化过程中的信息损失。

## 实验评估

实验在 Adroit、Franka Kitchen、AntMaze、Maze2D 和 Multi2D 五个基准上进行，对比了包括 BC、CQL、IQL、DT、DD、HDMI、HD 等在内的 15 种基线方法。基线覆盖了非生成式、生成式和分层生成式三大路线，但缺失了 TD3+BC 等策略约束类强基线，以及最新的离线到在线（O2O）混合方法。在 Adroit 稀疏奖励任务中，MAGE 表现突出，尤其在 Pen-Expert 场景下得分 147.8，显著高于 HDMI 的 109.5 和 DD 的 107.6。

| 场景 | IQL | DT | HDMI | HD | MAGE |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Pen-Expert | 128.0±9.2 | 116.3±1.2 | 109.5±8.0 | 121.4±14.3 | **147.8±4.9** |
| Door-Cloned | 3.0±1.7 | 7.6±3.2 | 9.3±1.6 | 4.5±3.6 | **20.5±2.5** |
| Hammer-Cloned | 1.5±0.6 | 1.8±0.5 | 1.0±0.1 | 0.9±0.2 | **13.2±4.7** |
| Kitchen-Partial | 59.7±8.3 | 31.4±19.5 | - | 73.3±1.4 | **91.3±3.2** |
| AntMaze-U-maze | 70.6±3.7 | 51.7±0.4 | - | 94.0±4.9 | **95.2±2.2** |

消融实验揭示了多尺度数量 $K$ 的关键作用。在 Pen-Expert 任务中，$K$ 从 2 增加到 8 时，性能从 127.5 提升至 147.8，但 $K=10$ 时性能下降至 149.9（注：原文数据 $K=8$ 为 147.8，$K=10$ 为 149.9，此处需仔细核对原文表格，原文 Table 5 显示 $K=8$ 为 147.8，$K=10$ 为 149.9，但文字描述称“beyond this point... performance declines”，可能存在数据记录或描述不一致，此处以表格数值为准，但需指出文字与数据的潜在矛盾）。实际上，原文 Table 5 显示 $K=8$ 为 147.8，$K=10$ 为 149.9，数值上 $K=10$ 略高，但文字描述称性能下降，这可能源于标准误差或特定子任务的波动。此外，轨迹生成方案中，建模 $(R, S)$ 优于 $(R, S, A)$，表明显式建模动作序列引入了不必要的复杂性，反而阻碍了性能提升。

评估边界方面，MAGE 的推理速度为 27.30 ms/step，虽快于 HD（1480.21 ms）和 DD（2339.16 ms），但慢于 DT（6.49 ms）。实验未报告计算效率与性能的权衡指标，且未在数据覆盖极稀疏的 OOD 场景下进行鲁棒性测试。代码已开源，但超参数配置对多尺度数量 $K$ 的敏感性未详细披露，可能影响复现性。

## 关联研究分析

从问题动机看，MAGE 与 HDMI 的核心差异在于层级结构的灵活性。HDMI 采用固定两层扩散策略，高层生成子目标，低层生成动作，这种刚性结构导致两个策略需联合优化，且在任务时间尺度变化时适应性差。MAGE 通过多尺度 Token 自回归，将层级结构内化于单一 Transformer 中，避免了多策略耦合，但代价是增加了序列长度和计算复杂度。这种设计选择源于对长时程任务中时间尺度多样性的假设，即不同子任务需要不同粒度的时间抽象。然而，MAGE 未显式引入保守约束，其性能提升主要依赖于生成模型对数据分布的拟合，而非对 OOD 动作的惩罚。这与 CQL 等保守价值学习路线形成对比，后者通过惩罚 OOD 动作确保安全性，但牺牲了表达力。MAGE 在稀疏奖励任务上的优势可能部分源于其生成轨迹更贴近数据支持集，而非显式的保守机制。

从方法设计看，MAGE 借鉴了视觉自回归模型（VAR）的层级概率分解思想，将其从空间尺度迁移至时间尺度。VAR 通过多空间尺度 Token 映射捕捉图像的全局结构，MAGE 则通过多时间尺度 Token 映射捕捉轨迹的全局动态。这一迁移的关键挑战在于，时间序列的因果性与空间序列的对称性不同，MAGE 通过条件引导机制（$s_0, R_0$）弥补了这一差异。然而，MAGE 未探索多尺度机制在非平稳环境下的适应性，其假设环境动态固定，这与 O2O 方法试图通过在线交互适应动态环境的路径形成对比。MAGE 的纯离线范式在数据覆盖不足时可能产生幻觉轨迹，而 O2O 方法通过在线反馈修正，但面临稳定性与可塑性的平衡难题。

## 总结

MAGE 旨在解决长时程稀疏奖励任务中生成式轨迹的全局一致性缺失问题。现有自回归方法受限于单向注意力，扩散方法存在局部偏差，而固定层级分层方法因策略耦合导致优化困难。MAGE 通过多尺度 Token 自回归生成，在单一模型内解耦长程规划与短程执行，并引入条件引导机制确保初始状态匹配。实验表明，MAGE 在 Adroit Pen-Expert 任务上得分 147.8，显著优于 HDMI 的 109.5，验证了多尺度建模的有效性。然而，MAGE 未显式引入保守约束，且在密集奖励任务上的优势幅度小于稀疏奖励任务，其多尺度机制在数据覆盖极稀疏区域的鲁棒性未得到充分验证。当离线数据覆盖范围极度狭窄时，多尺度自回归生成是否会产生偏离数据支持集的幻觉轨迹，论文未给出回答。
