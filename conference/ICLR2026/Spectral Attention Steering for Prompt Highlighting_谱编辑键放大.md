# ICLR2026最新论文 ｜Spectral Attention Steering for Prompt Highlighting ｜谱编辑键放大

研究机构：英国爱丁堡大学、英国伦敦玛丽女王大学

作者：Weixian Waylon Li、Yuchen Niu、Yongxin Yang 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.01281)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.01281)

> 注意力引导旨在通过干预模型内部机制，使特定提示词获得更高的注意力权重，从而解决长上下文中关键信息被忽略的问题。现有主流方法如 PASTA 需在注意力矩阵计算后对其进行修改，导致无法兼容 FlashAttention 等高效推理架构，且存在高昂的显存与延迟开销。本文切入点在于将干预位置前移至注意力计算之前，直接编辑 Key 向量。通过谱分解学习相关性子空间并施加投影放大，SEKA 实现了与高效注意力机制兼容的无训练引导。该方法在标准基准上显著优于基线，但其对模型内部检索头分布的依赖及跨模型泛化能力仍存疑。

## 研究背景

理解本文需厘清注意力机制中 Query 与 Key 的交互逻辑。在多头注意力中，注意力分数由 Query 向量与 Key 向量的内积决定，即 $Attn(i, j) = \frac{q_i^\top k_j}{\sqrt{d_k}}$。若需提升特定 Token $j$ 的注意力权重，直接修改已计算的注意力矩阵是直观但低效的手段，因为它要求显式存储 $O(N^2)$ 的矩阵。另一种思路是修改参与内积计算的向量本身，即编辑 Key 向量 $k_j$，使其在几何空间中更靠近 Query 的方向，从而在不触碰注意力矩阵的前提下改变注意力分布。

注意力引导领域长期面临效率与效果的权衡。以 PASTA 为代表的后处理方法通过缩放注意力矩阵行来突出高亮 Token，但其架构缺陷在于必须完整计算并存储注意力矩阵，这与现代 IO 感知的 FlashAttention 实现根本不兼容。此外，PASTA 依赖耗时的任务特定搜索来确定需干预的注意力头，进一步限制了其部署实用性。本文针对这一瓶颈，提出在注意力计算前对 Key 向量进行谱编辑，旨在以极低的计算开销实现 Token 级注意力引导，同时保持与高效推理引擎的完全兼容。

## 核心方法

### 方法参照系

本文问题属于推理时干预范式，但干预对象从 MLP 层激活转向注意力 Key 向量。与基于线性表示假设的激活引导不同，本文假设相关性在 Key 空间存在结构化子空间，需通过谱分解提取投影方向，而非简单的向量加法。

### 谱学习相关性对齐投影

离线阶段，SEKA 利用对比提示（中性、正相关、负相关）提取 Key 嵌入，计算交叉协方差矩阵 $\Omega^+_{\ell,h} = h_n^\top h^+$ 和 $\Omega^-_{\ell,h} = h_n^\top h^-$。通过奇异值分解（SVD）获取投影方向，正投影 $P^+_{\ell,h}$ 选取最大奇异值对应的左奇异向量，负投影 $P^-_{\ell,h}$ 选取最小奇异值对应的方向。这一设计动机在于，最大奇异值方向捕捉了与相关性最相关的特征，而最小奇异值方向则对应最不相关的特征，从而构建出具有几何可解释性的相关性子空间。

$$
\mathbf{k}'_j = \mathbf{k}_j + g^+ \mathbf{P}^+_{\ell,h} \mathbf{k}_j - g^- \mathbf{P}^-_{\ell,h} \mathbf{k}_j
$$

该公式表明，编辑后的 Key 向量是原始向量与两个投影分量的线性组合，其中 $g^+, g^-$ 为独立可调的增益系数。通过放大相关性子空间分量并抑制非相关性分量，SEKA 在几何上拉近了高亮 Token 的 Key 与 Query 的距离，从而提升注意力分数。

### 查询自适应专家路由

AdaSEKA 扩展了 SEKA 的静态投影，引入多专家机制。每个专家 $m$ 针对特定任务（如事实回忆、指令遵循）学习独立的 SVD 分量。推理时，提取提示词最后一个 Token 的 Query 向量 $q_{\ell,h}$，计算其与各专家投影方向的对齐度，生成动态系数 $\alpha_{m,\ell,h}$。最终投影矩阵 $P_{dynamic}$ 为专家投影的加权和。这一设计解决了静态投影在不同任务间需手动调参的问题，通过查询感知路由自动选择最相关的专家子空间，实现了输入依赖的自适应控制。

$$
\mathbf{P}_{dynamic,\ell,h}(q_{\ell,h}) = \sum_{m=1}^{M} \alpha_{m,\ell,h}(q_{\ell,h}) \cdot \mathbf{U}^+_{m,\ell,h,:K} (\mathbf{U}^+_{m,\ell,h,:K})^\top
$$

该公式表明，动态投影矩阵由前 $K$ 个主奇异向量重构，权重由 Query 与专家方向的对齐度决定。这种机制不仅减少了超参数调优负担，还允许新专家模块化集成，无需重新计算现有投影。

## 实验评估

实验在 CounterFact、Bias in Bios 和 Pronouns 三个标准基准上进行，基线包括原始模型、标记模型、PASTA 和 SPA。SEKA 和 AdaSEKA 在 Qwen3 和 Gemma3 系列模型上均显著优于 PASTA。例如，在 Qwen3-4B 的 CounterFact 任务上，SEKA 的 Efficacy Score (ES) 达到 99.02，而 PASTA 仅为 89.58；在 Gemma3-4B 上，SEKA 的 ES 为 98.04，PASTA 为 82.58。

| 模型 | 任务 | 指标 | SEKA | PASTA |
|---|---|---|---|---|
| Qwen3-4B | CounterFact | ES | 99.02 | 89.58 |
| Qwen3-4B | CounterFact | PS | 94.96 | 82.94 |
| Gemma3-4B | CounterFact | ES | 98.04 | 82.58 |
| Gemma3-4B | CounterFact | PS | 95.14 | 91.00 |

消融实验显示，移除谱学习（使用随机投影）导致性能大幅下降，如 Qwen3-4B CounterFact ES 从 99.02 降至 92.38，证实了谱分解提取相关性子空间的必要性。移除头筛选机制后，性能进一步下降，表明选择性干预中后层检索头对避免非目标能力退化至关重要。

评估边界方面，论文未报告置信区间，且仅在 Qwen3 和 Gemma3 系列上验证，缺乏跨架构泛化性测试。代码未公开，超参数 $\delta_{min}$ 和 $\gamma$ 的网格搜索范围有限，可复现性依赖附录细节。

## 关联研究分析

从问题动机看，SEKA 与 PASTA 的核心差异在于干预时机。PASTA 在注意力矩阵计算后修改分数，导致必须显式存储矩阵，与 FlashAttention 不兼容；SEKA 在 Key 向量层面编辑，避免了矩阵存储，实现了架构兼容。这一差异源于任务特性：注意力引导需实时处理长上下文，后处理方法的 $O(N^2)$ 显存开销成为瓶颈，而 Key 编辑仅需 $O(N)$ 计算，更适合高效推理场景。

从方法设计看，SEKA 与基于 MLP 层激活引导的方法（如 CAA）不同，后者假设高层语义在残差流中线性可分，通过向量加法控制行为；SEKA 假设相关性在 Key 空间存在结构化子空间，通过谱投影放大特定方向。这一差异暗示 Key 空间可能比 MLP 层更具局部性和 Token 特异性，适合细粒度注意力控制，但论文未直接对比 Key 编辑与 MLP 引导在相同任务上的效果，无法判断哪种干预位置更鲁棒。

## 总结

SEKA 解决了注意力引导与高效推理架构不兼容的核心矛盾，通过谱编辑 Key 向量实现了 FlashAttention 兼容的 Token 级引导。其切入点在于将干预前移至注意力计算之前，利用谱分解提取相关性子空间，避免了后处理方法的显存瓶颈。实验证明 SEKA 在标准基准上显著优于 PASTA，如 Qwen3-4B CounterFact ES 达 99.02，且延迟仅 0.03s。然而，论文仅在 Qwen3 和 Gemma3 系列上验证，缺乏跨架构泛化性测试，且未直接对比 Key 编辑与 MLP 层引导的效果。当模型架构变化时，Key 空间的相关性子空间是否保持稳定，论文未给出回答。
