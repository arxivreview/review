# ICLR2026最新论文 ｜VCWorld: A Biological World Model for Virtual Cell Simulation ｜生物世界模型：基于知识图谱与LLM推理的虚拟细胞模拟器

研究机构：上海交通大学

作者：Zhijian Wei、Runze Ma、Zichen Wang 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.00306)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.00306)

> 单细胞扰动建模的核心困境在于，现有生成式模型虽能拟合分布，却因依赖海量配对数据而难以泛化至未见扰动，且作为黑盒无法提供可验证的机制解释。VCWorld 切入这一盲区，将全转录组回归任务重构为基因级二分类，通过构建开放世界生物知识图谱并驱动大语言模型进行链式推理，实现数据高效且可解释的预测。该范式在低数据场景下展现了超越传统生成模型的分类精度，但其牺牲了连续表达值的预测能力，且缺乏与主流生成式模型在统一回归指标下的公平对比。

## 研究背景

单细胞扰动预测面临数据非配对与高维稀疏的双重约束。RNA-seq 的破坏性导致扰动前后细胞无法一一配对，传统监督学习失效，必须转向分布建模。然而，基因表达数据的高维稀疏性使得直接建模噪声困难，主流方案如变分自编码器（VAE）和扩散模型需在潜空间或离散 token 空间进行生成，以捕捉细胞群体内的响应异质性。

主流生成式路线（如 CPA、scDFM）通过解耦潜空间或流匹配实现分布对齐，但在未见扰动泛化上受制于训练数据的覆盖范围，且缺乏因果机制解释。LLM 智能体推理路线（如 PertReason、AROMA）试图通过知识整合提升可解释性，但早期方法多依赖纯文本检索，缺乏结构化生物知识的接地。VCWorld 的切入点在于将 LLM 推理与结构化生物知识图谱（KG）深度耦合，通过符号化节点特征和图引导的证据检索，解决黑盒模型在数据效率与机制透明度上的双重短板。

## 核心方法

### 任务重构与参照系

传统扰动预测定义为从对照表达 $x$ 和扰动 $p$ 到扰动后表达 $y$ 的回归映射 $f: \mathbb{R}^d \times P \rightarrow \mathbb{R}^d$。VCWorld 将其重构为基因中心分类任务，预测单元为三元组 $(c, p, g)$，输出二元标签 $l \in \{0, 1\}$，分别对应差异表达（DE）和方向变化（DIR）。这一重构规避了高维稀疏回归的数值不稳定性，将问题转化为基于生物知识的逻辑推理。

### 知识图谱符号化表征

设计动机：静态嵌入无法捕捉生物实体间的复杂语义关系，导致 LLM 缺乏对分子机制的深层理解。VCWorld 整合 PubChem、DrugBank、Reactome 等数据库构建异质知识图谱 $G=(V, E, R)$。对于节点 $v$，提取 $k$-hop 邻域子图 $N_k(v)$，通过模板函数 $f_{prompt}$ 序列化为自然语言查询，再由 LLM 生成符号化描述 $d_v$：

$$ d_v = L(f_{prompt}(v, N_k(v))) $$

该公式将图拓扑结构转化为富含生物语义的文本特征，为后续检索提供比数值向量更丰富的上下文信息。

### 图引导因果证据检索

设计动机：纯语义检索易受表面相似性干扰，忽略生物通路间的结构性关联。VCWorld 引入混合相似度评分，结合语义余弦相似度与图路径结构相似度：

$$ Sim(q_{input}, q_i) = \alpha \cdot Sim_{sem}(d_{q_{input}}, d_{q_i}) + (1-\alpha) \cdot Sim_{struct}(q_{input}, q_i) $$

其中 $\alpha$ 平衡语义与结构权重。基于此评分，检索两个不相交子集：正例类比集 $S_{analog}$（标签为 1）和负例对比集 $S_{contrast}$（标签为 0）。最终证据集 $S(q_{input}) = S_{analog} \cup S_{contrast}$ 为 LLM 提供平衡的实证基础，强制模型在推理时区分相似但结果不同的生物案例。

## 实验评估

实验基于从 Tahoe-100M 构建的 GeneTAK 基准，包含 5 种细胞系和 348 种药物扰动，采用 3:7 的训练/测试划分以模拟少样本场景。基线包括 scVI、CPA、STATE 和 GAT，但缺失 scDFM、scPPDM 等最新生成式 SOTA，导致无法在统一回归指标下直接对比。

| 模型 | DE Accuracy (Avg) | DIR Accuracy (Avg) | DE F1 (Avg) |
| :--- | :--- | :--- | :--- |
| RANDOM | 0.50 | 0.50 | - |
| CPA | 0.21 | 0.19 | 0.03 |
| STATE | 0.30 | 0.51 | 0.16 |
| scVI | 0.61 | 0.42 | 0.21 |
| VCWorld (Gemini-2.5-Flash) | 0.68 | 0.68 | 0.62 |

VCWorld 在 DE 和 DIR 任务上均显著优于基线，其中 Gemini-2.5-Flash 版本在 DE 任务上达到 0.68 的平均准确率，F1 分数为 0.62，远超 STATE 的 0.16。消融实验显示，移除生物上下文（Biocontext）导致性能大幅下降（如 C32 细胞系 DE 从 0.70 降至 0.52），证实了知识图谱接地的关键作用；而移除链式思维（CoT）仅造成轻微下降，表明结构化检索比推理路径对最终预测的贡献更直接。

评估边界方面，GeneTAK 仅评估基因级二分类，未涉及全转录组分布保真度或剂量-响应连续性。论文未报告计算效率指标，且 LLM 推理的延迟和成本未纳入考量。代码已公开，但超参数 $\alpha$ 的敏感性分析缺失，限制了方法的可复现性细节。

## 关联研究分析

从问题动机看，VCWorld 与 PertReason 同属 LLM 推理路线，但 PertReason 侧重通过监督微调（SFT）和组相对策略优化（GRPO）灌输生物知识，而 VCWorld 依赖外部知识图谱的动态检索。这一差异源于任务定义：PertReason 处理的是更通用的机制推理，而 VCWorld 聚焦于特定扰动下的基因响应分类，后者对结构化知识的依赖更强。从方法设计看，VCWorld 与 AROMA 均使用检索增强，但 AROMA 整合多模态架构和拓扑表示，VCWorld 则通过 LLM 生成符号化特征替代数值嵌入。这种设计选择牺牲了数值精度以换取语义丰富性，但在数据稀疏场景下，符号化特征可能比数值向量更具鲁棒性，尽管论文未提供数据充足时的对比证据。

## 总结

VCWorld 针对黑盒模型在数据效率与可解释性上的矛盾，通过知识图谱符号化与 LLM 链式推理，在 GeneTAK 基准上实现了 DE 任务 0.68 的准确率和 0.62 的 F1 分数，显著优于传统生成模型。其边界在于将回归任务简化为分类，丢失了连续表达值的预测能力，且缺乏与主流生成式模型在统一指标下的公平对比。当训练数据规模扩大至全转录组回归任务时，LLM 推理的数值精度是否仍能维持优势，论文未给出回答。
