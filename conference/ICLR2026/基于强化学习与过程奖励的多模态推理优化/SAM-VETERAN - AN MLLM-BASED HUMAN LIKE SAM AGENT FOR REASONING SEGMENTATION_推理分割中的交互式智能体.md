# ICLR2026最新论文 ｜SAM-VETERAN: AN MLLM-BASED HUMAN LIKE SAM AGENT FOR REASONING SEGMENTATION ｜推理分割中的交互式智能体

作者：Tianyuan Du、Haopeng Li、Zhen Fan 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_15375461)

> 推理分割要求模型根据复杂文本查询生成像素级掩码，现有方法要么依赖监督微调导致泛化差，要么仅单次调用分割模型而忽略迭代精化潜力。SAM-Veteran 将多模态大模型（MLLM）建模为具备“文本接地”与“掩码理解”能力的智能体，通过多任务强化学习框架统一了边界框生成、迭代点精化与自适应终止三个环节。该工作证明了交互式控制能显著提升域外性能，但其对分割模型（SAM）的强依赖及迭代带来的计算开销，限制了其在实时场景下的适用性。

## 研究背景

当 MLLM 面对“穿红衣的人手中的物体”这类查询时，直接生成掩码往往因缺乏细粒度视觉定位能力而失效。这引出了推理分割任务：它不依赖预定义类别标签，而是通过逻辑推理将文本查询映射到像素区域。该任务的核心难点在于，MLLM 擅长语义理解但缺乏像素级定位精度，而分割模型（如 SAM）擅长像素操作但缺乏语义推理能力。如何弥合这一“语义-像素”鸿沟，是构建智能视觉助手的关键。

主流解决方案分为两类：监督微调（SFT）与强化学习（RL）。SFT 方法（如 LISA, PixelLM）通过训练可学习的分割头将 MLLM 与分割模块端到端耦合，但存在灾难性遗忘通用推理能力且域外泛化差的问题。RL 方法（如 Seg-Zero, SAM-R1）通过奖励信号优化 MLLM 生成边界框或点，但多数方法将 MLLM 与 SAM 解耦训练，或仅进行单次前向传播，未能利用 SAM 支持交互式迭代精化的特性。SegAgent 虽尝试模仿人类交互，但依赖外部 MLLM 生成初始框且缺乏自适应终止机制。SAM-Veteran 的切入点在于：将 MLLM 本身训练为“熟练的 SAM 用户”，在一个统一的 RL 框架内同时掌握定位、评估与修正能力。

## 核心方法

### 方法参照系

本文问题可归类为基于 MLLM 的工具集成推理。标准流程是 MLLM 生成视觉提示（Box/Point）输入分割模型，获取掩码后输出答案。本文的关键差异在于：将单次生成扩展为“生成-评估-修正”的闭环迭代，并将分割模型（SAM）的输出质量直接作为 RL 奖励信号，而非仅依赖最终答案的正确性。

### 多任务强化学习框架

设计动机在于解决单一任务奖励信号稀疏且无法区分“定位错误”与“精化失败”的问题。SAM-Veteran 基于组相对策略优化（GRPO）构建多任务框架，包含文本接地、掩码理解与辅助任务。文本接地任务优化边界框 $b$，使其最大化 SAM 生成的掩码与真值的交并比（IoU）。掩码理解任务要求模型判断当前掩码 $M$ 是否满意，若不满意则生成正/负点 $(p_+, p_-)$ 以改进掩码。奖励函数 $R$ 综合了格式奖励、SAM 掩码 IoU 奖励 $R_{SAM}$ 以及决策奖励 $R_{DCS}$。对于掩码理解任务，若模型正确判断“需精化”并生成有效点，或正确判断“已满意”并终止，则获得决策奖励。

$$
R_{total} = R_{format} + \lambda_1 R_{SAM} + \lambda_2 R_{DCS} + \lambda_3 R_{\Delta}
$$

该公式表明，模型不仅被鼓励生成高 IoU 的掩码，还被鼓励做出正确的“继续/终止”决策，从而避免无效迭代或过早停止。

### 自适应终止与动态采样

设计动机在于解决迭代过程中模型可能陷入无限循环或过早终止的稳定性问题。SAM-Veteran 引入自适应终止机制：当模型输出 $(null, null)$ 时，表示掩码已满足要求，流程结束。为防止训练不稳定，框架引入了源自 DAPO 的动态采样策略，根据样本难度调整采样概率。此外，辅助任务通过人工构造带有随机假阳性/假阴性的损坏掩码，训练模型识别缺陷中心，增强了掩码理解的鲁棒性。

$$
a_t = \begin{cases}
(p_+, p_-) & \text{if } IoU(M_t, M_{GT}) < \tau \\
(null, null) & \text{if } IoU(M_t, M_{GT}) \ge \tau
\end{cases}
$$

该逻辑定义了动作空间，模型需学习隐式的阈值 $\tau$，通过比较当前掩码质量与预期质量来决定是否继续迭代，实现了类似人类用户的“满意即停”行为。

## 实验评估

实验在 ReasonSeg、RefCOCO 系列等域内与域外基准上进行，基线覆盖 SFT（LISA, PixelLM）与 RL（SegAgent, SAM-R1, Seg-Zero）路线。缺失纯 SFT 的最新 SOTA 对比，但覆盖了主要的交互式 RL 方法。

| 方法 | ReasonSeg val (gIoU) | ReasonSeg test (gIoU) | RefCOCO testA (cIoU) | RefCOCO+ testA (cIoU) | RefCOCOg test (cIoU) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Qwen2.5-VL+SAM2 | 57.2 | 53.0 | 76.1 | 71.4 | 64.8 |
| SegAgent | 64.5 | 62.0 | 80.3 | 75.5 | 74.6 |
| SAM-R1 | 62.6 | 55.8 | 79.2 | 74.7 | 73.1 |
| **SAM-Veteran** | **68.2** | **62.6** | **80.8** | **76.6** | 73.4 |

SAM-Veteran 在域外数据集 ReasonSeg 上显著领先，gIoU 达到 68.2，较 SegAgent 提升 3.7 个点，表明迭代精化在复杂查询中有效。但在域内 RefCOCOg 上，其 cIoU (73.4) 略低于 SegAgent (74.6)，暗示迭代机制在几何结构简单的任务上可能引入额外误差或计算冗余。

| 消融项 | ReasonSeg val | ReasonSeg test | RefCOCO testA | Avg. | 终止行为 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 仅文本接地 (TG) | 62.4 | 62.1 | 79.3 | 70.3 | Arbitrary |
| TG + 掩码理解 (MC) | 67.4 | 62.5 | 80.6 | 72.1 | Never |
| TG + MC + 辅助 (A) | **68.2** | **62.6** | **80.8** | **72.2** | **Adaptive** |

消融实验显示，仅使用文本接地任务时，模型终止行为随机；加入掩码理解后，性能提升但模型倾向于“永不终止”；引入辅助任务后，模型实现了“自适应”终止，且平均 IoU 达到最高。这表明辅助任务对建立正确的终止策略至关重要，缺失该任务会导致模型无法判断何时停止迭代。

评估边界方面，论文未报告推理延迟与计算开销，迭代次数对实时性的影响未知。代码未公开，复现依赖 Qwen2.5-VL-7B 与 SAM2-Large 的具体配置。指标仅关注 IoU，未评估掩码的拓扑完整性或边缘平滑度。

## 关联研究分析

从问题动机看，SAM-Veteran 与 SegAgent 均旨在模仿人类使用 SAM 的行为，但 SegAgent 依赖外部 MLLM 生成初始框，导致定位误差无法通过后续精化完全修正，且缺乏自适应终止。SAM-Veteran 将定位与精化统一于同一 MLLM 策略中，通过 RL 联合优化，解决了定位与精化目标不一致的问题。这种统一框架使得模型能根据初始框的质量动态调整精化策略，而非盲目执行固定轨迹。

从方法设计看，SAM-Veteran 与 SAM-R1 同属 RL 路线，但 SAM-R1 仅优化单次生成的边界框或点，未利用 SAM 的迭代接口。SAM-Veteran 引入掩码理解任务，将“评估掩码质量”作为显式学习目标，这与知识库中过程奖励模型（PRM）的思想一致，但奖励信号直接来自分割模型的物理输出（IoU），而非独立的评分模型。这种设计避免了训练额外 PRM 的成本，但强依赖于 SAM 输出的准确性，若 SAM 本身存在系统性偏差，RL 可能放大该偏差。

## 总结

SAM-Veteran 解决了 MLLM 在推理分割中缺乏交互式迭代控制能力的问题，通过多任务 RL 框架统一了定位、精化与终止。实验证明其在域外复杂查询上优于现有 SOTA，ReasonSeg val gIoU 达 68.2。然而，其在域内 RefCOCOg 上略逊于 SegAgent，且未报告迭代带来的计算开销，表明该方法在简单任务上可能存在效率-精度权衡的盲区。当查询复杂度降低时，迭代精化的边际收益是否足以抵消其计算成本，论文未给出定量回答。
