> 多模态大模型（MLLMs）在复杂推理任务中常因视觉感知与语言逻辑解耦而失效，现有强化学习（RL）范式直接迁移文本域经验时遭遇收益递减。本文指出传统多模态冷启动数据复杂度不足且标准组相对策略优化（GRPO）存在梯度停滞，提出“文本冷启动+多模态RL+文本RL”三阶段课程及优先优势蒸馏（PAD）机制。该框架在开源7B模型上刷新多项基准SOTA，但缺乏理论解释且未验证大规模架构泛化性。

## 研究背景

多模态推理要求模型将离散的语言逻辑锚定在连续的高维视觉空间。当模型生成思维链（Chain-of-Thought, CoT）时，若中间步骤未显式引用图像证据，模型极易依赖语言先验产生幻觉，即“视觉漂移”。解决此问题需强化学习提供细粒度信号，但传统可验证奖励强化学习（RLVR）仅依赖最终答案正确性，导致信用分配模糊，无法区分基于视觉的正确推理与基于猜测的侥幸正确。

早期研究试图通过过程奖励模型（PRM）细化监督，或引入感知对齐优化（如VPPO）过滤视觉无关Token，但这些方法多聚焦于RL阶段内部的奖励设计或梯度调整，忽视了训练流程的前置条件。实验证据表明，若初始模型缺乏足够的反思能力与长链推理基础，后续RL阶段难以激发复杂的自我批判模式。ReVisual-R1的切入点在于解构整个训练管线，发现冷启动数据的质量与模态选择、RL算法的稳定性以及后处理阶段的模态侧重，共同决定了多模态推理的上限。

## 核心方法

### 训练流程参照系

主流多模态推理训练通常采用“多模态SFT冷启动 + 多模态RL”的两阶段范式。该流程假设视觉数据能直接建立跨模态关联，且GRPO算法在稀疏奖励下能稳定收敛。本文的核心差异在于挑战了“多模态数据冷启动必要性”与“GRPO在稀疏奖励下的稳定性”这两个隐含假设，将训练重构为三阶段课程。

### 文本中心冷启动与数据构建

传统冷启动依赖Vision-R1等多模态数据集，但本文发现其平均响应长度仅821.48 tokens，远低于DeepMath文本数据的8,207.76 tokens，且多模态数据通过率高达96.00%，表明其复杂度不足以激发深度推理。本文提出GRAMMAR数据集，冷启动阶段仅使用283K高难度文本样本，通过NV-EmbeddingV2编码与HDBSCAN聚类进行去重与难度分层。这一设计动机在于：文本高难度数据能强制模型学习长链反思逻辑，这种抽象推理能力是多模态推理的上位约束，比直接学习视觉-语言映射更能奠定推理基础。

### 优先优势蒸馏（PAD）

标准GRPO在多模态稀疏二元奖励下，常出现整组样本奖励相同（全对或全错）的情况，导致优势函数 $\hat{A}_i$ 趋近于零，策略梯度消失，即“梯度停滞”。PAD机制在优势计算后引入过滤与重采样。首先，定义有效样本集 $E = \{i \mid T_{low} \le |\hat{A}_i| \le T_{high}\}$，其中 $T_{low} > 0$ 剔除零优势样本。其次，从 $E$ 中按概率 $p_i \propto \exp(\hat{A}_i / \tau)$ 采样 $k'$ 个序列，其中温度 $\tau$ 随训练线性衰减。该公式的物理含义是：优先更新那些具有显著正或负优势信号的样本，避免计算资源浪费在无法提供学习信号的停滞样本上，从而提升训练稳定性与样本效率。

### 文本RL后处理

多模态RL（MRL）阶段虽能建立视觉接地，但往往导致纯文本推理能力退化。本文在MRL后增加文本RL（TRL）阶段，冻结视觉塔，仅对语言模型部分进行GRPO优化。这一设计的动机在于：视觉接地与语言逻辑是互补而非互斥的，TRL阶段在不破坏已习得视觉特征的前提下，通过高难度文本任务进一步打磨逻辑一致性与语言流畅性，实现“1+1>2”的协同效应。

## 实验评估

实验基于Qwen2.5-VL-7B/3B-Instruct，使用8块A100-80G GPU。基线覆盖开源SOTA（如VLAA-Thinker, OpenVLThinker）及闭源模型（GPT-4o, Claude-3.7-Sonnet）。

| 基准 | ReVisual-R1-7B | 开源最佳基线 | 提升幅度 |
| :--- | :--- | :--- | :--- |
| MathVerse-V | 53.6 | 48.2 (VL-Rethinker) | +5.4 |
| MathVision | 48.8 | 30.2 (MMR1-Math) | +18.6 |
| AIME24 | 53.3 | 10.0 (Qwen2.5-VL) | +43.3 |
| MATH500 | 89.2 | 67.2 (OpenVLThinker) | +22.0 |

ReVisual-R1-7B在9/10个基准上超越开源最佳，平均得分53.1%，显著高于GPT-4o的41.6%。消融实验显示，三阶段课程（CS+MRL+TRL）优于混合RL或单一阶段，其中TRL阶段对MathVision提升尤为明显，验证了文本后处理对视觉推理的增益。

评估边界方面，论文未报告置信区间，且AIME24/25采用average@32以减小方差，但其他基准为pass@1。代码已开源，但超参数细节（如PAD的温度衰减曲线具体值）仅在附录提及，复现需仔细核对。

## 关联研究分析

从问题动机看，ReVisual-R1与SPECS（ICLR 2026）均挑战了多模态冷启动的必要性，但SPECS采用自蒸馏偏好数据，而本文证明纯文本高难度数据即可超越多模态数据。这一差异暗示：多模态推理的瓶颈可能不在视觉编码，而在语言逻辑的深度。然而，本文未对比VPPO等感知对齐方法，无法排除是数据量差异（283K文本 vs 少量多模态）而非方法优势导致的性能提升。

从方法设计看，PAD与VPPO均针对GRPO的稀疏性问题，但作用层级不同：VPPO在Token级过滤视觉无关梯度，PAD在序列级过滤零优势样本。PAD更侧重于训练稳定性，而VPPO侧重于视觉忠实度。本文未结合两者，若将PAD的序列级过滤与VPPO的Token级过滤结合，是否能在保持稳定性的同时进一步提升视觉接地，论文未给出回答。

## 总结

ReVisual-R1旨在解决多模态推理中视觉感知与语言逻辑解耦导致的性能瓶颈，其切入点在于发现传统多模态冷启动数据复杂度不足且GRPO存在梯度停滞。通过“文本冷启动+PAD多模态RL+文本RL”三阶段课程，该模型在MathVerse上达到53.6%，AIME24上达到53.3%，显著超越开源SOTA。然而，论文缺乏理论解释为何文本优化能提升视觉推理，且仅在3B/7B规模验证，未探索MoE等大规模架构。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
