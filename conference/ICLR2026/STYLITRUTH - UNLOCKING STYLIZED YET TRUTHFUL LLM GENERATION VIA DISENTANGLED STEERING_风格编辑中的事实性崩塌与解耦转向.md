> 在推理时通过激活空间干预实现风格控制时，模型往往因风格信号污染事实表征而输出错误答案，这一现象被定义为风格诱导的事实性崩塌。现有表征编辑方法将风格视为单一方向注入，忽略了风格与真理在特定注意力头中的纠缠，导致风格增强必然伴随事实退化。StyliTruth 通过正交消去法分离风格与真理子空间，并实施自适应 token 级编辑，在保持风格强度的同时恢复事实准确性。该方法在 Qwen1.5-14B 上验证了解耦的有效性，但其对子空间维度的敏感性揭示了正交假设在有限维度下的信息损失边界。

## 研究背景

当大语言模型（LLMs）被要求以特定风格（如莎士比亚体）回答事实性问题时，其内部激活状态同时承载了风格特征与事实知识。若直接注入风格转向向量，风格信号可能覆盖或干扰事实相关的激活方向，导致模型生成符合风格但内容错误的响应。这一冲突源于线性表示假设：高层概念对应激活空间中的方向，但不同概念的方向并非天然正交，尤其在某些注意力头中，风格与真理的激活差异存在强耦合。

表征编辑作为轻量级推理时干预手段，旨在不更新参数的前提下控制模型行为。主流方法如 RepE 和 ITI 通过提取正负样本的激活差值构建转向向量，但通常假设目标属性（如风格）与核心语义（如真理）在激活空间中近似正交。这一假设在风格控制任务中失效：风格编辑往往导致事实性指标显著下降，即风格诱导的事实性崩塌。现有研究多关注单一属性的增强或抑制，缺乏对风格与真理之间结构性冲突的显式建模，导致在追求风格保真度时牺牲了回答的正确性。

本文切入点在于识别并解耦风格与真理在激活空间中的纠缠。通过探针分析发现，部分注意力头对风格与真理均敏感，且两者激活差异的余弦相似度显著高于其他头。StyliTruth 针对这一发现，构建相互正交的风格与真理子空间，确保风格编辑不干扰真理表征，从而在推理时实现风格与事实的独立控制。

## 核心方法

### 方法参照系

表征编辑的标准流程包括对比样本准备、头部选择、转向向量构建与注入。本文问题与该通用流程的关键差异在于：传统方法假设属性方向正交，而风格与真理在特定头部存在纠缠，需引入子空间解耦机制以消除干扰。

### 子空间正交解耦

针对风格与真理在相关头部（Relevant Heads）中的纠缠，StyliTruth 采用正交消去法构建相互正交的子空间。对于同时属于风格与真理敏感头的情况，首先对风格激活差值矩阵 $\Delta \mathbf{A}_s$ 进行奇异值分解（SVD），提取前 $K$ 个右奇异向量构成风格子空间基 $\mathbf{V}_{s,K}$。随后，将真理激活差值矩阵 $\Delta \mathbf{A}_t$ 投影到风格子空间的正交补空间，即 $\tilde{\Delta \mathbf{A}}_t = \Delta \mathbf{A}_t \mathbf{P}_{s^\perp}$，其中 $\mathbf{P}_{s^\perp} = \mathbf{I} - \mathbf{V}_{s,K}\mathbf{V}_{s,K}^\top$。对 $\tilde{\Delta \mathbf{A}}_t$ 再次进行 SVD，提取前 $K$ 个右奇异向量构成真理子空间基 $\tilde{\mathbf{V}}_{t,K}$，满足 $\tilde{\mathbf{V}}_{t,K}^\top \mathbf{V}_{s,K} = 0$。这一设计动机在于消除风格转向向量对真理表征的污染，确保两者在编辑过程中互不干扰。

### 自适应 Token 级编辑

解耦后的子空间需结合 token 级自适应强度以实现精细控制。风格子空间中的 token 级强度系数定义为 $\lambda_{s,i}^{(h,l)} = g_{s,i}^{(h,l)} \kappa_{s,i}^{(h,l)} \gamma_s$，其中 $g_{s,i}^{(h,l)} = \frac{\sigma_{s,i}^{(h,l)}}{\sqrt{d}}$ 为全局强度，$\kappa_{s,i}^{(h,l)} = \frac{\langle \mathbf{a}^{(h,l)} - \bar{\mathbf{a}}^{(h,l)}, \mathbf{v}_{s,i}^{(h,l)} \rangle}{\|\mathbf{v}_{s,i}^{(h,l)}\|_2}$ 为自适应缩放因子，$\gamma_s$ 为超参数。该公式通过计算当前 token 激活与正样本均值激活在风格基向量上的投影差，动态调整编辑强度，避免对无关 token 的过度扰动。这一机制解决了统一强度编辑导致的语义失真问题，使风格控制更具针对性。

## 实验评估

实验在 Qwen1.5-14B-Chat 上进行，风格语料为莎士比亚体与《红楼梦》体，事实性基准为 TruthfulQA 及其中文翻译。基线包括 CAA、LLM Steer、ITI、Vector Prompt 和 DRESS。StyliTruth 在两种风格下均取得最高的 S-TI（风格-真理调和均值）指标。

| 方法 | DRC→TruthfulQA(ZH) S-TI | Shakespeare→TruthfulQA S-TI |
| :--- | :--- | :--- |
| CAA | 0.1489 | 0.1293 |
| ITI | 0.1560 | 0.1912 |
| DRESS | 0.2366 | 0.2529 |
| StyliTruth | 0.2366 | 0.2803 |

在 DRC 风格下，StyliTruth 的 S-TI 为 0.2366，与 DRESS 持平，但 TI（真理-信息量）达到 0.5000，显著高于 DRESS 的 0.4028。在莎士比亚风格下，StyliTruth 的 S-TI 为 0.2803，比最强基线 ITI 的 0.1912 提升 10.83%。

| 变体 | OA | TI | S-TI |
| :--- | :--- | :--- | :--- |
| w/o ATE | 0.1079 | 0.2017 | 0.1632 |
| w/o SD | 0.1095 | 0.3194 | 0.1789 |
| StyliTruth | 0.1550 | 0.5000 | 0.2366 |

消融实验显示，移除子空间解耦（w/o SD）导致 TI 从 0.5000 降至 0.3194，表明解耦是保持事实性的关键。移除自适应 token 级编辑（w/o ATE）导致 OA 从 0.1550 降至 0.1079，说明自适应机制对风格保真度至关重要。

评估边界方面，实验仅在 Qwen1.5-14B 上验证，未测试更大规模模型或不同架构。子空间维度 $K$ 的敏感性分析显示，$K=64$ 时性能最佳，$K=128$ 时 S-TI 降至 0.2002，表明正交消去在高维下引入的信息损失不可忽略。代码已开源，但超参数 $\gamma_s$ 的搜索范围未在正文中详细披露。

## 关联研究分析

从问题动机看，StyliTruth 与谄媚缓解研究共享“目标冲突”这一核心结构，但根源不同。谄媚源于 RLHF 训练中用户偏好与事实准确性的内在冲突，模型在优化有用性时主动牺牲真理；而风格崩塌源于外部推理时干预对激活空间的非预期污染，模型并无欺骗意图。这一差异决定了缓解策略的不同：谄媚缓解需调整训练目标或解码策略，而风格崩塌需解耦激活空间中的特征方向。StyliTruth 的正交消去法针对后者，但无法解决前者，因为谄媚涉及的是训练后的权重分布而非推理时的激活干扰。

从方法设计看，StyliTruth 与 DRESS 同属风格解耦路线，但 DRESS 仅解耦风格子空间，未考虑真理子空间的正交性。StyliTruth 引入真理子空间并强制正交，解决了 DRESS 中风格编辑干扰事实的问题。然而，StyliTruth 的探针选择头部方法借鉴了 ITI 的概念定位思路，但 ITI 用于抑制或促进单一概念，而 StyliTruth 用于分离两个纠缠概念。这种从“单概念控制”到“双概念解耦”的转变，是本文方法的核心创新，但也引入了子空间维度选择的复杂性，这是 ITI 等单概念方法所不面临的挑战。

## 总结

StyliTruth 旨在解决风格编辑导致的事实性崩塌，其切入点在于识别风格与真理在特定注意力头中的纠缠，并通过正交消去法构建相互正交的子空间。该方法在 Qwen1.5-14B 上验证了解耦的有效性，S-TI 在莎士比亚风格下达到 0.2803，TI 达到 0.5000。然而，实验仅在单一模型规模上进行，且子空间维度 $K$ 的敏感性表明正交假设在有限维度下存在信息损失。当模型规模扩大或风格复杂度增加时，风格与真理的纠缠程度是否会变化，正交消去法是否仍能保持有效，论文未给出回答。
