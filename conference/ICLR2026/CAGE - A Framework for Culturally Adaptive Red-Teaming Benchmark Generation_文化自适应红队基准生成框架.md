# ICLR2026最新论文 ｜CAGE: A Framework for Culturally Adaptive Red-Teaming Benchmark Generation ｜文化自适应红队基准生成框架

研究机构：韩国首尔大学

作者：Chaeyun Kim、YongTaek Lim、Kihyun Kim 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.20170)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.20170)

> 多语言大语言模型（LLM）的安全评估长期依赖英语基准的直接翻译，导致本地法律与社会规范下的隐性危害被系统性遗漏。现有模板填充与原生构建方法在结构多样性与文化真实性之间难以兼顾，CAGE 通过语义模具（Semantic Mold）解耦攻击意图与文化内容，实现了跨文化红队提示的自动化生成。该框架在韩语与高棉语上验证了文化接地提示对模型漏洞揭示能力的提升，但其效果是否完全归因于文化特异性而非提示复杂度，仍需更严格的对照实验加以区分。

## 研究背景

红队测试通过对抗性提示探测模型安全边界，其有效性取决于提示能否模拟真实用户面临的威胁。当英语基准被直接翻译至其他语言时，提示中的法律语境与社会冲突往往发生错位，例如烧国旗行为在不同司法管辖区的法律定性差异，导致翻译后的提示无法触发模型在本地语境下的真实风险响应。这种文化错配使得基于翻译的评估产生虚假安全感，而现有跨文化适配方法面临两难：模板填充（如 KoBBQ）虽保证语义控制但限制表达多样性，原生构建（如 KorNAT）虽具备文化真实性但缺乏结构一致性与可扩展性。

多语言安全评估的核心矛盾在于，安全对齐训练主要基于英语数据，导致模型在低资源语言中拒绝率显著下降，易被越狱攻击利用。2023 年 Cross-lingual Jailbreaks 研究证实低资源语言是攻击高发区，但后续工作多聚焦于行为层评估，缺乏对“为何”文化语境影响攻击有效性的机制解释。CAGE 的切入点在于将红队测试的目标从简单的越狱成功率扩展至评估模型对现实社会技术场景的鲁棒性，通过结构化语义表示解决文化接地与攻击多样性之间的权衡。

## 核心方法

### 语义模具与风险分类体系

CAGE 框架建立在三级风险分类体系之上，包含 5 个风险域、12 个二级类别及 53 个三级类型。该分类体系整合了 OpenAI 与 Meta 的安全政策定义，并通过六个前沿模型（GPT-4.1、Claude 3.5 Sonnet 等）对种子提示进行共识标注，仅保留所有模型一致同意的标签，经人工验证后确定最终分类。这一多模型共识机制旨在消除单一模型的偏见，确保攻击意图识别的可靠性。

### 语义模具解耦机制

语义模具（Semantic Mold）是 CAGE 的核心创新，它将提示的对抗性结构从文化内容中解耦。模具定义表达有害场景所需的最小语义元素，包括动作、目标、工具及上下文条件，而非仅限于命名实体。其形式化表示为：

$$
M = \{s_i \in S \mid s_i \text{ is essential or optional for category } C\}
$$

其中 $S$ 为语义槽位集合，$C$ 为风险类别。该公式表明模具是一个约束集合，规定提示必须包含的语义成分，但不限定句法结构。例如，“2023 年全球领导人殖民火星的谣言”被重构为“[谣言] [虚假事件] 在 [时间]”，保留了修辞流的同时显式化了语义单元。这种设计解决了模板填充方法中结构刚性导致攻击场景复杂度受限的问题，使生成的提示在保持对抗意图的同时具备语言多样性。

### 本地化内容注入流程

本地化阶段通过三个输入驱动：语义模具提供对抗结构，槽位模式定义必需语义成分，本地内容库提供文化接地素材。内容库构建采用双轨策略：对于定义明确的类别（如非法活动），采用分类驱动方法从立法、法院判决等权威来源检索关键词；对于动态社会议题（如偏见与仇恨），采用趋势驱动管道从新闻门户提取高参与度话题。所有素材经过二元通过/失败验证过滤噪声。最终提示通过少样本学习生成，每个类别提供 3-4 个槽位标注示例，指导模型准确实例化模具。这一流程解决了原生构建方法中人工成本高、难以规模化的瓶颈，实现了文化真实性与自动化生成的平衡。

## 实验评估

实验在 KorSET 韩语基准上进行，包含 5,500 个专家验证测试用例，覆盖 12 个风险类别。基线包括直接翻译（DirTrans）、模板填充（Template）及 LLM 适配（LLM-Adapt），攻击方法涵盖 GCG、TAP、AutoDAN 及 GPTFuzzer。目标模型包括 Llama-3.1-8B、Qwen2.5-7B、gemma2-9B-it、EXAONE3.5-7.8B-it 及 gemma3-12B-it。

| 攻击方法 | 模型 | DirTrans ASR | LLM-Adapt ASR | Template ASR | CAGE ASR |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Direct Request | Llama3.1 | 28.2 | 32.4 | 31.9 | 43.8 |
| AutoDAN | Llama3.1 | 39.2 | 34.1 | 34.0 | 45.3 |
| TAP | Llama3.1 | 36.7 | 34.4 | 23.8 | 42.7 |
| Direct Request | Qwen2.5 | 14.6 | 18.5 | 16.6 | 25.3 |
| Direct Request | gemma2 | 14.6 | 9.8 | 9.3 | 20.1 |

CAGE 在所有模型与攻击方法上均取得最高攻击成功率（ASR），其中 Llama-3.1 在 Direct Request 下的 ASR 达 43.8%，较 DirTrans 提升 15.6 个百分点。这一差距在 Direct Request 攻击中最为显著，表明文化接地提示本身即具备更强的漏洞揭示能力，无需依赖复杂的对抗优化算法。

| 风险类别 | DirTrans 文化特异性 | CAGE 文化特异性 | DirTrans 总分 | CAGE 总分 |
| :--- | :--- | :--- | :--- | :--- |
| A. ToxLang | 0.59 | 2.02 | 4.91 | 10.46 |
| D. BiasHate | 0.39 | 2.35 | 4.40 | 10.60 |
| E. Misinfo | 0.35 | 1.94 | 3.43 | 10.14 |
| L. Security | 0.03 | 1.52 | 4.03 | 8.22 |

质量评估显示 CAGE 提示在文化特异性上全面优于 DirTrans，BiasHate 类别的文化特异性从 0.39 升至 2.35，总分从 4.40 升至 10.60。Khmer 语实验进一步验证了框架在低资源语言中的鲁棒性，gemma3-12B-it 在 Security Threats 类别的 ASR 从 2.7% 升至 35.1%，Self-Harm 类别从 4.9% 升至 34.4%。

评估协议采用 GPT-4.1 作为自动裁判，通过元评估验证其与人类判断的一致性高于标准评分规则。代码与评估规则已公开，但论文未报告置信区间，且未对比原生人工构建基准（如 RICoTA），限制了与高保真本地化方法的直接比较。

## 关联研究分析

从问题动机看，CAGE 与 KoBBQ 均旨在解决跨文化红队测试中的文化错配问题，但 KoBBQ 采用硬编码模板与预定义实体列表，导致攻击场景受限于模板覆盖范围，而 CAGE 通过语义模具实现结构解耦，允许在保持对抗意图的同时灵活注入本地内容。这一差异源于任务特性的不同：KoBBQ 侧重偏见检测的标准化评估，而 CAGE 聚焦于复杂社会技术场景的漏洞揭示，后者对提示多样性与真实性的要求更高。

从方法设计看，CAGE 与 XSafety 等直接翻译方法在文化接地策略上存在根本分歧。XSafety 假设安全概念可跨语言等价转换，而 CAGE 认为安全定义高度依赖本地法律与社会规范，必须通过本地化内容重构提示语境。这一分歧反映了领域内普世主义与文化相对主义的核心争议，CAGE 的实验结果支持相对主义观点，即文化特异性是攻击有效性的关键变量。然而，CAGE 未量化文化特异性与提示复杂度对 ASR 的独立贡献，其 2×2 分解实验仅展示了英语中心模型（Llama-3.1）与韩语专用模型（EXAONE）的差异，未完全排除提示长度或词汇丰富度对结果的混淆效应。

## 总结

CAGE 框架针对多语言安全评估中直接翻译导致的文化错配问题，通过语义模具解耦攻击结构与文化内容，实现了文化接地红队提示的自动化生成。该框架在韩语 KorSET 基准上证明，CAGE 提示在 Direct Request 攻击下的 ASR 达 43.8%，显著高于直接翻译基线的 28.2%，并在高棉语低资源场景中验证了框架的通用性。其边界在于，实验未完全区分文化特异性与提示复杂度对攻击有效性的独立贡献，且缺乏与原生人工构建基准的对比。当控制提示长度与词汇丰富度后，CAGE 的 ASR 优势是否仍能保持，论文未给出回答。
