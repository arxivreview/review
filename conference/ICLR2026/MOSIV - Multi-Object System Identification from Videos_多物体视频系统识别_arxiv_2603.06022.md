# ICLR2026最新论文 ｜MOSIV: Multi-Object System Identification from Videos ｜多物体视频系统识别

研究机构：美国卡内基梅隆大学、瑞士苏黎世联邦理工学院

作者：Chunjiang Liu、Xiaoyuan Wang、Qingran Lin 等 12 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.06022)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.06022)

> 物理基础视觉推理旨在从视频流中解耦出物体的内在物理状态，但现有方法多局限于单物体隔离场景，无法处理真实世界中物体间的碰撞、遮挡与运动耦合。MOSIV 切入这一空白，将任务形式化为多物体连续本构参数的联合识别，而非离散材料分类。该方法通过物体感知的动态高斯重建与可微物质点法（MPM）仿真器，利用几何对齐损失直接优化每个物体的刚度、塑性及摩擦参数。这一框架在接触丰富的合成场景中显著提升了长时程预测的物理一致性，但其对预定义本构模型的依赖及合成数据规模限制了向真实噪声环境的泛化能力。

## 研究背景

理解多物体交互场景的物理动力学，首先需解决从像素到几何状态的映射问题。3D 高斯溅射（3D Gaussian Splatting, 3DGS）作为显式场景表示，相比隐式神经辐射场（NeRF）能提供更稳定的几何结构，是构建可微仿真初始状态的基础。然而，3DGS 本身仅编码外观与几何，不包含物理定律；要将几何转化为可预测的动力学系统，必须引入可微物理仿真器，通过反向传播将视觉误差转化为对物理参数的梯度更新。

从单物体到多物体的跨越是物理系统识别领域的关键瓶颈。早期工作如 PhysGS 和 CoupNeRF 虽实现了从视频恢复物理属性，但前者假设单物体或共享材料库，后者依赖隐式 NeRF 在自由落体场景下运行，难以应对接触丰富、高度变形场景中的时间不一致性与计算瓶颈。OmniPhysGS 等近期方法虽支持多材料场景，但其核心机制是从固定库中选择离散材料类别，而非识别连续的物理参数（如杨氏模量 $E$、泊松比 $\nu$、摩擦系数 $\mu$）。这种离散选择无法解决刚度与摩擦之间的参数歧义性，导致在复杂接触交互中产生累积漂移。MOSIV 的切入点在于打破单物体假设与离散分类范式，提出逐物体独立优化连续本构参数，以构建可泛化的场景“数字孪生”。

## 核心方法

### 方法参照系

视频逆向物理推断的标准流程通常包含几何重建、可微仿真与参数优化三个阶段。MOSIV 与该通用流程的关键差异在于：它摒弃了单物体或共享材料库的假设，引入物体感知的动态高斯重建以解耦多物体运动，并通过 Gaussian-to-Continuum 提升机制处理多物体接触界面，实现逐物体连续参数的联合优化。

### 物体感知动态高斯与连续体提升

传统动态高斯重建往往将场景视为整体，无法区分不同物体的独立运动与材料属性。MOSIV 引入预定义的 2D 材料掩码，将高斯核按物体与材料进行分区，确保每个物体拥有独立的形变场。设计动机在于解决多物体场景中运动耦合导致的几何混淆，使后续仿真能准确追踪每个物体的独立状态。重建完成后，通过 Gaussian-to-Continuum 提升机制，将非均匀分布的高斯点转换为模拟粒子集。该过程通过随机采样与深度对齐生成粗略内部形状，再逐步提升密度场分辨率并平滑边界，最终提取物体表面。针对多物体接触，该方法强制初始化时物体支撑集不相交，将重叠体素分配给最近物体表面，并保证各物体网格分辨率兼容，从而确保接触界面的对齐。

### 可微 MPM 仿真与几何对齐优化

离散材料选择无法捕捉连续物理参数间的细微差异，导致仿真轨迹在长时程中偏离真实运动。MOSIV 采用可微物质点法（MPM）模拟器，将每个物体的材料参数 $\boldsymbol{\theta}_k$ 作为优化变量。MPM 通过背景网格计算应力与动量，支持接触与库仑摩擦的精确建模，且整个时间步进映射 $\mathbf{z}_{n+1} = T(\mathbf{z}_n; \boldsymbol{\Theta})$ 对状态与参数完全可微。优化目标由几何对齐损失驱动，包括模拟表面与重建表面的对称 Chamfer 距离，以及模拟剪影与目标剪影的 Alpha 掩码损失：

$$
\mathcal{L} = \sum_{j} \sum_{t_i} \left( \mathcal{L}_{CD}(S_k(t_i), \tilde{S}_k(t_i)) + \mathcal{L}_{\alpha}(A_{j,k}(t_i), \tilde{A}_{j,k}(t_i)) \right)
$$

该公式的物理含义是：通过最小化模拟结果与视频观测在几何形状和轮廓上的偏差，反向传播梯度以更新每个物体的连续物理参数。这种几何驱动的监督信号比纯光度损失更具物理约束力，能有效区分刚度与摩擦等易混淆属性，确保优化收敛到物理合理的参数空间。

## 实验评估

MOSIV 在自建合成数据集上验证了方法有效性，该数据集包含 45 个多物体交互视频，涵盖 10 种几何形状与 5 种材料（弹性、弹塑性、流体、沙、雪）。基线对比包括 OmniPhysGS-RGB 及其 Oracle 变体（提供真实材料模型以隔离识别难度），以及 CoupNeRF。评估指标涵盖 PSNR、SSIM、Chamfer Distance (CD) 与 Earth Mover’s Distance (EMD)。

| 方法 | PSNR (Avg) | CD (Avg) | EMD (Avg) |
| :--- | :--- | :--- | :--- |
| OmniPhysGS-RGB | 25.93 | 11.79 | 0.095 |
| OmniPhysGS-RGB w/ Oracle | 24.39 | 43.50 | 0.168 |
| MOSIV | 30.51 | 1.256 | 0.049 |

MOSIV 在平均 PSNR 上达到 30.51，显著优于 OmniPhysGS-RGB 的 25.93；CD 降至 1.256，仅为基线的十分之一。值得注意的是，Oracle 变体在 CD 上表现更差（43.50），表明即使提供正确材料模型，离散选择范式在接触丰富场景中仍难以维持几何稳定性，而连续参数优化能更好地处理接触界面的动态变化。

消融实验聚焦于监督粒度，对比场景级与物体级监督。结果显示，物体级监督在所有指标上均优于场景级，特别是在 Chamfer Distance 上，场景级损失因允许质量或刚度在投影中互换而最小化，导致模拟训练不稳定与接触处理不准确。物体级监督纠正了这一缺陷，确保了物理合理的滚动预测。此外，单一来源监督（仅 CD 或仅 Silhouette）不足以支撑鲁棒的物理属性训练，联合优化是必要的。

评估边界方面，实验仅在合成数据上进行，未涉及真实世界噪声与光照变化；代码与数据集声明将发布但未提供具体链接；优化过程依赖 NVIDIA RTX A6000 GPU，计算密集且对初始几何敏感。

## 关联研究分析

从问题动机看，MOSIV 与 PhysGS 均致力于从视频恢复物理属性，但 PhysGS 聚焦单物体或简单交互，依赖贝叶斯推断优化单一属性，而 MOSIV 针对多物体接触场景，强调连续本构参数的联合识别。这一差异源于任务复杂度的提升：多物体交互引入了遮挡与运动耦合，使得单物体假设失效，必须通过逐物体参数优化与接触处理机制来解耦状态估计误差。MOSIV 的几何对齐损失设计直接回应了这一挑战，而 PhysGS 的优化策略在复杂接触中可能因参数歧义性而收敛到局部最优。

从方法设计看，MOSIV 与 CoupNeRF 同属可微仿真框架，但 CoupNeRF 采用隐式 NeRF 表示，在高度变形场景中易出现时间不一致性，且计算开销大；MOSIV 改用显式 3DGS，提升了几何稳定性与渲染效率。然而，CoupNeRF 在自由落体场景下的有效性表明，隐式表示在特定条件下仍有优势，MOSIV 是否在所有动态场景中均优于隐式方法，论文未给出全面对比。此外，MOSIV 依赖预定义本构模型，而 CoupNeRF 等部分工作探索了神经本构律的学习，MOSIV 对未知材料属性的处理能力尚存疑问。

## 总结

MOSIV 旨在解决多物体视频系统中物理参数不可辨识与接触交互导致的状态漂移问题。现有方法因局限于单物体假设或离散材料分类，无法捕捉连续本构参数间的细微差异，导致长时程预测失效。MOSIV 通过物体感知动态高斯重建与可微 MPM 仿真器，利用几何对齐损失直接优化逐物体连续参数，实现了从视觉观测到物理状态的端到端推断。实验表明，该方法在合成数据集上显著提升了 PSNR 与几何精度，验证了连续参数优化在接触丰富场景中的有效性。然而，其依赖预定义本构模型且仅在合成数据上验证，限制了向真实噪声环境的泛化。当面对未知材料属性或复杂真实光照时，该框架的鲁棒性是否仍能维持，论文未给出回答。
