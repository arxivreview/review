# ICLR2026最新论文 ｜Shift-and-Sum Quantization for Visual Autoregressive Models ｜视觉自回归模型的后训练量化：Shift-and-Sum 量化与校准重采样

研究机构：韩国延世大学

作者：Jaehyeon Moon、Bumsub Ham

论文原文见 [arXiv](https://arxiv.org/abs/2606.16131)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.16131)

> 视觉自回归模型（VAR）通过层级化 Next-Scale 生成实现了高质量图像合成，但其多尺度 Transformer 结构导致推理资源消耗巨大，阻碍了端侧部署。现有后训练量化（PTQ）方法在迁移至 VAR 时，因忽略注意力-值乘积在粗尺度的误差放大及校准数据分布偏差，导致低比特性能急剧下降。本文提出 Shift-and-Sum 量化核与校准数据重采样策略，通过对称移位聚合抑制注意力误差，并强制校准频率匹配预测概率。该方法在 4/4-bit 下将 VAR-d30 的 FID 从 12.25 降至 9.12，确立了 VAR 全低比特量化的新基准，但其额外计算开销是否抵消加速收益仍存疑。

## 研究背景

VAR 模型依赖多尺度向量量化变分自编码器（VQVAE）与 Transformer 的协同工作，从粗到细逐层生成 Token 映射。PTQ 旨在不重新训练模型的情况下，通过少量校准数据确定量化参数（如步长、零点），将权重与激活转换为低比特表示。然而，VAR 的层级生成特性使得早期粗尺度的量化误差会跨尺度传播并放大，这与传统单尺度生成模型的误差累积机制存在本质差异。

视觉生成领域的量化研究长期聚焦于扩散模型，针对 VAR 的 PTQ 工作极为稀缺。现有主流方案如 LiteVAR 虽识别出 GELU 后全连接层量化敏感，但选择保留全精度以规避误差，导致硬件需支持混合精度算术，限制了部署灵活性。BRECQ 等通用 PTQ 方法直接应用于 VAR 时，因未考虑注意力机制中高分值 Token 的误差放大效应，在低比特下性能崩塌。本文切入点在于识别 VAR 特有的两个量化失效点：注意力-值乘积在粗尺度的重构误差激增，以及有限校准数据导致的码本采样频率与预测概率失配。

## 核心方法

### 方法参照系

标准 PTQ 流程包含校准数据收集、量化参数确定（步长/零点）及舍入函数优化。本文基于 BRECQ 框架，但针对 VAR 的注意力机制与 VQVAE 码本采样特性，引入了非标准的量化核与数据重采样机制，核心差异在于对“注意力-值乘积”这一特定运算的误差抑制，而非全局权重优化。

### Shift-and-Sum 量化核

传统量化中，注意力分数 $a_i$ 与值 Token $\mathbf{v}_i$ 的乘积误差方差随 $a_i$ 增大而增加，尤其在粗尺度 Token 数量少、注意力集中时更为显著。为抑制此误差，本文提出量化核 $f_n(v; t_n)$，将值 Token 对称移位后量化再聚合。其核心公式为：

$$ f_n(v; t_n) = \frac{1}{2^n} \sum_{k=0}^{2^n-1} Q\left(v + \left(k - \frac{2^n-1}{2}\right) t_n\right) $$

该公式通过 $2^n$ 次移位量化取平均，将量化误差上界压缩至 $s/4^n$。仅对平均注意力分数超过阈值 $\theta$ 的“注意力 Token”应用此核，其余 Token 使用标准量化，以平衡计算开销与精度。

### 校准数据重采样

PTQ 中校准样本量极小（如 256 张），导致 VQVAE 码本条目的实际采样频率与模型预测概率严重偏离，进而偏置量化参数。本文提出重采样策略，在生成校准 Token 映射时，动态调整码本条目选择概率，使高频条目被抑制、低频条目被增强，直至采样频率与预测概率对齐。这一机制解决了因校准数据不足导致的分布偏差问题，确保量化参数反映真实的生成分布。

## 实验评估

| 方法 | 比特位宽 (W/A) | VAR-d30 FID | VAR-d30 FID2FP16 | VAR-d16 FID |
| :--- | :--- | :--- | :--- | :--- |
| Full-precision | 16/16 | 1.97 | - | 3.41 |
| BRECQ | 4/4 | 12.25 | 11.11 | 35.87 |
| LiteVAR | 4/4 | 12.25 | 11.11 | 35.87 |
| Ours | 4/4 | 9.26 | 8.68 | 24.57 |
| Ours+LiteVAR | 4/4 | 9.12 | 8.48 | 18.92 |

实验在 ImageNet 256x256 类别条件生成上进行，对比基线包括 BRECQ 和 LiteVAR。在 4/4-bit 极端低比特下，本文方法将 VAR-d30 的 FID 从 12.25 降至 9.26，结合 LiteVAR 后进一步降至 9.12，显著优于基线。FID2FP16 指标显示，量化后模型与全精度模型的分布距离从 11.11 缩小至 8.48，表明量化损失得到有效控制。

消融实验表明，Shift-and-Sum 量化与校准重采样均有独立贡献。在 4/6-bit 设置下，仅使用 Shift-and-Sum 使 VAR-d16 FID 从 11.16 降至 10.15，仅使用重采样降至 10.19，两者结合降至 9.20。这证实了注意力误差抑制与分布匹配是解决 VAR 量化失效的两个独立且必要的维度。

评估边界方面，论文未报告具体推理加速比或延迟数据，仅定性声称效率提升。FID2FP16 作为相对指标，无法直接反映绝对生成质量，且 4/4-bit 下 FID 9.12 仍远高于全精度 1.97，表明低比特 VAR 在保真度上仍有较大差距。代码已开源，但校准数据重采样的具体实现细节（如重采样迭代次数）未在正文中详细披露。

## 关联研究分析

从问题动机看，本文与扩散模型量化研究（如 PTQ4DM）存在根本差异。扩散模型量化主要关注去噪过程中的时间步误差累积，而 VAR 的误差源于空间尺度的层级传播。本文识别的“粗尺度注意力误差放大”是 VAR 特有的结构缺陷，通用 PTQ 方法无法捕捉。相比之下，LiteVAR 虽针对 VAR，但采取“保留敏感层全精度”的保守策略，牺牲了硬件兼容性；本文则通过算法层面的误差抑制实现全低比特，代表了从“硬件适配”到“算法鲁棒”的技术路线转变。

从方法设计看，本文的 Shift-and-Sum 量化核与混合精度量化（Mixed-Precision Quantization）形成对比。混合精度为注意力 Token 分配更高比特位宽，需硬件支持多精度矩阵乘法；本文通过增加计算量（移位、求和）换取精度，仅需标准低比特硬件。这一设计选择暗示了当前端侧硬件对混合精度支持不足的现状，但也引出了疑问：当硬件支持高效混合精度运算时，本文的额外计算开销是否仍具优势？此外，校准重采样策略与扩散模型中基于时间步的校准采样（如 PTQ4DM 的后期时间步采样）异曲同工，均旨在解决有限数据下的分布偏差，但本文将其应用于离散码本采样，具有更强的针对性。

## 总结

本文旨在解决 VAR 模型在低比特量化下的性能崩塌问题，其核心矛盾在于层级生成结构导致的误差跨尺度放大与有限校准数据引发的分布偏差。现有方法如 LiteVAR 依赖混合精度硬件，BRECQ 忽略结构特性，均无法在纯低比特硬件上保持生成质量。本文通过 Shift-and-Sum 量化核抑制注意力误差，并引入校准重采样对齐码本分布，在 4/4-bit 下将 VAR-d30 FID 降至 9.12，FID2FP16 降至 8.48。然而，实验未报告具体加速比，且 4/4-bit 下 FID 仍显著高于全精度，表明低比特 VAR 在保真度与效率间存在未解决的权衡。当校准数据量增加至千级时，重采样策略的边际收益是否递减，论文未给出回答。
