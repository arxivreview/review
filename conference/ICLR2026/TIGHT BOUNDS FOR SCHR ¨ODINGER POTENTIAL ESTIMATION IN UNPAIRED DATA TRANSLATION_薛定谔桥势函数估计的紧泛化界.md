# ICLR2026最新论文 ｜TIGHT BOUNDS FOR SCHR ¨ODINGER POTENTIAL ESTIMATION IN UNPAIRED DATA TRANSLATION ｜薛定谔桥势函数估计的紧泛化界

研究机构：俄罗斯高等经济大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_2759895)

> 薛定谔桥旨在寻找连接两个边缘分布且最接近参考随机过程的最优概率耦合，但现有求解器多关注算法效率，缺乏对有限样本下估计误差的严格理论保证。本文切入点在于利用Ornstein-Uhlenbeck (OU) 过程的指数混合性质，为经验风险最小化器提供高概率KL散度上界。通过构建基于OU算子的风险函数并应用集中不等式，证明了在近似误差较小时，泛化误差以 $O(\log^3 n / n)$ 的速率收敛。这一结果填补了非渐近统计保证的空白，但其理论优势能否转化为高维图像生成中的实际性能提升，尚存疑问。

## 研究背景

当生成模型试图将源分布传输至目标分布时，薛定谔桥问题要求寻找一个耦合，使其相对于参考过程（如布朗运动）的相对熵最小。参考过程的选取直接决定了传输路径的几何特性与统计性质；若参考过程为布朗运动，其端点间的相关性以多项式速率衰减，导致初始样本对最终结果产生过度影响，且无法捕捉数据的各向异性结构。为克服这一局限，本文引入OU过程作为参考动力学，其均值回归特性使得端点相关性以指数速率衰减，从而在理论上更适配非配对数据翻译任务。

主流薛定谔桥求解器如迭代比例拟合 (IPF) 和流匹配 (FM) 已确立了无模拟训练范式，解决了高维计算复杂性，但理论分析往往局限于渐近行为或理想化设定。Korotin et al. (2024) 虽提供了LightSB算法的期望收敛率，但未给出耦合层面KL散度的高概率界；Rigollet & Stromme (2025) 分析了双目标函数的收敛性，却未触及估计耦合与真实最优耦合之间的分布距离。本文聚焦于这一理论缺口，旨在为基于OU参考过程的薛定谔桥势函数估计提供非渐近的高概率泛化界，从而在有限样本场景下量化估计误差。

## 核心方法

### 方法参照系

本文方法基于LightSB框架，该框架通过参数化Schrödinger势函数来近似最优耦合，避免了IPF的迭代耦合。关键差异在于，LightSB通常采用布朗运动作为参考过程，而本文将其替换为OU过程，以利用其指数混合性质推导更紧的统计界。

### OU参考过程与风险函数

设计动机在于解决布朗运动参考过程导致的端点强相关性问题，该问题在图像翻译中表现为初始图像对输出结果的过度干扰。本文选取OU过程 $dX_t = b(m - X_t)dt + \sqrt{\Sigma}dW_t$ 作为参考动力学，其转移密度 $q_T(y|x)$ 具有闭式高斯形式。基于此，定义经验风险函数为：

$$
\hat{L}(\phi) = \frac{1}{n}\sum_{j=1}^n \log c_\theta(Z_j) - \frac{1}{n}\sum_{i=1}^n \log v_\theta(Y_i)
$$

其中 $v_\theta(y)$ 为调整后的势函数，$c_\theta(x)$ 为归一化常数。该公式的物理含义是最大化耦合 $\pi_\theta(x,y) = \nu_0(x) q_T(y|x) \nu_T(y)$ 在数据上的对数似然，同时通过OU算子 $T_t$ 的闭式解加速计算，避免了数值积分。

### 高概率泛化界

设计动机在于现有理论仅提供期望收敛率，无法保证单次运行的可靠性，而生成建模任务对单次估计的稳定性要求极高。本文利用OU过程的指数遍历性，证明经验风险最小化器 $\hat{\pi}$ 与最优耦合 $\pi^*$ 之间的KL散度满足：

$$
\text{KL}(\pi^*, \hat{\pi}) \leq C \left( \frac{\log^3 n}{n} + \epsilon_{\text{approx}}^2 \right)
$$

其中 $C$ 为常数，$\epsilon_{\text{approx}}$ 为势函数类的近似误差。该界表明，当近似误差足够小时，统计误差以 $O(\log^3 n / n)$ 的速率收敛，接近参数模型的最优速率。这一结果依赖于OU过程的混合性质，使得随机变量具有亚指数尾，从而允许应用Bernstein不等式进行集中控制。

## 实验评估

实验在25分量高斯混合分布和单细胞RNA测序数据上进行，基线包括LightSB、DSB、OT-CFM等。LightSB-OU在单细胞数据上取得W1=0.812±0.020，优于LightSB的0.823±0.017，但低于OT-CFM的0.790±0.068。在高斯混合任务中，LightSB-OU的Sliced W1为0.156±0.018，显著优于LightSB的0.260±0.016，且模式覆盖率达到25.0±0.0，表明OU参考过程有效提升了分布匹配的完整性。

| 实验任务 | 指标 | LightSB | LightSB-OU | OT-CFM |
| :--- | :--- | :--- | :--- | :--- |
| 单细胞数据 | W1 | 0.823±0.017 | 0.812±0.020 | 0.790±0.068 |
| 高斯混合 (Standard) | Sliced W1 | 0.260±0.016 | 0.156±0.018 | - |
| 高斯混合 (Irregular) | Sliced W1 | 0.525±0.024 | 0.214±0.028 | - |
| 高斯混合 (Anisotropic) | Sliced W1 | 0.255±0.017 | 0.206±0.024 | - |

消融实验显示，在25分量高斯混合任务中，增加势函数分量数 $K$ 至30时，LightSB-OU在所有三种配置下均显著降低W1和MMD，且模式覆盖率达到理论最大值25.0。这表明OU参考过程与高斯混合势函数的组合具有较好的可扩展性，但在单细胞数据上，其性能提升幅度（0.011）小于高斯混合任务（0.104），暗示在复杂生物数据中，参考过程的改进可能受到其他因素（如数据噪声、维度）的制约。

评估边界方面，论文未提供代码URL，但超参数通过Optuna优化并报告了具体值（如 $b=2.0, m=0.0$ for I2I）。指标涵盖W1、MMD和模式覆盖率，但缺乏FID等图像生成常用指标，限制了其在高维视觉任务上的直接可比性。实验在个人电脑（AMD Ryzen 5 1600）上完成，计算效率未量化，无法评估其在大规模数据上的实际耗时。

## 关联研究分析

从问题动机看，本文与QDSB (Fuchs et al., 2026) 同属无模拟薛定谔桥求解器，但QDSB侧重通过量化锚点加速训练，解决计算效率问题；本文则聚焦理论保证，解决统计可靠性问题。QDSB在Gauss ↔ GMM 2D任务上取得W2=0.010，优于本文未报告的对应指标，表明在低维合成数据上，计算加速策略可能比理论界更直接地提升性能。本文的理论优势在于提供了误差界，但未验证该界在实际高维任务中的紧致性，导致其在单细胞数据上未超越OT-CFM。

从方法设计看，本文与Korotin et al. (2024) 的LightSB框架共享势函数参数化思路，但LightSB使用布朗运动参考过程，其端点相关性衰减慢，导致在图像翻译中需要更大的 $\sigma$ 或 $T$ 来缓解初始样本影响。本文的OU过程通过均值回归项 $b(m - X_t)$ 加速混合，理论上更适配非配对数据。然而，OU过程的各向同性假设（$\Sigma = \epsilon I_d$）可能限制了其对复杂各向异性数据的建模能力，这在单细胞数据上的性能差距中有所体现。

## 总结

本文核心矛盾在于薛定谔桥求解器缺乏有限样本下的严格统计保证，导致其在数据稀疏场景下的可靠性未知。本文抓住OU过程的指数混合性质，通过构建基于OU算子的风险函数并应用集中不等式，证明了经验风险最小化器的KL散度以 $O(\log^3 n / n)$ 速率收敛。实验验证了该理论优势在低维合成数据上的有效性，Sliced W1从0.260降至0.156，但在单细胞数据上仅从0.823降至0.812，未超越OT-CFM。这一差距暴露了理论界紧致性与实际高维数据复杂性之间的鸿沟。当数据维度增加且分布呈现复杂各向异性时，OU参考过程的指数混合优势是否足以抵消其各向同性假设带来的表达力损失，论文未给出回答。
