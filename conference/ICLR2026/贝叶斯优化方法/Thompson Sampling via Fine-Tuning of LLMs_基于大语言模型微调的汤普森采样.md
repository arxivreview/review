# ICLR2026最新论文 ｜Thompson Sampling via Fine-Tuning of LLMs ｜基于大语言模型微调的汤普森采样

研究机构：IBM研究院

作者：Nicolas Menet、Aleksandar Terzić、Michael Hersche 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.13328)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.13328)

> 贝叶斯优化在超大规模无结构离散空间（如蛋白质序列、量子电路）中面临采集函数最大化不可行的计算瓶颈，传统梯度上升或投影方法在此类缺乏几何结构的组合空间中失效。本文切入点在于摒弃显式最大化，转而直接参数化“最大化概率”（Probability of Maximality, PoM），将优化问题转化为生成式模型的微调任务。通过变分贝叶斯乐观采样（Variational Bayesian Optimistic Sampling, VBOS）目标函数引导预训练大语言模型（LLM）向奖励后验分布适应，TOSFIT 实现了兼具理论保证与计算效率的离散空间优化。该方法在样本效率上优于强化学习与进化搜索基线，但其性能高度依赖 LLM 先验与任务结构的匹配度，在未见过的离散结构上泛化能力存疑。

## 研究背景

在连续域中，贝叶斯优化（Bayesian Optimization, BO）通过高斯过程（Gaussian Process, GP）代理模型量化不确定性，并利用采集函数平衡探索与利用。然而，当搜索空间扩展至无结构离散域时，采集函数的最大化变得计算不可行：连续域可通过梯度上升求解，而离散域缺乏梯度信息，需遍历所有组合点，导致复杂度随空间规模指数爆炸。这一困境在蛋白质设计（20 种氨基酸，长度 100 即超过可观测宇宙原子数）和量子电路设计中尤为突出，使得标准 BO 范式在此类高价值科学场景中失效。

现有针对离散空间的解决方案多依赖结构假设或启发式搜索。例如，REMBO 通过随机嵌入将高维连续问题投影至低维子空间，TuRBO 利用局部信任域缓解计算瓶颈，但这些方法均预设了空间的某种几何或局部结构，无法直接应用于无结构的组合空间。另一类方法如 FIBO 或进化搜索，虽能处理离散变量，但缺乏严格的理论保证，且往往依赖指令跟随能力或复杂的奖励工程，导致样本效率低下。本文的核心切入点在于利用预训练 LLM 的强先验知识，将汤普森采样（Thompson Sampling, TS）中的“从后验采样”操作转化为对 LLM 的增量微调，从而规避显式最大化，同时保留 TS 的理论优势。

## 核心方法

### 变分贝叶斯乐观采样框架

标准 TS 在离散域中需从奖励后验中采样函数并寻找其最大值，这在组合空间中不可行。本文采用 VBOS 作为替代框架，其核心思想是寻找一个策略 $\pi$，使其最大化变分目标函数 $V(\pi)$，该目标函数近似于 PoM。VBOS 揭示了 PoM 与带有熵正则化的上置信界（UCB）之间的内在联系，使得策略优化成为可能。然而，精确求解 VBOS 在大规模离散域中仍不可行，因此本文采用基于梯度的近似优化，并通过理论分析证明，只要策略 $\pi$ 与精确 VBOS 策略 $\tilde{\pi}$ 之间的 Bregman 散度足够小，累积遗憾界即可保持次线性增长。

### LLM 微调与梯度稳定化

TOSFIT 的关键创新在于将 VBOS 的梯度上升过程实例化为 LLM 的微调。设计动机在于：预训练 LLM 已包含丰富的领域先验（如蛋白质序列语法、量子电路逻辑），直接作为策略初始化可避免从均匀分布开始探索的巨大开销。具体而言，TOSFIT 使用线性核 GP 基于固定嵌入（如 ProtGPT2 或 Qwen3-Embedding）计算奖励后验，并推导 VBOS 目标关于 LLM 参数 $\theta$ 的梯度：

$$
\nabla_\theta V(\pi_\theta) = \mathbb{E}_{x \sim \pi_\theta} \left[ \hat{r}_x^\theta \nabla_\theta \log \pi_\theta(x) \right]
$$

其中 $\hat{r}_x^\theta = \mu_x - v^{-1}(\pi_\theta(x)) \cdot \sigma_x$ 为伪奖励，$v^{-1}$ 为 VBOS 近闭式解的反函数。该公式表明，梯度方向取决于当前策略对真实奖励均值的低估程度：若 LLM 生成的候选点 $x$ 的预测均值 $\mu_x$ 高于其当前生成概率所隐含的期望，则梯度将提升该点的生成概率。

为稳定梯度估计，TOSFIT 引入 RLOO（Reinforce Leave-One-Out）基线，将伪奖励减去批次内其他样本的均值，并除以经验标准差。这一设计等价于 Group Relative Policy Optimization 中的优势函数，有效降低了高方差问题，使得小学习率下的微调能够谨慎地适应后验 PoM，同时保留预训练先验中的关键结构信息。

## 实验评估

实验在三个离散任务上进行：FAQ 响应优化（Qwen3-1.7B/8B）、热稳定蛋白质搜索（ProtGPT2-0.7B）和量子电路设计（Qwen2.5-Coder-1.5B/7B）。基线覆盖无引导生成、后生成 TS、Actor-Critic、Soft Actor-Critic、FIBO 及进化搜索。由于论文未提供具体的数值表格，仅通过 Figure 4 展示 Best-Seen Reward 随评估次数的变化趋势，无法提取具体数值进行量化对比。

从定性结果看，TOSFIT 在三个任务上均表现出优于基线的样本效率。在蛋白质搜索中，TOSFIT 显著快于 FIBO 和进化搜索，表明 VBOS 目标比基于奖励的强化学习策略更有效地利用了 GP 的不确定性信息。在量子电路设计中，TOSFIT 同样领先，说明其在复杂逻辑结构上的适应性。消融实验（Section 5.6）验证了预训练初始化的重要性：从均匀策略开始的 VBOS 在高维概率单纯形中难以收敛，而 TOSFIT 通过预训练初始化位于正确区域，仅需少量微调即可接近最优策略。

评估边界方面，实验仅使用自定义任务，缺乏与标准离散 BO 基准（如 NAS-Bench-201 中的特定子集）的横向对比。代码已开源，但超参数（如学习率 $\eta$、批次大小 $B$）对性能的影响未详细讨论。此外，GP 的线性核假设可能限制了其对复杂非线性奖励函数的建模能力，论文未探讨非线性核或深度核的影响。

## 关联研究分析

从问题动机看，TOSFIT 与 FIBO 均旨在解决离散空间 BO 的采样效率问题，但路线截然不同。FIBO 依赖 LLM 的指令跟随能力执行复杂的搜索程序，而 TOSFIT 将 LLM 视为概率生成器，通过微调适应后验。这一差异源于对 LLM 角色的不同定位：FIBO 视 LLM 为“执行器”，TOSFIT 视 LLM 为“策略参数化器”。根源在于任务特性：蛋白质和量子电路任务中，奖励函数与 LLM 预训练分布高度相关，使得微调比指令跟随更高效；而在奖励函数与预训练分布无关的任务中，FIBO 的指令跟随能力可能更具优势，但论文未对此进行验证。

从方法设计看，TOSFIT 与 GP-UCB 在理论保证上具有同源性，均依赖核结构推导遗憾界。但 GP-UCB 适用于连续或低维离散空间，通过显式最大化 UCB 选择点；TOSFIT 则通过隐式采样（微调）规避最大化。这一差异暗示了离散空间 BO 的理论瓶颈：显式最大化在组合空间中不可行，而隐式采样虽可行，但依赖生成模型的表达能力。若 LLM 先验与任务结构不匹配（如未见过的分子骨架），微调可能无法纠正先验偏差，导致遗憾界中的 Bregman 散度项主导，性能退化。

## 总结

本文核心矛盾在于无结构离散空间中采集函数最大化的计算不可行性与理论保证的必要性之间的冲突。TOSFIT 抓住 LLM 预训练先验与任务结构的潜在匹配性，通过 VBOS 目标微调 LLM 直接参数化 PoM，规避了显式最大化。实验证明其在蛋白质和量子电路任务上优于强化学习与进化搜索基线，且理论遗憾界从 $O(\sqrt{T|X|})$ 改进至 $O(\sqrt{T\gamma[T]})$。然而，其性能高度依赖 LLM 先验质量，当任务结构与预训练分布差异较大时，微调可能无法有效纠正偏差。当 LLM 先验与任务结构不匹配时，TOSFIT 的样本效率是否仍优于基于指令跟随的方法，论文未给出回答。
