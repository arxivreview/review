# ICLR2026最新论文 ｜ASYMMETRIC SYNTHETIC DATA UPDATE FOR DOMAIN INCREMENTAL DATASET DISTILLATION ｜域增量数据集蒸馏中的非对称合成数据更新

作者：Minyoung Oh、Jae-Young Sim

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_32982957)

> 域增量数据集蒸馏（Domain Incremental Dataset Distillation, DIDD）旨在解决数据随时间顺序到达时，如何在固定存储预算下持续蒸馏而不丢失旧域知识的问题。传统数据集蒸馏方法仅关注对最新数据的适配，导致早期域知识被覆盖，引发灾难性遗忘。本文通过引入稳定性损失与非对称更新策略，利用双层优化为每个样本分配独立的稳定性与可塑性更新率，从而在单一合成数据集中平衡新旧知识的保留。该方法在多个增量基准上显著优于现有持续学习基线，但其评估局限于小尺度数据集，且未验证在大规模复杂域上的泛化能力。

## 研究背景

当深度学习模型面对随时间顺序到达的不同域数据时，若采用逐域蒸馏策略，存储与训练成本将随域数量线性增长。为维持固定存储预算，需将新域知识融入已有的合成数据集，这一过程面临核心矛盾：合成数据需快速适应新域分布（可塑性），同时必须保留旧域特征（稳定性）。这种稳定性与可塑性的内在冲突，直接导致了灾难性遗忘现象，即新域知识的注入导致旧域性能急剧下降。

数据集蒸馏（Dataset Distillation, DD）的主流路线如分布匹配（Distribution Matching, DM），通过最小化合成数据与真实数据在特征空间的最大均值差异（Maximum Mean Discrepancy, MMD）来优化合成样本。然而，现有DD方法假设数据一次性可用，仅最大化可塑性，未考虑时序约束。在增量场景下，直接应用DM会导致合成数据完全被最新域主导，旧域信息被抹除。本文切入点在于将DD扩展至域增量场景，通过显式建模稳定性与可塑性的权衡，解决固定存储预算下的知识遗忘问题。

## 核心方法

### 分布匹配基线与增量约束

本文基于DM范式构建增量蒸馏框架。传统DM通过最小化合成数据 $\hat{\mathbf{D}}_t$ 与真实数据 $\mathbf{D}_t$ 的特征分布差异来优化合成样本，其损失函数定义为可塑性损失：

$$ \mathcal{L}_{plastic}(\hat{\mathbf{x}}_t) = d(F(\mathbf{x}_t), F(\hat{\mathbf{x}}_t)) $$

其中 $d(\cdot, \cdot)$ 为高斯核MMD，$F(\cdot)$ 为随机初始化模型提取的特征。在DIDD设定中，仅最小化该损失会导致 $\hat{\mathbf{D}}_t$ 仅包含当前域 $\mathbf{D}_t$ 的知识，而丢失前一时刻合成数据集 $\hat{\mathbf{D}}_{t-1}$ 中的旧域信息。为保留旧知识，本文引入稳定性损失 $\mathcal{L}_{stable}$，强制 $\hat{\mathbf{D}}_t$ 的特征与 $\hat{\mathbf{D}}_{t-1}$ 保持一致，从而在优化目标中显式加入时序约束。

### 非对称更新与双层优化

直接联合最小化 $\mathcal{L}_{plastic}$ 和 $\mathcal{L}_{stable}$ 会导致梯度冲突，因为两个目标分别指向不同的特征空间方向。本文提出非对称合成数据更新策略，为每个样本 $\hat{\mathbf{x}}_i$ 引入独立的缩放参数 $\alpha_i$ 和 $\beta_i$，分别控制稳定性与可塑性梯度的更新幅度：

$$ \hat{\mathbf{x}}_t^{new} = \hat{\mathbf{x}}_t - \eta_{\mathbf{x}} (\bar{\alpha}_i \mathbf{g}_{S,i} + \bar{\beta}_i \mathbf{g}_{P,i}) $$

其中 $\bar{\alpha}_i, \bar{\beta}_i$ 为经Sigmoid函数约束在 $(\alpha_{min}, \alpha_{max})$ 和 $(\beta_{min}, \beta_{max})$ 范围内的值。该设计允许每个样本专注于稳定性或可塑性，避免单一更新率导致的次优解。为求解最优的 $\alpha_i$ 和 $\beta_i$，本文采用基于元学习的双层优化框架。外层优化通过最小化元损失 $\mathcal{L}_{meta}$ 更新 $\alpha_i, \beta_i$，同时引入惩罚项 $\mathcal{L}_{penalty}$ 防止所有样本同时最大化更新率导致的平凡解：

$$ \mathcal{L}_{meta}^{penalty} = \mathcal{L}_{meta} + \lambda_{\alpha} \sum_{i=1}^N \bar{\alpha}_i + \lambda_{\beta} \sum_{i=1}^N \bar{\beta}_i $$

这一机制使接近违反稳定性或可塑性约束的样本获得更大的更新权重，实现了样本级的自适应平衡。

## 实验评估

实验在Rotated MNIST (R-MNIST)、Seq-CORe50和PACS三个域增量基准上进行，使用3层ConvNet作为特征提取器，每域蒸馏3,000次迭代。基线涵盖Finetune、EWC、MAS、LF、LwF等持续学习方法，以及Joint（联合蒸馏上限）和Gather（逐域蒸馏累积）。

| 数据集 | 方法 | IPC=10 Avg Acc (%) | IPC=20 Avg Acc (%) |
| :--- | :--- | :--- | :--- |
| PACS | Finetune | 26.9 ± 0.8 | - |
| PACS | LwF | 35.0 ± 0.6 | - |
| PACS | MAS | 35.0 ± 1.7 | - |
| PACS | Proposed | 48.0 ± 3.1 | - |
| R-MNIST | Finetune | 33.4 ± 0.7 | 31.3 ± 2.0 |
| R-MNIST | + L_stable | 26.9 ± 0.7 | 29.4 ± 3.7 |
| R-MNIST | + Asym. (Bi-level) | 36.3 ± 1.1 | 32.9 ± 1.0 |

在PACS数据集上，本文方法在IPC=10时达到48.0%的平均准确率，显著优于LwF的35.0%和Finetune的26.9%。消融实验显示，仅添加稳定性损失（+ L_stable）在R-MNIST早期域段（A_1:5）性能从33.4%降至26.9%，表明稳定性约束单独使用会损害可塑性。引入非对称双层优化后，早期域段性能恢复至36.3%，且晚期域段（A_16:20）达到94.5%（IPC=10），证明该策略有效平衡了新旧知识。

评估边界方面，本文仅使用32×32分辨率的小尺度数据集，未验证在ImageNet等大规模数据上的可扩展性。代码未公开，超参数如 $\alpha_{max}=2$ 的敏感性分析缺失。此外，基线中未包含生成式蒸馏方法（如CoDA），无法对比生成先验在增量场景下的表现。

## 关联研究分析

从问题动机看，本文与持续学习中的正则化方法（如EWC、MAS）存在本质差异。EWC和MAS通过约束模型参数更新来防止遗忘，而本文直接优化合成数据本身，将遗忘问题转化为数据分布的稳定性约束。这一差异源于DD的目标是生成静态代理数据，而非训练动态模型。然而，本文未讨论当域间分布差异极大时，固定存储预算是否足以容纳所有域的判别性特征，这可能导致合成数据在极端域偏移下的性能瓶颈。

从方法设计看，本文的双层优化框架借鉴了元学习（MAML）的结构，但目标不同。MAML优化模型参数以快速适应新任务，而本文优化数据更新率以平衡稳定性与可塑性。与分布匹配方法（如DM）相比，本文引入了时序依赖的稳定性损失，这是静态DD所不具备的。但本文未探索生成式模型在增量蒸馏中的应用，生成先验可能提供更丰富的语义结构，缓解优化方法合成数据的“噪声状”问题，这一潜在优势在本文中被忽略。

## 总结

本文核心矛盾在于固定存储预算下，增量到达的域数据导致合成数据集的稳定性与可塑性冲突。现有DD方法仅关注可塑性，导致旧域知识被覆盖，而持续学习方法作用于模型参数，不适用于静态数据蒸馏。本文通过非对称更新策略，利用双层优化为每个样本分配独立的稳定性与可塑性权重，实现了样本级的自适应平衡。实验证明，该方法在PACS上IPC=10时达到48.0%准确率，较Finetune提升21.1个百分点，且有效缓解了R-MNIST上的灾难性遗忘。其边界在于评估局限于小尺度数据集，未验证大规模域偏移下的泛化能力，且未对比生成式方法。当域间分布差异超过合成数据的表达能力时，非对称更新策略是否仍能维持性能，论文未给出回答。
