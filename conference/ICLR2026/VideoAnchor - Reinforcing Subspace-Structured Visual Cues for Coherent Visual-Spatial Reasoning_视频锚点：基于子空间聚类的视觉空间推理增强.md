论文原文见 [arXiv](https://arxiv.org/abs/2509.25151)

> 多模态大语言模型在跨帧视觉空间推理中常因语言先验压制视觉线索而产生幻觉，现有测试时增强方法多依赖启发式注意力调整或外部编码器，缺乏对视觉结构内在一致性的建模。VideoAnchor 抓住“视觉 token 在注意力中贡献过弱且缺乏跨帧语义锚点”这一被忽略的机制缺陷，通过稀疏子空间聚类提取共享视觉结构并转化为注意力缩放因子，在推理阶段无需训练即可强化空间推理。该方法在 VSI-Bench 和 Video-MME 上带来稳定提升，但其隐式几何建模在复杂遮挡场景下的鲁棒性仍存疑。

## 研究背景

当模型处理多帧视频中的空间关系时，视觉编码器输出的 token 往往被语言骨干的统计规律所淹没。这种压制导致模型无法在帧间保持对同一物体或区域的稳定关注，进而产生与视觉输入矛盾的空间描述。为解决此问题，稀疏子空间聚类（Sparse Subspace Clustering, SSC）提供了一种结构化视角：它假设数据点位于多个子空间的并集上，每个点可由同一子空间内的其他点线性表示。这种自表达特性天然捕捉了跨帧的语义连续性，为识别稳定的视觉锚点提供了数学基础。

当前视觉空间推理的主流路线分为显式几何接地与隐式特征融合两类。显式方法如 GeoWeaver 引入深度图或点云作为硬约束，虽在复杂 3D 任务中表现鲁棒，但依赖外部几何输入且计算开销大；隐式方法如 Spatial-ViLT 通过辅助任务学习几何特征，无需架构修改，但在真实世界噪声下鲁棒性不足。测试时增强路线（如 VisionFuse）试图避免重训练成本，但多依赖多编码器融合或手动区域指定，缺乏对视觉结构内在一致性的建模。VideoAnchor 的切入点在于：不引入外部几何信息，而是直接在视觉 token 层面挖掘子空间结构，将跨帧共享的语义模式转化为注意力机制中的缩放信号，从而在推理阶段实现视觉锚点的强化。

## 核心方法

### 方法参照系

本文问题属于测试时视觉增强范畴，与 VisionFuse 等方法的通用流程一致：在推理阶段修改注意力计算以强化视觉信号。关键差异在于，现有方法多基于像素级或区域级的启发式调整，而 VideoAnchor 将增强机制从局部像素级提升至语义子空间级，通过结构化聚类识别跨帧一致的视觉锚点。

### 子空间到缩放因子单元

该单元解决“视觉 token 缺乏跨帧语义一致性”的失效。传统注意力机制将 token 视为独立单元，无法捕捉物体或区域在帧间的连续性。VideoAnchor 首先通过 SSC 求解自表达矩阵 $W$，其优化目标为：

$$ \min_{W} \lambda_e \| X_{Vis} - W X_{Vis} \|_1 + \lambda_z \| W \|_1 \quad \text{s.t.} \quad \text{diag}(W) = 0 $$

该公式通过 $l_1$ 范数约束确保每个 token 仅由同一子空间内的稀疏邻居重构，从而揭示视觉 token 的底层子空间结构。随后，基于 $W$ 构建对称邻接矩阵并应用谱聚类，为每个 token 分配子空间标签 $c_i$。接着，计算每个 token 的共享表达分数 $s_i$，定义为子空间基数 $\pi_i$（同簇 token 数量）与自表达行和 $r_i$（重构强度）的乘积：

$$ s_i = \pi_i \cdot r_i $$

该分数量化了 token 作为视觉锚点的稳定性：既要求其在语义上被广泛共享（大 $\pi_i$），又要求其在结构上对重构其他 token 有强贡献（大 $r_i$）。最后，将 $s_i$ 归一化至 $[0,1]$ 并扩展至文本 token 位置（赋值为 0），生成 token 级缩放因子 $\gamma_{Q,K,V} = 1 + \alpha_{Q,K,V} \tilde{s}$，其中 $\alpha$ 为手动设定的调制强度。

### 注意力正则化单元

该单元解决“视觉锚点在注意力计算中权重不足”的失效。标准自注意力机制中，视觉 token 的贡献常被语言 token 压制。VideoAnchor 将缩放因子 $\gamma$ 嵌入注意力计算，修改后的注意力矩阵 $A$ 为：

$$ A = \sigma\left( \gamma_Q Q K^T \gamma_K \odot \exp\left( \frac{QK^T}{\sqrt{d_h}} \right) \right) $$

该公式在指数运算后对 query-key 相似度进行成对门控，确保所有条目非负且归一化步骤保持完整，同时选择性地将注意力概率质量重新分配至共享锚点。输出表示 $Y$ 进一步通过值向量放大：

$$ Y = A \cdot \text{Expand}_c(\gamma_V V) $$

$\text{Expand}_c$ 将 token 级缩放因子广播至通道维度，确保锚点 token 不仅被更强烈地关注，还在最终聚合输出中获得更高权重。该设计在 MLLM 的每一层块中插入，实现空间接地的一致性增强。

## 实验评估

实验在 VSI-Bench（视频空间推理）、All-Angles-Bench（多视角空间推理）和 Video-MME（通用视频理解）上进行，覆盖 InternVL、Qwen、LLaVA 系列骨干。基线审计显示，论文未与 GeoWeaver、SpatialLadder 等训练式 SOTA 方法直接对比，仅与自身骨干的基线版本比较，限制了绝对性能的评估。

| 基准 | 骨干模型 | 基线分数 | +VideoAnchor | 提升幅度 |
| :--- | :--- | :--- | :--- | :--- |
| VSI-Bench | InternVL2-8B (8帧) | 34.6 | 37.8 | +3.2 |
| VSI-Bench | LLaVA-Video-72B (16帧) | 39.4 | 40.9 | +1.5 |
| All-Angles-Bench | LLaVA-Video-72B | 49.9 | 53.0 | +3.1 |
| Video-MME | Qwen2.5VL-72B (16帧) | 75.4 | 80.0 | +4.6 |

核心数字对比表明，VideoAnchor 在更大模型上带来更显著的提升，InternVL2-8B 在 VSI-Bench 上提升 3.2%，Qwen2.5VL-72B 在 Video-MME 上提升 4.6%，验证了方法随模型容量扩展的有利行为。

消融实验揭示了关键设计决策。在 VSI-Bench 上，仅对 V 缩放带来 +1.8 提升，添加 Q 和 K 后提升至 +2.2，三者同时缩放达到 +2.8，表明 Q/K/V 联合调制优于单一组件。在子空间聚类方法对比中，SSC 达到 37.8，显著优于 k-Means 的 35.2 和 UniformBoost 的 34.2，证实了结构化子空间建模对视觉锚点识别的必要性。共享表达分数中，仅使用子空间基数（+1.0）或仅使用自表达行和（+0.4）均弱于两者结合（+3.2），说明锚点稳定性需同时考虑语义共享与结构代表性。

评估边界方面，论文未报告置信区间，数值比较需谨慎。代码已开源，但超参数 $\alpha_{Q,K,V}$ 为手动设定，缺乏自动化调整机制。评估协议未涵盖真实世界噪声场景，且未与显式几何接地方法在相同骨干下对比，限制了方法鲁棒性的全面评估。

## 关联研究分析

从问题动机看，VideoAnchor 与 GeoWeaver 形成显式与隐式几何建模的对比。GeoWeaver 引入深度图或点云作为硬约束，在 VSI-Bench 上达到 57.9%，但依赖外部几何输入且计算开销大；VideoAnchor 通过 SSC 挖掘视觉 token 内部的子空间结构，无需外部输入，在 InternVL2-8B 上达到 37.8%。差异根源在于任务特性：GeoWeaver 适用于几何信息精确的场景，而 VideoAnchor 更适合几何信息不精确或不可得的真实世界场景。然而，隐式子空间结构能否替代显式几何约束处理复杂 3D 遮挡，论文未给出回答。

从方法设计看，VideoAnchor 与 VisionFuse 同属测试时增强路线，但机制不同。VisionFuse 依赖多编码器融合，计算成本高且需额外编码器；VideoAnchor 通过单编码器的 SSC 聚类实现，计算效率更高。差异根源在于增强粒度：VisionFuse 在像素级或区域级调整注意力，而 VideoAnchor 在语义子空间级识别锚点。这种粒度提升使得 VideoAnchor 能捕捉跨帧的物体连续性，而 VisionFuse 可能遗漏高层语义结构。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

VideoAnchor 要解决的核心矛盾是 MLLMs 在跨帧视觉空间推理中视觉线索被语言先验压制的问题。现有测试时增强方法缺乏对视觉结构内在一致性的建模，而 VideoAnchor 通过 SSC 提取跨帧共享的语义子空间，将视觉锚点转化为注意力缩放因子，在推理阶段实现无需训练的视觉强化。该方法在 VSI-Bench 上为 InternVL2-8B 带来 3.2% 提升，在 Video-MME 上为 Qwen2.5VL-72B 带来 4.6% 提升，验证了子空间结构化建模的有效性。其边界在于：隐式几何建模在复杂遮挡场景下的鲁棒性未经验证，且超参数手动设定限制了自动化部署。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
