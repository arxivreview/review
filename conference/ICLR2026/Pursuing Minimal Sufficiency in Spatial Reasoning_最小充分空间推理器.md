# ICLR2026最新论文 ｜Pursuing Minimal Sufficiency in Spatial Reasoning ｜最小充分空间推理器

研究机构：上海交通大学、北京理工大学

作者：Yejie Guo、Yunzhong Hou、Wufei Ma 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.16688)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.16688)

> 视觉语言模型（VLM）在3D空间推理中常因缺乏几何先验和冗余信息干扰而失效。现有单模型微调或累积式智能体框架未能解决信息过载导致的注意力稀释问题。MSSR通过双智能体闭环构建“最小充分集”，在零样本设定下显著提升了多视图空间推理精度。该方法验证了“少即是多”的认知原则，但其对强推理骨干的依赖及迭代延迟仍是实际部署的潜在瓶颈。

## 研究背景

当VLM面对多视图3D场景时，其预训练数据中缺失的几何先验导致深度与方位感知失效。这种感知缺陷迫使模型依赖语义捷径，而3D环境的高信息密度进一步加剧了问题：朴素聚合所有感知结果会引入大量弱相关细节，稀释模型注意力并诱发启发式错误。这一现象揭示了空间推理的两个核心瓶颈：3D感知能力不足与信息冗余导致的推理退化。

主流解决方案分为两类：一是通过合成数据微调或集成点云模块增强单模型能力，但这依赖昂贵的3D指令数据且易引发灾难性遗忘；二是采用ReAct等累积式智能体框架，通过工具调用逐步获取信息。然而，累积策略在密集场景中会累积冗余，反而降低准确率。MSSR的切入点在于引入认知科学中的“最小充分统计量”概念，主张在回答前主动构建一个既充分又最小的信息子集，通过显式剪枝而非单纯累积来优化推理路径。

## 核心方法

### 方法参照系

MSSR属于工具增强智能体推理路线，其基础范式是视觉编程（Visual Programming）。与VisProg等一次性执行框架不同，MSSR的关键差异在于引入了状态保持的闭环迭代机制，将信息获取与策略性剪枝解耦为两个协作智能体，以解决累积式方法在冗余场景下的性能退化。

### 感知智能体与SOG模块

感知智能体（Perception Agent, PA）负责通过代码生成调用外部专家模型提取空间原语。其核心创新在于情境方向接地（Situated Orientation Grounding, SOG）模块，该模块将VLM难以直接回归的3D方向估计重构为视觉选择任务。PA生成稀疏候选方向向量，将其叠加在原始图像与正交视图上，由VLM通过多选机制筛选最匹配语言描述的向量，再迭代细化。这一设计规避了VLM在连续数值回归上的固有缺陷，将几何感知转化为离散的语义匹配问题。

$$ S_{n+1} = S_n \cup \text{SOG}(I, q, \mathcal{V}_{cand}) $$

其中 $\mathcal{V}_{cand}$ 为候选方向向量集，SOG通过视觉提示引导VLM选择最优向量并更新信息集。

### 推理智能体与最小充分集构建

推理智能体（Reasoning Agent, RA）负责维护最小充分集（Minimal Sufficient Set, MSS）。RA首先制定高层推理计划，随后对PA提供的信息集进行减法过滤，剔除与计划无关的项。若剩余信息不足以回答问题，RA发出针对性请求；否则，RA丢弃所有历史上下文，仅基于最终MSS进行链式思维推理。这一机制确保了最终推理过程不受冗余数据干扰，实现了可解释且聚焦的决策。

$$ S^* = \arg\min_{S \subseteq W} |S| \quad \text{s.t.} \quad R^*(S, q) = a^* $$

该公式定义了MSS的优化目标：在满足充分性（能得出正确答案 $a^*$）的前提下，最小化信息集 $S$ 的规模。

## 实验评估

MSSR在MMSI-Bench和ViewSpatial-Bench上进行了零样本评估，基线涵盖专有LLM（o3, GPT-4o）、开源LLM（Qwen3-VL）、3D-VLM（VLM-3R）及智能体框架（ViLaSR）。实验显示，MSSR在MMSI-Bench整体准确率达49.5%，超越最强LLM o3（41.0%）8.5个百分点；在ViewSpatial-Bench达51.8%，显著优于LEO（39.3%）和ViLaSR（30.2%）。

| 方法 | MMSI-Bench Overall | ViewSpatial-Bench Overall |
| :--- | :--- | :--- |
| o3 | 41.0 | 41.0 |
| GPT-4o | 30.3 | 35.0 |
| VLM-3R | 32.0 | - |
| LEO | 39.3 | 43.7 |
| ViLaSR | 30.2 | 38.2 |
| **MSSR** | **49.5** | **51.8** |

消融实验揭示了组件贡献与冗余效应。移除RA仅保留PA时，MMSI-Bench准确率降至37.1%；移除PA仅保留RA时降至31.1%，证明双智能体协同的必要性。去除SOG模块导致准确率降至46.9%，验证了方向接地对复杂空间查询的关键作用。更关键的是，控制变量实验表明，随着迭代剪枝将信息集元素从17.3个减少至5.9个，推理准确率从45.8%提升至48.3%，实证了信息冗余对LLM推理的负向干扰。

| 消融变体 | MSR (MMSI) | MMSI-Bench | ViewSpatial-Bench |
| :--- | :--- | :--- | :--- |
| GPT-4o (Baseline) | 30.8 | 30.3 | 35.0 |
| Only PA | 33.8 | 37.1 | 32.5 |
| Only RA | 31.8 | 31.1 | 35.3 |
| w/o SOG | 47.0 | 46.9 | 43.2 |
| w/o Iteration | 44.4 | 47.2 | 48.8 |
| **MSSR (Full)** | **50.0** | **49.5** | **51.8** |

评估边界方面，MSSR依赖GPT-4o作为骨干，未报告在轻量级开源模型上的完整性能衰减曲线（仅展示部分交叉模型结果）。代码已开源，但迭代次数上限及SOG候选向量生成策略的超参数细节未在正文中完全披露，可能影响复现一致性。

## 关联研究分析

从问题动机看，MSSR与VisProg同属视觉编程范式，但VisProg侧重通过工具库演化解决任务分解复杂度，而MSSR聚焦于信息冗余对推理准确率的负面影响。VisProg的累积式执行在信息稀疏场景中有效，但在MMSI-Bench这类密集多视图任务中，累积的无关细节会稀释注意力。MSSR通过RA的主动剪枝机制，将“信息获取”转化为“信息筛选”，这一差异源于对3D场景信息密度特性的不同假设：MSSR认为冗余是性能退化的主因，而VisProg更关注工具调用的效率。

从方法设计看，MSSR与LEO等3D-VLM路线形成鲜明对比。LEO通过端到端微调将3D知识内化于模型参数，依赖大规模合成数据，存在灾难性遗忘风险且推理过程黑盒化。MSSR则采用零样本、免训练策略，通过外部工具链和显式MSS构建保持VLM通用能力。这种差异反映了“内化”与“外化”两种技术路线的取舍：LEO追求推理效率与部署简洁性，MSSR追求可解释性与零样本泛化能力。MSSR的MSS推理路径可作为高质量监督数据，为未来训练端到端3D-VLM提供中间桥梁，这在LEO的纯黑盒框架中无法实现。

## 总结

MSSR旨在解决VLM在3D空间推理中因感知缺失与信息冗余导致的性能瓶颈。其核心创新在于将认知科学的最小充分统计量原理转化为双智能体闭环框架，通过SOG模块解决方向接地难题，并通过RA的迭代剪枝构建最小充分集。实验证明，该方法在MMSI-Bench和ViewSpatial-Bench上分别取得49.5%和51.8%的准确率，显著超越o3和LEO等强基线，验证了主动剪枝优于被动累积的假设。然而，MSSR的性能高度依赖GPT-4o的强推理能力，在轻量级开源骨干上性能衰减明显，且迭代机制引入了额外的推理延迟。当支持集规模扩大或场景动态性增强时，最小充分集的构建成本与收益比是否依然成立，论文未给出回答。
