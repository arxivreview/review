# ICLR2026最新论文 ｜FROM “SURE” TO “SORRY”: DETECTING JAILBREAK - IN LARGE VISION LANGUAGE MODEL VIA JAILNEU RONS ｜越狱神经元定位与检测

研究机构：浙江大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_34528762)

> 多模态大语言模型（LVLMs）在引入视觉通道后，其原有的文本安全对齐机制因“模态间隙”而失效，导致越狱攻击面指数级扩张。现有防御多依赖外部过滤或全层表示分析，缺乏对越狱行为内部机理的精准定位，且推理时防御往往伴随高延迟与泛化性不足。本文通过因果消融定位专门响应越狱输入的“越狱神经元”（JailNeurons），并构建轻量级检测器，实现了高检测率与低误报率的平衡。该方法在内部激活检测子领域表现优异，但其白盒假设限制了在闭源模型中的直接应用，且对良性数据分布的敏感性暴露了特征提取的潜在脆弱性。

## 研究背景

当 LVLMs 处理包含排版文本或对抗扰动的图像时，视觉编码器将恶意语义注入语言模型，绕过了针对纯文本设计的过滤器。这一现象源于视觉嵌入与文本嵌入在安全语义空间中的分布差异，即“模态间隙”。模态间隙导致标准的安全神经元（SafeNeurons）无法有效覆盖视觉输入，使得模型在理解图像内容时未能将其与安全风险关联，出现“安全感知失败”。为量化这种失效，研究者通常使用攻击成功率（ASR）衡量攻击有效性，而防御机制则需平衡拒绝率（Refusal Rate）与过度拒绝率（Over-Refusal Rate），以避免牺牲模型效用。

现有防御路线主要分为训练时安全对齐与推理时干预。训练时方法如 SafeMLLM 通过对抗训练增强鲁棒性，但计算开销大且依赖高质量标注数据；推理时方法如 HiddenDetect 利用 Logit Lens 分析中间层激活，但往往依赖全层或浅层线性探测，难以隔离高维噪声中的越狱特定信号，且对分布外（OOD）攻击泛化能力弱。本文的切入点在于区分“拒绝标准有害查询”的 SafeNeurons 与“捕获越狱绕过路径”的 JailNeurons，通过定位后者实现更精准、高效的越狱检测，填补了神经元级越狱机理研究的空白。

## 核心方法

### 方法参照系

本文问题属于推理时防御中的内部激活分析范畴。通用流程通常提取中间层隐藏状态，通过线性分类器或语义相似度度量区分良性与恶意输入。本文的关键差异在于不直接使用全维激活，而是通过可学习掩码优化定位稀疏的越狱特定神经元，并采用多层聚合策略以增强泛化性。

### 越狱神经元定位

针对全层激活包含大量与越狱无关噪声的问题，本文提出“Sure-to-Sorry”定位程序。该过程通过因果消融，识别那些掩蔽后能将模型输出从有害响应（如“Sure”）翻转为拒绝响应（如“Sorry”）的神经元。形式化地，对于第 $i$ 层，引入可学习掩码 $m \in [0, 1]^d$，优化目标为最小化交叉熵损失与 $L_1$ 正则项之和：

$$ \min_{\delta} \mathcal{L}_{CE}(f_i(\sigma(\delta), x), e_s) + \lambda \|\sigma(\delta)\|_1 $$

其中 $\sigma(\delta)$ 为 sigmoid 函数，$e_s$ 为拒绝响应嵌入，$\lambda$ 控制稀疏度。这一设计通过稀疏约束隔离了关键信号，解决了全维激活中噪声干扰导致的分类边界模糊问题。

### 多层聚合检测

单层神经元无法覆盖不同攻击类型引发的多样化越狱特征，导致 OOD 泛化失败。本文采用“Top-to-Bottom”算术采样策略，从模型顶层向下每隔 $k$ 层选取一层，聚合这些层中掩码值大于阈值 $\tau$ 的神经元激活。聚合后的特征向量输入轻量级支持向量机（SVM）分类器：

$$ \text{Prediction} = \text{SVM}(\text{Concat}(h_{l_1}, h_{l_2}, \dots, h_{l_j})) $$

其中 $h_{l_k}$ 为第 $l_k$ 层选定的神经元激活。这种多层聚合策略通过整合不同抽象层级的表示，弥补了单层特征信息的不足，显著提升了检测器对未见攻击类型的鲁棒性。

## 实验评估

实验在 MiniGPT4-7B、LLaVA-v1.5-7B、Qwen2-VL-7B 和 Janus-pro-7B 上进行，攻击类型包括 JAMLLM、FigStep 和 JailBreakV，良性数据涵盖 MM-Bench、MM-Vet 和 Normal Prompts。基线覆盖了输入预处理（CIDER）、输出分析（JailGuard, ECSO）和内部激活（HiddenDetect, GradSafe）三类方法，但未包含参数层干预类基线（如 SafeNexus），因本文定位为无训练检测。

| 方法 | LLaVA (JailBreakV) | LLaVA (FigStep) | LLaVA (JAMLLM) | Janus-pro (JailBreakV) |
| :--- | :--- | :--- | :--- | :--- |
| JDJN1 | 0.997 | 0.942 | 0.996 | 0.853 |
| JDJN2 | 1.0 | 0.524 | 1.0 | 0.838 |
| HiddenDetect | 0.532 | 0.340 | 0.776 | 0.573 |
| CIDER | 0.421 | 0.534 | 0.566 | 0.71 |

JDJN 在 LLaVA 上对已知攻击（JailBreakV, FigStep）实现了接近 100% 的真阳性率（TPR），且在 OOD 攻击（JAMLLM）上保持 99.6% 的 TPR，显著优于 HiddenDetect（77.6%）和 CIDER（56.6%）。这表明多层聚合策略有效提升了泛化能力。

消融实验显示，良性训练数据的选择对假阳性率（FPR）影响显著。使用 MM-Vet 训练时，FPR 低于 5%；而使用 MM-Bench 或 Normal Prompts 训练时，FPR 升至 16.8% 和 28.5%。这揭示了检测器可能依赖良性数据的表面特征（如输出格式）而非内在语义，导致在分布差异较大的良性数据上泛化能力下降。

评估边界方面，本文假设白盒访问内部激活，不适用于闭源模型。超参数 $\tau$ 和 $k$ 在不同模型间需手动调整（如 LLaVA 用 $\tau=0.4, k=5$，Janus-pro 用 $\tau=0.2, k=3$），缺乏自适应机制。代码未公开，但实验在单张 A800 GPU 上完成，计算开销低，具备实时部署潜力。

## 关联研究分析

从问题动机看，SafeNexus 聚焦于引导安全神经元以增强防御，而本文聚焦于识别越狱神经元以检测攻击。SafeNexus 假设安全机制由共享神经元控制，旨在通过 LoRA 校准修复模态间隙；本文则假设越狱行为由特定的 JailNeurons 驱动，旨在通过检测这些神经元的异常激活来拦截攻击。两者的根本差异在于对安全机制失效的解释：SafeNexus 认为安全神经元在视觉输入下被抑制或漂移，而本文认为存在独立的神经元子集专门响应越狱信号。这种差异暗示了安全对齐的复杂性可能不仅在于现有安全神经元的失效，还在于攻击者利用了模型中未被安全对齐覆盖的潜在通道。

从方法设计看，HiddenDetect 使用 Logit Lens 提取语义信息并计算与拒绝片段的相似度，属于全层或浅层线性探测；本文使用掩码优化定位特定神经元，属于稀疏化因果定位。HiddenDetect 的局限性在于全维激活中的噪声可能掩盖越狱信号，导致对 OOD 攻击泛化差；本文通过 $L_1$ 正则化强制掩码稀疏，隔离了关键信号。然而，本文的掩码优化依赖于拒绝响应的嵌入 $e_s$，若攻击者构造的越狱响应与标准拒绝响应在嵌入空间中距离较远，掩码定位可能失效。这种对目标响应的依赖是本文方法未探索的盲区，而 HiddenDetect 的语义相似度度量可能对此类变体更具鲁棒性。

## 总结

本文旨在解决 LVLMs 中越狱攻击检测的精准性与效率矛盾，现有方法因全层噪声干扰和高推理延迟而难以兼顾。本文通过因果消融定位 JailNeurons，并构建多层聚合 SVM 检测器，在 LLaVA 上实现了 99% 以上的 TPR 和低于 1% 的 FPR，证明了神经元级定位的有效性。然而，实验暴露了检测器对良性数据分布的敏感性，使用 MM-Bench 训练时 FPR 升至 16.8%，暗示特征提取可能依赖表面特征而非内在语义。当良性数据分布发生显著偏移时，JailNeurons 的激活模式是否仍能保持与越狱信号的线性可分性，论文未给出回答。
