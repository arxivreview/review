【RedCodeAgent: AUTOMATIC RED TEAMING AGENT AGAINST DIVERSE CODE AGENTS ｜代码代理自动化红队测试

研究机构：美国芝加哥大学、美国伊利诺伊大学厄巴纳-香槟分校

作者：Chengquan Guo、Chulin Xie、Yu Yang 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_43583852)

> 代码代理在集成解释器执行代码时，面临静态基准无法覆盖的动态边界风险。现有红队工具依赖人工设计或固定提示优化，难以适应代理的实时演化与执行反馈。本文提出 RedCodeAgent，通过自适应记忆模块与动态工具组合实现自动化漏洞挖掘。该方法在多个代理上显著提升了攻击成功率，但其对底层大语言模型推理能力的依赖及防御机制的局限性仍存疑。

【RESCUE: Retrieval Augmented Secure Code Generation ｜检索增强安全代码生成

研究机构：美国普渡大学

作者：Jiahao Shi、Tianyi Zhang

论文原文见 [arXiv](https://arxiv.org/abs/2510.18204)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.18204)

> 大语言模型（LLM）生成的代码普遍存在安全漏洞，而现有微调或静态分析工具反馈方法存在数据泄露风险或僵化局限，难以灵活注入新知识。RESCUE 提出了一种训练无关的检索增强生成（RAG）框架，通过构建分层安全知识库与多面检索机制，在提升安全性的同时保留模型功能正确性。该方法在四个基准上实现了 SecurePass@1 平均 4.8% 的绝对提升，但其性能高度依赖离线构建的高质量补丁数据，对无明确修复实例的场景适用性存疑。

【SHIELDEDCODE: LEARNING ROBUST REPRESENTA TIONS FOR VIRTUAL MACHINE PROTECTED CODE ｜虚拟机保护代码的鲁棒表示学习

研究机构：中国科学院大学、美国明尼苏达大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_87671773)

> 传统虚拟机保护（VMP）依赖僵化的规则转换，易被逆向工程破解，且设计成本高。现有大语言模型（LLM）虽能生成代码，但缺乏对虚拟化机器码多态性的语义理解，无法有效生成或评估受保护代码。本文提出 ShieldedCode，通过构建源-虚拟机（VM）配对数据，结合层级依赖建模与功能-保护对比学习，实现保护感知代码生成。该方法在 L0 级别 VM 代码生成上超越 GPT-4o，但在高保护级别下的泛化能力与真实逆向场景的对抗鲁棒性仍存疑。

】
