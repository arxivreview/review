# ICLR2026最新论文 ｜DIVID: DISENTANGLED SPATIO TEMPORAL MODELING WITHIN LLMS FOR TEMPORALLY GROUNDED VIDEO UNDERSTANDING ｜解耦时空建模的视频语言框架

研究机构：北京交通大学、中国科学院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_36037428)

> 长视频理解面临的核心矛盾是：密集采样导致视觉 Token 序列过长，超出大语言模型（LLM）上下文窗口，而稀疏采样又丢失关键时序动态。现有 Slow-Fast 架构虽在编码器端分离快慢特征，但在 LLM 解码层内时空信息仍纠缠处理，导致时间幻觉。本文切入点是将时空解耦从编码器后移至 LLM 解码器内部，通过双分支并行注意力与查询感知关键帧选择实现细粒度定位。其价值在于以 7B 参数规模超越部分 72B 模型，但缺乏强化学习优化，绝对精度仍落后于最新 SOTA。

## 研究背景

当视频时长超过分钟级，均匀采样产生的视觉 Token 序列长度呈线性增长，迅速耗尽 LLM 的上下文窗口。为缓解此问题，Slow-Fast 架构（Feichtenhofer et al., 2019）将视频特征解耦为低频时间 Token 和高频空间 Token，分别捕获长程动态与局部细节。然而，该范式仅在编码器端完成特征分离，进入 LLM 后时空 Token 仍被拼接为单一序列进行联合注意力计算，缺乏显式的时空边界约束。这种纠缠导致模型在定位短暂事件时，空间细节干扰时间推理，产生时间幻觉。

视频时间理解的主流路线已从任务特定回归转向基于 LLM 的生成式框架，但面临两大瓶颈：一是计算效率与时间精度的权衡，二是空间特征采样与语言查询的对齐缺失。现有方法如 LITA 和 VideoExpert 虽引入时空分离，但时空特征在统一注意力空间中交互，易导致语义混淆。本文针对这一架构级缺陷，提出在 LLM 解码器内部实现时空解耦，并引入查询感知机制，使空间特征的选择依赖于时间分支的注意力输出，从而在计算受限条件下提升时序定位精度。

## 核心方法

### 方法参照系

本文问题属于视频时间定位（Temporal Grounding），标准流程为：视觉编码器提取帧特征 → 投影至 LLM 嵌入空间 → LLM 生成时间戳。与通用流程的关键差异在于，本文不将时空特征简单拼接，而是在 LLM 解码器每层内部并行处理时间流与空间流，并通过动态路由融合。

### 双分支解耦解码器

传统 Slow-Fast 架构在编码器后拼接时空 Token，导致 LLM 内部时空纠缠。本文在 LLM 解码器每层引入两个并行注意力分支：时间感知分支处理低分辨率密集帧，空间感知分支处理高分辨率稀疏关键帧。时间分支通过自注意力捕获长程动态，并提取跨模态注意力图 $A_{temp}^{T2V} \in \mathbb{R}^{L \times T}$，其中 $L$ 为文本 Token 数，$T$ 为帧数。该图量化每个文本 Token 对每帧的关注度，用于指导空间分支的关键帧选择。

$$
s_{t2v} = \frac{1}{L} \sum_{i=1}^{L} A_{temp}^{T2V}[i, t]
$$

该公式计算每帧的重要性得分，通过平均所有文本 Token 对该帧的注意力权重，实现查询感知的关键帧筛选。这一设计解决了传统均匀采样忽略语言查询相关性的问题，使空间分支仅处理与查询最相关的 $k$ 帧，降低计算冗余。

### 时空软路由融合

时间分支与空间分支输出后，需动态融合以生成最终表示。本文引入时空软路由（ST-Router），基于原始文本表示 $X_{text}$ 生成门控权重 $G \in \mathbb{R}^{L \times 2}$：

$$
G = \text{softmax}(X_{text} W_g + b_g)
$$

其中 $W_g \in \mathbb{R}^{d \times 2}$ 为可学习参数。第 $i$ 个文本 Token 的融合表示为：

$$
Z_{text}[i] = G[i, 1] \cdot H_{temp}[i] + G[i, 2] \cdot H_{spat}[i]
$$

该机制允许每个文本 Token 自适应地权衡时间线索与空间细节，避免固定权重导致的语义偏差。相比 MASH-VLM 的掩码解耦，ST-Router 不依赖预定义位置编码，兼容高效注意力机制，提升了架构灵活性。

## 实验评估

实验在 Charades-STA、NExT-GQA、ReXTime 和 CG-Bench 上进行，基线覆盖 Moment-DETR、TimeChat、VideoMind 等经典方法，但缺失 TempR1、TimeLens 等 2025-2026 年基于强化学习的最新 SOTA 方法。

| 方法 | 规模 | Charades-STA mIoU | NExT-GQA mIoU | ReXTime mIoU |
| :--- | :--- | :--- | :--- | :--- |
| Divid (Ours) | 7B | 51.3 | 34.5 | 35.78 |
| VideoMind | 7B | 27.7 | 21.1 | 24.83 |
| Qwen2.5-VL | 72B | 50.9 | - | - |

Divid (7B) 在 Charades-STA 上 mIoU 51.3，超越 Qwen2.5-VL (72B) 的 50.9，表明架构效率优于单纯参数扩展。在 NExT-GQA 上 mIoU 34.5，较 VideoMind (7B) 的 21.1 提升 13.4 个点，验证了解耦架构在细粒度定位上的优势。

消融实验显示，关键帧选择策略对性能影响显著。均匀采样 mIoU 49.70，加权采样 46.27，而本文 Top-K 选择 51.37，提升 1.67 个点。ST-Router 的引入使 mIoU 从 50.98 提升至 51.37，边际收益 0.39 个点，表明动态融合对精度的贡献有限，主要价值在于计算效率。数据集方面，TempGCap 较 Momentor-1M 提升 mIoU 2.41 个点，验证了高质量时间戳监督的重要性。

评估协议采用零样本设置，未报告置信区间，数值比较需谨慎。代码未开源，超参数（如 $T=128$, $k=32$）固定，缺乏不同视频时长下的泛化性验证。计算效率方面，Divid 的 TFLOPs 为 10.5，低于 Full 模型的 28.2 和 Slow-Fast 的 16.2，但论文未提供推理时间数据，效率优势仅基于 FLOPs 估算。

## 关联研究分析

从方法设计看，Divid 与 LITA 的核心差异在于时空解耦的位置。LITA 在编码器端分离快慢特征后拼接输入 LLM，时空信息在统一注意力空间中交互，易导致语义纠缠。Divid 将解耦移至 LLM 解码器内部，通过并行分支与 ST-Router 实现 token 级动态融合，避免了统一注意力空间的干扰。这一改进源于对“时空纠缠导致时间幻觉”问题的针对性解决，但论文未量化解耦位置对幻觉率的具体影响，仅通过 mIoU 间接验证。

从问题动机看，Divid 与 TempR1 代表两条不同路线。TempR1 通过强化学习优化时序推理，在 Charades-STA 上 mIoU 59.8，显著高于 Divid 的 51.3。Divid 仅使用监督微调（SFT），缺乏过程奖励机制，导致在复杂时序推理任务上精度受限。这一差距暗示，架构解耦与优化算法（如 RL）可能存在协同效应，但论文未探索两者结合的可能性。查询感知关键帧选择在数据充足时是否仍有增益，论文未给出回答，因为实验仅基于固定数据集，未测试不同数据规模下的性能变化。

## 总结

Divid 解决的核心矛盾是长视频中时空特征纠缠导致的时间幻觉与计算冗余。其切入点是将解耦从编码器后移至 LLM 解码器内部，通过双分支并行注意力与查询感知关键帧选择，在计算受限条件下提升时序定位精度。实验证明，7B 规模的 Divid 在 Charades-STA 上 mIoU 51.3，超越 Qwen2.5-VL (72B) 的 50.9，验证了架构效率的价值。然而，论文边界在于仅使用 SFT，缺乏强化学习优化，导致绝对精度落后于 TempR1 等 RL 方法。当解耦架构与过程奖励结合时，时序推理精度能否进一步提升，论文未给出回答。
