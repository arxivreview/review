# ICLR2026最新论文 ｜LEARNING DYNAMICS FEATURE REPRESENTATION - VIA POLICY ATTENTION FOR DYNAMIC PATH PLAN NING IN URBAN ROAD NETWORKS ｜动态路径规划中的动力学特征表示

研究机构：南京大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_91529380)

> 导读 动态路径规划（Dynamic Path Planning, DPP）旨在交通流持续变化的城市路网中实时生成最优行驶轨迹，其核心难点在于强化学习（RL）状态表示的完整性与计算效率难以兼得。全局动态编码虽信息完备但维度爆炸，局部观测虽高效却易因缺失非局部信息导致决策短视，且可能破坏马尔可夫性。本文提出动力学特征表示（Dynamics Feature Representation, DFR）框架，通过策略注意力预筛选任务相关子图，再结合 n-hop 邻域解耦出紧凑的节点局部特征，以层级蒸馏方式平衡信息充分性与计算开销。该框架在真实城市路网中显著加速了 RL 策略收敛并提升了规划效率，但其对非最短路径最优解的探索能力及参数自适应机制尚存疑。

## 研究背景

当车辆在城市路网中行驶时，边权（如通行时间）随交通密度实时波动，传统基于静态成本图或显式流量预测的规划算法（如 A* 或预测+搜索范式）在事故或拥堵等突发事件下泛化能力极差。为摆脱对精确预测的依赖，RL 被引入 DPP，其价值函数通过交互隐式吸收状态转移的统计规律，从而增强对未见事件的鲁棒性。然而，RL 的有效性高度依赖状态表示的质量：若状态仅包含局部观测，智能体可能因忽略全局拥堵而选择次优路径；若状态包含全局动态，高维输入将导致计算不可行且训练不稳定。

DPP 领域的核心矛盾在于如何在保留关键动态信息的同时降低状态维度以维持马尔可夫性。现有方法陷入两难：全局方法（如 Lin et al., 2025）编码整个图动态，虽信息完整但计算复杂度随图规模指数增长；局部方法（如 Du et al., 2024b）仅使用智能体邻域观测，虽高效但易遗漏非局部动态，导致规划短视。这种“完整性-效率”权衡是 RL 在大规模动态图决策中的根本瓶颈。本文切入点在于不直接端到端学习状态压缩，而是引入基于任务语义的硬注意力机制进行特征蒸馏，先提取与源-目标对相关的稀疏子图，再局部化，从而在 RL 训练前大幅降低问题维度。

## 核心方法

### 方法参照系

本文问题属于 RL 在动态图上的状态表示优化。标准流程是将图动态直接输入 RL 智能体，但本文的关键差异在于引入“预筛选-局部化”的层级蒸馏机制，而非依赖 GNN 端到端学习图嵌入。

### 策略注意力任务筛选

在标准 DPP 中，智能体通常接收全图动态 $W_t$ 作为状态输入，导致维度冗余。本文创新在于引入预训练的策略注意力模块，基于距离导向的最短路径专家，识别 top-$k$ 最短路径并提取其节点构成的稀疏子图。该设计动机是解决全局动态中大量与当前任务无关的边权带来的计算浪费。形式化地，任务相关关键特征 $W'_t(\tau)$ 定义为：

$$ W'_t(\tau) = \Psi(\tau, W_t) $$

其中 $\Psi$ 为提取函数，满足 $\pi^*(v_t, v_g; W'_t) \approx \pi^*(v_t, v_g; W_t)$。这一硬注意力机制提供了可解释的结构先验，将高维全局动态压缩为任务相关的低维子集，为后续局部化奠定基础。

### n-hop 邻域局部解耦

策略注意力输出的 $W'_t$ 在大规模路网中仍可能维度较高。本文进一步引入 n-hop 邻域方法，计算当前节点 $v_t$ 的 n-hop 邻域，并与策略注意力子图取交集，得到节点相关局部特征 $W''_t(v_t)$。该设计动机是解决任务相关子图中仍包含远离当前智能体的冗余动态，导致状态表示不够紧凑。形式化地，局部特征定义为：

$$ W''_t(v_t) = \Phi(W'_t, v_t) $$

其中 $\Phi$ 为特征提取函数，同样满足策略近似最优性。通过这一层级解耦，DFR 提供了既计算高效又信息充分的马尔可夫状态，使 RL 智能体能在紧凑输入下有效感知局部交通条件并做出全局一致的决策。

## 实验评估

实验在南京、北京朝阳、上海浦东的 OSM 真实路网子图上进行，基线包括 DQN、PPO 和 GCN+DQN，均对比有无 DFR 两种设置。基线覆盖 RL 价值型、策略型及图卷积型路线，但缺乏与显式预测+搜索范式的直接对比，仅以动态 Dijkstra 作为 Ground Truth 计算 GAP。

| 配置 | Mean GAP | Success Rate | Compactness Rate |
| :--- | :--- | :--- | :--- |
| DQN+AD (Baseline) | 0.170 | 0.884 | - |
| DQN+DFR (n=4, k=0.4) | 0.095 | 0.908 | <5.7% |
| DQN+DFR (n=2, k=0.6) | 0.118 | 0.867 | - |
| DQN+DFR (n=4, k=0.6) | 0.113 | 0.892 | - |

消融实验显示，n-hop 邻域大小 $n$ 对性能影响显著且存在饱和效应：$n=1$ 时 Mean GAP 为 0.151，$n=2$ 降至 0.118，$n=4$ 进一步降至 0.113，但继续增大 $n$ 收益递减。相比之下，策略注意力比例 $k$ 的影响更复杂：$n=4$ 时，$k$ 从 0.4 增至 0.6，Mean GAP 从 0.095 升至 0.113，表明过大的子图可能引入噪声。DFR 使 DQN 规划时间降低 85.59%，GCN+DQN 降低 79.32%，验证了特征压缩对计算效率的提升。

评估指标包含 Mean GAP、SR、CR 和规划时间，但未报告置信区间或多次运行方差。代码已公开，超参数（如学习率 $10^{-3}$，$\gamma=0.99$）明确，但缺乏 GPU 型号及训练总时长等可复现性细节。

## 关联研究分析

从方法设计看，本文与 CoLight 等 TSC 方法均使用注意力机制建模空间依赖，但 CoLight 的 GAT 是端到端学习的软注意力，用于信号协同决策；本文的策略注意力是基于最短路径专家的硬注意力，用于状态预筛选。这一差异源于任务特性：TSC 需实时响应所有路口动态，而 DPP 的源-目标对具有明确的任务导向性，允许利用结构先验进行稀疏化。然而，策略注意力依赖预训练的最短路径专家，若最优路径显著偏离最短路径（如避开拥堵），该先验可能限制探索空间，论文未对此进行量化分析。

从问题动机看，本文与 MetaLight 均关注泛化，但 MetaLight 通过元学习适应新场景分布，本文通过 DFR 适应动态权重变化。MetaLight 解决的是“场景迁移”问题，而 DFR 解决的是“状态维度”问题。两者在应对分布偏移时路径不同：MetaLight 增强模型对新分布的适应能力，DFR 则通过压缩状态减少分布偏移对高维输入的冲击。本文未探索 DFR 与元学习的结合，也未验证在非平稳交通流下 DFR 的长期稳定性。

## 总结

本文核心矛盾是 RL-DPP 中状态表示的完整性与计算效率权衡。现有全局方法计算不可行，局部方法信息缺失，本文通过策略注意力与 n-hop 邻域的层级蒸馏，在保留关键动态的同时大幅降低维度。实验证明 DFR 使 DQN 规划时间降低 85.59%，Mean GAP 从 0.170 降至 0.095，验证了特征压缩的有效性。然而，策略注意力基于最短路径先验，当最优路径因拥堵显著偏离最短路径时，该先验的鲁棒性未经验证；且 $k$ 和 $n$ 参数需手动调优，缺乏自适应机制。当交通流分布发生剧烈偏移时，预训练策略注意力的子图选择是否仍能保持任务相关性，论文未给出回答。
