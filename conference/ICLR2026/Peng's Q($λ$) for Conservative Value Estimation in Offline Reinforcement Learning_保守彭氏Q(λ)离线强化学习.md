# ICLR2026最新论文 ｜Peng's Q($λ$) for Conservative Value Estimation in Offline Reinforcement Learning ｜保守彭氏Q(λ)离线强化学习

研究机构：韩国首尔大学

作者：Byeongchan Kim、Min-hwan Oh

论文原文见 [arXiv](https://arxiv.org/abs/2605.14779)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.14779)

> 离线强化学习面临分布偏移导致的Q值过估计与保守正则化引发的过悲观估计双重困境，现有单步方法难以兼顾。本文切入点在于利用离线轨迹中的多步信息，通过彭氏Q(λ)算子替代Bellman算子，使固定点自然靠近行为策略值函数，从而在低保守参数下实现稳定学习。该方法首次将多步算子引入离线保守价值估计，理论上保证性能不低于行为策略。其价值在于缓解了CQL对超参数的敏感性，但理论保证是否依赖Bellman完备性假设仍未明确。

## 研究背景

离线强化学习从静态数据集学习策略，核心挑战是分布偏移。当学习策略访问数据未覆盖的状态-动作对时，函数逼近产生外推误差，导致Q值过估计。保守Q学习（CQL）通过惩罚OOD动作缓解此问题，但过强的保守正则化导致对分布内动作的过悲观估计，限制了策略探索能力。

主流离线RL方法基于单步时间差分（TD）学习，如TD3、SAC和AWR。这些方法将轨迹碎片化为单步转移，忽略了轨迹中蕴含的行为策略信息。在线RL中，多步算子如彭氏Q(λ)（PQL）已被证明能提升学习效率，但其固定点收敛性依赖行为策略与目标策略的接近程度，这在离线设置中因行为策略固定而具有不同性质。本文利用PQL算子在离线设置下固定点靠近行为策略值函数的特性，将其与保守价值估计结合，旨在同时缓解分布偏移导致的过估计与保守正则化导致的过悲观。

## 核心方法

### 方法参照系

本文问题属于离线RL中的保守价值估计类别，标准流程为CQL：在Bellman算子基础上添加保守正则化项，惩罚OOD动作的Q值。关键差异在于CQL使用单步Bellman算子，而本文使用多步PQL算子，利用轨迹信息隐式正则化。

### PQL算子的离线适配

CQL的保守正则化项 $\alpha \log \sum_a e^{Q(s,a)}$ 在单步Bellman更新中易导致过悲观，因为Q值估计受学习策略影响较大。本文引入PQL算子 $T_{\lambda}^{\pi_\beta, \pi} Q := (1-\lambda)\sum_{n=1}^{\infty} \lambda^{n-1} T_{\pi_\beta, \pi}^n Q$，其中 $\pi_\beta$ 为行为策略，$\pi$ 为目标策略。该公式的物理含义是：PQL算子通过加权组合不同步长的回报，使Q值更新更依赖行为策略的轨迹分布，而非学习策略的探索。在离线设置中，行为策略 $\pi_\beta$ 固定，PQL的固定点 $Q^{\lambda\pi_\beta + (1-\lambda)\pi}$ 是行为策略与目标策略的混合策略值函数，这自然诱导了隐式行为正则化，降低了学习策略对Q值估计的影响。

### 保守PQL算法设计

基于PQL算子的固定点特性，本文设计CPQL算法，将CQL的保守正则化项与PQL算子结合。具体而言，在递归计算多步目标值时，仅在最后一步引入保守惩罚项 $\gamma^n \alpha \log \pi_\phi(\cdot|s_n)$，中间步骤不添加熵奖励项以保证数值稳定性。这一设计解决了CQL中保守参数 $\alpha$ 敏感性问题：由于PQL算子已隐式限制了OOD动作的影响，较小的 $\alpha$ 即可有效缓解过估计，避免了CQL中因 $\alpha$ 过大导致的过悲观。理论上，CPQL学习的混合策略性能保证不低于行为策略（Theorem 2），且子最优性间隙小于CQL（Theorem 3）。

## 实验评估

实验在D4RL基准上进行，涵盖MuJoCo、Adroit和AntMaze任务，对比基线包括CQL、IQL、TD3+BC、BC、MCQ、MISA、CSVE、EPQ等。CPQL在29个任务中的22个取得最高或接近最高性能，MuJoCo运动任务中一致超越所有基线，Adroit操作任务中在door-human和cloned数据集上领先，AntMaze导航任务中在稀疏奖励下表现突出。

| 任务 | CQL | IQL | CPQL (ours) |
|---|---|---|---|
| halfcheetah-medium | 47.0* | 47.4 | 66.6±0.9 |
| hopper-medium | 53.0* | 66.2 | 99.7±2.0 |
| walker2d-medium | 73.3* | 78.3 | 90.0±1.5 |
| halfcheetah-medium-expert | 75.6* | 86.7 | 95.3±0.6 |
| hopper-medium-expert | 105.6* | 91.5 | 111.3±1.2 |
| walker2d-medium-expert | 107.9* | 109.6 | 112.9±2.0 |

消融实验显示，CPQL对保守参数 $\alpha$ 的敏感性显著低于CQL。在Walker2d任务中，CQL性能随 $\alpha$ 变化剧烈，而CPQL在 $\alpha \in [0.1, 0.9]$ 范围内保持较高性能。与其他多步算子（Uncorrected N-step、Retrace、Tree-backup）相比，CPQL在训练后期性能更稳定，Retrace因依赖行为策略估计而性能下降，Tree-backup在连续动作空间中因数值尺度问题不稳定。

评估边界方面，论文未报告置信区间，数值比较需谨慎。超参数通过网格搜索确定，$\alpha \in \{0.1, 0.5, 1, 3, 5, 7, 10\}$，$\lambda \in \{0, 0.1, 0.3, 0.5, 0.7, 0.9, 0.95, 0.99\}$。代码开源，但计算成本略高于CQL（1000梯度步耗时42.4秒 vs 40.6秒），多步备份带来4.4%的运行时增加。

## 关联研究分析

从问题动机看，CPQL与CQL共享缓解分布偏移的目标，但CQL通过显式惩罚OOD动作实现，而CPQL通过PQL算子的隐式行为正则化实现。这一差异源于对轨迹信息的利用方式：CQL将轨迹碎片化为单步转移，忽略了多步依赖关系；CPQL利用完整轨迹，使Q值估计更贴近行为策略分布。根源在于单步TD学习在离线设置中无法充分利用轨迹中的行为策略信息，而多步算子通过加权组合不同步长回报，自然限制了OOD动作的影响。

从方法设计看，CPQL与在线RL中的PQL算子共享固定点性质，但在线PQL的固定点收敛性依赖行为策略与目标策略的接近程度，这在离线设置中因行为策略固定而具有不同性质。CPQL利用这一特性，将PQL算子与保守价值估计结合，解决了CQL的过悲观问题。与IQL等基于隐式Q学习的离线RL方法相比，CPQL不依赖额外的价值函数网络，而是通过算子设计实现保守估计，这降低了模型复杂度，但理论保证是否依赖Bellman完备性假设仍未明确。

## 总结

CPQL要解决的核心矛盾是离线RL中分布偏移导致的Q值过估计与保守正则化引发的过悲观估计之间的权衡。本文抓住的切入点是PQL算子在离线设置下固定点靠近行为策略值函数的特性，这一特性在CQL等单步方法中未被利用。CPQL通过PQL算子替代Bellman算子，结合保守正则化项，理论上保证性能不低于行为策略，实验中在D4RL基准上超越CQL、IQL等基线，MuJoCo运动任务中一致取得最高性能。本文的边界在于理论保证是否依赖Bellman完备性假设未明确讨论，且计算成本略高于单步方法。当轨迹长度 $n$ 增大时，CPQL的性能是否持续改善，论文未给出回答。
