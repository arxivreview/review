# ICLR2026最新论文 ｜Beyond Sequential Reranking: Reranker-Guided Search Improves Reasoning Intensive Retrieval ｜重排引导搜索

研究机构：美国麻省理工学院、美国华盛顿大学

作者：Haike Xu、Tong Chen

论文原文见 [arXiv](https://arxiv.org/abs/2509.07163)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.07163)

> 在检索-重排两阶段架构中，LLM 重排器的高计算成本限制了可处理的文档数量，导致最终精度受限于初始检索阶段。现有顺序重排策略在固定预算下无法有效利用文档间相似性，而图重排方法（如 SlideGAR）依赖嵌入相似度选择下一文档，忽略了重排器对文档相关性的真实判断。本文提出 Reranker-Guided-Search（RGS），通过基于文档近邻图的贪心搜索，优先重排重排器判定为高相关的文档邻域，在 BRIGHT、FollowIR 和 M-BEIR 基准上，于 100 文档预算内分别提升 NDCG@10 至 28.8、63.3 和 31.0。该方法将重排预算分配问题转化为图搜索问题，但仅在特定预算约束下有效，且未处理重排器本身的位置偏差。

## 研究背景

当 LLM 重排器面对大规模候选集时，其自回归解码的高延迟使得全量重排在实时系统中不可行。此时，重排预算（Reranker Budget）成为核心约束：给定固定数量的重排调用次数，如何分配这些调用以最大化检索精度？传统顺序重排（Retrieve-and-Rerank, RR）按嵌入相似度顺序处理 Top-K 文档，假设相关性随嵌入距离单调递减，但在推理密集型查询中，高相关文档可能位于嵌入空间的远端。近似最近邻搜索（Approximate Nearest Neighbor Search, ANNS）算法（如 DiskANN）通过构建文档近邻图实现高效检索，其聚类假设——相似文档具有相似相关性——为基于图结构的重排预算分配提供了理论基础。

LLM 文档重排领域的主流路线聚焦于优化重排器内部机制，如通过 Fusion-in-Decoder 架构降低延迟（MVP）或消除位置偏差（CapCal）。这些方法隐含了“全量重排”假设，即重排器能处理所有候选文档，但忽略了实际部署中预算受限的场景。当重排预算固定时，顺序重排的效率瓶颈凸显：在 BRIGHT 基准上，顺序重排 Top-100 文档仅获得 25.3 的 NDCG@10，而 Top-500 文档仅提升至 27.7，表明边际收益递减。现有图重排方法（如 GAR、SlideGAR）虽引入图结构，但依赖嵌入相似度或顺序位置选择下一文档，未利用重排器对文档相关性的实时判断。本文切入点在于：将重排分数作为图搜索的引导信号，优先探索重排器判定为高相关的文档邻域，从而在有限预算内定位远端高相关文档。

## 核心方法

### 方法参照系

标准检索-重排流程为：嵌入模型检索 Top-K 文档 → 重排器顺序处理 → 输出排序。本文问题与该流程的关键差异在于：重排预算固定且远小于候选集大小，需决定哪些文档值得重排，而非如何快速重排单个文档。

### 基于近邻图的贪心搜索

RGS 的核心创新在于将重排预算分配转化为图搜索问题。在标准流程中，重排器按嵌入相似度顺序处理文档；RGS 改为基于文档近邻图的贪心搜索，优先探索重排器判定为高相关的文档邻域。具体地，RGS 首先使用 DiskANN 构建文档近邻图 $G = (V, E)$，其中每个节点 $v$ 有至多 $R$ 个出边邻居 $N_{out}(v)$。给定查询 $q$，RGS 执行两阶段搜索：阶段一，使用 DiskANN 找到嵌入空间中距离 $q$ 最近的种子文档 $s$；阶段二，从 $s$ 开始贪心搜索，维护有序列表 $A$，每次选取 $A$ 中首个未扩展文档 $v$，将其邻居 $N_{out}(v) \setminus A$ 追加至 $A$ 末尾，并使用列表式重排器 $D$ 对新增文档进行滑动窗口重排。该过程重复直至重排预算 $k$ 耗尽，最终返回 $A$ 中首个文档。

$$
A_{t+1} = A_t \cup (N_{out}(v_t) \setminus A_t), \quad v_t = \text{first unexpanded in } A_t
$$

此公式表示：在时间步 $t$，选取 $A_t$ 中首个未扩展文档 $v_t$，将其邻居加入 $A_{t+1}$。设计动机在于：顺序重排假设相关性随嵌入距离单调递减，但推理密集型查询中，高相关文档可能位于嵌入空间远端（如 TheoremQA-T 中 D3 初始排名 2812 位）。RGS 通过重排器分数引导图扩展，跳过低相关邻域，直接定位远端高相关文档，解决了顺序重排在固定预算下无法探索远端文档的失效。

### 重排分数引导的邻域扩展

RGS 的关键改进在于使用重排器分数而非嵌入相似度决定扩展方向。在标准图重排方法（如 SlideGAR）中，下一文档由嵌入相似度或顺序位置决定，即使高相关文档出现在图前沿，若其嵌入距离查询较远，也可能被延迟处理。RGS 维护有序列表 $A$，其中文档按重排器分数降序排列，每次扩展 $A$ 中首个未扩展文档的邻域。滑动窗口重排确保新增文档与已有高相关文档进行比较，避免局部最优。

$$
\text{score}(d) = D(q, d), \quad A = \text{sort}(A, \text{by } \text{score}(d) \downarrow)
$$

此公式表示：重排器 $D$ 计算查询-文档对的相关性分数，列表 $A$ 按分数降序排列。设计动机在于：嵌入相似度仅捕捉表面词汇或语义重叠，而重排器能捕捉深层逻辑关系（如数学推导、指令遵循）。在 BRIGHT 基准上，RGS 在 Reranker@100 下获得 28.8 的 NDCG@10，较顺序重排的 25.3 提升 3.5 点，证明了重排分数引导扩展的有效性。

## 实验评估

实验在 BRIGHT（推理密集型）、FollowIR（指令遵循）和 M-BEIR（多模态）三个基准上进行，使用 BGE-Large 和 CLIP 作为嵌入模型，Gemini-2.0-Flash 作为重排器。基线包括顺序重排（RR）和 SlideGAR，但未对比 MVP、E2Rank 等高效重排器，因本文关注预算分配策略而非重排器本身。

| 基准 | 方法 | Reranker@100 NDCG@10 | Reranker@500 NDCG@10 |
| :--- | :--- | :--- | :--- |
| BRIGHT | RR | 25.3 | 27.7 |
| BRIGHT | SlideGAR | 25.4 | 26.9 |
| BRIGHT | RGS | 28.8 | 33.0 |
| FollowIR | RR | 60.4 | 61.6 |
| FollowIR | SlideGAR | 62.5 | 59.8 |
| FollowIR | RGS | 63.3 | 64.2 |
| M-BEIR | RR | 25.9 | 30.1 |
| M-BEIR | SlideGAR | 28.6 | 29.9 |
| M-BEIR | RGS | 31.0 | 38.3 |

RGS 在所有基准上均优于 RR 和 SlideGAR，尤其在 M-BEIR 上，Reranker@500 时 NDCG@10 达 38.3，较 RR 的 30.1 提升 8.2 点。消融实验显示，嵌入模型质量影响达到特定精度所需的预算，但最终精度由重排器能力决定：在 BRIGHT 子集上，使用 BGE-Micro（17M）和 SFR-Mistral（7B）时，RGS 在 Reranker@500 下收敛至相似精度，而 RR 的精度随嵌入模型质量显著变化。

评估边界方面，RGS 仅在固定预算约束下有效，未处理重排器本身的位置偏差；M-BEIR 实验仅使用 100 个随机采样查询，可能影响结果泛化性；代码已开源，但超参数（如搜索列表大小 $L_s$）需根据预算调整，未提供自动化调参策略。

## 关联研究分析

从问题动机看，RGS 与 MVP 等高效重排方法解决不同维度的效率问题。MVP 通过 Fusion-in-Decoder 架构降低单次重排延迟，隐含全量重排假设；RGS 则关注预算受限下的文档选择，假设重排器容量固定。两者差异源于任务特性：MVP 适用于实时大规模检索，需处理所有候选文档；RGS 适用于推理密集型查询，候选集大但高相关文档稀疏。RGS 未对比 MVP，因 MVP 的单步解码特性可能改变预算消耗模式，但论文未探索两者结合的可能性。

从方法设计看，RGS 与 SlideGAR 同属图重排路线，但搜索逻辑不同。SlideGAR 交替扫描嵌入短列表和图前沿，依赖嵌入相似度选择下一文档；RGS 维护有序列表，始终扩展重排器判定为最高相关的文档邻域。这一差异源于对重排器角色的理解：SlideGAR 将重排器视为评分器，RGS 将其视为搜索引导器。在 FollowIR 基准上，RGS 提升（+2.9）小于 BRIGHT（+3.5），因 FollowIR 中 87% 的高相关文档位于 Top-100 嵌入排名内，图扩展的边际收益有限。

## 总结

RGS 解决的核心矛盾是 LLM 重排器高计算成本与固定预算约束下检索精度的平衡。现有顺序重排无法探索嵌入空间远端的高相关文档，而 SlideGAR 等图重排方法依赖嵌入相似度，忽略了重排器对深层逻辑关系的判断。RGS 通过基于文档近邻图的贪心搜索，优先扩展重排器判定为高相关的文档邻域，在 BRIGHT 和 M-BEIR 上，于 100 文档预算内分别提升 NDCG@10 至 28.8 和 31.0。其边界在于：仅在固定预算约束下有效，未处理重排器位置偏差，且 M-BEIR 实验样本量有限。当重排器本身存在显著位置偏差时，RGS 的图搜索是否会被偏差误导，论文未给出回答。
