# ICLR2026最新论文 ｜AGENTIC REINFORCEMENT LEARNING WITH IM PLICIT STEP REWARDS ｜隐式步骤奖励驱动的智能体强化学习

研究机构：中国科学院大学、中国科学院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_90197331)

> 多轮交互式智能体训练面临奖励稀疏且常不可验证的困境，导致传统轨迹级优化无法有效归因中间动作。现有过程监督方法依赖昂贵的人工标注或存在状态重叠假设，难以在开放环境中稳定运行。iStar 通过联合训练隐式过程奖励模型（PRM）与策略模型，利用多轮直接偏好优化（DPO）目标生成步骤级隐式奖励，实现了无需显式标签的细粒度信用分配。该方法在 WebShop 和 SOTOPIA 等基准上显著提升了样本效率与任务成功率，但其对动态参考模型的依赖可能引入长期泛化风险。

## 研究背景

智能体在长程交互中需将最终结果奖励归因至具体动作，这一过程称为信用分配。由于环境反馈通常仅在轨迹末端给出，且中间步骤缺乏客观验证标准，策略梯度估计方差极大，导致探索脆弱。直接偏好优化（DPO）通过比较偏好对隐式学习奖励函数，避免了显式奖励建模，但其原始形式针对单轮静态任务设计，参考模型固定且优化单元为整个响应序列。

主流 RLVR 路线在智能体场景中遭遇瓶颈：显式 PRM 依赖人工标注中间步骤，成本高且易受奖励黑客攻击；基于相同状态分组的方法（如 GiGPO）假设状态重叠，但在开放语言环境中状态空间巨大且重叠率极低，导致优势估计失效；Token 级隐式奖励（如 PRIME）粒度过细，在多轮长轨迹中方差累积， destabilize 训练。iStar 的切入点在于将 DPO 扩展至多轮 MDP 框架，以动作序列为优化单元，并引入动态策略快照作为参考模型，从而在不可验证奖励的开放环境中实现稳定、低方差的步骤级信用分配。

## 核心方法

### 方法参照系

标准 RLVR 流程中，策略模型生成轨迹，验证器提供结果奖励，算法（如 GRPO）计算组内归一化优势并更新策略。本文的关键差异在于：不依赖外部验证器提供中间步骤标签，而是通过在线学习的隐式 PRM 生成步骤级奖励，并将该奖励与结果奖励结合，形成双层优势函数。

### 多轮 DPO 隐式 PRM 优化

传统 DPO 使用冻结的初始策略作为参考模型，优化单元为完整响应。iStar 将参考模型替换为上一轮策略快照 $\pi_{\theta_{old}}$，并将优化单元定义为 MDP 中的动作序列 $a_t$。隐式 PRM $\pi_\phi$ 通过最大化以下多轮 DPO 目标进行在线更新：

$$ \mathcal{L}_{DPO} = -\mathbb{E}_{\tau^+, \tau^-} \left[ \log \sigma \left( \beta \log \frac{\pi_\phi(\tau^+|x)}{\pi_{\theta_{old}}(\tau^+|x)} - \beta \log \frac{\pi_\phi(\tau^-|x)}{\pi_{\theta_{old}}(\tau^-|x)} \right) \right] $$

该公式的物理含义是：$\pi_\phi$ 学习区分正负轨迹中各动作序列的相对偏好，$\beta$ 控制奖励尺度。动态参考模型 $\pi_{\theta_{old}}$ 确保隐式奖励始终校准于当前策略分布，避免静态参考模型导致的分布偏移与过拟合。

### 双层优势函数融合

隐式 PRM 生成步骤级奖励 $r_\phi(a_t) = \beta \log \frac{\pi_\phi(a_t|o_{1:t}, x)}{\pi_{\theta_{old}}(a_t|o_{1:t}, x)}$，衡量当前动作在 $\pi_\phi$ 下相对于旧策略的偏好程度。iStar 将结果奖励计算的 episode 级优势 $A^{[E]}(\tau_i)$ 与步骤级优势 $A^{[S]}(a_t^{[i]})$ 线性组合：

$$ A(a_t^{[i]}) = A^{[E]}(\tau_i) + \alpha A^{[S]}(a_t^{[i]}) $$

其中 $\alpha$ 平衡全局任务成功与局部动作贡献。该设计解决了单一结果奖励在长轨迹中信用稀释的问题，同时通过步骤级粒度（而非 Token 级）控制了方差，使策略更新既能区分优劣轨迹，又能识别轨迹内有益与有害的具体步骤。

## 实验评估

实验在 WebShop、VisualSokoban 和 SOTOPIA 三个基准上进行，基线覆盖 PPO、GRPO、RLOO、REINFORCE++、PRIME 和 GiGPO。iStar 在 WebShop 上取得 86.5% 成功率和 93.6% 得分，显著优于 GiGPO 的 84.1% 和 PRIME 的 81.5%；在 SOTOPIA 的 Hard 子集上，Self-Chat 目标完成度达 8.06，GPT-4o-as-Partner 达 7.16，较 GRPO 基线分别提升 14% 和 48%。

| :--- | :--- | :--- | :--- | :--- | :--- |
| GRPO | 80.1±1.7 | 89.3±2.8 | 86.3±0.6 | 6.97±0.24 | 6.27±0.14 |
| GiGPO | 84.1±3.9 | 91.2±1.5 | 85.9±2.6 | - | - |
| PRIME | 81.5±1.8 | 91.3±0.6 | - | - | - |
| **iStar (RLOO)** | **86.5±2.8** | **93.6±1.0** | **91.7±1.2** | **7.11±0.19** | **6.76±0.18** |
| **iStar (GRPO)** | - | - | - | **8.06±0.11** | **7.16±0.14** |

消融实验显示，使用环境原始步骤奖励（VisualSokoban）仅带来有限提升，而将隐式步骤奖励直接合并至结果奖励（merged rewards）的效果弱于双层优势融合（iStar），后者在 WebShop 上取得 89.1% 成功率，较 merged rewards 的 81.3% 提升 7.8 个百分点。Token 级过程奖励在 WebShop 上取得 82.0%，低于步骤级的 89.1%，验证了步骤级粒度在方差控制上的优势。

评估协议存在局限：SOTOPIA 使用 GPT-4o 作为裁判，温度设为 0，但未报告裁判一致性指标；WebShop 和 VisualSokoban 的结果基于三个随机种子平均，但未提供置信区间。论文未公开代码与超参数细节，可复现性受限。

## 关联研究分析

从问题动机看，iStar 与 SC-GRPO 同属自监督信用分配路线，但 SC-GRPO 针对单轮数学推理，通过测量原始策略与自条件教师策略的 Token 级 KL 散度实现归因；iStar 则面向多轮交互，将优化单元从 Token 提升至动作序列，并引入动态参考模型。这一差异源于任务特性：单轮任务中 Token 级粒度足以捕捉关键推理步骤，而多轮任务中动作序列包含完整的 CoT 与执行动作，Token 级奖励方差过大，步骤级粒度更符合决策结构。

从方法设计看，iStar 与 PRIME 均使用隐式奖励，但 PRIME 基于静态参考模型且针对单轮任务，iStar 采用动态策略快照并扩展至多轮 DPO。动态参考模型的设计动机在于消除 off-policy bias，使隐式奖励始终校准于当前策略分布。然而，这种设计可能导致隐式 PRM 过拟合近期策略，丧失对长期行为模式的泛化能力，论文未对此进行理论分析或实验验证。

## 总结

iStar 解决了多轮智能体训练中奖励稀疏且不可验证导致的信用分配难题，其核心在于通过多轮 DPO 在线学习隐式 PRM，生成步骤级奖励并与结果奖励融合，形成双层优势函数。实验证明该方法在 WebShop 和 SOTOPIA 上显著优于基线，样本效率提升约 2 倍。然而，动态参考模型的使用可能引入长期泛化风险，且 SOTOPIA 评估依赖 LLM 裁判，缺乏客观验证标准。当训练轮次增加时，隐式 PRM 是否会因过度拟合近期策略而丧失对早期关键动作的区分能力，论文未给出回答。
