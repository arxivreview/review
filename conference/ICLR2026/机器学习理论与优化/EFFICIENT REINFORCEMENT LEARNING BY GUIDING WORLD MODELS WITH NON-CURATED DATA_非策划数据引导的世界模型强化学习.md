# ICLR2026最新论文 ｜EFFICIENT REINFORCEMENT LEARNING BY GUIDING WORLD MODELS WITH NON-CURATED DATA ｜非策划数据引导的世界模型强化学习

研究机构：芬兰阿尔托大学、英国爱丁堡大学

作者：Yi Zhao、Aidan Scannell、Wenshuai Zhao 等 10 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_14325721)

> 离线到在线强化学习（Offline-to-Online RL）旨在利用历史数据加速在线策略优化，但现有方法通常依赖带有奖励标签的高质量策划数据，难以利用海量无奖励、混合质量且跨本体的非策划数据。本文指出直接微调预训练世界模型会因离线与在线数据的分布失配而失效，提出NCRL框架，通过经验排练与执行指导机制复用非策划数据。该方法在72个视觉运动任务上实现了样本效率的显著提升，但其对检索精度的依赖及在极端分布偏移下的鲁棒性仍存疑。

## 研究背景

当智能体在复杂环境中进行强化学习时，在线交互的高昂成本与探索风险迫使研究者转向利用离线数据。然而，传统离线强化学习（Offline RL）假设数据覆盖充分且带有奖励标签，这在机器人操控等场景中往往不成立：真实世界数据常缺乏精确奖励标注，且由不同能力水平的策略或不同本体（embodiment）采集，导致数据质量参差不齐。这种数据特性使得直接应用保守价值学习（Conservative Value Learning）或策略约束方法变得困难，因为缺乏明确的奖励信号来界定“好”与“坏”的动作，且跨本体数据的状态-动作空间存在维度与语义差异。

现有离线到在线（O2O）范式虽能通过少量在线交互突破数据覆盖限制，但主流方法如MOTO和Cal-QL仍假设离线数据经过精心策划（curated），即包含任务相关的奖励标签或专家轨迹。当面对无奖励、混合质量的大规模非策划数据时，直接将其用于世界模型预训练并微调的策略往往失效。根本原因在于预训练阶段学习的动态模型与在线微调阶段采集的数据之间存在显著的分布偏移（Distributional Shift）。本文切入点在于打破“离线数据必须带奖励”的假设，探索如何利用无奖励、跨本体的非策划数据，通过特定的微调机制缓解分布失配，从而加速在线强化学习。

## 核心方法

### 方法参照系

NCRL基于递归状态空间模型（Recurrent State Space Model, RSSM）构建世界模型，遵循DreamerV3的模型基强化学习框架。与标准O2O方法直接微调策略或价值函数不同，NCRL将离线数据仅用于世界模型预训练，并在微调阶段通过检索机制复用该数据，而非直接参与策略梯度更新。

### 多本体世界模型预训练

预训练阶段旨在从非策划数据中学习通用的环境动态。设计动机在于解决跨本体数据维度不统一及缺乏任务特定奖励的问题。NCRL采用RSSM架构，移除任务相关损失，并对动作进行零填充以统一不同本体的动作维度，模型规模扩展至2.8亿参数。预训练目标函数为：

$$ \mathcal{L} = \beta_1 \mathcal{L}_{pred} + \beta_2 \mathcal{L}_{dyn} + \beta_3 \mathcal{L}_{rep} $$

其中 $\mathcal{L}_{pred}$ 最小化观测重构误差，$\mathcal{L}_{dyn}$ 鼓励序列模型预测未来潜在状态，$\mathcal{L}_{rep}$ 通过KL散度促进表征的可预测性。该设计使单一世界模型能够捕捉多种本体的共性动态结构，为后续微调提供基础。

### 经验排练与执行指导

微调阶段的核心挑战是缓解离线预训练数据与在线采集数据间的分布失配。经验排练（Experience Rehearsal）通过神经特征距离检索任务相关轨迹，将其混入在线数据以维持世界模型稳定性。检索距离定义为：

$$ d(\tau_{on}, \tau_{off}) = \| e_\theta(o_{on}) - e_\theta(o_{off}) \| $$

其中 $e_\theta$ 为预训练编码器，$o_{on}$ 和 $o_{off}$ 分别为在线与离线轨迹的初始观测。该机制防止世界模型在窄分布在线数据上发生灾难性遗忘，并扩充初始状态分布以支持更广泛的模型滚动。执行指导（Execution Guidance）则训练一个基于行为克隆的先验策略 $\pi_{bc}$，在在线数据采集中与RL策略 $\pi_\phi$ 交替使用。这一设计引导智能体探索世界模型置信度高的区域，避免在分布外区域无效探索，从而加速策略收敛。

## 实验评估

实验在DMControl和Meta-World的72个像素级连续控制任务上进行，包含运动与操控任务。基线覆盖从零训练（DrQ-v2, DreamerV3）、视觉预训练（R3M）、离线数据复用（UDS, ExPLORe, JSRL-BC）及模型基方法（iVideoGPT）。NCRL在15万样本预算下，聚合分数接近从零训练基线使用更大样本预算时的性能，且在困难任务上显著优于利用离线数据的现有方法。

| 方法 | 数据特性 | 跨本体支持 | 持续改进 | 训练稳定性 |
| :--- | :--- | :--- | :--- | :--- |
| Offline RL | 有奖励 | ✗ | ✗ | ✗ |
| Off2On RL | 有奖励 | ✗ | ✓ | ✗ |
| RLPD | 有奖励 | ✗ | ✓ | ✓ |
| MT Offline RL | 有奖励 | ✓ | ✗ | ✗ |
| NCRL (ours) | 无奖励 | ✓ | ✓ | ✓ |

该表格展示了NCRL在数据假设与功能特性上的独特定位，其核心优势在于无需奖励标签且支持跨本体数据。

消融实验表明，移除经验排练导致世界模型在困难探索任务上性能急剧下降，验证了其在缓解分布失配中的关键作用。执行指导的移除则导致早期探索效率降低，但在后期收敛速度上影响较小，说明其主要贡献在于加速初期学习。

评估边界方面，论文未报告计算效率指标（如FLOPs或训练时间），且检索机制依赖Faiss库，其精度对最终性能的影响未充分量化。代码已开源，但超参数配置复杂，复现难度较高。

## 关联研究分析

从问题动机看，NCRL与MOTO等O2O方法的核心差异在于数据假设。MOTO依赖有奖励的策划数据，通过模型基价值扩展进行微调；而NCRL处理无奖励的非策划数据，通过世界模型预训练提取动态先验。这一差异源于任务场景的不同：MOTO适用于数据标注成本可控的场景，而NCRL针对数据标注昂贵或不可得的真实世界场景。NCRL的检索机制是其区别于RLPD的关键，RLPD直接回放小规模策划数据，而NCRL通过神经特征距离从大规模非策划数据中筛选相关轨迹，解决了数据规模与相关性之间的矛盾。

从方法设计看，NCRL与DreamerV3共享RSSM骨干，但NCRL引入了经验排练与执行指导机制。DreamerV3假设在线数据分布与预训练数据分布一致，而NCRL通过检索和先验策略引导显式处理分布偏移。这一设计选择反映了NCRL对非策划数据质量低、覆盖窄特性的适应。然而，NCRL未探索扩散模型等生成式策略在捕捉多模态分布上的优势，其RSSM架构在处理复杂多模态行为时可能存在表达力瓶颈，这与领域内生成式策略建模路线形成对比。

## 总结

NCRL旨在解决非策划数据在O2O强化学习中的利用难题，通过世界模型预训练与经验排练、执行指导机制，缓解了离线与在线数据的分布失配。该方法在72个视觉运动任务上实现了样本效率的显著提升，证明了无奖励、跨本体数据的有效性。然而，其性能高度依赖检索精度，且在极端分布偏移下的鲁棒性未充分验证。当离线数据分布与在线任务分布差异极大时，检索机制是否仍能有效缓解分布失配，论文未给出明确回答。
