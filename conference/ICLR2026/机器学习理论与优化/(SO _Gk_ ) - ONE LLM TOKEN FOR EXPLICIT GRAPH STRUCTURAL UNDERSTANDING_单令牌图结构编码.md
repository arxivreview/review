# ICLR2026最新论文 ｜<SO _Gk_ >: ONE LLM TOKEN FOR EXPLICIT GRAPH STRUCTURAL UNDERSTANDING ｜单令牌图结构编码

研究机构：上海交通大学、中国科学院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_14871978)

> 大语言模型（LLM）在处理文本属性图时，因序列化输入格式导致结构信息丢失或模态错位，引发严重的结构幻觉。现有方法要么将图转化为冗长文本导致注意力分散，要么投影为连续嵌入造成与文本空间的不兼容。本文提出“图到令牌”范式，通过拓扑感知分词器将图结构压缩为单一离散令牌，并利用混合问答微调实现令牌与文本空间的统一。该方法在分子图分类任务上显著优于基线，但在大规模引文网络上的泛化能力尚未验证，其单令牌容量是否足以承载复杂拓扑仍存疑。

## 研究背景

LLM 对非欧几里得图结构的理解受限于其序列化的输入机制。当图拓扑被转化为自然语言时，节点和边的枚举消耗大量令牌，导致模型注意力分散，且对节点顺序的微小扰动敏感，产生不稳定的结构推理。为减少令牌开销，另一种主流策略是将图压缩为连续嵌入并投影至 LLM 空间，但这种跨模态投影不可避免地引入模态错位，使得结构嵌入与 LLM 固有的文本令牌空间对齐不良，削弱了结构理解能力。

该领域的核心矛盾在于如何在保留结构完整性的同时实现高效、准确的 LLM 输入。Graph-to-Text 方法虽直观但效率低下，Graph-to-Embedding 方法虽紧凑但存在语义鸿沟。本文切入点在于摒弃连续嵌入的模糊性，引入离散化的结构令牌，旨在通过显式的拓扑编码消除结构幻觉，实现结构信息与文本语义在统一令牌空间内的无缝融合。

## 核心方法

### 方法参照系

本文问题属于“图结构原生编码”路线，旨在消除外部编码器瓶颈。与 GraphGPT 等使用 MLP 投影连续嵌入的方法不同，本文的关键差异在于采用离散令牌替代连续向量，并通过自监督重建约束确保令牌的拓扑保真度，而非依赖下游任务损失进行端到端优化。

### 拓扑感知结构分词器

该模块解决连续嵌入与离散文本令牌不兼容的问题。首先，通过锚点节点和层级遍历策略为每个节点分配结构属性，消除节点置换带来的歧义。随后，利用 GNN 聚合多跳邻居信息，生成全局节点表示 $h_{global}^s$。核心创新在于引入向量量化（VQ）机制，将连续表示映射到离散词表 $C = \{c_1, ..., c_K\}$。通过最小化更新损失 $\mathcal{L}_{update} = \|sg[h_i^s] - c_k\|^2$ 和承诺损失 $\mathcal{L}_{commit} = \|h_i^s - sg[c_k]\|^2$，使词表项 $c_k$ 成为结构原型。最终，全局节点对应的词表索引被选为整图的唯一结构令牌 $<SO_{Gk}>$，该过程通过拓扑重建损失 $\mathcal{L}_{recon}$ 约束，确保令牌能忠实还原邻接矩阵。

### 混合结构问答对齐

该阶段解决新引入的结构令牌与 LLM 预训练文本空间分布不一致的问题。构建三类任务无关的问答语料：$k$-近邻令牌匹配、真假结构相似度判断、描述-令牌对匹配。通过监督微调，冻结原有文本令牌嵌入，仅更新结构令牌嵌入，并采用 LoRA 注入结构信息。这种设计使得 LLM 能够理解结构令牌与文本令牌在同一空间内的相对位置关系，从而在推理时实现结构与语义的联合推理，避免了传统软提示中结构信息被文本噪声淹没的问题。

## 实验评估

实验在 MoleculeNet 的五个分子图数据集（BBBP, Tox21, ClinTox, HIV, BACE）上进行，涵盖 17 个子任务。基线包括 GPT-4、LLaMA3-70B 等大模型零样本/少样本结果，以及 GPF、GIMLET 等传统 GNN 方法和 Soft Prompt 方法。本文方法在 LLaMA3-3B 和 LLaMA2-7B 骨干上均取得最佳性能。

| 方法 | BBBP (AUC) | Tox21 (AUC) | ClinTox (AUC) | HIV (AUC) |
| :--- | :--- | :--- | :--- | :--- |
| Soft Prompt | 27.9 ± 1.7 | 39.9 ± 1.9 | 35.0 ± 2.0 | 42.0 ± 14.7 |
| LoRA SFT | 60.2 ± 1.2 | 50.8 ± 0.8 | 63.8 ± 2.8 | 68.2 ± 17.5 |
| **Ours (LLaMA3-3B)** | **76.9 ± 3.1** | **83.4 ± 3.3** | **85.5 ± 3.7** | **75.7 ± 1.6** |
| **Ours (LLaMA2-7B)** | **66.4 ± 2.7** | **72.4 ± 3.1** | **94.3 ± 0.1** | **83.2 ± 1.9** |

消融实验表明，移除结构令牌、使用静态令牌或随机令牌均导致性能显著下降，证实了结构令牌的高选择性。例如，在 BBBP 任务中，移除结构令牌后 AUC 从 76.9 降至 61.2，随机令牌降至 57.3。结构词表大小 $K$ 对性能影响显著，$K=256$ 时平均性能最优（81.7），$K=64$ 时性能最低（60.1），表明适度的词表容量能平衡结构表达力与泛化能力。

评估指标采用 AUC-ROC，以应对类别不平衡。实验重复三次取平均值。代码已开源。局限在于数据集均为小规模分子图，未验证在大规模引文网络（如 Cora, ogbn-arxiv）上的可扩展性，且未报告计算效率指标。

## 关联研究分析

从方法设计看，本文与 GraphGPT 的核心差异在于结构信息的表示形式。GraphGPT 使用 MLP 将 GNN 输出投影为连续软令牌，依赖下游任务损失进行端到端优化，导致结构嵌入与文本空间存在固有错位。本文采用 VQ 离散化，通过自监督重建约束确保令牌的拓扑保真度，并通过混合 QA 微调显式对齐令牌空间。这种离散化设计牺牲了连续空间的平滑性，但换来了结构信息的显式性和可解释性，解决了连续嵌入在复杂拓扑下易受噪声干扰的问题。

从问题动机看，本文与 NAG 同属原生编码路线，但注入机制不同。NAG 修改 LLM 的自注意力机制以强制拓扑依赖，属于架构级修改，训练复杂度高。本文仅扩展词表并微调嵌入，属于轻量级适配，保留了 LLM 的预训练知识。然而，本文的单令牌方案在节点数超过 1000 的大图上，是否会出现结构信息瓶颈，论文未给出回答。NAG 的全局注意力机制可能在大规模图上更具优势，而本文的离散令牌方案在计算效率上更优，但结构容量受限。

## 总结

本文旨在解决 LLM 理解图结构时的结构幻觉与模态错位矛盾。通过引入拓扑感知分词器将图结构压缩为单一离散令牌，并利用混合结构问答实现令牌与文本空间的统一，本文提出了“图到令牌”的新范式。实验显示，该方法在分子图分类任务上 AUC 提升 9.9%-41.4%，显著优于 Soft Prompt 和 LoRA SFT 基线。然而，本文的边界在于仅验证了小规模分子图，未涉及大规模引文网络，且单令牌容量是否足以承载复杂拓扑的长程依赖，论文未给出回答。当图规模扩大至数万节点时，单一离散令牌能否保持足够的结构区分度，仍是该方法面临的关键挑战。
