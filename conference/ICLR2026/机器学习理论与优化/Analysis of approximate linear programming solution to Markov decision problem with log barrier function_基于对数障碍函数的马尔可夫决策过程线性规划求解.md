# ICLR2026最新论文 ｜Analysis of approximate linear programming solution to Markov decision problem with log barrier function ｜基于对数障碍函数的马尔可夫决策过程线性规划求解

研究机构：韩国科学技术院

作者：Donghwan Lee、Hyukjun Yang、Bum Geun Park

论文原文见 [arXiv](https://arxiv.org/abs/2509.19800)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.19800)

> 马尔可夫决策过程（MDP）的线性规划（LP）形式虽在离线强化学习中具备理论优势，但传统原始-对偶迭代求解器收敛缓慢且计算成本高。本文切入点在于利用对数障碍函数将不等式约束内化至目标函数，从而将LP转化为无约束优化问题。通过推导近似解与最优Q函数间的线性误差界，并证明梯度下降的指数收敛性，该方法为高效求解MDP提供了新的理论框架。其价值在于摆脱了对偶变量迭代的依赖，但在部分可观测或安全约束场景下的适用性尚未验证。

## 研究背景

当智能体在离散状态空间中执行序贯决策时，动态规划方法通过贝尔曼方程迭代求解最优策略，构成了经典强化学习的基础。然而，当问题被表述为线性规划时，其不等式约束结构导致标准求解器面临挑战：原始-对偶方法虽能处理约束，但往往收敛缓慢且计算开销大，这在需要快速求解或大规模状态空间的场景中成为瓶颈。

MDP的LP形式近年来在离线强化学习领域受到关注，因其能更好地处理数据分布偏移与约束优化。主流路线如近似线性规划（ALP）及凸Q学习，多依赖原始-对偶框架或特定的函数逼近结构。然而，这些方法在处理不等式约束时，通常引入拉格朗日乘子进行迭代，导致算法复杂度高且缺乏对近似误差的显式量化。本文的切入点在于，利用凸优化中的对数障碍函数技术，将LP的不等式约束转化为目标函数中的惩罚项，从而避免显式的对偶变量迭代，直接通过梯度下降求解。

## 核心方法

### 方法参照系

本文问题属于LP-based RL路线，其标准流程是将MDP转化为基于Q函数的LP，并通过原始-对偶迭代求解。本文与该通用流程的关键差异在于，摒弃了对偶变量更新，转而使用对数障碍函数将约束内化，将问题重构为无约束优化。

### 对数障碍重构与误差界

传统LP求解中，不等式约束 $Q(s,a) \ge R(s,a) + \gamma \sum_{s'} P(s'|s,a) Q(s',a')$ 需通过对偶变量 $\lambda$ 进行迭代平衡。本文引入对数障碍函数，将约束违反转化为目标函数 $f_\eta(Q)$ 中的惩罚项：

$$
f_\eta(Q) = \sum_{(s,a,a') \in S \times A \times A} w(s,a,a') \left[ Q(s,a) - \eta \ln\left( Q(s,a) - (FQ)(s,a,a') \right) \right]
$$

其中 $\eta > 0$ 为障碍参数，$w(s,a,a')$ 为权重。该设计的动机是消除对偶变量迭代，使问题可通过标准梯度下降求解。理论分析表明，近似解 $\tilde{Q}_\eta$ 与真实最优Q函数 $Q^*$ 的 $l_\infty$ 范数误差 $\|\tilde{Q}_\eta - Q^*\|_\infty$ 存在上下界，且均随 $\eta$ 线性衰减。这意味着通过逐步减小 $\eta$，解将线性收敛至最优解，提供了显式的精度-计算量权衡。

### 无约束优化与策略导出

基于上述重构，本文证明 $f_\eta(Q)$ 在其定义域内严格凸，且子水平集具有强凸性与Lipschitz连续梯度。这保证了确定性梯度下降在表格型设定下指数收敛至 $\tilde{Q}_\eta$。从近似解 $\tilde{Q}_\eta$ 可导出两种策略：基于贪心规则的原始 $\eta$-策略（确定性），以及基于近似对偶变量 $\tilde{\lambda}_\eta$ 的对偶 $\eta$-策略（随机性）。其中，$\tilde{\lambda}_\eta$ 由一阶最优性条件直接给出，无需独立迭代。这一机制的价值在于，它将LP求解简化为单目标优化，避免了原始-对偶方法中常见的收敛停滞问题，并通过 $\eta$ 的调节实现了近似精度的可控性。

## 实验评估

实验在Gymnasium离散控制（CartPole, Acrobot等）与MuJoCo连续控制（Ant, Humanoid等）环境中进行，基线为标准DQN与DDPG。审计显示，基线覆盖主流深度强化学习算法，但缺失凸Q学习或原始-对偶LP求解器等同类LP-based方法，无法直接对比求解效率。

| 环境 | 标准 DDPG | Log-barrier DDPG |
| :--- | :--- | :--- |
| AdroitHandDoor-v1 | -39.3 ± 1.3 | -36.0 ± 2.0 |
| AdroitHandHammer-v1 | -303.1 ± 22.0 | -154.8 ± 129.4 |
| AdroitHandPen-v1 | -519.1 ± 56.1 | -635.9 ± 125.0 |
| HandManipulateBlockDense-v1 | -308.7 ± 14.1 | -278.8 ± 5.4 |

在MuJoCo任务中，Log-barrier DDPG在Ant、Humanoid等复杂任务上显著优于标准DDPG，但在AdroitHandPen-v1上表现更差（-635.9 vs -519.1）。消融实验显示，障碍参数 $\eta$ 对性能高度敏感，不同环境需单独调优（如CartPole $\eta=7$，Acrobot $\eta=0.25$）。在Sutton最大化偏差示例中，Log-barrier Q-learning比Double Q-learning更彻底地消除了Q值高估，且仅需单一Q表。

评估边界方面，论文未提供代码开源链接，超参数 $\eta$ 与 $\nu$ 需针对每个环境手动网格搜索，缺乏自适应调度策略。实验仅验证了完全可观测、无安全约束的标准MDP，未涉及部分可观测或约束MDP场景。

## 关联研究分析

从方法设计看，本文与凸Q学习（Lu et al., 2021）同属凸优化视角，但凸Q学习仍依赖原始-对偶迭代或特定函数逼近，而本文通过障碍函数实现无约束化。这一差异源于对“约束处理”的不同哲学：前者视约束为需平衡的对偶变量，后者视约束为需规避的边界。根源在于LP求解器的选择，本文更侧重计算效率而非对偶信息的利用。

从问题动机看，本文与离线强化学习中的LP方法（如Gabbianelli et al., 2024）共享对LP形式的关注，但后者多聚焦于数据分布偏移下的策略评估，而本文聚焦于在线/离线通用的最优策略求解。本文未探索在存在安全约束的CMDP中，障碍函数如何处理硬约束与软约束的区分，这限制了其在安全关键系统中的应用。

## 总结

本文核心矛盾在于LP-based MDP求解中原始-对偶迭代的低效性。切入点在于利用对数障碍函数将不等式约束内化，从而将问题转化为无约束优化。方法上，通过推导误差随障碍参数 $\eta$ 线性衰减的界，并证明梯度下降的指数收敛性，实现了高效求解。实验证明其在MuJoCo复杂任务上优于标准DDPG，且能更彻底消除Q值高估。边界在于，$\eta$ 需手动调优，且实验局限于完全可观测、无约束场景。当状态空间扩展至部分可观测或存在严格安全约束时，障碍函数能否保持收敛性与约束满足性，论文未给出回答。
