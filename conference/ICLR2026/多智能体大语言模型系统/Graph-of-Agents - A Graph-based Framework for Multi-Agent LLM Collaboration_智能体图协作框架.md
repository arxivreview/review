# ICLR2026最新论文 ｜Graph-of-Agents: A Graph-based Framework for Multi-Agent LLM Collaboration ｜智能体图协作框架

研究机构：美国麻省理工学院、美国斯坦福大学

作者：Sukwon Yun、Jie Peng、Pingzhi Li 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.17148)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.17148)

> 多智能体大语言模型系统（MAS）旨在通过协调多个模型实例突破单一模型在长程推理与复杂任务处理上的局限，但现有方法如 Mixture-of-Agents (MoA) 存在智能体选择盲目、通信开销大及响应集成低效的瓶颈。本文切入点在于将异构 LLM 池中的协作过程形式化为动态有向图，通过基于元数据的节点采样与基于响应互评的边采样构建稀疏通信结构。具体做法是引入双向消息传递机制，让高相关智能体向低相关智能体传播信息，再反向更新，最后通过图池化生成最终答案。该框架在仅使用 3 个智能体的情况下超越了使用 6 个智能体的基线，证明了结构化稀疏通信在效率与性能上的双重优势，但其对模型卡元数据质量的依赖及阈值手动调整的局限仍需审视。

## 研究背景

当任务查询跨越生物医学、数学与代码等多个领域时，单一通用大语言模型（LLM）往往因上下文窗口限制或领域知识偏差而表现不佳。此时引入多个专业化智能体进行协作成为必然选择，但协作的有效性取决于通信拓扑结构：若采用全连接或层间聚合，不仅 Token 消耗呈 $O(LNd)$ 指数级增长，且无关智能体的噪声会污染共识。为平衡性能与成本，核心概念是“相关性加权通信”，即根据智能体对当前查询的贡献度动态调整信息流动路径，而非平等对待所有响应。

多智能体协作领域的主流路线曾长期依赖静态角色分工或全量聚合，如 MoA 将所有智能体响应拼接后输入下一层，这种“多对一”模式无法捕捉细粒度的智能体间交互，且在智能体池扩大时面临计算爆炸风险。尽管 GPTSwarm 等工作引入了动态拓扑优化，但多依赖强化学习训练，增加了部署复杂度。本文的切入点在于测试时（test-time）的无训练协作，针对异构 LLM 池，提出通过模型卡元数据筛选节点、通过响应互评构建加权有向边，从而在无需梯度更新的前提下实现自适应的稀疏图通信。

## 核心方法

### 方法参照系

本文问题归属于通信拓扑优化路线，与 GPTSwarm 等动态图方法共享“结构自适应”目标，但关键差异在于：本文完全基于提示工程（Prompt-based），不依赖强化学习或额外训练，且针对异构 LLM 池而非同构智能体，通过元数据先验与响应互评实现测试时的即时图构建。

### 节点采样与元数据驱动选择

节点采样环节通常依赖启发式规则或固定角色，本文改为利用 Hugging Face 模型卡中的领域、任务与规模元数据，由 Meta-LLM 根据查询 $Q$ 选择 Top-$k$ 相关智能体。这一设计解决了 MoA 中“全量转发”导致的无关智能体噪声问题，通过先验过滤确保进入通信图的节点均具备领域相关性。形式化地，选择子集 $V_s \subseteq V$ 满足：

$$ V_s = \text{Top-}k(Q, \text{ModelCards}) $$

该公式的物理含义是：以查询与模型卡元数据的对齐度为评分依据，仅保留得分最高的 $k$ 个智能体，从而在源头上抑制智能体爆炸并提升任务匹配度。

### 双向消息传递与图池化

在边采样与消息传递环节，常规做法是单向聚合或对称辩论，本文创新性地引入基于响应互评的加权有向边与双向消息传递。首先，每个智能体对其他智能体的响应进行归一化评分，计算相关性得分 $S_j$：

$$ S_j = \sum_{i \neq j} A_{ij} $$

其中 $A_{ij}$ 为智能体 $i$ 对智能体 $j$ 的评分。基于 $S_j$ 排序，定义源节点（高相关）与目标节点（低相关），并通过阈值 $\tau$ 剪枝低相关节点。消息传递分两步：首先源节点向目标节点传播信息，更新目标响应 $R'_j$；随后目标节点向源节点反向传播，使源节点基于更新后的邻居响应进一步调整。这一双向机制解决了单向通信中“源节点被噪声污染”或“目标节点无法反馈修正”的失效问题，确保高相关智能体保持初始优势的同时，低相关智能体获得有效修正。最终，通过 Max 或 Mean 池化聚合更新后的响应，生成统一答案。

## 实验评估

实验在 MMLU、MMLU-Pro、GPQA、MATH、HumanEval 与 MedMCQA 六个基准上进行，基线覆盖单智能体（General、Code 等）、多智能体（Debate、Refine、MoA、Self-MoA）及 DyLAN。主实验显示，GoA 在仅使用 3 个智能体时，MMLU 准确率达 79.18%，MMLU-Pro 达 54.78%，GPQA 达 40.54%，MATH 达 73.12%，HumanEval 达 84.98%，MedMCQA 达 60.04%，全面超越使用 6 个智能体的 MoA（MMLU 75.71%）与 Self-MoA（MMLU 78.14%）。

| 基准 | GoA (3 Agents) | MoA (6 Agents) | Self-MoA (6 Agents) | Refine (6 Agents) |
| :--- | :--- | :--- | :--- | :--- |
| MMLU | 79.18 | 75.71 | 78.14 | 77.40 |
| MMLU-Pro | 54.78 | 53.33 | 54.19 | 54.71 |
| GPQA | 40.54 | 32.83 | 33.84 | 38.92 |
| MATH | 73.12 | 65.80 | 68.20 | 71.60 |
| HumanEval | 84.98 | 76.22 | 79.27 | 80.49 |
| MedMCQA | 60.04 | 54.94 | 55.56 | 54.94 |

消融实验揭示了双向消息传递的关键作用：移除 Target-to-Source 导致 MMLU-Pro 下降 1.12 点，GPQA 下降 1.95 点；移除 Source-to-Target 导致 MMLU-Pro 下降 2.57 点，GPQA 下降 3.86 点，表明初始信息流比反馈修正更重要。反转消息传递方向则造成最大性能损失（MMLU-Pro -2.60，GPQA -5.05），验证了“高相关向低相关传播”方向的必要性。阈值 $\tau=0.05$ 在稀疏性与连通性间取得平衡，$\tau=0.1$ 或 $0.2$ 均导致性能下降。

评估边界方面，实验主要使用 7-8B 开源模型，虽在 gpt-4o 上验证了泛化性（GPQA 55.05%），但未报告置信区间，且未与 G-Designer、SELFORG 等 2025-2026 年最新生成式拓扑方法对比。代码已开源，但阈值 $\tau$ 与 Top-$k$ 需手动调整，缺乏自适应机制。

## 关联研究分析

从方法设计看，GoA 与 DyLAN 均实现动态智能体激活，但 DyLAN 依赖预定义角色与 Agent Importance Score 的前向-反向传播，而 GoA 通过模型卡元数据与响应互评构建更通用的异构智能体选择机制，避免了角色冗余。与 GPTSwarm 相比，GoA 摒弃了强化学习训练拓扑的复杂流程，证明无训练的启发式图构建在测试时推理中同样有效且更高效，这暗示了训练范式在快速部署场景下的局限性。

从问题动机看，GoA 聚焦于“异构 LLM 池中的智能体选择与结构化通信”，而知识库中多数工作针对同构智能体或固定角色分工。GoA 的“少而精”策略（3 智能体优于 6 智能体）挑战了“规模扩展必然提升性能”的共识，表明在通信开销约束下，结构化稀疏通信比全量聚合更具性价比。然而，GoA 对模型卡元数据质量的依赖可能成为盲区：若模型卡信息缺失或误导，节点采样将失效，这一风险在论文中未充分讨论。

## 总结

本文核心矛盾在于多智能体协作中通信效率与性能的权衡，现有 MoA 方法因全量聚合导致 Token 开销大且噪声干扰严重。GoA 抓住“相关性加权通信”切入点，通过模型卡元数据筛选节点、响应互评构建加权有向边，并引入双向消息传递机制，在无需训练的前提下实现自适应稀疏图通信。实验证明，仅用 3 个智能体即可在 MMLU 上达到 79.18%，超越 6 智能体基线，验证了结构化通信的效率优势。然而，GoA 的边界在于对模型卡元数据质量的强依赖及阈值 $\tau$ 的手动调整，缺乏自适应机制。当模型卡信息不完整或查询领域高度交叉时，节点采样的准确性是否仍能支撑性能优势，论文未给出回答。
