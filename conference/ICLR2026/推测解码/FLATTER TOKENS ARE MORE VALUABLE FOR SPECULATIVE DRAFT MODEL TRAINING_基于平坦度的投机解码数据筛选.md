# ICLR2026最新论文 ｜FLATTER TOKENS ARE MORE VALUABLE FOR SPECULATIVE DRAFT MODEL TRAINING ｜基于平坦度的投机解码数据筛选

研究机构：东南大学、南京大学

作者：Jiaming Fan、CAO DAMING、Xiangzhong Luo 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_89835391)

> 投机解码中草稿模型训练通常依赖全量数据，但不同 token 对接受率的贡献存在显著异质性，导致训练资源被低价值样本稀释。现有方法聚焦于损失函数优化或模型结构改进，忽视了数据分布特性对训练效率的影响。本文提出“平坦度”指标，通过离线计算目标模型分布与均匀分布的余弦相似度，筛选高价值样本进行子集训练。该方法在保持推理加速比损失小于 4% 的前提下，实现了 2 倍以上的训练加速，但其效果依赖于目标模型分布的静态特性，未探索动态筛选机制。

## 研究背景

自回归解码的串行特性导致 LLM 推理延迟高企，投机解码（Speculative Decoding, SD）通过“草稿-验证”范式将串行生成转化为并行验证，在不改变输出分布的前提下提升吞吐量。SD 的核心性能指标是接受率，其理论上限由目标模型分布 $p$ 与草稿模型分布 $q$ 的 $L_1$ 范数决定。然而，当前训练式 SD 方法普遍采用全量数据进行知识蒸馏（Knowledge Distillation, KD），默认所有 token 对对齐目标具有同等价值，这一假设忽略了数据内部的异质性。

主流训练式 SD 路线如 EAGLE 系列通过特征对齐提升接受率，但其训练过程未区分 token 的边际贡献。DistillSpec 等研究指出 KL 散度与 $L_1$ 范数在优化目标上的偏差，但仅从损失函数角度切入，未能解决“哪些数据提供有效训练信号”的问题。本文切入点在于：接受率提升的本质是 $L_1$ 距离的缩减，而不同 token 在单步更新中对 $L_1$ 距离的缩减潜力不同。通过识别并保留高潜力 token，可以在不牺牲最终模型性能的前提下，大幅削减无效训练计算。

## 核心方法

### 方法参照系

本文基于 EAGLE-2 框架，该框架利用目标模型倒数第二层隐藏状态作为草稿头输入，通过回归损失对齐特征空间。标准流程使用全量数据集训练草稿头，本文的关键差异在于引入数据筛选步骤：在训练前离线计算每个样本的“平坦度”，仅保留高平坦度样本进行训练，从而将全量训练转化为子集训练。

### 平坦度指标与理论推导

传统 KD 最小化 KL 散度，但 SD 接受率与 $L_1$ 范数线性相关。本文定义 token $t$ 的平坦度为：

$$
\text{flatness}(p_t) = \frac{p_t \cdot U}{\|p_t\|_2 \|U\|_2}
$$

其中 $p_t$ 为目标模型在 token $t$ 处的分布，$U$ 为词表上的均匀分布。该公式计算目标分布与均匀分布的余弦相似度，值越高表示分布越平坦（不确定性越高）。理论分析表明，在预算受限的单步更新中，平坦度高的 token 能带来更大的 $L_1$ 距离缩减 $\Delta L_1$，而尖锐分布的 token 贡献迅速饱和。这一指标仅依赖目标模型，无需预热草稿模型，可离线计算。

### 样本级数据集蒸馏（SFDD）

将 token 级平坦度聚合至样本级，形成 SFDD 流程：(i) 对目标模型执行单次离线前向传播，计算每个样本的平均平坦度；(ii) 按平坦度排序，保留前 $k\%$ 的高价值样本；(iii) 在筛选后的子集上训练草稿模型。该设计解决了全量训练中低价值 token 稀释梯度信号的问题，使训练资源集中于对接受率提升贡献最大的数据区域。

## 实验评估

实验基于 EAGLE-2 框架，目标模型为 LLaMA3-8B-Instruct，训练数据为 ShareGPT，评估任务涵盖 GSM8K、Alpaca、MT-Bench、CNN/DM 和 NQ。基线包括无筛选（No Filter）、随机筛选（Random）及五种常见重要性指标（Entropy、Top-1 Probability、Margin、Energy Score、PPL）。

| 方法 | GSM8K Speedup | Alpaca Speedup | MTB Speedup | CNN/DM Speedup | NQ Speedup | Average Speedup |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| No Filter | 2.71× | 2.71× | 2.53× | 2.30× | 2.19× | 2.49× |
| Random | 2.43× | 2.37× | 2.26× | 1.99× | 1.93× | 2.20× |
| Entropy | 2.43× | 2.43× | 2.20× | 1.95× | 1.98× | 2.20× |
| Top-1 Probability | 2.49× | 2.44× | 2.26× | 1.99× | 1.98× | 2.23× |
| **SFDD (Ours)** | **2.69×** | **2.66×** | **2.44×** | **2.14×** | **2.14×** | **2.41×** |

在 50% 数据保留率下，SFDD 平均加速比 2.41×，仅比全量训练（2.49×）低 3.2%，显著优于随机筛选（2.20×）和次优指标 Top-1 Probability（2.23×）。

| 保留率 | 方法 | Average Speedup | 训练时间 (s) |
| :--- | :--- | :--- | :--- |
| 100% | No Filter | 2.49× | 58227 |
| 50% | Random | 2.20× | 31044 |
| 50% | **SFDD (Ours)** | **2.41×** | **28787** |
| 30% | Random | 2.14× | 23921 |
| 30% | **SFDD (Ours)** | **2.33×** | **18222** |

消融实验显示，SFDD 在所有保留率下均优于随机筛选。在 70% 保留率时，SFDD 加速比（2.44×）接近全量训练（2.49×），且在 Alpaca 任务上甚至超过全量训练（2.77× vs 2.71×），表明筛选可能移除了噪声数据。训练时间方面，50% 保留率下 SFDD 耗时 28787s，较全量训练加速 2.02×。

评估边界方面，实验仅使用单一目标模型（LLaMA3-8B-Instruct）和单一数据集（ShareGPT），未验证跨模型或跨域泛化性。代码已开源，但超参数（如平坦度阈值）未提供敏感性分析。

## 关联研究分析

从问题动机看，DistillSpec 聚焦于损失函数选择（KL vs $L_1$），而本文指出损失函数替换不足以解决数据异质性问题，转向数据筛选视角。这一差异源于对“训练瓶颈”的不同定位：前者认为优化目标不匹配，后者认为数据信号分布不均。从方法设计看，EAGLE 系列通过特征对齐提升接受率上限，本文则通过数据筛选提升训练效率，两者正交且可组合。REST 等无训练方法避免了训练成本，但接受率受限；本文通过降低训练成本，使训练式方法在部署灵活性上更接近无训练方法，但未改变推理加速的理论上限。

## 总结

本文解决的核心矛盾是训练式 SD 中全量数据训练的低效性，切入点在于识别目标模型分布平坦度与 $L_1$ 距离缩减潜力的关联。通过提出平坦度指标和 SFDD 流程，在 50% 数据保留率下实现 2.02× 训练加速，同时保持推理加速比损失小于 4%。其边界在于平坦度指标基于静态目标分布计算，未考虑训练过程中草稿模型分布的动态变化，也未验证在长上下文或多模态场景下的有效性。当目标模型分布随上下文长度增加而变得更为尖锐时，平坦度筛选的边际收益是否递减，论文未给出回答。
