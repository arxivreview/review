# ICLR2026最新论文 ｜MITIGATING HALLUCINATION IN VISION-LANGUAGE - - MODEL WITH DEPTH AND SPATIAL AWARE KEY VALUE REFINEMENT ｜深度与空间感知键值缓存精炼

研究机构：韩国首尔大学、韩国成均馆大学

作者：Gusang Lee、Soohyun Kim、Donghoon Kim 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_21428876)

> 导读 大视觉语言模型（LVLMs）在生成图像描述时，常因语言先验压制视觉信号而产生对象幻觉，这一可靠性危机在2023年随开源模型爆发而凸显。现有推理时干预策略如视觉对比解码（VCD）虽无需重训，但依赖额外前向传播且缺乏对图像几何结构的感知，导致在复杂场景下抑制效果有限。本文通过主成分分析（PCA）发现幻觉源于键向量（Key Vector）的空间相干性丧失，进而提出深度与空间感知缓存精炼（DSCR），在推理时直接重构Transformer的键值（KV）缓存以恢复视觉接地。该方法在多个基准上实现了最高41.6%的准确率提升，但其对单目深度估计模型的依赖引入了额外的推理开销，且未验证在深度估计严重失真场景下的鲁棒性边界。

## 研究背景

当LVLMs处理视觉查询时，视觉编码器提取的图像块（Patch）特征需通过交叉注意力机制与语言模型交互。若相邻图像块的键向量在表征空间中缺乏空间相干性，交叉注意力将无法锚定到具体的视觉区域，导致模型退化为依赖文本共现统计规律进行“猜测”，即产生幻觉。这种相干性的丧失在深层Transformer中尤为显著，因为视觉信息随层数加深而衰减，使得模型在生成后期更容易偏离视觉证据。

该领域的主流路线已从训练时对齐转向推理时动态平衡。VCD通过对比原始与扰动输入的logits分布来抑制幻觉，OPERA则引入注意力权重惩罚项，但两者均作用于解码层或注意力权重，未能触及视觉表征内部的几何结构缺陷。现有方法普遍假设视觉特征在编码器输出后已具备足够的局部一致性，忽略了单目深度与2D空间距离对物体边界定义的物理约束。本文的切入点在于揭示键向量相干性与幻觉之间的因果联系，并证明通过注入深度与空间先验重构KV缓存，可以在不修改模型权重的前提下，从表征源头恢复视觉接地的几何基础。

## 核心方法

### 方法参照系

本文问题属于推理时表征空间编辑路线，但区别于传统的激活层或权重层编辑，DSCR直接作用于Transformer的KV缓存。标准流程中，视觉编码器输出的键值对直接进入语言模型，本文的关键差异在于在解码前引入外部几何先验，对键向量进行加权重构，以强制恢复相邻图像块的空间相干性。

### 深度与空间邻近度加权

DSCR的核心创新在于构建基于深度差与2D欧氏距离的加权邻接矩阵，用于重构键向量。设计动机在于解决VCD等对比解码方法缺乏几何感知的问题，后者无法区分同一物体表面的相邻块与不同物体表面的相邻块。DSCR利用高斯核函数计算深度邻近度 $w_{ij}^{d} = \exp(-\frac{(d_i - d_j)^2}{2\sigma_d^2})$ 和空间邻近度 $w_{ij}^{s} = \exp(-\frac{\|s_i - s_j\|^2}{2\sigma_s^2})$，其中 $d_i, d_j$ 为归一化深度值，$s_i, s_j$ 为2D像素坐标。总邻近度 $w_{ij} = \alpha w_{ij}^{d} + \beta w_{ij}^{s}$ 结合了几何深度与平面局部性，$\alpha, \beta$ 为控制贡献度的超参数。这一设计使得同一物体表面的键向量在重构后形成低频率子空间聚类，而不同表面或远距离的块被推远，从而在表征层面锐化物体边界。

### 键值缓存重构与注意力引导

基于上述加权矩阵，DSCR对原始键缓存 $\mathbf{K}_I$ 进行重构，计算公式为 $\mathbf{k}_i' = \sum_{j \neq i} \frac{w_{ij}}{\sum_{k \neq i} w_{ik}} \mathbf{k}_j$。该公式的物理含义是，每个键向量被其邻居的加权平均所替代，权重由深度与空间邻近度决定。这一重构过程相当于在键向量图上施加了图拉普拉斯平滑，抑制了高频噪声并放大了可靠的局部证据。重构后的键缓存 $\mathbf{K}_I'$ 被注入语言模型，引导交叉注意力机制聚焦于几何一致的视觉区域。与VCD的全局对比不同，DSCR是实例自适应的，其重构强度随输入图像的几何结构动态变化，避免了全局校正向量在特定样本上过度或不足校正的问题。

## 实验评估

实验在MME、POPE、RePOPE、CHAIR和AMBER五个基准上进行，基线覆盖VCD、OPERA、HALC等主流推理时干预方法，但未包含DPO类训练方法，符合本文training-free的定位。在POPE Random (MSCOCO)设置下，DSCR应用于LLaVA-1.5时准确率为0.89，与知识库SOTA CHASD的88.53%持平；在CHAIR (LLaVA-1.5)上，DSCR的CHAIRs为39.2，与SOTA CAAC持平。

| 方法 | MME Total (LLaVA-1.5) | CHAIRs (LLaVA-1.5) | POPE Acc (LLaVA-1.5, Random) |
| :--- | :--- | :--- | :--- |
| Baseline | 892.68 | 48.2 | 0.88 |
| VCD | 892.68 | 54.4 | 0.89 |
| OPERA | 914.69 | 39.2 | 0.88 |
| DSCR | 925.96 | 39.2 | 0.89 |

消融实验显示，深度估计模型的大小对性能影响显著，从Small (0.03B)到Large (0.3B)，MME Total从633.33提升至650.00，表明深度信息的精度是DSCR有效性的关键。超参数敏感性分析表明，$\sigma_d, \sigma_s$在0.6时性能最优，变化范围在±7%以内，显示方法对超参数不敏感。

评估边界方面，DSCR依赖单目深度估计模型（如Depth-Anything-v2），增加了约1.7秒的推理延迟和2.8GB的GPU内存开销，这与“零额外模型”的极简主义部署共识存在冲突。可复现性方面，论文固定了超参数 $\sigma_d=0.6, \sigma_s=0.6, \alpha=0.6, \beta=0.8$，但未提供代码URL，且未报告置信区间，数值比较需谨慎。

## 关联研究分析

从方法设计看，DSCR与VCD的根本差异在于干预层级与信号来源。VCD在Logits层通过外部对比信号抑制幻觉，而DSCR在KV缓存层通过内部几何先验重构表征。VCD的局限性在于其对比信号是全局的，无法区分不同物体表面的几何差异，导致在复杂场景下抑制效果有限。DSCR引入深度与空间邻近度，使得重构过程具有实例自适应性和几何感知能力，这解释了其在CHAIR等细粒度指标上与SOTA持平的原因。然而，DSCR对深度估计精度的依赖是其与VCD相比的主要劣势，VCD无需外部模型，部署更轻量。

从问题动机看，DSCR与OPERA同属注意力调控路线，但OPERA通过惩罚注意力权重来抑制幻觉，而DSCR通过重构键向量来增强视觉接地。OPERA的惩罚机制是盲目的，可能抑制了正确的视觉注意力，而DSCR的重构机制是建设性的，通过恢复键向量的空间相干性来引导注意力。这种从“抑制”到“增强”的范式转变，使得DSCR在保持通用能力方面表现更稳定，如MME Total的提升。但DSCR未探索在深度估计严重失真（如透明物体、镜面反射）场景下的表现，这是其与OPERA相比的一个潜在盲区。

## 总结

本文要解决的核心矛盾是推理时干预方法缺乏对图像几何结构的感知，导致在复杂场景下视觉接地失效。DSCR抓住的切入点是键向量空间相干性与幻觉的因果关系，通过注入深度与空间先验重构KV缓存，从表征源头恢复视觉接地。该方法在MME和CHAIR基准上实现了与SOTA持平的性能，证明了几何先验在幻觉缓解中的有效性。本文的边界在于对单目深度估计模型的依赖，增加了推理开销，且未验证在深度估计失真场景下的鲁棒性。当输入图像包含大量透明或反光物体时，深度估计误差是否会抵消DSCR的几何重构收益，论文未给出回答。
