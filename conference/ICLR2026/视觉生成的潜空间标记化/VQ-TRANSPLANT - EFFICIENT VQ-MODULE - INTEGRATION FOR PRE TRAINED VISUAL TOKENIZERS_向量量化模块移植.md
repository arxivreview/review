# ICLR2026最新论文 ｜VQ-TRANSPLANT: EFFICIENT VQ-MODULE - INTEGRATION FOR PRE TRAINED VISUAL TOKENIZERS ｜向量量化模块移植

研究机构：加拿大多伦多大学、美国波士顿学院

作者：Xianghong Fang、Yuan Yuan、Dehan Kong 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_29195437)

> 离散视觉分词器中，向量量化（VQ）算法的迭代长期受制于端到端重训的高昂算力成本，导致新型量化机制难以在资源受限环境下快速验证。现有方案将VQ模块与编码器-解码器视为不可分割的整体，任何量化策略的变更都需从头训练整个架构，这在计算上几乎不可行。本文提出VQ-Transplant框架，通过冻结预训练分词器的编码器与解码器，仅替换VQ模块并辅以轻量级解码器适配，实现了量化算法的低成本集成。该框架显著降低了VQ研究的算力门槛，但其仅评估重建保真度而未验证下游生成性能，解耦训练对潜空间几何结构的影响仍存疑。

## 研究背景

离散视觉分词器将图像映射为紧凑的离散令牌序列，其核心组件VQ模块负责将连续潜特征量化为码本索引。VQ模块的性能直接决定了分词器的重建保真度与码本利用率，而码本坍塌（即大量码本向量未被激活）是传统VQ训练中的普遍难题。为缓解这一问题，近期研究引入了分布对齐策略，如Wasserstein VQ通过匹配特征与码本分布来优化量化过程，但其依赖高斯分布假设，在非高斯数据下退化为仅对齐一阶和二阶统计量，导致分布匹配失效。

离散分词器的训练通常依赖对抗损失以提升重建质量，但这要求大规模数据集（如ImageNet）和长时间训练，且对抗训练本身具有不稳定性。这种计算负担严重阻碍了新型VQ算法的探索，特别是在资源受限的研究环境中。现有方法将VQ模块与编码器-解码器框架视为单体系统，要求联合优化所有组件，这不仅增加了计算成本，还使得将新量化技术集成到预训练模型中变得困难。例如，直接替换冻结分词器的VQ模块会导致解码器与量化空间之间的分布失配，因为解码器的条件依赖于原始量化空间。

本文的切入点在于解耦VQ模块开发与分词器训练。通过保留预训练分词器的编码器-解码器参数，仅替换VQ模块并进行轻量级解码器适配，VQ-Transplant框架消除了对昂贵全模型重训的需求。这一策略允许研究者以极低的计算成本快速迭代和验证新型VQ算法，从而降低了量化研究的创新门槛。

## 核心方法

### 方法参照系

标准离散分词器训练流程涉及编码器、VQ模块和解码器的联合优化，其中VQ模块通过最近邻搜索将连续特征映射到码本向量。本文问题与该通用流程的关键差异在于：不从头训练整个架构，而是在预训练分词器上替换VQ模块，并解决由此引发的解码器-量化空间失配问题。

### 两阶段VQ-Transplant框架

VQ-Transplant框架的核心在于两阶段解耦训练。第一阶段为VQ模块替换，冻结预训练分词器的编码器 $E_{\theta^*}$ 和解码器 $D_{\phi^*}$，仅优化新VQ模块 $Q_{\phi}^{new}$ 的参数。训练目标为最小化量化误差并满足VQ模块特有的约束：

$$
\min_{\phi} \mathbb{E}_{x} \left[ \| z_e - Q_{\phi}^{new}(z_e) \|_2^2 + \gamma L_{unique} \right]
$$

其中 $z_e = E_{\theta^*}(x)$ 为编码器输出，$L_{unique}$ 为唯一性强制损失（如Wasserstein损失），$\gamma$ 为平衡系数。这一设计解决了传统联合优化中VQ模块与编码器-解码器相互干扰的问题，允许独立优化量化策略。

第二阶段为解码器适配，冻结编码器和已优化的VQ模块，仅更新解码器参数 $\phi$ 以对齐新量化空间。解码器通过复合损失进行优化：

$$
\min_{\phi} \mathbb{E}_{x} \left[ \| x - D_{\phi}(Q_{\phi^*}^{new}(E_{\theta^*}(x))) \|_2^2 + \lambda_P L_{Per} + \lambda_G L_{GAN} \right]
$$

其中 $L_{Per}$ 为感知损失，$L_{GAN}$ 为对抗损失。这一轻量级适配策略仅需5个epoch即可消除解码器先验与新量化空间的失配，解决了直接替换VQ模块导致的重建质量下降问题。

### MMD-VQ：分布对齐向量量化

MMD-VQ是专为VQ-Transplant框架设计的新型VQ方法，利用最大均值差异（MMD）对齐特征与码本分布。MMD通过特征核函数实现无参数分布匹配，避免了Wasserstein VQ的高斯假设限制。MMD距离定义为：

$$
D_{MMD}^2(X, Y) = \mathbb{E}[k(x, x')] + \mathbb{E}[k(y, y')] - 2\mathbb{E}[k(x, y)]
$$

其中 $k(\cdot, \cdot)$ 为特征核函数，$X$ 和 $Y$ 分别为特征向量和码本向量集合。MMD-VQ通过最小化 $D_{MMD}^2$ 作为 $L_{unique}$，确保码本分布与特征分布紧密匹配，从而在替换VQ模块时最小化信息损失，提升与冻结解码器的兼容性。

## 实验评估

实验在ImageNet-1k数据集上进行，基线覆盖VQGAN系列、VAR、Llama GEN等主流离散分词器，但缺失2025-2026年最新SOTA方法（如PAE、AffineTok）。主实验表明，VQ-Transplant框架结合MMD-VQ在重建保真度上超越原始VAR分词器：

| 方法 | VQ类型 | Tokens | Codebook Size | r-FID | r-IS |
| :--- | :--- | :--- | :--- | :--- | :--- |
| VAR (Tian et al., 2024) | MS VQ | 680 | 4096 | 0.92 | 198.6 |
| MMD VAR (Ours) | MS VQ | 680 | 8192 | 0.81 | 201.0 |
| MMD VQ (Ours) | FS VQ | 512 | 65536 | 0.86 | 197.1 |

MMD VAR在8192码本大小下达到0.81 rFID，优于VAR的0.92 rFID，且训练速度提升21.8倍。消融实验显示，解码器适配对性能提升至关重要：仅替换VQ模块（无适配）时，MMD VAR的rFID为1.49，经5 epoch适配后降至0.81。进一步扩展适配至20 epoch，rFID进一步降至0.74，表明持续对抗训练可将量化误差转化为重建性能提升。

评估边界方面，论文仅报告重建指标（rFID, r-IS, PSNR, SSIM, LPIPS），未评估下游生成质量（gFID），无法验证解耦训练对潜空间扩散友好性的影响。可复现性方面，论文提供代码链接，但超参数细节（如 $\gamma$, $\lambda_P$, $\lambda_G$ 的具体值）未在正文中明确列出，需查阅附录。

## 关联研究分析

从问题动机看，VQ-Transplant与Wasserstein VQ（Fang et al., 2025）同属分布对齐VQ路线，但本文聚焦于计算效率而非理论完备性。Wasserstein VQ通过最优传输理论优化码本学习，但依赖高斯假设；MMD-VQ通过核方法实现无参数分布匹配，提升了非高斯数据下的鲁棒性。这一差异源于任务特性：VQ-Transplant旨在降低集成成本，而非追求理论最优性，因此选择了计算更轻量、假设更宽松的MMD。

从方法设计看，VQ-Transplant与端到端联合训练范式（如VAR、VQGAN）形成鲜明对比。联合训练通过梯度流优化所有组件，确保潜空间与生成模型的最佳匹配；而VQ-Transplant通过冻结编码器-解码器，牺牲了部分联合优化潜力以换取计算效率。这种取舍是否损害潜空间几何结构，论文未给出回答。特别是，解耦训练可能导致潜空间分布与预训练编码器特征分布出现细微偏移，这种偏移对下游扩散模型收敛的影响尚不明确。

## 总结

VQ-Transplant框架解决了离散分词器中VQ算法迭代的高算力成本问题，通过冻结预训练编码器-解码器并引入轻量级解码器适配，实现了新型VQ模块的低成本集成。该框架结合MMD-VQ在ImageNet-1k上达到0.81 rFID，超越原始VAR的0.92 rFID，且训练速度提升21.8倍。然而，论文仅评估重建保真度，未验证解耦训练对下游生成性能的影响，且0.81 rFID与当前SOTA（如SPAE的0.13 rFID）存在显著差距。当解码器适配epoch数增加时，重建性能持续提升，但这种提升是否以牺牲潜空间扩散友好性为代价，论文未给出回答。
