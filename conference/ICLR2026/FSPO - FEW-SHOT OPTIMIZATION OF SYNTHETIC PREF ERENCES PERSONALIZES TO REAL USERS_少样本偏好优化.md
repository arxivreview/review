# ICLR2026最新论文 ｜FSPO: FEW-SHOT OPTIMIZATION OF SYNTHETIC PREF ERENCES PERSONALIZES TO REAL USERS ｜少样本偏好优化

研究机构：美国斯坦福大学、谷歌DeepMind

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_42846388)

> 大语言模型（LLM）的通用对齐机制将群体偏好聚合为单一奖励函数，导致个体差异被抹平，无法生成适配特定用户风格的响应。现有检索增强生成（RAG）或参数高效微调（PEFT）方法要么依赖静态上下文注入，要么需要大量用户数据训练独立适配器，难以在冷启动场景下快速适应。FSPO 将个性化重构为黑盒元学习问题，通过少样本偏好推断用户奖励函数，并引入用户描述合理化（RAT）机制提升推理时精度。该框架在合成数据上实现了 87% 的胜率，但在真实用户研究中的泛化边界与事实性约束仍存疑。

## 研究背景

当 LLM 面对具有不同文化背景与价值观的用户时，基于群体平均的强化学习从人类反馈（RLHF）会系统性忽略少数派观点。这种聚合偏差源于传统偏好数据集未区分用户身份，导致模型学习到的是“最大公约数”而非个体特征。要解决此问题，需将奖励建模从单一函数扩展为分布，即针对每个用户 $u$ 学习独立的奖励函数 $r_u$。然而，真实用户偏好数据收集成本高昂，且新用户往往缺乏足够的历史交互记录，这构成了冷启动场景下的核心挑战：如何在仅有少量（few-shot）偏好标签的情况下，快速推断出该用户的奖励函数并生成个性化响应。

当前主流路线分为参数化与非参数化两类。参数化方法如 LoRA 需为每个用户维护独立适配器，存储成本随用户数线性增长，且面临灾难性遗忘；非参数化方法如 RAG 虽具备黑盒兼容性，但受限于上下文窗口与检索噪声，在长程一致性上表现不足。FSPO 的切入点在于利用 LLM 强大的上下文学习能力，将用户视为元学习中的“任务实例”，通过训练模型从少样本偏好中快速适应新用户的奖励函数，从而在计算效率与个性化深度之间取得平衡。

## 核心方法

### 方法参照系

FSPO 基于直接偏好优化（DPO）的隐式奖励参数化框架，但关键差异在于引入了元学习结构。标准 DPO 优化单一策略以匹配群体偏好，而 FSPO 要求策略 $\pi_\theta$ 能够根据输入的少样本偏好序列 $D_{i}^{fewshot}$ 动态调整其奖励估计，实现对特定用户 $S_i$ 的快速适应。

### 元学习偏好优化

传统偏好优化假设所有用户共享同一奖励函数，导致个体偏好被边缘化。FSPO 将每个用户 $S_i$ 视为一个任务，其目标是最小化在用户分布 $\mathcal{S}$ 上的期望损失。具体而言，模型接收用户 $S_i$ 的少样本偏好 $D_{i}^{fewshot}$ 作为上下文，并对保留的未标注偏好 $(x, y_1, y_2)$ 输出预测标签 $c$。该过程通过以下元学习目标进行优化：

$$
\min_{\theta} \mathbb{E}_{S_i \sim \mathcal{S}} \mathbb{E}_{D_i \sim P(D|S_i)} \mathbb{E}_{(x, y_1, y_2) \sim D_i \setminus D_i^{fewshot}} \left[ -\log \sigma \left( \beta \log \frac{\pi_\theta(y_w | x, D_i^{fewshot})}{\pi_{ref}(y_w | x, D_i^{fewshot})} - \beta \log \frac{\pi_\theta(y_l | x, D_i^{fewshot})}{\pi_{ref}(y_l | x, D_i^{fewshot})} \right) \right]
$$

此公式表明，策略 $\pi_\theta$ 在计算对数似然时，不仅依赖查询 $x$，还条件依赖于该用户的少样本偏好历史 $D_i^{fewshot}$。这种设计解决了传统 DPO 在冷启动场景下因缺乏用户特定信号而导致的偏好混淆问题，使模型能够利用上下文中的离散偏好标签推断出连续的用户奖励空间。

### 用户描述合理化（RAT）

少样本偏好作为 $N$-bit 表示，信息容量有限，直接用于生成响应可能引入噪声。RAT 将预测过程解耦为两步：首先从少样本偏好生成自然语言用户描述 $d_u$，再基于 $d_u$ 和查询 $x$ 生成响应。该步骤通过偏好优化训练，其中“偏好”定义为生成的描述与真实用户描述的语义接近度。RAT 本质上是一种推理时计算（inference-time compute）策略，通过生成中间表示 $d_u$ 来增强奖励建模的精度。这一设计解决了少样本偏好直接条件化生成时可能出现的幻觉或风格漂移问题，使模型能够利用 LLM 的指令遵循能力，将抽象的偏好标签转化为具体的生成约束。

## 实验评估

实验在三个自建半真实域（Reviews, ELIX, Roleplay）上进行，基线包括 Base LLM、Few-shot Prompting、SFT、Oracle Description 及 Rewards-in-Context。值得注意的是，实验未包含 RAG 或 LoRA 等参数化基线，限制了与领域主流方法的直接对比。在 Roleplay 任务中，FSPO 对 Base 模型的胜率为 68.2%，对 SFT 模型的胜率为 72.3%。

| 方法 | ELIX-easy Winrate (%) | ELIX-hard Winrate (%) | Roleplay Winrate vs Base (%) |
| :--- | :--- | :--- | :--- |
| Llama 3.2 3B Instruct | 50.0 | 50.0 | - |
| Few-shot Prompted | 92.4 | 81.4 | - |
| FSPO (Ours) | 97.8 | 91.8 | 68.2 |

在 ELIX 任务中，FSPO 在 easy 和 hard 子集上均显著优于 Few-shot Prompting，表明元学习训练提升了模型对教育水平差异的敏感度。在 Roleplay 任务中，FSPO 对 Base 模型的 68.2% 胜率经单侧二项检验（p-value = 5.65e-09）确认具有统计显著性。

消融实验显示，引入 RAT 机制后，模型在 Roleplay 任务上接近 Oracle Description 的性能上限，验证了用户描述作为中间表示的有效性。此外，合成数据的多样性与结构一致性对 Sim2Real 迁移至关重要：通过迭代细化 persona，偏好标签的二元香农熵从 0.64 nats 降至 0.13 nats，表明数据结构的优化显著提升了 persona-prompt-response 的一致性。

评估边界方面，实验主要依赖 AlpacaEval 胜率和人工评估，缺乏对事实性错误的量化指标。代码已开源，基于 PyTorch FSDP 框架，使用 NVIDIA A100 GPU 训练。由于未使用 LaMP 或 LongLaMP 等标准基准，结果的可比性局限于特定任务设置。

## 关联研究分析

从问题动机看，FSPO 与 RAG 路线存在根本差异。RAG 假设用户偏好可通过历史上下文直接检索注入，属于非参数化适配，其瓶颈在于检索质量与上下文窗口的限制。FSPO 则通过训练模型从少样本偏好中推断奖励函数，属于参数化适配的变体，但其参数更新发生在元学习层面而非用户特定适配器层面。这种差异源于任务特性：RAG 适合偏好静态且数据丰富的场景，而 FSPO 针对冷启动与动态偏好场景，通过元学习实现快速适应。然而，FSPO 未验证在长程交互中少样本偏好的稳定性，当用户偏好随时间演化时，静态的少样本上下文是否足以捕捉动态变化，论文未给出回答。

从方法设计看，FSPO 与 DPO 的关系是继承与扩展。DPO 优化单一策略以匹配群体偏好，而 FSPO 将 DPO 的隐式奖励参数化嵌入元学习框架，使策略能够条件依赖于用户上下文。与 PerFit 等表示空间偏移方法相比，FSPO 不修改模型权重，而是利用上下文学习实现个性化，这避免了灾难性遗忘，但可能牺牲长期一致性。RAT 机制的引入类似于智能体架构中的规划步骤，先推理用户状态再生成动作，体现了推理时计算的思想。然而，RAT 生成的描述是否可能引入新的幻觉风险，特别是在事实性敏感任务中，论文未进行专门评估。

## 总结

FSPO 旨在解决通用对齐中个体偏好被聚合抹平的问题，通过黑盒元学习框架实现少样本个性化。其核心创新在于将用户视为任务实例，利用 DPO 的隐式奖励参数化结合上下文学习，并引入 RAT 机制提升推理时精度。实验证明 FSPO 在合成数据上实现了 87% 的胜率，在真实用户研究中达到 70% 的胜率。然而，实验局限于自建半真实域，未与 RAG 或 LoRA 在标准基准上对比，且缺乏对事实性错误的量化评估。当用户偏好随时间动态演化时，静态的少样本上下文是否足以捕捉这种变化，论文未给出回答。
