# ICLR2026最新论文 ｜LLMs Process Lists With General Filter Heads ｜列表过滤的模块化机制：Filter Heads 与谓词编译

研究机构：美国东北大学

作者：Arnab Sen Sharma、Giordano Rogers、Natalie Shapira 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.26784)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.26784)

> 机制可解释性（Mechanistic Interpretability, MI）旨在通过逆向工程揭示 Transformer 内部计算机制，以打破大语言模型的黑盒性质。现有电路发现范式多聚焦于序列依赖任务，难以解释模型如何处理无固定顺序的集合操作，且缺乏对抽象语义谓词如何被“编译”为可复用几何表示的因果证据。本文通过激活修补定位中间层的稀疏注意力头（Filter Heads），证明其 Query 状态编码了可跨语言、跨格式移植的谓词表示。这一发现验证了 Transformer 存在模块化计算原语，但仅局限于语义过滤场景，未覆盖非线性算术或长程状态追踪。

## 研究背景

当语言模型面对“找出列表中的水果”这类指令时，其内部并非对每个新任务重新学习过滤逻辑，而是复用一种通用的选择机制。这种机制依赖于残差流（Residual Stream）上的信息路由，其中注意力头（Attention Head）作为功能单元，通过 Query 与 Key 的交互实现信息检索。然而，传统分析常将注意力头视为静态组件，忽略了其在不同上下文间动态编码抽象语义的能力，导致无法解释模型为何能在未见过的列表中执行相同的过滤操作。

机制可解释性领域的核心矛盾在于计算效率与因果严谨性的平衡。早期电路分析（Olah et al., 2020）确立了稀疏子网络范式，但多依赖相关性证据；激活修补（Vig et al., 2022）引入了因果干预标准，却主要应用于序列模式识别（如间接宾语识别）。对于集合操作，现有方法缺乏对“谓词”这一抽象概念如何被神经表示的深入剖析，且自动化电路发现算法（如 ACDC）计算成本高昂，难以扩展至大规模模型。本文切入点在于将过滤操作形式化为函数式编程中的 `filter` 原语，通过因果中介分析定位专门负责谓词编码的注意力头，从而在语义层面建立可验证的机制解释。

## 核心方法

### 方法参照系

本文问题属于电路发现与归因路线，但区别于标准流程修补残差流以识别功能组件，本文聚焦于注意力头 Query 状态的特定干预。标准电路发现通常通过消融组件观察任务性能下降，而本文通过跨上下文移植 Query 向量，直接验证谓词表示的因果必要性与可移植性，将分析粒度从“组件重要性”提升至“语义功能等价性”。

### 谓词编译与 Query 状态互换

传统激活修补替换整个残差流或特定层的输出，易引入无关变量干扰。本文创新在于仅互换注意力头在特定 token 位置的 Query 状态，以隔离谓词编码的因果作用。设计动机是解决单一头干预强度不足的问题，通过稀疏掩码学习联合优化多个头的贡献。

$$
q_{\text{patched}}^{[\ell,j]} = \text{mask}_{\ell j} \cdot q_{\text{src}}^{[\ell,j]} + (1 - \text{mask}_{\ell j}) \cdot q_{\text{dest}}^{[\ell,j]}
$$

该公式表明，通过二值掩码 $\text{mask}_{\ell j}$ 选择性地用源提示（$p_{\text{src}}$）的 Query 状态替换目标提示（$p_{\text{dest}}$）的对应状态，从而将源谓词“编译”后的几何方向注入新上下文。

### 因果性量化与稀疏掩码优化

为量化 Filter Heads 的集体因果影响，本文定义因果性分数（Causality Score），即修补后模型正确预测目标项的概率。设计动机是克服单个头干预被其他备份机制抵消的问题，通过最大化目标项 Logit 差值并施加稀疏正则化，自动识别最小充分头集合。

$$
\mathcal{L} = \log P(c_{\text{targ}} | p_{\text{dest}} \leftarrow q_{\text{src}}) - \log P(c_{\text{other}} | p_{\text{dest}} \leftarrow q_{\text{src}}) + \lambda \|\text{mask}\|_1
$$

该损失函数在最大化目标项 Logit 的同时抑制其他选项，并通过 $\ell_1$ 正则化确保掩码稀疏，从而定位出数量极少（<2% 总头数）但因果效力显著的 Filter Heads。

## 实验评估

实验基于 Llama-70B 模型，在六个自建 Filter-Reduce 任务上评估，包括 SelectOne、Counting 等。基线对比涵盖随机头、Function Vector 及 Concept Induction 头，但缺失 ACDC 等自动化电路发现算法的直接对比，限制了方法效率维度的评估。

| 任务 | Filter Heads 因果性 | ∆logit | 随机头因果性 |
| :--- | :--- | :--- | :--- |
| SelectOne (Obj) | 0.863 | +9.03 | 0.00 |
| Person Profession | 0.836 | +7.33 | - |
| Word Rhymes | 0.041 | +0.65 | - |

Filter Heads 在语义任务（如物体分类、职业识别）中保持高因果性（0.863, 0.836），但在非语义任务（如押韵词识别）中因果性骤降至 0.041，表明其功能严格限定于语义过滤。

| 消融条件 | SelectOne 准确率 | SelectOne-MCQ 准确率 |
| :--- | :--- | :--- |
| Filter Heads 消融 | 22.5% | 0.4% |
| 随机头消融 | 99.6% | 100% |

消融实验显示，移除 Filter Heads 导致 SelectOne 任务准确率从 100% 降至 22.5%，而随机头消融几乎无影响，证实了该稀疏子网络的因果必要性。跨语言移植测试中，从英语提取的 Query 状态在西班牙语、法语等语言中仍保持 0.775-0.951 的因果性，验证了表示的语言无关性。

评估边界受限于 Llama-70B 单一模型，未在小模型（如 GPT-2 Small）上验证机制的规模依赖性。代码发布于 filter.baulab.info，但超参数（如稀疏度 $\lambda$）未详细披露，且未报告置信区间，数值比较需谨慎。

## 关联研究分析

从问题动机看，本文与归纳头（Induction Heads, Olsson et al., 2023）研究形成互补。归纳头处理序列模式复制，而 Filter Heads 处理集合语义筛选。差异根源在于任务特性：序列任务依赖位置编码与时间步，而集合任务依赖语义嵌入的几何方向。本文未探索 Filter Heads 在长序列中的位置敏感性，尽管其 Query 状态在位置编码前缓存，暗示其对位置信息不敏感，但这在长上下文检索失败场景中是否成立，论文未给出回答。

从方法设计看，本文的 Query 互换策略比 ACDC 的递归消融更高效，但牺牲了全局最优性。ACDC 通过多次前向传播移除低重要性边，而本文通过单次掩码学习定位头集合。这种差异源于任务结构：Filter-Reduce 任务具有明确的因果路径（谓词→选择），适合局部干预；而通用电路发现需处理复杂交互，需全局搜索。本文未对比 ACDC 在相同任务上的性能，无法量化效率-精度权衡的具体边界。

## 总结

本文要解决的核心矛盾是 Transformer 内部抽象语义操作（如过滤）的机制不透明性。现有方法多依赖相关性或全局消融，无法证明特定头对谓词编码的因果必要性。本文通过 Query 状态互换与稀疏掩码学习，定位了中间层的 Filter Heads，证明其 Query 状态编码了可移植的谓词表示。实验显示，这些头在语义任务中因果性达 0.863，消融后准确率降至 22.5%，且表示可跨语言移植。本文的边界在于仅验证了语义过滤场景，未覆盖非线性算术或长程状态追踪，且缺乏跨模型规模对比。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
