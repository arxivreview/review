# ICLR2026最新论文 ｜Hybrid Reinforcement: When Reward Is Sparse, It's Better to Be Dense ｜混合集成奖励优化

作者：Leitian Tao、Ilia Kulikov、Swarnadeep Saha 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.07242)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.07242)

> 基于可验证奖励的强化学习（RLVR）旨在利用确定性验证器提供客观二元信号以训练大语言模型推理能力，但严格 0-1 验证在部分正确或格式敏感任务中易产生假阴性，导致梯度稀疏与优化停滞。现有方案中，规则验证器精度极高但召回率不足，而奖励模型（RM）提供密集信号却存在噪声与对齐偏差，二者简单混合往往引发训练不稳定。本文提出 HERO 框架，通过分层归一化将 RM 分数锚定在验证器定义的组内，并引入方差感知加权以聚焦高难度提示。该设计在难验证数学任务上显著优于单一信号基线，但其对 RM 假阳性风险的抑制机制及跨领域泛化能力仍需进一步审视。

## 研究背景

当模型生成数学证明或复杂代码时，最终答案的正确性往往依赖于中间步骤的逻辑一致性。传统 RLVR 依赖确定性检查器（如单元测试或符号等价检查）输出二元奖励 $r(x, y) \in \{0, 1\}$，这种稀疏信号虽无歧义，却无法区分“完全错误”与“部分正确”的响应。当组内所有响应获得相同标签时，组相对策略优化（GRPO）的优势函数归零，导致梯度消失，模型无法从失败轨迹中提取有效学习信号。

RLVR 领域的核心瓶颈在于验证器可靠性与信用分配精度的矛盾。规则验证器在格式敏感任务上召回率极低，例如 math_verify 库在难验证样本上召回率仅为 38.6%，大量有效解被误判为错误；而奖励模型虽能捕捉细微质量差异，但其连续分数常与正确性语义错位，直接混合会引入噪声并破坏训练稳定性。主流路线如 DAPO 或 Risk-Sensitive RL 侧重探索机制或目标函数调整，未解决奖励信号本身的结构性缺陷。本文切入点在于构建一种结构化混合框架，既保留验证器的正确性约束，又利用 RM 的密集信号缓解组内方差为零导致的优化停滞。

## 核心方法

### 方法参照系

标准 RLVR 流程中，策略 $\pi_\theta$ 对提示 $x$ 采样 $K$ 个响应，验证器输出二元奖励，GRPO 通过组内归一化计算优势函数。本文问题与该通用流程的关键差异在于：当验证器对难验证任务失效（全 0 或全 1）时，标准流程无法提供梯度，而本文需在保持正确性语义的前提下，在组内引入密集区分信号。

### 分层归一化

设计动机是解决 RM 连续分数与二元验证器语义错位导致的训练不稳定。在标准 GRPO 中，奖励直接来自验证器，本文在此环节引入 RM 分数，但通过分层归一化将其限制在验证器定义的组内。具体而言，将响应按规则验证器输出 $r_{rule}$ 分为正负两组，对每组内的 RM 分数 $r_{RM}$ 进行 min-max 归一化，并通过参数 $\alpha, \beta$ 控制允许范围：

$$ \hat{r}_i = r_{rule,i} + \begin{cases} \alpha \frac{r_{RM,i} - \min(r_{RM}^{pos})}{\max(r_{RM}^{pos}) - \min(r_{RM}^{pos}) + \epsilon}, & r_{rule,i}=1 \\ \beta \frac{r_{RM,i} - \min(r_{RM}^{neg})}{\max(r_{RM}^{neg}) - \min(r_{RM}^{neg}) + \epsilon}, & r_{rule,i}=0 \end{cases} $$

该公式确保正确响应始终高于错误响应，同时在组内引入梯度差异，使模型能区分“更正确”与“仅正确”的解，从而在全对或全错组中恢复有效梯度流。

### 方差感知加权

设计动机是解决 GRPO 对所有提示均匀处理导致计算资源浪费的问题。在计算最终奖励时，本文引入基于 RM 分数标准差 $\sigma_u$ 的加权函数 $w(\sigma_u)$，动态调整不同提示的贡献度：

$$ w(\sigma_u) = w_{min} + (w_{max} - w_{min}) \cdot \frac{\sigma_u}{\bar{\sigma} + \sigma_u} $$

其中 $w_{min}=0.5, w_{max}=2.0$。该机制识别高方差（即模型不确定性高、RM 区分度强）的难提示并上调其权重，同时下调低方差易提示的权重，使训练容量聚焦于最具信息量的样本，避免易题主导优化过程。

## 实验评估

实验基于 Qwen3-4B-Base 与 OctoThinker-8B-Hybrid-Base 两个骨干，在 OpenMathReasoning 子集上训练，涵盖易验证、难验证及混合三种数据配置。基线包括 AceMath-7B-RM（仅 RM）、math_verify（仅验证器）及 SFT 冷启动模型，但缺失 DAPO、RiskPO 等最新探索机制基线，限制了与当前 SOTA 的直接对比。

在难验证任务上，HERO 以 66.3 的平均分领先 RM-only（54.6）11.7 点及验证器-only（57.1）9.2 点，表明混合设计在验证器失效场景下具有显著鲁棒性。消融实验显示，移除负组归一化（Neg Only）导致难验证任务性能从 73.2 降至 68.4，证实负组密集信号对错误检测至关重要；方差感知加权在难验证任务上带来 3.8 点提升，验证了聚焦高难度样本的有效性。

评估边界受限于仅测试数学任务，未覆盖代码或科学推理等非数学可验证领域。可复现性方面，论文未提供代码 URL，且 RM 阈值选择（如 threshold 1 时 FPR 高达 46.4%）未深入消融，存在 RM 假阳性风险未被完全抑制的隐患。

## 关联研究分析

从问题动机看，HERO 与 Process Reward Models (PRM) 均旨在解决稀疏奖励下的信用分配问题，但 PRM 依赖人工标注中间步骤，成本高且易过拟合，而 HERO 利用外部 RM 提供密集信号，避免了标注成本，却引入了 RM 噪声风险。HERO 通过分层归一化将 RM 分数限制在验证器组内，实质上是用验证器作为“门控”来约束 RM 的漂移，这与 Self-Aligned Reward 利用内部信号缓解开放域奖励缺失的思路不同，后者不依赖外部模型，但 HERO 在难验证任务上的性能提升（+11.7 点）表明外部 RM 在特定场景下仍具优势。

从方法设计看，HERO 与 Token Hidden Reward 同属细粒度信用分配路线，但 Token Hidden Reward 基于策略梯度动态识别 token 级隐藏奖励，无需外部模型，而 HERO 依赖 7B RM 提供序列级密集分数。HERO 的方差感知加权机制与 Risk-Sensitive RL 的目标函数调整不同，前者在数据层面重加权，后者在优化目标层面插值，二者在机制上互补，但 HERO 未探索与探索机制的结合，可能在高难度任务上面临探索不足的限制。

## 总结

HERO 针对 RLVR 中验证器稀疏性与 RM 噪声的冲突，提出分层归一化与方差感知加权相结合的混合奖励框架，在难验证数学任务上实现 66.3 的平均分，较 RM-only 基线提升 11.7 点。其核心价值在于通过结构化约束保留验证器正确性语义的同时，利用 RM 密集信号恢复组内梯度流，解决了标准 GRPO 在全对/全错组中梯度消失的问题。然而，论文仅测试数学任务，且 RM 阈值选择对假阳性率的影响未充分消融，当 RM 在开放域任务中产生系统性偏差时，分层归一化是否仍能有效抑制噪声，论文未给出回答。
