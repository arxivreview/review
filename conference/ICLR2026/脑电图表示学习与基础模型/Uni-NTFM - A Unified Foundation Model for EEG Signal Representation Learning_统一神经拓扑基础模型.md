# ICLR2026最新论文 ｜Uni-NTFM: A Unified Foundation Model for EEG Signal Representation Learning ｜统一神经拓扑基础模型

研究机构：中国科学院、新加坡南洋理工大学

作者：Zhisheng Chen、Yingwei Zhang、Qizhen Lan 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.24222)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.24222)

> 脑电信号（EEG）基础模型旨在从非平稳、高噪声的神经信号中提取具备跨被试泛化能力的通用特征，以突破传统手工特征工程在复杂临床场景下的性能瓶颈。现有方法多将神经信号视为像素网格或离散令牌序列，忽略了大脑皮层复杂的几何拓扑结构与稀疏编码机制，导致频谱偏差与个体身份混淆。Uni-NTFM 通过异构特征投影模块解耦时频域信号，结合层级拓扑嵌入对齐电极布局，并引入混合专家架构实现功能模块化，在 28,000 小时数据上预训练以构建神经生理学一致的通用表示。该架构在九项下游任务中超越了主流基础模型，但其对在线适应机制的缺失及频域重建对高频伪影的抑制效果仍需进一步验证。

## 研究背景

脑电信号解码的核心痛点在于信号的非平稳性与个体异质性。早期方法依赖功率谱密度等手工特征，泛化能力差，难以应对跨被试分布偏移。随着深度学习引入，端到端表示学习成为主流，但标注数据稀缺限制了模型性能。自监督预训练范式通过掩码重建学习通用神经表示，旨在通过计算成本换取跨任务迁移能力，然而单纯扩大模型规模暴露了频谱偏差与身份陷阱等内在缺陷。

当前 EEG 基础模型（EEG Foundation Models, EFMs）主要继承自计算机视觉或自然语言处理范式，将连续信号分割为固定尺度的补丁或令牌，并采用稠密注意力网络进行全局交互。这种设计哲学与 EEG 信号的物理特性存在根本矛盾：它无法捕获大脑的解耦编码机制，忽略了电极作为连续皮层几何采样器的空间拓扑属性，且缺乏生物网络的稀疏模块化效率。现有架构在处理高度异构的 EEG 信号时，易产生任务干扰，且难以将不同标准的电极布局映射至统一的语义空间。

Uni-NTFM 的切入点在于从神经生理学第一原理重构模型架构。它不再将 EEG 视为简单的时空序列，而是模拟大脑的并行处理架构，通过显式建模波形形态、频谱节律与空间拓扑，解决现有模型在跨设备泛化与信号保真度上的瓶颈。该模型旨在构建一个能够自适应不同国际电极标准与任务范式的统一框架，实现从信号重建到临床语义对齐的深层映射。

## 核心方法

### 方法参照系

标准 EEG 基础模型通常采用“分词-预训练-微调”范式，将时间序列切分为固定长度补丁，通过 Transformer 进行掩码重建。本文的关键差异在于拒绝将时间轴简单分段，而是将每个电极的完整时间序列视为整体“补丁”，并通过多域特征投影与拓扑嵌入，在输入端即引入神经解剖学先验，改变了传统模型仅依赖可学习位置编码的空间建模方式。

### 异构特征投影与双域交叉注意力

为了解决单一处理通道混淆波形形态与频谱结构的问题，Uni-NTFM 设计了异构特征投影模块（Heterogeneous Feature Projection Module, HFPM）。该模块将输入信号 $x_i \in \mathbb{R}^{[T]}$ 并行投影至时域、频域与原始域三个特征空间。时域路径通过一维卷积编码器 $\Phi_T$ 捕获非平稳瞬态，频域路径通过离散傅里叶变换计算功率谱密度并投影至频域特征向量 $h_{i,F}$。随后，双域交叉注意力模块（Dual-domain Cross-attention Module, DCM）强制时频特征进行跨域对话，时域特征作为 Query 探测频域特征的 Key 和 Value，反之亦然，生成深度融合表示 $H_{fused}$。

$$ H_{fused} = \text{FFN}(\text{Concat}(H_T', H_F')) $$

这一设计确保了模型在预训练阶段同时学习时域波形与频域节律的生成规则，从源头抑制了单一重建目标导致的低频偏好，提升了表示对非平稳事件的敏感性。

### 层级拓扑嵌入与稀疏混合专家

针对电极布局异构性问题，Uni-NTFM 引入层级拓扑嵌入（Topological Embedding, TE），将空间语义分解为区域、区域内及全局绝对位置三个层级。区域嵌入 $E_{region}$ 基于 10-20 系统划分五个脑区，区域内嵌入 $E_{intra}$ 编码相对空间方位，全局绝对嵌入 $E_{abs}$ 保留标准电极身份。最终空间表示为三者之和，使模型能将不同传感器配置映射至统一神经坐标系。

$$ H_{spatial} = H_{fused} + E_{region}[x_{region}] + E_{intra}[x_{intra}] + E_{abs}[x_{abs}] $$

在此基础上，模型采用稀疏激活的混合专家（Mixture-of-Experts, MoE）架构替代稠密前馈网络。门控网络 $g(h_i)$ 计算每个令牌在 $N_e$ 个专家网络上的 logits，通过 Top-k 路由选择特定专家处理信号。这种动态路由机制实现了功能模块化，将不同信号模式分配给专用子网络，有效缓解了任务干扰，并将模型容量扩展至 1.9 亿参数。

## 实验评估

实验在九个公开数据集上进行，包括 TUAB、TUEV、SEED 等，涵盖异常检测、事件检测、情绪识别等任务。基线覆盖传统任务特定方法（如 EEGNet）、仅预训练基础模型（如 NeuroLM-XL）及微调基础模型（如 LaBraM、CBraMod）。Uni-NTFM 在微调设置下表现优异，在 TUAB 上达到 89.82% 的 AUROC，在 TUEV 上达到 70.30% 的加权 F1，显著优于 LaBraM 和 CBraMod。

| 方法 | TUAB AUROC | TUEV Weighted F1 | SEED Weighted F1 |
| :--- | :--- | :--- | :--- |
| LaBraM-Base | 89.65 | 66.37 | 73.18 |
| CBraMod | 86.36 | 67.72 | 72.72 |
| Uni-NTFM_large | 89.82 | 70.30 | 73.37 |

消融实验表明，HFPM 是性能提升的关键，单独引入使 TUAB AUROC 从 71.16% 提升至 78.05%。MoE 模块单独加入时收益有限，但与 HFPM 和 TE 结合后，完整模型在 TUEV 上达到 81.74% 的 Cohen's Kappa，验证了组件间的协同效应。

| 配置 | TUAB AUROC | TUEV Cohen's Kappa |
| :--- | :--- | :--- |
| Baseline (A1) | 71.16 | 63.34 |
| + HFPM (A2) | 78.05 | 76.69 |
| Full Model (A10) | 83.25 | 81.74 |

评估边界方面，论文未报告置信区间，且主要对比基线缺失 2025-2026 年的最新 SOTA 模型（如 REVE、Laya）。代码已开源，但预训练数据的具体构成与清洗细节在附录中仅部分披露，可能影响复现性。

## 关联研究分析

从空间建模策略看，Uni-NTFM 的层级拓扑嵌入与 REVE 的 4D 位置编码形成对比。REVE 依赖大规模数据学习空间拓扑，而 Uni-NTFM 通过显式注入神经解剖学先验（如 10-20 系统脑区划分）来对齐电极布局。这种设计使 Uni-NTFM 在缺失通道场景下更具鲁棒性，但可能限制了其对非标准电极布局的泛化能力。相比之下，CBraMod 采用 Criss-Cross Attention 分离时空注意力，侧重于长序列依赖建模，而 Uni-NTFM 通过 MoE 稀疏激活实现功能模块化，更关注任务间的干扰抑制。

从预训练目标看，Uni-NTFM 的双域重建损失与 Laya 的潜在预测架构存在分歧。Laya 通过抑制重建目标对高方差伪影的偏好来提升跨任务泛化，而 Uni-NTFM 坚持时频双域重建以保留信号细节。这种选择可能导致 Uni-NTFM 在噪声敏感任务上性能受限，但在高保真重建任务（如事件检测）上具有优势。论文未明确讨论频域重建是否真正解决了频谱偏差，还是仅增加了计算开销，这一疑问在缺乏频谱平衡损失对比实验的情况下难以解答。

## 总结

Uni-NTFM 旨在解决 EEG 基础模型架构与神经生理机制不匹配的问题，通过异构特征投影、层级拓扑嵌入与稀疏混合专家架构，实现了跨设备与跨任务的通用表示学习。该模型在 28,000 小时数据上预训练，在九项下游任务中超越了 LaBraM 和 CBraMod，证明了结构感知建模的有效性。然而，其性能优势主要基于微调设置，且缺乏与最新在线适应方法（如 NeuroTTT）的对比，暴露了其在个体差异动态校准上的潜在短板。当面对极端缺失通道或非标准电极布局时，层级拓扑嵌入的鲁棒性边界是否仍能维持跨被试泛化能力，论文未给出明确回答。
