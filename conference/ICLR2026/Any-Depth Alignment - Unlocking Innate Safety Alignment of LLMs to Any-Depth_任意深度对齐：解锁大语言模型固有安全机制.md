# ICLR2026最新论文 ｜Any-Depth Alignment: Unlocking Innate Safety Alignment of LLMs to Any-Depth ｜任意深度对齐：解锁大语言模型固有安全机制

研究机构：美国芝加哥大学、美国伊利诺伊大学厄巴纳-香槟分校

作者：Jiawei Zhang、Andrew Estornell、David D. Baek 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.18081)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.18081)

> 大语言模型（LLM）的安全对齐长期受困于“浅层性”，即模型仅在响应起始处拒绝有害请求，一旦生成进入深处，防御机制便失效。现有防御方案或依赖外部护栏导致高延迟，或依赖深度对齐训练但无法泛化至任意生成深度。本文发现助手头（Assistant Header）Token 的隐藏状态中编码了可线性分离的固有安全信号，提出任意深度对齐（Any-Depth Alignment, ADA），通过推理时重新注入该 Token 或探测其状态，在生成任意位置恢复拒绝行为。该机制无需修改模型权重，显著提升了防御深度，但其对特定模板 Token 的依赖是否具备跨架构普适性仍存疑。

## 研究背景

LLM 安全对齐的核心困境在于模型内部安全表征与生成轨迹的解耦。当模型开始生成有害内容时，其隐藏状态中已包含识别有害性的信号，但在常规解码过程中，这些信号被锁定在复杂的上下文依赖中，无法直接触发拒绝行为。这种“浅层对齐”现象导致模型在面对对抗性提示或长文本预填充时，安全机制迅速崩溃，而外部护栏模型虽能检测有害内容，却因需等待完整生成后判定，导致有害信息已泄露至客户端。

主流防御路线分为训练时深度对齐与推理时外部干预。深度对齐（Deep Alignment）通过微调让模型在响应中途拒绝，但实验表明其保护范围有限，面对长预填充攻击时拒绝率仍大幅下降；外部护栏（如 Llama Guard）虽鲁棒，但引入了额外的模型推理开销与延迟。本文的切入点在于挖掘模型自身的“固有安全”：对齐模型在训练过程中已习得对有害性的判断，这一判断被锚定在聊天模板的助手头 Token 上。本文旨在证明，通过推理时重新激活这一锚点，无需额外训练或外部模型，即可在生成任意深度实现安全拦截。

## 核心方法

### 方法参照系

本文问题属于推理时安全干预范畴，但区别于依赖外部分类器或全序列扫描的传统方法。其关键差异在于不引入额外模型，而是利用基座模型自身的隐藏状态作为安全判据，将防御机制内化于生成过程之中，解决了外部护栏延迟高与深度对齐泛化性差的问题。

### 安全 Token 的线性可分性

设计动机在于解决浅层对齐中安全信号随生成深度增加而“锁定”的问题。本文发现，助手头 Token（如 `<|start_header_id|>assistant<|end_header_id|>`）的隐藏状态在生成过程中保持对有害内容的高线性可分性。设 $h_{safe}$ 为注入的助手头 Token 在层 $l$ 的隐藏状态，$y \in \{0, 1\}$ 为有害性标签，线性探针 $f(h_{safe}) = w^T h_{safe} + b$ 能够以超过 99.5% 的验证准确率区分良性与有害上下文。这一性质表明，助手头 Token 充当了安全证据的“聚合器”，将分散在上下文中的有害性信号压缩为可线性检测的表征，使得安全判断不再依赖于生成内容的具体词汇，而是依赖于模型内部对上下文语义的整体评估。

### 任意深度对齐机制

基于上述可分性，本文提出两种推理时干预策略。第一种是任意深度对齐-反思（ADA-RK），在周期性检查点（如每 100 Token）分叉生成流，重新注入助手头 Token 并生成短前瞻（Lookahead）。若前瞻中出现拒绝语句，则终止当前流并返回拒绝。其决策逻辑可形式化为：

$$
\text{Refuse} \iff \exists t \in [1, T_{lookahead}] : \text{Token}_t \in \mathcal{R}
$$

其中 $\mathcal{R}$ 为拒绝词集合。第二种是任意深度对齐-线性探针（ADA-LP），直接对注入的助手头 Token 隐藏状态执行单次前向传播，应用线性分类器 $f(h_{safe})$。若 $f(h_{safe}) > \tau$（阈值），则立即终止生成。ADA-LP 避免了额外的解码开销，实现了常数时间的安全检测，且由于复用了基座模型的 KV 缓存，内存开销极低。

## 实验评估

实验在 AdvBench、JailbreakBench、StrongREJECT 和 HEx-PHI 四个基准上进行，对比基线包括基础模型、深度对齐、自我防御（Self-Defense）及外部护栏（Llama Guard、Granite Guardian）。

| 方法 | AdvBench 拒绝率 (%) | 备注 |
| :--- | :--- | :--- |
| Base Model | < 10 | 25-token 预填充下崩溃 |
| Deep Alignment | < 25 | 100-token 预填充下失效 |
| ADA (RK) | > 95 | Claude Sonnet 4, 500-token 预填充 |
| ADA (LP) | ~ 100 | 开源模型，深度预填充 |

在对抗性提示攻击（GCG, AutoDAN, PAIR, TAP）中，ADA-LP 将平均攻击成功率从 >50% 降至 <3%。消融实验显示，助手头 Token 的线性探针准确率显著高于最后生成 Token 的探针，且 `assistant` 角色 Token 的信号强度优于其他特殊 Token。

| 探测目标 | 验证准确率 (%) | 模型 |
| :--- | :--- | :--- |
| 助手头 Token | > 99.5 | Llama, Qwen, Mistral 等 |
| 最后生成 Token | 显著较低 | 所有测试模型 |

评估边界方面，论文未报告置信区间，且线性探针仅在 Wild 数据集上训练后直接用于下游基准，未展示跨模型迁移时的探针重训练需求。代码未公开，复现需依赖具体的 Token 定义与层选择。

## 关联研究分析

从问题动机看，本文与深度对齐（Deep Alignment）形成直接对立。深度对齐试图通过微调扩展拒绝行为的触发深度，但本文实验证明其保护范围有限，且仍受对抗性提示攻击影响。本文的切入点在于揭示对齐模型已具备“固有”的深层安全判断，只是被解码过程锁定，因此无需修改权重，仅需推理时干预即可解锁。这一发现将防御重心从“训练模型学会拒绝”转向“激活模型已有的拒绝能力”，解决了深度对齐中灾难性遗忘与泛化性差的问题。

从方法设计看，本文与外部护栏（如 Llama Guard）存在显著差异。外部护栏依赖独立的分类模型，需等待完整生成后判定，导致延迟高且有害内容已泄露。本文的 ADA-LP 利用基座模型自身的隐藏状态，实现了生成中的实时拦截，且无需额外模型部署。然而，本文方法高度依赖聊天模板中的助手头 Token，若模型架构或模板变更（如移除 Header 或采用不同分隔符），安全信号的锚点可能失效。相比之下，AlignTree 等方法通过树搜索探索内部表示，虽计算开销大，但对模板依赖较低。本文在效率上占优，但在模板鲁棒性上存在潜在盲区。

## 总结

本文针对 LLM 浅层对齐在生成深处失效的核心矛盾，抓住了助手头 Token 隐藏状态中线性可分的固有安全信号这一被忽略的切入点。通过推理时重新注入该 Token 或探测其状态，ADA 实现了无需修改权重的任意深度安全对齐。实验证明，ADA-LP 在深度预填充攻击下实现近 100% 拒绝率，并将对抗性提示攻击成功率降至 3% 以下。然而，该方法的有效性紧密依赖于特定聊天模板中的助手头 Token 结构，当模型架构或模板设计发生变化时，这一安全锚点是否依然稳定，论文未提供跨模板或跨架构的鲁棒性验证。
