# ICLR2026最新论文 ｜BOOTSTRAPPING MLLM FOR WEAKLY-SUPERVISED CLASS-AGNOSTIC OBJECT COUNTING ｜弱监督类无关目标计数

研究机构：同济大学、武汉大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_75444184)

> 目标计数任务旨在从图像中估计特定类别实例的数量，传统全监督方法依赖高昂的点级标注，而现有弱监督方法多局限于单一类别且难以应对密集场景。多模态大语言模型（MLLM）虽具备零样本计数潜力，但在密集场景下因预训练分布偏差导致严重低估。本文提出WS-COC框架，通过分治对话、排序优化及全局-局部融合策略，仅利用图像级计数标签实现类无关计数。该方法在FSC-147测试集上达到13.91 MAE，接近全监督SOTA，但推理效率与密集场景的局部细节捕捉仍存在局限。

## 研究背景

目标计数通常通过回归密度图或检测实例边界框实现，其中密度图积分法需为每个实例提供点级标注。在密集场景中，实例数量可达数百甚至上千，点级标注成本呈线性增长且易受遮挡影响，这使得全监督方法在实际部署中面临标注瓶颈。为降低标注成本，弱监督计数范式仅使用图像级总数作为监督信号，但早期基于CNN或ViT的方法（如GCNet）受限于局部感受野，难以建立从全局视觉特征到精确数量的稳健映射，且大多局限于行人等单一类别。

随着多模态大语言模型（MLLM）的兴起，利用文本提示指定类别并自回归生成计数值成为新路径。然而，MLLM在预训练语料中接触到的多为稀疏物体分布，导致其在密集场景下出现系统性低估。直接微调MLLM以预测绝对计数值（WS-COC-Base）因缺乏物体分布监督，在密集场景下仍表现不佳。本文切入点在于利用MLLM的语言推理能力，将计数任务重构为一系列更易处理的子任务，从而在极低标注成本下实现类无关的高精度计数。

## 核心方法

### 方法参照系

传统弱监督计数方法直接学习从图像特征到计数值的回归映射，或基于VLM的判别式计数头。本文采用MLLM作为骨干，将计数转化为文本生成任务，关键差异在于不直接回归绝对数值，而是通过多轮对话和排序优化引导模型理解数量关系，利用语言模型的推理能力弥补视觉特征与离散数值间的模态鸿沟。

### 分治对话调优（D3T）

直接预测绝对计数值对MLLM而言难度过高，D3T策略将计数任务分解为一系列范围判断任务。给定图像 $I$ 和真实计数 $c$，初始范围设为 $[L_1, U_1]$，计算中点 $\tau_1 = \lfloor (L_1 + U_1) / 2 \rfloor$。模型被询问“图像中是否有超过 $\tau_1$ 个物体？”，根据回答更新范围边界：

$$
[L_t, U_t] = \begin{cases} [\tau_{t-1}, U_{t-1}] & \text{if } R_{t-1}^{gt} = \text{yes} \\ [L_{t-1}, \tau_{t-1}] & \text{if } R_{t-1}^{gt} = \text{no} \end{cases}
$$

此过程迭代直至范围宽度小于阈值 $\delta = 0.2 \times c$，最后要求模型预测具体数值。该设计通过课程学习机制，让模型从粗粒度判断逐步过渡到细粒度估计，有效缓解了直接回归在密集场景下的低估问题。

### 比较排序计数优化（CRCO）

视觉特征与文本计数值之间存在模态鸿沟，直接优化绝对误差困难。CRCO策略训练模型对多张图像的计数进行相对排序。对于同一类别，将训练集图像按计数值分为 $K$ 组（默认 $K=4$），每组随机采样一张图像构成集合 $\mathcal{I} = \{I_1, I_2, I_3, I_4\}$，其计数满足 $c_1 < c_2 < c_3 < c_4$。模型接收打乱顺序的图像集合，输出排序结果，损失函数为语言建模交叉熵：

$$
\mathcal{L}_{CRCO} = -\sum_{i=1}^{K} \log P(\hat{r}_i | \mathcal{I}, T_{inst})
$$

其中 $\hat{r}_i$ 为预测的排序位置。相比绝对回归，相对排序更符合人类视觉直觉，且通过覆盖不同密度区间，增强了模型对密集场景的数量感知能力。

### 全局-局部计数增强（GLCE）

推理阶段，为缓解密集场景下的计数偏差，GLCE策略融合全局与局部预测。首先对整图进行全局计数预测 $c_g$，然后将图像划分为 $L \times L$ 个子图（默认 $L=2$），独立查询每个子图获得局部计数 $\{c_k\}_{k=1}^{L^2}$。最终计数为全局与局部平均值的加权融合：

$$
c_{final} = \frac{c_g + \frac{1}{L^2} \sum_{k=1}^{L^2} c_k}{2}
$$

实验发现，全局预测倾向于低估（81.2%的情况），而局部聚合因边缘效应倾向于高估（79.4%的情况），两者互补性使得平均融合能显著降低密集场景的计数误差。

## 实验评估

实验在FSC-147、CARPK、PUCPR+和ShanghaiTech四个基准上进行，主要指标为MAE和RMSE。基线覆盖全监督VLM方法（如CLIP-Count、T2ICount）和弱监督CNN方法（如GCNet）。在FSC-147测试集上，WS-COC取得13.91 MAE，优于全监督的T2ICount（14.76）和弱监督的GCNet（17.83），但略逊于全监督SOTA CountGD（11.76）。在密集场景（>100实例/图）中，WS-COC将MAE从MLLM-Zero的149.69降至54.37，显著优于基线WS-COC-Base的82.44。

| 方法 | 监督类型 | FSC-147 Test MAE | FSC-147 Test RMSE |
| :--- | :--- | :--- | :--- |
| CountGD | Point-level | 11.76 | 97.86 |
| T2ICount | Point-level | 14.76 | 120.42 |
| GCNet | Image-level | 17.83 | 102.89 |
| WS-COC | Image-level | 13.91 | 97.28 |

消融实验显示，移除D3T导致验证集MAE上升3.36，移除CRCO上升2.62，表明两种训练策略均有效。GLCE中，仅使用全局预测（$c_g$）比完整策略MAE高1.87，验证了局部预测对密集场景的补偿作用。值得注意的是，D3T在测试阶段单独使用（WS-COC w/ D3T-T）性能大幅下降（MAE 37.07），因为测试时中间轮次的错误判断会误导后续推理，说明该策略依赖训练时的真值引导，不具备测试时自适应能力。

评估协议遵循领域惯例，使用MAE和RMSE。代码已开源，训练使用NVIDIA L20 GPU，LoRA秩为128。局限在于推理速度较慢（2.16 FPS），远低于全监督方法（如CLIP-Count的15.50 FPS），且未报告跨域泛化时的计算开销变化。

## 关联研究分析

从方法设计看，WS-COC与CLIP-Count等VLM计数方法的核心差异在于架构范式。CLIP-Count依赖判别式模型，需额外设计计数头将视觉特征映射为数值；WS-COC利用MLLM的生成式特性，将计数视为文本生成任务。这种差异源于MLLM具备更强的语义推理能力，能处理“数量”这一抽象概念，而VLM缺乏这种内在推理机制。然而，WS-COC的D3T策略在测试时失效，暗示其推理能力高度依赖训练时的真值分布，这与MLLM的通用推理能力预期存在差距，可能源于LoRA微调仅优化了特定任务参数，未充分激活模型的通用计数推理逻辑。

从问题动机看，WS-COC与GCNet等传统弱监督计数方法均旨在降低标注成本，但技术路径截然不同。GCNet基于CNN/ViT直接回归计数，受限于局部感受野，难以捕捉密集场景的全局分布；WS-COC利用MLLM的全局上下文先验，通过对话和排序策略显式建模数量关系。这种差异表明，弱监督计数的瓶颈不仅在于标注稀疏，更在于模型缺乏对“数量”这一离散属性的内在理解。WS-COC通过语言接口引入数量推理，弥补了视觉模型在密集场景下的感知缺陷，但其效果是否依赖于MLLM的规模（如7B vs 16B）及特定架构，论文未深入探讨。

## 总结

WS-COC旨在解决弱监督类无关计数中密集场景低估与标注成本高的矛盾。其切入点在于利用MLLM的语言推理能力，将计数重构为范围判断、相对排序和全局-局部融合的子任务，从而在仅使用图像级标签的条件下逼近全监督性能。实验证明，该方法在FSC-147测试集上取得13.91 MAE，显著优于传统弱监督方法，并在密集场景中将误差降低近60%。然而，D3T策略在测试时因缺乏真值引导而失效，且推理速度仅为2.16 FPS，限制了其实时应用潜力。当MLLM规模扩大至16B时，性能提升是否足以抵消计算开销的增加，以及D3T策略能否通过测试时自适应机制克服对训练真值的依赖，仍是亟待解决的问题。
