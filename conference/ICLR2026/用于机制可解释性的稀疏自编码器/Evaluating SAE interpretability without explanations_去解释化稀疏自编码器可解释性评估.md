# ICLR2026最新论文 ｜Evaluating SAE interpretability without explanations ｜去解释化稀疏自编码器可解释性评估

论文原文见 [arXiv](https://arxiv.org/abs/2507.08473)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2507.08473)

> 稀疏自编码器（Sparse Autoencoder, SAE）通过过完备字典将密集激活分解为稀疏单义特征，但评估这些特征是否真正具备人类可解释性仍缺乏统一标准。现有主流评估流程依赖大型语言模型（Large Language Model, LLM）生成自然语言解释，再评估解释对预测特征激活的效用，这一间接路径引入了额外超参数，且隐含了“可解释性必须可被语言简洁表达”的强假设。本文提出入侵者检测（Intruder Detection）与示例嵌入评分（Example Embedding Scoring）两种无需生成自然语言解释的直接评估方法，通过测量人类或LLM区分激活样本与非激活样本的能力来量化可解释性。入侵者检测与人类判断的Pearson相关系数达到0.84，验证了去解释化评估的有效性，但示例嵌入评分的相关性仅为0.48，提示轻量级评估器在捕捉细粒度激活语义时存在局限。

## 研究背景

当SAE从语言模型中提取出数以万计的潜在特征（latents）时，研究者面临的核心困境是如何判断这些特征是否真正对应了人类可理解的单一概念。多义性（Polysemanticity）导致单个神经元对多个无关概念同时响应，SAE通过稀疏约束将密集激活解耦为单义特征，但特征提取的质量评估却陷入了循环论证：评估者需要理解特征，而理解特征又依赖于评估结果。

为打破这一循环，领域内形成了以自动解释（Auto-interpretability）为核心的评估范式。该范式收集触发特征激活的文本上下文，交由LLM生成自然语言解释，再通过模拟（Simulation）或检测（Detection）任务评估解释的预测能力。然而，这一流程存在两个根本性缺陷：其一，解释生成过程引入了采样策略、提示词设计等额外超参数，使得评估结果难以与特征本身的内在属性解耦；其二，该范式预设了“可解释性等同于可被语言简洁表达”，忽略了人类可能通过直觉而非语言定义来理解特征的情况。

本文直接挑战了这一预设，提出可解释性应定义为人类能否直觉地理解特征含义并区分激活与非激活样本。基于此，本文设计了两种绕过自然语言解释生成的直接评估方法，并在SmolLM2 135M模型上验证了其与人类判断的一致性，为SAE评估提供了一条更短、更直接的因果路径。

## 核心方法

### 方法参照系：基于解释的评估流程

在标准SAE评估流程中，特征可解释性的量化依赖于“激活收集-解释生成-解释评估”三步。首先，在大规模语料上收集特征激活的上下文；其次，将高激活分位数的样本输入LLM，要求其总结触发激活的语义模式；最后，通过让LLM根据生成的解释预测新样本的激活状态（模拟）或判断特定token是否激活特征（检测），计算预测准确率作为可解释性分数。本文问题与该通用流程的关键差异在于：本文完全移除了“解释生成”这一中间环节，直接测量评估器对原始激活样本的区分能力，从而将评估信号与解释生成的噪声隔离。

### 入侵者检测：直接区分激活与非激活样本

入侵者检测任务将可解释性评估转化为一个五选一的分类问题。对于每个待评估特征，从激活分布的同一分位数（decile）中采样四个正样本，并从激活其他特征但不激活目标特征的样本池中采样一个负样本作为“入侵者”。评估器（人类或LLM）需识别出入侵者。为提供上下文，正样本中触发激活的token被高亮标记，负样本中则随机高亮相同数量的token。

该方法的评分函数定义为评估器在多个分位数上识别入侵者的平均准确率：

$$
\text{Score}_{\text{intruder}} = \frac{1}{D} \sum_{d=1}^{D} \mathbb{I}(\hat{y}_d = y_{\text{intruder}})
$$

其中 $D$ 为分位数数量，$\mathbb{I}$ 为指示函数。设计动机在于：若特征具备单义性，人类或LLM应能直觉地识别出与其余四个样本语义模式不符的入侵者，无需依赖LLM生成的中间解释文本。实验表明，人类在该任务上的平均准确率为65%，最高激活分位数达78%，证明直接观察激活样本足以支撑可解释性判断。

### 示例嵌入评分：轻量级嵌入空间聚类

为降低计算成本，本文提出示例嵌入评分，利用小型嵌入模型替代LLM进行评估。该方法测量激活样本在嵌入空间中的聚类程度。对于目标特征，采样正样本集合 $E_+$ 和负样本集合 $E_-$，并计算正查询 $\mathbf{q}_+$ 与负查询 $\mathbf{q}_-$ 到各自类别的相对距离：

$$
\Delta_+ = \min_{\mathbf{e} \in E_-} \|\mathbf{q}_+ - \mathbf{e}\| - \min_{\mathbf{e} \in E_+} \|\mathbf{q}_+ - \mathbf{e}\|
$$

$$
\Delta_- = \min_{\mathbf{e} \in E_+} \|\mathbf{q}_- - \mathbf{e}\| - \min_{\mathbf{e} \in E_-} \|\mathbf{q}_- - \mathbf{e}\|
$$

最终评分为基于 $\Delta_+$ 和 $\Delta_-$ 计算的AUROC。设计动机在于：若特征可解释，其激活样本应在语义嵌入空间中形成紧密簇，与非激活样本显著分离。该评分使用22M参数的all-MiniLM-L6-v2模型，计算效率远高于LLM评估，但实验显示其与人类判断的相关性（$r=0.48$）显著低于LLM入侵者检测（$r=0.84$），表明轻量级嵌入模型难以捕捉高亮token的细粒度语义。

## 实验评估

实验在SmolLM2 135M模型的MLP输出上训练TopK SAE（$k=32$），评估56个特征在四个层（9, 15, 21, 27）上的可解释性。基线覆盖包括人类评估、多种LLM（Claude Sonnet 3.5, Llama 3.1 70b/8b, QwQ 32b, Gemini Flash 2.0）及传统解释评估方法（Fuzzing F1, Detection F1）。

| 评估器 | 与人类入侵者检测的Pearson相关系数 |
| --- | --- |
| Claude Sonnet 3.5 | 0.84 |
| Gemini Flash 2.0 | 0.83 |
| QwQ 32b | 0.78 |
| Llama 3.1 70b | 0.77 |
| Llama 3.1 8b | 0.64 |
| 示例嵌入评分 | 0.48 |

Claude Sonnet 3.5与人类判断的相关性最高（0.84），且人类评估者倾向于比LLM给出更高的可解释性评分，表明LLM未捕捉到人类无法识别的虚假模式。Llama 3.1 8b表现最差（0.64），提示模型规模对去解释化评估的可靠性有显著影响。

| 评估方法 | 与人类入侵者检测相关性 | 与LLM入侵者检测相关性 |
| --- | --- | --- |
| 示例嵌入评分 | 0.48 | 0.51 |
| Fuzzing F1 | 0.69 | 0.74 |
| Detection F1 | 0.50 | 0.59 |

示例嵌入评分与所有基线的相关性均最低，验证了其在细粒度语义捕捉上的不足。Fuzzing F1与人类相关性（0.69）低于LLM入侵者检测（0.84），说明即使基于解释的评估，其信号强度也不如直接区分任务。

评估边界方面，本文未覆盖因果干预基线，无法验证去解释化评估与特征因果有效性的关联。实验仅使用SmolLM2 135M，未在GPT-2 Small或Llama-3.1 8B等标准基准上复现，跨模型泛化性未知。代码已集成至delphi pipeline，但超参数（如分位数采样策略）的敏感性分析缺失。

## 关联研究分析

从问题动机看，本文与Automated Interpretation Pipeline（P8）和SFAL Score（P30）形成直接对话。Automated Interpretation Pipeline依赖LLM生成解释并评估其预测效用，本文指出该流程的间接性引入了噪声；SFAL Score通过语义-功能邻域对比量化解释一致性，但仍以解释为中介。本文的入侵者检测完全绕过解释生成，将评估锚定在人类直觉区分能力上，这一差异源于对“可解释性”定义的根本分歧：前者认为可解释性是可被语言编码的预测规则，后者认为可解释性是可被直觉识别的语义模式。

从方法设计看，本文与Board Game Models Benchmark（P6）的评估逻辑互补。Board Game Models通过构造已知真实特征的合成模型提供金标准，本文则在真实语言模型上通过人类对齐验证评估器可靠性。本文未采用Board Game Models的因果干预协议，导致无法回答“高入侵者检测准确率的特征是否具备因果有效性”这一关键问题。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文针对SAE评估中自然语言解释引入噪声与假设过强的矛盾，提出入侵者检测与示例嵌入评分两种去解释化评估方法。入侵者检测通过五选一分类任务直接测量评估器对激活样本的区分能力，示例嵌入评分利用嵌入空间聚类实现轻量级近似。实验证明Claude Sonnet 3.5与人类判断的Pearson相关系数达0.84，验证了去解释化评估的有效性，但示例嵌入评分相关性仅0.48，暴露了轻量级评估器的语义捕捉局限。本文的边界在于未验证去解释化评估与因果干预的关联，且仅在SmolLM2 135M上实验。当评估器从LLM降级为嵌入模型时，可解释性信号的衰减是否源于嵌入空间对高亮token语义的固有盲区，论文未给出回答。
