# ICLR2026最新论文 ｜ONE PATCH DOESN T FIT ALL: ADAPTIVE PATCH ING FOR NATIVE-RESOLUTION MULTIMODAL LARGE LANGUAGE MODELS ｜自适应分块（AdaPatch）：原生分辨率多模态大语言模型的粒度失配修正

研究机构：中国科学院大学、中国科学院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_84071483)

> 导读 多模态大语言模型（MLLMs）在处理高分辨率文档与低分辨率缩略图时，常因固定分块尺寸导致细节丢失或全局上下文断裂，现有“任意分辨率”架构在极端像素区间性能显著波动。本文指出固定 Patch Size 是造成这种分辨率-密度失配的核心原因，而非模型容量不足。通过引入基于信息密度的自适应分块策略及免训练权重转换机制，该方法在不改变骨干网络的前提下实现了跨分辨率的稳定性能。这一修正提升了原生分辨率处理的鲁棒性，但其在长序列视频流中的计算开销与线性注意力架构的兼容性尚存疑。

## 研究背景

当 MLLM 接收一张包含密集文本的 4K 文档图像时，若沿用固定 14 像素的分块策略，视觉编码器将生成数万枚 Token，导致注意力计算复杂度呈二次方爆炸；反之，若处理一张低分辨率缩略图，同样的分块尺寸又过于粗糙，无法捕捉细微特征。这种“一刀切”的分块机制构成了原生分辨率处理的核心矛盾：分块尺寸 $s$ 决定了视觉 Token 的数量 $n$ 与感受野粒度，而真实图像的信息密度 $\rho$ 与原生分辨率 $r$ 是动态变化的。

早期 MLLM 如 LLaVA 采用固定分辨率或固定尺寸分块，虽简化了预处理，但牺牲了细节保留能力。NaViT 提出的原生分辨率范式通过序列打包（Sequence Packing）保留了图像原始尺寸，Qwen2.5-VL 等最新模型均声称支持任意输入分辨率。然而，本文通过系统性实验发现，这些模型在低像素预算下因重采样损失细节，在高像素预算下因固定小分块无法捕获全局结构，性能均出现显著退化。这表明“任意分辨率”的声明并未真正实现鲁棒性，固定分块尺寸导致的表示粒度失配是当前架构的主要瓶颈。

## 核心方法

### 方法参照系

本文基于 NaViT 范式的原生分辨率 MLLM 架构，其标准流程为：图像预处理至目标分辨率 $\tilde{r}$，经固定步长 $s$ 的卷积层嵌入为 Token 序列，再经视觉编码器、投影层与 LLM 生成响应。本文的关键差异在于将静态的 $s$ 替换为动态变量，并引入信息密度估计作为决策依据，从而打破分块尺寸与输入分辨率之间的刚性绑定。

### 信息密度感知的分块尺寸估计

固定分块失效的根源在于其无法区分“高分辨率低密度”与“低分辨率高密度”图像。本文通过比较原生图像与降采样图像在视觉编码器第 0 层的特征差异，量化信息密度 $\rho$。$\rho$ 越大，表明降采样损失越多，图像细节越丰富。基于此，本文提出幂律关系模型，将分辨率 $r$ 与密度 $\rho$ 映射为最优分块尺寸 $s^*$：

$$ s^* = \text{Quantize}\left( \text{clip}\left( s \cdot \left( \frac{\kappa(r)}{r_0} \right)^\alpha \cdot \left( \frac{\rho}{\rho_0} \right)^\beta, s_{\min}, s_{\max} \right) \right) $$

该公式的物理含义是：高分辨率倾向于使用更大分块以维持全局上下文，而高信息密度倾向于使用更小分块以保留细节。通过超参数 $\alpha, \beta$ 调节两者敏感度，实现了单图像粒度的自适应选择，解决了固定分块在极端分辨率下的表示失配问题。

### 固定分块到任意分块的权重转换

动态分块要求视觉编码器的 Patch Embedding 层支持多种输入尺寸，而预训练模型仅针对单一尺寸 $s$ 优化。本文提出伪逆缩放（PI-resize）实现免训练转换，通过最小化不同尺寸下 Token 嵌入的一致性误差，求解新的卷积核权重 $\omega_{\theta_i}$：

$$ \omega_{\theta_i} = B_i (B_i^\top B_i)^{-1} \omega_\theta $$

其中 $B_i$ 为插值矩阵。该设计动机在于避免重新训练高昂的骨干网络，利用线性代数性质在推理时即时生成任意尺寸的分块嵌入。对于上采样，内积精确保持；对于下采样，伪逆提供最优近似。这一机制使得预训练 MLLM 无需额外数据或算力即可扩展为支持 $s \in [6, 56]$ 的自适应模型，保持了与序列打包的兼容性。

## 实验评估

实验在 MME、DocVQA、ChartQA 等 16 个基准上评估了 Qwen2.5-VL、SAIL-VL 等四个 SOTA 原生分辨率模型。基线覆盖充分，对比了固定分块（$s=14$）与直接图像缩放，但缺失与 InfiniteVL 等线性注意力架构的直接对比，无法评估 AdaPatch 在长序列内存约束下的表现。

| 模型 | 基准 | 固定分块 (s=14) | AdaPatch | 提升幅度 |
| :--- | :--- | :--- | :--- | :--- |
| Qwen2.5-VL-3B | MME | 2135.90 | 2210.41 | +74.51 |
| Qwen2.5-VL-3B | DocVQA | 92.31 | 92.62 | +0.31 |
| Qwen2.5-VL-3B | OCRBench | 821.00 | 845.00 | +24.00 |
| SAIL-VL-2B | MME | 2026.27 | 2103.96 | +77.69 |

数据显示，AdaPatch 在异构分辨率基准（如 MME、OCRBench）上提升显著，而在单一分辨率基准（如 DocVQA）上提升微弱，验证了方法对分辨率多样性的敏感性。消融实验表明，PI-resize 优于双线性插值，且 $\alpha$ 对性能影响大于 $\beta$，默认值 (0.5, 0.3) 为最优平衡点。

评估边界方面，论文未报告 AdaPatch 引入的信息密度估计带来的额外推理延迟，仅定性提及高分辨率下因 Token 减少而加速。代码未开源，但提供了详细超参数（AdamW, lr=1e-5），可复现性依赖骨干模型开源状态。

## 关联研究分析

从问题动机看，本文与 FastV 等 Token 剪枝方法同属“视觉 Token 压缩”路线，但切入点截然不同。FastV 在推理阶段基于交叉注意力分数动态丢弃冗余 Token，属于后处理优化；而 AdaPatch 在预处理阶段通过调整分块尺寸直接改变 Token 生成数量，属于源头控制。这种差异源于任务特性：FastV 针对长序列内存爆炸，而 AdaPatch 针对分辨率-密度失配。若将 AdaPatch 与 FastV 结合，可能在高分辨率长视频场景中实现双重优化，但论文未探索此组合，查询侧增强在数据充足时是否仍有增益，论文未给出回答。

从方法设计看，本文与 InfiniteVL 的线性注意力架构形成互补。InfiniteVL 通过 Gated DeltaNet 解决长序列二次复杂度问题，但假设输入 Token 序列是固定的；AdaPatch 则优化了输入序列的生成质量与数量。两者在“高效 VLM”目标上正交，但存在潜在冲突：线性注意力对序列长度的敏感度低于标准 Transformer，AdaPatch 减少 Token 带来的计算收益在 InfiniteVL 中可能边际递减。这种架构间的耦合效应是本文未触及的盲区，固定分块假设在状态空间模型中是否同样导致性能瓶颈，值得进一步验证。

## 总结

本文核心矛盾在于固定分块尺寸无法适应动态变化的图像分辨率与信息密度，导致原生分辨率 MLLM 在极端像素区间性能失稳。本文抓住“分块粒度与输入特性失配”这一被忽略的架构缺陷，通过信息密度感知的幂律映射与伪逆权重转换，实现了免训练的自适应分块。实验证明该方法在 MME 等异构基准上带来 74.51 分提升，且在高分辨率下减少 Token 数以加速推理。其边界在于未量化信息密度估计的延迟开销，且缺乏与线性注意力架构的兼容性验证。当输入序列长度超过 100K 时，AdaPatch 减少的 Token 数能否抵消线性注意力中状态更新的计算成本，论文未给出回答。
