# ICLR2026最新论文 ｜MULTIMODAL ALIGNED SEMANTIC KNOWLEDGE FOR - UNPAIRED IMAGE TEXT MATCHING ｜多模态对齐语义知识

研究机构：山东大学、新加坡南洋理工大学

作者：Laiguo Yin、Yixin Zhang、YUQING SUN 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_58021323)

> 无配对图文匹配旨在解决缺乏大规模标注数据时，如何利用通用语义知识实现跨模态对齐的问题。现有知识驱动方法受限于词汇表覆盖度不足、区域表示方差大及语义关系缺失，导致在分布外（OOD）词匹配上失效。本文提出 MASK，通过预训练词向量构建视觉原型与词嵌入的等变映射，并引入原型一致性对比损失抑制方差。该方法在无配对设定下显著优于前驱 MACK，但其性能绝对值远低于配对数据训练的主流模型，且依赖特定知识集构建，泛化边界尚待检验。

## 研究背景

跨模态匹配的核心挑战在于图像与文本异构表示间的语义鸿沟。传统模型依赖大规模配对数据训练双塔编码器，但在实际场景中，获取特定领域的配对数据往往成本高昂甚至不可行。无配对图文匹配范式假设训练阶段无法获取领域特定的配对数据，转而利用通用的多模态对齐知识作为桥梁，关联视觉区域与语言词汇。这一范式的关键在于构建“多模态对齐概念知识”，即建立原型区域表示与词汇之间的一一对应关系，使得模型能够通过查询词汇在知识集中检索对应的视觉原型，进而计算图像与文本的相似度。

主流的知识驱动匹配方法，如 MACK（Huang et al., 2022），虽然实现了基础的概念对齐，但存在三个显著瓶颈：首先，其知识集仅覆盖训练数据中出现的词汇，无法处理分布外（OOD）词汇，导致模型泛化能力受限；其次，同一词汇对应的不同区域表示存在巨大的外观方差，偏离分布均值的实例容易被误分类；最后，原始区域表示主要受区域共现关系影响，未能捕捉词汇间的深层语义相似性（例如“人”与“绅士”的语义关联高于“人”与“帽子”）。本文切入点在于利用预训练词向量的内在语义结构，将已知词汇的视觉原型迁移至 OOD 词汇，并通过结构化正则化消除方差干扰，从而构建更鲁棒的多模态对齐语义知识。

## 核心方法

### 方法参照系

本文问题属于无配对图文匹配，与标准配对数据训练的双塔检索流程的关键差异在于：训练阶段不使用领域特定的图文对，而是利用公开数据集（如 Visual Genome）构建通用的“词-区域原型”知识集。该知识集作为中介，将测试时的图像区域映射到词嵌入空间，或将文本词汇映射到视觉原型空间，从而实现跨模态匹配。

### 基于词向量的 OOD 原型构建

针对 MACK 无法处理 OOD 词汇的问题，本文引入预训练词向量作为语义桥梁。设计动机是利用词嵌入空间中语义相近词汇的局部线性特性，通过已知词汇的原型加权重构 OOD 词汇的视觉原型。对于 OOD 词汇 $w_{out}$，首先计算其与知识集中所有词汇 $w_q$ 的余弦相似度 $s_q$，选取 Top-$m$ 最相似的词汇作为基向量。随后，利用这些基向量的原型表示 $v_q$ 及其相似度分数 $s_q$ 进行加权聚合，得到 OOD 词汇的视觉原型 $v_{out}$：

$$ v_{out} = \sum_{q=1}^{m} \frac{\exp(s_q / \tau)}{\sum_{j=1}^{m} \exp(s_j / \tau)} v_q $$

该公式表明，OOD 词汇的视觉原型由其语义邻居的原型按相似度加权生成，使得模型能够利用已知词汇的视觉信息推断未知词汇的视觉特征，解决了词汇表覆盖度不足导致的匹配失效。

### 原型一致性对比学习

为抑制同一词汇下不同区域表示的方差干扰，本文引入原型一致性对比损失 $L_{cl}$。设计动机是传统实例级对比学习缺乏全局语义锚点，导致类内紧凑性不足。本文以原型 $v_k$ 作为类中心，最大化区域表示 $\mu$ 与其对应原型的相似度，同时最小化与其他原型的相似度：

$$ L_{cl} = -\log \frac{\exp(\text{sim}(\mu, v_k) / \tau)}{\sum_{j \neq k} \exp(\text{sim}(\mu, v_j) / \tau)} $$

该损失函数强制同一词汇的区域表示紧密聚集在其原型周围，同时推开不同词汇的原型，从而在特征空间中构建清晰的语义边界，有效缓解了因外观方差导致的误分类问题。

## 实验评估

实验在 Flickr30K 和 MSCOCO 数据集上进行，评估无配对图文匹配性能。基线包括模型基方法（CHAN, BOOM 等）和知识基方法（MACK, MACK-VG-M）。本文方法 MASK 在两个数据集上均显著优于知识基前驱 MACK。

| 方法 | Flickr30K R@1 | Flickr30K Rs | MSCOCO R@1 | MSCOCO Rs |
| :--- | :--- | :--- | :--- | :--- |
| MACK | 2.5 | 72.7 | 5.2 | 148.5 |
| MASK | 4.8 | 122.8 | 7.6 | 209.5 |

在 Flickr30K 上，MASK 的 R@1 从 MACK 的 2.5% 提升至 4.8%，Rs 从 72.7 提升至 122.8；在 MSCOCO 上，R@1 从 5.2% 提升至 7.6%，Rs 从 148.5 提升至 209.5。这表明语义桥接与方差正则化在无配对设定下具有显著增益。

消融实验显示，移除 OOD 词支持后，Flickr30K Rs 从 122.8 降至 116.2，MSCOCO Rs 从 209.5 降至 193.1，证实了 OOD 原型构建的重要性。移除原型一致性对比损失 $L_{cl}$ 后，Flickr30K Rs 降至 92.4，MSCOCO Rs 降至 123.5，降幅最大，说明方差抑制对匹配精度的贡献最为关键。移除跨模态对齐损失 $L_{cm}$ 后，性能亦有明显下降，表明词向量语义结构的引入不可或缺。

评估边界方面，本文仅使用 R@1/5/10 和 Rs 指标，未报告置信区间。实验仅覆盖 Flickr30K 和 MSCOCO 两个自然图像数据集，未验证在遥感、医学等专业领域的泛化能力。代码已开源，但知识集构建依赖 Visual Genome，其词汇覆盖度可能限制在长尾词汇上的表现。

## 关联研究分析

从问题动机看，本文与 MACK 同属无配对匹配路线，但 MACK 仅处理已知词汇，而本文通过词向量语义结构扩展至 OOD 词汇。这一差异源于 MACK 假设知识集可覆盖所有测试词汇，而本文承认词汇表的有限性，并利用预训练词向量的通用语义先验弥补这一缺口。相比之下，CLIP 等配对数据训练模型依赖大规模图文对，在无配对设定下无法直接应用，本文则提供了一种无需领域特定标注的替代方案。

从方法设计看，本文与 SCAN 等细粒度交互方法在区域-词对齐上思路一致，但机制不同。SCAN 依赖注意力机制在配对数据上学习对齐，而本文通过原型聚合和对比学习在无配对数据上构建对齐。本文未采用 Transformer 双塔结构，而是使用 Faster-RCNN 提取区域，PAE 和 MTM 模型进行映射，这种轻量级设计可能限制了其在复杂场景下的表达能力，但降低了计算开销。与 CLIP 的重排实验表明，MASK 可作为互补模块提升预训练模型的性能，但其独立性能远低于 CLIP，说明知识驱动方法在数据充足场景下仍具局限性。

## 总结

本文核心矛盾在于无配对数据下如何克服词汇覆盖度不足与区域方差干扰。切入点在于利用预训练词向量的语义结构构建 OOD 原型，并通过原型一致性对比学习抑制方差。方法上，MASK 通过词向量加权聚合生成 OOD 原型，并引入 $L_{cl}$ 和 $L_{cm}$ 优化特征空间。实验证明，MASK 在 Flickr30K 和 MSCOCO 上显著优于 MACK，Rs 分别提升 50.1 和 61.0。边界在于，其绝对性能（R@1 4.8%）远低于配对数据训练的 SOTA 模型（如 ABE-CLIP 81.9%），且依赖 Visual Genome 构建的知识集，词汇覆盖度受限。当知识集词汇量进一步增加时，OOD 原型构建的边际收益是否递减，论文未给出回答。
