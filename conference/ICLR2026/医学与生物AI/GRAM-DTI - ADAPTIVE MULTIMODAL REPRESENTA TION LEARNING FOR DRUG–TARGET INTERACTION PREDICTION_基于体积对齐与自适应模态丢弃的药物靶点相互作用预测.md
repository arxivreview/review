# ICLR2026最新论文 ｜GRAM-DTI: ADAPTIVE MULTIMODAL REPRESENTA TION LEARNING FOR DRUG–TARGET INTERACTION PREDICTION ｜基于体积对齐与自适应模态丢弃的药物靶点相互作用预测

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_504363)

> 药物靶点相互作用（DTI）预测旨在通过计算手段解析分子结合机制，以缓解实验筛选的高昂成本。现有方法多依赖SMILES与蛋白序列的双模态输入，忽略了分子文本、层级分类等丰富信息，且在模态质量不均时易受主导模态干扰。本文提出GRAM-DTI，通过扩展体积损失实现四模态高阶对齐，并引入基于梯度的自适应模态丢弃机制。该方法在冷启动场景下显著优于基线，但其评估数据集与主流基准不重叠，泛化能力的普适性仍存疑。

## 研究背景

DTI预测面临的核心困境在于数据稀疏与模态异质性。当模型仅依赖SMILES序列时，无法捕捉分子的功能语义；而引入文本或层级分类注释后，不同模态的信息量与质量差异巨大，静态融合策略往往导致低信息量模态被高信息量模态掩盖。这种模态间的非对称性使得传统成对对比学习失效，因为成对损失无法捕捉三模态或四模态之间的高阶语义依赖关系。

主流DTI预测路线已从早期的序列基模型（如DeepDTA）演进至图神经网络（GNN）与多模态融合范式。然而，现有工作如DTIAM采用独立预训练后融合的策略，未能解决模态贡献动态变化的问题；TRIDENT等框架虽引入多模态对齐，但局限于三模态且缺乏对模态信息量差异的自适应调节。本文切入点在于将体积损失（Volume Loss）从音视频领域迁移至分子-蛋白交互场景，并首次提出基于梯度贡献的自适应模态丢弃机制，以解决高阶模态对齐中的冗余与噪声问题。

## 核心方法

### 方法参照系

本文问题属于多模态表征学习范畴，标准流程为使用预训练编码器提取各模态特征，通过投影层映射至共享空间，再执行对比学习对齐。本文的关键差异在于：将成对对比损失替换为基于Gram矩阵行列式的体积损失，并引入动态模态选择机制，以处理四模态输入下的几何对齐与模态重要性波动。

### 体积基多模态对齐

传统成对对比学习在处理超过两个模态时，无法捕捉模态间的高阶交互依赖。本文采用Gramian体积损失，通过计算四个归一化嵌入向量张成的四维空间体积来衡量语义对齐程度。体积越小，表明模态在共享空间中占据的子空间越紧凑，语义一致性越强。

$$
V(f_i^s, f_i^t, f_i^h, f_i^p) = \sqrt{\det(G)}
$$

其中 $G$ 为Gram矩阵，其元素为各模态嵌入的内积。该公式的物理含义是：通过最小化正样本四模态嵌入的体积，最大化负样本（通过置换锚点模态构造）的体积，迫使模型学习一个所有模态均紧密对齐的紧凑子空间，而非仅满足两两相似。

### 梯度感知自适应模态丢弃

静态融合假设所有模态同等重要，但在实际训练中，某些模态（如噪声较大的文本描述）可能贡献微弱或产生误导。本文提出基于梯度贡献的自适应丢弃策略，动态调节各模态在体积损失计算中的参与度。

$$
\bar{g}_{\tilde{t}}^m = \sum_{k=0}^{K-1} \alpha^k g_{\tilde{t}-k}^m
$$

该公式通过指数加权平均计算模态 $m$ 在过去 $K$ 步的梯度贡献平滑值。若某模态的梯度贡献显著高于均值（主导性）或显著低于均值（低贡献），则按概率 $p_{drop}$ 将其从当前批次的体积损失计算中剔除。这一设计解决了主导模态掩盖互补信号的问题，确保模型在训练过程中持续利用所有模态的有效信息，避免过拟合于单一数据源。

## 实验评估

实验在Yamanishi 08、Hetionet、Activation和Inhibition四个数据集上进行，基线包括CPL-GNN、TransformerCPI、DTIAM等。值得注意的是，本文未与知识库中提及的HiF-DTA、MolBridge等最新SOTA方法对比，且评估数据集与Davis、KIBA等主流基准无重叠，限制了跨论文的直接数值比较。

| 数据集 | 场景 | 指标 | DTIAM | GRAM-DTI |
| :--- | :--- | :--- | :--- | :--- |
| Yamanishi 08 | Target Cold Start | AUROC | 0.941±0.0180 | **0.955±0.0155** |
| Hetionet | Warm Start | AUROC | 0.957±0.0015 | **0.981±0.0011** |
| Activation | Target Cold Start | AUPR | 0.844±0.0350 | **0.849±0.0312** |
| Inhibition | Target Cold Start | AUROC | 0.917±0.0090 | **0.921±0.0079** |

在冷启动场景下，GRAM-DTI表现尤为突出，尤其在Yamanishi 08的Target Cold Start AUROC上达到0.955，较DTIAM提升0.014。消融实验表明，移除体积损失或自适应丢弃机制均导致性能下降，验证了高阶对齐与动态模态选择的必要性。

评估边界方面，本文采用1:10负采样比例，与DTIAM框架保持一致，但未报告计算效率与模型参数量。代码已开源，但预训练数据构建细节（如IC50离散化阈值）仅在附录中简要提及，复现时需仔细核对超参数设置。

## 关联研究分析

从方法设计看，GRAM-DTI与TRIDENT同属多模态对齐路线，但TRIDENT局限于三模态且采用静态融合，而本文通过体积损失实现四模态几何对齐，并引入梯度感知丢弃机制。这一差异源于任务特性：DTI预测中蛋白序列与分子结构的信息量差异远大于分子内部模态差异，静态融合易导致蛋白序列主导，而自适应丢弃能有效平衡这种非对称性。

从问题动机看，与DTIAM的独立预训练后融合策略相比，GRAM-DTI强调端到端的多模态联合对齐。DTIAM假设模态间可独立学习后简单拼接，而本文假设模态间存在高阶语义依赖，需通过体积损失显式建模。这一假设在冷启动场景下得到验证，但在数据充足的大规模数据集（如Hetionet Warm Start）上，两者差距缩小，暗示高阶对齐的收益可能随数据量增加而递减。

## 总结

GRAM-DTI旨在解决多模态DTI预测中模态信息量不均与高阶依赖缺失的矛盾。通过扩展体积损失至四模态并引入梯度感知自适应丢弃，该方法在冷启动场景下实现了显著性能提升，Yamanishi 08 Target Cold Start AUROC达0.955。然而，其评估数据集与主流基准不重叠，且未与最新SOTA方法对比，泛化能力的普适性尚未得到充分验证。当预训练数据规模进一步扩大时，体积损失的计算复杂度与自适应丢弃机制的稳定性是否仍能保持优势，论文未给出回答。
