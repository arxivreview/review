# ICLR2026最新论文 ｜STRUCTURED IN CONTEXT ENVIRONMENT SCALING FOR LARGE LANGUAGE MODEL REASONING ｜结构化上下文环境

研究机构：上海交通大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_59675890)

> 大语言模型（LLM）在复杂推理任务中依赖强化学习（RL）进行后训练，但现有训练环境往往受限于专家标注成本或领域特异性，难以兼顾可扩展性与泛化能力。本文指出环境内在属性决定了模型可习得的推理策略，切入点在于利用大规模结构化数据自动构建兼具可验证性、可扩展性与泛化性的推理环境。具体做法是从知识图谱中提取局部子图作为上下文软约束，通过控制信息保留率构建不同难度的部分环境，并利用规则奖励进行RL微调。该框架在结构化推理任务上显著提升了模型性能，并展示了向数学与逻辑域迁移的潜力，但其泛化增益的绝对幅度与通用数学基准的SOTA存在明显差距。

## 研究背景

当LLM面对多跳逻辑推导时，其自回归生成机制常陷入局部最优，无法处理需要回溯或并行探索的问题。这一局限促使研究从静态提示工程转向基于环境反馈的动态策略优化，其中基于可验证奖励的强化学习（Reinforcement Learning with Verifiable Rewards, RLVR）成为核心范式。RLVR依赖明确的外部奖励信号来塑造策略，其有效性直接受限于训练环境的构建质量与覆盖范围。

当前RLVR训练环境存在两类主要瓶颈：内部规则环境（如数学题）依赖昂贵的人工标注，限制了数据规模扩展；外部规则环境（如游戏引擎）虽具备显式规则，但习得的技能高度特化，难以迁移至通用推理任务。这种“可扩展性”与“泛化性”的矛盾阻碍了RL后训练在更广泛领域的部署。本文的切入点在于发现结构化数据（如知识图谱）天然具备显式模式与约束，既能通过自动化管道低成本构建大规模环境，又能通过多跳路径提供可泛化的组合推理脚手架。

## 核心方法

### 方法参照系

本文问题归属于RLVR训练环境构建范畴，与标准流程的关键差异在于：传统方法将环境视为独立于模型的外部交互系统，而SIE将环境动态编码为LLM提示词中的结构化上下文（In-context），使模型在文本空间内完成隐式探索，无需修改模型架构或引入复杂的环境交互接口。

### 自动化环境构建管道

设计动机是解决传统环境构建中人工标注成本高且干扰项设计缺乏语义相关性的问题。SIE通过四步管道从知识图谱（KG）中自动提取环境：首先，采用双向多跳检索策略，从问题实体集 $E_Q$ 和答案实体集 $E_A$ 同时出发，约束总跳数 $n_{hop}$，以指数级降低种子子图 $G_{seed}$ 的规模；其次，利用Dijkstra算法在 $G_{seed}$ 中提取连接 $E_Q$ 与 $E_A$ 的最短路径，形成支持子图 $G_{support}$；再次，通过两阶段语义过滤（关系过滤与三元组过滤）从剩余三元组中筛选出与问题语义相关的干扰子图 $G_{distract}$，以平衡环境复杂度与上下文长度限制；最后，通过随机保留 $G_{support}$ 中不同比例（100%, 75%, 50%, 25%, 0%）的三元组并混合 $G_{distract}$，构建出系列部分SIE。该过程实现了从原始KG到可控难度推理环境的自动化映射，其中部分SIE的构建公式为：

$$ SIE_{ratio} = \text{Shuffle}(\text{Retain}(G_{support}, ratio) \cup G_{distract}) $$

此公式表明环境难度由支持信息的保留率 $ratio$ 直接控制，而干扰项的存在确保了即使支持信息缺失，模型仍需进行区分与推理。

### 基于GRPO的RL后训练

设计动机是验证结构化上下文能否作为有效的RL训练信号，并量化信息约束对推理范式的影响。SIE将环境作为软约束嵌入提示词，LLM的探索过程被建模为隐式马尔可夫决策过程（MDP），其中状态为当前探索的子图，动作为选择实体，奖励由外部验证器给出。采用组相对策略优化（Group Relative Policy Optimization, GRPO）算法进行微调，其目标函数为：

$$ \mathcal{L}(\theta) = \mathbb{E}_{x \sim \mathcal{D}, y_i \sim \pi_{\theta_{old}}} \left[ \frac{1}{G} \sum_{i=1}^G \left( \min\left( \frac{\pi_\theta(y_i|x)}{\pi_{\theta_{old}}(y_i|x)} A_i, \text{clip}\left( \frac{\pi_\theta(y_i|x)}{\pi_{\theta_{old}}(y_i|x)}, 1-\epsilon, 1+\epsilon \right) A_i \right) - \beta D_{KL}[\pi_\theta \| \pi_{ref}] \right) \right] $$

其中 $A_i$ 为组内归一化优势，由答案奖励（精确匹配得1.0，否则0.0）与格式奖励共同决定。该设计避免了独立Critic模型的开销，并使模型在结构化上下文中通过试错学习组合推理策略，而非单纯模仿静态数据。

## 实验评估

实验在WebQSP、CWQ、GrailQA等结构化推理基准及GSM8K、MATH500等通用数学基准上进行，基线覆盖CoT提示、SFT（结构化推理数据）及无上下文RL。主结果显示，RL w/ SIE在结构化推理任务上显著优于其他方法，例如Qwen2.5-7B-Instruct在WebQSP上从CoT的26.3%提升至93.4%，在GrailQA上从40.5%提升至85.8%。

| 数据集 | CoT | SFT w/ SRD | RL w/ SIE |
| :--- | :--- | :--- | :--- |
| WebQSP (Qwen2.5-7B-Instruct) | 26.3 | 40.5 | 93.4 |
| CWQ (Qwen2.5-7B-Instruct) | 34.4 | 43.3 | 87.7 |
| GrailQA (Qwen2.5-7B-Instruct) | 40.5 | 55.7 | 85.8 |
| GSM8K (Qwen2.5-7B-Instruct) | 29.2 | - | 87.4 |
| MATH500 (Qwen2.5-7B-Instruct) | 43.0 | - | 61.6 |

消融实验揭示了奖励机制的关键作用：仅使用格式奖励（Format Only）时，Qwen模型在WebQSP上仅达31.6%，而引入随机噪声（Random + Format）后性能崩溃至6.3%，证明模型并非利用格式偏差或随机信号，而是真正习得了基于可验证反馈的组合推理。部分SIE分析显示，即使支持信息完全移除（SIE-0%），模型在WebQSP上仍达72.8%，表明信息约束促使模型从浅层检索转向深层组合推理，利用参数化知识填补环境缺口。

评估边界方面，论文未报告置信区间，且通用数学基准（GSM8K 87.4%, MATH500 61.6%）远低于领域SOTA（如DeepSeek-R1的96.7%和79.8%），暗示泛化增益主要源于结构化推理能力的迁移，而非通用数学能力的突破。代码已开源，但超参数细节（如GRPO的 $\epsilon$ 和 $\beta$ 值）未在正文中明确列出，可能影响复现精度。

## 关联研究分析

从问题动机看，SIE与ZPD-Guided Synthesis均通过动态调整难度优化学习过程，但ZPD侧重数据合成的课程化，而SIE将难度控制内嵌于环境上下文的信息保留率中。这一差异源于任务特性：结构化数据的多跳路径天然具备层级性，使得通过保留率控制难度比重新合成数据更高效。然而，SIE未探讨当结构化数据本身存在噪声或缺失时，部分SIE的难度控制是否仍有效，这在开放域知识图谱中可能成为瓶颈。

从方法设计看，SIE与ToT在SIE-0%场景下的行为相似，均要求模型在信息不足时进行内部探索，但ToT依赖显式树状搜索与人工评估函数，而SIE通过RL隐式学习探索策略。这一差异表明SIE将搜索策略从外部模板转化为内部参数，提升了泛化潜力，但牺牲了搜索过程的可解释性。与RLAD等关注奖励信号设计的RL方法相比，SIE的创新在于奖励信号的来源——它不依赖人工标注的中间步骤，而是利用结构化数据的显式约束自动生成可验证奖励，这在数据稀缺场景中更具优势，但可能限制了模型在缺乏显式结构约束的开放域任务中的应用。

## 总结

本文核心矛盾在于RLVR训练环境的可扩展性与泛化性难以兼得，切入点在于利用结构化数据的显式模式与约束，通过自动化管道构建可验证的推理环境。SIE框架通过从知识图谱提取局部子图作为上下文软约束，并控制信息保留率构建部分环境，实现了环境构建的自动化与难度可控。实验证明RL w/ SIE在结构化推理任务上较CoT提升超过40%，并在GSM8K上达到87.4%，展示了向通用推理域迁移的能力。然而，其在MATH500上仅61.6%的成绩，远低于领域SOTA，暴露了结构化推理能力向复杂数学推理迁移的局限性。当结构化数据的多跳路径无法覆盖复杂数学问题的逻辑结构时，SIE习得的组合推理策略是否仍能保持泛化优势，论文未给出回答。
