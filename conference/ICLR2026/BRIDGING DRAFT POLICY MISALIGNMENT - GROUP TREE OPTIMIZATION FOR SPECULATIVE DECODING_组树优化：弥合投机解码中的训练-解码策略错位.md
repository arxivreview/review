# ICLR2026最新论文 ｜BRIDGING DRAFT POLICY MISALIGNMENT: GROUP TREE OPTIMIZATION FOR SPECULATIVE DECODING ｜组树优化：弥合投机解码中的训练-解码策略错位

研究机构：复旦大学、新加坡国立大学

作者：Shijing Hu、Jingyang Li、Zhihui Lu 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_95438610)

> 投机解码旨在通过轻量草稿模型并行生成候选序列，再由目标模型验证以加速大语言模型推理，但现有训练目标仅优化单一路径的贪心预测，与解码时采用的多分支树状重排策略存在根本性错位。这种错位导致训练信号在解码阶段被大量浪费，限制了加速比的上限。本文提出组树优化（Group Tree Optimization, GTO），通过直接优化草稿树的期望接受长度作为奖励，并引入基于组对比的去偏训练算法，使训练目标与解码策略严格对齐。该方法在多个基准上显著提升了接受长度与加速比，但其收益是否完全源于算法改进而非训练数据分布差异，仍需更严格的对照实验验证。

## 研究背景

投机解码的核心机制依赖于草稿模型生成的候选序列能被目标模型高效接受。接受长度 $\tau$ 是衡量这一过程效率的关键指标，它直接决定了每个验证周期内有效生成的 Token 数量。然而，草稿模型在训练时通常被优化为预测与目标模型一致的下一个 Token，这本质上是一个单路径序列预测问题。当解码阶段引入树状验证策略，即同时生成多个候选分支并进行全局重排时，训练时优化的“局部最优”贪心路径往往在解码的全局竞争中落选，导致训练目标与实际解码行为脱节。

早期研究如 EAGLE 系列通过特征对齐提升了草稿模型的质量，HASS 和 GRIFFIN 进一步解决了特征与 Token 级别的不一致问题，但这些方法均假设草稿策略是固定的单路径贪心生成。这种假设忽略了树状解码中分支间的竞争机制：即使贪心路径在局部概率最高，其累积置信度可能低于其他分支，从而在重排阶段被剪枝。本文指出，这种“草稿策略错位”是现有方法加速比停滞的结构性瓶颈，亟需一种直接针对树状解码策略的训练范式。

## 核心方法

### 方法参照系

现有特征对齐类草稿模型（如 EAGLE-3）的标准训练流程是：利用目标模型隐藏状态作为输入，通过回归或交叉熵损失优化 Token 级似然。该流程的关键差异在于，其优化目标是单路径的局部准确性，而解码阶段实际执行的是多分支的全局选择，两者在策略空间上并不等价。

### 草稿树奖励函数

传统方法优化 Token 级似然，忽略了树状解码中分支竞争对最终接受长度的影响。GTO 引入草稿树奖励函数，直接以解码时的期望接受长度作为优化目标。该奖励定义为草稿树中所有候选序列期望接受长度的平滑最大值（Log-Sum-Exp）：

$$ R(\mathbf{T}_t) = \eta \log \sum_{i=1}^{N} \exp\left(\frac{\mathbf{L}_{t,i}}{\eta}\right) $$

其中 $\mathbf{L}_{t,i}$ 是序列 $\mathbf{S}_{t,i}$ 在目标模型下的期望接受长度，$\eta$ 为温度系数。这一设计将优化目标从“预测下一个 Token 正确”转变为“生成能存活验证并延长接受前缀的草稿树”，直接对齐了训练与解码的效率指标。

### 组对比策略优化

直接优化树级奖励面临奖励稀疏、高方差的问题，尤其在训练初期草稿模型较弱时。GTO 采用两阶段组对比策略：首先使用标准蒸馏训练参考模型 $M_0$，然后在优化阶段采样当前模型 $M$ 与冻结参考模型 $M_0$ 的草稿树组。通过计算组内标准化优势（Advantage），消除位置特定难度带来的偏差：

$$ \hat{A}_t = \frac{R(\mathbf{T}_t^M) - R(\mathbf{T}_t^{M_0})}{\sigma_{\text{group}}} $$

其中 $\sigma_{\text{group}}$ 为组内奖励标准差。该机制利用参考模型作为控制变量，抵消上下文难度差异，使梯度信号聚焦于真正提升接受长度的分支选择，而非过拟合特定上下文。

## 实验评估

实验在 MT-Bench、HumanEval 和 GSM8K 三个基准上，使用 LLaMA-3.1-8B、LLaMA-3.3-70B、Vicuna-1.3-13B、DeepSeek-R1-Distill-LLaMA-8B 和 Qwen3-8B 进行验证。基线覆盖 EAGLE 系列、HASS、GRIFFIN 及 PLD 等主流方法，但缺失无训练类（如 REST）及多模态基线。

| 模型 | 方法 | MT-Bench SR (T=0) | HumanEval SR (T=0) | GSM8K SR (T=0) | Average SR (T=0) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| LLaMA-3.1-8B | EAGLE-3 | 3.34 | 3.59 | 3.78 | 3.57 |
| LLaMA-3.1-8B | **GTO** | **3.49** | **3.98** | **4.20** | **3.89** |
| DeepSeek-R1-8B | EAGLE-3 | 3.11 | 3.49 | 3.71 | 3.43 |
| DeepSeek-R1-8B | **GTO** | **3.27** | **3.71** | **4.20** | **3.73** |

GTO 在 LLaMA-3.1-8B 上的平均加速比（SR）为 3.89，较 EAGLE-3 的 3.57 提升 8.9%；在 DeepSeek-R1-8B 上，GTO 的 GSM8K SR 达到 4.20，显著高于 EAGLE-3 的 3.71。

| 消融项 | 方法 | Average SR (T=0) | Average $\tau$ (T=0) |
| :--- | :--- | :--- | :--- |
| 聚合算子 | GTO (LSE) | 3.73 | 6.52 |
| 聚合算子 | Max | 3.65 | 6.40 |
| 聚合算子 | Sum | 3.55 | 6.24 |
| 组大小 | m=8 (GTO) | 3.73 | 6.52 |
| 组大小 | m=1 | 3.60 | 6.30 |
| 去偏 | GTO (Debiased) | 3.73 | 6.52 |
| 去偏 | w/o Debiasing | 3.55 | 6.21 |

消融实验显示，LSE 聚合算子比 Max 和 Sum 分别高 2.2% 和 5.4% 的 SR，表明平滑最大值在保留强分支信号的同时避免了单路径过拟合。组大小 $m=8$ 表现最佳，$m=1$ 因方差过大导致性能下降，$m=32$ 则因信号稀释而退化。去偏机制带来 5.1% 的 SR 提升，验证了参考模型对比在消除上下文偏差中的关键作用。

评估协议未报告置信区间，且所有实验均在单卡 A100 80GB 上完成（70B 模型除外），限制了高并发场景下的泛化性验证。代码已开源，但训练数据（ShareGPT）与 EAGLE-3 相同，未排除数据分布对结果的潜在影响。

## 关联研究分析

从问题动机看，GTO 与 EAGLE-3 的核心差异在于优化目标的层级。EAGLE-3 通过训练时滚动（Rollout）模拟解码过程，但仍以 Token 级似然为损失函数，本质上是在单路径空间内寻找最优策略。GTO 则直接优化树级期望接受长度，将解码时的全局重排机制内化到训练目标中。这一差异源于任务特性：树状解码的效率不仅取决于单个 Token 的预测准确性，更取决于分支间的相对置信度排序。EAGLE-3 无法捕捉这种排序信息，而 GTO 通过树级奖励直接优化排序结果。

从方法设计看，GTO 与 HASS 在特征对齐范式下形成了互补。HASS 通过和谐化上下文对齐解决长序列中的特征不一致问题，但其训练目标仍是 Token 级似然，未涉及策略错位。GTO 则假设特征对齐已基本解决，转而优化策略层。两者结合（如 HASS+GTO）在实验中显示出叠加收益，表明特征质量与策略对齐是独立且正交的优化维度。然而，GTO 的组对比机制依赖冻结参考模型，这在目标模型频繁更新的场景下可能引入滞后，而 HASS 的在线对齐机制可能更具适应性，这一权衡在论文中未深入探讨。

## 总结

本文针对投机解码中训练目标与解码策略的错位问题，提出组树优化（GTO）框架。现有方法如 EAGLE-3 和 HASS 虽提升了草稿模型质量，但均优化单路径贪心策略，无法适应树状解码中的分支竞争机制。GTO 通过引入草稿树奖励函数，直接优化期望接受长度，并利用组对比去偏算法稳定训练过程，实现了训练与解码策略的严格对齐。实验表明，GTO 在 LLaMA-3.1-8B 上将平均加速比从 3.57 提升至 3.89，接受长度提升 7.4%。然而，论文未提供与 EAGLE-3 在相同训练预算下的严格对照，且所有实验基于 ShareGPT 数据，无法排除数据分布对结果的贡献。当训练数据分布与解码场景存在显著差异时，GTO 的树级奖励是否仍能保持优势，论文未给出回答。
