# ICLR2026最新论文 ｜TIME OPTIMAL EXECUTION OF ACTION CHUNK POLICIES BEYOND DEMONSTRATION SPEED ｜可达性感知加速分块执行

研究机构：韩国首尔大学、韩国科学技术院

作者：Sunwoo Kim、Jeongjun Kim、Joseph Lim

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_26649184)

> 机器人模仿学习策略的执行速度长期受限于遥操作演示的慢速与推理延迟，导致工业场景中的吞吐量瓶颈。现有加速方法仅通过提高动作执行频率或异步推理来压缩时间，却忽略了底层动力学改变导致的物理不可达性与状态漂移，致使高精度任务成功率骤降。RACE 通过预测期望状态替代动作指令、应用时间最优路径参数化（TOPP-RA）重定时以及测试时搜索对齐分块，解决了高速执行下的动力学可行性问题。该方法在仿真与真实世界中实现了超越演示速度的执行，但在非刚性物体操作及极端异步延迟下的泛化能力仍存疑。

## 研究背景

模仿学习（Imitation Learning, IL）策略通常通过预测动作分块（Action Chunking）来稳定时序行为并提升精度，但其执行速度被演示数据的速度上限所锁定。当试图通过简单提高动作执行频率来加速时，底层低层控制器（如 PD 控制器）在更短的时间窗口内施加的力矩不足以使机器人达到预期的关节位置，导致“状态误差”在开环执行中累积。这种误差在涉及精密插入的任务中尤为致命，因为微小的位置偏差会直接导致任务失败。

当前领域的主流加速路线分为两类：一类是减少推理延迟，如扩散策略蒸馏或并行解码，但这仅缩短了等待时间，并未改变动作执行的物理节奏；另一类是异步推理，即在执行当前分块时预测下一分块，但这引入了基于过时状态的动作生成，造成计划与实际状态的错位。这两种方法均未解决核心矛盾：在更短的时间跨度内，机器人是否具备物理能力（扭矩、速度限制）去追踪期望轨迹。RACE 的切入点在于将“执行速度”视为一个受物理约束的最优控制问题，而非单纯的时间压缩问题，通过重新定义模仿目标与执行时序来突破演示速度的上限。

## 核心方法

### 方法参照系

标准 IL 策略预测动作指令 $a$，低层控制器据此生成力矩以追踪目标。本文的关键差异在于将模仿目标从“动作指令”转换为“期望状态”，并引入物理约束下的时间重参数化，使策略输出直接对应机器人应达到的物理位置，从而解耦了执行时序与动力学可行性。

### 期望状态作为动作

传统方法中，动作 $a$ 与期望状态 $s'$ 之间存在由低层控制器决定的映射关系，提高执行频率会改变这一映射，导致状态误差。RACE 直接训练策略模仿演示数据中的“到达状态”（reached states），即状态-下一状态对 $(s, s')$，而非状态-动作对。这使得策略输出的 $s'$ 成为低层控制器的直接目标，通过提高控制器增益（如 PD 增益），机器人可以在更短时间内更准确地追踪 $s'$，从而对执行时序的变化具有鲁棒性。这一设计消除了因执行频率变化导致的动力学失配，为后续的高速执行奠定了状态追踪的基础。

### 可达性感知时间最优规划

即使使用期望状态作为目标，若期望状态在物理上不可达（如超出扭矩限制），执行仍会失败。RACE 对生成的状态分块应用时间最优路径参数化（TOPP-RA）。给定几何路径 $\mathbf{q}(s)$，TOPP-RA 求解时间参数化 $s(t)$ 以最小化总时长 $T$，同时满足广义二阶约束：

$$ \mathbf{A}(\mathbf{q})\ddot{\mathbf{q}} + \mathbf{q}^{\top}\mathbf{B}(\mathbf{q})\dot{\mathbf{q}} + \mathbf{f}(\mathbf{q}) \in C $$

该公式将物理约束投影到路径相空间，通过反向传播计算可控集 $K_i$，确保每一步的速度选择都在物理可行范围内。若初始状态不在可控集 $K_0$ 内，算法回退至原始频率。这一机制确保了加速后的轨迹在动力学上严格可行，避免了因强行加速导致的扭矩超限或轨迹断裂。

### 测试时搜索最大化可控性

异步推理导致新分块的起始状态与机器人实际状态错位，可能使路径曲率激增，超出物理控制能力。RACE 采用 Best-of-N 采样，从策略中采样多个候选分块，选择使路径平滑度最大化的分块。其优化目标为最小化路径曲率积分：

$$ \min_{\mathbf{q}} \int_0^{s_{end}} \|\mathbf{q}''(s)\| ds $$

较小的曲率意味着较小的加速度需求，从而扩大了可控集 $K_0$ 的体积，确保机器人在漂移后的实际状态仍能成功追踪新分块。这一搜索过程将物理可控性显式纳入推理阶段，解决了异步执行下的状态对齐难题。

## 实验评估

实验在 Robomimic 仿真环境（Lift, Can, Square, Tool Hang）和 FurnitureBench 真实世界任务（Door Insertion）上进行。基线包括 Action/State Fast-forward、SAIL 以及 RTC（Inpainting）。在仿真实验中，RACE 在 Square 和 Tool Hang 等高精度任务上实现了 2.02x 的加速比（Speedup over Demonstration, SOD），同时保持成功率（SR）为 0.53，优于 SAIL 的 0.61x SOD 和 0.27 SR。在真实世界 Door Insertion 任务中，RACE 实现了 4x 的原始策略加速，且成功率未下降，验证了其在物理约束下的有效性。

| 任务 | 方法 | Success Rate (SR) | Speedup over Demonstration (SOD) |
| :--- | :--- | :--- | :--- |
| Square (Sim) | RACE | 0.53 | 2.02x |
| Square (Sim) | SAIL | 0.27 | 0.61x |
| Tool Hang (Sim) | RACE | 0.63 | 1.32x |
| Tool Hang (Sim) | SAIL | 0.27 | 0.84x |

消融实验表明，仅使用“状态作为动作”而未结合 TOPP-RA 时，Pareto 曲线改善有限，证明时间最优规划是解决物理不可达性的关键。测试时搜索（TTS）在存在 0.1 秒推理延迟的异步设置下，显著提升了可控性指标，减少了因状态错位导致的 TOPP 求解失败。然而，论文未报告 TTS 的计算开销，Best-of-N 中的 N 值对推理延迟的影响未量化，这可能在实际部署中抵消部分加速收益。

评估边界方面，实验仅涵盖刚性物体操作，未涉及软体或流体动力学场景，其中状态误差的累积机制可能不同。真实世界实验仅使用单一任务（Door Insertion），缺乏多任务泛化验证。代码未公开，超参数（如 PD 增益、TOPP 约束阈值）的敏感性分析缺失，限制了可复现性。

## 关联研究分析

从问题动机看，RACE 与 SAIL（Arachchige et al., 2025）均旨在加速执行，但 SAIL 依赖任务特定的规则调整动作频率，缺乏对物理可达性的显式建模，因此在高精度任务中易因扭矩超限而失败。RACE 通过 TOPP-RA 将物理约束内嵌于执行规划中，实现了任务无关的加速，这源于其对“执行速度”本质的不同理解：SAIL 视其为时间压缩，RACE 视其为受约束的最优控制问题。

从方法设计看，RACE 与 RTC（Black et al., 2025）都处理异步推理下的状态对齐，但 RTC 使用动作填充（Inpainting）来隐式鼓励一致性，未保证物理可行性。RACE 的测试时搜索显式优化路径曲率以最大化可控集，这是一种基于物理属性的对齐机制。差异根源在于 RTC 关注动作序列的语义连贯性，而 RACE 关注动力学可行性，后者在高速执行下更为关键，因为语义连贯的动作若物理上不可达，仍会导致任务失败。

## 总结

RACE 解决了模仿学习策略执行速度受限于演示数据与物理约束的矛盾，通过状态预测、时间最优规划与测试时搜索，实现了在保持精度的前提下突破演示速度上限。实验证明其在仿真与真实世界中分别达到 2x 和 4x 的加速，且成功率未下降。然而，其依赖刚性动力学假设，在非刚性物体操作中，状态误差的累积机制可能失效，且 Best-of-N 搜索的计算开销未量化，可能在实时性要求极高的场景下成为新瓶颈。当操作对象从刚性变为软体时，TOPP-RA 的约束模型是否仍能准确捕捉动力学边界，论文未给出回答。
