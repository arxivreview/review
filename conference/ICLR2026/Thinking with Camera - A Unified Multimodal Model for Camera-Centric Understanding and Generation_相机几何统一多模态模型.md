# ICLR2026最新论文 ｜Thinking with Camera: A Unified Multimodal Model for Camera-Centric Understanding and Generation ｜相机几何统一多模态模型

研究机构：新加坡南洋理工大学、商汤

作者：Kang Liao、Size Wu、Zhonghua Wu 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.08673)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.08673)

> 相机中心理解与生成长期被割裂为独立任务，导致空间智能缺乏闭环反馈。现有大模型难以将抽象的相机参数转化为精确的空间控制信号，而专用几何模型又缺乏语义推理能力。Puffin 提出“以相机思考”范式，将相机几何作为一等模态融入统一多模态框架，通过离散参数 Token 与连续像素级相机图潜变量实现双向对齐。该工作验证了统一架构在单视图几何精度上的优势，但其对透视投影的依赖限制了向全景或动态视频场景的迁移潜力。

## 研究背景

相机几何是机器感知物理世界的核心接口，其本质在于建立三维空间与二维图像平面之间的投影映射关系。理解这一映射（即相机标定）是恢复空间结构的基础，而通过调节内参与外参控制成像视角则是空间内容生成的关键。然而，相机参数以数值形式描述视场角（Field-of-View, FoV）、姿态等抽象属性，缺乏直观的语义内容，这构成了将其整合进大语言模型（Large Language Model, LLM）时的模态间隙。

传统研究将相机理解与生成视为孤立问题：理解侧依赖几何特征提取（如消失线、语义置信度），生成侧则通过条件扩散模型实现可控合成。前者难以捕捉全局空间概念，后者往往忽略精确的空间布局约束，导致生成结果在复杂姿态下出现空间不一致。Puffin 的切入点在于打破这种割裂，将相机几何解释为一种“语言”，通过链式思维（Chain-of-Thought）机制对齐视觉线索与摄影术语，从而在统一框架内实现空间一致的理解与可控生成。

## 核心方法

### 统一多模态架构参照系

Puffin 基于视觉编码器、LLM 与扩散模型构建统一架构。其关键差异在于不将相机参数视为辅助标签，而是引入离散相机 Token 与连续相机图潜变量（Camera Map Latent），使几何信息成为模型推理的一等公民。

### 相机作为语言的推理机制

传统方法直接回归相机参数，忽略了参数与视觉线索间的语义关联。Puffin 引入“以相机思考”机制，引导模型在预测参数前，先通过自然语言描述对齐空间线索与摄影术语。该过程可形式化为：

$$ \hat{c} = \text{LLM}(I, T_{\text{think}}) $$

其中 $I$ 为输入图像，$T_{\text{think}}$ 为包含几何上下文的推理文本，$\hat{c}$ 为预测的相机参数。这一设计解决了专用模型在缺乏丰富几何特征场景下的泛化失效问题，通过语义推理弥补了低层特征的不足。

### 离散-连续几何条件融合

生成任务中，仅依赖离散参数 Token 难以实现像素级精确控制。Puffin 引入像素级相机图（如透视场 Perspective Field），经 VAE 编码后作为连续潜变量 $z_{\text{cam}}$ 注入扩散模型：

$$ \epsilon_\theta(x_t, t, z_{\text{cam}}, h_{\text{LLM}}) $$

其中 $h_{\text{LLM}}$ 为 LLM 隐藏状态经连接器映射的条件信号。该融合机制解决了纯文本条件在复杂姿态控制上的精度瓶颈，使生成图像在重力方向与视场角上严格遵循目标参数。

## 实验评估

实验在 MegaDepth、TartanAir、LaMAR 及自建 Puffin-Und 数据集上评估理解性能，在 Puffin-Gen 上评估生成性能。基线覆盖 DeepCalib、GeoCalib 等专用标定方法及 GPT-4o、PreciseCam 等生成模型，但未包含全景视频生成基线，因任务模态不同。

| 方法 | Roll Error (MegaDepth) | Pitch Error (MegaDepth) | FoV Error (MegaDepth) | FID (Puffin-Gen) |
|---|---|---|---|---|
| GeoCalib | 0.51 | 4.59 | 10.92 | - |
| Puffin | 0.32 | 1.08 | 2.42 | 69.46 |
| PreciseCam | - | - | - | 83.31 |

Puffin 在 MegaDepth 上 Roll 误差 0.32° 优于 GeoCalib 的 0.51°，生成 FID 69.46 优于 PreciseCam 的 83.31，表明统一架构在精度与多样性上均占优。

消融实验显示，移除“思考”机制后 Roll 误差从 0.41° 升至 0.47°，验证了语义推理对几何精度的贡献。相机图潜变量的引入使生成误差显著降低，证明连续几何条件对像素级控制不可或缺。

评估边界受限于单视图透视假设，未处理全景循环一致性。代码与模型已开源，训练使用 64 张 A100 GPU 耗时 4 天，超参数完整披露，可复现性良好。

## 关联研究分析

从问题动机看，Puffin 与 GeoCalib 等专用标定方法的核心差异在于几何信息的处理方式。GeoCalib 依赖视觉特征直接回归参数，而 Puffin 将参数转化为语言推理对象。这一差异源于任务目标：前者追求单点精度，后者追求语义-几何闭环。Puffin 在复杂姿态下的优势表明，语义先验对几何估计具有不可替代的补充作用，但其在低纹理场景下的鲁棒性仍需验证。

从方法设计看，Puffin 与 PreciseCam 等可控生成方法的关键区别在于条件注入方式。PreciseCam 通过文本提示控制相机，而 Puffin 引入像素级相机图潜变量。这一设计解决了文本条件在空间布局上的模糊性，但增加了计算开销。与全景视频生成方法（如 Pantheon360）相比，Puffin 未处理球面拓扑约束，其透视投影假设限制了向沉浸式场景的迁移。

## 总结

Puffin 解决了相机理解与生成割裂导致的空间智能缺失问题，通过“以相机思考”范式将几何参数转化为语言推理对象，并融合离散 Token 与连续潜变量实现精确控制。实验表明其在 MegaDepth 上 Roll 误差 0.32°、生成 FID 69.46，均优于专用基线。然而，其单视图透视假设未处理全景循环一致性，且未验证在动态场景中的时空一致性。当输入图像包含复杂物体运动时，该静态几何推理机制能否保持轨迹连贯，论文未给出回答。
