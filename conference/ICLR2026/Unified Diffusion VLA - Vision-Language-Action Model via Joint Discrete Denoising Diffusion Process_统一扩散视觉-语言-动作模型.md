# ICLR2026最新论文 ｜Unified Diffusion VLA: Vision-Language-Action Model via Joint Discrete Denoising Diffusion Process ｜统一扩散视觉-语言-动作模型

研究机构：香港科技大学、西湖大学

作者：Jiayi Chen、Wenxuan Song、Pengxiang Ding 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.01718)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.01718)

> 具身智能中的统一视觉-语言-动作模型（Unified Vision-Language-Action Models, Unified VLAs）旨在通过单一架构同时实现视觉理解、未来图像生成与动作执行，其核心挑战在于如何避免生成任务干扰理解性能，并解决动作预测与视觉生成在优化目标上的割裂。现有方案要么依赖外部专家模块导致模态间弱耦合，要么将图像生成与动作预测作为分离过程，无法在推理时利用未来视觉信息显式引导动作。本文切入点在于提出联合离散去噪扩散过程（Joint Discrete Denoising Diffusion Process, JD3P），使动作Token在同步去噪轨迹中持续受未来图像Token引导，实现理解、生成与动作的内在协同。该设计在CALVIN基准上取得4.64的平均成功长度，较自回归方法快4倍，但其泛化性受限于离散Token化对细粒度视觉信息的损失，且未验证在更大规模真实场景中的稳定性。

## 研究背景

当机器人执行长时序操作任务时，动作预测往往依赖对当前观测的即时反应，缺乏对未来状态的显式规划能力。这种“反应式”范式导致模型难以处理需要多步推理的任务，如堆叠碗或翻转塔。为解决此问题，研究者引入未来图像预测作为“思维链”，将抽象的动作预测转化为更可控的逆运动学问题：先预测目标视觉状态，再推断实现该状态所需的动作。然而，现有统一VLA架构在实现这一范式时面临两难：模块化设计（如GR-1、DreamVLA）通过外部扩散模型生成图像，但视觉生成与动作预测在独立模块中执行，导致信息传递延迟与语义对齐不足；而原生Token化设计（如UniVLA、WorldVLA）虽在统一词表空间内建模，但通常仅在训练时预测图像作为辅助任务，推理时仅解码动作Token，丧失了未来视觉信息在决策时的显式引导价值。

本文的研究问题聚焦于如何在单一Transformer架构内，使视觉生成与动作预测在推理阶段形成双向、迭代的信息交换，而非单向条件或分离过程。这一问题的紧迫性源于具身智能对实时性与规划能力的双重需求：自回归方法虽能灵活生成序列，但每个动作Token仅通过单次计算整合上下文，限制了视觉引导的深度；扩散方法虽支持迭代细化，但传统设计将图像与动作去噪过程分离，无法实现跨模态的同步协同。UD-VLA的切入点在于将视觉生成与动作预测纳入同一去噪轨迹，通过混合注意力机制确保动作Token在每一步去噪中因果地关注所有未来图像Token，从而将动作预测重构为对预测视觉结果的隐式映射。

## 核心方法

### 统一离散Token化与混合注意力机制

UD-VLA的基础架构建立在离散Token化与混合注意力机制之上，旨在消除模态边界并最大化信息利用。视觉观测通过VQ分词器量化为$V_v$个Token，动作通过FAST分词器量化为$V_a$个Token，文本Token遵循Emu3设计，三者拼接为统一序列：$[\text{text tokens}; \text{current image tokens}; \text{future image tokens}; \text{action tokens}]$。混合注意力机制的关键设计在于模态内双向、模态间因果：输入文本与当前图像分别采用因果与双向注意力，输出部分划分为生成块（未来图像）与动作块，块内采用双向注意力以打破动作Token的时间序列依赖，避免捷径学习；块间采用因果注意力，即动作块关注输入与生成块，但无反向信息流。这一设计将端到端动作预测分解为两个耦合过程：(i) 预测下一视觉状态的“前瞻”过程，(ii) 基于该预测推断动作的“逆运动学”过程。其物理含义在于，通过禁止动作到视觉的信息路径，消除了粗粒度动作信息的泄漏与误差累积，确保下游控制真正基于预测的视觉后果而非虚假相关。

### 联合离散去噪扩散过程（JD3P）

JD3P是UD-VLA的核心创新，将视觉生成与动作预测整合为单一同步去噪轨迹。给定量化后的未来图像Token $\mathbf{v}_0$ 与动作Token $\mathbf{a}_0$，JD3P通过马尔可夫链逐步将Token替换为掩码Token $M$，形成噪声序列 $\mathbf{v}_t, \mathbf{a}_t$。去噪过程定义条件分布 $p_\theta(\mathbf{v}_{t-1}, \mathbf{a}_{t-1} | \mathbf{v}_t, \mathbf{a}_t, \mathbf{c})$，其中 $\mathbf{c}$ 为输入上下文（文本与当前图像）。关键公式为：

$$
p_\theta(\mathbf{v}_{t-1}, \mathbf{a}_{t-1} | \mathbf{v}_t, \mathbf{a}_t, \mathbf{c}) = \prod_{j=1}^{L_v} p_\theta(v_{t-1,j} | v_{t,j}, a_{t,i}, \mathbf{c}) \prod_{i=1}^{L_a} p_\theta(a_{t-1,i} | v_{t,j}, a_{t,i}, \mathbf{c})
$$

该公式表明，在每一步去噪中，动作Token的预测分布显式依赖于当前步骤的所有未来图像Token，且这一计算在去噪轨迹中重复多次。与自回归方法中每个动作Token仅通过单次计算整合上下文不同，JD3P的迭代细化使动作从初始化状态逐步收敛至精确值，同时未来图像也从噪声中逐步清晰。损失函数采用单步掩码预测目标，对掩码位置计算交叉熵，并通过权重 $\omega$ 下调视觉Token的贡献，避免其主导优化过程。这一设计解决了此前方法中视觉生成与动作预测分离导致的协同不足问题，使动作预测真正受益于未来视觉信息的迭代引导。

## 实验评估

实验在CALVIN、LIBERO与SimplerEnv三个模拟基准及真实机器人平台上进行，基线覆盖模块化（GR-1、DreamVLA）、原生Token化（UniVLA、WorldVLA）与离散扩散（CEED-VLA）等路线，但缺失纯自回归SOTA如π0-FAST在CALVIN上的直接对比。主结果显示，UD-VLA在CALVIN ABCD→D基准上取得4.64的平均成功长度，较UniVLA的4.20高出0.44，显著优于DreamVLA的4.26；在LIBERO上平均成功率为92.7%，其中Long套件达89.6%，超过DreamVLA的89.5%；在SimplerEnv-WidowX上整体成功率为62.5%，较F1的59.4%高出3.1个百分点。

| 基准 | 方法 | 平均成功长度/成功率 |
| :--- | :--- | :--- |
| CALVIN ABCD→D | UD-VLA | 4.64 |
| CALVIN ABCD→D | UniVLA | 4.20 |
| CALVIN ABCD→D | DreamVLA | 4.26 |
| LIBERO Average | UD-VLA | 92.7% |
| LIBERO Long | UD-VLA | 89.6% |
| SimplerEnv Overall | UD-VLA | 62.5% |

消融实验验证了混合注意力机制与JD3P的有效性：在CALVIN上，混合注意力（4.64）优于纯因果（4.04）与纯双向（4.32）；JD3P（4.64）较自回归解码（4.18）提升0.46，且推理速度达219.3 tokens/s，为自回归的4.3倍。视觉生成目标的选择也至关重要：预测未来图像（4.64）优于重建当前图像（4.39）与无视觉生成（4.21），证实了未来视觉信息作为“思维链”的价值。

## 关联研究分析

从问题动机看，UD-VLA与UniVLA、WorldVLA等原生Token化方法的核心差异在于推理时的视觉利用方式。UniVLA与WorldVLA在训练时建模视觉与动作Token，但推理时仅解码动作Token，视觉仅作为条件；UD-VLA则通过JD3P在推理时同步去噪视觉与动作Token，使未来图像成为显式的决策依据。这一差异源于任务特性：具身智能中动作的精确性高度依赖对目标状态的视觉规划，而自回归或分离去噪无法提供迭代细化所需的跨模态信息交换。论文未探索在视觉信息质量较低（如遮挡、模糊）时JD3P的鲁棒性，这是否影响其在真实场景中的部署效果，值得进一步验证。

从方法设计看，UD-VLA与DreamVLA、F1等模块化扩散方法的关键区别在于去噪过程的统一性。DreamVLA使用连续扩散在独立模块中生成图像与动作，F1通过混合Transformer实现下一尺度预测，但二者均未在单一去噪轨迹中实现跨模态同步。UD-VLA采用离散扩散，继承Emu3的Token化范式，但将去噪过程扩展至动作模态，并通过混合注意力确保因果方向。这一设计解决了模块化方法中视觉生成与动作预测的弱耦合问题，但离散Token化可能损失细粒度视觉信息（如小文本、复杂纹理），这在需要高精度视觉感知的任务中是否成为瓶颈，论文未给出定量分析。

## 总结

UD-VLA要解决的核心矛盾是统一VLA中视觉生成与动作预测的协同不足：现有方法要么通过外部模块导致信息割裂，要么在推理时丧失视觉引导价值。本文抓住的切入点是同步去噪轨迹，通过JD3P使动作Token在每一步去噪中因果地关注未来图像Token，实现迭代细化。这一设计在CALVIN上取得4.64的平均成功长度，较自回归方法快4倍，证明了联合去噪在具身智能中的有效性。然而，其边界在于离散Token化对细粒度视觉信息的潜在损失，以及真实世界实验的规模有限。当视觉输入包含复杂纹理或小目标时，VQ分词器的码本容量是否足以保留关键信息，从而维持JD3P的协同优势，论文未提供直接证据。
