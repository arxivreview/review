# ICLR2026最新论文 ｜BEYOND LENGTH: QUANTIFYING LONG-RANGE IN FORMATION FOR LONG-CONTEXT LLM PRETRAINING DATA ｜长上下文预训练数据筛选：基于条件互信息的增益量化

研究机构：美国加州大学洛杉矶分校、美国加州大学圣迭戈分校

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_45145873)

> 长上下文大语言模型（Long-Context LLM）的持续预训练面临“长长度”与“长依赖”混淆的问题，现有仅调整序列长度比例的方法无法区分真正需要长程信息的数据与可被短上下文预测的冗余文本。LongFilter 通过量化扩展上下文对下一词预测的条件互信息增益，筛选出高信息依赖样本。该方法在 LLaMA-3-8B 上将 8K 上下文扩展至 64K，在 HELMET、LongBench 和 RULER 基准上取得平均 2 分以上的提升，但其收益是否随模型规模扩大而递减，以及筛选过程对领域分布的潜在偏置，仍缺乏充分验证。

## 研究背景

持续预训练（Continual Pre-training）是激活大语言模型长上下文能力的标准流程，通常涉及调整旋转位置编码（RoPE）基频并引入长序列数据。然而，训练信号的有效性取决于数据中是否包含真实的长距离依赖。若数据仅长度长但局部可预测，模型在长上下文任务上的性能提升将受到限制。

现有数据工程方法主要关注序列长度分布，如 ProLong 通过增加长序列比例来扩展上下文窗口，LongWanjuan 则引入启发式质量指标。这些方法忽略了“长度”与“依赖”的本质差异：许多长文本（如诗歌集、独立代码片段）的下一词预测仅依赖局部上下文，扩展上下文并未提供额外信息。这种信号稀释导致训练效率低下，且无法区分真正需要长程推理的数据。

LongFilter 的切入点在于将数据筛选从“长度统计”转向“信息论量化”。它假设只有当扩展上下文显著降低下一词预测的不确定性时，该数据才对长上下文预训练有价值。这一视角将数据质量定义为模型在长、短上下文下的预测分布差异，从而为长上下文数据筛选提供了可计算的理论基础。

## 核心方法

### 方法参照系

长上下文数据筛选通常基于启发式规则或长度阈值，缺乏对语义依赖的显式建模。LongFilter 将问题重构为信息增益估计，利用预训练语言模型作为评分器，通过对比长、短上下文下的预测分布来量化数据的长程依赖性，区别于仅依赖文本表面特征的传统过滤方法。

### 条件互信息增益量化

LongFilter 的核心在于计算扩展上下文 $E$ 相对于短上下文 $S$ 提供的信息增益。理论上，这对应于条件互信息 $I(T; E | S)$，即已知短上下文 $S$ 时，扩展上下文 $E$ 对目标词 $T$ 预测不确定性的减少量。由于直接计算互信息需要遍历整个词表且计算成本高昂，LongFilter 采用基于真实标签 $t^*$ 的代理分数。该分数定义为长上下文下预测 $t^*$ 的对数似然与短上下文下预测 $t^*$ 的对数似然之差，再乘以长上下文下的预测概率：

$$
\text{Score}(t^*) = \left( \log p(t^* | L) - \log p(t^* | S) \right) \cdot p(t^* | L)
$$

这一设计解决了传统方法无法区分“长但局部可预测”文本的问题。公式中的对数似然差项衡量了扩展上下文带来的预测改进幅度，而乘以 $p(t^* | L)$ 则确保模型仅对高置信度的预测赋予高权重，避免噪声标签干扰。该分数直观地反映了扩展上下文对特定 token 预测的边际贡献，为数据筛选提供了细粒度的信号。

### 序列级聚合与筛选

单个 token 的增益分数需聚合为序列级分数以指导数据选择。LongFilter 将序列中所有 token 的增益分数取平均值，得到该序列的最终 LongFilter 分数：

$$
\text{LongFilter Score}(X) = \frac{1}{N} \sum_{i=1}^{N} \text{Score}(x_i^*)
$$

这一聚合策略解决了 token 级分数波动大、难以直接用于批量数据筛选的问题。通过平均化，LongFilter 平滑了局部噪声，突出了整体序列的长程依赖特性。随后，所有序列按分数排序，选取前 20% 的高分数据作为持续预训练集。这一过程确保了训练数据中真正需要长上下文理解的比例最大化，从而在固定计算预算下提升模型对长距离信息的利用效率。

## 实验评估

实验基于 LLaMA-3-8B 进行，将其上下文从 8K 扩展至 64K，使用 SlimPajama 数据集的 ArXiv、Book 和 CommonCrawl 子集。基线包括 ProLong（长度比例调整）和 LongWanjuan（启发式质量筛选）。LongFilter 在三个基准上均取得最高分，其中在 RULER Book 数据集上达到 78.95，显著优于 ProLong 的 73.35 和 LongWanjuan 的 73.74。

| 数据集 | 方法 | NIAH Single | NIAH MultiKey | NIAH MultiValue | NIAH MultiQuery | Other | Overall |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Book** | ProLong | 93.83 | 83.80 | 92.76 | 95.08 | 46.56 | 73.35 |
| | LongWanjuan | 90.08 | 91.03 | 91.38 | 82.75 | 48.23 | 73.74 |
| | LongFilter | 95.33 | 97.87 | 93.15 | 80.10 | 54.71 | **78.95** |

在 LongBench 上，LongFilter 在 Synthetic 任务（如 CC 数据集的 57.02）和 Code 任务上表现突出，表明其有效提升了模型对任意位置信息的利用能力。消融实验显示，LongFilter 在 1.5B 过滤 token 下即可达到未过滤数据 3-4B token 的训练效果，验证了数据质量对训练效率的关键作用。

评估边界方面，实验仅使用 8B 参数模型，未验证在更大规模模型上的边际收益。此外，筛选过程依赖 LLaMA-3.1-8B 作为评分器，其自身能力可能限制高分数据的上限。代码未公开，但超参数（短上下文 4K，长上下文 64K，Top 20% 筛选）已明确，具备可复现性。

## 关联研究分析

从问题动机看，LongFilter 与 ProLong 和 LongWanjuan 均旨在优化长上下文预训练数据，但 LongFilter 是唯一基于信息论指标的方法。ProLong 仅调整长度比例，忽略了内容依赖性；LongWanjuan 使用启发式指标，但其指标对短文本同样适用，缺乏长程特异性。LongFilter 通过条件互信息量化，显式区分了“长长度”与“长依赖”，这一差异源于其对数据价值的定义：只有当扩展上下文提供额外预测信息时，数据才有效。

从方法设计看，LongFilter 与 LongAttn 均利用模型内部信号评估数据，但 LongAttn 使用注意力分数，而 LongFilter 使用预测分布差异。研究表明注意力分数不可靠地反映 token 重要性，而预测分布差异直接关联于预测性能，因此 LongFilter 的指标更具鲁棒性。此外，LongFilter 的筛选过程是静态的，未考虑训练过程中的动态变化，这与 RLVR 等动态优化方法形成对比。LongFilter 的静态筛选是否足以应对长上下文推理中的复杂依赖，或在更大规模模型上是否需结合动态加权，论文未给出回答。

## 总结

LongFilter 解决了长上下文预训练中“长长度”与“长依赖”混淆的核心矛盾，通过条件互信息增益量化，筛选出真正需要长程信息的数据。该方法在 LLaMA-3-8B 上验证了有效性，RULER Book 数据集上 78.95 的分数显著优于基线，且 1.5B 过滤 token 即可达到 3-4B 未过滤数据的训练效果。然而，实验仅局限于 8B 模型，未验证在更大规模骨干上的边际收益，且筛选过程依赖固定评分器，可能引入领域偏置。当模型规模扩大至 70B 以上时，信息增益筛选的边际收益是否递减，以及评分器能力对筛选上限的影响，仍需进一步探索。
