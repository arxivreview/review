# ICLR2026最新论文 ｜Align to Misalign: Automatic LLM Jailbreak with Meta-Optimized LLM Judges ｜对齐以失对齐：基于元优化的LLM越狱攻击框架

研究机构：韩国延世大学、微软研究院

作者：Hamin Koo、Minseon Kim、Jaehyung Kim

论文原文见 [arXiv](https://arxiv.org/abs/2511.01375)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.01375)

> 大语言模型（LLM）越狱攻击旨在通过构造特定提示词绕过安全对齐机制，诱导模型生成有害内容。现有基于LLM的迭代优化攻击方法普遍依赖二元攻击成功率（ASR）或人工设计的固定评分模板，导致优化信号稀疏或存在系统性偏差，限制了攻击的泛化能力与效率。本文提出AMIS框架，通过双层优化结构协同进化越狱提示词与评分模板，使评估信号与真实攻击结果动态对齐。该方法在黑盒设定下显著提升了针对强模型的攻击成功率，但其元优化过程对计算成本的依赖及跨模型迁移的局限性仍需进一步审视。

## 研究背景

越狱攻击的核心在于对抗性提示词的构造，其有效性取决于优化过程中反馈信号的质量。攻击成功率（ASR）作为二元指标，仅能区分成功与失败，无法提供梯度式的方向指引；而人工设计的评分模板虽能输出连续分数，却往往与真实ASR存在偏差，导致优化过程陷入局部最优或产生误导性信号。这种评估信号与真实目标之间的错位，是现有LLM驱动攻击方法难以突破性能瓶颈的关键原因。

自2023年GCG奠定白盒梯度优化基线、PAIR确立黑盒迭代攻击范式以来，研究重心逐渐从“如何探索提示词”转向“如何评估提示词”。PAIR、TAP及AutoDAN-Turbo等方法虽在语义级迭代上取得进展，但均将评分函数视为固定组件，未考虑其自身的可优化性。这种静态评估机制在面对不同模型的安全对齐差异时，难以自适应地调整评估标准，导致攻击策略的泛化性受限。AMIS的切入点在于将评分模板本身纳入优化目标，通过元优化机制使其与真实ASR动态对齐，从而解决固定评估器导致的信号偏差问题。

## 核心方法

### 方法参照系

AMIS属于LLM驱动的黑盒迭代攻击框架，其基础流程与PAIR一致：攻击者LLM生成候选提示词，目标LLM生成响应，评估者LLM提供反馈以指导下一轮迭代。与标准流程的关键差异在于，AMIS将评估环节从固定函数升级为可优化的元组件，引入了外层循环对评分模板进行迭代更新，打破了传统方法中评估信号静态不变的假设。

### 查询级提示词优化

在查询级内层循环中，AMIS通过密集评分信号引导提示词的迭代精炼。设计动机在于解决二元ASR信号过于稀疏、无法提供稳定优化方向的问题。具体而言，对于有害查询 $q$，攻击者生成 $C$ 个初始前缀提示词，目标模型生成响应 $r$，评估者根据当前评分模板 $\pi_{sc}$ 分配连续分数 $s \in [1.0, 10.0]$。保留分数最高的 $K$ 个提示词进入下一轮迭代，攻击者基于这些高质量提示词生成 $M$ 个新候选，重复此过程 $L$ 次。该机制通过连续分数提供细粒度的优化梯度，使提示词在语义空间中稳定地向高危害区域收敛。

### 数据集级评分模板元优化

在数据集级外层循环中，AMIS通过ASR对齐分数优化评分模板本身。设计动机在于解决人工设计模板与真实ASR结果不一致导致的优化偏差。对于内层循环收集的每个提示词-响应-分数三元组 $(q', r', s_i)$，首先通过二元ASR评估获取真实标签 $y_i \in \{0, 1\}$，然后计算对齐度 $\alpha_i$：

$$
\alpha_i = \begin{cases}
100 \cdot \frac{s_i - s_{min}}{\Delta} & \text{if } y_i = 1 \\
100 \cdot \frac{s_{max} - s_i}{\Delta} & \text{if } y_i = 0
\end{cases}
$$

其中 $\Delta = s_{max} - s_{min}$ 为分数范围。该公式的物理含义是：当攻击成功时，分数越高对齐度越高；当攻击失败时，分数越低对齐度越高。整体ASR对齐分数 $Align(\pi_{sc})$ 为所有三元组 $\alpha_i$ 的均值。外层循环利用该分数指导评分模板优化器LLM生成新模板，通过迭代 $L'$ 次使评分模板逐步捕获数据集级别的危害评估知识，从而提供更校准的优化信号。

## 实验评估

实验在AdvBench（50个有害查询）和JBB-Behaviors（100个有害查询）上进行，对比PAIR、TAP、PAP、SeqAR、AutoDAN-Turbo等6种黑盒基线。基线覆盖了树搜索、遗传算法、提示词组合等主要路线，但缺失GCG等白盒基线（因黑盒设定排除）及Crescendo等多轮攻击方法。

| 目标模型 | PAIR ASR | AutoDAN-Turbo ASR | AMIS ASR | AMIS StR |
| :--- | :--- | :--- | :--- | :--- |
| Llama-3.1-8B | 90.0 | 84.0 | 100.0 | 0.84 |
| GPT-4o-mini | 82.0 | 54.0 | 98.0 | 0.87 |
| GPT-4o | 84.0 | 38.0 | 100.0 | 0.87 |
| Claude-3.5-Haiku | 46.0 | 42.0 | 88.0 | 0.42 |
| Claude-4-Sonnet | 28.0 | 38.0 | 100.0 | 0.70 |

AMIS在5个目标模型上均取得最高ASR，平均提升26.0%。在JBB-Behaviors上，AMIS在Llama-3.1-8B和GPT-4o-mini上达到100% ASR，平均提升20.2%。值得注意的是，AMIS在Claude系列模型上的StR分数（0.42-0.70）显著低于开源模型（0.84-0.87），表明其生成的提示词在强模型上虽能绕过拒绝，但响应质量较低。

| 消融组件 | ASR | StR |
| :--- | :--- | :--- |
| W/O INNER, OUTER LOOP | 4.0 | 0.04 |
| W/O OUTER LOOP | 86.0 | 0.28 |
| W/O DENSE SCORING TEMPLATE | 74.0 | 0.40 |
| W/O DATASET-LEVEL | 84.0 | 0.35 |
| W/O PROMPT INHERITANCE | 80.0 | 0.28 |
| AMIS (Ours) | 88.0 | 0.42 |

消融实验显示，移除外层循环导致ASR下降2.0%，StR下降0.14，表明评分模板元优化对信号校准的贡献有限但稳定。移除密集评分模板导致ASR下降14.0%，验证了连续分数优于二元信号。移除提示继承机制导致ASR下降8.0%，说明跨外层循环保留高质量提示词对优化效率有显著影响。

评估协议使用GPT-4o-mini作为ASR和StR的评估者，可能存在评估者偏差。代码已开源，但论文未报告计算成本细节，仅定性指出AMIS与PAIR成本相当但ASR增长更快。跨数据集泛化实验显示，在AdvBench上优化的提示词迁移到JBB-Behaviors时ASR为87.0%，反之亦然，表明框架生成的提示词具有较好的泛化性，但迁移效率低于原数据集优化结果。

## 关联研究分析

从问题动机看，AMIS与PAIR的核心差异在于评估信号的动态性。PAIR将评分函数视为固定组件，其优化过程受限于初始模板的质量；AMIS通过元优化使评分模板与真实ASR对齐，解决了固定评估器导致的信号偏差问题。这一差异的根源在于任务特性：越狱攻击的目标是绕过动态变化的安全对齐机制，静态评估标准难以适应不同模型的安全边界差异。AMIS的元优化机制本质上是将评估过程从“人工设计”转变为“数据驱动”，使攻击策略能够自适应地调整评估标准。

从方法设计看，AMIS与AutoDAN-Turbo的差异在于优化信号的粒度与校准机制。AutoDAN-Turbo采用固定评分模板，其优化过程受限于模板的预设标准；AMIS通过ASR对齐分数动态调整模板，使评分信号与真实攻击结果保持一致。这一差异的根源在于优化信号的稀疏性问题：二元ASR信号过于粗糙，固定评分模板存在人工偏差，而AMIS的密集且校准的信号提供了更稳定的优化方向。AMIS的元优化机制借鉴了强化学习中奖励函数优化的思路，将评估器本身作为可学习组件，这一设计在LLM越狱攻击领域具有新颖性。

## 总结

AMIS要解决的核心矛盾是LLM驱动越狱攻击中评估信号与真实攻击结果之间的错位。现有方法如PAIR、AutoDAN-Turbo依赖固定评分模板，导致优化信号存在系统性偏差，限制了攻击的泛化能力与效率。AMIS通过双层优化结构协同进化提示词与评分模板，使评估信号与真实ASR动态对齐，从而解决了固定评估器导致的信号偏差问题。实验表明，AMIS在AdvBench和JBB-Behaviors上均取得SOTA性能，在Claude-4-Sonnet上达到100% ASR，平均提升26.0%。然而，AMIS在强模型上的StR分数较低，且元优化过程依赖计算成本，跨模型迁移效率有限。当目标模型的安全对齐机制发生显著变化时，AMIS的评分模板元优化是否仍能保持有效的信号校准，论文未给出回答。
