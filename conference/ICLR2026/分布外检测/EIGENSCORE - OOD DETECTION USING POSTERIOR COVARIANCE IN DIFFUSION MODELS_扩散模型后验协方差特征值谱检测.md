# ICLR2026最新论文 ｜EIGENSCORE: OOD DETECTION USING POSTERIOR COVARIANCE IN DIFFUSION MODELS ｜扩散模型后验协方差特征值谱检测

研究机构：美国圣路易斯华盛顿大学、美国加州大学河滨分校

作者：Shirin Shoushtari、Yi Wang、Xiao Shi 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_63814771)

> 扩散模型在分布外（Out-of-Distribution, OOD）检测中面临似然与评分范数信号不稳定的困境，尤其在近邻 OOD 场景下失效。EigenScore 切入去噪过程的后验协方差结构，证明分布偏移会导致协方差特征值谱的系统性膨胀。该方法通过无 Jacobian 子空间迭代估计前 K 个特征值，构建稳定的不确定性评分。其在近邻 OOD 基准上超越了重建与轨迹类基线，但整体性能仍低于基于特征几何的训练式方法，且对高噪声水平的依赖限制了其计算效率。

## 研究背景

扩散模型通过逐步去噪学习数据分布，其核心机制是训练一个去噪网络 $D_\theta(\mathbf{x}_t, t)$ 预测含噪状态 $\mathbf{x}_t$ 中的噪声或干净信号。Tweedie 公式建立了去噪均值与对数密度梯度（评分函数）之间的数学联系，使得去噪过程不仅生成样本，还暴露了数据分布的局部几何结构。然而，直接利用似然或评分范数进行 OOD 检测时，生成模型常出现“似然异常”现象，即对 OOD 样本赋予过高的似然值，导致检测失效。

现有扩散模型 OOD 检测路线主要分为重建误差法（如 DDPM-OOD）与轨迹几何法（如 DiffPath）。重建法假设 OOD 样本重建质量差，但在近邻 OOD 中，OOD 样本可能拥有视觉上合理的重建，导致信号缺失；轨迹法依赖评分范数的时序变化，但其方向性不稳定，在不同数据集对之间可能出现 OOD 评分低于 ID 评分的反转现象。EigenScore 的切入点在于，放弃标量化的似然或范数，转而分析去噪器后验协方差的特征值谱。理论分析表明，当在 ID 数据上训练的扩散模型应用于 OOD 输入时，其后验方差会在结构化方向上膨胀，这种谱膨胀提供了比标量指标更稳定、更具方向一致性的分布偏移信号。

## 核心方法

### 去噪不确定性与分布偏移的理论关联

扩散模型 OOD 检测的通用流程通常提取去噪轨迹上的标量统计量（如 NLL、评分范数）作为评分。本文的关键差异在于，将检测信号从标量统计量替换为后验协方差的谱结构。设计动机在于解决标量指标在近邻 OOD 下方向性失效的问题。

根据命题 1，ID 分布 $p$ 与 OOD 分布 $q$ 之间的 KL 散度可表示为去噪误差的累积。对于 ID 去噪器 $D_p$，其在 OOD 输入上的均方误差（MSE）大于其在 ID 输入上的 MSE。通过全方差定律，该 MSE 分解为后验协方差的迹：

$$
\text{MSE}(D_p; q, t) = \mathbb{E}_{\mathbf{x}_t \sim q_t} \left[ \text{tr}(\text{Cov}_p[\mathbf{x} | \mathbf{x}_t]) \right]
$$

此公式表明，去噪误差直接对应于模型对干净信号的预测不确定性总和。当输入偏离 ID 流形时，后验分布变宽，协方差迹增大，从而在理论上保证了 OOD 评分高于 ID 评分的方向一致性，克服了评分范数可能反转的缺陷。

### 基于无 Jacobian 子空间迭代的特征值估计

直接计算高维后验协方差矩阵 $\Sigma_t(\mathbf{x}_t)$ 及其特征值在计算上不可行。本文利用 Miyasawa 恒等式，将后验协方差表示为去噪器 Jacobian 的函数：$\Sigma_t(\mathbf{x}_t) = \sigma_t^2 \nabla D_p(\mathbf{x}_t)$。设计动机在于避免显式计算大规模 Jacobian 矩阵，同时保留谱结构信息。

EigenScore 采用无 Jacobian 子空间迭代法估计前 $K$ 个最大特征值。该方法通过有限差分近似 Jacobian-向量乘积：

$$
\mathbf{v}_{+} \approx \frac{D(\mathbf{x}_t + c\mathbf{v}) - D(\mathbf{x}_t - c\mathbf{v})}{2c}
$$

其中 $c$ 为小常数，$\mathbf{v}$ 为当前主成分方向。通过迭代正交化，算法仅利用去噪器的前向传播即可估计特征值 $\lambda_k^{[t]}$。最终评分 $S_\theta(\mathbf{x})$ 为多个时间步 $t$ 上前 $K$ 个特征值之和的 Z-score 归一化累加。这一设计将计算复杂度从矩阵分解降低为向量迭代，使得在大规模图像数据集上部署成为可能，同时保留了谱膨胀这一关键检测信号。

## 实验评估

实验在 CIFAR-10 (C10), CIFAR-100 (C100), SVHN, CelebA 及 TinyImageNet 上进行，涵盖远端 OOD 与近邻 OOD 任务。基线覆盖似然类（NLL, WAIC）、重建类（DDPM-OOD）及轨迹类（DiffPath, LMD）。缺失基于 VLM 或特征几何的训练式强基线（如 GEODE, PROTON），导致无法直接对比当前领域 SOTA。

| 方法 | C10 vs C100 (Near-OOD) | C10 vs TinyImageNet (Near-OOD) | Avg (Near-OOD) |
| :--- | :--- | :--- | :--- |
| DDPM-OOD | 0.618 | 0.462 | 0.527 |
| LMD | 0.601 | 0.569 | 0.580 |
| DiffPath | 0.554 | 0.993 | 0.754 |
| **EigenScore** | **0.884** | **0.888** | **0.849** |

在近邻 OOD 任务中，EigenScore 平均 AUROC 达到 0.849，显著优于 DDPM-OOD (0.527) 和 LMD (0.580)。值得注意的是，DiffPath 在 C10 vs TinyImageNet 上取得 0.993 的高分，但在 C10 vs C100 上仅 0.554，表现极不稳定；而 EigenScore 在两个子任务上均保持 0.88 以上，验证了谱结构在语义重叠场景下的鲁棒性。

消融实验显示，时间步 $T$ 和重复次数 $I$ 对性能影响有限。$T=5$ 时平均 AUROC 为 0.648，$T=10$ 时为 0.648，表明少量时间步即可捕捉主要信号。特征值数量 $K$ 的影响更为显著：$K=1$ 时平均 AUROC 为 0.713，$K=3$ 时降至 0.648。这与理论预测一致，即主要判别信息集中在前几个特征值，高阶特征值受噪声影响较大，引入后反而稀释了信号。

评估边界方面，论文未报告计算效率的具体数值（如推理延迟或 FLOPs），仅定性提及子空间迭代降低了成本。代码未公开，超参数（如 $c$ 的取值、$K$ 的选择）依赖验证集调优，限制了跨数据集的即插即用能力。此外，实验仅使用预训练扩散模型，未探讨模型容量或训练数据规模对协方差膨胀幅度的影响。

## 关联研究分析

从信号源选择看，EigenScore 与 SCOPED 同属高效扩散检测路线，但信号机制不同。SCOPED 利用评分范数与曲率的信息论联系，通过离线噪声水平选择实现并行化；EigenScore 则聚焦后验协方差的特征值谱。SCOPED 的优势在于计算效率极高，适合实时部署；EigenScore 的优势在于理论上的方向一致性，特别是在近邻 OOD 中避免了评分范数的反转问题。两者的差异根源在于对“不确定性”的量化方式：SCOPED 依赖评分函数的局部几何，EigenScore 依赖去噪器的预测方差。

从方法范式看，EigenScore 与 GEODE 形成鲜明对比。GEODE 基于神经坍缩理论，利用中间层特征的几何结构（如原型距离）进行训练式检测，在 Near-OOD 上取得 95.02 的 AUROC。EigenScore 作为无监督方法，无需额外训练或标签，但在 C10 vs C100 上仅取得 0.884。这一差距表明，仅靠生成模型内部的后验统计量，难以完全弥补特征空间几何结构缺失带来的检测精度损失。GEODE 利用了判别式模型训练过程中形成的紧凑簇结构，而 EigenScore 仅利用了扩散模型的去噪特性。这暗示在无监督设定下，生成模型的后验协方差可能不足以捕捉细粒度的语义边界，除非结合更强的特征提取器。

## 总结

EigenScore 解决了扩散模型 OOD 检测中似然与评分范数信号不稳定的核心矛盾。其切入点在于证明后验协方差特征值谱在分布偏移下的系统性膨胀，并通过无 Jacobian 子空间迭代实现了高效估计。实验证明，该方法在近邻 OOD 场景下比重建与轨迹类基线更稳定，平均 AUROC 提升显著。然而，其性能仍低于基于特征几何的训练式方法，且高阶特征值的引入反而降低性能，表明谱结构中的判别信息高度集中于低维子空间。当扩散模型在复杂长尾分布上训练时，后验协方差的膨胀是否仍能保持单调性与方向一致性，论文未给出回答。
