# ICLR2026最新论文 ｜SCOPED: Score-Curvature Out-of-distribution Proximity Evaluator for Diffusion ｜评分-曲率分布外检测器

研究机构：美国德克萨斯大学奥斯汀分校、美国康奈尔大学

作者：Brett Barkley、Preston Culbertson、David Fridovich-Keil

论文原文见 [arXiv](https://arxiv.org/abs/2510.01456)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.01456)

> 扩散模型在分布外（Out-of-Distribution, OOD）数据上常出现似然异常升高，导致基于似然的检测失效，且现有路径积分方法计算开销巨大。SCOPED 利用信息几何中评分函数范数与曲率的内在联系，构建单一测试统计量，将模型评估次数降低一个数量级。该方法通过单点探针替代全路径积分，实现了高效并行化，但在近邻 OOD 场景下的鲁棒性尚未得到充分验证。

## 研究背景

当检测器面对未见数据时，传统分类器往往给出高置信度的错误预测。这种过度自信源于模型在训练分布内形成的紧凑特征簇，而 OOD 样本可能落在簇边界附近，导致基于最大 Softmax 概率（MSP）等后验评分的方法失效。为捕捉更细微的分布偏移，研究者转向生成式模型，利用其去噪轨迹或重构误差作为信号源。然而，生成式模型存在似然异常现象，即 OOD 数据的似然值可能高于 ID 数据，这使得直接基于似然的检测不可靠。

扩散模型 OOD 检测的主流路线包括基于重构误差的方法和基于轨迹几何的方法。重构方法依赖信息瓶颈的精细调节，实际应用中较为脆弱；轨迹方法如 DiffPath 需要沿去噪路径进行多次模型评估，计算成本随路径长度线性增长，难以满足实时部署需求。尽管这些方法在信号丰富度上优于判别式模型，但效率瓶颈限制了其广泛应用。SCOPED 的切入点在于利用扩散模型直接学习的评分函数，结合信息几何理论，提取单点处的曲率信息，从而在保持信号有效性的同时大幅降低计算开销。

## 核心方法

### 方法参照系

扩散模型 OOD 检测通常依赖全去噪路径的积分或重构误差，这些方法需要多次前向传播。SCOPED 的关键差异在于其探针的独立性：它不重建完整去噪路径，而是在选定的噪声水平上直接评估评分函数及其曲率，使得不同时间步和样本间的计算可以完全并行。

### 评分-曲率统计量

传统方法依赖似然比，但似然在 OOD 数据上不可靠。SCOPED 利用信息几何中的典型集理论，定义评分-曲率比作为典型性度量。对于密度 $p(x)$，评分函数 $s(x) = -\nabla_x \log p(x)$，曲率 $\kappa(x) = \text{Tr}(\nabla_x s(x))$。统计量定义为：

$$ T(x) = \frac{\|s(x)\|^2}{\kappa(x)} $$

该公式的物理含义是，在分布的典型集内，评分范数的平方与曲率近似相等，比值接近 1；而 OOD 样本偏离典型集，导致比值显著偏离 1。这一设计规避了似然异常问题，直接利用模型内部的几何结构。

### 核密度估计校准与噪声水平选择

$T(x)$ 的绝对值在不同数据集和噪声水平下不可比，固定阈值不可靠。SCOPED 在 ID 数据上计算 $T(x)$，并使用核密度估计（KDE）拟合其分布，将异常分数定义为 $-\log h(T(x))$，其中 $h$ 是 KDE 拟合的密度函数。此外，基于信噪比（SNR）的单调衰减特性，离线选择早期（$t=1$）和中期（$t=300$）两个噪声水平，取两者异常分数的最大值作为最终分数。这一策略仅使用 ID 数据进行校准，避免了对 OOD 数据的依赖，确保了方法的无监督特性。

## 实验评估

实验在 CIFAR-10、SVHN、CelebA 和 CIFAR-100 上进行，基线包括 DiffPath、MSMA、DDPM-OOD 等扩散模型方法以及 Glow 似然方法。SCOPED 在多数数据集对上取得了有竞争力或最优的 AUROC，同时计算成本显著低于路径方法。

| 方法 | C10 vs SVHN | C10 vs CelebA | C10 vs C100 | 计算成本 (F+J) |
| :--- | :--- | :--- | :--- | :--- |
| DiffPath | 0.910 | 0.939 | 0.998 | 10F+ 0J |
| SCOPED | 0.897 | 0.979 | 1.00 | 2F+ 2J |
| SCOPED (Single) | 0.590 | 0.953 | 0.998 | 1F + 1J |

SCOPED 在 C10 vs C100 上达到 1.00 的 AUROC，优于 DiffPath 的 0.998，且计算成本仅为 2F+2J，远低于 DiffPath 的 10F+0J。消融实验显示，SCOPED (Single) 在 C10 vs SVHN 上性能下降至 0.590，表明早期噪声水平对细粒度细节的捕捉至关重要，而中期噪声水平提供了更鲁棒的粗结构信号。

评估边界方面，论文未报告置信区间，且未在近邻 OOD 基准（如 NINCO）上进行测试。代码未公开，但提供了详细的超参数选择策略。计算成本以函数评估次数（NFE）衡量，JVP 成本近似为一次前向传播，实际墙钟时间因并行化而显著降低。

## 关联研究分析

从信号源角度看，SCOPED 与 EigenScore 同属利用扩散模型内部统计量的路线，但 EigenScore 关注后验协方差的特征值谱，而 SCOPED 关注评分-曲率比。EigenScore 理论上证明了协方差在 OOD 数据上的一致性标记，但计算特征值谱可能涉及更高的复杂度；SCOPED 通过 Hutchinson 迹估计器将曲率计算降至线性复杂度，更适合实时场景。两者均规避了似然异常问题，但 SCOPED 的并行化优势使其在部署上更具吸引力。

从效率与精度的权衡看，SCOPED 与 DiffPath 形成鲜明对比。DiffPath 依赖全路径积分，信号丰富但计算昂贵；SCOPED 通过单点探针牺牲了部分路径信息，换取了数量级的效率提升。在 C10 vs C100 上，SCOPED 的精度甚至略优于 DiffPath，表明单点曲率信号在特定分布偏移下足以捕捉关键差异。然而，在 C10 vs SVHN 上，SCOPED (Single) 的性能大幅下降，暗示单点探针在细粒度语义偏移下的局限性，而双步策略通过融合早期和中期信号弥补了这一缺陷。

## 总结

SCOPED 旨在解决扩散模型 OOD 检测中似然不可靠与计算效率低下的矛盾。它利用信息几何中的评分-曲率关系，构建单一统计量，并通过 KDE 校准和离线噪声水平选择实现高效无监督检测。在视觉基准上，SCOPED 以 2F+2J 的成本达到了与 DiffPath 相当或更优的 AUROC，验证了单点探针的有效性。然而，实验未覆盖近邻 OOD 场景，且单步变体在细粒度偏移下性能波动较大。当 ID 与 OOD 数据在特征空间高度重叠时，评分-曲率比是否仍能保持足够的区分度，论文未给出明确回答。
