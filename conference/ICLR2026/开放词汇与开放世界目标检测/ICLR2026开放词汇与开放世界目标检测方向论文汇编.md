【BEYOND THE KNOWN: AN UNKNOWN-AWARE LARGE - LANGUAGE MODEL FOR OPEN-SET TEXT CLASSIFI CATION ｜未知感知大语言模型用于开放集文本分类

研究机构：中国科学技术大学、中国科学院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_1542046)

> 开放集文本分类（OSTC）要求模型在准确识别已知类别（ID）样本的同时，可靠地拒绝分布外（OOD）输入，但现有方法多依赖封闭集训练后的后处理检测，导致模型对OOD输入产生过度自信且偏差的预测。本文切入点在于将OOD检测从后处理程序转化为训练时的内生建模能力，通过子集条件化生成式微调、OOD参数校准及类比增强自反思，系统性地强化模型对“未知”的表征、概率与推理能力。该范式在六个基准上持续超越现有SOTA，但其依赖标签子集构造伪OOD的机制，在真实OOD分布复杂多变时的泛化边界尚存疑。

【DeCo-DETR: Decoupled Cognition DETR for efficient Open-Vocabulary Object Detection ｜解耦认知检测器

研究机构：美国布朗大学、新加坡南洋理工大学

作者：Siheng Wang、Yanshu Li、Bohan Hu 等 15 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.02753)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.02753)

> 开放词汇目标检测（OVOD）旨在让检测器识别训练集中未出现的类别，但现有方法在推理时依赖大型文本编码器或大语言模型（LLM），导致计算开销巨大，且多模态融合常引发闭集精度与开放世界泛化之间的优化冲突。DeCo-DETR 通过构建离线动态层级概念池替代在线文本编码，并采用参数解耦训练分离定位与语义对齐的梯度流，试图在保持零样本泛化能力的同时降低推理延迟。该框架在 OV-COCO 和 OV-LVIS 上取得了优于经典蒸馏基线的性能，但其与最新 SOTA 方法的对比缺失及协议差异引发的数值可比性问题，限制了其实际定位的清晰度。

【DETR-ViP: Detection Transformer with Robust Discriminative Visual Prompts ｜视觉提示检测中的全局判别性优化

研究机构：浙江大学

作者：Bo Qian、Dahu Shi、Xing Wei

论文原文见 [arXiv](https://arxiv.org/abs/2604.14684)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.14684)

> 开放词汇检测依赖提示（Prompt）定义目标类别，文本提示虽通用但跨模态对齐存在固有偏差，视觉提示虽天然兼容图像特征却在稀有类别上表现更优，却长期因嵌入空间语义混乱而性能受限。现有方法如T-Rex2仅在当前图像内采样提示，导致负样本匮乏，无法建立全局类别边界。本文通过全局提示聚合与文本-视觉关系蒸馏，重构视觉提示嵌入空间的拓扑结构，使其具备类内紧凑与类间分离特性。该工作显著提升了视觉提示检测的零样本性能，但其对文本提示的依赖仍限制其在纯视觉交互场景下的独立性。

【OVID: OPEN-VOCABULARY INTRUSION DETECTION ｜开放词汇入侵检测

研究机构：香港中文大学、中国科学技术大学

作者：Fujun Han、Jingqi Ye、Chenglong Zhang 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_73229531)

> 动态视角下的入侵检测长期受限于预定义类别，无法识别训练集外的车辆或骑行者。现有方法仅能处理固定类别，且缺乏文本模态支持，导致在开放场景中漏检严重。本文提出OVID任务与OVIDNet框架，通过多模态对齐与噪声混合策略实现零样本入侵判定。该工作填补了入侵检测领域的开放词汇空白，但其小骨干网络与单一数据集验证限制了泛化能力的评估。

【RETAIN AND ADAPT: AUTO-BALANCED MODEL EDIT ING FOR OPEN-VOCABULARY OBJECT DETECTION UNDER DOMAIN SHIFTS ｜自动平衡模型编辑用于开放词汇目标检测

研究机构：南京大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_43543947)

> 开放词汇目标检测（OVOD）在分布偏移下性能骤降，传统持续学习因顺序敏感与遗忘问题难以灵活扩展新域。本文切入点在于将少样本适应重构为模型编辑问题，通过微调前馈网络（FFN）层提取键值（KV）统计量，实现无顺序依赖的知识注入。该方法在19个少样本数据集上验证了接近全量微调的新任务性能与高旧任务保留率，但其对极端语义偏移的泛化能力仍存疑。

】
