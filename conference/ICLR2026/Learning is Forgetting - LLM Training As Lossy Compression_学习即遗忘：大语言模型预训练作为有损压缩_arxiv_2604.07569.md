# ICLR2026最新论文 ｜Learning is Forgetting: LLM Training As Lossy Compression ｜学习即遗忘：大语言模型预训练作为有损压缩

研究机构：美国普林斯顿大学、Cohere

作者：Henry C. Conklin、Tom Hosking、Tan Yi-Chern 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.07569)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.07569)

> 大语言模型（LLM）在海量数据上训练后，其内部表征空间的结构如何形成，以及哪些信息真正驱动了下游性能，仍是解释性研究的核心盲区。现有基于探针或因果干预的方法难以在模型整体尺度上量化表征的信息含量，且缺乏与经典学习理论的直接联系。本文提出将 LLM 预训练视为有损压缩过程，利用信息瓶颈（Information Bottleneck, IB）理论构建信息平面，通过软熵估计器在 LLM 规模下量化表征与输入、输出的互信息。该方法揭示了预训练遵循“先扩展后压缩”的两阶段动态，并证明压缩的最优性可直接预测下游基准性能，为理解 LLM 学习机制提供了统一的信息论框架，但其结论依赖于特定校准数据分布，且未涉及压缩后的硬件加速或参数移除工程。

## 研究背景

理解 LLM 如何从万亿级 token 中提取有效信息，需先厘清“压缩”在机器学习中的理论地位。传统观点认为学习是拟合数据，但贝叶斯推断与奥卡姆剃刀原则暗示，模型倾向于保留与预测目标相关的最简假设。这一思想在率失真理论（Rate Distortion Theory, RDT）中形式化：编码器保留输入 $X$ 的信息量（速率）与预测输出 $Y$ 的误差（失真）之间存在权衡。信息瓶颈（IB）理论进一步将速率定义为表征 $Z$ 与输入 $X$ 的互信息 $I(X;Z)$，失真定义为 $Z$ 与目标 $Y$ 的互信息 $I(Y;Z)$，从而在二维“信息平面”上界定最优压缩边界。

主流 LLM 解释性研究多聚焦于局部机制，如稀疏自编码器识别单义特征或注意力头分析，这些方法虽能定位特定功能，但无法解释模型整体为何在复杂任务上表现优异。Tishby 等人（2015）曾提出深度学习训练遵循 IB 两阶段动态（拟合与压缩），但该假设仅在小型前馈网络（如 MNIST 上的 MLP）中得到验证，且在 Transformer 架构及大规模预训练场景下是否成立尚存争议。本文切入点在于将 IB 理论扩展至 LLM 规模，通过高效估计高维表征的离散熵，直接测量预训练过程中模型逼近最优压缩边界的轨迹，并探索该压缩程度与下游行为性能的关联。

## 核心方法

### 信息平面与最优压缩边界

本文参照系为 IB 理论中的信息平面，横轴为复杂度 $I(X;Z)$，纵轴为表达力 $I(Y;Z)$。通常做法是寻找最小化 $I(X;Z) + \beta I(Y;Z)$ 的编码 $Z$，其中 $\beta$ 控制失真容忍度。本文的关键差异在于，不直接优化参数，而是测量现有 LLM 在预训练过程中是否自然逼近该边界。最优压缩边界定义为 $I(X;Z) = I(Z;Y)$，即每增加一比特输入信息保留量，恰好增加一比特输出预测能力，直至共享信息饱和。

### 软熵估计器（Soft-Entropy Estimator）

传统互信息估计依赖将连续表征 $Z \in \mathbb{R}^h$ 分箱为离散类别，但在 LLM 高维空间中，分箱法内存开销呈指数增长，无法扩展至 7B 参数模型。本文采用软熵估计器，通过随机锚点与软分配近似离散分布。具体而言，将表征归一化至单位球面 $S^{h-1}$，采样 $n$ 个均匀锚点 $W \in \mathbb{R}^{h \times n}$，计算每个表征 $z$ 与锚点的余弦相似度并应用 softmax，得到概率向量 $\hat{z}$。

$$
\hat{z}_i = \text{softmax}\left( \frac{\bar{z} \cdot w_i}{\epsilon} \right)
$$

其中 $\epsilon$ 为温度参数，控制软分配的锐度。该公式的物理含义是：将高维连续空间中的点“软投影”到有限个离散锚点上，从而将连续熵估计转化为离散类别分布的香农熵计算。通过平均批量与序列维度，得到每层的概率分布 $\hat{Z}_l$，进而计算熵 $H(\hat{Z}_l) = -\sum_j \hat{z}_j \log \hat{z}_j$。此设计解决了分箱法在 LLM 规模下的计算不可行性问题，使互信息 $I(X;Z) = H(Z) - H(Z|X)$ 可在 10,000 个 C4 样本上高效估计。

### 条件互信息与回退机制

为捕捉语言建模中的上下文依赖，本文引入回退（Back-off）机制，将输入标签 $X$ 从单 token 扩展至 n-gram（如 bigram, trigram, quad-gram）。通常做法是固定上下文长度，但本文通过改变条件上下文宽度，量化不同层级局部上下文对表征信息的贡献。

$$
I(X;Z) = H(Z) - H(Z|X)
$$

该公式中，$H(Z|X)$ 为给定输入特征 $X$ 的条件熵。当 $X$ 为 quad-gram 时，$H(Z|X)$ 显著降低，表明模型表征中编码了大量局部上下文信息。通过比较不同回退层级下的互信息差值，本文发现模型主要编码局部上下文而非长程依赖，且随着上下文增加，模型对目标与源的压缩是联合进行的，而非独立压缩目标。

## 实验评估

实验基于 OLMo2 7B/32B/1B 模型的中间检查点，使用 C4 数据集的 10,000 个样本估计互信息，并对比 47 个开源 LLM 的最终状态。基线审计方面，本文未对比任何剪枝或量化方法（如 SparseGPT, Wanda），而是以不同规模 OLMo2 模型及跨家族 LLM 作为参照，验证 IB 动态的普适性。

| 模型规模 | 训练阶段 | 逼近边界程度 | 下游性能相关性 |
| :--- | :--- | :--- | :--- |
| OLMo2 7B | 预训练全程 | 随 loss 饱和逐步逼近 | $r=0.76, p<0.001$ |
| OLMo2 1B | 预训练后期 | 难以实现有效压缩 | 未报告具体数值 |
| 47 个开源 LLM | 训练结束 | 均收敛至边界附近 | 预测 6 项基准性能 |

核心数字对比显示，7B 模型在预训练后期显著逼近 IB 边界，而 1B 模型在训练后期未能实现有意义的压缩，表明规模是压缩动态的条件变量。在 47 个 LLM 中，压缩最优性指标与下游基准性能的相关系数达 $r=0.76$，显著高于随机基线，证实表征结构可直接预测行为性能。

消融分析聚焦于回退层级对信息分解的影响。当回退至 token 级别时，$I(X;Z)$ 较高，表明模型保留了大量原始输入信息；当回退至 quad-gram 时，$I(X;Z)$ 显著下降，但 $I(Y;Z)$ 保持相对稳定，说明模型通过压缩局部上下文冗余来优化表达力。这一发现解释了为何基于激活范数的剪枝方法（如 Wanda）有效：激活范数高通常对应局部上下文信息密集区域，移除这些区域会破坏 $I(Y;Z)$，而本文的信息平面分析提供了其背后的理论依据。

评估边界方面，本文未报告压缩后的困惑度（PPL）或准确率数值，仅使用“Optimality”统计量衡量逼近边界的程度。代码已开源（https://github.com/hcoxec/soft_h），但温度参数 $\epsilon$ 的校准过程依赖附录 E.1.1 中的特定协议，不同维度表征的可比性受 $\epsilon$ 选择影响。此外，实验仅使用 C4 数据集，未验证在其他语料（如 WikiText-2）上结论的泛化性，且未涉及硬件加速或参数移除的工程实现。

## 关联研究分析

从问题动机看，本文与 SparseGPT 等后训练剪枝方法存在根本差异。SparseGPT 关注如何在固定架构下移除冗余权重以保持性能，其核心假设是权重幅值或泰勒展开能捕捉重要性；而本文关注预训练过程中表征空间如何自然形成最优压缩，其核心假设是模型通过丢弃与预测无关的信息来逼近 IB 边界。这一差异源于任务特性：剪枝是工程优化问题，需在给定模型上寻找最优子集；而本文是理论解释问题，需揭示模型为何能高效学习。本文发现“压缩是意见化的”，即模型选择性保留信息，这为剪枝方法提供了理论支撑：若某权重对应的信息在 IB 边界之外（即对 $I(Y;Z)$ 贡献小），则移除该权重理论上不会损害性能。

从方法设计看，本文与 Tishby & Zaslavsky (2015) 的 IB 理论一脉相承，但扩展了适用尺度。Tishby 的理论基于小型前馈网络，其压缩阶段由非线性激活驱动；而本文在 Transformer LLM 中验证了类似动态，但发现压缩主要由数据分布与训练动态驱动，而非单纯的非线性效应。这一差异可能源于 Transformer 的注意力机制允许长程依赖建模，使得信息压缩更依赖于上下文结构而非局部非线性。此外，本文引入的软熵估计器解决了高维表征熵估计的计算瓶颈，这是 Tishby 时代未面临的技术挑战，也是本文能在 LLM 规模上应用 IB 理论的关键技术突破。

## 总结

本文要解决的核心矛盾是 LLM 表征结构的不透明性与经典学习理论的可解释性之间的脱节。现有方法无法在模型整体尺度上量化信息含量，而本文通过软熵估计器将 IB 理论扩展至 LLM 规模，证明了预训练遵循“先扩展后压缩”的动态，且压缩最优性可预测下游性能（$r=0.76$）。本文的边界在于仅使用 C4 数据集验证，且未涉及压缩后的工程实现，如硬件加速或参数移除。当校准数据从 C4 切换至领域特定语料时，IB 边界的位置是否发生系统性偏移，以及这种偏移是否影响压缩最优性与下游性能的相关性，论文未给出回答。
