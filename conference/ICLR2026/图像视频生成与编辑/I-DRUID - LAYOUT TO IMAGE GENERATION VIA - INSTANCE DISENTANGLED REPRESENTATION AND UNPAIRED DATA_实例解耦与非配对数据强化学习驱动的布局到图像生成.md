# ICLR2026最新论文 ｜I-DRUID: LAYOUT TO IMAGE GENERATION VIA - INSTANCE DISENTANGLED REPRESENTATION AND UNPAIRED DATA ｜实例解耦与非配对数据强化学习驱动的布局到图像生成

作者：Fengxiang Yang、Tianyi Zheng、Bangjie Yin 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_59579344)

> 布局到图像生成（L2I）旨在根据给定的边界框与实例描述合成多物体图像，但现有方法常因注意力机制中的特征纠缠导致属性泄漏，且依赖大量配对数据导致对新场景泛化能力不足。I-DRUID 通过实例解耦模块（IDM）分离语义相关特征与虚假特征，并引入基于非配对数据的强化学习（RL）框架，利用视觉语言模型（VLM）反馈优化生成策略。该方法在 SD-1.5 和 SD3 架构上均实现了 SOTA 性能，但其 RL 阶段对 VLM 评估准确性的依赖及 ODE 流程中探索效率的潜在瓶颈，构成了其应用边界。

## 研究背景

布局到图像生成的核心挑战在于如何精确控制多个实例的空间位置与语义属性。扩散模型通过去噪过程生成图像，但标准的交叉注意力机制倾向于融合不同实例的特征，导致“属性泄漏”现象，即一个实例的颜色或形状错误地出现在另一个实例上。为缓解此问题，现有方法多采用注意力图操纵或适配器注入布局信息，但这些方法通常局限于 UNet 架构，且缺乏对特征纠缠的显式解耦机制。

随着多模态扩散 Transformer（MM-DiT）如 SD3 的普及，L2I 研究面临新的瓶颈。MM-DiT 采用确定性常微分方程（ODE）前向过程，限制了传统强化学习（RL）中基于随机性探索的能力。同时，现有 L2I 模型在训练集与测试集提示词长度或风格不一致时（如长描述训练、短描述测试），性能显著下降，暴露出对配对数据过度依赖的泛化缺陷。I-DRUID 的切入点在于同时解决特征解耦与数据泛化两个问题，通过显式约束分离语义特征，并利用非配对数据结合 RL 提升模型对新场景的适应能力。

## 核心方法

### 方法参照系

I-DRUID 基于适配器注入布局信息的标准 L2I 流程，但在特征提取与训练策略上进行了重构。与 GLIGEN 或 InstanceDiff 等依赖交叉注意力直接融合布局与文本特征的方法不同，I-DRUID 引入了独立的实例解耦模块（IDM）对增强特征进行加权分离，并将训练过程分为监督学习与强化学习两个阶段，以应对配对数据稀缺问题。

### 实例解耦模块与约束

IDM 接收 $n+1$ 个增强特征 $E$（包含 $n$ 个实例特征与 1 个全局特征）及对应的布局掩码 $M$，通过特征分支与掩码分支计算通道级权重 $\alpha$。其核心创新在于实例解耦约束（IDC），要求语义相关特征 $R^+$ 触发的注意力图比虚假特征 $R^-$ 更精确地聚焦于实例边界框内。IDC 通过比较两者在背景区域的注意力偏差来定义损失：

$$
\mathcal{L}_{dis} = \text{Softplus}(\text{CAS}(R^+) - \text{CAS}(R^-))
$$

其中 $\text{CAS}(R)$ 衡量特征 $R$ 在实例掩码外区域的平均注意力值。最小化该损失迫使 $R^+$ 在背景区域产生更低的注意力响应，从而在生成过程中抑制跨实例的特征混淆，从根源上解决属性泄漏。

### 基于非配对数据的强化学习

针对 MM-DiT 确定性 ODE 流程难以进行环境探索的问题，I-DRUID 将 ODE 采样转换为随机微分方程（SDE）以引入随机性，构建 RL 环境。状态 $s_t$ 定义为当前潜变量、时间步及条件信息，动作 $a_t$ 为去噪后的潜变量。奖励函数由 VLM 对生成图像的空间准确性与实例一致性评分构成。通过 PPO 算法优化策略网络，模型仅利用提示词（无图像配对）数据学习生成策略。这一设计使得模型无需收集昂贵的配对数据，即可通过 AI 反馈在新场景提示词上提升泛化能力，且 IDM 提供的更纯净特征为 RL 提供了更准确的初始策略，两者形成协同效应。

## 实验评估

| 方法 | 骨干 | COCO-MIG Avg ISR (%) | COCO-MIG Avg mIoU (%) | LayoutSAM-eval FID |
| :--- | :--- | :--- | :--- | :--- |
| MIGC | UNet | 59.68 | 52.60 | - |
| Creati-Layout | SD3 | 57.67 | 50.94 | 19.10 |
| I-DRUID | SD-1.5 | 69.13 | 68.18 | 17.95 |
| I-DRUID | SD3 | 62.75 | 55.60 | 17.21 |

实验在 COCO-MIG 和 LayoutSAM-eval 上进行，基线涵盖 BoxDiff、GLIGEN、MIGC 及 Creati-Layout 等主流方法。I-DRUID 在 SD-1.5 骨干下取得最高 ISR（69.13%），显著优于 MIGC（59.68%）；在 SD3 骨干下，其 FID（17.21）优于 Creati-Layout（19.10），但 ISR（62.75%）低于 SD-1.5 版本，表明 MM-DiT 架构下 RL 的探索效率可能受限。

消融实验显示，引入 IDC 使 COCO-MIG Avg ISR 从 56.82% 提升至 57.64%，而加入 RL 后进一步提升至 62.75%（SD3）。值得注意的是，使用配对数据进行监督微调（SFT）在 COCO-MIG 上表现更好（66.92%），但在 LayoutSAM-eval 上性能下降，证实了 SFT 存在域差距问题，而 RL 在非配对数据上展现了更稳定的泛化能力。PPO 与 GRPO 对比显示，PPO 训练速度更快（15s/iter vs 60s/iter），且性能相当。

评估协议依赖 Grounded-SAM 进行空间检测，可能引入检测误差。论文未提供代码，但详细列出了超参数（如学习率 $1 \times 10^{-4}$，RL 前 10 个 epoch 不启用）。SD3 版本性能低于 SD-1.5 版本，暗示确定性 ODE 向 SDE 转换的探索噪声可能不足以充分优化复杂布局，或 VLM 奖励信号在高分辨率 MM-DiT 生成中不够敏感。

## 关联研究分析

从问题动机看，I-DRUID 与 InstanceDiff 均关注属性泄漏，但 InstanceDiff 依赖注意力图的后处理操纵，而 I-DRUID 通过 IDC 在特征层面进行显式解耦。这种差异源于 I-DRUID 对 MM-DiT 架构的适配需求，MM-DiT 的联合注意力机制使得后处理操纵更加困难，迫使方法转向特征解耦。然而，IDC 的约束是否过度限制了特征的表达能力，特别是在复杂背景下的语义融合，论文未给出深入分析。

从方法设计看，I-DRUID 的 RL 框架与 DPOK 等早期扩散 RL 方法不同，后者依赖生成轨迹的随机性，而 I-DRUID 通过 SDE 转换解决 MM-DiT 的确定性探索问题。与 LayoutGPT 等基于 LLM 的布局生成方法相比，I-DRUID 保留了扩散模型的像素级生成能力，但引入了 VLM 作为奖励模型。这种设计将布局生成的语义理解与像素生成解耦，但 VLM 评估的偏差可能直接传导至生成策略，导致模型学习错误的空间关系。

## 总结

I-DRUID 旨在解决 L2I 生成中属性泄漏与配对数据依赖导致的泛化不足问题。通过 IDC 约束实现特征解耦，并利用非配对数据 RL 提升新场景适应性，该方法在 SD-1.5 上取得 69.13% 的 ISR，在 SD3 上取得 17.21 的 FID。其边界在于 SD3 版本性能低于 SD-1.5，暗示 SDE 探索在确定性 ODE 架构中的效率瓶颈，以及 VLM 奖励信号对复杂空间关系的评估局限性。当 VLM 对细微空间错误不敏感时，RL 是否仍能引导模型收敛到正确的布局策略，论文未给出回答。
