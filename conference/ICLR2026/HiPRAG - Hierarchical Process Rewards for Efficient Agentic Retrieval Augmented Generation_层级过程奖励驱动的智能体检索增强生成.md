> 智能体检索增强生成（Agentic RAG）旨在让大语言模型（LLM）自主规划多步搜索以获取外部知识，但现有强化学习（RL）训练仅依赖最终答案正确性，导致智能体普遍存在过度搜索与搜索不足的低效行为。HiPRAG 通过引入层级过程奖励，在训练时实时解析推理轨迹并验证每步搜索的必要性，从而在保障答案准确性的同时大幅降低冗余检索。该方法在七个问答基准上实现了 67.2% 的平均准确率，并将过度搜索率从 27% 降至 2.3%，但其依赖外部 LLM 进行在线验证的机制在计算开销与可扩展性上仍存疑。

## 研究背景

当 LLM 面对需要多跳推理的复杂查询时，其参数化知识的时效性滞后与事实幻觉迫使系统引入外部检索。然而，传统的静态检索增强生成（RAG）管道无法根据中间结果动态调整查询，而 ReAct 等框架虽赋予模型工具调用能力，却未解决“何时搜索”与“搜索什么”的决策优化问题。这一决策失误表现为过度搜索（Over-search，发出冗余检索）与搜索不足（Under-search，必要检索缺失），二者共同削弱了智能体的推理效率与最终答案的可靠性。

现有 RL 训练方法主要依赖可验证奖励（RLVR），仅以最终答案正确性作为信号，无法指导中间查询的质量。部分研究尝试引入长度惩罚或模型置信度作为代理指标，但长度惩罚易导致模型完全回避搜索，置信度阈值则因判断不准而引入偏差。这些方法均未对每个检索决策提供细粒度的步骤级反馈，导致长轨迹中的信用分配难题无法有效解决。HiPRAG 的切入点在于将过程奖励与在线验证结合，直接评估每步搜索的必要性，而非依赖静态代理指标。
