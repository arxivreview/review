# ICLR2026最新论文 ｜Distributionally Robust Cooperative Multi-Agent Reinforcement Learning via Robust Value Factorization ｜分布鲁棒合作多智能体强化学习

研究机构：腾讯AI实验室、美国加州理工学院

作者：Chengrui Qu、Christopher Yeh、Kishan Panaganti 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.11437)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.11437)

> 合作型多智能体强化学习在部署时面临环境模型失配导致的协调失效，传统集中训练去中心化执行范式下的价值分解方法无法保证鲁棒性。现有单智能体分布鲁棒强化学习直接迁移至多智能体场景时，个体最坏情况与团队最坏情况的不一致破坏了去中心化贪心执行的对齐性。本文提出分布鲁棒个体-全局最大原则，通过基于全局最坏情况模型定义鲁棒个体价值函数，实现了鲁棒价值分解。该方法在SustainGym和SMAC上验证了分布外性能的提升，但缺乏对连续控制复杂任务及大规模异构智能体系统的测试，其鲁棒性增益在分布内性能上的普遍性存疑。

## 研究背景

合作型多智能体强化学习依赖集中训练去中心化执行范式，训练时利用全局信息优化联合策略，执行时各智能体仅基于局部历史独立决策。这一范式通过价值分解方法实现，其核心是个体-全局最大原则，即个体贪心动作需与团队最优联合动作对齐。当部署环境存在模型失配、系统噪声或仿真到现实的差距时，这种对齐性极易被破坏，导致团队性能急剧下降。

环境不确定性在单智能体强化学习中可通过分布鲁棒优化缓解，但在合作多智能体场景中，部分可观测性和智能体间耦合使得微小失配级联为协调失败。主流鲁棒多智能体强化学习研究多针对对抗队友或状态扰动，针对模型不确定性的工作往往假设完全可观测或个体奖励，缺乏对共享团队奖励下部分可观测场景的系统处理。本文切入点在于解决鲁棒个体价值函数定义与去中心化执行一致性的矛盾，即如何在保证团队鲁棒性的同时，维持个体贪心动作与团队鲁棒最优动作的对齐。

## 核心方法

### 鲁棒价值分解参照系

标准价值分解方法如QMIX通过单调混合网络将联合价值函数分解为个体价值函数之和，确保个体贪心动作恢复团队最优联合动作。本文问题与该通用流程的关键差异在于，训练目标从标准贝尔曼算子替换为分布鲁棒贝尔曼算子，且个体价值函数需基于全局最坏情况模型定义，而非个体最坏情况。

### 分布鲁棒个体-全局最大原则

设计动机在于解决单智能体分布鲁棒强化学习中个体最坏情况模型与团队最坏情况模型不一致导致的对齐失效。本文提出分布鲁棒个体-全局最大原则，要求鲁棒个体贪心动作与鲁棒团队最优联合动作对齐。该原则的充分条件是基于全局最坏情况模型定义鲁棒个体价值函数：

$$Q_{\text{rob}}^i(h_i, a_i) = \inf_{P \in \mathcal{P}} Q_P^i(h_i, a_i) \quad \text{where} \quad P^* = \arg\min_{P \in \mathcal{P}} Q_P^{\text{tot}}(h, a^*)$$

其中 $P^*$ 是使联合价值函数最小化的全局最坏情况模型，$a^*$ 是鲁棒团队最优联合动作。这一构造确保所有智能体针对共享的对抗模型进行协调，而非各自独立的最坏情况，从而保证去中心化贪心执行的一致性。

### 鲁棒贝尔曼算子与价值分解变体

设计动机在于将分布鲁棒优化原则具体化为可训练的损失函数。本文推导了两种不确定性集下的鲁棒贝尔曼算子：$\rho$-污染集和总变差集。对于 $\rho$-污染集，鲁棒贝尔曼算子为：

$$\mathcal{T}^{\text{rob}} Q(h, a) = r(h, a) + \gamma \left[ (1-\rho) \mathbb{E}_{P_0}[Q(h', a')] + \rho \min_{P \in \mathcal{P}} \mathbb{E}_{P}[Q(h', a')] \right]$$

该算子通过凸组合名义模型期望和最坏情况模型期望，显式建模模型不确定性。基于此，本文推导了VDN、QMIX和QTRAN的鲁棒变体，通过鲁棒Q目标训练个体价值网络，同时保持CTDE信息结构。QMIX变体通过超网络生成混合参数，确保单调性约束在鲁棒设定下依然成立，使得鲁棒个体价值函数自动满足分布鲁棒个体-全局最大原则。

## 实验评估

实验在SustainGym HVAC控制任务和SMAC 3s5z地图上进行，基线包括非鲁棒价值分解方法（VDN/QMIX/QTRAN）和GroupDR鲁棒基线。SustainGym实验测试季节性分布偏移，SMAC实验通过向敌方单位位置观测添加高斯噪声模拟分布偏移。

| 方法 | SustainGym (TV) | SustainGym (ρ) | SMAC (ρ) |
| :--- | :--- | :--- | :--- |
| QMIX-DrIGM | **0.520±0.048** | **0.500±0.075** | **0.911±0.005** |
| QTRAN-DrIGM | **0.733±0.026** | **0.682±0.026** | — |
| GroupDR | 0.383±0.053 | 0.520±0.049 | 0.499±0.022 |
| 非鲁棒QMIX | 0.478±0.052 | 0.895±0.008 | 0.895±0.008 |

QTRAN-DrIGM在SustainGym上达到0.733±0.026，显著优于非鲁棒基线0.654±0.066和GroupDR 0.520±0.049。SMAC实验中，QMIX-DrIGM在小$\rho$值下显著改善分布外性能，但未报告具体胜率数值，仅展示趋势图。

消融实验显示，TV不确定性集在SustainGym上表现优于$\rho$-污染集，QTRAN架构在鲁棒设定下稳定性最强。反直觉发现是鲁棒训练有时能提升分布内性能，这与单智能体分布鲁棒强化学习中保守性惩罚分布内回报的经验相悖，表明在合作多智能体系统中，鲁棒性可同时增强稳定性和适应性。

评估边界方面，SMAC实验缺乏定量胜率对比，无法与领域SOTA直接比较。SustainGym实验仅测试季节性偏移，未覆盖更复杂的动态分布偏移。代码已开源，但超参数选择依赖验证集调优，缺乏统一的带宽-鲁棒性权衡基准。

## 关联研究分析

从问题动机看，本文与GroupDR的核心差异在于鲁棒性定义层面。GroupDR采用组策略鲁棒优化，关注团队整体策略在不确定性下的表现；本文则聚焦个体价值函数定义，通过全局最坏情况模型保证个体-全局对齐。这一差异源于任务特性：合作多智能体系统中，个体动作的鲁棒性必须与团队协调一致，而组策略优化可能忽略个体层面的对齐约束。

从方法设计看，本文与MADDPG同属CTDE范式，但MADDPG使用集中式评论家评估个体行为，本文使用鲁棒贝尔曼算子训练个体价值函数。MADDPG假设环境平稳，本文显式建模环境不确定性集。这一差异暗示，在模型失配场景下，集中式评论家的非平稳性缓解能力可能不足以应对分布偏移，需要更底层的鲁棒价值函数定义。

## 总结

本文解决的核心矛盾是分布鲁棒优化与去中心化执行一致性的冲突。现有单智能体分布鲁棒强化学习直接迁移至多智能体场景时，个体最坏情况与团队最坏情况的不一致破坏了价值分解的对齐性，而本文通过基于全局最坏情况模型定义鲁棒个体价值函数，实现了分布鲁棒个体-全局最大原则。该方法在SustainGym上达到0.733±0.026的分布外性能，显著优于非鲁棒基线和GroupDR。本文的边界在于仅测试了SustainGym和SMAC，缺乏对连续控制复杂任务及大规模异构智能体系统的验证，且SMAC实验缺乏定量胜率对比。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
