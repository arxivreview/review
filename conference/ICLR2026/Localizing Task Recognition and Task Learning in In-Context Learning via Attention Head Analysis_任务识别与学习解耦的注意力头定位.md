# ICLR2026最新论文 ｜Localizing Task Recognition and Task Learning in In-Context Learning via Attention Head Analysis ｜任务识别与学习解耦的注意力头定位

研究机构：美国芝加哥大学、日本东北大学

作者：Haolin Yang、Hakaze Cho、Naoya Inoue

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_89127397)

> 导读 上下文学习（ICL）的机制解释长期受困于“功能分解”与“组件定位”的割裂：行为实验能区分任务识别（TR）与任务学习（TL），却无法指出具体由哪些注意力头执行；而归纳头（IH）等电路分析虽定位了组件，却只能测量性能变化幅度，无法解释其几何作用机制。本文切入点在于将TR/TL的功能定义转化为任务子空间上的几何投影度量，从而将抽象功能映射到具体注意力头。通过提出任务子空间logit归因（TSLA）方法，本文识别出TR头与TL头，并证明前者对齐隐藏状态至任务子空间，后者在子空间内旋转至正确标签。该工作统一了IH与任务向量的解释，但在开放生成任务中任务子空间的定义仍存疑，且未提供性能提升数值。

## 研究背景

Transformer电路形式化将输出logits分解为注意力头与MLP输出的线性加和，这一框架使得对单个组件的贡献归因成为可能。然而，直接logit归因（DLA）仅计算头输出与标签unembedding的点积，忽略了标签间的竞争关系：一个头可能同时提升正确标签与错误标签的logits，导致无法区分真正的任务映射头与仅放大标签空间的头。这种归因模糊性使得IH等关键电路的功能定位停留在“影响大小”层面，无法揭示其如何具体执行ICL。

ICL机制研究存在两条主流路线：内省范式通过消融注意力头测量性能变化，如IH消融导致准确率下降，但无法解释头在输入变化下的行为；整体范式通过扰动演示标签将ICL分解为TR与TL，但无法追溯这些功能到具体组件。两条路线的割裂导致IH与TR/TL的关系长期存在争议：部分研究认为IH识别正确标签，另一些则指出IH可能误导预测。本文的切入点在于构建一个统一的几何框架，将TR/TL的功能定义转化为可计算的子空间投影指标，从而在组件层面实现功能定位。

## 核心方法

### 电路形式化与DLA局限

本文基于Transformer电路形式化，将最终隐藏状态表示为所有注意力头输出与MLP输出的加和。DLA方法通过计算 $\mathbf{W}^U_{y^*} \mathbf{a}^{[l]}_{N,k}$ 识别TL头，通过 $\mathbf{1}^\top \mathbf{W}^U_Y \mathbf{a}^{[l]}_{N,k}$ 识别TR头。然而，DLA存在两个根本缺陷：其一，TR头识别依赖于具体演示标签，当标签从“positive/negative”替换为“favourable/unfavourable”时，同一组头可能失效；其二，TL头识别忽略标签竞争，无法区分真正映射文本-标签关系的头与仅放大所有标签logits的头。

### TSLA：任务子空间几何投影

TSLA的核心创新在于将TR/TL识别转化为任务子空间上的几何投影问题。对于TR头，定义TR分数为头输出在任务子空间上的投影范数：

$$
\text{TR}_{l,k} = \left\| \text{Proj}_{\mathbf{W}^U_Y} \mathbf{a}^{[l]}_{N,k} \right\|_2
$$

其中 $\text{Proj}_{\mathbf{W}^U_Y} = \mathbf{W}^U_Y (\mathbf{W}^U_Y{}^\top \mathbf{W}^U_Y)^{-1} \mathbf{W}^U_Y{}^\top$ 是到演示标签unembedding张成子空间的投影矩阵。该公式的物理含义是：TR头应将其输出能量集中在任务子空间内，而非分散到其他语义方向。

对于TL头，定义TL分数为头输出在任务子空间内沿“正确-错误”平均方向的投影：

$$
\text{TL}_{l,k} = \frac{\left\| \text{Proj}_{\mathbf{W}^U_Y} \left( \mathbf{a}^{[l]}_{N,k} - \frac{1}{|\mathcal{Y}|-1} \sum_{y' \in \mathcal{Y} \setminus \{y^*\}} \mathbf{W}^U_{y'} \right) \right\|_2}{\text{TR}_{l,k}}
$$

分子测量头输出在任务子空间内区分正确标签与竞争标签的能力，分母归一化TR分数以隔离子空间内的旋转效应。该设计解决了DLA的标签竞争问题：只有那些在子空间内明确偏向正确标签而非所有标签的头，才能获得高TL分数。

## 实验评估

实验在Llama3-8B、Qwen2-7B等6个模型上，使用SST-2、TREC等7个分类数据集，采用8-shot ICL协议。基线包括DLA、随机头、IH消融，但缺失与Function Vector Heads等同类几何方法的直接对比。主实验结果显示，TR头与IH的Jaccard系数在top 3%水平显著高于TR-TL或TL-IH对，且TR头在深层分布更集中。

| 指标 | TR-IH | TL-IH | TR-TL |
| :--- | :--- | :--- | :--- |
| Jaccard Coefficient (3%) | 0.47 | 0.12 | 0.1860 |
| Spearman’s ρ | 0.92 | 0.13 | 0.2980 |
| Kendall’s τ | 0.76 | 0.09 | 0.1860 |

消融实验验证了TR/TL的可分离性：消融top 3% TR头导致准确率降至随机猜测水平（40.48%），而消融TL头仅降低准确率但不破坏任务识别。在翻转演示标签的实验中，消融TL头反而提升准确率，证实TL头捕获的是具体的文本-标签映射而非标签空间本身。

评估边界方面，本文未报告SST-2绝对准确率提升，而是聚焦机制验证；代码已开源，但超参数（如top 3%阈值）的敏感性分析仅在附录中简要提及。多模态或长上下文场景下的TSLA有效性未测试，任务子空间在开放生成任务中的定义仍不明确。

## 关联研究分析

从问题动机看，本文与Pan et al. (2023)的TR/TL行为分解共享功能定义，但关键差异在于定位粒度：Pan et al. 通过输入扰动观察性能变化，无法区分TR/TL由哪些头执行；本文通过TSLA将功能映射到具体头，实现了从“行为”到“组件”的因果闭环。这一差异源于任务特性：分类任务中标签空间有限且固定，使得任务子空间定义清晰；而在开放生成任务中，标签空间动态变化，TSLA的子空间假设可能失效。

从方法设计看，本文与Olsson et al. (2022)的IH电路分析同属内省范式，但IH识别基于注意力模式匹配（搜索前序token并复制后续token），而TSLA基于几何投影。IH是TR头的子集这一发现解释了IH为何能恢复零样本性能：IH通过对齐任务子空间实现标签识别，而非直接映射文本-标签关系。这一统一框架澄清了IH与任务向量的关系：TR头输出构成有效任务向量，因其几何效应是子空间对齐而非logit放大。

## 总结

本文要解决的核心矛盾是ICL功能分解与组件定位的割裂。现有方法要么停留在行为层面（TR/TL扰动实验），要么仅测量性能变化（IH消融），无法建立功能与组件的因果映射。本文抓住的切入点是任务子空间几何，将TR/TL定义转化为可计算的投影指标，从而在组件层面实现功能定位。TSLA方法识别出TR头与TL头，证明前者对齐任务子空间，后者在子空间内旋转至正确标签。消融实验证实TR头消融导致任务识别崩塌，TL头消融仅降低准确率，验证了可分离性。本文的边界在于任务子空间假设在开放生成任务中的适用性未验证，且未提供性能提升数值。当演示标签从固定集合扩展为动态生成时，TSLA的子空间定义是否仍能准确捕获TR功能，论文未给出回答。
