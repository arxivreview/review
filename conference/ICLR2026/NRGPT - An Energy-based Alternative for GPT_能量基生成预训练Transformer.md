# ICLR2026最新论文 ｜NRGPT: An Energy-based Alternative for GPT ｜能量基生成预训练Transformer

研究机构：IBM研究院、美国布朗大学

作者：Nima Dehmamy、Benjamin Hoover、Bishwajit Saha 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.16762)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.16762)

> 自回归语言建模长期依赖固定深度的前向传播，难以从动力学角度解释推理过程。现有“Transformer即梯度下降”的理论多局限于线性简化或图像补全场景，无法直接适配因果生成任务。本文通过构造特定能量函数，将GPT的层间变换严格形式化为能量景观上的梯度下降过程，并证明了其渐近稳定性。该工作提供了统一的理论视角，但实验规模较小，且未验证在大规模任务上的性能优势。

## 研究背景

理解本文需厘清能量基模型（Energy-Based Model, EBM）与自回归生成的关系。EBM将神经网络操作定义为标量能量函数的优化，数据分布对应能量极小值。然而，传统EBM如Hopfield网络适用于静态模式补全，而GPT要求每个Token演变为序列中的下一个Token，这种动态演化过程缺乏明确的能量定义。此前研究如Von Oswald et al. (2023) 指出上下文学习隐含梯度下降机制，但仅在线性Transformer中成立，忽略了Softmax等非线性组件。

主流动态推理路线聚焦于计算资源分配，如早期退出或稀疏化，旨在减少冗余计算。然而，这些方法多基于启发式规则或离散路由，缺乏对推理过程内在动力学的理论解释。现有工作如Energy Transformer (Hoover et al., 2023) 虽尝试统一Transformer与EBM，但其架构设计不适用于无掩码Token的因果生成场景。本文切入点在于设计一种能量函数，使其梯度更新规则在数学结构上等价于标准Transformer层，从而将GPT推理重构为能量景观上的粒子运动。

## 核心方法

### 方法参照系

标准GPT采用多层堆叠结构，每层独立参数，通过前向传播映射输入序列至下一Token。本文将其置于“递归单模块”框架下，关键差异在于：标准层间无权重共享，而本文通过递归应用同一NRGPT块模拟深度，且层间变换由能量梯度驱动而非直接矩阵乘法。

### 能量函数构造

设计动机在于解决传统EBM无法处理因果Token演化的问题。本文定义总能量 $E = E_{AT} + E_{FF}$，其中注意力能量 $E_{AT}$ 和前馈能量 $E_{FF}$ 分别对应Transformer的注意力与前馈模块。

$$
E_{AT} = \sum_{A} \sum_{h} \alpha_h \left( \log \sum_{B \neq A} \exp(\mathbf{g}_A^T \mathbf{J}_h \mathbf{g}_B) - \mathbf{g}_A^T \mathbf{J}_h \mathbf{g}_A \right)
$$

该公式表明，注意力能量由Token间交互的指数项构成，其梯度更新 $\mathbf{x}_{A}^{[t+1]} = \mathbf{x}_{A}^{[t]} - \eta \nabla_{\mathbf{g}_A} E_{AT}$ 在结构上等价于多头注意力输出，其中 $\mathbf{J}_h = \mathbf{W}_K^T \mathbf{W}_Q$ 替代了传统的Value-Projection权重组合。

### 推理率与稳定性

设计动机在于确保能量下降的收敛性。本文引入推理率矩阵 $\eta$，并证明当 $\eta = c \text{diag}(\gamma)$ 时，能量在瞬态阶段后单调递减。

$$
\dot{E}_A = E_A^{[t+1]} - E_A^{[t]} < 0, \quad \text{if } \eta = c \text{diag}(\gamma), c > 0
$$

这一性质源于因果注意力掩码导致的Token依赖顺序：前序Token收敛后，后续Token的能量更新受限于已稳定的状态，从而保证全局渐近稳定。该机制避免了传统递归网络中常见的振荡或不收敛问题，为固定步数推理提供了理论保障。

## 实验评估

实验在ListOps、Shakespeare和Open Web Text (OWT) 上进行，基线包括标准GPT-2风格模型和递归GPT (GPT_Rec_parallel)。对比路线覆盖静态深度模型与简单递归模型，但缺失动态早退（如LEAP）或稀疏化（如SHRP）等动态推理基线，限制了与领域主流方法的直接比较。

| 模型 | 参数量 | OWT困惑度 | 语法质量分数 |
| :--- | :--- | :--- | :--- |
| GPT | 124M | 2.905±0.006 | 0.978 |
| GPT_Rec_parallel | 85M | 3.447±0.046 | 0.976 |
| NRGPT_H_FF2W | 90M | 3.456±0.076 | 0.966 |

NRGPT_H_FF2W在OWT上的困惑度（3.456）略高于递归GPT（3.447），但显著低于标准GPT（2.905）。这表明在相同宽度配置下，递归能量下降结构未能完全匹配深层独立参数模型的表达能力，尽管其参数量（90M）少于标准GPT（124M）。

消融实验显示，NRGPT_H_FF1在ListOps上的学习转换点（2.4×10⁴参数）早于基线（2.3×10⁴参数），表明残差FF变体在小规模代数任务上具有参数效率优势。然而，在OWT等复杂语言任务上，FF2W变体表现更优，暗示不同能量函数形式对任务复杂度的敏感性。

评估边界方面，论文未报告计算延迟或FLOPs，仅关注参数效率与生成质量。代码未公开，超参数细节见附录F，可复现性受限。指标涵盖困惑度、语法质量分数及多样性分数，但未包含下游任务（如MMLU）的详细对比，尽管正文提及在MMLU上有优势。

## 关联研究分析

从问题动机看，NRGPT与动态早退方法（如LEAP）存在根本差异。LEAP通过修改蒸馏目标恢复层间收敛性以实现早退，依赖输入难度的显式判断；而NRGPT通过能量下降动力学隐式决定计算深度，无需额外退出判据。这种差异源于任务特性：LEAP针对固定架构的压缩，NRGPT重构架构本身。NRGPT的固定递归步数是否违背了“输入难度自适应”的领域共识？论文未提供变长推理的实验证据，仅验证了固定步数下的收敛性。

从方法设计看，NRGPT与Energy Transformer (ET) 同属EBM框架，但ET面向图像补全，其能量函数假设部分Token固定、部分演化；NRGPT面向因果生成，所有Token均需演化至下一状态。这一差异导致ET无法直接应用于GPT场景，而NRGPT通过引入推理率矩阵 $\eta$ 和因果掩码下的能量定义解决了该问题。然而，NRGPT的权重共享机制（递归单模块）可能限制了模型容量上限，这在OWT困惑度高于标准GPT的结果中有所体现。

## 总结

本文核心矛盾在于GPT前向传播缺乏动力学解释，现有理论无法适配因果生成。切入点在于构造能量函数使梯度更新等价于Transformer层，凭借数学推导证明渐近稳定性。方法上，NRGPT通过递归应用能量下降模块替代多层堆叠。实验证明，NRGPT_H_FF2W在OWT上以90M参数达到3.456困惑度，接近递归GPT但低于标准GPT。边界在于固定递归步数未验证输入自适应能力，且小规模实验未揭示大规模扩展规律。当序列长度增加时，能量收敛速度是否线性增长，从而限制推理延迟，论文未给出回答。
