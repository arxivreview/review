> 符号回归旨在从数据中恢复可解释的数学表达式，但现有方法常截断“假设-实验-分析”的科学闭环，仅完成假设生成与误差评估，缺乏将观测误差转化为结构化修正指引的机制。本文提出 RESTART 框架，通过求解符号子问题显式建模未解释信号，并引入长期结构库累积有效修正，实现 LLM 驱动的迭代细化。该框架在 LLM-SRBench 上显著优于基线，尤其在分布外泛化上表现稳健，但其对复杂常数项的恢复能力仍受限于底层求解器精度。

## 研究背景

符号回归（Symbolic Regression, SR）的核心挑战在于离散符号空间的组合爆炸。给定观测数据 $\mathcal{D}$，寻找最小化经验风险且满足复杂度约束的表达式 $f(x; \theta)$ 是 NP-hard 问题。传统遗传编程（Genetic Programming, GP）通过随机变异与交叉遍历树空间，但收敛缓慢且易陷入局部最优；映射式方法（如 Transformer）虽能生成强初始假设，却缺乏基于误差模式的迭代修正机制，在分布外（Out-of-Distribution, OOD）场景下表现脆弱。

LLM 的引入为 SR 提供了语义先验，但多数现有工作仅利用 LLM 生成候选方程并反馈损失值，未建立从误差到结构修正的因果链路。这种“黑箱”反馈导致 LLM 难以定位具体缺失项，易产生幻觉或过拟合噪声。本文切入点在于将科学发现的“分析”阶段算法化：不直接反馈标量损失，而是求解一个辅助符号子问题，将当前假设的未解释部分显式建模为可执行的代码片段，从而为 LLM 提供高精度的局部修正指引。

## 核心方法

### 方法参照系

本文属于 LLM 驱动搜索路线，其标准流程为：LLM 生成候选方程 $\to$ 数值评估损失 $\to$ 反馈损失值给 LLM $\to$ 生成新候选。本文的关键差异在于将“反馈损失值”替换为“反馈误差结构”，即通过求解辅助子问题 $g(f(x), x)$ 获取当前假设 $f(x)$ 与真实值 $y$ 之间的残差模式，并将该模式作为提示工程的核心组件。

### 短期引导：误差结构显式建模

在迭代 $t$ 中，当前假设 $f_t$ 的失效往往源于特定非线性项的缺失或参数偏差。传统方法仅告知 LLM“误差很大”，而 RESTART 通过求解以下子问题，将误差转化为具体的函数形式：

$$ g_t = \arg\min_{g \in \mathcal{G}} \sum_{i=1}^N (y_i - g(f_t(x_i), x_i))^2 $$

其中 $\mathcal{G}$ 为符号函数类。该公式的物理含义是：寻找一个函数 $g_t$，它接收当前预测值 $f_t(x_i)$ 和原始特征 $x_i$，输出对预测值的修正量，使得修正后的结果最接近真实值 $y_i$。这一设计解决了 LLM 无法从标量损失中推断具体缺失结构的问题，例如当 $f_t$ 缺失正弦项时，$g_t$ 会显式呈现正弦相关的残差模式，直接引导 LLM 补全该结构。

### 长期引导：验证性结构库累积

短期引导提供即时反馈，但可能导致对局部噪声的过拟合。为此，RESTART 引入长期结构库 $\mathcal{C}$，仅保留经过验证的高价值修正。当新假设 $f_{new}$ 的损失 $l_{new}$ 显著低于基准 $l_{base}$ 时，计算适应度分数 $s_{fit}$：

$$ s_{fit} = 100 \cdot (w_r s_r + w_a s_a) $$

其中 $s_r$ 为相对改进比率，$s_a$ 为绝对改进量。仅当 $s_{fit} \ge \alpha$ 时，LLM 才被提示总结该修正的结构特征（如代码片段 `np.sin(x)`）并存入库中。该机制通过门控策略防止库膨胀，确保后续迭代中 LLM 能复用已验证的物理结构模式，实现跨迭代的知识累积。

## 实验评估

实验基于 LLM-SRBench 基准，涵盖 Physics、Biology、Material Science 等域，对比 PySR（GP）、DSR（RL）、E2E（映射）、LLMSR（LLM）等基线。RESTART 在 Physics 域取得 0.003 NMSE 和 85.23% Acc，优于 LLMSR 的 0.004 NMSE 和 73.86% Acc；在 Biology 域取得 0.001 NMSE，显著优于 PySR 的 4.115 NMSE。

| 方法 | Physics NMSE | Physics Acc | Biology NMSE | Biology Acc |
| :--- | :--- | :--- | :--- | :--- |
| PySR | 7.151 | 62.50 | 4.115 | 96.00 |
| LLMSR | 0.004 | 73.86 | 0.084 | 96.00 |
| RESTART | 0.003 | 85.23 | 0.001 | 77.08 |

消融实验表明，移除短期引导或长期结构库均导致性能显著下降，验证了双通道引导的必要性。特别地，当将短期引导简化为仅拟合加性残差（Additive 变体）时，NMSE 大幅上升，证明性能增益源于结构性细化而非数值残差填补。

评估边界方面，论文未报告计算效率指标，且 LLM 骨干固定为 Qwen3-8B，未测试不同规模模型的影响。代码已开源，但超参数（如阈值 $\alpha$、库容量 $K$）的敏感性分析未在正文中详述，可能影响复现性。

## 关联研究分析

从问题动机看，RESTART 与 LLMSR 的核心差异在于反馈信号的粒度。LLMSR 依赖 LLM 的语义先验直接生成方程，反馈仅为损失值，导致在复杂方程中易遗漏关键项；RESTART 通过求解 $g(f(x), x)$ 子问题，将误差分解为可解释的结构模式，使 LLM 能针对性修正。这一差异源于任务特性：SR 的离散性要求反馈必须包含结构信息，而标量损失无法提供此类信息。

从方法设计看，RESTART 与 DiffuSR 等神经符号生成模型不同，后者端到端学习符号结构，缺乏显式的物理一致性检查；RESTART 保留 LLM 的符号推理能力，通过结构库累积验证过的物理模式，增强了科学一致性。然而，RESTART 依赖底层求解器（如 E2E）的精度，若求解器无法准确拟合 $g_t$，则短期引导的有效性受限。结构库容量 $K$ 的限制是否会导致复杂方程中关键结构的丢失，论文未给出回答。

## 总结

RESTART 针对 LLM 驱动符号回归中“误差反馈缺乏结构信息”的矛盾，通过求解符号子问题显式建模未解释信号，并引入门控结构库累积有效修正，实现了科学发现闭环的自动化。在 LLM-SRBench 上，RESTART 在 Physics 域取得 0.003 NMSE，在 Biology 域取得 0.001 NMSE，显著优于基线。其边界在于依赖底层求解器精度，且结构库容量限制可能影响复杂方程的发现。当底层求解器无法准确拟合高维非线性残差时，短期引导的结构信息是否仍能有效引导 LLM 修正，论文未给出回答。
