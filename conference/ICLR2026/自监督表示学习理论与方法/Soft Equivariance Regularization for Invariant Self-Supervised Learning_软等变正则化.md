# ICLR2026最新论文 ｜Soft Equivariance Regularization for Invariant Self-Supervised Learning ｜软等变正则化

研究机构：韩国科学技术院

作者：Joohyung Lee、Changhun Kim、Hyunsu Kim 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.06693)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.06693)

> 自监督学习（SSL）通过强制表示对语义保持的增强不变来提升识别能力，但这种强不变性往往抑制了方向、尺度等几何结构信息，导致模型在几何扰动和空间敏感任务中表现脆弱。现有方法将不变性与等变性目标同时施加于最终表示，却因最终层空间结构坍缩而陷入“等变分数升高但分类精度下降”的权衡困境。本文提出软等变正则化（SER），通过层解耦策略，在保留中间层空间结构的特征图上施加解析式群作用正则化，同时保持最终层不变性损失不变。该设计以极低的计算开销（1.008× FLOPs）提升了几何鲁棒性，但其收益是否随模型规模扩大而衰减，以及禁用裁剪对尺度鲁棒性的潜在影响，仍存疑。

## 研究背景

当视觉模型面对旋转或翻转的输入时，若其特征表示能随之发生可预测的结构性变化，则称该表示具有等变性（Equivariance）。然而，主流自监督学习范式追求的是不变性（Invariance），即无论输入如何增强，表示应保持恒定。不变性虽利于分类，却抹去了几何线索；而等变性保留了这些线索，但传统方法难以在大规模预训练中稳定引入。

SSL领域长期面临“增强依赖”与“信息丢失”的矛盾。SimCLR、MoCo等对比方法依赖随机裁剪等强增强，但裁剪不可逆，破坏了群作用的数学定义，使得无法在特征空间直接应用几何变换。EquiMod、STL等早期等变SSL方法试图通过辅助模块预测变换标签，或在最终层施加等变约束，但最终层通常是空间坍缩的[CLS]向量，无法承载精细的几何结构。这导致等变正则化越靠近输出层，分类性能越差。本文切入点在于：不变性与等变性不应在同一层、同一表示上竞争，而应在不同层、不同结构上解耦。

## 核心方法

### 方法参照系

标准不变性SSL流程（如MoCo-v3）将图像增强为两个视图，通过对比损失对齐最终嵌入。本文问题与该通用流程的关键差异在于：需在保持最终层不变性损失不变的前提下，于中间层引入显式等变约束，且该约束必须基于可逆几何变换，避免不可逆裁剪导致的群作用失效。

### 层解耦架构与解析式群作用

设计动机：最终层空间坍缩，无法定义自然的几何群作用；中间层保留空间token map，是施加等变正则化的理想位置。SER将ViT编码器分解为前缀编码器 $f^{(1)}$（输出空间token map）和后缀头 $f^{(2)}$（输出最终嵌入），[CLS] token仅在 $f^{(2)}$ 输入端插入，确保 $f^{(1)}$ 输出保持空间结构。对于可逆几何群 $G$（含90°旋转、翻转、无裁剪缩放），SER在特征空间直接应用解析式群作用 $\rho_g$，无需学习变换预测头。等变损失定义为：

$$
\mathcal{L}_{\text{equiv}} = \frac{1}{|b_2|} \sum_{i \in b_2} \frac{1}{H_f W_f} \sum_{j=0}^{H_f W_f - 1} \log \left( \frac{\exp(s(z_{ij}, \rho_g(z'_{ij})) / \tau)}{\sum_{k \neq i} \sum_{l} \exp(s(z_{ij}, \rho_g(z'_{kl})) / \tau)} \right)
$$

其中 $z_{ij}$ 为中间层特征，$\rho_g$ 为解析式群作用，$\tau$ 为温度系数。该损失鼓励中间层特征在几何变换下保持结构一致性，同时不干扰最终层的不变性优化。

### 批次分区与增强策略

设计动机：随机裁剪不可逆，无法定义群作用；需分离不变性与等变性的增强策略。SER将mini-batch分为 $b_1$ 和 $b_2$：$b_1$ 使用标准增强策略（含裁剪），仅贡献不变性损失；$b_2$ 使用等变视图策略 $T_{eq}$（禁用裁剪，保留光度抖动，采样可逆几何变换），同时贡献不变性损失和等变损失。总损失为：

$$
\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{inv}}(b_1) + \mathcal{L}_{\text{inv}}(b_2) + \lambda \mathcal{L}_{\text{equiv}}(b_2)
$$

其中 $\lambda$ 控制等变正则化强度。该策略确保等变约束仅作用于可逆几何变换，避免不可逆裁剪导致的群作用定义失效，同时保持不变性损失的完整性。

## 实验评估

实验在ImageNet-1k上预训练ViT-S/16，采用线性探测评估。基线覆盖MoCo-v3、DINO、Barlow Twins（不变性）及EquiMod、AugSelf、STL、E-SSL（等变性），但缺失I-JEPA等预测式基线。在严格匹配的2视图设置下，SER+MoCo-v3达到69.28% Top-1，较MoCo-v3基线（68.44%）提升0.84%，优于EquiMod（68.95%）和AugSelf（67.55%）。

| 方法 | 视图数 | ImageNet-1k Top-1 (%) | ImageNet-C Top-1 (%) | COCO mAP |
| :--- | :--- | :--- | :--- | :--- |
| MoCo-v3 | 2 | 68.44±0.07 | - | - |
| +SER | 2 | 69.28±0.01 | +1.11 | +1.7 |
| +EquiMod | 3 | 68.95±0.02 | - | - |
| +AugSelf | 2 | 67.55±0.05 | - | - |

消融实验显示，等变损失层位置对性能影响显著：Layer 3时Top-1为69.28%，Layer 12时降至68.18%，但等变分数从0.840升至0.924，证实了“等变分数升高但分类精度下降”的权衡。将层解耦策略应用于EquiMod（从Layer 12移至Layer 3）使其Top-1从68.95%提升至69.51%，表明层解耦是普适性设计原则。

评估边界：仅使用ViT-S/16，未验证ViT-L/g规模下的收益；禁用裁剪可能牺牲尺度鲁棒性，但ImageNet-P（几何扰动）提升+1.22%表明几何鲁棒性增强；代码开源，超参数完整，可复现性高。

## 关联研究分析

从问题动机看，SER与I-JEPA均旨在避免最终层信息坍缩，但机制不同：I-JEPA通过潜在空间预测缺失块嵌入，捕获语义抽象；SER通过中间层等变正则化，保留几何结构。I-JEPA的预测目标模糊，而SER的解析式群作用提供了明确的几何约束，但SER未探索预测式目标与等变正则化的结合。

从方法设计看，SER与EquiMod均引入等变约束，但EquiMod依赖辅助变换模块，SER使用解析式群作用。EquiMod的模块增加了计算开销和超参数调优难度，而SER的解析式动作无需额外训练，计算开销仅1.008× FLOPs。然而，SER的批次分区策略可能降低数据效率，$b_2$ 的等变视图策略禁用裁剪，是否导致模型对尺度变化的鲁棒性下降，论文未给出回答。

## 总结

SER解决的核心矛盾是强不变性抑制几何结构信息，导致模型在几何扰动和空间敏感任务中脆弱。其切入点在于层解耦：不变性与等变性在不同层、不同结构上优化，避免了最终层空间坍缩导致的群作用失效。SER通过解析式群作用在中间层施加等变正则化，保持最终层不变性损失不变，在ViT-S/16上实现+0.84% Top-1和+1.7 mAP COCO检测提升。其边界在于仅验证ViT-S/16规模，且禁用裁剪可能牺牲尺度鲁棒性。当模型规模扩大至ViT-g时，层解耦的收益是否随参数增加而衰减，论文未给出回答。
