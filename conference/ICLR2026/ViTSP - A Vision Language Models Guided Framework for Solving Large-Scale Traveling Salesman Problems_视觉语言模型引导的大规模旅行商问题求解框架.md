> 大规模组合优化问题在实例规模与分布偏离训练域时，传统神经求解器面临泛化失效与可扩展性瓶颈，而经典启发式算法依赖人工参数调优且难以自适应。本文切入点在于将预训练视觉语言模型（VLM）从端到端求解器重新定位为分解启发式组件，通过视觉识别子问题区域并交由精确求解器优化，实现免训练的大规模求解。ViTSP 框架异步协调 VLM 的 I/O 密集选择与求解器的 CPU 密集优化，在 1k-88k 节点 TSPLIB 实例上平均最优性差距达 0.24%，优于 LKH-3 的 0.31%。该范式验证了多模态大模型在组合优化中的实用价值，但其对 VLM API 延迟的依赖及子问题规模阈值设定仍需进一步量化评估。

## 研究背景

组合优化问题如旅行商问题（TSP）要求寻找最小化总路径长度的哈密顿环，其 NP-hard 特性导致精确算法在规模增长时计算时间不可控。传统神经组合优化（NCO）方法通过图神经网络（GNN）或 Transformer 编码实例特征，利用强化学习（RL）训练策略网络进行自回归或非自回归构造，但在分布外（OOD）实例上泛化能力显著下降，且 Transformer 的二次复杂度限制了大规模实例的推理效率。

NCO 领域的主流路线在解质量与推理效率间做出不同取舍：自回归方法保证可行性但序列延迟高，非自回归方法并行推理快但约束处理复杂。当实例规模超过 1000 节点时，现有神经求解器如 AM、DIFUSCO 在 TSPLIB 真实分布实例上的最优性差距急剧扩大，部分方法甚至因 GPU 内存溢出（OOM）无法运行。经典启发式 LKH-3 虽为当前 SOTA，但其性能高度依赖实例特定的参数校准，缺乏对未知分布的自适应能力。

本文针对这一矛盾，提出利用预训练 VLM 的通用多模态推理能力替代领域特定的神经编码器。VLM 将 TSP 实例视为 2D 图像，通过视觉选择识别具有组合邻域结构的子问题区域，避免了传统 NCO 方法对固定训练数据的依赖。这一设计将分解启发式与精确求解器解耦，使框架无需针对特定 TSP 分布进行训练或微调，直接适配不同规模与分布的实例。

## 核心方法

### 方法参照系

本文问题属于神经启发式搜索改进路线，其标准流程为：神经模型编码实例特征 → 策略网络指导局部搜索或子问题选择 → 经典算法精调。关键差异在于，本文用预训练 VLM 替代 GNN/Transformer 编码器与策略网络，直接输出子问题坐标，且子问题优化由精确求解器而非学习式模型完成。

### 视觉子问题选择与缩放重选

传统分解方法依赖学习式模型预测子问题边界，但此类模型在 OOD 实例上预测精度下降。ViTSP 在视觉选择模块中，将当前全局解 $\Pi$ 的节点与连接绘制为图像，作为 VLM 的视觉提示。VLM 接收元指令 $I$、选择轨迹 $\Phi$ 和待处理子问题队列 $\Omega$ 作为文本输入，输出图像级坐标四元组 $C = (x_{min}, x_{max}, y_{min}, y_{max})$。该公式定义了子问题在图像空间中的边界，VLM 可单次生成 $Q \ge 2$ 个坐标集以并行处理。当子区域内节点数 $|W|$ 超过阈值 $\alpha$ 时，触发缩放重选机制：VLM 对初始区域进行二次放大，识别更细粒度的子区域 $C'$。这一设计解决了大规模实例中节点密集导致初始可视化连接不可辨识的问题，确保子问题规模在精确求解器可处理范围内。

### 子问题重构与异步编排

子问题 $\omega = (W, K)$ 包含自由节点集 $W$ 和固定线段集 $K$。为兼容精确求解器，ViTSP 将每个线段 $(\pi_k^1, \dots, \pi_k^{c_k})$ 聚合为超级节点 $s_k$，构建部分非对称 TSP（ATSP）距离矩阵 $D_{ATSP}$。由于现有精确求解器主要针对对称 TSP（STSP）设计，引入虚拟节点 $s'_k$ 将 ATSP 转化为 STSP，其对称块距离矩阵为：

$$
D_{STSP} = \begin{bmatrix} \infty & D_{|W|\times|K|}^T & \hat{D}_{|K|\times|K|}^T \\ D_{|W|\times|K|} & D_{|W|\times|W|} & D_{|K|\times|W|}^T \\ \hat{D}_{|K|\times|K|} & D_{|K|\times|W|} & \infty \end{bmatrix}
$$

其中 $\hat{D}_{|K|\times|K|}$ 对角线设为小值以鼓励超级节点与虚拟节点相邻连接。求解器优化 $D_{STSP}$ 后，移除虚拟节点并展开超级节点恢复原 TSP 解。由于 VLM 选择是 I/O 密集型而求解器是 CPU 密集型，ViTSP 采用异步编排：多个 VLM 与求解器并行运行，通过共享全局解 $\Pi$、轨迹池 $\Phi$ 和子问题队列 $\Omega$ 协调。P 个“从求解器”筛选改进子问题，单个“主求解器”更新 $\Pi$，直至连续 $K=5$ 步无改进。该机制消除了串行执行中的空闲时间，最大化求解器利用率。

## 实验评估

实验在 33 个 TSPLIB 实例（1k-88k 节点）和 16 个合成 TSP-10K 实例上进行，基线覆盖经典 OR 方法（Concorde, LKH-3, FI）和学习式方法（AM, DIFUSCO, INViT, SIT, DeepACO, SO, UDC, EoH）。学习式基线未包含最新生成式 SOTA（如 CycFlow, NEXCO）及线性复杂度架构（ECO），但覆盖了主流自回归与非自回归方法。

| 方法 | 平均最优性差距 (%) | 平均运行时间 (s) |
|---|---|---|
| ViTSP | 0.24 | 165.1 |
| LKH-3 (Default) | 0.31 | 47.0 |
| LKH-3 (more RUNS) | 0.18 | 165.1 |
| Concorde | 0.34 | 46.2 |
| SIT | 1.21 | 165.1 |
| DIFUSCO (S + 2-opt) | 7.83 | 23.6 |

ViTSP 在 33 个实例中的 20 个上取得最优性能，相对 LKH-3 的最优性差距降低 3.57% 至 100%。学习式方法在 OOD 实例上性能显著退化，AM 和 DeepACO 的差距超过 20%，部分方法在 pla85900 等大规模实例上 OOM。ViTSP 的运行时间包含 LKH-3 初始化、VLM API 延迟和 Concorde 求解时间，反映真实端到端耗时。

消融实验未单独报告，但设计决策验证显示：缩放重选机制在节点数超过阈值 $\alpha$ 时触发，确保子问题规模可控；异步编排中“从求解器”筛选机制避免了无效子问题对全局解的干扰。VLM 选择轨迹 $\Phi$ 作为记忆，使后续选择能利用前期求解揭示的实例结构，提升子问题质量。

评估边界方面，最优性差距基于 TSPLIB 已证明最优值计算，但运行时间受 VLM API 延迟影响，不同硬件和网络条件下结果可能波动。代码已开源，但 VLM 模型（GPT-4.1, o4-mini）的 API 依赖限制了可复现性，且未报告 GPU 内存占用细节。

## 关联研究分析

从方法设计看，ViTSP 与 NICO-TSP 同属神经启发式搜索改进路线，但 NICO-TSP 使用 GNN 建模 2-opt 动作空间，依赖训练数据学习局部改进策略，而 ViTSP 使用 VLM 直接输出子问题坐标，无需训练。这一差异源于任务特性：NICO-TSP 针对固定规模的 TSP 实例优化，而 ViTSP 需适配 1k-88k 节点的 OOD 实例，VLM 的通用推理能力更适合跨规模泛化。但 VLM 的视觉选择是否捕捉了组合邻域结构中的关键特征，而非仅依赖空间局部性，论文未提供细粒度分析。

从问题动机看，ViTSP 与 SIT 同属分解-求解范式，但 SIT 使用学习式模型分解子问题，ViTSP 使用 VLM 分解。SIT 在 TSP-10K 上训练后，在更大规模实例上性能仍不如 ViTSP，表明学习式分解器在 OOD 场景下的局限性。ViTSP 的免训练特性使其部署成本更低，但 VLM 推理延迟（平均 165.1s）远高于 SIT（165.1s 但含训练摊销），在实时性要求高的场景中，VLM 的 I/O 瓶颈可能成为制约。

## 总结

ViTSP 解决的核心矛盾是大规模 OOD TSP 实例中神经求解器泛化失效与经典启发式参数依赖的困境。其切入点在于利用预训练 VLM 的通用多模态推理能力替代领域特定编码器，通过视觉选择子问题并交由精确求解器优化，实现免训练的大规模求解。框架在 33 个 TSPLIB 实例上平均最优性差距 0.24%，优于 LKH-3 的 0.31%，在 20 个实例上取得最优性能。本文的边界在于 VLM API 延迟导致运行时间较长，且子问题规模阈值 $\alpha$ 的设定缺乏理论指导，可能影响不同分布实例的分解质量。当实例节点分布极度不均匀时，VLM 的视觉选择是否仍能准确识别具有组合邻域结构的子问题区域，论文未给出系统性验证。
