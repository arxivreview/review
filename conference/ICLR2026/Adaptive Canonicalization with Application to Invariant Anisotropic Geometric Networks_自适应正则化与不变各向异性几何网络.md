# ICLR2026最新论文 ｜Adaptive Canonicalization with Application to Invariant Anisotropic Geometric Networks ｜自适应正则化与不变各向异性几何网络

研究机构：德国慕尼黑工业大学、以色列理工学院

作者：Ya-Wei Eileen Lin、Ron Levie

论文原文见 [arXiv](https://arxiv.org/abs/2509.24886)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.24886)

> 等变机器学习旨在通过硬编码对称性结构提升模型泛化，但传统正则化策略常因映射不连续导致训练不稳定与理论缺陷。本文提出自适应正则化框架，使标准形式同时依赖输入与网络参数，通过先验最大化机制实现端到端连续性。该方法在分子、蛋白质及点云分类任务中验证了性能优势，但其在高维连续群上的计算效率与优化收敛性仍存疑。

## 研究背景

当分类器面对同一物体的不同旋转姿态时，若缺乏对称性约束，模型需为每个姿态学习独立特征，导致样本效率低下。解决此问题的核心概念是正则化（Canonicalization），即将输入映射至标准形式后再处理，以消除姿态冗余。然而，传统正则化仅依赖输入确定标准形式，这种静态映射在输入微小变化时可能引发标准形式的剧烈跳变，造成端到端架构的不连续性。不连续性不仅破坏训练稳定性，更使得通用逼近定理难以成立，因为连续函数无法被不连续网络有效逼近。

等变神经网络领域长期存在严格架构约束与数据噪声鲁棒性之间的张力。主流路线包括设计严格等变架构（如EGNNs）、数据增强及传统正则化。其中，传统正则化虽避免了架构设计的复杂性，但其固有的不连续性成为关键瓶颈，限制了其在复杂几何数据上的应用。本文切入点在于打破正则化仅依赖输入的局限，提出标准形式应同时依赖输入与网络参数，从而在保持对称性不变性的同时，恢复端到端模型的连续性与逼近能力。

## 核心方法

### 方法参照系

传统正则化流程将输入 $x$ 通过固定映射 $\beta_x$ 变换为标准形式 $\pi(\beta_x)x$，再送入非等变网络 $\Psi$。该流程的关键差异在于 $\beta_x$ 仅由 $x$ 决定，导致 $\pi(\beta_x)x$ 在 $x$ 的对称等价类边界处不连续。本文问题在于如何构造一个依赖网络参数 $\Psi$ 的映射，使得标准形式随网络学习动态调整，从而消除不连续性。

### 自适应正则化定义

设计动机在于解决传统正则化中标准形式跳变导致的训练不稳定。本文定义自适应正则化映射 $\rho_f: C_0(K, \mathbb{R}^D) \times G \to K$，其中 $f$ 为网络函数，$g$ 为输入。该映射需满足等连续性条件，即对于任意 $\epsilon > 0$，存在 $\delta > 0$，使得当 $\|f - y\|_\infty < \delta$ 时，对所有 $g \in G$，有 $|f(\rho_f(g)) - y(\rho_y(g))| < \epsilon$。这一条件确保了网络参数的微小变化不会引起输出的剧烈波动，从而保证了端到端模型的连续性。

### 先验最大化机制

设计动机在于为自适应正则化提供具体的优化目标，使标准形式选择能够最大化网络预测置信度。本文提出先验最大化自适应正则化，其中 $\rho_f(g)$ 定义为最大化网络先验的变换参数 $u^*$：

$$ u^* = \arg\max_{u \in U} h(f(\kappa_u(g))) $$

其中 $\kappa_u$ 为参数化变换族，$h$ 为先验函数（如分类概率）。该公式的物理含义是：网络通过搜索最优变换 $u^*$，将输入对齐至其“最自信”的姿态，而非固定姿态。这种机制借鉴了认知心理学中的“心理旋转”概念，允许网络在训练过程中动态学习最优参考系，从而在保持对称性不变性的同时，利用非等变网络的表达力。

## 实验评估

实验在ModelNet40点云分类、OGB分子/蛋白质分类及TUDataset图分类上进行。基线覆盖等变架构（VN-DGCNN）、传统正则化（CN-DGCNN）、数据增强（DGCNN-Aug）及谱图神经网络（NLSF, S2GNN）。缺失帧平均（FA）在点云任务上的直接对比，但FA在图任务中作为基线出现。

| 方法 | ModelNet40 Acc (%) | OGB-molhiv AUROC | OGB-molpcba AP | OGB-ppa Acc |
|---|---|---|---|---|
| DGCNN | 88.6* | - | - | - |
| VN-DGCNN | 90.2* | - | - | - |
| CN-DGCNN | 90.0* | - | - | - |
| AC-DGCNN | 91.6 ± 0.6 | - | - | - |
| GPS | - | 0.7880 ± 0.0101 | 0.2907 ± 0.0028 | 0.8015 ± 0.0033 |
| A-NLSF | - | 0.8019 ± 0.0152 | 0.2968 ± 0.0022 | 0.8149 ± 0.0067 |

AC-DGCNN在ModelNet40上以91.6%准确率超越VN-DGCNN（90.2%）和CN-DGCNN（90.0%），验证了自适应正则化在点云任务上的有效性。在OGB分子分类中，A-NLSF在ogbg-molhiv、ogbg-molpcba及ogbg-ppa上均优于GPS基线，表明该方法在大规模图数据上具有泛化优势。

消融实验未在正文中详细展开，但附录提及存在消融研究。从主结果看，AC-DGCNN较CN-DGCNN提升1.6个百分点，较VN-DGCNN提升1.4个百分点，提示自适应机制带来的收益主要源于连续性与动态参考系学习，而非单纯架构复杂度增加。在图分类任务中，A-NLSF在MUTAG数据集上达到87.94%准确率，显著高于NLSF（84.13%）和S2GNN（82.70%），但提升幅度在ENZYMES数据集上较小（73.01% vs 65.94%），暗示方法收益可能依赖于数据对称性结构。

评估边界方面，论文未报告计算效率指标，特别是先验最大化涉及的优化过程在连续群上的开销。代码未公开，超参数细节仅见于附录，可复现性受限。指标完备性上，缺乏对不连续性程度的直接量化指标（如Lipschitz常数），仅通过任务性能间接验证连续性收益。

## 关联研究分析

从问题动机看，本文与Kaba et al. (2023)的能量正则化方法同属正则化路线，但关键差异在于标准形式的依赖项。Kaba et al.通过最小化能量函数确定标准形式，该能量函数仅依赖输入，导致不连续性；本文引入网络参数依赖，使标准形式随网络学习动态调整。这一差异的根源在于任务特性：能量正则化假设存在固定的“最优姿态”，而本文假设最优姿态依赖于网络当前的表征能力。这种假设差异使得本文方法在对称性破坏场景下更具鲁棒性，但代价是优化过程的非凸性增加。

从方法设计看，本文与Puny et al. (2022)的帧平均方法形成对比。帧平均通过平均所有变换下的输出来实现等变性，计算开销随群大小线性增长，且无法处理无限维群；本文通过先验最大化选择单一最优变换，计算开销恒定，但依赖优化过程的收敛性。这一差异源于对对称性处理策略的不同：帧平均是“全量处理”，本文是“选择性处理”。选择性处理在计算效率上占优，但在对称性破坏严重时，单一最优变换可能无法充分代表对称等价类，导致性能下降。论文未探讨在何种对称性破坏程度下，选择性处理优于全量处理。

## 总结

本文核心矛盾在于传统正则化的不连续性与等变模型对连续性的理论需求。切入点在于将标准形式从输入依赖扩展为输入-网络联合依赖，通过先验最大化机制实现动态参考系学习。方法上，本文定义了等连续性条件并证明了通用逼近性，在ModelNet40上以91.6%准确率超越基线，在OGB分子分类中全面优于GPS。边界在于，先验最大化的优化过程在连续群上的计算效率未量化，且缺乏对不连续性程度的直接诊断指标。当群作用维度增加至SO(3)以上时，先验最大化搜索空间的非凸性是否导致收敛失败，论文未给出回答。
