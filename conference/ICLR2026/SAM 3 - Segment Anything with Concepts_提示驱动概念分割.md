# ICLR2026最新论文 ｜SAM 3: Segment Anything with Concepts ｜提示驱动概念分割

作者：Nicolas Carion、Laura Gustafson、Yuan-Ting Hu 等 38 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.16719)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.16719)

> 开放词汇分割领域长期受困于视觉-语言模型全局对齐特性与像素级空间定位需求之间的结构性矛盾，导致边界模糊与背景偏差。现有方案或依赖昂贵的像素级标注进行特征修正，或受限于免训练范式的性能上限，难以同时兼顾实例身份保持与复杂场景下的鲁棒性。SAM 3 通过解耦识别与定位机制，结合大规模数据引擎，将任务从单对象视觉提示扩展至全实例概念提示。该工作确立了提示驱动概念分割的新范式，但其对简单名词短语的依赖与对复杂推理指令的回避，暴露了通用语义理解与原子概念检测之间的深层张力。

## 研究背景

当检测器面对新生成模型时，其训练域与测试域的数据分布出现系统性差异——这一现象称为分布偏移。分布偏移导致传统分类器决策边界失效，而实际场景中往往能获取少量目标域样本，这恰好构成了小样本学习的条件：仅凭每个类别极少量标注样本泛化到新任务。解决此类问题的经典框架是原型网络，它计算各类别支持样本的特征均值作为"原型"，再通过距离度量完成分类。

开放词汇语义分割旨在突破固定类别集合限制，利用视觉-语言模型实现基于任意文本描述的像素级预测。早期研究聚焦于弥补 CLIP 等模型的空间定位缺陷，通过先生成类无关掩码再分类的两阶段范式引入结构先验，但受制于掩码生成器质量与计算开销。随着免训练范式兴起，研究者转向注意力修正与特征精炼，用零标注部署能力换取性能上限的妥协，但复杂场景下的鲁棒性仍受限于骨干网络固有特征质量。SAM 3 的切入点在于将任务粒度从语义掩码扩展至实例身份保持，通过解耦识别与定位机制，结合大规模数据引擎，解决了长尾概念覆盖与视频跟踪中的身份混淆问题。

## 核心方法

### 方法参照系

SAM 3 基于 DETR 检测器与 SAM 2 跟踪器的双模块架构，共享 Perception Encoder 骨干。与通用开放词汇分割流程的关键差异在于，本文显式分离检测与跟踪任务，并引入 Presence Head 解耦识别与定位，以应对开放词汇场景下的背景偏差与实例混淆。

### Presence Head 解耦机制

传统 DETR 变体中，每个对象查询需同时解决识别（是否存在）与定位（在哪里）问题，但全局上下文识别与局部定位目标存在内在冲突。SAM 3 引入 Presence Token，将分类问题分解为全局存在性预测与局部匹配预测。公式如下：

$$ p(q_i \text{ matches NP}) = p(q_i \text{ matches NP} | \text{NP present}) \cdot p(\text{NP present}) $$

该公式表明，最终得分是局部匹配概率与全局存在概率的乘积。Presence Token 仅负责预测概念是否存在于图像中，而对象查询仅负责在概念存在的前提下进行定位。这种解耦设计有效抑制了背景偏差，特别是在训练包含困难负样本时，避免了对象查询因全局上下文不足而误判。

### 歧义处理与多专家模块

开放词汇任务中，同一短语可能存在多种有效解释（如“mouse”指设备或动物），导致模型输出冲突掩码。SAM 3 引入歧义头，采用混合专家策略，训练 $K=2$ 个并行专家，仅对损失最低的专家进行监督。公式如下：

$$ \mathcal{L}_{\text{mixture}} = \min_k \mathcal{L}_k $$

该公式表示，仅通过损失最小的专家路径反向传播梯度，使每个专家特化于一种解释。推理时，通过分类头预测最可能的专家，并结合 Intersection-over-Minimum (IoM) 检测重叠实例，实现了 15% 的重叠实例减少。这一设计解决了传统方法在语义歧义场景下输出冲突掩码的问题，提升了模型在复杂场景下的鲁棒性。

## 实验评估

| 模型 | LVIS Mask AP | SA-Co/Gold cgF1 | RefCOCO+ cIoU (Zero-shot) |
| :--- | :--- | :--- | :--- |
| OWLv2* | 38.5 | 20.1 | 65.1 |
| SAM 3 | 48.8 | 37.2 | 71.1 |
| SAM 3 Agent (Gemini 2.5 Pro) | - | - | 71.1 |

SAM 3 在 LVIS 零样本 Mask AP 上达到 48.8，较 OWLv2* 的 38.5 提升 10.3 点，在 SA-Co/Gold 上 cgF1 翻倍。基线覆盖 OWLv2、GroundingDINO、LISA 等，但缺失 SCLIP、NERVE 等纯免训练 OVSS 方法，因任务定义不同非直接竞品。

| 消融项 | SA-Co/Gold cgF1 | IL_MCC | pmF1 |
| :--- | :--- | :--- | :--- |
| Baseline | 50.7 | 0.77 | 65.4 |
| + Presence Head | 52.2 | 0.82 | 63.4 |
| + Hard Negatives (30/img) | 43.0 | 0.68 | 62.8 |

Presence Head 提升 cgF1 1.5 点，IL_MCC 提升 0.05。困难负样本显著改善图像级识别，但单独使用会降低 cgF1，需与 Presence Head 协同。合成数据（SYN）较外部数据（EXT）提升 8.8 cgF1，高质量标注（HQ）再提升 14.6 cgF1，验证了数据引擎的有效性。

评估协议涵盖图像与视频 PCS，指标包括 cgF1、pHOTA、mAP。局限在于未直接对比纯语义分割基准上的免训练 SOTA，且 RefCOCO 上零样本结果低于微调方法，暴露了通用 Agent 与专用模型在标注偏差利用上的差异。代码与 SA-Co 基准已开源，训练消耗 172k A100 GPU 小时，可复现性高。

## 关联研究分析

从问题动机看，SAM 3 与 SCLIP、NERVE 等免训练方法在“降低标注依赖”上逻辑同构，但路径截然不同。SCLIP 通过修改 CLIP 自注意力机制抑制背景噪声，依赖推理时修正，性能上限受限于 CLIP 特征质量；SAM 3 则通过大规模数据引擎与 Presence Head 解耦，从训练阶段解决识别-定位冲突。这种差异源于任务粒度：SCLIP 聚焦语义掩码，SAM 3 聚焦实例身份保持，后者需要更强的结构先验与数据规模。

从方法设计看，SAM 3 Agent 与 LISA 均集成 MLLM 处理复杂指令，但架构角色不同。LISA 将 MLLM 与分割解码器端到端结合，通过特殊令牌触发掩码生成，依赖微调；SAM 3 Agent 将 MLLM 作为推理前端，SAM 3 作为工具，通过迭代调用处理长指令。这种工具调用范式避免了 MLLM 幻觉对分割精度的直接影响，但牺牲了端到端优化的潜力。SAM 3 在 RefCOCO+ 上零样本超越 LISA 微调版本，验证了工具调用在复杂指令分解上的优势，但其在纯语义分割任务上的表现未与 LISA 直接对比，通用性与专用性的平衡仍存疑问。

## 总结

SAM 3 要解决的核心矛盾是开放词汇分割中识别与定位的耦合冲突，以及长尾概念覆盖不足。现有方法或依赖昂贵标注进行特征修正，或受限于免训练范式的性能上限，难以同时兼顾实例身份保持与视频跟踪。SAM 3 通过 Presence Head 解耦机制与大规模数据引擎，将任务从单对象视觉提示扩展至全实例概念提示，在 LVIS 上实现 48.8 的 Mask AP，在 SA-Co 上 cgF1 翻倍。其边界在于对简单名词短语的依赖，以及对复杂推理指令的回避，通过 Agent 模式而非端到端微调处理长指令。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
