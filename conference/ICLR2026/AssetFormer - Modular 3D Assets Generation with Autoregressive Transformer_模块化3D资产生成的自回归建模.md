# ICLR2026最新论文 ｜AssetFormer: Modular 3D Assets Generation with Autoregressive Transformer ｜模块化3D资产生成的自回归建模

作者：Lingting Zhu、Shengju Qian、Haidi Fan 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.12100)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.12100)

> 游戏工业与用户生成内容（UGC）场景亟需高效、可编辑且文件体积小的三维资产，传统网格或点云表示因存储传输开销大且难以被非专业用户操控而受限。现有潜空间扩散模型虽能生成高保真单体几何，但缺乏结构可控性，无法直接满足模块化组装与引擎集成的需求。AssetFormer 将三维资产解构为离散原语序列，利用自回归 Transformer 结合深度优先搜索（DFS）重排序策略，从文本描述直接生成符合物理连接规则的模块化资产。该工作验证了离散 Token 化在特定结构化任务上的有效性，但其对复杂非模块化几何的泛化能力及与主流扩散范式的性能对比仍存疑。

## 研究背景

三维资产生成旨在通过算法自动合成具备几何、语义及物理属性的三维内容。在游戏开发与 UGC 平台中，资产通常由预定义的原语（Primitives）通过特定位置、旋转和类别组合而成，这种模块化表示源于计算机辅助设计（CAD）中的构造实体几何（CSG）概念。原语具有离散属性，天然适配序列建模，但三维空间中原语的排列顺序并非像文本那样具有固有的线性逻辑，如何确定最优的 Token 化顺序以捕捉空间层级关系，是该领域区别于图像或文本生成的核心难点。

当前主流范式依赖潜空间扩散模型（Latent Diffusion Model, LDM）在连续潜空间中优化几何表示，虽在单体高保真度上表现优异，但生成的网格缺乏内部结构信息，难以直接用于部件级编辑或物理仿真。自回归模型（Autoregressive Model, AR）在语言建模中的成功促使研究者将其应用于视觉生成，但现有 3D 自回归方法多聚焦于网格拓扑或点云，缺乏针对模块化资产结构特性的专用 Token 化策略。AssetFormer 切入这一空白，利用真实 UGC 平台数据，探索如何通过改进的序列重排序与解码策略，实现文本可控的模块化资产生成。

## 核心方法

### 离散 Token 化与联合词表构建

AssetFormer 将每个原语映射为包含类别 $c$、旋转 $r$ 和三维位置 $\mathbf{x}$ 的元组，构成离散 Token 序列。不同于 MeshGPT 等使用图编码器处理网格拓扑的方法，本文利用原语属性的有限离散值特性，直接构建联合词表 $V$，无需复杂的连续潜空间编码。这种设计消除了对复杂几何编码器的依赖，使得模型能直接学习原语间的组合分布，但要求推理时严格过滤非法 Token 以维持属性一致性。

### 基于图遍历的 Token 重排序

原始原语序列的空间随机性导致自回归模型难以捕捉局部连接约束。AssetFormer 引入基于深度优先搜索（DFS）和广度优先搜索（BFS）的遍历算法，从资产底部角落出发，生成保持局部连通性的重排序序列 $T'$。设计动机在于解决原始顺序下模型无法拟合空间分布的问题。重排序后的序列定义为：

$$ T' = \{ (\tau_0, c_{\tau_0}, r_{\tau_0}, \mathbf{x}_{\tau_0}), \dots, (\tau_{n-1}, c_{\tau_{n-1}}, r_{\tau_{n-1}}, \mathbf{x}_{\tau_{n-1}}) \} $$

其中 $\tau_i$ 为原语索引。DFS 策略在实验中优于 BFS，因其栈式弹出机制更符合建筑结构的层级构建逻辑，有助于模型学习“先基础后上层”的空间依赖关系。

### 慢快解码与分类器自由引导

为提升推理效率，AssetFormer 采用慢快解码（SlowFast Decoding）策略，结合小型草稿模型（AssetFormer-S）与大型目标模型（AssetFormer-B）。草稿模型快速预测简单 Token，目标模型验证并修正复杂 Token，显著加速生成过程。同时，引入分类器自由引导（Classifier-Free Guidance, CFG）以增强文本对齐度。解码 logits 计算如下：

$$ l_{cfg} = l' + s \cdot (l - l') $$

其中 $l$ 和 $l'$ 分别为条件与无条件 logits，$s$ 为引导尺度。该机制在保持生成多样性的同时，强化了文本描述对资产全局特征（如屋顶类型、层数）的控制力。

## 实验评估

实验基于自建数据集，包含 16,000 个真实 UGC 样本和 4,000 个程序化生成（PCG）样本，平均 Token 长度超过 4,000。基线对比涵盖 PCG 算法及不同解码策略（Greedy Search, Beam Search），但未直接对比主流潜空间扩散方法（如 TRELLIS、Hunyuan3D-2），这在一定程度上限制了跨范式性能评估的完整性。

| 方法 | FID ↓ | CLIP ↑ |
| :--- | :--- | :--- |
| PCG (Algorithm 1) | 108.476 | 0.319 |
| AssetFormer + Greedy Search | 63.351 | 0.319 |
| AssetFormer + Beam Search | 63.333 | 0.321 |
| AssetFormer + Top-K Sampling | 55.186 | 0.320 |

Top-K 采样在 FID 上取得最佳成绩 55.186，显著优于 PCG 的 108.476，表明神经生成在覆盖数据分布多样性上优于规则式程序化生成。

| 训练数据类型 | FID ↓ | CLIP ↑ |
| :--- | :--- | :--- |
| Synthesized Data Only | 113.560 | 0.320 |
| Collected Data Only | 63.381 | 0.321 |
| Synthesized + Collected Data | 55.186 | 0.320 |

消融实验显示，混合数据源策略带来最大增益，FID 从单源数据的 63.381 降至 55.186。合成数据提供结构化骨架，真实数据提供多样性，二者互补性显著。Token 重排序方面，DFS 策略（FID 55.186）优于原始顺序（65.215）和随机重排序（83.561），验证了空间层级建模的重要性。

评估指标主要依赖 FID 和 CLIP Score，缺乏对生成资产在物理仿真引擎中稳定性或可编辑性的量化验证。代码已开源，但数据集未公开，且未报告计算效率的具体硬件配置，限制了可复现性。

## 关联研究分析

从方法设计看，AssetFormer 与 MeshGPT 同属自回归 3D 生成，但 MeshGPT 处理连续网格拓扑，需图编码器处理非结构化数据，而 AssetFormer 利用模块化资产的离散属性直接构建词表，避免了图编码的计算开销。这一差异源于任务特性：模块化资产具有预定义的原语库和固定属性空间，使得离散 Token 化成为可能且高效。相比之下，通用网格生成缺乏这种结构化先验，必须依赖更复杂的表示学习。

从问题动机看，AssetFormer 与 Procedura 均关注程序化与神经生成的融合，但 Procedura 依赖 LLM 生成代码，强调可解释性，而 AssetFormer 直接生成几何属性 Token，强调生成质量与速度。AssetFormer 的 DFS 重排序策略是针对模块化连接约束的特定适配，其能否推广至其他非模块化 3D 序列生成任务，论文未提供证据。此外，与 TRELLIS 等潜空间扩散方法相比，AssetFormer 在单体几何细节上可能处于劣势，但在结构可控性和推理效率上具有潜在优势，这种取舍在 UGC 场景中更具实用价值。

## 总结

AssetFormer 旨在解决模块化 3D 资产生成中结构可控性与数据稀缺的矛盾。现有扩散模型难以直接生成具备明确拓扑连接关系的模块化资产，而传统程序化生成缺乏多样性。本文通过离散 Token 化、DFS 重排序及慢快解码，实现了文本可控的高效生成。实验表明，混合数据源与 Top-K 采样使 FID 降至 55.186，显著优于纯程序化基线。然而，模型仅支持文本输入，且缺乏与主流扩散范式的直接对比，其生成资产在复杂非模块化场景下的泛化能力未知。当原语库规模扩大或资产结构偏离标准建筑逻辑时，DFS 重排序策略的有效性是否依然成立，论文未给出回答。
