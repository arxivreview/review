# ICLR2026最新论文 ｜MOTION-ALIGNED WORD EMBEDDINGS FOR - TEXT TO-MOTION GENERATION ｜运动对齐词嵌入

研究机构：南京大学

作者：Ke Han、Yueming Lyu、Nicu Sebe

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_8056967)

> 文本驱动人体运动生成（Text-to-Motion Generation, T2M）的核心瓶颈在于通用大语言模型（LLM）的词嵌入层缺乏运动学语义，导致“顺时针”等特定动作词汇无法被准确解码为空间旋转。现有方法多聚焦于改进生成器架构或训练全新编码器，却忽视了文本编码器内部的词级语义错位。本文提出运动对齐文本编码（Motion-Aligned Text Encoding, MATE），通过微调LLM的词嵌入层并引入运动定位与解耦机制，在不改变生成器架构的前提下实现词级语义对齐。该方法在HumanML3D基准上显著提升了语义一致性，但其效果高度依赖数据规模，且未解决长序列生成的物理合理性问题。

## 研究背景

T2M任务要求模型将自然语言描述映射为三维人体姿态序列。这一过程依赖文本编码器将词汇转化为向量表示，再由生成器解码为运动。然而，通用LLM（如CLIP、DistilBERT）在大规模语料上训练，其词嵌入层定义的是语言学语义（如“clockwise”作为副词修饰动词），而非运动学语义（如具体的旋转方向与轨迹）。这种跨模态的词级错位导致模型在生成复杂动作时出现语义偏差，例如将“顺时针慢跑”生成为错误的旋转方向。

主流T2M方法通常冻结文本编码器，专注于优化扩散模型或自回归生成器，这忽略了语义错位的根源。部分工作尝试从头训练运动感知语言模型（如LaMP、MotionGPT），但受限于小数据集，其语言建模能力受损。本文切入点在于：保留预训练LLM的高层上下文建模能力，仅优化轻量级的词嵌入层，并通过显式的运动定位与解耦机制，将运动语义注入词向量空间。

## 核心方法

### 方法参照系

标准T2M流程包含文本编码与运动合成两阶段。本文问题与通用流程的关键差异在于：不修改生成器，而是改造文本编码器的词嵌入层，使其具备运动学感知能力。

### 运动定位与软注意力先验

针对数据集缺乏词级时间标注的问题，MATE首先通过ChatGPT将文本分解为子文本，并利用最优分割算法将运动序列切分为对应片段。这一过程建立文本子单元与运动片段的时空对应关系，为词级语义提取提供软注意力先验。设计动机在于解决长句中多动作语义纠缠导致的定位模糊。

$$
\text{AttentionPrior}(t) = \exp\left(-\frac{(t - c)^2}{2\sigma^2}\right), \quad c = \frac{s_n + e_n}{2}
$$

该公式定义高斯形状的注意力先验，其中 $c$ 为片段中心帧，$\sigma$ 控制衰减范围。它平滑地强调目标片段内的帧，同时抑制无关帧，提高了对分割噪声的鲁棒性。

### 运动解耦与词嵌入对齐

在定位基础上，MATE引入解耦模块以分离特定词汇的运动语义。自解耦机制利用可学习的运动原型，通过对比学习拉近同一词汇在不同运动中的特征，推远不同词汇的特征；交叉解耦机制则强制模型在运动不包含某词汇语义时产生正交特征。设计动机在于解决相关词汇（如“turn”与“clockwise”）语义交织导致的判别性不足。

$$
\mathcal{L}_{align} = -\log \frac{\exp(\text{sim}(f_w^e, f_w^m) / \tau)}{\sum_{j} \exp(\text{sim}(f_w^e, f_w^j) / \tau)}
$$

该对称InfoNCE损失函数将解耦后的运动特征 $f_w^m$ 与投影后的词嵌入 $f_w^e$ 对齐，同时推远负样本。它确保了词向量空间的结构化重组，使运动相关词汇在嵌入空间中聚集，反义词分离。

## 实验评估

实验在HumanML3D（14,616序列）和KIT（3,911序列）上进行，对比MDM、MotionDiffuse、MMM、MoMask等主流方法。基线覆盖了扩散与自回归两大路线，但缺失Flow Matching类新方法（如HY-Motion）。

| 方法 | R-Precision Top-1 | FID | MM-Dist |
| :--- | :--- | :--- | :--- |
| MoMask | 0.521±0.002 | 0.045±0.002 | 2.958±0.008 |
| MoMask + MATE | 0.550±0.002 | 0.040±0.002 | 2.811±0.007 |
| MDM | 0.320±0.005 | 0.544±0.044 | 5.566±0.027 |
| MDM + MATE | 0.509±0.002 | 0.332±0.002 | 3.057±0.063 |

MoMask+MATE在R-Precision Top-1上从0.521提升至0.550，FID从0.045降至0.040，表明语义对齐显著改善。MDM+MATE的提升幅度更大，说明MATE对弱基线具有更强的补偿作用。

| 消融项 | Top-1 | FID | MM-Dist |
| :--- | :--- | :--- | :--- |
| Full Model | 0.550 | 0.040 | 2.811 |
| w/o $\mathcal{L}_{self}$ | 0.498 | 0.339 | 2.982 |
| w/o $\mathcal{L}_{cross}$ | 0.533 | 0.044 | 2.934 |
| w/o $\mathcal{L}_{align}$ | 0.519 | 0.049 | 2.954 |

移除自解耦损失 $\mathcal{L}_{self}$ 导致FID从0.040飙升至0.339，表明原型对比学习对分布相似性至关重要。移除交叉解耦 $\mathcal{L}_{cross}$ 对Top-1影响较小（0.533 vs 0.550），但对MM-Dist有负面影响，说明其主要贡献在于增强词间判别性而非整体分布。

评估指标包含R-Precision、FID、MM-Dist等标准度量，但未报告物理合理性指标（如Foot Skate）。代码已开源，但论文未提供超参数细节与GPU配置，可复现性依赖官方实现。KIT数据集上提升幅度较小，暗示数据规模对词嵌入优化的制约。

## 关联研究分析

从问题动机看，MATE与FineMoLA均关注细粒度对齐，但路线迥异。FineMoLA利用最优传输从片段级监督恢复帧级对齐，侧重时间定位的精确性；MATE则通过解耦机制重构词嵌入空间，侧重语义特征的判别性。MATE无需帧级标注，但依赖ChatGPT进行文本分割，引入了外部LLM的潜在偏差。

从方法设计看，MATE与LaMP、MotionGPT同属运动感知文本编码器，但MATE仅微调词嵌入层（3.2M参数），而LaMP等从头训练新编码器。MATE保留了预训练LLM的语言知识，避免了小数据集导致的过拟合，但其效果受限于词嵌入层的表达能力。若运动语义需要更深层的上下文交互，仅调整输入层可能不足以捕捉复杂组合动作。

## 总结

MATE针对通用LLM词嵌入层缺乏运动学语义这一核心矛盾，通过运动定位与解耦机制，在保留高层语言知识的前提下实现了词级语义对齐。实验证明，MoMask+MATE在HumanML3D上R-Precision Top-1达到0.550，FID降至0.040，显著优于基线。然而，KIT数据集上的有限提升暴露了数据规模对词嵌入优化的制约，且方法未涉及物理合理性约束。当支持集增大到万级规模时，词嵌入微调的边际收益是否递减，论文未给出回答。
