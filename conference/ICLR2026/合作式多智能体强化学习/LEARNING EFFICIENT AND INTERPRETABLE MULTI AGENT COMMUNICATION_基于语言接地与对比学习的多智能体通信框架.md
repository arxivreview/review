# ICLR2026最新论文 ｜LEARNING EFFICIENT AND INTERPRETABLE MULTI AGENT COMMUNICATION ｜基于语言接地与对比学习的多智能体通信框架

研究机构：山东大学、新加坡南洋理工大学

作者：Wei Du、Benyu Wu、YUQING SUN 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_22365268)

> 多智能体在部分可观测环境中协作时，通信协议往往陷入效率与可解释性的二元对立：追求任务性能的方法产生黑箱向量，追求人类可读的方法则带宽开销巨大。GLC 通过离散自编码器压缩、LLM 语义接地与跨智能体对比学习，将信息瓶颈原则操作化为动态权重调度，试图同时优化效用、复杂度与可解释性三元目标。实验显示其在通信比特数上较连续向量方法降低两个数量级，但任务性能绝对值缺乏与当前 SOTA 的直接对比，且推理时完全解耦 LLM 的泛化边界尚不明确。

## 研究背景

当智能体仅能获取局部观测时，协调失败源于信息不对称。解决此问题的传统路径是学习通信协议，但协议设计面临根本张力：连续向量通信（如 IC3Net）虽能最大化任务效用，却因维度高而带宽消耗大且语义不可解释；离散符号通信（如 aeComm）虽压缩率高，但符号缺乏语义锚点，导致跨智能体或人机协作时无法对齐。信息瓶颈（Information Bottleneck, IB）原则提供了形式化框架，将通信问题转化为在消息复杂度（压缩率）与关于源变量的信息量（效用与可解释性）之间的权衡。

现有研究多聚焦于三元困境中的单一或双重维度。效用优化路线（CommNet, TarMAC）牺牲可解释性换取性能；效率驱动路线（aeComm, VQ-VIB）通过离散化降低带宽，但符号语义空洞；可解释性路线（LangGround）利用语言模型接地，但依赖连续表示导致开销回升。GLC 的切入点在于指出这些方法未能统一优化三元目标，且缺乏动态平衡机制。其核心假设是：通过离线 LLM 轨迹提供语义锚点，结合在线对比学习确保智能体间一致性，可在推理时完全脱离 LLM 依赖，实现高效且可解释的通信。

## 核心方法

### 离散符号通信参照系

GLC 基于去中心化部分可观测马尔可夫决策过程（Dec-POMDP）框架，采用集中训练去中心化执行（CTDE）范式。与标准离散通信方法（如 aeComm）仅优化重构损失不同，GLC 在自编码器基础上引入语义接地与对比对齐模块，将通信符号的优化目标从单纯的“可重构”扩展至“语义一致”与“人类可解释”。

### 离散自编码器与语义接地

设计动机在于解决离散符号缺乏语义锚点导致的可解释性缺失。GLC 使用 3 层 MLP 自编码器将 128 维观测特征 $h_i^{t-1}$ 量化为离散符号 $c_i^{t-1}$，并通过直通估计器（Straight-Through Estimator）实现梯度回传。关键创新在于引入语言接地损失，将离散符号映射至 256 维嵌入空间 $m_i = \phi(c_i^t)$，并与 LLM 生成的专家轨迹中的自然语言参考嵌入 $m_r$ 进行余弦相似度对齐：

$$ \mathcal{L}_{align} = \mathbb{E}_{(o_i^t, a_i^t) \sim \mathcal{D}} \left[ \mathcal{I}_{\mathcal{D}} \left( 1 - \frac{m_i \cdot m_r}{\|m_i\| \|m_r\|} \right) \right] $$

该公式仅在专家数据集 $\mathcal{D}$ 覆盖的状态-动作对上生效，强制离散符号的几何结构与人类语言语义空间对齐，从而赋予符号可解释的语义内涵。

### 跨智能体对比对齐与动态权重调度

设计动机在于解决离散符号在智能体间语义不一致导致的协作失效。GLC 引入监督对比损失，将同一轨迹时间窗口 $w=5$ 内其他智能体的消息定义为正样本集 $\mathcal{H}(m_i^t)$，批次内其他轨迹消息为负样本：

$$ \mathcal{L}_{contrast} = -\frac{1}{|\mathcal{H}(m_i^t)|} \sum_{p \in \mathcal{H}(m_i^t)} \log \frac{\exp(\text{sim}(m_i^t, m_p)/\rho)}{\sum_{z \in \mathcal{Z}(m_i^t)} \exp(\text{sim}(m_i^t, m_z)/\rho)} $$

其中温度参数 $\rho=0.1$。总损失 $\mathcal{L}_{total} = \mathcal{L}_{policy} + \lambda_A \mathcal{L}_{align} + \lambda_R \mathcal{L}_{recon} + \lambda_C \mathcal{L}_{contrast}$ 中的权重 $\lambda_A, \lambda_R, \lambda_C$ 并非静态超参数，而是基于 IB 原则的动态调度变量：$\lambda_R$ 线性退火以实施“先探索后压缩”，$\lambda_A$ 任务自适应以平衡可解释性与性能，$\lambda_C$ 固定以稳定共识。

## 实验评估

实验在 Predator-Prey (MPE 变体) 和 USAR 基准上进行，基线包括 IC3Net、aeComm、LangGround、VQ-VIB 及无通信基线。基线覆盖连续向量、离散符号及语言接地三类路线，但缺失当前 MPE 基准上的强基线如 CroMAC 或 Communication-Constrained Priors，导致任务性能绝对值的竞争力评估受限。

| 方法 | Bits/Step | Avg. Steps | Total Bits | Ratio to GLC |
| :--- | :--- | :--- | :--- | :--- |
| GLC | 32.0 | 4.5 | 144.0 | 1.0 |
| LangGround | 8192.0 | 5.3 | 43417.6 | 301.5 |
| IC3Net | 8192.0 | 5.5 | 45056.0 | 312.9 |
| aeComm | 24.0 | 5.4 | 129.6 | 0.9 |
| VQ-VIB | 58.0 | 7.2 | 417.6 | 2.9 |

在 ppv_1 环境中，GLC 总通信比特数为 144.0，较 LangGround 和 IC3Net 降低两个数量级，但略高于 aeComm (129.6)。GLC 平均步数 4.5 低于所有基线，表明其通信不仅高效，还促进了更快的任务完成。

| 方法 | Cos sim (ppv_0) | Bleu score (ppv_0) |
| :--- | :--- | :--- |
| GLC | 0.87±0.02 | 0.65±0.04 |
| LangGround | 0.82±0.02 | 0.52±0.03 |

GLC 在可解释性指标上优于 LangGround，余弦相似度 0.87 和 BLEU 分数 0.65 均显著高于后者。消融实验显示，动态权重调度较固定权重将 ppv_0 环境下的平均步数从 9.62 降至 8.71，总比特数从 307.8 降至 278.7，但 BLEU 分数从 0.65 微降至 0.62，表明效率优化对可解释性存在轻微负迁移。

评估边界方面，论文未报告任务性能的绝对数值（如 Episode Return），仅展示学习曲线，无法与领域 SOTA 直接对比。实验仅在 RTX 4090 上运行，未提供代码开源链接，且 USAR 基准未在主流 MARL 评测体系中广泛使用，限制了结果的可复现性与横向可比性。

## 关联研究分析

从方法设计看，GLC 与 aeComm 的核心差异在于语义锚点的引入。aeComm 仅通过自编码器重构损失优化离散符号，导致符号语义空洞，无法支持人机协作；GLC 通过 LLM 离线轨迹提供语义监督，将符号嵌入空间与人类语言对齐。这一差异的根源在于任务目标的不同：aeComm 聚焦于带宽受限下的智能体间协作，而 GLC 明确将人类可解释性纳入优化目标。然而，GLC 的 LLM 接地仅发生在训练阶段，推理时完全解耦，这种“离线接地、在线执行”的模式是否能在未见过的任务或智能体组合中保持语义稳定性，论文未提供跨任务迁移实验予以验证。

从问题动机看，GLC 与 VQ-VIB 均基于信息瓶颈原则，但 VQ-VIB 仅优化压缩-重构权衡，忽略可解释性；GLC 将 IB 原则扩展至三元目标，并引入动态权重调度。VQ-VIB 的静态 IB 约束在复杂任务中可能导致语义表达不足，而 GLC 的退火策略允许早期丰富语义探索。但 GLC 的动态调度依赖任务特定的 $\lambda_A$ 设置，缺乏通用的自适应机制，其在异构智能体或动态环境中的鲁棒性存疑。

## 总结

GLC 旨在解决多智能体通信中效率与可解释性的长期权衡，其切入点在于利用离线 LLM 轨迹提供语义锚点，结合在线对比学习确保智能体间一致性，并通过动态权重调度实现三元目标的平衡。实验证明其在通信效率上较连续向量方法降低两个数量级，且在可解释性指标上优于语言接地基线。然而，论文未报告任务性能的绝对数值，且推理时完全解耦 LLM 的设计使得语义泛化能力缺乏验证。当智能体团队规模扩大或任务环境发生分布偏移时，离线接地的语义锚点是否仍能维持跨智能体通信的一致性，论文未给出回答。
