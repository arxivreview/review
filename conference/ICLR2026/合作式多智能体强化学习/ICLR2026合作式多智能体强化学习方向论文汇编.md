【BAYESIAN ROBUST COOPERATIVE MULTI-AGENT REINFORCEMENT LEARNING AGAINST UNKNOWN ADVERSARIES ｜贝叶斯鲁棒合作多智能体强化学习

研究机构：瑞典皇家理工学院

作者：Kiarash Kazari、György Dán

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_86864327)

> 合作多智能体系统在部署时面临智能体被恶意操控或故障导致策略偏离的风险，传统基于最坏情况假设的对抗训练方法因优化非凸、易陷入局部最优且对单一攻击类型过拟合，难以适应目标未知的多样化攻击。本文提出BATPAL框架，通过参考值分区将连续对抗类型空间离散化，并引入外部约束强化学习生成各分区内的代表性对抗策略，使防御方基于信念更新自适应响应。该方法在未知攻击下实现了接近无后悔的性能，但其鲁棒性增益依赖于信念网络的精度，且在标准合作任务上未超越现有SOTA，泛化边界尚存疑。

【Continuous-Time Value Iteration for Multi-Agent Reinforcement Learning ｜连续时间多智能体强化学习中的价值梯度迭代

研究机构：美国普渡大学

作者：Xuefeng Wang、Lei Zhang、Henglin Pu 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.09135)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.09135)

> 合作型多智能体强化学习（Cooperative Multi-Agent Reinforcement Learning, MARL）在离散时间框架下已趋于成熟，但真实物理系统往往以高频或连续时间运行，离散化步长导致控制不平滑或计算爆炸。现有连续时间强化学习（Continuous-Time Reinforcement Learning, CTRL）方法多局限于单智能体，且基于物理信息神经网络（Physics-Informed Neural Networks, PINNs）的求解器在耦合动态下易产生价值梯度偏差，破坏策略优化。本文提出 Value Iteration via PINN (VIP) 框架，通过引入价值梯度迭代（Value Gradient Iteration, VGI）模块，沿轨迹显式修正价值梯度，确保微分价值函数与哈密顿-雅可比-贝尔曼（Hamilton-Jacobi-Bellman, HJB）方程的一致性。该工作填补了连续时间合作 MARL 的价值学习空白，但其对确定性系统的依赖及缺乏显式通信机制，限制了其在部分可观测环境中的直接应用。

【CORRELATED POLICY OPTIMIZATION IN MULTI-AGENT SUBTEAMS ｜基于贝叶斯网络子团队分解的协同策略优化

研究机构：美国圣路易斯华盛顿大学、美国伍斯特理工学院

作者：Dingyang Chen、Jianing Ye、Zhenyu Zhang 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_73520102)

> 合作型多智能体强化学习（Cooperative Multi-Agent Reinforcement Learning, MARL）面临联合动作空间随智能体数量指数增长导致的维度灾难，传统乘积策略因强制条件独立而表达力受限，难以捕捉智能体间的强相关性。现有基于贝叶斯网络（Bayesian Networks, BNs）的策略优化方法虽能引入相关性，但缺乏在有限依赖预算下保证近最优性的理论边界，且动态结构构建缺乏指导。本文通过定义子团队（Subteam）结构，证明在环境可分解条件下，正则化策略梯度上升可收敛至具有有界次优性的策略，并提出基于依赖分数的动态DAG构建启发式。该工作填补了BN策略从渐近收敛到有限时间近最优保证的理论空白，但其实验验证未与最新SOTA进行直接数值对标，且假设完全可观测性，限制了其在部分可观测场景下的直接适用性。

【DISTRIBUTIONALLY ROBUST COOPERATIVE MULTI AGENT REINFORCEMENT LEARNING VIA ROBUST VALUE FACTORIZATION ｜分布鲁棒合作多智能体强化学习

研究机构：腾讯AI实验室、美国加州理工学院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_67616454)

> 合作型多智能体强化学习在部署时面临训练环境与真实环境动力学不一致的难题，导致策略性能骤降。传统价值分解方法依赖个体-全局最大（IGM）原则实现去中心化执行，但该原则在环境不确定性下失效，直接迁移单智能体鲁棒强化学习（DR-RL）方法会导致个体贪心动作与团队最优动作错位。本文提出分布鲁棒IGM（DrIGM）原则，通过基于最坏情况联合动作值定义个体鲁棒动作值，保证去中心化贪心执行的一致性，并据此推导了VDN、QMIX和QTRAN的鲁棒变体。该方法在SustainGym和SMAC上验证了分布外性能的提升，但其鲁棒性保证严格依赖于测试环境位于预设不确定性集内，且未处理观测噪声等非模型不确定性。

【Distributionally Robust Cooperative Multi-Agent Reinforcement Learning via Robust Value Factorization ｜分布鲁棒合作多智能体强化学习

研究机构：腾讯AI实验室、美国加州理工学院

作者：Chengrui Qu、Christopher Yeh、Kishan Panaganti 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.11437)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.11437)

> 合作型多智能体强化学习在部署时面临环境模型失配导致的协调失效，传统集中训练去中心化执行范式下的价值分解方法无法保证鲁棒性。现有单智能体分布鲁棒强化学习直接迁移至多智能体场景时，个体最坏情况与团队最坏情况的不一致破坏了去中心化贪心执行的对齐性。本文提出分布鲁棒个体-全局最大原则，通过基于全局最坏情况模型定义鲁棒个体价值函数，实现了鲁棒价值分解。该方法在SustainGym和SMAC上验证了分布外性能的提升，但缺乏对连续控制复杂任务及大规模异构智能体系统的测试，其鲁棒性增益在分布内性能上的普遍性存疑。

【GlobeDiff: State Diffusion Process for Partial Observability in Multi-Agent Systems ｜全局状态扩散算法

研究机构：中国科学院、清华大学

作者：Yiqin Yang、Xu Yang、Yuhua Jiang 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.15776)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.15776)

> 导读 合作型多智能体强化学习（Cooperative Multi-Agent Reinforcement Learning, MARL）在部分可观测性（Partial Observability, PO）下面临核心困境：单个智能体的局部观测往往对应多种截然不同的全局状态，这种“一对多”映射导致基于判别式模型（如RNN）的状态推断发生模式坍缩，即平均化不同可能状态或忽略次要模式，从而引发次优协调。现有信念状态估计与显式通信方法分别受限于误差累积和高通信开销，未能从根本上解决多模态分布的建模问题。GlobeDiff 将全局状态推断重构为条件扩散过程，引入潜变量作为模式选择器，通过去噪网络生成高保真的全局状态假设，使智能体在去中心化执行阶段能基于推断出的全局状态 $\hat{s}$ 而非局部观测 $o_i$ 进行决策。该方法在 SMAC 和 MPE 基准上显著优于判别式基线，但其性能仍低于当前价值分解类 SOTA，且未报告推理延迟，实际部署中的计算成本存疑。

】

【LEARNING EFFICIENT AND INTERPRETABLE MULTI AGENT COMMUNICATION ｜基于语言接地与对比学习的多智能体通信框架

研究机构：山东大学、新加坡南洋理工大学

作者：Wei Du、Benyu Wu、YUQING SUN 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_22365268)

> 多智能体在部分可观测环境中协作时，通信协议往往陷入效率与可解释性的二元对立：追求任务性能的方法产生黑箱向量，追求人类可读的方法则带宽开销巨大。GLC 通过离散自编码器压缩、LLM 语义接地与跨智能体对比学习，将信息瓶颈原则操作化为动态权重调度，试图同时优化效用、复杂度与可解释性三元目标。实验显示其在通信比特数上较连续向量方法降低两个数量级，但任务性能绝对值缺乏与当前 SOTA 的直接对比，且推理时完全解耦 LLM 的泛化边界尚不明确。

【POTENTIALLY OPTIMAL JOINT ACTIONS RECOGNI - TION FOR COOPERATIVE MULTI-AGENT REINFORCE MENT LEARNING ｜潜在最优联合动作加权

研究机构：同济大学、美国斯坦福大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_40179853)

> 合作型多智能体强化学习（Cooperative Multi-Agent Reinforcement Learning, MARL）中，价值分解方法通过单调性约束保证去中心化执行，但牺牲了联合价值函数的表达力，导致在非单调奖励结构下无法恢复最优策略。WQMIX 提出加权训练以弥补此缺陷，但其启发式近似导致权重与真实最优动作集错位。本文引入识别模块 $Q_r$ 显式估计联合动作价值，通过迭代加权机制使候选集收敛至真实最优集，从而在理论上保证最优策略恢复。该方案在矩阵博弈和捕食者-猎物任务中显著优于基线，但在大规模连续动作空间中的可扩展性尚未验证。

【Retaining Suboptimal Actions to Follow Shifting Optima in Multi-Agent Reinforcement Learning ｜保留次优动作以追踪动态最优的多智能体强化学习

作者：Yonghyeon Jo、Sunwoo Lee、Seungyul Han

论文原文见 [arXiv](https://arxiv.org/abs/2602.17062)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.17062)

> 合作型多智能体强化学习（Cooperative Multi-Agent Reinforcement Learning, MARL）在集中训练去中心化执行（Centralized Training with Decentralized Execution, CTDE）范式下，长期依赖单调价值分解来协调智能体。现有方法如QMIX在训练过程中若遭遇价值函数最优解的动态漂移，往往因丢弃次优动作信息而陷入局部最优。本文提出S2Q，通过序列学习多个子价值函数保留高价值备选动作，并采用Softmax策略引导探索以快速适应新最优。该框架在SMACv2等基准上验证了动态适应优势，但其对抑制常数$\alpha$的敏感性及通信同步机制的泛化能力仍存疑。

【STAIRS-Former: Spatio-Temporal Attention with Interleaved Recursive Structure Transformer for Offline Multi-task Multi-agent Reinforcement Learning ｜离线多任务多智能体强化学习中的时空层级Transformer架构

研究机构：韩国科学技术院

作者：Jiwon Jeon、Myungsik Cho、Youngchul Sung

论文原文见 [arXiv](https://arxiv.org/abs/2603.11691)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.11691)

> 离线多任务多智能体强化学习（Offline MT-MARL）旨在从固定数据集训练能应对智能体数量动态变化且泛化至未见任务的策略，但现有方法仅将Transformer用于观测维度适配，未能利用其建模长程历史与复杂实体关系的潜力。本文通过引入空间递归模块、时间层级结构与Token-Dropout机制，重构了Transformer在部分可观测环境下的信息处理流程。该架构在SMAC与SMAC-v2基准上超越了基于单层Transformer的基线，但在连续控制任务中的泛化能力与计算开销的平衡仍存疑。

【STAIRS-FORMER: SPATIOTEMPORAL ATTENTION WITH INTERLEAVED RECURSIVE STRUCTURE TRANSFORMER FOR OFFLINE MULTI-TASK MULTI-AGENT REINFORCEMENT LEARNING ｜时空交错递归结构Transformer

研究机构：韩国科学技术院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_67266774)

> 离线多任务多智能体强化学习（Offline MT-MARL）面临智能体数量动态变化与部分可观测性下长时程依赖建模的双重挑战。现有基于Transformer的方法仅利用其处理变长观测维度的能力，却未挖掘其建模复杂Token关系与历史序列的潜力，导致注意力分布均匀且历史信息利用不足。本文提出STAIRS-Former，通过引入空间递归模块、分层时间模块及Token-Dropout机制，重构了Transformer在离线MT-MARL中的信息处理流程。该架构在SMAC等基准上实现了SOTA性能，但其对连续动作空间的支持及与显式保守正则化方法的对比尚存疑。

【WHO MATTERS MATTERS: AGENT-SPECIFIC CONSER VATIVE OFFLINE MARL ｜异构离线多智能体强化学习中的保守度分配

研究机构：华东师范大学、上海交通大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_97833894)

> 离线多智能体强化学习（Offline MARL）旨在从静态数据集中学习策略，以规避在线交互的高成本与安全风险，但核心难题在于如何防止策略偏离数据分布导致性能崩溃。现有方法通常对所有智能体施加统一的保守约束，忽视了异构智能体在团队中影响力的差异，导致关键角色被过度约束或次要角色约束不足。本文提出OMCDA框架，通过将Q函数解耦为回报项与偏差项，并基于智能体对系统回报的影响动态分配保守度，实现了安全与探索的平衡。该方法在MuJoCo和SMAC基准上优于现有离线MARL算法，但其对总保守度超参数的敏感性以及计算复杂度仍是主要局限。
