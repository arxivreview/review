# ICLR2026最新论文 ｜DISTRIBUTIONALLY ROBUST COOPERATIVE MULTI AGENT REINFORCEMENT LEARNING VIA ROBUST VALUE FACTORIZATION ｜分布鲁棒合作多智能体强化学习

研究机构：腾讯AI实验室、美国加州理工学院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_67616454)

> 合作型多智能体强化学习在部署时面临训练环境与真实环境动力学不一致的难题，导致策略性能骤降。传统价值分解方法依赖个体-全局最大（IGM）原则实现去中心化执行，但该原则在环境不确定性下失效，直接迁移单智能体鲁棒强化学习（DR-RL）方法会导致个体贪心动作与团队最优动作错位。本文提出分布鲁棒IGM（DrIGM）原则，通过基于最坏情况联合动作值定义个体鲁棒动作值，保证去中心化贪心执行的一致性，并据此推导了VDN、QMIX和QTRAN的鲁棒变体。该方法在SustainGym和SMAC上验证了分布外性能的提升，但其鲁棒性保证严格依赖于测试环境位于预设不确定性集内，且未处理观测噪声等非模型不确定性。

## 研究背景

当多智能体系统在真实环境中部署时，训练时假设的马尔可夫决策过程（MDP）动力学往往因系统噪声或仿真-现实差距而偏离。这种环境不确定性在合作型多智能体强化学习（Cooperative MARL）中尤为致命，因为部分可观测性和智能体间的耦合效应会使微小的模型偏差级联为协调失败。为应对此问题，集中训练去中心化执行（CTDE）范式成为主流，其中价值分解方法通过个体-全局最大（IGM）原则，确保每个智能体的贪心动作与团队最优联合动作对齐，从而实现无需实时通信的去中心化执行。

然而，IGM原则的可靠性在虚拟任务中已被验证，但在存在环境不确定性的真实场景中是否依然成立尚不明确。单智能体DR-RL通过在最坏情况模型下优化策略来应对不确定性，但直接将其应用于合作MARL存在根本障碍：每个智能体基于局部历史行动，却共享耦合的团队奖励，使得个体鲁棒Q函数的定义变得困难。若简单地将单智能体DR-RL中的个体最坏情况Q函数应用于多智能体设定，不同智能体可能面对不同的对抗模型，导致个体贪心动作无法对齐团队鲁棒最优动作，从而破坏IGM原则。

本文的切入点在于识别并解决这一错位问题。作者指出，合作MARL的鲁棒性应关注整个系统的最坏情况，而非独立地鲁棒化每个智能体。基于此，本文提出DrIGM原则，重新定义个体鲁棒动作值，使其锚定于全局最坏情况模型下的联合贪心动作，从而在保持CTDE信息结构的同时，为价值分解方法提供可证明的鲁棒性保证。

## 核心方法

### 方法参照系

标准价值分解方法（如QMIX）在CTDE框架下训练联合价值函数和个体价值函数，通过单调混合网络确保IGM原则成立。本文的关键差异在于，训练目标从标准Bellman算子替换为基于不确定性集的鲁棒Bellman算子，且个体价值函数的定义需满足新的DrIGM条件，以应对环境模型的不确定性。

### DrIGM原则与鲁棒个体动作值定义

设计动机在于解决单智能体DR-RL方法直接迁移至合作MARL时，个体对抗模型与全局对抗模型不一致导致的IGM失效问题。本文定义个体鲁棒动作值 $Q_i^{rob}(h_i, a_i)$ 为全局最坏情况模型下，在联合贪心动作 $\bar{a}$ 处的个体动作值：

$$ Q_i^{rob}(h_i, a_i) = \inf_{P \in \mathcal{P}} Q_i^P(h_i, a_i) \bigg|_{\bar{a} = \arg\max_{\mathbf{a}} \inf_{P \in \mathcal{P}} Q_{tot}^P(\mathbf{h}, \mathbf{a})} $$

该公式的物理含义是：个体鲁棒动作值不再独立考虑每个智能体自身的最坏情况，而是固定在全局最坏情况模型所决定的联合贪心动作上，评估该动作下个体的价值。这确保了所有智能体面对同一个对抗模型，从而保证个体贪心动作与团队鲁棒最优动作对齐。

### 鲁棒Bellman算子与算法实现

设计动机在于将DrIGM原则转化为可训练的损失函数。本文针对两种常见不确定性集（$\rho$-contamination和总变差TV）推导了鲁棒Bellman算子。以$\rho$-contamination为例，其鲁棒Bellman算子为：

$$ \mathcal{T}Q_{tot}(\mathbf{h}, \mathbf{a}) = r(\mathbf{h}, \mathbf{a}) + \gamma \mathbb{E}_{\mathbf{h}' \sim P_0(\cdot|\mathbf{h}, \mathbf{a})} \left[ (1-\rho) \max_{\mathbf{a}'} Q_{tot}(\mathbf{h}', \mathbf{a}') - \rho \min_{\mathbf{a}'} Q_{tot}(\mathbf{h}', \mathbf{a}') \right] $$

该算子通过加权平均最坏情况联合动作值来更新目标，其中 $\rho$ 控制不确定性强度。算法实现上，本文保持VDN/QMIX/QTRAN的网络结构不变，仅将TD损失中的目标值替换为上述鲁棒Bellman算子计算的结果，并采用目标网络稳定训练。这种设计使得鲁棒性扩展可以无缝集成到现有代码库中，无需为每个智能体设计特殊的鲁棒价值函数。

## 实验评估

实验在SustainGym的HVAC控制任务和SMAC的3s5z地图上进行，对比非鲁棒基线（VDN/QMIX/QTRAN）和鲁棒基线GroupDR。SustainGym实验包含季节性偏移和气候/季节性偏移两种分布外设置，SMAC实验通过向敌方单位位置观测添加高斯噪声模拟分布偏移。

| 任务 | 方法 | 不确定性集 | 平均回报 (±SE) |
| :--- | :--- | :--- | :--- |
| SustainGym (季节性) | Non-robust QMIX | - | 0.895±0.008 |
| SustainGym (季节性) | Robust QMIX | TV | 0.916±0.006 |
| SustainGym (气候/季节性) | Non-robust QMIX | - | 0.478±0.052 |
| SustainGym (气候/季节性) | Robust QMIX | TV | 0.520±0.048 |
| SustainGym (气候/季节性) | Robust QTRAN | TV | 0.733±0.026 |

在SustainGym气候/季节性偏移设置下，Robust QTRAN (TV) 达到0.733±0.026，显著优于非鲁棒QTRAN的0.654±0.066和GroupDR基线的0.520±0.049。SMAC实验中，Robust QMIX ($\rho$-contamination) 在 $\rho=0.04$ 时测试胜率较非鲁棒基线提升约2%，但 $\rho$ 过大时性能下降，表明鲁棒性参数需根据实际偏移水平调优。

消融实验显示，TV不确定性集在SustainGym上表现优于$\rho$-contamination，尤其在QTRAN架构下。一个反直觉发现是，鲁棒训练在部分情况下提升了分布内性能，例如SustainGym季节性偏移下Robust QMIX (TV) 的0.916高于非鲁棒QMIX的0.895。这表明在合作MARL中，显式建模鲁棒性可能通过缓解部分可观测性和去中心化执行带来的误差，同时增强稳定性和适应性，而非单纯牺牲性能。

评估边界方面，实验仅覆盖模型不确定性，未涉及观测噪声或通信延迟。SustainGym数值与领域综述中记录的SOTA（0.75）存在差异，可能源于任务子集或评估协议不同。论文未提供代码，但基于QMIX/VDN的开源实现可复现。

## 关联研究分析

从问题动机看，本文与GroupDR等基于策略梯度的鲁棒MARL方法形成对比。GroupDR通过对抗训练增强策略鲁棒性，但本文在SustainGym上显著优于GroupDR（0.733 vs 0.520），表明基于值分解的鲁棒性在离散动作空间中可能更稳定。这一差异的根源在于，值分解方法通过IGM原则保证去中心化执行的一致性，而策略梯度方法在鲁棒设定下可能面临信用分配模糊性加剧的问题。

从方法设计看，本文与MAGIC等因果信用分配方法同属CTDE框架，但解决不同问题。MAGIC通过反事实分支量化智能体动作的因果影响以解决稀疏奖励下的协调信号缺失，而本文聚焦环境不确定性下的鲁棒性。两者均未处理多源不确定性（如模型不确定性+观测噪声）的联合影响。本文的DrIGM原则要求测试环境位于预设不确定性集内，这一假设在动态变化的真实环境中可能过于严格，而MAGIC的因果影响估计是否能在模型不确定性下保持无偏，论文未给出回答。

## 总结

本文要解决的核心矛盾是合作MARL中环境不确定性导致IGM原则失效，进而破坏去中心化执行的可靠性。现有方法无法做到这一点，因为单智能体DR-RL的个体最坏情况定义在多智能体耦合奖励下会导致个体与团队动作错位。本文凭DrIGM原则，通过锚定全局最坏情况模型定义个体鲁棒动作值，解决了这一错位问题。方法上，本文推导了VDN/QMIX/QTRAN的鲁棒变体，在SustainGym气候/季节性偏移下，Robust QTRAN (TV) 达到0.733±0.026，较非鲁棒基线提升12%。本文的边界在于，鲁棒性保证严格依赖于测试环境位于预设不确定性集内，且实验未覆盖观测噪声等非模型不确定性。当不确定性集无法准确刻画真实环境偏差时，DrIGM原则的鲁棒性保证是否依然成立，论文未给出回答。
