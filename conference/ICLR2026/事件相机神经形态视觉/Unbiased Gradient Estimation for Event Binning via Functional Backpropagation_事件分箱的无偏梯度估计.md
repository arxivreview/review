# ICLR2026最新论文 ｜Unbiased Gradient Estimation for Event Binning via Functional Backpropagation ｜事件分箱的无偏梯度估计

研究机构：中国科学技术大学

作者：Jinze Chen、Wei Zhai、Han Han 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.12590)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.12590)

> 事件视觉中，将异步事件流分箱为密集帧是适配现有深度学习架构的主流手段，但分箱函数的不连续性导致反向传播时梯度截断或引入偏差，阻碍了从原始事件直接优化运动参数。现有平滑近似与直通估计器缺乏无偏性保证，导致学习效率受限。本文提出功能反向传播（Functional Backpropagation, FBP），通过泛函提升与弱导数合成，在保持前向输出不变的前提下，重构共轭函数以计算无偏梯度。该方法在运动估计、光流及SLAM任务中提升了精度与收敛速度，但其计算开销增加可能限制边缘部署，且未解决分箱本身的时间离散化信息丢失问题。

## 研究背景

事件相机记录的是像素级亮度变化的异步脉冲，而非绝对强度帧。为了利用成熟的卷积神经网络（CNN）处理这些稀疏数据，研究者通常采用分箱技术，将事件在时空维度聚合为密集图像或体素网格。然而，分箱操作本质上是一个离散化过程，其映射函数在边界处不连续。这种不连续性导致标准反向传播算法在计算参数梯度时失效：要么梯度被截断为零，要么需要引入平滑近似，而后者不可避免地引入梯度偏差，使得优化过程偏离真实的最优解。

事件视觉领域长期面临稀疏异步数据与稠密深度学习架构不兼容的矛盾。早期工作如E2VID确立了基于循环神经网络的帧化重建基线，Voxel Grid成为通用的密集表征形式，但这些方法大多忽略分箱梯度或依赖启发式平滑，导致在高速运动或复杂动态场景下，参数优化效率低下且精度受限。尽管Spiking Patches等新兴方法试图保留异步性，但针对分箱操作本身的梯度偏差问题，缺乏具有理论保证的解决方案。本文切入点在于识别并形式化分箱函数不连续性导致的梯度偏差问题，通过泛函分析工具提供无偏梯度估计的理论框架，从而在保留密集化架构兼容性的同时，提升底层信号处理的优化效率。

## 核心方法

### 方法参照系

事件分箱通常被视为将事件流 $E$ 映射为密集帧 $H$ 的前向操作，参数 $\theta$（如运动参数）通过优化帧的锐度指标（如方差或似然）来恢复。标准流程中，分箱函数 $h_d$ 被视为黑盒，其梯度要么被忽略，要么用平滑核 $k$ 的导数近似。本文的关键差异在于，不改变前向分箱逻辑，而是重构反向传播路径，将不连续的分箱函数提升为连续泛函，利用弱导数理论计算精确梯度。

### 泛函提升与共轭函数重构

设计动机在于解决传统平滑近似（如Sigmoid或STE）缺乏无偏性保证的问题，这些方法仅提供启发式梯度，无法确保优化方向的正确性。本文提出将离散分箱函数 $h_d$ 提升为连续泛函 $h_c$，并定义采样算子 $S$ 连接两者。在反向传播中，共轭向量 $v_{hd}$ 实际上是对连续共轭函数 $v_{hc}$ 的采样。通过信号重构技术，利用平滑先验从离散样本 $v_{hd}$ 恢复连续函数 $v_{hc}$，从而避免直接计算不连续的Dirac delta函数。

$$
\frac{\partial f_c}{\partial x'_i} = \int_{\mathbb{R}} v_{hc}(x) \cdot \frac{\partial h_c}{\partial x'_i}(x) dx
$$

该公式表明，损失函数对事件坐标的梯度可通过共轭函数与分箱函数弱导数的积分计算。由于 $v_{hc}$ 编码了连续运动流，其重构不依赖前向路径的具体实现，仅依赖共轭向量的采样特性，从而保证了梯度估计的无偏性。

### 弱导数合成与算法实现

设计动机在于将理论上的弱导数转化为可计算的卷积操作，以适配现有深度学习框架。本文推导了分箱函数弱导数的精确公式，发现其等价于共轭函数与重构核导数的卷积。具体而言，用重构核 $l$ 替代Dirac delta，通过分部积分将弱导数计算转化为卷积运算。

$$
\tilde{v}_{x'_i} = (v_{hc} * \kappa')(\cdot)
$$

其中 $\kappa'$ 是重构核的导数。该公式将不连续的梯度计算转化为连续的卷积操作，使得梯度估计在数值上稳定且可并行化。算法实现中，仅修改反向传播的梯度累积步骤，前向分箱保持不变，确保了与现有事件视觉管线的兼容性。

## 实验评估

实验在ECD（运动估计）、DSEC（光流）和ECD（SLAM）数据集上进行，基线包括STE、Sigmoid等启发式梯度方法，但未与最新稀疏Transformer架构（如Spiking Patches）直接对比。在ECD运动估计任务中，FBP方法在角速度估计上实现了10.3%的RMS误差降低和1.66倍的收敛加速，在线性速度估计上RMS误差增加3.9%但收敛加速1.48倍，整体平均RMS误差降低3.2%，收敛加速1.57倍。在DSEC光流任务中，端到端EPE误差降低9.4%；在SLAM任务中，轨迹RMS误差降低5.1%。

| 任务 | 指标 | 基线 (STE/Sigmoid) | FBP (Ours) | 改进幅度 |
| :--- | :--- | :--- | :--- | :--- |
| ECD 角速度 | RMS Error (°/s) | 12.44 / 10.14 | 12.44 / 10.14 | 10.3% 降低 |
| ECD 角速度 | Conv. Time (ms) | 6.50 / 8.07 | 6.50 / 8.07 | 1.66× 加速 |
| DSEC 光流 | EPE | - | - | 9.4% 降低 |
| SLAM | RMS Traj. Error | - | - | 5.1% 降低 |

注：表格中ECD具体数值取自Table 2中FBP列的boxes/dynamic/poster/shapes平均值，DSEC与SLAM数值取自正文描述。

消融实验显示，不同重构核（Bicubic, Lanczos, Linear）对性能影响显著，Lanczos核在boxes旋转任务中取得最佳RMS误差12.44和收敛时间6.50ms。计算开销方面，FBP在GPU上的开销为1.71-3.68倍，CPU上为2.03-2.38倍，表明其计算复杂度高于标准反向传播，但被优化效率提升所抵消。

评估边界方面，实验主要聚焦于受控优化任务和端到端任务，但未报告置信区间，且缺乏在极端动态场景下的大规模对比。代码已开源（github.com/chjz1024/EventFBP），使用JAX框架和NVIDIA RTX 4090 GPU，超参数包括分箱步长$\Delta=0.01$和事件包大小$N_e=20,000$。

## 关联研究分析

从问题动机看，本文与Spiking Patches均致力于解决事件数据与深度学习架构的兼容性问题，但路径截然不同。Spiking Patches通过稀疏Token化保留异步性，旨在降低计算冗余并适配Transformer架构；而本文坚持密集分箱路线，通过精确梯度提升优化效率。这种差异源于对“时间保真度”与“计算生态”的不同权衡：Spiking Patches牺牲部分计算效率换取原生稀疏性，本文则牺牲计算开销换取梯度无偏性。根源在于任务特性：Spiking Patches适用于长程依赖建模，而本文方法更适用于需要精确参数优化的运动估计任务。

从方法设计看，本文与Neural Events形成互补。Neural Events通过离散异步自编码器压缩事件流，侧重语义信息的提取与长程依赖建模，牺牲部分原始时间精度；本文则通过弱导数合成提升参数优化效率，侧重底层信号处理的精确性，保留原始时间分辨率。两者均未直接解决分箱本身的时间离散化信息丢失问题，但分别从语义压缩和梯度优化角度缓解了密集化带来的负面影响。查询侧增强在数据充足时是否仍有增益，论文未给出回答，但本文方法在受控优化任务中的显著优势表明，精确梯度在参数敏感任务中具有独立价值。

## 总结

本文核心矛盾在于事件分箱函数的不连续性导致梯度偏差，阻碍了从原始事件直接优化运动参数。现有平滑近似方法缺乏无偏性保证，而本文通过泛函提升与弱导数合成，提供了具有理论保证的无偏梯度估计框架。FBP方法在ECD运动估计中实现3.2%的RMS误差降低和1.57倍的收敛加速，在DSEC光流中实现9.4%的EPE降低，证明了其在提升优化效率方面的有效性。然而，实验暴露了计算开销增加（1.71-3.68倍）的局限，且在极端动态场景下的鲁棒性未充分验证。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答，但本文方法在受控优化任务中的显著优势表明，精确梯度在参数敏感任务中具有独立价值。
