# ICLR2026最新论文 ｜CLAUSE: Agentic Neuro-Symbolic Knowledge Graph Reasoning via Dynamic Learnable Context Engineering ｜预算感知的智能体神经符号知识图谱推理

作者：Yang Zhao、Chengxiao Dai、Wei Zhuo 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.21035)

> 多跳知识图谱问答（KGQA）需在保证答案准确性的同时，严格满足延迟与提示词成本约束，但现有静态 k-hop 扩展或长链思维提示往往导致上下文冗余与运行时不可预测。本文指出，上下文构建本身应被视为一个学习问题，而非依赖启发式参数调节。CLAUSE 框架通过三个协同智能体在显式预算约束下联合优化子图编辑、路径遍历与证据策展，实现了精度-效率权衡的显式可调。该方法在 HotpotQA 与 MetaQA 上以更低资源消耗取得了最优精确匹配率，但其性能优势依赖于特定骨干模型，且缺乏与最新 SOTA 方法的直接对比。

## 研究背景

当 LLM 处理多跳 KGQA 时，其参数化知识的不完整性导致事实幻觉，必须依赖外部结构化知识图谱（KG）提供事实依据。然而，传统的固定 k-hop 邻域扩展会序列化大量三元组，不仅增加了 Token 质量与延迟，还引入了干扰项降低准确率。为控制资源消耗，现有系统通常暴露跳数深度、度数上限等启发式旋钮，但这些静态规则无法根据查询难度动态调整，导致在简单问题上过度计算，在复杂问题上证据不足。

该领域的核心矛盾在于：如何在利用 LLM 语义理解能力的同时，通过神经符号机制确保推理过程的事实一致性与逻辑可执行性，并满足部署端的资源限制。主流路线中，检索增强生成（RAG）范式侧重证据召回但缺乏逻辑约束，智能体（Agentic）范式强调动态规划但计算成本高且缺乏细粒度资源控制。ToG（2023）开启了 LLM 与 KG 动态交互的方向，但依赖启发式 Beam Search，无法在延迟与精度间进行显式权衡。本文切入点在于将上下文构建建模为约束强化学习问题，通过学习到的停止规则替代硬编码的启发式，使精度-延迟-成本权衡成为可优化的目标。

## 核心方法

### 方法参照系

本文问题属于智能体推理框架路线，但区别于传统 Agentic 方法依赖固定步数或启发式搜索，CLAUSE 将多跳 KGQA 形式化为需求条件化的上下文组装问题。关键差异在于引入显式的每查询预算（边编辑、交互步骤、选定 Token），将资源消耗直接纳入训练目标，实现了预算感知的联合控制。

### 约束强化学习优化

传统多智能体强化学习（MARL）方法如 MAPPO 缺乏对异构资源约束（边数、延迟、Token）的独立控制机制，导致无法在部署时灵活调整精度-效率权衡。CLAUSE 提出 LC-MAPPO 算法，通过拉格朗日对偶变量将资源约束转化为价格信号，使智能体仅在边际效用超过当前价格时继续行动。

$$
L(\pi, \mathbf{\lambda}) = \mathbb{E} \left[ R_{acc}(\tau) - \mathbf{\lambda}^\top C(\tau) \right]
$$

该公式表明，策略优化目标由任务奖励 $R_{acc}$ 与资源成本 $C(\tau)$ 的加权和构成，其中 $\mathbf{\lambda}$ 为动态更新的对偶变量，代表每种资源的“价格”。通过多头 Critic 分离任务价值与成本价值，LC-MAPPO 实现了任务性能与约束满足的平衡，避免了单一惩罚项导致的梯度冲突。

### 三智能体协同架构

单一智能体难以同时处理子图结构、路径发现与证据选择的耦合优化，导致上下文冗余或关键证据遗漏。CLAUSE 设计三个协同智能体：子图架构师（Subgraph Architect）负责保守编辑以维持子图紧凑性，路径导航员（Path Navigator）在步骤预算内发现与修正推理路径，上下文策展人（Context Curator）在 Token 预算下组装最小证据集。

$$
g(a_t, e_t) = \phi_{ent}(v) + \phi_{rel}(r) + \phi_{nbr}(v) - \lambda_{edge} \cdot \mathbb{1}[a_t \in \{ADD, DELETE\}]
$$

该评分函数融合了实体、关系与邻域特征，并减去边编辑的价格惩罚 $\lambda_{edge}$。只有当增益 $g$ 为正且预算充足时，架构师才执行编辑操作。这种设计确保了子图扩展始终基于问题锚定，避免了无信息的 k-hop 盲目扩展，同时通过显式 STOP 动作实现了学习到的停止规则。

## 实验评估

实验在 HotpotQA、MetaQA 与 FactKG 上进行，基线覆盖预训练 LLM、RAG 方法（Vanilla/Hybrid/GraphRAG）与智能体方法（ReAct/GoT/AutoGen/KG-Agent）。主结果显示，CLAUSE 在所有数据集与跳数上均取得最优 EM@1，且在同等 Token 预算下显著降低延迟与边数。

| 方法 | HotpotQA EM@1 | MetaQA 2-hop EM@1 | HotpotQA Latency (×) | MetaQA 2-hop Edge Budget (×) |
| :--- | :--- | :--- | :--- | :--- |
| Hybrid RAG | 66.0 | 41.5 | 1.18 | 1.12 |
| GraphRAG | 50.1 | 48.0 | 1.45 | 1.32 |
| KG-Agent | 68.7 | 78.0 | 1.70 | 1.32 |
| CLAUSE | 71.7 | 87.3 | 1.48 | 0.78 |

CLAUSE 在 MetaQA 2-hop 上较最强 RAG 基线 GraphRAG 提升 39.3 个 EM 点，同时延迟降低 18.6%，边数增长降低 40.9%。消融实验表明，移除任一智能体或约束处理机制均导致精度或效率显著下降，验证了联合控制与显式预算的必要性。

| 变体 | EM@1 | Latency (×) | Edge Budget (×) |
| :--- | :--- | :--- | :--- |
| CLAUSE (full) | 87.3 | 1.00 | 1.00 |
| w/o Subgraph Architect | 74.8 | 1.32 | 1.44 |
| w/o Path Navigator | 82.1 | 1.18 | 1.22 |
| MAPPO (no duals) | 85.0 | 1.08 | 1.28 |

移除子图架构师导致 EM 下降 12.5 点，边数增加 44%，表明保守编辑对抑制冗余至关重要。LC-MAPPO 相比 MAPPO 在约束满足率上提升 191%，验证了对偶变量机制的有效性。

评估边界方面，论文未报告置信区间，且未与 EvoMemKG、STEM 等最新 SOTA 方法在相同骨干下直接对比，可能因骨干差异导致性能偏差。代码未公开，超参数与 GPU 配置未详述，可复现性受限。

## 关联研究分析

从问题动机看，CLAUSE 与 ToG（2023）均关注 LLM 与 KG 的动态交互，但 ToG 依赖启发式 Beam Search，无法在延迟与精度间进行显式权衡，而 CLAUSE 通过 LC-MAPPO 将资源消耗纳入训练目标，实现了预算感知的联合优化。这一差异源于任务特性：ToG 侧重单次查询的准确性，而 CLAUSE 面向部署场景，需满足严格的延迟与成本约束。

从方法设计看，CLAUSE 与 GraphRAG（2023）在子图构建上存在根本分歧。GraphRAG 采用静态 k-hop 扩展，导致上下文冗余与干扰项引入，而 CLAUSE 通过子图架构师的保守编辑与学习到的停止规则，动态决定何时停止检索，超越了静态 RAG 的固定窗口限制。这一改进源于对“上下文构建即学习问题”的重新定义，将启发式旋钮替换为可优化的策略。

## 总结

CLAUSE 旨在解决多跳 KGQA 中精度与资源消耗的矛盾，通过 LC-MAPPO 将上下文构建建模为约束强化学习问题，实现了精度-延迟-成本的显式可调。在 MetaQA 2-hop 上，CLAUSE 以 87.3 的 EM@1 和 0.78 的边数预算，显著优于 GraphRAG 的 48.0 与 1.32。然而，实验仅在 Qwen3-32B 骨干上进行，且未与 EvoMemKG 等最新 SOTA 方法直接对比，其性能优势是否源于骨干差异而非方法本身，论文未给出回答。
