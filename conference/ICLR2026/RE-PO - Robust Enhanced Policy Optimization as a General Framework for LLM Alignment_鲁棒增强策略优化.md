# ICLR2026最新论文 ｜RE-PO: Robust Enhanced Policy Optimization as a General Framework for LLM Alignment ｜鲁棒增强策略优化

研究机构：美国麻省理工学院、清华大学

作者：Xiaoyang Cao、Zelai Xu、Mo Guang 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.24159)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.24159)

> 大语言模型偏好优化面临的核心矛盾是：主流算法假设偏好数据干净可靠，但实际数据集中20%-40%的标签存在噪声，导致模型过拟合错误信号并引发性能退化。现有鲁棒方法或需已知全局噪声率，或仅修改损失函数形状，无法自适应区分信号与噪声。RE-PO将标签正确性建模为潜在变量，通过EM算法联合推断标注者可靠性与策略参数，实现了对DPO等主流算法的系统性鲁棒化。该框架在多个基准上验证了有效性，但其理论恢复保证依赖于完美校准假设，在严重失准初始化下的鲁棒性边界尚不明确。

## 研究背景

偏好对齐任务中，模型需从成对响应 $(y_w, y_l)$ 中学习人类偏好，但标注过程受主观性、注意力分散及系统性偏差影响，产生大量噪声标签。标准损失函数（如DPO的交叉熵）对噪声敏感，会将错误标签视为真值进行优化，导致泛化性能严重下降。这一现象在标签噪声学习（Learning with Noisy Labels, LNL）领域已有充分研究，但其在大规模LLM对齐场景中的具体影响机制及解决方案尚不清晰。

直接偏好优化（Direct Preference Optimization, DPO）及其变体（如IPO、SimPO）已成为离线对齐的主流范式，其核心优势在于消除显式奖励模型，简化训练流程。然而，这些方法均隐含“硬标签”假设，即每个偏好对都是绝对正确的二元选择。当数据噪声率超过10%时，下游胜率可能下降数十个百分点，这一瓶颈限制了DPO在真实场景中的部署价值。现有鲁棒方法如rDPO需预先知道全局噪声率，Holder-DPO通过损失重降性处理异常值，但均缺乏对标注者个体可靠性的建模能力。RE-PO的切入点在于将标注者可靠性作为可学习的潜在变量，通过期望最大化（Expectation-Maximization, EM）算法动态推断每个标签的正确性后验概率，从而在无需先验噪声率的情况下实现自适应去噪。

## 核心方法

### 方法参照系

标准DPO通过最小化分类损失优化策略 $\pi_\theta$，其损失函数为 $-\log \sigma(\beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)})$。该流程假设所有标签正确，未考虑数据生成过程中的噪声机制。RE-PO的关键差异在于引入潜在变量模型，将标签正确性视为待推断的隐状态，而非固定真值。

### 潜在变量建模与诱导概率

RE-PO的核心创新在于将标注者可靠性 $\eta_k$ 和标签正确性 $z_i$ 建模为潜在变量。对于每个数据点，引入二元变量 $z_i \in \{0, 1\}$，其中 $z_i=1$ 表示观测标签与无噪声真值一致。标注者 $k$ 的可靠性定义为 $\eta_k \triangleq p(z_i=1 | k_i=k)$。为兼容不同偏好损失，RE-PO通过Gibbs构造将任意损失函数 $L_{pref}$ 转化为诱导概率模型：

$$
p(y_w \succ^* y_l | x, \theta) = \sigma(L_{pref}(x, y_l \succ y_w; \theta) - L_{pref}(x, y_w \succ y_l; \theta))
$$

该公式将损失函数的差值映射为无噪声偏好概率，使DPO、IPO等非似然损失也能纳入统一的概率框架。这一设计解决了此前方法无法处理非似然损失鲁棒化的问题，因为传统方法仅针对特定损失形状进行修改，而RE-PO通过概率重构实现了通用性。

### EM算法与在线更新

基于潜在变量模型，RE-PO采用EM算法交替优化策略参数 $\theta$ 和可靠性参数 $\eta$。E-step计算每个标签的正确性后验概率 $w_i$，作为软置信度权重：

$$
w_i = \frac{\eta_{k_i} p(y_{w,i} \succ^* y_{l,i} | x_i, \theta^{(t)})}{\eta_{k_i} p(y_{w,i} \succ^* y_{l,i} | x_i, \theta^{(t)}) + (1-\eta_{k_i}) p(y_{l,i} \succ^* y_{w,i} | x_i, \theta^{(t)})}
$$

M-step使用 $w_i$ 作为自适应权重更新策略，并通过闭式解更新可靠性 $\eta_k$ 为标注者 $k$ 所有标签置信度的平均值。为降低计算成本，RE-PO采用指数移动平均（EMA）进行在线更新，平衡历史估计与当前批次信息。这一机制解决了全批次更新计算开销过大的问题，使RE-PO适用于大规模分布式训练场景。

## 实验评估

实验在Mistral-7B-Instruct-v0.2和Llama-3-8B-Instruct上验证RE-PO，使用UltraFeedback衍生数据集训练，AlpacaEval 2和Arena-Hard评估。基线覆盖DPO、IPO、SimPO、CPO及其标签平滑变体，以及rDPO、Holder-DPO等鲁棒方法。RE-PO在四个算法家族上均取得一致提升，其中RE-DPO在Mistral-7B上将AlpacaEval 2 LC胜率从28.5提升至35.5（+7.0），在Llama-3-8B上从40.8提升至44.1（+3.3）。

| 方法 | Mistral-7B LC/WR | Llama-3-8B LC/WR |
| :--- | :--- | :--- |
| DPO | 28.5 / 28.6 | 40.8 / 42.9 |
| RE-DPO | 35.5 / 33.0 | 44.1 / 46.2 |
| IPO | 30.8 / 28.0 | 43.6 / 41.6 |
| RE-IPO | 32.9 / 30.5 | 48.3 / 48.6 |
| SimPO | 28.3 / 29.7 | 44.5 / 37.1 |
| RE-SimPO | 30.4 / 32.9 | 48.1 / 38.7 |
| CPO | 26.3 / 26.4 | 46.9 / 39.4 |
| RE-CPO | 28.5 / 28.8 | 40.1 / 43.8 |

消融实验显示，初始可靠性 $\eta_0=0.9$ 和EMA动量 $\alpha=0.1$ 为最优配置。$\eta_0=0.99$ 导致模型过度信任噪声标签，$\alpha=0.001$ 使可靠性更新过慢，无法适应策略变化。在MultiPref多标注者数据集上，RE-DPO在Llama-3-8B上将LC胜率从36.7提升至41.1，验证了其在真实标注者异质性下的有效性。

评估边界方面，论文未报告置信区间，且理论恢复保证（Theorem 4.1）依赖于完美校准假设，而实际模型难以满足此条件。代码已开源，但超参数敏感性分析仅覆盖有限范围，EMA更新在策略快速变化时的滞后效应未充分探讨。

## 关联研究分析

从问题动机看，RE-PO与rDPO、Holder-DPO同属鲁棒对齐路线，但机制本质不同。rDPO需已知全局噪声率构造无偏估计，Holder-DPO通过损失重降性抑制异常值，两者均未建模标注者个体差异。RE-PO通过潜在变量推断每个标注者的可靠性，实现了细粒度的样本级加权，这源于其对数据生成过程的显式建模，而非仅修改损失形状。这一差异在标注者数量多且可靠性差异大时尤为关键，但论文未对比标注者数量对EM收敛性的影响。

从方法设计看，RE-PO借鉴了Dawid-Skene模型和Crowd-BT的EM思想，但将其迁移至LLM偏好优化场景。与标准DPO相比，RE-PO引入了额外的可靠性参数 $\eta_k$ 和E-step计算，增加了计算开销。与SimPO等参考模型无关的方法相比，RE-PO保留了参考策略的正则化作用，这可能影响其在长序列生成中的长度偏差表现。论文未探讨RE-PO与长度归一化方法的组合效果，也未分析EMA更新在动态数据流中的稳定性。

## 总结

RE-PO旨在解决偏好数据噪声导致的对齐失效问题，其切入点在于将标注者可靠性建模为可学习的潜在变量，通过EM算法实现自适应去噪。该方法将DPO等主流算法转化为鲁棒版本，在AlpacaEval 2上取得最高7.0个百分点的胜率提升，并在MultiPref数据集上验证了多标注者场景下的有效性。然而，其理论恢复保证依赖于完美校准假设，而实际模型难以满足此条件；EMA更新机制在策略快速变化时的滞后效应也未充分验证。当基础模型处于严重失准状态时，E-step是否仍能准确推断标签正确性，论文未给出回答。
