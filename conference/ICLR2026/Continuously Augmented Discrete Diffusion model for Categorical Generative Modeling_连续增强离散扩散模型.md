# ICLR2026最新论文 ｜Continuously Augmented Discrete Diffusion model for Categorical Generative Modeling ｜连续增强离散扩散模型

作者：Huangjie Zheng、Shansan Gong、Ruixiang Zhang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.01329)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.01329)

> 掩码离散扩散模型（Masked Discrete Diffusion, MDM）在去噪过程中将未观测 token 映射为吸收态 [MASK]，导致语义信息在步骤间彻底丢失，形成“信息空洞”，使模型在歧义处缺乏分级指导。现有连续扩散模型（Continuous Diffusion Models, CDM）虽能保留语义邻近性，但存在过度平滑与舍入误差，难以精确预测离散 token。CADD 通过并行引入连续潜变量，在保留离散掩码框架的同时，利用平滑衰减的语义提示引导去噪，实现了生成质量与多样性的平衡。该设计在文本与代码生成上优于纯 MDM，但未验证其在复杂推理任务中能否替代强化学习对齐，且连续潜变量的训练稳定性尚存疑。

## 研究背景

当模型面对“Language”或“Diffusion”两个候选词时，纯 MDM 的 [MASK] 状态无法提供偏向任一选项的语义线索，迫使模型在缺乏分级指导的情况下进行硬选择。这种信息丢失源于吸收态设计，它抹去了被掩码位置与原始 token 的相似度信息，加剧了早期错误固化。为解决此问题，CDM 将 token 映射至连续嵌入空间进行高斯扩散，保留了平滑语义信号，但其去噪过程完全在连续空间进行，仅在最后一步离散化，导致 token 身份被过度平滑，产生舍入误差。

MDLM 已成为挑战自回归范式的主流路线，其基于掩码的并行解码显著提升了推理效率，并在 OpenWebText 等基准上达到与 AR 模型持平的困惑度。然而，MDLM 的固定掩码机制导致误差累积，且缺乏对歧义 token 的细粒度控制。现有改进多聚焦于重掩码策略或架构优化，但未解决掩码本身造成的语义信息梯度丢失。CADD 的切入点在于融合 MDM 的稳定性与 CDM 的灵活性，通过连续潜变量在离散掩码过程中保留语义提示，从而在不改变骨干网络的前提下提升生成质量。

## 核心方法

### 离散掩码扩散参照系

标准 MDM 的前向过程通过单调递增的掩码概率将原始序列 $x_0$ 转化为全掩码序列 $x_T$，反向过程学习预测被掩码位置的真实 token。其训练目标为最小化变分下界，通常简化为交叉熵损失。本文问题与该通用流程的关键差异在于：MDM 的 [MASK] 状态是信息黑洞，无法区分不同 token 的语义邻近性，而 CADD 在掩码位置引入了保留语义信息的连续潜变量。

### 连续潜变量增强机制

CADD 在离散掩码过程中并行引入连续潜变量 $z_t$，其设计动机是解决 MDM 中 [MASK] 状态导致的语义信息梯度丢失。对于被掩码的位置，$z_t$ 不再坍缩为零向量，而是遵循高斯扩散轨迹平滑衰减，保留原始 token 嵌入的分级邻近性。前向过程中，$z_t$ 的演化由离散掩码状态触发，一旦 token 被掩码，其嵌入即开始沿高斯路径退化，SNR 平滑下降而非骤降至零。

$$
z_t^{[i]} = \sqrt{\bar{\gamma}_t} z_0^{[i]} + \sqrt{1 - \bar{\gamma}_t} \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)
$$

该公式表明，被掩码位置的连续潜变量 $z_t^{[i]}$ 是原始嵌入 $z_0^{[i]}$ 与高斯噪声的线性组合，$\bar{\gamma}_t$ 控制噪声强度。这种平滑衰减使得模型在去噪时能利用 $z_t$ 作为软语义提示，降低歧义 token 的预测难度。

### 多采样估计与训练简化

CADD 在采样时允许对连续潜变量进行多次重采样（$K$ 次），以探索替代但有效的 token 选择，从而增强生成多样性。训练时，CADD 保持标准交叉熵损失用于离散 token 预测，并可选地加入重加权 MSE 损失用于连续潜变量预测。这种设计使得 CADD 无需特殊架构，可直接复用 MDM 骨干网络，参数量与 MDM 相同（168M 参数），且 $K=1$ 时计算开销与 MDM 相当。

$$
\mathcal{L}_{\text{CADD}} = \mathcal{L}_{\text{CE}}(x_0, x_t, z_t) + \lambda \mathcal{L}_{\text{MSE}}(z_0, z_t)
$$

该损失函数表明，CADD 通过联合优化离散 token 预测与连续潜变量预测，实现了训练过程的简化。$\lambda$ 控制连续损失的权重，实验中通常设为 0 以追求计算效率，仅在需要更精确变分下界时启用。

## 实验评估

实验在 OpenWebText (OWT)、HumanEval 和 BigCodeBench 上进行，基线包括 MDLM、SEDD、DiffuCoder 及 AR 模型 Qwen2.5-Coder。CADD 在 OWT 上的生成困惑度（Generative PPL）显著低于 MDLM，例如在 128 步采样时，CADD 为 49.6，MDLM 为 55.3。在代码生成任务上，CADD 的 HumanEval Pass@1 达到 72.0，优于 DiffuCoder 的 67.1；BigCodeBench-Hard 子集上，CADD 从 12.8 提升至 17.6。

| 数据集 | 指标 | CADD | MDLM | DiffuCoder | Qwen2.5-Coder |
| :--- | :--- | :--- | :--- | :--- | :--- |
| OWT | Gen PPL (128 steps) | 49.6 | 55.3 | - | - |
| HumanEval | Pass@1 | 72.0 | - | 67.1 | - |
| BigCodeBench-Hard | Pass@1 | 17.6 | - | 12.8 | - |

CADD 在 OWT 上的 PPL 优势表明连续潜变量有效缓解了信息空洞问题，而在代码生成上的提升验证了其在结构化任务中的适用性。然而，论文未报告 GSM8K 或 MATH500 等复杂推理基准的结果，无法直接对比 SPG 或 TraceRL 等 RL 对齐方法。

消融实验显示，$K=1$ 时 CADD 的计算时间与 MDLM 相当（5000 样本在 8 张 H100 上耗时 0.5 小时），但 $K>1$ 时计算成本线性增加。多采样估计在提升多样性的同时，可能引入额外的推理延迟，论文未量化 $K$ 值对质量与效率的具体权衡。

评估边界方面，论文未提供代码仓库，超参数细节（如 $\bar{\gamma}_t$ 调度）未在正文中完整列出，可复现性受限。指标完备性上，缺乏对长文本生成一致性的评测，且未报告置信区间，数值比较需谨慎。

## 关联研究分析

从问题动机看，CADD 与重掩码策略（如 Self-Reflective Remasking）均旨在缓解早期错误固化，但路径不同。重掩码通过动态调整掩码状态来修正错误，而 CADD 通过保留语义信息来预防错误。CADD 的优势在于无需额外推理步骤，但重掩码可能更适应长序列中的累积误差。CADD 未探索与重掩码的结合，其在长文本生成中的有效性存疑。

从方法设计看，CADD 与 CDCD（Dieleman et al., 2022）均利用连续空间，但 CDCD 完全在连续空间去噪，而 CADD 保留离散掩码框架。CADD 的混合设计避免了 CDCD 的舍入误差，但引入了连续潜变量的训练不稳定性风险。论文未报告训练过程中的损失曲线或收敛性分析，连续潜变量是否在所有任务上都优于纯离散掩码，缺乏系统性验证。

## 总结

CADD 要解决的核心矛盾是 MDM 中 [MASK] 状态导致的语义信息梯度丢失，现有方法要么牺牲离散精度（CDM），要么依赖额外推理步骤（重掩码）。CADD 通过并行引入连续潜变量，在保留离散掩码框架的同时，利用平滑衰减的语义提示引导去噪，实现了生成质量与多样性的平衡。实验证明，CADD 在 OWT 上的 Gen PPL 为 49.6（128 步），HumanEval Pass@1 为 72.0，均优于纯 MDM 基线。然而，论文未验证 CADD 在复杂推理任务中的表现，且连续潜变量的训练稳定性与 $K$ 值对效率的影响未充分量化。当序列长度增加至 4096 时，连续潜变量的语义提示是否仍能有效抑制误差累积，论文未给出回答。
