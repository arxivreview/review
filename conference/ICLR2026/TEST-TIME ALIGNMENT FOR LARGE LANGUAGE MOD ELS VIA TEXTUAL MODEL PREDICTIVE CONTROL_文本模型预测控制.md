# ICLR2026最新论文 ｜TEST-TIME ALIGNMENT FOR LARGE LANGUAGE MOD ELS VIA TEXTUAL MODEL PREDICTIVE CONTROL ｜文本模型预测控制

研究机构：国立阳明交通大学、国立台湾大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_48876948)

> 测试时对齐旨在不更新参数的前提下修正大语言模型输出，以规避重训的高昂成本。现有方法在Token级引导时受困于长序列信用分配失效，在响应级重写时则陷入高维动作空间搜索不稳定的困境。本文引入控制理论中的模型预测控制思想，通过事后识别高奖励子目标并以此为条件迭代再生成，在无需训练的情况下平衡了规划时域与动作维度。该框架在翻译、长文本生成及代码合成任务上验证了有效性，但其对奖励模型质量的依赖及子目标粒度选择的自动化程度仍存疑。

## 研究背景

当模型生成长序列文本时，若将每个Token视为独立动作，长程依赖导致早期错误在后续步骤中累积放大，这种长时域下的信用分配失效被称为“时间维度的诅咒”。反之，若将整段响应视为单一动作进行迭代重写，动作空间随序列长度指数级膨胀，搜索过程极易陷入局部最优或产生不稳定的振荡，即“维度诅咒”。解决这一矛盾需要一种介于Token级与响应级之间的中间粒度规划机制，而模型预测控制（Model Predictive Control, MPC）通过滚动时域优化局部目标来逼近全局最优，为文本生成提供了天然的结构参照。

训练时对齐方法如直接偏好优化（Direct Preference Optimization, DPO）虽能内化偏好，但每次偏好变更均需重训，资源消耗巨大。测试时对齐路线试图在推理阶段通过外部信号引导生成，但现有方法存在结构性缺陷：引导解码（Guided Decoding）如ARGS在Token级操作，受限于时间诅咒；迭代精化（Iterative Refinement）如TPO在响应级操作，受限于维度诅咒。本文切入点在于将文本生成重构为轨迹优化问题，利用MPC的滚动时域特性，通过动态发现任务特定的子目标来缩短有效规划时域，同时通过子目标条件化再生成来约束动作空间，从而在免训练条件下实现稳定对齐。

## 核心方法

### 轨迹优化参照系

文本生成被形式化为有限时域马尔可夫决策过程（MDP），目标是最长轨迹累计奖励 $J(\tau)$。标准模型预测路径积分（Model Predictive Path Integral, MPPI）通过采样多条轨迹并基于奖励加权聚合来近似最优动作序列。本文的关键差异在于：标准MPC假设存在预定义的硬分段边界，而文本生成（尤其是代码或长文本）缺乏自然边界，因此需引入动态子目标机制替代固定分段。

### 事后子目标识别

传统MPC依赖预定义的分段边界，但在无自然边界的文本任务中，固定分段往往切分语义单元，导致规划信号噪声化。TMPC通过事后子目标识别（Hindsight Subgoal Identification）解决此问题：在生成多条候选轨迹后，回溯分析并提取高奖励的中间片段作为子目标。子目标缓冲区 $B$ 的更新规则为：

$$ B_{t+1} = \text{TopK}_\alpha \left( \{ \text{segments}(\tau_i) \mid J(\tau_i) > \alpha \} \right) $$

其中 $\alpha$ 为奖励阈值，$\text{TopK}_\alpha$ 选取奖励高于阈值且质量最高的 $K$ 个片段。这一设计将“规划步骤”从预定义结构转变为数据驱动发现，使规划时域自适应于任务结构（如翻译中的句子、代码中的函数块），有效规避了固定分段导致的语义断裂。

### 子目标条件化再生成

仅识别子目标不足以保证全局最优，需确保新轨迹能复用已验证的高质量片段。TMPC通过子目标条件化再生成（Subgoal-Conditioned Re-Generation）实现累积改进：下一轮生成的轨迹 $\tau_{t+1}$ 以缓冲区 $B$ 中的子目标为条件，通过聚合函数 $G$ 组合这些片段并扩展至完整序列。聚合函数定义为：

$$ \mathbf{a}_{\text{TMPC}} = G(\{ \tau_i \}_{i=1}^K, B) = \sum_{i=1}^K \frac{\exp(\lambda J(\tau_i))}{\sum_{j=1}^K \exp(\lambda J(\tau_j))} \mathbf{a}_i $$

其中 $\lambda$ 控制探索-利用权衡。该公式表明，高奖励轨迹及其子目标在组合中占据更高权重，使优化过程从“随机搜索”转向“基于已验证片段的定向扩展”。这一机制确保每次迭代都建立在上一轮发现的最优局部解之上，避免了迭代精化中常见的振荡与退化，实现了稳定累积的对齐增益。

## 实验评估

实验在WMT’24文学翻译、HH-RLHF长文本子集及MBPP代码合成三个任务上进行，基线覆盖引导解码（ARGS, RAIN, RE-Control, GenARM）与迭代精化（TPO）两类主流测试时对齐方法，以及训练时方法（DPO, SimPO）。基线选择完整覆盖了Token级与响应级两条技术路线，但未包含InferAligner等基于内部表示修改的测试时方法，可能低估了TMPC相对于此类方法的相对优势。

| 任务 | 方法 | 指标 | 数值 |
| :--- | :--- | :--- | :--- |
| WMT’24 zh→en | TMPC | SEGALEcomet | 94.62 |
| WMT’24 zh→en | GPT-4o | SEGALEcomet | 94.58 |
| WMT’24 zh→en | Best-of-60 | SEGALEcomet | 90.97 |
| MBPP | TMPC | Pass Rate | 61% |
| MBPP | TPO (iter=4) | Pass Rate | 48% |
| MBPP | Best-of-35 | Pass Rate | 50% |

TMPC在WMT’24 zh→en方向上以94.62的SEGALEcomet得分超越GPT-4o（94.58）及Best-of-60（90.97），且在MBPP上以61%通过率显著优于TPO（48%）与Best-of-35（50%）。值得注意的是，TMPC仅需10次LLM调用（3轮迭代×3条轨迹+1次初始生成），而TPO在4轮迭代时需20次调用，表明TMPC在样本效率上具有优势。

消融实验显示，移除事后子目标识别（Principle 1）导致平均奖励从4.595降至4.264，降幅最大，证实子目标质量排序对优化方向的决定性作用；移除子目标条件化再生成（Principle 2）则降至4.463，表明条件化机制对累积改进的贡献。超参数敏感性分析表明，缓冲区大小与分段长度的变化对性能影响小于0.1点，框架对超参数不敏感。然而，当奖励模型验证准确率从88.53%降至77.54%时，平均奖励从4.595降至4.332，显示TMPC对奖励模型质量存在中度依赖，子目标缓冲区的过滤机制仅能部分缓解噪声影响。

评估协议存在局限：WMT’24使用MetricX-24-XL进行无参考评估，可能无法捕捉细微语义偏差；MBPP仅报告通过率，未区分部分正确性；长文本任务使用GPT-4作为裁判，存在裁判偏差风险。论文未提供代码开源链接的具体实现细节，仅给出项目页面，可复现性依赖社区后续贡献。

## 关联研究分析

从问题动机看，TMPC与TPO（Li et al., 2025）均针对迭代精化的不稳定性，但根源处理方式不同。TPO依赖文本批评作为语言奖励，其改进依赖于模型自我评估的准确性，当模型能力不足时批评信号易失真；TMPC则依赖数值奖励子目标，将改进锚定在可量化的局部最优片段上，避免了文本批评的模糊性。这一差异源于任务特性：代码合成等结构化任务中，局部正确性（如通过单个测试用例）可被精确量化，而开放式长文本中，局部“正确性”的定义更为模糊，TMPC在此类任务上的子目标发现能力可能受限。

从方法设计看，TMPC与MPPI（Williams et al., 2015）共享轨迹加权聚合框架，但关键差异在于动作空间的离散性与子目标的动态性。MPPI假设连续动作空间与固定时域，而TMPC通过子目标缓冲将离散文本片段转化为可组合的“伪连续”动作单元，实现了滚动时域优化。这一改造解决了标准MPC在文本生成中因缺乏自然边界而失效的问题，但引入了对奖励模型质量的依赖。MPPI在连续控制中依赖精确动力学模型，而TMPC依赖奖励模型作为“文本动力学”的代理，当奖励模型无法准确反映偏好时，规划路径可能偏离真实最优，这一风险在开放域任务中更为突出。

## 总结

TMPC旨在解决测试时对齐中Token级引导的时间诅咒与响应级重写的维度诅咒之间的矛盾。其切入点在于将文本生成重构为轨迹优化问题，通过事后子目标识别动态发现任务特定的规划步骤，并以子目标条件化再生成实现稳定累积改进。实验表明，TMPC在WMT’24 zh→en方向上以94.62的SEGALEcomet得分超越GPT-4o，在MBPP上以61%通过率优于TPO的48%。然而，其性能对奖励模型质量存在中度依赖，当验证准确率降至77.54%时性能下降0.263点，且子目标粒度选择仍依赖人工设定的缓冲区大小与分段长度。当任务缺乏可量化的局部正确性信号（如开放式创意写作）时，事后子目标识别能否发现有效的规划步骤，论文未给出回答。
