# ICLR2026最新论文 ｜CellDuality : UNLOCKING BIOLOGICAL REASONING IN LLMS WITH SELF-SUPERVISED RLVR ｜互补任务对偶自监督强化学习

研究机构：美国北卡罗来纳大学教堂山分校、美国亚利桑那州立大学

作者：Yuhang Chen、Zhen Tan、Ruichen Zhang 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_67270394)

> 单细胞生物推理面临的核心困境是缺乏可验证的地面真值，导致基于可验证奖励的强化学习（RLVR）范式失效。现有LLM模型多优化预测精度或局限于逻辑谜题，缺乏开放式的机制推理能力。CellDuality通过构建前向-逆向互补任务对，利用重建一致性作为内在奖励信号，实现了无需外部标注的自监督RL对齐。该框架在分布外扰动预测上缩小了与全监督模型的差距，但其数值精度仍低于全监督基线，且未证明超越专用生成式模型的分布保真度。

## 研究背景

单细胞生物推理要求模型从转录组数据中推断因果机制，而非仅拟合统计相关性。这一过程涉及将细胞表达谱转化为序列化的“Cell Sentence”，并在此基础上执行细胞身份标注、条件生成、药物敏感性分类及扰动响应生成四类任务。由于RNA-seq数据的破坏性，扰动前后的细胞无法一一配对，传统监督学习失效，必须依赖分布建模或生成式方法解决非配对数据对齐问题。然而，生成式模型（如scDFM、scPPDM）虽能捕捉分布异质性，却难以提供生物学机制解释；而现有LLM基础模型（如scGPT、InstructCell）虽具备通用表示能力，但往往掩盖扰动特异性信号，且未显式训练生成连贯的解释性步骤。

RLVR在数学和代码合成中通过确定性验证器提供客观奖励，显著提升了LLM的推理能力。但在生物学中，大多数推理任务（如条件细胞生成）的输出具有内在随机性，不存在唯一正确的基因序列版本，使得简单验证不可行。Cell-o1将生物推理框定为逻辑约束谜题，虽引入了推理概念，但限制了开放式假设驱动的科学探索。CellDuality的切入点在于解决生物任务不可验证的根本瓶颈：通过设计互补任务对，让模型自身生成监督信号，从而在缺乏地面真值的情况下实现深度机制推理。

## 核心方法

### 任务形式化与对偶原理

CellDuality将单细胞推理组织为2x2矩阵，涵盖细胞身份（标注/生成）和细胞动态（敏感性/响应）四大任务。核心创新是互补任务对偶（Complementary Task Duality）原则，旨在解决生物任务缺乏可扩展奖励源的问题。设原任务 $T_p: X \to Y$ 的输入空间 $X$ 分解为已知分量 $X_k$ 和未知分量 $X_u$。互补对偶任务 $T_{cd}$ 利用原任务输出 $y$ 和已知分量 $x_k$ 重建未知分量 $\hat{x}_u$。

$$
d(x_u, \hat{x}_u) \le \epsilon
$$

该公式定义了互补一致性原则：当重建误差低于阈值 $\epsilon$ 时，原任务输出被视为逻辑和生物学上连贯的。这一设计动机在于，通过强制模型满足双向推理循环，将无监督问题转化为自验证问题，避免了经典对偶学习中的不可逆性和不对称性挑战。

### 两阶段自监督训练

训练分为SFT冷启动和自监督RL对齐两个阶段。SFT阶段利用教师模型（如GPT-4o）生成高质量思维链（CoT）数据集，包含原任务和对偶任务的推理轨迹。对于分类任务，采用拒绝采样确保答案正确；对于生成任务，采用秩感知过滤，使用秩加权Jaccard相似度（RWJS）评估生成序列与真值在基因重叠和表达排序上的保真度。

$$
\mathcal{L}_{SFT}(\theta) = -\sum_{(x, y) \in \mathcal{D}_{SFT}} \log \pi_\theta(y|x)
$$

SFT阶段的目标是最小化负对数似然，使模型掌握生物推理的语言和格式。随后进入RL阶段，使用组相对策略优化（GRPO）在大规模无标签数据上对齐模型。奖励信号直接来自对偶任务的重建一致性，即比较重建输入与原始输入的相似度。这一机制消除了对昂贵且稀缺的地面真值标签的依赖，使模型能够学习生物过程的内在机制一致性，而非仅拟合表面统计模式。

## 实验评估

实验在He-2020-Liver、Segerstolpe-2016、Xin-2016、GSE149383、GSE117872、GSE110894及sci-Plex3等数据集上进行，基线包括scGPT、Geneformer、InstructCell、C2S-Scale及scGen等。CellDuality基于Llama-3.2-3B架构，SFT阶段学习率为1e-5，RL阶段使用GRPO，组大小G=8，运行200步。

| 任务 | 数据集 | 模型 | Acc. (%) | F1 (%) | scFID | MMD |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 细胞标注 | He-2020-Liver | CellDuality (Self-Sup) | 96.34 | 95.41 | - | - |
| 细胞标注 | He-2020-Liver | RL with Ground-Truth | 97.21 | 94.85 | - | - |
| 扰动响应 | sci-Plex3 | CellDuality (Self-Sup) | - | - | 0.038 | 0.019 |
| 扰动响应 | sci-Plex3 | RL with Ground-Truth | - | - | 0.025 | 0.012 |
| 扰动响应 | sci-Plex3 | C2S-Scale (GRPO w/ GT) | - | - | 0.02 | 0.01 |

在He-2020-Liver标注任务上，CellDuality的Accuracy为96.34%，低于全监督RL的97.21%，但Macro F1-score为95.41%，高于全监督的94.85%，表明其决策边界更鲁棒。在sci-Plex3扰动响应生成上，CellDuality的scFID为0.038，MMD为0.019，优于SFT-only基线（0.045/0.028），但高于全监督RL（0.025/0.012）和C2S-Scale（0.02/0.01）。这表明自监督RL显著提升了性能，但仍未达到全监督的数值精度上限。

消融实验显示，自监督RL在所有任务上均显著优于SFT-only基线。在OOD扰动预测上，CellDuality缩小了与全监督RLVR模型35-56%的性能差距。这一结果验证了对偶奖励机制的有效性，但也暴露了自监督信号在捕捉细微分布差异上的局限性。

评估边界方面，论文未报告计算效率指标，且缺乏与主流生成式SOTA（如scDFM、scPPDM）在Tahoe-100M等大规模基准上的直接横向对比。代码未公开，但提供了详细的超参数设置（8x A6000 GPUs）。指标涵盖Accuracy、F1、scFID、MMD及GW距离，但未包含E-distance等分布距离指标，可能低估了模型在分布层面的性能。

## 关联研究分析

从问题动机看，CellDuality与Cell-o1均旨在提升LLM的生物推理能力，但Cell-o1将推理框定为逻辑约束谜题，限制了开放式探索；CellDuality则通过互补任务对偶实现开放式机制推理。这一差异源于任务特性：逻辑谜题有唯一解，而生物响应具有随机性，需通过一致性验证而非精确匹配来评估。CellDuality借鉴了DuPO的对偶原理，将其从数学领域迁移至生物领域，解决了生物任务不可验证的问题。

从方法设计看，CellDuality与InstructCell同属多任务LLM智能体框架，但InstructCell依赖外部知识图谱或监督微调，缺乏深度机制推理；CellDuality通过自监督RL增强内在一致性。与生成式模型（如scDFM）相比，CellDuality牺牲了数值精度以换取机制解释性。scDFM在Tahoe-100M上DEG Δ-Pearson为0.85，而CellDuality未报告该指标，无法直接比较。CellDuality的自监督奖励是否足以替代数值精度上的监督信号，论文未给出明确回答，仅显示其缩小了与全监督模型的差距。

## 总结

CellDuality旨在解决单细胞生物推理中缺乏可验证奖励的瓶颈，通过互补任务对偶生成内在奖励信号，实现了自监督RL对齐。该方法在He-2020-Liver标注任务上Macro F1-score达95.41%，在sci-Plex3扰动响应生成上scFID为0.038，显著优于SFT基线，但低于全监督RL的0.025。其边界在于数值精度仍落后于全监督模型，且未证明超越专用生成式模型的分布保真度。当支持集增大或数据分布发生偏移时，对偶奖励的一致性信号是否仍能保持鲁棒性，论文未提供进一步验证。
