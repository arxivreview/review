# ICLR2026最新论文 ｜Beyond Structure: Invariant Crystal Property Prediction with Pseudo-Particle Ray Diffraction ｜伪粒子射线衍射网络

研究机构：香港科技大学、香港中文大学

作者：Bin Cao、Yang Liu、Longhan Zhang 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.21778)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.21778)

> 晶体性质预测（CPP）的核心瓶颈在于实空间图编码的有限感受野导致不同晶体结构映射至相同表示，进而丢失决定物理性质的长程原子相互作用。现有倒易空间方法虽引入傅里叶变换，但忽略了形状因子的环境依赖性与不变性，且将衍射特征作为原子级信息融合而非全局模态处理。PRDNet 通过引入可学习的伪粒子探针生成物理不变的合成衍射图案，并在模态层面与图特征融合，解决了表示唯一性问题。该方法在多个基准上刷新了晶体性质预测的精度上限，但其对非周期性体系及动力学稳定性的适用性仍存疑。

## 研究背景

晶体结构本质上是无限周期性三维原子系统，其物理性质由电子密度分布决定。在实空间中，图神经网络（GNN）通过截断半径内的消息传递聚合局部原子信息，这种局部编码机制天然存在感受野限制。当晶体结构的差异源于长程周期性或细微对称性变化时，局部邻域可能完全相同，导致不同晶体被映射至相同的图表示，即表示碰撞。这种碰撞使得模型无法区分具有不同长程相互作用的晶体，从而在预测形成能、带隙等依赖全局电子结构的性质时产生系统性误差。

当前主流晶体编码路线包括多边形图、角度嵌入及周期性向量参考系，它们均未能从根本上解决表示唯一性问题。早期工作如 CGCNN 和 MEGNet 仅依赖成对距离，无法捕捉角度信息；ALIGNN 和 M3GNet 引入键角特征，但受限截断半径仍可能导致角度关系相同；MatFormer 和 Crystalformer 等 Transformer 架构虽扩展了关联范围，但仍基于实空间坐标，难以保证对长程效应的无损编码。与此同时，倒易空间衍射被证明是晶体结构的唯一表示，因为完整的衍射图案可由单个实空间晶胞解析推导，无需构建大超胞。然而，现有倒易空间方法如 EwaldMP 和 PotNet 将 Ewald 求和视为类似傅里叶的信息融合，忽略了形状因子（Form Factor）作为物理量的唯一性和不变性，且未保留形状因子对局部化学环境的依赖，导致倒易空间表示在物理上不一致。

PRDNet 的切入点在于将衍射视为独立于实空间图的全局模态，并引入可学习的伪粒子探针替代固定物理表值。这一设计旨在解决两个关键缺陷：一是传统物理探针（如 X 射线）的形状因子仅依赖原子种类和散射矢量，无法区分同一元素在不同局部环境中的差异；二是现有方法将衍射特征作为原子级特征融合，违背了衍射作为整体结构属性的物理本质。通过构建物理不变的合成衍射图案，PRDNet 试图在保持计算效率的同时，实现晶体表示的唯一性与长程相互作用的显式建模。

## 核心方法

### 方法参照系

晶体性质预测的标准流程是将晶体结构编码为图，通过消息传递层聚合节点特征，最后通过全局池化得到结构嵌入以预测性质。本文问题与该通用流程的关键差异在于，标准流程仅依赖实空间局部几何，缺乏对长程周期性效应的无损编码机制，且未将衍射这一全局物理属性作为独立模态纳入学习框架。

### 可学习伪粒子形状因子

传统 X 射线衍射中，原子形状因子 $f_{i}[\text{type}]$ 是固定表值，仅依赖散射矢量大小 $|\mathbf{Q}|$ 和原子种类，无法感知局部化学环境。PRDNet 引入可学习伪粒子，定义其形状因子为：

$$ f_{i}^{\text{pseudo}}(\mathbf{Q}) = G_{\theta}(\mathbf{G}) \cdot f_{\text{base}}(|\mathbf{Q}|) $$

其中 $G_{\theta}(\mathbf{G})$ 是由图网络学习的局部化学环境编码，$f_{\text{base}}$ 为基函数。这一设计动机在于解决固定表值无法区分同元素不同环境原子的失效问题。通过让形状因子显式依赖局部环境，伪粒子探针获得了对化学环境变化的敏感度，从而在倒易空间中生成具有区分度的衍射信号，弥补了实空间局部编码的不足。

### 模态级衍射-图融合

现有方法通常将倒易空间特征作为边特征或节点特征注入消息传递过程，这违背了衍射作为全局属性的物理本质。PRDNet 提出模态级融合机制，将图嵌入 $\mathbf{g}$ 与衍射嵌入 $\mathbf{d}$ 在结构层面进行整合：

$$ \mathbf{z}_{\text{fused}} = \text{MLP}_{\text{fusion}}(\text{GlobalPool}(\mathbf{g}) \oplus \text{MLP}_{\text{diff}}(\mathbf{d})) $$

其中 $\text{GlobalPool}(\mathbf{g})$ 聚合所有原子节点特征，$\mathbf{d}$ 为伪粒子衍射图案的嵌入。该设计确保了衍射信息作为整体结构描述参与预测，而非被局部消息传递稀释。由于 $\mathbf{g}$ 和 $\mathbf{d}$ 均基于相对几何特征和不变衍射模式构建，最终输出 $\mathbf{z}_{\text{fused}}$ 严格满足 E(3) 群（旋转、反射、平移）不变性，解决了此前方法在对称性约束下表示不一致的问题。

## 实验评估

PRDNet 在 Materials Project (MP)、JARVIS-DFT 和 Matbench 三个基准上进行了评估，基线覆盖 CGCNN、SchNet、MEGNet、GATGNN、MatFormer、Crystalformer、Crystalframer、eComFormer 以及倒易空间方法 EwaldMP、PotNet、ReGNet。值得注意的是，基线中未包含 MoE-MLIP、Facet 等最新高效架构，也未包含 MACE-MP-0 等通用基础模型，这可能影响对当前 SOTA 的全面对比。

| 方法 | MP 形成能 (eV/atom) | MP 带隙 (eV) | MP 体积模量 (log(GPa)) | Matbench 形成能 (eV/atom) |
| :--- | :--- | :--- | :--- | :--- |
| CGCNN | 0.041 | 0.262 | 0.079 | - |
| MatFormer | 0.035 | 0.193 | 0.089 | - |
| eComFormer | 0.033 | 0.153 | 0.088 | - |
| EwaldMP | 0.052 | 0.332 | 0.098 | - |
| PotNet | 0.035 | 0.251 | 0.104 | - |
| ReGNet | 0.047 | 0.331 | 0.088 | - |
| **PRDNet** | **0.028** | **0.151** | **0.035** | **0.019** |

PRDNet 在 MP 数据集上取得 0.028 eV/atom 的形成能 MAE，显著优于最佳基线 eComFormer 的 0.033 eV/atom 和倒易空间方法 PotNet 的 0.035 eV/atom。在 Matbench 上，PRDNet 形成能 MAE 为 0.019 eV/atom，与领域综述中提到的 Pseudo-Particle Ray 持平，优于 MatRIS 的 0.021 eV/atom。

| 消融配置 | MP 形成能 (eV/atom) | MP 带隙 (eV) | MP 体积模量 (log(GPa)) |
| :--- | :--- | :--- | :--- |
| Default (Full) | 0.028 | 0.151 | 0.035 |
| NoDiff (无衍射) | 0.041 | 0.361 | 0.081 |
| SingleHead (单头) | 0.040 | 0.318 | 0.067 |
| NoRes (无残差) | 0.038 | 0.297 | 0.077 |
| NoEdge (无边特征) | 0.043 | 0.355 | 0.071 |

消融实验显示，移除衍射模块（NoDiff）导致形成能 MAE 从 0.028 上升至 0.041 eV/atom，带隙 MAE 从 0.151 上升至 0.361 eV，表明衍射模块对长程性质预测至关重要。移除边特征（NoEdge）导致性能最差（0.043 eV/atom），说明局部几何信息与全局衍射信息缺一不可。单头注意力（SingleHead）相比多头注意力性能下降，表明多头机制有助于捕捉不同方向的衍射信息。

评估边界方面，PRDNet 仅评估了静态晶体性质，未涉及分子动力学（MD）模拟或力预测，因此无法验证其在动力学稳定性上的表现。代码已开源，但论文未报告训练超参数的详细敏感性分析，且基线中 ReGNet 的结果为作者自行实现，可能存在实现偏差。

## 关联研究分析

从问题动机看，PRDNet 与 LR-MACE 均致力于解决长程相互作用建模，但路线截然不同。LR-MACE 基于 MACE 架构，通过倒易空间注意力在消息传递过程中引入全局特征，旨在提升 MLIPs 的力预测精度；而 PRDNet 将衍射视为独立模态，通过模态级融合解决 CPP 中的表示唯一性问题。这种差异源于任务特性：MLIPs 需要逐原子力场以驱动 MD 模拟，因此长程效应需嵌入局部消息传递；CPP 关注整体结构性质，全局衍射模态更契合其物理本质。PRDNet 未验证其在力预测任务上的有效性，查询侧增强在数据充足时是否仍有增益，论文未给出回答。

从方法设计看，PRDNet 与 MatRIS 同属高效架构路线，但设计哲学不同。MatRIS 侧重 O(N) 复杂度的注意力机制，通过可分离注意力高效编码三体特征，旨在降低大规模预训练的计算成本；PRDNet 侧重物理表示的唯一性，通过可学习伪粒子增强对局部环境的敏感度，旨在提升表示的区分度。PRDNet 参数量 20.9M，未提及大规模预训练，依赖架构设计而非数据规模。这种差异暗示，在数据稀缺场景下，PRDNet 的物理约束可能比 MatRIS 的规模效应更具优势，但在数据充足场景下，MatRIS 的泛化能力可能更强。

## 总结

PRDNet 旨在解决晶体性质预测中实空间编码导致的表示碰撞问题，其切入点在于利用倒易空间衍射的唯一性，并通过可学习伪粒子探针解决固定形状因子无法区分局部环境的缺陷。该方法通过模态级融合将衍射作为全局属性纳入学习框架，在 MP 数据集上取得 0.028 eV/atom 的形成能 MAE，在 Matbench 上取得 0.019 eV/atom 的形成能 MAE，刷新了多项基准的精度上限。然而，PRDNet 的局限在于其仅针对静态晶体性质，未验证在分子动力学模拟中的稳定性，且基线中缺乏最新高效架构和通用基础模型的对比。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
