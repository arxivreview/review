# ICLR2026最新论文 ｜BEYOND FIXED: ｜动态自适应长度扩展

研究机构：香港中文大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_51250404)

> 扩散大语言模型（DLLMs）在推理时面临静态生成长度的刚性约束：长度过短导致复杂任务截断，过长则引发计算冗余甚至性能衰减。现有加速方案多聚焦于步数压缩或缓存优化，却忽视了长度维度上的资源错配。DAEDAL 利用去噪过程中模型对结束符（EOS）的预测置信度作为内部信号，通过免训练的两阶段策略动态调整序列长度。该方法在 LLaDA-8B 上实现了比固定长度基线更优的性能与更高的有效 Token 比率，但其对训练-推理分布一致性的理论保障尚存疑。

## 研究背景

DLLM 的生成过程始于一个固定长度的全掩码序列，模型通过多步迭代去噪逐步恢复文本。这一过程依赖双向注意力机制，其计算复杂度随序列长度呈二次方增长。在标准推理流程中，生成长度 $L$ 是预先设定的超参数，模型无法根据任务复杂度动态调整输出空间。这种静态设定导致了一个根本性矛盾：AR 模型能根据任务灵活调整输出长度，而 DLLM 必须将任务输出适配到给定的固定长度中。

当前领域的主流优化路线集中在减少采样步数或优化 KV 缓存，如 Fast-dLLM 和 FLASHDLM 通过并行解码提升了吞吐量，但均未触及生成长度这一核心变量。固定长度不仅造成了计算资源的浪费（生成大量无意义的填充 Token），还限制了模型在复杂推理任务上的表现，因为模型可能在中间推理步骤空间不足时被迫提前结束。DAEDAL 的切入点在于发现模型内部存在一个未被利用的信号——EOS 预测置信度，该信号能反映当前长度是否足以容纳完整回答，从而为动态长度调整提供了依据。

## 核心方法

### 掩码扩散去噪参照系

标准 DLLM 推理遵循固定的去噪范式：从长度 $L$ 的全掩码序列开始，每步预测所有掩码位置，保留高置信度 Token 并重新掩码低置信度 Token，直至无掩码剩余。该流程的关键局限在于 $L$ 在推理开始前即被锁定，缺乏对任务复杂度的自适应能力。DAEDAL 在此参照系上引入了长度动态调整机制，将静态的 $L$ 转化为动态变量。

### 初始长度调整

初始长度调整阶段发生在主去噪过程之前，旨在确定一个粗略的任务适配长度。其设计动机是解决固定长度导致的“一刀切”问题，即简单任务被过度分配空间，复杂任务则空间不足。DAEDAL 从一个短初始长度 $L_{init}$ 开始，模型对当前序列进行前向传播，计算序列末尾固定窗口内 EOS Token 的平均预测置信度。若该置信度低于阈值 $\tau$，则判定长度不足，向序列末尾追加额外的 [MASK] Token 并重复此过程，直至置信度超过阈值或达到最大长度限制。该过程可形式化为：

$$ L_{new} = L_{current} + \Delta L \cdot \mathbb{I}(\bar{C}_{EOS} < \tau) $$

其中 $\bar{C}_{EOS}$ 为窗口内 EOS 置信度均值，$\mathbb{I}$ 为指示函数。这一机制利用了模型在长度不足时倾向于利用所有可用空间、从而降低 EOS 置信度的特性，实现了长度的粗粒度自适应。

### 迭代掩码插入

迭代掩码插入阶段在主去噪过程中实时执行，旨在解决局部推理空间不足的问题。其设计动机是初始长度调整仅提供全局预算，而复杂推理可能在序列的特定局部区域需要更多“讨论空间”。在每步去噪中，除了保留高置信度 Token 外，DAEDAL 还识别出预测置信度极低（低于极低阈值）的掩码位置，将其标记为“扩展点”。这些位置不被简单重新掩码，而是被替换为多个 [MASK] Token 的块，从而在局部插入额外空间。该操作可表示为：

$$ x_{t-1}[i] = \text{[MASK]}^k \quad \text{if} \quad C_i < \tau_{low} $$

其中 $C_i$ 为位置 $i$ 的预测置信度，$k$ 为扩展因子。这种局部扩展机制允许模型在需要详细推理或描述的地方获得“呼吸空间”，避免了因空间受限导致的逻辑中断，实现了细粒度的动态长度控制。

## 实验评估

实验在 LLaDA-Instruct-8B、LLaDA-1.5-8B 和 Dream-Instruct-7B 上进行，基准涵盖 GSM8K、MATH500、MBPP 和 HumanEval。基线为固定长度去噪（64-2048 Token），未使用任何加速或缓存优化。DAEDAL 在所有模型和基准上采用统一超参数，无需针对特定任务调优。

| 基准 | 指标 | 基线最佳 (Acc) | DAEDAL (Acc) | 基线最佳 (Eratio) | DAEDAL (Eratio) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| GSM8K | Acc | 83.8 | **85.8** | 27.7% | **73.5%** |
| MATH500 | Acc | 39.6 | **44.2** | 56.9% | **76.8%** |
| MBPP | Acc | 38.8 | **40.8** | 32.7% | **52.5%** |
| HumanEval | Acc | 47.6 | **48.2** | 62.6% | **64.3%** |

DAEDAL 在四个基准上均超越了基线的最佳固定长度配置，且有效 Token 比率（Eratio）显著提升，表明其以更少的总 Token 数实现了更高的性能，大幅降低了双向注意力的计算开销。

消融实验显示，初始长度调整（Stage 1）和迭代掩码插入（Stage 2）单独使用均能带来性能提升，但组合使用效果最佳。例如在 GSM8K 上，仅 Stage 1 达到 84.1%，仅 Stage 2 达到 84.7%，而完整 DAEDAL 达到 85.8%。这表明两个阶段具有协同效应：Stage 1 提供全局预算，Stage 2 进行局部精细化。此外，DAEDAL 对初始长度 $L_{init}$ 不敏感，在 32-512 范围内性能稳定，验证了其鲁棒性。

评估边界方面，论文未报告与 Fast-dLLM 等加速方法的直接对比，也未提供置信区间。代码已开源，但超参数细节仅在附录中简要提及。由于未使用缓存优化，DAEDAL 的绝对推理速度可能仍低于结合 KV 缓存的方案，但其效率优势体现在计算资源的有效利用上。

## 关联研究分析

从问题动机看，DAEDAL 与 Entropy-Guided Step Selection 均利用模型内部信号指导推理过程，但前者关注步数选择，后者关注长度调整。Entropy-Guided Step Selection 通过熵值判断何时停止去噪，而 DAEDAL 通过 EOS 置信度判断何时扩展长度。这种差异源于 DLLM 的两个独立瓶颈：时间维度（步数）和空间维度（长度）。DAEDAL 填补了空间维度优化的空白，但其信号选择（EOS 置信度）是否在所有任务类型上均有效，论文未给出全面验证。

从方法设计看，DAEDAL 与 Reversible Diffusion Decoding 均涉及去噪过程中的动态调整，但前者是前向扩展（插入 Mask），后者是后向回溯（重新掩码）。Reversible Diffusion Decoding 通过回溯纠正早期错误，而 DAEDAL 通过扩展提供额外空间。这两种策略在理论上互补：回溯解决错误累积，扩展解决空间不足。然而，DAEDAL 的动态插入是否破坏了去噪过程的马尔可夫性假设，以及这种破坏对最终分布正确性的影响，论文未提供理论分析。

## 总结

DAEDAL 解决了 DLLM 静态生成长度导致的性能与效率权衡矛盾，其核心在于利用 EOS 预测置信度作为长度充分性的内部信号。通过初始长度调整和迭代掩码插入两阶段策略，DAEDAL 在 LLaDA-8B 上实现了 GSM8K 85.8% 和 MATH500 44.2% 的准确率，超越了固定长度基线的最佳配置，同时显著提高了有效 Token 比率。然而，论文未探讨动态长度变化对训练-推理分布一致性的影响，也未提供与加速方法的直接对比。当序列长度动态变化时，模型在训练阶段从未见过这种变长分布，这种分布偏移是否会在更复杂的长文本生成任务中导致误差累积，是一个值得深入探究的问题。
