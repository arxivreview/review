# ICLR2026最新论文 ｜CONTROLLABLE FIRST-FRAME-GUIDED VIDEO EDITING VIA MASK-AWARE LORA FINE-TUNING ｜掩码感知LoRA微调的首帧引导视频编辑

研究机构：香港中文大学、商汤

作者：Chenjian Gao、Lihe Ding、Cai 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_5063471)

> 首帧引导视频编辑旨在通过修改视频首帧并传播至后续帧实现内容重构，但现有方法难以独立控制编辑区域的运动与外观，常导致背景泄漏或编辑漂移。本文指出预训练图像到视频（Image-to-Video, I2V）模型中的时空掩码机制被低估，其不仅能控制保留区域，更能作为信号引导低秩适配（Low-Rank Adaptation, LoRA）选择性学习运动或外观。通过双阶段掩码配置微调LoRA，该方法实现了编辑与背景的解耦控制。该方法在特定任务上优于基线，但缺乏大规模标准基准验证，且依赖单视频微调，泛化能力存疑。

## 研究背景

当用户编辑视频首帧中的花朵颜色时，模型需将这一变化传播至后续帧，同时保持花朵绽放的运动轨迹与背景静止。这一过程涉及两个核心概念：运动一致性要求编辑区域在时间轴上的动态连贯，结构保持则要求非编辑区域在空间与时间上严格不变。若仅依赖首帧作为条件，模型无法区分“应变化的区域”与“应静止的区域”，导致编辑效果模糊或背景污染。

视频编辑的主流路线分为端到端训练与免训练两类。端到端方法如VACE依赖大规模指令-视频配对数据，虽精度高但数据成本高昂，且对域外测试案例表现不佳；免训练方法如TokenFlow通过操纵注意力矩阵实现零样本编辑，灵活性强但精度有上限。首帧引导编辑（如I2VEdit、AnyV2V）介于两者之间，通过“首帧编辑+运动传播”范式降低数据需求，但缺乏对后续帧的细粒度控制。本文切入点在于发现预训练I2V模型内置的时空掩码机制具有未被充分利用的潜力，可通过LoRA微调将其转化为区域级控制信号，从而在轻量级训练下实现编辑与背景的解耦。

## 核心方法

### 方法参照系

本文问题属于首帧引导视频编辑，其标准流程为：使用图像编辑工具修改首帧，再通过运动条件化的I2V模型将编辑传播至全序列。与通用视频编辑的关键差异在于，本文不依赖大规模指令数据，而是针对单个源视频进行LoRA微调，利用掩码机制实现区域级控制，而非全局运动传播。

### 掩码引导的运动学习

传统LoRA微调仅学习视频整体运动模式，无法区分编辑区与背景区。本文在LoRA训练中引入时空掩码 $M_{cond}$，将未编辑区域标记为1（保留），编辑区域标记为0（生成）。损失函数定义为：

$$
\mathcal{L} = \mathbb{E}_{t, \mathbf{x}_0, \mathbf{x}_1} \left[ \| v_\theta(\mathbf{x}_t, t, \mathbf{V}_{cond}, M_{cond}) - (\mathbf{x}_0 - \mathbf{x}_1) \|^2 \right]
$$

其中 $\mathbf{x}_1 = E(\mathbf{V}_{target})$ 为目标视频潜变量，$\mathbf{V}_{cond}$ 为掩码后的条件视频。该公式的物理含义是：LoRA在掩码约束下学习速度场，使模型仅对标记为0的区域生成新内容，而保留标记为1的区域。这一设计解决了朴素LoRA微调中背景泄漏的问题，使编辑区域能独立演化而不影响背景。

### 掩码引导的外观学习

运动学习仅确保动态连贯，无法控制编辑区域在变形或旋转时的外观。本文通过重新配置掩码，将编辑区域标记为0，背景标记为1，并以用户提供的参考帧作为目标 $\mathbf{V}_{target}$。损失函数同上，但 $\mathbf{V}_{cond}$ 由源视频掩码后的背景构成。该公式的含义是：LoRA在背景约束下学习参考帧的外观特征，使编辑区域在后续帧中能合成未见过的状态（如花朵完全绽放）。这一设计解决了首帧引导中编辑漂移的问题，使模型能根据参考帧生成符合用户意图的外观，而非仅依赖首帧的模糊推断。

## 实验评估

实验基于I2VEdit测试集，对比AnyV2V、I2VEdit、Go-with-the-Flow（首帧引导类）及Kling1.6、VACE（参考引导类）。基线覆盖首帧引导与参考引导两条路线，但缺失免训练类基线（如TokenFlow）和统一框架类基线（如Omni-Video 2），限制了与领域SOTA的直接对比。

|---|---|---|---|---|---|
| AnyV2V | 0.8995 | 3.7348 | 0.7569 | - | - |
| Go-with-the-Flow | 0.9047 | 3.5622 | 0.7504 | - | - |
| I2VEdit | 0.9128 | 3.4480 | 0.7536 | - | - |
| **Ours** | **0.9172** | **3.8013** | **0.7608** | **1.620** | **1.734** |
| Kling1.6 | - | - | - | 1.869 | 1.806 |
| VACE (14B) | - | - | - | 2.511 | 2.460 |

本文在CLIP Score（0.9172）和DEQA Score（3.8013）上均优于所有首帧引导基线，且在运动一致性（1.620）和背景保持（1.734）上显著优于Kling1.6和VACE，表明掩码引导有效提升了区域级控制精度。

消融实验未提供具体数值，但论文指出掩码配置对LoRA学习的关键性：若移除掩码，模型无法区分编辑区与背景区，导致背景泄漏；若仅使用运动掩码，编辑区域外观漂移。这验证了双阶段掩码设计的必要性，但缺乏量化对比，难以评估各组件的边际贡献。

评估边界方面，实验仅基于I2VEdit测试集，未使用FiVE-Bench、MLV-EVAL等大规模标准基准，泛化能力存疑。指标完备性上，CLIP Score和DEQA Score侧重语义对齐与图像质量，但未包含时序一致性指标（如Warp-Err），可能低估运动连贯性。可复现性上，论文提供代码URL，但GPU内存需求（20 GB）和训练步骤（100步）未详细讨论，复现成本较高。

## 关联研究分析

从问题动机看，本文与I2VEdit同属首帧引导编辑，但I2VEdit依赖DDIM采样和注意力差异掩码，缺乏对背景区域的显式约束，导致编辑传播中背景泄漏。本文通过掩码引导LoRA微调，将背景保留从隐式约束转为显式信号，根源在于I2VEdit未充分利用I2V模型内置的掩码机制，而本文将其转化为训练信号。这一差异是任务特性决定，还是I2VEdit未探索的盲区，论文未给出回答。

从方法设计看，本文与TokenFlow同关注时间一致性，但TokenFlow通过运动特征注入实现免训练编辑，依赖预训练先验，精度有上限；本文通过LoRA微调学习运动与外观，数据需求低但需单视频训练，灵活性受限。TokenFlow的免训练特性适合长尾任务，而本文的轻量级训练适合特定编辑类型，两者在数据效率与精度间的取舍不同。本文未与TokenFlow对比，可能因任务设置（首帧引导 vs. 指令编辑）差异，但这也暴露了本文在通用性上的局限。

## 总结

本文要解决的核心矛盾是首帧引导编辑中运动一致性与结构保持的冲突，现有方法如I2VEdit和AnyV2V无法独立控制编辑区域与背景，导致背景泄漏或编辑漂移。本文抓住预训练I2V模型中时空掩码机制的潜力，通过双阶段掩码引导LoRA微调，实现编辑与背景的解耦控制。实验表明，该方法在I2VEdit测试集上CLIP Score达0.9172，运动一致性1.620，优于所有基线。本文的边界在于依赖单视频微调，缺乏大规模标准基准验证，且未与免训练SOTA对比。当支持集增大到多视频时，掩码引导LoRA的泛化能力是否衰减，论文未给出回答。
