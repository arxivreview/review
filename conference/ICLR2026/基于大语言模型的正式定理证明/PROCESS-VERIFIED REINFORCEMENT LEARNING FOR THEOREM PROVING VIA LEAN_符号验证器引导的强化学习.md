# ICLR2026最新论文 ｜PROCESS-VERIFIED REINFORCEMENT LEARNING FOR THEOREM PROVING VIA LEAN ｜符号验证器引导的强化学习

研究机构：韩国科学技术院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_37697082)

> 大语言模型在形式化定理证明中面临的核心矛盾是自然语言生成的模糊性与交互式定理证明器（ITP）严格逻辑验证之间的张力。现有强化学习（RL）方法多依赖二元结果奖励或外部过程奖励模型，导致信用分配稀疏且缺乏可验证性。本文切入点在于直接利用 Lean 证明助手的解析树作为符号过程预言机，将战术级反馈转化为密集训练信号。通过首错误传播与首令牌信用分配机制，该方法在 MiniF2F 和 ProofNet 上稳定优于结果级 RL 基线，但其单次生成范式在研究级基准上的表现仍受限。

## 研究背景

当 LLM 生成形式化证明时，其自回归特性与 ITP 的树状验证结构存在根本性的表示不匹配。LLM 输出的是线性令牌序列，而 Lean 等 ITP 通过抽象语法树（AST）记录每个战术（Tactic）的局部健全性与错误位置。这种结构差异导致传统的结果级奖励（仅判断最终证明是否通过）无法提供细粒度的梯度信号，使得模型难以定位具体哪一步战术导致了证明失败。为了解决这一信用分配难题，过程奖励模型（Process Reward Model, PRM）被引入，但现有 PRM 通常依赖大规模人工标注或蒙特卡洛采样，成本高且缺乏形式化保证。

形式化定理证明的自动化长期受限于搜索空间爆炸与数据分布偏差。早期工作如 GPT-f 将证明视为序列建模任务，但在长程依赖下易产生幻觉。随着 DeepSeek-Prover 等模型引入大规模 RL，问题转变为如何在巨大搜索空间中高效导航。然而，主流 RL 范式仍主要依赖二元结果反馈，这在复杂证明中信号过于稀疏，导致训练不稳定。本文的研究问题因此聚焦于：如何在不依赖自然语言思维链或外部 PRM 的情况下，将 ITP 的结构化符号反馈直接转化为有效的 RL 训练信号，以实现密集且可验证的信用分配。

## 核心方法

### 方法参照系

本文方法置于“RL 结合编译器反馈”路线下，与 DeepSeek-Prover-V1.5 等使用结果级奖励的方法形成对比。关键差异在于，本文不将 Lean 仅作为推理时的验证器或训练时的二元过滤器，而是将其解析出的战术级错误日志直接映射为过程级奖励，从而在 GRPO 框架内实现无价值模型的密集信用分配。

### 战术级 MDP 与首错误传播

在标准 GRPO 中，奖励通常均匀分配给整个响应序列，导致信用分配模糊。本文首先将证明过程建模为战术级马尔可夫决策过程（MDP），其中状态为部分证明前缀，动作为单个战术。针对 Lean 反馈的树状结构，本文引入首错误传播规则：一旦战术 $T_j$ 出现错误，所有后续战术 $T_k (k \ge j)$ 均被视为无效。这一设计解决了自回归生成中“无效前缀条件化”的问题，即后续步骤基于错误状态生成，无法构成有效推理。该规则确保了信用分配的因果一致性，避免了对错误路径中后续“看似正确”战术的错误奖励。

$$
r_{process}(T_j) = \begin{cases} 1 & \text{if } T_j \text{ is elaborated successfully and } j < j_{err} \\ d_1 & \text{if } T_j \text{ is elaborated successfully but } j \ge j_{err} \\ d_2 & \text{if } T_j \text{ has type/parser error} \end{cases}
$$

其中 $j_{err}$ 为第一个错误战术的索引，$d_1, d_2$ 为负惩罚值。该公式将 Lean 的符号反馈转化为标量奖励，区分了“局部健全但未完成”与“根本性错误”两种情况。

### 首令牌信用分配与 GRPO 集成

战术级奖励需映射到令牌级优势值以更新策略。本文采用首令牌信用分配策略，将战术 $T_j$ 的优势值仅分配给该战术的第一个令牌。这一选择基于 Lean 语义：战术关键词（如 `intro`, `apply`）决定了后续证明策略与子目标结构，是关键的决策点。通过将战术优势注入 GRPO 目标函数，本文实现了结果级与过程级优势的叠加。

$$
A_{i,t} = A_{outcome}(Y_i) + \mathbb{I}[t = \text{first}(T_{s(i,t)})] \cdot A_{process}(T_{s(i,t)})
$$

其中 $\mathbb{I}$ 为指示函数，$s(i,t)$ 为令牌 $t$ 所属战术的索引。该公式表明，只有战术首令牌接收过程级优势，其余令牌仅受结果级优势影响。这种稀疏但精准的信用分配机制，避免了将奖励分散到非决策令牌上，从而提升了模型选择正确战术的能力。

## 实验评估

| 模型 | 预算 | MiniF2F-Test (pass@64) | ProofNet-Test (pass@32) |
| :--- | :--- | :--- | :--- |
| STP-Lean + Outcome only (GRPO) | 64 | 57.9% ± 0.5 | 19% ± 0.3 |
| STP-Lean + Tactic only | 64 | 56.8% ± 0.6 | 17.9% ± 0.8 |
| **STP-Lean + Ours** | 64 | **59.2% ± 0.5** | **19% ± 0.3** |
| DeepSeek-Prover-V1.5 + Ours | 64 | 57.8% ± 0.4 | 18.5% ± 0.3 |

实验在 STP-Lean 和 DeepSeek-Prover-V1.5 两个基线上进行，对比了结果级、战术级及混合奖励策略。主结果显示，混合奖励在 MiniF2F 上较纯结果级提升 1.3 个百分点，在 ProofNet 上保持持平或微升。基线覆盖包括 SFT、结果级 RL 及树搜索方法，但缺失最新智能体框架（如 Hilbert, OProver）的直接对比，限制了在研究级基准上的横向评估。

消融实验揭示了关键设计决策的影响。移除首错误传播规则导致性能显著下降，证实了因果信用分配的必要性。将战术奖励分配给所有令牌或末令牌均不如首令牌策略稳定，表明战术关键词确实是证明结构的关键决策点。此外，混合奖励策略在训练动态中表现出更低的熵和更稳定的证明长度，说明密集过程奖励引导模型收敛至更高效的证明策略，而非通过延长输出获取奖励。

评估边界方面，本文仅在 MiniF2F 和 ProofNet 上验证，未覆盖 PutnamBench 等研究级基准。代码未公开，但提供了详细超参数附录。由于 Lean 超时设置为 15 秒，部分复杂证明可能被截断，影响结果的可复现性。此外，实验未报告计算效率指标，无法评估符号反馈解析带来的额外开销。

## 关联研究分析

从问题动机看，本文与 Process-Verified RL (ICLR 2026) 同属过程奖励方向，但根源差异在于反馈来源。Process-Verified RL 依赖学习式 PRM 或人工标注，而本文直接利用 Lean 的符号解析树，避免了 PRM 构建的数据依赖与泛化风险。这一差异源于形式化证明的确定性：Lean 的验证是类型论层面的绝对正确性，无需近似估计。然而，本文未探索如何将此方法扩展至 Coq 等其他 ITP，其符号反馈结构可能不同，导致首错误传播规则的适用性存疑。

从方法设计看，本文与 DeepSeek-Prover-V1.5 同属 RL 框架，但信用分配机制存在根本分歧。DeepSeek-Prover 采用结果级奖励，依赖大规模采样以缓解稀疏性；本文则通过战术级反馈实现密集信号，无需增加采样预算。这一设计解决了结果级 RL 在复杂证明中训练不稳定的问题，但牺牲了单次生成的灵活性。与智能体框架（如 Ax-Prover）相比，本文坚持单次生成范式，未引入多轮工具调用，因此在长程依赖任务上可能受限。这种取舍是否足以在研究级基准上弥补缺乏搜索的劣势，论文未给出明确回答。

## 总结

本文要解决的核心矛盾是 LLM 自回归生成与 ITP 树状验证之间的表示不匹配，导致传统结果级 RL 信用分配稀疏。本文抓住的切入点是 Lean 解析树提供的战术级符号反馈，将其转化为密集且可验证的训练信号。通过首错误传播与首令牌信用分配机制，该方法在 MiniF2F 上实现 59.2% 的准确率，较结果级 RL 提升 1.3 个百分点。本文的边界在于其单次生成范式，未覆盖研究级基准，且依赖 Lean 特定的符号结构。当支持集增大或证明复杂度提升时，首错误传播规则是否过度惩罚了后续可能正确的战术，论文未给出回答。
