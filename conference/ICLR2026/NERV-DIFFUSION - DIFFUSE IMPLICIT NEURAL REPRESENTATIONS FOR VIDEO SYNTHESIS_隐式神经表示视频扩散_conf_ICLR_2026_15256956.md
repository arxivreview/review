# ICLR2026最新论文 ｜NERV-DIFFUSION: DIFFUSE IMPLICIT NEURAL REPRESENTATIONS FOR VIDEO SYNTHESIS ｜隐式神经表示视频扩散

研究机构：美国马里兰大学帕克分校

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_15256956)

> 视频生成模型长期受困于帧级潜空间带来的二次方计算复杂度与内存膨胀。传统潜空间扩散模型将视频编码为逐帧特征图，迫使去噪网络引入跨帧注意力以维持时序一致性，导致模型规模与计算开销随分辨率平方增长。NeRV-Diffusion 提出将视频压缩为隐式神经表示（INR）的权重参数，并在该权重空间执行扩散去噪，从根源上消除跨帧注意力需求。该框架在 UCF-101 上以 97 的 gFVD 超越现有隐式与多数非隐式模型，但其验证局限于小规模数据集，未触及大规模文本到视频生成的质量-效率权衡。

## 研究背景

当视频扩散模型处理高分辨率长视频时，潜空间 Token 数量随分辨率平方增长，双向注意力的 $O(N^2)$ 计算复杂度成为部署瓶颈。为缓解这一问题，研究者引入跨帧注意力约束时序一致性，但这进一步膨胀了模型参数量与显存占用。隐式神经表示（INR）将数据编码为神经网络权重，通过坐标输入解码像素，其连续性与可微性支持平滑插值与紧凑存储，但传统 INR 依赖反向传播拟合单点数据，缺乏生成新样本的能力。

视频生成领域的主流路线包括步数蒸馏、高效注意力机制与潜空间优化。步数蒸馏（如 DMD）压缩去噪步数但无法解决空间 Token 冗余；线性注意力（如 SANA-Video）降低复杂度但需重构骨干网络；潜空间优化（如 SemanticGen）改进 VAE 编码但保留帧级结构。这些方法均在“帧级特征图”范式内优化，未触及表示本身的结构性冗余。NeRV-Diffusion 的切入点在于：若视频可被整体表示为一组神经权重，则去噪过程无需感知时空结构，跨帧注意力变得多余，且权重空间对分辨率呈次线性增长。

## 核心方法

### 隐式潜空间扩散范式

传统视频潜空间扩散模型（LDM）将视频编码为帧级特征图，去噪网络需处理具有时空对齐的 Token 序列。本文的关键差异在于：潜空间 Token 是无时空结构的神经权重，去噪网络无需时空注意力模块，且解码器为实例特定的 INR 而非共享卷积网络。这一范式将“生成像素”转化为“生成网络参数”，从根本上改变了计算复杂度的来源。

### 生成专用 INR 自编码器

NeRV-VAE 的编码器基于 FastNeRV，但引入 KL 瓶颈与多头仿射映射以适配扩散生成。设计动机在于：原始 FastNeRV 的权重仅优化重建性能，分布不规则且表达能力受限，无法直接作为扩散目标。本文通过多头仿射映射复用同一组权重 Token 调制所有 INR 层，扩大潜空间表达力；同时采用通道级参数化，将权重 Token 直接设为卷积核而非调制共享基权重，最大化解码自由度。

$$
L_{VAE}(E, \theta_s) = \|x - \tilde{x}\|_2^2 + L_{LPIPS}(x, \tilde{x}) + L_{GAN}(x, \tilde{x}) + D_{KL}(N(0,1), \theta_{\tilde{}})
$$

该损失函数联合优化重建保真度、感知质量、对抗真实性与高斯分布约束，确保权重 Token 既支持高保真重建又具备平滑扩散所需的分布特性。

### 隐式扩散去噪

去噪骨干采用标准 DiT，但去除时空注意力模块，因为权重 Token 无时空结构。设计动机在于：传统视频扩散模型中的时序注意力在隐式权重空间中无意义，反而增加计算开销。为弥合训练-推理差距，引入 Min-SNR-$\gamma$ 损失加权与调度采样。

$$
w_t = \min\{\text{SNR}(t), \gamma\}, \quad \text{SNR}(t) = \frac{\alpha_t^2}{\sigma_t^2}
$$

该加权策略防止训练过度关注低噪声阶段，使模型在所有时间步均匀收敛。调度采样在训练时随机使用模型预测作为下一步输入，模拟推理时的误差累积，对齐训练与推理分布。

## 实验评估

实验在 UCF-101 与 Kinetics-600 上进行，基线覆盖非隐式模型（Latte, OmniTokenizer, LARP-L）与隐式模型（DIGAN）。缺失 SANA-Video、DMD 等高效扩散基线，因数据集与指标（gFVD vs. VBench）不同，无法直接比较。

| 方法 | UCF 128² 16帧 gFVD | UCF 256² 16帧 gFVD | UCF 128² 128帧 gFVD |
| --- | --- | --- | --- |
| LARP-L | 102 | — | — |
| OmniTokenizer | — | 191 | — |
| NeRV-Diffusion-L | 97 | 140 | 366 |

NeRV-Diffusion-L 在 UCF 128² 16帧上以 97 的 gFVD 优于 LARP-L (102) 与 MAGVITv2-AR (109)，在 256² 分辨率上以 140 优于 OmniTokenizer (191)。

| 设计决策 | gFVD | 变化幅度 |
| --- | --- | --- |
| 无复用 | 570 | 基准 |
| 多头仿射 | 283 | -50.3% |
| Min-SNR-$\gamma$ + 调度采样 | 184 | -35.0% (vs. Vanilla DiT 295) |

多头仿射映射将 gFVD 从 570 降至 283，降幅最大，验证了权重复用对表达力的关键作用。Min-SNR-$\gamma$ 与调度采样联合使用将 gFVD 从 295 降至 184，表明训练策略对隐式扩散收敛至关重要。

评估边界：仅使用 UCF-101 与 K600 小规模数据集，未验证大规模文本到视频生成；指标为 gFVD，未报告 FPS/Latency 等效率指标；代码未明确开源，可复现性受限。

## 关联研究分析

从问题动机看，NeRV-Diffusion 与 SemanticGen 均关注潜空间优化，但 SemanticGen 在帧级特征图范式内改进 VAE 编码，保留时空结构；本文则彻底重构潜空间为无结构权重，消除跨帧注意力。这一差异源于任务特性：SemanticGen 面向收敛速度优化，需保留时空信息以指导去噪；本文面向计算复杂度与内存效率，牺牲时空结构以换取次线性扩展。

从方法设计看，NeRV-Diffusion 与 SANA-Video 均追求线性复杂度，但 SANA-Video 通过块线性注意力修改 DiT 骨干，保留帧级 Token 结构；本文通过 INR 权重生成消除 Token 时空对齐需求，复杂度降低源于表示重构而非注意力机制优化。SANA-Video 在 VBench T2V 上验证了大规模生成质量，本文仅在 UCF 上验证小规模生成，两者在评估协议上存在根本差异。

## 总结

NeRV-Diffusion 解决的核心矛盾是帧级潜空间导致的二次方计算复杂度与内存膨胀。其切入点在于：将视频表示为 INR 权重，使去噪过程无需时空注意力，且权重空间对分辨率呈次线性增长。方法上，通过多头仿射映射与通道级参数化构建生成专用 INR 自编码器，并在权重空间执行 DiT 去噪，辅以 Min-SNR-$\gamma$ 与调度采样。实验证明，在 UCF-101 128² 16帧上，NeRV-Diffusion-L 以 97 的 gFVD 超越 LARP-L (102) 与 MAGVITv2-AR (109)。其边界在于：验证局限于小规模数据集，未触及大规模文本到视频生成的质量-效率权衡；权重空间无时空结构，长视频时序一致性依赖 INR 插值能力，未进行分钟级视频盲测。当视频时长从 16 帧扩展至 128 帧时，gFVD 从 97 升至 366，这一增幅是否源于 INR 权重空间的表达力瓶颈，还是去噪模型对长序列误差累积的敏感性，论文未给出回答。
