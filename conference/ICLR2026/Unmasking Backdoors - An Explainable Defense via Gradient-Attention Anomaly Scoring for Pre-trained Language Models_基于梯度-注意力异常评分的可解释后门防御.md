# ICLR2026最新论文 ｜Unmasking Backdoors: An Explainable Defense via Gradient-Attention Anomaly Scoring for Pre-trained Language Models ｜基于梯度-注意力异常评分的可解释后门防御

研究机构：新加坡南洋理工大学

作者：Anindya Sundar Das、Kangjie Chen、Monowar Bhuyan

论文原文见 [arXiv](https://arxiv.org/abs/2510.04347)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.04347)

> 预训练语言模型在供应链分发中面临后门植入风险，传统防御依赖训练时数据清洗或模型重训练，计算成本高且缺乏可解释性。X-GRAAD 利用触发器在注意力与梯度信号中的主导性异常，在推理时定位并扰动可疑 Token，无需重训练即可消除后门。该方法在 BERT 等编码器上实现了低攻击成功率与高干净准确率的平衡，但其对语义级触发器及生成式模型的适用性存疑。

## 研究背景

后门攻击的本质是在模型训练阶段植入隐蔽的恶意行为，使得模型在特定触发器出现时激活异常输出，而在常规评估中保持正常性能。这一问题的起源可追溯至传统自然语言处理分类任务，早期研究假设触发器是静态的词法模式，且攻击者拥有白盒访问权限。随着大语言模型在推理、对话及多模态任务中的广泛应用，其训练数据依赖性和模型分发机制带来的供应链安全风险日益凸显，问题定义随之发生第一次变形：从“可见触发器植入”转向“隐蔽触发器构造”，关注点从攻击的可行性扩展至攻击在自然语言语境中的不可察觉性。

现有防御策略主要分为训练时清洗、模型净化与推理时过滤三类。训练时防御如数据分区训练需监控整个数据集，计算开销巨大；模型净化如 MEFT 或 PURE 依赖重训练或注意力头剪枝，破坏了模型原始结构且缺乏对触发器位置的直观解释；推理时防御如 ONION 基于困惑度过滤，但难以应对未知触发器。Lyu et al. (2022) 发现被植入后门的 BERT 模型存在“注意力漂移”现象，即触发器 Token 在多个注意力头中占据主导地位，但未提出具体防御方案。X-GRAAD 的切入点在于将这种注意力异常与梯度信号结合，构建一种无需修改模型权重、仅通过推理时输入扰动即可消除后门的可解释防御机制。

## 核心方法

### 方法参照系

本文问题属于推理时后门防御，与训练时数据清洗或模型权重剪枝路线不同。其核心差异在于不依赖对训练数据的访问或模型参数的修改，而是利用模型内部状态（注意力与梯度）在推理阶段的异常表现来识别并中和触发器，从而在保持模型效用不变的前提下实现防御。

### 联合注意力-梯度异常评分

传统方法仅依赖单一信号（如注意力或梯度）进行异常检测，易受噪声干扰或遗漏隐蔽触发器。X-GRAAD 提出联合评分机制，首先计算每个 Token 的注意力重要性 $AttnScore_x(t_k)$ 与梯度重要性 $GradScore_x(t_k)$，二者分别反映 Token 在注意力分配中的占比及其对输出 Logit 的敏感度。随后，通过归一化处理消除量纲差异，定义组合 Token 属性分数为：

$$ Score_x(t_k) = AttnScore_x(t_k) \cdot GradScore_x(t_k) $$

该公式的物理含义是：只有当某个 Token 同时吸引大量注意力并显著影响输出梯度时，才被判定为高嫌疑触发器。这种乘积关系确保了单一信号的异常（如高注意力但低梯度）不会被误判为后门，从而提高了检测的鲁棒性。

### 基于噪声注入的触发器中和

识别出高嫌疑 Token 后，传统方法通常直接删除或替换，这可能破坏句子语义连贯性。X-GRAAD 采用字符级噪声注入策略，对嫌疑 Token 进行随机字符插入或替换，而非完全移除。具体而言，对于异常分数 $\psi(x)$ 超过阈值 $\tau$ 的句子，定位 $Score_x(t_k)$ 最高的 Token，并对其进行轻微扰动以生成新输入 $\tilde{x}$。这一设计的动机在于：触发器通常是短小的罕见词，轻微扰动足以破坏其与模型内部后门逻辑的匹配，同时保留句子的整体语义结构，从而在消除后门激活的同时最小化对干净预测的干扰。

## 实验评估

实验在 SST-2、IMDb 和 AG's News 数据集上，针对 BERT、DISTILBERT 和 ALBERT 三种编码器，测试 BadNets、RIPPLES 和 LWS 三种攻击。基线覆盖 ONION、RAP、FT、MEFT 和 PURE，但缺失 2025-2026 年提出的 P2P、Critical Neuron Pruning 等最新防御方法，导致对比范围局限于经典编码器防御。

| 模型 | 数据集 | 攻击 | 方法 | CACC | ASR |
| :--- | :--- | :--- | :--- | :--- | :--- |
| BERT | SST-2 | BadNets | X-GRAAD | 0.931 | 0.002 |
| BERT | SST-2 | RIPPLES | X-GRAAD | 0.923 | 0.000 |
| BERT | SST-2 | LWS | X-GRAAD | 0.930 | 0.000 |
| DISTILBERT | IMDb | LWS | X-GRAAD | 0.907 | 0.003 |
| ALBERT | SST-2 | LWS | X-GRAAD | 0.815 | 0.201 |

在 BERT 和 DISTILBERT 上，X-GRAAD 在多数攻击下将 ASR 降至 0.000-0.003，且 CACC 保持在 0.90 以上，显著优于 PURE 和 MEFT。然而，在 ALBERT-LWS/SST-2 设置下，ASR 高达 0.201，CACC 降至 0.815，表明该方法在小模型与自适应触发器（LWS）组合下鲁棒性不足。消融实验显示，联合注意力与梯度信号（X-GRAAD）的 ASR 始终低于单一信号变体，验证了双信号融合的必要性，但论文未提供具体的消融数值表格，仅定性描述了“协同效应”。

评估边界方面，论文未报告置信区间，数值比较需谨慎；未提供代码开源链接，可复现性依赖 OpenBackdoor 工具包；超参数如阈值 $\tau$ 的选取（95% 或 65% 分位数）缺乏理论依据，可能影响不同数据集上的泛化性能。

## 关联研究分析

从问题动机看，X-GRAAD 与 PURE (Zhao et al., 2024) 均基于注意力机制，但 PURE 采用模型剪枝，X-GRAAD 采用输入扰动。这一差异源于对“防御代价”的不同权衡：PURE 追求彻底消除后门但牺牲模型结构，X-GRAAD 追求零重训练成本但依赖推理时计算。根源在于任务特性：编码器分类任务中，触发器对输出的影响可通过梯度直接量化，而生成式 LLM 的推理链中，触发器影响分散于多个中间步骤，单一 Token 的梯度主导性可能失效。

从方法设计看，X-GRAAD 与 Semantic Drift Analysis (P5) 形成白盒与黑盒的对比。X-GRAAD 依赖梯度与注意力访问，精度更高（ASR 0.000 vs P5 的 92.5% 检测率），但无法部署于 API 服务；P5 仅依赖输入输出，部署可行但精度受限。这一冲突暗示了当前防御体系在“精度”与“部署可行性”之间的根本性取舍，X-GRAAD 选择了前者，而忽略了后者在实际供应链场景中的关键性。

## 总结

X-GRAAD 旨在解决预训练语言模型后门防御中“高计算成本”与“缺乏可解释性”的矛盾，通过联合注意力与梯度异常评分，在推理时定位并扰动触发器，实现了无需重训练的防御。实验证明其在 BERT 等主流编码器上能将 ASR 降至 0.000-0.003，同时保持 CACC 在 0.90 以上。然而，其在 ALBERT-LWS 设置下 ASR 高达 0.201，暴露了方法对小模型与自适应触发器的脆弱性。当触发器从静态罕见词演变为语义级或推理链内嵌模式时，基于单一 Token 梯度主导性的异常检测是否仍能有效定位后门，论文未给出回答。
