# ICLR2026最新论文 ｜ROBUST TEST TIME VIDEO-TEXT RETRIEVAL: BENCHMARKING AND ADAPTING FOR QUERY SHIFTS ｜视频-文本检索的测试时鲁棒性：基准构建与Hubness抑制

研究机构：澳大利亚昆士兰大学

作者：Bingqing Zhang、Zhuo Cao、Heming Du 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_27007519)

> 视频-文本检索（VTR）模型在分布偏移下性能急剧下降，现有图像域测试时适应（TTA）方法无法处理视频特有的时空扰动。本文指出该失效源于Hubness现象的放大，并构建了首个多层级视频扰动基准MLVP。通过引入Hubness抑制记忆（HSM）与多粒度损失，HAT-VTR在多种扰动场景下显著优于现有TTA基线。该方法确立了视频TTA的鲁棒性基线，但其在极端语义扰动下的恢复能力仍受限于双编码器架构的固有缺陷。

## 研究背景

VTR模型依赖双编码器架构将视频与文本映射至共享嵌入空间，其性能高度依赖训练与测试数据同分布的假设。当测试数据分布偏离训练域时，即发生查询偏移（Query Shift, QS），导致检索精度骤降。视频数据特有的时空动态性使得这种偏移比静态图像更复杂，例如雾天或遮挡不仅改变像素值，还破坏帧间时序一致性。

主流VTR研究聚焦于干净数据下的检索精度提升，如CLIP4Clip通过时间Transformer聚合图像特征，X-Pool引入跨模态注意力实现细粒度对齐。然而，这些方法均假设测试数据无噪声，未考虑真实场景中的分布偏移。图像域TTA方法如TENT通过熵最小化适应新分布，TCR通过表示均匀性处理查询偏移，但它们仅针对静态帧级扰动，缺乏对视频时序动态的建模能力。

本文切入点在于揭示视频扰动下Hubness现象的放大机制。Hubness指少数库项目（Gallery items）在最近邻检索中不成比例地占据主导地位。在干净数据下，Hubness程度较轻；但在视频扰动下，查询嵌入空间发生坍缩，导致Hubness急剧恶化，成为性能崩溃的根本原因。现有TTA方法未能直接针对这一机制进行干预，导致其在视频场景下效果有限。

## 核心方法

### 方法参照系

在线TTA的标准流程是：接收无标签测试批次，通过自监督信号（如熵最小化或均匀性损失）更新模型参数，以最大化预测置信度。本文问题与该通用流程的关键差异在于：视频扰动导致的Hubness放大无法仅通过优化嵌入均匀性解决，需在相似度分数层面进行显式抑制，同时利用视频时序结构增强适应信号。

### Hubness抑制记忆（HSM）

HSM模块在相似度计算后、检索排序前介入，通过动态记忆库跟踪近期查询-库交互模式，对过度流行的库项目进行分数降权。其核心机制是双边归一化：基于最近$K$个批次的聚合相似度矩阵$\bar{S}$，计算库中心权重$W_{gallery} = \text{softmax}_{col}(\alpha \bar{S})$和查询中心权重$W_{query} = \text{softmax}_{row}(\beta \bar{S})$，最终抑制分数为：

$$\hat{S} = m (\bar{S} \odot W_{gallery}) + (1-m) (\bar{S} \odot W_{query})$$

其中$m \in [0,1]$为平衡参数。该设计直接针对Hubness的“伪负样本主导”问题，通过实时降权高频出现的库项目，恢复邻域分布的平衡性，弥补了TCR仅优化嵌入均匀性而无法处理分数层面偏置的缺陷。

### 多粒度时序适应损失

HAT-VTR将TCR的均匀性损失扩展至视频时序维度，引入多粒度交叉模态损失$\mathcal{L}_{MGCM}$，包含全局对齐损失$\mathcal{L}_{global}$、帧级对齐损失$\mathcal{L}_{frame}$、多粒度均匀性损失$\mathcal{L}_{inter}$与$\mathcal{L}_{intra}$，以及噪声鲁棒熵项$\mathcal{L}_{NA}$。帧级损失强制相邻帧嵌入在扰动下保持局部一致性，全局损失确保视频整体语义不变。该设计解决了标准TTA在视频时序扰动下特征坍缩的问题，通过时序约束增强模型对动态扰动的适应能力，使查询嵌入中心向库中心偏移，提升检索对齐精度。

## 实验评估

实验在MSRVTT-1kA和ActivityNet数据集上进行，覆盖12种视频扰动类型（低层像素、中层对象运动、高层语义时序）及5个严重度等级，共60个测试场景。基线包括TENT、READ、SAR、EATA和TCR，均为图像域TTA方法，未包含视频专用鲁棒性方法。

| 方法 | MSRVTT-1kA v2t Avg R@1 (%) | ActivityNet v2t Avg R@1 (%) |
| :--- | :--- | :--- |
| CLIP4Clip (Baseline) | 17.0 | 12.41 |
| TCR | 21.4 | 12.86 |
| HAT-VTR | 26.2 | 22.28 |

HAT-VTR在MSRVTT-1kA上较TCR提升4.8个百分点，在ActivityNet上提升9.42个百分点，验证了HSM与多粒度损失的有效性。消融实验显示，HSM在目标选择和后验重排序两个阶段均贡献正向收益，其中后验重排序增益更大；多粒度损失中，帧级对齐损失$\mathcal{L}_{frame}$对v2t任务贡献最显著，表明时序一致性是视频TTA的关键。

评估边界方面，实验仅报告R@1和R@5，未提供置信区间或计算效率的详细对比（除运行时分析外）。代码已开源，超参数（$\alpha=100, \beta=10, m=0.5$）在两个数据集上保持一致，表明方法稳定性。然而，实验未覆盖联合编码器架构（如HCMI），仅基于双编码器骨干，限制了结论的普适性。

## 关联研究分析

从问题动机看，本文与TCR（Li et al., 2025b）同属查询偏移适应框架，但TCR聚焦图像域表示均匀性，本文针对视频Hubness放大机制。差异根源在于视频扰动的时空动态性：图像扰动仅影响单帧像素，而视频扰动破坏帧间时序一致性，导致嵌入空间坍缩程度更严重，Hubness效应被放大。TCR的均匀性损失无法区分“正常多样性”与“Hubness偏置”，而HSM通过分数层面降权直接干预这一机制。

从方法设计看，本文与DSL（Cheng et al., 2021）共享后验分数归一化思想，但DSL为离线后处理，HAT-VTR为在线流式适应。差异在于HSM引入FIFO记忆队列，使Hubness统计基于最近$K$个批次，实现快速适应。这一设计解决了DSL在动态数据流中统计滞后的问题，但引入了记忆管理开销。论文未探索HSM在非CLIP骨干（如联合编码器）上的泛化能力，其效果是否依赖于双编码器的独立嵌入特性，尚不明确。

## 总结

本文核心矛盾在于视频VTR模型在时空扰动下的性能崩溃与现有TTA方法的失效。切入点在于揭示Hubness放大机制，并通过HSM与多粒度损失直接干预该机制。HAT-VTR在MSRVTT-1kA上实现26.2%的v2t R@1，较TCR提升4.8个百分点，证明了方法有效性。其边界在于仅验证双编码器骨干，且在高严重度语义扰动（如时间打乱）下优势减弱，表明Hubness并非唯一失效模式。当扰动破坏视频叙事因果结构时，HSM的分数降权是否仍能恢复检索精度，论文未给出回答。
