# ICLR2026最新论文 ｜CONSISTENCY-DRIVEN CALIBRATION AND MATCH ING FOR FEW-SHOT CLASS INCREMENTAL LEARNING ｜一致性驱动校准与匹配

研究机构：中南大学、澳大利亚悉尼大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_73132094)

> 少样本类增量学习（Few-Shot Class Incremental Learning, FSCIL）旨在解决新类别样本稀缺导致的原型偏差与固定嵌入结构引发的知识冲突。现有前瞻学习方法通过预分配空间缓解遗忘，但刚性结构约束限制了新类特征的适应性，导致跨会话性能衰减。ConCM 提出特征-结构双重一致性视角，利用语义属性校准原型并动态优化几何结构，在 mini-ImageNet 等基准上取得 SOTA 性能。该方法在少样本约束下有效平衡了稳定性与可塑性，但其对 WordNet 语义依赖及 5-shot 重放设置的适用性边界尚需进一步验证。

## 研究背景

FSCIL 任务将训练过程划分为数据充足的基座会话与仅含少量新类样本的增量会话。由于新类样本极少，直接微调骨干网络极易引发过拟合，因此主流范式采用冻结骨干网络并训练轻量投影器的策略。然而，冻结骨干导致新类特征难以适应基座会话建立的嵌入几何结构，新类原型往往偏离真实类中心，形成特征不一致。这种偏差不仅降低新类识别率，还因嵌入空间混淆导致旧类误分类，即结构不一致。

现有特征空间优化方法试图通过预分配嵌入空间解决上述问题。NC-FSCIL 将分类器原型预设为等角紧框架（Equiangular Tight Frame, ETF），OrCo 构建正交伪目标以最大化类间距离。这些方法虽增强了结构适应性，但固定结构对新类施加了刚性先验，限制了特征匹配灵活性。ConCM 从一致性驱动视角切入，指出知识冲突源于特征与结构的双重不一致，需通过语义校准消除原型偏差，并通过动态结构匹配实现跨会话几何一致性。

## 核心方法

### 方法参照系

FSCIL 标准流程包含基座会话训练冻结骨干、增量会话微调投影器及 NCM 分类。本文关键差异在于引入原型校准网络 $h(\cdot)$ 与动态结构矩阵 $\Delta_t$，替代固定结构约束，实现特征与结构的联合优化。

### 记忆感知原型校准

针对少样本原型偏离真实类中心的问题，MPC 模块借鉴海马体联想记忆机制，通过属性分离与补全实现校准。属性分离阶段利用 WordNet 解析基座类标签，提取同义词与上位词构建语义属性池 $A$，并计算每个属性的视觉原型 $F_a$。属性补全阶段采用编码-聚合-解码架构，通过交叉注意力计算属性与当前类的关联权重 $w_{a_i^k}$，聚合输出校准原型 $\hat{p}_k$。

$$
\hat{p}_k = h(p_k, \Pi_t; \theta_h) = \alpha \cdot p_k + (1-\alpha) \cdot \sum_{i} w_{a_i^k} f_{a_i}
$$

该公式表明校准原型是原始原型与语义属性视觉原型的加权组合，$\alpha$ 控制校准强度。MPC 通过元学习在基座会话训练，以有偏原型为输入、真实基座原型为监督，学习属性补全映射，从而消除新类原型的特征偏差。

### 动态结构匹配

针对固定结构限制新类匹配灵活性的问题，DSM 模块构建动态几何结构 $\Delta_t$，满足几何最优性与最大匹配性。几何最优性要求原型等距分离，最大匹配性要求新类嵌入时结构变化最小。DSM 通过 SVD 分解历史结构 $\Delta'_t$，更新当前结构 $\Delta_t$ 以最小化全局结构变化。

$$
\Delta_t = \arg\min_{\Delta} \|\Delta - \Delta'_t\|_F^2 \quad \text{s.t.} \quad \Delta^\top \Delta = I_{N_t}
$$

该公式表明动态结构在保持正交性的同时，最大化与历史结构的相似度，实现结构知识的蒸馏。投影器 $g(\cdot)$ 通过匹配损失与对比损失优化，将特征对齐至动态结构向量，确保跨会话结构一致性。

## 实验评估

实验在 mini-ImageNet、CIFAR100 和 CUB200 上进行，采用 5-shot 重放协议，对比 FACT、NC-FSCIL、OrCo 等 SOTA 方法。ConCM 在 mini-ImageNet 上取得 59.78% 的 AHM，比 OrCo 高 2.48 个百分点；在 CIFAR100 上取得 59.05% 的 AHM，比 NC-FSCIL 高 6.27 个百分点；在 CUB200 上取得 62.20% 的 AHM，比 NC-FSCIL 高 5.06 个百分点。

| 数据集 | 方法 | AHM (%) | FA (%) |
| :--- | :--- | :--- | :--- |
| mini-ImageNet | OrCo | 57.30 | 55.34 |
| mini-ImageNet | ConCM | 59.78 | 59.92 |
| CIFAR100 | NC-FSCIL | 52.78 | 51.52 |
| CIFAR100 | ConCM | 59.05 | 58.33 |
| CUB200 | NC-FSCIL | 57.14 | 55.34 |
| CUB200 | ConCM | 62.20 | 62.66 |

消融实验显示，MPC 模块使 mini-ImageNet AHM 提升 4.52%，DSM 模块提升 8.96%，两者结合提升 11.95%。移除 MPC 后，结构匹配性能显著下降，表明特征一致性是结构优化的前提。计算效率方面，ConCM 参数量 13.22M，FLOPS 4.77G，训练时间 16.37 分钟，内存占用 9.57M，低于 NC-FSCIL 的 24.78M 内存占用。

评估协议采用 5-shot 重放，与 OrCo、NC-FSCIL 保持一致，但高于 Exemplar-free 设置的严格性。代码已开源，实验在 RTX 4090 GPU 上完成，超参数详见附录。指标包含 AHM、FA、NAcc 和 BER，但未报告置信区间，跨数据集比较需谨慎。

## 关联研究分析

从方法设计看，ConCM 与 NC-FSCIL 的核心差异在于结构动态性。NC-FSCIL 使用固定 ETF 结构，假设所有类别共享相同几何配置，而 ConCM 通过 SVD 动态更新结构，适应不同会话的类别分布变化。这一差异源于任务特性：FSCIL 中类别顺序随机，固定结构难以适应任意类别组合，动态结构通过最小化结构变化实现跨会话一致性。

从问题动机看，ConCM 与 OrCo 均关注类间干扰，但解决路径不同。OrCo 通过正交伪目标最大化类间距离，属于静态结构优化；ConCM 通过语义校准消除原型偏差，属于特征级优化。OrCo 未考虑原型偏差问题，导致新类特征与真实中心不一致，而 ConCM 通过 WordNet 语义属性提供先验知识，弥补了少样本下特征表示的不足。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

ConCM 解决的核心矛盾是少样本 FSCIL 中特征偏差与结构刚性导致的知识冲突。现有方法如 NC-FSCIL 和 OrCo 通过固定结构优化缓解遗忘，但无法适应新类特征的动态变化。ConCM 通过语义属性校准原型消除特征偏差，通过 SVD 动态更新结构实现几何一致性，在 mini-ImageNet 上取得 59.78% AHM，比 SOTA 高 2.48 个百分点。其边界在于依赖 WordNet 语义属性，对无文本标签场景适用性有限；5-shot 重放设置弱化了少样本挑战的严格性。当支持集增大到 10-shot 时，语义校准的边际收益是否递减，论文未给出回答。
