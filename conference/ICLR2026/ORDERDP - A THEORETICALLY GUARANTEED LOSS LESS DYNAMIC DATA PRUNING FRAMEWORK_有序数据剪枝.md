# ICLR2026最新论文 ｜ORDERDP: A THEORETICALLY GUARANTEED LOSS LESS DYNAMIC DATA PRUNING FRAMEWORK ｜有序数据剪枝

研究机构：香港中文大学、香港浸会大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_5041517)

> 动态数据剪枝旨在训练过程中剔除冗余样本以降低算力成本，但现有方法常因梯度估计偏差导致训练不稳定。OrderDP 指出，传统动态剪枝的“近无损”性能缺乏理论支撑，其核心切入点是将剪枝过程形式化为对代理损失的无偏优化。该方法通过排序统计量机制，在保持无偏梯度估计的同时实现精确的剪枝比率控制。这一设计在理论上保证了收敛性，但在非凸深度网络中，无偏性是否总能转化为泛化性能提升，仍存疑。

## 研究背景

动态数据剪枝（Dynamic Data Pruning, DP）的核心困境在于样本选择与梯度估计的耦合。当模型在训练初期对某些样本产生高损失时，这些样本被视为“高信息量”而被保留。然而，若选择机制仅基于瞬时损失，会导致后续迭代中梯度分布发生系统性偏移。这种偏移不仅改变了梯度的尺度，还扭曲了其方向，使得优化路径偏离全量数据训练的轨迹。为量化这一偏差，需引入代理损失（Surrogate Loss）概念，它将非均匀采样权重显式建模，从而区分“优化误差”与“剪枝偏差”。

现有动态剪枝方法如InfoBatch（Qin et al., 2024）和UCB（Raju et al., 2021）试图通过在线反馈机制缓解静态方法的时效性问题，但二者均存在显著瓶颈。InfoBatch依赖全量数据重计算或复杂缩放因子来校正偏差，在高剪枝率下需引入退火等技术以稳定训练，计算开销大且理论保证缺失。UCB将选择建模为多臂老虎机问题，虽具备在线决策能力，但其黑盒特性导致无法提供收敛性证明，且存储复杂度为 $O(n)$。OrderDP的切入点在于：不追求对全量损失梯度的直接无偏估计，而是构造一个与剪枝机制内生的代理损失，使得在该代理目标下的梯度估计天然无偏，从而在理论上消除偏差来源，同时通过解耦探索与利用参数实现精确的剪枝比率控制。

## 核心方法

### 方法参照系

动态数据剪枝的标准流程是在每个迭代步中，基于当前模型状态评估样本重要性，并选择子集进行参数更新。OrderDP与InfoBatch等主流方法的关键差异在于：后者试图通过缩放因子校正已选子集的梯度偏差，而OrderDP将选择机制本身视为优化算法的一部分，直接定义了一个与选择过程一致的代理目标函数。

### 基于排序统计量的代理损失

OrderDP的核心创新在于将动态选择过程形式化为对代理损失 $\mathcal{L}_q$ 的无偏优化。在标准SGD中，梯度估计基于均匀采样，而OrderDP通过从候选批次 $S_t$ 中选取损失值最高的 $q$ 个样本 $Q_t$，引入了非均匀采样。为消除由此产生的偏差，OrderDP定义了代理损失：

$$
\mathcal{L}_q(\theta) = \sum_{j=1}^{n} \gamma_j L_{(j)}(\theta)
$$

其中 $L_{(j)}(\theta)$ 是第 $j$ 个排序后的样本损失，权重 $\gamma_j$ 仅依赖于数据集大小 $n$、探索大小 $s$ 和利用大小 $q$。这一设计的动机在于：传统方法（如InfoBatch）的偏差源于采样分布与目标分布的不匹配，而OrderDP通过构造 $\mathcal{L}_q$，使得基于 $Q_t$ 计算的子梯度 $\tilde{g}_t$ 成为 $\mathcal{L}_q$ 的无偏估计。这意味着，尽管 $\tilde{g}_t$ 相对于全量损失 $\mathcal{L}$ 是有偏的，但它在代理目标 $\mathcal{L}_q$ 下是无偏的，从而保证了优化过程的稳定性。

### 收敛性与泛化界

在建立无偏梯度估计的基础上，OrderDP进一步推导了收敛性与泛化界。对于收敛性，OrderDP证明了在凸性和Lipschitz假设下，其收敛速率与标准mini-batch SGD相同，为 $O(1/\sqrt{T})$。对于泛化性，OrderDP通过谱风险分析，将泛化误差分解为优化误差和剪枝偏差两项：

$$
\mathbb{E}[\mathcal{L}_q(\theta_t, D)] - \mathcal{L}(\theta^*) \leq \underbrace{\mathbb{E}[\mathcal{L}_q(\theta_t, D)] - \mathbb{E}[\mathcal{L}(\theta_t, D)]}_{\text{剪枝偏差}} + \underbrace{\mathbb{E}[\mathcal{L}(\theta_t, D)] - \mathcal{L}(\theta^*)}_{\text{优化误差}}
$$

剪枝偏差由权重序列 $\{\gamma_j\}$ 与均匀分布的偏差决定，具体量化为 $C_s$ 和 $Q_n(\theta; s, q)$。当 $q \to s$ 时，$\gamma_j$ 趋近均匀分布，偏差项消失，OrderDP退化为标准SGD。这一理论框架解释了为何OrderDP在高剪枝率下仍能保持性能稳定：它并非消除偏差，而是将偏差显式建模并控制在有限范围内，避免了InfoBatch中因大缩放因子导致的梯度爆炸或训练震荡。

## 实验评估

OrderDP在CIFAR-10、CIFAR-100和ImageNet-1K上进行了全面评估，基线覆盖静态方法（K-Center, EL2N）和动态方法（UCB, InfoBatch）。在CIFAR-10（30%保留率，ResNet-18）上，OrderDP达到95.6%的准确率，与全量数据训练的95.6%持平，优于InfoBatch的95.2%。在ImageNet-1K（40%剪枝率，ResNet-50）上，OrderDP保持76.4%的准确率，与全量数据一致，且总计算成本（43.0 node-hours）低于InfoBatch（43.2 node-hours）。

| 数据集 | 剪枝率 | 方法 | 准确率 (%) | 时间 (h) |
| :--- | :--- | :--- | :--- | :--- |
| CIFAR-10 | 30% | InfoBatch | 95.2 | - |
| CIFAR-10 | 30% | OrderDP | 95.6 | - |
| CIFAR-100 | 30% | InfoBatch | 77.3 | - |
| CIFAR-100 | 30% | OrderDP | 78.2 | - |
| ImageNet-1K | 40% | InfoBatch | 75.6 | 21.6 |
| ImageNet-1K | 40% | OrderDP | 76.4 | 21.5 |

消融实验显示，解耦探索大小 $s$ 和利用大小 $q$ 对性能影响显著。在固定剪枝率下，不同 $(s, q)$ 组合的准确率几乎相同，但训练时间保持稳定，表明OrderDP能精确控制剪枝比率而不损失效率。当剪枝率从30%增加到70%时，CIFAR-10准确率从95.6%降至95.0%，而训练时间减半，展示了平滑的效率-性能前沿。

评估边界方面，OrderDP仅在图像分类任务上验证，未涉及多模态或LLM推理任务。实验使用ResNet-18/50和ViT-Base，但未报告跨架构迁移的鲁棒性细节。代码已公开，超参数（如 $s/|D|=0.5, q/s=0.6$）固定，未探索自适应调整策略。

## 关联研究分析

从问题动机看，OrderDP与InfoBatch的核心差异在于对“无偏性”的定义。InfoBatch试图通过缩放因子使选样子集的梯度期望等于全量梯度期望，但这在高剪枝率下需大缩放因子，导致梯度方差增大和训练不稳定。OrderDP则承认选样子集与全量分布的差异，转而定义一个与选择机制一致的代理损失 $\mathcal{L}_q$，使得在该目标下的梯度估计无偏。这一转变源于对“近无损”性能的理论反思：OrderDP认为，无偏性应相对于实际优化的目标（即代理损失）而非全量损失来定义，从而避免了InfoBatch中因强行校正偏差而引入的不稳定性。

从方法设计看，OrderDP与SAGE（Jha and Ahmadi-Asl, 2025）形成互补。SAGE通过流式频率方向草图解决大规模数据上的计算瓶颈，侧重效率，但牺牲了梯度幅值的精确性。OrderDP则侧重理论保证，通过排序统计量实现无偏估计，但计算复杂度为 $O(\log q)$，在极大规模数据上可能不如SAGE高效。OrderDP未探索草图近似，其理论保证依赖于精确的排序统计量，这在数据量极大时可能成为瓶颈。此外，OrderDP的代理损失理论是否适用于非凸深度网络中的泛化性能提升，论文未给出明确回答，仅提供了凸性假设下的理论保证。

## 总结

OrderDP要解决的核心矛盾是动态数据剪枝中梯度估计偏差与训练稳定性的冲突。现有方法如InfoBatch通过缩放因子校正偏差，但导致训练不稳定；OrderDP的切入点是将剪枝机制形式化为对代理损失的无偏优化，从而在理论上消除偏差来源。该方法通过排序统计量机制，在保持无偏梯度估计的同时实现精确的剪枝比率控制。实验证明，OrderDP在CIFAR-10和ImageNet-1K上实现了近无损剪枝，准确率与全量数据持平，且计算成本降低40%以上。其边界在于理论保证依赖于凸性假设，且仅在图像分类任务上验证，未探索多模态或LLM场景。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
