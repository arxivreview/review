# ICLR2026最新论文 ｜INDEPENDENCE TEST FOR LINEAR NON-GAUSSIAN DATA AND APPLICATIONS IN CAUSAL DISCOVERY ｜线性非高斯数据独立性检验

研究机构：阿联酋扎耶德大学、复旦大学

作者：Yiqing Li、Xiaofei Wang、Boyang Sun 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_54644736)

> 在因果发现中，观测数据无法直接区分因果方向，需依赖独立性检验打破对称性。通用非参数检验虽能控制错误率，但在已知数据生成机制为线性非高斯时，其泛化性导致统计功效低下。本文利用线性非高斯模型的结构约束，证明条件均值与方差的恒定性等价于独立性，并据此构建专用核统计量。该方法在特定假设下显著提升了检验功效，但其有效性严格依赖于线性与非高斯假设的成立，一旦数据偏离该模型类，理论保证即刻失效。

## 研究背景

因果发现算法如 Direct-LiNGAM 依赖回归残差与自变量之间的独立性来识别因果方向。这一过程的核心工具是独立性检验，其质量由 Type I 错误（假阳性）和 Type II 错误（假阴性）共同决定。理想检验需在保持 Type I 错误于显著性水平 $\alpha$ 的同时，最大化统计功效（1 - Type II 错误率）。再生核希尔伯特空间（RKHS）为检验提供了几何框架，通过特征映射将分布比较转化为向量空间中的范数计算。希尔伯特-施密特独立性准则（HSIC）利用通用核函数度量协方差算子的 Hilbert-Schmidt 范数，实现了非参数独立性检验，但其功效受限于单核带宽选择的敏感性，且在有限样本下对特定结构依赖的检测能力不足。

现有通用非参数检验（如 HSIC、dCor）旨在捕捉任意形式的依赖关系，这种泛化性在缺乏先验知识时是优势，但在已知数据生成过程为线性非高斯混合时却成为劣势。通用检验未利用线性混合与独立非高斯噪声的结构信息，导致在检测此类特定依赖时统计效率低下。本文的切入点在于：在线性非高斯模型约束下，独立性可由低阶条件矩（均值与方差）的恒定性完全刻画。这一发现使得检验问题从复杂的分布比较简化为对两个特定函数性质的测试，从而为构建高功效专用统计量提供了理论基础。

## 核心方法

### 方法参照系

通用核独立性检验的标准流程是：选择通用核函数，计算协方差算子的 HSIC 统计量，并通过置换检验或渐近分布确定阈值。本文问题与该通用流程的关键差异在于：Y 侧不使用通用特征核，而是利用线性非高斯假设，将 Y 侧核限制为二阶多项式核，从而将检验目标从“任意依赖”缩小为“线性非高斯依赖”。

### 独立性刻画与统计量构建

通用 HSIC 检验中，Y 侧使用通用核以捕捉任意非线性依赖，但这在已知数据为线性非高斯混合时引入了不必要的复杂度。本文基于定理 4.2 和 4.3，指出在线性非高斯设定下，$X \perp Y$ 当且仅当 $\text{Cov}(f(X), Y) = 0$ 且 $\text{Cov}(f(X), Y^2) = 0$ 对所有有界连续函数 $f$ 成立。这一刻画将检验问题转化为对 Y 的一阶和二阶矩与 X 的协方差是否为零的测试。据此，本文定义线性非高斯独立性准则（LiNGIC）统计量：

$$
\text{LiNGIC}(X, Y) = \left\| \text{Cov}(\phi(X), \psi(Y)) \right\|_{HS}^2 + \left\| \text{Cov}(\phi(X), \psi(Y^2)) \right\|_{HS}^2
$$

其中 $\phi$ 是 X 侧通用核（如高斯核）的特征映射，$\psi$ 是 Y 侧二阶多项式核的特征映射，仅包含 $y \mapsto y$ 和 $y \mapsto y^2$。该公式的物理含义是：同时测量 Y 的一阶和二阶矩与 X 的核嵌入之间的协方差强度。设计动机在于，通用 HSIC 使用通用核于 Y 侧，计算成本高且对线性非高斯结构不敏感；本文通过限制 Y 侧核为二阶多项式，直接对齐模型假设，消除了对高阶矩的冗余估计，从而在相同样本量下获得更高的检测功效。

### 对称化与渐近分布

原始 LiNGIC 统计量关于 $(X, Y)$ 不对称，且 Y 侧多项式核在非紧支集上可能导致数值不稳定。为解决此问题，本文构造对称化特征映射 $\tilde{\phi}_1, \tilde{\phi}_2$，将 X 和 Y 的样本向量与特征映射结合，形成对称的核矩阵 $\tilde{K}_1, \tilde{K}_2$。对称化后的统计量定义为：

$$
\text{LiNGIC}_{sym}(X, Y) = \left\| \text{Cov}(\tilde{\phi}_1(X), \tilde{\phi}_2(Y)) \right\|_{HS}^2
$$

该公式通过扩展特征映射，将一阶和二阶协方差测试整合为单一的对称 HSIC 形式。设计动机在于，非对称统计量在 Y 取极端值时数值不稳定，且无法直接应用标准的 V 统计量渐近理论。对称化后，统计量成为三个 V 统计量之和，其渐近分布可推导为加权卡方和，从而无需昂贵的置换检验即可确定阈值。这一改进解决了通用 HSIC 依赖置换检验的计算瓶颈，同时保证了在零假设下 Type I 错误的渐近控制。

## 实验评估

实验在合成数据与 SACHS 真实数据集上进行，基线包括 HSIC、HSIC-RFF、dCor 和 LFHSIC。基线覆盖通用非参数检验路线，但缺失多核聚合（如 DUAL）及深度检验（如 Deep-Testing）等强基线，可能低估了本文方法的相对优势。在 SACHS 数据集上，本文方法在 TruncNorm 噪声下取得 SHD 0.2 和 F1 0.99，显著优于 HSIC 的 SHD 13.2 和 F1 0.91，表明在 LiNGAM 假设成立时，专用检验的功效提升显著。

| Noise Type | SHD (↓) | F1 Score (↑) |
|---|---|---|
| Uniform | 0.8 | 0.98 |
| Laplace | 0.2 | 0.99 |
| Student t | 2.3 | 0.91 |
| TruncNorm | 6.3 | 0.79 |

注：表中数值为 Direct-LiNGAM 算法使用本文方法（Ours）的结果。HSIC 在 TruncNorm 噪声下 SHD 为 13.2，F1 为 0.91。

消融实验未单独报告，但不同噪声类型下的性能差异揭示了模型假设的敏感性：在 TruncNorm 噪声下，SHD 从 0.2 升至 6.3，F1 从 0.99 降至 0.79，表明当噪声分布偏离理想非高斯假设时，检验功效显著下降。这一反直觉发现说明，本文方法的性能高度依赖于噪声分布的特定结构，而非仅依赖线性混合假设。

评估边界方面，论文未报告置信区间，数值比较需谨慎。代码未公开，超参数（如高斯核带宽）采用启发式选择，可复现性受限。SACHS 数据集规模较小，未验证方法在高维数据上的可扩展性。

## 关联研究分析

从问题动机看，本文与通用核独立性检验（如 HSIC）的根本差异在于对模型假设的利用。HSIC 旨在捕捉任意依赖，其通用核选择导致在特定结构下功效损失；本文则通过线性非高斯假设，将检验问题简化为低阶矩测试，从而在相同样本量下获得更高功效。这一差异的根源是任务特性：因果发现算法（如 Direct-LiNGAM）已假设数据生成过程为线性非高斯，因此检验无需泛化到任意依赖，而应聚焦于该特定结构。本文方法在 LiNGAM 假设下优于通用检验，但当数据偏离该假设时，其理论保证失效，而通用检验仍能提供基本的错误率控制。

从方法设计看，本文与 LFHSIC 的差异在于核带宽选择策略。LFHSIC 通过自适应学习带宽来缓解单核敏感性，适用于通用场景；本文则通过模型假设规避了带宽选择对功效的巨大影响，仅需 X 侧通用核，Y 侧固定为二阶多项式核。这一设计选择的根源是线性非高斯结构：Y 侧的依赖仅通过一阶和二阶矩体现，因此无需通用核捕捉高阶结构。然而，当 Y 侧存在非线性依赖时，二阶多项式核可能不足，此时 LFHSIC 的自适应带宽学习可能更具优势。本文未探索 Y 侧核的扩展，这限制了其在更复杂依赖结构下的适用性。

## 总结

本文解决的核心矛盾是通用非参数检验在已知线性非高斯结构下的功效低下问题。其切入点在于证明线性非高斯设定下独立性等价于条件均值与方差的恒定性，从而将检验问题简化为低阶矩测试。基于此，本文构建了 LiNGIC 统计量，利用 X 侧通用核与 Y 侧二阶多项式核的协方差，并推导其渐近分布以替代置换检验。实验表明，在 SACHS 数据集上，本文方法在 TruncNorm 噪声下取得 SHD 0.2 和 F1 0.99，显著优于 HSIC 的 SHD 13.2 和 F1 0.91。本文的边界在于其理论保证严格依赖于线性混合与独立非高斯噪声假设，当噪声分布偏离理想非高斯（如 TruncNorm）时，性能显著下降。当数据生成过程包含非线性混合或高斯噪声时，本文方法的 Type I 错误控制是否仍能保持，论文未给出回答。
