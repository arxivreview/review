【CONSISTENCY-DRIVEN CALIBRATION AND MATCH ING FOR FEW-SHOT CLASS INCREMENTAL LEARNING ｜一致性驱动校准与匹配

研究机构：中南大学、澳大利亚悉尼大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_73132094)

> 少样本类增量学习（Few-Shot Class Incremental Learning, FSCIL）旨在解决新类别样本稀缺导致的原型偏差与固定嵌入结构引发的知识冲突。现有前瞻学习方法通过预分配空间缓解遗忘，但刚性结构约束限制了新类特征的适应性，导致跨会话性能衰减。ConCM 提出特征-结构双重一致性视角，利用语义属性校准原型并动态优化几何结构，在 mini-ImageNet 等基准上取得 SOTA 性能。该方法在少样本约束下有效平衡了稳定性与可塑性，但其对 WordNet 语义依赖及 5-shot 重放设置的适用性边界尚需进一步验证。

【INTERFERENCE-ISOLATED ELASTIC WEIGHT CONSOL - IDATION AND KNOWLEDGE CALIBRATION FOR INCRE MENTAL OBJECT DETECTION ｜干扰隔离弹性权重整合与知识校准

研究机构：西安电子科技大学、华为

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_37849533)

> 增量目标检测（IOD）旨在让检测器在连续学习新类别时，避免旧类别性能因参数更新而崩溃，同时解决密集预测中未标注对象被误标为背景导致的跨任务知识冲突。现有方法多依赖知识蒸馏或统一参数正则化，未能显式量化并隔离由“未来类被当作背景”引发的特定干扰，导致稳定性与可塑性失衡。本文通过重推导贝叶斯后验，在参数重要性估计中剔除干扰项，并引入原型校准模块修正分类头语义漂移。该框架在PASCAL VOC和MS-COCO上超越了基于蒸馏的SOTA，但其效果高度依赖伪标签质量，且在大规模类别流下的扩展性存疑。

【NAMING TO LEARN: CLASS INCREMENTAL LEARNING FOR VISION-LANGUAGE MODEL WITH UNLABELED DATA ｜无标签类增量学习中的解析式回归与伪标签精炼

研究机构：北京大学、哈尔滨工业大学

作者：Qiwei Li、Xiaochen Yang、Jiahuan Zhou

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_64454933)

> 类增量学习（Class-Incremental Learning, CIL）在冻结预训练骨干下顺序学习新类别时，面临灾难性遗忘与数据标注稀缺的双重约束。现有方法多假设训练样本带有精确标签，而真实场景中往往仅能获取类名与无标签数据，直接利用视觉-语言模型生成的伪标签会因噪声加剧遗忘。本文提出N2L，通过SVD降维精炼伪标签并结合双层权重调整的解析式回归，在无标签条件下实现接近有标签上界的性能。该方法在多个基准上显著超越现有无标签基线，但其对伪标签初始质量的依赖及SVD阈值的固定设置，限制了其在极端分布偏移下的泛化边界。

【Random Anchors with Low Rank Decorrelated Learning: A Minimalist Pipeline for Class Incremental Medical Image Classification ｜随机锚点与低秩去相关学习

研究机构：香港中文大学、美国哥伦比亚大学

作者：Xinyao Wu、Zhe Xu、Raymond Kai-yu Tong

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_55318253)

> 类增量学习（CIL）旨在解决模型在顺序学习新类别时因参数更新导致的灾难性遗忘问题，其核心价值在于平衡知识保留与模型可塑性。现有预训练模型（PTM）适配方法多依赖复杂的提示路由或多任务适配器，在通用域有效，但在医学影像的低类内变异与高域偏移场景下易发生特征坍缩。本文提出极简的表示校准框架，通过冻结随机锚点投影与单会话低秩投影联合校准特征，并采用岭回归闭式解更新分类器。该设计在四个医学基准上接近联合训练上界，但其在通用域高类内变异场景下的泛化边界尚存疑。

【The Lie of the Average: How Class Incremental Learning Evaluation Deceives You? ｜类增量学习评估协议的分布偏差与极端序列采样

研究机构：南京大学

作者：Guannan Lai、Da-Wei Zhou、Xin Yang 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.22580)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.22580)

> 类增量学习（Class-Incremental Learning, CIL）模型的性能对类别到达顺序高度敏感，但主流评估协议仅通过随机采样3-5个序列计算均值和标准差，导致对真实性能分布的均值高估与方差严重低估。本文指出这种随机采样（Random Sampling, RS）协议无法捕捉极端序列下的性能边界，从而误导模型选择与部署决策。为此，本文提出基于任务间语义相似度的极端序列采样框架EDGE，通过自适应生成最易、最难及中等难度的类别序列，更准确地逼近真实性能分布。该工作揭示了CIL评估的统计缺陷，但其在大规模类别空间下的序列生成效率与语义相似度假设的普适性仍存疑。

【TWO-WAY IS BETTER THAN ONE: BIDIRECTIONAL - ALIGNMENT WITH CYCLE CONSISTENCY FOR EX EMPLAR-FREE CLASS-INCREMENTAL LEARNING ｜双向循环一致性对齐

研究机构：美国罗切斯特理工学院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_53221488)

> 无样本类增量学习（Exemplar-Free Class-Incremental Learning, EFCIL）旨在禁止存储原始数据的前提下，通过缓存紧凑的类统计量（均值/协方差）来维持旧类识别能力。现有主流方案多采用“先训练新任务，后学习单向适配器”的两阶段范式，这种后置补偿机制导致新旧特征空间间存在系统性偏差，且循环误差随任务累积。本文提出BiCyc，将适配器学习嵌入主训练阶段，通过双向投影与循环一致性约束实现传输与表征的共演化。该方法在标准基准上显著降低了遗忘度，但其理论依赖高斯假设，且在预训练骨干场景下增益有限。

【Two-Way Is Better Than One: Bidirectional Alignment with Cycle Consistency for Exemplar-Free Class-Incremental Learning ｜双向循环一致性无样本类增量学习

研究机构：美国罗切斯特理工学院

作者：Hongye Xu、Bartosz Krawczyk

论文原文见 [arXiv](https://arxiv.org/abs/2606.05675)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.05675)

> 无样本类增量学习（Exemplar-Free Class-Incremental Learning, EFCIL）旨在禁止存储原始数据的前提下，通过统计量缓存维持旧类识别能力，但骨干网络更新引发的特征空间漂移导致缓存统计量失效。现有单向投影补偿方法存在系统性偏差，且后置适配器优化无法消除跨任务累积误差。本文提出BiCyc，将双向投影与循环一致性约束嵌入主训练阶段，实现传输与表征的协同演化。该方法在从头训练设置下显著降低遗忘，但在预训练细粒度场景下增益有限，其理论边界仍受限于高斯假设与小误差条件。

【XIL: CROSS-EXPANDING INCREMENTAL LEARNING ｜跨域扩展增量学习

作者：Heayoun Choi、Hyundong Jin、Eunwoo Kim

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_24099361)

> 类增量学习（CIL）长期假设训练与测试数据共享同一域分布，导致模型在真实场景中面对域偏移时泛化能力骤降。现有方法仅处理固定域下的类增量或单方向域适应，无法实现类-域关联的双向迁移。本文提出XIL设定，要求模型将新类知识扩展至旧域，同时将旧类知识迁移至新域，并设计XEED框架通过生成式重放与域特定提示实现该目标。该工作填补了跨域双向增量学习的空白，但其依赖扩散模型生成样本，计算开销与生成质量对性能的敏感性尚存疑。

】
