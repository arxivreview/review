# ICLR2026最新论文 ｜HardcoreLogic: Challenging Large Reasoning Models with Long-tail Logic Puzzle Games ｜长尾逻辑谜题基准：挑战大推理模型的鲁棒性

研究机构：复旦大学、美国南加州大学

作者：Jingcong Liang、Shijun Wan、Xuehai Wu 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.12563)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.12563)

> 导读 大推理模型（Large Reasoning Models, LRMs）在标准逻辑谜题上表现优异，但其是否具备真正的逻辑推理能力而非依赖模式匹配，仍是核心争议。现有基准多聚焦于标准形式（Canonical Form）的难度扩展，未能覆盖分布外（Out-of-Distribution, OOD）的长尾变体，导致模型过拟合于训练数据中的固定解题策略。HardcoreLogic通过引入复杂度提升、罕见元素和不可解任务三个维度的长尾变换，系统性地测试LRMs在非标准规则下的鲁棒性。该基准揭示了SOTA模型在面对规则变异和不可解场景时的显著性能退化，证实了当前模型对记忆化策略的依赖，为评估逻辑推理的泛化能力提供了关键诊断工具。

## 研究背景

当LRMs面对逻辑谜题时，其表现往往取决于谜题是否属于训练语料中的常见形式。以数独为例，模型在标准的9x9网格上准确率极高，但一旦引入不规则子网格或字母编码等罕见变体，性能便急剧下降。这种现象源于训练数据分布的严重不平衡：标准形式占据绝大多数，导致模型习得了针对特定形式的固定解题策略，而非通用的逻辑规则应用机制。当输入偏离标准分布时，模型要么无法理解新规则，要么错误地套用旧策略，暴露出“模式匹配”而非“符号推理”的本质。

现有逻辑推理基准如ZebraLogic和Enigmata主要关注标准谜题的难度扩展，通过增加推理步数或搜索空间来测试模型上限，但缺乏对分布外泛化能力的评估。这种评估盲区掩盖了模型在长尾场景下的脆弱性。此外，主流基准几乎全部由可解任务组成，缺乏对模型识别“无解”或“矛盾”能力的测试，导致模型在面对逻辑不一致时倾向于幻觉出错误答案而非拒绝回答。HardcoreLogic正是为了填补这一空白，通过系统性的长尾变换，将评估焦点从“解题深度”转向“规则适应性与鲁棒性”。

## 核心方法

### 长尾变换体系与复杂度量化

HardcoreLogic将逻辑谜题的长尾变换划分为三个家族：复杂度提升（Increased Complexity, IC）、罕见元素（Uncommon Element, UE）和不可解任务（Unsolvable Puzzle, UP）。这一分类体系旨在从搜索空间、规则形式和逻辑一致性三个维度剥离模型的记忆化捷径。

对于IC类变换，论文通过扩大搜索空间和增强约束纠缠度来量化难度。搜索空间扩展（IC1）通过减少初始给定信息或扩大网格尺寸实现，其复杂度通过候选状态数的对数尺度衡量。例如，在Binario谜题中，若空单元格数量为$N$，则搜索空间$|S|$为：

$$ |S| = 2^N $$

该公式表明，随着空单元格数量线性增加，搜索空间呈指数级膨胀，直接挑战模型的组合搜索能力。对于约束增强（IC2），论文利用Z3求解器记录决策数（Decisions）和冲突数（Conflicts），作为约束纠缠度的代理指标。

### 罕见元素与不可解任务的构造

UE类变换通过改变谜题形式（UE1）或修改逻辑规则（UE2）来引入分布外特征。UE1如将数独数字替换为字母或引入不规则子网格，其难度通过预训练模型的困惑度（Perplexity）量化，高困惑度表示模型对形式的陌生程度。UE2如引入对角线约束或邻接约束，通过Z3求解器的决策数变化来衡量规则修改对推理链的影响。

UP类变换则通过添加矛盾约束或破坏连通性，使原本可解的谜题变为无解。这一设计旨在测试模型是否具备逻辑一致性检测能力，而非仅依赖搜索找到答案。例如，在Navigation谜题中，通过破坏图的连通性使目标不可达，模型应识别出“无解”而非强行输出路径。

## 实验评估

实验在10种逻辑谜题（包括ZebraLogic, Sudoku, Minesweeper等）上评估了20+个LRMs，涵盖开源与闭源SOTA模型。评估协议采用4次采样，以无错误输出比例作为实例级成功率。

| 模型 | 数据集 | 准确率 (%) | 备注 |
| :--- | :--- | :--- | :--- |
| gpt-oss-120b | Original | 78.0 | 开源最佳 |
| gpt-oss-120b | HardcoreLogic | 62.0 | 下降16.0% |
| Kimi-K2-Instruct | Original | 75.0 | - |
| Kimi-K2-Instruct | HardcoreLogic | 37.0 | 下降38.0% |
| Minimax-M1 | Original | 45.0 | - |
| Minimax-M1 | HardcoreLogic | 15.0 | 下降30.0% |

*注：具体数值基于论文Figure 4及文本描述估算，精确数值需参考原始图表。*

主结果显示，所有模型在HardcoreLogic上均出现显著性能退化。Kimi-K2-Instruct下降幅度最大（38.0%），而gpt-oss-120b虽保持最高绝对准确率，但也下降了16.0%。Binario谜题因搜索空间扩大导致平均性能下降最严重，而Skyscraper因本身难度极高或极低，下降幅度最小。

消融分析表明，IC1（搜索空间扩展）对模型性能影响最大，其回归系数显著为负。UE1（形式变异）在Sudoku上影响显著，表明模型难以识别不规则网格。错误分析显示，事实性错误（Factual Errors）和暴力搜索（Brute-Force）是主要失败模式，强模型倾向于尝试穷举而非策略推理，弱模型则倾向于幻觉答案。

评估边界方面，论文未提供置信区间，且部分闭源模型仅采样600例，统计效力受限。此外，未对比神经符号方法（如Logic-Thinker）在长尾场景下的表现，无法判断外部验证器是否能缓解UE类变换带来的性能下降。

## 关联研究分析

与ZebraLogic和Enigmata相比，HardcoreLogic的核心差异在于评估维度的扩展。ZebraLogic通过增加推理步数测试深度，而HardcoreLogic通过规则变异测试广度。ZebraLogic的SOTA成绩（81.0%）在HardcoreLogic的Original子集上可复现，但在长尾变体上失效，说明现有SOTA仅覆盖了分布内能力。HardcoreLogic的UP任务填补了逻辑一致性检测的空白，而ZebraLogic等基准缺乏此类任务，导致模型幻觉问题未被充分暴露。

与神经符号方法（如Logic-Thinker）相比，HardcoreLogic侧重于纯神经模型的鲁棒性诊断。Logic-Thinker通过外部求解器保证逻辑健全性，理论上能更好地处理UE2（规则变异），因为形式化器可解析新规则。然而，HardcoreLogic的UE1（形式变异）可能仍构成挑战，因为自动形式化（Autoformalization）在面对罕见符号系统时易出错。论文未对比此类方法，无法确定神经符号融合是否是解决长尾泛化的终极方案。

## 总结

HardcoreLogic通过长尾变换揭示了LRMs在分布外逻辑推理中的系统性脆弱性。其核心贡献在于将评估焦点从“解题深度”转向“规则适应性”，并通过UP任务暴露了模型在逻辑一致性检测上的缺陷。实验显示，即使GPT-5等SOTA模型，在面对非标准规则时性能也下降16.0%以上，证实了模型对记忆化策略的依赖。该基准的边界在于未涵盖多模态逻辑推理及动态环境下的规则演化。当模型面对需要实时解析全新规则体系的场景时，其内部是否具备可迁移的符号操作机制，还是仅依赖预训练中的统计关联，仍是未解之谜。
