# ICLR2026最新论文 ｜WithAnyone: Towards Controllable and ID Consistent Image Generation ｜破解复制粘贴伪影：配对训练与对比损失驱动的身份生成

研究机构：复旦大学

作者：Hengyuan Xu、Wei Cheng、Peng Xing 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.14975)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.14975)

> 身份保持人脸生成（IPFG）旨在从参考图锁定特定人物身份，同时允许文本提示控制姿态与表情，但现有模型常陷入“复制粘贴伪影”，即过度复制参考图细节而丧失对文本指令的响应能力。这一失效源于主流重建式训练范式，其中参考图与目标图重合，迫使模型学习低层纹理复制而非高层身份泛化。本文通过构建大规模配对数据集 MultiID-2M 并提出 ID 对比损失，在 FLUX 架构上实现了高保真与高可控性的平衡。该工作打破了保真度与多样性的长期权衡，但其依赖大规模人工标注数据，推理效率与极端视角下的鲁棒性仍存疑。

## 研究背景

当生成模型面对同一人物的不同照片时，其输出往往僵化地复制参考图的妆容与姿态，而非根据文本提示生成自然变化的肖像。这种失效模式被称为复制粘贴伪影，其根源在于身份嵌入与语义嵌入在特征空间中的耦合：模型将参考图的像素级特征误认为身份本身，导致对姿态、表情等动态属性的控制失效。解决此问题需要区分“身份”与“外观”，但现有数据集缺乏同一身份在不同视角、表情下的配对样本，使得模型无法学习这种解耦。

IPFG 领域的主流路线已从早期的 GAN 微调转向基于潜空间扩散模型（LDM）的免微调注入，如 IP-Adapter 和 InstantID 通过交叉注意力机制注入 ArcFace 嵌入。然而，这些方法多依赖单图重建训练，参考图与目标图一致，本质上强化了复制行为。随着扩散 Transformer（DiT）架构的兴起，如 PuLID 和 WithAnyone 等模型虽提升了生成质量，但仍未解决复制粘贴伪影导致的可控性下降问题。本文的切入点在于指出数据层面的缺陷：缺乏多视角、多表情的配对参考图，导致模型无法区分身份不变性与外观可变性。

## 核心方法

### 方法参照系

本文基于 FLUX（DiT 架构）构建身份定制模型，其标准流程为：提取参考图 ArcFace 嵌入，通过交叉注意力注入去噪过程，并以重建损失优化。与 PuLID 等仅依赖残差适配器注入的方法不同，本文的核心差异在于训练策略：从单一重建目标转向配对对比学习，以显式抑制复制行为。

### 配对训练与 ID 对比损失

传统重建训练中，参考图与目标图相同，模型倾向于直接复制像素。本文在训练阶段引入配对样本，随机选取同一身份的两张不同图像，一张作为参考，另一张作为目标，迫使模型学习跨视角的身份一致性。在此基础上，引入 ID 对比损失，利用 InfoNCE 公式将生成图像拉近参考身份，同时推远其他身份：

$$ \mathcal{L}_{CL} = -\log \frac{\exp(\text{sim}(\mathbf{g}, \mathbf{r})/\tau)}{\exp(\text{sim}(\mathbf{g}, \mathbf{r})/\tau) + \sum_{j=1}^{M} \exp(\text{sim}(\mathbf{g}, \mathbf{n}_j)/\tau)} $$

其中 $\mathbf{g}$ 为生成图像嵌入，$\mathbf{r}$ 为参考图像嵌入，$\mathbf{n}_j$ 为负样本嵌入。该损失通过大规模负样本池提供强判别信号，确保模型关注身份特征而非背景或纹理。

### GT 对齐 ID 损失

直接对生成图像进行人脸检测与对齐不可靠，因生成图像存在噪声。本文采用 GT 对齐策略，使用目标图像的预检测关键点来对齐生成图像，计算 ArcFace 嵌入的余弦距离：

$$ \mathcal{L}_{ID} = 1 - \cos(\mathbf{g}_{aligned}, \mathbf{t}) $$

其中 $\mathbf{g}_{aligned}$ 为使用 GT 关键点对齐后的生成图像嵌入，$\mathbf{t}$ 为 GT 图像嵌入。此设计避免了噪声关键点导致的身份度量偏差，使 ID 损失可在所有噪声水平下稳定应用，显著提升了身份保持的准确性。

## 实验评估

在 MultiID-Bench 单人子集上，WithAnyone 以 0.460 的 Sim(GT) 和 0.144 的 Copy-Paste (CP) 分数领先，显著优于 PuLID（0.452, 0.315）和 InstantID（0.464, 0.337）。基线覆盖包括 OmniGen、UMO 等通用定制模型及 PuLID、InstantID 等面部定制模型，但缺失 DreamBooth 等早期微调方法，因其计算开销大且与 DiT 架构不兼容。

| 方法 | Sim(GT)↑ | Sim(Ref)↑ | CP↓ | CLIP-I↑ | CLIP-T↑ | Aes↑ |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| PuLID | 0.452 | 0.705 | 0.315 | 0.779 | 0.305 | 4.839 |
| InstantID | 0.464 | 0.734 | 0.337 | 0.764 | 0.295 | 5.255 |
| WithAnyone | 0.460 | 0.578 | 0.144 | 0.798 | 0.313 | 4.783 |

消融实验显示，移除配对训练（w/o Phase 3）导致 CP 分数从 0.161 升至 0.239，Sim(GT) 从 0.405 降至 0.406，表明配对训练是抑制复制伪影的关键。移除扩展负样本（w/o Ext. Neg.）使 Sim(GT) 降至 0.368，证明大规模负样本池对身份判别至关重要。移除 GT 对齐（w/o GT-Align）导致 Sim(GT) 降至 0.385，验证了 GT 对齐在身份度量准确性上的贡献。

评估边界方面，MultiID-Bench 仅包含 435 个测试用例，且身份来自长尾分布，可能高估模型在常见身份上的表现。论文未报告推理时间与 GPU 显存占用，无法评估其实时性。代码与模型已开源，但 MultiID-2M 数据集的构建依赖大量人工标注与清洗，复现成本较高。

## 关联研究分析

从问题动机看，WithAnyone 与 PuLID 同属 DiT 架构下的身份注入路线，但 PuLID 侧重通过残差适配器提升保真度，而 WithAnyone 聚焦于解决保真度与可控性的权衡。PuLID 的 CP 分数高达 0.315，表明其虽保真度高，但复制伪影严重；WithAnyone 通过配对训练将 CP 降至 0.144，但 Sim(Ref) 从 0.705 降至 0.578，暗示其在参考图相似度上有所牺牲。这一差异源于任务特性：PuLID 面向高保真肖像生成，而 WithAnyone 面向可控多身份生成，后者需容忍参考图与生成图的自然差异。

从方法设计看，WithAnyone 与 UMO 均处理多身份场景，但 UMO 依赖 VAE 派生嵌入拼接输入，易产生像素级复制；WithAnyone 采用 ArcFace 嵌入与对比损失，更强调身份语义的解耦。UMO 在 MultiID-Bench 多人子集上的 Sim(GT) 为 0.328，低于 WithAnyone 的 0.405，表明 WithAnyone 的身份隔离能力更强。然而，WithAnyone 未探索空间定位约束，如掩码注意力或布局控制，这在复杂多人场景中可能成为瓶颈。

## 总结

WithAnyone 针对 IPFG 中复制粘贴伪影导致的可控性丧失问题，指出其根源在于重建式训练缺乏配对样本。通过构建 MultiID-2M 数据集并引入 ID 对比损失与 GT 对齐 ID 损失，该模型在 FLUX 架构上实现了 Sim(GT) 0.460 与 CP 0.144 的平衡，显著优于 PuLID 和 InstantID。其边界在于依赖大规模配对数据，且未报告推理效率，极端视角下的鲁棒性也未充分验证。当参考图与目标图的视角差异超过 45 度时，GT 对齐策略是否仍能有效抑制复制伪影，论文未给出回答。
