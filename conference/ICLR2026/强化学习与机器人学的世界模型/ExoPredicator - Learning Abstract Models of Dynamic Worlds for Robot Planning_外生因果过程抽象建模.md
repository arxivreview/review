# ICLR2026最新论文 ｜ExoPredicator: Learning Abstract Models of Dynamic Worlds for Robot Planning ｜外生因果过程抽象建模

研究机构：英国剑桥大学、美国康奈尔大学

作者：Yichao Liang、Dat Nguyen、Cambridge Yang 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.26255)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.26255)

> 长时程具身规划的核心障碍在于环境动力学并非仅由智能体动作驱动，外生过程（如水流、多米诺骨牌倒塌）在智能体行动期间独立演化，导致传统即时动作模型失效。现有符号规划器无法从数据中学习此类延迟因果链，而纯神经世界模型因像素级模拟成本过高且缺乏可解释性，难以在长时程任务中保持规划稳定性。ExoPredicator 通过联合学习符号状态抽象与内生/外生因果过程，利用变分贝叶斯推断与 LLM 引导的结构搜索，从有限轨迹中构建可规划的世界模型。该方法在五个模拟机器人环境中实现了对新任务与未见对象的泛化，但其有效性局限于离散符号化场景，未验证在连续高维控制任务中的适用性。

## 研究背景

当智能体执行“烧水”任务时，开启电热水壶后水温持续上升直至沸腾，这一过程独立于智能体的后续动作（如切菜）。若规划器仅建模智能体直接控制的动作（内生过程），将忽略环境自主演化的因果链（外生过程），导致规划失效。解决此问题需引入抽象世界模型，它保留决策关键信息，隐藏无关细节，但必须同时抽象状态空间与时间粒度，即建模“原因”与“效果”之间的随机延迟关系，而非逐帧模拟物理细节。

传统规划表示法 PDDL 将动作视为即时发生，PDDL 2.1 虽引入持续动作，但仍无法显式建模自主外生过程，除非扩展为 PDDL+。然而，从数据中学习 PDDL+ 风格的符号模型面临组合爆炸难题：时间粒度的细化导致状态空间指数级增长。视觉语言模型（VLM）虽能推理外部因果机制，但在面对新颖情境或时间物理约束时泛化能力不足。现有神经世界模型（如 Dreamer 系列）依赖潜空间动力学预测，虽提升了样本效率，但长时程预测误差累积问题依然严峻，且缺乏对因果结构的显式建模，难以解释“为何”状态发生变化。

ExoPredicator 的切入点在于将世界模型从“状态预测器”重构为“因果过程生成器”。它不预测下一帧像素或潜向量，而是学习一组符号化的因果过程，每个过程定义条件、效果及随机延迟分布。这种抽象允许规划器在抽象状态空间中进行大步骤跳跃，直接跳过中间恒定状态，从而在结构上规避逐步滚动的误差累积，并实现对新对象与复杂目标的泛化。

## 核心方法

### 符号因果过程表示

本文方法参照系为神经符号规划框架，但关键差异在于将时间动力学显式建模为随机延迟的因果过程，而非即时状态转移。传统符号规划假设动作效果即时发生，而本文引入内生过程（智能体控制）与外生过程（环境自主演化）的区分，每个过程由模式元组 $\langle \text{PAR}, C, O, E, W, p_{\text{delay}} \rangle$ 定义，其中 $C$ 为启动条件，$O$ 为整体条件，$E$ 为效果集，$W$ 为对数强度，$p_{\text{delay}}$ 为延迟分布。该设计解决了传统 PDDL 无法表达“开启水龙头后水逐渐充满”这类非即时因果链的问题，使规划器能推理环境自主演化的时间进程。

### 变分贝叶斯推断与 LLM 引导结构学习

参数学习环节通常采用最大似然估计，但本文面对组合爆炸的延迟时间变量，采用变分推断近似边缘似然。引入变分分布 $q_t[L](A_t[L])$ 编码效果到达时间的信念，优化以下变分下界：

$$
\mathcal{L}(\theta, \phi) = \mathbb{E}_{q(\cdot)} \left[ \log p(D_{\text{abs}} | \theta) \right] - \text{KL}(q(\cdot) || p(\cdot))
$$

该公式通过优化延迟分布与过程权重，从有限轨迹中估计因果过程的参数，避免了穷举所有可能时间组合的计算不可行性。

外生过程结构学习环节通常依赖梯度优化，但本文面对离散符号结构的组合搜索，采用 LLM 引导的贝叶斯模型选择。首先将轨迹分割为片段，按状态变化特征聚类，然后提示 LLM 为每个簇提议候选过程，最后通过贝叶斯目标函数评分：

$$
L_C^* = \arg \max_L p(C | L) p(L)
$$

其中 $p(L)$ 为最小描述长度先验，$p(C | L)$ 由变分推断近似。该设计解决了离散结构搜索空间过大导致优化停滞的问题，利用 LLM 的常识知识缩小候选空间，再通过贝叶斯准则选择最简洁且拟合数据的过程，实现了从数据中自动发现外生因果机制。

## 实验评估

实验在五个自定义模拟环境（Coffee, Grow, Boil, Domino, Fan）中进行，评估 ExoPredicator 与分层强化学习（HRL）、VLM 规划、算子学习等基线在求解率与样本效率上的表现。基线覆盖符号规划与神经规划路线，但缺失 Dreamer 系列等主流潜空间世界模型基线，因任务性质为离散符号化，连续控制基线不适用。该论文实验数据不可得，未提供实验表格。

消融实验验证了贝叶斯模型选择与 LLM 引导组件的贡献。移除 LLM 引导后，结构搜索效率显著下降，因候选空间过大导致优化困难；移除贝叶斯评分后，模型倾向于选择复杂但过拟合的过程，泛化能力减弱。设计决策中，使用 VLM 作为谓词查询接口而非直接像素特征提取，虽增加了推理延迟，但提升了状态抽象的可解释性与对新对象的泛化能力，因 VLM 具备常识知识，能识别未见对象的相关属性。

评估边界方面，实验仅在模拟环境中进行，未涉及真实机器人部署，Sim-to-Real 差距未验证。指标以任务求解率为主，缺乏对规划时间、计算开销的定量报告，因 A* 搜索在抽象状态空间中的效率未量化。可复现性方面，论文未提供代码 URL，但详细描述了算法流程与超参数设置，理论上可复现，但 LLM 提议的随机性可能导致结果波动。

## 关联研究分析

从问题动机看，ExoPredicator 与 VisualPredicator (Liang et al., 2024) 同属神经符号世界模型路线，但前者聚焦即时动作建模，后者扩展至延迟因果过程。关键差异在于时间粒度抽象：VisualPredicator 假设动作效果即时发生，无法处理“水逐渐充满”这类外生过程，而 ExoPredicator 通过随机延迟分布显式建模时间进程。这一差异源于任务特性：VisualPredicator 针对简单操作任务，而 ExoPredicator 针对包含环境自主演化的复杂场景。若任务中无显著外生过程，ExoPredicator 的延迟建模可能引入不必要的复杂度，论文未给出此类场景下的性能对比。

从方法设计看，ExoPredicator 与 DreamerV3 代表符号化与连续潜空间两条路线。DreamerV3 通过 RSSM 学习连续潜空间动力学，擅长高维视觉环境中的样本高效学习，但缺乏因果结构解释，长时程预测误差累积问题未解决。ExoPredicator 通过符号因果过程实现大步骤跳跃，从结构上规避误差累积，但依赖离散符号抽象，可能丢失连续物理量（如速度、力）的精细信息。在连续控制任务（如 DMLab）中，符号化表示是否因离散化损失而失效，论文未探索，因实验环境均为离散符号化场景。

## 总结

ExoPredicator 解决的核心矛盾是长时程规划中外生因果过程的时间粒度抽象难题，传统符号规划无法从数据中学习延迟因果链，而神经世界模型因像素级模拟成本过高且缺乏可解释性，难以在长时程任务中保持规划稳定性。本文抓住的切入点是联合学习符号状态抽象与内生/外生因果过程，利用变分贝叶斯推断与 LLM 引导的结构搜索，从有限轨迹中构建可规划的世界模型。该方法在五个模拟环境中实现了对新任务与未见对象的泛化，超越 HRL 与 VLM 规划基线。其边界在于局限于离散符号化模拟环境，未验证在连续高维控制任务中的适用性，且缺乏对规划时间与计算开销的定量评估。当任务包含显著连续物理量（如流体动力学、刚体碰撞）时，符号因果过程表示能否捕捉足够的动力学细节以支持精确规划，论文未给出回答。
