# ICLR2026最新论文 ｜Rethinking Residual Errors in Compensation-based LLM Quantization ｜补偿感知误差：修正PTQ中的残差对齐目标

研究机构：浙江大学

作者：Shuaiting Li、Juncan Deng、Kedong Xu 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.07955)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.07955)

> 导读 大语言模型（LLM）部署面临内存瓶颈，后训练量化（PTQ）通过降低权重精度实现压缩，但极低比特下精度崩塌严重。现有基于误差补偿的PTQ方法在逐列量化时，校准目标存在偏差，导致误差累积无法被精确抵消。本文指出GPTQ与GPTAQ在层内迭代中忽略了权重补偿本身引入的固有误差，提出“补偿感知误差”以严格对齐全精度输出。这一修正在2-3 bit量化下显著提升了困惑度与下游任务准确率，但其有效性是否延伸至1 bit以下或长链推理场景，尚待验证。

## 研究背景

Transformer架构中，自注意力机制与前馈网络（FFN）构成了模型参数的主体，导致Llama 3 70B等模型在FP16精度下需占用140GB显存。为缓解此问题，PTQ成为主流压缩范式，其核心在于利用校准数据，通过二阶信息（如Hessian矩阵）迭代更新未量化权重，以补偿已量化权重带来的输出误差。然而，当比特宽度降至2-3 bit时，离散化空间极度稀疏，微小的校准偏差会引发严重的精度退化。

补偿类量化方法源于最优脑损伤（OBD）与最优脑外科（OBS）框架，GPTQ（Frantar et al., 2022）通过Cholesky分解实现了高效的大规模应用。GPTAQ（Li et al., 2025）进一步引入非对称校准，试图解决层间误差累积问题，其核心思想是将前一层量化后的输出误差作为残差，传播至当前层的校准目标中。尽管GPTAQ在层间对齐上取得了进展，但其层内迭代过程仍依赖于“补偿后权重”的输出作为校准基准，而非原始全精度模型的输出。这种基准的偏移意味着，随着量化步骤的推进，校准目标逐渐偏离真实的全精度参考，导致误差补偿机制在深层或低比特下失效。本文切入点在于重新审视这一层内校准目标，揭示被忽略的层内固有误差。

## 核心方法

### 方法参照系

GPTQ与GPTAQ的标准流程是逐列量化权重，并利用Hessian逆矩阵计算剩余权重的更新量$\Delta \mathbf{w}$。GPTAQ在GPTQ基础上引入了残差误差$\mathbf{r}$，定义为量化流（Quant-flow）与全精度流（FP-flow）在输入端的差异，旨在对齐层间输出。本文的问题在于，该残差定义仅考虑了输入端的误差传播，未考虑当前层权重在迭代过程中因补偿而发生的状态变化。

### 补偿感知误差的推导

GPTAQ在量化第$q$列时，其列级优化目标隐含假设校准目标为当前补偿后权重$\mathbf{w}^{(q)}$的输出。然而，对于$q \ge 1$，$\mathbf{w}^{(q)}$已偏离原始权重$\mathbf{w}^{(0)}$，导致校准目标失真。本文重新定义优化目标，要求量化后的输出严格对齐原始全精度权重$\mathbf{w}^{(0)}$的输出。通过展开该目标，残差误差被分解为两部分：原有的输入端残差$\mathbf{r}_1$，以及新增的补偿感知误差$\mathbf{r}_2$。

$$
\mathbf{r}' = \mathbf{r}_1 + \mathbf{r}_2 = (\mathbf{w}^{(q)} \tilde{\mathbf{X}} - \mathbf{w}^{(q)} \mathbf{X}) + (\mathbf{w}^{(0)} - \mathbf{w}^{(q)}) \tilde{\mathbf{X}}
$$

其中，$\mathbf{r}_1$对应GPTAQ中的项，$\mathbf{r}_2$即补偿感知误差，它量化了当前层权重从原始状态到当前补偿状态的偏差对输出的影响。这一设计动机在于，仅补偿输入误差不足以消除层内权重状态漂移带来的累积误差，必须显式建模权重本身的补偿历史。

### 高效计算与集成

直接计算$\mathbf{r}_2$需要存储原始权重矩阵，开销巨大。本文利用GPTAQ的神经元分解技术，将$\mathbf{r}_2$表示为预计算矩阵$\mathbf{P}_2$与权重差值的乘积。

$$
\Delta \mathbf{W} = \mathbf{E}_{:q} \mathbf{L}^T_{q,q:} + (\mathbf{W}^{(0)}_{:q} - \mathbf{W}^{(q)}_{:q}) \mathbf{P}_2_{q,q:}
$$

其中，$\mathbf{P}_2_{q,q:} = \tilde{\mathbf{X}}_{q,:} \mathbf{X}^T_{:,q:} \mathbf{H}^{-1}_{-q}$。该公式表明，只需额外存储原始权重$\mathbf{W}^{(0)}$和预计算矩阵$\mathbf{P}_2$，即可在权重更新中融入补偿感知误差。这一改进无需修改GPTQ/GPTAQ的整体架构，仅替换了权重更新公式中的残差项，计算开销增加约5%，且不影响推理时的内存占用。

## 实验评估

实验在Llama 2/3系列（1B-70B）上进行，评估指标包括WikiText-2/C4困惑度及六个下游任务准确率。基线覆盖GPTQ、GPTAQ、AWQ及结合旋转变换的QuaRot/SpinQuant。值得注意的是，实验未包含AQLM、SDQ-LLM等向量量化或原生低比特基线，限制了与极低比特前沿方法的直接对比。

| 模型 | 方法 | Wiki2 PPL | Avg Acc |
| :--- | :--- | :--- | :--- |
| L2-7B | GPTQ | 6.73 | 64.9 |
| L2-7B | GPTQ+Ours | 6.40 | 66.5 |
| L2-7B | GPTAQ | 6.53 | 66.3 |
| L2-7B | GPTAQ+Ours | 6.25 | 66.6 |
| L2-13B | GPTQ | 5.43 | 71.4 |
| L2-13B | GPTQ+Ours | 5.42 | 72.3 |
| L2-13B | GPTAQ | 5.42 | 71.9 |
| L2-13B | GPTAQ+Ours | 5.39 | 72.1 |

在3-bit权重量化下，本文方法在Llama2-7B上将GPTQ的Wiki2 PPL从6.73降至6.40，平均准确率从64.9%提升至66.5%。在2-bit结合QuaRot的设置中，Llama2-13B的PPL从7.50降至7.32，准确率从55.8%提升至58.2%。消融实验表明，补偿感知误差项在GPTQ和GPTAQ框架下均带来一致增益，且在低比特下增益更为显著，证实了层内误差建模的重要性。

评估边界方面，实验主要聚焦于权重量化（W-only）及W2A4KV4设置，未探索1-bit或Sub-1-bit场景。代码已开源，但70B模型的量化依赖单卡H20 GPU，复现成本较高。此外，论文未报告置信区间，且不同方法在比特宽度、校准数据量上的差异使得直接PPL对比需谨慎。

## 关联研究分析

从问题动机看，本文与GPTAQ同属PTQ误差补偿路线，但GPTAQ关注层间误差传播，本文聚焦层内权重状态漂移。GPTAQ假设层间对齐即可保证全局精度，而本文指出层内校准目标的偏移会导致误差累积。这一差异源于对“校准基准”的不同理解：GPTAQ使用动态变化的补偿权重作为基准，本文坚持使用静态的全精度权重作为基准。这种设计选择使得本文方法在低比特下更稳健，因为低比特下权重补偿幅度大，状态漂移更显著。

从方法设计看，本文与AQLM、SDQ-LLM等向量量化方法形成对比。AQLM通过多码本加性量化突破标量极限，SDQ-LLM利用Sigma-Delta调制处理1-bit量化，二者均改变了权重的表示形式。本文则保持标量量化框架，仅优化误差补偿逻辑。这意味着本文方法依赖于权重分布的近似高斯特性（Hessian假设），在权重分布严重偏离高斯或存在极端离群值时，其效果可能受限。相比之下，向量量化方法通过结构化编码更适应非均匀分布，但推理内存带宽压力更大。本文未探索与向量量化的结合，也未验证在1-bit下补偿感知误差是否仍有效，这构成了其方法边界。

## 总结

本文针对PTQ中GPTQ/GPTAQ层内校准目标偏差的问题，提出补偿感知误差，通过显式建模权重补偿引入的固有误差，实现对齐全精度输出。实验证明，该改进在2-3 bit量化下显著提升了Llama系列模型的困惑度与下游任务准确率，例如Llama2-7B 3-bit下PPL从6.73降至6.40。然而，本文实验未覆盖1-bit及Sub-1-bit场景，且未与向量量化等极低比特前沿方法对比，其方法有效性在极致压缩下的边界尚不明确。当比特宽度进一步降低至1 bit时，补偿感知误差能否抵消离散化空间的稀疏性导致的精度崩塌，论文未给出回答。
