# ICLR2026最新论文 ｜ROBUST PREFERENCE ALIGNMENT VIA DIRECTIONAL NEIGHBORHOOD CONSENSUS ｜鲁棒偏好对齐：方向邻域共识

研究机构：香港科技大学、上海交通大学

作者：Ruochen Mao、Yuling Shi、Xiaodong Gu 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.20498)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_8894747)

> 大语言模型在训练数据覆盖的“平均偏好”区域表现稳定，但面对偏离中心趋势的个体化需求时，性能会不可预测地退化。现有训练时干预方法（如数据增强、分布鲁棒优化）成本高且难以泛化至全谱系偏好。本文提出免训练的推理时方法 RPS，通过采样目标偏好的局部邻域方向生成候选响应，再基于原始目标偏好筛选最优解。该方法在分布外（OOD）偏好上显著提升了鲁棒性，但其理论保证依赖于奖励模型在 OOD 区域的平滑性假设，这一前提在极端偏好场景下的有效性尚存疑。

## 研究背景

当用户指令隐含特定的风格权衡（如“高有用性但低冗余”）时，模型需在高维偏好空间中定位对应的生成方向。然而，对齐训练数据通常集中于少数主导偏好方向，导致模型在稀疏的个体化偏好区域缺乏足够的训练信号。这种训练分布与用户真实需求分布之间的错位，构成了“偏好覆盖缺口”（Preference Coverage Gap）。该缺口使得模型在面对分布外（Out-of-Distribution, OOD）偏好时，无法通过内化的参数知识稳定地生成高质量响应，而是表现出对单一特定方向的脆弱依赖。

偏好对齐的主流路线长期聚焦于训练时优化。直接偏好优化（Direct Preference Optimization, DPO）及其变体通过离线数据更新模型权重，虽简化了流程，但本质上仍是对训练分布的拟合。分布鲁棒优化（Distributionally Robust Optimization, DRO）尝试在训练阶段增强对分布偏移的韧性，但需要昂贵的重训周期，且难以覆盖所有可能的个体化偏好组合。推理时对齐（Inference-Time Alignment）提供了另一条路径，如 Token 级引导或激活转向，但这些方法通常需干预模型内部状态或依赖辅助模型，增加了系统复杂度。本文的切入点在于：不修改模型权重，也不干预生成过程，而是将鲁棒性问题转化为偏好空间中的几何采样与选择问题，利用模型在已训练良好区域的既有能力，通过“邻域共识”机制间接满足 OOD 请求。

## 核心方法

### 偏好空间形式化与覆盖缺口定义

本文基于方向偏好对齐（Directional Preference Alignment, DPA）框架，将用户偏好建模为二维单位圆上的方向向量 $\mathbf{v} = (\cos \theta, \sin \theta)$，其中 $\theta$ 表示有用性与冗余性的权衡角度。奖励模型将提示-响应对 $(x, y)$ 映射为奖励向量 $\mathbf{r}(x, y) \in \mathbb{R}^2$。偏好覆盖缺口被形式化为训练偏好集 $V_{train}$ 的 $\epsilon$-邻域之外的所有向量集合：

$$
\text{Gap} = V_{user} \setminus N_\epsilon(V_{train})
$$

当目标偏好 $\mathbf{v}_{target}$ 落入该缺口时，直接生成响应 $\arg\max_y \mathbf{v}_{target}^T \mathbf{r}(x, y)$ 变得不可靠。此定义将模糊的“个性化需求”转化为可计算的几何距离问题，为后续邻域采样提供了明确的边界依据。

### 方向邻域共识机制

RPS 的核心创新在于将单点生成转化为局部集合优化。传统方法直接以 $\mathbf{v}_{target}$ 为条件生成响应，而 RPS 首先构建一个以 $\mathbf{v}_{target}$ 为中心、角度阈值 $\theta_{max}$ 为半径的邻域 $N_k$，从中采样 $k$ 个更靠近训练分布中心的方向 $\mathbf{v}_i$。对于每个 $\mathbf{v}_i$，模型生成候选响应 $y_i \sim \pi_\theta(\cdot|x, \mathbf{v}_i)$。最终响应通过最大化目标偏好的投影奖励选出：

$$
y^* = \arg\max_{i \in \{1,\dots,k\}} \mathbf{v}_{target}^T \mathbf{r}(x, y_i)
$$

这一设计解决了单点生成在 OOD 区域的失效问题：邻域内的方向 $\mathbf{v}_i$ 通常位于模型训练充分、性能稳定的区域，生成的候选池平均质量更高。通过“邻域生成 + 目标选择”的解耦，RPS 利用了模型在已知区域的鲁棒性，规避了在未知区域直接外推的风险。

### 理论保证：邻域生成的优越性

RPS 的有效性依赖于两个假设：一是 OOD 性能退化，即邻域内方向的期望得分高于目标方向；二是局部一致性，即小角度扰动下，基于 $\mathbf{v}_i$ 生成的响应在 $\mathbf{v}_{target}$ 下的评分与其在 $\mathbf{v}_i$ 下的评分高度相关。在此条件下，定理 1 证明 RPS 的期望最优得分严格高于基线（从 $\mathbf{v}_{target}$ 重复采样 $k$ 次并选优）：

$$
\mathbb{E}[\max(S_{RPS})] > \mathbb{E}[\max(S_{Baseline})]
$$

该不等式表明，邻域采样不仅增加了候选多样性，更通过利用“更可靠”的生成方向，提升了候选池的整体质量上限。这一理论框架将 RPS 从启发式技巧提升为具有严格数学基础的鲁棒性增强策略，其核心在于将“鲁棒性”定义为对生成源分布的优化，而非对生成结果的直接修正。

## 实验评估

实验在 DPA、DPO 和 SFT 三种训练范式下，使用 UltraFeedback、HelpSteer 和 HelpSteer2 数据集验证 RPS 的有效性。基线为“单方向基线”，即在相同计算预算下，从目标偏好 $\mathbf{v}_{target}$ 重复采样 $k=5$ 次并选优。该基线覆盖了推理时对齐中常见的“多次采样”策略，但未对比训练时 DRO 方法或 Token 级引导方法，限制了与训练时鲁棒性方案的直接量化比较。

| 模型 | 数据集 | RPS 平均胜率 (%) | 基线胜率 (%) | 提升幅度 |
| :--- | :--- | :--- | :--- | :--- |
| DPA | UltraFeedback | 58.7 ± 6.1 | 50.0 | +8.7 |
| DPA | HelpSteer2 | 59.7 ± 7.8 | 50.0 | +9.7 |
| DPO | UltraFeedback | 52.1 ± 1.1 | 50.0 | +2.1 |
| SFT | HelpSteer2 | 67.3 ± 11.9 | 50.0 | +17.3 |

RPS 在所有模型-数据集组合上均超过 50% 胜率，其中 SFT 模型在 HelpSteer2 上提升最大（+17.3%），表明未对齐模型在 OOD 偏好下更依赖邻域共识。在 OOD 方向（如 45° 偏离）上，DPA 模型的胜率从 53.4% 升至 69.1%，验证了邻域采样在分布外区域的鲁棒性增益。

消融实验显示，邻域角度 $\theta_{max}$ 的选择至关重要。$\theta_{max}=30^\circ$ 时性能最佳，更小角度导致多样性不足，更大角度则引入语义过远的方向，破坏局部一致性假设。这一发现揭示了 RPS 对超参数的敏感性，其有效性依赖于奖励景观在局部尺度上的平滑性。

评估边界方面，实验仅覆盖 2D 偏好空间，未验证高维（如 HHH 多目标）场景下的可扩展性。奖励模型（RewardModel-Mistral-7B-for-DPA-v1）在 OOD 区域的校准性假设未经独立验证，若奖励模型在稀疏区域评分失真，RPS 的选择机制可能失效。代码已开源，但 GPU 资源需求未详细报告，大规模部署的计算成本需进一步评估。

## 关联研究分析

从问题动机看，RPS 与训练时 DRO 方法（如 Xu et al., 2025）形成互补而非替代关系。DRO 通过修改损失函数增强模型对分布偏移的韧性，但需重训且难以覆盖全谱系偏好；RPS 则在推理时通过几何采样规避 OOD 风险，无需修改权重。两者的差异根源在于对“鲁棒性”的定义：DRO 追求参数层面的分布不变性，RPS 追求生成层面的候选池质量。这种差异暗示，在偏好空间高度非凸或奖励景观不连续的场景下，训练时 DRO 可能更优，而 RPS 在偏好空间局部平滑的前提下更具效率优势。

从方法设计看，RPS 与 Token 级引导（如 Li et al., 2025）代表了推理时对齐的两种范式。Token 级引导通过干预生成过程逐步修正输出，依赖模型内部状态的精细控制；RPS 则完全在偏好向量空间操作，通过“生成-选择”解耦实现鲁棒性。RPS 的优势在于黑盒性，无需访问模型内部激活或 Logit，适用于 API 调用等封闭场景。然而，这种黑盒性也意味着 RPS 无法利用模型内部的语义结构信息，其性能上限受限于奖励模型的评分质量。当偏好维度增加时，邻域采样的组合爆炸问题可能使 RPS 的计算成本急剧上升，而 Token 级引导可通过梯度信息更高效地导航偏好空间。

## 总结

本文针对偏好覆盖缺口导致的 OOD 性能退化问题，提出免训练的 RPS 方法，通过方向邻域共识机制将单点生成转化为局部集合优化。实验证明，RPS 在 2D 偏好空间下，SFT 模型于 HelpSteer2 上胜率提升至 67.3%，DPA 模型在 45° OOD 方向上胜率达 69.1%。其边界在于：理论保证依赖奖励模型在 OOD 区域的局部平滑性假设，且实验仅覆盖 2D 空间，未验证高维多目标场景下的可扩展性。当偏好维度扩展至 HHH 等多目标空间时，邻域采样的组合复杂度与奖励模型校准性之间的平衡，是否仍能保证 RPS 的鲁棒性增益，论文未给出回答。
