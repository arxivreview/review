# ICLR2026最新论文 ｜ADAPTIVE CONCEPT DISCOVERY FOR - INTERPRETABLE FEW SHOT TEXT CLASSIFICATION ｜结构化概念瓶颈模型

研究机构：香港科技大学

作者：Lifang ZHENG、Hanmo Liu、Kani Chen

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_72709274)

> 少样本文本分类面临数据稀疏与模型黑盒的双重困境，传统概念瓶颈模型（CBM）因需训练预测层而无法在极少样本下泛化，而大语言模型（LLM）虽具强推理能力却缺乏可审计性。StructCBM 通过构建原型-判别双层概念架构，将预测过程解耦为基于嵌入相似度的两阶段匹配，并引入错误驱动的概念精炼闭环，实现了无需 LLM 参与的推理阶段。该方法在 10-shot 设定下性能逼近黑盒 LLM，但其概念库的静态特性与类别扩展时的二次方复杂度，限制了其在大规模动态场景下的适用性。

## 研究背景

当分类任务仅拥有每类 10 个标注样本时，传统监督学习无法拟合可靠的决策边界，这构成了少样本学习（Few-Shot Learning, FSL）的核心约束。为在数据稀缺下保持可解释性，概念瓶颈模型（Concept Bottleneck Model, CBM）被提出，其核心机制是强制模型预测必须经过一层人类可理解的概念中间层，从而将黑盒决策转化为白盒逻辑。然而，标准 CBM 架构依赖于一个从概念向量到标签的线性预测层，该层在少样本条件下因参数远多于样本量而严重过拟合，导致模型失效。

现有 LLM 增强 CBM 路线存在明显的效率与性能权衡。迭代式方法如 TBM 和 BC-LLM 虽能通过 LLM 动态生成概念，但推理阶段仍需调用 LLM，导致高昂的 API 成本与延迟；而 CB-LLM 等高效推理方法虽移除了推理时的 LLM 依赖，却要求大规模数据集来训练嵌入匹配模型，与少样本前提相悖。此外，现有方法多将文本-概念相似度视为固定的监督目标，缺乏对概念库本身的迭代优化机制，导致概念质量受限于初始 LLM 生成的噪声。StructCBM 的切入点在于彻底移除预测层训练，利用 LLM 的世界知识建立概念与标签的显式映射，并通过“生成-预测-精炼”闭环在离线阶段优化概念库，从而在保持推理高效性的同时解决少样本下的概念泛化问题。

## 核心方法

### 方法参照系

标准 CBM 流程包含概念提取、概念-标签预测层训练及最终分类三个步骤，其核心假设是存在一个可学习的线性映射 $g: \mathbb{R}^{|C|} \to \mathbb{R}^{|Y|}$。StructCBM 的关键差异在于摒弃了 $g$ 的训练，转而利用 LLM 的先验知识建立概念与标签的一对一或一对多静态映射，将预测负担完全转移至概念表示函数 $f(\cdot)$ 的优化上，从而适应少样本场景。

### 原型-判别双层概念架构

针对单一扁平概念库难以同时满足召回率与精确率的问题，StructCBM 设计了双层概念结构。第一层为原型概念集 $C_p$，旨在通过捕捉类别共性实现高召回，其支持分数 $s_p(x)$ 定义为输入 $x$ 与该类别下 Top-$m$ 最相关原型概念嵌入余弦相似度的均值：

$$ s_p(x) = \frac{1}{m} \sum_{c \in \text{top-}m(C_p^{[i]}, x)} \cos(e(x), e(c)) $$

该公式通过聚合最具代表性的概念特征，筛选出包含真实标签的候选集 $Y_k$。第二层为判别概念集 $C_d$，旨在通过细粒度对比证据实现高精确率，其相对判别分数 $s_{d}^{[i,j]}(x)$ 量化了支持类别 $y_i$ 而非混淆类别 $y_j$ 的净证据：

$$ s_{d}^{[i,j]}(x) = \sum_{c \in C_d^{[i,j]}} \cos(e(x), e(c)) $$

最终预测分数 $s_i(x)$ 由原型分数与判别分数加权组合，其中 $\alpha$ 为平衡超参数。这一设计解决了单一概念库在模糊类别边界上既无法准确召回又无法有效区分的问题，通过粗到细的决策流程提升了少样本下的分类鲁棒性。

### 错误驱动的概念精炼闭环

为克服 LLM 初始生成概念的质量波动，StructCBM 引入了基于分类错误的离线精炼机制。当预测模块产生误分类时，系统区分召回错误与排序错误，并触发语义或逻辑调整。对于召回错误，算法通过重写原型概念描述，使其与正样本集的平均相似度最大化，同时保持对原错误样本的排斥；对于排序错误，则重写判别概念描述以最小化其与错误样本的相似度。该过程受正则化约束，即更新后的概念必须维持或提升其与正确匹配样本的平均相似度，防止概念漂移。这一闭环机制将预测误差转化为概念库优化的信号，实现了概念质量的迭代提升，弥补了少样本数据不足以直接监督概念表示的缺陷。

## 实验评估

StructCBM 在 AGNews、SST2、MedAbs 和 FinaQuery 四个数据集的 10-shot 设定下进行评估，基线涵盖黑盒 LLM（DeepSeek）及白盒 CBM（TBM, CB-LLM, C3M, SparseCBM）。实验结果显示，StructCBM 在白盒模型中表现最优，且在 AGNews 和 MedAbs 上性能接近甚至超越黑盒 LLM，但在语义密度较低的 SST2 和 FinaQuery 上仍存在差距。

| 模型 | SST2 Acc | AGNews Acc | MedAbs Acc | FinaQuery Acc |
| :--- | :--- | :--- | :--- | :--- |
| DeepSeek-ICL | 0.6284 | 0.8359 | 0.6395 | 0.8499 |
| TBM | 0.4526 | 0.6326 | 0.3521 | 0.5392 |
| CB-LLM | 0.2490 | 0.6834 | 0.3465 | 0.5568 |
| StructCBM | 0.8390 | 0.8545 | 0.6070 | 0.7742 |

消融实验揭示了双层架构与精炼机制的必要性。仅使用原型概念（$C_p$）时，SST2 准确率为 0.7507，加入判别概念（$C_d$）后提升至 0.8029，验证了细粒度边界分析对消除歧义的作用。引入无约束精炼（Refine）后，SST2 准确率反而下降至 0.7677，表明在二分类任务中过度优化导致过拟合；加入正则化约束（Reg.）后，准确率恢复至 0.8127，证明正则化对防止概念漂移的关键作用。最后，嵌入模型微调（Train）进一步将 SST2 准确率提升至 0.8390，表明对齐表示空间能显著改善匹配精度。

评估边界方面，论文未报告计算效率的具体指标（如推理延迟），仅定性指出推理阶段无需 LLM 调用。代码已开源，但超参数 $\alpha$ 的敏感性分析仅展示了单一值 0.75 下的结果，缺乏跨数据集的自适应策略讨论。此外，实验未包含与最新归因方法（如 SHAP）的对比，无法直接量化其解释忠实性相对于后验方法的提升幅度。

## 关联研究分析

从问题动机看，StructCBM 与 CB-LLM（Sun et al., 2025）同属高效推理 CBM 路线，但两者对数据量的假设截然不同。CB-LLM 依赖大规模数据训练嵌入模型以匹配概念，而 StructCBM 通过 LLM 生成概念并利用少样本数据微调嵌入，解决了数据稀缺下的泛化问题。这一差异源于 StructCBM 将概念生成与预测解耦，利用 LLM 的先验知识弥补数据不足，而 CB-LLM 仍依赖数据驱动的学习过程。

从方法设计看，StructCBM 与 TBM（Ludan et al., 2024）均利用分类错误优化概念，但 TBM 在推理阶段实时调用 LLM 生成新概念，导致高延迟；StructCBM 则将精炼过程移至离线阶段，推理时仅使用静态概念库。这一设计取舍牺牲了概念库的动态适应性，换取了推理效率。对于类别数量极大（$|Y| \gg 10$）的任务，StructCBM 的判别概念生成复杂度为 $O(|Y|^2)$，而 TBM 的在线生成可能更具扩展性，但论文未对此进行量化对比，这一盲区限制了其在大规模分类任务中的应用潜力。

## 总结

StructCBM 旨在解决少样本文本分类中可解释性与推理效率的矛盾，通过移除预测层训练并引入双层概念架构，利用 LLM 先验知识建立概念-标签映射，实现了无需 LLM 参与的高效推理。实验表明，该方法在 10-shot 设定下 SST2 准确率达 0.8390，AGNews 达 0.8545，性能逼近黑盒 LLM 且显著优于现有白盒 CBM。然而，其判别概念的二次方复杂度与静态概念库特性，限制了其在大规模类别及动态概念变化场景下的适用性。当类别数量增加至数百时，判别概念生成的计算开销是否成为主要瓶颈，论文未给出回答。
