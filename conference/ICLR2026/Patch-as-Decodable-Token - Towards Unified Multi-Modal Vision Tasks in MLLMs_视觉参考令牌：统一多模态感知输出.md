# ICLR2026最新论文 ｜Patch-as-Decodable-Token: Towards Unified Multi-Modal Vision Tasks in MLLMs ｜视觉参考令牌：统一多模态感知输出

研究机构：华南理工大学、新加坡南洋理工大学

作者：Yongyi Su、Haojie Zhang、Shijie Li 等 14 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.01954)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.01954)

> 多模态大语言模型（MLLMs）在细粒度视觉感知任务中面临输出表征的语义割裂困境：将检测框序列化为文本坐标虽兼容自回归架构，却导致格式混乱、数值离散化断裂及空间-语义对齐失效。现有方案依赖全局离散码本或纯文本坐标，前者存在相似物体混淆风险，后者缺乏视觉语义锚点。本文提出Patch-as-Decodable Token (PaDT)范式，通过动态嵌入查询图像的视觉块特征作为可解码令牌，使LLM直接生成视觉引用而非文本坐标。该设计在3B参数规模下显著超越78B基线模型，但其性能增益是否完全归因于架构改进而非数据增强，仍需进一步剥离验证。

## 研究背景

当MLLMs处理指代表达理解任务时，模型需将自然语言描述映射到图像特定区域。传统方法将边界框坐标 $[x_1, y_1, x_2, y_2]$ 序列化为文本字符串输出，这种“视觉作为文本”的范式源于LLM输出空间的文本约束。然而，坐标值被离散化为独立字符令牌（如“489”→“4,8,9”），破坏了数值连续性；更关键的是，纯数字坐标缺乏视觉语义信息，导致模型在密集预测任务中产生重复或幻觉。这一失效根源在于文本令牌与视觉块特征在表征空间中的语义鸿沟，使得模型无法建立语言描述与图像区域间的细粒度对应关系。

MLLMs在通用推理上取得进展，但细粒度感知任务（检测、分割）仍受限于视觉编码器固定网格对局部细节的模糊化。主流路线分为两类：一类通过自适应分块或强化学习增强空间分辨率，但输出仍为文本坐标；另一类引入离散视觉令牌化，如ClawMachine使用全局码本将图像块映射为视觉词汇，但固定码本导致相似物体映射歧义，且码本规模巨大增加计算开销。本文切入点在于摒弃全局码本，直接复用查询图像的视觉块嵌入作为动态令牌，使每个视觉引用令牌（Visual Reference Token, VRT）在每次前向传播中唯一对应图像特定区域，从而在LLM特征空间内实现语义-空间对齐。

## 核心方法

### 方法参照系

标准MLLM流程为：视觉编码器提取块特征→投影层对齐维度→与文本嵌入拼接→LLM自回归生成文本输出。本文问题与该通用流程的关键差异在于：输出侧需生成结构化视觉目标（框/掩码），而非纯文本。现有方案将视觉目标序列化为文本坐标，本文则扩展LLM输出空间以直接生成视觉引用令牌。

### 动态多模态码本扩展

设计动机：全局码本方法（如ClawMachine）将固定数据集级码本插入LLM嵌入表，导致两个失效：(1) 码本包含大量与当前查询图像无关的令牌，增加预测噪声；(2) 相似视觉块可能映射到同一码本令牌，造成物体混淆。本文创新在于动态码本扩展：每次前向传播仅将当前查询图像的视觉块嵌入 $F_{patch} \in \mathbb{R}^{N' \times d}$ 投影为视觉参考原型 $\mathcal{P}_{vrt} = f_p(F_{patch})$，并动态扩展LLM嵌入表。公式表达为：

$$
\mathcal{C}_{vrt} = \{ \mathcal{P}_{vrt}^{(i)} \mid i=1,...,N' \}
$$

其中 $\mathcal{C}_{vrt}$ 为当前图像专属的视觉令牌集合。每个 $\mathcal{P}_{vrt}^{(i)}$ 唯一对应图像块 $P_i$，保留空间位置信息。此设计使LLM在输出时仅从当前图像相关令牌中选择，避免全局码本的歧义与冗余，实现细粒度空间定位。

### 统一多模态输出解码

设计动机：LLM生成的VRTs需转换为结构化视觉输出（框/掩码），但不同任务输出格式异构。本文创新在于轻量级PaDT解码器：给定LLM输出的VRT子集 $\{v_{r_1}, ..., v_{r_k}\}$，解码器通过索引选择获取对应块特征，经双向注意力块与上采样生成掩码，或通过坐标回归生成边界框。公式表达为：

$$
\hat{y}_{vis} = \text{Decoder}(\{ \mathcal{P}_{vrt}^{(r_j)} \}_{j=1}^k, \text{task\_type})
$$

其中 $\hat{y}_{vis}$ 为预测的框或掩码。此设计将视觉输出解耦为“令牌预测”与“结构解码”两阶段，使LLM专注于语义-空间对齐，解码器处理几何转换，提升输出一致性与解析鲁棒性。

## 实验评估

实验在RefCOCO/+/g（指代表达理解/分割）、COCO2017（开放词汇检测）及自建RIC基准（指代表达描述）上进行。基线覆盖模块化MLLMs（Qwen2.5-VL, InternVL3）、视觉-语言检测器（Grounding DINO）及强化学习方法（VLM-R1, Seg-R1），但缺失最新原生统一模型（如MANZANO, NEO）对比。主结果显示，PaDT Pro (3B)在RefCOCO val上达96.0准确率，超越78B InternVL3的95.4；COCO检测mAP达38.2，较Qwen2.5-VL (3B)的13.7提升24.5点。

| 任务 | 模型 | 参数量 | RefCOCO val | COCO mAP |
| :--- | :--- | :--- | :--- | :--- |
| REC | InternVL3 | 78B | 95.4 | - |
| REC | PaDT Pro | 3B | 96.0 | - |
| Det | Qwen2.5-VL | 3B | - | 13.7 |
| Det | PaDT Pro | 3B | - | 38.2 |

消融实验表明，移除VRTs（仅预测坐标）导致RefCOCO val准确率从93.2降至88.7，证明VRTs对细粒度定位的关键作用。随机选择VRTs策略较全量选择提升1.5点，验证了稀疏监督的有效性。评估边界方面，论文未报告置信区间，且COCO检测基线较弱（Qwen2.5-VL 13.7），可能高估相对提升幅度；代码已开源，但超参数细节未在正文完整披露。

## 关联研究分析

从问题动机看，PaDT与ClawMachine均致力于解决MLLMs视觉输出表征问题，但根源差异在于码本策略。ClawMachine依赖预训练离散视觉分词器构建全局码本，其失效源于码本与查询图像的静态不匹配；PaDT则通过动态嵌入复用当前图像特征，将码本规模从数据集级降至图像级，直接消除相似物体混淆风险。这一差异并非任务特性决定，而是对“视觉令牌应包含何种语义”的不同假设：ClawMachine假设视觉语义可全局离散化，PaDT假设视觉语义需上下文动态绑定。

从方法设计看，PaDT与MANZANO同属混合令牌化路线，但目标不同。MANZANO聚焦图像生成与理解协同，其混合分词器整合离散与连续表示以平衡保真度与语义；PaDT仅针对结构化视觉输出，不涉及像素级生成，因此无需处理生成-理解梯度冲突。PaDT的轻量解码器设计使其计算开销低于MANZANO，但牺牲了生成能力。查询侧增强在数据充足时是否仍有增益，论文未给出回答，因实验仅在固定数据集上验证。

## 总结

本文要解决的核心矛盾是MLLMs文本输出空间与结构化视觉目标间的语义-空间割裂。现有方法通过全局码本或纯文本坐标处理此问题，但前者存在物体混淆，后者缺乏视觉锚点。PaDT抓住“视觉块特征本身即含语义”这一被忽略的点，通过动态嵌入查询图像块特征作为可解码令牌，使LLM在输出空间直接生成视觉引用。实验证明3B模型在RefCOCO达96.0准确率、COCO mAP达38.2，超越78B基线。本文边界在于未与最新原生统一模型对比，且COCO检测基线较弱，可能高估相对提升。当支持集增大到5-shot时，动态码本的边际收益是否递减，论文未给出回答。
