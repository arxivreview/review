# ICLR2026最新论文 ｜STATION2RADAR: QUERY CONDITIONED GAUSSIAN SPLATTING FOR PRECIPITATION FIELD ｜查询条件高斯泼溅降水场生成

研究机构：韩国科学技术院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_8109388)

> 降水预报长期受限于雷达覆盖的地理局限与分辨率固定，而卫星与地面站数据虽可互补，却难以直接生成高分辨率连续降水场。现有纯卫星模型存在强度偏差，传统插值方法则导致边界模糊，QCGS 通过融合卫星影像与自动气象站观测，利用可学习的高斯泼溅机制实现无雷达条件下的分辨率无关降水场重建。该方法在 2km 训练下渲染至 0.5km 时，RMSE 降至 1.23，CSI 达 0.74，显著优于纯卫星产品与经典插值，但其单帧重建特性未验证时序演变能力，且依赖稀疏地面站锚点，跨区域泛化能力存疑。

## 研究背景

降水场重建面临数据异构性与分辨率失配的困境。卫星红外亮温（BT）影像提供密集空间覆盖，但与降水强度仅存在间接相关；自动气象站（AWS）提供精确的地面点观测，却稀疏且存在缺失。传统目标分析采用高斯加权插值，将点观测映射至网格，但固定各向同性核导致降水边界模糊，且对站点密度敏感。隐式神经表示（INR）通过坐标到值的连续映射实现分辨率无关渲染，但密集查询所有坐标导致计算开销随分辨率线性增长，难以高效处理局部化降水结构。

主流降水预报路线依赖雷达输入，从 ConvLSTM 到扩散模型，均在雷达原生分辨率上优化，无法突破雷达网络的地域限制与固定分辨率瓶颈。纯卫星转雷达方法（如 NPM）虽摆脱雷达依赖，但缺乏地面真值锚定，强度偏差显著。QCGS 的切入点在于将高斯加权插值与高斯泼溅（GS）建立表示等价性：传统插值是 GS 在固定各向同性核下的特例，而 GS 允许学习各向异性协方差与自适应振幅，结合 INR 的条件化参数预测，可在仅渲染降水支持区域的前提下，实现任意分辨率的连续场生成。

## 核心方法

### 方法参照系

本文问题属于多源异构数据融合下的连续场重建，与标准图像到图像翻译（如 Sat2Radar）的关键差异在于：输入包含密集图像与不规则点集，输出需在任意查询位置定义，而非固定网格。标准流程假设输出分辨率与训练网格一致，而 QCGS 要求模型在 2km 训练后能渲染至 0.5km 或连续坐标，兼具超分辨率与点云融合特性。

### 雷达点提议网络与 AWS-卫星融合

设计动机：纯卫星特征缺乏局部强度锚定，纯 AWS 数据稀疏且含噪，需联合建模以产生可靠的降水支持位置。该阶段采用 ConvNeXt U-Net 编码卫星 BT 影像，通过 GAT 提取 AWS 观测的鲁棒表示 $z^{[t]} = f_x(X^{[t]}; \theta_x)$，并在解码器中通过交叉注意力融合卫星密集特征与 AWS 稀疏锚点，生成粗粒度替代场 $\hat{R}^{[t]}$。此步骤将 AWS 的地面真值硬约束嵌入特征空间，校正纯卫星模型的强度偏差，为后续高斯参数估计提供可靠的降水支持区域提议。

### 降雨感知采样与 INR 高斯参数估计

设计动机：均匀采样浪费计算于无雨区域，且无法优先捕捉极端降水；传统 GS 直接拟合高斯基元，缺乏跨场景泛化能力。QCGS 采用混合采样策略，构造凸组合概率 $P_{sample}(\mathbf{x}) = \lambda_1 P_{edge}(\mathbf{x}) + \lambda_2 P_{uniform}(\mathbf{x}) + \lambda_3 P_{heavy}(\mathbf{x})$，其中边缘项强调边界、均匀项保证覆盖、强雨项通过温度参数 $T$ 聚焦极端区域。采样点 $\mu^{[n]}$ 输入五层 MLP INR，条件化于卫星中间特征，预测高斯参数 $\{(\sigma_x^{[n]}, \sigma_y^{[n]}, \rho^{[n]}), \alpha^{[n]}\}$。在 AWS 非零降雨站点，直接设定 $\alpha^{[n]} = s^{[n]}$，将地面观测作为硬约束锚定振幅。最终渲染值通过选择性高斯合成计算：

$$
R(\mathbf{x}) = \sum_{n=1}^{N} \alpha^{[n]} \exp\left(-\frac{1}{2} (\mathbf{x} - \mu^{[n]})^T \Sigma^{[n]-1} (\mathbf{x} - \mu^{[n]})\right)
$$

该公式仅对采样点求和，避免全图计算，实现分辨率无关的高效渲染。

## 实验评估

实验在 KMA 雷达（0.5km GT）、GK2A 卫星（2km）与 AWS 数据上进行，训练集为 2019-2022 年小时数据，测试集为 2023 年。基线覆盖经典插值（Barnes、Kriging、3DMQ）、运营产品（IMERG、GSMaP、MSWEP）与数据驱动模型（Pix2PixHD、NPM、BBDM），但缺失基于雷达外推的 SOTA 模型（如 SimVP、STLDM），因本文任务为无雷达场重建，无法直接对比。

QCGS 在 2km 训练下渲染至 0.5km 时，RMSE 1.23 优于 0.5km 训练的 BBDM（1.68）与 NPM（1.95），CSI 0.74 显著高于 IMERG（0.50）与 Kriging（0.50），验证了 AWS 锚定与 GS 分辨率无关渲染的有效性。

消融显示，AWS 融合将 CSI 从 0.62 提升至 0.73，GS 进一步增至 0.76，证明地面锚定与选择性渲染的协同作用。采样策略中，混合策略（0.76）优于单一梯度（0.71）或强雨（0.70）采样，表明边界、背景与极端区域需联合覆盖。查询点数 K 从 1000 增至 6000 时 CSI 从 0.69 升至 0.76，K=9000 仅微增至 0.77，边际收益递减，K=6000 为效率-精度最优平衡点。

评估指标包含 RMSE、LPIPS、CSI、FSS、CC 与 Bias，覆盖误差、感知相似度与分类性能，但未报告计算效率（FLOPs、推理延迟）。实验在 8×NVIDIA H200 GPU 上进行，超参数（Adam lr=1e-4, batch=16, epochs=100）已披露，但代码未公开，可复现性受限。评估仅针对单帧场重建，未验证时序一致性或长时程预报能力。

## 关联研究分析

从问题动机看，QCGS 与 Sat2Radar（NPM）同属无雷达降水生成，但 NPM 依赖纯卫星输入，缺乏地面真值锚定，导致强度偏差（NPM RMSE 1.95 vs QCGS 1.23）。QCGS 引入 AWS 观测作为硬约束，将 $\alpha$ 直接设定为观测值，解决了纯卫星模型的系统性偏差问题。这一差异源于任务特性：NPM 假设卫星特征足以推断降水强度，而 QCGS 承认卫星的间接性，需地面站校正。然而，AWS 的稀疏性限制了 QCGS 在站点稀少区域的适用性，NPM 虽精度较低，但具备全球部署潜力，二者在精度-覆盖度上存在根本权衡。

从方法设计看，QCGS 借鉴 3D Gaussian Splatting 的渲染机制，但将其简化为 2D 并引入 INR 条件化。与 GaussianImage 等图像压缩方法不同，QCGS 的高斯参数由卫星-AWS 上下文预测，而非直接拟合图像内容，实现了跨场景泛化。与 INR 超分辨率方法（如 Chen et al., 2021）相比，QCGS 采用选择性渲染，仅查询降水支持区域，避免了 INR 密集查询的计算瓶颈。这一设计源于降水场的稀疏性：大部分区域无雨，全图渲染浪费计算。但 QCGS 的单帧特性未利用时序信息，而 ConvLSTM 等时序模型虽依赖雷达，但能捕捉对流演变，QCGS 是否可通过嵌入时序模块实现无雷达动态预报，论文未探索。

## 总结

QCGS 解决的核心矛盾是无雷达条件下高分辨率降水场重建与数据异构性、分辨率失配之间的张力。现有纯卫星模型缺乏强度锚定，传统插值导致边界模糊，QCGS 通过建立高斯加权插值与 GS 的表示等价性，结合 INR 条件化参数预测，实现了分辨率无关的选择性渲染。实验证明，2km 训练下渲染至 0.5km 时，RMSE 1.23 与 CSI 0.74 显著优于纯卫星产品与经典插值，验证了 AWS 锚定与 GS 机制的有效性。然而，该方法的边界在于依赖稀疏 AWS 观测，站点密度不足时性能可能退化，且单帧重建未验证时序演变能力。当 AWS 站点密度降低至每 100km² 少于 1 个时，QCGS 的强度锚定能力是否仍能维持 CSI 0.70 以上，论文未给出回答。
