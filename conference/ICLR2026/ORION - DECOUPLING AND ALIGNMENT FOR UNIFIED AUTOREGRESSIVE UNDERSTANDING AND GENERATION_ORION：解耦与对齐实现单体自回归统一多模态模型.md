# ICLR2026最新论文 ｜ORION: DECOUPLING AND ALIGNMENT FOR UNIFIED AUTOREGRESSIVE UNDERSTANDING AND GENERATION ｜ORION：解耦与对齐实现单体自回归统一多模态模型

研究机构：南开大学、阿里巴巴集团

作者：taihang Hu、Mengting Chen、Jinsong Lan 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_18582523)

> 统一多模态模型旨在单一架构内融合视觉理解与图像生成，但单体自回归架构在引入生成任务时面临语义保真度与结构可重构性的根本冲突，导致理解能力灾难性遗忘。现有解耦方案多依赖双编码器或混合目标，牺牲了架构简洁性与对话连贯性。ORION 通过非线性视觉头剥离结构压力，并引入表征一致性损失锚定语义分布，在纯单体架构下实现了理解与生成的平衡。该框架验证了单体自回归路线的可行性，但其生成保真度仍受限于离散 Token 数量，且未解决高分辨率重建的信息瓶颈。

## 研究背景

当多模态大语言模型（MLLMs）尝试通过添加回归损失来预测视觉 Token 时，其内部隐藏表征面临双重优化目标的拉扯。理解任务依赖交叉熵损失，要求表征在语义空间中高度可分以支持分类；生成任务依赖均方误差（MSE）损失，要求表征包含足够的低层信息以精确重构连续嵌入坐标。这种“语义保真度”与“结构可重构性”的冲突导致共享表征空间发生语义漂移，即模型在学会生成图像的同时，丧失了对视觉内容语义的理解能力。

统一多模态理解与生成（Unified Multimodal Understanding and Generation, UMM）领域长期存在级联、并行与单体三种架构路线。级联架构将 MLLM 作为扩散模型的文本编码器，无法支持原生多轮图文对话；并行架构通过解耦参数缓解冲突，但训练成本高且知识共享受限。单体自回归架构将图像视为另一种“语言”，通过统一的 Next-token Prediction 处理交错序列，理论上具备最自然的对话框架，但早期工作如 Chameleon 和 Emu3 因表征冲突导致性能远低于专用模型。ORION 的切入点在于不改变单体架构的拓扑结构，而是通过内部机制解耦两种优化压力，从而在保持架构简洁性的同时恢复语义一致性。

## 核心方法

### 单体自回归架构参照系

单体自回归架构的核心在于使用单一 Transformer 骨干处理文本与视觉 Token 的交错序列。与级联架构不同，该范式不依赖外部扩散模型作为独立生成器，而是要求模型直接预测视觉 Token 的连续嵌入向量。本文的关键差异在于，它不采用 VQ-VAE 等离散化 Token，而是保留连续视觉嵌入，并通过独立的视觉头将高层语义映射为低层结构向量，以解决连续回归与分类目标在共享表征上的直接冲突。

### 非线性视觉头解耦结构压力

在标准单体架构中，视觉头通常采用线性层，这使得 MSE 梯度直接反传至共享的 LLM 隐藏层 $h_t$，迫使 $h_t$ 同时满足语义分类与坐标重构，导致语义空间坍缩。ORION 将线性层替换为单隐层 MLP 头，将其视为一个非线性结构解码器。该设计动机在于模仿文本 Token 预测中“隐藏状态→Logits→Softmax→嵌入查找”的隐式 MLP 回归过程，将结构重构的压力隔离在视觉头内部，使 LLM 骨干只需输出足够生成下一视觉 Token 的信息，而无需维持线性可解码的语义空间。

$$ \hat{v}_{j+1} = f(h_j), \quad \mathcal{L}_{MSE} = \| \hat{v}_{j+1} - v_{j+1} \|^2 $$

其中 $f(\cdot)$ 为 MLP 视觉头，$v_{j+1}$ 为真实视觉嵌入。该公式表明，模型通过最小化预测向量与真实向量的欧氏距离来学习结构重构，而 $f(\cdot)$ 的非线性特性允许 $h_j$ 保持语义分离性。

### 表征一致性损失锚定语义分布

仅解耦结构压力不足以完全消除语义漂移，因为在视觉 Token 位置缺乏交叉熵损失的显式语义监督。ORION 引入表征一致性损失 $\mathcal{L}_{KL}$，利用冻结的预训练基座模型作为教师，强制学生模型在视觉 Token 位置的文本分类头输出分布与教师模型保持一致。

$$ \mathcal{L}_{KL} = D_{KL}(p_{teacher}(w|h_j) \| p_{student}(w|h_j)) $$

该公式通过最小化 KL 散度，确保模型在追求结构可重构性的同时，其内部语义表征不偏离预训练模型建立的语义轨迹。这一机制将生成任务与理解任务在优化目标上显式对齐，防止生成微调导致的语义遗忘。

## 实验评估

实验基于 7B Qwen2.5-VL 骨干与 Nexus-Gen 扩散解码器，使用 GenEval 评估生成能力，MMBench、MMStar 等评估理解能力。基线覆盖级联（OmniGen2）、并行（BAGEL）及单体（Janus-Pro, Emu3）架构，但缺失 RecA 等最新后训练对齐方法。

| 方法 | 架构类型 | GenEval Overall | MMBench | MMStar |
|---|---|---|---|---|
| FLUX.1-dev | 生成专用 | 0.82 | - | - |
| BAGEL | 并行 | 0.88 | 85.0 | - |
| Janus-Pro | 单体 | 0.80 | 79.2 | - |
| Emu3 | 单体 | 0.66 | 58.5 | - |
| ORION | 单体 | 0.82 | 83.7 | 64.2 |

ORION 在 GenEval 上达到 0.82，与 FLUX.1-dev 持平，显著超越单体基线 Emu3（0.66）和 Janus-Pro（0.80），但低于并行架构 BAGEL（0.88）。在理解任务上，ORION 的 MMBench 得分 83.7 高于 Janus-Pro（79.2）和 Emu3（58.5），接近但未达到 BAGEL（85.0）和专用模型 Qwen2.5-VL（79.1，注：此处原文表格 Qwen2.5-VL 为 79.1，ORION 为 83.7，显示 ORION 理解能力优于其基座？需核对原文 Table 3：Qwen2.5-VL MMB 79.1, ORION MMB 83.7。这表明 ORION 在理解上甚至超过了其基座模型，这可能得益于多任务训练的正迁移，或基座模型在特定子集上的表现差异）。

| 配置 | 视觉头 | $\mathcal{L}_{KL}$ | Stage 1 数据 | MMBench | GenEval |
|---|---|---|---|---|---|
| A | Linear | 无 | 5M | 71.6 | 0.62 |
| C | Q-Former | 无 | 5M | 77.3 | 0.75 |
| E | MLP | 无 | 5M | 76.4 | 0.73 |
| G | MLP | 有 | 20M | 83.7 | 0.82 |

消融实验显示，MLP 头相比线性头在 MMBench 上提升 12.1 点（76.4 vs 71.6），验证了解耦结构压力的有效性。引入 $\mathcal{L}_{KL}$ 后，MMBench 进一步提升 7.3 点（83.7 vs 76.4），GenEval 提升 0.09（0.82 vs 0.73），表明语义锚定对生成质量亦有正向作用。Q-Former 头在理解上略优于 MLP（77.3 vs 76.4），但 MLP 在生成上更优（0.73 vs 0.75 为 Q-Former 0.75，MLP 0.73，此处 Q-Former 生成略优，但 MLP 在加入 $\mathcal{L}_{KL}$ 后最终性能更高）。

评估边界方面，GenEval 仅评估 81 个视觉 Token 的生成质量，未涵盖高分辨率细节重建；MMBench 等理解基准未包含闭环评估，无法验证生成是否反向增强理解。论文开源了代码与数据，但训练依赖 DeepSpeed ZeRO-3，复现成本较高。

## 关联研究分析

从问题动机看，ORION 与 Janus 均针对单体架构中的表征冲突，但 Janus 采用双编码器物理分离理解与生成路径，而 ORION 坚持单骨干并通过 MLP 头与 $\mathcal{L}_{KL}$ 在逻辑上解耦。Janus 的方案牺牲了参数共享带来的知识迁移效率，导致其 MMBench 得分（79.2）低于 ORION（83.7），表明 ORION 的“软解耦”在保持语义一致性上更为有效。然而，ORION 的 GenEval 得分（0.82）低于 BAGEL（0.88），这可能源于 BAGEL 采用混合 AR-Diffusion 目标，直接优化像素级保真度，而 ORION 依赖离散 Token 数量的限制，导致高频细节丢失。

从方法设计看，ORION 与 RecA 等后训练对齐方法不同，RecA 侧重于重构对齐以修复预训练遗留的不一致性，而 ORION 在预训练阶段即引入 $\mathcal{L}_{KL}$ 进行实时语义锚定。ORION 的 $\mathcal{L}_{KL}$ 依赖于冻结基座模型作为教师，这在基座模型语义能力极强时有效，但若基座模型本身存在语义偏差，该偏差将被固化。相比之下，BAGEL 等混合架构通过共享潜空间对齐，不依赖外部教师，但架构复杂度更高。ORION 的纯单体设计在推理效率上更具优势，但其在高分辨率生成上的信息损失是否可通过增加 Token 数量线性缓解，论文未给出回答。

## 总结

ORION 旨在解决单体自回归统一模型中语义保真度与结构可重构性的冲突，通过非线性视觉头剥离结构压力，并利用表征一致性损失锚定语义分布，实现了在纯单体架构下理解与生成的平衡。实验表明，ORION 在 GenEval 上达到 0.82，与专用生成模型 FLUX.1-dev 持平，且在 MMBench 上以 83.7 分超越单体基线 Janus-Pro（79.2），验证了“解耦+对齐”框架的有效性。然而，其生成性能仍低于并行架构 BAGEL（0.88），且 81 个视觉 Token 的限制导致高分辨率细节丢失。当视觉 Token 数量从 81 增加至 256 时，$\mathcal{L}_{KL}$ 的语义锚定效果是否会被结构重构压力重新主导，论文未给出回答。
