# ICLR2026最新论文 ｜PATHCHAT-SEGR1: REASONING SEGMENTATION IN PATHOLOGY VIA SO-GRPO ｜病理图像推理分割：基于SO-GRPO的自主时机决策模型

研究机构：上海交通大学

作者：Zelin Liu、Dongdong Chen、Yusong Sun 等 10 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_4654347)

> 临床病理分割面临罕见形态泛化难与染色变异鲁棒性差的双重困境，传统闭集模型失效，现有推理分割模型缺乏病理特异性且无法自主判断分割时机。本文通过引入病理专用视觉编码器与染色不变自蒸馏，并设计SO-GRPO强化学习算法实现<SEG> token的自主生成，解决了固定插入位置导致的语义上下文不足问题。该框架在零样本未见病理任务上显著优于基线，但其推理链质量评估仍依赖文本重叠指标，临床逻辑一致性有待进一步验证。

## 研究背景

病理图像分割需处理训练分布外的罕见形态与染色变异，闭集模型因缺乏开放集泛化能力而失效。推理分割通过自然语言查询引导分割，但现有模型依赖通用视觉编码器，缺乏对组织形态与染色差异的病理特异性理解。LISA等模型将<SEG> token固定插入预设位置，导致模型无法根据累积的语义上下文自主判断何时触发分割输出，在复杂推理任务中性能受限。

病理分割领域长期存在“精度-泛化-可解释性”三角约束。主流路线分为闭集分割（如nnU-Net）与基于提示的开放集分割（如SAM-Path），前者在训练分布内表现优异但无法泛化至新病理，后者虽具开放集能力但依赖密集人工点击且无法解析文本语义。推理分割范式试图通过文本查询替代人工提示，但现有方法（如LISA、MMR）在病理场景下暴露出两大瓶颈：视觉编码器对染色变异的敏感性导致特征漂移，以及强化学习训练无法优化分割触发的时序决策。PathChat-SegR1的切入点在于将病理特异性视觉表征与自主分割时机决策解耦，通过染色不变自蒸馏预训练与SO-GRPO强化学习，实现从“被动响应提示”到“主动推理分割”的范式转变。

## 核心方法

### 方法参照系

推理分割的标准流程为：视觉编码器提取特征，LLM生成包含分割标记的推理链，分割解码器生成掩码。本文的关键差异在于将<SEG> token从固定位置插入改为由LLM在推理过程中自主生成，并引入病理专用编码器替代通用视觉骨干。

### 染色不变视觉预训练

设计动机：通用视觉编码器在染色变异下特征不稳定，导致跨域泛化失败。本文对MedSAM与RuiPath编码器施加染色不变自蒸馏，通过LAB色彩空间增强生成虚拟重染色视图，迫使模型学习染色无关的形态学特征。预训练目标函数为：

$$ \mathcal{L}_{SSL} = \mathcal{L}_{MAE} + \alpha \cdot \cos(\mathbf{s}_{i,1}, \mathbf{s}_{i,2}) $$

其中 $\mathbf{s}_{i,1}, \mathbf{s}_{i,2}$ 为两个增强视图的染色模板向量，余弦距离项根据染色差异幅度加权特征不一致性，确保模型在染色变化时保持特征一致性。

### SO-GRPO强化学习

设计动机：标准GRPO对完整生成轨迹均匀分配奖励，无法识别<SEG> token生成的最优时机。SO-GRPO引入广义优势估计（GAE）进行时间步级信用分配，并设计可微分分割奖励与稀疏性奖励。GAE优势函数为：

$$ \hat{A}_{GAE}(s_t, a_t) = \sum_{l=0}^{\infty} (\gamma\lambda)^l \delta_{t+l} $$

该公式通过指数加权的时间差分残差，评估当前推理状态是否已累积足够语义上下文以触发分割。可微分奖励 $R_{soft}$ 将离散Dice指标转化为连续概率分布，使梯度能从分割质量反向传播至<SEG> token表示，实现分割性能对推理过程的直接优化。

## 实验评估

| 数据集 | 方法 | Dice |
| :--- | :--- | :--- |
| Camelyon16 | PathChat-SegR1 | 0.76 |
| Camelyon16 | MMR-7B | 0.60 |
| PMBT (Zero-shot) | PathChat-SegR1 | 0.58 |
| PMBT (Zero-shot) | MMR-7B | 0.36 |
| RD (One-shot) | PathChat-SegR1 | 0.72 |
| RD (One-shot) | MMR-7B | 0.47 |

实验覆盖8个域内基准与2个域外未见病理数据集，基线包括闭集模型（nnU-Net、MedSAM）与推理分割模型（LISA、MMR、Seg-Zero）。PathChat-SegR1在Camelyon16上达到0.76 Dice，较最强推理基线MMR-7B提升33%相对值；在零样本PMBT任务上以0.58 Dice领先MMR-7B的0.36 Dice，验证了病理专用编码器与染色不变预训练对跨域泛化的贡献。

| 消融组件 | Dice | 变化幅度 |
| :--- | :--- | :--- |
| Full Model | 0.58 | - |
| w/o RuiPath Encoder | 0.42 | -0.16 |
| w/o RL | 0.40 | -0.18 |
| w/o GAE | 0.55 | -0.03 |
| w/o Differentiable reward | 0.56 | -0.02 |

消融实验显示，移除RuiPath编码器与强化学习阶段分别导致0.16与0.18 Dice下降，证实病理特异性视觉表征与自主时机决策是性能提升的核心。GAE与可微分奖励的移除仅导致0.03与0.02 Dice下降，表明SO-GRPO的改进主要源于时序信用分配机制，而非奖励函数本身的复杂度。

评估指标以Dice为主，推理链质量采用BLEU-4与F1，但缺乏临床逻辑一致性评估。代码已开源，训练使用8块H800 GPU，LoRA秩为16，SO-GRPO收敛步数为18K。

## 关联研究分析

从问题动机看，PathChat-SegR1与LISA均基于<SEG> token机制，但LISA将token位置固定，依赖预设推理步数，而本文通过GAE实现自主时机决策。这一差异源于病理分割对语义上下文累积的敏感性：罕见病理需更长的推理链以识别细微形态特征，固定位置插入易导致上下文不足或冗余生成。LISA未探索时序优化，本文的SO-GRPO填补了这一空白，但GAE的信用分配依赖状态价值函数估计，在长推理链中可能存在方差累积问题。

从方法设计看，本文与Seg-Zero同属推理分割范式，但Seg-Zero依赖MLLM生成点提示引导SAM，而本文直接通过<SEG> token连接VLM与分割解码器。Seg-Zero的提示机制在复杂空间结构上信息损失较大，本文的端到端掩码生成避免了提示瓶颈。然而，本文的稀疏性奖励依赖规则-based空间检测（如“boundary”关键词），这种启发式方法在缺乏明确空间描述词的查询中可能失效，限制了其在非结构化临床文本中的通用性。

## 总结

PathChat-SegR1针对病理分割中罕见形态泛化难与染色变异鲁棒性差的核心矛盾，通过病理专用编码器与染色不变自蒸馏解决视觉表征漂移，通过SO-GRPO实现<SEG> token的自主时机决策。实验证明其在零样本未见病理任务上较MMR-7B提升61%相对值，验证了自主推理分割的临床适用性。然而，推理链质量评估仍依赖BLEU-4等文本重叠指标，无法直接量化诊断逻辑的正确性；稀疏性奖励的规则-based检测在缺乏空间描述词的查询中可能失效。当临床查询仅包含模糊形态描述而无明确空间定位词时，SO-GRPO的稀疏性约束是否仍能有效抑制冗余生成，论文未给出回答。
