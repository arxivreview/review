# ICLR2026最新论文 ｜APT: TOWARDS UNIVERSAL SCENE GRAPH GENERA - TION VIA PLUG IN ADAPTIVE PROMPT TUNING ｜自适应提示调优

研究机构：华中科技大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_99338991)

> 场景图生成（SGG）旨在将视觉内容转化为由对象节点和关系边组成的结构化图，其核心价值在于为视觉问答、机器人导航等高层推理任务提供可解释的语义桥梁。现有两阶段与一阶段方法虽在架构上各有优劣，但均依赖冻结的预训练语言模型嵌入作为语义先验，导致模型无法区分同一对象在不同视觉上下文中的语义角色，限制了细粒度关系推理能力。本文提出自适应提示调优（Adaptive Prompt Tuning, APT），通过轻量级可学习提示模块动态调制冻结语义特征，使其具备上下文感知能力。该方案以极低的参数开销实现了跨架构的性能提升，但其效果是否受限于底层检测器精度，以及在生成式范式下的竞争力，仍存疑。

## 研究背景

场景图生成的核心挑战在于将离散的视觉证据映射到结构化的语义空间。这一过程依赖于对象检测的精度与关系预测的语义理解。然而，传统方法普遍采用静态词嵌入（如GloVe或BERT）作为语义先验，这些嵌入在预训练阶段已固定，无法根据当前图像的视觉上下文进行动态调整。这种静态性导致模型在面对“人骑马”与“人拿手机”等具有相同主体但不同关系场景时，无法区分主体的语义角色，从而产生关系预测偏差。

主流SGG方法分为两阶段（先检测后分类）和一阶段（端到端联合预测）两类。两阶段方法如PE-Net依赖强大的检测器，但存在误差累积问题；一阶段方法如SGTR通过Transformer架构实现了联合预测，提升了效率，但其重参数骨干和密集注意力机制带来了高昂的计算成本。尽管架构范式不同，两者共享一个根本缺陷：对冻结语义表示的依赖。这种表示刚性使得模型难以捕捉关系中的细微差别和主客体间的语义不对称性。本文的切入点在于超越架构之争，聚焦于表示范式本身，提出一种通用的插件式机制，将冻结语义特征转化为动态、上下文感知的表示，从而在不修改主干网络的前提下提升SGG性能。

## 核心方法

### 方法参照系

本文问题置于通用SGG框架下，其标准流程包括对象检测、关系预测及语义特征融合。与现有方法的关键差异在于，本文不修改主干网络的检测或预测逻辑，而是引入一个独立的提示调制模块，作用于冻结的语义嵌入层，实现语义特征的动态适配。

### 统一插件提示机制

在语义特征融合环节，传统方法直接使用冻结嵌入 $e_{static}(c)$ 与视觉特征交互。本文引入可学习提示 $P(c)$ 作为条件适配器，通过聚合函数 $A(\cdot)$ 将提示序列压缩为单向量，并与冻结嵌入及视觉特征 $\phi(v)$ 经轻量级融合网络 $f_\theta$ 交互，生成自适应表示 $\tilde{e}(c)$。该设计解决了静态嵌入无法区分细粒度关系（如“站在”与“走在”）的失效问题，通过提示携带的视觉上下文信息，使语义特征能够根据当前场景动态调整，从而提升关系预测的准确性。

$$
\tilde{e}(c) = f_\theta(A(P(c)), e_{static}(c), \phi(v))
$$

该公式表明，最终表示是提示、冻结语义和视觉特征的非线性组合，仅提示和融合网络参数可学习，主干保持冻结，确保了参数效率。

### 组合泛化提示器

针对开放词汇场景，本文提出组合泛化提示器（CGP），包含关系上下文门控（RCG）、基础提示合成（BPS）和特征精炼融合（FRF）三个子模块。RCG生成角色感知的提示权重，BPS通过加权组合有限的基础提示集 $B \in \mathbb{R}^{N \times L_{ov} \times D}$ 合成针对未见类别的提示，FRF执行非线性变换以融合合成提示、原始语义和视觉特征。该机制解决了静态表示无法泛化到未见谓词组合的问题，通过从有限基础集合成无限多样的提示，实现了组合泛化。

$$
P_{syn} = \sum_{i=1}^{N} w_i B_i, \quad \tilde{e}_{ov} = FRF(P_{syn}, e_{static}, v)
$$

其中 $w_i$ 由RCG生成，BPS通过加权求和合成提示，FRF完成最终融合，使模型能够处理训练集中未见的关系三元组。

## 实验评估

实验在Visual Genome（VG）、Open Image V6和GQA上进行，主要报告VG结果。基线覆盖两阶段（PE-Net, DRM）、一阶段（SGTR, EGTR, ST-SGG）及开放词汇（SDSGG, OvSGTR）方法，但缺失最新生成式方法如SGG-R3和FlowSG。

| 方法 | PredCls R@50 | PredCls mR@50 | SGDet R@50 | SGDet mR@50 |
| :--- | :--- | :--- | :--- | :--- |
| EGTR | 54.1 | 35.7 | 27.4 | 27.4 |
| EGTR+APT | 56.4 | 37.5 | 29.7 | 29.7 |
| SGTR | 59.2 | 30.4 | 31.0 | 31.0 |
| SGTR+APT | 62.3 | 32.7 | 33.5 | 33.5 |
| SDSGG | 18.7 | 9.2 | 18.4 | 17.1 |
| SDSGG+APT | 19.5 | 10.1 | 19.4 | 18.6 |

在VG SGDet任务上，EGTR+APT的R@50为29.7，较基线EGTR的27.4提升2.3个点；在开放词汇Novel split上，SDSGG+APT的mR@50为18.6，较基线17.1提升1.5个点。

消融实验显示，仅添加关系提示（R-Prompt）对mR@K的提升显著大于仅添加检测提示（D-Prompt），表明关系提示是缓解谓词偏差的关键。在CGP模块中，BPS对Novel split mR@50的提升最大（+3.8），证实了基础提示合成在组合泛化中的核心作用。

评估指标涵盖R@K、mR@K和F@K，但缺乏对幻觉率的直接度量。代码已开源，但论文未报告置信区间，且未对比生成式范式下的性能，限制了其在开放词汇任务上的竞争力评估。

## 关联研究分析

从问题动机看，本文与Salience-SGG在缓解长尾分布上形成对比。Salience-SGG通过显式显著性估计区分高频和低频关系，而APT采用隐式语义对齐，通过提示调制动态调整特征。前者在封闭集长尾任务上更稳定，后者在开放词汇场景下泛化能力更强。这一差异源于对“关系本质”的不同理解：Salience-SGG视关系为统计共现，APT视关系为语义因果。

从方法设计看，本文与OvSGTR在开放词汇处理上存在互补。OvSGTR结合Swin Transformer和BERT实现开放词汇识别，但依赖冻结特征，导致细粒度关系推理受限。APT的CGP模块通过基础提示合成解决这一问题，但OvSGTR的架构更复杂，计算成本更高。APT的插件式设计使其能无缝集成到不同架构中，而OvSGTR需专门设计。这种差异反映了参数效率与架构复杂度之间的权衡。

## 总结

本文要解决的核心矛盾是冻结语义表示的刚性导致的关系推理偏差。现有方法因依赖静态嵌入无法区分上下文中的语义角色，而APT通过轻量级提示模块实现了语义特征的动态调制。该方法在VG SGDet上提升了2.3个点的R@50，在开放词汇Novel split上提升了1.5个点的mR@50，证明了其有效性。然而，本文的边界在于其效果受限于底层检测器精度，且在生成式范式下缺乏竞争力。当支持集增大到5-shot时，提示机制的边际收益是否递减，论文未给出回答。
