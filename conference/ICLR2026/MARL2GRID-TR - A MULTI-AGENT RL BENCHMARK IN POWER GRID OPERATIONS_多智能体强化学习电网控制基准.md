# ICLR2026最新论文 ｜MARL2GRID-TR: A MULTI-AGENT RL BENCHMARK IN POWER GRID OPERATIONS ｜多智能体强化学习电网控制基准

研究机构：美国麻省理工学院、法国国家科学研究中心

作者：Enrico Marchesini、Eva Boguslawski、Alessandro Leite 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_88835395)

> 输电网在去中心化运营中面临协调失效与安全风险，现有单智能体强化学习基准无法反映真实多运营商结构。本文构建首个支持离散拓扑重构与连续重调度的多智能体强化学习基准，基于法国RTE高保真仿真平台。实验表明当前主流多智能体算法在真实电网约束下性能严重受限，揭示了去中心化协调的核心瓶颈。该基准填补了多智能体电网控制评估空白，但现有算法尚未解决高维离散动作空间下的探索难题。

## 研究背景

电网实时控制依赖拓扑重构与功率重调度两类机制，前者通过开关操作改变网络结构以缓解过载，后者调整发电机出力平衡供需。这两类动作均受线路热极限、发电机爬坡率等物理约束限制，违反约束将导致停电或经济损失。传统优化求解器在高维非线性非凸交流潮流方程下计算缓慢，难以满足5分钟级实时调度需求，促使研究者转向数据驱动的强化学习范式。

L2RPN竞赛与RL2GRID基准确立了单智能体强化学习在电网控制中的研究范式，但将复杂电网抽象为单一决策主体，忽略了实际输电网由多个传输系统运营商（TSO）分区管理的去中心化结构。这种单智能体假设导致模型无法捕捉局部观测下的协调难题，且难以扩展至大规模电网。MARL2GRID-TR针对这一缺口，将电网控制建模为多智能体马尔可夫决策过程（MMDP），每个智能体控制子站集合，通过部分可观测马尔可夫决策过程（Dec-POMDP）框架处理信息不对称，首次在多智能体层面引入安全约束形式化与启发式空闲转换机制。

## 核心方法

### 多智能体电网控制参照系

本文问题属于多智能体强化学习（MARL）在电网拓扑与功率控制中的应用。标准MARL流程采用集中训练去中心化执行（CTDE）范式，智能体在训练阶段利用全局信息优化策略，部署时仅依赖局部观测。本文关键差异在于：电网物理耦合导致局部动作产生全局非线性影响，且安全约束需全局共享而非局部分配，这要求约束形式化与奖励设计必须反映系统级安全目标。

### 联合安全约束形式化

传统MARL约束优化将安全成本分配至各智能体，但电网中单条线路过载可能引发连锁故障，局部约束满足无法保证系统安全。本文采用联合约束形式化，将安全成本全局累积并共享至所有智能体，迫使智能体超越局部视角进行协调。对于线路过载约束，定义每步成本为所有连接线路过载指示函数与断开指示函数之和：

$$C_O(s, \mathbf{a}) = \sum_{\ell \in L} (O_\ell(s, \mathbf{a}) + D_\ell(s, \mathbf{a}))$$

其中 $O_\ell$ 在线路功率流超过热极限时取1，$D_\ell$ 在线路因持续过载被环境断开时取1。该设计解决了局部约束优化在电网级联故障场景下的失效问题，确保智能体集体维持系统级安全，但增加了策略学习的协调复杂度。

### 多智能体空闲启发式转换

高维离散动作空间导致探索效率低下，传统方法在正常工况下浪费大量样本于冗余决策。本文引入专家启发的空闲转换机制，当所有线路负载低于安全阈值 $\rho_{max}$ 时，智能体控制被挂起，环境自动推进至安全关键状态。该机制通过减少有效决策时域，将学习焦点集中于故障响应阶段，提升了样本效率。然而，在离散拓扑任务中，空闲转换压缩了智能体探索多步协调重构的时间窗口，与组合爆炸的动作空间产生冲突，导致探索能力进一步受限。

## 实验评估

实验基于Grid2Op的bus14、bus36、bus118电网，评估QPLEX、MAPPO、LagrMAPPO、PPO等基线。拓扑优化任务在bus14上测试，重调度任务在bus118上测试。基线覆盖价值分解与策略梯度两类主流MARL算法，但缺失HAPPO等异构多智能体方法，且未对比架构级安全屏蔽机制。

| 任务 | 智能体类型 | 平均生存率 |
|---|---|---|
| bus14拓扑优化 | DoNothing | 0.18 |
| bus14拓扑优化 | QPLEX | 0.04 |
| bus14拓扑优化 | MAPPO | 0.79 |
| bus14拓扑优化 | PPO | 0.38 |
| bus14拓扑优化 | LagrMAPPO (L) | 0.19 |
| bus14拓扑优化 | LagrMAPPO (O) | 0.04 |
| bus14拓扑优化 | LagrPPO (L) | 0.04 |
| bus14拓扑优化 | LagrPPO (O) | 0.01 |
| bus118重调度 | DoNothing | 0.29 |
| bus118重调度 | RecoPowerline | 0.34 |
| bus118重调度 | MASAC | 0.25 |
| bus118重调度 | MAPPO | 0.58 |
| bus118重调度 | PPO | 0.67 |

bus14拓扑优化中，MAPPO以79%平均生存率显著优于其他方法，但LagrMAPPO在约束版本下性能急剧下降至19%以下，表明拉格朗日软约束在离散动作空间中难以平衡安全与性能。bus118重调度中，PPO（67%）优于MAPPO（58%），显示集中式观测在连续任务中仍有优势。

消融实验揭示空闲启发式在离散任务中的负迁移效应：添加空闲转换后，MAPPO平均生存率从约84%降至约20%，因启发式压缩了多智能体协调探索的时间窗口。这一反直觉结果挑战了启发式加速学习的常规假设，表明在组合爆炸动作空间中，探索机会的减少比冗余决策的消除更具破坏性。

评估边界存在局限：未报告置信区间，数值比较需谨慎；未测试架构级安全屏蔽，安全性能评估不完整；bus118拓扑优化任务因复杂度未充分评估，可扩展性结论受限。代码已开源，超参数通过网格搜索确定，但GPU资源未明确说明。

## 关联研究分析

从问题动机看，本文与RL2GRID（Marchesini et al., 2025）共享Grid2Op仿真基础，但将单智能体框架扩展为多智能体Dec-POMDP。RL2GRID假设全局观测与集中决策，而本文强制局部观测与去中心化执行，这一差异源于真实TSO运营结构。然而，本文实验显示去中心化在bus14上导致PPO（38%）低于MAPPO（79%），且整体性能低于单智能体预期，挑战了去中心化必然提升扩展性的假设。这种性能差距可能源于电网物理耦合导致的协调难度，而非算法本身缺陷，但论文未提供证据区分任务特性与算法局限。

从方法设计看，本文采用拉格朗日软约束处理安全要求，与Hierarchical RL with Safety Shielding的架构级硬屏蔽形成方法论对比。硬屏蔽在策略执行层强制拦截危险动作，提供硬安全保证；软约束通过奖励塑形让策略学会避免危险，保持灵活性。本文未测试硬屏蔽，导致安全性能评估不完整。在极端场景下，软约束的约束满足率不足（LagrMAPPO生存率低于20%），而硬屏蔽可能以牺牲最优性为代价换取安全性。这种权衡在超大规模电网中是否可接受，论文未给出量化分析。

## 总结

MARL2GRID-TR要解决的核心矛盾是去中心化电网控制中协调失效与安全约束满足的冲突。现有单智能体基准无法反映多运营商结构，而本文通过Dec-POMDP框架与联合约束形式化，首次在多智能体层面建模电网控制。实验证明当前MARL方法在真实电网约束下性能严重受限，MAPPO在bus14拓扑优化中仅达79%生存率，LagrMAPPO在约束版本下降至19%以下，揭示高维离散动作空间下探索与协调的双重瓶颈。本文边界在于未测试架构级安全屏蔽，且bus118拓扑优化任务未充分评估，可扩展性结论受限。当智能体数量增加至bus118的12个分区时，联合约束形式化是否因梯度传播受阻而进一步恶化收敛速度，论文未给出回答。
