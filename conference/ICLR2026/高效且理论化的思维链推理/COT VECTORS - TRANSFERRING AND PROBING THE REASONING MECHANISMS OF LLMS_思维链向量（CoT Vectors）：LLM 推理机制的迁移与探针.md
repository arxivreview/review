# ICLR2026最新论文 ｜COT VECTORS: TRANSFERRING AND PROBING THE REASONING MECHANISMS OF LLMS ｜思维链向量（CoT Vectors）：LLM 推理机制的迁移与探针

研究机构：东南大学、澳大利亚莫纳什大学

作者：Li Li、Ziyi Wang、Yongliang Wu 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_13675468)

> 导读 思维链（Chain-of-Thought, CoT）提示虽能提升大语言模型（LLM）推理能力，但依赖长上下文或高成本微调，难以实现轻量级复用。现有参数高效方法如 LoRA 需更新百万级参数，而任务向量（Task Vectors）范式此前仅用于简单分类，未触及多步推理。本文提出 CoT Vectors，将 CoT 效应形式化为激活空间中的可迁移向量，通过提取或学习获得紧凑表示并注入推理过程。该方法以 3.6K 参数实现接近 LoRA 的性能，揭示了 LLM 内部三阶段推理结构，但其绝对准确率仍低于当前 SOTA 压缩方法，且对模型潜空间结构高度敏感。

## 研究背景

当 LLM 处理复杂数学问题时，直接生成答案往往出错，需插入中间推理步骤引导逻辑。这一过程称为思维链（Chain-of-Thought, CoT），其本质是输入前缀对注意力输出的调制。然而，CoT 序列冗长，导致推理延迟与计算开销激增。为降低成本，研究界转向参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）或隐式推理（Implicit CoT）。PEFT 如 LoRA 虽有效，但需训练百万级参数；隐式推理如 COCONUT 需修改架构，训练不稳定。任务向量（Task Vectors）提供了另一条路径：通过计算微调模型与基座模型的激活或参数差值，获得紧凑向量以引导行为。但该范式此前局限于简单任务，能否捕捉多步推理的通用策略尚属未知。

CoT 推理的效率优化已成为核心研究目标，但现有方案在“紧凑性”与“通用性”间存在矛盾。显式压缩方法如 UCoT 依赖专用模块，隐式推理方法如 CODI 需架构改造，均难以实现即插即用。本文切入点在于：CoT 对模型内部激活的影响是否可被形式化为一个可迁移的向量？若可行，该向量能否在不修改模型权重的前提下，以极小参数开销实现任务通用的推理增强？这一问题连接了机制可解释性与参数高效适配，旨在揭示 LLM 内部推理的组织结构。

## 核心方法

### 方法参照系

本文问题属于参数高效适配范畴，但区别于 LoRA 等更新权重矩阵的方法。关键差异在于：本文不修改模型参数，而是将 CoT 效应编码为外部向量，通过激活注入实现推理引导。这要求形式化 CoT 对注意力输出的数学影响，并设计稳定的向量获取机制。

### CoT 向量的形式化

CoT 序列作为前缀，改变了答案 token 的注意力计算。设问题为 $Q$，CoT 为 $C$，答案为 $A$，单头自注意力输出可分解为无 CoT 项与 CoT 诱导的额外项。该额外项量化为标量系数 $\mu$ 与 CoT 向量 $\vec{v}_{CoT}$ 的乘积：

$$ \text{SA}(a, [K_Q, K_C, K_A], [V_Q, V_C, V_A]) = \text{SA}(a, [K_Q, K_A], [V_Q, V_A]) + \mu \cdot \vec{v}_{CoT} $$

此公式表明，CoT 的作用等价于在激活空间中施加一个一致偏移。设计动机在于：若该偏移对同类任务具有共性，则可通过平均或学习获得任务通用向量，避免逐样本推理。

### 可学习 CoT 向量

提取式向量通过计算支持集中有/无 CoT 输入的激活差值获得，但存在层间不稳定性。为解决此问题，本文提出可学习 CoT 向量 $\vec{v}_L$，采用教师-学生框架优化。教师路径处理完整三元组 $(Q, C, A)$，学生路径仅处理 $(Q, A)$ 并注入 $\vec{v}_L$。训练目标结合预测损失与表示对齐损失：

$$ \mathcal{L} = \mathcal{L}_{CE} + \lambda \cdot \mathcal{L}_{Align} $$

其中 $\mathcal{L}_{CE}$ 为学生答案 token 的交叉熵损失，$\mathcal{L}_{Align}$ 为教师与学生答案 token 隐藏状态的 KL 散度。设计动机在于：被动平均激活易受样本特异性干扰，而主动学习可蒸馏出更鲁棒的推理信号，克服提取式向量在中间层的失效。

## 实验评估

实验在 Qwen2.5-Math-7B 与 LLaMA-3.1-8B-Instruct 上进行，覆盖 GSM8K、MATH、MMLU-Pro 等基准。基线包括 Zero-shot CoT 与 LoRA，但缺失 UCoT、SLAT 等当前 SOTA 压缩方法，也未对比 Prefix-Tuning 等其他 PEFT 方法。

| 模型 | 方法 | 参数量 | GSM8K | MATH-E | MATH-H | Avg. |
|---|---|---|---|---|---|---|
| Qwen2.5-Math-7B | Baseline | — | 74.6 | 69.9 | 47.9 | 50.5 |
| | Extracted | — | 78.2 | 72.0 | 49.7 | 53.6 |
| | Learnable | 3.6K | 83.5 | 71.9 | 50.9 | 55.1 |
| | LoRA | 10.0M | 79.0 | 70.4 | 48.2 | 53.4 |
| LLaMA3.1-8B-Instruct | Baseline | — | 77.4 | 62.0 | 34.6 | 58.7 |
| | Learnable | 4.2K | 78.2 | 63.8 | 36.4 | 60.6 |
| | LoRA | 13.6M | 78.6 | 63.5 | 36.3 | 60.4 |

Learnable CoT Vector 在 Qwen 上 GSM8K 达 83.5%，较基线提升 8.9 点，超过 LoRA 的 79.0%；在 LLaMA 上提升 0.8 点，与 LoRA 持平。据领域综述，当前 SOTA 方法如 UCoT 在 GSM8K 上达 90.0%，本文绝对准确率较低，但参数量仅为 LoRA 的 1/2777.8。

| 样本大小 | Baseline | Learnable CoT Vector | LoRA |
|---|---|---|---|
| 100 | 74.6 | 78.2 | 76.0 |
| 500 | 74.6 | 79.0 | 77.9 |
| 1000 | 74.6 | 82.3 | 78.5 |
| 3000 | 74.6 | 83.5 | 79.0 |

消融显示，Learnable CoT Vector 在 100 样本时即显著优于 LoRA，且随数据量增加性能持续提升，而 LoRA 增益趋于饱和。这表明向量学习具有更强的数据效率，但绝对性能上限受限于单一向量表示的容量。

评估协议未报告置信区间，且未控制预训练数据变量。代码声明将发布但未提供 URL，超参数 $\mu=1.0$、$\lambda=0.5$ 固定，缺乏敏感性分析。跨模型迁移实验显示，Qwen2.5-Math-7B-Instruct 的向量迁移至 Qwen2.5-Math-7B 后，GSM8K 从 74.6 提升至 77.5，低于自获取的 78.2，提示迁移存在性能损耗。

## 关联研究分析

从问题动机看，本文与 UCoT 同属 CoT 压缩路线，但 UCoT 依赖专用压缩器生成精简轨迹，本文通过向量注入引导推理。UCoT 在 GSM8K 上达 90.0%，本文仅 83.5%，差距源于 UCoT 保留了显式推理步骤的语义完整性，而向量注入可能丢失任务特异性细节。这一差异暗示：当任务复杂度超过向量表示容量时，显式压缩可能优于隐式引导。

从方法设计看，本文与 COCONUT 同属潜在推理机制，但 COCONUT 需修改架构并训练不稳定，本文保持架构冻结。COCONUT 在 GSM8K 隐式推理上仅 39.0%，本文 Learnable CoT Vector 在显式 CoT 评测中达 83.5%，但本文未测试纯隐式推理场景。这引发疑问：向量注入是否真正替代了推理过程，还是仅作为提示增强？若后者，其在无 CoT 提示场景下的有效性需进一步验证。

## 总结

本文核心矛盾在于 CoT 推理的高成本与轻量级复用需求之间的张力。切入点在于将 CoT 效应形式化为激活空间中的可迁移向量，利用任务向量范式实现参数高效适配。方法上，提出可学习 CoT 向量，通过教师-学生框架优化，克服提取式向量的层间不稳定性。实验证明，在 Qwen 上以 3.6K 参数实现 GSM8K 83.5% 准确率，超过 LoRA 的 79.0%，但低于 UCoT 的 90.0%。边界在于：向量表示容量有限，难以捕捉任务内多样性；且性能高度依赖模型潜空间结构，Qwen 因更清晰的三阶段推理组织而受益更多，LLaMA 则增益微弱。当支持集增大到 5-shot 时，向量表示的边际收益是否递减，论文未给出回答。
