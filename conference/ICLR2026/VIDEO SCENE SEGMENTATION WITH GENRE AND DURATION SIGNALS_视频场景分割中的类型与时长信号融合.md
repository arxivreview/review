# ICLR2026最新论文 ｜VIDEO SCENE SEGMENTATION WITH GENRE AND DURATION SIGNALS ｜视频场景分割中的类型与时长信号融合

研究机构：韩国光州科学技术院、韩国延世大学

作者：Jungu Cho、Seong Jong Ha、Hae-Gon Jeon

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_90857208)

> 视频场景分割旨在从长视频流中识别叙事连贯的语义边界，但现有方法过度依赖视觉相似性，导致在叙事转换缺乏视觉突变时失效。本文切入点在于利用制作元数据（类型定义与镜头时长分布）作为语义先验，弥补纯视觉特征的盲区。通过类型引导的表示学习与时长感知锚点采样，该方法在自监督预训练阶段增强了镜头特征的叙事区分度。其价值在于验证了元数据对场景边界的增益，但类型先验的静态性限制了其在混合类型视频上的泛化能力。

## 研究背景

长视频理解需将连续帧流结构化为语义单元。镜头（Shot）是相机连续拍摄的最小单元，可通过低层视觉特征可靠检测；而场景（Scene）是维持动作、地点与时间连贯性的语义集合，其边界检测需超越视觉不连续性，理解主题与叙事逻辑。当叙事转换未伴随明显的视觉断裂时，基于视觉相似度的传统方法极易产生误判，这构成了场景分割的核心难点。

视频场景分割的主流路线分为监督学习与自监督学习两类。监督方法依赖MovieNet等大规模标注数据，但标注成本高昂且难以扩展至无标签视频库。自监督方法（如BaSSL、TranS4mer）采用两阶段范式：先在无标签数据上通过伪边界生成预训练镜头编码器，再在少量标注数据上微调。然而，现有自监督框架多依赖固定锚点或纯视觉对比，缺乏对制作层面元数据（如类型惯例、镜头时长规律）的系统利用。Movies2Scenes虽探索了元数据，但聚焦于电影级相似度而非镜头级表示学习。本文旨在将类型文本定义与镜头时长分布融入自监督预训练，解决视觉信号与叙事语义错位的问题。

## 核心方法

### 方法参照系

本文基于BaSSL与TranS4mer建立的自监督场景分割框架，该框架包含镜头编码器、上下文编码器与预测头。标准流程通过固定端点锚点生成伪边界，利用对比损失优化镜头表示。本文的关键差异在于：在预训练阶段引入类型嵌入作为语义先验，并改造锚点采样策略以利用时长分布，从而提升伪边界生成的多样性与语义相关性。

### 类型引导的镜头表示学习

在ViT编码器内部，本文引入预计算的类型嵌入作为固定参数，通过余弦相似度计算视觉Token与类型嵌入的亲和度矩阵 $A$。随后，类型嵌入经投影矩阵 $W$ 加权后，通过残差连接融入视觉特征：

$$ V_t^{genre} = V_t + W \cdot (A \odot G_e) $$

其中 $V_t$ 为视觉Token特征，$G_e$ 为类型嵌入集。这一设计动机在于解决单一视觉特征无法捕捉类型特定叙事模式的问题。通过动态加权，模型能根据当前镜头的视觉内容自适应地激活相关类型语义，从而在表示层面区分不同叙事风格的场景边界，避免了简单拼接导致的性能下降。

### 时长感知伪边界生成

针对固定锚点导致训练样本单一的问题，本文提出逆时长加权（IDW）采样策略。锚点 $s_i$ 的采样概率 $P(s_i)$ 与镜头时长 $d_i$ 成反比：

$$ P(s_i) = \frac{1/d_i}{\sum_{j \in \text{subseq}} 1/d_j} $$

该公式赋予短镜头更高的采样权重。短镜头在序列中分布更密集，作为锚点能生成更多样的子序列组合，从而提供更丰富的对比学习信号。随后，基于DTW变体的相似度搜索确定伪边界 $b^*$，将序列划分为两个伪场景。这一改动直接提升了预训练阶段对复杂叙事结构的覆盖能力，解决了固定端点策略在长序列中捕获局部模式不足的问题。

## 实验评估

实验在MovieNet-SSeg（318部电影）、BBC（11部纪录片）及新提出的MovieChat-SSeg（1000个片段）上进行。基线涵盖BaSSL、TranS4mer、CAT等自监督方法，以及Movie-CLIP等监督方法。本文方法在MovieNet-SSeg上取得63.62 AP，显著优于TranS4mer的60.78 AP；在MovieChat-SSeg上，总体AP为46.7，较TranS4mer提升8.8个点。

| 数据集 | 方法 | AP | AUC | F1 | mIoU |
| :--- | :--- | :--- | :--- | :--- | :--- |
| MovieNet-SSeg | TranS4mer | 60.78 | 91.89 | - | - |
| MovieNet-SSeg | Ours | 63.62 | 92.84 | - | - |
| MovieChat-SSeg | BaSSL* | 36.6 | - | - | - |
| MovieChat-SSeg | TranS4mer* | 37.9 | - | - | - |
| MovieChat-SSeg | Ours | 46.7 | - | - | - |

消融实验显示，类型嵌入的集成方式对性能影响显著：帧级拼接导致性能下降（59.13 AP），而本文的亲和度残差连接达到最佳（63.62 AP）。时长采样策略中，逆时长加权（IDW）比固定端点（Side）提升0.8 AP，比时长加权（DW）提升0.18 AP。测试时镜头分割阈值设为10秒时，MovieNet-SSeg AP达到63.80，略高于无分割的63.62，表明长镜头细分有助于边界检测。

评估指标包括AP、AUC、F1及mIoU，覆盖了镜头级分类与序列级对齐。然而，论文未报告计算效率指标，且MovieChat-SSeg仅包含平均7.4分钟的片段，可能无法反映长时程叙事模式。代码未公开，但提供了详细的超参数设置（ViT-B/32, 8x A100 GPU），保证了可复现性。

## 关联研究分析

从问题动机看，本文与Movies2Scenes均利用元数据，但后者聚焦于电影级共看模式构建正样本对，而本文将类型定义下沉至镜头级表示学习。这一差异源于任务粒度：Movies2Scenes旨在跨电影场景分组，而本文关注单视频内的边界检测。类型先验在镜头级引入，可能更直接地影响边界决策，但这也意味着模型对类型标签的准确性更为敏感。

从方法设计看，本文与BaSSL共享自监督框架，但BaSSL依赖固定端点锚点，而本文引入时长感知采样。这一改动并非简单的参数调整，而是基于“短镜头分布更密集”的假设。与TranS4mer相比，本文额外引入了类型嵌入模块。值得注意的是，类型嵌入仅在预训练阶段使用，微调阶段冻结。这暗示类型信息主要作为特征初始化的引导，而非推理时的动态条件。若类型标签错误，预训练阶段的表示学习是否会受到负面影响，论文未给出回答。

## 总结

本文旨在解决视觉信号与叙事语义错位导致的场景分割失效问题。通过引入类型文本作为语义先验，并利用镜头时长分布优化伪边界生成，该方法在自监督预训练阶段增强了镜头表示的叙事区分度。实验表明，该方法在MovieNet-SSeg上取得63.62 AP，在MovieChat-SSeg上较基线提升8.8个点，验证了元数据的有效性。然而，类型先验的静态性限制了其在混合类型视频上的泛化能力，且测试时镜头分割仅带来微小增益。当视频内容包含大量非标准类型或类型标签缺失时，该方法的性能退化程度如何，论文未给出回答。
