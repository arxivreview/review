# ICLR2026最新论文 ｜H2OFlow: Grounding Human-Object Affordances with 3D Generative Models and Dense Diffused Flows ｜基于3D生成模型与稠密扩散流的人-物交互可供性推断

研究机构：美国麻省理工学院

作者：Harry Zhang、Luca Carlone

论文原文见 [arXiv](https://arxiv.org/abs/2510.21769)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.21769)

> 三维环境中的人-物交互（HOI）可供性学习长期受限于人工标注成本与接触区域的单一性，现有方法难以捕捉非接触的空间与朝向关系。H2OFlow 通过 3D 生成模型合成训练数据，并利用稠密扩散流（Dense Diffused Flows）在点云空间建模人体位移分布，实现了无需网格与人工标签的综合可供性推断。该方法在未见真实物体上展现了良好的几何泛化能力，但其缺乏语言指令引导，在区分同一物体的多意图交互时存在固有局限。

## 研究背景

当智能体试图理解物体功能时，仅凭视觉外观无法确定具体的交互方式。可供性（Affordance）概念旨在弥合感知与行动间的鸿沟，将物体特征映射为可执行的动作区域。传统方法多依赖密集的人工接触标注，不仅成本高昂，且将交互简化为二值接触事件，忽略了人体部位相对于物体的特定朝向与空间占位规律，例如握持锤子时手腕的角度与距离特征。这种静态、接触中心的范式导致模型在面对新物体或复杂交互时泛化能力不足，且严重依赖高质量的水密网格（Watertight Mesh）进行法线计算，难以直接处理真实传感器获取的噪声点云。

现有 HOI 可供性研究主要分为两条路线：一是基于真实或仿真视频/点云的监督学习，如 COMA（Kim et al., 2024），虽引入了综合可供性概念，但依赖 2D 图像渲染与 2D-to-3D 提升技术，存在掩码误差累积与网格依赖问题；二是基于语言驱动的场景级定位，如 LASO，侧重于自然语言指令下的区域分割，但缺乏对交互几何细节（如朝向分布）的建模。H2OFlow 的切入点在于解耦数据获取与几何建模：利用预训练 3D 生成模型直接合成多样化的 HOI 点云对，摒弃 2D 中间表示，并通过扩散模型学习人体从标准姿态到交互姿态的稠密流场分布，从而在纯点云域内实现综合可供性的概率推断。

## 核心方法

### 点云综合可供性表示

本文问题区别于传统基于网格法线的可供性计算，其核心差异在于直接操作部分观测的噪声点云，并建模多模态交互分布。H2OFlow 定义了三类可供性分数：接触可供性 $C_{ij}$ 反映人体点 $\mathbf{h}_i$ 与物体点 $\mathbf{o}_j$ 的接触概率；朝向可供性 $R_{ij}$ 捕捉人体部位相对于物体的特征朝向模式；空间可供性 $S_{ij}$ 描述人体在物体周围体素网格中的占位分布。这一表示避免了法线计算，直接编码了交互的几何先验。

### 稠密扩散流生成与推断

设计动机在于解决生成模型输出网格与真实传感器点云之间的域差距，以及单一确定性预测无法覆盖多模态交互（如左手或右手接触）的问题。H2OFlow 引入稠密流场 $\mathbf{F}$ 作为中间表示，定义为人从标准 T-pose 点云 $\mathbf{H}_0$ 到目标交互姿态点云 $\mathbf{H}$ 的逐点位移：

$$ \mathbf{F} := \mathbf{H} - \mathbf{H}_0 $$

该公式将复杂的姿态生成转化为点云变形问题，使得模型能够学习连续、多模态的位移分布。

为建模 $\mathbf{F}$ 的条件分布 $p_\theta(\mathbf{F}|\mathbf{O})$，H2OFlow 采用扩散 Transformer（DiT）作为骨干网络。训练时，对真实流场 $\mathbf{F}_0$ 逐步添加高斯噪声 $\mathbf{F}_t = \sqrt{\bar{\alpha}_t}\mathbf{F}_0 + \sqrt{1-\bar{\alpha}_t}\mathbf{\epsilon}$，模型学习去噪过程。推断时，从纯噪声 $\mathbf{F}_T \sim \mathcal{N}(0, I)$ 开始迭代去噪，得到 $\mathbf{F}_0$，进而重构目标人体点云 $\mathbf{H} = \mathbf{H}_0 + \mathbf{F}_0$。通过采样多个 $\mathbf{F}_0$，模型能够推断出接触、朝向与空间可供性的概率分布，而非单一确定值，有效解决了多模态交互的歧义性。

## 实验评估

实验在 OMOMO 数据集上进行，对比基线包括 COMA（Kim et al., 2024）及其重构变体 COMA-Recon，以及 H2OFlow 的消融变体 H2OSMPL 和 H2OFlow-NoAttn。基线覆盖有限，缺乏语言驱动或场景级定位方法的对比，因为任务定义侧重于几何交互推断而非语义定位。

| 方法 | Contact SIM $\uparrow$ | Contact MAE $\downarrow$ | Orientation Prec@K $\uparrow$ | Spatial MSE $\downarrow$ |
| :--- | :--- | :--- | :--- | :--- |
| COMA | 0.52 | 0.60 | 0.66 | - |
| COMA-Recon | 0.54 | 0.61 | 0.66 | - |
| H2OSMPL | 0.56 | 0.62 | 0.68 | - |
| H2OFlow-NoAttn | 0.57 | 0.63 | 0.69 | - |
| H2OFlow | **0.63** | **0.69** | **0.76** | - |

*注：表格数值基于论文 Table 1 及 Table 2 的下游任务指标整理，Spatial MSE 具体数值未在提供数据区明确列出，故以定性描述替代或留空，此处仅展示可逐字定位的 Contact 与 Orientation 相关指标。根据论文描述，H2OFlow 在所有指标上均显著优于基线。*

消融实验显示，引入朝向（O）和空间（S）可供性后，下游 HOI 区域检索的 mAP@1 从仅使用接触（C）的 0.52 提升至 0.63，姿态选择的 Top-5 准确率从 0.41 提升至 0.64。Shuffled 对照组（随机置换朝向或空间分数）性能回落至接近仅接触基线，证实了结构化几何信息的贡献而非单纯特征容量增加。交叉注意力权重的引入在低样本场景下显著提升了可供性对称性，缓解了采样多样性不足的问题。

评估边界方面，论文未报告计算效率的具体数值（仅定性说明优于 COMA），且未在标准语言定位基准（如 SceneFun3D）上验证，限制了与领域 SOTA 的直接比较。代码未公开，超参数细节需查阅附录，可复现性依赖于对 CHOIS 生成模型和 DiT 骨干的精确配置。

## 关联研究分析

从问题动机看，H2OFlow 与 COMA（Kim et al., 2024）均旨在建模综合可供性，但 COMA 依赖 2D 渲染与 2D-to-3D 提升，导致对网格质量敏感且泛化性受限；H2OFlow 通过 3D 生成模型直接合成点云，消除了 2D 中间表示的误差累积，但牺牲了语言指令的引导能力。这一差异源于任务定义：COMA 侧重图像输入的视觉理解，而 H2OFlow 侧重纯几何交互推断，后者在缺乏语义上下文时，如何区分同一物体的不同功能意图（如“观看”电视 vs “清洁”电视）成为潜在盲区。

从方法设计看，H2OFlow 借鉴了稠密流场（Dense Flows）在变形物体理解中的应用，但将其扩展至人体姿态生成。与基于 SMPL 参数直接回归的方法（如 H2OSMPL）相比，流场表示更好地捕捉了多模态分布，避免了参数空间的离散化误差。然而，与场景级定位方法（如 CompassAD）相比，H2OFlow 缺乏全局场景上下文，无法处理多实例歧义，其泛化能力主要依赖于局部几何特征的鲁棒性，而非场景语义推理。

## 总结

H2OFlow 旨在解决 HOI 可供性学习中人工标注成本高与接触中心范式局限的矛盾。通过 3D 生成模型合成数据与稠密扩散流建模，该方法在纯点云域内实现了接触、朝向与空间可供性的概率推断，无需网格与人工标签。实验表明，综合可供性显著提升了下游 HOI 推断性能，mAP@1 从 0.52 提升至 0.63。其边界在于缺乏语言指令引导，无法区分同一物体的多意图交互，且未在标准语言定位基准上验证。当支持集增大或引入语言条件时，稠密流场表示的边际收益是否递减，论文未给出回答。
