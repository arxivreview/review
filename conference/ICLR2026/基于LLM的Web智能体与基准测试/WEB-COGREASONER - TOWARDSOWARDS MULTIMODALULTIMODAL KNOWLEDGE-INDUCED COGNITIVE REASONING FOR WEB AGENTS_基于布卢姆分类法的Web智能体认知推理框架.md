> Web智能体在开放网络中执行长程任务时，常因缺乏对页面元素语义与交互逻辑的深层理解而陷入重复循环或动作失效。现有方法多依赖端到端模仿学习或即时上下文拼接，忽视了“先积累知识、后应用推理”的认知构建过程，导致模型在未见过的复杂场景下泛化能力不足。本文借鉴布卢姆分类法，将Web知识解构为事实、概念与程序三层，并通过课程学习与知识驱动思维链（KCoT）训练多模态智能体。该框架在认知密集型任务上显著优于基线，但在通用导航成功率上仍落后于当前多模态SOTA，其知识内化机制对长程自主探索的支撑力尚存疑。

## 研究背景

Web智能体处理动态网页时，面临的核心困境是感知接地（Grounding）与规划鲁棒性的耦合失效。若模型无法将自然语言指令准确映射到具体DOM节点或像素坐标，后续动作必然失效；而缺乏对历史交互的有效存储与检索，智能体在步骤增多后易出现“迷失在中间”现象。这种感知与记忆的断裂，使得单纯依赖大语言模型（LLM）零样本提示或简单强化学习的方法，在复杂多步任务中表现远落后于人类水平。

当前主流路线分为两类：一类是基于ReAct范式的线性推理-行动循环，其瓶颈在于早期步骤错误会导致级联失败，缺乏错误恢复机制；另一类是端到端多模态模仿学习，如UI-TARS，虽提升了视觉定位精度，但缺乏对页面深层语义结构的系统性理解，导致在知识密集型任务中泛化受限。现有知识增强方法往往缺乏理论指导，未能将“知道什么”与“如何思考”解耦。本文的切入点在于，将人类教育学中的布卢姆分类法引入Web智能体训练，主张智能体必须先通过结构化课程习得事实与概念知识，才能发展出程序性推理能力，从而解决“有知识无推理”或“有推理无知识”的割裂问题。

## 核心方法

### 方法参照系

本文问题可置于多模态Web智能体的监督微调（SFT）流程中。标准流程通常将截图与无障碍树（AX Tree）直接映射至动作，依赖模型隐式学习页面语义。本文的关键差异在于，在输入与动作之间插入显式的分层知识推理层，将隐式特征学习转化为显式的认知过程建模，强制模型在生成动作前完成对页面事实、概念与程序的逐步解析。

### 分层知识课程学习

传统SFT将复杂任务数据混合训练，导致模型在感知未稳固时即被迫学习高阶规划，引发负迁移。本文设计三阶段课程：第一阶段（S1）注入事实知识（Factual Knowledge），训练模型识别元素属性与页面状态变化；第二阶段（S2）注入概念知识（Conceptual Knowledge），训练模型理解元素功能与页面整体语义；第三阶段（S3）注入程序知识（Procedural Knowledge），训练模型执行目标导向的多步任务。该过程可形式化为累积损失函数：

$$ \mathcal{L}_{total} = \sum_{i=1}^{3} \lambda_i \mathcal{L}_{S_i}(\theta_{i-1}) $$

其中 $\theta_{i-1}$ 为上一阶段参数，$\lambda_i$ 为阶段权重。此设计确保高阶推理建立在稳固的低层感知基础上，避免了直接训练复杂任务导致的性能崩溃。

### 知识驱动思维链（KCoT）

仅拥有分层知识不足以实现动态决策，模型需将静态知识激活为实时推理。本文提出KCoT机制，在推理阶段强制模型按“事实-概念-程序”顺序生成思维链。其推理过程定义为：

$$ h_t = \text{KCoT}(o_t, k_{f}, k_{c}, k_{p}) \rightarrow a_t $$

其中 $o_t$ 为观察，$k_f, k_c, k_p$ 分别为事实、概念、程序知识层，$a_t$ 为动作。KCoT作为“激活器”，桥接了知识拥有与知识应用之间的鸿沟，使模型能根据当前页面状态动态调用相应层级的知识，而非依赖固定的动作映射。

## 实验评估

实验在Web-CogBench、VisualWebBench、WebVoyager及Online-Mind2Web上进行，基线涵盖商业模型（Claude Sonnet 4, Gemini 2.5 Pro）及开源模型（Qwen2.5-VL-7B, UI-TARS-7B-SFT, OpenWebVoyager）。值得注意的是，对比中缺失了Branch-and-Browse等树搜索类SOTA方法，限制了在长程导航鲁棒性上的直接比较。

| 模型 | Web-CogBench (Overall) | WebVoyager (Overall) | Online-Mind2Web (Cross-Task) |
| :--- | :--- | :--- | :--- |
| Qwen2.5-VL-7B | 69.8 | 2.2% | 1.0% |
| UI-TARS-7B-SFT | 46.4 | 18.1% | 6.3% |
| OpenWebVoyagerMax | - | 26.2% | 20.5% |
| **Web-CogReasoner** | **84.4** | **30.2%** | **17.0%** |

在Web-CogBench上，Web-CogReasoner以84.4分大幅领先，验证了分层知识在认知维度上的有效性。在WebVoyager上，其30.2%的成功率优于OpenWebVoyagerMax的26.2%，但显著低于Gemini 2.5 Pro的54.9%，表明其在通用导航上仍受限于骨干模型能力。

| 配置 | Web-CogBench (Overall) | WebVoyager (Overall) |
| :--- | :--- | :--- |
| Base Model | 69.8 | 2.2% |
| S1 only | 72.1 | 12.67% |
| S1+S3 | 76.17 | 23.47% |
| S1+S2+S3 (w/o KCoT) | 84.4 | 25.35% |
| **S1+S2+S3 (w/ KCoT)** | **84.4** | **42.9%** |

消融实验揭示两个关键发现：其一，事实知识（S1）是前置条件，S1+S3在WebVoyager上的成功率（23.47%）几乎是仅S3（13.14%）的两倍，证实程序性探索依赖准确的事实接地；其二，KCoT是性能跃升的关键，移除KCoT后WebVoyager成功率从42.9%骤降至25.35%，说明显式推理链对知识激活至关重要。

评估边界方面，Web-CogBench采用LVM Judge评估部分任务，可能存在主观偏差；Online-Mind2Web结果未提供置信区间，且不同方法可能使用不同骨干网络，公平性受限。代码已开源，但训练细节（如GPU数量、超参数）仅在附录中简要提及，复现门槛较高。

## 关联研究分析

从问题动机看，Web-CogReasoner与WebCoach均关注长程任务中的信息丢失，但路线截然不同。WebCoach依赖外部记忆存储（EMS）持久化历史经验，属于“外部记忆”范式；本文则通过分层知识内化，将策略固化于模型参数中，属于“内部认知”范式。WebCoach的优势在于可动态更新记忆，但面临记忆投毒风险；本文的优势在于推理连贯性高，但知识更新需重新训练。这种差异源于任务特性：WebCoach针对动态变化的环境，而本文更侧重静态知识结构的掌握。

从方法设计看，本文与Avenir-Web同属多模态架构，但侧重点不同。Avenir-Web通过混合接地专家（MoGE）解决视觉定位的不确定性，侧重“感知精度”；本文通过KCoT解决语义理解的深度，侧重“认知深度”。Avenir-Web在Online-Mind2Web上取得48.0%的成功率，远高于本文的17.0%（Cross-Task），这暗示在真实开放网络中，感知的鲁棒性可能比认知的深度更具决定性。本文在认知基准上的优势，是否能在高噪声、高动态的真实环境中转化为导航成功率，论文未给出回答。

## 总结

Web-CogReasoner试图解决Web智能体“有动作无认知”的矛盾，通过布卢姆分类法将知识解构为事实、概念与程序三层，并引入KCoT实现知识激活。实验证明，该框架在Web-CogBench上取得84.4分，WebVoyager上达到30.2%成功率，显著优于基线模型。然而，其在Online-Mind2Web上仅17.0%的Cross-Task成功率，暴露了知识内化机制在真实开放环境中的泛化局限。当面对高动态、高噪声的真实网页时，结构化知识能否有效抵御环境漂移，而非仅作为静态模板被调用，是决定该框架能否从“认知基准”走向“真实代理”的关键。
