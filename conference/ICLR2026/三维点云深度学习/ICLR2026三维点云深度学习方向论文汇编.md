【POINT-FOCUSED ATTENTION MEETS CONTEXT-SCAN - STATE SPACE: ROBUST BIOLOGICAL VISUAL PERCEP TION FOR POINT CLOUD REPRESENTATION ｜点聚焦注意力与上下文扫描状态空间：生物视觉启发的点云表征学习

研究机构：南京大学、北京邮电大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_65402417)

> 点云表征学习长期受困于局部细粒度结构捕捉与全局长程依赖建模之间的计算效率权衡，现有局部注意力网络视野受限，而纯状态空间模型（SSM）局部感知不足。PointLearner 借鉴生物视觉的中央凹视觉与扫视机制，提出点聚焦注意力（Point-Focused Attention, PFA）与上下文扫描状态空间（Context-Scan State Space, CSSS）相结合的混合架构。该方法通过竞争归一化注意力融合局部与全局特征，并利用希尔伯特曲线引导双向 S6 进行全局推理，在多个基准上取得 SOTA 性能。其价值在于验证了生物启发混合架构的有效性，但 S3DIS 分割任务上的绝对精度仍显著低于最新专用方法，且对序列化路径的依赖限制了其在极端非规则拓扑下的泛化潜力。

【POINT-UQ: AN UNCERTAINTY QUANTIFICATION - PARADIGM FOR POINT CLOUD FEW SHOT CLASS INCREMENTAL LEARNING ｜基于不确定性量化的点云少样本类增量学习框架

研究机构：中国科学院、中国科学院大学

作者：Xiangqi Li、Libo Huang、Jiarui Zhao 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_63437478)

> 3D少样本类增量学习（FSCIL）旨在解决模型在获取新类别极少样本时，如何在不遗忘旧类知识的前提下实现有效适应。现有方法过度依赖特征微调，导致过拟合新样本或灾难性遗忘旧知识，且静态决策边界无法适应动态分布。Point-UQ提出将优化重心从特征微调转移至决策优化，通过不确定性量化动态仲裁语义分类与几何原型匹配。该范式在多个基准上显著提升了平均准确率与调和均值，但其对极端少样本（1-shot）下几何原型鲁棒性的依赖仍存疑。

【TEST-TIME OPTIMIZATION OF 3D POINT CLOUD LLM VIA MANIFOLD-AWARE IN-CONTEXT GUIDANCE AND REFINEMENT ｜流形感知上下文引导与置信度精化的3D点云大语言模型

作者：Tiankai Chen、Nanqing Liu、Li Yang 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_61485622)

> 3D点云大语言模型（MLLM）在处理类间视觉高度相似的物体时，常因孤立推理导致细粒度判别失效。现有PointLLM等框架虽能生成描述，但缺乏利用数据分布结构进行上下文增强的机制，且LLM输出的置信度往往过度自信或校准偏差。本文切入点在于利用测试时数据流形构建KNN图，通过检索邻居样本的3D描述作为上下文演示，并引入标签传播算法平滑置信度分数。该框架在3D分布外（OOD）检测与识别任务上显著优于基线，但其性能高度依赖预训练编码器对OOD样本的特征提取质量，且未解决4D动态场景建模问题。

】
