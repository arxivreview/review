【QPROMPT-R1: REAL-TIME REASONING FOR DO MAIN GENERALIZED SEMANTIC SEGMENTATION VIA GROUP-RELATIVE QUERY ALIGNMENT ｜实时域泛化语义分割中的查询对齐机制

研究机构：南京大学、清华大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_76728433)

> 自动驾驶与机器人感知要求语义分割模型在毫秒级延迟内对天气、光照等分布偏移保持鲁棒，但现有域泛化方法依赖重型解码器导致推理缓慢，而实时方法又因固定类嵌入缺乏跨域适应能力。本文指出速度瓶颈在于预测头而非骨干，提出在视觉基础模型最后一层注入可学习查询的轻量架构，并引入仅训练时生效的组相对查询对齐策略。该方法在保持54 FPS实时性的同时，将合成到真实场景的mIoU提升至64.1%，但其在极端域偏移下的泛化上限及单层查询交互的表征能力边界仍存疑。

】
