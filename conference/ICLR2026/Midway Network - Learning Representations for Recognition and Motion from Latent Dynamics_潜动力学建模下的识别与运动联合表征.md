# ICLR2026最新论文 ｜Midway Network: Learning Representations for Recognition and Motion from Latent Dynamics ｜潜动力学建模下的识别与运动联合表征

研究机构：美国纽约大学

作者：Christopher Hoang、Mengye Ren

论文原文见 [arXiv](https://arxiv.org/abs/2510.05558)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.05558)

> 视频自监督学习长期面临语义识别与运动理解难以兼得的困境，现有方法或依赖外部光流网络，或牺牲语义精度换取运动感知。Midway Network 通过引入逆动力学推断帧间运动潜变量，并将其作为条件输入前向预测器，在自然视频中同时优化这两类表征。该架构采用层级化设计细化运动潜变量，实现了在分割与光流任务上的双重提升。其价值在于证明了内生运动建模的可行性，但缺乏与最新大规模预训练模型的直接对比，泛化边界尚存疑。

## 研究背景

视觉感知中，识别同一物体以建立对应关系，与追踪物体运动以学习其不变性，是相互依存的两个核心能力。传统自监督学习（SSL）方法多基于单帧图像，缺乏时间维度信息，导致模型难以捕捉动态变化；而专注于运动预测的方法往往将运动视为像素级对应任务，忽略了高层语义结构，造成表征在静态识别任务上的性能衰退。这种“非此即彼”的权衡构成了视频表征学习的主要瓶颈。

主流视频 SSL 路线中，掩码建模（如 VideoMAE）虽能捕捉时空结构，但像素级重建目标迫使模型学习不可预测的低级细节，限制了语义抽象能力；联合嵌入预测架构（JEPA）虽在潜在空间预测以规避噪声，但通常仅关注全局语义，未显式建模帧间变换的动力学机制。部分方法尝试引入外部光流网络作为监督信号，但这引入了额外的计算开销与误差累积，且限制了模型在未见场景中的泛化能力。Midway Network 的切入点在于，将决策论中的潜动力学建模迁移至视觉感知，通过内生推断运动潜变量，摆脱对外部光流网络的依赖，从而在自然视频中实现识别与运动的联合优化。

## 核心方法

### 方法参照系

本文问题可置于潜空间预测架构（JEPA）的框架下审视。标准 JEPA 流程包括：编码器提取特征、教师网络生成目标、预测器在潜在空间预测被掩码区域。本文的关键差异在于，预测器不仅依赖源特征，还显式引入由逆动力学推断的运动潜变量作为条件，且预测目标为密集特征而非全局向量。

### 逆动力学运动潜变量推断

Midway Network 的核心创新在于引入“Midway”路径，通过逆动力学模型推断帧间运动潜变量 $m$。该设计解决了传统方法中运动信息缺失或依赖外部网络的问题。具体而言，逆动力学 Transformer 接收源帧特征 $z_t^{[l]}$、目标帧特征 $z_{t+1}^{[l]}$ 及上一层级运动潜变量 $m^{[l+1]}$，输出当前层级的运动潜变量：

$$ m^{[l]} = \text{midway}(m^{[l+1]}, z_t^{[l]}, z_{t+1}^{[l]}) + m^{[l+1]} $$

此公式表明，运动潜变量是层级累积的，高层预测结果作为低层推断的条件，实现了从粗到细的运动建模。这种层级化设计借鉴了光流网络中利用中间估计细化预测的思路，使得模型能够捕捉多物体场景中的复杂运动模式，而非仅关注全局位移。

### 条件化密集前向预测

在获得运动潜变量后，前向动力学模型以源帧反向特征 $v_t^{[l]}$ 和运动潜变量 $m^{[l+1]}$ 为输入，预测目标帧的密集特征。预测损失定义为归一化特征间的均方误差：

$$ \mathcal{L}_{dyn}^{[l]} = \left\| \frac{\hat{z}_{t+1}^{[l]}}{\|\hat{z}_{t+1}^{[l]}\|_2} - \frac{z_{t+1}^{[l]}}{\|z_{t+1}^{[l]}\|_2} \right\|_2^2 $$

该损失函数强制预测器在潜在空间中精确重建目标帧的局部结构，而非全局语义。设计动机在于，密集预测目标迫使模型保留细粒度的时空结构信息，从而提升在分割等密集预测任务上的性能。此外，前向预测器中引入了门控单元，通过可学习的权重控制残差连接，防止模型退化为恒等映射，确保运动信息的有效传递。

## 实验评估

实验在 BDD100K 和 Walking Tours 两个自然视频数据集上进行预训练，评估语义分割（BDD100K, CityScapes, WT-Sem, ADE20K）和光流估计（FlyingThings, MPI-Sintel）任务。基线覆盖 DINO、iBOT、VideoMAE、CroCo v2 等主流 SSL 方法，但缺失 V-JEPA 2.1、SALT 等最新大规模预训练模型，限制了与当前 SOTA 的直接对比。

| 方法 | 架构 | BDD100K mIoU | CityScapes mIoU | FlyingThings EPE | MPI-Sintel EPE |
| :--- | :--- | :--- | :--- | :--- | :--- |
| PooDLe | R50 | 47.4 | 59.2 | 11.5 | 10.8 |
| CroCo v2 | ViT-S | 49.3 | 57.9 | 11.5 | 10.8 |
| Midway | ViT-S | 50.4 | 58.5 | 7.3 | 4.1 |
| Midway | ViT-B | 55.2 | 62.2 | 7.0 | 4.1 |

Midway Network 在 BDD100K 分割任务上以 50.4 mIoU 超越 PooDLe 的 47.4 mIoU，并在光流任务上显著优于 CroCo v2（7.3 vs 11.5 EPE），验证了内生运动建模的有效性。消融实验显示，移除反向网络导致 mIoU 从 31.5 降至 30.4，移除多层级细化导致 EPE 从 4.1 升至 5.2，表明层级化设计对性能提升具有实质性贡献。

评估边界方面，论文未报告置信区间，且预训练数据规模（BDD100K 70,000 视频）远小于 Kinetics 等大规模数据集，特征在动作识别任务上的泛化能力未经验证。代码已开源，但超参数细节（如门控单元初始化）未在正文中详述，可复现性依赖附录补充。

## 关联研究分析

从问题动机看，Midway Network 与 PooDLe 均旨在解决自然视频中多物体场景的表征学习，但 PooDLe 依赖外部监督光流网络提供运动信号，而 Midway Network 通过逆动力学内生推断运动潜变量。这一差异源于对运动信息获取方式的根本分歧：PooDLe 假设光流网络已提供高质量运动估计，而 Midway Network 认为运动信息应从视频数据中直接学习。前者在光流网络性能受限时易受误差累积影响，后者则通过层级化细化机制提升运动推断的鲁棒性，但代价是增加了模型复杂度。

从方法设计看，Midway Network 与 DynaMo 共享潜动力学建模的核心思想，但 DynaMo 聚焦于机器人控制任务，使用全局特征预测动作，而 Midway Network 针对视觉感知任务，采用密集特征预测。这一差异由任务特性决定：控制任务关注全局状态转移，而感知任务需保留局部结构信息。Midway Network 的密集预测目标使其在分割任务上表现优于 DynaMo，但在长程依赖建模上可能不如基于全局特征的模型，这一权衡在论文中未充分讨论。

## 总结

Midway Network 旨在解决视频自监督学习中语义识别与运动理解难以兼得的核心矛盾。其切入点在于将潜动力学建模引入视觉感知，通过逆动力学内生推断运动潜变量，摆脱对外部光流网络的依赖。方法上，该架构采用层级化设计细化运动潜变量，并以密集前向预测目标保留细粒度时空结构。实验证明，Midway Network 在 BDD100K 分割任务上达到 50.4 mIoU，在 FlyingThings 光流任务上达到 7.3 EPE，显著优于基线方法。然而，其预训练数据规模有限，且未与 V-JEPA 2.1 等最新大规模模型对比，特征在动作识别等高层任务上的泛化能力未经验证。当预训练数据规模扩大至 Kinetics 级别时，内生运动建模的优势是否仍能保持，论文未给出回答。
