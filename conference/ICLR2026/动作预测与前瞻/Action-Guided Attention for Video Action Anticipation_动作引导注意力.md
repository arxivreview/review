# ICLR2026最新论文 ｜Action-Guided Attention for Video Action Anticipation ｜动作引导注意力

作者：Tsung-Ming Tai、Sofia Casarin、Andrea Pilzer 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.01743)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.01743)

> 视频动作预测的核心困境在于，过去帧仅提供模糊的视觉线索，而标准视觉Transformer依赖像素级自注意力，极易被无关视觉杂乱误导，导致模型过拟合于表面特征而非潜在意图。现有方法虽在时序建模上取得进展，但缺乏对高层语义依赖的显式建模，难以在部分观察下实现稳健泛化。本文提出动作引导注意力（AGA），将模型自身的动作预测概率作为查询与键，替代像素特征以引导注意力聚焦于语义相关的历史时刻。该设计在EPIC-Kitchens-100上展现出优异的验证集到测试集泛化能力，但其性能仍落后于基于基础模型的最新探针方法，且未显式处理未来动作的多模态不确定性。

## 研究背景

动作预测要求从部分观察的视频流中推断未来动作标签，这与动作识别存在本质区别：识别关注“发生了什么”，而预测关注“将要发生什么”。在形式化定义上，给定观察序列 $X_{obs}$，模型需预测未来动作 $Y_{fut}$，通常以动词-名词对作为输出单元。由于未来信息不可见且同一过去观察可能对应多种未来结果，任务具有内在不确定性。视觉Transformer（ViT）已成为该领域主流范式，其自注意力机制能有效建模长程依赖，但在预测任务中，像素级Token的注意力权重易受视觉杂乱干扰，导致模型过度依赖当前帧的显式线索，而非挖掘历史动作间的语义关联。

早期研究以循环神经网络（RNN）为主线，如RULSTM通过双LSTM架构确立基线，但长序列误差累积问题显著。2021年，AVT引入因果注意力解码器，初步缓解遗忘问题；2023年，RAFTformer优化Transformer效率，提升预测精度。然而，这些方法均将注意力局限于像素特征空间，未能利用动作标签本身的高层语义信息。本文的切入点在于：既然预测目标是动作，那么动作预测概率本身应成为引导注意力聚焦历史相关时刻的语义信号，而非仅作为最终输出。

## 核心方法

### 方法参照系

标准视觉Transformer在动作预测中通常将视频帧编码为像素Token，通过自注意力机制在Token间计算相关性，以聚合时空信息。本文问题与该通用流程的关键差异在于：像素Token缺乏动作语义，导致注意力易被无关视觉细节分散，而动作预测概率天然蕴含高层语义，可作为更有效的注意力引导信号。

### 动作引导注意力机制

设计动机：解决标准自注意力在部分观察下因视觉杂乱导致的过拟合问题，通过语义级引导提升对历史相关时刻的聚焦能力。在标准点积注意力中，查询（Q）与键（K）由像素特征投影得到，值（V）为帧特征。本文创新在于，将过去S个时间步的动作预测概率 $\hat{y}_{t-S:t-1}$ 作为键，当前动作预测的指数移动平均（EMA） $\bar{y}_t$ 作为查询，帧特征 $e_t$ 作为值。具体地，键与查询通过多层感知机（MLP）投影至注意力空间：

$$K_t = E_K(\hat{y}_{t-S:t-1}), \quad Q_t = E_Q(\bar{y}_t)$$

其中 $\bar{y}_t = \alpha \bar{y}_{t-1} + (1-\alpha)\hat{y}_{t-1}$，$\alpha=0.8$。注意力输出通过多头机制聚合相关历史帧特征，再经前馈网络与残差连接处理。该设计使注意力权重直接反映动作间的语义依赖，而非像素相似性，从而抑制对视觉杂乱的过度关注。

### 自适应门控融合

设计动机：历史上下文与当前视觉证据的相关性随时间动态变化，需平衡二者贡献。在动作引导注意力输出 $\tilde{h}_t$ 与当前帧特征 $e_t$ 之间，引入门控向量 $g_t \in [0,1]^d$ 进行逐元素融合：

$$o_t = g_t \odot \tilde{h}_t + (1-g_t) \odot e_t$$

其中 $g_t = \sigma(\text{MLP}(\tilde{h}_t \parallel e_t))$，$\sigma$ 为Sigmoid函数。门控向量接近1时强调历史，接近0时侧重当前证据。最终预测 $\hat{y}_t = \text{Softmax}(\text{MLP}(o_t))$。该机制使模型能根据任务需求动态调整历史与当前的权重，避免固定融合策略在不确定场景下的失效。

## 实验评估

实验在EPIC-Kitchens-100（EK100）、EPIC-Kitchens-55（EK55）和EGTEA Gaze+三个基准上进行，仅使用RGB模态，指标为Mean Top-5 Recall（MT5R）或Top-1准确率。基线覆盖RULSTM、AVT、RAFTformer、S-GEAR等经典方法，但缺失2025-2026年基于V-JEPA的最新探针方法（如JFAA、TAP-JEPA），后者在EK100上MT5R达27.95%，显著高于本文。

| 方法 | 骨干 | EK100 Test Overall MT5R (%) |
| :--- | :--- | :--- |
| RAFTformer | MViTv2-16 | 17.6 |
| S-GEAR-2B | ViT-B x2 | 19.6 |
| AGA | Swin-B | 18.8 |

AGA在Swin-B骨干下Overall MT5R为18.8%，高于RAFTformer的17.6%，但低于S-GEAR-2B的19.6%。在Unseen类上，AGA达16.3%，优于RAFTformer的15.2%，表明语义引导对罕见动作的泛化更有效。消融实验显示，将标准注意力替换为动作引导注意力，MT5R从15.9%提升至18.2%；加入自适应门控后进一步提升至18.8%。EMA系数$\alpha=0.8$时性能最优，$\alpha=0$或1.0时性能下降，表明查询需平衡近期与历史预测。

评估边界方面，本文未报告置信区间，且未提供代码链接。超参数（如队列大小S=16、隐藏维度2048）在附录中给出，但GPU型号与训练时长未明确。EGTEA Gaze+标注稀疏，模型需依赖自身预测而非监督信号，该设置更贴近实际部署，但限制了与全监督方法的直接对比。

## 关联研究分析

从方法设计看，AGA与MemViT均使用记忆队列存储历史信息，但MemViT通过Token压缩扩展上下文窗口，而AGA将动作预测概率作为语义键，压缩的是语义空间而非像素空间。这一差异源于任务特性：动作预测中，动作标签的语义相关性比像素相似性更能指示未来意图，因此语义级引导比像素级压缩更契合任务本质。然而，AGA未处理早期预测错误被放大的风险，当初始预测偏差较大时，基于错误预测的注意力可能进一步偏离正确轨迹，论文未对此进行敏感性分析。

从问题动机看，AGA与AFFT均关注多模态融合，但AFFT通过GPT-2架构融合音频与光流，而AGA仅使用RGB，聚焦于单模态内的语义引导。这一选择反映了论文对“视觉杂乱”问题的特定理解：即使无额外模态，仅通过语义引导即可抑制过拟合。但这也暴露了边界：在遮挡或模糊场景下，RGB单模态的语义信号可能不足，此时多模态融合或3D几何先验（如MotionForesight的场景流）可能更具优势，论文未探索此方向。

## 总结

本文要解决的核心矛盾是视觉Transformer在动作预测中因像素级注意力导致的过拟合与泛化不足。切入点在于利用动作预测概率作为高层语义信号，替代像素特征引导注意力，从而聚焦历史相关时刻。方法上，AGA通过动作引导注意力与自适应门控，实现语义级历史聚合与动态融合。实验证明，在EK100上AGA的Overall MT5R达18.8%，Unseen类达16.3%，验证集到测试集差距小，表明抗过拟合能力。边界在于，其性能落后于基于V-JEPA探针的最新方法（如JFAA的27.95%），且未显式建模未来动作的多模态不确定性，仅通过门控隐含处理。当早期预测出现系统性偏差时，基于错误预测的注意力引导是否会导致误差累积，论文未给出回答。
