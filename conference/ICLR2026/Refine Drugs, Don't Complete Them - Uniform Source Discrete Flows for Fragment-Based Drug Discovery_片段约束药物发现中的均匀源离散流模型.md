# ICLR2026最新论文 ｜Refine Drugs, Don't Complete Them: Uniform Source Discrete Flows for Fragment-Based Drug Discovery ｜片段约束药物发现中的均匀源离散流模型

作者：Benno Kaech、Luis Wyss、Karsten Borgwardt 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_72597409)

> 片段基药物发现（FBDD）旨在保留特定骨架并修改周围区域以优化分子属性，但传统线性化表示破坏了化学子结构完整性，导致生成模型难以实现片段级精确控制。现有自回归与掩码扩散模型受限于顺序生成或逐步揭示机制，无法在采样过程中对全序列进行协调更新，且采样步长与序列长度强耦合。InVirtuoGen 提出基于均匀源的离散流模型，通过全位置并行细化解耦采样步长与序列长度，并引入遗传算法与近端策略优化混合框架。该模型在实用分子优化基准上刷新了状态最先进结果，但其片段约束生成性能因强制位置固定而受损，暴露出细化范式与硬约束间的内在张力。

## 研究背景

片段基药物发现依赖保留活性骨架或药效团，通过修改周围区域调节分子性质。这一过程要求生成模型具备对分子子结构的显式控制能力，但分子图的自然序列表示——简化分子输入行条目系统（SMILES）——通过深度优先遍历将图线性化，破坏了化学上有意义的子结构边界。为保留片段完整性，研究者采用顺序附着基片段嵌入（SAFE）框架，将分子分解为带连接点的片段块。然而，SAFE 表示中片段顺序通常由原始分子拓扑决定，引入了任意的位置偏置，与分子结构固有的无序性相悖。

主流序列生成模型在处理片段约束任务时面临根本性局限。自回归模型如 SAFE-GPT 按固定左到右顺序逐 token 生成，其顺序与分子结构无关，导致片段保留依赖前缀提示，缺乏全局协调性。掩码扩散模型如 GenMol 从全掩码输入开始逐步揭示 token，但训练目标仅计算掩码位置的误差，一旦 token 被揭示即视为固定，不再更新。这种“完成式”生成范式将采样步数限制在初始掩码 token 数量内，除非引入任意重掩码启发式，且无法在采样过程中对已生成片段进行协调修正。InVirtuoGen 的切入点在于将生成范式从“完成”转向“细化”，通过均匀源离散流模型实现全序列位置在每一步去噪中的同时更新，从而解耦采样步长与序列长度，并支持片段级控制。

## 核心方法

### 方法参照系

本文问题属于序列分子生成范畴，标准流程为自回归或掩码扩散模型在 SMILES 变体上训练。关键差异在于：标准流程中采样步长与序列长度强耦合，且生成过程为顺序或逐步揭示，无法实现全序列协调更新。InVirtuoGen 采用离散流模型框架，从均匀源分布向数据分布转化，实现全位置并行细化。

### 均匀源离散流与全位置细化

掩码扩散模型的核心失效在于训练目标仅关注掩码位置，导致已揭示 token 无法在后续步骤中修正，采样步数受限于序列长度。InVirtuoGen 采用 Gat et al. (2024) 的离散流框架，目标是将源分布 $X_0 \sim p$ 的样本转化为目标分布 $X_1 \sim q$ 的样本。训练数据由独立采样的插值对 $(X_0, X_1)$ 构成，选择线性调度器 $\kappa[t]$，概率路径定义为：

$$X_t = (1-t)X_0 + tX_1$$

采样时，每个 token $X_t[i]$ 根据离散时间马尔可夫更新规则演化，其中 $u_t$ 为概率速度，$h > 0$ 为步长。训练目标为：

$$\mathcal{L} = \sum_{i} w(t) \cdot \text{CrossEntropy}(p_{1|T}, X_1[i])$$

其中 $p_{1|T}$ 为模型预测，$w(t)$ 为时间依赖损失加权项，受 Sahoo et al. (2024) 启发，强调后期时间步的准确性。该设计使所有序列位置在每一步去噪中可能同时变化，实现全序列协调更新，解耦采样步长与序列长度。骨干网络采用扩散 Transformer，利用双向自注意力捕获片段间长程依赖。

### 片段表示与混合优化框架

片段约束生成要求固定特定位置，与全位置细化范式存在冲突。InVirtuoGen 基于修订 BRICS 算法分解分子，片段随机洗牌以消除顺序偏置，连接点标记为 $[i^*]$。对于片段约束任务，强制固定提示片段位置会损害性能，因此采用软提示机制，允许在输入分子邻域内受控探索。针对属性优化任务，提出遗传算法（GA）与近端策略优化（PPO）混合框架。GA 通过重组高分分子快速收敛，维护 Tanimoto 距离 $\ge 0.7$ 的分子词汇表，后代由替换父代片段形成。PPO 适配离散流策略，由于离散流无法直接计算序列对数概率，采用蒙特卡洛估计近似：

$$\log p(x) \approx \frac{1}{K} \sum_{k=1}^K \log p(x | x_t^{(k)})$$

其中 $t \sim U(0,1)$，$x_t^{(k)}$ 为部分噪声状态。奖励函数 $A = \sigma_r r - \bar{r} + \epsilon$ 引导梯度优化，结合自适应序列长度采样加速收敛。

## 实验评估

实验在四个任务上评估：从头生成、片段约束生成、目标属性优化（PMO 基准）和先导化合物优化。预训练数据为 ZINC 和 UniChem（约十亿分子），与 GenMol 和 SAFE-GPT 一致。基线覆盖 GenMol（掩码扩散）、SAFE-GPT（自回归）、REINVENT（强化学习）、MolGA（遗传算法）和 Genetic GFN。PMO 基准包含 23 个单目标优化任务，评估 top10 AUC 指标。

| 设置 | 方法 | Sum AUC-top10 |
| :--- | :--- | :--- |
| 有 ZINC250k 预筛 | InVirtuoGen | 18.993 (±0.219) |
| 有 ZINC250k 预筛 | GenMol | 18.362 |
| 有 ZINC250k 预筛 | f-RAG | 16.928 |
| 无预筛 | InVirtuoGen | 16.676 (±0.256) |
| 无预筛 | Genetic GFN | 16.213 |
| 无预筛 | Mol GA | 14.708 |
| 无预筛 | REINVENT | 14.184 |

InVirtuoGen 在两种设置下均取得最高总分，有预筛时较 GenMol 提升 0.631，无预筛时较 Genetic GFN 提升 0.463。消融实验表明，PPO 无预筛且无遗传算法的性能仍高于 REINFORCE，验证了梯度引导优于纯采样。

从头生成中，InVirtuoGen 在质量-多样性帕累托前沿上优于所有基线，时间粒度 $h=0.001$ 时增益最大。片段约束生成中，强制固定提示位置导致性能下降，论文承认该任务与细化范式“根本性矛盾”，仅提供附录结果。先导化合物优化中，InVirtuoGen 在 parp1 和 jak2 上取得显著更优对接分数，$\delta=0.6$ 严格约束下基线常失败，而本文方法仍有效。

评估边界方面，PMO 基准仅评估单目标优化，未涵盖多目标帕累托前沿。片段约束生成缺乏定量对比，仅定性描述性能受损。可复现性方面，论文提供 GitHub 链接和预训练检查点，但 GenMol 对比基于已发布数值，因 NVIDIA 许可限制无法直接运行。

## 关联研究分析

从问题动机看，InVirtuoGen 与 GenMol 同属片段 SMILES 生成，但 GenMol 采用掩码扩散，训练目标仅计算掩码位置误差，导致已揭示 token 无法修正，采样步数受限于序列长度。InVirtuoGen 的均匀源离散流实现全位置并行细化，解耦采样步长与序列长度，使模型能在采样过程中协调更新所有片段。这一差异源于任务特性：片段约束生成要求保留特定子结构，而掩码扩散的“完成”范式一旦揭示 token 即固定，无法在后续步骤中调整片段连接或属性，导致片段保留依赖前缀提示，缺乏全局协调性。InVirtuoGen 的细化范式允许在采样过程中修正片段连接，但强制固定提示位置会破坏全序列协调更新，暴露出细化范式与硬约束间的内在张力。

从方法设计看，InVirtuoGen 与 SAFE-GPT 同基于片段表示，但 SAFE-GPT 采用自回归模型，按固定左到右顺序生成，顺序与分子结构无关，引入任意位置偏置。InVirtuoGen 随机洗牌片段，消除顺序偏置，并采用扩散 Transformer 双向自注意力捕获片段间长程依赖。这一差异源于表示特性：自回归模型的顺序生成无法利用双向信息，而分子结构固有无序性要求表示不依赖任意顺序。InVirtuoGen 的随机洗牌与双向注意力组合，使模型能更准确地建模片段间相互作用，但随机洗牌可能破坏片段间的局部连接信息，论文未探讨这一权衡。

## 总结

InVirtuoGen 解决的核心矛盾是片段约束生成中全序列协调更新与采样步长解耦的需求，现有自回归和掩码扩散模型因顺序生成或逐步揭示机制无法实现。本文抓住均匀源离散流的全位置并行细化特性，通过解耦采样步长与序列长度，实现片段级控制与属性优化的统一。实验证明在 PMO 基准上，有预筛时 Sum AUC-top10 达 18.993，无预筛时达 16.676，均超越所有基线。边界在于片段约束生成中强制固定提示位置导致性能下降，论文承认该任务与细化范式“根本性矛盾”，仅提供附录结果，未提供定量对比。当片段约束强度增加时，全位置细化范式能否通过软约束机制恢复性能，论文未给出回答。
