# ICLR2026最新论文 ｜MIXED-CURVATURE TREE-SLICED WASSERSTEIN DISTANCE ｜混合曲率树切片沃瑟斯坦距离

研究机构：新加坡国立大学

作者：Duy-Tung Pham、Viet-Hoang Tran、Thieu Vo 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_12103780)

> 混合曲率空间旨在通过组合欧氏、球面与双曲分量来更精确地拟合复杂数据的内在结构，但现有分布比较方法如KL散度缺乏度量性质，而标准沃瑟斯坦距离计算复杂度呈超立方级增长。本文切入点在于利用树状结构的几何丰富性替代线性投影，构建混合曲率树系统以解决异构几何下的分布比较难题。通过定义混合曲率Radon变换并推导沃瑟斯坦距离的闭式解，该方法实现了高效且保真的分布匹配。尽管在生成模型与自监督学习中展现了优于单一曲率基线的性能，但其闭式解的近似误差在极端曲率下的稳定性仍存疑。

## 研究背景

当数据同时包含周期性方向特征与层级结构时，单一曲率空间无法同时低失真地编码这两类几何属性。混合曲率空间（Mixed-Curvature Spaces, MCS）定义为欧氏、球面与双曲分量的笛卡尔积，旨在通过异构几何的组合提升表示灵活性。然而，在MCS中比较概率分布面临根本性挑战：KL散度不是真度量且无法处理支撑集不相交的情况，而标准最优传输（Optimal Transport, OT）虽然几何自然，但其计算复杂度随支撑点数量呈超立方增长，严重限制了可扩展性。

切片沃瑟斯坦（Sliced Wasserstein, SW）距离通过将高维测度投影至一维子空间来获得闭式解，从而降低计算成本。然而，一维线性投影无法捕获弯曲空间中的完整几何与拓扑复杂度。树切片沃瑟斯坦（Tree-Sliced Wasserstein, TSW）框架通过用树度量系统替代线性投影，在保持闭式解的同时提供了更丰富的几何结构。尽管TSW在欧氏或单一曲率空间中已有应用，但其在混合曲率潜在空间中的潜力尚未被充分探索，因为此类设置需要同时结合异构几何属性，而现有的树投影机制无法直接处理不同曲率分量间的交互。

## 核心方法

### 方法参照系

本文问题属于度量学习中的分布距离计算，与标准流程的关键差异在于：不训练参数化嵌入网络，而是定义一种无参数的几何距离度量，该度量需同时尊重混合曲率空间中各分量的异质性。

### 混合曲率树系统构建

设计动机在于解决线性投影在弯曲空间中丢失拓扑信息的问题。本文首先定义混合曲率树（Mixed-Curvature Trees, MCT），其由从公共根节点 $x$ 发出的 $k$ 条测地射线组成，每条射线对应混合空间中的一个方向。对于树中的两点 $a=(t_i, r_{x[y_i]})$ 和 $b=(t_j, r_{x[y_j]})$，树度量 $d_T$ 定义为：

$$
d_T(a, b) = \begin{cases} |t_i - t_j| & \text{if } i = j \\ t_i + t_j & \text{if } i \neq j \end{cases}
$$

该公式表明，同射线上的点距离等于沿射线的测地距离差，不同射线上的点距离则通过根节点连接，从而将不同曲率区域的几何结构统一在树度量下。

### 混合曲率Radon变换与MCTSW距离

设计动机在于实现分布比较的高效闭式解。本文定义了混合曲率Radon变换，将分布 $\mu$ 投影到树系统上。投影函数将点 $z$ 映射到其在各射线上的坐标 $d_M(z, x)$，分裂映射 $\alpha$ 通过测地距离的softmax分配质量：

$$
\alpha(z, T) = \left( \frac{e^{-d_M(z, r_{x[y_1]})}}{\sum_{l=1}^k e^{-d_M(z, r_{x[y_l]})}}, \dots, \frac{e^{-d_M(z, r_{x[y_k]})}}{\sum_{l=1}^k e^{-d_M(z, r_{x[y_l]})}} \right)
$$

基于此，MCTSW距离定义为在树度量空间上对Radon变换后的分布计算1-沃瑟斯坦距离的期望：

$$
\text{MCTSW}(\mu, \nu) = \int_{\mathcal{T}_k^M} W_{d_T, 1}(\mathcal{R}_\alpha \mu, \mathcal{R}_\alpha \nu) \, d\sigma(T)
$$

该公式允许质量通过跨越多个子空间的树进行传输，从而联合尊重不同的几何结构，且由于树度量下沃瑟斯坦距离具有闭式解，计算复杂度显著降低。

## 实验评估

实验在梯度流、变分自编码器（VAE）和图自监督学习三个设置中进行，基线包括环境空间SW、乘积TSW和乘积SW。在Cora节点分类任务中，MCTSW-SSGE取得了79.86±0.45的准确率，优于E-TSW-SSGE的77.85±0.32和H-TSW-SSGE的75.10±0.22，但低于领域综述中提到的Hypformer+PLFC的85.7±0.2，这主要归因于本文采用自监督预训练加线性探针的协议，而非端到端分类。

| 方法 | Cora准确率 (%) | CIFAR10 Test BCE |
|---|---|---|
| SSGE | 79.55±0.35 | - |
| E-TSW-SSGE | 77.85±0.32 | - |
| H-TSW-SSGE | 75.10±0.22 | - |
| MCTSW-SSGE | 79.86±0.45 | - |
| SWAE | - | 0.6043±0.0005 |
| STSW-VAE | - | 0.6026±0.0009 |
| HSW-VAE | - | 0.6012±0.0006 |
| MCTSW-VAE | - | 0.6000±0.0002 |

在CIFAR10 VAE任务中，MCTSW-VAE的Test BCE为0.6000±0.0002，优于HSW-VAE的0.6012±0.0006和SWAE的0.6043±0.0005，表明混合曲率表示在生成质量上优于单一曲率替代方案。消融实验显示，当曲率幅度 $K$ 为4且子空间数 $m$ 为32时，性能最佳（79.9±0.5），而 $K$ 增大至8时性能下降至77.3±0.5，表明过大的曲率可能引入数值不稳定或优化困难。

评估边界方面，论文未报告计算效率的具体对比数据，仅定性声称高效；评估协议局限于自监督预训练后的线性探针，未涵盖端到端微调场景；代码未公开，可复现性依赖于附录中的实现细节。

## 关联研究分析

从问题动机看，本文与双曲度量学习中的嵌入方法（如Poincaré Embeddings）存在根本差异：后者旨在通过优化参数将数据映射到低维双曲空间以最小化嵌入失真，而本文不训练嵌入，而是定义分布间的几何距离。这种差异源于任务目标的不同：嵌入方法关注单点表示的保真度，而MCTSW关注整体分布结构的匹配。然而，本文未与双曲GNN或双曲Transformer等架构进行直接对比，这可能掩盖了度量方法与参数化架构在特定任务上的性能差距。

从方法设计看，本文与Tree-Sliced Wasserstein (TSW) 框架的关系是扩展而非替代。TSW在欧氏或单一曲率空间中通过树投影捕获拓扑结构，而MCTSW将这一机制推广至混合曲率空间，通过分裂映射处理异构几何的质量分配。关键差异在于，MCTSW的树系统由不同曲率分量的测地射线组成，其Radon变换需处理不同曲率下的距离计算。这种设计使得MCTSW能够同时利用双曲空间的层级编码能力和球面空间的周期性特征，但论文未探讨当数据主要具有单一几何特性时，混合曲率是否带来不必要的计算开销或性能损失。

## 总结

本文要解决的核心矛盾是混合曲率空间中分布比较的计算效率与几何保真度之间的冲突。现有方法如KL散度缺乏度量性质，标准OT计算复杂度高，而线性投影的SW距离无法捕获弯曲空间的拓扑结构。本文抓住的切入点是树状结构的几何丰富性，通过构建混合曲率树系统并定义Radon变换，实现了沃瑟斯坦距离的闭式解。实验证明，MCTSW在Cora自监督学习中的准确率为79.86±0.45，在CIFAR10 VAE中的Test BCE为0.6000±0.0002，均优于单一曲率基线。本文的边界在于其闭式解依赖于树系统的采样，当曲率幅度增大时性能出现下降，且评估协议局限于自监督预训练场景。当数据分布的支撑集高度分散且曲率异质性极强时，树投影的近似误差是否会导致距离度量的失真，论文未给出回答。
