# ICLR2026最新论文 ｜ACTIONS AS LANGUAGE: FINE-TUNING VLMS INTO VLAS WITHOUT CATASTROPHIC FORGETTING ｜动作即语言：VLM2VLA 微调范式

研究机构：美国普林斯顿大学

作者：Asher Hancock、Xindi Wu、Lihan Zha 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_24383278)

> 视觉-语言-动作模型（Vision-Language-Action, VLA）微调面临的核心矛盾是：习得低层控制能力往往以牺牲视觉-语言模型（Vision-Language Model, VLM）的通用世界知识为代价，导致策略在分布外任务中泛化失效。现有主流方案依赖全量参数微调或昂贵的互联网规模共训练来缓解灾难性遗忘，但前者加剧过拟合，后者计算成本高昂且需精细调节数据混合比。VLM2VLA 的切入点在于识别出动作空间与预训练语料间的分布失配是遗忘的根源，通过将低层动作重新表征为自然语言文本，使微调数据直接对齐 VLM 的预训练分布，从而仅使用低秩适应（Low-Rank Adaptation, LoRA）即可实现知识保留。该范式在保留 85% 以上 VQA 性能的同时实现了具有竞争力的真实世界操作，但其自回归生成带来的 6.1 秒中位推理延迟是否限制了实时闭环控制的可行性，仍需进一步验证。

## 研究背景

当 VLM 被直接微调为机器人策略时，其原本用于理解图像和文本的参数权重会被机器人遥操作数据覆盖。这种覆盖导致模型在遇到训练集之外的物体或指令时，无法调用预训练阶段习得的语义推理能力，即发生灾难性遗忘。为了解决这一遗忘问题，研究者通常引入共训练机制，即在微调过程中混合非机器人数据（如视觉问答、图像描述）来正则化模型，防止其过度拟合到狭窄的控制任务上。然而，共训练需要精心调节机器人数据与网络数据的比例，这一超参数的搜索空间巨大，且每次调整都需要昂贵的重新训练和真实世界评估，使得该方案难以在资源受限的研究环境中复现。

VLA 领域的研究重心正从“能否执行”转向“如何稳定且泛化地执行”。早期工作如 RT-2 和 OpenVLA 确立了基于离散 Token 的自回归范式，但全量微调不可避免地破坏了 VLM 的底层表征。π0 等后续工作引入流匹配动作专家以解决连续动作生成的平滑性问题，但新增的随机初始化参数同样可能腐蚀预训练表示。VLM2VLA 针对这一共性瓶颈，提出了一种数据层面的解决方案：不修改架构，不增加参数，而是改变动作的表示形式，使其落入 VLM 已有的语言分布中。这一思路将问题从“如何保护参数”转化为“如何对齐数据”，为轻量化部署提供了一条新路径。

## 核心方法

### 方法参照系

VLA 的标准训练流程是将 VLM 骨干与动作头结合，通过全量微调或共训练习得从观测到动作的映射。本文的关键差异在于摒弃了显式动作头（如扩散或流匹配模块）和全量参数更新，转而将动作预测重构为纯文本生成任务，并仅通过 LoRA 适配 VLM 的注意力层。

### 层级化语言动作表征

传统 VLA 将连续动作向量映射为离散 Token 或独立向量，导致动作分布与 VLM 预训练的语言分布存在显著失配。VLM2VLA 将动作预测分解为三个层级的文本生成过程：高层子任务预测 $l_i$、中层运动规划 $m_i$ 和低层动作块 $\bar{a}_i$。其核心分布建模公式为：

$$ p_\theta(\bar{a}_i, m_i, l_i | \bar{o}_i, L) = p_\theta(\bar{a}_i | m_i, l_i, \bar{o}_i) p_\theta(m_i | l_i, \bar{o}_i) p_\theta(l_i | \bar{o}_i, L) $$

该公式表明，模型通过自回归方式依次生成子任务描述、空间运动指令和具体的数值动作序列。设计动机在于，自然语言描述（如“向左移动 4.2 厘米”）能直接激活 VLM 对数值幅度和空间方向的固有理解，避免了任意 Token 映射带来的语义断裂。这种表征使得 LoRA 微调时的梯度更新方向与预训练分布一致，从而最小化对骨干权重的扰动。

### 数据重标注与 LoRA 训练

为了获取上述层级化语言数据，VLM2VLA 利用 Gemini 2.5 对原始遥操作轨迹 $D_{rob}$ 进行自动重标注，生成包含子任务、运动计划和动作块的自然语言数据集 $D_{lan}$。训练阶段，仅对 Gemma-3-12B-IT 的注意力层应用 LoRA，冻结其余参数。这一设计解决了全量微调导致的灾难性遗忘，因为 LoRA 的低秩约束限制了参数更新幅度，而语言化的动作数据确保了更新方向不偏离预训练流形。实验证据显示，语言化动作在 VLM 骨干下的对数概率密度显著高于任意 Token 映射，证实了分布对齐的有效性。

## 实验评估

实验基于 Bridgev2 数据集构建，对比基线包括 OpenVLA、ECoT、MolmoAct 和 π0.5。OpenVLA 和 ECoT 代表了基于 Token 的自回归路线，MolmoAct 和 π0.5 代表了共训练路线。VLM2VLA 在 VQA 基准上保留了 Gemma-3-12B-IT 的大部分性能，而 OpenVLA 和 ECoT 在多个基准上性能归零或大幅下降，表明全量微调严重损害了多模态理解能力。

| 方法 | MMMU | MMStar | MME | OCRBench |
|---|---|---|---|---|
| Gemma-3-12B-IT | 46.0 | 46.3 | 1456.6 | 70.2 |
| VLM2VLA | 42.7 | 48.0 | 1391.7 | 63.9 |
| OpenVLA | 26.3 | 0 | 0 | 0 |
| ECoT | 26.6 | 0 | 0 | 0 |

在真实世界操作任务中，VLM2VLA 在分布外（OOD）任务上表现优于 OpenVLA 和 ECoT。例如，在多语言指令任务“Pick Up - T”中，VLM2VLA 成功识别并抓取目标物体，而 ECoT 仅依赖启发式规则。消融实验显示，将动作映射为 Gemma-3 的最不可能 Token（VLM2VLA-AT）虽能保留 VQA 性能，但在复杂 OOD 任务上的成功率仅为 VLM2VLA 的一半，证明语言化动作表征对策略泛化至关重要。

评估边界方面，论文未报告 LIBERO 等标准仿真基准成绩，无法与 SimpleVLA-RL 等 SOTA 方法直接比较。推理延迟中位数为 6.1 秒，远高于实时控制所需的 10Hz 以上频率，限制了其在动态环境中的应用。代码未公开，数据重标注流水线依赖 Gemini 2.5，复现成本较高。

## 关联研究分析

从问题动机看，VLM2VLA 与 π0 等流匹配方法均旨在解决动作生成的平滑性与精度问题，但路径截然不同。π0 通过引入独立的动作专家模块处理连续动作，而 VLM2VLA 坚持在 VLM 内部通过语言生成动作。这种差异源于对“知识保留”的不同理解：π0 认为动作精度优先，可通过新增参数实现；VLM2VLA 认为通用知识优先，必须避免任何架构修改。VLM2VLA 的局限在于，语言化动作的离散性可能无法表达极高精度的连续控制，这在需要毫米级精度的任务中可能成为瓶颈。

从方法设计看，VLM2VLA 与 ECoT 共享层级化推理结构，但 ECoT 的动作输出仍为 Token，而 VLM2VLA 的动作输出为文本。这一差异导致 ECoT 在微调后完全丧失 VQA 能力，而 VLM2VLA 保留了大部分能力。根源在于 ECoT 的全量微调破坏了 VLM 的语义空间，而 VLM2VLA 的 LoRA 加语言对齐策略保护了该空间。然而，VLM2VLA 依赖 Gemini 进行数据重标注，引入了外部模型的偏差，这种偏差是否会影响策略的鲁棒性，论文未给出回答。

## 总结

VLM2VLA 要解决的核心矛盾是 VLA 微调中控制能力习得与通用知识保留之间的冲突。现有方法通过全量微调或共训练缓解遗忘，但前者加剧过拟合，后者成本高昂。VLM2VLA 抓住的切入点是动作空间与预训练语料的分布失配，通过将动作表征为自然语言，使 LoRA 微调在保留 VLM 知识的同时习得控制策略。实验证明，该方法在 VQA 基准上保留了 85% 以上的性能，并在真实世界 OOD 任务上优于 OpenVLA 和 ECoT。其边界在于 6.1 秒的推理延迟限制了实时性，且缺乏标准仿真基准的对比。当任务要求毫秒级响应时，语言化动作的自回归生成延迟是否构成不可逾越的障碍，论文未给出回答。
