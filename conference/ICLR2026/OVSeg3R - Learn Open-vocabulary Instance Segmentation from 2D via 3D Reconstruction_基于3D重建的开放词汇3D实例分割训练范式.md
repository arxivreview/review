> 3D实例分割旨在从点云中定位并识别物体实例，但高质量3D标注成本极高，导致模型泛化能力受限。现有方法要么依赖昂贵的深度相机采集，要么在推理时通过启发式规则合并2D掩码，前者数据获取难，后者鲁棒性差且无法提升原生3D感知能力。OVSeg3R利用3D重建模型自动生成训练场景与2D-3D对应关系，将2D开放词汇掩码提升为3D视图级伪标签，通过端到端训练实现开放词汇分割。该方案在ScanNet200上取得24.6 mAP，显著优于现有开放词汇基线，但其性能上限受限于重建模型的几何平滑特性，且未验证在动态场景下的时间一致性。

## 研究背景

理解本文需厘清三个概念的因果链条。3D实例分割要求模型输出每个点的实例标识与语义标签，其核心瓶颈在于3D标注的稀缺性。为缓解此问题，研究者引入2D视觉-语言模型（VLM）作为语义先验，但2D图像特征投影至3D时存在视角依赖与遮挡歧义，即2D-3D模态差异。解决模态差异通常依赖多视图几何对齐，而获取多视图几何数据传统上依赖深度相机，这又回到了标注成本高的原点。

3D重建技术的突破改变了这一僵局。MASt3R-SLAM等模型能从普通视频生成带2D-3D对应关系的点云，使得“重建即数据”成为可能。然而，直接利用重建数据训练面临两个新挑战：一是重建点云往往过度平滑，丢失几何细节；二是2D掩码独立估计，缺乏跨视图关联，直接拼接会产生大量重复或冲突的伪标签。OVSeg3R的切入点在于，不将2D模型视为推理时的外挂，而是将其作为训练时的监督信号源，通过特定的分区与聚类策略，将2D先验内化为3D模型的感知能力。

## 核心方法

### 方法参照系

OVSeg3R基于SegDINO3D架构，该架构通过融合2D图像级与对象级特征增强3D点云表示。与SegDINO3D依赖人工标注ScanNet数据不同，OVSeg3R将数据源替换为3D重建生成的点云，并将分类头改为文本特征相似度计算，从而在训练阶段引入开放词汇能力。

### 视图级实例分区（VIP）

传统方法将2D掩码直接提升为场景级3D标注，但每个视图仅覆盖场景局部，直接监督会导致视窗外的预测被错误惩罚为假阳性。VIP算法根据物体查询（Object Query）在视口中的可见性，将场景级预测分配至对应视图，并截断掩码仅保留该视图可见区域。其核心逻辑可表述为：对于第 $v$ 个视图，仅当物体查询 $q$ 对应的超点包含来自视图 $v$ 的重建点时，才将 $q$ 的预测掩码 $M_q$ 截断为 $M_q \cap V_v$ 用于监督，其中 $V_v$ 为视图 $v$ 的可见点集。这一设计消除了跨视图标注重复，避免了因部分监督导致的训练不稳定。

### 2D实例边界感知超点（IBSp）

主流3D分割方法基于几何连续性构建超点，但重建点云的过度平滑特性导致几何不显著物体（如墙上的画）被聚类进背景超点。IBSp在超点聚类过程中引入2D实例掩码作为约束，防止不同实例的点被错误聚类。其约束条件可形式化为：若两个3D点 $p_i, p_j$ 在任一视口中的2D投影属于不同实例掩码，则禁止 $p_i, p_j$ 归入同一超点，即 $Cluster(p_i) \neq Cluster(p_j) \iff \exists v, Mask_v(proj_v(p_i)) \neq Mask_v(proj_v(p_j))$。该机制确保了即使几何细节丢失，语义边界仍能引导超点划分，为后续实例分割提供准确的几何基底。

## 实验评估

OVSeg3R在ScanNet200验证集上评估，基线涵盖封闭词汇（Mask3D, SegDINO3D）与开放词汇（OpenMask3D, Any3DIS）两类方法。开放词汇设置下，OVSeg3R取得24.6 mAP，显著领先于Any3DIS的19.1 mAP和OpenMask3D的12.7 mAP。在标准开放词汇设置（仅用ScanNetv2的20类训练，评估200类）中，OVSeg3R在Novel类上取得24.2 mAP，较Any3DIS的16.5 mAP提升7.7个点，而在Base类上仅提升0.0个点，表明性能增益主要源于对未见类别的泛化能力。

| 方法 | 设置 | All mAP | Head mAP | Tail mAP | Novel mAP | Base mAP |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Any3DIS | Open | 19.1 | - | - | 16.5 | - |
| OpenMask3D | Open | 12.7 | - | - | 11.9 | - |
| OVSeg3R | Open | 24.6 | 27.8 | 26.4 | 24.2 | 25.8 |

消融实验显示，VIP与IBSp对训练稳定性至关重要。移除VIP后，mAP从24.6降至18.4，Novel类mAP从24.2降至16.2，证实了部分监督导致的假阳性惩罚对泛化能力的负面影响。移除IBSp后，mAP降至23.9，Novel类mAP降至23.0，表明几何平滑导致的超点错误聚类主要影响细粒度实例区分。此外，使用100% ScanNet3R-MSLAM重建数据优于100% VGGT数据，说明重建模型的选择对最终性能有显著影响。

| 变体 | VIP | IBSp | 重建数据 | mAP | Novel mAP |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Full | ✓ | ✓ | 100% MSLAM | 24.6 | 24.2 |
| w/o VIP | ✗ | ✓ | 100% MSLAM | 18.4 | 16.2 |
| w/o IBSp | ✓ | ✗ | 100% MSLAM | 23.9 | 23.0 |
| VGGT | ✓ | ✓ | 100% VGGT | 23.6 | 22.0 |

评估边界方面，论文未报告计算效率指标，且所有实验基于静态室内场景。代码未公开，超参数细节（如阈值 $\tau$ 的选择）未在正文中详述，可复现性受限。此外，论文未对比3DGS路线方法（如Ilov3Splat），无法直接评估点云表示与高斯表示在开放词汇任务上的优劣。

## 关联研究分析

从问题动机看，OVSeg3R与OpenMask3D均旨在利用2D先验解决3D标注稀缺，但路径截然不同。OpenMask3D采用“先3D分割后2D分类”的解耦范式，其3D模型仅学习类别无关掩码，语义识别完全依赖推理时的2D投影。这种设计导致3D模型缺乏对未见类别的几何感知能力，在遮挡或视角变化时易失效。OVSeg3R则通过端到端训练，将2D语义信息内化为3D特征，使模型具备原生开放词汇能力。这一差异的根源在于对“2D-3D对齐”发生时刻的选择：推理时对齐灵活但脆弱，训练时对齐稳定但依赖伪标签质量。

从方法设计看，OVSeg3R与SegDINO3D共享骨干网络，但数据引擎不同。SegDINO3D依赖高质量人工标注点云，其超点构建基于精确几何；OVSeg3R依赖重建点云，其几何噪声迫使引入IBSp。这一对比揭示了重建数据作为训练源的代价：虽然降低了数据获取成本，但引入了几何平滑问题，需额外机制补偿。论文未探讨重建质量与分割性能的非线性关系，即当重建模型精度进一步提升时，IBSp的边际收益是否递减，这一盲区限制了该方法在更高精度重建场景下的适用性评估。

## 总结

OVSeg3R解决了3D开放词汇分割中数据获取成本与原生3D感知能力缺失的矛盾。其切入点在于利用3D重建模型自动生成带对应关系的训练数据，并通过VIP与IBSp机制克服重建数据的噪声与部分监督缺陷。实验证明，该方案在ScanNet200开放词汇设置下取得24.6 mAP，Novel类mAP提升7.7个点，验证了端到端训练优于推理时投影的范式。然而，其性能受限于重建模型的几何平滑特性，且未验证在动态场景或不同重建质量下的鲁棒性。当重建点云的几何细节进一步退化时，IBSp的约束是否足以维持实例边界的准确性，论文未给出回答。
