# ICLR2026最新论文 ｜ATTRIBUTING RESPONSE TO CONTEXT: A - JENSEN–SHANNON DIVERGENCE DRIVEN MECHANIS - TIC STUDY OF CONTEXT ATTRIBUTION IN RETRIEVAL AUGMENTED GENERATION ｜基于Jensen-Shannon散度的RAG上下文归因与机制解析

研究机构：新加坡南洋理工大学、英国伦敦大学学院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_70465783)

> 检索增强生成（RAG）系统依赖外部上下文缓解幻觉，但验证生成内容是否真正 grounded 于特定上下文片段（Context Attribution）仍是难题。现有方法或依赖昂贵的人工标注，或需进行模型微调与梯度计算，导致计算开销巨大且难以集成。本文提出 ARC-JSD，一种基于推理时 Jensen-Shannon 散度（JSD）的归因方法，无需微调或反向传播即可定位关键上下文句子。该方法在准确率上较基线提升约 10.7%，计算速度提升 3 倍，并进一步揭示了负责归因的内部注意力头与 MLP 层，为通过操纵内部组件降低幻觉率提供了路径。其价值在于实现了归因效率与机制可解释性的统一，但白盒机制分析结论在黑盒 API 场景下的迁移性存疑。

## 研究背景

当 RAG 模型生成回答时，用户需要确认该回答是否由检索到的文档支撑，而非模型参数中的固有知识。这一过程称为上下文归因（Context Attribution）。传统归因方法分为两类：一类是“佐证型”（Corroborative），评估引用是否支持回答；另一类是“贡献型”（Contributive），识别引用是否导致回答生成。贡献型归因更贴近因果机制，但现有实现如 Cohen-Wang et al. (2024) 需采集数百次概率消融样本训练线性代理模型，Chuang et al. (2025) 则依赖直接偏好优化（DPO）微调，两者均存在高计算成本或训练依赖，阻碍了在大规模 RAG 系统中的实时部署。

RAG 安全与隐私研究已确立外部知识库为主要攻击面，但归因任务的核心矛盾在于：如何在无梯度、无微调条件下，高效量化上下文句子对生成分布的因果影响。主流推理时归因方法（如 ContextCite）通过线性代理模型拟合上下文掩码与生成概率的关系，但线性假设可能平滑掉非线性依赖，且需大量前向调用。本文切入点在于利用 JSD 的对称、有界与尺度无关特性，直接量化全上下文与单句消融上下文下的响应分布差异，替代线性代理模型，从而在保持归因精度的同时消除训练开销。

## 核心方法

### 方法参照系

本文问题属于推理时贡献型归因，参照系为 Cohen-Wang et al. (2024) 的线性代理模型框架。该框架通过采集上下文消融样本训练线性模型预测生成概率，但需数百次前向调用且假设线性关系。本文关键差异在于摒弃代理模型，直接计算分布散度，将归因转化为分布差异的排序问题。

### JSD 驱动的上下文句子归因

传统方法在计算上下文重要性时，依赖梯度或代理模型拟合，导致计算瓶颈。本文创新在于直接计算全上下文 $C$ 与单句消融上下文 $C_{\text{ABLATE}(c_i)}$ 下响应 $R$ 的概率分布差异，使用 JSD 作为度量：

$$ \text{JSD}(c_i) = \sum_{j=1}^{|R|} \text{JSD}\left( P_{\text{LM}}(\cdot|C, Q) \parallel P_{\text{LM}}(\cdot|C_{\text{ABLATE}(c_i)}, Q) \right) $$

该公式聚合了响应中每个 token 在消融句子 $c_i$ 后的分布散度。JSD 的有界性（$[0, \log 2]$）解决了 KL 散度在零概率处爆炸的问题，尺度无关性允许跨层比较。通过选取 $\text{JSD}(c_i)$ 最大的句子作为 Top-1 归因结果，本文避免了线性代理模型对非线性关系的平滑，直接捕捉分布的实际偏移，实现了无需训练的高效归因。

### 基于 Logit Lens 的内部组件定位

在定位关键上下文句子后，需进一步解析模型内部如何执行归因。本文结合 Logit Lens 将中间表示投影至词表空间，计算注意力头 $\mathbf{a}_{[\ell,h]}^i$ 与 MLP 输出 $\mathbf{m}_{[\ell]}^i$ 在消融 Top-1 句子前后的 JSD 差异：

$$ \text{JSD}(\text{head}_{\ell,h}) = \text{JSD}\left( P_{\text{LM}}(\cdot|C, Q) \parallel P_{\text{LM}}(\cdot|C_{\text{ABLATE}(c_{\text{top-1}})}, Q) \right)_{\text{via } \mathbf{a}_{[\ell,h]}^i} $$

此设计动机在于解决现有机制研究仅关注幻觉检测或复制粘贴检索的局限。通过 JSD 评分作为置信门控，本文识别出对归因贡献最大的注意力头与 MLP 层，揭示了模型如何通过特定层级的参数化知识整合检索信息，为后续通过操纵这些组件控制 RAG 行为提供了机制基础。

## 实验评估

实验在 TyDi QA、Hotpot QA 和 MuSiQue 三个问答基准上进行，使用 Qwen2-1.5B/7B-IT 和 Gemma2-2B/9B-IT 四个指令微调 LLM。基线包括 ALTI-Logit（logit 差异）、MIRAGE（梯度归因）和 ContextCite（线性代理）。ARC-JSD 在计算-准确率权衡上全面优于基线，平均归因准确率提升 10.7%，计算速度提升 3 倍。ContextCite 在上下文句子数 $|C| > 32$ 时效率较高，但准确率仍低于 ARC-JSD，表明线性代理在捕捉非线性依赖上的局限。

| 方法 | 理论 FLOPs | 相对 ARC-JSD 减速比 |
| :--- | :--- | :--- |
| ALTI-Logit | $2PT|C||R|L$ | $|R|L/|C|$ |
| MIRAGE | $4PT|C|(2|C|+1)$ | $4 + 2/|C|$ |
| ContextCite (32 calls) | $2PT \times 32^2$ | $(32/|C|)^2$ |
| ContextCite (256 calls) | $2PT \times 256^2$ | $(256/|C|)^2$ |
| ARC-JSD | $2PT|C|^2$ | 1 |

消融实验显示，JSD 比 KL、Wasserstein、TV 和 MMD 更优，因 KL 在深层零概率处爆炸，TV 过于粗糙。机制分析中，JSD 定位的 Top-10 注意力头与语义增益指标高度相关（Spearman $\rho$ 显著），验证了 JSD 捕捉的是真实的检索信号。在 Hotpot QA 上，使用 JSD 评分门控 Top-5 注意力头与 MLP，将幻觉率从 13.4% 降至 8.2%，而事实 F1 保持 75.9，随机门控则导致 F1 降至 69.4，证明定位组件的有效性。

评估边界方面，实验仅使用句子级归因准确率，未评估短语级或子句级归因；机制分析依赖白盒访问内部激活值，未验证黑盒 API 场景下的迁移性；代码已开源，但超参数（如 JSD 聚合方式）的敏感性分析未在正文中详细展开。

## 关联研究分析

从问题动机看，本文与 RAG 安全领域的投毒防御研究存在视角差异。安全研究（如 PoisonedRAG）关注外部知识库被注入恶意文档后的系统鲁棒性，而本文聚焦于内部机制如何归因上下文，两者均依赖上下文对生成分布的影响，但前者是黑盒攻击，后者是白盒解析。这种差异源于任务目标不同：安全防御需在不访问内部参数的情况下检测异常，而归因需精确量化内部组件贡献。本文的 JSD 方法若应用于安全场景，可能因需访问内部激活值而受限，但其分布差异度量思想可启发黑盒攻击检测。

从方法设计看，本文与 Cohen-Wang et al. (2024) 的 ContextCite 同属推理时归因，但本文用 JSD 直接计算替代线性代理模型。ContextCite 的线性假设在上下文句子数较少时可能失效，而 JSD 的有界性使其在深层 LLM 中更稳定。与 MIRAGE 等梯度方法相比，本文避免了反向传播的计算开销，但牺牲了 token 级细粒度归因能力，仅支持句子级。这种取舍反映了效率与精度的权衡，在大规模 RAG 部署中，句子级归因已满足多数应用场景需求，但细粒度归因在学术评估中仍有价值。

## 总结

本文核心矛盾在于 RAG 上下文归因的高计算成本与实时部署需求之间的冲突。现有方法依赖微调或大量前向调用，而本文利用 JSD 的数学特性直接量化分布差异，实现了无需训练的高效归因。ARC-JSD 在三个基准上平均准确率提升 10.7%，速度提升 3 倍，并通过 Logit Lens 定位了关键注意力头与 MLP 层，门控这些组件可将幻觉率降低 39%。其边界在于机制分析依赖白盒访问，且仅验证了句子级归因。当 RAG 系统以黑盒 API 形式部署时，JSD 定位的内部组件结论是否仍具指导意义，论文未给出回答。
