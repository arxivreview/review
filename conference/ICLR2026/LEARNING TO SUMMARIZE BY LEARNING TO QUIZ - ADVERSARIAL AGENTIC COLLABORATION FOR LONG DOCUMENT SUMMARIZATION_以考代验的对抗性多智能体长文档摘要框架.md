# ICLR2026最新论文 ｜LEARNING TO SUMMARIZE BY LEARNING TO QUIZ: ADVERSARIAL AGENTIC COLLABORATION FOR LONG DOCUMENT SUMMARIZATION ｜以考代验的对抗性多智能体长文档摘要框架

研究机构：英国爱丁堡大学、阿里巴巴集团

作者：Weixuan Wang、Minghao Wu、Barry Haddow 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_97243467)

> 长文档摘要面临信息丢失与事实幻觉的双重困境，现有单模型生成或简单多智能体协作难以闭环验证摘要的完整性。SUMMQ 将摘要生成与测验生成解耦为两个对抗域，通过“考生”智能体仅依据摘要回答测验题，强制摘要包含可验证的关键信息。该方法在 MENSA 和 BookSum 上显著优于 GPT-4O 等基线，但其高计算开销与对强 LLM 骨干的依赖限制了其通用性，且未量化推理成本。

## 研究背景

长文档摘要的核心挑战在于模型上下文窗口有限导致的远距离依赖断裂。当文档长度超出模型处理极限时，传统分块策略会切断语义连贯性，而直接截断则造成关键信息遗漏。为解决此问题，多智能体系统（Multi-Agent Systems, MAS）被引入，通过多个 LLM 实例的并行处理与聚合来缓解单点失效。然而，现有 MAS 多采用“生成-投票”或“生成-审查”的单向流程，缺乏对摘要内容完整性的硬性约束，导致审查者可能遗漏细微的事实错误，或生成者因缺乏反馈而重复相同偏差。

长文档摘要（Long Document Summarization, LDS）要求从数万词文本中提炼核心观点，同时保持事实一致性与逻辑连贯性。主流路线包括基于稀疏注意力的架构优化（如 U.FORMER）和基于 LLM 提示的端到端生成。前者依赖大规模监督微调，泛化能力受限；后者虽无需训练，但易产生幻觉，且无法自我检测信息覆盖度。SUMMQ 的切入点在于引入“测验”作为摘要质量的代理指标：如果摘要未能涵盖文档关键信息，基于该摘要生成的测验题将无法被正确回答。这种“以考代验”的机制将模糊的质量评估转化为可量化的问答正确率，从而构建了一个闭环的对抗性优化过程。

## 核心方法

### 方法参照系

本文问题属于基于 LLM 的生成式摘要范畴，但区别于传统的“生成-评估”单向流程。标准 MAS 摘要流程通常由多个生成器产出候选摘要，经聚合或投票后输出，审查者仅对最终结果进行事后检查。SUMMQ 的关键差异在于引入了与摘要生成并行的“测验生成”任务，并通过“考生”智能体建立摘要与测验之间的强依赖关系，使测验成为摘要质量的实时探针。

### 对抗性双域生成机制

SUMMQ 将智能体分为摘要域与测验域，两域并行运作。摘要生成器 $G_s$ 独立起草并聚合摘要 $S_t$，测验生成器 $G_q$ 同步生成包含 30 道选择题、判断题和简答题的测验 $Q_t$。设计动机在于解决传统审查机制中“审查者视角单一”导致的盲区：测验生成器被迫从文档中提取可验证的事实点，若摘要遗漏这些点，测验将无法被回答。测验生成的形式化定义为：

$$
Q_t = \text{Generate}(G_q, D, Q_{t-1})
$$

其中 $D$ 为原始文档，$Q_{t-1}$ 为上一轮测验。该公式表明测验生成不仅依赖文档，还受历史测验引导，确保问题覆盖度的迭代扩展。摘要与测验的对抗动态体现为：摘要旨在最大化测验可答性，而测验旨在最大化对摘要信息覆盖度的挑战。

### 基于辩论的争议验证与考生闭环

审查阶段采用结构化辩论机制处理争议问题。审查者 $R_s$ 和 $R_q$ 独立标注问题，若某问题被至少两名审查者标记，则视为“共识问题”；否则进入“争议问题”集合 $C$。对于 $C$ 中的每个问题 $c$，审查者进行 $T_{debate}$ 轮辩论，基于文档 $D$ 和当前摘要/测验 $z$ 提供证据，最终通过多数投票决定其有效性：

$$
I = M \cup \{c \in C \mid \text{MajorityVote}(R, c) = \text{VALID}\}
$$

其中 $M$ 为共识问题集合，$I$ 为最终问题列表。这一设计解决了简单投票中“少数派正确意见被淹没”的问题。此外，考生智能体 $E$ 仅依据摘要 $S_t$ 回答测验 $Q_t$，若回答失败，则生成反馈 $F_e$ 并入摘要反馈流。考生机制将“摘要是否包含足够信息”这一抽象概念转化为具体的问答失败事件，提供了比人工审查更客观的完整性指标。

## 实验评估

实验在 MENSA、BookSum 和 GovReport 三个长文档摘要基准上进行，基线涵盖监督微调（U.FORMER, SLED）、提示工程（GPT-4O, O3）及多智能体系统（HM-SR, C.MULTILLM）。SUMMQ 未对比 Topic-Guided RL 等显式结构方法，这可能遗漏了主题建模对长文档覆盖度的潜在贡献。

| 方法 | MENSA R-2 | BookSum R-2 | GovReport R-2 |
| :--- | :--- | :--- | :--- |
| GPT-4O | 7.24 | 11.87 | 10.50 |
| O3 | 9.14 | 9.93 | 10.50 |
| SUMMQSOLO | 9.70 | 17.26 | 11.14 |
| SUMMQCOMBO | 11.08 | 18.47 | 11.14 |

SUMMQCOMBO 在 MENSA 和 BookSum 上显著优于所有基线，其中 BookSum 的 R-2 提升幅度最大（从 GPT-4O 的 11.87 至 18.47），表明对抗性机制在复杂长文本中更有效。在 GovReport 上，SUMMQCOMBO 与监督微调基线 CACHED（10.50）持平，略低于 U.FORMER（10.50），说明在结构化较强的政府报告领域，大规模微调模型仍具竞争力。

消融实验显示，移除测验机制导致 SUMMQSOLO 的 R-1 下降 5.00，BS_F1 下降 6.40，证实测验是性能提升的关键驱动因素。智能体数量从 1 增至 5 时，R-1 从 39.30 升至 42.52，但边际收益递减，且计算成本线性增加。迭代次数超过 3 次后，性能趋于饱和甚至轻微下降，表明过度迭代可能导致信息冗余或噪声累积。

评估指标包括 ROUGE 和 BERTScore，但缺乏对推理时间、Token 消耗等效率指标的量化报告，这使得 SUMMQ 在实时应用场景中的可行性存疑。代码已开源，但实验主要依赖 GPT-4O 等专有模型，开源模型（如 QWEN3-32B）上的性能提升幅度较小（R-1 从 23.49 至 26.50），暗示框架性能高度依赖骨干 LLM 的推理能力。

## 关联研究分析

从问题动机看，SUMMQ 与 HM-SR（Jeong et al., 2025）同属 MAS 摘要框架，但 HM-SR 侧重自验证，即生成者自我检查错误，而 SUMMQ 通过外部测验生成者引入独立视角，避免了自验证中的认知偏差。这一差异源于对“幻觉来源”的不同假设：HM-SR 认为幻觉主要源于生成过程中的随机性，可通过自我纠正缓解；SUMMQ 则认为幻觉源于信息覆盖不全，需通过外部探针检测。从方法设计看，SUMMQ 与 Topic-Guided RL（P8）形成对比，后者通过显式主题建模优化高层语义对齐，而 SUMMQ 依赖隐式问答验证。Topic-Guided RL 在 Multi-News 上取得 0.48 ROUGE-2，但其在长文档任务上的表现未知。SUMMQ 未对比此类方法，可能是因为主题建模在长文档中面临计算开销大、主题边界模糊等问题，但这也意味着 SUMMQ 可能未充分利用文档的结构化语义信息。

## 总结

SUMMQ 旨在解决长文档摘要中信息丢失与事实幻觉的矛盾，其切入点在于将摘要质量转化为可验证的问答正确率，通过对抗性多智能体协作实现闭环优化。该方法在 MENSA 和 BookSum 上分别取得 11.08 和 18.47 的 R-2 分数，显著优于 GPT-4O 基线，证明了测验机制的有效性。然而，其性能高度依赖强 LLM 骨干，且未量化计算成本，限制了其在资源受限场景中的应用。当骨干模型替换为开源小模型时，性能提升幅度显著缩小，这是否意味着对抗性机制的有效性存在一个模型能力阈值，论文未给出明确回答。
