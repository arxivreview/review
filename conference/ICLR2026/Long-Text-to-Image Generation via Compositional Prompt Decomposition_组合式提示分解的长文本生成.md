# ICLR2026最新论文 ｜Long-Text-to-Image Generation via Compositional Prompt Decomposition ｜组合式提示分解的长文本生成

研究机构：北京大学、美国哈佛大学

作者：Jen-Yuan Huang、Tong Lin、Yilun Du

论文原文见 [arXiv](https://arxiv.org/abs/2604.18258)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.18258)

> 长文本到图像生成面临的核心矛盾是：预训练模型在短描述上表现优异，但面对包含大量细节的段落时，因训练数据分布偏差导致关键信息丢失。现有微调路线存在灾难性遗忘，投影路线则牺牲细节保真度。PRISM 提出了一种组合式策略，将长提示分解为多个语义组件，利用能量基模型的可组合性独立预测噪声并求和。该方法在无需微调骨干网络的前提下，实现了比微调基线更优的长序列泛化能力，但其组件间语义耦合与全局一致性依赖无监督学习，鲁棒性尚存疑。

## 研究背景

扩散模型通过迭代去噪过程生成图像，其核心机制可视为对数据分布对数似然梯度的估计，即分数函数。这一分数视角揭示了扩散模型与能量基模型（Energy-Based Model, EBM）的内在联系：噪声预测等价于隐式能量函数的梯度。EBM 具有天然的可组合性，多个分布的乘积对应能量函数的求和，这一数学性质为将复杂条件分解为简单子条件提供了理论支撑。

文本到图像（Text-to-Image, T2I）模型主要基于短标签数据训练，导致其难以理解长段落中的叙事流与分散细节。现有解决方案分为两类：一是直接在长描述数据上微调模型，虽在训练长度内有效，但向更长提示外推时性能急剧下降，且易引发预训练知识的灾难性遗忘；二是将长提示投影至模型的有效上下文窗口，这种信息瓶颈不可避免地丢失了长提示中丰富的细节信息。PRISM 的切入点在于利用预训练模型对短提示的既有专长，通过组合式生成避免分布外输入，将长提示处理转化为多个短提示的联合分布建模问题。

## 核心方法

### 方法参照系

长文本生成的标准流程通常涉及将长序列编码后直接输入扩散模型，或先进行压缩投影。本文的关键差异在于不修改骨干网络或压缩信息，而是引入一个轻量级分解模块，将长提示编码拆解为多个独立组件，利用扩散模型作为可组合 EBM 的特性，通过噪声预测的线性叠加实现联合生成。

### 组合式噪声预测

传统方法将长提示视为单一条件向量，导致模型在处理超出训练分布的长序列时失效。PRISM 将长提示 $C$ 分解为 $N$ 个组件 $\{c_1, ..., c_N\}$，每个组件对应一个简化的语义片段。基于 EBM 的可组合性，最终图像由这些组件的联合分布生成，其噪声预测公式为：

$$ \epsilon_{composed}(x_t, t) = \sum_{i=1}^{N} \epsilon_\theta(x_t, t, c_i) $$

该公式的物理含义是，每个组件独立引导去噪过程，其梯度叠加后指向同时满足所有组件约束的高密度区域。这种设计消除了对长序列整体理解的依赖，使预训练模型始终在其擅长的短提示域内工作，从而保留了预训练知识并提升了细节保真度。

### 无监督分解模块

分解模块的设计动机在于解决简单语言分割导致的全局上下文丢失问题。对于双向文本编码器（如 T5），PRISM 采用查询 Transformer 结构，使用 $N$ 个可学习向量作为查询，从长提示编码中提取组件表示。对于因果语言模型（如 Qwen），则通过 LoRA 微调文本编码器，使其在扩展序列中直接输出组件表示。分解模块通过冻结 T2I 模型的组合扩散损失进行无监督优化，确保提取的组件既可被预训练模型解读，又能产生连贯的合成场景。

## 实验评估

实验在 DetailMaster 基准上进行，该基准包含平均 284.89 tokens 的长提示，评估维度涵盖角色存在、属性、位置、场景属性及空间关系。基线覆盖微调路线（LongAlign）、投影路线（ELLA）及现代架构模型（SDXL, FLUX, Qwen-Image）。

| 模型 | Character Presence (%) | Character Attributes (%) | Spatial Relation (%) |
| :--- | :--- | :--- | :--- |
| LongAlign | 24.53 | 81.67 | 20.88 |
| ELLA | 19.43 | 76.53 | 15.17 |
| **PRISM-SD1.5** | **28.21** | **84.78** | **24.47** |
| Qwen-Image | 40.46 | 90.21 | 41.49 |
| **PRISM-Qwen** | **46.84** | **91.55** | **49.23** |

PRISM-SD1.5 在角色存在性上比 LongAlign 高 3.68%，在空间关系上高 3.59%。PRISM-Qwen 相比原生 Qwen-Image，角色存在性提升 6.38%，空间关系提升 7.74%，表明组合策略在现代架构上同样有效。

| 变体 | Character Presence (%) | Spatial Relation (%) |
| :--- | :--- | :--- |
| Sentence Splitting | 14.01 | 5.18 |
| w/o Composition | 28.98 | 20.97 |
| **w/ Composition** | **29.49** | **22.22** |

消融实验显示，简单句子分割导致性能大幅下降，验证了学习分解的必要性。去除组合机制（即单组件投影）后，空间关系性能从 22.22% 降至 20.97%，表明组合机制对全局一致性有正向贡献。

评估边界方面，论文未报告置信区间，且仅在 DetailMaster 上验证，未覆盖 DPG-Bench 等其他长提示基准。代码已开源，训练配置明确（4 A100 GPU，20 小时），可复现性较高。

## 关联研究分析

从问题动机看，PRISM 与 LongAlign 均旨在解决长提示遵循问题，但 LongAlign 依赖数据驱动的微调，其泛化能力受限于训练数据长度分布；PRISM 则通过结构化的组合生成，将长提示处理转化为短提示的联合分布，从而在未见过的更长提示上保持性能。这一差异源于对“长提示理解”本质的不同假设：前者假设模型可通过学习长序列模式来理解，后者假设长提示是多个短模式的组合。

从方法设计看，PRISM 与 Concept Conjunction 共享 EBM 组合的理论基础，但 Concept Conjunction 通常用于融合两个独立提示，而 PRISM 将其扩展为多组件分解与重组。与 FIBO 等结构化字幕方法相比，PRISM 不依赖显式的提示分解监督，而是通过无监督学习自动发现语义组件，这降低了数据标注成本，但也引入了组件语义重叠的风险。

## 总结

PRISM 针对长文本生成中预训练模型分布外泛化失效的核心矛盾，提出了一种基于 EBM 可组合性的分解策略。通过将长提示拆解为多个短组件并独立预测噪声，PRISM 在无需微调骨干网络的情况下，实现了比微调基线更优的长序列泛化能力，在 >500 tokens 提示上平均提升 7.4%。其边界在于分解模块的无监督学习可能导致组件间语义耦合，且实验仅在单一基准上验证。当提示长度进一步增加或组件数量 $N$ 增大时，组合噪声预测的累积误差是否会抵消分解带来的保真度收益，论文未给出回答。
