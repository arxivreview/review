# ICLR2026最新论文 ｜A Balanced Neuro-Symbolic Approach for Commonsense Abductive Logic ｜基于骨架反馈的溯因神经符号推理

研究机构：加拿大麦吉尔大学

作者：Joseph Cotnareanu、Didier Chetelat、Yingxue Zhang 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.18595)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.18595)

> 现有神经符号系统受限于演绎推理的封闭世界假设，当问题缺失常识前提时，符号求解器直接返回“未知”，导致推理链断裂。本文指出，大语言模型（LLM）虽擅长识别常识，但缺乏将其转化为逻辑约束的机制，而现有溯因方法搜索空间过于受限。ARGOS通过利用SAT求解器返回的骨架（Backbone）引导LLM生成缺失的常识命题，实现了在开放空间中的高效溯因。该方法在多个基准上显著优于纯神经与纯符号基线，但其性能高度依赖LLM对常识的准确概率化评估，且未解决生成命题的逻辑一致性验证问题。

## 研究背景

**预备知识**
理解本文需厘清演绎与溯因推理在逻辑完备性上的差异。演绎推理要求所有前提显式给出，若前提集 $P$ 无法蕴含查询 $Q$ 或其否定 $\neg Q$，则问题不可解。然而，人类推理常依赖未言明的背景知识，即溯因推理（Abductive Reasoning），其目标是在前提集 $P$ 基础上补充常识命题集 $C$，使得 $P \cup C \vdash Q$ 或 $P \cup C \vdash \neg Q$。在命题逻辑中，SAT求解器不仅能判断可满足性，还能输出“骨架”（Backbone），即由前提 $P$ 必然推出的所有文字（Literals）集合。骨架代表了当前逻辑状态下确定的事实边界，是连接符号确定性与神经不确定性的关键接口。

**研究脉络**
神经符号推理的主流范式是“翻译-求解”：LLM将自然语言转化为形式逻辑，符号求解器执行严格推导。这一范式在前提完备的演绎任务中表现优异，但在现实场景中，问题往往隐含大量未陈述的常识（如“白色表面反射阳光”）。当求解器因前提缺失而返回“未知”时，现有方法陷入停滞。早期尝试如LLM-Tres在受限规则空间内穷举，Logic-of-Thought（LoT）依赖LLM生成可推导的新规则，但二者均无法处理需要引入全新变量或关系的复杂常识。本文切入点在于：利用符号求解器的骨架作为搜索引导，让LLM在骨架约束下生成具有常识性的新命题，从而在保持逻辑严谨性的同时扩展前提集，解决前提不完备导致的推理失效问题。

## 核心方法

### 方法参照系

标准神经符号流程为：LLM翻译自然语言至命题逻辑 $\rightarrow$ SAT求解器判断 $P \vdash Q$ 或 $P \vdash \neg Q$ $\rightarrow$ 输出结果。本文问题的关键差异在于：输入问题被设计为“欠定”（Underdetermined），即 $P$ 无法单独决定 $Q$ 的真值。因此，流程需增加一个迭代环节：当求解失败时，利用求解器反馈生成新前提 $C$，并重新求解，直至收敛。

### 骨架引导的常识生成

**设计动机**：随机生成常识命题会导致搜索空间爆炸且大量生成无关或错误命题。利用骨架中已确定的文字作为前件，可确保新命题与当前逻辑状态强相关，从而缩小搜索空间并提高生成效率。

ARGOS算法的核心在于迭代扩展常识集 $C$。初始时 $C = \emptyset$。每轮迭代首先调用SAT求解器，若 $P \cup C \vdash Q$ 或 $P \cup C \vdash \neg Q$，则终止；否则，获取当前前提下的骨架 $B = \{L \in L(V) \mid P \cup C \vdash L\}$。随后，算法从 $B$ 中选取两个文字 $L_1, L_2$ 作为前件，提示LLM生成后件 $L_{right}$，构成候选命题 $L_1 \land L_2 \rightarrow L_{right}$。为筛选高质量常识，引入双阈值评分机制：

$$
\text{Score}(L_1, L_2, L_{right}) = \min(\text{CS}(L_1 \land L_2 \rightarrow L_{right}), \text{Rel}(L_1 \land L_2 \rightarrow L_{right}))
$$

其中 $\text{CS}$ 为LLM评估的常识性概率，$\text{Rel}$ 为相关性概率。仅当 $\text{Score} > \tau$（实验中 $\tau=0.3$）时，该命题被加入 $C$。此公式的物理含义是：新命题必须同时满足“普遍为真”（常识）和“与当前问题相关”（骨架关联）两个条件，否则被丢弃。

### 自适应终止与自一致性融合

**设计动机**：纯符号求解可能因常识生成错误而陷入死循环，纯神经推理则缺乏逻辑保证。需一种机制平衡二者，并在符号求解失败时提供兜底答案。

ARGOS引入自一致性（Self-Consistency, SC）作为并行求解路径。每轮迭代中，LLM通过 $k$ 次采样（$k=5$）投票判断 $Q$ 的真值。若投票比例超过阈值 $\gamma$，则直接输出结果。初始 $\gamma=1.0$，每轮迭代后 $\gamma \leftarrow \gamma - \alpha$（$\alpha=0.1$）。当 $\gamma$ 降至 $0.5$ 时，由于二分类投票必然有一方占比 $\ge 0.5$，算法强制终止并输出SC结果。该机制确保了算法在有限步数内（最多5轮）收敛，避免了无限搜索。

## 实验评估

**实验设置与主结果**
实验在FOLIO、CLUTRR、ProntoQA、ESNLI、CosmosQA、QUAIL六个基准上进行，使用Llama3-8B/70B和Mistral-7B作为骨干模型。基线涵盖纯神经（SC, CoT）、纯符号（SAT-LM）及混合方法（LoT, LLM-Tres）。值得注意的是，本文未对比VERUS-LM或NL2LOGIC等翻译优化方法，因任务设定为“前提缺失”的溯因问题，而非“翻译错误”的演绎问题。

| 方法 | FOLIO (L8B) | CLUTRR (L8B) | ProntoQA (L8B) | ESNLI (L8B) |
| :--- | :--- | :--- | :--- | :--- |
| SC-20 | 71.7 | 69.5 | 95.6 | 97.0 |
| CoT | 70.1 | 68.8 | 94.4 | 96.3 |
| SAT-LM | 77.7 | 69.4 | 94.1 | 99.5 |
| LoT-20 | 65.5 | 67.8 | 89.6 | 98.9 |
| LLM-Tres | 65.5 | 65.6 | 92.4 | 47.7 |
| **ARGOS** | **81.8** | **78.4** | **98.1** | **99.2** |

ARGOS在FOLIO上较SC提升10.1%，在CLUTRR上提升8.9%，在ProntoQA上提升2.5%。在ESNLI上，ARGOS（99.2%）略低于SAT-LM（99.5%），表明在常识需求较低的结构化任务中，纯符号方法仍具竞争力。

**消融与设计决策验证**

| 变体 | FOLIO (L8B) |
| :--- | :--- |
| ARGOS - No T (无阈值) | 79.8 |
| ARGOS - No BB (无骨架) | 79.4 |
| ARGOS - No Both | 75.2 |
| **ARGOS** | **81.8** |

移除骨架引导（No BB）导致性能下降2.4%，移除阈值筛选（No T）下降2.0%，同时移除两者下降6.6%。这表明骨架引导与阈值筛选具有协同效应，骨架提供了相关性约束，阈值提供了质量过滤，二者缺一不可。

**评估边界与可复现性**
论文未报告计算效率指标（如平均迭代次数、LLM调用延迟），仅提及最大成本受限于 $\gamma$ 的衰减步数。评估协议基于二分类准确率，未区分“正确溯因”与“错误但碰巧正确”的情况。代码未公开，但超参数（$\tau=0.3, \alpha=0.1, k=5$）已明确给出，便于复现。

## 关联研究分析

从问题动机看，ARGOS与Logic-LM（Pan et al., 2023）均利用LLM-求解器交互，但Logic-LM聚焦于修正翻译错误（即前提形式化不准确），而ARGOS聚焦于补全前提缺失（即前提集不完备）。这一差异源于任务设定：Logic-LM假设自然语言到逻辑的翻译存在噪声，而ARGOS假设翻译准确但背景知识缺失。若将ARGOS应用于翻译错误场景，其骨架引导机制可能失效，因为骨架基于错误前提生成，会误导常识生成方向。

从方法设计看，ARGOS与LLM-Tres（Toroghi et al., 2024）均进行溯因搜索，但LLM-Tres在受限规则空间（仅单命题Modus Ponens）内穷举，而ARGOS在骨架引导的开放空间内生成。LLM-Tres的搜索空间小但覆盖不全，ARGOS的搜索空间大但依赖LLM的常识判断准确性。ARGOS在ESNLI上性能低于SAT-LM，暗示当问题本身常识需求低时，LLM生成的额外命题可能引入噪声，反而干扰符号求解。

## 总结

ARGOS解决了神经符号推理中因前提缺失导致的“未知”困境，通过骨架引导LLM生成常识命题，实现了从演绎到溯因的范式扩展。实验显示其在FOLIO和CLUTRR上较基线提升10%左右，验证了骨架反馈的有效性。然而，论文未量化生成命题的逻辑一致性风险，即LLM可能生成看似常识但实际与前提矛盾的命题，导致 $P \cup C \vdash \bot$。当骨架中文字数量激增时，LLM生成相关常识的准确率是否下降，论文未给出回答。
