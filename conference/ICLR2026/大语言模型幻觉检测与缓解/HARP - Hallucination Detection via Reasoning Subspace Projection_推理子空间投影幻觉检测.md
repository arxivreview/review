# ICLR2026最新论文 ｜HARP: Hallucination Detection via Reasoning Subspace Projection ｜推理子空间投影幻觉检测

研究机构：华中科技大学

作者：Junjie Hu、Gang Tu、ShengYu Cheng 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.11536)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.11536)

> 大语言模型（LLM）在生成事实性错误时，常伴随内部推理轨迹的异常，但现有黑盒检测依赖多次采样，白盒探针则混淆语义与逻辑信号。HARP 抓住 Unembedding 层天然区分语义与推理信息的特性，通过奇异值分解（SVD）提取推理子空间基向量，将隐藏状态投影至该低维空间以消除噪声。该方法在 TriviaQA 上取得 92.8% AUROC，显著优于基线，但其直和分解假设在复杂推理任务中的普适性仍存疑。

## 研究背景

当模型生成看似流畅但事实错误的回答时，仅凭输出文本的困惑度或语义熵难以区分“知识缺失”与“逻辑断裂”。这一困境源于 LLM 的生成机制：隐藏状态同时编码了用于预测下一个 token 的语义信息和用于中间计算的推理轨迹，而 Unembedding 层在输出时仅压缩语义部分，丢弃推理部分。这种信息不对称导致传统基于输出一致性的检测器（如 Semantic Entropy）无法捕捉内部逻辑错误，而基于全维隐藏状态的线性探针（如 SAPLMA）则因特征维度高、噪声大，在长上下文或复杂推理场景中泛化能力不足。

白盒内部表征探测路线旨在利用模型内部信号实现实时幻觉检测。SAPLMA 等早期工作证明最后一层隐藏状态包含可线性解码的幻觉信号，但线性探针难以捕捉深层语义空间中的非线性结构，且对推理过程中的动态变化响应不足。HaloScope 尝试通过 SVD 识别关键子空间方向，但其应用于嵌入层且依赖监督标签，通用性受限。HARP 的切入点在于：既然 Unembedding 层在生成过程中天然过滤了推理信息，那么对该层参数进行 SVD 分解，即可分离出主导 token 预测的语义子空间与正交的推理子空间，从而构建免训练、低维且专注于逻辑信号的检测特征。

## 核心方法

### 方法参照系

白盒幻觉检测的标准流程通常是在最后一层隐藏状态上训练线性探针或逻辑回归分类器。本文问题与该通用流程的关键差异在于：不依赖监督标签训练分类器，而是利用 Unembedding 层的几何结构直接提取无监督特征，将检测任务转化为对推理子空间投影幅值的阈值判断。

### 子空间直和分解与 SVD 解耦

设计动机：解决全维隐藏状态中语义噪声淹没推理信号的问题，以及线性探针在复杂推理任务中混淆语义错误与逻辑错误的失效。HARP 假设隐藏状态空间 $H_l$ 可分解为语义子空间 $\mathcal{S}_{Semantic}$ 与推理子空间 $\mathcal{S}_{Reasoning}$ 的直和。通过对 Unembedding 参数矩阵 $W_{unemb}$ 进行 SVD 分解，利用 Eckart–Young–Mirsky 定理进行秩 $k$ 近似，其中 $k = d \times 95\%$。语义子空间由前 $k$ 个右奇异向量 $V_S$ 张成，推理子空间由剩余 $d-k$ 个右奇异向量 $V_R$ 张成。

$$
\mathcal{S}_{Semantic} = \text{span}(V_S), \quad \mathcal{S}_{Reasoning} = \text{span}(V_R)
$$

该公式表明，推理子空间是 Unembedding 层“忽略”的方向，即对 token 预测贡献极小的维度。通过截断 5% 的微小奇异值，HARP 在保留主要语义预测能力的同时，将推理信号隔离在低维正交空间中，实现了特征维度的大幅压缩。

### 推理子空间投影检测

设计动机：解决高维特征中噪声导致的检测鲁棒性不足问题，利用推理子空间的低维性提升信噪比。HARP 将第 $l$ 层隐藏状态 $h_l$ 投影至推理子空间，得到投影向量 $proj_R(h_l)$。该投影向量仅包含约 5% 原始维度的信息，高度集中于推理过程。随后，使用一个轻量级检测器 $g_\theta$ 计算每个 token 的幻觉分数，并取最大值作为整个回答的幻觉分数。

$$
g_\theta(y|x) = \max_{i \in [1,n]} g_\theta(proj_R(h_{l,i}))
$$

该公式意味着，只要回答中任意一个 token 的推理子空间投影表现出异常模式（如逻辑断裂），整个回答即被标记为幻觉。这种“最大值”聚合策略强化了对局部逻辑错误的敏感性，避免了平均操作对显著异常信号的稀释。

## 实验评估

| 方法 | NQ Open (Qwen) | TruthfulQA (Qwen) | TriviaQA (Qwen) | TyDiQA (Qwen) |
| :--- | :--- | :--- | :--- | :--- |
| Perplexity | 76.5 | 64.4 | 83.1 | 30.5 |
| Semantic Entropy | 77.7 | 63.6 | 76.9 | 60.3 |
| EigenScore | 78.9 | 63.8 | 76.2 | 74.8 |
| HaloScope | 76.2 | 74.8 | 60.7 | 63.0 |
| **HARP** | **84.0** | **88.1** | **92.8** | **88.4** |

实验覆盖 NQ Open、TruthfulQA、TriviaQA 和 TyDiQA 四个数据集，使用 Qwen-2.5-7B-Instruct 和 LLaMA-3.1-8B 作为骨干模型。基线包括 Perplexity、Semantic Entropy、EigenScore 和 HaloScope，覆盖了黑盒采样、协方差特征和子空间探针路线，但缺失 SAPLMA 和 ICR-Probe 等最新白盒基线。HARP 在 TriviaQA 上以 92.8% AUROC 领先，较次优方法提升 7.5 个百分点；在 TyDiQA 等长上下文任务上，HARP 的 88.4% 显著优于 Semantic Entropy 的 60.3%，表明推理子空间投影在复杂推理场景中更具鲁棒性。

消融实验显示，移除投影操作（HARP w/o）或随机选择子空间（HARP random）均导致性能显著下降。在 NQ Open 上，HARP 的 84.0% 远高于 HARP w/o 的 62.9% 和 HARP random 的 70.7%，证明推理子空间的几何结构而非随机方向是检测性能的关键。此外，推理子空间维度对性能影响显著：当维度从 32 增加至 256 时，AUROC 从约 70% 提升至 84%，但超过 256 后收益递减，验证了 5% 维度截断的合理性。

评估指标仅使用 AUROC，未报告 F1 或校准误差，限制了对其弃权行为影响的评估。实验未提供代码链接，且未报告置信区间，数值比较需谨慎。基线中未包含 2025 年后的最新方法如 CausalGaze，使得 HARP 的 SOTA 地位受限于基线时效性。

## 关联研究分析

从方法设计看，HARP 与 HaloScope 均使用 SVD 解耦子空间，但 HaloScope 作用于嵌入层并依赖监督探针，而 HARP 作用于 Unembedding 层且免训练。这一差异源于任务特性：Unembedding 层直接关联输出 token 预测，其“忽略”的方向更纯粹地对应推理信息，而嵌入层混合了输入语义与初始状态，解耦难度更高。HARP 的免训练特性使其在部署效率上优于 HaloScope，但牺牲了对特定领域幻觉模式的适应性。

从问题动机看，HARP 与 SAPLMA 同属白盒探测路线，但 SAPLMA 关注全维隐藏状态的线性可分性，而 HARP 聚焦于推理子空间的低维投影。SAPLMA 在简单事实问答上有效，但在推理链逻辑断裂场景中，全维特征中的语义噪声可能掩盖逻辑异常。HARP 通过维度压缩解决了这一问题，但其直和分解假设在模型架构变化（如 MoE）或推理过程非线性强时是否依然成立，论文未给出回答。

## 总结

HARP 旨在解决白盒幻觉检测中语义噪声掩盖推理信号的问题，其切入点在于利用 Unembedding 层天然区分语义与推理信息的特性，通过 SVD 提取低维推理子空间基向量。该方法在 TriviaQA 上取得 92.8% AUROC，在 TyDiQA 上以 88.4% 显著优于黑盒基线，证明了推理子空间投影的有效性。然而，其直和分解假设依赖于 Unembedding 层的线性性，且在复杂推理任务中，推理子空间与语义子空间的正交性可能因模型训练动态而减弱。当模型架构从标准 Transformer 演进至混合专家（MoE）或状态空间模型时，Unembedding 层是否仍能清晰解耦语义与推理信息，论文未给出回答。
