# ICLR2026最新论文 ｜TiTok: Transfer Token-level Knowledge via Contrastive Excess to Transplant LoRA ｜LoRA 适配器跨模型移植中的 Token 级选择性知识迁移

研究机构：韩国延世大学

作者：Chanjoo Jung、Jaehyung Kim

论文原文见 [arXiv](https://arxiv.org/abs/2510.04682)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.04682)

> 大语言模型参数高效微调产生的 LoRA 适配器与特定骨干网络绑定，无法直接迁移至新模型，而传统知识蒸馏依赖原始训练数据，合成数据方案又需额外判别器。TITOK 通过计算源模型带与不带 LoRA 的 Token 级对比超额分数，筛选高信息量样本与 Token 进行目标模型训练，实现了无原始数据、无额外模型的轻量级适配器移植。该方法在多种跨模型设置下平均提升 4-10%，但其有效性高度依赖合成数据质量，且在长链推理任务上的泛化能力尚存疑。

## 研究背景

参数高效微调（PEFT）通过冻结骨干网络并仅更新低秩矩阵（如 LoRA）来降低微调成本，但生成的适配器参数与特定骨干网络强耦合，导致模型版本迭代或架构切换时无法复用。这一局限在模型快速发布的当下尤为突出，迫使研究者寻求将源模型适配器中的任务知识迁移至目标模型的方法。知识蒸馏（KD）是经典解法，但其通常要求访问原始训练数据以对齐教师与学生分布，这在数据隐私或成本受限场景下不可行。

现有替代方案主要依赖合成数据。TransLoRA 利用源模型生成合成数据并训练目标模型，但需额外训练判别器过滤低质量数据，增加了计算开销与流程复杂度。传统 KD 方法虽能处理分布对齐，但往往忽略 Token 级信息密度的差异，导致目标模型在冗余 Token 上浪费学习容量。TITOK 的切入点在于：不依赖外部判别器，而是利用源模型内部“带 LoRA”与“不带 LoRA”的预测差异，直接定位并迁移那些真正承载任务知识的 Token，从而在保持轻量级的同时提升迁移效率。

## 核心方法

### 方法参照系

TITOK 属于基于合成数据的适配器移植框架，其标准流程为：源专家模型生成合成数据 → 数据过滤 → 目标模型训练。与 TransLoRA 等基线相比，TITOK 的关键差异在于过滤机制：基线使用外部判别器或随机采样，而 TITOK 使用源自模型内部的 Token 级对比信号进行两级筛选（样本级与 Token 级），无需额外模型训练。

### Token 级对比超额分数

传统 KD 假设所有 Token 对知识迁移贡献均等，但在合成数据中，大量 Token 仅反映骨干模型的通用能力，而非 LoRA 注入的特定任务知识。TITOK 引入 Token 级对比超额分数（Token-wise Contrastive Excess Score），通过计算源模型带 LoRA（专家）与不带 LoRA（业余）在相同 Token 上的负对数似然差，量化 LoRA 对该 Token 预测分布的改变程度。

$$ S(y_i) = L_e(y_i) - L_a(y_i) $$

其中 $L_e(y_i)$ 和 $L_a(y_i)$ 分别为专家模型和业余模型在 Token $y_i$ 上的损失。该公式的物理含义是：若骨干模型对某 Token 预测不确定（$L_a$ 高），而加入 LoRA 后预测置信度显著提升（$L_e$ 低），则 $S(y_i)$ 为大正值，表明该 Token 是 LoRA 注入任务知识的关键位置。这一设计解决了合成数据中“噪声 Token”稀释学习信号的问题，使训练聚焦于高信息密度区域。

### 两级筛选与掩码对齐

在计算超额分数后，TITOK 执行两级筛选以优化训练数据。第一级为样本过滤：计算每个合成样本中所有 Token 超额分数的均值 $\bar{S}_j$，仅保留均值最高的 $M$ 个样本，移除整体信息量低的样本。第二级为 Token 选择：在保留的样本中，仅选取超额分数排名前 $k\%$ 的 Token 参与损失计算，其余 Token 被掩码忽略。

$$ \mathcal{L}_{\text{TITOK}} = \sum_{(\mathbf{q}_j, \mathbf{y}_j) \in D_f} \sum_{y_i \in \mathbf{y}_j} I_{k\%}(y_i) \cdot L_t(y_i) $$

其中 $I_{k\%}(y_i)$ 为指示函数，仅当 $y_i$ 属于前 $k\%$ 高分数 Token 时为 1。该损失函数确保目标模型仅从高信息量 Token 中学习，避免了在低价值 Token 上的过拟合。对于跨分词器场景，TITOK 通过最小编辑距离（MinED）对齐源与目标 Token 掩码，确保筛选信号在异构词表间的有效传递，解决了传统 Logits 对齐在词表不匹配时的失效问题。

## 实验评估

实验在 BBH、MMLU 和 LaMP（新闻标题、学术标题生成）四个任务上进行，覆盖同模型、跨家族、跨尺寸及跨版本四种迁移设置。基线包括 Vanilla（无微调）、KD+MinED（传统蒸馏+词表对齐）和 TransLoRA（判别器过滤）。TITOK 在所有设置中均优于基线，例如在 Mistral 7B → Llama3 8B 迁移中，BBH 准确率从 Vanilla 的 0.469 提升至 0.484，MMLU 从 0.469 提升至 0.485。

| :--- | :--- | :--- | :--- | :--- | :--- |
| Mistral 7B → Mistral 7B | Vanilla | 0.397 | 0.557 | 0.104 | 0.310 |
| | KD (+MinED) | 0.417 | 0.560 | 0.137 | 0.385 |
| | TransLoRA | 0.416 | 0.534 | 0.156 | 0.382 |
| | **TITOK** | **0.424** | **0.561** | **0.161** | **0.473** |
| Mistral 7B → Llama3 8B | Vanilla | 0.469 | 0.469 | 0.112 | 0.387 |
| | KD (+MinED) | 0.475 | 0.482 | 0.110 | 0.397 |
| | TransLoRA | 0.473 | 0.473 | 0.126 | 0.397 |
| | **TITOK** | **0.484** | **0.485** | **0.139** | **0.464** |

消融实验显示，样本过滤与 Token 选择均带来显著增益。在 Mistral 7B → Llama3 8B 设置中，仅使用样本过滤（无 Token 选择）时 BBH 准确率为 0.470，加入 Token 选择后提升至 0.483。进一步分析表明，选取前 20% 高分数 Token 的效果优于随机选取（0.482 vs 0.476）和后 20%（0.468），验证了超额分数作为信息密度代理的有效性。

评估边界方面，实验主要依赖零样本准确率与 ROUGE 指标，未报告置信区间或计算效率（如 FLOPs/Token）。代码已开源，但超参数（如 $k\%$ 和 $M$）的敏感性分析仅在部分设置中展示，跨任务泛化能力（如从推理任务迁移至生成任务）虽在 Table 4 中有所体现，但缺乏对长链推理任务中误差累积影响的深入讨论。

## 关联研究分析

从问题动机看，TITOK 与 TransLoRA 同属合成数据驱动的适配器移植，但 TransLoRA 依赖外部判别器识别高质量样本，而 TITOK 利用模型内部对比信号实现自监督过滤。这一差异源于对“数据质量”定义的不同：TransLoRA 关注样本整体合理性，TITOK 关注 Token 级知识增量。根源在于 TITOK 假设 LoRA 注入的知识具有稀疏性，即仅部分 Token 承载关键信息，这一假设在短文本生成任务中成立，但在长链推理中是否依然有效，论文未给出回答。

从方法设计看，TITOK 的 Token 级掩码机制与选择性 Token 训练（Selective Token Training）思想一致，但将其应用于知识迁移而非优化加速。与 GKD 等在线策略蒸馏方法相比，TITOK 属于离线策略，不解决训练-推理分布失配问题，而是通过数据筛选间接缓解。这种设计选择牺牲了对推理时误差累积的鲁棒性，换取了无需实时生成学生序列的计算效率。在跨分词器对齐上，TITOK 采用 MinED 掩码对齐，相比 SRA 的跨度表示对齐，计算开销更低，但可能损失细粒度语义信息，这在复杂推理任务上的影响尚不明确。

## 总结

TITOK 解决了 LoRA 适配器跨模型移植中原始数据不可用与合成数据噪声并存的核心矛盾。其切入点在于利用源模型内部“带/不带 LoRA”的预测差异，将知识迁移从序列级对齐细化至 Token 级选择性学习，避免了额外判别器的开销。通过两级筛选机制，TITOK 在 BBH 和 MMLU 等任务上实现了 4-10% 的平均性能提升，证明了 Token 级信息密度筛选的有效性。然而，实验主要局限于短文本生成与简单推理任务，未验证在长链推理中，离线策略是否会导致误差累积，且跨分词器对齐的 MinED 方法在语义复杂场景下的鲁棒性缺乏深入分析。当任务长度增加至数百 Token 时，Token 级超额分数能否持续区分关键知识位置，论文未给出回答。
