> 深度研究智能体旨在通过自主检索与长程推理解决开放式复杂任务，但开源模型与闭源系统间存在显著性能鸿沟，主要源于训练数据逻辑结构单一及强化学习环境不稳定。WebSailor-V2 通过构建稠密知识图谱生成多样化不确定性数据，并设计双环境强化学习框架，实现了数据与策略的协同进化。该方法在 Qwen3-30B-A3B 上取得 BrowseComp-EN 35.3 分，超越 671B 参数模型，验证了工程化训练对缩小模型规模差距的有效性，但其模拟环境到真实环境的迁移损失量化仍存疑。

## 研究背景

当智能体在开放网络中执行多步检索时，其决策质量受限于训练数据的逻辑复杂度与训练环境的稳定性。若数据仅包含简单的混淆（obfuscation）结构，模型难以泛化至包含循环依赖与反馈回路的真实知识网络；同时，依赖外部 API 的强化学习（Reinforcement Learning, RL）训练面临高延迟、故障与输出不一致问题，导致轨迹数据被污染，策略收敛受阻。

现有开源智能体训练主要沿两条路线演进：数据构建方面，WebSailor 等采用基于种子问题的迭代扩展策略，生成树状逻辑结构，但无法覆盖现实世界中常见的稠密循环关系；训练方面，ASearcher 等方法直接依赖真实网络环境进行大规模 RL，受限于 API 成本与并发限制，难以支持高频算法迭代与消融实验。WebSailor-V2 的切入点在于同时解决数据结构的拓扑局限与环境工程的稳定性瓶颈，通过离线模拟器加速算法验证，并通过数据-策略反馈闭环动态优化训练集，从而在有限模型规模下逼近闭源系统性能。

## 核心方法

### 方法参照系

本文基于 ReAct 框架，将智能体轨迹定义为思考（$\tau_t$）、行动（$a_t$）与观察（$o_t$）的序列，策略 $\pi(a_t, \tau_t | H_{t-1})$ 基于历史上下文采样。与通用 RL 智能体不同，本文核心差异在于将数据构建与 RL 训练解耦为两个可独立优化且相互反馈的模块，而非端到端黑盒训练。

### 稠密知识图谱与多不确定性数据生成

传统数据构建依赖树状扩展，导致逻辑结构单一。WebSailor-V2 在图谱构建阶段主动建立节点间稠密连接，刻意引入循环结构以模拟真实知识网络的非线性依赖。在子图提取上，采用随机游走策略替代穷举枚举，利用 Weisfeiler-Leman 算法验证非同构性，确保结构多样性。QA 生成时，不仅分析拓扑中的轨道节点分布以均衡问题焦点，更引入超越混淆的多种不确定性定义，迫使模型执行假设生成与验证。该设计解决了树状结构无法覆盖复杂循环推理的失效，使模型具备处理多源证据冲突与间接依赖的能力。

### 双环境强化学习与数据-策略共生闭环

真实网络 API 的波动性会污染 RL 训练信号。WebSailor-V2 构建基于离线 Wikipedia 的高保真模拟环境，用于低成本高频次的算法迭代与数据筛选；同时设计统一工具执行接口，通过 QPS 约束、结果缓存与故障重试机制，将真实环境抽象为确定性接口。RL 算法采用 GRPO 变体，其优势估计器为：

$$ A_{\hat{i},t} = \frac{r_i - \text{mean}(r_{1:N})}{\text{std}(r_{1:N})} $$

其中 $r_i$ 为轨迹奖励，通过组内归一化降低方差。数据筛选模块根据训练动态实时合成与过滤高质量样本，形成数据-策略共生闭环。该机制解决了真实环境噪声导致策略收敛不稳定的问题，使 30B 模型能在稀疏奖励下有效探索。

## 实验评估

实验在 BrowseComp-EN/ZH、GAIA、HLE 及 xBench-DeepSearch 上进行，基线涵盖开源（ASearcher、WebExplorer、DeepSeek-V3.1）与闭源（OpenAI-o3、Claude-4-Sonnet）智能体。

| 模型 | 参数规模 | BrowseComp-EN | BrowseComp-ZH | GAIA | HLE |
| :--- | :--- | :--- | :--- | :--- | :--- |
| WebSailor-V2-30B-A3B (RL) | 30B | 35.3 | 44.1 | 74.1 | 30.6 |
| DeepSeek-V3.1-671B | 671B | 30.0 | 49.2 | 63.1 | 29.8 |
| ASearcher-Web-32B | 32B | 5.2 | 15.6 | 52.8 | 12.5 |
| OpenAI-o3 | - | 49.7 | 58.1 | 70.5 | 20.2 |

WebSailor-V2 在开源模型中全面领先，GAIA 74.1 分超越 OpenAI-o3 的 70.5 分，HLE 30.6 分超过 671B 的 DeepSeek-V3.1（29.8 分），证明智能体训练可部分弥补模型规模差距。SFT 冷启动阶段已达成 BrowseComp-EN 24.4 分，表明高质量合成数据对初始策略的奠基作用。

消融实验未单独列出，但文中指出 SFT 阶段使用纯合成数据，RL 阶段采用严格 on-policy 训练并排除超长负样本以防止格式崩溃。数据-策略闭环的动态筛选机制是性能提升的关键，但论文未量化模拟环境与真实环境间的分布差异对最终策略的影响。

评估采用 pass@1 指标，温度 0.85，top-p 0.95，使用 LLM 作为裁判。代码已开源，但模拟环境的构建依赖特定 Wikipedia 版本，复现时需确保数据一致性。GAIA 74.1 分与领域综述中 Fathom-DeepResearch 的 45.47 分存在巨大差距，可能源于评估协议或子集差异，需进一步核实。

## 关联研究分析

从数据构建看，WebSailor-V2 与 ASearcher 的“易到难”迭代扩展策略形成鲜明对比。ASearcher 依赖简单种子问题逐步增加复杂度，生成树状结构，适合线性推理任务；而 WebSailor-V2 通过稠密图谱采样引入循环依赖，更贴近真实知识网络的复杂性。这一差异源于任务特性：深度研究常涉及多源证据交叉验证，树状结构无法模拟这种非线性依赖，导致模型在复杂场景中泛化能力不足。

从训练环境看，WebSailor-V2 与直接依赖真实 API 的 RL 方法（如 ASearcher）存在工程化差异。后者受限于 API 成本与稳定性，难以支持高频消融实验；前者通过模拟环境隔离噪声，加速算法迭代。然而，模拟环境基于离线 Wikipedia，其信息时效性与真实网络存在差异，这种分布偏移对策略迁移的影响未被量化。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

WebSailor-V2 针对开源智能体与闭源系统的性能差距，抓住数据逻辑结构单一与 RL 环境不稳定两大瓶颈，通过稠密知识图谱生成多不确定性数据，并设计双环境 RL 框架实现数据-策略协同进化。在 Qwen3-30B-A3B 上，其 GAIA 74.1 分与 HLE 30.6 分超越 671B 的 DeepSeek-V3.1，验证了工程化训练对缩小规模差距的有效性。然而，模拟环境基于离线 Wikipedia，其信息时效性与真实网络存在分布差异，这种偏移对策略迁移的影响未被量化。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
