# ICLR2026最新论文 ｜CPQS-TUNING: A MODEL SELF-PERCEPTION-BASED - DATA FILTERING ALGORITHM FOR EFFICIENT IN STRUCTION FINE-TUNING ｜基于模型自感知的指令数据筛选

研究机构：南京大学、西安电子科技大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_83851564)

> 指令微调面临数据冗余与噪声导致的训练效率低下问题，现有筛选方法依赖外部预定义指标，忽略了目标模型自身的感知差异。本文切入点在于利用大语言模型（LLM）隐层状态中编码的数据质量信号，通过外部卷积神经网络（CNN）构建对比感知质量分数（CPQS）进行筛选。该方法在通用与下游任务上以不足10%的数据量超越全量训练及现有基线，但其泛化边界与因果机制尚存疑。

## 研究背景

指令微调旨在将预训练模型转化为能遵循人类意图的助手，其性能高度依赖训练数据的质量。当使用大规模合成数据时，高质量与低质量样本混杂，直接训练会导致模型性能受损。LIMA等工作证明，少量高质量数据即可对齐模型，这促使研究重心转向从大规模数据集中筛选高价值子集。

现有数据筛选方法主要分为基于预定义奖励模型、多维质量指标及小模型代理三类。这些方法的共同缺陷在于评估标准是外生的，未考虑目标微调模型对数据的内部感知。例如，ALPAGASUS使用强模型评分，MoDS结合质量与覆盖度指标，Superfiltering利用小模型评估难度。这种外生评估与目标模型实际需求之间的错位，可能导致筛选出的数据并非对该模型最优。本文切入点在于假设LLM隐层状态隐含了对数据质量的评估，通过解析这一内部信号实现模型自感知的数据筛选。

## 核心方法

### 方法参照系

数据筛选的标准流程是从大规模指令数据集中提取特征，计算质量分数并保留高分样本。本文问题与该通用流程的关键差异在于特征来源：传统方法使用外部模型评分或统计指标，本文使用目标LLM处理数据时产生的隐层状态作为特征，将筛选过程内化为模型对自身训练数据的感知解析。

### 隐层状态提取与对比数据集构建

设计动机在于解决外部评估指标与目标模型内部表征不匹配的问题。通常做法是使用独立奖励模型打分，本文改为提取目标LLM处理指令-响应三元组时的隐层状态。具体而言，将Instruction与Input拼接作为用户输入，Response作为助手输入，仅保留Response部分对应的隐层状态，因为数据质量主要取决于响应内容。为构建训练CNN的对比数据，从Alpaca-GPT4中随机采样5,000条作为高质量样本，使用Llama-3.2-1B-Instruct和Qwen2.5-1.5B-Instruct重新生成响应，各采样5,000条作为低质量样本，形成1:2的正负样本比例，共15,000条训练数据。

### 基于CNN的对比感知质量分数计算

设计动机在于隐层状态是高维向量，需通过轻量级模型解析其质量信号。通常做法是使用线性探针或MLP，本文采用包含2D和1D卷积的CNN架构，以捕捉隐层状态中的空间与序列模式。CNN通过自适应最大池化和全连接层执行二分类，输出预测概率作为CPQS。CPQS的计算公式为：

$$ CPQS = \sigma(W_{fc} \cdot \text{MaxPool}(Conv_{2D/1D}(H_{response}))) $$

其中 $H_{response}$ 为响应部分的隐层状态，$\sigma$ 为Sigmoid函数。该公式的物理含义是：CNN将LLM对数据的内部感知转化为一个标量分数，分数越高表示该样本对当前模型的训练价值越大。在预测阶段，对每个新样本提取隐层状态并输入CNN，根据CPQS阈值筛选数据子集。

## 实验评估

实验在Alpaca-GPT4、Reasoning-DeepSeek、GSM8K及Magicoder-Evol-Instruct-110K数据集上进行，对比ALPAGASUS、MoDS、Superfiltering三种基线。基线覆盖了LLM评分、多维指标及小模型代理路线，但缺失LESS（梯度法）和TRIM（注意力法）等基于模型内部信号的强基线，这可能影响对“内部信号筛选”优势的全面评估。

| 数据集/模型 | 方法 | 数据量 | GSM8K | HumanEval | AlpacaEval |
|---|---|---|---|---|---|
| Alpaca-GPT4 / Llama2-7B | Self (CPQS) | 1k | - | - | 55.98 |
| Alpaca-GPT4 / Llama2-7B | Alpagasus | 1k | - | - | 49.65 |
| Reasoning-DeepSeek / Qwen2.5-7B | Self (CPQS) | 10k | 85.37 | 36.36 | - |
| Reasoning-DeepSeek / Qwen2.5-7B | Full | 146k | 85.06 | 30.71 | - |
| GSM8K / Qwen2.5-7B | Self (CPQS) | 500 | 81.12 | - | - |
| GSM8K / Qwen2.5-7B | Full | 7.5k | 69.83 | - | - |

在通用域，CPQS筛选的1k样本在AlpacaEval上达到55.98，超越Alpagasus的49.65；在下游数学任务，Qwen2.5-7B-Instruct使用500个筛选样本在GSM8K上达到81.12，显著高于全量训练的69.83，表明筛选有效去除了噪声。

消融实验显示，使用Qwen2.5-7B-Instruct全层隐层状态训练的CNN在GSM8K上达到84.91，优于仅使用最后11层的83.70，表明全层表征包含更完整的质量信号。在代码任务上，最后11层表现优于早期层，暗示不同任务依赖不同层级的表征。这一发现揭示了隐层状态中任务特异性信息的分布差异，但论文未深入分析各层的具体贡献机制。

评估边界方面，实验仅使用7B参数模型，未验证方法在更大规模模型上的有效性；CPQS分数依赖CNN分类器的准确性，而CNN训练数据仅来自两个小模型生成的低质量样本，其泛化能力存疑。代码已开源，但超参数（如CNN结构细节）未在正文中完全披露，可复现性依赖代码仓库。

## 关联研究分析

从方法设计看，CPQS与TRIM（Nagaraj et al., 2025）均利用模型内部信号，但TRIM基于注意力权重计算显著性分数，而CPQS基于隐层状态训练外部CNN。TRIM假设注意力权重直接反映样本重要性，CPQS则假设隐层状态编码了质量评估，需通过CNN解析。这一差异源于对“内部信号”的不同解读：注意力是计算过程，隐层状态是计算结果。CPQS引入外部CNN增加了模型复杂度，但可能更鲁棒地捕捉非线性质量信号。

从问题动机看，CPQS与LESS（Xie et al., 2023）都旨在降低数据筛选成本，但LESS基于梯度计算样本贡献，计算开销大；CPQS基于前向传播提取隐层状态，计算成本较低。LESS的梯度信号直接关联模型参数更新，CPQS的隐层信号关联模型内部表征，两者在“数据质量”的定义上存在微妙差异：LESS关注样本对性能提升的边际贡献，CPQS关注模型对样本质量的感知。这种定义差异导致两者在特定任务上的表现可能不同，论文未提供直接对比。

## 总结

本文核心矛盾是指令微调中数据质量评估与目标模型内部感知脱节。切入点在于利用LLM隐层状态作为质量信号源，通过外部CNN解析生成CPQS分数。方法在7B模型上以不足10%数据量实现性能超越，如GSM8K上500样本达81.12 vs 全量69.83。边界在于CNN训练数据仅来自小模型生成的低质量样本，且未与梯度/注意力法基线直接对比。当目标模型规模扩大或数据分布变化时，隐层状态中的质量信号是否仍保持线性可分性，论文未给出回答。
