# ICLR2026最新论文 ｜Bootstrapping MLLM for Weakly-Supervised Class-Agnostic Object Counting ｜弱监督类别无关目标计数

研究机构：同济大学、武汉大学

作者：Xiaowen Zhang、Zijie Yue、Yong Luo 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.12774)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.12774)

> 目标计数任务旨在从图像中估计特定类别实例的数量，传统全监督方法依赖高昂的点级标注，而现有弱监督方法多局限于单一类别。多模态大语言模型（MLLM）虽具备零样本计数潜力，但在密集场景下因预训练数据分布偏差导致严重低估。本文提出WS-COC，通过分治对话、比较排序及全局局部融合策略，仅利用图像级计数标签引导MLLM实现高精度类别无关计数。该方法在FSC-147上达到与全监督SOTA相当的性能，但其推理效率与密集场景下的绝对精度仍受限于MLLM骨干的计算开销。

## 研究背景

当检测器面对新生成模型时，其训练域与测试域的数据分布出现系统性差异——这一现象称为分布偏移。分布偏移导致传统分类器决策边界失效，而实际场景中往往能获取少量目标域样本，这恰好构成了小样本学习的条件：仅凭每个类别极少量标注样本泛化到新任务。解决此类问题的经典框架是原型网络，它计算各类别支持样本的特征均值作为"原型"，再通过距离度量完成分类。

目标计数任务的核心矛盾在于标注成本与密集场景精度的权衡。全监督方法通过密度图回归实现高精度，但需为每个实例提供点级标注，在数百或数千物体共存的密集场景中成本极高。现有弱监督方法仅利用图像级计数标签，但多局限于行人等单一类别，且基于CNN或ViT的架构缺乏跨类别泛化能力。MLLM凭借大规模视觉-语言预训练，提供了文本提示驱动的类别无关计数新路径，但其自回归生成机制在密集场景下表现出显著的低估偏差，源于预训练语料中稀疏物体分布的主导地位。

本文切入点在于利用MLLM的推理能力重构计数监督信号。直接微调MLLM预测绝对计数面临视觉-文本模态鸿沟，导致密集场景下映射失效。WS-COC将计数任务解耦为范围判断、相对排序与局部增强三个子任务，通过多轮对话引导模型从易到难学习数量感知，从而在极低标注成本下逼近全监督性能。

## 核心方法

### 方法参照系

传统弱监督计数方法（如GCNet）基于CNN/ViT骨干，通过图像级标签直接回归计数值，缺乏跨类别泛化能力。本文采用MLLM作为骨干，将计数转化为文本生成任务，关键差异在于利用语言建模损失优化相对关系而非绝对数值，以缓解模态鸿沟。

### 分治对话调优（D3T）

直接回归绝对计数在密集场景下困难，D3T将预测任务重构为一系列范围判断。给定图像 $I$ 和真实计数 $c$，初始范围 $[L_1, U_1]$ 设为数据集最小最大计数（如FSC-147的 $[1, 2000]$）。第 $t$ 轮计算中点 $\tau_t = \lfloor (L_t + U_t) / 2 \rfloor$，构造指令 $Q_t$：“Are there more than $\tau_t$ [obj] in the image?”，真实响应 $R_t^{gt}$ 为“yes”（若 $c > \tau_t$）或“no”。模型预测 $R_t$ 并通过语言建模损失优化。范围更新规则为：若 $R_t^{gt} = \text{yes}$，则 $L_{t+1} = \tau_t, U_{t+1} = U_t$；否则 $L_{t+1} = L_t, U_{t+1} = \tau_t$。当 $U_t - L_t < \delta \cdot c$（$\delta=0.2$）时终止，要求模型预测实际计数。该设计通过课程学习缓解直接回归的噪声，使模型逐步聚焦密集区域。

### 比较排序计数优化（CRCO）

视觉特征高维而计数为离散标量，直接优化存在模态鸿沟。CRCO训练模型对多图像进行相对排序。对每个类别，将计数范围 $[c_{min}, c_{max}]$ 分为 $K=4$ 个等长区间，从每个区间随机采样一图像构成集合 $\mathcal{I} = \{I_1, I_2, I_3, I_4\}$，其计数满足 $c_1 < c_2 < c_3 < c_4$。随机打乱顺序后，构造指令要求模型输出排序结果，通过语言建模损失优化。该策略利用相对差异的视觉可探测性，避免绝对数值回归的困难，且通过分层采样确保稀疏与密集场景均被覆盖。

### 全局局部计数增强（GLCE）

推理阶段，全局预测 $c_g$ 易低估（81.2%情况），局部聚合预测 $c_l$ 易高估（79.4%情况，因边缘效应）。GLCE将图像划分为 $L \times L$（$L=2$）子图，独立查询每个子图计数 $c_k$，最终计数为 $c = \alpha c_g + (1-\alpha) \sum_{k=1}^{L^2} c_k / L^2$。该融合利用全局与局部预测的互补偏差，显著降低密集场景误差。

## 实验评估

实验在FSC-147（6,135张图像，147类）、CARPK、PUCPR+及ShanghaiTech上进行，指标为MAE和RMSE。基线覆盖全监督方法（CLIP-Count, T2ICount, CountGD, VLPG）及弱监督方法（GCNet, CLIP-Count*, T2ICount*），但缺乏其他MLLM-based弱监督计数方法的对比。

| 方法 | 监督类型 | FSC-147 Test MAE | FSC-147 Test RMSE |
|---|---|---|---|
| T2ICount | point-level | 11.76 | 97.86 |
| CountGD | point-level | 14.76 | 120.42 |
| GCNet | image-level | 17.83 | 102.89 |
| WS-COC | image-level | 13.91 | 97.28 |

WS-COC在FSC-147测试集MAE为13.91，优于弱监督基线GCNet（17.83）和CLIP-Count*（30.01），接近全监督SOTA T2ICount（11.76）。在密集场景（>100实例/图），WS-COC MAE从MLLM-Zero的149.69降至54.37，显著缓解低估问题。

消融实验显示，移除D3T导致MAE增加3.21（测试集），移除CRCO增加2.84，移除GLCE增加1.81。D3T停止阈值 $\delta=0.2$ 最优；CRCO中 $K=4$ 优于 $K=3$ 或 $K=7$；GLCE中 $L=2$ 优于 $L=3$ 或 $L=4$。反直觉发现：测试阶段应用D3T（WS-COC w/ D3T-T）性能劣于训练阶段应用，因中间轮次错误判断会误导模型方向。

评估边界：未报告计算效率详细对比（仅Table 4显示训练时间3.44小时，FPS 2.16），未提供置信区间。代码开源，超参数（LoRA rank 128, scaling 256）明确，可复现性良好。

## 关联研究分析

从问题动机看，WS-COC与CLIP-Count（Jiang et al., 2023）均解决类别无关计数，但CLIP-Count基于VLM判别式头预测密度图，需点级标注；WS-COC利用MLLM生成式能力，仅需图像级标签。差异根源在于任务特性：密度图回归依赖局部特征，而MLLM自回归生成依赖全局语义，后者在密集场景下更易受预训练分布偏差影响，需通过D3T/CRCO显式建模数量关系。

从方法设计看，WS-COC与CrowdCLIP（Liang et al., 2023）均采用排序策略，但CrowdCLIP通过裁剪单图不同尺寸子图构建排序集，假设大裁剪含更多物体；WS-COC跨图像采样不同计数实例，利用语言建模损失直接生成排序。差异根源在于监督信号形式：CrowdCLIP依赖对比学习优化视觉特征，WS-COC依赖语言建模优化文本生成，后者更契合MLLM的推理机制，但可能牺牲视觉细节捕捉能力。

## 总结

WS-COC解决的核心矛盾是密集场景下MLLM计数低估与图像级标签信息不足之间的张力。其切入点在于利用MLLM的推理能力，通过D3T将绝对计数转化为范围判断，CRCO利用相对排序缓解模态鸿沟，GLCE融合全局局部预测互补偏差。实验证明，在FSC-147测试集上，WS-COC MAE为13.91，优于弱监督基线GCNet（17.83），接近全监督SOTA T2ICount（11.76）。本文边界在于推理效率（FPS 2.16）低于全监督方法，且密集场景MAE（54.37）仍高于稀疏场景，暴露了MLLM骨干在极端密集分布下的局限。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
