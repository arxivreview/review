# ICLR2026最新论文 ｜HSIC BOTTLENECK FOR CROSS-GENERATOR AND - DOMAIN-INCREMENTAL SYNTHETIC IMAGE DETEC TION ｜基于HSIC瓶颈的跨生成器与域增量合成图像检测

研究机构：国立台湾大学、国立清华大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_33667738)

> 合成图像检测面临生成模型快速迭代与检测器泛化滞后的结构性矛盾，现有基于视觉基础模型（VFM）的方法虽能捕捉通用分布差异，但常受限于骨干网络中无关语义信息的干扰，且缺乏应对新渲染域（如3DGS）的持续适应能力。本文切入点在于识别并抑制CLIP特征中与真实性无关的文本对齐噪声，同时构建信息论引导的回放机制以解决域增量学习中的灾难性遗忘。具体做法是在CLIP ViT中间层特征上施加Hilbert-Schmidt Independence Criterion (HSIC) 瓶颈，并提出HSIC-Guided Replay (HGR) 进行样本选择。该方法在3DGS持续检测任务上显著优于基线，但在通用GenImage基准上未超越最新SOTA，其价值在于为开放世界下的动态检测提供了可解释的特征整形与记忆管理范式，但HSIC对低层伪迹的压缩效应尚存疑。

## 研究背景

当检测器面对新生成模型时，其训练域与测试域的数据分布出现系统性差异——这一现象称为分布偏移。分布偏移导致传统分类器决策边界失效，而实际场景中往往能获取少量目标域样本，这恰好构成了小样本学习的条件：仅凭每个类别极少量标注样本泛化到新任务。解决此类问题的经典框架是原型网络，它计算各类别支持样本的特征均值作为"原型"，再通过距离度量完成分类。

AI生成图像检测的核心挑战在于应对生成模型逼真度的指数级提升与检测器泛化能力滞后之间的结构性矛盾。早期研究聚焦于挖掘生成器在空间或频率域留下的特定低层伪迹，思路直观却受制于跨生成器泛化能力的严重不足。随着冻结视觉基础模型（Vision Foundation Model, VFM）被证明能捕捉更深层的统计分布差异，领域范式从“寻找特定伪迹”转向“利用通用表示”。然而，现有VFM检测器（如UniFD）直接利用CLIP最终层特征，这些特征主要优化于文本-图像对齐，嵌入了与真实性无关的语义信息，导致在纯图像检测任务中引入噪声。同时，面对3D Gaussian Splatting (3DGS) 等新兴渲染管线，静态检测器无法适应分布漂移，亟需一种既能抑制无关语义、又能持续适应新域的检测机制。

## 核心方法

### 方法参照系

本文问题属于“基础模型特征挖掘”与“动态适应与持续学习”的交叉路线。标准VFM检测流程通常冻结CLIP骨干，仅训练线性探针，缺乏对特征空间内部噪声的显式约束，且无持续学习机制。本文的关键差异在于引入信息论正则化重塑特征空间，并设计基于信息相关性的回放策略。

### HSIC瓶颈特征整形

设计动机在于解决CLIP特征中语义聚类与真实性边界不一致的问题，即原始特征按物体类别聚集而非按真假标签分离。本文在CLIP ViT的24个中间层与最终层特征拼接后，通过投影层压缩至潜在空间 $z$，并优化HSIC目标函数：

$$ \mathcal{L}_{HSIC} = \lambda_x \text{HSIC}(x, z) - \lambda_y \text{HSIC}(y, z) $$

该公式通过最小化输入 $x$ 与潜在表示 $z$ 的依赖性（抑制文本对齐等噪声），同时最大化标签 $y$ 与 $z$ 的依赖性（保留真假判别信息），从而生成生成器不变且具判别力的表示。

### HSIC引导回放 (HGR)

承接HSIC瓶颈输出的特征空间，HGR解决域增量学习中的灾难性遗忘。传统回放方法（如iCaRL）基于类均值或随机采样，未考虑样本的信息量。本文提出结合HSIC相关性评分 $r_i$ 与k-center覆盖度 $d_i(t)$ 的混合评分函数：

$$ s_i(t) = \alpha r_i + \lambda_{kc} d_i(t) $$

其中 $r_i$ 衡量样本在特征空间中的信息中心性，$d_i(t)$ 衡量样本与已选集合的空间距离。通过最小化该评分选择样本，HGR确保回放缓冲区既包含高信息量的代表性样本，又覆盖特征空间的广泛分布，从而在适应新3DGS域时稳定保留旧域性能。

## 实验评估

实验在GenImage（跨生成器泛化）和自建3DGS基准（域增量学习）上进行。基线覆盖CNNSpot、UniFD、NPR等经典方法，但缺失WaRPAD、SSAFE等最新SOTA，限制了通用检测性能的全面对比。

| 方法 | GenImage Avg ACC (Diffusion Train) | GenImage Avg ACC (GAN Train) | 3DGS mACC (SDV1.4 Base) |
| :--- | :--- | :--- | :--- |
| UniFD | 65.37 | 77.72 | 63.87 |
| NPR | 76.50 | 82.84 | - |
| Ours (w/ intermediate) | 93.86 | 91.07 | 94.38 |
| iCaRL | - | - | 92.40 |
| CBRS | - | - | 92.66 |

在GenImage上，本文方法（Ours w/ intermediate）平均ACC达93.86%（扩散训练）和91.07%（GAN训练），显著优于UniFD（65.37%/77.72%）和NPR（76.50%/82.84%），但低于领域综述中提到的WaRPAD（95.8%）。在3DGS域增量任务中，HGR的平均mACC为94.38%，优于iCaRL（92.40%）和CBRS（92.66%），且接近Oracle（93.75%），表明其有效缓解了遗忘。

消融实验显示，同时启用HSIC(x,z)和HSIC(y,z)并使用中间层特征时性能最佳（SDV1.4: 93.86%），仅使用最终层特征性能下降至91.69%。HSIC核函数选择中，RBF核配合中位数启发式带宽表现最优，优于Cosine和IMQ核。这表明中间层特征蕴含更多结构线索，且HSIC正则化对核函数敏感。

评估边界方面，论文未报告置信区间，数值比较需谨慎。代码未公开，超参数细节（如 $\lambda_x, \lambda_y$ 的具体值）未在正文中明确列出，影响可复现性。3DGS基准为自建，缺乏外部验证，其代表性有待社区确认。

## 关联研究分析

从问题动机看，本文与UniFD同属VFM检测路线，但UniFD直接利用CLIP最终层特征，假设其已包含足够的真假判别信息；本文则指出最终层特征受文本对齐语义干扰，需通过HSIC瓶颈显式抑制。这一差异源于任务特性：UniFD侧重跨生成器泛化，而本文额外关注3DGS渲染域的持续适应，后者对特征空间的纯净度要求更高。从方法设计看，本文的HGR与iCaRL同属回放机制，但iCaRL基于类均值选择样本，未考虑样本的信息量；本文引入HSIC相关性评分，将信息论原则融入样本选择。这一改进是否在所有域增量场景中均优于类均值策略，论文仅在3DGS任务上验证，未在其他域（如视频、局部编辑）上测试，其普适性存疑。

## 总结

本文要解决的核心矛盾是VFM特征中无关语义噪声与开放世界下持续适应能力的缺失。本文抓住的切入点是CLIP特征中语义聚类与真实性边界的不一致性，以及传统回放机制对样本信息量的忽视。通过HSIC瓶颈重塑特征空间，HGR优化回放样本选择，本文在3DGS域增量任务上实现了94.38%的mACC，优于iCaRL的92.40%。本文的边界在于GenImage基准上未超越最新SOTA，且3DGS基准为自建，缺乏外部验证。当支持集增大到5-shot时，HSIC引导回放的边际收益是否递减，论文未给出回答。
