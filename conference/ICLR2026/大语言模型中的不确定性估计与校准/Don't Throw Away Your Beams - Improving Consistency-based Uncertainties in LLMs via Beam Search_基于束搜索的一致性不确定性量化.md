# ICLR2026最新论文 ｜Don't Throw Away Your Beams: Improving Consistency-based Uncertainties in LLMs via Beam Search ｜基于束搜索的一致性不确定性量化

> 导读 大语言模型在短文本问答中的不确定性量化面临采样冗余与高方差的双重困境，传统多项式采样因分布尖锐导致大量重复输出，严重削弱一致性估计的鲁棒性。现有黑盒方法虽通过语义聚类缓解词法噪声，却未触及采样机制本身的低效本质。本文提出以束搜索替代多项式采样生成候选集，并引入概率加权估计器，在零额外计算成本下显著降低估计方差。该工作以增量式改进验证了采样策略对一致性指标的决定性影响，但其有效性是否可迁移至长文本或复杂推理场景仍存疑。

## 研究背景

当大语言模型（Large Language Models, LLMs）在医疗、法律等高风险场景部署时，其输出的可靠性依赖于准确的不确定性量化（Uncertainty Quantification, UQ）。一致性估计作为黑盒场景的主流范式，通过评估多次采样输出与最终答案的语义或词法一致性来推断置信度。然而，在短文本问答任务中，模型输出分布往往高度尖锐，多项式采样极易产生大量重复样本。这种采样冗余不仅造成计算资源的直接浪费，更导致一致性估计量在多次运行间呈现高方差，使得置信度信号难以稳定区分正确与错误回答。

领域内主流研究聚焦于提升一致性度量的语义区分度，如通过双向蕴含关系进行语义聚类以消除表面形式差异。但这一路线隐含了一个未被充分审视的前提：采样过程能够充分且无偏地覆盖模型输出空间。在短答案场景下，多项式采样的重复率高达30%–50%，意味着即便采用最先进的语义聚类算法，其输入候选集本身已严重失真。本文正是切入这一被忽略的采样层瓶颈，指出在短文本问答中，优化候选生成策略比改进一致性度量函数具有更高的边际收益，且束搜索可在不增加推理成本的前提下提供去重、高概率且稳定的候选集。

## 核心方法

### 一致性估计的采样层参照系

一致性不确定性估计的标准流程包含两个解耦环节：候选生成与一致性度量。通常做法是通过多项式采样从模型输出分布中抽取 $M$ 个独立同分布样本，再计算这些样本与目标答案 $\mathbf{y}^*$ 的平均语义或词法相似度。该流程的关键假设是采样集能无偏近似模型的真实输出分布。然而，在短文本问答中，该假设因分布尖锐性而失效，导致候选集退化为少数高频答案的重复副本，使得后续的一致性度量建立在失真的经验分布之上。

### 概率加权束搜索估计器

针对多项式采样在短文本中的重复与高方差问题，本文在候选生成环节引入束搜索（Beam Search），并在一致性度量环节引入概率加权机制。传统做法将采样输出视为均匀分布进行平均，而束搜索输出的候选天然具有不同的序列概率，直接均匀平均会过度代表低概率候选。为此，本文定义束集 $\text{BM}(\mathbf{x}) = \{\mathbf{b}^{(1)}, \dots, \mathbf{b}^{(M)}\}$ 上的归一化质量权重：

$$w_i = \frac{p(\mathbf{b}^{(i)} | \mathbf{x})}{\sum_{j=1}^{M} p(\mathbf{b}^{(j)} | \mathbf{x})}$$

基于该权重，一致性度量从均匀平均改为重要性加权估计。以 Dissimilarity 为例，其束搜索加权估计器为：

$$\hat{U}_{D[b]}(\mathbf{y}^* | \mathbf{x}) = \sum_{i=1}^{M} w_i \cdot (1 - s(\mathbf{y}^*, \mathbf{b}^{(i)}))$$

该公式的物理含义是：高概率候选对不确定性估计的贡献被放大，低概率候选的贡献被抑制，从而在避免重复的同时更准确地反映模型分布的真实形状。这一设计直接解决了多项式采样在尖锐分布下因重复导致的估计方差膨胀问题，且由于束搜索本身即为生成最终答案的解码策略，不确定性估计无需额外前向传播，计算成本近乎为零。

### 分布无关的误差下界分析

为从理论上确立束搜索估计器的优越性，本文推导了其在均方误差（Mean-Squared Error, MSE）上优于蒙特卡洛估计器的充分条件。设束集总概率质量为 $m_B$，束集内与束集外的平均不相似度分别为 $\mu_B$ 和 $\bar{\mu}_B$，则束搜索估计器的确定性平方误差为 $(1-m_B)^2(\mu_B - \bar{\mu}_B)^2$。当该误差小于蒙特卡洛估计器的方差上界时，束搜索估计器必然更优：

$$(1-m_B)^2(\mu_B - \bar{\mu}_B)^2 < \frac{\sigma^2}{M}$$

该不等式表明，只要束搜索捕获了足够高的概率质量（$m_B$ 接近1），即便存在截断偏差，其估计精度仍显著优于无偏但高方差的多项式采样。这一理论分析为短文本场景下放弃无偏性换取低方差提供了严格的数学依据，明确了方法生效的边界条件。

## 实验评估

实验在 TriviaQA、CoQA、HotpotQA 等六个短文本问答数据集上进行，采用 PRR（Prediction Ranking Ratio）作为核心指标，在 Llama 3.1 8B、Gemma 3 4B、Qwen 3 8B 等模型的 base 与 instruct 变体上验证。基线覆盖信息论（MSP, Perplexity）、反思（P(True)）及采样一致性（Semantic Entropy, Lexical Similarity）等主流路线，但未包含基于图结构聚合或共形预测的复杂语义方法。

| 方法 | Llama 3.1 8B base | Llama 3.1 8B instruct | Gemma 3 4B base | Gemma 3 4B instruct |
| :--- | :--- | :--- | :--- | :--- |
| Dissimilarity | .505 ±.018 | .379 ±.028 | .630 ±.021 | .206 ±.019 |
| Dissimilarity + beamsearch | **.543** ±.019 | .417 ±.026 | **.650** ±.022 | .252 ±.022 |
| Eccentricity | .453 ±.016 | .368 ±.029 | .563 ±.021 | .231 ±.025 |
| Eccentricity + beamsearch | .505 ±.017 | .397 ±.029 | .603 ±.023 | .285 ±.024 |
| CocoaMSP | .505 ±.018 | .404 ±.025 | .587 ±.023 | .314 ±.024 |
| CocoaMSP + beamsearch | .521 ±.019 | **.426** ±.024 | .615 ±.021 | **.345** ±.026 |

束搜索加权在所有模型与一致性变体上均带来稳定提升，其中 Dissimilarity 在 Llama 3.1 8B base 上从 0.505 提升至 0.543，Eccentricity 在 Gemma 3 4B base 上从 0.563 提升至 0.603。值得注意的是，提升幅度在 base 模型上普遍大于 instruct 模型，这印证了理论分析中 $m_B$ 的作用：base 模型分布更尖锐，束搜索捕获的概率质量更高，方差降低收益更显著。此外，混合方法 CocoaMSP 结合束搜索后在 Gemma 3 4B instruct 上达到 0.345，超越所有纯信息论基线，验证了采样优化对混合范式的普适增益。

评估协议存在两点局限：一是 PRR 指标与领域常用的 AUROC 不可直接换算，跨论文比较需谨慎；二是实验仅覆盖短文本问答，未验证长文本生成或推理链场景。论文未提供代码仓库，但方法仅依赖标准解码接口，复现门槛较低。

## 关联研究分析

从问题动机看，本文与 Semantic Entropy（Kuhn et al., 2023）共享“一致性估计”框架，但二者攻击的失效点截然不同。Semantic Entropy 假设采样充分，致力于解决词法变异性对语义一致性的干扰；本文则指出在短文本中采样本身即不充分，词法层面的重复已使语义聚类失去意义。这一差异揭示了领域内一个被忽视的层级关系：在短答案场景下，采样质量是语义度量的前置条件，而非可独立优化的模块。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

从方法设计看，本文与 GENUINE（Wang et al., 2025）代表了黑盒 UQ 的两条互补路径。GENUINE 通过图结构聚合捕捉 token 级语义依赖，以计算复杂度换取表示精度；本文则通过优化解码策略，以零额外成本换取估计稳定性。二者并非替代关系，而是作用于一致性估计流程的不同环节。当束搜索候选集已充分覆盖高概率区域时，图结构聚合的边际收益是否递减，论文未给出回答。

## 总结

本文针对短文本问答中多项式采样导致的一致性估计高方差问题，提出以概率加权束搜索替代传统采样，并通过理论分析确立了其在分布尖锐条件下的误差优势。实验表明，该采样层改进在所有测试模型与一致性变体上均带来稳定提升，Dissimilarity 在 Llama 3.1 8B base 上 PRR 从 0.505 提升至 0.543。然而，方法有效性严格依赖于束集概率质量 $m_B$ 足够高这一前提，在长文本或分布平坦的生成任务中，束搜索的多样性不足可能使截断偏差主导误差，导致理论优势失效。当输出长度增加导致 $m_B$ 下降时，束搜索加权估计器是否会退化为次优解，论文未给出回答。
