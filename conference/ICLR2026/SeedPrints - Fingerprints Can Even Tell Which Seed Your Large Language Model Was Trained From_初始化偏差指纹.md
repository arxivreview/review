# ICLR2026最新论文 ｜SeedPrints: Fingerprints Can Even Tell Which Seed Your Large Language Model Was Trained From ｜初始化偏差指纹

研究机构：新加坡国立大学、香港中文大学

作者：Yao Tong、Haonan Wang、Siquan Li 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.26404)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.26404)

> 大语言模型（LLMs）溯源验证旨在确认嫌疑模型是否衍生自特定源模型，以保护模型权重这一高价值资产。现有被动指纹方法依赖训练后涌现的特征，在预训练早期或数据分布剧烈偏移时失效，无法实现全生命周期的身份追踪。本文发现随机初始化本身会在模型内部留下持久的种子依赖偏差，提出 SeedPrints 方法，通过检测这种初始化偏差的统计显著性来验证血缘关系。该方法填补了早期预训练检测的空白，但其依赖白盒访问的局限限制了其在纯黑盒 API 场景下的直接应用。

## 研究背景

当模型所有者需要验证一个疑似窃取的模型是否源自自己的基座模型时，核心挑战在于如何区分“血缘关系”与“训练相似性”。传统被动指纹技术通过提取注意力矩阵分布或权重余弦相似度来识别模型，这些特征在模型完全收敛后表现稳定。然而，这些特征本质上是训练数据、优化动态和超参数的印记，而非模型本身的固有属性。当训练数据分布发生显著变化，或模型处于预训练早期阶段时，这些后验特征尚未形成或已被数据特征覆盖，导致指纹信号消失。

现有指纹研究多聚焦于微调后的模型验证，假设模型已具备稳定的行为签名。这种假设忽略了大模型能力主要获取于预训练阶段的事实，导致现有方法在大规模预训练轨迹的早期检查点上无法可靠检测血缘。例如，在 OLMo-2-7B 的预训练过程中，现有基线方法在早期检查点的相似度分数均低于 0.8 的检测阈值，而最终检查点才达到可接受水平。这种“后验识别”特性使得指纹无法像生物指纹那样从“出生”（初始化）起就存在并持久。本文的切入点在于重新定义指纹的来源：不依赖训练后涌现的特征，而是挖掘随机初始化阶段即存在的、与种子强相关的内部表示偏差，从而建立一种从初始化到部署全周期有效的“Galtonian”指纹。

## 核心方法

### 方法参照系

被动指纹的标准流程是从模型中提取内在特征向量，计算源模型与嫌疑模型的特征相似度，并设定阈值判断血缘。本文的关键差异在于：特征提取不依赖训练后的参数或行为，而是基于随机输入下模型输出的统计偏差；验证机制不依赖固定阈值，而是基于假设检验的 p 值。

### 身份维度提取

传统方法直接比较全维度输出，易受架构相似性和训练动态的干扰。本文首先定义“身份维度”（Identity Dimensions），即两个模型在随机输入下均表现出最低响应的输出坐标交集。对于模型 $g$，计算其在 $n$ 个随机输入序列上的平均响应向量 $\bar{g} = \frac{1}{n} \sum_{i=1}^n g(x_i)$。设 $M(g)$ 为 $\bar{g}$ 中数值最小的 $m$ 个坐标集合，则身份维度 $S = M(f) \cap M(f')$。这一交集操作起到了互验证作用，抑制了由架构共性导致的虚假相关，仅保留可能源自共同初始化血缘的偏差信号。

### 分布相关性假设检验

在确定身份维度 $S$ 后，本文不直接计算相似度，而是检验两个模型在这些维度上的响应分布是否显著相关。对于每个维度 $s_j \in S$，计算两个模型响应序列的 Kendall-Tau 秩相关系数 $\tau_j$。随后，将 $\tau_j$ 的均值 $\bar{\tau}$ 与零假设下的分布进行比较。根据中心极限定理，在弱独立假设下，$\bar{\tau}$ 近似服从正态分布 $N(0, \sigma^2/|S|)$。通过计算 z 分数 $z = \bar{\tau} / (\sigma/\sqrt{|S|})$ 并获取单侧 p 值，若 $p < \alpha$（如 0.01），则拒绝零假设，判定两模型共享血缘。这种统计检验方法避免了固定阈值在不同模型规模或训练阶段下的漂移问题。

## 实验评估

实验在 LLaMA-2、Qwen2.5 等模型家族上进行，基线包括 REEF、PCS、ICS、Intrinsic 和 Gradient 等被动指纹方法。在 LeaFBench 基准（包含 65 个模型、7 个家族、6 种变换）上，SeedPrints 的整体 AUC 为 0.992，KS 统计量为 0.986。虽然略低于 Intrinsic 方法的 0.997 AUC，但显著优于 REEF（0.924 AUC）和 Gradient（0.812 AUC）。在大规模微调场景中，SeedPrints 在 700B tokens 微调后的 Llemma-7B 上仍保持 $10^{-5136}$ 的 p 值，而 REEF 和 ICS 的相似度分数分别降至 0.9470 和 0.2905，低于 0.8 阈值。

| 方法 | LeaFBench AUC | LeaFBench KS | 700B微调后相似度 (Llemma-7B) |
|---|---|---|---|
| SeedPrints | 0.992 | 0.986 | $10^{-5136}$ (p-value) |
| Intrinsic | 0.997 | 0.995 | 0.9470 |
| REEF | 0.924 | 0.801 | 0.9470 |
| ICS | 0.995 | 0.978 | 0.2905 |

消融实验显示，随机输入序列长度 $l$ 对性能影响显著：当 $l$ 从 512 增加到 1024 时，准确率从 0.9048 提升至 1.0000，且假阳性率从 0.04 降至 0。指纹尺寸 $m$ 的影响呈非单调性：$m=400$ 时准确率为 0.9375，而 $m=800$ 时降至 0.875，表明过大的 $m$ 引入了噪声维度，缩小了偏差边际 $\gamma$，需要更多样本才能检测。

评估边界方面，本文主要依赖白盒访问（logits 或 hidden states），未评估纯黑盒 API 场景下的性能。超参数 $n=2000, l=1024, m=0.1 d_{out}$ 在实验中表现稳定，但代码已开源，可复现性良好。指标上，p 值提供了统计显著性保证，但缺乏对计算成本的详细量化分析，特别是在大规模模型库上的验证效率未充分讨论。

## 关联研究分析

从问题动机看，本文与 Intrinsic（Yoon et al., 2025）和 REEF（Zhang et al., 2024）形成鲜明对比。Intrinsic 和 REEF 提取的是训练后形成的注意力分布或权重方向，其鲁棒性依赖于训练过程的稳定性。本文指出，这些方法在数据分布偏移（如从 OpenWebText 转向 The Stack 代码数据）时失效，因为它们追踪的是数据域相似性而非血缘身份。SeedPrints 利用初始化偏差，该偏差在训练前已确定，因此对数据分布变化具有天然的免疫性。这种差异源于对“指纹本质”的不同理解：前者视指纹为训练产物，后者视指纹为初始化遗产。

从方法设计看，本文与 ZeroPrint（Shao et al., 2025）同属被动指纹，但 ZeroPrint 依赖零阶梯度估计，计算成本高且依赖训练动态。SeedPrints 仅需前向传播计算平均响应，计算复杂度更低。然而，ZeroPrint 在纯黑盒场景下更具适用性，而 SeedPrints 必须访问内部状态。这种访问层级的差异决定了两者在部署场景中的互补性：SeedPrints 适用于拥有模型权重或内部访问权限的所有者，而 ZeroPrint 适用于仅能通过 API 交互的场景。本文未探索如何在无内部访问权限下近似初始化偏差，这限制了其在商业 API 模型上的直接应用。

## 总结

本文要解决的核心矛盾是现有指纹方法在预训练早期和数据分布偏移下的失效问题。现有方法依赖训练后涌现的特征，无法捕捉模型“出生”时的固有身份，而本文抓住随机初始化偏差这一被忽略的内在属性，提出 SeedPrints 方法，通过统计检验验证这种偏差的持久性。实验证明，SeedPrints 在 OLMo-2-7B 预训练早期检查点上实现完美检测（p ≪ 0.001），并在 700B tokens 微调后保持极高显著性。其边界在于依赖白盒访问，且未评估在纯黑盒 API 场景下的可行性。当模型所有者无法访问内部状态时，如何仅通过输入输出行为近似初始化偏差，论文未给出回答。
