# ICLR2026最新论文 ｜TRAJECTORY GENERATION WITH CONSERVATIVE VALUE GUIDANCE FOR OFFLINE REINFORCEMENT LEARNING ｜保守价值引导的轨迹生成

研究机构：北京邮电大学

作者：Tieru Wang、Kunbao Wu、Guoshun Nan

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_9928970)

> 离线强化学习（Offline RL）面临的核心困境是分布偏移导致的价值过估计，传统保守算法虽能缓解此问题但计算效率低下，而基于扩散模型的数据增强方法虽能提升数据多样性却因多步去噪过程带来高昂的训练与推理开销。TGCVG 切入这一效率与性能的矛盾点，提出用轻量级 Transformer 策略替代扩散模型，并通过保守 Q 学习（CQL）引导生成动作以限制分布外（OOD）风险。该方法在 D4RL 基准上以显著降低的计算成本实现了与现有 SOTA 相当甚至更优的性能，但其对动力学模型精度的依赖及在长时程任务中的误差累积效应仍存疑。

## 研究背景

当智能体仅能从固定的历史数据集 $\mathcal{D}$ 中学习策略时，若策略生成的动作偏离行为策略 $\pi_\beta$ 的分布，价值函数会在未见过的状态-动作对上产生错误的高估，即外推误差。这种分布偏移是离线 RL 性能退化的根本原因，迫使算法必须在“探索高回报区域”与“保持数据分布一致性”之间做出权衡。传统的保守价值学习（如 CQL）通过惩罚 OOD 动作的 Q 值来抑制过估计，但受限于数据覆盖范围，难以突破性能上限；而近期引入的生成式数据增强方法（如 Synther, GTA）试图通过合成新轨迹来扩展数据分布，但扩散模型的多步去噪机制导致计算开销巨大，且缺乏对高价值区域的显式引导，导致合成数据质量参差不齐。

现有数据增强路线存在明显的效率-质量瓶颈。早期方法如 S4RL 仅通过添加高斯噪声扰动状态，多样性受限且无法捕捉动态一致性；基于扩散模型的方法（Lu et al., 2023; Lee et al., 2024）虽能生成动态一致的样本，但训练成本高且推理慢，难以在实际部署中应用。TGCVG 的切入点在于解耦“数据生成”与“策略训练”：它不直接训练最终的高复杂度策略，而是训练一个轻量的、受保守价值约束的 Transformer 策略作为“数据合成器”，配合预训练的动力学模型自回归生成轨迹。这种设计将计算负担从在线决策阶段转移至离线数据准备阶段，旨在以较低的计算成本获得高质量、分布一致的增强数据，从而提升标准离线 RL 算法的性能。

## 核心方法

### 方法参照系

TGCVG 属于离线 RL 中的数据增强子路径，其参照系是“生成式模型 + 动力学模型”的轨迹合成框架。与直接训练最终策略的模型基方法不同，TGCVG 将生成过程视为一个独立的预处理步骤：先训练一个中间策略和动力学模型，利用二者交互生成合成轨迹，再将这些轨迹与原始数据混合，用于训练标准的无模型离线 RL 算法（如 CQL, TD3BC, IQL）。关键差异在于，TGCVG 用 Transformer 架构替代了扩散模型，并引入了保守价值引导机制来约束生成动作。

### Transformer-CQL 策略训练

在数据生成阶段，策略网络的质量直接决定合成数据的分布特性。常规 Transformer 策略（如 Decision Transformer）通常基于回报条件监督学习（RCSL），缺乏对动作分布边界的显式约束，容易生成 OOD 动作。TGCVG 在此环节引入 CQL 正则化项，构建 Transformer-CQL 策略。其 Q 函数优化目标为：

$$ \min_{\phi} \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}} \left[ \left( Q_\phi(s,a) - r - \gamma \min_{i=1,2} Q_{\phi'_i}(s', \hat{a}') \right)^2 \right] + \alpha \mathbb{E}_{s \sim \mathcal{D}, a \sim \mu(\cdot|s)} \left[ Q_\phi(s,a)^2 \right] - \alpha \mathbb{E}_{s \sim \mathcal{D}, a \sim \pi_\beta(\cdot|s)} \left[ Q_\phi(s,a)^2 \right] $$

该公式中，前两项构成标准的 n-step Bellman 备份，后两项为 CQL 正则化项，通过惩罚数据分布外动作的 Q 值并提升数据分布内动作的 Q 值，确保策略 $\pi_\theta$ 生成的动作 $\hat{a}$ 始终位于数据集支持集内。这一设计解决了纯生成式模型缺乏价值引导、易产生低质量或 OOD 样本的问题，使合成数据既具备动态一致性，又偏向高回报区域。

### 动力学模型引导的自回归生成

策略网络生成动作后，需要预测下一状态和奖励以构建完整轨迹。TGCVG 采用预训练的动力学模型 $f_\omega$ 进行单步预测：

$$ (\hat{s}_{t+1}, \hat{r}_t) = f_\omega(s_t, \hat{a}_t) $$

生成的 $\hat{s}_{t+1}$ 被追加到状态序列窗口中，作为下一步策略网络的输入，形成自回归循环。与扩散模型的多步去噪不同，这种单步预测机制显著降低了计算开销。保守价值引导在此处起到“刹车”作用：由于策略 $\pi_\theta$ 已被 CQL 约束在数据分布内，动力学模型只需在局部邻域内进行预测，从而将 OOD 风险限制在单步交互中，防止误差在长时程 rollout 中累积。最终，生成的轨迹与原始数据随机混合，用于训练最终策略。

## 实验评估

实验在 D4RL 基准的 MuJoCo Gym、Maze2D 和 AntMaze 任务上进行，对比基线包括 S4RL（噪声扰动）、Synther（扩散模型）和 GTA（回报引导扩散）。TGCVG 作为数据增强模块，分别应用于 CQL、TD3BC、IQL 和 DT 四种算法。在 Gym 领域，TGCVG 显著提升所有算法性能，例如在 Hopper-Medium 任务中，TGCVG+TD3BC 达到 90.47 的归一化分数，高于 GTA 的 69.57 和 Synther 的 63.70；在 Walker2D-Medium 任务中，TGCVG+TD3BC 达到 87.50，接近 SOTA 水平。在 Maze2D 和 AntMaze 任务中，TGCVG+IQL 在 AntMaze-Large-Play 任务上达到 83.20，优于 GTA 的 81.88，表明其在稀疏奖励和高维状态空间下的有效性。

| 任务 | 算法 | 增强方法 | 归一化分数 |
| :--- | :--- | :--- | :--- |
| Hopper-Medium | TD3BC | TGCVG | 90.47 |
| Hopper-Medium | TD3BC | GTA | 69.57 |
| Hopper-Medium | TD3BC | Synther | 63.70 |
| Walker2D-Medium | TD3BC | TGCVG | 87.50 |
| AntMaze-Large-Play | IQL | TGCVG | 83.20 |
| AntMaze-Large-Play | IQL | GTA | 81.88 |

消融实验表明，Transformer-CQL 策略优于纯 Transformer-TD3BC 策略，前者在 Hopper-Medium 上比后者高约 10 分，验证了保守价值引导对数据质量的关键作用。此外，TGCVG 的训练与数据生成时间显著低于 GTA，Figure 4 显示 TGCVG 的总时间开销约为 GTA 的 1/4，证实了 Transformer 替代扩散模型在计算效率上的优势。然而，论文未报告 FLOPs 或推理延迟的具体数值，仅定性描述“显著减少”，缺乏严格的量化对比。

评估边界方面，实验仅覆盖 D4RL 标准基准，未涉及真实世界部署场景或高维视觉输入任务。代码已开源，但超参数设置（如 CQL 系数 $\alpha$、动力学模型容量）对不同任务的敏感性未充分讨论。在 AntMaze 任务中，TGCVG 的性能提升幅度较小，暗示动力学模型误差在复杂迷宫环境中可能成为瓶颈。

## 关联研究分析

从问题动机看，TGCVG 与 GTA（Lee et al., 2024）均旨在通过生成高回报轨迹提升离线 RL 性能，但 GTA 依赖扩散模型的多步去噪过程，计算开销大且缺乏显式的分布约束，导致合成数据可能偏离原始分布。TGCVG 通过 Transformer-CQL 策略引入保守价值引导，将生成动作限制在数据支持集内，解决了 GTA 中 OOD 风险累积的问题。这一差异源于任务特性：GTA 追求数据多样性，而 TGCVG 更强调分布一致性与计算效率的平衡。TGCVG 的设计表明，在数据覆盖有限的情况下，保守约束比单纯的回报引导更能保证合成数据的可靠性。

从方法设计看，TGCVG 与 Synther（Lu et al., 2023）同属生成式数据增强路线，但 Synther 使用扩散模型学习转移分布，缺乏价值引导，导致合成数据质量参差不齐。TGCVG 引入 CQL 正则化，使策略网络在生成动作时考虑价值信息，从而偏向高回报区域。这一改进源于对“数据质量”而非“数据数量”的重视。TGCVG 的实验结果（如 Hopper-Medium 上 90.47 vs Synther 的 63.70）证实了价值引导对性能提升的关键作用。然而，TGCVG 依赖预训练的动力学模型，其性能受限于模型精度，而 Synther 直接学习转移分布，可能在模型误差较小的任务中更具优势。TGCVG 在 AntMaze 任务上的表现（83.20 vs GTA 的 81.88）提升有限，暗示动力学模型误差在复杂环境中可能抵消价值引导的收益。

## 总结

TGCVG 解决的核心矛盾是离线 RL 中数据增强方法的计算效率与性能上限之间的权衡。现有扩散模型方法虽能生成动态一致的轨迹，但多步去噪导致计算开销巨大，且缺乏价值引导，导致合成数据质量不稳定。TGCVG 抓住这一痛点，提出用轻量级 Transformer-CQL 策略替代扩散模型，并通过保守价值引导约束生成动作在数据分布内，从而以较低的计算成本获得高质量增强数据。实验证明，TGCVG 在 D4RL 基准上显著提升了标准离线 RL 算法的性能，例如在 Hopper-Medium 任务中，TGCVG+TD3BC 达到 90.47 的归一化分数，高于 GTA 的 69.57，且训练时间仅为 GTA 的 1/4。然而，TGCVG 的性能受限于动力学模型的精度，在 AntMaze 等复杂任务中提升幅度较小，暗示模型误差在长时程生成中可能累积。当动力学模型误差超过一定阈值时，保守价值引导是否仍能有效抑制 OOD 风险，论文未给出回答。
