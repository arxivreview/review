# ICLR2026最新论文 ｜MatRIS: Toward Reliable and Efficient Pretrained Machine Learning Interatomic Potentials ｜材料表征与交互模拟：基于分离注意力的不变原子间势

作者：Yuanchang Zhou、Siyu Hu、Xiangyu Zhang 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.02002)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.02002)

> 机器学习原子间势（MLIPs）旨在以远低于密度泛函理论（DFT）的成本逼近量子化学精度，但主流等变架构因依赖高阶张量积导致计算开销巨大，限制了大规模模拟的可行性。本文切入点在于质疑等变对称性在海量量子力学（QM）数据下的必要性，提出不变架构 MatRIS，通过引入线性复杂度的分离注意力机制显式建模三体相互作用。该设计在保持近 DFT 精度的同时，将训练效率提升 6.4 至 13 倍，验证了数据充足时不变架构的高效性，但其对长程相互作用的建模能力仍存疑。

## 研究背景

原子模拟的核心困境在于 DFT 计算成本随系统规模呈立方级增长，而 MLIPs 通过从数据中学习势能面（PES）来突破这一瓶颈。在形式化定义上，MLIP 的目标是学习映射函数 $f_\theta: (\mathbf{R}, \mathbf{Z}) \rightarrow E$，使得预测能量与 DFT 参考能量误差最小化。早期不变模型依赖距离和角度等局部几何特征，虽计算高效但难以捕捉复杂多体相互作用；随后 E(3)-等变架构（如 MACE、NequIP）通过不可约表示（irreps）和 Clebsch-Gordan 张量积原生满足旋转与平移对称性，显著提升了精度，确立了当前主流范式。然而，这种精度提升以计算复杂度的急剧增加为代价，张量积运算的内存和计算开销使得大规模预训练成本高昂，例如 eSEN-30M-MP 和 eqV2 S DeNS 分别需要 335 和 228 个 A100 GPU 天。

随着 QM 参考数据集（如 MPTrj、OMAT24）的迅速扩张，数据规模已足以让模型从数据中隐式学习对称性，这引发了一个核心问题：在数据充足的前提下，严格的等变约束是否仍是实现高精度所必需的？现有等变模型的高计算成本主要源于三个因素：密集的等变运算、庞大的参数量以及冗长的训练周期。本文 MatRIS 正是在此背景下提出，旨在通过一种更紧凑的不变架构，充分利用 QM 数据中的高维原子交互信息，从而在降低计算成本的同时维持甚至超越等变模型的精度。

## 核心方法

### 方法参照系

MatRIS 属于不变 MLIP 架构，其标准流程包括图生成、特征嵌入、消息传递和读出。与 DPA3 等基于线图的不变模型不同，MatRIS 的关键差异在于引入了基于注意力的三体交互建模机制，而非简单的径向基函数聚合，旨在解决传统两体交互在区分复杂化学性质时的表达力不足问题。

### 线图构建与三体交互

传统 MLIP 通常仅通过原子对之间的边特征捕捉两体相互作用，这在 Xu et al. (2019) 中被证明不足以区分具有不同化学性质的图结构。MatRIS 显式构建线图（Line Graph）来编码三体相互作用：在原子图中，节点代表原子，边代表键；在线图中，节点代表原子图的边，而线图中的边则代表共享同一原子的两条边，即角度信息。这种结构允许模型在消息传递过程中自然地融入角度特征，从而捕捉更丰富的局部几何信息。

### 分离注意力与维度级 Softmax

为提升表达力并降低计算复杂度，MatRIS 引入了两种注意力机制。首先是维度级 Softmax（Dim-wise Softmax），它针对每个特征维度独立计算注意力权重，打破了传统注意力在所有维度共享权重的假设，从而保留特征维度的独立性。其计算公式为：

$$ \alpha_{d} = \text{softmax}\left( \frac{x_{id} \cdot x_{jd}^T}{\sqrt{D}} \right) $$

其中 $x_{id}$ 表示节点 $i$ 的第 $d$ 个特征，$D$ 为隐藏维度。这一设计使得模型能够区分不同特征维度的相对重要性，增强对局部结构信息的捕捉能力。

其次是分离注意力（Separable Attention），它显式区分目标节点和源节点的角色，分别计算源注意力和目标注意力权重。在极性键或缺陷结构中，源节点对目标节点的影响与反向影响往往不对称。MatRIS 通过两个独立的注意力分支并行处理这种非对称性，其输出为源、目标注意力权重与融合边特征的加权和。这种机制不仅提高了模型对复杂化学环境的感知能力，还通过线性复杂度 $O(N)$ 的注意力计算，避免了全注意力机制 $O(N^2)$ 的开销，实现了表达力与效率的平衡。

## 实验评估

MatRIS 在 Matbench-Discovery、MatPES、MDR phonon 和 Molecular zero-shot 等基准上进行了评估，基线涵盖 MACE-MP-0、eSEN-30M-MP、eqV2 S DeNS、SevenNet 等主流等变与不变模型。在 Matbench-Discovery 合规测试中，MatRIS-L 取得了 F1 分数 0.847 和 RMSD 0.0717 的最优结果，超越了 eSEN-30M-MP 的 0.831 和 eqV2 S DeNS 的 0.815。

| 模型 | 参数量 | F1 (↑) | MAE (↓) | RMSD (↓) |
| :--- | :--- | :--- | :--- | :--- |
| eSEN-30M-MP | 30.1M | 0.831 | 0.033 | 0.0752 |
| eqV2 S DeNS | 31.2M | 0.815 | 0.036 | 0.0757 |
| MatRIS-L | 10.4M | **0.847** | **0.031** | **0.0717** |

MatRIS-L 以更少的参数量（10.4M vs 30.1M）实现了更高的 F1 分数和更低的能量误差，证明了不变架构在大数据下的优越性。在训练效率方面，MatRIS-S 和 MatRIS-M 分别比 eqV2 S DeNS 和 eSEN-30M-MP 提升了 13.0 倍和 6.4 倍的训练速度，验证了分离注意力机制在降低计算开销方面的有效性。

消融实验表明，维度级 Softmax 和分离注意力对模型精度有显著贡献。移除维度级 Softmax 导致 MAE 从 28.0 meV/atom 上升至 28.4 meV/atom，而移除分离注意力则进一步增加至 29.1 meV/atom。此外，去噪预训练和磁矩预测任务也提升了模型性能，其中磁矩预测作为节点级任务，有助于缓解过平滑问题。

| 消融项 | Ef MAE (meV/atom) |
| :--- | :--- |
| 完整模型 | 28.0 |
| 无 Dim-wise Softmax | 28.4 |
| 无 Separable Attention | 29.1 |
| 无 Learnable Envelope | 31.3 |

评估边界方面，MatRIS 在 MatPES 上取得了 0.033 eV/atom 的形成能 MAE，优于 MACE-MP-0 的 0.07 eV/atom，但在长程相互作用建模上缺乏直接证据。论文未提供代码 URL，且部分实验结果（如 MDR phonon）未报告置信区间，数值比较需谨慎。此外，MatRIS 在 OOD 场景下的泛化能力未得到充分验证，其不变架构在分布外数据上的可靠性仍需进一步考察。

## 关联研究分析

从问题动机看，MatRIS 与 DPA3 同属不变架构路线，但 DPA3 依赖径向基函数和线图进行静态特征聚合，而 MatRIS 引入动态注意力机制以捕捉非对称交互。这一差异源于任务特性：DPA3 侧重于晶体结构的静态性质预测，而 MatRIS 旨在通过注意力机制提升对复杂化学环境（如极性键、缺陷）的感知能力。MatRIS 的分离注意力设计解决了传统消息传递中源-目标角色混淆的问题，这在 DPA3 中未被显式处理，可能导致在复杂分子体系中的精度损失。

从方法设计看，MatRIS 与 eSEN-30M-MP 等高效等变模型形成对比。eSEN-30M-MP 通过稀疏激活和高效张量积降低计算成本，但仍依赖等变约束；MatRIS 则完全摒弃等变约束，转而依赖数据驱动学习对称性。这一设计选择反映了两种不同的技术路线：等变模型通过结构先验保证物理一致性，而不变模型通过数据规模换取表达灵活性。MatRIS 在 Matbench-Discovery 上的优越表现表明，在数据充足时，不变架构可能比等变架构更具效率优势，但这是否适用于所有化学空间（如过渡金属配合物）仍存疑问。

## 总结

MatRIS 旨在解决等变 MLIPs 计算成本高昂与不变架构表达力不足之间的矛盾，其核心切入点在于利用海量 QM 数据隐式学习对称性，并通过分离注意力机制显式建模三体交互。该方法在 Matbench-Discovery 上实现了 F1 0.847 和训练效率 13 倍提升，证明了不变架构在大数据下的高效性。然而，MatRIS 的边界在于其未显式建模长程静电和色散效应，且在 OOD 场景下的泛化能力缺乏充分验证。当训练数据覆盖度不足时，不变架构是否仍能保持对复杂化学环境的鲁棒性，论文未给出回答。
