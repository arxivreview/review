# ICLR2026最新论文 ｜DON’T PASS@K: A BAYESIAN FRAMEWORK FOR LARGE LANGUAGE MODEL EVALUATION ｜贝叶斯后验评估框架

研究机构：美国凯斯西储大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_50500922)

> 大语言模型（LLM）评估长期依赖 Pass@k 等点估计指标，在有限样本下排名不稳定且缺乏统计显著性判断。现有方法无法区分真实能力差异与采样噪声，导致排行榜频繁波动。本文提出基于 Dirichlet 先验的后验估计框架，将评估转化为统计推断问题，提供闭式解的可信区间。该框架在数学推理基准上实现了小样本下的快速收敛，但其对题目难度异质性的忽略可能限制其在复杂基准上的泛化能力。

## 研究背景

LLM 推理任务具有随机性，同一模型对同一问题多次采样会产生不同结果。传统评估通过计算 N 次试验的平均准确率（avg@N）或至少一次正确的概率（Pass@k）来量化性能。然而，当 N 较小时，这些点估计的方差极大，导致模型排名随试验次数增加而剧烈波动。这种不稳定性源于将评估视为确定性计算，而非对潜在成功概率的统计推断。

当前 LLM 评估领域面临的核心矛盾是计算成本与统计可信度的冲突。全面评估需运行数万题目，耗时且昂贵；而减少试验次数以降低成本时，Pass@k 等指标的高方差特性使得微小分数差异无法被区分，排名结果不可靠。主流路线如 Bootstrap 近似或中心极限定理（CLT）误差棒在小样本场景下校准失效，无法提供有效的置信区间。本文切入点在于将评估重构为贝叶斯推断问题，通过引入先验分布与后验更新，在有限样本下提供具有统计保证的性能估计与不确定性量化。

## 核心方法

### 贝叶斯评估参照系

本文问题属于心理测量与统计建模范畴，但与传统项目反应理论（IRT）不同，它不建模题目难度参数，而是假设题目难度固定，仅对模型在每道题目上的潜在成功概率进行贝叶斯推断。关键差异在于支持非二元分类输出，允许对部分正确、格式错误等中间状态进行量化，从而提升评估对推理过程质量的测量效度。

### 分类后验估计与闭式解

传统 Pass@k 仅处理二元结果，无法捕捉模型输出的细粒度特征。本文引入加权评分量表（Weighted Rubric），将每次试验的结果映射到 C+1 个离散类别，并通过 Dirichlet 先验计算后验均值。对于第 α 道题目，设其结果向量为 $\mathbf{R}_\alpha$，权重向量为 $\mathbf{w}$，后验均值 $\mu$ 的闭式解为：

$$ \mu = \frac{1}{M} \sum_{\alpha=1}^{M} \sum_{j=0}^{C} \frac{\nu_{\alpha j}}{T} (w_j - w_0) $$

其中 $T = 1 + C + D + N$，$\nu_{\alpha j}$ 为第 α 题第 j 类的计数加先验。该公式的物理含义是：通过先验平滑与数据计数，直接计算模型在所有题目上的加权平均成功概率，无需迭代优化或蒙特卡洛模拟。这一设计解决了 Pass@k 在 k 接近 N 时方差爆炸的问题，提供了数值稳定的点估计。

### 不确定性量化与显著性检验

点估计无法判断两个模型的性能差异是否显著。本文利用后验方差 $\sigma^2$ 构建可信区间（CI），并定义排名置信度 $\rho$。对于两个模型的后验均值 $\mu, \mu'$ 与标准差 $\sigma, \sigma'$，其差值的 z 分数为：

$$ z = \frac{|\mu - \mu'|}{\sqrt{\sigma^2 + (\sigma')^2}} $$

排名置信度 $\rho = \frac{1}{2}(1 + \text{erf}(z/\sqrt{2}))$。当 CI 重叠时，不宣布胜负，从而避免排行榜的过度解读。这一机制将“是否显著”从模糊的统计检验转化为透明的区间重叠判断，解决了传统方法缺乏原则性决策规则的问题。

## 实验评估

实验在 AIME'24/25、HMMT'25 和 BrUMO'25 四个数学推理基准上进行，每个模型运行 80 次试验。基线覆盖 Pass@k (k=2,4,8)、Pass^k、G-Pass 和 mG-Pass，但未包含动态基准生成类方法（如 AutoBench），因本文不涉及题目生成。主结果显示，Bayes@N 在 N=10 时 Kendall's τ > 0.90，N=80 时 τ ≈ 0.95（AIME'25）或 ≈ 1.0（其他基准），显著快于 Pass@k 的收敛速度。

| 数据集 | Bayes@N (N=10) τ | Bayes@N (N=80) τ | Pass@8 (N=80) τ |
| :--- | :--- | :--- | :--- |
| AIME'25 | >0.90 | ≈0.95 | <0.90 |
| HMMT'25 | >0.90 | ≈1.0 | <0.90 |

消融实验表明，引入可信区间后，AIME'25 的排名压缩至 11 个不同等级，而 HMMT'25 和 BrUMO'25 压缩至 14 个等级，说明 AIME'25 在 80 次试验下不确定性更高。设计决策验证显示，列式与行式 Bootstrap 产生几乎相同的收敛曲线，证明结果对试验顺序不敏感。

评估边界方面，本文仅使用数学推理基准，未验证在代码生成或开放式问答上的有效性；代码开源（Scorio），超参数（温度 0.6, top-p 0.95）固定，GPU 成本为 1651-2217 小时/基准，可复现性高。

## 关联研究分析

从问题动机看，RankLLM（Zhang et al., 2026）同样关注排名稳定性，但其通过二部图迭代传播估计题目难度与模型能力，而本文假设题目难度固定，仅推断模型能力。这一差异源于任务特性：数学推理题目难度相对均匀，而通用基准题目难度异质性强。本文方法在难度分布不均的基准上是否失效，论文未给出回答。

从方法设计看，EssenceBench（Wang et al., 2025）通过子集选择重构分数，目标是降低计算成本；本文通过贝叶斯推断提升统计可信度，目标是降低收敛所需样本量。两者互补：EssenceBench 解决“测多少题”，本文解决“测几次”。本文未采用子集选择，而是全量题目下的统计推断，这在题目数量较少（如 AIME 30 题）时更具优势，但在大规模基准上可能计算开销较高。

## 总结

本文要解决的核心矛盾是 LLM 评估中有限样本下的排名不稳定性与统计显著性缺失。现有 Pass@k 方法因高方差无法区分真实差异与噪声，而本文通过贝叶斯后验框架提供闭式解的均值与可信区间，实现了小样本下的快速收敛与透明决策。实验证明，Bayes@N 在 N=10 时 τ > 0.90，N=80 时 τ ≈ 0.95-1.0，显著优于 Pass@k。本文的边界在于仅验证数学推理基准，且假设题目难度固定，未建模题目异质性。当基准题目难度分布高度不均时，该假设是否导致排名偏差，论文未给出回答。
