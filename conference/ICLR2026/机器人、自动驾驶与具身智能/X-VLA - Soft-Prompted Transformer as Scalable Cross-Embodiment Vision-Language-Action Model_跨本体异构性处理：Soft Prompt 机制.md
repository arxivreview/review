# ICLR2026最新论文 ｜X-VLA: Soft-Prompted Transformer as Scalable Cross-Embodiment Vision-Language-Action Model ｜跨本体异构性处理：Soft Prompt 机制

研究机构：清华大学、北京大学

作者：Jinliang Zheng、Jianxiong Li、Zhihao Wang 等 15 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.10274)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.10274)

> 跨本体视觉-语言-动作模型（Vision-Language-Action, VLA）旨在通过大规模混合数据预训练实现通用机器人策略，但硬件配置、相机设置及动作空间的异构性导致严重的分布偏移，使现有独立解码器方案难以有效蒸馏共享知识。本文切入点在于将异构性视为任务特异性特征，通过引入轻量级可学习嵌入（Soft Prompt）在特征融合早期注入本体信息，而非仅在后端处理动作空间差异。该方法以标准 Transformer 编码器堆叠结合流匹配（Flow Matching）动作头，实现了跨平台稳定预训练与高效适配。其价值在于以极小参数开销（1%）达成接近全量微调的性能，但在极端异构场景下的泛化边界尚存疑。

## 研究背景

当 VLA 模型在混合本体数据上训练时，不同机器人的动作维度、控制频率及视觉域差异导致特征空间无法对齐。这种异构性不仅体现在低层动作信号，更渗透至高层视觉语义理解，若未有效解耦，模型将陷入“平均化”陷阱，导致预训练误差累积并阻碍下游适配。解决此问题的关键概念是参数高效微调（Parameter-Efficient Fine-Tuning, PEFT），它通过冻结骨干网络、仅更新少量适配参数，在保留通用知识的同时吸收特定域特征。

传统 VLA 架构如 π0 或 RDT 主要依赖为每个本体分配独立的动作解码器头，以处理动作空间差异。然而，这种“后端隔离”策略忽略了相机视角、视觉域及任务分布等前端异构性，导致模型在混合数据训练中难以建立跨本体的共享表征。现有方法在应对多维异构性时，往往因参数冗余或优化冲突而性能受损，无法在保持骨干通用性的同时实现细粒度的本体适配。

本文针对这一瓶颈，提出将异构性处理前置至特征融合阶段。通过借鉴提示学习（Prompt Learning）思想，为每个数据源分配一组可学习的 Soft Prompt 嵌入，使模型在早期特征交互中即感知硬件配置差异。这一设计旨在克服独立解码器方案对非动作异构性（如视觉域偏移）的忽视，从而在单一骨干中实现更稳定的跨本体知识蒸馏与高效的新域适配。

## 核心方法

### 方法参照系

本文问题属于 VLA 架构中的跨本体预训练与适配范畴。标准流程通常采用 VLM 骨干提取多模态特征，再通过独立动作头生成连续动作。本文的关键差异在于，不采用独立参数处理本体差异，而是引入共享骨干内的 Soft Prompt 机制，将异构性编码为输入端的条件信号，实现“一模型多本体”的统一建模。

### Soft Prompt 嵌入机制

设计动机在于解决独立解码器方案无法捕获视觉域与任务分布异构性的问题。在标准 Transformer 编码器中，多模态 token（视觉、语言、本体感觉）直接进行自注意力交互。本文在每个数据源对应的输入序列前，插入一组可学习的 Soft Prompt 嵌入 $P_i \in \mathbb{R}^{k \times d}$，其中 $k$ 为 prompt 长度，$d$ 为隐藏维度。这些嵌入与多模态 token 拼接后，共同进入堆叠的自注意力层：

$$
H = \text{Transformer}([P_i; X_{\text{multi}}])
$$

该公式表明，Soft Prompt 作为条件前缀，在特征融合初期即引导注意力机制区分不同本体的特征分布。通过这种方式，模型无需为每个本体分配独立参数，而是通过共享骨干学习本体无关的通用策略，同时利用 Soft Prompt 吸收本体特异性偏差，显著降低了参数冗余并提升了混合数据训练的稳定性。

### 两阶段适配策略

承接 Soft Prompt 的预训练输出，本文提出两阶段适配以解决新域部署问题。第一阶段冻结预训练骨干，仅优化新域的 Soft Prompt 与动作头，实现快速初始化；第二阶段解冻部分参数进行联合微调。适配损失函数定义为：

$$
\mathcal{L}_{\text{adapt}} = \mathbb{E}_{(o, A) \sim D_{\text{new}}} \left[ \ell_{\text{FM}}(\pi_\theta(o, P_{\text{new}}), A) \right]
$$

其中 $P_{\text{new}}$ 为新域对应的 Soft Prompt。该设计允许模型在保留通用知识的前提下，通过极少量参数（仅 1% 总参数，约 9M）快速适配新硬件配置。相比全量微调，该策略避免了灾难性遗忘，并在数据稀缺场景下表现出更强的鲁棒性，实现了从“预训练通用策略”到“部署特定策略”的高效转化。

## 实验评估

实验在 6 个仿真基准（LIBERO, Simpler-WidowX, Calvin, RoboTwin 2.0, VLABench, NAVSIM）及 3 个真实机器人平台上进行。基线覆盖 π0、OpenVLA、RDT 等主流 VLA 模型，但缺失 HiMoE-VLA 等最新 MoE 架构对比。主结果显示，X-VLA-0.9B 在 LIBERO 平均准确率达 98.1%，Simpler-WidowX 达 95.8%，Calvin ABC→D 达 4.43，均超越或持平于 SOTA 基线。

| 基准 | X-VLA-0.9B | π0 | OpenVLA-OFT | RDT |
| :--- | :--- | :--- | :--- | :--- |
| LIBERO Avg | 98.1 | 95.7 | 93.9 | 97.1 |
| Simpler-WidowX | 95.8 | - | 60.5 | 97.6 |
| Calvin ABC→D | 4.43 | - | - | 4.53 |
| RoboTwin 2.0 Easy | 70.0 | 46.4 | - | - |

消融实验表明，Soft Prompt 机制对预训练验证误差降低贡献显著。从基线模型（验证误差 0.11）到引入 Soft Prompt（0.041），误差降低 62.7%。进一步缩放模型至 0.9B 后，Simpler-WidowX 适配成功率从 73.8% 提升至 89.6%。值得注意的是，多域联合微调在某些场景下性能优于单域微调，暗示 Soft Prompt 促进了跨本体知识互补。

评估边界方面，论文未报告置信区间，且部分基准（如 NAVSIM）仅报告聚合分数。代码与超参数已公开，但 290K episodes 数据混合比例（如 Agibot 48.8%）可能影响结果可复现性。此外，Simpler-WidowX 95.8% 的成绩显著高于领域综述中 StructVLA 的 75.0%，需确认评估协议一致性，可能存在版本或子集差异。

## 关联研究分析

从问题动机看，X-VLA 与 HiMoE-VLA 均针对跨本体异构性，但路径迥异。HiMoE-VLA 采用层级混合专家（MoE）路由，通过动态分配 token 至特定专家处理动作维度差异，代价是增加路由计算开销与训练复杂度。X-VLA 则通过 Soft Prompt 在输入端注入本体信息，避免了专家路由的稀疏激活问题，更适合数据源固定且异构性主要源于硬件配置的场景。差异根源在于：MoE 适合动作空间维度差异巨大的本体，而 Soft Prompt 更适合视觉域与任务分布差异显著的本体。

从方法设计看，X-VLA 与 π0 同属 Flow Matching 路线，但 π0 采用独立动作头处理本体差异，X-VLA 则将异构性处理前置至特征融合。π0 在短程任务中延迟更低，但 X-VLA 通过 Soft Prompt 实现了更稳定的混合数据预训练。X-VLA 未探索 Soft Prompt 在极端异构（如机械臂 vs 人形）下的有效性，其假设是本体间存在足够的视觉与任务相似性。若本体差异过大，Soft Prompt 可能无法充分捕获异构性，导致预训练误差累积。

## 总结

X-VLA 旨在解决跨本体 VLA 训练中硬件配置、视觉域及任务分布异构性导致的分布偏移问题。现有独立解码器方案仅处理动作空间差异，忽视前端异构性，导致混合数据训练不稳定。本文通过 Soft Prompt 机制在特征融合早期注入本体信息，结合两阶段适配策略，以 1% 参数开销实现高效新域适配。实验证明其在 LIBERO 达 98.1%、Simpler-WidowX 达 95.8%，验证了轻量级适配的有效性。然而，论文未报告 Soft Prompt 在极端异构本体（如机械臂与人形）下的性能衰减，且多域联合微调的正迁移效应缺乏大规模消融。当本体间视觉域与任务分布差异超过一定阈值时，Soft Prompt 是否仍能维持预训练稳定性，论文未给出回答。
