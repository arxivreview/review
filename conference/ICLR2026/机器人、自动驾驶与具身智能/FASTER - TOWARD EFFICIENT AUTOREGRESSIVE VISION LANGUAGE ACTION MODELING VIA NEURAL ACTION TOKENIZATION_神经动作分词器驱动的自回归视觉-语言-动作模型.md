# ICLR2026最新论文 ｜FASTER: TOWARD EFFICIENT AUTOREGRESSIVE VISION LANGUAGE ACTION MODELING VIA NEURAL ACTION TOKENIZATION ｜神经动作分词器驱动的自回归视觉-语言-动作模型

研究机构：清华大学、复旦大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_54705946)

> 自回归视觉-语言-动作模型（VLA）面临动作离散化导致的推理延迟与重建保真度双重瓶颈，现有分词方案无法兼顾压缩效率与控制精度。FASTer 通过引入基于残差向量量化（RVQ）的神经动作分词器与块状自回归解码机制，在保持自回归范式语义优势的同时，将推理速度提升至实用区间。该框架在 LIBERO 基准上取得 97.9% 成功率，验证了离散 Token 范式在效率与泛化上的竞争力，但其性能仍略低于强化学习后训练方法，且缺乏对长时程记忆机制的整合。

## 研究背景

机器人控制策略需将视觉观测与语言指令映射为连续动作序列，传统扩散模型虽精度较高，但难以充分利用视觉-语言语义线索，且推理过程非自回归，限制了与大规模视觉-语言模型（VLM）架构的兼容性。自回归 VLA 通过离散动作 Token 复用 VLM 的自回归能力，在指令跟随与常识迁移上表现优异，但连续动作的离散化过程面临核心矛盾：Token 数量过少导致重建失真，数量过多则引发推理延迟随序列长度二次方增长。

现有动作分词方法如均匀分箱或一维序列扁平化，未能有效建模动作序列的二维结构特性——动作维度间物理语义差异大且冗余度低，而时间维度存在显著冗余。这种结构失配导致分词器在压缩率与重建质量间难以取得平衡，尤其在全身控制等高自由度场景下，FAST 等前作需 150–200 个 Token 表示 2 秒动作，对应约 3 秒推理延迟。FASTer 的切入点在于借鉴音频编解码器的残差量化思想，通过非均匀分块与混合 Transformer 编码器，构建能同时捕捉局部动态与全局趋势的紧凑离散动作空间，从而在自回归框架内实现高效且保真的动作生成。

## 核心方法

### 动作分词参照系

自回归 VLA 的标准流程是将连续动作序列离散化为 Token 序列，再由 VLM 骨干自回归生成。现有方法多采用均匀分箱或 DCT+BPE 组合，其关键局限在于未显式建模动作序列的二维耦合结构，导致 Token 利用率低且重建保真度受限。FASTer 的差异在于将动作序列视为具有物理语义分组的二维张量，通过非均匀分块与残差量化实现结构化压缩。

### 残差向量量化动作分词器（FASTerVQ）

FASTerVQ 首先对动作序列进行二维非均匀分块：时间维度均匀划分为 $m$ 组，动作维度按物理特性（如末端执行器位置、姿态、夹爪状态）非均匀划分为 $n$ 组，每组填充至最大维度 $d$，形成形状为 $(m \cdot h) \times (n \cdot d)$ 的张量。该设计动机在于缓解不同动作维度数据分布不均（如夹爪状态常为二值，基座运动常为零）导致的训练不稳定。随后，混合 Transformer 编码器将分块动作映射为潜在嵌入 $\mathbf{z} \in \mathbb{R}^{C_h \times C_a}$，并通过 $N_c$ 级残差向量量化（RVQ）分解为离散码本索引：

$$
\mathbf{z}_q = \sum_{i=1}^{N_c} Q_i(\mathbf{r}_i), \quad \mathbf{r}_{i+1} = \mathbf{r}_i - Q_i(\mathbf{r}_i)
$$

其中 $Q_i$ 为第 $i$ 级量化器，$\mathbf{r}_i$ 为残差。RVQ 的粗到细结构使早期阶段捕捉低频分量，后期阶段细化高频残差，从而在极小 Token 预算下保留精细运动细节。训练目标包含时域 $\ell_1$ 损失与离散余弦变换（DCT）频域 $\ell_1$ 损失，以同时优化局部动态与全局趋势重建：

$$
\mathcal{L}_{rec} = \|\mathbf{a} - \hat{\mathbf{a}}\|_1 + \lambda \|\text{DCT}(\mathbf{a}) - \text{DCT}(\hat{\mathbf{a}})\|_1
$$

该设计使 FASTerVQ 在跨本体与跨任务场景中实现近无损重建，且码本利用率达 100%（4096 码本），显著优于 FAST 的 48%（2048 码本）。

### 块状自回归解码与轻量动作专家

FASTerVLA 基于 FASTerVQ 的离散码本，采用块状自回归解码（BAR）替代传统逐 Token 自回归。BAR 利用动作维度 Token 的部分独立性，在每个块内并行预测多个 Token，仅块间保持自回归依赖，从而降低有效自回归深度。该设计动机在于解决高自由度场景下 Token 序列过长导致的推理延迟问题。同时，引入轻量动作专家模块，其架构与 VLM 骨干对齐但参数量高效，用于弥合语言推理与连续控制间的模态差距。位置编码采用旋转位置嵌入（RoPE）并施加间距增强：训练时相邻 Token 位置偏移 $\epsilon_i \sim U[0, k]$（如 $k=2$），推理时恢复固定间距，以缓解固定长度目标导致的位置过拟合。

## 实验评估

实验覆盖 LIBERO、Simpler-Bridge、VLABench 等 9 个基准，包含 4 个真实机器人平台与 4 个仿真环境。基线包括扩散模型（π0、π0.5）、自回归模型（OpenVLA、FAST、UniVLA）及混合模型（Octo-Base、SpatialVLA）。FASTerVLA 在 LIBERO 平均成功率达 97.9%，高于 π0 的 94.2% 与 OpenVLA 的 95.2%；在 Simpler-Bridge 上取得 87.9% 成功率，较次优模型高 12.9%。

| 方法 | LIBERO Avg (%) | Simpler-Bridge Avg (%) |
|---|---|---|
| FASTerVLA | 97.9 | 87.9 |
| π0 | 94.2 | 78.1 |
| OpenVLA | 95.2 | 75.1 |
| FAST | 96.4 | 77.0 |

消融实验显示，FASTerVQ 的贡献占性能提升的主要部分，BAR 解码仅带来较小增量增益。在跨骨干实验中，FASTer 将 InternVL3.5-2B 的成功率提升 17.3% 至 96.65%，表明其分词器对骨干网络的通用性。推理效率方面，在 RTX 5090 上，FASTerVLA 在 LIBERO 单臂设置下推理延迟为 112ms，低于 π0 的 176ms 与 π0-FAST 的 197–556ms；在 R1Lite 全身控制设置下，FASTerVLA 与 π0 延迟相近（约 230ms），而 π0-FAST 高达 1100–3000ms。

评估边界方面，论文未报告置信区间，且未与强化学习后训练方法（如 SimpleVLA-RL）直接对比，后者在 LIBERO 上达 99.1%。代码未公开，超参数细节仅部分披露，可复现性受限。

## 关联研究分析

从动作表征设计看，FASTer 与 π0 的流匹配方法形成范式对立：π0 通过连续动作生成避免离散化损失，但推理计算量高且需动作分块；FASTer 坚持离散 Token 路线，通过 RVQ 的结构化压缩在精度与效率间取得平衡。这一差异源于任务特性——FASTer 更关注推理延迟与跨本体泛化，而 π0 侧重精细操作的平滑性。FASTer 未探索连续-离散混合方案，其在高动态任务中的精度上限是否低于流匹配，论文未给出回答。

从推理效率优化看，FASTer 的 BAR 解码与 TurboVLA 的轻量化架构目标一致，但路径不同：TurboVLA 通过模型剪枝与量化降低计算量，FASTer 通过减少 Token 数量与并行预测降低序列长度。FASTer 的优势在于无需修改骨干网络，仅需替换分词器与解码策略，部署门槛更低。然而，FASTer 未集成显式记忆机制，在长时程任务中可能面临状态遗忘问题，而 HAMLET 等通过历史帧注意力解决此问题，FASTer 未对此类时序依赖进行建模。

## 总结

FASTer 解决的核心矛盾是自回归 VLA 中动作离散化的效率-保真度权衡，其切入点在于借鉴音频编解码器的残差量化思想，通过非均匀分块与 RVQ 构建结构化离散动作空间，并利用块状自回归解码降低推理延迟。该方法在 LIBERO 上取得 97.9% 成功率，推理延迟 112ms，验证了离散 Token 范式在效率与泛化上的竞争力。其边界在于未整合强化学习后训练或显式记忆机制，导致在长时程任务与分布外鲁棒性上可能弱于 SimpleVLA-RL 等方法。当任务序列长度超过 10 步时，FASTer 的块状解码是否仍能维持推理延迟优势，论文未提供相关实验数据。
