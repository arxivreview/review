# ICLR2026最新论文 ｜GT-Space: Enhancing Heterogeneous Collaborative Perception with Ground Truth Feature Space ｜基于真值特征空间的异构协同感知

研究机构：中山大学

作者：Wentao Wang、Haoran Xu、Guang Tan

论文原文见 [arXiv](https://arxiv.org/abs/2603.19308)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.19308)

> 导读 异构协同感知旨在解决不同传感器模态或模型架构产生的特征在语义与粒度上的不对齐问题，传统方法依赖编码器重训或成对解释器，导致系统扩展性差且性能受限于自车模型容量。GT-Space 通过构建基于真值标签的公共特征空间，将各智能体特征投影至该空间进行融合，实现了无需重训编码器的即插即用协作。该方法在 OPV2V 和 V2XSet 上显著提升了异构场景下的检测精度，但其对真值标注的依赖及理想通信假设限制了其在真实噪声环境下的直接适用性。

## 研究背景

当多智能体系统包含不同传感器配置时，各智能体生成的鸟瞰图（Bird's Eye View, BEV）特征在维度、尺度及语义分布上存在显著差异，这种异构性导致直接融合时特征错位，严重降低检测精度。为对齐这些特征，现有方案通常采用编码器重训或特征解释器策略，前者需为每个新智能体维护独立编码器，后者需为每种异构组合设计专用适配器，两者均面临组合爆炸的扩展性瓶颈，且协作性能受制于自车端模型的上限。

异构协同感知的核心矛盾在于如何在开放环境中实现低成本、高泛化的特征对齐。主流路线如 PnPDA 和 HEAL 虽解决了部分对齐问题，但前者仅支持点云模态，后者需重训编码器可能损害原始感知性能。GT-Space 的切入点在于引入一个独立于具体智能体模型的公共参考空间，利用真值标签构建该空间，使各智能体仅需训练轻量级投影器即可接入系统，从而解耦了特征对齐与模型训练过程。

## 核心方法

### 方法参照系

传统异构协同感知遵循“编码-传输-对齐-融合”流程，其中对齐环节通常将接收特征映射至自车特征空间或学习潜空间。本文的关键差异在于将对齐目标从“自车空间”或“学习潜空间”替换为“真值构建的公共空间”，并采用组合对比损失训练融合网络以支持任意模态组合。

### 真值公共特征空间构建

设计动机在于解决传统学习潜空间缺乏显式物体级监督导致域间隙难以弥合的问题。GT-Space 利用场景中的真值边界框标注生成 BEV 特征图。每个 3D 边界框 $B_i = (x, y, z, l, w, h, r, c)$ 通过两层全连接层加层归一化编码为向量 $\beta_i$，随后映射至 BEV 网格。若多个物体覆盖同一网格单元 $c$，其特征相加以保留重叠信息。该过程通过 IoU 损失监督解码器重建边界框，确保生成的真值特征图 $F_{GT}$ 具备准确的物体级空间语义，为异构特征提供精确的对齐基准。

$$
U_c = \sum_{i \in \mathcal{I}_c} \beta_i + PE(c)
$$

此公式表明，每个网格单元的特征是所有覆盖该单元的物体编码特征之和加上位置嵌入，实现了物体级信息的空间化聚合。

### 组合对比学习融合

设计动机在于使融合网络能够处理任意模态组合，并增强物体相关特征。各智能体特征 $F_a$ 通过特定投影器 $\Phi_a$ 映射至公共空间，随后输入 Transformer 融合网络。训练时采用组合对比损失，对所有可能的模态对 $(m, m')$ 计算对比损失。对于物体 $P$ 覆盖的网格 $c$，计算融合特征与真值特征的余弦相似度，通过交叉熵损失拉近同一物体特征、推远不同物体特征。

$$
\mathcal{L}_{m,m'} = -\sum_{P \in \mathcal{B}} \log \frac{\exp(\text{sim}(F_{m,m'}^{P}, U_{\bar{P}}) / \tau)}{\sum_{Q \in \mathcal{B}} \exp(\text{sim}(F_{m,m'}^{Q}, U_{\bar{Q}}) / \tau)}
$$

该公式通过温度控制的余弦相似度度量，强制融合特征在物体级别上与真值特征对齐，从而提升检测相关的特征判别力。

## 实验评估

实验在 OPV2V、V2XSet 和 RCooper 数据集上进行，对比基线包括 HM-ViT、PnPDA、HEAL、Hetercooper 和 STAMP。基线覆盖了端到端训练、编码器重训及解释器对齐等主流异构协同路线，但缺乏通信高效类（如 InfoCom）及鲁棒性类（如 CoopDiff）方法的对比，限制了其在带宽受限或噪声环境下的性能评估。

| 数据集 | 方法 | AP@50 | AP@70 |
| :--- | :--- | :--- | :--- |
| OPV2V | PnPDA | 0.857 | 0.801 |
| OPV2V | HEAL | 0.772 | 0.652 |
| OPV2V | STAMP | 0.887 | 0.804 |
| OPV2V | GT-Space | 0.891 | 0.810 |
| V2XSet | PnPDA | 0.835 | 0.763 |
| V2XSet | HEAL | 0.736 | 0.631 |
| V2XSet | STAMP | 0.854 | 0.778 |
| V2XSet | GT-Space | 0.874 | 0.802 |

GT-Space 在 OPV2V 上以 0.891 的 AP@50 超越 STAMP 的 0.887，在 V2XSet 上以 0.874 显著领先 STAMP 的 0.854，表明真值公共空间在异构对齐上的有效性。

| 配置 | OPV2V AP@50 | V2XSet AP@50 |
| :--- | :--- | :--- |
| w/o-GT feature | 0.868 | 0.830 |
| w/o-projector | 0.791 | 0.716 |
| w/o-contrastive loss | 0.845 | 0.823 |
| Full version | 0.892 | 0.873 |

消融实验显示，移除投影器导致性能大幅下降（OPV2V 从 0.892 降至 0.791），证实了模态特异性投影的重要性；移除真值特征损失 0.024，移除对比损失损失 0.047，表明组合对比学习对物体级特征增强贡献最大。

评估指标仅包含 AP@50/70，未报告通信带宽开销或推理延迟。实验假设理想定位与无延迟通信，未测试定位噪声或通信延迟下的鲁棒性，尽管论文提及了相关实验设置，但未提供具体数值对比。代码已开源，使用 A100 GPU 训练，超参数遵循 OpenCOOD 框架标准。

## 关联研究分析

从方法设计看，GT-Space 与 GenComm 代表了异构对齐的两种不同范式。GenComm 采用生成式模型翻译特征，依赖隐式学习对齐，在零样本场景下表现较好，但存在生成噪声问题；GT-Space 采用显式真值空间对齐，可控性强且易于调试，但依赖真值标注。两者的差异根源在于对“对齐基准”的定义：GenComm 认为基准应来自数据分布的隐式学习，GT-Space 认为基准应来自真值标签的显式构造。这种选择使得 GT-Space 在标注充足场景下性能更优，但在无标注或弱标注场景下适用性受限。

从问题动机看，GT-Space 与 PnPDA 均追求即插即用，但 PnPDA 需为每种模态设计解释器，GT-Space 用统一投影器替代。PnPDA 的局限在于仅支持点云，GT-Space 通过组合对比损失支持任意模态组合。这一改进源于 GT-Space 将对齐目标从“自车空间”转移至“真值空间”，使得投影器无需针对特定模态对进行优化，而是统一映射至公共参考系。这种设计在理论上提升了扩展性，但实际部署中真值空间的构建成本及投影器的训练效率仍需进一步验证。

## 总结

GT-Space 旨在解决异构协同感知中特征对齐的扩展性瓶颈，通过构建真值公共特征空间，使各智能体仅需训练轻量级投影器即可接入系统，避免了编码器重训或成对解释器的组合爆炸问题。该方法在 OPV2V 上以 0.891 的 AP@50 超越 STAMP 的 0.887，在 V2XSet 上以 0.874 领先 STAMP 的 0.854，验证了真值空间对齐的有效性。然而，论文实验假设理想定位与无延迟通信，未提供定位噪声或通信延迟下的具体性能数据，且真值空间的构建依赖高质量标注。当真实场景中定位误差超过一定阈值或通信延迟显著时，真值公共空间的对齐精度是否会急剧下降，论文未给出回答。
