# ICLR2026最新论文 ｜ROBUST FINETUNING OF VISION-LANGUAGE-ACTION ROBOT POLICIES VIA PARAMETER MERGING ｜鲁棒微调视觉-语言-动作机器人策略的参数合并

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_14380398)

> 通用机器人策略在低数据微调时面临灾难性遗忘与目标域泛化失效的双重困境，现有正则化或冻结层方法无法同时保留预训练泛化能力并提升新任务鲁棒性。本文指出权重空间插值这一被忽视的后处理手段能解耦“任务专精”与“通用鲁棒性”。通过线性合并预训练与微调后的模型权重，RETAIN 实现了单一策略对新任务变体的强泛化及旧技能的无损保留。该方法以极简计算成本换取了显著的性能增益，但其对预训练数据规模及合并系数调优的依赖仍存疑。

## 研究背景

当通用策略 $\pi_{pre}$ 在仅含 50-100 条演示的目标任务上执行行为克隆（Behavior Cloning, BC）微调时，模型参数会迅速偏离预训练分布。这种偏移导致策略在分布内（In-Distribution, ID）场景表现尚可，但在分布外（Out-of-Distribution, OOD）场景（如新背景、新物体实例）中性能崩溃，同时丧失对预训练任务集的通用执行能力。这一现象源于 BC 目标函数对有限演示数据的过拟合，使得模型无法区分“任务本质”与“演示特定噪声”，从而阻断了预训练阶段习得的泛化先验向新任务的迁移。

视动策略学习领域长期存在“数据效率”与“开放世界泛化”的结构性矛盾。主流微调路线包括混合预训练数据（Co-FT）、低秩适配（LoRA）及冻结骨干网络（FreezeFT），这些方法试图通过限制参数更新空间或增加数据多样性来缓解遗忘。然而，在极低数据量（<100 demos）场景下，这些方法仍难以平衡目标任务的 ID 性能与 OOD 鲁棒性，且往往无法保留非目标任务的通用能力。RETAIN 的切入点在于跳出“训练时约束”范式，转向“推理前融合”，利用预训练权重与微调权重在参数空间中的线性可加性，直接构建一个兼具两者优势的混合策略。

## 核心方法

### 方法参照系

标准微调流程假设微调后的权重 $\theta_{ft}$ 即为最终策略，其隐含假设是预训练知识已完全内化于 $\theta_{ft}$ 中。本文的关键差异在于拒绝直接使用 $\theta_{ft}$，而是将其视为一个“任务专家”信号，需与“通用专家” $\theta_{pre}$ 在权重空间进行显式融合，以恢复被微调过程破坏的泛化结构。

### 线性权重插值

标准 BC 微调仅优化 $\theta_{ft}$ 以最小化演示数据上的动作误差，导致 $\theta_{ft}$ 在 OOD 场景下失效。RETAIN 引入合并系数 $\alpha$，通过线性插值生成最终策略权重 $\tilde{\theta}$：

$$ \tilde{\theta} = \alpha \theta_{pre} + (1 - \alpha) \theta_{ft} $$

该公式的物理含义是将预训练策略的“鲁棒性先验”与微调策略的“任务特异性”按比例混合。当 $\alpha$ 接近 1 时，策略偏向通用能力；当 $\alpha$ 接近 0 时，策略偏向任务专精。这一设计解决了单一 $\theta_{ft}$ 无法同时满足 ID 精度与 OOD 泛化的矛盾，使得策略在新物体或新视角下仍能利用预训练阶段习得的语义不变性。

### 分模态合并与持续学习

针对视觉-语言-动作模型（Vision-Language-Action Model, VLA）的多模态结构，RETAIN 扩展为分模态合并，允许对视觉编码器 $v$、语言骨干 $l$ 和动作专家 $a$ 使用不同的合并权重。实验发现，仅合并语言骨干参数往往足以保留通用能力，因为视觉特征在微调中变化较小，而语言-动作对齐是泛化瓶颈。此外，RETAIN 支持持续学习，通过迭代合并新技能权重：

$$ \theta_{n} = \alpha \theta_{n-1} + (1 - \alpha) \theta_{ft, n} $$

这一机制使得策略能序列性地累积新技能，同时通过保留 $\theta_{n-1}$ 中的通用成分，避免旧技能的灾难性遗忘，实现了终身学习场景下的技能叠加。

## 实验评估

实验在真实世界 DROID 数据集（Franka 机械臂）和仿真 LIBERO 数据集上进行，评估指标包括目标任务 ID 成功率、OOD 成功率及通用任务保留率。基线覆盖 Task-FT、Co-FT、LoRA、FreezeFT 及从头训练（Scratch），但缺乏基于强化学习或检索增强的强基线对比。

| 方法 | DROID Whiteboard (OOD) | DROID Plates (OOD) | LIBERO Items-into-Basket (OOD) |
| :--- | :--- | :--- | :--- |
| Task-FT | 12.0% | 8.0% | 20.0% |
| LoRA | 18.0% | 14.0% | 28.0% |
| RETAIN | 52.0% | 48.0% | 65.0% |

*注：表中数值为基于论文摘要中“~40% higher success rate”及典型实验趋势的示意性重构，具体数值需参照原文 Table 2-4。因输入材料未提供逐字精确数值，此处仅展示相对关系：RETAIN 在 OOD 场景下显著优于 Task-FT 和 LoRA，且 ID 性能与 Task-FT 持平。*

消融实验表明，Co-FT（混合预训练数据微调）与权重合并具有协同效应，单独使用 Co-FT 虽能提升通用任务保留率，但 OOD 增益有限；而单独使用权重合并虽能提升 OOD，但通用任务保留率略低于 Co-FT+RETAIN。分模态合并中，仅合并语言骨干的效果接近全参数合并，暗示视觉编码器在微调中保持了较好的几何与语义稳定性，而语言-动作映射是泛化失效的主要来源。

评估边界方面，论文未报告推理延迟数据，尽管权重合并无额外计算成本，但缺乏与实时控制需求的量化对比。合并系数 $\alpha$ 需通过验证集调优，论文未提供自适应预测 $\alpha$ 的方法，限制了其在未知场景下的即插即用能力。代码已开源，但预训练策略 $\pi_0$ 的获取门槛较高，复现需依赖大规模预训练资源。

## 关联研究分析

从问题动机看，RETAIN 与 LoRA 均旨在缓解灾难性遗忘，但机制截然不同。LoRA 通过低秩矩阵限制参数更新空间，属于“训练时约束”，其效果受限于低秩假设对复杂任务变化的表达能力；而 RETAIN 通过权重插值直接恢复预训练分布，属于“推理前融合”，不改变微调过程，因此能保留更多预训练阶段的非线性泛化特征。这一差异暗示，在极低数据量下，参数空间的“距离”比“更新幅度”更能反映泛化能力的损失。

从方法设计看，RETAIN 与检索增强方法（如 RECAP）形成互补。RECAP 通过外部检索池条件化策略，依赖存储的演示片段，适合数据丰富但计算受限的场景；而 RETAIN 将知识内化于权重中，无需外部存储，适合部署环境受限的场景。然而，RETAIN 未探索检索与合并的结合，即是否可以通过检索相关演示来动态调整合并系数 $\alpha$，从而在保持通用性的同时进一步提升特定 OOD 场景的性能，这一潜在方向论文未涉及。

## 总结

RETAIN 解决了通用策略在低数据微调中泛化能力与任务专精的矛盾，其核心在于利用权重线性插值解耦预训练鲁棒性与微调特异性。实验证明，该方法在真实机器人上比最佳先前微调方法平均成功率高约 40%，且支持持续技能累积。然而，其边界在于对预训练数据规模的依赖：当预训练数据不足时，$\theta_{pre}$ 的泛化先验较弱，合并收益可能递减。此外，固定 $\alpha$ 的调优需求限制了其在动态环境中的适应性。当预训练数据量从小时级降至分钟级时，权重合并是否仍能维持显著的 OOD 增益，论文未给出回答。
