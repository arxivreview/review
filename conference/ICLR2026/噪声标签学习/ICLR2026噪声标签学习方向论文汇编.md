【ENHANCING LEARNING WITH NOISY LABELS VIA ROCKAFELLIAN RELAXATION ｜基于Rockafellian松弛的噪声标签损失重加权

研究机构：美国南加州大学

作者：Louis Chen、Bobbie Chern、Eric Eckstrand 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_14188440)

> 噪声标签学习（Learning with Noisy Labels, LNL）旨在解决深度神经网络对标注数据的高依赖性与现实标注噪声高企之间的矛盾。现有鲁棒损失方法多为静态设计，难以在缺乏干净验证集时自适应剔除噪声样本，而样本选择方法又依赖复杂的训练动态或固定阈值。本文提出Rockafellian Relaxation Method (RRM)，一种架构无关的损失重加权Wrapper，通过分布鲁棒优化视角动态调整样本权重。该方法在多个真实噪声基准上提升了基线性能，但其对实例依赖噪声的适用性及与最新特征正则化方法的对比尚存疑问。

【LANE: LEARNING WITH NOISY LABELS USING LABEL-AWARE MARGINS ｜标签感知噪声消除

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_21927131)

> 噪声标签学习旨在解决深度模型对标注质量的高依赖性与现实标注噪声高企之间的矛盾。现有基于固定阈值剔除或简单损失修正的方法，在处理细粒度文本分类中语义相近的混淆噪声时，往往误删难样本或无法区分语义距离。本文切入点在于利用类间语义相似度动态调整样本权重，而非直接剔除。通过引入标签感知边际与对比学习，LANE 在保留所有样本的前提下实现了噪声抑制。其价值在于解决了语义混淆噪声下的样本误判问题，但在视觉高噪声场景下的泛化性仍存疑。

【Noisy-Pair Robust Representation Alignment for Positive-Unlabeled Learning ｜噪声对鲁棒非对比表示对齐的正未标注学习

研究机构：美国德州农工大学、美国斯坦福大学

作者：Hengwei Zhao、Zhengzhong Tu、Zhuo Zheng 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.01278)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.01278)

> 正未标注学习（PU Learning）旨在仅利用少量正样本与大量未标注数据训练二分类器，但现有方法在复杂数据集上性能显著低于监督学习，且多依赖辅助负样本或预估计参数。本文指出瓶颈在于不可靠监督引入的噪声对主导了表示学习优化过程，导致特征空间判别性不足。NcPU 通过提出噪声对鲁棒非对比损失（NoiSNCL）与幻影标签消歧（PLD）模块，在无辅助信息下实现接近监督学习的性能。该方法在理论层面建立了期望最大化（EM）框架解释，但在多分类扩展与极端类别不平衡下的鲁棒性尚待验证。

【RESURFACING THE INSTANCE ONLY DEPENDENT LABEL NOISE MODEL THROUGH LOSS CORRECTION ｜实例感知损失修正：基于风险等价与单值噪声建模的二分类鲁棒学习

研究机构：比利时鲁汶大学

作者：Mustafa Enes Aydın、Maarten De Vos、Alexander Bertrand

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_39778378)

> 标签噪声导致深度模型过拟合错误标注，传统鲁棒损失函数在实例依赖噪声（Instance-Dependent Noise, IDN）下失效。现有方法多依赖类条件噪声假设或复杂的矩阵估计，难以兼顾计算效率与理论保证。本文通过风险等价框架，将噪声建模简化为实例级标量翻转率，实现无需验证集的自适应损失修正。该方法在二分类任务中展现了跨域泛化能力，但其对多分类场景的适用性及高噪声下的稳定性仍存疑。

【TRAINREF: CURATING DATA WITH LABEL DISTRIBU - TION AND MINIMAL REFERENCE FOR ACCURATE PRE DICTION AND RELIABLE CONFIDENCE ｜分布标签校正与极小参考集协同演化

研究机构：新加坡国立大学、上海交通大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_1488816)

> 噪声标签学习（Learning with Noisy Labels, LNL）旨在解决深度神经网络对标注数据的高依赖性与现实标注噪声高企之间的根本矛盾，但现有方法多聚焦于提升预测精度，忽视了置信度校准这一同等重要的目标。当类别数增加或噪声率极高时，传统的类别化标签校正（Categorical Curation）易受“正常性污染”影响，导致模型在模糊样本上产生过度自信或错误自信。本文提出 TrainRef，通过引入极小规模的干净参考集并采用分布标签校正策略，在训练过程中协同演化嵌入空间与数据集，以同时优化预测精度与置信度可靠性。该方法在真实噪声基准上显著优于现有去噪与校准技术，但其对参考集质量的依赖及高噪声下的收敛稳定性仍存疑。

】
