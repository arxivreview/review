# ICLR2026最新论文 ｜REAR: RETHINKING VISUAL AUTOREGRESSIVE MODELS VIA GENERATOR-TOKENIZER CONSISTENCY REGULARIZATION ｜生成器-分词器一致性正则化

研究机构：新加坡国立大学、美国斯坦福大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_35037444)

> 视觉自回归生成旨在通过离散Token序列预测实现图像合成，但长期受限于生成质量低于扩散模型。现有研究多聚焦于分词器结构或扫描顺序优化，却忽视了生成器与分词器在训练-推理阶段的分布失配。本文提出reAR框架，通过噪声上下文与码本嵌入对齐两项正则化策略，强制生成器输出符合分词器解码特性的序列。该方法在保持标准光栅扫描架构下显著提升了参数效率，但在大模型规模下仍未超越最新扩散模型SOTA。

## 研究背景

视觉自回归生成依赖编码器-量化器-解码器（Encoder-Quantizer-Decoder）框架，将图像映射为离散Token序列供Transformer预测。这一过程引入两个关键概念：曝光偏差（Exposure Bias）指训练时使用真实上下文而推理时使用自预测上下文导致的误差累积；嵌入无感知（Embedding Unawareness）指模型仅优化Token索引而忽略其在分词器嵌入空间中的几何位置。前者导致生成序列偏离分词器训练分布，后者使得即使Token索引错误，若嵌入接近正确值，解码质量仍可保持，但标准训练无法利用这一特性。

视觉自回归领域长期存在与扩散模型的性能差距，主流改进路线集中在分词器设计（如层级残差、因果约束）与生成顺序优化（如Next-Scale预测）。然而，这些方法均假设生成器能完美预测Token索引，未触及生成器与分词器之间的系统性不一致。本文切入点在于识别这一被忽略的瓶颈：自回归模型生成的Token序列可能无法被分词器有效解码，源于曝光偏差放大了视觉Token的结构敏感性，以及嵌入无感知导致解码分布漂移。

## 核心方法

### 方法参照系

标准视觉自回归流程包含分词器压缩与因果Transformer序列预测两阶段。本文问题与该通用流程的关键差异在于：不修改分词器结构或生成顺序，仅在训练阶段引入正则化项，以弥合生成器预测分布与分词器解码域之间的鸿沟。

### 噪声上下文正则化

针对曝光偏差导致的训练-推理分布失配，本文在输入端引入均匀噪声扰动。设计动机是打破模型对干净上下文的过度依赖，提升其对推理阶段自预测误差的鲁棒性。具体而言，对每个Token位置以概率 $\epsilon$ 替换为码本中随机索引，其中 $\epsilon$ 随训练进度 $t$ 按退火调度 $f(t)$ 动态调整：

$$ \tilde{x}_i = \begin{cases} x_i & \text{w.p. } 1-\epsilon \\ u_i & \text{w.p. } \epsilon \end{cases} $$

该机制使模型在训练期即暴露于含噪上下文，从而在推理时面对早期预测错误时仍能维持后续Token的合理性，避免结构性伪影的级联扩散。

### 码本嵌入正则化

针对嵌入无感知问题，本文在Transformer浅层与深层分别引入嵌入对齐损失。设计动机是让生成器不仅预测Token索引，还学习预测其在分词器嵌入空间中的位置，从而确保即使索引错误，嵌入序列仍兼容解码器。设 $h_\phi$ 为可训练MLP投影层，浅层 $l'$ 对齐当前Token嵌入，深层 $l$ 对齐下一Token嵌入：

$$ \mathcal{L}_{emb} = d(h_\phi(w_{\theta[l']}(\tilde{x})), z_{x_i}) + d(h_\phi(w_{\theta[l]}(\tilde{x})), z_{x_{i+1}}) $$

其中 $d(\cdot,\cdot)$ 为余弦距离，$z_{x_i}$ 为码本中对应嵌入。该设计将分词器的视觉先验注入生成器隐状态，使模型在预测时隐式感知解码质量约束，而非仅依赖共现统计。

## 实验评估

实验基于ImageNet-1K 256x256类别条件生成任务，对比基线覆盖扩散模型（DiT-XL, SiT-XL, REPA）、多尺度自回归（MAR）、Next-Scale范式（VAR）及多种光栅扫描AR变体（LlamaGen, RAR, RandAR）。基线审计显示，本文未对比2026年最新SOTA如BAR（FID 1.15）或IAR2（FID 1.50），但覆盖了主流AR架构。

| 模型 | 参数量 | FID↓ | IS↑ |
| :--- | :--- | :--- | :--- |
| LlamaGen-XL | 775M | 2.62 | 244.1 |
| reAR-S | 201M | 2.00 | 295.7 |
| reAR-L | 461M | 1.86 | 316.9 |
| VAR-d30 | 2.0B | 1.92 | 323.1 |
| REPA | 675M | 1.42 | 305.7 |

reAR-L以461M参数达到FID 1.86，超越参数量更大的LlamaGen-XL（2.62）和VAR-d30（1.92），但低于REPA（1.42）。在177M参数下，reAR-AliTok达到FID 1.42，与REPA持平，验证了小模型下的一致性正则化收益。

| 正则化配置 | FID↓ | IS↑ |
| :--- | :--- | :--- |
| Vanilla AR | 21.32 | 57.3 |
| + DE@15 | 20.03 | 61.0 |
| + EN@0 + DE@15 | 19.72 | 61.3 |
| λ=1.5 | 19.74 | 61.5 |

消融实验表明，单独使用嵌入正则化（DE@15）将FID从21.32降至20.03，加入噪声上下文（EN@0）进一步降至19.72。两项策略联合使用产生协同效应，单独使用噪声增强（FID 2.18）或嵌入对齐（FID 2.12）均不如联合方案（FID 2.00），证实了生成器-分词器一致性需双向约束。

评估边界方面，本文仅报告ImageNet类别条件生成结果，未验证开放域文本生成或动态分辨率场景。可复现性方面，论文未提供代码链接，但详细描述了噪声退火调度与嵌入对齐层选择（浅层第1层、深层第15层），超参数 $\lambda=1.5$ 与噪声上限 $\epsilon=0.25$ 可复现。

## 关联研究分析

从问题动机看，VAR通过Next-Scale预测解决空间结构错位，而reAR通过正则化解决分布失配，二者正交且可叠加。VAR的层级生成减少了推理步数，但未处理生成序列偏离分词器解码域的问题；reAR保留光栅扫描顺序，通过训练时注入分词器先验弥补这一缺陷。这种差异源于任务特性：Next-Scale范式改变了预测单元，而reAR仅优化预测目标，因此reAR更易与现有AR架构兼容，但无法获得VAR的全局一致性收益。

从方法设计看，LlamaGen作为主要改进对象，其光栅扫描AR架构在reAR正则化下性能显著提升，证明瓶颈不在扫描顺序而在训练动态。相比之下，MingTok等连续分词器试图通过消除量化误差解决细节丢失，但训练不稳定；reAR坚持离散Token，通过嵌入对齐间接缓解量化误差影响。这种选择反映了离散Token在LLM架构兼容性上的优势，但嵌入对齐层的选择（浅层/深层）是否依赖特定分词器架构，论文未给出跨分词器的系统性分析。

## 总结

视觉自回归生成的核心矛盾在于生成器预测分布与分词器解码域的失配，现有方法多聚焦于表征结构或生成顺序，未触及训练动态的一致性。reAR通过噪声上下文与码本嵌入对齐两项正则化，在标准光栅扫描架构下实现了生成器-分词器的行为协同，以461M参数达到FID 1.86，超越更大规模的LlamaGen-XL与VAR-d30。其边界在于：在177M参数下虽与REPA持平，但在大模型规模下仍未超越最新扩散模型SOTA，且未验证开放域任务泛化性。当模型参数量扩展至1B以上时，嵌入对齐的边际收益是否递减，论文未给出回答。
