# ICLR2026最新论文 ｜Constantly Improving Image Models Need Constantly Improving Benchmarks ｜从社区噪声到结构化基准：ECHO 框架

作者：Jiaxin Ge、Grace Luo、Heekyung Lee 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.15021)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.15021)

> 现有图像生成基准滞后于模型能力演进，导致评估指标无法捕捉新模型（如 GPT-4o Image Gen）涌现的“吉卜力化”等社区自发任务。传统基准依赖人工设计或接口收集，存在指令简单、语言分布失真及更新周期长的问题。ECHO 提出一种可复用框架，通过自动化挖掘社交媒体帖子，将非结构化的用户讨论转化为包含输入、输出及社区反馈的结构化基准。该框架在区分前沿模型与开源模型上展现出 3.2 倍的相对性能差距，但其自动评估器与人类评分的弱相关性（$\tau_b=0.117$）仍构成主要存疑点。

## 研究背景

理解 ECHO 需厘清基准构建中的“生态效度”与“分布偏移”矛盾。生态效度指评估任务是否反映真实用户意图，而分布偏移则源于基准数据与当前模型能力边界的脱节。当基准指令仍停留在“在天空中添加烟花”等简单操作时，模型间的性能差异被压缩，导致评估失效。这种脱节迫使研究者重新审视数据源：是从模型接口收集受限于编码器特性的提示词，还是从社交媒体获取旨在展示创意的自然语言交互？

图像生成评估领域长期面临静态基准与动态模型能力的错配。主流路线分为两类：一是开发者设计的传统基准（如 GenEval），指令简短且缺乏推理复杂度；二是众包基准（如 Pick-a-Pic），虽源自真实用户，但依赖人工筛选且受限于特定模型接口（如 Stable Diffusion），导致提示词风格偏向“关键词堆砌”而非自然语言。这些方法无法及时响应新模型释放的意外能力，例如 GPT-4o Image Gen 引发的“吉卜力化”风格迁移热潮。ECHO 的切入点在于绕过人工设计环节，直接利用社交媒体上用户对新模型的自发讨论，通过自动化流程提取高价值提示词，实现基准随社区反馈动态演化。

## 核心方法

### 方法参照系

ECHO 归属于生成模型基准测试路线，其核心差异在于数据源从“人工设计/接口收集”转为“社交媒体自动挖掘”。传统流程依赖专家定义任务模板，而 ECHO 将基准构建解耦为数据收集、上下文重构与多模态处理三个阶段，旨在从非结构化噪声中恢复自包含的评估样本。

### 两阶段相关性过滤与上下文重构

针对社交媒体帖子量大但相关性低的痛点，ECHO 采用两阶段管道。首先，基于时间窗口设计关键词查询，以平衡帖子池规模与 LLM 过滤成本；随后，利用 LLM 对帖子文本进行 5 点相关性评分，仅保留“极有可能相关”或“确定相关”的样本。设计动机在于解决单一关键词查询在模型发布初期与后期的时效性偏差。在上下文重构环节，ECHO 递归扩展回复树，将分散在父帖与子回复中的提示词片段合并为自包含样本。该过程通过 LLM 识别提示词跨度并剔除无关评论，同时提取社区反馈作为质量标签。样本被划分为“基准”（高质量、意图清晰）、“分析”（中等质量、部分提示）与“垃圾”（离题、格式错误）三类，确保最终基准仅包含高置信度数据。

$$
S_{sample} = \text{LLM}_{extract}(\bigcup_{P \in \mathcal{T}} P_{text}, \mathcal{I}_{images})
$$

其中 $\mathcal{T}$ 为重构后的回复树集合，$\mathcal{I}_{images}$ 为关联图像，$S_{sample}$ 为提取的自包含样本。该公式表明样本生成依赖于对完整对话树的多模态联合解析，而非单帖独立处理。

### 多模态非标准格式解析

社交媒体数据常以截图、填空模板等非标准形式存在，传统文本解析器无法处理。ECHO 引入 VLM（Qwen-2.5-VL）执行三项关键操作：区分输入与输出图像、逆向工程填空模板、解析对话截图。设计动机在于捕捉那些无法通过纯文本检索获得的高保真数据，例如用户直接分享包含提示词与生成结果的界面截图。VLM 被赋予边界框检测与分类任务，将截图中的子图像定位并标记为输入或输出，同时提取提示词文本。这一机制使得 ECHO 能够利用“截图”这一高信息密度数据源，显著提升了基准中复杂任务（如多图像主体驱动生成）的覆盖率。

$$
\mathcal{B}_{echo} = \{ (x_{in}, y_{out}, p, f) \mid p = \text{VLM}_{parse}(x_{in}, y_{out}, \text{Screenshot}) \}
$$

其中 $x_{in}, y_{out}$ 为输入输出图像，$p$ 为解析出的提示词，$f$ 为社区反馈。该公式强调了提示词 $p$ 并非直接读取，而是通过 VLM 对非标准视觉布局的逆向解析获得，从而保留了原始交互的完整性。

## 实验评估

实验在自建 ECHO 基准上进行，包含 710 个图生图样本与 848 个文生图样本。基线覆盖统一模型（Bagel, 4o Image Gen）、LLM+扩散模型（GPT-4o + DALL-E 3）及专用编辑模型（Flux Kontext）。评估采用 VLM-as-a-judge 机制，通过 GPT-4o、Gemini 2.0 与 Qwen2.5-VL 三个评估器的多数投票确定相对胜率（Win Rate）。

| 指标 | 4o Image Gen | Bagel | Flux Kontext | LLM+Diffusion |
|---|---|---|---|---|
| 相对性能差距 (vs. GEdit) | 3.2x | - | - | - |
| 人类评分相关性 ($\tau_b$) | 0.117 | - | - | - |

在图生图分割中，4o Image Gen 显著优于其他模型，且 ECHO 基准显示的相对性能差距是先前基准 GEdit 的 3.2 倍，证明其具备更强的模型区分度。然而，自动评估器与人类专家评分的相关性较弱，GPT 评估器的 $\tau_b$ 仅为 0.117，尽管统计显著（$p=0.0036$），但远低于人类间一致性（$W=0.49$）。这一结果暗示当前 VLM 在复杂开放任务上的判断稳定性不足。

消融实验未单独报告，但数据收集阶段的过滤效率提供了间接验证：初始 68k 帖子中 47% 通过相关性过滤，最终 20% 样本被标记为高质量基准数据。这表明两阶段过滤与上下文重构有效降低了噪声，但多模态解析步骤对最终基准多样性的贡献未通过定量消融隔离。

评估边界受限于自动评估器的可靠性。Win Rate 作为相对指标，规避了开放任务中“准确率”定义困难的问题，但牺牲了绝对质量度量。可复现性方面，论文提供了网站链接，但未明确开源代码仓库或完整超参数配置，且 VLM 解析步骤依赖特定模型版本（Qwen-2.5-VL），可能影响跨平台复现的一致性。

## 关联研究分析

从数据源动机看，ECHO 与 GEdit 及 IntelligentBench 存在根本差异。GEdit 虽也收集互联网提示词，但受限于作者想象力，仅覆盖 11 种单一编辑任务；IntelligentBench 针对新模型能力但数据源不透明。ECHO 的核心差异在于其“被动观察”机制：社交媒体用户为获取互动而倾向于展示新颖、创意任务，而非模型已熟练处理的常规操作。这种激励结构使得 ECHO 捕获的提示词包含 2.3 倍更多的独特二元组（unique first bigrams），且 LLM 困惑度低 1.2 倍，更贴近自然语言分布。然而，这种依赖社区自发行为的数据源是否引入系统性偏差（如偏向视觉冲击力强但实用性低的任务），论文未给出量化回答。

从方法设计看，ECHO 与 ImageDoctor 均关注细粒度诊断，但路径截然不同。ImageDoctor 依赖 MLLM 的推理能力对单张图像进行缺陷定位与解释，属于“评估器”范式；ECHO 则通过社区反馈挖掘潜在失败模式（如色彩偏移、身份保持），将其转化为二级评估指标，属于“基准构建”范式。ECHO 的优势在于其指标源于真实用户痛点，而非预设的评估维度，但这也导致其指标缺乏标准化定义，难以在不同模型间进行绝对比较。相比之下，ImageDoctor 的推理过程虽可解释，但受限于 MLLM 的幻觉风险，且无法自动扩展至新任务类型。

## 总结

ECHO 旨在解决静态基准无法捕捉新模型涌现能力的矛盾，其切入点在于利用社交媒体中用户为展示创意而自发产生的高价值提示词，通过自动化多模态解析将其转化为结构化基准。该框架在 GPT-4o Image Gen 案例中构建了 31,000+ 提示词数据集，并在图生图任务上展现出比 GEdit 大 3.2 倍的模型区分度。然而，实验暴露了自动评估器与人类判断的弱相关性（$\tau_b=0.117$），且多模态解析步骤对最终基准质量的独立贡献未通过消融实验隔离。当社区讨论的噪声进一步增加或模型能力边界发生剧烈变化时，ECHO 的自动化过滤机制是否仍能维持基准的生态效度与区分度，论文未给出回答。
