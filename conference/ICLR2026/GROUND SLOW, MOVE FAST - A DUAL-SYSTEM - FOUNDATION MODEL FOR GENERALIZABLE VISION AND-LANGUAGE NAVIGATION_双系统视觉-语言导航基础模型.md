# ICLR2026最新论文 ｜GROUND SLOW, MOVE FAST: A DUAL-SYSTEM - FOUNDATION MODEL FOR GENERALIZABLE VISION AND-LANGUAGE NAVIGATION ｜双系统视觉-语言导航基础模型

研究机构：浙江大学、清华大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_25379483)

> 视觉-语言导航（Vision-and-Language Navigation, VLN）旨在让具身智能体依据自然语言指令在三维环境中自主移动，其核心价值在于统一评估感知、语言理解与空间推理能力。现有端到端模型将视觉语言输入直接映射为短时程离散动作，导致运动碎片化且推理延迟高，难以应对动态避障需求。本文提出 DualVLN，通过解耦慢速推理与快速执行的双系统架构，结合显式像素目标与隐式潜变量实现实时连续控制。该设计在连续环境基准上刷新了性能记录，但在长程多语言任务中的泛化边界仍存疑。

## 研究背景

当智能体在连续空间中执行导航时，传统的离散节点选择无法捕捉几何约束与碰撞风险，必须转向低层动作控制。然而，直接利用多模态大语言模型（MLLM）进行端到端预测时，模型需频繁调用以生成下一步动作，这种同步机制导致执行频率受限，且将全局规划与局部控制纠缠在单一管线中，缺乏层级协调。为了解决这一矛盾，研究界开始探索异步推理与模块化架构，试图将语义推理的“慢”与控制执行的“快”分离，以在保持泛化能力的同时提升实时性。

VLN 领域已从早期的离散图遍历演进至基于 Habitat 模拟器的连续环境（VLN-CE）基准，核心挑战从简单的路径规划转向精细的几何感知与运动规划。主流路线如 StreamVLN 和 NaVILA 虽利用 VLM 提升了语义理解，但其同步框架在动态环境中难以实现高频决策，且对视觉扰动敏感。DualVLN 的切入点在于识别出“推理深度”与“控制频率”之间的根本冲突，通过引入扩散策略（Diffusion Policy）作为低层执行器，将 VLM 的推理频率降至 2Hz，而控制频率提升至 30Hz，从而在物理仿真与真实部署中实现鲁棒的动态避障。

## 核心方法

### 方法参照系

本文问题属于连续环境下的具身导航，标准流程通常依赖 VLM 直接输出离散动作或航点。与通用流程的关键差异在于，本文不直接预测动作，而是将高层规划抽象为图像像素空间中的目标接地，并通过异步机制解耦推理与控制，避免了端到端模型中语义推理与运动规划的耦合失效。

### 像素目标接地与视角调整

System 2 基于 Qwen-VL-2.5 构建，将高层规划形式化为最远像素目标接地问题。模型输入自中心 RGB 图像序列与指令，预测下一导航航点的 2D 像素坐标。为解决视角遮挡与方向错误导致的接地失败，System 2 引入自导向视角调整机制，通过离散动作（如 Turn Left/Right 15°）主动调整相机角度，确保目标位于视野内。该设计解决了传统投影方法中因视点过高或方向偏差导致的深度歧义问题，提升了像素目标的准确性与可解释性。

$$
\mathcal{L}_{\text{ground}} = \sum_{i=1}^{N} \| p_i^{\text{pred}} - p_i^{\text{gt}} \|^2
$$

该损失函数最小化预测像素坐标 $p_i^{\text{pred}}$ 与真实轨迹投影坐标 $p_i^{\text{gt}}$ 之间的欧氏距离，确保 VLM 输出的空间目标在图像平面上的精确接地。

### 潜变量引导的扩散策略

System 1 采用轻量级扩散 Transformer（DiT），接收 System 2 生成的显式像素目标与隐式潜变量作为条件，生成连续轨迹。隐式潜变量通过一组可学习查询 $Z$ 从 System 2 的隐藏状态中提取，经 Prompt Tuning 优化后，与高频 RGB 输入融合。这种双条件机制使 System 1 既能利用像素目标的语义指引，又能从 VLM 隐藏特征中自适应提取任务相关表示，解决了仅依赖显式目标导致的连接浅层化问题，增强了局部规划的鲁棒性。

$$
\mathcal{L}_{\text{diff}} = \mathbb{E}_{t, \epsilon} \left[ \| \epsilon - \epsilon_\theta(x_t, t, z_{\text{latent}}, v_{\text{rgb}}) \|^2 \right]
$$

该扩散损失函数训练 DiT 预测噪声 $\epsilon$，其中 $z_{\text{latent}}$ 为 System 2 提取的潜变量，$v_{\text{rgb}}$ 为高频视觉特征，确保生成的轨迹在语义一致性与运动平滑性之间取得平衡。

## 实验评估

实验在 R2R-CE、RxR-CE 及 VLN-PE 基准上进行，基线涵盖多传感器方法（如 CMA）、VLM-free 方法（如 LAW）及 Video-LLM 方法（如 StreamVLN）。DualVLN 仅使用第一人称 RGB 输入，在 R2R-CE 上取得 SR 64.3% 和 SPL 58.5%，显著优于 StreamVLN 的 SR 56.9% 和 SPL 51.9%，验证了解耦架构在连续控制中的优势。

| 方法 | R2R-CE SR (%) | R2R-CE SPL (%) | RxR-CE SR (%) |
| :--- | :--- | :--- | :--- |
| StreamVLN | 56.9 | 51.9 | 46.0 |
| DualVLN | 64.3 | 58.5 | 51.8 |

消融实验显示，移除 System 2 训练阶段导致收敛缓慢且泛化能力下降，证明解耦训练对保留 VLM 推理能力至关重要。移除显式像素目标后，SR 从 64.3% 降至 60.9%，表明像素目标提供了关键的语义指引；而移除潜变量后，SR 进一步降至 58.5%，证实隐式特征在自适应信息流中的补充作用。

评估边界方面，DualVLN 在 VLN-PE 物理仿真中表现优异，但 RxR-CE 上的 SR 51.8% 低于领域综述中 Efficient-VLN 的 64.5%，可能源于训练数据规模或指令复杂度的差异。代码与模型已开源，但超参数细节如 DiT 层数（12 层）与注意力头数（6 头）的敏感性未充分讨论，且未报告置信区间，数值比较需谨慎。

## 关联研究分析

从问题动机看，DualVLN 与 StreamVLN 均致力于提升 VLM 在导航中的泛化能力，但 StreamVLN 采用同步端到端架构，受限于推理延迟，难以应对动态障碍；DualVLN 通过异步解耦，将 VLM 推理频率降至 2Hz，控制频率提升至 30Hz，解决了实时性瓶颈。这一差异源于对“推理深度”与“控制频率”冲突的不同权衡：StreamVLN 优先语义一致性，DualVLN 优先执行鲁棒性。

从方法设计看，DualVLN 与 NaVILA 同属 VLM 骨干路线，但 NaVILA 依赖同步框架，在长程任务中易出现误差累积；DualVLN 引入扩散策略作为低层执行器，通过潜变量引导实现局部规划的自适应调整。与 iPlanner 等点目标导航策略相比，DualVLN 的 System 1 对像素目标回归误差更具鲁棒性，因其能利用视觉特征进行避障，而非直接投影像素坐标，这一优势在动态场景中尤为关键。

## 总结

DualVLN 旨在解决 VLN 中推理深度与控制频率的矛盾，通过解耦慢速 VLM 推理与快速扩散策略执行，实现了实时连续控制。该方法在 R2R-CE 上取得 SR 64.3% 和 SPL 58.5%，显著优于同步基线，证明了双系统架构在动态避障中的有效性。然而，其在 RxR-CE 上的性能低于领域 SOTA，且未充分探讨潜变量在不同指令复杂度下的边际收益。当指令长度增加至多语言长程任务时，潜变量的信息容量是否足以支撑全局一致性，论文未给出回答。
