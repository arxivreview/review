# ICLR2026最新论文 ｜DO LLM AGENTS KNOW HOW TO GROUND, RE - COVER, AND ASSESS? EVALUATING EPISTEMIC COM PETENCE IN INFORMATION-SEEKING AGENTS ｜搜索智能体认知胜任力评估

研究机构：香港科技大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_47213149)

> 现有搜索智能体评估仅关注最终答案准确率，无法区分“正确但推理错误”与“正确且推理严谨”的行为，导致高分数掩盖了幻觉与过度自信等认知缺陷。SeekBench 通过构建专家标注的轨迹模式，将评估对象从结果转向过程，量化智能体在证据获取、恢复与校准上的认知胜任力。该方法揭示了强化学习智能体在证据合成与推理接地上的能力分化，为过程级审计提供了可操作的指标体系，但其指标与最终任务成功率之间的因果转化机制尚未完全确立。

## 研究背景

搜索智能体（Search Agent）通过交替执行推理、搜索与证据整合来解答开放域问题，其核心循环是识别信息缺口、获取外部证据并据此决策。这一过程不同于代码生成或数学推理，后者可通过执行或证明进行客观验证，而搜索智能体必须处理缺乏客观验证器的真实世界文本信息。因此，评估智能体是否“知道自己在做什么”比评估其“是否做对了”更具挑战性，这要求引入认知心理学中的“认知胜任力”（Epistemic Competence）概念，即智能体以合理方式获取、评估并行动于知识的能力。

当前主流评估协议主要依赖最终答案的精确匹配（Exact Match）或 F1 分数，这种结果导向的指标存在根本性盲区：智能体可能通过忽略冲突来源、未识别歧义或过早回答而获得高分，但其推理过程充满幻觉或逻辑断裂。例如，两个智能体均给出正确答案，但一个基于充分证据严谨推导，另一个则依赖猜测或错误前提，传统基准无法区分二者。这种“准确率与过程质量脱节”的现象在强化学习（RL）训练的搜索智能体中尤为突出，因为 RL 优化的是最终奖励，可能激励智能体学习“捷径”而非稳健的认知策略。

SeekBench 的切入点在于将认知胜任力形式化为可量化的过程指标。它不依赖特定的工具 API，而是关注智能体轨迹中的认知行为质量，具体分解为三个维度：接地性（Groundedness，推理是否由证据支持）、恢复力（Recovery，能否在证据不足时自适应调整搜索策略）和校准度（Calibration，能否准确判断证据是否足以回答）。这一框架填补了从“行为序列”到“认知过程”的评估空白，使得研究者能够诊断智能体在信息获取与决策中的具体认知短板。

## 核心方法

### 方法参照系

过程评估的通用流程通常涉及轨迹记录、步骤标注与指标计算。然而，现有方法多关注动作路径的合规性或状态一致性，缺乏对认知质量的细粒度度量。SeekBench 的关键差异在于引入内容分析法（Content Analysis），通过专家标注构建可解释的认知特征，并将这些特征映射到抽象的认知胜任力指标，而非直接评估动作正确性。

### 认知特征标注与胜任力形式化

标注模式（Annotation Schema）是 SeekBench 的基础，它将智能体轨迹中的每个步骤分解为功能类型与质量属性。功能类型包括信息合成（InformationSynthesis）、计划形成（PlanFormation）和状态评估（StateAssessment），质量属性则评估推理是否接地（Grounded）及证据是否充分（Sufficient）。

设计动机在于解决传统评估无法区分“有证据支持的推理”与“无证据支持的猜测”的问题。通过严格定义接地性，即所有原子前提必须有明确证据支持，SeekBench 能够识别出那些看似合理但缺乏事实依据的推理步骤。

$$
E_{i,t} = C_{i,t} + Q_{i,t}, \quad C_{i,t}, Q_{i,t} \in \{0, 1\}
$$

该公式定义了证据状态 $E_{i,t}$，其中 $C$ 表示清晰度（无歧义），$Q$ 表示充分性（包含足够信息）。证据状态作为条件变量，用于评估智能体在不同证据质量下的推理行为，例如在 $E=0$（无有效证据）时是否仍进行推理，从而量化其过度自信程度。

### 量化指标与 LLM 评判管道

基于标注特征，SeekBench 定义了三个核心指标：推理质量指数（RQI）、证据恢复函数（ERF）和校准误差（CE）。RQI 衡量推理步骤的接地比例，ERF 衡量智能体在证据不足时调整查询策略的能力，CE 衡量智能体在证据充分时回答的准确性与在证据不足时拒答的准确性之间的偏差。

设计动机在于将抽象的认知胜任力转化为可大规模计算的数值，同时解决人工标注成本高的问题。SeekBench 引入 LLM-as-Judge 管道，使用 GPT-4.1-mini 等模型自动标注轨迹，并通过与专家标注的一致性验证（Cohen’s $\kappa > 0.7$）确保可靠性。

$$
CE = P(\text{Overconfident}) + P(\text{Overcautious})
$$

校准误差由过度自信（证据不足时回答）和过度谨慎（证据充分时拒答）两部分组成。该指标直接反映智能体对证据状态的判断能力，低 CE 值表明智能体能够准确识别何时拥有足够信息，从而避免幻觉或遗漏。

## 实验评估

实验在七个问答基准（包括 GAIA、PopQA、MusiQue 等）上进行，涵盖 28,493 条轨迹，评估对象包括基于 Qwen-2.5-7B 的 RL 训练智能体（Search-R1、ASearcher 等）及基座模型。基线覆盖 RL 训练与提示策略（CoT、ReAct），但缺乏与通用非搜索智能体（如 WebArena 中的导航智能体）的直接对比，限制了跨任务泛化性的评估。

| 模型 | 过度自信 (↓) | 过度谨慎 (↓) | 校准误差 (↓) |
| :--- | :--- | :--- | :--- |
| Base | 0.631 | 0.030 | 0.329 |
| Few-shot | 0.511 | 0.024 | 0.317 |
| RL-trained | 0.353 | 0.085 | 0.309 |
| ASearcher | 0.343 | 0.044 | 0.302 |
| Search-R1 | 0.226 | 0.187 | 0.319 |

校准误差分析显示，RL 训练智能体在降低过度自信方面表现显著，ASearcher 的 CE 最低（0.302），表明其证据判断最准确。然而，Search-R1 虽然过度自信率最低（0.226），但过度谨慎率高达 0.187，导致其整体 CE 略高于 ASearcher。这一反直觉结果揭示了 RL 智能体在“保守回答”与“覆盖范围”之间的权衡：Search-R1 倾向于仅在证据极其充分时回答，牺牲了部分任务覆盖率。

| 模型 | RQI (7B) | ERF (7B) | CE (7B) |
| :--- | :--- | :--- | :--- |
| ASearcher | 0.22 | 42% | 0.38 |
| WebSailor | 0.15 | 35% | 0.33 |
| GPT-5-mini | – | – | 0.34 |

在 GAIA 基准上，ASearcher 的 RQI（0.22）高于 WebSailor（0.15），表明其推理接地性更强。GPT-5-mini 的 CE 为 0.34，与 ASearcher 接近，但其 RQI 未报告，限制了对其认知过程的完整评估。这些指标揭示了不同智能体在认知维度上的互补性：ASearcher 擅长证据获取与恢复，而 Search-R1 擅长信息合成。

评估边界方面，SeekBench 的指标依赖于专家标注的主观性，尽管 LLM 评判器与专家的一致性较高（$\kappa > 0.7$），但跨模型评估的客观性仍受标注偏差影响。此外，论文未报告计算效率与 GPU 资源消耗，且代码开源但超参数配置未完全披露，限制了可复现性。

## 关联研究分析

从问题动机看，SeekBench 与 CORE 均关注全路径过程评估，但 CORE 侧重动作路径的合规性与状态一致性，而 SeekBench 聚焦认知质量。这一差异源于任务特性：CORE 评估的是智能体在结构化环境中的行为正确性，而 SeekBench 评估的是智能体在非结构化信息环境中的认知稳健性。SeekBench 引入认知心理学概念，使得评估能够捕捉到 CORE 无法识别的“正确但推理错误”现象，但这也导致其指标更复杂，难以直接用于自动化部署监控。

从方法设计看，SeekBench 与 Agent GPA 均使用 LLM-as-Judge，但 Agent GPA 侧重通用能力评估，而 SeekBench 侧重搜索特定认知。SeekBench 的创新在于通过专家标注校准 LLM 评判器，提高了指标的解释性，但这一过程成本较高，且依赖于标注模式的可扩展性。相比之下，Agent GPA 的指标更通用，但缺乏对认知过程的细粒度诊断。SeekBench 的局限在于其指标与最终任务成功率之间的因果机制尚未完全确立，即提升 RQI 或降低 CE 是否必然导致 F1 分数提升，论文未给出明确回答。

## 总结

SeekBench 解决了搜索智能体评估中“准确率与过程质量脱节”的核心矛盾，通过形式化认知胜任力指标，揭示了 RL 智能体在证据接地与校准上的能力分化。其切入点在于将认知心理学概念引入评估框架，使得过程级审计成为可能，证明了 ASearcher 在证据获取上的优势与 Search-R1 在信息合成上的专长。然而，论文的实验边界在于指标与最终任务成功率的因果转化机制未完全确立，且评估依赖于专家标注的主观性。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
