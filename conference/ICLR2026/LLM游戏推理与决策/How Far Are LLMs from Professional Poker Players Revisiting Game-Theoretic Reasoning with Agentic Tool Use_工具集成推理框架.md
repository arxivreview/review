# ICLR2026最新论文 ｜How Far Are LLMs from Professional Poker Players? Revisiting Game-Theoretic Reasoning with Agentic Tool Use ｜工具集成推理框架

研究机构：清华大学

作者：Minhua Lin、Enyan Dai、Hui Liu 等 14 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.00528)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.00528)

> 导读 扑克作为不完全信息博弈的典范，要求智能体在隐藏信息下估计对手范围并做出符合博弈论原理的决策，而现有大语言模型（LLM）在此类任务中普遍依赖浅层启发式且存在严重的“知道-做”差距。本文指出，仅靠内部策略微调无法弥补LLM在精确数值计算与均衡策略推导上的固有缺陷。为此，作者提出ToolPoker，通过统一接口调用外部求解器获取GTO动作，并由LLM生成专业级解释。该框架在Leduc Hold'em中实现了+6.8的平均筹码收益，显著优于未微调基线，但其性能高度依赖外部求解器的准确性，LLM自身的推理能力并未得到本质提升。

## 研究背景

扑克游戏可形式化为部分可观测马尔可夫决策过程（POMDP），其中智能体仅能观测公共信息 $s_t^{pub}$ 和私有手牌 $s_t^{pri}(i)$，需基于历史 $h_t^i$ 选择动作 $a_t^i$ 以最大化累积奖励。由于对手手牌不可见，决策必须依赖对对手范围（Range）和底池赔率（Pot Odds）的概率估计，这构成了不完全信息博弈的核心挑战。

传统强化学习（RL）算法如CFR+通过逼近纳什均衡解决此类问题，但缺乏可解释性；而LLM虽具备语义推理能力，却在静态基准上的高性能无法转化为动态对抗中的战略优势。GTBench等基准已证实LLM在扑克中表现不佳，但现有研究多聚焦于胜率等结果指标，未能深入剖析推理过程中的具体失效环节。本文的切入点在于：LLM不仅输在动作选择，更输在推理逻辑本身——其推理轨迹中普遍存在启发式偏差、事实性误解以及推理与行动的不一致。

## 核心方法

### 方法参照系

本文问题属于“均衡策略求解”路线，但与传统流程存在关键差异：标准做法是训练LLM内部策略逼近均衡，而本文将LLM定位为“解释者”，将“求解者”职能外包给外部工具。这一转变源于LLM在精确数值计算和随机性模拟上的固有缺陷，使其难以独立生成GTO一致的动作。

### 统一工具接口与数据构建

为解决多工具依赖导致的错误传播和高数据成本问题，ToolPoker设计了统一工具接口，将CFR求解器、权益计算器和范围分析器整合为单一API。该接口在一次查询中返回所有必要的博弈论量，简化了LLM的工具调用逻辑。数据构建阶段，作者从约5k个专家级推理样本出发，通过自动化流水线程序化地添加标准化工具调用模板（如`<tool></tool>`）和执行输出（如`<output></output>`），形成数据集 $D_c$。这一设计避免了大规模人工标注，同时确保了训练数据中工具调用与执行结果的一致性，为后续的监督微调（SFT）提供了稳定基础。

### 基于遗憾的强化学习微调

在SFT基础上，ToolPoker引入基于遗憾的强化学习（RIRL）以进一步优化策略。其核心思想是利用预训练CFR求解器计算的累积遗憾值，将其归一化为细粒度奖励信号，以捕捉每个动作的相对贡献。对于策略 $\pi_\theta$ 作为玩家 $i$，动作 $a_t^i$ 的奖励定义为：

$$ R_t^i = \frac{1}{T} \sum_{k=t}^{T} \left( Q(s_k, a_k^i) - V(s_k) \right) $$

其中 $Q$ 和 $V$ 分别由CFR求解器提供。该公式的物理含义是：奖励反映当前动作相对于状态价值函数的偏离程度，从而引导LLM在推理过程中更倾向于选择符合均衡原理的动作。这一设计弥补了纯行为克隆（BC）仅能模仿风格而无法保证策略最优性的不足，使LLM在生成解释的同时，其最终动作更紧密地对齐GTO原则。

## 实验评估

实验在Leduc Hold'em和Limit Texas Hold'em上进行，对比基线包括NFSP、DQN、DMC、CFR+及多个Vanilla LLM。ToolPoker（基于Qwen2.5-7B）在Leduc Hold'em中取得+6.8的平均筹码收益，显著优于Vanilla Qwen2.5-7B的-73.0和BC-RIRL的-40.5。在Limit Texas Hold'em中，ToolPoker取得+45.0的平均收益，同样大幅领先于其他LLM基线。

| 方法 | Leduc Hold'em Avg. | Limit Texas Hold'em Avg. |
| :--- | :--- | :--- |
| Qwen2.5-7B (Vanilla) | -73.0 | -121.6 |
| Qwen2.5-7B (BC-RIRL) | -40.5 | -77.6 |
| Qwen2.5-7B (ToolPoker) | +6.8 | +45.0 |
| o4-mini (Vanilla) | -2.6 | -42.2 |

消融实验显示，移除工具调用后，LLM的推理一致性（AC）指标从1.73降至1.56，表明外部工具对维持推理-行动一致性至关重要。然而，RIRL阶段对事实对齐（FA）指标的改善有限（仅提升0.12），说明LLM在基础游戏事实（如手牌强度判断）上的错误难以通过策略优化完全纠正。

评估边界方面，本文未报告置信区间，且仅在两个简化扑克变体上验证，未涵盖更复杂的No-Limit Texas Hold'em。代码未公开，超参数细节仅在附录中简要提及，可复现性受限。此外，LLM-as-a-Judge评分依赖GPT-4.1-mini，可能存在评估者偏差。

## 关联研究分析

从问题动机看，ToolPoker与PokerSkill均试图弥合数值求解与语言推理的鸿沟，但PokerSkill侧重上下文引擎的构建，而ToolPoker强调API调用的稳定性。这一差异源于任务特性：PokerSkill假设LLM具备较强的上下文整合能力，而ToolPoker承认LLM在精确计算上的不足，选择将计算任务完全外包。Solver-Guided Reasoning同样采用求解器引导，但其重点在于将数值策略转化为自然语言规则，而ToolPoker更直接地获取GTO动作，牺牲了部分可解释性以换取策略最优性。

从方法设计看，ToolPoker与MARSHAL代表了两种截然不同的增强路径：MARSHAL通过自博弈RL提升LLM内部策略，而ToolPoker通过外部工具保证动作正确性。本文实验表明，内部RL（BC-RIRL）在Leduc Hold'em中仍亏损-40.5筹码，而ToolPoker实现+6.8收益，这暗示在需要精确均衡策略的任务中，外部工具可能比内部优化更有效。然而，这种依赖是否掩盖了LLM自身推理能力的提升，论文未给出明确回答。

## 总结

本文要解决的核心矛盾是LLM在不完全信息博弈中推理与行动的不一致，以及内部策略无法保证GTO一致性的问题。作者抓住的切入点是LLM在工具使用上的优势，通过统一接口调用外部求解器，将计算任务外包，从而保证动作的均衡性。ToolPoker在Leduc Hold'em中实现+6.8的平均筹码收益，显著优于未微调基线，证明了外部工具对提升博弈表现的有效性。然而，其边界在于：LLM的推理质量仍受限于基础事实判断的准确性，且性能高度依赖外部求解器的可用性。当外部求解器不可用或计算延迟过高时，ToolPoker的实时性将受到严重制约，此时LLM自身的推理能力能否独立支撑战略决策，论文未给出回答。
