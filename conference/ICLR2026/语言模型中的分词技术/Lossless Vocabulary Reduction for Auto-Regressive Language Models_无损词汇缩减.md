# ICLR2026最新论文 ｜Lossless Vocabulary Reduction for Auto-Regressive Language Models ｜无损词汇缩减

作者：Daiki Chijiwa、Taku Hasegawa、Kyosuke Nishida 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.08102)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.08102)

> 自回归语言模型因训练数据独立导致词汇表不匹配，阻碍了模型集成、知识蒸馏等协作任务。现有字节级还原方案虽保证理论等价，但将粒度强制降至字节导致推理成本激增。本文提出无损词汇缩减框架，通过引入嵌套分词概念，将任意词汇表无损映射至其任意子词汇表，从而在保留多字节 token 效率的同时实现跨模型协作。该工作填补了从字节到通用子词汇表的理论空白，但近似算法在极端低概率场景下的精度损失及动态子词汇表选择机制尚存疑。

## 研究背景

自回归语言模型通过迭代预测下一个 token 的概率分布来生成文本，其效率直接取决于 token 的平均长度。每个模型基于特定训练数据统计构建词汇表，导致不同模型的 token 集合存在差异。这种词汇表不匹配使得模型无法直接在 next-token 分布层面进行交互，例如在模型集成（Ensemble）中，若两个模型的词汇表不同，其概率分布无法直接相加或相乘，必须先将分布投影到共同的表示空间。

主流解决方案包括基于字符串匹配的启发式方法、共享嵌入空间的相似度映射，以及将分布还原至字节级（Byte-level）的理论保证方法。启发式方法缺乏理论保证且难以推广；字节级还原（Phan et al., 2025; Vieira et al., 2025）虽证明了分布等价性，但强制将粒度降至 256 个字节 token，导致生成序列长度成倍增加，显著提升了推理延迟。本文切入点在于突破字节级的粒度限制，探索在保留多字节 token 效率的前提下，实现任意子词汇表间的无损分布转换。

## 核心方法

### 方法参照系

本文问题属于“跨词汇表分布对齐”范畴。通用流程是将源模型分布 $p_V$ 映射至目标空间 $V_{sub}$。传统做法是简单截断（Naive Restriction），即对不在 $V_{sub}$ 中的 token 置零并重新归一化，但这会破坏概率守恒。本文的关键差异在于引入“嵌套分词”（Nested Tokenization）机制，确保映射过程在概率论意义上严格无损。

### 嵌套分词与无损映射

设计动机在于解决简单截断导致的概率质量丢失问题。本文定义嵌套分词 $T_{V \to V_{sub}}$，其编码过程为先使用源分词器 $T_V$ 将文本编码为 $V$ 中的 token 序列，再将这些 token 重新映射为 $V_{sub}$ 中的 token 序列。基于此，定义词汇缩减分布 $p_{V \to V_{sub}}$ 为源分布 $p_V$ 在嵌套分词下的边缘概率：

$$
p_{V \to V_{sub}}(y_{1:K}) := \mathbb{E}_{x_{1:T} \sim p_V(x_{1:T})} [\mathbb{1}_{y_{1:K} = [x_{1:T}]_{V \to V_{sub}}}]
$$

该公式表明，子词汇表上的概率等于源词汇表中所有能映射到该子序列的 token 序列概率之和。通过证明 $p_{V \to V_{sub} \to A} = p_{text}$，本文确立了该映射在文本生成行为上的无损性，即缩减后的模型生成的文本分布与原模型完全一致。

### 高效近似算法 K-LVR

设计动机在于精确计算上述边缘概率涉及对最小覆盖集（Minimal Cover）的求和，计算复杂度随序列长度指数增长，无法用于实时推理。本文提出 K-LVR 算法，通过截断低概率 token 来近似计算。具体而言，在计算 next-token 分布时，仅考虑源词汇表中概率最高的前 $K$ 个 token（实验中 $K=300$），忽略其余低概率 token 的贡献。该近似将计算复杂度从指数级降至线性级（$O(K)$），且实验表明在 $K=300$ 时，精度损失可忽略不计，实现了理论无损性与工程可行性的平衡。

## 实验评估

实验在 GSM8K、MATH、ACP 和 MMLU-Pro 基准上评估了词汇缩减的精度保持能力，以及基于最大公共词汇表（MCV）的模型集成效果。基线包括 Naive Restriction（简单截断）、Union（并集词汇表）和 Byte-level Ensemble。主实验结果显示，K-LVR 在 GSM8K 上对 OLMo2-1B 的缩减精度达到 30.40，与 Full 模型的 30.40 持平；对 Qwen2.5-3B 达到 71.27，与 Full 模型的 71.27 持平。在集成任务中，K-LVR (MCV) 在 GSM8K 上取得 82.49，优于 Union 基线的 27.60 和 Naive (MCV) 的 24.94，且接近 Byte-level Ensemble 的性能，但推理速度更快。

| 模型 | 方法 | GSM8K | MATH | ACP | MMLU-Pro |
| :--- | :--- | :--- | :--- | :--- | :--- |
| OLMo2-1B | Full | 30.40 | - | - | - |
| OLMo2-1B | K-LVR (1-Bytes) | 30.40 | - | - | - |
| Qwen2.5-3B | Full | 71.27 | - | - | - |
| Qwen2.5-3B | K-LVR (MCV) | 71.19 | - | - | - |
| Ensemble | Union | 27.60 | 19.57 | 25.86 | 1.93 |
| Ensemble | K-LVR (MCV) | 81.12 | 30.29 | 34.71 | 42.00 |

消融实验显示，随着子词汇表粒度从 1-byte 增加到 8-byte，K-LVR 的精度逐渐接近 Full 模型，验证了保留多字节 token 对精度的重要性。在 1-byte 情况下，贪心解码可能出现偏差，但最终答案仍保持一致，符合理论预测。评估边界方面，论文未报告 K-LVR 在不同 $K$ 值下的详细延迟开销，且仅在静态子词汇表（如 MCV）上测试，未探索动态子词汇表选择对长上下文或 OOD 数据的影响。

## 关联研究分析

从问题动机看，本文与 HAT 架构形成鲜明对比。HAT 旨在通过层级自回归结构彻底消除固定分词器，实现 Tokenizer-Free 训练，侧重于架构重构以解决多语言公平性和 OOD 鲁棒性。本文则保留现有分词器结构，聚焦于推理时的分布对齐，解决的是模型协作而非单模型性能问题。这种差异源于任务特性：HAT 需要重新预训练以适配新架构，而本文方法适用于已训练好的模型，无需重训，因此更适用于现有大模型的快速集成场景。

从方法设计看，本文与 Phan et al. (2025) 的字节级还原方法存在本质区别。Phan 的方法将粒度固定为字节，计算复杂度与文本长度线性相关，但序列长度增加导致推理成本上升。本文通过嵌套分词将粒度推广至任意子词汇表，允许保留多字节 token，从而在保持理论无损性的同时降低了序列长度。然而，本文的 K-LVR 近似算法依赖于固定 $K$ 值，未考虑上下文对子词汇表选择的影响。查询侧增强在数据充足时是否仍有增益，论文未给出回答，且动态 $K$ 值的选择策略在复杂分布下的鲁棒性尚待验证。

## 总结

本文核心矛盾在于跨词汇表模型协作中，理论无损性与推理效率的冲突。现有字节级还原方案虽保证无损，但牺牲了效率；启发式方法虽高效，但缺乏理论保证。本文通过引入嵌套分词概念，建立了任意子词汇表间的无损映射理论，并设计 K-LVR 算法实现高效近似。实验证明 K-LVR 在 GSM8K 上精度与 Full 模型持平，且在集成任务中显著优于启发式基线。其边界在于近似算法依赖固定 $K$ 值，未探索动态子词汇表选择，且在长上下文或 OOD 数据上的无损性未得到验证。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
