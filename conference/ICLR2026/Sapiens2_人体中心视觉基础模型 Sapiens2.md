# ICLR2026最新论文 ｜Sapiens2 ｜人体中心视觉基础模型 Sapiens2

作者：Rawal Khirodkar、He Wen、Julieta Martinez 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.21681)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.21681)

> 人体姿态与分割等密集预测任务长期受困于域偏移与标注稀缺，传统专用模型在野外图像上性能退化。Sapiens 等前代基础模型虽引入大规模预训练，但仅依赖掩码图像建模导致语义表征不足，难以兼顾零样本泛化与像素级保真。本文切入点在于混合掩码重建与对比学习目标，并扩展至 4K 分辨率，以统一特征空间同时捕捉低层纹理与高层语义。该方案在多项人体中心任务上刷新了性能上限，但其对计算资源的极端依赖及自建测试集的封闭性，限制了其在资源受限场景下的直接适用性。

## 研究背景

密集预测任务要求模型在输出每个像素或关键点时，既需理解人体语义结构，又需保留光照、纹理等低层视觉细节。掩码图像建模（Masked Image Modeling, MIM）通过重建被遮挡像素来学习表征，其本质是压缩过程，能保留空间细节但缺乏语义组织能力；对比学习（Contrastive Learning, CL）通过强制实例级不变性注入语义，但全局不变性目标往往牺牲局部光度保真度。这两种范式在人体中心任务上存在互补性缺陷：纯 MIM 特征在零样本姿态估计中语义模糊，纯 CL 特征在法线估计中丢失颜色线索。

人体中心视觉基础模型旨在构建能跨任意人体任务与图像泛化的通用表征。Sapiens（Khirodkar et al., 2024）作为第一代模型，主要依赖 MIM 预训练，在受控环境下表现良好，但在野外图像中语义理解能力受限。DINOv2 等通用视觉模型虽引入混合目标，但在高分辨率下出现表征漂移，即激进的数据增强导致教师与学生模型脱离真实观测，侵蚀了对密集预测至关重要的颜色等线索。Sapiens2 针对这一矛盾，提出在像素空间锚定特征的同时进行语义组织，以解决高分辨率下语义与保真度的权衡问题。

## 核心方法

### 预训练目标混合机制

Sapiens2 的预训练流程基于 Transformer 编码器，输入图像被划分为 $N$ 个 patch token。标准 MIM 流程中，编码器仅处理可见 token，解码器重建所有 patch；标准 CL 流程中，编码器提取 [CLS] token 进行实例匹配。Sapiens2 的关键差异在于同时优化这两个目标，且 CL 部分采用 DINOv3 的师生架构，教师模型参数为学生模型的指数移动平均（EMA），不可学习。

### 联合损失函数设计

设计动机在于解决单一目标在密集预测中的失效：MIM 缺乏语义区分度，CL 缺乏像素保真度。Sapiens2 引入联合损失 $\mathcal{L} = \mathcal{L}_{MAE} + \lambda \mathcal{L}_{CL}$，其中 $\mathcal{L}_{MAE}$ 为掩码 token 的均方误差重建损失，$\mathcal{L}_{CL}$ 为跨视图 [CLS] 分布的交叉熵损失。

$$
\mathcal{L}_{CL} = - \sum_{i \in S} \log \frac{\exp(\text{sim}(\mathbf{c}_s^i, \mathbf{c}_t^i)/\tau)}{\sum_{j \in S \setminus \{i\}} \exp(\text{sim}(\mathbf{c}_s^i, \mathbf{c}_t^j)/\tau)}
$$

该公式中，$S$ 为全局-全局与全局-局部正对集合，$\mathbf{c}_s, \mathbf{c}_t$ 分别为学生与教师 [CLS] 嵌入，$\tau$ 为温度系数。此设计强制特征在保持像素级重建能力（通过 $\mathcal{L}_{MAE}$）的同时，在语义空间中对齐不同视图的实例表征，避免了纯 CL 中因激进增强导致的颜色信息丢失。

### 高分辨率分层注意力架构

设计动机在于解决 4K 输入下全局自注意力的二次复杂度爆炸问题。标准 Transformer 对 $N$ 个 token 进行全局注意力，计算量为 $O(N^2)$，在 4K 分辨率下不可行。Sapiens2 采用分层设计：前 $K$ 层使用窗口自注意力（Windowed Self-Attention）捕获局部纹理，随后通过 [CLS] 引导的池化将 token 数量下采样至 $N/\omega$，最后 $L$ 层对缩减后的序列执行全局自注意力。

$$
\mathbf{Z}_{global} = \text{GlobalSA}\left( \text{Pool}\left( \text{WinSA}(\mathbf{X}) \right) \right)
$$

其中 $\text{WinSA}$ 为窗口自注意力，$\text{Pool}$ 为空间下采样操作。该架构在局部阶段后丢弃掩码 token，防止信息跨掩码区域泄漏，同时通过全局阶段融合长程上下文，使模型在 4K 输入下仍能保持训练稳定性与推理效率。

## 实验评估

实验在自建的人体中心测试集上进行，包括 11K 姿态图像、5K 分割图像及 10K 几何任务图像，基线涵盖 ViTPose、DWPose、Sapiens 及 DINOv2/v3 等通用模型。Sapiens2-5B 在姿态估计上取得 82.3 mAP，较 Sapiens-1B 提升 4.0 mAP；在分割任务上，Sapiens2-1B 较 Sapiens-1B 提升 27.9% mIoU，主要得益于野外监督与输出分辨率从 0.5K 提升至 1K。

| 任务 | 模型 | 指标 | 数值 |
| :--- | :--- | :--- | :--- |
| 姿态估计 | Sapiens2-5B | mAP | 82.3 |
| 姿态估计 | Sapiens-1B | mAP | 78.3 |
| 分割 | Sapiens2-1B | mIoU | 81.7 |
| 分割 | Sapiens-1B | mIoU | 53.8 |

消融分析显示，混合预训练目标对密集预测任务的增益显著高于零样本任务。Sapiens2-0.4B 在法线估计上达到 8.63° 平均角度误差，优于 DAViD-L 的 10.73°，表明即使在小模型规模下，混合目标也能有效保留低层几何细节。然而，4K 分辨率模型仅在分割与法线任务中微调，姿态估计仍使用 1K 输入，暗示高分辨率对姿态精度的边际收益尚未被充分验证。

评估边界方面，论文未报告置信区间，且测试集为自建封闭集，缺乏与 COCO 等公开基准的直接可比性。代码已开源，但 5B 模型训练需 A100 GPU 集群与 FSDP 并行，复现成本极高。指标上，姿态使用 mAP，分割使用 mIoU，几何任务使用角度误差与 L2 距离，覆盖了主要密集预测维度，但未包含实时性指标。

## 关联研究分析

从预训练目标看，Sapiens2 与 DINOv2 均采用混合 MIM 与 CL 策略，但 DINOv2 主要面向通用视觉分类与检测，其 CL 目标侧重于全局不变性，而 Sapiens2 针对人体中心任务，在 CL 中保留更多像素锚定信息，以应对法线、反照率等对光度敏感的任务。这一差异源于任务特性：人体密集预测需要同时理解“是什么”（语义）与“长什么样”（外观），而通用分类仅需前者。Sapiens2 的混合权重 $\lambda$ 未公开具体数值，其在不同任务上的最优配置是否一致，论文未给出回答。

从架构设计看，Sapiens2 与 ViTPose 同属 Transformer 骨干，但 ViTPose 依赖大规模监督预训练，而 Sapiens2 采用自监督预训练加轻量微调。ViTPose 在 COCO 上表现优异，但在野外图像泛化能力较弱；Sapiens2 通过 1B 图像自监督预训练，在野外测试集上显著优于 ViTPose。这一差异表明，自监督预训练在数据分布偏移场景下更具鲁棒性，但其代价是预训练计算量远超监督预训练。Sapiens2 的 4K 分层注意力是否能在不牺牲精度的前提下进一步降低计算成本，论文未提供消融实验。

## 总结

Sapiens2 旨在解决人体中心密集预测中语义理解与像素保真度的矛盾，通过混合 MIM 与 CL 目标，在像素空间锚定特征的同时注入实例级语义。该方法在 1B 图像上预训练，并扩展至 4K 分辨率，在姿态、分割、法线等任务上均超越前代 Sapiens 及通用模型 DINOv2/v3。核心数字显示，Sapiens2-5B 姿态 mAP 达 82.3，分割 mIoU 达 81.7，较前代提升显著。然而，论文实验局限于自建封闭测试集，且 4K 模型仅在部分任务中验证，未报告实时性指标。当支持集增大或任务扩展至非人体对象时，混合目标中 CL 权重的最优配置是否保持恒定，论文未给出回答。
