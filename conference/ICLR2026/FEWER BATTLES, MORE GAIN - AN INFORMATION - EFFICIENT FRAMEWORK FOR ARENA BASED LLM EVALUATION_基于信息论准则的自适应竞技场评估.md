# ICLR2026最新论文 ｜FEWER BATTLES, MORE GAIN: AN INFORMATION - EFFICIENT FRAMEWORK FOR ARENA BASED LLM EVALUATION ｜基于信息论准则的自适应竞技场评估

研究机构：中国科学技术大学、南京大学

作者：Zirui Liu、Xianquan Wang、Yan Zhuang 等 8 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_85275859)

> 竞技场评估（Arena-based Evaluation）通过模型两两对战与人工标注生成排名，但现有方法依赖穷举或随机配对，导致标注成本随模型数量呈平方级增长。本文切入点在于利用ELO评分的渐近正态性，将实验设计中的A-最优性与D-最优性准则引入模型对选择，以最小化能力估计方差。该方法在Chatbot Arena数据集上以0.8941的成对一致性指标超越了随机基线的0.8797。其价值在于提供了可证明的统计效率提升，但受限于对稀疏图结构的假设，且未解决标注者偏差问题。

## 研究背景

当竞技场平台容纳超过190个模型时，生成可靠排名所需的对战次数呈指数级增长。这一困境源于ELO评分系统的统计特性：模型能力估计的方差与观测样本的Fisher信息矩阵逆成正比。若随机选择模型对，信息增益低且分布不均，导致收敛缓慢。为加速收敛，需动态选择能最大化信息增益的模型对，这要求将评估过程建模为序贯实验设计问题。

传统高效评估方法如TinyBenchmarks与MetaBench聚焦于静态基准的题目子集选择，通过聚类或遗传算法筛选高信息量题目。然而，竞技场评估是动态交互过程，模型对是实时生成的，且排名依赖迭代更新的人工偏好，静态子集选择假设在此失效。现有竞技场方法如UDA仅关注排名准确性，忽略了标注效率这一核心瓶颈。本文针对这一空白，将统计实验设计理论引入动态竞技场，通过优化模型对匹配策略降低冗余标注。

## 核心方法

### 方法参照系

本文问题属于高效评估中的序贯采样优化，但对象从静态题目转为动态模型对。标准流程中，子集选择基于题目特征向量的信息密度；本文则基于模型能力估计的协方差结构，利用Fisher信息矩阵指导配对。关键差异在于，竞技场中模型对是动态生成的，且能力估计随每次标注迭代更新，需在线计算信息增益。

### A-最优性准则

A-最优性准则旨在最小化能力估计量的采样方差之和，等价于最小化信息矩阵逆的迹。设计动机是解决随机配对导致的方差收敛缓慢问题，通过选择能最快降低整体不确定性的模型对，实现均衡的排名可靠性。

$$
\arg\min_{i<j} \text{tr}\left[ \left( I_{S_{t-1}}(\hat{\mathbf{r}}) + I_{(i,j)}(\hat{\mathbf{r}}) \right)^{-1} \right]
$$

该公式计算添加模型对$(i,j)$后信息矩阵逆的迹，选择使该值最小的配对。迹的最小化直接对应于所有模型能力估计方差总和的最小化，确保没有模型的能力估计被过度忽略。

### D-最优性准则

D-最优性准则通过最大化信息矩阵行列式的对数来减少不确定性，避免了A-最优性中矩阵求逆的高计算复杂度。设计动机是解决A-最优性在大规模模型场景下的计算瓶颈，同时提供更鲁棒的方差控制。

$$
\arg\max_{i<j} \log \left| I_{S_{t-1}}(\hat{\mathbf{r}}) + I_{(i,j)}(\hat{\mathbf{r}}) \right|
$$

该公式选择使信息矩阵行列式最大化的模型对。行列式最大化等价于最小化能力估计协方差矩阵的广义体积，从而在所有维度上均匀降低不确定性。相比A-最优性，D-最优性对ELO系统中固定锚点模型的偏差更不敏感，更适合竞技场场景。

## 实验评估

实验在Chatbot Arena与PPE数据集上进行，基线包括Random、Nearest、Ada-Pair。未对比静态子集方法如TinyBenchmarks，因任务性质不同。主结果显示，D-optimality在Chatbot Real ELO下达0.8941，显著优于Random的0.8797与Ada-Pair的0.8316。

| 方法 | Chatbot Real ELO | PPE Real ELO |
| :--- | :--- | :--- |
| Random | 0.8797 | 0.8825 |
| Ada-Pair | 0.8316 | 0.8398 |
| D-optim | 0.8941 | 0.8880 |

D-optimality在两个数据集上均取得最高成对一致性，验证了信息论准则的有效性。Nearest方法表现次优，因竞技场中平局率高，相似能力模型配对的信息增益低。A-optimality虽提升信息增益，但导致特定模型被过度采样，可能引入偏差。

消融实验显示，时间改进版D-optimality相比原版有0.5%的性能提升，表明高D-Info模型对确实被优先选择。计算复杂度方面，D-optimality为$O(N^{\beta+2})$，A-optimality为$O(N^{\beta+3})$，但单次选择时间远低于LLM API调用或人工标注成本。

评估边界方面，指标仅关注排名一致性，未评估标注者偏差或模型对多样性。代码已开源，但超参数如Top-K值未详细报告。实验未覆盖多模态竞技场或LLM-as-a-Judge自动标注场景，限制了方法在自动化评估中的适用性。

## 关联研究分析

从问题动机看，本文与TinyBenchmarks同属信息驱动的高效评估，但TinyBenchmarks针对静态题目，通过聚类选择高信息量样本；本文针对动态模型对，利用Fisher信息在线优化配对。差异根源在于任务特性：静态基准的题目是固定集合，可离线优化；竞技场的模型对是动态生成，需在线决策。TinyBenchmarks未考虑模型能力估计的迭代更新，而本文通过渐近正态性保证稀疏采样下的统计有效性。

从方法设计看，本文与MetaBench均利用历史数据优化采样，但MetaBench基于IRT与Fisher信息量选择题目子集，本文将Fisher信息应用于ELO评分更新过程。MetaBench假设题目难度固定，而本文假设模型能力随标注迭代更新。这一差异源于评估对象的本质不同：题目是静态测量工具，模型是动态被试。MetaBench未解决模型能力估计的方差控制问题，而本文通过A/D-最优性准则直接优化估计精度。

## 总结

本文核心矛盾是竞技场评估中标注成本与排名可靠性的权衡。现有方法忽略标注效率，本文利用ELO渐近正态性，将A/D-最优性准则引入模型对选择，以最小化能力估计方差。实验证明D-optimality在Chatbot Arena上达到0.8941成对一致性，优于随机基线。其边界在于假设E-R图结构，且未处理标注者偏差。当模型数量增至千级时，D-optimality的计算复杂度是否仍可控，论文未给出回答。
