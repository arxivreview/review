# ICLR2026最新论文 ｜Revisiting Multimodal Positional Encoding in Vision-Language Models ｜多模态旋转位置编码（M-RoPE）的系统重构与全频谱分配

研究机构：阿里巴巴集团、中国科学院

作者：Jie Huang、Xuejing Liu、Sibo Song 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.23095)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.23095)

> 导读 视觉语言模型（VLM）在处理图文混合序列时，面临位置编码无法兼顾视觉空间几何与文本线性顺序的矛盾。现有方法如 MRoPE 虽引入 3D 坐标，但频率分配不均导致长视频建模失效，且部分变体破坏了预训练 LLM 的文本先验。本文通过解构位置设计与频率分配两个维度，提出 MHRoPE 与 MRoPE-I 两种全频谱分配策略，并引入空间重置机制。该方法在无需架构改动的前提下，显著提升了细粒度定位与多模态理解性能，但其对极端长序列外推能力的验证尚显不足。

## 研究背景

自注意力机制的置换不变性要求显式注入位置信息，旋转位置编码（RoPE）通过正交旋转矩阵将绝对位置转化为相对距离依赖，成为现代大语言模型（LLM）的标准配置。然而，当输入扩展至包含 2D/3D 视觉数据时，传统的 1D 线性位置索引丢弃了图像的固有空间结构，导致视觉定位任务性能大幅衰退。为保留空间几何，多模态 RoPE（MRoPE）将位置标识扩展为时间、高度、宽度的三维元组，但其在嵌入通道上的块状频率分配引入了新的几何偏差。

主流路线在解决视觉几何保留时陷入了“局部优化”陷阱。MRoPE 将高频通道完全分配给时间轴，导致注意力随时间快速衰减，损害长视频理解；VideoRoPE 等后续工作尝试对角布局或频率重排，却因位置 ID 重叠引发模态混淆，或因破坏文本 RoPE 兼容性导致预训练知识迁移失效。这些方案各自解决了单一模态或单一任务的问题，却缺乏对位置编码设计空间的系统性审视，导致 VLM 在通用理解与细粒度定位之间难以取得平衡。

本文切入点在于将多模态 RoPE 设计解耦为“位置设计”与“频率分配”两个正交维度，并确立“位置连贯性”、“全频谱利用”与“文本先验保留”三大准则。通过系统对比现有方法在这些准则上的缺失，本文识别出频率分配不均与位置歧义是性能瓶颈的核心成因，进而提出两种轻量级变体以填补这一设计空白。

## 核心方法

### 方法参照系

本文问题属于多模态序列的位置编码设计，参照系为 MRoPE 的 3D 坐标框架。关键差异在于，MRoPE 采用固定的块状频率分配，而本文关注频率在嵌入维度上的分布策略及其对跨模态交互的影响，旨在解决 MRoPE 中时间轴高频偏置与空间轴低频受限导致的建模失衡。

### 全频谱频率分配

针对 MRoPE 中时间轴独占高频通道导致长程依赖衰减过快的问题，本文提出两种全频谱分配策略。多模态多头 RoPE（MHRoPE）将不同注意力头分配给不同位置轴，确保每个轴在各自头内拥有完整频率谱；MRoPE-Interleave（MRoPE-I）则采用轮询方式交错分配通道。其核心公式为：

$$
\theta_i = \text{base}^{-2i/d}, \quad i \in [0, d/2 - 1]
$$

其中 $d$ 为嵌入维度，$\theta_i$ 为旋转频率。通过全频谱分配，每个位置轴（$t, h, w$）均能访问从高频到低频的完整谱系，消除了 MRoPE 中空间轴仅能使用低频通道导致的长程空间关系建模能力缺失，使注意力衰减曲线在所有轴上保持一致。

### 空间重置机制

为缓解 MRoPE 中视觉注意力汇聚于左上角的“注意力汇聚”现象，本文引入空间重置（spatial-reset）机制。该机制在编码视觉内容时，重置其空间坐标起点，使视觉 token 的位置 ID 与 LLM 对短 ID 的偏好对齐。其位置定义公式为：

$$
\mathbf{m}_i = (t_i, h_i, w_i)
$$

相较于 MRoPE 的耦合位置 $\mathbf{m}_i = (t_i, t_i+h_i, t_i+w_i)$，空间重置解耦了时间与空间维度，使相对位置向量 $\mathbf{m}_{rel}$ 仅包含纯粹的时空差值。这一设计不仅加速了视觉信息的适应，还通过消除时间-空间耦合带来的运动表示纠缠，为视频理解提供了更清晰的归纳偏置。

## 实验评估

实验基于 Qwen2.5-VL 架构，冻结 ViT，微调连接器与 LLM 主干，使用约 200 万 SFT 样本训练。基线覆盖 Vanilla RoPE、MRoPE、VideoRoPE、HoPE 及 CircleRoPE，但未包含 CLIP 类双编码器基线，因任务聚焦于生成式 VLM 而非检索。

| 方法 | RefCOCO_val | RefCOCO_testA | RefCOCO_testB | MMMU | MVBench |
| :--- | :--- | :--- | :--- | :--- | :--- |
| MRoPE | 78.35 | 82.52 | 72.31 | 50.22 | 57.85 |
| VideoRoPE | 77.95 | 80.43 | 72.62 | 49.89 | 56.78 |
| MHRoPE | 79.87 | 83.66 | 73.20 | 53.00 | 58.93 |
| MRoPE-I | **80.94** | **84.55** | **75.05** | **53.22** | 57.05 |

MRoPE-I 在定位任务上全面领先，RefCOCO_val 较 MRoPE 提升 2.59 点，MMMU 提升 3.00 点，验证了全频谱分配对细粒度空间推理的增益。

消融实验显示，位置设计中引入 3D 结构仅带来微弱提升，而空间重置机制在所有基准上产生显著增益，RefCOCO_val 从 65.87 升至 66.65。频率分配中，交错分配（Interleave）优于多头分配（Multi-Head），整体得分 64.95 对比 64.63，表明细粒度通道交错在保持外推兼容性方面更具优势。对角布局导致 DocVQA 性能暴跌至 60.13，证实位置 ID 重叠引发的模态混淆是严重失效模式。

评估边界方面，实验仅覆盖 32K 上下文长度，未测试超长序列外推性能；代码已开源，但缺乏对不同分辨率下频率分配鲁棒性的详细分析。

## 关联研究分析

从问题动机看，本文与 VideoRoPE 等视频专用方法形成鲜明对比。VideoRoPE 通过对角布局解决视频时序问题，但牺牲了图像文档理解的稳定性，导致 DocVQA 性能大幅下降。本文通过全频谱分配与空间重置，在统一框架下兼顾图像与视频，根源在于其将位置编码视为跨模态共享的几何结构，而非针对单一模态的局部修补。

从方法设计看，本文与 CircleRoPE 的差异在于对文本先验的处理。CircleRoPE 采用圆形布局以均匀化注意力，但破坏了文本 RoPE 的线性兼容性，导致预训练知识迁移受阻。本文严格保持文本 RoPE 不变，确保 LLM 预训练权重的有效复用，这一选择源于对 VLM 作为 LLM 扩展而非独立架构的认知，避免了因位置编码不兼容导致的性能退化。

## 总结

本文核心矛盾在于多模态位置编码需同时保留视觉空间几何与文本线性顺序，且不能破坏预训练 LLM 的文本先验。现有方法如 MRoPE 因频率分配不均导致长程建模失效，而本文通过全频谱分配与空间重置机制，在保持文本 RoPE 兼容性的前提下，实现了视觉信息的解耦表示。实验证明 MRoPE-I 在 RefCOCO_val 上达到 80.94，较 MRoPE 提升 2.59 点，验证了设计准则的有效性。然而，实验仅覆盖 32K 上下文，未验证在更长序列下全频谱分配是否仍能维持注意力衰减的稳定性，这一边界限制了其在超长视频理解中的直接应用。当序列长度远超训练分布时，全频谱分配下的相对位置计算是否会出现数值不稳定，论文未给出回答。
