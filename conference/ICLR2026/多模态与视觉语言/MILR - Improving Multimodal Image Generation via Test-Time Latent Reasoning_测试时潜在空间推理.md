论文原文见 [arXiv](https://arxiv.org/abs/2509.22761)

> 统一多模态模型（UMM）在生成图像时，常因单步推理的缺陷导致语义与视觉细节错位，即“理解-生成”鸿沟。现有方法要么依赖昂贵的训练时微调，要么在文本与图像空间分别进行显式推理，缺乏跨模态协同。MILR 提出在测试时直接优化模型中间层的统一潜在向量，通过策略梯度实现隐式跨模态推理。该方法在组合性生成任务上表现优异，但在依赖外部世界知识的任务上仍受限于基座模型的参数化记忆上限。

## 研究背景

当模型面对复杂指令时，文本理解与像素生成往往脱节。统一多模态生成（MUG）模型通过自回归机制将文本与图像 token 置于同一 Transformer 架构中，理论上实现了模态融合。然而，MUG 的中间层输出向量（latent vectors）通常被视为黑盒，未被直接用于推理优化。这种“表征未利用”的状态，使得模型在生成阶段无法根据指令反馈动态修正内部状态，导致复杂空间关系或属性绑定错误频发。

传统推理增强方法分为两类：一类在语言空间通过思维链（Chain-of-Thought, CoT）细化指令，另一类在图像空间通过迭代生成与外部批评模型反馈进行修正。前者缺乏视觉感知，后者缺乏语义连贯性，且均需大量高质量推理数据或额外训练。MILR 的切入点在于，既然 MUG 模型已具备跨模态表征能力，为何不直接在测试时优化这些表征？通过绕过离散 token 搜索，直接调整连续潜在空间，MILR 试图以零训练成本实现跨模态协同推理。

## 核心方法

### 方法参照系

MILR 基于 Janus-Pro 等自回归 MUG 模型。标准流程中，模型接收指令 $c$，自回归生成文本 token $\mathbf{t}$ 和图像 token $\mathbf{v}$，最后解码为像素图像。本文的关键差异在于，不优化离散 token 序列，而是优化 Transformer 最后一层的中间输出向量 $\mathbf{z}$，将其作为推理的搜索空间。

### 统一潜在空间定义

MILR 将文本与图像 token 的中间输出向量定义为统一潜在空间。设文本 token 序列为 $\mathbf{t}$，图像 token 序列为 $\mathbf{v}$，其在 Transformer 最后一层的输出分别为 $\mathbf{z}^{(t)}$ 和 $\mathbf{z}^{(v)}$。由于两者共享同一层，它们位于同一个 $d$ 维向量空间 $\mathbb{R}^d$ 中。MILR 的目标是寻找最优潜在向量 $\mathbf{z}_\star = [\mathbf{z}^{(t)}; \mathbf{z}^{(v)}]$，使得后续解码生成的图像 $V_f$ 与指令 $c$ 的兼容性奖励 $R(V_f, c)$ 最大化：

$$ \mathbf{z}_\star = \arg\max_{\mathbf{z}} \mathbb{E}_{\mathbf{t},\mathbf{v} \sim p(\cdot|\mathbf{z},c)} [R(V_f, c)] $$

这一设计消除了模态间隙，因为文本与图像推理在同一向量空间内进行，避免了跨模态对齐的额外开销。

### 测试时策略梯度优化

由于上述优化问题无解析解，MILR 采用 REINFORCE 策略梯度算法在测试时进行迭代优化。每步更新中，仅优化前 $\lambda_t M$ 个文本潜在向量和前 $\lambda_v N$ 个图像潜在向量，其余部分通过标准自回归生成完成。梯度仅回传至潜在向量 $\mathbf{z}$，不更新任何模型参数。更新规则为：

$$ \mathbf{z} \leftarrow \mathbf{z} + \eta \nabla_{\mathbf{z}} \log p(\mathbf{t},\mathbf{v}|\mathbf{z},c) \cdot R(V_f, c) $$

其中 $\eta$ 为学习率。这种“部分优化+自回归补全”的策略，既利用了奖励信号引导方向，又保留了 MUG 模型的生成能力，避免了纯随机搜索的偏差。

## 实验评估

MILR 在 GenEval、T2I-CompBench 和 WISE 三个基准上进行了评估。基线覆盖非推理模型（如 FLUX.1-dev, GPT-4o）、训练式推理模型（如 T2I-R1, Flow-GRPO）和测试时推理模型（如 ReflectionFlow, PARM）。在 GenEval 上，Janus-Pro-7B+MILR 取得 0.95 的综合分数，超越基线 Janus-Pro-7B 的 0.78，且优于最强测试时方法 PARM 的 0.91。在 WISE 上，MILR 取得 0.63，较基线提升 80%，但低于领域综述中提到的 AlphaGRPO 的 0.79.5。

| 方法 | GenEval Overall | WISE Overall | T2I-CompBench Avg |
| :--- | :--- | :--- | :--- |
| Janus-Pro-7B | 0.78 | 0.35 | 0.35 |
| T2I-R1 | 0.79 | 0.54 | 0.55 |
| PARM | 0.91 | - | - |
| **Janus-Pro-7B+MILR** | **0.95** | **0.63** | **0.63** |

消融实验显示，仅优化文本潜在向量（w/o Image）在 GenEval 上达到 0.94，接近完整模型的 0.95，表明文本推理是主要贡献者，图像潜在向量的优化边际收益较小。在 WISE 上，w/o Image 为 0.61，w/o Text 为 0.56，完整模型为 0.63，说明跨模态协同在知识密集型任务上更为关键。

评估边界方面，MILR 依赖基准自带的评估工具作为奖励模型，缺乏通用奖励模型的鲁棒性测试。实验在单张 A100 80GB GPU 上完成，代码已开源。然而，论文未报告计算延迟，且未对比 2026 年最新的 RL 优化方法（如 UniGRPO），可能低估了其在世界知识任务上的相对性能。

## 关联研究分析

从方法设计看，MILR 与 ThinkMorph 等显式 CoT 方法形成鲜明对比。ThinkMorph 通过生成中间文本步骤来引导生成，而 MILR 直接优化隐式向量。这种差异源于对“推理”定义的不同：前者将推理视为可解释的文本序列，后者视为不可解释的向量轨迹。MILR 的优势在于无需额外推理数据，但劣势在于缺乏可解释性，且受限于基座模型的初始表征质量。若基座模型在特定领域知识上存在盲区，MILR 的测试时优化无法弥补这一参数化缺陷。

从知识获取机制看，MILR 与 ToolArtist 等智能体范式存在根本分歧。ToolArtist 通过调用外部搜索工具获取实时知识，而 MILR 完全依赖模型内部参数。在 WISE 基准上，MILR 的 0.63 低于 ToolArtist 的 0.79，印证了纯参数化推理在长尾知识上的局限。这种差异并非算法优劣，而是任务特性决定：组合性生成依赖内部逻辑，而知识密集型生成依赖外部事实。MILR 未探索将外部检索信号注入潜在空间优化的可能性，这可能是其性能瓶颈的根源。

## 总结

MILR 针对统一多模态模型中“理解-生成”脱节的问题，提出在测试时优化统一潜在向量以实现跨模态协同推理。其核心创新在于绕过离散 token 搜索，直接利用策略梯度调整 Transformer 中间层输出，从而以零训练成本实现推理增强。实验证明，该方法在 GenEval 上达到 0.95，显著优于传统测试时扩展方法，验证了隐式潜在推理在组合性生成上的有效性。然而，在 WISE 基准上，MILR 的 0.63 分数暴露了其对参数化记忆的依赖，无法像智能体范式那样通过外部检索弥补知识缺口。当基座模型缺乏特定领域知识时，仅优化内部潜在向量是否足以提升生成质量，论文未给出肯定回答。
