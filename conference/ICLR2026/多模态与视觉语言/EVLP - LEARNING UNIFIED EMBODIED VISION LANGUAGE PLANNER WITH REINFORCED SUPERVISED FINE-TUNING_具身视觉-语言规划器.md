# ICLR2026最新论文 ｜EVLP: LEARNING UNIFIED EMBODIED VISION LANGUAGE PLANNER WITH REINFORCED SUPERVISED FINE-TUNING ｜具身视觉-语言规划器

研究机构：中国科学院、中国科学院大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_71607730)

> 具身智能长时程操作任务要求系统同时解析高层指令的逻辑顺序与预测动作执行后的视觉状态，现有方法将语言规划与视觉生成割裂，导致语义与空间信息不一致。EVLP 切入点在于利用统一多模态架构实现“一步生成”，并通过强化学习对齐动态一致性。其通过双塔视觉模块、动态感知预训练及强化监督微调（RSFT），在仿真与真实机器人任务中显著提升了任务成功率。该方法验证了统一生成范式在具身规划中的有效性，但其对实时流式交互及端侧部署的适用性尚未验证。

## 研究背景

当机器人执行“整理房间”这类高层指令时，系统需将其分解为原子动作序列（What），并预判每个动作执行后的环境状态（How）。传统语言规划仅输出文本指令，缺乏对空间状态的显式建模；而视觉规划虽能生成子目标图像，却常因缺乏逻辑推理导致语义漂移。这种割裂使得模型难以在复杂多步任务中维持全局一致性，因为语言与视觉信息无法在统一的特征空间内相互约束。

具身长时程规划的核心矛盾在于：语言推理提供逻辑骨架，视觉想象提供感知锚点，但现有架构难以在单一模型中协同优化二者。主流路线中，PAR 和 EmbodiedGPT 依赖层级语言规划，虽逻辑清晰但缺乏空间细节；SuSIE 和 CoTDiffusion 采用外部扩散模型生成图像，虽视觉逼真但存在多步采样延迟且语义对齐不足。PERIA 尝试联合规划，但仍受限于外部生成器的交互瓶颈。EVLP 的切入点在于摒弃外部生成器，将视觉生成内化为 LLM 的直接输出，通过一步生成机制解决多步采样的计算瓶颈，并利用强化学习弥补最大似然训练在动态对齐上的缺陷。

## 核心方法

### 统一多模态生成架构

本文问题区别于通用多模态理解，关键在于需同时输出语言动作与视觉子目标，且二者需满足物理动态一致性。EVLP 采用双塔视觉模块：理解侧冻结 SigLIP 提取语义，辅以可训练的低层编码器补偿空间细节；生成侧使用 Open-MAGVIT2 量化器将 256×256 图像编码为 16×16 离散 Token。核心创新在于一步生成机制，LLM 直接建模 $x_{0:N} \sim p(\cdot|c)$，通过可学习图像 Token 一次性预测所有离散 Token ID，避免了扩散模型的多步去噪与自回归模型的顺序依赖，使得单次前向传播即可采样多个独立候选，为后续强化学习提供高效基础。

### 动态感知预训练

为解决静态多模态模型缺乏状态转移推理能力的问题，EVLP 引入双向动态预训练。逆动态任务要求模型根据前后两帧图像推断动作，优化目标为动作序列的条件对数似然：

$$ \mathcal{L}_{\text{Inverse}} = -\sum_{i=1}^{L} \log p_\theta(a_{t[i]} | a_{t[<i]}, x_t, x_{t+1}) $$

前向动态任务则要求根据当前图像与动作生成下一帧图像，优化图像 Token 的条件对数似然。这种双向训练迫使模型在统一特征空间中建立“动作-状态”映射，弥补了传统预训练仅关注静态匹配的不足，为规划阶段提供了物理动态先验。

### 强化监督微调（RSFT）

最大似然训练存在“感知过度指定”与“因果约束不足”缺陷，即模型过度关注无关视觉细节而忽略任务关键的空间一致性。RSFT 结合最大似然与策略梯度，在 SFT 基础上引入动态对齐奖励函数 $R(x)$。联合优化目标为：

$$ \mathcal{L}_{\text{RSFT}} = \mathcal{L}_{\text{SFT}} - \mathbb{E}_{x \sim p_\theta} [R(x) \log p_\theta(x|c)] $$

其中 $\mathcal{L}_{\text{SFT}}$ 约束全局分布，策略梯度项通过奖励加权强化动态一致性。利用一步生成特性，模型在单次前向中采样 $K$ 个候选，计算优势函数并更新参数，避免了传统 RL 多步采样的计算开销，实现了分布约束与偏好对齐的稳定联合优化。

## 实验评估

实验在 LoHoRavens（11 个积木任务、9 个字母任务）及 Meeting Preparation 仿真器上进行，基线覆盖语言规划（PAR, EmbodiedGPT）、视觉规划（SuSIE, CoTDiffusion）及多模态规划（PERIA）。

| 模型 | Blocks Stacking | Letters Shape Orders |
| :--- | :--- | :--- |
| PERIA | 63.9±5.8 | 60.6±5.2 |
| EVLP (ours) | 79.4±7.9 | 75.3±4.4 |

EVLP 在 LoHoRavens 所有任务上均超越最强基线 PERIA，例如 Blocks Stacking 成功率从 63.9% 提升至 79.4%，表明统一生成架构在指令遵循与任务完成度上具有显著优势。在真实世界数据集（基于 BridgeData v2）评估中，EVLP 的语言对齐分数（LA）达 0.78，LPIPS 降至 0.11，优于 PERIA（0.75, 0.17）和 SuSIE（0.23），证明其生成的子目标图像在空间一致性上更优。

消融实验显示，移除 RSFT 中的强化学习项后，生成图像的动态一致性显著下降，验证了奖励函数对物理动态对齐的关键作用。一步生成机制相比多步扩散，在保持生成质量的同时大幅降低了采样延迟，使得强化学习中的多候选评估成为可能。

评估边界方面，实验主要基于仿真环境与特定真实机器人任务，未涉及实时流式交互下的延迟测试。指标聚焦于任务成功率与图像相似度，缺乏对规划逻辑错误（如动作顺序颠倒）的细粒度分析。论文未提供代码与超参数细节，可复现性受限。

## 关联研究分析

从问题动机看，EVLP 与 PERIA 均致力于解决多模态规划中的语义-视觉不一致问题，但 PERIA 依赖外部扩散模型，导致生成过程与推理过程解耦，难以通过梯度直接优化动态一致性。EVLP 将生成内化为 LLM 输出，使得奖励信号能直接作用于生成过程，这是其性能超越 PERIA 的根本原因。然而，PERIA 在复杂背景下的视觉保真度可能优于 EVLP 的一步生成，因为扩散模型的多步细化能力在静态细节上更具优势，EVLP 在真实世界 LPIPS 上的优势是否源于任务简单性，论文未深入探讨。

从方法设计看，EVLP 的一步生成机制借鉴了自回归模型的高效性，但通过离散 Token 直接预测避免了顺序依赖。这与知识库中强调的“流式因果约束”存在差异：EVLP 侧重离线/仿真中的状态转移预测，未验证在实时视频流中处理连续帧时的延迟与精度权衡。相比之下，领域内针对可穿戴设备的主动辅助系统（如 Pro^2Assist）更关注干预时机，而 EVLP 聚焦于动作执行路径，二者在“实时性”与“精度”的取舍上截然不同。EVLP 的大模型架构在端侧部署上的可行性存疑，其计算开销是否满足实时机器人控制要求，是方法落地的关键盲区。

## 总结

EVLP 旨在解决具身长时程规划中语言推理与视觉想象割裂导致的动态不一致问题。其切入点在于利用统一多模态架构实现一步生成，并通过 RSFT 将物理动态对齐引入训练过程，克服了传统最大似然训练对任务无关细节的过度约束。实验表明，EVLP 在 LoHoRavens 上取得 79.4% 的最高成功率，真实世界 LPIPS 降至 0.11，验证了统一生成范式的有效性。然而，其实验主要局限于仿真与特定机器人任务，未涉及实时流式交互下的延迟测试及端侧部署的算力约束。当任务复杂度进一步增加或环境动态性增强时，一步生成机制在保持动态一致性的同时，能否维持足够的视觉细节保真度，论文未给出回答。
