# ICLR2026最新论文 ｜Multimodal Dataset Distillation via Phased Teacher Models ｜多模态数据集蒸馏中的分阶段教师建模

研究机构：哈尔滨工业大学、香港中文大学

作者：Shengbin Guo、Hang Zhao、Senqiao Yang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.25388)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.25388)

> 多模态数据集蒸馏旨在通过合成少量样本替代大规模图文数据，以解决存储与计算开销问题。现有方法直接复用单模态轨迹匹配策略，忽视了教师模型在训练后期编码知识形式的剧烈变化，导致学生模型性能在后期阶段反而下降。PTM-ST 将蒸馏过程分解为多个阶段，为每个阶段分配特定的教师模型，并构建捷径轨迹以稳定优化方向。该方法在 Flickr30K 和 COCO 上显著优于基线，但其阶段划分与插值端点依赖人工设定，自动化程度存疑。

## 研究背景

当多模态模型面对海量图文对时，直接存储与训练带来的算力瓶颈迫使研究者寻求数据压缩方案。数据集蒸馏（Dataset Distillation, DD）通过合成紧凑的代理数据集来近似原始数据的统计特性与训练动态，成为解决这一矛盾的核心手段。然而，将 DD 从单模态扩展至多模态场景时，简单的结构适配或距离度量设计无法捕捉模态间的异质性，导致蒸馏效果受限。

多模态数据集蒸馏（Multimodal Dataset Distillation, MDD）的主流路线基于匹配训练轨迹（MatchTraining-Trajectory, MTT）框架，通过优化合成数据使学生在其上训练后的参数轨迹与教师在真实数据上的轨迹对齐。LoRS 等近期工作引入了低秩相似矩阵增强跨模态对齐，但本质上仍沿用单模态的单一教师全程匹配机制。这种静态匹配假设教师知识是均匀且稳定的，然而实验表明，多模态教师在不同训练阶段编码的知识形式存在显著差异，直接使用后期高性能教师进行蒸馏反而导致学生性能急剧下降。PTM-ST 针对这一“分阶段知识间隙”现象，提出动态适配教师模型与轨迹平滑策略，以解决后期知识迁移失效的问题。

## 核心方法

### MTT 框架与单模态蒸馏的局限

MTT 框架的核心在于最小化学生在合成数据 $\tilde{D}$ 上训练 $t$ 步后的参数 $\tilde{\theta}_{T+t}$ 与教师在真实数据上对应时刻参数 $\theta_{T+\Delta_T}$ 之间的差异。其损失函数定义为：

$$ \mathcal{L}_{MTT} = \frac{\|\tilde{\theta}_{T} - \theta_{T+\Delta_T}\|_2^2}{\|\theta_{T} - \theta_{T+\Delta_T}\|_2^2} $$

该公式通过归一化轨迹长度，确保不同训练阶段的匹配具有可比性。然而，在单模态任务中，教师指导在全程有效；而在多模态任务中，由于数据稀疏性与缺乏显式语义约束，教师后期轨迹的梯度方向呈现高变异性，导致上述静态匹配失效。

### 分阶段教师建模（PTM）

PTM 将整体蒸馏目标分解为 $P$ 个子任务，每个阶段 $p$ 独立蒸馏一个子集 $\tilde{D}_p$。设计动机在于隔离不同训练阶段的知识形态，避免后期不稳定梯度污染早期稳定知识。具体而言，阶段 $p$ 的采样范围 $\{T_p^-, \dots, T_p^+\}$ 随训练进程动态演化，使得每个子集专注于蒸馏特定阶段的教师知识。最终，所有子集的并集 $\tilde{D}_1 \cup \dots \cup \tilde{D}_P$ 捕获完整训练动态，学生模型按阶段顺序渐进式训练，逐步吸收教师知识。

### 捷径轨迹（ST）与梯度稳定性

PTM 虽解决了知识分段问题，但原始轨迹在后期仍存在梯度方向不一致。ST 通过构建插值轨迹 $\tau_{conv}^p$ 替代原始轨迹，其端点由当前阶段的起始点 $\theta_0$ 和终点 $\theta_{t_p}$ 确定，中间点通过权重函数 $\beta_p(t)$ 插值：

$$ \tau_{conv}^p = \{ \theta_t^p \mid 0 \le t \le t_p \}, \quad \theta_t^p = (1-\beta_p(t))\theta_0 + \beta_p(t)\theta_{t_p} $$

其中 $\beta_p(t)$ 基于原始轨迹的累积距离比例计算。这一设计将复杂的非线性轨迹简化为凸组合，理论上证明了插值轨迹的梯度差随匹配范围 $\Delta_t$ 线性收敛，而原始轨迹无此保证。结合指数移动平均（EMA）平滑，ST 显著降低了蒸馏过程中的优化振荡，确保了知识转移的稳定性。

## 实验评估

| 数据集 | 方法 | IR@1 | IR@5 | TR@1 | TR@5 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Flickr30K (500 pairs) | LoRS | 12.7 | 32.9 | 14.7 | 37.6 |
| Flickr30K (500 pairs) | PTM-ST | 16.0 | 40.5 | 22.2 | 51.1 |
| COCO (500 pairs) | LoRS | 3.3 | 11.8 | 4.1 | 12.8 |
| COCO (500 pairs) | PTM-ST | 6.6 | 20.5 | 6.9 | 20.1 |

实验在 Flickr30K 和 COCO 上进行，采用 Karpathy 划分，基线涵盖核心集选择（RAND, HERD 等）及数据集蒸馏方法（MTT-VL, LoRS, EDGE）。PTM-ST 在 500 pairs 设置下，Flickr30K 的 IR@1 从 LoRS 的 12.7 提升至 16.0，TR@1 从 14.7 提升至 22.2；COCO 的 IR@1 从 3.3 提升至 6.6。这一提升幅度表明，分阶段策略有效缓解了后期知识迁移失效问题，且优势随合成样本数量增加而扩大。

| 组件 | Flickr IR@1 | Flickr TR@1 | COCO IR@1 | COCO TR@1 |
| :--- | :--- | :--- | :--- | :--- |
| BASE | 12.2 | 16.2 | 3.4 | 4.2 |
| + EMA | 12.9 | 16.2 | 3.5 | 4.0 |
| + PTM | 13.4 | 19.6 | 4.2 | 4.8 |
| + ST | 14.2 | 19.5 | 4.9 | 4.8 |
| PTM + ST + EMA | 15.5 | 22.9 | 6.6 | 6.9 |

消融实验显示，ST 提供了最大的性能增益，Flickr30K 的 TR@1 从 BASE 的 16.2 提升至 22.9，验证了轨迹平滑对稳定知识转移的关键作用。PTM 进一步提升了 IR@1，表明分阶段建模有助于捕获不同阶段的语义信息。EMA 的边际收益较小但一致，主要起到平滑训练动态的作用。值得注意的是，单独使用 ST 或 PTM 均不如组合使用，说明二者在解决梯度不稳定与知识分段问题上具有互补性。

评估协议聚焦于检索任务（IR@K/TR@K），未涵盖生成任务或分类任务，限制了方法通用性的验证。代码已开源，但论文未报告训练时间与 GPU 资源消耗，考虑到分阶段训练涉及多次教师模型加载与轨迹计算，其计算开销可能显著高于单阶段基线。此外，阶段数 $P$ 与插值端点的设定依赖人工经验，缺乏自动化调整机制，可能在其他数据集上需要重新调参。

## 关联研究分析

从问题动机看，PTM-ST 与 Frequency-Decoupled Distillation 均关注模态间异质性，但前者聚焦于时间维度上的知识演化，后者聚焦于频率维度上的信息解耦。PTM-ST 假设教师知识随训练阶段线性或非线性演化，通过分阶段匹配来适应这种演化；而 Frequency-Decoupled Distillation 假设模态间存在固定的频率结构差异，通过频域分解来解耦通用与特定信息。PTM-ST 的“分阶段”策略更适用于教师模型训练动态不稳定的场景，而频域解耦更适用于模态间存在固定结构差异的场景。两者在解决模态异质性问题上形成了时间域与频率域的互补视角。

从方法设计看，PTM-ST 与 Unpaired CMKD 均试图摆脱对严格配对数据的依赖，但 PTM-ST 通过合成数据近似真实数据分布，而 Unpaired CMKD 通过分布级对齐直接处理无配对数据。PTM-ST 的 MTT 框架本质上是一种轨迹匹配，依赖于教师模型的训练过程；而 Unpaired CMKD 的双层优化策略不依赖教师模型的显式训练轨迹，而是通过代理变量进行分布对齐。PTM-ST 的优势在于保留了教师模型的丰富知识细节，劣势在于计算成本高且依赖教师训练过程；Unpaired CMKD 的优势在于理论简洁且无需教师训练，劣势在于可能丢失细粒度知识。PTM-ST 在数据充足且教师模型可用的场景下更具优势，而在数据稀缺或隐私敏感场景下，Unpaired CMKD 可能更适用。

## 总结

PTM-ST 针对多模态数据集蒸馏中教师后期知识导致学生性能下降的问题，提出了分阶段教师建模与捷径轨迹策略。通过动态分配教师模型并平滑优化轨迹，该方法在 Flickr30K 和 COCO 上实现了 IR@1 和 TR@1 的显著提升，验证了分阶段知识迁移的有效性。然而，该方法依赖人工设定阶段数与插值端点，缺乏自适应调整机制，且在计算开销上可能高于单阶段基线。当数据集规模进一步扩大或模态类型增加时，人工设定的阶段划分是否仍能准确捕捉知识演化规律，论文未给出回答。
