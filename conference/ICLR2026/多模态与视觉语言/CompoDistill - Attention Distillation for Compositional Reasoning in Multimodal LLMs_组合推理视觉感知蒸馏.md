# ICLR2026最新论文 ｜CompoDistill: Attention Distillation for Compositional Reasoning in Multimodal LLMs ｜组合推理视觉感知蒸馏

研究机构：韩国科学技术院

作者：Jiwan Kim、Kibum Kim、Sangwoo Seo 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.12184)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.12184)

> 多模态大模型（MLLMs）的知识蒸馏（KD）旨在降低部署成本，但现有方法仅能迁移视觉识别能力，无法有效传递视觉感知能力。本文指出这一失效源于学生与教师在视觉理解层的注意力错位，并提出 CompoDistill 框架，通过显式对齐视觉注意力并复用教师适配器来弥合特征空间差异。该框架在组合推理任务上实现了显著增益，但其对教师适配器冻结的依赖是否限制了学生模型的自适应重构能力，仍存疑。

## 研究背景

MLLMs 通常由视觉编码器、投影适配器和语言模型组成。视觉编码器提取图像特征，适配器将其投影至语言空间形成视觉 Token，语言模型处理视觉与文本 Token 的联合序列以生成答案。在蒸馏过程中，学生模型需继承教师的视觉处理能力，但视觉识别（如物体分类）与视觉感知（如物体关系理解）对模型内部机制的要求存在本质差异。

现有 KD 方法主要依赖 Logits 蒸馏，即通过匹配教师与学生的输出概率分布来传递知识。这种方法在视觉识别任务上表现良好，但在需要细粒度视觉感知的组合推理（CR）任务上，学生模型的性能往往停滞在与标准监督微调（SFT）模型相当的水平。这种“识别有效、感知失效”的现象表明，仅对齐输出分布不足以捕获教师模型中复杂的视觉接地机制。

本文的切入点在于揭示视觉感知能力蒸馏失败的微观机制。通过对比教师与学生模型在视觉理解层的注意力分布，本文发现学生模型未能继承教师对关键视觉区域的聚焦能力，这种“视觉注意力错位”是导致 CR 性能瓶颈的核心原因。基于此，本文提出通过显式对齐中间层视觉注意力，并解决由此引发的特征空间冲突，以实现视觉感知能力的有效迁移。

## 核心方法

### 方法参照系

标准 MLLM 蒸馏流程通常包含两个阶段：首先通过 Logits 蒸馏对齐输出分布，随后进行监督微调以巩固知识。该流程假设教师与学生的特征空间具有足够的兼容性，使得仅通过输出匹配即可传递内部表征。本文的关键差异在于，它认为这种假设在视觉感知任务上不成立，必须显式干预中间层的注意力机制以解决空间不匹配问题。

### 视觉注意力对齐（VAT）模块

VAT 模块旨在解决学生模型在视觉理解层（LLM 总层数的 30%-70%）注意力分布与教师不一致的问题。通常做法是直接匹配对应层的注意力矩阵，但教师与学生层数不同，且直接替换学生注意力会导致性能下降。本文采用分组匹配策略，将每个学生层与一组教师层进行一对一匹配，并计算视觉 Token 子矩阵的余弦距离作为损失。

$$
\mathcal{L}_{ADL} = \frac{1}{|L_{vis}|} \sum_{l_s \in L_{vis}} \left( 1 - \text{sim}\left( \tilde{A}_{t, l_t(l_s)}, \tilde{A}_{s, l_s} \right) \right)
$$

该公式通过最小化教师与学生视觉注意力子矩阵的余弦距离，强制学生模型在生成答案时聚焦于与教师相同的视觉区域，从而直接传递视觉接地信息。

### 教师适配器复用（TAF）模块

VAT 模块引入的注意力约束与学生模型自身的特征空间存在冲突，因为教师的注意力是在其特定的视觉-语言空间中优化的。通常做法是让学生适配器从头训练或独立微调，但这会导致特征空间与教师注意力不兼容。本文提出 TAF 模块，在蒸馏预训练阶段直接复用并冻结教师的预训练适配器，仅优化学生 LLM 和 KL 散度损失。

$$
\mathcal{L}_{DPT} = \mathcal{L}_{LM} + \lambda \mathcal{L}_{KL}
$$

此设计确保学生模型在接收视觉 Token 时，其投影空间与教师保持一致，使得 VAT 模块施加的注意力约束能够在兼容的特征空间中生效，避免了因空间错位导致的性能退化。

## 实验评估

实验在 VQAv2、GQA 等视觉识别基准和 SugarCrepe、SADE 等组合推理基准上进行，基线包括 LLaVA-KD、LLaVA-MoD 等主流 KD 方法。CompoDistill-2B 在 CR 任务平均准确率上达到 66.7%，显著高于 LLaVA-KD-2B 的 61.5% 和 SFT 模型的 60.7%，同时在 VQA 任务上保持 61.9% 的竞争力，验证了注意力对齐对感知能力的增益。

| 方法 | VQA Avg | CR Avg |
| :--- | :--- | :--- |
| LLaVA-2B (SFT) | 60.7 | 60.7 |
| LLaVA-KD-2B | 61.6 | 61.5 |
| LLaVA-MoD-2B | 58.9 | 62.6 |
| CompoDistill-2B | 61.9 | 66.7 |

消融实验显示，VAT 和 TAF 模块均不可或缺。单独使用 VAT 时，CR 性能仅提升至 63.8%，而联合使用 TAF 后提升至 66.7%，表明特征空间一致性是注意力对齐生效的前提。此外，分组匹配策略优于自适应匹配，且使用 7B 教师比 4B 教师能带来更高的 CR 性能，支持了“大教师产生强学生”的传统假设。

评估边界方面，实验仅基于 Qwen 1.5 和 MobileLLaMA 骨干，缺乏跨架构的广泛验证。论文未提供代码 URL，且未报告训练过程中的内存峰值等计算效率指标，限制了其在资源受限场景下的可复现性评估。

## 关联研究分析

从问题动机看，CompoDistill 与 Switch-KD 形成方法论对立。Switch-KD 主张通过切换视觉输出至教师语言路径来隐式迁移视觉知识，认为无需显式注意力匹配；而 CompoDistill 认为显式对齐是解决视觉感知缺失的关键。这种分歧的根源在于任务特性：Switch-KD 在通用 VQA 上表现良好，但在需要细粒度视觉接地的 CR 任务上，隐式迁移可能无法捕获教师对特定区域的聚焦机制，导致感知能力蒸馏不足。

从方法设计看，CompoDistill 与 TRAG 同属注意力蒸馏路线，但层匹配策略不同。TRAG 采用自适应匹配，而 CompoDistill 采用简单的分组匹配。实验表明分组匹配在 CR 任务上更优，这可能因为分组匹配更稳定地覆盖了视觉理解层的关键区域，而自适应匹配可能因动态调整导致注意力分布的波动。此外，CompoDistill 对教师适配器的冻结处理，与 RichKD 等融合多教师特征的方法不同，后者通过混合 Logits 和特征来增加多样性，而 CompoDistill 通过空间一致性来保证注意力对齐的有效性。

## 总结

CompoDistill 旨在解决 MLLM 蒸馏中视觉感知能力无法有效迁移的矛盾。现有 Logits 蒸馏方法因忽略中间层注意力机制，导致学生在组合推理任务上性能停滞。本文通过识别视觉注意力错位这一微观机制，提出 VAT 模块显式对齐视觉理解层注意力，并引入 TAF 模块冻结教师适配器以消除特征空间冲突。实验证明，该框架将 CR 任务平均准确率从 61.5% 提升至 66.7%，同时保持 VQA 性能稳定。然而，TAF 模块对教师适配器的完全冻结，可能限制了学生模型在特定视觉特征上的自适应重构能力。当教师模型与学生在视觉编码器架构上存在较大差异时，这种空间一致性约束是否会导致感知能力的过拟合，论文未给出回答。
