# ICLR2026最新论文 ｜FLARE: FULLY INTEGRATION OF VISION-LANGUAGE - REPRESENTATIONS FOR DEEP CROSS-MODAL UN DERSTANDING ｜全管线视觉语言动态对齐架构

研究机构：北京大学、南京大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_58002945)

> 视觉语言模型（VLMs）长期面临模态间语义割裂与交互深度不足的问题，传统架构将视觉特征独立编码后仅通过静态投影层单向注入语言模型，导致细粒度空间定位与组合推理能力受限。本文切入点在于打破“编码-投影-解码”的静态流水线，主张在视觉编码、模态映射及语言解码全阶段引入文本引导的双向交互机制。通过文本引导视觉编码、上下文感知对齐解码及双语义映射损失，FLARE 实现了像素级到查询级的动态融合。该架构在显著降低视觉 Token 数量的同时提升了多基准性能，但其对合成数据依赖及编码期文本引导对视觉通用性的潜在影响尚存疑。

## 研究背景

多模态大语言模型（MLLMs）的核心瓶颈在于视觉与语言表示在深层网络中的融合深度。当视觉特征被压缩为固定数量的向量后，其内部的空间结构与语义细节在投影过程中大量丢失，导致模型在处理“黑狗白猫”这类需要属性绑定关系的组合语义时，往往退化为全局向量匹配的“词袋”系统。这种静态融合机制无法响应查询内容的变化，使得视觉编码器在缺乏文本上下文的情况下，难以区分与当前问题无关的背景噪声与关键目标。

现有主流路线如 LLaVA-NeXT 通过动态分辨率增加视觉 Token 数量，或 Eagle 采用多编码器混合策略，本质上仍是在增强视觉编码本身的容量，而非改变模态间的交互逻辑。这些方法忽视了视觉特征在解码阶段与文本查询之间的动态依赖关系，导致注意力分散且计算冗余。FLARE 的切入点在于将文本信息前置到视觉编码阶段，并在解码阶段引入语义交换层，构建贯穿全管线的双向对齐机制，以解决静态投影导致的语义信息断层。

## 核心方法

### 全管线交互架构参照系

标准 VLM 流程为：视觉编码器独立提取特征，经 MLP 投影至 LLM 空间，最后通过因果注意力与文本 Token 交互。FLARE 的关键差异在于打破了视觉编码的独立性，将文本嵌入投影至视觉空间参与编码，并在 LLM 解码层间插入语义交换层，实现从像素级到查询级的多层级动态对齐。

### 文本引导视觉编码与双语义映射

传统视觉编码器在提取特征时缺乏语义上下文，导致低层特征难以区分语义相关区域。FLARE 将查询文本嵌入 $T_q$ 投影至视觉空间得到 $V_q$，与视觉嵌入 $V_i$ 在编码器内联合处理。为平衡视觉保真度与文本增强效果，模型对编码器前半层（浅层）和后半层（深层）的特征分别取平均，得到 $V_{i[s]}$ 和 $V_{i[d]}$，并沿通道维度拼接：

$$ V_{i[e]} = \text{Concat}(V_{i[s]}, V_{i[d]}; \text{dim}=\text{channel}) $$

这一设计使得最终视觉特征既保留了浅层的纯视觉细节，又融合了深层的文本引导语义。为约束双向映射的一致性，FLARE 引入双语义映射损失，通过余弦相似度强制视觉空间中的文本重建表示 $T_q[r]$ 接近 LLM 原始文本表示 $T_q$，同时强制文本空间中的图像重建表示 $V_i[r]$ 接近原始视觉特征 $V_i$：

$$ \mathcal{L}_{v2t} = 1 - \cos(T_q[r], T_q), \quad \mathcal{L}_{t2v} = 1 - \cos(V_i[r], V_i) $$

该损失无需额外输入，直接监督投影层 $MLP_{v2t}$ 和 $MLP_{t2v}$ 的映射质量，从根源上缓解模态间隙导致的分布不匹配。

### 上下文感知对齐解码

LLM 解码阶段的因果掩码限制了视觉与文本的双向交互，导致视觉特征无法根据当前查询动态调整。FLARE 在查询 Token 前插入一组上下文感知潜在 Token $T_L$，并在每三层解码层间插入语义交换层。在语义交换层中，潜在 Token 与查询末尾的隐藏状态 $H_P$ 拼接形成上下文感知查询，通过窗口注意力从视觉 Token $T_i$ 中提取局部相关特征：

$$ T_L[r,c] = \text{Softmax}\left(\frac{W_Q(H_P \oplus T_L[r,c]) W_K(T_i)^T}{\sqrt{D}}\right) W_V(T_i) $$

其中 $r,c$ 为空间索引，窗口大小限制注意力范围以计算效率。更新后的潜在 Token 在后续解码层中与文本 Token 交互，实现了查询驱动的视觉特征细粒度聚合，解决了静态投影中视觉信息无法响应查询变化的问题。

## 实验评估

FLARE 在 16 个基准上进行了评估，基线覆盖 Qwen2.5VL、LLaVA-OneVision、Cambrian-1 等主流 MLLM，但缺乏纯对比学习架构（如 CLIP 变体）的直接对比，难以完全剥离架构改进与数据规模的影响。在同等参数量下，FLARE-X 8B 在 MMBench 上取得 83.6 分，高于 Qwen2.5VL 7B 的 83.2 分；在 POPE 上取得 89.1 分，显著优于 Qwen2.5VL 7B 的 85.9 分。

| 模型 | MMB_EN | POPE | MME_P | TextVQA | MMMU |
|---|---|---|---|---|---|
| Qwen2.5VL 7B | 83.2 | 85.9 | 1652.7 | 83.5 | 83.4 |
| FLARE-X 8B | 83.6 | 89.1 | 1639.1 | 79.7 | 83.6 |
| LLaVA-OneVision 7B | 81.7 | 87.2 | 1626.0 | 78.5 | 78.8 |

消融实验显示，移除文本引导视觉编码（A）后，MME_P 从 1583.9 降至 1531.7，MME_C 从 355.8 降至 338.2，表明编码期文本注入对认知任务贡献最大。移除双语义映射损失（B）后，MMStar 从 74.6 降至 72.8，验证了双向映射对细粒度对齐的作用。移除上下文感知解码（C）后，MMVP 从 71.7 降至 69.8，说明解码期动态聚合对视觉中心任务有正向影响。值得注意的是，FLARE-L 8B 仅使用 630 个视觉 Token，性能即超过使用 2400 个 Token 的 LLaVA-OneVision 7B，凸显了架构效率优势。

评估协议存在局限：FLARE 依赖大量合成数据（SynthColor, SynthCount 等），其性能提升可能部分源于合成数据与测试集的分布重叠，而非纯粹的架构泛化能力。代码与模型已声明开源，但合成数据生成流程的完整复现需依赖 Llama3-70B 与 FLUX 模型，计算成本较高。

## 关联研究分析

从问题动机看，FLARE 与 SSP（Yi et al., 2025）均关注模态间隙，但 SSP 采用后处理子空间投影，假设间隙是静态几何偏移；FLARE 则通过训练目标重构（双语义损失）和动态交互（语义交换层）解决间隙，认为间隙源于缺乏上下文相关的动态对齐。这一差异暗示，模态间隙可能并非固定几何属性，而是随查询内容变化的动态现象，静态投影方法在复杂推理任务上的局限正源于此。

从方法设计看，FLARE 与 Qwen2.5VL 同属深层融合路线，但 Qwen2.5VL 依赖大规模预训练数据与动态分辨率，FLARE 则通过架构创新降低数据依赖。FLARE 在更少视觉 Token 下超越 Qwen2.5VL 7B，表明其文本引导编码有效提升了视觉特征的信息密度。然而，FLARE 未报告在纯文本任务上的性能变化，无法量化视觉引导对语言能力的潜在干扰，这与领域共识中“多模态融合中的语言退化”问题形成对照，其编码期文本注入是否导致视觉特征过拟合于特定查询，损害通用性，论文未给出回答。

## 总结

FLARE 针对视觉语言模型中静态投影导致的语义割裂问题，提出全管线双向动态对齐架构，通过文本引导编码、双语义映射损失及上下文感知解码，实现像素级到查询级的细粒度融合。实验表明，FLARE-X 8B 在 MMBench 上以 83.6 分超越 Qwen2.5VL 7B 的 83.2 分，且在 POPE 上取得 89.1 分，验证了架构在降低视觉 Token 数量同时提升性能的有效性。然而，其性能提升部分依赖合成数据，且未评估编码期文本引导对视觉通用性的负面影响。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
