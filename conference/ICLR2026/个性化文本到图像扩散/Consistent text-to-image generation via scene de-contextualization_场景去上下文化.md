# ICLR2026最新论文 ｜Consistent text-to-image generation via scene de-contextualization ｜场景去上下文化

研究机构：复旦大学、加拿大向量研究所

作者：Song Tang、Peihao Gong、Kunyu Li 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.14553)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.14553)

> 叙事驱动的文生图任务要求同一主体在多个不同场景提示词下保持身份一致，但现有方法普遍依赖预知所有目标场景这一不切实际的假设，或需额外训练适配器。本文指出身份漂移（ID shift）的根源在于预训练模型中固有的“场景上下文化”现象，即场景提示通过注意力机制污染身份嵌入。SDeC 通过推理时的奇异值分解（SVD）方向稳定性分析，自适应抑制身份嵌入中的场景相关子空间，实现了无需参考图、无需预知全量场景的逐场景一致性生成。该方法在 ConsiStory+ 基准上取得了 ID 保持与场景多样性的最佳平衡，但其对强视觉偏移场景的鲁棒性仍存疑。

## 研究背景

文生图模型在生成包含特定主体的图像时，往往因场景描述而改变主体的外观特征，如服装或发型随季节或地点变化，这种现象被称为身份漂移。身份漂移的根源在于预训练模型在自然图像分布上学习到了场景与主体之间的强相关性，例如牛通常出现在草地上而非海中。这种相关性通过 Transformer 架构中的注意力机制内化，使得场景提示词在生成过程中不可避免地注入身份特征，导致跨场景生成时主体特征发生偏移。

现有解决身份漂移的方法主要分为两类：基于参考图的个性化生成和基于全量场景假设的故事生成。前者如 DreamBooth 和 LoRA 通过微调模型权重或低秩适配来记忆特定主体，但需要针对每个主体进行训练，且难以处理无参考图的场景；后者如 StoryDiffusion 和 1Prompt1Story 利用自注意力适配器或提示词重构来保持多场景一致性，但均假设已知所有目标场景，这在电影预可视化或动态叙事创作中往往不成立，因为场景内容通常是在迭代过程中逐步确定的。本文的切入点在于揭示身份漂移的内在机制——场景上下文化，并提出一种无需训练、无需预知全量场景的推理时嵌入编辑方法，从根源上抑制场景对身份嵌入的干扰。

## 核心方法

### 方法参照系

本文问题属于免微调适配路线，但与传统注入图像特征的方法（如 IP-Adapter）不同，SDeC 直接编辑文本提示词的身份嵌入。其核心差异在于操作对象从视觉特征转为文本嵌入，且无需参考图像，仅依赖单一身份提示词和当前场景提示词。

### 场景上下文化的理论刻画

设计动机在于解释为何预训练模型在跨场景生成时必然发生身份漂移。本文通过定理证明，即使身份子空间 $H_{id}$ 与场景子空间 $H_{sc}$ 理想正交，注意力机制仍会导致场景信息泄漏至身份输出。具体而言，对于身份查询 $q_{id}$，其注意力输出在身份子空间上的投影包含场景项 $T_{sc}$，该非零性由注意力权重 $\alpha_{sc}$ 非零及价值矩阵 $W_V$ 的非块对角性共同决定。

$$
\|T_{sc}\|_2 \le \epsilon \cdot \|R_{\cap}\|_2 \cdot \|T_{\cap}\|_F + \epsilon \cdot \|R_{\perp}\|_2 \cdot \|T_{\perp}\|_F
$$

该不等式界定了场景上下文化强度的上界，其中 $\epsilon$ 为场景注意力权重范数，$R_{\cap}$ 和 $T_{\cap}$ 分别代表场景-身份重叠子空间的数据分量与映射分量。这一理论框架表明，身份漂移是预训练模型的固有属性，而非偶然误差，为后续去上下文化提供了数学基础。

### SVD 方向稳定性与自适应加权

设计动机在于如何在推理时识别并抑制身份嵌入中的场景相关成分。SDeC 首先对身份嵌入 $Z_{id}$ 和场景嵌入 $Z_{sc}$ 进行 SVD 分解，计算其子空间主角余弦值 $\sigma_i = \cos \theta_i$。通过设定阈值 $\tau$（通常取 0.98），筛选出 $\sigma_i \ge \tau$ 的方向，构成场景-身份重叠子空间基 $B_{\cap}$。随后，通过前向-反向特征值优化，量化这些方向的稳定性，并自适应调整对应特征值 $\Lambda_{id}$ 的权重，抑制场景相关分量。

$$
Z_{id}^* = Z_{id} (I - P_{\cap})
$$

该公式表示通过正交投影算子 $P_{\cap}$ 从身份嵌入中移除场景相关子空间分量，重构去上下文化后的身份嵌入 $Z_{id}^*$。这一过程无需训练，仅需单次前向传播即可完成，实现了逐场景的灵活适配。

## 实验评估

实验在 ConsiStory+ 基准上进行，该基准扩展至 192 个提示词集，生成 1292 张图像，覆盖更广泛的主体、描述和风格。基线包括 SD1.5、SDXL、BLIP-Diffusion、Textual Inversion、PhotoMaker、ConsiStory、StoryDiffusion 和 1Prompt1Story。SDeC 在 ID 指标（DreamSim-F、CLIP-I）和场景指标（DreamSim-B、CLIP-T）上均表现优异，尤其在场景多样性（DreamSim-B）上显著优于 1Prompt1Story，后者虽在 ID 保持上略优，但存在严重的场景间干扰。

| 方法 | DreamSim-F↓ | CLIP-I↑ | DreamSim-B↑ | CLIP-T↑ |
| :--- | :--- | :--- | :--- | :--- |
| SDXL | 0.2778 | 0.8558 | 0.3861 | 0.8865 |
| 1P1S | 0.2238 | 0.8798 | 0.2955 | 0.8883 |
| SDeC | 0.2589 | 0.8655 | 0.3675 | 0.8946 |
| SDeC+ConsiStory | 0.2542 | 0.8744 | 0.4155 | 0.8967 |

SDeC 与 ConsiStory 结合后，CLIP-T 分数提升至 0.8967，表明两者在 ID 保持与场景背景方面具有互补性。消融实验显示，移除软估计模块后，DreamSim-F 从 0.2589 恶化至 0.3351，证实了自适应加权对抑制场景干扰的关键作用。

评估边界方面，ConsiStory+ 基准未覆盖强视觉偏移场景（如极端光照变化），SDeC 在此类场景下与 Nano Banana 均未能准确捕捉光源方向，表明其对强视觉偏移的鲁棒性有限。代码已开源，使用 NVIDIA RTX A6000 GPU，推理时间开销可忽略（POT 0.61s），但 VRAM 占用略高于基线（15GB vs 10.72GB）。

## 关联研究分析

从问题动机看，SDeC 与 1Prompt1Story 均旨在解决无参考图场景下的多场景一致性，但 1Prompt1Story 依赖全量场景假设和额外的 IPCA 适配器，而 SDeC 通过纯嵌入编辑实现了逐场景灵活适配。这一差异源于任务特性的不同：1Prompt1Story 适用于场景已知的静态故事生成，而 SDeC 更契合场景动态变化的实时创作需求。SDeC 在 DreamSim-B 上的优势（0.3675 vs 0.2955）表明，去除 IPCA 模块后，纯嵌入编辑在抑制场景间干扰方面更为有效，这暗示了适配器可能引入的额外干扰。

从方法设计看，SDeC 与 IP-Adapter 同属免微调路线，但操作对象不同：IP-Adapter 注入图像特征，SDeC 编辑文本嵌入。这一差异导致 SDeC 在细粒度视觉属性控制上可能受限，因为文本嵌入无法捕捉图像中的局部细节。然而，SDeC 的优势在于无需参考图像，适用于无参考图场景。此外，SDeC 与 DreamBooth 等微调方法在 ID 保持机制上形成对比：DreamBooth 通过修改权重记忆主体，SDeC 通过抑制场景干扰保持主体。SDeC 在 ConsiStory+ 上的表现优于多数微调方法，表明推理时嵌入编辑在特定场景下可能比参数微调更高效。

## 总结

本文要解决的核心矛盾是叙事驱动文生图中身份漂移与场景多样性的权衡，现有方法因依赖全量场景假设或参考图像而难以满足动态创作需求。本文抓住场景上下文化这一被忽略的内在机制，通过理论证明其不可避免性，并设计 SDeC 方法在推理时抑制身份嵌入中的场景相关子空间。实验证明 SDeC 在 ConsiStory+ 基准上取得了 ID 保持与场景多样性的最佳平衡，DreamSim-F 0.2589 和 CLIP-T 0.8946 均优于多数基线。本文的边界在于对强视觉偏移场景的鲁棒性不足，且在细粒度视觉属性控制上可能受限于文本嵌入的表达力。当场景提示词包含极端光照或色彩偏移时，SDeC 能否有效抑制身份漂移，论文未给出回答。
