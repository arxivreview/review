# ICLR2026最新论文 ｜FLEXIVOICE: ENABLING FLEXIBLE STYLE CONTROL - IN ZERO-SHOT TTS WITH NATURAL LANGUAGE IN STRUCTIONS ｜FlexiVoice：基于渐进式后训练的零样本TTS风格-音色解耦

研究机构：香港中文大学、华为

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_54125861)

> 零样本文本转语音（TTS）在克隆音色的同时，常因参考音频的情感风格或文本内容的情感暗示干扰指令指定的目标风格，导致“风格-音色-内容”三者纠缠。现有指令驱动TTS模型多依赖简单的条件输入，缺乏对冲突模态的主动解耦机制，难以在复杂指令下保持音色稳定与风格精准。本文提出FlexiVoice，通过构建大规模指令数据集并设计渐进式后训练（PPT）框架，利用多模态直接偏好优化（DPO）与解耦组相对策略优化（GRPO）逐步强制模型分离风格、音色与内容。该方案在解耦鲁棒性上表现优异，但其在开放域复杂指令上的绝对性能仍落后于闭源商业模型，且依赖外部音频语言模型作为奖励信号。

## 研究背景

零样本TTS的核心挑战在于从短参考音频中泛化说话人音色，同时独立控制韵律与情感。当引入自然语言指令作为风格控制信号时，模型面临模态冲突：参考音频携带的声学先验（如情感色彩）与文本内容隐含的情感倾向，往往与指令指定的目标风格相悖。这种冲突导致模型在标准监督训练中过度依赖参考音频的声学特征（音色泄漏）或从文本推断韵律（内容泄漏），从而忽略显式风格指令。解决这一问题的关键在于建立一种机制，使模型在保留参考音色的同时，能够主动抑制来自参考音频和文本的风格干扰，实现指令风格的精准遵循。

早期指令TTS系统如PromptTTS和Parler-TTS主要依赖弱标签或模板化描述，缺乏对音色与风格的显式解耦。近期系统如CosyVoice2和VoxInstruct虽结合了指令与参考音频，但在面对冲突场景时，指令遵循度与音色一致性难以兼得。现有方法多将指令视为简单的条件输入，未通过训练策略主动优化模态间的正交性。本文切入点在于将指令遵循任务重构为解耦过程，通过课程学习式的强化学习后训练，逐步解锁模型在冲突模态下的控制能力。

## 核心方法

### 方法参照系

本文基于预训练大语言模型（LLM）构建TTS系统，采用离散音频Token作为LLM的输入输出。与标准LLM对齐流程（SFT+DPO）不同，本文针对TTS特有的多模态冲突问题，设计了包含三个阶段的渐进式后训练（PPT）框架，旨在通过多目标优化实现风格、音色与内容的数学解耦。

### 多模态直接偏好优化

S1阶段旨在建立指令与参考音频的初始对齐。针对情感任务，利用情感语音数据集（ESD）构造偏好对：同一说话人、同一文本的不同情感样本构成“胜者”与“败者”，中性样本作为参考。DPO损失定义为：

$$ \mathcal{L}_{DPO} = -\mathbb{E}_{(x, y_w, y_l)} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)} \right) \right] $$

该公式通过最大化胜者样本与败者样本的对数概率差，使模型在给定指令和参考音频时，更倾向于生成符合指令情感的语音，无需显式奖励模型。

### 解耦组相对策略优化

S2阶段针对参考音频或文本情感与指令冲突的场景。引入多目标GRPO，奖励函数包含情感识别准确率 $r_{ser}$ 和说话人验证准确率 $r_{sv}$。优势函数定义为：

$$ A_i = \frac{r_i - \text{mean}(r_1, ..., r_K)}{\text{std}(r_1, ..., r_K)} $$

其中 $r_i = \alpha r_{ser} + (1-\alpha) r_{sv}$。该设计强制模型在最大化情感遵循的同时保持音色一致，通过冲突数据场景（如Happy指令 vs Sad参考）迫使模型学习忽略参考音频中的情感风格，仅提取音色特征，从而实现风格与音色的解耦。

### 指令组相对策略优化

S3阶段扩展至复杂开放域指令。由于缺乏成对偏好数据，采用GRPO并引入音频语言模型（ALM）作为奖励模型。ALM判断生成语音是否匹配指令，输出二值奖励 $r_{llm} \in \{1, 0\}$。此阶段丢弃参考音频以避免与开放域约束（如性别、年龄）冲突，并通过混合S2数据防止灾难性遗忘，最终实现从情感控制到复杂语义指令的泛化。

## 实验评估

实验在自建情感数据集（MEAD/CSEMOTIONS）和InstructTTSEval基准上进行，对比Parler-TTS、CosyVoice2、VoxInstruct等开源模型及Gemini、GPT-4o等闭源模型。在解耦能力评估中，FlexiVoice在TR-Hard任务（冲突参考）上表现显著优于基线。

| 模型 | TO-Easy ACC-I (EN) | TR-Hard ACC-I (EN) | TR-Hard ACC-R (EN) | TR-Hard SV (EN) |
| :--- | :--- | :--- | :--- | :--- |
| CosyVoice2 | - | 48.8 | 32.2 | 99.4 |
| VoxInstruct | 70.6 | 49.7 | 23.9 | 90.6 |
| FlexiVoice-Base | 72.4 | 48.8 | 32.2 | 99.4 |
| FlexiVoice | 97.4 | 78.2 | 10.6 | 95.8 |

FlexiVoice在TR-Hard任务中ACC-I达78.2%，ACC-R降至10.6%，表明其有效抑制了参考音频的情感干扰，同时保持95.8%的说话人验证准确率。在InstructTTSEval复杂指令评估中，FlexiVoice英文平均准确率为79.3%，优于所有开源基线，但低于Gemini-2.5-pro的84.8%。

| 训练策略 | Decoupling Set Avg. (EN) | InstructTTSEval Avg. (EN) |
| :--- | :--- | :--- |
| FlexiVoice-Base | 54.9 | 66.4 |
| + S3 (First) | 72.6 | 72.3 |
| + S1→S2→S3 (PPT) | 88.7 | 79.3 |

消融实验显示，PPT策略（S1→S2→S3）在解耦集和复杂指令集上均优于联合训练或单一阶段训练。S2阶段的引入对解耦能力贡献最大，将TR-Hard ACC-I从48.8%提升至80.2%。S3阶段进一步提升了复杂指令遵循能力，但边际收益小于S2。

评估指标涵盖情感准确率、说话人验证、WER及MOS。局限在于：自建数据集仅覆盖5种情感，未测试非情感类细粒度风格（如语速、音调）的解耦；ALM奖励模型依赖外部模型，增加推理延迟；未报告实时因子（RTF），无法评估实时应用潜力。代码未公开，仅提供音频样本，复现性受限。

## 关联研究分析

从问题动机看，FlexiVoice与ReStyle-TTS均关注风格-音色解耦，但ReStyle-TTS依赖架构设计（正交LoRA融合）实现属性独立控制，而FlexiVoice依赖训练策略（PPT）通过冲突数据强制解耦。ReStyle-TTS在LibriTTS韵律控制基准上SIM达0.85，但缺乏对指令遵循的评估；FlexiVoice在指令遵循上表现更优，但解耦机制更依赖数据构造而非架构约束。这种差异暗示：架构解耦可能更具泛化性，而训练策略解耦在特定冲突场景下更鲁棒，但两者结合的效果尚未探索。

从方法设计看，FlexiVoice的PPT框架借鉴了Vevo2的多目标后训练思路，但Vevo2聚焦于音质与韵律的联合优化，而FlexiVoice将多目标优化应用于模态解耦。Vevo2使用单一奖励模型，FlexiVoice分阶段使用SER、SV和ALM奖励，体现了任务复杂度的递增。与OV-InstructTTS相比，后者通过推理链机制提升开放词汇控制精度，MOS达4.2，但缺乏对音色-风格冲突的显式处理。FlexiVoice在解耦鲁棒性上更优，但在复杂指令的绝对性能上略逊，表明RL后训练在解耦任务上的优势可能以牺牲部分通用指令遵循能力为代价。

## 总结

FlexiVoice旨在解决零样本TTS中风格、音色与内容的模态冲突问题，通过渐进式后训练框架实现主动解耦。其核心创新在于将指令遵循重构为课程学习式的多目标优化过程，利用冲突数据场景强制模型分离参考音频的情感风格与音色特征。实验证明，该方案在冲突参考场景下显著提升了指令遵循度（ACC-I 78.2%）并降低了情感干扰（ACC-R 10.6%），同时在复杂指令评估中超越所有开源基线。然而，其性能仍低于闭源商业模型，且依赖外部ALM奖励模型，增加了系统复杂度。当参考音频与指令在多个维度（如情感、语速、音调）同时冲突时，PPT框架的解耦能力是否仍能保持鲁棒性，论文未给出回答。
