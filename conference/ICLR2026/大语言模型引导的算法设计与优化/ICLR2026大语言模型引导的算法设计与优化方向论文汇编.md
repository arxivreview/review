【CALM: CO EVOLUTION OF ALGORITHMS AND LAN GUAGE MODEL FOR AUTOMATIC HEURISTIC DESIGN ｜算法与语言模型协同进化

研究机构：香港城市大学、东南大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_96454454)

> 自动启发式设计（AHD）旨在利用大语言模型（LLM）的语义推理能力，在计算预算受限条件下突破传统进化算法的局部最优陷阱，实现从自然语言意图到高性能算法结构的自动化映射。现有主流方法仅通过操纵提示词引导进化，即“言语梯度”，忽视了利用评估反馈调整模型权重这一“数值梯度”维度，导致生成能力受限于静态模型的固有偏差。CALM 提出将 LLM 微调与启发式搜索解耦为双通道协同过程，通过强化学习内化成功启发式的特征，使模型在进化过程中自我适应。该方法在本地 24GB GPU 上运行 7B 量化模型，性能超越依赖商业 API 的 SOTA 基线，但其跨域泛化能力与微调稳定性仍存疑。

【MetaMuse: Algorithm Generation via Creative Ideation ｜基于外部刺激与反馈嵌入的系统算法生成

研究机构：美国加州大学伯克利分校、微软研究院

作者：Ruiying Ma、Chieh-Jan Mike Liang、Yanjie Gao 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.03851)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.03851)

> 系统算法设计面临解空间不连续导致的搜索困难，传统手工设计耗时且依赖通用启发式。现有LLM方法受限于“可得性偏差”，倾向于生成经典模板而非创新结构。MetaMuse通过外部刺激引导跳跃采样，并结合性能向量度量多样性，实现了从抽象概念到可执行代码的系统化映射。该方法在缓存与装箱问题上显著优于基线，但其对非平稳动态环境的适应性及跨域泛化能力仍存疑。

】
