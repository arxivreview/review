# ICLR2026最新论文 ｜LSA: LAYER WISE SPARSITY ALLOCATION FOR - LARGE LANGUAGE MODEL PRUNING BASED ON MIN IMAL LINEAR RECONSTRUCTION ERROR ｜基于最小线性重构误差的层级稀疏率分配

研究机构：电子科技大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_58723331)

> 大语言模型（LLM）在非结构化剪枝中普遍采用均匀稀疏率，忽略了层间冗余度的显著差异，导致高稀疏率下性能急剧退化。现有基于权重评分的层级分配方法（如OWL、DLP）依赖经验性归约函数，且在细粒度（块级/投影级）分配时性能崩溃。LSA通过直接计算各层移除50%最不重要权重后的最小线性重构误差（LRE）来量化层重要性，摒弃了权重评分与归约函数设计，并首次实现了无性能崩溃的投影级稀疏分配。该方法在70%稀疏率下显著优于现有层级分配策略，但其依赖贪心算法计算LRE，在超大模型上的可扩展性仍存疑。

## 研究背景

LLM剪枝的核心困境在于参数规模与计算资源的矛盾。非结构化剪枝通过移除单个权重实现高压缩率，但通用GPU难以加速非规则稀疏模式，且均匀稀疏率假设各层冗余度相同。然而，LLM激活值中存在少量极大值特征（Outliers），忽略这些异常值会导致压缩后性能严重退化。因此，层级稀疏率分配（Layer-wise Sparsity Allocation）成为关键：需识别哪些层包含更多可安全移除的权重，哪些层因包含关键异常值而需保留更多参数。

主流路线基于Wanda式权重评分（权重幅值×激活范数）评估层重要性。OWL（Yin et al., 2024）通过层级异常值分布（LOD）分配稀疏率，但依赖经验乘数$m$，跨模型泛化性差；DLP（Chen et al., 2025）使用中位数归约函数替代固定阈值，虽改善了适应性，但归约函数的选择仍具启发式色彩，且两者均局限于层级粒度，无法在块级或投影级进行非均匀分配而不引发性能崩溃。LSA的切入点在于：直接度量层在移除部分权重后的输出重构误差，将重要性评估从“权重评分代理”转变为“重构误差直接度量”，从而消除归约函数依赖并支持细粒度分配。

## 核心方法

### 方法参照系

LSA属于非结构化后训练剪枝中的层级稀疏率分配策略。与SparseGPT/Wanda的均匀稀疏不同，LSA不改变底层剪枝算法（仍使用Wanda或SparseGPT），而是重构稀疏率分配机制。其关键差异在于：不计算每个权重的独立重要性分数，而是通过模拟移除权重后的重构误差来评估层/块/投影的整体冗余度。

### 最小线性重构误差（LRE）计算

传统方法通过权重评分的归约函数（如均值、中位数）间接推断层重要性，但归约函数无法捕捉权重移除后的累积误差效应。LSA直接计算层在移除$p=50\%$最不重要权重后的最小线性重构误差。设层权重矩阵为$W$，输入激活为$X$，重构误差定义为：

$$
\mathcal{E} = \min_{M} \| (W \odot M) X - W X \|_F^2
$$

其中$M$为二值掩码，约束$\|M\|_0 = (1-p)\|W\|_0$。LSA通过贪心算法求解：初始化误差向量$\epsilon$为$S$的对角元素（$S = H \odot (W^T W)$，$H = X^T X$），每步选择$\epsilon_j$最小的通道移除，并更新剩余通道的误差。该设计消除了对权重评分归约函数的依赖，直接反映层对权重移除的容忍度。

### 细粒度稀疏率分配

层级LRE计算后，LSA将误差转化为相对重要性分数$I_l = 1 - \mathcal{E}_l / \sum_i \mathcal{E}_i$。为适应目标稀疏率$p_r$，引入超参数$\beta$将重要性范围压缩至$[0, 2\beta]$，层$l$的稀疏率$s_l$在$[p_r - \beta, p_r]$内调整。关键创新在于：LSA将LRE计算扩展至块级（自注意力/FFN）和投影级（Q/K/V/O/FFN内部投影），且未引发性能崩溃。实验表明，LSA在块级分配时性能甚至优于层级，而OWL/DLP在细粒度分配时性能显著下降。这源于LRE直接度量了局部重构误差，避免了权重评分在细粒度下的分布偏移问题。

## 实验评估

实验在LLaMA1/2/3、Vicuna、Mistral、Qwen等模型上验证，稀疏率固定为70%，评估指标包括WikiText-2困惑度（PPL）和7个零样本任务准确率。基线覆盖Uniform、OWL、DLP，但缺失结构化剪枝（如LLM-Pruner）和低秩分解基线。

| 模型 | 方法 | WikiText-2 PPL (70%稀疏) |
|---|---|---|
| LLaMA1-13B | Uniform | 20.36 |
| LLaMA1-13B | OWL | 14.15 |
| LLaMA1-13B | DLP | 12.87 |
| LLaMA1-13B | LSA | 12.45 |
| LLaMA2-13B | Uniform | 45.26 |
| LLaMA2-13B | OWL | 18.16 |
| LLaMA2-13B | DLP | 16.80 |
| LLaMA2-13B | LSA | 15.36 |

LSA在LLaMA1-13B上PPL为12.45，较DLP的12.87降低0.42；在LLaMA2-13B上PPL为15.36，较DLP的16.80降低1.44。零样本任务中，LSA在LLaMA2-7B上平均准确率较DLP提升1.37%（Magnitude剪枝）。

消融实验显示，LSA的块级分配在LLaMA3-8B上PPL为32.94，优于层级的39.56；而OWL/DLP在块级分配时PPL显著恶化（如LLaMA3-8B上OWL块级PPL为37.06，层级为37.06，但细粒度下性能波动大）。LRE计算复杂度方面，LSA在LLaMA1-7B上耗时411.74秒，较Wanda的470.39秒略低，但较Magnitude的0.56秒高两个数量级，表明LRE计算是主要开销。

评估边界：实验未报告置信区间，数值比较需谨慎；未评估量化与剪枝的联合优化；DeepSparse加速实验仅针对LLaMA2-7B，未覆盖通用GPU场景。代码已开源，但LRE贪心算法在超大模型（>30B）上的可扩展性未验证。

## 关联研究分析

从问题动机看，LSA与OWL/DLP均针对层级稀疏率分配，但LSA将重要性评估从“权重评分代理”转变为“重构误差直接度量”。OWL依赖LOD（异常值比例），DLP依赖中位数归约，两者均假设权重评分的统计特性能反映层冗余度。LSA则直接模拟权重移除后的输出变化，捕捉了权重移除的累积误差效应。这一差异源于任务特性：LLM中权重异常值对性能影响非线性，权重评分的线性归约无法准确反映异常值移除后的性能退化，而LRE通过重构误差直接量化了这一退化。

从方法设计看，LSA与Thinet（Luo et al., 2017）等结构化剪枝方法共享“重构误差最小化”思想，但LSA将其扩展至非结构化剪枝的层级分配。Thinet通过最小化输出误差选择剪枝通道，但需重复前向传播，复杂度为通道数的平方；LSA通过预计算$S$矩阵和贪心更新，将复杂度降至线性，使其适用于LLM。此外，LSA的投影级分配与低秩分解方法（如SVD-LLM）不同：低秩分解通过参数复用压缩，LSA通过稀疏率分配压缩，前者产生不规则维度，后者保持密集结构但需稀疏内核支持。

## 总结

LSA解决的核心矛盾是：非结构化剪枝中均匀稀疏率忽略层间冗余差异，导致高稀疏率下性能退化，而现有层级分配方法依赖启发式归约函数且无法支持细粒度分配。LSA通过最小线性重构误差直接量化层重要性，消除了归约函数依赖，并首次实现无性能崩溃的投影级分配。在70%稀疏率下，LSA在LLaMA2-13B上PPL为15.36，较DLP的16.80降低1.44；在LLaMA3-8B上块级分配PPL为32.94，优于层级的39.56。其边界在于：LRE贪心算法计算开销较大（LLaMA1-7B耗时411.74秒），且未验证在超大模型上的可扩展性；未评估与量化、低秩分解的联合优化。当模型规模扩展至100B以上时，LRE计算的线性复杂度是否仍能满足实时剪枝需求，论文未给出回答。
