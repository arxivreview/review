# ICLR2026最新论文 ｜SCALING LINEAR ATTENTION CAPACITY WITH SPARSE STATE EXPANSION ｜稀疏状态扩展（SSE）：线性注意力中的信息分类与容量解耦

研究机构：中国科学院、香港理工大学

作者：Yuqi Pan、Yongqi An、Zheng Li 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_25773893)

> 长上下文建模的核心矛盾在于，线性注意力通过固定尺寸状态实现恒定内存，却因信息过度压缩导致检索与推理能力崩塌。现有方案或依赖全注意力层保留精度，或简单扩大状态矩阵导致参数爆炸，均未能同时解决容量瓶颈与计算效率问题。本文提出将状态更新重构为信息分类过程，通过行稀疏选择与分区扩展机制，在参数不变的前提下提升状态容量。该设计在数学推理任务上超越了同规模Transformer，但在长上下文精确检索上仍落后于全注意力基线，其静态选择机制在动态语义场景下的鲁棒性存疑。

## 研究背景

自回归语言模型在推理阶段需将历史Token编码为紧凑状态以预测下一Token。Softmax Attention通过键值缓存（KV Cache）存储所有历史向量，虽保证了信息无损，但内存占用随序列长度线性增长，计算复杂度呈二次方。为突破此瓶颈，线性注意力将历史上下文压缩至固定尺寸状态矩阵，实现恒定内存与线性计算，但固定状态容量（如128×d）导致远距离信息被过度压缩，在需要精确回忆的检索与推理任务上表现显著劣于Softmax Attention。

该领域的主流路线是混合架构，通过交错全注意力层与线性递归层来平衡精度与效率。然而，这种方案仍依赖全注意力层处理关键检索任务，未能从根本上提升线性层自身的表达能力。另一条路线是简单扩大状态矩阵尺寸，但这直接导致参数量与计算开销同步增加，违背了线性注意力的效率初衷。本文的切入点在于重新审视状态更新的微观机制：现有线性注意力将状态行视为同质存储单元，忽略了信息在状态空间中的分布特性。通过将状态行解释为潜在类别，并引入稀疏选择机制，可以在不增加参数的前提下，有效扩展状态的有效容量，从而缓解信息干扰与遗忘问题。

## 核心方法

### 方法参照系

标准线性注意力采用外积更新机制，将当前Token的键值向量累加至固定状态矩阵。其核心局限在于所有状态行在每个时间步均被更新，导致不同类别的信息相互干扰，状态行趋于同质化，降低了查询时的判别力。本文问题与该通用流程的关键差异在于，不再假设所有状态行对当前Token同等重要，而是引入选择性更新机制。

### 行稀疏状态更新：信息分类视角

本文首先提出行稀疏更新框架，将状态行视为潜在类别，键向量映射 $\mathbf{k}_t = f(\mathbf{x}_t, \mathbf{W}_k)$ 作为类别分配函数。设计动机在于解决全行更新导致的跨类别噪声问题。具体而言，采用Top-k-then-Softmax策略，仅对 $\mathbf{x}_t \mathbf{W}_k$ 中最大的k个元素应用Softmax，其余置零，从而仅更新对应的状态行。

$$
\mathbf{k}_t = \text{softmax}(\text{top}_k(\mathbf{x}_t \mathbf{W}_k)), \quad \mathbf{S}_t = \tilde{\mathbf{\Lambda}}_t \mathbf{S}_{t-1} + \mathbf{k}_t^\top \mathbf{v}_t
$$

该公式表明，状态更新仅发生在被选中的行上，且门控矩阵 $\tilde{\mathbf{\Lambda}}_t$ 也仅作用于选中行。理论分析证明，这种稀疏更新能降低状态行间的余弦相似度，提高判别力，并扩展有效感受野，避免强近期偏置导致的信息衰减。

### 稀疏状态扩展（SSE）

在行稀疏框架基础上，本文进一步提出SSE以突破固定状态容量限制。设计动机在于固定状态尺寸（如128行）限制了长程记忆的存储能力，而简单增加行数会成倍增加参数。SSE将状态扩展为N个分区，每个分区包含c行，总状态大小为 $N \times c$，但所有分区共享同一套注意力投影参数（QKV）。

$$
\mathbf{e}_t = \text{softmax}(\mathbf{x}_t \mathbf{W}_e), \quad \mathbf{k}_t^{[i]} = e_t^{[i]} \cdot \text{softmax}(\mathbf{x}_t \mathbf{W}_k)
$$

其中 $\mathbf{e}_t$ 为门控向量，用于Top-k选择分区；$\mathbf{k}_t^{[i]}$ 为第i个分区的键向量。该机制通过门控向量选择分区，再在选中分区内通过Softmax选择行，实现了参数大小与状态容量的解耦。实验显示，SSE状态具有更低的行间相似度和更高的奇异值熵，表明其能更有效地利用状态空间存储判别性信息。

## 实验评估

实验基于MHA-SwiGLU骨干，在600M和2B参数规模下，覆盖预训练、长上下文扩展、推理蒸馏及强化学习阶段。基线包括GLA、Mamba2、GDN等先进线性模型及Transformer。在语言建模与常识推理上，SSE-n4k1在2B规模下WikiText困惑度为16.92，优于GLA的21.30和Mamba2的17.27；在检索任务上，SSE-n4k1在SQuAD上得分61.46，显著高于GDN的49.29，但仍低于Transformer的73.00。

| 模型 | WikiText PPL ↓ | SQuAD Recall | AIME24 | AIME25 |
| :--- | :--- | :--- | :--- | :--- |
| Transformer-2B | 16.46 | 73.00 | 64.1 | 52.8 |
| GLA-2B | 21.30 | 51.27 | - | - |
| Mamba2-2B | 17.27 | 56.62 | - | - |
| GDN-2B | 17.08 | 54.63 | - | - |
| **SSE-n4k1-2B** | **16.92** | **61.46** | - | - |
| **SSE-H-n4k1-2B** | **16.47** | **70.87** | **64.5** | **50.2** |

SSE-H（混合架构）在AIME24上取得64.5分，AIME25上取得50.2分，超越了同规模开源Transformer（如Qwen3-1.7B的43.1分）。消融实验显示，Softmax行选择比SiLU提升召回率6.93个百分点；共享参数设计在参数增加近一倍的情况下，召回率反而下降5.21个百分点，验证了参数共享对稳定性的关键作用；Write-Read门控比无门控提升召回率4.76个百分点。

评估边界方面，论文未提供代码开源链接，且未在RULER、HELMET等标准长上下文检索基准上进行测试，仅使用SQuAD等通用问答数据集。此外，实验主要聚焦于数学推理与语言建模，对多轮对话、代码生成等动态场景的评估不足。超参数细节（如Top-k的具体k值、分区数N的选取范围）在正文中描述较为简略，仅提及n4k1设置，缺乏对稀疏率与性能权衡的系统性扫描。

## 关联研究分析

从方法设计看，SSE与Factorization Memory（Xiong et al., 2025）均致力于解决线性注意力状态容量不足问题，但路径截然不同。Factorization Memory通过稀疏状态更新仅激活固定数量记忆状态中的子集，侧重于在固定总容量下优化更新效率；而SSE通过分区扩展直接增加状态总容量，并依赖参数共享控制开销。SSE的静态Top-k行选择机制与SpotAttention（Ahmad and Yun, 2026）的动态块选择形成对比，后者基于内容感知动态调整稀疏模式，而SSE的稀疏性由键向量分布决定，缺乏对序列语义演变的显式适应。这种静态选择在长序列中语义剧烈变化时，是否会导致选择滞后或错误，论文未给出回答。

从问题动机看，SSE-H混合架构与Jamba（P38）类似，均通过交错全注意力与线性层提升性能。但Jamba依赖全注意力层保证检索精度，线性层仅负责局部上下文总结；SSE-H则试图通过增强线性层本身的状态容量与判别力，缩小其与全注意力层的差距。实验显示SSE-H在SQuAD上得分70.87，接近Transformer的73.00，但在AIME推理任务上，SSE-H（64.5）与Transformer（64.1）持平，表明状态扩展对推理能力的提升可能部分依赖于混合架构中的全注意力层，而非线性层本身的独立贡献。

## 总结

本文旨在解决线性注意力固定状态导致的检索与推理性能瓶颈，切入点在于将状态更新重构为信息分类过程，通过行稀疏选择与分区扩展解耦参数与容量。SSE在2B规模下实现了16.92的WikiText困惑度和61.46的SQuAD召回率，SSE-H在AIME24上取得64.5分，超越了同规模开源Transformer。然而，实验暴露了SSE在长上下文精确检索上仍落后于全注意力Transformer（73.00 vs 70.87），且其静态Top-k选择机制缺乏对动态语义变化的适应性。当序列长度进一步增加或语义分布发生剧烈偏移时，静态稀疏选择是否仍能保持足够的判别力，论文未提供相关证据。
