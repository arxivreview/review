# ICLR2026最新论文 ｜Principled RL for Diffusion LLMs Emerges from a Sequence-Level Perspective ｜序列级策略优化（ESPO）：弥合扩散语言模型与强化学习目标的结构性断裂

研究机构：中国人民大学、美国斯坦福大学

作者：Jingyang Ou、Jiaqi Han、Minkai Xu 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.03759)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.03759)

> 扩散语言模型（dLLMs）通过并行去噪生成文本，但其非自回归特性导致标准强化学习（RL）算法中依赖的 Token 级条件概率失效，使得现有方法只能依赖启发式近似，在需要全局一致性的任务上表现不佳。本文指出，强行将 dLLMs 适配到 Token 级动作空间是根本性错误，应反过来将 RL 算法适配到 dLLMs 的序列级生成本质。为此，作者提出 ELBO-based Sequence-level Policy Optimization (ESPO)，将整条序列视为单一动作，并用证据下界（ELBO）作为序列似然的可行代理。该方法在规划任务上实现了显著的性能跃升，但在通用数学与代码任务上的增益相对有限，其普适性仍存疑。

## 研究背景

理解本文需厘清两个核心概念的冲突。自回归（AR）模型将序列似然分解为条件概率的乘积 $\pi_\theta(y|x) = \prod_{k=1}^L \pi_\theta(y_k|x, y_{<k})$，这种分解天然定义了 Token 级动作空间，是 GRPO 等主流 RL 算法的基础。然而，扩散语言模型（dLLMs）通过迭代去噪恢复文本，其生成过程是整体性的，不存在左到右的因果链，导致 AR 模型中的 Token 级条件概率 $\pi_\theta(y_k|x, y_{<k})$ 在 dLLMs 中要么定义不明，要么计算成本极高。这一结构性差异使得直接套用 AR 的 RL 目标在 dLLMs 上失效。

当前 dLLM 领域的研究重心已从预训练扩展转向后训练，旨在通过 RL 增强其在数学、代码等复杂推理任务上的能力。然而，现有尝试均陷入“适配模型”的误区：d1 (Zhao et al., 2025) 使用均值场近似 $\log p_\theta(y_k|x)$ 替代条件概率，忽略了上下文依赖；UniGRPO (Yang et al., 2025) 和 Coupled-GRPO (Gong et al., 2025) 则尝试用 ELBO 的 Token 级贡献 $\mathcal{L}^{[k]}_\theta(y|x)$ 作为代理。这些方法虽然缓解了部分计算问题，但 ELBO 仅在序列级别具有概率解释，将其拆解为 Token 级分量并代入 GRPO 目标引入了未知的理论不一致性，导致训练不稳定或在需要全局一致性的任务上性能停滞。

本文的切入点在于视角的逆转：不是修改 dLLM 以适配 AR 算法，而是修改 RL 算法以尊重 dLLM 的序列级本质。作者提出，dLLMs 不应被强制纳入 AR 的 Token 级动作空间，而应将整条序列的生成视为一个原子动作。这一转变消除了 Token 级近似的理论缺陷，为构建稳定且原则性的 dLLM-RL 框架奠定了基础。

## 核心方法

### 方法参照系

标准 GRPO 算法基于 AR 模型的 Token 级分解，通过计算每个 Token 的重要性比率 $\frac{\pi_\theta(y_k|x, y_{<k})}{\pi_{\theta_{old}}(y_k|x, y_{<k})}$ 来更新策略。本文的核心差异在于，dLLMs 缺乏这种分解，因此必须放弃 Token 级比率，转而构建基于整条序列的比率，并使用 ELBO 近似不可计算的序列对数似然。

### 序列级策略目标与 ELBO 近似

在参照系中，GRPO 的目标函数包含对 Token 级重要性比率的求和。本文将其扩展至序列级，定义序列级重要性比率。由于精确的序列对数似然 $\log \pi_\theta(y|x)$ 在 dLLMs 中不可计算，本文采用 ELBO $\mathcal{L}_\theta(y|x)$ 作为其可行代理。然而，原始 ELBO 差值 $\mathcal{L}_\theta(y|x) - \mathcal{L}_{\theta_{old}}(y|x)$ 的量级随序列长度 $L$ 线性增长，直接指数化会导致比率数值爆炸或消失，引发训练崩溃。为解决此问题，本文引入按 Token 归一化，将原始对数比率除以序列长度 $L$，得到稳定的序列级比率：

$$
\text{ratio}_i = \exp\left( \frac{1}{L} \left[ \mathcal{L}_\theta(y_i|x) - \mathcal{L}_{\theta_{old}}(y_i|x) \right] \right)
$$

这一设计动机在于消除序列长度对梯度信号的干扰，使优化过程在不同长度序列上保持一致性，从而解决了原始 ELBO 差值导致的数值不稳定问题。

### 稳定的 KL 散度估计

在序列级目标中，KL 散度正则项用于约束策略更新。标准 AR 模型常用 $k_3$ 估计器，但其公式包含指数项，在序列级 ELBO 近似下会重新引入前述的数值不稳定问题。本文改用 $k_2$ 估计器，其形式为 ELBO 差值的二次函数，避免了指数运算：

$$
\hat{D}_{KL} = \frac{1}{2} \left( \frac{1}{L} \left[ \mathcal{L}_\theta(y|x) - \mathcal{L}_{\theta_{old}}(y|x) \right] \right)^2
$$

该设计动机在于，$k_2$ 估计器的多项式形式确保了 KL 正则项的梯度信号在长序列下依然稳定且行为良好，避免了 $k_3$ 估计器因指数项导致的训练停滞或崩溃，从而保证了大规模训练的鲁棒性。

## 实验评估

实验在 LLaDA-8B-Instruct 和 Dream-7B-Instruct 两个开源 dLLMs 上进行，任务涵盖数学（GSM8K, MATH）、代码（HumanEval, MBPP）和规划（Countdown, Sudoku）。基线包括 d1 (diffu-GRPO) 和 wd1，均为 Token 级 RL 方法。

| 模型 / 序列长度 | GSM8K (Avg) | MATH (Avg) | Countdown (Avg) | Sudoku (Avg) |
| :--- | :--- | :--- | :--- | :--- |
| LLaDA + d1 | 78.0 | 37.7 | 33.9 | 22.2 |
| LLaDA + wd1 | 80.1 | 36.9 | 48.3 | 23.1 |
| LLaDA + ESPO | 82.0 | 39.5 | 81.0 | 86.0 |
| Dream + d1 | 80.2 | 45.1 | 30.8 | 61.7 |
| Dream + wd1 | 80.5 | 45.8 | 36.3 | 33.0 |
| Dream + ESPO | 81.3 | 46.0 | 66.8 | 71.8 |

ESPO 在规划任务上表现突出，LLaDA 在 Countdown 上从 48.3 提升至 81.0，Sudoku 从 23.1 提升至 86.0，增益远超 Token 级基线。在数学和代码任务上，ESPO 也一致优于基线，但增益幅度较小（如 GSM8K 从 80.1 提升至 82.0），且与 LLaDA-1.5 的性能相当。

消融实验显示，序列级动作空间与 ELBO 近似的组合是唯一能稳定收敛至最高奖励的配置。Token 级 ELBO 虽然初期有进展，但随后崩溃，验证了 ELBO 不可拆解的理论分析。在 KL 估计器选择上，$k_2$ 估计器表现稳定，而 $k_1$ 和 $k_3$ 分别出现剧烈波动和停滞。此外，增加蒙特卡洛样本数（MC=2 或 4）在信号丰富的 Sudoku 任务上加速了收敛，但在稀疏奖励的 Countdown 任务上收益有限。

评估边界方面，本文仅在 256 长度上训练，但结果泛化至 128 和 512 长度，表明方法对序列长度具有鲁棒性。代码已开源，但论文未报告置信区间，且未与 AR 模型的 RL 方法（如 GRPO on LLaMA）进行直接对比，限制了跨范式比较的完整性。

## 关联研究分析

从问题动机看，ESPO 与 d1 和 wd1 的根本差异在于对 dLLM 生成机制的理解。d1 和 wd1 试图在 Token 级寻找 AR 条件概率的替代物，这本质上是在用局部近似去拟合全局过程，导致在需要全局一致性的规划任务上失效。ESPO 则承认 dLLM 的序列级本质，将整条序列作为动作，从而在理论上消除了近似误差。这一差异源于任务特性：规划任务（如 Sudoku）要求全局约束满足，Token 级优化无法捕捉这种长程依赖，而序列级优化则能直接优化全局一致性。

从方法设计看，ESPO 与 AR 模型中的 GRPO 共享组相对优势估计的思路，但动作空间从 Token 级跃迁至序列级。与 AR 模型相比，dLLM 的序列级比率计算涉及 ELBO 差值，其方差特性不同，因此需要按 Token 归一化和 $k_2$ KL 估计器来稳定训练。这种设计选择并非随意，而是由 dLLM 的 ELBO 近似特性决定的。然而，ESPO 在数学和代码任务上的增益有限，这可能暗示这些任务更依赖局部逻辑推理而非全局一致性，序列级优化的优势在此类任务上被稀释。

## 总结

本文旨在解决 dLLMs 中 RL 目标与生成机制的结构性不匹配，指出 Token 级近似是根本性错误，转而提出序列级视角。ESPO 通过将整条序列视为单一动作，并用 ELBO 作为似然代理，结合按 Token 归一化和 $k_2$ KL 估计器，实现了稳定且原则性的 RL 训练。实验证明，该方法在规划任务上实现了显著增益（如 Sudoku 提升 60+ 点），但在数学和代码任务上增益有限。其边界在于，序列级优化可能更适用于全局一致性任务，而对局部逻辑推理任务的普适性尚未充分验证。当任务类型从全局规划转向局部逻辑推理时，序列级优化的边际收益是否递减，论文未给出回答。
