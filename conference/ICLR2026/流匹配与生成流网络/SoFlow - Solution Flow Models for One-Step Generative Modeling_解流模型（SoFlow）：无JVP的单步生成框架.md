# ICLR2026最新论文 ｜SoFlow: Solution Flow Models for One-Step Generative Modeling ｜解流模型（SoFlow）：无JVP的单步生成框架

研究机构：美国普林斯顿大学

作者：Tianze Luo、Haotian Yuan、Zhuang Liu

论文原文见 [arXiv](https://arxiv.org/abs/2512.15657)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.15657)

> 流匹配（Flow Matching, FM）通过回归速度场实现分布传输，但多步ODE积分导致推理延迟高企，现有少步生成方法要么依赖蒸馏教师模型，要么在训练中引入计算开销巨大的雅可比-向量积（Jacobian-vector product, JVP）。本文切入点在于直接学习速度ODE的解函数，通过双时间参数化与解一致性损失，在无需JVP计算的前提下实现单步生成。该方法在相同架构与训练轮数下，以2.96的FID-50K超越MeanFlow的3.43，验证了无JVP解函数学习的有效性，但其对非直线轨迹的拟合能力与训练阶段CFG对多样性的影响仍未被充分探讨。

## 研究背景

流匹配将生成过程建模为从简单先验到复杂数据分布的确定性传输，其核心是学习一个时间依赖的速度场 $v_\theta(x_t, t)$。然而，从噪声 $x_1$ 到数据 $x_0$ 的采样需通过数值求解器积分ODE，步数越多质量越高但延迟越大。为突破这一瓶颈，一致性模型（Consistency Models, CM）通过强制轨迹自一致性实现少步生成，但从零训练时存在优化目标不稳定且无法有效利用无分类器引导（Classifier-Free Guidance, CFG）的缺陷。近期工作如MeanFlow通过引入FM损失解决稳定性问题，但其训练依赖JVP计算，在PyTorch等框架中优化程度远低于前向传播，成为新的计算瓶颈。

本文针对这一计算瓶颈，提出直接学习速度ODE的解函数 $f(x_t, t, s)$，该函数将时间 $t$ 的状态 $x_t$ 直接映射到时间 $s$ 的状态 $x_s$。这一设计将轨迹积分问题转化为函数逼近问题，既继承了FM的无模拟训练特性，又通过双时间参数化天然兼容CFG，同时消除了对JVP的依赖。

## 核心方法

### 解函数参数化与边界约束

本文方法参照系为FM中的速度场回归，但关键差异在于不回归瞬时速度，而是回归ODE的解函数。为确保解函数满足边界条件 $f(x_t, t, t) = x_t$，本文采用参数化形式：

$$f_\theta(x_t, t, s) = a(t, s)x_t + b(t, s)F_\theta(x_t, t, s)$$

其中 $a(t, s)$ 和 $b(t, s)$ 为标量函数，满足 $a(t, t)=1, b(t, t)=0$，$F_\theta$ 为原始神经网络。该设计动机在于，通过显式约束边界条件，避免了CM中因优化目标随时间变化导致的训练不稳定，同时为后续损失函数构造提供了可微的基础。

### 解一致性损失与无JVP训练

在参数化基础上，本文构造解一致性损失以学习 $s < t$ 时的状态转移。根据泰勒展开，当 $l$ 接近 $t$ 时，有近似关系 $f(x_t, t, s) \approx f(x_t + (\alpha_t' x_0 + \beta_t' x_1)(l-t), l, s)$。据此，本文定义损失函数：

$$\mathcal{L}_{SCM}(\theta) = \mathbb{E}_{x_0, x_1, t, l, s} \left[ w(t, s) \left\| f_\theta(x_t, t, s) - \text{sg}[f_{\theta^-}(x_t + (\alpha_t' x_0 + \beta_t' x_1)(l-t), l, s)] \right\|_2^2 \right]$$

其中 $\text{sg}$ 表示停止梯度，$w(t, s)$ 为自适应权重。该损失的核心创新在于，它利用泰勒展开的一阶近似替代了精确的ODE积分，从而无需计算 $f_\theta$ 对 $x_t$ 的雅可比矩阵，彻底消除了JVP计算。这一设计解决了MeanFlow在PyTorch中JVP效率低下的瓶颈，使得训练速度更快且GPU内存占用更低。

### 混合损失与CFG集成

总训练损失为FM损失与解一致性损失的加权组合：$\mathcal{L}(\theta) = \lambda \mathcal{L}_{FM}(\theta) + (1-\lambda) \mathcal{L}_{SCM}(\theta)$。FM损失项 $v(x_t, t) = \partial_3 f_\theta(x_t, t, t)$ 允许模型在训练阶段提供速度场估计，从而支持CFG。本文在训练阶段随机丢弃条件，使模型同时学习条件与无条件速度场，推理时通过线性组合增强生成质量。这一设计动机在于，CM从零训练时无法有效利用CFG，而本文通过FM损失锚定速度场，使得CFG在单步生成中依然有效，提升了生成保真度。

## 实验评估

实验在ImageNet 256×256类条件生成与CIFAR-10无条件生成上进行，基线覆盖MeanFlow（直接竞品）、DiT/SiT（多步基线）及CM/iCT（一致性基线），但缺失对抗后训练（如CAF）及最新RL对齐方法（如Flow-GRPO）的对比。

| 模型规模 | MeanFlow FID-50K (1-NFE) | SoFlow FID-50K (1-NFE) | SoFlow FID-50K (2-NFE) |
| :--- | :--- | :--- | :--- |
| B/2 | 6.17 | 4.85 | 4.24 |
| M/2 | 5.01 | 3.73 | 3.42 |
| L/2 | 3.84 | 3.20 | 2.90 |
| XL/2 | 3.43 | 2.96 | 2.66 |

在相同DiT架构与240轮训练下，SoFlow-XL/2的1-NFE FID-50K为2.96，优于MeanFlow-XL/2的3.43，2-NFE FID-50K为2.66，优于MeanFlow的2.93。

消融实验显示，损失权重系数 $p$ 对性能影响显著，$p=1.0$ 时FID-50K为58.57，而 $p=0.0$ 时为68.25，表明鲁棒损失对大误差样本的抑制至关重要。噪声调度方面，线性调度配合Euler参数化（FID-50K 11.59）优于三角调度（FID-50K 17.50），验证了直线轨迹假设的有效性。CFG强度 $w=3.0$ 时FID-50K最低（11.59），但速度混合比 $m$ 需较小（0.25）以抑制CFG引入的方差。

评估边界方面，论文未报告置信区间，数值比较需谨慎；CIFAR-10实验未提供具体FID数值，仅说明采用U-Net架构；代码已开源，但超参数如 $\lambda$ 的最优值未完全披露，可复现性依赖于附录中的详细设置。

## 关联研究分析

从方法设计看，SoFlow与MeanFlow同属映射学习路线，但MeanFlow通过估计区间平均速度消除离散化误差，其损失函数需计算JVP以关联瞬时速度与平均速度；SoFlow则直接学习解函数，通过泰勒展开近似状态转移，避免了JVP。这一差异的根源在于，MeanFlow关注速度场的统计特性，而SoFlow关注轨迹的几何映射，后者在计算效率上更具优势，但可能牺牲了对非直线轨迹的精确拟合能力。

从问题动机看，SoFlow与一致性模型（CM）共享少步生成的目标，但CM通过强制轨迹自一致性实现，其优化目标随时间变化导致训练不稳定；SoFlow引入FM损失锚定速度场，使得训练目标稳定且兼容CFG。这一差异源于CM的自一致性假设在从零训练时缺乏物理约束，而SoFlow的解函数参数化提供了明确的边界条件，使得训练过程更可控。

## 总结

SoFlow要解决的核心矛盾是少步生成中的计算效率与生成质量权衡，现有方法如MeanFlow因依赖JVP计算而效率受限，CM因优化目标不稳定而难以利用CFG。本文抓住的切入点是直接学习ODE解函数，通过双时间参数化与解一致性损失，在无需JVP的前提下实现单步生成。实验证明，在相同架构与训练轮数下，SoFlow-XL/2的1-NFE FID-50K为2.96，2-NFE为2.66，均优于MeanFlow。本文的边界在于，其线性噪声调度与Euler参数化假设了轨迹的近似直线性，对复杂分布的拟合能力未充分验证；训练阶段引入CFG可能过度平滑条件分布，影响生成多样性。当数据分布呈现高度非线性时，解函数的泰勒展开近似是否仍能保持精度，论文未给出回答。
