# ICLR2026最新论文 ｜Test-Time Iterative Error Correction for Efficient Diffusion Models ｜迭代误差修正

研究机构：厦门大学

作者：Yunshan Zhong、Weiqi Yan、Yuxin Zhang

论文原文见 [arXiv](https://arxiv.org/abs/2511.06250)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.06250)

> 扩散模型在部署后常因量化或缓存引入近似误差，且这些误差随时间步累积导致生成质量严重退化。现有加速方法多为部署前优化，一旦模型上线便无法重新校准或访问原始高精度权重，导致误差不可逆。本文切入点在于揭示误差传播的指数增长特性，并提出一种无需重训、不修改架构的测试时迭代修正机制。该方法通过不动点迭代将误差累积从指数级降至线性级，为已部署模型提供了质量恢复手段，但其额外计算开销与特定采样器的依赖关系仍存疑。

## 研究背景

扩散模型的反向去噪过程通常被建模为确定性常微分方程（ODE）的求解，其中每一步去噪都依赖于前一步的输出。当引入网络量化或特征缓存等结构效率技术时，每一步都会产生微小的预测偏差。这种偏差并非孤立存在，而是作为输入扰动传递至下一步，形成误差传播链。理解这一链式反应的关键在于分析每一步线性变换的谱范数，即误差放大系数。若该系数持续大于1，微小误差将在多步迭代中被指数级放大，最终导致生成图像出现严重伪影或结构崩坏。

当前领域主流关注点集中在如何降低推理延迟与显存占用，如通过蒸馏减少采样步数或通过量化压缩模型体积。然而，这些方法大多假设在部署前完成所有优化，且依赖原始高精度模型进行校准或蒸馏。一旦模型部署在边缘设备或生产环境，原始权重往往不可获取，且重新执行效率化流程的工程成本极高。这导致了一个被忽视的困境：已部署的加速模型因累积误差而质量下降，却缺乏有效的后部署修正手段。本文正是针对这一“部署后不可逆误差”问题，探索在不触碰模型参数的前提下，通过推理时的动态修正来恢复生成质量。

## 核心方法

### 方法参照系

本文问题置于“高效扩散模型推理加速”的通用流程中。标准流程为：加载量化/缓存模型 → 执行DDIM确定性采样 → 输出图像。关键差异在于，标准流程视模型为黑盒，仅执行单次前向传播；而本文在每一步去噪后插入一个迭代修正循环，将“单次预测”转化为“多次精化”，以抵消累积误差。

### 误差传播动力学分析

设计动机在于解释为何简单的误差补偿无效。本文首先建立误差传播的递归关系。在DDIM采样中，理想更新规则为 $x_{t-1} = A_t x_t + B_t \epsilon_\theta(x_t, t)$。引入量化或缓存误差后，实际输入变为 $\tilde{x}_t = x_t + \delta_t$，模型预测变为 $\tililde{\epsilon}_\theta(x_t, t) = \epsilon_\theta(x_t, t) + \epsilon_\delta^\theta$。通过泰勒展开，误差 $\delta_{t-1}$ 的递归式为：

$$ \delta_{t-1} = (A_t + B_t J_t) \delta_t + B_t \epsilon_\delta^\theta $$

其中 $J_t$ 为模型输出的雅可比矩阵。该公式表明，当前步误差由前一步误差经矩阵 $(A_t + B_t J_t)$ 放大，并叠加新的预测误差。实证分析显示，$\|A_t + B_t J_t\|$ 在多数时间步大于1，导致误差呈指数增长。这一发现揭示了加速模型质量退化的动力学根源，为后续修正提供了理论依据。

### 迭代误差修正机制

设计动机在于打破误差的指数累积链。IEC在每一步去噪后，对初步估计 $x_{t-1}^{(0)}$ 进行迭代精化。更新规则定义为：

$$ x_{t-1}^{(k+1)} = A_t x_t + B_t \epsilon_\theta(x_{t-1}^{(k)}, t-1) + \lambda (x_{t-1}^{(k)} - x_{t-1}^{(k-1)}) $$

该公式可视为求解不动点方程 $x = G(x)$ 的迭代过程，其中 $G(x)$ 包含模型预测与修正项。根据Banach不动点定理，若映射 $G(x)$ 的Lipschitz常数 $L < 1$，则迭代收敛至唯一解。通过调整超参数 $\lambda$，可确保 $L < 1$，从而将误差累积从指数级抑制为线性级。理论上，经过 $K$ 次迭代后，误差上界为 $\|\delta_{t-1}^{(K)}\| \le L^K \|\delta_{t-1}^{(0)}\| + \frac{C(1-L^K)}{1-L}$，其中 $C$ 为与迭代无关的常数。当 $K$ 足够大时，误差收敛至 $\frac{C}{1-L}$，消除了对前序时间步误差的依赖。

## 实验评估

实验在CIFAR-10、LSUN-Churchs、LSUN-Bedrooms、ImageNet 256×256及MS-COCO上进行，基线包括DDIM、LDM、Stable Diffusion及量化（W4A8/W8A8）、DeepCache、CacheQuant等加速方法。基线覆盖全面，但缺失蒸馏类（如一致性模型）基线，因IEC主要针对结构效率误差而非步数减少误差。

| 数据集 | 方法 | 基线 FID | IEC FID | 提升幅度 |
| :--- | :--- | :--- | :--- | :--- |
| CIFAR-10 | W8A8 量化 | 4.32 | 3.76 | 0.56 |
| CIFAR-10 | DeepCache N=10 | 9.74 | 7.77 | 1.97 |
| LSUN-Bedrooms | DeepCache N=10 | 26.09 | 16.91 | 9.18 |
| ImageNet | CacheQuant W8A8 N=10 | 4.68 | 4.15 | 0.53 |
| MS-COCO | CacheQuant W8A8 N=5 | 23.74 | 22.83 | 0.91 |

IEC在所有测试场景中均带来FID下降，尤其在DeepCache大N值（如N=10, N=15）下提升显著，表明其对缓存误差的修正能力更强。消融实验显示，仅对首尾1/10时间步应用IEC即可获得大部分收益，且增加迭代次数K=2或3仅带来边际改善，说明单次迭代已足够有效。

评估边界方面，论文仅验证了DDIM确定性采样器，未测试DDPM等随机采样器，限制了结论的普适性。此外，IEC引入额外计算开销，论文未详细报告时间开销与加速收益的净平衡，且实验未包含大规模T2I任务（如Stable Diffusion XL），在复杂语义对齐场景下的表现未知。代码已开源，超参数 $\lambda=0.5$ 固定，缺乏自适应调度机制。

## 关联研究分析

从问题动机看，本文与CacheQuant（Liu et al., 2025b）等加速方法形成互补而非竞争关系。CacheQuant通过量化与缓存结合降低计算成本，但引入了复合误差；IEC则作为后处理插件，修复这些误差。差异根源在于任务阶段：前者关注部署前优化，后者关注部署后修正。这种分工反映了扩散模型效率优化的两个维度：计算资源节约与质量损失控制。然而，IEC对误差的修正依赖于模型输出的雅可比矩阵稳定性，若模型本身存在训练-推理不一致（如蒸馏模型），IEC的收敛性可能受损，论文未对此类场景进行验证。

从方法设计看，IEC与内部引导（Internal Guidance, Zhou et al., 2025）同属推理时干预策略，但机制不同。内部引导利用模型内部状态调整采样路径，旨在提升多样性或对齐度；IEC则通过迭代精化单步输出，旨在消除累积误差。差异根源在于目标函数：前者优化全局采样轨迹，后者优化局部预测精度。IEC的不动点迭代框架更通用，可应用于任何存在误差累积的迭代过程，但其效果受限于模型局部线性近似的有效性。对于高度非线性的模型区域，IEC的收敛速度可能变慢，论文未提供对此类区域的敏感性分析。

## 总结

本文核心矛盾在于已部署扩散模型因量化/缓存误差累积导致质量退化，且无法通过重训或重新校准解决。切入点在于揭示误差指数增长的数学特性，并利用不动点迭代将其转化为线性增长。方法上，IEC通过引入 $\lambda$ 修正项确保迭代收敛，无需修改模型架构。实验证明，在CIFAR-10上，IEC将W8A8量化模型的FID从4.32降至3.76，在LSUN-Bedrooms上将DeepCache N=10的FID从26.09降至16.91。边界在于仅验证DDIM采样器，且未量化额外计算开销对实时性的影响。当模型部署在资源极度受限的边缘设备时，IEC的迭代开销是否会被量化/缓存节省的资源完全抵消，论文未给出明确回答。
