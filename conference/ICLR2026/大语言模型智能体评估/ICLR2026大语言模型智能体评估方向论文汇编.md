【DO LLM AGENTS KNOW HOW TO GROUND, RE - COVER, AND ASSESS? EVALUATING EPISTEMIC COM PETENCE IN INFORMATION-SEEKING AGENTS ｜搜索智能体认知胜任力评估

研究机构：香港科技大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_47213149)

> 现有搜索智能体评估仅关注最终答案准确率，无法区分“正确但推理错误”与“正确且推理严谨”的行为，导致高分数掩盖了幻觉与过度自信等认知缺陷。SeekBench 通过构建专家标注的轨迹模式，将评估对象从结果转向过程，量化智能体在证据获取、恢复与校准上的认知胜任力。该方法揭示了强化学习智能体在证据合成与推理接地上的能力分化，为过程级审计提供了可操作的指标体系，但其指标与最终任务成功率之间的因果转化机制尚未完全确立。

【Talk, Evaluate, Diagnose: User-aware Agent Evaluation with Automated Error Analysis ｜用户感知智能体评估框架

研究机构：美国斯坦福大学

作者：Penny Chong、Harshavardhan Abichandani、Jiyuan Shen 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.15483)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.15483)

> 智能体评估长期受困于异构环境下的指标碎片化，且现有方法普遍忽视用户交互质量对性能的独立影响。本文切入点在于将用户角色从任务指令中解耦，并引入轮次效率指标以捕捉中间过程。通过构建“对话-评估-诊断”三阶段闭环，TED 框架实现了跨领域的通用化审计。该框架在揭示模型排名反转方面具有独特价值，但其对 LLM 评判器稳定性的依赖仍构成主要存疑点。

【TRAJECT-Bench:A Trajectory-Aware Benchmark for Evaluating Agentic Tool Use ｜轨迹感知的工具调用评估基准

研究机构：美国密歇根州立大学、美国宾夕法尼亚州立大学

作者：Pengfei He、Zhenwei Dai、Bing He 等 13 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.04550)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.04550)

> 现有智能体评估多聚焦于最终答案的正确性，导致无法区分模型是真正掌握了工具调用逻辑，还是仅凭内部知识“猜”出了结果。TRAJECT-Bench 通过构建包含 1228 个高保真生产级 API 的工具集，并引入轨迹结构（并行/串行）与查询难度（直接/隐含）的双维度控制变量，将评估重心从结果导向转向过程审计。该基准通过精确匹配、包含率及参数校验等细粒度指标，量化了模型在复杂依赖链中的执行偏差。其核心价值在于揭示了从短轨迹向中长轨迹过渡时的性能瓶颈，但在动态环境适应性与多智能体协作归因方面仍存在局限。

【VitaBench: Benchmarking LLM Agents with Versatile Interactive Tasks in Real-world Applications ｜真实世界交互智能体基准

研究机构：美团

作者：Wei He、Yueqing Sun、Hongyan Hao 等 16 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.26490)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.26490)

> 现有智能体评估基准多局限于静态环境或单一领域，无法捕捉真实部署中多工具依赖、动态用户交互及跨场景推理的复杂性。VitaBench 通过构建包含 66 个工具、400 个任务的跨场景生活服务平台，并引入基于评分标准的滑动窗口评估器，解决了长轨迹评估中的上下文截断与多解路径判定难题。该基准揭示了当前最先进模型在跨场景任务中仅 30.0% 的成功率，验证了真实世界交互对智能体能力的严峻挑战，但其去策略化设计对评估方差的影响尚需进一步消融验证。
