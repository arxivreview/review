# ICLR2026最新论文 ｜pi-Flow: Policy-Based Few-Step Generation via Imitation Distillation ｜策略基流模型（π-Flow）：基于模仿学习的少步生成范式

研究机构：美国斯坦福大学、Adobe研究院

作者：Hansheng Chen、Kai Zhang、Hao Tan 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.14974)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.14974)

> 少步扩散蒸馏旨在将多步教师模型压缩为极少步学生模型，以解决实时生成中的推理延迟瓶颈。现有捷径预测方法因直接映射噪声至数据，导致训练复杂且易引发质量-多样性权衡失效。本文提出策略基流模型（π-Flow），通过解耦网络评估与ODE积分子步，利用在线模仿学习训练无网络策略，实现稳定且高保真的少步生成。该方法在保持教师级质量的同时显著提升了多样性，但其在非可微奖励对齐场景下的鲁棒性尚未得到充分验证。

## 研究背景

扩散模型通过迭代求解概率流常微分方程（Probability Flow ODE, PF-ODE）实现高质量生成，但每次求解均需多次神经网络前向传播，导致推理成本高昂。为降低计算开销，少步蒸馏技术试图将教师模型压缩为仅需1-4次网络评估（Number of Function Evaluations, NFE）的学生模型。这一过程的核心挑战在于如何在不损失分布保真度的前提下，大幅减少ODE积分所需的网络查询次数。

主流蒸馏路线分为轨迹一致性与分布匹配两类。轨迹一致性方法（如Consistency Models）通过自监督映射学习单步生成，但面临训练不稳定与高频细节丢失问题；分布匹配蒸馏（Distribution Matching Distillation, DMD）通过最小化KL散度对齐分布，虽提升了保真度，却引入了模式坍缩风险，导致生成多样性下降。此外，捷径预测模型直接预测从噪声到数据的映射，绕过了中间ODE状态，但这种格式不匹配使得训练目标复杂，且误差在少步累积中迅速放大，进一步加剧了质量与多样性的冲突。

本文切入点在于重新定义学生模型的输出形式。传统方法将网络评估次数与ODE积分步数耦合，而π-Flow将二者解耦：网络仅负责预测一个“无网络策略”（Network-Free Policy），该策略以极低成本提供密集子步的速度场，从而在极少网络评估下实现高精度ODE积分。这一设计规避了捷径预测的格式不匹配问题，使得训练目标简化为标准流匹配损失，从根本上缓解了误差累积与多样性坍缩。

## 核心方法

### 策略基流模型架构

π-Flow的核心在于将学生网络 $G_\phi$ 的输出从单一速度向量扩展为动态策略函数 $\pi$。给定初始状态 $(\mathbf{x}_{t_{src}}, t_{src})$，网络预测一个参数化的速度场，该场在后续ODE积分子步中无需再次查询网络即可提供速度值。这一架构解耦了网络评估（仅1次）与ODE积分（多次子步），使得学生模型既能享受少步生成的效率，又能保留教师模型密集积分的精度。

### 策略基模仿蒸馏（π-ID）

π-ID采用DAgger风格的在线模仿学习策略，解决少步蒸馏中的误差累积问题。在训练过程中，学生策略 $\pi$ 在自身轨迹上滚动（Rollout），在访问的中间状态 $\mathbf{x}_t$ 处查询教师速度 $G_\theta(\mathbf{x}_t, t)$，并最小化策略输出与教师速度之间的 $\ell_2$ 损失：

$$
\mathcal{L}_\phi = \frac{1}{2} \left\| G_\theta(\mathbf{x}_t, t, \mathbf{c}) - \pi(\mathbf{x}_t, t) \right\|_2^2
$$

该损失函数的物理含义是：在策略自身生成的轨迹上，强制策略的速度场与教师的速度场对齐。由于训练在策略自身轨迹上进行，教师模型的纠正信号能够引导偏离的轨迹回归正轨，从而避免离线行为克隆中常见的 $O(n^2 \epsilon)$ 误差复合效应，将误差界控制在 $O(n \epsilon)$ 范围内。

### GMFlow策略与鲁棒性增强

为提升策略的表达能力与鲁棒性，本文采用GMFlow策略，其速度场由因子化高斯混合（Gaussian Mixture, GM）分布参数化：

$$
q(\mathbf{u} | \mathbf{x}_{t_{src}}) = \sum_{i=1}^L \sum_{k=1}^K A_{ik} \mathcal{N}(\mathbf{u}_i; \boldsymbol{\mu}_{ik}, s^2 \mathbf{I})
$$

其中 $A_{ik}$ 为混合权重，$\boldsymbol{\mu}_{ik}$ 为均值，$s$ 为标准差。GMFlow通过预测多个去噪模式，能够适应初始状态的扰动。为进一步提升鲁棒性，训练过程中引入GM Dropout，随机掩蔽部分混合分量，迫使策略在缺失部分模式时仍能生成合理速度，从而增强对轨迹变异的泛化能力。

## 实验评估

实验在ImageNet-256、COCO-2014、HPSv2及OneIG-Bench上进行，对比基线包括MeanFlow、Shortcut、FACM、SenseFlow（DMD）、FLUX Turbo（GAN）及Qwen-Image Lightning。基线覆盖了轨迹一致性、分布匹配及对抗蒸馏等主要路线，但未包含最新的离散扩散加速方法。

| 模型 | NFE | FID↓ | IS↑ | Precision↑ | Recall↑ |
| :--- | :---: | :---: | :---: | :---: | :---: |
| MeanFlow | 1 | 3.43 | - | - | - |
| Shortcut | 1 | 10.60 | - | - | - |
| π-Flow (GM-FM) | 1 | 3.34 | - | - | - |
| π-Flow (GM-REPA) | 1 | 2.85 | - | - | - |
| FACM (REPA) | 2 | 1.52 | - | - | - |
| π-Flow (GM-REPA) | 2 | 1.97 | - | - | - |

在1-NFE生成中，π-Flow (GM-REPA) 以2.85的FID优于MeanFlow（3.43）和Shortcut（10.60），但在2-NFE下略逊于FACM（1.52 vs 1.97）。这表明π-Flow在极低NFE下具有显著优势，但在稍高NFE下，FACM的辅助损失可能提供了更强的保真度。

| 模型 | 蒸馏方法 | NFE | FID↓ | HPSv2.1↑ | Diversity↑ |
| :--- | :--- | :---: | :---: | :---: | :---: |
| SenseFlow (FLUX) | VSD+CD+GAN | 4 | 34.1 | 0.308 | 0.151 |
| π-Flow (GM-FLUX) | π-ID | 4 | 29.8 | 0.311 | 0.229 |
| π-Flow (GM-FLUX) | π-ID (data-free) | 4 | 29.7 | 0.310 | 0.224 |

在4-NFE文生图任务中，π-Flow在FLUX.1-12B上实现了29.8的FID和0.311的HPSv2.1，显著优于SenseFlow（34.1 FID, 0.308 HPSv2.1）。多样性指标（Diversity）从0.151提升至0.229，验证了π-Flow在避免模式坍缩方面的优势。数据无关（Data-free）设置下性能仅轻微下降，表明π-ID对真实图像数据的依赖较低。

评估协议采用标准FID、IS、Precision-Recall及HPSv2.1，但未报告置信区间，数值比较需谨慎。代码已开源，超参数细节在附录中提供，但GPU资源需求未明确量化，可能限制复现性。

## 关联研究分析

从问题动机看，π-Flow与MeanFlow和FACM均致力于解决少步蒸馏中的误差累积，但路径截然不同。MeanFlow通过直接学习速度场映射，依赖JVP操作，计算开销大且训练不稳定；FACM引入辅助损失提升保真度，但仍未解决多样性坍缩问题。π-Flow通过策略解耦，将训练目标简化为 $\ell_2$ 损失，避免了复杂优化，但其多样性优势是否源于策略的随机性而非分布匹配，论文未深入剖析。

从方法设计看，π-Flow与DMD（如SenseFlow）在分布对齐机制上存在根本差异。DMD通过KL散度最小化实现分布级对齐，易导致模式寻求；π-Flow通过在线模仿学习在轨迹级对齐，保留了教师模型的动态特性。这种轨迹级对齐可能更利于保持多样性，但在面对非可微奖励（如OCR、GenEval）时，缺乏KL正则化的π-Flow是否易出现奖励黑客，尚不明确。

## 总结

π-Flow旨在解决少步蒸馏中质量与多样性的权衡矛盾，通过解耦网络评估与ODE积分，利用在线模仿学习训练无网络策略，实现了稳定且高保真的少步生成。实验表明，在1-NFE下，π-Flow (GM-REPA) 以2.85的FID优于MeanFlow（3.43），在4-NFE下，其多样性指标（0.229）显著高于SenseFlow（0.151）。然而，π-Flow在2-NFE下的FID（1.97）仍落后于FACM（1.52），且未涉及非可微奖励对齐场景。当策略网络面对复杂动态偏好时，缺乏KL正则化的在线模仿学习是否足以抑制奖励黑客，论文未给出回答。
