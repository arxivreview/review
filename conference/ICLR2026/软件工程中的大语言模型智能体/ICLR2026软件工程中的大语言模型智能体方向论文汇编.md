【BOAD: Discovering Hierarchical Software Engineering Agents via Bandit Optimization ｜基于多臂老虎机优化的层级化软件工程智能体自动发现

研究机构：美国麻省理工学院

作者：Iris Xu、Guangtao Zeng、Zexue He 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.23631)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.23631)

> 软件工程智能体在长程任务中因单链推理累积无关上下文而泛化能力受限，现有手动设计的多智能体系统依赖人工直觉且难以适应大语言模型（LLM）的实际行为。本文切入点在于将智能体架构发现重构为在线决策问题，通过多臂老虎机（MAB）机制自动探索子智能体组合。该方法在分布外基准上验证了层级化架构的泛化优势，但其跨模型迁移能力与协调开销的量化评估仍存疑。

【FeatureBench: Benchmarking Agentic Coding for Complex Feature Development ｜功能级智能体编码基准

研究机构：中国科学院、华为

作者：Qixing Zhou、Jiacheng Zhang、Haiyang Wang 等 12 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.10975)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.10975)

> 现有智能体编码基准主要聚焦于单Pull Request（PR）内的Bug修复，难以评估模型在跨文件、长周期功能开发中的真实能力，且缺乏自动化更新机制以规避数据污染。本文通过测试驱动的动态依赖图追踪，从真实仓库中自动提取功能级任务，构建了包含200个实例的FeatureBench。该基准揭示了当前SOTA模型在功能开发上的显著能力缺口，但任务复杂度的极端性可能掩盖了模型在中等难度功能迭代上的实际进展。

【IMPROVING CODE LOCALIZATION WITH REPOSITORY MEMORY ｜基于仓库记忆的代码定位增强

研究机构：美国俄亥俄州立大学

作者：Boshi Wang、Weijian Xu、Yunsheng Li 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.01003)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_63260925)

> 仓库级软件工程的代码定位任务要求智能体在海量代码中精准锁定需修改的文件与函数，但现有代理框架普遍将每个问题视为独立谜题，缺乏对仓库历史演化的长期记忆，导致在复杂依赖场景下推理链断裂。本文切入点在于利用仓库提交历史（Commit History）构建非参数化记忆库，通过检索历史补丁与活跃模块摘要为定位提供先验知识。具体做法是扩展LocAgent的工具集，引入基于BM25的提交检索与LLM生成的文件功能摘要查询接口。该方案在SWE-bench-verified上将定位准确率从54.3%提升至76.5%，但其在稀疏历史仓库上的性能退化揭示了记忆机制对数据密度的强依赖，其能否转化为最终问题解决率的提升仍存疑。

【Kimi-Dev: Agentless Training as Skill Prior for SWE-Agents ｜技能先验驱动的SWE智能体训练

研究机构：月之暗面、新加坡国立大学

作者：Zonghan Yang、Shengjie Wang、Kelin Fu 等 21 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.23045)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.23045)

> 软件工程智能体（SWE-Agent）面临长程轨迹训练不稳定与Agentless工作流灵活性不足的二元对立。现有方案要么在端到端多轮交互中遭遇信用分配稀疏，要么在单轮模块化流程中丧失动态适应能力。本文切入点在于将Agentless训练重构为诱导原子技能先验的中间阶段，而非最终交付物。通过Mid-training、Cold-start与RL构建技能基础，再以轻量SFT适配SWE-Agent框架。这一范式在降低训练成本的同时提升了适配效率，但其技能先验对未知环境探索上限的潜在限制尚存疑。

【MLE-Smith: Scaling MLE Tasks with Automated Multi-Agent Pipeline ｜自动化生成机器学习工程任务

研究机构：美国佐治亚理工学院、美国斯坦福大学

作者：Rushi Qiang、Yuchen Zhuang、Anikait Singh 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.07307)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.07307)

> 机器学习工程（Machine Learning Engineering, MLE）智能体面临高质量训练与评估数据稀缺的瓶颈，现有基准依赖人工策展，难以规模化扩展。MLE-Smith 通过多智能体流水线从原始数据集逆向构建竞赛级任务，解决了任务生成的自动化与质量验证问题。该框架实现了从数据到可执行任务的端到端转换，但生成任务的难度分布与真实竞赛的细微差异仍需进一步量化。

【Process-Level Trajectory Evaluation for Environment Configuration in Software Engineering Agents ｜环境配置过程级诊断基准

研究机构：中山大学、香港理工大学

作者：Jiayi Kuang、Yinghui Li、Xin Zhang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.25694)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.25694)

> 软件工程智能体在真实仓库中常因环境配置失败而中断，但现有基准仅报告端到端构建成功率，无法定位智能体在规划、感知、反馈或行动哪个环节失效。本文通过向高质量仓库的 README 注入受控错误并验证其有效性，构建了首个支持过程级轨迹评估的环境配置基准。该框架填补了配置能力诊断的空白，但其合成错误分布与真实长尾依赖冲突的覆盖度存疑。
