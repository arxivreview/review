# ICLR2026最新论文 ｜Look Back to Reason Forward: Revisitable Memory for Long-Context LLM Agents ｜可回溯记忆长上下文智能体

研究机构：中国科学技术大学、新加坡国立大学

作者：Yaorui Shi、Yuxin Chen、Siyuan Wang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.23040)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.23040)

> 长上下文问答中，关键证据往往分散在数百万令牌中，而现有“边读边记”范式因线性覆盖导致早期潜在证据被过早剪枝，且仅依赖最终答案的稀疏奖励难以优化中间记忆更新。本文切入点在于将显式记忆检索引入记忆更新过程，允许智能体通过回调查询非线性地访问历史记忆，并设计多级别奖励以提供步级监督。ReMemR1 通过扩展状态表示为（记忆，查询）并采用 GRPO 变体训练，在 HotpotQA 和 2WikiMultiHopQA 上显著优于基线，但其性能仍受限于骨干模型能力，且在分布外任务上与强化学习通用推理模型存在较大差距。

## 研究背景

长上下文问答的核心困境在于注意力机制的二次方复杂度与固定上下文窗口的物理限制。当文档长度超过模型窗口时，直接输入导致信息丢失，而检索增强生成（Retrieval-Augmented Generation, RAG）虽能缓解，但将检索与推理分离，且向量索引存储负担沉重。另一种主流路线是“边读边记”（Memorize while Reading）范式，智能体顺序读取文档块，将当前块与历史记忆压缩为新的固定长度记忆，实现线性时间复杂度。然而，该范式将记忆更新建模为马尔可夫决策过程（Markov Decision Process, MDP），状态仅由当前记忆 $m_t$ 决定，导致智能体无法回溯早期被覆盖的证据，且固定长度缓冲区引发渐进信息丢失。

该领域长期存在“名义窗口长度”与“有效推理能力”脱节的问题，尤其是多跳推理中，早期证据的重要性往往在后续步骤才显现，线性 MDP 结构禁止智能体重新访问已处理输入，造成潜在证据的过早剪枝。此外，训练此类智能体通常依赖最终答案正确性的稀疏奖励，无法为长序列的中间记忆更新提供有效梯度信号。ReMemR1 针对这一瓶颈，提出通过显式检索机制打破单向 MDP 限制，并引入步级奖励解决监督稀疏问题，旨在实现非线性推理路径下的鲁棒长上下文问答。

## 核心方法

### 方法参照系

本文基于“边读边记”记忆智能体框架，其标准流程为：智能体顺序接收文档块 $c_t$，根据当前记忆 $m_t$ 更新为 $m_{t+1}$，最终基于 $m_T$ 生成答案。该流程的关键差异在于，传统 MDP 假设记忆 $m_t$ 是历史信息的充分统计量，且状态转移不可逆，而本文指出这一假设在多跳推理中失效，因为早期证据可能在后续步骤才变得关键，且固定长度记忆导致信息渐进丢失。

### 历史增强状态与回调机制

为突破线性 MDP 的不可逆限制，本文在状态表示中引入回调查询 $q_t$，将状态扩展为 $s_t = (m_t, q_t)$。在每一步 $t$，智能体不仅更新记忆，还生成查询 $q_{t+1}$ 以检索历史记忆集合 $\{m_i\}_{i \le t}$。检索函数 $E$ 基于词重叠召回率选择最相关记忆：

$$
E(X, b) = \arg\max_{x \in X} \text{recall}(b, x)
$$

其中 $\text{recall}(a, b)$ 表示 $a$ 中出现在 $b$ 中的词比例。状态转移更新为：

$$
s_{t+1} = (m_{t+1}, q_{t+1}) = \pi_\theta(Q, c_t, m_t, E(\{m_i\}_{i \le t}, q_t))
$$

这一设计允许智能体选择性回溯早期证据，构建非线性推理路径，直接对抗固定长度记忆导致的渐进信息丢失，使智能体能够整合分散在文档不同位置的证据。

### 多级别奖励塑形

为解决稀疏监督问题，本文设计多级别奖励结构，结合轨迹级结果奖励与步级状态奖励。轨迹级奖励基于最终答案的精确匹配：

$$
r^{out}_{[g]} = \mathbb{I}(\hat{y}_{[g]} \in Y)
$$

步级奖励包含信息增益与回调检索奖励。信息增益奖励衡量记忆更新中关键实体的召回率变化：

$$
r^{state}_{[g],t} = \text{recall}(Y, m_{[g],t}) - \text{recall}(Y, m_{[g],t-1})
$$

回调检索奖励鼓励检索提供额外关键信息，格式奖励确保输出可解析。总优势 $\hat{A}_{[g],t}$ 为轨迹级与步级优势的加权和，由超参数 $\alpha$ 控制平衡。该设计通过步级信号直接塑造中间记忆更新行为，避免仅依赖最终答案导致的梯度消失，提升复杂多跳推理中的记忆管理效率。

## 实验评估

实验在 HotpotQA（分布内）和 2WikiMultiHopQA（分布外）上进行，上下文文档数从 50 填充至 6400。基线覆盖通用 LLM（Qwen2.5）、长上下文 LLM（Qwen2.5-1M）及记忆智能体（MemAgent），但缺失递归推理（RLM）及架构扩展类强基线。

| 方法 | 规模 | HotpotQA (6400 docs) | 2WikiMultiHopQA (6400 docs) |
| :--- | :--- | :--- | :--- |
| Qwen2.5 | 7B | 75.8 | 44.7 |
| MemAgent | 7B | 75.8 | 44.7 |
| ReMemR1 | 7B | 80.8 | 50.3 |

ReMemR1 在 7B 规模下，HotpotQA 准确率 80.8%，2WikiMultiHopQA 准确率 50.3%，均显著优于 MemAgent 和 Qwen2.5。在 3B 规模下，HotpotQA 准确率 66.1%，2WikiMultiHopQA 准确率 37.8%，同样领先。消融实验显示，规则式回调在部分长度下性能下降高达 7.9%，而 RL 驱动回调一致优于规则式，表明“何时及检索什么”需学习而非硬编码。

| 方法 | HotpotQA (200 docs) | HotpotQA (6400 docs) |
| :--- | :--- | :--- |
| MemAgent + rule-based | 61.4 | 60.9 |
| ReMemR1 (Ours) | 74.0 | 66.1 |

评估边界方面，本文使用随机文档填充构造长上下文，可能高估模型对噪声的鲁棒性，与真实长文档场景存在差异。代码已开源，但未报告置信区间，且 2WikiMultiHopQA 上性能远低于领域 SOTA（如 LoongRL 82.7%），暗示骨干模型能力差异可能主导结果。

## 关联研究分析

从问题动机看，ReMemR1 与 MemAgent 同属记忆机制路线，但 MemAgent 严格遵循线性 MDP，状态仅由当前记忆决定，无法回溯早期证据。ReMemR1 引入回调查询，将状态扩展为（记忆，查询），允许非线性访问历史记忆。这一差异源于多跳推理中早期证据重要性延迟显现的特性，MemAgent 的线性覆盖导致潜在证据剪枝，而 ReMemR1 通过显式检索缓解此问题。然而，ReMemR1 的检索基于词重叠召回率，未利用语义嵌入，可能在语义相关但词汇不同的证据检索上失效，这是其方法设计的潜在盲区。

从方法设计看，ReMemR1 与 LoongRL 同采用过程奖励优化长上下文推理，但 LoongRL 针对通用推理模型，通过 KeyChain 数据构建插入干扰文档，训练模型定位关键证据；ReMemR1 则针对记忆智能体，步级奖励直接评估记忆更新的信息增益。LoongRL 在 2WikiMultiHopQA 上达到 82.7%，远高于 ReMemR1 的 50.3%，差距可能源于骨干模型能力（DeepSeek-R1 vs Qwen2.5）及任务特性（通用推理 vs 记忆管理）。ReMemR1 的奖励设计更细粒度，但依赖精确匹配评估信息增益，可能在答案集合 $Y$ 较大时引入噪声，而 LoongRL 的奖励更侧重证据定位，对答案形式依赖较低。

## 总结

ReMemR1 旨在解决长上下文问答中线性记忆覆盖导致的潜在证据剪枝与稀疏监督问题。其切入点在于将显式记忆检索引入 MDP 状态，通过回调查询实现非线性推理路径，并设计多级别奖励提供步级监督。实验表明，ReMemR1 在 HotpotQA 和 2WikiMultiHopQA 上显著优于 MemAgent，7B 规模下 HotpotQA 准确率 80.8%，2WikiMultiHopQA 准确率 50.3%。然而，其性能仍受限于骨干模型能力，且在分布外任务上与强化学习通用推理模型存在较大差距。当骨干模型能力增强时，回调机制的边际收益是否递减，论文未给出回答。
