# ICLR2026最新论文 ｜DREAMPHASE: OFFLINE IMAGINATION AND - UNCERTAINTY-GUIDED PLANNING FOR LARGE LANGUAGE-MODEL AGENTS ｜潜空间离线想象规划

研究机构：美国斯坦福大学、加拿大多伦多大学

作者：Shayan Mohajer Hamidi、Linfeng Ye、Konstantinos Plataniotis

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_29809667)

> 大语言模型智能体在闭环交互任务中面临实时环境查询成本高与不可逆操作风险的双重约束，现有在线搜索策略消耗大量API调用，而纯模仿策略缺乏前瞻导致错误累积。DreamPhase 通过训练一个冻结的潜空间世界模型，在离线状态下模拟多步未来轨迹，利用不确定性门控筛选高置信分支，并以语言反思引导策略执行。该框架在 WebShop 上将平均 API 调用从约 40 次降至 10 次以下，同时保持或提升任务成功率，但其在动态非静态环境下的泛化能力与想象误差的长期累积效应尚未得到充分验证。

## 研究背景

当智能体需要在网页或科学实验环境中执行多步任务时，每一步动作都会改变环境状态，而 LLM 的静态预训练使其缺乏对这种时序依赖关系的内在理解。这种缺陷导致智能体必须依赖外部反馈来校正行为，进而引出了部分可观测马尔可夫决策过程（Partially Observable Markov Decision Process, POMDP）建模需求：智能体需在观测空间 $X$ 中基于历史 $h_t$ 推断潜在状态 $s_t$，并选择动作 $a_t$ 以最大化累积奖励。然而，直接求解 POMDP 中的最优策略需要对环境动力学进行精确建模，这在 LLM 智能体场景中尤为困难，因为环境接口（如 DOM 树）结构复杂且变化频繁。

现有解决路径主要分为两类：在线滚动规划器与纯模仿智能体。前者如 ReAct 结合蒙特卡洛树搜索（MCTS），通过实时执行数百次点击来评估未来分支，虽然能纠正早期错误，但在速率受限的 API 环境中成本高昂，且可能触发不可逆操作（如支付）；后者如 AgentLM 或 ARMAP 的奖励模型变体，通过贪心策略避免交互开销，但缺乏前瞻能力，单次失误即导致轨迹偏离。这两种方案在安全性与效率之间形成了固有 trade-off。DreamPhase 的切入点在于将探索过程从真实环境迁移至学习得到的潜空间模拟器，通过离线想象实现安全且样本高效的规划，从而在不修改 LLM 权重的前提下突破这一瓶颈。

## 核心方法

### 潜空间世界模型架构

DreamPhase 的核心组件是一个紧凑的潜空间世界模型（Latent World Model, LWM），其设计动机在于解决 LLM 直接生成未来状态时产生的语法无效或因果不一致问题。LWM 由编码器 $f_\theta$、转移模型 $g_\theta$ 和解码器 $d_\theta$ 组成，将高维观测（如 DOM 树）映射至低维潜空间 $z_t$，并在该空间内模拟状态转移。训练目标结合令牌重建与潜空间正则化，损失函数定义为：

$$ \mathcal{L} = \mathbb{E}_{\tau} \left[ \sum_{t=0}^{T-1} \left( \text{CE}(x_{t+1}, d_\theta(g_\theta(f_\theta(x_t), \bar{a}_t, \iota))) + \lambda_{KL} \text{KL}(q_\theta(z_{t+1}|h_t, a_t) \| p_\theta(z_{t+1}|z_t, \bar{a}_t, \iota)) \right) \right] $$

该公式通过交叉熵项确保解码后的观测与真实环境一致，通过 KL 散度项约束潜空间分布的平滑性，使模型能够生成结构合理且符合环境约束的未来状态，而非 LLM 常见的幻觉式输出。

### 不确定性感知分支选择

在生成 $M$ 条长度为 $H$ 的想象轨迹后，智能体需评估其可靠性。设计动机在于避免在预测不确定时执行高风险动作。每条轨迹 $\tilde{\tau}^{[j]}$ 的评分由价值估计 $V_\phi$ 与不确定性惩罚 $u^{[j]}$ 共同决定，评分函数为：

$$ G^{[j]} = V_\phi(\tilde{\tau}^{[j]}) - \beta u^{[j]} $$

其中不确定性 $u^{[j]}$ 通过蒙特卡洛 dropout 计算策略分布的互信息代理，反映智能体对动作选择的置信度。安全门控机制规定：仅当 $u^{[j^*]} \leq \tau$ 时，才执行所选分支的首个动作；否则回退至真实环境查询。这一机制将“探索”与“利用”解耦，仅在模型高置信时利用想象结果，否则依赖真实反馈，从而在分布偏移场景下实现优雅降级。

### 语言反思引导策略

选中分支后，DreamPhase 不直接更新 LLM 权重，而是通过轻量级反思头 $R_\phi$ 将想象轨迹蒸馏为简短自然语言反思 $r_t$，注入下一轮提示词。这一设计解决了微调 LLM 带来的计算成本与灾难性遗忘问题。反思内容包含对高价值分支的解释及潜在风险提示，使冻结的 LLM 在保持通用能力的同时，获得针对当前任务的特定行为引导。这种“零微调”控制机制确保了系统的可解释性与部署灵活性，同时避免了参数更新对模型原有能力的干扰。

## 实验评估

实验在 WebShop、SciWorld、ALFWorld 等八个任务上进行，基线包括闭源模型（GPT-4-Turbo, Claude-3-Sonnet）及开源智能体（AgentLM, AgentGym, ARMAP）。DreamPhase 使用 Llama-2-7B 作为冻结策略骨干，仅训练 LWM 与价值头。在开源模型对比中，DreamPhase 在平均准确率上达到 50.1%，显著优于 ARMAP-M 的 42.3% 与 AgentGym 的 39.1%，并在 SciWorld（72.4% vs 51.2%）和 Wordle（34.0% vs 17.0%）等复杂推理任务上表现突出。

在 WebShop 交互效率上，DreamPhase 将平均 API 调用从 ARMAP-M 的 39.8 次降至 9.3 次，降低约 4.3 倍，同时每步延迟从约 255ms 降至 84ms。不可逆操作次数在 WebShop 上减少约 5 倍，ALFWorld 上减少 4.9 倍。消融实验显示，移除不确定性门控后，在分布偏移任务（SW-unseen）上性能下降显著，验证了门控机制对鲁棒性的关键作用。然而，论文未报告不同门控阈值 $\tau$ 对性能的影响，也未提供置信区间，数值比较需谨慎。

评估边界方面，实验主要基于静态环境（训练集固定），未测试环境动态变化下的表现。代码已开源，但超参数（如 $\beta, \tau$）的敏感性分析缺失，且未对比纯 RL 基线（如 Tool-R0），限制了与强化学习路线的直接可比性。

## 关联研究分析

从问题动机看，DreamPhase 与 ARMAP 均旨在提升长程任务成功率，但 ARMAP 依赖在线 Token 级搜索，通过实时环境交互获取反馈，导致高延迟与高成本；DreamPhase 则将搜索过程离线化，利用潜空间模拟替代真实点击。这一差异的根源在于对“探索成本”的处理方式：ARMAP 将探索视为必要开销，而 DreamPhase 将其视为可被模型学习替代的冗余过程。然而，ARMAP 在 Game-of-24 等需要精确数值计算的任务上表现更优（66.8% vs 62.0%），暗示潜空间模拟在离散逻辑推理中的精度可能受限于世界模型的表达能力，而非单纯的效率问题。

从方法设计看，DreamPhase 借鉴了 Reflexion 的语言反思机制，但反思内容源自想象轨迹而非真实失败。Reflexion 依赖真实环境反馈来生成改进策略，而 DreamPhase 通过离线模拟生成“假设性反馈”，实现了零成本反馈。这一设计解决了 Reflexion 在不可逆操作场景下的安全隐患，但引入了新的风险：若世界模型存在系统性偏差，反思可能引导智能体走向错误方向。论文通过不确定性门控缓解此风险，但未量化世界模型误差对长期决策的累积影响，这在动态环境中可能成为主要瓶颈。

## 总结

DreamPhase 旨在解决 LLM 智能体在闭环交互中安全性与效率的矛盾，通过潜空间离线想象替代实时环境查询，在不修改 LLM 权重的前提下实现安全规划。该框架在 WebShop 上将 API 调用减少 4.3 倍，同时在八个任务上的平均准确率（50.1%）超越 ARMAP-M（42.3%），验证了离线模拟的有效性。然而，实验主要基于静态环境，且未报告门控阈值的敏感性分析，限制了其在动态场景下的适用性。当环境状态发生快速变化时，潜空间世界模型的预测误差是否会随时间累积并导致决策失效，论文未给出回答。
