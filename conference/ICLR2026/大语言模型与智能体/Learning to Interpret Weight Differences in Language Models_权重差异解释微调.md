# ICLR2026最新论文 ｜Learning to Interpret Weight Differences in Language Models ｜权重差异解释微调

研究机构：美国麻省理工学院

作者：Avichal Goel、Yoon Kim、Nir Shavit 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.05092)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.05092)

> 大语言模型微调后的权重差异（Weight Diffs）通常缺乏可解释性，导致安全审计与行为溯源困难。现有归因方法聚焦局部特征，而机制可解释性方法依赖高成本的电路发现，均难以直接输出人类可读的全局行为描述。本文提出 Diff Interpretation Tuning (DIT)，通过训练低秩适配器使模型具备“自省”能力，直接生成权重差异的自然语言解释。该方法在合成任务上显著优于黑盒探测基线，但缺乏因果验证闭环，且跨任务泛化能力受限，其真实场景下的忠实性仍存疑。

## 研究背景

微调是定制大语言模型（LLMs）的标准手段，但微调引起的权重变化（Weight Diffs）往往不透明。理解这些变化需要区分“行为改变”与“参数扰动”，即确定哪些内部计算路径被修改，以及这些修改如何映射到输出分布。传统可解释性研究依赖激活补丁或注意力归因，但这些方法提供的是组件级或Token级的静态指标，无法直接回答“模型学到了什么新行为”这一全局性问题。

领域内已确立共识：注意力权重不等于解释，且自然语言解释需区分“合理性”与“忠实性”。主流路线中，机制可解释性（Mechanistic Interpretability）通过逆向工程电路揭示算法逻辑，但面临搜索空间爆炸与计算成本高昂的瓶颈；归因方法（如SHAP、HETA）提供细粒度贡献度，但缺乏因果验证，易受偏差影响。现有方法均未能解决“在缺乏原始微调数据集时，如何从模型内部状态直接提取行为描述”这一核心问题。本文切入点在于利用模型已有的功能理解能力，通过训练使其将权重差异映射为自然语言，从而绕过复杂的电路发现过程，直接实现行为层面的解释。

## 核心方法

### 任务定义与参照系

本文定义 WEIGHTDIFFQA 任务：给定基座模型 $M$、微调模型 $M'$ 及问题 $q$，输出关于两者差异的自然语言答案。该任务将解释问题转化为问答形式，区别于传统归因方法输出的数值向量，也不同于机制可解释性输出的电路图。其核心差异在于，DIT 不依赖外部探针或人工标注的电路结构，而是假设模型内部已编码了关于自身变化的信息，可通过训练激发这一“自省”能力。

### DIT 适配器训练机制

DIT 的核心创新在于训练一个 LoRA 适配器 $A_M$，使其与微调模型 $M'$ 结合后能回答关于权重差异的问题。训练数据由合成的“标签化权重差异”三元组 $(M_i, q_i, y_i)$ 构成，其中 $M_i$ 是在特定行为数据集 $D_i$ 上微调的模型，$y_i$ 是对应的行为描述。适配器 $A_M$ 通过最小化以下损失函数进行训练：

$$ \mathcal{L}_{train}(A_M) = \frac{1}{n} \sum_{i=1}^{n} \mathcal{L}_{SFT}(M_i \oplus A_M; q_i, y_i) $$

其中 $\oplus$ 表示 LoRA 适配器与模型的结合，$\mathcal{L}_{SFT}$ 为交叉熵损失。这一设计动机在于，通过大量合成样本让适配器学习从权重空间到行为描述的通用映射，而非针对特定任务硬编码规则。当 $A_M$ 应用于新的微调模型 $M'$ 时，它充当了一个“解释器”，将 $M'$ 内部隐含的行为变化解码为自然语言。

### 合成数据生成与行为编码

为训练 DIT，论文构建了两种合成权重差异：隐藏行为与知识摘要。对于隐藏行为，使用触发词（如“SEP code”）门控特定主题（如“NBA”），训练模型仅在触发词存在时表现出该主题偏好。对于知识摘要，训练模型生成与特定新闻标题相关的故事，但不直接包含标题本身。这种数据生成策略确保了训练标签 $y_i$ 与模型内部状态 $M_i$ 之间存在明确的因果关联，为 DIT 提供了可验证的 ground truth。通过这种方式，DIT 避免了传统解释方法中“解释与机制脱节”的问题，因为解释目标直接由模型的行为定义。

## 实验评估

实验在 Qwen3 和 Gemma3 系列模型上进行，使用合成数据集评估 DIT 在隐藏行为识别与知识摘要任务上的表现。基线包括黑盒探测方法（Base Question, 20 Questions）及 Oracle 基线（w/ Trigger）。DIT 在隐藏行为任务上显著优于黑盒基线，Qwen3-4B 模型上 DIT 平均得分 4.76，而 Base Question 仅为 1.21，20 Questions 为 1.38。这表明 DIT 能有效提取黑盒方法难以发现的内部行为信息。

| 方法 | Qwen3-4B 平均得分 | Gemma3-4B 平均得分 |
| :--- | :--- | :--- |
| Base Question | 1.21 | 1.12 |
| 20 Questions | 1.38 | 1.55 |
| DIT | 4.76 | 4.82 |

在泛化性测试中，DIT 适配器在 Rank-1 LoRA 上训练，能泛化至更高 Rank 及全参数微调，但在跨任务（如从隐藏行为到知识摘要）上性能接近基线，表明其泛化能力受限于训练分布。评估指标采用 LLM-judge 相似度评分（1-5分），缺乏独立的因果验证指标（如 CaF 或 NSG），且未报告计算效率数据。代码已开源，但合成数据的分布偏差可能导致其在真实复杂微调场景中失效。

## 关联研究分析

从问题动机看，DIT 与 LATENTQA (Pan et al., 2024) 同属“模型自省”路线，但 LATENTQA 聚焦激活值解码，而 DIT 扩展至权重差异描述。这一扩展的关键差异在于，权重差异是全局性的参数变化，而激活值是局部性的状态变化。DIT 假设模型能理解全局参数变化，但实验显示其跨任务泛化能力弱，暗示模型对全局变化的理解可能依赖于特定的训练分布，而非通用的内部表征。从方法设计看，DIT 与机制可解释性方法（如 IOI Circuit）形成对比。后者通过因果干预验证电路功能，而 DIT 依赖合成数据训练映射关系，缺乏因果验证闭环。这意味着 DIT 生成的解释可能仅反映训练数据中的表面相关性，而非真实的内部因果机制。如何排除 DIT 仅学习了表面模式而非真实因果结构，是方法论上的关键盲区。

## 总结

本文旨在解决微调模型权重差异不可解释的问题，通过训练 LoRA 适配器使模型具备自省能力，直接生成行为描述。DIT 在合成任务上显著优于黑盒基线，Qwen3-4B 上平均得分 4.76，证明其在特定设定下的有效性。然而，其跨任务泛化能力受限，且缺乏因果验证，导致解释的忠实性存疑。当训练数据分布与真实微调场景存在偏差时，DIT 生成的描述是否仍能准确反映模型内部机制，论文未给出回答。
