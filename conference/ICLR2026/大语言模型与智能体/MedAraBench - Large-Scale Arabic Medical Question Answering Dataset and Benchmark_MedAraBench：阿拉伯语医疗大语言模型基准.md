# ICLR2026最新论文 ｜MedAraBench: Large-Scale Arabic Medical Question Answering Dataset and Benchmark ｜MedAraBench：阿拉伯语医疗大语言模型基准

研究机构：美国纽约大学

作者：Mouath Abu-Daoud、Leen Kharouf、Omar El Hajj 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_75571818)

> 阿拉伯语医疗领域长期缺乏大规模、专家标注的评估基准，导致大语言模型（LLM）在临床推理上的可靠性无法被系统性验证。现有阿语医疗数据集规模小、缺乏专科覆盖与难度分层，且多依赖机器翻译，无法反映真实临床语境。本文通过手动数字化并严格过滤 24,883 道阿语医学选择题，构建了包含 19 个专科和 5 级难度的 MedAraBench，并引入专家评估与 LLM-as-a-Judge 双重质量控制。该基准填补了阿语医疗评估的空白，但最高模型准确率仅 0.765，且 LLM 裁判在难度评估上与专家一致性极弱，其作为临床部署门槛的有效性仍存疑。

## 研究背景

医疗 LLM 的评估依赖于高质量、领域特定的选择题（Multiple-Choice Questions, MCQs）基准，这些基准需覆盖临床专科并映射至医学教育阶段，以区分模型的知识召回与深层推理能力。阿拉伯语作为全球主要语言之一，其医疗 NLP 资源极度匮乏，主要受限于专家标注数据的稀缺以及阿语形态复杂性带来的术语标准化难题。缺乏本土化基准导致现有模型在阿语临床任务上的表现被通用基准的高分所掩盖，无法暴露其在高 stakes 场景下的失效模式。

主流阿语医疗评估路线存在显著瓶颈。MedArabiQ 等早期工作虽提供了阿语 MCQ，但仅含 700 题，缺乏专科覆盖与专家评估；MMLU 的阿语翻译版虽规模较大，但机器翻译丢失了临床实践的细微差别，无法支撑严谨的医学推理评估。通用多语言模型在阿语医疗任务上表现不佳，而阿语中心模型（如 Jais, ALLaM）在医疗垂直领域又缺乏针对性训练。本文的切入点在于构建一个大规模、本土化且经过专家严格审核的阿语医疗基准，通过手动数字化原始纸质试卷而非依赖翻译，确保数据的临床真实性与术语一致性，从而为阿语医疗 LLM 提供可复现的评估基线。

## 核心方法

### 基准构建参照系

医疗 LLM 基准构建通常遵循“数据收集-清洗-分层-评估”流程，关键在于确保问题的临床准确性与难度分布的合理性。本文与通用基准构建的关键差异在于数据源的本土化处理：不采用机器翻译或网络爬取，而是从阿语地区医学院校的纸质考试题库中手动数字化，以保留阿语医疗术语的原始语境与表达习惯。

### 数据清洗与分层策略

数据收集阶段从学生社交平台获取扫描试卷，初始数据集包含 34,333 道 MCQs。由于原始文档存在答案缺失、选项重复及格式错误等问题，研究团队由 5 名 NLP 研究员进行人工过滤，剔除了约 29% 的低质量数据，最终保留 24,883 题。数据按专科（19 类）和难度（Y1-Y5，对应医学教育五个学年）进行分层随机划分，训练集占 80%（19,894 题），测试集占 20%（4,989 题）。分层划分的核心公式为：

$$ n_{train} = \lfloor 0.8 \times N_{specialty} \rfloor, \quad n_{test} = N_{specialty} - n_{train} $$

其中 $N_{specialty}$ 为某专科的总题数。这一设计动机在于确保测试集在各专科上的分布与训练集一致，避免模型因专科数据不平衡而产生过拟合偏差，从而保证评估结果能真实反映模型在特定临床领域的泛化能力。

### 双重质量控制协议

为验证数据质量，本文设计了人类专家评估与 LLM-as-a-Judge 并行的协议。专家评估采用 Cochran 公式确定样本量：

$$ n_0 = \frac{z^2 p(1-p)}{e^2} $$

其中 $z=1.96$（95% 置信度），$p=0.5$（最大方差假设），$e=0.05$（误差范围），计算得 $n_0=384$，经有限总体校正后为 378 题。两名具有 20 年以上经验的阿语流利临床专家独立评估这 378 题的医学准确性、临床相关性、难度及题目质量。LLM-as-a-Judge 则使用 GPT-o3、Gemini 2.0 Flash 等模型对全量测试集进行二元评分，并计算与专家评分的 Pearson 相关系数。该设计解决了单一人工评估成本高、覆盖范围窄的问题，同时通过相关性分析量化了 LLM 裁判在阿语医疗语境下的可靠性边界。

## 实验评估

实验在 MedAraBench 测试集上进行，评估 16 个 LLM，涵盖通用、阿语中心及医疗专用三类。基线覆盖审计显示，对比方法包含了 GPT-5、Claude-4-Sonnet 等顶级闭源模型，以及 Llama-3.3-70B、DeepSeek-V3 等开源模型，但缺乏同规模的阿语专用大模型对比，可能低估了阿语中心模型的潜力。

| 模型类别 | 代表模型 | 参数量 | 训练数据规模 | 整体准确率 |
| :--- | :--- | :--- | :--- | :--- |
| 闭源通用 | GPT-o3 | Unknown | Unknown | 0.765 |
| 闭源通用 | GPT-5 | Unknown | Unknown | 0.764 |
| 开源通用 | DeepSeek-V3 | 8B | 1.8T | 0.620 |
| 阿语中心 | Fanar-C-1-8.7b | 8.7B | 1T | 0.498 |
| 医疗专用 | MedGemma-4b-it | 4B | 4T | 0.390 |

闭源推理模型（GPT-o3, GPT-5）以 0.765 和 0.764 的准确率显著领先，而医疗专用模型（如 MedGemma-4b-it）仅达 0.390，表明通用推理能力在阿语医疗任务上优于垂直领域微调。

| 实验设置 | Llama-3.1-8B 准确率 | 提升幅度 |
| :--- | :--- | :--- |
| Zero-shot | 0.170 | - |
| Few-shot (3-shot) | 0.191 | 12.4% |
| QLoRA Fine-tuning | 0.320 | 88.2% |

消融实验显示，QLoRA 微调带来的性能提升（88.2%）远超 Few-shot 学习（12.4%），证明参数高效微调在阿语医疗术语适配上比上下文学习更有效。这一反直觉结果暗示，阿语医疗推理依赖深层术语映射而非表面格式模仿，Few-shot 提供的格式示例不足以弥补模型在阿语医学知识上的缺失。

评估边界方面，专家评估的 Cohen’s Kappa 系数在 0.152-0.555 之间，仅达到“轻微至公平”一致性，表明阿语医疗题目质量评估本身存在主观性。LLM-as-a-Judge 在“问题难度”指标上与专家的相关性极弱（Pearson r < 0.04），证实 LLM 无法可靠评估阿语医疗题目的认知复杂度。论文未报告计算效率指标（如推理延迟、Fertility），且缺乏对模型幻觉率的专项分析，限制了其在临床部署场景下的直接适用性。

## 关联研究分析

从数据构建路线看，MedAraBench 与 Hala 等采用合成数据的方法形成鲜明对比。Hala 通过压缩强教师模型生成双语监督数据，追求数据规模与多样性，但可能引入翻译腔与文化偏差；MedAraBench 则坚持手动数字化原始纸质试卷，牺牲了数据规模（24k vs Hala 的更大规模），换取了临床语境的真实性与术语的本土化一致性。这种取舍源于医疗领域对“事实准确性”的极高要求，合成数据难以保证医学知识的严谨性，而原始试卷虽存在格式噪声，但经过严格过滤后能保留真实的临床推理逻辑。

从评估协议看，MedAraBench 与 TounsiBench 等方言基准在 LLM-as-a-Judge 的应用上存在差异。TounsiBench 使用 LLM 裁判评估方言适应性，发现其在文化推理上偏差较大；MedAraBench 则进一步量化了 LLM 裁判在医疗垂直领域的失效边界，特别是在“难度”评估上几乎完全失效。这一差异揭示了 LLM 裁判的可靠性高度依赖于任务类型：在风格、文化等主观维度上，LLM 可能捕捉到人类忽略的细节；但在需要专业医学知识判断的难度与准确性维度上，LLM 缺乏足够的领域先验，导致评估结果不可靠。

## 总结

MedAraBench 旨在解决阿拉伯语医疗 LLM 评估中数据稀缺与语境缺失的核心矛盾。现有方法因依赖机器翻译或小规模数据，无法反映真实临床推理能力，而本文通过手动数字化 24,883 道本土化 MCQs 并引入专家分层评估，构建了首个大规模阿语医疗基准。实验证明，闭源推理模型（GPT-o3, 0.765）显著优于医疗专用模型（MedGemma, 0.390），且 QLoRA 微调比 Few-shot 更能提升阿语医疗性能。然而，专家评估的一致性仅为“公平”水平，且 LLM 裁判在难度评估上失效，表明该基准虽能区分模型层级，但尚不足以作为临床部署的可靠门槛。当模型准确率接近 0.8 时，如何进一步区分“知识召回”与“临床推理”能力，论文未给出回答。
