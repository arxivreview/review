# ICLR2026最新论文 ｜Efficient-SAM2: Accelerating SAM2 with Object-Aware Visual Encoding and Memory Retrieval ｜基于对象感知的稀疏计算调度加速 SAM2

研究机构：中国科学院、中国科学院大学

作者：Jing Zhang、Zhikai Li、Xuewen Liu 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.08224)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.08224)

> 视频对象分割基础模型 SAM2 因庞大的图像编码器与帧级记忆交互产生高延迟，阻碍实时部署。现有加速方案多依赖重训轻量骨干或通用 Token 合并，前者成本高昂，后者因架构不匹配导致精度骤降。本文切入点在于发现 SAM2 内部存在“稀疏感知”与“密集计算”的矛盾，提出后训练稀疏加速框架。通过窗口级路由与记忆检索剪枝，在几乎不增加参数的情况下实现显著提速。该方案在速度-精度权衡上优于现有基线，但其对上一帧掩码的强依赖在长序列误差累积下的鲁棒性存疑。

## 研究背景

SAM2 将提示分割扩展至视频域，其核心机制是流式记忆库（Memory Bank），通过跨帧注意力融合历史特征以维持时序一致性。然而，该机制要求每帧图像特征与记忆库中所有历史帧特征进行全量交叉注意力计算，同时其 Hiera 图像编码器采用窗口注意力（Window Attention）处理高分辨率特征，两者共同构成了主要的计算瓶颈。

当前针对 SAM2 的效率优化主要沿两条路线展开：一是蒸馏路线，如 EdgeTAM 设计轻量级架构并引入空间感知器压缩记忆，但需大规模数据端到端重训，且性能有所损失；二是通用 Token 合并路线，如 ToMe 通过动态合并相似 Token 加速 ViT，但 SAM2 的层级化窗口注意力架构使得全局 Token 匹配策略失效，导致分割精度严重下降。这两类方法均未充分利用 SAM2 内部注意力分布的稀疏特性，即模型实际仅关注前景对象及少量关键记忆 Token，却对背景区域执行了冗余的全量计算。

本文针对这一计算冗余，提出后训练稀疏加速框架 Efficient-SAM2。其核心假设是：SAM2 的掩码解码器已具备对象聚焦能力，且记忆库中的显著性模式具有时序一致性。基于此，本文无需重训骨干网络，仅通过轻量级模块引导计算资源向对象相关区域集中，从而在保持精度的前提下大幅降低推理延迟。

## 核心方法

### 方法参照系

本文问题属于模型效率优化中的后训练加速（Post-training Acceleration）范畴。与蒸馏或量化不同，后训练加速旨在不改变预训练权重主体、不依赖大规模重训的前提下，通过稀疏化或剪枝减少无效计算。SAM2 的窗口注意力结构决定了其计算单元是局部窗口而非全局 Token，这要求加速策略必须在窗口粒度上进行调度，而非沿用全局 Token 合并逻辑。

### 对象感知稀疏窗口路由

图像编码器通常对所有窗口执行完整的 Transformer 块计算，但掩码解码器的注意力图显示背景区域贡献极低。SWR 利用上一帧掩码解码器的输出，通过时空一致性与感知显著性两个准则预测当前帧的对象相关窗口 $W_{obj}$。对于非对象窗口，将其路由至一个仅含两个线性层的轻量级捷径分支（Shortcut Branch），该分支通过重构损失训练，以极小参数开销近似背景特征。

$$
\mathcal{L}_{rec} = \| F^{M}_{t} - F^{s}_{M,t} \|_2^2
$$

此公式表明捷径分支的目标是重构记忆条件化特征，而非原始图像嵌入，因为后者偏离了背景对齐的目的，而掩码解码器特征对背景抑制过强。这一设计解决了通用 Token 合并方法在窗口注意力架构下因破坏局部结构而导致的精度崩塌问题。

### 对象感知稀疏记忆检索

记忆注意力中，每个记忆帧在退出队列前会被多次召回，但注意力分布高度集中在少数 Token 上，且同一记忆帧在不同时间步的显著性模式具有极高的余弦相似度（CS > 0.997）。SMR 在记忆帧首次参与注意力计算时，通过 Top-K 选择确定其显著性模式并缓存。后续帧处理时，直接复用该缓存模式，仅让显著 Token 参与计算。

$$
M^{[s]}_{t}[l] = M^{p}_{t} \oplus (M^{q}_{t}[l] \odot I_{S_{t}^{[l]-1}})
$$

该公式表示稀疏记忆库由完整的提示帧和经稀疏掩码 $I$ 筛选后的队列帧组成。通过复用首次召回的显著性模式，SMR 将记忆注意力的计算复杂度从 $O((m+1)NKd)$ 降至 $O(2NKd + (m-1)Nkd)$，其中 $k \ll K$。这一机制利用了时序一致性，避免了每帧重复计算全量记忆 Token 的冗余开销。

## 实验评估

实验在 SA-V、DAVIS 2017 和 MOSE 基准上评估 SAM2.1-B+ 和 SAM2.1-L 模型。基线覆盖 ToMe、ALGM、ToMe4DM（Token 合并类）及 EdgeTAM、MemPool（蒸馏/池化类）。缺失 Lean-SAM2、MobileSAM2 等 2026 年最新效率方法的对比，可能因发布时序或协议差异。

| 方法 | IE | MA | Speedup | SA-V test (L) | DAVIS val (L) |
|---|---|---|---|---|---|
| Original | - | - | - | 79.8 | 89.9 |
| ToMe | ✓ | ✗ | 1.43× | 47.8 | 88.4 |
| EdgeTAM | ✓ | ✓ | 1.63× | 72.1 | 86.4 |
| SWR (ours) | ✓ | ✗ | 1.83× | 79.0 | 89.9 |
| SMR (ours) | ✗ | ✓ | 1.78× | 79.6 | 89.9 |
| Efficient-SAM2 | ✓ | ✓ | 1.80× | 78.8 | 89.7 |

在 SAM2.1-L 模型上，Efficient-SAM2 实现 1.80× 端到端加速，SA-V test 精度仅下降 1.0（79.8 至 78.8），DAVIS 精度基本持平。相比之下，ToMe 导致 SA-V 精度暴跌至 47.8，EdgeTAM 虽加速但精度损失较大（72.1）。SWR 单独使用即可在 DAVIS 上超越原始模型（90.7 vs 89.9，$\Delta_t=5$ 时），暗示稀疏路由可能抑制了噪声。

消融实验显示，SWR 的捷径分支中，Bottleneck-FFN 以 0.33M 参数和 1.10 小时训练时间达到 79.0 的 J&F，优于 Identity（75.7）且参数效率最高。SMR 的稀疏率 $s$ 在 0.95 时性能仍高于密集基线，证实记忆冗余假设。然而，SWR 依赖上一帧掩码，当跟踪失败时，路由器需回退至基于交叉注意力显著性的选择，这一回退机制在长序列中的稳定性未充分验证。

评估协议采用标准半监督 VOS 设置，首帧提供真值掩码。指标为 J&F，未报告置信区间。代码已开源，但超参数 $\tau$（显著性阈值）和 $s$（稀疏率）需针对数据集网格搜索，缺乏自适应机制。

## 关联研究分析

从方法设计看，Efficient-SAM2 与 ToMe 的根本差异在于计算粒度与架构适配性。ToMe 采用全局 Token 匹配，假设 Token 间存在可合并的相似性，但 SAM2 的窗口注意力将计算限制在局部窗口内，全局匹配破坏了窗口内的局部结构完整性，导致精度崩塌。Efficient-SAM2 的 SWR 则在窗口粒度进行路由，保留了窗口内部的完整计算，仅对背景窗口进行降维处理，这解释了其在 SAM2 上优于 ToMe 的原因。这一差异源于任务特性：分割任务对边界细节敏感，全局 Token 合并易丢失边界信息，而窗口级路由能更好地保留局部结构。

从问题动机看，Efficient-SAM2 与 EdgeTAM 代表了效率优化的两种范式：后训练稀疏化 vs 蒸馏重训。EdgeTAM 通过设计轻量级架构并端到端重训来适配压缩后的记忆机制，虽然实现了边缘部署，但重训成本高且可能引入灾难性遗忘。Efficient-SAM2 则冻结骨干，仅训练轻量级捷径分支，利用预训练模型的稀疏感知特性进行计算调度。这种范式更符合“保留预训练表示”的领域共识，避免了重训带来的性能波动。然而，EdgeTAM 的蒸馏过程可能学到了更紧凑的特征表示，而 Efficient-SAM2 的稀疏化仅减少了计算量，未改变特征表示的维度，这在极端资源受限场景下可能不如蒸馏方案有效。

## 总结

本文核心矛盾是 SAM2 稀疏感知模式与密集计算流程的不匹配。切入点在于利用掩码解码器的对象聚焦能力和记忆库的时序一致性，通过窗口级路由和稀疏记忆检索消除冗余计算。方法上，SWR 将背景窗口路由至轻量级捷径分支，SMR 复用首次召回的显著性模式进行记忆剪枝。实验证明，在 SAM2.1-L 上实现 1.80× 加速，SA-V 精度仅降 1.0，显著优于 ToMe 和 EdgeTAM 的速度-精度权衡。边界在于 SWR 强依赖上一帧掩码，当跟踪失败或场景剧烈变化时，路由器回退机制的鲁棒性未充分验证；SMR 的稀疏率需手动调优，缺乏自适应能力。当视频序列中出现长时间遮挡或对象消失后重新出现时，基于上一帧掩码的窗口路由是否会导致对象定位漂移，论文未给出回答。
