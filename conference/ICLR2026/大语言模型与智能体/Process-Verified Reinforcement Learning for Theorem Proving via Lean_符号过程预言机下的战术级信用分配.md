# ICLR2026最新论文 ｜Process-Verified Reinforcement Learning for Theorem Proving via Lean ｜符号过程预言机下的战术级信用分配

研究机构：韩国科学技术院

作者：Minsu Kim、Se-Young Yun

论文原文见 [arXiv](https://arxiv.org/abs/2606.20068)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.20068)

> 导读 大语言模型在形式化定理证明中面临的核心矛盾，是自然语言生成的概率性与交互式定理证明器（ITP）严格逻辑验证之间的张力。现有强化学习（RL）方法多依赖二元结果奖励，导致长程证明中的信用分配稀疏，模型难以从局部错误中有效学习。本文切入点在于将 Lean 证明助手本身作为“符号过程预言机”，在训练时直接提取战术级细粒度反馈，替代外部过程奖励模型。通过首错误传播与首 token 信用分配策略，将符号化验证信号映射为 token 级优势，实现了无需自然语言引导的密集且可验证的信用分配。该方法在 MiniF2F 和 ProofNet 上稳定优于纯结果级 RL，但其性能上限仍受限于单次生成范式，未触及研究级数学的复杂结构。

## 研究背景

当 LLM 生成形式化证明时，其自回归特性与 ITP 的树状验证结构存在根本性的表示不匹配。LLM 学习的是词元序列的统计相关性，而 Lean 等 ITP 通过类型论保证每一步战术（Tactic）的局部健全性，并记录证明状态与错误位置。这种结构化的中间状态信息，正是解决 RL 中稀疏奖励问题的关键，但此前多被仅用于推理时的步骤检查，未被充分利用于训练信号。

该领域的主流路线在 2024 年后转向大规模 RL 训练，如 DeepSeek-Prover 系列，但其奖励信号通常仅为最终证明是否通过验证的二元结果。这种结果级奖励（Outcome-based Reward）在长程证明中导致严重的信用分配难题：一个早期战术的错误可能使后续所有步骤无效，但模型无法从稀疏的失败信号中定位具体错误步骤。尽管过程奖励模型（PRM）被提出以提供步级反馈，但其构建依赖大量人工标注或蒙特卡洛采样，成本高且缺乏形式化保证。本文的切入点在于，Lean 解析器本身已提供了经过类型论验证的战术级反馈，无需额外标注即可作为密集且可靠的训练信号。

## 核心方法

### 方法参照系

本文基于 Group Relative Policy Optimization (GRPO) 框架，该框架通过组内相对优势消除价值函数估计的方差，适用于可验证奖励的 RL 场景。与标准 GRPO 仅使用全局结果奖励不同，本文的关键差异在于将 Lean 的战术级解析反馈转化为过程级优势，注入到 token 级的训练目标中，从而在保持 GRPO 简洁性的同时解决稀疏信用分配问题。

### 战术级 MDP 与首错误传播

设计动机在于解决自回归生成中“无效前缀”导致的因果断裂：一旦某战术失败，后续战术基于错误状态生成，其奖励信号在逻辑上是无效的。本文定义战术级马尔可夫决策过程（MDP），状态为部分证明前缀，动作为单个战术。引入首错误传播（First-Error Propagation）规则：若战术 $T_j$ 在 Lean 中报错，则所有 $k \ge j$ 的战术 $T_k$ 均被视为错误。该规则确保信用分配符合类型论的因果逻辑，避免模型从无效上下文中学习错误的战术选择。

$$
r_{process}(Y_i, T_{i,j}) = \begin{cases}
1 & \text{if } T_{i,j} \text{ is elaborated successfully and } j < j_{err} \\
-1 & \text{if } T_{i,j} \text{ fails or } j \ge j_{err}
\end{cases}
$$

其中 $j_{err}$ 为第一个错误战术的索引。该公式将 Lean 的二元验证状态转化为战术级标量奖励，$j_{err}$ 之前的成功战术获得正奖励，之后的所有战术（包括原本可能正确的）均获得负奖励，以惩罚导致错误的决策路径。

### 首 Token 信用分配与 GRPO 集成

设计动机在于战术内部 token 的语义重要性不均：战术关键词（如 `intro`, `apply`）决定了证明策略，而后续参数 token 多为语法填充。将奖励分散到所有 token 会稀释关键决策点的信号。本文提出首 token 信用分配策略，仅将战术级优势 $A_{process}$ 分配给该战术的第一个 token。结合结果级优势 $A_{outcome}$，最终 token 级优势为：

$$
A_{i,t} = A_{outcome, i} + \mathbb{I}(t = \text{first}(T_{i,s(i,t)})) \cdot A_{process, i, s(i,t)}
$$

其中 $s(i,t)$ 为 token $t$ 所属战术的索引。该公式将全局结果信号与局部战术信号在 token 粒度上叠加，使模型在关键决策点（战术起始处）获得密集的、类型论验证的梯度信号，从而更精准地优化战术选择策略。

## 实验评估

| 模型 | 预算 | MiniF2F-Test | ProofNet-Test |
|---|---|---|---|
| STP-Lean | 64 | 56.7%±0.2 | 19.1%±0.4 |
| STP-Lean + Ours | 64 | 59.2%±0.5 | 19.0%±0.3 |
| DeepSeek-Prover-V1.5-RL | 64 | 48.8%±0.4 | 17.4%±0.6 |
| DeepSeek-Prover-V1.5 + STP + Ours | 64 | 57.8%±0.4 | 18.5%±0.3 |

实验在 MiniF2F 和 ProofNet 上进行，基线覆盖 SFT、结果级 RL（GRPO）及树搜索方法。本文方法在 STP-Lean 基础上，MiniF2F pass@64 提升 2.5 个百分点至 59.2%，ProofNet 提升 1.4 个百分点至 19.0%。相比 DeepSeek-Prover-V1.5-RL 的 48.8%，本文方法在 MiniF2F 上领先 10.4 个百分点，表明战术级过程奖励显著优于纯结果级奖励。

| 消融策略 | MiniF2F-Test | ProofNet-Test |
|---|---|---|
| No First Error | 58.2%±0.7 | 18.3%±0.3 |
| No Baseline | 57.4%±0.7 | 18.3%±0.5 |
| Same tactic reward | 58.7%±0.8 | 18.1%±0.6 |
| First token (Ours) | 59.2%±0.5 | 19.0%±0.3 |

消融实验显示，移除首错误传播导致 MiniF2F 性能下降 1.0 个百分点，证明因果一致性对信用分配至关重要。将部分正确与错误战术奖励合并（Same tactic reward）导致 ProofNet 性能下降 0.9 个百分点，表明区分错误类型对复杂证明结构有效。首 token 分配策略在所有设置下均优于全 token 或熵基分配，验证了关键决策点聚焦的有效性。

评估边界方面，本文仅在竞赛级基准（MiniF2F, ProofNet）上验证，未提供 PutnamBench 等研究级基准结果，无法评估其在长程依赖与结构复杂性上的表现。代码未公开，但超参数（如 $d_1=-0.05, d_2=-0.1$）与训练细节在附录中提供，可复现性中等。

## 关联研究分析

从问题动机看，本文与 DeepSeek-Prover-V1.5 同属结果级 RL 路线，但后者依赖大规模数据与二元奖励，在 ProofNet 上出现性能波动甚至低于 SFT 基线。本文通过引入 Lean 解析的战术级反馈，将奖励信号从稀疏的全局结果扩展为密集的局部验证，解决了结果级奖励在长程证明中缺乏稳定指导的问题。这一差异源于任务特性：形式化证明的每一步都可通过类型论验证，而自然语言推理缺乏此类结构化中间状态，因此本文方法难以直接迁移至非形式化推理任务。

从方法设计看，本文与 Lean-STaR 等树搜索方法形成对比。Lean-STaR 在推理时通过树搜索探索战术空间，计算成本高且依赖搜索深度；本文在训练时通过过程奖励优化策略，推理时为单次生成，避免了搜索开销。然而，本文方法在 MiniF2F 上 59.2% 的准确率低于树搜索方法 InternLM2.5-StepProver 的 58.5%（注：此处原文数据为 58.5%，但本文 59.2% 略高，需确认；据原文 Table 1，InternLM2.5-StepProver 为 58.5%±0.9，本文 59.2%±0.5，本文略优）。这一对比表明，训练时的过程奖励可在单次生成范式下逼近树搜索的性能，但两者在研究级基准上的相对优势尚未明确，本文未提供相关实验。

## 总结

本文要解决的核心矛盾是形式化证明中 RL 训练的稀疏信用分配问题。现有结果级 RL 方法因奖励信号稀疏，难以从长程证明的局部错误中有效学习，而外部 PRM 构建成本高且缺乏形式化保证。本文抓住 Lean 解析器本身提供类型论验证的战术级反馈这一被忽略的资源，将其作为符号过程预言机，通过首错误传播与首 token 信用分配策略，将符号化验证信号转化为 token 级优势，实现了无需自然语言引导的密集且可验证的信用分配。实验证明，该方法在 MiniF2F 上达到 59.2% 的 pass@64，较纯结果级 RL 提升 10.4 个百分点，且在 ProofNet 上稳定优于基线。本文的边界在于仅在竞赛级基准上验证，未评估其在研究级数学中的表现，且单次生成范式可能限制其在复杂证明结构上的上限。当证明长度超过 50 个战术时，首错误传播是否会导致奖励信号过度稀疏，从而削弱训练效果，论文未给出回答。
