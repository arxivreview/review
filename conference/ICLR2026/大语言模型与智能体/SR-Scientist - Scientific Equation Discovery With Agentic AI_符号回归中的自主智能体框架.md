# ICLR2026最新论文 ｜SR-Scientist: Scientific Equation Discovery With Agentic AI ｜符号回归中的自主智能体框架

研究机构：上海交通大学

作者：Shijie Xia、Yuhan Sun、Pengfei Liu

论文原文见 [arXiv](https://arxiv.org/abs/2510.11661)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.11661)

> 符号回归（Symbolic Regression, SR）旨在从观测数据中恢复可解释的数学公式，是科学发现的核心底层任务。现有方法将大语言模型（Large Language Models, LLMs）局限于遗传编程中的静态变异算子，缺乏通过工具交互获取数据洞察的自主性，导致在复杂非线性系统中搜索效率低下。SR-Scientist 将 LLM 升级为自主智能体，通过代码解释器进行长程数据分析与方程迭代优化，并引入端到端强化学习（Reinforcement Learning, RL）以进化模型能力。该框架在四个科学学科上显著优于基线，但其性能高度依赖底层 LLM 的固有推理能力，且长程优化的计算成本限制了大规模部署。

## 研究背景

符号回归是一个 NP-hard 问题，其搜索空间由符号算子、常数和变量构成。传统方法依赖遗传编程（Genetic Programming, GP）进行组合搜索，或训练深度神经网络直接预测表达式，但前者效率低且易陷入局部最优，后者缺乏可解释性。随着 LLMs 的引入，研究者开始利用其预训练的科学先验知识生成更有效的假设，但现有工作（如 LLM-SR）通常将 LLM 嵌入固定管道，仅作为方程提案者，无法自主决定分析策略或从实验反馈中修正错误。

该领域的核心瓶颈在于 LLM 的“被动性”与科学发现所需的“主动探索”之间的错位。主流路线如 FunSearch 和 LLM-SR 虽然提升了搜索效率，但 LLM 无法通过代码执行来验证假设或分析数据残差，导致其在面对未见过的物理机制时，往往依赖模式匹配而非逻辑推导。SR-Scientist 的切入点在于打破这种静态管道，赋予 LLM 自主调用工具、分析数据、调试代码并基于反馈迭代优化的能力，将 SR 任务重构为长程智能体交互过程。

## 核心方法

### 方法参照系

SR 的标准流程通常包含假设生成、参数优化和误差评估三个环节。传统 GP 方法通过随机变异生成候选方程，而 LLM-based 方法（如 LLM-SR）利用模型生成初始候选，随后通过 BFGS 等算法优化常数。本文的关键差异在于，LLM 不再一次性生成最终方程，而是作为智能体在 ReAct 框架下，通过多轮工具交互动态调整方程结构，直至满足精度目标。

### 长程工具交互与经验缓冲

在标准 SR 流程中，假设生成与数据评估是解耦的，LLM 无法感知数据分布特征。SR-Scientist 将代码解释器封装为数据分析师（$T_1$）和方程评估器（$T_2$）两个工具。智能体在每一轮迭代中，先通过 $T_1$ 执行代码分析数据样本、统计特征及残差，再基于洞察提出方程骨架，并通过 $T_2$ 执行 BFGS 优化常数并计算平均绝对百分比误差（Mean Absolute Percentage Error, MAPE）。为解决长程交互中的上下文长度限制，引入经验缓冲 $E = \{(e_i, s_i)\}_{i=1}^N$，其中 $e_i$ 为方程，$s_i$ 为 MAPE。每轮迭代开始时，从 $E$ 中获取表现最好的 $K$ 个方程作为上下文示例，并动态更新优化目标 $G_i$。

$$
\text{MAPE} = \frac{100\%}{n} \sum_{i=1}^{n} \frac{|y_i - f(\mathbf{x}_i)|}{|y_i|}
$$

该公式定义了智能体的优化目标，MAPE 相比均方误差（MSE）提供了更均匀的精度目标，使智能体在不同量级的数据上具有可比的优化压力。经验缓冲机制替代了传统 GP 的种群管理，通过保留历史最优解，使智能体能够基于过往失败或成功进行反思，避免了长程任务中的错误累积。

### 端到端强化学习训练

现有 LLM-SR 方法仅利用预训练知识，无法通过自身经验进化能力。SR-Scientist 构建了端到端 RL 管道，使用对数线性奖励函数 $R(s)$ 映射 MAPE 值 $s$ 到 $[0, 1]$ 区间：

$$
R(s) = \begin{cases}
1 & \text{if } s \le s_{\text{goal}} \\
\frac{\log(s_{\text{max}}/s)}{\log(s_{\text{max}}/s_{\text{goal}})} & \text{if } s_{\text{goal}} < s < s_{\text{max}} \\
0 & \text{if } s \ge s_{\text{max}}
\end{cases}
$$

该奖励函数避免了二元奖励的稀疏性，允许智能体在优化过程中获得连续反馈。通过 GRPO 策略优化，模型在 1024 个合成科学问题上进行训练，学习长程问题求解策略。RL 训练使模型能够自主决定何时分析数据、何时提交方程，从而在未见过的学科领域实现能力迁移。

## 实验评估

实验在 LSR-Synth 数据集上进行，涵盖材料科学、化学、生物和物理四个学科，旨在防止 LLM 依赖记忆化方程。基线包括 GPLearn、PySR、DSR、LLM-SR 和 LaSR，覆盖了 GP、深度学习和 LLM 混合路线。SR-Scientist 使用 GPT-OSS-120B、Qwen3-Coder-480B 等五种模型作为骨干，在 Acc0.01 指标上，GPT-OSS-120B 达到 63.57%，绝对提升 6% 至 35% 优于基线。

| 方法 | Overall Acc0.01 | Overall Acc0.001 | Material Science Acc0.01 | Chemistry Acc0.01 | Biology Acc0.01 | Physics Acc0.01 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| SR-SCIENTIST (GPT) | 63.57 | 49.35 | 81.33 | 22.22 | 18.18 | 37.21 |
| SR-SCIENTIST (Qwen) | 49.09 | 24.55 | 85.33 | 29.17 | 25.00 | 20.45 |
| SR-SCIENTIST (GLM) | 48.32 | 25.06 | 84.00 | 33.33 | 20.45 | 17.83 |

消融实验显示，移除数据分析师工具（$T_1$）导致性能大幅下降（GPT 从 63.57% 降至 35.66%），证明数据洞察是长程优化的关键。移除经验缓冲后，性能降至 57.36%，表明历史记忆对避免局部最优至关重要。然而，移除 Top-K 采样（随机采样）对 GPT 影响较小（58.14%），但对 Qwen 影响显著（26.36%），暗示小模型更依赖结构化上下文。

评估边界方面，论文使用 MAPE 作为优化目标，但评估时采用 NMSE 和 Acc 指标，存在指标不一致风险。代码和超参数已开源，但 RL 训练仅在小模型（Qwen3-Coder-30B）上进行，大模型仅用于推理，限制了 RL 效果的可复现性。此外，单问题 API 成本高达 $0.25，长程优化的计算瓶颈未得到充分解决。

## 关联研究分析

从问题动机看，SR-Scientist 与 FunSearch 和 LLM-SR 的核心差异在于 LLM 的角色定位。FunSearch 将 LLM 视为进化算子，在固定搜索空间中生成候选；LLM-SR 则利用 LLM 生成初始方程，随后由传统算法优化。SR-Scientist 将 LLM 升级为自主智能体，通过代码执行获取数据洞察，这一设计源于科学发现中“假设-验证”闭环的需求。然而，PTB-Search 等单代组件化方法表明，LLM 的贡献可能更多在于组件生成而非多代进化，SR-Scientist 的长程优化是否真正超越了单代组件化，论文未提供直接对比。

从方法设计看，SR-Scientist 的经验缓冲机制与传统 GP 的种群管理存在本质区别。GP 通过交叉和变异维护种群多样性，而 SR-Scientist 通过 Top-K 采样保留历史最优解，这可能导致搜索空间探索不足。论文未探讨经验缓冲是否比 GP 种群更利于避免局部最优，也未分析在高度非线性系统中，长程优化是否会导致过拟合训练数据。此外，RL 训练的提升是否主要源于模型容量而非框架本身，论文未给出控制变量实验。

## 总结

SR-Scientist 解决了 LLM 在符号回归中缺乏自主探索能力的问题，通过长程工具交互和端到端 RL 训练，使模型能够基于数据洞察迭代优化方程。该框架在 LSR-Synth 上显著优于基线，GPT-OSS-120B 的 Acc0.01 达到 63.57%，验证了自主智能体范式在 SR 中的有效性。然而，其性能高度依赖底层 LLM 的固有推理能力，小模型在移除 Top-K 采样后性能骤降，表明框架对小模型的鲁棒性不足。此外，长程优化的计算成本（单问题 $0.25）和指标不一致风险（MAPE 优化 vs NMSE 评估）限制了其实际应用。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
