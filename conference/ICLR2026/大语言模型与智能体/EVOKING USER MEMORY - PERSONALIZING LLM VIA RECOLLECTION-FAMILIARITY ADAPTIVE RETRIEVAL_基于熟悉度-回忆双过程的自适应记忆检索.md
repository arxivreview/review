# ICLR2026最新论文 ｜EVOKING USER MEMORY: PERSONALIZING LLM VIA RECOLLECTION-FAMILIARITY ADAPTIVE RETRIEVAL ｜基于熟悉度-回忆双过程的自适应记忆检索

研究机构：大连理工大学、香港城市大学

作者：Yingyi Zhang、Junyi Li、Wenlin Zhang 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.09250)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_55999821)

> 个性化大语言模型（LLM）在调用用户历史记忆时，面临全量上下文输入导致的计算爆炸与单次相似度检索导致的深层信息遗漏双重困境。现有检索策略将记忆简化为静态向量匹配，缺乏对模糊查询或长尾知识的链式重构能力，且无法在快速识别与深度回忆间动态切换。本文提出RF-Mem框架，通过计算检索结果的均值与熵作为熟悉度信号，自适应地在单次Top-K检索与基于聚类的迭代扩展检索间切换。该设计在保持单次检索低延迟的同时，显著提升了复杂推理任务的准确率，但其有效性高度依赖底层嵌入模型的几何特性，且未验证在参数化记忆更新场景下的适用性。

## 研究背景

当LLM处理包含数万至百万token的用户交互历史时，直接注入全量上下文会迅速超出模型窗口限制，而仅依赖单次向量相似度检索（即“熟悉度”检索）往往只能捕获表面匹配的碎片，无法重构分散在多个会话中的深层语境。这种检索失效在模糊查询或需要跨会话推理的任务中尤为严重，导致模型回答缺乏个性化深度。解决这一矛盾需要一种既能快速响应明确事实，又能对不确定查询进行链式证据重构的检索机制。

个性化记忆检索领域的主流路线分为查询改写、索引构建与检索策略三个维度。前两者已相对成熟，但检索策略仍被基于嵌入的单次Top-K搜索主导，这对应认知科学中的“熟悉度”通道：快速但浅层。现有系统缺乏“回忆”路径，即当熟悉度信号不足时，主动发起慢速、上下文重构的检索过程。同时，现有方法缺乏路径切换机制，导致要么因过度检索引入噪声与延迟，要么因检索不足遗漏关键线索。RF-Mem的切入点在于引入认知双过程理论，将检索建模为熟悉度与回忆的动态协调，通过不确定性驱动的路径选择，在效率与覆盖度间取得平衡。

## 核心方法

### 检索策略参照系

标准个性化记忆检索流程为：查询嵌入计算、与记忆库向量余弦相似度匹配、返回Top-K结果。该流程假设查询与记忆间的语义关系可通过单一相似度分数充分表征，忽略了记忆检索中常见的“表面相似但语境缺失”现象。RF-Mem在此流程中插入不确定性评估模块，将单次检索扩展为双路径自适应检索。

### 熟悉度不确定性门控

在标准Top-K检索后，RF-Mem计算候选集的熟悉度信号以决定路径切换。设计动机在于解决单次检索在模糊查询下“自信地返回错误结果”的失效：当相似度分布集中且高分时，直接返回；当分布分散或低分时，触发深度检索。具体地，设探针检索返回的相似度分数为 $s_i$，归一化概率 $p_i = \frac{\exp(s_i/\lambda)}{\sum_{j=1}^K \exp(s_j/\lambda)}$，其中 $\lambda$ 控制锐度。熟悉度由均值 $\bar{s}$ 与熵 $H(p) = -\sum_{i=1}^K p_i \log p_i$ 共同决定：若 $\bar{s} \geq \theta_{high}$ 或 $H(p) \leq \tau$，走熟悉度路径；若 $\bar{s} \leq \theta_{low}$ 或 $H(p) > \tau$，走回忆路径。该机制将检索深度与查询的确定性显式绑定，避免了对所有查询无条件执行高成本检索。

### 基于聚类与α混合的回忆检索

当门控触发回忆路径时，系统执行迭代式证据重构。设计动机在于解决表面匹配无法关联分散语境线索的问题：通过聚类发现记忆中的语义簇，再以簇中心与查询的混合向量作为新查询，逐步扩展检索范围。具体地，第 $r$ 轮检索候选集 $C^{[r]}$ 经KMeans聚类为 $B$ 个簇，簇中心 $\mathbf{g}_b^{[r]}$ 与当前查询 $\mathbf{x}^{[r]}$ 通过 $\alpha$-混合生成回忆查询：$\mathbf{x}_b^{[r+1]} = \alpha \mathbf{x}^{[r]} + (1-\alpha) \mathbf{g}_b^{[r]}$。该查询用于下一轮检索，形成“检索-聚类-混合”循环，直至达到最大轮数 $R$ 或收集足够证据。此过程在嵌入空间内模拟链式回忆，无需LLM参与中间推理，仅依赖向量搜索与小规模聚类，保持计算可控。

## 实验评估

实验在PersonaMem（32K/128K/1M tokens）、PersonaBench与LongMemEval三个基准上进行，基线包括Zero Memory、Full Context、Dense Retrieval（熟悉度）与Recollection（纯回忆）。RF-Mem在PersonaMem所有规模下均取得最高整体准确率：32K时0.6350（vs. Dense 0.5908，Full Context 0.6129），128K时0.5394（vs. Dense 0.5259），1M时0.4589（vs. Dense 0.4518）。在1M规模下，Full Context因超出上下文窗口失效（OOC），而RF-Mem仅用3.8K平均token即超越Dense Retrieval，验证了自适应深度调节的有效性。

| 数据集 | 规模 | 方法 | Overall Accuracy | 检索时间 (ms) |
| :--- | :--- | :--- | :--- | :--- |
| PersonaMem | 32K | Dense Retrieval | 0.5908 | 3.14 |
| PersonaMem | 32K | RF-Mem | 0.6350 | 5.09 |
| PersonaMem | 128K | Dense Retrieval | 0.5259 | 3.24 |
| PersonaMem | 128K | RF-Mem | 0.5394 | 4.27 |
| PersonaMem | 1M | Dense Retrieval | 0.4518 | 4.42 |
| PersonaMem | 1M | RF-Mem | 0.4589 | 6.28 |

消融实验显示，纯Recollection路径在推理密集型任务（如家庭关系、治疗咨询）上优于Familiarity，但在事实型任务（如食物推荐）上表现更差。RF-Mem通过门控机制在两类任务间取得平衡：32K时，RF-Mem在Aligned Recommendations上达0.7818，显著高于Dense的0.6364；在Food Recommendation上，RF-Mem与Dense持平（1.0000），未引入额外开销。不同嵌入模型对路由行为影响显著：MiniLM与MPNet触发更多回忆路径，BGE则更多依赖熟悉度，表明框架性能与嵌入空间几何特性强相关。

评估边界方面，实验仅覆盖非参数化外部记忆，未测试参数化记忆更新场景。指标以Accuracy与Recall@K为主，未报告置信区间，且多数结果基于单一GPU（A100）上的小规模聚类，计算开销未量化。代码已开源，但超参数（如 $\theta_{high}=0.6$, $\theta_{low}=0.3$, $\lambda=20$）在不同数据集间未做敏感性分析，可复现性依赖于特定嵌入模型配置。

## 关联研究分析

从问题动机看，RF-Mem与MemGPT等动态记忆管理框架共享“解决长上下文检索不稳定性”的目标，但路径截然不同。MemGPT通过分层分页机制管理上下文窗口，侧重内存分配与调度；RF-Mem则聚焦检索策略本身，通过认知双过程理论重构检索逻辑。这一差异源于任务特性：MemGPT处理的是通用对话状态管理，而RF-Mem针对个性化记忆中的“证据链重构”需求。RF-Mem未涉及内存管理，其贡献在于证明检索路径的自适应切换比单纯的窗口扩展更能提升复杂推理任务的准确性，但这也意味着它无法解决MemGPT所针对的上下文窗口物理限制问题。

从方法设计看，RF-Mem与MemoryBank等索引构建方法形成互补而非竞争关系。MemoryBank通过摘要或图结构优化记忆表示，RF-Mem则作为在线检索层叠加于其上。实验表明，RF-Mem在MemoryBank摘要索引下仍保持优势（32K时Overall 0.5314 vs. Familiarity 0.4941），验证了其模块化特性。然而，RF-Mem的回忆路径依赖KMeans聚类，这在记忆库高度结构化（如MemoryBank的摘要索引）时可能引入冗余计算，因为摘要本身已压缩了语义簇。论文未探讨聚类算法在结构化索引上的效率损失，也未对比基于图遍历的替代方案（如附录中提到的Graph+BFS），后者在PersonaBench上Recall@10 Overall为0.5899，低于RF-Mem的0.6071，但计算开销可能更高。

## 总结

RF-Mem旨在解决个性化LLM中全量上下文不可行与单次检索深度不足的矛盾，其切入点在于引入认知双过程理论，通过熟悉度不确定性门控实现检索路径的自适应切换。该方法在PersonaMem 1M规模下以0.4589的准确率超越Dense Retrieval（0.4518），且检索时间仅6.28ms，验证了效率与效果的平衡。然而，实验仅覆盖非参数化外部记忆，且性能高度依赖嵌入模型的几何特性，BGE等弱校准模型下路由行为显著偏移。当记忆库从用户私有历史扩展至多用户共享场景时，聚类迭代是否会在隐私边界内保持有效，论文未给出回答。
