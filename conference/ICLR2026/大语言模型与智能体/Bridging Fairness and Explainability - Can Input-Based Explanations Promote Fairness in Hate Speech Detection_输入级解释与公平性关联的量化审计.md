# ICLR2026最新论文 ｜Bridging Fairness and Explainability: Can Input-Based Explanations Promote Fairness in Hate Speech Detection? ｜输入级解释与公平性关联的量化审计

研究机构：德国萨尔大学、德国马克斯·普朗克信息学研究所

作者：Yifan Wang、Mayank Jobanputra、Ji-Ung Lee 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.22291)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.22291)

> 语言模型在仇恨言论检测等高风险任务中常因依赖敏感特征而产生偏见，但现有解释方法能否可靠地揭示这种偏见缺乏系统性量化证据。传统研究多停留在定性分析或小规模案例，无法回答解释信号在检测、模型选择与训练去偏中的实际效用边界。本文通过16种归因方法在编码器与解码器模型上的大规模实验，构建了“敏感Token依赖度”与“个体不公平性”的统计关联框架。该研究证实了输入级解释在偏差检测与训练正则化中的有效性，但否定了其作为公平模型自动选择代理的可靠性，为解释性AI的公平审计提供了实证边界。

## 研究背景

仇恨言论检测模型若依赖种族或性别等敏感词进行预测，会导致对边缘群体的系统性误判。这种依赖可通过反事实替换敏感词后预测概率的变化来量化，即个体不公平性（Individual Unfairness, IU）。然而，模型内部对敏感词的依赖程度无法直接观测，需借助输入级解释（Input-based Explanations）将预测归因到具体Token。解释分数与IU之间的统计相关性，即公平性相关性（Fairness Correlation），成为衡量解释方法能否有效识别偏差的核心指标。

早期研究假设解释能直接映射模型决策逻辑，从而辅助公平性约束，但后续工作指出解释可能不忠实于真实机制，且模型可通过降低敏感词归因来掩盖偏见。现有文献多局限于定性分析或单一解释方法，缺乏对多种归因技术在不同模型架构（编码器/解码器）及去偏策略下的系统性对比。本文切入点在于将解释信号从“事后审计工具”拓展至“训练时正则化信号”，并量化其在偏差检测、模型选择与去偏三个环节的真实效用，填补了解释性与公平性之间缺乏大规模定量关联研究的空白。

## 核心方法

### 归因框架与公平性度量参照系

本文沿用标准输入级解释流程，但将评估目标从“预测忠实度”转向“公平性敏感度”。参照系中，归因方法计算每个Token对预测的贡献，而本文聚焦于敏感Token子集的聚合分数。关键差异在于，本文不评估解释是否准确反映模型内部机制，而是评估解释分数与外部公平指标（IU）的统计一致性。这种视角转换使得解释方法的有效性不再取决于其理论忠实性，而取决于其能否稳定地标记出高偏差预测。

### 敏感Token依赖度与公平性相关性

为量化解释对偏差的识别能力，本文定义敏感Token依赖度为输入中所有敏感Token归因分数的最大绝对值：

$$ \text{Reliance}(\mathbf{x}, c) = \max_{j \in \{g_1, ..., g_m\}} |a_j^c| $$

其中 $a_j^c$ 为Token $j$ 对类别 $c$ 的归因分数。该设计动机在于，单一敏感词的高归因往往主导了模型的偏见决策，取最大值能更敏锐地捕捉这种局部依赖，避免平均化操作稀释关键信号。随后，计算依赖度与IU分数的Pearson相关系数作为公平性相关性。高相关性表明解释方法能准确区分高偏差与低偏差预测，为偏差检测提供可靠信号。

### 解释引导的训练去偏

在训练阶段，本文利用解释分数作为正则化项，惩罚模型对敏感Token的过度依赖。具体而言，在损失函数中加入敏感Token归因的L1或L2范数，迫使模型在优化任务性能的同时降低对敏感特征的敏感度。这一设计解决了传统去偏方法（如数据平衡）仅改变输入分布而未直接约束模型内部依赖的问题。通过梯度追踪，解释方法（如Occlusion、IxG）在反向传播中提供可微的敏感词依赖信号，实现了对模型决策路径的直接干预，从而在保持任务精度的同时系统性降低个体不公平性。

## 实验评估

实验在Civil Comments与Jigsaw数据集上进行，涵盖BERT、RoBERTa等编码器模型及Llama3.2、Qwen3等解码器模型，对比16种归因方法。基线覆盖梯度、注意力、扰动与传播四类路线，但缺失机制可解释性方法（如电路发现）作为对照。

| 方法 | 公平性相关性 (BERT) | 公平性相关性 (Qwen3-4B) |
| :--- | :--- | :--- |
| Occlusion abs | 0.433 | 0.32 |
| Grad L2 | 0.437 | 0.32 |
| Attention | 0.402 | 0.14 |
| KernelSHAP | 0.254 | 0.06 |

Occlusion abs与Grad L2在两种架构上均取得最高公平性相关性，显著优于Attention与KernelSHAP。这表明基于扰动与L2范数的归因方法在识别敏感词依赖上更具鲁棒性，而注意力权重因受语法结构干扰，公平性相关性较低。

在模型选择环节，所有解释方法的Spearman秩相关系数均低于使用验证集IU作为基线的结果，MRR@1指标也未能超越随机选择。这证实了解释信号无法可靠地用于在候选模型中自动筛选最公平模型，其效用局限于单模型内的偏差检测。

| 去偏方法 | Avgiu (Race) | Avgiu (Gender) | Avgiu (Religion) |
| :--- | :--- | :--- | :--- |
| Default (BERT) | 3.17 | 0.66 | 1.27 |
| IxG L1 Debiased | 0.012 | 0.005 | - |
| IxG L2 Debiased | 2.162 | 0.308 | - |

解释引导去偏显著降低了Avgiu，尤其在种族偏见上效果突出。然而，混合去偏实验显示，预处理（如Group Balance）与解释去偏结合时，收益并非简单叠加，部分组合下解释去偏的边际收益递减，表明数据分布调整与模型内部约束存在交互效应。

评估边界方面，本文仅关注二分类任务，未验证生成式任务中的公平性解释。代码已开源，但实验依赖H100 GPU，复现成本较高。公平性相关性指标未考虑解释的忠实性，高相关性可能源于对敏感词的过度敏感而非真实机制反映。

## 关联研究分析

从问题动机看，本文与Dimanov et al. (2020) 的立场形成对比。后者质疑解释在公平性中的可靠性，认为模型可通过降低敏感词归因来掩盖偏见；本文则通过大规模实验证实，尽管存在掩盖风险，Occlusion等扰动方法在去偏模型中仍保持高公平性相关性，表明解释信号在特定条件下具有鲁棒性。这一差异源于本文区分了“检测”与“选择”两个环节，指出解释在单模型审计中有效，但在跨模型比较中失效，从而调和了先前研究的矛盾。

从方法设计看，本文与HETA (Pramanik et al., 2026) 等高精度归因方法不同，后者追求Token级贡献的数学严谨性，而本文关注敏感子集聚合分数的统计效用。HETA依赖Hessian矩阵捕捉高阶效应，计算成本高且需白盒访问；本文采用轻量级Occlusion与L2归因，牺牲部分机制解释深度以换取在大规模模型上的可扩展性。这种取舍反映了公平性审计对计算效率的刚性需求，但可能忽略模型内部复杂的非线性交互，导致对某些隐蔽偏见的漏检。

## 总结

本文核心矛盾在于解释信号的“忠实性”与“公平性效用”之间的脱节。现有方法假设解释忠实于机制即可辅助公平性，但本文证明高忠实性方法（如某些梯度法）未必带来高公平性相关性，而低计算成本方法（如Occlusion）反而更有效。本文通过构建敏感Token依赖度与IU的统计关联，证实了输入级解释在偏差检测与训练去偏中的实用价值，Occlusion abs在BERT上取得0.433的公平性相关性，IxG L1去偏将种族偏见Avgiu从3.17降至0.012。然而，实验边界显示解释信号无法用于模型选择，且仅在二分类任务中验证。当模型通过微调学会降低敏感词归因而非真正消除偏见时，解释信号是否会失效，本文未给出回答。
