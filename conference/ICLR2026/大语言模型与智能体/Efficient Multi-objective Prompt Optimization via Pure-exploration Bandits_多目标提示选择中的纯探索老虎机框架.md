# ICLR2026最新论文 ｜Efficient Multi-objective Prompt Optimization via Pure-exploration Bandits ｜多目标提示选择中的纯探索老虎机框架

研究机构：美国弗吉尼亚大学、美国普林斯顿大学

作者：Donghao Li、Chengshuai Shi、Weijuan Ou 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.14553)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.14553)

> 自动提示优化（APO）在闭源大语言模型（LLM）适配中面临评估预算受限与多指标权衡的双重困境。现有方法多聚焦于单目标优化或依赖启发式生成，缺乏在固定预算下识别帕累托最优解的理论保证。本文首次将多目标提示选择形式化为纯探索多臂老虎机（Pure-Exploration Multi-Armed Bandits, PE-MAB）问题，提出GENSEC与GENPSI算法以高效识别最佳可行提示及帕累托集。该方法在摘要任务上显著优于均匀采样基线，但其对固定候选集与非平稳环境的假设限制了其在开放生成场景的泛化能力。

## 研究背景

提示工程的核心在于通过自然语言指令激发LLM潜能，而自动提示优化（APO）旨在算法化地搜索最优指令。然而，实际部署中提示性能并非由单一指标决定，而是涉及连贯性、忠实度、简洁度等多维度的复杂权衡。这种多目标特性使得传统的标量化优化方法失效，因为单一指标无法捕捉所有维度的最优解，且不同指标间存在固有的冲突关系。

当前APO领域的主流路线分为生成式搜索与选择式优化两类。生成式方法如GEPA（Agrawal et al., 2025）和MOPO（Resendiz & Klinger, 2025）利用进化算法或强化学习生成新提示，但往往采用均匀采样作为选择策略，导致在有限预算下样本效率低下。选择式方法如TRIPLE（Shi et al., 2024）虽引入了单目标最佳臂识别（Best Arm Identification, BAI）框架，但未处理多目标约束。本文切入点在于填补这一空白：将多目标提示选择纳入PE-MAB框架，利用其固定预算下的理论保证，解决在严格评估成本约束下如何高效定位满足硬约束的最佳可行提示及完整帕累托前沿的问题。

## 核心方法

### 多目标提示选择的形式化

本文解决的问题可视为从固定候选提示集 $X$ 中，在总评估预算 $B$ 限制下，识别出在多个评估指标 $\{f_1, ..., f_m\}$ 上表现最优的提示。与通用BAI流程的关键差异在于，本文不假设奖励为标量，而是处理向量奖励，并引入硬约束条件。具体而言，定义提示 $x$ 的期望性能向量为 $\mu(x) = \mathbb{E}[(f_1(y,a), ..., f_m(y,a))]$，其中 $y \sim M(q; x)$。问题被分解为两个子任务：一是最佳可行提示识别，即最大化主目标 $\mu_1(x)$ 同时满足次要目标 $\mu_j(x) \ge \tau_j$；二是帕累托集识别，即恢复所有不被其他提示严格支配的提示集合 $X^*$。

### 基于轮次消除的约束优化算法

针对最佳可行提示识别，本文提出GENSEC算法，其核心在于将约束检查融入轮次消除过程。设计动机在于解决传统消除算法忽略可行性约束导致次优解的问题。算法分为 $R$ 轮，每轮 $r$ 包含 $n_r$ 次拉取，总预算 $\sum_{r=1}^R n_r = B$。每轮结束后，根据估计性能 $\hat{\mu}_{r}(x)$ 对活跃臂集合 $A_{r-1}$ 进行排序与剪枝。关键创新在于消除步骤中，首先构建经验可行集 $\hat{F}_r = \{x \in A_{r-1} : \hat{\mu}_{2,r}(x) > \tau\}$，将可行臂置于不可行臂之前。在可行臂内部，按主目标 $\hat{\mu}_{1,r}(x)$ 降序排列；在不可行臂内部，按次要目标 $\hat{\mu}_{2,r}(x)$ 降序排列。保留前 $l_r$ 个臂形成新的活跃集 $A_r$。

$$
A_r = \text{Top}_l \left( \text{Sort}_{\text{feasible}}(\hat{F}_r, \hat{\mu}_1) \cup \text{Sort}_{\text{infeasible}}(\hat{F}_r^c, \hat{\mu}_2) \right)
$$

该公式表明，算法通过分层排序确保最终保留的臂既满足约束又在主目标上尽可能优，从而在理论上保证以指数级衰减的概率返回最优可行提示 $x^*$。

### 帕累托集恢复与结构化特征利用

针对帕累托集识别，本文提出GENPSI算法，统一了标准与线性老虎机设置下的帕累托集恢复问题。设计动机在于利用提示间的语义相关性提升样本效率。本文引入特征映射 $\phi: X \to \mathbb{R}^d$，假设期望奖励 $\mu(x) = g_\theta(\phi(x))$，其中 $g_\theta$ 为共享参数函数。通过GPT-3.5-turbo提取提示嵌入并执行主成分分析（PCA）降维，构建 $\phi(x) = U_d^\top (e(x) - \bar{e})$。这种结构化假设使得评估任意提示的观察值都能贡献于参数 $\theta$ 的估计，从而加速收敛。在帕累托集恢复中，算法利用经验间隙消除（Empirical Gap Elimination, EGE）策略，根据提示在帕累托前沿上的相对位置动态分配预算，确保以高概率恢复真实帕累托集的超体积（Hypervolume）。

## 实验评估

实验在XSum与CNN/DailyMail两个摘要基准上进行，使用LLaMA-3-8B-instruct与Gemma-7B-it作为骨干模型。候选提示集大小为100，通过LLaMA-3生成并人工筛选。基线方法仅包含均匀采样（Uniform），缺失GEPA、ELPO等生成式或集成式强基线，这限制了与当前SOTA方法的直接性能对比。

| 方法 | K=30, b=10 (XSum-Gemma) | K=100, b=10 (XSum-Gemma) | K=100, b=10 (CNN-LLaMA) |
| :--- | :--- | :--- | :--- |
| Uniform | 0.036 ± 0.014 | 0.044 ± 0.015 | 0.1631 ± 0.0023 |
| CSR | 0.140 ± 0.002 | 0.143 ± 0.002 | - |
| MLP-CSR | 0.142 ± 0.001 | 0.147 ± 0.001 | - |
| EGE | - | - | 0.1754 ± 0.0022 |
| MLP-EGE | - | - | 0.1716 ± 0.0023 |

在XSum-Gemma设置下，MLP-CSR在K=100, b=10时取得0.147的软约束奖励，显著高于Uniform的0.044。在CNN-LLaMA的帕累托集恢复任务中，EGE在K=100, b=10时取得0.1754的超体积，略高于MLP-EGE的0.1716，表明在特定预算下标准消除策略可能优于结构化估计。

消融实验显示，引入MLP结构（即利用特征映射）在XSum任务上带来稳定提升，如K=30时从CSR的0.140提升至MLP-CSR的0.142。然而，在CNN/DailyMail任务中，MLP-EGE在b=10时（0.1716）低于EGE（0.1754），暗示结构化假设在该数据集上可能引入过拟合或特征噪声。这一反直觉结果提示，特征映射的有效性依赖于提示集内部的语义一致性，当提示多样性过高时，线性假设可能失效。

评估边界方面，本文仅使用ROUGE-L F1与Brevity Score两个指标，未涵盖人工评估或更复杂的语义指标。实验未报告计算延迟或内存占用，且未提供代码开源链接，限制了可复现性。此外，所有实验均基于固定候选集，未验证方法在动态生成提示场景下的适用性。

## 关联研究分析

从问题动机看，本文与GEPA（Agrawal et al., 2025）形成鲜明对比。GEPA通过自然语言反思与帕累托引导进化生成新提示，侧重探索未知提示空间；而本文聚焦于从固定候选集中选择，侧重利用已有提示的结构化信息。这种差异源于任务假设的不同：GEPA假设最优提示可能不在初始集合中，需通过变异生成；本文假设最优提示已存在于候选集中，需高效筛选。本文未与GEPA对比，可能是因为两者优化目标不同（生成vs选择），但这也暴露了本文在开放生成场景下的适用性盲区。

从方法设计看，本文与CAPO（Zehle et al., 2025）均处理约束优化，但技术路径迥异。CAPO采用拉格朗日对偶结合进化搜索，通过动态调整乘子平衡准确率与长度成本；本文采用PE-MAB轮次消除，通过硬约束检查与分层排序确保可行性。CAPO的软约束处理允许一定程度的违反，适合成本敏感场景；本文的硬约束处理要求严格满足阈值，适合安全敏感场景。本文未讨论软约束扩展，这限制了其在实际部署中处理模糊约束的能力。

## 总结

本文核心矛盾在于如何在有限评估预算下高效解决多目标提示选择问题，现有生成式方法缺乏理论保证，单目标BAI方法无法处理多指标权衡。本文抓住“固定候选集选择”这一被忽略的切入点，利用PE-MAB框架提供了理论保证。通过GENSEC与GENPSI算法，本文在XSum与CNN/DailyMail上实现了80-90%的最优效用恢复，显著优于均匀采样基线。然而，实验仅覆盖摘要任务，且依赖固定候选集与非平稳环境假设，未验证在动态生成或复杂耦合流水线中的表现。当候选提示集随优化过程动态扩展时，PE-MAB框架的收敛性是否依然成立，论文未给出回答。
