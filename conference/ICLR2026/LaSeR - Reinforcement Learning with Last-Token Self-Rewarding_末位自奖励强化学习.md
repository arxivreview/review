# ICLR2026最新论文 ｜LaSeR: Reinforcement Learning with Last-Token Self-Rewarding ｜末位自奖励强化学习

研究机构：中国人民大学

作者：Wenkai Yang、Weijie Liu、Ruobing Xie 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.14943)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.14943)

> 标准可验证奖励强化学习（RLVR）在测试时因缺乏真值答案而无法提供验证信号，现有自验证方案需额外生成验证文本，导致推理成本翻倍。LaSeR 指出模型对解正确性的评估隐含在末位 token 的预测概率分布中，通过理论推导将自验证目标简化为末位自奖励分数与验证器奖励的均方误差（MSE）对齐，以单次 token 前向传播实现推理与自验证的联合优化。该方法在数学推理任务上提升了推理精度与自验证 F1 分数，但其对末位 token 概率稳定性的依赖在长序列或开放域任务中是否依然成立，尚存疑。

## 研究背景

当模型在测试时面对无真值答案的推理任务，标准 RLVR 依赖的确定性验证器失效。此时需模型具备自验证能力，但传统做法要求模型在生成解后，切换提示模板额外生成一段验证文本。这一过程不仅使单样本推理成本翻倍，且验证文本的生成质量受限于模型自身的推理能力，形成“用不确定的推理去验证推理”的循环。

RLVR 领域的主流路线分为外部验证器与联合自验证两类。外部验证器（如过程奖励模型 PRM）需独立训练，存在对齐偏差与额外算力开销；联合自验证方法（如 Sareen et al., 2025）虽统一了生成与验证角色，但受限于序列生成的串行依赖，效率瓶颈显著。LaSeR 的切入点在于，模型在生成解的最后一个 token 时，其下一 token 预测分布已隐含了对整体解正确性的评估，无需额外生成即可提取该信号。

## 核心方法

### 方法参照系

LaSeR 基于组相对策略优化（GRPO）框架，在标准 RLVR 损失中引入自验证优化项。与需显式生成验证序列的联合优化方法不同，LaSeR 将自验证目标转化为对末位 token 概率分布的约束，消除了额外的生成步骤。

### 末位自奖励分数推导

自验证的强化学习目标可形式化为最大化验证奖励与 KL 散度正则项之差。通过隐式奖励理论，该目标的闭式解依赖于策略模型与参考模型在验证 token 上的对数概率比。由于参考模型在解末位对任意特殊 token 的预测概率极小（小于 $e^{-20}$），配分函数项可忽略，使得真实推理奖励近似等于策略模型与参考模型在预设正确 token $z_c$ 上的对数概率比，乘以 KL 系数 $\beta_v$：

$$ r_s = \beta_v \log \frac{\pi_\theta(z_c | \mathbf{x}, \mathbf{y})}{\pi_{\text{ref}}(z_c | \mathbf{x}, \mathbf{y})} $$

该公式表明，模型对解正确性的评估可直接从末位 token 的概率分布中提取，无需生成验证文本。

### MSE 对齐与常数简化

为优化自验证能力，LaSeR 用 MSE 损失替代显式 RL 优化，使末位自奖励分数 $r_s$ 对齐验证器奖励 $r_v$。进一步地，由于参考模型在 $z_c$ 上的对数概率在所有问题与解中近似为常数，LaSeR 将其预计算为 $c_{\text{ref}}$，简化为：

$$ r_s = \beta_v \log \pi_\theta(z_c | \mathbf{x}, \mathbf{y}) - \beta_v c_{\text{ref}} $$

此简化消除了对参考模型的前向传播需求，仅需策略模型单次前向即可计算分数。MSE 损失直接加入 GRPO 总损失，实现推理与自验证的无缝联合优化。

## 实验评估

实验基于 DeepMath-103K 训练，在 MATH500、AMC23、AIME24/25、OlympiadBench 上评估，基线为 GRPO。LaSeR 在 Qwen2.5-7B-Base 上 MATH500 达 80.2%，较 GRPO 的 79.9% 提升 0.3 个点；在 Open-Reasoner-Zero-7B 上 AIME24 达 19.1%，较 GRPO 的 18.1% 提升 1.0 个点。自验证 F1 分数方面，LaSeR 在 ORZ-7B 上达 77.6%，接近 72B 外部奖励模型的 76.8%。

| 模型 | 方法 | MATH500 | AIME24 | 自验证 F1 (Avg) |
| :--- | :--- | :--- | :--- | :--- |
| Qwen2.5-7B-Base | GRPO | 79.9 | 16.2 | 49.2 |
| Qwen2.5-7B-Base | LaSeR | 80.2 | 15.4 | 79.6 |
| Open-Reasoner-Zero-7B | GRPO | 83.1 | 18.1 | 38.8 |
| Open-Reasoner-Zero-7B | LaSeR | 82.8 | 19.1 | 77.6 |

消融实验显示，移除自奖励优势（-SWA）后，ORZ-7B 的 MATH500 从 82.8 降至 83.2（注：原文表格中 -SWA 为 83.2，LaSeR 为 82.8，此处以原文为准，LaSeR 略低但自验证 F1 更高），表明自奖励优势对推理精度的贡献有限，主要收益体现在自验证能力上。参考模型常数简化（w/ Simpl.）对推理精度影响微小（ORZ-7B MATH500 从 82.5 降至 81.0），但显著提升了计算效率。

评估边界方面，论文未报告置信区间，且 AIME24 上 19.1% 的成绩远低于领域 SOTA（如 PIPO 的 55.31%），可能源于训练数据分布或模型规模差异。代码已开源，但超参数细节未完全披露，可复现性依赖社区实现。

## 关联研究分析

从问题动机看，LaSeR 与 SC-GRPO 均追求无外部资源的细粒度信用分配，但 SC-GRPO 依赖原始策略与自条件教师策略间的 token 级 KL 散度，需构建额外教师模型；LaSeR 则直接从末位 token 概率提取信号，计算成本更低，但牺牲了对中间步骤的归因能力。从方法设计看，LaSeR 与 Token Hidden Reward 均利用策略梯度隐含信号，但 Token Hidden Reward 分析正负样本中 token 预测错误的相似度，需额外计算相似度矩阵；LaSeR 将信号压缩至单点，效率更高，但依赖末位 token 概率对全局正确性的敏感性，这一假设在长序列中是否成立，论文未给出验证。

## 总结

LaSeR 解决的核心矛盾是测试时验证信号缺失与自验证生成成本过高的冲突。其切入点在于发现模型末位 token 概率分布隐含正确性评估，通过理论推导将自验证目标简化为 MSE 对齐，以单次前向传播实现联合优化。实验证明该方法在 Qwen2.5-7B 上将自验证 F1 从 49.2 提升至 79.6，接近 72B 外部模型水平。其边界在于，末位 token 概率对全局正确性的依赖在长序列或开放域任务中可能失效，且推理精度提升有限。当序列长度增加至数千 token 时，末位 token 概率是否仍能可靠反映早期步骤的正确性，论文未给出回答。
