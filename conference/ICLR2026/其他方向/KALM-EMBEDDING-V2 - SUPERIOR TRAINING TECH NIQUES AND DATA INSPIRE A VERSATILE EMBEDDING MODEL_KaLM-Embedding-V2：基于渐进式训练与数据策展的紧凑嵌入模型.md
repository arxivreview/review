# ICLR2026最新论文 ｜KALM-EMBEDDING-V2: SUPERIOR TRAINING TECH NIQUES AND DATA INSPIRE A VERSATILE EMBEDDING MODEL ｜KaLM-Embedding-V2：基于渐进式训练与数据策展的紧凑嵌入模型

研究机构：同济大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_58920904)

> 文本嵌入模型旨在将变长文本映射为固定长度稠密向量，其核心价值在于为检索、推荐及检索增强生成（RAG）提供语义匹配的基础设施。现有主流 LLM 适配方案多聚焦于数据规模扩张或合成数据生成，对训练技术细节与数据质量缺乏系统性探索，导致小参数模型性能受限。本文通过移除因果掩码实现双向注意力，并构建“预训练-微调-对比蒸馏”三阶段渐进式训练流程，结合 Focal 重加权与在线难负样本混合策略，在 0.5B 参数规模下实现了 MTEB 中文与英文子集的 SOTA 性能。该工作证明了训练策略与数据质量对紧凑模型上限的决定性作用，但其多阶段流程的复杂性与小模型在长文本场景下的泛化能力仍存疑。

## 研究背景

当检索系统面对复杂查询时，单一向量表示往往难以捕捉细粒度语义差异，导致召回率瓶颈。这一困境源于 LLM 因果注意力的局部性与嵌入任务全局语义需求之间的冲突：直接复用 LLM 的单向机制无法充分聚合上下文信息，而传统双向编码器又缺乏 LLM 的深层语义知识。解决这一冲突的关键在于架构改造与训练策略的协同优化，即通过双向化改造释放 LLM 的表示潜力，同时通过精细化的训练流程弥补小模型的知识容量不足。

当前 LLM 嵌入适配路线的主流做法是移除因果掩码并启用双向注意力，如 LLM2Vec 和 NV-Embed 所示，但多数工作将重点放在数据规模或合成数据上，忽视了训练目标与数据质量的系统性设计。标准 InfoNCE 损失对易样本与难样本一视同仁，导致优化方向被大量易样本主导，而离线挖掘的难负样本在训练后期逐渐失效，无法提供持续的信息量。此外，现有 SOTA 模型多源自工业界，存在数据封闭、代码不可复现等问题，学术界缺乏兼具高性能与高透明度的紧凑模型基准。

本文的切入点在于系统性地优化训练技术与数据策展策略，而非单纯扩大数据规模。通过引入 Focal 风格重加权机制强调难样本，提出在线难负样本混合策略维持训练后期的信息量，并构建涵盖 20+ 预训练与 100+ 微调类别的高质量数据配方，KaLM-Embedding-V2 在 0.5B 参数规模下实现了与 3-26 倍更大模型竞争的性能，为开源紧凑嵌入模型树立了新标准。

## 核心方法

### 方法参照系

本文基于 Qwen2-0.5B 骨干，移除因果掩码启用双向注意力，采用 Mean Pooling 生成固定长度嵌入。与标准 LLM 适配流程（如 E5 或 GTE）相比，关键差异在于引入了多阶段渐进式训练流程与改进的对比学习目标，而非单阶段微调。

### 渐进式多阶段训练流程

标准 LLM 嵌入训练通常采用单阶段对比学习微调，但小模型在弱监督数据上易受噪声干扰，难以直接收敛到高质量嵌入空间。本文设计了三阶段渐进式流程：首先在大规模弱监督数据集上进行预训练，建立粗粒度语义表示；其次在高质量监督数据集上进行微调，细化任务特定语义；最后通过对比蒸馏引入细粒度软信号，捕捉正负样本间的细微差异。该流程逐步从粗粒度到细粒度激励 LLM 的嵌入能力，避免了小模型在噪声数据上的过拟合。

### Focal 重加权与在线难负样本混合

标准 InfoNCE 损失对每个样本赋予相同权重，导致优化方向被易样本主导，难样本学习不足。本文引入 Focal 风格重加权机制，根据样本难度动态调整损失权重，使模型更关注难样本。同时，针对离线挖掘的难负样本在训练后期失效的问题，提出在线难负样本混合策略，通过成对或列表式混合现有难负样本的特征，合成新的难负样本，维持训练过程中的信息量。

$$
\mathcal{L}_{\text{focal}} = -\sum_{i=1}^{N} w_i \log \frac{\exp(s(q_i, p_i^+)/\tau)}{Z_i}
$$

其中 $w_i = (1 - p_i)^{\gamma}$ 为 Focal 权重，$p_i$ 为样本 $i$ 的预测概率，$\gamma$ 为聚焦参数。该公式通过降低易样本的权重，迫使模型集中计算资源于难样本，提升细粒度区分能力。

$$
\mathbf{h}_{i}^{-} = \frac{\lambda \mathbf{p}_{i,j}^{-} + (1-\lambda) \mathbf{p}_{i,k}^{-}}{\|\lambda \mathbf{p}_{i,j}^{-} + (1-\lambda) \mathbf{p}_{i,k}^{-}\|_2}
$$

其中 $\lambda \sim \text{Beta}(2, 2)$，$\mathbf{p}_{i,j}^{-}$ 和 $\mathbf{p}_{i,k}^{-}$ 为随机抽取的难负样本。该公式通过线性插值合成新的难负样本，避免重新挖掘的高计算成本，同时保持难负样本的语义相关性。

## 实验评估

实验在 MTEB (cmn, v1) 和 MTEB (eng, v1) 上进行，基线覆盖 Qwen3-Embedding、NV-Embed、bge-m3 等主流开源模型，但缺失工业界闭源 API（如 Cohere）的详细对比。

| 模型 | 参数量 | MTEB (cmn, v1) MTK | MTEB (eng, v1) MTK |
| :--- | :--- | :--- | :--- |
| KaLM-Embedding-V2.5 | 494M | 70.93 | 69.33 |
| Qwen3-Embedding-0.6B | 596M | 66.33 | 66.76 |
| Qwen3-Embedding-8B | 8B | 73.84 | 73.08 |
| NV-Embed-v2 | 7B | 68.52 | 72.31 |

KaLM-Embedding-V2.5 在 <1B 参数规模内达到 SOTA，MTEB (cmn, v1) 分数 70.93 超越同规模 Qwen3-Embedding-0.6B 的 66.33，但绝对分数仍低于 8B 级模型，验证了紧凑性与性能的权衡。

消融实验显示，移除 Focal 重加权导致 MTEB (cmn, v1) 分数从 70.93 降至 69.41，降幅 1.52 分，表明难样本学习对整体性能的关键作用。移除在线难负样本混合导致分数降至 70.54，降幅 0.39 分，说明该策略在训练后期维持信息量的有效性。移除双向注意力导致分数降至 70.50，降幅 0.43 分，验证了双向机制对嵌入质量的贡献。

| 设置 | MTEB (cmn, v1) MTK | MTEB (eng, v1) MTK |
| :--- | :--- | :--- |
| KaLM-Embedding-V2.5 | 70.93 | 69.33 |
| w/o Focal-style Reweighting | 69.41 | 68.70 |
| w/o Hard Negative Mixing | 70.54 | 68.91 |
| w/o Bidirectional Attention | 70.50 | 68.94 |

评估边界方面，论文未报告置信区间，数值比较需谨慎；最大输入长度限制为 512 tokens，长文本场景下的泛化能力未充分验证；代码、数据与模型已开源，超参数与 GPU 配置详细披露，可复现性高。

## 关联研究分析

从问题动机看，本文与 LLM2Vec 和 NV-Embed 均聚焦于解决 LLM 因果注意力与嵌入任务全局语义需求的冲突，但 LLM2Vec 仅通过架构改造实现双向化，NV-Embed 引入潜在注意力层，而本文进一步通过多阶段训练与改进的对比学习目标优化小模型的表示质量。这一差异源于任务特性：小模型知识容量有限，单纯架构改造不足以弥补知识缺口，需通过精细化训练策略提升数据利用效率。

从方法设计看，本文与 E5 系列均采用对比学习框架，但 E5 依赖大规模弱监督数据与指令微调，本文则强调数据质量与训练目标优化。E5 在数据充足时表现优异，但本文的 Focal 重加权与在线难负样本混合策略在数据有限或噪声较多时更具优势。查询侧增强在数据充足时是否仍有增益，论文未给出回答，这限制了该方法在大规模数据场景下的适用性评估。

## 总结

本文要解决的核心矛盾是小参数 LLM 嵌入模型在紧凑性与性能之间的权衡，现有方法多聚焦数据规模扩张，忽视了训练技术与数据质量的系统性优化。本文抓住的切入点是多阶段渐进式训练流程与改进的对比学习目标，通过 Focal 重加权强调难样本、在线难负样本混合维持信息量，以及高质量数据策展，在 0.5B 参数规模下实现了 MTEB (cmn, v1) 70.93 和 MTEB (eng, v1) 69.33 的 SOTA 性能。本文的边界在于最大输入长度限制为 512 tokens，长文本场景下的泛化能力未充分验证，且多阶段训练流程的复杂性与计算成本较高。当输入长度超过 512 tokens 时，该模型的性能衰减程度与长文本适配策略的有效性，论文未给出回答。
