# ICLR2026最新论文 ｜Robust Optimization for Mitigating Reward Hacking with Correlated Proxies ｜基于相关代理奖励的鲁棒策略优化

研究机构：美国杜兰大学

作者：Zixuan Liu、Xiaolin Sun、Zizhan Zheng

论文原文见 [arXiv](https://arxiv.org/abs/2604.12086)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.12086)

> 导读 在真实强化学习场景中，智能体依赖近似真实目标的代理奖励进行训练，但优化压力往往导致其利用代理与真实目标间的偏差获取高代理回报而牺牲真实效用，即奖励黑客。现有缓解方法如占用正则化策略优化（ORPO）仅针对固定代理奖励进行正则化，无法应对代理奖励本身存在不确定性或对抗性偏差的情况，且缺乏对策略行为的可解释性。本文提出最大-最小策略优化框架，将奖励黑客形式化为在$r$-相关代理奖励集合上的最坏情况优化问题，并引入线性特征结构假设以推导闭式解。该方法在五个真实感环境中显著提升了最坏情况回报，但其鲁棒性上限受限于线性特征假设的准确性，且在非线性动态系统中的泛化能力尚未得到充分验证。

## 研究背景

当智能体在交通控制或医疗决策等安全关键领域部署时，设计者难以构建完美捕捉真实目标的奖励函数，只能依赖从噪声数据或启发式规则中推导的代理奖励。这种代理与真实目标间的偏差在优化过程中被放大，导致智能体在未被参考策略访问的状态-动作空间中寻找漏洞，产生高代理回报但低真实效用的行为。为量化这种偏差，Laidlaw等人定义了$r$-相关代理奖励：若代理奖励与真实奖励在参考策略分布下的相关系数大于$r$，则称其为$r$-相关。这一框架允许代理与真实奖励在参考策略未覆盖的区域任意偏离，正是智能体可能利用的漏洞所在。

奖励黑客缓解的主流路线分为架构派与优化派。架构派如CausalRM通过因果分解阻断虚假相关，优化派如ORPO通过正则化约束策略偏离参考分布。然而，ORPO的核心局限在于其仅针对单一固定代理奖励提供保证，当代理奖励本身存在设计不确定性或对抗性选择时，其最坏情况性能保证较弱。此外，ORPO将奖励函数视为黑盒，无法解释策略为何避免黑客行为，难以满足安全关键领域对可解释性的监管要求。本文切入点在于将鲁棒性来源从“正则化约束”转变为“对抗性代理选择”，通过优化所有$r$-相关代理中的最坏情况，显式应对代理设计的不确定性，同时引入线性结构假设以增强可解释性。

## 核心方法

### 方法参照系

本文问题属于黑客缓解策略中的鲁棒优化路线，与ORPO共享$r$-相关代理奖励定义和占用度量框架。关键差异在于：ORPO优化固定代理下的正则化目标，而本文优化$r$-相关代理集合上的最大-最小目标，将鲁棒性从“偏离惩罚”升级为“最坏情况对抗”。

### 最大-最小策略优化

ORPO通过$\chi^2$散度正则化限制策略偏离参考分布，但其正则化强度$\sigma_{R_{proxy}}\sqrt{1-r^2}$仅针对单一代理。本文将内层最小化转化为对$r$-相关奖励集合的对抗选择，利用Radon-Nikodym导数$L(s,a) = \mu_\pi(s,a)/\mu_{\pi_{ref}}(s,a)$进行测度变换，将目标重写为参考策略下的期望。通过拉格朗日对偶求解内层最小化，得到闭式最坏情况奖励：

$$R^*(s,a) = \frac{L(s,a) - \lambda_1 R_{proxy}(s,a) - \lambda_2}{2\lambda_3}$$

该公式表明，在参考策略未访问的区域（$L$极大），对抗奖励可任意低，迫使策略避免探索这些区域。最终策略优化目标为最大化代理奖励减去$\chi^2(\mu_\pi \| \mu_{\pi_{ref}}) - \mathbb{E}_{\mu_\pi}[R_{proxy}]^2$的惩罚项，相比ORPO，其正则化强度为$r$而非$\sigma_{R_{proxy}}\sqrt{1-r^2}$，且惩罚项包含代理奖励期望的平方项，更精确地捕捉分布偏移与奖励偏差的交互作用。

### 线性特征白化与可解释性

最大-最小框架的奖励不确定性集过宽可能导致过度保守，且最坏情况奖励不可解释。本文假设真实奖励为已知特征的线性组合$R(s,a) = \boldsymbol{\theta}^\top \boldsymbol{\phi}(s,a)$，将不确定性限制在特征权重$\boldsymbol{\theta}$上。通过Cholesky分解对特征向量进行白化变换$\boldsymbol{\phi}_{\tilde{}}(s,a) = Q^{-1/2}\boldsymbol{\phi}(s,a)$，使协方差矩阵$Q$变为单位阵，将内层最小化转化为标准凸二次规划。最优权重闭式解为：

$$\boldsymbol{\theta}^* = \max\left(0, -\frac{u_{\lambda_1,\lambda_2}(s,a) \boldsymbol{\phi}(s,a)}{\lambda_3}\right)$$

该解表明最坏情况奖励是特征的稀疏线性组合，权重直接揭示策略对哪些特征维度脆弱。例如，在交通环境中，若$\theta_{velocity}$权重极高，表明策略对速度特征的偏差最敏感。这一设计解决了ORPO无法利用奖励结构先验的问题，使策略鲁棒性可被诊断和解释。

## 实验评估

实验在Traffic、Pandemic、Glucose、Tomato和RLHF五个环境中进行，基线包括ORPO、ORPO*（充分训练判别器的ORPO）和Ensemble。ORPO*的引入隔离了判别器训练充分性对鲁棒性的贡献，但缺失CausalRM、PRISM等架构派方法作为对比，无法评估优化派与架构派在相同环境下的相对优势。

| 环境 | 方法 | True Reward | Proxy Reward | Worst-Case Reward |
| :--- | :--- | :--- | :--- | :--- |
| Traffic | ORPO | 16.91±0.12 | 3.41±0.13 | -1.96e+04±0.02e+04 |
| Traffic | Max-Min | 12.70±0.06 | 3.63±0.09 | -268.31±4.14 |
| Traffic | Linear Max-Min | 16.46±0.10 | 2.40±0.11 | -1.19e+04±0.01e+04 |
| Pandemic | ORPO | -1.04±0.21 | 1.75±0.19 | -5.31e+06±0.01e+06 |
| Pandemic | Max-Min | 1.18±0.19 | 1.18±0.19 | -63.29±3.35 |
| Pandemic | Linear Max-Min | 3.65±0.11 | 7.60±0.13 | -6.82e+05±0.01e+05 |
| Glucose | ORPO | 6.0±0.1 | 100.48±0.54 | -27.54±0.32 |
| Glucose | Max-Min | 6.3±0.1 | 102.66±0.58 | -1.71±0.25 |
| RLHF | ORPO | 8.30±1.07 | 0.63±0.21 | -1.84±0.03 |
| RLHF | Max-Min | 5.38±0.92 | 0.84±0.11 | -0.10±0.01 |

Max-Min在Traffic和Pandemic环境的最坏情况回报显著优于ORPO（-268.31 vs -1.96e+04，-63.29 vs -5.31e+06），但Linear Max-Min在Traffic环境的最坏情况回报（-1.19e+04）劣于Max-Min，表明线性假设在特征结构不匹配时可能削弱鲁棒性。ORPO*的最坏情况回报优于ORPO，证实判别器训练充分性对占用估计准确性至关重要。

消融实验显示，Linear Max-Min在Linear Worst*评估（使用训练时未见特征）中性能下降，而Max-Min性能稳定，表明线性假设的鲁棒性依赖于特征结构的准确性。ORPO*与ORPO的差异主要源于判别器训练步数，Traffic环境中判别器损失从1.4降至0.2，占用估计误差显著降低。

评估边界方面，RLHF环境使用Pythia-70M作为代理奖励模型，Llama 3 Tulu V2 8B作为真实奖励模型，但指标为Return而非准确率，无法与SignCert-PO等SOTA缓解策略直接比较。代码开源，超参数完整，但训练时间增加（Glucose环境从7小时增至37小时），内存开销可忽略（<50MB）。

## 关联研究分析

从问题动机看，本文与ORPO同属优化派，但ORPO假设代理奖励固定，本文假设代理奖励在$r$-相关集合内变化。这一差异源于任务特性：ORPO适用于代理奖励设计明确但存在偏差的场景，本文适用于代理奖励设计本身存在不确定性或对抗性选择的场景。然而，本文未评估当代理奖励偏差超出$r$-相关约束时的鲁棒性，而ORPO的正则化项在偏差较大时可能提供更强的约束，两者在极端偏差场景下的相对优势未得到验证。

从方法设计看，本文与CausalRM同追求可解释性，但CausalRM通过因果分解学习潜在变量，本文通过线性特征白化推导权重。CausalRM的可解释性源于学习到的因果结构，本文的可解释性源于先验特征工程。这一差异暗示：当真实奖励结构未知时，CausalRM可能更具优势；当特征结构已知时，本文的闭式解更高效。但本文未验证线性特征假设在非线性动态系统（如Glucose）中是否导致鲁棒性上限受限，而CausalRM的因果分解可能更适应非线性关系。

## 总结

本文要解决的核心矛盾是代理奖励不确定性下的鲁棒性保证与策略可解释性缺失。现有方法如ORPO仅针对固定代理提供正则化保证，无法应对代理设计的不确定性，且黑盒策略难以解释。本文抓住“对抗性代理选择”这一被忽略的点，通过最大-最小框架显式优化最坏情况，并引入线性结构假设推导闭式解，实现了鲁棒性与可解释性的统一。实验证明Max-Min在Traffic和Pandemic环境的最坏情况回报显著优于ORPO（-268.31 vs -1.96e+04），但Linear Max-Min在特征结构不匹配时鲁棒性下降。本文的边界在于线性假设的准确性依赖，当真实奖励为非线性组合时，最坏情况奖励的推导可能失效。当Glucose环境中的健康风险指标与患者成本指标存在非线性交互时，线性特征白化是否仍能捕捉最坏情况偏差，论文未给出回答。
