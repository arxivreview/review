# ICLR2026最新论文 ｜A Scene is Worth a Thousand Features: Feed-Forward Camera Localization from a Collection of Image Features ｜稀疏特征集合的前馈视觉定位

研究机构：英国牛津大学

作者：Axel Barroso-Laguna、Tommaso Cavallari、Victor Adrian Prisacariu 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.00978)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.00978)

> 视觉定位旨在从单张图像估计相机在已知场景中的六自由度位姿，其核心瓶颈在于地图构建的高昂时间与存储成本。传统结构定位需数小时构建稀疏点云，场景坐标回归（SCR）虽将训练时间压缩至分钟级，却仍依赖场景特定训练且泛化性差。本文切入点在于证明仅凭数百个锚定在三维空间的图像特征即可构成有效地图表示，通过单次前馈推理同时完成建图与定位。该范式在免训练场景下实现了与需训练方法相当的精度，但其对动态场景的鲁棒性及特征采样策略的最优性仍存疑。

## 研究背景

当定位器面对未见过的查询图像时，其性能直接受制于场景表示的完备性与获取成本。结构从运动（SfM）构建的稀疏点云虽几何精度高，但特征三角化耗时随图像数量线性增长，难以满足实时应用需求。为降低这一开销，场景坐标回归（SCR）与绝对位姿回归（APR）通过端到端网络学习隐式场景表示，将建图时间缩短至分钟级，但这类方法需针对每个场景单独训练网络，且在新视角或未见区域泛化能力不足。相对位姿回归（RPR）虽无需场景特定训练，但通常依赖双视图几何求解，精度低于结构定位与SCR，且多视图三角化后处理显著增加了推理延迟。

现有方案在“建图速度”与“定位精度”之间难以兼得：结构定位精度高但建图慢，SCR/APR建图快但需训练且泛化弱，RPR免训练但精度低。本文的核心切入点是重新定义地图表示的最小充分条件——不再依赖稠密点云或训练好的网络权重，而是利用从多张位姿已知的映射图像中随机采样的稀疏特征集合，结合基础模型的几何推理能力，在单次前馈中直接预测查询图像在地图坐标系下的三维坐标。这一设计旨在消除场景特定训练环节，同时保留多视图几何约束以克服RPR的精度瓶颈。

## 核心方法

### 方法参照系

本文问题可归类于绝对位姿回归（APR）范畴，但与传统APR直接回归旋转平移参数不同，FastForward回归查询图像像素在地图坐标系下的三维坐标，再通过透视n点-随机采样一致性（PnP-RANSAC）求解位姿。其关键差异在于地图表示并非训练好的网络权重或稠密点云，而是由随机采样的映射图像特征与射线编码构成的动态集合，且整个流程无需场景特定训练。

### 稀疏特征地图表示与归一化

传统SfM地图需存储海量描述符，SCR地图隐含于网络权重中，二者均导致建图时间或存储开销巨大。FastForward将地图表示重构为从K张映射图像中随机采样的N个特征向量集合，每个特征向量融合其对应的射线编码以保留三维位置信息。为消除不同场景尺度差异对网络泛化的影响，引入场景与尺度归一化：将其中一张映射图像位姿设为原点，计算所有映射相机平移向量的最大模长作为场景尺度$s$，并将所有平移向量除以$s$进行归一化。射线编码通过傅里叶编码将归一化后的相机原点$\hat{t}_k$与视线方向$r_{ij}^k$映射为高维向量，再经多层感知机（MLP）投影至与特征向量相同的维度$d$。该设计动机在于解耦几何尺度学习与视觉特征匹配，使网络能泛化至训练时未见的尺度范围。

$$
\mathcal{M} = \{ \mathbf{R}_{n} + \mathbf{f}_{n} \mid n = 1, \dots, N \}, \quad \mathbf{R}_{ij}^k = \text{MLP}(\text{Fourier}(\hat{t}_k, r_{ij}^k))
$$

该公式定义了地图表示$\mathcal{M}$，其中每个元素是射线编码与图像特征的逐元素相加，确保每个特征都携带其三维空间来源信息。

### 编码器-解码器架构与置信度损失

标准RPR方法需逐对计算查询与映射图像的相对位姿，计算复杂度随映射图像数量线性增长。FastForward采用基于DUSt3R初始化的ViT编码器提取查询与映射图像特征，冻结编码器权重以保留预训练几何先验。解码器引入交叉注意力机制，使查询特征能直接关注整个地图特征集合，在单次前馈中完成多视图几何推理，避免了逐对位姿估计的冗余计算。查询头采用DPT头预测三维坐标，映射头采用单层MLP提供额外监督。训练损失采用置信度加权回归，允许网络在天空或半透明物体等歧义区域预测低置信度，避免错误坐标主导梯度更新。

$$
\mathcal{L} = \sum_{i \in D} C_i \| \mathbf{X}_i - \bar{\mathbf{X}}_i \| + \alpha \sum_{i \in D} (1 - C_i)
$$

该损失函数中$C_i$为像素置信度，第一项为置信度加权的坐标回归误差，第二项为置信度正则化项，$\alpha$控制正则强度，整体鼓励网络在不确定区域降低置信度而非强行预测。

## 实验评估

实验在Wayspots、Indoor6、RIO10及Cambridge Landmarks四个基准上进行，对比方法覆盖SCR（ACE, GLACE）、RPR（Reloc3r, E5+1）及结构定位（hLoc, MASt3R+Kapture）。基线覆盖较全面，但缺少2025-2026年最新SOTA如GRLoc、ULF-Loc，可能高估了本文方法的相对优势。

| 数据集 | 方法 | 平移误差 (m) | 旋转误差 (°) | 10cm,10° 准确率 (%) | 建图时间 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Wayspots (Unseen) | FastForward | 0.17 | - | 51.4 | 3s |
| Wayspots (Unseen) | Reloc3r | 1.31 | - | 37.1 | 3s |
| Wayspots (Unseen) | E5+1 (RoMa) | 0.77 | - | 49.5 | 3s |
| Cambridge (Unseen) | FastForward | 0.27 | 0.4 | - | ~30s |
| Cambridge (Unseen) | Reloc3r | 0.52 | 0.5 | - | - |
| Cambridge (Unseen) | MASt3R | 3.90 | 0.7 | - | ~30s |

在Wayspots未见场景中，FastForward以0.17m平移误差显著优于Reloc3r（1.31m）和E5+1（0.77m），验证了多视图特征融合对RPR精度瓶颈的突破。在Cambridge Landmarks未见场景中，FastForward（0.27m）远优于MASt3R（3.90m）和Reloc3r（0.52m），但据领域综述，GRLoc在该基准上达到2.9cm，表明免训练方法在精度上仍落后于需训练的最新SOTA。

消融实验未单独报告，但论文指出添加映射头监督可提升查询预测精度，且尺度归一化对跨域泛化至关重要。在RIO10动态场景中，FastForward的20cm,20°准确率（59.7%）高于MASt3R（58.2%），但10cm,10°准确率（45.1%）低于MASt3R（45.1%持平，但MASt3R在部分场景因对应点不足无法计算中位误差），暗示稀疏特征表示在细粒度动态变化下可能丢失细节。

评估协议存在局限：Cambridge Landmarks仅报告中位误差，未提供置信区间；RIO10因测试服务限制仅报告验证集结果；所有方法均未报告GPU内存占用与推理延迟的完整对比，FastForward声称运行时恒定，但缺乏量化数据。代码开源情况未在正文中明确说明，仅提供项目主页链接。

## 关联研究分析

从问题动机看，FastForward与Reloc3r同属基于DUSt3R的免训练定位方法，但Reloc3r依赖双视图相对位姿估计，需逐对计算后三角化，而FastForward通过多视图特征集合的单次前馈推理避免了这一冗余。这一差异的根源在于任务特性：Reloc3r将定位分解为多个独立的双视图问题，而FastForward将其建模为单一的多视图几何推理问题。然而，FastForward在RIO10动态场景中10cm精度未超越MASt3R，暗示当场景发生显著变化时，稀疏静态特征可能无法捕捉足够的细节，而MASt3R的全图像输入保留了更多上下文信息。

从方法设计看，FastForward与SCR方法（如ACE, GLACE）在输出形式上一致，均预测三维坐标，但SCR需场景特定训练，而FastForward利用预训练基础模型实现零样本泛化。这一差异源于对“地图表示”的不同理解：SCR将地图编码为网络权重，FastForward将地图编码为动态特征集合。FastForward的随机采样策略虽降低了计算开销，但未考虑特征的空间分布均匀性，可能在纹理稀疏区域导致地图表示偏差。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

FastForward要解决的核心矛盾是视觉定位中地图构建开销与定位精度的权衡。现有方法要么牺牲精度换取速度（RPR），要么牺牲速度换取精度（SCR/结构定位），而本文抓住的切入点是证明稀疏特征集合足以构成有效地图表示，并借助基础模型的几何推理能力在单次前馈中完成定位。该方法通过随机采样映射特征与射线编码构建地图，结合场景尺度归一化与置信度加权损失，在Wayspots未见场景实现0.17m平移误差，Cambridge Landmarks未见场景实现0.27m，显著优于同类免训练方法。其边界在于：在动态场景细粒度定位上未超越全图像输入方法，且随机采样策略未优化特征空间分布。当映射图像数量从数百张增加至数千张时，固定N值的随机采样是否会导致地图表示的信息瓶颈，论文未给出回答。
