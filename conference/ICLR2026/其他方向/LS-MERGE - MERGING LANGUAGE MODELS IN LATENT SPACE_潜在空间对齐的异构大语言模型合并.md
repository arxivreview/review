# ICLR2026最新论文 ｜LS-MERGE: MERGING LANGUAGE MODELS IN LATENT SPACE ｜潜在空间对齐的异构大语言模型合并

研究机构：韩国科学技术院、英国牛津大学

作者：Bedionita Soro、Aoxuan Zhang、Bruno Andreis 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_89882081)

> 模型合并旨在通过参数空间操作整合多个专家模型，以缓解海量微调模型部署时的存储与推理成本瓶颈。现有方法多假设架构同构，导致跨宽度或深度的异构模型合并因形状不匹配而失效。LS-Merge 将合并过程从原始权重空间转移至学习得到的潜在空间，通过变分自编码器（Variational Autoencoder, VAE）编码权重，并利用最优传输（Optimal Transport, OT）对齐异构分布，实现了单模型自增强与跨架构融合。该方法在异构场景下展现出优于传统权重插值的鲁棒性，但其对 VAE 训练稳定性的依赖及高压缩比下的泛化衰减仍存疑。

## 研究背景

当预训练大语言模型（Large Language Model, LLM）面临不同任务微调或不同架构迭代时，直接合并其参数往往因维度不匹配或分布偏移而失效。这一困境源于权重空间的几何特性：LLM 权重呈现低方差与重尾分布，且不同架构的权重张量在原始空间中缺乏统一的度量基准，导致线性插值等简单操作无法保持功能一致性。为理解这一现象，需引入流形嵌入理论，即假设高维权重数据集中于一个低维光滑流形上，存在可学习的投影映射将权重压缩至紧凑潜在空间，从而在统一维度下执行合并操作。

模型合并领域的主流路线长期聚焦于同构模型间的任务向量代数操作，如 Task Arithmetic 和 TIES-Merging，这些方法通过稀疏化与符号对齐消解参数干扰，但严格依赖共享初始化与架构一致性。当面对异构架构（如 Gemma 与 LLaMA 系列）或单模型自增强需求时，现有方法因缺乏跨架构对齐机制而陷入瓶颈。LS-Merge 的切入点在于将合并问题重构为潜在空间中的分布对齐与插值问题，通过生成式模型学习权重的内在流形结构，从根本上解耦了合并操作对架构同构性的依赖，为异构模型融合提供了新的几何基础。

## 核心方法

### 潜在空间编码参照系

传统模型合并直接在权重空间执行线性插值或任务向量加法，假设模型参数在欧氏空间中具有线性模式连通性。LS-Merge 的核心差异在于引入 VAE 作为权重编码器，将高维权重张量映射至固定维度的潜在空间，使得不同架构的模型在潜在空间中具有相同的维度表示，从而支持统一的插值操作。

### 重尾分布感知的 VAE 训练

LLM 权重分布具有显著的重尾特性，高峰度（kurtosis）表明存在少量高幅度参数对功能至关重要，这导致标准 VAE 训练易发生模式崩溃。LS-Merge 采用两阶段课程学习策略：首先训练确定性自编码器（关闭 KL 散度项）以收敛至高保真重建，随后启用 KL 项微调以结构化潜在空间。该设计动机在于避免早期训练阶段因重尾分布导致的优化不稳定，确保编码器能够保留罕见的功能关键参数。

$$
\mathcal{L}_{\beta\text{-VAE}} = \mathbb{E}_{q(z|x)}[\log p(x|z)] - \beta D_{KL}(q(z|x) || p(z))
$$

此公式定义了 VAE 的优化目标，其中 $\beta$ 控制重建保真度与潜在空间正则化之间的权衡，两阶段训练通过动态调整 $\beta$ 的有效作用来平衡重尾分布下的训练稳定性。

### 最优传输对齐与潜在插值

异构模型的潜在分布往往位于不相交的流形上，直接插值会产生位于目标解码器有效密度区域之外的无效权重。LS-Merge 将异构合并建模为流形配准问题，利用 OT 求解 Monge 问题，将源模型潜在分布 $\mu_s$ 映射至目标分布 $\mu_t$。在假设潜在分布为高斯的前提下，OT 映射具有闭式仿射解：

$$
T^*(z_s) = \mu_t + A(z_s - \mu_s), \quad A = \Sigma_s^{-1/2} \Sigma_s^{1/2} \Sigma_t \Sigma_s^{1/2} \Sigma_s^{-1/2}
$$

该公式通过调整均值与协方差，将源潜在向量对齐至目标分布的几何结构，消除架构差异导致的分布偏移。对齐后的潜在向量 $z_{\tilde{s}}$ 与目标潜在向量 $z_t$ 共享支持集，随后执行线性插值 $z_\lambda = (1-\lambda)z_t + \lambda z_{\tilde{s}}$，最后通过目标解码器 $D$ 重建合并权重。这一过程确保了合并后的潜在向量始终位于解码器的有效流形内，从而维持模型的功能完整性。

## 实验评估

实验在 Gemma-3 和 LLaMA-3 系列模型上进行，涵盖自合并、专家合并与跨架构合并场景。基线包括 Uniform Soup、Greedy Soup、SLERP、Task Arithmetic 及 AIM。在 Llama-2-13B 专家合并任务中，LS-Merge 在 MMLU 上达到 56.0，显著优于 Task Arithmetic 的 52.18 和 AIM 的 54.18；在 GSM8K 上，LS-Merge 取得 44.12，低于 AIM 的 46.20 但高于 Task Arithmetic 的 4.20。

| 方法 | MMLU | GSM8K | HumanEval |
| --- | --- | --- | --- |
| Task Arithmetic | 52.18 | 4.20 | 26.83 |
| AIM | 54.18 | 46.20 | 29.27 |
| LS-Merge | 56.0 | 44.12 | 28.14 |

消融实验表明，OT 对齐是异构合并的关键：在未对齐的跨家族合并中，性能显著下降，而引入 OT 对齐后，$\lambda=0.1$ 时取得最佳整体得分。此外，VAE 在压缩比 $r=1.6$ 时能恢复 96% 的基础模型 MMLU 性能，但在 $r=4$ 时性能急剧下降，表明高压缩比导致后验崩溃。

评估边界方面，论文未报告计算效率指标，且 VAE 训练依赖大量 GPU 资源。可复现性受限于 VAE 超参数（如学习率 $1e-4$）的敏感性，且未提供开源代码。跨架构合并仅在 1B 参数规模模型上验证，未探索更大规模模型的扩展性。

## 关联研究分析

从问题动机看，LS-Merge 与 Git Re-Basin 均旨在解决模型间的对称性/对齐问题，但 Git Re-Basin 通过显式重排神经元恢复线性模式连通性，依赖共享初始化假设；而 LS-Merge 通过生成模型隐式学习流形结构，无需共享初始化，适用于更广泛的异构场景。这一差异源于任务特性：Git Re-Basin 针对同构但不同初始化的模型，而 LS-Merge 针对架构差异导致的形状不匹配。

从方法设计看，LS-Merge 与 Fisher-Rao Manifold Merging 均关注参数空间的几何结构，但 Fisher-Rao 方法通过解析计算测地线距离来最小化方差坍缩，依赖局部二次假设；LS-Merge 则通过 VAE 学习非线性流形，能够处理更复杂的非高斯分布。LS-Merge 的优势在于无需计算 Fisher 信息矩阵，计算开销相对较低，但其性能依赖于 VAE 的训练质量，而 Fisher-Rao 方法的理论保证更为严格。

## 总结

LS-Merge 解决了异构 LLM 合并中因架构不匹配导致的操作无定义问题，其切入点在于利用 VAE 学习权重的非线性流形结构，并通过 OT 对齐消除分布偏移。该方法在 Llama-2-13B 专家合并中实现了 MMLU 56.0 的性能，优于 Task Arithmetic 和 AIM。然而，实验暴露了 VAE 在高压缩比下的泛化衰减问题，且仅在 1B 参数规模上验证了跨架构合并的有效性。当模型规模扩大至 7B 以上时，VAE 的训练稳定性与 OT 对齐的计算开销是否成为主要瓶颈，论文未给出回答。
