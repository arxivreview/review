# ICLR2026最新论文 ｜IMPLICIT REGULARIZATION OF SGD REDUCES SHORTCUT LEARNING ｜随机梯度下降的隐式正则化如何抑制捷径学习

研究机构：伊朗谢里夫理工大学、伊朗德黑兰大学

作者：Nahal Mirzaie、Alireza Alipanah、Ali Abbasi 等 10 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_77261515)

> 虚假相关导致模型在分布偏移下性能崩溃，现有去偏方法多依赖显式群体标签或复杂优化目标，工程部署门槛高。本文切入点在于优化器超参数本身：证明随机梯度下降（SGD）的隐式正则化机制能自然抑制对捷径特征的依赖，而全批梯度下降（GD）反而加剧此依赖。具体做法是在四点数据模型上建立理论保证，并在深度网络实证中验证小批大小与大学习率组合对最坏群体准确率的提升。该工作提供了无需修改损失函数或数据分布的“免费”鲁棒性增益，但其理论边界局限于线性模型，且实证增益幅度远小于显式去偏方法。

## 研究背景

当模型在训练数据中观察到特征与标签的统计关联时，优化器倾向于拟合那些能最大化分类间隔（Margin）的特征，即便这些特征在测试分布中不稳定。这种对简单捷径的偏好源于梯度下降算法的隐式正则化效应：离散化更新步骤使优化轨迹偏离精确的梯度流，转而跟随一个包含额外惩罚项的代理损失。对于全批梯度下降（GD），该惩罚项与全批梯度范数的平方成正比，引导模型寻找平坦极小值；而对于随机梯度下降（SGD），惩罚项还包含小批次间梯度方差的平均，这一额外项在数学上更强烈地抑制了依赖高方差捷径特征的解。

虚假相关研究的主流路线分为数据层面去偏与特征层面解耦。数据层面方法如 SAGE 通过生成少数群体样本平衡分布，特征层面方法如 SITAR 在潜在空间施加正则化，但两者均引入了额外的计算开销或架构修改。GroupDRO 等群体鲁棒性优化方法虽无需数据增强，但依赖显式群体标签，这在医疗影像等缺乏敏感属性标注的真实场景中难以部署。现有理论工作（如 Puli et al., 2023）多关注数据生成参数（如捷径强度 $\rho$ 和缩放因子 $B$）对捷径学习的影响，将优化器视为收敛到最大间隔解的黑盒，忽略了学习率 $\epsilon$ 和批大小 $b$ 等训练超参数在调制捷径依赖中的关键作用。本文旨在填补这一空白，揭示优化器动力学本身如何决定模型对捷径的依赖程度。

## 核心方法

### 方法参照系

本文问题属于“优化机制与理论”类别，旨在解释优化器超参数对捷径学习的影响。与显式去偏方法（如 GroupDRO 修改损失函数、SAGE 修改数据分布）不同，本文不改变训练目标或数据，仅通过调整 SGD 的批大小 $b$ 和学习率 $\epsilon$ 来利用其固有的隐式正则化效应，从而在标准经验风险最小化（ERM）流程中自然诱导鲁棒性。

### 四点数据模型与隐式正则化分解

设计动机在于建立一个能精确分离不变特征与捷径特征影响的理论载体，以量化优化器超参数的具体作用。本文采用四点数据模型，其中 $X_1=y$ 为完全信息不变特征（FIIF），$X_2=Bz$ 为捷径特征，$B>1$ 放大捷径影响。在指数损失下，SGD 的修改损失可分解为：

$$ C_{SGD}(\mathbf{w}) = C(\mathbf{w}) + \frac{\epsilon}{b} \left( \text{Var}[\hat{\rho}_{1:m}] + f(\mathbf{w}; B, \bar{\rho}) \right) $$

其中 $\text{Var}[\hat{\rho}_{1:m}]$ 是 $m$ 个小批次中捷径相关统计量 $\hat{\rho}$ 的方差，$f(\mathbf{w})$ 是依赖于权重 $\mathbf{w}$ 的函数。该公式表明，SGD 的隐式正则化强度与 $\epsilon/b$ 成正比。当 $B$ 较大或 $b$ 较小时，方差项主导，迫使优化器选择 $w_z$（捷径权重）较小、$w_y$（不变特征权重）较大的解，从而抑制捷径依赖。

### GD 与 SGD 的机制差异

设计动机在于解释为何 GD 无法提供相同的鲁棒性增益，甚至可能恶化捷径依赖。GD 的隐式正则化仅惩罚全批梯度范数 $\|\nabla C(\mathbf{w})\|_2^2$，缺乏对批次间梯度方差的抑制。理论证明（Theorem 3.1）显示，在 $B$ 足够大且样本量 $n$ 足够大时，GD 解 $w_z^{*, GD}$ 相对于梯度流解 $w_z^*$ 的恶化程度与学习率 $\epsilon$ 线性相关：

$$ w_z^{*, GD} - w_z^* \geq C \cdot \epsilon $$

其中 $C$ 为仅依赖于 $B$ 的常数。相比之下，SGD 解（Theorem 3.2）在 $b$ 足够小时，$w_z^{*, SGD} < w_z^*$，即向不变特征偏移。这一差异源于 SGD 通过小批次注入梯度噪声，该噪声在优化过程中起到了“去偏”作用，而 GD 的全批更新平滑了这种噪声，导致模型更倾向于拟合高间隔的捷径特征。

## 实验评估

实验在 ColorMNIST (CMNIST)、Domino、Waterbirds、CelebA 和 CIFAR10 等基准上进行，使用 MLP、ResNet 和 BERT 架构，评估指标为最坏群体准确率（WGA）和平均准确率（ACC）。基线审计方面，本文未直接对比 GroupDRO、IRM 或 SAGE 等显式去偏方法的具体数值，仅通过不同超参数组合的消融实验展示优化器本身的增益，这限制了其与 SOTA 去偏方法的直接竞争力评估。

| 数据集 | 批大小 $b$ | WGA (mean ± std) | $\Delta$ (max-min) |
| :--- | :--- | :--- | :--- |
| CMNIST | 8 | 67.5 ± 1.1 | +3.7 |
| CMNIST | 256 | 64.7 ± 0.9 | |
| Domino | 8 | 59.3 ± 5.3 | +15.9 |
| Domino | 256 | 43.4 ± 2.1 | |
| Waterbirds | 8 | 79.7 ± 0.8 | +11.5 |
| Waterbirds | 256 | 68.2 ± 1.9 | |
| CelebA | 8 | 46.0 ± 1.0 | +11.4 |
| CelebA | 256 | 45.0 ± 1.3 | |
| CIFAR10 | 8 | 80.1 ± 2.2 | +3.8 |
| CIFAR10 | 256 | 77.9 ± 2.5 | |

在 Waterbirds 上，$b=8$ 时 WGA 为 79.7%，显著高于 $b=256$ 时的 68.2%，$\Delta$ 达 11.5%。CelebA 上 $b=8$ 时 WGA 为 46.0%，$b=256$ 时为 45.0%，$\Delta$ 为 11.4%。这些结果表明，小批大小能系统性地提升 WGA，且增益幅度在捷径关联较强的数据集（如 Domino）上最大（+15.9%）。然而，与领域综述中 SOTA 方法（如 DFR 在 Waterbirds 上 92.9%）相比，本文最佳 WGA（79.7%）仍有显著差距，说明仅靠优化器调整无法替代显式去偏方法。

消融实验显示，学习率对 WGA 的影响呈非单调性：在 ACC 达到近最优后，WGA 随学习率增加而上升，直至达到峰值后下降。这验证了理论中隐式正则化强度与 $\epsilon$ 的正相关关系，但过大的 $\epsilon$ 会导致收敛不稳定。在语言数据集 Multi-NLI 和 CivilComments 上，$b=8$ 时 WGA 分别为 76.75% 和 59.73%（$\epsilon=10^{-5}$），同样高于大批大小结果，证实了该效应在 Transformer 架构中的普适性。

评估边界方面，本文未报告计算效率指标，且理论证明局限于线性模型和指数损失，未推广至非线性深度网络。代码已开源，但超参数搜索范围有限，未探索动态调整批大小的策略。

## 关联研究分析

从问题动机看，本文与 SGD Shortcut Prioritization (2026) 形成互补。后者在 XOR 模型中理论证明 SGD 优先收敛到虚假特征解，侧重于描述现象；本文则通过隐式正则化机制解释了为何小批大小能逆转这一偏好。差异根源在于分析视角：前者关注优化动力学路径，后者关注优化器超参数对损失景观的修改。本文未探索 SGD 在极端稀疏捷径场景下的表现，而 SGD Shortcut Prioritization 的 XOR 模型可能更贴近此类场景。

从方法设计看，本文与 GroupDRO (2019) 存在根本差异。GroupDRO 通过修改优化目标（最小化最坏组损失）显式平衡群体性能，依赖群体标签；本文则通过调整优化器超参数隐式诱导鲁棒性，无需标签。这一差异源于对“鲁棒性来源”的不同假设：GroupDRO 假设鲁棒性需通过目标函数约束实现，本文假设鲁棒性可从优化器的归纳偏置中自然涌现。本文未对比 GroupDRO 在相同超参数下的表现，无法量化隐式正则化与显式目标优化的相对贡献。

## 总结

本文要解决的核心矛盾是：如何在缺乏显式群体标签和额外计算开销的情况下，提升模型对虚假相关的鲁棒性。现有方法如 GroupDRO 依赖标签，SAGE 依赖数据增强，均增加了部署复杂度。本文抓住的切入点是优化器超参数本身，证明 SGD 的隐式正则化能自然抑制捷径依赖。具体做法是在四点模型上建立理论保证，并在深度网络实证中验证小批大小与大学习率组合的有效性。实验证明，在 Waterbirds 上，$b=8$ 相比 $b=256$ 提升了 11.5% 的 WGA，但在 CelebA 上仅提升 1.0%。本文的边界在于理论局限于线性模型，且实证增益远小于显式去偏方法（如 DFR 的 92.9% WGA）。当捷径关联强度 $\rho$ 极小或 $B$ 极大时，所需的最小批大小 $b$ 是否趋于零，导致计算成本不可接受，论文未给出回答。
