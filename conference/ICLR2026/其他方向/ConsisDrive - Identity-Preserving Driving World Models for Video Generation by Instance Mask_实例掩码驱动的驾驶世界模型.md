# ICLR2026最新论文 ｜ConsisDrive: Identity-Preserving Driving World Models for Video Generation by Instance Mask ｜实例掩码驱动的驾驶世界模型

研究机构：中国科学技术大学

作者：Zhuoran Yang、Yanyong Zhang

论文原文见 [arXiv](https://arxiv.org/abs/2602.03213)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.03213)

> 生成式驾驶世界模型旨在通过数据驱动方式合成高保真视频以替代昂贵的人工标注，但现有扩散模型在长时序生成中普遍存在同一物体外观或类别随帧漂移的“身份漂移”问题，导致合成数据无法用于多目标跟踪等依赖时序稳定性的下游任务。本文切入点在于指出标准 MMDiT 的全注意力机制导致实例间信息泄漏，且均匀损失函数造成前景监督稀释。ConsisDrive 通过引入实例掩码注意力模块与实例掩码损失，在注意力层和训练目标层同时强制实例级时间一致性。该方法在 nuScenes 上实现了 SOTA 的感知与跟踪性能，但其对复杂遮挡场景下跨实例交互的建模能力尚存疑。

## 研究背景

驾驶世界模型的核心挑战在于生成视频需同时满足视觉真实感与语义一致性。当模型基于扩散模型（Diffusion Model）生成多帧视频时，每一帧的生成依赖于前序帧的潜在表示，这种自回归特性使得误差随时间累积。若模型缺乏对特定物体身份的显式约束，早期帧中微小的外观偏差会在后续帧中被放大，导致物体颜色改变甚至类别突变，即身份漂移。

现有主流路线如 MagicDrive-V2 和 DriveDreamer2 主要依赖全局时间注意力或场景级监督来维持整体连贯性。MagicDrive-V2 虽提升了全局时序一致性，但其注意力机制未区分不同实例，导致不同车辆的颜色特征相互渗透；DriveDreamer2 缺乏实例级条件输入，致使公交车在生成过程中逐渐变为卡车。这些方法的共同缺陷在于将“场景一致性”等同于“实例一致性”，忽略了多智能体交通场景中物体身份的独立性。ConsisDrive 针对这一盲区，提出将实例身份作为显式结构先验，嵌入到注意力计算与损失函数中，从机制上阻断跨实例的信息泄漏。

## 核心方法

### 方法参照系

ConsisDrive 基于 OpenSora V2.0 架构，采用 MMDiT 作为去噪骨干，并通过 ControlNet 注入 3D 边界框投影、道路地图及文本描述等条件。与标准视频生成流程的关键差异在于，本文未改变整体生成范式，而是在 MMDiT 的注意力层和损失计算层引入了实例感知的掩码机制，将全局连贯性约束细化为实例级约束。

### 实例掩码注意力机制

标准 MMDiT 的 3D 全注意力允许所有视觉 token 相互交互，导致不同实例的特征混合。ConsisDrive 引入实例掩码注意力（Instance-Masked Attention, IMA）模块，通过构建实例身份掩码和轨迹掩码，限制视觉 token 仅与其对应实例的 token 进行注意力交互。具体而言，对于视觉 token $v_k$ 和实例条件 token $g_i$，注意力分数通过掩码矩阵 $M$ 进行调制：

$$
\text{Attn}(v_k, g_i) = \begin{cases}
\text{softmax}(\frac{v_k W_Q g_i W_K^T}{\sqrt{d}}) & \text{if } I(v_k) \cap \{i\} \neq \emptyset \\
-\infty & \text{otherwise}
\end{cases}
$$

其中 $I(v_k)$ 为指示函数，返回覆盖 token $v_k$ 空间区域的实例 ID 集合。该公式的物理含义是：只有当视觉 token 位于某实例的投影边界框内时，它才能关注该实例的全局身份嵌入（包含类别、ID 和尺寸），从而在长序列中锚定物体的语义身份，防止类别漂移。同时，轨迹掩码确保同一实例在不同帧的 token 之间可以相互关注以传播颜色纹理，而不同实例间的交互被严格阻断，解决了 MagicDrive-V2 中颜色特征跨物体渗透的问题。

### 实例掩码损失监督

现有训练目标对整帧施加均匀 MSE 损失，由于背景像素（如天空、建筑）占据大部分画面，前景小物体（如行人）的梯度信号被稀释，导致其时序一致性易被破坏。ConsisDrive 设计实例掩码损失（Instance-Masked Loss, IML），通过概率性动态掩码策略，自适应地平衡前景聚焦损失与全局重建损失。其核心思想是利用实例掩码 $M_{loss}$ 对损失函数进行加权：

$$
\mathcal{L}_{IML} = \mathbb{E}_{t, \epsilon} \left[ \| \epsilon - \epsilon_\theta(x_t, t, c) \|^2 \cdot (M_{loss} \cdot \alpha + (1 - M_{loss}) \cdot (1-\alpha)) \right]
$$

其中 $\alpha$ 为前景权重系数，$M_{loss}$ 为基于 3D 框投影生成的前景掩码。该公式的含义是：在前景区域，损失权重被放大以强制模型关注细粒度的身份特征；在背景区域，权重降低以保留自然场景外观。这种设计避免了前景信号被背景噪声淹没，确保了小物体在生成视频中的时序稳定性。

## 实验评估

实验在 nuScenes 验证集上进行，对比基线包括 MagicDrive-V2、DriveDreamer2 和 Panacea。基线覆盖了基于 GAN 和扩散模型的主流路线，但缺失 3D 高斯泼溅（3DGS）类方法如 SymDrive 的对比，这可能影响对几何一致性维度的全面评估。

| 方法 | 数据增强 NDS (%) | 数据增强 mAP (%) | 验证集 NDS (%) |
| :--- | :--- | :--- | :--- |
| Oracle (Real) | 46.90 | - | - |
| Panacea | 32.10 (68.00%) | 22.5 (65.22%) | - |
| MagicDrive-V2 | 36.82 (78.51%) | - | - |
| ConsisDrive | 41.38 (88.23%) | 31.5 (91.3%) | 42.06 (89.68%) |

ConsisDrive 在数据增强感知任务中取得 41.38% 的 NDS，较 MagicDrive-V2 提升 4.56 个百分点，达到真实数据性能的 88.23%。在验证集评估中，其 NDS 为 42.06%，mAP 为 31.5%，显著优于 Panacea 的 22.5% mAP。

| 消融组件 | IDS (MOT) | FVD | NDS (Perception) |
| :--- | :--- | :--- | :--- |
| w/o Identity Mask | - | - | -3.83 |
| w/o Trajectory Mask | +549 | +16.43 | - |
| w/o IML | - | - | -4.53 |

消融实验显示，移除轨迹掩码导致多目标跟踪中的身份切换（IDS）增加 549 次，FVD 上升 16.43，证实了轨迹掩码在传播实例外观属性中的关键作用。移除实例身份掩码使感知 NDS 下降 3.83 点，表明全局身份条件对类别绑定的重要性。移除 IML 导致 NDS 下降 4.53 点，验证了前景聚焦损失对小物体生成的贡献。

评估边界方面，论文未报告 FID 指标，仅通过下游任务间接评估生成质量，这使得与 ConsistentCity（FID 8.3）等纯视觉质量 SOTA 方法的直接对比缺失。代码未公开，但提供了 64 张 A100 GPU 的训练配置，输入分辨率为 16x256x448，可稳定生成超过 200 帧。

## 关联研究分析

从问题动机看，ConsisDrive 与 ConsistentCity 均关注时序一致性，但技术路线截然不同。ConsistentCity 采用语义流引导的 Occupancy DiT，侧重于场景级的语义连贯；而 ConsisDrive 聚焦于实例级的身份保持，通过显式掩码阻断跨实例干扰。这种差异源于任务特性的不同：ConsistentCity 更关注场景结构的整体合理性，而 ConsisDrive 针对的是多智能体跟踪中对单个物体身份稳定性的严苛要求。ConsisDrive 的掩码机制是否能在物体频繁遮挡、边界框重叠的复杂场景中保持有效性，论文未提供相关实验数据，这构成了其方法适用性的潜在盲区。

从方法设计看，ConsisDrive 与 MagicDrive-V2 同属扩散模型框架，但 MagicDrive-V2 依赖全局时间注意力提升整体连贯性，而 ConsisDrive 引入实例感知注意力。MagicDrive-V2 的“前景稀释”问题源于其均匀损失函数，而 ConsisDrive 通过 IML 模块针对性解决。然而，ConsisDrive 的掩码机制基于 3D 边界框投影，这意味着其性能高度依赖于边界框标注的准确性。若边界框存在噪声或偏差，掩码将错误地阻断或允许注意力流动，可能导致新的不一致性。相比之下，基于隐式学习的方法如 SAGE 不依赖显式几何约束，可能在标注噪声较大的场景中更具鲁棒性，但牺牲了物理可行性。

## 总结

ConsisDrive 旨在解决扩散模型生成驾驶视频时的实例身份漂移问题，其切入点在于识别出标准 MMDiT 全注意力机制导致的跨实例信息泄漏及均匀损失造成的前景监督稀释。通过引入实例掩码注意力模块和实例掩码损失，该方法在机制层面强制了实例级时间一致性。实验表明，其在 nuScenes 上的数据增强感知 NDS 达到 41.38%，较 MagicDrive-V2 提升 4.56 点，且多目标跟踪 IDS 显著降低。然而，其方法依赖于精确的 3D 边界框投影，且在评估中缺乏 FID 等纯视觉质量指标的直接对比，限制了其与领域内其他 SOTA 方法的全面可比性。当边界框标注存在系统性偏差时，掩码机制是否会引入新的时序不一致，论文未给出回答。
