# ICLR2026最新论文 ｜Any-Subgroup Equivariant Networks via Symmetry Breaking ｜任意子群等变网络

研究机构：美国麻省理工学院、德国慕尼黑工业大学

作者：Abhinav Goel、Derek Lim、Hannah Lawrence 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.19486)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.19486)

> 等变神经网络旨在利用数据对称性提升泛化，但现有架构通常绑定单一预设群，导致跨域知识迁移受阻。ASEN 通过引入自对称群为目标子群的对称性打破输入，将大群等变基座映射为任意子群等变模型，实现了单一架构对多对称性的动态配置。该方法在图与序列任务中验证了灵活性，但其依赖先验子群选择且近似计算存在表达力边界，限制了其在完全未知对称性场景下的通用性。

## 研究背景

等变神经网络的核心在于将群作用嵌入架构，使得模型输出随输入对称变换同步变化。理解本文需掌握两个关键概念：群表示论提供的严格等变层设计，以及对称性打破（Symmetry Breaking）机制。前者通过权重共享实现 $f(gx)=gf(x)$，但要求数据完美对称；后者通过引入非对称特征破坏部分对称性，以换取表达力。当数据对称性未知或随任务变化时，严格等变架构因过度约束而无法拟合目标函数，而固定群架构又无法跨域复用，这构成了当前灵活等变建模的主要瓶颈。

现有主流路线分为两类：一是为每个群单独设计等变层，如 GCNNs 和 EGNNs，虽理论严谨但工程成本高且无法迁移；二是近似等变或软约束方法，如残差等变（Finzi et al., 2021），通过放松硬约束应对噪声，但缺乏对特定子群结构的精确控制。Blum-Smith et al. (2025) 等近期工作虽提出通过辅助输入实现子群等变，但局限于单任务场景，未解决多任务与迁移学习中的对称性复用问题。ASEN 的切入点在于将对称性打破从“数据增强”提升为“架构参数化”，通过一个统一的基座模型和可配置的对称性打破输入，实现单一网络对多种置换子群的等变建模，从而支持跨任务的表示共享。

## 核心方法

### 方法参照系

本文问题属于“架构设计与扩展”路线，但区别于传统为每个群定制等变层的流程。标准流程需针对目标群 $G$ 推导特定的等变层，而 ASEN 的关键差异在于：它不直接构建 $G$-等变层，而是利用一个更大群 $\mathbf{G}$ 的等变基座 $h_\theta$，通过引入自对称群为 $G$ 的输入 $\mathbf{v}$，间接实现 $G$-等变性。这种“大群基座 + 对称性打破”的范式，将架构设计问题转化为对称性打破对象的构造问题。

### 对称性打破与子群等变

设计动机在于解决固定群架构无法适配不同对称性任务的问题。ASEN 定义模型 $f_\theta(x) = h_\theta(x, \mathbf{v})$，其中 $h_\theta$ 是 $\mathbf{G}$-等变的，$\mathbf{v}$ 满足 $\text{Aut}(\mathbf{v}) = G$。

$$
f_\theta(gx) = h_\theta(gx, \mathbf{v}) = h_\theta(gx, g\mathbf{v}) = g h_\theta(x, \mathbf{v}) = g f_\theta(x), \quad \forall g \in G
$$

该公式表明，当 $g \in G$ 时，$\mathbf{v}$ 在 $g$ 作用下不变（$g\mathbf{v}=\mathbf{v}$），因此 $h_\theta$ 的 $\mathbf{G}$-等变性退化为 $G$-等变性。若 $h_\theta$ 对 $\mathbf{v}$ 是单射的，则 $f_\theta$ 仅对 $G$ 等变，而对 $\mathbf{G} \setminus G$ 中的元素不等变。这一机制使得同一基座 $h_\theta$ 可通过更换 $\mathbf{v}$ 适配不同子群，无需重新设计架构。

### 2-Closure 近似与高效构造

设计动机在于精确构造自对称群为 $G$ 的超图特征计算复杂度极高，可能需高阶张量。ASEN 采用 2-closure 群 $G^{[2]}$ 近似 $G$，即通过二阶张量（边特征）$A^{(2)}$ 编码节点对的轨道划分。

$$
\text{Aut}(A^{(2)}) = G^{[2]} \approx G
$$

算法 1 通过提升生成元至 $S_{n^2}$ 并计算轨道，生成边特征矩阵 $A^{(2)}$，使得 $\text{Aut}(A^{(2)})$ 等于 $G$ 的 2-closure。当 $G$ 是 2-closed 群时，$G^{[2]}=G$，实现精确等变；否则，$G^{[2]}$ 包含 $G$ 的额外对称性，引入近似误差。这种近似以计算效率（$O(rn^2)$）换取对称性精确度，使得 ASEN 能在图神经网络等实际场景中高效部署，避免了高阶超图构造的指数级开销。

## 实验评估

实验涵盖图学习（人体姿态、交通流）与序列任务（多任务/迁移学习），基线包括非等变模型及特定群等变模型，但缺乏与连续群 SOTA（如 EGNNs）的横向对比，因任务聚焦离散置换群。在人体姿态估计中，ASEN 通过选择不同子群（$I, S_2, S_2^2, S_6^2$）和图结构（全连接、稀疏），展示了对称性选择对性能的影响。

| 任务 | 模型/群 | 全连接 | 稀疏 | 弱稀疏 |
|---|---|---|---|---|
| 人体姿态 (P-MPJPE↓) | $I$ | 34.71 | **33.39** | 34.75 |
| | $S_2$ | 39.48 | 40.52 | **38.80** |
| | $S_2^2$ | 43.24 | 42.37 | **40.67** |
| | $S_6^2$ | 47.54 | 49.45 | **46.52** |
| 交通流 (MAE↓) | 全连接, $S_{n1} \cdot S_{n2}$ | 2.72 | - | - |
| | 稀疏, $S_{n1} \cdot S_{n2}$ | - | **2.69** | - |
| | 全连接, $S_{n1} \cdot \dots \cdot S_{n9}$ | 2.79 | - | - |
| | 稀疏, $S_{n1} \cdot \dots \cdot S_{n9}$ | - | 2.77 | - |
| | DCRNN, $S_n$ | 2.77 | - | - |

数据显示，在人体姿态任务中，稀疏图结构下 $I$ 群（无对称性）表现最佳（33.39），而对称性越强（$S_6^2$）性能越差（46.52），表明在特定图结构下，过度对称性约束可能损害表达力。交通流任务中，稀疏结构下 $S_{n1} \cdot S_{n2}$ 群（2.69）优于 DCRNN（2.77），验证了子群等变在特定对称性下的优势。

消融实验未单独报告，但通过对比不同群和图结构，揭示了 2-closure 近似的条件依赖性：当目标群非 2-closed 时，近似误差可能导致性能下降。论文未量化近似误差对下游任务的具体影响，仅通过实验结果间接反映。

评估边界方面，论文未报告置信区间，数值比较需谨慎。代码已开源，但超参数与 GPU 配置未详细披露，可复现性依赖社区实现。指标完备性上，P-MPJPE 和 MAE 是标准指标，但缺乏对称性质量诊断指标（如 SEIS），无法直接评估模型对称性结构的准确性。

## 关联研究分析

从问题动机看，ASEN 与 Frame Averaging (Puny et al., 2022) 均处理对称性，但 FA 通过平均所有参考帧实现后处理等变，适用于对称性已知且计算资源充足的场景；ASEN 则通过输入级对称性打破实现架构级控制，适用于对称性未知或需动态配置的场景。差异根源在于任务特性：FA 假设对称性完美，而 ASEN 承认对称性破坏的普遍性，通过参数化控制平衡表达力与对称性。

从方法设计看，ASEN 与 Residual Equivariance (Finzi et al., 2021) 均应对对称性破坏，但残差等变通过旁路非等变路径实现软约束，适用于噪声数据；ASEN 通过硬约束下的对称性打破实现参数化控制，适用于对称性明确但需灵活配置的场景。差异根源在于对称性破坏的性质：残差等变处理随机噪声，而 ASEN 处理结构性对称性变化。ASEN 的 2-closure 近似是否在高维连续群中保持表达力，论文未给出回答。

## 总结

ASEN 解决了固定群等变架构无法跨域迁移的核心矛盾，通过引入自对称群为目标子群的对称性打破输入，将大群等变基座映射为任意子群等变模型。该方法在人体姿态和交通流任务中验证了灵活性，稀疏图下 $I$ 群 P-MPJPE 33.39 优于 $S_6^2$ 群的 46.52，表明对称性选择需匹配数据结构。其边界在于依赖先验子群选择，且 2-closure 近似在非 2-closed 群中引入额外对称性，可能导致表达力损失。当目标群非 2-closed 时，近似误差对下游任务性能的具体影响量化了吗？
