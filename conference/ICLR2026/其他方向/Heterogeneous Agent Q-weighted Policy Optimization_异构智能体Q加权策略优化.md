# ICLR2026最新论文 ｜Heterogeneous Agent Q-weighted Policy Optimization ｜异构智能体Q加权策略优化

研究机构：国立台湾大学、新加坡南洋理工大学

作者：Bor Jiun Lin、Chun-Yi Lee

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_62620353)

> 多智能体强化学习（MARL）在异构场景下面临稳定性与表达力的根本冲突：传统值分解方法虽稳定但受限于单模态高斯策略，导致模式坍缩；生成式模型虽能建模多模态分布，却缺乏优化收敛保证。HAQO通过顺序优势感知更新、Q加权变分代理及熵正则化，将扩散策略纳入信任域优化框架，实现了理论保证与表达力的统一。该框架在多个基准上验证了有效性，但其计算开销与绝对性能上限仍存疑，特别是在与最新SOTA生成式方法的直接对比中处于劣势。

## 研究背景

当多个能力各异、观测空间不同的智能体需协同完成复杂任务时，联合动作空间的指数级增长与非平稳性使得传统独立学习或集中式方法失效。集中训练去中心化执行（CTDE）范式通过训练时共享全局信息、执行时依赖局部观测，成为解决部分可观测性问题的主流框架。然而，CTDE下的同时策略更新会导致优势函数估计失效，引发训练震荡；同时，异构智能体需要切换多种行为模式以适配不同伙伴，而标准高斯策略无法捕捉这种多模态分布，导致策略收敛至次优的单模态解。

现有方法在稳定性与表达力之间做出非此即彼的取舍。值分解方法（如QMIX）通过单调混合网络保证训练稳定，但受限于单调性约束，难以表达复杂的多模态协调行为；信任域方法（如HAML）通过顺序更新缓解非平稳性，但通常假设同质智能体，无法处理异构观测与动作空间。生成式策略（如扩散模型）虽能建模多模态分布，但其对数似然不可计算，导致经典策略梯度定理失效，缺乏单调改进保证。HAQO的切入点在于：将顺序更新机制与Q加权变分优化结合，为异构扩散策略建立理论完备的优化框架，从而在不牺牲表达力的前提下保证收敛性。

## 核心方法

### 方法参照系

HAQO基于CTDE范式，继承HAML（Zhong et al., 2024）的顺序更新机制以缓解非平稳性，并扩展QVPO（Ding et al., 2024）的Q加权变分目标至多智能体场景。与标准生成式MARL方法（如Diffusing to Coordinate）不同，HAQO不依赖在线采样效率优化，而是通过理论约束确保策略更新的单调改进，核心差异在于将扩散策略纳入信任域优化框架，解决了对数似然不可计算导致的优化失效问题。

### 顺序优势感知更新

同时更新异构智能体策略会导致优势函数相对于联合策略的定义失效，引发梯度冲突。HAQO采用随机顺序 $i_1: n$ 更新智能体，定义单智能体代理目标 $L_i(\pi_i) = \mathbb{E}_{s \sim \rho_{\pi_{old}}, a_{-i} \sim \pi_{new, -i}} [\mathbb{E}_{a_i \sim \pi_i} [A_i(s, a_i)]]$，其中 $a_{-i}$ 采样自已更新的其他智能体策略，而状态分布 $\rho_{\pi_{old}}$ 保持基线不变。该设计通过条件化于最新伙伴策略，使每个智能体的更新基于当前协调状态，避免同时更新导致的优势估计失效。为控制分布漂移，HAQO施加信任域约束 $\mathbb{E}_{s \sim \rho_{\pi_{old}}} KL(\pi_{old, i}(\cdot|s) \| \pi_i(\cdot|s)) \le \delta_i$，确保顺序更新的累积漂移为二次小量，从而获得单调改进保证。

### Q加权变分扩散目标

扩散策略的对数似然 $\log \pi_i(a_i|s)$ 不可计算，导致经典策略梯度无法应用。HAQO采用Q加权去噪目标作为策略改进代理：

$$J_i^{QV}(\theta_i) = \mathbb{E}_{s \sim \rho_{\pi_{old}}, a_{-i} \sim \pi_{new, -i}, a_i \sim \pi_{old, i}, \epsilon, t} \left[ \omega_i(s, a_i, a_{-i}) \|\epsilon - \epsilon_{\theta_i}(\sqrt{\bar{\alpha}_t} a_i + \sqrt{1-\bar{\alpha}_t} \epsilon, s, t)\|^2 \right]$$

其中 $\omega_i$ 为非负权重函数，由条件优势 $A_i$ 经qadv或qcut变换得到。qadv变换通过中心化优势并截断负值，保持权重校准；qcut变换通过阈值过滤低优势样本，聚焦高价值动作。该目标将去噪损失与Q值对齐，使扩散策略在保持多模态表达力的同时，获得与经典策略梯度相同的理论保证。

### 熵正则化代理

扩散策略无法直接计算熵 $\log \pi_i$，导致最大熵RL原则失效。HAQO引入均匀采样重构作为熵代理：

$$J_i^{ent}(\theta_i) = \alpha_i \mathbb{E}_{s, \tilde{a}_i \sim U(A_i), t} \left[ -\|\tilde{a}_i - \mu_{\theta_i}(\tilde{a}_i^t, t, s)\|^2 \right]$$

其中 $\tilde{a}_i$ 为均匀采样动作，$\mu_{\theta_i}$ 为去噪网络均值。该代理通过注入均匀分布动作扩展策略支持，防止模式坍缩，且保证动作协方差的正谱下限，提供熵下界。与Q加权目标协同，$J_i^{QV}$ 驱动概率质量向高优势动作集中，$J_i^{ent}$ 防止过度集中，实现探索与利用的平衡。

## 实验评估

实验在MPE、SMAC/SMACv2、GRF、MAMuJoCo及Bi-DexHands基准上进行，覆盖离散/连续控制与异构场景。基线包括IPPO、MAPPO、QMIX等经典方法，但缺失与最新生成式MARL方法（如TIGER-MIX、OMAD）的直接对比。据领域综述，HAQO在MAMuJoCo HalfCheetah上取得0.96累积回报，低于SOTA OMAD的0.98但高于MADDPG的0.88；在Bi-DexHands上成功率为0.45，与经典BC持平，低于SOTA IWoL的0.48。SMAC 3s5z未报告具体数值，仅定性描述优于基线。

消融实验确认顺序更新、扩散策略及熵正则化的必要性：移除顺序更新导致训练不稳定，移除扩散策略引发模式坍缩，移除熵正则化导致探索不足。但论文未报告计算效率指标，扩散模型的推理延迟可能限制实时部署。评估协议未严格控制预训练骨干网络变量，HAQO的性能提升可能部分归因于其强大的预训练组件，而非纯粹的策略生成机制。

## 关联研究分析

从问题动机看，HAQO与Diffusing to Coordinate（Li et al., 2026）均针对多模态协调，但前者侧重理论保证与异构性，后者侧重在线采样效率。Diffusing to Coordinate通过优化噪声调度提升推理速度，但未建立单调改进保证，在异构场景下可能因非平稳性导致收敛失败。HAQO的顺序更新机制解决了这一问题，但计算开销随智能体数量线性增长，在大规模异构系统中可能成为瓶颈。

从方法设计看，HAQO与HAML（Zhong et al., 2024）共享顺序更新框架，但HAML假设同质智能体并使用参数共享，无法处理异构观测与动作空间。HAQO通过Q加权变分目标扩展至异构场景，但依赖精确的Critic估计，在Critic偏差较大时理论保证退化。与值分解方法（如QMIX）相比，HAQO放弃了单调性约束，换取多模态表达力，但在简单离散任务上可能不如值分解方法高效。

## 总结

HAQO解决的核心矛盾是异构MARL中稳定性与表达力的权衡。其切入点在于将顺序更新机制与Q加权变分优化结合，为扩散策略建立理论完备的优化框架，从而在不牺牲表达力的前提下保证收敛性。方法上，HAQO通过顺序优势感知更新、Q加权变分代理及熵正则化，实现了异构智能体的稳定协调。实验证明其在MAMuJoCo上取得0.96累积回报，在Bi-DexHands上达到0.45成功率，验证了框架的有效性。但论文未报告计算效率指标，且缺失与最新SOTA生成式方法的直接对比，其绝对性能上限与实时部署能力存疑。当智能体数量增加至10以上时，顺序更新的计算开销是否线性增长，论文未给出回答。
