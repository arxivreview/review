# ICLR2026最新论文 ｜Intrinsic Lorentz Neural Network ｜内在洛伦兹神经网络

研究机构：中国科学技术大学、北京大学

作者：Xianglong Shi、Ziheng Chen、Yunhan Jiang 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.23981)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.23981)

> 双曲度量学习旨在利用恒定负曲率黎曼流形的指数体积增长特性，以更低失真编码层级与树状结构，其核心价值在于突破欧几里得空间在表示包含关系时的维度诅咒。现有基于洛伦兹模型的双曲神经网络虽解决了庞加莱球边界梯度爆炸问题，但普遍采用混合运算或外在参数化，导致几何一致性受损。本文提出完全内在的ILNN架构，通过点-超平面全连接层与陀螺群批归一化，将所有运算严格限制在流形内部。该设计在视觉与基因组学任务上超越了混合架构基线，但其固定曲率设定与未覆盖图结构数据的实验边界，限制了其作为通用层级表示框架的普适性验证。

## 研究背景

当神经网络处理具有层级结构的数据时，欧几里得空间的体积多项式增长特性导致嵌入失真随维度指数上升。双曲空间（Hyperbolic Space）的体积随半径指数增长，使得低维流形能紧凑编码树状结构，这一几何差异构成了双曲度量学习的核心驱动力。然而，早期基于庞加莱球（Poincaré Ball）的模型在优化接近边界时出现严重的数值不稳定，导致梯度爆炸。洛伦兹模型（Lorentz Model）通过Minkowski空间定义双曲几何，提供了更好的数值稳定性，成为构建可微分双曲神经网络（Hyperbolic Neural Networks, HNNs）的主流选择。

尽管洛伦兹模型解决了稳定性问题，但现有先进架构如HCNN（Bdeir et al., 2024）仍属于“部分内在”设计。这些方法在洛伦兹向量上执行欧氏仿射变换，或依赖切空间近似，导致特征在欧氏与双曲空间间频繁映射，引入几何失真。例如，洛伦兹全连接层（LFC）先进行欧氏矩阵乘法，再提取空间部分并计算时间部分，这种混合运算破坏了流形的内在几何结构。归一化层同样存在矛盾：洛伦兹批归一化（LBN）忽略陀螺方差，而陀螺群批归一化（GyroBN）依赖计算昂贵的弗雷歇均值迭代。本文的切入点在于消除所有外在欧氏操作，构建一个所有参数、运算与更新均定义在洛伦兹模型内部的完全内在架构，以恢复严格的几何一致性。

## 核心方法

### 方法参照系

标准双曲CNN流程通常在切空间执行线性变换，或通过混合运算处理洛伦兹向量。本文的关键差异在于拒绝任何切空间映射或欧氏仿射变换，强制所有神经原语直接在洛伦兹流形上定义，确保端到端的几何一致性。

### 点-超平面洛伦兹全连接层

传统全连接层执行欧氏仿射变换 $y = Ax - b$，这在几何上等价于计算输入向量到超平面的有符号距离。在洛伦兹模型中，直接应用欧氏矩阵乘法 $Wx$ 利用了环境Minkowski空间的线性结构，而非流形上的内在操作。本文提出点-超平面洛伦兹全连接层（Point-to-hyperplane Lorentz Fully Connected, PLFC），将输出定义为输入特征到学习超平面的闭式洛伦兹距离。对于类 $c$，其logit由以下公式给出：

$$
v_c(\mathbf{x}) = \text{sign}(\langle \mathbf{w}_c, \mathbf{x} \rangle_L) \frac{1}{\sqrt{-K}} \text{arccosh}\left( -\frac{\langle \mathbf{w}_c, \mathbf{x} \rangle_L}{\sqrt{\langle \mathbf{w}_c, \mathbf{w}_c \rangle_L}} \right)
$$

该公式通过闭式计算点到超平面的有符号双曲距离，替代了传统的仿射logits。这一设计解决了LFC层中欧氏映射导致的曲率感知缺失问题，使得决策边界严格遵循流形的内在几何，提供了可解释的边际（margin）语义。

### 陀螺群洛伦兹批归一化

批归一化在流形上的扩展面临统计量计算效率与几何对齐的矛盾。GyroBN使用弗雷歇均值进行陀螺中心化和缩放，但迭代求解弗雷歇均值在大批量2D卷积中计算开销巨大。本文提出陀螺群洛伦兹批归一化（GyroLBN），结合陀螺群运算与闭式洛伦兹统计量。其归一化映射定义为：

$$
\mathbf{y} = \gamma \odot (\mathbf{x} \oplus \mu_B) \oplus \beta
$$

其中 $\mu_B$ 为闭式计算的洛伦兹质心，$\gamma$ 和 $\beta$ 分别为可学习的缩放与偏置。GyroLBN保留了GyroBN的陀螺群中心化与缩放机制，但用闭式洛伦兹质心和方差替代了迭代弗雷歇统计量。这一改动消除了迭代求解器，在保持几何对齐的同时显著降低了训练时间，解决了GyroBN在大规模数据上的效率瓶颈。

## 实验评估

实验在CIFAR-10/100视觉数据集及TEB、GUE基因组学基准上进行，对比欧氏CNN、HCNN-S/M等基线。基线覆盖欧氏与混合双曲架构，但缺失双曲GNN（如HGCN）及Transformer基线（如HexFormer），限制了在图结构数据上的横向对比。

| 数据集 | 任务 | 欧氏CNN | HCNN-M | ILNN |
| :--- | :--- | :--- | :--- | :--- |
| TEB | Pseudogenes (unprocessed) | 51.94±2.69 | 70.26±0.32 | 64.90±0.74 |
| GUE | Core Promoter (tata) | 78.26±2.85 | 83.90±0.53 | 83.26±1.90 |
| GUE | Promoter (notata) | 90.81±0.51 | 92.48±0.35 | 92.48±0.35 |
| CIFAR-10 | Classification | - | 94.98 | 95.36±0.13 |

在TEB伪基因未处理数据上，HCNN-M以70.26±0.32的MCC显著优于ILNN的64.90±0.74，表明在特定基因组子任务上，混合架构可能因保留部分欧氏灵活性而表现更佳。但在CIFAR-10上，ILNN以95.36±0.13的准确率超越HCNN的94.98，验证了内在设计在视觉任务上的几何优势。

| 模型配置 | CIFAR-10 Acc | Fit Time (s) |
| :--- | :--- | :--- |
| LFC + LBN | 95.14±0.08 | 142 |
| LFC + GyroLBN | 95.19±0.15 | 125 |
| PLFC + GyroBN | 95.28±0.17 | 314 |
| PLFC + GyroLBN | 95.36±0.13 | 169 |

消融实验显示，PLFC+GyroLBN组合在准确率与效率上均占优。相比PLFC+GyroBN，GyroLBN将训练时间从314秒降至169秒，同时准确率提升0.08个百分点。这一结果证实了闭式洛伦兹统计量在替代迭代弗雷歇均值时的效率收益，且未牺牲几何对齐带来的性能增益。

评估协议采用固定曲率 $K=-1$，未探索自适应曲率对性能的影响。代码基于PyTorch与Geoopt实现，使用NVIDIA A100 GPU，结果平均自五个随机种子。论文未报告与欧氏基线直接对比的训练耗时，仅提供了双曲模型间的相对效率数据，限制了对其绝对计算开销的评估。

## 关联研究分析

从方法设计看，ILNN与FGG-LNN（van der Klis et al., 2026）均致力于解决洛伦兹神经网络的效率瓶颈，但路径截然不同。FGG-LNN通过缓存中间变量和优化矩阵乘法，在混合运算框架下提升速度，牺牲了部分严格的内在几何一致性；而ILNN坚持完全内在运算，通过闭式距离与统计量实现效率提升。这种差异反映了领域内“几何保真度优先”与“计算效率优先”的根本分歧。ILNN在CIFAR-10上超越HCNN的结果支持了前者在视觉任务中的有效性，但其在TEB未处理数据上落后于HCNN-M，暗示在噪声较大的基因组数据中，混合架构的欧氏灵活性可能更具鲁棒性。

从问题动机看，ILNN与HexFormer（Alyoussef et al., 2026）都关注双曲架构中的聚合与失真问题，但针对的组件不同。HexFormer解决的是Transformer中质心聚合在大曲率下的失真，采用切空间聚合；ILNN解决的是CNN中全连接层与归一化层的混合运算失真，采用流形内闭式运算。两者共同指向双曲深度学习中的核心矛盾：如何在保持几何一致性的同时控制计算复杂度。ILNN未涉及注意力机制，其贡献局限于CNN架构，而HexFormer展示了双曲Transformer的潜力，两者互补而非竞争。

## 总结

ILNN旨在解决现有洛伦兹神经网络中混合运算导致的几何一致性缺失问题。通过引入点-超平面全连接层与陀螺群洛伦兹批归一化，本文实现了所有运算在流形内的闭式计算，避免了切空间映射与迭代求解器。实验表明，ILNN在CIFAR-10上达到95.36±0.13的准确率，超越混合架构基线HCNN，且训练时间较GyroBN减少46%。然而，其在TEB未处理数据上落后于HCNN-M，且固定曲率设定未探索自适应机制，暴露了内在设计在噪声数据与复杂层级结构中的潜在局限。当输入数据存在显著分布偏移或层级结构非平衡时，完全内在运算是否仍能保持对混合架构的性能优势，论文未给出回答。
