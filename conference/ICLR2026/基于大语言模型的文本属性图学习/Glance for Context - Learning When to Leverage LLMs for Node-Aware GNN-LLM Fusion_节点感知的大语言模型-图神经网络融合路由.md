# ICLR2026最新论文 ｜Glance for Context: Learning When to Leverage LLMs for Node-Aware GNN-LLM Fusion ｜节点感知的大语言模型-图神经网络融合路由

研究机构：美国密歇根大学

作者：Donald Loveland、Yao-An Yang、Danai Koutra

论文原文见 [arXiv](https://arxiv.org/abs/2510.10849)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.10849)

> 文本属性图（TAGs）学习面临的核心矛盾是：大语言模型（LLMs）的语义推理能力与图神经网络（GNNs）的结构归纳偏置难以在统一计算预算下高效协同。现有混合架构通常对所有节点施加单一融合策略，导致在GNN已能准确建模的节点上浪费昂贵的LLM调用，而在GNN失效的异质节点上又因序列化引入结构扭曲。本文切入点在于识别“哪些节点需要LLM”，通过局部同配性（local homophily）作为路由信号，动态决定LLM的调用时机。GLANCE框架利用轻量级路由器筛选困难节点，仅对这部分节点进行LLM嵌入融合，实现了精度与效率的平衡。其价值在于揭示了GNN与LLM的互补边界，但路由策略对标签分布的依赖及在大规模稀疏图上的泛化能力仍存疑。

## 研究背景

当GNN处理引文网络或社交图谱时，其性能高度依赖于邻居节点的同配性（homophily），即相连节点共享标签的概率。若节点处于异质区域（heterophilous regions），GNN的消息传递机制会聚合错误信号，导致预测失效。此时，LLM凭借其在低资源场景下的强泛化能力，本可弥补这一缺陷。然而，直接将图结构序列化为文本输入LLM，会破坏拓扑关系的完整性，且在结构简单的节点上，LLM的介入反而引入噪声，降低整体准确率。

该领域的主流路线分为“LLM-as-Enhancer”与“LLM-as-Predictor”。前者将LLM嵌入作为特征拼接至GNN，后者直接由LLM预测标签。两者均存在静态融合的弊端：前者无法区分节点难度，后者受限于提示长度与拓扑编码损失。近期工作如LOGIN利用不确定性重连边，E-LLaGNN使用度或中心性启发式路由，但这些静态规则在不同数据集上表现波动极大，甚至劣于随机路由。本文指出，现有方法忽视了节点层面的结构异质性，未能捕捉GNN失效与LLM增益之间的结构性关联。

## 核心方法

### 方法参照系

GLANCE属于GNN-LLM协同融合路线，其标准流程为：GNN编码结构特征，LLM编码文本语义，二者通过线性层或注意力机制融合。本文的关键差异在于引入一个非可微的路由决策层，将“是否融合”转化为基于节点属性的二分类问题，而非对所有节点执行固定融合操作。

### 基于局部同配性的路由信号

传统路由依赖度或聚类密度，但实验表明这些指标在不同数据集上缺乏鲁棒性。本文发现，局部同配性 $h_v$ 是预测LLM增益的强信号。由于真实标签在推理时不可得，本文训练一个MLP $Q$ 预测节点标签 $\hat{y}_v$，并计算软局部同配性：

$$ \hat{h}_v = \frac{1}{|\mathcal{N}(v)|} \sum_{u \in \mathcal{N}(v)} \mathbf{1}[\hat{y}_u = \hat{y}_v] $$

该公式通过预测标签的一致性量化邻居对齐程度。设计动机在于解决静态启发式规则（如度）在异质图上的失效问题，$\hat{h}_v$ 提供了无需真实标签即可识别GNN失效区域的先验信号，使路由决策具备结构感知能力。

### 优势函数训练的非可微路由器

路由器 $r(\cdot)$ 接收GNN嵌入 $\mathbf{z}_G(v)$、不确定性估计及 $\hat{h}_v$，输出路由概率。由于LLM调用不可微，无法使用标准反向传播。本文引入优势函数（advantage-based objective）训练路由器：

$$ \mathcal{L}_{router} = -\mathbb{E}_{v} \left[ r(v) \cdot A(v) \right] $$

其中 $A(v)$ 定义为路由后LLM修正错误节点数与引入错误节点数之差（Net Correction Score, NCS）。该公式的物理含义是：路由器仅当LLM调用带来净收益（修正错误多于引入错误）时，才增加该节点的路由概率。这一设计解决了非可微管道中梯度缺失的问题，使路由器能自适应地学习“何时调用LLM最划算”，避免了固定阈值带来的过拟合或欠拟合。

## 实验评估

实验在Cora、Pubmed、Arxiv23及OGB-Products上进行，基线涵盖GCN、GCNII、FAGCN等GNN及其LLM增强变体，但未对比NAG、TAG-DLM等原生架构方法。GLANCE在Cora上达到89.5%准确率，Pubmed上92.6%，Arxiv23上82.1%，均优于最强基线GCNII-Enhanced。

| 数据集 | 方法 | 准确率 (%) |
| :--- | :--- | :--- |
| Cora | GCNII (Enhanced) | 88.4 ± 0.8 |
| Cora | GLANCE | 89.5 ± 0.4 |
| Pubmed | GCNII (Enhanced) | 89.1 ± 0.6 |
| Pubmed | GLANCE | 92.6 ± 0.1 |
| Arxiv23 | GCNII (Enhanced) | 75.9 ± 2.1 |
| Arxiv23 | GLANCE | 82.1 ± 0.1 |

GLANCE在异质节点子集上提升显著，Cora上异质节点准确率提升13.0%，而整体提升仅0.5%-0.9%。这表明增益主要来源于对GNN失效区域的精准修复，而非全局性能提升。消融实验显示，移除同配性信号后，路由性能下降至接近随机水平，验证了该信号的核心作用。

评估边界方面，论文未报告计算效率的具体数值（如LLM调用次数节省比例），仅定性描述“显著减少”。代码未公开，超参数依赖Qwen3-8B，限制了跨LLM基座的复现性。此外，实验未包含动态图或极端稀疏图场景，路由策略在结构剧烈变化下的稳定性未经验证。

## 关联研究分析

从问题动机看，GLANCE与LOGIN（Qiao et al., 2025）均关注GNN失效节点，但LOGIN通过重连边改变图结构，而GLANCE保留原图结构仅调整特征融合。这一差异源于任务特性：LOGIN假设结构噪声是主要问题，而GLANCE认为结构本身有效但语义理解不足。在异质图上，LOGIN的重连可能破坏原有的异质连接，导致信息丢失，而GLANCE的路由机制避免了结构编辑，更适用于结构稳定的TAGs。

从方法设计看，GLANCE与E-LLaGNN（Jaiswal et al., 2024）同属自适应融合，但E-LLaGNN使用固定启发式（度/中心性），GLANCE使用可学习路由。E-LLaGNN的局限在于启发式规则需人工调参且跨数据集泛化差，而GLANCE通过优势函数自动学习路由策略。然而，GLANCE的路由器依赖预测标签 $\hat{y}_v$，若GNN预测严重偏差，$\hat{h}_v$ 将失效，此时路由可能退化为随机。论文未讨论这种“预测-路由”循环依赖在极端分布偏移下的鲁棒性，这是其与基于纯结构信号（如度）方法的关键区别。

## 总结

GLANCE旨在解决GNN-LLM融合中计算资源浪费与结构保真度冲突的矛盾。其切入点在于发现局部同配性是GNN失效的强预测信号，从而将静态融合转化为动态路由。通过优势函数训练非可微路由器，GLANCE实现了仅对困难节点调用LLM，在Cora异质节点上提升13.0%。然而，其路由策略依赖GNN预测标签的准确性，在GNN预测严重偏差的场景下，同配性估计可能失效，导致路由决策偏离最优。当支持集增大或图结构发生动态演化时，基于静态预测标签的路由信号是否仍能保持有效性，论文未给出回答。
