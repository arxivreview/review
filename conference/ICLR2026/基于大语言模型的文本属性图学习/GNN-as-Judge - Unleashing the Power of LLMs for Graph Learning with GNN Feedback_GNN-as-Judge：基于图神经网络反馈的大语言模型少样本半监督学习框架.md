> 导读 文本属性图（TAGs）节点分类在标签稀缺场景下面临大语言模型（LLM）因缺乏图结构感知能力而导致的伪标签噪声与过拟合问题。现有 LLM-as-Predictors 范式依赖充足监督信号，直接应用于少样本半监督设置时性能急剧下降，且单纯依靠 LLM 自身置信度筛选伪标签易陷入自偏差陷阱。本文提出 GNN-as-Judge 框架，利用图神经网络（GNN）的结构归纳偏置作为“裁判”，通过一致性与不一致性协同筛选伪标签，并结合弱监督微调算法抑制噪声。该方法在极端低资源场景下显著优于传统 GNN 与早期 LLM 基线，但其对 GNN 可靠性的依赖及跨域泛化能力的边界尚存疑。

## 研究背景

当 LLM 处理 TAGs 节点分类时，其文本语义理解优势无法直接转化为对图拓扑结构的感知。这种结构盲点导致 LLM 在缺乏大量标注数据时，无法像 GNN 那样通过消息传递机制利用未标注节点的信息，从而在少样本半监督设置中因监督信号不足而失效。为解决此问题，伪标签技术被引入以扩充训练集，但 LLM 生成的“易”伪标签学习信号有限，而“难”伪标签虽具信息量却伴随高噪声，传统基于置信度的筛选策略难以平衡二者。

TAGs 研究的主流路线分为 LLM-as-Enhancers 与 LLM-as-Predictors。前者如 TAPE 利用 LLM 生成解释文本增强 GNN 特征，后者如 GraphGPT 将图结构序列化后直接由 LLM 预测。然而，现有 LLM-as-Predictors 工作主要聚焦于监督充足场景，忽视了真实世界中标签稀疏的普遍性。直接应用这些方法于少样本场景会导致过拟合，且 LLM 的幻觉与自偏差使得其自生成的伪标签可靠性存疑。本文切入点在于引入 GNN 作为独立的结构感知裁判，通过模型间的一致性与不一致性模式，解决伪标签筛选与噪声抑制两大核心挑战。

## 核心方法

### 方法参照系

本文问题属于 LLM-as-Predictors 范式下的少样本半监督学习。标准流程通常依赖 LLM 自身置信度或单一模型预测进行伪标签筛选，但本文关键差异在于引入 GNN 作为外部结构代理，通过双模型协同机制替代单一模型自训练，以解决 LLM 缺乏结构归纳偏置导致的伪标签不可靠问题。

### 影响力引导节点选择

针对全图伪标签计算成本过高且未标注节点价值不均的问题，本文首先基于节点影响力筛选候选子集。节点影响力定义为标签节点表示对未标注节点表示的雅可比范数，量化了信息通过图结构传播的程度。根据定理 1，影响力随节点间距离衰减，且存在可计算上界。基于此，计算每个未标注节点 $v_j$ 的影响力分数 $IS(v_j)$ 为所有标签节点对其影响的最大值：

$$ IS(v_j) = \max_{v_i \in V_{train}} I_{v_i, v_j} $$

该公式通过选取影响力最高的 Top-K 节点，确保伪标签生成集中在受标签数据强烈影响的区域，从而在计算约束下最大化伪标签的可靠性与代表性。

### 协同伪标签筛选与弱监督微调

在选定子集上，GNN 与 LLM 分别生成预测，将节点划分为一致性集合 $V_{agreed}$ 与不一致性集合 $V_{disagreed}$。一致性节点因双模型独立偏置下的预测重合，其伪标签准确率理论上高于任一单模型，故采用指令微调（Instruction Tuning）强化正确预测。对于不一致性节点，直接微调易引入噪声，本文引入 GNN 偏好分数 $S_{pref}(v_i)$ 作为筛选阈值：

$$ S_{pref}(v_i) = P_{GNN}(\hat{y}_i^{GNN} | v_i) - P_{GNN}(\hat{y}_i^{LLM} | v_i) $$

仅保留 $S_{pref}(v_i) \ge \tau$ 的节点进入偏好微调（Preference Tuning），使 LLM 学习 GNN 预测优于自身预测的相对偏好。最终损失函数联合优化两部分：

$$ L(\theta) = \mathbb{E}_{(x_i, y_i) \sim D_{agreed}} [L_{IT}(\theta; x_i, y_i)] + \lambda \mathbb{E}_{(x_i, y_{w,i}, y_{l,i}) \sim D'_{disagreed}} [L_{PT}(\theta; x_i, y_{w,i}, y_{l,i})] $$

这一设计通过 GNN 的结构先验过滤高噪声“难”样本，同时利用偏好学习机制让 LLM 在不确定区域向结构更可靠的预测靠拢，有效缓解了伪标签噪声导致的性能退化。

## 实验评估

实验在 Cora、Citeseer、Pubmed、ogbn-arxiv 及 ogbn-products 五个基准上评估，覆盖 3-shot、5-shot 及 0-shot 设置。基线涵盖 GCN、SGC 等传统 GNN，以及 GraphGPT、LLaGA、TAPE 等 LLM 方法，但未包含 2025-2026 年提出的 NAG 或 TAG-DLM 等原生架构方法。

在 3-shot 极端低资源场景下，GNN-as-Judge 在 Cora 上达到 77.89%，较 GCN 提升 8.44 个点，较 GraphGPT 提升 20.12 个点，验证了 GNN 反馈在标签稀缺时的关键作用。消融实验显示，移除伪标签、不一致性节点集或弱监督微调均导致性能显著下降，其中移除弱监督微调在 Pubmed 上损失最大，表明该机制对高噪声场景的鲁棒性至关重要。

评估边界方面，论文未报告计算效率指标，且跨数据集零样本实验仅在 ogbn-arxiv 到 Cora/Citeseer/Pubmed 方向验证，未覆盖反向迁移或更复杂的分布偏移场景。代码已开源，但超参数 $\tau$ 与 $\lambda$ 的敏感性分析未在正文详细展开，可能影响复现稳定性。

## 关联研究分析

从问题动机看，GNN-as-Judge 与 LLM-GNN Co-Teaching 同属协同融合路线，但二者解决噪声的机制不同。Co-Teaching 侧重通过双模型互教筛选干净样本，而 GNN-as-Judge 明确利用 GNN 的结构偏置作为“裁判”来判定 LLM 预测的可靠性，特别是在不一致性节点上引入偏好微调。这种差异源于任务特性：Co-Teaching 假设双模型错误分布相似，而 GNN-as-Judge 假设 GNN 在结构主导任务上比 LLM 更可靠，这一假设在文本稀疏但结构清晰的图上可能更成立，但在文本语义主导的图上是否依然有效，论文未给出充分验证。

从方法设计看，GNN-as-Judge 与 TAPE 形成鲜明对比。TAPE 将 LLM 视为特征增强器，生成解释文本供 GNN 使用，本质是单向信息流；而 GNN-as-Judge 将 GNN 视为 LLM 的反馈源，实现双向协同。TAPE 的优势在于保留 GNN 的完整结构建模能力，但受限于 LLM 生成文本的质量；GNN-as-Judge 的优势在于直接优化 LLM 的预测能力，但依赖 GNN 的预训练质量。在 ogbn-arxiv 大规模图上，GNN-as-Judge 的优势幅度缩小，可能暗示 GNN 在大规模稀疏图上的结构捕获能力受限，导致其作为“裁判”的可靠性下降，这一现象在 TAPE 等纯 GNN 增强路线中未出现，提示了混合架构在规模扩展上的潜在瓶颈。

## 总结

GNN-as-Judge 针对 LLM 在少样本半监督 TAGs 节点分类中因缺乏结构感知导致的伪标签噪声问题，提出利用 GNN 作为裁判的协同筛选与弱监督微调框架。通过影响力引导节点选择、一致性/不一致性协同筛选及偏好微调，该方法在 Cora 3-shot 场景下达到 77.89% 准确率，显著优于 GCN 与 GraphGPT。然而，其性能高度依赖 GNN 的结构建模能力，在大规模 ogbn-arxiv 上优势幅度缩小至 1.13 个点，且跨域零样本泛化能力仅在单一方向验证。当图结构复杂度增加或文本语义主导时，GNN 作为“裁判”的可靠性假设是否依然成立，论文未给出回答。
