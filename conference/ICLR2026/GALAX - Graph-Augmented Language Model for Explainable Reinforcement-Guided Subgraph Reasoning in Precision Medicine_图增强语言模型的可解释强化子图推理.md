# ICLR2026最新论文 ｜GALAX: Graph-Augmented Language Model for Explainable Reinforcement-Guided Subgraph Reasoning in Precision Medicine ｜图增强语言模型的可解释强化子图推理

研究机构：美国圣路易斯华盛顿大学、Hugging Face

作者：Heming Zhang、Di Huang、Wenyu Li 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.20935)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.20935)

> 精准医学中从多组学数据到治疗靶点的预测长期缺乏机制层面的可解释性，现有方法要么忽略拓扑结构，要么依赖静态检索导致推理链不可靠。GALAX 的切入点在于将子图构建视为强化学习序列决策，利用预训练图神经网络作为过程奖励模型，在无显式标签条件下监督中间步骤的生物合理性。该方法通过图过程奖励模型（Graph Process Reward Model, GPRM）引导大语言模型（Large Language Model, LLM）动态生成患者特异性信号子图，实现靶点预测与机制解释的统一。其价值在于提供了无标签的过程级监督框架，但受限于自建基准的封闭性与预训练图模型偏差的继承风险。

## 研究背景

精准医学的核心困境在于多组学数据的高维稀疏性与生物系统网络复杂性之间的张力。当面对癌症细胞系的转录组、蛋白质组等数值特征时，传统扁平表格模型无法捕捉基因间的层级依赖与通路动态。图神经网络（Graph Neural Network, GNN）通过消息传递引入结构先验，缓解了过拟合，但静态拓扑匹配无法弥合“结构-功能鸿沟”——网络相似不代表功能相同。大语言模型（LLM）具备多步推理能力，却缺乏结构化知识 grounding，易产生幻觉。检索增强生成（Retrieval-Augmented Generation, RAG）试图通过外部知识图谱弥补 LLM 缺陷，但现有图增强方法（如 G-Retriever, RoG）仅关注最终答案准确率，忽视中间推理步骤的可靠性，且检索到的子图往往噪声大、缺乏真实机制结构。

过程奖励模型（Process Reward Model, PRM）旨在为推理中间步骤提供细粒度监督，但在生物医学领域面临标注不可行难题：基因调控路径的组合爆炸使得逐步标注成本极高，且缺乏 ground-truth 步骤定义。现有 PRM 依赖人工规则或模型自评估，易陷入奖励黑客（reward hacking）陷阱。GALAX 的切入点在于将预训练 GNN 转化为生物合理性评估器，替代人工标注，通过强化学习（Reinforcement Learning, RL）引导 LLM 动态构建子图，从而在无标签条件下实现过程级监督。这一设计直接回应了领域内“可解释性与机制发现”的核心需求，将预测任务转化为可追溯的图结构生成任务。

## 核心方法

### 方法参照系

本文问题属于“图谱基础模型构建”与“分子机制扰动模拟”的交叉路线。标准流程为：多模态特征提取 → 图结构编码 → 端到端预测。本文的关键差异在于摒弃端到端预测，引入 RL 循环，将子图构建视为序列决策问题，由预训练 GNN 实时评估每一步边的生物合理性，而非依赖静态检索或注意力归因。

### 文本-组学信号图构建

GALAX 首先构建文本-组学信号图（Text-Omic Signaling Graph, TOSG），统一数值组学证据 $X^{(0)}$、文本实体描述 $T$ 与拓扑信息 $G=\{V, E\}$。节点集 $V$ 包含启动子、基因、转录本、蛋白质四类实体，边集 $E$ 分解为内部信号传播子图 $G_{in}$（遵循中心法则：启动子→基因→转录本→蛋白质）与蛋白质-蛋白质相互作用子图 $G_{PPI}$。设计动机在于解决多模态数据语义空间不一致问题，通过跨模态编码器对齐特征空间，为 LLM 提供结构化上下文。TOSG 的构建依赖 BioMedGraphica 工具整合 DepMap 数据，确保数值特征与文本描述的拓扑对齐。

### 图过程奖励模型引导的子图生成

子图生成被建模为 RL 问题，状态 $G_n^{(i)}$ 为当前部分子图，动作 $\Delta_n^{(i)}$ 为添加单条边 $(v_{src}^{(i)}, v_{tgt}^{(i)})$。策略 $\pi(\cdot)$ 使用消息传播模块生成节点嵌入，并通过掩码概率函数采样源节点与目标节点。奖励函数 $R_{total}^{(i)}$ 结合预训练分类器 $g(\cdot)$ 的即时反馈、$L$ 次 rollout 模拟的未来轨迹平均，以及基于 BioMedGraphica 关系的规则项 $R_{rule}$：

$$
R_{total}^{(i)} = \lambda \cdot g_{o^\star}(G_n^{(i+1)}) + (1-\lambda) \cdot \frac{1}{L} \sum_{\ell=1}^{L} \text{Rollout}_\ell(G_n^{(i+1)}) + R_{rule}(G_n^{(i+1)})
$$

其中 $g_{o^\star}(\cdot)$ 为预训练 GNN 对目标疾病类别 $o^\star$ 的预测概率，$\lambda$ 平衡即时与未来反馈。设计动机在于解决 PRM 在生物医学领域缺乏逐步标注的困境，利用预训练 GNN 作为生物合理性代理，避免人工规则的主观性与模型自评估的偏差。仅当 $R_{total}^{(i)} > 0$ 时接受动作，确保生成的子图在生物学上可行。最终子图 $G_n^\dagger$ 被转化为自然语言描述，附加至查询中供 LLM 进行最终靶点预测。

## 实验评估

实验在自建 Target-QA 基准上进行，包含 363 个来自 TCGA 与 DepMap 的 QA 对，采用 80/20 训练-测试划分。基线覆盖 M2T（纯多组学）、L3 变体（LLM+组学/知识图谱）、G-Retriever、RoG、SubgraphRAG、GNN-RAG 等路线，但缺失纯 GNN 直接预测基线（如 GCN/GAT）及 GPT-4 等强 LLM 基线。

| 方法 | F1 Score | Precision@10 | Recall |
| :--- | :--- | :--- | :--- |
| GALAX | 0.5472±0.0053 | 0.3726±0.0037 | 0.9249±0.0048 |
| L3-FT(QA) + Omics + KG | 0.5185±0.0240 | 0.3393±0.0298 | 0.8794±0.0114 |
| G-Retriever + pre-GAT | 0.5345±0.0185 | 0.3619±0.0055 | 0.9063±0.0079 |

GALAX 在 F1 与 Precision@10 上均优于基线，但 Recall 提升有限（0.9249 vs 0.9063），表明其优势主要在于精确率而非召回率。消融实验显示，加入知识图谱与 RL 子图生成后，F1 从 0.5185 提升至 0.5472，Precision@10 从 0.3393 提升至 0.3726，验证了动态子图生成对精确率的贡献。然而，GALAX (Qwen2.5-7B) 变体在部分癌症类型（如 LUAD）上 F1 降至 0.2921±0.0055，显著低于主模型，提示模型对 LLM 骨干的敏感性。

评估边界方面，Target-QA 为自建基准，缺乏外部独立验证，80/20 划分可能导致过拟合。指标仅报告 F1、Precision@K、Recall，未提供 PR-AUC 或 AUC，难以评估类别不平衡下的鲁棒性。代码与数据集已开源，但预训练 GNN 的超参数（如掩码比例 $p=0.0001$）未详细消融，可复现性受限于 H100 GPU 资源需求。

## 关联研究分析

从问题动机看，GALAX 与 GLaDiGAtor 均融合 LLM 与 GNN，但 GLaDiGAtor 侧重静态特征增强，通过 ProtT5 与 BioBERT 嵌入提升节点表示丰富性，而 GALAX 侧重动态过程推理，将子图构建视为 RL 序列决策。这一差异源于任务特性：GLaDiGAtor 面向疾病-基因关联预测，静态拓扑匹配已足够；GALAX 面向靶点优先级排序，需捕捉信号通路的动态因果链。GALAX 的 RL 框架解决了静态检索噪声问题，但引入了对预训练 GNN 偏差的继承风险，而 GLaDiGAtor 的静态设计避免了这一风险，却牺牲了机制解释的深度。

从方法设计看，GALAX 与 G-Retriever 同属图增强 LLM 框架，但 G-Retriever 采用静态子图检索，GALAX 采用动态子图生成。G-Retriever 的检索过程缺乏过程级监督，易受噪声子图影响；GALAX 的 GPRM 通过预训练 GNN 实时评估每一步边的生物合理性，提供了细粒度监督。然而，GALAX 的 GPRM 依赖预训练 GNN 的分类能力，若预训练数据分布与目标任务不一致，奖励信号可能失真。G-Retriever 的静态检索虽缺乏过程监督，但计算成本低，更适合大规模部署。GALAX 的 RL 训练复杂度显著更高，且对预训练 GNN 的质量敏感，这一权衡在论文中未充分讨论。

## 总结

GALAX 要解决的核心矛盾是生物医学多组学数据中机制解释的缺失与 PRM 标注不可行的困境。其切入点在于利用预训练 GNN 作为生物合理性代理，通过 RL 引导 LLM 动态生成子图，实现无标签的过程级监督。该方法在 Target-QA 上取得 0.5472 F1 与 0.3726 Precision@10，优于静态检索基线，但 Recall 提升有限，且对 LLM 骨干敏感。其边界在于自建基准的封闭性与预训练 GNN 偏差的继承风险，缺乏跨数据集泛化验证。当预训练 GNN 的分布外性能下降时，GPRM 的奖励信号是否仍能保持生物学真实性，论文未给出回答。
