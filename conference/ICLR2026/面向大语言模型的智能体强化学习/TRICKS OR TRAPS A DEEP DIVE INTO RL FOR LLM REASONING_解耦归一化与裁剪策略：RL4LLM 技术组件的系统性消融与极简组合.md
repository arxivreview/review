研究机构：阿里巴巴集团、北京交通大学

作者：Zihe Liu、Jiashun Liu、Yancheng He 等 15 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_39857292)

> 强化学习（RL）在提升大语言模型（LLM）推理能力时，面临技术组件推荐相互矛盾、实验设置不统一导致的结论碎片化问题。现有方法如 GRPO 与 REINFORCE++ 在归一化粒度上各执一词，且缺乏针对模型初始化状态（Base vs Aligned）的差异化指导。本文切入点在于通过统一框架下的单变量消融实验，厘清各组件的适用边界，并证明仅组合“组均值+批标准差归一化”与“Token级损失聚合”即可超越复杂算法。其价值在于提供了可复现的技术选型指南，但存疑点在于该极简组合在长程多轮交互任务中的泛化能力尚未验证。

## 研究背景

当 LLM 通过 RL 优化推理策略时，策略梯度估计的方差成为训练稳定性的核心瓶颈。为降低方差，研究者引入了优势归一化（Advantage Normalization），但归一化的统计量计算范围（组内 vs 批次内）直接决定了梯度更新的幅度与方向。若组内奖励分布高度集中（如全对或全错），除以极小的组内标准差会导致梯度爆炸；反之，批次级统计量虽能平滑波动，却可能掩盖组内相对优劣。这一矛盾在模型初始化状态不同时表现各异：Base 模型策略表达力弱，裁剪（Clipping）对探索影响有限；而 Aligned 模型因后训练已具备较强推理能力，过紧的裁剪上限会抑制低概率但高价值的推理路径，导致熵坍缩。

RL4LLM 领域正经历从“算法创新”到“工程实践”的转折，但技术碎片化阻碍了落地。GRPO（Shao et al., 2024）主张组级归一化以增强组内竞争，REINFORCE++（Hu et al., 2025）则偏好批次级归一化以缓解低多样性下的过拟合，Dr. GRPO（Liu et al., 2025b）甚至建议移除方差项以防止偏差。这些冲突源于各研究在数据难度、模型规模与初始化条件上的差异，导致单一结论难以普适。本文旨在通过控制变量实验，打破这种“黑盒”状态，为从业者提供基于模型特性与数据分布的精细化技术选型依据。

## 核心方法

### 方法参照系

本文基于 PPO 损失函数与 REINFORCE 优势估计构建统一基线，核心差异在于对归一化统计量、裁剪边界及损失聚合粒度的解耦分析。不同于端到端提出新算法，本文聚焦于现有组件（Normalization, Clip, Filtering）在不同模型初始化（Qwen3-Base/Aligned）与数据难度（Easy/Medium/Hard）下的独立效应，旨在识别“必要组件”与“冗余组件”。

### 解耦归一化统计量

传统 GRPO 采用组内均值与组内标准差进行归一化，即 $A_i = \frac{r_i - \mu_{group}}{\sigma_{group}}$。然而，当组内奖励分布高度集中时，$\sigma_{group}$ 趋近于零，导致优势值被异常放大，引发梯度爆炸。本文提出解耦策略：均值仍采用组内计算以保留相对竞争信号，但标准差改用批次级全局计算，即 $A_i = \frac{r_i - \mu_{group}}{\sigma_{batch}}$。这一设计动机在于，批次级标准差提供了更强的全局归一化能力，有效抑制了因局部奖励集中导致的梯度幅值震荡，同时保留了组内相对优劣的排序信息，从而在稀疏奖励场景下实现更稳定的策略更新。

### 模型自适应裁剪与损失聚合

针对 Aligned 模型中常见的熵坍缩问题，本文调整 PPO 的裁剪上限 $\epsilon_{high}$。标准 PPO 限制策略比率 $r_t$ 在 $[1-\epsilon, 1+\epsilon]$ 内，但 Aligned 模型初始高概率 token 较少，过低的 $\epsilon_{high}$（如 0.20）会过度抑制低概率推理路径的探索。本文发现，将 $\epsilon_{high}$ 提升至 0.28 或 0.32 可显著延缓熵下降，促进多样化推理结构的生成。同时，损失聚合从序列级（Sequence-level）改为 Token 级（Token-level），即 $L = \frac{1}{\sum T} \sum_{t} \min(r_t A_t, \text{clip}(r_t, 1-\epsilon, 1+\epsilon) A_t)$，而非先对序列内 token 取平均再对批次取平均。这一改动解决了序列级聚合中长响应被短响应“稀释”的问题，确保每个 token 对梯度的贡献均等，尤其适用于 Base 模型在困难数据上的学习。

## 实验评估

实验基于 ROLL 框架，使用 Qwen3-4B/8B 的 Base 与 Aligned 版本，在 MATH500、AIME24/25、AMC23 等六个数学基准上进行了超过 160 次独立训练。基线覆盖 PPO、GRPO、DAPO 及 REINFORCE++，但缺失 Tree-GRPO 等系统级多轮方法。由于论文未提供统一的最终 SOTA 数值对比表，仅展示训练曲线与消融结果，无法直接量化 Lite PPO 相对于 GRPO 的具体性能增益幅度，但定性结论指出其超越主流方法。

消融实验揭示了关键的设计依赖：在 Easy 数据上，移除标准差项（w/o std）显著提升了稳定性，而 Group-level 归一化在 Hard 数据上优于 Batch-level。Clip-Higher 对 Base 模型影响微弱（裁剪率仅 0.003），但对 Aligned 模型至关重要，4B 模型在 $\epsilon_{high}=0.32$ 时性能峰值最高，8B 模型则在 0.28 时最优，呈现小模型的“缩放律”。Token 级损失聚合在 Base 模型上显著优于序列级，但在 Aligned 模型上优势消失，表明后训练已使模型具备稳定的推理结构，无需细粒度 token 加权。Overlong Filtering 在 8k 阈值下提升准确率并缩短响应长度，但在 20k 阈值下效果有限，甚至导致重复生成。

评估边界受限于数学推理任务，未涉及 Web 导航或代码生成等 Agentic 场景。可复现性方面，论文提供了开源框架链接与详细超参数（如 batch size 1024, lr 1e-6），但缺乏对 GPU 资源消耗与训练时间的报告，难以评估其在大规模集群中的工程效率。

## 关联研究分析

从问题动机看，本文与 GRPO 的核心分歧在于归一化统计量的选择。GRPO 假设组内竞争是主要学习信号，因此采用组内标准差；而本文指出，在奖励分布集中时，组内标准差是噪声源而非信号源。这一差异根源在于数据难度：GRPO 在 DeepSeek-R1 的训练中可能更多依赖中等难度数据，而本文在 Easy 数据上验证了组内标准差的危害。若数据分布均匀，组内标准差或许仍有效，但本文未提供跨难度分布的混合实验，限制了结论的普适性。

从方法设计看，本文的 Lite PPO 与 Dr. GRPO 在“移除方差”观点上一致，但 Dr. GRPO 侧重于防止偏差，而本文进一步引入了批次级标准差作为替代。与 DAPO 相比，DAPO 强调动态采样与长度惩罚，而本文通过 Token 级聚合间接解决了长度偏差问题。这种差异反映了两种技术路线：DAPO 通过数据侧调整优化，本文通过损失函数侧调整优化。在 Aligned 模型上，本文发现 Token 级聚合收益有限，暗示 DAPO 的长度惩罚可能在 Aligned 模型上更具必要性，但本文未对此进行直接对比。

## 总结

本文要解决的核心矛盾是 RL4LLM 技术组件推荐的碎片化与实验设置的不一致性。切入点在于通过统一框架下的单变量消融，剥离模型初始化与数据难度的干扰，识别出归一化与裁剪策略的适用边界。方法上，提出组均值+批标准差归一化与 Token 级损失聚合的极简组合（Lite PPO）。实验证明，该组合在 Base 模型上显著优于序列级聚合，在 Aligned 模型上通过 Clip-Higher 缓解熵坍缩，整体性能超越 GRPO 与 DAPO。边界在于，实验局限于数学推理任务，未验证在长程多轮交互中的稳定性，且缺乏对计算效率的评估。当任务从单轮数学推理扩展到多轮工具调用时，批次级标准差是否仍能有效抑制跨轮次的奖励波动，论文未给出回答。
