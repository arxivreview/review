# ICLR2026最新论文 ｜SPINNING STRAW INTO GOLD: RELABELING LLM - AGENT TRAJECTORIES IN HINDSIGHT FOR SUCCESS FUL DEMONSTRATIONS ｜后见之明监督学习

研究机构：加拿大麦吉尔大学、Adobe研究院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_7891907)

> 大语言模型智能体在长程任务中面临监督信号稀缺的瓶颈，传统强化学习依赖稀疏奖励难以高效探索，而监督微调又受限于专家演示的覆盖度。本文切入点在于利用智能体自身轨迹中“未指令但已达成”的目标，将其转化为高质量监督数据。具体做法是引入辅助大语言模型对轨迹进行后见之明重标注，并结合动作掩码与重加权策略进行微调。该方法在样本效率上表现突出，但其对重标注模型推理能力的依赖及缺乏与主流强化学习基线的直接对比，使其在通用智能体训练范式中的定位仍存疑。

## 研究背景

当智能体在部分可观测马尔可夫决策过程（POMDP）中执行长程任务时，环境状态的高维性与观察的局部性导致策略难以直接优化。此时，监督微调（SFT）虽能利用专家演示，但数据获取成本高且分布覆盖有限；而强化学习（RL）虽能通过试错挖掘策略，却在稀疏奖励下陷入信用分配困境，难以从失败轨迹中提取有效信号。后见之明经验回放（Hindsight Experience Replay, HER）在机器人领域通过重标注失败轨迹的目标来解决稀疏奖励问题，但其假设环境状态完全可观测且目标为结构化向量，无法直接迁移至自然语言指令驱动的大语言模型智能体场景。

现有后训练方法在数据效率与策略泛化间存在显著割裂。SFT 依赖静态专家数据，无法利用智能体自身探索产生的丰富轨迹；RL 方法如 PPO 或 GRPO 虽能在线学习，但受限于奖励信号的稀疏性与延迟性，在长程任务中收敛缓慢且易陷入局部最优。近期研究尝试通过合成数据或启发式奖励缓解此问题，但往往引入分布偏差或增加计算开销。本文针对这一矛盾，提出利用大语言模型的推理能力，从智能体已生成的轨迹中挖掘隐性成功目标，将“失败”转化为“成功”监督信号，从而在不依赖显式奖励函数的情况下提升数据利用率。

## 核心方法

### 方法参照系

本文问题可置于“基于演示的智能体后训练”框架下，标准流程为收集专家轨迹并进行 SFT 或 DPO 优化。关键差异在于：标准流程假设演示数据与指令严格匹配，而本文处理的是指令与轨迹目标不一致的场景，需通过重标注机制构建新的监督对，而非直接优化原指令下的策略。

### 后见之明目标重标注

传统 SFT 仅利用指令与轨迹完全匹配的样本，丢弃了大量包含部分成功信息的失败轨迹。本文在轨迹收集后引入辅助大语言模型 $M$，通过零样本推理识别轨迹中实际达成的所有目标 $K$ 个指令 $\{I'_1, \dots, I'_K\}$。对于每个重标注目标 $I'_k$，提取其首次达成时刻 $S(I'_k)$ 之前的轨迹片段 $\tau_{S(I'_k)}$ 作为成功演示。该过程将监督信号从“单一指令-完整轨迹”解耦为“多目标-局部轨迹”，解决了稀疏奖励下有效样本不足的问题。

$$
\{I'_1, \dots, I'_K\} = M_{\text{inst}}(\tau_T, o^*)
$$

其中 $M_{\text{inst}}$ 为包含目标空间描述的系统提示，$o^*$ 为最终观察。该公式表明重标注不依赖环境动力学预测，仅基于观察序列的逆向推理，降低了标注难度。

### 动作相关性掩码与演示重加权

重标注轨迹中可能包含与目标 $I'_k$ 无关的动作，直接训练会导致策略学习噪声。本文引入动作相关性标签 $z_{1:S(k)}$，由 $M$ 推断每个动作 $a_u$ 对 $I'_k$ 的贡献度，并在损失函数中掩码无关动作。同时，对重标注演示进行重加权，优先学习高置信度或高难度目标。这一设计解决了重标注数据中“动作-目标”错位导致的策略退化问题，确保智能体仅从有效行为中学习。

$$
\mathcal{L}_{\text{HSL}} = \sum_{k=1}^{K} w_k \sum_{u=1}^{S(I'_k)} z_u \cdot \log \pi_\theta(a_u | \tau_{u-1}, o_u, I'_k)
$$

其中 $w_k$ 为演示权重，$z_u$ 为动作相关性掩码。该损失函数通过掩码与加权机制，将重标注数据转化为高质量监督信号，弥补了原始轨迹在重标注目标下的次优性。

## 实验评估

实验在 ALFWorld、PlanCraft 和 WebShop 三个基准上进行，基线包括 SFT、DPO、ReAct、BAGEL 和 SELFIMIT。本文未对比 PPO、GRPO 等主流 RL 基线，仅评估 SFT/DPO 框架下的改进。主结果显示，HSL 在 ALFWorld Unseen 子集上显著提升：SFT+HSL 达到 97.8%，DPO+HSL 达到 94.8%，分别较基线 SFT（85.7%）和 DPO（82.8%）提升 12.1 和 12.0 个百分点。在 WebShop 上，SFT+HSL 达到 75.42%，DPO+HSL 达到 70.52%，提升幅度较小，表明 HSL 在目标多样性高的任务中收益更大。

| 方法 | ALFWorld Seen | ALFWorld Unseen | WebShop |
| :--- | :--- | :--- | :--- |
| SFT | 85.7% | 85.7% | 67.9% |
| SFT+HSL | 93.6% | 97.8% | 75.42% |
| DPO | 82.1% | 82.8% | 64.2% |
| DPO+HSL | 90.0% | 94.8% | 70.52% |

消融实验表明，移除动作掩码（NoMask）导致 ALFWorld Unseen 成功率从 97.8% 降至 89.3%，移除重加权（UniWeight）降至 87.1%，证明两项技术对抑制重标注噪声至关重要。样本效率测试显示，HSL 使用 1/4 真值演示即可超越全量数据基线，例如 DPO+HSL 在 800 个演示下达到 92.5%，而 DPO 在 3200+ 演示下仅 82.8%。

评估边界方面，论文未报告置信区间，且未提供代码与超参数细节，可复现性受限。指标仅关注成功率，未评估推理步数或计算开销。此外，实验未涵盖 OOD 任务，无法验证 HSL 在分布外场景的泛化能力。

## 关联研究分析

从问题动机看，HSL 与 BAGEL（Murty et al., 2024）均旨在解决演示数据稀缺问题，但 BAGEL 使用固定合成数据，而 HSL 动态更新重标注缓冲区。这一差异源于 BAGEL 假设目标空间静态，而 HSL 利用智能体自身探索的多样性，使重标注分布与智能体占用分布对齐，从而在长程任务中更有效地覆盖专家策略支持区域。BAGEL 的固定数据导致分布漂移，而 HSL 的在线更新机制缓解了此问题，但代价是增加了重标注模型的推理开销。

从方法设计看，HSL 与 SLEA-RL（Wang and Jiang, 2026）均利用智能体经验提升性能，但 SLEA-RL 依赖 RL 优化策略，而 HSL 采用纯监督学习。SLEA-RL 在 ALFWorld Unseen 上达到 60.3%，远低于 HSL 的 97.8%，表明在数据受限场景下，监督学习可能比 RL 更高效。然而，SLEA-RL 的 RL 机制在算力充足时可能具备更强的探索能力，而 HSL 的重标注依赖辅助 LLM 的推理准确性，若重标注模型存在系统性偏差，可能导致策略学习错误。论文未对比 RL 基线，无法排除 RL 在同等数据量下的潜在优势。

## 总结

本文核心矛盾在于长程任务中监督信号稀缺与智能体探索数据浪费之间的冲突。切入点在于利用大语言模型的推理能力，从失败轨迹中挖掘隐性成功目标，将“失败”转化为“成功”监督信号。方法上，HSL 通过辅助 LLM 重标注轨迹目标，并结合动作掩码与重加权策略进行 SFT/DPO 优化。实验证明，HSL 在 ALFWorld Unseen 上达到 97.8% 成功率，且使用 1/4 真值数据即可超越全量基线。边界在于，HSL 依赖重标注模型的推理准确性，且未与主流 RL 基线对比，无法验证其在算力充足场景下的相对优势。当重标注模型在复杂任务中出现系统性偏差时，HSL 的策略学习是否会被误导，论文未给出回答。
