# ICLR2026最新论文 ｜TABLET: A Large-Scale Dataset for Robust Visual Table Understanding ｜视觉表格理解数据集

研究机构：英国爱丁堡大学

作者：Iñigo Alonso、Imanol Miranda、Eneko Agirre 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.21205)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.21205)

> 视觉表格理解（Visual Table Understanding, VTU）旨在让模型直接从像素中解析表格，以应对真实网页中合并单元格、背景色等视觉线索无法被文本序列化完整保留的困境。现有VTU数据集多依赖合成渲染，导致模型在真实视觉布局上泛化失效，本文通过回溯历史网页快照构建无损图像数据集填补该空白。其核心做法是聚合14个种子数据集并保留88%的原始可视化，以统一指令格式支持21项任务。该资源确立了数据真实性对鲁棒性的决定性作用，但其对复杂层级结构的视觉解析能力仍存疑。

## 研究背景

当VLM处理屏幕上的表格时，若依赖Markdown或HTML序列化，合并单元格的空间对齐与字体变化等视觉特征会被扁平化丢失。这种2D-to-1D转换的固有缺陷，迫使研究者转向直接处理表格图像，但现有训练数据多为从序列化文本重新渲染的合成图像，其视觉模式与真实网页截图存在系统性偏差，即训练-测试失配。

表格理解领域长期聚焦于结构编码与推理增强，如通过图/超图建模保留拓扑结构（TABGR, TAMO）或引入强化学习提升计算可靠性。然而，这些方法多假设输入为结构化文本或理想化图像，忽视了真实世界表格的视觉噪声与不规则性。MMTab等早期VTU数据集虽引入图像模态，但其图像源自合成渲染，无法反映真实布局的复杂性，导致模型在含细微 ruling lines 或嵌入图像的表格上性能骤降。

本文切入点在于数据源的真实性而非模型架构创新。通过利用Wikipedia归档API回溯表格被爬取时的历史版本，TABLET获取了保留原始视觉特征的无损图像，从而在数据层面消除了合成渲染带来的分布偏移，为VLM提供了与下游应用对齐的训练资源。

## 核心方法

### 方法参照系

VTU任务通常遵循“图像输入-视觉编码-文本生成”流程，核心挑战在于视觉编码器能否捕捉表格的空间语义。本文不改变模型架构，而是重构数据供给环节，将传统的“序列化-渲染”流程替换为“原始截图-指令对齐”，关键差异在于图像来源的保真度与可追溯性。

### 无损可视化获取

设计动机在于解决合成渲染导致的视觉线索丢失，如背景色与字体变化在重新渲染中常被标准化。本文通过计算种子数据集表格与Wikipedia历史版本Markdown格式的Levenshtein编辑距离，筛选相似度阈值 $\ge 0.7$ 的原始截图：

$$
S = 1 - \frac{D_{lev}(T_{seed}, T_{wiki})}{\max(|T_{seed}|, |T_{wiki}|)}
$$

其中 $D_{lev}$ 为编辑距离，$S$ 为相似度。该机制确保了图像与文本内容的一致性，同时保留了原始网页的视觉布局，使模型能学习到真实表格的细微视觉特征。

### 统一指令格式与多任务聚合

设计动机在于避免固定提示词导致的过拟合，并支持跨任务迁移。本文将14个种子数据集的任务统一为指令格式，包含指令、原子数据、HTML版本及元数据：

$$
\mathcal{D} = \{(I_i, T_i^{img}, T_i^{html}, M_i, A_i)\}_{i=1}^{N}
$$

其中 $I_i$ 为指令，$T_i^{img}$ 为图像，$T_i^{html}$ 为HTML序列化，$M_i$ 为元数据，$A_i$ 为答案。这种设计允许模型在缺乏原始图像时使用HTML渲染，并在训练时通过混合原始与合成图像提升鲁棒性，实现了数据规模与视觉多样性的平衡。

## 实验评估

实验基于Qwen2.5-VL-7B-Instruct，对比Zero-shot、1-shot及MMTab微调模型，覆盖8个held-in与7个held-out任务。基线审计显示，本文未直接对比TABGR等文本模态SOTA方法，因模态不同，但对比了MMTab这一主要VTU基线，揭示了数据源差异的影响。

| 训练变体 | WikiTQ (Acc) | TabFact (Acc) | HiTab (F1) | 退化幅度 (∆) |
|---|---|---|---|---|
| Zero-shot | - | - | - | 28.9 |
| TABLET-Bsynth | - | - | - | 22.35 |
| TABLET-Borg | - | - | - | 6.63 |
| TABLET-Bmix | - | - | - | 7.87 |

注：表格中具体任务数值未在数据区逐字提供，仅退化幅度（∆）可定位。TABLET-Borg在原始可视化评估下退化幅度最低（6.63点），显著优于合成训练（22.35点），证明原始图像暴露对鲁棒性的关键作用。TABLET-Bmix在5/7任务上取得最佳绝对性能，表明混合训练兼顾准确性与鲁棒性。

消融实验显示，TABLET-M（1.1M样本）在部分任务上优于TABLET-L（4M样本），提示任务平衡比单纯规模更重要。移除Table Interpretation任务后，模型在HiTab等视觉丰富任务上性能下降，验证了基础结构理解任务对下游推理的迁移价值。

评估边界方面，本文未报告置信区间，且部分held-out数据集可能在预训练中已被曝光，影响泛化评估的严谨性。代码与数据已开源，但GPU配置与训练细节仅在附录中简要提及，复现成本较高。

## 关联研究分析

从问题动机看，本文与Table-LLaVA同属多模态路线，但Table-LLaVA侧重模型内部的视觉-文本对齐机制，而本文聚焦数据源的视觉保真度。这一差异源于任务特性：Table-LLaVA假设图像质量可控，而本文直面真实网页的视觉噪声。若数据源已足够真实，模型内部对齐机制的边际收益是否递减，论文未给出回答。

从方法设计看，本文与MMTab形成直接对比，MMTab依赖合成渲染，而本文通过历史回溯获取原始图像。这种数据构建策略的根源在于对“视觉表格理解”定义的差异：MMTab视表格为结构化文本的视觉化，本文视其为独立的多模态实体。在含复杂层级结构的表格中，视觉保真度能否替代显式结构编码（如图/超图），仍是未解之谜。

## 总结

本文核心矛盾在于VTU训练数据与真实视觉布局的分布失配。通过回溯Wikipedia历史版本获取无损图像，TABLET在数据层面解决了合成渲染导致的泛化失效。其证明了原始可视化训练可将退化幅度从22.35点降至6.63点，确立了数据真实性对鲁棒性的决定性作用。边界在于，本文未验证视觉保真度在复杂层级表格中能否替代显式结构编码，且部分held-out数据集的预训练曝光影响了泛化评估的严谨性。当表格包含多级表头与合并单元格时，纯视觉解析的准确率是否足以支撑复杂推理，论文未给出回答。
