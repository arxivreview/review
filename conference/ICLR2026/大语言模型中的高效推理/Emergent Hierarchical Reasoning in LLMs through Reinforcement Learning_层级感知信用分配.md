# ICLR2026最新论文 ｜Emergent Hierarchical Reasoning in LLMs through Reinforcement Learning ｜层级感知信用分配

研究机构：加拿大滑铁卢大学、英国帝国理工学院

作者：Haozhe Wang、Qixin Xu、Che Liu 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.03646)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.03646)

> 强化学习（RL）在提升大语言模型（LLM）复杂推理能力时，常出现“顿悟时刻”与长度扩展等难以解释的训练动力学现象，且现有算法如GRPO对所有Token施加无差别的优化压力，导致学习信号在低价值Token上被稀释。本文切入点在于揭示RL训练中存在从“程序正确性”到“战略规划”的阶段性瓶颈转移，并指出当前算法未能针对这一战略瓶颈进行聚焦。HICRA通过识别战略语法（Strategic Grams, SGs）并放大规划Token的信用分配，实现了训练效率与最终准确率的提升。该工作为理解RL推理涌现提供了机制解释，但其依赖静态文本代理的局限性及未验证的效率影响存疑。

## 研究背景

当LLM通过RL进行后训练时，模型并非从零学习推理，而是基于预训练中内化的人类解题先验进行微调。这一过程涉及两个核心概念：一是**程序性执行**，即算术计算、变量替换等基础操作；二是**战略规划**，即推导、分支与回溯等高阶逻辑操纵。传统RL算法如GRPO（Group Reward Policy Optimization）将轨迹视为整体，对所有Token均匀计算优势值，这种无差别优化假设了所有Token对最终奖励的贡献是均等的，忽略了推理过程中不同Token的功能层级差异。

现有主流路线如LEASH、DeepCompress等聚焦于通过长度惩罚或奖励整形来抑制“过度思考”，旨在优化Token效率与准确率的帕累托边界。然而，这些方法主要关注推理结果的长度约束，未深入探究RL训练内部的动力学机制，即模型究竟是如何从基础技能过渡到高级策略的。本文的切入点在于，通过实证分析发现RL训练存在一个动态的“学习前沿”转移：初期受限于程序正确性，后期瓶颈转向战略规划。这一发现揭示了现有无差别信用分配算法的根本低效性，即未能将优化压力集中在真正驱动性能提升的战略Token上。

## 核心方法

### 方法参照系

本文问题置于RLVR（Reinforcement Learning with Verifiable Rewards）框架下，标准流程为GRPO：对同一查询生成$G$条轨迹，基于组内归一化奖励计算每个Token的优势值$A_{i,t}$，并更新策略。本文与标准流程的关键差异在于，它不将Token视为同质单元，而是基于功能层级对Token进行分类，并据此修改优势计算逻辑，以解决无差别优化导致的信号稀释问题。

### 战略语法识别与层级分解

设计动机在于解决“如何自动化识别高价值规划Token”的难题，避免人工标注的主观性。本文提出战略语法（SGs）作为功能代理，定义为在多个不同解题方案中高频出现、但在单一方案中稀疏使用的$n$-gram（$n \in [3, 5]$）。通过语义聚类合并同义表达，并筛选Cluster Document Frequency（簇文档频率）前20%的簇，构建SG集合。若Token属于SG，则标记为规划Token，否则为执行Token。这一机制将离散的文本Token映射到连续的战略功能空间，为后续差异化优化提供了可操作的分类依据。

### 层级感知信用分配

设计动机在于解决GRPO在战略探索阶段优化压力不足的问题。HICRA修改GRPO的优势函数，引入层级掩码。设$S_i$为轨迹$i$中规划Token的索引集合，HICRA优势值定义为：

$$
\hat{A}_{i,t}^{\text{HICRA}} = \begin{cases}
\hat{A}_{i,t} + \alpha \hat{A}_{i,t} & \text{if } t \in S_i, \hat{A}_{i,t} > 0 \\
\hat{A}_{i,t} - \alpha |\hat{A}_{i,t}| & \text{if } t \in S_i, \hat{A}_{i,t} < 0 \\
\hat{A}_{i,t} & \text{otherwise}
\end{cases}
$$

其中$\alpha \in (0, 1)$控制放大强度（实验取0.2）。该公式的物理含义是：对于成功轨迹，放大规划Token的正向信用；对于失败轨迹，放大规划Token的负向惩罚；执行Token保持原状。这种各向异性的目标分布$\pi^*_{\text{HICRA}}$将策略更新压力从均匀分布转向战略维度，加速模型对有效高阶策略的探索与强化，从而在保持程序可靠性的同时，突破战略规划的瓶颈。

## 实验评估

实验在Qwen3-4B、Llama-3.1-8B等文本模型及MiMO-VL等视觉语言模型上，使用DAPO、DeepScaleR等数据集训练，并在AIME24/25、Math500、Minerva等基准上评估。基线覆盖GRPO、Base及Entropy Regularization，但缺失LEASH、DeepCompress等效率优化强基线，导致无法直接对比准确率-效率权衡。

| Model | AIME24 | AIME25 | Math500 | AMC23 | Minerva | Olympiad |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Qwen3-4B-Instruct** | | | | | | |
| Base | 63.4 | 47.7 | 94.6 | 86.7 | 45.2 | 72.4 |
| GRPO | 68.5 | 60.0 | 96.2 | 88.5 | 50.0 | 72.7 |
| HICRA | **73.1** | **65.1** | **97.2** | **90.2** | **50.7** | 72.0 |
| **Qwen3-4B-Base** | | | | | | |
| Base | 9.4 | 5.3 | 63.8 | 38.9 | 28.3 | 30.7 |
| GRPO | 24.9 | 23.8 | 83.0 | 51.2 | 38.9 | 45.8 |
| HICRA | **31.0** | **27.6** | **89.0** | **54.0** | **42.5** | **48.1** |

在Qwen3-4B-Instruct上，HICRA在AIME24上较GRPO提升5.4个百分点，在AIME25上提升5.1个百分点，表明战略聚焦在强基座模型上仍有显著增益。在Qwen3-4B-Base上，HICRA在Math500上较GRPO提升6.0个百分点，显示在弱基座上，解决战略瓶颈对整体性能提升更为关键。

消融分析显示，HICRA相比Entropy Regularization，不仅提升了准确率，还避免了后者导致的长度失控。Entropy Regularization虽增加了Token级熵，但未提升语义熵（战略多样性），导致推理链冗长且无效。HICRA通过提升语义熵，实现了战略探索的有效扩展，验证了“语义熵优于Token熵”作为探索诊断指标的有效性。

评估边界方面，论文未报告推理Token消耗或延迟，无法评估HICRA对“过度思考”的影响，可能牺牲效率换取准确率。代码未公开，仅提供项目主页，复现依赖SGs构建流程的细节。评估协议采用Pass@1，未提供置信区间，数值比较需谨慎。

## 关联研究分析

从问题动机看，HICRA与LEASH、DeepCompress等效率优化方法存在根本差异。LEASH通过拉格朗日约束优化长度，旨在降低简单任务的计算开销；HICRA则通过放大规划Token信用，旨在提升复杂任务的战略探索效率。前者关注“做多少”，后者关注“怎么做”。这种差异源于对RL瓶颈的不同定义：效率优化认为瓶颈是冗余计算，HICRA认为瓶颈是战略信号稀释。若将HICRA与长度惩罚结合，可能探索“战略深度”与“计算效率”的联合优化，但论文未验证两者是否冲突。

从方法设计看，HICRA与推理机制可解释性研究（如Thinking Sparks、STARS）有交集但路径不同。Thinking Sparks通过电路分析识别推理注意力头，属于内部状态监控；HICRA使用基于文本n-gram的SGs，属于表面特征代理。尽管SGs通过语义聚类提升了鲁棒性，但其静态性可能无法适应动态推理结构中的新战略模式。知识库共识认为“内部状态信号优于表面启发式”，HICRA的选择是否违背这一共识，取决于SGs能否充分捕捉内部策略变化，论文未提供内部状态对比实验。

## 总结

本文核心矛盾在于RL训练中存在战略探索瓶颈，但现有算法如GRPO无差别优化导致信号稀释。HICRA通过识别战略语法并放大规划Token信用，解决了这一低效性，在Qwen3-4B-Instruct上AIME24准确率提升至73.1%，较GRPO提升5.4个百分点。其边界在于依赖静态文本代理SGs，未验证对推理效率的影响，且缺乏与效率优化方法的直接对比。当SGs集合无法覆盖模型在训练后期涌现的新战略模式时，HICRA的信用分配是否仍能有效引导探索，论文未给出回答。
