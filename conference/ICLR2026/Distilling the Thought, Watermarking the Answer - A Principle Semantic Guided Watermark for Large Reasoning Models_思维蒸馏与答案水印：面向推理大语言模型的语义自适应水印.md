# ICLR2026最新论文 ｜Distilling the Thought, Watermarking the Answer: A Principle Semantic Guided Watermark for Large Reasoning Models ｜思维蒸馏与答案水印：面向推理大语言模型的语义自适应水印

研究机构：香港科技大学

作者：Shuliang Liu、Xingyu Li、Hongyi Liu 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.05144)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.05144)

> 推理大语言模型（RLLMs）在生成最终答案前需经历内部思维链（CoT）阶段，传统水印方法对全序列施加统计偏置会破坏推理逻辑，导致答案准确率下降。现有语义水印虽改善质量，但引入额外推理延迟或依赖辅助模型，无法兼顾效率与逻辑完整性。ReasonMark 将生成过程解耦为无扰动的思维阶段与受控的答案阶段，通过提取思维链中的关键语义向量（PSV）动态调制答案阶段的水印强度，在保持推理完整性的同时实现高检测率。该方法在质量-检测权衡上优于通用基线，但其对长思维链的泛化能力及多比特编码支持仍存疑。

## 研究背景

推理大语言模型（RLLMs）如 DeepSeek-R1 采用内部独白或思维链（Chain-of-Thought, CoT）机制处理复杂任务，其生成序列 $T$ 可划分为思维阶段 $T_{think}$ 与答案阶段 $T_{answer}$。水印嵌入需在不破坏 $T_{think}$ 逻辑连贯性的前提下，在 $T_{answer}$ 中植入可检测信号。传统基于 Token 的水印方法（如 KGW）通过伪随机划分词汇表并偏置 Logits 实现检测，但其随机性会干扰思维阶段的因果依赖，导致推理断裂。

文本水印领域长期存在质量、鲁棒性与效率的三角权衡。KGW 等 Token 级方法虽检测效率高，但伪随机偏置破坏了 RLLMs 的逻辑一致性；Unigram 等无偏方法虽保持分布不变，但检测率随编辑攻击显著下降；EWD 与 SWEET 通过增强统计信号提升检测率，却引入可感知的文本伪影；WaterMax 等迭代优化方法虽平衡了质量与检测，但多次生成导致推理延迟激增。语义水印方法（如 SemStamp）在嵌入空间操作以抵抗改写，但通常需辅助模型或架构修改，增加了部署复杂度。

ReasonMark 的切入点在于识别 RLLMs 特有的“思维-答案”结构差异。现有方法将水印视为全局信号，未区分推理过程与最终输出的功能差异。本文提出“蒸馏思维，水印答案”原则，将水印作用域限制在答案阶段，并通过思维链中的语义锚点引导水印强度，从而在结构上规避对推理逻辑的干扰，同时避免语义水印的高计算开销。

## 核心方法

### 方法参照系

本文问题属于自回归文本水印范畴，但针对 RLLMs 的 CoT 结构进行了阶段解耦改造。标准 KGW 流程在每一步生成时基于上下文哈希划分绿红列表并偏置 Logits，而 ReasonMark 仅在答案阶段执行偏置，且偏置强度由思维阶段蒸馏的语义向量动态调制，而非固定或上下文哈希决定。

### 关键性评分与语义向量构建

传统方法未区分 Token 在推理过程中的重要性，导致水印信号均匀分布，易被局部编辑破坏。ReasonMark 引入关键性评分（Criticality Score, CS）识别思维链中的语义锚点。CS 由全局因果贡献（GCC）与竞争持久性评分（CPS）组成，GCC 量化 Token 对后续推理轨迹的因果影响，CPS 衡量 Token 在局部窗口内的竞争稳定性。

$$
CS(w) = GCC(w) \cdot \log(1 + CPS(w))
$$

该公式表明，高关键性 Token 需同时具备强因果影响力与高竞争稳定性。通过选取 Top-K 关键 Token 并执行主成分分析（PCA），构建初始主语义向量（Principal Semantic Vector, PSV）。PSV 作为连续语义罗盘，捕捉思维链的核心方向，为答案阶段提供动态引导。

### 语义自适应水印嵌入

传统水印强度固定，导致与语义无关的 Token 也被偏置，破坏文本自然度。ReasonMark 在答案阶段，基于候选 Token 与当前 PSV 的对齐程度动态调制水印强度。设 $R_i$ 为第 $i$ 步的 PSV，$\delta_{i,t_i}$ 为水印引导量，则 Logits 调整量为：

$$
\Delta z_{i,t} = \gamma \cdot \text{sim}(e_t, R_i)
$$

其中 $\text{sim}$ 为余弦相似度，$\gamma$ 为强度系数。该机制使语义连贯的 Token 获得更强水印信号，而偏离推理轨迹的 Token 偏置减弱。通过单次采样完成水印嵌入，避免了迭代优化带来的延迟，实现了鲁棒性与效率的平衡。

## 实验评估

实验在 C4、WMT16-DE-EN、AIME 与 GSM8K 数据集上评估，基线涵盖 KGW、Unigram、SWEET、EWD、SemStamp 等 Token 级与语义级方法，缺失 DLM 专用方法（如 DMark，因架构不同）。

| 方法 | C4 PPL (↓) | C4 AUC (↑) | WMT16 BLEU (↑) | AIME mACC (↑) |
|---|---|---|---|---|
| No Watermark | 10.55 | - | 7.851 | 70.03 |
| KGW | 12.15 | 98.78 | 7.351 | 69.23 |
| SemStamp | 11.42 | 97.85 | 7.912 | 68.90 |
| ReasonMark | 10.31 | 99.31 | 9.916 | 69.86 |

ReasonMark 在 C4 上 PPL 10.31 低于无水印基线 10.55，AUC 99.31 高于 KGW 的 98.78；WMT16 BLEU 9.916 显著高于无水印的 7.851，表明水印未损害翻译质量。

| 变体 | PPL (↓) | AUC (↑) |
|---|---|---|
| ReasonMark | 10.3080 | 99.31 |
| w/o CTs | 12.8801 | 99.21 |
| w/o GCC | 11.1510 | 99.11 |
| w/o CPS | 11.0597 | 98.69 |

移除关键 Token 选择（w/o CTs）导致 PPL 升至 12.8801，表明语义锚点对质量至关重要；移除 CPS 使 AUC 降至 98.69，验证了竞争持久性对检测鲁棒性的贡献。

评估协议未报告置信区间，且仅使用 Qwen3-32B 与 DeepSeek-R1-32B 两个模型，缺乏跨模型规模验证。代码已开源，但 PSV 构建的 PCA 维度与 Top-K 值未详细披露，复现时需依赖默认设置。

## 关联研究分析

从问题动机看，ReasonMark 与 KGW 的核心差异在于水印作用域。KGW 假设生成过程顺序确定且攻击者仅进行简单替换，故全程偏置；ReasonMark 针对 RLLMs 的 CoT 结构，将水印限制在答案阶段，避免了思维链的逻辑干扰。这一差异源于任务特性：RLLMs 的推理过程对扰动敏感，而通用 LLM 的生成过程相对鲁棒。

从方法设计看，ReasonMark 与 SemStamp 均利用语义信息，但 SemStamp 依赖辅助模型计算嵌入相似度，引入额外延迟；ReasonMark 通过思维链蒸馏 PSV，无需辅助模型，且 PSV 随答案生成动态更新，更贴合 RLLMs 的实时推理特性。PSV 对长思维链的泛化能力未验证，当思维链长度超过训练分布时，PCA 提取的语义方向是否仍具代表性，论文未给出回答。

## 总结

ReasonMark 旨在解决 RLLMs 水印嵌入中逻辑完整性与检测鲁棒性的矛盾。现有方法要么破坏推理逻辑（KGW），要么引入高延迟（WaterMax），ReasonMark 通过“思维-答案”解耦与 PSV 引导，在结构上规避了推理干扰，并通过语义自适应调制提升检测率。实验显示，其在 C4 上 PPL 10.31 低于无水印基线，AUC 99.31 优于 KGW，验证了解耦架构的有效性。然而，实验仅覆盖两个 32B 模型，且未评估多比特编码能力，PSV 在长思维链或跨语言场景下的稳定性仍存疑。当思维链长度显著增加时，PCA 提取的语义方向是否仍能准确捕捉推理核心，论文未给出回答。
