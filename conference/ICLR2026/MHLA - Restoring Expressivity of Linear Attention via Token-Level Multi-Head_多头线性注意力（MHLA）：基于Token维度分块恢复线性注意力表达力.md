# ICLR2026最新论文 ｜MHLA: Restoring Expressivity of Linear Attention via Token-Level Multi-Head ｜多头线性注意力（MHLA）：基于Token维度分块恢复线性注意力表达力

研究机构：北京大学

作者：Kewei Zhang、Ye Huang、Yufan Deng 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.07832)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.07832)

> 线性注意力通过压缩全局键值摘要实现 $O(N)$ 复杂度，但固定大小的摘要矩阵导致“全局上下文坍缩”，使模型丧失查询依赖的多样性。现有补偿方案依赖额外卷积或门控模块，引入计算开销且随序列增长性能仍退化。MHLA 将序列沿 Token 维度划分为非重叠块，通过可学习的块间混合系数恢复查询条件化的局部摘要组合，在不增加辅助模块的前提下维持线性复杂度。该方法在图像分类、生成及 NLP 任务上显著优于基线，但其块划分策略的静态性限制了动态场景下的适应性，且理论秩界在极端长序列下的实际可达性尚存疑。

## 研究背景

理解 MHLA 需先厘清线性注意力的数学瓶颈。标准 Softmax 注意力计算所有 Token 对的相似度，复杂度为 $O(N^2)$；线性注意力替换为核函数特征映射 $\phi(\cdot)$，将计算重排为全局键值摘要 $G = \sum_j \phi(K_j)^\top V_j$ 与查询向量的内积，复杂度降至 $O(Nd^2)$。然而，$G$ 是一个固定的 $d \times d$ 矩阵，无论序列长度 $N$ 如何增长，其容量始终受限。当 $N \gg d$ 时，大量 Token 信息被压缩进低维空间，导致注意力矩阵秩严格受限于 $d$，且注意力分布趋向均匀，即“全局上下文坍缩”。

该现象揭示了线性注意力在效率与表达力间的根本矛盾：全局摘要虽保证了线性复杂度，却抹平了不同查询对上下文的差异化需求。早期工作如 RALA 和 MALA 尝试通过引入深度卷积或门控机制来补偿表达力损失，但这些外部模块增加了参数量与计算开销，且在长序列下性能退化问题并未根本解决。MHLA 的切入点在于识别出“Token 维度缺乏分组”是秩受限的根源，主张通过内部结构重构而非外部模块堆叠来恢复表达力。

## 核心方法

### 线性注意力参照系与秩瓶颈

标准线性注意力将序列所有 Token 压缩为单一全局摘要 $G$，其注意力矩阵 $A_{lin} = \phi(Q)\phi(K)^\top$ 的秩满足 $\text{rank}(A_{lin}) \le d$。这一上界意味着当序列长度 $N$ 远大于头维度 $d$ 时，模型无法表达 $N \times N$ 全注意力矩阵中丰富的查询-键交互模式。MHLA 的核心差异在于摒弃单一全局摘要，转而采用多块局部摘要的线性组合，从而打破秩的硬性上界。

### Token 维度分块与局部摘要计算

MHLA 将输入序列 $X \in \mathbb{R}^{N \times d}$ 沿 Token 维度划分为 $M$ 个非重叠块，每块包含 $n_b$ 个 Token。对每个块 $b$，独立计算局部键值摘要 $S_b = \sum_{t \in \text{block}_b} \phi(K_t)^\top V_t$ 及归一化项 $z_b$。设计动机在于：局部摘要保留了块内 Token 的细粒度信息，避免了全局压缩导致的细节丢失。由于块间无重叠，各 $S_b$ 捕获了序列不同区段的上下文特征，为后续查询依赖的组合提供了基础。

### 多块混合与查询条件化重加权

MHLA 引入可学习系数矩阵 $M_c \in \mathbb{R}^{M \times M}$，其中第 $i$ 行 $m_i$ 表示查询块 $i$ 对各局部摘要的混合权重。查询块 $i$ 的混合摘要定义为：

$$ S_i = \sum_{b=1}^{M} m_{i,b} S_b $$

输出计算为 $O_i = \phi(q_i)^\top S_i / z_i$。该公式的物理含义是：每个查询块通过 $m_i$ 动态加权所有局部摘要，实现块级选择；块内 Token 的贡献则通过核内积 $\phi(q_i)^\top \phi(K_t)$ 进一步区分。这种“块级选择 × 块内重加权”的两阶段机制，使注意力矩阵秩提升至 $\sum_{b=1}^{M} \min(n_b, d)$，在 $M^2 \le N$ 条件下保持 $O(Nd^2)$ 复杂度。初始化时 $m_{i,j}$ 按欧氏距离衰减，确保局部性偏置以加速收敛。

## 实验评估

实验覆盖图像分类（DeiT/VLT）、图像生成（DiT/DiG/Sana）、NLP（GLA/Mamba 架构）及视频生成（Wan2.1）。基线涵盖 Self-Attention、标准 Linear Attention、MALA、RALA、GLA、Mamba 等，但未直接对比 FlashAttention 等硬件优化基线。在 DeiT-S 设置下，MHLA 以 22M 参数、4.2G FLOPs 取得 81.0% Top-1 准确率，超越 Self-Attention 的 79.8% 和 MALA 的 80.3%；在 ImageNet-1K SOTA 对比中，MHLA-VLT-S 以 27M 参数、4.6G FLOPs 达到 84.6%，优于 MAViT-S 的 84.3%。

| 模型 | 参数量 | FLOPs | Top-1 ACC |
| :--- | :--- | :--- | :--- |
| Self Attn (DeiT-S) | 22M | 4.2G | 79.8 |
| MALA (DeiT-S) | 24M | 4.6G | 80.3 |
| MHLA (DeiT-S) | 22M | 4.2G | 81.0 |
| MAViT-S | 27M | 4.6G | 84.3* |
| MHLA-VLT-S | 27M | 4.6G | 84.6 |

消融实验显示，头数 $M$ 对性能影响显著：在 DiT-S/2 512 分辨率下，$M=16$ 时 FID 为 78.63，吞吐量 435；$M=64$ 时 FID 升至 79.50，吞吐量降至 408。这表明 $M$ 过小导致表达力不足，过大则引入冗余计算，$M=16$ 在性能与效率间取得最优平衡。NLP 实验中，MHLA 在 MMLU 上取得 51.3 分，超越 Mamba 的 46.4 和 GLA 的 46.0；LongBench 平均分为 7.41，高于 Mamba 的 6.97。

评估边界方面，论文未报告置信区间，且 LongBench 成绩（7.41）高于领域综述中记录的 MHLA 基线值（6.97），可能源于评测协议或模型规模差异。代码已开源，但硬件感知内核优化（如 FlashAttention 集成）未深入讨论，实际部署中 IO 瓶颈可能影响加速比。

## 关联研究分析

从问题动机看，MHLA 与 Condensate Theorem 形成理论互补。Condensate Theorem 证明训练后 Transformer 自发学习稀疏性，动态选择高注意力位置可实现无损稀疏化；而 MHLA 通过静态块划分恢复线性注意力的秩，二者均挑战了“稀疏化/线性化必然损失精度”的传统认知。差异在于：Condensate Theorem 依赖内容相关性评分，计算开销随序列增长；MHLA 依赖空间距离初始化，计算开销固定。这种差异暗示，在长序列动态生成场景中，MHLA 的静态块划分可能无法适应内容驱动的依赖变化，而 Condensate Theorem 的动态选择虽更灵活，但面临计算瓶颈。

从方法设计看，MHLA 与 SPAttention 同属“头部专业化”路线，但维度不同。SPAttention 在特征维度划分频段，强制不同头部关注不同距离范围；MHLA 在 Token 维度划分块，通过可学习系数混合局部摘要。SPAttention 依赖头部数量配置确保频段均匀性，MHLA 依赖 $M$ 值平衡表达力与效率。二者均未解决训练-推理不匹配问题：SPAttention 的频段划分在推理时固定，MHLA 的块划分同样静态。这种共性局限表明，当前头部专业化方法在动态场景下的泛化能力仍待验证。

## 总结

MHLA 针对线性注意力全局摘要导致的秩受限与熵升高问题，提出 Token 维度分块与多块混合机制，在不增加辅助模块的前提下将注意力矩阵秩从 $d$ 提升至 $\sum \min(n_b, d)$。实验证明其在 DeiT-S 上以 81.0% 准确率超越 Self-Attention，在 MMLU 上以 51.3 分优于 Mamba，验证了内部结构重构对表达力恢复的有效性。然而，块划分策略的静态性限制了其对动态内容依赖的适应性，且 $M$ 值需手动调优以平衡性能与效率。当序列长度进一步增长至百万级时，固定块划分是否仍能维持查询条件化的多样性，论文未给出回答。
