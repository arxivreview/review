# ICLR2026最新论文 ｜Sannara Ek ｜时序惊讶度引导的视觉Token剪枝

研究机构：英国南安普顿大学、英国伦敦大学学院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ICLR_2026_3936147)

> 视频理解模型在处理长序列时面临计算资源与上下文窗口的硬性约束，现有基于注意力权重或关键帧选择的剪枝方法往往依赖内部状态或额外训练，难以在部署环境中灵活适配。本文切入点在于利用视频帧间的时序可预测性，将“惊讶度”作为无需训练且骨干无关的Token保留准则。通过构建轻量级时序预测器并计算预测误差，SURGE在大幅削减Token数量的同时维持了精度稳定性。该方法在效率-精度权衡上表现优异，但其对复杂语义推理能力的提升边界尚存疑。

## 研究背景

视频语言模型（VLMs）在处理视频时，视觉编码器将每帧划分为大量Patch Token，导致输入序列迅速膨胀至数千甚至数万Token。这种规模使得注意力机制的二次方复杂度成为长视频理解的瓶颈，尤其在流式输入或有限硬件场景下，模型往往因内存溢出或延迟过高而无法部署。为缓解此问题，研究界主要沿两条路径探索：一是时间稀疏性，即通过关键帧选择（如AKS、SeViLA）减少处理帧数；二是Token稀疏性，即通过注意力阈值或相关性分数（如FastV、SparseVLM）在帧内剪枝冗余Patch。然而，这些方法存在显著局限：关键帧选择可能丢失帧内细粒度动态，而基于注意力的剪枝依赖内部注意力图，这在许多部署系统中不可用，且需针对特定模型进行阈值校准。

现有方案的核心缺陷在于缺乏一个通用的、无需重训练的动态计算分配信号。注意力权重反映的是当前步骤的“重要性”，而非“新颖性”，导致模型在冗余但相关的片段上浪费计算，同时可能忽略突发新事件。本文提出SURGE，旨在解决这一矛盾：通过测量Token在时序上的可预测性，直接识别携带新信息的内容。该方法不依赖模型内部状态或额外训练，仅利用视觉编码器输出的Patch嵌入，通过时序预测误差生成“惊讶度”分数，从而在推理阶段自适应地分配计算资源，实现高效且鲁棒的视频理解。

## 核心方法

### 方法参照系

本文问题属于视频VLM推理效率优化范畴，具体聚焦于Token级剪枝。与依赖注意力图或训练选择器的传统方法不同，SURGE的核心差异在于其准则的“时序动态性”：它不评估Token的静态重要性，而是评估Token相对于历史上下文的偏离程度，从而在无需访问模型内部状态的情况下实现自适应计算分配。

### 时序惊讶度计算

SURGE首先建立Token空间的常速度先验，利用一阶泰勒展开近似帧间动态。对于Token $j$，其位移 $\Delta z_t^{(j)} = z_t^{(j)} - z_{t-1}^{(j)}$ 被用于构建因果预测器。为消除相机平移等全局漂移带来的虚假惊讶，SURGE引入仿射漂移校正，通过最小二乘法拟合位移场的仿射系数 $\hat{C}$，得到去趋势化位移 $\tilde{\delta}_t^{(j)}$。最终，惊讶度分数 $s_t^{(j)}$ 定义为预测误差与历史方差归一化后的比值：

$$ s_t^{(j)} = \frac{\| z_t^{(j)} - \hat{z}_t^{(j)} \|^2}{\sigma_t^2[j] + \epsilon} $$

该公式的物理含义是：在局部线性高斯动态假设下，若Token变化符合预期，分数接近均值；若出现显著偏离，分数激增，从而精准标记新颖内容。这一设计解决了传统方法无法区分“全局运动”与“局部事件”的失效问题，确保了惊讶度信号的稳定性。

### 时空掩码构建

基于Token级惊讶度，SURGE通过全局百分位阈值生成二值掩码，保留Top-$\rho$ 的高惊讶Token。随后，将Token分数在时间维度聚合，形成“惊讶曲线”，并通过指数移动平均平滑后检测峰值，划分关键事件窗口。对于查询驱动任务，SURGE进一步利用CLIP相似度对峰值帧进行排序，仅保留Top-$K$ 相关事件，形成紧凑的时空掩码。这一机制将计算资源集中分配给既“新颖”又“相关”的内容，实现了从静态剪枝到动态聚焦的跨越，显著提升了长视频检索的精度与效率。

## 实验评估

实验在Video-MME、MLVU、MMBench-Video、TempCompass和LongVideoBench五个基准上进行，对比基线包括随机剪枝、FastV（注意力剪枝）和AKS（关键帧选择）。SURGE在默认保留25% Token（$\rho=0.25$）时，精度与全Token基线保持在±1点以内，而Token数量减少约4倍；结合CLIP Top-5聚焦后（SURGE$^\star$），Token减少至约14%（7倍），精度仍稳定。

| Qwen2.5-VL (7B) | Baseline | 41,590 | 62.2 | 65.8 / 4.26 | 70.5 | 60.0 |
| | + SURGE | 10,992 | 60.9 | 65.7 / 4.26 | 70.5 | 59.4 |
| | + SURGE$^\star$ | 5,207 | 62.7 | 66.1 / 4.24 | 67.7 | 61.3 |
| | + Random | 10,398 | 53.6 | 55.9 / 3.32 | 57.4 | 49.7 |

消融实验显示，移除漂移校正或方差归一化会导致MLVU和TempCompass性能下降，验证了时序动态建模的必要性。在激进剪枝（$\rho=0.01$）下，SURGE保持58.7%的V-MME精度，而随机剪枝仅29.8%，凸显了惊讶度准则在极端预算下的鲁棒性。

评估边界方面，实验未涉及音频模态，且主要关注通用视频QA，未深入测试细粒度时间定位任务。代码已开源，超参数（如EMA系数$\gamma=0.9$、峰值间隔$\Delta=8$）固定，复现成本低。

## 关联研究分析

从问题动机看，SURGE与GroundVTS等查询引导方法形成互补。GroundVTS依赖查询信号过滤Token，适用于特定任务，但需额外计算查询-帧相似度；SURGE则基于时序动态自主筛选，无需查询即可初步定位新颖内容，更具通用性。然而，SURGE未直接解决“时间幻觉”问题，其保留的“新颖”Token可能包含噪声而非语义关键信息，这在复杂推理任务中可能成为瓶颈。

从方法设计看，SURGE与FastV等注意力剪枝方法存在根本差异。FastV依赖注意力权重，反映Token对当前预测的贡献，但无法区分“重要但冗余”与“重要且新颖”；SURGE通过时序预测误差直接测量新颖性，避免了注意力图的依赖，但在静态场景或慢速运动中，惊讶度信号可能减弱，导致关键静态信息被误剪。这种设计取舍使得SURGE在动态视频上表现优异，但在静态主导的视频中可能不如注意力方法稳定。

## 总结

SURGE旨在解决视频VLM在长序列处理中的计算瓶颈，通过引入时序惊讶度作为无需训练的Token剪枝准则，实现了计算资源与新颖内容的动态对齐。实验证明，SURGE在削减7倍Token的同时，精度损失控制在±1点以内，且在激进剪枝下显著优于随机基线。然而，其边界在于对静态场景的适应性不足，且未验证其在细粒度时间定位或复杂因果推理任务中的有效性。当视频内容以静态背景为主且动态事件稀疏时，惊讶度信号是否仍能准确区分关键信息，论文未给出回答。
