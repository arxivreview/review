## 命名与结构

- 目录层级：`conference/<会议>/<方向>/`。每个方向目录含一份 `<会议><方向>方向论文汇编.md`（该方向论文的标题/机构/作者/链接/导语汇总）+ 该方向的论文正文 md。
- 一篇论文 = 一个 Markdown 文件，**标题即文件名**：`<英文标题>_<中文标题>.md`；正文内容未改动，只按领域移动了位置。
- 方向划分依据：论文库中 `paper_field_labels` 的最高分标签 → 15 个中文大方向（如「三维视觉与3D与4D重建」「大语言模型与智能体」）；分不到具体方向归入「其他方向」。分类清单见各会议 README。
- Windows 非法字符已改写：`:` → ` -`，`?` `*` 删除，`"` → `'`，`<` `>` → 圆括号，`|` `/` `\` → `-`。
- 长度上限：英文标题 120、中文标题 40 字符（英文按词边界截断），故所有路径都在 260 字符内。
- 台账没有中文标题的论文只保留英文段，不做重复。
- 同一会议内标题撞车的（arXiv 版与会议版各收一次）双方在文件名尾部追加素材 id，例如 `…_arxiv_2512.12167.md` 与 `…_conf_ICLR_2026_38864063.md`。
- 本目录的 `README.md` 是索引，不计入论文数。
- 正文结构：一级标题（`标签 ｜英文标题 ｜中文标题`）→ 研究机构 / 作者 → 论文原文与分析报告外链 → 摘要导语 → `## 研究背景` 起的分节分析。
