# WACV2026最新论文 ｜TS-PCI: Point Cloud Frame Interpolation with Time-Aware Point Cloud Sampling and Self-Supervised Learning Strategy ｜时间感知非生成式点云采样帧插值

作者：Kohei Matsuzaki、Keisuke Nonaka

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ab899019f0fb)

> 点云帧插值旨在从低帧率LiDAR序列中恢复任意时间步的密集几何结构，以弥合传感器物理限制与下游动态任务对时序连续性的需求。现有基于场景流的方法在融合双向中间帧时普遍采用生成式策略，引入了难以避免的几何幻觉与拓扑错误。TS-PCI 将融合环节替换为时间感知的非生成式采样，直接保留原始点几何，并通过自监督动态标签实现端到端训练。该方法在效率与精度上均超越现有基线，但其对极端大运动下点丢失的鲁棒性仍缺乏验证。

## 研究背景

LiDAR 点云序列的帧率通常仅为 10-20 Hz，远低于相机与 IMU 的采样频率，导致多传感器融合时出现时间对齐困难。为提升时序连续性，帧插值任务需在两帧之间预测中间时刻的点云分布。该任务的核心挑战在于处理帧间大位移带来的非线性运动，以及双向场景流估计产生的两个中间帧如何合并为单一几何一致的结构。

主流场景流路线（如 PointINet 和 FastPCI）通过估计双向位移构建中间帧，但合并阶段依赖生成式模块（如 k-近邻聚类生成新点）。这种生成式融合虽能填补空隙，却不可避免地引入几何失真，且 PointINet 的自适应采样未考虑时间权重，FastPCI 虽引入精炼模块但仍在合并前执行，未能有效消除生成误差。此外，现有学习式采样方法多为生成式或忽略时间维度，无法直接服务于帧插值的端到端训练。

TS-PCI 的切入点在于将“融合”重构为“采样”。它摒弃生成新点的做法，转而预测每个原始点的重要性，依据插值时间动态调整采样率，直接从两个中间帧中选取 N 个点构成输出。这一非生成式策略从根源上杜绝了生成误差，但面临训练标签缺失的难题——中间帧是动态构造的，无法预先生成真值标签。为此，论文提出自监督策略，利用预测帧与真值帧的动态匹配关系实时生成采样标签，实现了采样模型的端到端优化。

## 核心方法

### 场景流中间帧构建

场景流估计是帧插值的基础，用于将输入帧 $P_0$ 和 $P_1$ 变形至目标时间步 $t$。TS-PCI 采用金字塔卷积-Transformer 架构，在三个层级（分辨率 $N, N/4, N/32$）上估计双向场景流 $S_{0\to1}$ 和 $S_{1\to0}$。通过线性插值位移，构建前向中间帧 $\hat{P}_{0\to t}$ 和后向中间帧 $\hat{P}_{1\to t}$：

$$ \hat{P}_{0\to t} = P_0 + t S_{0\to1}, \quad \hat{P}_{1\to t} = P_1 + (1-t) S_{1\to0} $$

此步骤确立了插值的几何基础，但两个中间帧存在冗余与冲突，需进一步融合。

### 时间感知非生成式采样

传统方法在融合中间帧时生成新点，导致几何失真。TS-PCI 在此环节引入时间感知采样模型，由基于 Point Transformer 的沙漏网络预测点重要性 $\hat{I}$。为解决不同时间步下两帧贡献不均的问题，引入高斯时间权重 $W(t)$：

$$ W(t) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{t^2}{2\sigma^2}} $$

加权重要性 $\hat{I}'_{0\to t} = W(t)\hat{I}_{0\to t}$ 和 $\hat{I}'_{1\to t} = W(1-t)\hat{I}_{1\to t}$ 决定了采样比例。为防止局部密度偏差，采用块状采样策略，将拼接后的 $2N$ 点划分为非重叠块，每块按加权重要性降序采样 50% 的点。该设计确保了输出点均源自原始几何，避免了生成误差，且高斯权重平滑了时间步变化对采样率的影响。

### 注意力几何精炼与自监督训练

采样后的点云 $\hat{P}^{smp}_t$ 仍存在局部几何偏差。TS-PCI 在合并后（而非合并前）应用注意力精炼模块，通过 k-近邻（k=4）位置编码与多头注意力聚合局部特征，预测偏移向量 $R$ 修正点位置：

$$ \hat{P}_t = \hat{P}^{smp}_t + R $$

针对训练标签缺失问题，提出自监督策略：利用预测帧 $\hat{P}_t$ 与真值帧 $P_t$ 的动态标签分配，实时生成点级二值标签，指导采样模型学习哪些点对插值任务更重要。损失函数包含加权二元交叉熵，避免距离项对几何质量的负面影响。

## 实验评估

实验在 KITTI odometry、Argoverse 2 sensor 和 nuScenes 三个大规模数据集上进行，评估指标为 Chamfer Distance (CD) 和 Earth Mover's Distance (EMD)。基线覆盖场景流方法（PointINet, FastPCI）、神经场方法（NeuralPCI）及视频转换方法（SPCV），但未包含扩散模型基线（如 DiffPCI），可能低估了生成式方法在复杂拓扑下的表现。

| 数据集 | 方法 | CD ↓ | EMD ↓ |
| :--- | :--- | :--- | :--- |
| KITTI | FastPCI | 0.58 | 53.78 |
| KITTI | Ours (TS-PCI) | 0.49 | 48.34 |
| Argoverse 2 | FastPCI | 0.73 | 57.95 |
| Argoverse 2 | Ours (TS-PCI) | 0.68 | 53.48 |
| nuScenes | FastPCI | 1.11 | 173.64 |
| nuScenes | Ours (TS-PCI) | 1.00 | 145.75 |

TS-PCI 在所有数据集上均优于 FastPCI，CD 降低约 15-16%，EMD 降低约 8-16%。消融实验显示，移除时间加权（ITW）导致 CD 从 0.49 升至 0.51，验证了高斯权重对采样平衡的贡献；移除自监督学习（SLS）导致 CD 升至 0.61，表明动态标签对采样模型至关重要。

评估边界方面，论文未报告计算效率的详细对比（仅提及推理时间 69ms，快于 NeuralPCI 的 30843ms，与 FastPCI 的 72ms 相当），且未提供代码开源链接。超参数设置（如 $\sigma=1, k=4$）在三个数据集间保持一致，但块大小在 KITTI 为 8，其他为 16，暗示数据规模对局部结构建模的影响。

## 关联研究分析

从问题动机看，TS-PCI 与 FastPCI 同属场景流路线，但核心差异在于融合策略。FastPCI 采用生成式融合，虽能填补空隙但引入几何幻觉；TS-PCI 采用非生成式采样，牺牲了填补能力以换取几何保真度。这一选择源于对“生成误差”的规避，但在极端大运动导致中间帧覆盖不足时，非生成式采样可能面临点丢失风险，论文未对此进行定量分析。

从方法设计看，TS-PCI 与 PointINet 共享场景流框架，但 PointINet 的自适应采样是非学习式的，无法适应下游任务需求；TS-PCI 引入学习式时间感知采样，并通过自监督策略解决标签缺失问题。与扩散模型方法（如 DiffPCI）相比，TS-PCI 未建模运动概率分布，而是依赖场景流的确定性估计，这在处理非线性大运动时可能不如概率模型灵活，但显著提升了推理效率。

## 总结

TS-PCI 针对场景流帧插值中生成式融合导致的几何失真问题，提出时间感知非生成式采样与自监督训练策略。通过高斯时间权重动态调整采样率，并在合并后应用注意力精炼，该方法在 KITTI 上取得 CD 0.49 和 EMD 48.34 的最优结果，推理时间 69ms 与 FastPCI 相当。其边界在于非生成式采样对中间帧覆盖度的依赖，当场景流估计误差较大或运动剧烈时，采样点可能无法充分覆盖目标几何。当帧间位移超过场景流估计的鲁棒范围时，非生成式采样的点丢失率是否显著高于生成式方法，论文未给出回答。
