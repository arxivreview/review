# WACV2026最新论文 ｜Point2Pose: A Generative Framework for 3D Human Pose Estimation with Multi-View Point Cloud Dataset ｜点云驱动的条件生成式3D人体姿态估计

研究机构：韩国首尔大学、韩国科学技术院

作者：Hyunsoo Lee、Daeum Jeon、Hyeokjae Oh

论文原文见 [arXiv](https://arxiv.org/abs/2512.10321)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.10321)

> 3D人体姿态估计（3D HPE）旨在从传感器数据恢复关节坐标与旋转，其核心难点在于单目RGB图像固有的深度歧义与点云模态下的稀疏噪声干扰。现有基于2D-to-3D提升的生成方法依赖中间2D表示，而点云回归方法难以建模自遮挡关节的分布不确定性。Point2Pose摒弃2D中间表示，直接在原始点云域应用条件扩散模型与最优传输条件流匹配，结合时空注意力编码点云-姿态交互。该方法在LiDARHuman26M上将MPJPE从58.56mm降至35.40mm，验证了生成式框架在非视觉模态的有效性，但其对初始姿态历史的强依赖及缺乏与最新点云回归SOTA的对比限制了结论的普适性。

## 研究背景

理解本文需厘清三个因果关联的概念。首先，单目RGB成像将3D姿态投影至2D平面，丢失深度信息，导致同一2D投影对应无限多3D解，即深度歧义。为缓解此问题，主流范式采用2D-to-3D提升，先检测2D关键点再回归3D坐标，但该过程引入2D检测误差累积，且无法直接利用3D空间几何。其次，点云传感器（如LiDAR、iToF）直接提供3D空间坐标，规避了投影歧义，但原始点云存在稀疏、噪声大及自遮挡导致的关节缺失问题，传统确定性回归难以刻画这种多解性。最后，生成式模型（如扩散模型）通过迭代去噪学习数据分布，能输出多种合理假设而非单一确定解，为处理点云的不确定性提供了概率框架。

3D HPE领域长期受限于输入模态与建模范式的错配。基于RGB的方法虽数据丰富，但受深度歧义制约，精度瓶颈明显；基于点云的方法（如LIP、LiveHPS）虽具备空间信息，但多采用确定性回归或条件VAE，无法有效捕捉自遮挡关节的分布特性，且在稀疏场景下细节丢失严重。与此同时，现有大规模点云数据集多为单视角、简单动作，缺乏多视角、复杂自遮挡场景的覆盖，导致模型泛化能力不足。Point2Pose的切入点在于：将生成式建模从2D域迁移至原始点云域，直接以点云序列为条件生成3D姿态分布，并构建包含多视角密集点云与IMU的大规模数据集MVPose3D，以解决点云模态下分布建模与数据稀缺的双重挑战。

## 核心方法

### 方法参照系

本文问题属于条件生成式姿态估计，但输入模态为原始点云而非2D关键点。与基于2D-to-3D提升的扩散模型（如DiffPose）不同，Point2Pose无需2D中间表示，直接在3D点云域执行去噪。其核心差异在于编码器需处理无序点云的局部-全局几何结构，且生成过程需同时预测关节坐标与旋转，以维持运动学一致性。

### 时空点云-姿态联合编码

传统点云编码器（如PointNet++）仅提取空间特征，忽略时序依赖；而姿态编码器（如ST-GCN）仅处理骨架图，未融合点云几何。Point2Pose引入联合编码机制，通过交叉注意力对齐点云特征与姿态历史，解决自遮挡关节在点云中缺失但可从时序推断的问题。具体地，点云编码器采用FPS采样局部补丁，结合Mini-PointNet提取局部特征与PointNet++提取全局特征，拼接后经ViViT式时空MHSA融合：

$$ \mathbf{F}_{st}^p = f_s(\cdot) \circ f_t(\cdot) (\mathbf{F}_p) $$

其中 $f_t$ 与 $f_s$ 分别为时间分支与空间分支的MHSA模块。该设计使模型能利用相邻帧的点云几何补全当前帧的遮挡关节，提升对复杂姿态的表征能力。

### 因子化生成式姿态回归

现有生成方法（如MOVIN）采用联合去噪，同时预测坐标与旋转，易导致运动学不一致。Point2Pose提出因子化去噪分支，先预测关节坐标 $\mathbf{J}$，再以 $\mathbf{J}$ 为先验预测旋转 $\mathbf{R}$，强化运动学约束。噪声扰动采用DDPM或OT-CFM，去噪过程通过MHCA融合点云-姿态特征 $\mathbf{F}_{px}$：

$$ \hat{\mathbf{X}}_i = f_{\text{Denoiser}}(\tilde{\mathbf{X}}_i, \mathbf{F}_{px}, e_i, e_J) $$

其中 $e_i$ 为去噪迭代嵌入，$e_J$ 为关节索引嵌入。该因子化设计确保旋转预测依赖于已确定的坐标，减少运动学伪影，在自遮挡场景下提升姿态合理性。

## 实验评估

实验在LiDARHuman26M、LIPD、ITOP-Side及自建MVPose3D数据集上进行，基线包括MOVIN（条件VAE）与SPiKE（确定性回归）。Point2Pose_OT-CFM在LiDARHuman26M上MPJPE为35.40mm，显著优于MOVIN的58.56mm；在LIPD上为38.01mm，优于MOVIN的59.13mm。在ITOP-Side上，Point2Pose_OT-CFM（T=4→T=3）MPJPE为125.01mm，优于SPiKE的142.83mm。

| 数据集 | 方法 | MPJPE (mm) | Ang. Err (°) |
| :--- | :--- | :--- | :--- |
| LiDARHuman26M | MOVIN | 58.56 | 25.68 |
| LiDARHuman26M | Point2Pose_OT-CFM | 35.40 | 5.61 |
| LIPD | MOVIN | 59.13 | 17.71 |
| LIPD | Point2Pose_OT-CFM | 38.01 | 8.01 |
| ITOP-Side | SPiKE | 142.83 | - |
| ITOP-Side | Point2Pose_OT-CFM (T=4→T=3) | 125.01 | - |

消融实验表明，移除姿态-点云特征编码器导致MPJPE从35.40mm激增至101.48mm，验证了联合编码对遮挡关节恢复的关键作用；移除因子化去噪器使MPJPE升至43.63mm，证实因子化设计对运动学一致性的贡献。在稀疏输入场景（N=128）下，MPJPE降至183.86mm，优于N=256的192.54mm，表明模型对点云密度具有鲁棒性。

评估边界方面，论文未报告置信区间，且缺乏与LiveHPS等最新点云回归SOTA的直接对比，有效性局限于生成式内部比较。代码未开源，超参数（如T=4, N=256）固定，可复现性受限。指标仅包含MPJPE与Angular Error，未评估推理延迟，无法验证实时性。

## 关联研究分析

从问题动机看，Point2Pose与DiffPose（Gong et al.）同属生成式姿态估计，但DiffPose依赖2D-to-3D提升，受2D检测误差累积制约；Point2Pose直接在点云域生成，规避了2D投影歧义，但牺牲了RGB数据的纹理丰富性。这一差异源于任务特性：点云模态天然具备3D空间信息，无需2D中间表示，但需更强的几何编码能力处理稀疏噪声。

从方法设计看，Point2Pose与SasMamba代表“生成式”与“高效回归”两条路线。SasMamba采用Mamba架构以线性复杂度捕捉长程依赖，适合实时应用；Point2Pose采用扩散/流匹配，推理需20步迭代，速度慢但能输出多假设分布。两者在LiDARHuman26M上MPJPE接近（35.40mm vs 36.42mm，据领域综述），但Point2Pose在遮挡场景的定性评估更优。这一分歧反映领域核心争论：确定性回归在实时性上占优，生成式在分布建模上更合理，但缺乏标准化指标量化“多假设解的分布质量”。

## 总结

Point2Pose旨在解决点云模态下3D姿态估计的分布不确定性问题，通过摒弃2D中间表示，直接在原始点云域应用条件扩散与流匹配，结合时空联合编码与因子化去噪，实现了对自遮挡关节的概率建模。实验表明，该方法在LiDARHuman26M上将MPJPE从58.56mm降至35.40mm，验证了生成式框架在非视觉模态的有效性。然而，其性能高度依赖初始姿态历史，在缺乏初始信息的场景下MPJPE升至129.63mm，且未与最新点云回归SOTA对比，限制了结论的普适性。当点云密度进一步降低至N=64时，MPJPE回升至191.36mm，表明模型对极端稀疏场景的鲁棒性仍有待提升，这一边界是否可通过更高效的采样策略缓解，论文未给出回答。
