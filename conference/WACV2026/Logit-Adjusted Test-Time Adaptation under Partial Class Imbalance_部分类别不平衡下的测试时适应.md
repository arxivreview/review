# WACV2026最新论文 ｜Logit-Adjusted Test-Time Adaptation under Partial Class Imbalance ｜部分类别不平衡下的测试时适应

研究机构：澳大利亚皇家墨尔本理工大学

作者：Thilina Weerasinghe、Ruwan Tennakoon、WeiQin Chuah 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_fcfa8a2635b5)

> 导读 测试时适应（Test-Time Adaptation, TTA）旨在利用无标签测试数据在线修正模型以应对分布偏移，但现有方法普遍假设目标域包含源域的全部类别。当实际部署中仅出现部分类别时，基于熵最小化的主流方法会因批归一化参数漂移导致性能崩溃。本文通过理论分析揭示了这一失效机制，并提出了一种对数几率调整（Logit Adjustment）策略来抵消该偏差。该策略在多个基准上显著提升了适应稳定性，但其对极端类别缺失场景的泛化能力仍存疑。

## 研究背景

当预训练模型部署到真实环境时，测试数据的类别分布往往与训练阶段不一致。这种不一致不仅表现为类别频率的变化，更极端的情况是目标域中完全缺失某些源域类别，即部分类别不平衡（Partial Class Imbalance）。在工业检测或野生动物监测等场景中，模型可能长期仅观察到少数几类对象，而其余类别从未出现。这种设定下，模型无法通过标签反馈来纠正对缺失类别的遗忘，只能依赖无标签数据的自监督信号进行更新。

传统TTA方法如TENT和EATA主要关注分布偏移下的特征对齐，其核心假设是测试批次中所有类别均存在。然而，当目标域仅包含源域的一个子集时，熵最小化目标会引导模型过度拟合可见类别，导致未观测类别的特征表示向主导类别坍缩。这种失效在长序列适应中尤为严重，因为错误会随时间累积，最终导致模型性能从峰值急剧下降。现有研究虽涉及在线类别不平衡或长尾分布，但鲜有工作系统研究“类别缺失”这一更严苛的约束条件下的适应稳定性问题。

本文切入点在于揭示熵最小化在部分类别不平衡下的内在缺陷，并设计一种无需标签、可无缝集成到现有框架的修正机制。通过理论分析证明批归一化（Batch Normalization, BN）参数漂移是性能衰退的根源，进而提出基于目标域类别先验的对数几率调整策略，旨在从优化目标层面抑制这种偏差，从而在长序列适应中维持模型对全类别的区分能力。

## 核心方法

### 方法参照系

本文基于标准的熵最小化TTA框架，该框架通常仅更新BN层的仿射参数（$\gamma, \beta$）以最小化预测熵。与通用流程的关键差异在于，本文不假设目标域类别分布与源域一致，而是显式建模目标域中类别出现的概率先验，并将其引入分类器的输出端，以修正因类别缺失导致的优化偏差。

### 对数几率调整机制

在标准熵最小化中，BN层的偏移参数 $\beta$ 会向主导类别的分类权重对齐，导致所有预测偏向该类别。为抵消这一效应，本文在Softmax函数前引入对数几率调整项。具体而言，对于类别 $i$，调整后的对数几率 $z'_i$ 定义为：

$$ z'_i = z_i + \tau \log \pi_i $$

其中 $\tau$ 为温度系数，$\pi_i$ 为目标域中类别 $i$ 的先验概率。该公式的物理含义是，通过减去主导类别的高先验概率（$\log \pi_i$ 为大正数，故 $\tau \log \pi_i$ 为负值），降低其最终预测概率，从而平衡各类别的竞争关系。这一设计直接针对BN参数漂移导致的对数几率偏差，从源头上抑制了模型对可见类别的过拟合。

### 在线先验估计

由于目标域无标签，$\pi_i$ 无法直接获取。本文采用指数移动平均（Exponential Moving Average, EMA）策略在线估计类别先验。对于每个测试批次，首先计算各类别的预测计数 $n_i$，然后计算批次先验 $\pi_{\text{batch}, i} = \frac{\sqrt{n_i}}{\sum_{k=1}^C \sqrt{n_k}}$。随后，全局先验 $\pi^{(t)}$ 通过以下公式更新：

$$ \pi^{(t)} = \alpha \pi^{(t-1)} + (1 - \alpha) \pi_{\text{batch}} $$

其中 $\alpha$ 控制先验收敛速度。该机制允许先验动态跟踪目标域中类别分布的变化，确保对数几率调整始终基于最新的类别出现频率，从而在长序列适应中保持稳定性。

## 实验评估

| 方法 | AllAcc (%) | PeAR (%) |
| :--- | :--- | :--- |
| TENT | 23.7 | 64.2 |
| TENT + LA | 34.4 | 4.68 |
| SAR | 32.6 | 9.19 |
| SAR + LA | 34.5 | 5.43 |

实验在ImageNet-C（CIR=0.1）上进行，对比了TENT、SAR等基线及其加入对数几率调整（LA）后的性能。基线覆盖熵最小化（TENT）、教师-学生框架（CoTTA）及多问题处理（SAR）等主流路线，但未包含无梯度方法如FOA或NEO。核心数字显示，TENT+LA将AllAcc从23.7%提升至34.4%，同时将PeAR从64.2%降至4.68%，表明调整策略不仅提升了精度，更显著增强了适应过程的稳定性。

在消融实验中，温度系数 $\tau$ 和EMA系数 $\alpha$ 的设定对性能影响显著。论文设定 $\tau=1.0, \alpha=0.1$ 为最佳权衡点。值得注意的是，在极端类别不平衡（CIR=0.01，仅1个类别）场景下，EATA+LA将AllAcc从68.6%提升至70.2%，PeAR从2.36%降至0.03%，显示该方法在极端条件下仍具鲁棒性。然而，对于DeYO+LA，PeAR仅从20.2%降至13.4%，降幅有限，暗示对数几率调整在某些基于伪标签差异的方法中可能存在边际收益递减。

评估边界方面，论文引入了PeAR指标以量化适应过程中的不稳定性，弥补了AllAcc无法区分“快速达峰后衰退”与“稳定维持”的缺陷。但实验未报告计算开销，且ViT模型需100步预热以避免早期崩溃，这可能影响实时部署的可行性。代码已开源，但超参数敏感性分析较为简略，未提供不同CIR下的详细网格搜索结果。

## 关联研究分析

从问题动机看，本文与SAR（Self-Adaptive Regularization）存在显著差异。SAR同样处理在线类别不平衡，但其侧重于小批量统计不稳定和混合域数据，通过正则化项约束参数更新幅度。本文则聚焦于“类别缺失”这一更极端的场景，指出SAR等正则化方法无法解决BN参数向主导类别对齐的根本问题。根源在于，正则化仅限制更新步长，而未修正优化目标本身的偏差；本文的对数几率调整直接修正了损失函数的梯度方向，从而在机制上更为彻底。

从方法设计看，本文与Label Shift Adapter（LSA）有理论渊源，但LSA依赖标签信息来估计类别先验，而本文在无标签TTA场景下通过预测计数在线估计先验。这一差异源于任务约束：LSA假设测试集有标签，而TTA严格无标签。本文的在线估计策略引入了估计误差，但在长序列中通过EMA平滑，使得误差可控。然而，当类别分布变化剧烈时，预测计数的准确性可能下降，导致先验估计偏差，这是本文未深入探讨的潜在盲区。

## 总结

本文核心矛盾在于熵最小化TTA在部分类别不平衡下的性能崩溃，其切入点在于揭示BN参数漂移这一微观机制，并通过引入目标域类别先验的对数几率调整来抵消该偏差。实验证明，该策略在ImageNet-C上将TENT的AllAcc从23.7%提升至34.4%，PeAR从64.2%降至4.68%，显著提升了适应稳定性。然而，论文边界在于其先验估计依赖预测计数，在类别分布剧烈变化或极端缺失时可能失效，且未评估计算开销对实时系统的影响。当目标域类别分布随时间动态变化时，EMA先验的滞后性是否会导致调整策略失效，论文未给出回答。
