# WACV2026最新论文 ｜Zero-Shot Domain Generalisation via Prompt-Driven Feature Refinement ｜提示驱动特征精炼实现零样本域泛化

研究机构：新西兰奥克兰大学

作者：Tingrui Qiao、Di Zhao、Caroline Walker 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f576ede84660)

> 域泛化旨在让模型从源域泛化至未见目标域，但现有方法多依赖源域数据或额外训练，在隐私受限或数据不可得场景下失效。Prefer 提出零样本域泛化（Zero-Shot Domain Generalisation, ZSDG）设定，彻底移除源数据、目标数据及训练环节。该方法利用大语言模型生成域特定提示，通过计算特征通道的相似度与方差筛选鲁棒通道，在推理时实现特征精炼。这一“无训练”策略在标准基准上超越了现有源自由方法，但其性能上限仍低于依赖源域微调的强基线，且对 LLM 生成提示的质量依赖尚未被充分量化。

## 研究背景

当视觉-语言模型（Vision-Language Models, VLMs）如 CLIP 面对风格、背景或成像条件发生变化的测试数据时，其预训练分布与目标域分布的失配导致性能显著下降。这种分布偏移使得模型过度依赖源域中的虚假相关（Spurious Correlation），例如将背景纹理误判为物体特征。为应对此问题，域泛化（Domain Generalisation, DG）试图在仅使用源域数据的情况下学习域不变表示，而源自由域泛化（Source-Free Domain Generalisation, SFDG）进一步去除了对源域图像的直接访问需求，转而依赖合成数据或代理表示进行微调。

然而，SFDG 仍保留了“训练”这一环节，这在数据隐私严格（如医疗影像）或部署环境快速变化的场景下依然不切实际。现有基于参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）的方法，如 StyLIP 和 CLIPCEIL，虽然通过轻量级适配器或提示学习提升了跨域性能，但本质上仍需访问源域数据或进行梯度更新。Prefer 的切入点在于彻底切断模型与外部数据的训练连接，将域泛化问题转化为纯推理时的特征空间筛选问题，即在不更新任何模型参数的前提下，仅利用预训练 VLM 的内在结构实现跨域泛化。

## 核心方法

### 方法参照系

标准 DG 流程通常包含源域数据加载、域不变特征学习及模型参数更新三个环节。Prefer 的关键差异在于完全冻结预训练 VLM 主干，将“学习”过程替换为“推理时特征精炼”，即通过文本提示探针量化特征通道的域稳定性，而非通过梯度下降优化参数。

### 域特定提示生成与特征探针

传统提示学习将提示作为可训练参数以优化分类损失，而 Prefer 将提示作为“探针”用于评估特征通道的鲁棒性。设计动机在于解决静态提示无法覆盖所有域偏移导致特征空间对齐失效的问题。Prefer 首先利用大语言模型（LLM）生成 $D$ 个视觉域（如“素描”、“水彩”），并为每个类别 $c$ 生成对应的域特定提示 $p_{c,d}$。这些提示经文本编码器 $\mathcal{E}_T$ 映射为嵌入 $T_{c,d}$，构成对类别 $c$ 在不同域下表现的模拟。

$$ T_{c,d} = \mathcal{E}_T(p_{c,d}) $$

该公式表明，域特定嵌入并非来自真实图像，而是通过文本语义在预训练空间中“想象”出的域变体，从而在无数据条件下构建域变化的代理变量。

### 通道相似度与方差评分机制

在获得域特定嵌入后，Prefer 需从 $F$ 维特征向量中筛选出既保持类别语义又对域变化不敏感的通道。设计动机在于抑制高方差通道中携带的域特异性噪声（如背景、笔触），避免模型依赖虚假相关。对于每个通道 $i$，计算其与原始类别提示嵌入 $T_c$ 的相似度 $\text{sim}_i$ 及跨域方差 $\text{var}_i$。

$$ s_i = \text{sim}_i \cdot \exp(-\text{var}_i) $$

其中 $\text{sim}_i = \sum_{d=1}^D (T_c)_i \cdot (T_{c,d})_i$，$\text{var}_i = \text{Var}(\{(T_{c,d})_i\}_{d=1}^D$。该评分函数通过指数项对高方差通道进行非线性惩罚，确保选中的通道 $i$ 在语义上与类别强相关，同时在数值上对域扰动保持稳定。最终，通过肘部法则（Elbow-Point Heuristic）自动确定每类保留的通道数 $K$，仅使用这些鲁棒通道计算图像与文本的余弦相似度，实现无训练的特征精炼。

## 实验评估

Prefer 在 PACS、Office-Home、VLCS 和 DomainNet 四个标准域泛化基准上，采用留一域（Leave-one-domain-out）协议进行评估。基线覆盖多源 DG 方法（如 StyLIP、CLIPCEIL）及源自由 DG 方法，但缺失知识库中提到的 SHED、DiCoOP 等最新 SOTA 对比，这可能影响对当前技术边界的准确定位。

消融实验显示，域特定提示数量 $D$ 对性能影响显著。当 $D=5$ 时，Prefer 性能与 CLIP-ZS 持平，表明少量提示无法充分模拟域变化；随着 $D$ 增加至 25-35，性能趋于饱和，超过此范围后边际收益递减。这一发现揭示了提示多样性与噪声引入之间的权衡：过少的提示导致域覆盖不足，过多的提示则引入冗余信息，干扰通道筛选的稳定性。

评估边界方面，Prefer 仅报告了平均准确率，未提供置信区间或标准差，且未报告计算效率指标（如推理延迟）。由于依赖 GPT-4o 生成提示，其可复现性受限于 LLM 输出的随机性，论文未提供固定提示集或种子控制策略，这可能导致结果在不同运行间存在波动。

## 关联研究分析

从问题动机看，Prefer 与 SHED 均追求域不变特征，但路径截然不同。SHED 通过减去源域质心来移除域风格，依赖源域数据的统计特性；而 Prefer 完全摒弃源域数据，利用 LLM 生成的文本提示作为域变化的代理。这种差异源于任务约束：SHED 假设源域数据可访问，而 Prefer 针对数据不可得的极端场景。Prefer 的“无训练”特性使其在隐私敏感场景中更具适用性，但代价是放弃了源域数据提供的精确域分布信息，转而依赖 LLM 的语义泛化能力，其有效性高度依赖于 LLM 对视觉域变化的描述准确性。

从方法设计看，Prefer 与 CLIPCEIL 均涉及特征通道精炼，但机制本质不同。CLIPCEIL 通过训练轻量级适配器调整特征通道权重，属于参数化方法；Prefer 则通过推理时的相似度与方差评分进行非参数化筛选。这种非参数化设计避免了过拟合风险，但也限制了模型对特定域偏移的适应能力。Prefer 的通道选择是静态的（基于提示生成），而 CLIPCEIL 的适配器是动态的（基于输入图像），这暗示在细粒度或复杂域偏移任务中，静态筛选可能不如动态适配灵活，但论文未对此进行对比实验。

## 总结

Prefer 旨在解决源域数据不可得且无法训练条件下的域泛化难题，其核心矛盾在于如何在无参数更新的前提下消除域特异性噪声。通过引入 LLM 生成域提示作为探针，并设计基于相似度与方差的通道评分机制，Prefer 实现了纯推理时的特征精炼。实验表明，该方法在 PACS 和 DomainNet 上分别较 CLIP-ZS 提升 1.9% 和 2.8%，验证了无训练策略的有效性。然而，其性能上限仍低于依赖源域微调的强基线，且对 LLM 提示质量的依赖尚未被量化。当 LLM 生成的提示无法准确覆盖特定域的视觉特征时，通道筛选的鲁棒性是否会显著下降，论文未给出回答。
