# WACV2026最新论文 ｜Predicting Task fMRI Contrasts from Resting-State fMRI Using Sparse 3D Convolutions ｜稀疏体素卷积预测任务态激活

作者：Ivan Sviridov、Maria Boyko、Maksim Sharaev

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ae0ad56d9af0)

> 从静息态功能连接推断个体特异性任务态激活，旨在解决任务态fMRI采集成本高且对认知障碍患者不可行的临床痛点。现有表面基线受限于网格投影失真，密集体素基线则因计算冗余导致细节丢失，两者均无法兼顾拓扑保真与效率。本文提出BrainSparseCNN，利用稀疏3D卷积直接在非零体素上运算，以保留皮层几何结构。该方法在精度与效率上均优于现有基线，但其泛化能力受限于单一健康人群数据，临床适用性存疑。

## 研究背景

任务态fMRI（tfMRI）通过受控任务诱发特定脑区激活，是解析认知机制的金标准，但其采集耗时且要求受试者严格配合，导致在认知或运动障碍群体中难以实施。静息态fMRI（rsfMRI）无需任务配合，其内在功能连接（FC）模式被证明编码了预测任务响应所需的充分信息。然而，从rsfMRI到tfMRI的映射并非线性过程，早期线性回归模型无法捕捉大脑的非线性动态与细粒度空间模式，亟需具备高表达力且计算高效的深度学习架构。

主流解决方案分为表面基线与体素基线两类。表面基线如BrainSurfCNN在球面网格上进行卷积，虽保留皮层拓扑，但各向同性滤波器与网格约束限制了空间分辨率；体素基线如SwiFUN采用3D Transformer处理密集体素，虽具备全局注意力能力，但需对高分辨率fMRI体积进行激进下采样或掩码以适配GPU显存，这一过程不可避免地扭曲了原生脑拓扑并丢失细粒度解剖结构。BrainSparseCNN的切入点在于利用脑组织在体素空间中的天然稀疏性，通过仅在非零体素上执行卷积运算，同时规避了表面投影的几何失真与密集体素的计算冗余。

## 核心方法

### 稀疏体素表征构建

本文问题属于从静态连接组生成动态激活图的回归任务，与主流GNN分类范式的关键差异在于输出为高维体素场而非低维类别标签。BrainSparseCNN基于U-Net架构，利用MinkowskiEngine库实现所有张量操作（包括批归一化与池化）的稀疏化。输入为双半球50通道的rsfMRI连接组，输出为双半球47个任务对比的激活图。数据预处理阶段，利用HCP表面网格将皮层顶点映射至稀疏3D张量，建立顶点到体素的一一对应关系，避免了插值与密集重采样，从而保持fs LR 32k注册中的拓扑关系完整，防止产生人工跨半球邻居。

### 稀疏卷积与多任务生成

传统3D CNN在密集体素上运算时，大量零值体素参与卷积导致计算资源浪费且引入噪声。BrainSparseCNN在卷积核滑动窗口内仅对非零体素执行乘法与累加操作，其稀疏卷积运算可形式化为：

$$
y_i = \sum_{j \in \mathcal{N}(i)} w_{ij} x_j
$$

其中 $\mathcal{N}(i)$ 为体素 $i$ 的稀疏邻域，$w_{ij}$ 为可学习权重。该设计动机在于通过空间稀疏性保留细粒度结构细节，同时大幅降低计算开销。模型采用两阶段训练策略：第一阶段使用L2重建损失训练100个epoch，确保预测图与真实图的数值对齐；第二阶段引入BrainSurfCNN提出的对比-重建损失再训练100个epoch，通过惩罚不同受试者预测图的相似度，增强个体特异性表征。这种设计解决了单一重建损失易导致模型学习群体平均模式而忽略个体差异的失效问题，使得模型能够区分不同受试者的神经响应模式。

## 实验评估

实验基于HCP数据集，选取919名受试者训练，39名重复扫描受试者测试。基线覆盖表面基线BrainSurfCNN、体素Transformer基线SwiFUN、群体平均基线及重测信度基线。缺失GNN分类基线，因任务性质不同不可比。

| 方法 | 平均Pearson相关 | 参数量 (M) | 训练内存 (MB) | 推理时间 (ms) |
| :--- | :--- | :--- | :--- | :--- |
| BrainSparseCNN | 0.672 | 5.51 | 2931.8 | 14.6 |
| BrainSurfCNN | 0.620 | 0.38 | 12938.7 | 104.9 |
| SwiFUN | 0.584 | 16.74 | 25375.3 | 179.6 |
| Retest | 0.611 | - | - | - |

BrainSparseCNN在跨任务平均相关上达到0.672，较BrainSurfCNN提升8.5%，较SwiFUN提升15.1%。在语言任务（LANGUAGE STORY）中提升幅度达7%，而在运动任务中，群体平均基线表现与CNN模型相当，反映了运动激活的低个体变异性与重测信度天花板。

| 任务 | BrainSparseCNN Dice | BrainSurfCNN Dice | SwiFUN Dice |
| :--- | :--- | :--- | :--- |
| SOCIAL TOM | 0.169–0.188 | 0.078–0.104 | 0.064–0.086 |

在SOCIAL TOM任务的显著性图（ERF）与真实激活重叠度上，BrainSparseCNN的Dice分数显著高于其他方法，其高亮区域与颞顶联合区、内侧前额叶等核心理论心智区域高度重合。受试者识别准确率方面，BrainSparseCNN达到98.3%，远超BrainSurfCNN的91.6%和SwiFUN的70.5%，表明其学到了更鲁棒的个体化神经表征。

评估指标涵盖Pearson相关、Dice分数及识别准确率，但未报告置信区间，且重测分析仅基于39名受试者，限制了上限估计的精度。代码已公开，但SwiFUN的对比涉及表面-体素-表面转换管道，与本文的稀疏体素管道存在表征差异，严格架构级对比受限于组件公开程度。

## 关联研究分析

从问题动机看，BrainSparseCNN与BrainGNN等图神经网络方法均旨在捕捉脑网络结构，但前者聚焦于体素级激活生成，后者聚焦于图级分类诊断。BrainGNN通过注意力机制识别关键脑区以提升可解释性，而BrainSparseCNN通过稀疏卷积保留皮层拓扑以提升空间精度。这种差异源于任务特性：分类任务对空间分辨率要求较低，而激活图预测对解剖细节敏感。BrainSparseCNN未利用图结构中的高阶交互信息，而是依赖体素邻域的局部卷积，这可能在捕捉长距离功能连接时存在理论劣势，但通过U-Net的跳跃连接部分弥补了这一不足。

从方法设计看，BrainSparseCNN与SwiFUN同属体素处理路线，但SwiFUN采用密集Transformer注意力，计算复杂度随体素数平方增长，而BrainSparseCNN利用稀疏性实现线性复杂度。SwiFUN在16.74M参数下仍受限于显存瓶颈，需下采样处理，导致细节丢失；BrainSparseCNN以5.51M参数实现更低内存占用与更快推理速度。这种效率优势并非单纯源于架构简化，而是源于对脑组织稀疏性的物理利用。然而，BrainSparseCNN仅在HCP健康年轻成人数据上验证，未涉及多中心分布偏移问题，与领域内强调跨站点泛化的共识存在设置差异，其稀疏体素空间是否丢失了SPD矩阵的几何结构信息，导致泛化能力受限，论文未给出回答。

## 总结

BrainSparseCNN旨在解决从静息态连接组预测个体任务激活时的拓扑失真与计算冗余矛盾。现有表面方法受限于网格投影，密集体素方法受限于下采样失真，均无法兼顾精度与效率。本文通过稀疏3D卷积仅在非零体素上运算，保留了皮层几何结构并降低了计算开销。实验表明，该方法在HCP数据上取得0.672的平均Pearson相关，较最强基线提升8.5%，且受试者识别准确率达98.3%。然而，其训练数据局限于HCP健康年轻成人，未验证临床队列或跨站点泛化能力。当支持集扩展至多中心数据时，稀疏体素架构能否通过引入非欧几何约束消除站点特异性偏差，论文未给出回答。
