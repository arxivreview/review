# WACV2026最新论文 ｜ControlEvents: Controllable Synthesis of Event Camera Data with Foundational Prior from Image Diffusion Models ｜基于扩散先验的事件相机数据可控合成

作者：Yixuan Hu、Yuxuan Xue、Simon Klenk 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_5dbb76d0d8e6)

> 事件相机视觉任务长期受困于标注数据稀缺与仿真器域差距的双重瓶颈，传统图形渲染或基于强度帧的生成方法无法复现真实传感器的噪声特性与空间阈值变化。ControlEvents 抓住“预训练图像扩散模型蕴含的强生成先验可迁移至非标准模态”这一被忽略的切入点，通过微调 Stable Diffusion 和 ControlNet 实现多条件事件流合成。该方法以极低标注成本生成带伪标签的高质量数据，显著提升了下游识别与姿态估计性能，但其对特定传感器硬件参数的依赖性及跨域泛化边界仍存疑。

## 研究背景

事件相机以像素级异步亮度变化替代固定帧率采样，其输出为离散事件流而非连续图像。处理此类数据需将其累积为二维直方图，通常编码为三通道图像（正/负极性），以便复用基于 RGB 图像的深度学习架构。然而，这种转换丢失了原始时间戳信息，且不同数据集（如 N-ImageNet、DHP-19）采用不同的累积策略（全量、固定数量或固定时间窗），导致数据分布高度依赖采集协议。

事件视觉领域的核心矛盾在于：深度模型需要大规模标注数据，但事件相机标注成本极高且现有模拟器存在显著域差距。主流路线分为两类：图形渲染模拟器（如 SMPL-ESIM）通过 3D 资产渲染生成事件，但缺乏背景噪声和空间变化阈值，导致仿真数据与真实数据分布不一致；学习式生成器（如 Event-GAN）从强度帧对生成事件，但依赖成对 RGB 输入，无法直接由文本或 3D 姿态条件生成，且难以模拟传感器特有的噪声特性。ControlEvents 的切入点在于利用预训练图像扩散模型的生成先验，直接在真实事件数据上微调，从而在保留传感器物理特性的同时实现多模态条件控制。

## 核心方法

### 方法参照系

本文问题属于条件生成数据增强，标准流程为：定义条件空间 $c$，训练生成器 $p_\theta(e|c)$，利用生成数据 $e_{synth}$ 增强下游任务训练集。与通用图像生成不同，事件数据具有稀疏性、极性二值性及传感器噪声特异性，且缺乏大规模配对 RGB 数据，这要求生成器必须在小样本下学习真实事件分布，而非依赖 RGB 先验直接映射。

### 基于文本条件的扩散微调

针对分类任务，ControlEvents 将类别标签 $c_{class}$ 增强为自然语言描述 “A photo of {c_class}”，以对齐 Stable Diffusion 的文本条件接口。设计动机在于解决小样本下事件分布学习不足的问题：直接训练生成器难以从每类仅 100 张图像中捕获完整分布，而预训练扩散模型已学习丰富的视觉语义先验。微调时冻结 VAE 编码器，仅更新 U-Net 参数，优化目标为去噪误差最小化：

$$ L_{ControlEvents} = \mathbb{E}_{e_i, \epsilon, t} \left[ \| \epsilon - \epsilon_\theta(e_{i,t}, t, c_i) \|^2 \right] $$

其中 $e_{i,t}$ 为添加噪声后的事件图像，$\epsilon_\theta$ 预测需移除的噪声。该设计使模型继承文本-图像对齐能力，实现零样本生成未见类别的事件，弥补了传统模拟器无法支持文本条件的缺陷。

### 基于骨架与法线图的 ControlNet 扩展

针对 2D 骨架和 3D 姿态任务，ControlEvents 引入 ControlNet 作为条件注入接口。设计动机在于解决 3D 姿态条件无法直接输入扩散模型的问题：SMPL 参数为数值向量，缺乏空间结构，而法线图提供逐像素表面方向信息，可被 ControlNet 正常图分支有效编码。对于 2D 骨架，使用 ControlNet 骨架分支；对于 3D 姿态，在 Blender 中渲染 SMPL 模型的法线图 $c_{normal}$，并微调 ControlNet 的可训练 U-Net 副本，保持原始 Stable Diffusion U-Net 和 VAE 冻结。条件生成过程遵循：

$$ p_\theta(e | c_{skeleton}, c_{text}) \quad \text{or} \quad p_\theta(e | c_{normal}, c_{text}) $$

其中 $c_{text}$ 统一设为 “A moving human”。该设计将 3D 姿态估计转化为 2D 条件生成问题，利用法线图的空间局部性缓解自遮挡导致的单目歧义，使模型能从任意 SMPL 参数生成对应事件，突破了传统模拟器对 3D 资产库的依赖。

## 实验评估

实验在 N-ImageNet（分类）、DHP-19/CDEHP（2D 骨架）、Event-HPE（3D 姿态）上进行，基线包括 Event-GAN（学习式）和 SMPL-ESIM（图形式），但未对比其他扩散模型基线（如基于 LDM 的直接微调）。主实验表明，合成数据与原始数据混合训练可显著提升性能：

| 任务 | 数据设置 | 指标 | 数值 |
| :--- | :--- | :--- | :--- |
| 3D SMPL 恢复 | 原始训练数据 | 3D-MPJPE (mm) | 27.30 |
| 3D SMPL 恢复 | ControlEvents + 原始数据 | 3D-MPJPE (mm) | 18.65 |
| 2D 骨架估计 (DHP-19) | ControlEvents + 原始数据 | 2D-MPJPE | 6.006 |
| 2D 骨架估计 (CDEHP) | ControlEvents + 原始数据 | 2D-MPJPE | 10.792 |

3D-MPJPE 从 27.30mm 降至 18.65mm，降幅达 31.7%，表明合成数据有效缓解了姿态分布偏差。消融实验显示，移除 Stable Diffusion 先验后，模型无法生成未见文本标签的事件，仅产生噪声，证实扩散先验对零样本泛化的关键作用。数据规模消融表明，合成数据量从 0 增至 20,000 时，骨架估计性能持续提升，但边际收益递减。

评估边界存在局限：指标未覆盖生成质量（如 FID 仅提及未列数值），且未报告推理时间与 GPU 资源消耗。可复现性方面，论文声明公开模型与数据集，但超参数细节（如学习率、训练步数）仅在补充材料中提供，主文未列明。

## 关联研究分析

从问题动机看，ControlEvents 与 Event-GAN 均旨在解决事件数据稀缺，但 Event-GAN 依赖成对强度帧输入，无法支持文本或 3D 姿态条件，导致其无法生成开放集类别的事件；ControlEvents 通过扩散先验解耦条件与生成过程，实现多模态控制，根源在于事件数据的稀疏性使得基于像素对的生成难以捕获全局语义，而扩散模型的全局注意力机制更适合建模此类分布。

从方法设计看，ControlEvents 与图像域 ControlNet 应用（如深度图生成）共享框架，但事件数据的极性二值性与噪声特性要求微调策略不同：图像生成可冻结大部分参数，而事件生成需更充分微调 U-Net 以适配稀疏分布。法线图作为 3D 条件的引入，是否比直接 SMPL 参数更利于扩散模型学习，论文未给出对比实验，仅基于法线图的空间局部性假设进行设计，这一选择的有效性在复杂自遮挡场景下是否稳健，缺乏定量验证。

## 总结

ControlEvents 解决了事件视觉中“标注稀缺”与“仿真域差距”的核心矛盾，其切入点在于利用预训练扩散模型的生成先验，在真实事件数据上微调以保留传感器物理特性。方法通过文本、骨架、法线图多条件控制，实现了零样本事件生成，3D-MPJPE 降低 31.7% 证明了合成数据的有效性。边界在于：实验仅验证了与原始数据混合训练的提升，未单独评估纯合成数据的性能上限；且法线图条件的设计缺乏与直接 SMPL 参数输入的对比，其在复杂姿态下的鲁棒性未充分验证。当合成数据量超过一定阈值后，性能提升是否趋于饱和，论文未给出回答。
