# WACV2026最新论文 ｜VideoSketcher: A Training-Free Approach for Coherent Video Sketch Transfer ｜视频草图风格迁移中的时空自注意力调制

研究机构：新加坡管理大学、香港城市大学

作者：Huining Li、Bangzhen Liu、Rui Yang 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_6590ec14f6d8)

> 视频草图风格迁移旨在将静态草图的美学特征注入动态视频流，同时保持帧间内容的连贯性。现有基于文本提示或逐帧独立处理的方法，因缺乏对草图稀疏语义的显式建模及帧间结构约束，常导致内容丢失与时序抖动。本文提出 VideoSketcher，一种无需训练的框架，通过时空自注意力调制机制，在潜空间中同步优化空间布局与时间一致性。该方法在内容保真度上显著优于现有基线，但其对高动态场景及复杂抽象风格的适应性仍存疑。

## 研究背景

当扩散模型处理视频时，其自注意力层（Self-Attention, SA）中的 Query 决定空间布局，Key 和 Value 决定内容特征。若仅替换 Key 和 Value 以注入草图风格，Query 仍保留原始视频的空间结构信息，导致风格与内容在语义层面错位。这种错位在草图任务中尤为严重，因为草图具有稀疏的线条和无色背景，其注意力图方差与自然图像存在显著分布差异，直接替换会导致注意力分散，引发模糊与失真。

视频风格迁移的核心挑战在于平衡风格注入与时间一致性。主流路线分为两类：一是基于文本提示的特征调制，如利用 CLIP 引导去噪过程，但文本描述难以捕捉草图特有的空间语义，导致内容遗漏；二是逐帧独立风格化后拼接，虽保留了单帧质量，但缺乏帧间约束，产生剧烈抖动。此外，基于参考图像的方法如 StyleID 和 IP-Adapter 虽能利用视觉先验，但前者仅处理单帧，后者存在内容泄漏问题。VideoSketcher 的切入点在于，将草图风格迁移视为潜空间中的时空协同优化问题，通过显式传播结构一致性 Query 并引入草图特定的正则化约束，解决静态方法无法捕捉的动态时序问题。

## 核心方法

### 方法参照系

本文基于预训练文本到图像（Text-to-Image, T2I）扩散模型，采用 DDIM 反转获取视频帧与参考草图的噪声项。标准流程中，风格注入通常通过替换自注意力层的 Key 和 Value 实现，但此做法忽略了 Query 对空间布局的控制作用，且在视频序列中缺乏帧间关联，导致时序不连贯。

### 时间链接注意力机制

设计动机在于解决逐帧独立处理导致的时序闪烁问题。传统方法中，每帧的 Query 独立计算，无法感知相邻帧的结构变化。VideoSketcher 引入时间链接注意力（Time-Linked Attention, TLA），通过传播结构一致性 Query 来维持帧间对齐。具体而言，定义结构一致性 Query $Q_{sc}$ 为原始视频 Query $Q_c$ 与当前风格化帧 Query $Q_g$ 的加权组合：

$$ Q_{sc} = \epsilon Q_c + (1 - \epsilon) Q_g $$

其中 $\epsilon$ 控制原始空间结构信息的保留比例。随后，利用 $Q_{sc}$ 与参考草图的 Key $K_s$ 和 Value $V_s$ 进行注意力计算，确保风格注入不破坏原始视频的空间布局。此外，TLA 还引入前一帧的潜变量参与当前帧的注意力计算，通过交替使用风格化注意力与结构对齐注意力，实现平滑的内容过渡。

### 草图指令放大与笔画图正则化

设计动机在于弥合自然图像与草图在分布上的差异，防止边缘失真与细节丢失。草图指令放大（Sketch Directive Amplification, SDA）模块通过校准注意力图的方差，增强稀疏区域的语义关注。其公式为：

$$ \bar{A}_g = \frac{(A_g - \mu(A_g)) \varpi(A_s)}{\varpi(A_g) + \mu(A_g)} $$

其中 $A_g$ 为风格化帧的注意力图，$A_s$ 为参考草图的注意力图，$\mu$ 和 $\varpi$ 分别表示均值和方差。该操作动态调整注意力分布，使模型聚焦于草图的关键边缘。笔画图正则化（Stroke Graph Regularization, SGR）模块则将笔画视为图结构，通过跨域相似度约束稳定潜空间特征。SGR 利用图匹配网络检测关键点与线条结构，计算相邻帧间的结构差异并施加 MSE 损失，从而在潜空间中进行一步更新，确保笔画的连续性。

## 实验评估

实验在 DAVIS 视频分割基准上进行，对比了 StyleID、IP-Adapter、Cross-IA 等参考引导方法以及 AnyV2V、VideoComposer 等视频风格迁移方法。基线覆盖了基于单帧风格化、特征调制及视频扩散模型的多种路线，但未包含基于视频扩散模型训练的强基线。

| 方法 | CLIP-Image ↑ | Pixel-MSE ↓ | FID ↓ | LPIPS ↓ | ArtFID ↓ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| StyleID | 0.9575 | 0.0324 | 35.4799 | 0.1860 | 42.1789 |
| IP-Adapter | 0.9390 | 0.0210 | 24.7112 | 0.1330 | 29.4180 |
| Cross-IA | 0.9568 | 0.0755 | 25.6296 | 0.1941 | 31.6175 |
| Ours | 0.9740 | 0.0193 | 27.8128 | 0.0862 | 31.3526 |

VideoSketcher 在 CLIP-Image 和 LPIPS 指标上取得最优，表明其在时间一致性和内容保真度上表现突出。尽管 FID 略高于 IP-Adapter，但 LPIPS 的显著优势说明其更好地保留了原始视频结构，避免了内容泄漏。

| 变体 | CLIP-Image ↑ | Pixel-MSE ↓ | FID ↓ | LPIPS ↓ | ArtFID ↓ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| wo. TLA | 0.8101 | 0.0652 | 44.2558 | 0.1245 | 50.4422 |
| wo. SDA | 0.9698 | 0.0199 | 46.9603 | 0.4771 | 71.7012 |
| wo. SGR | 0.9699 | 0.0291 | 27.4695 | 0.1817 | 33.6554 |
| Full | 0.9740 | 0.0193 | 27.8128 | 0.0862 | 31.3526 |

消融实验显示，移除 TLA 导致风格崩溃，CLIP-Image 降至 0.8101，验证了其核心地位。移除 SDA 使 FID 飙升至 46.9603，表明其对风格一致性至关重要。移除 SGR 主要影响 Pixel-MSE 和 LPIPS，证实其在结构对齐中的作用。

评估指标主要关注单帧质量与帧间一致性，缺乏对复杂拓扑结构的专项评估。论文未提供代码，但详细列出了超参数设置，如 $\epsilon=0.6$，$\varpi_1=1$，$\varpi_2=15$，以及 TLA 启动阈值 $\vartheta=0.1T$，保证了可复现性。

## 关联研究分析

从问题动机看，VideoSketcher 与 StyleID 均基于自注意力调制，但 StyleID 仅处理单帧，无法解决视频时序问题。VideoSketcher 通过 TLA 引入帧间 Query 传播，将单帧风格化扩展至视频域，解决了静态方法在动态场景中的失效。与 IP-Adapter 相比，后者通过交叉注意力注入风格，但存在内容泄漏，而 VideoSketcher 通过 SDA 和 SGR 显式约束草图语义，减少了内容干扰。

从方法设计看，VideoSketcher 与 Pix2video 共享跨帧注意力思路，但 Pix2video 侧重于通用视频编辑，而 VideoSketcher 针对草图稀疏性设计了 SDA 和 SGR。SGR 将笔画视为图结构进行正则化，这一设计在通用视频风格迁移中较少见，体现了对草图任务特性的深度适配。然而，SGR 依赖图匹配网络检测关键点，对于非线形或高度抽象的草图风格，其泛化能力可能受限，论文未对此进行充分验证。

## 总结

VideoSketcher 旨在解决视频草图风格迁移中风格注入与时序一致性的矛盾。现有方法因缺乏对草图稀疏语义的显式建模及帧间结构约束，导致内容丢失与抖动。本文通过 TLA 传播结构一致性 Query，并结合 SDA 与 SGR 模块，在潜空间中实现了时空协同优化。实验表明，该方法在 LPIPS 上达到 0.0862，显著优于 IP-Adapter 的 0.1330，验证了其在内容保真度上的优势。然而，论文指出 SGR 对抽象或复杂草图风格效果有限，且假设场景结构相对稳定。当面对高动态内容或极度抽象的草图时，图匹配网络的结构检测能力是否足以支撑稳定的风格迁移，仍是待验证的问题。
