> 商业文档中的表格提取长期受困于私有布局的标注稀缺与公开基准的域偏移，导致模型在内部发票上表现远逊于公开科学表格。现有评估仅依赖单一聚合分数，无法诊断具体失效模式，且忽视了大规模部署中的碳足迹成本。本文构建了一个涵盖零样本、微调与从头训练的统一协议，引入自动化错误分类法与生态排放量化，以揭示不同规模模型在精度、成本与鲁棒性间的真实权衡。其价值在于提供了部署导向的实证参照，但受限于单页单表场景，未触及多页复杂结构。

## 研究背景

商业文档自动化理解的核心困境在于数据分布的系统性偏移。公开数据集如 PubTables-1M 遵循 LaTeX 规范，边界清晰；FinTabNet 呈现密集规则网格。然而，真实发票包含行间手写注释、不规则表头及非表格噪声，这些元素在标注中被排除，却迫使模型学习“跳过”而非“识别”它们。这种结构性差异导致在公开域表现优异的监督模型，在私有商业布局上性能急剧下降，形成了基准高分与部署低效之间的鸿沟。

表格检测（Table Detection, TD）与表格结构识别（Table Structure Recognition, TSR）是提取流程的两个独立环节。TD 旨在定位表格边界框，TSR 则恢复行列结构与文本内容。传统评估依赖 TEDS 等聚合指标，虽便于排名，却掩盖了定位错误、结构混淆或文本归一化失败等具体失效模式。在商业场景中，不同错误类型的修复成本差异巨大，单一分数无法指导针对性优化。此外，随着视觉语言模型（Vision-Language Models, VLMs）的兴起，零样本能力成为关键变量，但缺乏统一协议对比其与传统检测器在精度、延迟及环境成本上的综合表现。

本文切入点在于构建一个面向实际部署的审计框架。不同于追求 SOTA 精度的算法创新，本文聚焦于评估协议的完整性：通过统一输入模态（OCR/图像）与训练制度（零样本/微调/从头），结合自动化错误分类法与碳排放估算，量化不同模型在商业文档上的真实可用性。这一视角将评估从“模型竞赛”转向“工程决策支持”，回应了工业界对可解释性与可持续性的双重需求。

## 核心方法

### 统一评估协议与模态解耦

本文建立了一个跨模型、跨训练制度的统一评估框架，其核心差异在于强制解耦输入模态与任务类型。标准流程通常允许模型自由选择输入，但本文规定 TD 任务对通用 LLM 使用 OCR 文本输入，而 TSR 任务使用图像输入。这一设计源于实验发现：通用 LLM 未经过边界框预测训练，直接处理图像导致 TD 性能失效，而 OCR 文本提供了更丰富的空间线索。对于 TSR，图像输入在 GPT-4o/5-mini 上表现更优且成本更低。该协议确保了不同架构模型在公平条件下对比，避免了因输入模态差异导致的性能偏差。

### 自动化错误分类法

为突破聚合指标的局限，本文提出了一套轻量级、自动化的错误分类法，将预测结果映射至具体失效模式。TD 错误包括 Wrong Table（定位错误）、Empty Prediction（漏检）及 Noise Above/Below（包含非表格噪声）。TSR 错误则细化为 Column/Row Error（行列数不匹配）、Header Error（表头语义偏差）及 False Empty（单元格内容缺失）。这些指标基于二值判断，通过阈值 $\tau_{IoU}$ 和 $\sigma_{hdr}$ 控制灵敏度。该分类法将单一分数转化为可操作的诊断信号，例如 Noise Above 高发提示模型需增强对表头上方噪声的抑制能力，从而指导数据清洗或后处理策略。

### 生态足迹量化

本文引入碳排放估算作为评估维度，使用 CodeCarbon 和 Ecologits 工具量化本地执行与 API 调用的 kg CO2eq 排放。对于本地模型，排放计算考虑设备功率与电网碳强度；对于 API 模型，基于提供商参数估算。这一设计动机在于揭示精度与可持续性之间的权衡：大型 VLM 虽精度高，但单次完整评估的排放可达轻量级模型的 $10^4$ 倍。通过联合报告精度与排放，本文提供了多维决策依据，帮助团队在预算、延迟与环境约束下选择最优模型组合。

## 实验评估

实验在私有 STM154（154 页，平均 45 单元格/表）与公开 DocILE-QUEST（141 页，平均 15 单元格/表）上进行，覆盖零样本、微调及从头训练三种制度。基线涵盖紧凑检测器（YOLOv9, DETR）、开源 VLM（TATR, SmolDocling）及商业 API（GPT-4o, GPT-5-mini）。缺失 PIX-TAB、TableSeq 等 2026 年最新高效识别方法，可能低估了当前 SOTA 在特定场景下的表现。

| 模型 | 参数 | DocILE-QUEST GIoU | STM154 GIoU | DocILE-QUEST TEDS | STM154 TEDS-S |
| :--- | :--- | :--- | :--- | :--- | :--- |
| YOLOv9† | 2M | 0.75 ± 0.03 | 0.66 ± 0.05 | - | - |
| DETR† | 41M | 0.56 ± 0.06 | 0.87 ± 0.03 | - | - |
| SmolDL | 256M | 0.12 ± 0.07 | 0.25 ± 0.08 | 0.71 | 0.86 |
| GPT-4o | NA | 0.66 ± 0.06 | 0.83 ± 0.03 | 0.68 | - |
| GPT-5m | NA | 0.66 ± 0.05 | 0.78 ± 0.04 | 0.75 | 0.93 |

监督检测器在 TD 上显著优于零样本系统：YOLOv9 在 DocILE-QUEST 上 GIoU 达 0.75，而零样本 DETR 仅 0.21。在 TSR 上，GPT-5-mini 以 0.75 TEDS（DocILE-QUEST）和 0.93 TEDS-S（STM154）领先，但 SmolDocling 微调后表现强劲，显示小模型在有限数据下的潜力。GPT-5-mini 在 STM154 上的 Completeness 指标（0.91）统计显著优于其他模型，表明其在内容完整性上的优势。

消融分析显示，输入模态选择对 TD 影响巨大：GPT-4o/5-mini 使用 OCR 输入时 GIoU 达 0.66-0.83，而纯图像输入失效。这证实了通用 LLM 在空间定位上的固有局限。错误分类法揭示，Noise Above 是 TD 的主要失效模式，尤其在表头未明确分隔时，模型易将上方键值对误纳入表格。TSR 中，Header Error 与 Column Error 高度相关，表明表头识别失败常导致整体结构崩塌。

评估边界受限于单页单表设定，未测试多页跨页合并或复杂表头。TEDS 指标依赖固定 OCR 与 HTML 规范化，绝对分数可能随预处理变化。代码未公开，但提供了详细超参数（如 $\alpha=0.5$, $\tau_{IoU}=0.1$）与排放估算工具，具备部分可复现性。

## 关联研究分析

从问题动机看，本文与 PubTabNet 等公开基准形成互补。PubTabNet 聚焦科学表格的结构识别，强调算法在干净数据上的上限；本文则直面商业文档的系统性噪声，揭示域偏移对监督模型的致命影响。差异根源在于任务特性：科学表格遵循统一规范，而商业文档模板异构且包含非结构化干扰。本文未探索如何将这些噪声作为训练信号，而是通过错误分类法定位其影响，这暗示了数据增强策略的潜在价值。

从方法设计看，本文与 TRivia 等自监督方法形成对比。TRivia 通过组相对策略优化提升 VLM 在无标签数据上的识别能力，侧重模型内在鲁棒性；本文则通过统一协议与生态评估，侧重部署层面的权衡分析。两者均未解决多页表格的跨页上下文建模问题，但本文的模块化评估框架（TD 与 TSR 解耦）为后续集成跨页推理提供了基础。本文未采用合成数据生成来模拟噪声，而是依赖真实私有数据，这限制了结论的泛化性，但增强了工业相关性。

## 总结

本文核心矛盾在于商业文档标注稀缺与公开基准域偏移导致的部署失效。切入点在于构建统一评估协议，通过解耦输入模态与训练制度，结合自动化错误分类法与生态足迹量化，揭示模型在精度、成本与可持续性间的真实权衡。实验证明，零样本 VLM 在 TSR 上具备竞争力（GPT-5-mini TEDS 0.75），但 TD 仍需监督检测器（YOLOv9 GIoU 0.75）；轻量级模型在有限数据下可接近商业 API 性能。边界在于单页单表设定，未触及多页复杂结构。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
