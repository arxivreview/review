> 导读 自我-外部视角对象对应旨在解决机器人从第三人称指令映射到第一人称执行时的空间错位问题，核心难点在于杂乱背景干扰与剧烈视角变换导致的外观漂移。现有纯视觉匹配方法难以区分相似物体，而依赖自由文本描述的视觉语言模型方法则存在计算昂贵且语义模糊的缺陷。RegionAligner 通过VLM提取任务相关短语列表筛选感兴趣区域，并结合多粒度监督策略实现跨视角对齐。该框架在EgoExo4D数据集上显著优于基线，但其无监督性能仍受限于伪标签质量，且未验证在动态时序场景下的稳定性。

## 研究背景

当机器人试图将外部视角的装配指令映射到自身第一人称视野时，面临的核心困境是视角变换引发的几何畸变与光照差异，即外观漂移。这种漂移使得基于像素级特征匹配的视觉参考分割（Visual Reference Segmentation, VRS）方法失效，因为目标物体在两个视角下的视觉表征不再具有直接可比性。为克服这一障碍，引入视觉语言模型（Vision-Language Model, VLM）提供语义先验成为主流思路，但传统路径依赖生成自由文本描述并输入指代图像分割（Referring Image Segmentation, RIS）模型，这一过程不仅计算延迟高，且生成的描述往往缺乏实例级细节，导致在杂乱场景中定位模糊。

该领域的主流路线在纯视觉特征匹配与VLM辅助语义引导之间摇摆。纯视觉方法如XSegTx和DCAMA在EgoExo4D等真实场景中因无法区分背景杂物与目标物体而表现受限；VLM辅助方法如Osprey+LISA虽引入语义，但受限于文本描述的歧义性，难以捕捉细粒度视觉差异。RegionAligner的切入点在于改变VLM的使用方式：不生成完整句子，而是提取短促的任务相关物体短语，利用其引导开放词汇检测器定义聚焦区域，从而在保留语义优势的同时规避了自由文本的脆弱性，并通过多粒度监督策略显式约束跨视角一致性。

## 核心方法

### 方法参照系

本文问题可置于视觉参考分割（VRS）框架下，其标准流程是利用查询图像与掩码建立像素级对应。与通用VRS的关键差异在于，本文输入包含剧烈视角变换与杂乱背景，且查询侧为掩码而非完整图像，要求模型在语义与空间双重约束下实现跨视角对齐，而非简单的特征匹配。

### 任务相关区域对齐

针对杂乱背景导致目标物体被无关物体干扰的问题，RegionAligner引入任务相关区域对齐机制。该模块利用VLM从帧中提取任务相关物体短语列表 $T_O$，并通过开放词汇检测器定位这些短语对应的边界框。设计动机在于，直接处理全图会导致模型关注大量无关物体，而短语列表提供了轻量级的语义剪枝信号。最终区域 $B_R$ 定义为所有检测框的最大覆盖边界框：

$$ B_R = (\min_i x_{i1}, \min_i y_{i1}, \max_i x_{i2}, \max_i y_{i2}) $$

这一操作将搜索空间从全图压缩至任务相关区域，显著降低了后续对应学习的干扰源，使模型能聚焦于目标物体及其直接上下文。

### 区域引导监督策略

在区域筛选基础上，RegionAligner提出多粒度监督策略以解决跨视角外观漂移与几何不一致问题。该策略包含区域级损失 $L_{reg}$、物体级损失 $L_{obj}$ 和跨视角一致性损失 $L_{cont}$。其中，跨视角一致性损失通过InfoNCE对比学习约束双向预测的互异性，确保查询物体w在另一视角中仅匹配其真实对应物v。公式如下：

$$ L_{cont} = -\lambda_{cont} \sum_{w=1}^{K} \log \frac{\exp(c_{ww})}{\sum_{v=1}^{K} \exp(c_{wv})} $$

其中 $c_{wv}$ 为双向Dice分数之和。该损失直接优化跨视角对应关系，抑制因外观差异导致的错误匹配，弥补了标准分割损失在跨视角任务中的不足。

## 实验评估

实验在EgoExo4D数据集上进行，对比基线包括纯视觉方法XSegTx、DCAMA及VLM辅助方法Osprey+LISA。基线覆盖了视觉匹配与语义引导两条主要路线，但缺乏与基于槽位注意力的对象中心学习方法的对比，这可能限制了结果在更广泛对象表示学习领域的可比性。

| 方法 | 类型 | Ego Query IoU | Exo Query IoU |
| :--- | :--- | :--- | :--- |
| XSegTx | Trained | 18.99 | 27.14 |
| DCAMA | Trained | 24.03 | 29.15 |
| RegionAligner | Trained | 29.15 | 33.18 |

RegionAligner在监督设置下IoU分别提升5.12%和4.03%，表明区域筛选与多粒度监督的有效性。消融实验显示，移除文本-视觉融合模块导致性能下降，验证了语义先验对区分相似物体的必要性；替换为更强VLM（GPT-4o-mini）带来小幅提升，说明框架对VLM能力的可扩展性。

评估指标包括IoU、轮廓精度与位置分数，但未报告计算效率或内存占用，且未提供置信区间。代码未公开，超参数如 $\lambda_{size}=5$ 和伪标签比例 $A=15\%$ 的敏感性分析缺失，限制了可复现性。

## 关联研究分析

从问题动机看，RegionAligner与对象中心表示学习（OCRL）中的Slot Attention存在根本差异。Slot Attention通过迭代竞争注意力在无监督条件下分解场景为离散槽位，旨在解决绑定问题；而RegionAligner依赖查询掩码作为条件，目标是有监督的跨视角对应。这种差异源于任务特性：OCRL关注场景结构的无监督发现，而本文关注特定对象在视角变换下的定位。RegionAligner未利用槽位机制，可能是因为查询掩码已提供了强先验，无需额外的对象解耦机制。

从方法设计看，RegionAligner的VLM短语引导策略与RIS中的自由文本描述形成对比。RIS依赖完整句子描述，易产生歧义；RegionAligner使用短语列表，更轻量且聚焦。这一设计选择解决了自由文本在杂乱场景中定位模糊的问题，但可能限制了模型对未提及物体的泛化能力。若查询物体不在短语列表中，区域筛选可能失效，论文未对此边界情况进行充分测试。

## 总结

RegionAligner旨在解决自我-外部视角对象对应中杂乱背景与外观漂移的双重挑战。其切入点在于改变VLM的使用方式，从生成自由文本转向提取短语列表进行区域筛选，从而在保留语义优势的同时降低计算成本与歧义性。通过区域引导监督策略，框架实现了跨视角对齐，在EgoExo4D上IoU提升5.12%至4.03%。然而，其无监督性能依赖伪标签质量，且未验证在动态时序场景下的稳定性。当查询物体不在VLM提取的短语列表中时，区域筛选机制是否仍能保持鲁棒性，论文未给出回答。
