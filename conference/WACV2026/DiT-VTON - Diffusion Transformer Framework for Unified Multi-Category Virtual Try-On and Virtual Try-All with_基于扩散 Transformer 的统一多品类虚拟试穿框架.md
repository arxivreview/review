# WACV2026最新论文 ｜DiT-VTON: Diffusion Transformer Framework for Unified Multi-Category Virtual Try-On and Virtual Try-All with Integrated Image Editing ｜基于扩散 Transformer 的统一多品类虚拟试穿框架

研究机构：美国加州大学洛杉矶分校、美国杜克大学

作者：Qi Li、Shuwen Qiu、Julien Han 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.04797)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.04797)

> 虚拟试穿（Virtual Try-On, VTO）旨在将指定商品合成至用户图像中，但现有基于 U-Net 的模型在细粒度细节保持、野外场景鲁棒性及多品类泛化上存在局限。本文切入点在于利用扩散 Transformer（DiT）的全局注意力机制替代传统的 ControlNet 旁路结构，并通过数据扩展实现从服装试穿到全品类虚拟试所有（Virtual Try-All, VTA）的任务跃迁。具体做法是系统对比 Token 拼接、通道拼接与 ControlNet 三种条件注入方式，确定最优配置并引入姿态缝合机制。该工作验证了 DiT 架构在全身试穿任务上的优越性，但其对掩码的依赖及单步推理效率的缺失仍制约其在实时交互场景中的落地。

## 研究背景

当生成模型试图在用户图像中替换服装时，需同时处理源图像中的人体结构、参考图像中的商品纹理以及掩码指定的编辑区域。这一过程本质上是图像条件修复（Inpainting），其核心难点在于如何在不破坏背景与身份的前提下，精准注入参考图像的高频细节。传统方法依赖显式几何变形或专用编码器，但前者易产生伪影，后者增加计算开销且限制泛化能力。

早期 VTO 研究基于生成对抗网络（GAN）的两阶段流水线，通过薄板样条（TPS）对齐服装，但受限于对齐误差累积。随着潜空间扩散模型（LDM）引入，问题重构为条件生成任务，U-Net 架构成为主流骨干。然而，U-Net 依赖 ControlNet 等旁路模块融合参考图像，导致训练与推理开销显著增加，且难以处理复杂背景下的野外图像。此外，现有模型多聚焦于服装单一类别，缺乏对鞋履、家具等非穿戴商品的统一建模能力。

本文针对上述瓶颈，提出 DiT-VTON 框架。其核心假设是 DiT 的全局注意力机制能更有效地整合多模态条件，且通过扩展训练数据至非穿戴品类，单一模型即可实现跨品类的虚拟试穿。这一思路将 VTO 从“服装替换”扩展为“通用商品合成”，旨在解决细粒度细节丢失、野外场景鲁棒性差及多品类模型碎片化三大问题。

## 核心方法

### 条件注入架构对比

VTO 任务的标准流程是将源图像、参考图像及掩码编码至潜空间，再通过去噪网络生成目标图像。传统 U-Net 方法通常采用 ControlNet 旁路结构，将参考图像特征通过交叉注意力融合至主网络，但这引入了额外的参数与计算延迟。本文的关键差异在于摒弃专用服装编码器，直接使用变分自编码器（VAE）编码所有输入，并探索三种 DiT 条件注入方式：通道拼接、ControlNet 集成与 Token 拼接。

### Token 拼接与姿态缝合

设计动机在于解决 ControlNet 带来的计算冗余及通道拼接在长序列下的注意力稀释问题。本文采用 Token 拼接策略，将参考图像、掩码图像及噪声图像的潜变量分块为 Token，直接串联至 Transformer 输入序列。其数学表达为：

$$ x_{in} = P(x_t) \circ P(x_r) \circ P(x_e) $$

其中 $P(\cdot)$ 表示分块操作，$\circ$ 表示序列维度拼接。该公式的物理含义是将多源图像信息视为同一序列的不同片段，利用自注意力机制隐式建模全局依赖，而非通过旁路网络显式传递特征。

为进一步恢复被掩码遮挡的人体姿态信息，本文提出姿态缝合（Pose Stitching）机制。不同于将姿态图作为独立条件输入，该机制直接将姿态图 $I_p$ 拼入掩码区域，形成增强后的源图像：

$$ I_e' = I_s \odot I_m + I_p \odot (1 - I_m) $$

这一设计避免了姿态 Token 对序列长度的额外占用，同时确保人体结构信息在去噪过程中被优先保留，解决了传统方法中掩码区域人体结构模糊的问题。

## 实验评估

实验在 VITON-HD 与 DressCode 数据集上进行，对比基线包括 StableVTON、LaDI-VTON、IDM-VTON、OOTDiffusion 及 CatVTON。基线覆盖了 U-Net 双分支、稀疏注意力及 ControlNet 等主流路线，但缺失无掩码（Mask-Free）最新 SOTA 及视频试穿基线。

| 模型 | VITON-HD FID↓ | VITON-HD KID↓ | DressCode FID↓ | DressCode KID↓ |
| :--- | :--- | :--- | :--- | :--- |
| CatVTON | 9.015 | 1.091 | 6.137 | 1.403 |
| DiT-VTON (Token Concat) | 8.869 | 1.024 | 5.498 | 1.349 |
| DiT-VTON (Pose Stitch) | 8.628 | 0.881 | 5.584 | 1.540 |

DiT-VTON 在 VITON-HD 上 FID 为 8.628，优于 CatVTON 的 9.015；在 DressCode 上 FID 为 5.584，显著低于 CatVTON 的 6.137。这表明 Token 拼接架构在全身试穿任务上具有更强的细节保持能力，但姿态缝合在 DressCode 上导致 KID 从 1.349 升至 1.540，显示其在未配对场景下的泛化能力略有下降。

消融实验显示，Token 拼接在两个数据集上均优于通道拼接与 ControlNet。在 VITON-HD 上，Token 拼接 FID 为 8.869，而 ControlNet 为 10.734；在 DressCode 上，Token 拼接 FID 为 5.498，ControlNet 为 9.804。这一结果验证了 DiT 全局注意力机制在整合多模态条件时的效率优势，且无需额外旁路模块。

评估指标包含 SSIM、LPIPS、FID 及 KID，但未报告细粒度语义一致性指标。实验使用 4 块 NVIDIA H100 80GB GPU 训练 5,000 次迭代，推理步数为 28。代码已开源，但训练数据规模未详细披露，可能影响结果的可复现性。

## 关联研究分析

从方法设计看，DiT-VTON 与 CatVTON 形成鲜明对比。CatVTON 采用双 U-Net 架构，通过稀疏注意力机制分别处理人物与衣物特征，以解决单网络中的特征干扰问题。而 DiT-VTON 采用单分支 Token 拼接，依赖 DiT 的全局注意力隐式融合特征。这一差异源于骨干网络特性：U-Net 的局部感受野需显式设计稀疏注意力以增强对齐，而 DiT 的全局注意力天然适合处理长距离依赖。然而，DiT-VTON 仍依赖掩码输入，与 All Parts Matter 等无掩码方法相比，在野外场景的鲁棒性上可能存在局限，论文未对此进行直接对比。

从任务边界看，DiT-VTON 与 RefTon 在 VITON-HD 上竞争，但 DiT-VTON 将任务扩展至 VTA。RefTon 基于 DiT 架构，引入参考人物图像以提升身份一致性，聚焦于服装试穿的精细化。DiT-VTON 则通过扩展训练数据至 1,000 个品类，验证了单一模型处理非穿戴商品的能力。这一扩展是否源于 DiT 架构的通用性，还是数据规模的简单叠加，论文通过 AnyDoor/MimicBrush 的消融实验部分回答：在相同 VTA 数据下，DiT-VTON 性能优于传统编辑模型，表明架构与数据的协同作用。但数据规模对性能的具体贡献比例，论文未给出量化分析。

## 总结

DiT-VTON 旨在解决现有 VTO 模型在细粒度细节保持、野外场景鲁棒性及多品类泛化上的局限。其切入点在于利用 DiT 的全局注意力机制替代 ControlNet 旁路结构，并通过数据扩展实现 VTA 任务。方法上，采用 Token 拼接整合多模态条件，并引入姿态缝合机制恢复人体结构。实验证明，该框架在 VITON-HD 上 FID 为 8.628，在 DressCode 上 FID 为 5.584，均优于对比基线。然而，论文仍依赖掩码输入，且推理步数为 28，未探索少步采样或无掩码范式。当训练数据扩展至非穿戴品类时，模型在 VITON-HD 上的性能提升是否源于数据多样性，还是 DiT 架构对复杂纹理的固有优势，论文未给出明确归因。
