# WACV2026最新论文 ｜Leveraging Pretrained Representations for Cross-Modal Point Cloud Completion ｜双分支图像编码器：基于预训练视觉模型的视图引导点云补全

作者：Kshitij Kale、Hrishikesh U、V sreenidhe 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_5084ae0fadcb)

> 视图引导点云补全旨在利用单张RGB图像辅助重建被遮挡的3D几何结构，但现有端到端训练方法难以捕获图像中隐含的高层语义，导致对完全遮挡区域的补全稀疏且错误。本文指出，补全所需的强形状先验已隐含于大规模预训练视觉模型中，无需从头学习。通过构建双分支图像编码器，融合DINOv2的语义特征与Depth-Anything的几何深度，并嵌入EGIInet框架，实现了跨类别泛化性能的提升。该方法验证了冻结预训练模型作为3D补全先验的有效性，但其对输入图像视角质量的依赖及2D-3D投影歧义问题仍构成应用边界。

## 研究背景

视图引导点云补全面临的核心困境在于2D图像与3D点云特征空间的模态鸿沟。图像包含丰富的纹理与上下文信息，但直接将其特征与点云特征拼接或重建，往往无法有效利用跨模态信息。为弥合这一鸿沟，早期方法如ViPC通过图像估计粗略点云来引导重建，而XMFnet则利用堆叠交叉注意力在潜域融合特征。然而，这些方法通常从头训练跨模态网络，受限于训练数据规模，难以捕获复杂结构所需的深层语义理解，导致在图像中仅微弱存在或完全缺失的几何部分补全效果不佳。

现有主流路线在解决模态对齐时存在显著瓶颈。CSDN利用图像特征影响点云变形，CDPNet采用两阶段策略先预测粗略形状，EGIInet则通过共享编码器对齐多模态特征并引入基于Gram矩阵的特征传输损失。尽管这些方法提升了补全质量，但它们仍依赖端到端学习来提取图像特征，未能充分利用大规模视觉模型中已编码的物体类别与形状先验。本文的切入点在于，将补全任务重构为利用预训练模型的知识转移问题，通过冻结权重的DINOv2和Depth-Anything提取互补的语义与几何特征，替代传统的端到端图像编码器，从而在数据受限条件下增强泛化能力。

## 核心方法

### 方法参照系

本文基于EGIInet架构，该框架通过共享特征编码器（SFE）对齐点云与图像特征，利用共享特征传输网络（SFTnet）进行受控信息交换，最后通过交叉注意力融合特征并解码。本文的关键差异在于替换了EGIInet中的2D图像编码器，引入双分支图像编码器以提取更丰富的先验，其余骨干网络与融合机制保持不变。

### 双分支图像特征提取

传统方法直接从图像像素学习特征，缺乏对物体整体结构的先验理解。本文设计双分支编码器，并行提取显式几何与高层语义。几何分支利用预训练的Depth-Anything模型生成单通道深度图，经CNN处理得到几何特征 $F_{geo}$：

$$F_{geo} = \text{CNN}(\text{Depth-Anything}(I))$$

该公式将图像转换为稠密深度表示，捕获可见表面的精细几何细节。语义分支利用预训练的DINOv2模型，将图像分块输入骨干网络，经MLP投影至与几何特征相同的维度 $C'$，得到语义特征 $F_{sem}$：

$$F_{sem} = \text{MLP}(\text{DINOv2}(I))$$

DINOv2在大规模数据集上训练，具备对物体类别与合理形状的深层理解，能够推断图像中未直接可见的结构。设计动机在于，几何特征准确描述可见表面，但无法补全在点云和图像中均被遮挡的部分；语义特征则提供高层形状先验，弥补几何信息的不足。

### 特征融合与对齐

几何与语义特征需融合为统一先验。本文通过拼接与线性层降维，将抽象语义知识锚定在深度图提供的空间上下文中：

$$F_{img} = \text{Linear}(\text{Concat}(F_{geo}, F_{sem}))$$

该公式确保语义信息具有明确的空间定位，避免纯语义特征的空间模糊性。融合后的 $F_{img}$ 与点云特征 $F_{pc}$ 进入EGIInet的SFE模块，通过共享ViT块投影至共同嵌入空间，实现模态对齐。随后，SFTnet通过信息损失 $L_{info}$ 和结构损失 $L_{stc}$ 监督特征传输，确保跨模态结构属性的一致性。最终，交叉注意力以图像特征为查询，从点云特征中提取信息，生成融合向量 $F_{fused}$，驱动解码器预测缺失部分。

## 实验评估

实验在ShapeNet-ViPC数据集上进行，包含38,328个物体和13个类别，输入部分点云与对应图像均为2048点。基线覆盖PCN、PoinTr、XMFnet、EGIInet等主流方法，但缺失Mamba类最新架构如DAPointMamba。在已知类别上，本文方法平均CD为1.119，F-Score为0.846，优于EGIInet的1.211和0.836，以及Mambatron的1.199和0.839。在未知类别（bench, monitor, speaker, cellphone）上，本文方法平均CD为2.192，F-Score为0.763，较EGIInet的2.354和0.750降低7%。

| 方法 | 已知类别 Avg CD (×10³) | 已知类别 Avg F-Score | 未知类别 Avg CD (×10³) | 未知类别 Avg F-Score |
|---|---|---|---|---|
| EGIInet | 1.211 | 0.836 | 2.354 | 0.750 |
| Mambatron | 1.199 | 0.839 | - | - |
| Ours | 1.119 | 0.846 | 2.192 | 0.763 |

消融实验验证了双分支设计的必要性。在仅使用3个已知类别训练、测试4个未知类别的设定下，完整模型CD为0.7034，F-Score为0.9410；DINO-Only变体CD为0.7072，F-Score为0.9397；Depth-Only变体CD为0.7193，F-Score为0.9393。完整模型显著优于单分支变体，表明语义与几何先验的协同融合是泛化性能的关键。DINO-Only表现次优，说明语义先验在无深度信息时仍能提供有效的形状推断；Depth-Only性能下降明显，表明几何数据缺乏高层语义上下文，难以在数据稀缺时补全新类别。

评估指标采用CD和F-Score，符合领域通用标准。实验在单张NVIDIA 4090 GPU上完成，训练150小时，代码已开源。局限在于未报告计算效率指标，且未对比Mamba等线性复杂度架构，无法评估预训练模型引入的计算开销对实时应用的影响。

## 关联研究分析

从问题动机看，本文与PGNet同属多模态融合路线，但策略迥异。PGNet采用“通过校正完成”范式，利用预训练图像到3D模型生成拓扑完整的形状先验，再通过校正函数对齐部分观测；本文则直接利用预训练2D模型提取特征，嵌入现有补全网络。PGNet依赖生成模型的质量，校正过程可能引入新误差；本文依赖冻结模型的语义理解，避免生成过程的病态性。差异根源在于任务特性：PGNet侧重几何保真度，本文侧重跨类别泛化。本文在未知类别上的7%提升是否足以证明预训练2D先验优于生成式3D先验，论文未给出直接对比。

从方法设计看，本文与MAGE同属视图引导补全，但特征提取机制不同。MAGE通过共享ViT模块初步对齐点云和图像特征，并引入锚点细化块调节锚点以表示整体形状；本文则利用冻结的DINOv2和Depth-Anything提取特征，仅训练融合层。MAGE的端到端训练可能更适应特定3D几何细节，但受限于训练数据规模；本文的冻结策略增强了泛化能力，但可能限制对特定几何细节的适应性。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文要解决的核心矛盾是视图引导点云补全中，端到端训练方法难以捕获图像隐含的高层语义，导致遮挡区域补全失败。本文抓住的切入点是，补全所需的强形状先验已隐含于大规模预训练视觉模型中，无需从头学习。通过构建双分支图像编码器，融合DINOv2的语义特征与Depth-Anything的几何深度，并嵌入EGIInet框架，实现了跨类别泛化性能的提升。实验证明，在未知类别上，本文方法较EGIInet降低7%的CD，验证了预训练先验的有效性。本文的边界在于，性能高度依赖输入图像的视角质量，模糊视角或不良光照会退化先验提取；此外，2D-3D投影歧义仍导致部分遮挡区域生成几何不准确的补全。当输入图像视角发生剧烈变化时，冻结的预训练模型能否自适应调整语义与几何特征的权重，论文未给出回答。
