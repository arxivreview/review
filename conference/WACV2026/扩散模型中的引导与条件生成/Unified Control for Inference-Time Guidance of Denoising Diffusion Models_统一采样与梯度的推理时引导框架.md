# WACV2026最新论文 ｜Unified Control for Inference-Time Guidance of Denoising Diffusion Models ｜统一采样与梯度的推理时引导框架

研究机构：荷兰代尔夫特理工大学

作者：Maurya Goyal、Anuj Singh、Hadi Jamali-Rad

论文原文见 [arXiv](https://arxiv.org/abs/2512.12339)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.12339)

> 扩散模型在推理时对齐下游目标（如美学、提示词一致性）面临采样法计算成本高与梯度法易发散的双重瓶颈。现有方法要么依赖指数级样本量探索高奖励区域，要么受限于奖励函数的可微性与泛化能力。UniCoDe 通过块状解码结构，在并行采样流中嵌入局部梯度修正，实现了探索效率与后验对齐的平衡。该框架在效率与奖励对齐上显著优于基线，但代价是生成样本偏离无条件先验分布的程度增加，其长期对感知质量的影响尚存疑。

## 研究背景

扩散模型通过逐步去噪从噪声恢复数据，其条件生成传统上依赖分类器梯度或无分类器引导（Classifier-Free Guidance, CFG）。然而，当目标是对齐非结构化奖励（如美学评分、压缩率）时，CFG 的线性外推假设失效，且微调基础模型成本高昂且易导致奖励黑客。推理时引导（Inference-time Guidance）成为免训练对齐的主流路径，分为基于梯度的方法（如 DPS, MPGD）和基于采样的方法（如 BoN, CoDe）。梯度法直接优化奖励但受限于可微性且易受噪声干扰；采样法通过多流探索保持分布特性，但所需样本数随先验与后验分布差异呈指数增长，计算开销巨大。

现有方案的核心矛盾在于：纯采样法在复杂奖励下效率低下，纯梯度法在不可微或高维场景下不稳定。UniCoDe 的切入点在于识别出这两种范式在块状解码（Blockwise Decoding）结构下的互补性。它不将采样与梯度视为互斥选项，而是将梯度信号作为局部修正项嵌入并行采样流中，旨在用少量样本实现高效的后验对齐，解决高维空间下奖励最大化与分布保真度之间的权衡问题。

## 核心方法

### 方法参照系

本文问题属于推理时控制优化范畴，标准流程通常选择单一范式：要么使用梯度下降直接更新样本（梯度法），要么生成多个候选并选择最优（采样法）。本文的关键差异在于拒绝单一范式，而是在 CoDe 的块状采样框架中引入梯度引导，形成“采样探索 + 梯度对齐”的混合机制。

### 块状梯度引导与采样统一

在 CoDe 的块状解码结构中，每个时间步生成 $N$ 个并行样本流，通常通过贪心选择保留高奖励流。UniCoDe 在此环节引入梯度修正，设计动机是解决纯采样法在奖励信号微弱或高维空间下探索效率低下的问题。对于每个并行流 $x_t$，计算奖励函数 $r(x_t)$ 的梯度并施加更新：

$$ x_{t-1}^{(i)} = x_{t-1}^{(i)} + \alpha \nabla_{x_t} r(x_t) $$

其中 $\alpha$ 为引导尺度。这一操作在采样选择前，将每个流显式推向高奖励区域，减少了后续采样所需的探索广度。随后，采用温度多项式采样（Temperature-based Multinomial Sampling）替代贪心选择，通过温度参数 $\tau$ 调节探索-利用平衡，避免过早收敛于局部最优。该机制使得在仅使用 4 个并行流的情况下，即可达到或超过使用 40 个流的纯采样法（CoDe40）的奖励水平，同时大幅降低计算时间。

### 扩展机制：调度、聚类与非可微处理

为进一步优化效率与通用性，UniCoDe 引入三项扩展。首先，采样调度（Sampling Schedule）根据去噪阶段动态分配采样预算，在奖励信号预期显著的步骤增加探索。其次，聚类引导（Clustering-based Guidance）对潜空间中相近的样本流进行 K-Means 聚类（$K=2$），仅计算一次梯度并应用于整个簇，降低了梯度计算开销。最后，针对不可微奖励（如图像压缩率），采用零阶优化（Zero-order Optimization）近似梯度，利用 torchopt 库实现。这些扩展解决了标准梯度法在不可微奖励下失效的问题，以及多流并行下梯度计算冗余的问题，使框架适用于更广泛的奖励类型。

## 实验评估

实验基于 Stable Diffusion v1.5，使用 ImageNet 动物子集（51 提示词）和 HPDv2 数据集，对比 CoDe（$N=4, 40$）、MPGD、FreeDoM 和 UG。基线覆盖了采样法（CoDe）和梯度法（MPGD 等），但缺少几何约束类方法（如 Manifold-Optimal Guidance），因后者通常基于不同骨干网络，不可直接比较。

| 方法 | Aesthetic Rew. (↑) | FID (↓) | CMMD (↓) | T-CLIP (↑) | Time (↓) |
|---|---|---|---|---|---|
| SD1.5 | 1.00 | 1.000 | 1.00 | 1.000 | 1.0 |
| CoDe4 | 1.08 | 1.026 | 1.36 | 1.001 | 21.7 |
| CoDe40 | 1.19 | 1.037 | 1.92 | 1.003 | 179.8 |
| UniCoDe4 | 1.61 | 1.027 | 3.12 | 1.003 | 41.3 |
| UniCoDe5 | 1.58 | 1.034 | 2.97 | 1.005 | 29.4 |

在美学引导任务中，UniCoDe4 的奖励得分（1.61）显著高于 CoDe4（1.08）和 CoDe40（1.19），且计算时间（41.3）仅为 CoDe40（179.8）的 1/4。然而，其 CMMD（3.12）远高于 CoDe4（1.36），表明生成样本偏离无条件先验分布的程度较大。在 Pickscore 引导任务中，UniCoDe3 的奖励（1.118）和 T-CLIP（1.016）均优于 CoDe40（1.107, 1.016），且 CMMD（1.439）低于 CoDe40（1.611），显示在文本对齐任务中偏离程度相对可控。

消融实验显示，添加梯度是主要性能提升来源（UniCoDe1 vs CoDe4），而调度采样和多项式采样带来边际改进。聚类（UniCoDe5）进一步降低时间至 29.4，但奖励略有下降（1.58 vs 1.61），表明聚类牺牲了部分全局探索能力。在不可微奖励（压缩率）任务中，UniCoDe1 的奖励（3.220）优于 CoDe4（1.676），但计算时间（238.60）远高于 CoDe4（4.99），暴露了零阶优化在高维空间下的效率瓶颈。

评估指标包括 FID、CMMD、T-CLIP 和 I-Gram，覆盖了分布保真度、语义对齐和风格保持。局限在于：所有结果基于 SD1.5 骨干，与基于 SiT/DiT 的 SOTA 方法（如 Manifold-Optimal Guidance 2.02 FID）不可直接数值比较；CMMD 显著增加但未提供感知质量的主观评估，高偏离是否导致结构失真未验证；代码已开源，但超参数（如引导尺度 0.2）固定，未报告敏感性分析。

## 关联研究分析

从方法设计看，UniCoDe 与 CoDe 的核心差异在于梯度信号的引入。CoDe 依赖纯采样探索，其效率受限于样本数量与分布差异的指数关系；UniCoDe 通过局部梯度修正，将探索空间从全局缩减至局部，从而在固定样本数下提升对齐度。这一设计的根源在于高维空间中纯采样的低效性，但论文未探讨梯度方向在高维非高斯分布下的稳定性，若奖励函数存在多个局部最优，梯度修正可能导致流陷入次优区域。

从问题动机看，UniCoDe 与 MPGD/FreeDoM 等梯度法同属免训练引导，但后者针对单一样本流优化，而 UniCoDe 针对多流并行结构。MPGD 通过改进梯度估计提高精度，但计算开销随维度增加；UniCoDe 通过聚类降低开销，但牺牲了部分探索多样性。两者均面临“效率-精度”权衡，但 UniCoDe 的混合范式在不可微奖励下更具通用性，而 MPGD 在可微奖励下可能提供更精确的局部最优解。

## 总结

UniCoDe 旨在解决推理时引导中采样法效率低与梯度法泛化差的矛盾，通过块状解码中嵌入梯度修正，实现了高效的后验对齐。实验表明，其在美学和 Pickscore 任务中奖励得分显著优于 CoDe 基线，且计算效率提升 4-5 倍，但代价是 CMMD 显著增加，表明生成样本偏离无条件先验分布。论文未验证高 CMMD 是否导致感知质量下降，也未提供与几何约束方法的直接对比。当奖励函数存在多个局部最优时，局部梯度修正是否会导致流陷入次优区域，论文未给出回答。
