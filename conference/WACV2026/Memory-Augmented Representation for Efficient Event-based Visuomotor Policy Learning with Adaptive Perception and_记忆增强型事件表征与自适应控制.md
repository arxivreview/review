# WACV2026最新论文 ｜Memory-Augmented Representation for Efficient Event-based Visuomotor Policy Learning with Adaptive Perception and Control ｜记忆增强型事件表征与自适应控制

研究机构：美国佐治亚理工学院

作者：Uday Kamal、Saibal Mukhopadhyay

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_731aaa948de1)

> 无人机在高速飞行中面临传感器数据率与控制频率不匹配的计算瓶颈，传统帧化方法丢弃了事件相机的异步优势，而固定窗口处理又产生冗余计算。本文切入点在于利用结构化记忆空间实现事件流的异步递归更新，并引入双重阈值机制动态决定何时停止感知与何时复用策略。通过端到端强化学习联合优化表征与策略，该方法在仿真导航任务中实现了计算量的显著压缩。其价值在于验证了原生异步处理在资源受限平台上的可行性，但真实传感器噪声下的鲁棒性仍存疑。

## 研究背景

无人机自主导航要求感知系统具备微秒级时间分辨率以应对高速运动中的运动模糊，事件相机通过异步记录像素级亮度变化突破了传统帧相机30-60Hz的帧率限制。然而，事件流的高频特性（100kHz）与控制任务的低频需求（100Hz）之间存在巨大带宽差异，直接处理所有事件在嵌入式平台上不可行。

现有主流路线将事件流聚合为密集帧或体素网格以适配卷积神经网络，但这牺牲了异步性与稀疏性，导致时间保真度损失。脉冲神经网络虽保留异步特性，但训练困难且超参数调优复杂；PointNet架构虽能处理变长事件流，但缺乏记忆机制，需重复处理历史事件，造成计算冗余。本文针对这一矛盾，提出一种无需预训练、端到端优化的记忆增强型架构，旨在通过自适应机制最小化事件处理量与策略执行频率。

## 核心方法

### 方法参照系

本文问题属于事件表征学习与强化学习控制的交叉领域。标准流程通常采用固定时间窗口将事件流转换为密集张量，输入CNN提取特征后送入策略网络。本文的关键差异在于摒弃了固定窗口的同步假设，转而采用变长批次递归更新的结构化记忆空间，实现异步、按需的事件处理与策略执行。

### 记忆增强型异步事件编码

设计动机在于解决PointNet等无记忆架构在处理新事件时需重新计算整个时间窗口历史事件的冗余问题。本文引入$m \times d$维度的结构化记忆空间$M$，通过自注意力计算当前批次事件嵌入$\pi_\tau$的成对交互，再利用交叉注意力从历史记忆$M_{t-1}$中读取相关上下文$H_{\tau-1}$。结合门控循环单元（GRU）生成更新交互$X_\tau$后，通过双重交叉注意力机制提取相对新信息，并以门控系数$\alpha_t$控制新旧信息的融合：

$$ M_t = \alpha_t M_{t-1} + (1 - \alpha_t) M'_t $$

其中$M'_t$为基于当前交互更新后的记忆状态。该公式的物理含义是：记忆状态并非简单累加，而是根据当前事件与历史记忆的相关性动态调整遗忘率，从而在有限维度内保留最具决策价值的时空特征，避免了固定窗口带来的信息稀释。

### 自适应感知与控制阈值机制

设计动机在于解决高频事件流中大量冗余事件导致的计算浪费，以及场景静止时策略网络的无效推理。本文定义记忆饱和度指标$D_{mem}$为相邻记忆状态的归一化L2距离：

$$ D_{mem} = \frac{\|M_{n-1} - M_n\|_2}{\|M_{n-1}\|_2 + \|M_n\|_2} $$

当$D_{mem} < T_{hm}$时，判定记忆已饱和，停止处理后续事件并生成上下文向量。同理，定义上下文向量变化率$D_{ce}$，当$D_{ce} < T_{hz}$时，复用上一时刻的策略输出而非重新推理。这一机制将感知与控制的计算量与场景动态性解耦：在自由飞行或场景静止时，计算量趋近于零；在接近障碍物时，计算量自动增加以捕捉快速变化的视觉信息。

## 实验评估

实验在AirSim模拟器中进行，四旋翼配备64×64分辨率事件相机，以20m/s速度飞行。基线包括RGB帧策略、事件图像策略（EIP）及预训练变分自编码器策略（eVAE）。本文方法在样本效率上优于端到端训练的RGB与EIP基线，与采用多阶段训练的eVAE相当，但无需特权数据集预训练。

| 模块/参数 | 成功率先验 | MFLOPs/ev | 总事件数 |
| :--- | :--- | :--- | :--- |
| 记忆维度 (32, 32) | 0.062 | - | - |
| 记忆维度 (48, 48) | 0.122 | - | - |
| 阈值 $T_{hm}=0.1$ | - | - | 77129 |
| 阈值 $T_{hm}=0.2$ | - | - | 37561 |
| 无记忆模块 | 0.028 | - | - |
| 无时间嵌入 | 0.061 | - | - |

消融实验显示，记忆模块是性能的关键，移除后成功率从0.062降至0.028；时间嵌入对性能提升有限，但成对交互对空间相关性计算至关重要。阈值$T_{hm}$的选择存在权衡：较低阈值（0.1）虽提升成功率，但导致处理事件数翻倍（77129 vs 37561），验证了自适应机制在计算效率与性能间的平衡作用。

评估边界受限于仿真环境，未包含真实传感器噪声与复杂物理动力学（如动态障碍物）。代码未公开，但超参数（如$d=32, m=32, k=50$）已详细列出，基于NVIDIA RTX 3090 GPU运行。

## 关联研究分析

从问题动机看，本文与Spiking Patches（Koo Øhrstrøm et al., 2025）均致力于保留事件异步性，但Spiking Patches侧重分类/分割等静态感知任务，采用Token化策略适配Transformer；本文则面向动态控制任务，引入记忆机制解决时序依赖问题。差异根源在于任务特性：分类任务可容忍固定窗口内的信息聚合，而导航任务需实时响应场景变化，固定窗口会导致延迟或冗余。

从方法设计看，本文与eVAE（Koo Øhrstrøm et al.）的主要区别在于训练范式。eVAE采用预训练VAE提取特征，需访问特权专家轨迹数据；本文采用端到端PPO优化，表征与策略联合学习。这一选择牺牲了eVAE的高样本效率，但消除了对特权数据的依赖，更适合真实部署场景。然而，本文未提供与SNN基线的直接对比，尽管SNN在理论上同样支持异步处理，但训练难度限制了其作为强基线的可行性。

## 总结

本文核心矛盾在于事件相机高频数据流与资源受限平台计算能力的不匹配。现有密集化方法丢失时间保真度，固定窗口异步方法存在计算冗余。本文通过记忆增强型异步编码与双重阈值自适应机制，实现了按需处理事件与策略。实验证明，在仿真导航任务中，该方法比eVAE少处理4倍事件（37561 vs 149432），策略执行率仅约33%。其边界在于仿真环境缺乏真实噪声与动态障碍物，且记忆机制在高噪声下可能饱和。当真实传感器引入热噪声与BA噪声时，记忆饱和度阈值$T_{hm}$的鲁棒性如何，论文未给出回答。
