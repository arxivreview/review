# WACV2026最新论文 ｜SasMamba: A Lightweight Structure-Aware Stride State Space Model for 3D Human Pose Estimation ｜结构感知步长状态空间模型

作者：Hu Cui、Wenqiang Hua、Renjing Huang 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.08872)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.08872)

> 单目3D人体姿态估计面临深度歧义与计算效率的双重瓶颈，Transformer架构虽能捕捉长程依赖但复杂度随序列长度平方增长，难以满足实时部署需求。现有状态空间模型（SSM）虽具备线性复杂度优势，却普遍将二维姿态序列展平为一维时间流，破坏了人体骨骼的空间拓扑结构，导致局部关节交互建模失效。本文提出SasMamba，通过结构感知时空卷积与多尺度步长扫描机制，在保持线性计算复杂度的同时显式保留骨骼空间结构。该方法以极低的参数量实现了具有竞争力的精度，但其性能上限仍受限于固定步长策略对非标准骨架的适应性，且未验证其在生成式多假设场景下的表现。

## 研究背景

单目3D姿态估计的核心难点在于从模糊的2D投影中恢复唯一的3D坐标，这一病态问题通常通过2D-to-3D lifting范式解耦处理，即先检测2D关键点再回归3D坐标。在此过程中，时序信息的引入至关重要，它利用视频帧间的连续性缓解单帧的深度不确定性。然而，传统基于Transformer的方法在处理长序列时，自注意力机制的计算复杂度呈二次方增长，成为实时应用的主要阻碍。

为突破效率瓶颈，研究者转向状态空间模型（State Space Models, SSMs），如Mamba架构，其通过线性时间复杂度实现长程依赖建模。尽管PoseMamba、HGMamba等SSM变体在效率上取得进展，但它们大多沿用图像处理中的展平策略，将时空联合的骨架数据强制映射为一维序列。这种操作混淆了空间与时间特征，导致模型难以区分“相邻关节的空间关联”与“同一关节的时间演化”，在复杂动作中易产生结构伪影。SasMamba的切入点正是修复这一被忽略的结构丢失问题，旨在不增加计算负担的前提下，重建SSM对骨骼拓扑的感知能力。

## 核心方法

### 方法参照系

SasMamba遵循标准的2D-to-3D lifting流程，输入为2D关键点序列，输出3D关节坐标。与主流SSM方法（如PoseMamba）的关键差异在于，后者将$T \times V$的骨架矩阵直接展平为$TV$维向量进行扫描，而SasMamba在扫描前引入了显式的空间结构保持机制，将局部结构建模与全局时序建模解耦为两个协同阶段。

### 结构感知时空卷积

传统SSM缺乏对非欧几里得骨架拓扑的感知，直接展平导致局部关节交互信息丢失。SasMamba引入结构感知时空卷积（SA-Conv），通过动态偏移预测替代固定邻接矩阵。对于每个关节，模型预测其时空邻域的偏移量$\Delta p$，并通过双线性插值采样动态邻居特征：

$$ X_{agg} = \sum_{k=1}^{K} W_k \cdot \text{Sample}(X, p + \Delta p_k) $$

其中$K$为邻居数量，$W_k$为投影权重。这一设计动机在于解决固定GCN邻接矩阵无法适应动态姿态变化的问题，使模型能根据当前姿态动态调整局部交互范围，从而在保留空间拓扑的同时增强特征表达的灵活性。

### 多尺度步长扫描

SA-Conv输出的特征仍需进入SSM进行全局建模，但直接展平仍会破坏空间顺序。SasMamba提出步长扫描（Stride Scan）策略，以不同步长$s \in \{1, 2, 3\}$对关节维度进行采样，构建多尺度全局表示：

$$ X_{stride} = \text{Concat}(\text{SSM}(X_{s=1}), \text{SSM}(X_{s=2}), \text{SSM}(X_{s=3})) $$

其中被跳过的关节用前一个有效关节填充以保持序列长度。该机制的设计动机是克服单一尺度扫描对局部细节或全局趋势的偏倚，通过多粒度并行处理，使SSM能在保留原始关节索引顺序的前提下，同时捕捉细粒度局部结构与粗粒度全局模式，避免了传统展平带来的时空特征纠缠。

## 实验评估

实验在Human3.6M和MPI-INF-3DHP数据集上进行，基线覆盖了Transformer（PoseFormer, MotionAGFormer）与SSM（PoseMamba, HGMamba）两类主流架构，但缺失生成式方法（如DreamPose3D）的对比，限制了其在多假设场景下的定位。

| 方法 | 参数量 (M) | MACs (G) | P1 (mm) | P2 (mm) |
| :--- | :--- | :--- | :--- | :--- |
| PoseMamba-S | 3.7 | 6.6 | 42.5 | 35.3 |
| HGMamba-S | 2.8 | 1.14 | 42.6 | 33.1 |
| MotionAGFormer-S | 6.1 | 8.02 | 41.8 | 35.0 |
| **SasMamba** | **0.64** | **1.3** | **41.48** | **34.84** |
| **SasMamba-L** | **4.1** | **8.56** | **39.77** | **33.61** |

SasMamba以0.64M参数量实现了41.48mm的P1误差，显著优于同量级的PoseMamba-S（42.5mm）和HGMamba-S（42.6mm），且计算量仅为MotionAGFormer-S的16%。SasMamba-L在精度上接近MotionAGFormer-B（38.4mm），但参数量仅为后者的21%。

| 组件配置 | P1 (mm) |
| :--- | :--- |
| GCN + Local-Global Scan | 43.41 |
| SA-Conv + Local-Global Scan | 42.89 |
| SA-Conv + Stride Scan | **41.48** |
| K=1 (SA-Conv) | 42.67 |
| K=3 (SA-Conv) | **41.48** |
| K=7 (SA-Conv) | 43.18 |

消融实验显示，SA-Conv相比GCN带来0.52mm的改进，而Stride Scan相比固定扫描带来1.41mm的显著增益，表明全局扫描策略对精度的贡献大于局部卷积。值得注意的是，SA-Conv的核大小$K=3$时性能最佳，$K=7$时性能反而下降至43.18mm，这暗示过大的动态邻域可能导致特征平滑过度，稀释了关键的局部结构信息。

评估仅依赖MPJPE指标，未报告置信区间或计算延迟的具体毫秒数，尽管声称实时性，但缺乏帧率数据支撑。代码已开源，训练使用单卡RTX 4090，推理使用A6000，超参数设置（如学习率衰减因子0.99）已公开，具备较高的可复现性。

## 关联研究分析

从方法设计看，SasMamba与PoseMamba的核心差异在于空间结构的处理机制。PoseMamba采用空间重排序策略，本质上仍是基于固定索引的展平，而SasMamba通过SA-Conv引入动态偏移，使局部交互范围随姿态变化。这一差异源于任务特性：人体骨架是非欧几里得图结构，固定重排序无法捕捉关节间距离的动态变化，而动态卷积能更好地适应这种拓扑弹性。然而，SasMamba的步长扫描仍依赖固定的$\{1, 2, 3\}$集合，对于关节数量非标准或拓扑结构异常的输入（如截肢或动物姿态），其适应性尚未得到验证。

从问题动机看，SasMamba与DreamPose3D代表了两种不同的歧义解决路径。DreamPose3D通过扩散模型生成多假设分布，显式处理深度歧义的不确定性；而SasMamba坚持确定性回归，依赖时序平滑与结构先验隐式消解歧义。SasMamba在Human3.6M上的41.48mm虽低于DreamPose3D的37.14mm（据领域综述），但其0.64M参数量与1.3G MACs的计算效率远超扩散模型的多步去噪过程。这种取舍反映了实时性与概率合理性之间的权衡：SasMamba牺牲了对多解性的显式建模，换取了边缘设备部署的可行性，但在遮挡严重或静态帧场景下，其确定性输出可能缺乏物理合理性。

## 总结

SasMamba旨在解决SSM在3D姿态估计中因展平操作导致的空间拓扑丢失问题，通过结构感知卷积与多尺度步长扫描，在保持线性复杂度的同时重建了对骨骼结构的感知。实验证明，该架构以0.64M参数量实现了41.48mm的P1误差，在轻量级模型中处于领先地位，且计算效率显著优于Transformer基线。然而，其性能边界受限于固定步长策略对非标准骨架的适应性，且确定性回归范式在遮挡场景下的鲁棒性未得到充分验证。当输入骨架的关节数量或拓扑结构偏离标准人体模型时，固定步长扫描是否仍能保持结构感知能力，论文未给出回答。
