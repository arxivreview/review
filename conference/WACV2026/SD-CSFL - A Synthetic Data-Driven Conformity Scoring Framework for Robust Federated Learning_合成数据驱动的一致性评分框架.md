# WACV2026最新论文 ｜SD-CSFL: A Synthetic Data-Driven Conformity Scoring Framework for Robust Federated Learning ｜合成数据驱动的一致性评分框架

研究机构：英国兰卡斯特大学

作者：Ebtisaam Alharbi、Abdulrahman Kerim、Leandro Soriano Marcolino 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_0fc704fe5873)

> 联邦学习（FL）中服务器无法审计本地数据，导致梯度操纵与后门攻击在数据非独立同分布（Non-IID）环境下难以被现有防御机制统一拦截。鲁棒聚合对良性方差敏感，聚类方法易被自适应攻击绕过，而依赖客户端数据的检测策略违背隐私原则。本文提出SD-CSFL，利用独立于客户端数据的合成校准集计算基于熵的非一致性分数，结合自适应百分位阈值实现统一防御。该框架在隐私保护约束下提升了检测鲁棒性，但其合成数据生成成本与极端异质性下的检测上限仍存疑。

## 研究背景

联邦学习允许客户端在不共享原始数据的前提下协作训练全局模型，但服务器仅接收模型更新，无法验证本地数据的真实性。这种结构性缺陷使得恶意客户端可通过操纵梯度方向或注入触发器样本实施攻击。在Non-IID设置下，本地数据分布的异质性导致良性更新本身具有较大的统计波动，传统基于距离或聚类的防御机制难以区分良性漂移与恶意投毒，误报率显著升高。

现有防御路线存在明显瓶颈。鲁棒聚合方法如Krum和FLAME通过几何中位数或HDBSCAN聚类过滤异常更新，但在Non-IID环境下，良性更新的方差增大导致这些方法对正常客户端的误判率上升，且计算开销随客户端规模线性增长。知识蒸馏类方法如FedDF和FedBE通过模型间知识转移提升泛化能力，但恶意模型可传播后门行为，导致防御失效。依赖客户端数据的检测策略虽能提升精度，但要求服务器访问本地数据或验证集，直接违背FL的隐私保护核心原则。

SD-CSFL的切入点在于解耦检测过程与客户端数据依赖。通过引入独立生成的合成校准数据集，服务器可在不接触任何客户端原始数据的情况下评估模型更新的可靠性。该设计将防御机制从“数据驱动”转向“分布驱动”，利用合成数据的可控抽象特性放大恶意更新在预测不确定性上的异常表现，从而在隐私保护与检测鲁棒性之间建立新的平衡。

## 核心方法

### 方法参照系

FL防御的标准流程通常包括接收客户端更新、计算异常分数、筛选良性更新并聚合。本文问题与该通用流程的关键差异在于：异常分数的计算不依赖客户端数据或验证集，而是基于服务器端独立生成的合成校准集，且阈值设定采用自适应百分位机制而非固定统计量。

### 熵基非一致性评分

传统防御方法通过计算更新向量与全局均值的距离或聚类隶属度来识别异常，但在Non-IID环境下，良性更新的距离分布本身具有重尾特性，导致固定阈值失效。SD-CSFL改用预测熵作为非一致性度量，其设计动机在于：后门攻击需同时优化干净数据与触发器样本的损失，这种冲突优化会导致模型在干净输入上的预测不确定性增加，而梯度操纵攻击（如ALiE）注入的高方差噪声会直接推高预测熵。

对于客户端模型 $M_i^r$ 在合成校准集 $D_{calibration}$ 上的预测，单样本熵定义为：

$$ H(x, M_i^r) = -\sum_{k=1}^{K} P(y=k|x, M_i^r) \log P(y=k|x, M_i^r) $$

其中 $K$ 为类别数。客户端的非一致性分数 $s_i^{(r)}$ 为校准集上所有批次平均熵的累积：

$$ s_i^{(r)} = \frac{1}{m} \sum_{l=1}^{m} \bar{H}_l $$

该公式的物理含义是：良性更新在合成数据上产生稳定且较低的熵值，而恶意更新因优化目标冲突或噪声注入导致熵值异常升高，从而在分数分布中形成可检测的离群点。

### 自适应百分位阈值与分层校准

固定阈值在Non-IID环境下易受分数分布漂移影响，导致检测性能随训练轮次波动。SD-CSFL采用自适应百分位阈值，其设计动机在于：通过动态调整阈值边界，使检测机制能够适应每轮训练中客户端分数分布的变化，避免固定阈值在异质性加剧时的失效。

服务器设定误报预算 $\delta \in (0,1)$，计算对称分位数阈值：

$$ \tau_{low}^r = Q_{\delta/2}(\{s_i^{(r)}\}_{i \in C}), \quad \tau_{high}^r = Q_{1-\delta/2}(\{s_i^{(r)}\}_{i \in C}) $$

其中 $Q_p(\cdot)$ 表示经验分位数。分数落在 $[\tau_{low}^r, \tau_{high}^r]$ 内的客户端被分类为潜在良性，其余为潜在恶意。为缓解合成校准集的类别不平衡，SD-CSFL构建分层校准集 $L_{balanced}$，对每个样本 $(x_i, y_i)$ 赋予采样权重 $s_i = w_{y_i}$，其中 $w_k = c_k$ 为类别 $k$ 的样本数。加权采样确保欠代表类别被更频繁抽取，减少分数计算中的类别偏差。

## 实验评估

实验在CIFAR-10（10类，50k样本）和Birds-525（525类，84,635样本）上进行，Non-IID设置采用Dirichlet分布（$\alpha=0.9$ 和 $\alpha=0.5$），30个客户端中20%、40%、60%被攻破。基线覆盖鲁棒聚合（FLAME、MKrum、CC）、聚类防御（RFCL）、知识蒸馏（RKD、FedDF、FedBE）及中位数方法。缺失的强基线包括针对参数空间攻击的防御方法如Neurotoxin防御机制，以及最新提出的MARS和BNGuard，这可能影响对SD-CSFL在极端威胁模型下相对性能的全面评估。

|---|---|---|---|---|---|---|
| Median ±1.5σ | 0.64 | 0.54 | - | - | - | - |
| Median ±0.5σ | 0.85 | 0.61 | - | - | - | - |
| Percentile (30–70%) | 0.89 | 0.87 | 0.8 | 1.0 | - | - |

在40%恶意客户端、$\alpha=0.9$ 条件下，百分位阈值（$\delta=0.60$）的F1值为0.8，显著优于中位数±1.5σ的0.54和±0.5σ的0.61。在$\alpha=0.5$ 极端异质性下，百分位阈值的FP达到1.0，TP未报告具体数值，但F1未提供，表明极端Non-IID下检测性能可能退化。消融实验显示，平衡校准集相比非平衡校准集在A3FL和F3BA攻击下均实现更高准确率和更低ASR，验证了分层校准对类别不平衡的缓解作用。

评估边界方面，论文报告了MTA和ASR，但未提供置信区间或多次运行的方差细节（仅提及5次重复）。可复现性方面，代码已开源，但合成数据生成依赖Stable Diffusion-V2和ChatGPT-3.5，生成过程未完全形式化，不同生成器版本可能导致校准集特性差异。超参数如$\delta$的选择基于经验平衡，缺乏理论最优性证明。

## 关联研究分析

从问题动机看，SD-CSFL与FLAME和RFCL的核心差异在于异常检测的统计基础。FLAME依赖HDBSCAN聚类，假设恶意客户端在更新空间中形成密集簇，但在自适应攻击（如A3FL）中，攻击者调整触发器以融入全局模型，导致聚类边界模糊。SD-CSFL改用预测熵作为分数，其检测逻辑不依赖更新向量的几何结构，而是基于模型在合成数据上的行为异常。这一差异的根源在于任务特性：FLAME适用于静态攻击，而SD-CSFL针对动态自适应攻击，但熵分数对梯度操纵攻击（如IPM）的敏感性较低，因为IPM通过微调梯度方向保持统计相似性，仅导致分数在阈值附近波动，检测依赖动态阈值调整。

从方法设计看，SD-CSFL与Conformal Prediction在FL中的应用存在框架差异。现有Conformal Prediction工作如部分可交换性方法主要用于不确定性量化，而非防御机制。SD-CSFL将Conformal Prediction的误报率保证引入防御流程，通过百分位阈值实现分布无关的FP控制。这一设计的创新在于将合成数据作为校准源，解决了Conformal Prediction通常依赖测试集或验证集的限制。然而，合成数据与真实数据分布的差异可能导致校准偏差，尤其在极端Non-IID下，合成数据的抽象特性可能无法充分覆盖所有潜在攻击模式，检测上限受限于生成器的表达能力。

## 总结

SD-CSFL旨在解决FL中隐私保护与统一防御的矛盾，通过合成数据校准解耦检测与客户端数据依赖。其核心创新在于熵基非一致性评分与自适应百分位阈值的结合，在CIFAR-10和Birds-525上实现了比基线更高的检测率和更低的ASR。实验表明，在40%恶意客户端、$\alpha=0.9$ 条件下，百分位阈值的F1为0.8，优于中位数方法。然而，论文未报告极端Non-IID（$\alpha=0.5$）下的完整F1值，且合成数据生成依赖特定模型版本，校准集特性可能随生成器变化而漂移。当合成数据与真实数据分布差异扩大时，熵分数的检测灵敏度是否仍能维持，论文未给出定量回答。
