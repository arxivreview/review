# WACV2026最新论文 ｜FairScene: Learning Class-Disentangled 2D/3D Representations for Semantic Scene Completion ｜类别解耦表示的语义场景补全

作者：Dian Jia、Pei Yu、Wei Tang

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_183e974f1f86)

> 语义场景补全（SSC）旨在从相机图像预测3D体素的占据状态与语义标签，是自动驾驶中低成本感知方案的核心。现有方法受限于体素类别不平衡、遮挡及深度歧义，导致长尾类别召回率极低且几何结构模糊。FairScene通过解耦2D/3D特征并显式建模跨类空间依赖，结合几何保持的数据增强，缓解了上述问题。该方法在SemanticKITTI上取得15.76 mIoU，但在实时性与动态场景适应性上缺乏验证。

## 研究背景

当相机传感器面对复杂驾驶场景时，像素级特征直接投影至3D空间会遭遇严重的深度歧义与遮挡干扰。这种2D-3D模态差距导致传统SSC方法在预测稀疏类别（如行人、交通标志）时，多数类特征主导了网络表征，使得少数类体素被错误分类或遗漏。为缓解此问题，研究者通常引入多视角编码或Transformer架构，但这些方法往往将不同类别的特征混合在同一通道中，未能显式利用物理世界中物体间的固有空间关系（如车辆行驶于路面、标志安装于立柱），从而难以解决遮挡区域的语义不确定性。

SSC领域的主流路线包括基于三视角平面编码（TPVFormer）和隐式立体匹配（OccDepth）的方法，它们通过几何建模提升投影精度，但仍未解决类别不平衡导致的表征偏置。Symphonize等方法尝试通过实例查询改善语义上下文，但在长尾类别上召回率依然低下（如person类仅2.10%）。FairScene的切入点在于将“类别解耦”引入2D-to-3D提升过程，不再让单一特征图承载所有类别信息，而是为每个类别构建独立的特征流，并通过跨类推理机制显式建模物理依赖，从而在数据稀缺条件下实现更公平的体素分类。

## 核心方法

### 方法参照系

标准SSC流程包含图像特征提取、2D-to-3D提升及体素级语义预测。本文的关键差异在于将“全局共享特征”替换为“类别解耦特征”，并在3D空间中引入跨类消息传递机制，而非仅依赖单类特征的独立预测。

### 类别解耦2D-to-3D表示学习

传统方法使用单一特征图提升所有类别，导致多数类特征淹没少数类。FairScene将2D骨干网络输出的特征解耦为$K$个类别特定表示$F^{2D}_k$，每个表示仅编码对应类别的空间与语义信息。解耦通过密集语义引导实现：利用语义射线行进（Semantic Ray Marching, SRM）生成连续2D掩码，替代稀疏的体素中心投影。SRM沿视线迭代采样，直至命中占据体素，从而提供鲁棒的2D监督信号。

$$
F^{3D}_k = \{(f^{lift}_{k,p}, p) : o_p = 1\}, \quad k = 1, \dots, K
$$

该公式表明，每个类别的3D特征体积仅保留占据体素处的提升特征，共享占据图以节省计算并允许多类特征共存于同一空间位置。这种解耦设计确保每个类别在2D和3D空间中均获得平衡的表征，防止多数类主导几何处理过程。

### 跨类占据推理

类别解耦后，不同类别特征间缺乏交互，无法利用物理先验（如车在路）解决遮挡歧义。FairScene引入跨类占据推理机制，动态推断类别间依赖度并指导空间消息传递。首先，对每个类别的3D特征体积进行全局平均池化得到全局表示$h_k$，再通过全连接层与Softmax推断依赖矩阵$a_{k,j}$。

$$
\bar{F}^{3D}_k = W_k * F^{3D}_k + \sum_{j=1}^{K} a_{k,j} W_j * F^{3D}_j
$$

该公式将类别$k$的更新表示定义为自身特征与所有其他类别特征的加权和，权重由依赖度$a_{k,j}$决定。若类别$k$强烈依赖类别$j$（如车辆依赖路面），则类别$j$的特征将更多贡献于$k$的更新。这一机制将图卷积推广至高维张量空间，实现了基于物理关系的跨类空间交互，有效缓解了遮挡与深度不确定性。

## 实验评估

实验在SemanticKITTI和SSCBench-KITTI-360上进行，基线包括SGN、Symphonize、MonoOcc及CGFormer。对比方法覆盖了Transformer架构（Symphonize）、知识蒸馏（MonoOcc）及多模态监督（CGFormer），但缺乏3DGS类显式表示方法的对比，这可能限制了与最新实时渲染范式的直接比较。

| 方法 | SemanticKITTI mIoU | SemanticKITTI IoU | KITTI360 mIoU | KITTI360 IoU |
| :--- | :--- | :--- | :--- | :--- |
| SGN | 12.16 | 40.43 | 12.63 | — |
| Symphonize | 13.26 | 41.40 | 14.28 | — |
| FairScene | 15.76 | 43.00 | 19.57 | 47.79 |

FairScene在两个数据集上均取得最高mIoU，尤其在KITTI360上mIoU达19.57，显著优于SGN的12.63。在遮挡区域评估中，FairScene的F1分数为15.77（SemanticKITTI），高于Symphonize的13.26，表明其在恢复被遮挡结构方面更具优势。

| 组件 | IoU | mIoU |
| :--- | :--- | :--- |
| w/o OccMix | 42.79 | 15.66 |
| + CRL | 41.40 | 13.82 |
| + 2D SG | 41.60 | 14.01 |
| + IOR | 42.12 | 14.67 |
| + 3D SG | 43.34 | 15.64 |
| + OccMix | 43.63 | 16.06 |

消融实验显示，单独使用类别解耦表示学习（CRL）导致mIoU下降（13.82 vs 15.66），表明解耦本身若无后续交互机制会损失信息。引入跨类占据推理（IOR）后mIoU回升至14.67，验证了跨类交互对弥补解耦损失的必要性。OccMix数据增强最终将mIoU提升至16.06，其中体素提案融合贡献了0.21的mIoU增益，证明几何一致性约束在数据增强中的关键作用。

评估指标涵盖mIoU、IoU、F1及深度误差（Abs Rel/RMSE），但未报告推理速度或内存占用，无法评估其实时性。代码已开源，但论文未提供详细超参数配置，复现需依赖补充材料。

## 关联研究分析

从问题动机看，FairScene与Symphonize均针对长尾类别，但Symphonize依赖实例查询建模上下文，而FairScene通过类别解耦与跨类推理显式利用物理先验。Symphonize在person类上召回率仅2.10%，而FairScene达到26.75%，差异根源在于FairScene的解耦机制避免了多数类特征对少数类几何投影的干扰，而Symphonize的查询机制在数据稀疏时难以形成稳定的实例表征。

从方法设计看，FairScene与OccDepth共享2D-to-3D提升框架，但OccDepth聚焦于隐式立体匹配解决深度歧义，而FairScene通过跨类推理解决语义歧义。OccDepth未处理类别不平衡问题，导致其在长尾类别上性能受限。FairScene的SRM生成密集2D监督，相比OccDepth的稀疏投影更鲁棒，但计算开销更大。这种设计选择反映了任务特性的差异：SSC更关注语义完整性，而深度估计更关注几何精度。

## 总结

FairScene针对SSC中体素类别不平衡与几何歧义的矛盾，通过类别解耦表示与跨类占据推理，实现了长尾类别召回率的显著提升。该方法在SemanticKITTI上取得15.76 mIoU，较Symphonize提升2.5个百分点，并在遮挡区域F1分数上领先2.51。其边界在于未验证实时性，且跨类推理依赖全局池化，可能丢失局部空间细节。当场景动态变化时，静态依赖矩阵$a_{k,j}$能否适应物体运动导致的类别关系变化，论文未给出回答。
