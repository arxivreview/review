# WACV2026最新论文 ｜EllipssianNet: Image-guided Sampling of 2D Gaussians for Gaussian Splatting ｜图像引导的各向异性高斯采样

作者：MyoungGon Kim、JeongHyeon Ahn、Seohyeon Park 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_6aefedfe0038)

> 3D高斯泼溅（3D Gaussian Splatting, 3DGS）的初始化质量直接决定后续致密化的计算开销与最终重建上限，但传统基于运动恢复结构（Structure from Motion, SfM）的稀疏点云初始化存在分布不均与噪声干扰，导致复杂区域欠重建。现有采样策略或依赖昂贵的预处理，或仅能生成各向同性高斯，无法对齐图像局部结构。EllipssianNet 通过前馈网络从单张 RGB 图像直接预测各向异性 2D 高斯的位置与协方差，实现免 SfM 的高效初始化。该方法在实时 SLAM 与图像表示任务中验证了有效性，但其对深度信息的忽略及缺乏多视图一致性约束，限制了其在复杂三维场景中的泛化潜力。

## 研究背景

3DGS 依赖初始高斯分布的合理性来平衡渲染质量与参数效率。SfM 提供的稀疏点云虽能建立全局几何框架，但其点距分布极不均匀，导致致密化阶段需在空白区域大量分裂高斯，而在密集区域产生冗余重叠。这种初始化缺陷迫使优化器在“欠重建”与“过参数化”之间反复震荡，增加了收敛时间并降低了最终保真度。

主流解决路线分为两类：一是后处理压缩，如 Light Gaussian 与 CompGS，通过剪枝或量化减少冗余，但无法修复初始分布的空间不连续性；二是预处理采样，如 Superpixel-Guided Sampling 与 On-the-Fly NVS，通过图像梯度或超像素调整高斯放置，但前者计算开销大难以实时化，后者仅支持各向同性高斯，无法捕捉纹理方向的几何细节。EllipssianNet 的切入点在于将初始化视为一个图像到几何参数的前馈预测问题，利用神经网络直接推断各向异性椭圆的分布与形状，从源头消除 SfM 依赖并降低致密化负担。

## 核心方法

### 方法参照系

标准 3DGS 流程为：SfM 稀疏点云 -> 致密化（分裂/克隆） -> 剪枝。本文的关键差异在于跳过 SfM，直接由 RGB 图像预测 2D 高斯参数，再提升为 3D 进行优化。这一改动将初始化从“几何反演”转变为“图像特征映射”，核心挑战在于如何定义图像到各向异性高斯的监督信号。

### 基于 Voronoi 图的合成数据生成

传统采样方法缺乏统一的真值定义，因为同一图像可对应多种合理的高斯分布。EllipssianNet 利用 Voronoi 图的凸分解特性构建监督数据：随机放置种子点生成 Voronoi 图，每个多边形赋予随机颜色，形成包含凸与凹区域的 RGB 图像 $I$。对于每个多边形，计算其质心到最近边缘的欧氏距离 $d_{edge}$，并定义中心图 $C$ 的像素值为快速衰减函数：

$$ f(d) = \frac{1}{1 + 10d} $$

其中 $d$ 为像素到质心的距离（截断于 $[0, d_{edge}]$）。该设计使得中心概率在质心处为 1，随距离增加迅速衰减，为网络提供了明确的“高斯中心”监督信号。协方差矩阵 $\Sigma$ 通过多边形边界像素的统计量计算，并采用 Cholesky 分解 $\Sigma = LL^\top$ 参数化为 $\{a, b, c\}$ 以保证正定性。这一合成策略解决了真值歧义问题，使网络能够学习图像局部结构到高斯几何参数的确定性映射。

### 编码器-解码器网络与辅助梯度监督

EllipssianNet 采用 ResNet 作为骨干网络，因其擅长提取边缘与纹理等局部特征，而 Transformer 的全局注意力机制在此任务中并非必需且推理较慢。网络输出三个图：中心图 $\hat{C}$、协方差图 $\hat{\Sigma}$ 和梯度图 $\hat{G}$。梯度图 $\hat{G}$ 存储像素到最近多边形边界的距离，作为辅助输出通过逐元素乘法加权特征 $z$，增强边缘感知能力。最终损失函数为：

$$ L = \lambda_C L_C + \lambda_\Sigma L_\Sigma + \lambda_G L_G $$

其中 $L_C, L_\Sigma, L_G$ 分别为预测图与真值图的均方误差。这一设计动机在于：单纯的中心与协方差预测易导致高斯边界模糊，引入梯度图监督迫使网络关注图像结构边界，从而生成更紧凑、对齐局部复杂度的各向异性高斯。训练数据包含 50K 样本，多边形数量在 10 至 500 之间变化，77% 的数据采用聚类分布以模拟真实图像的非均匀物体分布，确保跨域泛化能力。

## 实验评估

实验在 Kodak、DIV2K、Image-GS（图像表示）及 Replica、TUM、ScanNet（SLAM）上进行。图像表示任务对比 FR（随机采样）、CSR（颜色采样随机位置）、EGS（EllipssianNet 位置但各向同性）；SLAM 任务对比 Mono、Photo、Splat、OTF-NVS。基线覆盖了启发式采样与现有 SLAM 方法，但缺乏与 Faster-GS 等优化加速类方法的直接对比，且未在 Mip-NeRF 360 等标准新视角合成基准上测试。

| 数据集 | 方法 | PSNR (dB) |
| :--- | :--- | :--- |
| Kodak | EGS | 27.17 |
| Kodak | Ours | 27.54 |
| DIV2K | EGS | 25.62 |
| DIV2K | Ours | 25.84 |
| Image-GS | EGS | 23.95 |
| Image-GS | Ours | 24.80 |

在图像表示任务中，EllipssianNet 相比各向同性基线 EGS 在 Kodak 上提升 0.37 dB，在 Image-GS 上提升 0.85 dB，表明各向异性形状对高频细节重建有显著贡献。SLAM 任务中，Replica 数据集 PSNR 达 32.73，优于 OTF-NVS 的 30.36；TUM 数据集 PSNR 为 22.70，略高于 OTF-NVS 的 22.67。然而，轨迹误差（ATE）方面，TUM 数据集 ATE 为 3.58 cm，高于 OTF-NVS 的 34.79 cm（注：此处原文数据可能存在单位或记录错误，OTF-NVS 34.79 cm 远大于本文 3.58 cm，但 Replica 上本文 0.89 cm 优于 OTF-NVS 16.05 cm），显示渲染质量提升并未完全转化为轨迹精度优势。

消融实验表明，移除梯度图辅助损失会导致高斯边界模糊，验证了边缘监督对形状精度的必要性。评估边界方面，论文未报告训练时间对比（仅提及 EllipssianNet 训练耗时 33 小时），且 SLAM 实验未包含地图到帧（map-to-frame）的位姿细化，可能低估了最终精度。代码与权重已开源，但合成数据生成脚本未详细披露，复现需依赖补充材料。

## 关联研究分析

从问题动机看，EllipssianNet 与 On-the-Fly NVS 均旨在解决在线采样效率问题，但前者将启发式梯度规则替换为前馈网络，实现了从“规则驱动”到“数据驱动”的范式转移。这一差异的根源在于任务特性：On-the-Fly NVS 依赖实时深度估计，而 EllipssianNet 仅依赖 RGB 图像，避免了深度估计误差在初始化阶段的固化，但代价是丢失了显式深度信息，导致 2D 高斯提升为 3D 时深度固定为 1，依赖后续优化修正。

从方法设计看，EllipssianNet 与 Image-GS 均利用图像梯度信息，但 Image-GS 采样各向同性高斯，而 EllipssianNet 预测各向异性协方差。这一改进源于对高斯几何属性的更完整建模：各向异性椭圆能更好地对齐纹理方向，减少覆盖同一结构所需的高斯数量。然而，EllipssianNet 的 Voronoi 合成数据仅包含单视图信息，缺乏多视图一致性约束，这与 Scaffold-GS 等引入层级结构的方法形成对比。单视图预测在静态图像表示中有效，但在多视图 SLAM 中，不同视角预测的高斯可能产生几何冲突，论文未探讨此问题。

## 总结

EllipssianNet 针对 3DGS 初始化中 SfM 稀疏点云分布不均与致密化开销大的矛盾，提出从单张 RGB 图像直接预测各向异性 2D 高斯的前馈方法。通过 Voronoi 图合成数据解决真值歧义，并利用 ResNet 编码器-解码器网络学习图像结构到高斯几何的映射，在图像表示与 SLAM 任务中实现了比启发式基线更高的 PSNR（Kodak 27.54 dB，Replica 32.73 dB）。其边界在于 2D 高斯提升为 3D 时深度固定，且缺乏多视图一致性约束，导致在复杂三维场景中可能产生几何冲突。当支持集增大到多视图输入时，单视图预测的各向异性高斯是否仍能保持几何一致性，论文未给出回答。
