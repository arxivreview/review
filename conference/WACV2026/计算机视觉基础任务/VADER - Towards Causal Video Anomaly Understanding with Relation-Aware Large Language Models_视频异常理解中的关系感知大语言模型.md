# WACV2026最新论文 ｜VADER: Towards Causal Video Anomaly Understanding with Relation-Aware Large Language Models ｜视频异常理解中的关系感知大语言模型

研究机构：国立清华大学

作者：Ying Cheng、Yu-Ho Lin、Min-Hung Chen 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.07299)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.07299)

> 视频异常检测长期受限于仅输出二元分数，缺乏对事件因果链的语义解释能力。现有基于多模态大语言模型（MLLM）的方法虽能生成文本，但往往忽略对象间动态交互这一关键视觉证据，导致解释缺乏物理支撑。VADER 通过引入上下文感知采样与对比关系编码器，将对象交互动态显式编码为 Token 注入 LLM，实现了因果一致的异常叙事。该框架在多个基准上刷新了记录，但其对高运动异常的依赖及对象中心视角的局限，使其在低运动或群体行为场景下的泛化能力仍存疑。

## 研究背景

当监控视频中出现异常事件时，传统检测器仅能标记“此处异常”，却无法回答“为何异常”及“如何发生”。这种语义缺失源于早期方法对视觉统计量的过度依赖，而异常行为往往由对象间特定的交互模式引发，如人群中的逆行或物体间的碰撞。要捕捉这种交互，需引入场景图（Scene Graph）结构，将对象建模为节点、关系建模为边，从而超越低层特征，进入关系理解层面。然而，静态场景图无法反映交互随时间的演变，这正是视频异常理解（VAU）的核心难点。

视频异常检测的主流范式已从弱监督定位转向语义理解，但现有 MLLM 方案存在明显瓶颈。Holmes-VAU 等通过异常聚焦采样提升了效率，CUVA 等关注因果推理，但它们大多直接利用视觉特征或通用文本提示，未能显式建模对象间动态变化的关系。这种缺失导致模型在面对复杂交互时，生成的解释往往流于表面，甚至出现幻觉。VADER 的切入点在于，将对象关系的动态变化作为一种独立的视觉线索，通过专门的编码器将其转化为 LLM 可理解的语义 Token，从而弥补纯文本推理在视觉细节上的不足。

## 核心方法

### 方法参照系

VADER 属于 MLLM 驱动的 VAU 路线，其标准流程通常包括：异常检测、关键帧采样、视觉特征提取、LLM 推理。与通用 MLLM 直接处理视频帧不同，VADER 在特征提取与 LLM 之间插入了一个专门的关系建模分支，旨在将隐式的视觉交互转化为显式的语义信号。

### 上下文感知采样（CAES）

CAES 解决了传统均匀采样或 Top-K 采样忽略事件因果上下文的问题。传统方法往往只关注异常峰值帧，导致模型缺乏对事件前因后果的理解。VADER 基于异常分数序列的梯度，自适应地划分事件前、中、后三个阶段，并从中均匀采样关键帧。具体而言，系统首先通过百分位阈值检测异常区间，然后利用上升阈值（Rise Threshold）和平静阈值（Calm Threshold）确定事件的起止边界。关键帧集合 $K$ 的选取遵循：

$$ K = \{ k_i \mid k_i \in \text{Pre} \cup \text{On} \cup \text{Post}, \text{uniformly sampled} \} $$

这一设计确保了模型能捕捉到异常的完整叙事结构，而非孤立的异常瞬间。

### 对比关系编码器（CORE）

CORE 旨在将对象间动态交互编码为紧凑的关系 Token，解决静态场景图无法反映时间演变的问题。对于每个关键帧，VADER 利用 DETR 提取对象关系张量，并计算相邻帧间关系特征的 $L_2$ 范数差作为“关系波动率”（Relational Volatility）。波动率峰值对应显著的交互变化，被标记为正样本；谷值及正常视频片段作为负样本。CORE 通过三元组损失函数训练，将关系变化对映射为关系 Token：

$$ \mathcal{L} = \max(0, d(f_a, f_p) - d(f_a, f_n) + \alpha) $$

其中 $f_a, f_p, f_n$ 分别为锚点、正样本和负样本的关系 Token，$\alpha$ 为间隔。这些 Token 与视觉 Token 一同输入 LLM，使模型能基于显式的交互动态进行因果推理。

## 实验评估

VADER 在 HIVAU-70k、HAWK 和 CUVA 三个基准上进行了评估，对比了 Video-ChatGPT、Otter、Holmes-VAU 等强基线。在 HAWK 基准的描述任务中，VADER 的 BLEU-1 达到 1.266，显著优于 Holmes-VAU 的 0.913；在 CUVA 基准的因果任务中，MMEval 得分 66.30，较 CUVA* 的 50.64 提升 15.66 分。

| 基准 | 任务 | 指标 | VADER | Holmes-VAU | CUVA* |
| :--- | :--- | :--- | :--- | :--- | :--- |
| HAWK | Description | BLEU-1 | 1.266 | 0.913 | - |
| CUVA | Causes | MMEval | 66.30 | - | 50.64 |
| HIVAU-70k | Description | BLEU-1 | 1.266 | 0.913 | - |

消融实验显示，移除 CORE 模块导致 HAWK 描述任务的 BLEU 从 0.718 降至 0.668，验证了关系建模对文本生成的贡献。移除 CAES 后，BLEU 降至 0.594，表明上下文采样对叙事连贯性至关重要。值得注意的是，移除微调后，GPT 引导的细节得分反而异常升高至 0.527，这可能源于模型在未适配领域时生成了更长但更发散的回答，提示了微调在约束输出焦点上的作用。

评估指标涵盖了词汇级（BLEU）、语义级（MoverScore）和裁判级（MMEval），较为全面。然而，所有实验均基于微调后的模型，缺乏零样本泛化能力的直接对比。此外，论文未报告推理延迟，对于实时部署场景的适用性未作验证。代码已开源，但超参数配置细节需查阅补充材料。

## 关联研究分析

从问题动机看，VADER 与 Holmes-VAU 均关注关键帧采样，但 Holmes-VAU 侧重于基于异常分数的密度感知采样，旨在提高检测效率；而 VADER 的 CAES 侧重于基于分数梯度的因果上下文采样，旨在提升解释的完整性。这一差异源于任务目标的不同：Holmes-VAU 更偏向检测与定位，VADER 则聚焦于理解与解释。VADER 的采样策略更契合 VAU 对叙事连贯性的要求，但可能引入更多冗余帧，增加计算开销。

从方法设计看，VADER 与 CUVA 均致力于因果推理，但 CUVA 主要依赖 LLM 的文本推理能力，通过提示工程引导模型关注因果链；VADER 则通过 CORE 模块显式注入视觉关系动态，为因果推理提供物理证据。这种“视觉证据+文本推理”的混合路径，试图解决纯文本推理易产生幻觉的问题。然而，CORE 依赖 DETR 的对象检测准确性，若检测失败，关系 Token 将失效，这是其相对于纯文本方法的潜在脆弱点。

## 总结

VADER 旨在解决视频异常理解中因果解释缺乏视觉支撑的矛盾，通过 CAES 捕捉事件上下文，利用 CORE 显式编码对象动态交互，将视觉关系转化为 LLM 可理解的语义 Token。实验表明，该方法在 HAWK 和 CUVA 基准上显著优于现有 SOTA，证明了显式关系建模对因果推理的有效性。然而，其依赖关系波动率作为核心信号，导致对高运动异常敏感，而对低运动或静态异常（如环境变化）的捕捉能力有限。当异常事件主要由细微的环境变化或群体集体行为引发，而非显著的对象交互时，CORE 模块的波动率信号是否仍能提供有效的因果线索，论文未给出回答。
