# WACV2026最新论文 ｜Improving Out-of-Distribution Detection using Segmented Images and Cross-View Attention Fusion ｜跨视图注意力融合提升分布外检测

作者：Alexander Politowicz、Sahisnu Mazumder、Bing Liu

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_WACV_2026_67421800)

> 分布外检测（OOD Detection）旨在识别训练分布之外的样本，其核心瓶颈在于近邻分布外（Near-OOD）样本与分布内（ID）样本在特征空间中高度重叠。现有单视图方法因无法有效隔离类相关特征，常学习到捷径特征，导致近邻检测失效。本文提出 CASOD，通过显式分割前景与背景视图，并利用跨视图相关性注意力（CVCA）融合多源特征，以增强 ID 类判别力。该方法在中等规模基准上显著提升了检测精度，但其性能受限于分割工具的泛化能力及对复杂语义场景的覆盖度。

## 研究背景

当检测器面对与训练数据语义高度相似的近邻 OOD 样本时，传统基于最大 Softmax 概率（MSP）或能量分数（Energy Score）的后验评分往往失效。这是因为单视图学习框架将图像视为整体，迫使模型在包含大量类无关背景信息的特征空间中寻找判别边界，极易陷入对背景纹理或光照等捷径特征的依赖。这种依赖导致 ID 特征簇在特征空间中分布松散，使得近邻 OOD 样本与 ID 样本的边界模糊，难以通过简单的距离度量进行区分。

近邻 OOD 检测已成为该领域的主要瓶颈，现有方法在远端 OOD 上表现良好，但在特征空间边界处的区分能力不足。主流路线包括基于特征空间几何的分析（如神经坍缩理论）和生成式模型信号（如扩散模型评分函数），但前者依赖骨干网络的深层特征质量，后者面临计算效率与似然不可靠的双重挑战。CASOD 的切入点在于数据预处理阶段的显式结构解耦：它不改变骨干网络或评分函数，而是通过引入前景-背景分割，将单视图问题转化为多视图学习问题，旨在从源头上提升特征提取器对类相关信息的捕获能力。

## 核心方法

### 方法参照系

标准 OOD 检测流程通常包含特征提取与评分两个阶段：使用预训练骨干网络提取图像特征，再通过距离度量（如马氏距离，MD）或后验评分判断样本归属。CASOD 遵循此通用框架，其关键差异在于特征提取阶段引入了显式的前后景分割，并将单视图特征映射扩展为三视图（原始、前景、背景）的多源特征融合机制。

### 多视图特征提取与参数高效适配

传统单视图特征提取器在处理包含复杂背景的图像时，难以自动隔离类相关区域。CASOD 在特征提取环节引入 YOLOv5 分割模型，将输入图像 $x$ 分解为原始视图 $x_{org}$、前景视图 $x_{fg}$ 和背景视图 $x_{bg}$。为降低计算开销，模型采用冻结的 ViT-B-16 骨干网络，并为每个视图添加可训练的 LoRA Adapter 模块。每个视图 $x_v$ 通过对应的 Adapter 提取特征 $z_v$，其过程可表示为：

$$ z_v = \phi_v(x_v), \quad v \in \{org, fg, bg\} $$

其中 $\phi_v$ 包含冻结的 ViT 权重与视图特定的 Adapter 参数。这一设计解决了单视图模型在复杂背景下特征判别力不足的问题，通过显式分离前景与背景，迫使模型分别学习物体本身与上下文环境的特征表示，从而在参数成本降低 44% 的同时，获得了更纯净的类相关信号。

### 跨视图相关性注意力融合

单一视图的特征往往信息不完整，例如“狗”类特征主要在前景，而“山”类特征主要在背景。CASOD 引入跨视图相关性注意力（CVCA）模块，以层级结构融合三视图特征。CVCA 模块接收两个视图特征 $z_{v1}$ 和 $z_{v2}$，通过前馈网络生成查询 $Q_{v1}$、键 $K_{v2}$ 和值 $V_{v2}$，计算交叉注意力矩阵 $A$ 以捕获视图间的关联信息：

$$ z_{v2 \to v1} = A \cdot V_{v2}, \quad A = \text{softmax}\left(\frac{Q_{v1} K_{v2}^T}{\sqrt{d_k}}\right) + \text{softmax}\left(\frac{Q_{v2} K_{v1}^T}{\sqrt{d_k}}\right) $$

该公式通过双向注意力机制，使前景特征能够关注背景中的语义上下文，反之亦然。随后，原始视图与前景/背景视图的交互特征进一步通过第二层 CVCA 融合，最终生成融合特征 $z_{fused}$。这种层级化融合机制解决了简单拼接或加权求和无法捕捉视图间复杂语义依赖的问题，确保了融合特征同时包含物体细节与环境上下文，显著提升了特征空间的结构紧凑性。

## 实验评估

实验在 ImageNet-100-Random (I-100-R) 和 ImageNet-1k (I-1k) 上进行，涵盖 NINCO、SSB-Hard 等近邻 OOD 基准及 iNaturalist 等远端 OOD 基准。基线覆盖了 MSP、Energy、KNN、ViM 等主流后验与特征方法，但缺失了训练时正则化方法（如 Outlier Exposure）及最新的扩散模型检测方法（如 SCOPED）。

| 方法 | I-100-R Near-OOD AUC | I-100-R Far-OOD AUC | I-1k Near-OOD AUC | I-1k Far-OOD AUC |
| :--- | :--- | :--- | :--- | :--- |
| MSP | 84.77 | 90.77 | 79.65 | 86.19 |
| Energy | 81.30 | 86.00 | 72.63 | 80.66 |
| KNN | 75.05 | 84.78 | 82.88 | 90.81 |
| CASOD | 89.16 | 97.31 | 78.97 | 93.97 |

CASOD 在 I-100-R 上表现优异，近邻 OOD AUC 达到 89.16，远端 OOD AUC 达到 97.31，显著优于所有基线。然而，在大规模 I-1k 基准上，CASOD 的近邻 OOD AUC 为 78.97，低于 KNN 的 82.88，且远端 OOD AUC 93.97 虽高于 MSP 和 Energy，但优势幅度缩小。这表明多视图融合在中小规模数据集上能有效提升特征判别力，但在大规模复杂场景下，其增益可能被骨干网络的容量限制或分割误差所抵消。

消融实验显示，单独使用前景或背景视图的性能均低于原始视图，而任意两个视图的组合（如 Org+Fg）性能也低于完整的三视图融合，证实了 CVCA 融合机制的必要性。此外，与使用相同数据量和参数的单视图模型相比，CASOD 在远端 OOD 上 AUC 提升约 5.6 个百分点，验证了显式分割带来的特征质量提升。

评估协议遵循 OpenOOD v1.5 标准，但论文未报告计算效率指标，且依赖 YOLOv5 分割工具，该工具在未见域上的鲁棒性未做系统性分析。代码已开源，但超参数配置细节仅在附录中提供，复现时需特别注意分割模型的预训练数据与 ID 数据集的潜在重叠风险。

## 关联研究分析

从问题动机看，CASOD 与 GEODE 均旨在解决近邻 OOD 检测中特征边界模糊的问题，但二者路径截然不同。GEODE 依赖神经坍缩理论，通过多层特征融合来增强类内紧凑性，属于特征空间几何分析的深化；而 CASOD 则通过数据层面的显式分割来隔离类相关特征，属于数据增强与多视图学习的结合。CASOD 的优势在于无需修改骨干网络结构，部署成本低，但其性能高度依赖分割工具的准确性。相比之下，GEODE 对分割误差免疫，但计算复杂度更高。CASOD 在 I-1k 上性能不及 GEODE，暗示在大规模数据中，显式分割引入的噪声可能超过了其带来的特征纯净度收益。

从方法设计看，CASOD 与 ANTS 代表了单模态多视图与跨模态零样本两条竞争路线。ANTS 利用视觉语言模型（VLM）动态构建负文本空间，通过语义对齐来捕捉分布偏移，具有零样本能力；而 CASOD 坚持纯视觉路线，依赖 ID 数据训练，不具备零样本能力。CASOD 的局限在于其性能上限受限于 ID 数据的覆盖范围，当 OOD 样本与 ID 样本在语义上完全无关时，前景-背景分割可能无法提供足够的判别信息。ANTS 则通过文本模态的丰富语义空间，能够处理更广泛的分布偏移，但计算开销巨大。CASOD 在 I-100-R 上的优异表现表明，在资源受限且 ID 数据充足的场景下，纯视觉多视图方法可能比跨模态方法更具性价比。

## 总结

CASOD 针对近邻 OOD 检测中单视图特征判别力不足的核心矛盾，提出了基于前景-背景分割与跨视图注意力融合的多视图学习框架。通过显式隔离类相关特征并利用 CVCA 模块融合多源信息，该方法在 I-100-R 基准上实现了近邻 OOD AUC 89.16 和远端 OOD AUC 97.31 的性能提升。然而，其在 I-1k 大规模基准上的表现未能超越 KNN 等简单基线，暴露了显式分割在复杂场景下的局限性，且对分割工具泛化能力的依赖构成了潜在风险。当 ID 数据规模扩大至 ImageNet-1k 时，前景-背景分割带来的特征增益是否会被分割误差累积所抵消，论文未给出回答。
