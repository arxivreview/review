【SCATR: Mitigating New Instance Suppression in LiDAR-based Tracking-by-Attention via Second Chance Assignment and Track Query Dropout ｜缓解LiDAR注意力跟踪中新实例抑制的二次分配与查询丢弃机制

研究机构：加拿大多伦多大学

作者：Brian Cheong、Letian Wang、Sandro Papais 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.01485)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.01485)

> LiDAR多目标跟踪（MOT）旨在从时序点云中维持物体身份一致性，但基于注意力（TBA）的方法长期落后于基于检测（TBD）的流水线，核心症结在于新实例检测置信度被系统性抑制。现有TBA架构通过查询传播维持轨迹，却因新生物体样本稀缺导致模型学会“一刀切”地抑制提议查询，造成大量漏检。SCATR通过引入二次分配与查询丢弃两种训练策略，在不增加架构复杂度的前提下重构了监督信号分布。该方法在nuScenes测试集上以65.0% AMOTA刷新LiDAR TBA纪录，但推理频率仅2.9 Hz，且检测精度仍略逊于顶级TBD基线，其端到端优势是否足以抵消实时性损耗尚存疑。

【WiSAR3D - Aerial LiDAR Dataset for 3D Object Detection ｜野外搜救LiDAR三维检测数据集与基准

研究机构：以色列理工学院

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_8fb767a79d39)

> 野外搜救（WiSAR）场景要求无人机在复杂植被环境中快速定位人员，但现有自动驾驶LiDAR检测器因输入格式、目标形态及环境差异无法直接迁移。本文构建了首个针对该场景的空中LiDAR三维数据集WiSAR3D，并适配主流检测器建立基准。实验表明，现有方法在检测人体等变形目标时性能显著下降，且高显存模型与低显存模型存在精度-效率权衡。该工作填补了领域空白，但缺乏专用算法创新，其基准结果揭示了通用模型在野外场景的局限性。

【WiSAR3D - Aerial LiDAR dataset for 3D object detection ｜野外搜救场景下的机载LiDAR三维检测基准

研究机构：以色列理工学院

作者：Oren Shrout、Ori Nizan、Yizhak Ben-Shabat 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_WACV_2026_61777408)

> 无人机搜救（Wilderness Search and Rescue, WiSAR）面临植被遮挡与光照多变的双重挑战，传统RGB传感器在低光与密林环境下失效，而车载LiDAR数据集缺乏野外非结构化场景的标注。本文构建了首个针对该场景的机载多回波LiDAR数据集WiSAR3D，并适配现有自动驾驶检测器建立基准。通过引入多回波特征与采样率变量，揭示了现有模型在野外稀疏小目标上的性能瓶颈，但缺乏针对该场景的专用轻量化架构。
