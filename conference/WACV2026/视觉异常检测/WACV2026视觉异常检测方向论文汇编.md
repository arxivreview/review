【Enhancing Reverse Distillation with Core Exemplar Learning for Unified Multi-Class Anomaly Detection ｜统一多类异常检测中的核心样本学习与域适应

作者：Heechul Lim、Min-Soo Kim、Hyun-Boo Lee 等 6 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_cce298129e0d)

> 电子制造产线需同时处理数千种产品，现有逐类训练方法管理成本过高，而多类统一训练又面临异常分数分布失衡与噪声注入导致的训练不稳定。RDCEL 通过引入核心样本学习与 CORAL 域适应，在统一训练与测试（UTT）设置下实现了跨类一致的异常评分。该方法在 VisA 数据集 UTT 协议下将 IAUC 从基线的 83.36 提升至 90.68，但其在标准逐类测试（PTT）协议下的绝对精度未超越 PatchCore 等 SOTA 方法，且未验证在未见类别上的泛化能力。

【ObjectCore - Efficient Few-shot Logical Anomaly Detection using Object Representations ｜对象表示驱动的少样本逻辑异常检测

作者：Matic Fučka、Vitjan Zavrtanik、Danijel Skočaj

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_12b5e8478b58)

> 工业质检中，多部件产品的逻辑异常（如部件缺失、错位）与训练样本极度稀缺的少样本场景叠加，构成了当前视觉异常检测中最具挑战性的子任务。现有少样本方法依赖全局语义对齐或像素级特征记忆，无法捕捉对象间的组合关系，而全样本逻辑异常方法又因数据需求过高难以落地。ObjectCore 将图像组合信息建模为对象表示集合，通过微调开放世界检测器提取对象特征，并利用二分匹配在测试图像与支持图像的对象表示间建立对应关系，从而在极少样本下实现逻辑异常检测。该方法在 MVTec LOCO 和 CAD-SD 上刷新了少样本逻辑异常检测的 SOTA，但其推理速度受限于匹配算法，且在纯结构异常任务上未超越专用基线，提示对象级抽象对局部纹理异常的捕捉能力存在边界。

】

【ObjectCore – Efficient Few-shot Logical Anomaly Detection using Object Representations ｜基于对象表示的少样本逻辑异常检测

研究机构：斯洛文尼亚卢布尔雅那大学

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_WACV_2026_63359307)

> 工业质检中，多部件产品的逻辑异常（如部件缺失或错位）无法通过局部纹理重建捕捉，且新品类往往仅有极少量正常样本可用。现有少样本方法依赖语义分割图或手工文本提示，缺乏对对象间细粒度交互的建模能力，且超参数难以跨类别复用。本文提出 ObjectCore，利用微调后的开放世界检测器提取对象级表示，通过双记忆库与二分匹配机制实现无类别先验的逻辑异常检测。该方法在 MVTec LOCO 和 CAD-SD 上刷新了少样本逻辑异常检测的 SOTA，但其性能高度依赖 GroundingDINO 的检测精度，且推理速度受限于匈牙利匹配算法。

【PatchEAD: Unifying Industrial Visual Prompting Frameworks for Patch-Exclusive Anomaly Detection ｜纯视觉补丁比对异常检测

作者：Po-Han Huang、Jeng-Lin Li、Po-Hsuan Huang 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2509.25856)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2509.25856)

> 工业异常检测面临新品类频繁更替导致的重训练成本与跨域泛化难题，现有基于视觉-语言模型的方法虽具备零样本能力，但视觉处理管道高度依赖特定骨干网络特性，缺乏统一性。PatchEAD 提出了一种骨干无关的纯视觉补丁比对框架，通过排除文本模态和全局特征，仅利用冻结视觉编码器提取的补丁级余弦相似度进行异常评分，实现了无需训练的少样本与批量零样本检测。该框架在 MVTec 和 VisA 等七个数据集上达到了与需训练方法相当的性能，验证了统一视觉提示管道的可行性，但其对批次内正常样本比例假设的依赖及缺乏文本语义引导的局限，限制了其在极端缺陷率场景下的适用性。

【VLMDiff: Leveraging Vision-Language Models for Multi-Class Anomaly Detection with Diffusion ｜视觉异常检测

作者：Samet Hicsonmez、Abd El Rahman Shabayek、Djamila Aouada

论文原文见 [arXiv](https://arxiv.org/abs/2511.08173)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.08173)

> 工业质检中缺陷样本稀缺且类型多样，传统单类扩散模型难以泛化至多类场景，且合成噪声引导无法覆盖细微划痕等真实缺陷。VLMDiff 利用视觉-语言模型（VLM）提取正常图像的详细文本描述，作为潜空间扩散模型（LDM）的条件信号，实现单模型多类联合训练。该方法在像素级定位上显著优于现有扩散基线，但图像级分类精度仍落后于特征嵌入类 SOTA，且推理时弃用文本条件的设计限制了其语义可解释性。

】
