> 分布外检测（Out-of-Distribution Detection, OOD）旨在识别模型训练分布之外的样本，以消除其对未见数据的高置信度错误预测。现有基准普遍存在测试集污染、规模受限及缺乏细粒度控制等问题，导致算法在真实工业场景下的鲁棒性被高估。本文切入点在于构建一个无污染的、具有明确难度梯度的大规模工业数据集，通过物理隔离采集实现 ID/OOD 的严格界定。其价值在于揭示了现有 SOTA 方法在严苛约束下的失效边界，但缺乏对生成式模型等新范式的覆盖。

## 研究背景

当深度学习模型面对开放世界中的未见数据时，往往产生高置信度的错误预测，这种过度自信现象构成了 OOD 检测研究的根本驱动力。问题的形式化定义通常基于 N-way K-shot 设定，即模型在 $N$ 个类别、每类 $K$ 个样本上训练，需区分来自这 $N$ 类（ID）与来自未知类别或分布偏移（OOD）的测试样本。数学上，给定输入 $x$，检测器需输出一个评分 $s(x)$，使得 $s(x_{ID})$ 与 $s(x_{OOD})$ 在统计上可分。这一看似简单的二分类任务，实则依赖于对数据生成过程偏移类型的精确刻画，包括语义偏移（新类别）与协变量偏移（环境变化）。

主流评测协议通常依赖 ImageNet 或 CIFAR 等通用数据集，但这些基准存在严重的 ID/OOD 重叠（如 ImageNet 中的类别污染）和规模不足问题，导致算法性能被人为抬高。近邻 OOD 检测是核心瓶颈，它依赖于特征空间几何分析的技术突破，而现有基准缺乏对近邻、远端及极端 OOD 的平滑过渡控制。本文的切入点在于利用工业物体分拣场景，通过物理隔离采集构建无污染的 ID/OOD 分层结构，从而暴露现有方法在细粒度工业场景下的真实鲁棒性。

## 核心方法

### 方法参照系

本文不属于算法改进，而是评测基准构建。其参照系为标准的 OOD 检测评测流程：训练 ID 模型，在独立 OOD 集上评估后验评分（Post-hoc Score）或模型增强（Model Enhancement）方法。关键差异在于，本文引入了基于物理采集的无污染数据源，并定义了从近邻到极端的四级 OOD 难度梯度，而非依赖通用数据集的随机划分。

### 无污染的工业数据采集协议

传统基准的 OOD 样本往往来自通用数据集的剩余类别，存在语义重叠风险。本文通过工业自由落体分拣机原型，使用 4K RGB 线扫相机以 56 µm/pixel 的分辨率采集数据，确保每个图像代表一个独立的物理对象。这种采集方式从物理层面保证了 ID 与 OOD 类别的互斥性。设计动机在于消除现有基准中“类别污染”和“偶然污染”导致的性能虚高，为算法提供纯净的评估环境。

$$
\mathcal{D}_{OOD} = \{x \mid x \notin \mathcal{D}_{ID}, \text{ and } x \text{ is physically distinct from } \mathcal{D}_{ID}\}
$$

该公式表示 OOD 数据集 $\mathcal{D}_{OOD}$ 由所有不属于 ID 数据集 $\mathcal{D}_{ID}$ 且在物理属性上与 ID 样本严格区分的样本组成，确保了分布偏移的纯粹性。

### 四级 OOD 难度梯度定义

为量化检测难度，本文将 OOD 样本划分为近邻（Near）、远端（Far）、极端（Extreme）和合成（Synthetic）四类。近邻 OOD 来自同一 Food 类别的非 ID 类，远端 OOD 来自 Non-Food 类别，极端 OOD 来自 ImageNet 等外部数据集，合成 OOD 则通过模拟传感器故障生成。设计动机在于揭示不同语义距离下检测器的性能衰减规律，特别是近邻 OOD 在特征空间中的重叠问题。

$$
s(x) = f_{det}(x; \theta_{ID})
$$

其中 $s(x)$ 为检测评分，$f_{det}$ 为后验评分函数，$\theta_{ID}$ 为在 ID 数据上训练的模型参数。该公式强调了评分函数仅依赖 ID 数据分布，而 OOD 样本的语义距离决定了 $s(x)$ 的可分性难度。

## 实验评估

实验在 ICONIC-444 的四个任务（Almond, Wheat, Kernels, Food-grade）上进行，使用 ResNet18 和 CCT 两种架构，评估了 22 种后验 OOD 检测方法。基线覆盖了评分法（MSP, GRAM, KNN）和模型增强法（ReAct, DICE, ASH），但缺失了扩散模型（如 SCOPED, EigenScore）和视觉语言模型（如 ANTS）等前沿路线。

| 方法 | Near FPR95 | Far FPR95 | Extreme FPR95 | Synthetic FPR95 |
| :--- | :--- | :--- | :--- | :--- |
| GRAM | 35.74 | 19.75 | 0.00 | 0.44 |
| ATS | 54.59 | 36.89 | 0.00 | 2.40 |
| VIM | 88.13 | 94.03 | 0.00 | 99.99 |
| MSP | 92.35 | 89.03 | 92.55 | 93.83 |

GRAM 在近邻 OOD 上的 FPR95 为 35.74%，显著优于 MSP 的 92.35%，但在极端 OOD 上两者均接近 0% 或 92.55%（MSP 在极端 OOD 上表现异常高，可能源于数据分布差异）。值得注意的是，尽管 GRAM 在平均 FPR95 上表现最佳，其在近邻 OOD 上的 FPR99 仍高达 66.27%，表明在 99% TPR 约束下，现有方法仍难以可靠区分近邻 OOD。

消融实验显示，ResNet18 在 FPR99 上的平均性能下降（14.45%）小于 CCT（19.04%），且 ResNet18 在 GRAM 方法下的 FPR99 性能是 CCT 的两倍以上。这一反直觉发现表明，在细粒度工业数据上，传统 CNN 的特征空间结构比 Transformer 更利于 OOD 检测，这与 ImageNet 基准上 Transformer 通常表现更优的共识相悖。

评估边界方面，本文引入了 FPR99 指标，强调在安全关键应用中 99% TPR 的重要性，但现有方法在该指标下普遍失效。可复现性方面，论文未提供代码 URL，但数据获取协议详细，且使用了 OpenOOD 库中的标准实现。

## 关联研究分析

从问题动机看，本文与 NINCO 等基准不同，后者旨在解决 ImageNet 的类别污染，但仍依赖通用数据集；本文则通过物理隔离采集，从根本上消除了 ID/OOD 重叠，提供了更纯净的评估环境。这一差异源于任务特性：工业分拣要求极高的可靠性，任何 ID/OOD 混淆都可能导致严重事故，因此对数据纯净度的要求远高于通用视觉任务。

从方法设计看，本文测试的 22 种方法均为后验或模型增强方法，未包含扩散模型或 VLM 方法。这与知识库中“生成式模型提供丰富分布信息”的共识形成对比。可能的原因是工业场景对实时性要求高，扩散模型推理延迟大，而 VLM 依赖文本语料，在细粒度物体分类上可能缺乏足够的语义区分度。然而，论文未提供证据支持这一假设，仅基于现有方法进行了基准测试。

## 总结

本文要解决的核心矛盾是现有 OOD 基准的污染问题与工业场景对高可靠性需求之间的冲突。本文抓住的切入点在于利用工业分拣的物理隔离特性，构建无污染的 ID/OOD 分层数据集。本文做了什么：定义了 ICONIC-444 数据集和四个基准任务，并评估了 22 种后验方法。证明了什么：GRAM 在近邻 OOD 上 FPR95 为 35.74%，但 FPR99 高达 66.27%，表明现有方法在严苛约束下仍不可靠。本文的边界在于未测试生成式模型和 VLM 方法，且仅关注后验检测。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
