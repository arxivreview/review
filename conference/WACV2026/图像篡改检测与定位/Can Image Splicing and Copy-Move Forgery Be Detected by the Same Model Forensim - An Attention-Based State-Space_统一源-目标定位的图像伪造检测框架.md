# WACV2026最新论文 ｜Can Image Splicing and Copy-Move Forgery Be Detected by the Same Model? Forensim: An Attention-Based State-Space Approach ｜统一源-目标定位的图像伪造检测框架

研究机构：美国南加州大学

作者：Soumyaroop Nandi、Prem Natarajan

论文原文见 [arXiv](https://arxiv.org/abs/2602.10079)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.10079)

> 图像操纵检测与定位（IMDL）旨在识别篡改痕迹并输出像素级掩码，但传统方法仅能定位被篡改的目标区域，无法追溯其来源，导致在复制-移动伪造（Copy-Move Forgery Detection, CMFD）等场景中取证链条断裂。现有基于二分类掩码的模型假设拼接检测技术可泛化至所有篡改类型，忽略了源区域与目标区域的空间关联这一关键取证线索。Forensim 将 IMDL 重构为三分类掩码分割任务，通过状态空间模型（State Space Model, SSM）构建显式仿射矩阵，同时输出原始、源、目标三类区域。该框架在 CMFD 基准上显著优于传统基线，但其对语义连贯的 AI 生成篡改的鲁棒性尚未得到验证。

## 研究背景

当检测器面对复制-移动伪造时，仅定位被篡改的目标区域不足以建立完整的证据链，因为源区域与目标区域往往共存于同一图像中，且源区域本身未被篡改。这种空间上的成对依赖关系要求模型具备同时识别“被篡改处”与“来源处”的能力，而传统 IMDL 任务仅关注篡改边界，将源区域视为背景噪声。解决这一问题的关键在于将检测任务从二分类（篡改/未篡改）升级为三分类（原始/源/目标），从而显式建模图像内部的重复模式。

主流 IMDL 路线依赖低级统计伪影（如噪声不一致、频域不连续）进行定位，CAT-Net 和 TruFor 等方法在拼接检测上表现良好，但无法区分自然重复与伪造重复。BusterNet 虽针对 CMFD 设计了双分支架构，但受限于 USC-ISI 数据集的低复杂度与不可用性，且无法泛化至拼接任务。Forensim 的切入点在于：通过三分类监督信号统一 CMFD 与拼接检测，并利用 SSM 的线性复杂度高效捕捉长程空间依赖，解决高分辨率图像中注意力计算的瓶颈。

## 核心方法

### 三分类掩码分割范式

传统 IMDL 流程采用二分类掩码监督，仅标记篡改区域，隐含假设“有效拼接检测技术可泛化至所有篡改类型”。本文的关键差异在于将任务重构为三分类掩码分割，即同时预测原始（Pristine）、源（Source）和目标（Target）区域。这一设计动机源于取证需求：仅定位目标区域无法追溯篡改来源，尤其在源区域与目标区域视觉相似时，二分类模型易产生误报。三分类监督提供了更细粒度的结构信号，使模型能学习源-目标的空间对应关系，而非仅依赖篡改边界的伪影线索。

### 相似性状态空间注意力模块

在特征提取阶段，传统方法使用 CNN 或 Transformer 提取局部或全局特征，但缺乏对图像内部相似性的显式建模。Forensim 引入相似性状态空间注意力（Sim Attn）模块，通过 SSM 构建显式仿射矩阵 $Aff \in \mathbb{R}^{N \times N}$，量化不同空间位置间的相似度。该模块的核心公式为：

$$Aff = \bar{C} \bar{B}^\top$$

其中 $\bar{C}$ 和 $\bar{B}$ 是经过旋转位置编码（RoPE）调制后的特征表示。这一设计的动机是：CMFD 的本质是图像内部区域的重复，而自然图像中也存在纹理重复，需通过显式相似性度量区分二者。Sim Attn 通过双向 softmax 归一化仿射矩阵，确保相似性值在空间位置间相互增强，从而突出 top-k 最相似区域，抑制背景噪声。

### 操纵性状态空间注意力与融合

Sim Attn 输出的相似性图 $Sim_{map}$ 仅反映空间重复，无法区分自然重复与伪造重复。Forensim 进一步引入操纵性状态空间注意力（MSSA）模块，通过多尺度 SSM 块捕捉篡改区域的局部结构特征。MSSA 的输出 $MSSA_{map}$ 与 $Sim_{map}$ 通过非局部细化（NLR）模块融合，其核心公式为：

$$Sim_{Mani}^{Attn} = Mani_{Attn} \otimes Sim_{Attn} \otimes Sim_{map}$$

其中 $\otimes$ 表示通道级拼接。这一设计的动机是：单一相似性特征易受自然纹理干扰，而操纵性特征提供篡改区域的局部结构线索。NLR 模块利用 $Sim_{map}$ 和 $MSSA_{map}$ 作为权重，进行非局部加权聚合，强化语义相关区域的上下文一致性，抑制无关背景信号，从而提升源-目标定位的精度。

## 实验评估

Forensim 在 USC-ISI CMFD、CoMoFoD、CASIA CMFD 及自建 CMFD-Anything 数据集上评估，基线包括 BusterNet、ManTraNet、TruFor 和 SparseViT。基线覆盖了传统 CMFD 方法与通用 IMDL 模型，但缺失 FUSED、ICL-Net 等最新 SSM/MLLM 方法，因任务定义不同（本文聚焦源-目标联合定位，而非纯篡改定位）。

| 方法 | CASIA CMFD F1 | CoMoFoD F1 | CMFD-Anything F1 |
| :--- | :--- | :--- | :--- |
| BusterNet | 33.72 | 35.34 | — |
| TruFor | 43.62 | 36.54 | — |
| SparseViT | 45.87 | 37.92 | — |
| **Forensim** | **58.12** | **47.82** | **62.4** |

Forensim 在 CASIA CMFD 上 F1 达 58.12，较 TruFor 提升 14.5 个点，表明三分类监督与 SSM 注意力机制在源-目标定位上的有效性。

| 消融条件 | 224×224 F1 | 512×512 F1 |
| :--- | :--- | :--- |
| No MGMatting | 56.6 | 61.2 |
| Binary Mask | 53.9 | 59.4 |
| Noisy Groundtruth | 53.4 | 58.4 |
| **CMFD-Anything** | **59.6** | **62.4** |

消融实验显示，移除 MGMatting 后处理、使用二分类掩码或引入噪声标注均导致性能下降，其中二分类掩码在 512×512 分辨率下 F1 从 62.4 降至 59.4，验证了三分类监督的必要性。

评估协议采用像素级与图像级指标，但缺乏置信区间报告，且 CMFD-Anything 数据集由 Segment Anything 生成，可能存在过拟合风险。代码与项目页面已公开，但超参数与 GPU 配置未在正文中详述，可复现性依赖补充材料。

## 关联研究分析

从问题动机看，Forensim 与 FUSED 均关注跨域泛化，但 FUSED 通过法医-语义混合专家架构解决全局检测与局部定位的冲突，而 Forensim 聚焦源-目标联合定位，未引入语义理解。这一差异源于任务特性：CMFD 的核心是空间重复，而非语义篡改，因此 Forensim 依赖显式仿射矩阵而非 MLLM 推理。然而，当篡改由扩散模型生成时，语义连贯性可能导致低级相似性特征失效，Forensim 在此场景下的鲁棒性未经验证。

从方法设计看，Forensim 与 BusterNet 同属 CMFD 专用模型，但 BusterNet 采用 GAN 框架，而 Forensim 使用 SSM 替代 Transformer，利用线性复杂度捕捉长程依赖。这一设计选择解决了高分辨率图像中注意力计算的瓶颈，但 SSM 的序列建模特性可能不适用于非序列化的空间结构，Forensim 通过 2D 选择性扫描缓解此问题，但未与 VMamba 等通用 SSM 方法进行直接对比，其架构优势是否源于任务特定设计而非 SSM 本身，论文未给出回答。

## 总结

Forensim 要解决的核心矛盾是传统 IMDL 方法无法追溯篡改来源，导致 CMFD 场景下取证链条断裂。其切入点在于将任务重构为三分类掩码分割，显式建模源-目标空间关联，并通过 SSM 高效捕捉长程依赖。该框架在 CASIA CMFD 上 F1 达 58.12，较 TruFor 提升 14.5 个点，验证了三分类监督的有效性。其边界在于：实验仅覆盖传统 CMFD 与拼接任务，未测试扩散模型生成的语义连贯篡改，且 CMFD-Anything 数据集的构建可能引入过拟合风险。当篡改由 AI 生成且源-目标区域语义高度连贯时，纯相似性特征是否仍能区分自然重复与伪造重复，论文未给出回答。
