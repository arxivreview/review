# WACV2026最新论文 ｜SeaClips: A Video Dataset for Maritime Object Detection. ｜海事视频目标检测数据集与基准

研究机构：奥地利维也纳技术大学

作者：Franziska Denk、Christian Rankl、Shaban Almouahed 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_8401464e8df9)

> 海事自主航行要求感知系统具备全天候鲁棒性，但现有海事数据集多为静态图像，缺乏时序连续性以应对运动模糊与遮挡。本文切入点在于构建首个大规模、多场景的海事视频数据集 SeaClips，并系统评估通用视频目标检测（VID）模型在特定海事挑战下的表现。通过引入 74 段视频与 31,606 帧标注，论文验证了时序上下文对检测精度的有限增益，揭示了当前 SOTA 模型在极端尺度与复杂光照下的失效边界。其价值在于填补了海事时序感知的数据空白，但实验结果对“时序必然提升鲁棒性”的领域共识提出了质疑。

## 研究背景

当无人水面艇（USV）在波浪起伏中航行时，单帧图像常因船体滚动产生运动模糊，导致小目标漏检。为解决此问题，视频目标检测（Video Object Detection, VID）通过聚合时间上下文信息来增强特征表示，理论上能缓解瞬时遮挡与模糊。然而，VID 模型通常依赖大规模通用视频数据预训练，直接迁移至海事场景时，因缺乏针对海面杂波、反光及特定船舶形态的时序标注数据，其泛化能力存疑。

海事视觉领域长期依赖静态图像数据集（如 SMD、LaRS），这些数据集虽覆盖多样地理场景，但无法提供帧间连续性，导致时序模型无法在真实海事环境中进行有效训练与评估。现有海事视频数据集规模极小（少于 100 段视频）且场景单一，难以支撑对主流 VID 架构的系统性基准测试。本文旨在通过构建地理多样、场景复杂的海事视频数据集，填补这一基础设施缺口，并量化时序信息在海事检测中的实际贡献。

## 核心方法

### 方法参照系

本文工作属于“数据集构建与基准测试”路线，而非算法创新。其核心流程遵循标准 VID 评估范式：定义时序上下文窗口（参考帧数 $N$ 与时间范围 $T$），在统一协议下对比图像检测器与时序检测器的性能差异。与通用 VID 基准（如 ImageNet VID）的关键差异在于，海事场景引入了极端尺度变化、水面反光及非刚性运动，要求评估协议对 IoU 阈值与类别平衡进行特定调整。

### 时序上下文建模与评估协议

针对海事场景中小目标定位困难的问题，本文采用降低 IoU 阈值至 0.3 的评估策略，以适配小目标重叠度低的特性。对于时序模型，参考帧的采样策略直接影响特征聚合的有效性。本文定义了时间范围 $T$ 与参考帧数 $N$ 的组合空间，并在训练时随机采样、测试时均匀采样以平衡增强与确定性。

$$
\text{mAP}_{ca}@0.3 = \frac{1}{|C|} \sum_{c \in C} \text{AP}_c(\text{IoU} \ge 0.3, \text{class-agnostic})
$$

该公式计算忽略类别标签的平均精度，专门评估纯边界框定位能力，从而剥离分类错误对定位性能评估的干扰，更精准地反映模型在复杂海面背景下的几何感知能力。

### 数据集构建与场景多样性

为解决现有海事视频数据地理局限性问题，本文在欧洲大西洋沿岸两个地点采集数据，覆盖晴天、阴天、雨天及波浪/平静海况。数据集包含 7 类对象（4 类船舶、2 类非船舶、1 类通用对象），其中“通用对象”类用于处理远处无法识别的目标，避免了强制分类带来的噪声。

$$
\mathcal{D} = \{ (v_i, \mathcal{A}_i) \}_{i=1}^{74}, \quad \mathcal{A}_i = \{ (b_{i,t}, y_{i,t}, m_{i,t}) \}_{t=1}^{T_i}
$$

该集合表示由 74 段视频 $v_i$ 及其帧级标注 $\mathcal{A}_i$ 组成的数据集，其中 $b_{i,t}$ 为边界框，$y_{i,t}$ 为类别，$m_{i,t}$ 为视频级属性（如反光、天气）。这种帧级密集标注与视频级属性结合的设计，使得模型不仅能学习空间特征，还能显式建模环境条件对检测性能的影响。

## 实验评估

实验在 SeaClips 数据集上进行，对比 6 种图像检测器（YOLOX-S/L/X, Deformable DETR, RT-DETR）与 3 种视频检测器（T-YOLOX-S, YOLOV++, TransVOD++）。基线覆盖了从轻量级 YOLO 到重型 Transformer 架构，但未包含领域内最新的专用海事跟踪算法（如 DMSORT），这可能高估了通用检测器的相对性能。

| 方法 | 骨干网络 | mAPca@0.3 | mAP@0.3 | Small mAP@0.3 | Large mAP@0.3 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| YOLOX-S | CSPDarknet | 51.95 ± 6.58 | 17.66 ± 1.09 | 15.93 | 21.14 |
| RT-DETR | R50-D | 45.78 ± 5.10 | 28.15 ± 3.18 | 24.98 | 52.23 |
| TransVOD++ | Swin-B | 48.12 | 28.15 | 24.98 | 52.23 |
| YOLOV++ | CSPDarknet | 41.01 | 21.74 | 19.68 | 24.42 |

*注：表格数值取自论文 Table 3 与 Table 4 的对应行，TransVOD++ 的 mAP@0.3 与 RT-DETR 相同为 28.15，但论文指出其提升不显著。*

核心发现是时序模型并未如预期般显著超越其基线模型。T-YOLOX-S 的 mAP@0.3 甚至低于其基线 YOLOX-S，而 TransVOD++ 仅比基线 Deformable DETR (Swin-B) 提升 0.67%。这表明在 SeaClips 的特定场景下，简单的时序堆叠或注意力聚合未能有效解决小目标定位难题，反而可能因引入噪声帧而降低性能。

消融实验显示，YOLOV++ 在中大物体上相比 YOLOX-S 有 +14% 至 +16% 的提升，但在小物体上增益微乎其微。这一反直觉结果暗示，时序上下文对大尺度、运动明显的目标有效，但对受水面反光干扰的小目标（如浮标）作用有限。评估边界方面，论文未报告 FPS 或 GFLOPs，无法评估 USV 边缘部署的实时性；此外，验证集缺乏“休闲车辆”类样本，导致该类评估缺失，且所有结果未提供置信区间，统计显著性检验仅在补充材料中提及。

## 关联研究分析

从问题动机看，本文与 WaSR-T 等海事时序分割方法共享“利用时序缓解反光”的假设，但本文聚焦检测而非分割。WaSR-T 通过 3D 卷积融合多帧特征，而本文评估的 YOLOV++ 采用注意力机制聚合对象级特征。差异根源在于任务特性：分割需要像素级一致性，时序融合收益明显；而检测中，小目标的边界框定位对单帧特征依赖更强，时序聚合若未精确对齐，反而可能模糊小目标的边缘信息。

从方法设计看，本文与通用 VID 基准（如 ImageNet VID 上的 TransVOD++）形成对比。在 ImageNet VID 上，TransVOD++ 取得 90%+ mAP，但在 SeaClips 上仅 28.15 mAP。这一巨大落差并非算法缺陷，而是数据分布差异：海事场景的“小目标”占比远高于通用视频，且背景杂波（波浪、反光）具有非结构化特征。通用 VID 模型在预训练阶段未充分学习此类特定干扰，导致迁移时性能骤降。这提示，海事 VID 可能需要针对海面杂波设计的专用预训练策略，而非直接复用通用权重。

## 总结

本文旨在解决海事视频检测中缺乏时序基准数据的问题，通过构建 SeaClips 数据集并系统评估主流 VID 模型，揭示了时序上下文在海事小目标检测中的局限性。实验证明，尽管 RT-DETR 等图像模型在定位精度（mAPca@0.3）上表现尚可，但时序模型 TransVOD++ 和 YOLOV++ 未能带来显著的性能提升，甚至出现负迁移。这一结果挑战了“时序必然提升鲁棒性”的领域共识，指出在复杂海面环境下，时序聚合的有效性高度依赖于目标尺度与背景干扰类型。当参考帧数 $N$ 增加时，小目标的定位精度是否因噪声累积而进一步下降，论文未给出系统性回答。
