# WACV2026最新论文 ｜MemeTAG: Keyword-Driven Meme Classification through Tag Embedding Reconstruction ｜关键词驱动的多模态表情包分类

研究机构：印度理工学院

作者：Akshit Sharma、Prashant W Patil

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_f0249c9869a8)

> 多模态仇恨表情包检测的核心难点在于图像与文本单独看均无害，组合后却产生恶意语义，现有方法依赖通用特征对齐，难以捕捉这种细微的跨模态错位。MemeTAG 的切入点是将视觉语义显式化为关键词标签，并通过辅助重构任务强制主网络学习对齐特征。该方法利用冻结的视觉语言模型生成关键词，经注意力网络聚合后作为重构目标，结合 ArcFace 分类头实现双目标优化。实验显示其在 HarMeme 等基准上超越 CLIP 基线，但性能仍低于多智能体推理框架，且未解决低资源语言下的泛化问题。

## 研究背景

当检测器面对新生成的表情包时，其训练域与测试域的数据分布出现系统性差异——这一现象称为分布偏移。分布偏移导致传统分类器决策边界失效，而实际场景中往往能获取少量目标域样本，这恰好构成了小样本学习的条件：仅凭每个类别极少量标注样本泛化到新任务。解决此类问题的经典框架是原型网络，它计算各类别支持样本的特征均值作为"原型"，再通过距离度量完成分类。

多模态仇恨表情包检测旨在从图像与文本的交互中识别隐含的恶意意图，其核心难点在于单一模态往往无法独立承载完整的仇恨语义。2020 年 Facebook 发布的仇恨表情包挑战（Hateful Memes Challenge, FHM）确立了该任务范式，揭示了单模态基线在超过 60% 样本上的失效，迫使研究重心转向深层跨模态交互。早期方法以特征拼接和门控融合为主，通过显式建模图文依赖关系来捕捉语义错位，但受限于静态参数对动态文化梗的滞后。随着大型视觉语言模型（VLMs）的成熟，领域进入生成式推理阶段，通过提示工程和多智能体辩论解析幽默与仇恨的模糊边界，用计算成本换取可解释性和鲁棒性。当前研究进一步拓展至低资源语言和细粒度目标定位，试图构建具备文化感知能力的智能体框架。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。

## 核心方法

### 多模态融合架构参照系

多模态融合架构聚焦视觉与文本特征的深层交互机制，旨在解决模态缺失或语义错位导致的检测性能瓶颈。早期工作基于“特征拼接”假设，认为图像和文本特征在共享空间中简单融合即可捕捉仇恨意图，但这一假设在 FHM 基准上表现不佳，无法处理图文反差导致的隐含仇恨。MemeTAG 延续了 CLIP-Adapter 和 MemeCLIP 的适配器融合路线，但引入了外部语义锚点，将融合过程从纯内部特征交互扩展为内部特征与外部标签的对齐。

### 关键词嵌入聚合网络

MemeTAG 首先利用冻结的 VLM 从图像生成 10 个客观关键词，避免主观假设。这些关键词通过 CLIP 文本编码器映射为嵌入向量 $E = \{e_1, ..., e_{10}\}$。Aggregated Tag Inference Network (ATIN) 采用多头自注意力机制，使用可学习查询向量 $q$ 探测关键词集合，计算上下文感知表示 $E' = \text{LayerNorm}(E + \text{MHSA}(q, E, E))$。最终通过平均池化得到聚合标签嵌入 $z_{\text{tag}} = \frac{1}{10}\sum_{i=1}^{10} e'_i$。这一设计将离散的视觉语义压缩为连续向量，为后续重构提供稳定的监督信号，解决了传统融合方法缺乏显式语义锚点的问题。

### 双目标优化与辅助重构

主网络提取 CLIP 图像与文本特征，经线性投影和模态特定适配器处理后，通过元素级乘法融合 $f = \text{Norm}(z^*_{\text{img}}) \odot \text{Norm}(z^*_{\text{txt}})$。分类头采用 ArcFace 变体，引入角边距 $m$ 增强判别力。辅助重构任务要求一个 MLP 从融合特征 $f$ 重构 $z_{\text{tag}}$，损失函数为余弦距离 $L_{\text{aux}} = 1 - \frac{z_{\text{tag}} \cdot \hat{z}_{\text{tag}}}{\|z_{\text{tag}}\|\|\hat{z}_{\text{tag}}\|}$。总损失 $L = (1-\lambda)L_{\text{cls}} + \lambda L_{\text{aux}}$ 强制主网络在分类的同时保持与视觉语义标签的对齐。这一机制弥补了纯分类损失可能忽略的细微视觉线索，提升了模型对隐含语义的捕捉能力。

## 实验评估

MemeTAG 在 PrideMM、HarMeme 和 HMC 三个基准上进行了评估，对比了 CLIP 变体、MOMENTA、HateCLIPper 等基线。基线覆盖主要聚焦于 CLIP 适配器和早期多模态模型，未包含 2026 年的多智能体框架如 GECO 或 DR-HM。

| 数据集 | 方法 | Accuracy (%) | AUROC (%) | F1-Score (%) |
| :--- | :--- | :--- | :--- | :--- |
| HarMeme | MemeTAG | 85.540 | 92.230 | 84.810 |
| HarMeme | HateCLIPper | 83.910 | 91.050 | 83.470 |
| HMC | MemeTAG | 74.10 | 82.17 | - |
| HMC | MemeCLIP | 72.69 | 81.68 | - |

在 HarMeme 上，MemeTAG 的 Accuracy 为 85.540%，较 HateCLIPper 提升 1.63 个百分点；在 HMC 上，Accuracy 为 74.10%，较 MemeCLIP 提升 1.41 个百分点。据领域综述，GECO 在 HarMeme 上的 F1-Score 为 89.11%，MemeTAG 仍落后约 4.3 个百分点，表明单模型重构在复杂推理任务上存在局限。

消融实验显示，引入辅助重构损失后，HarMeme 上的 Accuracy 从 84.419% 提升至 85.540%，AUROC 从 91.910% 提升至 92.230%。这一 1.1 个百分点的增益验证了语义对齐对分类性能的贡献，但边际收益相对有限，暗示关键词重构主要起正则化作用，而非根本性地改变语义理解机制。

评估协议采用标准的 85/5/10 划分，指标包括 Accuracy、AUROC 和 F1-Score。论文未报告置信区间，且未提供代码仓库，限制了可复现性。此外，实验未涵盖低资源语言场景，无法验证方法在数据稀缺条件下的鲁棒性。

## 关联研究分析

从方法设计看，MemeTAG 与 GatedCLIP 同属 CLIP 骨干融合路线，但 GatedCLIP 侧重通过门控机制动态加权模态贡献，而 MemeTAG 侧重通过外部标签重构强制语义对齐。GatedCLIP 在 HMC 上的 AUROC 仅为 66.00%，远低于 MemeTAG 的 82.17%，这可能源于门控机制在复杂语义错位下的表达能力不足，而关键词重构提供了更稳定的语义锚点。然而，MemeTAG 的性能仍低于 GECO 等采用多智能体辩论的方法，暗示静态重构难以替代动态推理在解析幽默与仇恨边界上的作用。

从问题动机看，MemeTAG 与 HarmTrace 均关注细粒度语义，但 HarmTrace 聚焦于攻击目标和证据定位，而 MemeTAG 聚焦于整体分类的语义对齐。HarmTrace 通过锚点校准实现精确定位，为内容审核提供可操作证据；MemeTAG 则通过关键词重构提升分类准确率，但未提供具体的审核理由。这种差异反映了领域内“可解释性”定义的分裂：前者追求结构化解释，后者追求特征层面的语义一致性。MemeTAG 的关键词生成依赖 VLM 的零样本能力，若 VLM 本身存在偏见，重构目标可能引入系统性偏差，这一风险在论文局限性部分被提及，但未通过实验量化。

## 总结

MemeTAG 试图解决多模态表情包中图文语义错位导致的检测失效问题，其切入点是将视觉语义显式化为关键词标签，并通过辅助重构任务强制主网络学习对齐特征。该方法利用冻结的 VLM 生成关键词，经 ATIN 聚合后作为重构目标，结合 ArcFace 分类头实现双目标优化。实验证明其在 HarMeme 上达到 85.540% 的 Accuracy，较 HateCLIPper 提升 1.63 个百分点，验证了语义对齐的有效性。然而，论文未报告低资源语言下的性能，且关键词生成依赖 VLM 的零样本能力，若 VLM 存在偏见，重构目标可能引入系统性偏差。当支持集增大到 5-shot 时，关键词重构的边际收益是否递减，论文未给出回答。
