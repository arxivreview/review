# WACV2026最新论文 ｜Distilling Offline Action Detection Models into Real-Time Streaming Models ｜离线动作检测模型的流式蒸馏适配

研究机构：NEC实验室

作者：Deep Patel、Yasunori Babazaki、Yasuto Nagase 等 5 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_7c616d545855)

> 时空动作检测（Spatio-Temporal Action Detection, STAD）的离线模型依赖全时空注意力，在流式场景下因滑动窗口重算导致计算冗余与高延迟。现有在线方法要么牺牲精度，要么直接复用缓存引发训练-推理失配。本文切入点是将离线教师模型的知识蒸馏至原生因果架构，通过不确定性加权的多任务损失平衡不同知识源的迁移。该方法在保持SOTA精度的同时实现了4倍以上的延迟降低，但其短窗口假设在长程依赖任务中的有效性存疑。

## 研究背景

时空动作检测要求模型在视频流中定位并分类人类动作。离线Vision Transformer（ViT）通过处理固定长度片段（clip）并利用全时空自注意力捕捉复杂依赖，但这一机制在实时流式场景中失效：每帧输入需重算重叠窗口内所有特征，导致计算量随窗口大小线性增长。为消除冗余，直接引入Key-Value（KV）缓存是自然选择，但离线模型在训练时接触的是“干净”的自包含片段，而流式推理依赖前序窗口的“陈旧”状态，这种训练-推理失配（train-inference mismatch）导致性能显著下降。

流式视频理解领域的主流路线分为两类：一类是优化现有Transformer的在线推理，如利用缓存避免重算或引入记忆模块（MemViT），但均面临上述失配问题；另一类是设计轻量级在线架构（如YOWO），虽低延迟但精度远低于离线大模型。本文的切入点在于不强行改造非因果模型，而是构建一个原生因果的学生架构，通过自监督蒸馏继承教师的时空建模能力。这一策略将“如何流式化”的问题转化为“如何高效迁移知识”的问题，规避了直接适配带来的状态不一致风险。

## 核心方法

### 方法参照系

离线到在线蒸馏（Offline-to-Online Distillation）是视频模型效率优化的标准范式，通常训练一个逐帧处理的因果学生模型去模仿拥有未来帧信息的非因果教师。本文的关键差异在于：学生架构并非简单的CNN或RNN，而是基于ViT的因果变体，且蒸馏过程采用不确定性引导的多任务学习，而非固定的损失加权。

### 因果注意力架构：TSA与DSTA

传统ViT的自注意力计算复杂度与片段长度平方成正比，无法直接用于流式推理。本文提出两种替代机制，核心设计动机是消除对重叠帧的重复计算，同时保留时空依赖建模能力。第一种是时序移位注意力（Temporal Shift Attention, TSA），受时序移位模块（TSM）启发，将注意力头的一部分通道（如1/8）沿时间维度移位。在流式推理时，当前帧 $t$ 的特征与前一帧 $t-1$ 缓存的移位通道拼接，形成时序融合表示，随后仅对当前帧的空间patch执行自注意力。其计算过程可表示为：

$$ \mathbf{x}'_t = \text{Concat}(\mathbf{x}_{t-1}^{\text{shift}}, \mathbf{x}_t^{\text{static}}) $$

其中 $\mathbf{x}_{t-1}^{\text{shift}}$ 为缓存的上一帧移位通道，$\mathbf{x}_t^{\text{static}}$ 为当前帧非移位通道。这一设计以极低的开销实现了轻量级时序融合。第二种是分解时空注意力（Decomposed Spatial-Temporal Attention, DSTA），将全时空注意力分解为帧内空间自注意力与帧间LSTM时序建模两步。LSTM隐藏状态 $h_t$ 更新公式为：

$$ h_t = \text{LSTM}(z_t^{\text{spatial}}, h_{t-1}) $$

其中 $z_t^{\text{spatial}}$ 为当前帧空间注意力输出。DSTA通过LSTM捕捉更复杂的时序动态，但引入了额外参数。两种架构均支持逐帧缓存，确保推理时仅处理当前帧，实现零冗余计算。

### 不确定性引导的知识蒸馏

单一损失函数难以平衡不同知识源的贡献，固定权重易导致训练不稳定。本文设计动机是将蒸馏建模为多任务学习问题，利用任务不确定性动态调整损失权重，避免人工调参。总损失函数定义为：

$$ \mathcal{L}_{\text{total}} = \sum_{k=1}^{K} \left( \mathcal{L}_k \exp(-\lambda_k) + \lambda_k \right) $$

其中 $K=3$，对应Logits、Attention和RoI特征三个损失项，$\lambda_k$ 为可学习的任务不确定性参数（对数方差）。该公式的物理含义是：模型自动降低高不确定性任务（如深层抽象特征）的权重，聚焦于低不确定性任务（如浅层基础特征）的对齐。实验显示，模型在训练初期更重视浅层注意力图的匹配，后期逐渐平衡，这种自适应策略比固定加权更鲁棒。

## 实验评估

实验基于AVA v2.2数据集（主基准）、AVA-Kinetics（泛化测试）和PIE（安全场景），指标为mAP@0.5和Accuracy。基线覆盖离线教师（UMT）、朴素在线滑动窗口、传统在线方法（YOWOv2）及记忆增强模型（MeMViT）。未对比最新流式LLM方法，因任务定义不同。

| 模型 | 架构 | mAP (%) | 延迟 (ms) | 吞吐量 (FPS) |
| :--- | :--- | :--- | :--- | :--- |
| DSTA-Student | ViT-L | 33.5 | 20.3 | 49 |
| TSA-Student | ViT-L | 33.2 | 12.3 | 81 |
| MeMViT-24 | - | 33.5 | 87.9 | 11 |
| YOWOv2 | - | 21.7 | 33.30 | - |

DSTA-L在AVA上达到33.5% mAP，与MeMViT持平，但延迟降低4.3倍（20.3ms vs 87.9ms）。TSA-L以12.3ms延迟实现33.2% mAP，吞吐量达81 FPS，显著优于YOWOv2的精度（21.7%）。

| 消融项 | TSA mAP (%) | DSTA mAP (%) |
| :--- | :--- | :--- |
| 无蒸馏（从头训练） | 25.0 | 16.6 |
| 仅Logits损失 | 30.1 | - |
| 全损失无不确定性加权 | 32.3 | 32.3 |
| 全损失+不确定性加权 | 33.2 | 33.5 |

蒸馏带来8.2%（TSA）和16.9%（DSTA）的mAP提升，证明知识迁移的必要性。不确定性加权比固定加权提升0.9%（TSA）和1.2%（DSTA），表明动态平衡对深层特征对齐至关重要。Per-head时序建模比全局应用提升0.5%（TSA）和4.0%（DSTA），验证了多头独立时序模式的优越性。

评估边界方面，论文未报告置信区间，数值比较需谨慎。代码未公开，但提供了详细超参数（AdamW, lr=1e-4, batch=48, 4x A6000）。PIE数据集仅870个训练片段，DSTA性能下降（65.5% vs 70.2%），暴露了LSTM在数据受限场景下的过拟合风险。

## 关联研究分析

从问题动机看，本文与MemViT均旨在解决流式视频的计算冗余，但MemViT通过外部记忆模块扩展长程上下文，而本文聚焦短窗口（8-32帧）内的效率优化。这一差异源于任务特性：AVA数据集的动作检测主要依赖局部时空上下文，长程依赖并非核心瓶颈。MemViT在长视频叙事任务中可能更具优势，但在短窗口动作检测中，其记忆模块的额外计算开销反而成为劣势。

从方法设计看，本文与TSM共享通道移位思想，但TSM应用于CNN特征图，而TSA将其扩展至Transformer注意力头，并引入缓存机制实现流式推理。TSM无法直接用于流式场景，因其缺乏状态管理机制。本文的DSTA则借鉴了RNN的时序建模能力，但将其嵌入ViT架构，解决了传统RNN在空间建模上的不足。这种混合架构在精度与效率间取得了平衡，但LSTM的引入增加了模型复杂度，在数据受限场景下表现不佳，提示了架构选择对数据规模的敏感性。

## 总结

本文要解决的核心矛盾是离线ViT的高精度与流式推理的低延迟需求之间的冲突。现有方法要么牺牲精度（YOWO），要么因训练-推理失配导致性能下降（直接缓存适配）。本文通过构建原生因果学生架构（TSA/DSTA）并采用不确定性引导的蒸馏，成功将离线教师的知识迁移至在线模型。实验证明，DSTA-L在AVA上达到33.5% mAP，延迟20.3ms，比MeMViT快4.3倍；TSA-L以12.3ms延迟实现33.2% mAP，吞吐量81 FPS。本文的边界在于短窗口假设，未验证长程依赖任务中的有效性，且DSTA在数据受限场景下性能下降。当视频片段长度超过32帧时，TSA的轻量级时序融合是否足以捕捉长程依赖，论文未给出回答。
