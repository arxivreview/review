# WACV2026最新论文 ｜Unsupervised Discovery of Long-Term Spatiotemporal Periodic Workflows in Human Activities ｜长时程时空周期工作流无监督发现

研究机构：美国卡内基梅隆大学

作者：Fan Yang、Quanting Xie、Atsunori Moteki 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.14945)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.14945)

> 长时程人体活动中的周期性工作流通常包含低对比度、多分支的复杂结构，现有短期周期检测与单周期分割方法无法同时处理边界识别与流程挖掘。本文切入点在于将周期检测与无监督工作流提取联合建模，通过时空聚类、频域分析与序列对齐实现端到端解析。核心方法是构建软/硬Token表征，利用2D FFT估计周期尺度，并通过扩展的Needleman-Wunsch算法挖掘多分支工作流。该方法在自建基准上显著优于监督基线与LLM，但其有效性依赖于特定任务结构，跨模态泛化能力存疑。

## 研究背景

当工厂流水线或运动员训练产生重复性动作时，这些动作在时空维度上形成周期性序列。然而，与简单的“跑步-休息”交替不同，长时程工作流往往包含内部变异性，即相同动作Token可能出现在周期的不同位置，且不同周期间存在细微差异。这种复杂性导致传统基于峰值检测或自相似矩阵的方法难以准确界定周期边界，因为局部信号的周期性被全局工作流的非线性结构所掩盖。

短期周期活动检测（S-PAD）与单周期活动分割（SAS）构成了该领域的两大主流路线。S-PAD方法如TransRAC和PoseRAC依赖监督学习提取高对比度特征，适用于结构简单的重复动作，但在面对长时程、低对比度的复杂工作流时，其预定义的周期假设失效，导致边界识别错误。SAS方法如ASFormer和FACT专注于将单周期序列分割为语义Token，但通常假设周期边界已知或仅需分割单一实例，无法处理多周期序列中的边界发现任务。现有研究普遍忽略了“周期检测”与“工作流挖掘”的耦合性，导致在真实场景中无法直接应用。本文旨在填补这一空白，提出一个无需人工标注、能同时解决周期边界识别与多分支工作流提取的统一框架。

## 核心方法

### 方法参照系

本文问题可视为S-PAD与SAS的交叉，但关键差异在于：S-PAD仅输出周期计数，SAS仅输出单周期分割，而本文要求从多周期序列中无监督地提取包含内部变异性的统一工作流。标准流程通常先通过监督学习提取特征，再分别进行周期检测或分割，本文则采用无训练、基于符号的表征策略，将时空特征离散化后直接进行频域分析与序列对齐。

### 时空Token化与频域周期估计

设计动机在于解决硬Token在低对比度场景下的边界模糊问题。传统方法使用1D硬Token序列进行FFT或自相关分析，但硬Token仅保留最近邻聚类中心的信息，丢失了全局时空上下文，导致周期估计噪声大。本文引入软Token，定义为帧特征到所有聚类中心的归一化距离向量，形成$K \times T$的2D矩阵。通过2D FFT并沿空间维度边缘化，放大周期性分量：

$$
Mag(f_v) = \sum_{u} |FFT(\mathbf{Y}_{soft})_{u,v}|
$$

该公式通过累加空间频率分量，增强了时间轴上的周期性信号，从而更鲁棒地估计初始周期窗口大小$w$。

### 多分支工作流序列挖掘

设计动机在于解决固定窗口分割无法适应周期长度变异及内部分支结构的问题。本文基于估计的$w$将序列分段，并引入20%缓冲以容纳时间变异。随后，采用扩展的Needleman-Wunsch算法（MTA）进行多序列对齐。MTA通过动态规划填充多维矩阵$\mathbf{F}$，其中每个单元格$\mathbf{F}[\text{pos}]$表示对齐前缀的最优得分：

$$
\mathbf{F}[\text{pos}] = \max_{\text{neighbor}} \left( \mathbf{F}[\text{neighbor}] + \text{ScoreMatch}(\text{chars}) \right)
$$

该公式通过双向遍历识别首个重复基序（inter-repetition）作为边界点，并保留分支结构以捕获内部变异性。最终，通过指针同步机制，实现周期检测、完成度跟踪与异常检测的在线处理。

## 实验评估

实验在自建580条长时程工作流数据集上进行，涵盖3D姿态、室内/室外轨迹等模态。基线包括S-PAD方法（TransRAC, PoseRAC）、SAS方法（ASFormer, FACT）及LLM（GPT-4o, Gemini-2.5 Pro）。本文方法在任务1（周期检测）中MAPE为0.025，tIoU为0.937，显著优于S-PAD基线（MAPE >0.2）和LLM（MAPE 0.030-0.038）。在任务3（异常检测）中，本文tIoU为0.423，高于监督SAS方法ASFormer（0.294）和FACT（0.312）。

| 方法 | 任务1 MAPE ↓ | 任务1 tIoU ↑ | 任务3 tIoU ↑ |
| :--- | :--- | :--- | :--- |
| TransRAC [34] | 0.443 | - | - |
| PoseRAC [94] | 0.738 | - | - |
| ASFormer [95] | - | - | 0.294 |
| FACT [57] | - | - | 0.312 |
| GPT-4o [3] | 0.038 | 0.882 | - |
| Gemini-2.5 Pro [15] | 0.030 | 0.915 | - |
| **Our Baseline** | **0.025** | **0.937** | **0.423** |

消融实验显示，软Token与20%缓冲对性能提升关键。使用硬Token时，任务1 MAPE升至0.147，tIoU降至0.854；移除缓冲后，任务3 tIoU从0.423降至0.374。这表明软Token提供的全局上下文对低对比度周期估计至关重要，而缓冲机制有效缓解了周期长度变异带来的边界误差。

评估边界方面，本文仅使用自建数据集，缺乏跨数据集泛化验证。指标MAPE和tIoU适用于周期检测，但未能量化工作流语义的准确性。代码未开源，超参数$K$（6-14）的选择依赖经验，可复现性受限。

## 关联研究分析

从问题动机看，本文与S-PAD方法（如TransRAC）的核心差异在于对“周期”定义的扩展。TransRAC假设周期具有高对比度且边界清晰，适用于跑步、跳跃等简单动作；而本文处理的是包含内部变异性的长时程工作流，如工厂组装。这种差异源于任务特性：S-PAD关注重复计数，本文关注流程结构。TransRAC在本文基准上MAPE高达0.443，表明其监督学习提取的特征无法捕捉低对比度下的复杂周期结构，而非算法缺陷。

从方法设计看，本文与SAS方法（如ASFormer）的差异在于是否显式建模周期性。ASFormer通过半监督学习分割单周期序列，假设周期边界已知；本文则通过2D FFT与MTA联合估计边界与分割。ASFormer在任务3中tIoU为0.294，低于本文的0.423，表明其缺乏周期感知能力导致异常定位偏差。本文的无训练策略避免了标注成本，但可能牺牲了对复杂语义的精细建模，这在需要语义标签的场景中可能成为瓶颈。

## 总结

本文核心矛盾在于长时程低对比度工作流中周期边界识别与多分支结构建模的耦合难题。现有S-PAD方法因高对比度假设失效，SAS方法因缺乏周期感知而边界模糊。本文通过软Token频域分析与MTA序列对齐，实现了无监督的联合建模，在自建基准上MAPE 0.025、tIoU 0.937，显著优于监督基线与LLM。其边界在于依赖特定任务结构，且未验证跨模态泛化能力。当工作流包含高度非线性的内部变异时，MTA的动态规划复杂度是否成为实时部署的瓶颈，论文未给出回答。
