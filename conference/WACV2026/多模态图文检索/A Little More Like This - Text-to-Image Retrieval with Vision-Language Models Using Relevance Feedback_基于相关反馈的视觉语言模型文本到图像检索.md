# WACV2026最新论文 ｜A Little More Like This: Text-to-Image Retrieval with Vision-Language Models Using Relevance Feedback ｜基于相关反馈的视觉语言模型文本到图像检索

作者：Bulat Khaertdinov、Mirela Popa、Nava Tintarev

论文原文见 [arXiv](https://arxiv.org/abs/2511.17255)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.17255)

> 多模态检索的核心瓶颈在于静态嵌入难以捕捉查询意图的动态变化，导致复杂场景下匹配精度受限。现有微调方案计算开销大且缺乏灵活性，而本文切入点在于利用推理时的相关反馈机制，在不修改骨干模型的前提下动态优化查询向量。具体做法是引入生成式反馈与注意力摘要器，在特征空间聚合正负样本信号以修正查询表示。该方法以极低的额外参数量实现了跨模型的性能增益，但其对反馈信号质量的依赖及多轮迭代中的漂移问题仍存疑。

## 研究背景

当用户输入模糊的自然语言查询时，视觉语言模型（VLM）生成的全局嵌入往往无法区分细微的语义差异，这种现象被称为模态间隙。模态间隙源于对比学习训练中视觉与文本特征分布的系统性偏差，导致即使语义相同，嵌入向量在空间中仍存在距离。为缓解这一问题，传统做法是微调VLM以缩小间隙，但这需要大量计算资源且难以适应实时交互场景。

多模态检索的主流路线分为训练时优化与推理时增强两类。训练时优化如CLIP和SigLIP通过大规模对比学习建立共享空间，但一旦模型固定，其检索能力便受限于预训练数据的覆盖范围。推理时增强则试图在检索过程中动态调整查询或候选项表示，但早期工作多依赖大型语言模型（LLM）进行查询重写，引入了高昂的推理延迟。本文的切入点在于借鉴经典信息检索中的相关反馈理论，将其迁移至VLM的嵌入空间，通过轻量级模块在推理时聚合反馈信号，从而在保持模型通用性的同时提升检索精度。

## 核心方法

### 方法参照系

本文问题属于推理时查询优化范畴，与传统的两阶段检索（粗排+精排）不同，其核心差异在于不改变候选集排序逻辑，而是直接修正查询向量本身。标准流程中，查询与图像通过VLM投影至共享空间后计算余弦相似度，本文在此基础上引入反馈聚合步骤，将初始检索结果作为反馈信号源，动态调整查询表示以逼近真实意图。

### 扩展Rocchio算法

传统Rocchio算法通过平均正负样本向量来更新查询，但直接应用于VLM嵌入空间时，由于模态间隙的存在，简单平均会导致查询向量偏离语义中心。本文提出两项改进：一是采用softmax加权平均，赋予高相似度候选项更高权重；二是将正负反馈均源自Top-K检索结果，其中负反馈定义为与查询相似度较低的候选项。这一设计解决了传统Rocchio在VLM中因全局嵌入模糊性导致的反馈信号噪声问题。

$$
\mathbf{z}'_q = \alpha \mathbf{z}_q + \beta \sum_{i \in C_r^+} w_{q,i}^{[p]} \mathbf{z}_i + \gamma \sum_{i \in C_r^-} w_{q,i}^{[n]} \mathbf{z}_i
$$

该公式表明，更新后的查询向量是原始查询、正反馈加权平均与负反馈加权平均的线性组合，其中权重由候选项与查询的相似度决定。

### 注意力反馈摘要器（AFS）

Rocchio算法仅处理全局嵌入，忽略了图像patch和文本token级别的细粒度信息，导致无法捕捉局部语义细节。AFS作为一个轻量级Transformer模块，通过交叉注意力机制将查询token与反馈序列中的局部特征对齐。其设计动机在于弥合全局嵌入与局部语义之间的差距，使查询向量能够反映反馈项中的具体视觉与文本细节。

$$
\mathcal{L} = \frac{1}{N_b} \sum_{j=1}^{N_b} \left( \cos(\mathbf{z}_q^{[img]}, \mathbf{z}_{q,j}^{[img]}) + \cos(\mathbf{z}_q^{[cap]}, \mathbf{z}_{q,j}^{[cap]}) \right)
$$

该损失函数迫使AFS输出的查询表示与真实图像嵌入及额外描述嵌入在余弦相似度上对齐，从而确保反馈聚合后的向量既保留视觉信息又包含文本语义。

## 实验评估

实验在Flickr30K和COCO数据集上进行，使用CLIP-ViT-B/32、CLIP-ViT-L/14、SigLIP和BLIP-2四种骨干模型。基线包括无反馈、伪相关反馈（PRF）、生成式反馈（GRF）及显式反馈。本文方法在零样本设置下评估，未与微调后的SOTA方法（如ABE-CLIP）直接对比，但展示了相对于自身基线的增益。

| 骨干模型 | 反馈策略 | Flickr30K Hits@1 | Flickr30K MRR@5 | COCO Hits@1 | COCO MRR@5 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| CLIP-ViT-B/32 | No feedback | 0.671 | 0.295 | 0.316 | 0.411 |
| CLIP-ViT-B/32 | AFS | 0.724 | 0.336 | 0.336 | 0.428 |
| CLIP-ViT-L/14 | No feedback | 0.727 | 0.347 | 0.378 | 0.470 |
| CLIP-ViT-L/14 | AFS | 0.784 | 0.373 | 0.386 | 0.475 |
| BLIP-2 | No feedback | 0.868 | 0.543 | 0.583 | 0.677 |
| BLIP-2 | AFS | 0.890 | 0.562 | 0.558 | 0.649 |

AFS在CLIP-ViT-B/32上显著提升了MRR@5，从0.295提升至0.336，缩小了与CLIP-ViT-L/14基线的差距。然而，在BLIP-2上，AFS在COCO数据集上的MRR@5从0.677下降至0.649，表明该方法在大模型上可能存在负迁移或过拟合风险。

消融实验显示，仅使用图像损失训练的AFS在Hits@1上优于联合损失，但在MRR@5上略低，说明图像嵌入对齐对排名位置的影响有限。Rocchio权重设置中，$\alpha=0.8, \beta=0.1, \gamma=0.1$ 取得了最佳平衡，等权重设置导致性能显著下降，证实了查询向量主导性的重要性。

评估协议局限于零样本设置，未报告置信区间，且缺乏与微调SOTA方法的同骨干对比。代码已开源，但AFS训练依赖H100 GPU，复现成本较高。多轮检索实验中，AFS表现出比GRF更强的鲁棒性，但PRF在多轮迭代中性能持续下降，暴露了简单反馈聚合的局限性。

## 关联研究分析

从问题动机看，本文与VISA（Ding et al., 2025）均致力于推理时优化，但VISA依赖LLM生成问答式描述进行重排，而本文直接在嵌入空间修正查询。VISA的优势在于利用LLM的推理能力澄清歧义，但引入了巨大的计算开销；本文的AFS仅含2-25M参数，推理延迟极低，更适合实时场景。这种差异源于任务特性：VISA面向复杂问答，需要深层语义理解，而本文聚焦于标准检索，强调效率与精度的平衡。

从方法设计看，本文与TTE-v2（Cui et al., 2025）均利用额外计算提升精度，但TTE-v2通过级联检索和重排序引入推理链，而本文通过反馈聚合优化查询表示。TTE-v2的推理链能够处理多跳逻辑，但延迟显著；本文的反馈机制仅依赖Top-K结果，无法捕捉长距离依赖。这种设计选择反映了论文对效率的优先考量，但也限制了其在复杂推理任务上的适用性。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文旨在解决VLM检索中静态嵌入无法动态适应查询意图的问题，切入点在于利用推理时的相关反馈机制，以轻量级模块替代昂贵的微调或LLM推理。通过扩展Rocchio算法和引入AFS，本文在零样本设置下实现了跨模型的性能增益，其中CLIP-ViT-B/32+AFS的MRR@5从0.295提升至0.336，显著缩小了与小模型与大模型间的差距。然而，实验暴露了AFS在BLIP-2+COCO上的性能下降，以及PRF在多轮迭代中的不稳定表现，表明反馈信号的质量与聚合策略对最终性能具有决定性影响。当反馈项中包含大量噪声或无关信息时，AFS的注意力机制是否能够有效过滤这些干扰，论文未给出明确验证。
