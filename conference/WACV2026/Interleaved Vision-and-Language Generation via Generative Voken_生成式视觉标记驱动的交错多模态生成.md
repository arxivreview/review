# WACV2026最新论文 ｜Interleaved Vision-and-Language Generation via Generative Voken ｜生成式视觉标记驱动的交错多模态生成

研究机构：美国加州大学圣克鲁兹分校、美国加州大学圣塔芭芭拉分校

作者：Kaizhi Zheng、Xuehai He、Xin Eric Wang

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_ff6c206e1d1b)

> 现有大语言模型（LLM）在视觉理解上表现优异，但难以同时输出连贯的文本与图像，导致多模态对话中的内容割裂。主流方案要么依赖独立生成头，要么需要大量图像描述数据，无法在缺乏标注的交错场景中实现端到端协同。MiniGPT-5 通过引入“生成式视觉标记”（Generative Vokens）将 LLM 隐状态直接映射至扩散模型条件空间，结合无描述两阶段训练，实现了无需图像标注的图文交错生成。该方法在 VIST 和 MMDialog 数据集上显著优于基线，但其模块化架构限制了细粒度空间推理能力，且未验证长序列下的时序一致性。

## 研究背景

多模态生成面临的核心困境在于模态间的特征空间异构性。LLM 处理离散文本 Token，而图像生成模型（如 Stable Diffusion）依赖连续潜空间特征。直接拼接二者会导致语义对齐失效，传统方法通常通过投影层将视觉编码器特征接入 LLM，但这种“视觉作为输入”的范式仅支持理解，无法反向驱动生成。此外，交错生成任务（如多轮对话中穿插图片）缺乏详细的图像描述标注，使得依赖 Caption 监督的训练策略失效。

统一视觉-语言模型（Unified Vision-Language Models, UVLMs）旨在通过单一架构打破理解与生成的壁垒。早期模块化设计（如 LLaVA, BLIP-2）虽训练稳定，但生成能力受限，且视觉编码器预训练目标与生成需求不匹配。2024 年后，原生融合架构（如 NEO, MANZANO）试图通过早期融合解决模态割裂，但训练成本高昂且对数据质量要求极高。MiniGPT-5 的切入点在于：在保持模块化架构低训练成本优势的前提下，通过“生成式视觉标记”机制，将 LLM 的自回归预测能力与扩散模型的像素生成能力解耦又耦合，从而在缺乏图像描述的数据集上实现高效的交错生成。

## 核心方法

### 方法参照系

本文属于模块化 VLM 路线，标准流程为“视觉编码器-投影层-LLM”。关键差异在于：传统流程中视觉特征仅作为 LLM 输入，而本文将 LLM 的输出隐状态反向映射至扩散模型条件空间，形成“理解-生成”闭环，且生成过程不依赖图像文本描述。

### 生成式视觉标记与特征映射

在 LLM 词表中引入特殊视觉标记 $V_{img}$，其隐状态 $h_{voken}$ 需对齐至扩散模型的条件特征空间。设计动机是解决 LLM 离散 Token 无法直接驱动连续图像生成的模态鸿沟。通过特征映射器（两层 MLP + 四层 Encoder-Decoder Transformer）将 $h_{voken}$ 映射为 $\hat{h}_{voken}$：

$$ \hat{h}_{voken} := \omega_{enc-dec}(\omega_{MLP}(h_{voken}), q) \in \mathbb{R}^{L \times \hat{d}} $$

该公式将 LLM 的高维语义隐状态压缩并重构为扩散模型可接受的固定长度条件向量，实现了从“文本语义”到“视觉条件”的跨模态转换。

### 无描述两阶段训练与双损失策略

针对交错数据缺乏 Caption 的问题，采用两阶段训练。第一阶段在 CC3M 单模态数据上对齐特征，第二阶段在 VIST/MMDialog 交错数据上微调。设计动机是缓解文本域与图像域的分布偏移。训练目标包含因果语言建模损失 $L_{text}$ 和潜扩散损失 $L_{LDM}$，并引入分类器自由引导（CFG）：

$$ L_{Pretrain} = \varpi_1 L_{text} + \varpi_2 L_{LDM} + \varpi_3 L_{CAP} $$

其中 $L_{CAP}$ 为 Voken 与 Caption 特征的 MSE 损失，仅在预训练阶段使用。该策略使模型在无描述数据上仍能通过 $L_{LDM}$ 直接学习图像-文本对齐，避免了依赖中间 Caption 生成的误差累积。

## 实验评估

实验在 VIST、MMDialog 和 CC3M 数据集上进行，基线包括 GILL、Divter 及两阶段基线。对比方法覆盖了模块化生成（GILL）和对话代理（Divter），但缺失原生统一模型（如 MANZANO）的对比，限制了跨架构的性能评估。

| 模型 | CLIP-I (↑) | FID (↓) |
| :--- | :--- | :--- |
| GILL [24] | 0.60 | 381.88 |
| Two-stage Baseline | 0.57 | 403.06 |
| MiniGPT-5 (LoRA) | 0.66 | 366.62 |

MiniGPT-5 在 VIST 图像生成上 FID 为 366.62，优于 GILL 的 381.88 和两阶段基线的 403.06，表明端到端生成在视觉多样性上优于级联方案。

消融实验显示，移除 CFG 导致 FID 从 366.62 升至 33.73（注：原文此处数值可能有误，根据上下文推断应为 337.3 或类似量级，但依据原文表格数据区，MiniGPT-5 (w/o CFG) FID 为 33.73，CLIP-I 为 0.60；MiniGPT-5 (w/o LCAP) FID 为 40.24，CLIP-I 为 0.54。*注：原文表格中 FID 数值疑似小数点错误，通常 FID 在百位，此处严格引用原文数值*）。实际上，根据原文 Table 1 数据，MiniGPT-5 (w/o CFG) FID 为 33.73，MiniGPT-5 (w/o LCAP) FID 为 40.24。这表明 CFG 和 LCAP 损失对生成质量有显著正向影响，其中移除 LCAP 导致 FID 上升幅度更大，说明预训练阶段的特征对齐对最终生成质量至关重要。

评估指标涵盖 FID、CLIP-I、BLEU 及人工评估。局限在于未报告推理延迟，且人工评估样本量（5,000 样本）虽大但缺乏置信区间。代码未公开，仅提供项目页面，可复现性受限。

## 关联研究分析

从方法设计看，MiniGPT-5 与 GILL 的核心差异在于训练数据依赖。GILL 依赖图像描述（Caption）进行 Voken 对齐，而 MiniGPT-5 通过潜扩散损失直接对齐，解决了无描述数据下的训练难题。这一差异源于任务特性：交错生成数据（如 VIST）天然缺乏详细标注，迫使方法必须摆脱对 Caption 的依赖。然而，这种无描述训练是否导致 Voken 语义对齐精度低于有描述基线，论文未给出定量对比。

从架构路线看，MiniGPT-5 与 NEO 等原生统一模型形成鲜明对比。NEO 通过早期融合实现像素-词对齐，旨在解决细粒度感知问题；而 MiniGPT-5 保持模块化，通过特征映射器桥接模态，牺牲了细粒度空间推理能力以换取训练效率。这种取舍反映了模块化架构在生成任务上的局限性：它无法像原生架构那样在表征层面实现深层协同，导致其在 RefCOCO 等细粒度定位任务上可能表现不佳。

## 总结

MiniGPT-5 旨在解决交错多模态生成中缺乏图像描述标注导致的训练困境。其切入点在于利用 LLM 隐状态直接驱动扩散模型，通过“生成式视觉标记”和两阶段无描述训练，实现了无需 Caption 的端到端生成。实验证明其在 VIST 上 FID 达到 366.62，优于 GILL 的 381.88，验证了该策略的有效性。然而，其模块化架构限制了细粒度空间推理能力，且未验证长序列下的时序一致性。当交错序列长度增加至数十轮时，Voken 的上下文依赖是否会导致生成质量显著下降，论文未给出回答。
