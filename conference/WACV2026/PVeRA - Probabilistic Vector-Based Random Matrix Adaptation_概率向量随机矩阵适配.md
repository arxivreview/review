# WACV2026最新论文 ｜PVeRA: Probabilistic Vector-Based Random Matrix Adaptation ｜概率向量随机矩阵适配

作者：Leo Fillioux、Enzo Ferrante、Paul-Henry Cournède 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.07703)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.07703)

> 视觉基础模型在少样本场景下微调时，确定性适配器难以量化预测的不确定性，且对特征空间中的歧义处理不足。VeRA 虽通过冻结随机矩阵大幅压缩参数，但其确定性缩放向量无法表达模型对输入的置信度分布。PVeRA 将 VeRA 的缩放向量替换为高斯分布参数，通过变分推断学习权重更新的分布而非点估计。该方法在 VTAB-1k 基准上以极低参数量实现了优于 VeRA 和 LoRA 的平均性能，并原生支持置信区间估计，但其概率推理模式带来的计算开销与 KL 正则化系数的敏感性仍未得到充分验证。

## 研究背景

当视觉基础模型（如 DINOv2）面对与预训练分布存在显著偏移的下游任务时，全参数微调因算力需求高且易过拟合而不可行。参数高效微调（PEFT）通过冻结主干网络、仅训练轻量适配器来解决这一矛盾。低秩适配（LoRA）假设权重更新具有低内在维度，通过低秩矩阵分解近似更新量；向量随机矩阵适配（VeRA）进一步将 LoRA 中的可训练矩阵替换为跨层共享的冻结随机矩阵，仅训练缩放向量，将参数量降低至 LoRA 的百分之一量级。然而，VeRA 的确定性输出无法反映模型对特定输入的预测置信度，这在医疗影像等高风险应用中构成关键缺陷。

现有 PEFT 方法在视觉少样本任务中面临两难：Bottleneck 和 AdaptFormer 等直接修改表示的适配器虽能处理域偏移，但推理时无法合并权重，带来持续的计算延迟；LoRA 和 DoRA 虽可合并，但其确定性结构无法量化不确定性。VeRA 解决了参数效率问题，但其点估计性质限制了其在歧义输入下的鲁棒性。PVeRA 的切入点在于，将低秩适配的权重更新从确定性值扩展为概率分布，通过引入变分推断机制，使适配器既能保持 VeRA 的极低参数开销，又能通过采样生成置信区间，从而在性能与不确定性量化之间取得平衡。

## 核心方法

### 方法参照系

PVeRA 建立在 VeRA 的架构之上。VeRA 在 Transformer 的 Query 和 Value 分支插入适配器，使用跨层共享的冻结随机矩阵 $A, B$ 和可训练缩放向量 $d, b$ 计算更新量 $\Delta W = \alpha B \odot d \cdot A \odot b$。本文的关键差异在于，将 VeRA 的确定性缩放向量替换为分布参数，使适配器输出变为随机变量而非固定值。

### 概率化缩放向量

VeRA 的缩放向量 $d$ 是固定参数，导致适配器对同一输入始终产生相同的权重更新，无法表达模型内部的歧义。PVeRA 将 $d$ 扩展为双参数向量，分别生成均值 $\mu$ 和标准差 $\sigma$，并通过重参数化技巧从 $\mathcal{N}(\mu, \sigma^2)$ 中采样潜变量 $z$。

$$ z = \epsilon \odot \sigma + \mu, \quad \epsilon \sim \mathcal{N}(0, I) $$

该公式的物理含义是，适配器不再输出固定的缩放系数，而是输出一个分布，每次前向传播时从该分布中采样，使得权重更新具有随机性。这种随机性为模型提供了处理特征空间歧义的归纳偏置，允许模型在训练过程中探索不同的适配路径，避免陷入确定性局部最优。

### 变分正则化与双模推理

为防止采样分布偏离标准正态先验导致训练不稳定，PVeRA 引入 KL 散度损失约束潜变量分布。

$$ \mathcal{L}_{total} = \mathcal{L}_{task} + \beta \cdot D_{KL}(\mathcal{N}(\mu, \sigma^2) \| \mathcal{N}(0, I)) $$

其中 $\beta$ 为 KL 损失缩放因子，通过网格搜索确定。该设计解决了纯变分模型中后验分布可能过度尖锐的问题，确保适配器在保持灵活性的同时不偏离预训练模型的分布中心。推理阶段支持两种模式：确定性模式直接使用 $\mu$ 作为缩放向量，权重可合并至主干，无额外延迟；概率模式通过蒙特卡洛采样生成多个预测，计算置信区间。这种双模设计使得 PVeRA 在需要高效推理的场景下退化为 VeRA，在需要不确定性量化的场景下提供概率输出。

## 实验评估

PVeRA 在 VTAB-1k 基准上进行评估，该基准包含 19 个视觉分类数据集，每个数据集仅 1000 个训练样本，旨在测试少样本学习能力。基线覆盖 Linear Probing、Bottleneck、AdaptFormer、IA、DoRA、LoRA 和 VeRA，缺失 Prompt Tuning 类方法，但覆盖了主要的低秩适配变体。

| 方法 | 平均准确率 (%) | 可训练参数量 | 推理延迟 |
| :--- | :--- | :--- | :--- |
| PVeRA | 最高 | 极低 | 可合并/采样 |
| VeRA | 次高 | 极低 | 可合并 |
| DoRA | 7 个数据集最优 | 中等 | 可合并 |
| LoRA | 中等 | 中等 | 可合并 |
| Bottleneck | 较低 | 高 | 不可合并 |

PVeRA 在整体平均性能上领先，尤其在分布偏移较大的 specialized 和 structured 数据集上表现稳定，而 DoRA 虽在 7 个自然图像数据集上最优，但整体稳定性不及 PVeRA。PVeRA 的参数量比 LoRA 低两个数量级，FLOPS 增加 15.7%，但确定性推理模式下可合并权重，无额外延迟。

消融实验显示，秩 $r=256$ 时验证损失最低，略优于 $r=128$ 和 $r=512$，表明中等秩在少样本场景下能平衡表达力与过拟合风险。位置消融证实，将适配器应用于 Query 和 Value 分支优于其他组合，与 LoRA 原论文结论一致。KL 系数 $\beta$ 的敏感性未在正文中详细报告，仅提及通过网格搜索确定，这可能影响不同数据集间的泛化性。

评估边界方面，实验仅覆盖分类任务，未涉及分割或检测等密集预测任务；概率推理模式的计算开销未量化，仅说明其用于置信区间估计；代码已开源，但 $\beta$ 的搜索范围与收敛性分析缺失，限制了复现时的超参数选择指导。

## 关联研究分析

从问题动机看，PVeRA 与 DoRA 均旨在提升 LoRA 的适配能力，但路径截然不同。DoRA 通过解耦幅值与方向更新，优化权重更新的几何结构以提升确定性性能；PVeRA 则通过概率化权重更新，引入不确定性量化能力。这一差异源于任务需求：DoRA 关注性能上限，PVeRA 关注预测可靠性。在医疗影像等高风险场景中，PVeRA 的置信区间输出具有直接应用价值，而 DoRA 的确定性输出无法提供此类信息。然而，PVeRA 的概率推理模式需要多次前向传播，其计算开销在实时性要求高的场景中是否可接受，论文未给出量化数据。

从方法设计看，PVeRA 与 VeRA 同属随机矩阵适配路线，但 VeRA 的冻结随机矩阵是确定性初始化，PVeRA 在此基础上引入变分推断。与 ProbVLM 相比，PVeRA 的适配器应用于所有 Transformer 层的 Query 和 Value 分支，而 ProbVLM 仅作用于最后一层且限于多模态任务。PVeRA 的设计更通用，但 ProbVLM 的最后一层适配可能更专注于最终决策的不确定性，而 PVeRA 的全层适配可能引入更多噪声。查询侧增强在数据充足时是否仍有增益，论文未给出回答，这暗示 PVeRA 的优势可能主要局限于少样本场景。

## 总结

PVeRA 解决的核心矛盾是视觉基础模型在少样本微调中性能与不确定性量化的不可兼得。现有确定性适配器如 VeRA 虽参数高效，但无法表达预测置信度；概率模型如 BNN 虽能量化不确定性，但计算开销巨大。PVeRA 通过变分推断改造 VeRA 的缩放向量，以极低参数开销实现了性能提升与不确定性量化的兼容。实验证明，PVeRA 在 VTAB-1k 上以比 LoRA 低两个数量级的参数量取得了最高平均准确率，并原生支持置信区间估计。其边界在于，概率推理模式的计算开销未量化，KL 系数 $\beta$ 的敏感性分析缺失，且实验仅覆盖分类任务。当支持集增大到 5-shot 时，概率化适配的边际收益是否递减，论文未给出回答。
