【Structured Context Learning for Generic Event Boundary Detection ｜结构化上下文学习用于通用事件边界检测

研究机构：中国科学院大学、中国科学院

作者：Xin Gu、Congcong Li、Xinyao Wang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.00475)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.00475)

> 通用事件边界检测（Generic Event Boundary Detection, GEBD）旨在无分类学约束下定位视频中人类感知的事件切分点，其核心难点在于长序列下的计算冗余与边界模糊性。现有逐帧独立处理或全局自注意力方法分别陷入计算浪费与二次复杂度瓶颈，无法兼顾效率与精度。本文提出结构化上下文学习（SCL），通过结构化序列划分（SPoS）机制实现线性复杂度的局部上下文共享，并辅以分组相似度与高斯软标签优化。该方法在效率与精度间取得显著平衡，但其固定窗口设计对长程依赖的捕捉能力存疑。
