# WACV2026最新论文 ｜Efficient Vision Transformers via Token Merging with Head-wise Attention Correction ｜基于头特异性注意力修正的Token合并方法

研究机构：日本东京科学大学

作者：Yuki Ichikawa、Masato Motomura、Thiem Van Chu 等 4 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_35ca7cbb7b11)

> 视觉Transformer（ViT）在高分辨率输入下因自注意力机制的二次方复杂度导致计算量激增，Token合并（ToMe）通过减少序列长度缓解此问题，但标准比例注意力机制未能完全消除合并引发的注意力分布失真。本文指出比例注意力仅补偿合并Token对其他Token的影响，忽略了合并Token自身自注意力分数变化导致的系统性偏差，且该偏差随注意力头投影权重特性显著变化。通过双线性形式分析揭示失真与头特异性统计量的关联，提出头特异性注意力修正（Head-wise Attention Correction, HAC）方法，动态调整注意力分数以恢复原始平衡。该方法在理论上填补了ToMe精度保持的机制空白，但缺乏与主流压缩方法的定量对比，实际部署收益尚待验证。

## 研究背景

ViT将图像分割为固定大小的块并线性投影为Token序列，利用自注意力机制建模长程依赖。当输入分辨率提高时，Token数量$N$激增，自注意力计算复杂度呈$O(N^2)$增长，成为边缘设备部署的主要瓶颈。为降低计算量，Token合并操作将相似Token融合，缩短序列长度，但合并过程改变了Token间的交互关系，导致注意力分布发生偏移。

Token合并路线的核心挑战在于精度保持。现有方法如ToMe采用比例注意力机制，通过缩放合并Token的权重来补偿其对其他Token的影响，但这一机制存在根本性缺陷：它忽略了合并Token自身自注意力分数的变化。由于Softmax归一化的存在，自注意力分数的微小变化会强制重新分配所有其他Token的注意力权重，引入不可忽略的失真。这种失真并非均匀分布，而是强烈依赖于每个注意力头的查询-键投影权重特性，使得“一刀切”的比例注意力机制无法有效应对。本文切入点在于揭示这种头特异性失真的数学本质，并设计针对性的修正机制，以在保持计算效率的同时恢复注意力分布的原始平衡。

## 核心方法

### 方法参照系

本文问题置于Token压缩路线下的精度保持子问题。标准ToMe流程包含Token合并与比例注意力补偿两个步骤，其中比例注意力通过缩放因子$s$调整合并Token的权重，公式为$Attn^{(h)} = \text{Softmax}(\frac{Q^{(h)}K^{(h)T}}{\sqrt{D_h}} + \log s)V^{(h)}$。本文的关键差异在于指出该补偿机制仅处理了合并Token作为“值”提供者时的权重失衡，未处理其作为“查询”接收者时的自注意力分数变化，导致注意力分布的二次失真。

### 注意力失真的双线性形式分析

比例注意力机制的失效源于对合并Token自注意力分数变化的忽视。当Token $B$ 和 $C$ 合并为 $D$ 时，$D$ 的自注意力分数$Q_D K_D^T$与原始$B, C$的自注意力分数存在偏差，该偏差通过Softmax归一化影响所有其他Token的权重分配。本文通过双线性形式分析量化这一失真，定义注意力失真$D^{(h)}_{src \to dst}$为合并前后注意力分数的差值：

$$
D^{(h)}_{src \to dst} = Q^{(h)}_{src} K^{(h)}_{dst} - Q^{(h)}_{merged} K^{(h)}_{dst}
$$

该公式的物理含义是衡量源Token与目标Token在合并前后的交互强度变化。进一步推导表明，失真的期望值可分解为均值项与协方差项，其中协方差项$\text{tr}(C_{AB}^T W)$由Token间的交叉协方差矩阵$C_{AB}$与投影权重矩阵$W$的迹决定。这一分析揭示了失真的头特异性：不同头的$W$矩阵迹不同，导致失真方向与幅度存在显著差异，验证了比例注意力机制的不足。

### 头特异性注意力修正（HAC）

基于上述分析，HAC方法在比例注意力基础上引入头特异性修正项$\Delta^{(h)}$，直接调整注意力分数以补偿自注意力变化。修正后的注意力分数矩阵为：

$$
A^{(h)}_{corr} = Q^{(h)}K^{(h)T} + \Delta^{(h)} + \log s
$$

其中$\Delta^{(h)}$根据头$W$矩阵的迹与协方差结构动态计算，旨在抵消合并导致的自注意力分数偏差。这一设计解决了比例注意力机制在头特异性失真下的失效问题，通过精确补偿每个头的注意力分数变化，恢复了合并前的注意力分布平衡。HAC无需额外训练，仅依赖预训练模型的投影权重与校准集统计量，实现了计算效率与精度的平衡。

## 实验评估

实验在ImageNet-1K分类任务上进行，基线覆盖ToMe与比例注意力机制，但缺失结构化剪枝（如Elastic ViTs）及量化方法（如FTerViT）的直接对比。论文未提供具体Top-1准确率数值表格，仅定性描述HAC改善了效率-性能权衡，因此无法与领域SOTA（如Jumbo Token 86.1%、APT 84.2%）进行定量对比。

消融实验验证了头特异性修正的有效性：当$W$矩阵迹为正时，注意力失真呈负值，HAC通过正向修正恢复平衡；当迹为负时，失真呈正值，HAC通过负向修正恢复平衡。这一结果证实了双线性形式分析的预测，表明HAC的修正方向与幅度与头特异性统计量高度相关。然而，论文未报告HAC与比例注意力机制在相同计算预算下的精度差异，也未分析HAC在不同分辨率输入下的性能变化，限制了对其实际部署价值的评估。

评估边界方面，论文仅使用ImageNet-1K分类任务，未覆盖密集预测任务（如语义分割、目标检测），无法验证HAC在保留空间细节方面的能力。可复现性方面，论文提供代码URL（https://github.com/ychikawa/HAC-ToMe），但未详细报告超参数设置与GPU配置，可能影响结果复现。

## 关联研究分析

从问题动机看，HAC与DynamicViT同属动态Token操作路线，但DynamicViT侧重通过剪枝减少Token数量，而HAC侧重通过修正恢复合并后的注意力平衡。这一差异源于任务特性：剪枝不可逆地丢弃信息，需依赖重要性评估；合并保留信息但引入失真，需依赖注意力机制分析。HAC的修正机制是否适用于剪枝场景，论文未给出回答。

从方法设计看，HAC与Elastic ViTs同属后训练压缩路线，但Elastic ViTs通过移除冗余结构实现压缩，HAC通过修正注意力分数实现精度保持。这一差异源于压缩目标：Elastic ViTs关注参数冗余消除，HAC关注计算冗余消除后的精度恢复。HAC的修正项是否可集成到Elastic ViTs的剪枝流程中，以同时实现结构压缩与注意力平衡，论文未探索。

## 总结

本文要解决的核心矛盾是Token合并引发的注意力失真与计算效率的平衡。现有比例注意力机制因忽略头特异性自注意力变化而失效，本文通过双线性形式分析揭示失真与投影权重迹的关联，提出HAC方法动态修正注意力分数。实验验证了HAC在理论上恢复注意力平衡的有效性，但缺乏与主流压缩方法的定量对比，实际部署收益尚待验证。本文的边界在于仅关注分类任务，未覆盖密集预测场景，且修正机制依赖校准集统计量，泛化性受限。当输入分布发生偏移时，HAC的修正项是否仍能准确补偿注意力失真，论文未给出回答。
