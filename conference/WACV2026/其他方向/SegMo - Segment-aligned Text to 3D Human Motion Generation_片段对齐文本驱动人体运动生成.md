# WACV2026最新论文 ｜SegMo: Segment-aligned Text to 3D Human Motion Generation ｜片段对齐文本驱动人体运动生成

研究机构：英国谢菲尔德大学、英国格拉斯哥大学

作者：Bowen Dang、Lin Wu、Xiaohang Yang 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.21237)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.21237)

> 文本驱动人体运动生成（Text-to-Motion Generation, T2M）旨在从自然语言描述合成逼真、物理合理且语义一致的人体运动序列，其核心价值在于缓解动作捕捉数据标注成本高企与具身智能对高自由度动作生成需求之间的张力。现有主流方法通常将整段文本与完整运动序列进行全局对齐，这种序列级映射忽略了模态内部的时序结构，导致生成动作出现缺失、重复或顺序错误。本文提出 SegMo，通过大语言模型（Large Language Model, LLM）解析文本短语并均匀分割运动序列，在共享嵌入空间实施片段级对比学习，以原子单元对齐替代全局对齐。该方法在不依赖语言-运动预训练模型的情况下，显著提升了语义对齐精度，但均匀分割策略在复杂动作边界捕捉上存在固有局限。

## 研究背景

理解本文需厘清离散自回归范式中的量化机制与对齐粒度。残差向量量化变分自编码器（Residual Vector Quantized Variational Autoencoder, RVQ-VAE）将连续运动序列映射为离散 Token 序列，其中基础 Token 捕捉粗粒度动态，残差 Token 补充高频细节。在生成阶段，掩码 Transformer 通过迭代预测被遮蔽的基础 Token 来重建运动。然而，传统方法仅将整句文本的 CLIP 特征作为条件输入，这种全局对齐无法区分文本中“先走三步”与“后跳跃”的时序对应关系，导致模型难以精确控制特定时间片段内的动作细节。

T2M 领域长期存在细粒度语义对齐不足的瓶颈。早期扩散模型虽提升了保真度，但在复杂语义结构上表现乏力；离散自回归模型虽增强了组合性，却因单向依赖累积误差。现有工作如 CoMo 利用 LLM 生成身体部位描述，GraphMotion 构建语义图，但均未在生成过程中引入显式的片段级时空约束。SegMo 的切入点在于借鉴事件分割理论，将连续运动流分解为语义连贯的原子事件，通过缩小对齐单元至片段级，解决全局对齐导致的内部结构忽略问题，从而在离散自回归框架内实现更精准的文本-运动对应。

## 核心方法

### 离散自回归生成参照系

SegMo 基于 MoMask 架构，采用 RVQ-VAE 编码运动，掩码 Transformer 生成基础 Token，残差 Transformer 生成残差 Token。与标准流程的关键差异在于，本文在掩码 Transformer 的输入端引入了文本片段 Token，并增加了片段级对比对齐损失，将对齐粒度从序列级细化至片段级。

### 片段提取与对齐机制

在掩码 Transformer 输入中，通常仅包含全局文本 Token $T$ 和被遮蔽的基础 Token $\hat{\mathbf{x}}^{[0]}$。SegMo 引入 LLM 将文本分解为 $A$ 个时序短语，并采用均匀分割策略将运动 Token 均分为 $A$ 段。对齐模块通过对比学习强制第 $i$ 个文本片段 $\mathbf{t}_i$ 与对应运动片段 $\mathbf{m}_i$ 在嵌入空间中靠近，同时远离其他片段。该设计动机在于解决全局对齐无法捕捉局部时序依赖导致的动作错位问题。对齐损失定义为：

$$ \mathcal{L}_{align} = -\frac{1}{B} \sum_{i=1}^{B} \frac{1}{A} \sum_{j=1}^{A} \log \frac{\exp(\text{sim}(\mathbf{t}_{i,j}, \mathbf{m}_{i,j}) / \tau)}{\sum_{k=1}^{A} \exp(\text{sim}(\mathbf{t}_{i,j}, \mathbf{m}_{i,k}) / \tau)} $$

其中 $\text{sim}$ 为余弦相似度，$\tau$ 为温度参数。该公式确保样本内配对片段相似度最大化，避免跨样本语义干扰。总损失结合掩码重建损失 $\mathcal{L}_{mask}$ 与对齐损失，权重 $\lambda_{align}$ 在 HumanML3D 上设为 1.0，KIT-ML 上设为 0.1。

### 检索任务扩展

基于片段级共享嵌入空间，SegMo 自然支持运动定位（Motion Grounding）与运动-文本检索。给定查询文本片段 $\mathbf{t}_q$，通过滑动窗口计算其与候选运动片段 $\mathbf{m}$ 的相似度，取最大值定位动作区间：

$$ \mathbf{m}^* = \arg \max_{\mathbf{m} \in \mathcal{M}} \text{sim}(\mathbf{t}_q, \mathbf{m}) $$

这一机制将生成任务中的对齐能力转化为检索能力，无需额外训练即可实现细粒度动作定位，弥补了传统生成模型缺乏可解释性定位功能的缺陷。

## 实验评估

实验在 HumanML3D 和 KIT-ML 数据集上进行，对比了 T2M-GPT、MDM、MLD、LAMP 等离散与连续模型。基线覆盖较全，但缺失 Flow Matching 类最新方法。在 HumanML3D 测试集上，SegMo 的 R-Precision Top-1 达到 0.553，优于基线 MoMask 的 0.521，接近 SOTA 方法 LAMP 的 0.557；FID 为 0.042，略优于 MoMask 的 0.045，但高于 LAMP 的 0.032。MM-Dist 从 MoMask 的 2.958 降至 2.782，表明语义对齐显著改善。

| 方法 | R-Precision Top-1 | FID | MM-Dist | Diversity |
| :--- | :--- | :--- | :--- | :--- |
| Real | 0.511±.003 | 0.002±.000 | 2.974±.008 | 9.503±.065 |
| MoMask (Baseline) | 0.521±.002 | 0.045±.002 | 2.958±.008 | – |
| SegMo (Ours) | 0.553±0.003 | 0.042±0.002 | 2.782±0.008 | 9.632±0.079 |
| LAMP | 0.557±.003 | 0.032±.002 | 2.759±.007 | 9.571±.069 |

消融实验显示，均匀分割策略优于 CPD 和聚类分割，其分割误差方差最低，带来最稳定的训练性能。对齐模块中，样本内片段对齐（Token Align）优于批级对齐（Batch-Level Align）和全局对齐（Global Align），R-Precision Top-1 从 0.546 提升至 0.553，FID 从 0.056 降至 0.042。这表明细粒度样本内对齐比跨样本对比更能捕捉局部语义对应。

评估协议遵循 T2M 标准，报告 95% 置信区间。局限在于未报告计算效率指标（如 AITS），且均匀分割假设动作时长均匀分布，可能不适用于时长差异巨大的复杂动作。代码未公开，但训练细节（如 A100 GPU、温度 0.1）完整披露，可复现性中等。

## 关联研究分析

从问题动机看，SegMo 与 CoMo 均利用 LLM 增强文本理解，但 CoMo 聚焦于生成身体部位特定描述以提升可控性，而 SegMo 聚焦于时序片段对齐以提升语义一致性。CoMo 的改进源于对空间维度（身体部位）的细化，SegMo 的改进源于对时间维度（动作片段）的细化。两者差异反映了 T2M 中空间控制与时间对齐是两个独立的优化维度，SegMo 未探索空间维度的片段对齐，这可能限制了其在复杂全身动作生成中的表现。

从方法设计看，SegMo 与 MotionCLIP 均采用对比学习，但 MotionCLIP 在序列级对齐运动与 CLIP 空间，SegMo 在片段级对齐文本与运动。MotionCLIP 的优势在于利用大规模预训练视觉-语言先验，SegMo 的优势在于无需预训练模型即可实现细粒度对齐。SegMo 的均匀分割策略与 MotionCLIP 的全局对齐形成对比，前者牺牲了边界精确性换取训练稳定性，后者牺牲了局部细节换取全局语义丰富性。这种取舍表明，在数据规模有限时，稳定的片段对齐可能比复杂的边界检测更有效，但边界精确性对长序列生成的影响尚不明确。

## 总结

SegMo 旨在解决 T2M 中序列级对齐导致的细粒度语义缺失问题，通过 LLM 文本分解与均匀运动分割，在共享嵌入空间实施片段级对比学习。该方法在 HumanML3D 上实现了 R-Precision Top-1 0.553 和 FID 0.042，优于基线 MoMask 并接近 LAMP，证明了片段对齐的有效性。其边界在于均匀分割假设动作时长均匀，无法精确捕捉复杂动作的非均匀边界，且未验证长序列生成中的累积误差。当动作时长分布高度偏斜时，均匀分割导致的片段-动作错位是否会抵消对齐收益，论文未给出回答。
