# WACV2026最新论文 ｜LVM-Lite: Training Large Vision Models with Efficient Sequential Modeling ｜大视觉模型的高效两阶段训练

研究机构：美国约翰斯·霍普金斯大学

作者：Xianhang Li、Hongru Zhu、Sucheng Ren 等 9 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_dc2a44fff713)

> 大视觉模型（Large Vision Models, LVMs）在大规模视觉序列上进行自回归预训练时，因随机拼接图像导致的二次方注意力计算开销，使得训练成本极高且难以普及。现有方法将单张无关图像强行拼接为长序列，不仅浪费算力，还引入了大量预测噪声。本文通过解耦单图预训练与序列微调，将注意力复杂度从 $O(N^2S^2)$ 降至 $O(S^2)$，实现了最高 2.7 倍的训练加速。该策略在生成任务上保持了竞争力，但在理解任务上仍显著落后于专用模型，其通用性边界尚待明确。

## 研究背景

当视觉模型试图模仿大语言模型（LLMs）的上下文学习能力时，必须处理由离散视觉 Token 构成的长序列。然而，视觉 Token 的语义连贯性远低于自然语言，若将多张无关图像直接拼接，自注意力机制需计算所有 Token 对之间的依赖关系，导致计算量随序列长度平方增长。这种冗余计算不仅消耗大量 GPU 资源，还因图像间缺乏逻辑关联而增加了下一 Token 预测的噪声，使得模型难以从随机序列中提取有效的视觉规律。

LVM 系列模型确立了通过大规模视觉序列自回归预训练来实现通用视觉理解与生成的范式，但其训练过程高度依赖将 16 张随机图像拼接为 4096 长度的序列。这种设计导致训练算力主要消耗在单图数据集的冗余序列处理上，而非真正有意义的视觉动态建模。尽管 LVM 在生成任务上表现优异，但其高昂的训练成本限制了研究者的可及性，且随机序列中的噪声可能削弱模型对细粒度视觉结构的捕捉能力。

LVM-Lite 的切入点在于识别出“随机图像序列”与“自然视觉序列”在信息密度与计算效率上的本质差异。通过剖析 LVM 的训练瓶颈，作者发现单图预训练阶段占据了绝大部分算力，且该阶段的序列结构对模型最终性能的影响可通过后续的序列微调进行补偿。这一观察为解耦训练流程提供了理论依据，旨在以更低成本实现同等规模的视觉序列建模能力。

## 核心方法

### 方法参照系

LVM 的标准训练流程采用统一的自回归目标，将 $N$ 张图像拼接为长度为 $L=N \times S$ 的序列，其中 $S$ 为单图 Token 数。模型通过预测序列中每个 Token 的概率分布来学习视觉分布，其注意力计算复杂度为 $O(L^2)$。本文的关键差异在于打破这种统一序列假设，将训练过程拆分为两个具有不同序列长度和计算复杂度的阶段，以消除随机拼接带来的计算冗余。

### 单图预训练阶段

设计动机在于解决随机图像序列中因图像间无关性导致的注意力计算浪费。在标准 LVM 训练中，16 张随机图像形成 4096 长度的序列，注意力需遍历所有 Token 对。LVM-Lite 将预训练阶段限制在单张图像内，将图像数量 $N$ 从 16 降至 1，序列长度 $L$ 从 4096 降至 256。此时，模型仅利用同一图像内的前序 Token 预测下一 Token，注意力复杂度从 $O(N^2S^2)$ 降至 $O(S^2)$。

$$
\mathcal{L}_{pre} = -\sum_{m=1}^{S-1} \log p(z_{q_{m+1}} | z_{q_{1:m}})
$$

该公式表明，预训练损失仅计算单图内部 Token 的自回归概率，彻底消除了跨图像边界的注意力计算。对于 3B 参数模型，此改动将前向传播 FLOPs 从 33 TFLOPs 降至 1.7 TFLOPs，实现了 19.4 倍的单步计算加速。通过保持总训练 Token 数不变，模型在低算力下完成了基础视觉特征的提取，为后续阶段奠定了高效的参数初始化基础。

### 序列微调阶段

承接单图预训练获得的视觉特征表示，微调阶段引入具有语义连贯性的视觉序列，以恢复模型对长程依赖和时序动态的建模能力。该阶段使用三类数据：自然序列（视频帧）、判别序列（图像-标注对）和生成序列（标注-图像对），序列长度恢复至 4096。

$$
\mathcal{L}_{fine} = -\sum_{m=1}^{L-1} \log p(z_{q_{m+1}} | z_{q_{1:m}})
$$

与预训练阶段不同，此处的自回归损失作用于完整的 4096 长度序列，允许模型学习跨图像或跨帧的上下文关系。通过仅使用 96B Token（约为预训练阶段的 1/3）进行微调，模型在保留单图高效特征提取能力的同时，获得了处理复杂视觉任务所需的序列建模能力。这种“先简后繁”的策略避免了在噪声较大的随机序列上进行高成本训练，实现了训练效率与模型能力的平衡。

## 关联研究分析

从问题动机看，LVM-Lite 与 InfiniteVL 等高效 VLM 架构研究存在本质差异。InfiniteVL 通过线性注意力解决推理阶段的长序列内存爆炸问题，而 LVM-Lite 聚焦于训练阶段的计算冗余。两者均针对 Transformer 的二次方复杂度，但 LVM-Lite 通过数据组织方式的改变（单图 vs 序列）而非架构修改来降低复杂度，这是一种更轻量但可能牺牲长程依赖建模能力的策略。LVM-Lite 的单图预训练假设视觉特征可在短序列内充分学习，这与 InfiniteVL 认为长序列对视觉理解至关重要的共识相悖，暗示单图预训练可能在处理复杂场景时存在信息丢失。

从方法设计看，LVM-Lite 与 BARD 等推理加速策略不同，后者通过并行解码优化推理延迟，而 LVM-Lite 通过解耦训练优化训练成本。LVM-Lite 的两阶段策略类似于 NLP 中的课程学习，但应用于视觉领域时，其有效性依赖于视觉序列的内在结构。与 Q-Zoom 等 Token 压缩方法相比，LVM-Lite 未改变模型架构，而是改变了训练数据的呈现方式，这使得其改进更易于集成到现有 LVM 框架中，但可能无法解决推理阶段的效率问题。LVM-Lite 在理解任务上的表现（mIOU 0.7）远低于专用模型，表明其通用性在判别任务上仍受限，这与 Q-Zoom 在文档理解上的高精度形成对比，暗示单图预训练可能不足以支撑细粒度视觉理解。

## 总结

LVM-Lite 旨在解决 LVM 训练中因随机图像序列导致的计算冗余与噪声问题。通过解耦单图预训练与序列微调，该策略将注意力复杂度从 $O(N^2S^2)$ 降至 $O(S^2)$，实现了 2.1 至 2.7 倍的训练加速，并在图像生成任务上超越了 LVM-7B。然而，实验显示其在语义分割等理解任务上的 mIOU 仅为 0.7，远低于专用模型，暴露了单图预训练在细粒度视觉理解上的局限。当模型规模进一步扩大或任务复杂度增加时，单图预训练是否仍能保持生成质量的提升，而不会加剧理解任务的性能衰退，论文未给出回答。
