# WACV2026最新论文 ｜MarineEval: Assessing the Marine Intelligence of Vision-Language Models ｜海洋视觉语言模型评估基准

研究机构：德国卡尔斯鲁厄理工学院、香港科技大学

作者：YuK-Kwan Wong、Tuan-An To、Jipeng Zhang 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2512.21126)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2512.21126)

> 通用视觉语言模型在垂直领域的可靠性验证长期缺乏针对性基准，现有通用数据集无法反映海洋场景的分布偏移与专业知识需求。MarineEval 通过构建包含 2,000 个人工验证问答对的多任务基准，引入视觉必要性测试与领域专家双重过滤机制，系统量化了 17 个前沿模型在海洋智能上的能力边界。该工作揭示了模型规模与领域性能的非线性关系，但开放式问答依赖 LLM 判定的评估协议引入了新的不确定性，其结论的普适性仍受限于单一垂直领域。

## 研究背景

当视觉语言模型（Vision-Language Model, VLM）从通用场景迁移至海洋垂直领域时，其性能骤降并非源于单纯的视觉识别错误，而是由分布偏移（Distribution Shift）与领域知识缺失共同导致。分布偏移指训练数据与测试数据在统计特性上的系统性差异，海洋图像特有的低对比度、运动模糊及色彩衰减加剧了这一现象。同时，海洋生物分类学、IUCN 保护状态等专业知识在通用语料中极度稀疏，导致模型在缺乏视觉证据时倾向于依赖语言先验（Language Prior），即利用文本统计规律而非视觉内容生成答案，从而产生严重的幻觉。

现有通用基准如 MMBench 和 CREPE 侧重于组合性推理与细粒度感知，但未能覆盖垂直领域的特定任务需求，如种群密度估算与生态关系总结。这些基准的评估协议往往假设模型具备通用的视觉-语言对齐能力，却忽视了领域专家对“视觉必要性”的严格定义——即答案必须严格依赖图像内容而非文本线索。MarineEval 的切入点在于构建一个领域感知的评估框架，通过剔除可仅凭文本回答的样本，并引入领域专家验证，确保基准能够真实反映 VLM 在海洋科学中的“专家级”理解能力，而非通用常识的泛化。

## 核心方法

### 评估范式参照系

垂直领域 VLM 评估通常沿用通用基准的多任务问答框架，但关键差异在于数据构建的领域特异性与评估协议的客观性。通用流程往往依赖 Likert 量表或简单匹配，而 MarineEval 采用二元判定（Binary Judgement）策略，将模型输出严格分类为正确或错误，以消除主观评分的波动，确保跨模型比较的稳定性。

### 视觉必要性过滤机制

针对语言先验导致的知识泄漏问题，MarineEval 在数据构建阶段引入自动化的视觉必要性测试。该机制将候选问答对中的图像移除，仅保留文本输入，并送入 5 个闭源 VLM（Claude-3.7Sonnet-Vision, Gemini-2.0-Flash-Vision, Grok-2Vision, GPT-4o-Vision, Qwen-VL-Plus）进行推理。若任一模型能在无视觉输入的情况下给出正确答案，该样本即被判定为存在数据泄漏并予以剔除。这一设计直接对抗了通用基准中常见的“文本捷径”问题，确保最终保留的 2,000 个样本必须依赖视觉证据才能解答。其核心逻辑可形式化为：

$$
\mathcal{D}_{final} = \{ (q, a, v) \in \mathcal{D}_{raw} \mid \forall m \in \mathcal{M}_{test}, f_m(q, \emptyset) \neq a \}
$$

其中 $\mathcal{D}_{raw}$ 为原始候选集，$\mathcal{M}_{test}$ 为测试模型集合，$f_m$ 表示模型在无视觉输入 $\emptyset$ 下的预测函数。该公式确保了基准对视觉理解的纯粹性，避免了模型通过记忆文本模式而非理解图像内容得分。

### 多格式二元评估协议

为覆盖从简单判断到复杂推理的完整能力谱，MarineEval 设计了五种问题格式，并针对每种格式定制了客观的二元评估指标。对于定位任务，模型需输出 COCO 格式的边界框 $(x, y, w, h)$，评估采用交并比（Intersection-over-Union, IoU）阈值判定：

$$
\text{Acc}_{loc} = \mathbb{1}[\text{IoU}(\hat{b}, b_{gt}) > 0.3]
$$

其中 $\hat{b}$ 为预测框，$b_{gt}$ 为真值框，$\mathbb{1}[\cdot]$ 为指示函数。该设计将连续的定位误差离散化为二元结果，解决了传统 IoU 评分在跨模型比较中的尺度不一致问题。对于开放式问答，由于语义等价性难以通过字符串匹配捕捉，MarineEval 引入 3 个 LLM（GPT-4o-mini, Grok-3mini, DeepSeek-chat）作为自动评判器，基于领域专家总结的关键点（Key Points）进行缺失内容与冗余内容的双向匹配，从而在保持客观性的同时实现了大规模评估的可扩展性。

## 实验评估

实验在 MarineEval 基准上对 12 个开源 VLM（参数量 1.8B-38B）和 5 个闭源 VLM 进行了评估。基线覆盖了 Flamingo、BLIP-2、LLaVA 系列及 GPT-4o 等主流架构，但缺乏针对对比预训练（Contrastive Pretraining）专用模型的对比，这可能限制了对其组合性缺陷根源的深入分析。

| 问题格式 | 有视觉输入准确率 (%) | 无视觉输入准确率 (%) | 随机猜测基线 (%) |
| :--- | :--- | :--- | :--- |
| Yes-No | 62.24 | 42.66 | 50.00 |
| Multiple-Choice | 43.28 | 19.00 | 23.77 |
| Localization | 01.27 | 00.00 | - |
| Closed-form | 20.85 | 04.34 | - |
| Summarization | 12.67 | 00.00 | - |
| **Total** | **35.84** | **13.83** | **-** |

数据表明，视觉输入对性能有显著提升，但整体准确率仅为 35.84%，远低于通用基准上的表现。定位任务准确率仅为 1.27%，揭示了 VLM 在细粒度空间几何理解上的严重缺陷。值得注意的是，InternVL2.5（4B）在多个维度上超越了参数量更大的模型，证实了模型规模并非领域性能的可靠预测器，架构选择与训练策略在领域监督稀缺时更为关键。

评估协议的主要局限在于开放式问答依赖 LLM 判定。虽然使用了 3 个 LLM 进行交叉验证，但论文未报告 LLM 评判与人工评判的一致性指标（如 Cohen's Kappa），也未量化 LLM 自身的偏见对最终准确率的影响。此外，实验仅在 6 张 RTX 4090 D 上运行开源模型，闭源模型通过 API 调用，这种混合评估方式可能引入推理延迟与输出格式的细微差异，影响结果的严格可比性。

## 关联研究分析

从问题动机看，MarineEval 与 CREPE 均关注 VLM 的细粒度理解缺陷，但 CREPE 侧重于通用场景下的组合性检索，而 MarineEval 聚焦于垂直领域的知识整合与视觉必要性。CREPE 揭示了模型规模与组合性能力无关，MarineEval 则在海洋领域进一步验证了这一结论，并指出领域知识缺失是性能瓶颈的另一主要来源。两者的差异根源在于任务特性：通用组合性测试可依赖视觉-语言对齐的通用能力，而海洋物种识别需要特定的分类学知识，这超出了通用预训练语料的覆盖范围。

从方法设计看，MarineEval 的视觉必要性测试与 VLind-Bench 的语言先验测量思路一致，但 VLind-Bench 通过构造图文冲突对来量化偏差，而 MarineEval 通过剔除无图可答样本来预防偏差。这种预防式过滤比事后量化更为严格，但也可能导致基准样本分布偏向“高视觉依赖”任务，从而高估模型在真实海洋场景中处理模糊或低信息量图像的能力。LLM 辅助评估的设计与 VisionArena 的众包偏好评估不同，前者追求客观的二元判定，后者捕捉主观的用户偏好，两者在评估“可靠性”与“可用性”之间做出了不同的取舍。

## 总结

MarineEval 旨在解决通用 VLM 在海洋垂直领域评估中缺乏针对性基准与客观协议的核心矛盾。通过引入视觉必要性过滤与领域专家验证，该工作构建了一个能够区分“统计捷径”与“真实视觉理解”的评估体系。实验结果显示，最佳模型准确率仅为 49.58%，且定位任务表现极差，证实了现有 VLM 在细粒度空间推理与领域知识整合上的显著局限。然而，该基准的边界在于其开放式评估依赖 LLM 判定，且未量化评估器自身的偏差，这可能导致对模型真实能力的系统性误判。当 LLM 评判器在海洋专业术语的理解上存在盲区时，MarineEval 报告的准确率是否仍能准确反映 VLM 的领域智能，论文未给出回答。
