# WACV2026最新论文 ｜Anatomy-VLM: A Fine-grained Vision-Language Model for Medical Interpretation ｜解剖感知视觉语言模型

研究机构：美国罗格斯大学、美国斯坦福大学

作者：Difei Gu、Yunhe Gao、Mu Zhou 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2511.08402)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2511.08402)

> 医学影像诊断的核心矛盾在于，全局对比学习将整张胸片压缩为单一向量，导致“肺实变”等术语在上下叶间的语义混淆，且无法区分心脏扩大与肺水肿等共病。现有方法如MedKLIP虽引入知识增强，但仍依赖隐式区域划分，缺乏显式的空间定位能力。Anatomy-VLM通过引入可学习的解剖查询（Anatomy Queries）与目标检测模块，将图像显式分割为29个临床区域，实现区域-文本的细粒度对齐。该方法在长尾分布下显著提升了零样本分类的平衡准确率，但其依赖预计算边界框的设定限制了其在无标注场景下的泛化潜力。

## 研究背景

临床放射科医生的诊断流程并非直接匹配图像与报告，而是遵循“定位解剖结构-评估区域特征-整合临床知识”的多步推理链条。这一过程要求模型具备视觉接地（Visual Grounding）能力，即能够将文本描述映射到具体的空间坐标。然而，主流视觉-语言预训练（Vision-Language Pre-training, VLP）模型如CLIP和BiomedCLIP采用全局对齐策略，将整张图像嵌入为单一特征向量。这种“整体主义”假设在病灶稀疏或存在多器官共病时失效，例如“实变”一词可能指代上叶或下叶，全局特征无法区分这种空间歧义，导致诊断混淆。

细粒度对齐是解决上述问题的关键，但现有方法存在两种局限：一是基于固定网格的划分（如RGRG），缺乏临床解剖学依据；二是基于交叉注意力的隐式对齐（如CARZero），虽能捕捉局部特征但缺乏显式的空间坐标输出，难以支撑下游分割任务。Anatomy-VLM的切入点在于模拟人类专家的“检测-对齐”工作流，通过显式的目标检测模块定位解剖结构，并在该空间锚点上执行对比学习。这不仅解决了语义歧义问题，还通过提供边界框（Bounding Box）实现了可解释性，使模型预测具备空间证据。

## 核心方法

### 多模态对齐参照系

标准VLP范式通过InfoNCE损失对齐全局图像特征与文本嵌入，假设全局语义足以捕捉诊断信息。本文的关键差异在于将对齐粒度从“图像-文本”细化为“解剖区域-文本片段”，并引入显式的空间检测模块作为对齐的前置条件，而非仅依赖特征空间的隐式匹配。

### 解剖区域检测与查询机制

设计动机在于解决全局特征中非诊断背景主导的问题。Anatomy-VLM在Vision Transformer骨干中引入$M$个可学习的解剖查询向量$A \in \{a^k\}_{k=1}^M$，这些查询作为空间锚点，通过自注意力机制与图像Patch Token交互。检测过程采用集合预测（Set-Prediction）形式，结合GIoU和L1损失监督边界框回归：

$$ \mathcal{L}_{anat} = \sum_{k=1}^M (\text{GIoU}(\hat{b}^k, b^k) + \alpha \| \hat{b}^k - b^k \|_1) $$

该公式确保每个查询准确定位其对应的解剖区域，如右肺上叶或心包，从而将图像显式分割为具有临床意义的子区域，为后续的区域级对齐提供空间基础。

### 区域-文本细粒度对齐

承接检测模块输出的区域特征，本文实施解剖级对比学习。首先，将每个区域的边界框Token与全局Patch池化特征拼接，形成富含上下文的区域表示$\hat{o}$。随后，通过InfoNCE损失将$\hat{o}$与对应的临床短语嵌入$\hat{p}$对齐：

$$ \mathcal{L}_{fine} = -\frac{1}{TB} \sum_{i=1}^T \sum_{j=1}^B \log \frac{\exp(\hat{o}_i^T \hat{p}_{i,j} / \tau)}{\sum_{k=1}^{TB} \exp(\hat{o}_i^T \hat{p}_{k,j} / \tau)} $$

其中$T$为解剖区域数，$B$为批大小。这一设计强制模型在特定解剖区域内建立视觉特征与文本描述的精确对应，例如将“右肺下叶”的视觉特征与“实变”文本绑定，同时抑制与“左肺”或“心脏”描述的关联，从而消除全局对齐中的知识混淆。

## 实验评估

实验在Chest ImaGenome（2D胸片，240k样本）上进行，基线覆盖CLIP、BiomedCLIP、BioViL、MedKLIP及CARZero。值得注意的是，基线中缺失3D专用模型（如CT-CLIP），且未包含基于LLM增强的最新方法（如PhenoLIP），这可能低估了知识增强路线的竞争力。

| 方法 | BMAC (%) | AUC (%) | F1 (%) |
| :--- | :--- | :--- | :--- |
| CLIP | 50.5 | 50.5 | 11.0 |
| BiomedCLIP | 52.4 | 52.4 | 8.0 |
| MedKLIP | 51.4 | 55.7 | 14.8 |
| CARZero | 65.8 | 85.3 | 30.8 |
| **Anatomy-VLM** | **68.7** | **81.2** | **34.2** |

在分布内数据上，Anatomy-VLM的BMAC（68.7%）和F1（34.2%）均优于所有基线，尤其是相比MedKLIP（F1 14.8%）有显著提升，表明细粒度对齐在长尾分布下更有效。尽管CARZero的AUC（85.3%）更高，但论文指出AUC在类别不平衡时易受大量真负样本影响，BMAC更能反映临床实际。

| 组件 | AUC (%) | mAP |
| :--- | :--- | :--- |
| Global Only | 0.82 | – |
| Global + Detect | 0.90 | 0.73 |
| Global + Detect + Fine | 0.91 | 0.76 |

消融实验显示，仅添加检测模块（Global + Detect）即可将AUC从0.82提升至0.90，而进一步添加细粒度对齐（Fine）仅带来0.01的AUC增益但提升了mAP至0.76。这表明空间定位本身对分类性能贡献巨大，而文本细粒度对齐主要优化了定位精度而非分类判别力。

评估边界方面，论文未报告置信区间，且仅在2D胸片上验证，未测试3D CT数据。代码未公开，但提供了详细的训练阶段（三阶段：检测-全局-全损失）和超参数（AdamW, 40 epochs），可复现性中等。

## 关联研究分析

从方法设计看，Anatomy-VLM与MedKLIP均引入医学知识，但MedKLIP依赖实体级隐式对齐，而本文通过显式检测模块生成边界框，实现了从“语义匹配”到“空间定位”的跨越。这一差异源于任务目标的不同：MedKLIP侧重特征表示的质量，而本文侧重可解释性与下游分割能力。然而，本文依赖Chest ImaGenome预计算的29个标准边界框，这种强监督设定在真实临床场景中可能难以获取，限制了其无监督泛化能力。

从问题动机看，与fVLM（3D CT）相比，Anatomy-VLM将区域对齐从3D体积迁移至2D平面，并引入了检测模块。fVLM依赖解剖分割掩码，而本文使用可学习查询，降低了数据依赖。但本文未验证该框架在3D数据上的有效性，且其检测模块仅针对胸片设计，是否适用于腹部或脑部CT等复杂解剖结构，论文未给出回答。

## 总结

Anatomy-VLM旨在解决全局VLP在医学影像中因空间歧义导致的诊断混淆问题。其核心创新在于引入可学习的解剖查询与目标检测模块，将对比学习从图像级细化至解剖区域级，从而在长尾分布下实现了更鲁棒的零样本分类。实验表明，该方法在Chest ImaGenome上取得了68.7%的BMAC，显著优于BiomedCLIP等全局对齐基线。然而，其性能高度依赖预计算的解剖边界框，且仅在2D胸片上验证，未探索3D体积数据或无标注场景下的适应性。当解剖结构边界模糊或存在严重病变变形时，检测模块的定位精度是否会成为瓶颈，进而影响下游分类性能，仍是该框架面临的具体挑战。
