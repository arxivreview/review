# WACV2026最新论文 ｜OW-Rep: Open World Object Detection with Instance Representation Learning ｜开放世界检测中的实例表征学习

研究机构：韩国科学技术院、美国卡内基梅隆大学

作者：Sunoh Lee、Minsik Jeon、Jihong Min 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2409.16073)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2409.16073)

> 开放世界目标检测（OWOD）旨在让检测器识别训练集未标注的未知物体，但现有方法仅关注“是否物体”的二分类，忽略了物体间细粒度的语义关联，导致下游跟踪与类发现任务失效。本文切入点在于利用视觉基础模型（VFM）的像素级特征，通过蒸馏弥补检测器在未知物体表征上的语义空洞。具体做法是引入未知框精化模块与嵌入迁移模块，联合优化定位精度与嵌入质量。该方法在泛化性上显著优于自监督基线，但其对VFM推理开销的依赖及在线学习能力的缺失仍存疑。

## 研究背景

开放世界检测面临的核心困境是“未知”的双重性：既包括训练集中出现但无标注的“已知-未知”（known-unknown），也包括部署时完全未见的“未知-未知”（unknown-unknown）。检测器需在不依赖类别标签的情况下，不仅定位这些物体，还需生成能反映其语义属性的特征向量，以便在特征空间中进行聚类或匹配。若特征缺乏语义区分度，基于相似度的关联算法（如跟踪中的帧间匹配）将失效，因为不同类别的未知物体会被错误地视为同一类。

主流OWOD路线如PROB和OW-DETR通过能量函数或物体性分数识别未知物体，但其特征空间往往粗糙，无法捕捉细粒度关系。部分研究尝试通过自监督对比学习（如RNCDL、UC-OWOD）优化嵌入，但这些方法依赖检测器自身的预测框作为正负样本对。由于OWOD检测器在未知物体上的定位误差大且误检率高，基于噪声预测框构建的对比信号会引入大量错误的正负样本，导致特征空间坍缩或泛化性差。本文的切入点在于引入外部强监督信号：利用SAM的高质量掩码修正未知框定位，利用DINOv2的像素级特征蒸馏语义相似度，从而摆脱对检测器自身低质量预测的依赖。

## 核心方法

### 方法参照系

本文基于PROB检测器架构，该架构采用Deformable DETR骨干，通过匈牙利匹配处理已知类别，并通过物体性分数识别未知类别。与标准OWOD流程的关键差异在于，本文不将检测器查询嵌入直接作为最终实例特征，而是将其视为待优化的中间表示，通过两个训练时模块进行精化与蒸馏，推理时丢弃这些模块，仅保留优化后的检测器权重。

### 未知框精化模块

传统OWOD方法直接使用检测器预测的未知框进行后续处理，但预测框往往偏移或包含大量背景，导致基于框裁剪的特征提取引入噪声。本文引入未知框精化模块（URM），利用SAM生成的高精度实例掩码作为伪真值，修正检测器的回归头。具体而言，选取物体性分数最高的前 $k=10$ 个未知提案，将其框作为提示输入SAM，生成精化后的框 $\mathbf{b}_{u,i}^{SAM}$。仅保留与原始框IoU大于阈值 $\kappa$ 的精化框，并使用广义IoU（GIoU）损失训练回归头：

$$ \mathcal{L}_{b,unk} = \frac{1}{|U|} \sum_{i \in U} (1 - \text{GIoU}(\mathbf{b}_{u,i}, \mathbf{b}_{u,i}^{SAM})) $$

该设计通过外部掩码监督，显著降低了未知物体的定位误差，为后续特征提取提供了更纯净的感兴趣区域，解决了自监督方法因框不准导致的特征污染问题。

### 嵌入迁移模块

自监督对比学习通常使用二元标签（同类为正，异类为负），这种硬约束无法捕捉物体间程度的差异，且易受误检干扰。本文提出嵌入迁移模块（ETM），利用DINOv2的像素级特征计算实例间的连续语义相似度，作为松弛对比损失的权重。首先，对DINOv2特征在精化框内进行平均池化，得到源嵌入 $\mathbf{s}_i$。计算源嵌入间的相似度 $w_{ij}$ 作为高斯核权重：

$$ w_{ij} = \exp\left(-\frac{\|\mathbf{s}_i - \mathbf{s}_j\|^2}{2\sigma^2}\right) $$

随后，使用松弛对比损失优化检测器的实例嵌入 $\mathbf{z}_i$：

$$ \mathcal{L}_{et} = \sum_{i,j} w_{ij} \left[ \log\left(1 + \sum_{k \neq i} e^{-\|\mathbf{z}_i - \mathbf{z}_k\|^2 / \delta}\right) \right] $$

该公式中，$w_{ij}$ 动态调整了样本间排斥与吸引的力度：语义相似的样本被更强烈地拉近，语义相异的被更强烈地推远。相比二元标签，这种连续权重机制使特征空间能更细腻地反映语义结构，提升了嵌入对“未知-未知”物体的泛化能力。

## 实验评估

实验在MSCOCO和Pascal VOC的OWOD split及新提出的Unknown-Unknown split上进行。基线包括PROB、OSODD、UC-OWOD和RNCDL，覆盖了自监督对比学习的主要变体，但缺乏基于CLIP等视觉-语言模型的强基线对比。

| 方法 | Task 1 Unknown Recall | Task 1 Recall@1 | Task 4 Known mAP |
| :--- | :--- | :--- | :--- |
| PROB | 18.84 | 4.42 | 31.72 |
| RNCDL | 18.93 | 1.41 | 31.49 |
| Ours | 30.56 | 11.69 | 31.46 |

在OWOD split中，本文方法在Task 1的Unknown Recall达到30.56，较PROB的18.84提升11.72个点；Recall@1从4.42提升至11.69，表明嵌入质量显著改善。已知类别mAP保持在31.46左右，未出现明显遗忘。

| 方法 | Task 1 Unknown Recall | Task 1 Recall@1 |
| :--- | :--- | :--- |
| PROB | 21.04 | 3.32 |
| RNCDL | 21.91 | 1.72 |
| Ours | 37.27 | 11.21 |

在更严苛的Unknown-Unknown split中，本文方法优势扩大：Unknown Recall达37.27，Recall@1达11.21，而RNCDL的Recall@1仅为1.72。消融实验显示，URM主要提升Unknown Recall（如Task 1从18.84升至30.79），ETM主要提升Recall@1（从4.42升至7.25），两者结合达到最优。

评估边界方面，论文未报告推理延迟，而SAM和DINOv2均为大型模型，训练时的计算开销巨大。此外，Recall@1指标依赖于检测器成功检测出物体，若检测失败则无法计算嵌入，因此该指标可能高估实际嵌入质量。代码已开源，但超参数如 $\kappa=0.5$ 的敏感性未充分探讨。

## 关联研究分析

从问题动机看，本文与RNCDL等自监督方法的核心差异在于监督信号的来源。RNCDL依赖检测器自身的预测框构建正负样本对，其假设是“检测器预测的框足够准确以反映语义关系”，但在OWOD场景中，未知物体的预测框噪声极大，导致聚类结果混乱，Recall@1极低。本文通过引入SAM和DINOv2，将监督信号从“检测器内部”转移到“外部基础模型”，打破了这一假设。这种差异源于任务特性：OWOD的未知物体缺乏标签，检测器自身无法提供可靠的语义锚点，必须依赖外部先验。

从方法设计看，本文与基于CLIP的开放词汇检测（如GroundingDINO）存在路线分歧。后者通过文本-图像对齐实现开放词汇，依赖文本提示；本文则通过像素级特征蒸馏，不依赖文本，而是直接学习视觉语义结构。这意味着本文方法更适合无文本提示的纯视觉场景，如机器人自主探索。然而，像素级蒸馏是否足以替代文本对齐以支持细粒度属性理解（如“红色的狗”），论文未给出回答。此外，本文未与OW-DETR等SOTA OWOD方法进行直接精度对比，仅聚焦于嵌入质量，这可能掩盖了其在检测精度上的潜在劣势。

## 总结

本文要解决的核心矛盾是OWOD中未知物体定位不准与嵌入语义贫乏的耦合问题。现有自监督方法因依赖低质量预测框而失效，本文凭借VFM的外部强监督，通过URM修正定位、ETM蒸馏语义，实现了定位与表征的联合优化。实验证明，在Unknown-Unknown split上，本文Recall@1达11.21，远超RNCDL的1.72，验证了泛化性优势。然而，本文的边界在于训练时对SAM和DINOv2的强依赖，导致训练成本高昂，且未探索推理时的轻量化或在线学习机制。当支持集增大或场景复杂度提升时，VFM蒸馏的边际收益是否递减，论文未给出回答。
