# WACV2026最新论文 ｜Trajectory Tactics: When Transformers Learn Exploration to Generate Online Signature ｜基于决策Transformer与Q学习的在线签名生成框架

研究机构：印度理工学院

作者：Anurag Pandey、Aditya Nigam、Arnav Bhavsar 等 7 人

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_8cfeb40bef1b)

> 在线签名验证系统面临数据稀缺与机器生成伪造的双重威胁，传统生成模型难以兼顾长程时序依赖与用户特定风格保真。现有强化学习（RL）方法受限于样本效率低与训练不稳定，无法有效捕捉数百至数千点轨迹中的微观动态。本文提出一种三阶段混合架构，利用决策Transformer（DT）重构序列预测任务，并引入Q学习仲裁器筛选高保真变体。该框架在DeepSignDB上实现了优于GPT与扩散模型的分布一致性，但缺乏生成数据对验证系统端到端性能提升的闭环验证。

## 研究背景

在线签名验证依赖动态轨迹中的压力、速度与笔尖坐标，其核心难点在于区分熟练伪造与真迹的微观动力学差异。当真实签名数据因隐私敏感而稀缺时，合成数据生成成为增强系统鲁棒性的关键路径。然而，传统生成模型如变分自编码器（VAE）与生成对抗网络（GAN）往往陷入模式坍塌，难以复现个体书写的长程时序一致性。

签名轨迹长度从数百点延伸至数千点，传统循环神经网络（RNN）在处理此类长序列时面临梯度消失问题，导致长程依赖建模失效。强化学习虽将签名生成建模为马尔可夫决策过程（MDP），但基于策略梯度的在线交互训练效率低下，且稀疏奖励信号导致收敛不稳定。现有基于GPT的自回归生成方法虽能处理长序列，但其通用语言模型架构缺乏针对手写运动学的结构约束，导致生成轨迹在Y轴方向出现剧烈波动，分布偏差显著。

本文切入点在于将强化学习问题重构为序列预测任务，规避价值函数估计与策略梯度优化的不稳定性。通过引入决策Transformer处理长程依赖，并结合Q学习仲裁器进行用户特定风格筛选，该框架旨在解决传统RL方法在样本效率与风格保真度之间的权衡困境，为数据稀缺场景下的高保真签名合成提供新路径。

## 核心方法

### 方法参照系

在线签名生成的标准流程通常采用端到端生成模型（如GAN或扩散模型）直接映射噪声到轨迹，或基于模仿学习（IL）复制专家动作。本文问题与该通用流程的关键差异在于：不直接学习状态到动作的映射，而是将RL轨迹生成作为中间表示，通过序列建模重构生成过程，并引入后处理仲裁机制以解决用户特定风格的个性化需求。

### 决策Transformer序列建模

传统RL方法依赖价值函数估计未来奖励，导致训练不稳定。本文采用决策Transformer（DT）将RL问题转化为自回归序列预测，输入为状态-动作-回报三元组序列 $\tau = \{(s_1, a_1, r_1), ..., (s_t, a_t, r_t)\}$。DT通过因果掩码Transformer编码历史轨迹，预测下一动作 $a_t = f(h_t)$，其中 $h_t$ 为隐藏状态。损失函数采用5步均方误差（MSE）：

$$ L_{distmse} = \sum_{t=2}^{K-2} \sum_{i=-2}^{2} ||a_{t+i} - \hat{a}_{t+i}||^2 $$

该公式通过最小化预测动作与真实动作在时间窗口内的偏差，确保生成轨迹的平滑性与时序连贯性，克服了RNN在长序列上的梯度消失问题。

### Q学习顺序仲裁器

DT生成的多个候选轨迹中，部分可能偏离用户特定风格。顺序仲裁器（SAB）基于Q学习动态筛选高保真变体。SAB维护Q表，行对应时间步，列对应候选轨迹点，Q值更新遵循贝尔曼方程：

$$ Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha [r_t + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t)] $$

该机制通过迭代优化累积奖励，动态选择最符合用户书写习惯的轨迹点，解决了DT在用户特定风格保持上的不足，实现了从通用笔画模式到个性化高保真签名的过渡。

## 实验评估

实验在DeepSignDB数据集上进行，涵盖中文、英文与荷兰文签名，对比基线包括GAN、GPT、扩散模型与GAIL。本文方法在KLD指标上显著优于所有基线，尤其在Y轴方向分布一致性上表现突出。

| 方法 | KLD (X) | KLD (Y) |
| :--- | :--- | :--- |
| GAN Network | 0.0814 | 0.0765 |
| Transformer (GPT) | 0.0445 | 0.0563 |
| Diffusion Network | 0.0336 | 0.0412 |
| GAIL | 0.0223 | 0.0319 |
| Proposed Approach | 0.0121 | 0.0196 |

消融实验验证了SAB模块的关键作用。移除SAB后，TD3+DT的KLD从0.0069（X）/0.0112（Y）上升至0.0312（X）/0.0343（Y），表明SAB在风格筛选中贡献了约78%的分布一致性提升。

| 配置 | KLD (X, NF=5) | KLD (Y, NF=5) |
| :--- | :--- | :--- |
| TD3+DT With SAB | 0.0069 | 0.0112 |
| TD3+DT Without SAB | 0.0312 | 0.0343 |

评估边界方面，论文未报告生成数据对验证系统EER的端到端影响，仅评估生成保真度。代码与超参数未公开，可复现性受限。KLD指标虽能反映分布一致性，但无法直接映射到验证系统的抗伪造能力。

## 关联研究分析

从问题动机看，本文与DeepWriteSYN同属合成数据生成路线，但DeepWriteSYN基于VAE与Sigma-Lognormal模型分解，侧重静态分布匹配；本文采用RL+DT架构，强调动态轨迹的时序建模。差异根源在于任务特性：DeepWriteSYN处理短序列静态特征，而本文应对长程动态依赖，DT的自注意力机制在此场景下更具优势。

从方法设计看，本文与GAIL同属模仿学习范畴，但GAIL通过对抗训练直接复制专家策略，存在策略漂移问题；本文通过DT序列预测与SAB仲裁解耦生成与筛选，规避了策略漂移。然而，SAB的Q学习更新依赖内部一致性评分，未引入真实用户反馈，其在长尾风格分布下的泛化能力存疑。

## 总结

本文核心矛盾在于数据稀缺与机器伪造对抗下的高保真签名生成需求。现有RL方法因样本效率低与训练不稳定难以捕捉长程依赖，本文通过DT序列预测与SAB仲裁解决了这一瓶颈。实验显示，该方法在DeepSignDB上KLD X=0.0121，Y=0.0196，显著优于GPT与扩散模型。边界在于缺乏生成数据对验证系统EER的闭环验证，SAB的Q学习更新未引入真实用户反馈。当支持集增大到长尾风格分布时，SAB的内部一致性评分是否仍能准确筛选高保真变体，论文未给出回答。
