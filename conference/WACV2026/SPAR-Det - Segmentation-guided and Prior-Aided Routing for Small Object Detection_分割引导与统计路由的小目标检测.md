# WACV2026最新论文 ｜SPAR-Det: Segmentation-guided and Prior-Aided Routing for Small Object Detection ｜分割引导与统计路由的小目标检测

作者：Seungchan Kwon、Gyuil Lim、Youngjoon Han

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_d9b40cf0ff15)

> 小目标检测的核心困境在于深层特征图中目标像素占比极低，导致传统基于IoU阈值的正样本分配失效，进而引发梯度稀疏与定位漂移。现有方法多聚焦于频域增强或Transformer注意力优化，但忽略了分割网络在像素级边界保留上的天然优势。SPAR-Det通过引入并行分割骨干生成注意力权重，并结合基于RoI统计特征的混合专家路由，在AI-TOD上取得31.2 AP。该框架验证了分割先验对弱特征表示的补偿作用，但其依赖冻结的分割骨干，跨域泛化能力存疑。

## 研究背景

小目标检测中，目标在特征图上的响应区域往往仅占据数个像素，这使得基于RoI Align的正样本选择机制面临根本性挑战。当目标尺寸小于32×32像素时，其对应的特征区域难以满足0.5的IoU阈值，导致大量潜在正样本被排除，损失函数接收到的梯度信号微弱。这种“标签分配失效”直接削弱了检测器对微小目标的定位能力，而分割模型通过像素级监督保留了更丰富的边界与形状信息，为缓解这一问题提供了潜在路径。

主流小目标检测路线分为多尺度特征融合与频域增强两类。前者如FPN及其变体试图通过空间尺度对齐保留浅层细节，但受限于卷积的低通滤波特性，高频边缘信息在多次下采样后严重衰减；后者如DFIR-DETR、FSDC-DETR通过小波或傅里叶变换显式恢复频谱成分，提升了极小目标的信噪比。然而，这些方法均依赖单一检测骨干的特征提取能力，未充分利用分割网络在前景-背景判别上的优势。SPAR-Det的切入点在于将分割骨干从辅助分支提升为核心特征源，通过跨注意力机制将像素级边界信息注入检测流，同时引入基于统计特征的MoE路由以应对复杂背景下的场景多样性。

## 核心方法

### 双骨干特征融合参照系

本文基于Cascade R-CNN架构，采用DetectoRS作为检测骨干，U-Net++作为分割骨干。与常规单骨干检测器不同，SPAR-Det并行处理两路特征，旨在利用分割网络保留的像素级边界信息补偿检测骨干在小目标上的特征缺失。关键差异在于，分割骨干在AI-TOD上预训练后冻结，仅作为静态先验提供空间判别信号，而非参与端到端梯度更新。

### 跨注意力异质特征融合（CAHF）

CAHF模块解决检测特征中前景信号被背景噪声抑制的问题。该模块将分割特征 $F_{seg}^l$ 与检测特征 $F_{obj}^l$ 经1×1卷积降维后拼接，形成融合特征 $F_f^l$。随后并行计算通道注意力与空间注意力：通道注意力通过全局平均池化与两层全连接生成权重，强调低对比度特征；空间注意力利用可变形卷积（DCN）增强位置敏感线索。最终输出为：

$$
\mathbf{F}_{CAHF}^l = \mathbf{C}^l(\mathbf{F}_f^l) \odot \mathbf{S}^l(\mathbf{F}_f^l) \odot \mathbf{F}_{obj}^l
$$

其中 $\odot$ 表示逐元素乘法。这一设计将分割网络的边界判别能力转化为检测特征的通道与空间权重，使小目标区域在特征空间中获得更高响应，从而缓解因特征模糊导致的定位漂移。

### 几何先验监督损失与MoE路由

CAHF增强了特征表示，但小目标的几何结构（如长宽比、朝向）仍需显式约束。SPAR-Det提出几何先验监督损失，将分割特征投影为语义图，并与基于真值框的高斯热图加权组合，形成监督目标 $G_{target}$：

$$
\mathbf{G}_{target} = \alpha \cdot \phi(\mathbf{F}_{seg}^1) + (1 - \alpha) \cdot \mathbf{H}_{gaussian}
$$

其中 $\alpha=0.8$，$\mathbf{H}_{gaussian}$ 为标准差 $\sigma_x=w/6, \sigma_y=h/6$ 的二维高斯分布。该损失通过加权二元交叉熵（WBCE）约束检测特征，弥补小目标自表示能力的不足。此外，MoE-Head采用基于RoI统计特征（熵、方差、对比度等8项）的门控机制，通过两层MLP生成Top-K（K=4）专家权重，实现场景感知的专家选择，避免传统MoE中专家负载不均导致的性能下降。

## 实验评估

实验在AI-TOD、VisDrone和LEVIR-Ship三个基准上进行，采用COCO mAP指标。基线覆盖RFLA、DINO、BAFNet等代表性方法，但缺失2025-2026年频域SOTA如FSDC-DETR、D3R-DETR，导致对比范围受限。

| 方法 | AI-TOD AP | AI-TOD mAP | VisDrone AP | VisDrone mAP | LEVIR-Ship mAP |
| :--- | :--- | :--- | :--- | :--- | :--- |
| RFLA | 24.8 | 55.2 | - | - | 45.3 |
| DINO | 23.2 | 56.6 | 26.8 | 44.2 | 73.4 |
| BAFNet | 30.5 | 59.8 | 30.8 | 52.6 | 84.2 |
| SPAR-Det | 31.2 | 61.2 | 30.8 | 53.4 | 84.3 |

SPAR-Det在AI-TOD上以31.2 AP超越BAFNet 0.7 AP，在VisDrone上持平BAFNet的30.8 AP，LEVIR-Ship上略低于BAFNet的84.2 mAP。消融实验显示，CAHF贡献最大（+3.9 AP），MoE-Head次之（+1.1 AP），几何先验损失贡献最小（+0.3 AP）。

| 组件 | AP | mAP |
| :--- | :--- | :--- |
| Base (RFLA) | 24.8 | 55.2 |
| + CAHF | 28.7 | 57.8 |
| + CAHF + MoE-Head | 30.1 | 59.9 |
| + CAHF + MoE-Head + Geo Loss | 31.2 | 61.2 |

CAHF的增益显著高于其他组件，表明分割先验对特征表示的改善是主要驱动力。MoE-Head在复杂场景下的增益有限，可能受限于统计特征的表达能力。几何先验损失的边际收益递减，暗示其作用已被CAHF部分覆盖。

评估协议采用标准COCO mAP，未报告置信区间，数值比较需谨慎。代码已开源，超参数（如 $\alpha=0.8$、K=4）基于启发式设定，缺乏系统性搜索。分割骨干在AI-TOD上预训练后冻结，限制了其在VisDrone等域外数据集上的泛化能力，这解释了为何VisDrone性能未显著提升。

## 关联研究分析

从问题动机看，SPAR-Det与频域增强方法（如FSDC-DETR）解决同一高频丢失问题，但路径不同。频域方法通过显式频谱操作恢复细节，依赖骨干网络的频谱保真度；SPAR-Det则通过分割先验间接保留边界，依赖分割网络的像素级判别能力。前者在AI-TOD上达到31.3 AP，略高于SPAR-Det的31.2 AP，表明频域操作在极小目标上可能更具优势。SPAR-Det的分割骨干冻结策略可能限制了其性能上限，若解冻并联合训练，是否能在保持边界精度的同时提升泛化性，论文未给出回答。

从方法设计看，SPAR-Det的MoE-Head与V-MoE等视觉MoE方法共享稀疏路由思想，但路由依据不同。V-MoE基于视觉Token的数据驱动学习，SPAR-Det基于RoI统计特征（熵、方差等）。统计特征路由在纹理复杂的场景中可能更鲁棒，但在语义模糊的小目标上可能失效，因为统计特征无法捕捉语义信息。这种设计选择反映了任务特性对路由机制的约束：小目标检测更依赖局部纹理与几何结构，而非全局语义。

## 总结

SPAR-Det针对小目标检测中IoU阈值导致的正样本分配失效问题，提出分割引导特征融合与统计路由MoE框架。通过CAHF模块将分割骨干的像素级边界信息注入检测特征，结合几何先验损失与RoI统计特征路由，在AI-TOD上取得31.2 AP，超越BAFNet 0.7 AP。该框架证明了分割先验对弱特征表示的补偿作用，但分割骨干冻结策略限制了跨域泛化，VisDrone性能未显著提升。当分割骨干解冻并联合训练时，其边界精度与泛化能力能否同时提升，论文未给出回答。
