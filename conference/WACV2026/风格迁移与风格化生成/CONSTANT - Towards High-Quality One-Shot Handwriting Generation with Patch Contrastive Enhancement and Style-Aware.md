# CONSTANT：用补丁对比增强与风格感知量化，解决单样本手写生成中风格与噪声纠缠难题

作者：Anh-Duy Le、Van-Linh Pham、Thanh-Nam Vo 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.07543)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.07543)

CONSTANT (Patch Contrastive Enhancement and Style-Aware Quantization)

> 单样本手写生成面临的核心困境是：仅凭一张参考图，模型难以从噪声中剥离出稳定的风格属性，导致生成结果风格残缺或细节模糊。现有扩散模型方法依赖固定高频滤波器或连续向量，无法有效区分“核心风格”与“随机噪声”。CONSTANT 引入向量量化（VQ）将风格离散化为概念Token，并辅以潜空间补丁对比损失，实现了风格提取的鲁棒化与局部细节的锐化。该方法在IAM基准上显著优于SOTA，但其离散化表示对风格连续性的潜在影响尚未被充分验证。

## 研究背景

单样本手写生成要求模型从单一参考图像中解耦出书写者的独特风格（如笔触宽度、倾斜度、墨色）并应用于新内容。这一任务的核心难点在于“风格-噪声纠缠”：参考图中的风格特征与背景噪声、随机笔误在像素层面高度耦合。传统的连续特征提取方法（如One-DM使用的高频滤波器）倾向于保留所有高频信息，导致噪声被误判为风格细节；而简单的平均池化又会丢失细微的风格差异。为了解决这一矛盾，需要一种机制能够主动筛选出具有语义一致性的风格成分，同时抑制随机扰动。

手写生成领域长期依赖GAN架构，如HiGAN+，但其训练不稳定且难以捕捉复杂风格。随着潜空间扩散模型（LDM）的兴起，One-DM等扩散方法在生成质量上超越了GAN，但其风格编码器仍受限于固定的高频滤波策略，无法适应多变的手写风格（如墨色变化、连笔差异）。此外，现有方法多采用多阶段训练或依赖多张参考图（Few-shot），限制了其在真实场景中的实用性。CONSTANT的切入点在于：利用离散表示学习（Discrete Representation Learning）的思想，将风格建模为有限的“概念码本”，通过量化过程天然过滤噪声，并结合对比学习强化风格的可区分性，从而在单样本条件下实现更鲁棒的风格迁移。

## 核心方法

### 方法参照系

本文基于潜空间扩散模型（LDM）框架，其标准流程为：通过编码器提取风格与内容特征，注入去噪网络的条件分支，最终生成图像。与One-DM等现有LDM方法的关键差异在于风格提取模块：本文摒弃了连续特征向量或固定滤波器，转而采用基于向量量化（VQ）的离散风格表示，并引入了针对潜空间局部细节的对比优化目标。

### 风格感知量化 (SAQ)

**设计动机**：One-DM使用拉普拉斯算子提取高频信息，但该方法无法区分“风格性高频”（如笔触纹理）与“噪声性高频”（如扫描伪影），导致单样本输入时风格提取不稳定。SAQ模块旨在通过离散化机制，将风格压缩为有限的语义Token，从而在量化过程中自动丢弃无法归类的噪声信息。

SAQ模块以预训练的Inception-V3为骨干，提取参考图 $X_s$ 的特征图 $F \in \mathbb{R}^{h \times w \times d}$。随后，通过一个可学习的码本 $E = \{e_i\}_{i=1}^K \in \mathbb{R}^{K \times D}$ 对特征进行最近邻量化，得到量化特征 $F_q$。量化过程由VQ损失 $L_{vq}$ 和承诺损失 $L_{cmt}$ 共同优化：

$$ L_{vq} = \| sg(F) - E \|_2^2, \quad L_{cmt} = \| F - sg(E) \|_2^2 $$

其中 $sg(\cdot)$ 为停止梯度操作。为了保留连续特征中的局部细节，SAQ将连续特征 $F$ 与量化特征 $F_q$ 拼接并展平，通过注意力池化模块生成全局风格表示 $F_{global}$ 和序列风格特征 $F_{seq}$。这种“离散+连续”的混合表示，既保证了风格概念的抽象性与鲁棒性，又保留了适应特定书写者的细微变化。

### 潜空间补丁对比增强 ($L_{LatentPCE}$)

**设计动机**：标准去噪损失关注全局一致性，但往往导致生成图像局部细节模糊（如笔画边缘不清晰）。$L_{LatentPCE}$ 旨在通过对比学习，强制生成图像与目标图像在潜空间的局部补丁（Patch）位置上保持对齐，从而锐化细节。

该损失函数在潜空间提取多尺度补丁特征。设目标潜变量为 $z_p$，生成潜变量为 $\hat{z}_p$，负样本为 $\bar{z}_p$。对于尺度 $s$，对比损失定义为：

$$ \ell_{LatentPCE}(z_p^{[s]}, \hat{z}_p^{[s]}, \bar{z}_p^{[s]}) = -\log \frac{\exp(sim(z_p^{[s]}, \hat{z}_p^{[s]})/\tau)}{\exp(sim(z_p^{[s]}, \hat{z}_p^{[s]})/\tau) + \sum_{n=1}^{H-1} \exp(sim(z_p^{[s]}, \bar{z}_{p,n}^{[s]})/\tau)} $$

该公式通过最大化同一空间位置补丁的相似度，同时推开不同位置的补丁，实现了局部结构的精确对齐。与像素级的LPIPS不同，$L_{LatentPCE}$ 直接在扩散模型的潜空间操作，计算效率更高且更符合生成过程的内在表征。

## 实验评估

| 方法 | HWD ↓ | FID ↓ |
| :--- | :--- | :--- |
| HiGAN+ | 1.35 | 20.04 |
| HiGAN | 1.55 | 17.58 |
| One-DM | 1.22 | 18.94 |
| **CONSTANT** | **0.99** | **11.48** |

实验在IAM、IMGUR5K和IIIT-English-Word数据集上进行，对比基线涵盖GAN路线（HiGAN+）和扩散路线（One-DM）。CONSTANT在IAM测试集上取得了0.99的HWD和11.48的FID，显著优于One-DM（1.22 HWD, 18.94 FID）。这表明SAQ模块在风格模仿精度上具有明显优势，而$L_{LatentPCE}$有效提升了视觉质量。值得注意的是，尽管One-DM使用高频滤波器，CONSTANT在复杂风格（如IMGUR5K）上仍保持领先，验证了离散码本对噪声的鲁棒性。

| 配置 | FID ↓ | HWD ↓ |
| :--- | :--- | :--- |
| Base | 16.73 | - |
| Base + SAQ | 12.47 | 0.85 |
| Base + SAQ + $L_{SCE}$ | - | 0.84 |
| Base + SAQ + $L_{SCE}$ + $L_{LatentPCE}$ | 10.20 | 0.74 |

消融实验显示，SAQ模块将FID从16.73降至12.47，贡献了最大的质量提升，证明离散化是解决风格噪声的关键。$L_{SCE}$ 对HWD的改善较小（0.85至0.84），说明其主要用于增强风格区分度而非直接提升视觉质量。$L_{LatentPCE}$ 进一步将FID降至10.20，证实了潜空间对比学习对局部细节锐化的有效性。相比之下，替代损失如$L_{cosine}$（FID 21.06）和LPIPS（FID 14.05）效果均不如$L_{LatentPCE}$，表明全局相似度或像素级感知损失无法替代潜空间局部对齐的作用。

评估指标包括FID（视觉质量）、HWD（风格相似度）和WER（可读性）。代码已开源，但论文未报告计算效率（如推理时间）和显存占用，这对于实际部署是一个缺失维度。此外，实验主要关注静态图像，未涉及视频手写生成的时序一致性，限制了其在动态场景中的应用评估。

## 关联研究分析

从风格表示机制看，CONSTANT与One-DM形成鲜明对比。One-DM依赖固定的拉普拉斯高频滤波器，本质上是一种手工设计的特征提取器，其假设是“风格存在于高频段”。然而，手写风格中的墨色、笔触密度等属性并非纯粹的高频信号，且噪声同样存在于高频。CONSTANT采用可学习的VQ码本，将风格抽象为离散概念，这种数据驱动的方式能够自适应地学习哪些特征构成“风格”，哪些是“噪声”。这一差异的根源在于任务特性：单样本场景下，数据量不足以支撑复杂连续特征的过拟合，离散化提供了更强的归纳偏置，防止模型记忆噪声。

从损失函数设计看，CONSTANT的$L_{LatentPCE}$与传统的感知损失（如LPIPS）存在本质区别。LPIPS在像素或浅层特征空间计算距离，容易受到纹理噪声的干扰，且计算开销大。CONSTANT直接在扩散模型的潜空间进行多尺度补丁对比，利用了扩散模型内部表征的语义丰富性。这种设计不仅提升了局部细节的清晰度，还通过对比学习增强了生成图像的结构一致性。与GAN中的PatchGAN判别器不同，$L_{LatentPCE}$ 是一种无对抗的优化目标，避免了训练不稳定性，更适合扩散模型的端到端训练范式。

## 总结

CONSTANT旨在解决单样本手写生成中风格与噪声纠缠导致的生成质量低下问题。其核心创新在于引入风格感知量化（SAQ）模块，将风格离散化为概念Token，从而在量化过程中过滤噪声；同时通过潜空间补丁对比损失（$L_{LatentPCE}$）锐化局部细节。实验表明，该方法在IAM基准上取得了11.48的FID和0.99的HWD，显著优于SOTA方法One-DM。然而，离散化表示虽然提升了鲁棒性，但可能牺牲了风格的连续性，使得风格强度的平滑调节变得困难。当参考图包含极其细微的风格渐变时，离散码本能否捕捉到这些连续变化，论文未给出回答。
