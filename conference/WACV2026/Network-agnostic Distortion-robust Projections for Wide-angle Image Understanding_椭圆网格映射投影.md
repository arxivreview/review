# WACV2026最新论文 ｜Network-agnostic Distortion-robust Projections for Wide-angle Image Understanding ｜椭圆网格映射投影

作者：Akshaya Athwale、Ola Ahmad、Jean-Francois Lalonde

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_a5be3ec6a12f)

> 宽角图像理解的核心矛盾在于，大视场角带来的几何畸变破坏了卷积神经网络所依赖的平移不变性，而传统去畸变方法在边缘拉伸与视场损失之间难以平衡。现有方案要么通过复杂的畸变感知架构（如HEALSwin）牺牲预训练模型的兼容性，要么采用透视投影导致信息丢失。本文切入点在于重新审视去畸变策略，引入计算机图形学中的椭圆网格映射（Elliptical Grid Mapping, EGM）作为规范表示，实现网络无关的畸变鲁棒投影。该方法通过简单的几何变换将宽角图像校正为圆形区域内的椭圆弧，使任意预训练分割网络可直接处理，并在零样本泛化实验中展现出优于专用架构的稳定性。其价值在于以极低的计算开销实现了跨镜头适配，但依赖精确标定参数这一前提限制了其在无标定场景下的适用性。

## 研究背景

宽角相机通过非透视投影（如等距、等角或统一相机模型）将三维场景映射至二维平面，这一过程引入了径向畸变。畸变导致图像边缘像素对应的角度跨度远大于中心，使得基于平面网格假设的标准卷积核在边缘区域失效。为恢复几何一致性，传统方法将图像去畸变为透视投影，但透视投影仅适用于小于150°的视场角，超出该范围后边缘拉伸严重，违背了使用宽角镜头的初衷。

领域内主流路线分为两类：一是直接处理畸变图像，通过修改网络架构（如DarSwin-Unet的极坐标嵌入、HEALSwin的HEALPix网格）来适应畸变，但这类方法计算复杂度高且无法利用大规模预训练骨干；二是去畸变预处理，将图像映射至规范域后再处理，但传统透视去畸变存在视场裁剪问题。本文的切入点在于探索介于两者之间的路径：保留去畸变的轻量级优势，同时通过选择更合适的投影函数（EGM）来避免透视投影的边缘拉伸缺陷，从而在保持网络无关性的同时实现跨镜头泛化。

## 核心方法

### 方法参照系

本文问题归属于“畸变鲁棒投影”路线，标准流程为：前向扭曲至规范域 → 网络处理 → 逆向扭曲回原域。与通用流程的关键差异在于，本文摒弃了透视或圆柱投影，转而采用方到圆映射函数（EGM）作为规范表示，以保留全视场并减少几何失真。

### EGM投影机制

EGM投影的核心在于将宽角图像的矩形网格转换为圆形区域内的同心椭圆弧。对于目标坐标 $(u, v)$，首先通过 $L_\infty$ 范数计算径向距离 $r = \max(|u|, |v|)$，进而确定入射角 $\theta$。结合已知的镜头畸变曲线 $f_{lens}(\theta)$，计算宽角图像中的半径 $r_w$，最终通过双线性采样获取像素值。

$$
r_w = f_{lens}(\theta) = f \frac{\sin \theta}{\xi + \cos \theta}
$$

该公式基于统一相机模型（UCM），其中 $\xi$ 为畸变参数。EGM的设计动机在于解决透视投影在宽视场下的边缘拉伸问题：通过将正方形映射为圆形，EGM在几何上保持了连续性，避免了立方体映射（Cubemap）在面交界处的不连续，从而在扭曲-逆扭曲过程中保留了更多的几何一致性。

### 零样本泛化策略

在零样本泛化实验中，模型在特定畸变区间（如 $\xi \in [0.5, 0.7]$）训练，并在未见过的畸变区间测试。EGM投影通过消除畸变对图像几何的影响，使得网络学习到的特征与具体畸变参数解耦。

$$
\mathcal{L}_{seg} = -\sum_{i=1}^{C} y_i \log(\hat{y}_i)
$$

该损失函数为标准交叉熵，但关键在于输入图像已通过对EGM的扭曲实现了畸变不变性。这一设计的改进价值在于，当测试镜头的畸变参数 $\xi$ 偏离训练分布时，EGM投影仍能提供稳定的几何基础，使得网络无需重新训练即可适应新镜头，而专用架构（如HEALSwin）因依赖特定网格结构，在分布外畸变下性能下降更显著。

## 实验评估

| 方法 | 分辨率 | mIoU |
| :--- | :--- | :--- |
| HEALSwin | 64×64×8 | 0.3718 |
| DarSwin-Unet | 192×192 | 0.3420 |
| Swin-Unet | 128×192 | 0.4071 |
| Swin-Unet+EGM | 192×192 | 0.4143 |
| DDRNet* | 128×192 | 0.4242 |
| DDRNet*+EGM | 192×192 | 0.4307 |
| SegNeXt* | 128×192 | 0.4156 |
| SegNeXt*+EGM | 192×192 | 0.4278 |

实验在WoodScape数据集上进行，对比了专用畸变感知架构（HEALSwin, DarSwin-Unet）与通用骨干加EGM投影的组合。基线覆盖了球面网格（HEALSwin）、极坐标嵌入（DarSwin-Unet）及标准Transformer（Swin-Unet），但缺失了基于位置编码适配的FishRoPE等最新基础模型适配方法。核心数字对比显示，Swin-Unet+EGM（0.4143）优于专用架构HEALSwin（0.3718）和DarSwin-Unet（0.3420），且DDRNet+EGM（0.4307）在所有组合中取得最高mIoU，验证了EGM与强预训练骨干的兼容性。

消融实验通过扭曲-逆扭曲一致性测试（PSNR）验证了EGM的几何优势。在相同畸变水平下，EGM的重建PSNR显著高于Polar和Cubemap投影，表明其在保持几何一致性方面更优。这一发现解释了为何EGM在零样本泛化中表现更稳定：更低的几何失真意味着网络在训练域学到的特征在测试域中更具鲁棒性。

评估边界方面，实验仅报告了mIoU和PSNR，未提供计算效率（FPS）或内存占用数据，限制了其在实时应用中的评估。可复现性方面，论文提供了代码链接，但零样本泛化实验依赖合成数据生成，真实场景下的标定误差影响未量化。

## 关联研究分析

从方法设计看，EGM与HEALSwin和DarSwin-Unet的根本差异在于几何处理的层级。HEALSwin和DarSwin-Unet将畸变信息嵌入网络内部（通过HEALPix网格或极坐标位置编码），属于“架构内适配”；而EGM在数据层面完成几何校正，属于“数据外适配”。这一差异导致EGM能无缝集成任意预训练骨干，而专用架构必须从头训练或深度修改。根源在于任务特性：语义分割对几何一致性敏感，但网络结构对预训练特征依赖度高，EGM通过解耦几何校正与特征提取，最大化了预训练知识的复用。

从问题动机看，EGM与FishRoPE（知识库SOTA）代表了两种不同的跨镜头泛化路径。FishRoPE通过修改位置编码（旋转射线嵌入）使冻结的DINOv2骨干原生兼容鱼眼几何，属于“特征对齐”路线；EGM通过投影变换消除畸变，属于“几何校正”路线。FishRoPE无需精确标定，对未知畸变更具鲁棒性，但依赖预训练模型的质量；EGM依赖精确标定，但计算开销更低。在标定不准场景下，EGM的性能退化是否显著，论文未给出回答，这构成了两条路线竞争的关键盲区。

## 总结

本文要解决的核心矛盾是宽角图像畸变与预训练模型兼容性之间的冲突。现有方法要么牺牲预训练优势（专用架构），要么损失视场信息（透视去畸变），本文通过引入EGM投影，在数据层面实现几何校正，从而保留了预训练骨干的通用表征能力。实验证明，EGM+DDRNet在WoodScape上取得0.4307的mIoU，优于所有专用架构基线，且在零样本泛化中展现出更稳定的性能。本文的边界在于依赖精确的镜头畸变曲线，当标定参数存在误差时，EGM的几何校正效果会直接受损。当测试镜头的畸变参数与训练分布偏差超过一定阈值时，EGM投影的几何一致性是否仍能维持，论文未给出回答。
