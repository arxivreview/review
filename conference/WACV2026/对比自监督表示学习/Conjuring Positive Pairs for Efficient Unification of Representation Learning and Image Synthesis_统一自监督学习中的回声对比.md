# WACV2026最新论文 ｜Conjuring Positive Pairs for Efficient Unification of Representation Learning and Image Synthesis ｜统一自监督学习中的回声对比

研究机构：西班牙巴塞罗那超级计算中心

作者：Imanol G. Estepa、Jesús M. Rodríguez-de-Vera、Ignacio Sarasúa 等 5 人

> 统一自监督学习（Unified SSL）旨在构建同时具备强判别力与高保真生成能力的单一模型，以解决传统方法中判别与生成任务相互制约的困境。现有统一框架如 MAGE 依赖在线语义 Token 化导致高昂计算开销，且其对比机制牺牲生成性能以换取判别提升。Sorcen 通过预计算 Token 消除在线转换开销，并引入“回声对比”（Echo Contrast）机制，利用解码器生成的语义变体作为正样本，实现单输入下的无增强对比学习。该方法在 ImageNet-1k 上以 60.8% 的训练效率提升超越了前代 SOTA，但其判别性能仍低于纯对比方法，且回声样本的多样性上限尚未明确。

## 研究背景

当模型试图同时执行图像分类与无条件生成时，其内部表示往往面临冲突：判别任务要求特征空间紧凑以区分类别，而生成任务要求特征分布覆盖数据流形以重建细节。这种冲突在统一自监督学习中表现为“此消彼长”现象，即优化判别指标常导致生成质量（FID）恶化。解决这一矛盾的关键在于构建一种能够同时满足两种几何约束的表示空间，而传统对比学习依赖的像素增强视图往往破坏生成所需的语义完整性，导致正样本对包含噪声或语义漂移。

主流统一 SSL 方法如 MAGE 采用 VQGAN 语义 Token 重建作为预训练目标，但其在线 Token 化过程引入巨大计算开销，且其对比变体 MAGE-C 需双视图输入，进一步加剧了资源消耗。更关键的是，MAGE 系列在提升线性探测准确率时，FID 指标显著上升，表明其未能实现判别与生成的协同增益。Sorcen 的切入点在于将生成能力内化为对比学习的正样本来源：不再依赖外部增强或双视图，而是利用模型自身的解码器在语义 Token 空间生成“回声”样本，从而在单输入条件下实现高效且语义一致的对比训练。

## 核心方法

### 方法参照系

Sorcen 基于 Encoder-Decoder 架构，继承 MAGE 的语义 Token 重建范式，但摒弃了在线 VQGAN 转换与双视图对比。其核心差异在于：正样本不再来自像素增强，而是来自解码器输出的 Logit 分布采样，形成“回声”（Echo）样本，与原始锚点（Anchor）在语义 Token 空间进行对比。

### 语义 Token 预计算与掩码重建

设计动机：消除 MAGE 中在线 VQGAN 编码带来的训练瓶颈，将 Token 化开销前置至数据准备阶段。对于每张图像 $I$，预计算其 VQGAN 语义 Token 序列 $\mathbf{t} = (t_1, \dots, t_{CS})$，其中 $CS$ 为码本大小。训练时，对 $\mathbf{t}$ 应用截断高斯掩码（均值 0.55，范围 [0.5, 1]），并丢弃一半掩码 Token 以降低计算量，最终输入长度为 $L+1$ 的序列 $\mathbf{t}'$（含全局占位符 $E$）。学生编码器 $E$ 处理 $\mathbf{t}'$，解码器 $G$ 重建原始 Token，损失函数为：

$$
\mathcal{L}_{rec} = \sum_{i=1}^{CS} \mathcal{L}_{CE}(t_i, G(E(\mathbf{t}'))_i)
$$

该公式确保模型在低维语义空间学习重建能力，为后续回声生成提供基础。

### 回声对比机制

设计动机：解决传统对比学习中正样本语义不一致问题，同时避免像素增强对生成能力的干扰。解码器输出 Logit 分布后，通过过滤与 JS 掩码采样生成回声 Token $\mathbf{t}_{echo}$，其由教师编码器 $T$（学生编码器的 EMA 版本）处理。对比损失采用 InfoNCE，锚点表示 $z_a = E(\mathbf{t}')$ 与回声表示 $z_e = T(\mathbf{t}_{echo})$ 拉近，批次内其他样本推远：

$$
\mathcal{L}_{CL} = -\log \frac{\exp(\text{sim}(z_a, z_e)/\tau)}{\sum_{j \in \mathcal{B}} \exp(\text{sim}(z_a, z_j)/\tau)}
$$

其中 $\tau$ 为温度系数，$\mathcal{B}$ 为批次索引。该机制使正样本在语义空间内保持多样性，无需像素操作，从而在单输入条件下实现有效对比。

## 实验评估

实验在 ImageNet-1k 上进行，预训练 1600 个 epoch，使用 ViT-L 骨干。基线覆盖生成模型（DiT、ADDP）、双裁剪对比方法（MoCo v3、iBot）及单裁剪 MIM 方法（MAGE、MAE），但未对比最新非对比方法如 VICReg 或 DINO v2。主结果显示，Sorcen 在无条件生成 FID 上达到 22.41，优于 MAGE 的 23.90；线性探测准确率为 69.62%，高于 MAGE 的 69.22%。

| 方法 | 线性探测 (Acc.) | FID |
| :--- | :--- | :--- |
| Sorcen | 69.62 | 22.41 |
| MAGE | 69.22 | 23.90 |
| MAGE-C | 70.02 | 26.21 |

消融实验表明，移除回声对比导致 Top-1 下降 1.56%（68.06% vs 69.62%），FID 上升 1.41（23.82 vs 22.41），证实回声机制对判别与生成的双重贡献。移除预热阶段（Warmup）使 Top-1 骤降至 33.20%，FID 升至 47.17，凸显早期回声样本质量对训练稳定性的关键影响。移除 JS 掩码仅导致 Top-1 下降 0.32%，FID 上升 0.61，表明其贡献相对次要。

评估边界方面，论文未报告置信区间，且仅在 ImageNet-1k 上验证，缺乏跨域鲁棒性测试。代码已开源，但超参数细节（如温度系数 $\tau$ 的具体值）未在正文中明确列出，可能影响复现精度。

## 关联研究分析

从问题动机看，Sorcen 与 MAGE 的核心差异在于正样本生成机制。MAGE 依赖在线 VQGAN 编码与双视图对比，导致计算开销大且判别与生成性能冲突；Sorcen 通过预计算 Token 与回声采样，将生成能力转化为对比信号，实现了单输入下的协同优化。这一设计源于对“正样本语义一致性”的重新定义：回声样本在语义空间内变异，而非像素空间内扭曲，从而避免了增强引入的噪声。

从方法设计看，Sorcen 与 BYOL 共享 Student-Teacher 架构，但教师输入为生成的回声而非增强视图。BYOL 的不对称结构依赖动量更新防止坍缩，而 Sorcen 的回声机制通过语义多样性提供对比信号，无需依赖大规模负样本。然而，Sorcen 未明确负样本的处理方式，其 InfoNCE 损失隐含批次内负样本，这与知识库中“非对比方法无需负样本”的共识存在潜在矛盾。回声样本是否足以替代负样本的判别边界细化作用，论文未给出理论解释。

## 总结

Sorcen 旨在解决统一 SSL 中判别与生成任务的冲突，其切入点在于利用生成能力内生正样本，而非依赖外部增强或双视图。通过预计算语义 Token 与回声对比机制，该方法在 ImageNet-1k 上以 60.8% 的训练效率提升超越了 MAGE，线性探测准确率达 69.62%，FID 为 22.41。然而，其判别性能仍低于纯对比方法如 MoCo v3，且回声样本的多样性受限于解码器能力，可能在复杂场景下不足。当数据集规模扩大或类别数增加时，回声采样的语义覆盖范围是否足以维持对比有效性，论文未给出回答。
