> 多智能体轨迹预测长期面临生成轨迹在几何精度上达标但行为逻辑失真的困境，现有扩散模型多采用开环采样，缺乏对速度、碰撞等安全约束的实时调控。M2Traj 将可学习行为分类器嵌入去噪循环，通过梯度反传实现闭环反馈。该框架在 Waymo 和 HighD 上验证了行为一致性的提升，但其评估协议与主流基准存在显著差异，限制了横向可比性。

## 研究背景

当自动驾驶系统从感知转向规划时，预测模块输出的轨迹若仅满足最小平均位移误差（minADE），却伴随急加速或车道偏离，将直接导致下游规划器失效。这种几何精度与行为合理性的割裂，源于传统生成模型将预测视为纯分布拟合问题，忽略了动力学约束。为弥合这一差距，条件扩散模型（Conditional Diffusion Model）通过迭代去噪生成多模态轨迹，但其开环特性使得模型无法在生成过程中感知并修正累积的行为偏差。

轨迹预测领域的主流路线已从早期的确定性回归转向生成式范式，其中 VectorNet 确立了向量化表示标准，WayFormer 引入了全局注意力机制以捕捉长程依赖。然而，这些方法大多将行为约束（如速度限制、碰撞避免）作为后处理步骤或辅助损失函数，未能直接介入采样过程。这种解耦设计导致模型在密集交互场景中易产生物理上不合理的轨迹，且无法动态响应实时变化的交通状态。M2Traj 的切入点在于打破预测与行为控制的边界，将行为反馈直接注入扩散去噪循环，实现生成过程中的实时行为校准。

## 核心方法

### 统一多模态 Token 构造

M2Traj 将异构场景元素转化为统一潜空间表示。邻居智能体动态特征通过 MLP-Mixer 块进行空间-时间轴混合，地图多边形与交通灯状态分别编码为紧凑嵌入。所有特征拼接为序列 $x^{(t)} = \text{Concat}(T_{agent}, T_{lane}, T_{light}) \in \mathbb{R}^{N_x \times d}$，作为扩散输入。该设计动机在于解决传统图神经网络中节点特征异构导致的交互建模碎片化问题，通过统一 Token 化使 Transformer 自注意力机制能同时捕捉智能体间交互与环境语义约束。

### 闭环行为引导去噪

标准扩散模型在反向过程中仅依赖噪声预测网络 $\epsilon_\theta$，缺乏对生成轨迹行为质量的监控。M2Traj 引入可学习分类器 $C_\phi$，其训练目标为最小化干净轨迹与加噪轨迹的行为成本差异：

$$
\mathcal{L}_{cls} = \mathbb{E}_{x^{(0)}, t, \epsilon} \left[ \left( C_\phi(x^{(t)}, t) - C_\phi(x^{(0)}, t) \right)^2 \right]
$$

其中 $x^{(t)} = \sqrt{\bar{\alpha}_t} x^{(0)} + \sqrt{1-\bar{\alpha}_t} \epsilon$。推理时，分类器梯度被注入去噪更新公式：

$$
\tilde{s}_\theta(x^{(t)}, t) = s_\theta(x^{(t)}, t) - \lambda \cdot \nabla_{x^{(t)}} C_\phi(x^{(t)}, t)
$$

该机制将速度调节、舒适度估计、碰撞风险及地图合规性转化为可微分软约束。设计动机在于克服手工成本函数不可微或分类器自由引导（Classifier-Free Guidance）缺乏细粒度控制的问题，使模型能在每个去噪步骤动态调整轨迹以符合驾驶语义。

### 历史条件自适应调制

为保持时间一致性，M2Traj 将自车历史轨迹编码为潜向量 $Q_n$，并通过自适应层归一化（AdaLN）在每个 Transformer 块中动态调制特征。该设计动机在于解决静态条件注入无法适应长时程意图漂移的问题，使历史运动从被动输入转变为主动调节器，确保生成轨迹在时间维度上的连贯性与目标对齐。

## 实验评估

| 方法 | Waymo minADE (m) | HighD RMSE (m) | MoCAD RMSE (m) |
| :--- | :--- | :--- | :--- |
| M2Traj | 1.461 | 1.242 | 2.680 |
| QCNeXt | 1.081 | - | - |
| WayFormer | - | - | - |
| MultiPath++ | - | - | - |

M2Traj 在 Waymo 上的 minADE 为 1.461 m，高于 QCNeXt 的 1.081 m，但在行为指标上表现均衡。基线覆盖包括 QCNeXt、WayFormer 等主流 Transformer 方法，但缺失 ProgD、RAG-TP 等最新联合预测 SOTA。评估协议采用 1 秒历史预测 8 秒未来，与知识库中常用的 5 秒历史协议不同，导致数值无法直接对比。

| 消融变体 | Waymo minADE (m) | 变化幅度 |
| :--- | :--- | :--- |
| 完整模型 | 1.461 | - |
| 无碰撞风险引导 | 1.640 | +12.3% |
| 无地图合规引导 | 1.590 | +8.8% |
| 无舒适度估计 | 1.568 | +7.3% |
| 无速度调节 | 1.510 | +3.4% |

消融实验显示，移除碰撞风险引导导致性能下降最显著（+12.3%），表明交互安全是行为一致性的核心。移除地图合规性次之（+8.8%），反映轨迹对可行驶区域的依赖。速度调节的边际收益最小（+3.4%），暗示其在与其他约束协同时作用有限。

评估边界受限于协议差异：Waymo 1 秒历史设定下，M2Traj 的 minADE 高于知识库中 5 秒历史下的 SOTA（如 HeLoFusion 0.72 m），但行为指标（如碰撞率 0.423）优于多数基线。论文未提供代码，超参数（如 $\lambda$、$\sigma$）未详细披露，可复现性受限。

## 关联研究分析

从问题动机看，M2Traj 与 CDDM 均关注扩散模型效率，但 CDDM 通过蒸馏加速推理，M2Traj 则通过闭环反馈提升行为质量。CDDM 假设行为约束可由单步生成隐式满足，而 M2Traj 认为显式梯度注入是必要的。这一差异源于任务特性：CDDM 侧重实时性，M2Traj 侧重安全性。M2Traj 未探索蒸馏与行为引导的结合，可能在效率与质量间存在未开发的权衡空间。

从方法设计看，M2Traj 与 WayFormer 同属 Transformer 骨干，但 WayFormer 采用开环全局注意力，M2Traj 引入闭环局部反馈。WayFormer 依赖大规模预训练捕捉长程依赖，M2Traj 依赖实时行为梯度修正短程偏差。这种设计选择反映了两种范式对“一致性”的不同定义：WayFormer 追求分布一致性，M2Traj 追求行为一致性。M2Traj 未验证闭环反馈在超长时程（>8 秒）下的稳定性，行为梯度是否会导致轨迹收敛到局部最优而非全局合理解，论文未给出回答。

## 总结

M2Traj 试图解决轨迹预测中几何精度与行为合理性的矛盾，通过可学习行为分类器将安全约束直接注入扩散去噪过程。该方法在 Waymo 上实现了 minADE 1.461 m 与碰撞率 0.423 的平衡，验证了闭环反馈对行为一致性的提升。然而，其评估协议（1 秒历史）与主流基准（5 秒历史）存在显著差异，且未与最新联合预测 SOTA 对比，限制了结论的普适性。当历史观测窗口从 1 秒扩展至 5 秒时，闭环行为引导的边际收益是否递减，论文未给出回答。
