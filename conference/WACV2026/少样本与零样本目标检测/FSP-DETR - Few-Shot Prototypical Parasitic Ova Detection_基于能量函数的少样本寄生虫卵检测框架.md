# WACV2026最新论文 ｜FSP-DETR: Few-Shot Prototypical Parasitic Ova Detection ｜基于能量函数的少样本寄生虫卵检测框架

研究机构：美国奥本大学、美国俄克拉荷马州立大学

作者：Shubham Trehan、Udhav Ramachandran、Akash Rao 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2510.09583)

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2510.09583)

> 生物医学成像中，标注数据极度稀缺且常伴随未知类别的出现，传统检测器难以在低监督下同时实现精准定位、已知类别识别与未知实例拒绝。现有少样本方法多孤立处理检测与分类，缺乏统一框架应对开放集场景。FSP-DETR 通过类无关 DETR 骨干提取形态先验，结合原型匹配与能量函数优化嵌入空间，实现了少样本、开放集及跨域任务的统一处理。该框架在自建数据集上验证了有效性，但其简单平均原型策略在复杂生物医学图像中的泛化能力存疑。

## 研究背景

当检测器面对新生成模型时，其训练域与测试域的数据分布出现系统性差异——这一现象称为分布偏移。分布偏移导致传统分类器决策边界失效，而实际场景中往往能获取少量目标域样本，这恰好构成了小样本学习的条件：仅凭每个类别极少量标注样本泛化到新任务。解决此类问题的经典框架是原型网络，它计算各类别支持样本的特征均值作为"原型"，再通过距离度量完成分类。

少样本目标检测（Few-Shot Object Detection, FSOD）旨在解决标注数据极度稀缺时对新类别目标的精准定位与识别。早期研究以微调与元学习为主线，试图通过基类预训练与轻量适配来缓解数据不足，但基类过拟合与特征空间失配问题长期制约着泛化性能。在生物医学垂直领域，如寄生虫卵检测，挑战更为严峻：不仅样本数量极少，还常需识别训练集中未出现的新型病原体或罕见形态，即开放集识别（Open-Set Recognition）。现有方法通常将少样本检测、开放集识别与零样本泛化作为独立任务处理，导致流水线脆弱且碎片化，缺乏在单一模型内协同解决这些问题的统一机制。

FSP-DETR 的切入点在于将上述任务统一于一个能量函数框架下。该框架假设类原型可作为灵活表示，支持检测、分类及新颖性拒绝。通过解耦类无关定位与原型驱动识别，模型无需在架构上为不同任务做专门修改，从而在低标签环境下保持高精度并最小化临床工作流中的误报。

## 核心方法

### 方法参照系

本文问题属于原型匹配与度量学习路线，但区别于直接微调检测器或冻结骨干的主流做法，FSP-DETR 采用两阶段解耦架构：第一阶段训练类无关 DETR 仅学习形态先验，第二阶段通过原型匹配进行细粒度分类。这种设计避免了基类过拟合，但引入了定位误差无法在分类阶段修正的风险。

### 类无关检测骨干与原型构建

设计动机在于解决微调过程中模型倾向于记住基类特征而忽略新类的问题。传统方法在检测与分类联合训练时，易受基类偏差影响。FSP-DETR 首先将 DETR 骨干在二元设置（卵 vs 背景）下微调，所有前景类别合并为单一类，使模型专注于学习跨类别共享的空间与形态线索。随后，从支持集提取特征，通过两层 MLP $\phi(\cdot)$ 映射为嵌入向量，并计算类原型：

$$ p_j = \frac{1}{|S_j|} \sum_{i \in S_j} \phi(v_i) $$

其中 $S_j$ 为第 $j$ 类支持样本集合，$v_i$ 为 DETR 解码器输出的特征。该公式通过平均支持集嵌入构建类中心，同时引入背景原型 $p_0$（由 IoU < 0.3 的预测框特征平均得到），用于拒绝非目标检测。

### 能量函数优化与嵌入细化

设计动机在于解决简单原型匹配导致的类间边界模糊问题。仅拉近查询与正确原型，不足以推开错误原型，尤其在低监督下易产生簇重叠。FSP-DETR 引入能量函数 $E(f, p_j) = d(f, p_j)$，定义类概率为负能量的 softmax。训练目标包含四项：类无关检测损失 $E_{box}$、原型匹配损失 $E_{match}$、KL 蒸馏损失 $D_{KL}$ 及对齐损失 $E_{align}$。其中，对齐损失基于 InfoNCE，利用温度缩放点积相似度 $s_{ij} = \langle q_i, p_j \rangle / \tau$ 强制查询与正确原型对齐，同时与其他原型对比：

$$ L_{align} = -\log \frac{\exp(s_{i, y_i} / \tau)}{\sum_{j} \exp(s_{i, j} / \tau)} $$

该公式通过结构化负样本（即其他类原型）促进类间分离，无需大 batch 或记忆库，适合低样本场景。KL 损失则对齐分类器预测与原型分数，增强判别性。

## 实验评估

实验在自建 20 类寄生虫卵数据集（3,001 例）上进行，对比 DETR、YOLOv9、FCOS、Stable-DINO 及 ProtoNet/ProtoKD 基线。基线覆盖通用检测器与原型方法，但缺失最新视觉基础模型（VFM）融合方法（如 FSOD-VFM）及跨域专用方法（如 LMP），限制了与当前 SOTA 的直接对比。

| 方法 | 5-shot mAP | 5-shot mAR | 10-shot mAP | 10-shot mAR |
| :--- | :--- | :--- | :--- | :--- |
| DETR | 0.026 | 0.063 | 0.054 | 0.120 |
| YOLO | 0.000 | 0.004 | 0.021 | 0.228 |
| ProtoNet + SS | 0.036 | 0.119 | 0.045 | 0.128 |
| ProtoKD + SS | 0.039 | 0.116 | 0.048 | 0.142 |
| FSP-DETR (M) | 0.069 | 0.170 | 0.080 | 0.203 |
| FSP-DETR | 0.066 | 0.171 | 0.094 | 0.207 |

FSP-DETR 在 5-shot 和 10-shot 设定下均取得最高 mAP 与 mAR，尤其在低数据量下优势明显。YOLO 在 10-shot 下召回率最高（0.228），但精度极低（0.021），表明其过度检测且背景区分能力差。

消融实验显示，完整损失函数（Matching+KL+Align）优于单一匹配损失。| 消融项 | mAP | mAR |

| :--- | :--- | :--- |
| L_Matching | 0.069 | 0.170 |
| L_Matching + L_KL | 0.012 | 0.091 |
| L_Matching + L_align | 0.052 | 0.169 |
| L_Matching + L_KL + L_align | 0.066 | 0.171 |

单独加入 KL 损失导致性能骤降（mAP 0.012），表明蒸馏损失在缺乏对齐损失约束时可能引入噪声。温度 $\tau=10$ 时 mAR 最高（0.171），$\tau=0.5$ 时 mAP 最高（0.069），显示温度对精度与召回的权衡作用。

评估边界方面，论文未报告置信区间，数值比较需谨慎。代码未公开，超参数（如 $\lambda_{KL}=\lambda_{align}=1$）固定，可复现性受限。指标仅包含 mAP/mAR，缺乏计算效率（FPS/内存）评估，无法全面衡量实用性。

## 关联研究分析

从方法设计看，FSP-DETR 与 PDA（Prototype-Driven Adaptation）同属原型匹配路线，但 PDA 侧重通过投影层与最佳 K 相似度解决特征空间失配，而 FSP-DETR 通过类无关骨干缓解基类过拟合。PDA 依赖支持集特征质量，FSP-DETR 依赖形态先验的迁移性。二者互补，但 FSP-DETR 未探索自适应原型构建，其简单平均策略在低纹理生物医学图像中可能导致类间边界模糊，这是 PDA 通过任务自适应记忆试图解决的问题。

从问题动机看，FSP-DETR 与 FSOD-VFM 形成对比。FSOD-VFM 利用多 VFM 协同（UPN, SAM2, DINOv2）实现无训练高精度检测，而 FSP-DETR 依赖 DETR+MLP 轻量架构。FSOD-VFM 在 PASCAL-5i 上取得 73.1 nAP50，远超 FSP-DETR 的 0.066 mAP（不同数据集，不可直接比，但反映 VFM 先验优势）。FSP-DETR 的轻量设计适合边缘部署，但缺乏 VFM 的强语义先验，在开放集识别中依赖背景原型，而 FSOD-VFM 通过图扩散细化提案，抑制碎片化，可能在复杂场景下更稳健。

## 总结

FSP-DETR 旨在解决生物医学成像中少样本检测、开放集识别与跨域迁移的统一问题。现有方法孤立处理这些任务，导致流水线脆弱；FSP-DETR 通过类无关 DETR 骨干与能量函数优化嵌入空间，实现了单一模型内的协同处理。实验显示，其在 5-shot 下取得 0.066 mAP 与 0.171 mAR，优于 DETR 与 ProtoKD 基线。然而，论文自身指出，简单平均原型简化了语义多样性，且固定 MLP 投影头可能无法捕捉复杂视觉对应关系。当支持集增大到 10-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
