# WACV2026最新论文 ｜CropAT: Leveraging Diffusion-Generated Target-Like Cropped Objects for Pseudo-Label Refinement in Domain-Adaptive Object Detection ｜基于扩散生成与可学习提示的伪标签精炼

研究机构：国立台湾大学

作者：Chen-Che Huang、Tzuhsuan Huang、Jun-Cheng Chen

分析报告见 [ArxivReview](https://www.arxivreview.com/papers/conf_aa529d62da59)

> 无监督域自适应目标检测（UDAOD）旨在利用有标签源域数据与无标签目标域数据，使检测器适应目标域分布，以规避高昂的标注成本。现有方法多依赖 Mean Teacher (MT) 框架生成伪标签，但伪标签中假阳性比例（FPP）居高不下，导致学生模型陷入确认偏差，性能提升受限。CropAT 通过微调扩散模型生成目标域风格图像，并将裁剪出的真值物体插入目标域图像，从数据层面稀释伪标签噪声。该方法在风格偏移严重的基准上表现优异，但在恶劣天气等复杂域偏移场景下，其性能增益受限于生成模型对细粒度细节的还原能力。

## 研究背景

当检测器从源域迁移至目标域时，因数据分布差异导致性能下降，这一现象称为分布偏移。为在缺乏目标域标签的情况下适应新分布，主流方法采用 MT 框架：教师模型通过指数移动平均（EMA）更新，为无标签目标域数据生成伪标签，学生模型据此进行自训练。然而，教师模型生成的伪标签常包含大量错误分类或定位不准的假阳性，这些噪声标签在迭代训练中不断累积，形成确认偏差，成为制约性能上限的核心瓶颈。

现有解决伪标签噪声的路线主要分为两类：一是通过对抗学习或对比学习对齐源域与目标域的特征分布，如 Adaptive Teacher (AT) 和 Contrastive Mean Teacher (CMT)；二是利用生成模型（如 GAN 或扩散模型）合成中间域数据以缩小域差距。前者侧重于特征空间的几何对齐，后者侧重于数据层面的分布模拟。然而，特征对齐易忽略目标域特定信息，而现有生成方法多使用固定提示词，生成的图像风格与真实目标域存在偏差，未能有效降低伪标签的 FPP。CropAT 的切入点在于，将可学习提示（Learnable Prompt）引入扩散图像编辑模型，精确捕获目标域风格，并通过物体级数据增强策略，将带有真值标签的生成物体直接注入目标域训练流程，从源头降低 FPP。

## 核心方法

### 方法参照系

本文基于 AT 框架，其标准流程为：初始化阶段在源域数据上训练 Faster R-CNN，随后进入互学习阶段，教师模型生成伪标签监督学生模型。本文的关键差异在于，在互学习阶段引入外部扩散模型生成目标域风格图像，并设计特定的数据增强策略，将生成图像中的真值物体与教师伪标签混合，重构了学生模型的监督信号。

### 目标域风格捕获

传统方法使用固定文本提示词驱动扩散模型，生成的图像风格往往偏离真实目标域。为解决此问题，本文借鉴 Textual Inversion 思想，引入可学习提示向量 $v$，通过感知相似度损失优化该向量，使其编码目标域的风格特征。优化目标定义为：

$$
\hat{v} = \arg \min_v \mathbb{E}_{x_s \sim X_s, x_t \sim X_t} [d_{LPIPS}(x_{s \to}, x_t)]
$$

其中 $x_{s \to}$ 为使用提示词 $v$ 编辑后的源域图像，$d_{LPIPS}$ 为基于 VGG 特征的感知相似度。该公式的物理含义是，通过最小化生成图像与真实目标域图像在感知空间的距离，迫使提示词 $v$ 收敛至能准确表达目标域风格的嵌入空间位置。这一设计解决了固定提示词无法适应特定域风格的问题，确保生成的“目标域风格图像”在视觉分布上更接近真实目标域。

### 物体级数据增强与 FPP 抑制

生成目标域风格图像后，本文并未直接将其作为监督数据，而是设计了两级 Mixup 策略。首先，在图像级 Mixup 中，从 Beta 分布采样比例 $r$，混合源域图像 $x_s$ 与目标域风格图像 $x_{s \to}$：

$$
\bar{x}_s = r x_s + (1 - r) x_{s \to}
$$

随后，在物体级 Mixup 中，利用源域真值标签裁剪出物体 $o_i^s$ 和 $o_i^{s \to}$，以相同比例 $r$ 混合生成混合物体 $\bar{o}_i^s$，并将其随机插入混合图像 $\bar{x}_s$ 中。这一策略的核心价值在于：插入的物体拥有来自源域的真值标签，而教师模型对目标域图像的预测仍包含噪声。通过增加真值标签样本在总样本中的占比，直接降低了伪标签的 FPP。公式表明，通过控制混合比例，可以在保持数据多样性的同时，精确调控真值标签与伪标签的比例，从而抑制确认偏差。

## 实验评估

| 基准 | 基线 (AT) | 前 SOTA (CAT) | CropAT | 提升 (vs AT) |
| :--- | :--- | :--- | :--- | :--- |
| Cityscapes→Foggy Cityscapes (0.02) | 49.3 | 52.5 | 53.2 | +3.9 |
| PASCAL VOC→Clipart1k | 45.7 | 49.1 | 52.2 | +6.5 |

实验在 Cityscapes→Foggy Cityscapes、PASCAL VOC→Clipart1k 等标准基准上进行，基线覆盖 AT、CMT、CAT 等主流对抗/对比学习方法，但缺失 VFM 增强类（如 VFM4SDG）及频域方法（如 PAGen）的直接对比。在风格偏移严重的 VOC→Clipart1k 上，CropAT 取得 52.2% mAP，显著超越前 SOTA 3.1 个点；在恶劣天气基准 Cityscapes→Foggy Cityscapes 上，取得 53.2% mAP，超越 AT 3.9 个点。

| :--- | :---: | :---: | :---: | :---: | :--- |
| 基线 (AT) | - | - | - | - | 49.3 |
| Config 1 | ✓ | - | - | - | 50.2 |
| Config 5 | ✓ | ✓ | - | - | 52.0 |
| Config 7 (Ours) | ✓ | ✓ | ✓ | ✓ | 53.2 |

消融实验显示，物体级 Mixup 带来的增益（52.0% vs 50.2%）大于图像级 Mixup，表明物体级真值注入对降低 FPP 更为关键。引入可学习提示后，mAP 从 52.0% 提升至 53.2%，验证了风格匹配对生成质量的影响。值得注意的是，将 Mixup 替换为 Poisson 图像编辑后，mAP 从 53.2% 降至 50.7%，说明 Mixup 的线性混合特性在保留物体结构方面优于传统图像编辑技术。

评估协议主要报告 mAP@0.5，未提供置信区间或计算效率指标。代码已开源，但论文未报告不同 GPU 配置下的训练时间，且未对生成模型的计算开销进行详细分析。在 Cityscapes→Cityscapes-C 基准上，CropAT 在 Brightness、Fog、Frost、Snow 四个子域均超越基线，但在 Single-DGOD 基准上，其性能与 SOTA 方法持平或略优，表明其在多域泛化场景下的优势不如单一域适应场景显著。

## 关联研究分析

从问题动机看，CropAT 与 DSBCO 均针对伪标签噪声，但 DSBCO 采用双层循环优化从特征和标签两个层面精炼伪标签，而 CropAT 通过数据增强从样本层面稀释噪声。DSBCO 在 Cityscapes→Foggy Cityscapes 上达到 64.7% mAP，远高于 CropAT 的 53.2%，这暗示在恶劣天气等复杂域偏移下，特征层面的精细对齐可能比数据层面的风格模拟更有效。CropAT 的优势在于其方法更轻量，无需复杂的优化循环，但在域偏移类型从风格转向内容（如雾密度变化）时，生成模型难以捕捉细粒度细节，导致性能瓶颈。

从方法设计看，CropAT 与 PAGen 均利用生成/频域视角，但 PAGen 通过相位引导幅度生成对齐频率特征，侧重于特征空间的频域对齐；CropAT 则生成像素级图像并插入物体，侧重于数据层面的分布模拟。PAGen 在 BDD100K Day→Night 上取得 49.8% mAP，与 CropAT 在类似光照偏移场景下的表现接近，但 PAGen 无需生成完整的图像，计算开销可能更低。CropAT 的可学习提示机制借鉴了 Textual Inversion，但其应用局限于风格捕获，未探索提示词在内容级域偏移（如物体形状变化）中的潜力。

## 总结

CropAT 针对 UDAOD 中伪标签假阳性比例高导致的确认偏差问题，提出通过可学习提示微调扩散模型生成目标域风格图像，并设计物体级 Mixup 策略将真值物体插入目标域数据，从而降低 FPP。该方法在 PASCAL VOC→Clipart1k 上取得 52.2% mAP，超越前 SOTA 3.1 个点，证明了数据增强策略在风格偏移场景下的有效性。然而，论文自身实验暴露了局限：在 Cityscapes→Foggy Cityscapes 上，其性能（53.2%）远低于 DSBCO（64.7%），且消融实验显示 Poisson 编辑导致性能下降，表明生成模型对细粒度视觉细节（如雾密度、霜雪纹理）的还原能力不足，且仅能学习目标域的主导风格。当目标域包含多种子风格或极端天气细节时，基于像素级生成的伪标签精炼策略是否仍能保持对 FPP 的有效抑制，论文未给出回答。
