作者：Fangcong Yin、Ming Yin、Tanvi Bhandarkar 等 10 人

> 导读 长程智能体任务中，稀疏的结果级奖励导致中间步骤的信用分配失效，模型难以从长轨迹中识别关键决策。现有方法依赖外部过程奖励模型或反事实重放，计算成本高且易受噪声干扰。Self-Credit 利用策略模型在上下文压缩时生成的带引用摘要作为自生成信用，并通过组内成功与失败轨迹的对比进行重缩放，实现无需外部监督的细粒度优势加权。该方法在 BrowseComp-Plus 等长程搜索任务上显著优于基线，证明了自监督信号在开放域智能体训练中的有效性，但其依赖动作语义匹配假设，在动作多样性极高的场景中可能失效。

## 研究背景

当大语言模型（Large Language Model, LLM）作为智能体执行多步工具调用时，其最终获得的二元奖励（如答案正确与否）需归因至数十个中间动作。这种稀疏性导致标准强化学习算法如组相对策略优化（Group Relative Policy Optimization, GRPO）将单一优势值均匀广播至所有 Token，造成关键决策点与无关 Token 获得相同梯度，即信用稀释。为解决此问题，领域内发展出过程奖励模型（Process Reward Model, PRM）与反事实推理等细粒度信用分配机制，但这些方法通常需要昂贵的人工标注或高计算开销的轨迹重放，且在开放域任务中缺乏可靠的验证器。

当前研究重心转向利用模型自身能力生成内部监督信号。然而，仅依赖模型自生成的反馈易导致奖励黑客（Reward Hacking），例如模型可能通过引用所有历史步骤来规避选择性学习的惩罚。此外，长程任务中上下文长度随交互轮次增长，导致计算资源浪费与注意力分散。因此，如何在无外部 PRM 的条件下，利用组内统计信息校正自生成信号的偏差，并在压缩上下文的同时提取有效信用，成为长程智能体训练的核心瓶颈。

## 核心方法

### 压缩增强 RL 与自生成引用

Self-Credit 建立在压缩增强强化学习（Compaction-augmented RL）框架之上。当上下文长度超过阈值 $C$ 时，策略模型 $M_\theta$ 生成摘要 $z_t$ 替换历史交互 $H_{t':t}$，以维持长程推理能力。传统方法如 SUPO 仅使用自由形式摘要，未利用摘要中的结构化信息。Self-Credit 的关键改动在于要求摘要包含对历史关键轮次的引用集合 $K \subseteq \{t', \dots, t-1\}$。这些引用被视为模型自生成的初始信用信号，指示哪些历史动作对当前状态或最终答案具有贡献。该设计将上下文管理从单纯的信息压缩转化为信用提取过程，避免了外部 PRM 的依赖。

### 组内重缩放机制

自生成引用存在噪声，模型可能过度引用或错误引用。Self-Credit 引入组内重缩放（Intra-group Rescaling）机制，利用同一提示词下 $G$ 条轨迹的成功与失败分布来校正信用权重。对于轨迹 $j$ 中被引用的轮次 $B_{jt}$，统计其在成功轨迹集合 $C$ 和失败轨迹集合 $F$ 中的匹配次数 $n_+(B_{jt})$ 和 $n_-(B_{jt})$。基于此，定义缩放权重 $w_{jt}$：

$$
w_{jt} := \begin{cases}
w_s & \text{if } \hat{A}_j > 0, n_-(B_{jt}) = 0, \text{ and } n_+(B_{jt}) \ge \tau_+ \\
1 & \text{if } \hat{A}_j > 0 \text{ and } n_-(B_{jt}) > 0 \\
\beta & \text{if } \hat{A}_j > 0, \text{ otherwise} \\
w_f & \text{if } \hat{A}_j < 0, n_+(B_{jt}) = 0, \text{ and } n_-(B_{jt}) \ge \tau_- \\
1 & \text{if } \hat{A}_j < 0, \text{ otherwise}
\end{cases}
$$

其中 $\hat{A}_j$ 为轨迹级优势，$\tau_+$ 和 $\tau_-$ 为阈值，$w_s > \beta$ 为成功增强权重，$w_f \ge 1$ 为失败惩罚权重。该公式的物理含义是：若某动作仅在成功轨迹中被引用，则增强其正向信用；若仅在失败轨迹中被引用，则增强其负向信用；若成功与失败轨迹均引用，则视为噪声，移除增强效应。这一机制利用组内统计一致性过滤了模型自生成信用的随机性，解决了单一轨迹自评估不可靠的问题。

### 优势重加权

获得重缩放权重后，Self-Credit 修改 GRPO 的目标函数，将均匀广播的优势替换为轮次级加权优势。对于轨迹 $j$ 中轮次 $t$ 的每个 Token $\ell$，其 Token 级优势定义为：

$$
\hat{A}_{j,t,\ell} := \hat{A}_j \cdot w_{jt}
$$

该公式表明，所有属于同一轮次的 Token 共享相同的重加权优势。未被引用的轮次保持 $w_{jt}=1$，即维持原始优势。这一设计确保了信用分配仅作用于模型认为关键的历史步骤，同时通过组内校正避免了盲目强化错误行为。此外，训练过程中对失败惩罚权重 $w_f$ 采用退火策略，早期强惩罚以抑制无效搜索，后期弱惩罚以鼓励探索。

## 实验评估

实验在 BrowseComp-Plus、GAIA 和 xBench-DeepSearch 三个长程搜索与深度研究基准上进行。基线包括零样本、GRPO、GiGPO、SUPO 和 ECHO。评估指标为 LLM-as-a-Judge 准确率，使用 Qwen3-32B 作为裁判模型。

| 方法 | BrowseComp-Plus (Qwen3-32B) Acc. | BrowseComp-Plus (Qwen3-8B) Acc. | GAIA (Gemma4-E4B) Acc. | xBench-DeepSearch (Gemma4-E4B) Acc. |
| :--- | :--- | :--- | :--- | :--- |
| Zero-shot | 10.8 | 3.6 | 23.4 | 4.0 |
| GRPO | 33.3±1.4 | 27.7±2.4 | 34.3±0.6 | 11.3±2.9 |
| GiGPO | 38.2±0.8 | 26.1±1.7 | 13.3±0.6 | 12.0±1.0 |
| SUPO | 36.9±4.6 | 32.1±2.5 | 27.2±2.4 | 6.3±1.5 |
| ECHO | 41.4±2.5 | 32.1±3.0 | 32.0±2.6 | 10.0±1.7 |
| **Self-Credit** | **47.0±2.1** | **40.6±0.7** | **39.2±1.5** | **16.7±1.5** |

Self-Credit 在 Qwen3-32B 上较最强基线 ECHO 提升 5.6 个百分点，在 Qwen3-8B 上提升 8.5 个百分点。在 GAIA 和 xBench-DeepSearch 上，Self-Credit 分别较最强基线提升 4.9 和 4.7 个百分点。值得注意的是，Self-Credit 在保持高准确率的同时，平均交互轮次少于 ECHO，表明其学习到了更高效的工具使用策略，而非单纯增加搜索深度。

| 消融变体 | Qwen3-32B Acc. | Qwen3-8B Acc. |
| :--- | :--- | :--- |
| Self-Credit (Full) | 47.0 | 40.6 |
| w/o Intra-group rescaling | 41.0 | 28.9 |
| w/o Penalties for repeated failures | 34.9 | 26.5 |
| w/o Rescaling for mixed outcomes | 41.0 | 31.3 |
| w/o Self-generated citations | 42.2 | 27.7 |
| w/ Random citations | 38.6 | 32.5 |

消融实验显示，移除对重复失败轮次的惩罚导致 Qwen3-8B 准确率从 40.6% 降至 26.5%，表明模型倾向于过度搜索以获取信用增强，而未能学会承诺答案。移除自生成引用改用随机引用，准确率降至 32.5%，证明模型生成的引用确实包含了比随机选择更有效的信用信号。组内重缩放对混合结果的处理（移除增强）对性能至关重要，移除该规则导致准确率下降 6.0 个百分点。

评估协议依赖 LLM-as-a-Judge，可能存在裁判模型偏差。实验未提供代码开源链接，复现需依赖论文描述的超参数（如 $\tau_+=\tau_-=2$）。动作匹配依赖语义相似度，在动作空间高度离散或语义模糊的任务中，匹配错误可能引入噪声。

## 关联研究分析

与 ECHO 相比，两者均利用成功轨迹进行信用分配，但 ECHO 仅依赖成功轨迹中的显式轮次选择，忽略了失败轨迹中的负面信号。Self-Credit 通过组内重缩放同时利用成功与失败轨迹，能够识别并惩罚那些在失败轨迹中频繁出现但在成功轨迹中缺失的动作，从而更准确地定位导致失败的根源。这种双向校正机制在探索阶段尤为重要，因为仅靠成功轨迹难以区分“必要动作”与“偶然动作”。

与 GiGPO 相比，GiGPO 通过动作状态匹配进行组内重分组，侧重于环境状态的相似性。Self-Credit 则通过引用匹配进行组内重缩放，侧重于模型内部对历史步骤的语义评估。GiGPO 假设相同状态下的动作具有可比性，而 Self-Credit 假设模型生成的引用反映了动作对最终结果的因果贡献。在长程搜索任务中，不同搜索查询可能返回重叠文档，GiGPO 的状态匹配可能失效，而 Self-Credit 的引用匹配能更好地捕捉语义层面的相关性。

## 总结

Self-Credit 针对长程智能体任务中稀疏奖励导致的信用稀释问题，提出了一种无需外部监督的自生成信用分配方法。其核心在于利用上下文压缩时的带引用摘要作为初始信用，并通过组内成功与失败轨迹的统计对比进行重缩放，从而校正自生成信号的噪声。实验表明，该方法在 BrowseComp-Plus 上较基线提升 5.6 个百分点，在 GAIA 上提升 4.9 个百分点，证明了自监督信号在开放域智能体训练中的有效性。然而，该方法依赖动作语义匹配假设，若动作空间高度离散或语义模糊，组内匹配可能失效，导致信用分配噪声增加。当动作匹配阈值 $\tau$ 设置不当或动作多样性极高时，组内重缩放机制是否会退化为均匀广播，论文未给出回答。
