# HuggingFace最新推荐论文 ｜Real In, Real Out: What If We Only Use Real Data for Scene Text Editing? ｜基于自配对真实数据监督的场景文本编辑

研究机构：复旦大学

作者：Xingsong Ye、Yongkun Du、Jiaxin Zhang 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2610.27592)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2610.27592)

> 场景文本编辑（Scene Text Editing, STE）旨在修改图像中的文本内容同时保留原始视觉风格，其核心矛盾在于训练数据中真实配对样本的极度稀缺与合成数据导致的域差距。现有方法依赖渲染工具生成合成配对数据或复杂的显式/隐式解耦模块，导致编辑结果常出现伪影、幻觉或风格失真。TextRIRO 提出了一种基于真实图像自配对（Self-Paired）的数据构造范式，通过“打乱与裁剪”（Shuffle&Crop）操作破坏文本语义但保留低层风格线索，结合条件扩散模型实现无需合成数据的真实感编辑。该工作证明了在特定任务中，数据构造策略的创新可替代对大规模合成数据的依赖，但其对复杂非水平文本布局的鲁棒性边界及自配对策略对全新字体风格的泛化能力仍存疑。

## 研究背景

当生成模型面对真实场景中的文本图像时，其训练域与测试域的数据分布存在系统性差异——这一现象称为域差距（Domain Gap）。在 STE 任务中，获取“同一背景、不同文本”的真实配对图像几乎不可能，因此早期方法（如 SRNet, MOSTEL）依赖渲染工具合成配对数据。然而，合成文本的字体、光照和透视分布无法完全覆盖真实世界的复杂性，导致模型在推理时产生明显的“合成味”伪影或字符幻觉。为解决此问题，后续研究引入了显式解耦（分离前景文本与背景）或隐式解耦（利用预训练特征提取风格），但这些架构设计增加了模型复杂度，且仍受限于合成数据的分布偏差。

随着扩散模型（Diffusion Models）成为图像编辑的主流骨干，研究重心转向如何利用更高质量的数据提升生成保真度。尽管部分工作（如 RS-STE）尝试利用真实图像进行半监督学习，但合成数据仍占主导。TextRIRO 的切入点在于挑战“STE 必须依赖合成配对数据”的共识，提出仅使用真实图像即可构建监督信号。其核心洞察是：场景文本的风格主要蕴含在颜色、纹理和光照等低层视觉线索中，而语义是高层序列结构。通过特定的图像扰动操作，可以从单张真实图像中构造出“内容被破坏但风格保留”的伪源图像，从而在无需人工标注或合成渲染的情况下，迫使模型学习风格保持与内容替换的映射关系。

## 核心方法

### 方法参照系：条件扩散编辑框架

TextRIRO 建立在条件扩散模型（Conditional Diffusion Model）框架之上，其标准流程是将源图像 $I_{src}$ 和目标文本 $T_{tgt}$ 映射为控制信号，指导去噪过程生成目标图像 $I_{tgt}$。与通用图像编辑不同，STE 的关键差异在于对文本字符级精度的严格要求以及对局部风格（如笔触厚度、透视）的极高敏感度。传统方法通常通过显式分割或合成数据提供精确的布局约束，而 TextRIRO 则通过数据构造策略隐式地提供这些约束，其骨干网络采用 Stable Diffusion 的 U-Net 结构，通过 ControlNet 风格的零卷积注入多尺度特征。

### 自配对数据构造：Shuffle&Crop 机制

该创新发生在数据预处理环节，替代了传统的合成数据生成流程。通常做法是利用渲染工具在背景上绘制新文本以生成配对数据，但这引入了合成域偏差。TextRIRO 提出 Algorithm 1 所示的自配对策略：给定真实图像 $I_{tgt}$ 及其文本标签 $T_{tgt}$，首先沿文本长轴将图像分割为 $L$（文本长度）个等宽片段 $B = \{B_1, ..., B_L\}$。以概率 $p_{shuffle}$ 随机打乱片段顺序得到 $B'$，否则保持原序；随后从 $B'$ 中随机选取连续子集拼接生成伪源图像 $I_{src}$。

$$ I_{src} = \text{Concat}(\text{Crop}(\text{Shuffle}(I_{tgt}, p_{shuffle}))) $$

该公式描述了从真实图像到伪源图像的映射过程。其物理含义是：通过打乱字符列顺序，破坏了文本的语义连续性（模型无法从 $I_{src}$ 读出原意），但保留了每个字符片段的局部外观（颜色、纹理、光照）；通过裁剪，进一步限制了模型可见的上下文范围，防止其利用全局布局线索作弊。这种构造迫使模型在重建 $I_{tgt}$ 时，必须从 $I_{src}$ 中提取风格特征，并根据 $T_{tgt}$ 重新排列和渲染字符，从而实现了无需显式解耦模块的风格-内容分离。

### 条件注入与训练目标

在模型架构层面，TextRIRO 改进了条件注入方式以适配自配对数据。通常做法是使用 CLIP 或合成字体预训练的文本编码器，但这类编码器对真实场景中的复杂字形感知能力较弱。TextRIRO 采用在真实场景文本识别（STR）任务上预训练的轻量级字符编码器，以自回归方式提取字符级特征 $F_{text}$。同时，使用 ViT 风格编码器提取 $I_{src}$ 的多尺度特征 $F_{style}$。

$$ \mathcal{L} = \mathbb{E}_{t, \epsilon} [ \| \epsilon - \epsilon_\theta(z_t, t, F_{style}, F_{text}) \|^2 ] $$

该公式为标准的噪声预测扩散损失。其算法含义是：模型 $\epsilon_\theta$ 在给定时间步 $t$、潜变量 $z_t$、风格特征 $F_{style}$ 和文本特征 $F_{text}$ 的条件下，预测添加的噪声 $\epsilon$。由于 $I_{src}$ 的语义已被破坏，模型无法通过“复制粘贴”源图像内容来降低损失，必须依赖 $F_{text}$ 提供的目标字符信息和 $F_{style}$ 提供的风格线索进行生成。这种设计消除了对显式解耦模块（如前景/背景分离网络）的需求，简化了架构并减少了误差累积。

## 实验评估

实验在 ScenePair 基准上进行，该基准提供真实世界的配对图像用于评估。基线覆盖 GAN 方法（SRNet, MOSTEL）、扩散方法（TextCtrl, AnyText, TextSSR）、统一多模态模型（RS-STE）及通用编辑模型（Flux.1 Kontext, Qwen-Image-Edit）。评估指标包括文本识别准确率（ACC）、归一化编辑距离（NED）和 Fréchet Inception Distance（FID，衡量视觉真实性）。

| Method | ACC (%)↑ | NED↑ | FID↓ |
| :--- | :--- | :--- | :--- |
| SRNet (2019) | 17.84 | 0.478 | 49.22 |
| MOSTEL (2023) | 37.69 | 0.557 | 49.19 |
| TextCtrl (2024) | 84.67 | 0.936 | 43.78 |
| RS-STE (2025) | 91.80 | 0.981 | 49.59 |
| TextRIRO (Ours) | 85.23 | 0.964 | 41.53 |
| Real (Upper Bound) | 88.44 | 0.974 | 0.00 |

TextRIRO 在 FID 上取得 41.53，显著优于依赖合成数据的 TextCtrl（43.78）和 RS-STE（49.59），表明其生成结果更接近真实分布。虽然 RS-STE 的 ACC（91.80%）高于 TextRIRO（85.23%），但 RS-STE 的 FID 较差，说明其通过牺牲视觉真实性换取了识别器友好的输出，存在过拟合识别器而非真实编辑能力的风险。TextRIRO 在保持高 ACC 的同时实现了最低的 FID，证明了自配对策略在平衡准确性与真实性上的优势。

| Operator | Straight (IC13) | Curved (CUTE) | Multi-oriented (SVTP) |
| :--- | :--- | :--- | :--- |
| Shuffle only | 79.00 | 54.83 | 66.67 |
| Crop only | 77.83 | 60.93 | 69.76 |
| Shuffle&Crop | 80.16 | 58.42 | 68.84 |

消融实验揭示了 Shuffle&Crop 的互补性：Shuffle 对水平文本（IC13）效果最佳，因为它最大程度破坏了左右语义顺序；Crop 对弯曲和多方向文本（CUTE, SVTP）更有效，因为它保留了局部倾斜和曲率。组合操作在整体性能上达到最优，验证了该数据构造策略对不同文本布局的适应性。

评估边界方面，TextRIRO 在 ScenePair 上的 ACC 仍低于真实图像上限（88.44%），且存在 10.10% 的精度差距源于编辑失败样本混入训练集。此外，论文未报告计算效率指标，且自配对策略对全新字体风格（训练集中未出现的字形）的泛化能力未单独测试。

## 关联研究分析

从数据依赖角度看，TextRIRO 与 TextCtrl 和 RS-STE 形成鲜明对比。TextCtrl 依赖合成数据进行隐式解耦，其性能瓶颈在于合成域与真实域的分布差异，导致风格迁移不自然。RS-STE 利用识别模型辅助编辑，虽提升了 ACC，但通过优化识别器损失而非视觉保真度，导致 FID 恶化。TextRIRO 通过自配对真实数据消除了合成域偏差，其优势根源在于直接利用真实图像的分布特性，而非通过模型架构去弥补数据缺陷。然而，RS-STE 的高 ACC 是否源于对特定识别器的过拟合，还是其确实具备更强的语义理解能力，论文未通过跨识别器评估完全排除前者可能性。

从任务协同角度看，TextRIRO 与 TextSSR 均探索了 STE 对 STR 的增益，但路径不同。TextSSR 通过掩码修复生成数据，受限于上下文风格缺失；TextRIRO 通过拼接编辑前后图像构建长文本数据集 TextRIRO-3M，显著提升了 STR 模型在长文本和多词场景下的性能（Union14M 基准提升 1.91%）。这一差异表明，STE 模型作为数据增强器的价值不仅在于生成新样本，更在于通过保持风格一致性来扩展数据分布的多样性。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

TextRIRO 针对 STE 任务中合成数据导致的域差距问题，提出了一种基于真实图像自配对的数据构造范式。通过 Shuffle&Crop 操作破坏文本语义但保留风格线索，结合条件扩散模型，实现了无需合成数据的真实感编辑。实验表明，TextRIRO 在 ScenePair 上取得了 41.53 的 FID，显著优于依赖合成数据的基线，并验证了其生成数据对下游 STR 任务的增益。该方法的边界在于对复杂非水平文本布局的鲁棒性依赖于 Crop 操作的有效性，且自配对策略可能限制了模型对训练集中未出现的全新字体风格的泛化能力。当面对极端弯曲或遮挡严重的文本时，Shuffle&Crop 能否保持风格线索的完整性，论文未给出明确回答。
