## 研究背景

当大语言模型处理百万级 Token 上下文时，自回归解码的每一步都需从 GPU 高带宽内存（HBM）读取整个键值缓存（KV Cache）至片上 SRAM 进行注意力计算。这种线性增长的内存流量使解码过程受限于内存带宽而非算力，成为长上下文推理的主要延迟瓶颈。稀疏注意力通过仅访问 KV Cache 的一小部分来缓解此问题，其核心假设是注意力分布的稀疏性，即少数“重击者”（Heavy Hitters）Token 贡献了绝大部分注意力质量。然而，在极端稀疏度下，注意力分布往往呈现长尾特性，确定性 Top-k 检索会丢弃非零但显著的残差注意力质量，导致输出与密集注意力存在显著偏差。

现有稀疏注意力方法主要分为三类：确定性检索、纯采样和混合方法。确定性检索（如 Quest, PQCache）通过代理分数选择高分 Token，但在分布弥散时丢失大量注意力质量；纯采样（如 MagicPig）通过重要性采样覆盖长尾，但引入高方差；混合方法（如 vAttention）结合 Top-k 与均匀采样，虽改善了覆盖度，但均匀采样忽略了残差 Token 中注意力质量的非均匀分布，导致在有限预算下仍与密集注意力存在较大差距。SSA 的切入点在于：残差 Token 的注意力质量并非均匀分布，而是高度非均匀的，因此应使用代理分数引导随机采样，而非均匀采样，以在保持低方差的同时有效捕获长尾注意力质量。

## 核心方法

### 方法参照系：稀疏注意力的预算分配范式

稀疏注意力的核心是在固定注意力预算 $k$ 下，从 $N$ 个缓存 Token 中选择子集 $K$ 进行精确计算。通用流程包括：(1) 计算代理分数 $\tilde{s}_i$；(2) 根据分数选择 Token 子集 $K$；(3) 对 $K$ 中的 Token 计算精确注意力并聚合。本文问题与该通用流程的关键差异在于子集 $K$ 的构建策略：传统方法采用确定性 Top-k 或均匀采样，而 SSA 采用分层策略，将预算 $k$ 自动划分为确定性保留的“重击者”集合 $H$ 和分数引导采样的“残差”集合 $S$，并通过逆概率加权校正采样偏差。

### 分层预算分配与分数引导采样

SSA 的核心创新在于将确定性检索与重要性采样统一于一个自适应框架中。首先，SSA 将代理分数 $\tilde{s}_i$ 转换为概率 $q_i = \exp(\tilde{s}_i) / \sum_j \exp(\tilde{s}_j)$，并寻找阈值 $\lambda$ 使得 $\sum_{i=1}^N \min(1, \lambda q_i) = k$。满足 $\lambda q_i \ge 1$ 的 Token 构成确定性保留的重击者集合 $H$，其大小 $h = |H|$ 由代理分布自动决定，无需手动设定。剩余预算 $m = k - h$ 用于从残差集合 $R = [N] \setminus H$ 中进行重要性采样。

在残差采样阶段，SSA 对 $R$ 中的概率进行归一化得到提议概率 $p_i = q_i / \sum_{j \in R} q_j$，并进行 $m$ 次有放回的多项式采样，保留唯一键值对构成集合 $S$。对于 $i \in R$，其被选中的包含概率为 $\pi_i = 1 - (1 - p_i)^m$。这一设计解决了 vAttention 等混合方法中均匀采样忽略残差注意力质量非均匀分布的问题，通过代理分数引导采样向更可能携带残差注意力质量的 Token 倾斜，从而在相同预算下捕获更多有效注意力质量。

### 逆概率加权校正与理论误差界

为消除采样偏差，SSA 对每个选中的 Token $i \in K = H \cup S$ 计算精确分数 $\ell_i = q^\top k_i / \sqrt{d}$，并应用逆概率加权校正权重 $\hat{w}_i = \exp(\ell_i) / \pi_i$。最终输出为归一化加权和：

$$
\hat{o} = \frac{\sum_{i \in K} \hat{w}_i v_i}{\sum_{i \in K} \hat{w}_i}
$$

该公式的物理含义是：通过除以包含概率 $\pi_i$，补偿了因采样概率不均导致的偏差，使估计量 $\hat{o}$ 成为密集注意力输出 $o$ 的无偏估计。SSA 提供了严格的理论误差界：在概率 $1-\delta$ 下，近似误差 $\|\hat{o} - o\|_2$ 与残差注意力质量 $A_R$、代理质量参数 $\rho$ 及采样预算 $m$ 相关，具体为 $\|\hat{o} - o\|_2 \le 4 \sqrt{\frac{A_R \rho}{\kappa(c) m} \log(4/\delta)} \|V\|_2$。这表明误差随采样预算 $m$ 的增加以标准蒙特卡洛速率 $m^{-1/2}$ 衰减，且代理分数越准确（$\rho$ 越小），误差越小。

## 实验评估

实验在 RULER、LongBench、LOFT 和 AIME 数据集上，对 Llama-3.1-8B、Qwen3.5 系列和 Ministral-3 系列模型进行评估，对比基线包括确定性检索（PQCache）、混合方法（vAttention）和理论上限（Oracle-top-k）。在 50× 稀疏度下，SSA 在 RULER-HARD 基准上显著优于基线。

| 模型 | 方法 | 32K | 64K | 128K |
| :--- | :--- | :--- | :--- | :--- |
| Ministral-3-8B | Dense | 91.95 | 91.11 | 89.45 |
| | PQ | 91.22 | 90.72 | 88.72 |
| | vAttn (PQ) | 90.56 | 90.61 | 89.28 |
| | Oracle-top-k | 91.39 | 90.39 | 89.39 |
| | SSA | 91.45 | 90.83 | 89.50 |
| Qwen3.5-4B | Dense | 93.45 | 92.22 | 91.28 |
| | PQ | 92.00 | 91.08 | 90.95 |
| | vAttn (PQ) | 91.67 | 91.30 | 90.61 |
| | Oracle-top-k | 92.56 | 92.28 | 91.39 |
| | SSA | 93.33 | 92.36 | 91.45 |

在 Ministral-3-8B 上，SSA 在 32K 上下文下达到 91.45%，超过 Oracle-top-k 的 91.39%，表明分数引导采样在极端稀疏度下能捕获确定性检索遗漏的注意力质量。在 Qwen3.5-4B 上，SSA 在 32K 下达到 93.33%，接近密集注意力的 93.45%，而 PQ 和 vAttention 分别为 92.00% 和 91.67%。SSA 在 128K 长上下文下仍保持显著优势，例如在 Ministral-3-8B 上 SSA 为 89.50%，而 PQ 为 88.72%，vAttention 为 89.28%。

消融实验显示，SSA 的自适应预算分配优于固定比例分配，且分数引导采样显著降低采样方差。然而，评估协议存在局限：未与低比特量化方法（如 KIVI, KVQuant）在相同内存预算下对比，且未报告端到端延迟与内存占用的三维帕累托前沿。代码已开源，但自适应算法的高效 GPU 实现仍为未来工作，当前实验使用固定重击者比例。

## 关联研究分析

从方法设计看，SSA 与 vAttention 同属混合稀疏注意力框架，但核心差异在于残差采样策略。vAttention 对残差 Token 进行均匀采样，假设残差注意力质量分布均匀；SSA 则利用代理分数引导采样，承认残差分布的非均匀性。这一差异源于对注意力长尾分布特性的不同假设：vAttention 侧重覆盖度，SSA 侧重效率。在长尾分布显著的场景下，SSA 的分数引导采样能更有效地将有限预算分配给高价值残差 Token，从而降低近似误差。

从问题动机看，SSA 与 PQCache 均使用乘积量化（PQ）码本计算代理分数，但目标不同。PQCache 旨在通过代理分数进行确定性 Top-k 检索，以加速 KV Cache 访问；SSA 则将代理分数作为重要性采样的提议分布，旨在通过随机采样捕获长尾注意力质量。PQCache 在注意力高度集中时有效，但在分布弥散时丢失质量；SSA 通过采样校正弥补了这一缺陷。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文要解决的核心矛盾是稀疏注意力在极端稀疏度下确定性检索丢失长尾注意力质量与随机采样引入高方差之间的权衡。SSA 抓住残差注意力质量非均匀分布这一被忽略的特性，通过分层预算分配与分数引导采样，统一了确定性检索与重要性采样。实验表明，SSA 在 50× 稀疏度下显著缩小了与密集注意力的精度差距，例如在 Ministral-3-8B 的 32K 上下文下达到 91.45%，超过 Oracle-top-k 的 91.39%。然而，SSA 仅减少内存带宽访问，未降低 KV Cache 显存占用，需与量化或驱逐方法组合使用。当显存容量仍是瓶颈时，SSA 的稀疏注意力与 2-bit 量化方法在长上下文任务上的帕累托前沿如何，论文未给出回答。
