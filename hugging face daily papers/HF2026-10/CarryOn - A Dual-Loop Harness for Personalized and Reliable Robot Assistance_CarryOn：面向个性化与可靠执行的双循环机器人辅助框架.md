# HuggingFace最新推荐论文 ｜CarryOn: A Dual-Loop Harness for Personalized and Reliable Robot Assistance ｜CarryOn：面向个性化与可靠执行的双循环机器人辅助框架

作者：Zixuan Wang、Yuqi Liu、Yuxin Chen 等 10 人

> 通用视觉-语言-动作（Vision-Language-Action, VLA）模型在开放环境中的操作泛化能力已获验证，但其在真实日常辅助场景中仍面临个性化决策缺失与物理执行脆弱性两大瓶颈。现有方法多聚焦于模型架构优化或端到端训练，忽略了运行时上下文管理与故障恢复机制的独立价值。CarryOn 提出一种围绕冻结 VLA 的双循环 Harness 架构，通过持久化记忆实现跨交互的个性化规划，并结合几何屏蔽与反思式恢复技能保障执行可靠性。该框架在安全违规率与故障恢复成功率上取得显著改善，但其对动态连续干扰的适应性及解耦架构在精细操作中的上限仍有待验证。

## 研究背景

当机器人执行“为我准备食物”这类日常指令时，其面临的挑战远超单一任务的动作预测。首先，指令本身往往隐含未明说的约束，如用户的素食偏好或特定物品的存放位置，这要求机器人具备跨对话的上下文记忆能力，即个性化（Personalization）。其次，物理世界的非结构化特性导致执行过程极易受干扰，如抓取失败或意外碰撞，这要求系统具备主动的安全防护与故障后的状态修复能力，即可靠执行（Reliable Execution）。传统 VLA 模型将感知、规划与控制耦合在单一神经网络中，难以在保持模型泛化能力的同时，灵活处理动态变化的用户偏好与突发的物理故障。

当前领域主流路线集中在优化 VLA 骨干网络的动作生成机制，如引入流匹配（Flow Matching）或扩散模型以提升控制精度，或通过大规模数据预训练增强语义理解。然而，这些方法在解决“看见-做到”差距时，往往将安全与恢复视为训练目标的一部分，导致模型在分布外（Out-of-Distribution, OOD）场景下仍表现出脆弱性。例如，即使经过安全微调的 VLA 模型，在复杂干扰下仍可能产生高比例的约束违规。此外，端到端架构难以在不重新训练的情况下，快速适应新用户的偏好或修正错误的场景记忆。CarryOn 的切入点在于将“决策”与“执行”解耦，通过外部 Harness 层接管上下文管理与安全监控，从而在不修改冻结 VLA 权重的前提下，实现个性化与可靠性的双重增强。

## 核心方法

### 双循环 Harness 架构参照系

CarryOn 将机器人辅助系统重构为围绕冻结 VLA 策略的双循环 Harness。该架构区别于传统的端到端 VLA 或分层规划-执行系统，其核心在于将规划循环（Planning Loop）与执行循环（Execution Loop）分离，并通过共享的任务上下文进行协同。规划循环负责基于持久化记忆生成子任务序列，执行循环负责在 VLA 输出动作后施加几何屏蔽与故障恢复。这一设计将高层语义推理与低层物理控制解耦，使得 VLA 仅作为动作生成器，而 Harness 负责上下文一致性、安全约束与故障修复。

### 基于持久化记忆的个性化规划

规划循环的核心创新在于维护可修订的用户记忆（User Memory）与场景记忆（Scene Memory）。用户记忆存储偏好与习惯，场景记忆存储物体位置与环境状态。当接收到指令时，规划器结合当前多模态请求、用户记忆与场景记忆生成子任务计划。若观测结果与记忆冲突（如记忆中为胡萝卜但实际为肉类），系统触发场景记忆更新操作，并重新规划后续步骤。这一机制解决了传统 VLA 无法跨对话保持偏好、且难以修正错误场景知识的问题。规划器通过指令 $c$ 与记忆 $M_u, M_s$ 生成计划 $P$，其中每个子任务指定指令 $\ell_i$ 与执行端点，确保决策与用户意图及环境状态动态对齐。

### 几何屏蔽与反思式恢复技能

执行循环包含主动几何屏蔽（Proactive Shielding）与被动反应式恢复（Reactive Recovery）。几何屏蔽在 VLA 输出动作块 $U_t$ 后、执行前介入，通过预测末端执行器与携带物体的运动轨迹，过滤可能导致碰撞的动作。其核心公式为动作释放前缀长度 $g$ 的计算：

$$
g = \min \left( \{ k \in \{0, \dots, H-1\} : \min_a (d_{a,k} - \delta_a) \le 0 \} \cup \{H\} \right)
$$

其中 $d_{a,k}$ 为第 $k$ 步时身体 $a$ 与障碍物的距离，$\delta_a$ 为安全阈值。该公式确保仅释放不会导致距离低于阈值的安全动作前缀，若首步即违规则执行后退。

当视觉判断器（Visual Judge）检测到子任务失败时，系统调用恢复技能库中的控制型技能进行修复。恢复技能通过离线反思（Offline Reflection）机制迭代优化：系统收集失败案例，由反思器分析失败原因并修订技能参数或策略，生成新版本技能存入库中。这一过程在不更新 VLA 权重的前提下，实现了恢复能力的跨尝试累积，解决了固定恢复策略无法适应多样化故障模式的问题。

## 实验评估

实验在真实机器人（Franka Research 3）与仿真环境（LIBERO-Safety, LIBERO-Recovery, RoboLab）上进行。基线覆盖包括原始 VLA、安全微调 VLA（$\pi_{0.5}$-SFT）、VLSA 安全层及纯 VLA 恢复策略。评估指标涵盖子任务分发准确率、违规率（Violation Rate）、违规无任务成功率（Violation-Free Success）及恢复成功率。

| 方法 | 违规率 (%) | 违规无任务成功率 (%) | 恢复成功率 (%) |
| :--- | :--- | :--- | :--- |
| $\pi_{0.5}$-SFT | 52.6 | 25.3 | - |
| $\pi_{0.5}$-SFT + VLSA | 37.7 | 25.4 | - |
| $\pi_{0.5}$-SFT + CarryOn | 6.1 | 25.6 | - |
| Pure VLA (Recovery) | - | - | 13.0 |
| CarryOn R0 (Base Skill) | - | - | 50.0 |
| CarryOn R2 (Refined) | - | - | 76.1 |

在安全评估中，CarryOn 将已安全微调的 $\pi_{0.5}$ 模型违规率从 52.6% 降至 6.1%，且未牺牲任务成功率（25.3% vs 25.6%）。在恢复评估中，纯 VLA 在物体移除扰动下的成功率为 13.0%，CarryOn 基础技能提升至 50.0%，经两轮反思优化后达到 76.1%。真实机器人实验中，恢复成功率从 3/20 提升至 18/20。

消融实验显示，反思轮次对恢复率提升显著：R0 至 R1 提升 23.9 个百分点，R1 至 R2 提升 2.2 个百分点，表明边际收益递减。在个性化规划中，记忆机制使偏好更新后的子任务准确率从 83.3% 提升至 100%（无更新时），场景记忆修正成功率达 76/88。

评估边界方面，实验主要覆盖离散扰动（如物体移除、静态障碍），对连续动态干扰（如移动障碍物）的适应性未充分测试。此外，恢复技能优化依赖离线反思，实时在线适应能力有限。代码已开源，但部分超参数（如反思轮次阈值）未在正文中详细披露。

## 关联研究分析

从问题动机看，CarryOn 与 RoboHarness 及 Harness VLA 同属“VLA 增强框架”路线，但差异显著。RoboHarness 侧重通过记忆编排异构策略，Harness VLA 结合冻结原语与分析操作，二者均未深入解决用户个性化偏好与场景记忆动态修订问题。CarryOn 将 LLM Agent 的记忆机制系统性引入机器人执行层，填补了个性化决策与物理执行之间的空白。然而，这种解耦是否牺牲了语义-动作对齐精度，论文未给出在需要紧密耦合的精细操作（如插入）中的对比数据。

从方法设计看，CarryOn 的几何屏蔽与 VLSA 的安全层机制类似，但 CarryOn 强调跨骨干迁移能力，在 OpenVLA-OFT 与 VLAct 上均验证了有效性。相比之下，VLSA 依赖特定策略的适配。在恢复机制上，CarryOn 的反思式技能库优于 FailSafe 等基于生成数据训练恢复策略的方法，因其无需重新训练 VLA，且通过版本化技能库实现了经验的累积。但反思机制的计算开销（API 令牌消耗）与实时性之间的权衡，论文仅提供了离线评估，未讨论在线部署的延迟影响。

## 总结

CarryOn 针对通用 VLA 模型在日常辅助场景中个性化缺失与执行脆弱性的核心矛盾，提出了一种围绕冻结 VLA 的双循环 Harness 架构。通过持久化记忆实现跨交互的个性化规划，结合几何屏蔽与反思式恢复技能保障执行可靠性。实验证明，该框架将安全违规率从 52.6% 降至 6.1%，恢复成功率从 13% 提升至 80%。其边界在于对连续动态干扰的适应性未充分验证，且解耦架构在精细操作中的性能上限尚不明确。当面对高速移动的障碍物或需要毫秒级响应的动态接触任务时，该 Harness 的离线反思机制与几何屏蔽的实时性是否足以支撑可靠执行，仍需进一步实证。
