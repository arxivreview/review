> 信息密集型图形生成要求模型在保持视觉美观的同时，精确渲染长文本并遵循复杂的空间排版约束。现有文本到图像模型多依赖后处理适配器或推理时注意力干预，难以在统一架构中实现像素级精确的文本-空间对齐，且缺乏将简短用户意图转化为详细设计规范的能力。MOSS-Image 通过从头预训练 5B 单流 Diffusion Transformer (DiT)，将自然语言与结构化布局统一编码为文本 Token，并引入智能体提示增强模块在推理时动态生成布局规范。该工作确立了 DiT 原生布局控制在长文本渲染任务上的优势，但其对闭源大语言模型的依赖及缺乏图像编辑能力限制了其在迭代设计工作流中的直接应用。

## 研究背景

当生成模型面对包含数百字符文本、多元素层级及严格空间关系的复杂图形（如信息图、用户界面）时，其核心挑战在于“渲染”与“规范”的耦合失效。渲染失效表现为长文本字符畸变、小字不可读及文本与图像元素重叠；规范失效则源于用户简短请求（如“设计一个考拉知识图”）未指定具体内容、信息层级及空间组织，导致模型生成的构图杂乱或语义缺失。传统布局控制方法如 GLIGEN 通过 U-Net 适配器注入边界框，虽解决了物体位置随机性，但暴露出空间控制与语义理解分离的架构瓶颈，难以处理文本内容本身的排版逻辑。

随着 Diffusion Transformer (DiT) 架构的普及，研究重心转向在统一 Transformer 中融合文本与空间信息。然而，现有 DiT 布局控制方法（如 Laytrol, ConsistCompose）多聚焦于通用场景下的物体空间放置，未充分解决长程文本渲染与排版一致性问题。此外，LLM 生成的布局规划往往无法被生成模型精确执行，存在“想得好画不准”的推理与执行脱节现象。MOSS-Image 针对这一缺口，提出将布局信息编码为文本 Token 通过统一条件路径处理，并利用智能体在推理时补全用户意图，以实现从简短请求到复杂图形的端到端生成。

## 核心方法

### 统一文本条件路径下的 DiT 架构

MOSS-Image 摒弃了 U-Net 适配器范式，采用 5B 单流 DiT 架构，其核心创新在于将自然语言描述与结构化布局指令（JSON 格式）统一编码为文本 Token，通过单一文本条件路径注入模型。这一设计解决了传统方法中空间控制模块与语义理解模块分离导致的架构耦合问题，使模型能够原生理解“文本内容”与“文本位置”的关联。

在 DiT 块中，模型使用联合自注意力机制处理文本与图像潜变量。为增强非线性表达能力，引入 SiTU-GLU 前馈网络。对于输入 $x$，其计算过程为：

$$
\text{FFN}(x) = W_o \left( c_{\beta_g}(g) \odot \text{sigmoid}(g) \odot c_{\beta_u}(u) \right)
$$

其中 $g = W_g x$，$u = W_u x$，$c_{\beta}(v) = \beta \tanh(v/\beta)$ 为平滑饱和函数，$\odot$ 表示逐元素乘法。该公式通过门控机制动态调节特征流，相比标准 GLU 在保持梯度稳定的同时提升了模型对复杂排版指令的拟合能力。

### 4D RoPE 位置编码与布局对齐

为精确编码文本在图像中的空间位置，MOSS-Image 采用 4D 旋转位置编码 (RoPE)。每个查询或键头被划分为四个子空间，分别对应参考索引 $r$、序列位置 $t$、宽度 $w$ 和高度 $h$。对于坐标 $p = (r, t, w, h)$，RoPE 应用独立旋转：

$$
\text{RoPE}_{4D}(z, p) = [R_r(r)z_r; R_t(t)z_t; R_w(w)z_w; R_h(h)z_h]
$$

其中 $R_a(p_a)$ 为旋转矩阵。在无参考图像输入时，$r=0$ 使参考子空间保持未旋转状态，而其他轴编码序列与空间位置。这一设计使模型能够区分文本的语义顺序（$t$）与空间坐标（$w, h$），从而在去噪过程中更准确地对齐字符内容与像素位置，解决了长文本渲染中常见的字符错位问题。

### 智能体提示增强与结构化布局规划

针对用户请求信息稀疏的问题，MOSS-Image 引入基于 GPT-6 的智能体提示增强 (PE) 模块。该模块在推理时执行任务路由、知识检索和布局规划，将简短请求转化为包含边界框、字体属性及文本内容的 JSON 规范。与仅输出自然语言提示的生成器无关智能体不同，该模块直接生成 DiT 可执行的结构化布局指令。

智能体输出的布局 JSON 包含元素类型、文本内容、位置（bbox）及排版属性。例如：
`{"type":"text", "text":"all you\nneed is\nlove", "where":"center", "bbox":[420,350,780,700]}`
这一设计将意图级规划与渲染器的文本-空间控制接口直接连接，弥补了语义空间与像素空间之间的映射鸿沟，确保模型在生成时严格遵循指定的信息层级与空间组织。

## 实验评估

实验在 LongLongTextBench (LLTB)、7Bench 和 RealLayoutArena (RLA) 上进行。LLTB 评估长文本渲染能力，7Bench 评估布局控制精度，RLA 评估端到端系统性能。基线覆盖 GPT Image 2、Seedream 5.0 Pro 等闭源模型及 Qwen Image、FLUX.2 等开源模型。

| 方法 | EN-S | EN-M | EN-L | ZH-S | ZH-M | ZH-L | Mean-6 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| GPT Image 2 | 99.8 | 99.8 | 97.3 | 99.4 | 99.2 | 98.2 | 99.0 |
| Nano Banana Pro | 98.8 | 99.6 | 97.4 | 98.1 | 94.2 | 91.4 | 96.6 |
| Qwen Image 3.0 Pro | 89.8 | 94.3 | 96.2 | 98.9 | 97.9 | 88.5 | 94.3 |
| **MOSS-Image** | **98.0** | **97.1** | **97.1** | **96.3** | **96.7** | **92.4** | **96.3** |
| Qwen Image 2512 | 88.8 | 86.7 | 48.1 | 89.9 | 44.4 | 31.3 | 64.9 |

在 LLTB 上，MOSS-Image 以 96.3 的 Mean-6 得分在开源模型中领先，较 Qwen Image 2512 提升 31.4 个百分点，接近闭源模型 GPT Image 2 的水平。在 7Bench 布局控制上，MOSS-Image 的 mIoU 达到 0.88，显著高于 Ideogram 4 的 0.44，验证了统一文本条件路径在空间定位上的有效性。

在 RLA 端到端评估中，MOSS-Image 以 1698.70 Elo 排名第二，仅次于 GPT Image 2。在共享增强自然语言提示的对比中，MOSS-Image 以 1807.34 Elo 排名第一，表明其骨干网络在接收详细指令时具有最强的执行能力。消融实验显示，JSON 布局提示（1622.87 Elo）优于自然语言提示（1506.20 Elo），证实了结构化规范对复杂排版生成的必要性。

评估边界方面，RLA 依赖人工盲测，存在主观偏差；LLTB 虽覆盖长文本，但未评估文本与图像元素的遮挡交互。代码与模型权重已开源，但智能体模块依赖闭源 GPT-6 API，限制了完全本地化部署。

## 关联研究分析

从方法设计看，MOSS-Image 与 ConsistCompose 均基于 DiT 架构实现布局控制，但 ConsistCompose 通过 MoT 架构将布局语义编码为文本令牌嵌入语言流，侧重多模态理解生成的原生集成；MOSS-Image 则通过 4D RoPE 和统一文本条件路径，更强调文本内容本身的空间排版对齐。这一差异源于任务特性：ConsistCompose 面向通用物体布局，而 MOSS-Image 面向信息密集型图形，后者要求模型不仅知道“物体在哪里”，还要知道“文字怎么排”。

从推理时优化看，MOSS-Image 与 RPG/AgentComp 均利用 LLM 进行布局规划，但 RPG 输出自然语言提示，AgentComp 侧重组合性奖励优化，而 MOSS-Image 的智能体直接输出结构化 JSON 布局。这一设计选择解决了 LLM 规划与生成模型执行之间的“语义-像素”映射鸿沟，但引入了对外部 LLM 的强依赖。当 LLM 的审美判断或事实检索出现偏差时，即使渲染器完美执行，最终结果仍可能不符合用户意图，这一风险在论文中未被量化评估。

## 总结

MOSS-Image 针对信息密集型图形生成中渲染精度与意图规范的双重缺失，提出了一种结合原生 DiT 布局控制与智能体提示增强的端到端系统。其核心在于通过统一文本条件路径和 4D RoPE 实现文本内容与空间位置的精确对齐，并利用智能体将简短请求转化为可执行的 JSON 布局规范。实验表明，该模型在长文本渲染（LLTB Mean-6 96.3）和布局控制（7Bench mIoU 0.88）上达到开源 SOTA，并在端到端评估中仅次于 GPT Image 2。然而，系统依赖闭源 LLM 进行规划，且不支持图像编辑与参考图像条件生成，限制了其在迭代设计工作流中的应用。当智能体生成的布局规范与用户隐含的审美偏好冲突时，模型是否具备基于视觉反馈的自修正能力，论文未给出回答。
