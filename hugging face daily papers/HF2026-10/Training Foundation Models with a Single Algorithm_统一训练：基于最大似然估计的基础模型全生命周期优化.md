> 导读 基础模型训练通常被划分为预训练、中训练、监督微调（Supervised Fine-Tuning, SFT）和强化学习（Reinforcement Learning, RL）等独立阶段，各阶段依赖不同的数据分布与优化算法。这种算法层面的割裂导致模型在阶段切换时面临能力退化与算力分配低效的问题，且难以通过单一理论框架解释跨阶段的能力演化。现有方法多通过正则化或参数隔离缓解灾难性遗忘，却未触及训练算法本身的统一性。本文提出统一训练框架，通过推导 RL 目标的最大似然等价形式，将全生命周期训练转化为单一似然目标下的动态数据混合问题。该框架在受控推理任务中验证了算力效率与能力保留的双重优势，但其有效性目前局限于二元奖励与合成任务，在复杂真实场景下的泛化能力尚待验证。

## 研究背景

当基础模型从通用语料学习转向特定任务适配时，训练过程通常被固化为预训练、中训练、SFT 和 RL 的串行流水线。每个阶段拥有独立的训练配方与基础设施，被视为分离的学习问题。这种范式将设计决策锚定在阶段边界上，导致模型在阶段切换时面临分布突变，进而引发灾难性遗忘与算力分配次优。尽管参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）通过冻结主干缓解了部分遗忘，但其本质仍是在分阶段框架内修补，未解决算法割裂的根本矛盾。

领域研究长期聚焦于单阶段的缩放定律或跨阶段的经验性迁移分析，缺乏对全生命周期训练轨迹的统一理论刻画。预训练缩放定律描述了数据、算力与性能的关系，而 RL 缩放研究则关注策略优化效率，两者在数学形式上互不兼容。这种割裂使得研究者难以判断早期训练决策如何联合决定最终模型能力。本文指出，算法分离并非训练过程的本质属性，而是特定数据混合策略的产物。通过将 RL 转化为最大似然拟合，预训练、SFT 与 RL 可被纳入同一学习算法，从而将核心设计问题从“选择何种算法”转变为“如何演化数据分布”。

## 核心方法

### 方法参照系：分阶段训练与最大似然估计

传统基础模型训练遵循分阶段范式，各阶段使用不同的损失函数与数据源。预训练、中训练和 SFT 均基于最大似然估计（Maximum Likelihood Estimation, MLE），通过最小化负对数似然拟合静态数据分布。RL 则通常被表述为策略优化问题，通过奖励反馈优化模型生成的补全。本文的关键差异在于，它不将 RL 视为独立的优化算法，而是通过理论推导将其重构为对模型生成目标分布的似然拟合，从而消除算法边界。

### 核心创新：RL 的最大似然等价形式

传统 RL 目标通过策略梯度优化期望奖励，其梯度形式与 MLE 的梯度形式在数学上存在显著差异，导致无法直接混合训练。本文基于最大似然强化学习（Maximum Likelihood Reinforcement Learning, MaxRL）理论，证明在二元奖励下，MaxRL 梯度可等价于对当前策略成功条件分布的似然拟合。对于给定提示 $x$，模型成功概率为 $p_\theta(x)$，成功条件分布为 $\pi^+_\theta(y|x)$。MaxRL 更新可视为固定 $\pi^+_{\theta_t}$ 时的 MLE 更新：

$$
L(\theta; \rho \circ \pi^+_{\theta_t}) = -\mathbb{E}_{x \sim \rho} \mathbb{E}_{y \sim \pi^+_{\theta_t}(\cdot|x)} [\log \pi_\theta(y | x)]
$$

该公式表明，RL 更新在数学形式上与预训练完全一致，仅目标分布从静态语料变为模型自身生成的成功样本分布。这一推导打破了 RL 与 MLE 的算法壁垒，使得 RL 数据可与静态数据在同一损失函数下混合。设计动机在于消除阶段切换时的算法不连续性，使模型能在单一优化器下同时学习静态知识与动态策略。

### 核心创新：统一数据混合与异步训练架构

在确立统一损失函数后，本文构建了支持静态数据与 RL 生成数据混合的训练系统。所有数据源被表示为统一的 $(z, w)$ 格式，其中 $z$ 为 token 序列，$w$ 为 token 权重。预训练与中训练使用单位权重，SFT 对提示 token 赋零权重，RL 则根据奖励与采样通过率计算响应权重 $A$。统一损失函数定义为：

$$
\hat{L}(\theta; B) := -\frac{1}{T_B} \sum_{(z,w) \in B} \sum_{\ell=1}^{L} w_\ell \log \pi_\theta(z_\ell | z_{<\ell})
$$

其中 $T_B$ 为批次中非提示 token 总数。该公式通过权重 $w$ 统一了不同数据源的贡献，使得混合比例成为唯一的设计变量。系统采用异步架构，生成器基于近期权重采样 RL 数据并附加至共享缓冲区，训练器从缓冲区采样并周期性发布权重。这一设计允许数据源在训练过程中动态重叠与混合，而非严格串行，从而支持对数据混合比例与时间调度的连续优化。

## 实验评估

实验在受控推理任务（Reasoning Gym 风格谜题）与真实代码任务（HumanEval+）上评估统一训练。基线为分阶段训练（Staged Training），使用 MaxRL 作为 RL 阶段算法以确保对比公平性。评估指标包括准确率（pass@1）、覆盖率（pass@16）及通用能力保留度。由于论文未提供具体数值表格，以下基于文字描述进行审计。

在受控设置中，统一训练在 Base 与 Extended 任务上均优于分阶段训练，尤其在 Extended 泛化测试中表现出更强的分布外鲁棒性。算力匹配对比显示，分阶段训练在中等算力预算下准确率更优，但统一训练在最小与最大算力预算下均实现更高准确率，且在覆盖率指标上分阶段训练更具优势。这一反直觉发现表明，统一训练的优势依赖于算力规模与任务复杂度，并非在所有设置下均占优。

消融实验揭示了数据混合比例与调度的权衡。增加中训练数据比例可提升数学性能但损害代码能力，线性衰减调度能在保留数学增益的同时减少代码性能损失。持续学习实验显示，经过统一训练初始化的模型在后续代码 RL 任务中收敛更快且最终性能更高，验证了统一训练作为持续学习起点的优势。评估边界方面，实验仅覆盖二元奖励与合成任务，未验证连续奖励或复杂指令遵循场景，且未报告置信区间，数值比较需谨慎。

## 关联研究分析

从问题动机看，本文与任务向量（Task Vector）研究存在深层关联但路径迥异。Task Arithmetic 将微调知识解耦为参数差值，支持事后线性组合；本文则通过统一似然目标，在训练过程中动态混合数据源，隐含了任务知识在参数空间连续演化的假设。Task Arithmetic 依赖模型间激活分布相似性，而本文通过异步生成器解耦生成与优化，降低了对模型架构一致性的依赖。然而，本文未显式提取任务向量，其“数据混合”是否等价于参数空间的线性叠加，论文未给出理论证明。

从方法设计看，本文与 LoRA 等 PEFT 方法形成互补而非竞争。LoRA 通过低秩约束限制更新空间以缓解遗忘，本文则通过数据混合在参数空间内显式保留通用能力。两者可结合使用：在统一训练框架下，LoRA 适配器可作为轻量级组件处理特定数据源，而主干网络通过统一损失学习全局分布。但本文未探索 PEFT 与统一训练的结合，查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文针对基础模型分阶段训练导致的算法割裂与能力退化问题，提出统一训练框架，通过推导 RL 的最大似然等价形式，将全生命周期训练转化为单一似然目标下的动态数据混合问题。实验表明，统一训练在同等算力下可提升推理任务准确率与覆盖率，并增强持续学习起点性能。然而，其有效性目前局限于二元奖励与合成任务，在复杂真实场景下的泛化能力尚待验证。当奖励信号从二元验证转向连续偏好或复杂多目标优化时，统一似然框架的稳定性与收敛性是否仍能保持，论文未给出回答。
