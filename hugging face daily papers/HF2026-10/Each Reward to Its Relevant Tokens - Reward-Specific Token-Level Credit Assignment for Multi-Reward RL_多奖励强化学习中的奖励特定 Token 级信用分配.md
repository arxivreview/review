> 导读 在多奖励强化学习中，现有方法如 GDPO 虽解决了奖励组合的区分问题，但仍将响应级优势均匀广播至所有 Token，导致关键决策点与无关 Token 获得相同梯度，造成信用稀释。MRTPO 抓住验证器拥有特权信息这一被忽略的特性，提出通过自回放机制量化 Token 对特定奖励的依赖程度。该方法在无需外部模型或标注的情况下，将各奖励的优势精准重分配至相关 Token。MRTPO 在文本转 SQL、指令遵循等任务上验证了细粒度归因的有效性，但其依赖特权信息文本化的假设限制了其在非文本化奖励场景的适用性。

## 研究背景

当大语言模型面对包含格式、正确性等多维约束的任务时，单一奖励信号无法区分不同维度的贡献。组相对策略优化（Group Relative Policy Optimization, GRPO）通过组内归一化消除了对 Critic 网络的依赖，成为主流基线。然而，GRPO 将多个奖励求和后计算优势，导致不同奖励组合可能映射到相同的优势值，即奖励坍缩。奖励解耦归一化（Group Decoupled Policy Optimization, GDPO）通过分别归一化每个奖励再求和，解决了这一区分度问题。但 GDPO 及其变体（如 SAW）仍停留在响应级加权，将聚合后的优势均匀分配给响应中的所有 Token。这种均匀分配隐含了“每个 Token 对每个奖励同等负责”的假设，而实际上验证器通常仅评估响应的特定部分。例如，格式错误仅由标签 Token 决定，但均匀分配会将格式惩罚施加于所有 Token，包括正确生成的参数，从而稀释了关键错误步骤的学习信号。

信用分配机制旨在解决长序列推理中稀疏奖励导致的中间步骤学习信号不足问题。现有细粒度归因方法主要依赖过程奖励模型（Process Reward Models, PRM）或基于熵的启发式规则。PRM 需要大量人工标注中间步骤，且易过拟合特定推理模式；基于熵的方法虽无需标注，但仅重加权聚合后的优势，无法区分不同奖励的具体贡献 Token。MRTPO 的切入点在于利用验证器自身的特权信息（如参考 SQL、执行错误日志）。既然验证器依据这些信息做出判断，那么移除这些信息后模型预测的变化程度，即可作为 Token 与该奖励相关性的代理指标。这一思路将信用分配从“响应级加权”推进至“奖励特定的 Token 级归因”，填补了多奖励场景下细粒度因果归因的空白。

## 核心方法

### 方法参照系：多奖励组优化与均匀分配失效

在多奖励强化学习框架下，对于每个提示 $x$，策略采样 $G$ 个响应，每个响应由 $K$ 个验证器评分。GDPO 的标准流程是先对每个奖励 $k$ 进行组内标准化得到优势 $A_k^{(j)}$，再求和得到响应级优势 $S^{(j)}$，最后将该优势均匀分配给响应中的每个 Token $t$，即 $A_t^{(j)} = S^{(j)}$。这一流程在响应级解决了奖励区分问题，但在 Token 级失效：当响应包含多个奖励维度时，无关 Token 会接收到与其无关的奖励梯度，导致关键决策点的信号被噪声淹没。MRTPO 保留了 GDPO 的奖励解耦归一化步骤，但改变了优势在 Token 维度的分配方式。

### 核心创新：基于特权信息自回放的 Token 相关性量化

MRTPO 的核心在于通过自回放（Self-replay）机制量化每个 Token 对特定奖励的依赖程度。对于每个奖励 $k$，构建两个上下文：$P_{all}$ 包含所有验证器的特权信息块 $Z_{K_x}$，$P_{\backslash k}$ 移除奖励 $k$ 的信息块 $Z_k$。这两个上下文仅相差 $Z_k$，因此模型在两者下预测分布的差异直接反映了 $Z_k$ 对预测的影响。

$$ q_{k,t} = \frac{JS(p_t^{\backslash k}, p_t^{all})}{\ln 2} \in [0, 1] $$

该公式计算 Token $t$ 在移除信息 $Z_k$ 前后，下一 Token 预测分布的 Jensen-Shannon (JS) 距离，并归一化至 $[0, 1]$。$q_{k,t}$ 越高，表明该 Token 的预测越依赖于奖励 $k$ 的特权信息，即该 Token 与奖励 $k$ 的相关性越强。这一设计动机在于利用模型自身的预测敏感性替代外部标注，实现了无监督的细粒度归因。

### 核心创新：基于相关性的优势重分配

获得相关性分数 $q_{k,t}$ 后，MRTPO 将奖励 $k$ 的优势 $A_k^{(j)}$ 按相关性重新分配至 Token。权重 $w_{k,t}$ 定义为：

$$ w_{k,t} = (1 - \beta) + \beta \frac{q_{k,t}}{\bar{q}_k} $$

其中 $\bar{q}_k$ 是响应中所有 Token 相关性分数的均值，$\beta \in [0, 1)$ 控制分配强度。该公式确保平均相关性为 1 的 Token 权重为 1，高相关性 Token 获得更高权重，且每个 Token 至少保留 $1-\beta$ 的均匀优势。最终 Token 级优势 $A_t^{(j)}$ 为所有奖励加权优势之和：

$$ A_t^{(j)} = \frac{\sum_{k=1}^{K} A_k^{(j)} w_{k,t}}{\text{std}_B(S)} $$

这一重分配机制使得格式奖励的优势主要落在标签 Token 上，执行奖励的优势主要落在查询语句的关键部分，从而解决了均匀分配导致的信用稀释问题。

## 实验评估

实验在文本转 SQL（Spider/BIRD）、指令遵循（IFEval/IFBench）和工具调用（BFCL-v4）三个任务上进行。基线包括 GRPO、GDPO、OPSD（在线自蒸馏）和 CoRT（Token 级方法）。MRTPO 在所有任务上均优于 GDPO，且在指令遵循任务上增益最大，表明多奖励场景下均匀分配的噪声效应随奖励数量增加而加剧。

| 方法 | Spider Dev (%) | Spider Test (%) | BIRD Dev (%) | Average (%) |
| :--- | :--- | :--- | :--- | :--- |
| GDPO | 79.21 | 80.62 | 55.11 | 71.55 |
| OPSD | 79.11 | 80.39 | 53.87 | 71.49 |
| MRTPO | 81.33 | 81.65 | 56.42 | 73.15 |

*表：Qwen2.5-Coder-7B-Instruct 在文本转 SQL 任务上的执行准确率。MRTPO 较 GDPO 平均提升 1.60 个百分点。*

消融实验验证了归因位置的重要性。若打乱 Token 权重位置（Shuffled pos.），性能降至 71.03%，低于 GDPO，证明增益源于将优势分配至特定 Token 而非仅调整权重分布。联合回放（Joint replay）虽优于 GDPO，但低于 MRTPO，说明各奖励需独立归因。超参数 $\beta$ 对性能影响显著，$\beta=0.5$ 在多数任务上表现最佳，但最优值存在任务依赖性。

评估边界方面，MRTPO 要求验证器信息可文本化，无法处理如响应长度等非文本化奖励。此外，自回放增加了前向传播开销，尽管论文指出仅 12%-21% 的响应-奖励对需要回放，但在超长序列任务中的扩展性仍需验证。

## 关联研究分析

从问题动机看，MRTPO 与 OPSD 均利用特权信息，但目标截然不同。OPSD 将特权信息用于构建教师分布，通过蒸馏替代奖励最大化，其教师需看到完整参考解；MRTPO 仅利用特权信息计算 Token 相关性，奖励仍是优化目标。实验显示 OPSD 在文本转 SQL 上低于 MRTPO，表明策略仅需验证器使用的局部信息即可实现有效归因，无需完整参考解。这一差异揭示了在信用分配任务中，信息粒度与归因精度的匹配关系。

从方法设计看，MRTPO 与 CoRT 同属 Token 级方法，但归因依据不同。CoRT 基于 Token 熵或整体 Rubric 重加权聚合优势，无法区分不同奖励的贡献；MRTPO 基于单奖励验证器信息的因果差异，实现了奖励特定的归因。在多约束指令遵循任务中，MRTPO 在 IFBench（未见约束）上显著优于 CoRT，证明其归因机制具有更好的泛化性。然而，CoRT 无需构建上下文对，计算开销更低，MRTPO 在计算效率与归因精度之间的权衡尚未在大规模训练中充分量化。

## 总结

MRTPO 针对多奖励强化学习中响应级优势均匀广播导致的信用稀释问题，提出利用验证器特权信息通过自回放量化 Token 相关性，并将各奖励优势重分配至相关 Token。该方法在文本转 SQL 任务上较 GDPO 平均提升 1.60 个百分点，在指令遵循任务上显著优于基线，验证了细粒度归因的有效性。其边界在于依赖特权信息的文本化表示，且自回放机制引入了额外计算开销。当验证器信息无法文本化或序列长度极大时，该方法的适用性与效率是否仍能保持，论文未给出回答。
