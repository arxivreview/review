> 数据视频生成旨在将原始表格数据转化为包含动态图表、语音旁白和同步动画的时序叙事，以解决传统静态可视化缺乏叙事逻辑、像素级生成模型存在数值幻觉的问题。现有工具或依赖预制作图表，或无法保证数据溯源，难以实现端到端自动化。本文提出 DATAMAGIC，通过声明式规范 DVSPEC 统一音视频表示，并结合“生成-编排”多智能体策略实现全局叙事协同。该方法在 109 个真实样本上将平均质量分从 2.13 提升至 3.89，执行成功率稳定在 95% 以上，但动画创意多样性受限于结构化约束。

## 研究背景

数据视频的核心难点在于跨模态时序对齐与数据保真度的耦合。传统制作流程中，动画触发依赖硬编码的时间戳或 DOM 标识符，一旦数据更新或图表类型变更，引用即失效，导致大量返工。为解决此问题，系统需建立一种基于数据属性而非渲染标识的语义引用机制，确保视觉元素可溯源至底层数据记录。同时，旁白与动画的同步不能依赖人工计算绝对时间，而需一种声明式触发机制，将时序对齐延迟至渲染阶段，从而解耦内容创作与时间控制。

数据视频生成领域长期面临“局部准确”与“全局连贯”的矛盾。单阶段端到端生成方法（如直接调用 LLM 生成代码）在处理多场景叙事时，易因上下文窗口限制导致早期决策锁定，产生叙事重复或覆盖缺口；而逐场景顺序生成则缺乏全局视角，难以保证宏观叙事逻辑（如从宏观到微观）。现有自动化工具如 Data Playwright 虽支持叙事中心的工作流，但需以预制作图表为起点，无法从原始数据提取洞察；像素级模型如 Sora 虽能端到端合成，但其黑盒特性导致数值幻觉且无法溯源。DATAMAGIC 的切入点在于将视频生成建模为分层内容编排问题，通过声明式中间表示统一约束，并在多智能体框架中分离场景生成与全局编排，以同时满足数据保真度与叙事连贯性。

## 核心方法

### 声明式视频规范（DVSPEC）

DVSPEC 将数据视频形式化为元数据 $M$ 与有序场景序列 $S$ 的组合，即 $V := (M, S)$。每个场景 $s_i$ 定义为五元组 $(id, type, content, narration, animation)$，其中 $content$ 封装图表配置与数据绑定，$narration$ 为旁白片段序列，$animation$ 为动画效果列表。该设计动机在于解决传统工具中跨模态引用脆弱的问题：通过数据驱动的语义引用替代硬编码标识符，确保数据更新时引用依然有效。

### 生成-编排多智能体策略

针对设计空间组合爆炸问题，DATAMAGIC 采用两阶段策略。第一阶段并行生成候选场景，第二阶段全局编排。场景生成阶段，故事规划器、数据管理器与视觉设计师协作产生多样化候选；编排阶段，旁白导演与动画协调器基于洞察价值与查询覆盖度选择并排序场景。该策略解决了单模型长程任务中的逻辑断裂问题，通过解耦局部生成与全局决策，避免了顺序生成中的决策锁定。

$$
s_i := (id, type, content, narration, animation)
$$

其中 $animation$ 中的每个效果 $a_l$ 定义为四元组 $(type, target\_data, trigger, style)$，$trigger$ 为旁白索引而非绝对时间戳，实现声明式音视频同步。

### 数据绑定与语义引用

DVSPEC 的核心创新在于通过数据属性值而非渲染标识符引用视觉元素。例如，动画目标 $target\_data$ 指向数据字段中的特定值（如“4K Monitor”），而非 DOM ID。这一设计确保了当数据切片或图表类型变更时，引用自动重绑定，无需重新计算时间戳。该机制直接解决了像素级生成模型无法溯源数据记录的问题，为交互式编辑提供了基础：用户修改数据或脚本时，系统仅重渲染受影响场景，保持跨模态绑定不变。

## 实验评估

实验在 109 个真实世界样本上进行，对比基线包括 GPT-5、DeepSeek-V3.2、Gemini-2.5-Pro 和 Claude-Sonnet-4 的直接生成方法。评估维度涵盖意图、洞察、叙事、动画和美学五个方面。直接生成方法执行成功率波动大（48.62%–86.24%），平均质量分最高仅为 2.13（GPT-5）。DATAMAGIC 在所有基座模型上均将执行成功率提升至 95% 以上，平均质量分达到 3.89（使用 Claude-Sonnet-4 时），较最佳直接生成模型提升 83%。

| 方法 | 执行成功率 (%) | 平均质量分 (/5) |
| :--- | :--- | :--- |
| GPT-5 (Direct) | 86.24 | 2.13 |
| DeepSeek-V3.2 (Direct) | 48.62 | 1.91 |
| DATAMAGIC (Claude-Sonnet-4) | 98.17 | 3.89 |
| DATAMAGIC (DeepSeek-V3.2) | 96.33 | 3.44 |

消融实验表明，移除故事规划器使平均分从 3.89 降至 3.44（降幅 11.6%），其中叙事和动画维度下降最显著（15.1% 和 13.7%）；移除编排模块使平均分降至 3.54（降幅 9.0%），意图维度受影响最大（12.4%）。值得注意的是，即使移除编排模块，动画维度仍保持 3.95 的高分，验证了 DVSPEC 声明式触发机制在音视频同步上的鲁棒性，不依赖全局编排。

用户研究（N=12）显示，DATAMAGIC 将任务完成时间从 39.2 分钟缩短至 8.0 分钟（减少 79.7%），并在 NASA-TLX 的五个维度上显著降低认知负荷。然而，评估边界存在局限：实验未包含像素级视频生成模型（如 Sora）作为基线，无法直接对比数据保真度与视觉真实感的权衡；此外，动画多样性受限于结构化提示词，可能导致创意表达受限，论文未提供量化指标评估此代价。

## 关联研究分析

从问题动机看，DATAMAGIC 与 CoDA 同属多智能体生成框架，但 CoDA 聚焦静态图表生成，通过搜索智能体获取代码示例解决长上下文问题；DATAMAGIC 则扩展至动态视频，核心挑战从代码正确性转向时序同步与叙事连贯。CoDA 依赖数据驱动的自我反思修正错误，而 DATAMAGIC 通过 DVSPEC 的声明式约束在生成前即保证结构合规，这种差异源于视频介质对时序精度的刚性要求，静态图表可容忍局部错误，视频则需全局时序一致。

从方法设计看，DATAMAGIC 与 Data Playwright 均支持叙事中心工作流，但 Data Playwright 以预制作图表为输入，通过 LLM 建立语义链接；DATAMAGIC 从原始数据出发，通过多智能体并行生成候选场景。这一差异决定了 Data Playwright 无法处理数据洞察提取，而 DATAMAGIC 需解决设计空间搜索问题。然而，DATAMAGIC 的“生成-编排”策略在场景数量增加时，编排阶段的全局优化复杂度可能呈指数增长，论文未讨论此扩展性瓶颈，也未提供大规模场景（>7 个）的性能衰减数据。

## 总结

DATAMAGIC 解决了数据视频生成中数据保真度与叙事连贯性难以兼得的核心矛盾，通过 DVSPEC 声明式规范统一音视频表示，并以“生成-编排”多智能体策略实现全局协同。实验证明其在 109 个样本上将质量分提升至 3.89，执行成功率稳定在 95% 以上，显著优于直接生成方法。然而，系统依赖结构化动画模式以保证可靠性，可能抑制创意多样性；且编排阶段的全局优化在场景数量增加时的计算开销未经验证。当场景数量超过 7 个时，编排阶段的全局搜索是否会导致性能显著下降，论文未给出回答。
