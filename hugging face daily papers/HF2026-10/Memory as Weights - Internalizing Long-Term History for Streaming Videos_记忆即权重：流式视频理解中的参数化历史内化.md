> 导读 流式视频理解的核心矛盾在于无限累积的历史观测与有限上下文窗口之间的物理冲突，传统方法通过压缩或检索将历史重新注入输入，导致历史记忆与当前观测在注意力机制中竞争资源。MaLoW 提出了一种范式转移：将历史上下文内化为模型权重的动态更新，而非输入序列的扩展。该框架利用循环超网络（HyperNetwork）将视频片段增量整合为低秩适应（LoRA）权重，使基础视觉语言模型（VLM）仅处理当前观测即可访问长期记忆。这一设计消除了上下文竞争，在保持实时感知能力的同时显著提升了回溯性任务的性能，但其权重容量饱和机制与极端长视频下的遗忘风险仍需进一步验证。

## 研究背景

当流式视觉语言模型（Streaming Vision-Language Model, VLM）处理实时视频流时，每一帧新观测都要求模型在严格因果约束下整合过去、现在与未来的信息。为了在有限显存中维持长程依赖，现有主流方案通常采用滑动窗口或记忆压缩机制，将历史视频片段编码为文本摘要、视觉 Token 或键值缓存（Key-Value Cache, KV Cache），并在推理时将其重新拼接到当前输入序列中。这种“检索-注入”范式虽然缓解了显存溢出，却引入了结构性缺陷：历史记忆与当前观测被迫共享有限的注意力上下文窗口，导致模型在需要精细感知当前场景时，注意力资源被冗长的历史 Token 稀释，造成实时响应延迟与感知精度的双重下降。

随着视频时长的增加，上下文爆炸问题愈发严峻。尽管近期研究如 VST 和 HERMES 通过分层记忆或动态 KV 缓存优化了存储效率，但它们本质上仍依赖于在输入空间中显式保留或重构历史信息。这种设计使得模型难以在“记住过去”与“看清现在”之间取得平衡，尤其是在需要回溯早期关键细节（如 Episodic Memory 任务）时，压缩后的历史往往丢失细粒度语义。MaLoW 的切入点在于彻底解耦记忆载体与输入通道：既然参数可以存储知识，为何不将历史直接编码进模型权重？通过让历史以权重形式存在，当前观测得以独占输入通道，从而在架构层面消除了记忆与感知的竞争。

## 核心方法

### 方法参照系：流式记忆的标准范式与失效点

在标准的流式视频理解流程中，模型在时间步 $t$ 接收当前观测 $C_t$ 和用户指令 $I_t$，并依赖历史上下文 $C_{0:t-1}$ 生成响应 $R_t$。通常做法是将 $C_{0:t-1}$ 压缩为固定长度的 Token 序列 $M_t$，并与 $C_t$ 拼接后输入 VLM。这一流程的关键差异在于 MaLoW 完全移除了输入端的历史 Token，转而通过参数更新 $\Delta\theta_t$ 来承载 $C_{0:t-1}$ 的信息，使得推理公式变为 $R_t = M_{\theta + \Delta\theta_t}(I_t, C_t)$。

### 循环超网络与增量权重生成

MaLoW 的核心创新在于使用循环超网络（Recurrent HyperNetwork）$\Phi$ 来生成 LoRA 权重。该超网络接收压缩后的历史上下文表示，并输出低秩矩阵更新。具体而言，超网络由单步更新函数 $f$ 递归构成，其状态更新与权重生成过程如下：

$$
h_t, \Delta\theta_t = f(h_{t-1}, C_{t-1})
$$

其中 $h_t$ 是隐藏状态，$\Delta\theta_t$ 是应用于基础 VLM 的 LoRA 权重。这一设计动机在于避免传统方法中因历史 Token 堆积导致的注意力稀释。通过将历史“固化”为权重，模型在推理时无需重新计算历史 Token 的注意力分数，从而降低了计算复杂度并保留了当前观测的注意力带宽。

### 双分支隐藏状态更新机制

为了在权重中同时保留局部时序动态和全局语义，MaLoW 将隐藏状态 $h_t$ 分解为两个并行分支：状态空间模型（State-Space Model, SSM）分支 $m_t$ 和门控求和分支 $s_t$。SSM 分支利用 DeltaNet 捕捉视频流中的局部时间依赖，而门控求和分支则通过跳过连接保留长期语义。其更新公式为：

$$
s_t = s_{t-1} + \beta_{t-1} q_{t-1}, \quad \text{with } \beta_{t-1} = \mathbb{I}[\text{sim}(\bar{V}_{t-1}, \bar{V}_{t-2}) \leq \beta]
$$

这里 $\beta_{t-1}$ 是基于相邻视频片段余弦相似度的二值门控，当场景变化显著时（相似度低），门控开启以更新全局语义。这一机制解决了固定窗口方法在场景突变时记忆断裂的问题，确保权重更新能自适应地响应视频内容的动态变化。

## 实验评估

实验在 OVO-Bench、StreamingBench 和 StreamArena 上进行，基线覆盖了离线 VLM、局部窗口流式模型及多种记忆增强方法。MaLoW 在记忆关键任务上取得了显著突破，但在实时感知任务上表现与基线持平或略低，验证了权重化记忆在回溯性任务上的优势。

| 方法 | 骨干模型 | OVO-Bench Backward (%) | StreamingBench Real-Time (%) | OVO-Bench Overall (%) |
| :--- | :--- | :--- | :--- | :--- |
| VST-7B | Qwen2.5-VL-7B | 62.0 | 79.5 | 62.0 |
| HERMES-7B | Qwen2.5-VL-7B | 59.2 | 79.4 | 59.2 |
| StreamTTT-4B | Qwen2.5-VL-4B | 69.0 | 81.3 | 69.0 |
| MaLoW (Qwen3.5-9B) | Qwen3.5-9B | 71.3 | 82.3 | 71.3 |
| MaLoW (MOSS-VL-Real-11B) | MOSS-VL-Real-11B | 74.5 | 81.0 | 74.5 |

在 OVO-Bench 的 Backward 分割（侧重回溯记忆）上，MaLoW (Qwen3.5-9B) 达到 71.3%，超越 StreamTTT-4B 的 69.0% 和 VST-7B 的 62.0%。在 StreamingBench 的 Real-Time 分割上，MaLoW (Qwen3-VL-4B) 取得 84.8% 的 SOTA 成绩，显著高于 TimeChat-Online 的 75.28%。这表明权重内化机制在保持实时响应能力的同时，有效提升了长程记忆精度。

消融实验显示，MaLoW 引入的额外参数量仅为 1.4%-4.0%，且 LoRA 生成可与骨干推理并行，延迟开销可控。然而，评估协议存在局限：StreamArena 的 HR 分割测试了极长视频（>1小时）下的记忆稳定性，MaLoW 在 L4 层级（最长回溯）的准确率为 15.7%，虽优于基线但绝对值较低，暗示权重容量在极端长程任务中可能接近饱和。此外，论文未报告在音频-视频多模态同步下的权重更新延迟，限制了其在具身智能全双工场景中的适用性评估。

## 关联研究分析

从记忆载体设计看，MaLoW 与 StreamTTT 代表了“记忆移出上下文”的两种路径。StreamTTT 维护一个独立的测试时训练（Test-Time Training, TTT）分支，通过在线更新快速权重来存储历史，而 MaLoW 直接将历史内化至 VLM 自身的 LoRA 权重中。StreamTTT 的独立分支设计允许更灵活的遗忘机制，但引入了额外的分支计算开销；MaLoW 的集成设计则通过共享骨干网络降低了部署复杂度，但可能因权重更新干扰基础模型的预训练知识。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

从任务适配性看，MaLoW 与 VST 在推理时机上存在本质差异。VST 利用查询前的流式间隔进行显式文本推理，构建双记忆系统，其优势在于可解释性和多步推理能力；MaLoW 则通过隐式权重更新实现记忆，无需显式文本中间态，更适合低延迟场景。然而，VST 的显式记忆在需要复杂逻辑组合的任务上可能更具鲁棒性，而 MaLoW 的隐式权重在遭遇分布外（Out-of-Distribution）视频内容时，其泛化能力尚不明确。

## 总结

MaLoW 针对流式视频理解中历史记忆与当前观测竞争上下文窗口的核心矛盾，提出了“记忆即权重”的新范式。通过循环超网络将历史观测增量内化为 LoRA 权重，该框架在 OVO-Bench Backward 任务上达到 71.3% 的准确率，显著超越了基于 Token 压缩的基线方法。这一设计证明了参数化记忆在保持实时感知精度的同时，能有效提升长程回溯能力。然而，论文在极端长视频（>1小时）下的权重饱和效应及多模态同步下的延迟开销尚未充分验证。当视频流持续超过数小时，LoRA 权重的容量边界是否会引发早期关键信息的灾难性遗忘，仍需更严格的长期稳定性测试来回答。
