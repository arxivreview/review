> 交互式视频世界模型旨在构建能够感知、交互并预测物理世界演化的内部模拟器，其核心价值在于弥合被动视频生成与主动具身智能之间的鸿沟。现有纯视频生成路线受限于隐式状态，难以保证长时程逻辑一致性，而传统游戏引擎虽具备显式状态，却面临高昂的视觉资产制作成本。AgentGarten 提出“代码世界”框架，将引擎的显式状态管理与神经渲染器的视觉合成解耦，通过结构化条件驱动实时渲染。该架构在保持物理规则严格性的同时实现了高保真视觉多样性，但其在缺乏精确几何条件的真实世界中的泛化能力仍存疑。

## 研究背景

当智能体在虚拟环境中学习时，其能力上限受限于环境的保真度与多样性。传统游戏引擎通过显式状态和可编程规则支持代理学习，但扩展视觉多样性需要大量 3D 资产创建，导致新环境构建成本高昂。相反，视频世界模型能从数据中合成丰富的交互式视觉观察，但其任务相关状态和物理转换规则隐含在生成的历史中，无法直接检查、编辑或测试环境行为。这一矛盾构成了当前具身智能环境构建的核心瓶颈：如何在保持状态与规则严格可控的同时，实现低成本、高保真的视觉生成。

领域内主流路线在“实时交互架构”与“具身智能应用”之间做出了不同取舍。纯视频生成路线如 Genie 和 GameNGen 确立了动作条件化生成范式，但依赖隐式状态导致长时程一致性难以维持，且缺乏对物理规则的显式约束。具身智能应用路线如 ABot-PhysWorld 通过 DPO 后训练抑制非物理行为，但依赖高质量标注且后训练复杂。AgentGarten 的切入点在于将“状态管理”与“视觉渲染”解耦：引擎负责维护持久化状态和执行显式交互规则，神经渲染器负责根据结构化条件生成视觉观察。这种解耦使得新环境可以通过代码编写，无需为每个场景创建定制视觉资产，从而突破了传统引擎与纯视频模型各自的局限。

## 核心方法

### 方法参照系：代码世界架构

AgentGarten 将交互式世界建模问题置于“代码世界”框架下，其核心差异在于将状态演化与视觉生成分离。标准视频世界模型直接预测未来观测 $O_{t+1:T}$，状态隐含在生成历史中；而 AgentGarten 中，引擎更新状态 $s_{t+1}$ 并导出结构化条件 $c_t$，神经渲染器 $R_\theta$ 仅根据条件、视觉历史 $x_{<t}$、外观参考 $x_0$ 和文本 $y$ 生成观测 $x_t$。这一架构确保了渲染误差不会累积到状态中，因为状态转换 $f_p$ 不接收渲染观测作为输入。

### 几何条件化与块因果自回归

为了将预训练双向视频模型适配为受引擎条件约束的渲染器，AgentGarten 引入几何条件化与块因果自回归机制。传统视频扩散模型通常直接生成像素，缺乏对几何结构的显式控制。本文使用颜色化深度或表面法线作为结构化条件，通过空间平均池化减少 token 数量，并复用预训练 RGB 输入投影 $W_{in}$ 加上零初始化模态嵌入 $e_{geo}$ 形成条件 token：

$$ G_t = W_{in} \mathcal{P}([E(S(c))]_t) + e_{geo} $$

该公式表明几何条件通过冻结的视频编码器 $E$ 和空间池化 $S$ 提取特征，再投影到与 RGB 相同的潜在空间。设计动机在于避免通道拼接或控制分支带来的像素对齐归纳偏置，允许几何与 RGB token 在序列维度上联合注意力，从而在保持几何对齐的同时允许跨 token 交互。

在自回归生成阶段，本文采用并行教师强制（Parallel Teacher Forcing）机制。训练时在单个 Transformer 中使用每个块的两个副本：干净副本 $P_j$ 代表历史，噪声副本 $Q_j$ 用于去噪。注意力掩码允许 $Q_j$ 读取参考 $A_0$、之前的干净块 $P_{<j}$ 和自身 $Q_j$，但绝不读取其自身的干净目标。这种设计使得所有目标块可以并行训练，同时保持块间因果依赖，解决了标准自回归训练效率低下的问题。

### Adversarial Forcing 与 Exact Replay

为了将教师强制模型蒸馏为实时渲染器，本文提出 Adversarial Forcing，结合分布匹配与真实数据对抗训练。标准 Self Forcing 方法在长时程滚动中会出现视觉退化，且历史编码计算不可微，导致后续损失无法更新历史编码参数。本文引入 Exact Replay 机制，通过两遍训练解决这一问题：第一遍无梯度滚动记录每个块的输入和输出，第二遍可微重放重新计算历史编码和预测，确保重放轨迹与采样轨迹在数值上逐位一致（bitwise identical）。

$$ z_{\theta,j} = \text{sg}(U_j) - t^* v_\theta(\text{sg}(U_j), t^* | \text{sg}(Z_{<j}), \mathcal{C}; \mathcal{M}_{TF}) $$

该公式表明，在重放阶段，历史键值被重新计算并组装在计算图中，使得后续损失能够更新写入历史缓存的参数，而无需对采样轨迹进行微分。这一设计消除了 SGF 风格全序列 FlexAttention 重放中因内核差异导致的数值发散（3.99% 相对 $L_2$ 误差），实现了零误差重放。

此外，为抑制分布匹配在长时程中的视觉退化，本文引入真实数据对抗目标。由于融合注意力内核不支持双反向传播，本文推导了针对冻结骨干网络的精确 R1/R2 正则化方案，通过一次向量-雅可比积和一次雅可比-向量积计算精确惩罚，避免了双反向传播的计算开销。

## 实验评估

实验在单 NVIDIA H100 GPU 上进行，评估了重放精度、推理吞吐量及视觉质量。基线对比主要集中于 Self Forcing 及其变体，缺乏与 Genie、GameNGen 等纯视频世界模型在相同计算预算下的直接对比。

| 指标 | SGF-style (FlexAttention) | Ours (block-by-block SDPA) | 变化 |
| :--- | :--- | :--- | :--- |
| 重放误差 (相对 $L_2$) | 3.99% | 0 (bitwise) | — |
| 前向时间 | 2.95 s | 2.79 s | -5.4% |
| 峰值分配内存 | 50.83 GiB | 50.92 GiB | +0.2% |

Exact Replay 机制实现了逐位一致的重放，消除了数值发散，同时前向时间减少 5.4%，内存开销仅增加 0.2%。这一结果验证了块级 SDPA 重放在保持梯度路径正确性方面的有效性。

在稳态推理中，渲染器在单 H100 上以 36.5 fps 生成 480×832 视频，满足实时交互需求。消融实验显示，Adversarial Forcing 相比 Self Forcing 在 30 秒滚动中保留了自然纹理和细节，避免了重复表面模式的出现。然而，评估主要依赖自建 Hide-and-Seek 环境，缺乏在 LIBERO、DROID 等标准机器人操作基准上的量化结果，限制了其跨域泛化能力的评估。

## 关联研究分析

从问题动机看，AgentGarten 与 GameNGen 均试图利用神经渲染替代传统游戏引擎的渲染管线，但两者在状态管理上存在根本差异。GameNGen 依赖游戏引擎内部状态直接驱动生成，状态与视觉耦合紧密，难以支持灵活的规则编辑；AgentGarten 通过“代码世界”抽象，将状态管理完全委托给引擎，渲染器仅作为视觉合成器，这种解耦使得环境可以通过代码动态生成，无需修改渲染器权重。这一差异源于对“可编程性”的不同理解：GameNGen 侧重于现有游戏的视觉替换，而 AgentGarten 侧重于新环境的快速构建。

从方法设计看，AgentGarten 的 Exact Replay 机制与 Self Gradient Forcing (SGF) 形成直接对比。SGF 通过全序列 FlexAttention 重放实现历史梯度回传，但受限于内核差异导致数值发散；AgentGarten 通过块级 SDPA 重放保持执行结构一致，实现零误差重放。这一改进解决了自回归蒸馏中历史编码不可微的关键瓶颈，但查询侧增强在数据充足时是否仍有增益，论文未给出回答。此外，与 ABot-PhysWorld 等通过 DPO 后训练抑制非物理行为的方法相比，AgentGarten 通过引擎显式规则保证物理一致性，避免了后训练的复杂性，但依赖精确的几何条件输入。

## 总结

AgentGarten 针对交互式世界模型中状态持久性与视觉多样性难以兼得的矛盾，提出“代码世界”解耦架构，通过引擎维护显式状态、神经渲染器合成视觉观察，实现了可编程、高保真的实时交互环境。其核心创新 Adversarial Forcing 结合 Exact Replay 机制，解决了自回归蒸馏中历史梯度回传与视觉退化问题，在单 H100 上实现 36.5 fps 实时渲染。然而，该方法依赖引擎导出的精确几何条件，在缺乏结构化条件的真实世界场景中泛化能力受限，且缺乏在标准机器人操作基准上的量化评估。当几何估计存在噪声或遮挡时，渲染器对条件误差的鲁棒性如何，论文未给出回答。
