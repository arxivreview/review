# HuggingFace最新推荐论文 ｜Semifactual Credit-Augmented Policy Optimization ｜半事实信用增强策略优化

研究机构：浙江大学、西湖大学

作者：Junshu Pan、Zhizhang Fu、Shulin Huang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2609.40360)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.40360)

> 强化学习可验证奖励（RLVR）旨在通过自动验证结果提升大语言模型推理能力，但模型对任务无关的提示特征仍存在隐性依赖，导致分布外泛化脆弱。现有组相对策略优化（GRPO）将序列级奖励均匀分配给所有 Token，无法区分关键推理步骤与受无关特征干扰的噪声 Token，致使正向奖励可能强化虚假关联。SCAPO 通过半事实提示干预测量固定响应的 Token 概率漂移，仅将负向稳定性分数作为去梯度修正项加入优势函数，在训练初期抑制不稳定 Token 的信用。该方法在 Qwen3-4B-Base 上将 AIME 2024–2026 准确率提升 5.63 个百分点，但仅验证了数学领域，且未解决长序列中的信用分配粒度问题。

## 研究背景

当模型面对包含无关背景信息的数学题时，其预测概率会随提示措辞变化而波动，这种对任务无关特征的敏感性被称为虚假依赖。虚假依赖导致模型在分布外任务上性能骤降，而传统强化学习仅关注最终答案的正确性，无法在训练过程中识别并抑制这种 Token 级的脆弱性。因果不变性理论指出，若模型依赖的是真实因果特征，其预测应在干预下保持稳定；反之，若预测随干预大幅漂移，则表明模型依赖了虚假特征。

RLVR 范式确立了基于可验证奖励的训练流程，GRPO 作为其代表算法，通过组内相对奖励消除 Critic 网络依赖，大幅降低了计算开销。然而，GRPO 的优势函数 $A_i$ 对响应中所有有效 Token 施加相同权重，这种均匀分配机制无法捕捉 Token 级的语义差异。近期研究证实，RLVR 虽能减少部分虚假相关，但模型对输入扰动仍高度敏感，且现有改进多聚焦于探索机制或熵正则化，缺乏从因果视角重构信用分配信号的尝试。SCAPO 的切入点在于将半事实干预引入训练过程，利用 Token 概率漂移作为虚假依赖的代理指标，在无需外部奖励模型的情况下实现细粒度信用修正。

## 核心方法

### 方法参照系

GRPO 的标准流程是采样一组响应，计算组内奖励均值与标准差，得到轨迹级优势 $A_i = \frac{R_i - \mu_R}{\sigma_R + \epsilon_A}$，并将其应用于该响应的所有 Token。本文的关键差异在于，GRPO 假设所有 Token 对结果的贡献等同，而 SCAPO 认为 Token 对任务无关特征的敏感性不同，需引入半事实稳定性信号修正优势函数。

### 半事实概率漂移测量

设计动机在于，标准解码无法区分 Token 是依赖数学逻辑还是依赖提示中的无关措辞，导致虚假关联被强化。SCAPO 首先构造四类半事实扰动（改写、拼写错误、场景包装、无关上下文），保持数学问题与答案不变。对于固定响应 $y_i$，在原始提示 $x^{(0)}$ 和扰动提示 $x^{(k)}$ 下，通过教师强制计算同一 Token $y_{i,t}$ 的概率 $p^{(0)}_{i,t}$ 和 $p^{(k)}_{i,t}$。Token 级漂移定义为有界对称距离：

$$
d^{(k)}_{i,t} = \tanh\left(\frac{\log p^{(0)}_{i,t} - \log p^{(k)}_{i,t}}{2}\right)
$$

该公式通过归一化局部平均概率，消除了低概率 Token 的尺度偏差，并将漂移限制在 $[-1, 1]$ 区间，确保数值稳定性。对四类扰动取平均得到 $\bar{d}_{i,t}$，量化了 Token 对提示变化的敏感程度。

### 负向稳定性信用增强

设计动机在于，稳定性本身不等同于正确性，若奖励稳定 Token 可能抑制探索，因此仅惩罚不稳定 Token。SCAPO 在组内对所有有效 Token 的负向漂移进行标准化，得到相对稳定性分数 $u_{i,t}$。仅保留其负值部分 $u^-_{i,t} = \min(u_{i,t}, 0)$，并乘以系数 $\lambda$ 加入 GRPO 优势：

$$
\hat{A}_{i,t} = A_i + \lambda \cdot \text{sg}(u^-_{i,t})
$$

其中 $\text{sg}$ 表示停止梯度，确保修正项不参与反向传播。该设计使得不稳定 Token 的优势降低，而稳定 Token 的优势保持不变，从而在训练初期（前 $N_0$ 步）抑制虚假依赖的强化，随后切换回标准 GRPO 优化。

## 实验评估

实验在 DAPO-Math-17K 上训练 Qwen3-4B-Base 和 Qwen3-1.7B-Base，对比 GRPO、GSPO、SAPO、CF-GRPO 和 FIPO。基线覆盖了序列级优化、平滑门控及反事实掩码等路线，但缺失 DAPO、SSVPO 等 2025–2026 年最新的步骤级信用分配方法，限制了与当前 SOTA 的直接对比。

| 基准 | 模型 | GRPO | SCAPO | 提升 |
| :--- | :--- | :--- | :--- | :--- |
| AIME 24–26 | 4B | 22.08 | 27.71 | +5.63 |
| AIME 24–26 | 1.7B | 7.71 | 11.88 | +4.17 |
| GPQA-Diamond | 4B | 36.26 | 42.45 | +6.19 |
| GPQA-Diamond | 1.7B | 27.42 | 31.25 | +3.83 |

SCAPO 在两个模型规模上均优于所有基线，且在分布外基准（NoOp-AIME、ThinkBench-AIME、GPQA-Diamond）上取得最高准确率，表明半事实稳定性信号有效提升了泛化能力。

消融实验显示，仅负向修正（Negative-only）优于全符号（All-sign）和仅正向（Positive-only）修正，验证了“稳定性不奖励，不稳定才惩罚”的设计原则。随机打乱稳定性分数（Random shuffle）导致性能接近 GRPO，证明信号的有效性依赖于 Token 与漂移的对应关系。计算开销方面，半事实探测仅占训练总时间的 1.8%，远低于自回归生成（52.7%），且仅在训练初期执行，不影响后续优化效率。

评估边界方面，论文未报告置信区间，且 AIME 题目数量少（30 题/年），高方差可能影响结论稳健性。代码已开源，但超参数 $\lambda_0$ 和 $N_0$ 的敏感性分析缺失，不同模型规模下的最优值可能不同。

## 关联研究分析

从问题动机看，SCAPO 与 CF-GRPO 均试图解决 Token 级信用分配粗糙问题，但 CF-GRPO 基于反事实掩码推理跨度，依赖外部过程奖励模型或复杂的掩码策略，而 SCAPO 仅利用模型自身的概率漂移，无需额外监督。这一差异源于任务特性：CF-GRPO 假设推理跨度具有明确的因果边界，而 SCAPO 认为虚假依赖是 Token 级的局部现象，无需显式步骤分割。SCAPO 的轻量级设计使其更易集成，但可能忽略跨 Token 的长程依赖。

从方法设计看，SCAPO 与 EP-GRPO 均使用 Token 级不确定性信号，但 EP-GRPO 基于熵门控，关注探索-利用平衡，而 SCAPO 基于半事实稳定性，关注因果不变性。EP-GRPO 的熵信号反映模型内部置信度，可能受训练阶段影响；SCAPO 的漂移信号反映模型对提示变化的敏感性，更直接关联虚假依赖。两者在数学推理任务上的表现差异，可能源于信号来源的不同：熵信号在训练初期可能不稳定，而漂移信号在固定响应下更可预测。

## 总结

SCAPO 针对 GRPO 中 Token 级虚假依赖导致的泛化脆弱问题，利用半事实干预测量 Token 概率漂移，通过负向稳定性修正优势函数，在训练初期抑制不稳定 Token 的信用。该方法在 Qwen3-4B-Base 上将 AIME 2024–2026 准确率提升 5.63 个百分点，并在分布外基准上取得最佳性能，证明了因果不变性信号在 RLVR 中的有效性。然而，论文仅在数学领域验证，且未探索半事实稳定性在长序列或复杂逻辑任务中的适用性。当推理链长度超过 1000 Token 时，Token 级漂移信号是否仍能准确捕捉虚假依赖，而非被长程噪声淹没，论文未给出回答。
