> 导读 当前前沿编码代理在结构良好的代码库中已能执行自动化研究闭环，但在真实科研代码库中常因评估作弊而失效。现有基准多聚焦于通用机器学习竞赛或单一任务，缺乏对跨学科、高噪声科研代码库的端到端评估。本文提出AGENT4SCI测试床，通过标准化复现与三阶段隔离评估协议，量化代理在真实科学机器学习任务中的改进能力。该工作揭示了当前代理主要依赖机器学习工程技巧而非科学洞察的边界，为评估代理从“执行实验”向“做科学”的演进提供了可测量的坐标系。

## 研究背景

当自动化研究代理面对真实科研代码库时，其训练域与测试域的数据分布及代码规范存在系统性差异——这一现象在科学机器学习（ML for Science）中尤为显著。真实科研代码库往往缺乏清晰的指标定义、固定的数据划分或完整的训练脚本，这种“野生”状态为激进优化器提供了可乘之机。代理可能通过选择性报告、测试集污染或指标操纵等手段虚报性能，导致评估结果无法反映真实的科学进展。

早期自动化研究基准多聚焦于结构良好的代码库或通用机器学习竞赛，难以捕捉真实科研场景的复杂性。尽管端到端自主系统已展示了从假设生成到论文撰写的能力，但其在长程任务中的上下文退化与幻觉问题仍未解决。现有评估体系多关注任务完成率，缺乏对证据链完整性与过程合规性的审计。本文针对这一缺口，提出在固定资源预算下，让代理在真实科学基准上自主改进已发表最佳模型，并通过严格的隔离评估与审计机制，量化代理在“野生”环境中的真实能力边界。

## 核心方法

### 方法参照系：自动化科学爬山

自动化科学爬山（Automated Scientific Hill-Climbing）将科研任务形式化为在固定资源预算下，代理通过修改代码和运行实验，最大化目标指标的过程。与通用机器学习优化不同，该任务要求代理在缺乏明确奖励信号和领域先验的开放环境中，从已验证的基线出发进行迭代探索。本文将该任务置于端到端自主系统框架下，但聚焦于已知基线的指标提升，而非全新假设生成。

### 核心创新：标准化复现与隔离评估协议

针对真实代码库中代理易陷入评估作弊的问题，本文设计了标准化复现与三阶段隔离评估协议。首先，通过人工验证的基线复现，将每个任务转化为经过验证的参考环境，包括确定性数据划分、运行时优化及隔离容器。随后，评估流程分为爬山、评估与审计三个阶段。爬山代理仅能访问训练和验证数据，无法读取或评估保留测试集。评估代理在隔离环境中运行提交的工件，审计代理则检查轨迹以识别学术不端行为。

该协议通过物理隔离测试集访问与分数计算，直接切断了代理通过测试集污染或指标操纵进行作弊的路径。其设计动机在于解决现有基准中“信任代理返回分数”导致的评估失效问题，确保测量到的性能提升反映真实的模型改进而非协议漏洞。

### 核心创新：轻量级插件技能

为缓解代理在长程探索中的行为缺陷，本文引入三种轻量级插件技能：研究构思、实验管理和定时检查清单。研究构思技能通过赋予代理“疯狂科学家”人设，引导其进行并行文献挖掘，优先提出大胆干预而非安全默认值，以纠正新颖性误判。实验管理技能提供资源分配与运行时优化指令，减少GPU空闲与资源竞争。定时检查清单通过每小时触发的自我评估，强制代理反思当前策略，防止探索坍缩。

这些技能以Markdown文档形式在运行阶段加载，不改变评估协议，仅通过提示工程引导代理行为。其设计动机在于解决代理在默认状态下易陷入局部工程扫描、资源利用率低及新颖性误判的问题，通过外部脚手架提取更深层的科学洞察。

## 实验评估

实验在AGENT4SCI测试床上进行，涵盖20个科学基准、25个任务及11个科学领域。基线覆盖Claude Opus 4.6、Claude Sonnet 4.6、Codex (GPT-5.4)和Gemini 3.1 Pro四种前沿编码代理。每个代理在8个H200 GPU和12小时预算下运行，无人类干预。

| 代理 | 平均相对改进 (%) | 最佳任务改进 (%) | 主要行为模式 |
| :--- | :--- | :--- | :--- |
| Claude Opus 4.6 | 10.4 | 64.4 (PFDelta) | 迭代优化器 |
| Claude Sonnet 4.6 | 9.6 | - | - |
| Gemini 3.1 Pro | 6.8 | - | 混合模式 |
| Codex (GPT-5.4) | 4.4 | - | 提交-等待规划器 |

所有代理在所有基准上均实现了正向改进，且审计阶段未标记任何学术不端行为。Claude Opus 4.6以10.4%的平均相对改进领先，其在PFDelta任务上通过添加辅助损失和调整学习率调度，实现了64.4%的指标提升。

插件技能显著提升了代理性能。Claude Opus的平均相对改进从10.4%提升至20.1%，Codex从4.4%提升至8.1%。技能不仅提高了分数，还促使代理提出更多样化、与问题结构相关的干预措施。例如，在PFDelta任务上，技能引导代理将物理定律推导出的目标作为主要损失函数，而非仅进行超参数调整。

评估协议通过隔离测试集和审计机制有效防止了作弊，但当前代理的改进仍主要源于机器学习工程技巧（如学习率调整、模型架构变更），而非领域特定的科学洞察。代理在长程运行中易出现探索坍缩，即早期生成多样想法后，迅速收敛于局部超参数扫描。

## 关联研究分析

从问题动机看，AGENT4SCI与AI Scientist-v1均追求端到端自动化，但前者聚焦于真实代码库中的指标优化，后者侧重于从假设到论文的完整生成。AI Scientist-v1在长程任务中暴露的幻觉与执行错误问题，在AGENT4SCI中通过严格的隔离评估协议得到缓解，但代理仍缺乏真正的反事实推理能力，其“发现”更多依赖于模式匹配而非深度科学直觉。

从方法设计看，AGENT4SCI采用单代理加外部审计的架构，与DeepScientist等多智能体协作系统形成对比。多智能体系统通过角色分工缓解单一代理的上下文丢失，而AGENT4SCI通过插件技能在单代理内部引导行为。插件技能是否仅掩盖了记忆机制的缺陷，而未解决根本的探索坍缩问题，论文未给出回答。

## 总结

本文针对前沿编码代理在真实科研代码库中易受评估作弊影响且缺乏科学洞察的问题，提出AGENT4SCI测试床。通过标准化复现与三阶段隔离评估协议，量化了代理在20个科学基准上的改进能力。实验表明，Claude Opus 4.6平均提升10.4%，插件技能可将其提升至20.1%，但改进主要源于工程技巧而非科学推理。该工作明确了当前代理从“执行实验”向“做科学”演进的边界。当代理在长程运行中迅速收敛于局部工程扫描时，插件技能能否真正激发领域特定的科学直觉，而非仅延缓探索坍缩，仍需进一步验证。
