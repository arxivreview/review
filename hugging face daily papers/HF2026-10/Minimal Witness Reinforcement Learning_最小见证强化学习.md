> 现有强化学习范式在求解“最小充分条件”类问题时，往往陷入单一解坍缩或冗余超集陷阱，无法恢复任务中所有互不包含的最小见证集合。本文指出，标准组相对策略优化（GRPO）等方法的奖励函数是提案可分离的，即每个提案的奖励独立计算，导致策略无法区分“新发现的最小见证”与“已发现见证的冗余超集”。MWRL 通过引入基于集合覆盖的删除信用机制，将组内提案的验证器比特转化为对覆盖区域边际贡献的归因，从而在仅依赖二元验证器反馈的条件下，实现了对完整最小见证反链的恢复。该工作将强化学习的目标从单一解优化扩展至多解族恢复，但在非单调验证器下的鲁棒性边界仍需进一步界定。

## 研究背景

当系统故障诊断或化学反应条件筛选需要识别“哪些因素组合足以导致结果”时，答案往往不是唯一的。例如，服务器宕机可能由电源故障单独引起，也可能由两块镜像磁盘同时故障引起，这两组条件互不包含且均不可再简化，构成了最小充分见证的反链。在布尔逻辑中，这对应于主合取项（Prime Implicants）的枚举；在科学发现中，对应于关键变量子集的识别。然而，这些任务通常不提供显式的逻辑公式，仅暴露一个黑盒验证器，输入一个条件子集，输出二元比特表示该子集是否充分。

传统强化学习算法如 PPO 和 GRPO 将验证器比特作为奖励，通过组内相对优势估计更新策略。然而，这类方法的奖励函数是提案可分离的，即每个提案的奖励仅取决于其自身的验证结果，而不考虑组内其他提案的存在。这导致策略倾向于集中于单一高奖励见证，或生成包含已发现见证的冗余超集，无法恢复完整的反链。本文的切入点在于，最小见证的识别本质上是一个集合覆盖问题，奖励必须反映提案对组内已认证区域的边际贡献，而非提案本身的局部价值。

## 核心方法

### 方法参照系

本文问题可置于组相对策略优化（GRPO）框架下，但关键差异在于奖励函数的定义。标准 GRPO 假设奖励是提案可分离的，即 $r(S_i, s_c(S_i))$ 仅依赖单个提案 $S_i$ 及其验证比特。而最小见证识别要求奖励反映提案在组内集合关系中的独特性，即一个提案是否引入了其他提案未覆盖的充分条件区域。

### 认证区域与删除信用

标准 GRPO 中，优势函数基于组内奖励均值归一化，无法区分冗余提案。MWRL 引入认证区域概念：一个被接受的提案 $S$ 认证其所有超集 $\uparrow S = \{T \subseteq E : T \supseteq S\}$。组内成功提案的认证区域并集 $U(W) = \bigcup_{S \in W} \uparrow S$ 定义了组已覆盖的充分条件空间。删除信用 $A_i$ 定义为移除提案 $i$ 后组返回值的损失：

$$
A_i = R(U_K) - R(U_{-i})
$$

其中 $U_{-i}$ 是移除提案 $i$ 后的认证区域并集。该公式的物理含义是：提案 $i$ 的信用等于它独占认证的充分条件区域的度量值。若提案 $i$ 是其他成功提案的超集，则其独占区域为空，信用为零，从而抑制冗余。

### 子模覆盖度量与策略梯度

为量化独占区域，MWRL 采用覆盖度量 $R_\mu(U) = \mu(U)$，其中 $\mu$ 是定义在子集格上的全支撑概率测度。在独立几何测度下，$\mu(\uparrow S) = p^{|S|}$，$p$ 为元素包含概率。删除信用因此成为子模边际增益：

$$
A_i = y_i \mu(\uparrow S_i \setminus U_{-i})
$$

该设计解决了标准 RL 中奖励稀疏导致的信用分配模糊问题：只有引入新覆盖区域的提案获得正信用，重复或冗余提案获得零信用。策略梯度更新使用留二出（l2o）基线调整后的信用 $\bar{A}_i$，确保梯度无偏且方差可控。

## 实验评估

实验在 MaxSAT 布尔公式、Suzuki-Miyaura 化学反应条件筛选及冻结 LLM 稀疏电路恢复三个场景中进行，基线包括 PPO、GRPO、GFlowNet 及 MaxEnt RL 等带尺寸惩罚的变体。MaxSAT 实验验证了理论正确性，MWRL 恢复了大部分实例的最小见证反链，而基线方法仅恢复约四分之一。化学反应实验测试了摊销泛化能力，LLM 电路实验在非单调验证器下测试了鲁棒性。

| 方法 | MaxSAT 恢复率 | 化学反应 born-minimal 率 | LLM 电路 antichain recall |
| :--- | :--- | :--- | :--- |
| MWRL | 大部分反链 | 0.998±0.001 | 0.999±0.001 |
| PPO w/ Size Pen. | ≤1/4 反链 | 0.866±0.138 | 0.888±0.163 |
| GFlowNet w/ Size Pen. | ≤1/4 反链 | 0.516±0.176 | 0.594±0.140 |

在 LLM 电路实验中，随着训练验证器调用次数从 1,024 增至 20,000，MWRL 的 born-minimal 率从 0.970±0.027 提升至 0.998±0.001，antichain recall 从 0.972±0.020 提升至 0.999±0.001，表明覆盖度量随采样密度增加而收敛。基线方法在相同预算下性能停滞，证实了删除信用机制对冗余抑制的有效性。

评估边界方面，MaxSAT 实验依赖精确枚举，未测试大规模不可枚举实例；化学反应实验使用合成条件面板，未验证湿实验部署；LLM 电路实验使用原始验证器，存在非单调性，但论文仅报告 1-最小性而非严格最小性。代码已开源，但超参数搜索范围未在正文中详细披露。

## 关联研究分析

从问题动机看，MWRL 与 Token Hidden Reward 均追求细粒度信用分配，但前者基于集合论覆盖关系，后者基于 token 级梯度相似度。Token Hidden Reward 假设关键步骤在正负样本中表现出不同的预测错误模式，而 MWRL 假设关键见证在组内集合关系中表现出独特的覆盖贡献。这一差异源于任务结构：Token Hidden Reward 适用于序列推理中的步骤归因，MWRL 适用于组合优化中的子集归因。MWRL 的覆盖度量是否可迁移至序列任务中的步骤覆盖，论文未给出回答。

从方法设计看，MWRL 与 SC-GRPO 均使用组内相对信号，但 SC-GRPO 基于 token 级 KL 散度，MWRL 基于集合覆盖边际增益。SC-GRPO 需要构建自条件教师模型，计算开销较高；MWRL 仅需验证器比特和集合运算，计算开销更低。然而，MWRL 依赖全支撑测度 $\mu$，在元素空间极大时，$\mu(\uparrow S)$ 可能趋近于零，导致信用信号稀疏。SC-GRPO 的 KL 散度是否在高维空间中更稳定，论文未提供对比实验。

## 总结

MWRL 解决的核心矛盾是标准 RL 奖励函数的提案可分离性与最小见证识别的组内集合依赖性之间的冲突。本文抓住的切入点是，最小见证的识别本质上是集合覆盖问题，奖励必须反映提案对组内认证区域的边际贡献。通过引入删除信用机制和子模覆盖度量，MWRL 在 MaxSAT 上恢复了大部分最小见证反链，在 LLM 电路实验中实现了 0.999±0.001 的 antichain recall。本文的边界在于，实验主要依赖可枚举或小规模实例，未验证在元素空间极大且验证器非单调时的覆盖度量稀疏性问题。当元素空间维度增加至数百时，全支撑测度下的覆盖信号是否仍能有效区分冗余提案，论文未给出回答。
