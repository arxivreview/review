# HuggingFace最新推荐论文 ｜World-in-Context: Interactive Video World Modeling with In-Context Conditioning ｜交互式视频世界模型中的统一上下文条件化

研究机构：阿里巴巴集团

作者：Harold Haodong Chen、Rui Peng、Rongjin Guo 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2610.33169)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2610.33169)

> 交互式视频世界模型旨在构建能够感知、交互并预测物理世界演化的内部模拟器，其核心价值在于弥合被动视频生成与主动具身智能之间的鸿沟。现有方法通常将视角模式隐式包含在文本描述中，且将离散动作与连续相机轨迹通过独立的模块化分支（如 AdaLN）注入，导致多控制信号间的交叉依赖难以被直接建模，引发视角歧义与动作-相机纠缠。World-in-Context 提出 In-Context Conditioning (ICC) 范式，将视角、动作和相机控制统一转化为 Token 序列，直接拼接到视觉潜变量前，在共享自注意力空间中进行交互，并引入 IT-RoPE 编码控制过渡的累积传输算子。该架构以 5B 参数量在导航性能上逼近 22B 模型，并大幅提升了视角切换成功率，但在长序列推理中的计算复杂度及显式视角 Token 的泛化边界仍需进一步验证。

## 研究背景

当交互式视频世界模型试图模拟复杂环境时，模型必须同时处理“世界如何被观察”（视角模式）与“用户如何干预世界”（动作与相机控制）这两个核心维度。在第三人称（Third-Person Perspective, TPP）视角下，角色动作与相机运动构成独立的自由度；而在第一人称（First-Person Perspective, FPP）和自由相机（Free-Camera, FREE）模式下，相机轨迹往往同时承担了角色移动与视角旋转的双重语义。这种运动语义的混淆导致模型难以区分无约束的 FREE 漫游与受身体物理限制的 FPP 运动，进而产生违背物理直觉的视觉幻觉。

当前主流的视频扩散模型（Video Diffusion Models）与 DiT 架构在处理多模态控制时，通常采用模块化分支注入策略。例如，通过 AdaLN 调制处理相机轨迹，通过交叉注意力处理文本，或通过附加 Token 注入离散动作。这种架构分离将不同控制信号隔离在独立的参数空间中，使得信号间的交叉依赖只能被间接捕获。随着交互维度的增加，协调这些模块化分支变得极其复杂，尤其是当某一信号的解释依赖于并发输入和当前活动视口时。World-in-Context 正是针对这一“动作-相机纠缠”与“视角模式歧义”问题，提出将多维交互重构为统一的上下文建模问题。

## 核心方法

### 统一上下文条件化（In-Context Conditioning, ICC）

在传统的交互式视频生成流程中，控制信号 $u$ 通常通过条件特定路径 $f_{cond}(\cdot)$ 注入到扩散模型中。World-in-Context 摒弃了这种碎片化的侧通道设计，将所有交互信号投影为统一的条件 Token 序列 $c$，并直接前置到视觉潜变量 $z_\tau$ 之前。

$$ \hat{v}_\tau = F_\theta \left( [c \parallel z_\tau] ; y, \tau \right) $$

该公式表明，生成器 $F_\theta$ 在共享的自注意力流形上直接处理条件 Token $c$ 与视觉潜变量 $z_\tau$ 的拼接序列。$c$ 由视角 Token $c_{view}$、动作 Token $c_{action}$ 和相机 Token $c_{camera}$ 拼接而成。这一设计动机在于，通过将所有控制信号置于同一注意力空间，模型能够原生地捕获跨条件依赖，而无需依赖复杂的模块化分支来间接协调信号。

### 显式视角模式建模与动作-相机解耦

针对视角歧义问题，World-in-Context 引入显式的、时间对齐的视角 Token，取代隐式的文本描述。

$$ c_{view}^t = e_{view}(v_t) + e_{type}(view), \quad v_t \in \{FREE, FPP, TPP\} $$

该公式将离散视角映射为可学习的类别嵌入，作为上下文开关，直接调制共享注意力空间以匹配特定视角的物理运动场。实验表明，显式视角建模能有效区分 FPP 的周期性振荡（体现具身运动）与 FREE 的平滑轨迹。

在动作与相机控制方面，模型将离散动作分解为语义子槽（如移动、转向），并通过零初始化残差分支编码连续运动增量；相机控制则通过 Plücker 射线场编码相对 6-DoF 位姿。这种解耦设计解决了 TPP 下角色与相机自由度纠缠的问题，同时揭示了动作与相机在 FPP/FREE 模式下的互补作用：动作主导局部命令保真度，而相机锚定全局轨迹稳定性。

### 交互传输旋转位置编码（IT-RoPE）

尽管 ICC 暴露了单帧的控制输入，但标准 3D-RoPE 仅编码相对时空坐标，导致远距离帧之间的控制演化被隐式建模。为此，World-in-Context 引入 IT-RoPE，将控制诱导的传输算子累积融入时间注意力。

$$ s_{ij} = s_{ij}^{base} + \frac{\lambda_b}{\sqrt{r}} \sum_{b \in \{a,c\}} g_i^b m_{ij}^b \left( q_i^b (T_{i \to j}^b)^\top k_j^b - I \right) $$

该公式在标准时空注意力 $s_{ij}^{base}$ 的基础上，增加了基于控制传输算子 $T_{i \to j}^b$ 的修正项。$T_{i \to j}^b$ 是沿执行序列累积的步变换，保留了控制顺序的非交换性。减去单位矩阵 $I$ 确保修正项在静态区间或 $t_i = t_j$ 时消失，而零初始化的 $\lambda_b$ 保证训练初期保留原生骨干行为。这一设计显式建模了帧间控制过渡，提升了长时程交互的连贯性。

## 实验评估

实验在 WBench 基准上进行，涵盖 NAVIGATION（轨迹跟踪）与 FPP↔TPP（视角切换）两个子集。基线包括同尺寸 5B 模型（Zing-0.5, DreamX-World 等）及更大参数量的参考模型（EchoWM 22B, LingBot-World v2 14B）。

| 模型 | 参数量 | 控制策略 | Navigation 平均 | FPP↔TPP 切换成功率 (%) |
| :--- | :--- | :--- | :--- | :--- |
| EchoWM | 22B | Positional Attn. | 81.6 | 32.0 |
| LingBot-World v2 | 14B | AdaLN | 81.8 | 21.9 |
| Zing-0.5 | 5B | Additive Inject. | 81.0 | 18.8 |
| **World-in-Context** | **5B** | **In-Context** | **81.5** | **93.8** |

World-in-Context-5B 在导航性能上（81.5）与 22B 的 EchoWM（81.6）持平，但在视角切换成功率上（93.8%）大幅超越所有基线，验证了统一上下文接口在处理复杂交互时的有效性。

消融实验进一步验证了 ICC 与 IT-RoPE 的贡献。随着控制信号从单一相机（C）扩展到动作+相机（A+C）再到视角+动作+相机（V+A+C），ICC 相对于 Additive Injection 的优势逐渐扩大。在 V+A+C 设置下，ICC 在导航和交互得分上分别提升 1.0 和 1.4 分。IT-RoPE 的引入使导航得分从 80.5 提升至 81.2，交互得分从 86.2 提升至 86.8，证明累积控制过渡比仅依赖端点偏移更能捕捉动态演化。

评估边界方面，实验主要依赖 WBench 基准，该基准虽涵盖导航与视角切换，但缺乏对物理合理性（如碰撞、重力）的细粒度评估。此外，视角切换的 93.8% 成功率依赖于 500 条微调数据，若移除微调，基线成功率为 37.5%，虽仍高于文本基线（6.25%），但表明显式视角 Token 的零样本泛化能力仍有提升空间。

## 关联研究分析

从控制注入机制看，World-in-Context 与 Zing-0.5 和 EchoWM 形成鲜明对比。Zing-0.5 采用 Additive Injection，EchoWM 采用 Positional Attention，两者均将控制信号与视觉特征在特定层或特定通道进行融合。World-in-Context 则通过 ICC 将所有控制信号 Token 化并前置，利用 Transformer 的自注意力机制原生处理跨模态依赖。这种差异的根源在于对“交互复杂性”的理解：当控制信号维度较低时，模块化分支足够高效；但当视角、动作、相机三者耦合时，统一注意力空间能更有效地协调信号间的非线性交互。

从视角建模策略看，World-in-Context 与 LingBot-World v2 和 Alaya-EVOKE 存在分歧。后者通常将视角模式隐式包含在文本提示或相机位姿中，导致 FREE 与 FPP 的运动语义混淆。World-in-Context 引入显式视角 Token，通过离散类别嵌入强制模型区分不同视角的物理运动场。这一设计选择解决了隐式条件在相同几何轨迹下无法区分具身运动与自由漫游的失效问题，但也引入了对视角标签质量的依赖。

## 总结

World-in-Context 针对交互式视频世界模型中视角歧义与动作-相机纠缠的核心矛盾，提出将多维控制信号统一为 Token 序列并在共享注意力空间中建模。通过显式视角 Token 与 IT-RoPE 的引入，该架构以 5B 参数量在 WBench 导航任务上达到 81.5 分，逼近 22B 模型性能，并将视角切换成功率提升至 93.8%。然而，该方法的边界在于其计算复杂度随控制 Token 数量线性增加，且在长序列推理中可能面临注意力稀疏性挑战。当控制信号进一步扩展至天气、光照等高维语义时，统一 Token 序列的长度是否会成为实时交互的瓶颈，论文未给出回答。
