作者：Simran Khanuja、Rohit Gandikota、Gaurav Parmar 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2610.29003)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2610.29003)

> 导读：文本到图像（Text-to-Image, T2I）平台通常返回多张图像供用户选择，但现有模型仅优化单图质量，导致多图多样性不足，且无法响应用户对特定视觉属性（如“艺术风格”或“人物种族”）的差异化变化需求。现有多样性方法多为无轴（axis-agnostic）干预，无法将变化约束在用户指定的语义维度上。T-DIG 将多样性建模为条件生成问题，通过训练大语言模型（Large Language Model, LLM）策略，将基础提示与用户指定的变化轴扩展为 $K$ 个具体提示，输入冻结的 T2I 模型生成图像集。该框架在保持高保真对齐的同时显著提升了轴条件多样性，但其依赖外部感知指标作为奖励信号，可能引入评估偏差。

## 研究背景

当用户向 T2I 模型输入提示词时，期望获得一组在特定维度上存在差异的图像以供筛选。然而，独立同分布（Independent and Identically Distributed, I.I.D.）采样仅通过随机种子引入噪声，生成的图像在构图、主体属性上高度同质，且这种同质性无法通过用户意图进行定向控制。为解决此问题，研究者提出了多种多样性增强方法，如 CADS 通过向条件嵌入添加退火噪声，或 Scaling Group Inference 通过大规模候选采样与筛选。但这些方法均属于无轴干预，它们最大化图像在潜在空间中的整体距离，却忽略了用户可能仅希望改变“背景”而保持“主体”不变的具体需求。

这种“无轴”与“有轴”的矛盾构成了当前 T2I 多样性生成的核心瓶颈。现有方法要么牺牲对齐度以换取整体多样性（如 CADS 导致 VQAScore 下降），要么计算成本高昂且无法定向（如 Scaling Group Inference 需 3.3–21.9 倍去噪成本）。T-DIG 的切入点在于将多样性视为文本条件生成问题：给定基础提示 $p$ 和用户自由文本指定的变化轴 $a$，生成 $K$ 张沿 $a$ 变化且符合 $p$ 的图像。这一转变要求模型具备将抽象用户意图转化为具体提示变体的推理能力，而非仅依赖统计分布的扰动。

## 核心方法

### 交互式提示扩展框架

T-DIG 采用模块化流水线，核心是一个冻结的 T2I 生成器 $R_{gen}$ 和一个可训练的 LLM 策略 $\pi_{gen}$。用户输入基础提示 $p$ 和变化轴 $a$，策略 $\pi_{gen}$ 输出 $K$ 个扩展提示 $q = \{q_1, \dots, q_K\}$，随后 $R_{gen}$ 基于共享初始潜变量渲染图像集 $X' = R_{gen}(q)$。该设计的关键在于保持生成器冻结，仅训练提示策略，从而兼容开源、蒸馏及闭源 API 模型。策略 $\pi_{gen}$ 实现为冻结语言模型上的低秩适应（Low-Rank Adaptation, LoRA）适配器，其权重更新受多样性强度 $s$ 控制：

$$ \pi_{\alpha s} = W_0 + \alpha s \Delta W $$

其中 $W_0$ 为预训练权重，$\Delta W$ 为 LoRA 增量，$\alpha s \in [0, 1]$ 调节多样性强度。这一设计使得用户可通过滑块直观控制变化幅度，解决了传统方法中多样性与可控性解耦的问题。

### 文本条件多样性奖励机制

为了训练策略生成沿特定轴变化的提示，T-DIG 设计了基于 TPIPS 的文本条件多样性奖励。TPIPS 是一种基于视觉语言模型（Vision-Language Model, VLM）的感知相似度指标，能够根据文本描述（如“光照”）评估图像在该维度上的相似性。策略优化的目标是最大化图像集在轴 $a$ 上的 Vendi Score（VS），同时惩罚对齐度损失。轴条件多样性 $D_a(X)$ 定义为：

$$ D_a(X) = \frac{VS(\{e_i\}_{i=1}^K) - 1}{K - 1} \in [0, 1] $$

其中 $e_i = f_{TPIPS}(x_i; a)$ 为图像 $x_i$ 在轴 $a$ 条件下的嵌入，VS 衡量有效不同图像的数量。该公式的物理含义是将图像在指定语义维度上的分散程度归一化为 0 到 1 之间的分数，确保奖励信号仅响应沿用户指定轴的变化，而非无关维度的噪声。

### 复合对齐与偏好惩罚

单纯最大化多样性会导致图像偏离基础提示或降低美学质量。T-DIG 引入复合奖励函数，结合对齐、长度和偏好惩罚。最终奖励 $r$ 为：

$$ r(q, X; p, a, R) = D_a(X) - \lambda L_{align} - \mu L_{len} - \eta L_{pref} $$

其中 $L_{align}$ 为基于 VQAScore 的对齐惩罚，$L_{len}$ 为提示长度惩罚，$L_{pref}$ 为基于 HPSv3 的偏好惩罚。对齐惩罚采用逐提示阈值 $\tau(p, R)$，仅当图像 VQAScore 低于 I.I.D. 采样均值时施加惩罚，避免对原本对齐度较低的提示过度惩罚。这一设计解决了传统固定阈值奖励在长尾提示上失效的问题，确保多样性提升不以牺牲基础语义忠实度为代价。

## 实验评估

实验在四个开源 T2I 模型（SD3.5 L/M, Qwen-Image, FLUX.2 [klein]）及两个闭源 API 模型上进行。基线包括 I.I.D. 采样、CADS、Scaling Group Inference 和 PAG。评估指标涵盖轴条件多样性（TPIPSv）、整体多样性（DINOv）、对齐度（VQAScore）及人类偏好（HPSv3）。

| 方法 | TPIPSv (Qwen-Image) | VQAScore (Qwen-Image) | HPSv3 (Qwen-Image) |
| --- | --- | --- | --- |
| I.I.D. | 0.124 | 0.889 | 11.55 |
| CADS | 0.293 | 0.808 | 8.76 |
| Scaling Group Inference | 0.168 | 0.885 | 11.43 |
| T-DIG ($\alpha=1$) | 0.379 | 0.859 | 10.84 |

在 Qwen-Image 上，T-DIG ($\alpha=1$) 的 TPIPSv 达到 0.379，较 I.I.D. (0.124) 提升 3.06 倍，而 VQAScore 仅从 0.889 降至 0.859，损失 0.03。相比之下，CADS 虽将 TPIPSv 提升至 0.293，但 VQAScore 降至 0.808，HPSv3 从 11.55 骤降至 8.76，表明其多样性提升伴随显著的质量与对齐损失。Scaling Group Inference 虽保持高对齐度 (0.885)，但 TPIPSv 仅提升至 0.168，且计算成本高昂。

消融实验显示，移除对齐惩罚 ($L_{align}$) 会导致 VQAScore 从 0.849 降至 0.228，证实了该惩罚项对维持语义忠实度的关键作用。移除偏好惩罚 ($L_{pref}$) 则导致 HPSv3 从 12.35 降至 11.38，表明模型可能通过生成低质量但高多样性的图像来“奖励黑客”。策略规模方面，9B 策略在 VQAScore 上略优于 4B 策略，但 35B 策略未带来显著增益，表明中等规模 LLM 足以胜任提示扩展任务。

评估边界方面，TPIPSv 作为核心指标，其有效性依赖于 TPIPS 模型对人类感知判断的拟合程度。若 TPIPS 对某些抽象轴（如“情感”）的感知存在偏差，奖励信号可能误导策略。此外，实验未覆盖极端长提示或高度抽象概念，其在复杂语义下的鲁棒性有待验证。

## 关联研究分析

从问题动机看，T-DIG 与 Contextual Repulsion (Dahary et al., 2026) 均旨在提升多样性，但路径截然不同。Contextual Repulsion 在扩散 Transformer 的注意力块中实施排斥机制，直接干预生成过程，属于模型内部干预；而 T-DIG 通过外部 LLM 策略修改输入提示，属于输入端干预。前者受限于特定架构（仅适用于 DiT），后者则具有模型无关性，可应用于任何 T2I 模型。然而，Contextual Repulsion 无需训练额外策略，计算开销更低，而 T-DIG 需训练 LoRA 适配器，引入了额外的训练成本与推理延迟。

从方法设计看，T-DIG 与 Think-Then-Generate (Kou et al., 2026) 均利用 LLM 推理细化提示，但目标不同。Think-Then-Generate 旨在解决复杂语义对齐，通过思维链推理生成中间视觉草稿，侧重于“正确性”；T-DIG 侧重于“差异性”，通过 GRPO 优化提示变体以最大化轴条件多样性。Think-Then-Generate 的奖励信号基于图像与提示的匹配度，而 T-DIG 的奖励信号基于图像集内部的分散度。这种差异导致 T-DIG 在处理模糊用户意图时更具灵活性，但在处理严格语义约束时可能因过度追求多样性而引入幻觉。

## 总结

T-DIG 解决了 T2I 生成中用户意图驱动的多样性控制难题，其核心在于将多样性建模为文本条件生成问题，并通过训练 LLM 策略将抽象变化轴转化为具体提示变体。实验表明，T-DIG 在 Qwen-Image 上将轴条件多样性提升 3.06 倍，同时保持 VQAScore 损失低于 0.03，显著优于 CADS 等无轴基线。然而，该方法依赖 TPIPS 作为奖励信号，其有效性受限于 TPIPS 对人类感知判断的拟合精度。当用户指定的变化轴超出 TPIPS 训练分布（如高度抽象或文化特定概念）时，奖励信号是否仍能准确引导策略生成符合预期的多样性，论文未给出回答。
