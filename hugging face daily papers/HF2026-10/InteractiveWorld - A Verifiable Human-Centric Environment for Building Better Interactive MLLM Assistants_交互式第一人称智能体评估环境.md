> 导读 第一人称多模态任务辅助旨在利用可穿戴设备构建能实时理解用户意图并提供主动指导的智能系统。现有评估体系多局限于静态视频问答，无法测试模型在动态环境中的闭环适应能力与组合技能。本文提出InteractiveWorld，一个基于物理引擎的闭环交互环境，通过模拟人类执行动作并更新环境状态，实现了对多模态大语言模型（MLLMs）协作能力的可验证评估。该工作填补了领域内缺乏动态、可验证评估基准的空白，为从被动感知向主动共生演进提供了关键测试床。然而，模拟环境中的高保真物理交互是否完全复现了真实世界传感器噪声对意图推断的影响，仍需进一步验证。

## 研究背景

当智能眼镜等可穿戴设备普及，第一人称多模态任务辅助的核心矛盾从“如何看懂视频”转变为“如何在资源受限且隐私敏感的环境中实时理解用户状态”。传统评估依赖静态视频问答，模型在给定视频片段 $V$ 和查询 $Q$ 后预测标签 $y$，这种离线范式无法捕捉实时交互中的因果约束。在流式辅助场景中，模型需在时刻 $t$ 仅能访问 $V_{1:t}$，并决策是否生成干预 $A_t$。这一约束引入了时间同步、状态估计与干预时机耦合等多重子问题，而静态基准无法测试模型在指令改变环境后，如何根据新观测调整后续策略的闭环适应能力。

领域内已形成“主动式交互优于被动问答”的共识，但缺乏可验证的评估手段。现有方法如 Pro^2Assist 强调连续步骤感知的主动辅助，EgoSelf 引入图结构记忆支持长时程关联，但这些方法的评估多基于离线标注或静态基准。由于真实世界实验成本高且难以规模化，研究者亟需一个能模拟人类-助手协作动态过程的虚拟环境。InteractiveWorld 正是在此背景下提出，它通过构建物理、人类动作与语义三层架构，将自由文本指导转化为可执行动作，并基于物理状态更新进行验证，从而解决了静态评估无法测试闭环适应性与组合能力的痛点。

## 核心方法

### 方法参照系：闭环交互评估范式

本文解决的问题属于“系统部署”与“主动辅助”的交叉路线，其核心差异在于评估范式从静态问答转向动态闭环。在通用视频理解中，模型利用全视频信息优化全局特征；而在 InteractiveWorld 中，评估单元是版本化的 TaskPack，包含场景、实体、初始事件历史及可执行动作程序。Assistant 接收第一人称视觉片段与自然语言指令，输出干预指令；Human Agent 将指令接地为动作序列，环境执行动作并更新物理状态，随后渲染新的第一人称视角。这一流程要求模型具备视觉感知、状态追踪、规则推理及沟通等多维能力，且成功与否由最终物理状态决定，而非文本匹配。

### 物理层：稳定人类表征与碰撞检测

物理层为闭环交互提供基础，其设计动机在于确保人类动作的可重复性与物理一致性。传统机器人模拟器关注低层关节控制，而本文需模拟人类作为协作者的自主执行能力。系统采用 SMPL+H 模型表征人体，每帧由 156 维轴角向量参数化：

$$
q = [\omega_{\text{root}}, \theta_{\text{body}}, \theta_{\text{left}}, \theta_{\text{right}}] \in \mathbb{R}^{3+63+45+45}
$$

该向量包含根节点朝向、21 个身体关节及每手 15 个关节的旋转参数。为避免物理失败，人类模型采用运动学驱动而非动力学模拟，确保上层提供的有效姿态序列能确定性执行。碰撞检测采用紧凑的代理骨架（17 个胶囊体加头部球体），在导航与操作前预检查路径与手臂可达性。若检测到碰撞，系统通过二分法估计穿透深度并尝试调整姿态或路径，从而在保持相机轨迹可复现的同时，拒绝导致严重穿模的动作。

### 人类动作层：碰撞感知导航与自适应操作

人类动作层将高层语义目标转化为底层运动轨迹，其创新在于实现了从自由文本到物理动作的自动接地。导航阶段，系统基于 A* 搜索规划无碰撞路径，转移代价函数为：

$$
c(n, n') = r \cdot \ell_8(n, n') + \lambda \max(0, d_{\text{safe}} - D(n')) + c_{\text{door}}(n')
$$

其中 $r$ 为网格分辨率，$\ell_8$ 为步长，$D(n')$ 为单元格净空距离，$\lambda$ 为权重系数。该公式通过净空项偏置路径向开阔空间，避免狭窄通道成为硬障碍。操作阶段，系统根据目标几何特征选择抓取家族（PINCH、CYLINDRICAL 或 ROUND），并通过逆运动学（IK）规划手臂轨迹。抓取位置与手型取决于物体形状与功能部件，若初始位置无可行轨迹，系统重新规划站立姿态。这一设计解决了此前方法中动作执行不稳定、无法处理复杂物体交互的问题，使 Human Agent 能可靠执行日常动作。

### 语义层：可验证多轮交互

语义层连接自然语言与行为，其核心是统一动作接口与状态验证机制。Assistant 输出干预指令，Human 将其解析为结构化命令，环境执行后返回关系增量与执行结果。信息流遵循严格边界：Assistant 仅接收采样帧与人类语音，无法访问内部实例 ID 或坐标；Human 接收视觉证据与可操作对象句柄，输出推理、动作与语音。评分基于物理谓词（如 ON, INSIDE, HELD），读取当前物理关系集与目标状态。若 Assistant 声明完成，系统检查世界状态是否满足目标，而非依赖文本声明。这一机制确保了评估的客观性，防止模型通过幻觉或误导性对话获得虚假高分。

## 实验评估

实验在 InteractiveBench 上进行，包含 120 个多轮任务，分为 Guidance、Planning、Accessibility、Decision、Prevention、Finding 六类。基线覆盖 Claude、GPT、Gemini 等 12 个前沿 MLLMs。主结果显示，即使最强模型 Claude Fable 5.1 的平均通过率（Pass）仅为 41.7%，在长时程 Guidance 和 Planning 任务上通过率分别低至 20.0% 和 25.0%。相比之下，Oracle Assistant 在相同 Human Agent 下实现 100% 通过率，表明当前模型在闭环协作中存在显著缺陷。

| 模型 | AVG. Pass (%) | Guidance Pass (%) | Planning Pass (%) | Decision Pass (%) |
| :--- | :--- | :--- | :--- | :--- |
| Claude Fable 5.1 | 41.7 | 20.0 | 25.0 | 85.0 |
| Claude Opus 5 | 33.3 | 15.0 | 25.0 | 70.0 |
| Muse Spark 1.1 | 31.7 | 20.0 | 25.0 | 55.0 |
| GPT-5.6 Sol | 30.8 | 20.0 | 25.0 | 50.0 |

消融实验揭示了记忆增强与人类代理的影响。在 Assistant 响应中附加隐藏 Memory 字段以记录事件，可提升 Prevention 和 Finding 任务成功率 5–15%，但对 Decision、Guidance 和 Accessibility 的影响因模型而异，且 Planning 成功率在部分模型中下降 5%。这表明简单的推理时记忆增强不足以支撑可靠的长时程辅助。此外，跨模型交叉评估显示，Human Agent 的执行能力对结果有显著影响，但 Assistant 的沟通与规划能力仍是瓶颈。

评估边界方面，InteractiveBench 聚焦于闭环交互，但缺乏对实时流式交互延迟的量化评估。指标完备性上，Pass 与 MCR 侧重任务完成度，未充分反映干预时机与过度干预的代价。可复现性方面，代码已开源，但模拟环境的物理参数与资产依赖 BEHAVIOR-1K，可能限制在其他场景的泛化。

## 关联研究分析

从问题动机看，InteractiveWorld 与 Pro^2Assist 均关注主动辅助，但评估范式截然不同。Pro^2Assist 依赖连续步骤感知的显式规则，在程序性任务中表现稳定，但泛化性受限；InteractiveWorld 则通过物理状态验证干预效果，测试模型在开放场景中的适应能力。这一差异源于任务特性：Pro^2Assist 针对结构化流程，而 InteractiveWorld 模拟非结构化日常交互。InteractiveWorld 的低分结果揭示了现有方法在动态环境中的失效模式，即视觉感知与记忆错误占首错率的 70.4%–85.7%，单一误判会级联导致后续指令错误。

从方法设计看，InteractiveWorld 与 EgoSelf 在记忆机制上形成互补。EgoSelf 提出基于图结构的交互记忆，支持跨天/跨小时的上下文关联，在 EgoLife 基准上取得 85.2 的准确率；InteractiveWorld 则指出当前模型在动态交互中的记忆瓶颈，并验证了简单记忆增强的局限性。EgoSelf 的图结构记忆是否能在 InteractiveWorld 的闭环环境中提升长时程任务表现，论文未给出回答。此外，InteractiveWorld 的 Human Agent 采用 Gemini 3.1 Pro，其执行能力可能掩盖 Assistant 的规划缺陷，如何解耦 Human 执行误差与 Assistant 决策误差，是后续评估需解决的难题。

## 总结

本文要解决的核心矛盾是现有静态基准无法评估 MLLMs 在动态环境中的闭环协作能力。InteractiveWorld 通过构建物理、人类动作与语义三层架构，将自由文本指导转化为可执行动作，并基于物理状态更新进行验证，填补了领域内缺乏动态评估基准的空白。实验表明，最强模型在长时程任务上通过率仅为 20.0%–25.0%，揭示了视觉感知与记忆错误是主要瓶颈。然而，模拟环境中的高保真物理交互是否完全复现了真实世界传感器噪声对意图推断的影响，以及 Human Agent 的执行能力是否干扰了对 Assistant 决策质量的归因，仍需进一步验证。
