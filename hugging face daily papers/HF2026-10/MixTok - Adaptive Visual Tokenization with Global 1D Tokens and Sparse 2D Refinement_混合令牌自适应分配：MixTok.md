# HuggingFace最新推荐论文 ｜MixTok: Adaptive Visual Tokenization with Global 1D Tokens and Sparse 2D Refinement ｜混合令牌自适应分配：MixTok

研究机构：浙江大学、香港科技大学

作者：Chenge Li、Yefei He、Xinyu Liu 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2610.13181)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2610.13181)

> 视觉分词器需在紧凑表示与细节保留间取得平衡，但现有方法要么因固定空间网格导致简单区域冗余，要么因全局聚合丢失局部细节。MixTok 提出一种混合架构，将紧凑的 1D 全局令牌与稀疏的 2D 局部细化令牌结合，通过内容自适应路由器动态决定细化位置与数量。该设计在极低令牌预算下实现了重建与生成的有效平衡，验证了离散混合范式的潜力，但其绝对性能仍受限于离散量化误差，且未探索连续潜空间或高分辨率场景。

## 研究背景

视觉生成模型依赖分词器将高维像素压缩为紧凑潜变量，这一过程的核心矛盾在于信息密度分布不均与固定压缩预算之间的冲突。当分词器采用二维网格结构时，每个空间位置分配相同数量的令牌，导致平滑天空区域与复杂纹理区域占用同等容量，造成资源浪费；若改用一维序列结构，虽提升了全局紧凑性，但缺乏显式空间对应关系，难以在短序列中保留细粒度局部细节。这两种范式分别代表了“空间均匀性”与“全局紧凑性”的极端，单一范式难以同时满足高效压缩与高保真重建的需求。

为解决这一矛盾，研究路线逐渐分化为离散量化机制优化与高效压缩灵活编码两类。前者致力于提升码本利用率以增强离散表示能力，后者则探索动态令牌预算分配。然而，现有自适应方法多聚焦于调整一维序列长度或整体压缩率，未能联合解决“在哪里分配局部容量”与“每图分配多少容量”这两个耦合问题。MixTok 正是针对这一被忽略的联合优化缺口，提出在保持全局紧凑性的同时，通过内容感知机制稀疏地注入局部细化能力。

## 核心方法

### 混合视觉表示构建

MixTok 建立在离散令牌化通用流程之上，其关键差异在于将单一维度的令牌表示扩展为 1D 全局与 2D 局部的混合结构。标准流程中，编码器输出单一形式的潜变量，而 MixTok 并行使用预训练的 TiTok（1D）和 LlamaGen（2D）分支。1D 分支提供紧凑的全局特征序列，2D 分支提供候选的局部细化特征。

为了将无空间对应关系的 1D 特征与有空间结构的 2D 特征融合，MixTok 首先通过空间查询网格将 1D 量化特征 $F_{1D}$ 扩展为空间特征图 $\tilde{F}_{1D}$，并经适配器投影至解码器输入空间 $\bar{F}_{1D}$。随后，在选定的细化位置 $R$ 上，用 2D 特征 $F_{2D}$ 替换对应的 1D 衍生特征，形成混合特征网格 $F_{mix}$：

$$
F_{mix,i} = \begin{cases} F_{2D,i}, & i \in R \\ \bar{F}_{1D,i}, & i \notin R \end{cases}
$$

该公式定义了混合表示的物理构成：在低优先级区域保留全局压缩信息，在高优先级区域注入局部空间细节，从而在单一解码器输入空间中实现容量的高效再分配。

### 内容自适应令牌分配

在混合表示构建中，细化位置集合 $R$ 及其大小 $K$ 的确定是核心创新。传统方法通常固定细化数量或依赖启发式规则，MixTok 引入内容自适应路由器，包含网格评分器与预算控制器。网格评分器基于 1D 基础重建误差与 2D 特征差异，预测每个空间位置的细化优先级分数 $\rho_{rec}$。

预算控制器采用 Top-p 采样机制，将分数归一化为概率分布 $q_i$，并选择累积概率达到阈值 $p$ 的最短前缀作为细化集合：

$$
K(x) = \min \left\{ k \in \{1, \dots, N\} : \sum_{j=1}^{k} q_{\pi_j(x)}(x) \ge p \right\}
$$

这一机制解决了固定预算导致的效率低下问题：当图像简单时，概率质量集中，$K(x)$ 自动减小；当图像复杂时，概率分布分散，$K(x)$ 自动增大。通过校准阈值 $p$，系统在保持目标平均令牌预算的同时，实现了逐图自适应的容量分配。

### 两阶段生成策略

在下游生成任务中，由于 2D 特征在生成阶段不可用，MixTok 设计了蒸馏式的生成网格评分器，仅凭 1D 基础特征预测细化位置。生成过程分为两阶段：首先由 MaskGIT 生成 1D 全局令牌，构建基础网格；随后，基于预测的细化位置，由 Halton-MaskGIT 仅生成稀疏的 2D 局部令牌。

这一设计解决了离散生成中全局与局部依赖难以建模的问题。通过先生成全局结构再细化局部，模型避免了在完整 2D 网格上进行密集自回归建模的高计算成本，同时利用 1D 令牌提供的空间上下文引导局部生成，提升了生成效率与质量。

## 实验评估

实验在 ImageNet-256 数据集上进行，评估指标包括重建质量（rFID, PSNR）与生成质量（gFID）。基线覆盖了一维紧凑方法（TiTok, One-D-Piece）、自适应方法（FlexTok, ALIT）及二维网格方法（LlamaGen, MaskGIT-VQGAN）。

| 方法 | 平均令牌数 | rFID ↓ | PSNR (dB) ↑ |
| :--- | :--- | :--- | :--- |
| TiTok S-128 | 128 | 1.7222 | 17.72 |
| One-D-Piece L-256 | 128 | 1.4406 | 17.71 |
| FlexTok d18-d28 | 128 | 1.1422 | 16.76 |
| MixTok (ours) | 128 | 1.1950 | 19.51 |

在 128 令牌预算下，MixTok 的 rFID 为 1.1950，显著优于 TiTok 和 One-D-Piece，并接近 FlexTok，但 PSNR 高于 FlexTok，表明其在保持紧凑性的同时更好地恢复了像素级细节。在生成任务中，MixTok 以约 131 个令牌实现 1.95 gFID，优于同预算的 TiTok-S-128（2.00 gFID），且采样轮数从 64 降至 16，推理速度提升 3.77 倍。

消融实验显示，稀疏 2D 细化将 gFID 从 4.33 提升至 1.95，证实了局部容量注入对生成质量的关键贡献。然而，评估局限于 256×256 分辨率，未涉及高分辨率或视频场景，且未与连续潜空间 SOTA（如 PAE）直接对比，限制了其在绝对性能上的定位。

## 关联研究分析

从问题动机看，MixTok 与 FlexTok 均致力于解决固定令牌预算的低效性，但 FlexTok 仅通过调整 1D 序列长度实现自适应，缺乏空间维度的细化能力；MixTok 则通过 1D-2D 混合架构，同时解决了“多少”与“哪里”的问题。这种差异源于对局部细节恢复机制的不同理解：FlexTok 依赖全局序列的隐式编码，而 MixTok 显式保留空间局部性。

从方法设计看，MixTok 与 ALIT 均涉及令牌数量的动态调整，但 ALIT 通过递归添加令牌逐步提升重建质量，训练与推理流程复杂；MixTok 通过 Top-p 机制一次性确定预算，效率更高。然而，MixTok 依赖预训练离散码本的语义结构，未显式引入视觉基础模型（VFM）特征对齐，这可能限制了其在开放域或复杂语义场景下的生成一致性上限，与当前领域强调语义对齐的趋势存在偏差。

## 总结

MixTok 针对视觉分词器中固定令牌预算导致的效率低下与细节丢失矛盾，提出了一种结合 1D 全局紧凑性与 2D 局部稀疏细化的混合架构。通过内容自适应路由器联合优化空间选择与每图令牌数量，该论文在 ImageNet-256 上以约 128 个令牌实现了 1.1950 rFID 和 1.95 gFID，验证了离散混合范式在极低预算下的有效性。其边界在于仍受限于离散量化误差，且未探索连续潜空间或高分辨率场景。当令牌预算进一步压缩至 64 以下时，1D 全局表示是否仍能提供足够的空间上下文以支撑有效的 2D 细化，论文未给出回答。
