## 研究背景

当金融机构受限于数据驻留法规时，无法调用云端前沿模型 API，只能部署本地开源小模型。然而，小模型在多步金融推理任务中常因逻辑漂移导致失败，而传统的监督微调（Supervised Fine-Tuning, SFT）虽能提升领域能力，却常以牺牲指令遵循和合规行为为代价。为解决分布不匹配，在线策略蒸馏（On-Policy Distillation, OPD）通过在学生自身轨迹上采样并计算教师分布，缓解了暴露偏差。但标准 OPD 依赖外部强教师，违背了数据驻留初衷；自蒸馏（Self-Distillation）虽消除了外部依赖，却通常要求教师条件于完整的参考解，这在推理时无法获取，且长序列蒸馏计算开销巨大。

现有方法在“特权信息密度”与“计算效率”之间缺乏平衡。完整参考解作为特权信息虽能引导正确路径，但掩盖了错误定位的关键作用；而仅依赖最终答案的强化学习又面临信用分配稀疏问题。本文切入点在于探究自蒸馏中特权信息的必要边界：是否仅需定位错误发生的位置，而非提供具体修正逻辑，即可实现高效的能力内化？

## 核心方法

### 方法参照系：在线策略自蒸馏

Fin-SD 建立在在线策略自蒸馏（On-Policy Self-Distillation, OPSD）框架之上。标准 OPSD 中，教师模型（学生自身冻结副本）条件于完整参考解，学生模型仅条件于问题，两者在学生生成的轨迹上最小化 KL 散度。本文的关键差异在于特权信息的构造与轨迹截断策略：不再使用完整解，而是通过错误定位生成简短批评，并仅在错误发生前的正确前缀上进行蒸馏。

### 错误定位与提示合成

传统 OPSD 假设教师需知晓完整正确路径以提供密集监督。Fin-SD 引入错误定位机制，由提示模型（Hint Model，即冻结学生自身）接收问题、失败轨迹和真值，输出首个错误步骤索引 $k$、简短批评 $h$ 及错误类型。设计动机在于：长轨迹中大部分步骤是正确的，均匀蒸馏浪费信号；且纯算术错误可通过工具解决，无需模型内化。

提示模型输出 $(k, h, type) \sim \pi_H(\cdot | x, \tau_{stud}, y^*)$。若 $type$ 为算术错误，则跳过梯度更新。批评 $h$ 仅描述逻辑偏离点，如“假设空置损失仅基于公寓租金计算”，而非提供完整修正步骤。这一设计将特权信息从“完整解”降维至“错误定位+简短批评”，大幅降低了提示生成的复杂度与长度。

### 前缀截断与反向 KL 蒸馏

标准 OPD 在全轨迹上计算损失，导致计算开销随序列长度线性增长。Fin-SD 在首个错误步骤 $k$ 前截断学生轨迹，得到前缀 $\tau_{<k}$。学生与教师均条件于该前缀，但教师额外接收批评 $h$。

$$
\mathcal{L}_{RKL}(\theta) = \mathbb{E}_{(x, \tau_{<k}, h) \sim \mathcal{F}} \left[ \sum_{j=k}^{k+L-1} D_{KL} \left( \pi_\theta(\cdot | c_j^{stud}) \parallel \pi_\phi(\cdot | c_j^{teach}) \right) \right]
$$

其中 $c_j^{stud} = [x; \tau_{<k}; \tau_{k:j-1}]$，$c_j^{teach} = [x; \tau_{<k}; h; \tau_{k:j-1}]$。该公式表明，蒸馏仅在错误发生后的 $L=100$ 个 Token 上进行，且采用反向 KL 散度。反向 KL 的模式寻求特性防止学生模型在教师认为不可能的区域分配概率质量，从而避免生成无效推理路径。通过截断，训练上下文严格位于学生原生分布内，消除了暴露偏差，同时短 Rollout 显著降低了显存占用与计算成本。

## 实验评估

实验在自建 FinanceReasoning Hard 子集（238 题）上进行，基线包括 GPT-OSS-20B 基础模型、SFT 及标准 OPSD。Fin-SD 在准确率上超越基础模型 3.03 pp，优于 OPSD 1.77 pp，且 Token 消耗减少 9.5%。

| 方法 | 准确率 (%) | 完成率 (%) | Token 消耗 (k) |
| :--- | :--- | :--- | :--- |
| Base | 69.16 | 91.18 | 525.8 |
| SFT | 62.46 | 99.02 | 228.9 |
| OPSD | 70.42 | 89.75 | 562.1 |
| Fin-SD | 72.19 | 92.19 | 508.5 |

Fin-SD 在保持高完成率的同时，显著降低了 Token 消耗，表明其生成的推理路径更简洁。SFT 虽完成率高，但准确率大幅下降，验证了微调对推理能力的破坏。

消融实验显示，将具体批评替换为通用提示（Placebo Hint）后，准确率提升幅度（+3.36 pp）与 Fin-SD（+3.03 pp）无显著差异。这暗示性能提升主要源于错误定位与截断机制，而非提示的具体内容。此外，使用 6 倍参数量的 GPT-OSS-120B 生成提示，相比自生成提示，准确率无显著变化，进一步支持了“定位即足够”的假设。

| 配置 | 准确率变化 (pp) | 95% CI |
| :--- | :--- | :--- |
| Fin-SD | +3.03 | [0.31, 5.75] |
| Placebo Hint | +3.36 | [0.98, 5.74] |
| 120B Hint | +3.03 | [0.66, 5.40] |

评估边界方面，Fin-SD 在 MMLU-Pro 和 FinTrust 合规基准上未显示显著性能退化，验证了其在受监管领域的适用性。然而，实验未对比外部强教师 OPD 方法，无法排除外部教师结合短提示的潜在优势。此外，提示内容不显著的现象可能受限于任务错误类型单一（多为约定选择错误），在更复杂的逻辑推理中是否依然成立，论文未给出回答。

## 关联研究分析

从问题动机看，Fin-SD 与 HINT-SD 均致力于解决长轨迹蒸馏中的信号稀释问题。HINT-SD 在多轮智能体场景中，通过 hindsight 选择失败相关动作跨度进行蒸馏；Fin-SD 将其迁移至单链思维推理，但进一步简化了特权信息，从“反馈条件”降维至“错误定位”。这一差异源于任务特性：金融推理错误常源于单一约定误用，定位即可纠正；而智能体任务中，错误可能源于多步交互的累积，需更丰富的反馈信号。

从方法设计看，Fin-SD 与标准 OPSD 的核心差异在于特权信息的粒度。OPSD 依赖完整参考解，计算成本高且可能引入分布外监督；Fin-SD 仅使用简短批评，降低了计算开销并保持了分布内训练。然而，Fin-SD 未对比外部教师 OPD（如 GKD 或 MiniLLM），无法证明自蒸馏在金融领域的绝对优势。若外部教师能提供更精准的逻辑修正，Fin-SD 的“定位即足够”假设是否仍成立，论文未给出回答。

## 总结

Fin-SD 针对金融合规场景下小模型推理能力不足与微调破坏对齐行为的矛盾，提出了一种局部化后见自蒸馏方法。通过定位首个错误步骤并截断轨迹，Fin-SD 在无需外部教师的情况下，实现了准确率提升与 Token 消耗降低的双重目标。实验表明，Fin-SD 在 FinanceReasoning Hard 上达到 72.19% 准确率，优于 OPSD，且未损害合规性。然而，提示内容对性能贡献不显著的现象，可能受限于任务错误类型的单一性。当面对更复杂的跨域逻辑推理时，仅靠错误定位是否足以引导正确路径，论文未给出回答。
