> 导读 在基于强化学习（Reinforcement Learning, RL）的代理系统中，技能库作为外部程序性记忆，通过提供行为先验来引导策略探索。然而，现有方法普遍将技能库视为只增不减的静态资产，导致随着策略成熟，早期有效但后期冗余或误导性的技能持续污染上下文，形成“延迟过时”现象。SKILLFORGE 提出了一种将技能库管理视为主动锻造过程的框架，通过引入基于适应度的技能生命周期状态机，实现技能与策略在训练过程中的协同进化。该框架在具身控制、网页导航及检索增强问答任务中均取得了显著性能提升，确立了动态技能管理在复杂长程任务中的有效性。其核心局限在于对预训练技能质量的依赖以及在线变异带来的计算开销，且未深入探讨技能变异在极端分布偏移下的鲁棒性。

## 研究背景

当大语言模型代理面对长程复杂任务时，单纯依赖参数化知识往往因上下文窗口限制和推理深度不足而失效。为解决此问题，代理技能（Agent Skill）被引入作为外部程序性记忆，将任务分解与工具调用封装为可复用的文本模块，在推理时动态注入上下文。这种机制实现了模型能力与任务需求的解耦，使代理无需修改权重即可扩展工作流。然而，随着技能库规模扩大，基于语义相似度的扁平检索暴露出依赖遗漏与上下文溢出问题，且静态技能库无法适应策略在训练过程中的动态演变。

主流技能增强 RL 方法（如 SkillRL）通常采用“检索-执行”两阶段架构，将技能库视为只增不减的累积资产。这种设计在策略初期能有效加速收敛，但随着策略 $\pi_\theta$ 的优化，原本辅助探索的技能可能变得冗余甚至误导，导致“延迟过时”（Delayed Obsolescence）：即技能适应度随策略成熟而下降，却仍被检索并注入上下文，造成性能退化。现有方法缺乏在训练过程中动态淘汰低效技能或修正边界技能的机制，导致技能库膨胀与上下文污染。SKILLFORGE 针对这一失效模式，提出在 RL 训练循环中嵌入技能生命周期管理，通过预退役、状态流转与 LLM 引导变异，实现技能库与策略的同步进化。

## 核心方法

### 方法参照系：技能增强 RL 与 GRPO 基线

SKILLFORGE 建立在技能增强 RL 的标准范式之上，以 Group Relative Policy Optimization (GRPO) 为策略优化器。在标准流程中，代理根据任务描述 $d$ 从技能库 $S$ 中检索 Top-$K$ 技能，将其与历史交互 $h_t$ 和当前观测 $o_t$ 拼接为上下文 $p_t$，策略 $\pi_\theta$ 据此生成动作。GRPO 通过组内归一化优势估计更新策略，无需单独的价值网络。本文的关键差异在于，标准流程中技能库 $S$ 在训练期间保持静态或仅做离线更新，而 SKILLFORGE 将 $S$ 视为随训练步数 $k$ 动态演化的变量 $S^{(k)}$，并在每个训练周期执行“锻造”操作以更新 $S$。

### 预退役评估与冷启动微调

针对初始技能库中可能存在的低质量或不适配技能，SKILLFORGE 在 RL 训练前引入预退役（Pre-retirement）阶段。该阶段利用基础模型 $\pi_{\theta_0}$ 在初始技能库 $S_0$ 上进行 $M$ 次 rollout 评估，计算每个技能 $s_i$ 的原型适应度 $\hat{f}_i$。

$$
\hat{f}_i = \frac{C_i^{(0)}}{U_i^{(0)}}, \quad S_{\text{retire}}^{(0)} = \{s_i \in S_0 \mid \hat{f}_i < \delta_{\text{pre}} \land U_i^{(0)} \ge N_{\min}\}
$$

其中 $C_i^{(0)}$ 和 $U_i^{(0)}$ 分别为成功次数和使用次数，$\delta_{\text{pre}}$ 为预退役阈值。该公式的物理含义是：仅当技能被充分使用且成功率低于保守阈值时，才将其从初始库中剔除。幸存技能 $S^{(0)} = S_0 \setminus S_{\text{retire}}^{(0)}$ 用于构建监督微调（SFT）数据集 $D_{\text{SFT}}$，仅包含未依赖被退役技能的成功轨迹。这一设计解决了直接 RL 训练初期因低质技能干扰导致的探索效率低下问题，为后续 RL 提供了高质量的冷启动策略 $\pi_{\theta_{\text{sft}}}$。

### 技能生命周期状态机与协同进化

在 RL 训练阶段，SKILLFORGE 维护一个基于适应度 $f_i^{(k)}$ 的技能生命周期状态机，包含 Trial、Active、Stable 和 Retired 四种状态。适应度 $f_i^{(k)}$ 是非平稳的，依赖于当前策略 $\pi_{\theta_k}$ 的表现。状态转移由阈值 $\delta_{\text{retire}} < \delta_{\text{demote}} < \delta_{\text{stable}}$ 控制，并引入迟滞机制以防止状态震荡。

$$
\ell(s_i) \in \{\text{Trial}, \text{Active}, \text{Stable}, \text{Retired}\}
$$

具体而言，当技能适应度 $f_i^{(k)}$ 低于 $\delta_{\text{retire}}$ 且使用次数满足要求时，技能被退役；当适应度高于 $\delta_{\text{stable}}$ 时进入稳定状态；若稳定技能适应度下滑至 $\delta_{\text{demote}}$ 以下，则降级为 Active 状态。该机制确保了技能库始终与当前策略能力对齐，解决了延迟过时问题。此外，对于适应度处于变异区间 $[\delta_{\text{low}}, \delta_{\text{high}}]$ 的边界技能，系统调用教师模型（如 Kimi-K2.5）进行 LLM 引导的变异（Mutation），生成子技能以探索技能空间的局部改进。这种在线变异机制将技能优化从离线文本编辑转化为在线策略协同进化，显著提升了技能在动态环境中的适应性。

## 实验评估

实验在 ALFWorld（具身控制）、WebShop（网页导航）和 Search-Augmented QA（检索增强问答）三个基准上进行。基线覆盖上下文记忆方法（ReAct, Reflexion）、纯 RL 方法（GRPO, RLOO）及技能增强 RL 方法（SkillRL, MemRL）。SKILLFORGE 在所有环境中均超越最强基线 SkillRL，且在 ALFWorld 上取得 92.4% 的成功率，较 SkillRL 的 89.9% 提升 2.5 个百分点；在 WebShop 上成功率为 78.4%，较 SkillRL 的 72.7% 提升 5.7 个百分点。

| 方法 | ALFWorld Succ. (%) | WebShop Succ. (%) | Search-Aug. QA Succ. (%) |
| :--- | :--- | :--- | :--- |
| GRPO | 77.6 | 66.1 | - |
| SkillRL | 89.9 | 72.7 | - |
| SKILLFORGE | **92.4** | **78.4** | **48.7** |

消融实验表明，预退役（Pre-retirement）是贡献最大的组件，移除后 WebShop 成功率下降 3.5%。移除整个生命周期管理（w/o forging）导致 ALFWorld 成功率下降 2.6%，WebShop 下降 5.8%。值得注意的是，禁用退役机制（w/o retirement）虽使技能库规模膨胀至 132 个（ALFWorld），但成功率反而低于使用 100 个技能的完整模型，证实了“质量优于规模”的假设。LLM 变异（w/o mutation）的移除导致性能下降较小（0.6%-1.6%），表明其在稳定阶段主要起微调作用，而非核心驱动力。

评估边界方面，实验未报告置信区间，且部分基线（如 SkillOpt）未在 RL 框架下直接对比，可能低估了静态优化方法在特定场景的竞争力。此外，Search-Augmented QA 的训练耗时显著高于其他环境（约 72 小时），主要受限于检索开销，这限制了该方法在实时性要求高的场景中的应用。

## 关联研究分析

从问题动机看，SKILLFORGE 与 SkillRL 同属技能增强 RL 路线，但 SkillRL 假设技能库在训练期间静态不变，仅通过检索注入上下文，无法处理策略进化导致的技能效用衰减。SKILLFORGE 通过引入动态生命周期，将技能库从“被动积累”转变为“主动锻造”，解决了 SkillRL 在长程训练中的上下文污染问题。这一差异源于对“延迟过时”现象的显式建模，而 SkillRL 未对此进行形式化定义或处理。

从方法设计看，SKILLFORGE 与 SkillOpt 均涉及技能优化，但 SkillOpt 采用离线文本梯度与验证门控，适用于静态任务分布；SKILLFORGE 则将优化嵌入在线 RL 循环，通过 LLM 变异实现技能与策略的协同进化。SkillOpt 的稳定性源于离线验证，而 SKILLFORGE 的适应性源于在线反馈。查询侧增强在数据充足时是否仍有增益，论文未给出回答，但 SKILLFORGE 在动态环境中的优势表明，在线适应度信号比离线验证更能捕捉策略-技能交互的细微变化。

## 总结

SKILLFORGE 针对技能增强 RL 中技能库静态化导致的延迟过时问题，提出了一种基于适应度的技能生命周期管理框架。通过预退役过滤低质技能、在线状态流转淘汰过时技能、以及 LLM 引导变异优化边界技能，实现了技能库与策略的协同进化。实验显示，该方法在 ALFWorld 和 WebShop 上分别取得 92.4% 和 78.4% 的成功率，显著优于静态技能库基线。其边界在于对教师模型变异质量的依赖，以及在线评估带来的计算开销。当技能库规模进一步扩大至数万级时，基于使用计数的适应度估计是否仍能保持低方差，论文未给出回答。
