作者：Kunlun Zhu、Tao Feng、Xu Han 等 8 人

> 导读 大语言模型智能体在执行长程任务时，其执行框架（Harness）在每一步均调用大型模型进行决策，导致高昂的计算成本与推理延迟。现有方法多依赖外部路由或全量调用，未能有效利用智能体内部高频、低复杂度的多步决策特性。本文提出 JevAgentHarness，将智能体循环中的常规选择拆解为选择题，由轻量级决策模型处理，大型模型仅在决策模型置信度低于阈值时介入。该架构通过构建专用基准与训练包含错误状态的决策模型，实现了效率与成功率的平衡。其价值在于确立了智能体内部细粒度决策分流的可行性，但跨环境泛化能力与复杂任务下的决策上限仍存疑。

## 研究背景

当智能体在动态环境中执行长程任务时，其核心瓶颈已从模型推理能力转移至执行框架的调用效率。传统智能体框架遵循“推理-行动-观察”循环，每一步均需大型语言模型（LLM）生成动作、参数及终止条件。这种全量调用模式在长轨迹任务中引发严重的计算冗余，因为多数步骤仅涉及从有限选项中做出常规选择。为缓解此问题，路由（Routing）与级联（Cascade）机制被引入，旨在将简单查询分配给小模型。然而，现有路由方法多作用于外部 API 网关，未能深入智能体内部循环，且缺乏针对智能体动态状态分布的评估与训练机制。

智能体内部的决策具有强依赖性：前一步的错误会导致后续状态偏离训练分布，形成分布偏移。现有决策模型多在静态、孤立的问答数据上训练，缺乏对智能体自身错误轨迹的适应性。因此，如何在智能体内部实现细粒度的决策分流，并训练能够适应动态状态分布的轻量级决策模型，成为突破执行效率瓶颈的关键。本文通过构建三级评估基准与混合决策架构，直接回应了这一执行层效率优化的核心需求。

## 核心方法

### 智能体内部决策点建模与级联架构

本文方法置于智能体执行框架（Harness）的优化范畴，区别于外部 API 路由，其核心在于将智能体循环中的决策权进行细粒度拆分。在标准智能体循环中，LLM 负责所有决策；本文将其重构为混合决策系统，定义了八个决策点（如工具选择、参数填充、反思触发等），并引入五种集成模式。

设计动机在于解决全量 LLM 调用导致的成本爆炸，同时避免小模型盲目接管导致的任务失败。本文主要采用级联（CASCADE）模式，其决策逻辑如下：

$$
a = \begin{cases}
\hat{a} & \text{if } c(s) \ge \tau_d \\
\sim \pi_L(\cdot | h_t) & \text{otherwise}
\end{cases}
$$

其中，$\hat{a}$ 为决策模型给出的最高概率选项，$c(s)$ 为其置信度，$\tau_d$ 为特定决策点的阈值，$\pi_L$ 为 LLM 策略。该公式表明，仅当决策模型置信度超过阈值时，才采纳其结果并跳过 LLM 调用；否则，LLM 接管决策。这一机制将 LLM 从高频常规决策中解耦，使其专注于处理决策模型不确定的复杂状态。

### 基于轨迹拟合的置信度阈值机制

级联架构的有效性高度依赖阈值 $\tau_d$ 的设定。固定阈值无法适应不同决策点（如工具选择与参数填充）的风险差异。本文提出基于影子模式（Shadow Mode）轨迹的阈值拟合方法。在独立任务上运行智能体，决策模型静默回答所有问题，收集轨迹数据以估计 LLM 准确率 $q_L$、调用成本 $\Delta C$ 及错误代价 $V$。

设计动机在于解决固定阈值导致的过度自信或过度保守问题。本文推导出的最优阈值规则为：

$$
\tau_d^* = \max(0, q_L - \Delta C / V)
$$

该公式的物理含义是：当决策模型的置信度超过 LLM 准确率减去成本收益比时，采纳决策模型的结果在期望损失上是最优的。通过从轨迹中拟合 $q_L$ 和 $V$，系统能够动态调整阈值，确保在节省成本的同时，将任务成功率的损失控制在可接受范围内。

### 面向动态状态分布的决策模型训练

现有决策模型在静态数据上训练，无法适应智能体因自身错误而进入的异常状态。本文提出 AGENTDECISION-4B，通过在智能体实际访问的状态上训练决策模型来解决分布偏移问题。训练数据包含成功轨迹及通过注入错误生成的“近失误”状态。

设计动机在于弥补静态训练数据与动态执行状态之间的鸿沟。本文采用监督微调（SFT）结合组相对策略优化（GRPO）的训练范式。SFT 阶段使用交叉熵损失结合 Brier 项以保持概率校准：

$$
L_{\text{SFT}} = \mathbb{E}_s \left[ -\sum_a y_a \log p_a + \mu \sum_a (p_a - y_a)^2 \right]
$$

其中 $y_a$ 为混合标签（结合真实标签与教师模型概率），$\mu$ 为校准权重。该损失函数不仅优化分类准确率，还强制模型输出概率与真实正确率对齐，为后续阈值拟合提供可靠的置信度估计。

## 实验评估

实验在 DECISIONGYM、ALFWorld 及 SWE-bench Verified 等基准上进行，对比了 LLM-only 基线、Intern-Decision 及 StartLux 等决策模型。评估协议采用非劣效性检验，要求任务成功率损失不超过 3 个百分点。

| 方法 | 基准 | 任务成功率 (%) | 成本节省 (%) | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| LLM-only (Flash) | DECISIONGYM | 99.4 | 0.0 | 基线 |
| JEV (Cascade) | DECISIONGYM | 99.4 | 14.2 | 阈值拟合后 |
| AGENTDECISION-4B | DECISIONGYM | 91.5 | 81.1 | 训练后模型 |
| LLM-only (Flash) | ALFWorld | 90.7 | 0.0 | 基线 |
| Trained 4B (Cascade) | ALFWorld | 95.0 | 89.0 | 非劣效性通过 |

主结果显示，在 DECISIONGYM 上，训练后的 AGENTDECISION-4B 在保持高成功率的同时实现了 81.1% 的成本降低。在 ALFWorld 上，该模型甚至超越了 LLM 基线，成本降低 89.0%。这表明在结构化决策任务中，轻量级模型足以替代 LLM。

消融实验揭示了训练数据分布的关键作用。仅使用成功轨迹训练会导致模型在异常状态下性能骤降，而包含错误状态的数据使模型在偏移状态下的准确率从 52.9% 提升至 98.4%。此外，GRPO 阶段在 SFT 基础上未带来显著增益，表明 SFT 已能充分拟合状态分布。

评估边界方面，本文未覆盖多语言环境及复杂代码生成任务（如 SWE-bench 上的路由效果不稳定）。可复现性方面，代码与模型已开源，但训练依赖特定 GPU 配置与 API 调用成本。

## 关联研究分析

从问题动机看，本文与 LLMRouter 等外部路由方法存在本质差异。LLMRouter 作用于查询级别，将不同复杂度的查询分配给不同模型，其假设是查询难度可静态评估。而 JevAgentHarness 作用于智能体内部步骤级别，其决策依赖于动态上下文与历史轨迹。这种差异源于任务特性：智能体步骤间的强依赖性使得静态路由失效，必须引入基于置信度的动态分流。

从方法设计看，本文与 Reflexion 等自我反思机制形成互补。Reflexion 通过语言反馈优化 LLM 策略，侧重于提升决策质量；本文则通过决策模型分流优化执行效率，侧重于降低决策成本。两者在架构上可叠加：决策模型可触发 Reflexion 模块，而 LLM 在反思后重新接管决策。然而，本文未探索决策模型与反思机制的联合优化，查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文针对智能体执行层全量调用 LLM 导致的效率瓶颈，提出 JevAgentHarness 混合决策架构。通过定义内部决策点、拟合动态置信度阈值及训练适应错误状态的决策模型，实现了执行效率的显著提升。实验证明，在结构化任务中，该方法可在保持成功率的前提下降低 81.1% 至 89.0% 的成本。然而，该方法在复杂代码任务上的路由效果不稳定，且跨环境泛化能力受限。当智能体面对完全未见过的工具生态或高度非结构化的决策空间时，基于选择题的决策模型是否仍能维持其置信度校准的有效性，论文未给出回答。
