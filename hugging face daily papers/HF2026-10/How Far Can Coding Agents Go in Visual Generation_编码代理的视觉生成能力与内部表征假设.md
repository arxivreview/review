# HuggingFace最新推荐论文 ｜How Far Can Coding Agents Go in Visual Generation? ｜编码代理的视觉生成能力与内部表征假设

研究机构：美国加州大学洛杉矶分校、清华大学

作者：Hengguang Zhou、Yuanhao Ban、Jiaqi Feng 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2610.19025)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2610.19025)

> 导读 当前文本到图像生成主要依赖端到端神经网络，其构建过程隐式编码于参数中，缺乏可解释性与精确控制。现有评估体系多聚焦于生成结果的质量打分，忽视了生成过程本身的逻辑一致性与中间表征的有效性。本文提出通用编码代理作为零样本绘图者的新范式，通过编写并执行代码（如Canvas 2D、SVG）间接生成图像。该研究揭示了代理在结构保真度上的优势与感知真实感上的局限，并验证了代码作为“外部视觉思维语言”在生成与理解中的双向效用。这一发现挑战了专用生成模型主导的默认假设，为评估从结果打分转向过程逻辑验证提供了新视角，但其在自然场景感知上的短板及内部表征假设的验证深度仍存疑。

## 研究背景

当评估模型面对生成图像时，传统指标如FID受限于高斯假设，难以捕捉局部伪影与语义错误，导致评估与人类感知脱节。为解决这一问题，多模态大语言模型（MLLMs）被引入评估领域，通过推理与定位实现细粒度诊断。然而，MLLMs在评估中通常作为黑盒评分器，其内部如何组织视觉信息、是否具备跨模态的结构化表征，仍是未解之谜。这种对生成过程“黑盒”状态的忽视，使得评估难以深入诊断模型在逻辑约束或空间一致性上的具体失效机制。

随着智能体技术的发展，通用编码代理展现出通过编写和执行代码来协调工具、迭代优化任务的能力。这一进展促使研究者追问：通用编码代理在视觉生成中的能力边界究竟在哪里？现有研究多将MLLMs用于评估或作为生成器的控制器，较少直接考察代理通过代码构建图像的能力及其内部表征特性。本文切入点在于将编码代理视为零样本绘图者，通过构建AgentDrawBench基准，系统评估其在结构保真、感知实现及整体质量上的表现，并进一步探索代码作为“外部视觉思维语言”在生成与理解中的角色，以及代理是否具备“内部视觉语言”假设所预测的一致性与连贯性。

## 核心方法

### 方法参照系：智能体驱动的视觉生成

本文问题属于“智能体生成”范畴，区别于知识库中常见的“智能体评估”或“端到端生成”。通用流程通常涉及代理接收文本提示，调用工具或生成代码，执行后获得反馈并迭代。本文的关键差异在于，代理不直接输出像素或调用专用扩散模型，而是通过编写可执行的视觉程序（如JavaScript Canvas 2D、SVG文档）来构建图像。这一范式将图像构建过程显式化为代码逻辑，使得生成过程具备可检查性与可修改性，但也引入了代码执行环境与视觉渲染之间的映射挑战。

### 核心创新：代码作为外部视觉思维语言

在生成环节，代理通过代码构建图像，其核心创新在于验证代码作为“工作表征”的有效性。通常做法是代理依赖渲染后的图像反馈进行迭代，但本文设计了“盲画”实验，即代理仅接收代码执行结果（如错误信息），不接收渲染后的RGB图像。实验显示，盲画的结构保真度达到83.0%，与有视觉反馈的85.6%相比仅下降2.6个百分点。这一结果表明，代码本身已承载了足够的场景结构信息，代理能够基于代码逻辑而非像素反馈进行有效的图像构建。

在理解环节，代理将原始图像重构为SVG代码，并基于代码回答视觉问题。这一设计解决了传统视觉问答中视觉干扰导致的信息提取困难。通过代码重构，代理能够隔离问题相关的属性（如按钮数量、文本内容），避免背景纹理的干扰。实验表明，基于代码的问答准确率为69.0%，高于基于渲染图像的65.0%，在学术与数字世界领域甚至超过基于原始图像的准确率。这验证了代码作为外部思维语言，能够以更结构化、去噪的方式支持视觉推理。

### 核心创新：内部视觉语言假设的行为探针

为探究代理是否具备共享的内部场景表征，本文提出内部视觉语言假设：$I_h = D_h(z)$，其中 $z$ 为内部表征，$D_h$ 为通过界面 $h$ 渲染图像的过程。该假设预测代理在不同界面下生成的图像应具有跨界面一致性，且在视角变换下保持空间连贯性。

为验证一致性，本文设计了独立像素查询实验：代理在独立上下文中被询问单个像素颜色，最终组装成图像。结果显示，独立查询组装的图像在粗粒度布局与色调上与整体绘图高度相似，表明代理内部存在稳定的场景布局表征。为验证连贯性，代理被要求布置房间并从不同视角绘制，随后删除其之前的绘图代码。实验显示，即使删除绘图代码，代理在重访视角时仍能保持家具位置与关系的高度一致（Jaccard 0.99，关系一致性 0.96），且墙面视图与自身平面图的一致率达99%。这一结果提供了行为证据，支持代理内部存在可复用的场景内容表征，而非仅依赖上下文中的代码片段。

## 实验评估

本文构建了AgentDrawBench基准，包含200个提示，涵盖摄影场景、人物/有机体、产品/材料、空间/3D、风格化插图、设计/符号、图表/符号七类。评估指标包括结构保真度（基于检查清单的通过率）、感知实现（基于十维度的相对胜率）及整体质量（基于MMRB2的成对胜率）。基线对比了GPT-image-1与GPT-image-2等原生生成模型。

| 方法 | 结构保真度 (%) | 整体胜率 vs GPT-image-1 (%) |
|---|---|---|
| GPT-6-Astra (Canvas 2D) | 85.8 | 47.7 |
| GPT-image-1 | 68.8 | - |
| GPT-image-2 | 90.7 | - |
| DeepSeek V4.1 Flash (SVG) | 74.7 | 34.7 |

GPT-6-Astra在结构保真度上以85.8%显著超越GPT-image-1的68.8%，但在整体胜率上仅为47.7%，低于GPT-image-2。在“设计/符号”类任务中，GPT-6-Astra的结构保真度达94.6%，整体胜率达92.0%，显示出在结构化任务上的显著优势。

消融实验揭示了反馈与预算的影响。盲画（无视觉反馈）结构保真度为83.0%，有反馈为85.6%，表明代码本身已具备较强结构表达能力。将迭代预算扩展4倍，结构保真度仅从85.6%提升至86.8%，整体胜率50.5%，显示边际收益递减。这表明在固定Canvas 2D界面下，单纯增加迭代次数难以显著提升感知质量，需改进绘图界面或引入程序化技能。

评估边界方面，本文主要依赖自动化判断（VLM评分），人工验证有限。内部视觉语言假设的验证基于行为探针，未涉及模型内部权重或激活分析。此外，实验主要使用GPT-6-Astra，跨模型泛化性未充分测试。

## 关联研究分析

从问题动机看，本文与ImageDoctor、Q-REAL等评估方法形成互补。ImageDoctor与Q-REAL利用MLLM对生成图像进行细粒度诊断，关注“结果”的质量与合理性；本文则关注“过程”的构建逻辑，通过代码执行确保结构一致性。这种差异源于任务特性：评估需模拟人类主观判断，而生成需确保逻辑可执行性。本文的“结构保真度”评估逻辑与Q-REAL的“合理性”评估类似，但本文通过代码执行而非VLM判断来保证逻辑正确性，提供了更客观的验证手段。

从方法设计看，本文与HandEval、TIQA等专用评估模型存在路线差异。HandEval与TIQA针对特定维度（手部、文本）设计专用架构，追求局部缺陷检测的精度；本文则通过通用编码代理实现多任务生成，追求跨界面的结构一致性。这种差异反映了通用性与专用性的权衡：专用模型在特定维度上精度更高（如TIQA在TIQA-Crops上SRCC 0.942），但通用代理在结构化任务上展现出更强的逻辑控制能力。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文针对端到端生成模型过程隐式、缺乏可解释性的问题，提出通用编码代理作为零样本绘图者的新范式。通过构建AgentDrawBench基准，本文验证了代理在结构保真度上的优势（GPT-6-Astra达85.8%）与感知真实感上的局限，并证实代码可作为有效的外部视觉思维语言。进一步的行为探针实验支持了内部视觉语言假设，显示代理具备跨界面一致性与空间连贯性。然而，本文实验主要依赖自动化评估，且内部表征假设的验证基于行为层面，未深入模型内部机制。当代理面对更复杂的自然场景或需要更高感知真实感的任务时，其内部表征是否仍能保持结构一致性，或是否会因感知缺陷而崩溃，论文未给出回答。
