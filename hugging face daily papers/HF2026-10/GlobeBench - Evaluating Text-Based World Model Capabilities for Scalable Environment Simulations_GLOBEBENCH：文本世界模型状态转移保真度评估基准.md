论文原文见 [arXiv](https://arxiv.org/abs/2610.22708)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2610.22708)

> 强化学习在软件工程、计算机操作等复杂环境中的规模化应用，高度依赖稳定且高保真的环境模拟器。现有文本世界模型虽能近似真实世界行为，但缺乏标准化基准来定位其模拟能力的具体失效点，导致强化学习可能优化于模型的模拟错误而非真实环境动态。GLOBEBENCH 通过构建包含 1,632 个多轮交互任务的基准，结合确定性执行后端与混合裁判架构，首次将世界模型评估从特定智能体域扩展至通用文本模拟任务。该基准通过“回溯距离”与“影响半径”两个维度量化了模型在长程依赖与状态传播上的失效模式，为评估文本世界模型作为通用环境模拟器的可靠性提供了执行级验证标准。

## 研究背景

当强化学习智能体在软件仓库、企业工作流或文本游戏等复杂环境中进行训练时，其策略优化依赖于环境状态转移的准确预测。若环境模拟器在状态更新时出现偏差，智能体将利用这些错误进行策略优化，导致在真实环境中部署时失效。文本世界模型（Text World Models）通过自回归生成预测环境对动作的响应，为构建低成本、可扩展的模拟器提供了可能。然而，评估这些模型作为通用模拟器的保真度面临根本性挑战：缺乏能够区分表面文本匹配与深层状态一致性的评估指标，且现有基准未能将失败归因于具体的模拟能力（如状态持久性或因果正确性）。

在 LLM 评估领域，主流方法多聚焦于静态题库的准确率排名或基于 LLM 裁判的开放式生成评估。这些方法隐含了题目难度固定且无数据污染的假设，且评估对象多为模型在特定任务上的表现，而非模型在潜在能力空间中的分布。对于世界模型而言，静态题库无法反映环境状态的动态演化，而纯 LLM 裁判难以验证数值计算、状态持久性等确定性约束。GLOBEBENCH 的切入点在于将评估目标从“模型生成文本的质量”转向“模型预测环境状态转移的保真度”，通过执行后端生成标准答案，规避了静态题库的记忆效应，并引入细粒度诊断体系以揭示模型在状态追踪中的具体缺陷。

## 核心方法

### 方法参照系：执行级验证与混合裁判架构

GLOBEBENCH 将世界模型评估置于“动态与自动化基准构建”与“评估指标与方法论创新”的交叉领域。与 AutoBench 等侧重题目生成的动态基准不同，GLOBEBENCH 的核心差异在于其标准答案（Gold）由确定性代码执行产生，而非人工标注或模型生成。每个评估项定义为元组 $x = (P, a, g, m)$，其中 $P$ 为可见交互历史，$a$ 为最终动作，$g$ 为执行后端生成的真实下一状态。模型需根据 $P$ 和 $a$ 预测 $\hat{g}$，评估过程采用混合裁判架构：确定性门控处理可精确匹配的字段，剩余部分交由 LLM 裁判进行语义判断。

### 核心创新：能力与技能分类体系

为定位模型失效的具体原因，GLOBEBENCH 定义了四项核心能力（Capabilities）与 19 项具体技能（Skills）。能力包括状态一致性（State Coherence, SC）、因果正确性（Causal Correctness, CC）、接口保真度（Interface Fidelity, IF）和约束执行（Constraint Enforcement, CE）。技能则是能力在具体环境行为中的实例化，如“读写持久性”或“副作用传播”。每个评估项测试一项主要技能，并映射至一项或多项能力。这种分类体系解决了传统评估中“分数高但能力弱”的构念效度问题，确保测试项测量的是环境模拟的具体行为而非表面文本匹配。例如，状态一致性要求预测状态与早期交互中的实体和事实保持一致，因果正确性要求不同动作组合导致不同的正确下一状态。

### 核心创新：回溯距离与影响半径量化

为量化模型在长程依赖与状态传播上的失效模式，GLOBEBENCH 引入两个控制变量：回溯距离（Reach-back）与影响半径（Impact Radius）。回溯距离定义为最终动作与决定其答案的早期事件之间的轮数，衡量模型向后追踪历史的能力。影响半径描述动作状态变化的传播范围，分为 L0（无状态变化）、L1/L2（仅改变命名实体）和 L3（改变未命名依赖实体）。这两个维度对应了状态追踪模型可能失效的两个方向：向后通过历史，向外通过状态。通过这两个轴，聚合成功率被分解为模型在状态传播广度与历史记忆深度上的具体失效模式，揭示了模型在长程审计与复杂状态依赖中的根本缺陷。

## 实验评估

实验在 GLOBEBENCH 的 1,632 个多轮交互任务上进行，评估了 18 个通用 LLM 与 2 个专用文本世界模型。评估协议采用二元任务成功率，标准答案由执行后端生成，确保评估目标由确定性代码产生。基线覆盖包括 GPT-6 Astra、Claude Opus 5.5 等前沿模型，以及 Qwen-AgentWorld 等专用世界模型。主实验结果显示，GPT-6 Astra 以 49.57% 的成功率位居榜首，但仍有 631 项任务未被任何模型解决，表明通用 LLM 作为世界模型存在显著能力缺口。

消融分析揭示了模型失效的具体模式。在影响半径维度上，当动作需改变未命名依赖实体（L3）时，所有模型的平均成功率从 L0 的 43.49% 骤降至 5.10%。在回溯距离维度上，当决定事件超过 40 轮时，模型成功率从 42.3% 降至 11.4%。失败类型分析显示，53.21% 的失败源于报告错误值，22.95% 源于结构错误，23.84% 源于无状态字段。开放权重模型更倾向于报告错误值（58.22%），而闭源模型更倾向于遗漏或添加字段（31.54%）。

评估边界方面，GLOBEBENCH 依赖确定性执行后端生成标准答案，确保了评估的可复现性，但限制了其在开放域或无执行后端环境中的适用性。混合裁判架构中，LLM 裁判在状态一致性维度上比人工标注更严格，可能引入评估偏差。此外，专用世界模型（DWM）表现远低于通用 LLM，暗示当前专用模型架构在通用状态追踪上存在根本缺陷，但论文未深入探讨其架构原因。

## 关联研究分析

从问题动机看，GLOBEBENCH 与 AgentWorldBench（Zuo et al., 2026）均关注文本世界模型的评估，但 AgentWorldBench 聚焦于特定智能体域的预测观测与真实执行配对，而 GLOBEBENCH 将评估范围扩展至通用文本模拟任务，并引入了更细粒度的技能分类体系。GLOBEBENCH 的“回溯距离”与“影响半径”量化方法，解决了 AgentWorldBench 未能将失败归因于具体模拟能力的问题，提供了更精细的诊断工具。

从方法设计看，GLOBEBENCH 与 AutoBench（Loi et al., 2025）均涉及自动化基准构建，但 AutoBench 侧重通过模型间互惠评估生成题目，而 GLOBEBENCH 侧重通过执行后端验证状态转移保真度。GLOBEBENCH 的混合裁判架构是对纯 LLM 裁判在数值/状态一致性上不可靠性的修正，但论文主要依赖单一 LLM 裁判（GPT-5.6 Terra）处理非确定性部分，虽有人工审计但规模有限。单一 LLM 裁判在处理“状态一致性”时的偏差是否被人工审计充分覆盖，论文未给出回答。

## 总结

GLOBEBENCH 针对文本世界模型作为通用环境模拟器缺乏标准化评估基准的问题，通过构建包含 1,632 个任务的基准，结合执行级验证与混合裁判架构，首次实现了世界模型状态转移保真度的细粒度诊断。该基准通过“回溯距离”与“影响半径”量化了模型在长程依赖与状态传播上的失效模式，揭示了通用 LLM 在复杂状态追踪中的根本缺陷。GPT-6 Astra 以 49.57% 的成功率位居榜首，但仍有 631 项任务未被任何模型解决，表明当前模型在模拟复杂环境动态方面存在显著能力缺口。GLOBEBENCH 的边界在于其依赖确定性执行后端，限制了其在开放域环境中的适用性，且混合裁判架构中 LLM 裁判的偏差可能影响评估的客观性。当评估目标从静态题库转向动态环境模拟时，如何确保 LLM 裁判在状态一致性判断上的可靠性，仍是一个待验证的问题。
