# HuggingFace最新推荐论文 ｜Multilinguality in Hybrid Attention LLMs ｜混合注意力架构下的多语言表征重组与层序优化

研究机构：美国加州大学洛杉矶分校、复旦大学

作者：Lucas Bandarkar、Junlin Hu、Chenyuan Yang 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2609.35378)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.35378)

> 长序列推理需求驱动大模型采用混合注意力架构以突破二次方计算瓶颈，但递归机制与全注意力的组合如何影响内部多语言语义组织尚属空白。现有研究聚焦于静态表征对齐或单一解码器内部的神经元干预，忽视了架构异构性对跨语言抽象形成的动态调控作用。本文通过提出 SoftCKA 指标追踪层间对齐动态，发现混合模型在首个全注意力层发生剧烈的跨语言重组，并验证了以全注意力层起始的层序在蒸馏训练中显著优于常规布局。该发现挑战了“递归层仅负责效率”的假设，但实验局限于小模型蒸馏场景，其结论向从头预训练及大规模部署的迁移性仍存疑。

## 研究背景

长序列处理中，全注意力机制的 $O(T^2)$ 复杂度成为瓶颈，混合注意力模型通过引入线性复杂度的递归机制（如 Gated DeltaNet、Mamba-2）与稀疏的全注意力层交替，在保持检索能力的同时降低内存开销。这种架构异构性引入了不同的归纳偏置：递归层维护压缩且演化的状态，而全注意力层直接访问所有先前 token 表示。这种差异可能改变模型处理语言形式与构建内部抽象的方式，但此前研究未系统考察混合架构对多语言处理的影响。

多语言大语言模型（mLLMs）普遍存在“英语中心潜在空间”，即非英语输入需映射至英语表征进行推理。早期研究通过对比学习在静态嵌入空间中拉近平行句子距离，或识别语言特异性神经元进行干预，但这些方法均假设模型内部结构同质。随着 Kimi K3、Qwen 等开源模型广泛采用混合注意力，架构本身成为影响多语言性能的新变量。本文切入点在于：混合架构中递归层与全注意力层的层序如何影响跨语言语义表征的组织？这一问题是理解混合模型多语言能力局限及优化架构设计的关键，此前缺乏系统性研究。

## 核心方法

### 方法参照系

本文问题归属于多语言表征对齐机制研究，但区别于传统在静态嵌入空间优化对齐目标的方法，其核心差异在于将分析对象从单一解码器扩展至混合架构，并引入层序作为干预变量。标准流程通常假设模型内部存在平滑的跨语言对齐过程，而本文关注异构层序导致的对齐动态突变。

### SoftCKA 跨语言对齐度量

传统跨语言对齐评估多依赖序列平均池化或最后 token 表示，导致信息丢失严重。本文提出 SoftCKA（Soft Centered Kernel Alignment），基于中心核对齐（CKA）改进，通过软对齐 token 而非显式配对，计算平行句对在隐藏状态空间中的几何相似度。其设计动机在于解决混合模型中因 tokenization 差异导致的跨语言 token 映射困难，提供比平均池化更鲁棒的层间对齐度量。

$$
\text{SoftCKA}(D) = \frac{\sum_{s \in D} h_{12}(s)}{\sqrt{\sum_{s \in D} h_{11}(s) \sum_{s \in D} h_{22}(s)}}
$$

其中 $h_{12}$ 为跨语言 RBF 核矩阵的行列中心化后 Frobenius 范数，$h_{11}, h_{22}$ 为语言内对应项。该公式通过归一化跨语言核变异，量化两种语言表示空间的共享程度，避免了绝对值比较的偏差。

### 层序蒸馏优化

基于 SoftCKA 观察到的“首个全注意力层对齐事件”，本文质疑常规“递归层后接全注意力层”的周期性布局。设计动机在于：若全注意力层是跨语言抽象形成的关键节点，则将其前置可能加速多语言语义共享。本文通过从全注意力教师模型（Qwen3-4B、Granite-4.1-3B）蒸馏训练混合学生模型，对比五种层序（Standard Periodic、Reverse Periodic、Sandwich 等）。

$$
\mathcal{L}_{KL} = D_{KL}(P_{teacher} \| P_{student})
$$

学生模型仅优化输出分布的 KL 散度，跳过中间层隐藏状态匹配，以确保层序本身而非教师结构主导多语言处理组织。实验表明，所有以全注意力层起始的层序在 1B token 训练内均显著优于标准布局，其中 Reverse Periodic 的 LLM Gap 比标准布局低 10%。

## 实验评估

实验在 27 种语言、7 个语系的数据集上进行，涵盖 MGSM、MMLU ProX、Belebele 等基准。基线覆盖同架构非混合模型（如 Qwen3 vs Qwen3.5），但缺失知识库中典型的微调对齐基线（如 AlignX、SiLP），导致无法直接对比架构优化与参数干预的相对收益。

| 教师模型 | 层序 | 相对 DKL ↓ | LLM Gap (nats) ↓ |
| :--- | :--- | :--- | :--- |
| Qwen3-4B-Base | Standard Periodic | 1.000 / 1.000 | 0.071 / 0.068 |
| Qwen3-4B-Base | Reverse Periodic | 0.677 / 0.697 | 0.045 / 0.045 |
| Qwen3-4B-Base | Sandwich | 0.665 | 0.050 |
| Granite-4.1-3B-Base | Reverse Periodic | 0.767 | 0.020 |

Reverse Periodic 在 Qwen3-4B 蒸馏中 DKL 相对值为 0.677，显著低于标准布局的 1.000，表明层序优化加速了多语言知识迁移。消融显示，Sandwich 与 Reverse Periodic 在 DKL 上接近，但 Reverse Periodic 在 16/26 种语言中 LLM Gap 最低，提示层序对语言特异性性能的影响存在差异。

评估边界受限于小模型蒸馏场景，未报告 FLORES BLEU 或 XQuAD F1 等标准 SOTA 数值，仅关注训练过程中的损失收敛。代码未公开，但超参数与数据划分细节（如 30% 英语锚点、3.5:2:1 资源分层）在附录中完整披露，可复现性较高。

## 关联研究分析

从问题动机看，本文与 LogitLens 和 PLND 共享“内部机制可解释性”思路，但将分析对象从单一解码器扩展至混合架构。LogitLens 揭示中间层英语偏向，PLND 定位语言特异性神经元，而本文发现混合模型中跨语言对齐在首个全注意力层发生剧烈重组，且 SWA 混合模型无此现象。这一差异根源在于递归层的压缩状态阻碍了平滑的跨语言抽象形成，全注意力层成为必要的“重置点”。

从方法设计看，本文与 Sparse Dimensions Control 均发现语言控制集中在局部，但干预对象从稀疏维度升级为层序结构。Sparse Dimensions Control 通过约 50 句数据定位维度，本文通过蒸馏训练验证层序，后者属于架构级干预，成本更高但影响更根本。AlignX 在中间层执行对齐，本文发现混合模型的对齐“事件”位置因架构而异，提示对齐策略需适配架构特性。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文核心矛盾在于混合注意力架构的效率优势与多语言语义组织效率之间的潜在冲突。现有方法假设内部结构同质，无法解释混合模型中跨语言对齐的动态突变。本文通过 SoftCKA 指标定位首个全注意力层的关键作用，并验证了以全注意力层起始的层序在蒸馏训练中显著降低损失。实验证明 Reverse Periodic 层序的 LLM Gap 比标准布局低 10%，但局限于 1B token 小模型蒸馏场景。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
