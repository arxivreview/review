> 像素空间扩散模型因绕过潜空间压缩而具备架构简洁性，但二次方注意力复杂度使其在高分辨率生成中面临严重的计算瓶颈。现有加速方法多针对潜空间模型设计，或依赖静态Token合并策略，难以在生成过程中动态感知图像内容的空间复杂度差异。BudgetPix提出一种基于像素熵的四叉树布局机制，通过熵引导的递归分割将图像划分为多尺度Token，并引入Patch Aggregator与Refiner处理多尺度特征，实现推理时计算预算的连续调节。该框架在极低Token预算下显著优于传统合并基线，但其布局估计依赖模型中间预测，在生成早期噪声较大时的稳定性仍需进一步验证。

## 研究背景

像素空间扩散模型直接对原始像素进行去噪，避免了潜空间自编码器带来的重建上限与额外训练阶段。然而，这种架构纯度引入了严重的计算瓶颈：标准Transformer的自注意力机制复杂度随Token数量呈二次方增长。在像素空间，高分辨率图像被划分为大量细粒度Patch，导致计算量爆炸。更关键的是，传统模型在训练时硬编码了固定的Patch网格分辨率，使得推理成本刚性固定，无法根据边缘设备的资源约束或用户的实时延迟需求动态调整，除非进行完全重训。

视觉数据的信息密度在空间上分布极不均匀：无云天空的视觉熵极低，而纹理复杂的物体需要捕捉高频细节。强制均匀网格在平坦区域与复杂区域分配相同的计算资源，造成了严重的计算浪费。现有判别式模型中的Token合并或剪枝方法虽能动态分配Token，但将其迁移至生成式模型面临“先有鸡还是先有蛋”的困境：去噪器必须在图像内容尚未完全生成时，评估局部空间复杂度以决定Token分配。现有方法要么依赖静态特征相似度，要么无法在生成过程中动态调整布局，导致在低计算预算下生成质量急剧下降。

## 核心方法

### 方法参照系：非均匀Token化与生成式适配

在判别式视觉模型中，Token优化通常基于输入图像的静态特征相似度进行合并或剪枝。然而，生成式扩散模型的去噪过程是动态的，图像内容随时间步逐步显现。BudgetPix将问题置于“计算自适应Token化”框架下，其核心差异在于：Token布局必须在推理过程中根据当前去噪状态动态估计，而非基于固定的输入特征。该框架包含三个关键组件：熵引导的编码器、尺度感知的解码器，以及支持可变Token数量的训练与采样策略。

### 熵引导四叉树布局构建

传统方法使用固定大小的Patch网格，忽略了图像内容的空间异质性。BudgetPix引入基于局部强度熵的四叉树递归分割机制，构建非均匀布局。在训练阶段，布局直接由真实图像计算；在推理阶段，由于干净图像不可得，模型先运行若干预热步生成预测图像，再据此估计布局。

对于每个空间单元 $R$，计算其内部像素强度的 $K$ 分箱直方图及香农熵：

$$ H(R) = -\sum_{k=1}^{K} q_k(R) \log_2 q_k(R) $$

其中 $q_k(R)$ 表示落入第 $k$ 个分箱的像素比例。若熵 $H(R)$ 低于阈值 $\tau_s + \delta$，该单元保留为单个Token；否则递归分裂为四个更细粒度的单元。这一机制确保平坦区域使用大Patch（低Token数），复杂区域使用小Patch（高Token数），从源头减少无效计算。

### 多尺度Token编码与解码

非均匀布局导致Patch尺寸不一，标准Patch Embedder无法直接处理。BudgetPix设计了双路径编码器：细路径处理基础 $p \times p$ Patch，直接通过预训练Embedder映射；粗路径处理大于 $p \times p$ 的Patch，先双线性下采样至 $p \times p$ 再嵌入，同时引入Patch Aggregator（PA）恢复高频细节。PA将粗Patch分割为子Patch，独立嵌入后通过尺度混合器融合为校正向量。

解码器镜像该结构，通过Patch Refiner（PR）恢复粗Token解码后的局部纹理。PR是一个轻量级Transformer，在局部坐标系内处理子Patch序列，生成高频残差并加回上采样后的基础Patch：

$$ \hat{P}_i^{(s)} = \text{resize}_{np}(\hat{P}_i) + \text{PR}_s(\text{split}(\hat{P}_i), h_i) $$

其中 $h_i$ 为Transformer输出的Token特征。该设计使粗Token在保持宏观语义的同时，通过局部注意力机制恢复细节，避免了直接下采样导致的纹理丢失。

### 布局增强训练与动态采样

预训练模型仅见过固定Token数量，直接输入可变长度序列会导致分布偏移。BudgetPix在微调阶段引入布局增强策略，以概率 $a$ 使用均匀布局，以概率 $b$ 使用随机布局（强制粗Token覆盖复杂区域），以概率 $1-a-b$ 使用内容自适应布局。这种混合训练迫使模型学习处理任意Token分布，而非依赖“粗Token仅代表平坦背景”的假设。推理时，前 $n_w$ 步使用均匀布局确立全局构图，后续步骤根据当前预测图像的熵动态更新布局，实现计算预算的连续调节。

## 实验评估

实验在ImageNet类条件生成与PartiPrompts文本到图像生成任务上进行，评估指标包括FID、Inception Score、GenEval及DPG-Bench。基线对比涵盖ToMe、FeatSim及并发工作RTI。BudgetPix在极低Token预算下展现出显著优势，而基线方法在预算低于50%时性能急剧崩溃。

| 方法 | 预算 | GenEval ↑ | DPG-Bench ↑ |
| :--- | :--- | :--- | :--- |
| Base Model | 100% | 0.882 | 84.7 |
| Base Model | 25% | 0.017 | 8.0 |
| ToMe | 25% | 0.229 | 54.6 |
| FeatSim | 25% | 0.007 | 17.0 |
| RTI | 25% | 0.859 | 83.0 |
| **BudgetPix** | **25%** | **0.874** | **84.3** |

在MiniT2I-L/16模型上，BudgetPix在25% Token预算下GenEval得分0.874，接近全预算基线的0.882，而ToMe与FeatSim分别降至0.229与0.007。RTI虽在低预算下保持较高得分，但BudgetPix在DPG-Bench上仍略胜一筹。

| 方法 | 预算 | FID-50k ↓ | Inception Score ↑ |
| :--- | :--- | :--- | :--- |
| Base Model | 100% | 2.66 | 337 |
| Base Model | 50% | 31.57 | 127 |
| ToMe | 50% | 49.16 | 78 |
| FeatSim | 50% | 110.60 | 16 |
| **BudgetPix** | **50%** | **5.57** | **281** |

在JiT-L/32类条件生成中，BudgetPix在50%预算下FID为5.57，远低于基线的31.57，且Inception Score保持在281，证明其在大幅压缩计算量时仍能维持高感知质量。消融实验显示，Patch Aggregator贡献了主要性能提升，而Patch Refiner在低预算下进一步降低FID约1-2个点。

评估边界方面，论文未提供代码开源链接，且布局估计依赖模型中间预测，在生成早期噪声较大时可能产生次优布局。此外，全分辨率阶段（如PixelDiT的像素阶段）限制了最大加速比。

## 关联研究分析

从问题动机看，BudgetPix与ToMe、FeatSim等Token合并方法存在根本差异。后者基于特征相似度合并Token，假设相似特征可共享表示，这在判别式任务中有效，但在生成式任务中，特征相似度无法反映像素级的空间复杂度，且合并操作本身引入额外计算开销。BudgetPix基于像素熵直接量化信息密度，无需特征提取，且通过四叉树结构保证布局的层级一致性。RTI作为并发工作，使用区域Token进行自适应，但BudgetPix的多尺度四叉树在极低预算下展现出更强的鲁棒性，表明基于熵的启发式规则在生成早期比基于学习的区域划分更稳定。

从方法设计看，BudgetPix与潜空间DiT加速方法（如TeaCache、SpargeAttention）处于不同技术路线。后者通过缓存或稀疏注意力优化计算内核，属于训练-free或轻量级微调方法，主要解决时间步冗余或注意力稀疏性。BudgetPix则通过改变输入Token结构，从源头减少序列长度，属于架构级改造。这种差异源于像素空间模型缺乏潜空间压缩先验，必须通过显式的Token优化来缓解二次方复杂度。然而，BudgetPix需要微调预训练模型以适应可变Token布局，这与领域内“训练-free优先”的共识相悖，暗示像素空间模型可能因架构刚性而必须采用训练-based的Token优化策略。

## 总结

BudgetPix针对像素空间扩散模型计算成本刚性固定与视觉信息空间分布不均的矛盾，提出基于像素熵的四叉树动态Token化框架。通过熵引导布局构建、多尺度编码解码及布局增强训练，该框架使预训练模型能在推理时连续调节计算预算。实验表明，在25% Token预算下，BudgetPix在MiniT2I-L上GenEval得分0.874，接近全预算性能，显著优于传统合并基线。其局限在于布局估计依赖模型中间预测，在生成早期噪声较大时可能产生次优布局，且全分辨率阶段限制了最大加速比。当模型在生成早期无法准确估计图像熵时，基于预测图像的布局估计是否会引入系统性偏差，进而影响最终生成质量，论文未给出回答。
