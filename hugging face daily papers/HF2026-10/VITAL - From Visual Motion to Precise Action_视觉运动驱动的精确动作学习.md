# HuggingFace最新推荐论文 ｜VITAL: From Visual Motion to Precise Action ｜视觉运动驱动的精确动作学习

研究机构：复旦大学、新加坡国立大学

作者：Ao Liang、Youquan Liu、Mingxiao Li 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2610.20604)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2610.20604)

> 世界-动作模型旨在将视觉预测转化为驾驶决策，但现有方法通常将动作专家与视觉动态解耦，导致动作目标缺乏视觉接地。本文指出，即使给定未来图像，纯视觉重建仍遗留高频度量误差，无法直接支撑高精度轨迹规划。VITAL 提出一种动作分词器，将视觉运动脚手架与归一化度量残差配对，使动作专家直接学习物理动态与厘米级修正。该架构在单步推理下实现了高精度与高效率的平衡，但残差强化学习的泛化边界及分布外场景的鲁棒性仍需进一步验证。

## 研究背景

当自动驾驶系统试图从视觉流推断未来轨迹时，世界-动作模型（World-Action Models）通过耦合视频预测与轨迹生成来建立视觉与控制的联系。然而，主流设计通常让动作专家学习由轨迹坐标独立定义的代码，而非直接源自视觉动态。这种表征间隙导致两个专家通过分离构建的表示描述同一物理运动，注意力机制虽连接了特征，却未共享预测目标。近期研究如 RepWAM 和 LingBot-VA 2.0 尝试从视觉转换中学习潜在动作，但这些分词器主要在视觉特征空间重建转换，难以恢复驾驶所需的度量细节。

本文的核心切入点在于揭示“视觉重建精度”与“动作预测精度”之间的断层。研究首先在一个简化设定中考察：即使给定记录的未来图像，模型重建自车轨迹时仍遗留平均 123.6 mm 的位移误差（ADE），且高频速度能量占比仅为 0.1%。这表明视觉运动仅能捕捉平滑的主导机动，而丢失了道路边界附近至关重要的厘米级细节。因此，单纯依赖视觉预测或端到端轨迹回归均存在瓶颈：前者精度不足，后者缺乏视觉接地。VITAL 旨在通过显式分离视觉运动脚手架与度量残差，解决这一精度与接地的双重缺失。

## 核心方法

### 视觉运动与度量残差的解耦表示

在标准世界-动作模型中，动作专家通常直接预测轨迹坐标或离散动作令牌。VITAL 改变了这一动作目标的构建方式，提出一种双码表示：视觉运动脚手架（Visual Scaffold）与归一化度量残差（Metric Residual）。视觉运动码从记录的未来图像中解码出轨迹脚手架，捕捉主导机动；度量残差码则编码脚手架与演示轨迹之间的差异。

该设计的动机在于解决纯视觉重建的高频细节丢失问题。通过归一化，残差获得了独立的学习尺度，使得模型能够同时优化宏观运动与微观修正。解码过程可表示为：

$$ \hat{Y} = \text{Decode}_{\text{scaffold}}(Z_{\text{vis}}) + \text{Decode}_{\text{residual}}(Z_{\text{res}}) $$

其中 $Z_{\text{vis}}$ 为视觉运动码，$Z_{\text{res}}$ 为归一化残差码。这一解耦使得视觉接地与度量精度不再相互干扰，而是互补增强。

### 基于流匹配的一步生成与残差强化学习

在获得解耦的动作目标后，VITAL 使用流匹配（Flow Matching）训练动作专家，从当前图像、自车状态和导航命令联合预测这两个代码。与传统扩散模型需要多步去噪不同，VITAL 在推理时仅需一步流评估即可生成可执行轨迹，无需生成未来图像或评分候选轨迹。

为进一步优化执行精度，本文引入残差强化学习（Residual RL）后训练。在模仿学习后，冻结动作生成器和解码器，仅在残差坐标中学习有界更新。这一设计允许通过单次确定性修正来细化局部执行，同时保持预测的视觉脚手架固定。残差修正的优化目标可形式化为：

$$ \mathcal{L}_{\text{RL}} = \mathbb{E}_{\pi} [R(\tau_{\text{refined}}) - R(\tau_{\text{base}})] $$

其中 $\tau_{\text{refined}}$ 为经过残差修正的轨迹，$R$ 为奖励函数。该机制在不增加推理延迟的前提下，通过局部修正提升了规划质量。

## 实验评估

实验在 NAVSIM v1 和 v2 基准上进行，主要评估指标为 PDMS（Planning Driving Metric Score）和 EPDMS（Extended PDMS）。基线覆盖包括 DiffusionDrive、SUV、SimWAM 等世界-动作模型及回归/选择方法。VITAL 在单步推理下实现了 90.8 PDMS，接近其十步推理的 90.9 PDMS，且推理速度提升 3.29 倍。

| 方法 | NFE/plans | PDMS (v1) | EPDMS (v2 navtest) | EPDMS (v2 navhard) |
| :--- | :--- | :--- | :--- | :--- |
| DiffusionDriveV2 | 2/20 | 91.2 | 87.5 | - |
| SUV | 10/1 | 90.9 | 91.0 | 36.9 |
| SimWAM (RL) | 1/1 | 91.5 | - | - |
| VITAL (1 step) | 1/1 | 90.8 | 91.1 | 38.6 |
| VITAL (10 steps) | 10/1 | 90.9 | - | 38.1 |

消融实验验证了视觉接地与残差修正的必要性。在冻结特征探针实验中，仅使用自车/导航输入时，轨迹自编码器（AE）的 ADE 为 1.08 m，而 VITAL 为 1.62 m；但加入匹配视觉输入后，VITAL 的 ADE 降至 0.72 m，PDMS 提升至 79.4，显著优于 AE 的 0.80 m 和 73.2 PDMS。这表明 VITAL 的优势源于视觉场景对应关系，而非单纯的容量优势。

| 目标类型 | ADE (m) | PDMS | MSEV |
| :--- | :--- | :--- | :--- |
| Raw trajectory | 1.46 | 55.0 | - |
| Trajectory AE | 1.25 | 64.9 | - |
| VITAL (shuf. vision) | 2.20 | 52.3 | - |
| VITAL (matched vision) | 0.72 | 79.4 | 0.38 |

评估边界方面，实验主要依赖 NAVSIM 的模拟评分，缺乏真实世界闭环测试。残差强化学习在反应式延续场景（navhard）中仅带来 0.5 EPDMS 的提升（38.6 vs 38.1），表明局部修正无法替代对机动本身的重新规划。此外，多数基线未报告置信区间，且计算效率评估仅包含推理延迟，未涵盖训练成本。

## 关联研究分析

从问题动机看，VITAL 与 RepWAM 和 LingBot-VA 2.0 共享“视觉运动作为动作目标”的理念，但存在关键差异。RepWAM 和 LingBot-VA 2.0 学习视觉状态转换之间的潜在动作，旨在重建视觉变化；而 VITAL 的残差目标明确指向视觉解码轨迹与演示轨迹之间的度量差异。这一差异源于任务特性：驾驶规划对厘米级精度敏感，而通用视频生成更关注语义一致性。VITAL 通过显式编码度量误差，解决了纯视觉重建在物理坐标上的精度瓶颈。

从方法设计看，VITAL 与 SUV 和 SimWAM 同属世界-动作模型框架，但推理范式不同。SUV 和 SimWAM 通常依赖多步采样或候选评分来优化动作，计算成本高；VITAL 通过解耦表示和残差 RL，实现了单步确定性生成。然而，SUV 在 v2 navhard 上通过十步采样达到 36.9 EPDMS，而 VITAL 单步即达 38.6，显示了解耦表示在效率上的优势。但 SUV 的多步机制是否能在更复杂的分布外场景中提供更强的鲁棒性，论文未给出回答。

## 总结

VITAL 针对世界-动作模型中视觉预测与动作控制表征脱节的问题，提出了一种视觉运动脚手架与度量残差解耦的动作分词器。通过流匹配一步生成和残差强化学习，该架构在 NAVSIM v1 上实现 90.8 PDMS，并在 v2 navhard 上达到 38.6 EPDMS，显著优于多步采样基线。其核心价值在于证明了视觉接地与度量精度可通过解耦表示同时优化，且单步推理足以支撑高精度规划。然而，残差修正仅能调整局部路径，无法应对需要根本性改变机动的反应式场景，且实验局限于模拟评分。当面对真实世界中传感器噪声或极端分布外场景时，这种依赖视觉脚手架的解耦架构是否仍能保持精度，仍需进一步验证。
