> 导读 从人类第一人称视频中提取手部动作以训练机器人策略，核心瓶颈在于单目重建的几何不稳定与物理信息缺失。现有方法多依赖裁剪帧回归，导致深度抖动与尺度漂移，且缺乏接触力标签，难以直接用于机器人控制。RLHND 将预训练视频扩散模型转化为确定性特征提取器，通过形状缓存消除尺度歧义，利用解剖学约束保证姿态合理性，并解耦触觉专家流以估计顶点级接触与力。该工作显著提升了手部重建精度与机器人重定向质量，但其对视频基础模型先验的依赖及触觉泛化能力仍待验证。

## 研究背景

当机器人策略学习试图从海量人类视频中获取监督信号时，首要障碍是动作空间的映射与物理状态的感知。传统手部追踪方法通常基于裁剪图像回归 MANO 参数，这种逐帧独立处理方式忽略了时序上下文，导致重建结果在深度轴上剧烈抖动，且因透视投影的尺度-深度歧义，同一手部的估计尺寸在单段视频内波动可达 8 mm。这种几何不稳定性直接破坏了机器人动作重定向的可行性，微小的姿态误差在重定向过程中会被放大为不可执行的关节指令。

为缓解几何歧义，近期研究引入视频基础模型以利用其内部化的运动先验，但现有方案如 ACE-Ego-Hand 仍主要关注姿态回归，未显式建模交互中的物理接触与力分布。然而，机器人操作不仅依赖几何轨迹，更依赖接触状态以区分“抓取”与“悬停”。由于人类视频缺乏触觉传感器数据，现有方法要么忽略物理信息，要么依赖昂贵的人工标注。RLHND 针对这一缺口，提出在单目视频下联合估计高精度手部姿态与稠密触觉信号，旨在为机器人学习提供兼具几何稳定性与物理合理性的动作标签。

## 核心方法

### 视频基础模型的确定性特征提取

RLHND 的方法参照系建立在视频扩散模型的特征提取之上。通用流程通常将视频输入扩散模型的去噪接口，但 RLHND 指出，对于确定性追踪任务，应利用 Cosmos 3 的 conditioning-frame 接口接收干净帧，以保持与预训练分布的一致性。该模块通过 Wan2.2 VAE 将视频片段编码为干净潜变量 $z$，并仅微调 Patch Embedding 与 LoRA 适配器，输出确定性的时空特征网格 $F$。这一设计避免了去噪接口在零噪声水平下的分布外问题，使特征提取器能稳定继承视频模型对手部运动与物体交互的强先验。

### 解剖学约束与形状缓存机制

在姿态专家流中，RLHND 针对传统 MANO 模型 45 自由度（DoF）中存在的非物理旋转轴问题，引入解剖学约束。标准 MANO 允许每个关节进行三轴旋转，但人类手指在 PIP 和 DIP 关节处无法进行扭转（twist）和展开（spread）运动。RLHND 将旋转轴对齐解剖结构，并冻结不可行轴，将自由度缩减至 29 DoF。约束集 $C$ 定义为：

$$
C = \{ \Theta : \phi^{\text{twist}}_j = 0, \phi^{\text{spread}}_j = 0, \forall j \in \text{PIP} \cup \text{DIP} \}
$$

该公式强制手指关节仅保留弯曲自由度，消除了非物理的扭曲姿态。此外，为解决尺度-深度歧义，RLHND 引入形状缓存（Shape Caching）机制。模型在视频首个高可见度片段估计形状参数 $\beta$，并将其缓存用于整个视频的重建：

$$
\beta_{\text{cache}} = \hat{\beta}_{w^*}, \quad w^* = \min \{ w' : v_{w'} > T_v \}
$$

其中 $v_w$ 为片段 $w$ 中手部可见帧的比例，$T_v$ 为可见度阈值。该机制消除了单段视频内手部尺寸的波动，并允许注入预校准的 $\beta$ 值，显著提升了重定向到机器人时的动作平滑度。

### 解耦触觉专家与 LBS 特征传播

触觉专家流在姿态流冻结的情况下独立训练，以避免稀疏的触觉监督干扰姿态预测。由于对 778 个 MANO 顶点进行注意力计算成本过高，RLHND 在骨骼级别（16 个关节）进行特征推理，并通过线性混合蒙皮（LBS）权重将特征传播至顶点。顶点触觉特征 $h_{t,v}$ 计算如下：

$$
h_{t,v} = \sum_{j} W_{\text{lbs}, vj} [X^L_B]_{t,j} + m_v
$$

其中 $W_{\text{lbs}}$ 为固定的 MANO 蒙皮权重矩阵，$X^L_B$ 为骨骼级特征，$m_v$ 为可学习的顶点嵌入。该设计在保持计算效率的同时，实现了顶点级的接触概率 $\hat{c}_{t,v}$ 与力分布 $\hat{f}_{t,v}$ 预测，为机器人策略提供了细粒度的物理交互标签。

## 实验评估

实验在 HOT3D、ARCTIC 和 EgoDex 数据集上评估姿态重建，在 OpenTouch 和 PressureVisionDB (PVDB) 上评估触觉估计。基线覆盖包括 HaMeR、WiLoR 等经典 2D/3D 方法，以及 ACE-Ego-Hand 等视频基础模型方法。RLHND 在 HOT3D 上的 MPJPE-p 为 13.01 mm，显著优于 ACE-Ego-Hand 的 24.41 mm，且 Jitter 指标从 6.48 降至 4.38，验证了视频先验与形状缓存对时序稳定性的贡献。

| 方法 | HOT3D MPJPE-p (mm) | HOT3D Jitter | OpenTouch Contact F1 | OpenTouch Force MAE (kPa) |
| :--- | :--- | :--- | :--- | :--- |
| ACE-Ego-Hand | 24.41 | 6.48 | - | - |
| HOPE | - | - | 0.663 | 1.781 |
| RLHND (Ours) | 13.01 | 4.38 | 0.696 | 0.489 |

消融实验表明，移除 Cosmos 3 编码器（A0）导致所有指标显著下降，证实了视频基础模型先验的主导作用。移除解剖学约束（A1）或形状缓存（A2）均导致 MPJPE 上升，但形状缓存对重定向质量（Q-err）的改善更为显著。在触觉估计中，移除仅接触数据（B2）导致 Contact F1 从 0.572 骤降至 0.047，而力估计指标变化不大，说明接触标签对接触头至关重要，而力标签主要依赖力监督数据。

评估边界方面，触觉估计仅在 OpenTouch 和 PVDB 上验证，未测试在未见物体类别上的泛化能力。此外，机器人实验仅针对 Dexterous Point Policy，未覆盖更复杂的全身控制策略。代码承诺开源，但具体超参数与训练细节需参考附录。

## 关联研究分析

从问题动机看，RLHND 与 ACE-Ego-Hand 均利用视频基础模型，但 ACE-Ego-Hand 将干净视频输入去噪接口，而 RLHND 使用 conditioning 接口并引入形状缓存。这一差异源于 RLHND 对机器人重定向中尺度一致性的强调，ACE-Ego-Hand 未显式解决单视频内的尺度漂移问题。从方法设计看，RLHND 与 HOPE 均涉及触觉估计，但 HOPE 依赖专用触觉数据集，而 RLHND 通过解耦专家流和 LBS 特征传播，实现了从单目视频到稠密触觉的端到端估计，尽管其力估计精度（MAE 0.489 kPa）仍受限于触觉数据的稀缺性。

## 总结

RLHND 解决了单目手部追踪中几何不稳定与物理信息缺失的核心矛盾，通过视频基础模型先验、解剖学约束与解耦触觉流，实现了高精度姿态与稠密触觉的联合估计。在 HOT3D 上 MPJPE-p 降至 13.01 mm，机器人策略成功率提升 6.7%。其边界在于触觉估计依赖特定数据集，且解剖学约束可能限制非标准手势的重建。当面对训练集中未出现的复杂物体交互时，该模型估计的接触力分布是否仍具备物理合理性，论文未给出回答。
