> 交互式视频世界模型旨在构建能够感知、交互并预测物理世界演化的内部模拟器，其核心价值在于弥合被动视频生成与主动具身智能之间的鸿沟。现有方法多依赖单一动作接口（如键盘或机器人关节），难以同时处理自由文本语义与连续相机轨迹的混合控制，且在多轮交互中易出现动作时序错位与跨段重复。Hy-Nomas 提出了一种 8B 参数的扩散 Transformer（Diffusion Transformer, DiT）架构，通过动作感知因果注意力（Action-aware Causal Attention）将动作指令限制在特定时间窗口，结合 Prompt Enhancer 模块实现多模态控制统一。该模型在单张 RTX 4090 上实现了分钟级推演的实时交互，但在物理因果性的显式建模上仍依赖数据驱动，其长时程状态持久性是否仅靠 KV Cache 即可支撑，尚需更严苛的基准验证。

## 研究背景

当用户试图通过自然语言指令（如“让角色跳上桌子”）和相机运动（如“环绕拍摄”）共同控制一个虚拟世界时，模型必须同时解析语义意图与几何约束。这一需求暴露了传统视频生成模型的局限：它们通常是开环的，仅关注视觉分布匹配，缺乏对动作-状态因果关系的显式建模。为解决此问题，领域内确立了动作条件化生成范式，即给定历史观测 $O_{1:t}$ 和动作 $A_{1:t}$，预测未来观测 $O_{t+1:T}$。然而，当动作从离散键盘指令扩展为自由文本时，模型面临两个核心失效：一是段内动作时序错位，即视频生成未能严格遵循文本中动作发生的先后顺序；二是跨段动作重复，即早期动作描述在后续生成中被错误地反复执行。

当前主流路线如 Genie 系列和 GameNGen 虽确立了动作条件化范式，但多聚焦于单一模态控制或特定游戏环境。具身智能应用（如 ABot-PhysWorld）虽强调物理一致性，但依赖机器人关节等结构化动作接口，难以泛化至开放域文本交互。实时交互架构（如 WorldPlay）虽解决了延迟问题，但在多轮交互中缺乏对持久场景信息与瞬时动作指令的区分机制。Hy-Nomas 的切入点在于：通过解耦描述性上下文与动作性指令，在注意力机制层面实现语义与几何控制的统一，从而在多轮交互中维持场景持久性并精确响应瞬时指令。

## 核心方法

### 方法参照系：自回归 DiT 与因果注意力

Hy-Nomas 基于 HunyuanVideo 1.5 预训练权重，将其从双向生成模型改造为自回归世界模型。标准流程中，视频被划分为时间有序段（Segment），模型逐段生成。传统做法是将双向注意力替换为分段因果注意力（Segment-wise Causal Attention），即当前段仅能关注当前及历史段。然而，这种粗粒度掩码无法区分段内的描述性文本与动作性文本，导致动作时序错位。Hy-Nomas 在此参照系基础上，引入了更细粒度的动作感知掩码机制。

### 动作感知因果注意力（Action-aware Causal Attention）

该机制旨在解决段内动作错位与跨段动作重复。在标准分段因果注意力中，查询令牌（Query Tokens）可关注整个段的文本令牌，包括不同时间点的动作描述。Hy-Nomas 将每段文本令牌划分为描述性头部（Descriptive Head，描述环境）和动作尾部（Action Tails，$a_0, \dots, a_n$，指定具体动作及时间窗口）。

$$
\text{Mask}(q, k) = \begin{cases}
1 & \text{if } k \in \text{Descriptive Head} \text{ or } (k \in \text{Action Tail } a_i \text{ and } q \in \text{Window}(a_i)) \\
0 & \text{otherwise}
\end{cases}
$$

该公式定义了注意力掩码：查询令牌仅能关注描述性头部令牌，或当查询令牌位于特定动作 $a_i$ 的时间窗口内时，才能关注对应的动作尾部令牌。这一设计确保了环境上下文跨段可用，而动作指令被严格限制在其原始段和时间窗口内，从而阻断了历史动作对后续生成的干扰，解决了跨段重复问题。

### 分段强制训练（Segment Forcing）

为缓解自回归生成中的误差累积，Hy-Nomas 采用分段强制训练策略。在训练过程中，模型不仅使用真实历史作为上下文，还利用自身预测的低噪声潜变量作为后续段的上下文。

$$
\tilde{x}_{s,t_{\text{ctx}}} = x_{s,t} + (t_{\text{ctx}} - t)\hat{v}_s, \quad t_{\text{ctx}} \sim U(0.1, 0.3)
$$

该公式表示从当前段的噪声潜变量 $x_{s,t}$ 出发，通过一步去噪得到低噪声状态 $\tilde{x}_{s,t_{\text{ctx}}}$，并将其追加到 KV Cache 中作为下一段的上下文。$t_{\text{ctx}}$ 的采样范围模拟了推理时上下文段的噪声水平。这一机制使模型在训练阶段即暴露于自身预测误差分布中，提升了推理时的鲁棒性。

## 实验评估

### 实验设置与主结果

Hy-Nomas 在自建基准 Hy-Nomas-Bench 上进行了评估，涵盖多轮文本交互、相机导航、交错控制及空间记忆四个维度。对比基线包括 Genie 3、LingBot-World v2 和 HappyOyster。评估采用成对人类评估，指标包括提示遵循度、物理合理性、相机控制和记忆一致性。

| 对比模型 | 空间记忆胜率 (Win) | 平局 (Tie) | 空间记忆败率 (Loss) |
| :--- | :--- | :--- | :--- |
| Genie 3 | 56.7% | 13.3% | 30.0% |
| HappyOyster | 46.7% | 30.0% | 23.3% |
| LingBot-World v2 | 40.0% | 58.3% | 1.7% |

在空间记忆任务中，Hy-Nomas 对 Genie 3 的胜率为 56.7%，显著高于对 LingBot-World v2 的 40.0%。这表明动作感知注意力机制在维持场景持久性方面具有优势。然而，该基准为自建，缺乏与领域内标准基准（如 LIBERO、Minecraft）的直接可比性。

### 消融与设计决策验证

论文未提供详细的消融实验表格，但通过训练课程（Training Curriculum）的设计验证了关键决策。从分段因果注意力到动作感知注意力的过渡，显著减少了动作顺序错误。分段强制训练与扩散蒸馏（Diffusion Distillation）的结合，将采样步数降至 4 NFEs（Number of Function Evaluations），在单张 RTX 4090 上实现了实时推理。这一设计决策表明，通过系统级优化（INT8 量化、滑动窗口注意力）与算法级优化（蒸馏）的结合，可在保持视觉质量的同时满足实时性需求。

### 评估边界与可复现性

评估主要依赖人类主观判断，缺乏客观的几何一致性或物理合理性量化指标。自建基准 Hy-Nomas-Bench 的评估者偏好偏差未通过盲测或交叉验证完全排除。代码与模型权重已承诺开源，但训练基础设施细节（如具体 GPU 型号与数量）未在正文中完全披露，可能影响复现精度。

## 关联研究分析

从问题动机看，Hy-Nomas 与 Genie 3 均致力于交互式世界生成，但 Genie 3 更侧重于从视频数据中学习通用动态，其动作接口多为离散或受限。Hy-Nomas 则聚焦于自由文本与相机轨迹的混合控制，通过 Prompt Enhancer 模块将用户意图转化为结构化 JSON 提示，这一设计在开放域语义解析上更具灵活性。然而，Genie 3 在大规模视频预训练上的数据规模可能赋予其更强的物理常识，Hy-Nomas 是否能在无显式物理引擎的情况下达到同等物理合理性，论文未给出直接对比。

从方法设计看，Hy-Nomas 与 WorldPlay 均关注实时性与几何一致性。WorldPlay 通过流式生成架构维持长期几何一致性，而 Hy-Nomas 依赖 KV Cache 与结构化 Caption 的隐式记忆。WorldPlay 在 RE10K 基准上达到 0.82 的准确率，而 Hy-Nomas 未在该基准上报告成绩。两者在记忆机制上的差异——显式几何重建 vs. 隐式文本/视觉缓存——暗示了在不同任务域（室内场景 vs. 开放世界）下的取舍。Hy-Nomas 的 KV Cache 机制在分钟级推演中表现稳定，但其状态持久性是否依赖于文本描述的冗余性，而非真正的几何理解，尚不明确。

## 总结

Hy-Nomas 针对交互式世界模型中自由文本与相机控制难以统一、多轮交互易出现动作时序错位的核心矛盾，提出了动作感知因果注意力与分段强制训练策略。该模型通过解耦描述性上下文与动作性指令，在单张 RTX 4090 上实现了分钟级实时交互，并在空间记忆任务中对 Genie 3 取得 56.7% 的胜率。然而，其评估依赖自建基准，缺乏与标准具身智能基准的直接对比，且物理因果性仍依赖数据驱动而非显式物理引擎。当推演时长超过分钟级或场景复杂度显著增加时，仅靠 KV Cache 与结构化文本能否维持几何与语义的长期一致性，论文未给出回答。
