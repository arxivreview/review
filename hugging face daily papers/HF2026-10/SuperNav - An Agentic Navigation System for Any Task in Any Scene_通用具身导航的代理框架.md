# HuggingFace最新推荐论文 ｜SuperNav: An Agentic Navigation System for Any Task in Any Scene ｜通用具身导航的代理框架

研究机构：浙江大学、深圳大学

作者：Jinkai Zhang、Jingyi Xu、Yuanhong Yu 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2610.12126)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2610.12126)

> 导读 通用服务机器人需在未知环境中响应从具体物体定位到抽象需求满足的多样化指令，现有方法受限于僵化的任务特定工作流或依赖导航数据覆盖的端到端模型，难以兼顾任务与场景泛化。SuperNav 引入代理框架（Agent Harness），让预训练多模态大语言模型（MLLM）专注于语义理解与决策，通过统一视觉点接口调用导航工具执行物理交互。该框架解耦了高层推理与低层控制，在单物体、多物体及需求驱动导航中显著超越基线。其核心价值在于确立了“模型调用工具”的具身导航范式，但无显式地图下的全局路径规划鲁棒性仍存疑。

## 研究背景

当机器人面对“寻找一个休息的地方”这类抽象指令时，其挑战远超“寻找沙发”的类别匹配。前者要求智能体理解隐含需求、推断场景中的可满足对象，并动态调整探索与验证策略。传统零样本导航（Zero-Shot Object Navigation, ZSON）依赖预训练视觉语言模型（Vision-Language Model, VLM）评估观测与目标的语义相关性，但任务特定逻辑硬编码了模型介入时机与终止条件，无法适应目标解释与进度追踪的剧烈变化。端到端方法虽试图在单一模型内支持多任务，但其泛化能力受限于导航训练数据的覆盖范围，在未见视觉外观与空间布局中易失效。

领域内逐渐形成共识：分层架构是平衡推理深度与实时性的主流妥协。然而，现有分层系统（如 InstructNav, OmniNav）仍预设了高层推理与低层执行的固定接口，模型无法在运行时动态选择或组合能力。SuperNav 的切入点在于将计算机领域的代理框架概念迁移至具身导航，让 MLLM 保留通用推理能力，通过工具调用与上下文管理实现跨任务类型的无缝切换，而非依赖导航特定微调。

## 核心方法

### 代理循环与上下文管理

在标准具身导航流程中，智能体通常按固定流水线执行感知、规划与控制。SuperNav 将该流程重构为代理循环（Agent Loop），MLLM 作为决策核心，代理框架负责协调执行与上下文。该循环初始化会话并返回首个观测，MLLM 据此解释目标与完成条件。在后续步骤中，MLLM 根据当前上下文与任务进度选择操作：观测、移动、更新目标状态或读取导航技能（Navigation Skills）。工具返回与检索到的指令进入上下文供下一次决策使用，执行反馈直接改变 MLLM 的规划。

长时程执行要求局部决策与早期证据保持连接。代理框架维护目标记录（待处理/已完成）与文本交互历史（已检查区域、候选线索、失败尝试）。为控制图像上下文膨胀，框架在图像被处理并被新观测取代后，仅从后续请求中移除其媒体负载，保留文本历史、任务状态与图像路径。这种仅媒体剪枝（Media-only Pruning）策略限制了重复图像传输，同时保留了访问早期证据的能力。

### 统一视觉点接口与可互换执行后端

传统端到端方法直接预测低层动作，导致模型行为与特定运动后端强耦合。SuperNav 设计了统一视觉点接口（Unified Visual-Point Interface），将目标选择与执行机制解耦。MLLM 在观测图像上直接指定目标点，导航工具内部执行运动并返回新观测与诊断信息。该接口形式化为：

$$PointNav(d, [u, v]), \quad u, v \in [0, 1]$$

其中 $d$ 标识视角（前/右/后/左），$u, v$ 为归一化水平与垂直坐标。MLLM 可选择候选对象或可见地板上的点以接近目标或获取新视角。

该接口支持可互换的运动后端。几何后端（Geo-based Executor）利用深度、相机标定与位姿将选定点关联至环境位置，规划并跟随路径至可达目标；学习后端（Learned Executor）受 NoMaD 启发，从选定的图像-点对与近期 RGB 观测中预测局部位移增量与停止信号。两种后端均接受视觉目标并返回带执行反馈的观测，使代理保持相同的决策工作流。这一设计解决了此前方法中决策与执行接口僵化的问题，允许通过相同交互模式支持不同运动后端。

### 导航技能与工具调用

模块化系统通常将模型角色硬编码于任务导向流水线中。SuperNav 将可复用的导航经验组织为导航技能，MLLM 可按需读取。每个技能为 Markdown 包，描述适用情况、需检查的证据、推荐步骤及链接参考。搜索技能指导记录已检查区域与可见开口；恢复技能建议在运动失败后改变点或路线，或在玻璃阻挡时寻找入口；完成技能要求检查候选外观、请求关系与周围上下文。

技能通过进入上下文影响决策，但不添加环境能力或强制动作序列。MLLM 仍从当前请求与反馈中选择每个操作。代理导向工具（Agent-oriented Tools）覆盖初始化、观测、转向、视觉点导航、目标进度管理与终止。进度工具允许查询或更新待处理/已找到目标；终止工具记录达成/受阻判断并关闭会话。这种设计让 MLLM 动态协调可用能力，而非受限于预定义工作流。

## 实验评估

实验在 Habitat-GS、AI2-THOR 及 HM3D 基准上进行，对比 NaVid、UniNaVid、StreamVLN 及 OmniNav 的 Action Former 等端到端与分层基线。SuperNav 在单物体、多物体及需求驱动导航中均取得最高成功率（Success Rate, SR）与路径长度加权成功率（Success weighted by Path Length, SPL）。

| 方法 | 单物体 SR (%) | 单物体 SPL | 多物体 SR (%) | 多物体 SPL | 需求驱动 SR (%) | 需求驱动 SPL |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| NaVid | 24.67 | 0.1599 | 2.67 | 0.0216 | 17.00 | 0.0920 |
| UniNaVid | 34.00 | 0.1833 | 1.33 | 0.0131 | 25.00 | 0.0943 |
| StreamVLN | 13.33 | 0.1036 | 0.00 | 0.0000 | 25.50 | 0.0775 |
| OmniNav (Action Former) | 27.33 | 0.2133 | 4.00 | 0.0275 | 37.50 | 0.1213 |
| SuperNav + Geo-based | 78.00 | 0.4127 | 34.00 | 0.1388 | 59.50 | 0.1801 |
| SuperNav + Learned | 68.00 | 0.2059 | 34.00 | 0.0862 | 45.00 | 0.1603 |

SuperNav 结合几何执行器在单物体导航中达到 78.00% SR，较最强基线 UniNaVid 的 34.00% 提升 44 个百分点。在需求驱动导航中，59.50% SR 较 OmniNav 的 37.50% 提升 22 个百分点。学习执行器保留了大部分成功率，但路径效率显著下降（SPL 从 0.4127 降至 0.2059），表明几何后端在长序列任务中更具优势。

消融实验验证了代理框架组件的必要性。移除导航技能对 SR 的降低幅度大于仅限制前向交互，尤其在严格阈值下。保留技能时，仅前向交互导致 SR 与 SPL 下降且需更多显式转向。外部接地（Grounding Motion Tool）未改善代理的直接点选择，而将决策模型从 GPT-5.6 Terra 替换为 GPT-6 Astra 在固定框架下提升了 SR 与 SPL，证明框架与不同决策模型配置的兼容性。

评估协议存在局限：HM3D-OVON 与 HM3Dv2 的对比中，部分基线使用不同评估子集或协议，且未报告置信区间。计算效率维度未覆盖，MLLM 推理延迟与实时控制需求的平衡依赖工具调用的稀疏性，但具体延迟数据未公开。

## 关联研究分析

从问题动机看，SuperNav 与 VLFM 同属零样本导航路线，但 VLFM 依赖视觉-语言前沿地图将语义理解与几何前沿检测结合，任务逻辑仍预设了探索与验证的转换条件。SuperNav 摒弃显式地图构建，依赖 MLLM 上下文记忆与技能指导，挑战了“显式地图对长程导航至关重要”的领域共识。在无显式地图情况下，SuperNav 如何处理大型环境中的全局路径规划，论文未给出明确回答。

从方法设计看，SuperNav 与 OmniNav 均采用分层架构，但 OmniNav 结合前瞻性探索与子目标规划，由快速路点策略执行，高层推理与低层控制接口固定。SuperNav 通过代理框架实现更灵活的任务切换，支持抽象需求导航，且统一视觉点接口允许后端互换。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

SuperNav 针对通用具身导航中任务特定逻辑僵化与端到端泛化受限的矛盾，引入代理框架让预训练 MLLM 通过工具调用与上下文管理实现跨任务与场景泛化。该框架在单物体导航中达到 78.00% SR，需求驱动导航中达到 59.50% SR，显著超越基线。其边界在于无显式地图下的全局路径规划鲁棒性，以及长序列需求驱动任务中几何执行器仍面临挑战。当环境动态性增加或目标关系更复杂时，仅依赖文本历史与按需图像检索的上下文管理是否足以维持长时程一致性，论文未给出回答。
