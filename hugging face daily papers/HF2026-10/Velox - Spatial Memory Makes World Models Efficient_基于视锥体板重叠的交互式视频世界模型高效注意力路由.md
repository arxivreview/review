# HuggingFace最新推荐论文 ｜Velox: Spatial Memory Makes World Models Efficient ｜基于视锥体板重叠的交互式视频世界模型高效注意力路由

研究机构：新加坡国立大学

作者：Qiuhong Shen、Shizun Wang、Xinchao Wang

论文原文见 [arXiv](https://arxiv.org/abs/2610.22311)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2610.22311)

> 交互式视频世界模型在长时程生成中面临计算复杂度随历史长度线性增长的瓶颈，导致后期生成延迟急剧增加。现有方法多采用帧级检索或系统级优化，前者粒度粗糙且需架构修改，后者难以从根本上解决注意力计算膨胀。本文提出 Velox，一种训练无关的注意力路由框架，利用几何视锥体板重叠度在 Token 块级别动态筛选历史 KV 缓存。该框架在不重训模型的前提下显著降低长时程生成的注意力开销，但在几何模糊区域的语义一致性保持上仍存疑。

## 研究背景

当视频世界模型通过自回归方式生成连续帧时，为了维持场景的几何与语义一致性，模型必须访问历史观测序列。这种历史依赖通常通过键值（Key-Value, KV）缓存实现，即当前帧的查询（Query）需与所有历史帧的键值进行注意力计算。然而，随着生成步数增加，KV 缓存体积线性膨胀，导致注意力计算成本呈二次方或线性增长，使得长时程生成的后期阶段延迟显著增加，难以满足实时交互需求。

为解决这一计算瓶颈，主流路线分为两类：一是帧级记忆检索，如 Context-as-Memory 通过相机视场重叠筛选历史帧，但帧级粒度对于 Transformer 注意力而言过于粗糙，无法区分同一帧内不同区域对历史信息的差异化需求；二是系统级优化或模型蒸馏，如 ABot-World-0 通过推理管线优化降低延迟，但未改变注意力机制本身的计算复杂度。此外，部分方法如 AnchorWeave 通过 ControlNet 注入扭曲渲染，但这需要额外的架构适配或微调，限制了预训练模型的直接复用。本文切入点在于：能否在不修改预训练视频扩散模型权重的前提下，利用几何先验在更细粒度的 Token 块级别实现稀疏注意力路由，从而在保持视觉质量的同时大幅降低长时程生成的计算成本。

## 核心方法

### 方法参照系：块因果自注意力与 KV 缓存

本文方法建立在块因果自注意力（Block-Causal Self-Attention）架构之上，该架构将视频序列划分为时间有序块，块内双向注意力，块间严格因果注意力。在标准流程中，当前块 $c$ 的生成依赖于历史上下文 $C_{<c}$，其注意力计算成本随 $C_{<c}$ 中 KV 块数量 $M_c$ 的增长而增加。本文问题与该通用流程的关键差异在于：标准流程对所有历史 KV 块一视同仁，而本文引入几何视锥体板（Frustum Slabs）作为路由信号，仅让当前块中几何已覆盖的区域访问相关的历史 KV 块，未覆盖区域则回退至模型自导出的路由。

### 几何视锥体板构建与重叠评分

该创新发生在历史上下文表示环节。通常做法是将历史帧直接存入 KV 缓存，或仅记录相机位姿。本文创新在于将历史 KV 块抽象为视锥体板原语，每个原语包含源相机 Token 矩形、鲁棒深度区间及有效性统计。对于历史块 $r$，其视锥体板集合为 $\Psi_r$。为了评分当前查询块 $i$ 与历史块 $r$ 的相关性，本文在世界空间中近似相机视锥体板为定向包围盒（Oriented Bounding Box, OBB），并计算其重叠度：

$$
g_{i,r} = \max_{\psi_{j,r,m} \in \Psi_r} \frac{\text{Vol}(O_i^Q \cap O_{j,r,m}^K)}{\text{Vol}(O_i^Q) + \text{Vol}(O_{j,r,m}^K) - \text{Vol}(O_i^Q \cap O_{j,r,m}^K) + \epsilon}
$$

该公式计算查询块与历史块在世界空间中的 OBB 交并比（IoU）。其物理含义是：如果当前相机视锥体与历史相机视锥体在三维空间中重叠，则历史块中的几何信息对当前块具有潜在参考价值。这一设计解决了帧级检索无法处理局部几何对应关系的失效，通过几何重叠度提供了比相机位姿更细粒度的相关性信号。

### 软几何融合与模型重要性调制

该创新发生在注意力路由决策环节。通常做法是基于几何重叠度进行硬 Top-K 筛选，但这会忽略 Transformer 各层对视觉证据的差异化偏好。本文创新在于提出软几何融合规则，将几何重叠度作为先验调制模型自导出的块重要性。首先，计算第 $\ell$ 层中查询块 $i$ 与可见 KV 块 $r$ 的模型重要性 $p_{i,r}^\ell$。对于几何覆盖良好的块，将几何重叠度 $g_{i,r}$ 归一化并截断后，与模型重要性相乘并重新归一化：

$$
\tilde{p}_{i,r}^\ell = \frac{p_{i,r}^\ell (1 + \lambda \hat{g}_{i,r})}{\sum_{r'=1}^{M_c} p_{i,r'}^\ell (1 + \lambda \hat{g}_{i,r'})}
$$

其中 $\hat{g}_{i,r}$ 是经过噪声阈值 $\tau$ 过滤和参考值 $g_{\text{ref}}$ 归一化的几何重叠度，$\lambda$ 控制融合强度。该公式的含义是：几何重叠度高的历史块获得注意力权重提升，但提升幅度受模型自身重要性分布约束。这一设计解决了硬路由可能切断模型内部语义关联的问题，确保几何先验仅作为“软引导”而非“硬替换”，保留了预训练模型对非几何语义（如天空、新暴露区域）的处理能力。

## 实验评估

实验在 WBench 导航子集（158 例）上进行，对比了密集注意力基线 LingBot-Fast-Cam、纯模型重要性路由 Block-Sparse 以及本文方法 Velox。评估指标包括 API-free 平均分（排除依赖 VLM 评分的指标）和 19 项指标总体平均分。

| 方法 | API-free 平均分 | Overall 平均分 | 空间一致性 |
| :--- | :--- | :--- | :--- |
| LingBot-Fast-Cam (Dense) | 73.66 | 75.52 | 73.0 |
| Block-Sparse | 73.11 | 75.01 | 71.8 |
| Velox | 73.51 | 75.60 | 74.3 |

Velox 在 API-free 平均分上比密集基线低 0.15 分，但在 Overall 平均分上高出 0.08 分，且空间一致性从 73.0 提升至 74.3。这表明几何路由在保持整体质量几乎无损的同时，显著提升了空间几何的连贯性。

在效率方面，Velox 在生成第 48 个块时，注意力延迟从密集 FlashAttention 的 34.2 ms 降至 7.8 ms，加速比为 4.36 倍；去噪时间从 7.19 s 降至 2.96 s，加速比为 2.43 倍。加速比随生成块数增加而扩大，证实了该方法有效缓解了长时程生成中注意力计算随历史长度增长的问题。

评估边界方面，本文未对比基于显式记忆检索的方法（如 AlayaWorld），且依赖深度估计的准确性。若深度估计存在噪声，几何路由的可靠性可能下降。此外，实验主要在相机控制场景下进行，对非刚性动态场景（如流体、烟雾）的泛化能力未充分验证。

## 关联研究分析

从问题动机看，Velox 与 Context-as-Memory 均旨在解决长时程生成的上下文管理问题，但 Context-as-Memory 在帧级别进行检索，而 Velox 在 Token 块级别进行路由。Context-as-Memory 的帧级粒度导致同一帧内不同区域共享相同的历史上下文，无法处理局部几何对应关系；Velox 通过视锥体板重叠度实现了区域级的差异化路由，更适应复杂场景中的局部动态变化。

从方法设计看，Velox 与 AnchorWeave 均利用几何信息增强生成一致性，但 AnchorWeave 通过 ControlNet 注入扭曲渲染，需要额外的架构模块和微调；Velox 则直接修改注意力可见性，无需修改预训练模型权重。这一差异源于对预训练模型复用性的不同考量：AnchorWeave 追求更强的几何控制力，而 Velox 追求部署的便捷性与通用性。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文针对交互式视频世界模型长时程生成中注意力计算成本随历史长度线性增长的核心矛盾，提出利用几何视锥体板重叠度作为软先验，在 Token 块级别动态路由历史 KV 缓存。该方法在不重训模型的前提下，实现了第 48 块生成时 4.36 倍的注意力加速，且空间一致性提升 1.3 分。本文的边界在于依赖深度估计的准确性，且未验证对非刚性动态场景的泛化能力。当场景中存在大量几何模糊或深度估计失效的区域时，几何路由的误剪是否会导致语义一致性显著下降，论文未给出回答。
