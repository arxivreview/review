作者：Seo Hyun Kim、Sunwoo Hong、Younwoo Choi 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2610.03665)

> 掩码扩散语言模型（Masked Diffusion Language Models, MDLM）在并行去噪过程中，少数关键决策步骤决定了后续生成的走向，但现有后训练方法往往对全序列或整步进行均匀监督，导致信用分配模糊。本文提出 Pivot-SD，通过信息增益识别高影响的“枢轴”提交，仅对这些特定 token 实施基于结果的正负向自蒸馏。该方法以极低的计算成本实现了优于在线强化学习（RL）和全序列监督微调（SFT）的效果，但其离线固定数据集的特性是否限制了模型对新分布的适应能力，仍需进一步验证。

## 研究背景

掩码扩散语言模型通过迭代去噪并行生成文本，其核心机制是在每个去噪步骤中，模型根据当前部分掩码状态 $M_t$ 预测被掩码位置的真实 token。与自回归模型固定的从左到右生成顺序不同，MDLM 允许根据置信度动态决定 token 的揭示顺序。这种灵活性带来了双向上下文利用的优势，但也引入了独特的信用分配难题：在一条去噪轨迹中，某些步骤的 token 提交会显著降低剩余掩码位置的不确定性，从而塑造整个响应的路径，而大多数步骤的 token 则主要由周围上下文决定。

现有 MDLM 后训练方法主要借鉴自回归范式，通常对最终文本进行全序列 SFT，或采用在线 RL 对整条轨迹或去噪步骤分配奖励。全序列 SFT 忽略了 token 在生成过程中的时序重要性，将早期关键决策与后期填充 token 等同对待；在线 RL 虽然能利用结果信号，但计算成本高且存在训练不稳定性，且在低预算下容易因零奖励批次而停滞。本文的切入点在于利用 MDLM 特有的去噪轨迹记录，识别出对结果影响最大的“枢轴”提交，并通过离线自蒸馏仅针对这些关键节点进行精准监督，从而在极低计算成本下实现高效对齐。

## 核心方法

### 方法参照系

MDLM 后训练的标准流程通常涉及从基础模型采样轨迹，并根据验证器结果（正确/错误）对模型参数进行更新。传统 SFT 对所有掩码位置施加均匀交叉熵损失，而在线 RL 则通过策略梯度更新整个去噪过程。本文的关键差异在于将监督单元从“最终文本”或“整步”缩小至“特定去噪步骤中的特定 token 提交”，并引入基于信息增益的选择机制。

### 信息增益枢轴选择

在标准去噪过程中，每个步骤 $t$ 模型会对剩余掩码位置 $A_t \setminus U_t$ 进行预测。本文定义每个步骤的信息增益 $g(t)$ 为该步骤提交 token 前后，剩余掩码位置平均熵的下降量：

$$
g(t) = \frac{H_{pre}(t) - H_{post}(t)}{|A_t \setminus U_t|}
$$

其中 $H_{pre}(t)$ 和 $H_{post}(t)$ 分别为提交前和提交后剩余掩码位置的预测熵。这一设计动机在于，早期步骤中少量 token 的提交往往能大幅约束后续生成，而后期步骤的熵降较小。通过选择 $g(t)$ 最高的 $K$ 个步骤，模型能够聚焦于对轨迹路径影响最大的“枢轴”提交，避免了均匀监督带来的信号稀释。

### 结果条件自蒸馏

选定枢轴后，Pivot-SD 根据轨迹最终结果 $s(\tau) \in \{+1, -1\}$ 决定更新方向。对于正确轨迹中的枢轴 token $y_p$，施加交叉熵损失以提升其概率；对于错误轨迹中的枢轴 token，施加非似然（Unlikelihood）损失以降低其概率：

$$
L_{pivot}(z) = \mathbb{1}[s(\tau)=+1] \ell_p^+(\theta; M_t, y_p) + \lambda_{neg} \mathbb{1}[s(\tau)=-1] \ell_p^-(\theta; M_t, y_p)
$$

其中 $\ell_p^+ = -\log P_\theta(y_p | M_t)$，$\ell_p^- = -\log(1 - P_\theta(y_p | M_t))$。这一机制确保了模型仅从失败轨迹中学习“避免特定错误决策”，而不惩罚失败轨迹中其他有效的中间步骤，从而实现了细粒度的信用分配。

## 实验评估

实验在 LLaDA-8B-Instruct 和 Dream-7B 骨干上进行，使用 200 道训练题和 4 条轨迹/题，对比 SFT-GT、SFT-SD、diffu-GRPO 和 wd1++ 基线。基线覆盖了离线 SFT 和在线 RL 两条主要路线，但未对比其他离线蒸馏方法或纯架构改进方法。

| 方法 | MATH500 | GSM8K | HumanEval+ | MBPP+ |
| :--- | :--- | :--- | :--- | :--- |
| Base | 31.40 | 75.13 | 32.32 | 43.12 |
| SFT-GT | 35.47 | 76.94 | 33.94 | 46.32 |
| diffu-GRPO (matched) | 33.47 | 76.04 | 32.52 | 43.39 |
| Pivot-SD | 37.47 | 79.51 | 40.43 | 47.12 |

Pivot-SD 在四个基准上均取得最高平均分，较 SFT-GT 在 MATH500 上提升 2.0 点，较 diffu-GRPO 在 GSM8K 上提升 3.5 点。

| 方法 | MATH500 | GSM8K | HumanEval+ | MBPP+ |
| :--- | :--- | :--- | :--- | :--- |
| Positive All-token | 31.60 | 74.37 | 36.59 | 39.68 |
| Random-Step Pivot | 29.93 | 76.51 | 39.00 | 44.80 |
| Pivot-SD | 37.47 | 79.51 | 40.43 | 47.12 |

消融实验表明，随机选择步骤或监督所有掩码 token 均导致性能下降，验证了信息增益选择机制的有效性。Pivot-SD 仅监督每条轨迹 10 个 token（<4% 预算），计算时间仅为 diffu-GRPO 的 1/8，证明了高效性。

评估边界方面，论文未报告置信区间，且仅在 256 token 长度下进行了三次重随机化运行，512 token 长度下的性能转移未充分验证。代码未公开，超参数 $\lambda_{neg}$ 和 $K$ 的敏感性分析仅在附录中简要提及，可复现性受限。

## 关联研究分析

从问题动机看，Pivot-SD 与 GIFT (Xu et al., 2025) 均利用熵信号加权 token，但 GIFT 作用于最终序列，而 Pivot-SD 作用于去噪过程中的状态。这一差异源于 MDLM 的时序特性：同一 token 在早期和后期步骤中的重要性不同，最终序列无法记录这种动态变化。Pivot-SD 通过重放枢轴提交时的状态 $M_t$，确保了监督信号与推理时的决策状态一致，解决了训练-推理不一致性问题。

从方法设计看，Pivot-SD 与 diffu-GRPO (Zhao et al., 2025) 均使用结果标签，但 diffu-GRPO 采用在线策略梯度更新整个去噪过程，而 Pivot-SD 采用离线自蒸馏仅更新特定枢轴。这一差异导致 Pivot-SD 在低预算下更稳定，避免了在线 RL 的零奖励批次停滞问题。然而，离线固定数据集是否限制了模型对新分布的适应能力，论文未给出回答。

## 总结

Pivot-SD 针对 MDLM 后训练中信用分配模糊的问题，提出基于信息增益的枢轴选择机制，通过离线自蒸馏仅对高影响 token 实施正负向监督。该方法在 200 题预算下，以 1/8 的计算成本实现了优于在线 RL 和全序列 SFT 的效果，MATH500 准确率达 37.47%，GSM8K 达 79.51%。其边界在于离线固定数据集可能限制泛化能力，且仅在 256 token 长度下充分验证。当训练数据规模扩大至 2000 题时，Pivot-SD 相对于在线 RL 的优势是否依然显著，论文未给出回答。
