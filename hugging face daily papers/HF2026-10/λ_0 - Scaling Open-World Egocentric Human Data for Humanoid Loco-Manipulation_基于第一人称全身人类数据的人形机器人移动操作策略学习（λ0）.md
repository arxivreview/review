# HuggingFace最新推荐论文 ｜λ_0: Scaling Open-World Egocentric Human Data for Humanoid Loco-Manipulation ｜基于第一人称全身人类数据的人形机器人移动操作策略学习（λ0）

研究机构：阿里巴巴集团

作者：Lambda-humanoid Team

论文原文见 [arXiv](https://arxiv.org/abs/2610.18950)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2610.18950)

> 人形机器人全身移动操作（Loco-manipulation）需要协调行走、姿态调整与物体交互，但依赖机器人遥操作采集数据成本高昂且难以规模化。现有基于第一人称人类视频的方法多仅提取手部轨迹，忽略了支撑全身交互的步态与躯干运动，且跨本体动作重定向常因几何失配与控制执行误差导致末端执行器精度不足。本文提出一种人-人形对齐管线，通过观测替换与三阶段离线动作优化消除执行误差，并构建包含500小时全身动作的HUMANVERSE数据集。该工作验证了大规模全身人类数据对下游机器人策略性能的单调提升作用，但动力学感知优化能否完全弥补真实物理接触中的力反馈缺失，仍存疑。

## 研究背景

当人形机器人执行如“搬运重物”或“整理厨房”等任务时，其控制策略必须同时处理下肢的全身移动（Locomotion）与上肢的精细操作（Manipulation）。这种全身移动操作要求机器人在动态改变身体姿态与位置的同时，保持末端执行器与物体的精确接触。传统的视觉-语言-动作（Vision-Language-Action, VLA）模型通常依赖机器人遥操作数据，但受限于硬件可用性与操作成本，难以覆盖开放世界的多样化场景。为突破数据瓶颈，研究者转向利用第一人称人类视频作为监督源，然而，仅从视频中重建的手部轨迹无法提供支撑全身交互的步态与躯干运动信息，导致策略在需要全身协调的任务中失效。

即便引入了全身动作捕捉，将人类运动直接重定向至机器人仍面临严峻挑战。人类与机器人在骨骼几何上的差异会导致运动参考的几何失配，而机器人底层控制器的执行误差会进一步放大末端执行器的位置与姿态偏差。这些误差在需要精确抓取的交互任务中是致命的。现有方法多依赖仿真环境中的物理引擎进行后处理，或仅通过简单的轨迹模仿进行联合训练，未能系统性地解决从人类运动参考到机器人实际执行之间的全链路误差累积问题。本文的切入点在于：如何在无机器人参与的情况下，通过可穿戴设备高效采集全身交互数据，并通过离线对齐管线消除跨本体的执行误差，从而为VLA模型提供高保真的动作监督。

## 核心方法

### 人-人形观测与动作对齐管线

本文方法属于具身智能中的“重定向”路线，其核心在于将人类第一人称观测与全身运动转化为机器人兼容的状态-动作对。与传统的仅替换外观或简单缩放骨骼不同，本文提出了一套包含观测对齐与动作对齐的完整管线。观测对齐通过匹配相机高度与视角，并利用图像修复技术将人类手臂替换为渲染的机器人手臂，以消除视觉域差异。动作对齐则针对运动参考与控制执行误差，设计了三级离线优化机制，确保人类运动能准确映射至机器人的动作接口。

### 三级离线动作对齐优化

动作对齐旨在解决从人类运动参考到机器人实际执行之间的误差累积。该过程分为人体参考对齐、机器人参考对齐与动力学感知优化三个阶段。首先，通过缩放SMPL模型至机器人高度并调整姿态，对齐末端执行器目标，消除几何高度差异。其次，利用机器人运动学模型进行约束逆运动学（Inverse Kinematics, IK）求解，修正因骨骼结构差异导致的残差误差。最后，针对控制器执行误差，引入动力学感知优化。该阶段利用机器人执行反馈与响应模型，通过梯度下降直接优化动作令牌（Motion Tokens）。

$$
\theta^* = \arg\min_\theta \mathcal{L}_{EE}(\text{Rollout}(\theta), \mathbf{p}_{target})
$$

其中，$\theta$ 为动作令牌参数，$\mathcal{L}_{EE}$ 为末端执行器误差损失，$\text{Rollout}(\theta)$ 表示在机器人动力学模型下的执行轨迹，$\mathbf{p}_{target}$ 为固定的末端执行器目标。该公式的物理含义是：在保持末端执行器目标不变的前提下，通过迭代更新动作令牌，使机器人在实际动力学环境中的执行轨迹逼近目标，从而弥补纯运动学修正无法解决的动态执行误差。

### 三阶段渐进式训练策略

λ0 模型采用三阶段训练策略，逐步将人类经验适配至机器人控制。第一阶段为第一人称手部运动预训练，利用公开的手-物交互数据集训练视觉-语言骨干网络，使其具备基础的交互语义理解能力。第二阶段为全身人类数据中训练，使用经过对齐管线处理的HUMANVERSE数据，训练生成式动作专家，使其学习协调的全身与手部动作。第三阶段为机器人后训练，利用少量机器人遥操作数据，将学习到的行为适配至目标机器人。

$$
\mathcal{L}_{total} = \mathcal{L}_{hand} + \lambda_1 \mathcal{L}_{whole-body} + \lambda_2 \mathcal{L}_{robot}
$$

该公式表示三阶段训练的总损失函数，其中 $\mathcal{L}_{hand}$、$\mathcal{L}_{whole-body}$ 和 $\mathcal{L}_{robot}$ 分别对应手部预训练、全身人类中训练和机器人后训练的损失，$\lambda_1$ 和 $\lambda_2$ 为权重系数。该设计通过渐进式的数据域迁移，避免了直接混合人类与机器人数据导致的分布冲突，使模型能够充分利用大规模人类数据的多样性，同时保留机器人数据的精确性。

## 实验评估

实验在Unitree G1人形机器人上进行，评估了全身移动操作与长距离移动操作任务。基线对比覆盖了ACT、$\pi_{0.5}$、StarVLA和GR00T N1.6等主流VLA模型。在SIMPLE仿真环境中，λ0 的成功率达到90.0%，较最强基线StarVLA（86.1%）提升3.9个百分点。在真机移动操作任务中，λ0 的成功率为62.5%，较StarVLA（27.5%）提升35.0个百分点，较$\pi_{0.5}$（10%）提升52.5个百分点。

| 方法 | SIMPLE 仿真成功率 (%) | 真机移动操作成功率 (%) |
| :--- | :--- | :--- |
| GR00T N1.6 | - | 7.5 |
| $\pi_{0.5}$ | - | 10.0 |
| StarVLA | 86.1 | 27.5 |
| ACT | 82.8 | - |
| λ0 (Ours) | 90.0 | 62.5 |

消融实验验证了全身人类数据中训练的关键作用。随着HUMANVERSE数据量的增加，验证损失从0.0111降至0.00714，真机任务进度从59.9%单调提升至80.4%。动作对齐管线的有效性通过末端执行器误差的降低得到验证：在50个任务上，位置误差从17.03 cm降至3.83 cm（降低77.5%），姿态误差从36.06°降至10.85°（降低69.9%）。

评估边界方面，真机评估仅覆盖4个任务，且未报告置信区间，可能不足以全面支撑“开放世界”泛化能力的结论。此外，计算效率维度未覆盖，且人类数据采集虽降低了人力成本（每演示33.30人秒 vs 机器人140.85人秒），但可穿戴设备的佩戴与校准时间是否计入总成本，论文未明确说明。

## 关联研究分析

从问题动机看，本文与EgoAlign（Jiang et al., 2026b）和EgoHumanoid-V2（Chen et al., 2026）同源，但后两者主要聚焦于手部操作或局部对齐。本文的差异在于将对齐管线扩展至全身移动操作，并引入了动力学感知优化以解决控制器执行误差。这一差异源于任务特性的根本不同：全身移动操作涉及下肢与躯干的复杂动力学耦合，纯运动学对齐无法保证末端执行器在动态行走中的精度。

从方法设计看，本文与HAT（Qiu et al., 2025）均尝试统一人类与机器人状态空间，但HAT依赖联合训练，而本文强调通过离线对齐消除执行误差后再进行训练。这一差异反映了两种不同的数据利用哲学：HAT假设模型能从噪声数据中学习鲁棒表示，而本文假设通过显式优化消除噪声能提供更高质量的监督信号。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文要解决的核心矛盾是人形机器人全身移动操作数据获取成本高与人类视频缺乏全身动作监督之间的冲突。本文抓住的切入点是通过可穿戴设备采集全身动作，并通过三级离线对齐管线消除跨本体执行误差。本文构建了HUMANVERSE数据集并提出了λ0模型，证明了全身人类数据中训练能将真机任务成功率提升至62.5%，且性能随数据量单调提升。本文的边界在于动力学感知优化仅基于离线反馈，未考虑真实物理接触中的力反馈缺失，且真机评估任务数量有限。当机器人执行需要精细力控的接触任务时，仅靠位置与姿态对齐是否足以保证交互稳定性，论文未给出回答。
