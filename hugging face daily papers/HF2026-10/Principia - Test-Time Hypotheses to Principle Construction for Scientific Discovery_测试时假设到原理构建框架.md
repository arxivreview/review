研究机构：韩国科学技术院

作者：Dongki Kim、Sangwoo Park、Jinheon Baek 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2610.32195)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2610.32195)

> 导读 科学发现的核心瓶颈在于将零散的实验观测转化为可指导后续探索的通用原理，这一过程高度依赖人类专家的解释与归纳。现有自动化方法多依赖静态知识库或无结构的经验摘要，难以在测试时动态修正因观测覆盖不足导致的解释偏差。PRINCIPIA 提出一种基于大语言模型（Large Language Models, LLMs）的测试时知识构建框架，通过比较相似输入生成因果假设，归纳重复模式形成原理，并利用新观测修订假设。该框架在分子优化与性质预测任务中显著优于基线，但其原理的语义正确性仍依赖 LLM 判断，缺乏形式化验证机制。

## 研究背景

当研究人员面对复杂的科学系统（如药物发现）时，底层物理机制往往未知，需通过累积实验观测构建经验原理。这一“假设到原理”的构建过程要求从个体观测中提炼因果关系，并泛化为覆盖更广范围的科学定律。然而，单个输入及其观测结果提供的证据有限，多个输入特征可能解释同一结果，导致假设生成缺乏区分度。此外，实验观测仅覆盖输入空间的极小部分，基于有限证据生成的假设可能包含错误或遗漏，且随着新观测的积累，早期假设的局限性会暴露，需不断修订。

传统自动化科学发现方法主要聚焦于候选生成或单点任务优化，缺乏从累积观测中构建可复用科学知识的机制。部分方法利用 LLM 作为进化算子搜索程序空间，或依赖检索增强生成（Retrieval-Augmented Generation, RAG）引入外部知识，但这些方法多为静态知识注入，无法在测试时根据新观测动态修正知识体系。另一类方法如 ExLLM 使用文本摘要记录经验，但缺乏结构化的因果建模，难以捕捉输入特征与观测结果间的深层联系。PRINCIPIA 针对这一空白，提出在测试时动态构建、应用并修订因果假设与归纳原理，实现科学知识的持续演化。

## 核心方法

### 方法参照系：测试时知识构建流程

PRINCIPIA 将科学发现建模为测试时的知识构建过程，区别于传统的训练时知识注入或静态检索。其核心流程包括三个环节：从比较证据中生成因果假设、从假设中归纳科学原理、以及利用新观测修订假设并重构原理。该流程在优化任务中通过修改输入并评估结果获取新观测，在预测任务中通过预测与真实标签的对比获取新观测，形成“观测-假设-原理-应用-修订”的闭环。

### 比较因果假设生成

传统假设生成通常基于单个输入及其观测，导致解释空间过大。PRINCIPIA 引入比较证据，通过对比相似输入及其结果来缩小解释范围。对于优化任务，比较生成的候选 $x_j$ 与其源输入 $x_i$；对于预测任务，计算目标输入 $x_j$ 与参考输入 $x_i$ 的距离，选取最近邻构成比较对。比较证据定义为 $e_{i \to j} = (x_i, O(x_i), x_j, O(x_j))$。LLM 基于此证据生成因果假设 $H_{i \to j}$：

$$ H_{i \to j} = \text{LLM}_{\text{hypothesis}}(e_{i \to j}; q) $$

该公式表示 LLM 根据比较证据 $e_{i \to j}$ 和任务描述 $q$ 生成假设。当结果不同时，假设聚焦于解释差异的输入特征；当结果相同时，假设描述维持结果的共享特征。这一设计解决了单点观测下因果归因模糊的问题，通过对比增强了假设的区分度。

### 归纳原理构建与假设修订

单个假设可能受限于特定输入对，无法泛化。PRINCIPIA 通过相似性聚类将输入分组，收集组内所有假设，由 LLM 归纳出紧凑的科学原理 $P_k$：

$$ P_k = \text{LLM}_{\text{principle}}(E_k; q) $$

其中 $E_k$ 为第 $k$ 个聚类中所有假设及其证据的集合。该步骤将局部因果关系提升为全局规律。随后，框架利用检索到的假设与原理指导新任务，获取新观测 $B_{i \to j}$，并修订假设：

$$ H'_{i \to j} = \text{LLM}_{\text{refine}}(e_{i \to j}, H_{i \to j}, B_{i \to j}; q) $$

修订后的假设替换原假设，并触发原理重构。这一机制解决了静态知识无法适应新观测导致的解释过时问题，确保知识体系随实验进程动态演化。

## 实验评估

实验在 Scientific Discovery Evaluation 基准（分子、蛋白、基因优化）及 TDC 基准（分子性质预测）上进行。基线覆盖无指导优化（MolLEO）、经验摘要（ExLLM）、外部检索（WebSearch）及进化搜索（DeepEvolve）。PRINCIPIA 在多数任务上取得最优性能，尤其在分子优化 GSK3$\beta$ 任务中，AUC@10 达到 0.452，显著高于 ExLLM 的 0.363。在分子性质预测 DILI 任务中，准确率为 70.49%，优于 Few-shot ($k=7$) 的 62.15%。

| 方法 | GSK3$\beta$ AUC@10 | GB1 AUC@10 | DILI Acc (%) | DILI F1 (%) |
| :--- | :--- | :--- | :--- | :--- |
| MolLEO | 0.341 | 0.245 | 52.43 | 44.11 |
| ExLLM | 0.363 | 0.277 | - | - |
| WebSearch | 0.421 | 0.233 | - | - |
| PRINCIPIA | **0.452** | **0.383** | **70.49** | **67.48** |

消融实验显示，移除比较假设生成导致 GB1 任务 AUC@10 从 0.337 降至 0.245，验证了比较证据对假设质量的提升作用。移除原理构建或假设修订均导致性能下降，表明结构化知识构建与动态修订缺一不可。在 Syn-3bfo 优化任务中，PRINCIPIA 达到 ExLLM 最终性能所需的 Oracle 调用次数减少约 55%，体现了知识构建对实验预算的节约。

评估边界方面，实验主要依赖 AUC、准确率等结果导向指标，缺乏对生成原理“可证伪性”或“逻辑一致性”的量化评估。虽然提供了代码，但 LLM 骨干网络（GPT-5-mini）的版本与具体超参数对结果的影响未充分隔离，基线是否使用同等骨干网络存在不确定性。

## 关联研究分析

从知识构建机制看，PRINCIPIA 与 ExLLM 形成直接对比。ExLLM 依赖无结构的文本摘要记录经验，而 PRINCIPIA 构建结构化的因果假设与归纳原理。ExLLM 的摘要难以捕捉输入特征与结果间的因果依赖，导致在复杂优化任务中指导能力有限。PRINCIPIA 通过比较证据与聚类归纳，显式建模因果关系，从而在 GSK3$\beta$ 等任务中取得更高 AUC。然而，PRINCIPIA 的原理生成仍依赖 LLM 的语义理解，未引入形式化验证器，其科学正确性缺乏严格保证。

从任务范式看，PRINCIPIA 与 FunSearch 或 AlphaEvolve 存在差异。后者将 LLM 作为进化算子直接搜索程序空间，适用于可形式化的数学问题；PRINCIPIA 则侧重于从非结构化观测中归纳自然语言描述的科学原理，适用于分子、蛋白等复杂系统。PRINCIPIA 的闭环修订机制使其能处理观测覆盖不足的问题，而传统进化搜索通常假设评估函数固定，缺乏对知识本身的动态修正能力。

## 总结

PRINCIPIA 针对科学发现中从观测到原理转化的瓶颈，提出测试时动态构建因果假设与归纳原理的框架。通过比较证据生成假设、聚类归纳原理及新观测修订机制，该框架在分子优化与性质预测任务中显著优于静态知识基线，如 GSK3$\beta$ 任务 AUC@10 达 0.452，DILI 预测准确率达 70.49%。其核心价值在于将知识构建从训练时移至测试时，实现了知识的持续演化。然而，该框架的原理语义正确性完全依赖 LLM 判断，缺乏形式化逻辑验证，且动态修订机制在长程任务中是否会导致知识震荡或遗忘，论文未提供稳定性分析。当观测数据存在噪声或分布偏移时，LLM 生成的因果假设是否会陷入局部错误并误导后续探索，仍需进一步验证。
