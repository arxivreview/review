# HuggingFace最新推荐论文 ｜X-Ragent: Tool-Augmented Reinforcement Learning for Evidence-Grounded Chest X-Ray Reasoning ｜证据接地的胸部X光诊断推理代理

研究机构：中国科学院大学、美国卡内基梅隆大学

作者：Yi Wang、Zhenlong Yuan、Yuchan Guo 等 12 人

论文原文见 [arXiv](https://arxiv.org/abs/2610.16811)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2610.16811)

> 胸部X光（Chest X-ray, CXR）诊断要求模型将视觉发现与特定临床证据结合，而非仅依赖全局视觉识别。现有工具增强代理虽能获取外部证据，却缺乏学习何时需要辅助证据的机制，且无法阻止不适用的定量证据误导诊断。X-Ragent提出一种后训练框架，将策略路由的辅助证据获取与有效性门控的定量测量解耦，通过两阶段代理式监督微调（Supervised Fine-Tuning, SFT）与组相对策略优化（Group Relative Policy Optimization, GRPO）优化策略。该框架在完全保留的ChestAgentBench上取得71.7%准确率，较最强基线提升8.6个百分点，为高风险临床场景下的可审计推理提供了新路径，但其有效性门控机制在复杂多视图场景下的泛化能力仍存疑。

## 研究背景

当多模态大语言模型（Multimodal Large Language Model, MLLM）处理CXR图像时，其全局感知机制难以将宽泛的视觉线索与局部、细粒度的解剖证据或定量指标建立联系，导致视觉-诊断差距。为弥补这一缺陷，工具增强代理通过调用外部模块获取辅助证据，但现有代理常忽略或误解释工具返回的客观输出，受文本先验驱动生成看似合理但无证据支持的诊断，产生证据-诊断不一致。此外，确定性测量仅在特定采集条件下有意义，缺乏显式适用性检查时，不适用的定量证据会进入推理过程并误导最终诊断。

放射学报告生成（Radiology Report Generation, RRG）领域正从模式匹配转向临床推理，核心矛盾在于如何在高风险场景中构建具备视觉证据严格接地且可审计的系统。现有路线中，强化学习（Reinforcement Learning, RL）通过奖励机制抑制幻觉，多智能体系统（Multi-Agent System, MAS）通过工作流模拟增强可解释性，但两者均未解决“不适用测量证据进入推理”这一具体子问题。X-Ragent的切入点在于将学习到的证据寻求与有效性约束的测量获取解耦，使策略决定寻求哪些可选证据，而有效性门控决定哪些定量测量被允许进入推理。

## 核心方法

### 方法参照系：工具增强视觉推理

X-Ragent将CXR解释形式化为工具增强视觉推理过程。给定CXR图像 $I$ 和临床查询 $Q$，模型生成结构化输出 $O = \langle R, A \rangle$，其中 $R$ 为包含工具调用及其观察结果的推理轨迹，$A$ 为最终答案。与通用图像描述不同，$R$ 中的每个诊断结论必须严格对应 $I$ 中的视觉证据。X-Ragent实例化Qwen3-VL-8B为代理策略 $\pi_\theta$，策略从动作集 $T_\pi$ 中选择性调用辅助工具，而确定性定量测量通过独立的有效性门控路径提供。该流程的关键差异在于：策略仅负责路由可选的视觉细化或知识查找工具，定量测量的暴露完全由后端有效性门控 $g(I)$ 决定，实现了证据寻求与测量获取的解耦。

### 核心创新：两阶段代理式后训练与因果有序轨迹

现有MLLM训练数据主要监督最终答案，未捕捉诊断证据如何获取并整合到推理中。X-Ragent构建Rad-CoT数据集，包含7,715个SFT样本，其中3,715个为因果有序的两轮路由示例，4,000个为单轮报告式思维链（Chain-of-Thought, CoT）示例。在SFT阶段，采用选择性掩码策略，损失仅在策略生成的token上计算，注入的观察跨度被掩码。目标函数为：

$$
L_{\text{SFT}} = -\mathbb{E}_{T \sim D} \sum_{t=1}^{T} \log p_\theta(s_t | X, I, s_{<t})
$$

该公式的物理含义是：模型仅学习生成路由决策和推理轨迹的token，而不学习复现工具返回的观察结果，从而锚定辅助工具路由和证据整合的诊断推理行为。这一设计解决了直接GRPO从基础策略优化时难以引出结构化推理的问题，为后续RL提供了校准的策略初始化。

### 核心创新：准确率门控的复合奖励机制

GRPO优化策略时，结果级奖励监督最终诊断正确性，但对获取的证据是否被一致解释提供有限指导。X-Ragent引入准确率门控的复合奖励，将过程级信号仅应用于正确轨迹，防止看似合理的过程行为补偿错误诊断。奖励包含答案准确率 $R_{\text{acc}}$、格式合规 $R_{\text{format}}$、放射学证据一致性 $R_{\text{CXR}}$ 和工具使用成本 $R_{\text{tool}}$。对于测量 $k$，其奖励资格定义为 $a_k = r_k b_k$，其中 $r_k$ 表示查询相关性，$b_k$ 表示有效性门控后端是否暴露该测量。证据一致性奖励为：

$$
R_{\text{CXR}}(\tau) = \sum_{k} a_k s_k
$$

该公式表明：只有当测量与查询相关且被有效性门控暴露时，轨迹对该测量的解释一致性才获得奖励。这一设计解决了无门控时错误轨迹仍可获得 $R_{\text{CXR}}$ 的问题，确保过程奖励仅在诊断正确的前提下生效，从而抑制幻觉并鼓励选择性工具使用。

## 实验评估

实验在三个CXR基准上进行：完全保留的ChestAgentBench（OOD）、CheXbench和SLAKE。基线覆盖包括Qwen3-VL-8B、GPT-4o及MedRAX代理，但缺失经典报告生成基线（如R2GenGPT），因任务为VQA/诊断而非自由文本生成。X-Ragent在三个基准上均取得最强结果，ChestAgentBench达71.7%，CheXbench平均77.3%，SLAKE达93.0%。

| 方法 | ChestAgentBench (%) | CheXbench (%) | SLAKE (%) |
| :--- | :--- | :--- | :--- |
| Qwen3-VL-8B (Base) | 55.1 | 65.5 | 72.8 |
| MedRAX (GPT-4o) | 63.1 | 68.1 | 70.4 |
| X-Ragent (Ours) | 71.7 | 77.3 | 93.0 |

核心数字对比显示，X-Ragent较最强基线MedRAX在ChestAgentBench上提升8.6个百分点，较基础模型提升16.6个百分点，证明后训练使8B模型超越更大通用VLM。

消融实验验证了各组件贡献。移除工具轨迹监督导致ChestAgentBench下降4.5个百分点，移除报告式CoT导致OOD基准下降5.5个百分点。奖励设计消融显示，无门控组合 $R_{\text{CXR}}$ 和 $R_{\text{tool}}$ 反而低于单独使用，而准确率门控组合取得最佳结果。

| 奖励组件 | ChestAgentBench (%) | CheXbench (%) | SLAKE (%) |
| :--- | :--- | :--- | :--- |
| $R_{\text{acc}}$ only | 67.2 | 73.8 | 90.4 |
| $R_{\text{acc}} + R_{\text{CXR}} + R_{\text{tool}}$ (No Gate) | 69.8 | 75.6 | 91.2 |
| $R_{\text{acc}} + R_{\text{CXR}} + R_{\text{tool}}$ (Gated) | 71.7 | 77.3 | 93.0 |

评估边界方面，有效性门控在613个非正面或异常CXR上将准确率从69.17%提升至70.15%，但在1,887个正面CXR上无变化，表明门控收益集中于视图敏感子集。代码未开源，超参数完整报告，可复现性受限。

## 关联研究分析

从问题动机看，X-Ragent与Radiologist Copilot均模拟放射科医生工作流，但Copilot侧重报告生成全流程的多代理通信，X-Ragent侧重诊断证据的按需获取与验证，采用单代理两阶段架构。这一差异源于任务特性：报告生成需多阶段文本合成，而诊断推理需严格证据接地。X-Ragent的有效性门控机制为处理多模态数据中的不适用证据提供了新思路，但单代理两阶段是否比多代理通信在CXR任务上更具效率优势，论文未给出回答。

从方法设计看，X-Ragent与OraPO均使用RL抑制幻觉，但OraPO针对报告生成的零奖励批次问题，X-Ragent针对诊断中的证据一致性。X-Ragent的准确率门控奖励将过程信号与结果正确性绑定，而OraPO的Oracle-educated策略通过外部知识修正奖励。这一差异暗示了任务对奖励稀疏性的敏感度不同：诊断任务的二元正确性使门控机制有效，而报告生成的连续文本质量可能需要更复杂的奖励塑形。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

X-Ragent解决的核心矛盾是工具增强代理在CXR诊断中缺乏证据获取时机学习机制及不适用测量证据污染推理的问题。其切入点在于将策略路由的辅助证据获取与有效性门控的定量测量解耦，通过Rad-CoT数据集和准确率门控GRPO实现证据接地推理。实验证明该方法在ChestAgentBench上达71.7%准确率，较基线提升8.6个百分点。其边界在于有效性门控仅在视图敏感子集上产生净修正，正面视图无增益，且单代理架构在复杂多视图场景下的泛化能力未充分验证。当视图检查失败率超过31%时，门控机制是否会过度抑制有效测量证据，论文未给出回答。
