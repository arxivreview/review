# HuggingFace最新推荐论文 ｜Accurate but Not Humble: Evaluating Epistemic Humility in LLM Agents under Knowledge Conflict ｜智能体在知识冲突下的认知谦逊评估

研究机构：美国约翰斯·霍普金斯大学、美国纽约大学

作者：Kaiser Sun、Bernal Jimenez Gutierrez、Hongjun Liu 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2610.12360)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2610.12360)

> 导读 大语言模型智能体在多步执行中常遭遇内部参数化信念与外部检索证据的矛盾，现有评估仅关注最终答案正确性，忽略了智能体是否识别、处理并上报这种不确定性。传统单轮问答评估无法捕捉多步轨迹中不确定性信号的稀释与丢失，导致高准确率智能体可能“自信地犯错”。本文提出认知谦逊（Epistemic Humility, EH）概念，将其操作化为轨迹级的识别（Identify）、解决（Solve）和上报（Escalate）三个行为维度，通过构建受控与自然发生的知识冲突任务，评估智能体在冲突下的行为模式。该研究揭示了任务准确率与认知谦逊之间的负相关关系，指出智能体倾向于在早期识别冲突但未能有效跟进或上报，为构建可信智能体系统提供了过程评估的新视角。然而，评估依赖大模型裁判，且未深入探究智能体框架（Harness）与骨干模型（Backbone）在不确定性传递中的具体交互机制。

## 研究背景

当智能体在复杂任务中调用工具获取外部信息时，检索到的证据常与其内部参数化知识发生冲突。这种冲突若未被妥善处理，智能体可能盲目遵循错误证据或固执于过时信念，导致任务失败。现有研究多聚焦于单轮问答中的上下文-记忆冲突，通过解码干预或微调提升模型对上下文的忠实度。然而，智能体系统涉及多步推理、工具调用和状态更新，冲突可能在执行中途产生，且最终答案的生成受智能体框架（如规划循环、工具封装）的深刻影响。单轮评估无法反映智能体在长轨迹中是否“察觉”了冲突、是否“尝试”解决以及是否向用户“坦白”了残留的不确定性。

当前智能体评估体系以结果为导向，缺乏对过程可信度的量化指标。高准确率的智能体可能因训练奖励机制而倾向于给出自信但错误的回答，而非承认无知或寻求澄清。这种“过度自信”在高风险场景下构成严重隐患。因此，亟需一种能够评估智能体在知识冲突下行为模式的框架，以区分“能力不足导致的错误”与“缺乏谦逊导致的错误”。本文通过引入认知谦逊概念，填补了从单轮忠实度到多步过程可信度评估的空白。

## 核心方法

### 冲突构建与轨迹记录

本文的评估框架建立在知识冲突的诱发与轨迹级行为记录之上。不同于单轮问答中直接提供冲突上下文，本文在受控冲突场景中，通过提取骨干模型的参数化信念，构建包含相互矛盾证据的问答对；在自然冲突场景中，利用 GAIA、MoNaCo 等需要多步工具调用的基准，筛选出骨干模型持有错误信念但可通过工具获取正确证据的任务实例。每个冲突实例均配对一个无冲突控制组，以隔离冲突状态对行为的影响。

评估的核心在于记录完整的智能体轨迹 $\tau = (s_1, \dots, s_T)$，其中每一步 $s_t$ 包含推理链、工具调用及其参数、观察结果以及用户交互。这种细粒度的记录使得后续分析能够定位冲突识别发生的具体步骤，以及不确定性信号在轨迹中的演变。

### 认知谦逊的轨迹级操作化

为了将抽象的认知谦逊转化为可测量的指标，本文定义了三个轨迹级行为维度：识别（Identify）、解决（Solve）和上报（Escalate），简称 ISE。

**识别（Identify）** 衡量智能体是否在中间推理步骤中察觉到了证据与信念的矛盾。该指标通过大模型裁判（GPT-5）阅读中间轨迹（排除最终回答），判断智能体是否明确指出了冲突，并记录首次识别的步数。其核心公式为 F1 分数，平衡了漏报（未识别冲突）和误报（无冲突时过度怀疑）：

$$
F1_{\text{Identify}} = \frac{2 \cdot P_{\text{Identify}} \cdot R_{\text{Identify}}}{P_{\text{Identify}} + R_{\text{Identify}}}
$$

其中，$P_{\text{Identify}}$ 为识别的精确率，$R_{\text{Identify}}$ 为识别的召回率。该设计动机在于避免智能体通过在所有步骤中泛泛地表达不确定性来“刷分”，强制要求识别行为与真实冲突状态对齐。

**解决（Solve）** 衡量智能体在识别冲突后，是否采取了行动去弥合知识缺口。具体定义为：在首次识别冲突的步数 $t^*_i$ 之后，智能体是否发起了新的工具调用（非重复调用），并最终给出了答案。该指标关注行为努力而非结果正确性，旨在分离“尝试解决”与“解决成功”：

$$
R_{\text{Solve}} = \frac{\sum_{i} b_i}{\sum_{i} \mathbb{1}[\hat{g}_i = 1]}
$$

其中，$b_i$ 为指示变量，当轨迹中存在识别后的新工具调用且正常终止时为 1。该设计揭示了智能体是否具备“知错能改”的行为倾向，而非仅仅依赖最终答案的正确性。

**上报（Escalate）** 衡量智能体在最终回答中是否向用户坦白了残留的不确定性。该指标仅在冲突实例且最终答案错误（即知识缺口未被闭合）的子集上计算，评估最终回答是否包含承认不确定性的表述：

$$
R_{\text{Escalate}} = \frac{\sum_{i \in D^+} \mathbb{1}[a_i = 1 \land c_i = 0]}{\sum_{i \in D^+} \mathbb{1}[c_i = 0]}
$$

其中，$a_i$ 为最终回答承认不确定性的标签，$c_i$ 为答案正确性标签。该设计动机在于捕捉智能体在“无法解决”时的诚实度，防止其通过猜测或掩盖不确定性来误导用户。

## 实验评估

实验在受控冲突（TMD）和自然冲突（GAIA, MoNaCo, BrowseComp）两类设置下进行，评估了 Nemotron、Claude Code、OpenHands 和 Qwen-Agent 四种智能体框架。基线审计显示，本文未直接对比单轮解码干预方法（如 CAD），而是聚焦于智能体框架层面的行为差异。

主实验结果揭示了任务准确率与认知谦逊之间的复杂关系。在受控冲突中，所有配置在冲突组的表现均显著低于无冲突控制组，表明知识冲突对任务性能有实质性负面影响。在自然冲突中，高准确率配置（如 Claude Code 在 BrowseComp 上）往往伴随较低的解决率和上报率，而低准确率配置（如 Nemotron 在 TMD 上）则表现出较高的上报倾向。

| 智能体框架 | 数据集 | 冲突组准确率 (%) | 控制组准确率 (%) |
| :--- | :--- | :--- | :--- |
| Nemotron-Orch-8B | TMD | 3.0 | 39.0 |
| OpenHands (GPT-5) | GAIA | 51.0 | 65.4 |
| Claude Code (Sonnet 4.6) | BrowseComp | 55.2 | 44.0 |
| Qwen-Agent (Qwen3.5-9B) | MoNaCo | 26.9 | 42.4 |

*注：数据取自论文 Table 1。Claude Code 在 BrowseComp 上冲突组准确率高于控制组，表明其可能从冲突证据中获益，但后续分析显示其上报率极低。*

消融实验与干预分析表明，通过系统提示词（System Prompt）要求智能体考虑替代解释并报告不确定性，能显著提升上报率，但往往以牺牲任务准确率为代价。例如，在 MoNaCo 上，GPT-5 的上报率从 1.6% 激增至 60.7%，但准确率从 30.1% 降至 23.2%。这一反直觉发现暗示，当前的奖励机制和训练目标可能隐含地惩罚了“承认无知”的行为，导致智能体在默认状态下倾向于“自信地犯错”。

评估边界方面，本文依赖 GPT-5 作为裁判进行轨迹级打分，尽管与人类标注者的一致性较高（Identify 76.0%, Escalate 85.3%），但裁判模型本身的偏差可能影响评估的绝对准确性。此外，实验未隔离骨干模型与智能体框架的独立贡献，无法确定低上报率是源于模型能力不足还是框架设计缺陷。

## 关联研究分析

从问题动机看，本文与 NQ-SWAP 等单轮冲突基准存在本质差异。NQ-SWAP 旨在量化模型在单轮问答中对上下文的忠实度，其核心假设是模型应无条件遵循检索证据。而本文指出，在智能体场景中，盲目遵循上下文可能导致任务失败（若上下文错误），因此“忠实度”需让位于“认知谦逊”——即智能体应具备批判性评估证据并上报不确定性的能力。这一转变将评估重心从“答案正确性”转向“过程可信度”。

从方法设计看，本文与 INTRYGUE 等不确定性估计方法形成互补。INTRYGUE 通过内部熵估计量化模型的不确定性，属于白盒机制分析；而本文通过外部行为（上报）评估不确定性，属于黑盒行为分析。本文未采用内部状态监控，而是通过轨迹级行为捕捉不确定性，这使其适用于闭源模型和复杂智能体框架，但无法解释不确定性信号在内部表征中的具体演变路径。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文针对智能体在知识冲突下“自信地犯错”的问题，提出了认知谦逊（EH）的轨迹级评估框架 ISE。通过构建受控与自然冲突任务，本文证明了任务准确率与认知谦逊之间存在负相关，且智能体常在早期识别冲突但未能有效跟进或上报。核心发现包括：高准确率配置的上报率往往低于 10%，且提示词干预虽能提升上报率但会损害准确率。本文的边界在于未深入探究智能体框架（Harness）如何稀释或覆盖骨干模型的不确定性信号，且评估依赖大模型裁判。当智能体框架引入更复杂的规划与反思机制时，这种负相关关系是否依然存在，论文未给出回答。
