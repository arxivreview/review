作者：Shuo Gao、Chenhao Zheng、Zhongzheng Ren

论文原文见 [arXiv](https://arxiv.org/abs/2610.16118)

> 长视频理解的核心矛盾在于视觉Token数量随视频时长线性增长，导致内存消耗与推理延迟不可控。现有训练无关的压缩方法通过丢弃冗余Token或关键帧来缓解压力，但这种硬截断操作破坏了时间连续性，且保留的Token数量仍随视频长度线性扩展，未能从根本上解决内存瓶颈。FramePack-U提出了一种无需训练的推理时优化策略，通过相关性-多样性贪心采样筛选关键帧，并依据优先级分配异构空间分辨率，将任意长度的视频打包至固定Token预算中。该设计在保持全时间覆盖的同时，将内存复杂度降至$O(1)$，在多个长视频基准上显著优于均匀采样及现有Token剪枝方法，但其性能增益高度依赖骨干模型的容量，且低分辨率帧的细粒度感知能力尚存疑。

## 研究背景

当视觉语言模型（Vision-Language Models, VLMs）处理小时级视频时，逐帧编码产生的视觉Token数量与视频时长成正比，这种线性增长直接导致显存溢出与推理延迟激增。为缓解计算压力，主流方法采用Token剪枝或关键帧选择，通过评分机制过滤非关键内容。然而，这些方法存在两个根本缺陷：一是保留的Token数量仍随视频长度线性扩展，内存瓶颈仅被推迟而非消除；二是硬丢弃操作具有离散性和有损性，破坏了时间连续性，抹除了对长程推理至关重要的瞬时动作。

领域内已确立“视觉Token冗余是主要障碍”的共识，自适应采样优于均匀采样。但现有自适应方法多聚焦于“选哪些帧”，忽略了“如何表示帧”。在固定内存预算下，若所有选中帧均保持全分辨率，则能容纳的帧数极少，时间覆盖稀疏；若均匀降采样，则关键帧的空间细节丢失。FramePack-U的切入点在于：在固定Token预算下，通过异构分辨率分配，让高优先级帧保留高分辨率，低优先级帧大幅压缩，从而在内存恒定的前提下最大化时间覆盖与关键证据保真度。

## 核心方法

### 方法参照系：固定预算下的帧选择与表示

在长视频理解的通用流程中，模型需从$T$帧视频中提取视觉特征输入LLM。标准做法是均匀采样$N$帧并全分辨率编码，或基于注意力/相似度剪枝至$N$帧。本文问题与该通用流程的关键差异在于：本文不改变输入LLM的总Token预算$B$，而是通过动态调整每帧的空间分辨率，使实际处理的帧数$N$可远超$B$对应的全分辨率帧数，实现“恒定内存、可变帧数”的打包。

### 相关性-多样性贪心采样

传统关键帧选择仅依据查询相关性，易导致选中帧视觉冗余，覆盖时间跨度窄。FramePack-U在采样阶段引入多样性约束，确保选中帧既相关又互补。

首先计算每帧$x_i$与查询$q$的CLIP相似度$r_i$。随后执行贪心选择，第$n$步选择帧$x_n^*$的准则为：

$$
x_n^* = \begin{cases}
\arg\max_{x_i \in V} r_i, & n = 1 \\
\arg\max_{x_i \in V \setminus \tilde{V}} \left( \lambda r_i - (1 - \lambda) \max_{x_j \in \tilde{V}} \text{sim}(x_i, x_j) \right), & n > 1
\end{cases}
$$

其中$\tilde{V}$为已选帧集合，$\text{sim}$为帧间视觉相似度，$\lambda$为权衡系数（默认0.7）。该公式的物理含义是：在优先选择高相关性帧的同时，惩罚与已选帧视觉相似的候选帧，强制采样结果在语义相关性与视觉多样性之间取得平衡，避免高分辨率预算被重复内容占据。

### 异构分辨率层级打包

采样后得到$N$个按优先级排序的候选帧。传统方法对所有选中帧统一编码，导致内存占用随$N$线性增长。FramePack-U定义打包方案$S = \{(d, f_d)\}$，其中$d$为下采样因子，$f_d$为分配至该分辨率的帧数。

总内存约束为：

$$
\sum_{d} \frac{f_d}{d^2} \leq B
$$

其中$B$为固定Token预算（以全分辨率帧数为单位）。高优先级帧分配$d=1$（全分辨率），低优先级帧分配$d=2, 4$等。该公式表明，通过增加低分辨率帧的数量，可在不增加总Token数的情况下显著扩大时间覆盖范围。例如，方案`d1f16d2f448`在128帧内存预算下实际处理464帧，其中16帧全分辨率，448帧2倍下采样。这种设计将内存预算集中分配给指令相关且视觉独特的帧，同时保留全视频的时间上下文。

## 实验评估

实验在LongVideoBench、MLVU和Video-MME三个长视频基准上进行，对比基线包括均匀采样（Vanilla）及训练无关的Token压缩方法FastVID、VisionZip、FrameFusion。评估协议严格控制在相同视觉内存预算（128/256/512帧等效）下，以验证方法在固定资源下的效率增益。

| 模型 | 内存预算 | 方法 | LongVideoBench | MLVU | Video-MME |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Qwen3.5-35B-A3B | 128 | Vanilla | 59.4 | 71.8 | 66.7 |
| | | FastVID | 50.3 | 66.7 | 61.5 |
| | | VisionZip | 52.2 | 65.6 | 60.7 |
| | | FrameFusion | 56.5 | 63.9 | 61.3 |
| | | **FramePack-U** | **72.3** | **82.4** | **76.4** |
| Qwen3.6-27B | 512 | Vanilla | 71.8 | 78.0 | 74.4 |
| | | FastVID | 58.5 | 68.4 | 61.1 |
| | | VisionZip | 63.7 | 69.9 | 67.2 |
| | | FrameFusion | 62.8 | 70.5 | 66.9 |
| | | **FramePack-U** | **74.9** | **82.1** | **76.3** |

在Qwen3.5-35B-A3B的128帧预算下，FramePack-U在LongVideoBench、MLVU和Video-MME上分别较Vanilla提升12.9%、10.6%和9.7%，且全面超越FastVID等Token剪枝基线。在Qwen3.6-27B的512帧预算下，尽管Vanilla基线已较强，FramePack-U仍保持3.1%-4.1%的稳定增益。这表明异构分辨率打包在低预算下优势尤为显著，有效解决了Token剪枝方法因丢弃帧导致的时间覆盖不足问题。

消融实验揭示了两个关键设计决策的必要性。移除多样性约束（Relevance-only）导致Video-MME性能下降6.5%，证实了纯相关性采样易陷入视觉冗余陷阱。移除相关性约束（Diversity-only）在MLVU上下降1.8%，说明时间覆盖虽重要，但缺乏查询导向的帧选择会遗漏关键证据。此外，模型规模消融显示，在Qwen3.5-4B上FramePack-U在MLVU上出现-1.0%的负增益，表明小模型容量不足以整合大量低分辨率视觉证据，方法增益随模型规模增大而增强。

评估边界方面，实验主要在离线基准上进行，未充分验证流式实时场景下的延迟表现。此外，未与VideoMem等记忆增强类方法进行直接对比，无法判断异构分辨率打包与结构化记忆在长程依赖建模上的互补性。代码与超参数已开源，但低分辨率帧对OCR等细粒度任务的影响未单独评估。

## 关联研究分析

从方法设计看，FramePack-U与LLaMA-VID均致力于视觉Token压缩，但LLaMA-VID通过交叉注意力将视觉特征压缩为固定长度查询嵌入，需训练且丢失原始帧结构；FramePack-U无需训练，保留原始帧像素结构仅调整分辨率，更适合作为即插即用的推理优化模块。与FastVID等Token剪枝方法相比，FramePack-U的核心差异在于“压缩表示”而非“丢弃内容”：FastVID直接移除冗余Token，导致时间不连续；FramePack-U通过降采样保留所有帧的粗略信息，维持了时间连续性，这对依赖时序因果推理的任务至关重要。

从问题动机看，FramePack-U与VideoMem均针对长视频内存瓶颈，但路线截然不同。VideoMem构建外部记忆库存储视频摘要，通过检索增强生成解决长程依赖，属于“感知-记忆”解耦路线；FramePack-U则在感知阶段通过分辨率分配优化输入表示，属于“高效感知”路线。VideoMem在LVBench上取得77.4%的高分，表明结构化记忆在超长视频推理上具有优势；FramePack-U在VideoMME上76.4%的成绩则显示，在中等长度视频上，优化输入表示可能比构建外部记忆更高效。两种路线是否可叠加使用，论文未给出回答。

## 总结

FramePack-U针对长视频理解中视觉Token线性增长导致的内存瓶颈，提出了一种无需训练的异构分辨率打包方法。通过相关性-多样性贪心采样与层级分辨率分配，该方法在固定Token预算下实现了$O(1)$内存复杂度，同时最大化时间覆盖与关键证据保真度。在Qwen3.5-35B-A3B上，该方法在LongVideoBench和MLVU上分别取得72.3%和82.4%的准确率，显著优于均匀采样及Token剪枝基线。然而，实验显示该方法在4B小模型上出现性能退化，表明其增益依赖骨干模型整合多源视觉证据的能力。当骨干模型容量受限时，异构分辨率打包带来的时间覆盖增益是否会被低分辨率帧的感知噪声抵消，论文未给出明确边界。
