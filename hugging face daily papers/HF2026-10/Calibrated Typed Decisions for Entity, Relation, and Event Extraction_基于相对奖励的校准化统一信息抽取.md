> 导读 信息抽取模型在特定数据集上表现优异，但跨域泛化时性能急剧下降，且生成式模型常伴随幻觉与边界错误。现有判别式模型虽能锚定原文，却难以在零样本设定下平衡假阳性与类型混淆。CALON 提出一种统一编码器架构，将实体、关系和事件抽取转化为 Span 与 Span-pair 的概率决策，并引入相对奖励机制优化采样决策。该工作证明了小参数判别式模型结合强化学习信号在零样本结构化抽取中的有效性，但其对长文档跨句依赖的建模能力尚存疑。

## 研究背景

当抽取模型面对新领域时，其训练域与测试域的数据分布出现系统性差异，导致决策边界失效。传统流水线架构将实体识别与关系分类解耦，误差在阶段间传播；而生成式大语言模型（LLM）虽支持灵活 Schema，却易产生原文中不存在的实体或篡改提及边界。为解决此困境，判别式匹配范式（如 GLiNER）通过联合编码文本与类型定义，直接预测 Span 及其类型，将抽取任务转化为相似度比较。然而，此类模型在零样本设定下，面对未见类型时往往因缺乏显式的错误惩罚机制，导致假阳性率居高不下，且难以区分细粒度类型混淆。

领域内主流路线分为生成式与判别式两类。生成式模型（如 UIE, InstructUIE）通过文本生成表达抽取目标，虽能容纳详细指令，但输出不可控且计算成本高。判别式模型（如 UniEX, GLiNER2）通过 Span 匹配实现高效抽取，但其训练目标仅依赖似然监督，未显式优化“正确抽取”与“错误抽取”之间的相对优势。CALON 的切入点在于：在保持判别式模型锚定原文优势的同时，引入强化学习中的相对奖励信号，直接优化抽取决策的期望回报，从而在零样本跨域场景下抑制假阳性并提升类型判别精度。

## 核心方法

### 统一 Span 与 Span-pair 概率建模

CALON 将实体、关系和事件抽取统一为对候选 Span 或 Span-pair 的类型分类问题。对于实体，模型编码输入文本与 Schema 中的类型定义，通过双向 Transformer 获取 Token 表示。候选 Span 由首尾 Token、均值池化及宽度嵌入拼接而成。对于关系，候选对由两个实体 Span 的向量、逐元素乘积及中间 Token 均值构成。事件抽取则被分解为触发词识别（实体任务）与论元角色分配（关系任务）。

该架构的关键在于引入 Null 类以处理无匹配情况。对于候选 $c$ 和查询类型集合 $\mathcal{K}$，模型预测其属于类型 $m$ 或 Null 类 $0$ 的概率分布：

$$ p_c(m) = \frac{\exp(z_{m,c})}{\sum_{m' \in \{0\} \cup \mathcal{K}} \exp(z_{m',c})} $$

其中 $z_{m,c}$ 为双线性打分函数输出的 Logit。这种统一概率框架使得实体、关系和事件共享相同的解码逻辑，即通过阈值筛选候选并分配最高概率类型，避免了生成式模型的边界漂移问题。

### 基于相对奖励的决策优化

传统似然损失仅最大化 Gold 标签的概率，未显式惩罚模型在采样时可能产生的错误决策。CALON 借鉴 RLCD（Reinforcement Learning for Calibrated Decisions）思想，将每个候选视为随机策略，通过高斯扰动生成多个采样决策，并计算相对奖励。

对于候选 $c$，其 Logit 向量 $z_c$ 被扰动为 $\tilde{z}_c^{(k)} = z_c + \sigma \epsilon^{(k)}$，其中 $\epsilon^{(k)}$ 为标准正态分布噪声。每个采样决策 $d^{(k)} = \arg\max_m \tilde{z}_m^{(k)}$ 获得奖励 $R^{(k)}$：若为 Gold 类型则 $R=1$，若为非 Gold 类型则 $R=-1$，若为 Null 类则 $R=0$。相对优势 $\delta^{(k)}$ 定义为该样本奖励与其他样本平均奖励之差：

$$ \delta_c^{(k)} = R_c^{(k)} - \bar{R}_c^{(-k)} $$

决策奖励损失 $\mathcal{L}_{RL}$ 通过 Score Function 估计负期望奖励：

$$ \mathcal{L}_{RL} = -\frac{1}{S} \sum_{k=1}^S \delta_c^{(k)} \log \pi(\tilde{z}_c^{(k)} | z_c) $$

该机制无需额外的 Critic 网络，直接利用采样间的相对差异强化正确决策、抑制假阳性。这一设计解决了似然监督在类别不平衡（Null 类占主导）下对错误类型惩罚不足的问题，使模型在 Logit 微小波动时仍能保持决策稳定性。

### 先验概率校正与校准

由于 Null 类候选在训练中占绝大多数，模型通常对其赋予较低权重 $\omega$ 以平衡梯度。这导致模型输出的 Null 类 Logit 系统性偏低，即概率估计存在偏差。CALON 引入先验校正，在温度缩放前向 Null Logit 添加 $\log(1/\omega)$：

$$ z_{0,c}^{\text{corrected}} = z_{0,c} + \log(1/\omega) $$

该校正不改变候选间的相对排序，但显著改善了概率校准性，使得基于阈值的解码在零样本设定下更加鲁棒。

## 实验评估

实验在 40 个基准上评估 CALON 的零样本泛化能力，涵盖实体抽取（NER）、关系抽取（RE）和事件抽取（EE）。基线包括判别式模型 GLiNER2、GLiFormer，以及生成式模型 InstructUIE、GoLLIE 和 GNER。评估协议严格禁止使用目标数据集的标注数据进行训练或校准。

| 任务 | 数据集/类别 | CALON | GLiNER2 | GLiFormer | InstructUIE | GoLLIE |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| NER | CrossNER AI | **66.1** | 56.1 | 59.1 | 48.1 | 49.2 |
| NER | SciER | **70.9** | 51.6 | 51.9 | 51.4 | 54.6 |
| NER | BioRED | **72.1** | 57.3 | 57.5 | 33.7 | 60.4 |
| RE | 平均 F1 (Gold Entities) | **49.8** | - | - | - | - |
| RE | GLiREL (全对候选) | - | - | - | - | 2.6 |

在 NER 任务上，CALON 在 CrossNER AI 上较 GLiNER2 提升 10.0 个点，在 SciER 上较 GLiFormer 提升 19.0 个点，显示出在科学、生物医学等垂直领域的显著优势。在 RE 任务上，CALON 在所有报告基准上均领先。值得注意的是，当评估协议从“仅提供标注关系对”改为“提供所有 Gold 实体对”时，GLiREL 的平均 F1 从 40% 骤降至 2.6，而 CALON 保持 49.8，表明 CALON 的 Null 类决策机制在端到端关系抽取中有效抑制了假阳性。

消融实验显示，移除决策奖励项导致 NER F1 从 61.5 降至 61.1，RE F1 从 53.4 降至 48.8，表明奖励机制对关系抽取的增益大于实体抽取。使用 MLP 头替代双线性打分虽提升 NER 至 62.5，但降低了 RE 和 EE 性能，证实双线性形式在 Span-pair 交互建模中的必要性。

评估边界方面，CALON 的峰值 GPU 内存占用为 8.0 GB，高于 GLiNER2 的 2.9 GB，但吞吐量（120 Sent./s）远高于生成式基线。论文未报告置信区间，且未覆盖文档级长距离依赖基准（如 DocRED），其跨句推理能力尚未经过严格验证。

## 关联研究分析

从问题动机看，CALON 与 GLiNER2 同属判别式零样本抽取路线，但 GLiNER2 仅依赖似然监督，未显式优化决策边界。CALON 引入 RLCD 相对奖励，直接针对零样本场景下常见的假阳性与类型混淆进行优化。这一差异源于任务特性：零样本设定下，模型对未见类型的概率估计往往过于自信，似然损失难以纠正这种系统性偏差，而相对奖励通过采样对比提供了更直接的错误信号。

从方法设计看，CALON 与 InstructUIE 代表了判别式与生成式两种范式。InstructUIE 通过指令微调支持灵活 Schema，但受限于生成幻觉与边界错误。CALON 通过 Span-pair 显式建模关系方向与类型，避免了生成式模型在长文本中的上下文丢失问题。然而，CALON 的 Span-pair 复杂度随实体数量二次增长，限制了其在密集实体文档中的应用，而生成式模型在处理稀疏关系时可能更具效率优势。

## 总结

CALON 针对零样本信息抽取中判别式模型假阳性高、生成式模型幻觉严重的问题，提出了一种结合相对奖励优化的统一编码器架构。该模型将实体、关系和事件统一为 Span 与 Span-pair 的概率决策，并通过 RLCD 机制强化正确抽取、抑制错误类型。实验表明，CALON 在 40 个基准上多数领先，尤其在零样本关系抽取上显著超越 GLiREL 等基线（平均 F1 49.8 vs 2.6）。其边界在于 Span-pair 建模的计算复杂度限制了长文档处理能力，且未验证在文档级跨句依赖场景下的表现。当文档中实体密度极高时，Span-pair 候选空间的爆炸式增长是否会抵消奖励机制带来的精度增益，论文未给出回答。
