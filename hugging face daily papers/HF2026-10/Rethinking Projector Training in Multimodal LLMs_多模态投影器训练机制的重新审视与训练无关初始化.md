> 多模态大语言模型（MLLMs）通常采用两阶段训练范式，第一阶段通过大量图文对训练投影器以对齐视觉与语言特征。然而，该阶段究竟是在学习细粒度的语义对应关系，还是仅进行粗粒度的几何分布对齐，目前缺乏清晰认知，导致不同研究对数据规模与架构设计的结论相互矛盾。本文通过实证分析揭示，投影器训练仅需少量数据即可饱和，且不同数据源训练的投影器可线性插值，表明其本质是几何条件化而非语义学习。基于此，本文提出 PORTAL，一种无需配对数据与梯度优化的训练无关投影器初始化方法，通过最优传输映射直接构建投影器。该工作挑战了标准预训练范式，为降低 MLLM 训练成本提供了新路径，但在细粒度 OCR 任务上的性能损失提示了纯几何对齐的局限性。

## 研究背景

当视觉编码器与冻结的大型语言模型（LLM）结合时，视觉特征无法直接输入 LLM，需通过投影器映射至兼容的输入空间。这一过程通常依赖大量图文对进行监督训练，旨在缩小模态间隙（Modality Gap）。然而，现有研究对投影器训练的作用存在分歧：Prismatic 指出跳过该阶段可能提升性能，而 Cambrian-1 则显示增加数据至 2.5M 对有益。这种矛盾源于对投影器训练本质的理解缺失——它究竟是在学习复杂的视觉-语言语义对应，还是仅将视觉特征投影至一个宽泛的兼容区域？

若投影器仅执行粗粒度几何对齐，则其解空间应极为宽泛，对数据规模不敏感；若学习细粒度语义，则需大量数据且解空间狭窄。现有方法未能区分这两种机制，导致在架构设计与数据策略上缺乏理论指导。本文通过实证实验验证前者假设，指出标准 Stage-I 训练主要进行几何条件化，从而为替代该阶段提供了理论依据。

## 核心方法

### 方法参照系：标准两阶段训练流程

在 LLaVA 等标准 MLLM 架构中，训练分为两阶段：Stage-I 冻结视觉编码器与 LLM，仅训练投影器（通常为 2 层 MLP）以对齐视觉特征与 LLM 输入嵌入；Stage-II 解冻 LLM 进行指令微调。本文挑战 Stage-I 的必要性，提出用闭式解替代梯度优化。

### 核心创新：基于最优传输的闭式投影器构建

标准投影器训练通过最小化预测误差来学习映射，而 PORTAL 将投影器构建视为两个高斯分布间的最优传输问题。设计动机在于，若投影器仅需将视觉特征分布映射至 LLM 输入分布的兼容区域，则无需配对监督，仅需匹配两个模态的边际统计量（均值、主成分方向、方差）。

PORTAL 首先分别计算视觉特征分布 $N(\mu_s, \Sigma_s)$ 和 LLM 输入嵌入分布 $N(\mu_t, \Sigma_t)$ 的均值与协方差。随后，在共享的 Top-$k$ 主成分子空间上，计算 Bures-Wasserstein 最优传输映射。投影器第一层权重 $W_1$ 和偏置 $b_1$ 由下式闭式给出：

$$
W_1 = V_t \text{diag}\left(\frac{\sigma_t}{\sigma_s}\right) V_s^\top, \quad b_1 = \mu_t - W_1 \mu_s
$$

其中 $V_s, V_t$ 分别为源域和目标域的 Top-$k$ 主成分基，$\sigma_s, \sigma_t$ 为对应主成分方向上的标准差。该公式的物理含义是：$W_1$ 首先将视觉特征白化（去相关并缩放至单位方差），然后旋转至目标域的主轴方向，最后按目标域的方差进行缩放，从而在几何上对齐两个分布。$b_1$ 负责重新中心化。此过程无需任何梯度计算，仅依赖 PCA 分解。

### 理论支撑：矩匹配在非高斯分布下的有效性

尽管真实特征分布非高斯，PORTAL 仍有效，因为 LLM 在注意力计算前对 Token 进行归一化（如 RMSNorm），使得注意力权重仅依赖于 Token 的方向而非模长。PORTAL 通过匹配协方差，控制了 Token 方向的余弦离散度（Cosine Dispersion）。

定义余弦离散度 $\omega$ 为两个随机 Token 余弦相似度的标准差。理论分析表明，当 Token 模长变化较小时，$\omega$ 主要由协方差矩阵的有效维度 $d_{\text{eff}}$ 决定：

$$
\text{Var}(\cos \angle(z, z')) \approx \frac{1}{d_{\text{eff}}(\Sigma)}
$$

PORTAL 通过匹配目标域的协方差，使得输出 Token 的方向分布与 LLM 输入分布一致，从而保证注意力机制能正常运作。这一理论解释了为何仅匹配二阶矩即可实现有效的跨模态对齐。

## 实验评估

实验在 LLaVA 1.5 架构上进行，涵盖 7 种（视觉编码器，LLM）组合，包括 Vicuna、LLaMA、Qwen 等 LLM 及 CLIP、SigLIP 视觉编码器。评估基准包括 16 个任务，分为知识、通用、OCR 和视觉中心四类。基线对比包括标准 Stage-I 训练投影器（Baseline）和随机初始化投影器（Random）。

主实验结果显示，PORTAL 在无需任何配对数据的情况下，平均性能达到标准训练基线的 98.8% 至 106.2%。在 LLaMA 3.1 8B/CLIP 和 LLaMA 3.2 1B/CLIP 配置下，PORTAL 甚至超越了标准基线。

| 配置 | 初始化方法 | 平均得分 (Avg) | 相对基线百分比 (%BL) |
| :--- | :--- | :--- | :--- |
| Vicuna 1.5 7B / CLIP | Baseline | 48.0 | 100.0 |
| | Random | 44.9 | 93.5 |
| | **PORTAL** | **47.4** | **98.8** |
| LLaMA 3.1 8B / CLIP | Baseline | 50.8 | 100.0 |
| | Random | 50.4 | 99.2 |
| | **PORTAL** | **52.2** | **102.7** |
| LLaMA 3.2 1B / CLIP | Baseline | 41.6 | 100.0 |
| | Random | 41.5 | 99.9 |
| | **PORTAL** | **44.2** | **106.2** |

消融实验验证了 PORTAL 作为初始化策略的效率。当使用 PORTAL 初始化并继续少量配对数据训练时，仅需约 4k 样本即可达到标准 558k 样本训练的性能，相当于减少 135 倍的计算量。此外，主成分数量 $k$ 的选择显示，$k=512$ 为最佳平衡点，过小会丢失几何结构，过大则引入噪声。

评估边界方面，PORTAL 在 OCR 类任务上表现略逊于标准基线，表明纯几何对齐难以捕捉字符级的细粒度空间结构。此外，实验未对比 DPO 等偏好对齐算法，因为 PORTAL 关注的是预训练阶段的初始化，而非指令微调阶段的对齐。

## 关联研究分析

从问题动机看，本文与 Prismatic 和 Cambrian-1 形成直接对话。Prismatic 发现跳过 Stage-I 可行，但未解释原因；Cambrian-1 强调数据规模的重要性。本文通过线性插值实验证明，不同数据源训练的投影器可互换，揭示了 Stage-I 的解空间宽泛性，从而调和了上述矛盾：Prismatic 的成功是因为随机初始化已落入兼容区域，而 Cambrian-1 的数据增益仅在未饱和前有效。

从方法设计看，PORTAL 与传统的度量学习或原型网络不同，它不依赖类别标签或支持集，而是直接建模特征分布的几何结构。与 LLaVA 等依赖梯度优化的方法相比，PORTAL 完全消除了 Stage-I 的计算开销。然而，这种几何对齐是否限制了模型在复杂推理任务中的上限，论文未给出明确回答，仅指出 OCR 性能下降可能源于此。

## 总结

本文针对 MLLM 预训练中投影器作用不明的问题，通过实证发现 Stage-I 训练本质是粗粒度几何对齐，并提出 PORTAL 这一训练无关的闭式初始化方法。PORTAL 在无需配对数据的情况下，平均性能达到标准基线的 98.8% 以上，并在部分配置下超越基线，显著降低了训练成本。然而，其在 OCR 等细粒度任务上的性能损失暴露了纯几何对齐的局限，即无法捕捉字符级的空间结构。当几何对齐与细粒度语义对齐存在冲突时，如何设计混合机制以兼顾效率与精度，是该方法走向通用化必须解决的问题。
