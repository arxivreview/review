> 导读 长思维链（Chain-of-Thought, CoT）推理虽能提升大语言模型（Large Language Models, LLMs）在复杂任务上的表现，但自回归解码导致的离散 Token 序列冗长，使得强化学习（Reinforcement Learning, RL）探索效率低下且计算成本高昂。现有连续潜在推理方法多采用确定性映射，将 Token 分布坍缩为单一向量，导致策略分布丧失随机性，无法支持 RL 所需的试错探索。本文提出多路复用思维，通过独立采样 $K$ 个离散 Token 并聚合为连续向量，在保持离散采样动态的同时实现连续表示，使轨迹概率可分解并直接用于 RL 优化。该方法在数学推理基准上显著优于离散基线，但其性能增益是否源于模型容量对叠加路径干扰的抑制，而非机制本身的普适性，仍需进一步验证。

## 研究背景

当 LLM 执行多步算术推理时，模型需在每一步从词表中选择一个离散 Token 作为下一步推理动作。这一过程遵循自回归生成机制，即当前 Token 的采样依赖于前序所有 Token 的上下文。然而，离散 Token 的表达带宽有限，单个 Token 仅能承载单一语义单元，导致模型在面临高熵决策点时，必须通过生成冗长的中间步骤来逐步消解不确定性，从而引发推理链长度与计算复杂度的线性甚至二次方增长。这种离散瓶颈不仅限制了推理效率，更使得基于 RL 的优化面临探索困境：每次采样轨迹都承诺于单一离散路径，难以在单步内并行评估多条备选推理路径。

为突破离散 Token 的表达局限，研究界转向连续潜在空间推理，试图用低维连续向量替代离散 Token 以压缩推理信息。Soft Thinking 等方法通过概率加权嵌入混合实现连续表示，但其映射过程是确定性的：给定上下文，连续向量由 Token 分布唯一确定。这种确定性坍缩了策略分布，使得不同采样轨迹在连续空间中趋于一致，剥夺了 RL 算法赖以收敛的随机探索信号。与此同时，RL 结合可验证奖励（Reinforcement Learning with Verifiable Rewards, RLVR）已成为训练高效推理模型的主流范式，其核心依赖于策略梯度的无偏估计，而这要求 rollout 过程具备足够的随机性。现有连续推理方法在表示压缩与探索随机性之间形成了根本性冲突：压缩信息密度必然牺牲分布多样性，而保留多样性又难以实现紧凑表示。

本文的切入点在于重构连续 Token 的生成机制，使其既具备连续表示的信息密度，又保留离散采样的随机动态。通过引入基于采样的聚合策略，多路复用思维在单步内并行探索多条推理路径，并将这种并行性显式建模为可分解的概率分布，从而弥合了连续表示与 RL 优化之间的鸿沟。

## 核心方法

### 方法参照系

标准 CoT 推理中，模型在每一步从词表 $V$ 中采样一个离散 Token $t_i$，其概率由策略 $\pi_\theta(\cdot | q, t_{<i})$ 决定。现有连续推理方法（如 Soft Thinking）将 $t_i$ 替换为连续向量 $c_i$，通常通过 $c_i = E^\top p_i$ 计算，其中 $p_i$ 为 Token 分布，$E$ 为嵌入矩阵。该流程的关键差异在于：标准 CoT 保留采样随机性但表达带宽低；Soft Thinking 提升表达带宽但丧失随机性，导致 RL 优化失效。

### 随机采样聚合机制

多路复用思维在推理步 $i$ 不再直接映射分布，而是从 $\pi_\theta(\cdot | q, c_{<i})$ 中独立采样 $K$ 个离散 Token $\{k_{i,1}, \dots, k_{i,K}\}$。设计动机在于解决确定性映射导致的策略分布坍缩问题，通过引入采样随机性恢复 RL 所需的探索能力。聚合过程定义为：

$$
s_i = \frac{1}{K} \sum_{j=1}^{K} z_{i,j}, \quad c_i = E^\top (s_i \odot w_i)
$$

其中 $z_{i,j}$ 为 $k_{i,j}$ 的 one-hot 向量，$w_i$ 为权重向量。该公式的物理含义是：$s_i$ 捕获了 $K$ 个采样 Token 的统计分布，$c_i$ 则是该分布在嵌入空间中的加权表示。当 Token 分布低熵时，$K$ 个采样趋于一致，$c_i$ 退化为标准离散 Token；当分布高熵时，$c_i$ 编码多条路径的叠加信息，实现单步内的并行探索。

### 概率分解与 RL 优化

由于采样独立性，多路复用 Token 的概率可分解为各离散 Token 概率的乘积。设计动机在于使连续轨迹的概率可显式计算，从而直接应用策略梯度优化。整个推理轨迹 $c$ 的对数概率为：

$$
\log \pi_\theta(c | q) = \sum_{i=1}^{L} \sum_{j=1}^{K} \log \pi_\theta(k_{i,j} | q, c_{<i})
$$

该公式表明，多路复用轨迹的概率等价于 $K \times L$ 个离散采样的联合概率。基于此，RL 目标函数定义为最大化期望奖励：

$$
\mathcal{J}(\theta) = \mathbb{E}_{c, y \sim \pi_\theta} [r(y, y^*)]
$$

其中 $r$ 为可验证奖励函数。这一分解使得 GRPO 等 RL 算法可直接作用于多路复用轨迹，无需额外近似，解决了连续表示下梯度估计困难的问题。

## 实验评估

实验基于 DeepSeek-R1-Distill-Qwen-1.5B 和 7B 骨干，使用 GRPO 训练 300 步，评估涵盖 AIME 2024/2025、AMC 2023、MATH-500、Minerva 和 OlympiadBench 六个数学基准。基线包括离散 CoT、离散 RL 和 Stochastic Soft Thinking，覆盖了离散解码、离散强化学习和连续推理三条路线，但未对比 CODI、PCCoT 等其他潜在推理方法，可能低估了连续推理路线的整体竞争力。

| 模型规模 | 方法 | AIME 2024 | AIME 2025 | AMC 2023 | MATH-500 | Minerva | OlympiadBench |
|---|---|---|---|---|---|---|---|
| 1.5B | Discrete CoT | 10.2 | 11.3 | 36.9 | 66.3 | 23.4 | 30.5 |
| 1.5B | Discrete RL | 10.5 | 11.2 | 38.4 | 66.7 | 24.3 | 31.2 |
| 1.5B | Multiplex Thinking | 11.8 | 13.2 | 38.7 | 67.5 | 26.2 | 31.3 |
| 7B | Discrete CoT | 15.7 | 16.0 | 42.4 | 71.6 | 33.3 | 35.6 |
| 7B | Discrete RL | 17.2 | 19.1 | 44.7 | 74.1 | 35.3 | 38.0 |
| 7B | Multiplex Thinking | 20.6 | 19.7 | 50.7 | 78.0 | 38.6 | 41.7 |

在 7B 模型上，Multiplex Thinking 在 AIME 2024 上达到 20.6，较 Discrete RL 的 17.2 提升 3.4 个点；在 MATH-500 上达到 78.0，较 Discrete RL 的 74.1 提升 3.9 个点。1.5B 模型上增益较小，AIME 2024 仅提升 1.3 个点，表明模型容量对方法效果有显著影响。

消融实验显示，聚合策略对性能影响有限。Multiplex Thinking-Averaged 与 Multiplex Thinking-Weighted 在 7B 模型上的 AIME 2024 准确率分别为 19.9 和 20.6，差异仅 0.7 个点。这表明性能增益主要源于随机采样聚合机制本身，而非特定的加权方案。此外，多路复用宽度 $K$ 从 1 增加到 2 时，AMC 2023 准确率从 44.7 跃升至 49.6，提升 4.9 个点，证实了突破单 Token 瓶颈的关键作用。

评估边界方面，论文未报告置信区间，Pass@1 结果基于 64 次运行平均，Pass@k 基于 1024 次运行的 Bootstrap 估计。代码已开源，但训练超参数（如学习率 $1 \times 10^{-6}$、零 KL 惩罚）的敏感性未充分探讨。评估协议聚焦于数学推理，未覆盖代码生成或逻辑推理等其他任务类型，限制了结论的泛化性。

## 关联研究分析

从问题动机看，多路复用思维与 Soft Thinking 的核心差异在于对随机性的处理。Soft Thinking 通过概率加权嵌入混合实现连续表示，但其确定性映射导致策略分布坍缩，无法支持 RL 优化。多路复用思维通过独立采样 $K$ 个 Token 引入随机性，使连续轨迹的概率可分解，从而直接应用于 RL。这一差异的根源在于任务特性：RL 优化要求策略具备足够的探索能力，而确定性连续表示无法满足这一要求。然而，随机采样聚合是否会导致梯度方差增大，影响收敛稳定性，论文未给出理论分析或实验验证。

从方法设计看，多路复用思维与 CODI 同属潜在推理路线，但优化目标不同。CODI 侧重通过自蒸馏将 CoT 压缩至连续空间，提升潜在推理的稳定性；多路复用思维侧重通过随机采样聚合实现连续表示下的 RL 优化。两者在表示形式上相似，但训练范式存在根本差异：CODI 依赖监督信号，多路复用思维依赖 RL 奖励。这种差异导致多路复用思维在探索能力上占优，但在训练稳定性上可能面临挑战。论文未对比 CODI 等自蒸馏方法，无法判断随机采样聚合与自蒸馏在潜在推理中的相对优劣。

## 总结

多路复用思维旨在解决连续潜在推理中确定性映射导致的 RL 探索瓶颈。其切入点在于通过随机采样聚合保留离散采样的随机动态，同时实现连续表示的信息密度，使轨迹概率可分解并直接用于 RL 优化。方法核心是独立采样 $K$ 个 Token 并聚合为连续向量，基于概率分解应用 GRPO 优化。实验证明，在 7B 模型上，该方法在 AIME 2024 上达到 20.6，较离散 RL 基线提升 3.4 个点；在 MATH-500 上达到 78.0，提升 3.9 个点。然而，1.5B 模型上增益显著缩小，且未对比 CODI 等自蒸馏方法，表明性能增益可能部分依赖模型容量对叠加路径干扰的抑制，而非机制本身的普适性。当模型规模进一步缩小或任务复杂度增加时，随机采样聚合的梯度方差是否会成为收敛瓶颈，论文未给出回答。
