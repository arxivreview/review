# HuggingFace最新推荐论文 ｜DanQing: An Up-to-Date Large-Scale Chinese Vision-Language Pre-training Dataset ｜丹青（DanQing）：面向中文视觉语言预训练的大规模数据策展

作者：Hengyu Shen、Tiancheng Gu、Bin Qin 等 13 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.10305)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.10305)

> 视觉语言预训练（Vision-Language Pre-training, VLP）的性能上限长期受限于高质量图文数据的规模与质量，而中文领域因数据时效性滞后与URL失效问题，面临比英文更严峻的数据稀缺瓶颈。现有中文数据集如Zero和TaiSu虽规模庞大，但缺乏针对2024年后新兴语义的覆盖，且噪声过滤策略粗放，导致模型在零样本分类与检索任务上表现受限。本文切入点在于构建一个基于2024-2025年Common Crawl数据、经四阶段严格过滤的1亿对中文图文数据集，通过提升数据时效性与信噪比来突破中文VLP的性能天花板。其价值在于填补了中文高质量大模型训练数据的空白，但存疑点在于其性能增益是否完全源于数据质量提升，还是部分归因于SigLIP2骨干的特定适配性。

## 研究背景

当视觉语言模型（VLM）处理中文场景时，其训练数据往往滞后于互联网内容的实时演变，导致模型无法捕捉2024年后涌现的新概念与流行语义。这种数据时效性缺失直接削弱了模型在零样本分类任务中的泛化能力，而解决此问题的关键在于构建大规模、低噪声且时效性强的中文图文对。然而，现有中文数据集如Zero（250M对）和TaiSu（166M对）多基于2022年之前的数据，且存在大量失效URL，使得模型训练的可复现性与数据有效性大打折扣。

VLP领域的主流路线是通过大规模对比学习优化双编码器架构，其中SigLIP2等模型通过Sigmoid损失解耦批次耦合，提升了训练稳定性。然而，算法的进步无法弥补数据质量的缺陷，尤其是中文数据在语义密度与视觉多样性上的不足。本文的研究问题因此聚焦于：如何通过系统化的数据策展流水线，从海量网络数据中提炼出高信噪比、高时效性的中文图文对，以突破现有中文VLP数据集的性能瓶颈。

## 核心方法

### 数据策展流水线参照系

本文遵循大规模图文数据集构建的通用流程，即从Common Crawl等网络源采集原始数据，经文本清洗、视觉过滤与跨模态对齐后形成训练集。与LAION-400M等英文数据集相比，本文的关键差异在于针对中文语境的特异性过滤策略，包括中文分词熵过滤、中文NSFW检测及跨批次语义去重，以应对中文网络数据中特有的噪声类型。

### 多阶段文本与视觉精炼

文本精炼阶段旨在消除低信息密度与语法错误样本。设计动机在于解决网络爬取文本中大量存在的广告、乱码及低语义密度描述，这些噪声会干扰对比学习中的正样本对齐。本文采用基于熵的语义过滤器，计算公式为 $H = -\sum_{i=0}^{L} P(c_i) \log_2 P(c_i)$，其中 $P(c_i)$ 为词元概率，$L$ 为文本长度。该公式通过量化文本的信息不确定性，剔除 $H < 6 \times 10^{-4}$ 的低内容样本，确保保留的文本具有足够的语义丰富度。视觉精炼阶段则通过拉普拉斯方差 $\ge 1000$ 过滤模糊图像，并利用ChineseCLIP-L14提取嵌入，通过Union-Find算法对余弦距离低于 $\beta=0.1$ 的图像进行聚类去重，仅保留每簇中心图像，从而在感知与语义层面消除冗余。

### 跨模态跨批次过滤

跨模态过滤阶段旨在确保图文对的语义对齐质量。设计动机在于解决网络数据中图像与文本描述不匹配（如OCR主导图像）的问题，这类样本会引入虚假相关，削弱模型的语义绑定能力。本文利用Chinese-CLIP-L14计算L2距离，仅保留距离在 $[1.06, 1.24]$ 区间内的样本。该区间设定基于经验阈值：低于1.06表示语义相关性弱，高于1.24则多为OCR文本主导而非描述性内容。通过此过滤，数据集从178M对进一步缩减至99,892,381对，显著提升了图文对齐的精确度，为后续SigLIP2的继续预训练提供了高质量监督信号。

## 实验评估

实验设置采用SigLIP2（B/32, B/16, L/16）作为骨干，在16×A800 GPU上对DanQing、Wukong、Zero、TaiSu进行2轮继续预训练。基线覆盖现有主要中文数据集，但缺失英文SOTA（如CLIP）的直接对比，限制了跨语言性能评估。

| 数据集 | SigLIP2-L/16 零样本分类 Avg | SigLIP2-L/16 检索 Avg |
| :--- | :--- | :--- |
| Baseline | 65.2 | 74.1 |
| Wukong | 71.0 | 81.6 |
| Zero* | 72.4 | 81.5 |
| TaiSu* | 65.5 | 84.9 |
| DanQing | 72.9 | 84.3 |

DanQing在零样本分类上较Wukong提升1.9%，在检索任务上较Zero提升2.8%，表明其数据质量优势。消融实验显示，文本熵过滤与视觉去重对性能贡献最大，其中视觉去重通过消除冗余样本提升了模型对长尾概念的捕捉能力。

评估边界方面，论文未报告置信区间，且仅对比中文数据集，缺乏与英文SOTA的公平比较。可复现性上，论文提供了GitHub与HuggingFace链接，但100M数据的完整开源可能受存储限制影响。

## 关联研究分析

从问题动机看，本文与DynamiCS等动态采样方法不同，后者通过平衡高频与低频概念提升数据效率，而本文聚焦于数据时效性与噪声过滤。根源在于中文数据特有的URL失效与语义滞后问题，DynamiCS的采样策略无法解决数据源本身的时效性缺陷。从方法设计看，本文与TIPSv2等细粒度对齐方法存在差异，TIPSv2通过iBOT++提升patch-level对齐，而本文仅优化全局向量对齐。这种差异源于任务特性：中文VLP当前瓶颈在于数据规模与质量，而非密集特征监督，因此本文选择通过数据策展而非架构创新来提升性能。

## 总结

本文要解决的核心矛盾是中文VLP数据时效性滞后与噪声高企导致的性能瓶颈。现有方法如Zero和TaiSu虽规模大，但缺乏2024年后语义覆盖，本文凭借基于Common Crawl 2024-2025数据的四阶段过滤流水线，构建了1亿对高质量中文图文对。实验证明，DanQing在SigLIP2-L/16上实现72.9%零样本分类准确率与84.3%检索平均性能，较Wukong分别提升1.9%和2.7%。其边界在于仅验证了中文域内性能，未与英文SOTA对比，且未量化数据时效性对泛化能力的具体贡献。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
