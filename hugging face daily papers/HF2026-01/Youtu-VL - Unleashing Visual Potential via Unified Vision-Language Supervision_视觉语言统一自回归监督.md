> 统一视觉-语言模型旨在通过单一架构打破视觉理解与生成的任务壁垒，其核心价值在于利用共享表征实现多模态能力的协同增强。现有主流范式将视觉信号视为被动条件输入，优化过程仅由文本自回归目标驱动，导致模型隐式丢弃对粗粒度文本生成冗余的细粒度视觉细节，形成阻碍密集感知能力的信息瓶颈。Youtu-VL 提出 VLUAS 范式，将视觉 Token 纳入预测流作为监督目标，通过混合语义与几何特征的离散化编码，在标准架构内实现无任务头的高精度密集预测。该范式有效缓解了文本主导优化偏差，但在纯理解任务上未显著超越强模块化基线，且保留外部视觉编码器的设计与“原生早期融合”趋势存在张力。

## 研究背景

当视觉信号仅作为条件输入时，模型优化目标与视觉细节保留之间存在根本冲突。自回归语言模型在训练过程中，梯度更新主要服务于文本序列的预测准确性，视觉特征被压缩为服务于文本生成的中间表征。这种“视觉作为输入”的范式下，视觉编码器（如 CLIP、SigLIP）的预训练目标与统一生成需求存在不匹配，其表征对生成任务不友好，导致统一模型需要额外的对齐成本。为了解决这一优化瓶颈，研究者开始探索将视觉信号转化为可预测的离散 Token，使其参与自回归预测过程，从而在优化目标中直接约束视觉细节的保留。

统一视觉-语言模型的核心问题是如何在单一架构中同时最大化细粒度视觉理解精度与高保真视觉生成质量，并解决二者在优化目标上的内在冲突。早期模块化设计（Encoder-Projector-LLM）虽然训练稳定，但受制于模态割裂，生成能力缺失。2024-2025 年，研究重心转向原生早期融合架构，试图通过更深层的像素-词对齐换取细粒度感知潜力，但面临训练成本高、数据需求大的挑战。Youtu-VL 的切入点在于不改变架构拓扑，而是重塑监督信号：通过 VLUAS 范式，将视觉 Token 从“条件”转变为“目标”，在保持模块化架构稳定性的同时，引入密集视觉监督以弥补细粒度感知不足。

## 核心方法

### 统一词表构建与混合 Token 化

Youtu-VL 的核心架构基于 SigLIP-2 视觉编码器、空间合并投影层和 Youtu-LLM。其关键差异在于构建了统一图文词表 $V_{unified}$，将视觉信号离散化为可预测的 Token。设计动机在于解决传统 VLM 中视觉特征与文本 Token 对接粗糙导致的空间推理不足。通过融合 SigLIP-2 的语言对齐语义与 DINOv3 的边界一致几何结构，利用交叉注意力机制生成协同表征 $Z_{syn}$，再经 IBQ 量化为离散码本。该过程避免了纯语义编码的空间粗粒度问题，也规避了纯像素重建的高频噪声捷径，实现了语义与几何的平衡。

$$ Z_{syn} = \text{CrossAttention}(Q_{sem}, K_{geo}, V_{geo}) $$

该公式表示通过语义特征作为查询，几何特征作为键值，在共享流形上进行交叉注意力融合，生成兼具语义与空间结构的协同表征。

### 视觉语言统一自回归监督

VLUAS 范式将训练目标从判别式“视觉作为输入”转变为生成式“视觉作为目标”。设计动机在于消除文本主导优化偏差，强制模型保留细粒度视觉信息。模型优化视觉与语言序列的联合概率，输入端保留连续视觉嵌入以维持信号保真度，输出端引入离散视觉 Token 监督。统一损失函数 $L_{VLUAS}$ 为文本与视觉预测损失的加权和，权重 $\lambda$ 设为 0.5。通过强制 $L_{image}$，模型在预测文本的同时必须重建视觉细节，从而在优化过程中内化细粒度感知能力。

$$ L_{VLUAS} = L_{text} + \lambda L_{image} $$

该公式表示模型同时最小化文本 Token 和视觉 Token 的交叉熵损失，$\lambda$ 平衡两种模态的梯度贡献，确保视觉细节不被文本生成目标淹没。

### 多标签自回归密集预测

针对密集预测任务（如分割、深度），Youtu-VL 提出 NTP-M 损失。设计动机在于解决单标签 NTP 无法处理多语义标签及任务目标的问题。NTP-M 将单标签分类扩展为多标签框架，构建多热目标向量，独立建模词汇表中每个 Token 的伯努利概率。为应对词汇表巨大导致的类别不平衡，采用正负样本独立平均与相关负采样策略，仅对 Top-k 相关负样本计算平均损失，防止梯度稀释。该机制使标准 VLM 无需辅助解码器即可直接从原始 Logits 获得高质量密集预测。

$$ L_{NTP-M} = -\frac{1}{|P_i|} \sum_{j \in P_i} \log \sigma(z_{i,j}) - \frac{1}{|N_i^{rel}|} \sum_{j \in N_i^{rel}} \log(1 - \sigma(z_{i,j})) $$

该公式表示分别计算正样本和 Top-k 相关负样本的平均损失，通过解耦正负样本处理，确保多标签监督下的稳定收敛。

## 实验评估

Youtu-VL 在 30 个视觉中心任务和 45 个通用多模态基准上进行评估。基线覆盖 Qwen3-VL、InternVL-3.5 等通用 VLM，以及 UFO、GiT 等视觉中心模型，但缺失 MANZANO、NEO 等原生架构直接对比。在密集预测任务上，Youtu-VL 表现突出：ADE20k 语义分割 mIoU 达 54.2，NYUv2 深度估计 $\delta_1$ 达 87.6，接近专用模型 UniDepth-v2 的 88.2。在通用任务上，MMBench_EN 得分 84.5，DocVQA 得分 89.6，ChartQA 得分 89.6，均优于 Qwen3-VL 和 InternVL-3.5。

| 任务类型 | 基准 | Youtu-VL | Qwen3-VL | InternVL-3.5 |
| :--- | :--- | :--- | :--- | :--- |
| 语义分割 | ADE20k | 54.2 | 54.5 | 47.8 |
| 深度估计 | NYUv2 | 87.6 | 93.6 | - |
| 视觉定位 | RefCOCO | 91.8 | 89.4 | 91.6 |
| 文档理解 | DocVQA | 89.6 | 95.3 | 94.4 |
| 图表理解 | ChartQA | 89.6 | 86.0 | 84.6 |

消融实验显示，移除视觉 Token 监督后，PCA 可视化中特征分离度显著下降，证实 VLUAS 对细粒度表征的必要性。NTP-M 中的相关负采样策略对密集预测精度贡献显著，移除后梯度稀释导致收敛不稳定。评估边界方面，论文未报告置信区间，且 DocVQA 超越 SOTA 可能源于特定数据增强或评测协议差异，需进一步核实。代码已开源，但超参数细节（如 $\lambda$ 的敏感性分析）未充分披露。

## 关联研究分析

从问题动机看，Youtu-VL 与 MANZANO 均关注离散视觉 Token 的信息损失，但 MANZANO 侧重架构统一，通过混合分词器消除模态边界；Youtu-VL 侧重监督统一，保留模块化架构但重塑优化目标。差异根源在于任务特性：MANZANO 追求生成与理解的涌现能力，需彻底去中介化；Youtu-VL 追求密集预测的精度，需保留连续输入的保真度。从方法设计看，Youtu-VL 与 NEO 同属原生架构探索，但 NEO 摒弃外部编码器，直接从像素学习；Youtu-VL 保留 SigLIP-2，挑战“去中介化”趋势。这一选择暗示，在密集预测任务中，预训练视觉编码器的语义对齐能力仍具不可替代性，完全原生融合可能牺牲部分感知精度。

## 总结

Youtu-VL 要解决的核心矛盾是文本主导优化偏差导致的细粒度视觉信息丢失。其切入点是 VLUAS 范式，将视觉 Token 从条件输入转变为监督目标，在标准架构内实现密集预测。通过混合语义与几何特征的 Token 化及 NTP-M 多标签损失，Youtu-VL 在 ADE20k 上取得 54.2 mIoU，在 RefCOCO 上取得 91.8% 准确率，证明了统一监督对密集感知的有效性。然而，论文保留 SigLIP-2 视觉编码器，与原生早期融合趋势存在张力，且在纯理解任务上未显著超越强模块化基线。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
