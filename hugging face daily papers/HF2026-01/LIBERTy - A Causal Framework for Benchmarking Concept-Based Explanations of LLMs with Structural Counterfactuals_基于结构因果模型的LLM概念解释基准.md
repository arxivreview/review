> 概念解释的忠实度评估长期受困于缺乏真实因果机制作为参照，导致现有方法无法区分统计关联与因果效应。Abraham et al. (2022) 提出的 CEBaB 虽引入干预数据集，但受限于人工标注成本、短文本场景及简单因果图，无法适配 LLM 的复杂生成过程。LIBERTy 通过显式定义文本生成的结构因果模型（SCM），利用 LLM 作为 SCM 组件自动生成结构反事实，从而构建具有因果对齐的评估基准。该框架解决了评估参考值与数据生成过程（DGP）脱节的问题，但受限于合成数据的分布偏差，其结论在真实世界文本上的泛化性存疑。

## 研究背景

当决策者需要理解 LLM 为何做出特定预测时，仅关注词元级注意力分数往往无法提供可操作的洞察。概念解释（Concept-based Explanations）通过量化性别、经验等高层语义概念对预测的影响，弥合了模型内部机制与人类认知之间的鸿沟。然而，评估这些解释是否“忠实”于真实因果机制，需要知道改变某个概念究竟会如何改变模型输出。在缺乏真实世界因果图的情况下，研究者通常依赖人工编写的反事实文本作为代理，但这引入了标注噪声，且难以保证反事实与原始文本在因果结构上的一致性。

现有评估路线主要依赖 CEBaB 等基准，其核心瓶颈在于反事实生成与 DGP 的割裂。CEBaB 中的反事实由人类标注者独立撰写，而非通过干预数据生成过程产生，导致其作为“黄金标准”时本身存在偏差。此外，CEBaB 局限于餐厅评论等短文本，因果图仅含四个概念且无层级结构，无法反映现实决策中复杂的因果依赖。LIBERTy 的切入点在于将 LLM 嵌入 SCM 框架：LLM 不再是黑盒，而是 SCM 中负责将概念实例化为文本的组件。通过固定外生变量并干预概念，LIBERTy 生成的反事实严格遵循 Pearl 的三步程序，确保了评估参考值与 DGP 的因果对齐。

## 核心方法

### 方法参照系

概念解释评估的标准流程是计算解释分数与真实因果效应的误差。传统方法使用人工反事实估计个体因果概念效应（ICaCE），但人工反事实无法保证与原始文本共享相同的外生噪声（如作者风格、背景语境），导致 ICaCE 估计包含非因果的混淆因素。LIBERTy 的关键差异在于将反事实生成过程形式化为 SCM 中的干预操作，而非独立的人工创作。

### 结构反事实生成

LIBERTy 的核心创新在于将 LLM 定义为 SCM 中的内生变量生成器。设计动机是解决人工反事实无法固定外生变量（Exogenous Variables）的问题，从而消除混淆偏差。在 SCM 中，文本 $x_\epsilon$ 由概念变量 $C$ 和外生噪声 $\epsilon$（包括模板 $\epsilon_{template}$ 和人格 $\epsilon_{persona}$）共同决定。生成反事实时，保持 $\epsilon$ 不变，仅对概念 $C$ 进行干预 $do(C=c')$，并通过 SCM 传播至 LLM 生成新的文本 $\tilde{x}_{\epsilon c'}$。

$$
\text{ICaCE}_f(x_\epsilon, c) = f(\tilde{x}_{\epsilon c'}) - f(x_\epsilon)
$$

该公式表明，由于外生变量 $\epsilon$ 被固定且解码温度设为零，ICaCE 的估计是精确的，无需期望运算。这确保了参考效应完全由概念干预引起，而非文本风格或背景变化。

### 排序忠实度评估

针对解释方法输出尺度不一的问题，LIBERTy 引入排序忠实度（Order-Faithfulness, OF）指标。设计动机是解决误差距离（ED）对尺度敏感、无法公平比较不同归因方法的问题。OF 衡量解释方法对概念重要性排序的保持能力，即若概念 A 的真实因果效应大于概念 B，解释方法是否也赋予 A 更高的分数。

$$
\text{OF}(f, M_f) = \frac{1}{|\mathcal{C}|(|\mathcal{C}|-1)} \sum_{c_1 \neq c_2} \text{sign}(\text{ICaCE}_f(c_1) - \text{ICaCE}_f(c_2); M_f(c_1) - M_f(c_2))
$$

该公式计算所有概念对排序一致的比例。与 ED 关注数值精度不同，OF 关注相对顺序，更适合评估仅提供重要性分数而非直接因果效应估计的方法，如 ConceptSHAP 或线性擦除。

## 实验评估

实验在 LIBERTy 的三个数据集（疾病检测、CV 筛选、职场暴力预测）上进行，评估五个模型（DeBERTa-v3, T5, Qwen-2.5, Llama-3.1, GPT-4o）和八种解释方法。基线覆盖了归因（ConceptSHAP）、擦除（LEACE）、反事实生成（CF Gen）和匹配（FT Match, ST Match, PT Match, ConVecs）四类路线。缺失了知识库中强调的鲁棒性测试基线（如 Slack et al. 的扰动实验），但考虑到本文聚焦因果忠实度而非动态稳健性，这一缺失在任务设定内可接受。

| 方法 | 平均全局 OF (↑) | 平均局部 ED (↓) |
| :--- | :--- | :--- |
| FT Match | 0.85 | 0.30 |
| ConVecs | 0.82 | - |
| Approx | 0.77 | - |
| ST Match | 0.73 | - |
| PT Match | 0.69 | - |
| LEACE | 0.62 | - |
| CF Gen | 0.61 | - |
| ConceptSHAP | 0.41 | - |

FT Match 在全局 OF 上取得 0.85 的最高分，显著优于 ConceptSHAP 的 0.41。局部解释中，FT Match 的 ED 约为 0.30，表明即使最佳方法仍有 30% 的误差空间。这一结果揭示了现有概念解释方法在捕捉因果效应排序上的巨大差距，尤其是基于 Shapley 值的方法在复杂因果图中表现不佳。

消融实验显示，基于数据集特定微调模型表示的匹配方法（FT Match）优于基于预训练模型表示的方法（PT Match, ST Match）。这表明概念解释的忠实度高度依赖于模型对特定领域因果结构的感知能力，而非通用的语言表示。GPT-4o 等专有 LLM 对人口统计学概念（如种族）的敏感性极低，可能源于后训练对齐，这提示了模型对齐与因果忠实度之间的潜在冲突。

评估边界方面，LIBERTy 使用合成数据，其分布可能偏离真实世界文本，导致解释方法在真实数据上的性能未知。代码已开源，但 SCM 的定义依赖于人工设计的因果图，其合理性取决于领域知识的准确性。此外，OF 指标仅评估排序，无法捕捉解释的语义细微差别或数值精度，需结合 ED 综合评估。

## 关联研究分析

从问题动机看，LIBERTy 与 CEBaB 均旨在解决概念解释的因果评估问题，但 CEBaB 依赖人工反事实，而 LIBERTy 依赖 LLM 生成的结构反事实。这一差异的根源在于任务特性：CEBaB 面向短文本情感分析，人工标注成本可控；LIBERTy 面向长文本复杂决策，人工标注不可行。然而，LIBERTy 的“Silver”反事实虽在 SCM 内精确，但 LLM 生成的文本可能引入系统性偏差，导致评估参考值本身不可靠。这与数值反事实解释中 DANCE 等方法强调“数据流形对齐”的共识形成冲突：LIBERTy 确保因果逻辑对齐，但未验证生成文本是否位于真实数据流形的高密度区域。

从方法设计看，LIBERTy 与 ConceptSHAP 同属概念解释框架，但 ConceptSHAP 基于 Shapley 值计算边际贡献，而 LIBERTy 基于 SCM 干预计算因果效应。ConceptSHAP 在 LIBERTy 中表现较差（OF 0.41），表明 Shapley 值在存在中介变量和混杂因素的复杂因果图中可能失效。这与知识库中因果派观点一致：忽略因果结构可能导致解释反映统计关联而非因果机制。LIBERTy 通过显式 SCM 解决了这一问题，但其 SCM 是人工定义的，而非从数据中学习，这限制了其在未知因果结构场景下的适用性。

## 总结

LIBERTy 解决了概念解释评估中缺乏因果参照的核心矛盾，通过显式定义 SCM 并利用 LLM 生成结构反事实，实现了评估参考值与 DGP 的因果对齐。该框架证明了现有方法（如 ConceptSHAP）在复杂因果图中忠实度不足，最佳方法 FT Match 的 OF 仅为 0.85，ED 为 0.30，表明仍有显著改进空间。其边界在于依赖人工定义的 SCM 和合成数据，未验证在真实世界文本或未知因果结构下的性能。当 SCM 中的因果边存在遗漏或错误时，LIBERTy 生成的反事实是否仍能作为可靠的评估基准，论文未给出回答。
