# HuggingFace最新推荐论文 ｜InfiniteVGGT: Visual Geometry Grounded Transformer for Endless Streams ｜无限流式视觉几何重建

研究机构：上海交通大学

论文原文见 [arXiv](https://arxiv.org/abs/2601.02281)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.02281)

> 在线三维重建面临内存无限增长与长序列几何漂移的双重困境，现有流式架构要么累积全部历史导致显存溢出，要么压缩为隐式状态造成信息丢失。InfiniteVGGT 基于 Key 余弦相似度实现无训练、有界的滚动记忆机制，在约 10,000 帧的连续序列上维持了稳定的几何一致性。该方法以极低的计算开销解决了流式重建的扩展性瓶颈，但其对静态场景的强依赖及单一骨干的局限性，使其在动态复杂环境下的泛化能力存疑。

## 研究背景

在线三维重建要求模型在接收图像流的同时即时输出几何结构，这依赖于 Transformer 架构中的键值缓存（KV Cache）来存储历史帧的上下文信息。然而，随着序列长度增加，KV Cache 呈线性增长，导致显存占用迅速突破硬件极限。为应对此问题，现有流式方法通常采用因果注意力机制，但如何在有界内存下保留关键历史信息以维持长期几何一致性，仍是该领域的核心难题。

传统离线方法如 VGGT 虽能实现高精度重建，但其批量处理特性无法适应实时流式场景。流式架构如 StreamVGGT 通过因果注意力处理无限序列，但其 KV Cache 无限增长导致内存溢出；而 CUT3R 和 TTT3R 采用隐式状态压缩，虽保证资源有界，却因丢弃关键历史信息而加剧长序列漂移。InfiniteVGGT 的切入点在于识别连续相机轨迹中 Token 级别的冗余性，通过显式但动态更新的滚动记忆机制，在避免内存溢出的同时缓解信息丢失，从而实现真正无限时程的稳定重建。

## 核心方法

### 方法参照系

本文基于 StreamVGGT 的因果注意力架构，其标准流程是将全局交互替换为因果时序注意力，通过累积所有历史帧的 KV Cache 来预测当前帧的三维几何。本文的关键差异在于引入了一种无需训练、与 FlashAttention 兼容的 Token 剪枝策略，将无限增长的显式缓存转化为有界的滚动记忆。

### 基于 Key 多样性的 Token 保留

传统剪枝方法依赖注意力权重评估 Token 重要性，但这要求显式计算 $O(N^2)$ 的注意力矩阵，与 FlashAttention 避免物化矩阵的高效机制相冲突。InfiniteVGGT 改用 Key 向量的余弦相似度作为冗余度代理，在注意力计算前识别并丢弃冗余 Token。对于第 $l$ 层第 $h$ 头的候选 Key 集合 $K_{t,cand}^{[l,h]}$，首先计算 L2 归一化后的均值向量 $\mu^{[l,h]}$，然后定义每个 Key $\hat{k}_i$ 的多样性得分：

$$ s_{div}(\hat{k}_i) = - \cos(\hat{k}_i, \mu^{[l,h]}) $$

该公式表明，与全局均值方向差异最大的 Key 被视为最具信息量，从而被优先保留。这一设计解决了注意力权重剪枝与硬件优化内核的兼容性冲突，使得在保持 FlashAttention 推理速度的同时，能够智能地缩减缓存规模。

### 分层自适应预算分配

不同层级的 Token 冗余度存在显著差异，浅层关注空间细节而深层趋向语义收敛。InfiniteVGGT 引入分层自适应预算机制，根据每层的平均多样性得分动态分配存储预算。第 $l$ 层的预算比例 $p_{bud}^{[l]}$ 通过 Softmax 归一化计算：

$$ p_{bud}^{[l]} = \frac{\exp(s_{div}^{[l]} / \tau)}{\sum_{j=1}^{L} \exp(s_{div}^{[j]} / \tau)} $$

其中 $s_{div}^{[l]}$ 为该层所有 Token 多样性得分的均值，$\tau$ 为温度超参数。最终，每层每头保留的 Token 数量 $B^{[l,h]}$ 由总预算 $B_{total}$ 按此比例分配，并通过 TopK 选择执行。此外，首帧 Token 被设为不可变锚点，以确保全局坐标系的稳定性。这种分层策略避免了统一预算导致的浅层信息丢失或深层冗余堆积，实现了内存效率与几何精度的平衡。

## 实验评估

实验在 7-Scenes、NRGBD、Bonn 及新提出的 Long3D 基准上进行，对比基线包括 CUT3R、TTT3R、Point3R 及 StreamVGGT。在 7-Scenes 500 帧输入下，InfiniteVGGT 的 Chamfer Distance (CD) 为 0.043，优于 TTT3R 的 0.062 和 CUT3R 的 0.063；在 Long3D 9545 帧序列中，其 CD 为 5.733，显著低于 TTT3R 的 7.710 和 CUT3R 的 8.062。

| 数据集 | 输入帧数 | 方法 | CD ↓ | NC ↑ |
| :--- | :--- | :--- | :--- | :--- |
| 7-Scenes | 500 | InfiniteVGGT | 0.043 | 0.561 |
| 7-Scenes | 500 | TTT3R | 0.062 | 0.552 |
| 7-Scenes | 500 | CUT3R | 0.063 | 0.555 |
| Long3D | 9545 | InfiniteVGGT | 5.733 | 0.513 |
| Long3D | 9545 | TTT3R | 7.710 | 0.519 |
| Long3D | 9545 | CUT3R | 8.062 | 0.496 |

消融实验显示，基于 Key 余弦相似度的剪枝策略比基于注意力权重的方法在 CD 上降低 0.004（0.032 vs 0.036），且推理时间从 0.288 秒降至 0.168 秒，峰值显存从 17.30 GB 降至 14.49 GB。初始预算 $B^{[l,h]}$ 从 10000 增至 50000 时，CD 从 0.032 降至 0.032（500 帧输入下趋于饱和），表明过大的预算对精度提升有限。分层分配机制相比统一预算，在 500 帧输入下将 Acc 从 0.098 降至 0.093，NC 从 0.554 提升至 0.555。锚点帧机制的移除导致 Acc 从 0.040 恶化至 0.047，验证了首帧作为全局参考的必要性。

评估边界方面，Long3D 基准使用 ICP 对齐点云，可能掩盖全局漂移；实验仅在单张 A100 GPU 上进行，未报告多卡扩展性；代码已开源，但超参数 $\tau$ 和 $B_{total}$ 的敏感性分析未详细展开。

## 关联研究分析

从问题动机看，InfiniteVGGT 与 Scal3R 均关注大规模场景的扩展性，但 Scal3R 采用测试时训练（TTA）框架通过全局优化整合局部预测，计算开销大且依赖额外优化步骤；InfiniteVGGT 则通过纯前馈的滚动记忆实现有界内存，无需 TTA，更适合实时流式场景。两者的差异根源在于对“全局一致性”的实现路径不同：Scal3R 依赖离线式的后处理优化，而 InfiniteVGGT 依赖在线式的动态记忆管理。

从方法设计看，InfiniteVGGT 与 FastVGGT 均利用注意力冗余进行加速，但 FastVGGT 针对离线批量处理，通过 Token 合并减少计算量；InfiniteVGGT 针对在线流式处理，通过 Token 剪枝减少内存占用。FastVGGT 的加速依赖于对完整注意力矩阵的访问，而 InfiniteVGGT 的剪枝必须避免物化矩阵以兼容 FlashAttention。这一差异揭示了离线加速与在线内存优化在底层硬件约束上的根本不同：前者追求计算效率，后者追求存储效率。

## 总结

InfiniteVGGT 旨在解决在线三维重建中内存无限增长与长序列几何漂移的矛盾。现有流式方法或因累积全部历史导致显存溢出，或因压缩为隐式状态导致信息丢失，无法兼顾扩展性与稳定性。InfiniteVGGT 通过基于 Key 余弦相似度的滚动记忆机制，在无需训练的情况下实现了有界内存下的无限时程重建。在 Long3D 9545 帧序列上，其 CD 为 5.733，显著优于 TTT3R 的 7.710，验证了其在长序列稳定性上的优势。然而，该方法依赖 VGGT 骨干对首帧坐标系的刚性对齐，且实验仅覆盖静态室内场景，未涉及动态物体或非刚性形变。当场景中存在显著动态干扰或相机轨迹发生剧烈变化时，基于 Key 相似度的冗余假设是否依然成立，论文未给出回答。
