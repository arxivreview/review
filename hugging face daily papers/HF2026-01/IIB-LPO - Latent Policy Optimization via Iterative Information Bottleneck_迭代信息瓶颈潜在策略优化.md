> 导读 RLVR 训练常因随机采样轨迹的语义同质性导致探索坍缩，模型陷入少数高概率推理模板，丧失发现新解法的能力。现有熵正则化方法易引发无意义冗余，而 Token 级选择性更新难以克服预训练模型的强归纳偏置，两者均局限于概率扰动，无法实现推理结构的多样化。本文提出 I²B-LPO，通过在高熵状态触发潜在变量分支重构推理拓扑，并利用信息瓶颈作为双重过滤器与自奖励，在保持简洁性的同时实现结构化探索。该方法在中等难度数学任务上显著提升了精度与多样性，但在高难度竞赛数学上的表现仍落后于步骤级信用分配方法，其潜在分支机制在极端难度下的探索效率存疑。

## 研究背景

当 LLM 在 RLVR 框架下进行多轮推理时，随机生成的轨迹往往在表面措辞上存在差异，但底层逻辑迅速退化为少数高概率推理模板。这种语义同质性导致组内相对优势估计趋近于零，策略梯度信号失效，模型陷入局部最优。为打破这一僵局，策略熵被引入作为探索引导信号，旨在量化词汇分布的离散度以反映预测不确定性。然而，熵信号本身具有双重性：它既标记了关键决策点，也包含了大量由词汇歧义引起的噪声，如何区分并利用这两种熵来源，是解决探索坍缩的核心难点。

主流解决方案分为两类：全局熵正则化与 Token 级选择性更新。前者通过平滑整个词汇分布来最大化熵，但极易诱发奖励黑客，导致模型生成大量与解题无关的元话语冗余；后者聚焦于高熵 Token 进行局部锐化，却难以对抗预训练模型中根深蒂固的归纳偏置，因为高熵位置往往对应同义词选择等词汇歧义，而非真正的逻辑分叉。这两种范式均停留在统计层面的概率扰动，缺乏诱导推理过程结构性多样化的能力。本文的切入点在于将探索机制从“统计扰动”转向“拓扑分叉”，即通过潜在空间干预直接改变推理轨迹的结构，而非仅调整 Token 概率分布。

## 核心方法

### 方法参照系

本文基于 GRPO 框架，但摒弃了传统的优势函数直接优化路径。与标准 GRPO 依赖组内相对奖励计算优势不同，I²B-LPO 引入了两个前置阶段：熵驱动的潜在分支扩展与信息瓶颈剪枝。其核心差异在于，它不直接修改优势估计公式，而是通过重构训练数据池（即推理轨迹集合）来间接影响策略更新，将探索多样性问题转化为轨迹筛选与生成问题。

### 熵驱动潜在分支

传统方法在高熵位置仅调整 Token 权重，无法改变后续推理的逻辑走向。本文在高熵状态触发潜在分支，利用条件变分自编码器（CVAE）采样潜在变量 $z_i$，并将其注入 LLM 的注意力层以引导后续推理。具体而言，首先计算 Token 级熵 $H_t = -\sum_{v \in V} p(v|o_{<t}, q) \log p(v|o_{<t}, q)$，选取前 5% 高熵步骤作为分叉点。随后，CVAE 基于前缀上下文 $c_{t^*}$ 采样 $K$ 个独立潜在码 $z_i \sim p(z|c_{t^*})$。这些潜在码通过伪自注意力（PSA）机制注入模型，公式为：

$$ \text{Attention}(Q, K, V, z) = \text{softmax}\left(\frac{Q(K^T \oplus z^T)}{\sqrt{d}}\right)(V \oplus z) $$

其中 $\oplus$ 表示行级拼接。这一设计动机在于，潜在变量 $z_i$ 作为结构提示，能够持续重塑后续 Token 的分布，从而在逻辑层面（如微分法 vs 几何法）产生实质性分叉，而非仅在词汇层面产生同义替换。

### 信息瓶颈双重机制

潜在分支生成的轨迹池包含大量冗余或低质量路径，直接用于训练会引入噪声。本文引入信息瓶颈（IB）作为双重机制：既是轨迹过滤器，又是自奖励。IB 分数 $S_{IB}(r)$ 定义为：

$$ S_{IB}(r) \approx \frac{1}{T} \sum_{t=1}^T \left( H(o_t|o_{<t}, q) + A_t \right) $$

该公式量化了推理链的压缩性与预测力之间的权衡。高 $S_{IB}$ 值表示轨迹既简洁（低冗余）又信息丰富（高优势）。在训练前，系统保留 Top-N 高 $S_{IB}$ 轨迹作为训练集；在训练中，将 $S_{IB}$ 作为辅助最大化目标加入损失函数。这一设计解决了熵正则化方法中“高熵即好”的误区，通过惩罚语义空洞的冗长推理，实现了探索多样性与推理简洁性的平衡。

## 实验评估

实验在 Qwen2.5-7B 和 Qwen3-14B 骨干上，使用 MATH-500、AIME24/25 和 OlympiadBench 进行评估。基线覆盖了熵正则化（Entropy-Reg）、Token 选择性（KL-Cov, 80/20）及自奖励（SPINE, SRLM）三类方法，但缺失了步骤级信用分配方法（如 SSVPO）的对比，这可能影响对高难度任务性能的全面评估。

| 方法 | AIME25 P@1 (%) | MATH-500 P@1 (%) | OlympiadBench P@1 (%) |
| :--- | :--- | :--- | :--- |
| GRPO (Standard) | 8.2 | 54.4 | 44.9 |
| Entropy-Reg | 9.3 | 57.4 | 48.9 |
| KL-Cov | 11.3 | 68.2 | 53.0 |
| I²B-LPO (Ours) | 13.6 | 81.5 | 58.0 |

I²B-LPO 在所有基准上均取得最高精度，尤其在 MATH-500 上较 GRPO 基线提升 27.1 个百分点。值得注意的是，其平均响应长度（#Tok）显著低于熵正则化方法，验证了 IB 机制在抑制冗余方面的有效性。

| 组件 | MATH P@1 (%) | Dist-4 | PPL |
| :--- | :--- | :--- | :--- |
| GRPO Baseline | 54.4 | 0.40 | 17.6 |
| w/o Latent Injection | 59.7 | 0.64 | 18.4 |
| + PSA Fusion | 66.7 | 0.78 | 19.5 |
| + IB Pruning | 79.6 | 0.80 | 15.6 |
| I²B-LPO (Full) | 81.5 | 0.82 | 13.1 |

消融实验显示，潜在注入（PSA Fusion）贡献了主要精度提升，而 IB 剪枝进一步将 MATH P@1 从 79.6% 提升至 81.5%，并显著降低困惑度（PPL）至 13.1。这表明 IB 机制不仅筛选了高质量轨迹，还通过自奖励强化了模型的简洁推理能力。然而，IB 剪枝对 AIME25 的提升幅度（+1.1%）远小于 MATH（+14.8%），暗示其在高难度任务上的筛选效率可能受限。

评估协议采用 Pass@n 和多样性指标（Distinct-n, Self-BLEU），但未报告置信区间，且缺乏跨骨干网络的统一对比。代码已开源，但超参数敏感性分析显示，分支因子 $K=7$ 和最大响应长度 8192 为最优设置，偏离该设置会导致性能显著下降，表明方法对超参数较为敏感。

## 关联研究分析

从问题动机看，I²B-LPO 与 Latent-GRPO 同属潜在推理扩展路线，但两者解决的核心矛盾不同。Latent-GRPO 聚焦于潜在空间中的探索-优化错位，通过无效样本掩码防止轨迹偏离流形，侧重训练稳定性；而 I²B-LPO 聚焦于语义同质性导致的探索坍缩，通过主动拓扑分支增加轨迹多样性，侧重探索上限。这种差异源于任务特性：Latent-GRPO 处理的是连续表示中的噪声问题，而 I²B-LPO 处理的是离散推理路径中的模板化问题。I²B-LPO 的潜在分支机制是否在高难度任务上因分支数量有限而难以覆盖所有可能的解法空间，论文未给出回答。

从方法设计看，I²B-LPO 与 SSVPO 代表了细粒度信号重构的两种不同路径。SSVPO 通过显式的步骤级信用分配，将最终奖励公平分解至每个推理步骤，直接优化中间步骤的贡献；而 I²B-LPO 通过隐式的 IB 分数筛选，间接激励简洁且信息丰富的推理路径。SSVPO 在 AIME25 上达到 82.0%，远高于 I²B-LPO 的 13.6%，这一巨大差距暗示，在高难度竞赛数学中，显式的步骤级监督比隐式的轨迹筛选更具优势。I²B-LPO 的 IB 机制是否因缺乏对具体错误步骤的针对性惩罚，而在复杂逻辑链中失效，值得进一步探究。

## 总结

I²B-LPO 旨在解决 RLVR 中因轨迹语义同质性导致的探索坍缩问题。现有熵正则化方法易引发冗余，Token 级更新难以克服归纳偏置，本文通过潜在变量分支重构推理拓扑，并利用信息瓶颈作为双重过滤器与自奖励，实现了结构化探索与简洁推理的平衡。实验表明，该方法在 MATH-500 上达到 81.5% 的 Pass@1，较基线提升显著，且有效抑制了响应长度增长。然而，其在 AIME25 上仅达 13.6%，远低于步骤级方法 SSVPO 的 82.0%，暴露了潜在分支机制在高难度任务上的探索效率瓶颈。当推理链长度增加且逻辑分叉点增多时，固定数量的潜在分支是否足以覆盖所有关键决策路径，论文未给出回答。
