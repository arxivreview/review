研究机构：新加坡国立大学

论文原文见 [arXiv](https://arxiv.org/abs/2601.21598)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.21598)

> 潜在推理旨在用连续向量替代离散文本以压缩推理链，但现有方法通过模仿单一语言标签训练，导致模型过拟合特定路径，在测试时泛化能力受限。本文指出，由于同一问题存在多种等价推理路径，被动模仿任意一条都会引入策略偏差。ATP-Latent 通过变分自编码器（VAE）平滑潜在空间，并引入基于解码一致性的强化学习（RL）奖励，实现从被动模仿到主动规划的转变。该方法在 LLaMA-1B 上提升了准确率并减少了 Token 消耗，但其绝对性能仍远低于显式推理，且依赖小模型验证，大规模适用性存疑。

## 研究背景

当大语言模型（LLM）执行数学推理时，自回归生成的思维链（Chain-of-Thought, CoT）往往冗长且包含大量仅用于语义衔接的冗余 Token。为降低延迟，潜在推理方法将推理过程映射至连续潜在空间，用高维向量（latent tokens）替代离散文本，从而提升单位 Token 的信息密度。然而，潜在空间并非天然存在，需通过监督信号构建。现有主流方法采用模仿学习策略，将语言 CoT 的中间步骤逐步替换为潜在 Token，通过课程学习或自蒸馏让模型学会“用向量思考”。这种被动模仿机制隐含一个假设：存在唯一的“正确”推理路径。

这一假设在复杂推理任务中失效。对于同一数学问题，往往存在多条逻辑等价但表述不同的正确 CoT。若模型仅模仿其中一条，其潜在表示将过拟合该特定路径的语义特征，导致训练与测试分布出现显著偏差。此外，确定性预测的潜在 Token 缺乏随机性，使得后续强化学习难以在平滑的状态空间中进行有效探索。Coconut 等早期方法虽引入高斯噪声进行探索，但缺乏对潜在空间结构的约束，导致 RL 训练不稳定。本文的切入点在于：将潜在推理的训练过程重构为变分自编码器（Variational Auto-Encoder, VAE）建模，并通过引入无监督的一致性奖励，引导 RL 在平滑且可解释的潜在空间中主动寻找最优策略。

## 核心方法

### 方法参照系

现有潜在推理方法（如 Coconut, SIM-CoT）的标准流程是：SFT 阶段通过课程学习将语言 Token 替换为确定性潜在 Token，RL 阶段（若有）通常仅基于答案正确性进行优化。本文的关键差异在于，SFT 阶段不再追求确定性映射，而是建模潜在 Token 的概率分布；RL 阶段不仅关注答案正确性，还引入基于 VAE 解码内容一致性的辅助奖励，以约束状态空间。

### VAE 建模与停止机制

设计动机：确定性潜在 Token 导致表示空间过锐，限制了 RL 的探索能力，且不同步骤的信息密度不均。ATP-Latent 在 SFT 阶段引入 VAE 结构，将潜在 Token 建模为高斯分布 $\mathcal{N}(\boldsymbol{\mu}_t, \boldsymbol{\sigma}_t^2)$，其中 $\boldsymbol{\mu}_t$ 和 $\boldsymbol{\sigma}_t$ 由 MLP 头预测。

$$
\mathcal{L}_{SFT} = \mathcal{L}_{CE}^{enc} + \mathcal{L}_{CE}^{dec} + \beta \mathcal{L}_{KL} + \mathcal{L}_{Stop}
$$

该损失函数包含编码器交叉熵、解码器交叉熵、KL 散度正则项及停止头二元交叉熵。KL 项通过 $\beta$-VAE 技术（$\beta$ 设为极小值 $10^{-3d}$）平滑潜在空间，防止过拟合；停止头（Stop Head）动态决定何时结束潜在推理，确保每个潜在 Token 编码的信息量均匀，避免固定长度带来的信息密度失衡。解码器使用另一个 LLM 将潜在 Token 还原为语言步骤，提供可解释性并作为后续 RL 奖励的计算基础。

### 基于一致性的强化学习

设计动机：仅基于答案正确性的奖励信号稀疏且噪声大，难以引导模型在平滑潜在空间中收敛到通用策略。ATP-Latent 在 RL 阶段引入 Coherence 奖励，计算 VAE 解码出的语言步骤与原始标签的一致性。

$$
R = R_{Acc} + \lambda R_{Coh}
$$

其中 $R_{Acc}$ 为答案正确性奖励，$R_{Coh}$ 为一致性奖励，定义为解码内容与参考标签的匹配程度。该奖励提供了无监督的软约束，引导模型生成逻辑连贯的潜在推理路径，而非仅仅追求最终答案正确。通过 GRPO 框架优化策略，模型在平滑的 VAE 空间中主动探索，避免了确定性模仿导致的策略偏差。

## 实验评估

实验基于 LLaMA-3.2-1B-Instruct 模型，在 GSM8K、GSM-Hard、MultiArith 和 SVAMP 四个数学推理基准上进行评估。基线包括 Coconut 和 SIM-CoT 的重实现及原始报告结果。

| 方法 | GSM8K Acc (%) | GSM-Hard Acc (%) | MultiArith Acc (%) | SVAMP Acc (%) | Avg #Token |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Coconut | - | - | - | - | - |
| SIM-CoT | - | - | - | - | - |
| ATP-Latent | 47.7 | - | 94.4 | - | 8.4 |

*注：表格中部分数值因输入材料未提供具体单元格数值而留空，仅呈现可逐字定位的关键指标。ATP-Latent 在 GSM8K 上取得 47.7% 准确率，MultiArith 上达 94.4%，平均 Token 数为 8.4。*

消融实验表明，移除 VAE 结构导致平均准确率下降 0.5%，移除停止头下降 0.8%，而移除 RL 阶段导致最大降幅 1.9%。仅使用 Coherence 奖励（无答案正确性）仍能提升 SFT 模型 0.9% 的准确率，验证了一致性作为无监督信号的有效性。在 GSM8K 上，Coherence 奖励在 RL 前 800 步内显著提升了性能，且正确样本的平均归一化一致性为 0.26，错误样本为 -0.33，显示该奖励与答案正确性高度相关。

评估边界方面，实验仅在 1B 参数规模模型上进行，未验证 7B 及以上模型的迁移性。指标仅包含准确率与 Token 数，缺乏延迟、显存占用等系统级效率指标。代码已开源，但超参数（如 $\beta$ 值、噪声方差）的敏感性分析未在正文中详细展开，可复现性依赖附录细节。

## 关联研究分析

从问题动机看，ATP-Latent 与 SIM-CoT 均关注潜在推理的可解释性，但 SIM-CoT 依赖确定性解码，导致潜在空间过锐，RL 探索受限；ATP-Latent 通过 VAE 引入随机性，使 RL 能在平滑空间中有效搜索。这一差异源于对“潜在空间结构”的不同理解：SIM-CoT 视其为精确映射，ATP-Latent 视其为概率分布。从方法设计看，ATP-Latent 与 Coconut 共享课程学习框架，但 Coconut 的 RL 阶段缺乏结构约束，导致训练不稳定；ATP-Latent 的 Coherence 奖励提供了软约束，弥补了这一缺陷。然而，Coherence 奖励依赖 VAE 解码质量，若解码器性能不足，奖励信号可能失真，这一风险在论文中未充分讨论。

## 总结

ATP-Latent 针对潜在推理中模仿单一标签导致的泛化瓶颈，通过 VAE 平滑潜在空间并引入基于解码一致性的 RL 奖励，实现了从被动模仿到主动规划的转变。在 LLaMA-1B 上，该方法相比 SIM-CoT 提升了 4.1% 的准确率并减少了 3.3% 的 Token 消耗，验证了主动规划在提升推理效率与准确性上的有效性。然而，实验局限于小模型，且 Coherence 奖励的有效性依赖于 VAE 解码质量，其在大规模模型或复杂任务上的鲁棒性尚未验证。当潜在空间维度增加或任务复杂度提升时，Coherence 奖励是否仍能作为有效的无监督信号，论文未给出回答。
