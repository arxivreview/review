# HuggingFace最新推荐论文 ｜PersonalAlign: Hierarchical Implicit Intent Alignment for Personalized GUI Agent with Long-Term User-Centric Records ｜层级隐式意图对齐

研究机构：哈尔滨工业大学、美团

作者：Yibo Lyu、Gongwei Chen、Rui Shao 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.09636)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.09636)

> 现有GUI智能体在模拟环境中执行完整指令时表现良好，但真实日常交互中用户指令常省略偏好细节或完全缺失，导致智能体无法补全意图或主动预测例行行为。本文提出PersonalAlign任务，要求智能体利用长程用户记录进行层级意图对齐，并构建AndroidIntent基准与HIM-Agent记忆框架。实验表明HIM-Agent在模糊指令执行与主动建议上均优于基线，但其评估局限于自建数据集，缺乏跨平台泛化验证。

## 研究背景

GUI智能体执行动作依赖于对指令的精确解析，当指令包含“最近的麦当劳”等模糊指代时，智能体需从历史交互中提取用户偏好以消歧。这一过程涉及隐式意图（Implicit Intent）的推断，即用户未显式表达但基于长期习惯可预测的决策逻辑。若智能体仅依赖当前屏幕状态与即时指令，缺乏长程记忆机制，则无法区分一次性行为与稳定偏好，导致执行轨迹偏离用户真实意图。

主流GUI智能体研究聚焦于视觉定位精度与长程任务成功率，假设指令是完整且明确的。AndroidWorld等基准验证了强化学习在动态环境中的纠错能力，但均未涉及用户个性化建模。现有记忆机制如Memory OS多用于对话压缩，缺乏针对GUI执行轨迹的结构化组织。本文切入点在于将个性化从“对话摘要”转向“执行轨迹对齐”，指出模糊指令导致的细粒度执行失败（CER下降45%）是现有方法未覆盖的盲区，需通过层级记忆区分偏好与例行意图。

## 核心方法

### 方法参照系

本文问题属于长程记忆与个性化对齐范畴，但区别于标准检索增强生成（RAG）流程。通用RAG依赖语义相似度检索历史片段，而GUI交互包含动作轨迹与状态信息，单纯语义匹配无法捕捉执行一致性。本文核心差异在于引入执行轨迹一致性度量与状态熵过滤，将记忆从“文本片段”升级为“行为原型”。

### 流式聚合与执行偏好过滤

针对原始GUI记录碎片化且噪声大的问题，HIM-Agent引入流式聚合模块（Streaming Aggregation Module），以日粒度增量更新记录原型 $P_i$。设计动机是解决静态日志存储导致的记忆漂移，使偏好表示随用户行为演化。聚合一致性 $S_{consist}$ 由语义相似度 $S_{sim}$ 与动作一致性 $S_{action}$ 联合计算：

$$ S_{consist} = \alpha S_{sim} + (1-\alpha) S_{action} $$

其中 $S_{sim}$ 结合稠密嵌入余弦相似度与稀疏Jaccard相似度，以缓解短指令实体偏差；$S_{action}$ 采用动态时间规整（DTW）度量轨迹对齐，确保动作序列的结构一致性。该设计使偏好记忆不仅匹配“说什么”，更匹配“怎么做”，解决了语义相似但执行路径不同的误匹配问题。

### 状态例行过滤与主动置信度

在偏好原型基础上，状态例行过滤器（State-based Routine Filter）进一步分离主动意图。设计动机是区分被动偏好（需指令触发）与主动例行（需状态触发），避免过度主动导致的误报。主动置信度 $\Phi(P_i)$ 综合状态稳定性 $H_{state}$、记录长度 $L_{record}$ 与聚合权重 $R_{consist}$：

$$ \Phi(P_i) = f(H_{state}, L_{record}, R_{consist}) $$

其中 $H_{state}$ 为时间与场景偏移的归一化熵，低熵值表示高状态一致性。当 $\Phi(P_i)$ 超过阈值时，原型存入例行意图记忆。该机制通过量化状态稳定性，解决了现有方法在主动建议中“要么过激、要么沉默”的二元困境，实现了基于状态分布的精细化触发。

## 实验评估

实验在自建AndroidIntent基准上进行，包含775个偏好意图与215个例行意图，源自20k长程记录。基线覆盖检索式（Recent Retrieve）与归纳式（LLM-UM），但未包含知识库中提到的强化学习类基线（如UI-S1），可能低估了在线学习在动态环境中的潜力。

| 方法 | Type | SSR | CER |
| :--- | :--- | :--- | :--- |
| Base (Qwen3-VL) | 46.6 | 20.6 | 26.6 |
| Recent Retrieve | 49.4 | 21.1 | 33.2 |
| LLM-UM | 51.2 | 22.3 | 35.2 |
| HIM-Agent | 52.0 | 24.0 | 42.3 |

HIM-Agent在CER上较基线提升9.1%，表明执行轨迹一致性对模糊指令消歧至关重要。消融实验显示，移除执行偏好过滤器导致CER下降9.1%，验证了DTW动作度量的必要性；移除状态过滤器使误报率升至70%，证明状态熵对主动建议精度的关键作用。

评估边界方面，CER指标仅针对模糊指令设计，对明确指令的区分度未验证；AndroidIntent基于Fingertip20K数据，缺乏跨OS泛化测试；代码已开源，但超参数（如DTW窗口大小）未详细披露，可复现性依赖默认配置。

## 关联研究分析

从问题动机看，本文与FingerTip（Yang et al., 2025b）均关注历史交互个性化，但FingerTip仅利用短期动作序列，而本文通过流式聚合扩展至长程记录，并引入层级结构区分偏好与例行。这一差异源于任务目标不同：FingerTip侧重执行效率，本文侧重意图对齐的完整性。然而，本文未探索短期记忆与长期记忆的协同机制，可能在快速变化的用户习惯面前响应滞后。

从方法设计看，HIM-Agent与Memory OS（Kang et al., 2025）均采用多时间尺度记忆，但Memory OS依赖对话分段与语义检索，而本文引入执行轨迹DTW度量。这一差异反映了GUI任务对动作结构敏感性的要求，但本文未对比纯语义检索在特定场景下的表现，执行轨迹权重是否在所有应用类型中均最优，论文未给出回答。

## 总结

本文核心矛盾在于GUI智能体在模糊指令下的意图缺失与主动建议的误报率平衡。现有方法因缺乏长程执行轨迹记忆，无法区分稳定偏好与一次性行为，导致细粒度执行失败。本文通过HIM-Agent的流式聚合与状态过滤，将记忆从语义片段升级为行为原型，在AndroidIntent上实现CER 42.3与误报率49%的平衡。其边界在于评估局限于自建数据集，且未验证执行轨迹度量在非GUI任务中的泛化性。当用户习惯发生剧烈变化时，流式聚合的增量更新能否及时捕捉新偏好模式，而未被旧原型主导，论文未给出回答。
