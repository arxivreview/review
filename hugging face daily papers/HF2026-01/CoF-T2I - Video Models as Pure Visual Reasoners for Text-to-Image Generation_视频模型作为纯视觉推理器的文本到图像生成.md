# HuggingFace最新推荐论文 ｜CoF-T2I: Video Models as Pure Visual Reasoners for Text-to-Image Generation ｜视频模型作为纯视觉推理器的文本到图像生成

研究机构：北京大学、快手

作者：Chengzhuo Tong、Mingkun Chang、Shenglong Zhang 等 15 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.10061)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.10061)

> 文本到图像生成（T2I）在复杂提示遵循上长期受限于单次前向传播的语义错误累积，现有推理时计算范式依赖文本规划或外部验证器，导致像素级修正间接且信息有损。本文切入点在于利用视频生成模型固有的逐帧演化能力，将T2I重构为纯视觉的渐进式修正过程。通过构建三帧推理链并采用独立帧编码，模型在无文本规划下实现从语义布局到美学细节的逐步优化。该范式在GenEval上达到0.86，超越了依赖文本思维链的统一多模态大模型，但固定三帧长度与独立编码对时序依赖的剥离是否限制了更复杂场景的推理深度，仍存疑。

## 研究背景

当T2I模型面对包含多物体组合或属性绑定的复杂提示时，单次生成往往出现语义错位或细节缺失。这种缺陷源于扩散模型在去噪过程中缺乏显式的中间状态监督，导致模型无法在生成中途纠正早期布局错误。为解决此问题，推理时计算（Inference-time Reasoning）范式被引入，其核心是通过多步迭代提升生成质量。主流实现路径包括为图像模型配备外部多模态验证器，或在统一多模态大语言模型（MLLMs）中交错文本规划。然而，这些方法存在根本局限：前者依赖视觉与语言模态间的频繁切换，使得像素级修正变得间接且有损；后者缺乏在大规模纯视觉因果有序序列上的预训练，限制了逐帧自我修正的保真度。视频生成模型天然具备建模视觉状态演化的能力，在强时空先验下逐帧细化场景，这使其成为纯视觉推理器的理想候选。但此前视频模型在T2I中的应用受限于缺乏明确的视觉推理起点和可解释的中间状态，导致其潜力未被充分挖掘。本文旨在回答：能否利用视频模型作为纯视觉推理器，引导高质量T2I生成？

## 核心方法

### 方法参照系

本文问题属于推理时计算范式下的T2I生成。标准流程通常采用统一MLLM，通过文本思维链（CoT）生成中间规划步骤，再指导图像生成。本文的关键差异在于摒弃文本规划，转而利用视频骨干的时序生成能力，将推理过程内化为纯视觉的帧序列演化，即Chain-of-Frame (CoF)。

### 视频模型作为纯视觉推理器

传统T2I模型将生成视为从噪声到图像的单一映射，缺乏中间状态的可解释性。本文在视频骨干（Wan2.1）上重新定义T2I过程为结构化细化序列。给定文本提示 $p$，模型生成潜变量序列 $z_{1:3} = \{z_1, z_2, z_3\}$，其中 $z_1$ 代表粗略语义布局，$z_3$ 代表高保真最终图像。模型学习联合概率分布：

$$ p_\theta(z_{1:3} | p) $$

该公式的物理含义是，视频模型通过其序列处理架构，内化了从粗到细的视觉修正逻辑，无需额外的文本反馈信号。仅终端潜变量 $z_3$ 被解码为输出图像，中间帧作为内部推理状态存在。这一设计解决了统一MLLM因缺乏纯视觉因果序列预训练而导致的逐帧修正保真度不足问题，使模型能直接利用时空先验进行像素级迭代纠错。

### 独立帧编码与训练机制

视频VAE的原生时空压缩可能引入运动伪影，如隐式流和动态不一致，这会干扰静态图像的生成质量。为消除这一失效，本文采用逐帧独立编码策略。具体而言，将VAE沿时间轴滑动，确保目标帧始终在仅包含一帧的初始上下文窗口内被压缩。这限制了编码单元为单帧粒度，保留了视觉特征的空间独立性。训练采用标准流匹配目标，模型预测潜变量序列的去噪目标：

$$ \mathcal{L} = \mathbb{E}_{t, x_0, x_1} [ \| v_\theta(x_t, t; y, c) - (x_1 - x_0) \|^2 ] $$

其中 $y$ 为文本条件，$c$ 为视觉条件。该损失函数驱动模型学习从噪声到数据的直线路径，使模型在端到端优化中内化“后帧细化前帧”的生成轨迹。推理时，从高斯噪声开始多步去噪，恢复内化的生成推理，仅解码最终帧。这一机制在保持视频模型时序建模优势的同时，通过独立编码抑制了运动伪影，提升了静态图像生成的保真度。

## 实验评估

实验在GenEval和Imagine-Bench上进行，基线覆盖标准图像模型（SDXL, FLUX.1-dev）和统一MLLM（BAGEL-Think, T2I-R1）。GenEval侧重物体中心提示遵循，Imagine-Bench侧重概念转换与组合推理。

| 模型 | GenEval Overall | Imagine-Bench Overall |
| :--- | :--- | :--- |
| SDXL | 0.55 | 4.970 |
| BAGEL-Think | 0.82 | 6.930 |
| T2I-R1 | 0.79 | 6.780 |
| Wan2.1-T2V-14B | 0.55 | 5.939 |
| **CoF-T2I** | **0.86** | **7.468** |

CoF-T2I在GenEval上以0.86领先，超越BAGEL-Think 0.04，T2I-R1 0.07。在Imagine-Bench上，CoF-T2I达到7.468，较Wan2.1基线提升1.529，尤其在MultiObject类别（7.797 vs 5.383）表现突出，验证了纯视觉推理在复杂组合任务上的优势。

| 方法 | GenEval Overall |
| :--- | :--- |
| Wan2.1 Base | 0.55 |
| Target-only SFT | 0.81 |
| CoF w/o Independent VAE | 0.83 |
| **CoF-T2I** | **0.86** |

消融实验显示，仅使用最终帧监督的Target-only SFT达到0.81，证明中间帧监督贡献了0.05的增益。移除独立VAE编码后分数降至0.83，表明独立编码对消除运动伪影、提升保真度有0.03的边际收益。这证实了CoF轨迹学习与独立编码机制的协同作用，而非单纯依赖更强的目标监督。

评估局限在于仅使用1024x1024分辨率，未报告计算效率指标。代码未开源，仅提供项目页面。GenEval的自动验证标准可能无法完全捕捉美学细微差异，且缺乏跨分辨率或长视频生成场景的对比，限制了结论的泛化性。

## 关联研究分析

从问题动机看，本文与BAGEL-Think和T2I-R1均旨在解决T2I中的语义错误，但路线截然不同。BAGEL-Think依赖统一MLLM的文本CoT，T2I-R1采用强化学习后训练，而本文利用视频模型的时序先验进行纯视觉推理。差异根源在于任务特性：T2I的像素级修正需要高频细节的逐步优化，文本规划在模态转换中损失信息，而视频模型的逐帧演化天然适配这种渐进式细化。本文证明了在无需文本中介的情况下，视觉时序模型能更直接地执行像素级纠错。

从方法设计看，本文与Wan2.1等视频生成模型同属时序建模框架，但应用目标不同。Wan2.1用于视频内容合成，强调时空一致性；本文将其改造为T2I推理器，通过独立帧编码剥离时序依赖，仅保留帧间细化逻辑。这一改造牺牲了视频模型的部分时序建模优势，换取了静态图像生成的保真度。独立编码是否完全消除了时序伪影，还是仅缓解了部分问题，论文未提供细粒度的伪影类型分析，这限制了该方法在动态内容生成中的适用性判断。

## 总结

本文核心矛盾在于T2I生成中语义错误与美学细节的耦合优化难题，现有文本规划路线因模态切换导致像素修正有损。本文抓住视频模型固有的逐帧演化能力，将其重构为纯视觉推理器，通过CoF轨迹和独立帧编码实现无文本规划的渐进式修正。实验证明CoF-T2I在GenEval达到0.86，超越文本CoT基线，验证了纯视觉推理的有效性。其边界在于固定三帧长度限制了推理深度，且独立编码可能削弱时序建模的完整性。当提示复杂度进一步增加，需要更多中间状态时，三帧CoF是否足以捕捉所有语义修正步骤，还是必须扩展帧数并重新平衡计算成本，论文未给出回答。
