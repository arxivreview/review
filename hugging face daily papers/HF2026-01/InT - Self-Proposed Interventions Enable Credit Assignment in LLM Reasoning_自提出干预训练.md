> 长思维链推理中，结果级奖励无法区分正确与错误的中间步骤，导致模型在失败轨迹中无法有效学习。现有方案依赖昂贵的分支 rollout 或易受奖励黑客影响的过程奖励模型，难以在 LLM 场景落地。本文利用模型验证与生成能力的不对称性，让模型自提出单步干预来定位并修正首个错误，再通过 SFT 内化该干预。该范式在极端困难问题上显著提升了 pass@k，但其对参考解质量的强依赖及小模型骨干的性能上限仍存疑。

## 研究背景

当强化学习（RL）应用于数学推理时，模型生成的长思维链往往包含大量正确步骤，但结果级二元奖励将整条轨迹视为整体：若最终答案错误，所有中间步骤均被惩罚。这种“一刀切”的信用分配机制导致模型难以从失败中学习，且在无正确 rollout 的困难问题上优势函数坍缩为零，训练停滞。解决此问题需精准定位首个错误步骤并选择性惩罚，即信用分配问题。

传统信用分配方法依赖显式价值函数或过程奖励模型（PRM），但估计长序列中每个步骤的价值需运行大量分支 rollout，计算成本极高；训练 PRM 则面临标注成本高与奖励黑客风险。即便拥有准确的价值函数，在巨大的未来步骤空间中优化以找到替代步骤本身也是难题。本文切入点在于：LLM 在验证单个步骤（通过文本对比）上比从头生成完整解更可靠，这种任务难度不对称性可被利用，无需训练价值函数即可实现细粒度信用分配。

## 核心方法

### 方法参照系

标准 RLVR 流程中，策略 $\pi_\theta$ 采样响应，验证器输出二元奖励，GRPO 通过组内归一化估计优势函数并更新策略。本文问题与该通用流程的关键差异在于：针对全错组（零优势）或长序列中错误步骤的精准归因，标准流程缺乏机制，而本文在 RL 前插入 SFT 干预阶段，修改策略分布以消除特定错误步骤。

### 自验证与干预生成

设计动机：解决分支 rollout 成本高昂且 PRM 优化困难的问题，利用模型自身的验证能力替代显式价值估计。模型接收问题 $x$、错误 rollout $y$ 及参考解，通过提示 $p_{\text{InT}}$ 执行文本 diff，定位首个错误步骤 $t^*$ 并生成单步干预 $\tilde{y}_{t^*}$。干预定义为：

$$ \tilde{y}_{t^*} \sim \pi(\cdot | x, y, p_{\text{InT}}) $$

该公式表示模型基于当前轨迹与参考解，生成一个替代错误步骤的短文本。这一设计将端到端解生成任务降维为单步验证与修正任务，避免了全序列重新生成，且干预长度通常小于 200 token，远小于完整 rollout 的 6835.6 token 均值，确保了生成的干预在基础模型分布下具有较高的似然性。

### 干预内化与 RL 初始化

设计动机：解决 SFT 数据 off-policy 导致熵升高、损害后续 RL 探索能力的问题。仅对错误步骤前的前缀 $y_{<t^*}$ 与干预 $\tilde{y}_{t^*}$ 进行 SFT，排除错误步骤后的后缀 $y_{>t^*}$，并过滤仅保留至少产生一次正确 rollout 的干预。SFT 目标为：

$$ \mathcal{L}_{\text{SFT}} = -\log \pi_{\text{SFT}}(\tilde{y}_{t^*} | x, y_{<t^*}) $$

该公式表示最大化干预步骤在正确前缀下的概率，从而选择性降低错误步骤的似然。由于干预短且基于 on-policy 前缀，SFT 后模型的 next-token 分布熵与基础模型相当，避免了 off-policy SFT 导致的熵坍缩，为后续 RL 提供了高 pass@k 的初始化。

## 实验评估

实验基于 Qwen3-4B-Instruct-2507，在约 4500 道高难度问题（64 或 128 次 rollout 零准确率）上训练，基线包括标准 RL、参考解 SFT+RL、自反思 SFT+RL。主结果显示，InT+RL 在 IMO-AnswerBench 上达 25.62%，较基础模型 11.68% 提升 13.94 个点，且平均得分 33.72 优于标准 RL 的 28.26。

| 方法 | IMO-AnswerBench | HMMT 2025 Nov | AMO-Bench pass@8 | Apex Shortlist pass@8 | Average |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Base | 11.68 | 41.61 | 26.24 | 20.79 | 21.17 |
| + RL | 23.46 | 46.46 | 35.21 | 22.72 | 28.26 |
| + SFT on ref. solutions + RL | 11.56 | 27.45 | 25.19 | 20.51 | 20.76 |
| + InT + RL (Ours) | 25.62 | 49.77 | 36.16 | 28.22 | 33.72 |

消融实验揭示了关键设计决策：条件于干预的 rollout 准确率从 0.0713% 升至 1.56%（22 倍），证明干预有效性；无参考解的干预准确率仅 0.171%，远低于有参考解的 1.56%，凸显参考解的必要性。SFT 配置中，包含前缀、排除后缀并过滤正确性的设置覆盖率达 202/235，准确率 7.71%，优于无过滤的 5.06%。

评估边界方面，实验仅使用 4B 参数模型，未与更大骨干对比；基准侧重竞赛级数学题，未覆盖代码或开放域任务；未报告置信区间，且训练集难度极高（基础模型准确率仅 5.53%），可能限制了结果的可泛化性。代码未开源，超参数细节有限，可复现性依赖项目网站。

## 关联研究分析

从方法设计看，InT 与 SC-GRPO 均追求无外部资源的细粒度信用分配，但 SC-GRPO 通过测量原始策略与自条件教师策略间的 token 级 KL 散度调整权重，属于隐式归因；InT 则直接生成替代步骤，属于显式修正。这一差异源于任务特性：SC-GRPO 假设错误步骤可通过权重调整缓解，而 InT 假设错误步骤需被替换。InT 对参考解的依赖是其与 SC-GRPO 的根本分歧，前者利用外部监督定位错误，后者依赖自身 rollout 的分布差异。

从问题动机看，InT 与 Token Hidden Reward 均针对稀疏奖励下的信用分配，但 Token Hidden Reward 基于 GRPO 学习动态分析 token 级隐藏奖励，仅调整优势函数权重；InT 通过 SFT 显式修改策略分布。InT 的 SFT 阶段引入了 off-policy 风险，但其通过短干预与 on-policy 前缀缓解了这一问题，而 Token Hidden Reward 无需 SFT，避免了分布偏移，但可能缺乏对错误步骤的彻底修正。InT 在极端困难问题上的优势可能源于其显式修正能力，但在中等难度问题上，Token Hidden Reward 的轻量级方案可能更具效率。

## 总结

InT 要解决的核心矛盾是长思维链中稀疏奖励导致的信用分配失效，现有方法因分支 rollout 成本或 PRM 优化困难而难以落地。本文抓住模型验证与生成能力的不对称性，通过自提出单步干预定位并修正首个错误，再以 SFT 内化干预，为 RL 提供高 pass@k 初始化。实验证明，InT+RL 在 IMO-AnswerBench 上较基础模型提升 13.94 个点，且 pass@k 前沿显著扩展。其边界在于对参考解质量的强依赖，无参考解时干预效果骤降，且仅验证于 4B 模型竞赛题。当参考解缺失或质量低下时，自提出干预能否通过自博弈或内部信号替代外部参考，论文未给出回答。
