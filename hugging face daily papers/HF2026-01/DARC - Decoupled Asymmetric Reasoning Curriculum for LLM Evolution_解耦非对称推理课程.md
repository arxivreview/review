# HuggingFace最新推荐论文 ｜DARC: Decoupled Asymmetric Reasoning Curriculum for LLM Evolution ｜解耦非对称推理课程

研究机构：中国人民大学

作者：Shengda Fan、Xuyan Ye、Yankai Lin

论文原文见 [arXiv](https://arxiv.org/abs/2601.13761)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.13761)

> 导读 大语言模型（LLM）的自博弈进化旨在摆脱人工标注依赖，实现自主能力突破，但现有耦合式自博弈框架常因优化目标非平稳与伪标签噪声导致训练崩溃或性能平台期。本文指出这种不稳定性源于求解器（Solver）能力动态变化引发的奖励漂移，以及自生成监督信号中的自我确认偏差。DARC 通过解耦提问者（Questioner）与求解器的训练阶段，并引入非对称自蒸馏机制，将动态耦合优化转化为静态课程学习与高质量伪标签生成。该框架在多个基准上平均提升 10.9 点，接近全监督模型性能，但其解耦设计是否牺牲了动态适应能力尚存疑。

## 研究背景

自博弈范式通过提问者生成任务、求解者求解任务的闭环实现无监督进化，但其核心困境在于优化目标的非平稳性。当求解器能力随迭代提升时，提问者基于旧能力校准的难度信号迅速失效，导致任务难度震荡；同时，求解器依赖自生成的伪标签进行训练，噪声标签在迭代中被放大，引发自我确认偏差。这种耦合设计使得系统难以维持稳定的优化方向，常陷入性能平台期或崩溃。

早期工作如 R-Zero 和 Absolute Zero 确立了挑战者-求解者框架，但缺乏理论保证，实验显示其训练过程存在显著的不稳定性。SPICE 等语料接地方法虽引入外部文档，但仍依赖耦合更新，未能根本解决目标漂移问题。本文切入点在于将自博弈重构为两个解耦阶段：首先基于显式难度标签独立训练提问者，消除对求解器实时状态的依赖；其次通过非对称自蒸馏训练求解器，利用文档增强教师生成高质量伪标签，抑制噪声传播。

## 核心方法

### 解耦自博弈参照系

传统自博弈采用在线耦合更新，提问者根据求解器当前表现动态调整任务难度，求解器基于自生成标签迭代优化。本文问题与该通用流程的关键差异在于：将动态耦合优化拆解为静态课程构建与离线蒸馏两个独立阶段，切断提问者与求解器间的实时反馈回路。

### 难度锚定提问者训练

提问者训练阶段的核心在于消除非平稳目标。传统方法中提问者奖励 $J_t(\theta)$ 依赖于求解器能力参数 $\phi_t$，导致梯度方向随 $\phi_t$ 变化而反转。本文采用固定难度标签 $\tau \in [0,1]$ 作为条件，定义奖励函数：

$$R(q) = \mathbb{1}[\text{grounded}(q,d)] \cdot \left(1 - |D(q) - \tau|\right)$$

其中 $D(q)$ 为基于固定基线模型计算的实证难度估计。该设计使提问者优化目标 $J_{\text{decoupled}}$ 独立于求解器状态，梯度方向不再因求解器更新而失效，确保任务难度按预设课程稳定推进。

### 非对称自蒸馏求解器训练

求解器训练阶段通过非对称设计抑制自我确认偏差。传统自蒸馏中教师与学生共享相同输入，导致噪声标签直接传递。本文引入特权教师（Privileged Teacher），其输入包含源文档 $d$，而学生（Student）仅接收问题 $q$。教师通过多数投票生成伪标签 $a^*$：

$$a^* = \text{MajorityVote}\left(\{a_i \sim S_{\text{teacher}}(\cdot|q,d)\}_{i=1}^N\right)$$

学生基于 $a^*$ 进行策略优化。该非对称性迫使学生在缺乏文档辅助的情况下学习推理能力，避免了对源文档的简单复制，同时文档增强显著降低了伪标签噪声，提升了训练信号可靠性。

## 实验评估

实验在 Qwen3-4B/8B 和 OctoThinker-8B 三个骨干模型上评估，覆盖 MATH500、GSM8K 等数学基准及 MMLU-Pro、GPQA-Diamond 等通用推理基准。基线包括 R-Zero、Absolute Zero、SPICE 和 R-Few，但未对比 SPACE、IRIS 等引入散度优化的最新理论约束方法，可能因解耦范式与在线散度调整不兼容。

| 模型 | 方法 | Math Avg. | General Avg. |
|---|---|---|---|
| Qwen3-8B-Base | Base Model | 63.3 | 33.1 |
| Qwen3-8B-Base | + R-Zero | 67.6 | 36.3 |
| Qwen3-8B-Base | + SPICE | 69.7 | 36.5 |
| Qwen3-8B-Base | + DARC | 71.1 | 37.8 |
| OctoThinker-8B | Base Model | 35.8 | 10.6 |
| OctoThinker-8B | + DARC | 51.2 | 27.3 |

DARC 在 Qwen3-8B 上 Math Avg. 达 71.1%，较 Base Model 提升 7.8 点，优于 SPICE 的 69.7%；在 OctoThinker-8B 上提升 15.4 点，显示对弱骨干的增益更大。消融实验表明，移除非对称蒸馏导致 Math Avg. 下降 1.7 点，移除难度感知提问者下降 1.2 点，证实各组件互补性。

评估协议采用 GPT-4o 作为数学基准自动裁判，通用基准使用贪心解码与精确匹配。代码已开源，但论文未报告计算开销与 GPU 资源需求，且未提供置信区间，数值比较需谨慎。

## 关联研究分析

从问题动机看，DARC 与 R-Zero 均针对自博弈不稳定性，但 R-Zero 依赖在线耦合更新，其实验复现显示跨迭代准确率呈非单调震荡，验证了理论预测的梯度方向反转。DARC 通过解耦消除动态依赖，但代价是提问者无法适应求解器能力的实时变化，可能生成难度不匹配的任务。从方法设计看，DARC 与 SPICE 共享语料接地思想，但 SPICE 仍采用耦合训练，而 DARC 引入非对称自蒸馏，其教师-学生能力差距的最优区间未探索，文档长度对伪标签质量的影响在短上下文下显著，长文档场景下的表现未知。

## 总结

DARC 解决的核心矛盾是自博弈中非平稳目标与噪声伪标签导致的训练不稳定性。其切入点在于将动态耦合优化解耦为静态课程构建与离线蒸馏，通过固定难度标签消除目标漂移，通过非对称设计抑制噪声传播。该方法在三个骨干模型上平均提升 10.9 点，Qwen3-8B 上 Math Avg. 达 71.1%，接近全监督 General-Reasoner 的 70.0%。其边界在于解耦设计牺牲了提问者对求解器能力的动态适应，且未对比最新散度优化方法。当求解器能力快速提升时，静态课程是否会导致任务难度滞后，论文未给出回答。
