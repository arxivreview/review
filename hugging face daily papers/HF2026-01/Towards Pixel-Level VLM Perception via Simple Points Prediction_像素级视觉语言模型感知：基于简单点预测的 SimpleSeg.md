# HuggingFace最新推荐论文 ｜Towards Pixel-Level VLM Perception via Simple Points Prediction ｜像素级视觉语言模型感知：基于简单点预测的 SimpleSeg

研究机构：月之暗面、南京大学

作者：Tianhui Song、Haoyu Lu、Hao Yang 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.19228)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.19228)

> 导读 视觉定位任务旨在建立自然语言描述与图像特定区域之间的精确对应，但现有多模态大语言模型（MLLMs）的感知能力多停留在图像级，难以精确界定细粒度结构。主流方案要么依赖专用解码器导致架构耦合，要么采用文本序列化掩码面临 token 预算与可解释性困境。本文提出 SimpleSeg，将分割重构为语言空间内的点序列预测，并通过 SFT 与强化学习（RL）两阶段训练解锁原生感知能力。该方法在指代表达分割基准上达到与复杂解码器相当的性能，但其点序列在极细长物体上的闭合性鲁棒性仍存疑。

## 研究背景

当 MLLM 面对“定位图中闪电”这类指令时，其视觉编码器往往只能提供全局语义对齐，而丢失局部空间细节。这种细粒度感知不足源于传统定位任务将边界框（Bounding Box）作为标准输出，因其可便捷表示为文本坐标并融入预训练流程。然而，边界框的粗粒度定位无法满足可控图像编辑、GUI 代理等需要精确“位置”信息的应用需求，像素级分割因此成为连接语言推理与物理世界交互的关键缺失环节。

在 MLLM 出现前，指代表达理解（REC）主要依赖专用检测头，但受限于分辨率与开放词汇泛化。随着 MLLM 兴起，定位被重构为自回归坐标生成或掩码预测任务，但暴露出细粒度感知不足与累积误差瓶颈。现有像素级方案分为两类：混合架构在 MLLM 骨干上附加 SAM 等专用解码器，虽性能强但破坏架构统一性且输出脱离语言空间；统一架构如 Text4Seg 将掩码序列化为文本，却受限于密集 token 预算与可解释性差。SimpleSeg 的切入点在于挑战“必须依赖专用解码器或复杂序列化”的假设，验证标准 MLLM 架构是否具备原生的像素级感知潜力。

## 核心方法

### 点轨迹表示与统一查询接口

本文方法参照系为 MLLM 的自回归文本生成流程，关键差异在于将分割掩码表示为稀疏点轨迹而非密集像素编码。设计动机是解决 RLE 等序列化方法 token 预算随图像分辨率线性增长的问题，同时保持输出的可解释性与组合性。

### 点序列预测与轮廓提取

掩码通过 Suzuki–Abe 算法提取多边形轮廓，强制顺时针遍历并应用容差参数 $\epsilon$ 进行稀疏化，生成紧凑的点序列。该表示将 token 预算控制在顶点数量线性范围内，而非图像分辨率。统一查询接口将定位任务建模为四元组 $[text, point, bbox, mask]$ 的笛卡尔积，例如 $(text \rightarrow mask)$ 或 $(point \rightarrow mask)$，通过重组弱标签倍增监督源，提升数据效率与鲁棒性。

### SFT 与 GSPO 强化学习两阶段训练

SFT 阶段通过指令微调使模型学习输出格式与基础定位先验，为 RL 提供稳定初始化。RL 阶段采用 GSPO 算法，针对点序列的“多对一”特性（不同轨迹可对应同一掩码），设计基于渲染掩码的规则奖励系统。奖励函数包含三项：

$$
R = R_{IoU} + R_{Dist} + R_{Format}
$$

其中 $R_{IoU}$ 为预测与真实掩码的 IoU（阈值 $\tau$ 以下奖励为 0），$R_{Dist}$ 为质心 MSE 距离的负值（归一化），$R_{Format}$ 为格式合规奖励。该设计直接优化全局几何属性（闭合性、边界保真度），避免 SFT 中 token 级损失对单一标注的过拟合，使模型能探索等效的有效轨迹。

## 实验评估

实验在 refCOCO/+/g 基准上评估指代表达分割（RES）与指代表达理解（REC），基线覆盖解码器类（LISA、PixelLM）与无解码器类（Text4Seg、UFOLLaVA），但缺失 Qwen3-VL-Seg 等最新 SOTA 对比。

| 方法 | refCOCO val | refCOCO+ val | refCOCOg val | Avg cIoU |
|---|---|---|---|---|
| Text4SegInternVL2-8B | 79.4 | 75.5 | 73.2 | 71.4 |
| SimpleSeg*Qwen2.5-VL-7B | 80.9 | 77.3 | 74.7 | 74.6 |
| SimpleSeg*Kimi-VL | 80.6 | 76.2 | 74.8 | 74.8 |

SimpleSeg*（预训练版）在 RES 任务上 Avg cIoU 达 74.8，较 Text4Seg 提升 3.4 个点，接近解码器类方法 Groundhog 的 75.4。REC 任务中，SimpleSeg*Kimi-VL 的 Avg Acc@0.5 为 86.5，低于解码器类 Text4Seg (w/ SAM) 的 87.1，但优于无解码器类 Text4SegInternVL2-8B 的 85.0。

消融实验显示，仅 SFT 阶段在 refCOCO val 上 cIoU 为 75.2，加入 RL 后提升至 78.5（↑3.3）；refCOCOg val 从 70.9 提升至 71.7（↑0.8），表明 RL 对复杂轮廓的优化收益随任务难度递减。奖励设计中，IoU 奖励主导性能提升，距离与格式奖励主要保障输出稳定性。

评估边界方面，论文未报告置信区间，且 REC 性能低于领域综述中 EGM 的 91.4，可能源于点序列转框的 min-max 操作损失边界细节。可复现性上，代码与模型已开源，训练使用 32 块 NVIDIA GPU，超参数（学习率 $5 \times 10^{-5}$、KL 系数 0.01）完整披露。

## 关联研究分析

从方法设计看，SimpleSeg 与 Text4Seg 同属无解码器路线，但前者以点轨迹替代 RLE 编码，将 token 预算从图像分辨率解耦至顶点数量，解决了密集序列化在高分辨率下的计算瓶颈。这一差异源于任务特性：点序列天然适合轮廓描述，而 RLE 更适合填充区域，但点序列在极细长物体（如电线）上的闭合性挑战未被充分验证。

从问题动机看，SimpleSeg 与 LISA 代表像素级定位的两种范式：LISA 通过工具调用结合分割模型，输出密集掩码但依赖外部模块；SimpleSeg 主张原生架构具备感知潜力，通过 RL 优化序列级几何属性。两者在 REC 任务上的性能差距（86.5 vs 87.1）暗示，专用解码器在边界细节建模上仍具优势，但 SimpleSeg 的架构简洁性使其更易集成至基础模型预训练流程。

## 总结

SimpleSeg 要解决的核心矛盾是 MLLM 原生架构与像素级感知需求之间的脱节，其切入点在于验证点序列预测能否替代专用解码器。通过 SFT 与 GSPO 强化学习两阶段训练，该方法在 refCOCO 系列 RES 任务上达到 Avg cIoU 74.8，接近解码器类方法性能。然而，REC 任务中 86.5 的 Acc@0.5 低于 Text4Seg (w/ SAM) 的 87.1，暴露了点序列转框操作在边界细节上的损失。当面对极细长物体或高分辨率基准（如 HR-Bench 8K）时，点轨迹的闭合性与稀疏化容差 $\epsilon$ 的鲁棒性是否足以维持像素级精度，论文未提供直接证据。
