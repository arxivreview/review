# HuggingFace最新推荐论文 ｜When Personalization Misleads: Understanding and Mitigating Hallucinations in Personalized LLMs ｜个性化诱导幻觉的推理时缓解

研究机构：中国人民大学

作者：Zhongxiang Sun、Yi Zhan、Chenglei Shen 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2601.11000)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2601.11000)

> 大语言模型（LLM）个性化旨在适配用户偏好，但现有提示增强与检索方法在提升主观满意度的同时，往往导致事实推理被用户历史干扰，产生“个性化诱导幻觉”。本文指出该现象源于隐层表示空间中个性化方向与事实方向的非正交纠缠，并提出事实保持个性化转向（Factuality-Preserving Personalized Steering, FPPS）框架，通过推理时探测纠缠程度并自适应调整隐层激活来恢复事实性。FPPS在自建基准上显著提升了事实准确率，但其评估依赖LLM-as-a-Judge且未覆盖参数化基线，跨基准泛化性存疑。

## 研究背景

当LLM接入用户长期记忆或历史交互以提供个性化服务时，模型需同时满足两个目标：生成符合用户偏好的内容，以及保持客观事实的正确性。然而，将用户历史作为上下文注入模型时，这些个性化信号会改变模型内部隐层表示的分布。若个性化方向与事实知识方向在表示空间中不正交，激活值会被拉向用户偏好区域，导致模型在回答事实性问题时输出与用户历史一致但客观错误的信息。这种由个性化机制直接引发的错误，区别于传统因知识缺失导致的幻觉，被称为个性化诱导幻觉。

现有个性化主流路线分为参数化适配与非参数化推理两类。参数化方法如LoRA通过更新权重固化偏好，但计算成本高且难以动态更新；非参数化方法如检索增强生成（RAG）和提示增强（PAG）通过推理时注入上下文实现适配，部署灵活但缺乏对事实性的约束。领域共识认为，通用对齐无法满足个体需求，必须引入用户特定信号，但现有研究多关注如何更好地注入这些信号以提升相关性，极少关注这些信号对事实推理的副作用。多数基准如LaMP仅评估生成文本与参考的重叠度，无法区分“正确的个性化”与“错误的事实性”。本文切入点在于揭示个性化与事实性在表示层面的结构性冲突，并设计推理时干预机制，在不牺牲个性化效用的前提下恢复事实准确性。

## 核心方法

### 表示纠缠建模

本文问题可置于推理时自适应框架下，但关键差异在于干预层级。传统推理时优化多作用于解码阶段或提示工程，而本文直接操作模型内部隐层表示。本文定义个性化诱导幻觉为：给定查询$x$和用户信息$u$，模型生成$y$使得$p_\theta(y|x,u)$偏离事实真值，且该偏离由$u$引起。形式化地，个性化在隐层引入一个偏移向量$v_u$，使得个性化后的隐状态$h'_L = h_L + v_u$。由于$v_u$与事实方向$v_f$非正交，该偏移会扭曲事实子空间中的激活，导致事实性错误。

### 自适应转向机制

FPPS框架包含三个离线与在线阶段。首先，通过对比有无用户历史时的困惑度偏差，定位对事实预测最敏感的层$L$。其次，在该层训练一个逻辑回归探针，输入为最终token隐状态$h'_L$，输出纠缠概率$\hat{p} \in [0,1]$：

$$ \hat{p} = \sigma(W h'_L + b) $$

该公式通过二分类损失训练，区分“事实受损”与“个性化有益”样本，量化当前表示中个性化对事实推理的干扰程度。最后，根据$\hat{p}$执行自适应转向。当$\hat{p} \geq \tau$时，执行硬转向（FPPS-H），直接减去$v_u$以完全抑制个性化；当$\hat{p} < \tau$时，执行软转向（FPPS-S），沿事实方向$s_f$进行连续调整：

$$ \tilde{h}_L = h'_L + \beta_S(y) s_f $$

其中$s_f$为事实正确响应与个性化正确响应的隐状态均值差，$\beta_S(y)$为动态系数。混合策略（FPPS-M）结合两者，在高风险时硬移除，低风险时软调节，实现事实性与个性化效用的动态平衡。

## 实验评估

实验在自建基准PFQABench上进行，该基准包含1000个样本，均分为个性化问题与事实性问题，覆盖500个用户。基线包括PAG、DPL、RAG和LLM-TRSR四种主流个性化方法，骨干网络为LLaMA3.1-8B-IT、Qwen2.5-7B-IT和Qwen2.5-14B-IT。评估采用LLM-as-a-Judge协议，报告P-Score（个性化准确率）、F-Score（事实准确率）和Overall（两者均值）。

| 方法 | LLaMA3.1-8B-IT (P/F/Overall) | Qwen2.5-7B-IT (P/F/Overall) | Qwen2.5-14B-IT (P/F/Overall) |
|---|---|---|---|
| RAG | 35.6 / 40.4 / 38.0 | 38.8 / 30.0 / 34.4 | 35.6 / 40.4 / 38.0 |
| RAG+FPPS-M | 33.6 / 79.2 / 56.4 | 36.0 / 80.0 / 58.0 | 33.6 / 79.2 / 56.4 |
| PAG+FPPS-M | 43.2 / 84.4 / 63.8 | 48.4 / 81.2 / 64.8 | 43.2 / 84.4 / 63.8 |
| DPL+FPPS-M | 34.0 / 82.4 / 58.2 | 31.6 / 82.0 / 56.8 | 34.0 / 82.4 / 58.2 |

FPPS-M在所有设置下均显著提升Overall分数，例如在LLaMA3.1-8B-IT + RAG设置中，Overall从38.0提升至56.4，F-Score从40.4提升至79.2。FPPS-H在F-Score上表现最强，但P-Score下降明显；FPPS-S保持P-Score但F-Score提升有限。消融实验显示，替换探针或转向向量为随机值会导致性能大幅下降，验证了探测准确性与转向结构化的必要性。

评估边界方面，PFQABench为自建基准，未与LaMP或LongLaMP等标准基准对比，且指标依赖LLM-as-a-Judge，缺乏人工评估或固定指标如ROUGE的交叉验证。论文未提供代码URL，超参数如阈值$\tau$的敏感性分析仅在附录中简要提及，可复现性受限。

## 关联研究分析

从问题动机看，本文与RAG（Kumar et al., 2024）形成直接对立。RAG假设用户历史是有益上下文，通过检索注入提升相关性；本文则证明同一历史在事实性查询中成为噪声源，导致表示纠缠。这一差异源于任务特性：RAG优化的是“相关性”，而本文关注“事实性”，两者在表示空间中存在结构性冲突。本文未探索RAG检索质量的改进，而是转向隐层干预，暗示在检索端优化可能无法解决表示纠缠问题。

从方法设计看，本文与激活工程（Turner et al., 2023）共享技术原型，但应用场景不同。激活工程通常用于概念转向或安全对齐，而本文将其应用于个性化安全，引入纠缠探针作为动态门控。与参数化方法如LoRA相比，FPPS无需更新权重，适合黑盒或动态偏好场景，但缺乏长期一致性。本文未对比LoRA等参数化基线，无法判断在数据丰富、偏好稳定场景下，隐层转向是否优于参数固化。

## 总结

本文核心矛盾在于个性化信号与事实知识在表示空间中的非正交纠缠，导致个性化LLM在事实性查询中产生系统性错误。现有方法如RAG和PAG仅关注偏好注入，缺乏对事实性的约束，而本文通过隐层探测与自适应转向，在不更新权重的前提下动态抑制有害个性化。实验显示FPPS-M将Overall分数从基线的~30%提升至~60%，F-Score提升超过40个百分点。然而，本文边界在于评估依赖自建基准与LLM-as-a-Judge，未覆盖参数化基线，且未验证在长程对话或动态偏好变化场景下的鲁棒性。当用户历史长度增加或偏好快速变化时，隐层转向的阈值$\tau$是否仍需静态设定，论文未给出回答。
