> 化学大语言模型（LLMs）长期依赖自然语言思维链（CoT）进行推理，但离散文本难以承载连续的化学物理动力学，导致推理效率低且易产生结构幻觉。现有方法通过多模态编码或工具调用弥补语义缺失，却未触及推理模态本身的瓶颈。本文提出 LatentChem，通过引入连续潜空间思维向量与动态分子特征更新机制，将推理过程从文本生成解耦。该方法在 ChemCoTBench 上取得 59.88% 的非平局胜率，并实现 10.84 倍的推理开销降低，但牺牲了中间步骤的可解释性，其潜空间动力学与化学拓扑的深层对齐机制尚存疑。

## 研究背景

当模型处理分子优化任务时，需将电子离域、空间位阻等连续物理化学直觉转化为离散的自然语言 Token 序列。这一过程被称为思维链（Chain-of-Thought, CoT），它假设自然语言是表达化学逻辑的充分载体。然而，化学性质景观本质上是高维连续的，而语言 Token 的离散化将平滑的优化表面切割为阶梯状路径，导致模型在导航化学流形时产生低效的锯齿状轨迹，即连续性-离散化鸿沟。

当前化学 LLM 的主流路线聚焦于增强感知与工具调用。多模态架构如 MolT5 通过图编码器注入结构特征，解决了部分拓扑缺失问题；智能体框架如 ChemCrow 通过调用 RDKit 等工具保证数值精度。这些方法提升了输入端的结构感知或输出端的验证可靠性，但推理过程仍被锁定在自回归文本生成的线性序列中。这种“文本瓶颈”限制了模型在复杂多步推理中的并行性与全局一致性，导致长程依赖管理失效。

LatentChem 的切入点在于质疑自然语言作为化学推理计算基底的必要性。作者假设，若将推理过程移至连续潜空间，模型能更自然地执行结构导航与属性优化。该框架不改变骨干网络，而是重构推理接口，允许模型在生成最终答案前，通过连续向量进行“静默”思考，并动态更新对分子结构的理解。

## 核心方法

### 方法参照系

标准化学 LLM 流程为“分子编码 -> 文本 CoT 生成 -> 答案解码”。本文的关键差异在于将中间的“文本 CoT 生成”替换为“潜空间思维循环”，并引入感知-推理双向交互机制，打破静态特征输入的限制。

### 潜空间思维架构

传统 CoT 将推理绑定于 Token 输出，而 LatentChem 在感知与生成之间注入连续思维向量。设计动机是消除离散 Token 对连续化学动力学的量化误差。模型首先通过 ChemAdapter 将分子特征压缩为固定数量的 ChemTokens，作为前缀软提示。在推理阶段，LLM 骨干输出隐藏状态 $\mathbf{z}_t$，该状态不经过离散化，而是直接作为思维向量驱动后续步骤。

$$
\mathbf{h}_{t+1} = \mathbf{z}_t + \text{FFN}(\text{LN}(\mathbf{z}_t))
$$

该公式表明，当前思维向量 $\mathbf{z}_t$ 经层归一化与前馈网络处理后，与自身残差相加，形成下一步的输入 $\mathbf{h}_{t+1}$。这一机制实现了连续状态的递归传递，避免了自回归解码中的累积误差。

### 动态感知更新机制

静态编码器无法适应推理过程中的焦点转移，导致模型在关注不同子结构时缺乏灵活性。ChemUpdater 机制解决了这一失效，允许潜空间思维反向查询分子特征。在每一步 $t$，当前 ChemTokens $\mathbf{H}_{chem}^{[t]}$ 作为查询，累积的推理历史 $\mathbf{Z}_{1:t}$ 作为键和值，通过交叉注意力更新分子表示。

$$
\mathbf{H}_{chem}^{[t+1]} = \text{CrossAttn}(\mathbf{H}_{chem}^{[t]}, \mathbf{Z}_{1:t}, \mathbf{Z}_{1:t})
$$

该公式确保分子表示随推理状态动态演化，使模型能根据当前思维焦点重新加权不同原子或官能团的重要性。这种动态感知循环使推理过程具备结构感知能力，而非依赖初始静态嵌入。

## 实验评估

实验基于 Qwen-3-8B 骨干，在 ChemCoTBench、Mol-Instructions、ChEBI-20 和 ChemLLMBench 四个基准上评估。基线包括纯文本 LLM、显式 CoT 化学 LLM（Stage 1+2+4）及通用潜空间模型 Coconut-Chem。

| 基准 | 方法 | 非平局胜率 (%) |
| :--- | :--- | :--- |
| ChemCoTBench | LatentChem | 59.88 |
| ChemCoTBench | Explicit CoT (Stage 1+2+4) | 0.00 (参考) |
| ChEBI-20 | LatentChem | 85.26 |
| ChemLLMBench | LatentChem | 55.58 |

LatentChem 在推理密集型任务上显著优于显式 CoT 基线，但在 Mol-Instructions 上仅保持 49.88% 的胜率，显示其在简单指令任务上无显著优势。

消融实验揭示了关键设计决策的影响。移除潜空间思维导致性能骤降，验证了连续表示的核心价值。移除 ChemUpdater 使分子优化成功率下降 12.0%，证明动态感知对结构一致性至关重要。此外，预算压力测试显示，当潜空间步数限制在 6 步以下时，模型自发重新激活文本 CoT，表明隐式与显式推理存在水力补偿效应。

评估边界方面，论文未报告计算效率的绝对时间成本，仅对比 Token 数量。可复现性方面，代码已开源，但训练依赖特定的 ChemCoTDataset 快照（2025 年 11 月），且 GRPO 奖励函数细节仅在附录中简述，超参数敏感性未充分探讨。

## 关联研究分析

从问题动机看，LatentChem 与 MolT5 等多模态预训练范式存在根本差异。MolT5 旨在解决“输入端”的结构感知缺失，通过图编码器对齐模态；而 LatentChem 聚焦“推理端”的模态瓶颈，假设即使输入完美，文本推理本身仍是低效载体。这一差异源于对化学推理本质的不同理解：前者视化学为多模态匹配问题，后者视其为连续优化问题。

从方法设计看，LatentChem 与 Coconut 共享潜空间推理理念，但引入了化学专用的动态更新机制。Coconut 将分子嵌入视为静态上下文，限制了推理过程中的结构聚焦能力；LatentChem 的 ChemUpdater 允许思维向量反向查询分子特征，实现了感知与推理的闭环。这种设计是否在所有化学任务中均优于静态嵌入，论文未提供跨任务类型的全面对比，仅在分子优化与理解任务上验证了其必要性。

## 总结

LatentChem 针对化学推理中离散文本与连续物理化学动力学的失配问题，提出将推理过程移至连续潜空间。通过引入 ChemUpdater 动态更新机制，模型在推理中实时调整分子表示，解决了静态编码器的焦点僵化问题。实验显示，该方法在 ChemCoTBench 上取得 59.88% 的非平局胜率，并实现 10.84 倍的推理开销降低，验证了潜空间推理在效率与准确性上的双重优势。然而，该范式牺牲了中间步骤的可解释性，且模型在 Mol-Instructions 等简单任务上未展现显著优势。当潜空间步数受限导致模型回退至文本 CoT 时，这种混合推理模式的性能边界与稳定性如何，论文未给出明确回答。
