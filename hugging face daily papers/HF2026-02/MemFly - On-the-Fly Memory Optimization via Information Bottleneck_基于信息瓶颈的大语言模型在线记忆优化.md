# HuggingFace最新推荐论文 ｜MemFly: On-the-Fly Memory Optimization via Information Bottleneck ｜基于信息瓶颈的大语言模型在线记忆优化

研究机构：香港科技大学、南京大学

作者：Zhenyuan Zhang、Xianzhang Jia、Zhiqin Yang 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.07885)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.07885)

> 大语言模型智能体在长时程交互中面临记忆冗余累积与检索保真度下降的双重困境，现有检索中心或摘要增强范式均无法在压缩与保留间取得平衡。MEMFLY 将记忆构建形式化为在线信息瓶颈优化问题，通过无梯度语义评估驱动冗余合并，并构建分层符号锚点结构以支持多路径检索。该框架在 LoCoMo 基准上验证了理论有效性，但其性能上限仍受限于骨干模型能力，且未解决高并发场景下的计算延迟瓶颈。

## 研究背景

当智能体处理连续交互流时，原始观测数据包含大量冗余与噪声，直接存储导致记忆库熵值单调递增，检索噪声随之升高。为控制这一过程，需引入信息瓶颈（Information Bottleneck, IB）原则，即在压缩输入信息 $I(X;M)$ 的同时最大化对下游任务的相关性 $I(M;Y)$。然而，IB 优化通常依赖精确的条件概率分布，而在智能体场景中，未来任务 $Y$ 在记忆构建时不可知，且高维嵌入空间的稀疏性使得直接聚类失效，这构成了将经典信息论方法应用于在线记忆管理的核心障碍。

现有记忆架构主要分为两类：检索中心系统（如 RAG）保留原始细节但缺乏整合，导致冗余累积；记忆增强系统（如 MemGPT、A-MEM）采用 LLM 摘要进行压缩，但牺牲了细粒度保真度。两者均缺乏统一的理论目标来指导“保留什么、丢弃什么”的决策。MEMFLY 的切入点在于将记忆构建视为在线贪心聚合过程，利用 LLM 的语义评估能力近似 Jensen-Shannon 散度，从而在无需梯度优化的情况下实现 IB 目标的最小化，同时通过双层聚类原理构建分层结构以解决高维稀疏问题。

## 核心方法

### 在线信息瓶颈形式化

MEMFLY 将记忆状态 $M_t$ 定义为动态图 $G_t = (V_t, E_t, \Phi_t)$，其中节点映射至稠密嵌入与文本内容。其优化目标为最小化拉格朗日函数 $\mathcal{L}_{IB} = I(X_{1:t}; M_t) - \beta I(M_t; Y)$，其中 $\beta$ 控制压缩与相关性的权衡。由于未来任务 $Y$ 不可观测，论文引入局部连贯性（关键词共现）与全局可导航性（主题层级）作为代理信号，将抽象的信息论目标转化为可计算的结构化约束。这一设计解决了传统 IB 方法在流式数据中因分布未知而无法优化的问题，使记忆构建具备理论上的最优性基础。

### 无梯度语义聚合与分层结构

在记忆构建阶段，MEMFLY 采用 LLM 作为无梯度优化器，对候选记忆对 $(n_t, n_i)$ 计算冗余分数 $s_{red}$ 与互补分数 $s_{comp}$。当 $s_{red} > \tau_m$ 时执行合并操作，直接减少节点数以最小化 $I(X;M)$；当 $s_{comp} > \tau_l$ 时建立关联边 $E_{RELATED}$，保留条件依赖以支持多跳推理。该机制扩展了经典 AIB 算法，使其适应流式场景下的增量更新。同时，基于双层聚类原理构建 Note-Keyword-Topic 三层结构：Notes 保留原始保真度，Keywords 作为符号锚点缓解向量稀释，Topics 提供宏观语义导航。这种分层设计解决了高维嵌入空间直接聚类导致的拓扑退化问题，确保检索时的语义稳定性。

### 三路径混合检索与迭代精炼

检索阶段，查询被解析为主题描述与实体关键词，驱动三条并行路径：通过 Topics 进行宏观语义定位，通过 Keywords 进行微观符号锚定，通过 $E_{RELATED}$ 进行拓扑扩展。最终证据池通过倒数排名融合（RRF）合并。对于复杂查询，引入迭代证据精炼（IER）协议，动态评估证据充分性并逐步扩展检索范围。这一设计弥补了单次向量检索在多跳推理任务中的不足，通过结构化遍历与迭代反馈，提升了复杂逻辑链的召回率。

## 实验评估

实验在 LoCoMo 基准上进行，涵盖多跳、时间、开放域、单跳及对抗性五类任务，对比基线包括 LOCOMO、READAGENT、MEMORYBANK、MEMGPT、A-MEM 和 MEM-0。基线覆盖了检索中心与记忆增强两类主流路线，但缺失 MemAgent 等强化学习路线及 SSGM 等安全治理路线，限制了跨范式比较的全面性。

| 模型 | 方法 | Multi-Hop F1 | Temporal F1 | Open Domain F1 | Single Hop F1 | Adversarial F1 | Average F1 |
|---|---|---|---|---|---|---|---|
| GPT-4o-mini | MEM-0 | 34.72 | 45.93 | 22.64 | 43.65 | 30.15 | 38.70 |
| GPT-4o-mini | MEMFLY | 32.11 | 46.61 | 23.98 | 44.74 | 51.48 | 43.76 |
| Qwen3-8B | A-MEM | 24.30 | 34.50 | 13.10 | 38.10 | 31.00 | 32.76 |
| Qwen3-8B | MEMFLY | 28.24 | 38.39 | 15.43 | 42.09 | 43.79 | 38.62 |

在 GPT-4o-mini 骨干下，MEMFLY 平均 F1 为 43.76%，较最强基线 MEM-0 提升 5.06 个点；在 Qwen3-8B 下，较次优基线 A-MEM 提升 5.86 个点。开源模型上的更大增益表明，结构化记忆组织能有效补偿较弱骨干的上下文推理能力。

| 消融组件 | F1 | BLEU | Recall | Hit Rate |
|---|---|---|---|---|
| Full MEMFLY | 38.62 | 36.85 | 62.22 | 67.12 |
| w/o Update | 27.97 | 42.11 | 42.11 | - |
| w/o Link | 33.57 | 53.19 | - | - |
| w/o IER | 32.94 | 46.29 | - | - |

消融实验显示，移除门控更新（w/o Update）导致 F1 从 38.62% 降至 27.97%，Recall 从 62.22% 降至 42.11%，证实主动整合对防止噪声累积至关重要。移除关联边（w/o Link）对对抗性任务影响显著，表明拓扑结构在过滤干扰项中的关键作用。

评估仅使用 LoCoMo 单一基准，缺乏 LongMemEval 等超大规模多会话场景的验证，且未报告计算延迟与吞吐量指标。代码未公开，超参数（如 $\tau_m=0.7, \tau_l=0.5$）基于验证集调优，可复现性受限。

## 关联研究分析

从方法设计看，MEMFLY 与 A-MEM 均采用关联网络组织记忆，但 A-MEM 依赖启发式 Zettelkasten 链接，缺乏理论优化目标，而 MEMFLY 通过 IB 框架将链接决策转化为信息论最优问题，解决了启发式规则在长尾场景下的泛化不足。与 MemGPT 相比，MEMFLY 的分层结构借鉴其虚拟内存思想，但将“页面交换”替换为基于 JS 散度近似的主动合并，更侧重内容压缩而非容量管理，这导致其在高并发写入场景下的延迟可能高于 MemGPT 的简单分页机制。

从问题动机看，MEMFLY 聚焦于压缩-保真度权衡，而 MAGMA 等最新架构侧重多图谱融合以支持因果推理。MEMFLY 的单图结构虽简化了系统复杂度，但在处理跨模态或复杂因果链时，可能不如多图谱架构灵活。此外，MEMFLY 未涉及记忆安全治理，而 SSGM 等系统通过真值锚定机制防止记忆投毒，MEMFLY 的 LLM 驱动合并过程可能引入语义漂移风险，这是其未探索的盲区。

## 总结

MEMFLY 旨在解决长时程智能体记忆中冗余累积与保真度损失的矛盾，通过在线信息瓶颈形式化与无梯度语义聚合，实现了理论驱动的记忆优化。实验表明，其在 LoCoMo 上较最强基线提升 5.06 至 5.86 个 F1 点，验证了 IB 框架的有效性。然而，其性能仍受限于骨干模型能力，且在单一基准上未展示对超大规模动态状态更新的鲁棒性。当记忆库规模扩展至百万 Token 级别时，LLM 驱动的贪心合并策略的计算开销是否会导致实时性崩溃，论文未给出回答。
