> 分布式大模型训练中，矩阵优化器（如 Muon、Shampoo）因需访问完整张量维度以执行 SVD 或 Newton-Schulz 迭代，与 ZeRO-1 和 TP 的任意分片策略产生根本性冲突，导致现有方案要么冗余计算，要么破坏通信几何结构。Canzona 通过解耦逻辑优化器任务分配与物理参数分布，提出静态分区与异步微组调度，在保持原子性的同时消除负载不均。该方法在 Qwen3-32B 上实现了 1.57 倍端到端加速，但其异步执行在长周期训练中的收敛稳定性尚未得到理论证明。

## 研究背景

当 LLM 训练规模扩展至万亿参数时，单卡显存瓶颈迫使框架采用 ZeRO-1 分片优化器状态与 TP 切分权重矩阵。然而，矩阵优化器依赖二阶信息或结构特性加速收敛，其数学本质要求对完整张量进行整体操作，这与分布式系统中将张量碎片化存储于不同 Rank 的物理现实形成“原子性约束”冲突。若强行在碎片化状态下执行更新，需引入昂贵的 All-Gather 重构或冗余计算，导致吞吐量急剧下降。

主流解决方案存在显著缺陷：同步计算（SC）虽保证原子性，但所有 Rank 执行相同矩阵操作，造成算力浪费；NVIDIA 的层级优化器（NV-layerwise）按层分配状态，虽避免张量切分，但破坏了 ZeRO-1 的桶状几何布局，迫使系统退化为 All-Reduce 通信，带宽需求翻倍且需额外 All-Gather 重分布参数。Canzona 的切入点在于识别出“几何不兼容”是层级方案失效的根源，提出在保留 ZeRO-1 几何约束的前提下，通过静态分区实现零通信本地更新，并通过异步调度隐藏 TP 重构开销。

## 核心方法

### 方法参照系

标准 ZeRO-1 采用均匀切分（Equal Chunk）策略，将参数缓冲区均分为 $|B|/R$ 大小的分片以平衡内存。该流程假设优化器为元素级操作（如 AdamW），可独立更新每个元素。本文问题的关键差异在于，矩阵优化器无法在碎片化分片上执行整体矩阵运算，必须重构完整张量，导致标准分片策略失效。

### $\alpha$-Balanced 静态分区

针对 DP 维度，Canzona 摒弃均匀切分，引入 $\alpha$-Balanced Greedy LPT 算法。设计动机是解决朴素原子分配导致的计算负载不均：大参数张量（如 Attention 矩阵）的计算复杂度呈立方级增长，若随机分配，部分 Rank 将成为“慢节点”，引发流水线气泡。算法通过控制参数 $\alpha \in [0, 1]$ 插值两种目标：$\alpha=1$ 时优先填充负载赤字以最小化全局 Makespan，$\alpha=0$ 时优先保持桶内通信量均匀。其核心公式为混合目标向量：

$$
\mathbf{v}^* = (1 - \alpha) \mathbf{v}_{even} + \alpha \mathbf{v}_{fill}
$$

其中 $\mathbf{v}_{even}$ 为均匀分配基向量，$\mathbf{v}_{fill}$ 为基于历史负载缺口的补偿基向量。该公式物理含义为：在分配当前桶参数时，动态调整各 Rank 的目标负载，既避免计算过载，又维持通信重叠效率。

### 异步微组调度

针对 TP 维度，Canzona 设计异步计算流水线。设计动机是消除 TP 重构张量时的同步阻塞：传统 TP 需等待所有 Rank 完成计算后 All-Gather 重构，导致通信延迟直接计入迭代时间。Canzona 将碎片化更新任务打包为“微组”（Micro-Groups），由指定 Host Rank 异步执行。其调度算法采用贪心回滚策略，最小化微组内 Makespan 并最大化组饱和度：

$$
\min_{M_k} \max_{r \in R} L_{k,r} \quad \text{s.t.} \quad \sum_{p \in M_k} W(p) \le C_{max}
$$

其中 $L_{k,r}$ 为 Rank $r$ 在微组 $M_k$ 中的负载，$C_{max}$ 为内存/缓冲区容量上限。该公式物理含义为：在内存约束下，将计算任务分配给最空闲的 Rank，并通过异步执行隐藏 All-to-All 通信延迟，实现计算-计算重叠。

## 实验评估

实验基于 256 GPU 集群，训练 Qwen3 系列模型（1.7B-32B），序列长度 4096，Batch Size 1。基线包括同步计算（SC）和 NVIDIA 层级优化器（NV-layerwise），缺失其他矩阵优化器分布式实现（如 Distributed K-FAC）的对比。

| 方法 | 迭代时间 (s) | 优化器延迟 (s) | 加速比 (vs NV-layerwise) |
| :--- | :--- | :--- | :--- |
| NV-layerwise | 1.381 | 0.383 | 1.00x |
| Canzona (LB-ASC) | 0.877 | 0.066 | 1.57x |

Canzona 在 Qwen3-32B 上实现 1.57 倍端到端加速，其中优化器延迟降低 5.8 倍。消融实验显示，$\alpha=1.0$ 时总步长最低，表明计算负载不均是主要瓶颈，而通信不均衡可被重叠隐藏。

评估边界方面，论文仅验证了 Muon、Shampoo、SOAP 三种优化器，未覆盖 K-FAC 等近似二阶方法；实验规模上限为 256 GPU，未验证万卡集群下的可扩展性；代码未开源，超参数（如 $\alpha$ 值）未提供完整列表，可复现性受限。

## 关联研究分析

从问题动机看，Canzona 与 AsyncHZP 同属调度优化路线，但 AsyncHZP 针对通用优化器解决流水线利用率问题，而 Canzona 聚焦矩阵优化器的原子性约束。差异根源在于任务特性：矩阵优化器的非线性计算复杂度导致负载不均更严重，需专用调度算法。Canzona 的静态分区策略在 DP 维度实现了零通信，而 AsyncHZP 依赖异步窗口大小调优，存在收敛风险。

从方法设计看，Canzona 与 NV-layerwise 均试图解决原子性冲突，但 NV-layerwise 牺牲几何布局换取层级分配，导致通信开销翻倍；Canzona 通过边界移动保留几何约束，实现零通信本地更新。这一差异暗示，现有框架对“几何兼容性”的重视不足，Canzona 证明了在保留通信原语效率的前提下解决原子性冲突的可行性。

## 总结

Canzona 解决了矩阵优化器与分布式分片策略的原子性冲突，通过静态分区与异步调度在保留 ZeRO-1 几何约束的同时消除负载不均。该方法在 Qwen3-32B 上实现 1.57 倍加速，优化器延迟降低 5.8 倍，证明了异步执行在短周期训练中的有效性。然而，论文未提供异步执行在长周期训练（>1T tokens）中的收敛稳定性证明，且实验规模限于 256 GPU。当训练步数增加至百万级时，异步微组调度引入的微小进度偏差是否会累积导致模型性能下降，论文未给出回答。
