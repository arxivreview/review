# HuggingFace最新推荐论文 ｜Surprisal-Guided Selection: Compute-Optimal Test-Time Strategies for Execution-Grounded Code Generation ｜惊讶度引导选择

论文原文见 [arXiv](https://arxiv.org/abs/2602.07670)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.07670)

> 可验证执行接地（Verifiable Execution-Grounded, VEG）任务中，模型在推理阶段应分配算力于参数更新还是样本搜索？现有测试时训练（Test-Time Training, TTT）依赖梯度更新修正模型，但在密集连续奖励场景下易陷入局部最优。本文切入点在于发现模型置信度与代码质量呈负相关，通过选择高惊讶度（低对数概率）的正确样本替代梯度适应。该策略以零额外计算成本实现了与全量搜索相当的性能，但受限于小样本统计效力，其普适性仍需更大规模验证。

## 研究背景

当大语言模型生成GPU内核代码时，CUDA编译器与硬件提供了确定性的执行反馈，这种无需人工标注的自动评估机制构成了VEG任务的核心特征。然而，模型生成的代码往往存在性能差异，从0倍到10倍以上的加速比不等，这种连续且密集的奖励信号使得细微的性能退化可被精确捕捉。传统TTT方法通过梯度更新调整模型参数以适应测试分布，但这一过程可能破坏模型原有的多样性，导致其锁定在早期出现的平庸解上，而非探索分布尾部的高性能解。

测试时适应领域长期存在“参数更新”与“采样搜索”的路径之争。主流TTA方法如TENT通过最小化熵更新归一化层，CoTTA利用教师-学生框架抑制灾难性遗忘，这些方法假设梯度更新能提升模型对目标域的适应性。然而，在密集奖励的VEG任务中，最优解往往已存在于基础模型的分布尾部，梯度更新反而通过“过度锐化”（Over-sharpening）压缩了概率空间，使模型丧失发现罕见高性能策略的能力。本文挑战了“必须更新参数”的基本假设，提出在匹配计算预算下，纯搜索策略优于最小化梯度适应，并引入惊讶度作为选择准则，重新定义了测试时算力的分配优先级。

## 核心方法

### 双循环架构与匹配预算协议

本文采用双循环架构确保实验公平性。外循环通过可验证奖励强化学习（Reinforcement Learning from Verifiable Rewards, RLVR）在80个KernelBench L1训练任务上训练基础策略，使用组相对策略优化（Group Relative Policy Optimization, GRPO）与LoRA适配，生成98.4%正确率的基础检查点。内循环在5个保留评估任务上对比测试时策略，关键约束是匹配计算预算：所有策略共享320次总采样、0.25温度、1024最大令牌，唯一变量是算力分配方式——独立采样（Best-of-N）或作为梯度信号（TTT）。这一设计排除了评估协议差异的混淆，直接检验“搜索 vs. 适应”的本质差异。

### 惊讶度引导选择机制

标准选择策略通常选取最高置信度（最低惊讶度）的正确样本，但本文发现模型对最佳解的置信度最低。惊讶度引导选择（Surprisal-Guided Selection）定义为：在通过执行正确性过滤的样本中，选择对数概率最低（即惊讶度最高）的样本。其数学表达为：

$$ \hat{y} = \arg\min_{y \in \mathcal{C}} \log p_\theta(y | x) $$

其中 $\mathcal{C}$ 为通过功能等价性测试的正确样本集合。该公式的物理含义是：模型概率分布映射的是策略的“常见度”而非“质量”，高惊讶度样本对应训练数据中罕见但高性能的专家级优化（如非典型内存访问模式）。设计动机在于解决梯度适应导致的多样性丧失——通过直接筛选分布尾部样本，避免参数更新对概率空间的压缩。

### 最佳适应检查点选择

为公平评估TTT性能，本文定义最佳适应（Best-of-Adaptation, BoA）机制：在1-5步GRPO梯度更新轨迹中，选择验证集上fast@1（正确且加速>1x）最高的检查点。其选择准则为：

$$ \theta^* = \arg\max_{s \in \{0, \dots, S\}} \text{fast@1}(\theta_s) $$

其中 $\theta_s$ 为第 $s$ 步后的检查点。该机制允许TTT在适应过程中出现性能峰值时及时停止，避免过度锐化导致的性能退化。实验表明，性能通常在第1-2步达到峰值后回归，BoA选择捕捉了这一非单调轨迹的最优点。

## 实验评估

| 策略 | fast@1 | 标准差 | 平均加速比 |
|---|---|---|---|
| best-correct (Oracle) | 100% | 0% | 226.9x |
| surprisal-guided-top3 | 100% | 0% | 139.0x |
| surprisal-guided | 80% | 0% | 41.2x |
| random-correct | 59.2% | 2.7% | 30.0x |
| confidence-guided | 50% | 14.1% | 11.6x |

实验在KernelBench L1评估集（20任务）上进行，基线覆盖Best-of-N搜索、随机选择、置信度引导选择及TTT适应。核心发现是Best-of-N在K=64时达到90%任务成功率（18/20任务），而TTT最佳检查点仅30.6%（3种子均值），其等效K值小于1，意味着TTT表现劣于单次随机采样。惊讶度引导选择以80%成功率超越置信度引导的50%，提升30个百分点，且标准差为0%，表明跨任务一致性显著优于置信度策略（标准差14.1%）。

消融实验揭示了过度锐化的具体机制：TTT性能在第2步达到峰值42.5%后，第3步回归至36.3%。跨种子方差显示TTT BoA标准差为11.3%，远高于Best-of-N的3.2%，证实梯度更新导致的不稳定性。长度控制分析排除了代码长度混淆：对数概率与加速比的原始Spearman相关系数为-0.047（p=0.27），控制长度后的偏相关系数为0.003（p=0.95），证明惊讶度效应独立于代码长度。四分位分析显示，第二高惊讶度区间（Q2）的fast@1为81.0%，而最低惊讶度区间（Q4）仅为43.9%，高惊讶度半区（Q1+Q2）平均64.2% vs. 低惊讶度半区（Q3+Q4）58.1%。

评估边界存在明显局限：主选择比较基于n=10的二元结果（5任务×2种子），精确符号检验p=0.125，统计效力有限。连续加速比分析的配对Wilcoxon检验p=0.084，未达传统显著性水平。论文未报告GPU型号、训练时长或完整超参数配置，代码未公开，可复现性依赖KernelBench官方实现。惊讶度选择的有效性依赖于任务内对数概率方差，20个任务中仅9个具有高方差（std>1.0），限制了该策略的适用范围。

## 关联研究分析

从问题动机看，本文与TENT等视觉TTA方法存在根本差异。TENT假设分布偏移可通过局部参数调整（如BN层更新）修正，其核心是熵最小化以提升预测置信度。本文则发现，在密集奖励VEG任务中，高置信度样本往往对应平庸解，而高性能解位于低置信度尾部。这一冲突源于任务特性：视觉分类的奖励是离散的类别标签，熵最小化能有效抑制噪声；而内核优化的奖励是连续加速比，最优解的稀有性使得“常见度”与“质量”解耦。本文未探索稀疏奖励场景下惊讶度选择是否依然有效，这构成了其适用边界的关键疑问。

从方法设计看，本文与NEO（无优化测试时适配）同属“非参数适应”路线，但机制截然不同。NEO通过特征重中心化处理应对分布平移，假设偏移主要是整体平移；本文通过惊讶度选择应对分布尾部探索，假设最优解存在于低概率区域。二者均挑战了梯度更新的必要性，但NEO针对视觉特征空间，本文针对代码生成概率空间。与CoTTA的教师-学生框架相比，本文无需额外模型或记忆回放，仅利用现有对数概率信号，计算开销为零。然而，CoTTA在长时程持续适应中通过EMA教师抑制遗忘，本文的惊讶度选择是否能在多轮迭代中保持稳定性，论文未提供证据。

## 总结

本文要解决的核心矛盾是密集奖励VEG任务中测试时算力的分配效率：梯度适应是否优于纯搜索？现有TTT方法假设参数更新能提升适应性，但在内核优化中，梯度更新通过过度锐化压缩概率空间，导致模型锁定平庸解。本文抓住的切入点是模型置信度与代码质量的负相关，通过惊讶度引导选择直接筛选分布尾部的高性能样本，避免了参数更新的多样性损失。实验证明Best-of-N在K=64时达到90%任务成功率，而TTT仅30.6%，惊讶度选择以80%成功率超越置信度选择的50%。本文的边界在于小样本统计效力（n=10）和任务内对数概率方差的依赖性，20个任务中仅9个满足高方差条件。当任务内对数概率方差低于阈值时，惊讶度引导选择是否仍能区分高质量样本，论文未给出回答。
