# HuggingFace最新推荐论文 ｜No One Size Fits All: QueryBandits for Hallucination Mitigation ｜闭源大模型幻觉抑制的在线策略学习

论文原文见 [arXiv](https://arxiv.org/abs/2602.20332)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.20332)

> 大语言模型（LLM）在闭源部署中频繁产生事实性错误，而现有缓解方案多依赖白盒内部状态访问或多次采样，难以直接应用于API接口。本文切入点在于将查询重写视为一个上下文多臂赌博机问题，通过在线学习动态选择最优重写策略，规避了对模型内部参数的依赖。该方法利用17维语言特征向量作为上下文，在GPT-4o黑盒环境下实现了87.5%的查询级胜率。其价值在于提供了无需重训练的即插即用方案，但缺乏与白盒SOTA方法的公平对比，且重写策略可能引入新的语义漂移风险。

## 研究背景

当LLM面对复杂查询时，微小的表面形式扰动即可诱发巨大的输出差异，这种现象被称为提示敏感性。提示敏感性导致静态重写策略（如固定使用简化或扩展）无法普适，因为不同查询的幻觉风险源于不同的语言结构缺陷。解决这一问题的关键在于建立查询特征与最优干预策略之间的动态映射，这构成了上下文多臂赌博机（Contextual Multi-Armed Bandit, CMB）的应用场景：在每轮交互中，根据上下文向量选择动作以最大化累积奖励。

主流幻觉缓解路线分为白盒内部表征探测与黑盒解码干预。白盒方法如SAPLMA和HARP依赖隐藏状态访问，无法用于闭源模型；黑盒方法如SelfCheckGPT依赖多次采样一致性，计算成本高昂且无法区分“一致的错误”与“正确答案”。现有黑盒干预方法（如DoLa）虽无需内部访问，但通常依赖固定的解码时对比或投票机制，缺乏对查询特定特征的自适应能力。QueryBandits的切入点在于将干预前置到输入层，通过在线学习策略替代固定超参数，解决闭源模型下幻觉抑制的实时性与适应性矛盾。

## 核心方法

### 方法参照系

本文问题属于“解码与推理干预”类别的输入层变体。标准流程为在解码阶段利用Logits或注意力图进行对比或投票，而本文的关键差异在于干预发生在生成前，通过修改查询文本本身来引导模型行为，且策略选择基于在线学习而非固定规则。

### 复合奖励函数设计

奖励函数设计解决了单一指标（如BLEU）对语义正确性不敏感的问题。本文构建复合奖励 $r_t = \alpha s_{llm} + \beta s_{fuzz} + \gamma s_{bleu}$，其中 $s_{llm} \in \{0, 1\}$ 为LLM-as-a-judge二元正确性标签，$s_{fuzz} \in [0, 1]$ 为模糊字符串相似度，$s_{bleu} \in [0, 1]$ 为BLEU-1分数。该公式的物理含义是：以LLM判断为语义锚点，以模糊匹配校准精确度，以BLEU提供词汇层面的补充约束。通过Pareto前沿分析，确定权重 $(\alpha, \beta, \gamma) = (0.6, 0.3, 0.1)$ 位于1%最优区域内，该配置在150个样本后95%置信区间下限超过0.97，确保了奖励信号对正确性的稳定区分能力。

### 上下文Bandit策略学习

策略学习模块解决了静态重写策略无法适应查询多样性导致性能波动的问题。在上下文多臂赌博机框架中，每轮 $t$ 观察上下文向量 $\mathbf{f}_t \in \{0, 1\}^{17}$（17维二值语言特征），选择动作 $a_t \in \mathcal{A}$（5种重写策略：PARAPHRASE, SIMPLIFY, DISAMBIGUATE, EXPAND, CLARIFY TERMS）。Thompson Sampling算法通过维护每个臂的后验分布，在探索与利用之间动态平衡。该设计的核心改进在于：利用语言特征（如从属结构、领域专业化）作为上下文，使策略能够识别“何时”应用何种重写。例如，当查询包含“领域专业化”特征时，EXPAND策略的奖励权重显著高于SIMPLIFY，因为前者能补充必要的实体上下文，而后者可能切除关键语义。消融实验显示，移除17维特征后，Thompson Sampling的胜率从87.5%降至81.7%，证明语言特征携带了关于最优重写策略的关联信号。

## 实验评估

实验在13个QA基准（16个场景）上进行，基线覆盖静态重写（5种）、非上下文Bandit（3种）及无重写基线，但缺失白盒探针（如SAPLMA）及解码干预（如DoLa）强基线。主结果如下表所示：

| 算法 | 上下文? | 探索调整奖励 (↑) | 累积遗憾 (↓) | 胜率 (%) (↑) |
| :--- | :--- | :--- | :--- | :--- |
| TS (C) | ✓ | 819.04 | 135.84 | 87.5 |
| LinUCB+KL | ✓ | 818.79 | 136.00 | 87.0 |
| EXP3 (NC) | ✗ | 797.47 | 157.31 | 86.5 |
| Paraphrase | – | 732.39 | 222.56 | 44.9 |
| No-Rewrite (B) | – | 729.20 | 225.85 | – |

上下文Thompson Sampling（TS）以819.04的探索调整奖励和87.5%的胜率领先，较静态PARAPHRASE（732.39）提升42.6%。值得注意的是，部分静态策略（如EXPAND，639.25）的累积遗憾高于无重写基线（225.85），表明固定重写可能加剧幻觉。

消融实验聚焦于上下文特征的贡献。移除17维特征后，TS的探索调整奖励从819.04降至754.66（-64.38），胜率从87.5%降至81.7%。在准确率层面，上下文方法在16个场景中赢得8个，线性上下文家族赢得其余8个（LinUCB 4.5, LinUCB+KL 3.5），而非上下文Bandit未在任何数据集上取得最高准确率。这一结果证实，性能增益源于对查询语言指纹的自适应，而非随机探索。

评估边界方面，论文未报告计算效率（如重写延迟），且所有实验基于GPT-4o单一模型，缺乏跨模型泛化性验证。代码未公开，超参数通过网格搜索在验证集上调整，可复现性受限于闭源API的版本稳定性。

## 关联研究分析

从问题动机看，QueryBandits与SelfCheckGPT共享“一致性/正确性”评估思想，但将离线检测转化为在线学习信号。SelfCheckGPT依赖多次采样的一致性作为幻觉指标，计算成本高且无法实时部署；QueryBandits则利用单次LLM-judge评分作为奖励，通过Bandit学习将评估成本摊销到策略优化中。这一差异源于任务特性：SelfCheckGPT旨在检测已生成文本的幻觉，而QueryBandits旨在预防幻觉发生，因此需要低延迟的输入侧干预。

从方法设计看，QueryBandits与DoLa同属黑盒/白盒混合干预，但DoLa依赖解码时层对比（需部分内部访问），而QueryBandits完全依赖输入侧语言特征。DoLa的干预目标由模型内部状态决定，QueryBandits的干预目标由外部语言特征决定。这一差异暗示了两种不同的幻觉成因假设：DoLa假设幻觉源于内部表征的不稳定性，QueryBandits假设幻觉源于查询语义的模糊性。查询侧增强在数据充足时是否仍有增益，论文未给出回答，因为实验仅基于扰动后的查询，未对比原始查询上的性能差异。

## 总结

本文要解决的核心矛盾是闭源模型下幻觉抑制的实时性与适应性需求，现有白盒方法无法访问内部状态，黑盒静态策略无法适应查询多样性。QueryBandits抓住的切入点是语言特征与重写策略之间的关联信号，通过上下文Bandit在线学习实现无梯度干预。方法上，它构建了复合奖励函数并基于17维语言特征进行策略选择，证明了87.5%的查询级胜率。本文的边界在于缺乏与白盒SOTA的公平对比，且实验仅基于单一模型和扰动查询，未验证重写策略在原始查询上的净收益。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
