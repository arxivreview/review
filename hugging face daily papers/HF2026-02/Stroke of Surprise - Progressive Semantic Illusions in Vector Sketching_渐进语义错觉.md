# HuggingFace最新推荐论文 ｜Stroke of Surprise: Progressive Semantic Illusions in Vector Sketching ｜渐进语义错觉

研究机构：国立阳明交通大学

作者：Huai-Hsun Cheng、Siang-Ling Zhang、Yu-Lun Liu

论文原文见 [arXiv](https://arxiv.org/abs/2602.12280)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.12280)

> 矢量草图生成长期面临静态表示与动态语义演变的割裂，传统方法将草图视为最终状态，无法捕捉绘制过程中的语义反转。现有光栅模型依赖破坏性编辑，矢量模型则陷入贪心优化导致的结构冲突，均无法实现前缀笔画对双重语义的兼容。本文提出“渐进语义错觉”任务，通过双分支联合优化框架与叠加损失，在矢量参数空间中寻找满足初始与最终语义的公共结构子空间。该方法在自建基准上实现了100%的覆盖率与最高的语义对齐分数，但其有效性局限于特定对象类别，且缺乏标准基准的交叉验证，泛化能力存疑。

## 研究背景

矢量图形以贝塞尔曲线为基本单元，具备分辨率无关性与可编辑性，是计算机辅助设计与数字艺术的核心输出格式。然而，草图作为人类手绘产物，具有高度抽象性与歧义性，其稀疏笔画需通过时序累积传达复杂语义。理解这一过程的关键在于可微分光栅化技术，它允许梯度从渲染后的像素图像反向传播至矢量参数，使得基于图像空间损失函数的几何优化成为可能。在此基础上，Score Distillation Sampling (SDS) 利用预训练扩散模型作为语义先验，通过噪声预测器引导矢量参数向目标文本语义收敛，解决了传统优化方法缺乏全局语义多样性的问题。

草图生成领域已从基于循环神经网络的单类别建模演进至利用 CLIP 与扩散先验的开放词汇生成。主流路线分为优化派与生成派：优化派依赖可微分渲染与梯度优化，确保几何精度但易产生噪声；生成派通过条件注入提升质量，但常忽略时序约束。视觉错觉研究传统上依赖空间操纵，如多视图一致性或频率分解，要求观察者改变视角以感知隐藏含义。然而，这些方法将草图视为静态像素表示，忽略了绘制过程的时序性，导致无法实现通过笔画累积驱动的语义反转。本文切入点在于将视觉错觉从空间维度拓展至时间维度，提出“渐进语义错觉”任务，要求单一矢量草图在绘制过程中揭示不同的语义解释，解决静态生成中语义单一性与动态演变中结构冲突的矛盾。

## 核心方法

### 方法参照系

本文问题可置于基于扩散先验的矢量图形优化框架下。标准流程为：初始化可学习笔画参数，通过可微分光栅化渲染为图像，利用冻结扩散模型计算 SDS 损失并反向传播更新参数。本文的关键差异在于优化目标从单一语义拟合转向双语义联合优化，且引入了针对空间重叠的几何约束，以解决前缀笔画在双重语义角色下的结构冲突。

### 双分支联合优化

传统序列生成方法采用贪心策略，先优化前缀笔画以匹配初始对象，再追加笔画以匹配最终对象。这种串行优化导致前缀笔画成为最终对象的“语义噪声”，无法形成结构基础。本文提出双分支联合优化框架，同时优化前缀笔画 $S_{prefix}$ 与增量笔画 $S_{delta}$ 的参数 $\theta$。前缀分支渲染 $I_{prefix}$ 并受提示 $p_1$ 引导，全量分支渲染 $I_{full}$ 并受提示 $p_2$ 引导。总损失函数为：

$$ \mathcal{L}_{SDS} = \mathcal{L}_{SDS}^{prefix} + \mathcal{L}_{SDS}^{full} $$

该公式的物理含义是前缀笔画同时接收来自两个不同文本提示的梯度，迫使优化器寻找一个“公共结构子空间”，使得前缀笔画既清晰表达初始对象，又为最终对象提供必要的结构支撑，而非被后续笔画覆盖或冲突。

### 叠加损失与空间协调

纯语义引导无法防止增量笔画对前缀笔画的空间遮挡，导致视觉杂乱。本文引入叠加损失（Overlay Loss）以强制空间互补性。通过高斯模糊 $G_\sigma$ 生成软空间缓冲区，计算前缀与增量渲染图的归一化重叠：

$$ \mathcal{L}_{overlay} = \langle \tilde{I}_{prefix}, \tilde{I}_{delta} \rangle $$

其中 $\tilde{I}$ 为模糊后的图像。该损失惩罚空间重叠，确保增量笔画在结构上整合而非遮挡前缀，从而保证语义转换的连贯性。最终目标函数为 $\mathcal{L} = \mathcal{L}_{SDS} + \lambda_{overlay} \mathcal{L}_{overlay}$，其中 $\lambda_{overlay}=0.1$。这一设计解决了贪心策略中增量笔画随意放置导致的视觉混乱问题，实现了结构整合而非简单叠加。

## 实验评估

实验在自建数据集上进行，包含 64 个常见对象，随机采样配对形成 $(p_1, p_2)$ 组合。基线覆盖光栅模型 Nano Banana Pro 与矢量模型 SketchAgent、SketchDreamer，但缺失纯优化派基线（如 DiffVG 直接应用）及最新 LLM 驱动方法。评估指标包括 CLIP 分数（取各阶段最小值）、结构隐藏度（$C_{struct}$）及语义隐藏度（$C_{semantic}$）。

| 方法 | Phase 1 来源 | CLIP Avg min | $C_{struct}^{CLIP}$ | $C_{semantic}^{CLIP}$ | Coverage (%) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| SketchDreamer | - | 24.803 | -0.393 | 0.011 | 100.0% |
| SketchAgent | - | 24.393 | 0.338 | 0.000 | 100.0% |
| Nano Banana Pro | - | 26.821 | -2.544 | -0.019 | 34.9% |
| Ours (Metric-ranking) | – | 30.044 | 3.282 | 0.029 | 100.0% |

本文方法在 CLIP 分数与结构隐藏度上显著优于基线，覆盖率 100% 对比 Nano Banana Pro 的 34.9%，表明其成功实现了渐进约束。消融实验显示，联合优化相比序列生成能更好地解决结构冲突（如鸭嘴兼作牛耳），而中心初始化策略优于分散初始化，确保笔画聚合。

评估边界方面，指标依赖 CLIP 等预训练模型，可能无法完全反映人类感知的“惊喜”程度。评估协议局限于 64 个对象，缺乏标准基准（如 QuickDraw）的交叉验证，且未报告计算效率细节（仅提及 13-15 分钟/图）。可复现性受限于未公开代码，但超参数（Adam, 2000 迭代, guidance scale 100）已明确。

## 关联研究分析

从问题动机看，本文与 Visual Anagrams 等空间错觉方法形成鲜明对比。后者依赖多视图一致性或频率分解，要求观察者改变视角或关注不同频段以感知隐藏含义，本质上仍是静态像素的操纵。本文则引入时间维度，通过笔画累积实现语义反转，解决了空间方法无法捕捉“绘制过程”语义演变的问题。这一差异源于任务定义的根本不同：空间错觉关注“看哪里”，时间错觉关注“何时看”。然而，本文未探讨空间与时间维度的结合，即是否能在多视图基础上叠加时序语义，这一盲区限制了其在复杂艺术形式中的应用。

从方法设计看，本文与 SketchAgent 等序列矢量模型共享可微分渲染与 SDS 引导的基础设施，但摒弃了贪心策略。SketchAgent 逐步优化笔画，导致前缀固定后无法调整，形成结构冲突；本文通过联合优化动态调整前缀参数，发现公共子空间。这一改进源于对“双约束”问题的识别：前缀需同时满足初始清晰度与最终结构基础。然而，本文未探索 LLM 在笔画规划中的作用，尽管 LLM 在复杂代码生成中已展现潜力，但在几何参数优化中是否比 SDS 更有效地处理语义歧义，论文未给出回答。

## 总结

本文核心矛盾在于矢量草图静态表示与动态语义演变的割裂，现有方法因贪心优化或破坏性编辑无法实现前缀笔画的双重语义兼容。本文抓住“公共结构子空间”这一被忽略的点，通过双分支联合优化与叠加损失，在矢量参数空间中协调初始与最终语义。实验证明其在自建基准上实现 100% 覆盖率与最高 CLIP 分数（30.044），验证了联合优化的有效性。其边界在于局限于 64 个简单对象，复杂结构（如剪刀）优化失败，且缺乏标准基准验证。当对象拓扑复杂度增加时，SDS 引导是否仍能稳定收敛至公共子空间，而非陷入局部最优，论文未给出回答。
