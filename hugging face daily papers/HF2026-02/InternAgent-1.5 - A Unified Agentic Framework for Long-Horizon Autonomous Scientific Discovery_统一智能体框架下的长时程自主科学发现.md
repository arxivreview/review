# HuggingFace最新推荐论文 ｜InternAgent-1.5: A Unified Agentic Framework for Long-Horizon Autonomous Scientific Discovery ｜统一智能体框架下的长时程自主科学发现

作者：Shiyang Feng、Runmin Ma、Xiangchao Yan 等 57 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.08990)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.08990)

> 现有AI科学家系统受限于领域特定架构与线性优化管道，难以在计算与实证双领域维持长时程自主迭代。InternAgent-1.5通过生成、验证、演化三子系统协同，结合图增强蒙特卡洛搜索与结构化认知记忆，构建了跨学科统一框架。该设计在GAIA与HLE等基准上刷新了SOTA，但在湿实验硬件交互与跨机构复现性上仍显薄弱，其通用性是否以牺牲垂直领域深度为代价尚存疑。

## 研究背景

当科研智能体从单一代码生成转向全流程闭环时，上下文窗口的有限性导致早期假设与实验反馈在长时程任务中逐渐丢失。这种信息断裂迫使系统陷入局部最优，而科学发现的本质要求从失败中提炼策略并持续修正。为解决此问题，结构化认知记忆成为维持探索连贯性的关键，它将策略性、程序性与语义性知识分离存储，使智能体能在多轮迭代中保持推理一致性。

AI科学家领域的演进经历了从单点辅助到端到端自主的范式转移。早期如AI Scientist-v1确立了“想法-实验-写作”工作流，但暴露出幻觉与执行错误；DeepScientist引入贝叶斯优化提升资源效率，Kosmos整合世界模型实现数据驱动发现，但二者均局限于特定领域或线性迭代模式。当前系统普遍面临领域特定架构割裂、基础能力覆盖不全及长时程操作支持不足的瓶颈。InternAgent-1.5的切入点在于打破垂直领域壁垒，通过统一架构同时支持算法发现与实证发现，并引入非线性并行优化机制以突破线性管道的探索局限。

## 核心方法

### 三子系统协同架构

本文问题不同于传统单代理线性迭代，其核心差异在于将科研闭环解耦为生成、验证、演化三个功能独立又信息互通的子模块。生成子系统负责基于深度研究构建假设，验证子系统执行多轮并行实验优化，演化子系统则通过记忆机制更新长期策略。这种分工解决了单一代理在长程任务中上下文退化与角色混淆的问题，确保了信息流在假设提出、实证检验与策略修正间的有序传递。

### 图增强蒙特卡洛搜索

传统实验优化依赖线性试错或树状搜索，存在轨迹孤立与历史未利用的缺陷。InternAgent-1.5采用图增强蒙特卡洛搜索（Graph Augmented MCTS），将刚性树结构替换为动态解图，通过四个算子实现跨分支信息流动。其核心优化目标为：

$$ s^* = \arg\max_{s \in S} h(T, s) $$

其中 $h(T, s)$ 表示解 $s$ 在任务 $T$ 上的评估指标。该公式的物理含义是，系统不再局限于父节点的局部调整，而是通过跨分支引用与多分支聚合，从全局解图中提取互补优势，生成混合设计。这一设计解决了线性管道中“一条路径的失败无法警示另一条路径”的失效，使实验优化从独立探索转变为累积式协同收敛。

### 结构化认知记忆

长时程自主操作要求系统区分短期任务状态与长期策略知识。InternAgent-1.5引入策略-程序记忆（SPM）与任务-情景记忆，前者存储可复用的操作策略，后者记录具体任务轨迹。记忆更新机制可形式化为：

$$ M_{t+1} = \mathcal{U}(M_t, \mathcal{E}_t) $$

其中 $\mathcal{U}$ 为更新函数，$\mathcal{E}_t$ 为当前轮次实验证据。该机制将实验反馈转化为持久化知识，避免了重复探索已证伪的策略。设计动机在于解决现有系统缺乏基于错误诊断的策略调整能力，使智能体在代码执行错误或结果异常时能依据历史教训进行自我修复，而非盲目重试或终止。

## 实验评估

实验在GAIA、HLE、GPQA及FrontierScience等基准上评估基础推理能力，并在六个科学算法任务与多个实证发现任务中验证架构有效性。基线覆盖Gemini-3-pro、GPT-5、MiroThinker等前沿模型及专用Agent，但缺失与DeepScientist等同类多智能体系统的直接对比，限制了架构优势的归因分析。

| 基准 | 方法 | 准确率 (%) |
| :--- | :--- | :--- |
| GAIA | InternAgent-1.5 (Gemini-3-pro+o4-mini) | 86.06 |
| GAIA | MiroThinker-v1.5-235B | 80.8 |
| HLE (Text-only) | InternAgent-1.5 | 40.87 |
| HLE (Text-only) | Gemini-3-pro-preview | 34.65 |
| FrontierScience (Olympiad) | InternAgent-1.5 | 77.20 |
| FrontierScience (Olympiad) | DeepSeek-V3.2-Thinking | 64.70 |

在科学算法任务中，InternAgent-1.5在AutoEAP任务上达到0.91的HK-PCC，显著优于DeepSTARR基线的0.65；在AutoPower任务中RMSE降至0.00318，优于SenseFlow的0.00473。消融实验显示，移除策略-程序记忆后，GAIA平均准确率从86.06%降至82.42%，且平均工具调用次数从18.52次增至22.69次，表明记忆机制不仅提升性能，还优化了探索效率。

评估边界受限于湿实验硬件接口的标准化缺失，论文虽提及Wet Lab支持，但未提供跨实验室复现数据。代码已开源，但超参数配置与GPU资源需求未在正文中详述，可能影响结果的可复现性。多数基准未报告置信区间，数值比较需谨慎。

## 关联研究分析

从问题动机看，InternAgent-1.5与Kosmos均旨在突破领域特定架构，但Kosmos侧重通过世界模型组织代谢组学等垂直数据，而本文强调通过统一子系统架构支持算法与实证双领域。这一差异源于任务特性：Kosmos的目标是数据驱动发现，依赖领域先验；本文则追求通用推理能力，依赖结构化记忆与搜索算法。这种取舍导致本文在特定垂直领域（如药物研发）的深度可能不及Kosmos，但在跨学科泛化上更具优势。

从方法设计看，与DeepScientist相比，二者均关注资源效率，但DeepScientist采用贝叶斯优化循环，依赖先验知识进行精准探索；本文采用图增强MCTS，通过跨分支聚合实现非线性并行优化。DeepScientist的贝叶斯方法在低维参数空间效率更高，而本文的图结构搜索在高维、非结构化设计空间中更具扩展性。这种差异暗示，当搜索空间维度增加且缺乏强先验时，图结构搜索可能优于贝叶斯优化，但其在计算成本上的可控性论文未给出量化分析。

## 总结

InternAgent-1.5旨在解决AI科学家系统在跨学科长时程自主发现中的架构割裂与记忆缺失矛盾。其切入点在于通过生成、验证、演化三子系统协同，结合图增强MCTS与结构化认知记忆，实现了计算与实证领域的统一框架。实验证明该架构在GAIA基准上达到86.06%准确率，在AutoEAP任务中HK-PCC达0.91，显著优于基线。然而，论文未提供与DeepScientist等同类系统的直接对比，且湿实验硬件交互细节缺失，限制了通用性结论的普适性。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
