# HuggingFace最新推荐论文 ｜REDSearcher: A Scalable and Cost-Efficient Framework for Long-Horizon Search Agents ｜双约束任务合成与低成本中期训练框架

论文原文见 [arXiv](https://arxiv.org/abs/2602.14234)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.14234)

> 深度研究智能体在长程搜索中面临监督信号极度稀疏的瓶颈，现有方法因高质量任务合成困难与交互轨迹采集成本高昂而难以规模化。REDSearcher 将任务生成形式化为图拓扑与证据分散的双重约束优化，并引入分阶段中期训练与本地模拟环境，以低成本实现长程搜索策略的端到端强化学习。该框架在30B参数级开源模型中确立了性能基准，但其依赖静态合成数据的策略在动态真实网络环境中的泛化边界尚存疑。

## 研究背景

长程搜索任务要求智能体在开放环境中迭代获取证据、维持竞争假设并综合多源信息，这区别于依赖单次静态检索的检索增强生成（RAG）。此类任务的核心难点在于推理结构的复杂性，即智能体需处理非线性约束与分散证据，而非简单的线性推导。

当前主流路线分为架构派与训练派。架构派通过多智能体协作显式管理记忆与规划，但系统复杂度高；训练派（如 Search-R1）依赖大规模强化学习优化策略，但受限于高质量长程轨迹的稀缺性。现有开源数据集多为线性、检索友好的任务，无法驱动智能体进化出应对复杂约束的能力，导致训练效率低下。

REDSearcher 的切入点在于解决“数据供给侧”的瓶颈。它不直接优化模型架构，而是通过控制任务生成的结构复杂度与证据分布，主动制造高难度训练样本，从而降低强化学习对海量真实交互轨迹的依赖，实现可控且低成本的长程搜索能力优化。

## 核心方法

### 方法参照系

本文置于智能体强化学习路线中，但前置了任务合成与中期训练环节。标准流程直接基于现有数据进行 RL 训练，而本文的关键差异在于通过图论约束主动合成高树宽（treewidth）任务，并引入模拟环境替代真实 API 调用，以解决监督信号稀疏与采集成本高的问题。

### 双约束任务合成

传统 QA 数据集多为线性结构，导致智能体可通过单页捷径解题，无法训练跨文档综合能力。REDSearcher 将任务生成建模为约束满足问题，通过控制知识图的树宽（$tw(G)$）与最小源分散度（MSD）来定义难度。

$$
tw(G) = \min_{\text{decompositions}} \max_{i \in I} |X_i| - 1
$$

该公式定义了图 $G$ 的树宽，即所有树分解中最大袋（bag）大小减一的最小值。树宽越高，变量间的耦合越强，智能体需同时维持更多竞争假设，从线性传播转向高维约束满足。

$$
MSD = \min_{S \subseteq W} |S| \quad \text{s.t.} \quad \text{Cover}(S, G)
$$

MSD 衡量覆盖推理图 $G$ 所需的最少文档数。通过强制逻辑耦合事实分散在不同源中，该约束消除了单页捷径，迫使智能体进行迭代规划与跨文档综合，从而在训练阶段密集化学习信号。

### 成本高效中期训练与模拟环境

直接进行 RL 训练样本效率低，且真实 API 调用延迟高、成本大。REDSearcher 采用两阶段中期训练：第一阶段通过合成数据强化意图锚定接地与层级规划等原子技能；第二阶段引入模拟工具循环与长程轨迹，捕捉环境反馈。

$$
\mathcal{L}_{\text{mid}} = \mathcal{L}_{\text{grounding}} + \lambda \mathcal{L}_{\text{planning}} + \mu \mathcal{L}_{\text{interaction}}
$$

该损失函数分阶段加权，先优化静态推理能力，再引入交互反馈。配合本地模拟环境，该环境保证证据存在但物理分散于干扰文档中，实现了高吞吐量的 RL 迭代，显著降低了高质量轨迹采集的计算与时间成本。

## 实验评估

REDSearcher 在 GAIA、BrowseComp 等基准上对比了闭源（GPT-5, Gemini）与开源（Tongyi, WebSailor）智能体。基线覆盖全面，但缺失纯提示工程基线，可能高估训练带来的增益。

| 模型 | 参数规模 | GAIA | BrowseComp | Overall |
| :--- | :--- | :--- | :--- | :--- |
| REDSearcher | 30B-A3B | 80.1 | 42.1 | 51.6 |
| Tongyi DeepResearch-30B | 30B-A3B | 70.9 | 43.4 | 48.5 |
| GPT-5-Thinking-high | - | 76.7 | 54.9 | 59.1 |
| Gemini-3-Pro | - | 74.8 | 37.8 | 52.5 |

REDSearcher 在 30B 级开源模型中 Overall 得分 51.6，超越 Tongyi 的 48.5，GAIA 得分 80.1 甚至超过 GPT-5 的 76.7，但 BrowseComp 得分 42.1 低于 GPT-5 的 54.9，显示其在特定长程导航任务上仍有差距。

| 阶段 | BrowseComp | GAIA | Average |
| :--- | :--- | :--- | :--- |
| Base | 34.74 | 77.43 | 42.81 |
| Stage I. Planning | 36.97 | 80.83 | 44.75 |
| Stage II. Agentic | 40.44 | 79.13 | 47.39 |

消融实验显示，Stage I 的层级规划使 GAIA 提升 4.13 分，验证了目标分解对复杂推理的关键作用；Stage II 的交互训练使 BrowseComp-ZH 提升 8.91 分，表明环境反馈对长程目标一致性至关重要。RL 训练后，平均工具调用次数从 100.6 降至 90.1，降幅 10.4%，且奖励未降，证明模型学会了更高效的搜索策略。

评估边界方面，论文未报告置信区间，GAIA 高分可能受特定子集或协议影响。代码与 10K 轨迹已承诺开源，但模拟环境与真实 Web 的分布偏移未量化，可能影响策略在动态环境中的鲁棒性。

## 关联研究分析

从问题动机看，REDSearcher 与 ASearcher 均致力于解决长程搜索的稀疏奖励问题，但 ASearcher 依赖大规模端到端 RL 挖掘模型潜力，而 REDSearcher 通过图拓扑控制主动合成高难度任务。差异根源在于对数据质量的假设：ASearcher 假设模型可通过海量交互自发现策略，REDSearcher 则认为需通过结构约束预先定义难度，以避免模型陷入局部最优。

从方法设计看，REDSearcher 与 ABSeeker 互补。ABSeeker 侧重步骤级信用分配，通过答案回溯细化奖励信号；REDSearcher 侧重任务结构复杂度，通过树宽与 MSD 控制推理负载。ABSeeker 解决“如何评估每一步贡献”，REDSearcher 解决“如何生成需要多步贡献的任务”。二者结合可能进一步提升长程决策质量，但论文未探索这种组合效应。

## 总结

REDSearcher 针对长程搜索中监督信号稀疏与轨迹采集成本高的矛盾，通过双约束任务合成与低成本中期训练，实现了 30B 级开源模型在 GAIA 上 80.1 分与 Overall 51.6 分的性能突破。其边界在于依赖静态合成数据，模拟环境与真实 Web 的动态差异未量化，可能导致策略在复杂真实场景中泛化受限。当真实网络环境出现大规模动态变化时，基于静态图拓扑合成的任务是否仍能保持足够的训练有效性，论文未给出回答。
