# HuggingFace最新推荐论文 ｜Demo-ICL: In-Context Learning for Procedural Video Knowledge Acquisition ｜演示驱动的视频上下文学习

研究机构：新加坡南洋理工大学、香港中文大学

作者：Yuhao Dong、Shulin Tian、Shuai Liu 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.08439)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.08439)

> 视频理解模型长期依赖静态内部知识回答事实性问题，无法从新演示中习得程序性技能并迁移至新场景。现有基准缺乏对“从上下文学习”能力的评估，导致模型在需要动态知识获取的任务上表现失效。本文提出演示驱动的视频上下文学习（Demo-driven Video In-Context Learning, Demo-driven ICL）任务及基准，通过两阶段训练策略增强模型从视频/文本演示中抽象步骤逻辑的能力。该工作填补了视频模态上下文学习的评估空白，但其在通用视频理解任务上的性能未超越当前最优模型，且未验证与强化学习后训练路线的优劣对比。

## 研究背景

当模型面对“加热油后下一步做什么”这类问题时，若答案依赖于特定食谱的步骤序列而非通用常识，模型必须从给定的演示中提取程序性知识。这要求模型具备上下文学习（In-Context Learning, ICL）能力，即在不更新参数的前提下，通过条件化输入示例适应新任务。然而，视频模态的ICL面临独特挑战：演示与目标视频间的时序对齐、动作抽象以及跨视频的知识迁移，远超文本或图像ICL的复杂度。

视频问答（Video Question Answering, VQA）领域的主流路线聚焦于时空接地与多步推理，通过强化学习可验证奖励（RLVR）提升逻辑一致性，或引入智能体工具增强长视频证据检索。这些方法假设模型已具备足够的内部知识，仅需优化推理路径或证据定位。然而，当任务要求模型学习全新的操作流程（如特定版本的墨西哥米饭烹饪步骤）时，内部知识失效，模型必须依赖上下文演示。现有基准如Video-MME主要评估基于内部知识或可见事实的回答，缺乏对“从演示中学习并迁移”能力的系统评估，导致模型在程序性知识获取场景下的真实能力被高估。

本文切入点在于重构VQA任务范式，从“基于内部知识回答”转变为“基于上下文演示回答”。通过定义演示驱动的视频ICL任务，本文迫使模型显式利用演示中的步骤逻辑，而非依赖预训练知识。这一设计直接针对机器人学习、教育视频理解等需要动态技能获取的应用场景，揭示了当前多模态大语言模型（MLLMs）在程序性知识内化与迁移上的根本局限。

## 核心方法

### 方法参照系

本文问题属于视频上下文学习范畴，但区别于传统ICL仅使用文本或图像示例，本文引入视频演示作为上下文，并增加演示选择子任务。标准ICL流程中，模型通过条件化示例适应新任务，但视频模态需额外解决时序对齐与动作抽象问题。本文的关键差异在于：演示不仅是参考，更是知识来源，模型需从演示中抽象出通用步骤逻辑并应用于新视频。

### 演示驱动任务定义

传统VQA任务中，模型基于内部知识或目标视频可见事实回答，无需从外部演示中学习。本文定义三个子任务：文本演示ICL、视频演示ICL和演示选择。在视频演示ICL中，模型需从演示视频 $V_D$ 中抽象步骤序列，并应用于目标视频 $V_{Test}$ 的后续步骤预测。形式化表示为：给定演示 $V_D$、目标视频片段 $V_{Test}[0, t_1]$ 和问题 $Q$，模型生成答案 $A$，其中 $A$ 依赖于从 $V_D$ 中提取的步骤逻辑。这一设计迫使模型执行跨视频的时序对齐与知识迁移，而非简单的视觉检索。

### 信息辅助偏好优化

标准直接偏好优化（Direct Preference Optimization, DPO）依赖高质量偏好对，但当前模型在视频ICL任务上生成响应质量低，导致传统DPO数据构建管线失效。本文提出信息辅助DPO，通过自动生成的辅助信息 $I$ 简化任务，提升偏好对质量。偏好分布建模为：

$$
p^*(y_c > y_r | x, I) = \sigma(r^*(x, y_c, I) - r^*(x, y_r, I))
$$

其中 $y_c, y_r$ 分别为优选与劣选响应，$r^*$ 为奖励模型。通过最小化负对数似然训练奖励模型，利用辅助信息（如文本演示中的视频时间戳、视频演示中的文本指导）生成高质量优选响应。这一设计解决了视频ICL中响应生成困难的问题，使模型能从高质量偏好对中有效学习演示驱动的知识迁移能力。

## 实验评估

实验在Demo-ICL-Bench（1,200个问题）及通用基准VideoMME、VideoMMMU上进行。基线覆盖专有模型（GPT-4o, Gemini-2.5-Pro）和开源视频MLLMs（Qwen2.5-VL, InternVL-3, Video-R1等），但未包含专用视频推理模型如Video-Thinker在ICL任务上的对比。

| 模型 | 大小 | 帧数 | 文本演示ICL (Demo Acc / w/o Demo / ΔICL) | 视频演示ICL (Demo Acc / w/o Demo / ΔICL) | 演示选择 (Avg / S.Acc / Acc) |
|---|---|---|---|---|---|
| Gemini-2.5-Pro | - | - | 54.4 / 36.2 / - | 38.9 / 34.9 / - | - |
| Qwen2.5-VL | 7B | 32 | 30.2 / 29.0 / +1.2 | 44.5 / 20.5 / - | 25.0 / 26.2 / 27.0 |
| Video-R1 | 7B | 32 | 27.4 / 26.6 / +0.8 | 52.0 / 18.5 / - | 27.0 / - / - |
| Demo-ICL | 7B | 32 | 43.4 / 29.4 / +14.0 | 32.0 / 27.6 / +4.4 | 58.0 / 24.0 / 33.1 |

Demo-ICL在文本演示ICL上以43.4的准确率领先，较Qwen2.5-VL的30.2高出13.2个百分点，ΔICL达+14.0，表明演示显著提升了模型性能。在视频演示ICL上，Demo-ICL的32.0低于Video-R1的52.0，但ΔICL为+4.4，显示演示对视频模态的增益有限。

| 设置 | 文本ICL | 视频ICL | 演示选择 | 平均 |
|---|---|---|---|---|
| 无教学视频 | 34.0 | 26.2 | 19.0 | 26.4 |
| Demo-ICL (SFT) | 38.4 | 29.4 | 21.5 | 29.8 |
| 标准DPO | 40.0 | 30.0 | 22.0 | 30.7 |
| Demo-ICL (DPO) 1轮 | 41.8 | 30.8 | 22.5 | 31.7 |
| Demo-ICL (DPO) | 43.4 | 32.0 | 24.0 | 33.1 |

消融显示，引入教学视频SFT使平均准确率从26.4提升至29.8，信息辅助DPO较标准DPO提升2.4个百分点。迭代DPO训练带来边际收益递减，从1轮到最终提升1.4个百分点。

评估边界方面，Demo-ICL-Bench仅包含1,200个问题，样本量较小，统计显著性未报告。通用基准上，Demo-ICL在VideoMME上取得65.2/69.7（无字幕/有字幕），低于CoVER的70.3，表明ICL训练未提升通用视频理解能力。代码已开源，但超参数与GPU配置未在论文中详细披露，可复现性受限。

## 关联研究分析

从问题动机看，本文与Video-R1等RLVR方法形成对比。RLVR通过可验证奖励优化推理轨迹，假设模型已具备内部知识，仅需提升逻辑一致性。本文则针对内部知识失效的场景，要求模型从演示中学习新技能。这一差异源于任务特性：RLVR适用于因果推理等需要逻辑一致性的任务，而Demo-driven ICL适用于程序性知识获取等需要动态适应的任务。论文未验证DPO在视频ICL中是否优于RLVR，这一对比缺失限制了方法选择的指导意义。

从方法设计看，本文与VideoMMMU等知识获取基准存在关联。VideoMMMU评估模型从教育视频中学习知识的能力，但主要依赖内部知识或简单检索。本文通过演示选择子任务，要求模型从候选池中识别相关演示，模拟真实场景中的检索与选择过程。这一设计更接近人类学习行为，但增加了任务复杂度。论文未探索演示检索机制的优化，如基于语义相似度的自动检索，这可能影响模型在大规模演示库中的表现。

## 总结

本文核心矛盾在于视频模型依赖静态内部知识，无法从新演示中习得程序性技能。切入点在于重构VQA任务，要求模型显式利用上下文演示，通过信息辅助DPO解决视频ICL中响应生成困难的问题。方法上，提出演示驱动的视频ICL任务及两阶段训练策略，证明了模型能从演示中抽象步骤逻辑并迁移至新视频。核心数字显示，Demo-ICL在文本演示ICL上较基线提升13.2个百分点，ΔICL达+14.0。边界在于，视频演示ICL性能低于Video-R1，且通用基准上未超越SOTA，表明ICL训练未提升通用视频理解能力。当演示库规模扩大至数千个视频时，演示选择子任务的准确率是否随检索机制优化而提升，论文未给出回答。
