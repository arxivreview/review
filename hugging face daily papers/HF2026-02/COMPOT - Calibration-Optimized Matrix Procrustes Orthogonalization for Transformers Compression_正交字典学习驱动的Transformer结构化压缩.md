# HuggingFace最新推荐论文 ｜COMPOT: Calibration-Optimized Matrix Procrustes Orthogonalization for Transformers Compression ｜正交字典学习驱动的Transformer结构化压缩

作者：Denis Makhov、Dmitriy Shopkhoev、Magauiya Zhussip 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.15200)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.15200)

> 后训练压缩旨在通过降低模型参数量与计算复杂度来缓解大模型部署瓶颈，其核心矛盾在于低秩分解的单一子空间假设与权重矩阵列向量分布的局部异质性之间的冲突。现有SVD方法因强制所有列共享同一基向量而在中等压缩比下精度崩塌，而稀疏字典学习虽能捕捉子空间并集结构，却受限于K-SVD等迭代算法在十亿参数规模下的计算不可行性。本文提出COMPOT，通过强制字典正交性将字典更新转化为闭式Procrustes问题，并引入全局奇异值池化实现一次性动态压缩比分配。该方法在多个架构上显著优于SVD基线，但其正交约束在高压缩比下是否限制了表达力，以及校准数据分布偏移对闭式解稳定性的影响，仍需进一步验证。

## 研究背景

Transformer权重矩阵的冗余性表现为不同投影层对下游任务贡献的不均匀性，这为后训练压缩提供了空间。然而，直接截断SVD奇异值假设所有列向量位于同一低维子空间，当权重列分布呈现局部簇状结构时，单一基向量无法有效拟合，导致重构误差随压缩比增加而急剧上升。稀疏字典学习通过为每列分配不同的原子子集，构建了子空间并集模型，理论上能更灵活地捕捉这种异质性，但传统K-SVD算法需迭代更新字典原子与稀疏系数，在大规模模型上计算成本过高。

低秩因子化与稀疏字典学习构成了Transformer压缩的两大主流路线。SVD-LLM等方法通过白化校准优化截断损失，但在CR 0.2时Llama3-8B的WikiText-2困惑度仍达41.0，表明单一子空间假设的固有局限。CoSpaDi引入校准引导的稀疏字典学习，虽在精度上优于SVD基线，但其依赖的K-SVD迭代过程在十亿参数模型上耗时过长，限制了实际部署。本文切入点在于利用正交字典的数学性质，将字典更新与稀疏编码均转化为闭式解，从而在保持子空间并集灵活性的同时，消除迭代优化带来的计算瓶颈。

## 核心方法

### 方法参照系

本文问题属于后训练结构化压缩范畴，标准流程为：利用少量校准数据计算权重矩阵的低秩或稀疏近似，以最小化功能输出误差。与SVD截断不同，本文采用稀疏字典学习框架，将权重矩阵分解为字典与稀疏系数乘积，关键差异在于通过正交约束实现闭式优化，而非依赖迭代求解。

### 正交字典闭式优化

传统稀疏字典学习中，字典更新需通过K-SVD迭代调整原子，计算复杂度随模型规模线性增长。本文强制字典$D_O \in \mathbb{R}^{m \times k}$满足正交性$D_O^\top D_O = I_k$，其中$k \le m$。在此约束下，固定稀疏系数$S_O$时，字典更新转化为正交Procrustes问题：

$$D_O = \arg\min_{D_O^\top D_O = I_k} \|W_{whitened} - D_O S_O\|_F^2$$

该问题的解可通过$W_{whitened} S_O^\top$的SVD分解闭式获得，完全替代了K-SVD的原子级迭代。同时，固定$D_O$时，稀疏编码退化为逐列硬阈值操作，保留每列$s$个最大幅值元素。这一设计动机在于：正交性虽限制了字典的过完备性，但将优化问题从非凸迭代转化为凸闭式解，使得在十亿参数模型上实现高效压缩成为可能，解决了CoSpaDi等方法在大规模模型上的计算不可行性问题。

### 全局奇异值池化分配

Transformer不同投影层冗余度差异显著，统一压缩比往往导致敏感层过度压缩或冗余层压缩不足。本文提出一次性全局分配策略：首先对每个权重矩阵$W_i$进行Frobenius范数归一化，计算其薄SVD奇异值；然后将所有矩阵的奇异值池化为全局多重集，按升序排列并截断最小值以满足模型级压缩预算。每矩阵被截断的奇异值数量即为其压缩比。该策略通过约束防止负压缩与过度压缩，避免了SVD-LLM V2等方法中基于截断损失建模的迭代搜索过程。设计动机在于：归一化消除了不同层谱量级差异，全局池化实现了跨层预算的最优分配，使压缩过程从启发式迭代转变为确定性一次性计算，提升了方法的可复现性与部署效率。

## 实验评估

实验在Llama、OPT、Qwen系列模型（0.6B–30B）上进行，覆盖语言、视觉-语言、音频任务，压缩比CR 0.2–0.6。基线包括SVD-LLM、SVD-LLM V2、Dobi-SVD、CoSpaDi及结构化剪枝方法。校准数据为256条RefinedWeb序列（长度1024）。主实验显示，在Llama3-8B CR 0.2下，COMPOT静态分配取得64.5%平均准确率与13.0 WikiText-2困惑度，显著优于SVD-LLM的54.1%与41.0，以及CoSpaDi的61.8%与20.0。

| 方法 | CR | Avg. Acc. (%) | WikiText-2 PPL |
| :--- | :--- | :--- | :--- |
| SVD-LLM | 0.2 | 54.1 | 4.1E+01 |
| CoSpaDi | 0.2 | 61.8 | 2.0E+01 |
| COMPOT† | 0.2 | 64.5 | 1.3E+01 |

消融实验表明，SVD初始化相比随机初始化在20次迭代内将平均准确率从46.3%提升至48.5%（静态）和49.1%（动态）。全局池化分配（All grouped）相比逐层独立分配（All indiv.）将平均准确率从48.5%提升至50.1%，WikiText-2困惑度从24.62降至20.71。迭代次数方面，随机初始化需约300次迭代收敛，而SVD初始化在约100次即饱和，本文采用20次迭代作为精度-时间折中。

| 初始化/分组策略 | Avg. Acc. (%) | WikiText-2 PPL |
| :--- | :--- | :--- |
| Static + Random Init | 46.3 | 26.84 |
| Static + SVD Init | 48.5 | 24.67 |
| Dynamic + SVD Init + All indiv. | 48.5 | 24.62 |
| Dynamic + SVD Init + All grouped | 50.1 | 20.71 |

评估边界方面，论文未报告置信区间，且SVD-LLM V2的复现结果与原文存在显著差异（Llama3-8B CR 0.2下，原文PPL 8.01 vs 复现47.58），提示基线实现细节对结果影响较大。代码已开源，但校准数据多样性对闭式解稳定性的影响未充分探讨。

## 关联研究分析

从问题动机看，COMPOT与SmoothQuant等量化方法同属后训练压缩，但目标函数不同：量化关注数值精度截断，本文关注矩阵结构稀疏化。SmoothQuant通过离线缩放迁移激活异常值至权重，解决W8A8量化精度崩塌；本文通过白化空间重构误差最小化，解决低秩分解的子空间假设失效。两者均依赖校准数据，但本文的白化步骤（Cholesky分解）在数学形式上与SmoothQuant的缩放重参数化高度相似，均为消除分布偏差，但本文将其应用于字典学习而非量化参数优化。

从方法设计看，COMPOT与ButterflyQuant均利用正交变换，但目的截然不同：ButterflyQuant通过可学习正交旋转分散激活异常值，提升W4A4量化鲁棒性；本文通过正交字典约束实现闭式Procrustes更新，解决稀疏字典学习的计算瓶颈。这一差异源于任务特性：量化需保持分布均匀性，而结构化压缩需优化重构误差。正交约束在量化中是分布治理手段，在本文中则是计算效率工具，这种双重角色揭示了正交变换在不同压缩范式中的不同数学意义。

## 总结

COMPOT旨在解决低秩分解单一子空间假设与权重列异质性分布之间的冲突，以及稀疏字典学习迭代优化在大规模模型上的计算不可行性。其切入点在于利用正交字典的数学性质，将字典更新与稀疏编码均转化为闭式解，从而在保持子空间并集灵活性的同时消除迭代开销。方法通过正交Procrustes更新与全局奇异值池化分配实现高效压缩，在Llama3-8B CR 0.2下取得64.5%平均准确率与13.0 WikiText-2困惑度，显著优于SVD-LLM的54.1%与41.0。然而，正交约束限制了字典的过完备性，在高压缩比（CR 0.6）下精度下降幅度是否大于非正交基线，论文未提供直接对比。当压缩比进一步降低时，正交字典的表达力瓶颈是否会成为精度上限的决定因素，仍需更系统的实验验证。
