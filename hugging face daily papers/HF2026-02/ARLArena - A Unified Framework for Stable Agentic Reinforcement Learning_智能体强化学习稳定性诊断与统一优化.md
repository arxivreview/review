作者：Xiaoxuan Wang、Han Zhang、Haixin Wang 等 14 人

> 智能体强化学习（Agentic Reinforcement Learning, ARL）旨在通过多轮环境交互提升大语言模型（Large Language Models, LLMs）的长程决策能力，但训练过程极易因策略更新失控而崩溃。现有方法往往孤立调整超参数或损失函数，缺乏对崩溃微观机制的系统归因，导致算法改进缺乏理论指导且难以复现。本文提出 ARLArena 框架，将策略梯度解耦为四个正交维度进行消融，并基于诊断结果构建统一优化算法 SAMPO。该工作揭示了重要性采样裁剪策略是稳定性的核心瓶颈，为 ARL 提供了可复现的基线与稳定训练范式，但其结论主要局限于单智能体场景，多智能体协同下的稳定性边界尚不明确。

## 研究背景

当 LLM 作为智能体在 Web 导航或具身环境中执行多步任务时，早期决策的微小偏差会随交互轮次累积，导致后续状态分布发生剧烈偏移。这种非平稳性使得基于单轮生成假设的策略梯度估计失效，具体表现为重要性采样（Importance Sampling, IS）比率分布偏离正常范围，进而引发梯度爆炸与策略崩溃。理解这一机制的关键在于区分“探索不足”与“更新失控”：前者源于奖励稀疏，后者则源于优化算法对多轮轨迹中异常 IS 比率的容忍度不当。

ARL 领域长期面临训练不稳定与结果不可复现的困境，主流研究多聚焦于信用分配机制（如树搜索）或系统架构优化（如异步解耦），却忽视了策略优化算法本身在多轮交互中的适配性。GRPO 等基线算法在静态推理任务中表现优异，但在多轮智能体场景中，其 Token 级 IS 裁剪策略无法有效抑制负优势序列中低 IS 比率带来的噪声，导致训练中期出现熵坍缩。本文切入点在于将 ARL 策略梯度形式化分解为损失聚合、IS 裁剪、轨迹过滤与优势设计四个维度，通过正交消融定位崩溃根源，而非盲目堆叠技巧。

## 核心方法

### 策略梯度维度解耦

ARL 的策略梯度可分解为四个正交设计维度：损失聚合（Loss Aggregation）、IS 裁剪、轨迹过滤与优势设计。标准 GRPO 采用 Token 级 IS 裁剪与组内相对优势，但在多轮交互中，Token 级裁剪对长序列中的异常比率缺乏全局约束。本文构建标准化测试床，通过行为克隆初始化、格式惩罚与 KL 正则化建立稳定基线，随后独立评估各维度对训练稳定性的影响，以隔离单一因素的作用。

### 序列级裁剪与崩溃机制

传统 IS 裁剪在 Token 层面限制比率变化，但多轮轨迹中负优势序列常伴随极低的 IS 比率，Token 级裁剪无法阻断这些异常 Token 对梯度的污染。本文发现，宽容裁剪（Tolerant Clipping）虽能加速早期收敛，但会导致负优势序列中低 IS 比率 Token 的累积，引发梯度范数爆炸。序列级裁剪（Sequence-level Clipping）通过计算整条轨迹的几何平均 IS 比率 $s_i = \exp\left(\frac{1}{|T_i|}\sum_{t=0}^{|T_i|-1} \log \frac{\pi_\theta(y_t|x, y_{<t})}{\pi_{\theta_{old}}(y_t|x, y_{<t})}\right)$ 进行全局约束，有效抑制了异常轨迹对策略更新的干扰，确保 KL 散度与梯度范数在训练全程保持稳定。

### 细粒度优势与动态过滤

仅依赖序列级裁剪不足以解决稀疏奖励下的信用分配问题。本文引入状态级优势设计，将同一环境状态下的动作分组计算相对优势，细化梯度信号。同时，动态过滤机制剔除全对或全错的轨迹组，避免零梯度样本浪费计算资源。然而，动态过滤与优势设计存在强耦合：若优势信号多样性不足（如标准 GRPO），过滤会削弱格式学习信号，导致行为不稳定；而结合细粒度优势（如 GIGPO）后，过滤能显著提升有效样本比例，实现稳定性与性能的双重增益。

## 实验评估

实验在 ALFWorld、WebShop、Sokoban 及 TIR Math 四个智能体任务上进行，基线模型为 Qwen3-4B。对比方法覆盖 GRPO、GSPO、CISPO、SAPO、GIGPO、EMPG 及 DAPO，但未包含 Tree-GRPO 等树搜索类方法，限制了与复杂信用分配机制的直接对比。

| 方法 | ALFWorld Success | WebShop Success | Sokoban Success | TIR Math Avg |
| :--- | :--- | :--- | :--- | :--- |
| GRPO | 62.36 | 57.71 | 83.90 | 48.08 |
| GSPO | 78.61 | 72.48 | 82.22 | 52.28 |
| GIGPO | 81.09 | 56.55 | 82.67 | 49.71 |
| SAMPO | 92.72 | 77.73 | 88.86 | 60.21 |

SAMPO 在 ALFWorld 上取得 92.72% 成功率，较 GRPO 基线提升 48.7%，在 TIR Math 上平均得分 60.21，较基线提升 25.2%。GSPO 虽优于 GRPO，但在 WebShop 上仅提升 14.77 个点，而 SAMPO 提升 20.02 个点，表明单一维度优化存在性能天花板。

消融实验显示，IS 裁剪策略对稳定性影响最大。CISPO 与 SAPO 采用宽容裁剪，在 ALFWorld 上成功率分别降至 25.16% 与 0.80%，伴随训练崩溃；而引入序列掩码（Sequence Masking）后，CISPO 成功率回升至 78.88%，SAPO 回升至 76.92%，接近 GSPO 水平。动态过滤在标准 GRPO 上导致性能下降（ALFWorld 从 62.36% 降至 49.58%），但在 GIGPO 上提升至 60.55%，证实了优势设计与过滤机制的耦合效应。

评估协议采用 Pass@4 与成功率指标，未报告置信区间，且未涵盖多智能体协作场景。代码与模型已开源，超参数网格搜索细节见附录，但不同任务间的超参数敏感性差异较大，复现时需严格遵循各任务的特定配置。

## 关联研究分析

从问题动机看，本文聚焦单智能体策略优化的稳定性，而 Stronger-MAS 等多智能体框架通过角色专业化解决信用分配问题，两者在 ALFWorld 上的性能差距（92.72% vs 99.5%）可能源于协作机制带来的探索多样性，而非单纯算法稳定性。本文未探索多智能体场景下的 IS 裁剪策略，序列级裁剪在分布式策略更新中是否仍能有效抑制梯度噪声，缺乏实证支持。

从方法设计看，本文与 GSPO 共享序列级裁剪思想，但 GSPO 未结合细粒度优势与动态过滤，导致其在 WebShop 等复杂导航任务上增益有限。本文揭示的“优势多样性决定过滤有效性”机制，解释了为何 DAPO 在数学推理任务上表现良好，却在智能体任务中失效——数学任务的奖励信号天然具有多样性，而智能体任务的格式学习依赖早期密集信号，过滤会破坏这一过程。

## 总结

ARL 训练崩溃的核心矛盾在于多轮交互中 IS 比率分布偏移与策略更新稳定性的冲突。现有方法孤立调整超参数，无法阻断负优势序列中低 IS 比率 Token 的梯度污染。本文通过维度解耦诊断，提出 SAMPO 统一框架，结合序列级裁剪、细粒度优势与动态过滤，在 ALFWorld 上实现 92.72% 成功率，较 GRPO 提升 48.7%。其边界在于结论局限于单智能体场景，且动态过滤与优势设计的耦合机制在多智能体协同中是否成立，论文未给出回答。当智能体数量增加导致策略空间维度扩张时，序列级裁剪的全局约束是否仍能维持梯度稳定性，是后续研究需验证的关键问题。
