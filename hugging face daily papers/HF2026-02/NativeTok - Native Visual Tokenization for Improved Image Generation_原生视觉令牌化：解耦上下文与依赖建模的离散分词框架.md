# HuggingFace最新推荐论文 ｜NativeTok: Native Visual Tokenization for Improved Image Generation ｜原生视觉令牌化：解耦上下文与依赖建模的离散分词框架

论文原文见 [arXiv](https://arxiv.org/abs/2601.22837)

> 视觉生成领域长期面临“重构保真度与生成质量非单调”的困境，即高重构指标并不必然带来高生成指标。现有离散分词器仅优化像素重构，导致令牌序列缺乏内在因果结构，迫使生成模型从无序分布中学习，造成建模偏差。NativeTok 提出“原生视觉令牌化”，在分词阶段通过混合因果专家 Transformer 显式约束令牌间的依赖关系，实现分词与生成阶段的耦合。该框架在低令牌预算下显著提升了自回归生成质量，但其高令牌预算下的性能优势及因果约束对全局语义表达的潜在限制尚存疑。

## 研究背景

当自回归模型尝试预测下一个视觉令牌时，其性能上限受制于前序令牌序列的分布特性。若分词器仅以重构损失为监督信号，生成的令牌序列在统计上是“无序”的，即令牌间缺乏显式的因果依赖约束。这种无序性导致生成模型难以准确捕捉视觉信息的内在结构，进而产生有偏且不完整的分布估计。为解决此问题，需引入一种机制，在分词阶段即建立令牌间的因果顺序，使分词输出天然适配生成阶段的序列建模需求。

离散视觉令牌化旨在将高维像素映射为紧凑的离散表示，以支持高效的自回归或掩码生成。主流路线如 VQGAN 和 TiTok 侧重于提升压缩率或重构质量，但均将分词与生成视为独立阶段，分别优化重构损失和令牌分布损失。这种解耦设计忽略了分词阶段建立的令牌关系对生成阶段建模难度的直接影响。NativeTok 的切入点在于论证视觉信息本身遵循从全局结构到局部细节的因果顺序，并提出在分词过程中显式建模这种顺序，从而弥合分词与生成之间的鸿沟。

## 核心方法

### 方法参照系

传统离散分词器遵循“编码器-量化-解码器”流程，编码器独立优化重构，量化层将连续特征映射至码本，解码器重建图像。本文的关键差异在于，它不再将分词视为独立的压缩任务，而是将其重构为包含因果依赖建模的序列生成过程，使得分词输出直接具备生成所需的结构特性。

### 元图像 Transformer 与维度切换

设计动机在于解决单一 Transformer 同时处理图像自建模和令牌生成时的容量冲突。NativeTok 引入元图像 Transformer（MIT），首先通过双向注意力捕获图像的全局上下文表示 $X_{latent}$。随后，通过一个全连接网络作为维度切换器，将高维上下文压缩至低维潜空间。这一设计将复杂的图像内容建模与后续的令牌依赖建模解耦，确保每个令牌生成步骤都能自适应地访问完整的全局图像信息，而不受序列生成过程的干扰。

### 混合因果专家 Transformer

设计动机在于克服简单因果掩码在令牌生成中的低效性，即单一模型难以同时维持图像上下文和精确的令牌序列依赖。NativeTok 提出混合因果专家 Transformer（MoCET），由 $L$ 个轻量级专家 Transformer 块组成，每个块专门负责生成第 $i$ 个令牌。在生成第 $i$ 个令牌时，输入为锁定的潜空间图像信息 $X_{latent}$、已生成的前 $i-1$ 个令牌 $\{z_0, ..., z_{i-1}\}$ 以及当前的掩码令牌 $z_{padding}$。第 $i$ 个令牌的生成过程可形式化为：

$$ z_i = T_i(X_{latent}, z_0, ..., z_{i-1}, z_{padding}) $$

其中 $T_i$ 为第 $i$ 个专家 Transformer。一旦 $z_i$ 生成，它即被固定并纳入后续令牌的上下文。这种位置特定的专家设计允许模型在低维潜空间中精确建模因果依赖，避免了通用模型在序列生成中的性能衰减。

### 分层原生训练策略

设计动机在于缓解 MoCET 中专家数量随令牌长度线性增加带来的训练成本。NativeTok 采用分层训练策略：首先训练 32 令牌版本，然后复用其 MIT 和前 32 个专家权重初始化 64 令牌版本，仅训练新增的 32 个专家和解码器。此过程将可训练参数减少至 56%，并在最后 10% 的步骤中进行全参数微调。该策略确保了新专家继承先前的建模能力，同时大幅降低了扩展令牌长度的计算开销。

## 实验评估

| 分词器 | 参数量 | 令牌数 | rFID↓ | (LlamaGen-B) gFID↓ |
| :--- | :--- | :--- | :--- | :--- |
| VQGAN | 72M | 256 | 2.19 | 5.46 |
| TiTok-L-32 | 641M | 32 | 2.21 | 7.45 |
| NativeTok32 | 616M | 32 | 2.57 | 5.23 |

实验在 ImageNet-256 上进行，基线覆盖 VQGAN 和 TiTok，但缺失 2025-2026 年最新 SOTA 如 PAE 和 AffineTok。在自回归生成设置下，NativeTok32 的 gFID 为 5.23，优于 TiTok-L-32 的 7.45，但略逊于 VQGAN 的 5.46（注意 VQGAN 令牌数为 256，压缩率不同）。在 MaskGIT 设置下，NativeTok128 的 gFID 为 2.16，优于 VQGAN 的 2.19，但略逊于 TiTok-S-128 在 64 步采样下的 1.97。

| 模型 | 策略 | rFID↓ | 速度↓ |
| :--- | :--- | :--- | :--- |
| NativeTok64 | full | 6.50 | 1.53s |
| NativeTok64 | reuse | 6.46 | 1.15s |
| NativeTok64 | reuse+fine tune | 6.22 | - |

消融实验显示，分层训练策略将每批次时间从 1.53s 降至 1.15s，rFID 从 6.50 降至 6.46，全参数微调后进一步降至 6.22。这表明复用策略在保持性能的同时显著提升了训练效率。然而，NativeTok32 的 rFID（2.57）高于 VQGAN（2.19），表明因果约束可能以牺牲部分重构保真度为代价换取生成质量。

评估边界方面，实验限于 256x256 分辨率，未涉及高分辨率或视频。代码已开源，但论文未报告置信区间，且 NativeTok128 的 2.16 gFID 基于 8 步采样，可能低估了其实际性能。

## 关联研究分析

从问题动机看，NativeTok 与 VAR 均试图引入结构以改善生成，但路径不同。VAR 采用多尺度粗到细策略，通过“下一尺度预测”建模层级依赖；而 NativeTok 采用单尺度因果专家，通过位置特定的 Transformer 建模序列依赖。VAR 的结构源于图像的多尺度特性，而 NativeTok 的结构源于人类感知的全局到局部因果顺序。这种差异暗示，因果顺序是否比多尺度结构更本质地决定了视觉令牌的可生成性，论文未给出理论解释。

从方法设计看，NativeTok 与 TiTok 同属一维序列化路线，但 TiTok 侧重压缩率，NativeTok 侧重令牌顺序。TiTok 通过高压缩率加速生成，但令牌间缺乏显式依赖；NativeTok 通过 MoCET 引入因果约束，但参数量较大（616M vs 641M，相近）。NativeTok 在 32 令牌下优于 TiTok，但在 128 令牌下未超越 TiTok 最佳成绩，表明因果约束在高令牌预算下的边际收益可能递减。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

NativeTok 旨在解决离散分词中重构与生成的非单调关系，通过 MoCET 在分词阶段显式建模令牌间的因果依赖，实现了分词与生成的耦合。实验证明，在 32 令牌预算下，其 gFID 从 TiTok 的 7.45 降至 5.23，验证了因果约束对自回归生成的有效性。然而，其 rFID（2.57）高于 VQGAN（2.19），且在高令牌预算下未超越 TiTok 最佳成绩，暴露了因果约束对重构保真度的潜在负面影响及扩展性局限。当令牌预算增加至 128 时，因果约束带来的生成质量提升是否足以抵消其参数量增加和重构损失，论文未给出明确答案。
