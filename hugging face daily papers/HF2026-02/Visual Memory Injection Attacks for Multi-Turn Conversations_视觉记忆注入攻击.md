# HuggingFace最新推荐论文 ｜Visual Memory Injection Attacks for Multi-Turn Conversations ｜视觉记忆注入攻击

作者：Christian Schlarmann、Matthias Hein

论文原文见 [arXiv](https://arxiv.org/abs/2602.15927)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.15927)

> 多轮对话中的大视觉语言模型（LVLM）面临持久性视觉攻击威胁，现有单轮攻击无法模拟真实用户交互场景。本文利用图像在多轮上下文中持续存在的特性，提出视觉记忆注入（Visual Memory Injection, VMI）攻击。通过良性锚定与上下文循环机制，使模型仅在特定触发话题下输出恶意目标，其余轮次保持正常行为。该攻击在长对话中依然有效，但缺乏对防御机制的验证，实际威胁等级需结合防御场景评估。

## 研究背景

当用户与LVLM进行多轮对话时，初始上传的图像会持续保留在模型上下文中，影响后续所有轮次的输出。这种视觉记忆的持久性使得攻击者可通过微小扰动嵌入恶意意图，但单轮攻击要么在非触发提示下泄露目标，要么要求用户立即发出特定提示，不符合真实交互模式。为模拟真实场景，需构建一种隐蔽攻击，使模型在无关话题下表现正常，仅在触发话题下输出预设恶意内容。

现有LVLM安全研究聚焦于单轮越狱或排版注入，如FigStep将有害指令渲染为图像文本绕过文本过滤器，但均未考虑多轮对话中视觉记忆的累积效应。单轮攻击的局限性在于无法应对用户自然交互中的延迟触发需求，且缺乏对模型行为一致性的约束。本文切入点在于利用多轮上下文的持久性，结合良性锚定防止模型退化，通过上下文循环提升攻击在不同对话长度下的泛化能力，填补了多轮视觉攻击的研究空白。

## 核心方法

### 方法参照系

本文问题属于多模态越狱攻击类别，标准流程为通过梯度优化生成对抗扰动以诱导模型输出有害内容。与单轮攻击的关键差异在于，本文需同时优化多轮上下文中的行为一致性，确保非触发轮次正常、触发轮次恶意，且攻击效果随对话长度增加而保持。

### 良性锚定机制

单轮攻击常导致模型在非触发提示下也输出目标，引发用户怀疑。本文在优化目标中引入良性锚定项，联合优化首轮良性响应与第n轮恶意目标。具体地，给定锚点提示 $t_a$ 与目标 $y_a$，触发提示 $t_t$ 与目标 $y_t$，优化目标为：

$$\min_{\hat{x}} \mathbb{E}_{c} \left[ -\log P(y_a | t_a, \hat{x}, c) - \log P(y_t | t_t, \hat{x}, c) \right]$$

该公式强制模型在锚点提示下生成自然响应，同时在触发提示下输出恶意目标，防止模型行为退化。

### 上下文循环优化

固定长度上下文优化易过拟合特定对话轨迹，导致攻击在长对话中失效。本文提出上下文循环策略，在优化过程中周期性切换不同长度的上下文。设上下文序列为 $c_{(2)}, \dots, c_{(n)}$，每 $\tau$ 步切换一次上下文索引 $k$：

$$k = (k + 1) \mod (n - 1)$$

该机制迫使优化器适应多种对话长度，提升攻击在未知上下文长度下的鲁棒性。最终VMI攻击整合良性锚定与上下文循环，通过自适应投影梯度下降（APGD）求解，扰动半径设为 $\epsilon = 8/255$。

## 实验评估

实验在Qwen2.5-VL、Qwen3-VL和LLaVA-OneVision-1.5三个开源LVLM上进行，使用COCO和LMARKS数据集各20张图像，评估四种攻击目标（手机、汽车、政治、股票）。基线审计显示，本文未与单轮攻击方法（如Schlarmann & Hein, 2023）直接对比，仅通过消融实验验证组件贡献。主结果中，VMI在超过25轮对话后仍保持高成功率，且对未见过的提示集（Diverse、Holiday）具有泛化能力。

消融实验表明，移除上下文循环导致攻击在长对话中成功率显著下降，移除良性锚定则引发目标泄露至非触发轮次。反直觉发现是，Qwen3-VL比Qwen2.5-VL更鲁棒，而LLaVA-OneVision-1.5在连贯Holiday提示下最脆弱，暗示模型架构对视觉记忆处理的差异。

该论文实验数据不可得，未提供实验表格。评估边界方面，指标仅包含联合成功率（SR∧），未报告过度拒绝率或效用损失；评估协议未包含防御机制对比，无法量化攻击在防御下的实际威胁；可复现性方面，论文提供GitHub代码，但超参数（如迭代次数2000、周期τ）未在正文中完整列出。

## 关联研究分析

从问题动机看，VMI与FigStep同属视觉通道攻击，但FigStep针对单轮排版注入，依赖视觉编码器将文本指令传递给语言模型，而VMI利用多轮上下文中图像的持久性，无需修改图像内容本身，仅通过微小扰动实现延迟触发。这一差异源于任务特性：单轮攻击需立即绕过文本过滤器，而多轮攻击可利用模型对历史上下文的依赖，使攻击更隐蔽。

从方法设计看，VMI与Mosaic同属迁移攻击，但Mosaic针对闭源模型，通过多代理集成优化提升黑盒攻击迁移性，而VMI针对开源微调模型，验证白盒生成扰动在微调变体间的迁移能力。VMI未探索闭源模型场景，其迁移性验证局限于同系列微调模型，是否适用于跨架构模型（如从Qwen迁移到LLaVA）论文未给出回答。

## 总结

本文要解决的核心矛盾是多轮对话中视觉记忆的持久性与攻击隐蔽性之间的冲突。现有单轮攻击无法模拟真实交互中的延迟触发，而VMI通过良性锚定与上下文循环机制，使模型仅在特定话题下输出恶意目标，其余轮次保持正常。实验证明VMI在超过25轮对话后仍有效，且对未见提示具有泛化能力。本文边界在于未验证防御机制下的攻击效果，且迁移性测试局限于同系列微调模型。当防御机制引入上下文感知过滤时，VMI的良性锚定是否仍能维持隐蔽性，论文未给出回答。
