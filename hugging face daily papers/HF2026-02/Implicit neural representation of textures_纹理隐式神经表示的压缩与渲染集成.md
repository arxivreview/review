# HuggingFace最新推荐论文 ｜Implicit neural representation of textures ｜纹理隐式神经表示的压缩与渲染集成

研究机构：英国剑桥大学

作者：Albert Kwok、Zheyuan Hu、Dounia Hammou

论文原文见 [arXiv](https://arxiv.org/abs/2602.02354)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.02354)

> 纹理数据占据图形处理器（GPU）显存与能耗的主要部分，传统离散压缩方法在内容适应性上存在局限。现有隐式神经表示（INR）虽能实现紧凑存储，但缺乏针对图形学渲染管线的工程化集成与多尺度适配机制。本文通过构建支持 Mipmap 层级的纹理 INR 架构，并将其嵌入 Mitsuba 3 渲染器，实现了从权重压缩到实时推理的闭环。该工作验证了 INR 在感知质量上优于传统压缩算法，但其离线训练成本与高频细节丢失问题限制了实时部署的可行性。

## 研究背景

图形学中的纹理通常以离散像素网格形式存储，这种表示方式在高分辨率下导致显存占用激增，且无法在渲染时动态调整细节级别（Level of Detail, LOD）。为突破这一限制，隐式神经表示（INR）将纹理参数化为从 UV 坐标到 RGB 颜色的连续函数，利用多层感知机（MLP）的权重作为压缩后的纹理数据。然而，标准 MLP 存在频谱偏差，难以拟合高频细节，且传统 INR 研究多聚焦于通用图像重建，缺乏针对图形学特定需求（如 Mipmap 金字塔、渲染管线集成）的系统性评估。

纹理压缩领域长期依赖自适应可缩放纹理压缩（ASTC）等块基有损压缩算法，其比特率固定在 1 至 8 bits per pixel (bpp) 之间，缺乏内容感知的自适应能力。INR 作为一种替代方案，理论上可通过调整网络宽度与深度实现比特率连续变化，但此前研究未深入探讨其在图形学渲染场景下的效率与质量权衡。本文切入点在于将 INR 从通用信号重建拓展至图形学应用，重点解决两个被忽略的工程问题：一是如何在保持连续查询特性的同时支持 Mipmap 多尺度渲染；二是如何评估 INR 权重作为纹理表示在渲染管线中的实际部署成本与感知收益。

## 核心方法

### 方法参照系

本文基于标准 INR 架构，即输入 UV 坐标、输出 RGB 颜色的 MLP 模型。与通用图像 INR 不同，本文针对纹理压缩任务引入了比特率-质量权衡评估，并扩展了输入空间以支持多尺度渲染。核心差异在于将 INR 视为一种可嵌入渲染管线的压缩格式，而非单纯的离线重建工具。

### 多尺度 Mipmap 输入扩展

传统 INR 仅接受二维 UV 坐标作为输入，无法直接表达 Mipmap 金字塔中不同分辨率层级的纹理细节。本文在输入向量中增加一个归一化参数 $t \in [0, 1]$，表示细节级别，从而将映射函数扩展为 $f(u, v, t) \rightarrow \mathbb{R}^3$。

$$
\mathbf{x}_{input} = [u, v, t, \phi(u, v)]
$$

其中 $\phi(u, v)$ 为位置编码。该设计允许单一网络同时学习基础纹理及其下采样版本，避免了为每个 Mipmap 层级训练独立模型的冗余。通过在下采样图像上重新训练，网络消除了未采样点的幻觉效应，使得 $t$ 参数能够平滑过渡不同分辨率，实现了分辨率无关的 LOD 切换。

### 频率编码与激活函数优化

为缓解频谱偏差导致的高频细节丢失，本文对比了三种架构：纯 MLP、SIREN（正弦激活）和 Fourier 编码 MLP。Fourier 编码通过随机傅里叶特征映射将低维坐标提升至高维空间，重塑神经切线核（NTK）频谱。

$$
\phi(\mathbf{x}) = [\cos(2\pi \mathbf{B}\mathbf{x}), \sin(2\pi \mathbf{B}\mathbf{x})]
$$

其中 $\mathbf{B}$ 为随机高斯矩阵。实验表明，Fourier 编码 MLP 在 LPIPS 指标上表现最优，但会产生直线伪影；SIREN 虽能捕捉高频，但在几何纹理上产生“lumpy”伪影。纯 MLP 则始终呈现模糊结果。本文未采用 Hash Encoding，因其在低分辨率纹理中增益有限，且增加了实现复杂度。

## 实验评估

实验基于 Describable Textures Dataset (DTD) 中的 25 张多样化纹理图像，对比了纯 MLP、SIREN、Fourier MLP 与 ASTC 在比特率-质量曲线上的表现。基线覆盖传统压缩算法与三种 INR 架构，但缺失 Hash Encoding 的定量对比。

| 架构 | 优化器 | 主要伪影类型 | LPIPS 表现 |
| :--- | :--- | :--- | :--- |
| Pure MLP | Adam | 模糊、直线 | 较差 |
| SIREN | Adam | Lumpy 曲线 | 良好，高压缩比时下降 |
| Fourier MLP | Adam | 直线、颗粒噪声 | 最佳 |

在感知指标 LPIPS 上，Fourier MLP 显著优于 ASTC，表明 INR 能更好地保留纹理的高层结构。然而，在 PSNR 和 SSIM 等像素级指标上，INR 与 ASTC 的差距较小且结果噪声较大，说明 INR 在精确细节恢复上仍有不足。训练效率方面，在 RTX 5080Ti 上，50 次迭代耗时 50 至 200 秒，速度为 0.5-2 iterations/s，远低于实时渲染需求，仅适用于离线烘焙。渲染推理时间随每像素采样数（SPP）线性增长，在 Apple M1 CPU 上，SPP=1 时渲染耗时 4.7 秒。

消融实验显示，Adam 优化器在所有架构上均优于 Rprop，后者产生更模糊的结果和矩形伪影。Mipmap 拟合实验表明，引入 $t$ 参数后，模型性能与无 Mipmap 版本相似，但 VMAF 指标显著改善，验证了多尺度输入对感知质量的提升。INR 权重空间生成实验使用扩散模型生成新纹理，但受限于约 600 个训练权重样本，生成质量尚未达到理想水平。

评估边界方面，本文未报告置信区间，且仅在 DTD 数据集上验证，缺乏 Kodak 或 DIV2K 等通用图像基准的横向对比。代码未公开，超参数（如 Fourier 频率 $\omega_0$）未进行系统性调优，可能影响结果的可复现性。

## 关联研究分析

从问题动机看，本文与 SIREN（Sitzmann et al., 2020）和 Fourier Features（Tancik et al., 2020）共享缓解频谱偏差的目标，但本文更关注图形学应用中的工程约束。SIREN 和 Fourier Features 主要评估图像重建的 PSNR，而本文引入 LPIPS 和 VMAF 等感知指标，并对比 ASTC，更贴近实际压缩场景。差异根源在于任务特性：纹理压缩需平衡显存占用与渲染速度，而通用重建仅关注重建精度。本文发现 Fourier 编码在纹理上产生直线伪影，这在通用图像重建中较少被强调，反映了纹理重复结构对频率编码的敏感性。

从方法设计看，本文与 Hash Encoding（Müller et al., 2022）同属位置编码路线，但本文选择 Fourier 编码而非 Hash 网格。Hash Encoding 通过多分辨率哈希表提升高频表达能力，但牺牲了分辨率无关性，且参数量随分辨率增长。本文指出在低分辨率纹理中 Hash 编码增益有限，这一判断与领域共识中 Hash 编码加速收敛的观点存在潜在冲突。冲突暗示 Hash 编码的优势可能依赖于高分辨率输入，而在纹理压缩的中等分辨率场景下，Fourier 编码的紧凑性更具优势。此外，本文引入 Mipmap 层级 $t$ 作为输入，偏离了标准 INR 的纯坐标映射范式，引入了额外的归纳偏置，这在通用 INR 研究中较少见，但符合图形学 LOD 切换的需求。

## 总结

本文核心矛盾在于如何在保持 INR 紧凑存储优势的同时，满足图形学渲染对多尺度支持与实时性的要求。切入点在于将 Mipmap 层级参数化并集成至渲染管线，解决了传统 INR 无法直接支持 LOD 切换的问题。方法上，通过扩展输入空间至 $(u, v, t)$ 并对比 Fourier 与 SIREN 架构，实现了内容感知的纹理压缩。实验证明 Fourier MLP 在 LPIPS 上优于 ASTC，但训练速度仅 0.5-2 iter/s，限制了实时应用。边界在于缺乏通用图像基准验证，且高频细节恢复能力不足，导致 PSNR 提升有限。当纹理分辨率进一步提升时，Fourier 编码的直线伪影是否会加剧，从而抵消其感知质量优势，论文未给出回答。
