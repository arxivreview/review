作者：Haodong Li、Jingwei Wu、Quan Sun 等 17 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.09007)

> 图像生成模型作为 GUI 环境模拟器时，其核心挑战在于维持离散状态转换的逻辑一致性，而非仅追求视觉保真度。现有通用视觉基准无法评估这种由用户指令触发的界面跳转逻辑，导致生成模型在长时序交互中的可靠性存疑。本文构建了 GEBench 基准与 GE-Score 多维评估指标，系统量化了 12 款主流生成模型在单步、多步及定位生成任务上的表现。该工作揭示了当前模型在空间定位与长程规划上的显著缺陷，为 GUI 智能体训练提供了环境模拟视角，但评估依赖 VLM 裁判，其客观性边界尚待进一步验证。

## 研究背景

GUI 智能体的训练依赖于能够模拟真实交互反馈的环境。传统模拟器受限于固定软件栈与硬件依赖，难以覆盖海量应用场景。图像生成模型（Image Generation Models）凭借对视觉-语义映射的强拟合能力，被视为构建低成本、高灵活度 GUI 环境的潜在方案。然而，GUI 交互本质是离散的状态跳转，一次点击即导致界面布局的整体重构，这与自然视频生成的连续运动轨迹截然不同。这种离散性要求模型不仅生成像素，更需理解“动作-状态”之间的因果逻辑，即当前操作如何精确改变后续界面的元素位置与内容。

现有图像生成基准主要关注通用领域的视觉保真度（如 FID、CLIP Score）或视频生成的时间连续性，缺乏对 GUI 特定逻辑的评估维度。当生成模型被用作环境时，其输出的界面必须满足功能正确性、交互逻辑合理性及结构一致性，这些需求在通用视觉指标中完全缺失。因此，如何量化生成模型作为 GUI 环境的“功能性可靠性”成为关键瓶颈。GEBench 正是针对这一空白，将评估焦点从“像不像”转向“对不对”，通过引入离散状态转换逻辑评估，填补了生成式 GUI 环境验证的方法论缺口。

## 核心方法

### 方法参照系

本文问题归属于“生成式环境基准构建”范畴，但区别于评估单帧图像质量的通用基准，其核心差异在于评估对象是“序列化的状态转换过程”。标准流程通常基于静态图像对计算分布距离，而 GEBench 要求模型接收当前 GUI 状态与指令，生成下一状态，并验证该转换是否符合 GUI 交互逻辑。

### 离散状态转换任务设计

针对通用基准无法捕捉 GUI 离散跳转特性的问题，GEBench 设计了五类任务以覆盖不同维度的能力。其中，Grounding-based Generation 任务要求模型根据归一化坐标 $[0, 1000]$ 生成点击后的状态，直接测试模型对像素-语义映射的理解。Multi-step Planning 任务则要求从初始状态生成五步轨迹，评估长程逻辑一致性。这种设计将“空间定位”与“逻辑推理”解耦，使得模型在单步转换中的高分不能掩盖其在多步规划中的逻辑断裂。

### GE-Score 多维评估机制

为量化生成质量，本文提出 GE-Score，摒弃单一正确性信号，采用 VLM 引导的五维评分体系。设第 $i$ 个样本在第 $d$ 个维度的离散评分为 $r_{i,d} \in \{0, \dots, 5\}$，GE-Score 定义为：

$$
\text{GE-Score} = \frac{1}{N \times D} \sum_{i=1}^{N} \sum_{d=1}^{D} F(r_{i,d})
$$

其中 $F(r) = 20 \times r$ 为线性归一化变换，将评分映射至 $[0, 100]$ 区间。该公式的物理含义是计算模型在目标达成（GOAL）、交互逻辑（LOGIC）、一致性（CONS）、UI 合理性（UI）及视觉质量（QUAL）五个维度上的平均语义-结构对齐度。通过引入 VLM 作为裁判，该指标能够捕捉传统像素级指标无法识别的“逻辑幻觉”，如界面元素虽清晰但功能错误。

## 实验评估

实验在 GEBench 的 700 个样本上进行，涵盖中文与英文子集，对比了 8 款商业模型与 4 款开源模型。基线覆盖了当前主流的文本到图像及参考图像编辑模型，但未包含专用 GUI 定位模型作为直接对比，因为任务目标不同（生成 vs 定位）。

| 模型 | 中文 GE-Score | 英文 GE-Score | Grounding GOAL (中文) |
| :--- | :--- | :--- | :--- |
| Nano Banana Pro | 69.62 | 63.68 | 23.9 |
| GPT-image-1.5 | 65.75 | 63.16 | 18.61 |
| Seedream 4.5 | 64.83 | 58.93 | 14.14 |
| Qwen-Image-Edit | 50.80 | 54.55 | 8.61 |

Nano Banana Pro 在中文子集以 69.62 分领先，GPT-image-1.5 在英文子集以 63.16 分居首。然而，在 Grounding 任务上，所有模型的 GOAL 得分均低于 25%，其中最佳者 Nano Banana Pro 仅为 23.9%。这一巨大落差表明，尽管模型在单步视觉转换上表现良好，但其将抽象坐标映射到精确像素位置的能力严重不足，导致生成状态与预期点击效果脱节。

消融分析显示，Multi-step 任务得分普遍低于 60 分，部分模型甚至低于 10 分。这揭示了“感知-规划”失衡：模型擅长单步指令跟随，但无法维持长序列的逻辑一致性，中间步骤的微小视觉偏差会累积导致轨迹发散。此外，开源模型（如 Bagel、UniWorld-V2）在雷达图上呈现明显的内向收缩，表明其在处理复杂逻辑任务时存在系统性短板。

评估协议依赖三个 VLM（Gemini-3-Flash-Native, GPT-4o, Qwen3-vl-235b）进行交叉评估，虽缓解了单一裁判偏差，但 VLM 自身的空间感知局限可能影响评分准确性。代码已开源，但 700 样本规模较小，且未报告置信区间，数值比较需谨慎。

## 关联研究分析

从问题动机看，GEBench 与 ScreenSpot-Pro 等定位基准形成互补而非竞争关系。ScreenSpot-Pro 评估模型“找到”元素的能力，而 GEBench 评估模型“生成”元素变化后的状态。两者共同指向 GUI 智能体的核心瓶颈：空间感知。ScreenSpot-Pro 上 SOTA 模型（GUI-AIMA-3B）准确率为 61.5%，而 GEBench 中 Grounding 任务的 GOAL 得分最高仅 23.9%。这一差异暗示，生成模型缺乏定位模型所具备的显式坐标解码机制，其空间错误源于生成过程中的布局漂移，而非感知模糊。

从方法设计看，GEBench 的 GE-Score 与 SafeGround 的不确定性量化思路有异曲同工之妙，但应用对象不同。SafeGround 通过分布感知量化定位风险，而 GE-Score 通过 VLM 评分量化生成逻辑风险。然而，GE-Score 依赖 VLM 的“主观”判断，缺乏 SafeGround 那样的概率校准机制。若 VLM 裁判对“逻辑合理性”的判断存在系统性偏差，GE-Score 可能高估或低估模型的真实可靠性。这种评估偏差在高风险操作（如删除文件）场景中尤为关键，论文未提供针对 VLM 裁判一致性的详细统计检验，仅展示了与人类专家评分的 Pearson 相关性，其鲁棒性边界尚不明确。

## 总结

GEBench 旨在解决图像生成模型作为 GUI 环境时逻辑一致性无法量化的问题。现有通用视觉基准无法区分“视觉真实”与“逻辑正确”，而 GEBench 通过引入离散状态转换任务与 GE-Score 多维指标，首次系统性地暴露了生成模型在空间定位与长程规划上的缺陷。实验表明，尽管 Nano Banana Pro 在中文子集取得 69.62 分，但其 Grounding 任务 GOAL 得分仅 23.9%，揭示了生成模型在像素级精确控制上的根本局限。该工作的边界在于评估规模较小且依赖 VLM 裁判，未提供改进生成模型空间能力的具体方案。当 VLM 裁判对复杂逻辑的判断出现分歧时，GE-Score 的稳定性是否足以支撑模型迭代，论文未给出回答。
