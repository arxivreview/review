> 视觉模态中的位置编码长期依赖从一维语言序列迁移的机制，导致对二维或三维空间几何特性的捕捉不完整。现有方法如 RoPE 或 ALiBi 在适配视觉任务时，往往牺牲旋转不变性或方向性，无法同时满足平移、旋转、距离衰减、方向性及上下文感知这五项原则。PaPE 通过引入可学习的抛物线偏置项，将相对位置作为自变量嵌入注意力分数，实现了上述原则的统一。该设计在八项视觉基准上取得领先，但其在非图像模态上的泛化边界及计算开销仍需进一步审视。

## 研究背景

Transformer 的自注意力机制本质上是置换不变的，即打乱输入顺序不改变输出。在语言模型中，这一缺陷通过一维位置编码（Positional Encoding, PE）弥补，但在视觉任务中，token 分布在二维图像或三维点云空间，一维索引无法表达“上方”“左侧”或“深度”等几何关系。视觉 PE 的核心挑战在于如何在不破坏注意力计算效率的前提下，将多维空间坐标转化为注意力分数中的相对几何约束，同时保持对全局平移和局部旋转的鲁棒性。

主流视觉 PE 路线均存在结构性缺陷。绝对位置编码（如 nD-sincos）虽提供精确坐标，但缺乏平移不变性，导致模型难以泛化到不同分辨率或位置。RoPE 系列通过旋转查询和键向量实现相对位置编码，具备平移不变性和距离衰减特性，但其轴向变体（Axial RoPE）独立处理各维度，无法捕捉对角线交互；RoPE-Mixed 虽引入方向性，却依赖固定频率，缺乏上下文适应能力。ALiBi 及其二维变体（nD-ALiBi）通过线性距离偏置实现旋转不变性，但 LookHere 等扩展方向性的方法以牺牲旋转不变性为代价。这些方法均未能同时满足视觉任务所需的五项几何原则：平移不变性、旋转不变性、距离衰减、方向性和上下文感知。

PaPE 的切入点在于识别出上述原则在视觉模态中的互补性与冲突性，并设计一种统一的数学形式来容纳它们。与语言 PE 侧重序列顺序不同，视觉 PE 需处理空间各向异性与动态上下文依赖。PaPE 将相对位置视为抛物线的自变量，通过二次项捕捉距离衰减、线性项捕捉方向性，并引入基于 token 内容的可学习系数实现上下文感知，从而在单一框架内解决现有方法的碎片化问题。

## 核心方法

### 方法参照系

视觉 PE 的通用流程是将空间坐标 $r_i \in \mathbb{R}^p$ 转化为注意力分数中的偏置项或查询/键变换。标准 RoPE 通过旋转矩阵实现相对位置编码，ALiBi 通过线性距离偏置实现距离衰减。PaPE 的关键差异在于，它不直接操作坐标或频率，而是将相对位置 $\Delta r_{ij} = r_j - r_i$ 作为抛物线函数的自变量，构建一个包含二次项和线性项的可学习偏置结构，从而同时编码距离、方向和上下文信息。

### 抛物线偏置结构

PaPE 的核心创新在于将注意力分数分解为语义项、距离项和方向项之和。设计动机在于解决固定频率 RoPE 无法动态适应局部与全局交互需求的问题，以及线性 ALiBi 无法捕捉非对称方向性的局限。PaPE 定义注意力分数为：

$$
A_{ij} = \langle q_i, k_j \rangle + \langle a_i, (\Delta r_{ij})^{\odot 2} \rangle + \langle b_i, \Delta r_{ij} \rangle
$$

其中 $q_i, k_j$ 为语义查询和键，$a_i, b_i$ 为基于 token 内容 $x_i$ 通过可学习投影 $W_a, W_b$ 计算的系数向量，$(\cdot)^{\odot 2}$ 表示逐元素平方。该公式的物理含义是：二次项 $\langle a_i, (\Delta r_{ij})^{\odot 2} \rangle$ 通过负系数 $a_i$（由 softplus 激活保证）实现距离衰减，线性项 $\langle b_i, \Delta r_{ij} \rangle$ 通过向量点积实现方向性调制，语义项 $\langle q_i, k_j \rangle$ 保留原始内容匹配。这种分解使得模型能根据 token 内容动态调整距离衰减强度和方向偏好，而非依赖固定模式。

### 旋转不变性与高效内核兼容

PaPE-RI 通过约束参数实现旋转不变性，设计动机在于解决标准 PaPE 在三维点云或旋转敏感任务中因方向性项导致的性能波动。PaPE-RI 设定 $b_i = 0$，$a_{ik} = \alpha_i$（标量），且 $W_p = w_p I_p$，此时注意力分数仅依赖 $\|\Delta r_{ij}\|^2$，即欧氏距离平方，从而对任意旋转矩阵 $R$ 满足 $A_{ij}(Rr_i, Rr_j) = A_{ij}(r_i, r_j)$。为兼容 FlashAttention 等高效内核，PaPE 将偏置项转化为查询和键的独立变换：

$$
f_q(q_i, r_i) = [q_i \oplus a_i \oplus b_i \oplus s_i], \quad f_k(k_j, r_j) = [k_j \oplus 0 \oplus 0 \oplus s_j]
$$

其中 $s_i = W_p r_i$，$\oplus$ 表示向量拼接。该变换确保 $\langle f_q(q_i, r_i), f_k(k_j, r_j) \rangle$ 精确恢复原始 PaPE 公式，避免了显式计算全注意力矩阵，但将查询/键维度从 $h$ 扩展至 $h + 3m + 2$，其中 $m$ 为抛物线数量。

## 实验评估

PaPE 在八项覆盖图像、点云、视频和事件相机的数据集上评估，基线包括 nD-sincos、Axial RoPE、RoPE-Mixed、nD-ALiBi 和 LookHere。这些基线覆盖了绝对编码、旋转编码和线性偏置三条主要路线，但缺少 HoPE、GAPE 等最新上下文感知方法的对比。PaPE 在六项数据集上取得最佳性能，PaPE-RI 在 nuScenes 上以 68.9 mAP 领先，平均得分 66.3 优于 RoPE 的 65.3。

消融实验显示，移除距离衰减、方向性或上下文感知任一项均导致 ImageNet-1K 准确率下降约 2%，验证了三项原则的必要性。$m$ 值从 8 增至 50 时，性能提升趋于平缓，表明 $m=8$ 已接近饱和。效率测试表明，PaPE 增加推理时间最多 0.4 ms，引入最多 13.6M 位置参数，在 $m=50$ 时开销显著，但 $m=8$ 时影响可忽略。

评估边界方面，PaPE 在 ImageNet-1K 上从 224×224 训练分辨率外推至更大尺寸时，准确率提升最多 10.5%，远超其他基线，但缺乏在序列长度外推（如长视频）上的系统测试。代码已开源，但论文未报告 GPU 型号与训练时长，可复现性依赖默认超参数。

## 关联研究分析

从问题动机看，PaPE 与 RoPE-Mixed 均旨在解决视觉任务中的方向性问题，但根源不同。RoPE-Mixed 通过为每个空间维度分配独立可学习频率来编码方向，本质上是频率域调制，其方向性受限于频率的周期性，难以表达非对称或局部方向偏好。PaPE 则通过线性项 $\langle b_i, \Delta r_{ij} \rangle$ 在空间域直接建模方向，$b_i$ 作为 token 相关的向量，能动态调整方向敏感度，更适合视觉中“上方比下方更重要”这类非对称语义。这一差异源于视觉数据的方向性本质：语言序列中方向仅指前后，而视觉中方向是多维且内容依赖的，RoPE-Mixed 的固定频率无法捕捉这种动态性。

从方法设计看，PaPE 与 nD-ALiBi 同属注意力偏置路线，但处理距离衰减的方式截然不同。nD-ALiBi 使用线性距离偏置 $-\lambda \|r_i - r_j\|$，其衰减是单调且全局固定的，无法区分“近距离强交互”与“远距离弱交互”的强度梯度。PaPE 的二次项 $\langle a_i, (\Delta r_{ij})^{\odot 2} \rangle$ 提供非线性衰减，且 $a_i$ 随 token 内容变化，允许模型在需要长程依赖时减弱衰减（$a_i \to 0$），在需要局部聚焦时增强衰减。这一设计解决了 nD-ALiBi 在复杂场景（如多目标检测）中因固定衰减导致的注意力分散问题，但代价是增加了参数数量与计算维度。

## 总结

PaPE 解决的核心矛盾是视觉 PE 中几何原则的碎片化与统一编码的缺失。现有方法如 RoPE 和 ALiBi 各自满足部分原则，但无法同时兼顾旋转不变性、方向性与上下文感知，导致在跨模态任务中性能受限。PaPE 通过抛物线偏置结构，将相对位置转化为可学习的二次与线性项，在单一框架内实现五项原则的统一，并在八项视觉基准上验证了其通用性。实验表明，PaPE 在 nuScenes 上以 68.9 mAP 领先，ImageNet-1K 外推提升达 10.5%，证明了其几何建模的有效性。然而，PaPE 的上下文感知机制依赖 token 内容投影，在事件相机等稀疏数据上，$a_i, b_i$ 的估计稳定性未充分验证；且 $m$ 值增大时参数开销显著，限制了其在资源受限场景的部署。当输入 token 数量减少至极端稀疏（如事件相机低密度流）时，抛物线系数 $a_i, b_i$ 的估计方差是否会导致注意力分布不稳定，论文未给出回答。
