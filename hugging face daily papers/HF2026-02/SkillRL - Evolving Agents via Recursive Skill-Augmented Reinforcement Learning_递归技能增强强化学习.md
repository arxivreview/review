> 大语言模型代理在复杂任务中常因缺乏经验复用而陷入“一次性执行”困境，现有记忆方法多存储冗余原始轨迹，导致上下文噪声高且无法抽象出可泛化的行为模式。SKILLRL 通过差异化蒸馏成功与失败轨迹，构建层级化技能库，并在强化学习过程中实现技能库与策略的递归协同进化。该方法在 ALFWorld 和 WebShop 上显著超越基线，但受限于 7B 小模型骨干，其绝对性能仍低于使用更强模型的同类方法，且未验证多模态场景下的泛化能力。

## 研究背景

理解 SKILLRL 需先厘清两个核心概念：轨迹冗余与技能抽象。LLM 代理与环境交互产生的轨迹 $\tau$ 包含大量探索性动作与回溯步骤，直接存入记忆库会导致上下文窗口被噪声填满，模型难以提取关键决策逻辑。为解决此问题，研究者引入“技能”概念，即从具体轨迹中提炼出的紧凑、可复用的策略片段。然而，静态技能库无法适应策略进化过程中涌现的新失败模式，这构成了动态技能进化的必要性。

当前领域主流路线分为两类：一是基于提示的记忆增强方法（如 Mem0, ExpeL），它们通过检索原始轨迹或压缩经验辅助决策，但未能改变代理内部策略，导致经验利用效率低；二是基于强化学习（RL）的策略优化方法（如 GRPO, RLOO），它们能提升任务成功率，但缺乏对历史经验的显式结构化利用。这两类方法的共同瓶颈在于“经验-策略”解耦：记忆库是静态的，策略是动态的，二者缺乏协同进化机制。SKILLRL 的切入点在于将技能库视为 RL 循环中的动态组件，通过递归进化机制使技能库与代理策略共同适应任务复杂性，从而解决静态记忆无法应对长程规划中涌现失败模式的问题。

## 核心方法

### 方法参照系

SKILLRL 建立在 Group Relative Policy Optimization (GRPO) 框架之上。GRPO 通过组内相对奖励优化策略，避免了训练 Critic 网络，其目标函数为：

$$
\mathcal{L}_{GRPO} = \mathbb{E}_{x, \{y_i\}} \left[ \frac{1}{G} \sum_{i=1}^G \min \left( \rho_i A_i, \text{clip}(\rho_i, 1-\epsilon, 1+\epsilon) A_i \right) - \beta D_{KL}(\pi_\theta || \pi_{ref}) \right]
$$

其中 $\rho_i$ 为重要性比率，$A_i$ 为归一化优势。SKILLRL 的关键差异在于：在 GRPO 的上下文 $c$ 中动态注入层级化技能，并在验证阶段触发技能库更新，形成“策略优化-技能进化”闭环。

### 差异化轨迹蒸馏与层级技能库构建

传统记忆方法直接存储原始轨迹，导致信息密度低且噪声高。SKILLRL 采用教师模型 $M_T$ 对轨迹进行差异化处理：成功轨迹 $\tau_+$ 被提炼为策略模式，失败轨迹 $\tau_-$ 被合成为简洁的失败教训。这一设计动机在于，失败轨迹揭示了成功轨迹中难以推断的边界条件与错误推理路径。具体地，技能库 SKILLBANK 分为通用技能 $S_g$ 和任务特定技能 $S_k$，检索时通过语义相似度获取 $K$ 个相关技能：

$$
S_{ret} = \{ s \in S_k \mid \cos(e_d, e_s) > \delta \}
$$

其中 $e_d, e_s$ 分别为任务描述与技能的嵌入向量，$\delta$ 为阈值。该机制将原始轨迹压缩 10-20 倍，在保持语义完整性的同时显著降低 Token 开销，使代理能在有限上下文内利用丰富的经验知识。

### 递归技能进化机制

静态技能库无法预见策略进化后遇到的新场景。SKILLRL 引入递归进化机制，在每个验证轮次后，针对成功率低于阈值 $\delta$ 的任务类别 $C$，收集失败轨迹 $T_{val}^-$ 并分析其失败模式。教师模型据此生成新技能或修正现有技能，更新技能库：

$$
\text{SKILLBANK} \leftarrow \text{SKILLBANK} \cup S_{new}
$$

这一设计解决了静态记忆库在策略提升后“经验过时”的问题。通过多样性感知分层采样，确保新技能覆盖不同失败类型，避免技能库偏向特定错误模式。该机制使技能库与策略共同进化，形成“策略改进-新失败暴露-技能补充-策略再改进”的良性循环，提升了代理在复杂任务中的鲁棒性。

## 实验评估

SKILLRL 在 ALFWorld、WebShop 及七个搜索增强 QA 任务上进行评估。基线覆盖提示方法（ReAct, Mem0）、纯 RL 方法（GRPO, RLOO）及记忆增强 RL 方法（MemRL, EvolveR）。在 ALFWorld 上，SKILLRL 取得 89.9% 成功率，较 GRPO 提升 12.3%，较 Mem0+GRPO 提升 35.2%；在 WebShop 上取得 72.7% 成功率，较 GRPO 提升 6.6%。在搜索 QA 任务中，SKILLRL 平均得分 47.1%，超越 Search-R1（38.5%）和 EvolveR（43.1%），尤其在多跳推理任务 Bamboogle 上领先 EvolveR 19.4%。

| 方法 | ALFWorld (%) | WebShop (%) | Search QA Avg (%) |
| :--- | :--- | :--- | :--- |
| GRPO | 77.6 | 66.1 | - |
| Mem0+GRPO | 54.7 | 37.5 | - |
| EvolveR | 43.8 | 42.5 | 43.1 |
| SKILLRL | 89.9 | 72.7 | 47.1 |

消融实验显示，移除层级结构导致 ALFWorld 性能下降 13.1%，移除动态进化机制下降 5.5%，而用原始轨迹替代技能库导致最大降幅（25%）。这表明技能抽象比原始记忆更有效，层级结构提供了必要的战略指导，动态进化则确保了技能库的时效性。冷启动 SFT 阶段至关重要，移除后性能下降 20%，证实基础模型需先学习“如何使用”技能才能进入 RL 阶段。

评估边界方面，实验仅基于 Qwen2.5-7B-Instruct 骨干，未测试更大模型或不同架构。搜索 QA 任务中，SKILLRL 在域外数据集（如 TriviaQA）上表现稳健，但论文未报告置信区间或多次运行方差。代码已开源，但超参数（如 $\delta=0.4, K=6$）的敏感性分析未在正文中详细展开，可能影响复现性。

## 关联研究分析

从问题动机看，SKILLRL 与 Skill1 均关注技能-策略协同，但路径不同。Skill1 采用单一策略网络端到端优化技能选择、利用与蒸馏，强调参数化协同；SKILLRL 则保留显式文本技能库，通过外部进化机制实现协同。这一差异源于对可解释性的权衡：Skill1 牺牲了技能的可审计性以换取优化效率，而 SKILLRL 通过文本技能保留了人工干预与调试的可能性。然而，SKILLRL 的文本技能在长程任务中可能面临 Token 开销累积问题，论文未量化这一成本对推理延迟的影响。

从方法设计看，SKILLRL 与 SkillOpt 在优化信号来源上形成对比。SkillOpt 基于验证门控的文本梯度优化技能文档，属于规则驱动；SKILLRL 基于 RL 奖励驱动技能进化，属于探索驱动。SkillOpt 在结构化文档任务（如 SpreadsheetBench）中表现稳定，而 SKILLRL 在动态交互环境（如 ALFWorld）中更具优势。这种差异暗示，规则优化适合确定性任务，而 RL 优化适合非平稳环境。SKILLRL 未对比 SkillOpt 等文本梯度方法，其优势是否部分源于 RL 的探索能力而非技能机制本身，尚需进一步验证。

## 总结

SKILLRL 解决了 LLM 代理经验复用中“轨迹冗余”与“策略静态”的矛盾，通过差异化蒸馏构建层级技能库，并引入递归进化机制实现技能与策略的协同优化。实验表明，该方法在 ALFWorld 上较 GRPO 提升 12.3%，在搜索 QA 任务上超越现有基线，验证了技能抽象与动态进化的有效性。然而，其性能受限于 7B 小模型骨干，绝对值低于使用更强模型的 Skill1（97.9%），且未探索多模态场景下的技能蒸馏。当技能库规模扩大至数万级时，语义检索的延迟与精度是否成为瓶颈，论文未给出回答。
