# HuggingFace最新推荐论文 ｜SPARKLING: Balancing Signal Preservation and Symmetry Breaking for Width-Progressive Learning ｜渐进学习中的宽度扩展：信号保持与对称性打破

研究机构：北京大学

作者：Qifan Yu、Xinyu Ma、Zhijian Zhuo 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.02472)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.02472)

> 渐进学习（Progressive Learning, PL）旨在通过训练过程中逐步扩大模型规模来降低预训练计算成本，但现有宽度扩展方法局限于训练早期，无法实现显著的计算节省。本文指出中阶段宽度扩展面临激活统计量失稳与复制初始化导致的梯度对称性锁定两大核心障碍，提出 SPARKLING 框架，通过 RMS 尺度一致性约束与非对称优化器状态重置及学习率重预热机制，在 200B token 预算下实现 2× 宽度扩展时 20%–35% 的训练 FLOPs 节省，性能持平或超越从头训练，但其在非 MoE 架构及深度-宽度联合扩展中的普适性尚未验证。

## 研究背景

预训练 Transformer 的残差流中，每个子层（如 MLP 或 Attention）的输出需与主干隐藏状态保持特定的幅度比例，这一比例由输入与输出的均方根（Root-Mean-Square, RMS）尺度决定。当模型宽度在训练中动态扩展时，若新引入的参数未正确缩放，输出激活的 RMS 将偏离预训练阶段建立的统计流形，导致后续层接收失配输入，引发优化不稳定。此外，宽度扩展常采用复制初始化以保持前向函数连续，但复制的参数子空间在反向传播中接收相同梯度，形成“对称性锁定”，使新增容量无法分化出独立特征，导致扩展失效。

渐进学习领域长期聚焦于深度扩展（如层堆叠），宽度扩展因稳定性问题被忽视，且现有工作仅在训练前 10–30% token 内执行扩展，计算节省微乎其微。中阶段扩展是 PL 实现实际成本削减的关键，但此前缺乏系统机制处理该阶段的激活失稳与梯度耦合。SPARKLING 将中阶段宽度扩展重构为“信号保持”与“对称性打破”的平衡问题，前者通过 RMS 尺度一致性稳定激活统计量，后者通过非对称优化器干预解除梯度耦合，从而在训练中期实现高效、稳定的宽度增长。

## 核心方法

### 方法参照系

标准 PL 宽度扩展采用函数保持（Function Preservation, FP）初始化，即新参数复制旧参数以匹配前向映射，并沿用全局学习率调度。该流程假设前向连续性足以保证训练稳定，但未考虑激活统计量的尺度漂移及复制参数在反向传播中的梯度对称性，导致中阶段扩展后损失回升或收敛停滞。

### RMS 尺度一致性约束

FP 初始化的核心缺陷在于未保证扩展后激活的 RMS 尺度不变。对于线性层 $y = Wx$，输出 RMS 满足 $\text{RMS}(y)^2 = \text{RMS}(x)^2 \cdot \frac{1}{d_{\text{out}}} \sum_{i,j} W_{ij}^2$。当输入维度 $d_{\text{in}}$ 扩展时，为保持输出 RMS 不变，新引入的权重需按 $\alpha = \sqrt{\frac{d_{\text{in}}}{d'_{\text{in}}}}$ 缩放（单侧复制/随机初始化）或 $\alpha = \sqrt{\frac{d_{\text{in}}}{d'_{\text{in}} - c \cdot d_{\text{in}}}}$（双侧复制，$c$ 为复制比例）。该约束确保扩展瞬间隐藏状态统计量不偏移，避免残差流中分支输出与主干幅度的失衡，从而稳定后续优化。

### 非对称优化器状态重置与学习率重预热

RMS 保持解决了前向失稳，但复制初始化导致 $\nabla_W L = \nabla_{\tilde{W}} L$，在 AdamW 或 Muon 优化器下，对称的动量状态使新旧参数更新轨迹完全一致，新增容量冗余。SPARKLING 在扩展点 $t_e$ 对新增参数 $\tilde{W}$ 执行优化器状态重置：$\mathbf{S}' = [\mathbf{S}, \mathbf{0}]$，其中 $\mathbf{S}$ 为原参数状态，$\mathbf{0}$ 为零初始化新参数状态。同时，对新增参数实施非对称学习率重预热：从当前学习率 $\eta_e$ 开始，经 $\tau_w$ 步线性升至 $\eta_{\text{peak}} = \eta_e \cdot k$，而原参数维持原余弦衰减调度。该设计在保持前向连续性的同时，通过打破反向对称性使新增参数快速分化，避免对称性锁定。

## 实验评估

实验基于 OLMoE 架构（0.5B 激活/2.5B 总参数），在 200B token 预算下于 100B token 处执行 2× 宽度扩展（MoE 专家中间维度 512→1024 或隐藏维度 1024→2048），对比从头训练（From Scratch）及多种初始化策略。基线覆盖 Naive Init、Copy Init 及对称/非对称优化器状态处理，但未对比 AKI 等高级初始化方案或深度扩展 PL 方法。

| 扩展设置 | 方法 | 总 FLOPs (B) | 验证损失 | 相对从头训练 FLOPs 节省 | 墙钟加速 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Inner 2× | From Scratch | 200B | 9.01 | - | - |
| Inner 2× | SPARKLING | 100B | 7.21 | 20% | 1.27× |
| Hidden 2× | From Scratch | 200B | 10.80 | - | - |
| Hidden 2× | SPARKLING | 100B | 8.10 | 25% | 1.29× |
| 大模型扩展 | From Scratch | 200B | 18.00 | - | - |
| 大模型扩展 | SPARKLING | 100B | 11.70 | 35% | 1.49× |

SPARKLING 在所有设置下验证损失均低于从头训练，且 FLOPs 节省随模型规模增大而提升，最大达 35%。消融实验显示，对称优化器状态处理（Drop/Copy Opt.）导致显著的性能损失，而非对称重置（Asym. Reset）有效恢复收敛速度；优化器状态缩放（Scaled Opt.）未带来额外增益，表明初始状态失配可被后续梯度快速修正。双侧复制初始化在 RMS 保持下仍显著劣于单侧复制或随机初始化，证实对称性锁定是独立于激活尺度的核心障碍。

评估仅基于验证损失与下游任务准确率，未报告置信区间或多次运行方差；代码未公开，超参数（如 $\tau_w$、$k$）未在正文中详述，复现依赖附录细节。实验局限于 MoE 架构，未验证在稠密 Transformer 或不同优化器（如 LAMB）下的普适性。

## 关联研究分析

从问题动机看，SPARKLING 与 Chinchilla 定律下的计算最优训练策略存在根本差异：后者假设架构固定，通过静态分配参数与数据量实现最优性能；前者在训练动态中改变架构维度，将计算节省转化为训练过程中的效率增益。这一差异源于任务特性：Chinchilla 关注资源分配预测，SPARKLING 关注训练过程优化。然而，SPARKLING 的 35% FLOPs 节省是否等价于 Chinchilla 框架下的“有效计算量”提升，论文未提供映射关系，导致其在缩放定律坐标系中的定位模糊。

从方法设计看，SPARKLING 的非对称学习率重预热与 µP（Maximal Update Parametrization）的超参数迁移思想同源，均旨在解决规模变化下的优化稳定性。但 µP 针对模型宽度无限扩展时的谱条件约束，而 SPARKLING 针对有限宽度扩展中的参数分化需求。关键差异在于：µP 要求所有参数遵循统一的缩放规则以维持特征学习稳定性，而 SPARKLING 刻意对新旧参数施加不同学习率以打破对称性。这种非对称性是否破坏了 µP 所依赖的谱条件稳定性，论文未进行理论分析或实验验证，仅在结论中将其列为未来工作。

## 总结

SPARKLING 解决了中阶段宽度扩展中激活失稳与梯度对称性锁定的矛盾，通过 RMS 尺度一致性与非对称优化器干预，在 200B token 预算下实现 2× 宽度扩展时 20%–35% 的 FLOPs 节省，性能持平或超越从头训练。其边界在于实验局限于 MoE 架构，且未验证非对称学习率重预热与 µP 谱条件的兼容性。当扩展时机进一步推迟至训练后期（如 80% token 处），RMS 保持策略是否仍能有效抑制激活漂移，论文未给出回答。
