# HuggingFace最新推荐论文 ｜Kimi K2.5: Visual Agentic Intelligence ｜Kimi K2.5：视觉智能体与并行编排

论文原文见 [arXiv](https://arxiv.org/abs/2602.02276)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.02276)

> 导读 多模态大语言模型（Multimodal Large Language Models, MLLMs）在向智能体（Agentic）演进时，面临视觉与文本模态在训练中相互干扰，以及单智能体顺序执行导致推理延迟线性增长的双重瓶颈。现有方法多采用后期视觉注入或人工标注的视觉思维链（Chain-of-Thought, CoT），不仅加剧了模态冲突，还限制了复杂任务的并发处理能力。Kimi K2.5 提出了一种原生多模态联合优化范式，通过早期低比例视觉融合与零视觉监督微调（Zero-Vision Supervised Fine-Tuning, SFT）激活跨模态能力，并引入并行智能体强化学习（Parallel-Agent Reinforcement Learning, PARL）框架实现动态任务分解与并发执行。该工作确立了视觉与文本双向增强的新基线，但其并行编排策略在异构子智能体间的信用分配机制上仍存疑。

## 研究背景

当模型试图在复杂环境中执行长序列任务时，其内部表征往往陷入模态割裂与执行效率的困境。传统多模态模型通常在文本骨干网络训练后期注入视觉标记，这种“事后附加”策略导致视觉编码器与语言模型在特征空间上难以对齐，模型倾向于依赖文本先验而非视觉证据进行推理。为缓解这一问题，研究者引入视觉工具调用与思维链，但人工设计的视觉轨迹数据多样性匮乏，且单智能体在处理大规模信息检索时，其顺序执行模式导致推理时间随任务复杂度呈线性增长，引发严重的延迟瓶颈。

多模态评估领域正从静态感知向动态可靠性诊断转移，核心挑战在于如何量化模型在噪声环境下的视觉忠实度与工具协同能力。现有基准如 Agentic-MME 揭示了模型在主动调查与过程验证上的不足，但缺乏对并行编排能力的系统性训练框架。Kimi K2.5 的切入点在于打破模态隔离与顺序执行的假设：通过联合预训练实现跨模态对齐，利用纯文本数据激活视觉能力，并以强化学习驱动智能体自主探索并行调度策略，从而在提升视觉推理精度的同时突破延迟限制。

## 核心方法

### 原生多模态联合预训练

在标准多模态预训练流程中，视觉标记通常在训练后期以高比例（如 50%）注入文本骨干网络，以加速多模态能力获取。Kimi K2.5 颠覆了这一范式，提出在固定总标记预算下，早期融合与低视觉比例（如 10%:90%）能产生更优的跨模态对齐效果。该策略基于 MoonViT-3D 架构，将连续四帧图像视为时空体，通过共享的 NaViT 打包策略将二维标记展平为一维序列，实现图像与视频权重的完全共享。

$$
\text{Sequence}_{\text{packed}} = \text{Flatten}(\text{Patches}_{t_1} \cup \text{Patches}_{t_2} \cup \text{Patches}_{t_3} \cup \text{Patches}_{t_4})
$$

该公式描述了时空标记的打包机制，其物理含义是将时间维度上的连续帧标记在空间维度上拼接，使注意力机制能无缝跨越时空边界。这一设计动机在于消除图像与视频编码器之间的架构分叉，最大化静态图像知识向动态视频理解的迁移效率，同时通过轻量级时间池化实现 4 倍的时间压缩，显著扩展了长视频处理的上下文窗口。

### 零视觉监督微调与联合强化学习

传统后训练阶段依赖人工标注的视觉思维链数据来激活视觉工具调用，但此类数据往往局限于简单图表与基础操作，限制了泛化能力。Kimi K2.5 提出零视觉 SFT，仅使用纯文本监督微调数据，通过 IPython 中的程序化操作代理图像操作，从而激活视觉推理与工具使用能力。随后，模型进入联合多模态强化学习阶段，不再按输入模态划分专家，而是按能力（如知识、推理、编码）组织强化学习域。

$$
R_{\text{joint}} = R_{\text{perf}}(y|x) + \lambda_1 R_{\text{parallel}} + \lambda_2 R_{\text{finish}}
$$

该公式定义了联合强化学习的奖励结构，其中 $R_{\text{perf}}$ 评估最终解的质量，$R_{\text{parallel}}$ 激励子智能体实例化以缓解串行崩溃，$R_{\text{finish}}$ 确保子任务的有效完成。这一创新解决了传统模态特定专家模型中跨模态能力无法共享的失效问题，实验表明视觉强化学习不仅未损害文本性能，反而在 MMLU-Pro 和 GPQA-Diamond 上带来了显著提升，证实了视觉与文本在深层推理中的双向增强效应。

### 并行智能体强化学习（PARL）

单智能体在处理长视野任务时，受限于上下文窗口与推理深度，常遭遇性能瓶颈。Kimi K2.5 引入 Agent Swarm 框架，采用解耦架构：可训练的编排器（Orchestrator）负责动态任务分解与子智能体调度，而子智能体保持冻结状态，其执行轨迹被视为环境观测而非可微分决策点。

$$
T_{\text{critical}} = \max_{t \in [1, T]} \left( S_{\text{main}}[t] + \max_i S_{\text{sub}}[t, i] \right)
$$

该公式定义了关键步骤（Critical Steps）作为资源约束，其算法含义是计算整个执行过程中最耗时阶段的时间成本，即主智能体步骤与并行子智能体最大步骤之和。这一设计动机在于避免端到端协同优化中的信用分配模糊与训练不稳定问题。通过冻结子智能体，编排器专注于学习高层协调逻辑，将任务复杂度从线性扩展转化为并行处理，从而在保持推理完整性的同时大幅降低延迟。

## 实验评估

Kimi K2.5 在涵盖推理、编码、智能体、图像与视频理解的广泛基准上进行了评估，基线包括 GPT-5.2、Claude Opus 4.5 等前沿专有模型及 DeepSeek-V3.2 等开源模型。在智能体搜索任务中，Agent Swarm 展现出显著优势，其并行编排策略在 BrowseComp 上取得了 78.4% 的准确率，较单智能体基线提升 17.8 个百分点，并超越了 GPT-5.2 Pro。

| 基准 | Kimi K2.5 Agent Swarm | Kimi K2.5 (单智能体) | GPT-5.2 Pro | Claude Opus 4.5 |
| :--- | :--- | :--- | :--- | :--- |
| BrowseComp | **78.4** | 60.6 | 77.9 | 37.0 |
| WideSearch | **79.0** | 72.7 | - | 76.2 |
| In-house Swarm Bench | **58.3** | 41.6 | - | 45.8 |

在视觉推理与理解方面，Kimi K2.5 在 MathVista (mini) 上达到 90.1% 的准确率，在 VideoMMMU 上达到 86.6%，确立了新的状态-of-the-art（SOTA）。值得注意的是，视觉强化学习对文本任务产生了正向迁移，MMLU-Pro 准确率从 84.7% 提升至 86.4%，GPQA-Diamond 从 84.3% 提升至 86.4%。

| 基准 | 视觉 RL 前 | 视觉 RL 后 | 提升幅度 |
| :--- | :--- | :--- | :--- |
| MMLU-Pro | 84.7 | 86.4 | +1.7 |
| GPQA-Diamond | 84.3 | 86.4 | +2.1 |
| LongBench v2 | 56.7 | 58.9 | +2.2 |

消融实验揭示了预训练策略的关键影响：早期低比例视觉融合（10%:90%）在视觉知识、推理及文本知识上均优于后期高比例融合（50%:50%）。然而，评估边界在于部分基准（如 In-house Swarm Bench）为内部开发，缺乏外部可比性；且 Agent Swarm 的训练代码未开源，限制了对其并行调度策略可复现性的独立验证。

## 关联研究分析

从问题动机看，Kimi K2.5 与 Agentic-MME 均关注智能体的动态交互能力，但路径截然不同。Agentic-MME 侧重于构建评估基准以诊断模型在视觉操作与外部知识检索中的过程缺陷，属于评估侧工作；而 Kimi K2.5 通过 PARL 框架直接优化编排器的并行调度策略，属于训练侧创新。Agentic-MME 揭示了单智能体在过程验证上的不足，Kimi K2.5 则通过并行子智能体的独立上下文隔离，从架构上缓解了长序列推理中的上下文污染问题，但未直接回应 Agentic-MME 中关于工具调用必要性的细粒度诊断。

从方法设计看，Kimi K2.5 的零视觉 SFT 挑战了领域内关于“视觉接地需显式监督”的共识。传统方法如 MM-CoT 依赖人工标注的视觉思维链以确保推理的视觉一致性，而 Kimi K2.5 发现仅通过文本 SFT 即可激活视觉能力，这暗示了高质量联合预训练数据中已隐含了足够的跨模态对齐信息。然而，这种激活机制是否依赖于预训练数据中极高的图文对齐质量，以及在低质量数据下是否依然有效，论文未给出回答。

## 总结

Kimi K2.5 旨在解决多模态模型中模态干扰与单智能体执行效率低下的核心矛盾，其切入点在于打破视觉与文本的训练隔离及顺序执行假设。通过早期低比例联合预训练、零视觉 SFT 及 PARL 框架，该模型实现了视觉与文本的双向增强及复杂任务的并行分解。实验证明，Agent Swarm 在 BrowseComp 上达到 78.4% 的准确率，视觉 RL 使 MMLU-Pro 提升 1.7 个百分点。然而，该方法的边界在于其并行编排策略高度依赖冻结子智能体的固定能力上限，且内部基准的评估缺乏外部参照。当任务分解的粒度与子智能体的专长不匹配时，编排器能否通过强化学习有效纠正错误的并行策略，论文未给出回答。
