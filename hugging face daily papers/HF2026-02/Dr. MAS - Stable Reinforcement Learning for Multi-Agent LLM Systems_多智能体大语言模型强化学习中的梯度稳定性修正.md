# HuggingFace最新推荐论文 ｜Dr. MAS: Stable Reinforcement Learning for Multi-Agent LLM Systems ｜多智能体大语言模型强化学习中的梯度稳定性修正

研究机构：新加坡南洋理工大学

作者：Lang Feng、Longtao Zheng、Shuo He 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.08847)

> 多智能体大语言模型（LLM）系统通过角色分工处理复杂任务，但将组相对策略优化（GRPO）直接应用于此类系统时，全局优势基线常导致训练崩溃。现有框架多关注单智能体效率，缺乏对多智能体异构奖励分布下梯度失稳的理论解释与系统性解法。Dr. MAS 通过按智能体独立归一化优势函数，从理论上消除梯度范数膨胀，并配套支持异构模型调度的端到端训练框架。该工作填补了多智能体 RL 训练稳定性的机制空白，但其结论局限于同步训练与特定编排结构，在异步或更复杂拓扑下的普适性尚存疑。

## 研究背景

多智能体 LLM 系统的核心挑战在于不同角色智能体（如求解器与验证器）被调用的频率与产生的奖励分布存在显著差异。这种异构性使得传统的单智能体强化学习（RL）优化目标失效，因为全局统计量无法准确反映每个智能体局部的策略质量。当智能体间的奖励均值或方差偏离全局基线时，优势估计会产生系统性偏差，进而干扰策略梯度的方向与尺度。

GRPO 通过移除价值网络，利用组内轨迹的相对奖励计算优势，已成为 LLM 后训练的主流范式。然而，在单智能体场景中，组内分布同质性保证了归一化的有效性；而在多智能体场景中，全局均值与方差掩盖了角色间的分布差异，导致部分智能体的梯度被异常放大或抑制。现有基础设施如 veRL 和 ROLL 虽提供了高吞吐量的分布式训练能力，但其架构围绕单一 LLM 执行器设计，缺乏对多智能体协同训练中原生资源调度与梯度隔离的支持，使得算法层面的不稳定难以通过系统优化弥补。

Dr. MAS 的切入点在于将训练不稳定性归因于优势归一化机制与多智能体奖励分布的结构性错配。该工作不再将不稳定视为超参数调优问题，而是从梯度二阶矩的角度进行理论剖析，指出全局基线导致的梯度范数爆炸是根本原因。这一视角将多智能体 RL 的稳定性问题从经验性的工程调试转化为可推导、可修正的数学问题，为设计针对异构智能体的优化算法提供了理论依据。

## 核心方法

### 方法参照系

本文问题置于组相对策略优化（GRPO）的多智能体扩展框架下。标准 GRPO 流程为：对同一任务采样 $N$ 条轨迹，计算全局奖励均值 $\mu$ 与标准差 $\sigma$，进而得到每条轨迹的优势 $\hat{A}_i = (R_i - \mu)/\sigma$，最后对所有智能体共享该优势进行策略更新。本文的关键差异在于，多智能体系统中不同智能体 $k$ 的活跃步集合 $Y_k$ 具有不同的奖励分布，全局 $(\mu, \sigma)$ 无法适配所有智能体，导致梯度尺度失衡。

### 梯度范数膨胀的理论机制

设计动机在于揭示全局归一化在多智能体场景下失效的数学根源，即全局基线如何系统性放大特定智能体的梯度方差。在 GRPO 中，智能体 $k$ 的未裁剪梯度贡献可表示为 $\tilde{g}_{k}^{\text{global}} = \frac{1}{|Y_k|} \sum_{(i,t) \in Y_k} \frac{R_i - \mu}{\sigma} z_{i,t}^{(k)}$，其中 $z_{i,t}^{(k)} = \nabla_{\theta_k} \rho_{\theta_k}(\mathbf{a}_t^{[i]})$ 为得分函数。假设每个智能体的得分函数二阶矩有界，即 $\mathbb{E}[\|z_{i,t}^{(k)}\|^2] \le C_k$，则智能体 $k$ 的梯度二阶矩主导项为 $\frac{\sigma_k^2 + (\mu_k - \mu)^2}{\sigma^2} \mathbb{E}_k[\|z_{i,t}^{(k)}\|^2]$。该公式表明，当智能体 $k$ 的局部均值 $\mu_k$ 偏离全局均值 $\mu$，或其局部方差 $\sigma_k^2$ 远大于全局方差 $\sigma^2$ 时，梯度范数将线性膨胀。这种膨胀并非随机噪声，而是由奖励分布的结构性偏差引起的确定性偏移，足以触发梯度尖峰并破坏训练收敛。

### 按智能体独立归一化修正

设计动机在于通过校准每个智能体的优势尺度，消除全局基线带来的梯度失衡，使各智能体梯度保持在良态范围内。Dr. MAS 将全局基线 $(\mu, \sigma)$ 替换为按智能体计算的局部统计量 $(\mu_k, \sigma_k)$，其中 $\mu_k = \frac{1}{|Y_k|} \sum_{(i,t) \in Y_k} R_i$，$\sigma_k^2 = \frac{1}{|Y_k|} \sum_{(i,t) \in Y_k} (R_i - \mu_k)^2$。修正后的优势估计为 $\hat{A}_{i,k} = \frac{R_i - \mu_k}{\sigma_k}$，对应的梯度贡献变为 $\tilde{g}_{k}^{\text{agent}} = \frac{1}{|Y_k|} \sum_{(i,t) \in Y_k} \frac{R_i - \mu_k}{\sigma_k} z_{i,t}^{(k)}$。此时，梯度二阶矩的主导项简化为 $\mathbb{E}_k[\|z_{i,t}^{(k)}\|^2]$，不再受全局统计量偏差的影响。这一修正确保了无论智能体角色如何专业化，其梯度尺度仅由自身策略的局部随机性决定，从而在理论上保证了多智能体联合优化的稳定性。

## 实验评估

实验在数学推理（两智能体循环）与多轮搜索（三智能体层级）任务上进行，基线为 Vanilla GRPO。对比方法仅覆盖 GRPO 变体，缺乏与 PPO、Tree-GRPO 等主流算法的直接对比，也未测试异步训练场景。在搜索任务中，Dr. MAS 的 avg@16 从 GRPO 的 28.0 提升至 43.8，pass@16 从 40.5 提升至 58.3；在数学任务中，avg@16 提升 5.6%，pass@16 提升 4.6%。

| 任务 | 指标 | GRPO | Dr. MAS | 提升幅度 |
| :--- | :--- | :--- | :--- | :--- |
| 搜索 | avg@16 | 28.0 | 43.8 | +15.8 |
| 搜索 | pass@16 | 40.5 | 58.3 | +17.8 |
| 数学 | avg@16 | - | - | +5.6 |
| 数学 | pass@16 | - | - | +4.6 |

消融实验验证了独立归一化的必要性。在搜索任务中，仅使用按智能体均值（$\mu_k, \sigma$）或仅使用按智能体标准差（$\mu, \sigma_k$）均能带来显著提升，其中标准差修正贡献更大（avg@16 提升 14.9 vs 11.1），表明智能体间奖励分布的差异主要体现在尺度而非中心。完全独立归一化（$\mu_k, \sigma_k$）取得最佳效果，证实了均值与方差均需局部校准。

| 归一化配置 | avg@16 | pass@16 |
| :--- | :--- | :--- |
| 全局 ($\mu, \sigma$) | 28.0 | 40.5 |
| 局部均值 ($\mu_k, \sigma$) | 39.1 | 53.5 |
| 局部方差 ($\mu, \sigma_k$) | 42.9 | 57.6 |
| 完全局部 ($\mu_k, \sigma_k$) | 43.8 | 58.3 |

评估边界方面，论文未报告置信区间，且仅在 Qwen2.5 和 Qwen3 系列模型上验证，缺乏跨模型家族的泛化测试。代码已开源，但超参数配置未完全公开，复现时需依赖默认设置。异构模型分配实验显示，将 7B 模型用于验证器、3B 模型用于搜索与回答，可在保持性能几乎不变的前提下降低 31.6% 的延迟和 41.8% 的成本，但该结论依赖于特定的层级编排结构。

## 关联研究分析

从问题动机看，Dr. MAS 与 Stronger-MAS 均关注多智能体 RL 的稳定性，但切入点截然不同。Stronger-MAS 通过角色专业化采样和树搜索机制缓解信用分配难题，侧重于数据分布的优化；而 Dr. MAS 聚焦于优势函数的归一化偏差，从梯度几何角度解决训练崩溃问题。两者的差异源于对不稳定根源的不同假设：前者认为不稳定源于奖励稀疏与轨迹多样性不足，后者认为源于全局统计量对异构分布的失配。这种差异暗示，在奖励分布高度异质的场景中，仅优化采样策略可能无法解决梯度尺度失衡问题，而 Dr. MAS 的修正可能无法完全弥补采样多样性不足带来的探索局限。

从方法设计看，Dr. MAS 与 veRL 等基础设施框架形成互补而非竞争关系。veRL 提供高吞吐量的单智能体训练流水线，但缺乏多智能体编排逻辑；Dr. MAS 在其基础上增加了按智能体资源池化与异构模型调度机制，实现了算法与系统的协同设计。然而，Dr. MAS 的系统框架仍基于同步训练假设，未处理异步 Rollout 带来的 Off-policy 偏差。相比之下，CoPRIS 等异步框架通过重要性采样校正解决偏差问题，但未考虑多智能体间的梯度尺度差异。这引出一个疑问：在异步多智能体训练中，按智能体独立归一化是否仍能有效抑制梯度尖峰，还是会被 Off-policy 校正权重所干扰？

## 总结

Dr. MAS 旨在解决多智能体 LLM 系统中因奖励分布异构导致的 GRPO 训练不稳定问题。现有方法缺乏对全局归一化偏差的理论解释，而本文通过推导梯度二阶矩，证明全局基线会系统性放大特定智能体的梯度范数，并提出按智能体独立归一化作为修正方案。实验表明，该修正在搜索任务中将 avg@16 从 28.0 提升至 43.8，并显著消除梯度尖峰。然而，其有效性局限于同步训练与特定层级编排，未验证在异步架构或更复杂拓扑下的表现。当智能体间存在强时序依赖或动态角色切换时，静态的按智能体归一化是否仍能保持梯度良态，论文未给出回答。
