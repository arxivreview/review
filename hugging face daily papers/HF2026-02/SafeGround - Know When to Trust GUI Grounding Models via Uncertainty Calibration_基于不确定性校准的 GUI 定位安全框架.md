# HuggingFace最新推荐论文 ｜SafeGround: Know When to Trust GUI Grounding Models via Uncertainty Calibration ｜基于不确定性校准的 GUI 定位安全框架

研究机构：美国加州大学圣塔芭芭拉分校、美国加州大学圣克鲁兹分校

作者：Qingni Wang、Yue Fan、Xin Eric Wang

论文原文见 [arXiv](https://arxiv.org/abs/2602.02419)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.02419)

> GUI 定位旨在将自然语言指令映射至屏幕坐标，是 GUI 智能体执行原子操作的基础。现有模型仅输出确定性坐标，缺乏对预测可靠性的量化，导致在支付、配置等不可逆操作中，单次定位错误即引发严重后果。本文切入点在于黑盒视觉语言模型（VLM）无法获取内部 Logits 进行置信度评估，且现有不确定性量化（UQ）方法不适用于坐标预测任务。SafeGround 通过多次随机采样构建空间分布，结合 Learn Then Test (LTT) 校准范式，实现了具有有限样本保证的风险可控定位。该框架在 ScreenSpot-Pro 上验证了级联推理的有效性，但采样带来的计算开销与校准集依赖限制了其实时部署潜力。

## 研究背景

GUI 定位的核心挑战已从单纯的坐标预测精度转向决策可靠性。当模型面对高分辨率密集布局时，视觉编码器分辨率限制导致小目标混淆，而多模态大语言模型（MLLMs）缺乏原生空间感知能力，使得语义到像素的映射存在固有噪声。在此背景下，不确定性量化（UQ）成为区分“可执行”与“需弃权”预测的关键机制。然而，传统 UQ 方法如概率置信度（Probabilistic Confidence, PC）依赖模型内部 Logits，这在黑盒 API 模型中不可得；语言化自我评估则依赖模型显式推理能力，在坐标生成任务中往往失效。

主流 GUI 定位路线如 SeeClick 和 UI-TARS 聚焦于通过大规模预训练或强化学习提升单步定位准确率，但均假设模型输出即为最终决策，未提供风险感知机制。ScreenSpot-Pro 基准揭示了模型在专业软件中的性能退化，进一步凸显了高风险场景下“知道何时不可信”比“提高平均准确率”更具工程价值。SafeGround 针对这一空白，提出在不修改底层模型架构的前提下，通过外部采样与统计校准构建安全层，将定位任务从“单次预测”转化为“风险受控的选择性预测”。

## 核心方法

### 方法参照系

标准 GUI 定位流程为：输入截图 $I$ 与指令 $T$，模型 $f$ 输出单一坐标 $\hat{y}$。SafeGround 的关键差异在于将单次确定性输出扩展为多次随机采样，并引入统计校准环节，将坐标预测转化为带有置信度阈值的决策过程。

### 分布感知不确定性量化

针对黑盒模型无法获取 Logits 的问题，SafeGround 采用蒙特卡洛采样策略。对同一输入执行 $K$ 次前向传播，生成坐标集合 $S = \{\hat{y}_i\}_{i=1}^K$。这些坐标被投影至离散化屏幕网格，通过密度聚类形成 $M$ 个区域 $R_m$，每个区域得分 $S_m$ 为其平均概率密度。不确定性由三个互补指标加权融合：

$$
U_{COM} = w_1 U_{TA} + w_2 U_{IE} + w_3 U_{CD}
$$

其中 $U_{TA}$ 衡量前两名候选区域的得分差（局部歧义），$U_{IE}$ 为区域得分分布的归一化熵（全局分散度），$U_{CD}$ 为二次集中度缺失（主导性缺乏）。该设计动机在于单一指标无法覆盖所有失效模式：$U_{TA}$ 捕捉相邻按钮混淆，$U_{IE}$ 捕捉多区域分散，$U_{CD}$ 捕捉无明确焦点。固定权重 $w$ 保证了跨模型的即插即用性，避免了针对特定骨干网络的调参。

### 基于 LTT 的 FDR 校准

UQ 分数本身不具备统计保证，SafeGround 引入 Learn Then Test (LTT) 范式进行阈值校准。在校准集 $\mathcal{D}_{cal}$ 上，对候选阈值 $\tau$ 计算经验 FDR，并利用 Clopper–Pearson 区间构造高概率上界 $\widehat{FDR}_{1-\delta}^{upper}(\tau)$：

$$
\widehat{FDR}_{1-\delta}^{upper}(\tau) = \frac{1}{N_{acc}(\tau)} \sum_{i=1}^N \mathbb{1}[u_i \le \tau, A(\hat{y}_i, B_i^*) = 0] + \frac{\beta^{-1}(1-\delta; N_{err}(\tau)+1, N_{acc}(\tau)-N_{err}(\tau)+1)}{N_{acc}(\tau)}
$$

该公式的物理含义是：在显著性水平 $\delta$ 下，给定校准集观测到的错误率，真实系统 FDR 可能达到的最大可信值。SafeGround 选择满足 $\widehat{FDR}_{1-\delta}^{upper}(\tau) \le \alpha$ 的最大 $\tau$，其中 $\alpha$ 为用户指定的最大可接受错误率。此设计解决了传统 UQ 仅输出分数而无决策规则的问题，提供了有限样本下的安全保证：以 $1-\delta$ 的概率，被接受预测中的错误比例不超过 $\alpha$。

## 实验评估

实验在 ScreenSpot-Pro 基准上进行，涵盖 Holo1.5、GUI-Actor、UI-TARS-1.5 等 6 个主流 GUI 定位模型。基线对比包括概率置信度（PC）和随机分数，但缺失对语言化自我评估（Verbalized Self-Assessment）具体实现的对比，仅定性提及其局限性。

| 模型 | 风险等级 0.34 准确率 (%) | 风险等级 0.42 准确率 (%) | AUROC (U_COM) | AUROC (PC) |
| :--- | :--- | :--- | :--- | :--- |
| Holo1.5-7B | 58.66 | 55.73 | 0.7526 | 0.6983 |
| Holo1.5-3B | 53.44 | 52.02 | 0.6576 | 0.6444 |
| UI-TARS-1.5-7B | 54.70 | 53.04 | 0.8021 | 0.7844 |
| GUI-Actor-2VL-7B | 55.18 | 53.99 | 0.8155 | - |

在风险等级 0.34 下，Holo1.5-7B 结合 SafeGround 级联推理达到 58.66% 准确率，较 Gemini-only 推理提升 5.38 个百分点。AUROC 结果显示，$U_{COM}$ 在所有可用 PC 的模型上均优于基线，例如 Holo1.5-7B 从 0.6983 提升至 0.7526。对于无法获取 PC 的 GUI-Actor 变体，$U_{COM}$ 仍取得 0.8155 的高分，验证了空间分布度量在黑盒约束下的鲁棒性。

消融实验表明，采样次数 $K$ 对不确定性估计质量有显著影响，但论文未详细报告 $K$ 与计算延迟的权衡曲线。在严格风险等级（如 0.38）下，PC 基线常因无法找到有效阈值而失效，而 $U_{COM}$ 保持了较高的统计功效（Power），即在接受相同 FDR 约束下保留了更多正确预测。这一发现暗示空间分散度比 Token 级概率更能区分高风险样本，但具体机制未深入剖析。

评估边界方面，实验仅覆盖 ScreenSpot-Pro 单一基准，未验证在通用场景（如 ScreenSpot-v2）下的泛化性。校准集比例固定为 0.8 测试比，未探讨小样本校准集对 FDR 保证稳定性的影响。代码未开源，超参数（如权重 $w$、采样次数 $K$）的具体取值未在正文中明确列出，限制了可复现性。

## 关联研究分析

从问题动机看，SafeGround 与 UI-Ins 形成互补。UI-Ins 通过结构化指令推理提升单步定位精度，旨在解决“定位不准”问题；SafeGround 则通过 UQ 解决“定位不可信”问题。两者在 ScreenSpot-Pro 上均表现优异，但 UI-Ins 依赖模型内部推理能力，而 SafeGround 作为外部后处理框架，可叠加于任何黑盒模型之上。这种差异源于任务特性：精度提升需改变模型决策逻辑，而风险控制仅需评估决策可靠性。SafeGround 未探索将 UQ 信号反馈至模型训练过程，而是将其局限于推理时决策，这是否限制了其在低资源场景下的潜力，论文未给出回答。

从方法设计看，SafeGround 借鉴了 GUI-Actor 的注意力聚合思想，但将其从“定位机制”转化为“不确定性信号源”。GUI-Actor 利用注意力头直接生成坐标，属于连续坐标生成路线；SafeGround 接受离散坐标输出，通过多次采样的空间分布间接估计置信度。这一选择避开了连续回归头与 LLM 自解码机制的集成难题，但牺牲了单次推理的效率。与 SeeClick 等纯视觉定位范式相比，SafeGround 不改变底层感知逻辑，而是增加安全层，这种解耦设计使得其易于集成，但也意味着其性能上限受限于底层模型的基线准确率。

## 总结

SafeGround 解决了 GUI 定位中“单次预测不可逆风险”与“黑盒模型缺乏置信度”的核心矛盾。其切入点在于利用多次随机采样的空间分布特性，替代不可得的内部 Logits，并通过 LTT 校准提供有限样本 FDR 保证。实验证明，在 ScreenSpot-Pro 上，该框架通过级联推理将 Holo1.5-7B 的系统准确率提升至 58.66%，较 Gemini-only 提升 5.38 个百分点，同时实现了严格的风险控制。然而，其边界在于依赖校准集标注且采样次数 $K$ 带来线性计算开销，未评估在实时交互场景下的延迟影响。当底层模型基线准确率极低时，级联推理能否在保持 FDR 保证的同时，通过外部资源弥补精度短板，论文未给出回答。
