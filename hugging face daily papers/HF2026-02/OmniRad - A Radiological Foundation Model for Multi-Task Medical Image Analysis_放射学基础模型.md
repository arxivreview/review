> 放射学分析面临多任务表征碎片化与跨模态泛化不足的双重困境，现有基础模型往往针对单一模态或任务独立适配，导致特征空间不一致且复用性差。OmniRad 通过修改 DINOv2 预训练策略并引入轻量级密集预测适配器，实现了单一编码器在分类、分割及描述任务上的统一表征复用。该方法在 MedMNIST 与 MedSegBench 基准上验证了表征的稳定性，但其 2D 切片处理范式与领域内 3D 体积感知的主流趋势存在显著错位，限制了其在复杂解剖结构任务中的直接适用性。

## 研究背景

放射学影像分析的核心挑战在于从非结构化像素中提取可复用的定量特征。传统放射组学（Radiomics）依赖手工设计特征，虽具可解释性，但对采集协议与分割质量极度敏感，难以在多中心场景下保持复现性。深度学习虽能自动提取特征，但全监督训练导致模型与特定任务或模态强耦合，跨域迁移时性能显著下降。为突破标注瓶颈，自监督学习（Self-Supervised Learning, SSL）成为主流，通过无标签数据预训练通用视觉表征，但现有医学基础模型常因预训练数据缺乏模态多样性或下游适配策略独立，导致分类与分割任务间的特征空间割裂。

该领域正从“任务特定模型”向“通用基础模型”演进，但关键瓶颈在于表征的任务无关性与跨模态稳定性。主流路线如 DINOv2 虽提升了表征通用性，但在放射学专用场景下，其局部裁剪机制导致训练不稳定且计算冗余，且缺乏对放射组学原则中“特征复用”的显式约束。OmniRad 的切入点在于将放射组学的稳定性原则融入 SSL 框架，通过单一共享编码器同时支持全局分类与密集分割，旨在解决多任务场景下特征碎片化与跨模态泛化不足的问题。

## 核心方法

### 方法参照系

OmniRad 基于 Vision Transformer (ViT) 骨干，采用 DINOv2 自蒸馏框架进行预训练。与标准 DINOv2 流程的关键差异在于：移除局部裁剪（local crops）以简化计算并提升稳定性，并在下游密集预测任务中引入冻结骨干与并行卷积分支的适配机制，而非端到端微调。

### 预训练策略优化

标准 DINOv2 依赖全局与局部裁剪的对比学习，但局部裁剪在放射学图像中引入大量冗余计算且易导致特征坍塌。OmniRad 仅保留全局裁剪，显著降低训练开销约 2 倍，同时消除模型回滚需求。该策略的物理含义是：通过强制模型关注整幅图像的全局语义结构，而非局部纹理细节，从而获得更稳定的跨模态表征。预训练损失函数保持 DINO 与 iBOT 原型对比的加权组合：

$$ \mathcal{L} = \mathcal{L}_{\text{DINO}} + \mathcal{L}_{\text{iBOT}} $$

其中 $\mathcal{L}_{\text{DINO}}$ 为全局裁剪间的对比损失，$\mathcal{L}_{\text{iBOT}}$ 为基于原型的掩码图像建模损失。此简化设计直接回应了放射学图像中局部特征对采集参数敏感的问题，提升了表征对域偏移的鲁棒性。

### 密集预测适配架构

ViT 的单尺度表征难以直接用于分割等密集预测任务，传统适配器如 ViTAdapter 计算开销过大。OmniRad 引入并行卷积分支，从 Transformer 的第 3、7、11 层提取中间 token 特征，重塑为空间特征图，并与 $1/8, 1/16, 1/32$ 尺度的卷积先验对齐。解码器采用双阶段上采样，每阶段包含双线性插值与 $3 \times 3$ 卷积，最终输出 $1/8$ 分辨率的分割 logits。该设计的核心动机是：在冻结骨干的前提下，通过轻量级卷积分支重建多尺度空间信息，避免全微调带来的过拟合与计算负担。视觉 token 的池化过程定义为：

$$ \mathbf{P} = \text{CrossAttention}(\mathbf{Q}, \mathbf{Z}) $$

其中 $\mathbf{Q}$ 为可学习查询，$\mathbf{Z}$ 为投影后的视觉 token，$\mathbf{P}$ 为压缩后的视觉前缀，用于后续语言模型对齐。

## 实验评估

实验在 MedMNISTv2（分类）与 MedSegBench（分割）上进行，基线涵盖 DINO、DINOv2、DINOv3、MAE、CLIP 及 Radio DINO。OmniRad base 在 MedSegBench 平均 Dice 达 92.95%，优于 Radio DINO base 的 92.86%；在 MedMNIST 分类任务中，OmniRad small 在 BreastMNIST 上 F1 达 89.42%，超过 DINOv3 base 的 87.22%。

| 数据集 | 模型 | F1 (%) | Dice (%) |
| :--- | :--- | :--- | :--- |
| BreastMNIST | OmniRad small | 89.42 | - |
| BreastMNIST | DINOv3 base | 87.22 | - |
| MedSegBench (Avg) | OmniRad base | 93.03 | 92.95 |
| MedSegBench (Avg) | Radio DINO base | 92.93 | 92.86 |

消融实验显示，全微调（Full Fine-tuning）性能最优，Head-only 微调次之，LoRA 适配性能最低。例如在 PneumoniaMNIST 上，全微调 F1 为 94.15%，而 LoRA (R=16) 降至 90.84%。这表明冻结骨干虽能保持表征稳定性，但牺牲了部分任务特异性精度，且性能高度依赖解码器设计而非单纯的参数更新策略。

评估边界存在明显局限：所有实验均基于 2D 切片，未涉及 3D 体积数据，无法验证其在解剖连续性要求高的任务（如脑肿瘤分割）中的泛化能力。代码与模型已开源，但预训练数据 RadImageNet 的模态分布细节未完全披露，限制了跨模态鲁棒性的独立复现。

## 关联研究分析

从问题动机看，OmniRad 与 TAP-CT 均致力于解决放射学基础模型的泛化问题，但路径截然不同。TAP-CT 聚焦 3D CT 体积数据，通过适配 DINOv2 捕捉解剖连续性，而 OmniRad 局限于 2D 切片，强调多任务表征复用。这一差异源于任务特性：2D 切片更适用于筛查与分类，而 3D 体积对空间上下文依赖更强。OmniRad 未探索 2D 表征向 3D 的迁移机制，其“任务无关”主张在 3D 场景下是否成立，缺乏实验支撑。

从方法设计看，OmniRad 与 MedGMAE 同属自监督预训练范畴，但预训练目标存在根本分歧。MedGMAE 采用高斯掩码自编码器，通过几何原语重建捕捉全局结构，而 OmniRad 沿用 DINOv2 的判别性对比学习。MedGMAE 在 AMOS 3D 分割上表现优异，暗示重建目标可能更适合密集预测；OmniRad 在 2D 分割上的小幅优势，可能得益于其轻量级解码器对 2D 空间结构的适配，而非预训练目标本身的优越性。这种“判别 vs. 重建”的路线之争，在 3D 医学影像中尚未有统一结论。

## 总结

OmniRad 试图解决放射学基础模型在多任务场景下表征碎片化的矛盾，通过简化 DINOv2 预训练策略并引入冻结骨干适配机制，实现了单一编码器在分类与分割任务上的统一复用。实验证明其在 2D 基准上优于 Radio DINO 等基线，MedSegBench 平均 Dice 达 92.95%，MedMNIST 分类 F1 提升最高 2.05%。然而，其 2D 切片范式与领域内 3D 体积感知的主流趋势脱节，且消融实验显示冻结骨干在密集预测中牺牲了部分精度，性能高度依赖特定解码器设计。当支持集规模扩大或任务转向 3D 体积分割时，该轻量级适配策略的边际收益是否递减，论文未给出回答。
