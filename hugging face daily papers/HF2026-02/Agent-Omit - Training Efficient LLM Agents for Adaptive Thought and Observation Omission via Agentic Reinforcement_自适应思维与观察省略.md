# HuggingFace最新推荐论文 ｜Agent-Omit: Training Efficient LLM Agents for Adaptive Thought and Observation Omission via Agentic Reinforcement Learning ｜自适应思维与观察省略

研究机构：香港科技大学

作者：Yansong Ning、Jun Fang、Naiqiang Tan 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.04284)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.04284)

> 多轮智能体交互中，思维链与观察反馈占据绝大部分 Token 成本，但现有压缩策略往往对所有轮次一视同仁，忽略了不同轮次对任务成功率的贡献差异。Agent-Omit 通过量化分析发现中间轮次的思维与观察具有可省略性，进而提出结合冷启动微调与感知省略的强化学习框架，使智能体能够自适应地丢弃冗余上下文。该方法在五个基准上实现了小模型与前沿大模型相当的任务准确率，同时显著降低了 Token 消耗，但其省略策略的泛化边界及奖励权重敏感性仍需进一步验证。

## 研究背景

多轮智能体交互的核心状态由思维（Thought, $\tau_t$）、动作（Action, $a_t$）与观察（Observation, $o_t$）构成。思维是智能体分析上下文并规划动作的推理过程，观察则是环境执行动作后返回的反馈。随着交互轮次增加，上下文窗口迅速膨胀，其中思维与观察的累积 Token 成为效率瓶颈，而动作本身仅占极小比例。这种上下文爆炸不仅增加了推理延迟，还可能导致关键信息被淹没，影响长程任务的决策质量。

当前提升智能体效率的主流路线分为三类：思维管理（Thought Management, TM）、观察管理（Observation Management, OM）及思维观察联合管理（Thought&Observation Management, TOM）。TM 方法如 DEPO 和 ToolLight 通过微调压缩思维 Token 长度，OM 方法如 Observation-Mask 采用启发式策略剪枝历史观察，TOM 方法如 ReSum 则利用 LLM 摘要工具同时压缩两者。然而，这些方法普遍假设整个交互轨迹的冗余度是均匀的，倾向于对全轨迹进行同等程度的压缩或修改。这种静态处理忽略了思维必要性与观察效用随轮次变化的动态特性，导致在关键轮次丢失信息或在冗余轮次保留噪声，限制了智能体在复杂任务中的效率与准确性平衡。

Agent-Omit 的切入点在于识别并利用这种轮次间的差异性。通过蒙特卡洛 rollout 分析，论文发现中间轮次的思维与观察往往对最终任务成功率贡献甚微，且省略它们不会降低准确率。基于此，Agent-Omit 不再依赖静态启发式规则，而是训练智能体学习一种自适应策略，动态决定在哪些轮次省略思维或观察，从而在保持任务效果的同时最大化 Token 节省。

## 核心方法

### 方法参照系

本文问题属于智能体效率优化范畴，与传统的上下文压缩或摘要方法不同，其核心差异在于将省略行为建模为智能体策略的一部分，而非后处理步骤。传统方法在推理结束后对轨迹进行压缩，而 Agent-Omit 在推理过程中实时决定省略，使智能体能够基于当前状态动态调整上下文窗口，从而更灵活地应对不同任务结构。

### 冷启动省略行为合成

为让智能体掌握省略格式，Agent-Omit 首先构建冷启动数据集。该阶段通过遍历交互轨迹，显式省略特定轮次的思维或观察，并验证省略后任务准确率是否下降。若下降，则标记该轮次为不可省略；否则，生成包含省略行为的单轮与多轮样本。单轮样本教会智能体生成空思维标签或观察省略指令，多轮样本则训练智能体在历史上下文缺失的情况下维持推理连续性。这一设计解决了通用 LLM 缺乏省略格式先验的问题，为后续强化学习提供了初始策略。

### 感知省略的智能体强化学习

冷启动阶段仅建立格式先验，无法适应动态环境。Agent-Omit 引入感知省略的智能体强化学习（Omit-Aware Agentic RL），通过双重采样策略与定制奖励函数优化智能体策略。双重采样包括完整轨迹（Full Trajectory）与部分轨迹（Partial Trajectory），前者评估整体效率与任务成功，后者确保智能体在省略前的上下文中学习省略决策，避免“上下文变化”问题。奖励函数结合任务奖励 $R_{task}$ 与省略奖励 $R_{omit}$，其中 $R_{omit}$ 定义为节省 Token 数与总 Token 数的比值，且当 $R_{task}=0$ 时 $R_{omit}=0$，防止智能体通过牺牲准确率换取效率。优化目标采用组相对策略优化（GRPO），最大化期望奖励并最小化 KL 散度：

$$
\mathcal{J}(\theta) = \mathbb{E}_{y \sim \pi_\theta} \left[ \frac{1}{n} \sum_{i=1}^n \left( r(y_i) + \sum_{j=1}^{p(y_i)} r'(y_i^{[j]}) \right) - \beta \text{KL}(\pi_\theta \| \pi_{ref}) \right]
$$

其中 $r(y) = (1-\mu)R_{task} + \mu R_{omit}$，$\mu=0.2$ 为权重系数。该公式表明，智能体在追求任务成功的同时，被显式激励减少冗余 Token，且 KL 散度项确保策略偏离参考策略的程度可控，从而在效率与稳定性之间取得平衡。

## 实验评估

实验在 DeepSearch、WebShop、TextCraft、BabyAI 和 SciWorld 五个基准上进行，对比基线包括前沿 LLM（如 DeepSeek-R1-0528、OpenAI o3）及七种效率优化方法（如 DEPO、ReSum）。Agent-Omit-8B-RL 在 WebShop、TextCraft、BabyAI 和 SciWorld 上取得最高 Pass@1 准确率，同时在所有基准上实现最低平均 Token 消耗。例如，在 WebShop 上，Agent-Omit-8B-RL 的 Pass@1 为 23.57%，平均 Token 为 8,764，优于 ReSum（17.80%, 9,251）和 DEPO（10.26%, 10,286）。

| 方法 | WebShop Pass@1 (%) | WebShop Avg Tok. | TextCraft Pass@1 (%) | TextCraft Avg Tok. |
| :--- | :--- | :--- | :--- | :--- |
| Qwen3-8B Base | 6.93 | 16,741 | 55.00 | 19,587 |
| DEPO | 10.26 | 10,286 | 62.00 | 13,256 |
| ReSum | 17.80 | 9,251 | 72.00 | 9,258 |
| Agent-Omit-8B-RL | 23.57 | 8,764 | 87.00 | 7,328 |

消融实验显示，单轮省略数据在冷启动阶段起主导作用，而部分轨迹采样在强化学习阶段比完整轨迹采样更重要。省略奖励是提升效率的关键因素，移除后模型无法实现比 SFT 版本更多的 Token 减少。此外，奖励权重 $\mu$ 从 0.2 调整为 0.1 或 0.3 均导致效果-效率权衡变差，表明该参数对任务特性敏感，缺乏跨任务鲁棒性。

评估边界方面，论文未报告置信区间，且部分前沿 LLM（如 OpenAI o3）因 API 限制无法获取 Token 统计，导致效率对比不完整。代码与数据已开源，训练使用 8 块 NVIDIA A100 GPU，超参数细节在附录中提供，具备可复现性。

## 关联研究分析

从问题动机看，Agent-Omit 与 DEPO 等思维管理方法均旨在减少思维 Token 消耗，但 DEPO 采用静态压缩策略，假设所有轮次的思维冗余度相同，而 Agent-Omit 通过轮次级分析识别动态冗余，使省略决策更精准。这一差异源于任务结构的复杂性：在长程任务中，早期规划思维至关重要，而中间执行思维往往冗余，静态压缩无法区分这种差异，导致关键信息丢失或冗余保留。Agent-Omit 的自适应策略更贴合实际任务需求，但在任务结构高度均匀的场景中，其优势可能不明显。

从方法设计看，Agent-Omit 与 ReSum 等联合管理方法均涉及思维与观察的压缩，但 ReSum 依赖外部 LLM 摘要器，存在摘要器与智能体内部推理之间的语义鸿沟，导致信息损失。Agent-Omit 则将省略行为内化为智能体策略，通过强化学习直接优化省略决策，避免了外部摘要器的引入。这种内化设计提高了智能体的自主性，但也增加了训练复杂度，且省略奖励的设计需要精细调参，否则可能导致效率与准确率的失衡。

## 总结

Agent-Omit 解决了多轮智能体交互中上下文爆炸与效率低下的核心矛盾，通过识别轮次间的思维与观察冗余差异，提出自适应省略策略。其切入点在于利用强化学习将省略行为内化为智能体策略，克服了静态压缩方法的局限性。实验证明，Agent-Omit-8B-RL 在五个基准上实现了小模型与前沿大模型相当的任务准确率，同时显著降低 Token 消耗，例如在 WebShop 上 Pass@1 达 23.57%，平均 Token 仅 8,764。然而，论文暴露的边界包括奖励权重 $\mu$ 的敏感性以及部分前沿 LLM 效率数据的缺失。当任务结构高度动态或奖励函数设计不当，自适应省略策略是否仍能保持稳定的效果-效率权衡，论文未给出回答。
