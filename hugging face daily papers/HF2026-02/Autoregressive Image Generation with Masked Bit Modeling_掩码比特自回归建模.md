# HuggingFace最新推荐论文 ｜Autoregressive Image Generation with Masked Bit Modeling ｜掩码比特自回归建模

作者：Qihang Yu、Qihao Liu、Ju He 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.09024)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.09024)

> 视觉生成领域长期存在离散与连续范式的性能鸿沟，主流观点认为连续潜空间在保真度上天然优于离散令牌。本文指出该差距主要源于比特预算分配不均，而非范式本质差异，提出掩码比特自回归建模（Masked Bit Autoregressive modeling, BAR）框架。通过引入掩码比特建模（Masked Bit Modeling, MBM）头，将令牌预测转化为条件比特生成任务，突破大码本扩展瓶颈。BAR在ImageNet-256上刷新了离散与连续范式的生成质量上限，但其结论高度依赖特定的比特量化器，跨量化器泛化性存疑。

## 研究背景

当自回归模型试图直接预测大规模离散视觉令牌时，预测头的计算复杂度随词表大小线性增长，导致内存溢出或训练停滞。这一困境源于离散令牌化中的码本规模限制：传统向量量化（Vector Quantization, VQ）为维持训练稳定性，通常将码本大小限制在 $2^{18}$ 以内，导致潜空间比特预算远低于连续变分自编码器（Variational Autoencoder, VAE）。比特预算不足造成严重的信息丢失，使得离散方法在重构保真度上长期落后于连续方法，进而限制了下游生成模型的质量上限。

视觉生成领域的主流路线分为连续扩散与离散自回归两类。连续方法依赖SD-VAE等标准骨干，通过KL正则化构建平滑潜空间，但收敛速度慢且采样成本高；离散方法天然适配多模态大语言模型，但受限于码本坍塌与词表扩展瓶颈，难以释放其信息容量潜力。现有研究多聚焦于优化量化器利用率或改进扩散轨迹，却忽视了比特预算这一统一度量对范式性能差距的决定性作用。本文切入点在于：通过统一比特预算视角揭示离散与连续方法的真实差距，并设计可扩展的预测机制，使离散范式在同等信息容量下超越连续范式。

## 核心方法

### 比特预算统一度量

离散与连续分词器的直接对比缺乏统一标准，前者以码本大小表征，后者以潜通道维度表征。本文引入比特预算（Bit Budget, $B$）作为统一度量，量化潜空间的信息容量。对于码本大小为 $C$ 的离散分词器，$B = \log_2 C \times H_f \times W_f$；对于潜通道维度为 $D$ 的连续分词器，$B = 16 \times D \times H_f \times W_f$（16为混合精度比特数）。该度量揭示了离散方法性能落后的根本原因：其比特预算通常仅为连续方法的1/4至1/8，导致重构质量差距并非源于量化瓶颈，而是信息容量不足。

### 掩码比特建模头

传统自回归生成器使用线性头预测码本索引，当码本扩展至 $2^{32}$ 以上时，线性头的内存复杂度 $O(C)$ 导致训练不可行；直接预测比特的基线方法虽可扩展，但生成质量随词表扩大而严重退化。本文提出掩码比特建模（Masked Bit Modeling, MBM）头，将令牌预测重构为条件比特生成任务。给定自回归Transformer输出的潜条件 $z_{i-1}$，MBM头通过迭代去掩码过程生成目标令牌 $x_i$ 的 $k$ 位二进制表示：

$$
\hat{x}_i = G_\theta(z_{i-1}, \text{Mask}_{\text{bit}}(x_i))
$$

其中 $\text{Mask}_{\text{bit}}(\cdot)$ 随机掩码 $x_i$ 的部分比特，$G_\theta$ 为轻量级3层SwiGLU网络。训练时优化比特级交叉熵损失：

$$
\mathcal{L} = \frac{1}{n} \sum_{i=1}^n \text{CrossEntropy}_{\text{bit}}(\hat{x}_i, x_i)
$$

该设计将预测头复杂度从 $O(C)$ 降至 $O(\log_2 C)$，使自回归Transformer在码本扩展时保持计算不变，仅由MBM头吸收词表增长负担。比特级掩码作为强正则化器，显著提升了大词表下的生成稳定性，解决了线性头内存瓶颈与比特头质量退化的双重失效。

## 实验评估

实验在ImageNet-256基准上进行，对比覆盖连续扩散（DiT, MAR, RAE）与离散自回归（VAR, MAGVIT-v2, RAR）两类主流方法。基线审计显示，本文未对比最新VFM适配类方法（如DINO-Tok），但覆盖了离散范式的主要代表。主实验结果表明，BAR-B（415M参数）以gFID 1.13超越RAR（1.5B参数，gFID 1.48）及VAR（gFID 1.92），并优于连续方法xAR（gFID 1.24）与DDT（gFID 1.26）。BAR-L（1.1B参数）进一步将gFID降至0.99，刷新了离散与连续范式的SOTA记录。

| 方法 | 参数量 | gFID (w/o guidance) | gFID (w/ guidance) |
| :--- | :--- | :--- | :--- |
| RAR | 1.5B | 1.52 | 1.48 |
| VAR | 2.0B | 1.97 | 1.92 |
| xAR | 1.1B | - | 1.24 |
| RAE | 839M | 1.51 | 1.13 |
| BAR-B | 415M | 1.64 | 1.13 |
| BAR-L | 1.1B | 1.42 | 0.99 |

消融实验验证了MBM头在不同码本规模下的优势。当码本从 $2^{10}$ 扩展至 $2^{64}$ 时，线性头在 $2^{18}$ 以上出现OOM，比特头gFID从10.77恶化至183.0，而MBM头gFID稳定在1.19-1.67区间。在 $2^{32}$ 码本下，MBM头gFID 1.37显著优于比特头的5.81，证明迭代去掩码机制有效缓解了大词表下的统计优化困难。采样速度方面，BAR-B/2以150.52 img/s达到与MeanFlow（151.48 img/s）相当的速度，但gFID更优（1.35 vs 2.20）。

评估边界方面，本文仅报告ImageNet-256结果，未涉及高分辨率或视频生成；MBM头的迭代步数对质量-速度权衡的具体曲线未详细披露；代码开源但超参数配置严格遵循RAR，未提供独立训练细节。可复现性受限于H200 GPU环境，float32精度下基准测试可能影响跨硬件对比。

## 关联研究分析

从问题动机看，本文与RAR同属离散自回归生成框架，但RAR依赖线性头预测码本索引，受限于 $2^{18}$ 码本上限；本文通过MBM头将预测任务解耦，使码本可扩展至 $2^{64}$ 以上。这一差异源于对“词表扩展瓶颈”的不同认知：RAR视其为硬件限制，本文视其为预测头设计缺陷。从方法设计看，本文与Infinity同为大码本离散生成，但Infinity依赖外部比特修正器后处理，本文MBM头为自包含设计，无需额外模块。这一差异暗示Infinity的修正器可能掩盖了生成过程中的比特错误累积，而MBM的迭代去掩码机制在生成阶段即保证比特一致性。

## 总结

本文核心矛盾在于离散范式因比特预算不足导致的性能劣势，以及大码本扩展引发的训练不可行性。切入点在于统一比特预算度量揭示差距本质，并通过MBM头将预测复杂度与词表大小解耦。方法上，BAR将令牌预测重构为条件比特生成，使离散方法在同等信息容量下超越连续范式。实验证明BAR-L在ImageNet-256上实现gFID 0.99，采样速度较连续方法提升3.68倍。边界在于结论高度依赖FSQ量化器，未验证其他量化方案（如LFQ）下的泛化性；MBM头的迭代步数与生成质量的权衡关系未充分探索。当码本扩展至 $2^{128}$ 以上时，MBM头的迭代去掩码过程是否仍能保证比特级一致性，论文未给出回答。
