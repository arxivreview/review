# HuggingFace最新推荐论文 ｜RoboCurate: Harnessing Diversity with Action-Verified Neural Trajectory for Robot Learning ｜基于仿真重放一致性的神经轨迹数据过滤与增强

研究机构：韩国科学技术院

论文原文见 [arXiv](https://arxiv.org/abs/2602.18742)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.18742)

> 机器人基础模型的性能受限于遥操作数据的稀缺性，而视频生成模型产生的“神经轨迹”虽能缓解此问题，却常因物理失真或逆动力学模型误差导致动作标签失效。现有基于视觉语言模型的质量评估过于粗糙，无法直接验证动作的正确性。本文提出RoboCurate，通过仿真器重放预测动作并比对生成视频的运动一致性来过滤低质数据，同时利用图像与视频扩散模型扩展场景多样性。该方法在预训练阶段显著提升了视觉-语言-动作模型的性能，但其依赖精确动力学模型的假设限制了其在未知物理环境中的适用性。

## 研究背景

理解本文需厘清神经轨迹生成中的两个核心环节：视频生成与动作标注。视频生成模型（如I2V）从初始帧和文本指令生成任务执行视频，但缺乏动作标签；逆动力学模型（IDM）则从视频帧对反推动作序列，充当伪标签器。然而，IDM是学习模型而非物理定律，当生成视频出现物体重叠或形变等物理不合理现象时，IDM预测的动作将与视频实际运动脱节，导致训练数据质量下降。

视动策略学习领域长期面临数据稀缺与开放世界泛化的矛盾。主流路线包括基于仿真的合成数据生成和基于视频模型的神经轨迹生成。仿真数据虽动作标签精确，但存在显著的仿真到现实差距（Sim-to-Real Gap）且环境构建成本高；神经轨迹视觉逼真且易于通过文本提示生成多样任务，但缺乏物理约束。Jang et al. (2025) 提出的DreamGen管线确立了I2V+IDM的标准流程，但实验表明其带来的性能增益有限。本文的切入点在于：不直接优化策略网络，而是通过引入物理接地机制提升合成数据本身的质量，解决神经轨迹中动作标签不可靠的根本问题。

## 核心方法

### 方法参照系

标准神经轨迹生成流程包含视频生成与IDM动作标注两步，直接用于策略训练。本文的关键差异在于插入“动作验证”环节，将动作正确性评估转化为视频运动一致性分类问题，并前置了视觉多样性增强步骤。

### 视觉多样性增强管线

标准I2V生成仅依赖初始帧和指令，场景变化有限。本文在视频生成前引入图像到图像（I2I）编辑，利用Canny边缘图保持场景结构，沿桌面外观、目标物体、光照、背景四个轴生成变体；在视频生成后引入动作保持的视频到视频（V2V）迁移，仅改变纹理和颜色而保留运动动力学，从而复用IDM标注的动作。该设计解决了单一初始帧导致的场景同质化问题，使合成数据覆盖更广泛的视觉分布。

### 基于仿真重放的动作一致性过滤

IDM预测的动作 $a_{IDM}$ 可能因视频物理失真而错误。本文将 $a_{IDM}$ 在仿真器中重放，渲染出运动与动作严格对应的代理视频 $\mathbf{w}_{sim}(a_{IDM})$。动作验证被重构为判断生成视频 $\mathbf{w}_{gen}$ 与代理视频 $\mathbf{w}_{sim}$ 的运动一致性。训练一个轻量级注意力探针 $g_\theta$，输入两个视频编码器的特征拼接，输出对齐概率：

$$
p = \sigma(g_\theta([f_\phi(\mathbf{w}_{gen}), f_\phi(\mathbf{w}_{sim})]))
$$

其中 $f_\phi$ 为冻结的视频编码器，$\sigma$ 为sigmoid函数。探针通过真实演示数据构建的正负样本对训练，负样本包括时间错位和跨片段配对。仅当 $p$ 超过阈值时保留该样本。此机制直接评估动作与视觉运动的对应关系，弥补了VLM仅判断视频合理性的不足。

## 实验评估

实验在GR-1 Tabletop（24任务）和DexMimicGen（6任务）上进行预训练评估，并在ALLEX人形机器人上进行真实世界共微调。基线包括仅真实数据、DreamGen（无过滤无增强）及本文方法。所有合成数据方法均使用10K预过滤神经轨迹以确保公平。

| 方法 | GR-1 Tabletop (300 demos) Avg. | DexMimicGen Avg. |
| :--- | :--- | :--- |
| Real only | 15.4 | 44.6 |
| w/ DreamGen | 19.5 | 46.4 |
| w/ RoboCurate (No Filter) | 22.7 | 49.3 |
| w/ RoboCurate (Filter) | 26.2 | 51.8 |

RoboCurate在GR-1 Tabletop上较Real-only提升10.8个百分点，较DreamGen提升6.7个百分点；在DexMimicGen上较DreamGen提升5.4个百分点。消融实验显示，仅增加视觉多样性（无过滤）已带来3.2个百分点的提升，而加入过滤机制进一步带来3.5个百分点的增益，表明多样性与质量过滤均有独立贡献。在ALLEX真实机器人上，RoboCurate实现+179.9%的相对成功率提升，而DreamGen仅为+100.0%，且在新物体抓取任务上从0.0%提升至25.0%。

评估边界方面，实验未报告推理延迟或计算开销，无法评估“精度-效率”平衡。代码未公开，超参数细节（如过滤阈值 $c$ 的具体取值）仅在附录中提及，可复现性受限。此外，实验未对比其他合成数据方法（如基于物理引擎的增强），基线覆盖较窄。

## 关联研究分析

从问题动机看，本文与DreamGen (Jang et al., 2025) 同属神经轨迹路线，但DreamGen假设IDM标注足够可靠，直接用于训练；本文则质疑IDM的可靠性，引入仿真重放作为物理接地验证。这一差异源于对合成数据质量瓶颈的不同判断：DreamGen认为数据量是主要限制，本文认为数据质量（动作-视觉一致性）是更关键的制约因素。

从方法设计看，本文与Diffusion Policy等策略生成方法属于不同层级：后者优化策略网络以建模多模态动作分布，本文优化训练数据分布以提升策略上限。与Open X-Embodiment等跨具身数据集工作相比，本文聚焦于单一具身（GR-1/ALLEX）内的数据增强，未探索跨具身动作空间对齐问题。仿真重放机制依赖精确动力学模型，这在动力学未知或高度非线性的场景中可能失效，论文未讨论此局限。

## 总结

本文针对神经轨迹中动作标签不可靠的问题，提出通过仿真重放一致性验证动作正确性，并结合I2I/V2V增强扩展数据多样性。实验证明该框架在预训练阶段显著提升VLA性能，GR-1 Tabletop上较基线提升10.8个百分点，ALLEX真实机器人上实现+179.9%相对提升。其边界在于依赖精确仿真器动力学，且未评估计算开销。当仿真器动力学模型存在显著误差时，基于重放一致性的过滤机制是否仍能有效区分高质量与低质量样本，论文未给出回答。
