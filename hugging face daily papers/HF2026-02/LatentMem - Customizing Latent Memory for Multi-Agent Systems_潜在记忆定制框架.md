# HuggingFace最新推荐论文 ｜LatentMem: Customizing Latent Memory for Multi-Agent Systems ｜潜在记忆定制框架

研究机构：同济大学、香港中文大学

作者：Muxin Fu、Xiangyuan Xue、Yafu Li 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.03036)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.03036)

> 多智能体系统（MAS）在长时程任务中面临记忆同质化与信息过载的双重瓶颈，现有基于文本摘要或图谱的记忆架构因缺乏角色感知与计算冗余而失效。LatentMem 通过引入可微分的潜在空间记忆合成器，将原始轨迹压缩为固定长度的角色感知向量，并利用强化学习端到端优化该过程。该方案在知识问答与代码生成任务上实现了最高 18.45% 的性能提升，但其潜在表示的黑箱特性与对特定骨干模型的依赖，限制了其在高风险场景及异构框架中的泛化边界。

## 研究背景

多智能体系统的协作效能依赖于各智能体对历史交互经验的积累与复用，这一过程通常由外部记忆模块支撑。然而，当多个智能体共享同一记忆库时，若记忆单元未区分智能体的功能角色，会导致“记忆同质化”：所有智能体检索到相同的上下文，削弱了角色分工的必要性，并放大相关错误。同时，多粒度记忆设计往往引入大量离散文本条目，造成“信息过载”，使大语言模型（LLM）的注意力机制在冗长上下文中稀释关键决策信号。

现有主流路线试图通过结构化组织解决上述问题，如 MetaGPT 和 OAgents 采用多粒度文本摘要或技能模式，Mandol 和 MAGMA 依赖结构化语义图或知识图谱进行检索。这些方法虽提升了信息组织度，但本质上仍属于“手工工程”范畴：记忆内容的提取、压缩与更新依赖预定义规则或启发式评分，缺乏针对特定智能体角色的自适应能力，且文本形式的记忆在注入上下文时不可避免地增加 Token 开销。LatentMem 的切入点在于将记忆表示从离散的文本空间迁移至连续的潜在空间，通过可学习的合成器实现角色感知的记忆定制，从而在保持 Token 效率的同时，打破“一刀切”的记忆共享模式。

## 核心方法

### 潜在记忆合成参照系

传统 MAS 记忆流程通常包含轨迹存储、基于相似度的检索以及文本摘要注入三个环节。本文的关键差异在于摒弃了显式的文本摘要生成步骤，转而引入一个可微分的记忆合成器（Memory Composer），将检索到的原始轨迹与智能体角色档案（Role Profile）直接映射为固定长度的潜在向量，该向量作为额外 Token 嵌入智能体的推理输入中。

### 角色感知的潜在记忆生成

记忆合成器 $\sigma_\phi$ 的核心设计动机是解决记忆同质化问题，即通过条件化输入实现角色特定的记忆定制。给定查询 $q$ 检索到的轨迹集 $T_q$ 和当前活跃智能体 $a_{\alpha_j}$ 的角色档案 $\gamma_{\alpha_j}$，合成器生成固定长度 $L'$ 的潜在记忆矩阵 $m_j$：

$$ m_j = \sigma_\phi(T_q, \gamma_{\alpha_j}) \in \mathbb{R}^{L' \times D} $$

该公式表明，潜在记忆并非轨迹的通用压缩，而是受角色档案约束的特定表示。智能体将 $m_j$ 与其输入提示的隐藏状态 $h_j$ 拼接，形成增强输入 $\tilde{h}_j = [h_j; m_j]$。这种设计使得不同角色（如策略智能体与代码智能体）从同一轨迹中提取出侧重不同的潜在特征，从而在推理阶段强化角色合规性，避免盲目跟随检索到的通用轨迹。

### 潜在记忆策略优化（LMPO）

LMPO 旨在解决潜在记忆合成器缺乏任务级反馈信号的问题，使其能够自主优化以生成高效用表示。LMPO 基于组相对策略优化（GRPO）变体，通过多智能体 rollout 中的相对奖励计算优势函数，并利用潜在记忆的可微分性将梯度回传至合成器参数 $\phi$。其 token 级代理目标函数定义为：

$$ \mathcal{L}_{LMPO} = -\mathbb{E}_{\{ \hat{\tau}_i \}_{i=1}^G} \left[ \frac{1}{|\{ \hat{\tau}_i \}_{i=1}^G|} \sum_{i,j,t} \min \left( r_{i,j,t}(\phi) \hat{A}_{i,j,t}, \text{clip}(r_{i,j,t}(\phi), 1-\epsilon, 1+\epsilon) \hat{A}_{i,j,t} \right) \right] $$

其中 $r_{i,j,t}(\phi)$ 是重要性采样比率，$\hat{A}_{i,j,t}$ 是基于组内相对奖励计算的 token 级优势。该机制允许合成器在冻结智能体骨干网络的前提下，通过任务完成度信号反向调整潜在记忆的生成策略，实现记忆内容的端到端自适应优化，而非依赖静态的相似度检索。

## 实验评估

实验在 TriviaQA、KodCode、StrategyQA、PopQA、BigCodeBench 和 PDDL 六个基准上，结合 AutoGen、MacNet、CAMEL 和 DyLAN 四个 MAS 框架进行验证。基线覆盖了 Voyager、MetaGPT、OAgents 等代表性单智能体与多智能体记忆方法，但缺乏与 Mandol、MAGMA 等最新结构化图谱方法的直接对比，这可能低估了潜在记忆在复杂多跳推理任务上的相对优势。

| 方法 | TriviaQA (AutoGen) | KodCode (AutoGen) | PDDL (AutoGen) | KodCode (CAMEL) |
| :--- | :--- | :--- | :--- | :--- |
| No-memory | 60.31 | 79.53 | 53.61 | 56.96 |
| MetaGPT | 58.25 | 79.15 | 52.11 | 58.04 |
| OAgents | 59.85 | 80.52 | 54.89 | 58.33 |
| **LatentMem** | **76.51** | **81.49** | **60.72** | **68.74** |

LatentMem 在域内基准上表现显著，如在 AutoGen 的 TriviaQA 上较无记忆基线提升 16.20%，在 KodCode 上提升 1.96%。在域外基准 PDDL 上，LatentMem 达到 60.72%，而 MetaGPT 和 Voyager 分别下降 4.44% 和 2.77%，表明其潜在表示具备更强的跨域泛化能力。在未见过的 CAMEL 框架上，LatentMem 在 KodCode 上提升 7.05%，而多数基线性能下降，验证了角色感知记忆对新协作模式的适应性。

消融实验显示，潜在记忆长度 $L'$ 设为 8 时性能达到平衡，进一步增加长度收益递减；检索轨迹数 $K$ 设为 1 时效果最佳，表明高质量的角色感知压缩比大量冗余轨迹更有效。评估边界方面，论文未报告置信区间，且所有实验基于 Qwen3-4B 和 Llama-3.1-8B 两个骨干模型，缺乏对更大规模模型或不同架构 LLM 的验证。代码已开源，但 LMPO 的训练细节（如奖励函数具体实现）在正文中描述较为简略，复现需依赖附录。

## 关联研究分析

从问题动机看，LatentMem 与 Mandol 和 MAGMA 形成鲜明对比。Mandol 和 MAGMA 致力于通过结构化语义图或多图谱解决多跳推理和时序逻辑问题，其核心假设是“结构化组织优于扁平表示”。而 LatentMem 假设“角色感知的潜在压缩优于显式结构”，其优势在于 Token 效率（减少 50% Token）和端到端可优化性，而非显式的关系推理能力。这种差异源于任务特性：MAS 协作更强调角色分工与上下文对齐，而非单一事实的多跳检索。LatentMem 在 PDDL 等符号规划任务上的优势，暗示潜在表示在捕捉抽象规划模式上可能优于显式图谱，但其在 MuSiQue 等多跳问答基准上的表现未在本实验中验证，这是其与结构化方法对比的关键盲区。

从方法设计看，LatentMem 与 MemGPT 和 Generative Agents 存在继承与背离。MemGPT 引入操作系统类比进行分层记忆调度，Generative Agents 使用重要性评分管理记忆流，二者均依赖显式的文本记忆单元和启发式更新规则。LatentMem 继承了轨迹存储的思想，但摒弃了文本摘要和评分机制，转而使用可微分合成器和 RL 优化。这一背离解决了启发式规则难以覆盖长尾场景的问题，但引入了潜在表示的可解释性缺失。在高风险场景（如医疗或法律 MAS）中，无法追溯潜在记忆具体对应哪些原始事实，可能成为部署障碍。此外，LatentMem 的 LMPO 依赖任务级奖励，这在奖励信号稀疏或延迟的任务中可能面临优化困难，而 MemGPT 的分层调度不依赖奖励信号，具有更强的鲁棒性。

## 总结

LatentMem 旨在解决 MAS 中记忆同质化与信息过载的矛盾，其切入点在于将记忆表示从离散文本迁移至可微分的潜在空间，通过角色档案条件化合成与 LMPO 端到端优化，实现了 Token 高效的角色感知记忆定制。实验证明其在知识问答和代码生成任务上较 SOTA 提升最高 18.45%，并在未见过的 MAS 框架上展现出 7.90% 的泛化增益。然而，其潜在表示的黑箱特性与对特定骨干模型的依赖，限制了其在需要可解释性的高风险场景中的应用。当任务涉及复杂的多跳事实推理而非角色协作时，潜在记忆是否仍能保持对结构化图谱的优势，论文未给出回答。
