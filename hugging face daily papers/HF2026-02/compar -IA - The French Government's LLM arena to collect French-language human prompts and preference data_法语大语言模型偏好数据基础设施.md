# HuggingFace最新推荐论文 ｜compar:IA: The French Government's LLM arena to collect French-language human prompts and preference data ｜法语大语言模型偏好数据基础设施

论文原文见 [arXiv](https://arxiv.org/abs/2602.06669)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.06669)

> 大语言模型在非英语语言上的对齐能力受限于偏好数据的稀缺性，现有开源数据集以英语为主，法语占比极低。compar:IA 通过构建面向普通公众的盲测竞技场，解决了非英语偏好数据规模化获取与开放共享的瓶颈。该平台采用无账号、低摩擦的交互设计，结合隐私过滤管道，实现了大规模真实用户偏好的采集与发布。其价值在于填补了法语偏好数据的空白，但用户自选择偏差与缺乏算法验证限制了其作为对齐基准的完备性。

## 研究背景

大语言模型（LLM）在法语等非英语语言上的表现往往出现流畅度下降、语域错配及安全保证减弱，根源在于预训练与后训练数据中英语占绝对主导。以 Llama 2 为例，其技术报告披露法语仅占训练语料的 0.16%。这种数据不平衡直接导致模型在特定语言文化语境下的对齐失效，而解决这一问题的关键在于获取高质量的人类偏好数据。

强化学习从人类反馈（RLHF）与直接偏好优化（DPO）等主流对齐算法依赖成对偏好数据来优化策略，但大规模开源偏好数据集在非英语领域极度匮乏。LMSYS Chat-1M 等现有基准中法语对话占比仅为 1.5%，且多数专有系统的数据不对外开放，导致学术界与中小企业难以获取用于训练或评估的法语偏好资源。这种数据垄断不仅限制了模型多样性，也阻碍了非英语语言对齐研究的进展。

compar:IA 由法国政府发起，旨在通过公共数字服务解决上述数据缺口。不同于依赖专家标注或封闭系统的传统模式，该平台利用盲测成对比较机制，从以法语为母语的普通公众中收集无约束的真实提示与偏好投票。这一切入点将数据收集从“专家任务”转化为“公众参与”，通过降低参与门槛来换取数据规模与真实性，为多语言对齐研究提供了新的基础设施范式。

## 核心方法

### 盲测成对比较交互架构

compar:IA 的核心流程基于盲测成对比较，用户输入自由提示后，两个匿名模型并生成响应，用户通过消息级反应与对话级投票提供反馈。这一设计消除了品牌偏见与期望偏差，确保偏好信号反映内容质量而非模型知名度。交互流程包含提示输入、盲测响应展示、细粒度反馈提交及模型身份揭示四个阶段，其中反馈机制分为消息级（针对单条回复）与对话级（针对整体交互）两个层级，分别捕捉局部与全局偏好。

### 隐私保护与数据过滤管道

为平衡数据开放与隐私保护，compar:IA 实施了保守的隐私过滤策略。所有数据在发布前经过基于大语言模型的个人数据检测管道，若检测到个人身份信息（PII）或敏感信息，则整段对话及其关联投票与反应被完全排除，而非进行片段级匿名化。该策略导致约 5% 的对话被过滤，但显著降低了再识别风险，简化了 GDPR 合规流程。

$$
P_{filtered} = \frac{N_{total} - N_{excluded}}{N_{total}} \approx 0.95
$$

其中 $N_{total}$ 为总对话数，$N_{excluded}$ 为因隐私原因排除的对话数。该公式表明，尽管数据量有所损失，但保留了 95% 的数据完整性，确保了数据集在隐私安全前提下的可用性。

### 开放数据发布与许可证体系

compar:IA 将数据分为三个互补数据集：对话（comparia-conversations）、投票（comparia-votes）与反应（comparia-reactions），分别对应不同粒度的交互信号。所有数据在 Hugging Face 与 data.gouv.fr 上持续发布，采用 Etalab 2.0 开放许可证。专有模型响应仅允许用于分析与评估，禁止用于训练或微调，这一限制在保障数据开放性的同时，尊重了专有模型的知识产权边界。

$$
\mathcal{D} = \{ \mathcal{D}_{conv}, \mathcal{D}_{vote}, \mathcal{D}_{react} \}
$$

其中 $\mathcal{D}_{conv}$ 包含多轮对话，$\mathcal{D}_{vote}$ 包含对话级偏好标注，$\mathcal{D}_{react}$ 包含消息级反馈信号。这种分层结构支持从粗粒度到细粒度的多种对齐训练需求，为后续研究提供了灵活的数据接口。

## 实验评估

compar:IA 未进行传统的算法对比实验，而是通过平台运营数据与初步分析展示其作为数据基础设施的有效性。截至 2026-02-07，平台收集了超过 600,000 条自由提示与 250,000 条偏好投票，其中法语占比 89.14%。数据主题分布显示，自然科学与教育类提示合计占比 31.95%，反映了平台在教育领域的高渗透率。

| 语言 | 数量 | 占比 |
| :--- | :--- | :--- |
| 法语 (fr) | 357,842 | 89.14% |
| 英语 (en) | 34,335 | 8.55% |
| 西班牙语 (es) | 2,571 | 0.64% |
| 丹麦语 (da) | 1,240 | 0.31% |

| 类别 | 数量 | 占比 |
| :--- | :--- | :--- |
| 自然科学与形式科学与技术 | 145,357 | 17.67% |
| 教育 | 117,452 | 14.28% |
| 商业、经济与金融 | 83,111 | 10.10% |
| 社会与社会问题与人权 | 57,065 | 6.94% |

评估边界方面，compar:IA 未提供标准基准（如 AlpacaEval 2.0）上的算法性能对比，也未验证基于其数据训练的 DPO 模型是否优于英语数据训练模型。平台排行榜基于 Bradley-Terry 模型构建，但受限于提示分布、用户群体自选择效应，其排名仅具指示性而非决定性。此外，由于缺乏社会人口统计信息，无法进行用户群体偏差校正，限制了偏好分析的深度。

## 关联研究分析

从数据获取机制看，compar:IA 与 LMSYS Chatbot Arena 同属盲测成对比较范式，但前者通过政府公共服务属性降低了参与门槛，吸引了更广泛的普通公众而非技术专家。这一差异源于任务特性：LMSYS 侧重模型评估，用户多为技术爱好者；compar:IA 侧重数据收集，需最大化数据规模与真实性。然而，公众参与是否比专家标注更能捕捉真实用户偏好分布，论文未给出定量回答，仅通过 600k 提示规模间接证明其可行性。

从数据质量维度看，compar:IA 的隐私过滤策略与现有数据清洗方法（如 P5 中的样本级复合风险评分）存在本质差异。前者采用整段对话排除的保守策略，后者通过加权或修正保留数据。compar:IA 的选择牺牲了 5% 的数据量以换取更高的隐私安全性，这一权衡在 GDPR 合规场景下具有必要性，但在数据稀缺的非英语领域，是否导致关键偏好信号丢失，论文未进行消融分析。

## 总结

compar:IA 解决了非英语语言偏好数据稀缺的核心矛盾，通过构建面向公众的盲测竞技场，实现了法语偏好数据的规模化获取与开放共享。其切入点在于利用政府公共服务的低摩擦特性，将数据收集从专家任务转化为公众参与，从而突破专有系统的数据垄断。平台收集了超过 600,000 条提示与 250,000 条投票，其中法语占比 89.14%，为法语对齐研究提供了基础数据资源。然而，其边界在于用户自选择偏差导致的数据代表性局限，以及缺乏算法验证导致的对齐效果不确定性。当基于 compar:IA 数据训练的 DPO 模型在法语基准上的性能提升幅度，是否足以抵消用户群体偏差带来的噪声，论文未给出回答。
