# HuggingFace最新推荐论文 ｜FLAT: Resampling Image and Text into 1D Flexible-Length Aligned Transmodal Tokens for Retrieval and Generation ｜灵活长度对齐跨模态表征

研究机构：Meta AI

作者：Guangyu Sun、Shlok Kumar Mishra、Wentao Bao 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2609.16591)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.16591)

> 传统多模态系统将表征学习与生成建模割裂，导致生成性能受限于冻结的编码器。现有统一模型虽尝试联合训练，但往往依赖离散 Token 或固定长度序列，难以兼顾检索的判别性与生成的保真度。FLAT 提出一种表征预训练框架，通过共享编码器将图像与文本重采样为连续 1D 序列，并利用嵌套 Dropout 实现推理时的动态长度选择。该框架在 2B 参数规模下实现了 SOTA 级别的生成与检索性能，但其对 VLM 骨干的依赖及高分辨率生成的扩展性仍存疑。

## 研究背景

多模态模型面临的核心困境在于表征的双重需求：检索任务需要紧凑的语义描述符以区分类别，而生成任务需要丰富的细节条件以重建像素。CLIP 等对比学习模型确立了视觉-语言对齐的基准，但其冻结的表征空间无法直接驱动高质量生成；反之，Stable Diffusion 等生成模型依赖冻结的文本编码器，导致语义理解与生成能力脱节。这种割裂迫使下游模型在预训练编码器与生成解码器之间进行复杂的再对齐，限制了统一架构的涌现潜力。

统一多模态理解与生成领域正从功能集成转向认知协同，但主流路线存在明显瓶颈。纯自回归架构（如 Chameleon）通过离散 Token 化实现了架构统一，却因高频细节丢失导致生成保真度远低于专用扩散模型；解耦架构（如 Janus）虽缓解了梯度冲突，但增加了参数冗余且削弱了知识共享。FLAT 的切入点在于重新审视“联合表征学习与生成”这一被低估的方向，主张检索与生成是相互增强的过程，而非相互冲突的目标。通过构建一个既支持判别性检索又支持生成性条件的统一连续表征空间，FLAT 试图在单一编码器内消解理解与生成之间的表征冲突。

## 核心方法

### 1D 连续表征编码

FLAT 摒弃了传统的离散 VQ-VAE Token 化，转而采用基于预训练视觉语言模型（VLM）的连续 1D 表征。输入图像或文本 $x$ 被追加 $N$ 个可学习的寄存器 Token $R$，经共享编码器 $f_{enc}$ 处理后，提取寄存器位置的隐藏状态并线性投影得到表征 $z \in \mathbb{R}^{N \times d}$。这一设计的关键差异在于，它不将视觉信息压缩为固定长度的离散码本，而是保留为可变长度的连续向量序列，从而规避了离散化带来的信息不可逆损失，为后续的线性插值与算术运算奠定了几何基础。

### 嵌套 Dropout 与双向生成

为解决固定长度序列在推理时的灵活性不足，FLAT 引入嵌套 Dropout 机制。在训练阶段，每个批次从几何阶梯 $K \in \{1, 4, 16, 64, 256\}$ 中采样一个保留长度，仅使用前缀 $z_{:K}$ 参与对比损失与生成损失计算。这种设计使得模型在推理时可通过调整 $K$ 值动态平衡语义抽象与细节保真：小 $K$ 捕捉核心实体，大 $K$ 恢复空间关系与属性绑定。

$$
\mathcal{L}_{total} = \lambda_{align}\mathcal{L}_{align} + \lambda_{txt}\mathcal{L}_{txt} + \lambda_{img}\mathcal{L}_{img}
$$

该联合损失函数同时优化对比对齐、图像到文本（I2T）自回归生成与文本到图像（T2I）流匹配生成。其中，I2T 解码器使用 $z_{img}^{:K}$ 作为软 Token 条件生成文本，T2I 解码器使用 $z_{txt}^{:K}$ 通过交叉注意力引导整流流匹配去噪 VAE 潜变量。这种双向生成目标迫使表征空间不仅具备判别性，还必须具备作为生成条件的完备性，从而实现了检索与生成的相互增强。

## 实验评估

FLAT 在 GenEval、MS-COCO 和 Flickr30K 上进行了全面评估，基线覆盖了 Chameleon、Janus、Transfusion 等主流统一模型及 MetaQuery 等专用生成模型。实验设置中，FLAT 使用 Qwen3.5-2B 作为骨干，图像解码器初始化自 SANA-1.6B，所有评估均基于单一微调检查点，通过改变前缀长度 $K$ 实现不同粒度的输出。

| 方法 | 骨干 | GenEval (T2I) | MS-COCO R@5 (I2T) | Flickr30K R@5 (I2T) |
| :--- | :--- | :--- | :--- | :--- |
| Chameleon | scratch 7B | 0.39 | - | - |
| Janus | DeepSeek 1.5B | 0.61 | - | - |
| Transfusion | scratch 7B | 0.63 | - | - |
| MetaQuery-L | Qwen2.5-VL 3B | 0.78 | - | - |
| FLAT, K=16 | Qwen3.5 2B | 0.83 | 86.82 | 98.30 |
| FLAT, K=256 | Qwen3.5 2B | 0.82 | 86.62 | 98.20 |

FLAT 在 2B 参数规模下取得了 0.83 的 GenEval 得分，超越了 3B 参数的 MetaQuery-L（0.78）和 7B 参数的 Janus-Pro-7B（0.80），表明其表征效率显著优于同等规模的统一模型。在检索任务上，FLAT 在 MS-COCO 和 Flickr30K 上的 Recall@5 分别达到 86.82 和 98.30，且在前缀长度从 1 到 256 的变化中保持几乎不变，验证了首个 Token 已包含足够的判别性语义。

消融实验揭示了损失函数组合的关键作用。移除对比损失后，GenEval 得分从 0.327 骤降至 0.297，而移除生成损失则导致 GenEval 归零，证明生成目标对表征的判别性具有正向贡献。Shapley 值分解进一步显示，对比损失与生成损失并非相互冲突，而是提供了互补信号：对比损失驱动语义对齐，生成损失驱动细节重建。然而，当 $K=1$ 时，复杂类别（如颜色绑定）的 GenEval 得分仅为 0.03，表明小前缀长度在处理组合语义时存在显著局限，需依赖 $K \ge 16$ 才能恢复至 0.67 以上。

评估边界方面，FLAT 未报告计算效率指标，且其性能高度依赖 Qwen3.5-VLM 骨干的预训练质量。代码未公开，超参数配置仅见于附录，限制了可复现性。此外，实验未涵盖高分辨率生成（如 1024x1024）场景，连续 1D 表征在长序列下的扩展性未被验证。

## 关联研究分析

从问题动机看，FLAT 与 CoCa 和 DREAM 同属“联合表征学习与生成”路线，但 FLAT 更强调表征的几何性质。CoCa 使用离散 Token 进行掩码生成，而 FLAT 采用连续 1D 序列，使得表征空间天然支持线性插值与算术运算。这一差异源于 FLAT 对“检索与生成相互增强”的假设：连续表征允许在潜空间中进行平滑过渡，从而在零样本条件下实现组合检索。相比之下，DREAM 虽也联合优化对比与生成，但其表征空间未展示类似的几何可解释性，限制了其在编辑任务中的应用潜力。

从方法设计看，FLAT 与 FlexTok 共享 1D 重采样思想，但 FLAT 引入了嵌套 Dropout 以实现变长推理。FlexTok 通过填充学习到的空嵌入来维持固定长度，而 FLAT 直接截断前缀，实验表明后者在 FLAT 的训练设置中表现更优。这一设计选择解决了固定长度序列在推理时无法动态调整语义粒度的问题，使得单一模型能够根据任务复杂度（如单物体 vs. 多物体布局）自动选择合适的前缀长度。然而，这种灵活性是否依赖于特定的 VLM 骨干，以及其在多模态（如视频）场景下的泛化能力，论文未给出明确回答。

## 总结

FLAT 旨在解决统一多模态模型中检索与生成目标相互冲突的问题，其切入点在于构建一个既支持判别性检索又支持生成性条件的连续 1D 表征空间。通过共享 VLM 编码器与嵌套 Dropout 机制，FLAT 实现了推理时的动态长度选择，在 2B 参数规模下取得了 0.83 的 GenEval 得分和 86.82 的 MS-COCO Recall@5，超越了同等规模的基线模型。然而，其性能高度依赖 Qwen3.5-VLM 骨干，且在小前缀长度下处理组合语义的能力显著下降。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
