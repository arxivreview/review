# HuggingFace最新推荐论文 ｜DiagEvo: Diagnosis-Guided Self-Evolution via Hierarchical Error Memory ｜诊断引导自进化：基于分层错误记忆的自博弈课程生成

研究机构：香港中文大学、美团

作者：Xincheng Wei、Yifan Ding、Yoshua Li 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2609.00768)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.00768)

> 自博弈（Self-Play）旨在通过挑战者生成问题、求解者解答的闭环实现模型自主进化，但缺乏外部验证时，问题生成易陷入表面复杂化导致性能平台期。现有无标签方法仅依赖难度或多样性信号，无法定位求解者具体的推理弱点；有标签方法则依赖外部文档或人工示例，违背自进化初衷。DiagEvo 从求解者失败轨迹中提取可迁移错误原因，存入分层记忆以指导下一轮问题生成，并引入双置信度过滤剔除高冲突伪标签。该方法在无外部资源条件下超越了部分依赖外部资源的基线，但其跨域泛化能力与诊断模块的计算开销边界尚存疑。

## 研究背景

自博弈训练的核心困境在于课程难度与求解者能力边界的动态匹配。当挑战者生成的问题过于简单，求解者无法获得有效学习信号；当问题过于困难，求解者响应不稳定，多数投票产生的伪标签（Pseudo-label）可靠性下降，训练反而强化错误。这一矛盾源于缺乏对“为何失败”的诊断，仅凭难度指标无法区分是计算错误、逻辑断裂还是概念缺失。

主流自博弈路线分为无标签与有标签两类。无标签方法如 R-Zero 和 Absolute Zero 利用求解者响应调整问题难度，但反馈仅反映“多难”而非“为何错”，导致问题长度随轮次增加而表面复杂化，性能在几轮后停滞。有标签方法如 R-Few 和 DARC 引入人工示例或外部文档作为锚点，虽能稳定训练，但引入了外部任务资源依赖，限制了完全自主进化的可能性。DiagEvo 的切入点在于利用自博弈过程中已产生的失败轨迹，通过对比失败与成功响应的推理差异，提取可迁移的错误原因，将其转化为课程生成信号，从而在不依赖外部资源的前提下实现定向弱点修复。

## 核心方法

### 方法参照系

DiagEvo 基于挑战者-求解者交替更新的自博弈框架，采用 GRPO（Group Relative Policy Optimization）优化。与标准流程仅使用难度或多样性信号不同，本文在挑战者更新前引入诊断模块，从求解者失败轨迹中提取错误原因，并维护一个分层记忆结构，将错误原因状态（Active/Mastered）与频率作为课程生成的核心调度依据。

### 频率驱动混合生成策略

设计动机在于解决无标签自博弈中问题生成缺乏定向性、导致性能平台期的问题。传统方法中，挑战者仅根据难度反馈调整问题，无法针对特定弱点。DiagEvo 引入频率驱动混合生成策略，平衡定向生成与自由探索。设 $F_t$ 为第 $t$ 轮活跃错误原因的总失败次数，$F_1$ 为初始参考值，归一化失败率 $z_t = F_t / F_1$。自由探索概率 $\epsilon_{t+1}$ 定义为：

$$ \epsilon_{t+1} = \frac{F_1}{F_1 + F_t/k} $$

其中 $k$ 为平衡参数。当 $z_t = k$ 时，定向生成与自由探索概率相等。该公式表明，活跃错误原因的失败频率越高，挑战者越倾向于生成针对这些弱点的问题；当错误原因被标记为 Mastered（已掌握）后，其频率重置，概率重新分配至自由探索，确保课程多样性。

### 双置信度过滤与分层记忆

设计动机在于解决伪标签噪声导致的错误强化问题。多数投票在困难问题上易产生高冲突伪标签，即前两名答案投票份额接近，训练此类数据会放大模型不确定性。DiagEvo 引入双置信度过滤，仅保留满足绝对与相对置信度约束的问题。设 $p_1(x)$ 为多数答案投票份额，$p_2(x)$ 为次多数答案份额，保留条件为：

$$ p_{low} \le p_1(x) \le p_{high}, \quad p_1(x) \ge \tau p_2(x) $$

该约束确保求解者仅在高置信度且答案明确的问题上训练，剔除高冲突样本。同时，分层记忆 $M_t = (V_t, E_t, a_t)$ 将错误原因 $e$ 分组至技能节点 $v$，每个原因维护状态 $s_t(e) \in \{Active, Mastered\}$ 与频率 $f_t(e)$。诊断模块通过对比失败响应 $r^-$ 与成功响应 $r^+$ 的最早推理差异提取错误原因 $e_{new}$，若求解者在相关问题上达到高自一致性，该原因转为 Mastered，否则保持 Active 并累积频率，形成闭环反馈。

## 实验评估

实验在 Qwen3-4B、Qwen3-8B 和 OctoThinker-8B 三个基座模型上进行，评估九个推理基准，包括 AMC、MATH-500、GSM8K 等数学基准及 MMLU-Pro、GPQA-D 等通用基准。基线覆盖无标签方法（R-Zero、Absolute Zero）和有标签方法（SPICE、R-Few、DARC），但未对比 SPACE、IRIS 等侧重散度稳定性的最新方法。

| 模型 | 方法 | 数学平均 (%) | 通用平均 (%) | 整体平均 (%) |
|---|---|---|---|---|
| Qwen3-8B-Base | R-Zero | 67.8 | 36.2 | 53.8 |
| Qwen3-8B-Base | DARC | 71.1 | 37.8 | 56.3 |
| Qwen3-8B-Base | DiagEvo (4B) | 72.3 | 38.8 | 57.4 |
| Qwen3-4B-Base | R-Zero | 60.6 | 31.9 | 47.9 |
| Qwen3-4B-Base | DARC | 66.7 | 34.1 | 52.2 |
| Qwen3-4B-Base | DiagEvo (4B) | 68.3 | 35.0 | 53.5 |

在 Qwen3-8B 上，DiagEvo 数学平均 72.3%，较 R-Zero 提升 4.5 点，较 DARC 提升 1.2 点；整体平均 57.4%，较 DARC 提升 1.1 点。在 Qwen3-4B 上，DiagEvo 整体平均 53.5%，较 DARC 提升 1.3 点。消融实验显示，冻结挑战者导致数学平均下降 3.8 点，表明定向生成与自由探索的混合策略至关重要。双置信度过滤中，移除相对置信度约束导致第 5 轮 Oracle 一致性从 75% 降至 72%，验证了剔除高冲突伪标签的有效性。诊断模块规模从 4B 增至 235B，数学平均仅提升 1.0-1.2 点，表明 4B 诊断器已足够捕捉主要错误模式，规模并非主要增益来源。

评估边界方面，论文未报告计算开销，诊断模块引入额外 LLM 调用，其成本与性能增益的权衡未量化。跨域泛化实验中，求解者仅训练数学问题，通用基准提升 5.6 点（Qwen3-8B），但提升幅度小于数学基准，暗示诊断机制主要强化数学推理能力，跨域迁移有限。代码未公开，超参数 $k$、$\tau$ 的敏感性分析缺失，可复现性受限。

## 关联研究分析

从问题动机看，DiagEvo 与 R-Zero 的核心差异在于课程信号的来源。R-Zero 依赖求解者响应的难度反馈，本质是“黑盒”调整，无法区分错误类型；DiagEvo 通过诊断模块显式提取错误原因，将课程生成从“难度匹配”升级为“弱点定向”。这一差异源于对自博弈瓶颈的不同理解：R-Zero 认为性能停滞源于难度失配，DiagEvo 认为源于缺乏针对性练习。然而，诊断模块依赖轻量级 LLM 进行语义判断，其准确性受限于诊断器能力，若诊断器无法正确识别错误原因，记忆将积累噪声，导致课程偏离。

从方法设计看，DiagEvo 与 Reflexion 共享记忆机制，但用途不同。Reflexion 存储交互摘要以指导智能体决策，记忆服务于单任务推理；DiagEvo 存储错误原因以指导挑战者生成问题，记忆服务于课程调度。这一差异源于任务结构：Reflexion 面向交互式决策，需即时反馈；DiagEvo 面向离线训练，需跨轮次优化。DiagEvo 的分层记忆结构（技能节点-错误原因）比 Reflexion 的扁平摘要更具结构化，便于追踪错误原因的掌握状态，但增加了记忆维护复杂度。

## 总结

DiagEvo 针对自博弈中缺乏定向课程信号导致性能平台期的问题，提出从失败轨迹提取错误原因并存储于分层记忆，通过频率驱动混合生成与双置信度过滤实现无外部资源的定向进化。在 Qwen3-8B 上，数学平均 72.3%，较 R-Zero 提升 4.5 点，整体平均 57.4%，较 DARC 提升 1.1 点，验证了诊断引导的有效性。其边界在于诊断模块依赖外部 LLM，计算开销未量化，且跨域泛化提升有限，主要强化数学推理能力。当诊断器规模从 4B 增至 235B 时，性能增益仅 1.0 点，这是否意味着错误原因提取存在语义瓶颈，还是诊断器能力已饱和，论文未给出回答。
