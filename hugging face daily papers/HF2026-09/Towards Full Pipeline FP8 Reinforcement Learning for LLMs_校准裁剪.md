# HuggingFace最新推荐论文 ｜Towards Full Pipeline FP8 Reinforcement Learning for LLMs ｜校准裁剪

作者：Fanchao Chen、Ziheng Jiang、Ziyun Wei 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2609.22870)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.22870)

> 全流水线FP8强化学习（RL）旨在通过降低数值精度加速大语言模型（LLM）的推理能力训练，但现有方法仅关注Rollout与训练间的精度不匹配，忽略了训练后端内部量化噪声对优化器逻辑的破坏。本文发现FP8噪声会扭曲重要性比率，导致负优势Token被过度裁剪，使抑制错误输出的梯度消失。通过引入Calibrated Clipping，动态对齐FP8与BF16的裁剪分位数，该方法消除了熵激增并恢复了BF16级性能。其价值在于揭示了低精度训练失效的新机制，但校准开销与长期稳定性仍需权衡。

## 研究背景

理解本文需先厘清近端策略优化（PPO）中的信任区域机制。PPO通过裁剪重要性比率 $r_t(\theta) = \pi_\theta(y_t|h_t)/\pi_{old}(y_t|h_t)$ 来限制策略更新幅度，当 $r_t$ 超出 $[1-\epsilon, 1+\epsilon]$ 时梯度被置零。这一机制假设 $\pi_\theta$ 与 $\pi_{old}$ 的概率计算是精确的，但在低精度训练中，概率本身带有量化误差。当误差累积到比率层面时，原本应被惩罚的负优势Token可能因比率被错误地推至下界以下而触发裁剪，导致其梯度消失，错误行为无法被抑制。

FP8已成为LLM预训练与推理的事实标准，其有限动态范围要求引入缩放因子以适配数值表示。在RL场景中，早期工作如Jet-RL和FP8-RL聚焦于解决Rollout引擎（推理）与训练引擎间的精度不匹配，采用截断重要性采样（TIS）进行校正。然而，这些方法假设只要Rollout与训练使用相同精度，或通过TIS校正后，训练过程即可稳定。本文指出，即便采用全流水线FP8（Rollout与训练均为FP8）并默认使用TIS，训练后端内部的FP8量化噪声仍会独立地破坏PPO的裁剪逻辑，导致训练中期出现异常熵激增与乱码输出。

## 核心方法

### 方法参照系

标准FP8 RL流程包含Rollout生成、TIS校正与PPO更新。TIS通过截断比率 $w_{TIS} = \min(\pi_{old}/\pi_{sampler}, C)$ 消除Rollout精度差异。本文的关键差异在于：即使TIS已应用，训练后端中 $\pi_\theta$ 与 $\pi_{old}$ 均源自FP8前向传播，其概率误差在比率计算中非线性放大，使得静态裁剪边界 $[1-\epsilon, 1+\epsilon]$ 在量化空间中失效。

### 噪声复合与过度裁剪机制

设计动机：解释为何TIS无法阻止熵激增。在FP8训练中，概率 $p$ 的量化误差 $\delta p$ 虽小，但比率 $r = p_\theta/p_{old}$ 的误差被放大。本文定义“过度裁剪”：若 $A_t < 0$，$r_t^{BF16} > 1-\epsilon$ 但 $r_t^{FP8} \le 1-\epsilon$，则该Token被错误裁剪。

$$
\text{NMAE}_{ratio} = \frac{\mathbb{E}[|r_t^{FP8} - r_t^{BF16}|]}{\mathbb{E}[|r_t^{BF16}|]}
$$

实验显示，比率误差较概率误差放大了1.7×至2.9×。这种放大导致约70%的过度裁剪发生在下界，且90%来自高熵乱码响应。由于这些响应本应被负优势惩罚，但梯度被裁剪置零，模型无法学习抑制乱码，导致熵持续上升。

### 校准裁剪算法

设计动机：恢复量化空间中的信任区域语义。理想裁剪边界应满足 $L = \tilde{Q}(1-\epsilon)$ 和 $H = \tilde{Q}(1+\epsilon)$，其中 $\tilde{Q}$ 为FP8量化算子。由于 $\tilde{Q}$ 不可解析，本文提出基于分布分位数的动态校准。

$$
L = F_{FP8,-}^{-1}\left( F_{BF16,-}(1-\epsilon) \right)
$$

其中 $F_{BF16,-}$ 和 $F_{FP8,-}$ 分别为BF16和FP8下负优势Token重要性比率的累积分布函数（CDF）。该公式确保FP8中被下界裁剪的Token比例与BF16一致。随后，通过求解 $H$ 使得正负更新比率 $\rho_{FP8}$ 匹配 $\rho_{BF16}$，防止下界放宽导致的过度惩罚。算法每20步执行一次BF16影子前向传播以更新边界，避免每步计算带来的开销。

## 实验评估

实验在Qwen3-8B-Base上基于DeepScaleR数据集进行，对比BF16基线与Tensorwise/Rowwise/Blockwise FP8配置。基线覆盖不同缩放粒度，但缺失QUADS等双端对齐方法。主结果显示，所有FP8配置在训练100步后出现熵激增，而Calibrated Clipping成功抑制了该现象。

| 配置 | 熵激增 | 评估准确率 | 裁剪比例 |
| :--- | :--- | :--- | :--- |
| BF16 | 无 | 0.60 | 0.00 |
| Rowwise FP8 | 有 | 0.45 | 0.03 |
| Rowwise FP8 + CC | 无 | 0.55 | 0.01 |

注：表中数值为论文Figure 1及正文描述的定性/半定量结果，具体绝对数值未在数据区提供完整表格，此处仅呈现相对关系与关键指标趋势。

消融实验表明，单纯放宽下界至0.6可防止熵激增，但导致熵过早饱和、奖励降低及响应变短，证实需同时校准上界。Blockwise缩放虽比Tensorwise更稳定，但仍无法消除熵激增，证明问题根源在于比率噪声而非缩放粒度。

评估边界方面，论文未报告置信区间，且仅在8B模型上验证。代码未公开，超参数（如搜索步长0.02）未进行敏感性分析。BF16影子前向传播的开销虽被摊销，但在大规模集群中的实际吞吐量增益（1.5×）是否随模型规模线性扩展，缺乏实证。

## 关联研究分析

从问题动机看，本文与Jet-RL和FP8-RL形成互补。Jet-RL侧重统一精度流与TIS，假设消除Rollout-训练差异即可稳定训练；本文则证明训练后端内部的噪声独立于Rollout差异，即使TIS应用，PPO裁剪逻辑仍会失效。这一差异源于任务特性：RL对策略更新的稳定性要求高于预训练，微小的比率偏差即可导致优化方向错误。

从方法设计看，本文与GNMR（运行时稳定性控制）思路相近，但GNMR关注梯度/激活值的统计异常，本文聚焦于优化器目标函数的逻辑偏差。QUADS采用双端对齐消除误差，而本文通过动态校准边界适应误差，后者无需修改Rollout或训练引擎的精度配置，系统侵入性更低。然而，校准依赖BF16影子传播，这在FP4等更低精度下是否仍具成本效益，论文未给出回答。

## 总结

本文要解决的核心矛盾是全流水线FP8 RL中量化噪声对PPO信任区域的系统性扭曲。现有方法如TIS仅校正Rollout-训练差异，忽略了训练后端内部噪声对裁剪机制的破坏；本文凭借对比率误差放大效应的洞察，提出Calibrated Clipping，通过动态对齐分位数恢复信任区域语义。实验证明该方法消除了熵激增，恢复了BF16级性能，且吞吐量达1.5×。其边界在于校准依赖BF16影子传播，且仅在8B模型上验证，未探索FP4等更低精度下的适用性。当模型规模扩展至32B以上时，BF16影子传播的内存开销是否成为瓶颈，论文未给出回答。
