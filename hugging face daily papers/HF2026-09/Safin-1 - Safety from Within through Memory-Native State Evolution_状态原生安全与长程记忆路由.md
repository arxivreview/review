# HuggingFace最新推荐论文 ｜Safin-1: Safety from Within through Memory-Native State Evolution ｜状态原生安全与长程记忆路由

研究机构：Hugging Face

论文原文见 [arXiv](https://arxiv.org/abs/2609.00092)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.00092)

> 长时程智能体需同时维持上下文连贯性与行为一致性，但传统递归模型仅暴露最新状态，导致早期信息被覆盖且安全约束依赖外部微调。Safin-1 切入点在于将递归状态轨迹转化为可寻址的内部记忆库，并通过内容路由实现历史状态的选择性恢复与持久能力的解耦挂载。其核心机制是 MARCH 架构，通过周期性检查点化状态并引入基于内容的路由键，使模型能在不修改骨干参数的前提下，动态检索历史状态或激活特定的安全状态。该工作验证了状态原生安全在降低过拒率上的优势，但其对复杂多跳推理的替代外部记忆系统的能力尚未在对话基准上得到直接证实。

## 研究背景

递归状态空间模型（RNN/SSM）通过固定大小的状态矩阵压缩因果前缀，实现了常数内存解码，但传统设计仅允许读取最新状态。一旦早期关联被衰减或覆盖，其表示便不可恢复，这构成了长程依赖中的“单状态瓶颈”。为缓解此问题，近期研究尝试扩大记忆容量或保留时序状态集合，但引入了新挑战：如何在紧凑表示中高效检索与当前上下文相关的历史状态。

现有 LLM 智能体记忆架构多依赖外部存储（如向量库、知识图谱），通过检索增强生成（RAG）补充静态知识，但缺乏对动态状态演化的内生感知。主流路线在信息保真度与计算效率间存在权衡：结构化图谱支持多跳推理但开销大，扁平向量检索高效但难以处理时序逻辑。Safin-1 的切入点在于将记忆从“外部检索”转向“内部状态路由”，利用递归模型自身的状态轨迹作为可寻址记忆，并通过内容条件路由解决历史状态的检索问题，同时探索将安全等持久能力作为状态的一部分进行解耦适配。

## 核心方法

### 递归状态路由参照系

本文问题属于递归模型长程记忆增强范畴，与外部 RAG 的关键差异在于记忆载体是模型内部的递归状态而非外部文档。标准递归模型（如 Gated DeltaNet）仅维护单一累积状态 $S_t$，无法回溯早期状态。MARCH 在此基础上引入状态锚点机制，将状态轨迹离散化为可寻址单元，并建立内容路由接口，使记忆检索成为递归计算的内生部分。

### 上下文衍生状态锚点与内容路由

传统递归更新中，状态 $S_t$ 随时间连续演化，早期信息逐渐被覆盖。MARCH 在每 $C$ 个 token 处插入共享锚点嵌入 $\xi$，并在该位置快照当前累积状态 $A^{(m,\ell)} = S^{(\ell)}_{b_m}$，形成状态锚点。每个锚点通过其对齐的状态检查点生成紧凑的路由键 $\kappa^{(\ell)}_m = W^{(\ell)}_k u^{(\ell)}_m$，其中 $u^{(\ell)}_m$ 是锚点位置的归一化输入表示。对于文本 token $t$，路由模块计算查询 $\rho_t = W_R x_t$ 与所有因果可见锚点键及一个学习得到的空选项 $\emptyset$ 的相似度，通过 softmax 归一化得到路由概率 $\pi_{t,j}$。检索到的状态读出 $o_{t,j} = A^{(j)} q_t$ 加权后与当前状态读出相加：

$$
o_t = S_t q_t + \sum_{j \in \tilde{C}_t} \pi_{t,j} A^{(j)} q_t
$$

该设计允许模型根据当前上下文选择性地恢复早期状态，空选项的存在使模型能忽略无关历史，避免了强制检索带来的噪声干扰。

### 持久能力状态与解耦适配

MARCH 的状态库不仅包含上下文衍生的动态锚点，还可容纳学习得到的持久能力状态 $\{P_j\}$。这些状态作为参数直接插入状态库，其路由键通过相同的状态感知元数据路径生成。与动态锚点不同，持久状态从第一个 token 起即可用，不消耗输入序列位置。Safin-1 实例化了一个可拆卸的“安全状态”（Safety State），在冻结语言模型骨干的情况下，仅优化该状态集合。路由机制为每个 token 分配安全状态的贡献，实现了安全能力的选择性激活。这种解耦设计允许在不重写共享骨干的前提下挂载或移除特定能力，解决了传统微调中安全约束与通用能力耦合导致的过拒问题。

## 实验评估

实验在 0.8B 规模下验证 MARCH 架构，基线包括 Gated DeltaNet (GDN)、Kimi Delta Attention (KDA)、GDN2 及 Transformer。在 LongBench 12 项任务上，MARCH 平均得分 14.9，显著优于 GDN 的 11.9 和 Log-Linear Attention 的 12.5，尤其在多文档问答和摘要任务上提升明显。在 RULER NIAH 任务中，MARCH 在 19/24 个设置中超越最强递归基线，且在 32K 长度（超出 16K 训练长度）上表现稳健，表明路由机制具备长度外推能力。

| 模型 | LongBench Avg. | NIAH 4K | NIAH 32K | SQuAD | SWDE |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Gated DeltaNet | 11.9 | 53.80 | 15.13 | 34.8 | 45.0 |
| w/ MARCH | 14.9 | 59.58 | 31.71 | 37.7 | 51.9 |
| Transformer | 13.8 | 78.04 | 0.00 | 41.3 | 59.3 |

消融实验显示，路由维度 $d_r=64$ 是最佳权衡，增大至 192 虽提升检索但降低其他指标。Top-4 稀疏路由在 128K 长度下使吞吐量翻倍，核心运行时减少约一个数量级，验证了高效 Producer-Reader 实现的有效性。移除空选项导致所有聚合指标下降，证实了显式忽略无关历史状态的重要性。

在 4B 和 35B-A3B 规模下，Safin-1 在 AIME 2025 上分别达到 63.59 和 80.10，显著高于 Qwen3.5 基线。安全评估中，Safety State 使平均越狱攻击成功率（ASR）在 4B 上降低 42.3%，在 35B-A3B 上降低 52.3%，且过拒率（ORR）变化小于训练匹配的 LoRA 对照组，表明状态原生安全在保持有用性的同时提升了鲁棒性。

评估边界方面，论文未测试 LoCoMo 或 LongMemEval 等对话记忆基准，无法直接对比外部记忆系统在长程对话一致性上的表现。代码与超参数已公开，但 0.8B 实验基于 50B token 预训练，大规模复现成本高。

## 关联研究分析

从问题动机看，Safin-1 与 MemGPT 等操作系统类比架构均旨在解决固定上下文窗口的状态丢失问题，但 MemGPT 依赖外部存储与分页机制，而 Safin-1 将记忆内化为递归状态轨迹。这种差异源于任务特性：MemGPT 针对长对话中的显式记忆管理，而 Safin-1 针对递归模型固有的状态覆盖问题。Safin-1 未探索外部存储与内部状态路由的混合架构，其在需要大规模静态知识检索的场景中是否优于 RAG 基线，论文未给出回答。

从方法设计看，Safin-1 的持久能力状态与 LoRA 等参数高效微调方法形成对比。LoRA 通过低秩矩阵修改骨干权重，而 Safety State 通过路由机制选择性激活独立状态。实验表明 Safety State 在安全任务上具有更低的过拒率，这可能源于路由机制允许模型在特定 token 上抑制安全状态的影响，而 LoRA 的权重修改是全局性的。这种解耦设计是否适用于其他持久能力（如代码执行、数学推理），以及其在多智能体共享记忆场景中的泛化性，是后续研究的关键方向。

## 总结

Safin-1 旨在解决递归模型长程状态丢失与安全约束外部依赖的矛盾，通过 MARCH 架构将状态轨迹转化为可寻址记忆库，并利用内容路由实现历史状态恢复与持久能力解耦。实验证明其在长上下文检索上优于纯递归基线，且在安全任务上实现了比 LoRA 更优的效用-安全权衡。然而，其边界在于未验证在复杂对话记忆一致性任务上对外部记忆系统的替代能力，且持久状态机制的泛化性局限于安全领域。当支持集增大或任务复杂度提升时，内部状态路由与外部检索增强生成的协同机制如何设计，论文未给出回答。
