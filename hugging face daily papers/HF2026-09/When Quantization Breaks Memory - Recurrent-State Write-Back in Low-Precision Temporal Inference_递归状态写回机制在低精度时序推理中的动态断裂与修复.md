> 递归网络在低精度部署时，量化后的内部状态被反复读回并参与后续计算，导致存储规则本身成为时序计算的一部分。现有量化感知训练（QAT）假设固定比特宽度即可消除精度损失，但忽略了训练时接口与部署时接口不兼容导致的动态轨迹断裂。本文通过固定已训练模型权重，仅替换递归状态写回规则，揭示了“写回死区”对状态更新的持续抑制机制，并引入方向记忆算子在不重训练条件下恢复精度。该研究将状态存储从被动编码提升为独立设计变量，但其结论局限于GRU/LSTM架构，对Transformer等无显式递归状态结构的模型是否适用尚存疑问。

## 研究背景

当递归神经网络（RNN）在低比特精度下运行时，其内部状态在每一步计算后被存储并在下一步作为输入返回。这一过程使得状态存储操作不再是简单的数值近似，而是直接参与了时序动态的生成。若存储规则将微小的状态更新舍入为零，网络虽在计算层持续提出变化，但存储轨迹却保持静止，导致时序信息的累积中断。这种“计算-存储”解耦现象在量化感知训练（QAT）中未被充分建模，因为QAT通常在训练阶段固定数值表示，假设网络能自适应低比特噪声，却未考虑部署时可能出现的接口变更或精度不匹配。

低精度RNN推理的核心矛盾在于比特宽度与动态保真度的非线性关系。主流QAT方法通过逐步引入量化约束，使网络在低比特网格上学习动态，但实验表明，即使训练时已包含4-bit状态量化，部署时若改变写回规则或增加状态精度，固定模型的精度反而可能下降。这揭示了“数值保真度”（单个状态值的表示精度）与“动态保真度”（存储-读取循环产生的轨迹与学习解的兼容性）之间的脱节。现有研究多聚焦于权重或激活值的量化误差补偿，如GPTQ利用Hessian信息补偿权重舍入误差，但忽略了递归状态在时间维度上的累积效应。本文切入点在于将状态写回规则视为独立于比特宽度的设计变量，通过干预已训练模型的状态存储接口，分离出存储操作对时序动态的因果影响。

## 核心方法

### 方法参照系

本文问题置于低精度递归推理的量化感知训练框架下，但关键差异在于：传统QAT将量化视为训练时的固定约束，而本文将状态写回规则视为部署时可变的接口变量。标准流程中，QAT通过直通估计器（STE）在训练中模拟量化，但本文指出，即使训练时包含量化，部署时的写回规则变更仍可导致动态断裂，因为网络未学习对“亚阈值更新被抑制”这一特定失效模式的鲁棒性。

### 递归写回裕度与死区定义

设计动机在于量化传统“比特宽度决定精度”的范式无法解释为何固定模型在改变存储规则后精度崩塌。本文引入递归写回裕度（Recurrent Write Margin, $M_{t,j}$）来量化状态更新与量化器写回边界的相对位置。对于隐藏单元 $j$ 在时间步 $t$，设原始状态为 $h_{t,j}$，前一存储状态为 $q_{t-1,j}$，更新门为 $z_{t,j}$，候选状态为 $\tilde{h}_{t,j}$，则写回裕度定义为：

$$ M_{t,j} = \frac{2|\delta_{t,j}|}{\Delta_B = 2(1 - z_{t,j})|\tilde{h}_{t,j} - q_{t-1,j}|} $$

其中 $\delta_{t,j} = h_{t,j} - q_{t-1,j}$ 为提议的状态变化。当 $M_{t,j} < 1$ 时，提议变化位于半步写回边界内，确定性最近级写回将保留原存储值，形成“写回死区”。该指标直接揭示了哪些状态更新被存储规则屏蔽，从而无法进入后续递归计算。

### 方向记忆与残差补偿算子

设计动机在于死区内的亚阈值更新虽被屏蔽，但其方向信息对后续动态至关重要，传统误差反馈仅保留幅值，无法处理持续同向的小更新。本文引入方向记忆（Direction Memory），利用 $k$-bit辅助计数器累积连续同向亚阈值更新的符号，当累积证据达到阈值时，强制存储状态跨越一个量化级。同时，残差记忆（Residual Memory）存储被丢弃的量化误差幅值，在下一写回机会时补偿。这两种算子共同作用，在不改变主状态比特宽度（保持4-bit）的前提下，将死区内被抑制的信息传递至后续时间步。方向记忆的核心逻辑是：若网络在连续 $N$ 步中均提议同向微小变化，则累积效应足以触发一次有效状态转移，从而恢复时序动态的连续性。

## 实验评估

| 条件 | 序列MAE | τ1 RMSE (ns) | τ2 RMSE (ns) |
| :--- | :--- | :--- | :--- |
| P2E原生（连续状态） | 0.139248 | 1.3975 | 3.0309 |
| P2F确定性4-bit写回 | 0.09 | 25.37 | 106.59 |
| P2F误差反馈 | 0.34 | 0.34 | 0.46 |
| P2F方向记忆 | 0.49 | 0.49 | 0.58 |

实验基于Seq2SeqLite模型（32单元GRU，6,627参数）在荧光寿命成像（FLI）数据集上进行，该数据集包含160万高噪声时序信号。基线覆盖连续传播、随机舍入、误差反馈及本文提出的方向记忆，但未对比GPTQ等权重量化方法，因任务焦点在于状态接口而非权重压缩。主结果显示，仅将P2F检查点的状态存储从连续传播改为确定性4-bit写回，τ1和τ2的RMSE分别从0.36/0.35 ns激增至25.37/106.59 ns，增幅达70倍和300倍。这一极端退化证实了写回规则对动态的因果影响。方向记忆将误差恢复至0.49/0.58 ns，接近原生精度，证明被抑制的方向信息可被有效补偿。

消融实验揭示了比特宽度与接口兼容性的解耦。独立训练的8-bit状态参考模型，在强制4-bit写回时，解码器死区比例升至99.40%，状态变化比例降至0.60%，但引入方向记忆后，中位同向运行长度从132步缩短至6步，状态变化比例恢复至4.76%。反直觉发现是，增加状态精度（4-bit至8-bit）在固定模型下反而降低精度，因为更细的网格可能使网络更频繁地陷入死区，除非训练时已适配该接口。匹配训练实验表明，方向记忆在τ1上优于6-bit状态和残差记忆，但在τ2上略弱，说明不同时间尺度参数对存储接口的敏感度存在差异。

评估边界受限于单一架构（GRU/LSTM）和特定任务（FLI）。指标仅使用RMSE和MAE，未涉及下游任务准确率或硬件延迟。代码未公开，QMem训练细节仅部分披露，可复现性依赖补充材料。FLI任务的高噪声特性可能放大写回死区效应，其在低噪声或长序列任务中的普适性未验证。

## 关联研究分析

从问题动机看，本文与SDQ-LLM等噪声整形方法同属误差补偿路线，但SDQ-LLM针对权重分布的高频误差转移，而本文针对状态更新的时序累积抑制。SDQ-LLM假设权重在Hadamard变换后近似高斯，通过积分器平滑误差；本文则发现状态更新具有强方向性，需专门的方向累积机制。这一差异源于权重是静态参数，而状态是动态变量，其误差在时间维度上具有记忆性。SDQ-LLM的通用性建立在权重分布假设上，而本文的机制依赖于递归结构的时序特性，二者不可直接迁移。

从方法设计看，本文与BitNet b1.58等原生低比特训练方法形成对比。BitNet通过QAT从头训练三值权重，假设网络能自适应极低比特噪声；本文则证明，即使QAT训练，若部署时接口变更，动态仍会断裂。BitNet的成功依赖于训练与部署接口的一致性，而本文揭示了接口不兼容的独立风险。这一冲突暗示，QAT的“鲁棒性”是相对于特定接口而言的，而非对比特宽度本身的鲁棒性。方向记忆算子是否可推广至Transformer的KV Cache量化，论文未给出回答，但KV Cache的静态存储特性与递归状态的动态更新存在本质差异，迁移性存疑。

## 总结

本文核心矛盾在于低精度递归推理中比特宽度与动态保真度的非线性关系。现有QAT方法假设固定比特即可消除精度损失，但忽略了状态存储接口对时序动态的独立影响。本文通过固定权重仅改变写回规则，揭示了“写回死区”导致的状态更新抑制机制，并引入方向记忆算子在不重训练条件下恢复精度。实验证明，仅改变存储规则可使RMSE激增70-300倍，而方向记忆可将其恢复至接近原生水平。本文边界在于结论局限于GRU/LSTM架构和FLI任务，未验证其在Transformer等无显式递归状态模型中的适用性。当递归状态被替换为注意力机制中的KV Cache时，方向记忆算子是否仍能捕捉时序动态的断裂，论文未给出回答。
