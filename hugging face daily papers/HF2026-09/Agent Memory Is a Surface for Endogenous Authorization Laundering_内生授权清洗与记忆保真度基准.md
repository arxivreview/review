# HuggingFace最新推荐论文 ｜Agent Memory Is a Surface for Endogenous Authorization Laundering ｜内生授权清洗与记忆保真度基准

研究机构：瑞士苏黎世联邦理工学院、美国佐治亚理工学院

作者：Tommaso Cerruti、Mika Okamoto、Ansel Kaplan Erol

论文原文见 [arXiv](https://arxiv.org/abs/2609.01836)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.01836)

> 长期运行的LLM智能体依赖持久化记忆维持跨会话状态，当记忆压缩或更新导致权限、限制及撤销等授权状态失真时，智能体可能基于错误的内部记录执行未授权操作，这一现象被定义为内生授权清洗。现有记忆评估多聚焦于事实召回或对抗攻击防御，忽视了无外部攻击下记忆自身演化导致的授权状态漂移，且缺乏区分“记忆形成错误”与“执行器传播错误”的量化手段。本文提出EAL-BENCH基准，通过确定性账本与精确状态修复干预，分离记忆写入阶段的虚假权限形成与执行阶段的未授权行动传播。该工作揭示了记忆作为授权策略组件的关键性，但其缓解策略暴露出显著的安全-效用权衡，且依赖确定性账本限制了在开放域非结构化场景中的泛化能力。

## 研究背景

当智能体在长时程交互中维护用户偏好与任务状态时，固定上下文窗口迫使系统引入外部持久化记忆。然而，记忆并非静态存储，而是通过压缩、更新与检索动态演化的认知组件。若记忆更新过程未能准确反映历史交互中的权限变更（如授权、限制、撤销），智能体将基于失真的授权状态执行操作，导致“遗忘撤销”或“误留权限”等内生错误。这种错误不同于外部攻击导致的记忆投毒，而是系统自身记忆机制在普通更新中产生的状态保真度失效。

长期记忆架构研究已从静态检索增强生成（RAG）演进至动态认知治理，主流路线包括结构化图谱组织（如MAGMA、HiMem）与强化学习驱动的自适应策略（如Mem-T、AgeMem）。这些方法在提升多跳推理与任务效用方面取得进展，但普遍将记忆视为信息存储容器，而非授权策略的执行载体。现有安全治理框架（如SSGM、GATEMEM）主要关注外部攻击防御或检索时访问边界控制，缺乏对记忆写入阶段授权状态保真度的系统性评估。当记忆压缩将非权威来源的权限信息吸收进存储记录时，执行器无法区分真实授权与虚假权限，导致未授权行动在看似合规的内部逻辑下发生。

本文切入点在于将记忆保真度问题具体化为授权状态的生命周期管理。不同于关注事实准确性或对抗鲁棒性的现有基准，EAL-BENCH聚焦于无攻击者场景下，记忆更新如何扭曲授权状态，并量化这种扭曲从记忆形成到行动传播的因果链条。通过引入确定性账本与精确状态修复干预，该基准能够隔离记忆写入错误与执行器行为错误的责任归属，为记忆安全治理提供新的评估维度。

## 核心方法

### 授权状态保真度形式化

本文解决的问题可置于记忆安全治理的通用框架下，但关键差异在于评估对象从“记忆内容正确性”转向“授权状态保真度”。传统记忆评估假设执行器接收的记忆是可靠的，仅测试检索或推理能力；本文则假设记忆本身可能包含虚假权限，需验证其是否忠实反映历史交互建立的授权状态。

### 虚假权限形成与传播分解

设计动机：现有方法将记忆错误与执行错误混同，无法定位失败根源。本文通过确定性谓词分解，将内生授权清洗分解为形成（Formation）与传播（Propagation）两个独立阶段。

对于有序组织历史 $H = (B_1, \dots, B_T)$，确定性重放函数 $R$ 映射至规范授权状态 $S_t = R(B_1, \dots, B_t)$，领域特定谓词 $A(S_t, x) \in \{0, 1\}$ 判定动作 $x$ 是否授权。记忆写入器 $W$ 生成持久化记忆 $M_T$，执行器 $E$ 基于 $M_T$ 与请求 $q$ 决策。虚假权限形成定义为：

$$
F(M_T, a_q) = \mathbb{1}\{A(S_T, a_q) = 0 \land A_M(M_T, a_q) = 1\}
$$

其中 $A_M$ 为基于存储记忆的确定性授权判定。传播定义为执行器在虚假权限存在时执行该动作：

$$
G(E, M_T, q) = \mathbb{1}\{E(M_T, q) = a_q\}
$$

端到端清洗事件为 $F \land G$，其发生率分解为 $P(F=1) \cdot P(G=1 | F=1)$。该分解允许在授予执行器工具权限前，通过审计记忆本身估计违规率，将安全监控前移至写入阶段。

### 精确状态修复与因果验证

设计动机：仅观察行为无法区分“记忆错误导致执行错误”与“执行器固有缺陷”。本文通过记忆唯一变量干预，建立因果链。

对于自然生成的类型化记忆中 $F=1$ 的实例，在观察到任何执行器行为前，重放相同请求于两种条件下：原始错误记忆与精确状态修复（Oracle-exact replacement）。精确状态修复将记忆替换为规范授权状态 $S_T$，保持请求、执行器、工具及规范状态不变。若未授权行动在修复后消失，则证明记忆形成是瓶颈。该干预不引入LLM评判器，仅依赖确定性工具调用匹配，确保因果推断的严谨性。

## 实验评估

实验在采购、网络安全、金融三个领域进行，每个领域包含8-16个案例，历史跨度5-18个会话块。评估5种写入器（Nemotron 3 Ultra, Kimi K2.6, GLM 5.2, Grok 4.3, Qwen-Plus）与2种执行器（GPT-OSS-120B, DeepSeek V4 Pro），采用自由文本与类型化记忆、一次性与增量更新四种组合。基线覆盖主流LLM写入器，但缺乏经典RAG或Mem0等生产级记忆架构的直接对比，限制了与工业部署系统的横向比较。

| 领域 | 虚假权限形成率 P(F) | 未授权提交率 |
|---|---|---|
| 采购 | 28.3% | 28.9% |
| 网络安全 | 10.4% | 10.4% |
| 金融 | 50.2% | 51.0% |

类型化增量记忆下，虚假权限形成率与未授权提交率高度一致，差异不超过0.8个百分点，表明行为失败主要源于存储状态而非执行器偏差。精确状态修复干预显示，错误记忆下未授权行动发生率为98.6%，修复后降至0.0%，证实记忆形成是内生授权清洗的因果瓶颈。

| 缓解策略 | 未授权提交率 | 授权使用率 |
|---|---|---|
| 基线（类型化增量） | 25.3% | 93.3% |
| 源权威门控 | 7.3% | 53.8% |
| 有界事件溯源 | 9.0% | 64.7% |

源权威门控将未授权提交率降低18.0个百分点，但授权使用率骤降39.5个百分点；有界事件溯源降低16.3个百分点，授权使用率下降28.6个百分点。两种策略形成离散帕累托前沿，无单一配置在安全与效用上占优。金融领域受影响最大，Qwen-Plus在压力干预下授权使用率从93.0%降至54.7%，表明紧急性提示可放大记忆错误的影响。

评估协议依赖确定性账本，要求授权事件可形式化重放，这限制了在非结构化、模糊授权场景中的适用性。三个种子支持描述性复制而非精确分布估计，未报告置信区间。代码与基准已开源，但模型版本与提供商路由固定，跨平台泛化性未验证。

## 关联研究分析

从问题动机看，EAL-BENCH与GATEMEM均关注记忆中的授权状态，但GATEMEM聚焦检索时的生命周期感知访问边界控制，假设记忆状态本身正确；EAL-BENCH则质疑记忆状态的正确性，测量写入阶段是否引入虚假权限。这一差异源于任务特性：GATEMEM适用于多主体共享记忆场景，需防止越权检索；EAL-BENCH适用于单智能体长时程交互，需防止记忆演化导致的权限漂移。PPMF处理外部来源不可信问题，通过平台维护的溯源防止权限放大；EAL-BENCH处理内部历史失真，即使来源权威，记忆更新仍可能扭曲范围、有效性或生命周期状态。

从方法设计看，EAL-BENCH采用确定性账本与精确状态修复，挑战了“LLM-as-Judge”的评估惯例。领域共识认为结构化记忆优于纯文本，本文验证了类型化记忆在授权保真度上的优势，但指出结构化本身不保证保真，需配合源权威验证。与SSGM等通用安全治理框架相比，EAL-BENCH的缓解策略（源权威门控、有界事件溯源）针对形成阶段而非检索阶段，将安全监控前移。然而，确定性账本的可扩展性存疑：在开放域非结构化授权场景中，如何定义“规范授权状态”与“确定性重放函数”，论文未给出回答。

## 总结

本文要解决的核心矛盾是持久化记忆在长时程交互中授权状态保真度失效导致的内生授权清洗。现有方法将记忆视为信息容器，忽视其作为授权策略组件的角色，且缺乏区分记忆形成错误与执行传播错误的评估手段。本文通过EAL-BENCH基准，引入确定性账本与精确状态修复干预，将清洗事件分解为形成与传播两阶段，证明记忆写入是虚假权限的因果瓶颈。实验显示，类型化增量记忆下虚假权限形成率高达50.2%，精确修复可消除98.6%的未授权行动，但缓解策略暴露出显著的安全-效用权衡，授权使用率下降近40个百分点。本文的边界在于依赖确定性账本，限制了在模糊、非结构化授权场景中的适用性，且缓解策略的帕累托前沿表明，当前方法无法同时实现高安全与高效用。当授权状态无法形式化为确定性事件时，如何在不牺牲效用的前提下验证记忆保真度，论文未给出回答。
