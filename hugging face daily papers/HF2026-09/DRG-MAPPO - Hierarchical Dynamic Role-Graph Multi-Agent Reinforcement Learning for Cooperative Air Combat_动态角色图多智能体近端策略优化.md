> 多无人机协同空战面临高维状态空间下的实时协同难题，传统扁平架构难以捕捉战场实体的动态拓扑关系与战术角色分配。现有方法要么缺乏结构化关系建模导致态势感知模糊，要么依赖静态任务划分无法适应动态对抗。本文通过图注意力机制构建实体关系表征，并引入分层策略解耦高层战术角色分配与底层机动控制，辅以目标优先级辅助任务引导协同行为。该框架在2v2超视距空战中取得87%胜率，但其可扩展性至更大规模集群及复杂动态环境下的泛化能力尚存疑。

## 研究背景

多无人机协同空战的核心挑战在于如何在部分可观测且非平稳的环境中实现高效协同。去中心化部分可观测马尔可夫决策过程（Dec-POMDP）是处理此类问题的标准框架，其中智能体仅基于局部观测 $o_i^t$ 决策，目标是最大化团队累积奖励。然而，随着智能体数量增加，联合动作空间呈指数级增长，且其他智能体策略更新导致环境动态变化，使得独立学习难以收敛。集中训练去中心化执行（CTDE）范式通过训练时访问全局信息缓解非平稳性，但传统扁平架构将战略意图与底层机动执行混同，缺乏对实体间动态拓扑关系的显式建模，导致在快速变化的战场中难以捕捉最优战术窗口。

现有主流路线在关系建模与角色分配上存在显著瓶颈。基于图神经网络（GNN）的方法虽能提取关系特征，但多局限于友方通信拓扑或静态图结构，难以应对敌我混杂场景下的动态拓扑变化。分层强化学习（HRL）通过解耦决策层级缓解长时程信用分配问题，但现有工作多依赖启发式状态划分或静态任务分配，缺乏动态角色适应能力。DRG-MAPPO的切入点在于，将图注意力机制用于构建包含自、友、敌、导弹四类实体的动态关系表征，并在此基础上引入动态角色分配机制，通过时间承诺机制稳定高层策略，从而在保持CTDE优势的同时，实现战术意图与底层执行的解耦。

## 核心方法

### 方法参照系

DRG-MAPPO基于MAPPO算法框架，遵循CTDE范式，即集中式评论家使用全局状态 $s$ 评估价值，去中心化执行器仅依赖局部观测 $o_i$ 生成动作。与标准MAPPO的关键差异在于，本文未将原始观测视为单体特征向量，而是将其分解为局部实体图 $G_i = (V_i, E_i)$，并通过图注意力机制提取关系特征，进而引入分层策略结构，将决策过程解耦为高层角色分配与底层角色条件机动控制。

### 图注意力关系建模

标准GNN在动态战场中常因静态图结构或单一实体类型限制而失效，无法捕捉敌我交互的复杂拓扑。DRG-MAPPO构建全连接实体图，节点特征经零填充与类型嵌入后投影至共享隐空间。图注意力机制通过缩放点积计算节点间关系权重，公式如下：

$$
A = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_h}}\right), \quad \tilde{H} = \text{LayerNorm}(H^{(0)} + AV)
$$

其中 $Q, K, V$ 为可学习投影矩阵，$A$ 反映实体间注意力分布。该设计使智能体能动态感知敌方威胁转移或友方位置变化，解决传统扁平架构中因缺乏结构化关系建模导致的态势感知模糊问题，为后续角色分配提供精细化的战场拓扑表征。

### 分层动态角色分配

传统HRL高层策略通常生成空间子目标，但在动态对抗中，静态子目标难以适应战术需求变化。DRG-MAPPO引入动态角色分配，高层策略基于图关系表征与全局上下文，输出离散战术角色 $r_i \in \{1, \dots, K\}$（如“领导者”、“支援者”）。角色嵌入通过可学习嵌入表 $E_{role}$ 映射为连续向量，避免独热编码的梯度稀疏问题。为抑制角色振荡，引入时间承诺机制：

$$
r_i^t = \begin{cases}
\pi_{role}(\cdot | o_i^t) & \text{if } t \mod T_{role} = 0 \\
r_i^{t-1} & \text{otherwise}
\end{cases}
$$

其中 $T_{role}$ 为承诺周期。该机制强制角色在固定区间内保持一致，既降低了高层策略决策频率以稳定训练，又使队友能预判彼此持续意图，促进隐式协同。底层策略条件于角色嵌入 $e_i^{role}$ 与图特征，执行离散机动动作，实现战术意图与底层控制的解耦。

## 实验评估

实验在200km×100km的2v2超视距空战仿真环境中进行，基线包括IPPO、QMIX、MAPPO、HAPPO及MAPPO+GAT。DRG-MAPPO在2500个回合后达到87%胜率，显著优于MAPPO（80.9%）与MAPPO+GAT（78.2%），表明图关系建模与动态角色分配的协同效应优于单一改进。

| 方法 | 胜率 (%) |
| :--- | :--- |
| DRG-MAPPO | 87.6 |
| MAPPO | 80.9 |
| MAPPO+GAT | 78.2 |
| HAPPO | 71.8 |
| QMIX | 49.2 |
| IPPO | 63.2 |

消融实验显示，移除时间承诺机制导致胜率波动加剧，移除图建模或角色分配均造成性能显著下降，验证了各模块的必要性。目标优先级辅助任务通过交叉熵损失引导智能体聚焦高威胁目标，促进集火行为涌现，避免了复杂奖励工程的过拟合风险。

评估边界方面，实验仅覆盖2v2小规模场景，未测试更大规模集群下的可扩展性。代码未公开，超参数（如 $T_{role}$、$\lambda_{aux}$）未详细披露，可复现性受限。指标仅关注胜率与平均奖励，缺乏对战术行为（如机动效率、导弹消耗）的细粒度分析。

## 关联研究分析

从问题动机看，DRG-MAPPO与基于GNN的MARL方法（如Hu et al., 2023）均旨在解决部分可观测性下的协同问题，但前者聚焦于静态通信拓扑或单一实体类型，而DRG-MAPPO通过全连接实体图与动态角色分配，显式建模敌我交互的复杂拓扑。这一差异源于任务特性：空战中敌我关系动态变化且战术角色需实时调整，静态图结构无法捕捉此类动态性。DRG-MAPPO的图注意力机制与角色嵌入结合，提供了更灵活的态势感知与任务分配能力，但其在大规模集群中的计算开销与收敛稳定性尚需验证。

从方法设计看，DRG-MAPPO与分层强化学习（HRL）方法（如HAPPO）均解耦高层与底层决策，但HAPPO依赖启发式状态划分或静态子目标，而DRG-MAPPO引入动态角色分配与时间承诺机制。这一设计选择解决了静态子目标在动态对抗中适应性不足的问题，但角色嵌入的可解释性与泛化能力仍存疑。例如，角色“领导者”与“支援者”的边界在复杂战术中是否清晰，以及时间承诺周期 $T_{role}$ 对战术灵活性的影响，论文未提供深入分析。

## 总结

DRG-MAPPO旨在解决多无人机协同空战中动态拓扑关系建模与战术角色分配的矛盾，通过图注意力机制构建实体关系表征，并引入分层策略解耦高层角色分配与底层机动控制。该框架在2v2超视距空战中取得87%胜率，显著优于基线方法，验证了动态角色分配与图关系建模的协同效应。然而，实验仅覆盖小规模场景，未测试更大规模集群下的可扩展性，且角色嵌入的可解释性与时间承诺机制对战术灵活性的影响未深入分析。当智能体数量增加至数十个时，全连接实体图的计算开销与动态角色分配的收敛稳定性是否仍能保持优势，论文未给出回答。
