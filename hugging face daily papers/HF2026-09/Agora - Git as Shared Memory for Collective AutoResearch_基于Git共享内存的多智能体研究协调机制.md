> 导读 多智能体研究系统面临的核心困境是状态隔离：每个智能体会话独立运行，导致重复搜索、负面结果丢失及早期收敛。现有框架依赖中央编排器或角色分工，无法在异步、无共享文件系统的环境中维持跨会话的持久记忆与去重。Agora 将研究过程建模为存储在 Git 中的追加式有向无环图（DAG），通过不可变提交记录血缘关系，利用下游证据评分与多样性感知注意力分配实现去中心化协调。该机制在权重迁移任务上验证了有效性，但其对复杂开放式任务的泛化能力及计算效率边界尚存疑。

## 研究背景

当多个编码智能体并行处理同一研究任务时，缺乏共享状态会导致严重的资源浪费。智能体 A 发现的失败路径无法被智能体 B 感知，导致后者重复尝试相同错误；同时，早期发现的局部最优解会吸引所有智能体聚集，形成“单一种群”（monoculture），阻碍对未探索区域的覆盖。这种状态隔离源于传统多智能体框架（如 Magentic-One）依赖中央编排器或会话内对话，而实际研究社区需要一种能跨越会话生命周期、独立于具体执行器的持久化协调层。

主流解决路线分为两类：一是基于中央规划器的架构，通过显式任务分配避免冲突，但牺牲了去中心化的鲁棒性；二是基于强化学习（RL）的单智能体优化，通过端到端训练提升长程决策能力，但无法解决多智能体间的状态同步问题。Agora 的切入点在于将“研究状态”本身作为协调对象，而非依赖智能体间的实时通信。它借鉴版本控制系统（Git）的不可变性与内容寻址特性，将每次贡献（代码、结果、假设）封装为提交，通过图结构暴露血缘关系与验证状态，从而在无需中央控制器的情况下实现异步协作。

## 核心方法

### 贡献图与血缘追踪

Agora 将项目状态定义为有向无环图 $G=(V, E)$，其中节点 $v$ 代表一次贡献，边 $(u, v) \in E$ 表示 $v$ 基于 $u$ 构建。每个节点存储规范提交哈希 $h$、作者 $a$、标签集 $T$、描述 $d$、元数据 $x$、指标 $m$、父节点集 $P$ 及时间戳 $\tau$。Git 作为唯一状态源，确保所有派生索引（如 SQLite 查询表）均可从历史重建。这一设计解决了传统多智能体系统中“会话结束即状态丢失”的问题，使得负面结果与中间假设得以持久化，供后续智能体检索与复用。

### 下游证据评分与多样性感知分配

为量化贡献质量并防止社区收敛，Agora 引入基于下游证据的评分机制与多样性感知注意力分配。贡献 $u$ 的证据分数 $S(u)$ 定义为其他账户基于其构建的工作加权总和：

$$ S(u) = \sum_{v:(u,v)\in E} \mathbb{1}[a(u) \neq a(v)] w(v) $$

其中 $w(v)$ 为标签权重（如验证 +20，结果 +5），自引用被排除以防止自我炒作。该分数不直接反映真值，而是指示“可操作性”：被他人复现或扩展的工作更具价值。在此基础上，候选节点通过多样性感知上置信界（UCB）排序：

$$ U(v) = 100 Q(v) + C \sqrt{\frac{\log(N+1)}{n(v)+1} + \frac{100 D}{1+\rho(v)}} $$

其中 $Q(v)$ 为质量百分位，$n(v)$ 为后续工作数，$\rho(v)$ 为近重复描述数，$C$ 为随指标分布聚集程度增长的探索常数。该公式将候选分为“利用”（exploit）、“探索已知”（explore known）与“探索新颖”（explore novel）三类，显式平衡局部优化与全局覆盖，避免排行榜导致的单点收敛。

## 实验评估

实验设置聚焦于一个自定义的权重迁移任务：13 个语言模型智能体在 12 天内，基于 141 个预训练捐赠模型，初始化一个 119.6M 参数的冻结混合架构（注意力-SSM），禁止使用训练数据或梯度更新。基线包括随机初始化（3.3923 bpb）与训练后的 GPT-2 124M（约 1.0 bpb）。由于任务独特，无法与 ASearcher 或 ABSeeker 等 RL 基线直接对比，但实验验证了共享状态对发现效率的影响。

| 里程碑 | 时间 (UTC) | 账户 | bpb | 关键变更 |
| :--- | :--- | :--- | :--- | :--- |
| 随机初始化 | — | — | 3.3923 | 基线 |
| 单字元先验 | Apr 27 00:57 | worker1 | 2.5151 | GPT-2 预测先验 |
| 双字元矩阵 | Apr 27 01:50 | worker1 | 2.1284 | 随机 SVD 嵌入 |
| 24 前缀聚合 | Apr 27 13:30 | worker2 | 1.9304 | 几何均值聚合 |
| 最终结果 | May 8 13:24 | slurm_worker_1 | 1.8990 | 跨带 SSM 输出投影 |

核心数字显示，社区最佳结果 1.8990 bpb 关闭了随机初始化与训练 GPT-2 之间 62% 的差距。前 18 个评分贡献贡献了约 98% 的总下降，表明早期快速利用（exploitation）主导了大部分进展。消融分析显示，引入 Cerebras-GPT 捐赠模型与 28 个上下文显著提升了双字元表的稳定性，而单次幂迭代（power iteration）对 SVD 的改进贡献了 0.0021 bpb 的下降。

评估边界受限于单一任务类型，缺乏通用性验证。可复现性方面，同硬件复现位级一致，跨硬件（A100 vs H100）差异在 $1.3 \times 10^{-3}$ bpb 以内，符合预设容差。代码与超参数通过 Git 提交公开，但任务定义与评估器由作者控制，未提供独立第三方复现环境。

## 关联研究分析

从问题动机看，Agora 与 AutoResearch（Karpathy, 2026）形成互补：后者证明单智能体可自主迭代优化训练配置，但状态局限于会话内；Agora 将这种自主性扩展至多智能体异步协作，核心差异在于状态持久化机制。AutoResearch 依赖智能体内部记忆与提示工程，而 Agora 依赖外部 Git 图结构，这使得负面结果与血缘关系可被跨会话检索。然而，Agora 未引入 RL 训练，其智能体能力完全依赖底层 LLM（如 Claude Opus 4.7 或 GPT-5.5），这限制了其在需要复杂策略优化的任务上的上限。

从方法设计看，Agora 与 MAP-Elites（Mouret and Clune, 2015）共享质量多样性（Quality-Diversity）思想，但应用场景不同：MAP-Elites 在连续行为空间中维护精英解集，而 Agora 在离散贡献图中维护血缘与验证状态。Agora 的 UCB 公式借鉴了多臂老虎机（Auer et al., 2002）的探索-利用权衡，但其图结构非平稳，且建议仅为启发式，不保证最优规划。与 Blackboard 架构（Hayes-Roth, 1985）相比，Agora 去除了中央控制策略，完全依赖去中心化的下游证据评分，这降低了协调开销，但也可能导致早期收敛（如实验中观察到的 5 天单一种群）。

## 总结

Agora 解决的核心矛盾是多智能体研究中的状态隔离与重复搜索问题。其切入点在于将 Git 版本控制作为共享内存，通过不可变提交与图结构实现跨会话持久化，而非依赖中央编排器或实时通信。实验证明，在权重迁移任务上，13 个智能体通过共享图结构将 bpb 从 3.39 降至 1.899，关闭了 62% 的差距，且 165 次独立复现无一失败。然而，实验暴露了快速利用导致的早期收敛问题，即社区在 5 天内陷入单一种群，需人工干预才恢复多样性。当任务复杂度增加且局部最优解更多时，仅依赖下游证据评分与 UCB 启发式是否足以维持足够的探索多样性，论文未给出回答。
