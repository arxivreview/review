# HuggingFace最新推荐论文 ｜CERA-MoA: Co-Evolving Routing Mechanisms with Continually Learning LLM Agents ｜共进化路由与持续学习智能体

研究机构：清华大学、上海交通大学

作者：Jiaxuan Jiang、Liyuan He、Zhixuan Fang

论文原文见 [arXiv](https://arxiv.org/abs/2609.18779)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.18779)

> 多智能体系统（MAS）在复杂任务上常因通信开销与错误级联而难以稳定超越单智能体基线，现有方案将查询路由与智能体微调割裂，导致路由策略无法适应智能体能力的动态变化，且缺乏机制诱导智能体形成领域特化。CERA-MoA 通过构建路由与智能体策略的闭环共进化框架，利用中间隐藏层状态预测智能体熟悉度，并采用累积阈值动态激活最小智能体子集，在平衡推理精度与计算成本的同时实现了能力分化。该框架在 4B 参数小模型池上验证了共进化范式的有效性，但其绝对性能未超越领域内基于大模型集成的 SOTA，且特化机制在异构大模型池上的泛化性仍存疑。

## 研究背景

当多智能体系统处理长程推理任务时，静态拓扑与固定角色分工往往导致通信冗余与错误传播。为提升效率，研究转向动态路由，通过状态感知选择智能体子集。然而，现有路由机制（如 ICL-Router、LinUCB）假设智能体能力在训练期间保持静态，无法响应后训练阶段智能体策略的持续演化。这种解耦导致两个失效：路由无法适应能力漂移，且训练数据分配缺乏基于能力的动态机制，使智能体停留在通用水平而非形成领域专家。

多智能体强化学习（MARL）与拓扑优化路线虽解决了结构自适应问题，但多聚焦于通信图结构的生成或策略梯度的层级分配，未将“样本级路由”与“智能体持续学习”纳入同一优化闭环。CERA-MoA 的切入点在于识别这一断层：将路由策略视为智能体能力的动态函数，通过闭环反馈同时优化路由头与智能体策略，从而在训练过程中自动诱导技能特化，而非依赖人工划分数据集或预设工作流。

## 核心方法

### 方法参照系

本文问题归属于“智能体路由与调度”路线，但区别于基于固定能力画像或上下文赌博机（Contextual Bandit）的静态路由。标准流程假设候选模型参数冻结，路由仅基于当前查询特征选择最优子集；本文的关键差异在于路由头参数 $\psi$ 与智能体策略 $\theta_i$ 在训练过程中同步更新，路由决策直接受智能体实时能力演化驱动。

### 预测性熟悉度估计器

传统路由依赖外部评估器或完整生成回滚（Rollout）来评估智能体能力，计算开销巨大。CERA-MoA 引入预测性熟悉度估计器，直接提取 LLM 中间层隐藏状态 $h(q)$，通过可训练预测头 $g_i$ 与冻结目标头 $\bar{g}_i$ 的投影距离量化语义兼容性。设计动机在于避免自回归解码的递归开销，实现生成前的低成本能力评估。熟悉度分数 $f_i(q)$ 定义为：

$$ f_i(q) = \exp(-\lambda d_i(q)) $$

其中 $d_i(q)$ 为归一化欧氏距离，$\lambda$ 为温度超参数。该公式将几何距离转化为指数衰减的熟悉度信号，距离越小分数越高，为后续路由提供连续、可微的能力度量。

### 累积阈值自适应路由与闭环优化

固定 Top-k 路由无法平衡性能与成本，CERA-MoA 采用累积阈值策略，激活熟悉度分数排序后累计值超过阈值 $\tau$ 的最小智能体子集。设计动机在于实现细粒度的性能-成本权衡，避免复杂查询因激活不足而失败，或简单查询因冗余激活而浪费 Token。路由损失函数 $L_{router}$ 基于相对优势 $A_{i,q}$ 优化预测头：

$$ L_{router}(g_i) = \sum_{q \in Q} \begin{cases} A_{i,q} d_i(q), & \text{if } A_{i,q} \ge 0 \\ |A_{i,q}| \max(0, m - d_i(q)), & \text{if } A_{i,q} < 0 \end{cases} $$

该损失通过“推拉”机制调整投影空间：正优势拉近预测头与目标头，负优势在边界 $m$ 内推开，确保高绩效智能体的熟悉度分数随训练稳步提升，形成“能力越强-分配越多-特化越深”的正反馈闭环。

## 实验评估

实验在 GSM8K、MATH、MBPP 等四个领域进行，基线覆盖静态路由（ICL-Router, LinUCB, RouteMoA）与固定工作流微调（GSPO, MAPoRL, AT-GRPO）。CERA-MoA 在 Qwen3-4B 骨干上，ID 任务平均准确率 63.2%，OOD 任务 72.8%，显著优于 AT-GRPO（ID 61.0%，OOD 71.5%）与 RouteMoA（ID 53.1%，OOD 57.9%）。

| 方法 | ID Avg. | OOD Avg. | Avg. Tokens |
| :--- | :--- | :--- | :--- |
| RouteMoA | 53.1 | 57.9 | 53.1 |
| AT-GRPO | 61.0 | 71.5 | 61.0 |
| CERA-MoA | 63.2 | 72.8 | 367.77 |

消融实验显示，移除探索机制（UCB & Entropy）导致 ID 准确率从 63.2% 降至 57.1%，证明探索对防止策略饥饿至关重要。温度 $\lambda$ 从 2.0 降至 1.0 时，熟悉度分数过早饱和，ID 准确率降至 55.3%，表明过低的温度抑制了早期探索。分离边界 $m$ 移除后导致训练不稳定，验证了有界排斥机制的必要性。

评估边界方面，论文未报告置信区间，且仅在 4B 参数小模型池上验证。代码未公开，但提供了详细超参数（如 LoRA Rank 16, $\tau=0.7$）与硬件配置（NVIDIA H200），可复现性较高。指标涵盖 ID 与 OOD 泛化，但缺乏对通信延迟的细粒度分析，仅报告平均 Token 数。

## 关联研究分析

从问题动机看，CERA-MoA 与 AgentDropout 均旨在降低 Token 开销，但 AgentDropout 基于固定比例剪枝冗余节点，假设智能体能力静态；CERA-MoA 则通过动态阈值激活最小子集，其路由决策随智能体能力演化而调整。这一差异源于任务特性：AgentDropout 适用于推理时优化，而 CERA-MoA 聚焦训练时的能力诱导，后者更依赖闭环反馈而非静态剪枝规则。

从方法设计看，CERA-MoA 与 RouteMoA 同属对比学习路由框架，但 RouteMoA 使用外部评分器评估固定模型，CERA-MoA 将评分器内化为可训练预测头，并与智能体策略联合优化。这一改动解决了 RouteMoA 在智能体微调后路由失准的问题，但引入了路由头过拟合特定智能体组合的风险。查询侧增强在数据充足时是否仍有增益，论文未给出回答，且异构大模型池中的语义鸿沟可能削弱隐藏层熟悉度估计的有效性。

## 总结

CERA-MoA 解决了多智能体系统中路由策略与智能体持续学习解耦导致的特化缺失问题。其切入点在于将路由头视为智能体能力的动态函数，通过中间隐藏层熟悉度估计与累积阈值路由，在闭环中同步优化两者。实验证明该框架在 4B 小模型池上，ID 任务平均准确率 63.2%，OOD 任务 72.8%，优于静态路由与固定工作流基线。然而，论文仅在共享骨干或小规模异构池上验证，未探索大模型集成中的通信瓶颈与特化机制的泛化性。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
