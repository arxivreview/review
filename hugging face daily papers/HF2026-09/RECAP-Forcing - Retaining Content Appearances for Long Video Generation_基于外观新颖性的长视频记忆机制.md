# HuggingFace最新推荐论文 ｜RECAP-Forcing: Retaining Content Appearances for Long Video Generation ｜基于外观新颖性的长视频记忆机制

作者：Haiyang Xu、Zheng Ding、Zhuowen Tu

论文原文见 [arXiv](https://arxiv.org/abs/2608.26671)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.26671)

> 自回归长视频生成面临有限注意力窗口下的记忆管理困境，现有基于时间最近性的缓存策略在维持主体一致性与动态性之间陷入两难。本文提出以“外观新颖性”而非时间顺序作为记忆索引轴，通过强化注意力沉点与光流新颖性存储库，在推理阶段重构记忆组织方式。该免训练机制在多个因果视频生成骨干上显著提升了动态度指标，但其对复杂场景中新颖性检测的鲁棒性及计算开销仍存疑。

## 研究背景

因果自回归视频生成模型通过块状预测实现流式输出，其核心约束在于有限的KV缓存窗口。当生成时长超过窗口容量时，模型必须决定保留哪些历史帧的键值对（KV cache）。这一决策直接决定了长程一致性：若丢弃早期帧，主体身份将随时间漂移；若过度保留，运动动态性会被抑制导致画面冻结。

当前主流方法沿时间轴组织记忆，包括滑动窗口、基于重要性的压缩或循环重放初始帧。这些策略隐含一个假设：维持一致性需要回溯时间线中最近出现的帧。然而，这种时间索引导致记忆压力随视频长度线性增长，且早期内容的细节在压缩中永久丢失。RECAP-Forcing 指出，长视频的一致性不依赖于时间线的完整保留，而依赖于对“新出现内容”的精准捕捉。

本文切入点在于重构记忆的组织原则：从“何时出现”转向“是否为新”。通过识别内容首次进入视野的时刻并持久化其KV缓存，模型无需回溯漫长的时间序列即可维持主体身份。这一视角将长程一致性转化为记忆结构的固有属性，而非模型需通过注意力机制重新重建的目标。

## 核心方法

### 因果自回归视频生成与有限记忆约束

本文基于 Self-Forcing 等因果蒸馏模型，视频以 $b$ 帧为块生成，每帧划分为 $f$ 个 token。模型仅条件于最近 $L$ 帧的滑动 KV 缓存，通过旋转位置编码（RoPE）实现任意长度生成。为对抗漂移，LongLive 等骨干保留前 $s$ 帧作为永久注意力沉点（Attention Sink），其 RoPE 相位在检索时重置，确保锚点不超出训练分布。RECAP-Forcing 在此架构上操作，不修改模型权重，仅调整推理时的注意力分布与缓存准入策略。

### 强化注意力沉点：从稳定锚点到第一印象记忆

标准沉点仅维持全局色调与风格，对主体身份保持不足。本文在预软化 logits 中添加固定偏置，将沉点升级为“第一印象记忆”。对于查询 $q$ 与键 $k_j$，若 $j$ 属于沉点集合，则添加偏置 $\beta_j = \ln \lambda$：

$$
\alpha_j = \text{softmax}_j \left( \frac{q^\top k_j}{\sqrt{d}} + \beta_j \right)
$$

其中 $\lambda > 1$ 为强化因子。该设计动机在于解决默认注意力分布下沉点权重不足导致的主体漂移。通过 $\ln \lambda$ 偏置，沉点键的未归一化注意力权重被均匀放大 $\lambda$ 倍，在保持查询-键相似度选择性的同时，提升初始场景的持久影响力。实验设定 $\lambda=5$，此时沉点注意力占比约 24%，足以锚定主体身份而不抑制动态性。

### 光流新颖性存储库：基于外观事件的记忆准入

强化沉点仅覆盖开场场景，后续新进入的主体或区域需独立记忆。本文引入光流新颖性存储库（Novelty Bank），利用 RAFT 光流检测“新颖出现事件”：物体进入视野、遮挡解除或视角变化。新颖性得分基于相邻帧间光流聚合，选取得分最高的 $K$ 个 patch 的 KV 缓存存入固定容量存储库。准入机制与查询无关，仅依据视觉新颖性，无需实体识别。该设计解决了时间索引记忆中“新内容被旧内容挤出”的问题，确保第 3 秒引入的主体在第 5 分钟仍可直接访问。存储库容量 $K=1560$，约为单帧 token 数，记忆增长与新内容量成正比，而非视频时长。

## 实验评估

实验在 VBench-Long 基准上进行，使用 128 个提示词与 5 个随机种子，生成 60 秒（240 潜在帧）视频。基线覆盖 Self-Forcing、Infinite-Forcing、LongLive 及 Helios 四个因果模型，对比方法包括 Deep Forcing、MemRoPE 和 Rolling Sink 等免训练记忆策略。

| 方法 | 骨干 | Total | Dynamic Degree | Subject Consistency |
| :--- | :--- | :--- | :--- | :--- |
| Self-Forcing (Baseline) | Self-Forcing | 75.9 | 27.5 | - |
| RECAP-Forcing | Self-Forcing | 79.5 | 58.1 | - |
| Infinite-Forcing (Baseline) | Infinite-Forcing | 78.3 | 61.3 | - |
| RECAP-Forcing | Infinite-Forcing | 79.7 | 71.3 | - |
| Deep Forcing | Self-Forcing | - | 23.0-41.2 | - |
| MemRoPE | Self-Forcing | - | 23.0-41.2 | - |
| Rolling Sink | Self-Forcing | - | 23.0-41.2 | - |

RECAP-Forcing 在 Self-Forcing 骨干上将动态度从 27.5 提升至 58.1，总分从 75.9 升至 79.5；在 Infinite-Forcing 骨干上动态度提升 10.0 至 71.3。相比其他免训练方法，RECAP-Forcing 的动态度显著更高，且总分最优，表明其在一致性与动态性间取得了更优平衡。

消融实验显示，存储库容量 $f$ 从 1 增至 4 时总分仅微增，$f=8$ 时降至 79.3，故默认 $f=1$。强化因子 $\lambda$ 从 1 增至 5 时总分从 78.8 升至 79.7，$\lambda=8,10,12$ 时分别降至 79.2, 78.9, 78.6。诊断扫描表明，$\lambda=5$ 时主体一致性已饱和，而动态度在 $\lambda \approx 8$ 后开始侵蚀，证实适度强化是平衡点。

评估边界方面，VBench-Long 对细粒度空间一致性不敏感，且未报告推理延迟。光流计算在动态模糊场景下的鲁棒性未验证，代码未公开，超参数 $\lambda=5, K=1560$ 固定于 60 秒视频，外推至更长时长的有效性未知。

## 关联研究分析

从记忆组织原则看，RECAP-Forcing 与 LongLive 的 Sink 机制同源，但 LongLive 将 Sink 视为稳定性锚点，仅保留前 $s$ 帧，导致后续新主体缺乏记忆支持。RECAP-Forcing 将 Sink 重新解释为“第一印象记忆”并强化，同时引入光流存储库处理后续新内容，解决了 LongLive 在动态场景下主体漂移的问题。这一差异源于对“一致性”定义的不同：LongLive 侧重全局风格稳定，RECAP-Forcing 侧重主体身份持久。

从免训练策略看，MemRoPE 通过调整 RoPE 相位缓解位置编码失效，属于隐式缓存优化；RECAP-Forcing 通过显式存储新内容 KV 缓存，属于显式记忆机制。MemRoPE 无需额外存储，但无法处理新进入的主体；RECAP-Forcing 需光流计算与存储库管理，但能精准捕捉新内容。两者在实时性上存在权衡：MemRoPE 计算开销低，RECAP-Forcing 引入光流检测延迟。论文未提供延迟对比，光流在快速运动场景下的准确性存疑。

## 总结

RECAP-Forcing 旨在解决自回归长视频生成中记忆有限导致的一致性与动态性冲突。现有时间索引记忆策略因压缩早期内容而丢失细节，或因过度锚定而抑制运动。本文抓住“外观新颖性”这一被忽略的索引轴，通过强化沉点与光流存储库，在推理阶段将记忆组织从时间顺序转为内容新颖度。实验证明，该方法在 Self-Forcing 骨干上将动态度从 27.5 提升至 58.1，总分从 75.9 升至 79.5，显著优于其他免训练方法。其边界在于光流检测对动态模糊的鲁棒性未验证，且存储库容量固定于 60 秒视频，外推至更长时长的有效性未知。当视频时长扩展至分钟级以上，光流新颖性检测在复杂动态场景下的误检率是否会导致存储库污染，论文未给出回答。
