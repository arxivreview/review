论文原文见 [arXiv](https://arxiv.org/abs/2609.33803)

> 奖励模型（RM）在强化学习从人类反馈（RLHF）中充当优化信号，但主流设计将提示-响应对坍缩为标量或固定参数族分布，无法表征人类偏好固有的多模态结构。现有标量、多属性及参数化分布头均受限于预设输出族，导致在标注者分歧大的场景下丢失不确定性信息。DRM 引入扩散变换器（DiT）作为奖励头，通过去噪过程隐式建模条件密度 $p(r|x,y)$，无需假设特定分布族。该范式在受控实验中优于标量基线，并提供了测试时缩放轴，但其绝对性能未达领域SOTA，且高推理成本限制了大规模部署。

## 研究背景

当标注者对同一响应给出截然不同的评价时，单一标量奖励无法捕捉这种分歧。这种分歧并非噪声，而是人类偏好多模态性的体现：同一响应可能在有用性上得分高，但在无害性上得分低，或不同标注者基于不同标准产生系统性偏差。标量奖励模型（RM）通过Bradley-Terry（BT）损失拟合偏好，隐含假设偏好是单峰且一致的，这与实际数据中约63%的标注者一致性（Anthropic-HH）相悖。

现有尝试突破标量瓶颈的方法均存在局限：多属性RM需预定义属性schema并坍缩为向量；生成式RM通过长文本推理提供解释，但推理成本高昂且最终仍输出单一判决；参数化分布头如高斯或分位数网格，受限于固定分布族，无法表达多模态结构。这些方法在标注者分歧大或偏好分布复杂时，要么丢失不确定性，要么无法准确拟合分布形状。

DRM的切入点在于将奖励建模重构为条件密度估计问题。它不假设输出分布的参数形式，而是利用扩散模型强大的多模态覆盖能力，直接学习 $p(r|x,y)$ 的完整分布。这一设计使得模型能够自然表征人类偏好的多峰结构，并在推理时通过采样获得分布统计量，为不确定性量化和风险敏感决策提供基础。

## 核心方法

### 方法参照系

标准RM流程使用冻结LLM编码器提取语义特征 $h$，再通过MLP回归标量或参数。本文的关键差异在于替换输出头：不再回归固定参数，而是通过迭代去噪生成奖励向量，从而隐式建模任意分布。

### 扩散奖励头架构

DRM采用轻量级DiT作为奖励头，条件于冻结LLM编码器的最后一层隐藏状态 $h$。DiT通过自适应层归一化注入文本条件 $h$ 和时间步 $t$，预测前向过程中的噪声。该设计解决了参数化头无法表达多模态分布的问题，因为扩散模型已知能覆盖复杂分布模式。

$$
\hat{\epsilon} = \epsilon_\theta(r_t, t, h)
$$

此公式表示DiT头预测当前噪声水平 $r_t$ 下的噪声 $\hat{\epsilon}$，其中 $h$ 提供语义上下文，$t$ 指示去噪阶段。通过最小化预测噪声与真实噪声的均方误差，模型学习条件分布的得分函数。

### 统一训练目标

DRM支持两种监督模式：多属性回归和成对偏好。对于多属性数据，使用掩码去噪损失，仅在标注维度上计算误差；对于偏好数据，在去噪估计上施加BT排序损失。这种统一框架允许单一模型处理异构数据，无需预定义属性schema。

$$
\mathcal{L}_{\text{pair}} = \mathcal{L}_{\text{denoise}} + \lambda_{\text{BT}} \mathcal{L}_{\text{BT}}
$$

此公式结合了去噪信号和排序信号：$\mathcal{L}_{\text{denoise}}$ 确保分布形状准确，$\mathcal{L}_{\text{BT}}$ 强制偏好对的排序正确。$\lambda_{\text{BT}}$ 平衡两者，避免去噪过程破坏排序信息。

## 实验评估

DRM在五个基准上评估：RewardBench v2、PPE、RMB、RM-Bench和JudgeBench，覆盖聊天、指令跟随、数学、代码、事实性和安全性。基线包括标量RM（ArmoRM）、参数化分布RM（QRM、URM）和生成式裁判（GPT-4o）。在相同数据和骨干下，DRM-Multi-8B平均得分66.2，超过ArmoRM（62.3）和QRM（64.1），其中RMB提升最大（78.0）。

| 方法 | RewardBench v2 | PPE | RMB | RM-Bench | JudgeBench | 平均 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| ArmoRM | - | - | - | - | - | 62.3 |
| QRM | - | - | - | - | - | 64.1 |
| DRM-Multi-8B | - | - | 78.0 | - | - | 66.2 |
| GPT-4o | - | - | - | - | - | 67.7 |

DRM在受控对比中表现优于标量和参数化基线，但与更大规模的生成式裁判（GPT-4o, 67.7）仍有差距。消融实验显示，增加扩散样本数 $N$ 可提升评分精度：DRM-Multi-8B在RewardBench v2上从单样本的56.5%提升至32样本的65.6%，证明测试时缩放轴的有效性。LCB聚合在所有PPE和RMB Best-of-N设置中均优于均值聚合，例如在RMB Helpfulness $K=3$ 时，从68.231提升至68.611。

评估边界方面，论文未报告计算效率指标（FLOPs或延迟），尽管扩散头推理成本高于标量RM。代码和超参数已开源，但GPU需求未明确。评估协议基于标准基准，但未包含最新SOTA如Skywork-Reward-V2，可能限制绝对性能比较。

## 关联研究分析

从问题动机看，DRM与生成式RM（如Rubric-Based RM）同属“拒绝标量坍缩”路线，但机制不同。生成式RM通过长文本推理提供解释，推理成本高且最终输出单一判决；DRM通过分布采样提供不确定性，推理成本中等但输出完整分布。根源在于任务特性：生成式RM适合需要可解释性的场景，而DRM适合需要风险敏感决策的场景。DRM未探索文本解释能力，这在需要审计的部署中可能是盲区。

从方法设计看，DRM与参数化分布头（如QRM）同属“分布建模”路线，但DRM不假设分布族。QRM使用固定分位数网格，受限于量化交叉和尾部不稳定；DRM通过迭代去噪隐式建模任意分布，灵活性更高。然而，DRM的推理成本随样本数 $N$ 线性增长，而QRM单次前向传播即可输出。在计算受限场景下，QRM可能更具竞争力，但DRM在多模态偏好表征上更准确。

## 总结

DRM解决的核心矛盾是标量奖励无法表征人类偏好的多模态结构。其切入点在于利用扩散模型的非参数化特性，直接建模条件密度 $p(r|x,y)$，避免了固定分布族的限制。方法上，DRM用DiT头替换传统MLP，通过去噪过程生成奖励分布，并支持多属性和偏好两种监督模式。实验证明，在受控对比中，DRM-Multi-8B平均得分66.2，超过ArmoRM（62.3）和QRM（64.1），且LCB聚合提升决策质量。边界在于，DRM的绝对性能未达领域SOTA（如GPT-4o的67.7），且推理成本随样本数增加而上升，未报告具体延迟数据。当标注者分歧极大时，DRM的多模态输出是否总能优于生成式RM的文本解释，论文未给出直接对比。
