作者：Wenxu Jia、Xize Cheng、Zihan Zhang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2609.32522)

> 多说话人语音对话中的长期记忆面临身份混淆与交互角色丢失的双重困境，现有文本或图像记忆系统无法处理声学身份线索与“谁对谁说”的归因需求。本文切入点在于将声纹嵌入与有向交互图结合，构建层级化记忆结构，并引入基于证据增益的强化学习优化检索策略。VoxPolyMem 通过增量说话人识别、交互感知记忆层级及 EG-GRPO 训练的检索代理，实现了跨会话的身份关联与自适应证据获取。该方法在 VoxPolyBench 上取得 85.0 分，显著优于最强基线，但其依赖合成语音数据且未验证真实噪声下的鲁棒性，泛化能力存疑。

## 研究背景

当助手需要在多次会议或车载对话中记住“上周张三向李四承诺的截止日期”时，系统不仅需存储文本内容，还需关联张三的声纹特征与“张三对李四说话”这一交互角色。仅依赖自动语音识别（ASR）转录会丢失声学身份线索，导致跨会话身份混淆；而传统记忆系统缺乏对交互方向的显式建模，无法区分“张三说给李四”与“李四说给张三”的不同语义。这种身份与角色的缺失，使得个性化回答与交互归因任务难以实现。

现有长期记忆研究主要聚焦于二元文本或图像-文本对话，如 Mem0 和 A-Mem 通过事实提取与上下文链接构建记忆，但均未处理多说话人语音场景中的声学身份恢复与交互角色保留。近期工作虽扩展至多说话人文本历史，但缺乏对语音模态中声纹嵌入与交互图结构的联合建模。本文针对这一空白，提出 VoxPolyMem 框架，将增量说话人识别与交互感知层级记忆结合，解决多说话人语音对话中跨会话身份关联与交互归因的核心问题。

## 核心方法

### 方法参照系

本文问题属于多模态长期记忆构建与检索，但区别于通用文本记忆系统的关键在于：需同时处理声学身份（声纹嵌入）与交互角色（有向图），且检索策略需适应跨会话、跨模态的证据分布。通用记忆流程通常包含记忆提取、存储与检索三阶段，本文在存储阶段引入交互图结构，在检索阶段引入强化学习优化的代理决策。

### 增量说话人识别与交互感知记忆

传统记忆系统仅存储 ASR 转录文本，丢失声学身份线索，导致跨会话身份混淆。本文在记忆提取阶段引入 ECAPA-TDNN 声纹编码器，对每个语音轮次生成归一化声纹嵌入 $e_i$，并通过余弦相似度匹配维护在线说话人记忆集合 $V$。当相似度 $s_i \geq \tau_{match}$ 时，将当前轮次分配给已有说话人 ID，否则创建新 ID。为应对声学变化，仅当 $s_i \geq \tau_{update}$ 时通过指数移动平均更新声纹嵌入：

$$v_{k^*} \leftarrow \text{norm}((1-\alpha)v_{k^*} + \alpha e_i)$$

该机制在保留身份稳定性的同时适应声学波动。交互记忆进一步建模为有向图 $M_{int} = (P \cup U, E)$，其中边集 $E$ 记录“说话人→消息”与“消息→接收人”关系，显式保留交互角色。这一设计解决了传统记忆系统无法区分“谁对谁说”的问题，支持基于交互角色的证据过滤。

### 基于证据增益的自适应检索代理

固定检索策略无法适应跨会话、跨模态的证据分布，导致信息遗漏。本文将检索建模为序贯决策问题，状态 $s_t$ 包含查询、提问者身份、已保留证据 $C_{t-1}$、动作历史 $H_{t-1}$ 及剩余预算 $b_t$。策略 $\pi_\theta$ 选择记忆层、工具、重写查询及过滤条件。训练采用 EG-GRPO，对每个状态采样 $K=8$ 个候选动作，奖励函数基于新获取的支持证据覆盖率与排名：

$$r_i = \lambda \frac{|D_i|}{|G_q|} + (1-\lambda) N_i$$

其中 $D_i$ 为当前动作新保留的支持证据 ID 集合，$N_i$ 为基于排名的折扣项。该奖励机制仅对新获取证据计分，避免重复检索，鼓励互补性证据获取。相比终端奖励方法，EG-GRPO 通过轮次级信用分配，使代理在固定预算内更高效地覆盖分散证据。

## 实验评估

实验在 VoxPolyBench（1,527 QA 对，18.9 小时合成语音）、Mem-Gallery 及 H2HMem-Multi 上进行，基线覆盖 Mem0、A-Mem、LightMem 等文本/多模态记忆系统，但缺乏语音专用记忆基线（如 AFA）。VoxPolyMem 在 VoxPolyBench 上取得 85.0 分，超最强基线 23.6 分；在 Mem-Gallery 和 H2HMem-Multi 上分别取得 89.6 和 74.4 分，超最强基线 11.8 和 8.4 分。

| 基准 | 方法 | Score | Recall |
| :--- | :--- | :--- | :--- |
| VoxPolyBench | VoxPolyMem | 85.0 | 87.4 |
| VoxPolyBench | 最强基线 | 61.4 | - |
| Mem-Gallery | VoxPolyMem | 89.6 | 93.6 |
| Mem-Gallery | 最强基线 | 77.8 | - |
| H2HMem-Multi | VoxPolyMem | 74.4 | - |
| H2HMem-Multi | 最强基线 | 66.0 | - |

消融实验显示，移除层级记忆（事实/画像）导致 H2HMem-Multi 分数从 72.1 降至 63.6，移除交互关系导致 VoxPolyBench 分数从 84.0 降至 78.6，表明记忆抽象与交互结构对分散信息访问与角色区分至关重要。单轮检索比多轮检索分数下降更显著，说明迭代检索对证据完整性影响大于查询重写。RL 训练将 Mem-Gallery 分数从 86.3 提升至 89.6，H2HMem-Multi 从 72.1 提升至 74.4，验证了 EG-GRPO 对联合检索策略的优化效果。

评估协议使用 GPT-4.1-mini 作为回答模型，Score 为两个独立评判模型的平均分，Recall 为最终上下文中支持证据的覆盖率。VoxPolyBench 基于合成语音，WER 为 2.14%，但缺乏真实噪声、口音及不流利现象的测试，泛化能力未验证。代码与数据集已开源，但 RL 训练需约 900 QA 实例，超参数未完全披露。

## 关联研究分析

从问题动机看，VoxPolyMem 与 AFA 均关注语音身份在记忆中的作用，但 AFA 仅通过声纹分离用户记忆，未建模交互角色；VoxPolyMem 引入有向交互图，显式保留“谁对谁说”，支持交互归因任务。这一差异源于任务特性：多说话人对话中，交互角色直接影响个性化回答的准确性，而 AFA 面向二元对话，角色信息冗余。

从方法设计看，VoxPolyMem 的 EG-GRPO 与 Search-R1 均使用强化学习优化检索，但 Search-R1 采用终端答案奖励，无法隔离每轮检索的贡献；EG-GRPO 通过轮次级证据增益奖励，鼓励互补性证据获取。这一改进解决了终端奖励在跨会话、跨模态检索中可能导致的证据重复或遗漏问题，但论文未对比 EG-GRPO 与过程奖励（如 LeTS）在证据覆盖效率上的差异，查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

VoxPolyMem 针对多说话人语音对话中身份混淆与交互角色丢失的核心矛盾，通过声纹嵌入与有向交互图构建层级记忆，并以 EG-GRPO 优化检索策略，实现了跨会话身份关联与自适应证据获取。实验表明，该方法在 VoxPolyBench 上取得 85.0 分，超最强基线 23.6 分，验证了交互感知记忆与自适应检索的有效性。然而，其依赖合成语音数据，WER 2.14% 虽低但未测试真实噪声、口音及不流利现象，且 RL 训练需大量标注 QA 实例，超参数未完全披露。当支持集增大到真实场景的声学多样性时，声纹匹配的鲁棒性与 EG-GRPO 的证据覆盖效率是否保持优势，论文未给出回答。
