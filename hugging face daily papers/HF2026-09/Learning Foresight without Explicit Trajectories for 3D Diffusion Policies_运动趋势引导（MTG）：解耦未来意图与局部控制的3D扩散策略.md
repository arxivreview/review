# HuggingFace最新推荐论文 ｜Learning Foresight without Explicit Trajectories for 3D Diffusion Policies ｜运动趋势引导（MTG）：解耦未来意图与局部控制的3D扩散策略

研究机构：大连理工大学

作者：Zhongbo Zhang、Zaibin Zhang、Yifan Wang 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2609.20669)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.20669)

> 导读 3D扩散策略擅长从当前几何观测生成密集动作，但多步操作需要预判交互走向，现有方法将这种前瞻性隐含在动作学习目标中，导致预测误差刚性约束局部控制。本文提出运动趋势引导（Movement Trend Guidance, MTG），通过辅助损失监督紧凑潜变量编码未来趋势，而非直接预测轨迹坐标。该设计仅增加3.52%参数，在LIBERO-40上将成功率从37.08%提升至71.93%，验证了“教策略理解未来”优于“告诉策略去哪”的假设，但真机实验仅覆盖5个任务，泛化性存疑。

## 研究背景

当机器人执行抓取、插入或传递等任务时，仅靠当前点云几何无法确定下一步动作——它必须理解交互正在向何处演进：下一个接触点在哪，或双执行器应协调至何种构型。这种对“交互走向”的预判需求，构成了操作策略中“当前几何可行性”与“未来交互意图”的二元信息结构。标准扩散策略将两者混同于单一动作学习目标，迫使模型同时恢复局部控制与长程结构，一旦预测出现偏差，错误会作为中间控制目标持续约束后续行为，即使新观测已表明运动应被修正。

主流3D模仿学习路线通过显式中间结构解决此问题：GNF-Actor、RVT等方法预测关键帧位姿或未来视图，FLARE、ForeDiffusion则对齐策略特征与未来观测潜变量。但这些方法要么依赖位姿级目标与显式跟踪接口，要么在2D视觉空间操作，将未来信息转化为密集控制目标。DP3（3D Diffusion Policy）采用点云直接动作扩散，实现了强样本效率与真机迁移，但其未来交互结构仍隐含于动作学习，未显式分离“现在能做什么”与“交互正走向何方”。本文切入点在于：未来预测的价值不在于指定机器人去哪，而在于教策略表征哪些未来相关信息——用稀疏未来状态监督紧凑潜变量，而非生成可执行的轨迹。

## 核心方法

### 方法参照系

本文基于DP3的点云扩散策略框架，其标准流程为：编码观测窗口→全局条件注入→UNet去噪生成动作序列。关键差异在于，DP3将未来交互结构隐含于动作学习目标，而本文显式引入未来监督的潜变量作为独立条件通路，且该潜变量在推理时不解码为轨迹坐标。

### 潜变量运动趋势表征

设计动机：直接预测未来轨迹坐标会将预测误差转化为刚性控制目标，而操作策略仅需粗粒度交互演进指示。本文在观测编码后、动作去噪前插入轻量编码器 $\mathcal{F}_\phi$，将点云与机器人状态特征映射至256维潜变量 $z_t$：

$$z_t = \mathcal{F}_\phi(O_t) \in \mathbb{R}^{256}$$

该潜变量取自辅助未来夹爪目标头之前的隐藏层，训练时通过解码器恢复4个未来偏移（5,10,15,20帧）的夹爪状态，推理时仅保留 $z_t$ 作为条件，解码输出被丢弃。这一设计使潜变量编码“交互演进”而非“未来坐标”，避免了轨迹预测误差对局部控制的传播。

### 瓶颈门控FiLM调制

设计动机：潜变量若通过标准全局条件通路影响所有UNet层，可能主导局部去噪，破坏观测驱动的精细控制。本文将潜变量调制限制在UNet瓶颈层，采用门控FiLM：

$$\tilde{x} = (1+\alpha) \odot x + \beta, \quad y = x + \gamma \odot (\tilde{x} - x)$$

其中 $\alpha, \beta, \gamma$ 由条件向量投影生成，缩放与偏置投影初始化为零，确保初始时该分支为恒等映射。负门偏置进一步限制调制强度。潜变量仍通过全局条件通路影响动作序列整体结构，而直接调制仅作用于瓶颈，使未来信息塑造全局动作组织而不干扰局部几何精修。

## 实验评估

实验在RoboTwin2.0（50任务混合训练）、LIBERO-40、DexArt及5个SO101真机任务上评估，基线覆盖DP3、ACT、RDT、π0等主流策略，但未对比FLARE、ForeDiffusion等未来引导方法，缺乏对“未来信息注入方式”的横向审计。

| 基准 | 方法 | 成功率 (%) |
| --- | --- | --- |
| RoboTwin2.0 (50-task) | DP3* | 56.1 |
| RoboTwin2.0 (50-task) | Ours* | 62.8 |
| LIBERO-40 | DP3 | 37.08 ± 1.21 |
| LIBERO-40 | Ours | 71.93 ± 0.49 |
| DexArt | DP3 | 49.0 |
| DexArt | Ours | 59.25 |
| 真机 (5 tasks) | DP3 | 49.0 |
| 真机 (5 tasks) | Ours | 72.0 |

LIBERO-40的+34.85点增益最大，其中LIBERO-Goal套件提升68.80点，表明未来趋势对长程目标导向任务贡献显著；RoboTwin2.0的+6.7点增益相对温和，可能因混合训练中任务多样性稀释了单一趋势信号的效用。

| 消融变体 | LIBERO-40成功率 (%) |
| --- | --- |
| DP3 (无未来引导) | 37.08 ± 1.21 |
| 参数匹配潜变量 (无未来损失) | 44.87 ± 0.33 |
| 显式未来点条件 | 65.28 ± 0.19 |
| 完整MTG | 71.93 ± 0.49 |

消融显示，仅增加潜变量容量（无未来损失）仅提升7.79点，而添加未来监督再增27.06点，证明增益主要来自未来监督塑造的表征而非额外容量；显式未来点条件（65.28%）低于完整MTG（71.93%），验证了“潜变量引导”优于“轨迹目标”的设计假设。

评估协议局限：LIBERO-40使用stride-4时间子采样，DexArt报告最佳5个检查点均值而非固定epoch，聚合方式不一致影响跨基准可比性；真机实验仅5个任务、20次rollout，样本量不足以支撑泛化性结论；代码已开源，但超参数（如 $\lambda_{future}=1.0$）未提供敏感性分析。

## 关联研究分析

从问题动机看，FLARE与ForeDiffusion同样引入未来预测作为策略条件，但前者对齐未来视觉观测潜变量，后者预测未来视图表征，均在2D视觉空间操作；本文直接在3D点云空间用稀疏夹爪状态监督潜变量，差异根源在于任务特性：操作策略需任务空间（夹爪位姿）而非视图空间的未来信息，且3D几何表示天然保留空间拓扑，避免了2D投影的歧义。

从方法设计看，ControlNet引入外部条件通路但未限制调制范围，本文借鉴其条件注入思想但将门控FiLM限制在UNet瓶颈，这一设计选择源于对“未来信息不应主导局部去噪”的假设；与DP3相比，本文未改变密集动作生成与滚动时域执行框架，仅改造条件注入机制，属于最小干预式改进。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文核心矛盾在于密集动作生成与未来交互意图的耦合：标准扩散策略将两者混同于单一学习目标，导致预测误差刚性约束局部控制。本文抓住“未来预测的价值在于表征而非执行”这一被忽略的点，通过稀疏未来状态监督紧凑潜变量，使其编码交互演进而非轨迹坐标，并将调制限制在UNet瓶颈以保护局部精修。在LIBERO-40上，该方法将成功率从37.08%提升至71.93%，RoboTwin2.0从56.1%提升至62.8%，验证了设计有效性。其边界在于：真机实验仅5个任务，且未对比FLARE等未来引导方法，无法判断3D点云空间的优势是否源于任务特性还是方法设计。当任务复杂度增加至需要双执行器精细协调时，256维潜变量是否足以编码多模态交互趋势，论文未给出回答。
