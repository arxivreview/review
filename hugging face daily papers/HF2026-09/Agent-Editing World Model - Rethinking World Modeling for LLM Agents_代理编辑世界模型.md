# HuggingFace最新推荐论文 ｜Agent-Editing World Model: Rethinking World Modeling for LLM Agents ｜代理编辑世界模型

作者：Shuang Sun、Guoxin Chen、Fanzhe Meng 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2609.28416)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.28416)

> 长程 LLM 智能体在探索未知环境时，常将未验证假设固化为事实、保留过时计划或误判进度，导致错误在历史中累积并放大。现有语言世界模型试图通过预测工具响应来模拟环境，但高熵、执行依赖的观测难以准确重建，且模拟可能引入虚假证据而不改善智能体的决策。本文提出代理编辑世界模型（Agent-Editing World Model, AEWM），将预测目标从环境观测转向决策效应，通过判断-编辑机制直接修改智能体状态以中断污染传播。该方法在六个基准上平均提升 3.2–6.7 分，但绝对性能仍低于部分专用 SOTA，且其编辑机制是否可能引入新偏差尚未被充分验证。

## 研究背景

当智能体在终端环境中执行代码时，它可能基于对数组布局的错误假设进行计算，即使后续观测已暴露矛盾，该假设仍嵌入在导出代码中并误导后续步骤——这一现象称为任务状态污染（Task-State Contamination）。污染源于智能体从部分观测中维护假设、计划和进度判断时，将未验证前提当作事实接受，或在收到矛盾反馈后仍保留过时计划。这些错误通过局部合理的动作在历史中持续传播，即使环境提供接地反馈也无法自动纠正智能体的理解更新。

长程 LLM 智能体领域的核心矛盾在于：模型需要环境反馈来解决问题，但现有语言世界模型继承自具身 AI 和交互式视频生成的环境中心目标，即预测动作条件下的下一状态或观测（Hafner et al., 2025）。这种观测预测范式在搜索、终端和软件工程等异构环境中面临根本困难：搜索结果依赖动态网页内容和不透明排名，终端输出取决于文件系统状态，测试结果受运行时环境影响。预测这些高熵、执行依赖的观测不仅困难，而且在真实工具提供接地反馈时价值有限，模拟甚至可能引入虚假证据而不改善智能体的解释或后续决策（Zuo et al., 2026; Sun et al., 2026）。本文的切入点在于重新定义世界模型的预测目标：不是重建环境，而是建模智能体的推理和动作如何塑造后续任务进展，并在执行前编辑有问题的决策以中断污染传播。

## 核心方法

### 方法参照系

本文问题置于“长程智能体决策优化”类别下，与 ReAct（Yao et al., 2023）的推理-行动-观察循环共享基础架构。关键差异在于：ReAct 及变体依赖智能体自身生成推理-动作对，缺乏对决策质量的显式评估和事前干预机制；而本文引入外部世界模型在动作执行前判断决策效应并编辑状态，将反馈前置到执行环节而非事后反思。

### 决策效应预测与状态编辑

传统世界模型 $M_{obs}$ 学习观测分布 $M_{obs}(o_t | s_t)$，其中 $s_t = h_t \oplus (\hat{r}_t, \hat{a}_t)$ 为预执行状态。本文的 AEWM 替代目标为预测决策效应标签 $y_t \in \mathcal{Y} = \{\text{critical}, \text{exploratory}, \text{noisy}\}$，并生成编辑后的状态 $e_t$。Action Judge（AJ）从 $s_t$ 预测 $y_t$，区分关闭关键差距的 CRITICAL、降低不确定性的 EXPLORATORY 和提供有限进展的 NOISY 决策。对于 NOISY 判断，State Revision（SR）生成编辑后的推理-动作对 $(e_{r_t}, e_{a_t}) \sim M_{SR}(\cdot | s_t)$，形成编辑状态 $e_t = h_t \oplus (e_{r_t}, e_{a_t})$。

$$
(r_t, a_t) = \begin{cases} (\hat{r}_t, \hat{a}_t), & y_t \in \{\text{critical}, \text{exploratory}\} \\ (e_{r_t}, e_{a_t}), & y_t = \text{noisy} \end{cases}
$$

该公式表明：仅当决策被判断为 NOISY 时，SR 才介入替换当前推理-动作对；否则保留原始提议。编辑不仅改变下一步动作，还修改携带到未来历史的推理，从而中断污染在历史中的传播。设计动机在于解决观测预测范式的根本失效：接地环境反馈本身不保证智能体理解的适当更新，而直接编辑状态能在污染固化前进行干预。

### 跨域训练与轨迹内化

AEWM 通过两阶段训练获得判断和编辑能力：中期训练使用 52B tokens 的跨域语料（Search、Terminal、SWE），结合原始智能体轨迹与合成的 AJ 和 SR 数据；监督微调（SFT）使用 120K 精选样本（60K AJ + 60K SR，每域 40K）激活和校准两种能力。训练后，通过拒绝采样微调（RFT）将 AEWM 引导的轨迹内化到智能体：保留基于真实环境反馈验证的高质量 EditAct 轨迹，在智能体上微调以学习决策模式。

$$
\mathcal{L}_{RFT} = -\sum_{t} \log \pi_\theta(r_t, a_t | h_t) \cdot \mathbb{1}[\text{verified}]
$$

该损失函数仅在验证通过的轨迹上优化智能体策略，其中验证由真实环境反馈和任务完成标准决定。AEWM-RFT 的关键在于：监督覆盖局部状态纠正和后续决策，使智能体学习如何维持任务进展并从污染中恢复，而无需在线 AEWM 指导。

## 实验评估

实验在六个基准（BrowseComp、DeepSearchQA、Terminal-Bench 2.0、Doc2Repo、NL2Repo、SWE-Bench Pro）和三个骨干（Qwen3.5-4B、9B、35B-A3B）上进行，对比 ReAct、Step-level Best@3、Trajectory-level Best@3 三个基线。基线覆盖提示工程和候选选择路线，但缺失 LATS、StateAct 等规划类 SOTA 及 Reflexion 等反思机制的直接对比。

| 骨干 | 方法 | BrowseComp | Terminal-Bench 2.0 | Doc2Repo | 平均 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Qwen3.5-4B | ReAct | 31.5 | 17.6 | 9.5 | 28.5 |
| Qwen3.5-4B | EditAct | 41.2 | 37.1 | 18.2 | 41.8 |
| Qwen3.5-9B | ReAct | 34.1 | 26.6 | 15.5 | 34.5 |
| Qwen3.5-9B | EditAct | 42.3 | 39.3 | 20.3 | 44.1 |
| Qwen3.5-35B-A3B | ReAct | 40.9 | 37.1 | 22.4 | 42.2 |
| Qwen3.5-35B-A3B | EditAct | 48.1 | 48.3 | 25.3 | 48.8 |

EditAct 在所有骨干和基准上均优于 ReAct 和 Best@3，平均提升 6.7、5.2、3.2 分（对应 4B、9B、35B-A3B）。值得注意的是，Qwen3.5-9B 配合 EditAct（44.1）超过 Qwen3.5-35B-A3B 配合 ReAct（42.2），表明 AEWM 可缩小不同规模智能体间的性能差距。

消融实验揭示关键设计决策：相比随机门控，EditAct 在 BrowseComp 上提升 4.0 分（40.9→44.1），证明学习到的干预选择优于随机触发；相比 Agent Resampling 和 AEWM Hint，直接编辑更有效（48.1 vs 44.1/45.8），支持状态替换优于重采样或批评式指导；仅编辑推理或仅编辑动作均低于完整 EditAct（47.4/47.3 vs 48.1），验证联合推理-动作编辑的必要性。训练消融显示，中期训练+SFT 相比仅 SFT 在 Terminal-Bench 2.0 上提升 6.4 分（41.9→48.3），表明广泛交互知识与针对性监督的互补性。

评估边界存在局限：所有基准使用相同智能体、任务和设置，但缺乏计算效率维度（Token 消耗、延迟）的报告；Action Judge 基准仅 3,000 个决策样本，且 Search 域故意使用 1:1:3 的类别混合，可能影响泛化性评估；代码和超参数虽提供，但 52B tokens 的中期训练成本限制了可复现性。

## 关联研究分析

从问题动机看，本文与 Reflexion（Shinn et al., 2023）共享“从失败中学习”的目标，但机制根本不同：Reflexion 在任务失败后生成语言反馈，属于事后反思；AEWM 在动作执行前判断决策效应并编辑状态，属于事前干预。这一差异源于对污染传播时机的理解：Reflexion 假设错误在任务完成后才能识别，而本文发现污染在历史中逐步累积，需在早期步骤中断。然而，Reflexion 的低成本（无需额外模型）与 AEWM 的高训练成本（52B tokens）形成权衡，论文未讨论在计算受限场景下哪种机制更优。

从方法设计看，本文与 LATS（Zhou et al., 2023）都解决探索不足问题，但路径不同：LATS 通过树搜索显式探索多个分支，AEWM 通过 AJ 判断分支价值并选择性编辑。LATS 的计算复杂度随分支数指数增长，而 AEWM 的开销仅为单次 AJ 判断和可能的 SR 生成。但 LATS 的显式树结构提供可解释的探索路径，而 AEWM 的编辑决策是黑盒的，这是否影响调试和安全性验证，论文未给出回答。

## 总结

本文要解决的核心矛盾是：长程智能体需要环境反馈来解决问题，但观测预测范式难以准确重建高熵、执行依赖的工具响应，且模拟可能引入虚假证据。本文抓住的切入点是：污染源于智能体状态的错误更新，而非环境反馈的缺失，因此世界模型应预测决策效应并编辑状态，而非重建观测。AEWM 通过 AJ 判断和 SR 编辑实现这一目标，在六个基准上平均提升 3.2–6.7 分，AEWM-RFT 进一步证明编辑轨迹可提供可迁移监督。本文的边界在于：绝对性能仍低于部分专用 SOTA（如 BrowseComp 上 Flash-Searcher 的 67.7%），且编辑机制可能引入新偏差——当 SR 生成的推理-动作对本身包含错误时，污染是否会被转移而非消除？论文未提供对此的定量分析。
