# HuggingFace最新推荐论文 ｜TANGO: Humanoid Navigation in Cluttered Environments with a Whole-Body Vision-Language-Action Model ｜全身视觉-语言导航

研究机构：美国加州大学伯克利分校、北京大学

论文原文见 [arXiv](https://arxiv.org/abs/2609.09158)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.09158)

> 人形机器人在杂乱室内环境中的导航面临高维动作空间与低层物理约束的耦合难题，传统二维路点规划无法显式表达全身避障可行性。现有视觉-语言导航方法忽略具身几何差异，而强化学习遍历方法缺乏长程语义泛化能力。本文提出 TANGO，通过合成碰撞自由全身轨迹训练统一视觉-语言-动作模型，直接预测 29 自由度关节动作。该框架实现了零样本仿真到真实迁移，但在长程规划效率与动态环境适应性上仍存局限。

## 研究背景

当人形机器人进入杂乱室内空间时，导航可行性不再仅取决于路径几何，更取决于手臂、躯干与腿部能否在受限空间中协调运动。这种高维构型约束使得传统将导航简化为二维平面路径规划的方法失效，因为看似有效的 2D 轨迹在物理执行中可能因碰撞而不可行。解决这一矛盾需要建立语言指令、视觉感知与全身动力学之间的直接映射，即全身视觉-语言导航。

主流视觉-语言导航方法通常预测离散动作或 2D 路点，依赖下游控制器执行，导致高层决策与低层可行性解耦，无法在规划阶段显式推理避障需求。近期人形基础模型虽具备全身控制能力，但导航仍被简化为高层运动命令，缺乏对复杂场景几何的显式推理。TANGO 的切入点在于打破这种解耦，通过端到端生成关节空间动作，将避障逻辑内化于导航决策中，从而在杂乱环境中实现物理可行的语言引导遍历。

## 核心方法

### 方法参照系

TANGO 属于导航基础模型路线，但将动作空间从 2D 路点扩展至 29 自由度关节空间。与标准 VLA 流程不同，其核心差异在于动作专家直接输出连续关节角与基座旋转，而非离散指令，且训练数据需包含物理可行的全身避障行为。

### 数据合成管线

传统导航数据集缺乏杂乱场景下的全身避障样本，导致模型无法学习碰撞自由遍历。TANGO 引入 Plan-Edit-Track (PET) 管线，通过 A* 规划、运动编辑与强化学习追踪合成数据。设计动机在于解决真实数据获取成本高且缺乏物理一致性的问题。管线首先利用 A* 生成避障路径，随后通过 SoftMimic 伪力编辑运动以融入避障行为，最后用 SONIC 追踪器验证可行性。关键公式为运动编辑中的伪力引导：

$$ F_{pseudo} = \sum_{i} k_i (q_{target} - q_{current}) $$

该公式通过采样势场力引导关键连杆避开障碍物，确保生成的轨迹包含侧步、下蹲等全身避障动作，最终合成 64,633 条碰撞自由轨迹。

### 分层 VLA 架构

为解决 VLM 推理延迟与高频控制需求的矛盾，TANGO 采用三层架构：System-2 负责语义感知，System-1 生成动作块，System-0 执行高频追踪。设计动机在于平衡推理深度与实时性，避免端到端模型在长时程任务中的延迟累积。System-2 使用 Qwen2.5VL-7B 处理视觉与语言输入，System-1 采用 Flow Matching 生成 29 自由度动作块。关键公式为联合训练目标：

$$ \mathcal{L} = \mathcal{L}_{CE} + w_{FM} \cdot \mathcal{L}_{FM} $$

其中 $\mathcal{L}_{CE}$ 为视频问答交叉熵损失，$\mathcal{L}_{FM}$ 为 Flow Matching 损失，权重 $w_{FM}=20$。该设计通过联合训练保留通用世界知识，同时优化导航动作生成，配合 Real-Time Chunking (RTC) 实现流式执行。

## 实验评估

实验在 VLNVerse 基准上进行，对比 CMA、RDP、InternVLA-N1 等基线。基线覆盖离散动作、连续动作及 VLA 模型，但缺乏基于显式 3D 地图的方法。TANGO 是唯一配备低层物理控制的方法，其他基线在传送设置下评估。

| 方法 | 低层控制 | Val Unseen SR (%) | Val Unseen SPL (%) | Val Unseen CR (%) |
| :--- | :--- | :--- | :--- | :--- |
| InternVLA-N1 | ✗ | 45.56 | 34.98 | - |
| Uni-NaVid | ✗ | 45.00 | 39.42 | - |
| TANGO | ✓ | 52.89 | 40.18 | 9.90 |

TANGO 在 SR 和 SPL 上均领先，且 CR 显著低于模块化基线。消融实验显示，移除 RTC 导致 SR 从 43.75% 降至 10.94%，表明动作块连续性对执行稳定性至关重要。移除运动编辑使 CR 升至 20.60%，验证了避障监督对碰撞避免的贡献。

| 配置 | SR (%) | SPL (%) | CR (%) |
| :--- | :--- | :--- | :--- |
| w/o RTC | 10.94 | 10.94 | 14.60 |
| w/o Motion Editing | 36.25 | 30.36 | 20.60 |
| TANGO | 43.75 | 31.83 | 9.90 |

评估边界方面，VLNVerse 基准未覆盖动态障碍物场景，且 CR 指标仅统计至少一次碰撞的 episode 比例，未量化碰撞严重程度。代码与数据管线将开源，但真实世界实验仅包含 15 次试验，样本量较小，统计显著性有限。

## 关联研究分析

从问题动机看，TANGO 与 HumanoidPF 形成鲜明对比。HumanoidPF 依赖强化学习解决特定场景的碰撞避免，但缺乏长程语言引导能力；TANGO 则通过 VLM 实现语义泛化，但牺牲了部分规划效率。这一差异源于任务特性：HumanoidPF 聚焦短程避障，而 TANGO 需处理长程导航与避障的耦合。TANGO 在杂乱场景中 CR 低于 HumanoidPF 追踪基线，表明端到端全身动作生成在安全性上优于模块化组合，但 SPL 略低，暗示保守策略可能影响效率。

从方法设计看，TANGO 与 InternVLA-N1 共享 VLM 骨干，但动作空间不同。InternVLA-N1 输出 2D 路点，依赖下游控制器，导致物理可行性与导航决策解耦；TANGO 直接输出关节动作，将避障逻辑内化。这一设计使 TANGO 在物理执行下性能下降较小，而 InternVLA-N1 从传送设置到物理执行时 SR 大幅下降。根源在于 2D 路点无法显式表达全身构型约束，而 29 自由度动作空间能直接编码避障需求。

## 总结

TANGO 解决了人形机器人在杂乱环境中导航决策与全身可行性解耦的矛盾，通过合成碰撞自由轨迹训练统一 VLA 模型，直接预测 29 自由度关节动作。实验表明其在 VLNVerse 基准上 SR 达 52.89%，CR 降至 9.90%，优于模块化基线。然而，其保守策略导致 SPL 略低，且评估未覆盖动态环境。当障碍物密度进一步增加或环境动态变化时，Flow Matching 动作专家能否保持实时性与避障鲁棒性，论文未给出回答。
