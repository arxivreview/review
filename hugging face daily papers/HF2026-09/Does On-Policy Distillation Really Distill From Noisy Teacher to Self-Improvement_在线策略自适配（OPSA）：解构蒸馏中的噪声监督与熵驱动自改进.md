# HuggingFace最新推荐论文 ｜Does On-Policy Distillation Really Distill? From Noisy Teacher to Self-Improvement ｜在线策略自适配（OPSA）：解构蒸馏中的噪声监督与熵驱动自改进

研究机构：美国普渡大学、Hugging Face

论文原文见 [arXiv](https://arxiv.org/abs/2608.31046)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.31046)

> 在线策略蒸馏（On-Policy Distillation, OPD）旨在通过教师模型在 student 采样轨迹上提供密集 token 级监督，以解决强化学习中奖励稀疏导致的长程推理训练不稳定问题。然而，现有范式隐含假设教师对 off-policy 轨迹的评分是可靠且必要的，这一假设在教师规模扩大时面临严峻挑战。本文通过量化分析发现教师监督存在大量噪声，且学生性能提升主要源于对低概率 token 的抑制而非知识迁移，进而提出无需外部监督的熵自适应负优势机制。该工作颠覆了“蒸馏即对齐”的传统认知，但其在高熵探索与分布锐化间的平衡机制仍需更广泛的验证。

## 研究背景

当大型推理模型（Large Reasoning Models, LRMs）通过长思维链（Long-CoT）提升准确率时，其高昂的推理成本与小型学生模型的部署需求形成结构性张力。传统离线蒸馏因训练与推理分布不匹配导致逻辑漂移，促使领域转向在线策略蒸馏（OPD）。OPD 利用反向 KL 散度在学生自身采样的轨迹上计算教师分布，提供密集的 token 级优势信号，从而缓解暴露偏差（Exposure Bias）。然而，OPD 要求教师与学生共享词表并访问教师 logits，且教师需对并非由其生成的学生前缀进行评分，这种 off-policy 评分的可靠性存疑。

主流 OPD 变体如 GKD 和 MiniLLM 聚焦于优化散度类型或采样策略，但均默认教师信号是有效的学习源。随着教师模型规模从 4B 扩展至 235B，学生轨迹相对于教师分布的偏离程度加剧，导致教师对学生生成的错误答案赋予正优势、对正确答案赋予负优势的比例显著上升。这种噪声监督不仅增加了计算开销，更引发了对 OPD 增益来源的根本质疑：学生性能的提升究竟源于教师行为匹配，还是其他机制？本文切入点在于解构 OPD 中的监督信号，通过控制变量实验剥离教师贡献，揭示低概率 token 抑制在策略优化中的核心作用，并据此构建无教师依赖的自适配训练框架。

## 核心方法

### 方法参照系

OPD 的标准流程基于反向 KL 散度优化，其损失函数定义为：

$$ L_{OPD} = -E_{y \sim \pi_s} \sum_{i=1}^{|y|} \frac{1}{|y|} A_i \log \pi_s(y_i | x; y_{<i}) $$

其中 $A_i = \log \pi_t(y_i | x; y_{<i})$ 为教师提供的 token 级优势。该范式假设教师分布 $\pi_t$ 是可靠的目标，通过最小化学生分布 $\pi_s$ 与 $\pi_t$ 的差异实现知识迁移。本文的关键差异在于质疑 $A_i$ 的有效性，并探索在无 $\pi_t$ 条件下如何构造有效的负优势信号。

### 噪声监督的量化与解耦

设计动机在于验证教师监督的可靠性及其对性能的实际贡献。本文定义“噪声信号”为教师优势符号与可验证奖励符号不一致的 token（即错误答案获正优势或正确答案获负优势）。实验显示，4B 教师的噪声率为 30.6%，而 235B 教师高达 50.6%，且大教师倾向于对所有答案 token 赋予负优势。通过控制实验，仅使用噪声轨迹训练、仅使用干净轨迹训练与标准 OPD 训练，三者收敛性能相当。这表明学生策略对教师噪声不敏感，OPD 的增益并非来自教师行为匹配。进一步分析发现，高 logp token 的梯度贡献可忽略，性能提升主要源于低 logp token 的负优势抑制。固定负优势 $A_i = -0.5$ 即可复现 OPD 的大部分增益，证明教师信号并非必要。

### 熵自适应负优势机制

设计动机在于解决固定负优势忽略 token 级差异的问题，特别是区分“不确定”与“自信但错误”的低概率 token。本文提出 On-Policy Self-Adaptation (OPSA)，仅对 logp 最低的 20% token 分配熵自适应负优势：

$$ A_i^{dyn} = A_i^{fix} - \frac{1}{4} \delta \cdot r_i, \quad r_i = 2 \frac{H_i - H_{min}}{H_{max} - H_{min}} - 1 $$

其中 $H_i$ 为 token 熵，$r_i \in [-1, 1]$ 归一化熵值，$\delta=1$ 表示高熵位置获得更大幅度的负优势。该机制通过抑制尾部 token 概率并将质量重新分配至头部 token，在低熵位置锐化分布以稳定输出，同时在高熵分支点保留多样性以支持探索。相比固定负优势，熵自适应机制在 AIME24 上 Avg@4 达到 50.0%，显著优于标准 OPD 的 35.13%，且训练过程梯度范数更稳定，避免了正优势导致的策略崩溃。

## 实验评估

实验基于 Qwen3-1.7B/4B 和 Qwen3.5-9B 模型，在 DAPO-17k 数据集上训练，评估 AIME24/25、HMMT25（域内数学）及 MBPP+、GPQA-Diamond（域外代码与问答）。基线覆盖 GRPO、TTRL、OPD 和 OPSD，但缺失 Prune-OPD、SG-OPD 等最新 OPD 变体，限制了与当前 SOTA 的直接对比。

| 模型 | 基准 | 基线 Avg@32 | OPSA Avg@32 | 相对提升 |
|---|---|---|---|---|
| Qwen3-1.7B | AIME24 | 13.44 | 48.85 | ↑263.5% |
| Qwen3-1.7B | AIME25 | 9.69 | 35.31 | ↑264.4% |
| Qwen3-1.7B | HMMT25 | 5.73 | 23.33 | ↑307.2% |
| Qwen3.5-9B | AIME24 | 76.35 | 87.81 | ↑15.0% |

OPSA 在 Qwen3-1.7B 上实现 Avg@32 263%-307% 的相对提升，Pass@32 翻倍以上，显著优于 OPD（AIME24 Avg@32 32.08）和 GRPO（33.96）。在 Qwen3.5-9B 上，尽管基线性能已较高，OPSA 仍带来 11.46 点（AIME24）和 22.92 点（HMMT25）的绝对提升，表明该方法在强基线上仍有边际收益，但增益幅度随模型规模增大而递减。

消融实验证实，仅训练低 logp 20% token 即可复现全 token OPD 性能，验证了高 logp token 的无效性。熵自适应机制（$\delta=1$）优于固定负优势（$\delta=0$）和反向熵（$\delta=-1$），后者在训练 350-450 步间出现不稳定，梯度范数持续偏高。这证实高熵位置需要更强负信号以维持探索多样性，而低熵位置需锐化分布以稳定输出。

评估边界方面，实验仅在非思考模式下进行，未验证思考模式下的泛化性；基线缺失最新 OPD 变体，无法确认 OPSA 是否优于当前 SOTA；代码基于 slime 框架，8 张 H100/H200 GPU 训练，超参数未完全公开，可复现性依赖框架版本。

## 关联研究分析

从问题动机看，本文与 GKD（Agarwal et al., 2024）和 MiniLLM（Gu et al., 2024）形成根本对立。后者假设教师分布是可靠目标，通过优化散度或采样策略提升对齐效率；本文则证明教师信号在 off-policy 场景下高度噪声，且学生性能提升源于低概率 token 抑制而非分布匹配。这一差异的根源在于任务特性：长程推理中教师与学生分布差距随规模扩大而加剧，导致教师评分失效，而短程任务中分布差距较小，教师信号可能仍有效。本文未探索在教师-学生分布差距较小的场景下，OPSA 是否仍优于标准 OPD。

从方法设计看，OPSA 与 TTRL（Zuo et al., 2026）同属无外部监督路线，但机制不同。TTRL 基于自一致性进行测试时训练，倾向于锐化策略分布至局部最优，导致 Pass@k 显著下降；OPSA 通过熵自适应负优势在抑制尾部 token 的同时保留高熵分支多样性，从而在提升 Avg@32 的同时维持 Pass@32 增长。这一差异源于探索-利用平衡：TTRL 过度利用导致多样性丧失，而 OPSA 的熵调节机制在锐化与探索间取得平衡。本文未验证在需要高度多样性的开放域任务中，OPSA 的多样性保留机制是否足以避免局部最优陷阱。

## 总结

本文核心矛盾在于 OPD 范式对教师可靠性的隐含假设与 off-policy 评分噪声现实之间的冲突。切入点在于通过量化噪声率与控制实验，解耦教师贡献与 token 抑制效应，揭示低概率 token 负优势是性能提升的主因。方法上，OPSA 以熵自适应负优势替代教师信号，在无需外部监督下实现分布锐化与探索保留的平衡。实验证明其在 Qwen3-1.7B 上 AIME24 Avg@32 提升 263.5%，且优于 OPD 16.77 点。边界在于增益随模型规模增大而递减，且仅在非思考模式下验证，未覆盖最新 OPD 变体对比。当模型规模进一步扩大至 100B+ 时，熵自适应机制是否仍能维持探索多样性，避免分布过度锐化导致的泛化能力下降，论文未给出回答。
