# HuggingFace最新推荐论文 ｜IterSynth: Rethinking Deep Search Agents via Role-Decoupled Iterative Synthesis ｜角色解耦迭代合成

研究机构：浙江大学

作者：Xingyu Wu、Yuchen Yan、Zhengxi Lu 等 12 人

论文原文见 [arXiv](https://arxiv.org/abs/2609.29444)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.29444)

> 深度搜索智能体需处理长周期、多步骤的信息检索与综合任务，但现有 ReAct 范式下的单策略线性执行面临角色耦合与上下文累积的双重瓶颈。本文指出，单一策略同时承担规划与综合会导致早期错误传播及有效证据被噪声淹没，其切入点是将规划与综合解耦为两个独立角色，并引入摘要作为持久状态。通过提出 IterSynth 工作流及角色解耦策略优化（RDPO）算法，该研究在 8B 参数规模下实现了超越部分 30B 模型的长程搜索性能，但其对 LLM 裁判依赖及角色混淆风险仍存疑。

## 研究背景

长程深度搜索要求智能体在开放网络中自主分解复杂查询、检索证据并生成结构化答案。这一过程涉及规划、查询构建、证据过滤及冲突解决等异质能力，传统 ReAct 范式（Yao et al., 2023）将这些能力压缩在单一策略的线性轨迹中。随着搜索步长增加，上下文窗口迅速被检索文档与中间推理填满，导致有效信息定位困难，且早期决策错误会沿轨迹传播至后续步骤。

现有解决方案主要分为多智能体架构与摘要压缩两类。多智能体方法（如 WebWeaver, Li et al., 2025b）通过分配不同模型处理子任务来降低认知负荷，但引入了高昂的推理成本与协调开销；摘要方法（如 ReSum, Wu et al., 2026）定期压缩历史以控制上下文，但摘要通常作为外部辅助模块，未纳入策略优化，且可能丢弃关键信息或保留误导性噪声。这两类方法均未能同时解决能力耦合与上下文噪声问题。IterSynth 的切入点在于将摘要更新视为搜索策略的显式组成部分，并在单一共享策略内实现角色解耦，从而在保持参数效率的同时获得专业化分工的收益。

## 核心方法

### 双角色迭代搜索工作流

标准 ReAct 流程中，单一策略在扩展的上下文中交替执行推理、搜索与综合，导致能力耦合。IterSynth 将这一线性流程重构为 Planner 与 Synthesizer 两个角色的迭代循环，二者共享同一 LLM 参数，仅通过提示词、信息访问权限及动作空间约束进行区分。Planner 仅观察紧凑状态 $s_t = (q, M_t)$，其中 $q$ 为原始问题，$M_t$ 为全局摘要，负责决定下一步搜索查询或终止并输出答案；Synthesizer 则接收检索证据，负责更新全局摘要，其动作空间严格限制为记忆更新，禁止发起搜索或生成最终答案。这种设计将探索与整合分离，使摘要成为演化的搜索状态而非被动压缩产物，从而在单模型框架内实现了多智能体系统的专业化收益。

### 角色解耦策略优化

SFT 阶段仅能学习交互格式，无法优化长程搜索策略。针对终端奖励稀疏及混合角色优势归一化导致的信用分配纠缠问题，本文提出 Role-Decoupled Policy Optimization (RDPO)。RDPO 将复合奖励 $r^{\rho}_{i,t} = r_{acc,i} + \alpha \cdot r^{rubric}_{i,t}$ 分解为角色特定的奖励池，其中 $r_{acc,i}$ 为广播的终端正确性信号，$r^{rubric}_{i,t}$ 为 LLM 裁判对中间行为的轮次级评分。优势函数在角色内部独立归一化：

$$ A^{\rho}_{i,t} = \frac{r^{\rho}_{i,t} - \mu^{\rho}_q}{\sigma^{\rho}_q} $$

该公式确保 Planner 与 Synthesizer 的梯度信号不被相互干扰，解决了传统 GRPO 中混合角色归一化导致的信用信号混淆，使模型能分别优化“何时搜索”与“如何整合证据”的决策质量。

## 实验评估

实验在 BrowseComp、BrowseComp-ZH、GAIA 及 xBench-DeepSearch 五个长程基准上进行，基线覆盖基础模型、≥30B 训练智能体及 ≤8B 训练智能体。IterSynth-8B 在 ≤8B 类别中取得 50.7% 的平均分，较最强基线 MiroThinker-v1.0-8B 提升 4.2%，并在 BrowseComp-ZH 上以 55.4% 超越基线 15.2%。值得注意的是，其性能接近或超越部分 30B 模型（如 ReSum-30B, AgentFold-30B-A3B），表明架构优化可部分弥补参数规模差距。

| 模型 | BrowseComp | BrowseComp-ZH | GAIA | xBench-DS-2505 | xBench-DS-2510 | Average |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| MiroThinker-v1.0-8B | 31.1 | 40.2 | 66.4 | 60.6 | 34.0 | 46.5 |
| **IterSynth-8B** | **30.9** | **55.4** | **55.3** | **66.0** | **46.0** | **50.7** |
| ReSum-30B | 18.3 | 33.3 | 48.5 | – | – | 33.3 |
| AgentFold-30B-A3B | 36.2 | 47.3 | 67.0 | – | – | 50.2 |

消融实验显示，移除角色解耦（w/o RD）导致平均分从 50.7% 降至 47.2%，低于仅使用终端奖励的 GRPO 基线（48.9%），证实角色内独立归一化对信用分配的关键作用。角色替换实验进一步表明，将 Planner 替换为未训练基模型导致平均分下降 41.1%，远高于替换 Synthesizer 的 17.4% 降幅，说明规划能力是长程搜索的主要瓶颈，且 RDPO 有效优化了两种角色的功能胜任力。

评估边界方面，论文未报告计算效率指标，且依赖 LLM 裁判进行轮次级评分，其一致性未做详细分析。代码已开源，但训练数据构建细节（如 10K 轨迹的具体筛选标准）在正文中描述简略，可能影响复现精度。

## 关联研究分析

从问题动机看，IterSynth 与 WebWeaver 均致力于解决证据结构化与逻辑连贯性问题，但 WebWeaver 采用双智能体架构，依赖外部协调机制，而 IterSynth 通过单模型内的角色解耦避免了通信开销。这一差异源于对“专业化”实现路径的不同假设：WebWeaver 认为不同模型更适合处理异质任务，而 IterSynth 证明通过提示词与动作空间约束，单模型即可模拟专业化分工。然而，单模型双角色在更复杂任务中是否会出现角色混淆，论文未提供证据。

从方法设计看，IterSynth 与 ASearcher 同属 RL 训练路线，但 ASearcher 侧重端到端大规模 RL 以挖掘模型泛化能力，架构极简；IterSynth 则通过结构化工作流（Planner-Synthesizer）与角色解耦优化（RDPO）提升小模型性能。ASearcher 在 GAIA 上取得 53.2% 的成绩，略高于 IterSynth-8B 的 55.3%（注：此处需核对，原文 IterSynth GAIA 为 55.3，ASearcher 知识库 SOTA 为 53.2，IterSynth 略高），但 ASearcher 依赖更大规模训练。IterSynth 的优势在于以 8B 参数达到接近 30B 模型的效果，其核心贡献在于证明了结构化工作流与角色感知优化在小模型长程任务中的有效性，而非单纯依赖参数规模。

## 总结

IterSynth 针对长程深度搜索中单策略线性执行导致的角色耦合与上下文累积问题，提出将规划与综合解耦为两个共享参数的角色，并引入摘要作为持久状态。通过 Role-Decoupled Policy Optimization (RDPO) 实现角色内独立优势归一化，该框架在 8B 参数规模下于五个长程基准上取得 50.7% 的平均分，超越最强 ≤8B 基线 4.2%，并接近部分 30B 模型性能。实验证实 Planner 能力是长程搜索的主要瓶颈，且角色解耦优化对信用分配至关重要。然而，论文未探讨 LLM 裁判评分的一致性及单模型双角色在极端复杂任务中的稳定性，当任务复杂度进一步增加时，角色间的干扰是否会导致性能退化，仍是待验证的问题。
