> 科学假设生成长期受困于模型自评估的不可靠性与单轮生成的同质化，导致产出的假设缺乏生物合理性且难以迭代优化。现有方法多依赖静态检索或简单的多轮辩论，未能将“协作机制”本身作为可控变量来系统性地影响假设质量。HypoEvolve 将多智能体协作显式化为一个代际遗传搜索过程，通过种群竞争与语义变异，使假设在外部生物证据的约束下持续进化。该框架在药物重定位任务上显著优于基线，但其评估仍局限于特定癌症类型，且未验证其在非结构化复杂系统中的泛化能力。

## 研究背景

当大语言模型（LLM）试图从文献中生成科学假设时，它面临的核心困境是缺乏对假设生物合理性的即时反馈。模型生成的假设往往基于模式匹配而非机制推导，导致其提出的药物-疾病关联在真实生物学中可能完全无效。为了解决这一“幻觉”问题，研究者引入了检索增强生成（RAG）和外部数据库验证，但这通常仅作为初始化或最终评估手段，未能介入假设的生成与迭代过程。

在科学假设发现领域，主流路线分为两类：一是基于文献接地的单轮或迭代生成，如 SciMON 和 ResearchAgent，它们依赖检索质量但缺乏对假设间关系的利用；二是基于进化搜索的方法，如 FunSearch 和 AlphaEvolve，它们将 LLM 作为变异算子，但主要应用于代码或数学公式等可形式化空间，难以处理自然语言假设的语义复杂性。Co-Scientist 等系统尝试结合多智能体与锦标赛排名，但其扩展池机制使得协作设计难以作为独立变量进行控制。本文的切入点在于，将多智能体的协作过程解耦为“科学角色”与“搜索规则”，通过固定种群大小的代际遗传算法，使协作机制成为可实验、可优化的核心变量，从而直接考察协作设计对假设质量的因果影响。

## 核心方法

### 方法参照系

本文问题归属于“科学假设与创意生成”路线，但区别于传统的单轮生成或简单的多轮辩论。标准流程通常由 LLM 生成假设，经检索或简单评分后输出，缺乏对假设种群动态演化的建模。本文的关键差异在于，将假设视为种群个体，引入遗传算法的交叉、变异与选择机制，使假设在代际竞争中通过语义重组与修正实现进化，而非静态的独立生成。

### 基于 Bradley-Terry 模型的种群级适应度计算

在传统的多智能体系统中，假设的评估往往依赖单一 LLM 的绝对评分或简单的多数投票，这导致评估信号缺乏相对可比性，且难以捕捉假设间的细微优劣。本文引入 Bradley-Terry 模型，将成对比较结果转化为潜变量强度，从而构建一个统一的适应度尺度。

$$
P(h_i \succ h_j) = \frac{\pi_{t,h_i}}{\pi_{t,h_i} + \pi_{t,h_j}}, \quad f_t(h) = a \log \pi_{t,h} + b_t
$$

该公式的物理含义是：通过拟合所有假设两两比较的胜率，推断出每个假设的潜在强度 $\pi_{t,h}$，并通过对数变换和锚定偏移 $b_t$ 将其映射为可比的适应度分数 $f_t(h)$。这一设计解决了此前方法中评估标准不一致、无法跨代比较的问题，使得种群内的竞争具有数学上的严谨性，为后续的精英保留提供了可靠的排序依据。

### 语义交叉与变异驱动的代际进化

在适应度确定后，传统的进化算法通常对二进制串或代码进行位级操作，这在自然语言假设中会导致语义断裂。本文将交叉与变异重新定义为对科学声明（Claims）和理由（Rationales）的语义推理操作。

$$
Q_t = P_{t-1} \cup O_t, \quad f_t = \text{Score}(Q_t), \quad P_t = \text{Top}_\mu(Q_t; f_t)
$$

该公式描述了联合替换机制：将上一代种群 $P_{t-1}$ 与新一代后代 $O_t$ 合并为候选池 $Q_t$，重新计算适应度后，仅保留前 $\mu$ 个最优个体。交叉操作（概率 $p_c=0.6$）通过整合两个父代假设的兼容机制或证据，生成新的解释；变异操作（概率 $p_m=0.15$）则通过药物替换或“跳出盒子”重新审视假设前提。这一设计解决了此前方法中变异操作缺乏科学语义约束、容易生成无意义文本的问题，确保了新假设在保持科学连贯性的同时探索新的机制空间。

## 实验评估

实验在 34 种癌症类型上进行，使用 DepMap 选择性和 Open Targets 关联度作为外部生物证据指标。基线覆盖了单轮生成、自一致性、静态重排、多智能体辩论、Co-Scientist 和 Tree of Thoughts，但未包含纯符号回归方法（如 FunSearch），这可能限制了与形式化搜索路线的直接对比。

| 方法 | DepMap Selectivity | Open Targets Association |
| :--- | :--- | :--- |
| HypoEvolve | 0.171 | 0.426 |
| Tree of Thoughts | 0.115 | 0.329 |
| Single-pass Generation | 0.039 | 0.163 |
| Co-scientist Scaffold | 0.042 | 0.193 |
| Multi-agent Debate | 0.070 | 0.162 |

HypoEvolve 在两项指标上均取得最高分，其中 DepMap 选择性比最强基线 Tree of Thoughts 高出 0.056，Open Targets 关联度高出 0.097。这一优势在留出癌症类型上依然保持，表明模型未过拟合于训练协议中的特定癌症上下文。

消融实验显示，适应度引导的亲本选择显著提升了种群的平均和最低分数。在 94 次运行中，87 个最终假设是通过交叉或变异生成的，而非直接继承，证明了进化操作对假设质量的实质性贡献。然而，DepMap 选择性的绝对值仅为 0.171，远低于 Open Targets 的 0.426，这可能反映了 CRISPR 筛选数据在特定癌症类型中的稀疏性或指标本身的局限性。

评估边界方面，论文未报告计算成本与推理延迟，仅提及使用 gpt-5.4-mini 和 Tavily 检索。代码未公开，且实验局限于药物重定位任务，未验证其在材料科学或生物医学其他子领域的泛化能力。此外，外部证据仅用于最终评估，未参与搜索过程中的适应度计算，这可能导致搜索方向与真实生物证据存在偏差。

## 关联研究分析

从问题动机看，HypoEvolve 与 Co-Scientist 的核心差异在于种群管理策略。Co-Scientist 采用扩展池和 Elo 排名，允许假设数量无限增长，这使得协作设计难以作为独立变量进行控制；而 HypoEvolve 采用固定种群大小和代际替换，强制假设在有限资源下竞争，从而将“协作机制”本身转化为可实验的变量。这一设计选择源于对“如何隔离协作贡献”的明确需求，而非单纯追求假设数量的最大化。

从方法设计看，HypoEvolve 与 FunSearch 在进化搜索的应用空间上存在根本差异。FunSearch 将 LLM 作为代码变异算子，搜索空间是形式化的程序结构，评估基于执行结果；而 HypoEvolve 将 LLM 作为语义推理算子，搜索空间是自然语言假设，评估基于成对比较的适应度。这种差异源于任务特性：科学假设的语义复杂性使得位级变异不可行，必须依赖 LLM 进行语义层面的重组与修正。然而，这也意味着 HypoEvolve 的搜索效率受限于 LLM 的推理能力，且缺乏 FunSearch 中基于执行结果的硬约束，可能导致生成假设在逻辑上自洽但生物学上无效。

## 总结

HypoEvolve 旨在解决科学假设生成中协作机制不可控与外部证据脱节的核心矛盾。通过引入代际遗传算法，它将多智能体协作显式化为种群更新规则，使得协作设计成为可实验的变量，从而在药物重定位任务上实现了假设质量的显著提升。实验表明，HypoEvolve 在 DepMap 选择性上达到 0.171，在 Open Targets 关联度上达到 0.426，均优于最强基线 Tree of Thoughts。然而，其评估局限于特定癌症类型，且外部证据未参与搜索过程，可能导致搜索方向与真实生物证据存在偏差。当假设数量增加或癌症类型扩展时，固定种群大小的竞争机制是否会导致多样性过早收敛，论文未给出回答。
