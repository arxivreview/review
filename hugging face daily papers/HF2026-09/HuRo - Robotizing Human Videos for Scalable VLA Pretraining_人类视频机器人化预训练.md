# HuggingFace最新推荐论文 ｜HuRo: Robotizing Human Videos for Scalable VLA Pretraining ｜人类视频机器人化预训练

研究机构：韩国延世大学

论文原文见 [arXiv](https://arxiv.org/abs/2609.10706)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.10706)

> 视觉-语言-动作模型（Vision-Language-Action, VLA）的规模化预训练长期受限于真实机器人轨迹采集的高昂成本与场景覆盖局限。现有利用人类视频的方法要么仅做视觉转换而缺乏动作监督，要么仅做动作重定向而保留人类视角，导致观察与动作的具身对齐无法在大规模异构数据上联合实现。本文提出 HuRo 流水线，通过视觉机器人化与运动重定向将人类视频转化为机器人对齐的观测-动作对，构建了包含 630K 集成的预训练数据集。该工作验证了联合对齐预训练在真实世界操作任务中的规模化有效性，但其渲染保真度与物理接触缺失限制了在接触丰富任务中的直接适用性。

## 研究背景

VLA 策略的性能上限取决于预训练数据的规模与多样性，而真实机器人数据的稀缺构成了这一范式的核心瓶颈。人类视频在物体、场景与操作行为上具有远超机器人数据的多样性，但直接用于机器人学习面临具身差距：人类手部的视觉形态与运动学结构与目标机器人存在本质差异。弥合这一差距需要同时解决观察空间（视觉形态）与动作空间（运动轨迹）的对齐问题，即具身对齐（Embodiment Alignment）。

早期工作如 H2R 与 Masquerade 分别通过渲染机器人替换人类手部或预测末端执行器轨迹，仅解决了观察或动作单侧的对齐，且局限于任务匹配的小规模设置。近期 VITRA 与 EgoScale 实现了大规模动作重定向，但保留了人类中心视角的观测，导致视觉特征与机器人本体感知存在系统性偏差。这种观察与动作的分离处理，使得模型在分布外（Out-of-Distribution, OOD）场景下的鲁棒性提升受限。HuRo 的切入点在于，首次将视觉机器人化与动作重定向耦合为统一的流水线，在保持异构人类视频多样性的同时，生成观察与动作均对齐至目标机器人的预训练数据，从而探索联合对齐对 VLA 预训练规模化效应的贡献。

## 核心方法

### 方法参照系

本文问题属于“数据增强与预训练”路线，其通用流程为：从源数据提取语义与运动信息，转换为目标机器人格式，用于策略预训练。与仅做视觉编码预训练（如 H2R）或仅做动作监督（如 VITRA）的通用流程不同，HuRo 的关键差异在于同时执行视觉转换与动作重定向，并引入 VLM 自动标注以处理异构数据源的标注缺失问题。

### 联合观察-动作机器人化流水线

该流水线在数据预处理阶段介入，解决了异构人类视频标注层级不一导致无法直接用于 VLA 训练的问题。对于每个第一人称视频片段，流水线首先估计相机内参、手部姿态与相机轨迹，利用 Qwen3.5 生成指令并验证一致性。动作转换阶段通过 PyRoKi 将人类手部运动重定向为机器人关节轨迹，其核心优化目标为：

$$ \min_{q_t, \xi_i} \sum_t \left( \| \mathbf{p}^{hand}_t - \mathbf{p}^{robot}_t(q_t) \|^2 + \lambda_{temp} \| q_{t+1} - q_t \|^2 \right) $$

其中 $\xi_i$ 为块级对齐变换，$q_t$ 为机器人关节配置，$\lambda_{temp}$ 为时间平滑正则项。该公式通过联合优化对齐变换与关节配置，将人类指尖位置映射至机器人末端执行器，同时保证轨迹的时序平滑性。视觉转换阶段利用 SAM2 分割并 ProPainter 修复人类手臂区域，再通过 Isaac Sim 渲染机器人并叠加至修复后的帧，生成机器人化观测 $\tilde{I}_t$。这一设计使得预训练数据在视觉与动作两个维度上均对齐至目标机器人，克服了此前方法中视觉特征与动作空间不一致导致的 OOD 泛化瓶颈。

### 端到端 VLA 预训练策略

在策略训练阶段，HuRo 采用 GR00T-N1.6-3B 架构，动作头基于流匹配（Flow Matching）机制。给定机器人化观测 $\tilde{I}_t$、指令 $l_i$ 与状态 $s_t$，VLM 骨干编码为视觉-语言嵌入 $\phi_t$，动作头预测 $H=40$ 步动作块。训练目标为流匹配损失：

$$ \mathcal{L}_{FM} = \mathbb{E}_{t, \epsilon} \left[ \| v_\theta(\tilde{I}_t, l_i, s_t, a_t, t) - \epsilon \|^2 \right] $$

其中 $v_\theta$ 为预测的速度场，$\epsilon$ 为高斯噪声。该公式通过连续动作生成避免了离散 Token 的精度损失，支持高频控制。与仅转移视觉路径（PT Visual Only）不同，端到端预训练（PT Visual + Action）保留了预训练的动作头权重，使得下游微调时动作策略无需从零学习，显著提升了在未见物体与位置上的抓取一致性。

## 实验评估

实验在 ALLEX 双臂灵巧机器人上执行四个真实世界任务，对比基线包括无预训练（No PT）、纯视觉预训练（PT Visual Only）、视频生成预训练（I2V + IDM）及参考模型 π0.5 与 GR00T N1.6。基线覆盖了视觉转换、动作监督与视频生成三条主要路线，但缺失与 H2R 等纯视觉编码预训练方法的直接对比，且未包含标准仿真基准（如 LIBERO）的评估。

| 预训练规模 | ID 完成率 (%) | OOD 完成率 (%) |
| :--- | :--- | :--- |
| 0% PT | 68.1 | 34.9 |
| 10% PT | 76.9 | 59.5 |
| 50% PT | 78.2 | 66.7 |
| 100% PT | 88.4 | 72.2 |

主结果显示，随着预训练规模从 0% 增至 100%，ID 完成率从 68.1% 提升至 88.4%，OOD 完成率从 34.9% 提升至 72.2%。在 Diverse Pick-and-Place 任务中，PT (Visual + Action) 的 ID 与 OOD 完成率分别为 61.1% 与 50.0%，显著高于 PT (Visual Only) 的 31.9% 与 25.0%，证明动作监督对端到端策略迁移的关键作用。

消融实验揭示了视觉机器人化对 OOD 鲁棒性的独立贡献。无叠加（No-overlay）变体在 ID 上达到 89.4%，与完整 HuRo 的 88.4% 相当，但在 OOD 上仅为 55.7%，低于完整 HuRo 的 72.2%。更值得注意的是，No-overlay 在 OOD 上甚至低于 10% PT 的 59.5%，表明视觉对齐对 OOD 泛化的贡献独立于数据规模，且在小数据量下即显现。与 I2V + IDM 的对比中，HuRo 在 0.7M 帧时已超越 I2V + IDM 在 7.0M 帧时的 OOD 性能（69.4% vs 55.6%），且 I2V + IDM 在 3.5M 至 7.0M 帧间 OOD 性能无提升，而 HuRo 持续改善，表明联合对齐预训练具有更优的规模化趋势。

评估协议局限于真实世界任务，未报告置信区间与计算效率指标。代码与数据已开源，但机器人化流水线的渲染保真度受限于重建质量，未显式建模遮挡与物理接触，导致 44.8% 的轨迹存在非抓取自接触，限制了其在接触丰富任务中的直接应用。

## 关联研究分析

从问题动机看，HuRo 与 Zero-WAM 均利用人类视频，但 Zero-WAM 侧重上下文学习以实现零样本跨任务泛化，而 HuRo 侧重预训练数据构建以提升基础策略性能。这一差异源于任务特性：Zero-WAM 假设部署时可获得任务上下文，而 HuRo 假设预训练阶段需覆盖广泛操作行为。HuRo 的联合对齐设计在数据充足时更优，但在数据稀缺时，Zero-WAM 的上下文推断机制可能更具优势，论文未对此进行对比。

从方法设计看，HuRo 与 GigaBrain-0 均使用合成/生成数据，但 GigaBrain-0 依赖世界模型生成视频，而 HuRo 依赖真实人类视频转换。GigaBrain-0 的合成数据可能存在物理不一致性，而 HuRo 的机器人化观测受限于渲染保真度。两者在 OOD 鲁棒性上的表现差异，可能源于真实人类视频的多样性与世界模型生成的多样性之间的权衡，论文未提供大规模“合成 vs 真实”数据的消融实验。

## 总结

HuRo 旨在解决 VLA 预训练中真实机器人数据稀缺与人类视频具身差距之间的矛盾。现有方法要么仅做视觉转换，要么仅做动作重定向，无法在大规模异构数据上实现观察与动作的联合对齐。HuRo 通过耦合视觉机器人化与运动重定向的流水线，构建了 630K 集成的预训练数据集，验证了联合对齐预训练在真实世界操作任务中的规模化有效性，ID 完成率从 68.1% 提升至 88.4%，OOD 完成率从 34.9% 提升至 72.2%。其边界在于渲染保真度受限于重建质量，且未建模物理接触，导致 44.8% 的轨迹存在非抓取自接触。当预训练数据规模进一步增大时，视觉机器人化的渲染保真度对 OOD 鲁棒性的边际贡献是否递减，论文未给出回答。
