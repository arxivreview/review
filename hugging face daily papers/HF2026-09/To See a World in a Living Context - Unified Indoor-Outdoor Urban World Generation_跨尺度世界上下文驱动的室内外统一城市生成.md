# HuggingFace最新推荐论文 ｜To See a World in a Living Context: Unified Indoor-Outdoor Urban World Generation ｜跨尺度世界上下文驱动的室内外统一城市生成

研究机构：中山大学、挪威科技大学

作者：Xiaobin Huang、Zilong Huang、Yang Luo 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2608.05879)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.05879)

> 城市级3D生成长期面临室外外观与室内功能割裂的困境，现有方法虽能独立生成逼真的城市或房间，却缺乏建筑实例与内部空间的显式对应关系。HoloWorld通过构建一个从城市到建筑逐级演化的“活体上下文”（Living Context），将室外生成证据与几何足迹传递至室内合成阶段，实现了室内外空间的语义、视觉与几何一致性。该方法在统一生成任务上显著优于独立生成基线，但其依赖多阶段LLM推理与图像转3D转换，计算开销与实时性仍是主要制约。

## 研究背景

理解本文需厘清两个核心概念：自回归块生成与跨尺度上下文传递。自回归块生成通过条件化已生成的邻域块来维持城市空间连续性，如SynCity（Engstler et al., 2025）所示，但该方法仅处理室外外观，未涉及建筑内部。跨尺度上下文传递则要求信息从全局规划逐级细化至局部实例，传统方法中这一过程往往是单向且静态的，导致室内生成无法继承室外建筑的特定风格与几何约束。

城市级3D生成的核心矛盾在于空间组织、建筑多样性与视觉一致性需在大规模区域内协同，而室内生成则聚焦于语言驱动的房间规划与资产合成。主流路线如CityDreamer（Xie et al., 2024）和Holodeck（Yang et al., 2024）分别优化了室外结构或室内布局，但二者均将室内外视为独立任务，缺乏建筑实例与内部空间的显式对应。HoloWorld的切入点在于将室内外生成重构为单一世界生成问题，要求每个室内空间必须显式锚定其对应的室外建筑实例，并继承其语义、外观与足迹约束。

## 核心方法

### 方法参照系

本文问题可置于“智能体驱动场景创作”与“世界模型”混合路线下。标准流程通常由LLM规划布局，再由生成器执行，但本文的关键差异在于引入了一个动态演化的跨尺度状态机，而非静态记忆，以解决室内外信息断裂问题。

### 跨尺度活体上下文表示

传统方法中，上下文通常作为静态记忆存储历史输出，无法动态适应生成过程中的新证据。HoloWorld将上下文 $C_t$ 分解为世界、块、建筑三级层级结构，信息从高层继承至低层，同时新生成的验证证据反向传播以丰富上下文。

$$
C_t = \left( C_t^{world}, \{C_{t,i}^{block}\}_{i \in G}, \{C_t^b\}_{b \in B_t} \right)
$$

该公式定义了层级化上下文，其中 $C_t^{world}$ 编码城市全局语义与风格，$C_{t,i}^{block}$ 维护局部空间关系，$C_t^b$ 则整合特定建筑的身份、外观与几何属性。这种双向交互机制确保了城市生成在保持全局一致性的同时，能建立建筑级室内外对应。

### 建筑实例关联与足迹约束室内合成

室外生成后，需将上下文本地化至具体建筑实例以指导室内合成。HoloWorld通过关联建筑区域 $M_b^{iso}$ 与其3D实例 $x_b$，提取足迹 $F_b$，构建建筑级上下文 $C^b$。

$$
C^b = \Pi_{sv}(C^{world}, C_i^{block}) \oplus \{I_i, M_b^{iso}, id(x_b), F_b\}
$$

此公式将继承的语义、外观与实例几何约束融合，为室内合成提供局部条件。室内合成过程 $S_b^{in}$ 在足迹约束下进行层级化生成：

$$
S_b^{in} = A^{in}(\Pi_{in}(C^b)), \quad \text{Footprint}(S_b^{in}) \subseteq F_b
$$

该设计动机在于解决独立生成方法中室内布局与建筑几何脱节的问题，通过硬约束确保室内空间严格符合室外建筑边界，同时继承其视觉身份。

## 实验评估

实验在自生成城市集上进行，对比CityCraft、SynCity、MajutsuCity及独立生成基线TRELLIS。基线覆盖自回归块生成与独立室内外生成路线，但缺乏传统NeRF/3DGS基线，且未使用3D-FRONT等标准基准。

| 方法 | SVC AQS | SRC AQS | MTF AQS | LA AQS | Visual AQS | Shape IoU |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| MajutsuCity | 8.00 | 7.00 | 7.40 | 7.83 | - | - |
| TRELLIS | - | - | - | - | 5.88 | - |
| HoloWorld | 8.75 | 7.63 | 8.00 | 8.67 | 8.21 | 0.997 |

HoloWorld在室外生成AQS上全面领先，室内视觉一致性AQS从TRELLIS的5.88提升至8.21，Shape IoU达0.997，验证了足迹约束的有效性。

| 配置 | Functional AQS | Visual AQS | Spatial AQS | Shape IoU |
| :--- | :--- | :--- | :--- | :--- |
| Static Context | 5.75 | 4.58 | 3.25 | 0.670 |
| Full Model | 7.67 | 8.17 | 7.75 | 0.994 |
| w/o ANC | - | - | - | - |

消融显示，静态上下文导致Shape IoU从0.994降至0.670，证明动态上下文对几何对齐至关重要。移除自回归邻域条件（ANC）后，跨块连续性AQS从8.25降至7.25，表明邻域条件对视觉连续性有显著贡献。

评估指标包括AQS、RDR及Shape IoU，但缺乏FID、Chamfer Distance等标准几何指标。代码未公开，超参数与GPU配置未详述，可复现性受限。评估协议依赖GPT-5.5与人工评估，可能存在主观偏差。

## 关联研究分析

从问题动机看，HoloWorld与SynCity（Engstler et al., 2025）均采用自回归块生成，但SynCity仅关注室外连续性，而HoloWorld将上下文延伸至室内，解决了建筑-室内对应问题。这一差异源于任务定义：SynCity目标是生成连贯城市外观，HoloWorld则要求室内外作为同一世界的对应部分。从方法设计看，HoloWorld与Holodeck（Yang et al., 2024）均使用LLM规划，但Holodeck依赖物理引擎验证，HoloWorld则采用几何足迹约束。这种选择可能源于室内生成对精确几何对齐的需求高于物理交互，但论文未探讨足迹约束在复杂建筑（如多楼层、非凸形状）下的鲁棒性。

## 总结

HoloWorld解决的核心矛盾是室内外生成割裂导致的世界不一致性。其切入点在于构建跨尺度活体上下文，将室外生成证据与几何足迹传递至室内合成，这是独立生成方法无法实现的。方法通过层级化上下文与足迹约束，实现了室内外空间的显式对应。实验证明其室外AQS提升7.68%，室内Shape IoU达0.997。边界在于依赖多阶段LLM推理与图像转3D转换，计算开销大，且足迹约束在复杂建筑下的鲁棒性未验证。当建筑足迹为非凸或多楼层结构时，足迹约束是否仍能维持室内布局的合理性，论文未给出回答。
