> 导读 当前前沿推理能力被锁定在千亿参数级闭源系统中，学术研究者面临算力与数据双重壁垒。现有小模型依赖被动记忆或单一强化学习后训练，难以在长程任务中突破静态参数容量上限。ZGCM-1 通过混合滑动窗口注意力架构与马尔可夫决策过程（MDP）中训练，将外部工具交互重构为密集步骤级监督，在 7.39B 参数规模下实现了数学推理与智能体搜索的高效训练。该范式验证了小模型结合主动检索可逼近前沿模型性能，但其对工具链的强依赖及纯内部推理能力的边界仍存疑。

## 研究背景

长程推理任务要求模型在数万 token 上下文中维持逻辑一致性，传统全注意力机制的键值缓存（KV Cache）开销随序列长度平方级增长，导致 7B 级模型在 256K 上下文下显存溢出。滑动窗口注意力（SWA）通过限制局部感受野降低计算复杂度，但纯局部窗口无法捕捉全局依赖，需在局部效率与全局信息流之间取得平衡。同时，智能体任务中的交互轨迹通常仅获得终端奖励，导致中间步骤缺乏直接监督，策略学习信号稀疏且噪声大。

主流小模型训练路线分为两类：一类依赖大规模预训练数据被动记忆，另一类采用近端策略优化（PPO）或组相对策略优化（GRPO）进行强化学习后训练。前者受限于参数容量，难以泛化到未见过的复杂逻辑；后者虽能提升推理能力，但序列级奖励的均匀分配导致信用分配粗糙，且训练过程对算力要求极高，学术团队难以复现。ZGCM-1 的切入点在于将“内部思考”与“外部工具使用”解耦，通过架构优化降低长上下文训练成本，并通过 MDP 重构将交互轨迹转化为密集的状态-动作监督，从而在有限算力下实现高效的能力构建。

## 核心方法

### 混合滑动窗口与全局注意力架构

ZGCM-1 采用解码器-only Transformer 架构，核心创新在于混合注意力机制。标准全注意力在长序列下计算瓶颈显著，而纯 SWA 丢失全局信息。本文在 32 层中交替部署 27 层门控 SWA（128-token 窗口）与 5 层全局注意力，比例为 5:1。门控 SWA 模块通过可学习 sigmoid 门控调制局部注意力输出，公式如下：

$$
\text{GatedSWA}(h) = o_{proj}(\mathcal{A}_{SWA}(q, k, v) \odot \sigma(g_{proj}(h)))
$$

其中 $\mathcal{A}_{SWA}$ 为滑动窗口 GQA 输出，$\odot$ 为逐元素乘法。该设计动机在于解决纯 SWA 在长程依赖任务中信息截断的问题，同时避免全注意力的显存爆炸。实验显示，该架构在 256K 上下文下将每 token KV 缓存从 128 KiB 降至 20 KiB，吞吐量提升 3.94 倍，且尾损失与全注意力基线持平。

### MDP 中训练与状态-动作监督

传统智能体训练依赖终端奖励，导致中间步骤信用分配模糊。ZGCM-1 在中训练阶段将交互轨迹重构为 MDP 状态-动作转移，提供密集步骤级监督。具体而言，模型在 16K、64K、256K 三个阶段逐步扩展上下文，同时引入推理、指令与智能体数据。MDP 重构的核心在于将长轨迹分解为局部状态 $s_t$ 与动作 $a_t$ 的序列，监督信号不再仅依赖最终结果，而是覆盖每个交互步骤。这一设计解决了 GRPO 等 RL 方法中序列级奖励稀疏导致的优化偏差问题，使模型在缺乏外部奖励模型的情况下仍能学习细粒度的决策逻辑。

## 实验评估

实验覆盖 20 个基准，包括 MATH-500、AIME 2026、OlympiadBench 及 WebWalkerQA 等智能体任务。基线对比涵盖 7B-8B 规模模型（Qwen3-8B、MiniCPM4.1-8B）及前沿模型（GLM-5.1、Kimi-K2）。ZGCM-1-7B 在 14 个推理基准平均排名 7B 级第一，MATH-500 达 97.1%，AIME 2026 达 75.0%。在智能体搜索任务中，WebWalkerQA 得分 63.1%，BrowseComp 得分 19.4%，Binary Function Search 得分 62.0%，与 GLM-5.1（66.0%）接近，显著优于 Qwen3-8B（12.0%）。

| 基准 | ZGCM-1-7B | Qwen3-8B | GLM-5.1 |
| :--- | :--- | :--- | :--- |
| MATH-500 | 97.13 | 96.32 | - |
| AIME 2026 | 75.00 | - | - |
| WebWalkerQA | 63.09 | - | - |
| Binary Function Search | 62.00 | 12.00 | 66.00 |

消融实验表明，混合 SWA 5:1 相比全注意力在 256K 上下文下吞吐量提升 3.94 倍，KV 缓存减少 6.4 倍。SFT 数据筛选中，激进分层过滤（剔除约 50% 候选）使六基准平均分从 67.78 提升至 68.83，其中 BBH 提升 10.10 分，但部分任务出现负迁移。预训练效率方面，SWA（1.4×）、FP8（1.5×）、Muon（1.8×）与 Pre-LN（1.1×）协同作用，实现 16K 预训练时间-损失比约 4.2 倍加速。

评估边界方面，论文未报告置信区间，且智能体任务依赖特定工具链（Ghidra、Web 搜索），纯内部推理能力在闭卷任务中仍落后于前沿模型。可复现性上，模型权重、训练代码及 W&B 日志已开源，但 256K 上下文训练需 8 块 H100 GPU，学术团队复现门槛较高。

## 关联研究分析

从问题动机看，ZGCM-1 与 SSVPO 等步骤级信用分配方法均旨在解决序列级奖励稀疏问题，但路径截然不同。SSVPO 依赖 RL 框架中的优势函数重构，需训练 Critic 或进行组内相对奖励计算，算力开销大；ZGCM-1 则通过 MDP 中训练将交互轨迹直接转化为 SFT 监督信号，绕过了 RL 优化过程。这一差异源于任务特性：智能体搜索任务中，工具交互本身提供了丰富的中间反馈，使得 SFT 足以捕捉细粒度决策，而纯数学推理任务缺乏此类外部反馈，RL 仍是必要手段。

从方法设计看，ZGCM-1 的混合注意力架构与 DAPO 等训练稳定性方法形成互补。DAPO 通过解耦裁剪与动态采样缓解 GRPO 训练中的梯度消失，属于算法层优化；ZGCM-1 则从架构层降低长上下文计算成本，使 7B 模型能处理 256K 序列。两者结合可能进一步提升效率，但论文未探索算法-架构协同优化。此外，ZGCM-1 的“内部思考+外部工具”范式与 TreeAdv 的树分支探索机制不同，前者依赖外部检索弥补参数容量，后者依赖内部多样性生成。当外部工具不可用时，ZGCM-1 的推理能力是否显著下降，论文未给出回答。

## 总结

ZGCM-1 旨在解决小模型在长程推理与智能体任务中因参数容量限制与算力壁垒导致的性能瓶颈。其切入点在于将外部工具交互重构为 MDP 状态-动作监督，并通过混合 SWA/GA 架构降低长上下文训练成本，从而在 7.39B 参数规模下实现高效能力构建。实验证明，该模型在 MATH-500 达 97.1%，AIME 2026 达 75.0%，智能体搜索任务性能逼近千亿参数级前沿模型。然而，其性能高度依赖外部工具链，纯内部推理能力在闭卷任务中仍落后，且 256K 上下文训练需 8 块 H100 GPU，复现门槛高。当移除外部工具支持时，ZGCM-1 在复杂逻辑推理上的性能衰减幅度，论文未给出回答。
