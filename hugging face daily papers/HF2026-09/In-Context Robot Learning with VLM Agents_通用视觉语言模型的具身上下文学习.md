# HuggingFace最新推荐论文 ｜In-Context Robot Learning with VLM Agents ｜通用视觉语言模型的具身上下文学习

研究机构：华中科技大学、复旦大学

作者：Dongzhou Cheng、Taoran Yi、Ye Fang 等 15 人

论文原文见 [arXiv](https://arxiv.org/abs/2609.19138)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.19138)

> 具身智能的核心困境在于有限演示数据无法覆盖部署时的所有长尾场景，传统策略依赖梯度更新进行微调，难以在测试时即时适应新任务。现有基于预训练视觉-语言-动作模型（Vision-Language-Action Model, VLA）的方法虽具备一定泛化能力，但缺乏对异构上下文（如人类视频、动作参考、交互历史）的即时解析与执行闭环。本文提出GPT-Policy，通过上下文编译器与受限执行层，将通用视觉语言模型（Vision-Language Model, VLM）直接接入机器人工具接口，实现无梯度更新的测试时行为适应。该框架验证了通用VLM在跨具身模仿与精细操作中的潜力，但其在物理接触精度与安全验证上的局限暴露了从语义理解到物理执行间的鸿沟。

## 研究背景

机器人部署面临的核心挑战是环境非结构化与任务多样性，导致预训练策略在分布外（Out-of-Distribution, OOD）场景中失效。行为克隆（Behavior Cloning, BC）作为主流范式，受限于演示数据的多模态分布建模缺陷，且依赖梯度更新进行适应，无法在测试时利用新获取的上下文信息。上下文学习（In-Context Learning, ICL）提供了一种替代路径，即在不改变模型参数的前提下，利用测试时提供的演示、示例或交互历史来调整行为。然而，通用VLM虽具备强大的语义推理能力，却缺乏将视觉上下文转化为可执行、可验证的物理动作的闭环机制，导致其难以直接用于精细操作任务。

视动策略学习的主流路线正从单一模态回归向多模态生成式架构演进，扩散策略（Diffusion Policy）虽解决了动作分布的多模态性问题，但推理延迟高且依赖特定任务训练。与此同时，分层规划方法通过视觉语言模型（Vision-Language Model, VLM）进行高层语义分解，但低层控制与高层规划间的对齐误差累积问题尚未解决。GPT-Policy的切入点在于剥离专用策略训练，直接评估通用VLM在闭环执行框架下，利用异构上下文（人类视频、机器人动作参考、目标图像、交互历史）进行即时适应的能力。这一视角将研究焦点从“如何训练更鲁棒的策略”转向“如何验证通用模型的具身适应边界”，为理解VLM在物理世界中的能力上限提供了实证基础。

## 核心方法

### 方法参照系

GPT-Policy属于分层规划与技能组合的变体，其架构包含高层语义理解（VLM）与低层运动执行（Cartesian Adapter）。与传统的VLA模型不同，该方法不训练专用的动作头，而是通过工具调用接口（Tool Call Interface）让VLM直接生成参数化的运动请求。关键差异在于，VLM的参数在任务执行期间保持冻结，所有适应均通过上下文输入实现，而非权重更新。

### 上下文编译与动作生成

传统VLM处理视觉输入时，往往将图像视为静态特征，忽略了时序动态与动作参考的时空对齐。GPT-Policy引入上下文编译器，将演示视频 $V$ 编码为时间戳排序的关键帧序列，并可选地关联记录的动作序列 $A$ 与机器人状态。在决策步 $t$，VLM策略 $\pi_\theta$ 基于任务指令 $T$、上下文 $c_t$、当前观测 $o_t$ 及前一步工具结果 $f_{t-1}$，生成工具请求 $a_t = (u_t, v_t)$：

$$
a_t \sim \pi_\theta(\cdot \mid T, c_t, o_t, f_{t-1})
$$

其中 $u_t$ 为工具名称，$v_t$ 为参数对象。该设计动机在于，通过保留任务相关的视觉过渡与动作参考，VLM能够从上下文中提取程序性知识，而非仅依赖静态语义。例如，在“拧开瓶盖”任务中，动作参考提供了关键帧之间的中间位姿，减少了VLM对运动轨迹的推断歧义，从而提升了与演示动作的对齐精度。

### 受限执行与闭环反馈

VLM生成的动作请求可能包含物理不可行或安全违规的指令，直接执行将导致任务失败或硬件损坏。GPT-Policy引入受限执行层，通过笛卡尔适配器（Cartesian Adapter）解析位姿路径，求解逆运动学（Inverse Kinematics, IK），并执行残差检查。对于位置 $p$ 和姿态 $R$，路径插值采用线性位置插值与四元数球面线性插值（SLERP）：

$$
p_j(s) = (1-s)p_j + s p_{j+1}, \quad R_j(s) = R_j \exp(s \log(R_j^\top R_{j+1}))
$$

执行后，系统返回测量状态、端点误差及稳定状态作为反馈 $f_t$，更新上下文供下一决策使用。这一机制解决了通用VLM缺乏物理约束感知的问题，通过执行层验证动作可行性，并将执行结果反馈至VLM，形成闭环重规划能力。

## 实验评估

实验在真实机器人平台上进行，涵盖毛巾抓取、笔记本拾取、瓶盖拧开、插头拔插、T形排列、柠檬放置、移动探索、井字棋及指认水果拾取共9个任务。每个任务重复3次，评估指标包括成功率（S/T）、决策次数及执行时间。基线仅对比不同上下文条件（无上下文、人类视频、机器人视频、视频+动作、目标图像、自交互历史、人机交互），未包含基于梯度更新的专用策略基线（如Diffusion Policy或ACT），因此无法直接量化ICL相对于传统训练范式的性能增益。

| 任务 | 上下文条件 | 成功率 (S/T) | 决策次数 | 执行时间 (min) |
| :--- | :--- | :--- | :--- | :--- |
| Pick Red Towel | None | 0 / 3 | 96.3 | 24.6 |
| Pick Red Towel | Human Video | 2 / 3 | 76.7 | 18.9 |
| Pick Up Notebook | None | 0 / 3 | 94.0 | 24.6 |
| Pick Up Notebook | Human Video | 2 / 3 | 66.7 | 16.1 |
| Unscrew Bottle Cap | Robot Video + Action | 3 / 3 | 54.7 | 17.9 |
| Remove and Reinsert Plug | Robot Video + Action | 2 / 3 | 48.3 | 10.8 |
| Arrange T Shape | Target Image | 3 / 3 | 66.7 | 15.8 |
| Lemon To Pink Plate | Self History | 3 / 3 | 35.3 | 8.1 |

消融实验显示，人类视频在毛巾抓取任务中将成功率从0/3提升至2/3，同时决策次数减少20.6次，执行时间缩短5.7分钟。在瓶盖拧开任务中，添加动作参考（Robot Video + Action）使成功率从2/3提升至3/3，但执行时间从15.2分钟增加至17.9分钟，表明动作参考虽提升了精度，但增加了规划复杂度。在移动探索任务中，自交互历史使成功率达到3/3，但执行时间长达25.53分钟，远高于其他任务，揭示了决策次数与执行时间之间的非单调关系。

评估边界方面，论文未报告置信区间，且样本量仅为3次/条件，统计显著性不足。代码已开源，但超参数与模型版本（如GPT-6 Astra）未详细披露，限制了可复现性。此外，实验未包含与专用VLA模型（如Octo或OpenVLA）的对比，无法排除VLM通用推理能力对结果的贡献，而非ICL机制本身的有效性。

## 关联研究分析

从问题动机看，GPT-Policy与GEN-1.5和S1均关注测试时适应，但GEN-1.5依赖专用基础模型进行单样本技能适应，而GPT-Policy验证了通用VLM在无专用训练下的适应潜力。这一差异源于任务特性：GEN-1.5针对特定技能库，而GPT-Policy旨在评估通用模型的开放世界适应边界。然而，GPT-Policy未提供证据支持通用VLM在精细操作精度上优于专用VFM，其优势可能部分归因于VLM的强语义推理能力，而非ICL机制本身。

从方法设计看，GPT-Policy与Show-Harness同属闭环VLM控制，但Show-Harness使用离散语义动作接口并依赖视频演示进行任务规划，而GPT-Policy通过工具调用接口直接生成参数化运动请求，并引入受限执行层进行物理验证。这一差异源于执行精度需求：Show-Harness面向高层规划，而GPT-Policy需处理低层运动控制。然而，GPT-Policy的受限执行层仅进行残差检查，未引入接触力反馈或安全约束优化，导致其在接触敏感任务（如插头拔插）中成功率仅为2/3，暴露了从语义理解到物理执行间的精度鸿沟。

## 总结

GPT-Policy旨在解决有限演示数据下机器人测试时适应的难题，通过上下文编译器与受限执行层，将通用VLM接入机器人工具接口，实现无梯度更新的即时行为调整。实验表明，人类视频与动作参考能显著提升任务成功率并减少决策次数，如毛巾抓取任务中成功率从0/3提升至2/3。然而，该方法在接触敏感任务中表现受限，且缺乏与专用策略的公平对比，暴露了通用VLM在物理执行精度与安全验证上的局限。当上下文信息包含复杂接触动力学时，VLM的语义推理能否转化为可靠的物理动作，论文未给出回答。
