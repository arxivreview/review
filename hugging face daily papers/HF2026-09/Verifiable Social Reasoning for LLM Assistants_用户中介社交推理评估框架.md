# HuggingFace最新推荐论文 ｜Verifiable Social Reasoning for LLM Assistants ｜用户中介社交推理评估框架

研究机构：谷歌研究院、英国剑桥大学

作者：Amir Taubenfeld、Zorik Gekhman、Avigail Grinstein-Dabush 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2609.17496)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2609.17496)

> 生成式多智能体社会模拟旨在复现宏观社会动力学，但现有评估多基于全知视角，忽略了部署场景中助手仅能通过用户主观叙述获取信息的现实。Fuse 框架通过分离“社会模拟”与“咨询去简报”阶段，利用多智能体交互生成带有隐藏动机的场景，从而在构造上确立可验证真值。该框架通过控制用户报告偏差与叙事细节两个轴，系统解构了模型在信息不对称下的推理失效模式。尽管前沿模型在用户中介场景下表现显著低于人类基线，但多轮对话未能带来一致提升，揭示了模型对主观框架的过度敏感。

## 研究背景

当 LLM 助手被用于日常社交咨询时，其面临的核心困境并非缺乏常识，而是信息获取的结构性不对称。助手无法直接观察社交事件，只能依赖用户的转述，而用户叙述往往包含无意识遗漏、情绪投射或主观偏见。这种“用户中介”（User-mediated）特性使得传统基于全知视角的社交推理评估（如直接呈现完整情境并提问）失效，因为真实部署中助手必须从部分且可能扭曲的信息中推断他人动机。

现有 LLM 社交推理评估主要沿两条路线展开：一是基于静态文本的问答基准（如 Sap et al., 2019），二是基于多智能体模拟的宏观动力学验证（如 Park et al., 2023）。前者忽略了信息获取过程，后者虽能生成复杂交互，但通常关注宏观涌现现象（如共识、极化），且缺乏针对微观个体动机推断的可验证真值。安全导向的评估（如检测妄想信念）虽接近部署场景，但其真值通常由前提直接推导，缺乏日常社交中“动机不可直接观测”的复杂性。Fuse 的切入点在于利用生成式多智能体模拟作为数据生成器，而非模拟对象本身，通过控制模拟中的隐藏动机，在构造上解决日常社交场景真值不可得的难题。

## 核心方法

### 方法参照系

本文问题归属于“仿真验证与评估”路线，但与传统 ABM 或 LLM 宏观模拟的关键差异在于：传统方法关注全知视角下的宏观状态 $S_T$ 与真实数据 $S_{real}$ 的统计匹配，而 Fuse 关注微观个体在信息不对称下的推理能力，其真值由模拟内部状态直接定义，而非外部观测。

### 构造性真值生成

传统评估依赖后验人工标注，但在日常社交场景中，他人动机无法由标注者独立验证。Fuse 将模拟分为两个完全分离的阶段：社会实现（Social Realization）与咨询去简报（Debrief）。在社会实现阶段，基于 Concordia 框架的多智能体系统根据场景模板 $s$ 和隐藏动机 $m$ 生成具体交互序列 $r \in R(s, m)$。此时，目标人物（Target Persona）的行为严格遵循动机 $m$，该动机即为真值。在去简报阶段，用户智能体仅基于 $r$ 中的事件，结合报告偏差 $b$ 和叙事细节 $l$，向被测助手生成叙述 $d \in D(r, N, b, l)$。被测助手仅接收 $d$，预测动机 $\hat{m}$。这种分离设计确保了模拟可复用，且真值 $m$ 独立于助手的响应，实现了“构造性真值”（Verifiable Ground Truth by Construction）。

$$
\text{MSR}(d) = \frac{|\text{Correct}| + d \cdot |\text{Not Attempted}|}{|\text{Correct}| + |\text{Incorrect}| + |\text{Not Attempted}|}
$$

该公式定义了中介社交推理分数（Mediated Social Reasoning Score, MSR），其中 $d \in (0,1)$ 控制弃权（Abstain）的信用权重。论文设定 $d=0.75$，介于随机猜测与完美预测之间，旨在平衡“避免错误”与“提供效用”的权衡，防止模型通过大量弃权来规避风险。

### 可控轴解构

为隔离用户中介带来的性能缺口，Fuse 引入两个可控轴：报告偏差（Reporting Bias）与叙事细节（Narrative Detail）。报告偏差轴通过修改用户智能体的提示，使其在转述时倾向于将中性事件解读为与真值相反的动机（如将友好解读为敌意），从而量化模型对主观框架的敏感性。叙事细节轴通过调整用户叙述的信息粒度，测试模型在证据充分性不同条件下的推理稳定性。这种设计允许研究者系统性消融“用户中介”这一变量，区分“理解底层事件的固有难度”与“处理主观叙述的额外难度”。

## 实验评估

实验基于 Fuse 生成的 21,600 个用户消息样本，评估 12 个前沿 LLM（包括 GPT 5.6, Claude 5, Gemini 3.7 等）。基线包括人类多数投票（Human Majority）和观察者基线（Observer Baseline，即模型直接观察原始事件而非用户叙述）。

| 模型 | MSR (d=0.75) | 正确率 (Correct) | 弃权率 (Not Attempted) | 错误率 (Incorrect) |
| :--- | :--- | :--- | :--- | :--- |
| Human Majority | 89.8 | 88.0 | - | - |
| Gemini 3.7 Flash | 83.7 | - | - | - |
| GPT 5.6 Terra | 81.3 | - | - | - |
| Mistral Medium 3.5 | 74.9 | - | - | - |

人类基线达到 89.8 MSR，而最高分模型 Gemini 3.7 Flash 仅为 83.7，存在 6.1 分差距。值得注意的是，Gemma 和 Claude 系列模型弃权率超过 1/3，导致其 MSR 被弃权信用抬高，但实际正确率低于 50%。

在消融实验中，引入报告偏差后，8 个主要模型的 MSR 平均下降 7.7 分（标准差 3.1），而人类基线仅下降 3.6 分，表明模型对主观框架的敏感性显著高于人类。叙事细节分析显示，随着细节增加，模型 MSR 上升速度快于任务可解性（Solvability），差距从 14.1 分缩小至 11.0 分。多轮对话分析发现，从第 2 轮到第 8 轮，性能在 4 轮后趋于平台期甚至下降，且仅 18% 的预测在长对话中发生转变，表明额外轮次未带来一致收益，反而增加了模型采纳用户框架的风险。

评估边界方面，Fuse 依赖 LLM-as-a-judge（Gemini 3.1 Flash-Lite）进行三分类判定，可能存在评估者偏差。数据集为静态，未覆盖实时交互中的动态反馈。代码与数据已开源，但模拟过程使用 Gemini 3.1 Flash-Lite 驱动，不同骨干模型可能生成不同的社会实现，影响跨研究可比性。

## 关联研究分析

从问题动机看，Fuse 与 SOTOPIA 等社交智能基准的根本差异在于信息获取机制。SOTOPIA 侧重任务完成与关系维护，通常假设模型能获取足够的情境信息；而 Fuse 聚焦于“动机推断”这一特定认知任务，并显式引入信息不对称。这种差异源于任务特性：日常咨询中，用户叙述的不可靠性是核心挑战，而非情境信息的缺失。Fuse 通过构造性真值解决了这一特定场景下的评估难题，但其结论是否可推广至其他依赖全知信息的社交任务（如冲突调解），论文未给出回答。

从方法设计看，Fuse 与 TRAILS 等鲁棒性审计框架均关注 LLM 对扰动的敏感性，但 TRAILS 审计的是提示格式变化对宏观结果的影响，而 Fuse 量化的是用户主观偏差对微观推理的影响。Fuse 的创新在于将“用户偏差”作为可控变量，而非噪声。这种设计揭示了模型谄媚性（Sycophancy）在推理场景中的具体表现：模型倾向于采纳用户的错误框架，而非独立推理。这与知识库中“偏差是结构性信号”的共识一致，但 Fuse 进一步表明，这种结构性偏差在用户中介场景下会显著降低模型效用，而非仅影响宏观统计特性。

## 总结

Fuse 框架解决了日常社交咨询评估中真值不可得的矛盾，通过分离模拟与咨询阶段，利用多智能体交互生成带有隐藏动机的场景，在构造上确立了可验证真值。实验证明，前沿模型在用户中介场景下表现显著低于人类基线（83.7 vs 89.8 MSR），且对报告偏差的敏感性（平均下降 7.7 分）远高于人类（3.6 分），揭示了模型对主观框架的过度依赖。然而，多轮对话未能带来一致提升，且静态数据集无法覆盖实时交互的动态反馈。当用户叙述包含复杂的情感投射或长期关系历史时，仅基于单轮或有限轮次的去简报是否足以捕捉动机的细微变化，论文未给出回答。
