# HuggingFace最新推荐论文 ｜MixFlow: Mixed Source Distributions Improve Rectified Flows ｜混合源分布整流流

研究机构：德国马克斯·普朗克信息学研究所

作者：Nazir Nayal、Christopher Wewer、Jan Eric Lenssen

论文原文见 [arXiv](https://arxiv.org/abs/2604.09181)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.09181)

> 流匹配模型因生成轨迹高度弯曲，导致推理需大量神经函数评估（NFE）才能维持生成质量，这一效率瓶颈制约了其实时应用。现有轨迹直线化方法受限于独立耦合假设或推理时信息缺失，无法在低NFE下保持高保真度。MixFlow通过引入可学习前向耦合与混合源分布策略，在训练阶段优化源-目标对齐，使单一模型在2至128步采样范围内均优于基线。该方法在CIFAR-10上以124.7 NFE取得2.27 FID，较标准整流流提升12%，但其效果高度依赖条件信号的信息量，且未验证高分辨率潜空间场景下的泛化能力。

## 研究背景

流匹配将生成过程建模为从简单先验到数据分布的确定性传输，其采样效率直接受轨迹曲率影响。轨迹曲率源于源分布与目标分布间的耦合方式：当采用独立耦合时，不同源-目标对构成的直线轨迹在中间时刻严重交叉，迫使速度场学习平均方向，导致实际积分路径弯曲。这种弯曲使得数值求解器需更多步长才能控制误差累积，形成采样速度与生成质量的根本矛盾。

整流流通过最优传输位移插值替代扩散调度器，理论上降低了所需步数，但实践中仍需数十至上百步。近期研究指出，前向耦合的优化程度是决定轨迹直线性的关键变量。Fast-ODE（Lee et al., 2023）首次提出参数化耦合网络，将数据样本本身作为条件信号，但推理时数据样本不可用，限制了其无条件生成能力。QAC（Liang et al., 2024）引入可学习表示减少曲率，但仍假设源-目标独立。MixFlow的切入点在于：利用任意可用信号$\kappa$构建可学习耦合，并通过混合策略解决朴素条件分布导致的先验空洞问题，使模型在推理时无需条件信号仍能保持低曲率轨迹。

## 核心方法

### 方法参照系

标准整流流训练流程为：采样独立耦合$(x_0, x_1)$，计算中间点$x_t = tx_1 + (1-t)x_0$，最小化速度场$v_\theta(x_t, t)$与目标速度$(x_1 - x_0)$的均方误差。本文问题与该通用流程的关键差异在于：源分布不再是固定标准高斯，而是依赖于信号$\kappa$的可学习分布，且训练时使用混合源分布以平衡条件对齐与无条件覆盖。

### $\kappa$-前向耦合

独立耦合假设是轨迹交叉的主因，Fast-ODE虽引入数据样本条件，但推理时失效。MixFlow提出$\kappa$-FC，将前向耦合分解为条件分布$q_\phi(x_0|\kappa)$与边缘分布$q(x_1, \kappa)$的乘积，其中$\kappa$可为类标签、图像样本或任意噪声。该设计解决了此前方法在无条件推理时无法利用耦合信息的失效，允许源分布根据$\kappa$动态调整以对齐目标分布模式。

$$
q_\phi(x_0, x_1) = \int q_\phi(x_0|\kappa) q(x_1, \kappa) d\kappa
$$

此公式表明，源-目标联合分布由条件源分布与信号-目标联合分布积分得到，$\kappa$作为公共原因使$x_0$与$x_1$条件独立，从而通过优化$q_\phi(x_0|\kappa)$降低轨迹交叉度。

### 混合源分布训练

朴素条件高斯$q_\phi(x_0|\kappa) = \mathcal{N}(\mu_\phi(\kappa), \Sigma_\phi(\kappa))$在正则化权重$\beta \to 0$时导致先验空洞，推理时无法采样；$\beta \to \infty$时退化为独立耦合。MixFlow采用线性混合源分布$w\mathcal{N}(\mu_\phi(\kappa), \Sigma_\phi(\kappa)) + (1-w)\mathcal{N}(0, I)$，训练时$w \sim U(0,1)$随机采样。该设计解决了单一条件分布无法覆盖整个高斯空间的失效，使网络同时学习条件对齐与无条件生成，推理时可通过调整$w$控制速度-质量权衡。

$$
\mathcal{L} = \|x_1 - x_0 - v_\theta(x_t, t)\|_2^2 + \beta D_{KL}(\mathcal{N}(\mu_\kappa, \Sigma_\kappa) \| \mathcal{N}(0, I))
$$

此损失函数包含速度回归项与条件分布KL正则项，$\beta$控制条件分布偏离标准高斯的程度。混合策略使$\beta$可降至$10^{-5}$量级而不失稳定性，允许源分布更大幅度偏离高斯先验，从而获得更低轨迹曲率。

## 实验评估

实验在CIFAR-10、FFHQ 64×64、AFHQv2 64×64上进行无条件生成评估，对比Rectified Flow、Fast-ODE、QAC等轨迹优化基线，未包含Consistency Models或MeanFlow等蒸馏类方法。主实验使用RK45自适应求解器进行全ODE模拟，低NFE场景使用Heun二阶求解器。

| 方法 | 求解器 | NFE | FID (↓) |
| :--- | :--- | :--- | :--- |
| Rectified Flow | RK45 | 127 | 2.58 |
| Fast-ODE | RK45 | 118 | 2.45 |
| QAC | - | - | 2.43 |
| MixFlow | RK45 | 124.7 | 2.27 |
| Fast-ODE | Heun's | 5 | 24.40 |
| QAC | 2nd order | 5 | 19.68 |
| MixFlow | Heun's | 5 | 19.29 |
| Fast-ODE | Heun's | 9 | 9.96 |
| QAC | 2nd order | 9 | 10.28 |
| MixFlow | Heun's | 9 | 8.97 |

MixFlow在124.7 NFE下FID 2.27，较Rectified Flow的2.58降低12%，较Fast-ODE的2.45降低7%。在5 NFE时，MixFlow FID 19.29优于Fast-ODE的24.40约20%；9 NFE时FID 8.97优于Fast-ODE的9.96约10%。

消融实验显示，$\beta$值从$10^{-7}$增至$10^{-5}$时，低NFE性能改善但高NFE性能下降，$\beta = 10^{-5}$为最佳平衡点。条件信号$\kappa$的选择影响显著：$\kappa = x_1$（数据样本）在所有步数下FID最优，$\kappa \sim \mathcal{N}(0, I)$（噪声）次之，类标签$\kappa_c$略差于噪声。轨迹曲率评估表明，MixFlow较Rectified Flow降低约22%，较Fast-ODE降低约5%。

评估仅覆盖像素空间低分辨率图像，未报告计算效率、多样性指标或置信区间。代码已开源，但FFHQ/AFHQv2实验未提供完整超参数配置。

## 关联研究分析

从问题动机看，MixFlow与Fast-ODE同属前向耦合优化路线，但Fast-ODE将数据样本作为条件信号，推理时因样本不可用而失效；MixFlow引入任意信号$\kappa$并通过混合策略解决推理时信息缺失问题。这一差异源于任务特性：无条件生成场景下，数据样本不可用是根本约束，Fast-ODE未考虑此约束导致其应用受限，而MixFlow通过混合源分布将条件对齐能力迁移至无条件源分布，解决了这一盲区。

从方法设计看，MixFlow与QAC均旨在降低轨迹曲率，但QAC通过可学习表示条件化速度场，MixFlow通过优化源分布本身。QAC的表示学习增加了模型复杂度，且未解决源-目标独立耦合的根本问题；MixFlow直接修改源分布，从根源上减少轨迹交叉。两者差异在于：QAC假设独立耦合下通过表示增强降低曲率，MixFlow认为独立耦合是曲率过高的主因，需优化耦合本身。MixFlow在低NFE场景下优势更明显，表明源分布优化比表示学习对少步生成更有效。

## 总结

MixFlow针对流匹配模型轨迹弯曲导致的采样效率瓶颈，抓住前向耦合优化这一被忽视的切入点，通过$\kappa$-FC公式与混合源分布策略，使单一模型在2至128步采样范围内均优于基线。实验证明其在CIFAR-10上以124.7 NFE取得2.27 FID，较标准整流流提升12%，5 NFE时FID 19.29优于Fast-ODE约20%。其边界在于：效果高度依赖$\kappa$的信息量，$\kappa = x_1$时最优但推理时不可用，$\kappa \sim \mathcal{N}(0, I)$时性能下降；实验仅覆盖像素空间低分辨率，未验证高分辨率潜空间场景。当$\kappa$为弱信息信号时，混合策略能否在保持低曲率的同时避免源分布覆盖不足，论文未给出回答。
