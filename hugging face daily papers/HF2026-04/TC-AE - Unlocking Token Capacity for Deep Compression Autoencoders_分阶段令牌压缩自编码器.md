# HuggingFace最新推荐论文 ｜TC-AE: Unlocking Token Capacity for Deep Compression Autoencoders ｜分阶段令牌压缩自编码器

作者：Teng Li、Ziyuan Huang、Cong Chen 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.07340)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.07340)

> 深度压缩自编码器在降低潜空间分辨率以提升生成效率时，常因通道扩张导致潜表示坍塌，进而损害生成质量。现有方法多聚焦于参数规模扩展或外部基础模型对齐，却忽视了中间令牌空间在信息传递中的关键作用。本文提出分阶段令牌压缩（Staged Token Compression, STC）机制，将单一的令牌-潜变量瓶颈拆分为编码器内部的两级压缩，并结合iBOT自监督目标增强令牌语义结构，从而在固定潜预算下恢复令牌数量扩展对生成性能的正面影响。该方案在64令牌深度压缩场景下显著优于基线，但其性能优势是否可推广至更高压缩率或开放域数据，仍存疑。

## 研究背景

潜扩散模型（Latent Diffusion Models, LDMs）通过先压缩像素至潜空间再执行去噪，大幅降低了生成计算成本。在深度压缩场景中，为维持重构质量，模型通常激进降低潜空间空间分辨率（如降至8×8），同时大幅增加通道数（如128维）。这种“低分辨率、高通道”配置虽提升了压缩率，却极易引发潜表示坍塌：潜空间中的几何结构变得复杂且不规则，导致扩散模型难以收敛，生成质量显著下降。

主流解决方案包括扩展模型参数量（如Hansen-Estruch et al., 2025）或引入外部视觉基础模型（VFM）特征进行对齐（如REPA, Yu et al., 2024）。然而，参数扩展受限于计算资源，且未解决信息在压缩过程中的结构性丢失；VFM对齐虽能注入语义，但依赖大规模预训练数据，引入了强数据先验，且需严格匹配预训练配置。本文切入点在于识别出被忽视的中间环节——图像令牌（Image Tokens）。在ViT架构中，图像是首先被切分为令牌序列，再经Transformer处理，最后通过瓶颈层压缩为潜变量。令牌作为像素与潜空间之间的信息桥梁，其数量与结构直接决定潜空间的质量。本文发现，简单增加令牌数量（减小Patch Size）虽能提升重构，却因加剧令牌-潜变量压缩比而导致生成性能停滞甚至恶化。

## 核心方法

### 方法参照系

标准ViT自编码器流程为：图像经Patch Embedding转为令牌序列，经Transformer块处理，最后通过单一瓶颈层（Bottleneck）压缩为潜变量。该流程假设单一瓶颈足以完成从高分辨率令牌到低分辨率潜变量的映射。本文的关键差异在于指出，在深度压缩下，单一瓶颈造成的压缩比过大，导致语义结构在映射过程中严重丢失，这是生成性能无法随令牌数量扩展而提升的根本原因。

### 分阶段令牌压缩

针对单一瓶颈导致的结构坍塌，本文提出分阶段令牌压缩（STC）。在ViT编码器内部，将Transformer层分为两个阶段：第一阶段处理高分辨率令牌以捕获细节，随后通过一个中间压缩层将令牌序列长度缩减至1/4；第二阶段处理压缩后的令牌，最后通过最终瓶颈层生成潜变量。这一设计将原本集中的压缩压力分散至两个阶段，避免了单次激进压缩造成的信息断裂。

$$
f_{\text{pix} \to \text{lat}} = f_{\text{pix} \to \text{tok}} \times f_{\text{tok} \to \text{lat}}
$$

该公式表明总压缩比是像素-令牌压缩比与令牌-潜变量压缩比的乘积。STC通过引入中间压缩，实际上是在Transformer内部提前执行部分 $f_{\text{tok} \to \text{lat}}$，使得最终瓶颈层的压缩负担减轻，从而保留了更多语义结构。

### 自监督令牌结构化

为进一步增强潜空间的生成友好性，本文引入iBOT自监督目标作为辅助损失。iBOT采用学生-教师蒸馏框架，教师为学生模型的指数移动平均（EMA）。通过掩码图像建模（MIM）损失预测被掩码令牌的输出，并通过类令牌蒸馏损失对齐不同视图的全局语义。

$$
\mathcal{L}_{\text{iBOT}} = \mathcal{L}_{\text{MIM}} + \mathcal{L}_{\text{CLS}}
$$

其中 $\mathcal{L}_{\text{MIM}}$ 鼓励局部语义一致性，$\mathcal{L}_{\text{CLS}}$ 鼓励全局语义一致性。该设计无需外部VFM，直接在训练过程中塑造令牌的语义结构，使潜空间具备更强的判别性与生成性，弥补了单纯重构损失在语义抽象上的不足。

## 实验评估

实验在ImageNet-1K 256×256上进行，使用LightningDiT评估生成性能。基线包括DC-AE、MingTok等深度压缩方法，但缺失VQ-VAE等离散基线及DINO-Tok等最新VFM适配方法。

| 方法 | 令牌数 | gFID (w/o CFG) | gFID (w/ CFG) |
| :--- | :--- | :--- | :--- |
| DC-AE | 64 | 26.44 | - |
| DC-AE-1.5 | 64 | 17.31 | - |
| TC-AE | 64 | 7.16 | 2.57 |

TC-AE在64令牌下gFID为2.57（w/ CFG），显著优于DC-AE的26.44（w/o CFG）。这表明STC有效缓解了深度压缩下的潜表示坍塌。

| 配置 | gFID | 收敛加速比 |
| :--- | :--- | :--- |
| Baseline | - | 1.0× |
| w/ STC | - | 2.7× |
| TC-AE (Full) | - | 4.7× |

消融实验显示，仅引入STC即可将扩散模型收敛速度提升2.7倍，结合自监督后进一步提升至4.7倍。这证实了STC与自监督目标的互补性：STC解决结构丢失，自监督解决语义缺失。

评估边界方面，实验仅覆盖ImageNet-1K，未测试开放域或医学图像等分布偏移场景。代码已开源，但超参数细节（如iBOT温度系数）未在正文详述，可能影响复现精度。

## 关联研究分析

从问题动机看，TC-AE与PAE（Yue et al., 2026）均关注潜空间几何结构对生成的影响，但PAE通过先验对齐正则化显式塑造潜流形，而TC-AE通过架构改造（STC）隐式保留结构。PAE依赖外部先验，TC-AE依赖内部压缩策略，前者可能更适应复杂语义，后者在计算效率上更具优势。

从方法设计看，TC-AE与DINO-Tok（Jia et al., 2025）均利用VFM语义，但DINO-Tok直接冻结VFM作为编码器，引入强数据先验；TC-AE通过iBOT内生学习语义，避免了对外部预训练的依赖。这种差异源于任务特性：DINO-Tok追求极致语义对齐，TC-AE追求在有限计算资源下的鲁棒性。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

TC-AE旨在解决深度压缩自编码器中潜表示坍塌导致的生成性能下降问题。现有方法或依赖参数扩展，或依赖外部VFM，均未能有效解决令牌-潜变量压缩过程中的结构性信息丢失。本文通过分阶段令牌压缩（STC）将压缩压力分散，并结合iBOT自监督目标增强语义结构，在64令牌下将gFID从26.44降至2.57，并加速扩散收敛4.7倍。然而，实验仅在ImageNet-1K上进行，且未测试更高压缩率（如32令牌）下的性能边界。当压缩率进一步增加时，STC能否持续有效，还是会出现新的结构坍塌，论文未给出回答。
