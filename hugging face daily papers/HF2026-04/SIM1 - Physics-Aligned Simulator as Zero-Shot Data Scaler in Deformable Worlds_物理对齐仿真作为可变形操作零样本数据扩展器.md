# HuggingFace最新推荐论文 ｜SIM1: Physics-Aligned Simulator as Zero-Shot Data Scaler in Deformable Worlds ｜物理对齐仿真作为可变形操作零样本数据扩展器

研究机构：复旦大学、上海交通大学

作者：Yunsong Zhou、Hangxu Liu、Xuekun Jiang 等 15 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.08544)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.08544)

> 可变形物体操作面临真实数据获取成本极高与仿真物理失配的双重困境，导致现有仿真到真实迁移范式在衣物折叠等任务中失效。本文指出仿真失效的根源在于缺乏物理接地，而非合成数据本身，提出通过几何、动力学与运动三重对齐构建物理一致的仿真环境。SIM1 利用高精度扫描、变形稳定求解器及扩散轨迹生成，将有限真实演示转化为大规模合成数据，实现零样本迁移。该工作验证了物理对齐仿真作为数据扩展器的可行性，但其依赖专家手动校准参数的局限仍制约了自动化程度。

## 研究背景

可变形物体操作的核心挑战在于其几何形态与接触动力学随交互实时演化，远超刚性物体的状态空间复杂度。这一特性使得基于视觉语言动作模型（Vision-Language-Action, VLA）的策略训练对数据覆盖度提出极高要求，而真实世界数据采集受限于熟练操作员、专用硬件及人力成本，难以规模化。当策略在有限真实数据上训练时，泛化能力受限，无法应对未见过的衣物材质或形态。

现有仿真到真实迁移（Sim-to-Real, S2R）范式在刚性物体领域通过域随机化或资产库扩展取得了成功，但在可变形操作中遭遇瓶颈。传统物理引擎针对刚体动力学优化，处理布料等软体材料时产生不稳定响应；仿真场景往往缺乏度量保真度，几何误差在软体变形下被放大；行为生成依赖抓取点与简单拾放原语，无法适配衣物折叠的复杂交互。这些因素导致合成数据仅能作为预训练信号，可靠性能仍依赖真实后训练。本文切入点在于主张仿真的首要原则是接地（Grounding），即模拟物理必须对应现实，从而提出从后适应转向对齐优先的仿真范式。

## 核心方法

### 方法参照系

本文问题属于物理参数辨识与仿真-真实共训练的交叉领域，但关键差异在于其目标并非混合训练，而是验证纯仿真数据能否替代真实数据。通用流程通常依赖域随机化消除分布偏移，而本文强调通过度量级场景数字化与动力学校准，使仿真环境成为真实世界的物理孪生，从而生成无偏合成数据。

### 几何与动力学对齐

几何对齐是动力学对齐的前提，微小形状或尺度差异会传播为接触误差。本文采用高精度3D扫描结合网格后处理，生成亚毫米精度的纹理化网格，确保仿真资产与真实物体在度量上一致。动力学对齐的核心在于解决实时刚性-软体耦合中的应变传播滞后问题。传统顶点块下降（Vertex Block Descent, VBD）求解器在在线交互中因力传播缓慢导致过度拉伸。本文引入增强顶点块下降（Augmented Vertex Block Descent, AVBD）扩展，在优化过程中显式引入应变约束。当边长超过阈值 $(1+\xi)l_0$ 时，激活虚拟弹性约束，注入校正力以加速收敛至物理合理构型。该机制通过惩罚能量项 $E_{strain}^{[n]} = \frac{1}{2} k_{[n]} (C(\mathbf{e}) - \lambda_{[n]})^2$ 实现，其中 $k_{[n]}$ 为迭代惩罚刚度，$\lambda_{[n]}$ 为拉格朗日乘子，确保布料在机器人接触下保持形态稳定，避免粒子间隙导致的滑动与尖峰变形。

### 结构化运动合成

几何与动力学对齐后，运动对齐需解决可变形物体交互的非确定性。刚性物体的轨迹切片与重组在柔性任务中失效，因为有效抓取位置不可靠且切片破坏交互保真度。本文提出解耦交互与运动的轨迹分解策略：交互段（Interacting）保留专家演示中的稳定抓取构型，通过随机重排增加多样性；运动段（Moving）利用条件扩散强制（Conditional Diffusion Forcing）生成平滑过渡。扩散模型将轨迹合成视为序列补全，给定边界姿态 $\mathbf{p}_s, \mathbf{p}_e$ 与历史 $\mathbf{h}$，预测中间运动。形式化为 $\epsilon_\theta(g(\mathbf{x}^{[0]}, \mathbf{k}), \mathbf{k}, \mathbf{h}, \mathbf{p}_s, \mathbf{p}_e)$，其中 $g$ 为噪声函数，$\epsilon_\theta$ 为预测噪声残差的Transformer。该设计避免了刚性原语的局限，生成符合物理与运动学一致性的人类类轨迹，并通过外观随机化增强视觉鲁棒性。

## 实验评估

实验在自建衣物折叠场景中进行，对比真实数据、仿真遥操作数据与纯仿真生成数据在域内及域外（空间、纹理、光照、视角）的性能。基线覆盖真实数据训练、仿真遥操作训练及从头训练（De novo）设置，但缺乏与刚性物体SOTA方法的直接对比，因任务特性不同。

| 方法 | 域内成功率 (%) | 空间泛化 (%) | 纹理泛化 (%) | 光照泛化 (%) | 视角泛化 (%) | 平均 (%) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 真实数据 (π0.5) | 97 | - | - | - | - | - |
| 仿真遥操作 (π0.5) | 87 | - | - | - | - | - |
| 仿真生成 (π0.5) | 90 | 93 | 90 | 82 | 47 | 76 |
| 仿真生成 (π0) | 76 | 77 | 76 | 63 | 43 | 56 |

纯仿真数据训练的策略在域内达到90%成功率，接近真实数据的97%，差距为10%。在域外泛化中，仿真生成数据在空间、纹理、光照上分别比真实数据基线高50%、13%、47%，表明仿真多样性提升了鲁棒性。消融实验显示，引入变形稳定求解器后，域内成功率从47%提升至67%，平均成功率从33%提升至76%，证明求解器稳定性是泛化的关键。

| 方法 | 通过率 (%) | 域内成功率 (%) | 平均成功率 (%) |
| :--- | :--- | :--- | :--- |
| 基线 (MimicGen) | 0 | 0 | 0 |
| + 轨迹分解 + 扩散生成 | 65 | 47 | 33 |
| + 变形稳定求解器 | 40 | 67 | 76 |

评估边界方面，论文未报告置信区间，且材料校准依赖专家手动调参，限制了自动化程度。代码与数据已开源，但超参数细节未完全披露，可复现性受限于特定硬件（ARX ACONE）与扫描设备。

## 关联研究分析

从问题动机看，本文与DexNDM均关注接触丰富任务的动力学精度，但DexNDM侧重关节级神经动力学模型以克服域随机化在灵巧手任务中的不足，而本文聚焦软体求解器的稳定性以解决布料变形中的力传播滞后。这一差异源于任务对象的不同：DexNDM处理刚性关节与柔性手指的耦合，本文处理完全软体的衣物。DexNDM的神经模型可能更适应高自由度关节，而本文的AVBD扩展更直接针对软体网格的应变约束，两者在动力学建模粒度上存在互补性。

从方法设计看，本文与D-REX均强调闭环对齐，但D-REX通过可微仿真优化物体质量等参数，实现Real-to-Sim-to-Real的自动校准，而本文采用专家引导的行为一致性校准，不追求参数数值精确恢复。D-REX的可微方法计算开销大且依赖高质量场景重建，本文的专家校准虽成本低但缺乏自动化，且可能陷入局部行为一致而非全局物理一致。这种取舍反映了在软体任务中，行为一致性可能比参数精确性更关键，但论文未量化两者在长期稳定性上的差异。

## 总结

本文核心矛盾在于可变形操作数据稀缺与仿真物理失配，切入点在于主张仿真接地优先于数据规模化，通过几何、动力学、运动三重对齐构建物理一致仿真。SIM1利用高精度扫描、AVBD求解器及扩散轨迹生成，将有限演示转化为大规模合成数据，证明纯仿真数据在域内达到90%成功率，域外泛化提升50%。其边界在于材料校准依赖专家手动调参，且评估限于特定衣物类型与硬件。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
