> 导读 Transformer 架构中，注意力权重异常集中于无信息 Token 的现象被称为注意力汇聚（Attention Sink, AS），它导致量化误差放大、长上下文推理崩溃及模型可解释性缺失。现有研究多将 AS 视为可利用的缓存锚点或需规避的噪声，缺乏对其形成机理与系统性治理的统一框架。本文构建了“利用-解释-缓解”三维分类体系，整合了 Softmax 局限性、离群值电路等最新机理，并梳理了门控注意力等结构性缓解策略。该综述填补了 AS 研究的认知空白，但其作为文献综述，未提供新的实证数据以验证各缓解策略在不同模型规模下的通用性。

## 研究背景

当大语言模型（LLM）进行长序列推理时，Softmax 归一化强制将注意力权重之和约束为 1。若查询向量（Query）在上下文中缺乏强相关键（Key），冗余注意力质量被迫分配至特定位置，形成注意力汇聚（Attention Sink, AS）。AS 表现为对 `[BOS]` 等无信息 Token 的极端高注意力分数，这种数值异常不仅干扰模型对语义信息的捕捉，更在低精度量化中引发激活值离群，导致性能急剧下降。

注意力效率优化领域长期关注计算复杂度降低，如稀疏注意力与线性注意力，但往往忽视 AS 对数值稳定性的破坏。StreamingLLM 等工作发现保留初始 Token 可维持流式生成稳定，将 AS 定位为可利用特性；然而，这种被动保留并未解决 AS 对模型表达力的潜在抑制及量化瓶颈。随着 MoE 与多模态架构普及，AS 与专家路由、跨模态融合产生复杂交互，亟需从机理层面厘清其成因并探索主动消除路径。

本文切入点在于将 AS 从“经验现象”提升为“架构内生机制”，系统梳理其从利用到治理的演进。通过整合 Softmax 数学局限、离群值电路（Outlier Circuits）及隐式偏置（Implicit Attention Bias）等理论，本文揭示了 AS 的必然性，并评估了门控注意力等结构性缓解手段的有效性，为设计无 AS 依赖的下一代 Transformer 提供理论依据。

## 核心方法

### 方法参照系

AS 研究通常遵循“现象观测-启发式利用-后处理缓解”流程。早期工作聚焦于在 KV 缓存中保留 Sink Token 以维持推理稳定，属于被动利用。本文将其置于“失效机制分析与架构重构”类别，关键差异在于引入机理解释以指导结构性修改，而非仅依赖经验规则。

### 机理解释：Softmax 局限与离群值电路

AS 的根源在于 Softmax 的“和为 1”约束。当查询缺乏相关键时，注意力质量溢出至固定位置，形成数值水库。这一现象被解释为“无操作理论”（No-Op Theory），即 Sink Token 吸收冗余质量以维持数值稳定。进一步地，离群值电路理论指出，AS 与权重及激活值中的系统性离群点协同演化。在 MoE 架构中，少量“超级专家”（Super Experts）主导 Sink Token 的路由，剪除这些专家会导致 AS 崩溃及模型性能退化。公式上，AS Token 集合定义为累计注意力分数显著偏离全局均值的 Token：

$$ \mathcal{S} = \{ j \mid \hat{A}_j > \tau \mu_A \} $$

其中 $\hat{A}_j$ 为 Token $j$ 的累计注意力，$\mu_A$ 为全局均值，$\tau$ 为阈值。该定义量化了 AS 的极端数值特征，为检测提供依据。

### 战略缓解：门控注意力与修改 Softmax

针对 AS 的结构性缓解旨在切断其形成因果链。门控注意力机制引入输入依赖的门控参数，直接调制注意力输出，允许模型执行“无操作”更新，从而消除对 Sink Token 的依赖。实验表明，门控机制可将首 Token 注意力从 46.7% 降至 4.8%，激活峰度从 1657 降至 3.1，显著改善量化鲁棒性。修改 Softmax 函数（如 Softpick）通过软阈值截断低概率分数，直接抑制 AS 形成。这些方法从架构层面替代了隐式 AS 功能，实现了从“被动保留”到“主动消除”的范式转移。

## 实验评估

本文作为综述，未提供统一的新基准实验数据，主要引用已有工作结果。基线覆盖 Dense Attention、Sparse Attention 及量化基线，但缺乏与最新线性注意力（如 Mamba）在 AS 表现上的直接对比。引用数据显示，门控注意力在 LLaMA-2-7B 上显著降低首 Token 注意力占比与激活峰度，验证了结构性缓解的有效性。

消融分析显示，AS 强度受优化超参数影响：高学习率与权重衰减加剧 AS 形成，低学习率则延缓其出现。这一发现表明 AS 并非静态架构属性，而是训练动态的涌现结果。MoE 架构中，剪除 6,144 个专家中的 3 个超级专家即导致性能崩溃，揭示了 AS 与专家路由的强耦合性。

评估边界受限于综述性质，缺乏跨模型规模的统一量化指标。代码资源通过 GitHub 仓库提供，但各缓解策略的超参数配置未在文中统一标准化。可复现性依赖原始论文，本文未提供独立的复现脚本或基准测试套件。

## 关联研究分析

从问题动机看，本文与稀疏注意力研究（如 HySparse）存在根本分歧。稀疏注意力侧重通过限制 Token 交互范围降低计算复杂度，常将 AS 视为需保留的锚点以维持稳定性；本文则指出 AS 是数值不稳定的根源，主张通过门控机制主动消除。这一差异源于任务目标不同：前者追求效率-精度权衡，后者追求数值稳定性-表达力权衡。AS 治理如何与动态稀疏路由协同，避免消除 AS 后引入新的数值波动，是两者结合的关键盲区。

从方法设计看，本文与 StreamingLLM 形成互补。StreamingLLM 利用 AS 的稳定性实现无限长序列流式生成，属于“利用”范式；本文则整合了 Gated Attention 等“缓解”范式，旨在从架构上解除对 AS 的依赖。StreamingLLM 的局限性在于其性能高度依赖 Sink Token 的保留，一旦移除则崩溃；而门控注意力通过引入额外参数实现无 AS 依赖，但可能增加计算开销。查询侧增强在数据充足时是否仍有增益，论文未给出回答，需进一步实验验证。

## 总结

本文核心矛盾在于 AS 既是维持 Transformer 数值稳定的必要机制，又是限制量化精度与表达力的架构缺陷。现有方法多停留在经验性保留或后处理，缺乏对 AS 形成机理的系统解释。本文通过构建“利用-解释-缓解”三维框架，整合 Softmax 局限、离群值电路等理论，揭示了 AS 的涌现特性，并评估了门控注意力等结构性缓解手段。门控机制将首 Token 注意力从 46.7% 降至 4.8%，激活峰度从 1657 降至 3.1，证明了主动消除 AS 的可行性。然而，本文作为综述，未提供跨模型规模的统一实证数据，且门控注意力引入的额外参数是否抵消量化收益，在不同模型规模下的通用性如何，仍是亟待验证的问题。当模型规模扩大至万亿参数时，AS 的强度与缓解策略的有效性是否保持线性关系，论文未给出回答。
