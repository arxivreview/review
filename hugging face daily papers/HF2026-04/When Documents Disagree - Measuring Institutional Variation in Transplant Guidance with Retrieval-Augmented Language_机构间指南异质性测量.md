# HuggingFace最新推荐论文 ｜When Documents Disagree: Measuring Institutional Variation in Transplant Guidance with Retrieval-Augmented Language Models ｜机构间指南异质性测量

研究机构：美国卡内基梅隆大学

论文原文见 [arXiv](https://arxiv.org/abs/2603.21460)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.21460)

> 临床患者教育材料在不同医疗机构间存在显著差异，但缺乏量化手段。传统检索增强生成（RAG）关注模型幻觉，却忽略了源文档本身可能包含矛盾或缺失信息。本文利用RAG作为探针，对同一问题并行查询多个中心手册，通过五标签分类法量化分歧与缺失。该方法揭示了96.2%的覆盖缺口，但LLM裁判的准确性未经人工验证。

## 研究背景

当患者向不同移植中心询问“术后多久可以运动”时，得到的答案可能截然不同，甚至相互矛盾。这种机构间差异源于临床指南的非标准化，导致患者接收到的信息碎片化且不一致。为量化这种差异，需将非结构化的患者教育手册转化为可比较的结构化数据，这涉及文档解析与检索增强生成（RAG）技术。然而，传统RAG旨在从单一文档源生成最优答案，其核心假设是源文档内部一致且完整，这一假设在跨机构对比场景中失效。

现有临床NLP研究聚焦于从医患对话生成结构化笔记（如SOAP格式），或评估模型在静态问答基准（如MedQA）上的表现。这些工作隐含假设临床知识是统一的，模型的任务是准确提取或生成该统一知识。然而，在实体器官移植领域，国家注册数据显示不同中心在等待名单管理、术后随访协议上存在系统性差异。这种差异不仅存在于临床决策中，也延伸至面向患者的教育材料。当患者使用基于RAG的AI助手时，若系统仅接地于单一中心的手册，其回答将继承该机构的特定立场与遗漏，而非提供客观全面的医疗建议。

本文切入点在于将RAG从“答案生成工具”转化为“文档审计探针”。通过让同一问题并行查询多个中心的手册，并对比生成的答案，本文旨在测量机构间指南的异质性结构。这一视角转换使得研究焦点从“模型是否准确”转向“源文档是否一致”，揭示了患者教育材料中未被察觉的信息缺口与临床分歧。

## 核心方法

### 混合检索与接地生成

本文采用标准RAG流程作为基础参照系，但关键差异在于查询策略：对每个问题，并行查询所有相关中心的手册，而非选择单一最优源。文档解析使用LlamaParse将PDF转化为结构化JSON，保留章节标题与段落边界。检索阶段采用混合策略，结合BM25稀疏检索与FAISS稠密向量检索（使用BAAI/bge-large-en-v1.5编码器），通过倒数排名融合（RRF）合并候选集，并经交叉编码器重排序，选取Top-5段落作为上下文。生成模型为Qwen3-14B，温度设为0，指令要求仅基于提供上下文回答，若手册未涵盖该问题则输出“NOT ADDRESSED”。此设计将“幻觉”转化为可量化的“缺失”，区分了“无信息”与“错误信息”。

### 五标签一致性分类法

针对生成的多组答案，本文引入五标签分类法进行两两对比，替代传统的BLEU/ROUGE文本重叠指标。该分类法直接衡量临床语义分歧，定义如下：

$$
M_{ij} = \text{Judge}(Q, A_i, A_j) \in \{\text{ABSENT, CONSISTENT, COMPLEMENTARY, DIVERGENT, CONTRADICTORY}\}
$$

其中 $M_{ij}$ 表示中心 $i$ 与 $j$ 对问题 $Q$ 的答案关系。ABSENT表示至少一方未涵盖该话题；CONSISTENT表示建议相同；COMPLEMENTARY表示临床兼容但细节或范围不同；DIVERGENT表示存在实质性临床差异（如不同阈值或时间线）；CONTRADICTORY表示直接对立。LLM裁判（Qwen3-14B）以贪心解码方式输出分类标签、临床理由及显著性评分。此设计动机在于，传统指标无法捕捉“临床意义”上的分歧，而五标签法能区分“互补”与“矛盾”，为异质性分析提供细粒度语义基础。

### 异质性度量与聚合

基于两两对比矩阵，本文定义问题级分歧率与一致性率，并聚合至器官、主题及中心层级。对于问题 $q$，其分歧率 $r_{div}(q)$ 计算为：

$$
r_{div}(q) = \frac{|\{(i,j) : M_{ij}^{[q]} \in \{\text{DIVERGENT, CONTRADICTORY}\}\}|}{|\{(i,j) : M_{ij}^{[q]} \neq \text{ABSENT}\}|}
$$

该公式衡量非缺失答案对中，存在临床显著分歧的比例。一致性率 $r_{con}(q)$ 类似计算，但分子为CONSISTENT对数。在器官或主题层级 $g$，平均分歧率 $R_{div}(g)$ 为该组所有问题的 $r_{div}$ 均值。此外，报告“分歧存在率”（%Div），即 $r_{div} > 0$ 的问题比例。此双指标设计区分了“分歧普遍存在”与“分歧集中于少数问题”两种模式，避免了单一均值掩盖分布偏斜的问题。

## 实验评估

实验基于102份来自23个美国移植中心的手册及1,115个基准问题。基准问题源自患者论坛、医疗组织Q&A等，涵盖五种器官类型及13个临床主题。由于本文旨在测量异质性而非竞争SOTA，未设置传统基线对比，而是通过内部统计描述异质性结构。

| 指标 | 数值 |
| :--- | :--- |
| 总手册对数 | 1,772,261 |
| ABSENT对数 | 1,704,242 |
| 非ABSENT对数 | 68,019 |
| DIVERGENT对数 | 14,132 |
| CONTRADICTORY对数 | 143 |
| 整体缺失率 | 96.2% |
| 非缺失对分歧率 | 20.8% |

核心发现显示，96.2%的手册-问题对为ABSENT，表明覆盖缺口是主要问题。在非缺失对中，20.8%为DIVERGENT，0.2%为CONTRADICTORY。器官层面，肺（41.8%）与肾（39.8%）的分歧存在率最高，胰腺最低（11.0%）。主题层面，监测与随访（$R_{div}=0.277$）及生活方式（$R_{div}=0.235$）分歧最高，反映缺乏全国标准化指南。生殖健康缺失率达95.1%，表明多数手册未涉及移植后生育指导。

评估边界方面，LLM裁判的分类准确性未提供人工标注一致性检验（如Cohen's Kappa），存在系统性偏差风险。检索管道虽采用混合策略，但未消融不同检索器对分歧率的影响。此外，仅处理文本内容，忽略手册中的表格与图像，可能低估覆盖范围。代码未公开，复现依赖LlamaParse、FAISS及Qwen3-14B的具体配置。

## 关联研究分析

从问题动机看，本文与Source-Aware Evaluation（Faisal, 2026）共享“源感知”思想，但后者关注评估指标对不同数据源的敏感性，本文则直接量化源文档间的语义分歧。差异根源在于任务特性：Source-Aware Evaluation假设源文档是评估基准，本文则视源文档为被审计对象。这种视角转换使得本文能揭示“文档选择即临床决策”的隐含假设，而传统评估框架无法捕捉此层。

从方法设计看，本文的RAG应用与MED-COPILOT（Chen et al., 2026）形成对比。MED-COPILOT利用GraphRAG增强诊断推理，目标是提升单一答案的准确性；本文利用RAG暴露多源答案的异质性，目标是测量分歧结构。差异源于目标函数不同：前者优化事实接地，后者优化异质性度量。本文未探索检索噪声对分歧率的干扰，若检索失败导致错误段落被接地，可能产生虚假分歧。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文核心矛盾在于患者教育材料的机构间异质性缺乏量化手段，现有RAG方法假设源文档一致，无法暴露文档本身的矛盾与缺失。本文抓住“RAG作为探针”的切入点，通过并行查询多源手册并对比答案，实现了异质性的结构化测量。实验证明96.2%的覆盖缺口与20.8%的非缺失对分歧率，揭示了生殖健康等关键领域的系统性遗漏。边界在于LLM裁判的准确性未经人工验证，且仅处理文本内容，忽略多模态信息。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
