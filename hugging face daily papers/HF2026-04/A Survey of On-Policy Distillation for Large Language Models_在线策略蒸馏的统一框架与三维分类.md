# HuggingFace最新推荐论文 ｜A Survey of On-Policy Distillation for Large Language Models ｜在线策略蒸馏的统一框架与三维分类

作者：Mingyang Song、Mao Zheng

论文原文见 [arXiv](https://arxiv.org/abs/2604.00626)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.00626)

> 大语言模型知识蒸馏长期受限于离线训练与在线推理间的分布失配，导致误差在自回归生成中累积。现有研究虽已涌现出多种在线策略蒸馏方法，但缺乏统一的数学表述与系统分类，导致不同社区的方法难以横向对比。本文通过构建基于 f-散度 的统一目标函数，并从反馈信号、教师访问、损失粒度三个维度对现有方法进行正交分类，揭示了看似独立的方法实为同一设计空间下的不同参数化。该工作填补了理论整合的空白，但其作为综述未提供新的算法性能数据，且对黑盒场景下的信息损失量化仍停留在定性分析层面。

## 研究背景

自回归语言模型在推理时需基于自身生成的前缀预测下一个 Token，而传统知识蒸馏（Knowledge Distillation, KD）通常在教师生成的完美序列或静态数据集上训练学生模型。这种训练分布 $d_D(s)$ 与推理时学生自身策略诱导的状态分布 $d_{\pi_\theta}(s)$ 之间的不一致，被称为曝光偏差（Exposure Bias）。在模仿学习理论中，若学生策略在每步存在误差 $\epsilon$，离线训练导致的总误差随序列长度 $T$ 呈 $O(T^2)$ 增长，这使得长链推理任务中的小模型极易陷入幻觉或逻辑断裂。

为缓解此问题，在线策略蒸馏（On-Policy Distillation, OPD）让学生模型实时采样轨迹，并接收教师在这些自生成状态下的反馈。尽管 GKD、MiniLLM 和 DistiLLM 等方法相继提出，但它们源自知识蒸馏、强化学习（RL）和模仿学习不同社区，使用不同的术语和评估协议，且缺乏统一的理论框架来解释其有效性差异。现有综述多将 OPD 视为离线 KD 的变体，忽视了其在优化动力学和失败模式上的本质区别。本文旨在通过数学统一和系统分类，厘清 OPD 的设计空间，识别被忽视的挑战，并为后续研究提供理论坐标。

## 核心方法

### 统一 f-散度目标函数

传统 KD 框架通常固定使用前向 KL 散度（Forward KL, FKL）或反向 KL 散度（Reverse KL, RKL），且假设训练数据来自固定分布。本文的核心创新在于将 OPD 形式化为一个通用的序列决策问题，解耦了轨迹采样策略与局部散度度量。设计动机在于揭示 GKD、MiniLLM 等方法并非孤立创新，而是同一数学结构下的不同参数选择。

本文提出的统一目标函数为：

$$ \mathcal{L}_{OPD}(\theta) = \mathbb{E}_{y \sim \pi_{mix}} \left[ D_f(p_T(\cdot|y_{<t}), p_\theta(\cdot|y_{<t})) \right] $$

其中 $\pi_{mix}$ 是行为策略，决定了训练轨迹的来源（学生自采样、教师生成或混合）；$D_f$ 是由凸生成函数 $f$ 定义的 f-散度。该公式的物理含义是：在由 $\pi_{mix}$ 驱动的状态空间中，最小化教师分布与学生分布在每个 Token 位置上的散度。通过调整 $f$ 的凸性参数和 $\pi_{mix}$ 的混合比例，可以连续地在模式覆盖（Mode-Covering）与模式寻求（Mode-Seeking）之间切换，从而适配不同任务对多样性或精确性的需求。

### 三维正交分类体系

在统一数学框架之上，本文进一步构建了三维分类体系，以解决现有文献碎片化的问题。设计动机在于，单一维度（如仅按散度类型分类）无法捕捉部署约束（如教师是否开源）和信号密度（如 Logits 还是标量奖励）对方法可行性的影响。

该分类体系沿三个正交轴展开：

1.  **反馈信号（Feedback Signal）**：区分基于 Logits 的分布匹配、基于结果（Outcome）的标量奖励、以及无教师的自博弈（Self-Play）。

2.  **教师访问（Teacher Access）**：区分白盒（White-Box，可获取完整 Logits）、黑盒（Black-Box，仅获取生成文本或评分）、以及自蒸馏（Self-Distillation，无外部教师）。

3.  **损失粒度（Loss Granularity）**：区分 Token 级、序列级（Sequence-Level）及混合自适应粒度。

这一分类揭示了设计空间中的空白区域，例如“黑盒 + 序列级 + 自适应散度”的组合尚未被充分探索。它表明，方法的选择不仅取决于数学最优性，还受限于工程部署条件，如教师模型的 API 限制或计算预算。

## 实验评估

本文作为综述，未提出新的算法或进行独立的基准测试，其“实验”部分主要体现为对现有代表性方法的配置汇总与理论对比。由于缺乏新的实验数值，无法构建基于新数据的性能对比表格。

在基线覆盖审计方面，本文系统梳理了白盒方法（如 GKD, MiniLLM, DistiLLM）、黑盒方法（如 GAD, Lion）及自博弈方法（如 SPIN, OPSD）。值得注意的是，本文在 Table 2 中详细列出了各方法的教师/学生模型规模、损失函数及主要任务，但并未提供统一的算力消耗对比。例如，MiniLLM 基于 REINFORCE 推导，计算方差较高，而 DistiLLM 通过偏斜 KL 散度降低方差，但两者在相同算力预算下的收敛速度差异未在文中量化。

评估边界方面，本文指出当前评测体系存在方法贡献与骨干网络贡献混淆的问题。例如，某些 OPD 方法的优势可能源于其特定的预训练数据或架构，而非蒸馏算法本身。此外，黑盒 OPD 在理论上必然低于白盒 OPD 的信息保真度，但本文未提供在同等算力下两者的性能差距量化数据，仅定性分析了从完整概率分布到 Top-k 生成的信息损失。可复现性方面，本文未提供代码库，但引用的 GKD、MiniLLM 等方法均有开源实现，读者可据此复现对比实验。

## 关联研究分析

从问题动机看，本文与 MiniLLM（Gu et al., 2024）存在显著差异。MiniLLM 聚焦于解决 FKL 在长尾分布上的过估计问题，通过引入 RKL 和策略梯度优化实现模式寻求，其核心假设是教师分布是固定的且可访问。而本文指出，MiniLLM 的 REINFORCE 推导在高维组合空间中方差极大，导致训练不稳定。本文的切入点在于将 MiniLLM 视为统一框架中 $\pi_{mix}$ 包含教师混合比例、$D_f$ 为 RKL 的特例，并强调 DistiLLM（Ko et al., 2024）通过偏斜 KL 散度在保持模式寻求特性的同时降低了方差。这一差异揭示了单纯改变散度度量不足以解决 OPD 的稳定性问题，必须同时考虑采样策略与散度函数的耦合效应。

从方法设计看，本文与 GKD（Agarwal et al., 2024）的关系更为紧密，但视角不同。GKD 提出了混合采样策略，允许在教师序列和学生序列之间切换，但其散度选择（FKL/RKL/JSD）是静态的。本文则进一步指出，最优散度应随 Token 位置的教师分布熵动态调整。例如，在推理关键 Token 上，教师分布通常是单峰的，RKL 更优；而在生成灵活 Token 上，分布接近均匀，FKL 更能保留多样性。这种动态适应机制（如 ToDi, Entropy-Aware OPD）是 GKD 未探索的盲区，也是本文分类体系中“自适应”维度的核心。

## 总结

本文旨在解决 OPD 文献碎片化及缺乏统一理论解释的问题。其切入点在于将分散的方法重新定位为 f-散度框架下的不同参数化，并通过三维分类体系厘清设计空间。本文证明了从离线到在线策略的转变是消除曝光偏差的关键，且散度选择需根据任务特性动态调整。然而，本文的边界在于其综述性质，未提供新的算法性能数据，且对黑盒场景下的信息损失缺乏量化对比。当教师模型仅暴露 Top-k 生成结果时，黑盒 OPD 在同等算力下与白盒 OPD 的性能差距是否随模型规模扩大而收敛，本文未给出回答。
