> 统一多模态模型（UMMs）旨在单一架构中融合视觉理解与图像生成，但受限于静态参数记忆，难以准确还原长尾概念的身份特征。现有智能体方案多为松耦合的多API拼接，导致检索证据与生成过程割裂，无法将外部知识有效转化为视觉约束。本文提出 Unify-Agent，通过端到端统一模型内的“思考-检索-重述-生成”闭环，将多模态证据重构为结构化文本指令。该方案在事实性基准上显著优于基线，但其性能上限是否受限于骨干网络能力，以及推理延迟的工程代价，仍存疑。

## 研究背景

当生成模型面对稀有知识产权（IP）或历史人物时，常出现身份漂移或属性缺失。这并非渲染质量不足，而是模型缺乏关于目标实体“长什么样”的世界知识。这种知识缺失源于预训练阶段的参数固化，即“闭卷生成”（Closed-Book Generation）范式。模型无法在推理时更新其内部表征，导致对长尾概念的理解停留在模糊的语义层面，无法提取定义身份的关键视觉线索。

当前解决此问题的主流路线分为两类：一是纯参数优化，如通过强化学习（RL）提升模型对世界知识的内化能力，代表工作如 AlphaGRPO；二是智能体检索，通过外部工具获取信息。然而，现有的智能体文本到图像（T2I）系统多采用脆弱的多阶段流水线，将大语言模型（LLM）规划器、检索工具和独立图像生成器松散连接。这种解耦架构导致证据获取、多模态推理与视觉合成处于分离状态，检索到的文本往往缺乏细粒度视觉属性，而参考图像则可能包含无关背景，难以直接作为生成条件。

本文的切入点在于指出“检索”与“生成”之间的转化断层。核心挑战不仅是获取外部知识，更是如何将多模态证据转化为既保留源知识保真度又符合用户意图的视觉指导。Unify-Agent 摒弃了松耦合的 API 拼接，主张在统一多模态模型内部实现认知缺口检测、证据获取与生成的原生耦合，通过“重述”（Recaption）机制作为理解与生成之间的桥梁，解决证据转化的“最后一公里”问题。

## 核心方法

### 方法参照系

本文基于 Bagel 架构，该架构采用混合 Transformer（Mixture-of-Transformers, MoT）设计，通过专用专家分别处理自回归文本理解与基于整流流（Rectified Flow）的图像生成。与传统的解耦智能体不同，本文的关键差异在于将检索、推理与生成整合在单一模型权重内，利用共享的视觉编码器同时服务于理解与生成路径。

### 多模态证据的重述机制

传统智能体将检索到的原始文本或图像直接拼接至提示词中，这导致冗余信息干扰指令遵循，或参考图像过度约束生成灵活性。本文引入 Recaption 阶段，将检索证据转化为结构化文本约束。该机制利用 Bagel 中视觉 Transformer（ViT）与变分自编码器（VAE）的协同作用：ViT 提取高层语义以识别实体身份，VAE 保留低层纹理与几何细节。重述过程并非简单的语言任务，而是多模态理解问题，其目标是将视觉证据 $v$ 和文本证据 $t$ 映射为生成导向的规格说明 $s$：

$$ s = f_{recaption}(v, t; C) $$

其中 $C$ 为多模态上下文。这一设计解决了原始证据中“身份线索”与“场景构图”混杂的问题，显式解耦了保持身份的关键特征与场景组合要求，使得生成器能更精准地执行事实性约束。

### 端到端智能体闭环

Unify-Agent 将生成过程重构为推理时的顺序决策过程，包含 THINK（提示理解与缺口检测）、RESEARCH（主动获取文本与视觉知识）、RECAPTION（证据重构）和 GENERATE（最终合成）。在生成阶段，模型基于重述后的规格说明 $s$ 执行整流流匹配，最小化潜空间中的流匹配目标：

$$ \mathcal{L}_{flow} = \mathbb{E}_{t \sim U(0,1), z_t} \| u_\theta(z_t, t; s) - u_{[t]}(z_t, t) \|^2 $$

其中 $u_\theta$ 为预测的速度场，$u_{[t]}$ 为目标向量场。这种端到端设计消除了多 API 调用带来的级联误差，使得模型在检索阶段能根据生成需求动态调整证据获取策略，实现了认知与生成的原生耦合。

## 实验评估

实验在 FactIP、WiSE、KiTTEN 和 T2I-FactualBench 上进行，基线涵盖商业模型（如 GPT-Image-1.5）、纯生成模型（如 FLUX.1-dev）及统一多模态模型（如 Bagel、Janus-Pro）。Unify-Agent 在开源统一模型中表现最优，但在 WiSE 基准上略低于基于 RL 优化的 AlphaGRPO（据领域综述，AlphaGRPO 为 0.79.5，本文 Unify-Agent 为 0.77），表明智能体检索在知识密集型任务上具有竞争力，但非绝对最优。

| 基准 | 模型 | 整体得分 | 关键维度/备注 |
| :--- | :--- | :--- | :--- |
| FactIP | Unify-Agent | 73.2 | Relevance 72.4, 较 Bagel 提升 22.3 分 |
| FactIP | Bagel | 50.9 | 基线模型 |
| WiSE | Unify-Agent | 0.77 | Cultural 0.82, Chemistry 0.70 |
| KiTTEN | Unify-Agent | 4.08 | Text Align 4.22, Entity Align 3.93 |

消融实验揭示了 Recaption 机制的核心价值。移除图像检索导致整体得分从 73.2 降至 56.2，Relevance 维度从 72.4 骤降至 50.8，证实视觉证据对身份保真的决定性作用。移除 Recaption 阶段，整体得分降至 62.9，表明原始证据并非最优条件信号，必须经过结构化重构。此外，移除 VAE 分支导致 Relevance 下降 12.1 分，验证了低层感知潜变量在细粒度属性绑定中的必要性，支持了“生成先验增强理解”的架构洞察。

评估协议采用 MLLM-as-a-Judge，FactIP 使用 Seed2.0 作为评估器，其他基准使用 ChatGPT-4o。该协议虽具可扩展性，但缺乏置信区间报告，且 FactIP 仅 2,462 个样本，统计显著性需进一步验证。代码已开源，但论文未报告端到端智能体的推理延迟，这是评估其实际部署可行性的关键缺失维度。

## 关联研究分析

从方法设计看，Unify-Agent 与 ToolArtist 同属智能体生成框架，但架构选择存在根本差异。ToolArtist 依赖外部工具调用与独立生成器，而 Unify-Agent 将检索与生成整合于 Bagel 统一模型内。这种差异源于对“证据转化”效率的不同假设：解耦架构中，LLM 难以精确描述视觉细节，导致生成器接收到的指令模糊；统一架构中，VAE 潜变量直接参与重述，使得视觉细节能被更忠实地转化为文本约束。然而，这种端到端设计是否导致推理延迟显著高于解耦流水线，论文未提供数据，这可能限制了其在实时应用中的推广。

从知识获取路线看，Unify-Agent 代表检索增强路线，与 AlphaGRPO 代表的 RL 优化路线形成对比。在 WiSE 基准上，Unify-Agent（0.77）略低于 AlphaGRPO（0.79.5）。这一差距暗示，对于某些知识密集型任务，参数内化的世界知识可能比外部检索更稳定，或者 RL 优化能更好地对齐人类偏好。Unify-Agent 的优势在于处理长尾、稀有 IP 等参数记忆缺失的场景，而在通用知识领域，RL 优化可能更具优势。两者结合——即用 RL 优化 Recaption 策略以提升检索精度——可能是未来提升事实准确性的方向，但本文未探索此路径。

## 总结

Unify-Agent 旨在解决统一多模态模型在长尾概念生成中的世界知识缺失问题。现有解耦智能体因证据与生成割裂，无法有效转化外部知识；本文通过端到端统一模型内的 Recaption 机制，将多模态证据重构为结构化生成约束，实现了认知与生成的原生耦合。实验显示，该方法在 FactIP 上较基线 Bagel 提升 22.3 分，在 KiTTEN 上超越 Imagen-3，证明了其在身份一致性上的优势。然而，论文未报告推理延迟，且在 WiSE 上略逊于 RL 优化方法，暴露了其在通用知识对齐上的局限。当支持集增大或知识密度降低时，端到端智能体的边际收益是否递减，论文未给出回答。
