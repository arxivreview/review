> 现有科学基准依赖已发表文献，导致模型在证据不足时倾向于猜测而非弃权，且无法隔离参数化先验对数据推理的干扰。InfiniteScienceGym 通过种子驱动的模拟器生成具备“不可回答”真值的科学仓库，强制模型在受控环境中执行数据接地与弃权判断。该基准揭示了当前最强模型准确率不足 45% 且弃权识别能力薄弱的现状，为评估 LLM 的科学严谨性提供了无存储约束的新范式，但其程序化数据分布与真实科研噪声的差异仍存疑。

## 研究背景

当 LLM 被部署为科学助手时，其核心挑战从知识检索转向对实证数据的严谨推理。这一过程要求模型不仅能从文件系统中提取信息，还需在数据缺失或定义冲突时识别出“不可回答”状态，即弃权（Abstention）。弃权能力是科学严谨性的底线，但传统问答任务往往奖励猜测，导致模型在证据不足时仍输出高置信度的错误结论。

当前评估 LLM 科学推理的基准主要基于已发表研究或人工标注的真实数据集。这类基准存在结构性缺陷：已发表文献存在发表偏倚，过度呈现“干净”的阳性结果，缺乏“问题不可解”的负样本；同时，模型可能依赖参数化先验而非实际数据来回答熟悉领域的问题，使得数据推理与知识记忆难以解耦。此外，真实数据的人工标注引入标签噪声，且大规模语料的存储与分发受法律与成本限制。

InfiniteScienceGym 的切入点在于通过程序化生成消除上述混杂因素。它不依赖静态语料，而是从随机种子生成自包含的科学仓库，并通过特权访问底层生成过程，构造出真值绝对确定的“可回答”与“不可回答”问题。这种设计将评估焦点从“模型知道什么”转移到“模型如何从给定数据中推导结论”，并直接量化模型在证据不足时的弃权行为。

## 核心方法

### 方法参照系

本文问题属于科学数据推理基准构建，但区别于传统静态基准。通用流程通常依赖真实数据集与人工标注，而本文采用“模拟器→QA生成器→改写模块”的程序化管线，关键差异在于通过代码级特权访问保证真值的可验证性与不可回答性的构造性存在。

### 种子驱动的仓库模拟

模拟器从分层分类法中采样科学领域，生成项目规范、目录结构及文件内容。所有随机选择均由种子 $s$ 确定性推导，确保仓库 $\mathcal{R}_s$ 的可复现性。文件变量分为独立变量与依赖变量，独立变量采样自指定分布，依赖变量由 Python 函数 $f(\mathbf{x})$ 生成，其中 $\mathbf{x}$ 包含路径变量与独立变量：

$$ y = f(\mathbf{x}_{path}, \mathbf{x}_{indep}) + \epsilon $$

该设计动机在于解决真实数据中变量关系不可控的问题，通过显式定义生成函数，使数据中的因果结构与噪声过程完全透明，为后续真值计算提供基础。

### 特权QA生成与弃权构造

QA生成器利用对模拟器内部状态的访问权限，生成模板化问题。对于可回答问题，直接计算统计量作为真值；对于不可回答问题，通过构造过滤条件导致无数据行、或变量类型不匹配（如对分类变量求中位数）来确保答案不存在。不可回答性的判定基于数据完备性约束：

$$ \text{Unanswerable} \iff \left| \{ r \in \mathcal{R} \mid \phi(r) \} \right| = 0 \lor \text{TypeMismatch}(y) $$

其中 $\phi(r)$ 为问题中的过滤条件。这一设计解决了传统基准中“不可回答”标签依赖专家主观判断的噪声问题，实现了弃权评估的绝对客观性。

### 自然语言改写模块

为消除模板化问题的表面形式偏差，改写模块基于项目规范将模板问题转换为自然语言查询。该模块不改变问题的语义真值，仅调整表述方式，用于评估模型对表面形式变化的鲁棒性。通过对比模板与改写版本的模型响应一致性，可量化模型推理的稳定性，而非仅关注最终答案的正确性。

## 实验评估

实验从 500 个仓库中采样 500 个问题，评估 GPT-5.4、Claude Opus 4.6 等专有模型及 GPT-OSS 20B 等开源模型。基线覆盖主流 LLM，但缺乏针对弃权优化的专用模型（如 Feng et al., 2024 提出的方法），这可能高估了通用模型在弃权任务上的相对表现。

| 模型 | 总体准确率 (%) | 不可回答检测 Precision (%) | 不可回答检测 Recall (%) |
| :--- | :--- | :--- | :--- |
| GPT-5.4 | 44.8 | 82.0 | 81.5 |
| Claude Opus 4.6 | 35.5 | 81.0 | 80.5 |
| GPT-OSS 20B | 29.1 | 80.5 | 80.0 |
| Qwen3 4B Instruct | 24.6 | 80.0 | 80.0 |
| Gemma 3 27B it | 23.1 | 80.0 | 80.0 |

专有模型在总体准确率上领先开源模型至少 6.4 个百分点，且在不可回答检测的 Precision 与 Recall 上均超过 80%。开源模型呈现高 Precision 低 Recall 的特征，表明其倾向于在证据不足时强行作答，而非正确弃权。

| 模型 | 平均 Token 数 (千) | 平均工具调用次数 |
| :--- | :--- | :--- |
| GPT-5.4 | 24.0 | 5.0 |
| Claude Opus 4.6 | 30.0 | 4.0 |
| GPT-OSS 20B | 40.0 | 3.0 |
| Qwen3 4B Instruct | 50.0 | 2.0 |
| Gemma 3 27B it | 60.0 | 2.0 |

GPT-5.4 以最低 Token 消耗（约 24,000）取得最高准确率，且工具调用次数最多。这表明高性能模型通过程序化分析（代码执行）而非上下文堆叠来处理数据，Token 使用量并非努力程度的有效代理指标。

评估协议通过 Krippendorff’s Alpha 衡量模板与改写问题的一致性，得分在 0.68-0.71 之间，表明表面形式变化引入中等程度的噪声。代码与提示词将公开，但程序化生成的数据分布是否充分代表真实科研数据的复杂性，论文未提供量化对比。

## 关联研究分析

从问题动机看，InfiniteScienceGym 与 SimulBench 同属模拟评估路线，但 SimulBench 聚焦于交互式控制，而本文聚焦于文件系统导航与数据推理。ALCUNA 使用合成实体测试冲突知识下的模型表现，本文则聚焦证据不足下的弃权行为。两者的核心差异在于：ALCUNA 测试模型在“知道错误”时的鲁棒性，本文测试模型在“不知道”时的诚实性。这种差异源于任务特性：科学数据推理中，数据缺失是常态，而知识冲突是特例。

从方法设计看，本文与 SciCode 同涉及科学代码与文件操作，但 SciCode 缺乏对“不可回答”情况的显式评估。本文引入特权访问机制，使 QA 生成器能直接读取底层数据生成过程，从而构造出真值确定的不可回答问题。这一设计解决了传统基准中不可回答标签依赖人工标注的噪声问题，但也引入了程序化数据与真实数据分布差异的风险。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

InfiniteScienceGym 旨在解决 LLM 科学推理中数据接地与弃权评估的混杂问题，通过程序化生成具备绝对真值的科学仓库，实现了无存储约束的受控评估。实验表明，最强模型 GPT-5.4 准确率仅为 44.8%，且所有模型在不可回答检测上均存在显著缺陷，开源模型尤其倾向于强行作答。该基准通过特权访问机制保证了真值的可验证性，但其程序化生成的数据分布与真实科研噪声的差异未经验证。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
