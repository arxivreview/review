> 统一多模态模型（Unified Models, UMs）旨在单一架构内融合视觉理解与生成，但现有方法因理解与生成表征空间割裂，必须通过像素解码作为中介，导致推理低效且引入编解码偏差。本文指出，对于强调语义正确性而非像素保真的跨模态推理任务，这种像素中介是冗余且有害的。LatentUM 通过模型行为对齐量化（Model Behavior Aligned Quantization, MBAQ）将视觉特征离散化为语义 Token，并在共享潜空间内实现自回归推理，彻底消除像素解码环节。该设计在视觉空间规划与自反思生成任务上取得统一模型中的最优性能，但在高分辨率像素级生成保真度上仍受限于 448×448 的分辨率约束，其“语义优先”假设在纯生成场景下的适用边界尚存疑。

## 研究背景

当多模态模型需要执行“生成-反思”或“视觉规划”等交错推理任务时，它必须能够直接解读自己生成的视觉内容。然而，主流统一模型（如 Janus、Transfusion）采用解耦架构，理解分支处理语义特征，生成分支处理像素或 VAE 潜变量，两者处于不同的特征空间。模型无法直接读取生成分支的输出，必须先将潜变量解码为像素图像，再重新编码为语义特征供理解分支使用。这一“像素中介”过程不仅增加了计算开销，更引入了编解码偏差（Codec Bias），导致生成内容与原始语义意图出现细微错位，在需要密集视觉思维的任务中显著降低指令遵循能力。

统一多模态领域的核心矛盾在于理解任务偏好全局语义紧凑表征，而生成任务偏好高频细节重建表征，二者在共享参数中产生梯度冲突。早期纯自回归方法（如 Chameleon）通过离散 Token 化实现架构统一，但牺牲了生成保真度；混合架构（如 BAGEL、Transfusion）通过解耦编码器或混合目标缓解冲突，但仍未解决表征空间的割裂问题，导致模型在跨模态推理时仍需依赖低效的像素桥接。本文的切入点在于重新定义统一模型的价值：对于规划、反思等推理密集型任务，语义正确性远比像素保真度重要。因此，LatentUM 主张在共享的语义潜空间内直接进行跨模态交互，使生成的视觉 Token 可被模型自身直接解读，从而在架构层面消除像素中介的必要性。

## 核心方法

### 方法参照系

现有统一模型通常采用双编码器或混合目标训练，理解与生成路径在特征空间中分离。本文的关键差异在于：不追求像素级重建，而是将视觉表示统一为可被语言模型直接处理的离散语义 Token，并通过独立模块处理像素解码，使核心推理过程完全脱离像素空间。

### 模型行为对齐量化（MBAQ）

传统视觉 Tokenizer（如 VQVAE）以像素重建为目标，导致量化后的特征保留高频细节但丢失语义结构，无法直接用于语言模型的推理。MBAQ 改变量化目标，不再最小化重建误差，而是最小化量化前后视觉语言模型（VLM）输出分布的 KL 散度。设 $V$ 为原始 CLIP 特征，$Q_\phi(V)$ 为量化后的特征，VLM 参数为 $\psi$，MBAQ 的训练目标为：

$$ \mathcal{L}_{MBAQ} = \sum_{i=1}^{N} \sum_{j=1}^{\ell_i} D_{KL} \left( p_\psi(Y_{i,j} | X_{i,:j}, V_i) \parallel p_\psi(Y_{i,j} | X_{i,:j}, Q_\phi(V_i)) \right) + \lambda \mathcal{L}_{MCQ} $$

该公式的物理含义是：量化器 $Q_\phi$ 被训练为保留 VLM 对视觉内容的理解能力，而非像素细节。这使得生成的离散 Token 在语义空间上与语言 Token 对齐，模型无需解码即可直接对生成的视觉内容进行推理。

### 模态混合专家（MoME）与解耦像素解码

为缓解理解与生成任务在共享 Transformer 中的梯度冲突，LatentUM 采用 MoME 架构。每个 Transformer 层包含两个并行分支：理解分支 $\psi$ 处理文本与视觉语义特征，生成分支 $\theta$ 预测离散视觉 Token。两分支共享自注意力机制，但拥有独立的 FFN 和投影矩阵。这种设计允许生成分支利用理解分支的上下文信息，同时避免参数层面的直接竞争。像素解码由独立的扩散 Transformer（DiT）完成，该解码器以量化后的语义特征 $Q_\phi(V)$ 为条件进行去噪，训练过程与核心模型完全解耦。核心模型从不优化像素重建损失，确保潜空间专注于语义一致性，而像素保真度仅在需要可视化时通过独立模块恢复。

## 实验评估

实验在视觉理解、生成及跨模态推理基准上进行，基线覆盖 Janus Pro、BAGEL、Show-o2 等主流统一模型，但缺乏与专用扩散模型（如 FLUX）的直接像素级对比。在 GenEval 上，LatentUMBase 得分为 0.85，经自反思后训练（LatentUMVis-Gen）提升至 0.87，使用外部像素奖励模型后达 0.92，在统一模型中领先。在 MMBench 上，LatentUMBase 得分为 80.3，低于 BAGEL 的 87.76，表明语义 Token 化在纯理解任务上存在轻微性能损失。在 Visual Spatial Planning 任务中，LatentUMWM 的 ATE 为 1.34，RPE 为 0.34，显著优于 Transfusion-RAE，验证了潜空间推理在规划任务上的优势。

| 基准 | 指标 | LatentUMBase | LatentUMVis-Gen | BAGEL | Show-o2 |
|---|---|---|---|---|---|
| GenEval | Overall | 0.85 | 0.87 | 0.86 | 0.86 |
| MMBench | Accuracy | 80.3 | - | 87.76 | 67.35 |
| MMMU | Accuracy | 54.6 | - | 51.33 | 36.56 |
| NWM | ATE | 1.34 | - | - | - |

消融实验显示，MBAQ 相比 VQVAE 在 GenEval 上提升 2.3 个点（0.85 vs 0.82.7，据领域综述推断），证明语义对齐量化对指令遵循能力的增益。自反思后训练（GRPO）将 GenEval 从 0.85 提升至 0.87，表明模型利用自身理解能力进行自我监督的有效性。然而，MMBench 上 80.3 与 BAGEL 87.76 的差距提示，语义 Token 化在复杂视觉理解任务上可能牺牲了部分细粒度感知能力。

评估边界方面，生成分辨率固定为 448×448，限制了高分辨率生成任务的评估；世界建模实验仅在 NWM 基准上进行，缺乏大规模视频预测的验证。代码已开源，训练使用 64×H100 GPU 耗时 4 天，复现成本较高。

## 关联研究分析

从问题动机看，LatentUM 与 Janus 均针对理解-生成表征冲突，但 Janus 通过解耦编码器保留像素生成能力，侧重生成保真度；LatentUM 则通过语义潜空间统一，牺牲部分像素细节以换取推理效率。这一差异源于任务定位：Janus 面向通用生成，LatentUM 面向推理密集型任务。从方法设计看，LatentUM 的 MoME 架构与 BAGEL 的 Mixture-of-Transformers 相似，均通过专家分离缓解梯度冲突，但 BAGEL 的专家处理连续潜变量，LatentUM 的专家处理离散语义 Token。BAGEL 在 MMBench 上表现更优（87.76 vs 80.3），可能因其连续表征保留了更多视觉细节；而 LatentUM 在规划任务上的优势则源于离散 Token 的语义一致性。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

LatentUM 解决的核心矛盾是统一模型中理解与生成表征空间割裂导致的像素中介低效问题。其切入点在于识别出推理密集型任务对语义正确性的偏好，通过 MBAQ 将视觉特征离散化为语义 Token，并在 MoME 架构中实现共享潜空间内的直接跨模态交互。实验证明，该设计在 Visual Spatial Planning（ATE 1.34）和自反思生成（GenEval 0.87）上取得统一模型最优性能，但 MMBench 得分（80.3）低于 BAGEL（87.76），暴露了语义 Token 化在细粒度理解上的局限。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
