# HuggingFace最新推荐论文 ｜Context Unrolling in Omni Models ｜统一多模态模型中的上下文展开

作者：Ceyuan Yang、Zhijie Lin、Yang Zhao 等 19 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.21921)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.21921)

> 统一多模态模型旨在单一架构内融合理解与生成，但现有方法常将多模态视为孤立任务容器，缺乏模态间深层交互。本文指出，各模态仅是共享世界知识流形的偏置投影，需通过显式跨模态推理恢复完整近似。Omni 模型基于 BAGEL 架构，引入视频、3D 几何及隐藏表征，通过“上下文展开”机制在预测前动态构建异构上下文。该机制在生成与空间推理上表现强劲，但其推理时计算开销与离散视觉 Token 的信息损失边界尚存疑。

## 研究背景

当多模态模型处理复杂场景时，单一模态输入往往提供不完整且带有偏置的世界知识视图。这种局部性导致模型在跨模态任务中难以捕捉全局一致性，即“伪统一”现象。为突破此局限，需引入多模态投影间的显式推理机制，将各模态视为互补证据源，通过结构化整合恢复共享潜空间中的完整表征。

统一多模态理解与生成（UMM）领域长期受困于理解任务对语义紧凑表征的偏好与生成任务对像素保真表征的偏好之间的冲突。主流路线如 Janus 采用解耦编码器，Transfusion 采用混合自回归-扩散目标，虽缓解了梯度冲突，但多停留在功能集成层面，未实现模态间的认知协同。BAGEL 通过 Mixture-of-Transformers 架构实现了大规模交错训练，但其模态范围局限于图文，未充分利用视频时序动态与 3D 几何结构提供的空间约束。Omni 的切入点在于将训练模态扩展至视频、3D 几何及隐藏视觉表征，并提出“上下文展开”机制，将各模态能力转化为可组合的原子原语，在推理阶段动态构建任务相关的中间上下文，从而在单一架构内实现跨模态推理与生成的协同。

## 核心方法

### 方法参照系

Omni 基于 BAGEL 的 Mixture-of-Transformers 架构，继承其共享骨干与交错数据范式。与 BAGEL 仅处理图文不同，Omni 将视频、3D 几何（相机位姿、深度）及隐藏视觉表征纳入原生模态，构建异构上下文池。关键差异在于，Omni 不将多模态视为并行任务，而是将其视为可调用、可组合的原子原语，用于在最终解码前构建更丰富的共享工作空间。

### 上下文展开机制

传统统一模型将任务视为输入到输出的直接映射，缺乏中间推理步骤。Omni 引入上下文展开机制，将推理过程建模为迭代上下文构建与条件解码。具体而言，模型在预测前可调用“文本思考”（生成细粒度描述）、“视觉 Token 展开”（生成结构化视觉 Token）或“3D 原语”（相机位姿估计、新视角合成）等原子操作，将结果注入共享上下文。该过程形式化为：

$$ C_t = C_{t-1} \oplus \phi_t(x) $$

其中 $C_t$ 为第 $t$ 步的上下文状态，$\phi_t$ 为原子原语（如描述、位姿预测、视觉 Token 展开），$\oplus$ 表示上下文组合。这一设计解决了单一模态表征在几何歧义（如视角变化、遮挡）下的推理失效问题，通过显式引入结构约束提升预测的忠实度。

### 异构模态投影整合

Omni 将视频、3D 几何与隐藏表征作为世界知识流形的互补投影。视频提供时空动态结构，3D 几何提供相机变换与深度约束，隐藏表征支持潜空间推理。模型通过动态选择任务相关上下文，聚合互补信息。例如，在空间理解任务中，模型可先执行相机位姿估计（3D 文本上下文），再合成新视角（3D 视觉上下文），最后基于增强上下文进行推理。该机制将深度估计从直接回归 $I \to D$ 转化为条件推理 $D = \text{Depth}(I | C_{\text{text}}, C_{\text{vis}})$，显著提升了空间推理的准确性。

## 实验评估

Omni 在 GenEval2、DPG、VBench、FiVE 及 3D 几何基准上进行评估，对比基线包括 Qwen3-VL、InternVL3.5、Flux、Wan2.1 等专用模型。在图像生成上，Omni 在 GenEval2 上得分 54.12，高于 Qwen-Image 的 30.67 和 Z-Image 的 41.83；在 DPG 上得分 88.55，高于 Flux 的 88.32。在视频生成上，Omni 在 VBench 总分 83.35，与 Wan2.1 的 83.69 持平，但语义得分 84.29 高于 Hunyuan 的 76.88。在 3D 几何上，Omni 在 NYU 深度估计 $\delta_1$ 达 96.22，优于 VGGT 的 96.10 和 Marigold 的 92.75。

| 任务 | 基准 | Omni | 最强基线 | 基线得分 |
|---|---|---|---|---|
| 图像生成 | GenEval2 | 54.12 | Qwen-Image | 30.67 |
| 图像生成 | DPG | 88.55 | Flux | 88.32 |
| 视频生成 | VBench Total | 83.35 | Wan2.1 | 83.69 |
| 深度估计 | NYU $\delta_1$ | 96.22 | VGGT | 96.10 |

消融实验显示，上下文展开对生成质量提升显著。在 GenEval2 上，仅使用短文本思考（+ short）时 TIFA_GM 从 29.25 提升至 37.35，加入视觉 Token（+ visual）后进一步升至 48.02，结合长文本与视觉 Token（+ long and visual）达 53.44。Oracle 上下文（Gemini-3 Pro 生成）下 TIFA_GM 达 57.21，表明当前自展开上下文与理想上下文间存在差距。在空间理解上，加入 3D 视觉上下文（+ visual contexts）使 MMSI 总分从 27.14 提升至 34.17，其中位置关系子项从 19.63 升至 35.80，验证了生成式想象对空间推理的增益。

评估边界方面，Omni 视频生成分辨率限于 480×640、时长 12 秒，远低于专用视频模型。代码未公开，仅提供项目页面。实验未报告置信区间，且 MMBench 得分 75.3 低于 BAGEL 的 87.76，可能因训练数据侧重 3D/视频导致理解能力退化，论文未深入分析此权衡。

## 关联研究分析

从问题动机看，Omni 与 BAGEL 同属混合架构路线，但 BAGEL 聚焦图文交错训练，Omni 扩展至视频与 3D，动机在于利用时空动态与几何结构缓解单一模态表征的局限性。BAGEL 未显式引入推理时上下文构建，Omni 的上下文展开机制将多模态能力转化为可组合原语，解决了 BAGEL 在复杂空间推理中缺乏结构约束的问题。这一差异源于任务特性：3D 几何任务需显式空间约束，而图文任务可通过语义对齐缓解歧义。

从方法设计看，Omni 与 Transfusion 的混合 AR-Diffusion 目标不同，Transfusion 在训练阶段结合自回归与扩散损失，Omni 在推理阶段动态调用原子原语。Transfusion 未引入 3D 几何模态，Omni 的相机位姿估计与新视角合成作为上下文原语，提供了 Transfusion 缺乏的几何验证机制。Omni 使用离散视觉 Token 作为上下文，但未解决高分辨率生成中的信息损失问题，这与领域共识中“离散 Token 化瓶颈”相悖，暗示其视觉 Token 可能加剧高频细节丢失，论文未对此进行量化分析。

## 总结

Omni 旨在解决统一多模态模型中模态间缺乏深层交互导致的“伪统一”问题，通过扩展训练模态至视频、3D 几何及隐藏表征，并提出上下文展开机制，将各模态能力转化为可组合的原子原语，在推理阶段动态构建任务相关上下文。该机制在 GenEval2 图像生成上得分 54.12，NYU 深度估计 $\delta_1$ 达 96.22，验证了跨模态上下文对推理质量的提升。然而，Omni 视频生成分辨率与时长受限，且 MMBench 得分低于 BAGEL，暴露了多模态扩展与理解能力间的潜在权衡。当训练数据侧重 3D/视频时，离散视觉 Token 作为上下文是否加剧了高频细节丢失，论文未给出回答。
