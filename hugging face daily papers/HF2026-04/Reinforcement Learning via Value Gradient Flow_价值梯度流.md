> 行为正则化强化学习旨在平衡价值最大化与对参考分布的依赖，以防止离线数据外推导致的价值过估计或大语言模型对齐中的奖励黑客。现有方法依赖显式散度惩罚或重参数化策略梯度，前者难以解耦价值学习与策略改进的正则化强度，后者在扩散或流模型中因反向传播多步采样过程而计算昂贵且不稳定。本文提出价值梯度流（Value Gradient Flow, VGF），将行为正则化重构为从参考分布到价值诱导最优分布的最优传输问题，通过离散梯度流引导粒子移动，以传输预算作为隐式正则化机制。该范式消除了显式策略参数化，实现了训练与推理阶段正则化强度的解耦，但在高维连续动作空间中粒子数与步长的理论最优选取仍缺乏指导。

## 研究背景

离线强化学习面临的核心困境是分布偏移：静态数据集无法覆盖所有状态-动作对，导致值函数在分布外（Out-of-Distribution, OOD）区域产生严重过估计。为抑制这一现象，主流方法采用行为正则化，即约束策略 $\pi$ 接近参考分布 $\mu$（如离线数据分布或预训练模型）。该约束通常通过显式惩罚项实现，如KL散度或L2距离，其形式为 $\max_\pi \mathbb{E}[R(s,a)] - \beta M(\pi, \mu)$。然而，显式惩罚存在两个结构性缺陷：一是单一系数 $\beta$ 同时约束价值学习与策略改进，导致调参困难且易陷入过度保守或漂移失控；二是当策略采用扩散或流匹配等生成式模型时，计算策略梯度需反向传播通过多步去噪过程，数值不稳定且内存开销巨大。

行为正则化强化学习的主流路线分为重参数化策略梯度与拒绝采样两类。重参数化方法（如TD3+BC, FQL）通过直接优化策略参数最大化价值，但受限于生成式模型的多步采样特性，梯度估计方差大且计算成本高。拒绝采样方法（如IQL, IVR）通过加权行为克隆或Best-of-N采样避免显式策略优化，理论上接近KL约束下的最优解，但受限于参考分布的支持集，无法发现参考分布之外的新技能。VGF的切入点在于，将正则化从显式惩罚项转化为几何约束，即限制粒子从参考分布出发的传输距离，从而在避免多步反向传播的同时，突破参考分布的支持集限制。

## 核心方法

### 方法参照系

行为正则化强化学习的标准流程是求解约束优化问题 $\pi^* = \arg\max_\pi \mathbb{E}_{s \sim D, a \sim \pi} [R(s,a)] \text{ s.t. } M(\pi, \mu) \le \epsilon$。主流做法是将约束转化为拉格朗日项，通过策略梯度更新参数化策略 $\pi_\theta$。本文的关键差异在于，不参数化策略，而是将策略视为参考分布 $\mu$ 经有限步梯度流变换后的隐式分布，通过控制流步数与步长实现正则化。

### 最优传输重构

VGF首先将最大熵强化学习目标 $\mathbb{E}_{a \sim \pi}[R(s,a)] + \alpha H(\pi)$ 的最优解识别为玻尔兹曼分布 $\pi^*(a|s) \propto \exp(R(s,a)/\alpha)$。随后，将策略优化重构为从参考分布 $\mu$ 到 $\pi^*$ 的2-Wasserstein距离最小化问题。设计动机在于，Wasserstein度量天然捕捉分布间的几何位移，避免了KL散度在分布支持集不重叠时的无穷大惩罚，从而允许策略探索参考分布之外的区域。具体地，VGF采用Jordan-Kinderlehrer-Otto (JKO) 最小移动方案求解离散梯度流，其更新规则为：

$$ a_i^{(l+1)} = a_i^{(l)} + \epsilon \left( \nabla_{a} \log \pi^*(a_i^{(l)}|s) - \frac{1}{N} \sum_{j=1}^N \nabla_{a} \log \pi^*(a_j^{(l)}|s) \right) $$

该公式表明，每个粒子 $a_i$ 沿价值函数梯度方向移动，同时受其他粒子排斥力影响以维持多模态分布。$\epsilon$ 为步长，$N$ 为粒子数。此设计解决了重参数化策略梯度中反向传播多步生成过程的不稳定性，因为梯度仅作用于单步价值函数，无需遍历整个生成链。

### 隐式正则化与测试时扩展

VGF的核心创新在于将传输预算（步数 $L$ 与步长 $\epsilon$）作为隐式正则化机制。理论上，VGF证明了初始粒子与生成粒子间的最大均值差异（MMD）距离有界，且该界随 $L$ 和 $\epsilon$ 单调递增。这意味着，较小的 $L$ 和 $\epsilon$ 使策略紧密贴合参考分布，而较大的值则允许策略偏离参考分布以追求更高价值。设计动机在于解耦训练与推理阶段的正则化强度：训练时使用固定的 $L_{train}$ 确保值函数学习稳定，推理时通过调整 $L_{test}$ 实现自适应扩展。当 $L_{test}=0$ 时，VGF退化为Best-of-N采样；当 $L_{test} > L_{train}$ 时，策略可探索参考分布之外的区域，前提是价值函数在OOD区域泛化良好。这一机制解决了拒绝采样方法因过度保守而无法超越参考分布性能的问题，同时避免了显式惩罚系数 $\beta$ 的调参负担。

## 实验评估

VGF在D4RL（MuJoCo, AntMaze）与OGBench（机器人运动与操作）基准上评估，基线涵盖高斯策略（TD3+BC, IQL, IVR）、扩散策略（Diffusion-QL, SfBC）及流策略（FQL）。实验设置采用5个随机种子，报告最后10次评估的平均值与标准差。

| 数据集 | TD3+BC | IQL | FQL | VGF |
| :--- | :--- | :--- | :--- | :--- |
| halfcheetah-m-e | 84.2±4.6 | 94.0±0.4 | 102.1±0.6 | 110.5±1.5 |
| hopper-m-e | 76.1±7.3 | 98.0±0.8 | 110.1±0.3 | 110.0±0.8 |
| antmaze-m-d | 74.0±2.3 | 89.4±3.1 | 84.0±2.9 | 86.7±2.8 |
| puzzle-4x4 | 2.0±0 | 17.0±2 | 29.0±3 | 45.0±4 |

在D4RL高难度任务上，VGF显著优于基线。例如，在halfcheetah-m-e上，VGF得分110.5±1.5，高于FQL的102.1±0.6与IQL的94.0±0.4。在OGBench的puzzle-4x4任务中，VGF成功率45.0±4，远超FQL的29.0±3与IQL的17.0±2，表明其在复杂操作任务中具备更强的探索能力。

消融实验显示，训练时流步数 $L_{train}$ 对性能影响显著，需按任务调优。例如，在halfcheetah-m-e上，$L_{train}=3$ 时性能最佳，而 $L_{train}=1$ 或 $5$ 时性能下降。测试时流步数 $L_{test}$ 的调节实现了自适应扩展：在价值函数泛化良好的任务中，增加 $L_{test}$ 可提升性能；在价值函数外推误差大的任务中，设置 $L_{test}=0$ 退化为Best-of-N采样，仍优于参考策略。这一结果验证了传输预算作为隐式正则化机制的有效性，但也揭示了 $L_{train}$ 与 $L_{test}$ 的选取依赖价值函数质量，缺乏理论指导。

评估边界方面，VGF在D4RL MuJoCo任务上表现优异，但在walker2d-m-e上得分110.0±0.8，略低于知识库中Selective State-Adaptive Regularization的109.6±1.5（据领域综述）。OGBench antmaze-large任务上，VGF得分93±2，与SORL持平。可复现性方面，论文提供代码链接，但未报告GPU型号与训练时长，且粒子数 $N=5$ 在所有实验中固定，未探索 $N$ 对性能的影响。

## 关联研究分析

从问题动机看，VGF与FQL均旨在解决生成式策略在离线RL中的训练不稳定性，但路径截然不同。FQL通过蒸馏将多步流策略压缩为单步模型，以牺牲表达力换取计算效率；VGF则完全摒弃策略参数化，通过粒子流直接操作参考分布样本，保留了多模态表达力。这一差异源于对“策略”定义的重新理解：FQL视策略为可学习的函数映射，VGF视策略为分布变换过程。VGF的优势在于避免了蒸馏过程中的信息损失，但其代价是推理时需执行 $L_{test}$ 步梯度计算，计算复杂度随 $L_{test}$ 线性增长。

从方法设计看，VGF与IQL在价值函数学习上一致，均使用TD学习训练Q函数，但在策略生成上存在根本分歧。IQL通过隐式Q学习避免OOD动作，策略生成依赖参考分布的加权采样，受限于参考分布支持集；VGF通过梯度流引导粒子移动，可突破参考分布支持集，发现新行为。这一差异源于VGF引入的最优传输框架，其几何性质允许分布支持集的扩展。然而，VGF的突破能力依赖价值函数在OOD区域的准确性，若价值函数过估计，粒子将被引导至低价值区域，导致性能下降。论文未提供价值函数误差与传输预算的定量关系，这一盲区限制了VGF在极端稀疏奖励环境中的适用性。

## 总结

VGF旨在解决行为正则化强化学习中显式惩罚系数调参困难与生成式策略梯度不稳定的矛盾。其切入点在于将正则化从代数惩罚转化为几何传输约束，通过控制粒子流步数与步长实现隐式正则化，从而解耦训练与推理阶段的正则化强度。VGF在D4RL halfcheetah-m-e上取得110.5±1.5，在OGBench puzzle-4x4上取得45.0±4，显著优于FQL与IQL。其边界在于，传输预算的选取依赖价值函数质量，且粒子数 $N$ 固定为5，未探索高维动作空间中 $N$ 与 $L$ 的联合优化。当价值函数在OOD区域存在系统性偏差时，VGF的探索能力是否会被误导，论文未给出定量回答。
