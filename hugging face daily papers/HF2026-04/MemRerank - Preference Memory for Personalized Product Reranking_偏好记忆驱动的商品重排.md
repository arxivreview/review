作者：Zhiyuan Peng、Xuyang Wu、Huaixiao Tou 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.29247)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.29247)

> 智能体推荐系统面临长购买历史直接注入提示词导致噪声过大且上下文窗口饱和的困境，现有通用记忆框架未能针对下游重排任务优化记忆表示。本文切入点在于构建查询无关的紧凑偏好记忆，并通过强化学习直接优化该记忆对重排准确率的贡献。方法核心是设计基于GRPO的记忆提取器，以重排任务准确率为奖励信号训练LLM生成结构化偏好摘要。该框架在自建基准上显著优于原始历史注入与通用LLM提取基线，但评估局限于1-in-5小集合选择，未验证大规模端到端重排场景下的泛化能力。

## 研究背景

当LLM智能体处理电商推荐时，直接拼接用户长购买历史至提示词会引入大量无关噪声，且迅速耗尽上下文窗口，导致重排性能不升反降。这一现象源于原始历史数据缺乏结构化压缩，无法区分当前查询相关的稳定偏好与临时行为。解决此问题需要引入偏好记忆机制，即从历史中蒸馏出紧凑、查询无关的结构化表示，该表示需同时捕捉类别内偏好与跨类别行为模式，并能被下游重排模型直接消费。

智能体推荐框架正从静态候选列表向动态交互演进，记忆模块被视为核心组件。主流路线如Mem0和MR.Rec通过通用提取或强化学习优化记忆存储与检索，但其目标多为通用对话连贯性或整体推荐效用，未针对特定重排任务进行对齐。现有方法在将记忆转化为重排增益时存在断层：通用提取器生成的记忆可能流畅但缺乏对下游排序决策的针对性，导致信息利用率低。MEMRERANK针对这一断层，将记忆提取重构为下游重排任务的策略优化问题，通过直接优化重排准确率来训练记忆生成过程，从而弥合记忆表示与排序效用之间的差距。

## 核心方法

### 方法参照系

本文问题置于智能体推荐框架的记忆增强重排流程中。标准流程通常采用通用LLM提取用户画像或原始历史检索，作为重排器的辅助上下文。关键差异在于，本文不修改重排器本身，而是将记忆提取器视为独立策略，其训练目标直接绑定下游1-in-5重排准确率，而非通用的文本生成质量或对话连贯性。

### 偏好记忆提取与结构化

记忆提取器接收用户购买历史，输出包含`<within_memory>`和`<cross_memory>`标签的结构化文本摘要。设计动机在于解决原始历史注入导致的噪声干扰与上下文饱和问题，通过显式区分类别内与跨类别偏好，提供局部与全局行为信号。提取器采用Qwen2.5-7B-Instruct作为骨干，最大生成长度根据记忆类型设定为512或1024 tokens，确保摘要紧凑且信息密度高。

### 基于GRPO的记忆策略优化

记忆提取被建模为策略优化问题，使用Group Relative Policy Optimization (GRPO) 训练提取器。设计动机在于避免昂贵的金标准偏好记忆标注，并直接对齐记忆生成与重排效用。奖励函数 $r(x, m)$ 由格式奖励与重排奖励组成：

$$
r(x, m) = r_{format}(m) + r_{rerank}(x, m)
$$

其中 $r_{format}$ 检查标签结构正确性，$r_{rerank}$ 通过采样5次重排结果计算准确率均值。GRPO更新策略 $\pi_\theta$ 以最大化期望奖励：

$$
\nabla_\theta J(\theta) = \mathbb{E}_{x \sim D, m \sim \pi_\theta(\cdot|x)} \left[ \frac{\nabla_\theta \log \pi_\theta(m|x)}{\sigma(r)} (r(x, m) - \bar{r}) \right]
$$

该公式通过组内相对优势估计，使提取器生成对重排器最有用的记忆，而非仅追求文本流畅性。

## 实验评估

实验基于Amazon-C4衍生基准，聚焦Electronics类别，采用1-in-5选择协议。基线覆盖无记忆、原始历史注入、通用LLM提取（GPT-5.2、Qwen2.5-7B）及外部记忆框架（Mem0、MR.Rec），但未对比生成式推荐SOTA如TIGER，因任务范式不同。

| Reranker | Method | Acc. | Δ |
| :--- | :--- | :--- | :--- |
| GPT-4.1-mini | No memory | 32.47 | – |
| GPT-4.1-mini | + Within + cross-category products | 34.02 | +1.55 |
| GPT-4.1-mini | + Base-extractor memory | 31.96 | -0.51 |
| GPT-4.1-mini | + MEMRERANK | 38.14 | +5.67 |
| GPT-4.1-mini | + MEMRERANK+ think tag | 39.07 | +6.60 |
| o4-mini | No memory | 31.86 | – |
| o4-mini | + Within + cross-category products | 34.85 | +2.99 |
| o4-mini | + Base-extractor memory | 36.29 | +4.43 |
| o4-mini | + MEMRERANK | 40.72 | +8.86 |
| o4-mini | + MEMRERANK+ think tag | 42.47 | +10.61 |

MEMRERANK在两个重排器上均显著优于原始历史注入与未训练提取器，o4-mini下提升10.61点。消融显示，提示词设计对性能影响显著，v3提示（灵活方面发现+证据接地）优于固定schema（v1）与完全自由（v2），且RL训练放大了优质提示的收益。例如，训练后M_WC_v3达38.14，而M_WC_v2仅33.20。

评估边界受限：仅测试1-in-5小集合，未验证大规模候选池端到端重排；数据集限于Electronics，缺乏跨类别泛化验证；未报告计算开销与延迟，无法评估工业部署可行性。代码未公开，超参数细节有限，可复现性依赖作者实现。

## 关联研究分析

从问题动机看，MEMRERANK与Mem0、MR.Rec同属智能体记忆增强路线，但目标函数存在根本差异。Mem0聚焦通用会话记忆提取，MR.Rec优化整体推荐效用，而MEMRERANK将记忆提取严格限定为重排任务的策略优化。这种差异源于任务特性：重排是离散选择任务，记忆效用可直接通过准确率量化，适合RL优化；而通用对话记忆效用难以直接测量，需依赖代理指标。MEMRERANK的RL训练是否优于SFT，论文未提供SFT基线对比，无法排除收益源于模型容量而非RL本身。

从方法设计看，MEMRERANK与生成式推荐架构如TIGER解决物品表示对齐问题，但路径不同。TIGER通过语义ID将物品映射至LLM语义空间，实现自回归生成；MEMRERANK保持物品文本表示，通过偏好记忆增强重排器输入。前者改变物品表示范式，后者增强用户侧信号。MEMRERANK未对比TIGER，因任务范式不同（生成vs重排），但二者均面临LLM与协同信号对齐挑战。MEMRERANK的查询无关记忆设计牺牲了动态性，无法捕捉实时意图漂移，这在多轮对话场景中可能成为瓶颈。

## 总结

MEMRERANK解决的核心矛盾是长购买历史直接注入LLM提示词导致的噪声干扰与上下文饱和，现有通用记忆框架未能针对重排任务优化记忆表示。本文抓住的切入点是构建查询无关的紧凑偏好记忆，并通过强化学习直接优化该记忆对重排准确率的贡献，从而弥合记忆表示与排序效用之间的断层。方法核心是设计基于GRPO的记忆提取器，以重排任务准确率为奖励信号训练LLM生成结构化偏好摘要。实验证明，在Electronics类别1-in-5任务上，MEMRERANK较无记忆基线提升10.61点，显著优于原始历史注入与通用LLM提取基线。本文的边界在于评估局限于小集合选择，未验证大规模端到端重排场景下的泛化能力，且缺乏跨类别与计算效率验证。当候选池规模扩大至数百项时，1-in-5策略的重复应用是否仍能保持性能优势，论文未给出回答。
