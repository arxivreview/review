# HuggingFace最新推荐论文 ｜Can Large Language Models Reinvent Foundational Algorithms? ｜算法重发明

研究机构：清华大学、中国科学院

作者：Jian Zhao、Haoren Luo、Yu Wang 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.05716)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.05716)

> 大语言模型（LLM）在科学发现中的核心瓶颈在于其依赖预训练数据中的既有模式，难以区分“检索”与“创造”。现有算法发现系统如 FunSearch 和 AlphaEvolve 侧重于在已知问题空间内进行增量优化，无法验证模型是否具备从零构建基础算法的原创能力。本文提出 Unlearn-and-Reinvent 流水线，通过基于 GRPO 的遗忘机制移除特定算法知识，再测试模型能否独立重发明该算法。该框架揭示了 LLM 在复杂算法重发明上的能力边界，但受限于受控环境与单一学科，其结论向开放科学发现的泛化性存疑。

## 研究背景

理解本文需厘清 LLM 知识擦除与算法重发明的耦合机制。LLM 的预训练过程使其内化了大量基础算法，导致直接测试其“发明”能力时，模型往往通过记忆检索而非逻辑推导得出答案。为剥离这种先验干扰，需引入 LLM 遗忘（Unlearning）技术，即在保留通用能力的前提下，定向移除模型对特定知识的响应。然而，传统遗忘方法如梯度上升易导致模型性能崩溃，因此需采用基于策略优化的遗忘方法，确保模型在“失忆”后仍具备基本的代码生成与推理能力，从而为后续的重发明测试提供可控的初始状态。

LLM 驱动的科学发现研究正从“增量改进”向“基础创新”演进。FunSearch（Romera-Paredes et al., 2023）与 AlphaEvolve（Novikov et al., 2025）证明了 LLM 能发现优于人类已知方法的算法，但这些工作均假设模型已具备相关领域的背景知识，其贡献在于搜索效率而非知识创造。当前领域缺乏一种能严格隔离先验知识、验证模型“从零发明”能力的评估范式。本文切入点在于构建一个受控的“失忆-重发明”闭环，通过移除 Dijkstra 等基础算法的知识，测试模型能否在缺乏直接记忆的情况下，通过推理与交互重新推导这些算法，以此量化 LLM 的基础创新能力。

## 核心方法

### 方法参照系

本文问题属于“科学推理与算法发现”路线，但区别于 FunSearch 等直接利用 LLM 作为变异算子在程序空间搜索的范式。本文的关键差异在于引入“遗忘”前置步骤，将评估对象从“已知算法的优化者”转变为“未知算法的发明者”，从而在受控环境下模拟算法发明的认知过程。

### GRPO 基于策略的遗忘

传统遗忘方法如梯度上升直接增加遗忘集上的语言建模损失，易导致模型在保留集上的性能显著下降。本文采用基于 Group Relative Policy Optimization (GRPO) 的在线策略遗忘，将遗忘过程建模为强化学习问题。设计动机在于利用奖励信号引导模型在“不泄露目标知识”与“保持可读性”之间寻找平衡，避免硬约束导致的性能崩溃。遗忘目标函数定义为：

$$ L_{unlearn}(\theta) = \mathbb{E}_{x \sim D_{forget}} \left[ \frac{1}{G} \sum_{j=1}^{G} \left( J_{clip, j}(\theta) - \beta D_{KL}(\pi_\theta(\cdot|x) \| \pi_{ref}(\cdot|x)) \right) \right] $$

其中 $J_{clip, j}$ 为裁剪后的代理目标，$\beta$ 为 KL 散度系数，$\pi_{ref}$ 为参考策略。该公式通过相对奖励估计优势，使模型在生成不泄露算法名称且可读的响应时获得正奖励，从而在策略空间中平滑地移除目标知识。

### 生成式验证器与测试时强化学习

重发明阶段中，模型与 Python 解释器交互，失败时由生成式验证器提供诊断反馈。设计动机在于解决静态模型在长程推理中出现的“思维崩塌”现象，即模型在多次失败后推理 token 数递减，探索行为减少。验证器通过自然语言反馈引导模型定位错误，维持推理强度。为进一步突破静态模型的局限，本文引入测试时强化学习（Test-time RL），在推理过程中对模型进行在线优化。奖励函数定义为：

$$ r = \frac{1}{T} \cdot \mathbb{I}(\text{solution is correct}) $$

其中 $T$ 为执行时间，$\mathbb{I}$ 为指示函数。该公式将正确性与效率结合，鼓励模型在测试时通过强化学习更新策略，从而在特定提示级别下实现原本无法重发明的算法突破。

## 实验评估

实验在 10 个基础算法、3 个开源模型（Qwen3-4B-Thinking-2507, Qwen3-4B-Instruct-2507, Ministral-3-14B-Reasoning-2512）及 3 个提示级别上进行。基线审计显示，本文未与 FunSearch 或 AlphaEvolve 直接对比，因任务设定不同（重发明 vs. 优化），但缺乏与“无遗忘”基线的对比，无法完全隔离遗忘过程对重发明成功率的影响。

| 模型 | 无提示 RSR (%) | 提示级别 1 RSR (%) | 提示级别 2 RSR (%) |
| :--- | :--- | :--- | :--- |
| Qwen3-4B-Thinking-2507 | 21.8 | 48.5 | 80.9 |
| Ministral-3-14B-Reasoning-2512 | 3.9 | 15.6 | 26.5 |
| Qwen3-4B-Instruct-2507 | 0.2 | 9.2 | 30.6 |

Qwen3-4B-Thinking-2507 在无提示下重发明 50% 的算法，显著优于其他模型，表明推理能力对重发明至关重要。提示级别提升带来一致的性能增益，但 KMP、Manacher 和 Strassen 在提示级别 2 下仍失败，显示算法复杂度是主要瓶颈。

消融实验显示，移除验证器导致推理 token 数随轮次递减，重发明成功率下降。测试时强化学习在 Strassen（提示级别 2）上实现 62.5% 的正确率，从无正确解提升至有正确解，验证了在线优化对突破静态模型局限的有效性。

| 测试时 RL 目标 | 正确率 (前/后) | 时间 (前/后) |
| :--- | :--- | :--- |
| Strassen (Level 2) | 0.0% / 62.5% | — / 1.35 s |
| Prim (Level 1) | 100.0% / 100.0% | 2.22 s / 1.77 s |
| KMP (No Hint) | 100.0% / 100.0% | 2.12 s / 1.80 s |

评估边界方面，RSR 指标仅衡量正确性，未量化算法的新颖性或效率优化程度。评估协议依赖 DeepSeek-V3.2 作为 LLM-as-a-judge，可能存在主观偏差。代码已开源，但超参数配置复杂，复现成本较高。

## 关联研究分析

从问题动机看，本文与 FunSearch 和 AlphaEvolve 存在根本差异。FunSearch 和 AlphaEvolve 假设模型已具备相关算法知识，其贡献在于通过进化搜索发现更优解，而本文通过遗忘机制剥离先验知识，测试模型的“从零发明”能力。这一差异源于任务特性的不同：前者关注搜索效率，后者关注知识创造。本文未探索遗忘过程对模型通用能力的长期影响，可能低估了遗忘带来的性能损耗。

从方法设计看，本文与 SciMON 等基于检索增强生成（RAG）的假设生成方法形成对比。SciMON 依赖外部文献接地，而本文依赖内部推理与验证器反馈。本文的 GRPO 遗忘机制借鉴了强化学习中的策略优化，但将其应用于知识擦除，这一迁移是否适用于非形式化科学问题（如生物、化学）尚不明确。验证器反馈的有效性可能依赖于任务的确定性，在开放科学发现中，缺乏明确测试套件时，验证器反馈的质量可能下降。

## 总结

本文核心矛盾在于 LLM 依赖预训练知识导致无法区分“检索”与“创造”。通过 GRPO 遗忘与测试时强化学习，本文构建了受控的“失忆-重发明”闭环，证明最强模型在无提示下可重发明 50% 的基础算法，但复杂算法仍具挑战性。边界在于任务局限于计算机科学基础算法，缺乏跨学科验证，且 RSR 指标未涵盖算法新颖性。当遗忘过程导致模型通用能力显著下降时，重发明成功率的提升是否仍具科学意义，论文未给出回答。
