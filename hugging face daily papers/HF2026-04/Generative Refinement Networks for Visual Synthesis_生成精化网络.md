深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.13030)

> 视觉生成领域长期面临扩散模型计算冗余与自回归模型误差累积的双重困境。扩散模型对简单与复杂样本分配相同算力，而自回归模型因离散量化损失细节且无法回溯修正早期错误。GRN 通过层级二进制量化（HBQ）实现近无损离散表征，并引入全局精化机制允许模型在生成过程中迭代修正错误。该框架在 ImageNet 上刷新了重建与生成质量纪录，但其精化机制在高分辨率视频生成中的收敛稳定性仍存疑。

## 研究背景

视觉自回归生成依赖离散 Token 序列建模，其核心瓶颈在于量化误差与顺序预测的不可逆性。向量量化（VQ）将连续特征映射为离散码本索引，虽确立了“编码器-量化器-解码器”框架，但量化过程不可避免地丢失高频细节，导致重建保真度低于连续表征。同时，传统自回归模型采用严格的因果预测机制，无论是逐 Token 还是逐尺度预测，早期步骤产生的错误无法在后续步骤中修正，导致误差随序列长度累积。

主流路线中，VAR 模型通过 Next-Scale 预测改善了全局一致性，但仍未解决离散 Token 的细节丢失问题；Infinity 等模型尝试通过扩大潜空间维度或位级 Token 来弥补量化损失，却以牺牲收敛速度和增加模型规模为代价。扩散模型虽在质量上占优，但其基于均方误差（MSE）的优化缺乏显式似然估计，无法根据样本复杂度自适应调整推理步数，造成计算资源浪费。GRN 的切入点在于同时解决表征精度与生成机制的僵化问题：通过理论近无损的量化方案消除离散化瓶颈，并通过引入类似人类绘画的“逐步精化”机制，打破自回归模型“只增不减”的单向预测限制。

## 核心方法

### 方法参照系

GRN 属于离散自回归视觉生成范式，但其核心差异在于摒弃了传统的 Next-Token 或 Next-Scale 单向预测流程。标准自回归模型在每一步仅预测新 Token 并固定已生成部分，而 GRN 将生成过程重构为从随机初始化开始，通过多步迭代逐步填充并修正 Token 映射的闭环过程，其骨干网络采用 Transformer 架构，但训练目标与推理逻辑均围绕“状态精化”而非“序列补全”展开。

### 层级二进制量化（HBQ）

传统 VQ 分词器受限于码本大小，量化误差无法通过增加码本维度线性消除。HBQ 借鉴小波变换思想，将 VAE 编码特征映射至 $(-1, 1)$ 区间后，执行多轮层级二进制量化。第 $j$ 轮量化误差 $e_j$ 的上界为 $2^{-j}$，即误差随轮数 $M$ 呈指数衰减。

$$
\hat{F} = \sum_{j=1}^{M} q_j \cdot 2^{-j} + \text{offset}
$$

其中 $q_j \in \{0, 1\}$ 为第 $j$ 轮的量化位。该设计使得离散 Token 在保持低压缩率（如 16 通道）的情况下，重建质量逼近连续 VAE，避免了 Infinity 等方法通过扩大潜空间维度（如 64 通道）带来的收敛变慢问题。HBQ 的关键价值在于以极低的计算开销实现了“近无损”离散化，为后续精化机制提供了高保真的潜变量基础。

### 全局精化与熵引导采样

标准自回归模型中，已预测 Token 不可变，导致局部错误无法修正。GRN 定义当前状态 $F_t$ 为随机映射 $Y_{rand}$、预测映射 $Y_t$ 与选择映射 $S_t$ 的组合，通过 Transformer 预测下一状态 $Y_{t+1}$，并动态更新 $S_t$ 以决定哪些 Token 被保留、擦除或新填充。

$$
L_{CE} = -\sum_{i} \sum_{j=1}^{K} \mathbb{1}[y_i = j] \log p(y_i = j | F_t, \text{cond})
$$

训练时采用交叉熵损失拟合真实 Token 映射。推理时，引入熵引导采样策略，根据当前预测分布的平均熵 $H(Y_t)$ 动态调整选择比例 $l_t$。高熵（复杂区域）分配更多精化步数，低熵（简单区域）快速收敛。这一机制解决了传统 AR 模型误差累积不可逆的问题，使模型具备全局纠错能力，同时通过自适应步数避免了扩散模型的固定算力浪费。

## 实验评估

| 方法 | 类型 | 参数量 | rFID ↓ | gFID ↓ |
| :--- | :--- | :--- | :--- | :--- |
| SD-VAE | Continuous | - | 0.87 | - |
| VAR | Discrete | 600M | 0.85 | 1.92 |
| LlamaGen | Discrete | 343M | 2.19 | 3.07 |
| GRN-B | Discrete | 130M | 0.56 | 3.56 |
| GRN-G | Discrete | 2B | 0.56 | 1.81 |

GRN 在 ImageNet 256x256 类别条件生成任务中，GRN-G 以 1.81 的 FID 超越了 VAR（1.92）和 LlamaGen（3.07），并优于 DiT-L/2（5.02）等扩散模型。在重建指标上，HBQ 分词器以 0.56 的 rFID 显著优于连续 SD-VAE（0.87）和离散 VAR（0.85），验证了层级量化在保持低压缩率下的保真度优势。基线覆盖包括扩散、混合及自回归主流方法，但缺失 2026 年最新的 SSG 或 BAR 等前沿对比，限制了其在最新 SOTA 格局中的精确定位。

| HBQ 轮数 | 潜通道 | rFVD ↓ | PSNR ↑ |
| :--- | :--- | :--- | :--- |
| M=4 | 16 | 163.6 | 30.40 |
| M=8 | 16 | 144.9 | 31.10 |
| M=4 | 64 | 50.6 | 33.97 |
| M=4 (tune GAN) | 64 | 30.1 | 33.98 |

消融实验显示，增加 HBQ 轮数从 4 到 8 时，rFVD 从 163.6 降至 144.9，PSNR 从 30.40 升至 31.10，证实了指数衰减误差的理论预期。将潜通道从 16 扩展至 64 可进一步提升 PSNR 至 33.97，但论文强调在 16 通道下已能匹配连续基线，避免了维度扩展带来的计算开销。调整 GAN 损失权重后，rFVD 从 50.6 降至 30.1，表明感知损失对视频重建质量的显著影响。

评估协议主要依赖 ImageNet 标准基准，缺乏对开放域文本生成多样性的细粒度分析。代码已开源，但 T2I 和 T2V 任务使用了专有数据集微调，限制了外部复现的完整性。指标完备性方面，未报告推理延迟的具体加速比，仅定性描述了自适应步数的效率优势，缺乏与固定步数扩散模型的严格耗时对比。

## 关联研究分析

从问题动机看，GRN 与 Infinity 均致力于解决离散 Token 的量化误差，但路径截然不同。Infinity 通过随机翻转位级 Token 实现自校正，但假设错误率低于 30% 且覆盖模式有限；GRN 则通过 HBQ 从源头降低量化误差，并引入全局精化机制处理任意模式的错误累积。这一差异源于对“错误来源”的不同假设：Infinity 假设错误是稀疏且随机的，而 GRN 认为错误是系统性且可累积的，因此需要更鲁棒的迭代修正机制。

从方法设计看，GRN 与 VAR 同属自回归框架，但生成顺序逻辑存在根本冲突。VAR 采用 Next-Scale 预测，强调从粗到细的单向层级生成，其优势在于推理步数少且全局一致性好；GRN 则采用并行精化，允许在后续步骤中擦除早期错误，这挑战了“顺序预测符合自回归本质”的共识。GRN 的设计更接近扩散模型的迭代去噪逻辑，但保留了离散 Token 的 LLM 兼容性。这种混合范式是否能在长序列视频生成中保持收敛稳定性，而非陷入局部最优震荡，是两者路线差异带来的核心风险。

## 总结

GRN 旨在解决离散自回归模型中量化误差与误差累积的双重矛盾。其切入点在于利用层级二进制量化实现近无损离散表征，并通过全局精化机制赋予模型回溯修正能力，从而在保持 LLM 架构兼容性的同时突破传统 AR 的单向预测限制。实验证明 GRN-G 在 ImageNet 上取得 1.81 的 FID，重建 rFID 达 0.56，显著优于 VAR 和 LlamaGen。然而，论文在 T2V 任务中仅展示 480p 视频，且未报告精化步数与视频时长之间的计算复杂度关系。当视频时长从 2 秒扩展至 10 秒时，全局精化机制所需的迭代步数是否呈线性增长，导致推理延迟无法被自适应采样策略有效抵消，论文未给出明确回答。
