# HuggingFace最新推荐论文 ｜TIPSv2: Advancing Vision-Language Pretraining with Enhanced Patch-Text Alignment ｜视觉语言预训练中的密集对齐优化

研究机构：谷歌DeepMind、韩国首尔大学

作者：Bingyi Cao、Koert Chen、Kevis-Kokitsi Maninis 等 19 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.12012)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.12012)

> 视觉语言模型在全局语义对齐上已趋于成熟，但 patch 级特征与文本嵌入的局部对齐能力依然薄弱，导致其在开放词汇分割等密集任务上表现受限。现有统一架构往往牺牲局部语义以换取全局对比性能，且大规模旗舰模型在密集对齐上反而不如小模型。本文通过发现蒸馏过程能显著增强局部对齐，进而提出 iBOT++ 目标函数，将监督信号扩展至所有可见 token，并结合多粒度文本增强与轻量级 EMA 策略，在保持全局性能的同时大幅提升了密集任务表现。该方法在零样本分割上刷新了 SOTA，但其对预训练数据规模的依赖及与纯非对比方法的理论差异仍存疑。

## 研究背景

视觉语言预训练（Vision-Language Pretraining, VLP）的核心困境在于全局语义对齐与密集特征质量之间的结构性矛盾。对比学习范式（如 CLIP）通过 InfoNCE 损失优化全局向量，确立了零样本分类的主导地位，但全局池化操作抹平了 patch 级空间结构，导致模型无法直接支撑分割、检测等密集预测任务。自监督学习（Self-Supervised Learning, SSL）方法（如 DINOv2）虽能生成具有强局部语义的密集特征，却缺乏原生的文本对齐能力，需额外训练文本编码器才能用于多模态任务。这种“全局强、局部弱”或“局部强、全局弱”的二元对立，使得现有模型难以同时满足通用分类与细粒度空间理解的双重需求。

主流路线试图通过混合目标来弥合这一鸿沟，如 TIPS 和 SigLIP2 结合了自监督与对比损失，但研究发现这些现代模型在 patch 级文本对齐上仍存在显著缺陷。Perception Encoder (PE) 指出，Transformer 的最终层往往退化为全局对比“解码器”，而非保留局部语义的编码器。更令人意外的是，旗舰级大模型在密集对齐任务上常表现不如其蒸馏后的小模型，暗示预训练过程中的某些机制抑制了局部语义的保留。本文切入点在于揭示这一反常现象背后的机制，并将蒸馏中的有效监督策略反向移植至预训练阶段，从而在根源上解决密集特征缺乏文本监督的问题。

## 核心方法

### 方法参照系

TIPSv2 建立在 TIPS 框架之上，该框架整合了图像-文本对比损失与自监督损失。标准流程中，学生网络处理裁剪或掩码视图，教师网络（EMA 副本）处理原始图像，通过交叉熵损失对齐全局与 patch 级嵌入。本文的关键差异在于，它不再将蒸馏仅视为模型压缩手段，而是将其作为增强预训练模型局部对齐能力的核心机制，并据此重构了掩码图像建模（Masked Image Modeling, MIM）的损失函数。

### iBOT++：全 Token 监督机制

iBOT++ 是对 iBOT 掩码图像建模目标的直接改进。标准 iBOT 仅监督被掩码的 token，要求学生重建这些缺失区域以匹配教师表示，而可见 token 不受直接约束，导致其表示可能偏离局部语义。iBOT++ 将损失函数扩展至所有 token，包括可见与掩码部分，强制学生网络在所有空间位置上与教师表示保持一致。这一设计解决了标准 MIM 中可见 token 缺乏直接监督导致局部语义丢失的问题，使得模型在预训练阶段即建立起精确的 patch-文本对齐。

$$
\mathcal{L}_{iBOT++} = \frac{1}{N} \sum_{i=1}^{N} \left( \mathcal{L}_{CE}(h_s(f_s(I_{mask})_i), h_t(f_t(I)_i) \right)
$$

该公式表明，损失不再局限于掩码区域，而是对所有 $N$ 个 patch 位置计算交叉熵，其中 $h_s, h_t$ 分别为学生和教师的投影头，$f_s, f_t$ 为编码器。这种全区域监督确保了学生表示在空间上的均匀锚定，避免了可见 token 的表示漂移。

### Head-only EMA 与多粒度文本增强

为降低计算开销并提升训练稳定性，TIPSv2 引入了 Head-only EMA 策略。传统 SSL 需要对整个编码器进行 EMA 更新以提供稳定目标，但 TIPSv2 发现，由于对比损失 $\mathcal{L}_{CLIP}$ 已约束了编码器防止坍塌，因此仅需对投影头进行 EMA 更新，而共享同一个编码器实例。这一简化将可训练参数减少近一半，显著降低了显存需求。同时，引入 Gemini 生成的长描述与 PaliGemma 短描述交替训练，平衡了对比损失的难度，防止长文本导致的判别任务过于简单，从而提升了模型对细节语义的捕捉能力。

$$
\theta_t^{head} = \alpha \theta_t^{head} + (1-\alpha) \theta_s^{head}, \quad f_t = f_s
$$

此公式定义了仅更新投影头参数的 EMA 过程，编码器参数 $f$ 在学生与教师间共享。这种设计利用了文本监督提供的额外稳定性，使得无需全模型 EMA 即可维持训练收敛，实现了效率与性能的平衡。

## 实验评估

实验在 9 项任务、20 个数据集上进行，涵盖零样本分割、检索、分类及深度估计。基线覆盖 CLIP、SigLIP2、DINOv2、TIPS 等主流方法，但缺少 LeJEPA 等非对比最新方法的直接对比。在密集图像-文本对齐任务上，TIPSv2 表现显著优于其他模型。

| 方法 | PC59 (mIoU) | PC60 (mIoU) | VOC21 (mIoU) | ADE150 (mIoU) |
|---|---|---|---|---|
| SigLIP2 SO/14 | - | 19.6 | 26.8 | 15.6 |
| DINOv2 (dino.txt) L/14 | 30.9 | - | - | 20.6 |
| TIPS L/14 | 33.5 | 30.4 | 30.5 | 20.8 |
| TIPSv2 L/14 (ours) | **37.1** | **33.9** | **44.4** | **24.7** |

TIPSv2 在 ADE150 零样本分割上达到 24.7% mIoU，显著高于 DINOv2 的 20.6% 和 TIPS 的 20.8%，验证了 iBOT++ 对密集对齐的提升作用。

消融实验揭示了关键设计决策的影响。移除掩码（Masking Ratio 0.0）并随机初始化学生编码器是提升对齐性能的关键。在蒸馏设置中，将掩码比例从 0.75 降至 0.0，ADE150 mIoU 从 5.9% 提升至 20.0%，表明全 token 监督至关重要。此外，Head-only EMA 相比全模型 EMA，在保持性能的同时大幅降低了计算成本，ViT-B 规模下训练参数减少 42%。

| 设置 | 掩码比例 | ADE150 (mIoU) | PC59 (mIoU) |
|---|---|---|---|
| (1) Pretraining | 0.75 | 0.3 | 6.9 |
| (2) Distillation | 0.75 | 5.9 | 16.0 |
| (4) Distillation | 0.0 | 20.0 | 31.4 |
| (5) Distillation | 0.0 | 20.5 | 31.1 |

评估边界方面，论文未报告置信区间，且部分基线（如 SILC）使用了更昂贵的滑动窗口协议，可能导致数值不可直接比较。代码已开源，但超参数细节（如 EMA 衰减率）未在正文中完全列出，复现需参考附录。

## 关联研究分析

从问题动机看，TIPSv2 与 LeJEPA 均致力于消除对比学习对负样本的依赖，但路径截然不同。LeJEPA 采用预测式目标与 SIGReg 正则化，完全摒弃对比损失，旨在从理论上避免坍塌；而 TIPSv2 保留对比损失，通过 iBOT++ 增强局部监督，是一种混合策略。这种差异源于任务特性：LeJEPA 更关注训练稳定性与理论优雅性，适合低资源场景；TIPSv2 则利用对比损失的强全局对齐能力，通过密集监督弥补其局部缺陷，更适合追求 SOTA 性能的大规模预训练。TIPSv2 在 ImageNet-1K 零样本分类上达到 78.7%，高于 LeJEPA 的 71.5%，表明混合目标在保持全局性能方面更具优势。

从方法设计看，TIPSv2 与 TIPS 同属“对比+SSL”框架，但 TIPSv2 将蒸馏中的全 token 监督机制内化至预训练，而 TIPS 仅在蒸馏阶段使用。这一改动源于对“大模型在密集任务上表现不佳”现象的解释：预训练中的高掩码比例抑制了局部语义保留，而蒸馏中的低掩码（或无掩码）反而增强了它。TIPSv2 通过 iBOT++ 在预训练阶段即引入这种增强，避免了后续蒸馏的额外成本。然而，这种改进是否依赖于特定的数据规模（116M 图像）或文本质量（Gemini 长描述），论文未进行充分消融，数据效率的边界尚不明确。

## 总结

TIPSv2 针对视觉语言模型中全局对齐与密集特征质量的矛盾，抓住了“蒸馏过程能增强局部对齐”这一被忽略的现象，将其转化为预训练目标 iBOT++。通过全 token 监督、Head-only EMA 及多粒度文本增强，该方法在 ADE20K 零样本分割上取得 24.7% mIoU，在 ImageNet-1K 上达到 78.7% Top-1 准确率，实现了密集与全局性能的同步提升。其边界在于，实验主要基于大规模 WebLI 数据，未验证在小数据或长尾分布下的鲁棒性，且与纯非对比方法在理论收敛性上的差异未深入探讨。当训练数据规模缩减至 10M 以下时，iBOT++ 的全 token 监督是否仍能维持局部语义优势，还是会被数据噪声淹没，论文未给出回答。
