# HuggingFace最新推荐论文 ｜SciLT: Long-Tailed Classification in Scientific Image Domains ｜科学图像长尾分类中的多层特征融合

研究机构：中国人民大学

作者：Jiahao Chen、Bing Su

论文原文见 [arXiv](https://arxiv.org/abs/2604.03687)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.03687)

> 科学图像领域存在严重的长尾分布与域偏移双重挑战，导致在自然图像上验证有效的基础模型微调策略在此失效。现有方法依赖文本先验或单一末层特征，无法应对科学图像中语义描述模糊及特征信息丢失的问题。本文提出 SciLT，通过自适应融合倒数第二层与末层特征并施加差异化损失监督，以纯视觉范式提升尾部类别识别性能。该方法在 NIH-Chest 等基准上实现了平衡准确率的显著提升，但其收益是否源于域偏移特有的特征互补性，还是通用架构改进，仍需更多跨域验证。

## 研究背景

科学图像（如 X 光、细胞显微图）与自然图像在视觉纹理、成像模态及语义粒度上存在显著差异，这种域偏移（Domain Shift）使得在自然图像上预训练的基础模型直接微调时，其末层特征往往无法有效捕捉科学任务的判别性信息。同时，科学数据天然呈现长尾分布，尾部类别样本稀缺，进一步加剧了特征表示不足的问题。参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）如 AdaptFormer 虽能降低适配成本，但在强域偏移下，仅微调适配器难以弥补预训练分布与目标分布间的语义鸿沟。

长尾视觉识别的主流路线包括损失重加权、解耦学习及视觉-语言模型（Vision-Language Models, VLMs）引导。VLMs 方法（如 LIFT, VL-LTR）在自然图像长尾任务中表现优异，但其依赖文本先验的有效性在科学图像中受到质疑：科学概念（如“肺不张”）在预训练语料中表征不足，且视觉模式细微复杂，难以用简洁文本准确描述。此外，现有研究多假设预训练与微调在同一域内进行，忽视了科学图像特有的域偏移对基础模型迁移能力的破坏。本文切入点在于：在纯视觉范式下，探究基础模型中间层特征是否包含末层丢失的互补信息，并据此构建针对科学长尾场景的适配框架。

## 核心方法

### 方法参照系

本文问题属于基础模型微调下的长尾识别，标准流程为：使用预训练 ViT 骨干，通过 PEFT 模块（如 AdaptFormer）适配下游任务，提取末层特征并接分类器，采用交叉熵（CE）或 Logit 调整（LA）损失训练。本文的关键差异在于：不依赖文本先验，且质疑末层特征在域偏移下的充分性，转而挖掘倒数第二层特征的互补价值。

### 多层特征自适应融合

在标准微调流程中，仅使用末层特征 $z_N$ 进行预测，假设其已编码所有判别性语义。然而，在科学图像域偏移下，末层投影可能丢失倒数第二层 $z_{N-1}$ 中保留的特定信息。SciLT 引入门控融合机制，动态加权两层特征以构建统一表示 $\tilde{z}$：

$$ \tilde{z} = \alpha_{N-1} z_{N-1} + \alpha_N z_N $$

其中 $\alpha_{N-1} = \text{Sigmoid}(W_1^T z_{N-1})$ 和 $\alpha_N = \text{Sigmoid}(W_2^T z_N)$ 为可学习门控分数。该设计动机在于：Wasserstein 距离分析表明两层特征分布存在显著差异（如 NIH-Chest 上 CE 训练下距离为 0.98），非简单线性变换，融合可恢复末层丢失的判别信号，尤其利于样本稀缺的尾部类别。

### 双分支差异化监督

融合特征 $\tilde{z}$ 经分类器 $g_1$ 输出预测 $s_1$，同时末层特征 $z_N$ 经独立分类器 $g_2$ 输出预测 $s_2$。训练时采用差异化损失：融合分支使用 Logit 调整（LA）损失以显式对抗类别不平衡，末层分支使用标准 CE 损失以保持整体识别能力：

$$ \mathcal{L} = \mathcal{L}_{LA}(s_1, y) + \mathcal{L}_{CE}(s_2, y) $$

推理时集成两分支预测。此设计解决了单一损失在长尾场景下的权衡困境：LA 提升尾部性能但可能损害头部，CE 保持头部性能但忽略尾部。双分支结构通过功能分离，实现了头部与尾部性能的帕累托优化，避免了单模型内部梯度冲突导致的特征坍缩。

## 实验评估

实验在 Blood、ISIC、NIH-Chest 三个科学长尾基准上进行，使用 ViT-B/16 预训练模型与 AdaptFormer 适配。基线覆盖从零训练（ResNet-18）的 CE、CB、LDAM、LA、Focal、LADE，以及微调方法 LPT、LIFT、VL-LTR。缺失生成式方法（如 DiffuLT）及多专家集成方法（如 BBN）的对比，限制了与数据增强及架构多样性路线的全面比较。

| 数据集 | 方法 | OvAcc (%) | Macro (%) | BScore (%) |
| :--- | :--- | :--- | :--- | :--- |
| NIH-Chest | CE (Scratch) | 41.0 | 13.6 | 15.58 |
| NIH-Chest | LA (Scratch) | 22.2 | 93.0 | 11.33 |
| NIH-Chest | CE (Fine-tune) | 39.7 | 11.1 | 19.7 |
| NIH-Chest | SciLT | 36.3 | 18.8 | 38.9 |
| ISIC | CE (Scratch) | 75.3 | 65.9 | - |
| ISIC | CE (Fine-tune) | 79.9 | 62.2 | - |
| ISIC | SciLT | 74.5 | 71.1 | 74.5 |

在 NIH-Chest 上，SciLT 的 BScore 达 38.9%，较 CE 微调的 19.7% 提升 19.2 个百分点，但 OvAcc 从 39.7% 降至 36.3%，表明以少量整体准确率为代价换取了显著的尾部类别平衡性。ISIC 上 SciLT 的 Macro 准确率 71.1% 高于 CE 微调的 62.2%，验证了多层融合在中等域偏移下的有效性。

消融实验显示，移除融合模块后，NIH-Chest 的 BScore 从 38.9% 降至 21.1%，降幅达 17.8 个百分点，证实融合机制是性能提升的核心来源。值得注意的是，LA 损失在从零训练时 Macro 准确率高达 93.0%，但 OvAcc 仅 22.2%，显示极端重加权在域偏移下可能导致头部性能崩溃，而 SciLT 的双分支设计有效缓解了此问题。

评估协议未强制测试集平衡，更贴近真实场景，但缺乏置信区间报告，数值比较需谨慎。代码未公开，超参数细节（如门控权重初始化）未在正文详述，可复现性受限。

## 关联研究分析

从问题动机看，LIFT 和 VL-LTR 依赖文本先验初始化或联合优化，假设文本语义能可靠引导视觉特征学习。本文指出在科学图像中，专业概念（如“Atelectasis”）在预训练语料中表征不足，文本嵌入不可靠，因此转向纯视觉多层融合。这一差异根源在于科学图像的语义粒度与预训练语料分布不匹配，而非方法本身的优劣。LIFT 在自然图像上的成功是否可迁移至科学图像，论文通过实验否定了其直接有效性，但未探讨文本与视觉融合的混合策略在特定科学子域（如病理切片）中是否仍具潜力。

从方法设计看，BBN 等多专家集成方法通过训练针对不同分布的专家模型来覆盖全类别，而 SciLT 采用单模型双分支结构，基于特征层级而非数据分布进行互补。BBN 的计算开销大，SciLT 的开销较小，但 SciLT 仅利用倒数第二层，未探索更深层级的交互。这种设计选择是否源于科学图像域偏移特有的特征退化模式，还是通用长尾场景下的通用改进，论文未提供跨域对比实验加以区分。若 SciLT 在自然图像长尾基准上同样有效，则其贡献更偏向通用架构优化；若仅在科学图像上有效，则其价值局限于特定域偏移场景。

## 总结

本文核心矛盾在于科学图像域偏移下基础模型末层特征信息丢失与长尾分布尾部类别样本稀缺的叠加效应。现有 VLM 方法因文本先验失效而受限，单一末层特征微调无法恢复丢失的判别信息。SciLT 通过自适应融合倒数第二层与末层特征，并施加 LA 与 CE 差异化监督，在 NIH-Chest 上将 BScore 从 19.7% 提升至 38.9%，在 ISIC 上将 Macro 准确率从 62.2% 提升至 71.1%。其边界在于仅利用倒数第二层，未探索更深层级交互，且缺乏生成式及多专家集成方法的对比。当域偏移程度进一步加剧或类别数显著增加时，倒数第二层特征的互补性是否仍足以支撑尾部类别的鲁棒识别，论文未给出回答。
