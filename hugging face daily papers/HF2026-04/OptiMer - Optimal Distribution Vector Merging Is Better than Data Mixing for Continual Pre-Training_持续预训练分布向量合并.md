# HuggingFace最新推荐论文 ｜OptiMer: Optimal Distribution Vector Merging Is Better than Data Mixing for Continual Pre-Training ｜持续预训练分布向量合并

作者：Haiyue Song、Masao Utiyama

论文原文见 [arXiv](https://arxiv.org/abs/2603.28858)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.28858)

> 持续预训练（Continual Pre-training, CPT）旨在将预训练大语言模型（LLM）适配至特定语言或领域，但数据混合比例作为敏感超参数，必须在训练前固定，导致次优选择浪费数周算力。现有基于代理模型或回归拟合的静态优化方法无法在训练后修正比例，且存在代理与全量模型间的尺度偏差。本文提出OPTIMER，通过独立训练各数据集的CPT模型并提取分布向量，利用贝叶斯优化在训练后搜索最优合并权重，实现零重训练的目标导向模型定制。该方法在Gemma 3 27B上较数据混合基线提升2.1–6.7分，搜索成本降低15–35倍，但其线性合并假设在复杂非线性轨迹下的普适性仍存疑。

## 研究背景

CPT的核心困境在于数据混合比例对模型性能的强敏感性。当模型从基础预训练状态（$\theta_{pt}$）向特定分布（如日语、数学）迁移时，参数空间中的变化量被定义为分布向量（Distribution Vector），即 $\tau_i = \theta_{CPT_i} - \theta_{pt}$。这一向量编码了单一数据集对模型参数的净影响，而指令微调向量（IT Vector）$\tau_{it} = \theta_{it} - \theta_{pt}$ 则用于恢复指令跟随能力。由于不同分布诱导的参数变化在空间中近似正交，理论上可通过线性组合这些向量来重构多领域能力，从而规避传统数据混合中“先定比例后训练”的刚性约束。

传统数据混合优化路线依赖代理模型（Proxy Model）或回归拟合预测最优比例，如DoReMi和RegMix。这些方法的核心假设是数据效用恒定，且必须在训练开始前确定比例，一旦比例次优，整个训练周期即告失败，无法中途修正。此外，代理模型与全量模型间的尺度偏差（Scaling Gap）使得小模型预测的比例在大模型上可能失效。本文的切入点在于将比例选择从“训练前决策”重构为“训练后优化”，利用分布向量的线性可组合性，在参数空间直接搜索最优权重，从而解耦数据比例选择与模型训练过程。

## 核心方法

### 分布向量定义与线性组合

本文方法参照系为任务向量（Task Vector）合并，但针对CPT场景扩展为多分布向量组合。传统任务向量合并仅处理单一微调任务，而CPT涉及多个独立分布的叠加。本文定义分布向量 $\tau_i$ 为CPT模型与基础模型的参数差，并假设不同分布的向量在参数空间中近似正交，使得线性组合 $\theta_{merge} = \theta_{pt} + \alpha_{it}\tau_{it} + \sum_{i=1}^n \alpha_i \tau_i$ 能够以最小干扰重构多领域能力。这一设计动机在于消除传统数据混合中比例固定的滞后性，允许在训练完成后通过调整权重 $\alpha_i$ 灵活适配不同目标。

### 基于TPE的贝叶斯优化搜索

合并权重 $\alpha$ 的搜索被形式化为黑盒优化问题，因为评估分数 $S$ 来自离散基准测试，无法提供梯度。传统网格搜索复杂度为 $O(G^{n+1})$，随向量数量指数增长，不可行。本文采用树结构帕森估计器（Tree-structured Parzen Estimator, TPE）进行贝叶斯优化，其核心公式为：

$$
\alpha_{next} = \arg\max_{\alpha} \frac{\ell(\alpha)}{g(\alpha)}
$$

其中 $\ell(\alpha)$ 和 $g(\alpha)$ 分别通过核密度估计建模高分配置和低分配置的密度分布。该公式的物理含义是：通过最大化“好配置”与“坏配置”的密度比，将采样集中在权重空间中性能较高的区域。相比网格搜索，TPE通常收敛于 $O(10^n)$ 次试验，且支持并行执行，显著降低了搜索成本。这一创新解决了传统回归拟合方法依赖代理模型且无法处理高维权重空间的局限，实现了全量模型上的高效比例优化。

## 实验评估

实验基于Gemma 3 27B，使用LLM-jp Corpus v4构建日语、中文、数学、代码数据集，每个数据集1B tokens。基线覆盖数据混合（DataMix）、任务算术（Task Arithmetic）、TIES、DARE-Linear等模型合并方法，但缺失FastMix、HDS等动态调度方法，因本文是训练后方法，与在线重加权路线不可直接对比。

| 组合 | 方法 | Avg. |
|---|---|---|
| Ja + Math | DataMix | 67.86 |
| Ja + Math | OPTIMER | 69.98 |
| Ja + Code | DataMix | 67.23 |
| Ja + Code | OPTIMER | 69.68 |
| Ja + Zh + Math | DataMix | 63.71 |
| Ja + Zh + Math | OPTIMER | 70.37 |

OPTIMER在所有组合中均优于DataMix基线，提升幅度2.1–6.7分。值得注意的是，DataMixOptiMer ratio（使用OPTIMER发现的权重重新训练数据混合模型）也优于均匀比例DataMix，证明OPTIMER发现的权重确实对应更优的数据比例，但OPTIMER仍优于重新训练，表明事后合并本身具有额外优势。

消融实验显示，分布向量间余弦相似度为0.03–0.31，支持线性组合的可行性。训练动态分析表明CPT轨迹在参数空间中近似线性，合并权重可解释为有效训练时长。然而，模型合并方法（如DARE-Linear）在代码任务上出现严重退化（HumanEval得分0.00–0.80），生成语法错误代码，而OPTIMER保持较高分数，说明优化权重能更好地保留基础模型校准。

评估边界方面，实验仅覆盖Gemma 3 27B单一骨干，未验证其他模型规模或架构。评估协议使用1-shot prompting，未报告置信区间，数值比较需谨慎。代码开源（github.com/shyyhs/optimer），超参数设置详细（AdamW, lr=4e-5, 8x H200 GPUs），可复现性较好。

## 关联研究分析

从问题动机看，本文与DoReMi、RegMix等静态混合优化方法存在根本差异。DoReMi依赖代理模型进行分布鲁棒优化，RegMix通过回归拟合预测比例，两者均需在训练前固定比例，且受限于代理与全量模型的尺度偏差。本文则完全摒弃代理模型，直接在全量CPT模型上提取向量并优化权重，消除了尺度偏差，但增加了初始训练成本（需独立训练n个模型）。这一差异源于任务特性：CPT场景下数据规模相对较小（1B tokens/数据集），独立训练成本可控，而从头预训练场景下数据规模巨大，独立训练不可行，因此本文方法难以直接推广至从头预训练。

从方法设计看，本文与Task Arithmetic、TIES等模型合并方法同属参数空间操作，但本文引入了贝叶斯优化替代均匀权重或启发式权重。Task Arithmetic使用均匀权重 $\alpha_i = 1/n$，TIES通过符号冲突解决优化权重，但均未针对CPT多分布场景进行系统优化。本文的TPE搜索针对高维权重空间，且利用分布向量的正交性假设，使得搜索效率更高。然而，本文未探索非线性合并函数（如DARE-Linear的稀疏化）对性能的影响，仅使用DARE-Linear作为合并函数，未比较不同合并函数对最终性能的影响，这可能限制了方法在复杂非线性轨迹下的适用性。

## 总结

本文解决的核心矛盾是CPT中数据混合比例必须训练前固定导致的算力浪费与性能次优。现有静态优化方法因依赖代理模型且无法训练后修正而失效，本文凭借分布向量的近似正交性与线性可组合性，将比例选择重构为训练后的贝叶斯优化问题。OPTIMER通过独立训练各数据集CPT模型并提取分布向量，利用TPE搜索最优合并权重，在Gemma 3 27B上较DataMix基线提升2.1–6.7分，搜索成本降低15–35倍。本文的边界在于仅验证了单一骨干模型与1B tokens数据规模，且线性合并假设在复杂非线性CPT轨迹下的普适性未充分验证。当数据规模扩大至10B tokens或骨干模型更换为Llama系列时，分布向量的正交性假设是否依然成立，论文未给出回答。
