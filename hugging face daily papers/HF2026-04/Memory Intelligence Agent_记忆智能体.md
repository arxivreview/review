# HuggingFace最新推荐论文 ｜Memory Intelligence Agent ｜记忆智能体

研究机构：华东师范大学、哈尔滨工业大学

作者：Jingyang Qiao、Weicheng Meng、Yu Cheng 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.04503)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.04503)

> 深度研究智能体（Deep Research Agents, DRA）在长程任务中面临历史经验利用效率低与存储成本激增的矛盾。现有长上下文记忆方法因引入噪声和稀释注意力，往往导致性能不升反降，而基于提示工程的规划器缺乏任务特异性训练，无法有效指导执行。MIA 通过 Manager-Planner-Executor 架构，将非参数记忆压缩为结构化工作流，并引入交替强化学习（RL）与测试时学习（TTL）机制，实现记忆的参数化内化与自主进化。该框架在小模型上展现出显著增益，但其对大模型能力的依赖及无监督进化的稳定性仍存疑。

## 研究背景

深度研究智能体依赖多轮工具调用获取外部信息，其核心挑战在于如何高效利用历史搜索轨迹。长上下文记忆（Long-Context Memory）是主流方案，但存在根本局限：长文本稀释模型对当前问题的注意力，无关内容引入噪声导致推理退化，且随时间推移存储与检索成本呈线性增长。更关键的是，长上下文主要存储“结果是什么”的事实性知识，而深度研究更需要“结果如何获得”的过程性记忆（Process-Oriented Memory），如搜索策略与失败教训。

现有记忆系统多采用预训练模型作为规划器，通过少样本提示（Few-Shot Prompting）生成思维链（Chain-of-Thought, CoT）来指导搜索。然而，这种非参数化方法存在三个瓶颈：规划器未经任务特定训练，规划质量次优；少样本选择仅基于相关性，忽略质量与频率维度；执行器（Executor）缺乏训练，难以准确遵循规划指令。这导致记忆系统引入后性能提升有限，甚至因噪声干扰而低于无记忆基线。MIA 的切入点在于将记忆从“检索原始轨迹”转变为“参数化内化经验”，通过训练规划器与执行器的协同，解决记忆利用效率低与存储瓶颈问题。

## 核心方法

### 方法参照系

MIA 属于架构与规划策略路线，其参照系为基于 ReAct 范式的多智能体搜索框架。与 Search-R1 等纯 RL 方法不同，MIA 的核心差异在于引入显式的记忆管理模块（Manager），将非参数记忆转化为参数化规划能力，而非仅依赖端到端策略优化。

### 双记忆架构与混合检索

MIA 采用 Manager-Planner-Executor 架构，其中 Manager 负责非参数记忆的压缩与检索，Planner 负责生成搜索计划，Executor 负责执行。Manager 将历史轨迹压缩为结构化工作流，通过混合检索策略为 Planner 提供上下文。检索评分函数综合考虑语义相似度、价值奖励与频率奖励：

$$
S(m) = \alpha \cdot Sim(q, m) + \beta \cdot R_{value}(m) + \gamma \cdot R_{freq}(m)
$$

其中 $Sim(q, m)$ 为当前查询与记忆单元 $m$ 的语义距离，$R_{value}$ 优先选择高成功率轨迹，$R_{freq}$ 奖励低频单元以探索长尾知识。该设计解决了传统单维度检索忽略记忆质量与利用均衡的问题，使 Planner 能获取高质量且多样化的上下文先验。

### 交替强化学习与测试时学习

Planner 与 Executor 通过交替 RL 范式协同优化，确保高层规划与底层检索的对齐。Planner 将非参数记忆转化为参数化知识，减少存储开销；Executor 学习遵循规划指令。此外，MIA 引入测试时学习（Test-Time Learning, TTL）机制，允许 Planner 在推理过程中动态更新参数，实现无监督条件下的自主进化。TTL 的更新规则基于反思机制，当执行结果偏离预期时，Planner 重新规划并更新内部状态：

$$
\theta_{planner}^{t+1} = \theta_{planner}^{t} + \eta \cdot \nabla_{\theta} \mathcal{L}_{reflect}(o_t, p_t)
$$

其中 $\mathcal{L}_{reflect}$ 为基于执行轨迹 $o_t$ 与规划 $p_t$ 的反思损失。该机制使智能体能在缺乏标注数据时，通过自我验证与修正实现持续进化，解决了静态记忆系统无法适应新信息的问题。

## 实验评估

实验在 11 个基准上进行，包括多模态（FVQA, LiveVQA, MMSearch）与纯文本（SimpleQA, HotpotQA, GAIA）任务。基线覆盖无记忆、RAG、Mem0、ReasoningBank、ExpeL、Memento 等记忆方法，以及 MMSearch-R1、DeepMMSearch-R1 等搜索智能体。MIA 在 Qwen2.5-VL-7B 骨干上取得平均准确率 53.6%，比最强记忆基线 Memento 高 5.5%，在 GAIA 上达 31.1%，比 Memento 高 8.8%。

| 模型 | FVQA-test | LiveVQA | HotpotQA | GAIA |
| :--- | :--- | :--- | :--- | :--- |
| No Memory | 61.4 | 49.0 | 42.4 | 14.6 |
| Memento | 66.3 | 55.3 | 55.2 | 22.3 |
| MIA (Ours) | 69.6 | 62.6 | 63.5 | 31.1 |

消融实验显示，仅引入非参数记忆（Only Memory）导致多模态任务平均准确率下降 0.4，验证了长上下文噪声的负面影响。引入“Memory for Planner”架构后，平均准确率提升 3.5（多模态）与 4.15（纯文本）。交替 RL 训练（Trained Planner）进一步提升 2.37（多模态）与 1.72（纯文本），而 TTL 机制带来最终 3.23（多模态）与 2.64（纯文本）的增益。这表明参数化内化与动态进化是性能提升的关键，而非单纯记忆检索。

评估边界方面，MIA 在 GAIA 上的绝对性能（31.1%）低于前沿大模型（如 Fathom-DeepResearch 的 45.47%），但考虑到其 7B 骨干规模，相对增益显著。代码与模型已开源，但 TTL 机制的超参数敏感性未详细披露，可能影响复现稳定性。

## 关联研究分析

从问题动机看，MIA 与 ExpeL 均关注经验学习，但 ExpeL 依赖提示工程优化决策，而 MIA 通过 RL 将经验内化为参数化知识。这一差异源于任务复杂度：深度研究需要长程策略一致性，提示工程难以维持，而参数化训练能捕捉更深层的模式。MIA 的 Manager 模块压缩轨迹，解决了 ExpeL 中记忆膨胀导致的检索噪声问题，但代价是增加了架构复杂度。

从方法设计看，MIA 与 Search-R1 同属 RL 路线，但 Search-R1 聚焦端到端策略优化，MIA 则引入显式规划-执行解耦。Search-R1 的奖励信号基于最终答案，而 MIA 的交替 RL 优化规划与执行的协同，更适合多模态任务。然而，MIA 的 TTL 机制在推理时更新参数，可能引入分布偏移，论文未探讨其对长期稳定性的影响。

## 总结

MIA 解决的核心矛盾是深度研究智能体中历史经验利用效率低与存储成本增长的冲突。其切入点在于将非参数记忆转化为参数化规划，通过 Manager-Planner-Executor 架构实现记忆的内化与进化。实验证明，MIA 在 7B 骨干上比最强记忆基线平均提升 5.5%，在 GAIA 上提升 8.8%。然而，其绝对性能仍受限于骨干模型规模，且 TTL 机制的长期稳定性未充分验证。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
