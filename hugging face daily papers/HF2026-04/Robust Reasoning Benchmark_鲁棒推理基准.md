# HuggingFace最新推荐论文 ｜Robust Reasoning Benchmark ｜鲁棒推理基准

研究机构：加拿大多伦多大学、加拿大向量研究所

作者：Pavel Golikov、Evgenii Opryshko、Gennady Pekhimenko 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.08571)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.08571)

> 大语言模型在数学基准上的高分往往掩盖其推理过程的脆弱性，现有对抗性评估方法通过改变数值或增加干扰项来测试鲁棒性，但常引入混淆变量，无法区分解析失败与逻辑推理失败。本文提出鲁棒推理基准（Robust Reasoning Benchmark, RRB），通过14种确定性结构扰动保持数学逻辑不变，仅改变文本呈现形式，以隔离模型对表面形式的依赖。实验揭示开源模型在结构扰动下出现高达55%的准确率崩塌，并发现模型自身推理步骤会污染后续问题的解答，暴露出标准注意力机制缺乏工作记忆隔离的架构缺陷。该基准提供了区分“统计记忆”与“算法推理”的新维度，但闭源模型的高鲁棒性是否源于架构差异仍存疑。

## 研究背景

当模型面对一道数学题时，其内部处理依赖于将自然语言映射为符号操作序列。这一过程受限于分词器（Tokenizer）的离散化特性，数字和符号被拆分为子词单元，导致嵌入空间缺乏几何连续性。若模型仅依赖这些子词的统计共现概率而非深层逻辑结构，则对文本表面形式的微小扰动将表现出极端敏感性。这种敏感性在静态基准的高准确率下被掩盖，构成了“高分幻觉”的核心机制。

数学推理鲁棒性评估的主流路线分为两类：一是改变数值变量以测试泛化能力，如GSM-Symbolic通过替换数字揭示模型对特定数值的记忆；二是增加环境复杂度，如注入无关上下文或提高逻辑难度。然而，前者修改了数学约束本身，导致无法区分算术错误与逻辑错误；后者引入了难度混淆，难以区分鲁棒性不足与模型能力上限。此外，部分基准依赖大模型生成扰动，引入了非确定性噪声。本文的切入点在于设计一种“结构不变、语义不变”的扰动机制，通过确定性算法变换文本结构，严格隔离解析能力与推理能力，从而精准定位模型失败的机械根源。

## 核心方法

### 确定性结构扰动框架

对抗性评估的标准流程通常涉及修改输入数据的语义或数值属性。本文的关键差异在于保持数学问题的原始状态（pristine mathematical state）完全不变，仅施加可逆的算法变换。这种设计确保了任何性能下降均源于模型对文本结构的解析失败，而非数学逻辑的误解。

### 14种文本变换与顺序认知过载

扰动分为四类：语义/词汇替换（如双重否定、反义词映射）、上下文过载（如交错上下文、上下文饱和）、语法扭曲（如句子/单词/符号反转）以及视觉空间编码（如栅栏密码、蛇形网格）。所有变换遵循信息论不变性、算法可逆性、认知可处理性及显式解码协议四原则。

$$
\text{Accuracy}_{\text{last}} = \frac{1}{N} \sum_{i=1}^{N} \mathbb{I}(\hat{y}_i = y_i^{\text{target}})
$$

其中 $\hat{y}_i$ 为模型在包含 $i$ 个前置干扰题的序列中，对最后目标题生成的答案，$y_i^{\text{target}}$ 为真值。该公式量化了“查询内注意力稀释”（Intra-Query Attention Dilution），即模型自身生成的中间推理步骤如何污染后续问题的解答。

设计动机在于解决现有方法无法区分“解析失败”与“推理失败”的瓶颈。通过顺序认知过载实验，仅评估最后一题的准确率，可以剥离单题扰动的影响，直接测量上下文窗口内工作记忆的隔离能力。实验表明，开源模型（7B-120B）在此协议下准确率随前置题目数量增加而显著下降，而GPT-5.4和Gemini 3.1 Pro表现出强韧性，暗示标准密集注意力机制缺乏固有的工作记忆隔离能力。

## 实验评估

实验基于AIME 2024数据集，评估5个开源模型（Qwen3-30B, Nemotron-7B/32B, DSR1-Llama-70B, GPT-OSS-120B）和3个闭源模型（GPT-5.4, Gemini 3.1 Pro, Claude Opus 4.6）。基线覆盖主流开源与闭源旗舰模型，但未对比CoT/ToT等推理增强策略在扰动下的表现，仅测试基座模型的鲁棒性。

| 模型 | 平均准确率下降 (%) |
| :--- | :--- |
| GPT-5.4 | 7 |
| Gemini 3.1 Pro | 10 |
| Claude Opus 4.6 | 41.7 |
| Qwen3-30B-A3B | 47 |
| Nemotron-7B | 55 |

闭源模型GPT-5.4和Gemini 3.1 Pro的平均下降幅度仅为7%和10%，而开源模型Nemotron-7B和Qwen3-30B分别下降55%和47%。Claude Opus 4.6的41.7%下降主要归因于安全过滤器将符号操纵误判为提示注入，而非推理失败。在顺序认知过载实验中，开源模型在解决多题序列时，最后一题的准确率随前置题目数量增加而显著衰减，例如Qwen3-30B在4题序列中准确率从基线下降至约60%以下，而GPT-5.4保持90%以上。

消融分析显示，开源模型在“语法扭曲”和“视觉编码”类别上表现最差，尤其是将单词拆分为孤立字符的变换（如Interleave Symbol）导致Qwen3和DSR1准确率降至0%。这揭示了子词语义先验（subword semantic priors）是推理瓶颈，模型无法将孤立字符映射回连贯的内部因果图。视觉编码中，Snake Horizontal（水平蛇形）与Snake Vertical（垂直蛇形）的性能差异巨大，Gemini 3.1 Pro在水平任务中得98%，垂直任务中降至65%，Qwen3则从16%降至接近1%，证实了Transformer从左到右的1D预训练偏差对2D空间映射的固有约束。

评估边界方面，本文未报告置信区间，且闭源模型因计算成本仅采样基线和4题序列。可复现性受限于闭源API的黑盒特性，开源模型提供了完整超参数（温度0.7，top_p 1.0，max_tokens 32000）。代码未公开，但变换规则为确定性算法，理论上可复现。

## 关联研究分析

从问题动机看，RRB与GSM-Symbolic均旨在区分记忆与推理，但扰动机制存在根本差异。GSM-Symbolic通过改变数值测试算术泛化，而RRB保持数值不变，仅改变文本结构。这一差异源于任务特性的不同：GSM-Symbolic关注模型是否“记住”了特定数字组合，RRB关注模型是否“理解”了符号操作的逻辑结构。RRB的确定性扰动避免了GSM-Symbolic中数值替换可能引入的数学约束变化，从而更纯粹地测试解析鲁棒性。

从方法设计看，RRB与MatheMagic同属动态评估路线，但MatheMagic通过改变算术规则（如反事实数学）测试泛化，RRB则通过结构扰动测试鲁棒性。MatheMagic的扰动涉及数学逻辑本身，而RRB的扰动严格限于文本呈现形式。这种设计选择使得RRB能够更精细地定位失败根源：是模型无法解析扭曲的文本，还是无法执行正确的数学推理。RRB引入的“顺序认知过载”协议是MatheMagic未涉及的维度，它揭示了上下文窗口内工作记忆隔离的架构缺陷，为理解长程推理中的注意力漂移提供了新视角。

## 总结

RRB旨在解决静态基准高分掩盖推理脆弱性的矛盾，通过14种确定性结构扰动隔离解析与推理失败。其核心创新在于保持数学逻辑不变，仅改变文本结构，并引入顺序认知过载协议量化工作记忆污染。实验证明开源模型在结构扰动下平均准确率下降高达55%，且存在显著的查询内注意力稀释效应，而闭源模型表现出强韧性。本文的边界在于未对比推理增强策略在扰动下的表现，且闭源模型的高鲁棒性可能源于架构或对齐机制的差异，而非单纯的规模效应。当开源模型规模扩大至120B时，其结构鲁棒性是否仍无法超越闭源模型，论文未给出回答。
