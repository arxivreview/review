# HuggingFace最新推荐论文 ｜GFT: From Imitation to Reward Fine-Tuning with Unbiased Group Advantages and Dynamic Coefficient Rectification ｜组微调：从模仿到奖励的无偏优化

作者：Wangjie Gan、Miao Pan、Linbo Xi 等 7 人

> 大语言模型后训练的核心矛盾在于，监督微调（SFT）虽能高效注入知识，却因单路径依赖导致策略熵坍缩，并引发灾难性遗忘，使得后续强化学习（RL）的探索空间被严重压缩。现有方案如标准SFT或纯RL均无法在保持通用能力与提升推理上限间取得平衡，本文切入点在于从训练动力学视角揭示SFT本质上是带有不稳定逆概率权重的稀疏奖励RL特例。通过引入组优势学习与动态系数校正，GFT在单一阶段内实现了无偏对比监督与优化稳定性的统一。该框架在数据效率上显著优于SFT基线，但其绝对性能仍低于当前SOTA混合策略，且对多任务场景下的组构成动态调整缺乏验证。

## 研究背景

当模型在数学推理任务上进行SFT时，其策略往往被限制在专家演示的狭窄流形上，这种现象称为单路径依赖。单路径依赖导致模型对未见过但有效的推理路径赋予极低概率，进而引发策略熵坍缩，使得下游RL阶段可用的探索预算大幅缩减。为理解这一失效机制，需将SFT置于策略梯度框架下审视，此时SFT可被视为一种特殊的RL，其奖励函数仅在输出与专家轨迹完全匹配时提供非零信号，且梯度更新受逆概率权重 $1/\pi_\theta(y|x)$ 的调制。

后训练领域长期存在SFT与RL目标冲突的难题，主流路线采用“SFT冷启动+RL探索”的串联范式，但SFT阶段引发的分布漂移与遗忘效应常抵消RL带来的增益，形成“协同困境”。本文从训练动力学角度切入，指出SFT的泛化局限源于两个根本缺陷：一是稀疏奖励导致的探索不足，二是逆概率权重在低概率token上引发的梯度爆炸。这一视角为设计兼顾知识注入效率与策略稳定性的统一后训练方法提供了理论依据。

## 核心方法

### 方法参照系

标准SFT流程通过最小化交叉熵损失模仿专家演示，其梯度形式为 $\nabla_\theta \log \pi_\theta(y^*|x)$。该流程的关键差异在于，它未显式考虑替代输出的相对质量，且梯度更新幅度受当前策略概率的倒数调制，导致优化过程对低概率token极度敏感。

### 组优势学习

组优势学习（Group Advantage Learning, GAL）旨在解决SFT单路径依赖导致的探索不足问题。对于每个查询 $x$，GAL构建一个包含 $K$ 个候选轨迹的混合响应组 $G_x = \{y_1, ..., y_K\}$，其中融合了专家演示、教师蒸馏输出及模型自生成样本。每个轨迹 $y_k$ 被赋予标量奖励 $R(y_k)$，并计算标准化优势分数：

$$ A_k = \frac{R(y_k) - \bar{R}(G_x)}{\sigma_R(G_x) + \epsilon} $$

该公式通过组内归一化将稀疏的绝对奖励转化为相对对比信号，使模型能够区分不同质量轨迹的优劣，而非仅模仿单一专家路径。这一设计保留了早期后训练中的探索多样性，避免了策略过早收敛至单一模式。

### 动态系数校正

动态系数校正（Dynamic Coefficient Rectification, DCR）承接GAL输出的对比信号，解决逆概率权重引发的梯度爆炸问题。针对低置信度token（$\pi_t < \tau$），DCR引入截断机制：

$$ w_t = \begin{cases} \text{sg}(\pi_t) & \text{if } \pi_t < \tau \\ 1 & \text{if } \pi_t \ge \tau \end{cases} $$

其中 $\text{sg}(\cdot)$ 为停止梯度算子，$\tau$ 为动态阈值。该机制通过有界的有效系数抑制极端样本的梯度更新，同时保留高置信度token的完整学习强度。这一设计在稳定优化过程的同时，确保了新知识的高效注入，避免了标准SFT中因梯度爆炸导致的机械记忆与过拟合。

## 实验评估

实验在NuminaMath CoT数据集上进行，对比基线涵盖标准SFT、其稳定变体（DFT, ASFT, PSFT）及RL基线GRPO，但缺失RLHF及DPO类偏好优化基线。GFT在仅使用10k训练样本的情况下，性能匹配或超越使用100k样本的SFT基线，表明其数据效率优势源于训练机制而非额外蒸馏数据。

| 模型 | 方法 | MATH | Minerva Math | TabMWP |
| :--- | :--- | :--- | :--- | :--- |
| Qwen2.5-Math-1.5B | Base Model | 46.54 | 10.51 | 24.55 |
| | + SFT | 60.66 | 23.99 | 79.34 |
| | + GRPO | 65.97 | 21.17 | 76.94 |
| | + GFT (Ours) | 70.50 | 28.93 | 85.24 |

在Qwen2.5-Math-1.5B上，GFT在MATH基准上达到70.50，显著高于SFT的60.66和GRPO的65.97，验证了组对比信号与动态校正的协同效应。

消融实验显示，移除GAL导致在Olympiad基准上性能下降最显著，证实组对比对复杂推理的关键作用；移除DCR则主要影响Minerva基准的鲁棒性，符合其抑制梯度爆炸的设计初衷。组构成比例分析表明，2:6（演示:自生成）的比例在Minerva、Olympiad及Sat Math上均取得最佳平均性能（45.59），暗示自生成样本提供的丰富对比信号优于纯蒸馏数据。

评估边界方面，论文未报告置信区间，且仅在数学推理领域验证，缺乏代码生成或通用对话任务的对比。超参数 $\tau$ 的敏感性分析显示，过大的 $\tau$ 会降低学习效率，但论文未提供 $\tau$ 的自动调节策略。代码未公开，复现需依赖附录中的详细配置。

## 关联研究分析

从问题动机看，GFT与ASFT均旨在修正SFT的离策略偏差，但ASFT依赖重要性采样构建紧下界，对奖励函数准确性高度敏感，而GFT通过组内归一化直接生成相对优势，降低了对绝对奖励标度的依赖。这一差异源于GFT将SFT重构为组对比学习，而非单纯修正采样偏差，使得其在数据稀疏场景下更具鲁棒性。

从方法设计看，GFT与GRPO共享组相对优势的思想，但GRPO仅在RL阶段应用，而GFT将其前置至冷启动阶段。这种设计选择使得GFT能够作为RL的更强初始化器，但可能牺牲了SFT在格式规范建立上的效率。论文未验证GFT替代SFT后，模型在指令遵循格式上的表现是否受损，这一盲区限制了其在通用对齐任务中的适用性。

## 总结

本文核心矛盾在于SFT单路径依赖引发的策略熵坍缩与梯度爆炸，导致后训练协同困境。切入点在于揭示SFT作为稀疏奖励RL特例的训练动力学缺陷，通过组优势学习与动态系数校正实现无偏对比与优化稳定的统一。实验证明GFT在MATH基准上达到70.50，显著优于SFT的60.66，且数据效率提升10倍。边界在于仅验证数学推理任务，且未解决GFT替代SFT后格式规范建立的潜在缺失。当支持集增大到10-shot时，组构成比例的边际收益是否递减，论文未给出回答。
