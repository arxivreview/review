# HuggingFace最新推荐论文 ｜Prompt Relay: Inference-Time Temporal Control for Multi-Event Video Generation ｜提示中继（Prompt Relay）：推理时多事件视频生成的时间路由机制

研究机构：新加坡南洋理工大学

作者：Gordon Chen、Ziqi Huang、Ziwei Liu

论文原文见 [arXiv](https://arxiv.org/abs/2604.10030)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.10030)

> 视频扩散模型在处理包含多个连续事件的提示时，常因交叉注意力的全局性导致语义概念在不同时间段相互渗透，造成时序错乱。现有训练式方法依赖大量标注数据且改变预训练分布，而硬掩码式推理控制则在段间边界产生视觉伪影。本文提出 Prompt Relay，一种在推理阶段通过高斯衰减惩罚项对交叉注意力进行软路由的免训练机制，使每个时间片段仅关注其对应的局部提示。该方法在时间对齐与过渡自然度上显著优于基线，但视觉保真度仍受限于骨干模型容量，且缺乏自动量化指标支撑。

## 研究背景

当用户输入一段描述“先倒麦片再倒牛奶”的长提示时，视频扩散模型往往无法区分这两个动作发生的具体时刻。这一困境源于交叉注意力机制（Cross-Attention）的固有特性：它将文本嵌入作为全局条件，使视频潜空间中的每个查询向量（Query）都能同时关注所有文本键（Key）。这种全局耦合导致不同时间段的语义概念在注意力权重中竞争，造成“语义纠缠”，即本应属于后段的概念提前泄露到前段画面中。为解决此问题，研究者通常引入时间感知机制，但如何在保持模型泛化能力的同时实现精确的时间隔离，成为核心挑战。

当前解决多事件时序对齐的主流路线分为两类。一类是训练式方法，如 MinT，通过引入可训练的时间交叉注意力模块将事件描述绑定到预定义时间区间，但这需要大量时间标注数据并修改模型架构，导致预训练分布偏移。另一类是推理时注意力控制方法，如 DiTCtrl 和 SwitchCraft，它们在去噪过程中直接操纵注意力权重。DiTCtrl 使用硬掩码（Hard Masking）阻断非目标时间段的注意力，SwitchCraft 则依赖主体锚点 token。然而，硬掩码在段间边界造成注意力信号的突变，与自注意力（Self-Attention）的连续性产生冲突，导致背景不一致或过渡生硬；而依赖主体的方法在场景级变化或无主导前景主体的事件中失效。本文的切入点在于，利用软性高斯衰减替代硬掩码，在推理阶段实现平滑的时间路由，既避免训练成本，又消除边界伪影。

## 核心方法

### 方法参照系

本文问题属于推理时可控视频生成范畴。标准流程是在扩散去噪步骤中，通过修改交叉注意力的 Logits 或掩码来限制文本条件对特定视频区域的影响。与通用流程的关键差异在于，本文不依赖主体特征或额外训练模块，而是直接基于时间索引对注意力权重施加平滑惩罚，实现全局时间路由。

### 时间提示路由

在标准交叉注意力中，查询向量 $Q$ 与键向量 $K$ 的点积决定注意力分布，导致所有文本 token 对同一视频帧产生竞争。本文在 Logits 中引入惩罚项 $C(i, j)$，其设计动机是解决硬掩码在段间边界造成的信号冲突。对于属于提示 $p_s$ 的键 $j$ 和查询 $i$，惩罚项定义为：

$$
C(i, j) = \begin{cases}
0 & \text{if } |f(i) - m_s| \le w \\
\frac{1}{2\sigma^2} (|f(i) - m_s| - w)^2 & \text{otherwise}
\end{cases}
$$

其中 $f(i)$ 为查询对应的潜帧索引，$m_s$ 为时间片段中点，$w$ 为无惩罚窗口宽度。该公式的物理含义是：在片段内部（窗口内）注意力不受限制，而在窗口外，注意力权重随时间距离呈高斯衰减。这种软路由机制允许模型在边界附近同时关注相邻片段，形成平滑的“交接区”，从而避免硬掩码导致的突变。

### 边界注意力衰减

为确保段间语义干扰被充分抑制，本文引入边界注意力衰减机制，通过调整衰减参数 $\sigma$ 控制惩罚强度。设计动机是解决固定惩罚强度在不同片段长度下表现不一致的问题。设片段端点距离中点的距离为 $L$，选择 $\sigma$ 使得在端点处注意力先验降至阈值 $\epsilon$：

$$
\sigma = \frac{L - w}{\sqrt{-2 \ln \epsilon}}
$$

该公式确保了无论片段长度如何，边界处的注意力抑制程度保持一致。当 $w = L - 2$ 时，$\sigma$ 变为常数，简化了计算。这一设计使得模型在保持片段内高保真度的同时，有效抑制了跨片段的语义泄漏，实现了时间隔离与视觉连贯性的平衡。

## 实验评估

实验基于 Wan2.2-T2V-A14B 骨干模型，对比 Sora Storyboard、Kling 2.6、Veo 3.1 及原始 Wan 2.2。基线覆盖了当前主流商业模型与开源骨干，但缺失了 TempoControl 等同类推理时控制方法的直接对比，限制了方法间公平性评估。

| 指标 (↓) | Sora Storyboard | Kling 2.6 | Veo 3.1 | Wan 2.2 | Wan 2.2 + Prompt Relay |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 时间提示对齐 | 4.67 | 1.30 | 3.93 | 4.00 | **1.10** |
| 过渡自然度 | 4.60 | 4.43 | 1.30 | 3.50 | **1.17** |
| 视觉质量 | 3.67 | 2.50 | **2.0** | 4.00 | 2.83 |

Prompt Relay 在时间对齐（1.10 vs 4.00）和过渡自然度（1.17 vs 3.50）上显著优于原始 Wan 2.2，表明软路由机制有效解决了语义纠缠。然而，其视觉质量（2.83）虽优于 Wan 2.2，但仍低于 Veo 3.1（2.0），说明时间控制并未提升骨干模型的视觉保真上限。

消融实验显示，窗口参数 $w = L - 2$ 在时间隔离与片段内保真度间取得最佳平衡，而衰减阈值 $\epsilon$ 在小值范围内对人眼感知影响可忽略。这一发现表明，软路由机制对超参数不敏感，增强了方法的鲁棒性。但论文未提供不同片段数量或复杂场景下的消融数据，限制了结论的泛化性。

评估仅依赖 30 名参与者对 20 个场景的人工偏好排名，缺乏 FVD 或 CLIP Score 等自动指标。人评虽能捕捉感知层面的过渡质量，但样本量较小且未报告置信区间，统计显著性存疑。此外，论文未开源代码，仅提供项目主页，可复现性受限。

## 关联研究分析

从方法设计看，Prompt Relay 与 DiTCtrl 同属推理时注意力控制，但核心差异在于边界处理策略。DiTCtrl 使用硬掩码，在段间边界强制切换注意力，导致自注意力与交叉注意力的信号冲突，产生背景伪影。Prompt Relay 采用高斯衰减，允许边界附近同时关注相邻片段，形成平滑过渡。这一差异源于任务特性：多事件视频需要视觉连贯性，硬切换破坏了这一前提。然而，软路由是否在所有场景下优于硬掩码，特别是在事件语义差异极大时，论文未给出回答。

从问题动机看，Prompt Relay 与 SwitchCraft 均旨在解决多事件时序对齐，但适用场景不同。SwitchCraft 依赖主体锚点 token，假设每个事件存在主导前景主体，因此在场景级变化或无主体事件中失效。Prompt Relay 基于全局时间索引，不依赖主体特征，适用于更广泛的场景。这一差异揭示了现有方法对“主体”的过度依赖，而 Prompt Relay 通过时间路由实现了更通用的控制。但全局时间路由在复杂空间布局（如多主体交互）中是否足以避免语义混淆，仍需进一步验证。

## 总结

Prompt Relay 针对视频扩散模型在多事件生成中的语义纠缠问题，通过推理时高斯衰减惩罚实现平滑时间路由，解决了硬掩码的边界冲突与训练式方法的数据依赖。实验表明，该方法在时间对齐与过渡自然度上显著优于基线，但视觉质量仍受限于骨干模型。其边界在于缺乏自动量化指标支撑，且未验证在复杂空间布局或极端语义差异场景下的鲁棒性。当事件语义差异极大时，软路由的平滑过渡是否会导致语义模糊，论文未给出回答。
