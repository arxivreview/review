# HuggingFace最新推荐论文 ｜Counting to Four is still a Chore for VLMs ｜视觉-语言模型计数中的模态注意力失衡诊断与干预

作者：Duy Le Dinh Anh、Patrick Amadeus Irawan、Tuan Van Vo

论文原文见 [arXiv](https://arxiv.org/abs/2604.10039)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.10039)

> 视觉-语言模型（Vision-Language Model, VLM）在复杂推理任务上表现优异，却在物体计数等基础空间感知任务上频繁失效，且现有评估仅关注最终答案，无法定位内部失效环节。本文切入点在于区分“感知缺失”与“视觉证据在语言阶段被语言先验覆盖”两种失效模式，通过组件级探针定位瓶颈，并引入模态注意力份额（Modality Attention Share, MAS）正则化作为轻量级干预。该方法在部分骨干网络上带来约1%的准确率增益，但其效果高度依赖骨干网络架构，且在分布外测试集上出现性能回退，表明强制视觉注意力重分配并非通用解。

## 研究背景

VLM将图像编码为视觉token，经模态投影层（Modality Projector）映射至语言模型（Large Language Model, LLM）的嵌入空间，再由LLM生成文本答案。这一流程隐含一个假设：视觉信息在融合后仍能主导生成过程。然而，当任务要求细粒度空间计数时，模型常输出与图像内容不符的数字，且错误在物体密集或对抗性文本提示下加剧。这种失效并非源于视觉编码器未能“看见”物体，而是视觉信号在LLM推理阶段被语言先验系统性稀释，导致生成过程依赖高频数字token而非像素证据。

领域内对VLM幻觉的归因长期存在分歧：早期观点认为源于视觉编码失败，而近期机制分析（如Nooralahzadeh et al., 2026）指出视觉信息已被编码，但在仲裁阶段输给语言先验。然而，现有研究多聚焦于问答或思维链任务，缺乏对无中间文本步骤的纯空间计数任务的组件级诊断。本文针对这一空白，通过构建受控计数基准并引入可微分注意力约束，将“语言主导”现象从定性描述转化为可定位、可干预的量化问题。

## 核心方法

### 组件级探针定位视觉信号衰减

本文首先建立参照系：VLM的视觉信息流经视觉编码器（Vision Encoder, VE）、模态投影层和LLM三个组件。传统评估仅检查最终答案，无法区分错误源于哪个组件。本文在三个组件处挂载轻量级YOLO检测头，通过平均精度（Average Precision, AP@50）量化各阶段特征保留的空间几何信息。探针架构保持参数量一致（约1.7M-2.2M），确保性能差异反映特征质量而非探针容量。实验发现，AP在投影层达到峰值，在LLM层显著下降，例如Qwen2.5-VL中AP从0.554降至0.282，证实视觉空间证据在语言推理阶段被稀释，而非感知缺失。

### 模态注意力份额正则化

探针实验揭示LLM层中约89.3%的注意力预算分配给文本token，仅约10.7%用于视觉token，形成“视觉注意力沉没”（Visual Attention Sink）。为纠正这一失衡，本文提出MAS，将模态注意力份额转化为可微分训练目标。其核心公式为：

$$ \mathcal{L}_{MAS} = \max(0, \alpha - \frac{\sum_{i \in V} A_i}{\sum_{j \in T \cup V} A_j}) $$

其中 $A_i$ 为第 $i$ 个token的注意力权重，$V$ 和 $T$ 分别为视觉和文本token集合，$\alpha$ 为预设的视觉注意力最小阈值。该公式通过惩罚视觉注意力份额低于阈值的情况，强制模型在生成时重新关注视觉上下文。与VAR等推理时注意力重分配方法不同，MAS作为训练信号直接修改模型参数，从根源上调整模态间的资源分配，而非事后修正。

## 实验评估

实验在自建COUNTINGTRICKS基准上进行，包含18k个样本，覆盖32种patchification布局，评估10个3B-11B参数的开源VLM。基线覆盖LLaVA、Qwen2.5-VL、InternVL3等主流架构，但缺失GPT-4o等商业模型及FSC147等专用计数模型的直接对比。主结果显示，Qwen2.5-VL-7B平均准确率最高（50.52%），而LLaVA-1.5-7B仅为11.82%，表明架构对分辨率和空间嵌入的保留比参数量更关键。

| 模型 | 平均准确率 (%) |
| :--- | :--- |
| LLaVA-1.5-7B | 11.82% |
| Qwen2.5-VL-7B | 50.52% |
| InternVL3-8B | 21.72% |
| Llama-3.2-11B | 24.00% |

MAS消融实验显示其效果高度依赖骨干网络。在Ovis-2.5上，MAS将Circles合成集准确率从84.9%提升至85.2%，FSC-Val从17.5%提升至17.7%，但FSC-Test从16.6%降至16.1%。在Qwen3-VL上，MAS使Circles准确率从18.2%升至30.4%，却导致FSC-Val和FSC-Test性能下降。这种不一致性表明，强制视觉注意力重分配可能抑制了某些骨干网络中必要的语言推理能力，或过强的视觉约束干扰了分布外泛化。

| 骨干网络 | 训练方式 | Circles (Syn) | FSC-Val (Real) | FSC-Test (Real) |
| :--- | :--- | :--- | :--- | :--- |
| Ovis 2.5 | SFT | 84.9 | 17.5 | 16.6 |
| Ovis 2.5 | SFT + MAS | 85.2 | 17.7 | 16.1 |
| Qwen3-VL | SFT | 18.2 | 20.3 | 14.0 |
| Qwen3-VL | SFT + MAS | 30.4 | 18.2 | 13.4 |

评估边界方面，COUNTINGTRICKS为合成数据，未包含真实场景的复杂背景与遮挡，可能高估模型在真实环境中的计数能力。Attn-IoU指标依赖ground truth mask，对物体重叠场景的评估精度有限。代码已开源，但MAS的超参数 $\alpha$ 未提供敏感性分析，可复现性受限于特定骨干网络的调优经验。

## 关联研究分析

从问题动机看，本文与仲裁失败机制分析（Nooralahzadeh et al., 2026）均证实视觉信号在决策层被语言先验覆盖，但本文聚焦于无CoT的纯计数任务，将失效定位到具体的组件（LLM层）而非笼统的“仲裁阶段”。这一差异源于任务特性：计数任务缺乏中间文本步骤，使得语言先验的影响更直接地体现在注意力分配上，而非推理链的逻辑一致性中。

从方法设计看，MAS是VAR等推理时注意力重分配方法的训练式扩展，但两者在干预时机上存在根本差异。VAR在推理时动态调整注意力权重，不修改模型参数，因此适用于任意骨干网络；MAS作为训练目标，其效果依赖于骨干网络对视觉注意力约束的响应能力。本文在Qwen3-VL上的负向效果暗示，当骨干网络已具备较强的视觉-语言融合能力时，强制视觉注意力份额可能破坏原有的平衡。这种骨干依赖性是否源于不同架构中视觉token与文本token的嵌入空间几何差异，论文未给出回答。

## 总结

本文要解决的核心矛盾是VLM在基础计数任务上的失效归因不明，现有方法无法区分感知缺失与语言先验覆盖。本文通过组件级探针定位视觉信号在LLM层的衰减，并引入MAS正则化作为干预手段，证明了视觉证据在早期表示中已存在但被后续阶段稀释。核心数字显示，Qwen2.5-VL-7B在COUNTINGTRICKS上平均准确率仅为50.52%，而MAS在Ovis-2.5上带来1%的增益。本文的边界在于MAS的效果高度依赖骨干网络，且在分布外测试集上出现性能回退，表明强制视觉注意力重分配并非通用解。当骨干网络的视觉-语言融合机制已较为成熟时，MAS的干预是否反而破坏了原有的模态平衡，论文未给出回答。
