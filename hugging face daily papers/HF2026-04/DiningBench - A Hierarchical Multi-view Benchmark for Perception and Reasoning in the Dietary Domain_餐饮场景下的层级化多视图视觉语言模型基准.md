> 现有食物评估基准依赖粗粒度分类与单视图图像，无法反映真实用餐场景中多视角融合与营养量化的复杂性。本文通过构建包含硬负样本、多视图输入及层级化任务的 DiningBench，揭示了当前视觉语言模型在细粒度视觉区分与连续营养回归上的显著缺陷。其价值在于提供了垂直领域的高保真测试床，但 LLM 辅助生成的营养标签可靠性及文化偏向性仍存疑。

## 研究背景

当视觉语言模型（VLM）被应用于自动膳食记录时，其核心挑战在于从二维像素中推断三维体积与化学成分。这一过程涉及细粒度组合性（Compositionality）理解，即模型需区分视觉特征高度相似的菜品（如熏三文鱼与新鲜三文鱼），而非依赖类别级语义捷径。然而，现有基准如 Food-101 仅关注粗粒度分类，且假设单张图像足以表征菜品，忽略了真实用户拍摄的多角度行为。这种单视图假设导致模型无法学习跨视角信息融合，且在营养估算任务中，由于缺乏对份量与容器比例的物理推理，模型往往依赖参数化知识先验而非视觉证据，产生严重的幻觉。

食物领域评估长期受限于数据噪声与任务单一性。传统数据集如 Nutrition5K 局限于标准化食堂场景，而 Recipe1M+ 存在图像质量低与标注不准的问题。通用基准虽在 MMBench 等综合测试中表现优异，但在垂直领域的细粒度感知上存在“能力断层”。DiningBench 的切入点在于重构评估协议：从静态单图分类转向动态多视图层级推理，通过引入同菜单内的硬负样本与基于商家元数据的高保真营养标签，强制模型进行视觉接地（Visual Grounding）而非语义猜测。

## 核心方法

### 层级化任务定义与硬负样本构造

DiningBench 将评估分解为细粒度分类、营养估算与视觉问答（VQA）三个层级。分类任务的核心创新在于“硬负样本”（Hard Distractors）的构造逻辑。不同于随机采样干扰项，本文利用 Gemini-3-Pro-Preview 从同一商家菜单的同一类别中选取 7 个视觉或语义相似项。设输入图像集为 $I$，候选集 $C = \{c_1, c_2, \dots, c_K\}$ 包含真值 $y$ 与 $K-1$ 个硬干扰项，模型需输出正确选项。该设计动机在于消除模型对表面语义先验的依赖，迫使模型关注切割方式、纹理等低层视觉线索，从而暴露其在细粒度区分上的瓶颈。

### 多视图营养回归与 LLM 辅助标注

营养估算任务要求模型从图像集 $I$ 预测营养向量 $\mathbf{v} \in \mathbb{R}^4$（卡路里、碳水、蛋白质、脂肪）。这是一个回归问题，其核心难点在于 2D 到 3D 的体积推理。为构建高保真真值，本文采用混合策略：直接提取商家提供的营养数据，或利用 Gemini-3-Pro-Preview 结合食材列表与份量进行估算，并交叉验证 USDA FoodData Central 数据库。最终指标采用平均绝对百分比误差（MAPE），定义为：

$$ \text{MAPE}_k = \frac{1}{N} \sum_{i=1}^{N} \left| \frac{v_{i,k} - \hat{v}_{i,k}}{v_{i,k}} \right| $$

其中 $N$ 为样本数，$v_{i,k}$ 为第 $i$ 个样本第 $k$ 种营养素的真值，$\hat{v}_{i,k}$ 为预测值。该公式量化了模型在连续数值预测上的相对误差，比分类准确率更能反映模型对物理世界量化的理解能力。

### 多视图融合机制与 CoT 失效分析

DiningBench 提供平均每道菜 5.27 张不同角度的图像，旨在评估多视图信息融合能力。实验发现，从单视图到双视图（1→2）性能提升显著，但 $N > 2$ 后边际收益递减，小模型甚至出现性能波动。此外，Chain-of-Thought（CoT）推理在营养回归任务中表现出反直觉的负面效应。对于回归任务，显式语言化过程可能将最终预测与直接视觉证据解耦，导致“过度理性化”错误特征，从而增加 MAPE。这一发现挑战了 CoT 作为通用推理增强手段的假设，表明在依赖精确视觉接地的任务中，语言推理可能引入噪声而非纠正错误。

## 实验评估

实验覆盖 29 个模型，包括 GPT-4o、Gemini-3-Pro-Preview 等专有模型及 Qwen-2.5-VL 系列开源模型。基线选择涵盖了当前 SOTA 的多模态模型，但缺失早期专用食物模型（如 Food2K 基线），这可能影响对领域特定模型进步的评估。

| 模型 | 分类 Acc (%) | 营养 Avg MAPE (%) | VQA Acc (%) |
| :--- | :--- | :--- | :--- |
| Gemini-3-Flash-Preview | 81.83 | 38.60 | 88.56 |
| GPT-4o | 65.26 | 42.43 | 80.60 |
| Qwen-2.5-VL-72B-Instruct | 65.29 | 40.46 | 80.60 |
| Claude-Sonnet-4.5 | 54.40 | 35.01 | 83.58 |

数据显示，尽管 Gemini-3-Flash-Preview 在分类上达到 81.83%，但所有模型在营养估算上的 MAPE 均高于 24%，表明连续量化仍是未解决的难题。GPT-4o 在分类上的 65.26% 准确率远低于其在通用基准上的表现，证实了垂直领域细粒度任务的挑战性。

消融实验揭示了多视图输入的“能力跳跃”与饱和现象。从 1 到 2 张图像，准确率与 MAE 显著改善，但 3 张以上后性能趋于平稳或下降。小模型（如 Qwen-2.5-VL-3B）在增加图像数量时 MAPE 波动加剧，表明其缺乏有效的多视图聚合机制，额外视觉 token 反而成为噪声。CoT 实验进一步显示，在营养估算任务中，启用 CoT 后小模型的 MAPE 普遍上升，验证了语言化推理对视觉-数值映射的干扰。

评估边界方面，DiningBench 依赖 LLM 生成部分营养标签与干扰项，尽管经过人工验证，仍可能继承 LLM 的潜在偏差。数据集文化偏向中餐（2,086 道菜），可能限制其在非西方饮食场景的泛化性。可复现性方面，论文提供了 HuggingFace 数据集链接，但 LLM 辅助生成的具体提示词与过滤阈值仅在附录中部分披露，完整复现需依赖附录 C 的详细设置。

## 关联研究分析

从问题动机看，DiningBench 与 CREPE 在硬负样本构造上逻辑一致，均旨在测试组合性理解。然而，CREPE 聚焦于通用视觉-语言对齐中的系统性偏差，而 DiningBench 将其迁移至垂直领域，并引入了多视图维度。CREPE 揭示模型规模与组合性能力无关，DiningBench 进一步证实了这一结论在营养回归任务上的适用性，但增加了“体积推理”这一物理约束，使得问题从纯语义组合扩展至物理世界建模。

从方法设计看，DiningBench 与 VisionArena 均强调真实用户交互的生态效度，但 VisionArena 侧重多轮对话偏好，而 DiningBench 侧重单轮多视图感知。关键差异在于评估指标：VisionArena 使用人类偏好标签，而 DiningBench 采用 LLM-as-a-Judge 评估 VQA。这种选择引入了评估器自身的幻觉风险，特别是在营养估算这种需要精确数值判断的任务中，LLM 裁判可能无法准确区分细微的数值误差，导致排名失真。

## 总结

DiningBench 旨在解决食物领域 VLM 评估中粗粒度分类与单视图假设的局限，通过层级化任务与多视图硬负样本，揭示了模型在细粒度视觉区分与营养量化上的能力断层。其核心贡献在于构建了高保真的垂直领域测试床，证明即使最强模型在营养估算上的 MAPE 也高达 24.45%，且 CoT 在回归任务中可能加剧错误。然而，数据集的文化偏向与 LLM 辅助标注的潜在偏差限制了其普适性。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
