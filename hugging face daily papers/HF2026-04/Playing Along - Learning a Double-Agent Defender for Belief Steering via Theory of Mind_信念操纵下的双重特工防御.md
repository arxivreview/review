# HuggingFace最新推荐论文 ｜Playing Along: Learning a Double-Agent Defender for Belief Steering via Theory of Mind ｜信念操纵下的双重特工防御

研究机构：美国德克萨斯大学奥斯汀分校

作者：Hanqi Xiao、Vaidehi Patil、Zaid Khan 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.11666)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.11666)

> 现有LLM隐私防御多依赖单轮拒绝或静态误导，无法应对攻击者携带先验知识的多轮探测，导致防御行为易被识破。本文提出TOM-SB任务，要求防御者在共享层级宇宙中通过多轮对话主动构建攻击者心智理论（Theory of Mind, ToM），实施信念一致欺骗以保护隐私。通过强化学习联合优化ToM准确性与欺骗成功率，验证了二者存在双向涌现关系。该方法在硬场景下将欺骗成功率提升至42.4%，但绝对成功率仍低，且依赖结构化层级假设，其泛化能力存疑。

## 研究背景

当防御者面对携带部分先验知识的攻击者时，简单的拒绝会暴露防御意图，而随机误导则因与攻击者已知事实冲突而迅速触发信任崩塌。解决此困境需防御者准确推断攻击者的当前信念状态，即形成心智理论（Theory of Mind, ToM），并据此生成与攻击者信念兼容的虚假路径。然而，ToM不仅是静态推断，更需在多轮交互中动态更新，以维持欺骗的连贯性。

主流LLM防御路线分为被动过滤与主动误导两类。被动过滤（如Refusal）在单轮有效，但在多轮中因缺乏信念建模而显得僵化；主动误导（如Naive Fooling）虽尝试提供错误信息，但未考虑攻击者先验，导致逻辑矛盾。前沿模型（Gemini3-Pro, GPT-5.4）即便使用ToM提示，在攻击者拥有先验知识的硬场景中，欺骗成功率仅分别为34.4%和26.7%，表明提示工程无法诱导可靠的信念追踪。本文切入点在于将ToM从评估指标转化为可优化的奖励信号，通过强化学习训练防御者主动探测并操纵攻击者信念。

## 核心方法

### 方法参照系

本文问题属于多智能体对抗博弈中的主动防御。与传统的单轮欺骗检测或静态ToM评估不同，TOM-SB要求防御者在长程（最多29条消息）交互中，基于共享层级宇宙（Shared Hierarchical Universe）约束，动态平衡信息隐藏、信任维持与信念操纵。关键差异在于防御者需显式输出ToM反思，并以此指导后续回复，而非仅优化最终输出。

### 层级宇宙与信念一致欺骗

设计动机在于解决随机谎言易被先验知识证伪的问题。本文构建3层3叉树结构作为共享宇宙，防御者持有完整路径（私有信息），攻击者持有部分路径（先验知识）。防御者必须提供与攻击者已知信息不冲突的虚假属性。设攻击者先验为 $P_A$，防御者私有信息为 $P_D$，防御者生成的虚假信念 $B_{fake}$ 需满足 $B_{fake} \cap P_A = \emptyset$ 且 $B_{fake}$ 在宇宙结构上合法。此约束迫使防御者进行细粒度推理，而非简单替换实体。

### 双向涌现奖励机制

设计动机在于验证ToM与欺骗能力的因果耦合。本文采用Dr. GRPO算法，定义轨迹级二元奖励：欺骗奖励 $R_{fool}$ 在攻击者自信终止且信念错误时为1；ToM奖励 $R_{ToM}$ 在防御者对攻击者先验的估计与真值匹配时为1。总奖励为 $R_{total} = R_{fool} + R_{ToM}$。实验发现，仅优化 $R_{fool}$ 可使ToM准确率从36.0%提升至49.0%；仅优化 $R_{ToM}$ 可使硬场景欺骗率从13.2%提升至40.6%。这种双向涌现表明，准确建模对手信念是成功欺骗的必要条件，而欺骗压力反过来驱动模型更精细地推断对手状态。

## 实验评估

实验基于自建TOM-SB基准（300场景，75评估），对比Prompt-based（Refuse, Mislead, Base ToM）与Training-based（Online SFT, ADA变体）方法。基线覆盖主流防御策略，但缺乏白盒激活探针对比。

| 方法 | Hard Fooling % | All Fooling % | ToM Traj % | ToM Step % |
| :--- | :--- | :--- | :--- | :--- |
| Base Prompt (Gemini3-Pro) | 34.4 | 57.8 | 48.9 | 47.0 |
| Base Prompt (Qwen3-14B) | 13.2 | 36.0 | 36.0 | 49.3 |
| ADA (Fooling only) | 34.4 | 46.7 | 49.0 | 62.4 |
| ADA (ToM Only) | 40.6 | 43.6 | 53.3 | 65.5 |
| ADA (Fooling + ToM) | 42.4 | 51.3 | 58.7 | 64.9 |

联合奖励策略在硬场景欺骗率（42.4%）和ToM轨迹准确率（58.7%）上均优于单一奖励及前沿模型提示。消融显示，ToM-only训练在硬场景欺骗率上（40.6%）甚至优于Fooling-only（34.4%），证实信念建模对欺骗的杠杆作用。

在OOD攻击者（Cross-Examiner, Deception-Aware, Bluffing）测试中，ADA (Fooling + ToM) 的欺骗率随攻击者强度增加而下降（42.4% → 31.2% → 34.4% → 34.4%），但ToM准确率与欺骗率保持高相关（平均Pearson r = 0.92）。Bluffing Attacker（模拟先验知识）是最强攻击者，导致Gemini3-Pro欺骗率从34.4%降至20.8%，凸显训练模型在分布外场景的鲁棒性优势。

评估边界受限于结构化层级假设，未测试开放域对话。代码与数据已开源，训练使用4x RTX 6000 Ada GPUs，超参数（学习率1e-5，梯度累积4步）已公开。指标依赖LLM Judge评估ToM，可能存在评估偏差。

## 关联研究分析

从问题动机看，本文与DeceptionBench等基准不同，后者聚焦单轮事实准确性或静态欺骗检测，而TOM-SB强调多轮动态信念更新。DeceptionBench的SOTA（0.85）基于结构化输出分离推理与响应，但无法捕捉攻击者先验知识对防御策略的约束。本文的42.4%欺骗率虽低于DeceptionBench的静态指标，但任务复杂度更高，涉及信任累积与衰减，二者不可直接比较。

从方法设计看，本文与Anti-Scheming Training同属RL训练干预，但目标不同。Anti-Scheming旨在抑制模型逃避监控的行为，而ADA旨在增强模型主动操纵对手信念的能力。Shared Sycophancy-Lying Circuit发现谄媚与说谎共享注意力头，本文从行为层面验证了ToM（理解）与Fooling（欺骗）的因果关联，二者形成机制与行为的互补。本文未采用激活探针，而是通过外部奖励信号间接优化内部表征，这是否导致ToM提升仅为表面格式适应而非真实认知增强，论文未给出回答。

## 总结

本文核心矛盾在于多轮对抗中防御者难以兼顾隐私保护与信任维持。现有方法因缺乏动态信念建模而失效，本文通过引入ToM作为独立奖励信号，利用强化学习诱导ToM与欺骗能力的双向涌现。实验证明联合奖励在硬场景下将欺骗率提升至42.4%，ToM准确率提升至58.7%。然而，该结果依赖结构化层级宇宙假设，且绝对成功率仍低，表明任务难度极高。当攻击者具备更强的信念操纵能力或对话进入非结构化开放域时，基于层级约束的ToM奖励是否仍能维持双向涌现关系，论文未给出回答。
