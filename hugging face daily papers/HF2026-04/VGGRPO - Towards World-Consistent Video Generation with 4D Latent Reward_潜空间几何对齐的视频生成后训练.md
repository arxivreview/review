> 大规模视频扩散模型在生成高保真画面时，常因缺乏显式三维先验导致相机轨迹漂移与场景结构崩坏，严重制约具身智能与物理仿真应用。现有几何一致性方案要么修改生成器架构牺牲泛化性，要么依赖像素空间奖励计算带来高昂的解码开销且局限于静态场景。本文提出VGGRPO，通过构建潜空间几何模型（LGM）直接在扩散潜变量中提取几何特征，并以此计算奖励执行组相对策略优化（GRPO），实现无需RGB解码的动态场景几何对齐。该方法在静态与动态基准上均提升了几何一致性与运动平滑度，但其对几何基础模型质量的依赖及潜空间奖励的表征上限仍存疑。

## 研究背景

视频扩散模型的去噪过程可被建模为多步马尔可夫决策过程（MDP），其中策略网络预测速度场以逐步去除噪声。Group Relative Policy Optimization (GRPO) 通过从当前策略采样一组轨迹并计算组内相对优势，实现了无需价值函数估计的在线策略优化。然而，传统GRPO框架在视频生成中评估奖励时，需将潜变量解码为RGB图像以计算美学或几何指标，这一过程不仅引入解码噪声，更因反复调用VAE解码器导致显存与计算开销激增，且像素级奖励对低层纹理波动敏感，难以捕捉深层几何结构。

几何一致性视频生成旨在解决扩散模型缺乏三维空间约束导致的几何漂移问题。主流路线分为架构级几何注入与训练时正则化：前者通过点云条件或辅助几何预测头增强模型，但增加了架构复杂度并可能削弱预训练泛化能力；后者如Epipolar-DPO与VideoGPA，利用对极几何或重投影一致性构建偏好数据，但依赖离线偏好收集且假设场景静态，无法处理动态视频中的非刚性运动。本文切入点在于利用几何基础模型（Geometry Foundation Model, GFM）的强几何先验，将其与扩散潜空间直接耦合，从而在潜空间内高效计算几何奖励，突破静态场景限制并消除RGB解码瓶颈。

## 核心方法

### 方法参照系

本文基于Flow-GRPO框架，将视频扩散的去噪过程视为MDP，通过优化策略网络以最大化期望奖励。与标准Flow-GRPO在RGB空间评估美学或物理奖励不同，本文的核心差异在于将奖励计算迁移至潜空间，并引入几何基础模型作为奖励源，以解决动态场景下的几何一致性对齐问题。

### 潜空间几何模型构建

设计动机在于消除几何奖励计算对VAE解码的依赖，避免像素空间噪声干扰并降低计算成本。通常几何基础模型（如Any4D或VGGT）以RGB图像序列为输入，预测相机位姿、深度图、点云及场景流。本文通过模型拼接（Model Stitching）技术，用轻量级3D卷积连接器 $S_\psi$ 替换几何模型的前 $\hat{\ell}$ 层，使其直接接收视频VAE编码器输出的潜变量 $\mathbf{z}$。该过程通过最小化特征对齐误差确定拼接位置 $\hat{\ell}$ 与连接器参数 $\psi$：

$$ \min_{\psi, \hat{\ell}} \sum_{m=1}^{M} \| \Phi_{\hat{\ell}:L}(S_\psi(E(\mathbf{x}^{(m)}))) - \Phi_{\hat{\ell}:L}(\mathbf{x}^{(m)}) \|_2^2 $$

其中 $\Phi_{\hat{\ell}:L}$ 表示几何模型从第 $\hat{\ell}$ 层到第 $L$ 层的子网络，$E$ 为VAE编码器。随后微调 $\psi$ 与下游层以进一步对齐几何预测。此设计使得几何预测 $\{\mathbf{O}_i\}$（包括位姿 $\mathbf{C}$、深度 $\mathbf{D}$、点云 $\mathbf{P}$ 及场景流 $\mathbf{F}$）可直接从潜变量 $\mathbf{z}$ 提取，无需RGB解码。

### 潜空间几何奖励优化

承接LGM输出的几何预测，本文设计两项互补奖励以优化相机运动与几何一致性。相机运动平滑奖励 $r_{motion}$ 基于预测的相机位姿序列计算轨迹抖动惩罚，鼓励稳定运动；几何重投影一致性奖励 $r_{geo}$ 利用点云与场景流计算跨视图重投影误差，强制三维结构连贯。VGGRPO在潜空间执行GRPO，策略 $\pi_\theta$ 以速度场参数化，目标函数为：

$$ \max_\theta \mathbb{E}_{p \sim \mathcal{P}, \mathbf{x} \sim \pi_\theta} \left[ r(\mathbf{x}^0, p) - \beta D_{KL}(\pi_\theta \| \pi_{ref}) \right] $$

其中 $r(\mathbf{x}^0, p)$ 为 $r_{motion}$ 与 $r_{geo}$ 的加权和，$\beta$ 为KL正则系数。通过组内相对优势计算，模型在保持预训练泛化性的同时，逐步对齐至具有世界一致性的几何分布。

## 实验评估

实验在Wan2.1-1B与Wan2.2-5B骨干上验证，使用DL3DV、RealEstate10K与MiraData构建静态与动态测试集。基线覆盖SFT、Epipolar-DPO与VideoGPA，但未包含架构级几何注入方法（如GeoVideo），可能低估了架构修改路线在特定静态场景下的竞争力。

| 方法 | VQ (Static) | MQ (Static) | Epi. (Static) | VQ (Dynamic) | MQ (Dynamic) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Baseline | - | - | 0.142 | - | - |
| Epipolar-DPO | - | - | - | - | - |
| VideoGPA | - | - | - | - | - |
| VGGRPO (Any4D) | **59.57** | **67.21** | **0.093** | **59.57** | **67.21** |

VGGRPO在动态场景的Motion Quality (MQ) 达到67.21，显著优于静态假设下的基线，且Sampson对极误差降至0.093，表明4D几何奖励有效抑制了动态场景中的结构漂移。

消融实验显示，仅优化 $r_{motion}$ 可稳定相机轨迹但残留几何伪影，加入 $r_{geo}$ 后几何一致性显著提升，证实两项奖励的互补性。效率测试表明，潜空间奖励计算将峰值显存从76.80 GB降至68.57 GB，耗时从54.73 s缩短至41.33 s，验证了去解码化的效率优势。

评估边界受限于VBench与VideoReward指标，缺乏针对全景或极端动态场景的专用几何基准。代码已开源，但LGM训练依赖混合数据分布，超参数（如LoRA rank 32）对泛化性的影响未充分探讨。

## 关联研究分析

从问题动机看，VGGRPO与VideoGPA均旨在通过几何奖励对齐视频生成，但VideoGPA依赖离线偏好数据与RGB重投影计算，受限于静态场景假设。VGGRPO通过LGM将几何先验内化至潜空间，实现在线策略优化，其根源在于几何基础模型的4D重建能力被直接复用，而非重新构建像素级对应关系。这种差异源于任务特性：动态场景的非刚性运动使得静态对极约束失效，而4D场景流提供了时间维度的几何连续性。

从方法设计看，VGGRPO与Flow-GRPO共享MDP框架，但Flow-GRPO通常使用美学或物理VLM奖励，缺乏几何结构感知。VGGRPO引入LGM作为可微分奖励源，其设计优势在于几何基础模型已预训练了大规模三维先验，避免了从零学习几何特征的困难。然而，LGM的拼接层是否足以保留几何模型在潜空间中的全部几何精度，尤其是对于复杂遮挡场景，论文未提供细粒度误差分析。

## 总结

本文核心矛盾在于视频扩散模型的高保真生成与几何一致性之间的冲突，现有架构修改或像素级对齐方法难以兼顾泛化性与动态场景适应性。VGGRPO通过潜空间几何模型（LGM）将几何基础模型的先验直接映射至扩散潜变量，利用相机运动平滑与几何重投影一致性奖励执行潜空间GRPO，实现了无需RGB解码的在线几何对齐。实验显示其在动态场景MQ达67.21，对极误差降至0.093，验证了潜空间几何奖励的有效性。然而，LGM依赖几何基础模型的预训练质量，且潜空间奖励对极端几何畸变的鲁棒性未充分验证。当几何基础模型在复杂动态场景中的重建精度下降时，潜空间奖励是否仍能引导生成模型保持世界一致性，论文未给出回答。
