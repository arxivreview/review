论文原文见 [arXiv](https://arxiv.org/abs/2604.21480)

> 交互式智能体评估长期受困于线性蒙特卡洛滚动的低效性，即重复生成几乎相同的对话前缀导致 Token 成本激增且难以覆盖深层失败模式。现有基准如 τ-bench 虽确立了多轮交互标准，但其评估范式仍依赖从初始状态重启，无法利用对话固有的树状结构。本文提出 DIVERT，通过快照关键中间状态并注入多样性用户响应实现分支评估，在固定预算下显著提升失败发现效率与任务覆盖。该方法在效率维度上优于线性基线，但其对最终准确率排名的影响及跨领域通用性尚存疑。

## 研究背景

当 LLM 智能体部署为客服系统时，其行为由长交互历史、随机决策及累积错误共同决定，单次运行无法反映真实可靠性。这种概率性行为要求评估必须包含多次执行，以暴露用户侧多样性（不同用户行为导致不同路径）和智能体侧一致性（同一任务间歇性成功即不可靠）。然而，当前主流评估协议采用线性蒙特卡洛滚动，即从初始状态重复采样独立轨迹。这一范式存在结构性缺陷：早期对话前缀（如登录、基础诊断）在多次运行中高度相似，重复生成这些前缀不仅浪费 Token，且因语义相似而非 Token 相同，限制了 KV-Cache 复用。更关键的是，标准用户模拟器存在“善意偏差”，倾向于生成高概率合作行为，导致罕见但关键的失败模式（如对抗性用户输入）难以被暴露。

交互式智能体评估的核心矛盾在于：如何在有限的计算预算下，最大化对智能体行为空间的探索覆盖。τ-bench 等基准通过引入工具、策略和 LLM 用户模拟器，确立了真实服务场景（航空、零售、电信）的评估标准，但其执行策略仍局限于线性重启。这种“从头再来”的方式忽略了对话轨迹的树状本质——许多对话共享长前缀，仅在少数关键节点分叉。本文的切入点正是利用这一结构特性，将评估从线性序列转化为分支树，通过复用共享前缀和定向探索关键节点，解决线性滚动在效率与覆盖上的双重瓶颈。

## 核心方法

### 方法参照系

本文问题属于交互式智能体评估的执行策略优化。标准流程为：给定任务集，对每个任务执行 $R$ 次完整线性滚动，记录最终状态以计算成功率。本文的关键差异在于，不重复生成完整轨迹，而是从已有轨迹的中间状态分支，将评估从“独立采样”转变为“条件探索”。

### 关键节点选择与状态快照

线性滚动中，早期轮次对下游行为影响微弱，重复生成这些低影响轮次是主要浪费源。DIVERT 引入 LLM 驱动的节点选择器（Junction Chooser），识别对话中行为分叉的关键点。设计动机在于：只有改变关键节点的用户输入，才能显著改变智能体的后续决策路径，从而以最小代价探索新行为空间。节点选择器接收完整轨迹，输出待修改的用户轮次索引及理由，确保分叉点具有语义显著性。

$$
j = \text{JunctionChooser}(\tau)
$$

其中 $\tau$ 为完整轨迹，$j$ 为选定的分叉点索引。该步骤独立于具体用户策略，可兼容合作或对抗性模拟器。

### 多样性引导的用户响应生成

选定节点后，需生成替代用户响应以探索不同路径。标准做法是随机采样或固定模板，但易导致响应与原意过于相似，无法触发深层失败。DIVERT 采用多样性引导生成：在保留任务意图的前提下，生成 $K$ 个候选响应，并选择与原响应语义差异最大的一个。设计动机在于：最大语义偏离最有可能暴露智能体在边缘情况下的脆弱性，同时通过意图约束防止偏离任务目标。

$$
u^* = \arg\min_{k} \text{Sim}(u_k, u_j)
$$

其中 $u_k$ 为第 $k$ 个候选响应，$u_j$ 为原节点响应，$\text{Sim}$ 为余弦相似度。该公式确保选出的响应在语义空间上远离原路径，从而引导智能体进入未探索的行为区域。

## 实验评估

实验在 τ-bench 的航空、零售、电信三个领域进行，使用 GPT-OSS-120B 和 Gemini-2.5-Flash 作为智能体，GPT-OSS-120B 作为用户模拟器。基线为标准线性滚动，对比方法未涵盖其他分支策略（如 MCTS 变体）或不同用户模拟器配置。主实验结果显示，在固定轨迹预算下，DIVERT 的失败发现效率（Err/100K）和任务覆盖（Fail Count）均优于线性基线。

| 配置 | Err/100K ↑ | Fail C. ↑ | Total Tokens ↓ |
| :--- | :--- | :--- | :--- |
| Baseline (12 rollouts) | 13.6 | 78 | — |
| DIVERT (8 rollouts + 4 branches) | 16.2 | 81 | — |

*注：数据取自 Table 3 消融实验，固定 12 轨迹预算。*

消融实验揭示了各组件的贡献：仅使用节点选择器（JC）可提升效率（15.1 vs 13.6），但覆盖能力下降（75 vs 78），因为探索局限于已观察前缀的延续。加入定向用户生成（DG）后，效率与覆盖均显著提升（15.8, 80），表明主动引导探索是关键。最后，多样性选择（DC）带来额外增益（16.2, 81），通过避免生成过于相似的响应，进一步扩展了行为覆盖。

| 组件组合 | Err/100K ↑ | Fail C. ↑ |
| :--- | :--- | :--- |
| Base + JC | 15.1 | 75 |
| Base + JC + DG | 15.8 | 80 |
| Base + JC + DG + DC | 16.2 | 81 |

评估边界方面，本文仅报告效率与覆盖指标，未报告最终任务成功率，无法直接判断 DIVERT 是否提升智能体的实际性能排名。可复现性方面，论文未提供代码，但详细描述了超参数（$K=3$，分支数 $B$ 为超参）和模型配置，且使用开源模型，复现门槛较低。

## 关联研究分析

从问题动机看，DIVERT 与 Holistic Agent Leaderboard 均关注成本-性能权衡，但前者聚焦于执行采样策略的效率优化，后者侧重于多模型、多基准的横向对比基础设施。DIVERT 的创新在于将 MCTS 的树状探索思想简化为评估专用，避免了训练阶段的复杂搜索，但这也限制了其动态调整分支深度的能力。相比之下，Holistic Agent Leaderboard 通过标准化执行环境，解决了评估碎片化问题，但未深入优化单次评估的计算效率。

从方法设计看，DIVERT 与 MASEval 同属系统级评估，但 MASEval 侧重多智能体协作中的归因分析，记录每个智能体的消息历史以定位责任方；DIVERT 则聚焦单智能体交互中的效率优化，通过分支探索捕捉深层失败。两者的差异源于任务特性：多智能体系统需要细粒度的内部状态追踪，而单智能体交互更关注行为路径的多样性。DIVERT 未探索多智能体场景，其分支机制在协作环境中是否有效，论文未给出回答。

## 总结

本文要解决的核心矛盾是线性滚动评估在固定预算下效率与覆盖的双重瓶颈。其切入点在于利用对话轨迹的树状结构，通过快照关键节点和多样性引导生成，将评估从独立采样转化为条件探索。DIVERT 在 τ-bench 上证明，相比线性基线，其失败发现效率提升 19.1%（16.2 vs 13.6），任务覆盖提升 3.8%（81 vs 78）。然而，本文的边界在于仅验证了效率与覆盖指标，未证明其对最终准确率排名的影响，且分支策略在跨领域通用性上缺乏充分验证。当任务难度动态变化时，固定分支预算是否仍为最优，论文未给出回答。
