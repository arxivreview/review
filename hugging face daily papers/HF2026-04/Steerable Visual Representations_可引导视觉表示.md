# HuggingFace最新推荐论文 ｜Steerable Visual Representations ｜可引导视觉表示

研究机构：美国卡内基梅隆大学

作者：Jona Ruthardt、Manu Gaur、Deva Ramanan 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.02327)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.02327)

> 预训练视觉Transformer（ViT）生成的通用特征往往锁定于图像中最显著的物体，无法响应文本指令去关注次要概念，而多模态大语言模型（MLLMs）虽能理解文本但其特征偏向语言空间且参数量巨大。现有方法在“特征可控性”与“视觉质量”间存在不可调和的权衡，本文通过反转条件方向，将文本直接注入冻结ViT内部实现早期融合。该方法仅增加21M参数，在保持视觉表示质量的同时实现了全局与局部特征的文本引导，但其在标准检索基准上的竞争力及早期融合对模态间隙的影响尚存疑。

## 研究背景

预训练ViT（如DINOv2）通过自监督学习获取通用视觉特征，但其表征受限于“显著性偏差”，即编码器倾向于聚焦图像中占据主导地位的物体，忽略背景或次要对象。这种静态的、查询无关（query-agnostic）的特性使得模型无法根据任务需求动态调整关注点。与此同时，MLLMs通过后期融合（Late Fusion）将视觉特征映射到语言空间，虽然具备文本理解能力，但其视觉特征保真度下降，且需要数十亿参数才能维持基本的多模态交互，导致在纯视觉下游任务中表现不佳。

视觉语言对齐领域长期聚焦于构建共享嵌入空间以解决模态间隙，主流范式如CLIP采用双编码器对比学习，其文本仅作为训练监督信号，推理时视觉编码器仍独立运行，无法被文本“引导”。这种后期融合架构导致文本无法影响视觉编码过程本身，仅作用于输出端。本文切入点在于打破这一范式，提出“可引导视觉表示”概念，主张语言应在视觉特征提取的早期阶段介入，通过轻量级机制直接调制ViT内部状态，从而在不牺牲视觉质量的前提下实现特征的动态重定向。

## 核心方法

### 方法参照系

本文问题归属于高效多模态架构设计路线，但与传统跨模态对齐（如CLIP）的关键差异在于融合时机与目标。传统方法旨在对齐两个模态的静态嵌入，而本文旨在让单一模态（视觉）的特征生成过程动态响应另一模态（文本）的指令，且要求视觉编码器保持冻结状态以保留其预训练质量。

### 门控交叉注意力机制

为在冻结ViT中注入文本条件，本文在ViT块之间插入轻量级门控交叉注意力（Gated Cross-Attention, GCA）层。设计动机是解决后期融合无法影响中间视觉特征的问题，通过让视觉Token作为Query、文本Token作为Key/Value，使视觉编码过程直接受文本引导。GCA采用门控机制，初始时门控系数为0，确保模型初始状态与原始ViT一致，避免破坏预训练权重。其计算公式为：

$$ Z_v^{(\ell+1)} = Z_v^{(\ell)} + \alpha_\ell \cdot \text{CA}(Z_v^{(\ell)}, H_t) $$

其中 $\alpha_\ell$ 为可学习的门控系数，$\text{CA}$ 为交叉注意力操作，$H_t$ 为投影后的文本嵌入。该公式表明，文本对视觉特征的影响强度由 $\alpha_\ell$ 连续控制，允许在推理时调节引导力度。

### 参考分割预训练目标

为促使ViT学习利用文本线索，本文采用参考分割（Referential Segmentation）作为预训练任务。设计动机是全局分类任务无法强制模型关注特定区域，而分割任务要求模型根据文本提示预测对应像素区域，从而将文本信息路由到具体的视觉Patch Token。损失函数采用软交叉熵（Soft Cross-Entropy）：

$$ \mathcal{L} = -\sum_{i=1}^{N} y_i \log(p_i) + (1-y_i) \log(1-p_i) $$

其中 $y_i$ 为第 $i$ 个Patch的真值前景比例，$p_i$ 为模型预测概率。该损失函数鼓励交叉注意力层将文本语义精准映射到对应的视觉Patch，形成可引导的局部特征表示。

## 实验评估

| 方法 | CORE Acc@1 (%) | GeneCIS R@1 (%) | MOSAIC PR-AUC (%) |
| :--- | :--- | :--- | :--- |
| DINOv2 | 43.7 | 9.6 | 14.3 |
| CLIP (Late Fusion) | 44.2 | - | - |
| FLAIR | 81.3 | - | - |
| SAM3 | 93.3 | - | - |
| SteerViT | 96.0 | 25.4 | 50.2 |

实验设置涵盖自建CORE基准、GeneCIS真实场景检索及MOSAIC注意力定位任务。基线覆盖单模态ViT（DINOv2）、跨模态编码器（CLIP）、MLLMs（InternVL3, Qwen3-VL）及开放词汇定位模型（SAM3, GroundingDINO）。SteerViT在CORE上以96.0%的准确率显著超越DINOv2（43.7%）和FLAIR（81.3%），证明早期融合在可控性上的优势。在GeneCIS上，SteerViT的R@1为25.4%，远高于DINOv2的9.6%，验证了其在真实复杂场景中的泛化能力。

消融实验显示，门控系数 $\alpha$ 的调节实现了可控性与质量的连续插值。当 $\alpha$ 设为0.6时，SigLIP和DINOv2骨干的SteerViT在可控性与视觉质量间达到最优平衡。值得注意的是，随机文本提示导致SteerViT性能大幅下降（-47.7%），而CLIP几乎无变化，证实了SteerViT的可控性确实源于文本驱动而非训练伪影。

评估边界方面，本文未报告在Flickr30K或MS-COCO等标准检索基准上的绝对SOTA性能，主要聚焦于“可控性”这一新维度。代码与超参数已公开，但早期融合对模态间隙几何结构的具体影响未提供定量分析。

## 关联研究分析

从方法设计看，SteerViT与FLAIR的核心差异在于融合位置。FLAIR采用后期融合，仅在特征提取后通过注意力池化整合文本，导致其可控性受限（81.3% vs 96.0%）且视觉质量下降。SteerViT通过早期融合直接调制ViT内部状态，解决了后期融合无法影响中间特征的问题。这一差异根源在于任务目标：FLAIR旨在优化特定检索任务，而SteerViT旨在构建通用的可引导表示，因此需要更深层的模态交互。

从问题动机看，SteerViT与SAM3等开放词汇定位模型形成互补。SAM3具备强可控性，但其特征专为定位优化，在通用视觉任务（如分割、分类）上表现不佳。SteerViT通过保留冻结ViT的通用特征质量，同时引入文本引导，实现了“可控性”与“通用性”的Pareto改进。然而，SteerViT未处理模态间隙问题，其早期融合是否加剧或缓解了嵌入空间的几何偏移，论文未给出明确解释，这与领域内SSP、CMA等关注几何修正的方法形成对比。

## 总结

本文核心矛盾在于视觉特征的静态显著性偏差与任务所需的动态可控性之间的冲突。现有MLLMs因参数庞大且视觉保真度低，无法高效解决此问题；本文通过反转条件方向，利用21M参数的门控交叉注意力在冻结ViT内部实现早期融合，证明了文本可在不牺牲视觉质量的前提下引导特征生成。实验表明，SteerViT在CORE基准上达到96.0%准确率，显著优于后期融合方法。其边界在于未验证在标准大规模检索基准上的竞争力，且早期融合对模态间隙几何结构的影响机制尚不明确。当支持集规模扩大或任务复杂度增加时，这种轻量级早期融合是否仍能维持对复杂组合语义的引导能力，论文未给出回答。
