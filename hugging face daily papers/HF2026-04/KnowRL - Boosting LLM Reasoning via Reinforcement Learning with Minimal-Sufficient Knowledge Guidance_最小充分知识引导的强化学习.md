# HuggingFace最新推荐论文 ｜KnowRL: Boosting LLM Reasoning via Reinforcement Learning with Minimal-Sufficient Knowledge Guidance ｜最小充分知识引导的强化学习

研究机构：天津大学、中国科学院

作者：Linhao Yu、Tianmeng Yang、Siyu Ding 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.12627)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.12627)

> 基于可验证奖励的强化学习（RLVR）在困难数学题上常因全错采样导致梯度消失，现有提示增强方法通过增加前缀长度或抽象模板来缓解稀疏性，却引入了冗余与交互冲突。本文提出将提示设计重构为最小充分引导问题，通过原子知识点（KP）分解与约束子集搜索（CSS）筛选出无冗余且交互兼容的紧凑子集。该方法在1.5B模型规模下实现了显著的性能提升，但其对强教师模型生成KP的依赖及仅局限于数学域的验证范围，限制了其泛化能力的直接外推。

## 研究背景

当大语言模型面对高难度数学推理任务时，其生成的思维链往往整体错误，导致组相对策略优化（GRPO）中的优势函数为零，训练陷入停滞。这种奖励稀疏性迫使研究者引入外部提示，但简单的前缀注入并未解决根本问题：提示本身可能包含相互冲突或冗余的信息，反而干扰了策略分布的探索。理解这一困境需厘清两个概念：一是“关键段效应”，即性能随提示比例呈现非线性跳跃而非线性增长；二是“剪枝交互悖论”，即移除单个看似无用的知识点可能有益，但联合移除多个此类知识点因依赖关系导致性能下降。

RLVR领域的共识认为，稀疏奖励是限制模型在困难问题上学习效率的主要瓶颈，主流路线通过过程奖励模型或自适应前缀长度来增加信号密度。然而，这些方法隐含地将提示设计视为“量”的扩展问题，假设更强的引导需要更长的前缀或更丰富的抽象，忽略了“质”的最小充分性。本文的切入点在于指出，现有方法普遍存在提示冗余，导致策略分布锐化与解多样性坍缩。通过识别关键段效应与剪枝交互悖论，KnowRL 将问题从“如何提供更多引导”转化为“如何筛选出触发成功推理的最小知识单元”，从而在维持探索多样性的同时打破奖励稀疏。

## 核心方法

### 方法参照系

本文问题归属于提示增强 RL 范畴，标准流程是在提示中注入固定比例或自适应长度的解题前缀以辅助模型生成正确响应。与 QuestA 等固定比例方法或 StepHint 等自适应长度方法不同，KnowRL 的核心差异在于不关注提示的绝对长度，而是关注提示内部知识单元的原子化分解与交互兼容性筛选，旨在消除冗余而非增加信息量。

### 原子知识点分解与泄漏验证

设计动机在于解决长前缀中混杂无关信息与实例特定细节导致的跨提示不一致问题。KnowRL 首先利用 DeepSeek-R1 生成正确解，并提取其中不可或缺的数学原理作为原子知识点（KP）。为防止信息泄漏，每个 KP 需通过自动化审查确保其可泛化性。这一阶段将连续的解题文本离散化为独立的知识单元，为后续的交互分析奠定基础。KP 集合 $K = \{k_1, k_2, ..., k_n\}$ 的构建确保了每个单元都承载独立的推理价值，避免了传统前缀中语义纠缠带来的噪声。

### 约束子集搜索（CSS）

设计动机在于解决剪枝交互悖论，即简单的留一法（LOO）因忽略 KP 间的依赖关系，在联合移除时导致性能大幅波动。CSS 首先定义非退化集合 $H = \{k_i | A_{-i} \ge \max(A_K, A_\emptyset)\}$ 和近最优移除集合 $N = \{k_i \in H | A_{-i} \ge A_{max}\}$，其中 $A_{-i}$ 为移除 $k_i$ 后的准确率。直接移除 $N$ 中的 KP，然后在剩余集合 $C = H \setminus N$ 上进行全局子集枚举，选择准确率最高的配置：

$$ S^* = \arg\max_{S \subseteq C \cup \{\emptyset, K\}} A(S) $$

该公式的物理含义是，在排除掉那些单独移除即能显著提升性能的“冗余”KP 后，对剩余具有交互依赖的 KP 进行穷举搜索，以找到全局最优的紧凑子集。相比 LOO 的局部贪心，CSS 通过先剪枝后全局搜索，有效规避了联合移除引发的冲突，实现了在极少 KP 数量下的高准确率。

## 实验评估

实验在 AIME24/25、MATH500 等八个数学基准上进行，基线包括 Nemotron-1.5B、QuestA 和 JustRL。对比方法覆盖了固定前缀与自适应前缀路线，但缺失了 DAPO、RiskPO 等 2025-2026 年针对探索机制的前沿方法，这可能低估了 KnowRL 在熵坍缩缓解方面的相对优势。

| 模型 | 提示设置 | AIME24 | AIME25 | MATH-500 | Avg. |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Nemotron-1.5B | w/o KP | 59.06 | 48.33 | 92.35 | 60.45 |
| QuestA | CSS | 74.26 | 64.99 | 94.05 | 71.58 |
| KnowRL-Nemotron-1.5B | w/o KP | 69.79 | 64.69 | 95.70 | 70.08 |
| KnowRL-Nemotron-1.5B | CSS | 74.58 | 65.21 | 96.20 | 74.16 |

KnowRL 在无提示推理时平均准确率达 70.08，较基线提升 9.63 点，表明 KP 引导训练内化了推理能力而非仅依赖测试时提示。引入 CSS 筛选的 KP 后，性能进一步提升至 74.16，在 AIME25 上较 QuestA 的 CSS 策略高出 0.22 点，验证了交互感知筛选的有效性。

消融实验显示，CSS 相比 CBRS 在 HMMT25 和 CMIMC25 等最难数据集上表现更稳健，平均 KP 数量仅为 2.57，较全量 KP 减少 56%。随机选择相同数量的 KP 性能显著低于 CSS，证明提示有效性取决于结构而非数量。值得注意的是，全量 KP 注入在某些子集上甚至导致性能下降，凸显了交互冲突的负面影响。

评估协议采用 mean@8 或 mean@32，未报告置信区间，数值比较需谨慎。代码与数据已开源，训练耗时约 13 天（8 节点 H100），超参数包括 clip_high 从 0.28 退火至 0.26。可复现性良好，但依赖 DeepSeek-R1 生成 KP 的外部成本未计入训练开销，实际部署时需考虑这一前置计算成本。

## 关联研究分析

从问题动机看，KnowRL 与 DeepSearch 均旨在解决奖励稀疏导致的探索瓶颈，但路径截然不同。DeepSearch 通过集成蒙特卡洛树搜索（MCTS）在训练阶段生成高质量轨迹，侧重算法层面的结构化探索；而 KnowRL 通过数据层面的最小充分引导，改变策略的输入分布以间接提升探索效率。DeepSearch 依赖搜索算法的效率与奖励模型的准确性，计算开销随搜索深度增加；KnowRL 则通过离线筛选 KP，将计算成本前置，训练阶段无需额外搜索开销。这种差异源于任务特性：DeepSearch 适用于需要动态决策的长程任务，而 KnowRL 更适合静态推理题，其 KP 筛选假设问题解法存在稳定的关键知识单元，这一假设在动态环境中的适用性存疑。

从方法设计看，KnowRL 与 Token Hidden Reward 同属细粒度信用分配路线，但机制互补。Token Hidden Reward 基于 GRPO 学习动态，通过 token 级隐藏信号调整优势函数，实现无需外部资源的细粒度归因；KnowRL 则通过外部 KP 注入改变提示结构，提供显式的知识引导。Token Hidden Reward 依赖策略梯度更新中的隐含信号，可能受噪声干扰；KnowRL 依赖强教师模型生成的 KP，引入了外部偏差风险。两者结合可能形成“显式引导+隐式归因”的混合框架，但论文未探索这种组合，也未分析 KP 注入对 token 级梯度分布的具体影响。

## 总结

KnowRL 针对 RLVR 中困难样本的奖励稀疏问题，抓住了现有提示方法“量多质杂”的痛点，通过最小充分引导范式与 CSS 算法，实现了在极少 KP 数量下的高性能训练。实验证明，无提示推理时平均准确率提升 9.63 点，引入 CSS 筛选的 KP 后进一步提升至 74.16，确立了 1.5B 规模下的新 SOTA。然而，该方法依赖 DeepSeek-R1 生成 KP，且仅在数学域验证，其 KP 分解框架在代码或科学推理等开放域任务中的有效性尚未证实。当问题解法不存在稳定的原子知识单元，或 KP 间依赖关系高度动态时，CSS 的全局搜索是否仍能保持紧凑性与鲁棒性，论文未给出回答。
