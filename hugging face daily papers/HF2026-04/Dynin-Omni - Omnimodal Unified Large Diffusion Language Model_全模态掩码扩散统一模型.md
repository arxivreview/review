# HuggingFace最新推荐论文 ｜Dynin-Omni: Omnimodal Unified Large Diffusion Language Model ｜全模态掩码扩散统一模型

研究机构：韩国首尔大学

作者：Jaeik Kim、Woojin Kim、Jihwan Hong 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2604.00007)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2604.00007)

> 统一多模态理解与生成旨在单一架构内融合视觉、语音与文本的感知与生成，但现有自回归（AR）范式强制非序列模态遵循因果解码，导致生成并行度受限且跨模态交互碎片化。本文切入点在于利用掩码扩散（Masked Diffusion）的双向注意力机制，将全模态建模转化为共享离散词表上的迭代去噪过程，从而消除外部生成器依赖。通过引入模态解耦模型合并与调度填充学习，Dynin-Omni 在 8B 规模下实现了文本、图像、语音及视频的原生统一。其价值在于验证了非 AR 范式在全模态场景的可行性，但生成质量仍略逊于专用扩散模型，且长序列推理效率未获充分验证。

## 研究背景

当图像或语音信号被强制转化为线性序列时，其内部元素间天然存在的非因果依赖关系被破坏。这种序列化瓶颈源于自回归模型严格的左到右解码顺序，导致生成过程无法并行化，且难以在全局范围内精修交错输出。为缓解此问题，主流方案采用混合架构，将 AR 骨干与扩散或流匹配生成器通过潜在接口耦合，但这引入了异构训练目标与编排瓶颈，使得跨模态交互仅能通过中间表征间接完成，未能实现单一表征空间内的深层原生集成。

统一多模态领域长期面临理解与生成在表征空间中的冲突，早期研究通过解耦编码器或混合目标缓解梯度干扰，但核心矛盾在于 AR 范式与非序列模态的本征不匹配。2024 年后，掩码扩散大语言模型（如 LLaDA）证明了迭代去噪在文本任务上可竞争 AR 基线，但现有工作局限于视觉-语言场景，未能扩展至视频理解与高保真语音合成。Dynin-Omni 的切入点在于将掩码扩散范式扩展至全模态（Omni）接口，通过单一离散 Token 空间原生建模所有模态的理解与生成，避免模块化委托带来的语义割裂。

## 核心方法

### 全模态离散 Token 化与掩码扩散骨干

Dynin-Omni 基于 LLaDA 架构，将文本、图像、语音统一映射至共享离散词表。图像采用 MAGVIT-v2 风格量化器，语音使用预训练 Tokenizer，所有模态共享同一嵌入矩阵与 Transformer 骨干。该设计动机在于消除 AR 模型的因果约束，利用双向注意力实现任意顺序生成与全局一致性。训练目标为统一的掩码预测损失：

$$ \mathcal{L} = -\sum_{t \in \mathcal{M}} \log P(x_t | x_{\setminus t}, \theta) $$

其中 $\mathcal{M}$ 为随机掩码位置集合，$x_{\setminus t}$ 为剩余上下文。该公式表明模型在每一步迭代中，基于未掩码的全局上下文并行预测多个被掩码 Token，而非顺序生成，从而支持非序列模态的全局精修。

### 模态解耦多阶段训练与调度填充

直接联合训练异构数据易导致灾难性遗忘与训练不稳定。Dynin-Omni 提出三阶段训练范式：首先对齐新模态至骨干，其次执行模态解耦模型合并（Modality-Disentangled Model Merging），最后扩展高级推理能力。模型合并采用线性插值策略，保留原骨干 84% 的既有模态性能，同时扩展词表容量。此外，引入调度填充学习（Scheduled Padding Learning），通过动态调整填充 Token 的掩码比例，支持变长生成而不损害全局语义连贯性。该设计解决了全模态扩展中旧能力遗忘与新能力习得之间的优化冲突，确保单一骨干在增加语音/视频模态后，文本与图像理解能力不显著退化。

## 实验评估

实验覆盖 19 个基准，包括文本推理（GSM8K, MMLU）、多模态理解（MME, VideoMME）、图像生成（GenEval, DPG-Bench）及语音任务（LibriSpeech ASR/TTS）。基线涵盖感知中心模型（Qwen2.5-Omni）、组合统一模型（HyperCLOVAX-8B-Omni）及原生统一模型（Show-o2, BAGEL, NExT-OMNI）。

| 基准 | Dynin-Omni | Show-o2 | BAGEL | Qwen2.5-Omni |
| :--- | :--- | :--- | :--- | :--- |
| GSM8K | 87.6 | 75.3 | - | 88.7 |
| GenEval | 0.87 | - | 0.86 | - |
| VideoMME | 61.4 | - | - | 64.3 |
| LibriSpeech ASR (WER) | 2.1 | - | - | - |

Dynin-Omni 在 GSM8K 上达到 87.6，接近专用 LLM Qwen3-8B（89.8），显著优于统一模型 Show-o2（75.3）。在 GenEval 上得分为 0.87，与 BAGEL（0.86）持平，但低于专用生成模型 FLUX.1 [Dev]（0.82，据领域综述）及 UniDFlow（0.95，据领域综述）。VideoMME 得分 61.4，略低于 Qwen2.5-Omni 的 64.3，表明视频理解能力仍有提升空间。

消融实验显示，线性模型合并比 DARE 或 TIES 策略具有更低的初始训练损失与更稳定的收敛性。调度填充学习在 16 步扩散下即可实现接近 128 步的生成质量，验证了并行解码的效率优势。然而，论文未报告长序列文本推理的延迟对比，且 GenEval 分数未超过专用扩散模型，暗示离散 Token 化在高频细节重建上仍存在信息损失瓶颈。

评估边界方面，论文未提供置信区间，且部分基线结果标记为“复现”（†），可能存在版本差异。代码与模型已开源，但全模态闭环评估基准缺失，难以量化“生成辅助理解”的反向协同效应。

## 关联研究分析

从问题动机看，Dynin-Omni 与 BAGEL 均旨在解决统一模型中理解与生成的冲突，但 BAGEL 采用 AR+Flow-Matching 混合架构，通过共享与私有专家分离路径，而 Dynin-Omni 摒弃 AR 骨干，采用纯掩码扩散。这一差异源于对“序列化瓶颈”的不同判断：BAGEL 认为 AR 推理能力难以替代，故保留 AR 骨干；Dynin-Omni 则认为非序列模态（图像/语音）的生成质量受 AR 因果约束限制更甚，故彻底转向非因果范式。然而，Dynin-Omni 在 GSM8K 上虽接近专用 LLM，但在复杂推理任务上是否真正实现了“视觉思维”（即利用生成过程辅助理解），论文未提供因果干预实验证明，仅展示了性能持平。

从方法设计看，Dynin-Omni 与 NExT-OMNI 同属全模态统一模型，但 NExT-OMNI 使用 Flow-Matching 生成结合模态特定重构损失，引入异构目标；Dynin-Omni 坚持单一掩码扩散目标。这种统一性简化了训练流程，但可能导致在特定模态（如语音合成）上的保真度受限。NExT-OMNI 通过重构损失显式优化语音波形，而 Dynin-Omni 依赖离散 Token 的确定性去噪，其 WER 2.1 虽具竞争力，但在高保真 TTS 场景下是否优于连续值扩散模型，论文未进行对比。

## 总结

Dynin-Omni 试图解决 AR 范式与非序列模态的本征不匹配，通过掩码扩散实现全模态原生统一。其核心贡献在于验证了 8B 规模下非 AR 范式在文本、图像、语音及视频任务上的可行性，GSM8K 得分 87.6 与 GenEval 0.87 表明其在统一模型中处于领先地位。然而，实验暴露出两个边界：一是生成质量仍低于专用扩散模型，暗示离散 Token 化在高频细节上的信息损失未完全消解；二是视频理解得分（61.4）低于感知中心模型 Qwen2.5-Omni（64.3），表明全模态统一可能以牺牲特定模态的深度感知为代价。当支持集规模扩大或模态数量进一步增加时，单一掩码扩散目标是否仍能维持跨模态表征的深层协同，而非仅停留在表面统一，论文未给出回答。
