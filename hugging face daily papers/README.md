## 命名与结构

- 一篇论文 = 一个 Markdown 文件，标题即文件名，非法字符与长度处理同 [会议论文](../conference/README.md)；最长文件名 158 字符。
- 正文结构：一级标题（`HuggingFace最新推荐论文 ｜英文标题 ｜中文标题`）→ 作者 → [arXiv] 与 [ArxivReview] 外链 → 摘要导语 → `## 研究背景` 起的分节分析。
- 月目录内不另放清单文件，浏览请直接看目录页；跨月检索见下。
