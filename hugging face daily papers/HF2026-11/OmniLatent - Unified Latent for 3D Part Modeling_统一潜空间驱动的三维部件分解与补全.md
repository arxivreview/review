> 导读：三维资产生成正从单体几何复原转向具备语义结构的部件级合成，以支持下游编辑与物理仿真。现有后处理分割范式将部件推理与生成表示解耦，导致分割边界与几何表面错位，且难以控制部件粒度。OmniLatent 提出将几何、变形、外观与部件 ID 编码至统一潜空间，利用数据丰富的几何与外观先验指导数据稀缺的部件学习。该框架通过多属性变分自编码器与多模态扩散 Transformer 实现单图到部件感知资产的端到端生成，并支持点提示交互与无遮挡部件补全。其核心价值在于验证了统一潜空间在跨模态先验迁移上的有效性，但联合生成架构在复杂工业场景下的推理成本与单一模态极致保真度之间的权衡仍需进一步量化。

## 研究背景

当生成模型试图合成可交互的三维资产时，单体网格的视觉逼真度已不再是唯一瓶颈，语义部件的显式分离成为实现编辑、材质分配及动画绑定的前提。传统流程通常先生成或重建完整网格，再运行独立的部件分割模型。这种后处理范式将部件推理与产生资产的生成表示割裂，使得分割质量高度依赖输入网格质量，在薄结构、锐利边界或纹理定义的语义过渡处极易退化。此外，后处理分割器难以控制部件粒度，常将视觉连贯的组件拆分或合并功能不同的部件，导致边界与生成表面不匹配。

随着大规模三维数据集的涌现，原生三维潜空间扩散模型成为主流，但高质量三维部件标注数据远比整体几何与纹理数据稀缺。直接基于部件标签学习分割会浪费大型资产集合中蕴含的强几何与视觉先验。同时，实际场景中可用的部件线索往往不完整，单视图掩码或稀疏用户交互仅覆盖可见表面，而下游任务需要完整的对象级部件。这确立了本文的核心问题：如何构建一个统一潜空间，使其同时提供几何、视觉与语义上下文，从而在数据异质性条件下实现鲁棒的三维部件分解与无遮挡补全。

## 核心方法

### 统一多属性潜空间建模

本文方法属于“部件感知生成”类别，但与标准“先生成单体、后分割”或“独立部件生成”流程不同，OmniLatent 将部件分解视为统一潜空间建模问题。其参照系基于 VoxSet 架构，利用体素查询作为有序空间支架，将几何、变形、外观与部件 ID 压缩至同一 Token 序列。该设计的关键差异在于，部件 ID 并非独立预测，而是与几何和外观在去噪过程中同步生成，确保部件边界严格对齐于生成的表面与纹理。

### 级联解码与二进制部件编码

在变分自编码器（Variational Autoencoder, VAE）阶段，共享编码器将多属性输入 $X = [P, C, Q]$ 压缩为潜变量 $z$，其中 $P$ 为几何场，$C$ 为外观场，$Q$ 为部件场。解码器采用级联表面查询策略：首先重建符号距离场（Signed Distance Field, SDF）并提取表面，随后利用提取的表面顶点从同一潜变量中查询变形、外观与部件 ID。这种共享查询路径确保了部件场在定义几何与外观的同一表面上解码，减少了部件边界与对象结构的错位。

部件场 $Q$ 采用 6-bit 二进制编码，支持最多 64 个部件。相比 RGB 编码，二进制 ID 在去噪过程中更稳定，避免了微小颜色偏差导致单一语义部件分裂为多个不一致 ID 的问题。VAE 训练采用多任务目标：

$$
L_{\text{vae}} = \lambda_{kl}L_{KL} + \lambda_{sdf}L_{sdf} + \lambda_{def}L_{def} + \lambda_{app}L_{app} + \lambda_{part}L_{part}
$$

该公式通过加权平衡 KL 散度、SDF 重建、变形回归、外观重建及部件 ID 监督，其中较小的变形权重 $\lambda_{def}=0.1$ 防止结构偏移主导多任务目标。渐进式监督策略先建立稳定的几何潜空间，再引入外观与部件头，使部件解码器在已对齐的几何与视觉表示之上学习。

### 条件感知旋转位置编码与动态 Token 分配

在生成阶段，多模态扩散 Transformer（Multi-Modal Diffusion Transformer, MM-DiT）通过整流流（Rectified Flow）生成潜变量。为处理图像、分割掩码等多模态条件，引入条件感知 3D 旋转位置编码（Condition-Aware 3D Rotary Position Embedding, CA-RoPE）。对于图像类条件，RoPE 的第一维索引条件类型，其余两维编码空间高度与宽度。这确保了 RGB 图像与可选的 2D 分割掩码在条件 Token 序列中保持空间对齐且类型可区分。

针对无遮挡部件补全任务，不同部件占据的表面积差异巨大，固定 Token 数量会导致小部件浪费容量或大部件表示不足。OmniLatent 采用动态 Token 分配机制，根据部件可见体素数量分配 Token，并将每个部件的 Token 数量限制在平均预算的 $[0.5, 1.5]$ 倍范围内。每个部件的 Token 分为两组：一组通过 RoPE 锚定于观测表面区域，保留可见掩码的空间身份；另一组为无 RoPE 补全 Token，不绑定固定位置，提供灵活的补全容量以推断部件的完整范围。

## 实验评估

实验在 PartObjaverse-Tiny-wt 数据集上评估表面部件分割，在 ObjaversePart-Tiny 上评估无遮挡部件补全。基线覆盖后处理分割方法（Find3D, SAMPart3D, PartField, P3-SAM）及联合生成方法（X-Part, OmniPart）。OmniLatent 在掩码引导设置下取得 74.18 mIoU，显著高于最强基线 P3-SAM 的 58.10 mIoU。在无遮挡补全任务中，OmniLatent 的整体几何质量 CD 为 0.03，优于 X-Part 的 0.08。

| 方法 | Avg. mIoU ↑ | Human-Shape | Animals | Daily-Used | Buildings |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Find3D | 20.76 | 25.08 | 24.86 | 21.71 | 14.93 |
| SAMPart3D | 50.02 | 48.49 | 58.66 | 49.00 | 39.52 |
| PartField | 52.61 | 54.50 | 60.36 | 56.38 | 38.43 |
| P3-SAM | 58.10 | 64.10 | 62.04 | 60.74 | 43.66 |
| OmniLatent | 74.18 | 79.36 | 82.68 | 76.98 | 58.94 |

消融实验验证了统一潜空间建模与 CA-RoPE 的关键作用。移除 CA-RoPE 导致平均 mIoU 从 74.18 降至 69.20，表明条件感知位置索引对空间线索传递至关重要。与仅学习部件 ID 的基线相比，统一潜空间建模将 mIoU 从 67.69 提升至 74.18，证实了数据丰富的几何与外观模态为数据稀缺的部件学习提供了有效先验。在无遮挡补全中，移除表面 RoPE 使 CD 从 0.08 升至 0.15，移除全注意力机制使 CD 升至 0.13，说明跨部件通信与可见证据锚定对全局一致性不可或缺。

评估边界方面，OmniLatent 在生成表面上的分割性能（74.18 mIoU）高于其在真实水密表面上的性能（62.42 mIoU，无掩码），这暗示其高 mIoU 部分得益于生成网格的平滑性降低了分割难度。此外，论文未报告置信区间，且未提供代码开源链接，复现性受限。计算效率上，OmniLatent 单图生成耗时约 30 秒，相比分离式管线（几何 30s + 纹理 30s + 分割 20s）的 80 秒具有显著优势，但未对比联合生成与后处理在复杂工业场景下的推理成本差异。

## 关联研究分析

从问题动机看，OmniLatent 与后处理分割方法（如 SAMPart3D）的根本差异在于部件推理与生成表示的耦合程度。SAMPart3D 等后处理方法在现有表面上分配标签，其性能受限于输入网格质量，且在纹理定义的语义过渡处易失效。OmniLatent 通过统一潜空间将部件 ID 与几何、外观同步去噪，使分割边界能直接响应几何与视觉证据。然而，这种耦合是否牺牲了单一模态的极致保真度，论文未给出明确回答。尽管 OmniLatent 在几何生成指标上与 TRELLIS 等单体生成模型相当，但其联合建模架构在需要极高几何精度的工业制造场景中是否具备同等竞争力，仍存疑。

从方法设计看，OmniLatent 与 X-Part 同属部件感知生成，但技术路线不同。X-Part 侧重自回归或独立部件生成，而 OmniLatent 依赖统一潜空间的联合去噪。OmniLatent 引入的动态 Token 分配与无 RoPE 补全 Token 机制，专门解决了部件大小不均与无遮挡补全中的证据保留问题。相比之下，X-Part 未显式处理部件表面积差异导致的 Token 分配失衡。但 OmniLatent 的 6-bit 二进制 ID 限制最多 64 个部件，对于超精细部件分解任务可能构成瓶颈，而 X-Part 的表示方式是否支持更细粒度部件，论文未进行对比。

## 总结

OmniLatent 针对三维资产生成中部件结构缺失与数据异质性矛盾，提出将几何、外观与部件 ID 编码至统一潜空间，利用多模态先验指导部件学习。通过级联解码与动态 Token 分配，该框架实现了单图到部件感知资产的端到端生成及无遮挡补全。实验表明，其在 PartObjaverse-Tiny 上取得 74.18 mIoU，在无遮挡补全 CD 达 0.03，显著优于后处理及现有联合生成基线。然而，其统一潜空间架构在复杂工业场景下的推理成本与单一模态极致保真度之间的权衡尚未量化，且 6-bit ID 限制了部件数量上限。当面对超精细部件分解或需要物理属性绑定的仿真场景时，统一潜空间的容量瓶颈与物理属性缺失是否会成为实际部署的障碍，论文未给出回答。
