# HuggingFace最新推荐论文 ｜LowRAM: Low-Rank Keys and Amortised Values for Composable KV Cache Compression at Test-Time ｜低秩键与摊销值：可组合的测试时KV缓存压缩

作者：Teresa Delgado、Hugo Hazard、Martin Benfeghoul 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2611.07025)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2611.07025)

> 大语言模型自回归解码中，键值缓存（KV Cache）随序列长度线性增长，成为显存与带宽瓶颈。现有后训练压缩方法多将键与值视为同构对象，通过驱逐、量化或低秩分解统一处理，忽略了二者在结构上的本质差异。本文发现同一注意力头内，值向量高度可预测于其对应的键向量，据此提出非对称压缩框架：键采用跨层低秩分解，值采用测试时拟合的轻量预测器加稀疏残差存储。该框架在极端压缩下保持近无损性能，并与驱逐、量化正交组合，为长上下文推理提供了新的压缩维度。其测试时适应开销与解码延迟的权衡仍需更严格的端到端验证。

## 研究背景

自回归解码依赖KV缓存复用历史计算，将复杂度从序列长度的平方降至线性，但缓存占用随上下文与批大小线性膨胀，在长序列下超过模型参数本身。为缓解此瓶颈，主流后训练方法沿三条正交路线展开：驱逐策略基于注意力稀疏性丢弃低价值Token；量化策略利用数值分布特性降低存储精度；低秩分解则利用KV矩阵的谱衰减特性进行投影压缩。这些方法虽各自有效，但均隐含一个共同假设：键与值在压缩机制上是对称或同构的。

然而，键与值虽源于同一隐藏状态，功能却截然不同。键参与注意力分数计算，其能量集中于少数特征方向，呈现显著的低秩特性；值则承载信息内容，其分布特性与键存在结构性差异。现有方法要么对二者施加相同的低秩约束，要么采用非对称量化但缺乏对二者内在预测关系的利用。这一盲区导致在极端压缩下，统一处理策略难以同时保持键的注意力精度与值的信息保真度。本文正是切入这一被忽略的“键值内部相关性”，提出非对称的结构感知压缩范式。

## 核心方法

### 非对称压缩参照系

LowRAM将KV缓存压缩解耦为键压缩与值压缩两个独立子问题，分别匹配其结构特性。键压缩继承xKV的跨层低秩分解，利用相邻层键缓存主奇异向量的对齐性共享低秩基；值压缩则引入全新的摊销预测机制，利用键对值的可预测性替代直接存储。该参照系的关键差异在于：传统方法在特征维度或Token维度压缩，LowRAM在“键-值映射”维度压缩，且该映射是上下文自适应的。

### 值缓存摊销预测

值压缩的核心是用轻量预测器替代大部分值存储。对于单个注意力头，设键矩阵 $K \in \mathbb{R}^{T \times d_k}$，值矩阵 $V \in \mathbb{R}^{T \times d_v}$。本文学习一个逐头映射 $f_\theta: \mathbb{R}^{d_k} \to \mathbb{R}^{d_v}$，采用两层MLP加线性残差分支的结构：

$$
f_\theta(k) = \sigma(kW_{\ell,h}^{(1)} + b_{\ell,h}^{(1)})W_{\ell,h}^{(2)} + b_{\ell,h}^{(2)} + kW_{\text{lin}}
$$

其中 $W_{\text{lin}}$ 由Slim Attention先验 $W_K^+ W_V$ 初始化，提供键到值的最佳线性近似。预填充阶段，通过最小化重构损失 $\mathcal{L}(\theta) = \frac{1}{T}\|f_\theta(K) - V\|_F^2$ 拟合参数。解码时，值通过 $\hat{V} = f_\theta(K)$ 重建。由于少数Token重构误差极大，仅对误差排名前 $p$ 分位的Token存储精确残差 $\Delta v_i = v_i - f_\theta(k_i)$，最终值缓存为：

$$
\tilde{V} = f_\theta(K) + G \odot \Delta V
$$

其中 $G$ 为残差选择门控。该设计解决了线性近似无法捕捉非线性映射、以及全量存储值缓存内存过高的双重失效，在4×压缩下实现近无损值压缩。

### 测试时适应与元学习加速

逐上下文拟合MLP在单次查询场景下预填充开销过大。本文引入First-Order MAML元学习初始化，离线阶段学习通用键值映射先验 $\phi$，在线阶段仅需少量梯度更新即可适配新上下文。同时，为降低解码时全量重建值的计算开销，采用选择性重建：将前缀分块，仅重建当前查询相关的Top-$k$块，其余块复用持久化缓冲区。该机制将解码峰值吞吐提升最高5×，解决了摊销预测引入的额外计算抵消内存收益的问题。

## 实验评估

实验在RULER与LongBench（>10K Token子集）上进行，覆盖Mistral-7B、Llama-3.1-8B等模型。基线涵盖驱逐、量化及低秩方法，但未对比ThinKV等最新动态驱逐策略。主实验表明，LowRAM在中等压缩下保持近基线性能，与量化组合后在长上下文达到26.9×压缩率且保留94.5%性能。

| 方法 | 压缩率 (CR) | LongBench (>10K) 恢复率 (%) |
| :--- | :--- | :--- |
| Eviction | 10.0× | 91.6 |
| Quantisation | 7.5× | 92.3 |
| LowRAM | 9.0× | 90.7 |
| LowRAM-EQ | 26.9× | 94.5 |

消融实验揭示了组件贡献的显著差异。移除残差存储导致恢复率从99.0%骤降至64.9%，证实了少数高误差Token对重构的决定性作用；将逐头MLP替换为逐层共享模型损失19.5个百分点，表明不同注意力头学习到了不同的键值几何结构。线性预测器恢复率仅57.5%，远低于MLP，验证了非线性修正的必要性。

| 消融配置 | LongBench 恢复率 (%) | 变化量 |
| :--- | :--- | :--- |
| 完整摊销 | 99.0 | - |
| 无残差存储 | 64.9 | -34.1 |
| 逐层MLP | 79.5 | -19.5 |
| 线性预测器 | 57.5 | -41.5 |

评估边界方面，论文未报告端到端首Token延迟（TTFT）与解码延迟的具体数值，仅提及选择性重建提升吞吐。元学习初始化的离线训练成本（5分钟/模型）未计入推理开销。代码未开源，复现依赖xKV与Slim Attention的独立实现。

## 关联研究分析

从问题动机看，LowRAM与AQUA-KV均利用键值预测关系，但AQUA-KV采用线性适配器且跨层预测，本文采用逐头MLP且层内预测。根源在于本文发现层内键值非线性相关性更强，且跨层预测在GQA架构下受限于头维度不匹配。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

从方法设计看，LowRAM与KIVI同属非对称压缩，但KIVI的非对称性体现在量化粒度（键按通道、值按Token），LowRAM的非对称性体现在压缩机制（键低秩、值摊销）。这一差异源于对“非对称”理解的深化：从数值分布非对称走向结构功能非对称。当键的低秩性在特定架构中不成立时，该非对称机制的鲁棒性如何，论文未验证。

## 总结

本文针对KV缓存压缩中键值同构处理的局限，抓住层内键值非线性可预测性这一被忽略的结构特性，提出键低秩、值摊销的非对称压缩框架。在长上下文极端压缩下，LowRAM-EQ达到26.9×压缩率并保留94.5%基线性能，显著优于传统统一压缩方法。其边界在于测试时适应的预填充开销与解码计算延迟的权衡尚未量化，且键的低秩假设在GQA/MHA架构间的普适性未经验证。当上下文长度低于网络参数摊销阈值时，该框架的固定开销是否会抵消压缩收益，论文未给出回答。
