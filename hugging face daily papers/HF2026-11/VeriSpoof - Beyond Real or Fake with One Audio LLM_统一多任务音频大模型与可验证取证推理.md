> 音频深度伪造检测（Audio Deepfake Detection, ADD）正从单一的真伪判别向细粒度溯源与可解释取证演进。现有方法多依赖自监督学习（Self-Supervised Learning, SSL）骨干提取声学特征，但黑盒决策缺乏可验证证据，且多任务需独立模型导致部署成本高昂。VeriSpoof 将检测、归因、定位等任务统一为答案似然评分，并通过接地推理（Grounded Rationale）确保决策严格跟随可验证的中间证据。该模型在开放集泛化与源验证上展现出显著优势，但其封闭集检测精度略逊于专用架构，且接地推理的计算开销与实时性平衡仍需进一步验证。

## 研究背景

当检测器面对新生成模型时，其训练域与测试域的数据分布出现系统性差异——这一现象称为分布偏移。分布偏移导致传统分类器决策边界失效，而实际场景中往往能获取少量目标域样本，这恰好构成了小样本学习的条件：仅凭每个类别极少量标注样本泛化到新任务。解决此类问题的经典框架是原型网络，它计算各类别支持样本的特征均值作为“原型”，再通过距离度量完成分类。

音频深伪检测的演进经历了从手工特征到 SSL 骨干的转变。早期方法依赖恒定 Q 系数（CQCC）等手工特征，泛化能力差；随后 Wav2Vec 2.0 等 SSL 模型通过大规模预训练提升了跨域鲁棒性。然而，当任务从二元检测扩展至源归因（Source Attribution）和局部定位时，单一分类头无法提供取证所需的细粒度证据。现有音频大语言模型（Audio Language Model, ALM）虽能生成解释，但多为自由文本，缺乏与信号特征的严格对应，导致“幻觉”频发。VeriSpoof 的切入点在于：将取证问题转化为可验证的问答任务，通过强制模型输出与信号测量值对齐的中间陈述，解决黑盒模型解释不可信的问题。

## 核心方法

### 方法参照系：统一问答范式

传统 ADD 方法通常采用“SSL 骨干 + 分类头”的架构，每个任务（如检测、归因）需独立训练模型。VeriSpoof 将这一流程重构为统一问答范式：所有取证问题（真伪、归因、条件分析、源验证）均被转化为带有候选答案的句子，模型通过计算答案的似然概率进行评分。该范式的关键差异在于，它摒弃了独立分类头，利用大语言模型（Large Language Model, LLM）的生成能力统一处理多任务，并通过似然评分实现阈值化决策。

### 接地推理与可验证证据链

传统 ALM 的解释多为自由文本，无法验证其是否真实反映信号特征。VeriSpoof 引入接地推理机制，要求模型输出固定字段的陈述，每个陈述均有独立检查器（Checker）验证。检查器不依赖模型，而是直接对输入音频进行测量或查询元数据。例如，带宽、信噪比（SNR）等观测值通过波形测量验证，合成片段定位通过标签映射验证。

该机制的核心在于确保决策严格跟随证据。模型在生成决策前，必须先输出观测值、通道状态、定位结果和源配置文件。若定位结果与标签不符，决策将被标记为错误。这种设计解决了此前方法中解释与决策脱节的问题，确保“解释即证据”。

### 答案似然评分与多任务统一

为实现无分类头的多任务统一，VeriSpoof 采用答案似然评分机制。对于二元问题，评分函数定义为：

$$ s_q(u) = \log p_\theta(a^+ | u, q) - \log p_\theta(a^- | u, q) $$

其中 $u$ 为输入音频，$q$ 为问题，$a^+$ 和 $a^-$ 为正负答案句子。该公式的物理含义是：模型对正负答案的生成概率之差即为检测分数。对于多分类问题，则取最可能答案的准确率。这一设计使得检测、归因和源验证共享同一套权重和评分逻辑，无需为每个任务训练独立头，显著降低了模型复杂度。

## 实验评估

实验在 Speech-DF-Arena 的 14 个测试集及 VeriSpoof-Bench 上进行，对比了 SSL 骨干（XLS-R）、端到端 CNN（AASIST）及开源 ALM。VeriSpoof-Plus 在 Speech-DF-Arena 上达到 2.14% 的池化错误率（EER），位列开源系统第一；VeriSpoof-Base 在仅使用官方训练集的情况下达到 4.43% EER，显著优于其他开源系统。

| 方法 | 训练数据 | Speech-DF-Arena 池化 EER (%) | In-the-Wild EER (%) | MLAAD 源验证 EER (%) |
| :--- | :--- | :--- | :--- | :--- |
| VeriSpoof-Plus | 扩展混合数据 | 2.14 | 1.83 | 6.17 |
| VeriSpoof-Base | 官方训练集 | 4.43 | 1.25 | 13.80 |
| DF-Arena 500M | 官方训练集 | 9.96 | - | - |
| XLSR-SLS | 官方训练集 | 15.97 | - | - |

消融实验显示，接地推理显著提升了局部篡改检测能力。在 PartialEdit 数据集上，一步回答的准确率为 78.4%，而经过推理后的决策准确率达到 99.6%。此外，反事实训练确保了决策对证据的依赖性：当定位结果被替换为相反值时，99.5% 的决策随之翻转。

评估边界方面，VeriSpoof 在封闭集（如 ASVspoof 2019 LA）上的性能（0.18% EER）略逊于专用架构 WaveSP-Net（0.13% EER），表明统一范式在封闭集精度上存在轻微代价。此外，接地推理增加了推理延迟，论文未报告实时部署的具体计算开销。

## 关联研究分析

从问题动机看，VeriSpoof 与 SONAR 均致力于提升开放集泛化能力，但路径截然不同。SONAR 依赖频谱统计残差，通过 Jensen-Shannon 散度对齐低频和高频嵌入，本质上仍是特征工程；VeriSpoof 则依赖语义推理，通过 LLM 理解音频内容。两者在 In-the-Wild 上的性能差异（VeriSpoof 1.83% vs SONAR 6.48%）揭示了语义特征在复杂噪声环境下的鲁棒性优势，但 SONAR 在封闭集上的高精度表明统计特征在已知分布下仍具竞争力。

从方法设计看，VeriSpoof 与 WaveSP-Net 均追求高效微调，但架构选择不同。WaveSP-Net 采用可学习小波域稀疏提示微调，保留 CNN 架构的局部特征提取能力；VeriSpoof 采用 LoRA 微调 LLM，依赖全局注意力机制。WaveSP-Net 在 ASVspoof 2019 LA 上达到 0.13% EER，优于 VeriSpoof 的 0.18%，表明在封闭集上，专用架构的局部特征提取效率仍高于通用 LLM。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

VeriSpoof 解决了音频深伪检测中多任务部署成本高与解释不可信的核心矛盾。通过将取证问题统一为答案似然评分，并引入接地推理机制，该模型在开放集泛化（In-the-Wild 1.83% EER）和源验证（MLAAD 6.17% EER）上取得了显著突破。然而，其在封闭集上的精度略逊于专用架构，且接地推理的计算开销与实时性平衡尚未明确。当支持集增大到 5-shot 时，接地推理的边际收益是否递减，论文未给出回答。
