> 语音代理在嘈杂环境中需精准提取目标说话人语音以保障下游识别准确率，但传统目标说话人提取（Target Speaker Extraction, TSE）依赖外部注册语音，且评估多基于合成数据的信号级指标，难以满足实时部署与真实场景需求。现有方法在缺乏注册线索时性能骤降，且信号保真度与下游识别性能存在脱节。VoxLock 通过从通话自身截取语音片段作为条件线索，对因果 Band-Split RNN (BSRNN) 进行多阶段微调，并引入直通-隔离切换机制。该方案在真实录音上显著降低了背景语音泄漏，但在非受控会议场景的通用性及多语言支持上存在局限。

## 研究背景

当语音代理部署于开放环境时，麦克风会捕获周围所有声源，导致自动语音识别（Automatic Speech Recognition, ASR）将背景人声误认为目标指令。为解决此问题，TSE 技术利用辅助线索从混合音频中分离特定说话人。传统 TSE 依赖外部注册语音提取说话人嵌入，但在语音代理场景中，用户通常不提供注册音频，仅存在实时通话流。这一约束使得基于外部注册线索的 TSE 方法无法直接应用，迫使研究转向从通话自身提取线索或无监督分离。

主流 TSE 方法如 VoiceFilter 和 SpeakerBeam 依赖预录制的注册语音，而盲源分离（Blind Source Separation, BSS）方法如 TIGER 虽无需注册线索，但无法区分目标说话人与背景干扰。此外，现有研究多在 Libri2Mix 等合成数据集上评估信号级指标（如 SI-SDR），忽略了真实场景中混响、非平稳噪声对下游 ASR 性能的影响。REAL-TSE 挑战虽引入了真实对话数据，但仍依赖注册语音。VoxLock 针对无注册语音的语音代理场景，提出从通话前几秒自动截取语音作为条件线索，并直接以 ASR 词错误率（Word Error Rate, WER）为优化目标，填补了从学术基准到实际部署的评估空白。

## 核心方法

### 方法参照系：因果 BSRNN 与自采样线索

VoxLock 基于 REAL-TSE 基线中的因果 tfmap_context BSRNN 架构，该架构包含 16 kHz 音频输入、512 样本 STFT、128 样本跳步及六个带分裂块。标准 TSE 流程中，条件线索 $c$ 为外部注册语音，模型通过注意力机制将 $c$ 的特征融合至分离骨干。VoxLock 的关键差异在于线索来源：$c$ 是从通话自身截取的 3 秒语音片段。对于录音文件，取前 15 秒内最响亮的 3 秒；对于流式通话，音频直通直至检测到 3 秒语音后启动隔离。这一设计假设目标说话人为最早且最响亮的说话者，适用于耳机或手持电话场景。

### 核心创新：多阶段微调与直通-隔离切换

为适应自采样线索及真实场景，VoxLock 设计了四阶段微调策略。第一阶段（S1）在模拟通话上训练，混合近场 LibriSpeech 语音与背景说话人，25% 样本经过电话信道模拟。第二阶段（S2）引入真实 AMI 会议音频，利用耳机录音中的串扰数据，前 1000 步使用佩戴者独白作为精确目标，后 3000 步使用纯串扰数据并粘贴 3-4 秒目标语音片段。第三阶段（S4）针对长通话中目标语音衰减及距离变化问题，使用 30 秒长样本及不同距离的模拟房间进行训练。

在流式处理中，VoxLock 引入直通-隔离切换机制。在检测到 3 秒语音前，音频直通；检测到后，模型回溯处理已接收的音频（最多 30 秒）以初始化循环状态，确保分离过程从通话开始处连续。该机制解决了流式 TSE 中循环状态初始化不完整导致的分离不连续问题。损失函数仍为负尺度不变信噪比（Scale-Invariant Signal-to-Distortion Ratio, SI-SDR）：

$$ \mathcal{L} = -\text{SI-SDR}(\hat{x}, x) = -10 \log_{10} \frac{\| \alpha \hat{x} \|^2}{\| \alpha \hat{x} - x \|^2} $$

其中 $\hat{x}$ 为估计语音，$x$ 为目标语音，$\alpha$ 为最优缩放因子。该公式确保模型在优化信号保真度的同时，通过多阶段数据增强适应真实声学环境。

## 实验评估

实验在 Krisp 基准（265 个真实录音）和 AMI 会议数据集（134 个窗口及 400 个盲测窗口）上进行，评估指标为 WER、漏词率（Missed）和泄漏率（Leak）。基线包括商业产品（Krisp VI 2.5, ai-coustics, Sanas）及开源模型（TIGER, DeepFilterNet3, Hush）。VoxLock 在 Krisp 基准上达到 4.95% WER，显著优于未处理音频（23.21%）及多数开源模型，与 Krisp Default 无显著差异。在盲测 AMI 集上，WER 从 42.95% 降至 10.63%。

| System | WER (%) | Missed (%) | Leak (words/min) |
| :--- | :--- | :--- | :--- |
| VoxLock (open) | 4.95 | 4.22 | 0.11 |
| Krisp VI 2.5 Default | 5.30 | 4.21 | 1.52 |
| ai-coustics VF 2.2 L | 6.84 | 6.03 | 0.66 |
| TIGER + callerpick | 14.72 | 3.96 | 37.24 |
| No processing | 23.21 | 4.28 | 66.48 |

消融实验显示，S1 阶段贡献了主要性能提升，Krisp WER 从 9.99% 降至 5.61%。S2 阶段通过引入真实串扰数据进一步降低泄漏率，从 2.25 降至 0.11 words/min。S3 和 S4 阶段主要改善长通话和距离变化场景，在 Krisp 上显著降低 WER。评估协议存在局限：Krisp 基准由对比厂商提供，AMI 窗口均假设目标说话人先发言，且所有结果基于单次训练运行，缺乏多随机种子验证。

## 关联研究分析

从问题动机看，VoxLock 与 REAL-TSE 挑战中的基线方法共享因果 BSRNN 骨干，但 REAL-TSE 依赖外部注册语音，而 VoxLock 通过自采样机制消除了注册步骤。这一差异源于语音代理场景的实际约束：用户无法提供注册音频。VoxLock 的自采样机制在目标说话人先发言时有效，但在背景人声先于目标人声出现时失效，这限制了其在非受控会议场景的通用性。相比之下，Lin et al. 提出的基于距离的线索提取方法虽不依赖注册语音，但需额外硬件支持，VoxLock 则通过软件算法实现，部署成本更低。

从方法设计看，VoxLock 与 VoiceFilter-Lite 均致力于流式 TSE，但 VoiceFilter-Lite 依赖预录制的注册语音嵌入，而 VoxLock 动态生成条件线索。VoxLock 的多阶段微调策略针对真实场景的串扰和长通话问题进行了优化，而 VoiceFilter-Lite 主要在合成数据上训练。VoxLock 直接优化下游 ASR 性能，而传统 TSE 方法优化信号级指标，这一差异导致 VoxLock 在真实录音上的 WER 显著低于传统方法，但信号保真度可能未达最优。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

VoxLock 解决了语音代理在无注册语音条件下提取目标说话人并优化下游 ASR 性能的核心矛盾。通过从通话自身截取语音作为条件线索，并对因果 BSRNN 进行多阶段微调，VoxLock 在真实录音上实现了 4.95% WER，显著优于多数开源模型及未处理音频。该方案证明了自采样线索在受控场景下的有效性，但其依赖目标说话人先发言的假设限制了其在复杂会议场景的适用性。当背景人声在通话初期占据主导时，自采样机制是否会失效，以及多语言支持如何扩展，仍是待验证的问题。
