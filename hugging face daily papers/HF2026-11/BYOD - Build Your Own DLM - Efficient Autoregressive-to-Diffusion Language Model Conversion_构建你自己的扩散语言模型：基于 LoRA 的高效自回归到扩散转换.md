> 导读 扩散语言模型（Diffusion Language Models, DLMs）通过双向上下文与并行解码突破自回归（Autoregressive, AR）模型的串行延迟瓶颈，但其从头预训练或全参数微调的计算成本极高，限制了该范式的普及与跨架构研究。现有高效转换方法多依赖大规模数据或全参数更新，未能提供极低算力下的通用基线。本文提出 BYOD，一种仅使用低秩适应（Low-Rank Adaptation, LoRA）和双向注意力掩码替换的 AR-to-DLM 转换配方，在单 GPU 上数小时内完成四个主流模型家族的转换。该工作验证了轻量级适配在保留模型知识方面的可行性，但其在复杂推理与代码生成上的性能显著弱于全量训练模型，且低步数下的生成质量仍受限于似然估计的缺失。

## 研究背景

当语言模型需要生成长文本时，自回归模型严格的左到右串行解码导致推理延迟高企，且无法利用双向上下文。扩散语言模型（DLMs）将文本生成视为从噪声到数据的逆向去噪过程，支持并行解码与全局一致性，但离散空间下的精确似然计算不可行，且大规模预训练成本高昂。为解决这一问题，研究者尝试将预训练 AR 模型迁移至 DLM，但现有方法如 DiffuLLaMA 和 Efficient-DLM 仍需全参数微调或数百亿 Token 的数据量，计算资源开销巨大。

在极低算力预算下，如何通过纯 LoRA 适配实现跨架构的 AR-to-DLM 通用转换，并量化其性能保留率，是本文关注的核心问题。知识库共识认为迁移需大量数据（>100B tokens），但本文仅用 100M tokens 和 LoRA，挑战了“数据量决定转换质量”的隐含假设。本文旨在提供可复现的低成本基线，使 DLM 研究不再局限于拥有多节点集群的实验室，同时探究架构与父模型选择对扩散生成的影响。

## 核心方法

### 方法参照系：掩码扩散与参数高效适配

本文问题属于“自回归模型迁移适配”路线。该路线的标准流程是替换因果掩码为双向掩码，并使用掩码去噪目标进行训练。本文与该通用流程的关键差异在于：摒弃全参数微调，仅通过冻结骨干权重并附加高秩 LoRA 适配器，在极小数据量下诱导扩散生成能力。

### 掩码扩散训练目标与双向注意力干预

传统 AR 模型通过移位标签预测下一个 Token，而 BYOD 采用吸收态掩码目标，直接预测被替换为 [MASK] 的 Token。训练时，对指令 $p$ 和干净响应 $x_0$，采样掩码率 $t \sim U[10^{-3}, 1]$ 并独立掩码答案与填充位置，计算同位置重建损失：

$$
\ell_R(\theta) = -\frac{1}{t|R|} \sum_{i \in M_t \cap R} \log p_{\phi,\theta}(x_i^0 | p, x_t)
$$

该公式通过 $1/t$ 校正采样掩码率，确保不同噪声水平下的梯度平衡。物理含义是：模型需在双向上下文中，根据部分被掩码的序列恢复原始 Token。为支持双向信息流，本文移除所有层的因果掩码，允许每个位置关注所有其他位置。这一设计解决了 AR 模型无法利用右上下文的问题，使模型能在推理时根据后续 Token 修正早期预测。

### 高秩 LoRA 适配与跨架构通用性

在双向注意力干预后，本文仅在自注意力层的查询（Q）和值（V）投影上附加 LoRA 适配器，固定秩 $r=1024$，缩放因子 $\alpha=1024$，dropout 为零。骨干权重、嵌入层和输出头均冻结。这一设计动机在于：固定高秩 LoRA 可避免架构特定的超参数调优，实现跨模型家族的通用转换。尽管不同模型的总参数量不同导致可训练参数比例（4.1%–5.8%）存在差异，但统一的适配机制隔离了转换质量与父模型强度的影响。部署时，LoRA 权重可折叠进基础投影 $W_{merged} = W + (\alpha/r)BA$，消除适配器分支开销。

## 实验评估

实验在 MMLU, GSM8K, HumanEval 等九个标准基准上进行，采用贪心解码与低置信度重掩码策略。基线覆盖包括从头训练的 LLaDA 8B Instruct 及未修改的 AR 父模型。据领域综述，FLUID-7B 在 GSM8K 上达到 91.9%，而本文 BYOD-Llama-50k 仅为 61.6%，显示轻量级转换在复杂推理上存在显著差距。

| 模型 | 任务 | 准确率 (%) |
| :--- | :--- | :--- |
| BYOD-Gemma | MMLU | 68.8 |
| BYOD-Gemma | GSM8K | 64.0 |
| BYOD-Llama-50k | GSM8K | 61.6 |
| BYOD-Llama-50k | HumanEval | 28.0 |
| LLaDA 8B Instruct | MMLU | 65.5 |

BYOD-Gemma 在 MMLU 上达到 68.8%，略超 LLaDA 的 65.5%，表明知识保留良好；但在 HumanEval 上，BYOD-Llama-50k 仅为 28.0%，远低于 AR 父模型，且解析失败率高达 28.0%。消融实验显示，将 BYOD-Llama 训练步数从 25k 增至 50k，平均准确率仅提升 0.5 点，验证损失趋于平台期，表明边际收益递减。

评估边界方面，本文使用外部 Phi-4 模型计算困惑度以规避 DLM 似然计算难题，但该方法无法直接衡量多样性。可复现性上，所有转换均在单张 Google Colab GPU 上完成，代码与 Demo 已开源。

## 关联研究分析

从方法设计看，BYOD 与 Efficient-DLM 同属 AR 迁移路线，但 Efficient-DLM 采用全参数微调与 500B tokens 数据，性能更高但成本高昂；BYOD 仅用 100M tokens 和 LoRA，牺牲了复杂任务性能以换取极低算力成本。这一差异源于任务特性：代码生成对结构一致性要求高，LoRA 容量可能不足以捕捉严格的语法依赖，而知识问答任务更依赖语义表示，LoRA 足以保留。

从问题动机看，BYOD 与 LAD 均使用 LoRA 诱导扩散，但 LAD 采用混合目标函数（掩码+Token 交换），而 BYOD 证明纯掩码目标在跨架构上更通用。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文要解决的核心矛盾是 DLM 高昂的训练成本与普及需求之间的冲突。本文抓住的切入点是：AR 模型预训练权重包含丰富语义信息，可通过结构适配保留。本文通过固定高秩 LoRA 和双向掩码替换，在单 GPU 上完成四个模型家族的转换。证明了 BYOD-Gemma 在 MMLU 上达到 68.8%，接近 LLaDA 水平，但代码生成准确率仅为 28.0%。本文的边界在于：低步数下生成质量受限于似然估计缺失，且 LoRA 容量在严格逻辑任务上不足。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
