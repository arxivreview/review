> 神经影像的视觉-语言预训练旨在利用医院自然产生的影像-报告配对数据，以极低的标注成本学习通用的医学视觉-语言表示。现有方法多依赖全局特征对齐，在3D体数据面前因病灶稀疏与背景干扰而失效，且缺乏对临床纵向对比与鲁棒推理的建模。Neuro-VL 通过引入层级注意力机制与双对比目标，结合结构化推理轨迹与红队测试，构建了具备解剖感知与知识增强的神经影像基础模型。该模型在复杂3D神经影像解释中确立了SOTA地位，但其评估高度依赖LLM-as-judge，且未开源完整训练管线，限制了独立复现与跨中心泛化验证。

## 研究背景

当放射科医生面对包含数百个切片、多种对比序列的3D神经影像时，其诊断过程并非简单的图像分类，而是涉及跨切片的空间整合、跨序列的语义关联以及跨时间点的纵向对比。这一复杂的认知过程要求模型具备层级化的视觉感知能力。然而，传统的视觉-语言预训练（Vision-Language Pre-training, VLP）范式通常将影像视为扁平的2D图像或全局3D体积，通过全局对比学习对齐图像与文本的嵌入空间。这种全局对齐假设在神经影像中迅速失效，因为病灶往往仅占体积极小比例，全局特征易被非诊断背景主导，导致模型无法捕捉细粒度的病理定位信息。

为突破这一瓶颈，研究重心从2D胸片转向3D CT与MRI，催生了基于解剖感知的细粒度对齐路线。同时，原始报告的语义噪声与否定歧义催生了基于大语言模型（Large Language Model, LLM）的知识增强路线。然而，现有方法在临床部署中仍面临两大核心挑战：一是缺乏对神经影像内在层级结构（切片-扫描-研究）的显式建模，导致跨切片语义整合能力不足；二是模型在交互式诊断中易受误导性提示与临床上下文干扰，缺乏鲁棒的推理能力。Neuro-VL 正是在这一背景下，通过融合层级注意力、双对比目标与结构化推理，旨在解决复杂3D神经影像的细粒度对齐与鲁棒临床推理问题。

## 核心方法

### 方法参照系：层级注意力与双对比预训练

Neuro-VL 的视觉编码器建立在标准 ViT-Large 骨干之上，其核心创新在于将神经影像的内在层级结构（切片、扫描、研究）显式编码进注意力机制中。与通用 VLP 中常见的全局自注意力不同，该机制在 ViT 的不同层子集中分别应用切片注意力、扫描注意力与研究注意力，实现了跨层级的特征交换与整合。这一设计直接继承了 HLIP 的层级注意力架构，但将其扩展至 ViT-Large 并引入了针对神经影像报告复杂性的双对比目标，解决了原方法在大规模神经影像上的表示瓶颈。

### 核心创新：双对比目标与结构化推理轨迹

在预训练阶段，神经影像报告的复杂性远超通用网络文本，单句可能描述局部病灶，而全文则提供整体描述。为同时捕捉局部与全局语义，Neuro-VL 引入了双对比目标，通过两个可学习的视觉标记分别对齐局部病灶句子与整体报告摘要。该损失函数定义为：

$$
\mathcal{L}_{\text{dual}} = \frac{1}{2} \mathcal{L}_{\text{focal}}^{\text{CLIP}} + \frac{1}{2} \mathcal{L}_{\text{holistic}}^{\text{CLIP}}
$$

其中，$\mathcal{L}_{\text{focal}}^{\text{CLIP}}$ 和 $\mathcal{L}_{\text{holistic}}^{\text{CLIP}}$ 分别对应局部与全局的对比损失。这一设计放弃了单一全局归一化的简单性，换取了细粒度语义对齐的能力，有效提升了医疗影像表示的判别力。

在指令微调阶段，为抑制幻觉并提升可解释性，Neuro-VL 采用了结构化输出格式，强制模型在生成最终答案前，先生成“影像陈述”与“视觉推理轨迹”。影像陈述锚定具体扫描序列的模态、类型与解剖覆盖范围，视觉推理轨迹则描述具体发现并运用临床知识进行解释。这一设计解决了早期模型对提示措辞敏感、易产生语言捷径的问题，通过显式的中间监督信号，确保了视觉接地的准确性。

## 实验评估

Neuro-VL 在包含内部保留集与24个国际公共数据集的 NeuroBench 上进行了全面评估，涵盖定位、特征描述、诊断、报告生成及纵向疾病监测等任务。基线对比覆盖了前沿通用模型（GPT-5.4, Gemma 4）与专科模型（NeuroVFM, MedGemma-1.5）。在17个任务组组合中，Neuro-VL 在16个组合上超越了 GPT-5.4 与 Gemma 4，在所有17个组合上超越了 NeuroVFM。平均而言，Neuro-VL 较 GPT-5.4、Gemma 4 和 NeuroVFM 分别高出 15.9、16.9 和 23.0 个百分点。

在红队测试中，Neuro-VL 展现了显著的鲁棒性。在虚构抵抗任务中，当提示假设正常影像中存在病理时，Neuro-VL 的成功率保持在 95.6%，而 GPT-5.4 则从 87.7% 骤降至 64.1%。在误诊抵抗任务中，当提示提供错误诊断时，Neuro-VL 的成功率仅从 95.1% 降至 90.2%，而 GPT-5.4 则从 99.6% 暴跌至 44.5%。

| 任务类型 | 评估指标 | Neuro-VL | GPT-5.4 | Gemma 4 |
| :--- | :--- | :--- | :--- | :--- |
| 虚构抵抗（假设病理） | 成功率 (%) | 95.6 | 64.1 | - |
| 误诊抵抗（错误诊断） | 成功率 (%) | 90.2 | 44.5 | - |
| 纵向变化表征 | 准确率 (%) | 87.5 | 81.6 | - |
| 纵向疾病轨迹 | 准确率 (%) | 96.9 | 86.5 | - |

评估协议方面，Neuro-VL 引入了 NeuroJudge 作为报告生成的评估器，基于 LLM 进行偏好排序。然而，该评估器与人类专家的一致性（Kendall's $\tau$）虽在200个内部研究上进行了验证，但其在不同病理类别上的系统性偏差分析尚未提供。此外，完整训练管线与 NeuroBench 基准未开源，限制了独立复现。

## 关联研究分析

从问题动机看，Neuro-VL 与 CT-CLIP 等早期3D VLP 方法存在本质差异。CT-CLIP 等方法主要解决3D数据的空间感知问题，通过引入空间感知编码开启3D预训练方向，但其评估仍局限于零样本分类与检索。Neuro-VL 则进一步将问题延伸至交互式诊断与纵向对比，通过结构化推理轨迹解决了模型在复杂临床场景中的幻觉与鲁棒性问题。这一差异源于神经影像对临床决策支持的高要求，单纯的表示学习已无法满足需求。

从方法设计看，Neuro-VL 与 MedGemma 等通用医学模型形成了鲜明对比。MedGemma 依赖大规模通用医学数据与通用架构，追求开放世界的泛化。Neuro-VL 则通过领域特化数据（近百万神经影像研究）与层级注意力架构，在神经影像特定任务上大幅超越通用模型。这一差异验证了领域特化数据与架构设计在复杂模态中的必要性，但也引发了关于模型在极端分布偏移下泛化能力的疑问。

## 总结

Neuro-VL 针对神经影像中全局对齐失效与临床推理鲁棒性不足的核心矛盾，通过层级注意力机制与双对比目标实现了细粒度语义对齐，并借助结构化推理轨迹与红队测试提升了临床可靠性。该模型在 NeuroBench 上较 GPT-5.4 平均提升 15.9 个百分点，在虚构抵抗任务中成功率达 95.6%，确立了在复杂3D神经影像解释中的SOTA地位。然而，其评估高度依赖 LLM-as-judge，且未开源完整训练管线，限制了独立复现与跨中心泛化验证。当评估器本身存在系统性偏好时，NeuroJudge 的偏好排序是否足以支撑临床部署的信任建立，论文未给出回答。
