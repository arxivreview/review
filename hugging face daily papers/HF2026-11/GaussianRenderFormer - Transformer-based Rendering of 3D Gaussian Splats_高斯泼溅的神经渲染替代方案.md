# HuggingFace最新推荐论文 ｜GaussianRenderFormer: Transformer-based Rendering of 3D Gaussian Splats ｜高斯泼溅的神经渲染替代方案

研究机构：以色列耶路撒冷希伯来大学

作者：Shahaf Valencia Levy、Sagie Benaim

论文原文见 [arXiv](https://arxiv.org/abs/2611.05593)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2611.05593)

> 导读 3D高斯泼溅（3D Gaussian Splatting, 3DGS）依赖手写光栅化器进行渲染，该过程包含深度排序与Alpha混合，导致计算开销大且易产生弹出伪影。现有方法虽在优化与压缩上取得进展，但均未触及渲染管线本身的范式替代。本文提出GaussianRenderFormer，将高斯参数转化为Token，利用Transformer直接预测像素，完全摒弃光栅化器。该工作验证了神经渲染高斯的可行性，但推理延迟与重建质量仍显著落后于传统光栅化，目前仅具探索意义。

## 研究背景

当渲染器面对由数万个半透明、重叠的高斯基元组成的场景时，传统光栅化器必须执行逐像素的深度排序与Alpha混合。这一过程不仅计算密集，且因排序的非连续性导致相机移动时产生视觉伪影。为消除排序依赖，领域内出现了无排序渲染或射线追踪等尝试，但这些方法仍属于手写算法范畴，无法学习复杂的光传输特性。与此同时，基于Transformer的神经渲染（Learned Rendering）在网格（Mesh）渲染中展现了潜力，如RenderFormer能直接预测全局光照，但其架构针对稀疏的三角形面片设计，难以直接迁移至高斯场景。

高斯场景的密集性与半透明性构成了神经渲染的障碍：一个物体通常包含数万高斯，远超RenderFormer训练的4096个三角形。现有前馈重建方法（如PixelSplat）虽能快速生成高斯，但最终图像仍由光栅化器输出。本文的核心问题在于：能否构建一个前馈神经网络，直接以高斯参数集合为输入，在不使用任何光栅化步骤的情况下，输出高保真图像？这一探索旨在打破光栅化器作为3DGS渲染唯一高效途径的隐含假设，为后续学习光传输与统一渲染管线奠定基础。

## 核心方法

### 方法参照系：从网格到高斯的架构迁移

GaussianRenderFormer沿用了RenderFormer的两阶段Transformer架构，但将输入从三角形面片替换为高斯基元。标准流程中，RenderFormer通过视图无关编码器处理网格几何，再通过视图相关解码器结合相机射线生成像素。本文的关键差异在于输入表示的转换：每个高斯被嵌入为一个Token，包含位置、尺度、旋转、颜色和不透明度共14个参数。这一改动要求编码器能够处理高斯间的密集交互，而解码器需适应高斯在图像平面上的投影特性，而非网格的顶点位置。

### 视图无关编码器：高斯Token化与全局交互

在视图无关阶段，每个高斯 $g_i$ 被线性映射为Token $t_i$：

$$ t_i = e + \text{RMSNorm}(A g_i + b) $$

其中 $A$ 为线性层权重，$e$ 为共享嵌入。该Token化过程将高斯的几何与外观属性统一编码。设计动机在于，传统光栅化器仅在高斯投影后处理其属性，而Token化允许网络在投影前学习高斯间的全局关系。编码器通过12层自注意力机制，利用高斯中心的3D旋转位置编码（Rotary Position Embedding, RoPE）交换信息，模拟光在高斯间的传播。这一设计使模型能够捕捉场景的整体结构，而非仅依赖局部投影。

### 视图相关解码器：投影感知的位置编码与足迹注入

视图相关解码器需解决高斯在图像平面上的定位问题。传统3D RoPE仅编码相机坐标系下的位置，无法反映高斯在图像中的投影位置。本文引入2D投影位置编码，将高斯中心投影至图像平面 $(u_i, v_i)$，并以此旋转注意力键：

$$ u_i = \frac{1}{p} \left( \frac{W}{2} + f \frac{x_i}{z_i} \right), \quad v_i = \frac{1}{p} \left( \frac{H}{2} - f \frac{y_i}{z_i} \right) $$

其中 $p$ 为补丁大小，$f$ 为焦距。此外，为弥补网络对高斯投影尺度感知的缺失，本文计算高斯在图像上的投影足迹（Footprint） $\Sigma'_i$，并将其作为偏置加入注意力键。这一设计动机在于，高斯的半透明性与重叠性使得网络难以从3D位置推断其2D覆盖范围，显式注入投影几何信息可显著降低学习难度，使注意力机制聚焦于相关高斯。

## 实验评估

### 实验设置与主结果

实验在Objaverse数据集上进行，训练集包含26,820个物体，每个物体剪枝至20,000个高斯。评估指标为PSNR、SSIM和LPIPS，对比基线为gsplat光栅化器。主结果显示，GaussianRenderFormer在300个未见物体上达到38.08 dB PSNR，而光栅化相同剪枝输入达到44.02 dB。

| 方法 | PSNR (dB) | SSIM | LPIPS |
| :--- | :--- | :--- | :--- |
| GaussianRenderFormer | 38.08 | 0.9954 | 0.0046 |
| gsplat (光栅化) | 44.02 | 0.9954 | 0.0046 |

核心数字对比表明，神经渲染在质量上落后光栅化约6 dB，且推理速度显著慢于光栅化（275 ms vs <1 ms）。

### 消融与设计决策验证

消融实验验证了视图解码器中三项改动的重要性。移除投影足迹导致PSNR下降1.7 dB，证明显式几何先验对网络收敛至关重要。相比之下，移除小各向同性项仅导致0.08 dB下降，说明该增益并非来自光栅化器惯例。此外，分阶段训练策略（先冻结主干训练输入层）比从头训练提升3.1 dB，表明预训练权重对高斯渲染的迁移有效性。

| 消融项 | PSNR (dB) | 差异 (dB) |
| :--- | :--- | :--- |
| 完整模型 | 38.08 | - |
| 无投影足迹 | 36.38 | -1.70 |
| 无小各向同性项 | 38.00 | -0.08 |

### 评估边界与可复现性

评估局限于合成物体场景，未涉及真实世界复杂光照与背景。指标未包含渲染速度对比的详细硬件配置，但论文指出场景编码器复杂度随高斯数量平方增长，限制了大规模场景应用。代码与模型已开源，但训练需1,327 GPU小时，复现门槛较高。

## 关联研究分析

从问题动机看，GaussianRenderFormer与LVSM（Jin et al., 2025）均试图消除光栅化器，但LVSM输入为图像，输出为图像，属于隐式视图合成；而本文输入为显式高斯，输出为图像，属于显式场景的神经渲染。这一差异导致LVSM无法直接对比几何一致性，而本文可与光栅化器直接对比。从方法设计看，RenderFormer（Zeng et al., 2025）针对网格设计，其解码器依赖顶点位置；本文通过引入2D投影位置编码与足迹，解决了高斯在图像平面上的定位与尺度感知问题。这一改动是否足以弥补高斯与网格在表示上的本质差异，仍需更多场景验证。

## 总结

本文针对3DGS光栅化器计算开销大且无法学习光传输的问题，提出GaussianRenderFormer，通过Transformer直接渲染高斯场景。该方法在Objaverse上达到38.08 dB PSNR，虽低于光栅化器的44.02 dB，但验证了无光栅化渲染的可行性。其边界在于推理速度慢且依赖显式几何先验，难以处理大规模场景。当高斯数量进一步增加时，Transformer的注意力机制是否仍能保持线性扩展性，论文未给出回答。
