> 字节级语言模型（Byte-level Language Model）旨在消除子词分词器（Subword Tokenizer）引入的词汇表偏差与分布外（Out-of-Distribution, OOD）脆弱性，但全分辨率处理导致计算成本呈二次方增长。现有层级压缩方法在提升效率的同时，往往因信息泄露或重建失真而牺牲语义保真度。DEEPMEM 引入信号处理中的可逆小波变换（Lifting Scheme），将语义压缩与无损字节载体解耦，并通过因果超分辨率解码器恢复细节。该架构在 100M 参数规模下实现了优于同规模基线的语言建模性能，但其对代码等强局部依赖任务的适用性仍存疑。

## 研究背景

当语言模型直接处理原始字节序列时，其词汇表固定为 256 个符号，天然消除了未知词（Out-of-Vocabulary, OOV）问题并保留了字符级形态信息。然而，字节序列长度通常是子词序列的 3 至 5 倍，导致 Transformer 的自注意力机制计算复杂度急剧上升。为解决此瓶颈，层级计算（Hierarchical Computation）通过下采样缩短序列长度，但传统池化或补丁合并操作会不可逆地丢失局部细节，迫使模型依赖额外的局部解码器进行重建，增加了架构复杂性。

当前无分词（Tokenizer-Free）路线的核心矛盾在于：如何在激进压缩语义流以提升计算效率的同时，严格保留字节级信息的无损性。现有方法如 MEGABYTE 依赖粗粒度表示协调局部解码器，而 Byte Latent Transformer (BLT) 基于熵动态分块，均未在架构层面实现语义压缩与无损保真的严格解耦。DEEPMEM 的切入点在于利用多速率信号处理原理，构建因果约束下的可逆子带分解，使语义流可被激进压缩，而字节身份由独立的无损载体流显式保留。

## 核心方法

### 方法参照系：因果层级自回归建模

在标准的层级自回归模型中，输入序列通过下采样层逐步缩短，深层网络在压缩后的序列上执行计算，最后通过上采样层恢复原始分辨率以预测下一个 token。该流程的关键缺陷在于，下采样过程通常是非可逆的，导致深层语义表示无法精确还原底层字节信息，且自回归的因果性约束在层级转换中容易被破坏，引发未来信息泄露。

### 可逆子带分析与无损载体流

DEEPMEM 的核心创新在于将输入解耦为学习到的语义流 $S^{(\ell)}$ 和固定的无损载体流 $K^{(\ell)}$。载体流初始化为每个字节的 8 位二进制双极表示，并通过可逆小波变换（Lifting Scheme）在层级间传递。在第 $\ell$ 层，相邻载体向量被分离为偶数位置 $e_j^{(\ell)}$ 和奇数位置 $o_j^{(\ell)}$，通过学习的预测器 $P_\ell$ 和更新器 $U_\ell$ 生成粗粒度载体 $C_j^{(\ell+1)}$ 和细节侧带 $\Delta_j^{(\ell+1)}$：

$$
\Delta_j^{(\ell+1)} = o_j^{(\ell)} - P_\ell(e_j^{(\ell)}), \quad C_j^{(\ell+1)} = e_j^{(\ell)} + U_\ell(\Delta_j^{(\ell+1)})
$$

该变换具有精确的代数逆，确保在实数算术下可无损重建原始字节载体。这一设计解决了传统层级模型中压缩状态必须隐式记忆或依赖外部路径重建字节身份的失效问题，使语义流无需承担无损保真的负担。

### 因果超分辨率解码与共享状态精炼

在语义分析路径中，相邻语义向量被拼接并投影至下一层宽度，同时注入低秩投影的载体信息。在最深处的瓶颈层（16 个位置），模型使用共享的快权重（Fast-Weight）混合器进行两次迭代精炼，更新潜在状态 $Z_r$：

$$
Z_{r+1} = Z_r + R_{\text{bot}}(\text{RMSNorm}(B + Z_r)), \quad \tilde{S}^{(L)} = B + Z_2
$$

其中 $B$ 为编码器瓶颈表示。该模块通过共享参数和迭代更新，在极低计算量下增强了瓶颈处的语义抽象能力。随后，因果超分辨率解码器将父节点向量映射为子节点提案，并应用延迟解包规则（Shifted Unpacking Rule）：右子节点提案用于位置 $2j+1$，左子节点位置 $2j$ 接收来自父节点 $j-1$ 的提案。这一规则严格防止了父节点（覆盖 $2j$ 和 $2j+1$）的信息泄露到位置 $2j$，确保了自回归因果性。

## 实验评估

实验在 FineWeb-Edu、PG19、Stack-smol 及 FLORES 多语言数据集上进行，所有模型均训练至约 100M 参数，上下文长度为 2048 字节。基线包括标准 Transformer、FastWeight、BLT 及 Autoregressive U-Net (AU-Net)。

| 数据集 | DEEPMEM (BPB) | Transformer (BPB) | FastWeight (BPB) | BLT (BPB) | AU-Net (BPB) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| FineWeb-Edu | 1.0134 | 1.0457 | 1.0187 | 1.0336 | 1.0319 |
| PG19 | 1.4402 | 1.4635 | - | - | - |
| Stack-smol | 2.4854 | 2.4474 | - | - | - |
| FLORES (Macro) | 1.9694 | - | - | - | - |

DEEPMEM 在通用文本（FineWeb-Edu）和长文本（PG19）上均取得最低 BPB，显著优于全分辨率 Transformer 和扁平 FastWeight 基线。在多语言 FLORES 基准上，其宏平均 BPB 为 1.9694，验证了字节级建模结合层级压缩在多语言场景下的有效性。然而，在代码数据集 Stack-smol 上，DEEPMEM (2.4854 BPB) 略逊于扁平 Transformer (2.4474 BPB)，表明层级结构可能破坏了代码中紧密的局部字符依赖。

评估协议控制了训练语料、步数、批大小及硬件，确保了公平比较。但实验未报告置信区间，且未对比 MambaByte 等状态空间模型（SSM）基线，限制了其在长序列效率上的全面评估。此外，代码开源情况未明确，复现性存在一定门槛。

## 关联研究分析

从问题动机看，DEEPMEM 与 Byte Latent Transformer (BLT) 均致力于解决字节级模型的效率问题，但 BLT 依赖熵驱动的动态分块，其压缩粒度随输入内容波动，导致计算模式非结构化；DEEPMEM 采用固定二进层级和因果超分辨率，计算模式更确定且易于硬件优化。这一差异源于对“效率”定义的不同：BLT 追求自适应压缩率，DEEPMEM 追求结构化无损压缩。

从方法设计看，DEEPMEM 与 Autoregressive U-Net (AU-Net) 共享层级下采样与上采样框架，但 AU-Net 的跳跃连接直接融合特征，未显式处理自回归因果性在层级转换中的泄露风险。DEEPMEM 引入的延迟解包规则是对 AU-Net 在自回归场景下因果性缺陷的直接修正。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

DEEPMEM 针对字节级语言模型中语义压缩与无损保真的矛盾，提出了一种因果多尺度架构。通过引入可逆小波变换分离语义流与无损载体流，并设计因果超分辨率解码器，该架构在 100M 参数规模下实现了 1.0134 BPB 的 FineWeb-Edu 性能，优于同规模基线。其核心贡献在于证明了在严格因果约束下，激进压缩语义流同时保留字节级无损信息是可行的。然而，该架构在代码任务上的性能下降暴露了层级结构对强局部依赖任务的潜在干扰。当代码生成任务对字符级精确性要求极高时，层级压缩引入的延迟解包机制是否会成为新的性能瓶颈，论文未给出回答。
