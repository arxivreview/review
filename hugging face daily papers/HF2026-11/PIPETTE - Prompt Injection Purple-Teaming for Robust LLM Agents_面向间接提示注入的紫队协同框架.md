# HuggingFace最新推荐论文 ｜PIPETTE: Prompt Injection Purple-Teaming for Robust LLM Agents ｜面向间接提示注入的紫队协同框架

研究机构：加拿大滑铁卢大学、浙江大学

作者：Lipeng He、Yihan Wang、Jiawen Zhang 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2611.24362)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2611.24362)

> 导读 大语言模型智能体在调用外部工具时面临间接提示注入（Indirect Prompt Injection, IPI）风险，攻击者通过污染数据通道劫持智能体执行恶意任务。现有自动化红队方法虽能生成高攻击成功率（Attack Success Rate, ASR）的对抗样本，但往往陷入策略层面的模式坍塌，导致防御训练后对未见攻击的鲁棒性不足。Pipette 提出紫队协同框架，通过字典学习奖励引导红队覆盖多样化攻击策略，并结合 Token 级自蒸馏优化防御训练以保留良性效用。该工作揭示了红队攻击数量与防御鲁棒性之间的非线性关系，为智能体安全评估提供了攻防目标对齐的新范式，但其策略覆盖的完备性仍依赖字典构建的粒度。

## 研究背景

当智能体处理来自网页或 API 的不可信数据时，攻击者可在数据通道中嵌入恶意指令，诱导智能体忽略用户任务而执行攻击者指定的操作，这一漏洞称为间接提示注入（IPI）。与用户直接发起的越狱攻击不同，IPI 要求智能体在忽略注入指令的同时，仍需利用周围良性数据完成原始用户任务，这对防御机制提出了双重约束。为了在部署前发现此类漏洞，开发者通常采用紫队（Purple-Teaming）工作流，即利用强化学习（Reinforcement Learning, RL）生成对抗性注入字符串，并基于这些样本进行对抗训练以加固模型。

然而，现有基于 RL 的红队方法（如 RL-Hammer 和 PISmith）主要优化攻击成功率，容易收敛到少数几种高效的攻击策略上，造成策略层面的模式坍塌。尽管这些方法引入了基于文本表面差异（如 BLEU 分数或嵌入距离）的多样性正则化，但攻击者可通过改写措辞或插入无关文本绕过这些约束，而重复利用相同的逻辑漏洞。这种表面多样性掩盖了策略单一性的本质，导致生成的训练数据虽然数量庞大，却未能覆盖智能体潜在的多种失效模式。此外，传统的轨迹级奖励在防御训练中难以区分导致任务失败的特定 Token，迫使模型在遇到可疑输入时倾向于拒绝执行，从而牺牲了良性任务的完成率。Pipette 旨在解决红队策略覆盖不足与防御训练效用损失之间的耦合矛盾。

## 核心方法

### 紫队协同与模式坍塌诊断

Pipette 将红队测试与防御训练统一于最大化加固后智能体鲁棒性的目标下。在标准紫队流程中，红队策略 $\pi_\phi$ 通过 GRPO 算法优化，旨在最大化攻击奖励 $r_{atk} = \Phi_{t_{adv}}(\tau')$，其中 $\Phi$ 为任务完成指示函数。然而，仅优化该奖励会导致 $\pi_\phi$ 发现一种有效策略后便反复复用，因为该策略在多数任务上均能获得高回报。Pipette 指出，这种策略坍塌使得训练集 $\mathcal{D}_{train}$ 虽然规模扩大，但信息熵并未增加，无法为防御训练提供多样化的漏洞样本。

### 基于字典学习的策略覆盖奖励

为强制红队策略探索新的攻击逻辑，Pipette 引入基于字典学习的奖励机制。该机制将生成的攻击字符串分解为稀疏字典中的可复用组件，每个组件代表一种独立的攻击策略（如“声称任务已完成”或“伪造工作流元数据”）。红队策略仅在成功攻击无法被已发现的组件解释时获得奖励。

$$
R_{dict}(d_{adv}) = \begin{cases}
1 & \text{if } \min_{c \in \mathcal{C}} \| d_{adv} - c \| > \delta \\
0 & \text{otherwise}
\end{cases}
$$

其中 $\mathcal{C}$ 为动态更新的策略字典，$\delta$ 为相似度阈值。该公式的物理含义是：只有当新攻击与字典中所有已知策略的距离超过阈值时，才被视为新策略并给予奖励。这一设计动机在于，传统基于 Token 熵或嵌入距离的正则化仅衡量表面文本差异，而字典学习直接作用于语义策略层面，迫使 $\pi_\phi$ 在发现一种漏洞后必须寻找另一种逻辑不同的漏洞才能获得正向反馈，从而在训练过程中显式地覆盖更多样的失效模式。

### Token 级自蒸馏与效用保持

在防御训练阶段，Pipette 采用在线策略自蒸馏（On-Policy Self-Distillation, OPSD）替代传统的轨迹级奖励。传统 RL 防御使用二元奖励 $r_{def} = \Phi_{t_u}(\tau') \cdot (1 - \Phi_{t_{adv}}(\tau'))$，该奖励无法定位导致攻击成功的特定 Token，导致模型倾向于通过拒绝执行来规避风险。Pipette 通过自蒸馏机制，让当前策略 $\pi_\theta$ 向一个条件于干净观测的教师模型 $\pi_{teacher}$ 对齐，同时保留对攻击样本的鲁棒性约束。

$$
\mathcal{L}_{OPSD} = \mathbb{E}_{\tau' \sim \pi_\theta} \left[ \sum_{t=1}^{T} D_{KL} \left( \pi_{teacher}(\cdot | H_t^{clean}) \parallel \pi_\theta(\cdot | H_t') \right) \right]
$$

该公式表示在攻击上下文 $H_t'$ 下，最小化当前策略与干净上下文下教师策略之间的 KL 散度。其设计动机在于，通过 Token 级的软标签监督，模型能够学习到哪些 Token 是受注入指令驱动的（应抑制），哪些是完成用户任务所需的（应保留），从而在抵抗攻击的同时维持对良性数据的处理能力，避免了“因噎废食”式的过度防御。

## 实验评估

实验在 AgentDojo 和 AgentDyn 基准上进行，对比了 RL-Hammer 和 PISmith 两种 SOTA 红队方法生成的训练数据对防御效果的影响。评估协议包括静态攻击（ChatInject）和迭代自适应攻击（TAP, Genetic），重点考察训练时 ASR 与推理时鲁棒性之间的相关性。

| 红队方法 | 基础模型 | 训练时 ASR (%) | 训练集大小 (# Strings) |
| :--- | :--- | :--- | :--- |
| RL-Hammer | Qwen3-4B | 33.39% | 4,282 |
| PISmith | Qwen3-4B | 68.75% | 7,132 |
| RL-Hammer | Llama-8B | 25.18% | 1,671 |
| PISmith | Llama-8B | 27.32% | 1,783 |

数据显示，PISmith 在 Qwen3-4B 上的训练时 ASR（68.75%）远高于 RL-Hammer（33.39%），且生成的训练集规模更大。然而，在随后的防御训练中，基于 PISmith 数据训练的模型在未见攻击下的最坏情况 ASR 反而更高（47.5% vs 27.5%）。这一反直觉结果证实了高攻击成功率并不必然带来高鲁棒性，因为 PISmith 的高 ASR 主要源于对少数几种攻击策略的重复利用，而非策略多样性的提升。

在消融实验中，Pipette 通过字典学习奖励显著提升了策略覆盖度。在 AgentDojo 的静态攻击下，Pipette 防御后的模型 ASR 降至 0%-10%，且在良性任务上的效用（Benign Utility）与未防御基线相当。相比之下，传统 RL 防御往往在降低 ASR 的同时导致良性效用大幅下降。评估边界方面，实验主要依赖模拟环境中的任务对，未涉及真实世界复杂工具链的长尾分布，且自适应攻击的查询预算固定，可能低估了高计算预算攻击者的威胁。

## 关联研究分析

从问题动机看，Pipette 与 T-MAP 等轨迹感知红队方法存在显著差异。T-MAP 侧重于通过进化搜索发现导致有害动作执行的轨迹，其评估核心在于行为副作用的覆盖；而 Pipette 聚焦于 IPI 特有的“指令劫持”机制，强调在忽略注入指令的同时保留数据利用能力。T-MAP 的方法论假设是攻击成功即有害，而 Pipette 指出在 IPI 场景下，攻击成功（执行 $t_{adv}$）与防御成功（完成 $t_u$ 且忽略 $d_{adv}$）是正交且需同时满足的目标，这一任务特性决定了 Pipette 必须引入效用保持机制，而 T-MAP 未对此进行显式建模。

从方法设计看，Pipette 与 Rainbow Teaming 在多样性优化上采取了不同路径。Rainbow Teaming 利用质量多样性（Quality-Diversity, QD）搜索维护一个提示词档案，通过优化攻击质量与多样性的帕累托前沿来避免模式坍塌；Pipette 则通过字典学习将多样性约束内化为奖励函数的一部分，直接惩罚与已知策略相似的生成结果。Rainbow Teaming 的多样性度量通常基于嵌入空间或文本特征，而 Pipette 的字典学习试图在语义策略层面进行解耦。然而，字典的构建依赖于对“攻击策略”的抽象定义，若策略粒度定义不当，Pipette 可能退化为另一种形式的表面多样性搜索，这一风险在论文中未通过极端案例进行充分压力测试。

## 总结

Pipette 针对 LLM 智能体 IPI 防御中红队策略单一与防御效用损失的核心矛盾，提出了紫队协同框架。通过引入字典学习奖励，该框架强制红队策略在语义层面覆盖多样化攻击逻辑，并结合 Token 级自蒸馏在防御训练中实现细粒度的指令抑制与任务保留。实验表明，Pipette 在 AgentDojo 上将静态攻击 ASR 降至 0%-10%，同时保持了接近基线的良性效用，有效解决了高 ASR 红队数据导致防御鲁棒性下降的问题。然而，该方法的边界在于策略字典的构建依赖于对攻击模式的先验抽象，且实验环境为模拟沙箱，未验证在真实复杂工具链下的泛化能力。当攻击者采用与字典中已知策略在语义上高度相似但逻辑上全新的混合攻击时，该框架的策略覆盖机制是否仍能保持鲁棒，尚需进一步验证。
