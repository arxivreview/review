论文原文见 [arXiv](https://arxiv.org/abs/2611.21925)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2611.21925)

> 投机解码通过“草稿-验证”范式打破自回归生成的串行瓶颈，但并行草稿模型在生成候选序列时面临特征编码失真与历史拒绝信息丢失的双重困境。现有方法依赖密集投影矩阵混合目标模型隐藏状态，导致特征空间结构破坏，且忽略被拒绝 Token 中蕴含的修正信号。DNeo 提出混合特征注意力（MoFA）以保留特征结构，并引入拒绝记忆机制利用历史拒绝状态，通过融合因果头增强草稿一致性。该架构在保持无损性的前提下显著提升了 Tokens Per Forward (TPF)，确立了并行草稿架构的新基准，但其对目标模型层间冗余的依赖及长序列稳定性仍需进一步验证。

## 研究背景

当大语言模型（LLM）进行自回归解码时，每生成一个 Token 需执行一次完整前向传播，导致推理延迟与输出长度线性相关，且无法充分利用现代 GPU 的并行计算能力。投机解码（Speculative Decoding, SD）通过引入轻量级草稿模型并行生成候选序列，再由目标模型单次并行验证，将串行生成转化为并行验证，从而在不改变输出分布的前提下加速推理。然而，并行草稿模型在单次前向传播中生成多个 Token，各位置间缺乏因果依赖，导致草稿质量随位置增加而衰减，即“后缀衰减”现象。为缓解此问题，现有并行草稿架构（如 DFlash, DSpark）引入特征编码机制，将目标模型的隐藏状态投影至草稿模型空间，以提供丰富的上下文信息。

尽管特征编码提升了草稿质量，但现有方法存在三个关键缺陷：一是标准密集投影矩阵混合了目标模型隐藏维度的所有坐标，产生“残差混合”效应，破坏了特征空间的原始结构；二是编码过程无记忆，忽略前一轮被拒绝 Token 中蕴含的有用特征；三是层选择策略均匀分布，未针对草稿任务优化目标层的重要性。这些缺陷限制了草稿模型与目标模型分布的对齐程度，进而制约了加速比的上限。DNeo 针对并行草稿架构的特征编码机制进行重构，旨在通过结构保留编码与拒绝信息利用，提升 Tokens Per Forward (TPF) 指标。

## 核心方法

### 方法参照系：并行草稿架构的特征编码流程

在并行草稿架构中，草稿模型接收目标模型编码后的上下文特征作为输入，通过单次前向传播生成 $b$ 个候选 Token。标准流程中，目标模型选定 $c$ 层的隐藏状态 $\vec{h}^{(l_1)}, \dots, \vec{h}^{(l_c)}$ 经密集线性投影 $F_c$ 融合为草稿模型输入特征 $\vec{f}_i$。该特征随后用于计算草稿模型的键值缓存，并通过交叉注意力机制指导草稿生成。DNeo 在此流程中替换了密集投影模块，并扩展了输入序列以包含历史拒绝特征，同时优化了因果修正头。

### 结构保留编码：混合特征注意力（MoFA）

标准密集编码器 $F_c \in \mathbb{R}^{cd_h \times d_h}$ 将 $c$ 个隐藏状态的所有坐标混合至输出特征的每个坐标，导致残差混合，降低了特征的可解释性与有效性。DNeo 提出混合特征注意力（Mixture-of-Features Attention, MoFA），通过可学习的标量权重对目标层进行加权融合，避免跨维度混合。

$$
\vec{f}_{i} = \text{Enc}_{\text{MoFA}}(x_{i}) \triangleq \text{softmax}(w_{1},\dots,w_{c}) \cdot (\vec{h}_{i}^{(l_{1})},\dots,\vec{h}_{i}^{(l_{c})}) = \sum_{k=1}^{c} u_{k}\vec{h}_{i}^{(l_{k})}
$$

该公式表明，MoFA 对每个目标层隐藏状态进行标量加权求和，其中 $u_k$ 为 softmax 归一化后的层重要性权重。这种设计保留了目标模型特征空间的坐标结构，使每个输出坐标仅由对应目标层坐标加权组成，消除了残差混合。同时，softmax 权重分布提供了层重要性的可解释性，支持非均匀层选择策略。

### 历史拒绝信息利用：拒绝记忆机制

现有并行草稿模型忽略前一轮被拒绝 Token 的信息，导致重复错误。DNeo 引入拒绝记忆（Rejection Memory），利用目标模型验证阶段已计算出的被拒绝位置隐藏状态，通过辅助交叉注意力机制供草稿模型查询。

$$
X_{t+1} = [\underbrace{\vec{f}_{1},\dots,\vec{f}_{j}}_{\text{Context features}},\; x_{\text{bonus}} \circ \underbrace{[\mathbf{m}]_{1},\dots,[\mathbf{m}]_{b}}_{\text{Masked block}},\;\;\circ\underbrace{(\hat{f}_{j+1},\dots,\hat{f}_{b})}_{\text{Rejection features}}]
$$

该公式定义了下一轮草稿模型的输入序列 $X_{t+1}$，其中 $\hat{f}_{j+1},\dots,\hat{f}_{b}$ 为经 MoFA 编码的被拒绝 Token 特征。拒绝特征作为辅助上下文附加在掩码块之后，草稿模型通过交叉注意力检索相关拒绝信息，而不直接修改掩码嵌入。这种设计保留了掩码 Token 的独立角色，同时使草稿模型能利用历史拒绝信号修正当前预测。

### 因果一致性增强：融合因果头

并行草稿模型需通过因果头修正后缀衰减。DSpark 因果头 $W_r$ 仅基于前一个 Token 进行低秩线性修正，表达能力有限；DFlash-2 分数头虽具双线性表达能力，但仅修正 Top-$k$ 候选，无法进行全局词汇修正。DNeo 提出融合因果头，在共享潜在空间中结合两者优势。

$$
\text{DNeo}_{\text{head}}(\hat{x}_{j-1}) \triangleq W_{\text{up}} \left( \alpha_{j} \cdot \underbrace{[W^{V}(\mathbf{1}[\hat{x}_{j-1}]) \odot W^{K}\;\vec{h}_{j}^{(\ell_{m})}] \cdot W^{Q}[\mathcal{V}]}_{\text{Dense DF2 Head}} + \beta_{j} \cdot \underbrace{W_{\text{down}}(\mathbf{1}[x_{j-1}])}_{\text{DSpark Head}} \right)
$$

该公式在潜在空间融合 DF2 的上下文感知修正与 DSpark 的低秩修正，随后通过 $W_{\text{up}}$ 投影至全词汇表。$\alpha_j, \beta_j$ 为位置依赖的学习权重，允许修正强度随草稿位置动态调整。此设计使因果头既能利用上下文信息，又能对全词汇表进行全局修正，提升了草稿序列的因果一致性。

## 实验评估

实验在 H100 GPU 上使用 Qwen3-4B 作为目标模型，评估 DNeo 在 MT-Bench, HumanEval, GSM8K 等基准上的推理速度。基线覆盖自回归草稿模型（EAGLE-3）及并行草稿模型（DFlash, DFlash-2, DSpark）。DNeo 在并行草稿类别中确立新 SOTA，较 DFlash-2 加速 1.3x，TPF 提升 0.6。

| 方法 | 类型 | 相对加速比 (vs DFlash-2) | TPF 提升 |
| :--- | :--- | :--- | :--- |
| DNeo | 并行草稿 | 1.3x | +0.6 |
| DFlash-2 | 并行草稿 | 1.0x (基线) | - |
| EAGLE-3 | 自回归草稿 | 未直接对比 | - |

消融实验显示，MoFA 较密集编码提升 TPF 16%，拒绝记忆提升 TPF 0.17。前缀仅注意力（Prefix-only Attention）移除掩码块自注意力后，TPF 无显著下降，表明 2-tap 卷积与因果头已充分捕获局部依赖。评估协议未覆盖长上下文场景下的 KV 缓存开销变化，且未报告置信区间。

## 关联研究分析

从特征编码机制看，DNeo 与 EAGLE 系列同属特征对齐路线，但 EAGLE 采用自回归草稿，通过移位 Token 输入处理随机性，而 DNeo 针对并行草稿的残差混合问题，通过 MoFA 保留特征结构。EAGLE 的密集投影虽提升接受率，但在并行架构中因坐标混合导致特征失真，DNeo 的层间加权融合解决了此问题，但隐含了目标模型层间冗余的假设，若目标模型层间信息互补性强，MoFA 的标量加权可能损失信息。

从拒绝信息利用看，DNeo 与 DFlow 均利用被拒绝 Token，但 DFlow 将拒绝特征融合至掩码嵌入，导致上下文瓶颈；DNeo 通过辅助交叉注意力保持表示独立，使每个掩码位置仅检索相关拒绝特征。然而，拒绝记忆引入轮次间串行依赖，需通过在线蒸馏训练以匹配推理行为，这增加了训练复杂度。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

DNeo 针对并行草稿模型特征编码的残差混合与无记忆缺陷，提出 MoFA 结构保留编码与拒绝记忆机制，通过融合因果头增强草稿一致性。实验表明，DNeo 较 DFlash-2 加速 1.3x，TPF 提升 0.6，确立了并行草稿架构的新基准。其边界在于对目标模型层间冗余的依赖及长序列稳定性未验证。当目标模型层间信息互补性强时，MoFA 的标量加权是否会导致特征信息损失，论文未给出回答。
