> 统一多模态模型旨在单一架构内融合视觉理解与图像生成，但理解任务偏好全局语义紧凑表征，而生成任务偏好高频细节重建表征，两者在共享网络层中产生的优化目标矛盾导致联合训练时一方性能提升往往以另一方性能下降为代价。现有混合架构虽通过解耦编码器缓解了梯度冲突，但在处理长序列交错数据时，全注意力机制的计算开销呈二次方增长，且去噪过程中的中间噪声状态易污染后续推理上下文。UniSpark 提出混合 Mixture-of-Transformers (MoT) 架构，结合全注意力与 GatedDeltaNet 线性注意力，并设计块级可见性掩码与循环状态保留规则，隔离噪声预测目标与干净视觉上下文。该架构在保持理解与生成能力平衡的同时，显著降低了高分辨率图像生成的推理延迟，但其在复杂组合性控制上的表现仍受限于流匹配目标的固有特性。

## 研究背景

当模型试图在单一 Transformer 中同时处理文本序列与图像序列时，视觉 Token 化成为核心瓶颈。离散 Token 化（如 VQ-VAE）虽利于自回归预测，但存在不可逆的信息损失，导致生成图像保真度低；连续潜空间（如 VAE Latents）虽保留高频细节，但难以直接融入自回归序列。混合架构通过在同一骨干中结合自回归语言建模与扩散或流匹配目标，试图兼顾两者优势，但引入了新的计算与信息流挑战。

混合架构的瓶颈在于长序列处理效率与信息流隔离。全注意力机制在处理高分辨率图像时，计算复杂度随序列长度二次方增长，导致推理效率低下。更关键的是，在交错生成任务中，图像生成涉及迭代去噪，中间步骤的噪声状态若被后续文本或图像预测直接读取，会引入瞬态噪声干扰，破坏上下文一致性。现有方法多依赖后训练对齐或复杂的架构解耦来缓解表征冲突，缺乏在注意力机制层面直接隔离噪声目标与干净上下文的系统性方案。UniSpark 切入点在于利用混合注意力机制，在全注意力层实现显式交互，在线性注意力层实现紧凑上下文传播，并通过状态保留规则解决去噪过程中的信息污染问题。

## 核心方法

### 混合 MoT 架构与专家路由

UniSpark 建立在 Mixture-of-Transformers (MoT) 架构之上，该架构通过模态特定的 Transformer 参数分离理解与生成路径，同时共享注意力层以交换上下文。本文采用 Qwen3.5 混合注意力骨干，结合全注意力与 GatedDeltaNet 线性注意力层。文本和语义视觉特征由理解专家处理，而 VAE 潜变量由生成专家处理。这种设计动机在于避免纯共享参数导致的梯度冲突，同时通过共享注意力机制保留模态间的深层知识交互。专家间的信息交换依赖于全注意力层的显式 Token 交互和线性注意力层的持久状态传播，后者以线性复杂度处理长序列，解决了全注意力在高分辨率图像生成中的计算瓶颈。

### 噪声目标与干净上下文的隔离机制

在连续视觉生成中，去噪过程产生的中间状态不能直接作为后续预测的上下文。UniSpark 提出块级可见性掩码与循环状态保留规则，将私有预测目标与公共上下文分离。对于生成侧输入，模型接收噪声潜变量 $z_t$，其表示形式为：

$$
\mathbf{h}_{\text{vis}}^t = A_{\text{in}}(z_t) + E_{\text{time}}(t) + E_{\text{pos}}(p)
$$

其中 $A_{\text{in}}$ 将潜变量投影至骨干宽度，$E_{\text{time}}$ 嵌入噪声水平 $t$，$E_{\text{pos}}$ 编码空间坐标。在全注意力层，块可见性掩码确保噪声块仅读取公共前缀，而对后续块隐藏。在线性注意力层，模型对噪声块进行局部计算后，丢弃其私有状态和卷积历史更新，仅保留干净视觉表示更新公共上下文。这一机制解决了此前方法中噪声状态污染后续推理的问题，确保交错生成任务中上下文的一致性。

### 联合训练目标与数据打包策略

UniSpark 采用自回归文本预测与视觉流匹配（Flow Matching）作为联合训练目标。流匹配目标通过连续时间动态将噪声分布映射至数据分布，避免了离散 Token 化的信息损失。训练数据涵盖视觉理解、图像生成、编辑及交错序列，通过在线打包策略在 Token 预算内组合样本，同时保留样本边界和块结构。全注意力掩码防止跨样本可见性，线性注意力层在样本边界重置循环状态。这种数据组织方式确保了多任务训练中的信息隔离，防止不同任务间的数据泄露，同时最大化了 GPU 利用率。

## 实验评估

UniSpark 在多模态理解、文本到图像生成及指令编辑任务上进行了评估。基线覆盖专用视觉语言模型（如 Qwen2.5-VL）、统一模型（如 BAGEL, SenseNova-U1）及专用生成模型（如 FLUX.1）。在理解任务上，UniSpark 在 MME-S、MMBench 和 MMVP 上取得最高分，表明混合注意力架构在感知与细粒度判别上的优势。在生成任务上，GenEval 得分 0.83，接近 BAGEL 的 0.82，但在组合性控制（计数、位置）上弱于 LLaDA2.0-Uni。

| 任务 | 基准 | UniSpark | BAGEL | SenseNova-U1 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 理解 | MME-S | 2470.3 | - | - | 最高分 |
| 理解 | MMBench | 86.7 | 87.76 | - | 略低于 BAGEL |
| 生成 | GenEval | 0.83 | 0.82 | - | 接近 BAGEL |
| 生成 | DPG-Bench | 80.54 | 85.07 | - | 低于 BAGEL |
| 效率 | 512² 延迟 (s) | 7.27 | 11.76 | 6.43 | 1.62× 加速 |
| 效率 | 1024² 延迟 (s) | 14.16 | 45.80 | 13.86 | 3.23× 加速 |

推理效率测试显示，UniSpark 在 512² 和 1024² 分辨率下，生成延迟较 BAGEL 分别降低 1.62 倍和 3.23 倍，验证了线性注意力在长序列视觉生成中的效率优势。然而，在 2048² 分辨率下，UniSpark 的峰值显存占用（62.74 GB）显著高于 SenseNova-U1（37.39 GB），表明高分辨率下的内存开销仍是瓶颈。评估协议中，ImgEdit 使用 Qwen3-VL 作为评判模型，与基线使用的评判模型不同，导致编辑分数（3.13）无法直接横向比较。

## 关联研究分析

从问题动机看，UniSpark 与 BAGEL 均致力于解决理解与生成的表征冲突，但 BAGEL 依赖纯全注意力机制，在长序列交错生成中面临计算瓶颈。UniSpark 引入 GatedDeltaNet 线性注意力，通过线性复杂度传播上下文，直接回应了推理效率问题。然而，线性注意力在视觉去噪中的状态保留规则是否足以支撑高分辨率细节重建，论文未给出定量分析，仅通过定性示例展示。

从方法设计看，UniSpark 与 Transfusion 均采用混合训练目标，但 Transfusion 未解决交错生成中的噪声污染问题。UniSpark 的块级可见性掩码与状态保留规则，在架构层面实现了噪声目标与干净上下文的隔离，这与领域共识中通过解耦或后训练对齐缓解冲突的路径不同，提供了架构层面的新解法。但这一机制是否足以替代后训练对齐以消除“伪统一”现象，仍需更严格的闭环评估验证。

## 总结

UniSpark 针对统一多模态模型中理解与生成的表征冲突及长序列推理效率瓶颈，提出混合 MoT 架构与噪声-上下文隔离机制。通过结合全注意力与线性注意力，并在注意力层实施块级掩码与状态保留规则，该架构在保持理解能力（MME-S 2470.3）的同时，显著提升了生成效率（1024² 延迟降低 3.23 倍）。然而，其在复杂组合性控制（GenEval 0.83）上仍弱于专用扩散模型，且高分辨率下的显存开销较高。当线性注意力层丢弃噪声块的私有状态时，是否会导致多步去噪过程中的细节信息丢失，进而影响高分辨率图像的重建保真度，论文未提供消融实验予以回答。
