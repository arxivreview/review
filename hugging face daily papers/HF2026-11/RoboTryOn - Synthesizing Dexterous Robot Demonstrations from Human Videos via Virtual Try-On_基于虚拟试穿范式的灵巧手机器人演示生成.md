> 导读 机器人基础模型在通用控制上取得进展，但适配新任务仍依赖高成本的遥操作演示，尤其在高自由度灵巧手中，操作者需协调大量自由度与精细接触。现有利用人类视频的方法通过掩码或叠加渲染缩小视觉差距，却因形态学差异导致动作标签不精确，且部署时需对实时相机流进行同步编辑。RoboTryOn 将人类到机器人的转换视为虚拟试穿，保留运动语义并替换具身形态，通过自回归关键帧生成与视频合成构建高保真机器人视频，并利用逆动力学模型推断动作标签。该范式在无需真实演示的情况下显著提升了策略在未见任务上的成功率，但合成视频中的物理伪影是否导致长时序任务中的误差累积，仍需进一步验证。

## 研究背景

当机器人策略需要适应新任务时，数据采集成本成为主要瓶颈。遥操作虽能获取精确动作标签，但在灵巧手场景中，操作者需通过重定向接口协调多自由度与精细接触，开发难度大且效率低。人类视频提供了互联网规模的替代数据源，记录了人手抓取与操作物体的过程，包含双手协调等复杂行为。然而，人类视频与机器人演示之间存在视觉差距与动作差距：视觉上映射了人类手臂而非机器人本体，动作上人类手部重建不精确且缺乏从人手到机器人关节命令的精确映射，无法反映机器人抓握物体所需的力度。

早期研究通过掩码人类手臂或叠加渲染机器人来缩小视觉差距，但这类方法在训练和部署时均需对相机流应用相同的编辑操作，增加了系统复杂性。在动作层面，直接重定向人类手部姿态无法解决形态学差异导致的控制失配，且无法生成反映接触力度的动作标签。近期生成式方法尝试将人类视频直接翻译为机器人视频，但往往依赖配对监督或仅处理简单夹爪，难以应对高自由度灵巧手的复杂运动。RoboTryOn 针对这一空白，提出在保留运动语义的同时替换具身形态，通过生成式模型直接合成目标域数据，消除测试时编辑需求，并利用逆动力学模型从合成视频中反推动作标签，解决动作差距问题。

## 核心方法

### 方法参照系：从人类视频到机器人演示的转换

在机器人学习中，从人类视频生成机器人演示通常涉及视觉域适应与动作重定向两个环节。传统流程通过图像翻译或渲染叠加缩小视觉差距，并通过运动重定向将人类手部姿态映射为机器人关节命令。RoboTryOn 将这一流程重构为虚拟试穿范式：保留人类视频中的运动轨迹与场景背景，仅替换手臂与手部的具身形态。该范式的关键差异在于，它不依赖显式的物理仿真器或精确的形态学映射，而是通过生成式模型学习从人类运动到机器人运动的分布转换，并通过逆动力学模型从生成的视频中推断动作标签，从而绕过重定向的精度瓶颈。

### 自回归关键帧翻译与视频合成

RoboTryOn 首先从人类视频的手腕轨迹中选择关键帧，当双手速度达到局部最小值且手腕移动超过阈值时选取，确保手部清晰且运动显著。图像生成模型 $f_\theta$ 将人类关键帧翻译为机器人关键帧，其核心创新在于将翻译过程建模为受参考图像引导的修复任务。模型填充掩码区域 $M_t$，生成由骨架 $S_t$ 指定姿态的目标机器人，并利用同一片段中较早时刻的参考帧 $o_{t'}$ 确定具身、物体和背景的外观。训练目标采用流匹配损失：

$$ L_{img}(\theta) = \mathbb{E}_{(o_t, o_{t'}) \sim D, \epsilon, \tau} \left[ \| f_\theta(z_\tau, \tau | \tilde{o}_t, M_t, o_{t'}) - (z - \epsilon) \|^2 \right] $$

其中 $z = E_{img}(o_t)$ 为图像编码，$\tilde{o}_t$ 为条件帧。推理时，模型按时间顺序自回归地翻译关键帧，每个关键帧以前一个翻译后的机器人关键帧为条件，从而保持视觉一致性。随后，视频生成模型 $g_\phi$ 在关键帧之间合成运动，以人类手部骨架流 $S_{1:T}$ 为引导，确保生成的机器人视频在运动上忠实于人类演示。

### 基于逆动力学模型的动作标签推断

为解决动作差距，RoboTryOn 不直接从重建的人类手部姿态推导机器人动作，而是利用逆动力学模型（Inverse Dynamics Model, IDM）$h_\psi$ 从合成的机器人视频中推断动作标签。IDM 以合成视频中相隔 $K$ 步的两个观测为输入，预测两者之间的关节空间动作块。训练时，IDM 使用遥操作机器人演示中的真实动作作为目标：

$$ L_{idm}(\psi) = \mathbb{E}_{(o_t, o_{t+K}, a_{t:t+K}) \sim D, \epsilon, \tau} \left[ \| h_\psi(a_{t:t+K}^\tau, \tau | o_t, o_{t+K}) - (a_{t:t+K} - \epsilon) \|^2 \right] $$

推理时，IDM 对合成视频进行标注，生成动作标签 $\hat{a}_{t:t+K}$。由于 IDM 对手腕位置的估计精度低于手部重建，RoboTryOn 使用逆运动学校正动作标签中的手腕位置，同时保留 IDM 预测的手部关节。这一设计使得动作标签不仅反映手部形状，还隐含了机器人抓握物体所需的力度与接触模式，优于仅基于几何重定向的动作标签。

## 实验评估

实验在 OpenArm 和 RB-Y1 两种双臂机器人上评估，包含 4 个域内任务（有遥操作演示）和 7 个域外任务（仅有人类视频，包括新物体、新目标、新技能及双手任务）。基线包括 EgoMimic（掩码人类手臂）和 Masquerade（叠加渲染机器人）。主结果显示，RoboTryOn 在域外任务上显著超越基线。在 OpenArm 上，RoboTryOn 将域外平均成功率从基线的 5.1% 和 8.2% 提升至 73.0%；在 RB-Y1 上，从 5.1% 和 7.7% 提升至 46.9%。即使在无遥操作演示的情况下，仅使用合成数据训练的策略在 OpenArm 上仍达到 48.5% 的域外成功率。

| 方法 | 机器人 | 域内成功率 (%) | 域外平均成功率 (%) |
| :--- | :--- | :--- | :--- |
| Teleop only | OpenArm | 47.3 | 3.1 |
| + EgoMimic | OpenArm | 50.0 | 5.1 |
| + Masquerade | OpenArm | 67.9 | 8.2 |
| + RoboTryOn | OpenArm | 75.9 | 73.0 |
| RoboTryOn (Ours) | OpenArm | 57.1 | 48.5 |
| Teleop only | RB-Y1 | 69.6 | 1.0 |
| + EgoMimic | RB-Y1 | 63.4 | 5.1 |
| + Masquerade | RB-Y1 | 63.4 | 7.7 |
| + RoboTryOn | RB-Y1 | 79.5 | 46.9 |
| RoboTryOn (Ours) | RB-Y1 | 60.7 | 40.3 |

消融实验验证了 IDM 动作标签的有效性。在模拟环境中开环重放动作标签，RoboTryOn 生成的标签在 69.7% 的片段中成功完成任务，而重定向标签仅为 34.8%。差异主要源于抓握阶段：重定向动作使机器人手接近物体，但因手部重建不精确和几何差异无法稳固抓握。此外，RoboTryOn 在 RLDX-1-Img 策略骨干上同样有效，域外成功率从 0.0% 提升至 40.3%，表明其收益不依赖于特定策略架构。

评估边界方面，实验未报告置信区间，且基线评估遵循各自协议，可能存在实现细节差异。合成视频中的物理伪影是否导致长时序任务中的误差累积，论文未进行长时序稳定性测试。代码未开源，复现需依赖论文描述的模型架构与训练细节。

## 关联研究分析

从问题动机看，RoboTryOn 与 EgoMimic 和 Masquerade 均旨在利用人类视频数据，但处理视觉与动作差距的方式根本不同。EgoMimic 通过掩码人类手臂保留背景，Masquerade 通过叠加渲染机器人缩小视觉差距，两者均依赖测试时对实时相机流的同步编辑，且动作标签通过重定向生成。RoboTryOn 通过生成式模型直接合成目标域视频，消除了测试时编辑需求，并通过 IDM 从视频中反推动作标签，解决了重定向无法捕捉接触力度的问题。这一差异源于对“具身转换”本质的理解：前者视为图像编辑问题，后者视为分布转换问题。

从方法设计看，RoboTryOn 与 DexNDM 在灵巧手动力学建模上形成互补。DexNDM 通过显式建模每个关节的动力学差异来缩小现实差距，属于物理参数辨识路线；RoboTryOn 通过 IDM 隐式学习从视觉观测到动作的映射，属于数据驱动路线。DexNDM 依赖精确的关节级动力学模型，适用于接触丰富任务；RoboTryOn 依赖大规模生成式模型，适用于视觉多样性丰富的场景。两者在接触建模精度与数据泛化能力之间做出了不同取舍，RoboTryOn 未显式建模物理接触，其动作标签的物理一致性依赖于 IDM 在遥操作数据上的训练分布。

## 总结

RoboTryOn 针对灵巧手机器人数据稀缺问题，提出将人类视频转换为机器人演示的虚拟试穿范式。现有方法因掩码或叠加渲染导致测试时编辑负担，且重定向动作无法反映接触力度。RoboTryOn 通过自回归关键帧翻译与视频合成生成高保真机器人视频，并利用 IDM 推断动作标签，在 OpenArm 上将域外任务成功率从 3.1% 提升至 73.0%。该方法的边界在于 IDM 动作标签的物理一致性依赖于训练分布，且合成视频中的物理伪影可能影响长时序任务。当任务涉及复杂动态接触或长时序依赖时，IDM 生成的动作标签是否仍能保持物理可行性，论文未给出回答。
