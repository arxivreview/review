# HuggingFace最新推荐论文 ｜Modality-Aware Expert Pruning for MoE-Based Multimodal Large Language Models ｜模态感知专家剪枝

作者：Donggeun Kim

论文原文见 [arXiv](https://arxiv.org/abs/2611.05927)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2611.05927)

> 稀疏混合专家（Sparse Mixture-of-Experts, SMoE）架构在提升模型容量的同时，其庞大的专家参数驻留显存构成了部署瓶颈。现有压缩方法在聚合专家重要性时，通常对所有输入 Token 进行统一统计，忽略了多模态大语言模型（Multimodal Large Language Models, MLLMs）中视觉与文本 Token 对专家贡献的显著差异。MAEP 提出了一种免训练的模态感知专家剪枝框架，通过计算移除专家后的输出扰动（Delta-H Output, $\Delta H$），并将文本侧信号作为保留依据、低注意力视觉侧信号作为剪枝依据，实现跨层全局专家剔除。该工作有效缓解了多模态 MoE 的显存压力，但其依赖特定注意力分布的剪枝信号在跨架构场景下的普适性仍存疑。

## 研究背景

当多模态大语言模型引入稀疏混合专家架构以扩展参数规模时，其核心矛盾从计算量转移至内存占用。尽管每个 Token 仅激活少量专家，但所有专家权重必须常驻显存。在 InternVL3.5-30B-A3B 等模型中，专家参数占据总模型体积的 93–94%（约 54 GB / 58 GB），导致显存墙成为部署的首要障碍。为缓解此问题，后训练压缩技术（如剪枝、合并）被引入，其核心在于评估专家重要性以剔除冗余部分。然而，传统重要性评估多基于路由频率或激活范数，隐含假设所有 Token 对专家贡献的权重均等。

在多模态场景下，这一假设失效。视觉 Token 存在高度冗余，且文本与视觉 Token 在专家层中的分布存在显著差异。若统一聚合重要性，高频但低价值的视觉 Token 会掩盖关键文本 Token 的贡献，导致剪枝偏差。现有 MoE-MLLM 效率方法多聚焦于推理时的动态跳过或视觉 Token 裁剪，未能从根本上减少常驻显存的专家参数。MAEP 针对这一被忽略的“永久剪枝”需求，提出模态分解的重要性度量，旨在通过区分文本与视觉侧的专家角色，实现更精准的冗余识别与显存释放。

## 核心方法

### 方法参照系：基于输出扰动的专家重要性评估

在 MoE 压缩的标准流程中，专家重要性评估通常依赖于路由统计或激活范数。MAEP 将问题置于“基于反事实推理的专家重要性评估”框架下，其关键差异在于：传统方法评估专家在正常路由下的贡献，而 MAEP 评估移除专家并重新分配路由权重后，MoE 层输出的变化量。这一转变将重要性定义从“绝对贡献”转化为“功能冗余度”，即输出变化越小，说明剩余专家能更好地承接该专家的功能，该专家越适合被剪枝。

### 核心创新：Delta-H Output 度量与模态分解

MAEP 的核心创新在于定义了 Delta-H Output ($\Delta H$) 作为专家重要性指标，并对其进行模态分解。$\Delta H$ 衡量的是当专家 $j$ 被移除且路由权重重新归一化后，MoE 层隐藏状态输出的平方 L2 范数变化：

$$
\Delta H^{(l,j)} = \mathbb{E}_{x \sim D} \left[ \frac{1}{|x|} \sum_{h \in x} \| H_{\text{MoE}}^{(l)}(h) - H_{\text{MoE}}^{(l,-j)}(h) \|_2^2 \right]
$$

该公式的物理含义是：在给定校准集 $D$ 上，移除专家 $j$ 后，MoE 层输出 $H_{\text{MoE}}$ 的平均扰动程度。设计动机在于，直接计算输出分布的 KL 散度需多次前向传播，计算成本高昂；而 $\Delta H$ 仅需单次前向传播即可通过缓存的专家输出解析计算，且理论上与 KL 散度存在上界关系，适合作为层内排序的代理指标。

### 核心创新：非对称模态信号组合与全局剪枝

MAEP 进一步发现，文本与视觉 Token 对 $\Delta H$ 的贡献具有非对称性。文本侧 $\Delta H$ 高表示专家对语言处理至关重要，应作为“保留信号”；而视觉侧若使用低注意力 Token（即文本对视觉注意力最低的 Token）计算 $\Delta H$，高值表示专家过度处理非显著背景信息，应作为“剪枝信号”。最终得分 $s(l, j)$ 通过非对称组合实现：

$$
s(l, j) = (1 - \alpha) \cdot \tilde{z}_{\text{text}}^{(l,j)} - \alpha \cdot \tilde{z}_{\text{la}}^{(l,j)}
$$

其中 $\tilde{z}$ 为经对数变换和层内 Z-score 标准化后的 $\Delta H$ 值，$\alpha$ 为模态平衡系数。设计动机在于，传统统一聚合会混淆文本保留与视觉剪枝的需求。通过引入低注意力视觉信号，MAEP 避免了高注意力视觉 Token 带来的数据集敏感性，确保了剪枝信号的稳定性。最终，所有层的专家按 $s(l, j)$ 全局排序，剔除得分最低的专家，实现跨层非均匀剪枝。

## 实验评估

实验在 InternVL3.5-30B-A3B、Qwen3-VL-30B-A3B 和 Gemma4-26B-A4B 三个 MoE-MLLM 上进行，对比了基于合并的 HC-SMoE 和基于激活范数剪枝的 REAP。评估涵盖 ChartQA、TextVQA 等多模态基准及 MMLU-Redux 等文本基准。

| 模型 | 剪枝率 | 方法 | MME | ChartQA | TextVQA | Avg. (%) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| InternVL3.5 | 50% | Original | 2442.2 | 87.3 | 80.2 | 100.0 |
| | | HC-SMoE | 1907.5 | 75.3 | 66.5 | 53.2 |
| | | REAP | 2109.6 | 65.3 | 74.4 | 85.7 |
| | | **MAEP** | **2160.3** | **76.7** | **75.6** | **90.6** |
| Qwen3-VL | 50% | Original | 2416.6 | 85.3 | 84.6 | 100.0 |
| | | HC-SMoE | 1923.9 | 74.3 | 76.1 | 74.8 |
| | | REAP | 2026.6 | 67.1 | 78.1 | 86.6 |
| | | **MAEP** | **2042.8** | **69.6** | **79.7** | **88.3** |

在 50% 剪枝率下，MAEP 在 InternVL3.5 上的平均保留率为 90.6%，显著高于 REAP 的 85.7% 和 HC-SMoE 的 53.2%。在 Qwen3-VL 上，MAEP 同样保持最高平均保留率（88.3%）。消融实验表明，移除模态分解会导致 ChartQA 和 TextVQA 性能大幅下降，证实了非对称信号组合的必要性。此外，使用高注意力视觉 Token 替代低注意力信号会导致跨数据集排名不稳定，进一步验证了低注意力信号在剪枝任务中的鲁棒性。

评估边界方面，MAEP 在纯文本基准（如 MMLU-Redux）上的性能保持率略低于部分基线，提示视觉侧剪枝信号可能对纯文本能力产生轻微干扰。此外，实验未覆盖量化或低秩分解等互补压缩技术，无法评估 MAEP 与这些方法叠加后的极限压缩率。

## 关联研究分析

从问题动机看，MAEP 与 MoDES 均关注模态依赖的专家效率，但路线截然不同。MoDES 侧重于推理时动态跳过专家以降低计算量，专家参数仍驻留显存；MAEP 则致力于永久剪枝以释放显存。这一差异源于对部署瓶颈的不同判断：MoDES 假设显存充足但算力受限，MAEP 假设显存受限。在显存受限场景下，MAEP 的永久剪枝策略更具针对性，但其免训练特性限制了进一步微调恢复性能的可能。

从方法设计看，MAEP 与 REAP 同属基于激活的剪枝，但 REAP 使用路由加权激活范数，隐含假设所有 Token 对专家贡献均等。MAEP 指出这一假设在多模态下失效，因为视觉 Token 的冗余性会稀释文本 Token 的重要性信号。MAEP 通过引入低注意力视觉 Token 作为剪枝信号，修正了 REAP 的偏差。然而，低注意力信号是否仅适用于当前模型架构，还是具有跨架构的普适性，论文未给出跨架构的广泛验证。

## 总结

MAEP 针对 MoE-MLLM 中专家参数显存占用过高且传统剪枝忽略模态差异的问题，提出了基于 Delta-H Output 的模态感知剪枝框架。通过区分文本保留信号与低注意力视觉剪枝信号，MAEP 在 50% 剪枝率下实现了 InternVL3.5 90.6% 的平均性能保留率，显著优于模态无关基线。该方法的边界在于其依赖特定的注意力分布假设，且未探索与量化等技术的协同效应。当模型架构从共享专家池转向模态隔离专家池时，低注意力视觉信号是否仍能有效指示冗余专家，论文未给出回答。
