# HuggingFace最新推荐论文 ｜Cross-Prompt Reuse of Entity-Replacement Responses ｜跨提示实体替换响应的保真度与选择性解耦

作者：Jinkun Chen、Xuemin Yu、Sijia Han 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2611.00352)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2611.00352)

> 导读 大语言模型（Large Language Models, LLMs）在跨提示复用中，常通过激活向量或函数向量传递信息，但现有研究多关注答案是否改变，缺乏对响应保真度的量化。传统干预方法如RAVEL仅验证实体表示互换的有效性，未区分共享偏移与关系选择性偏移，导致无法评估模型是否真正复现了特定关系的推理逻辑。本文引入实体替换作为参考系，通过对比源问题与目标问题的隐藏状态变化，量化跨提示响应的复现程度。该研究揭示了LLM在零样本关系抽取中，主要复现共享偏移而难以可靠复现关系选择性偏移的机制局限，为理解模型内部关系绑定机制提供了新的干预式分析视角。

## 研究背景

当LLM处理涉及同一实体不同属性的问题时，模型内部存在一种机制，使得在某一问题中记录的激活变化可以迁移至另一问题。这种跨提示复用（Cross-Prompt Reuse）通常通过函数向量（Function Vectors）或激活添加（Activation Addition）实现，其核心假设是模型在中间层编码了可迁移的语义状态。然而，仅观察最终答案的变化无法揭示复现的保真度：模型可能仅复现了与实体相关的通用偏移，而非特定于当前问题关系的推理路径。为了量化这一差异，需要引入一个可测量的参考系，即实体替换（Entity Replacement），通过比较替换实体后的实际响应与迁移响应，分离出共享分量与关系选择性分量。

在零样本关系抽取（Zero-Shot Relation Extraction, ZSRE）领域，LLM的泛化能力依赖于其对关系语义的理解。现有机制可解释性研究多聚焦于静态神经元激活或线性探针，如RelSpec Neurons识别关系特定神经元，或Cell-Based Binding分析低维子空间中的绑定信息。这些方法虽揭示了关系知识的局部化存储，但缺乏动态干预下的保真度评估。本文针对这一盲区，提出通过动态注入隐藏状态变化，量化跨提示响应的复现程度，从而揭示LLM在关系绑定机制上的具体局限。

## 核心方法

### 方法参照系：跨提示状态复用

本文的方法置于跨提示状态复用（Cross-Prompt State Reuse）的通用框架下。该框架通常涉及从源提示（Source Prompt）提取隐藏状态变化，并将其注入目标提示（Target Prompt）。标准流程包括：计算源提示在原始实体与替换实体间的隐藏状态差异，通过某种对齐机制（如后缀插值）映射到目标提示，并在特定深度注入。本文的关键差异在于引入“实体替换响应”作为参考系，不仅评估答案是否改变，更量化响应中共享偏移与关系选择性偏移的复现比例。

### 核心创新：隐藏复用与直接复用的对比

在标准复用流程中，通常直接添加源提示的输出变化或隐藏状态变化。本文提出两种复用路径：隐藏复用（Hidden Reuse）与直接复用（Direct Reuse）。隐藏复用将源提示在50%深度处的对齐隐藏状态变化 $\Delta_{s,e}$ 添加至目标提示的未编辑状态，随后运行目标提示的剩余层；直接复用则直接添加源提示的输出分数变化。

$$
\Delta_{s,e} = H_\ell(s, e) - H_\ell(s, a)
$$

该公式定义了源提示 $s$ 在原始实体 $a$ 与替换实体 $e$ 之间的隐藏状态变化。隐藏复用的设计动机在于，它允许目标提示自身的计算层（Read-out）对注入的变化进行解释，从而可能复现目标问题特有的关系选择性偏移；而直接复用则强制源提示的读出机制主导输出，可能仅复现共享偏移。通过对比两者，本文量化了目标提示自身计算在关系绑定中的作用。

### 核心创新：共享与选择性分量的解耦

为量化复现的保真度，本文定义答案对比（Answer Contrast）$c_x$ 为目标关系答案组 $A_T$ 与其他关系答案组 $A_O$ 的对数概率质量之差。实体替换引起的对比变化 $\delta c$ 可分解为共享分量 $h$ 与关系选择性分量 $s$：

$$
s = \frac{\delta c_1 + \delta c_2}{2}, \quad h = \frac{\delta c_1 - \delta c_2}{2}
$$

其中 $\delta c_1$ 和 $\delta c_2$ 分别为两个关系互换问题中的对比变化。该分解的设计动机在于，传统评估仅关注整体误差降低，无法区分模型是复现了实体相关的通用偏移（$h$）还是特定关系的推理逻辑（$s$）。通过分别计算选择性误差 $|\hat{s} - s|$ 和共享误差 $|\hat{h} - h|$，本文揭示了隐藏复用主要复现共享偏移，而在小模型上难以可靠降低选择性误差的机制局限。

## 实验评估

实验基于ZsRE数据集，使用Qwen、Llama和Gemma系列模型，在35个原始块及两个新实体块上进行评估。基线包括零预测（Zero Prediction）、不同替换复用（Different-Replacement Reuse）及直接复用。本文未对比检索增强生成（RAG）或提示优化（APO）等性能导向方法，因研究重点在于机制分析而非SOTA性能提升。

| 模型 | 格式 | 隐藏复用误差消除率 (%) | 直接复用误差消除率 (%) | 选择性误差降低 (%) |
| :--- | :--- | :--- | :--- | :--- |
| Qwen 0.5B | Plain | 45 | - | - |
| Llama 1B | Plain | 49 | - | - |
| Gemma 2B | Plain | 22 | - | - |
| Gemma 2B | +BOS | 58-69 | - | - |
| Qwen 7B | Plain | 51 | - | - |
| Llama 8B | Plain | 46 | - | - |

*注：数据取自Table 2，Plain格式下隐藏复用误差消除率。选择性误差降低数据在Table 24中描述，小模型Plain格式下未可靠降低。*

消融实验显示，在50%深度注入时，隐藏复用优于直接复用，但优势在目标关系源（Target-Relation Sources）下缩小至0.2-0.9 nats。深度扫描表明，注入深度超过50%后，误差消除率下降，提示中间层是关系绑定的关键区域。此外，恢复BOS token显著提升了Gemma模型的性能，从22%提升至58-69%，表明输入格式对机制复现有显著影响。

评估边界方面，本文未提供代码开源，且实验局限于英语事实性问题。指标上，使用误差消除比例而非F1，与领域主流评估协议存在差异，导致无法直接与RE-GAR-AD等SOTA方法比较。可复现性依赖于确定性CPU运行，但不同模型对BOS token的敏感性增加了复现难度。

## 关联研究分析

从问题动机看，本文与RAVEL（Huang et al., 2024）均关注实体表示的跨提示转移，但RAVEL仅验证互换后答案的一致性，未量化复现保真度。本文通过实体替换参考系，揭示了RAVEL未触及的共享偏移与选择性偏移的解耦问题，指出实体表示转移可能仅复现共享偏移，而非完整的关系推理逻辑。

从方法设计看，本文与Cell-Based Binding（2026）均研究关系绑定，但Cell-Based Binding通过静态探针分析低维子空间，而本文通过动态干预验证绑定的可迁移性。本文发现，即使存在可解释的绑定机制，跨提示复用仍难以可靠复现关系选择性偏移，这暗示静态绑定结构可能不足以支持动态推理迁移。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文针对LLM跨提示复用中响应保真度不可量化的问题，引入实体替换参考系，通过隐藏复用与直接复用的对比，解耦了共享偏移与关系选择性偏移。实验表明，隐藏复用在Qwen和Llama上可消除45-49%的无变化误差，但在小模型上主要复现共享偏移，选择性误差降低不显著。该研究揭示了LLM关系绑定机制在跨提示迁移中的局限，即模型可能依赖实体通用偏移而非特定关系推理。当模型规模增大或输入格式改变时，这种选择性复用的瓶颈是否依然存在，论文未给出回答。
