> 扩散语言模型（Diffusion Language Models, DLMs）在复杂推理任务中面临并行解码导致的错误固化问题，其核心瓶颈在于现有解码策略过度依赖瞬时置信度，导致模型在局部高置信度下锁定错误的推理路径。传统方法通过增加采样次数或统一调整解码策略来缓解这一问题，但未能解决“虚假置信度”引发的样本收敛偏差。本文提出一种两阶段自适应测试时扩展框架，将计算资源与解码策略的分配形式化为优化问题，并引入频率感知重掩码机制。该机制通过追踪去噪轨迹中 token 预测的变化频率，优先提交高频变化位置以强制样本在关键决策点分叉。这一方法在不增加训练成本的前提下显著提升了难例恢复能力，但其有效性高度依赖于正确性预言机（Oracle）的准确性，且对超参数敏感。

## 研究背景

当扩散语言模型面对多步算术或逻辑推理任务时，其迭代去噪过程需要决定哪些 token 应当被固定（commit），哪些应当保持掩码状态（remask）以接受后续修正。现有的主流解码策略，如 LLaDA 采用的低置信度重掩码或 Dream 采用的熵基重掩码，均基于模型在当前去噪步骤的瞬时预测分布来评估 token 的确定性。这种机制隐含了一个假设：局部的高置信度等同于全局的正确性。然而，在复杂推理中，模型可能生成一个局部连贯但全局错误的推理轨迹，此时模型对错误 token 表现出极高的瞬时置信度，这种现象被称为“虚假置信度”（False Confidence）。

虚假置信度导致了一个严重的结构性缺陷：当使用基于置信度的解码器进行多次采样时，模型倾向于在早期步骤就锁定相同的错误推理路径，导致不同样本最终收敛于同一个错误答案。单纯增加采样次数（即测试时扩展的宽度轴）无法打破这种收敛，因为所有样本都受到相同的局部置信度偏差引导。现有的测试时扩展研究多集中于增加采样数或优化去噪步数，而忽视了“解码策略”这一维度。本文指出，测试时扩展应被视为计算资源与解码策略的自适应分配问题，即对于简单问题使用快速策略，对于陷入虚假置信度的难例问题，则需切换至能够打破路径依赖的解码策略。

## 核心方法

### 方法参照系：测试时扩展的自适应分配

本文首先将 DLM 的测试时扩展形式化为一个约束优化问题。给定问题集 $S$ 和总计算预算 $B$，目标是为每个问题 $x_i$ 分配计算量 $c_i$ 和解码策略 $\pi_i$，以最大化任务性能。这与传统的仅优化采样数量或去噪步数的方法不同，本文引入了策略集合 $\Pi$，允许在不同问题间动态切换解码行为。该框架的核心在于识别哪些问题是“难例”，即那些在基础快速采样器下无法通过增加样本数解决的问题，并将额外的计算资源专门分配给这些问题的策略切换。

### 频率感知重掩码与 SAFE 机制

针对虚假置信度导致的样本收敛问题，本文提出了频率感知重掩码（Frequency-Aware Remasking）。传统方法优先提交模型认为最确定的 token，而该机制反其道而行之：优先提交那些在去噪轨迹中预测变化频率最高的 token。其设计动机在于，高频变化表明模型在该位置尚未形成稳定共识，此时强制提交可以迫使不同样本在这些“未决”位置做出不同选择，从而探索不同的推理路径，避免所有样本坍缩至同一错误轨迹。

为了量化这种变化，本文定义了变化频率 $f_i^{(t)}$，表示位置 $i$ 在第 $t$ 步之前预测值发生改变的次数与总观测次数的比值：

$$
f_i^{(t)} = \frac{\sum_{j=1}^{N_i^{(t)}} \mathbb{1}[\hat{x}_{i,j} \neq \hat{x}_{i,j-1}]}{\max(N_i^{(t)}, 1)}
$$

其中 $\hat{x}_{i,j}$ 是位置 $i$ 的第 $j$ 次预测，$\hat{x}_{i,0}$ 初始化为掩码 token。该公式的物理含义是：频率越高，说明模型在该位置的预测越不稳定，越需要被优先“锁定”以打破僵局。

为了从频率分布中自适应地选择提交组，本文提出了支持感知频率选择（Support-Aware Frequency Selection, SAFE）机制。SAFE 不依赖固定阈值，而是通过寻找频率值分布中的最大间隙（Gap）来划分高频组。设当前活跃位置的频率值为 $u_1^{(t)} < \dots < u_m^{(t)}$，SAFE 选择使得相邻频率间隙 $u_{j+1}^{(t)} - u_j^{(t)}$ 最大的分割点 $j^*$，并将频率高于 $u_{j^*}^{(t)}$ 的位置作为候选提交组 $H_t$。这一设计解决了固定阈值在不同任务或去噪阶段泛化性差的问题，确保仅在频率分布存在显著分离时才执行策略覆盖。

### 两阶段自适应测试时扩展

频率感知重掩码被集成到一个两阶段算法中。第一阶段使用基础采样器（如置信度阈值策略）快速解决简单问题，一旦正确性预言机（Oracle）判定答案正确，该问题即从活跃集中移除。第二阶段仅对第一阶段未解决的问题应用频率感知采样器。这种设计避免了在所有问题上使用昂贵的频率感知策略，实现了效率与鲁棒性的平衡。频率感知采样器在每个块的预热阶段（Warm-up）仍使用不确定性感知规则收集频率统计，随后在剩余步骤中应用 SAFE 机制。

## 实验评估

本文在 LLaDA-8B-Instruct 和 Dream-7B-Instruct 两个骨干模型上，针对 GSM8K、MATH-500 和 HumanEval 基准进行了评估。实验采用 Coverage@k 和 Oracle Accuracy 作为主要指标，其中 Oracle 由 Gemini-2.5-Flash-Lite 担任。基线对比涵盖了标准的置信度阈值解码和熵基解码。

| 模型 | 基准 | 指标 | 基础策略 | 本文方法 (两阶段) | 绝对提升 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| LLaDA-8B | MATH-500 | Accuracy | - | - | +3.73% |
| Dream-7B | MATH-500 | Accuracy | - | - | +7.33% |
| LLaDA-8B | HumanEval | Coverage | - | - | +11.39% |
| Dream-7B | HumanEval | Coverage | - | - | +10.98% |

*注：表中绝对提升数据直接取自论文摘要及正文描述，基础策略具体数值未在提供的实验数据区逐字列出，故仅展示提升幅度。*

实验结果显示，频率感知重掩码在难例恢复上表现显著。对于基础策略在 100 次采样后仍未解决的 GSM8K 问题，本文方法成功恢复了 3.75% 至 18.75% 的样本。这一发现验证了虚假置信度假设：即难例的失败并非随机噪声，而是系统性的路径锁定，通过改变提交顺序可以有效打破这种锁定。然而，实验未提供与强化学习对齐方法（如 SPG、TraceRL）的直接对比，且 Oracle 的引入使得评估结果依赖于外部判断模型的准确性，这可能高估了模型自身的内在推理能力。

## 关联研究分析

从解码策略的演进来看，本文与 Self-Reflective Remasking 存在显著差异。Self-Reflective Remasking 依赖模型自身的置信度分数来识别并重新掩码错误 token，本质上仍是在瞬时置信度框架内的修补。而本文指出瞬时置信度在虚假置信度场景下失效，转而引入轨迹级的频率信号。这种从“瞬时状态”到“历史轨迹”的视角转换，是本文区别于现有重掩码方法的核心。然而，频率信号的计算依赖于多次去噪步骤的累积，这是否会在长序列生成中引入过高的计算开销，论文未给出详细的复杂度分析。

从测试时扩展的范式来看，本文与 SPG（Sandwich Policy Gradient）代表了两种不同的提升推理能力的路径。SPG 通过强化学习在训练阶段优化策略梯度，旨在从根本上提升模型的推理分布；而本文完全在推理阶段通过算法调度来弥补模型分布的缺陷。这两种方法在理论上是互补的：SPG 提升了基础模型的上限，而本文的自适应分配提升了现有模型在难例上的下限。但本文未探讨在已经经过 RL 对齐的模型上，频率感知重掩码是否仍有增益，这限制了对其通用性的判断。

## 总结

本文针对扩散语言模型在复杂推理中因虚假置信度导致的错误固化问题，提出了一种基于频率感知重掩码的两阶段测试时扩展方法。通过追踪去噪轨迹中的预测变化频率并优先提交高频变化 token，该方法强制样本在模型未决位置分叉，从而打破错误路径的收敛。实验表明，该方法在 MATH-500 和 HumanEval 上分别实现了最高 7.33% 和 11.39% 的绝对性能提升，并有效恢复了部分基础策略无法解决的难例。然而，该方法的有效性高度依赖于正确性预言机的准确判断，且频率统计的累积可能带来额外的推理延迟。当模型在早期步骤就陷入全局性错误而非局部未决状态时，频率信号是否仍能区分出有效的分叉点，论文未给出回答。
