> 智能体在长期交互中需从海量个人记录中检索上下文，但不同用户的历史数据在内容、模态和组织结构上差异显著，导致单一记忆设计难以普适。现有自动优化方法依赖显式任务成败信号，而个人记录通常缺乏此类反馈，人工标注问答对成本高昂。MemSteer 通过从历史中合成问答-证据监督信号，结合证据锚定答案规划与盲恢复验证，驱动记忆存储、检索及上下文构建的迭代优化。该框架在 ATM-Bench 和 RHELM 上验证了合成监督接近人工标注的效果，但合成数据与真实查询分布的偏差风险仍需警惕。

## 研究背景

当智能体处理跨会话任务时，其性能高度依赖于外部记忆系统对历史信息的组织与检索效率。这一过程涉及存储粒度、检索策略及上下文构建三个核心环节。然而，用户历史数据的异质性意味着针对某一用户优化的记忆架构，在另一用户上可能失效。为了适应这种差异，研究者开始探索自动记忆设计优化，即通过算法自动调整记忆系统的内部配置。

主流自动优化方法如 MemEvolve 和 M* 依赖下游任务的执行结果作为反馈信号。然而，在个人助理等场景中，用户记录往往缺乏明确的成功或失败标签，导致优化过程缺乏监督。虽然合成问答数据可用于训练检索器，但直接生成的问答对常因缺乏证据支持而误导设计选择。MemSteer 针对这一反馈缺失问题，提出从历史中自动生成带有证据锚定的问答监督，以此替代人工标注，实现记忆架构的自适应优化。

## 核心方法

### 方法参照系：记忆设计优化流程

在记忆设计优化中，系统通常将历史记录 $H$ 存储为记忆 $M_d$，针对查询 $q$ 检索并组装上下文 $X_d$，最终生成回答 $\hat{a}_d$。设计 $d$ 由存储策略 $s$、检索策略 $r$ 和上下文构建策略 $c$ 组成。标准优化流程通过评估回答准确率 $A(d)$ 来迭代更新设计。本文的关键差异在于，它不依赖真实任务反馈，而是利用从历史中合成的问答-证据对 $D_H = \{(q_i, a_i, E_i)\}$ 作为代理监督信号，其中 $E_i$ 为支持答案的证据记录集合。

### 证据锚定答案规划与合成监督构建

传统合成问答方法直接生成问题和答案，易产生幻觉或证据不匹配。MemSteer 引入证据锚定答案规划，首先从历史图中采样相关记录形成材料包 $B$，然后由 LLM 规划器构建答案计划，明确事实如何跨记录支持参考答案。

$$
\text{Plan}(B) \rightarrow \{ \text{facts } f_j \text{ with spans } [r_k:s_l], \text{ operations} \}
$$

该公式表示答案计划不仅包含事实，还包含事实的来源跨度及组合操作。随后，基于该计划生成独立问题。为确保质量，系统执行源锚定审计和盲恢复验证：盲恢复要求 LLM 仅基于问题和源记录恢复答案，只有当恢复答案与参考答案完全匹配且引用覆盖所有证据记录时，该问答对才被保留。这一机制解决了合成数据噪声大、证据链断裂的问题，为后续优化提供了高置信度的监督信号。

### 证据引导的失败诊断与设计迭代

获得监督信号后，MemSteer-Opt 通过证据引导的诊断机制优化设计。对于错误回答，系统检查证据是否缺失：若证据在上下文中缺失且无法从记忆中恢复，判定为存储失败；若可恢复但未检索到，判定为检索失败；若证据存在但回答错误，判定为回答失败。

$$
\text{Diagnosis}(\hat{a}_d, a, E) \rightarrow \begin{cases} \text{Storage Failure} & \text{if } E \not\subseteq M_d \\ \text{Retrieval Failure} & \text{if } E \subseteq M_d \land E \not\subseteq X_d \\ \text{Answering Failure} & \text{if } E \subseteq X_d \end{cases}
$$

该诊断逻辑将失败归因于记忆系统的具体环节。基于分层采样的失败案例，LLM 设计提议者提出针对性的存储、检索或上下文构建修改方案。新设计仅在验证集准确率 $A(d') > A(d)$ 时被接受。这种细粒度的反馈机制避免了盲目搜索，显著提升了优化效率。

## 实验评估

实验在 ATM-Bench（多模态个人记忆问答）和 RHELM（多角色交互记录）上进行。基线包括 RAG、MemGPT、Mem0 及现有优化器 M* 和 MemEvolve。评估指标为问题得分（QS）和证据召回率（R@10）。

| 方法 | ATM-Bench QS (%) | ATM-Bench R@10 (%) | RHELM Acc (w/o) (%) | RHELM Acc (w/) (%) |
| :--- | :---: | :---: | :---: | :---: |
| Base-BM25 | 54.9 | 61.7 | 22.3 | 33.3 |
| + Official-QA | 67.3 | 83.5 | 26.5 | 40.7 |
| + MemSteer | 68.3 | 84.1 | 26.4 | 39.9 |
| M* + MemSteer | 53.4 | 69.8 | - | - |
| MemEvolve + MemSteer | 53.7 | 63.7 | - | - |

MemSteer 生成的监督信号在 ATM-Bench 上使 QS 提升 13.4 点，接近人工标注的 Official-QA（67.3% vs 68.3%）。在 RHELM 上，MemSteer 优化后的准确率在无外部数据时提升 4.1 点，有外部数据时提升 6.6 点。值得注意的是，将 MemSteer 监督提供给 M* 和 MemEvolve 也能带来显著增益，证明该监督信号的通用性。

消融实验显示，证据锚定答案规划与两阶段生成（先规划后生成）显著优于直接生成。QA 质量评估表明，MemSteer 生成的问答对在前提支持、清晰度及证据支持上均优于 Naive-QA 和 Ragas-QA。然而，评估边界在于：实验未对比纯向量检索优化方法（如 SwiftMem），且 ATM-Bench 上 QS 的大幅提升可能部分源于生成 QA 与测试集分布的相似性，合成监督与真实用户查询分布的偏差风险未在长期运行中验证。

## 关联研究分析

从问题动机看，MemSteer 与 MemEvolve 和 M* 同属记忆设计自动优化路线，但解决了反馈信号缺失的根本瓶颈。MemEvolve 依赖 GAIA 等基准的显式任务成败信号，M* 依赖代码执行反馈，二者均无法直接应用于缺乏明确成功标准的个人记录场景。MemSteer 通过合成 QA 填补了这一空白，但其代价是引入了合成数据噪声，需通过复杂的验证机制缓解。

从方法设计看，MemSteer 与 Ragas 均使用 LLM 生成多跳问答，但目标不同。Ragas 旨在生成测试基准以评估 RAG 系统，而 MemSteer 旨在生成训练监督以优化记忆架构。MemSteer 引入的证据锚定答案规划和盲恢复验证，比 Ragas 的图关系采样更严格，确保了监督信号对记忆设计诊断的有效性。然而，查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

MemSteer 解决了个人记忆场景中缺乏显式反馈导致记忆设计难以自动优化的矛盾。通过从历史中合成带有证据锚定的问答监督，并结合证据引导的失败诊断，该框架实现了存储、检索及上下文构建的迭代优化。实验表明，合成监督在 ATM-Bench 上使 QS 提升 13.4 点，接近人工标注效果，且能增强现有优化器性能。其边界在于合成数据与真实查询分布的潜在偏差，以及未涉及遗忘机制对长期性能的影响。当用户历史数据规模扩大至百万级时，合成监督的生成成本与验证开销是否会抵消其带来的检索效率增益，论文未给出回答。
