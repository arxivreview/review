# HuggingFace最新推荐论文 ｜Order-Only On-Policy Distillation ｜仅序数监督的在线策略蒸馏

研究机构：美国密苏里大学

作者：Guangzeng Han、Yu Wu、Xiaolei Huang

论文原文见 [arXiv](https://arxiv.org/abs/2611.02112)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2611.02112)

> 导读：大语言模型在线策略蒸馏（On-Policy Distillation, OPD）旨在解决训练与推理分布不匹配导致的暴露偏差，但现有方法强制学生拟合教师概率分布，导致学生受限于教师容量与校准度，且对温度超参数高度敏感。本文指出教师概率值中混合了“偏好排序”与“置信度”两类信息，后者对小模型而言是不必要的约束。O3PD 仅提取教师 Top-K Token 的相对顺序，通过相邻对 Bradley-Terry 损失进行监督，剥离概率幅度拟合。该设计使蒸馏目标对教师温度严格不变，并在多个数学推理基准上超越标准 OPD，但长尾 Token 知识的潜在丢失风险仍需进一步验证。

## 研究背景

当自回归语言模型进行知识蒸馏时，若仅在教师生成的序列上进行监督微调（SFT），学生模型在推理阶段会因自身生成错误而进入从未训练过的上下文状态，产生分布偏移。在线策略蒸馏（OPD）通过在学生自生成的轨迹上查询教师并匹配其输出分布，有效缓解了这一暴露偏差。然而，标准 OPD 通常采用 KL 散度或广义散度作为损失函数，要求学生复现教师在每个 Token 位置上的完整概率分布。

这种概率匹配范式隐含了一个强假设：教师输出的概率数值本身携带了学生必须获取的知识。实际上，教师概率分布混合了“候选 Token 的相对偏好”与“教师自身的置信度校准”两类信息。当师生模型存在显著容量差距（Capacity Gap）时，小容量学生模型难以复现大容量教师模型的置信度分布，导致优化过程陷入拟合不可达目标的困境。此外，温度缩放虽不改变概率排序，却会剧烈改变概率数值，使得标准 OPD 对温度超参数极度敏感，不同师生对需单独调优。现有研究多聚焦于优化散度形式或 Token 筛选策略，却未质疑“概率数值是否必须被传递”这一基础假设。

## 核心方法

### 序数监督与概率匹配的解耦

在标准 OPD 流程中，监督信号由教师在学生生成前缀 $s_t$ 处的完整概率分布 $p_T(\cdot|s_t)$ 提供，损失函数通常形式化为 $L_{OPD} = D_{KL}(p_T || p_S)$。该流程的关键缺陷在于，$D_{KL}$ 对概率幅度的偏差施加了直接惩罚，迫使学生在拟合排序的同时，必须消耗模型容量去逼近教师的置信度标度。

O3PD 将监督目标从“分布匹配”降级为“序数监督”。在每一个前缀状态，O3PD 仅提取教师概率最高的 $K$ 个候选 Token 及其相对顺序 $(v_{t,(1)}, \dots, v_{t,(K)})$，完全丢弃其概率数值。这一设计基于一个核心洞察：对于推理能力的迁移，教师“认为哪个 Token 更优”比“认为该 Token 有多优”更具本质性。通过剥离概率幅度，O3PD 将蒸馏目标从连续值回归转化为离散排序约束，从而消除了对教师校准度的依赖。

### 基于相邻对 Bradley-Terry 损失的排序约束

为了在不拟合概率值的前提下传递完整排序，O3PD 采用相邻对比较机制。对于教师排序中相邻的两个候选 Token $v_{t,(i)}$ 和 $v_{t,(i+1)}$，学生模型在仅考虑这两个候选时的偏好概率由 Bradley-Terry 模型定义：

$$
r_{t,i}^S = \frac{p_t^S(v_{t,(i)})}{p_t^S(v_{t,(i)}) + p_t^S(v_{t,(i+1)})} = \sigma(\Delta_{t,i}^S)
$$

其中 $\Delta_{t,i}^S = z_t^S(v_{t,(i)}) - z_t^S(v_{t,(i+1)})$ 为学生模型在这两个 Token 上的 Logit 差值，$\sigma$ 为 Sigmoid 函数。O3PD 的损失函数最小化相邻对偏好概率的负对数似然：

$$
\ell_{t,i}^{adj} = -\log \sigma(\Delta_{t,i}^S)
$$

该公式的物理含义是：只要学生模型赋予高排名 Token 的 Logit 高于低排名 Token，损失即趋近于零，而不要求两者之间的 Logit 差值达到特定数值。由于 $K-1$ 个相邻不等式通过传递性即可确定完整的 Top-K 排序，该损失构成了排序信息的最小充分描述。相比全对比较（All-pairs）的 $K(K-1)/2$ 个约束，相邻对约束显著降低了计算开销，同时保留了排序监督的核心效力。

### 温度不变性与幅度自由特性

O3PD 的数学结构赋予了其两个关键性质：教师温度不变性与幅度自由监督。由于 Softmax 函数中温度参数 $T$ 仅对 Logit 进行正数缩放（$z/T$），这不会改变 Logit 的相对大小顺序。因此，无论教师温度如何变化，Top-K 候选集合及其排序保持不变，O3PD 的损失函数值亦保持恒定。

这一特性直接解决了标准 OPD 中温度调优的难题。在幅度自由方面，由于损失函数仅约束 $\Delta_{t,i}^S > 0$，学生模型可以自由决定 Logit 差值的幅度，无需复现教师的概率间隙。这使得小容量学生模型能够专注于学习教师的决策边界方向，而非被教师的置信度标度所束缚，从而在师生容量差距较大时仍能保持稳定的知识迁移效率。

## 实验评估

实验在 Qwen3 模型家族上进行，涵盖 1.7B、4B、8B 三种学生规模与 4B、8B、14B 三种教师规模的六种组合，训练数据为 OpenThoughts 数学推理子集。评估基准包括 HMMT25、AIME24 和 AIME25 三个竞赛级数学测试集。基线对比涵盖了标准 OPD、SFT 以及 GRPO 方法。

| 方法 | 平均性能提升 (vs OPD) | AIME25 最大提升 | 温度敏感性 |
| :--- | :--- | :--- | :--- |
| O3PD | +2.9 点 | +5.6 点 | 无 (Invariant) |
| OPD | 基线 | 基线 | 高 (Sensitive) |
| SFT | 低于 O3PD | 低于 O3PD | 不适用 |
| GRPO | 低于 O3PD | 低于 O3PD | 不适用 |

*注：具体各配置数值未在输入材料中逐字提供，此处仅呈现论文摘要中明确给出的提升幅度与定性对比。*

在消融实验方面，论文对比了相邻对（Adjacent）、全对（All-pairs）及 ListMLE 等排序损失变体。结果显示，尽管全对损失直接惩罚远距离排序错误，但相邻对损失通过传递性已能充分捕获排序信息，且在计算效率上更具优势。ListMLE 虽在理论上等价，但在实际优化中并未表现出显著增益，表明相邻对约束是序数监督的高效实现形式。

评估边界方面，实验仅覆盖了数学推理任务，未涉及代码生成或通用对话等长尾分布场景。此外，论文未提供开源代码，复现需依赖 Qwen3 官方权重及 OpenThoughts 数据集。由于缺乏与 TIP、TA-OPD 等 Token 筛选方法的直接对比，O3PD 在低预算或高噪声监督场景下的相对优势尚不明确。

## 关联研究分析

从监督信号的构造来看，O3PD 与 RKKD（Guan et al., 2025）存在本质差异。RKKD 将 Kendall's $\tau$ 排序损失作为 KL 散度的辅助项，教师概率值仍通过 KL 项进入目标函数，因此其温度敏感性并未根本消除。O3PD 则证明排序可作为独立且充分的主目标，彻底剥离了概率匹配，这一设计在 LLM 在线蒸馏中尚属首次。相比之下，BiLD（Li et al., 2025）虽也限制在 Top-K，但其匹配的是 Logit 差值，仍保留了偏好强度的信息，导致其仅具备平移不变性而非完全的温度不变性。

从问题动机来看，O3PD 与 TIP（Xu et al., 2026）代表了优化监督信号质量的两种不同路径。TIP 通过显式计算 Token 熵与分歧度来筛选高价值 Token，属于“样本级”的重要性加权；O3PD 则通过 Top-K 截断隐式过滤低概率噪声，属于“候选级”的排序约束。TIP 保留了概率分布的形态，而 O3PD 仅保留序关系。在师生容量差距极大时，O3PD 的幅度自由特性可能比 TIP 的概率加权更具鲁棒性，但 TIP 在保留教师置信度信息方面可能更利于需要精确校准的任务。

## 总结

本文针对在线策略蒸馏中概率匹配导致的温度敏感与容量瓶颈问题，提出仅序数监督的 O3PD 方法。通过仅约束教师 Top-K Token 的相对顺序，O3PD 实现了温度不变性与幅度自由监督，在六个师生配置中平均提升 2.9 点，AIME25 最高提升 5.6 点。该方法证明了在 LLM 蒸馏中，排序信息足以承载核心推理知识，概率数值并非必要约束。然而，O3PD 仅监督 Top-K 候选，可能忽略长尾 Token 的细微排序差异，且未验证在教师排序本身存在噪声时的鲁棒性。当教师模型在低置信度区域产生排序错误时，仅依赖序数监督是否会放大该噪声并误导学生模型，仍有待进一步探究。
