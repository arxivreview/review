> 导读 机器人操作策略通常将技能编码于网络权重中，导致模型性能高度依赖训练数据分布，在域随机化等分布偏移场景下鲁棒性急剧下降。现有视觉-语言-动作（Vision-Language-Action, VLA）模型与世界动作模型（World Action Model, WAM）虽在结构化环境中表现优异，但缺乏对未见场景的语义泛化能力，且每次适应新任务均需重新训练。本文提出世界上下文学习（World In-Context Learning, WICL）范式，利用模拟器作为反馈源，将演示经验蒸馏为可迁移的语义上下文（Task Memory），实现无梯度更新的技能获取。该范式在 RoboTwin 2.0 基准上以单演示数据超越多演示训练基线，但在真实硬件上的精细操作上限及计算成本仍需进一步验证。

## 研究背景

当机器人执行操作任务时，其感知到的视觉特征与执行动作所需的低层控制信号之间存在巨大的语义鸿沟。传统方法通过训练 VLA 模型或 WAM，将这种映射关系固化在神经网络权重中。这种“权重内学习”范式虽然能继承大规模预训练先验，但本质上是将技能绑定于训练数据的特定分布。一旦部署环境的光照、物体位置或物理参数发生微小变化（即分布偏移），模型因缺乏对任务语义的深层理解，往往出现动作抖动或任务失败。

为了摆脱对密集标注和特定任务规则的依赖，研究者尝试引入上下文学习（In-Context Learning, ICL），试图让模型仅通过观察演示视频即可适应新任务。然而，传统 ICL 在机器人领域面临核心瓶颈：上下文仅包含静态的视觉演示，缺乏来自物理世界的动态反馈。模型无法得知其预测的动作在真实环境中会产生何种后果，导致误差在长时程操作中不断累积。与此同时，强化学习（Reinforcement Learning, RL）虽能通过环境反馈优化策略，但其高昂的样本复杂度和对权重更新的依赖，限制了其在快速适应新任务场景下的应用。如何在冻结模型权重的前提下，利用世界反馈实现技能的语义化存储与跨分布迁移，成为当前具身智能研究的关键缺口。

## 核心方法

### 方法参照系：从权重优化到上下文更新

在标准的机器人策略学习中，策略 $\pi_\theta$ 通过最小化损失函数更新参数 $\theta$，以最大化累积奖励或模仿演示行为。WICL 将这一过程重构为上下文更新过程。模型权重 $\theta$ 保持冻结，学习过程转化为对上下文 $C$ 的迭代编辑。该范式将“世界”（如模拟器）视为提供反馈的终端，类似于编码代理在终端中运行代码并读取输出。WICL 的核心在于将 RL 的“试错-反馈”机制从参数空间迁移至文本空间，通过自然语言记录任务语义、物体角色及失败教训，形成可解释、可迁移的 Task Memory。

### 世界反馈驱动的上下文迭代

WICL 的学习过程由初始化与迭代更新两个阶段组成。初始上下文 $C_0$ 由演示 $d$ 生成，随后模型在模拟器 $W$ 中执行动作并接收反馈，进而更新上下文。这一过程形式化为：

$$
C_{k+1} = U_\theta(C_k, \tau_k, r_k), \quad (\tau_k, r_k) \sim W(\pi_\theta(\cdot | o, C_k), e_k)
$$

其中，$U_\theta$ 为更新函数，$\tau_k$ 为轨迹，$r_k$ 为反馈信号，$e_k$ 为排练实例。该公式表明，上下文的演化完全依赖于模型在特定世界中的交互结果。设计动机在于解决传统 ICL 缺乏闭环反馈导致的误差累积问题。通过引入可重置、可交互的模拟器，模型能够安全地“排练”任务，将视觉演示转化为包含成功条件与失败模式的语义知识，而非仅仅记忆视觉外观。

### 语义抽象与跨世界迁移机制

为了确保上下文知识能够跨越不同世界（如从模拟器到真实机器人）迁移，Task Memory 必须剥离特定场景的视觉特征，仅保留任务语义。定义实例 $e$ 的语义内容为 $\sigma(e)$，包括物体角色、指令及相对几何关系。若两个世界 $W$ 和 $W'$ 在语义上等价，即 $\sigma(W) = \sigma(W')$，则 $W$ 中习得的上下文 $C^*$ 可直接应用于 $W'$。

$$
a_t \sim \pi_\theta(\cdot | o_t, C^*), \quad e \in E_{\text{test}}
$$

该公式描述了部署阶段的动作生成过程，其中 $C^*$ 为冻结后的最终上下文。设计动机在于克服权重内学习对训练域视觉特征的过拟合。通过强制上下文仅引用语义量（如“从左侧接近把手”而非“坐标 (x,y)”），WICL 实现了知识的形式化抽象，使得在模拟器中习得的技能无需重新训练即可在视觉分布差异巨大的真实场景中生效。

## 实验评估

实验在 RoboTwin 2.0 基准上进行，涵盖 50 个双臂操作任务，分为 Clean（干净场景）和 Randomized（域随机化）两种设置。基线对比覆盖了主流 VLA 模型（如 $\pi_{0.5}$, StarVLA）和 WAM（如 FastWAM, 4D-WAM）。RoboScript 仅使用每个任务 1 个演示且无梯度更新，而基线方法通常使用 50 个演示进行训练。

| Method | Demos per task | Trained | Success Rate (%) Clean | Success Rate (%) Rand | Success Rate (%) Avg | Retention (%) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| $\pi_{0.5}$ | 50 | ✓ | 70.7 | 46.0 | 58.4 | 65.1 |
| FastWAM | 50 | ✓ | 77.8 | 1.9 | 39.9 | 2.4 |
| 4D-WAM | 50 | ✓ | 81.5 | 41.8 | 61.7 | 51.3 |
| RoboScript (GPT-6.1-Sol) | 1 | ✗ | 83.6 | 83.2 | 83.4 | 99.5 |

RoboScript 在平均成功率上达到 83.4%，较最强训练基线 4D-WAM（61.7%）提升 21.7 个百分点。在域随机化设置下，RoboScript 保持 83.2% 的成功率，而 FastWAM 骤降至 1.9%，$\pi_{0.5}$ 降至 46.0%。这表明基于语义上下文的学习在分布偏移下具有极高的鲁棒性，其保留率（Retention）接近 100%，远超训练式策略。

消融实验进一步验证了各组件的贡献。移除世界反馈（仅使用演示）导致平均成功率降至 69.0%，证明反馈机制是性能提升的关键。移除恢复机制（Recovery）使成功率降至 69.0%，表明闭环纠错对长时程任务至关重要。此外，特权监督（Privileged Supervision）的移除仅导致 0.5% 的性能下降，证实了 Task Memory 中存储的是可部署的语义知识，而非模拟器特有的特权信息。

| Variant | Success Rate (%) Clean | Success Rate (%) Rand | Success Rate (%) Avg |
| :--- | :---: | :---: | :---: |
| RoboScript (Full) | 77.0 | 80.0 | 78.5 |
| w/o recovery | 68.0 | 70.0 | 69.0 |
| w/o arm check | 78.0 | 72.0 | 75.0 |
| Demonstration written to memory | 69.0 | 69.0 | 69.0 |

评估边界方面，实验主要在仿真环境中进行，真实机器人部署仅测试了 4 个任务，且依赖轻量级适配器进行参数重映射。计算成本方面，GPT-6.1-Sol 学习 50 个任务并评估 1000 个回合的成本约为 1911 美元，主要开销来自评估阶段的模型调用。

## 关联研究分析

从问题动机看，WICL 与 SimpleVLA-RL 均致力于解决模仿学习的分布外脆弱性，但路径截然不同。SimpleVLA-RL 通过强化学习更新权重，利用奖励信号优化策略参数，其鲁棒性来源于策略在参数空间中的平滑性；而 WICL 冻结权重，通过文本编辑更新上下文，其鲁棒性来源于语义知识的抽象性。WICL 避免了 RL 训练中的样本效率问题，但引入了对基础模型语义理解能力的强依赖。当基础模型无法正确解析任务语义时，WICL 可能失效，而 RL 可通过大量交互数据弥补这一缺陷。

从方法设计看，WICL 与 HarnessVLA 同属 Agent 架构，但 HarnessVLA 依赖预训练的底层策略执行接触操作，WICL 则完全移除训练策略，通过 API 调用和代码生成实现控制。HarnessVLA 在接触丰富任务中表现更稳定，因为其底层策略已内化了物理动力学；WICL 则通过显式的恢复机制和重试逻辑来弥补底层控制的不足。这种差异反映了“隐式物理先验”与“显式语义推理”在机器人控制中的权衡。WICL 在需要复杂逻辑推理的任务上更具优势，但在高频、高精度力控任务上可能受限于 API 调用的延迟与精度。

## 总结

本文针对机器人策略在分布偏移下鲁棒性不足的问题，提出 WICL 范式，将技能学习从权重空间迁移至上下文空间。通过引入模拟器反馈，模型将演示经验蒸馏为语义化的 Task Memory，实现了无梯度更新的跨分布泛化。在 RoboTwin 2.0 上，该方法以单演示数据达到 83.4% 的平均成功率，显著超越多演示训练基线，且在域随机化下保持极高鲁棒性。然而，该方法依赖强大的基础模型进行语义解析，且真实硬件部署仅验证了简单任务，其在复杂接触操作中的精度上限及高计算成本仍是实际应用的瓶颈。当任务涉及非结构化环境中的动态交互时，仅靠静态语义上下文是否足以应对实时物理反馈的复杂性，尚需进一步验证。
