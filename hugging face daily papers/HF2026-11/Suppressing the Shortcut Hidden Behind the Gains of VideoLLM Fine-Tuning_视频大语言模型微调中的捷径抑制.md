# HuggingFace最新推荐论文 ｜Suppressing the Shortcut Hidden Behind the Gains of VideoLLM Fine-Tuning ｜视频大语言模型微调中的捷径抑制

研究机构：韩国科学技术院

作者：Youngwoo Shin、Jongsuk Kim、Junmo Kim

论文原文见 [arXiv](https://arxiv.org/abs/2611.25776)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2611.25776)

> 视频大语言模型（VideoLLM）在监督微调（SFT）中常依赖文本捷径而非视觉证据，导致分布外性能下降。现有方法多通过数据过滤或解码干预缓解，但无法阻止捷径在训练更新中形成。本文提出VETO，通过正交投影约束LoRA更新方向，抑制文本捷径子空间。该方法在保持训练分布精度的同时，显著提升分布外鲁棒性，为无需强化学习的幻觉缓解提供了新路径。其局限在于未验证与强化学习方法的直接对比，且正交投影是否限制合法文本-视觉关联尚待验证。

## 研究背景

当VideoLLM面对视频问答任务时，其核心能力在于将视觉动态与语言语义对齐。然而，SFT阶段模型常从训练数据的文本规律中学习捷径，即仅凭问题文本即可预测答案，绕过视频内容。这种捷径在训练分布内可能伴随精度提升而隐藏，但在分布偏移下会取代视觉证据，导致性能停滞甚至下降。现有缓解策略包括数据过滤、损失惩罚或解码修正，但均无法在捷径形成的源头——即模型参数更新过程中——进行干预。

领域共识认为，强化学习（RL）是提升时序推理与缓解幻觉的主流范式，如TempR1通过GRPO优化策略。然而，RL训练开销大且奖励设计复杂。本文切入点在于：捷径并非预训练先验的必然结果，而是SFT更新过程中写入的特定方向。若能识别并约束这些方向，即可在不引入RL开销的前提下抑制捷径。这一视角将问题从“如何修正输出”转向“如何约束更新”，为训练阶段干预提供了几何化解决方案。

## 核心方法

### 方法参照系：LoRA微调与捷径形成

本文问题置于参数高效微调（PEFT）框架下，具体采用LoRA（Low-Rank Adaptation）。标准LoRA通过低秩矩阵$B A$近似权重更新$\Delta W$，使模型适应下游任务。在VideoLLM中，该更新过程同时写入视觉-语言对齐信息与文本捷径。本文的关键差异在于：不将$\Delta W$视为整体优化对象，而是将其分解为“视觉证据方向”与“文本捷径方向”，并仅约束后者。这一分解依赖于对文本捷径在激活空间中几何结构的识别。

### 文本捷径子空间校准

捷径形成的根源在于文本输入在模型激活空间中占据特定方向。VETO首先通过校准集识别该子空间。设计动机在于：盲过滤数据虽移除基础模型可解样本，但SFT仍能从剩余文本规律中学习新捷径，需显式定位这些规律对应的激活方向。

具体而言，对校准集$\mathcal{D}_{\text{cal}}$执行文本-only前向传播，收集每层线性模块的输入激活$H_{\text{text}}^{l} \in \mathbb{R}^{d_{\text{in}} \times n_{\text{text}}}$。计算二阶矩矩阵：

$$
C^{l} = \frac{1}{n_{\text{text}}} H_{\text{text}}^{l} (H_{\text{text}}^{l})^{\top}
$$

对$C^{l}$进行特征分解，保留累积特征值占比达$\rho$的最小秩$r^{l}$，其对应特征向量构成捷径子空间基$U_{1}^{l}$。该子空间捕获文本输入在激活空间中的主要变异方向，即捷径所依赖的几何结构。校准仅需数百样本，且子空间为骨干网络属性，与具体校准样本无关。

### 正交投影更新约束

在识别捷径子空间后，VETO将LoRA更新投影至其正交补空间。设计动机在于：传统方法在数据或损失层面干预，无法阻止更新向量沿捷径方向写入；而几何投影可直接阻断捷径形成路径。

投影矩阵定义为：

$$
P^{l} = I - U_{1}^{l} (U_{1}^{l})^{\top}
$$

在每个优化步，LoRA的降维因子$A^{l}$更新为$A^{l} \leftarrow A^{l} P^{l}$，确保更新$\Delta W^{l} = B^{l} A^{l}$满足$\Delta W^{l} U_{1}^{l} = 0$。这一约束保证微调后模型在捷径子空间内的响应与基础模型一致，即不新增文本捷径。同时，正交补空间内的更新不受限制，模型仍可学习视觉-语言对齐。该设计为预防性而非修正性：捷径方向从第一步梯度更新起即不可达，无需事后检测或修正。

## 实验评估

实验在盲过滤的Something-Something v2（SSv2）训练集上进行，评估涵盖训练分布及六个分布外基准（Perception Test, Vinoground等）。基线包括标准SFT、LMH、mDPO及随机子空间投影。未与TempR1等RL方法直接对比，因任务侧重通用视频QA而非时序定位。

| 基准 | 方法 | Acc. | Text $\Delta$ |
| :--- | :--- | :--- | :--- |
| SSv2 | Base | 49.1% | – |
| SSv2 | SFT | 89.6% | +30.5 |
| SSv2 | VETO | 89.2% | +6.0 |
| Perception Test | Base | 61.1% | – |
| Perception Test | SFT | 61.1% | +17.0 |
| Perception Test | VETO | 64.3% | +4.9 |

VETO在SSv2上保持与SFT相当的精度（89.2% vs 89.6%），但文本捷径增益从+30.5降至+6.0。在分布外Perception Test上，SFT精度无提升（61.1%），而VETO提升至64.3%，且文本增益仅+4.9。这表明VETO抑制捷径后，模型转而依赖视觉证据，从而在分布偏移下获得增益。

消融实验验证投影时机与$\rho$值的影响。$\rho=0.95$时VETO精度89.2%、文本增益+6.0；$\rho=0.99$时文本增益降至+1.1但精度略升至89.5%；$\rho=0.90$时文本增益回升至+12.9。仅在初始化时投影无法抑制捷径（文本增益+30.0），每步投影必要。评估协议采用盲过滤与最高logit选项判定，代码与超参数公开，单卡B200可复现。

## 关联研究分析

从问题动机看，VETO与SEASON均针对视频LLM幻觉，但干预阶段不同。SEASON在解码阶段通过DINOv2特征重加权抑制幻觉Token，属训练无关方案；VETO在训练阶段约束更新方向，从根源阻断捷径形成。SEASON无需重新训练但效果有限，VETO需微调但效果持久。两者差异源于对幻觉机制的理解：SEASON假设幻觉为解码偏差，VETO假设幻觉为更新方向写入。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

从方法设计看，VETO与CRPO同属训练阶段干预，但机制迥异。CRPO通过反事实分支奖励增强时空敏感性，需生成反事实视频并计算跨分支奖励；VETO通过几何投影约束更新，无需额外数据生成或奖励设计。CRPO针对时序敏感性，VETO针对文本捷径，两者在“反事实”与“结构化”上形成互补。正交投影是否限制了模型学习合法的文本-视觉关联，论文未给出回答。

## 总结

本文针对VideoLLM微调中SFT必然引入文本捷径、导致分布外鲁棒性下降的核心矛盾，提出VETO通过正交投影约束LoRA更新方向，抑制文本捷径子空间。该方法在SSv2上保持89.2%精度（SFT为89.6%），在Perception Test上提升至64.3%（SFT为61.1%），证明捷径非精度提升必需。其边界在于未验证与RL方法的直接对比，且正交投影可能同时抑制合法文本-视觉关联。当$\rho$值增大至0.99时，文本增益降至+1.1但精度略升，提示投影强度与视觉证据利用之间存在权衡，该权衡的最优解是否依赖任务特性，论文未给出回答。
