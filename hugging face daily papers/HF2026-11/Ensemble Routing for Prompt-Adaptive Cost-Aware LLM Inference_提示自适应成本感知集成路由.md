> 导读：LLM路由旨在平衡异构查询的响应质量与推理成本，但单模型路由受限于能力上限，而固定集成路由无法适应动态成本偏好。现有方法多依赖硬聚类或固定基数，导致边界模糊与资源浪费。本文提出PISA与PISA-E，通过软聚类能力估计与泊松二项分布代理，实现推理时动态调整集成组成与基数。该框架在成本-性能帕累托前沿上实现了优于固定集成的平衡，但并行调用带来的延迟开销及贪心搜索的次优性仍需验证。

## 研究背景

当服务系统面对海量异构查询时，单一LLM难以同时满足所有任务的质量与成本要求。高成本模型处理简单任务造成资源浪费，低成本模型在复杂任务上表现不足。为解决这一矛盾，LLM路由（LLM Routing）通过为每个查询分配最优模型来最小化总成本。然而，单模型路由无法利用多模型间的互补能力，而传统集成方法虽能提升性能上限，却因固定模型数量导致成本僵化，无法根据查询难度动态调整资源投入。

现有路由方法主要面临两大瓶颈：一是能力估计的粒度不足，硬聚类方法在查询边界处易产生误判，导致路由崩溃；二是集成决策的静态性，多数方法在训练阶段固定集成大小，无法在推理时根据用户成本偏好（$\alpha$）灵活调整。PISA与PISA-E的切入点在于将能力估计与集成决策解耦：通过软聚类提供细粒度能力预测，再利用该预测构建集成成功率的解析代理，从而在无需重新训练的前提下，实现集成组成与基数的动态优化。

## 核心方法

### 方法参照系：成本感知路由框架

本文问题属于成本感知路由（Cost-Aware Routing）范畴。标准流程包括查询嵌入、模型能力估计、成本归一化及效用最大化选择。与通用流程的关键差异在于，PISA-E将动作空间从单模型扩展至模型子集，并引入推理时可变的成本-质量权衡参数 $\alpha$，要求能力估计模块具备跨基数的泛化能力。

### 软聚类能力估计（PISA）

传统路由常使用硬聚类或全局潜在表示估计模型能力，前者在簇边界处信息丢失严重，后者难以捕捉查询局部特性。PISA采用X-means算法确定簇数量 $K$ 与质心 $\mu_k$，并通过余弦距离计算软隶属度 $u_k(x)$：

$$
u_k(x) = \frac{\exp(-\beta d_k(x))}{\sum_{j=1}^K \exp(-\beta d_j(x))}, \quad d_k(x) = 1 - x^\top \mu_k
$$

其中 $\beta$ 控制分配集中度。该公式使查询表示融合多邻域信息，缓解硬分配导致的边界模糊。随后，PISA为每个模型 $m$ 训练独立的逻辑回归预测器，输出能力估计 $\hat{p}_m(x) = \sigma(w_m^\top u(x) + b_m)$。这一设计使能力估计具备局部适应性，为后续集成效用计算提供细粒度输入。

### 动态基数集成选择（PISA-E）

直接评估所有模型子集的集成性能需组合爆炸级计算。PISA-E利用独立伯努利变量假设，构建严格多数成功概率作为集成效用代理。对于大小为 $k$ 的集成 $E$，其成功概率 $\hat{p}_E^{maj}(x)$ 通过泊松二项分布动态规划计算：

$$
\hat{p}_E^{maj}(x) = \Pr\left(\sum_{m \in E} Z_m \geq \frac{k+1}{2}\right), \quad Z_m \sim \text{Bernoulli}(\hat{p}_m(x))
$$

该代理无需为每种组合训练独立预测器。集成效用 $J_E(x; \alpha)$ 结合质量代理与归一化成本 $\bar{C}(E)$：

$$
J_E(x; \alpha) = \alpha \hat{p}_E^{maj}(x) + (1 - \alpha)(1 - \bar{C}(E))
$$

PISA-E采用贪心前缀搜索：按单模型效用排序，仅评估奇数基数前缀。这一设计基于数学性质——偶数基数集成移除一个模型后，多数阈值降低且成本减少，效用不会下降。因此，奇数基数搜索空间足以覆盖最优解，显著降低计算复杂度。

## 实验评估

实验在LLMRouterBench、RouterBench、FusionBench和SPROUT四个基准上进行，覆盖分布内（ID）与分布外（OOD）场景。基线包括EmbedLLM、Avengers-Pro等单模型路由，以及DFPE、SelectLLM等集成方法。PISA在单模型路由中取得最高宏平均超体积（HV），ID为37.41，OOD为22.85，优于EmbedLLM-MF的35.78和21.33。

| 方法 | ID HV (×100) | OOD HV (×100) | ID 性能 (%) | ID 成本 (USD×10⁴) |
| :--- | :--- | :--- | :--- | :--- |
| EmbedLLM-MF | 35.78 | 21.33 | - | - |
| SelectLLM | - | - | 73.18 | 132 |
| PISA-E ($\alpha=0.75$) | - | - | 73.78 | 84 |
| PISA-E ($\alpha=1$) | - | - | 75.27 | 280 |

PISA-E在ID上以84成本实现73.78%性能，较SelectLLM（132成本，73.18%性能）成本降低36%且性能提升0.60个百分点。在OOD上，PISA-E（$\alpha=0.85$）以292成本实现60.85%性能，优于DFPE（387成本，60.37%性能）。

消融实验验证了动态基数的有效性。PISA-E宏平均HV为39.35（ID）和26.30（OOD），优于固定基数 $k=1$ 的39.07和24.50。在 $\alpha=0.3$ 时，84.33%的ID查询被分配至单模型，表明动态基数能有效避免简单任务的资源浪费。

评估边界方面，论文未报告推理延迟，并行调用多模型的延迟开销可能抵消成本节省。此外，贪心前缀搜索未与穷举搜索对比，次优性影响未知。代码未开源，复现依赖Qwen3-Embedding-8B等特定组件。

## 关联研究分析

从问题动机看，PISA-E与ZeroRouter均关注模型池动态变化下的适应性，但路径不同。ZeroRouter通过通用潜在空间实现零样本路由，侧重模型接入的便捷性；PISA-E通过软聚类与解析代理实现集成基数的动态调整，侧重成本-质量权衡的精细化。PISA-E的软聚类机制在分布外泛化上表现稳健，但缺乏ZeroRouter的理论保证。

从方法设计看，PISA-E与SelectLLM同属集成选择，但SelectLLM依赖预推理或固定组合，延迟较高。PISA-E利用能力估计直接评估子集效用，无需预推理，延迟更低。然而，PISA-E假设模型输出独立，忽略了模型间相关性，这在高度相关的模型池中可能导致效用估计偏差。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文针对单模型路由能力上限与固定集成成本僵化的矛盾，提出PISA/PISA-E框架。通过软聚类能力估计与泊松二项分布代理，实现推理时动态调整集成组成与基数。实验表明，PISA-E在ID上以36%成本降低实现性能提升，OOD上以25%成本降低实现性能提升，验证了动态基数的有效性。然而，并行调用的延迟开销及模型独立性假设的局限性，限制了其在低延迟场景的应用。当模型池中存在高度相关模型时，独立假设导致的效用估计偏差是否会显著影响路由决策，论文未给出回答。
