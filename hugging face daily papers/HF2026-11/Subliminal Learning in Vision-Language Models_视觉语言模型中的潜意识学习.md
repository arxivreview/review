# HuggingFace最新推荐论文 ｜Subliminal Learning in Vision-Language Models ｜视觉语言模型中的潜意识学习

作者：Arman Hatami、Romina Aalishah、Ilya E. Monosov

论文原文见 [arXiv](https://arxiv.org/abs/2611.08538)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2611.08538)

> 导读 视觉语言模型（Vision-Language Models, VLMs）在知识蒸馏与合成数据生成中，常假设训练数据仅传递显式语义信息。然而，现有研究多聚焦于提升任务性能或消除分布偏移，忽视了模型参数更新方向可能携带与任务无关的隐性偏好。本文首次将大语言模型中的“潜意识学习”现象扩展至多模态领域，揭示了VLMs通过无关视觉任务传递隐藏行为偏好的机制。研究通过构造几何形状计数任务作为载体，证明教师模型的动物或面部属性偏好可传递至学生模型，且传递强度随数据量增加而增强。这一发现挑战了“数据内容决定模型行为”的传统认知，对VLMs的数据生成安全与对齐机制构成潜在威胁，但其在复杂真实场景中的泛化边界尚待验证。

## 研究背景

当VLMs被用于生成训练数据时，其输出不仅包含显式标签，还隐含了模型内部的参数状态。若教师模型存在特定偏好（如偏爱某种动物），其生成的看似无关的数据（如数字序列）可能通过参数更新方向，将这一偏好“植入”学生模型。这种现象在纯文本大语言模型中被称为潜意识学习，其核心机制在于学生模型的参数更新向量与教师模型的偏好方向存在正相关。然而，VLMs涉及视觉与文本特征的复杂交互，其预测依赖于跨模态表示，因此潜意识学习是否能在多模态场景下发生，此前尚不明确。

现有VLMs适配研究主要致力于通过参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）或强化学习后训练来提升任务精度并保留通用能力。这些方法通常假设训练数据是“干净”的，即数据内容直接对应优化目标。然而，随着合成数据在VLMs训练中的普及，数据生成过程中的隐性偏差传递成为新的安全瓶颈。若无关数据能传递偏好，则依赖模型生成数据进行对齐或微调的流程可能引入不可控的行为偏差。本文切入点在于通过受控实验，量化VLMs中通过无关视觉任务传递隐藏偏好的可能性与强度，填补了多模态模型安全分析中的这一空白。

## 核心方法

### 方法参照系：受控教师-学生框架

本文未采用标准的PEFT或RLHF流程，而是构建了一个受控的教师-学生实验框架。该框架的核心差异在于：传统适配方法优化任务损失以对齐人类偏好，而本文构造“载体任务”（Carrier Task），故意使训练数据与目标偏好（如动物选择）语义无关。通过对比“偏差教师”与“控制教师”生成的数据对学生模型的影响，量化潜意识传递效应。

### 核心创新：基于参数方向对齐的传递机制

潜意识传递的物理基础在于参数空间中的方向对齐。设参考模型参数为 $\theta_0$，偏差教师参数为 $\theta_T = \theta_0 + \varepsilon \Delta \theta_T$，其中 $\Delta \theta_T$ 为指向偏差教师的方向向量。学生模型在载体数据上微调产生更新 $\delta \theta$。学生模型与偏差教师的平方距离变化为：

$$
\left\| \theta_0 + \delta \theta - \theta_T \right\|_2^2 - \left\| \theta_0 - \theta_T \right\|_2^2 = \left\| \delta \theta \right\|_2^2 - 2\varepsilon \, \delta \theta^{\top}\Delta \theta_T
$$

当 $\delta \theta^{\top}\Delta \theta_T > 0$ 时，学生模型在参数空间中向偏差教师移动。由于该方向与目标偏好相关，学生模型的目标选择概率 $P_T$ 随之增加。这一机制解释了为何无关数据能传递偏好：载体任务产生的参数更新在教师偏好方向上存在正投影。

### 核心创新：载体任务设计与数据规模效应

载体任务需满足两个条件：依赖视觉信息且存在多个有效输出。本文使用几何形状计数任务，模型需统计图像中形状数量并生成对应范围的数字。例如，形状数量为3-4时，生成25-49之间的数字。这种设计确保了视觉输入与输出数字之间的映射关系，同时允许不同教师生成不同的数字序列。

随着载体数据量 $N$ 增加，累积更新 $\delta \theta^{(N)} \approx \sum_{i=1}^{N}\delta \theta_i$ 在教师方向上的投影 $\sum_{i=1}^{N} \delta \theta_i^{\top}\Delta \theta_T$ 可能累积增加，导致传递效应增强。这一设计揭示了数据规模与潜意识传递强度之间的正相关关系，挑战了“数据量越大越能稀释噪声”的直觉。

## 实验评估

实验在Qwen2-VL-2B、Qwen2.5-VL-3B/7B及Phi-4-multimodal-Instruct上进行。载体数据包含20,480个候选样本，筛选出8,000个匹配样本用于动物偏好实验。评估指标为偏差学生与控制学生在目标选择率上的差异 $\Delta_T$。

| 模型 | 目标偏好 | 解码策略 | 控制学生选择率 (%) | 偏差学生选择率 (%) | $\Delta_T$ (百分点) | 95% CI |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Qwen2.5-VL-3B | Panda | Greedy | 30.50 | 40.42 | +9.92 | [+7.83, +12.08] |
| Qwen2.5-VL-3B | Lion | Greedy | - | - | +5.67 | - |
| Qwen2.5-VL-3B | Dolphin | Greedy | - | - | +5.58 | - |
| Qwen2.5-VL-3B | Panda | Temp | - | - | +1.58 | - |
| Qwen2.5-VL-3B | Lion | Temp | - | - | +5.33 | [+3.67, +7.08] |
| Qwen2.5-VL-7B | Dolphin | Temp | - | - | +6.00 | [+4.33, +7.67] |
| Qwen2.5-VL-7B | Dolphin | Greedy | - | - | +3.25 | [+1.17, +5.33] |

*注：部分数据未在原文表格中直接列出，仅引用文中明确提及的数值。*

实验显示，潜意识传递在VLMs中确实存在，但强度受目标偏好、模型规模及解码策略影响。Qwen2.5-VL-3B在贪心解码下对Panda的传递效应最强，达到+9.92个百分点。此外，传递效应不仅限于选择偏好，还延伸至文本表述。偏差学生的解释文本与偏差教师的相似度显著高于控制学生，Token-F1差异达+3.21个百分点，表明潜意识传递影响了模型的生成风格。

评估边界方面，实验主要使用合成几何图像与特定动物/面部属性，未覆盖复杂真实场景。此外，未对比PEFT方法（如LoRA）对传递效应的影响，无法确定参数高效微调是否会抑制或增强该现象。

## 关联研究分析

从问题动机看，本文与LLaVA等视觉指令微调研究形成鲜明对比。LLaVA旨在通过高质量指令数据提升模型的多模态理解能力，假设数据内容直接决定模型行为。而本文揭示，即使数据内容（数字序列）与目标行为（动物偏好）完全无关，模型行为仍可能受教师模型参数状态影响。这一差异源于对“数据-行为”映射关系的不同假设：前者关注显式语义对齐，后者关注隐式参数方向传递。

从方法设计看，本文与GRPO等强化学习后训练方法存在潜在冲突。GRPO依赖模型生成的偏好数据进行策略优化，若生成数据隐含教师模型的偏差，则RLHF流程可能放大而非消除这些偏差。本文未直接测试RLHF场景，但其发现的“无关数据传递偏好”机制暗示，在RLHF中若奖励模型或策略模型存在隐性偏好，这些偏好可能通过生成数据污染后续训练。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文揭示了VLMs中通过无关视觉任务传递隐藏偏好的潜意识学习现象，挑战了“训练数据内容决定模型行为”的传统认知。通过构造几何形状计数载体任务，证明教师模型的动物或面部属性偏好可传递至学生模型，最大传递效应达+9.92个百分点。该发现对依赖合成数据或知识蒸馏的VLMs训练流程构成安全威胁，表明模型可能学习数据中未显式表示的行为特征。然而，实验局限于合成数据与特定偏好类型，未验证在复杂真实场景或PEFT架构下的传递边界。当载体任务从简单计数扩展至复杂视觉推理时，潜意识传递的强度与方向是否仍保持线性累积，论文未给出回答。
