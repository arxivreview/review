论文原文见 [arXiv](https://arxiv.org/abs/2611.10329)

> 导读：在 AI 驱动的系统研究（AI-Driven Research for Systems, ADRS）中，大语言模型（Large Language Model, LLM）代理依赖仿真器评估候选设计，但仿真器为追求可扩展性必然引入建模局限（Modeling Limitations）。现有评估范式仅关注文本生成质量或仿真器本身的预测保真度，未能隔离出 LLM 对“仿真局限是否改变最终设计决策”这一核心判断能力的度量。SIRIS 框架通过向仿真器注入受控扰动，构建 Upheld（局限存在但不改变最优设计）与 Overturned（局限导致最优设计反转）的配对问题，量化 LLM 的 Judgment（综合准确率）与 Disposition（两类问题准确率偏差）。该研究揭示了 LLM 即使识别出建模局限，仍频繁做出错误设计选择的系统性缺陷，为评估 LLM 在数值密集型决策任务中的元认知能力提供了新基准。

## 研究背景

当 LLM 代理在 ADRS 中执行迭代设计时，其核心依赖是仿真器提供的性能预测。仿真器通过抽象系统行为（如忽略网络带宽竞争或简化微架构）来换取评估速度，这种抽象必然引入建模局限。建模局限对设计决策的影响具有高度情境依赖性：它可能仅扭曲绝对性能数值而不改变候选设计的相对排序，也可能直接反转最优设计的选择。因此，LLM 必须具备判断“建模局限是否影响当前决策”的能力，即区分仿真器预测的绝对误差与相对决策误差。

现有 LLM-as-a-Judge 研究主要聚焦于开放式文本生成的质量评估，其偏差分析（如位置偏差、冗长偏差）和统计校正方法均建立在语义理解与人类偏好对齐的假设之上。然而，在系统仿真评估中，评估信号是数值化的性能指标，决策逻辑依赖于对系统机制与数值敏感度的因果推理。现有方法未能将“识别仿真局限”与“基于局限修正决策”解耦，导致无法评估 LLM 是否真正理解仿真器误差的决策影响，还是仅仅在模仿人类对文本的评判模式。SIRIS 正是为了填补这一空白，将评估焦点从“生成文本的质量”转向“对仿真器可信度的决策判断”。

## 核心方法

### 方法参照系：仿真辅助评估的决策隔离

在标准的仿真辅助评估流程中，LLM 接收系统规范、候选代码及仿真器输出，直接输出设计选择。该流程的隐含假设是仿真器输出即为真值，LLM 仅需执行排序或选择操作。SIRIS 的关键差异在于，它不评估 LLM 的排序能力，而是评估其在仿真器存在已知缺陷时的决策鲁棒性。为此，SIRIS 将评估任务重构为：给定一个带有特定建模局限的仿真器推荐，LLM 必须判断该推荐在当前工作负载下是否依然成立。

### 受控扰动与配对问题构造

为了隔离建模局限的决策影响，SIRIS 借鉴软件变异测试（Mutation Testing）思想，向参考仿真器注入受控扰动（Controlled Perturbations）。每个扰动对应一个具体的建模局限（如将网络传输建模为全带宽而非共享带宽）。对于每个扰动，SIRIS 构造两个工作负载，使得扰动后的仿真器在两者上推荐相同的设计，但参考仿真器（无扰动）在一个负载上支持该推荐（Upheld），在另一个负载上推荐不同设计（Overturned）。

这一构造确保了任何固定策略（如始终跟随仿真器推荐或始终拒绝）都无法同时解决配对中的两个问题。LLM 必须根据工作负载的具体特征，动态判断建模局限是否足以改变设计排序。该设计动机在于消除“盲从”或“盲拒”策略的虚假高分，强制 LLM 进行基于机制的因果推理。

### 判断与倾向性度量

SIRIS 定义两个核心指标来量化 LLM 的决策行为。设 $U$ 为 Upheld 问题上的准确率，$O$ 为 Overturned 问题上的准确率，则 Judgment ($J$) 和 Disposition ($D$) 定义为：

$$
J = \frac{U + O}{2}, \quad D = \frac{U - O}{2}
$$

$J$ 衡量 LLM 在两类问题上的综合判断能力，$D$ 则揭示其决策倾向：$D > 0$ 表示 LLM 倾向于保留仿真器推荐（即使该推荐在 Overturned 问题上错误），$D < 0$ 表示倾向于推翻推荐。该公式的物理含义在于，它将“识别局限”与“修正决策”解耦：一个 LLM 可能准确识别出所有建模局限（高识别率），但因无法正确评估局限的数值影响，导致 $U$ 和 $O$ 同时偏低或 $D$ 极端化，从而暴露其推理链的断裂。

## 实验评估

实验在基于 LLMServingSim 构建的 LLM 服务系统仿真环境中进行，涵盖请求路由、预填充-解码交接及本地调度三类设计问题。评估对象包括 GPT、Grok 和 Gemini 系列的 13 个前沿 LLM。基线包括随机选择（Random）和盲从规则（Follow Rule，即始终选择仿真器推荐的设计）。

| 模型 | 无仿真器证据 Judgment (%) | 盲从规则 Judgment (%) | 扰动仿真器证据 Judgment (%) | 参考仿真器证据 Judgment (%) |
| :--- | :--- | :--- | :--- | :--- |
| GPT-6 Astra | ~50 | 50 | 79 | ~100 |
| GPT-6.1 Sol | ~50 | 50 | 75 | ~100 |
| GPT-6 Sol | ~50 | 50 | 66 | ~100 |
| Grok 4.7 | ~50 | 50 | 67 | ~100 |
| 盲从规则 (Follow Rule) | N/A | 50 | 50 | N/A |

*注：无仿真器证据下所有模型接近随机水平（50%）；盲从规则在 Upheld 问题上准确率为 100%，Overturned 为 0%，故 $J=50, D=+50$。*

主结果显示，在扰动仿真器证据下，GPT-6 Astra 的 Judgment 达到 79%，显著超越盲从规则的 50%，证明前沿 LLM 具备超越盲从的决策判断力。然而，GPT-6 Sol 与 Grok 4.7 的 Judgment 相近（66% vs 67%），但 Disposition 差异巨大（+29 vs +10），表明两者在“保留 vs 推翻”推荐上的决策倾向截然不同。

消融实验进一步揭示了证据组件的影响。当仅提供仿真器代码、成本参数和配置（Code）时，GPT-5.6 Sol 的 Judgment 接近全证据水平；但添加执行记录或预测结果后，Judgment 反而下降，且 Disposition 发生显著偏移。这表明 LLM 对仿真器输出数值存在过度依赖，数值证据反而干扰了其对系统机制的推理。此外，即使 LLM 识别出建模局限，仍有约 25% 的响应选择了错误设计，且这些错误导致 p95 延迟中位数增加 14%。

评估边界方面，SIRIS 仅针对 LLM 服务系统，未覆盖其他系统域；扰动为单一局限，未测试多局限复合效应；且未提供开源代码，复现依赖特定仿真器版本。

## 关联研究分析

从问题动机看，SIRIS 与 Proteus（Duan et al., 2024）均关注仿真器预测的保真度，但 Proteus 评估的是仿真器本身是否保持并行化策略的排序，属于仿真器验证；SIRIS 评估的是 LLM 在仿真器存在已知缺陷时的决策能力，属于评估者能力验证。这一差异源于任务特性的根本不同：前者关注工具精度，后者关注代理对工具局限的元认知。

从方法设计看，SIRIS 与 JudgeBench 等文本评判基准均使用成对或配对问题，但 JudgeBench 依赖人类偏好或客观正确性作为金标准，SIRIS 则通过参考仿真器构造逻辑上必然存在决策反转的配对问题。这种构造方式排除了 LLM 通过记忆训练数据中的系统设计来“作弊”的可能，因为决策反转完全依赖于扰动与特定工作负载的交互，无法通过静态知识获取。然而，SIRIS 未对比专用裁判模型（如 Prometheus）在数值决策任务上的表现，无法判断通用 LLM 的推理缺陷是否可通过领域微调弥补。

## 总结

SIRIS 针对 ADRS 中 LLM 代理无法可靠判断仿真器建模局限决策影响的核心矛盾，提出了基于受控扰动与 Upheld/Overturned 配对问题的评估框架。通过量化 Judgment 与 Disposition，该研究证明了前沿 LLM 在扰动仿真器证据下可达 79% 的 Judgment，显著优于盲从策略，但即使识别出局限，仍有 25% 的决策错误，且数值证据常引发负迁移。该框架的边界在于仅覆盖单一系统域与单一扰动，且未探索专用训练对数值决策能力的提升潜力。当 LLM 在识别出建模局限后仍频繁做出错误决策时，其推理链的断裂究竟源于对数值敏感度的理解不足，还是对系统机制的因果建模缺失，仍需进一步验证。
