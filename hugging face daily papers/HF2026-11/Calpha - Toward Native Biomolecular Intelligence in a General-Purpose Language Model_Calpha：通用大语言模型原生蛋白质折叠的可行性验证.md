> 导读 蛋白质结构预测与通用语言推理长期处于割裂状态，专用模型擅长生成坐标但无法理解自然语言指令，通用大语言模型（Large Language Model, LLM）擅长推理却无法直接输出分子几何结构。现有方法多将结构预测作为外部工具调用，或通过离散化结构破坏几何连续性，导致语言推理无法真正参与坐标生成。Calpha 提出了一种两阶段训练架构，将预训练的流匹配结构头嵌入 LLM 推理流程，使模型在单次前向传播中自主决定何时折叠并生成原子坐标。该工作验证了 LLM 原生输出蛋白质结构的可行性，但在长序列上性能显著低于专用基线，且伴随通用问答能力的下降，其“语言推理驱动结构修正”的核心愿景尚未得到实验证实。

## 研究背景

当科学家希望根据文献描述或突变信息预测蛋白质结构时，现有的专用结构预测模型（如 AlphaFold）无法直接解析自然语言指令，而通用 LLM 虽能理解指令却无法生成符合物理规律的三维坐标。这一矛盾源于两类模型在归纳偏置上的根本差异：结构预测模型依赖几何等变性与进化约束，而 LLM 依赖文本语义与逻辑推理。为了弥合这一鸿沟，研究者尝试将蛋白质序列特征注入 LLM，或让 LLM 调用外部折叠工具，但前者通常仅用于文本问答，后者则使语言推理停留在预测过程之外，无法直接影响原子坐标的生成。

领域内主流路线分为三类：LLM 代理调用外部工具、蛋白质编码器连接 LLM 进行文本描述、以及将结构离散化为 Token 供 LLM 读写。这三类方法均未实现语言推理对结构预测的直接干预。Calpha 试图构建一个通用模型，使其不仅具备折叠能力，还能让模型阅读到的文献信息、科学家的指令以及对机制的推断直接影响预测结果。本文作为该愿景的第一步，聚焦于验证 LLM 能否在保留通用对话能力的同时，原生输出单链蛋白质结构。

## 核心方法

### 方法参照系：LLM 与结构生成头的解耦与耦合

在标准的蛋白质结构预测流程中，序列特征直接输入结构生成网络（如 SimpleFold 或 ESMFold）以输出坐标。Calpha 将该流程改造为 LLM 主导的生成范式：LLM 作为信息路由与条件生成器，结构头作为纯几何生成器。关键差异在于，结构头不再直接接收序列特征，而是仅接收 LLM 处理后的隐藏状态。这种设计旨在让 LLM 的语义理解能力（如识别突变位点、结合位点）通过隐藏状态传递给结构头，从而实现“推理影响结构”。

### 多尺度特征注入与触发机制

为了让 LLM 理解蛋白质序列，Calpha 在输入端引入了多尺度特征注入机制。Qwen3.5-9B 的词表扩展了氨基酸 Token 和 `<structure>` 触发 Token。蛋白质序列以氨基酸 Token 形式嵌入对话轮次，同时，冻结的 ESM2-3B 提取的残基特征通过一个轻量级适配器（Adapter）映射到 LLM 的隐藏层宽度，并叠加到对应的氨基酸嵌入上。

$$
\mathbf{h}_{in} = \mathbf{e}_{aa} + \text{Adapter}(\mathbf{f}_{ESM2})
$$

其中 $\mathbf{e}_{aa}$ 是氨基酸 Token 的嵌入，$\mathbf{f}_{ESM2}$ 是 ESM2 提取的残基特征。该设计动机在于保留 LLM 的文本处理能力，同时注入进化约束信息，使 LLM 在“阅读”序列时即具备结构感知能力。在推理阶段，LLM 根据上下文自主决定是否输出 `<structure>` Token。若输出该 Token，则激活结构头；否则继续生成文本。这种路由机制使折叠决策成为语言模型推理的一部分，而非外部硬编码规则。

### 两阶段训练与条件前端适配

为了将预训练的流匹配结构头（SimpleFold-3B）接入 LLM，Calpha 设计了两阶段训练策略。Stage 1 联合训练 LLM、适配器和一个小型结构头（100M 参数），使 LLM 学会生成适合结构头消费的条件特征。Stage 2 冻结 LLM 和预训练的 SimpleFold-3B 结构头，仅训练一个 8.4M 参数的条件前端（Conditioning Front-end）。

该前端从 LLM 的 9 个不同层（第 0, 4, ..., 32 层）提取残基位置的隐藏状态，通过可学习的 Softmax 混合权重进行聚合，再投影到结构头的输入空间：

$$
\mathbf{c} = \sum_{i=1}^{9} \alpha_i \mathbf{h}_{layer_i}, \quad \alpha_i = \text{softmax}(\mathbf{w})_i
$$

其中 $\mathbf{h}_{layer_i}$ 是第 $i$ 层的隐藏状态，$\alpha_i$ 是混合权重。该设计动机在于解决 LLM 隐藏状态与结构头输入分布不匹配的问题，通过轻量级适配层对齐特征空间，避免重新训练庞大的结构头，同时保留 LLM 在 Stage 1 中习得的语义-结构映射能力。

## 实验评估

实验在三个单链基准上进行：FoldBench-334（开发集）、CASP16（盲测集）和 CAMEO-2025（近期 PDB 结构）。主要指标为 C$\alpha$ 原子上的 TM-score。基线包括专用折叠模型（ESMFold, SimpleFold）、序列-结构模型（ESM3, DPLM-2）以及通用 LLM（GPT, Claude 等）。

| 模型 | FoldBench-334 (All) | CASP16 (All) | CAMEO-2025 (All) |
| :--- | :--- | :--- | :--- |
| **Calpha (LLM + frozen 3B head)** | **0.808** | **0.635** | **0.900** |
| Calpha-Joint (LLM + 100M head) | 0.744 | 0.582 | 0.845 |
| Calpha-Token (DPLM-2 tokens) | 0.660 | 0.569 | 0.800 |
| ESMFold | 0.869 | 0.762 | 0.905 |
| SimpleFold-3B | 0.842 | 0.704 | 0.938 |
| OpenDDE (+MSA) | 0.938 | 0.872 | 0.958 |
| GPT (no tools) | 0.208 | 0.224 | 0.198 |

Calpha 在短序列上具备竞争力，但在长序列（300-600 残基）上性能显著下降。与 ESM2→SimpleFold-3B 基线相比，Calpha 在 300-600 残基区间的平均 TM-score 差值分别为 -0.044（FoldBench）、-0.160（CASP16）和 -0.025（CAMEO-2025），表明 LLM 作为信息瓶颈限制了长程几何细节的保留。此外，蛋白质训练导致 MMLU-Pro 子集准确率从 77.4% 下降至 70.3%，揭示了通用性与专业性之间的权衡代价。

评估边界方面，本文仅评估了 C$\alpha$ 原子精度，未评估侧链几何；仅验证了固定请求下的折叠触发率，未验证语言推理内容是否实际改变了预测坐标。可复现性方面，论文未提供代码，但依赖开源的 Qwen、ESM2 和 SimpleFold 组件。

## 关联研究分析

从问题动机看，Calpha 与 ESM3 均试图统一序列、结构与功能，但路径截然不同。ESM3 通过离散化结构 Token 实现统一建模，牺牲了连续几何的精度以换取语言模型的兼容性；Calpha 则保留连续流匹配生成头，通过隐藏状态条件化实现统一，旨在保留几何精度。然而，Calpha 目前未证明其“语言推理”能像 ESM3 那样通过文本提示直接控制结构生成，其推理能力仍停留在触发折叠决策层面。

从方法设计看，Calpha 与 RFDiffusion 等几何扩散模型相比，放弃了显式的 SE(3) 等变架构，转而依赖 LLM 的通用注意力机制。这一选择使模型能处理自然语言指令，但失去了对物理对称性的显式约束，导致长序列性能下降。相比之下，SimpleFold 等专用模型通过流匹配直接建模坐标分布，在无需语言理解的任务上效率更高。Calpha 的架构创新在于将结构生成“内化”为 LLM 的一个动作，但这一内化目前是以牺牲长程结构精度为代价的。

## 总结

Calpha 针对结构预测与语言推理割裂的矛盾，提出将流匹配结构头嵌入通用 LLM 的架构，通过两阶段训练实现 LLM 原生输出蛋白质结构。实验表明，该模型在短序列上达到 0.808 的 TM-score，验证了可行性，但在长序列上性能显著低于专用基线，且伴随通用问答能力下降。其核心局限在于 LLM 隐藏状态作为条件输入时，对长程几何信息的压缩损失，以及尚未验证语言推理内容对坐标生成的实际影响。当模型面对需要结合文献知识修正结构预测的复杂场景时，其隐藏状态是否足以承载这种细粒度的语义-几何映射，仍是未解之谜。
