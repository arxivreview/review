> 导读：大语言模型智能体在复杂任务中的表现不仅取决于底层模型，更受其外部框架（Harness）——包括提示、工具与控制逻辑——的制约。现有自动框架优化（AHO）方法多聚焦于单一任务质量提升，忽略了实际部署中至关重要的执行成本约束。当引入成本作为第二优化目标时，传统方法在中间评估阶段过早应用最终部署偏好，导致那些短期成本增加但长期能提升能力的中间解被错误剪枝。ParetoSaddler 提出了一种分阶段优化框架，将中间候选晋升与最终部署选择解耦，利用贝叶斯自举支持在重复执行中筛选具有可信质量或成本改进的候选。该研究揭示了在离散搜索空间中，多目标帕累托优化不仅能避免质量牺牲，甚至能引导搜索发现比单目标优化更优的解，但其在极端成本约束下的鲁棒性仍有待验证。

## 研究背景

当智能体在长程任务中执行时，其轨迹具有高度随机性，同一框架在不同执行中可能产生截然不同的质量与成本结果。这种执行随机性使得单次评估无法可靠反映框架的真实能力，而盲目增加执行次数又会带来高昂的计算开销。为了在有限预算下优化框架，现有方法通常采用分阶段评估策略，即先在少量样本上筛选候选，再对通过筛选的候选进行广泛评估。然而，当优化目标从单一质量扩展为质量与成本的双目标时，分阶段评估面临一个根本性矛盾：中间阶段的筛选标准若直接采用最终部署偏好，会过早拒绝那些当前成本较高但解决了关键失败模式（如提前终止）的更新，从而阻断后续优化路径。

自动框架优化（AHO）领域目前主要分为搜索式（如 Meta-Harness）和学习式（如 AutoSaddler）两类范式。前者通过全量评估迭代更新，后者通过小批量增量更新并依赖分阶段筛选。尽管这些方法在单目标质量优化上取得了进展，但在多目标场景下，它们缺乏对中间解保留机制的系统性设计。特别是在质量与成本存在耦合关系时（例如，更高质量的推理往往需要更多 Token），如何在不牺牲最终部署质量的前提下，保留那些具有潜在长期价值的中间解，成为当前 AHO 方法未能有效解决的关键瓶颈。

## 核心方法

### 分阶段优化与帕累托晋升机制

ParetoSaddler 建立在分阶段离线学习框架之上，其核心创新在于将优化过程划分为“中间晋升”与“最终选择”两个独立阶段。在标准分阶段流程中，候选框架通常在局部筛选阶段即需满足预设的权衡标准，这导致了搜索空间的过早收缩。ParetoSaddler 引入帕累托感知晋升规则，在中间阶段仅要求候选在质量或成本任一维度上具有统计显著的可信改进，而不强制其满足最终的质量-成本权衡偏好。这一设计动机在于避免局部最优陷阱，确保那些暂时违反成本约束但能解锁后续能力增益的中间解得以保留，供后续迭代进一步修正其低效部分。

### 贝叶斯自举统计筛选

针对执行随机性导致的评估噪声，ParetoSaddler 采用贝叶斯自举（Bayesian Bootstrap）方法对候选框架的质量与成本差异进行统计推断。在每次迭代中，父框架与候选框架在相同的筛选样本上进行 $R$ 次重复执行，生成联合观测数据。通过从狄利克雷分布中采样权重，计算候选优于父框架的后验概率，即帕累托支持度。只有当支持度超过阈值 $\gamma$ 时，候选才被晋升至开发集评估。

$$
\text{Promote}(h'_t) \iff \mathbb{P}_{\mathbf{w} \sim \text{Dirichlet}(\mathbf{1}_R)} \left( \Delta Q_t > 0 \land \Delta C_t \le \epsilon_C \right) \lor \left( \Delta C_t < 0 \land \Delta Q_t \ge -\epsilon_Q \right) \ge \gamma
$$

该公式表示，通过贝叶斯自举重采样，计算候选框架在质量提升且成本未显著增加，或成本降低且质量未显著下降条件下的后验概率。若该概率超过阈值 $\gamma$，则晋升候选。这一机制有效过滤了由执行随机性引起的虚假改进，确保晋升的候选具有统计意义上的可信度，而非仅仅是单次运行的偶然结果。

### 部署偏好与最终选择解耦

在优化预算耗尽后，ParetoSaddler 才应用最终部署偏好 $\pi$ 从保留的候选集中选择最终框架。部署偏好可以是加权求和、约束优化或帕累托集选择。对于帕累托集优化，框架保留非支配解集，允许在部署时根据具体需求选择质量极端或成本极端解。对于约束优化，则在满足质量下限的前提下最小化成本。这种解耦设计使得优化过程能够探索更广阔的质量-成本权衡空间，最终选择阶段仅需在已验证的可行解中进行偏好匹配，避免了优化过程中的偏好干扰。

## 实验评估

实验在 ClawMark 和 GAIA2 两个长程智能体基准上进行，采用领域不相交的划分策略，确保测试集任务与优化集任务在场景上完全隔离。基线包括搜索式的 Meta-Harness 和学习式的 AutoSaddler（仅质量优化）。ParetoSaddler 在两个基准上均实现了质量与成本的双重改进。在 ClawMark 上，质量从 70.86% 提升至 81.35%，成本从 $1.17 降至 $1.01；在 GAIA2 上，质量从 56.22% 提升至 62.89%，成本从 $0.78 降至 $0.45。值得注意的是，ParetoSaddler 的质量极端解（PS-PARETOQ）在质量上分别超越单目标优化的 AutoSaddler 7.49 和 5.56 个百分点，且成本更低，表明联合优化并未牺牲质量，反而通过保留多样化中间解引导搜索发现了更优解。

| 方法 | 基准 | 质量 (%) | 成本 ($/task) |
| :--- | :--- | :--- | :--- |
| Default Agent | ClawMark | 70.86 ± 2.29 | 1.17 ± 0.17 |
| AS-QUALITY | ClawMark | 73.86 ± 3.54 | 1.24 ± 0.04 |
| PS-PARETOQ | ClawMark | **81.35 ± 3.11** | **1.01 ± 0.02** |
| Default Agent | GAIA2 | 56.22 ± 1.07 | 0.78 ± 0.08 |
| AS-QUALITY | GAIA2 | 57.33 ± 0.67 | 0.61 ± 0.03 |
| PS-PARETOQ | GAIA2 | **62.89 ± 2.14** | **0.45 ± 0.02** |

消融实验验证了贝叶斯筛选与重复执行的有效性。将贝叶斯筛选替换为均值比较，PS-PARETOQ 的质量从 81.35% 降至 76.53%，成本从 $1.01 升至 $1.15，表明统计筛选能有效过滤噪声导致的虚假晋升。将重复执行次数从 3 次减至 1 次，质量从 81.35% 降至 75.71%，证实了重复执行对提供可靠优化证据的必要性。评估协议中，成本计算采用冷启动约定，即首次调用按新鲜输入计费，避免了缓存状态对成本评估的干扰，增强了结果的可复现性。

## 关联研究分析

从问题动机看，ParetoSaddler 与 OrthAlign 均处理多目标冲突，但二者针对的优化空间截然不同。OrthAlign 在连续参数空间中通过梯度正交化解决有用性与无害性的冲突，依赖可微分的损失函数；而 ParetoSaddler 在离散框架空间中通过帕累托前沿保留非支配解，无需梯度信息。这种差异源于任务特性：模型参数优化可通过反向传播直接调整，而框架优化涉及离散组件（如工具调用逻辑）的修改，只能通过黑盒搜索进行。ParetoSaddler 的帕累托晋升机制实际上是在离散搜索中模拟了连续优化中的“探索-利用”平衡，但其有效性依赖于执行反馈的统计显著性，这在低信噪比场景下可能失效。

从方法设计看，ParetoSaddler 与 AutoSaddler 共享分阶段评估框架，但 AutoSaddler 仅优化质量，其筛选标准单一。ParetoSaddler 将筛选标准扩展为多目标帕累托支持度，这一改动看似简单，实则改变了搜索动力学。AutoSaddler 的贪心筛选容易陷入局部质量峰值，而 ParetoSaddler 通过保留成本-质量权衡的多样化解，避免了过早收敛。然而，ParetoSaddler 未探讨当目标数量超过两个（如加入安全性）时，帕累托前沿的稀疏性是否会导致筛选效率急剧下降，这一高维多目标场景的适用性仍是未知数。

## 总结

ParetoSaddler 针对长程智能体框架优化中质量与成本联合优化时中间解易被过早剪枝的问题，提出了一种将中间晋升与最终选择解耦的框架。通过贝叶斯自举统计筛选和帕累托感知晋升，该方法在 ClawMark 和 GAIA2 上实现了质量与成本的双重提升，且质量极端解优于单目标优化基线。其核心贡献在于证明了在离散搜索空间中，保留多样化中间解能引导搜索发现更优解，而非仅仅在权衡中妥协。然而，该方法依赖重复执行以获取统计显著性，在计算预算极度受限或执行随机性极高的场景下，其筛选可靠性可能下降。当优化目标扩展至三个或更多维度时，帕累托前沿的稀疏性是否会削弱晋升机制的有效性，论文未给出回答。
