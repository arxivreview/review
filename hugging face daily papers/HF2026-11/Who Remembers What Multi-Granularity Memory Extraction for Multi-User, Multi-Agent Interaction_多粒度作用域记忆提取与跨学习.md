# HuggingFace最新推荐论文 ｜Who Remembers What? Multi-Granularity Memory Extraction for Multi-User, Multi-Agent Interaction ｜多粒度作用域记忆提取与跨学习

研究机构：美国南加州大学

作者：Yunzhe Wang、Mesut Erhan Unal、Sheng Zhang 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2611.10439)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2611.10439)

> 导读 在多用户与异构智能体共存的环境中，如何让智能体从彼此的经验中获益，同时确保私有信息不泄露，是现有记忆系统难以兼顾的矛盾。现有方法要么将记忆视为全局共享池，导致隐私泄露；要么严格隔离，导致知识无法跨用户或跨智能体复用。MIXUA 将记忆条目分配至用户-智能体对、用户、智能体或全局四个作用域，通过双流写入与周期性审查机制，在效用与隐私之间建立动态平衡。该工作填补了异构群体中知识效用与隐私权衡的评估空白，但其动态作用域分配的计算开销与高级攻击下的鲁棒性仍存疑。

## 研究背景

当智能体在开放环境中执行任务时，其经验往往包含两类截然不同的信息：一类是通用的技术缺陷或工具调用技巧，另一类是特定用户的偏好或隐私数据。若将所有经验存入单一共享记忆库，通用知识虽能跨用户复用，但隐私数据会随检索注入其他用户的上下文，造成泄露；若严格隔离每个用户-智能体对的记忆，隐私得以保护，但一个用户发现的通用缺陷无法惠及他人，导致重复试错。这一困境源于传统记忆系统缺乏对知识“受众范围”与“披露边界”的显式建模。

现有自进化智能体系统多聚焦于单用户或固定团队内的经验共享，如 MemGPT 通过虚拟内存分页解决上下文限制，Generative Agents 通过反思机制提升行为连贯性，但这些设计默认记忆在单一信任边界内流动。近期出现的跨用户共享系统（如 SkillClaw、FederatedSkill）虽尝试池化经验，但往往预设了固定的接收者或仅支持同构智能体间的联邦交换，未能处理异构智能体与独立用户混合场景下的细粒度访问控制。MIXUA 针对这一盲区，提出“跨学习”范式，将记忆共享问题形式化为受众路由问题，首次在多用户异构智能体环境中同时评估任务效用、个性化保留与隐私泄露。

## 核心方法

### 方法参照系：受众路由与披露边界

MIXUA 将跨学习建模为决定“谁读取每条记忆”的受众路由问题。在标准的外部记忆系统中，记忆条目通常仅包含内容向量与元数据，检索时依赖语义相似度。MIXUA 在写入阶段引入两个关键属性：泛化范围 $G(e)$（该条目对哪些用户-智能体对有效）与披露边界 $D(e)$（该条目在不泄露源用户隐私的前提下可触达的最大范围）。系统强制要求授权受众 $Aud(e)$ 满足：

$$
Aud(e) \subseteq G(e) \cap D(e)
$$

该约束确保有用知识能触达所有受益者，而私有知识严格保留在所有者作用域内。这一形式化将记忆管理从单纯的存储检索提升为基于属性的访问控制问题。

### 双流写入与四粒度作用域

传统记忆写入通常由单一 LLM 处理完整轨迹，易导致隐私内容混入共享记忆。MIXUA 采用双流写入机制：将轨迹拆分为“可复用流”与“受保护流”，分别送入两个隔离的写入器。可复用流生成的条目可进入任意作用域，而受保护流生成的条目仅能写入所有者专属的 USER 或 PAIR 作用域。系统定义四个作用域：PAIR（仅特定用户-智能体对）、USER（特定用户跨所有智能体）、AGENT（特定智能体跨所有用户）与 GLOBAL（全局共享）。

这一设计解决了此前方法在异构场景下的失效：当用户偏好与智能体特性冲突时（如要求冗长智能体简洁回复），PAIR 作用域可存储此类条件化知识；当通用缺陷被发现时，GLOBAL 作用域确保其跨用户复用。双流隔离机制从架构上阻断了隐私内容进入共享作用域的路径，而非依赖写入器的自我标注。

### 周期性存储审查与动态重作用域

单轨迹写入易导致作用域分配过窄或过宽，且不同轨迹可能产生重复条目。MIXUA 引入周期性存储审查（Store Review），在每轮交互后以全局视角重新评估所有条目。审查过程执行三项操作：晋升（将独立来源验证的窄作用域条目提升至更宽作用域）、降级（将失败或矛盾条目限制在更窄作用域）与合并（在目标作用域内整合相似条目）。

该机制解决了静态作用域分配无法适应知识演化动态性的问题。例如，一个最初仅对特定用户有效的工具调用技巧，若在多个用户-智能体对上被验证成功，审查机制可将其晋升至 GLOBAL 作用域，从而扩大知识复用范围。审查过程由 LLM 执行，确保作用域调整与知识语义一致性同步。

## 实验评估

实验基于自建基准 CROSSLEARNBENCH，包含 AutoCodeBench 等七个任务数据集，并注入用户偏好与隐私探针。基线覆盖 No Memory、PAIR-only、GLOBAL-only 等单作用域系统，但未包含 HippoRAG、Mem0 等经典结构化/扁平检索基线在同等隐私约束下的表现，因后者未原生支持多用户异构场景的受众路由。

| 方法 | 通过率提升 (pp) | 偏好保留率 (%) | 隐私泄露率 (%) |
| :--- | :--- | :--- | :--- |
| No Memory | 0.0 | 0.0 | 0.0 |
| GLOBAL-only | +11.5 | 10.0 | 5.5-26.3 |
| PAIR-only | +6.2 | 79.0 | 0.0 |
| MIXUA (LLM+R) | +16.3 | 90.0 | 0.9-4.8 |

MIXUA (LLM+R) 在通过率上较 No Memory 提升 16.3 个百分点，较 GLOBAL-only 提升 4.8 个百分点，同时保持 90% 的偏好保留率，隐私泄露率控制在 4.8% 以下。消融实验显示，移除 GLOBAL 作用域导致通过率提升从 15.3 降至 9.0，移除 USER 作用域导致偏好保留率从 90% 降至 81%，验证了四作用域协同的必要性。

评估边界方面，CROSSLEARNBENCH 的隐私探针主要检测静态事实泄露，未覆盖知识库中提到的“记忆投毒”等高级对抗攻击。此外，动态作用域分配与周期性审查的计算开销未与 TEE 方案进行量化对比，可复现性受限于未公开代码与特定 LLM 依赖。

## 关联研究分析

从问题动机看，MIXUA 与 Collaborative Memory 均关注多用户记忆共享，但 Collaborative Memory 依赖预定义访问策略，将受众固定为“私有”或“共享”二元状态，无法处理异构智能体间的细粒度知识路由。MIXUA 将受众扩展至二维矩阵（用户×智能体），并通过动态审查实现作用域演化，这一差异源于任务特性：前者假设信任边界稳定，后者假设知识效用随交互动态变化。

从方法设计看，MIXUA 与 FederatedSkill 均尝试跨用户知识交换，但 FederatedSkill 采用联邦学习范式，在客户端间交换蒸馏后的技能补丁，隐含假设客户端同构且隐私保护依赖梯度聚合。MIXUA 直接操作结构化记忆条目，通过双流写入与披露边界约束实现隐私保护，更适用于异构智能体场景。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

MIXUA 针对多用户异构智能体环境中知识效用与隐私保护的矛盾，提出四粒度作用域记忆系统与双流写入机制，通过受众路由与披露边界约束实现细粒度知识共享。实验表明，MIXUA 在 CROSSLEARNBENCH 上较 No Memory 提升通过率 16.3 个百分点，偏好保留率达 90%，隐私泄露率低于 4.8%。其边界在于动态作用域分配的计算开销未量化，且隐私评估未覆盖高级对抗攻击。当智能体数量扩展至数百个异构配置时，周期性审查的合并冲突与晋升延迟是否会成为系统瓶颈，论文未给出回答。
