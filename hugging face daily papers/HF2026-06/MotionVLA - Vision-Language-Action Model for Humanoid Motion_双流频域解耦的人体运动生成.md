作者：Nonghai Zhang、Siyu Zhai、Yanjun Li 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.15142)

> 文本驱动人体运动生成（Text-to-Motion Generation, T2M）旨在从自然语言合成逼真且物理合理的人体动作，但现有离散自回归方法将异构运动信号压缩至统一码本，导致高频物理动力学丢失。本文指出关节位置与速度在频域能量分布上存在显著差异，提出双流频域解耦分词器（DSFT）与视觉-语言-动作（VLA）框架 MotionVLA。该方法将运动拆分为低频姿态流与高频物理流独立量化，并通过因果注意力实现语义到物理的层级生成。其价值在于从表征源头缓解长序列生成的物理失真，但受限于固定流划分与轻量级骨干，在纯文本基准上的保真度仍略逊于最强基线。

## 研究背景

理解本文需厘清离散自回归生成中量化误差的累积机制。当运动序列被映射为离散 Token 时，量化器需平衡重建保真度与序列压缩率。若运动信号在频域上呈现非均匀分布，单一量化空间会因低频成分主导而系统性丢弃高频细节。这种表征偏置在自回归解码中随时间步累积，最终表现为脚部滑动或关节抖动等物理伪影，直接制约了长时程动作生成的可用性。

T2M 领域的主流路线分为连续扩散与离散自回归两大阵营。扩散模型在连续保真度上占优，但推理速度慢；离散自回归模型（如 T2M-GPT、MoMask）凭借 Transformer 架构实现了强语义组合性，却长期受困于累积误差。近期研究引入 DCT 变换以改善长序列生成，但仍未解决异构信号共享码本导致的频谱偏置问题。本文切入点在于揭示人体运动在频域上的双峰特性：关节位置能量高度集中于低频，而关节速度能量分散于高频。这一发现表明，将两者强行压缩至同一量化空间是物理伪影的结构性根源，而非单纯模型容量不足所致。

## 核心方法

### 方法参照系

标准离散自回归 T2M 流程将运动序列经 VQ-VAE 或 BPE 量化为单一 Token 流，再由 Transformer 自回归生成。本文问题与该通用流程的关键差异在于：运动信号包含低频姿态语义与高频物理动力学两类统计特性截然不同的成分，单一码本无法同时满足两者的量化需求。

### 双流频域解耦分词器（DSFT）

DSFT 在量化环节引入频域解耦，将运动序列 $\mathbf{M} \in \mathbb{R}^{[T] \times [D]}$ 拆分为 Base 流（位置/旋转）与 Phys 流（速度）。设计动机是消除单一码本中低频姿态对高频速度的量化压制。对每维信号独立应用离散余弦变换（DCT），并截断不同数量的系数：

$$
\mathbf{M}_{base}^{trunc} = \text{DCT}(\mathbf{M}_{base})_{1:K_b}, \quad \mathbf{M}_{phys}^{trunc} = \text{DCT}(\mathbf{M}_{phys})_{1:K_p}
$$

其中 $K_b=5$ 覆盖 Base 流约 86%-93% 能量，$K_p=25$ 覆盖 Phys 流约 80% 能量。截断后的系数分别经独立 BPE 压缩为离散 Token。该设计使高频物理信号获得独立的频率预算，避免了在统一码本中被视为噪声丢弃，从表征层面保留了接触稳定性所需的动力学细节。

### 层级自回归生成与相位约束

MotionVLA 将 Base 与 Phys Token 排列于统一序列 $s = [\mathcal{M}_{BOS}, b_1, ..., b_N, \mathcal{M}_{SEP}, p_1, ..., p_M, \mathcal{M}_{EOS}]$，由 Qwen3.5 骨干自回归生成。设计动机是利用物理动力学对姿态结构的条件依赖，使 Phys 预测能访问完整姿态上下文。训练采用掩码下一 Token 预测目标：

$$
L_{train} = \text{CE}(\mathbf{z} + \mathbf{m}, \mathbf{y})
$$

其中 $\mathbf{m}$ 为对数掩码，限制预测仅针对有效运动 Token。推理时施加相位感知约束：生成 $\mathcal{M}_{SEP}$ 前仅允许 Base Token，之后仅允许 Phys Token。该机制强制语义结构先于物理动力学生成，确保因果注意力下物理信号预测基于完整姿态语境，而非纠缠的混合表示。

## 实验评估

实验在 HumanML3D（纯文本）与 ViMoGen-228K/MBench（场景感知）两个设置下进行。基线覆盖扩散（MDM、MotionDiffuse）、自回归（T2M-GPT、MoMask）及 VLA（ViMoGen）三类路线，但缺失 Flow Matching 类方法（如 HY-Motion）对比。在 MBench 上，MotionVLA 使用 2B 骨干，在 Motion-Condition Consistency（0.55）与 Foot Sliding（0.0049）上取得最优，优于 ViMoGen（0.53, 0.0064）；在 HumanML3D 上，其 FID 为 0.071，R-Precision Top-1 为 0.507，均低于 MoMask 的 0.045 与 0.521，表明在纯文本任务上轻量级骨干的保真度仍受限制。

| 方法 | Motion-Cond. Consistency ↑ | Foot Sliding ↓ | FID (HumanML3D) ↓ | R-P Top-1 ↑ |
| :--- | :--- | :--- | :--- | :--- |
| MoMask | 0.38 | 0.0147 | 0.045 | 0.521 |
| ViMoGen | 0.53 | 0.0064 | – | – |
| MotionVLA | **0.55** | **0.0049** | 0.071 | 0.507 |

消融实验显示，Phys 流截断长度 $K_p$ 从 10 增至 25 时，Foot Sliding 从 0.0062 降至 0.0049，但 $K_p=30$ 时回升至 0.0052，表明过大的频率预算引入冗余 Token 反而损害生成质量。骨干规模从 0.8B 扩至 2B 带来最大增益，2B 至 9B 收益递减，暗示当前数据规模下 Token 表征的信息容量限制了大模型的边际收益。

评估边界方面，MBench 侧重物理质量但样本量仅 450，HumanML3D 缺乏场景条件。论文未报告长序列（>10 秒）的累积误差专项测试，也未提供置信区间。代码已开源，但 DSFT 分词器需在每个数据集上独立训练，增加了复现成本。

## 关联研究分析

从问题动机看，本文与 MoMask 同属离散自回归路线，但 MoMask 通过掩码并行生成解决顺序依赖瓶颈，而 MotionVLA 聚焦量化表征本身的频谱偏置。MoMask 在 HumanML3D 上 FID 更低（0.045 vs 0.071），说明其单流量化在短序列保真度上仍有优势；但 MotionVLA 在 MBench 上 Foot Sliding 显著更优（0.0049 vs 0.0147），揭示单流量化在长时程物理稳定性上的结构性缺陷。这一差异根源在于任务特性：HumanML3D 序列较短，累积误差尚未显现；MBench 强调物理质量，对高频动力学保留更敏感。

从方法设计看，本文与 ViMoGen 共享 VLA 框架，但 ViMoGen 采用单流 Tokenizer，导致时序漂移随时间累积（如图 1 所示）。MotionVLA 通过 Base-Phys 层级生成缓解此问题，但固定流划分（190/73 维）可能不适用于所有运动类型。与 FlowCoMotion 等混合表示方法相比，MotionVLA 未引入连续潜变量分支，完全依赖离散 Token 重建物理细节，这在复杂接触动作中可能面临重建误差累积的挑战。

## 总结

本文核心矛盾在于离散自回归生成中异构运动信号的量化偏置导致物理失真。现有方法通过增强模型容量或后处理修正伪影，但未触及量化表征的结构性缺陷。MotionVLA 基于频域能量双峰特性，将运动解耦为独立量化的 Base 与 Phys 流，并通过相位约束自回归生成实现语义到物理的层级建模。实验证明其在场景感知任务上 Foot Sliding 降低至 0.0049，Diversity 差距缩小超 50%，但在纯文本基准上 FID 仍高于 MoMask。其边界在于固定流划分与 2B 骨干的容量限制，当运动类型涉及复杂全身协调时，预设的 Base-Phys 分割是否仍能准确捕捉动力学依赖，论文未给出回答。
