# HuggingFace最新推荐论文 ｜ARM: An AutoRegressive Large Multimodal Model with Unified Discrete Representations ｜统一离散表征自回归多模态模型

研究机构：复旦大学

作者：Junke Wang、Xiao Wang、Jiacheng Pan 等 19 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.11188)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.11188)

> 多模态大模型长期面临理解与生成任务对视觉表征需求割裂的困境，现有方案多依赖双编码器或牺牲理解性能以换取生成保真度。ARM 通过训练一个同时保留语义判别力与像素细节的统一离散视觉分词器，构建了单骨干自回归架构。该模型结合大规模交错序列训练与基于组相对策略优化的强化学习对齐，实现了理解、生成与编辑能力的协同提升。尽管其在多项基准上达到领先性能，但依赖外部扩散解码器进行像素渲染的架构设计，限制了其作为纯自回归系统的完整性与推理效率。

## 研究背景

当多模态模型试图同时执行图像理解与生成时，视觉表征的语义抽象层级与像素细节保真度之间存在根本冲突。理解任务依赖高层语义特征以支持推理，而生成任务需要底层高频细节以重建图像，这种需求差异导致单一视觉编码器难以兼顾两者。为弥合这一鸿沟，研究界引入了向量量化自编码器（VQ-VAE）等离散化技术，将连续图像映射为离散 Token 序列，使 Transformer 能够以自回归方式处理视觉数据。然而，传统离散化过程往往引入量化误差，导致生成图像细节模糊，且光栅扫描顺序破坏了二维空间结构，制约了全局一致性。

自回归视觉生成领域的主流路线在“离散 Token 的语义-细节平衡”与“生成顺序的空间效率”上持续博弈。早期工作如 VQGAN 通过对抗损失提升重建保真度，但语义对齐能力较弱；VAR 模型提出的 Next-Scale 预测范式虽解决了空间错位问题，但其离散 Token 仍主要服务于生成，难以直接支撑复杂的视觉理解任务。现有统一多模态模型如 Janus-Pro 和 Bagel 采用双编码器架构，分别处理理解与生成，虽性能强劲但增加了系统复杂度与推理开销，且无法实现表征层面的真正统一。ARM 的切入点在于证明，通过精心设计的多目标监督信号，单一离散分词器可以同时满足理解所需的语义判别力与生成所需的像素细节，从而在统一的自回归框架内实现多模态能力的内生协同。

## 核心方法

### 统一离散视觉分词器架构

ARM 的视觉分词器基于冻结的 SigLIP2 编码器，通过有限标量量化（FSQ）将高维特征映射为紧凑的离散 Token。与仅依赖重建损失的 VQ-VAE 不同，该分词器采用四重互补监督信号联合训练，旨在同时优化语义对齐与像素保真度。其核心优化目标 $L_{Tok}$ 定义为：

$$ L_{Tok} = \lambda_{cap} L_{cap} + \lambda_{pix} L_{pix} + \lambda_{sig} L_{sig} + \lambda_{feat} L_{feat} $$

其中 $L_{cap}$ 为基于冻结语言模型的标题生成交叉熵损失，$L_{pix}$ 为像素空间扩散重建损失，$L_{sig}$ 为 SigLIP 文本-图像对比损失，$L_{feat}$ 为特征蒸馏损失。这种设计动机在于，单一重建损失易导致码本利用率低且语义模糊，而引入语义对比与标题生成约束，迫使离散 Token 空间在保留像素细节的同时，形成与语言模态对齐的语义结构，从而解决传统离散分词器在理解任务中表现不佳的问题。

### 基于组相对策略优化的偏好对齐

在自回归预训练与监督微调之后，ARM 引入组相对策略优化（GRPO）阶段，专门针对视觉 Token 预测进行偏好对齐。该阶段不更新语言模型骨干，仅优化视觉 Token 的生成策略。给定提示 $x$，策略模型 $\pi_\theta$ 采样 $K$ 个视觉 Token 序列 $\{y_{[1]}, \dots, y_{[K]}\}$，经扩散解码器渲染为图像后，由 GPT 系列模型作为奖励模型打分。优势函数 $A_k$ 通过组内归一化计算：

$$ A_k = \frac{r_k - \text{mean}(\mathbf{r})}{\text{std}(\mathbf{r})} $$

策略更新目标为最大化期望优势，同时施加 KL 散度正则化以限制策略偏离参考模型。这一设计的关键在于，离散 Token 接口使得视觉生成的偏好优化可以复用语言模型成熟的 RLHF 范式。实验发现，这种基于 Token 级别的偏好优化不仅提升了目标任务（如文生图或编辑）的性能，还引发了跨任务协同效应，即优化文生图会同步提升编辑能力，反之亦然，且未损害多模态理解性能。

## 实验评估

ARM 在 ImageNet 256x256 类别条件生成、GenEval、WISE 及 GEdit-Bench 等基准上进行了全面评估。基线覆盖包括连续表征统一模型（如 Janus-Pro, Bagel）、离散表征统一模型（如 Emu3, VILA-U）以及扩散模型（如 FLUX.1, SD3）。在理解任务上，ARM 在 MMMU 上取得 40.2 分，POPE 上取得 87.3 分，显著优于 Emu3（31.6）和 VILA-U（未报告 MMMU），接近连续模型 Janus-Pro（41.0）。在生成任务上，ARM-RL 在 GenEval 上达到 0.86，WISE 上达到 0.56，超越了离散模型 Emu3（0.54）和 VILA-U（0.31），并与扩散模型 FLUX.1（0.66 GenEval）具有竞争力。

| 模型 | 类型 | MMMU | POPE | GenEval | WISE | GEdit G_O |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Emu3 | AR | 31.6 | 85.2 | 0.54 | 0.39 | - |
| VILA-U | AR | - | 85.8 | - | 0.31 | - |
| Janus-Pro | AR | 41.0 | 87.4 | 0.80 | 0.35 | - |
| FLUX.1 | Dif. | - | - | 0.66 | 0.50 | - |
| ARM | AR | 40.2 | 87.3 | 0.79 | 0.50 | 5.75 |
| ARM-RL | AR | 41.0 | 87.11 | 0.86 | 0.56 | 6.68 |

消融实验揭示了分词器监督信号的关键作用。仅使用标题与像素损失（$L_{cap}, L_{pix}$）时，ImageNet 零样本准确率仅为 0.2，码本利用率 69.4%。加入 SigLIP 对比损失（$L_{sig}$）后，准确率跃升至 79.4，但 PSNR 从 15.2 降至 9.3，表明语义聚类牺牲了部分像素细节。进一步加入特征蒸馏损失（$L_{feat}$）后，PSNR 恢复至 19.6，准确率保持 80.2，码本利用率提升至 75.6%。这表明 $L_{feat}$ 在语义对齐与细节保留之间起到了关键的平衡作用。此外，RL 阶段显示，单独进行文生图 RL 可使编辑分数从 5.75 提升至 5.92，单独编辑 RL 可使 GenEval 从 0.79 提升至 0.80，联合 RL 则达到最优的 6.68 GEdit 分数，验证了跨任务协同效应。

评估边界方面，ARM 依赖 FLUX.1 作为潜空间扩散解码器进行像素渲染，这意味着其生成保真度部分依赖于外部扩散模型的容量，而非纯自回归解码。论文未报告具体的推理延迟与加速比，且 RL 阶段使用 GPT-o3 和 GPT-4.1 作为奖励模型，引入了外部模型依赖，可能影响结果的独立性与可复现性。代码已开源，但大规模预训练数据（2.5T tokens）的具体构成未完全公开，限制了第三方复现的可行性。

## 关联研究分析

从问题动机看，ARM 与 Janus-Pro 和 Bagel 的核心差异在于视觉表征的统一性。Janus-Pro 和 Bagel 采用双编码器架构，分别使用语义编码器（如 CLIP）和生成编码器（如 VQ-VAE）处理理解与生成任务，这种设计虽性能强劲，但导致同一视觉输入在上下文中存在冗余表征，增加了推理开销且阻碍了跨模态推理的深度融合。ARM 通过单一 FSQ 分词器解决这一问题，其关键在于四重损失函数中 $L_{sig}$ 和 $L_{feat}$ 的引入，强制离散 Token 空间保留 SigLIP 特征的语义结构。这一设计是否能在更高分辨率或更复杂场景下维持语义-细节平衡，论文未提供充分证据，因为其主要评估集中在 256x256 至 1024x1024 分辨率，且未对比双编码器在极端长序列下的内存效率。

从方法设计看，ARM 与 VAR 和 LlamaGen 等纯生成自回归模型的区别在于其统一建模目标。VAR 专注于 Next-Scale 预测以提升生成效率，其 Token 设计主要服务于重建保真度，缺乏显式的语义对齐机制，导致其难以直接用于理解任务。ARM 采用 Next-Token 预测，但通过 $L_{cap}$ 和 $L_{sig}$ 将语言模态信息注入 Token 空间，使得自回归模型能够同时处理文本理解与图像生成。这种设计使得 ARM 能够应用 GRPO 进行偏好对齐，而纯生成模型通常缺乏这种与语言模型兼容的优化接口。然而，ARM 依赖扩散解码器进行最终像素生成，这与 VAR 等纯自回归解码器不同，可能限制了其在实时生成场景下的应用潜力，因为扩散解码器通常需要多步采样。

## 总结

ARM 旨在解决多模态模型中理解与生成任务因视觉表征需求不同而导致的架构割裂问题。其切入点在于证明单一离散分词器可通过多目标监督同时保留语义与细节，从而在统一自回归框架内实现能力协同。通过训练基于 SigLIP2 的 FSQ 分词器，结合大规模交错序列训练与 GRPO 偏好对齐，ARM 在 MMMU 上达到 40.2 分，GenEval 上达到 0.86 分，验证了统一离散表征的有效性。然而，其架构依赖外部扩散解码器进行像素渲染，且 RL 阶段依赖 GPT 系列模型作为奖励模型，限制了其作为独立自回归系统的完整性与推理效率。当移除扩散解码器或更换为纯自回归解码器时，ARM 的生成保真度与语义对齐能力是否仍能维持当前水平，论文未给出回答。
