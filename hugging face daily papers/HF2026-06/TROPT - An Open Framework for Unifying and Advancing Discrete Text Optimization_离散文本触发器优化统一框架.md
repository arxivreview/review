研究机构：以色列特拉维夫大学

作者：Matan Ben-Tov、Mahmood Sharif

论文原文见 [arXiv](https://arxiv.org/abs/2606.23496)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.23496)

> 离散文本触发器优化旨在搜索能引导模型产生特定输出的短文本序列，是越狱攻击与模型审计的核心工具。现有优化器实现分散于孤立代码库，绑定特定模型与目标，导致跨域迁移成本高且缺乏受控对比，阻碍了安全评估的可靠性与算法进步。本文提出 TROPT，将优化器、损失函数与模型后端解耦为标准化模块，通过统一接口实现任意组件组合与受控基准测试。该框架解决了工程碎片化问题，但仅覆盖单轮静态输入优化，未触及多轮对话或系统级动态交互场景。

## 研究背景

理解本文需先厘清离散搜索优化器在安全攻防中的角色。越狱攻击的本质是在输入空间 $\mathcal{X}$ 中搜索对抗样本 $x_{adv}$，使模型 $f$ 违反安全约束 $C$ 输出有害内容。早期方法如 HotFlip 通过梯度引导翻转单个 token，GCG 则迭代优化多目标损失生成通用后缀。这些方法虽有效，但各自实现耦合了特定的模型架构、损失定义与输入模板，导致一个领域（如 LLM 越狱）的优化器难以直接迁移至另一领域（如稠密检索器投毒）。

离散优化器研究面临两大瓶颈：一是采纳摩擦，现有开源实现分散且缺乏标准化接口，研究者需大量工程工作才能复用或适配新模型；二是进度追踪困难，不同优化器在各自论文中基于不同模型、设置与耦合增强进行评测，导致纯优化器性能不可比，阻碍了有效方法的识别与迭代。例如，GCG 的成功源于对早期算法的细微修改，但后续变体（如 MAC、PAL）是否更优，缺乏统一基准下的验证。本文切入点在于将离散优化器抽象为独立算法模块，通过统一基础设施消除工程摩擦，实现跨域复用与受控对比。

## 核心方法

### 方法参照系

离散文本触发器优化可形式化为在可行触发器集合 $T$ 中搜索最小化损失 $L$ 的序列。给定目标模型 $M$、损失 $L$ 及输入模板 $\{p_i, s_i, y_i\}$，最优触发器为：

$$ x^* = \arg\min_{x \in T} \sum_{i=1}^{N} L(M(p_i \oplus x \oplus s_i), y_i) $$

其中 $\oplus$ 表示拼接，$p_i$ 或 $s_i$ 可为空。该通用流程与本文问题的关键差异在于：传统实现将模型、损失、优化器硬编码于单一脚本，而本文将其解耦为可独立替换的组件。

### 模块化架构与组件解耦

TROPT 的核心创新在于将优化流程拆解为模型、损失、优化器、输入目标四个标准化组件。设计动机是消除实现碎片化，使优化器能跨模型类型（LM、编码器、分类器）与目标无缝迁移。模型后端吸收触发模板、批处理、梯度计算等基础设施逻辑，保持损失与优化器前端轻量且自包含。新增损失或优化器仅需实现标准化 API，即可与所有现有组件组合。例如，将 GCG 优化器与 CLIP 余弦相似度损失组合，即可实现文本到图像模型的提示恢复，无需修改核心搜索逻辑。

### 受控基准与优化器对比

TROPT 通过固定配方中除优化器外的所有组件，实现优化器性能的隔离对比。设计动机是解决现有评测中实现细节混淆算法贡献的问题。在 LLM 越狱场景中，固定模型、损失（PrefillCE）、输入模板与计算预算（$3 \times 10^{17}$ FLOPs），仅变更优化器，以最终损失最小化效率为指标。该协议揭示了优化器对参数调优的敏感性：MAC 通过添加梯度动量、PAL 通过调整候选采样策略，均显著优于 GCG 基线。这种受控对比使研究者能可靠追踪优化器进步，识别被低估的有效方法。

## 实验评估

实验在四个开源模型（Qwen3-8B、Llama-3.1-8B-Instruct、Gemma-3-12B-it、Gemma-4-26B-A4B-it）上进行，使用 15 条 ClearHarm 有害指令，每个模型-优化器对运行三个随机种子。基线覆盖 14 种优化器，包括梯度类（GCG、MAC、PAL）、连续松弛类（GBDA、PEZ）与黑盒类（Random Search、RAL）。缺失多轮对话优化器（如 DAMON）及智能体框架，反映其单轮静态优化定位。

| 优化器 | 平均排名 (越低越好) | 显著性 (vs GCG) |
| :--- | :--- | :--- |
| PAL | ~3/14 | 显著优于 |
| MAC | ~3.5/14 | 显著优于 |
| GCG | ~5/14 | 基线 |
| RAL | ~5/14 | 无显著差异 |
| HotFlip | >10/14 | 显著劣于 |

Nemenyi 检验显示临界差异 CD=1.48，PAL 与 MAC 显著优于 GCG，而 RAL（PAL 的无梯度变体）性能与 GCG 相当，成为最强黑盒优化器。消融实验表明，优化器性能高度依赖参数调优，微小修改（如动量、采样策略）即可带来显著增益，验证了受控对比的必要性。

评估边界受限于单轮静态输入，未涵盖多轮对话、工具调用或系统级组件（如 RAG 检索库）的动态交互。指标为损失最小化效率，虽与越狱成功率相关，但未直接测量最终有害输出。代码开源（github.com/matanbt/TROPT），但超参数与计算预算固定，未报告不同计算资源下的性能变化。

## 关联研究分析

从问题动机看，TROPT 与 GCG、GBDA 等离散优化方法共享“搜索对抗触发器”的目标，但差异在于工程抽象层级。GCG 等方法将优化逻辑与特定模型、损失硬编码，导致跨域迁移需重写代码；TROPT 通过组件解耦，使同一优化器可应用于 LLM 越狱、检索器投毒、分类器规避等任务。这一差异源于任务特性：安全评估需快速适配新模型与防御机制，而传统实现的高工程摩擦阻碍了这种适应性。TROPT 的模块化设计是否牺牲了针对特定模型的端到端优化效率，论文未给出回答。

从方法设计看，TROPT 与 DAMON 等多轮对话越狱方法形成互补。DAMON 通过蒙特卡洛树搜索探索对话空间，解决单轮静态攻击在多轮护栏下的失效问题；TROPT 则聚焦单轮输入优化的标准化，未涉及对话状态建模。两者差异反映领域演进：从静态文本优化向动态系统交互迁移。TROPT 的受控基准可评估 DAMON 中单轮子步骤的优化器性能，但无法评估其整体对话策略。这种分工表明，离散优化器统一框架与多轮对话探索是解决 LLM 安全问题的不同维度，前者提供基础工具，后者应对上下文依赖的护栏失效。

## 总结

本文核心矛盾是离散优化器实现碎片化导致的安全评估不可靠与算法进步停滞。切入点在于将优化器抽象为标准化模块，通过统一接口消除工程摩擦，实现跨域复用与受控对比。TROPT 解耦模型、损失、优化器与输入目标，建立首个 14 种优化器的受控基准，证明 MAC 与 PAL 显著优于 GCG 基线。其边界在于仅覆盖单轮静态输入优化，未触及多轮对话、工具调用或系统级动态交互场景。当优化器应用于包含 RAG 检索库或工具链的复合系统时，其单轮假设是否仍能有效捕捉系统级攻击面，论文未给出回答。
