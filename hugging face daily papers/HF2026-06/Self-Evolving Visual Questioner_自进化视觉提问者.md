# HuggingFace最新推荐论文 ｜Self-Evolving Visual Questioner ｜自进化视觉提问者

研究机构：美国马里兰大学帕克分校、美国加州大学洛杉矶分校

作者：Yijun Liang、Hengguang Zhou、Ming Li 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.13929)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.13929)

> 视觉语言模型（VLM）长期被训练为被动回答者，其主动生成高质量、视觉接地且具推理深度的问题能力严重受限。现有视觉问题生成（VQG）方法依赖静态标注或外部教师模型，导致生成问题局限于重复模板与表面识别，无法持续扩展难度边界。本文提出一种无需外部监督的自进化框架，通过模型自身的提议-重写-过滤闭环迭代生成更难的自监督数据，并采用双格式训练保持回答能力。该框架在多个骨干上显著提升了问题质量，但评估协议的非标准化与重写机制的固定性限制了其通用性验证。

## 研究背景

当VLM面对复杂图像时，若仅依赖预训练数据中的统计偏差，往往生成缺乏视觉依据的浅层问题。这种语言偏差（Language Bias）导致模型倾向于模仿现有问答对中的表面模式，而非主动探索图像中的细粒度证据。为缓解此问题，研究者引入视觉定位（Grounding）机制，要求问题必须锚定具体的图像区域或对象，从而将生成任务从语言模式匹配转向视觉证据检索。然而，传统VQG方法仍受限于静态数据分布，难以在训练过程中动态提升问题的感知与推理难度。

VQA领域的主流路线聚焦于答案准确性，通过知识增强或视觉定位提升回答质量，但忽视了提问能力作为认知推理基础的重要性。现有VQG方法依赖人工标注或更强外部模型提供监督，导致生成问题的多样性与接地性被数据分布所束缚。本文切入点在于将VQG视为一个可自进化的能力，通过模型自身迭代生成更难的监督信号，打破静态数据瓶颈，实现问题难度的持续扩展。

## 核心方法

### 方法参照系

本文问题属于自监督学习范畴，但与传统自训练的关键差异在于：传统方法直接强化现有预测分布，易导致坍缩；本文通过引入重写与过滤机制，显式控制生成数据的难度与多样性，防止模型陷入重复性低信息量问题的循环。

### 提议-重写-过滤闭环

提议阶段使用当前模型 $M_t$ 基于多视觉意图生成候选问题，重写阶段使用初始模型 $M_0$ 对问题进行难度提升，过滤阶段保留视觉可答且难度提升的样本。这一设计动机在于解耦提议与重写，避免同一模型同时执行两步导致的分布耦合。重写公式为：

$$q_{rw} = M_0(x, q_{prop}, r)$$

其中 $r$ 为难度提升指令。该机制确保后期轮次能探索新的候选空间，同时保持重写过程的稳定性。

### 双格式训练与迭代自改进

训练阶段混合QG格式（图像→问题+答案）与QA格式（图像+问题→答案），以平衡提问能力与回答能力。迭代自改进通过 $M_{t+1}$ 作为下一轮提议者，形成闭环。双格式训练的损失函数为：

$$\mathcal{L} = \lambda_{QG} \mathcal{L}_{QG} + \lambda_{QA} \mathcal{L}_{QA}$$

其中 $\mathcal{L}_{QG}$ 优化问题生成，$\mathcal{L}_{QA}$ 锚定回答行为。该设计防止模型在提升提问能力时丧失回答能力，确保自进化过程不损害下游VQA性能。

## 实验评估

实验在Qwen2.5-VL-3B/7B与Qwen3VL-4B三个骨干上进行，评估协议为自定义的Agentic Evaluation Protocol，涵盖感知、推理与多样性维度。基线仅对比Base模型与不同训练策略，未对比SCRA-VQA、MaS-VQA等具体VQA方法，因任务定义不同。主实验显示，两轮自进化后QG平均分提升约82%，QA准确率在61-71%区间保持稳定。

| 骨干 | 训练阶段 | QG Avg. | QA Avg. |
| :--- | :--- | :--- | :--- |
| Qwen2.5-VL-3B | Base | 0.26 | 60.49 |
| Qwen2.5-VL-3B | Second-round | 0.50 | 62.56 |
| Qwen3VL-4B | Base | 0.38 | 71.31 |
| Qwen3VL-4B | Second-round | 0.57 | 71.11 |

消融实验表明，重写与过滤机制对QG提升贡献显著，过滤阶段将视觉搜索难度从0.353提升至0.433，空间推理从0.293提升至0.367。双格式训练在QG-only导致QA性能下降的情况下，实现了QG与QA的平衡。评估边界方面，自定义协议缺乏与标准VQA基准的直接对比，且重写机制固定使用 $M_0$，可能限制后期轮次的难度上限。

## 关联研究分析

从问题动机看，本文与MaS-VQA均关注噪声过滤，但MaS-VQA过滤外部检索知识，本文过滤自生成问题，逻辑相似但对象不同。MaS-VQA依赖外部知识库，本文强调自生成，二者在数据源依赖上存在张力。从方法设计看，本文与HAVC均强调视觉接地，HAVC通过裁剪图像提升VQA，本文通过评估问题对视觉证据的依赖度提升VQG。HAVC的裁剪策略是显式视觉操作，本文的接地评估是隐式质量度量，前者直接作用于输入，后者作用于生成过程。

## 总结

本文核心矛盾在于静态数据分布限制了VQG的难度扩展，切入点在于利用模型自身迭代生成更难的自监督数据。通过提议-重写-过滤闭环与双格式训练，实现了QG质量提升约82%且QA性能稳定。边界在于评估协议非标准化，重写机制固定使用 $M_0$ 可能限制后期难度上限。当支持集增大到5-shot时，重写机制的边际收益是否递减，论文未给出回答。
