> 统一多模态模型在生成复杂场景时，常因结构规划与外观渲染在单一条件流中纠缠，导致属性绑定错误或布局违背。现有显式思维链方法虽能缓解此问题，但引入了高延迟与多阶段误差累积。本文提出 IV-CoT，将结构规划内化为潜在查询级联，通过训练期草图监督实现单步前向推理中的隐式视觉思维。该方法在保持单步推理效率的同时，显著提升了结构敏感维度的生成精度，但其潜在表征的几何保真度边界尚待进一步验证。

## 研究背景

当提示词要求生成包含特定数量、空间关系和属性绑定的多物体场景时，统一多模态大语言模型（MLLMs）往往生成视觉上合理但结构错误的图像。这一失效源于条件流的纠缠：MLLM 将场景结构、物体身份、属性及外观细节压缩至同一视觉条件序列，使得生成器无法区分决定布局的结构因子与控制色彩纹理的外观因子。为解耦二者，研究界引入了思维链（Chain-of-Thought, CoT）机制，试图在像素合成前插入中间推理步骤。

显式 CoT 方法分为文本与交错两类。文本 CoT 生成场景描述或数值布局，但语言对连续二维几何、边界及遮挡的表达带宽有限；交错 CoT 引入掩码或草稿图像等视觉中间态，虽增强了结构线索，却需显式解码中间图像，导致推理延迟增加及误差累积。这两种范式均将推理外化为可观测序列，牺牲了生成效率。本文切入点在于：结构感知生成需要一种保留视觉空间信息、同时避免推理时解码中间态的规划机制。

## 核心方法

### 查询条件 MLLM-DiT 架构

本文基于 OpenUni-L-1024 骨干，该架构通过 MLLM 将文本提示映射为连续视觉查询，再由扩散 Transformer（DiT）条件去噪生成图像。标准流程中，所有视觉信息压缩为扁平查询序列，结构因子与外观因子混合，导致结构感知提示遵循失效。本文的关键差异在于对查询序列进行角色分离与因果排序，而非增加外部推理步骤。

### 结构到语义查询级联

设计动机在于解决单一条件流中结构规划与外观渲染的纠缠。本文将可学习视觉查询输入分为结构查询 $Q_s^0$ 与语义查询 $Q_m^0$，并按序输入 MLLM：

$$
[Q_s, Q_m] = \text{MLLM}([y, Q_s^0, Q_m^0])
$$

利用 MLLM 的因果自注意力，结构查询仅访问提示词与自身输入，无法访问语义查询；语义查询则可访问提示词与结构查询状态。这种单向依赖建立了从结构规划到语义渲染的级联，迫使模型先形成潜在视觉计划，再基于该计划渲染外观。

### 草图监督结构约束

设计动机在于引导结构查询编码轮廓、形状与布局，同时抑制色彩、纹理等外观因子。训练分两阶段：第一阶段冻结 MLLM 与 DiT，仅优化结构查询输入，以草图潜变量 $z_s$ 为干净潜变量进行扩散去噪：

$$
\mathcal{L}_{\text{struct}} = \mathbb{E}_{t, \epsilon} \left[ \| \epsilon - \epsilon_\theta(z_{s,t}, t, Q_s) \|^2 \right]
$$

该损失强制结构所需信息编码于 $Q_s$ 中，而非被生成器吸收。第二阶段联合优化生成器与查询输入，保留 $\mathcal{L}_{\text{struct}}$ 作为正则项，防止 $Q_s$ 漂向外观线索，同时允许 $Q_m$ 在结构条件下渲染细节。推理时仅输入文本提示，单步前向生成查询，无需提取草图或解码中间图像。

## 实验评估

实验在 GenEval 与 T2I-CompBench 上进行，基线覆盖统一模型（BAGEL, OpenUni-L-1024）与显式 CoT 方法（T2I-R1, GoT-R1, TWIG-RL）。

| 方法 | GenEval Overall | T2I-CompBench Overall | 推理时间 (s) | 相对延迟 |
|---|---|---|---|---|
| OpenUni-L-1024 | 0.86 | 0.5448 | - | - |
| T2I-R1 | 0.79 | 0.5281 | 15.261 | 9.01× |
| GoT-R1 | 0.75 | 0.5241 | 16.744 | 9.89× |
| TWIG-RL | - | 0.5624 | 25.362 | 14.98× |
| IV-CoT | 0.88 | 0.5743 | 1.693 | 1.00× |

IV-CoT 在 GenEval 上从 0.86 提升至 0.88，T2I-CompBench 从 0.5448 提升至 0.5743，增益集中于位置、颜色属性及空间关系等结构敏感维度。推理时间仅 1.693 秒，较显式 CoT 方法降低 9-15 倍，验证了潜在推理的效率优势。

| 消融变体 | 查询数 | 结构监督 | 级联 | GenEval | T2I-CompBench |
|---|---|---|---|---|---|
| Base | 256 | - | - | 0.860 | 0.5448 |
| Base + More Queries | 512 | - | - | 0.869 | 0.5507 |
| Flat Sketch Aux | 512 | ✓ | - | 0.866 | 0.5496 |
| Parallel Two-Query | 512 | ✓ | ✓ | 0.869 | 0.5562 |
| IV-CoT w/o Structural Constraint | 512 | - | ✓ | 0.861 | 0.5573 |
| Full IV-CoT | 512 | ✓ | ✓ | 0.885 | 0.5743 |

消融显示，仅增加查询数（256→512）仅带来 0.009 的 GenEval 增益，表明性能提升非源于查询容量。移除结构监督或级联均导致性能下降，证实二者互补：结构监督塑造 $Q_s$ 为潜在视觉计划，级联允许 $Q_m$ 基于该计划渲染。交叉注意力分析表明，$Q_s$ 在物体轮廓与边界处获得更高相对注意力，$Q_m$ 在物体内部与外观区域激活，呈现软功能特化。

评估仅覆盖静态图像生成，未涉及视频或 3D 扩展。代码声明接收后发布，当前未提供。GenEval 0.88 与领域综述中 UniGRPO 的 0.88 持平，但骨干不同（OpenUni vs. AR-Diffusion），无法排除骨干能力差异的影响。

## 关联研究分析

从问题动机看，IV-CoT 与 ThinkMorph 均针对复杂空间关系推理不足，但 ThinkMorph 采用显式交错思维链，通过动态调度语言与视觉推理步骤实现细粒度协同，代价是生成延迟增加与中间状态敏感。IV-CoT 将推理内化为潜在查询级联，避免了显式解码，但牺牲了推理过程的可解释性。这种取舍源于任务特性：结构感知生成更关注最终布局正确性，而非推理轨迹的可审计性。

从方法设计看，IV-CoT 与 BAGEL 同属统一架构，但 BAGEL 采用混合 Transformer 共享注意力，未显式分离结构语义角色；IV-CoT 在查询层面引入因果级联，实现了更细粒度的功能解耦。与 T2I-R1 等显式 CoT 方法相比，IV-CoT 的潜在推理机制更接近人类视觉规划的内隐过程，但缺乏外部验证机制。潜在查询是否真正捕获连续几何信息，还是仅拟合离散布局，论文未给出定量验证。

## 总结

IV-CoT 针对统一多模态模型中结构规划与外观渲染纠缠导致的结构感知提示遵循失效，提出将视觉规划内化为潜在查询级联的隐式思维链框架。通过训练期草图监督与结构到语义因果级联，该方法在单步前向推理中实现结构-语义解耦，GenEval 从 0.86 提升至 0.88，T2I-CompBench 从 0.5448 提升至 0.5743，推理延迟降低 9-15 倍。其边界在于潜在表征的几何保真度缺乏定量验证，且评估未覆盖动态生成场景。当提示词涉及连续几何变换或复杂遮挡关系时，潜在查询级联能否保持结构精度，论文未给出回答。
