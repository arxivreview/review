> 导读 自进化大语言模型智能体（Self-Evolving LLM Agents）通过更新外部脚手架（Harness）来适应环境，但现有评估仅关注端到端性能提升，掩盖了增益来源。本文切入点在于解耦“产生更新的能力”与“从更新中受益的能力”，揭示二者与模型基础能力存在非单调关系。具体做法是固定智能体与进化者变量，在三个基准上独立测量两种能力。该分析挑战了“更强模型进化更好”的直觉，但缺乏参数化进化基线对比，其结论在混合进化场景下的普适性存疑。

## 研究背景

当智能体在开放环境中执行长周期任务时，静态提示词与工具配置往往因任务分布漂移而失效。为解决此问题，Harness 进化机制允许智能体从执行轨迹中提取经验，自动修改提示、技能或记忆等外部组件，而保持模型权重冻结。这一过程涉及两个独立角色：负责生成更新的“进化者”（Evolver）和负责执行任务的“智能体”（Agent）。传统研究将二者视为同质整体，假设基础能力强的模型既能产生更优更新，也能更有效地利用更新。

然而，现有自进化方法如 Reflexion 和 EvolveR 主要评估端到端增益，无法区分性能提升究竟源于进化者生成了高质量指令，还是智能体更擅长遵循这些指令。这种混淆导致资源分配策略失当：若盲目升级进化者模型，可能忽略智能体本身缺乏执行复杂指令的能力。本文旨在通过控制变量实验，解耦这两种能力，明确在 Harness 进化系统中，计算预算应优先分配给哪个角色，以及不同能力层级的模型在进化过程中的具体失效模式。

## 核心方法

### 能力解耦形式化

本文基于 Harness 自进化协议，将智能体定义为冻结骨干 $f$ 与可变 Harness 状态 $H_t$ 的组合。核心创新在于定义了两个独立于基础能力的度量指标。首先，Harness 更新能力 $\Delta_{update}(e)$ 衡量进化者 $e$ 产生的更新对锚点智能体集合 $F^\star$ 的平均增益：

$$ \Delta_{update}(e) = \frac{1}{|F^\star|} \sum_{f \in F^\star} \left[ J_X(f, H_T^{[f,e]}) - J_X(f, H_0) \right] $$

该公式物理含义为：固定智能体，仅改变进化者，观察最终 Harness 带来的性能提升均值。其次，Harness 受益能力 $\Delta_{benefit}(f)$ 衡量智能体 $f$ 从锚点进化者集合 $E^\star$ 产生的更新中获得的最大增益：

$$ \Delta_{benefit}(f) = \max_{e \in E^\star} \left[ J_X(f, H_T^{[f,e]}) - J_X(f, H_0) \right] $$

这一设计动机在于打破“基础能力预测进化能力”的线性假设，通过分离变量，识别出更新质量与执行能力之间的解耦现象。

### 失效模式诊断机制

针对弱模型在受益能力上的异常低值，本文引入了细粒度轨迹指标进行诊断。定义技能加载率（SLR）为至少加载一个技能的轨迹比例，以及 Harness 遵循率（HFR）为加载技能后遵循其指导的轨迹比例。通过分解总收益为“激活”与“遵循”两个阶段，本文揭示了弱模型并非无法理解更新内容，而是存在“激活失败”（未调用相关技能）和“遵循失败”（调用后未忠实执行）两种具体失效模式。这种诊断机制将黑盒的性能差距转化为可解释的行为偏差，为后续针对弱模型的专项训练提供了具体目标。

## 实验评估

实验在 SWE-bench Verified、MCP-Atlas 和 SkillsBench 三个基准上进行，使用七款不同能力层级的 LLM 作为智能体和进化者。基线覆盖无进化状态及不同进化者组合，但缺乏参数化进化方法（如 EvolveR）的对比，限制了结论在混合进化场景下的推广。

| 模型 | SWE Base (%) | SWE Δbenefit (pp) | MCP Base (%) | MCP Δbenefit (pp) | SB Base (%) | SB Δbenefit (pp) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Qwen3-32B | 3.6 | 4.4 | 3.6 | 1.0 | 0.0 | 5.8 |
| GPT-OSS-120B | 20.7 | 19.3 | 28.0 | 7.0 | 4.7 | 1.1 |
| Opus 4.6 | 66.0 | 2.4 | 61.0 | 3.6 | 25.6 | 5.8 |

数据显示，Harness 更新能力在进化者间差异极小（最大差距 3.1 pp），而受益能力呈非单调分布：中档模型（如 GPT-OSS-120B）获益最大，强模型因接近性能上限获益较少，弱模型（如 Qwen3-32B）尽管提升空间最大，实际获益却最低。

消融分析表明，弱模型的低收益主要源于激活失败。在 SkillsBench 上，Qwen3-32B 的 SLR 仅为 25.1%，而强模型约为 96%。即使加载了技能，弱模型的遵循率（HFR）也显著低于强模型，且随轨迹长度增加，遵循度衰减速度是强模型的 4 倍以上。这证实了“指令遵循”而非“理解能力”是弱模型利用 Harness 的主要瓶颈。

评估边界方面，本文仅使用通过率作为主要指标，未报告置信区间，且未包含计算成本对比。代码已公开，但实验依赖特定的提示模板和轨迹窗口设置，跨环境复现时需严格对齐这些超参数。

## 关联研究分析

从问题动机看，本文与 DarwinX 等 Harness 进化方法形成互补。DarwinX 聚焦于通过自然选择机制优化 Harness 结构，隐含假设进化必然带来收益；而本文通过实证数据指出，收益高度依赖智能体的基础能力，挑战了“进化普适有效”的假设。这种差异源于任务特性：DarwinX 关注结构优化，本文关注执行能力匹配。若智能体无法忠实执行优化后的结构，结构本身的优劣便失去意义。

从方法设计看，本文与 A-Evolve 的理论框架存在张力。A-Evolve 区分参数化与非参数化更新，但未深入探讨非参数化更新中“更新者”与“执行者”的能力解耦。本文通过独立控制变量，揭示了非参数化进化中特有的“激活-遵循”失效模式，这是参数化进化（直接修改权重）所不具备的。这种差异暗示，非参数化进化的瓶颈可能不在知识存储，而在知识调用的可靠性。查询侧增强在数据充足时是否仍有增益，论文未给出回答，但本文的发现表明，对于弱模型，增强调用机制比增强知识内容更为关键。

## 总结

本文要解决的核心矛盾是 Harness 进化中更新质量与执行能力的混淆。现有方法因端到端评估无法区分增益来源，而本文通过解耦 $\Delta_{update}$ 和 $\Delta_{benefit}$，揭示了二者与基础能力的非单调关系。实验证明，进化者能力差异对最终性能影响有限（最大 3.1 pp），而智能体基础能力主导结果；弱模型因激活与遵循失败，无法有效利用进化收益。本文边界在于缺乏参数化进化基线，且仅验证了非参数化场景。当智能体同时具备参数化微调与非参数化 Harness 更新能力时，弱模型的“执行遗忘”是否会被权重内化所补偿，论文未给出回答。
