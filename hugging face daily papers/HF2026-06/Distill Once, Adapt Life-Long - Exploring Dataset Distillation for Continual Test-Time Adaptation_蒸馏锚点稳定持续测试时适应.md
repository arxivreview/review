# HuggingFace最新推荐论文 ｜Distill Once, Adapt Life-Long: Exploring Dataset Distillation for Continual Test-Time Adaptation ｜蒸馏锚点稳定持续测试时适应

研究机构：韩国科学技术院

作者：Hyun-Kurl Jang、Jihun Kim、Hyeokjun Kweon 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.20196)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.20196)

> 持续测试时适应（CTTA）旨在让模型在分布持续漂移的无标签数据流中保持性能，但纯源无关（Source-Free）设定下，自训练信号随时间推移变得不可靠，导致灾难性遗忘与误差累积。现有方法或依赖昂贵的源数据回放，或仅保留低维原型，难以在隐私约束下提供足够丰富的语义参考。DO-ALL 通过数据集蒸馏（DD）将源域压缩为少量合成锚点，在适应时动态匹配并正则化更新，实现了隐私友好的长期稳定。该方法在多个基准上提升了基线 CTTA 的稳定性，但其性能上限仍受限于蒸馏锚点的信息密度，且未解决极端非线性偏移下的适应失效问题。

## 研究背景

部署后的感知系统面临天气变化、传感器退化等动态环境，导致测试数据分布与训练分布产生系统性偏差，即分布偏移。为在线修正模型，测试时适应（TTA）利用无标签测试数据更新参数，而持续测试时适应（CTTA）进一步处理非平稳数据流，要求模型在适应新域的同时保留旧域知识。CTTA 的核心困境在于自训练产生的伪标签噪声随分布漂移而指数级累积，若无外部参考，模型极易陷入局部极小值或发生表示崩溃。

主流 CTTA 路线在稳定性与隐私性之间存在权衡。CoTTA 等教师-学生框架通过指数移动平均（EMA）抑制遗忘，但依赖复杂的模型副本；RMT 等方法保留源域特征原型，但原型仅捕捉类均值，丢失了类内结构与边界信息。完全丢弃源数据的严格源无关设定虽满足隐私要求，却使模型缺乏持久锚点，在长时程适应中表现脆弱。DO-ALL 的切入点在于利用数据集蒸馏技术，在部署前一次性将源域压缩为信息密集的合成样本，既避免了原始数据的隐私泄露，又保留了比原型更丰富的语义结构，为 CTTA 提供了轻量且稳定的外部参考。

## 核心方法

### 方法参照系

标准 CTTA 流程通常包含在线自监督更新（如熵最小化）与抗遗忘机制（如参数重置或正则化）。本文的关键差异在于引入离线预处理的“蒸馏锚点”作为持久参考，将源域知识从“隐式记忆”转化为“显式存储”，并在适应阶段通过语义匹配动态调用，而非依赖模型内部权重的自我维持。

### 源域蒸馏锚点构建

设计动机在于解决纯源无关方法缺乏持久参考点导致的长期漂移问题。DO-ALL 在部署前对源数据集执行数据集蒸馏，生成少量合成样本 $\tilde{D}_s$。每个锚点 $\tilde{a}_i$ 包含合成输入 $\tilde{x}_i$、源模型生成的软标签 $\tilde{s}_i$ 及潜在特征 $\tilde{z}_i$：

$$ \tilde{a}_i = (\tilde{x}_i, \tilde{s}_i, \tilde{z}_i), \quad \tilde{z}_i = g_{\theta_0}(\tilde{x}_i) $$

该公式表明，锚点不仅存储了像素级信息，还编码了源模型的特征空间几何结构。软标签保留了类间关系与置信度结构，相比硬标签提供了更平滑的监督信号，使模型在适应过程中能更稳健地维持源域决策边界，避免对单一类别的过拟合。

### 锚点-目标语义匹配与正则化

设计动机在于解决全局正则化导致的适应僵化问题，即均匀使用所有源域信息会阻碍模型对局部分布偏移的适应。在测试时 $t$，对目标样本 $x_b^t$ 计算其与所有锚点的余弦相似度，选取最近邻锚点 $\tilde{a}_b^t$ 形成关联锚点集 $\tilde{A}_t$。适应损失由直接回放、MixUp 回放与特征对齐组成：

$$ \mathcal{L}_{total} = \mathcal{L}_{replay} + \lambda_{mmd} \mathcal{L}_{mmd} + \lambda_{mix} \mathcal{L}_{mix} $$

其中 $\mathcal{L}_{replay}$ 通过温度缩放 KL 散度约束模型预测与锚点软标签的一致性，$\mathcal{L}_{mmd}$ 利用最大均值差异对齐目标与锚点的潜在特征分布，$\mathcal{L}_{mix}$ 则在目标-锚点混合样本上施加平滑约束。这种局部匹配机制确保模型仅在语义相关区域保留源域知识，而在其他区域自由适应目标分布，实现了稳定性与可塑性的动态平衡。

## 实验评估

实验在 ImageNet-C、CIFAR100-C 及 CCC 基准上进行，使用 ResNet-50 与 ResNeXt-29 骨干网络。基线覆盖 EATA、RMT、ROID 等代表性 CTTA 方法，但缺失无梯度方法（如 NEO、ZOTTA）及最新 SOTA（如 SloMo-Fast）的对比。在 ImageNet-C 严重度 5 下，ROID+DO-ALL 将平均错误率从 54.5% 降至 53.6%，EATA+DO-ALL 从 58.0% 降至 56.6%。

| 方法 | ImageNet-C 错误率 (%) | CCC-Hard 准确率 (%) |
|---|---|---|
| ROID | 54.5±0.10 | 13.2±2.47 |
| ROID+DO-ALL | 53.6±0.09 | 15.5±1.49 |
| EATA | 58.0±0.18 | - |
| EATA+DO-ALL | 56.6±0.22 | - |
| RMT | 59.8±0.18 | - |
| RMT+DO-ALL | 57.4±0.23 | - |

消融实验显示，各组件贡献互补：直接回放、MMD 对齐与 MixUp 单独引入均带来小幅提升，组合后错误率降至 54.0%，加入有害自适应混合（Harm-Adaptive Blending）后进一步降至 53.6%。锚点匹配策略中，最近邻匹配显著优于随机匹配（56.6% vs 57.3%）与最远邻匹配（58.7%），证实语义对应关系是稳定性的关键。

评估边界方面，论文未报告计算开销与内存峰值的具体对比，仅定性提及 DD 的存储优势。超参数（如 $\lambda_{mmd}=10$）固定，未探讨其对不同偏移类型的敏感性。代码已开源，但蒸馏过程需额外计算资源，未评估在线轻量级蒸馏的可行性。

## 关联研究分析

从问题动机看，DO-ALL 与 RMT 均利用源域信息对抗遗忘，但 RMT 依赖低维原型，而 DO-ALL 使用高维合成样本。这一差异源于对“源域知识”定义的认知不同：RMT 假设类均值足以代表源域，而 DO-ALL 认为类内结构与边界信息对长期稳定性至关重要。然而，DD 生成的合成样本是否真正保留了足够的类内多样性，还是仅优化了训练动态，论文未通过特征空间可视化或类内方差分析进行验证。

从方法设计看，DO-ALL 与 CoTTA 的教师-学生框架形成互补。CoTTA 通过 EMA 教师提供软标签，但教师模型随时间漂移；DO-ALL 的锚点标签固定不变，提供了更稳定的参考。但 DO-ALL 缺乏 CoTTA 的随机重置机制，在极端腐蚀场景下可能不如重置策略有效。此外，DO-ALL 的有害自适应混合基于梯度幅值判断参数稳定性，这一启发式规则在非线性优化景观中的理论依据尚不充分，其有效性可能依赖于特定骨干网络的梯度分布特性。

## 总结

DO-ALL 旨在解决 CTTA 中隐私约束与长期稳定性的矛盾，通过数据集蒸馏生成合成锚点，在适应时提供持久语义参考。实验表明，该方法在 ImageNet-C 上将 ROID 的错误率从 54.5% 降至 53.6%，在 CCC-Hard 场景下准确率从 13.2% 提升至 15.5%。其边界在于依赖离线 DD 计算，且锚点信息密度受限于蒸馏质量，未解决极端非线性偏移下的适应失效。当源域分布高度复杂或目标域发生剧烈结构变化时，固定锚点是否仍能提供有效正则化，论文未给出回答。
