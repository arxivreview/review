> 视频理解的核心矛盾在于，模型常依赖单帧静态线索或语言先验回答时序问题，而非真正追踪连续动态。现有基准多允许从关键帧或终态推断答案，掩盖了模型在连续状态维护上的缺陷。VSTAT 通过构造无法从单帧推断的任务，强制模型全程感知并更新状态，揭示了当前多模态大语言模型（Multimodal Large Language Models, MLLMs）在此能力上的严重不足。该基准提供了诊断视觉感知瓶颈的工具，但其任务设计是否过度依赖特定视觉线索，仍需在实际应用场景中验证。

## 研究背景

当模型面对篮球比赛视频时，它需要持续追踪比分、球员位置及投篮尝试，而非仅识别“有人投篮”这一动作。这种能力被称为视觉状态跟踪（Visual State Tracking），即从连续视频流中提取并维护实体、状态及事件的演化信息。然而，现有视频理解基准大多未显式评估此能力，许多问题的答案可从少数关键帧或可见终态推断，无需追踪底层状态的连续变化。这导致模型在基准上的高分并不反映其真实的状态跟踪能力，形成了评估盲区。

领域主流路线聚焦于时间定位与语义推理，通过强化学习（Reinforcement Learning, RL）或监督微调（SFT）提升模型在离散事件定位上的精度。然而，这些方法假设模型能准确感知视频中的关键事件，忽略了感知层面的瓶颈。VSTAT 的切入点在于，通过构造必须全程跟踪才能回答的任务，分离感知与推理瓶颈，揭示模型在视觉感知连续动态时的根本缺陷。

## 核心方法

### 方法参照系

VSTAT 属于视频理解基准类别，其标准流程为：输入视频流与查询，输出答案。与 Video-MME 等通用基准不同，VSTAT 的关键差异在于任务设计强制排除单帧捷径，要求模型处理整个视频流并维护状态，而非仅识别离散事件。

### 任务构造与状态复杂度

VSTAT 包含 834 个视频片段与 1,500 个问题，源自 Blender 合成、YouTube 及自录视频。每个任务设计确保答案无法从单帧或短片段推断，需持续感知并整合事件。状态复杂度分解为元素类型（计数、位置、属性）与结构（原子、序列、集合、字典）。例如，追踪魔方特定贴片的最终位置需维护原子位置状态，而追踪篮球比赛中各球员投篮数需维护字典结构。这种设计迫使模型在视觉流中持续更新状态表示，而非依赖静态线索。

$$
S_t = f(S_{t-1}, o_t)
$$

其中 $S_t$ 为时刻 $t$ 的状态，$o_t$ 为观测事件，$f$ 为状态更新函数。该公式表明，状态跟踪本质上是递归过程，任何时刻的状态都依赖前序状态与当前观测，单帧信息不足以确定最终状态。

### 感知与推理瓶颈分离

为诊断失败原因，VSTAT 引入文本转录对照实验。在 Blender 合成任务中，将视频替换为逐帧文本描述，对比模型在视频输入与文本输入下的性能。结果显示，模型在文本条件下几乎完美解题，而在视频条件下性能降至随机猜测水平，表明瓶颈在于视觉感知而非推理。这一设计动机在于，现有方法常将失败归因于推理缺陷，但 VSTAT 通过控制变量证明，感知连续动态事件的能力才是主要障碍。

$$
\Delta P = P_{\text{text}} - P_{\text{video}}
$$

其中 $P_{\text{text}}$ 为文本转录条件下的准确率，$P_{\text{video}}$ 为视频输入条件下的准确率。$\Delta P$ 的大小直接反映感知瓶颈的严重程度，若 $\Delta P$ 显著，则表明模型无法从视觉流中提取必要信息。

## 实验评估

实验在 VSTAT 上评估了 Gemini-3.1 Pro、Gemini-3.0 Flash 及多个开源模型（Qwen3VL、InternVL3.5 等），基线覆盖专有 API 与开源模型，但缺失传统视觉-语言预训练（VLP）方法。主结果显示，人类平均准确率为 90.5%，而最佳模型 Gemini-3.1 Pro 仅为 44.4%，仅略高于频率基线（37.8%）。开源模型普遍低于随机猜测水平，表明当前 MLLMs 在视觉状态跟踪上存在严重缺陷。

| 模型 | 平均准确率 (%) | 排名 |
| :--- | :--- | :--- |
| Human | 90.5 | - |
| Gemini-3.1 Pro (low) | 44.4 | 1 |
| Gemini-3.0 Flash (low) | 39.8 | 3 |
| LLaVA-OV-2-8B | 35.1 | 1 (开源) |
| Qwen3VL-8B-Thinking | 28.2 | 18 |

消融实验显示，启用思考模式或提高思考水平反而降低性能。例如，Qwen3VL-8B 从 33.2% 降至 28.2%，Gemini-3.1 Pro 从 44.4% 降至 43.9%。这一反直觉发现表明，当前模型的推理机制未能有效利用额外计算资源，可能因任务设计导致推理路径与视觉感知脱节。

评估边界方面，VSTAT 使用 MRA-with-MCQ 指标，但未报告置信区间，数值比较需谨慎。代码已开源，但超参数与 GPU 配置未详细披露，可复现性受限。任务设计强制全程跟踪，可能高于实际应用场景的难度，需进一步验证其在真实任务中的泛化性。

## 关联研究分析

从问题动机看，VSTAT 与 TempCompass 均揭示模型在时序逻辑上的缺陷，但 VSTAT 聚焦连续状态维护，而 TempCompass 侧重离散事件推理。VSTAT 的任务设计强制排除单帧捷径，要求模型追踪底层潜状态，这比 TempCompass 的细粒度时间定位更复杂。这一差异源于任务特性：状态跟踪需维护递归状态表示，而时间定位仅需识别事件边界。VSTAT 的发现表明，模型在感知连续动态时的瓶颈比在推理离散事件时更严重，这挑战了领域内“推理是主要瓶颈”的共识。

从方法设计看，VSTAT 与 CP-Bench 均使用合成任务，但 VSTAT 扩展至真实世界视频，覆盖更复杂的感知挑战（如遮挡、相机运动）。CP-Bench 仅关注简单合成任务（如计数立方体），而 VSTAT 包含多样化真实场景，使评估更具生态效度。然而，VSTAT 未采用 RL 或 SFT 等后训练方法，仅评估预训练模型的性能，这可能低估了后训练对状态跟踪能力的提升潜力。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

VSTAT 要解决的核心矛盾是，现有基准掩盖了模型在连续视觉状态跟踪上的缺陷。本文抓住的切入点是，通过构造无法从单帧推断的任务，强制模型全程感知并更新状态，从而分离感知与推理瓶颈。本文构建了包含 834 个视频片段与 1,500 个问题的基准，并引入文本转录对照实验，证明了视觉感知而非推理是主要瓶颈。实验显示，最佳模型 Gemini-3.1 Pro 的准确率仅为 44.4%，远低于人类的 90.5%，且启用思考模式反而降低性能。本文的边界在于，任务设计可能过度依赖特定视觉线索，且未评估后训练方法对状态跟踪能力的提升潜力。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
