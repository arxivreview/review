# HuggingFace最新推荐论文 ｜Not All Disagreement Is Learnable: Token Teachability in On-Policy Distillation ｜在线策略蒸馏中的Token可教性筛选

研究机构：香港理工大学

作者：Yuanyi Wang、Su Lu、Yanggan Gu 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.26844)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.26844)

> 在线策略蒸馏（OPD）旨在通过让学生模型在自身生成的轨迹上接受教师模型的Token级监督，解决训练与推理分布不匹配的暴露偏差问题。然而，现有选择性OPD方法仅依据熵或KL散度筛选显著Token，忽略了教师信号与学生当前预测支持集的几何兼容性，导致大量监督信号无法被学生有效吸收。本文提出“Token可教性”概念，通过固定上下文诊断解耦采样噪声，构建支持集对齐的分歧度评分机制，在仅保留5% Token的情况下实现了对全量OPD性能的超越。该工作揭示了OPD效率受限于信号质量而非预算规模，但其在非数学推理任务及跨架构泛化性上仍缺乏充分验证。

## 研究背景

OPD的核心困境在于教师提供的密集监督信号与学生实际可吸收的知识之间存在错位。当学生模型在特定上下文 $c_t$ 下生成前缀时，教师模型给出的下一Token分布 $p_T(\cdot|c_t)$ 可能与学生当前的预测支持集 $S_t^S$ 严重偏离。这种偏离并非均匀分布：部分Token的教师修正落在学生Top-K候选集内，属于可学习的局部调整；另一部分则指向学生概率质量极低的区域，形成不兼容分歧。传统方法将这两类信号混同处理，导致优化过程引入噪声。

早期选择性OPD研究聚焦于信号显著性，如TIP（Xu et al., 2026）基于学生熵与师生KL散度的二维分类筛选高价值Token。然而，高KL散度仅反映分布差异的大小，无法区分该差异是否处于学生当前假设空间的可达范围内。当教师信号指向学生支持集之外时，强制对齐不仅无效，还可能破坏学生已建立的局部语义结构。本文切入点在于将“显著性”转化为“可学习性”，通过量化教师修正与学生支持集的覆盖关系，识别真正可被学生吸收的Token级监督信号。

## 核心方法

### 固定上下文诊断框架

本文首先建立固定上下文诊断（Fixed-Context Diagnostic）以解耦Token级学习价值与采样噪声。传统端到端评估中，Token监督效果与下游上下文漂移、采样随机性耦合，难以归因。本文冻结学生生成的前缀库，对初始与训练后的学生在相同上下文下重新评分，定义固定上下文增益 $G_{fix}$ 为同一前缀下师生KL散度的减少量。该诊断将评估粒度从序列级降至Token级，确保后续筛选指标直接预测局部KL减少，而非受全局任务性能干扰。

### 支持集对齐的可教性评分

在诊断基础上，本文提出Token可教性评分机制。对于位置 $t$，定义学生Top-K支持集 $S_t^S$ 与教师Top-K支持集 $S_t^T$ 的并集 $U_t$。计算局部分歧度 $D_t$ 为 $U_t$ 上师生分布的KL散度，并定义兼容性质量 $C_t$ 为教师概率质量在学生支持集 $S_t^S$ 上的占比。可教性分数定义为归一化后的分歧度与兼容性乘积：

$$ s_{teach,t} = \tilde{D}_t \cdot \tilde{C}_t $$

其中 $\tilde{D}_t, \tilde{C}_t$ 为批次内鲁棒归一化值。该公式物理含义为：只有当教师修正既显著（高 $D_t$）又落在学生当前可调整范围内（高 $C_t$）时，该Token才具备高可教性。设计动机在于解决传统KL筛选混淆“可学习分歧”与“不兼容分歧”的问题，确保保留的Token监督信号与学生当前预测状态几何兼容。

### 预算约束下的OPD优化

基于可教性分数，TA-OPD在预算约束下优化OPD目标。给定保留比例 $\rho$，选取分数最高的 $n = \lceil \rho |I| \rceil$ 个位置，仅对这些位置应用反向KL散度损失：

$$ \mathcal{L}_{OPD} = \sum_{t \in I} m_t \left( \log p_\theta(y_t|c_t) - \log p_T(y_t|c_t) \right) $$

其中 $m_t$ 为二值掩码，仅当 $t$ 被选中时为1。该机制无需奖励模型或验证器，仅利用OPD过程中已有的师生概率分布，通过轻量级Top-K统计实现高效筛选。相比全量OPD，该方法将计算资源集中于高可教性位置，避免在不兼容Token上浪费优化步长。

## 实验评估

实验在Qwen3与Qwen2.5系列模型上进行，涵盖4B→1.7B、8B-GRPO→4B、14B→4B及跨架构DeepSeek-R1→Qwen2.5-3B四种师生对。基线包括全量OPD、熵筛选、TIP（熵+分歧）及随机选择。评估基准涵盖AIME24/25、GPQA-Diamond、HumanEval、IFEval及MATH-500，结果报告五次评估种子的均值与标准差。

| 设置 | 方法 | Avg. | AIME24 | MATH-500 |
| :--- | :--- | :--- | :--- | :--- |
| Qwen3-4B→1.7B | Full OPD | 42.37 | 11.67±5.00 | 75.00±1.20 |
| | TIP | 43.05 | 18.34±1.66 | 75.60±1.00 |
| | TA-OPD | **44.89** | **20.00±0.01** | 74.70±0.50 |
| Qwen3-14B→4B | Full OPD | 54.64 | 23.34±3.34 | 83.50±0.10 |
| | TIP | 53.62 | 20.00±0.01 | 82.40±0.01 |
| | TA-OPD | **54.65** | **23.34±3.34** | 82.50±1.70 |

在10%预算下，TA-OPD在所有师生对中均取得最高平均分。Qwen3-4B→1.7B设置中，TA-OPD平均分44.89较Full OPD提升2.52，AIME24提升8.33；Qwen3-14B→4B设置中，TA-OPD平均分54.65略高于Full OPD的54.64，且在HumanEval上领先。预算敏感性分析显示，性能并非随预算单调递增：Qwen3-8B-GRPO→4B设置中，TA-OPD+Entropy在5%预算下平均分57.89，高于30%预算下的57.46，表明低预算下高质量Token筛选优于高预算下的噪声稀释。

消融实验验证了可教性分数的有效性。固定上下文诊断中，TA-OPD在3%和5%预算下的KL减少量（$G_{3\%}=0.047, G_{5\%}=0.049$）均显著高于Raw KL（0.033, 0.036）和TIP（0.023, 0.026）。支持集大小 $K$ 的鲁棒性测试显示，$K=8,16,32$ 下高支持集增益间隙均为正，且 $K=16$ 时效果最佳。跨上下文验证中，held-out math、GSM8K-COT及更强教师（8B/14B）下，高可教性Token的增益间隙均保持正值，Bootstrap区间均大于零，证实可教性为OPD监督的局部属性而非特定运行伪影。

评估边界方面，实验局限于Qwen家族及数学推理任务，未覆盖多语言、对话或代码专用教师。Token预算指监督位置比例，非墙钟时间节省，实际加速效果需结合推理引擎评估。代码已开源，但超参数（如 $K=16$）的敏感性分析未在正文详细展开，仅附录提及。

## 关联研究分析

从问题动机看，TA-OPD与TIP（Xu et al., 2026）均针对OPD信号非均匀性问题，但TIP基于熵-分歧二维分类筛选显著Token，而TA-OPD引入支持集几何兼容性，将筛选标准从“显著性”转向“可学习性”。TIP的Q3区域（低熵高KL）内部存在异质性，TA-OPD通过分解可学习分歧与不兼容分歧，揭示了高KL散度中混杂的无效信号。这一差异源于任务特性：数学推理中Token间依赖性强，支持集对齐对局部语义保持至关重要，而TIP的显著性筛选在长程依赖任务中可能引入噪声。

从方法设计看，TA-OPD与GKD（Agarwal et al., 2023）共享OPD框架，但GKD采用全量Token监督，TA-OPD增加Token级筛选机制。GKD假设所有Token监督均有效，而TA-OPD证明在低预算下，仅保留高可教性Token即可匹配或超越全量监督。这一改进解决了GKD在师生能力差距大时的优化不稳定问题，但TA-OPD未探索与奖励模型的结合，可能忽略任务目标导向的信号。PACED（Xu et al., 2026）强调在学生能力前沿蒸馏，TA-OPD强调在局部支持集内蒸馏，两者互补但缺乏直接对比，跨架构泛化性仍是未解问题。

## 总结

本文核心矛盾在于OPD密集监督中有效信号与噪声信号的混杂，导致低预算下性能受限。TA-OPD通过固定上下文诊断解耦采样噪声，提出支持集对齐的可教性评分，将筛选标准从显著性转向可学习性。实验证明，在5%预算下TA-OPD可超越全量OPD，Qwen3-4B→1.7B设置中平均分提升2.52，AIME24提升8.33。其边界在于局限于Qwen家族及数学任务，未验证多语言或代码场景下的泛化性，且Token预算非墙钟时间节省。当支持集大小 $K$ 动态调整时，可教性分数的稳定性是否保持，论文未给出回答。
