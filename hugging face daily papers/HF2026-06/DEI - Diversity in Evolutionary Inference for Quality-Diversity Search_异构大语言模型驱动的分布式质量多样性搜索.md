# HuggingFace最新推荐论文 ｜DEI: Diversity in Evolutionary Inference for Quality-Diversity Search ｜异构大语言模型驱动的分布式质量多样性搜索

论文原文见 [arXiv](https://arxiv.org/abs/2605.27130)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.27130)

> 分布式进化搜索旨在通过并行计算加速高维离散空间的探索，但现有并行方案仅复制单一模型的归纳偏置，导致行为空间覆盖存在系统性盲区。本文指出，将不同家族的大语言模型（Large Language Models, LLM）作为异构变异算子，能利用其差异化的生成先验填补单一模型无法触及的档案区域。通过构建无同步屏障的异步冠军共享机制，DEI框架在固定计算预算下实现了跨模型对抗进化。该设计在Core War基准上验证了模型多样性对搜索效率的因果贡献，但其结论目前局限于单一竞争编程领域，跨域泛化能力尚未得到实证。

## 研究背景

质量多样性（Quality-Diversity, QD）搜索不追求单一最优解，而是维护一个覆盖行为空间（Behavioral Characteristic, BC）的精英档案。MAP-Elites算法通过离散化BC空间为网格单元，每个单元存储该行为特征下适应度最高的解，从而在解的质量与多样性之间取得平衡。当LLM被用作变异算子时，其训练数据与对齐策略决定了生成解的分布特性，例如偏向特定控制流模式或代码结构，这种归纳偏置在单一模型内是固定的。

传统并行LLM搜索如FunSearch通过增加同一模型的调用次数来扩展搜索，但多样性仅源于随机采样，无法突破该模型生成分布的边界。Digital Red Queen（DRQ）框架引入了对抗性共进化，通过保留历史冠军作为对手池提升选择压力，但其原始形式仍限于单节点单模型运行。当搜索空间复杂且单一模型存在生成盲区时，这种同质并行策略会导致档案中特定行为区域永久空缺，限制了QD搜索的覆盖上限。

本文的切入点在于将“计算扩展”转化为“认知扩展”。通过部署不同家族的LLM（如GPT系列与Claude系列）作为独立节点，利用其固有的生成差异作为多样性来源，并设计异步通信协议解决异构节点间的延迟不匹配问题。这种设计旨在证明，在相同计算预算下，模型异构性本身能带来超越单纯并行度的搜索增益。

## 核心方法

### 方法参照系

本文基于DRQ框架的单节点MAP-Elites流程，核心差异在于将单模型自博弈扩展为多模型异构对抗。标准流程中，LLM从档案采样精英进行变异或从头生成，适应度由当前对手池决定。本文保留了这一局部优化逻辑，但引入了跨节点的冠军交换机制，使得每个节点的对手池包含其他模型生成的解，从而打破单模型自博弈的局部最优陷阱。

### 异构节点异步通信架构

设计动机在于解决异构LLM节点间巨大的推理延迟差异，避免同步屏障导致整个系统被最慢节点拖慢。DEI采用全异步的发布-订阅模式，每个节点在每轮结束时独立发布其冠军解，其他节点在自身进度允许时消费这些解。这种机制允许慢速节点（如本地部署的开源模型）贡献多样性而不阻塞快速节点（如云端前沿模型）的迭代。

$$
O_{i} \leftarrow O_{i} \cup R_{i}
$$

其中 $O_{i}$ 为节点 $i$ 的对手池，$R_{i}$ 为从接收缓冲区排空获得的来自其他节点的冠军集合。该公式表明，节点在每轮迭代后，将接收到的外部冠军直接并入本地对手池，无需等待所有节点同步完成，实现了计算资源的解耦。

### 跨模型对抗压力与档案融合

设计动机在于利用不同模型生成解的行为差异，使每个节点能接触到自身生成分布之外的精英解，从而提升档案覆盖度。节点 $i$ 在每轮结束后，不仅将本地冠军 $w_{i}^{r}$ 发布给对端，还将从对端接收的冠军 $w_{j}^{r}$ 注入本地档案 $A_{i}$ 中，若其占据空单元则直接入库。

$$
\eta = \mathbb{E}[\mathbf{1}[\mathbf{bc}(w) \notin A_{i}[r-1]]]
$$

该公式定义了利基新颖度 $\eta$，即接收到的冠军落入接收节点档案中先前空单元的比例。高 $\eta$ 值表明跨模型共享引入了该节点自身难以生成的行为特征，直接量化了异构模型带来的探索增益，而非仅反映适应度提升。

## 实验评估

实验在Core War竞争编程基准上进行，使用MARS模拟器评估Redcode战士程序。基线包括单节点DRQ（Solo）和同质四节点集成（Homogeneous Ensemble），对比方法覆盖了单模型自博弈与同质并行两种路线，但缺失FunSearch或AlphaEvolve等经典LLM进化基线，限制了与更广泛LLM搜索范式的直接对比。

| 条件 | 峰值通用性 (Peak Gen.) | 利基新颖度 (Niche Nov. $\eta$) |
| :--- | :--- | :--- |
| Diverse Ensemble (Claude Sonnet 4.6) | **0.850**±**0.087** | **0.483**±**0.120** |
| Homogeneous Ensemble (Claude Sonnet 4.6) | 0.825±0.106 | 0.348±0.039 |
| Solo [DRQ] (Claude Sonnet 4.6) | 0.775±0.035 | — |
| Diverse Ensemble (GPT-5.4-mini) | **0.767**±**0.076** | **0.422**±**0.072** |
| Homogeneous Ensemble (GPT-5.4-mini) | 0.725±0.029 | 0.119±0.013 |
| Solo [DRQ] (GPT-5.4-mini) | 0.750±0.000 | — |
| Diverse Ensemble (GPT-5.2) | **0.767**±**0.076** | **0.454**±**0.070** |
| Homogeneous Ensemble (GPT-5.2) | 0.700±0.000 | 0.091±0.010 |
| Diverse Ensemble (Claude Haiku 4.5) | **0.700**±**0.050** | **0.443**±**0.132** |
| Homogeneous Ensemble (Claude Haiku 4.5) | 0.538±0.063 | 0.139±0.040 |
| Solo [DRQ] (Claude Haiku 4.5) | 0.650±0.141 | — |

在固定总LLM调用预算下，异构集成在所有四个模型家族上均实现了最高的峰值通用性。以Claude Sonnet 4.6为例，异构集成的0.850显著高于同质集成的0.825和单节点的0.775。利基新颖度指标进一步证实，异构集成接收到的外部冠军更频繁地落入空单元，表明模型多样性直接驱动了行为空间的探索广度。

| 条件 | 覆盖率 (Coverage) | QD-Score |
| :--- | :--- | :--- |
| Solo | 63.0% | 20.46 |
| Homo merged | 59.0% | 29.85 |
| Diverse merged | 80.6% | 45.90 |

合并档案的最终结果显示，异构集成的覆盖率达到80.6%，QD-Score为45.90，相比单节点的63.0%和20.46，分别提升了28%和124%。值得注意的是，同质集成的覆盖率（59.0%）甚至低于单节点，说明单纯增加并行度而未引入模型异构性，可能导致搜索资源在重叠区域浪费，反而降低了整体覆盖效率。

评估协议基于Core War的特定BC空间（时间-空间乘积与内存覆盖率），指标完备性依赖于该领域的定义。论文未提供代码仓库，且实验仅在单一竞争编程领域进行，缺乏在数学函数搜索或神经网络架构搜索等其他LLM进化任务上的验证。由于未报告GPU资源消耗与具体推理延迟分布，异步通信层的实际吞吐量优势难以独立复现。

## 关联研究分析

从问题动机看，本文与FunSearch的核心差异在于对“多样性”来源的定义。FunSearch通过大规模并行调用同一模型，依赖随机采样产生变异，其多样性受限于该模型的生成分布边界。本文则主张模型家族的差异本身是结构性的多样性来源，不同LLM的训练数据与对齐策略导致其偏好不同的代码模式，这种差异无法通过增加同一模型的采样次数来弥补。这一分歧的根源在于，FunSearch假设搜索瓶颈在于计算量，而本文认为瓶颈在于单一认知模型的归纳偏置盲区。

从方法设计看，本文与AlphaEvolve的对比揭示了异构性的维度差异。AlphaEvolve使用同一家族不同尺寸的模型（如小模型与大模型），旨在平衡吞吐量与解质量，其多样性主要源于模型容量的差异。本文则跨家族使用模型（如GPT与Claude），旨在最大化生成分布的差异。这种设计选择暗示，模型架构与训练语料的差异比模型规模的差异更能带来行为空间的互补性。然而，论文未探讨当两个模型来自同一家族但不同版本时，其生成分布的重叠程度是否足以维持QD搜索的有效性，这一盲区限制了结论在模型版本迭代场景下的适用性。

## 总结

本文针对分布式LLM进化搜索中单一模型归纳偏置导致的行为空间覆盖盲区，提出利用异构LLM家族作为变异算子，并通过异步通信机制实现跨模型对抗进化。DEI框架在Core War基准上证明，在固定计算预算下，模型多样性能带来比单纯并行度更高的QD-Score与档案覆盖率，具体表现为异构集成比单节点提升124%的QD-Score和28%的覆盖率。该结论的边界在于实验仅局限于Core War这一特定竞争编程领域，且未与FunSearch等经典基线进行直接对比，无法排除增益部分源于并行架构本身而非模型异构性。当行为空间维度增加或适应度评估成本显著上升时，异步冠军共享机制带来的覆盖增益是否仍能抵消通信开销，论文未给出回答。
