# HuggingFace最新推荐论文 ｜Sumi: Open Uniform Diffusion Language Model from Scratch ｜统一扩散语言模型的大规模原生预训练

研究机构：日本东北大学

作者：Mengyu Ye、Keito Kudo、Wataru Ikeda 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.19005)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.19005)

> 扩散语言模型旨在通过并行去噪突破自回归模型串行解码的延迟瓶颈，但现有统一扩散模型（UDLM）缺乏大规模从零预训练的参照系，导致其在数据丰富 regime 下的缩放行为与生成动态特性未知。本文切入点在于填补这一空白，构建首个 7B 参数、1.5T token 的原生 UDLM。通过基于广义插值离散扩散（GIDD）框架的从头训练，Sumi 在知识、推理与代码基准上展现出与同级自回归模型相当的竞争力，但在常识推理上存在显著差距，且其生成流畅度对画布长度高度敏感，揭示了原生统一扩散在长度自适应与自我修正机制上的未解之谜。

## 研究背景

当模型试图在固定长度的画布上恢复文本时，早期 Token 的错误决策会阻碍后续去噪进程，导致生成质量下降，这一现象称为误差累积。误差累积源于缺乏有效的回溯或修正机制，而掩码扩散语言模型（MDLM）的刚性约束——一旦填充不可修改——使得模型无法在生成过程中自我纠错。为突破这一限制，统一扩散语言模型（UDLM）允许任意 Token 在任意步更新，理论上支持更灵活的生成与自我修正，但其大规模预训练的稳定性与性能表现此前缺乏验证。

扩散语言模型的核心价值在于以并行解码与双向上下文换取全局一致性，但早期研究受制于算力与数据规模，性能远逊于自回归模型。随着 LLaDA 等大规模 MDLM 在 2025 年证明该范式可扩展，研究重心迅速转向效率优化与推理增强。然而，现有 UDLM 多为从预训练自回归模型迁移而来，或仅在较小 token 预算下训练，缺乏在数据丰富 regime 下从零训练的参照系。这使得社区难以区分 UDLM 的性能瓶颈是源于范式本身的固有缺陷，还是训练规模与数据混合策略的局限。

本文的切入点在于构建一个完全开源、从零预训练的大规模 UDLM，以提供干净的参照系。通过对比同等 token 预算的自回归模型，Sumi 旨在澄清原生统一扩散在知识、推理与代码任务上的真实能力边界，并探索其生成动态特性，如画布长度敏感性与置信度采样诱导的自组织承诺顺序。

## 核心方法

### 方法参照系

本文问题属于离散扩散语言模型的大规模预训练范畴。标准 MDLM 流程通过逐步将 Token 替换为 [MASK] 并学习反向恢复过程，但受限于固定掩码调度，无法实现 Token 的反复更新。本文的关键差异在于采用 GIDD 框架下的均匀噪声机制，允许任意 Token 在任意步更新，从而突破 MDLM 的刚性约束，旨在实现自我修正与更灵活的生成。

### GIDD 框架与 SNR 重参数化

GIDD 框架将离散扩散推广至连续时间，利用连续时间马尔可夫链描述前向腐蚀过程。本文采用其改进形式，将 GIDD 证据下界（ELBO）重参数化为信噪比（SNR）的函数，以优化训练稳定性。训练目标为最小化未加权的 ELBO 作为代理损失，同时报告真实 ELBO 用于评估。这一设计解决了离散空间下精确似然计算不可行的问题，并通过 SNR 重参数化缓解了噪声调度敏感性，使得模型在大规模预训练中保持稳定的训练损失与基准监控分数。

$$
\mathcal{L}_{\text{ELBO}}(\theta) = \mathbb{E}_{q(z_t | x_0)} \left[ \log p_\theta(x_0 | z_t) - \log q(z_t | x_0) \right]
$$

该公式表示模型通过最大化数据似然来学习去噪器，其中 $z_t$ 为噪声状态，$x_0$ 为原始数据。SNR 重参数化使得噪声强度与信号强度之间的比例关系更加明确，便于优化器调整学习率与权重衰减。

### 置信度采样与自组织承诺

置信度采样通过选择仍具噪声且模型对非当前 Token 赋予高概率的位置进行更新，诱导自组织承诺顺序。这一机制解决了 MDLM 中固定顺序解码导致的效率低下问题，使得模型能够优先确定高置信度 Token，延迟低置信度 Token 的更新。在代码任务上，这种结构允许有限的并行解码，从而提升推理速度。

$$
\Delta_t = \max_{z'} p_\theta(x = z' | z_t) - p_\theta(x = z_t | z_t)
$$

该公式计算潜在改进量，即模型对非当前 Token 的最大概率与当前 Token 概率之差。当 $\Delta_t$ 较大时，采样器选择该位置进行更新，从而实现自适应调度。

## 实验评估

实验设置采用 lm-evaluation-harness，画布长度固定为 2048，生成长度根据任务调整（BBH 512, GSM8K 64, HumanEval/MBPP 256）。基线覆盖 Falcon-7B、Llama 2-7B、OLMo-7B（自回归）及 LLaDA-8B（MDLM），但缺失其他 UDLM（如 DiffusionGemma）或最新强化学习后训练模型（如 ESPO）的对比。

| 基准 | Sumi-7B | Falcon-7B | Llama 2-7B | OLMo-7B | LLaDA-8B |
| :--- | :--- | :--- | :--- | :--- | :--- |
| MMLU (5-shot) | 51.1 | 27.2 | 46.0 | 65.9 | 65.9 |
| GSM8K (4-shot) | 32.8 | 5.3 | 13.5 | 70.3 | 70.3 |
| HumanEval (0-shot) | 22.6 | 0.0 | 12.8 | 35.4 | 35.4 |
| MBPP (3-shot) | 26.6 | 12.4 | 23.2 | 40.0 | 40.0 |
| PIQA (0-shot) | 66.4 | 80.5 | 78.7 | 73.6 | 73.6 |

Sumi 在 MMLU、GSM8K、HumanEval 和 MBPP 上表现优于 Falcon-7B 和 Llama 2-7B，但显著低于 OLMo-7B 和 LLaDA-8B。在常识推理任务（PIQA、HellaSwag、WinoGrande）上，Sumi 表现最弱，PIQA 准确率为 66.4%，远低于自回归模型的 80.5%。

消融实验显示，画布长度对生成流畅度影响显著。GSM8K 在画布长度偏离训练范围（1024-4096）时性能急剧下降，而 HumanEval 和 MBPP 在长画布上性能保持平稳。置信度采样在代码任务上实现有限并行解码，HumanEval 和 MBPP 在每步提交 4 个 Token 时准确率基本保持，但 GSM8K 在每步提交 2 个 Token 时即出现性能下降。

评估边界方面，Sumi 未报告置信区间，数值比较需谨慎。画布长度固定为 2048，未探索长度自适应机制。代码与超参数完全开源，但训练数据混合策略（教育密集型）可能导致常识推理性能下降，这一归因未直接验证。

## 关联研究分析

从问题动机看，Sumi 与 LLaDA 均旨在突破自回归模型的串行解码瓶颈，但 LLaDA 采用 MDLM 范式，受限于固定掩码调度，无法实现 Token 的反复更新。Sumi 采用 UDLM 范式，允许任意 Token 在任意步更新，理论上支持自我修正。然而，Sumi 在 GSM8K 上的准确率（32.8%）远低于 LLaDA-8B（70.3%），这可能源于 UDLM 在严格逻辑任务上的固有缺陷，而非单纯的训练规模差异。

从方法设计看，Sumi 与 DiffusionGemma 同为 UDLM，但 DiffusionGemma 基于预训练自回归模型迁移，而 Sumi 是从零训练。DiffusionGemma 在迁移过程中保留了自回归模型的语义表示能力，而 Sumi 需从头学习双向注意力与去噪目标。Sumi 在 MMLU 上的准确率（51.1%）低于 DiffusionGemma 的参考值（据领域综述，DiffusionGemma 在 MMLU 上表现优于同级自回归模型），这可能表明从零训练 UDLM 在知识密集型任务上面临更大的优化挑战。

## 总结

本文要解决的核心矛盾是统一扩散语言模型在大规模从零预训练下的性能与动态特性未知。Sumi 抓住的切入点在于构建首个 7B 参数、1.5T token 的原生 UDLM，通过 GIDD 框架与 SNR 重参数化实现稳定训练，并通过置信度采样诱导自组织承诺顺序。实验证明，Sumi 在知识、推理与代码基准上展现出与同级自回归模型相当的竞争力，但常识推理性能显著落后，且生成流畅度对画布长度高度敏感。本文的边界在于未探索长度自适应机制与自我修正的有效性，画布长度固定为 2048，且未验证教育密集型数据混合对常识推理性能下降的具体贡献。当画布长度偏离训练范围时，GSM8K 性能急剧下降，这一现象是否源于 UDLM 范式的固有缺陷，还是训练数据混合策略的局限，论文未给出回答。
