# HuggingFace最新推荐论文 ｜Geometric Action Model for Robot Policy Learning ｜几何动作模型

研究机构：韩国科学技术院、瑞士苏黎世联邦理工学院

论文原文见 [arXiv](https://arxiv.org/abs/2606.17046)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.17046)

> 通用机器人策略需在执行指令时推理物理世界在自身动作下的演化，但现有视觉-语言-动作模型 (VLA) 与视频世界-动作模型 (WAM) 均局限于二维图像或潜在空间，导致深度、尺度与遮挡等三维几何线索缺失，在相机视角变化等分布外场景中泛化能力受限。本文切入点在于将预训练的几何基础模型 (GFM) 从静态特征提取器改造为动态策略骨干，通过中间层拆分与因果预测器插入，在几何潜空间内统一感知、未来状态预测与动作解码。该架构以单次前向传播实现动作与未来几何的联合生成，在保持高控制频率的同时显著提升了空间鲁棒性。其价值在于以极低的计算成本实现了几何感知的内嵌，但语义推理能力受限于冻结的文本编码器，复杂指令解析仍是潜在瓶颈。

## 研究背景

当机器人执行精细操作时，单目视觉提供的二维图像无法直接解析物体的深度、相对尺度及遮挡关系，动作解码器必须从单目线索中自行推断三维几何，这种隐式推断在相机视角或机器人初始状态发生微小变化时极易失效。几何基础模型 (Geometric Foundation Model, GFM) 如 DA3-Giant 能够从前向传播中直接输出稠密的三维点云或深度图，提供了显式的几何先验。然而，现有的几何感知 VLA 通常仅将 GFM 作为冻结的特征提取器，通过表征对齐将几何特征蒸馏到 VLM 骨干中，或在其末端附加轻量级动作头，这种静态使用方式未能利用 GFM 多层结构中的时序动态信息，导致策略缺乏对物理世界随动作演化的预测能力。

VLA 领域的主流路线依赖大规模互联网预训练的 VLM 骨干获取语义泛化能力，结合流匹配或扩散机制生成连续动作，解决了离散 Token 的控制频率与精度问题。然而，这些方法本质上仍基于二维图像先验，缺乏对三维空间几何的显式建模，导致在需要几何理解的任务中表现不佳。视频 WAM 虽然引入了时序预测，但在二维像素空间进行扩散生成，计算成本高且无法显式解决深度与遮挡问题。本文针对这一空白，提出将 GFM 直接作为策略的共享介质，使其同时承担感知编码、未来几何预测与动作解码的功能，从而在几何潜空间中实现语言条件化的时序世界建模。

## 核心方法

### 方法参照系

现有几何感知 VLA 的标准流程是：使用 VLM 处理视觉与语言输入，通过外部 GFM 提取几何特征并蒸馏至 VLM 中间层，最后由动作头生成控制信号。本文的关键差异在于摒弃了 VLM 骨干与外部 GFM 的分离架构，转而将 GFM 本身拆分为编码器与解码器，并在中间层插入因果预测器，使几何特征成为时序预测与动作生成的唯一载体。

### 几何潜空间因果预测

传统方法在 VLM 特征空间或像素空间进行未来预测，缺乏显式几何约束。本文在 GFM 的第 $L_s$ 层（交替注意力起始层）插入一个 12 层因果 Transformer 预测器 $g_\phi$。该预测器接收当前及历史时间步的几何潜特征 $\mathbf{Z}^{(L_s)}_{t'}$、本体感觉状态 $\mathbf{s}_{t'}$ 与历史动作 $\mathbf{a}_{t'-1}$ 的嵌入，以及冻结 T5 编码器生成的语言 Token $\mathbf{L}_\ell$。通过块因果自注意力机制，预测器在几何潜空间直接预测下一时刻的几何特征 $\tilde{\mathbf{Z}}^{(L_s+1)}_{t'}$ 与动作 Token $\tilde{\mathbf{a}}_{t'}$。这一设计动机在于，将动作预测与几何预测置于同一潜空间，确保动作与空间表征的紧密交互，避免了跨模态特征传递的滞后与失配。

### 特征传播与联合解码

预测出的未来几何 Token 与动作 Token 被送入 GFM 的深层块 $D_{>L_s}$ 进行特征传播。动作 Token 被复制 $V$ 次并拼接至各视角的几何 Token 序列中，通过 GFM 原有的全局注意力层处理。最终，轻量级动作头 $h_{act}$ 回归出可执行的动作块 $\hat{\mathbf{a}}_t$，而 GFM 原有的 DPT 深度头 $h_{depth}$ 解码出未来深度图。训练目标为多任务损失：

$$
\mathcal{L}_{total} = \lambda_{act}\mathcal{L}_{act} + \lambda_{feat}\mathcal{L}_{feat} + \lambda_{depth}\mathcal{L}_{depth}
$$

其中 $\mathcal{L}_{act}$ 为动作 $\ell_1$ 回归损失，$\mathcal{L}_{feat}$ 为预测未来几何 Token 与冻结 GFM 提取的真实下一帧 Token 的对齐损失，$\mathcal{L}_{depth}$ 为未来深度图的尺度不变与梯度匹配损失。该机制利用 GFM 深层块预训练的几何解码能力，将预测的未来潜特征转化为物理一致的三维结构，从而在动作生成中内嵌了世界动力学约束。

## 实验评估

实验在 LIBERO 与 LIBERO-Plus 仿真基准及真实 Franka 机器人任务上进行。基线覆盖 VLA（OpenVLA, $\pi_0$）、WAM（Cosmos-Policy）及几何感知 VLA（Spatial Forcing）。在 LIBERO-Plus 相机扰动设置下，GAM 取得 83.1% 的成功率，较 Spatial Forcing 的 0.1% 提升 83.0 个百分点，较 $\pi_0.5$ 的 72.0% 提升 11.1 个百分点。在标准 LIBERO 基准上，GAM 达到 97.6%，与 $\pi_0.5$ 的 96.9% 和 Cosmos-Policy 的 98.5% 相当。

| 方法 | 参数量 | LIBERO 原始 (%) | LIBERO-Plus 相机 (%) | 推理延迟 (ms) |
| :--- | :--- | :--- | :--- | :--- |
| OpenVLA-OFT | 7B | 84.6 | 76.6 | 77.8 |
| $\pi_0.5$ | 3.3B | 96.9 | 72.0 | 29.2 |
| Cosmos-Policy | 2B | 98.5 | 73.4 | 382.4 |
| Spatial Forcing | 3.3B | 94.0 | 0.1 | 52.5 |
| **GAM (Ours)** | **1.4B** | **97.6** | **83.1** | **6.9** |

消融实验显示，预训练对鲁棒性至关重要：移除预训练后，LIBERO-Plus 成功率从 89.7% 降至 73.4%。移除未来特征损失 $\mathcal{L}_{feat}$ 或深度损失 $\mathcal{L}_{depth}$ 对名义 LIBERO 影响微小，但在 LIBERO-Plus 上分别导致 0.7 和 0.2 个百分点的下降，表明几何动态监督主要贡献于分布外鲁棒性。上下文窗口 $H=1$ 比 $H=4$ 更鲁棒，长历史可能引入虚假相关。

评估边界方面，真实世界实验仅使用 4 个任务且每任务 200 条演示，样本量较小。推理延迟 6.9ms 基于单次前向传播，未包含多步规划开销。代码已开源，但 GFM 骨干 DA3-Giant 的预训练数据细节未在正文中完全披露，复现时需依赖其原始论文。

## 关联研究分析

从问题动机看，Spatial Forcing 与 ROCKET 同样旨在利用 GFM 增强 VLA 的空间感知，但它们将 GFM 视为静态特征源，通过蒸馏或替换编码器引入几何信息，缺乏对几何随时间演化的建模。本文的核心差异在于将 GFM 的深层块复用为未来预测的解码器，使几何动态成为策略的内生属性。这一设计源于对“几何静态性”局限的识别：在相机视角变化时，静态几何特征无法反映场景结构的时序一致性，而因果预测器通过预测未来几何 Token，强制策略学习几何随动作变化的规律，从而在分布外场景中保持鲁棒。

从方法设计看，Cosmos-Policy 等视频 WAM 在像素空间进行扩散预测，计算成本高且缺乏显式三维结构。本文在 GFM 潜空间进行因果预测，避免了多步去噪，实现了 55 倍的速度提升。然而，GFM 潜空间主要编码几何结构，对语义信息的承载能力弱于 VLM 特征空间。本文使用冻结 T5 编码器处理语言指令，语义推理能力受限。在长程复杂语义任务中，GFM 骨干是否足以解析细粒度指令，论文未给出回答。

## 总结

本文解决的核心矛盾是二维视觉先验与三维物理操作需求之间的几何缺失。现有 VLA 与 WAM 因缺乏显式几何建模，在视角扰动下泛化能力差，而静态几何特征提取无法捕捉时序动态。本文通过将 GFM 拆分为编码器与解码器并插入因果预测器，在几何潜空间统一了感知、预测与动作生成，证明了联合预测未来几何与动作能内嵌世界动力学。实验显示，GAM 在相机扰动下成功率达 83.1%，推理延迟仅 6.9ms，显著优于基线。其边界在于语义推理受限于冻结文本编码器，且真实世界验证任务数量有限。当任务指令涉及复杂语义组合或长程逻辑规划时，GFM 潜空间是否足以承载所需的语义解析能力，论文未给出回答。
