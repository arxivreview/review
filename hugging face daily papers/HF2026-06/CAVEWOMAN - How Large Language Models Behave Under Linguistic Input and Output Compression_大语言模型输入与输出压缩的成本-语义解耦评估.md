# HuggingFace最新推荐论文 ｜CAVEWOMAN: How Large Language Models Behave Under Linguistic Input and Output Compression ｜大语言模型输入与输出压缩的成本-语义解耦评估

研究机构：Adobe研究院

作者：Morayo Danielle Adeyemi、Ryan A. Rossi、Franck Dernoncourt

论文原文见 [arXiv](https://arxiv.org/abs/2606.24083)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.24083)

> 大语言模型推理成本随输入与输出Token数线性增长，且输出Token单价通常为输入的4-8倍，但现有压缩研究仅关注单侧Token减少量与任务准确率，无法区分“实际成本降低”与“表面Token缩减”，亦无法识别“答案正确但推理逻辑偏离”的隐蔽失效。CAVEWOMAN提出双通道评估协议，在固定模型与题目条件下，同步测量输入压缩（词性过滤）与输出压缩（风格约束）在五个缩减层级下的任务准确率、实际计费成本及参考文本一致性。该协议揭示了输入压缩因输出补偿导致净成本上升的反直觉现象，以及输出压缩下51.9%的正确生成存在语义偏离，为压缩方法提供了超越准确率的成本-语义双维审计标尺，但其基于确定性词性过滤的输入压缩机制是否代表真实场景最优压缩策略，仍存疑。

## 研究背景

Transformer推理成本由输入与输出Token数共同决定，输出Token单价显著高于输入，这一经济结构使得“减少Token数”不等于“降低实际成本”。当模型在输入压缩后生成更长响应时，节省的输入成本可能被高昂的输出成本抵消，甚至导致净成本上升。这一现象要求评估指标从“Token减少量”转向“实际计费成本”，并引入“参考文本一致性”以区分“答案正确但推理路径改变”与“答案正确且推理路径一致”两种状态。

上下文压缩领域长期聚焦于如何缩短输入序列或约束输出长度，主流方法如LLMLingua系列通过困惑度或分类器剔除冗余Token，GIST等软压缩方法将提示映射为连续向量，TokenSkip等输出压缩方法通过解码控制限制生成长度。这些方法均报告“压缩后准确率@Token数”，但存在两个盲区：一是未分离实际成本与Token减少量，导致“短提示+长响应”的成本劣势被掩盖；二是将生成结果简化为二元准确率，无法识别压缩导致的语义漂移。CAVEWOMAN的切入点在于，将压缩评估从“单侧Token效率”重构为“双通道成本-语义解耦”，通过固定模型与题目，隔离压缩机制本身对成本与语义的影响，而非依赖特定任务的优化。

## 核心方法

### 双通道压缩评估框架

CAVEWOMAN将压缩评估置于“输入压缩”与“输出压缩”双通道框架下，核心差异在于：传统方法仅评估单侧压缩的准确率，而本文在固定模型$M$与题目$x$条件下，同步测量两侧压缩在五个缩减层级$\ell \in \{0,1,2,3,4\}$下的三轴指标。输入压缩通过确定性词性过滤$\phi_\ell(x)$修改用户提示，输出压缩通过系统提示约束模型响应风格，两者共享同一缩减层级家族，确保可比性。

### 词性过滤缩减层级

输入压缩采用基于Penn Treebank词性标签的确定性过滤，设计动机是提供透明、可审计的压缩机制，避免学习型压缩器的黑盒性干扰成本归因。缩减层级定义为嵌套子序列：

$$\phi_\ell(x) = \{w_i \mid g(w_i) \in S_\ell, i \in \mathcal{I}_\ell\}$$

其中$g(w_i)$为词性标签，$S_\ell$为层级$\ell$保留的标签集合，$\mathcal{I}_\ell$为索引递增序列。L1（电报式）移除限定词、介词、连词等封闭类标签；L2（关键词）仅保留名词、动词与基数词；L3（名词短语骨架）仅保留名词与基数词；L4（15-Token预算）在L3基础上截断至前15个Token。该嵌套结构确保相邻层级间的准确率变化可归因于特定词类移除，而非压缩机制本身的不稳定性。

### 三轴评估指标

参考文本一致性通过双向自然语言推理（NLI）蕴含关系操作化，设计动机是区分“命题内容一致”与“词汇形式一致”，避免表面文本差异被误判为语义偏离。一致性指标定义为：

$$\text{Agreement}(y_\ell, y_0) = \mathbb{1}[\text{NLI}(y_\ell \models y_0) \land \text{NLI}(y_0 \models y_\ell)]$$

其中$y_\ell$为层级$\ell$的生成结果，$y_0$为同通道无约束基线生成结果，$\text{NLI}$为DeBERTa-based NLI判断器。该指标与任务准确率、实际计费成本$C = n_{in}p_{in} + n_{out}p_{out}$共同构成三轴评估，其中$n_{in}, n_{out}$为输入/输出Token数，$p_{in}, p_{out}$为对应单价。解离表（Dissociation Table）进一步将生成结果划分为$C_1$（正确+蕴含）、$C_2$（正确+不蕴含）、$C_3$（错误+蕴含）、$C_4$（错误+不蕴含）四格，其中$C_2$为“正确但语义偏离”的关键失效模式，准确率指标无法识别。

## 实验评估

实验在GSM8K、BoolQ、ARC-Easy、CommonsenseQA、MMLU-STEM五个基准上评估8个模型（Qwen2.5-VL-7B、Qwen3.5-9B、DeepSeek-R1-Distill-Qwen7B、Gemma-4-E4B、GPT-4o、GPT-5.4、Claude Haiku 4.5、Claude Sonnet 4.6），基线覆盖硬压缩（LLMLingua-2）与输出压缩（TokenSkip类方法），但缺失ICAE、GIST等软压缩SOTA，构成评估空白。

| 模型 | 输入压缩净成本变化（L1） | 输出压缩成本降低倍数（L1） |
| :--- | :--- | :--- |
| GPT-4o | -2.6% | 1.4× |
| GPT-5.4 | +15.4% | 2.4× |
| Claude Haiku 4.5 | +3.1% | 1.4× |
| Claude Sonnet 4.6 | +5.1% | 2.4× |

输入压缩在L1层级导致GPT-5.4净成本上升15.4%，Claude Sonnet 4.6上升5.1%，而输出压缩在相同层级下降低GPT-5.4成本2.4倍、Claude Sonnet 4.6成本2.4倍，证实成本不对称性。在六个非推理模型上，51.9%的L1输出压缩生成属于$C_2$格（正确但不蕴含L0参考），长度匹配重评分后该比例升至80.4%，表明语义偏离非长度效应所致。

评估边界方面，输入压缩采用确定性词性过滤，未测试学习型压缩器（如LLMLingua-2）在成本维度上的表现，仅附录D验证其$C_2$率>70%；输出压缩依赖系统提示约束，未涉及解码器修改或后训练方法；NLI判断器在L1合成正对上的假阴性率为2.9%，但11项互补语义指标均报告显著偏离，鲁棒性可接受。代码与数据公开于GitHub，但推理配置与定价细节依赖附录，可复现性受限于API定价动态变化。

## 关联研究分析

从问题动机看，CAVEWOMAN与LLMLingua-2（Pan et al., 2024）形成互补：后者聚焦输入压缩的Token减少量与准确率，前者揭示输入压缩的实际成本劣势与语义偏离盲区。LLMLingua-2的评估协议假设“短提示=低成本”，但CAVEWOMAN证明该假设在输出Token单价高时失效，根源在于LLMLingua-2未建模输出补偿效应，而CAVEWOMAN通过固定模型与题目隔离了该效应。从方法设计看，CAVEWOMAN与TokenSkip（Xia et al., 2025）同属输出压缩路线，但TokenSkip报告“准确率@Token预算”，CAVEWOMAN报告“准确率+成本+NLI一致性”，差异在于TokenSkip将压缩视为优化问题，CAVEWOMAN将压缩视为评估对象，前者追求压缩效率最大化，后者追求压缩失效模式识别。

## 总结

CAVEWOMAN解决的核心矛盾是压缩评估中“Token减少量”与“实际成本”、“任务准确率”与“语义一致性”的解耦缺失。其切入点在于，通过固定模型与题目，将输入/输出压缩置于同一缩减层级家族下，利用确定性词性过滤与系统提示约束实现双通道可比性，从而隔离压缩机制本身对成本与语义的影响。该方法证明了输入压缩在L1层级导致GPT-5.4净成本上升15.4%，而输出压缩降低其成本2.4倍，且51.9%的正确生成存在语义偏离。其边界在于，输入压缩仅测试确定性词性过滤，未覆盖学习型压缩器的成本表现；输出压缩依赖系统提示，未涉及解码器修改。当输入压缩采用学习型压缩器时，其成本劣势是否因Token选择更优而缓解，论文未给出回答。
