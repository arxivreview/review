研究机构：Adobe研究院

论文原文见 [arXiv](https://arxiv.org/abs/2606.13898)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.13898)

> 扩散Transformer（DiT）在云端部署时，其二次复杂度导致推理延迟远高于卷积U-Net，成为大规模图像编辑服务的主要成本瓶颈。现有Token压缩方法或依赖昂贵的注意力计算，或引入质量回归，难以在生产环境中直接应用。本文提出HiLo-Token，通过Sobel边缘检测与16倍下采样并行提取高低频Token，实现输入自适应的预算分配。该方法在保持生成质量无回归的前提下，将DiT推理加速3.13倍，但缺乏公开基准的横向对比，其泛化性存疑。

## 研究背景

当DiT处理高分辨率图像时，注意力机制的计算量随Token数量平方增长，导致推理延迟成为云端服务的核心瓶颈。为降低延迟，业界通常采用时间步蒸馏，但这往往以牺牲生成质量为代价。在掩码编辑任务中，用户仅修改图像局部区域，这构成了Token稀疏性的物理基础，使得非编辑区域的计算成为冗余。

语义图像编辑领域的主流效率优化路线包括区域感知生成与激活缓存。RegionE通过区域划分与速度衰减缓存避免对未编辑区域的重复计算，但侧重于去噪步的时间冗余；LazyDiffusion利用掩码稀疏性仅生成掩码内内容，但其依赖的Transformer上下文编码器需全量计算，且丢弃了掩码外的大部分有用上下文Token。现有方法未能解决在激进Token丢弃下如何保留全局结构信息，以及如何在无注意力信号的情况下实现输入自适应的Token分配。

本文切入点在于利用图像的频率特性替代语义注意力信号。通过Sobel算子获取空间频率图，结合16倍下采样图像的低频Token，构建轻量级、无相关性依赖的Token选择机制。这一设计直接针对LazyDiffusion中上下文编码器开销大、注意力信号在遮挡场景下失效的问题，旨在实现生产级部署下的零质量回归加速。

## 核心方法

### 方法参照系

本文基于LazyDiffusion框架，该框架默认保留膨胀掩码内所有Token以维持局部性，并通过独立上下文编码器获取掩码外信息。关键差异在于，本文摒弃了基于Transformer的上下文编码器，转而采用基于频率域的并行分支策略，将Token选择从语义相关性驱动转变为空间频率驱动。

### 高频Token选择

高频分支旨在保留局部细节，避免激进下采样导致的过平滑。设计动机是解决注意力机制在遮挡场景下因内容未生成而失效的问题。本文使用Sobel算子计算空间频率图 $G = \sqrt{G_x^2 + G_y^2}$，其中 $G_x$ 和 $G_y$ 分别为水平和垂直方向的梯度。随后，对频率图进行16倍空间池化以对齐Token网格，并通过阈值（如0.1）筛选高频Token。这一过程无需语义先验，仅依赖局部边缘信息，计算开销约10ms，有效避免了跨区域依赖导致的漏选。

### 低频Token融合

低频分支旨在保留全局结构，解决仅保留掩码内Token导致的上下文丢失问题。设计动机是弥补高频Token在长距离依赖上的不足。本文将输入图像16倍下采样，通过VAE编码及线性层Patchify获取低频Token。由于下采样后Token数量极少，全部保留。最终，高频与低频Token沿Token维度拼接，形成HiLo-Token表示。该公式可表示为 $T_{final} = [T_{high}; T_{low}]$，其中 $T_{high}$ 为筛选后的高频Token，$T_{low}$ 为下采样后的低频Token。这种拼接方式确保了DiT在计算注意力时能同时感知局部细节与全局结构，且无需额外的模型组件。

## 实验评估

实验在Adobe内部407,630对图像-掩码数据上进行，基线仅对比无压缩的ME模型，缺失RegionE、FlowEdit等公开效率基线。评估依赖质量工程团队的主观偏好测试，而非FID或CLIP Score等量化指标。

| 掩码比例类别 | 平均掩码比例 | DiT加速比 | 端到端加速比 |
| :--- | :--- | :--- | :--- |
| 小 | 6.38% | 3.13× | 1.33× |
| 中 | 15.92% | 2.59× | 1.66× |
| 大 | 35.36% | 1.67× | 1.77× |

用户偏好测试显示，在移除、生成填充和生成扩展任务中，HiLo-Token与无压缩模型的“平局”率分别为48%、70%和81%，表明在大多数场景下质量无显著差异。对于生成填充任务，掩码外Token可更激进地丢弃，因为插入内容具有自包含性。

消融实验未提供详细数值，但设计决策验证了Sobel替代注意力的有效性。在遮挡对称图案（如教堂壁画前的交通标志）场景中，注意力方法因遮挡内容未生成而漏选对称区域，而Sobel方法基于边缘存在性成功保留了对称区域的高频Token。这一发现揭示了基于相关性先验的方法在早期去噪步骤中的固有缺陷。

评估边界受限于内部数据与主观指标，缺乏公开基准的横向可比性。代码未开源，超参数（如阈值0.1）未公开，可复现性受限。GPU环境为A100-80GB，未验证在H100或端侧设备上的表现。

## 关联研究分析

从问题动机看，HiLo-Token与RegionE均针对DiT的计算冗余，但RegionE侧重于时间维度的去噪步缓存，而HiLo-Token侧重于空间维度的Token压缩。RegionE通过自适应区域划分避免重复计算，但需保存注意力层的Key和Value，显存开销较大；HiLo-Token通过频率筛选减少Token数量，显存开销更低，但可能牺牲跨块语义一致性。这一差异源于任务特性：RegionE适用于全局编辑，HiLo-Token适用于局部掩码编辑。

从方法设计看，HiLo-Token与LazyDiffusion同属掩码稀疏性利用路线，但LazyDiffusion依赖Transformer上下文编码器，而HiLo-Token采用Sobel+下采样。LazyDiffusion的上下文编码器能捕获语义相关性，但计算开销大且对遮挡敏感；HiLo-Token的频率选择无相关性依赖，但可能忽略语义上重要但边缘不显著的区域。Sobel替代注意力是否牺牲了复杂语义场景的上下文关联，论文未给出回答。

## 总结

本文核心矛盾在于DiT推理延迟与生成质量之间的权衡，现有方法难以在生产环境中实现零质量回归的加速。HiLo-Token抓住图像频率特性与掩码稀疏性的结合点，通过Sobel边缘检测与16倍下采样并行分支，实现了输入自适应的Token预算分配。实验证明其在小掩码场景下实现3.13倍DiT加速，且用户偏好测试中平局率高达70%以上。本文边界在于缺乏公开基准对比，且Sobel方法在语义复杂但边缘不显著场景下的表现未知。当支持集包含大量低对比度语义区域时，频率选择是否会导致关键上下文丢失，论文未给出回答。
