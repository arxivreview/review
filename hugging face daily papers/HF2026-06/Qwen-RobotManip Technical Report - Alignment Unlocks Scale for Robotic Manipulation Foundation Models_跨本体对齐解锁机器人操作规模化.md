# HuggingFace最新推荐论文 ｜Qwen-RobotManip Technical Report: Alignment Unlocks Scale for Robotic Manipulation Foundation Models ｜跨本体对齐解锁机器人操作规模化

作者：Haoqi Yuan、Zhixuan Liang、Anzhe Chen 等 23 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.17846)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.17846)

> 视觉-语言-动作模型（VLA）旨在将自然语言指令映射为机器人控制信号，但现有模型在分布外（OOD）场景下泛化能力极差，主要受限于异构数据缺乏统一表征。本文指出数据多样性本身不足以驱动规模化，必须首先解决跨本体动作数值不一致问题。通过构建相机系增量位姿与统一状态-动作模板，QWEN-ROBOTMANIP 实现了约 38,100 小时开源数据的协同训练，在 OOD 基准上显著超越基线，但其对真实物理接触任务的鲁棒性仍存疑。

## 研究背景

当机器人执行跨本体任务时，不同形态的机械臂在关节空间与末端执行器（End-Effector, EEF）坐标系下对同一物理动作的数值表征存在系统性差异。这种异构性导致直接混合多源数据训练时，模型容量被消耗在调和冲突的动作约定上，而非学习可迁移的操作结构。解决该问题的关键概念是动作空间对齐，即通过统一的状态-动作表示，使视觉上相似的运动在不同坐标系下数值上接近，从而将数据扩展转化为能力增益而非干扰。

VLA 领域的主流路线曾聚焦于离散 Token 预测或简单的本体 Token 嵌入，但这类方法未能建立物理运动与数值表征之间的严格一致性。随着 Open X-Embodiment 等大规模数据集的出现，研究者发现仅增加数据量在缺乏对齐机制的情况下，会导致性能停滞甚至退化。现有评估体系多依赖域内（In-Domain, ID）基准，如 LIBERO，这些指标无法区分模型是真正掌握了泛化结构，还是仅仅记忆了特定分布下的模式。QWEN-ROBOTMANIP 的切入点在于将“对齐”确立为规模化的前置条件，而非独立的工程优化，并引入 OOD 评估作为衡量基础模型真实能力的核心标准。

## 核心方法

### 统一跨本体状态-动作表示

VLA 模型通常将动作离散化为 Token 或直接在原始关节空间预测，但这种方式在跨本体场景下导致数值冲突。本文采用连续动作生成范式，基于 DiT 风格的 Flow Matching 机制，将动作预测转化为去噪过程。设计动机在于消除离散化带来的精度损失，并为跨本体对齐提供连续的数值空间。

### 相机系增量位姿与上下文适应

传统方法在机器人本体坐标系下表达动作，导致不同形态机器人的动作向量无法直接比较。本文创新性地采用相机系增量位姿参数化，将 EEF 动作表达为相对于相机坐标系的位移与旋转增量。这一设计使得视觉上相似的运动在不同机器人上具有数值上的邻近性，解决了跨本体迁移中动作空间不兼容的核心失效。

$$
\mathbf{a}_t = (\mathbf{p}_t, \mathbf{R}_t, w_t)
$$

其中 $\mathbf{p}_t$ 为末端位置，$\mathbf{R}_t$ 为姿态，$w_t$ 为夹爪宽度，所有量均相对于相机坐标系定义。

此外，引入上下文策略适应机制，将单集内（intra-episode）的历史观测-动作块作为隐式本体标识符。该机制允许模型根据当前执行动态调整行为，弥补了静态本体提示（Embodiment Prompt）无法捕捉动态运动学差异的不足。

$$
\mathcal{L}_{total} = \mathcal{L}_{action} + \lambda \mathcal{L}_{vlm}
$$

通过双流共训练策略，联合优化动作预测与视觉-语言目标，防止 VLM 骨干在动作预测压力下发生感知能力退化。

## 实验评估

实验在 LIBERO、RoboTwin、RoboCasa365 及 EBench 等基准上进行，基线包括 $\pi_0$、$\pi_0.5$、StarVLA 及 GR00T 系列。QWEN-ROBOTMANIP 在 ID 基准上达到 SOTA，但在 OOD 评估中展现出显著优势。

| 基准 | QWEN-ROBOTMANIP | $\pi_0.5$ | StarVLA |
| :--- | :--- | :--- | :--- |
| LIBERO-Plus (Total) | 91.4 | 84.4 | 74.1 |
| RoboTwin-C2R (Hard) | 69.4 | 47.9 | 10.6 |
| RoboTwin-IF (Avg) | 72.2 | 49.6 | 29.4 |
| RoboTwin-XE (Avg) | 23.9 | 7.5 | - |

在 OOD 设置下，QWEN-ROBOTMANIP 在 RoboTwin-C2R Hard 设置中比 $\pi_0.5$ 高出 21.5 个百分点，在零样本跨本体迁移（RoboTwin-XE）中达到 23.9%，是 $\pi_0.5$ 的 3.2 倍。消融实验显示，移除统一 EEF 表示导致性能大幅下降，验证了相机系对齐的关键作用。

| 消融变体 | RoboTwin-C2R (Hard) | LIBERO-Plus (Total) |
| :--- | :--- | :--- |
| Full Model | 69.4 | 91.4 |
| w/o UnifiedEEF | 12.5 | - |
| w/o UnifiedSpace | 7.5 | - |
| w/o VL Co-training | 54.4 | 88.9 |

移除 VL 数据共训练导致 RoboTwin-C2R Hard 性能下降 8.2 个百分点，表明视觉-语言流对维持复杂场景下的泛化能力至关重要。

评估边界方面，论文未报告计算效率指标，且部分真实世界任务（如黄色圆盘插入）成功率较低（2/5），表明精细接触操作仍是瓶颈。代码已开源，但超参数细节需查阅技术报告。

## 关联研究分析

从问题动机看，QWEN-ROBOTMANIP 与 HiMoE-VLA 均致力于解决跨本体异构性，但 HiMoE-VLA 采用层级混合专家（MoE）路由机制，通过动态分配 Token 至特定专家来处理不同动作维度。相比之下，本文采用统一表征与相机系对齐，避免了 MoE 路由带来的计算开销与训练复杂度，但可能牺牲了对极端异构形态的适应性。这种差异源于任务特性：本文聚焦于桌面操作，动作空间相对规整，而 HiMoE-VLA 更适用于形态差异极大的场景。

从方法设计看，Zero-WAM 利用人类视频作为上下文实现零样本泛化，但依赖部署时的上下文推断，计算延迟较高。QWEN-ROBOTMANIP 通过 Human-to-Robot 合成流水线将人类视频转化为机器人轨迹，在预训练阶段完成对齐，实现了更高效的推理。然而，合成数据的物理一致性可能引入偏差，这在接触丰富任务中可能成为性能上限。

## 总结

QWEN-ROBOTMANIP 解决了跨本体数据规模化中“对齐不足导致干扰”的核心矛盾，通过相机系增量位姿与统一状态-动作模板，使约 38,100 小时开源数据产生协同效应。实验证明其在 OOD 基准上显著优于 $\pi_0.5$，如 RoboTwin-C2R Hard 设置中 69.4% 对 47.9% 的优势。然而，论文在真实世界精细接触任务（如黄色圆盘插入）中表现有限，且未量化合成数据的物理一致性对长期稳定性的影响。当支持集增大到 5-shot 时，上下文适应机制的边际收益是否递减，论文未给出回答。
