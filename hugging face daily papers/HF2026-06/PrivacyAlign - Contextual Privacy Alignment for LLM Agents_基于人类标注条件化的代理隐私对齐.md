作者：Manveer Singh Tamber、Abhay Puri、Marc-Etienne Brunet 等 6 人

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.21710)

> 导读 Agentic AI 在访问工具与持久记忆后，常将敏感细节泄露至外部动作，而现有评估与训练依赖不可靠的自动代理，无法捕捉人类对“适当披露”的规范判断。本文切入点在于将人类判断从评估标签提升为训练信号的核心，通过构建含 3,516 条标注的 PrivacyAlign 数据集，提出在强化学习（RL）中直接注入同提示人类标注作为奖励引导的方法。该方法使 4B 开放权重模型在隐私对齐上接近闭源前沿模型，但其效果高度依赖标注质量与上下文条件化机制，且未提供形式化隐私保证。

## 研究背景

当代理执行邮件发送或日历更新时，它需判断哪些信息属于“任务必要”，哪些属于“敏感隐私”。这一判断并非简单的实体识别，而是基于社会角色与关系规范的上下文完整性（Contextual Integrity, CI）决策。CI 理论指出，信息流动的合法性取决于其是否符合特定情境下的预期，而非信息本身是否为个人可识别信息（PII）。然而，现有代理隐私研究多将 CI 简化为静态规则或 LLM 自判，忽视了人类规范在定义“泄露”与“遗漏”中的构成性作用。

主流路线分为两类：一类是推理时过滤，如 AirGapAgent 和 PrivacyChecker，它们在模型外部拦截敏感数据，但无法改变模型内部的决策逻辑；另一类是训练时对齐，如 CI-RL 使用字符串匹配奖励，PrivAct 使用 DPO 与敏感项列表，但二者均依赖 LLM 生成的合成项或预定义规则，未直接对齐人类对隐私边界的判断。这些方法的瓶颈在于：自动代理（规则或 LLM 裁判）无法可靠区分“任务必要”与“敏感”的细微差异，导致过度删除或过度披露。本文的切入点是：人类判断不仅标注隐私违规，更定义了违规本身，因此必须将人类标注直接嵌入训练与评估循环。

## 核心方法

### 方法参照系

本文问题属于代理对齐中的隐私维度，最接近的通用流程是基于人类反馈的强化学习（RLHF）。标准 RLHF 训练标量奖励模型预测人类偏好，再用于策略优化。本文的关键差异在于：奖励信号不依赖预训练的奖励模型权重，而是在评分时直接注入同提示的人类标注作为上下文引导，解决了标准 RLHF 中奖励模型无法捕捉情境特定规范的问题。

### 标注条件化成对裁判

在 RL 评分阶段，通常做法是使用训练好的奖励模型对候选响应打分。本文改为使用一个冻结的 LLM 裁判，其提示中包含当前任务、两个参考响应、同提示的人类标注 $A(x)$ 及待评分的候选响应对。裁判输出一个 $[-2, +2]$ 的偏好分数，公式为：

$$ r_{judge}(y_1, y_2 | x, A(x)) = \text{LLM}_{frozen}(x, y_1, y_2, A(x)) $$

该设计动机是：人类标注包含自由文本理由与细粒度泄露/遗漏标签，能校准裁判对“敏感”与“相关”的情境理解，避免裁判因缺乏上下文而误判。相比训练好的生成式奖励模型（gen-RM），该方法无需将人类信号蒸馏进权重，保留了标注的局部特异性，解决了 gen-RM 因平均化偏好而平滑掉真实分歧的问题。

### 生成式奖励模型训练

作为对比基线，本文也训练了 gen-RM，其目标是从任务与参考响应预测泄露标签与偏好分数。训练损失为预测分数与人类标注均值的均方误差：

$$ \mathcal{L}_{gen} = \mathbb{E}_{x} \left[ \left( \hat{r}_{gen}(x) - \bar{r}_{human}(x) \right)^2 \right] $$

该设计动机是验证“将人类信号蒸馏进权重”是否足以替代“上下文条件化”。实验表明，gen-RM 虽提升隐私召回，但遗漏率显著上升，说明其过度聚焦泄露抑制而忽视任务相关性，暴露了权重蒸馏在捕捉情境细微差别上的局限。

## 实验评估

实验在自建 PrivacyAlign（1,350 样本）及外部基准 PrivacyLens、CIMemories 上进行，基线包括 CI-RL（字符串匹配）、gen-RM（训练式）及未训练基座模型。

| 模型 | 奖励源 | Clean Rate (%) | Leak Rate (%) | Omit Rate (%) |
|---|---|---|---|---|
| Nemotron-3-Nano-4B | Annotation-Conditioned | 32.6 | - | - |
| Nemotron-3-Nano-4B | Gen-RM | - | 27.8 | 59-70 |
| Qwen3-4B | Annotation-Conditioned | 27.3 | - | - |
| Qwen3-4B | CI-RL | 24.1 | - | - |

核心对比显示，标注条件化奖励在 Clean Rate 上全面优于 gen-RM 与 CI-RL，且未显著增加遗漏率。Gen-RM 虽将泄露率降至 27.8%，但遗漏率升至 59-70%，表明其通过过度保留信息来抑制泄露，违背了隐私-效用平衡原则。CI-RL 的字符串匹配奖励虽降低泄露，但 Clean Rate 始终低于标注条件化方法，证实了规则匹配在捕捉情境规范上的结构性局限。

消融实验揭示，未训练基座模型直接作为奖励源会导致性能退化，证明近随机信号无法驱动 RL。标注条件化奖励的有效性依赖于同提示标注的可用性，若标注缺失，则退化为普通 LLM 裁判，效果显著下降。

评估边界方面，PrivacyAlign 的标注者间一致性（Cohen’s κ）在泄露标签上为 0.558，遗漏标签上仅为 0.120，表明遗漏判断存在高度主观性。代码与数据已开源（Apache 2.0），但超参数与 GPU 配置未在正文中详细披露，复现性依赖附录。

## 关联研究分析

从问题动机看，本文与 CI-RL 的核心差异在于隐私规范的来源。CI-RL 依赖 LLM 生成的敏感项列表，将隐私简化为字符串匹配，忽视了人类对“适当披露”的规范判断；本文则直接以人类标注为奖励信号，解决了 CI-RL 在工具调用与持久记忆场景下的泛化不足。这一差异源于任务特性：代理隐私是情境决策问题，无法通过预定义规则穷举，必须依赖人类判断的构成性作用。

从方法设计看，本文与 FaithJudge 共享“上下文条件化评估”思想，但 FaithJudge 仅用于幻觉评估，本文将其扩展至 RL 训练阶段。FaithJudge 的条件化对象是幻觉示例，本文的条件化对象是隐私标注，后者包含更复杂的规范判断。这一扩展的关键挑战是：人类标注的主观性（κ=0.56）是否足以替代形式化保证的合规性？论文未提供回答，但实验表明，在开放权重模型上，人类标注条件化能显著提升隐私对齐效果，接近闭源模型水平。

## 总结

本文要解决的核心矛盾是：代理隐私对齐依赖人类规范，但现有方法将人类判断排除在训练循环之外。本文抓住的切入点是：人类标注不仅评估隐私违规，更定义了违规本身，因此必须直接嵌入 RL 奖励信号。通过构建 PrivacyAlign 数据集并提出标注条件化奖励，本文证明了人类判断在代理隐私对齐中的核心作用，使 4B 开放权重模型在 Clean Rate 上达到 32.6%，接近 Gemini 3.1 Pro 的 37.3%。本文的边界在于：标注条件化奖励依赖同提示标注的可用性，且未提供形式化隐私保证，其效果高度依赖标注质量与情境特异性。当标注者间一致性较低（如遗漏标签 κ=0.120）时，奖励信号的可靠性是否足以支撑大规模部署，论文未给出回答。
