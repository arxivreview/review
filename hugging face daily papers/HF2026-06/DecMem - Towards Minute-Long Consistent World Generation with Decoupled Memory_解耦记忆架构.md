# HuggingFace最新推荐论文 ｜DecMem: Towards Minute-Long Consistent World Generation with Decoupled Memory ｜解耦记忆架构

研究机构：快手

作者：Zhenhao Yang、Xiaoshi Wu、Zhengyao Lv 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.31336)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.31336)

> 长程可控视频生成面临的核心矛盾是：模型在推理时无法有效召回早期生成的场景，导致“重访”时出现严重的时空不一致。现有方案要么依赖脆弱的3D显式记忆，要么受限于帧级隐式记忆的粒度瓶颈，且朴素的全量注意力因计算爆炸和注意力分散而失效。本文提出DecMem，通过解耦稀疏全局记忆与锚定局部记忆，在块级粒度上实现可学习的细粒度检索。该方法在Minecraft域内实现了分钟级一致生成，但其在开放域通用视频生成任务上的泛化能力尚存疑。

## 研究背景

自回归视频生成模型在长程推理中面临分布偏移与误差累积的双重挑战。当模型基于自身生成的含噪帧进行预测时，微小的初始误差会随时间步长复利式增长，导致后期画面模糊或结构崩溃。为缓解这一问题，主流范式引入了记忆机制，试图在有限的计算预算下维持长程语义一致性。然而，现有记忆机制在粒度与鲁棒性上存在根本缺陷：显式3D记忆依赖外部几何估计器，其误差会随生成时长累积并侵蚀一致性；隐式记忆则受限于帧级粒度，无法捕捉帧内的时空对应关系，且基于视场角（FOV）的启发式检索无法与生成目标联合优化。

长视频生成的核心瓶颈已从单纯的时长扩展转向精细化治理，即如何在流式约束下维持长程语义与空间一致性。2025-2026年间，Self Forcing等训练策略通过模拟自回归采样消除了曝光偏差，但并未解决推理时上下文窗口有限导致的记忆丢失问题。与此同时，朴素的全量注意力（Dense Attention）虽能实现最细粒度的记忆访问，但随序列长度线性增长的计算复杂度使其无法扩展至分钟级，且大量弱相关历史特征会稀释关键权重的注意力分配，引发“注意力分散”现象。本文切入点在于指出，解决长程一致性的关键不在于更复杂的注意力先验，而在于一种可学习的架构，能够自适应地抑制冗余并提取关键历史特征，从而在计算效率与记忆精度之间取得平衡。

## 核心方法

### 方法参照系

本文问题属于长时记忆与缓存管理路线，旨在解决自回归生成中的长程一致性退化。与通用AR视频生成不同，本文聚焦于动作可控的世界模型，其核心差异在于记忆机制需支持细粒度的时空对应而非仅语义对齐。标准流程通常采用滑动窗口或全量注意力，但前者丢弃细粒度历史，后者面临计算爆炸与注意力分散的双重困境。

### 稀疏全局记忆（SGM）

SGM模块旨在解决全量注意力中弱相关特征稀释关键权重的问题，通过块级稀疏检索实现高效且细粒度的长程记忆访问。传统方法将帧作为不可分割单元进行检索，无法捕捉帧内细节；SGM将潜空间帧划分为$M$个非重叠块，通过池化特征计算相关性，仅对Top-$k$相关块执行密集注意力。

$$
C_{t,i} = \text{Top}_k(\text{Attn}(\bar{q}_{t,i}, \bar{K}_{1:T}))
$$

其中$\bar{q}_{t,i}$为当前帧第$i$块的池化特征，$C_{t,i}$为检索到的关键历史块集合。该设计将注意力计算从全序列降至Top-$k$块，既避免了线性增长的计算开销，又突破了帧级粒度瓶颈，使模型能精确召回远距离场景中的局部细节。

### 锚定局部记忆（ALM）与门控融合

ALM模块针对长程外推中注意力分布不稳定导致的时序漂移问题，通过严格限制注意力范围至最近$w$帧，提供高置信度的局部锚点。SGM虽能获取全局记忆，但其稀疏检索可能引入噪声，导致注意力分散；ALM通过滑动窗口机制稳定局部过渡，防止全局检索中的长尾干扰破坏短期保真度。

$$
o_t = o^{[alm]}_t + G_t \odot o^{[sgm]}_t
$$

其中$G_t$为基于当前帧特征学习的门控向量。该解耦架构将全局检索与局部锚定分离，通过可学习门控自适应权衡长程一致性与短期保真度。SGM提供细粒度记忆能力，ALM提供稳定性基线，二者融合后有效缓解了单一机制在长程推理中的失效模式。

## 实验评估

实验在Minecraft数据集上进行，基线包括Oasis、MineWorld（滑动窗口）和WorldMem（FOV检索）。所有模型初始化为221帧记忆库，生成后续120帧。DecMem在训练窗内与外推阶段均显著优于基线，尤其在长程外推中表现出更强的鲁棒性。

| 方法 | 训练窗内 PSNR↑ | 训练窗内 LPIPS↓ | 外推 PSNR↑ | 外推 LPIPS↓ |
| :--- | :--- | :--- | :--- | :--- |
| MineWorld | 20.2989 | 0.1789 | 14.6109 | 0.3736 |
| Oasis | 26.5414 | 0.0797 | 19.1401 | 0.2673 |
| WorldMem | 24.1293 | 0.1196 | 13.4232 | 0.4475 |
| **DecMem** | **30.0785** | **0.0494** | **25.2294** | **0.1006** |

DecMem在外推阶段PSNR达到25.2294，较WorldMem提升11.8062，较Oasis提升6.0893，表明其细粒度记忆机制在长程生成中有效抑制了误差累积。

消融实验验证了SGM与ALM的必要性。移除SGM导致模型退化为局部上下文生成器，长程一致性迅速丧失；移除ALM则在600帧后出现严重退化，FID和LPIPS均劣于朴素Dense Attention。Top-$k$检索块数实验显示，$k=80$时性能最佳，$k=100$时PSNR和FID反而下降，表明过大的检索范围会稀释上下文并削弱与ALM的互补性。

| $k$ | 长程外推 PSNR↑ | 长程外推 FID↓ |
| :--- | :--- | :--- |
| 20 | 19.6497 | 27.7425 |
| 50 | 19.9425 | 27.0902 |
| **80** | **20.5896** | **25.2748** |
| 100 | 20.5535 | 25.8790 |

评估边界受限于Minecraft域内数据，未覆盖通用视频生成基准如VBench。指标仅包含PSNR、LPIPS、FID，缺乏对叙事连贯性或物理合理性的细粒度评估。代码未公开，但提供了项目页面，超参数（如64 H200 GPU、batch size 64）已披露，可复现性中等。

## 关联研究分析

从方法设计看，DecMem与Spatia等显式3D记忆方法形成鲜明对比。Spatia依赖可更新3D点云作为几何记忆，其优势在于精确的空间布局追踪，但代价是点云维护的高复杂度及3D估计器误差的累积。DecMem主张细粒度隐式块检索优于显式3D，认为几何先验的脆弱性限制了长程一致性。这一分歧根源在于任务特性：Minecraft场景具有强几何结构且动作可控，隐式检索足以捕捉时空对应；而在开放域场景中，缺乏明确几何先验时，显式记忆可能更具优势，但论文未提供跨域对比证据。

从问题动机看，DecMem与Self Forcing等训练策略路线存在互补而非竞争关系。Self Forcing通过训练阶段模拟自回归采样消除曝光偏差，解决的是分布不匹配问题；DecMem通过推理时记忆架构解决的是上下文窗口有限导致的记忆丢失问题。二者分别作用于训练与推理阶段，理论上可结合使用。然而，论文未探讨DecMem与Self Forcing联合训练的效果，也未验证在缺乏Self Forcing训练策略的情况下，DecMem能否独立解决长程误差累积问题。这种隔离评估限制了对其通用性的判断。

## 总结

本文要解决的核心矛盾是长程可控视频生成中记忆精度与计算效率的权衡。现有方法要么受限于帧级粒度，要么依赖脆弱的3D估计器，且朴素全量注意力因注意力分散而失效。DecMem通过解耦稀疏全局记忆与锚定局部记忆，在块级粒度上实现可学习的细粒度检索，有效缓解了注意力分散问题。实验表明，其在Minecraft域内长程外推PSNR达25.2294，显著优于基线。然而，其边界在于仅在单一游戏域内验证，缺乏通用视频生成基准的横向对比，且未探讨与主流训练策略的协同效应。当场景从结构化游戏环境扩展至开放域自然场景时，块级隐式检索是否仍能维持细粒度时空一致性，论文未给出回答。
