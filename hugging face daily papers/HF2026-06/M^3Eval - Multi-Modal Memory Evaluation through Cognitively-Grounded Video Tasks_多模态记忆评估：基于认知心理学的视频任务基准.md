论文原文见 [arXiv](https://arxiv.org/abs/2606.05008)

> 多模态大语言模型在长视频理解中面临的核心瓶颈并非上下文长度，而是记忆机制本身的失效，即模型无法在并发、干扰或交错输入下维持信息的独立性与保真度。现有视频基准主要评估感知与推理能力，将记忆视为隐含组件，缺乏对记忆容量、保真度及抗干扰性的系统性隔离测量。本文提出 M3Eval，首个基于认知心理学范式构建的多模态记忆评估框架，通过分屏、干扰、交错及 N-Back 四类受控视频任务量化模型的记忆缺陷。该基准揭示了当前 SOTA 模型在来源归因与符号记忆上的严重短板，但其结论是否源于任务设计的过度简化，仍需结合真实场景验证。

## 研究背景

当模型处理包含多个并发事件或语义相似片段的长视频时，其内部表征常发生混淆，导致将干扰视频的内容错误归因于目标视频，这一现象在认知心理学中被称为“记忆干扰”。干扰机制的复杂性要求评估必须区分“前摄干扰”（旧信息阻碍新信息提取）与“倒摄干扰”（新信息覆盖旧信息），而传统视频问答任务仅关注最终答案的正确性，无法解耦这两种方向相反的干扰效应。此外，模型在将视觉片段抽象为符号属性（如场景、动作）并进行跨时间步比较时，表现出显著的符号记忆缺失，这限制了其在需要抽象推理的长程任务中的表现。

视频理解领域的主流评估路线长期聚焦于时间定位精度（如 IoU）与通用问答准确率，这些指标隐含假设模型具备可靠的记忆基础，却未直接测量记忆机制本身。例如，Charades-STA 等基准通过回归头预测时间区间，其性能提升往往归功于强化学习对边界对齐的优化，而非模型对视频内容记忆保真度的改善。这种评估盲区导致研究者难以区分模型是“记住了内容但定位不准”还是“根本没记住内容”。M3Eval 的切入点在于将认知心理学的受控实验范式迁移至视频领域，通过构造特定结构的视频刺激（如分屏、交错序列），强制模型暴露其在编码、存储与提取阶段的具体失效模式，从而填补了多模态记忆系统性评估的空白。

## 核心方法

### 评估框架参照系

本文问题归属于多模态基准测试类别，但与传统视频理解基准的关键差异在于评估目标的解耦。传统基准（如 Video-MME）评估的是“理解能力”，即模型能否从视频中提取语义并回答问题；M3Eval 评估的是“记忆能力”，即模型在特定干扰条件下能否维持信息的独立表征与准确提取。这一差异决定了其任务设计必须引入控制变量，以隔离记忆机制与其他认知过程（如视觉感知、语言推理）的耦合效应。

### 受控视频任务构造

设计动机在于解决现有基准无法区分“感知错误”与“记忆错误”的问题。M3Eval 通过四种范式实现机制隔离：分屏任务（Divided Attention）测试并发输入下的独立表征维持能力；干扰任务（Memory Interference）通过交换视频顺序量化前摄与倒摄干扰；交错任务（Interleaved Events）测试时间重组能力；N-Back 任务测试符号抽象与跨时间步比较能力。以干扰任务为例，其核心度量公式为：

$$ IR = \frac{N_{intrusion}}{N_{total}} $$

其中 $N_{intrusion}$ 为模型选择来自竞争视频选项的次数，$N_{total}$ 为总问题数。该公式直接量化了跨视频内容侵入的比例，而非仅关注最终答案的正确性，从而揭示了模型在语义相似内容下的混淆程度。

### 认知心理学范式映射

设计动机在于利用心理学中成熟的记忆理论作为评估的理论基础，确保任务设计的科学性与可解释性。M3Eval 将心理学中的“有限注意力资源”理论映射为分屏任务，将“竞争遗忘”理论映射为干扰任务，将“图式组织”理论映射为交错任务，将“符号表征”理论映射为 N-Back 任务。以 N-Back 任务为例，其匹配判断公式为：

$$ Match = \mathbb{1}[Attr(v_t) = Attr(v_{t-N})] $$

其中 $Attr(\cdot)$ 表示视频片段的抽象属性（如场景类别或动作类型），$N$ 为滞后距离。该公式要求模型将视觉输入抽象为符号，并在时间轴上进行比较，直接测试了模型的符号记忆容量与保真度，而非简单的视觉相似度匹配。

## 实验评估

实验在 2,403 个问题、451 个视频（约 403 小时）上进行，评估对象包括 Gemini-3.1-Pro-Preview、GPT-5.4、Qwen3.5 系列、InternVL3.5-8B 及两个 Agent 方法（VideoLucy, M3-Agent），并引入人类表现作为参照。基线覆盖了两类主流路线：闭源大模型与开源 VLM/Agent，但缺失传统基于回归头的时序定位模型（如 Moment-DETR），这限制了与定位精度 SOTA 的直接对比。

| 模型 | 分屏-来源识别 (Acc%) | 干扰-前摄 (Acc%) | 交错-来源识别 (Acc%) | N-Back-场景 (Acc%) |
| :--- | :--- | :--- | :--- | :--- |
| Human | 89.58 | 94.55 | 75.95 | - |
| Gemini-3.1-Pro-Preview | 62.50 | 63.64 | 43.04 | - |
| GPT-5.4 | 52.50 | 43.64 | 43.04 | - |
| Qwen3.5-27B | 35.42 | 45.45 | 39.24 | - |
| M3-Agent | 42.50 | 43.64 | 27.85 | - |

注：N-Back 具体数值未在表格中完整列出，据论文正文，GPT-5.4 在 N-Back 中表现最佳，但多数模型仅略高于随机基线（25%）。

核心数字对比显示，人类在分屏来源识别上达到 89.58%，而最佳模型 Gemini-3.1-Pro-Preview 仅为 62.50%，差距显著。在干扰任务中，人类表现出明显的前摄-倒摄不对称性（∆=20.00%），而模型的两类干扰水平相近，表明其记忆机制与人类存在根本差异。

消融分析揭示了两个反直觉发现：首先，重复干扰视频片段反而提升了模型对目标视频的理解，暗示重复策略可能通过强化记忆痕迹来缓解干扰；其次，模型在空间来源归因（分屏）上的准确率普遍高于时间来源归因（交错），许多模型在交错任务中甚至低于随机基线，表明时间维度的来源接地能力是更严重的瓶颈。

评估边界方面，M3Eval 未报告计算效率指标（如推理时间、Token 数），且视频素材来源于现有长视频数据集，可能存在领域偏差。代码已开源，但超参数配置（如视频采样率、问题生成提示词）的详细复现指南在正文中未完全披露，仅指向附录。

## 关联研究分析

从问题动机看，M3Eval 与 TempR1 等强化学习时序定位方法存在根本差异。TempR1 通过过程奖励提升时间边界预测精度，其假设是模型已具备可靠的内容记忆，仅需优化定位策略；而 M3Eval 揭示模型在基础记忆（如来源识别）上接近随机水平，暗示 RL 可能未触及记忆混淆的根本缺陷。这一差异源于任务定义的不同：TempR1 关注“何时发生”，M3Eval 关注“是否记住”。若模型记忆保真度不足，RL 优化的定位精度可能建立在错误的记忆表征之上，导致在复杂干扰场景下性能骤降。

从方法设计看，M3Eval 与 GroundVTS 等长视频高效推理方法形成互补。GroundVTS 通过查询引导的 Token 采样保留关键时序线索，旨在解决输入瓶颈；M3Eval 则测试采样后信息的保真度与抗干扰性，旨在解决表征瓶颈。两者在“保留”与“验证”上形成闭环：GroundVTS 决定哪些信息进入模型，M3Eval 评估这些信息在模型内部是否被正确存储与提取。然而，M3Eval 未测试 GroundVTS 等采样策略对记忆保真度的具体影响，这限制了其结论对实际系统设计的直接指导意义。

## 总结

M3Eval 要解决的核心矛盾是多模态模型在长视频理解中记忆机制失效但缺乏系统性评估的问题。其切入点在于将认知心理学的受控实验范式迁移至视频领域，通过分屏、干扰、交错及 N-Back 任务隔离记忆的不同维度，这是传统视频基准无法做到的。本文构建了首个多模态记忆评估基准，揭示了模型在来源归因与符号记忆上的严重短板，如 Gemini-3.1-Pro-Preview 在分屏来源识别上仅为 62.50%，远低于人类的 89.58%。其边界在于任务设计可能过度简化了真实视频的非线性时序结构，且未评估现有高效推理策略对记忆保真度的影响。当视频内容从语义相似变为语义无关时，模型的干扰模式是否会发生质变，论文未给出回答。
