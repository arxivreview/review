# HuggingFace最新推荐论文 ｜InSight: Self-Guided Skill Acquisition via Steerable VLAs ｜可操控视觉-语言-动作模型中的自主技能获取

研究机构：美国斯坦福大学、美国普林斯顿大学

论文原文见 [arXiv](https://arxiv.org/abs/2606.24884)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.24884)

> 视觉-语言-动作模型（Vision-Language-Action, VLA）的能力受限于训练数据中已有的技能，导致机器人在面对新任务时无法执行未见过的操作。现有方法要么依赖大量人工演示，要么在测试时通过推理组合已有技能，但无法将新技能持久化到策略中。INSIGHT 通过原语级分割与视觉-语言模型（Vision-Language Model, VLM）引导的数据飞轮，实现了零目标技能演示下的自主技能扩展。该框架在真实世界中验证了可行性，但受限于单轴运动原语的复杂度，其通用性仍存疑。

## 研究背景

机器人操作策略通常依赖密集的人工遥操作演示进行模仿学习，这导致每个新任务都需要高昂的数据采集成本。当 VLA 模型在特定任务（如抓取）上训练后，其策略空间被锁定在演示分布内，无法泛化到语义相关但动作不同的新任务（如倾倒）。这种“技能边界”问题源于模仿学习仅记忆演示行为，缺乏对物理世界动态的深层理解，使得模型在分布外（Out-of-Distribution, OOD）状态下表现脆弱。

当前主流路线分为两类：一是测试时组合，如 Code-as-Policies，利用大语言模型在推理阶段组合预定义技能，但底层策略未更新，无法积累新能力；二是强化学习（Reinforcement Learning, RL）后训练，如 SimpleVLA-RL，通过奖励信号提升鲁棒性，但真实世界 RL 面临样本复杂度极高与安全约束的双重瓶颈。INSIGHT 的切入点在于利用操作技能的组合性：新技能往往复用已有原语（Primitive）的新组合。通过使 VLA 具备原语级可控性，并利用 VLM 识别缺失原语、生成演示数据，INSIGHT 将技能获取从“全任务模仿”降维为“原语级扩展”，从而在零新演示条件下实现技能持久化。

## 核心方法

### 原语分割与 VLA 可控性构建

标准 VLA 训练将完整任务演示作为监督信号，导致动作与语义指令纠缠，无法单独控制特定动作片段。INSIGHT 首先通过自动分割管道将遥操作演示分解为带标签的原语序列。给定任务描述，VLM 生成预期原语计划，系统利用夹爪状态转换与末端执行器主导运动轴（$xy, z, rxy, rz$）对齐帧与原语标签。分割后的原语片段作为独立训练集，通过 LoRA 微调 VLA，使其在语言提示下执行特定原语。为提供终止信号，动作空间增加进度通道，标签范围 $[0, 1)$，当进度检测器跨越阈值时原语结束。这一设计解决了全任务指令中动作纠缠导致的不可操控性，使 VLA 成为可组合的“原语执行器”。

### VLM 引导的原语缺口发现与数据飞轮

在可控 VLA 基础上，INSIGHT 引入 VLM 作为主动代理，识别新任务中的原语缺口。设策略的原语词汇表为 $V$，VLM 为技能 $s$ 生成计划 $P = (p_1, \dots, p_n)$，原语缺口定义为 $p_i \in P \setminus V$。

$$
\text{Gap}(P, V) = \{ p_i \mid p_i \in P \land p_i \notin V \}
$$

该公式量化了当前策略能力与新任务需求之间的语义差距。对于每个缺口，VLM 分析场景并提议单轴运动参数（轴 $\{dx, dy, dz\}$ 或 $\{drx, dry, drz\}$ 及带符号幅度）。机器人执行已知原语（由 VLA 控制）与缺口原语（由 VLM 参数化低层控制器执行）的混合序列。执行后，VLM 作为裁判比较前后场景图像，判断任务成功。成功滚动的缺口原语被自动标注并加入训练集，VLA 联合原有数据与新原语重训练。此过程将 VLM 从测试时规划器转变为训练时数据生成器，实现了技能库的持久扩展。

## 实验评估

实验在 LIBERO 仿真环境（Franka Panda）与真实世界（UFactory xArm）进行，涵盖方块翻转、抽屉关闭、拧盖、倾倒及组合任务。基线包括 CaP-X（测试时组合）与 $\pi_0.5$（标准微调）。INSIGHT 在真实世界倾倒任务中达到 96% 成功率，显著高于 CaP-X 的 32% 与 $\pi_0.5$ 的 16%；在 14 原语长程组合任务中，INSIGHT 端到端成功率为 80%，而 CaP-X 仅为 4%。

| 任务 | 方法 | 成功率 (%) |
| :--- | :--- | :--- |
| 倾倒 (Pour) | INSIGHT | 96 |
| 倾倒 (Pour) | CaP-X | 32 |
| 倾倒 (Pour) | $\pi_0.5$ | 16 |
| 组合 (Twist+Pour) | INSIGHT | 80 |
| 组合 (Twist+Pour) | CaP-X | 4 |

在仿真方块翻转任务中，INSIGHT 在 246 次获取的原语滚动后达到 75% 成功率，而同等计算预算下的 RL SAC 基线成功率为 0%。消融实验显示，VLM 完成度检查对 OOD 初始状态（如从打开状态关闭抽屉）至关重要，缺失该机制会导致原语终止错误。评估边界方面，实验未报告置信区间，且真实世界任务仅限单臂操作，缺乏与双臂 SOTA（如 Z-1）的直接对比。代码与超参数未完全公开，复现需依赖项目网站提供的部分配置。

## 关联研究分析

从问题动机看，INSIGHT 与 SimpleVLA-RL 均旨在克服模仿学习的分布外脆弱性，但路径截然不同。SimpleVLA-RL 通过 RL 后训练提升策略在 OOD 状态下的鲁棒性，侧重于“纠错”；INSIGHT 则通过原语扩展解决“能力缺失”，侧重于“学习”。SimpleVLA-RL 在 LIBERO 整体基准上达到 99.1% 成功率，表明其在已知任务分布内的优化效果显著，但无法执行训练数据中完全缺失的技能。INSIGHT 的 96% 倾倒成功率证明了其在技能获取上的独特价值，但两者未在同一基准下直接对比，RL 在技能获取中的样本效率是否优于 VLM 引导的数据生成，仍是未解之谜。

从方法设计看，INSIGHT 与 STEER 共享“密集语言重标注”思想，但 STEER 将原语集视为固定，仅用于测试时控制；INSIGHT 将原语集视为动态可扩展，通过重训练持久化新技能。这一差异源于任务特性：STEER 适用于已知技能库内的参数调整，而 INSIGHT 适用于技能库外的能力扩展。然而，INSIGHT 依赖 VLM 提议单轴运动参数，这在复杂接触动力学（如多轴耦合的拧盖）中可能不足。VLM 生成的参数是否足以覆盖高维动作空间，论文未给出回答，这可能限制了其在更复杂操作任务中的适用性。

## 总结

INSIGHT 解决了 VLA 技能边界问题，通过原语级分割与 VLM 引导的数据飞轮，实现了零演示下的自主技能扩展。其核心在于将 VLM 从测试时规划器转变为训练时数据生成器，利用操作技能的组合性降低新技能获取成本。实验证明，INSIGHT 在真实世界倾倒任务中达到 96% 成功率，且在长程组合任务中显著优于测试时组合基线。然而，该方法受限于单轴运动原语的复杂度，且依赖 VLM 对场景的准确理解。当原语涉及多轴耦合或高动态接触时，VLM 提议的参数是否仍能引导成功滚动，论文未给出回答。
