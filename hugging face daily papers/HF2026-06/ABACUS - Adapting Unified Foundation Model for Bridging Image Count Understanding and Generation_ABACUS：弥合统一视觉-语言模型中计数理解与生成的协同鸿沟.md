# HuggingFace最新推荐论文 ｜ABACUS: Adapting Unified Foundation Model for Bridging Image Count Understanding and Generation ｜ABACUS：弥合统一视觉-语言模型中计数理解与生成的协同鸿沟

作者：Anindya Mondal、Sauradip Nag、Anjan Dutta

> 统一视觉-语言模型（Unified Vision-Language Models, UVLMs）旨在通过单一架构同时处理视觉理解与生成，但现有模型在细粒度实例级任务上存在显著的“协同鸿沟”：能正确计数图像中物体数量的模型，往往无法从文本提示生成精确数量的物体。ABACUS 基于 UniLIP-3B 构建，通过密度感知自适应缩放、物体性图空间锚定及循环一致性 GRPO 策略，实现了计数理解与生成的闭环自监督。该工作以 3B 参数规模在七个计数基准上超越专用模型与更大通用模型，但其对低分辨率输入的依赖及未验证的通用能力保持性，限制了其在复杂真实场景中的泛化边界。

## 研究背景

当多模态大语言模型（MLLMs）面对密集视觉场景时，其内部表征往往退化为粗粒度的数量级估计（如“大于100”），而非精确的实例级计数。这种失效源于视觉 Token 在密集排列下的空间混淆，导致模型无法区分相邻实例。为克服此局限，传统方法依赖密度图回归或专用计数头，但这些模块与生成架构割裂，无法在统一框架内实现理解与生成的相互增强。

计数理解与计数条件生成长期作为孤立任务处理，分别依赖密度图回归或外部布局规划器。现有统一模型虽能共享参数空间，但理解分支无法为生成分支提供可靠的计数监督，导致生成结果常出现数量错误。ABACUS 的切入点在于利用模型内部的注意力机制提取空间证据，并通过强化学习策略让理解分支直接评估生成输出，从而在无外部标注条件下闭合理解-生成循环。

## 核心方法

### 方法参照系

ABACUS 基于 UniLIP-3B 架构，该架构采用模块化设计，通过视觉编码器、投影层和 LLM 主干实现理解，并耦合扩散 Transformer 实现生成。与标准 UVLM 联合训练不同，ABACUS 采用分阶段策略：先稳定理解分支的计数能力，再将其作为冻结的评估器优化生成分支，关键差异在于引入了基于 Group Relative Policy Optimisation (GRPO) 的后训练机制以解决边界计数错误和生成数量偏差。

### 密度感知自适应缩放与物体性图

针对 MLLM 在密集场景下的计数失效，ABACUS 引入密度感知自适应缩放，通过冻结的 GroundingDINO 骨干计算密度分数 $s_d$，当 $s_d \ge 0.5$ 时递归将图像划分为 $2 \times 2$ 子区域，直至达到最小分辨率 $\gamma$。这一设计解决了密集场景下视觉 Token 空间混淆导致的计数偏差。同时，从 MLLM 的多头自注意力层分解出物体性图，通过隔离每个注意力头的贡献并应用可学习仿射对齐 $A(\cdot)$，计算视觉 Token 位置 $v$ 的 $\ell_2$ 范数作为物体性得分：

$$
\text{Objectness}(v) = \| r_{[l,i]} \|_2
$$

该公式将计数预测锚定在空间实例证据上，抑制了模型对虚假 Token 记忆的依赖，提升了细粒度定位精度。

### 边界感知计数策略与循环一致性 GRPO

自适应缩放必然导致物体跨越裁剪边界，引发重复计数。ABACUS 引入边界感知计数策略，通过 GRPO 训练模型将物体分类为内部、边缘或边界状态，利用嵌套的局部、边界和全局奖励消除边界歧义。在生成阶段，采用循环一致性 GRPO 策略：生成分支产生 $N$ 个候选图像，冻结的理解分支对每个候选进行计数并计算与提示数量的偏差，结合美学评分作为奖励，仅更新生成分支。这一机制实现了理解分支对生成分支的自监督，无需外部评估器或人工标注，直接弥合了理解-生成协同鸿沟。

## 实验评估

实验在 FSC-147、CARPK、ShanghaiTech、REC-8K、CoCoCount 等七个基准上进行，基线覆盖专用计数模型（如 CountGD++）和通用 VLM（如 UniLIP-3B、BAGEL）。ABACUS 在 FSC-147 Val 上取得 5.71 MAE，显著优于最强专用模型 CountGD++ 的 12.14 MAE 和基线 UniLIP-3B 的 30.19 MAE；在 CoCoCount 计数生成任务上，YOLOv9 精确匹配率达到 71%，远超 BAGEL 的 36% 和 CountGen 的 50%。

| 基准 | 指标 | ABACUS-3B | 最强专用模型 | 基线 UniLIP-3B |
| :--- | :--- | :--- | :--- | :--- |
| FSC-147 Val | MAE ↓ | 5.71 | 12.14 (CountGD++) | 30.19 |
| CoCoCount | YOLOv9 ↑ | 71 | 50 (CountGen) | 34 |
| REC-8K | MAE ↓ | 7.67 | 6.50 (GrREC) | 13.75 |

消融实验显示，移除物体性图正则化导致 FSC-147 Val MAE 从 5.71 上升至 9.63，表明空间锚定对密集场景至关重要；固定 $2 \times 2$ 网格划分虽优于单次推理，但引入边界重复计数，而自适应缩放结合边界感知策略在保持 1.2 倍推理时间的同时实现了最优精度。生成阶段的循环一致性 GRPO 比仅使用 SFT 提升 26 个点，比使用外部计数器的开环 GRPO 提升 9 个点，证实了理解分支自评估的有效性。

评估边界方面，论文未报告 MMMU 等通用理解基准，无法确认计数适配是否损害通用能力；低分辨率（<224 px）输入下物体性图失效，限制了其在监控等场景的应用；代码未公开，复现性依赖论文提供的超参数（如 LoRA r=32, GRPO β=0.04）。

## 关联研究分析

从问题动机看，ABACUS 与 WS-COC 均致力于无点级监督的计数，但 WS-COC 仅处理弱监督类无关计数，而 ABACUS 通过物体性图实现了实例级空间推理，解决了 WS-COC 在密集场景下的粗粒度估计问题。从方法设计看，ABACUS 与 BAGEL 同属统一架构，但 BAGEL 依赖外部数据平衡和多阶段优化，而 ABACUS 通过冻结理解分支进行生成训练，避免了生成损失对理解性能的干扰，这与领域共识中“联合优化易导致任务冲突”的观点形成对比，暗示解耦训练可能在特定细粒度任务上更具优势。

## 总结

ABACUS 针对统一视觉-语言模型中计数理解与生成无法协同的核心矛盾，利用模型内部注意力机制提取空间证据，并通过循环一致性 GRPO 实现自监督闭环。该工作以 3B 参数规模在 FSC-147 上取得 5.71 MAE，在 CoCoCount 上达到 71% 精确匹配率，证明了任务适配的有效性。然而，其依赖高分辨率输入且未验证通用理解能力的保持性，当支持集包含大量低分辨率或密集遮挡样本时，物体性图的空间锚定能力是否仍能维持计数精度，论文未给出回答。
