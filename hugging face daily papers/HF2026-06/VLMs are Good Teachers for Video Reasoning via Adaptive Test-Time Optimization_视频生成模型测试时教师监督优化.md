# HuggingFace最新推荐论文 ｜VLMs are Good Teachers for Video Reasoning via Adaptive Test-Time Optimization ｜视频生成模型测试时教师监督优化

研究机构：香港城市大学、快手

作者：Junhao Cheng、Liang Hou、Tianxiong Zhong 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.02564)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.02564)

> 视频生成模型（VGM）在“以视频推理”任务中常因优化目标偏向视觉保真度而违背逻辑规则，导致轨迹看似合理但因果断裂。现有测试时扩展策略如Best-of-N采样或VLM文本引导（VLM-as-Solver）无法突破模型内在生成能力的上限，因为系统性逻辑错误无法通过重复采样或语言描述修正。本文提出VLM-as-Teacher范式，将VLM角色从解题者转为教师，通过合成可微分奖励查询，在测试时在线优化VGM的LoRA模块以对齐过程约束与最终目标。该范式在符号与通用视频推理基准上取得16.7点平均增益，但84%的失败案例源于VLM感知错误，其上限受制于教师模型的视觉判别精度。

## 研究背景

当VGM执行迷宫导航或物体旋转等规则推理任务时，其生成的视频往往在视觉上连贯，却违背“不穿墙”或“保持物体完整性”等过程约束。这一现象源于VGM的训练目标主要优化视觉保真度，而非逻辑一致性，导致模型在缺乏显式规则监督时，倾向于生成符合物理直觉但违背任务规则的轨迹。为弥补这一缺陷，测试时扩展（Test-Time Scaling, TTS）策略被引入，通过增加推理时的计算量来提升性能。

主流TTS路线分为两类：一是Best-of-N采样，通过生成多个候选视频并选择最优，但受限于VGM的内在生成空间，无法纠正系统性逻辑错误；二是VLM-as-Solver，由VLM生成文本计划指导VGM，但语言提示难以精确捕捉时空细节，且VGM常无法将高层指令转化为细粒度视觉执行。本文切入点在于利用VLM强大的感知验证能力，将其转化为可微分奖励信号，直接优化VGM的生成参数，从而在测试时突破其内在逻辑上限。

## 核心方法

### 方法参照系

本文问题属于视频生成推理机制范畴，标准流程为VGM生成轨迹后由外部评估器打分。关键差异在于，本文不依赖离线训练或固定评估，而是在推理阶段动态更新VGM参数，将VLM从静态评估者转变为在线优化教师。

### 任务自适应奖励合成

VLM-as-Solver范式失效于语言描述无法覆盖细粒度时空约束，本文通过VLM Teacher从任务描述中自动提取规则，转化为二元奖励查询。设计动机是解决通用奖励函数无法适配异构规则任务的问题。给定任务条件 $\mathbf{c}$，VLM Teacher生成一个目标达成查询 $q_{goal}(\mathbf{c})$ 和 $M$ 个过程监督查询 $\{q_{proc}[m](\mathbf{c})\}_{m=1}^M$，所有查询均为正向表述，即回答“Yes”表示满足约束。该机制将过程约束（如物体完整性）与最终目标（如到达终点）解耦，确保轨迹既合规又达成目的。

### 测试时在线优化

VLM-as-Solver无法解决VGM执行能力不足的问题，本文通过可微分VQA损失直接优化VGM的LoRA模块。设计动机是绕过文本-视觉转换鸿沟，直接对齐视觉执行。对于每个奖励查询 $q \in Q(\mathbf{c})$，定义VQA损失为：

$$ \mathcal{L}_{VQA}(q, \mathbf{v}) = -\sum_{\ell=1}^{L} \log P_{\psi}(a_{+\ell} | q, \mathbf{v}, a_{+<\ell}) $$

其中 $P_{\psi}$ 为冻结的VLM Teacher，$a_{+}$ 为目标答案“Yes”的token序列。该公式通过反向传播VLM对“Yes”的置信度，驱动VGM生成更符合规则的轨迹。总损失 $\mathcal{L}_{Multi-VQA}$ 结合目标与过程项，通过梯度更新LoRA参数 $\phi_n$，直至损失低于阈值 $\tau_L$ 或达到最大步数 $N$。

## 实验评估

实验在VBVR-Bench（符号推理）和RULER-Bench（通用推理）上进行，基线包括Sora 2、Veo 3.1、Kling 2.6及Pass@N、VideoTPO等测试时策略。本文方法在VBVR-Bench上整体得分0.781，较基线Wan2.2-5B的0.676提升0.105；在RULER-Bench上平均得分68.2，较基线46.4提升21.8点。

| 基准 | 方法 | 整体得分 | 域内平均 | 域外平均 |
|---|---|---|---|---|
| VBVR-Bench | Wan2.2-5B | 0.676 | 0.713 | 0.639 |
| VBVR-Bench | + Pass@5 | 0.701 | 0.741 | 0.661 |
| VBVR-Bench | + VideoTPO | 0.663 | 0.697 | 0.629 |
| VBVR-Bench | + Ours | 0.781 | 0.803 | 0.759 |
| RULER-Bench | Wan2.2-5B | 46.4 | - | - |
| RULER-Bench | + Pass@5 | 49.1 | - | - |
| RULER-Bench | + VideoTPO | 50.3 | - | - |
| RULER-Bench | + Ours | 68.2 | - | - |

消融实验显示，移除过程奖励导致得分降至0.692，移除目标奖励降至0.688，证明两类奖励互补。步数蒸馏将生成成本从87秒降至14秒，仅造成0.010的性能下降，验证了高效适配的可行性。

评估边界方面，VBVR-Bench使用规则检测器，RULER-Bench依赖GPT-o3评分，后者存在主观性。论文未提供代码，但开源了Wan2.2和Qwen3-VL组件，超参数如LoRA秩16、学习率5e-5已公开，可复现性中等。

## 关联研究分析

从问题动机看，本文与Wan-R1同属视频生成推理机制，但Wan-R1侧重离线强化学习训练，而本文聚焦测试时在线优化。差异根源在于任务特性：Wan-R1针对迷宫等固定规则任务，可预先定义奖励；本文面对异构规则任务，需动态合成奖励，因此选择测试时优化以适配长尾场景。

从方法设计看，本文与VideoTPO同属VLM引导生成，但VideoTPO通过文本迭代优化Prompt，本文通过梯度优化LoRA。差异源于语言-视觉转换鸿沟：VideoTPO假设文本计划可指导VGM，但实验显示其在精确视觉执行任务上性能下降0.032，而本文直接优化视觉轨迹，在Anomaly、Color等任务上增益显著，证明视觉执行优于文本描述。

## 总结

本文核心矛盾是VGM视觉保真度与逻辑规则遵循的冲突，切入点在于利用VLM感知能力生成可微分奖励，突破VGM内在生成上限。通过VLM-as-Teacher范式与测试时在线优化，在VBVR-Bench和RULER-Bench上分别取得0.781和68.2的得分，较基线提升0.105和21.8点。边界在于84%的失败案例源于VLM感知错误，且方法依赖VLM Teacher的判别精度。当VLM Teacher在复杂时空约束下的感知误差率降至10%以下时，该范式能否进一步缩小与人类推理水平的差距，论文未给出回答。
