> 机器人操作视频生成面临的核心矛盾是视觉逼真度与接触动力学物理合理性的脱节，现有方法或依赖稀疏的后训练偏好优化，或仅约束局部几何，缺乏统一机制同时保障局部轨迹连续性与全局交互因果性。PhysisForcing 的切入点在于将物理监督从全帧均匀分布转向交互关键区域，并通过像素级与语义级双层级损失在训练阶段直接注入约束。该方法通过点跟踪监督 DiT 特征轨迹，并利用冻结视频编码器对齐区域间关系矩阵，在不增加推理开销的前提下提升物理一致性。其价值在于证明了训练时层级对齐对下游策略学习的增益，但其在非刚体流体交互及长时程累积误差上的有效性尚未验证。

## 研究背景

机器人操作场景中的物理违规通常表现为局部动态错误（如夹爪轨迹不连续、物体穿透）与全局关系错误（如被推物体静止、被抓物体漂移）。这些错误源于视频生成模型在去噪过程中缺乏对接触力学的显式建模，导致预测帧无法作为机器人动作的有效后果。解决此问题需区分像素级运动约束与语义级交互约束，前者关注单点轨迹的连续性，后者关注物体间时空关系的演化。

通用视频模型虽具备高保真度，但缺乏接触动力学数据曝光；机器人专用世界模型虽引入操作数据，但通常采用重建目标，将物理关键区域与背景像素同等对待。近期物理感知方法引入深度或 3D 结构以捕捉局部几何，或采用 DPO 等偏好优化抑制不合理生成，但前者无法建模语义交互，后者反馈稀疏且定位弱。PhysisForcing 针对这一空白，提出在训练阶段通过区域聚焦的层级对齐，同时约束局部运动与全局关系，从而在骨干网络内部形成稳定的物理结构。

## 核心方法

### 方法参照系

本文问题可置于“基于扩散模型的视频生成微调”框架下，但关键差异在于监督信号的层级与空间分布。标准流程仅使用流匹配损失优化视觉重建，而本文引入基于物理信息区域的层级对齐损失，将物理约束从后训练阶段前移至骨干网络训练阶段，且监督信号仅作用于交互关键区域而非全帧。

### 物理信息区域提取

设计动机在于物理证据高度局部化，全帧均匀监督会稀释交互信号。该方法利用点跟踪器获取密集轨迹，结合首帧深度图计算前景权重，生成时空物理掩码 $M_{phy}$。该掩码通过运动幅度与前景相关性的乘积筛选轨迹，确保监督仅施加于夹爪、物体及接触区域，为后续层级对齐提供空间引导。

$$ q_i = \frac{a_i \cdot r_i}{\epsilon + \sum_{j=1}^{N} a_j \cdot r_j} $$

其中 $a_i$ 为轨迹运动幅度，$r_i$ 为深度感知前景权重，$q_i$ 为物理信息分数。该公式通过归一化运动与前景的联合贡献，自动识别交互关键区域，避免背景抖动干扰。

### 层级物理对齐

设计动机在于局部轨迹连续性与全局交互因果性需分别约束。像素级对齐利用 DiT 中间层特征预测点轨迹，通过掩码均方误差损失 $L_{phy}^{pix}$ 监督轨迹连续性；语义级对齐将 DiT 特征投影至冻结视频编码器空间，对齐物理区域 token 的成对相似度矩阵，通过 $L_{phy}^{sem}$ 约束区域间关系。两者共同优化，使模型在像素层面保持运动平滑，在语义层面维持交互逻辑。

$$ L_{phy}^{sem} = \left\| \frac{\hat{R} \odot M}{\sum M} - \frac{R \odot M}{\sum M} \right\|_F^2 $$

其中 $\hat{R}$ 与 $R$ 分别为 DiT 侧与编码器侧的 token 相似度矩阵，$M$ 为物理区域掩码，$\odot$ 为逐元素乘积。该公式通过掩码加权对齐区域间关系结构，将冻结编码器的物理先验注入生成模型，确保被抓物体与夹爪保持耦合等全局一致性。

## 实验评估

实验在 R-Bench、PAI-Bench 及 EZS-Bench 上评估，基线涵盖通用模型（Wan、Sora）、商业模型（Veo、Kling）及机器人专用模型（Cosmos、Vidar）。PhysisForcing 在 R-Bench 上取得最佳整体分数 63.8，超越最强商业模型 Wan2.6（60.7）；在 PAI-Bench 机器人域得分 85.2，优于 Abot-PhysWorld（84.9）。在 WorldArena 闭环规划中，成功率从 16.0% 提升至 24.0%，超越最强基线 WoW（20.5%）。

| 模型 | R-Bench Avg. | PAI-Bench Robot | WorldArena Success |
| :--- | :--- | :--- | :--- |
| Wan2.6 | 60.7 | - | - |
| Abot-PhysWorld | 52.9 | 84.9 | - |
| PF-Cosmos | 63.8 | 85.2 | 24.0 |
| PF-Wan | 62.0 | 81.7 | - |

消融实验显示，像素级损失与语义级损失具有互补性：单独使用像素级损失将 R-Bench 平均分从 44.8 提升至 47.2，语义级损失提升至 46.2，联合使用达到 47.5。区域聚焦机制进一步将平均分从 46.0 提升至 47.5，表明背景区域确实稀释了物理信号。对齐层选择上，中间层（Layer 15）表现最佳（85.2），浅层（Layer 10）与深层（Layer 25）分别得 83.9 与 83.2，验证了中间层特征兼具运动与语义结构。

评估边界方面，R-Bench 与 PAI-Bench 侧重机器人操作场景，缺乏通用物理基准（如 VideoPhy）的横向验证，难以判断高分是否源于对特定机器人任务的过拟合。代码已开源，但训练细节如 LoRA 秩值及具体超参数在正文中未完全披露，可复现性依赖附录补充。

## 关联研究分析

从问题动机看，PhysisForcing 与 VJEPA-2 均利用视频理解编码器作为物理先验，但 VJEPA-2 将其作为推理时奖励信号，而本文将其转化为训练时特征对齐损失。这一差异源于任务特性：机器人操作需要严格的接触动力学约束，推理时修正难以处理局部轨迹不连续等细粒度错误，而训练时对齐能直接优化骨干网络表示。然而，训练时对齐是否牺牲了模型对未见物理场景的泛化能力，论文未给出回答。

从方法设计看，PhysisForcing 与 PhysGen 形成显式与隐式物理建模的对比。PhysGen 依赖刚体动力学仿真生成轨迹，提供强物理保证但受限于 3D 重建精度；本文采用点跟踪与特征对齐，无需显式仿真，计算开销更低，但缺乏对物理定律的严格遵循。在接触丰富场景中，隐式对齐的有效性可能依赖于数据分布的覆盖度，若训练数据缺乏特定接触模式，模型可能无法泛化到新的交互类型。

## 总结

PhysisForcing 旨在解决机器人操作视频生成中局部动态与全局交互的物理不一致性，其切入点在于将物理监督从全帧均匀分布转向交互关键区域，并通过层级对齐在训练阶段注入约束。该方法通过像素级轨迹损失与语义级关系损失联合优化，在 R-Bench 上取得 63.8 的最佳分数，并将 WorldArena 闭环成功率从 16.0% 提升至 24.0%。其边界在于实验仅覆盖刚体操作场景，缺乏流体等非刚体交互的验证，且训练时对齐对长时程累积误差的缓解效果未明确。当支持集扩展至包含复杂流体交互的数据时，区域聚焦机制是否仍能保持物理一致性，论文未给出回答。
