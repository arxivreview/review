# HuggingFace最新推荐论文 ｜One Token per Multimodal Evidence: Latent Memory for Resource-Constrained QA ｜单令牌多模态记忆

研究机构：新加坡国立大学

论文原文见 [arXiv](https://arxiv.org/abs/2606.10572)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.10572)

> 现有检索增强生成（RAG）范式将原始文本或图像证据直接输入大语言模型（LLM）或视觉语言模型（VLM），导致存储膨胀与生成延迟激增，难以满足边缘计算场景的严苛约束。本文切入点在于将多模态证据压缩为单一高维潜在令牌，在统一潜在空间中同时完成检索与生成。通过重建、对比与蒸馏三合一训练目标，该方法在保持问答性能的同时，将生成器令牌消耗降低3至10倍。其价值在于提供了资源受限场景下的可行记忆范式，但单令牌压缩在细粒度视觉特征保留上的边界尚存疑。

## 研究背景

当外部记忆库规模扩大至长上下文或多轮对话场景时，传统RAG系统面临存储与计算的双重瓶颈。原始图像证据需占用兆级存储空间，并在生成阶段扩展为数百个视觉令牌，导致推理延迟不可接受。这一困境催生了证据压缩需求，但现有文本压缩方法（如LLMLingua）仅针对文本设计，无法处理多模态数据，且高维令牌体积往往大于原始文本，无法实现真正的存储节省。

主流解决方案分为两条路线：一是基于原始证据的检索，如BM25或稠密检索，虽能保留完整信息但令牌开销巨大；二是文本证据压缩，如ICAE或CLaRa，将文档压缩为少量连续令牌，但局限于纯文本场景，且未解决多模态统一表示问题。本文的切入点在于构建一个统一的多模态潜在表示空间，使文本与图像证据均被压缩为单一潜在令牌，该令牌既作为检索索引，又直接作为生成器的输入条件，从而在存储、检索与生成三个环节同时实现效率突破。

## 核心方法

### 方法参照系

本文问题属于多模态对齐与融合范畴，但与传统流程存在关键差异：标准流程保留原始特征或局部特征进行拼接或注意力融合，而本文将证据压缩为单令牌，通过潜在空间检索后投影至冻结生成器，实现了表示、检索与生成的接口统一。

### 统一潜在空间构建

传统RAG中，检索与生成使用不同表示空间，导致检索精度与生成质量脱节。本文创新在于使用小型压缩LLM/VLM将每个证据项 $x_i$ 编码为单一潜在令牌 $z_i$，并通过MLP投影至检索空间 $\hat{z}_i$。查询 $q$ 也被压缩至同一空间，通过内积相似度检索Top-k令牌。该设计使检索与生成共享同一表示基础，避免了跨空间对齐的误差累积。

$$
\hat{z}_i = \text{MLP}_r(z_i), \quad \hat{q} \in \mathbb{R}^{d_r}
$$

此公式表明，潜在令牌经投影后进入统一检索空间，查询与证据在同一维度下计算相似度，确保检索行为与生成行为的一致性。

### 三合一训练目标

单令牌压缩易导致信息坍缩，仅保留判别性特征而丧失生成所需细节。本文通过重建、对比与蒸馏损失联合优化，确保令牌同时具备信息完整性、检索准确性与生成兼容性。重建损失 $L_{\text{Recon}}$ 通过教师强制方式恢复原始文本或CLIP图像嵌入，防止信息丢失；对比损失 $L_{\text{Contrast}}$ 使用InfoNCE拉近查询与正例证据、推远负例，塑造检索空间；蒸馏损失 $L_{\text{Distill}}$ 最小化冻结生成器在原始证据与潜在令牌条件下的输出KL散度，确保生成行为一致。

$$
L = \lambda_{\text{Recon}} L_{\text{Recon}} + \lambda_{\text{Contrast}} L_{\text{Contrast}} + \lambda_{\text{Distill}} L_{\text{Distill}}
$$

该公式表明，三个损失项协同作用，使潜在令牌在信息保留、检索精度与生成质量之间取得平衡，解决了单令牌压缩中信息丢失与生成失配的核心矛盾。

## 实验评估

实验在HotpotQA、2WikiMultihopQA、MuSiQue等文本基准及WebQA多模态基准上进行，基线覆盖BM25、稠密检索、LLMLingua、xRAG、CLaRa等主流方法，但未包含医学领域专用基线。在文本设置下，使用Meta-Llama-3-8B-Instruct作为冻结生成器，Latent Memory在k=5时外域平均F1为28.0，令牌数71，显著低于BM25的31.7 F1与219令牌，效率提升约3倍。在多模态WebQA图像子集上，k=5时F1达69.4，令牌数82，优于Nemo-Emb的53.0 F1与1885令牌，效率提升超10倍。

| 方法 | 数据集 | k | F1 | R@k | #Tok |
| :--- | :--- | :--- | :--- | :--- | :--- |
| BM25 Retrieval | 2WikiMultihopQA | 5 | 32.7 | 46.9 | 196 |
| Latent Memory | 2WikiMultihopQA | 5 | 36.7 | 74.2 | 69 |
| Nemo-Emb-1B | WebQA-Image | 5 | 53.0 | 81.4 | 1885 |
| Latent Memory | WebQA-Image | 5 | 69.4 | 91.2 | 82 |

消融实验显示，移除重建损失导致EM/F1下降1.1-1.7点，R@k下降0.1-1.7点，表明重建对信息保留至关重要。移除负例证据重建进一步降低R@k，验证了负例对统一潜在空间锚定的作用。8令牌变体相比1令牌，F1提升2.0-4.6点，但令牌数增加42-106，显示单令牌在效率与性能间存在权衡，但1令牌已具备竞争力。

评估边界方面，论文未报告置信区间，数值比较需谨慎。代码已开源，使用Nvidia H200 141GB GPU训练，超参数细节见附录。评估协议聚焦效率-性能权衡，但未涵盖细粒度视觉特征保留的量化指标，如病理纹理识别准确率。

## 关联研究分析

从方法设计看，本文与CLaRa同属潜在推理路线，但CLaRa聚焦文本连续潜在推理，而本文扩展至多模态统一空间，并引入蒸馏损失确保生成一致性。这一差异源于任务特性：多模态证据的异构性要求统一表示空间，而纯文本场景可依赖单一模态的潜在推理。从问题动机看，本文与LLMLingua均针对长上下文压缩，但LLMLingua通过丢弃令牌实现压缩，导致信息不可逆丢失，而本文通过重建损失保留可恢复信息，解决了LLMLingua在生成任务中信息缺失的问题。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文核心矛盾在于多模态记忆存储膨胀与生成延迟的冲突，现有RAG范式无法在资源受限场景下平衡效率与性能。本文抓住单令牌压缩的切入点，通过统一潜在空间与三合一训练目标，使证据在存储、检索与生成环节同时高效。实验证明，在WebQA图像子集上，Latent Memory以82令牌实现69.4 F1，效率提升超10倍；在文本外域平均上，以71令牌达到28.0 F1，接近BM25性能但令牌少3倍。其边界在于单令牌压缩可能损失细粒度视觉特征，论文未提供病理纹理等细粒度任务的验证。当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
