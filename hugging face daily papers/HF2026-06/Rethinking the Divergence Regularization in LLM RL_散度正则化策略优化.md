# HuggingFace最新推荐论文 ｜Rethinking the Divergence Regularization in LLM RL ｜散度正则化策略优化

研究机构：美国伊利诺伊大学厄巴纳-香槟分校、新加坡国立大学

论文原文见 [arXiv](https://arxiv.org/abs/2606.09821)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.09821)

> 大语言模型（LLM）强化学习（RL）在训练-推理引擎数值失配与多步梯度更新下呈现显著的 Off-policy 特性，传统基于重要性比率的信任区域约束在长尾词汇分布下产生几何失配，导致低概率 Token 被过度约束而高概率 Token 约束不足。现有 PPO 与 SPO 方法依赖固定比率窗口，无法准确反映策略分布的实际偏移，而 DPPO 虽引入散度掩码但缺乏边界外的修正信号。本文提出散度正则化策略优化（Divergence Regularized Policy Optimization, DRPO），通过优势加权的 $L_2$ 二次正则化替代硬掩码，在保持 Binary-TV 信任区域几何的同时实现有界且连续的梯度权重。该设计提升了训练稳定性，但在数学推理基准上未超越当前 SOTA，其泛化边界尚待验证。

## 研究背景

LLM 自回归生成过程可建模为 Token 级马尔可夫决策过程（Markov Decision Process, MDP），其中策略 $\pi(y_t|s_t)$ 在状态 $s_t$ 下采样 Token 并接收标量奖励。现代 RL 训练框架中，推理引擎与训练引擎的数值差异以及批量 Rollout 的多次梯度更新，使得行为策略 $\mu$ 与当前策略 $\pi$ 不一致，构成 Off-policy 优化场景。在此场景下，重要性比率 $r_t = \pi(y_t|s_t)/\mu(y_t|s_t)$ 是控制策略更新幅度的核心变量，但其对分布偏移的代理能力在长尾词汇中严重退化。

主流方法如 PPO 与 GRPO 采用比率裁剪机制近似信任区域，SPO 进一步引入平滑二次正则化以解决梯度突变问题。然而，这些方法共享相同的比率几何：固定比率窗口 $\epsilon$ 对低概率 Token 施加过严约束（微小概率变化导致巨大比率），对高概率 Token 约束不足（显著概率变化仅对应微小比率）。DPPO 通过 Binary-TV 散度掩码替代比率裁剪，将信任区域定义为采样 Token 的绝对概率偏移，但硬掩码在边界处产生梯度截断，缺乏将策略拉回信任区域的修正机制。本文切入点在于：如何在不牺牲比率几何优势的前提下，通过平滑正则化实现散度约束的连续控制，同时解决长尾词汇下的方差爆炸问题。

## 核心方法

### 方法参照系

本文问题属于 Off-policy 策略优化中的信任区域控制，与 PPO/SPO 的比率约束流程一致，关键差异在于约束几何从相对比率偏移转向绝对概率偏移。

### Binary-TV 信任区域重构

DPPO 的 Binary-TV 散度 $D_t^{Bin-TV} = |\pi(y_t|s_t) - \mu(y_t|s_t)|$ 等价于 Token 自适应比率约束 $|r_t - 1| \le \delta/\mu(y_t|s_t)$。该约束宽度与行为概率成反比，低概率 Token 获得更宽松的比率容差，高概率 Token 获得更严格的容差，避免了比率约束的长尾失配。然而，DPPO 通过二元掩码执行此约束，当 $D_t^{Bin-TV} > \delta$ 且更新方向远离行为策略时，梯度被置零，导致边界附近的更新脆弱性。

### 优势加权 $L_2$ 正则化

DRPO 将 Binary-TV 约束重写为 Token 自适应比率边界，并应用 SPO 的平滑正则化构造，得到目标函数：

$$
\mathcal{L}_{DRPO} = \mathbb{E}\left[ \hat{A}_t r_t - \frac{\mu(y_t|s_t)}{2\delta} \left( \hat{A}_t (r_t - 1) \right)^2 \right]
$$

该公式中，第一项为 Token 级代理目标，第二项为优势加权的 $L_2$ 正则化，其曲率由行为概率 $\mu(y_t|s_t)$ 缩放。这一设计动机在于：SPO 的 $\chi^2$ 正则化包含 $1/\mu(a|s_t)$ 因子，在低概率 Token 上产生任意大的方差，而 DRPO 的 $L_2$ 正则化直接惩罚绝对概率偏移，对相同偏移量施加相同代价，消除了长尾方差爆炸。

梯度形式为：

$$
\nabla_\theta \mathcal{L}_{DRPO} = \mathbb{E}\left[ \hat{A}_t w_t \nabla_\theta \log \pi(y_t|s_t) \right]
$$

其中连续权重 $w_t = 1 - \text{sign}(\hat{A}_t(r_t - 1)) \frac{D_t^{Bin-TV}}{\delta}$。当更新远离行为策略时（$\text{sign}(\hat{A}_t(r_t - 1)) > 0$），$w_t = 1 - D_t^{Bin-TV}/\delta$，在边界处衰减至零，边界外变为负值提供修正信号；当更新趋向行为策略时（$\text{sign}(\hat{A}_t(r_t - 1)) < 0$），$w_t = 1 + D_t^{Bin-TV}/\delta$，梯度被放大以加速回归。该权重有界于 $[1 - 1/\delta, 1 + 1/\delta]$，在 $\mu(y_t|s_t) \to 0$ 时保持有界，解决了 SPO 权重无界的问题。

## 实验评估

实验在 Qwen3-4B-Base、Qwen3-30B-A3B-Base 与 Qwen3.5-35B-A3B-Base 上进行，使用约 13K 道数学题的 DAPO 子集，评估 AIME 2024/2025 的 avg@16 准确率。基线覆盖 PPO、GRPO、SPO、DPPO 及无正则化代理目标，但缺失 DAPO、Quantile Advantage Estimation 等当前数学推理 SOTA 方法。

| 方法 | Qwen3-4B AIME24 | Qwen3-30B AIME24 | R1D AIME25 |
| :--- | :--- | :--- | :--- |
| 无正则化 | 0.25 | 0.35 | 0.35 |
| SPO | 0.20 | 0.30 | 0.30 |
| DPPO | 0.22 | 0.32 | 0.32 |
| DRPO | 0.25 | 0.35 | 0.35 |

DRPO 在 Qwen3-4B 上恢复无正则化基线的 0.25 准确率，而 SPO 与 DPPO 分别降至 0.20 与 0.22，表明平滑正则化在低精度场景下更稳定。在 Qwen3-30B 上，DRPO 与无正则化基线持平（0.35），优于 SPO（0.30）与 DPPO（0.32）。R1D 在 AIME25 上，DRPO 达到 0.35，与无正则化基线相同，高于 SPO（0.30）与 DPPO（0.32）。

消融实验显示，移除 $|\hat{A}_t|$ 权重后，DRPO 性能下降，验证了优势加权对信任区域边界独立于奖励尺度的必要性。FP8-E2E 设置下，DRPO 的稳定性优势更为显著，表明低精度加剧的数值失配使散度几何约束比比率几何更鲁棒。

评估边界方面，论文未报告置信区间，数值比较需谨慎；代码已开源，但超参数（如 $\delta=0.15$、正则化阈值 12.5）的敏感性分析缺失；GPU 需求未明确说明，可复现性受限。

## 关联研究分析

从问题动机看，DRPO 与 DPPO 同属散度约束路线，但 DPPO 的硬掩码在边界外缺乏修正信号，导致策略可能停滞在信任区域外，而 DRPO 的负权重提供回归力。这一差异源于任务特性：数学推理任务中，低概率 Token 常对应探索性路径，DPPO 的硬截断可能抑制有效探索，而 DRPO 的平滑衰减允许边界附近的梯度贡献。然而，DRPO 的 $L_2$ 正则化是否在高维状态空间中导致过约束，论文未给出回答。

从方法设计看，DRPO 与 SPO 共享平滑正则化构造，但 SPO 的 $\chi^2$ 几何在长尾词汇下方差爆炸，而 DRPO 的 $L_2$ 几何保持有界。这一差异源于词汇分布特性：LLM 词汇呈长尾分布，$\mu(y_t|s_t) \le 0.01$ 的 Token 占 7.8%，SPO 的 $1/\mu$ 因子在此区域产生巨大方差，而 DRPO 的 $\mu$ 缩放因子消除了这一问题。与 GRPO 相比，DRPO 保留了组相对优势估计，但将比率约束替换为散度约束，这一改动是否牺牲了探索多样性，导致泛化能力下降，论文未提供 OOD 任务上的实证数据。

## 总结

本文要解决的核心矛盾是 Off-policy LLM RL 中比率约束在长尾词汇下的几何失配与硬掩码的边界脆弱性。本文抓住的切入点是：Binary-TV 散度等价于 Token 自适应比率约束，可通过平滑正则化实现连续控制，同时 $L_2$ 几何避免长尾方差爆炸。本文提出 DRPO，通过优势加权 $L_2$ 正则化替代硬掩码，在 Qwen3-4B 上恢复无正则化基线的 0.25 AIME24 准确率，在 R1D 上达到 0.35 AIME25 准确率。本文的边界在于：实验仅覆盖数学推理任务，未验证在开放域生成或长程 Agentic 场景中的有效性；FP8 精度下的稳定性优势是否源于散度几何本身，还是低精度数值失配的特定效应，论文未分离变量。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
