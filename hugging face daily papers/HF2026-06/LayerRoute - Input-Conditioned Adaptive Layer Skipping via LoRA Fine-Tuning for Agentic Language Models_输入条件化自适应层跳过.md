# HuggingFace最新推荐论文 ｜LayerRoute: Input-Conditioned Adaptive Layer Skipping via LoRA Fine-Tuning for Agentic Language Models ｜输入条件化自适应层跳过

论文原文见 [arXiv](https://arxiv.org/abs/2606.01838)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.01838)

> 现代智能体系统在处理工具调用与规划推理时，面临计算资源分配不均的困境，现有推理系统对两类步骤施加同等计算成本，导致简单任务算力浪费。本文指出，通过参数高效适配器学习输入条件化的层跳过策略，可解决这一效率瓶颈。LayerRoute 结合 LoRA 微调与硬门控路由，在冻结骨干上实现按需计算。该方法在 0.5B 模型上验证了步骤类型异质性的可学习性，但其通用性与大规模扩展性存疑。

## 研究背景

Transformer 架构中，残差流中的深层特征通常承载复杂语义信息，而浅层特征多负责基础语法与嵌入映射。这种层级功能分化意味着，对于不同复杂度的输入，模型所需的计算深度存在显著差异。然而，标准推理流程强制所有输入通过全部层，忽略了这种计算需求的不均匀性。参数高效微调（PEFT）技术如 LoRA 允许在冻结骨干上注入少量可训练参数，为在不破坏预训练知识的前提下引入动态计算机制提供了可能。

现有动态计算分配方法主要分为两类：一类是从零训练的深度混合架构，如 Mixture of Depths (MoD)，通过 Token 级路由控制计算深度，但训练成本高且难以适配预训练模型；另一类是基于置信度的早退机制，如 DeeBERT，依赖中间层预测概率，但缺乏对输入类型的显式建模。这些方法未能充分利用智能体场景中步骤类型的结构性差异。LayerRoute 的切入点在于，将层跳过策略与 LoRA 联合训练，利用语言建模目标隐式学习步骤类型与层重要性的映射关系，实现预训练模型的后置适配。

## 核心方法

### 方法参照系

本文问题属于动态计算分配范畴，与 MoD 的 Token 级路由不同，LayerRoute 采用序列级路由，即每个 Transformer 块对整个输入序列执行统一的跳过决策。这一差异源于智能体步骤类型是序列级属性，而非 Token 级属性，使得序列级路由在计算开销与决策粒度间取得平衡。

### 硬门控路由与直通估计

传统层跳过方法使用软门控，导致训练与推理不一致。LayerRoute 引入硬门控机制，通过直通估计器 (STE) 解决不可微问题。路由器 $r_i$ 计算均值池化隐藏状态 $\bar{h}_i$ 的线性变换 $s_i = \mathbf{w}_i^T \bar{h}_i + b_i$，硬门 $g_i = \mathbf{1}[\sigma(s_i) > 0.5]$ 决定块 $i$ 是否执行。前向传播使用硬门，反向传播通过 $\sigma(s_i)$ 传递梯度，消除训练/推理不匹配。这一设计解决了软门控在推理时无法确定执行路径的问题，确保跳过决策的确定性。

### LoRA 联合训练与门控正则化

单独训练路由器易导致门控坍缩至全开状态，因为 LoRA 可适应权重以维持质量，使门控梯度趋零。LayerRoute 将 LoRA 适配器与路由器联合优化，目标函数为 $\mathcal{L} = \mathcal{L}_{LM} + \lambda \sum_{i=0}^{23} \sigma(s_i)$，其中 $\lambda=1.0$。门控正则化惩罚高软门值，迫使路由器识别真正可跳过的块。LoRA 适配器（秩 8）应用于 Q/K/V/O 投影，使路由策略与权重适配共演化。这一设计解决了路由器缺乏判别信号的问题，通过语言建模目标隐式学习步骤类型与层重要性的关联。

## 实验评估

实验在 Qwen2.5-0.5B-Instruct 上进行，使用 Hermes、Glaive、GSM8K 等构建的智能体数据集，训练 3,000 步（6.4 分钟，A100 40GB）。基线包括全模型及自身消融（BCE/NoReg/UniformInit），缺失 MoD、GateSkip 等外部强基线对比。

| 方法 | Tool Skip % | Plan Skip % | Skip Diff. ↑ | FLOPs Red. (tool) ↑ | PPL∆ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Full model | 0.0% | 0.0% | 0.0 | — | — |
| LayerRoute-NoReg | 0.0% | 0.0% | 0.0 | 0.0% | -0.02 |
| LayerRoute-UniformInit | 5.1% | 10.9% | -5.4 | 5.5% | -1.28 |
| **LayerRoute (ours)** | **15.25%** | **2.34%** | **12.91** | **15.2%** | **-1.29** |

LayerRoute 实现 12.91% 的跳过差异，工具调用节省 15.2% FLOPs，规划步骤仅节省 2.34%。PPL∆ 为负值，表明门控模型优于全层基线，LoRA 适配补偿了跳过损失。

消融实验显示，无正则化 (NoReg) 导致跳过率坍缩至 0%，验证了门控正则化的必要性。均匀初始化 (UniformInit) 反转跳过差异（规划跳过更多），证明偏差初始化对打破对称性的关键作用。中间层 (8-16) 收敛至 ≈0.274，形成单一批量跳过块，缺乏内部细粒度区分。

评估边界受限：仅验证 0.5B 模型，未测试 3B/7B 规模；数据集不平衡（Turing 仅 50 样本）；缺乏与 MoD 的直接对比。代码未公开，超参数（如 λ=1.0）未提供敏感性分析。

## 关联研究分析

从问题动机看，LayerRoute 与 MoD 均解决计算冗余问题，但 MoD 采用 Token 级路由，适用于通用语言建模中 Token 难度差异；LayerRoute 采用序列级路由，特化于智能体步骤类型异质性。这一差异源于任务特性：智能体步骤类型是序列级属性，而通用 LM 中 Token 难度是局部属性。LayerRoute 的序列级路由在智能体场景下更合理，但在长文本中是否导致局部依赖丢失，论文未给出回答。

从方法设计看，LayerRoute 与 SkipBERT 共享输入依赖路由思想，但 SkipBERT 从零训练，LayerRoute 基于 LoRA 后训练。这一差异使 LayerRoute 可适配预训练模型，但限制了其学习复杂路由策略的能力。LoRA 联合训练使路由策略与权重适配共演化，但仅应用于注意力投影，未覆盖 FFN 层，可能限制了路由策略的表达力。

## 总结

LayerRoute 解决智能体系统中工具调用与规划步骤计算资源分配不均的矛盾，通过 LoRA 联合训练与硬门控路由，在冻结骨干上实现输入条件化层跳过。该方法在 0.5B 模型上验证了 12.91% 的跳过差异，工具调用节省 15.2% FLOPs，且门控模型 PPL 优于全层基线。其边界在于仅验证小模型规模，中间层缺乏细粒度区分，且规划步骤跳过率极低。当模型规模扩展至 7B 时，中间层的重要性分布是否发生变化，导致当前路由策略失效，论文未给出回答。
