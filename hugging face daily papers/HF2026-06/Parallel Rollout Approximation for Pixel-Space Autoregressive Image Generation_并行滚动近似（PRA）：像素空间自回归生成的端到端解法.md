# HuggingFace最新推荐论文 ｜Parallel Rollout Approximation for Pixel-Space Autoregressive Image Generation ｜并行滚动近似（PRA）：像素空间自回归生成的端到端解法

研究机构：北京大学

作者：Jiayi Xu、Di He、Guolin Ke

论文原文见 [arXiv](https://arxiv.org/abs/2606.27978)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.27978)

> 像素空间自回归生成旨在直接对原始像素块进行序列预测，以规避离散化带来的量化误差与外部分词器依赖。然而，高维像素块的单步预测误差与教师强制训练导致的推理偏差相互耦合，使得现有连续Token自回归模型在高分辨率下性能急剧退化。本文提出并行滚动近似（PRA），通过引入低维中间状态降低输出难度，并并行构造推理似像素输入以消除训练-推理偏差。该框架在像素空间自回归家族内确立了新的性能上限，但其整体保真度仍落后于顶级离散模型，且未验证其在开放域文本生成中的语义对齐能力。

## 研究背景

自回归视觉生成的核心困境在于表征空间的选取。离散Token范式依赖向量量化（VQ）将图像映射为码本索引，虽解决了序列建模的可行性，但量化误差导致高频细节丢失，且分词器质量成为生成上限的硬约束。连续Token范式试图在潜在空间或像素空间直接建模，以保留完整信息，但面临高维连续向量难以在单步内精确预测的挑战。

主流连续Token自回归方法通常依赖预训练分词器将图像映射至低维潜在空间，再训练自回归模型。这种两阶段架构虽然降低了单步预测难度，但引入了表征学习的额外阶段，且潜在空间的设计需专门优化以适配自回归生成。像素空间自回归则直接以原始像素块为Token，理论上避免了分词器瓶颈，但实际表现远逊于扩散模型。诊断实验表明，当Token维度从48增至768时，自回归模型的FID从4.06恶化至9.94，远超同规模像素扩散模型JiT的4.56。这一退化源于两个耦合机制：输出侧的高维预测导致单步误差大，输入侧的教师强制训练使模型在推理时面对自身生成的不完美前缀，误差随序列长度累积放大。

本文切入点在于同时解决这两个耦合瓶颈。不同于仅优化预测参数化（如x-prediction）或独立噪声注入的局部修复，PRA通过架构级重构，将高维像素预测转化为低维中间状态预测，并并行构造与推理路径一致的像素输入，从而在保持像素进像素出接口的同时，显著缩小与扩散模型的差距。

## 核心方法

### 连续Token自回归基准框架

像素空间自回归将图像划分为$16 \times 16 \times 3 = 768$维的连续Token序列，按光栅扫描顺序排列。因果Transformer编码前缀Token生成隐状态$h_{i-1}$，附加的Token级扩散头基于Rectified Flow目标预测下一Token。该框架的关键差异在于：Token为原始像素块而非离散索引或预训练潜在特征，且生成过程需将预测的像素块反馈至后续步骤的因果上下文中，形成自回归闭环。

### 低维中间状态目标

直接预测768维像素块导致单步误差过大。PRA引入端到端学习的低维中间状态$z_i \in \mathbb{R}^{d_z}$（$d_z < d$），通过因果像素解码器$D_\phi$映射回像素空间。中间状态由当前Token与因果前缀表示联合投影生成：

$$z_i = g_\psi(x_i, h_{i-1}), \quad z_i \in \mathbb{R}^{d_z}$$

该公式的物理含义是：中间状态不仅编码当前像素信息，还融合了因果上下文，使自回归模型在低维空间预测时能利用全局结构信息。为防止$g_\psi$仅依赖当前Token，采用Token掩码策略，以概率$p_{mask}$将$x_i$替换为可学习掩码嵌入，强制中间状态整合因果前缀信息。此设计解决了高维预测的单步误差瓶颈，将预测难度从768维降至16维，同时通过解码器保持像素级输出接口。

### 并行推理似像素输入构造

低维中间状态仅解决输出侧问题，输入侧的训练-推理偏差仍需处理。PRA并行构造推理似像素输入：对每个目标中间状态$z_i$，采样噪声$z_i^0 \sim \mathcal{N}(0, I)$和时间步$t \sim U(t_{min}, 1)$，形成扰动状态$\tilde{z}_i^t = (1-t)z_i^0 + t z_i$，经同一像素解码器映射为像素Token $\bar{x}_i = D_\phi(\tilde{z}_i^t, \tilde{z}_{<i}^t)$。

$$\bar{x}_i = D_\phi((1-t)z_i^0 + t z_i, \tilde{z}_{<i}^t)$$

该公式的关键在于：$\bar{x}_i$通过推理时使用的同一解码路径生成，模拟了推理时自回归模型接收自身生成像素块的条件，而非独立噪声扰动的干净前缀。由于各位置的$\bar{x}_i$独立构造，训练过程保持并行性，避免了顺序滚动的计算开销。此设计解决了独立噪声注入无法匹配模型自生成结构化错误的问题，使训练输入更接近推理时的实际条件分布。

## 实验评估

实验在ImageNet-1K 256x256类别条件生成任务上进行，对比两阶段离散自回归（VAR, LlamaGen）、像素扩散（JiT, SiD）及像素自回归（FARMER, JetFormer）基线。PRA-S（135M参数）FID 2.58，超越1.9B参数的FARMER-1.9B（FID 3.60）；PRA-L（511M参数）FID 1.94，确立像素空间自回归新SOTA。

| 方法 | 参数量 | FID↓ | IS↑ |
| :--- | :--- | :--- | :--- |
| FARMER-1.9B/8 | 1.9B | 3.60 | 269.2 |
| PRA-S | 135M | 2.58 | 273.9 |
| PRA-B | 250M | 2.21 | 276.9 |
| PRA-L | 511M | 1.94 | 287.3 |
| JiT-L/16 | 459M | 2.36 | 298.5 |
| VAR-d20 | 600M+40M | 2.57 | 302.6 |

消融实验验证了两个核心组件的互补性。输出侧：中间状态维度$d_z=16$时FID 2.88，$d_z=8$时FID 3.36，$d_z=32$时FID 3.50，表明16维为最优平衡点；前缀感知目标（FID 2.88）优于局部目标（FID 3.08）。输入侧：解码像素输入（FID 2.88）显著优于干净像素（FID 42.36）和独立噪声注入（FID 32.60），证明推理似构造的关键作用。噪声水平$t_{min}=0.7$时FID 2.62，优于$t_{min}=1.0$（FID 3.35），表明适度噪声有助于鲁棒性。

评估边界方面，论文仅报告ImageNet类别条件生成FID/IS，未提供置信区间或计算效率数据。代码已开源，但超参数细节（如$p_{mask}$、$t_{min}$具体值）未在正文中完整列出，复现需依赖代码仓库。与领域共识相比，PRA-L FID 1.94仍落后于顶级离散模型BAR（FID 1.15，据领域综述），表明像素空间自回归在保真度上尚未超越离散范式。

## 关联研究分析

从问题动机看，PRA与VAR等离散自回归模型的根本差异在于表征空间的选择。VAR依赖预训练VQ-VAE分词器，其生成质量受限于码本容量与量化误差，而PRA通过端到端像素建模规避了这一瓶颈。然而，PRA的像素空间自回归在单步预测难度上远高于离散Token，需通过低维中间状态补偿，这引入了额外的解码器训练开销。VAR的Next-Scale范式通过层级生成降低单步难度，而PRA采用光栅扫描Next-Patch，依赖并行输入构造缓解误差累积，两者在生成顺序与难度控制上采取了不同策略。

从方法设计看，PRA与连续Token自回归方法MAR、SphereAR共享Rectified Flow头与因果Transformer骨干，但PRA的并行推理似输入构造是其独特贡献。MAR等方法的输入侧处理依赖独立噪声注入或潜在空间设计，无法模拟模型自生成的结构化错误，导致训练-推理偏差残留。PRA通过解码路径一致性解决了这一问题，但其并行近似在长序列下是否仍能准确模拟误差累积，论文未提供消融证据。此外，PRA的线性探测准确率（68.80%）高于扩散模型JiT-L（42.76%）和离散自回归SphereAR-L（52.19%），暗示像素空间端到端训练可能产生更优的视觉表征，但这一优势在开放域文本生成中是否成立，缺乏实验验证。

## 总结

像素空间自回归生成的核心矛盾在于高维像素预测的单步误差与自回归循环中的误差累积相互耦合，导致模型在高分辨率下性能急剧退化。PRA抓住这一耦合机制，通过低维中间状态降低输出难度，并行推理似输入消除训练-推理偏差，在保持像素进像素出接口的同时实现了架构级优化。实验证明PRA-L FID 1.94，超越1.9B参数基线FARMER-1.9B（FID 3.60），确立像素空间自回归新SOTA。然而，PRA的并行近似仅在256个Token长度上验证，未探索更长序列下的误差累积行为；其线性探测优势是否源于像素空间本身的信息密度，还是PRA训练策略的特异性，论文未给出区分性实验。当序列长度扩展至1024 Token时，并行构造的推理似输入是否仍能准确模拟顺序滚动的误差分布，这一问题的答案将决定PRA在高分辨率生成中的可扩展性。
