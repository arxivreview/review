研究机构：美国德克萨斯大学奥斯汀分校

> 知识密集型问答智能体在检索与推理循环中常陷入两种失效：过度依赖参数化知识导致答案错误，或在证据已充分时冗余检索浪费算力。现有方法仅暴露单一信号（置信度或接地性），无法区分“自信但错误”与“自信且正确”的状态，导致动作选择盲目。本文提出校准验证器遥测（CALVERT），将校准自置信度与接地验证分数作为每轮状态变量注入智能体，使其在无硬编码阈值下自然决策。该机制在训练-free与强化学习设置下均提升效率-精度权衡，但其增益高度依赖模型规模与任务复杂度，对单跳简单任务几乎无效。

## 研究背景

当智能体面对多跳问答任务时，它必须在“提交当前答案”与“继续检索”之间做出决策。这一决策依赖两个独立维度：模型对自身答案的置信度（Confidence），以及答案是否被检索证据支持（Grounding）。若仅依赖置信度，模型可能因参数化记忆产生“自信但错误”的判断；若仅依赖接地性，模型无法区分“证据不足需检索”与“证据矛盾需修正”的情形。这种测量能力的缺失，导致智能体在长程交互中错误累积或资源浪费。

知识密集型问答的主流路线基于 ReAct 范式，通过交错推理与行动解决静态知识局限。然而，现有方法如 Self-RAG 依赖内部反思 token，Search-R1 依赖结果强化学习，均仅条件于单一信号或隐式状态。这些方法在复杂多跳任务中面临瓶颈：单一信号无法提供足够的状态区分度，导致智能体在证据不足时过早提交，或在证据充分时过度检索。本文切入点在于引入外部校准验证器，将置信度与接地性作为显式遥测信号注入智能体状态，解决动作选择中的测量缺失问题。

## 核心方法

### 方法参照系

本文基于 ReAct 风格智能体循环，动作空间扩展为 {commit, retrieve, refine, decompose}。与标准 ReAct 依赖内部隐式状态不同，本文在每轮动作前注入外部校准信号，使智能体决策显式条件于两个正交的不确定性维度。

### 校准置信度与接地遥测

智能体在每轮动作前接收四个标量：归一化言语置信度（NVC）、自一致性率（SC）、接地均值（$g_{mean}$）与接地最小值（$g_{min}$）。NVC 通过提示生成器“Is this answer correct? Yes/No”计算，SC 为生成器自一致性率。接地分数由 Bespoke-MiniCheck-7B 验证器对候选答案束中的每个声明进行证据蕴含评分，$g_{min}$ 突出最弱链接。设计动机在于解决单一信号无法区分“自信但错误”与“自信且正确”的失效：置信度单独无法分离未验证的正确答案，接地性单独无法区分需检索与需修正的情形。

$$
\text{Telemetry} = \{ \text{NVC}, \text{SC}, g_{mean}, g_{min} \}
$$

该公式表示每轮注入智能体状态的四个校准标量，其中 $g_{min}$ 为候选答案束中接地分数最低的声明，用于识别证据支持的最薄弱环节。

### 无阈值动作路由

智能体将遥测信号与简短自然语言框架插入提示，但不定义具体置信度或接地阈值。智能体自然推理利用这些分数，决定提交、检索、修正或分解。设计动机在于避免硬编码阈值导致的泛化性差：不同任务与模型的最优阈值不同，显式阈值限制了智能体适应不同难度分布的能力。

$$
a_t = \pi_\theta(s_t, \text{Telemetry}_t)
$$

该公式表示智能体策略 $\pi_\theta$ 基于当前状态 $s_t$ 与遥测信号 $\text{Telemetry}_t$ 选择动作 $a_t$，其中策略通过提示工程（训练-free）或 GRPO 强化学习（训练-based）优化，无需预设阈值。

## 实验评估

实验在 HotpotQA-distractor、2Wiki、MuSiQue 与 WiTQA 四个基准上进行，每基准采样 300 题。基线覆盖无遥测基线、5 个现有框架（TARG、SeaKR、Self-Ask、Verify-and-Edit、SUGAR），但缺失 LATS、StateAct 等最新 SOTA 对比。

| 基准 | 模型 | F1 (-tel) | F1 (+tel) | ΔF1 | ΔTurns |
| :--- | :--- | :--- | :--- | :--- | :--- |
| HotpotQA | Qwen3-32B | 71.1 | 72.5 | +1.4 | -1.26 |
| 2Wiki | Qwen3-32B | 66.0 | 69.7 | +3.7 | -1.87 |
| MuSiQue | Qwen3-32B | 42.6 | 42.4 | -0.2 | -0.64 |
| WiTQA | Qwen3-32B | 82.2 | 86.9 | +4.7 | +0.25 |

Qwen3-32B 在 2Wiki 上 F1 提升 3.7 且轮次减少 1.87，表明遥测信号在多跳任务中有效平衡精度与效率；WiTQA 单跳任务 F1 提升 4.7 但轮次增加 0.25，反映智能体在简单任务中过度检索。

| 框架 | F1 (-tel) | F1 (+tel) | ΔF1 | ΔAct. |
| :--- | :--- | :--- | :--- | :--- |
| TARG | 45.1 | 60.5 | +15.4 | +36 |
| SeaKR | 51.0 | 58.7 | +7.8 | +31 |
| SUGAR | 61.3 | 60.3 | -1.0 | -34 |
| Self-Ask | 60.3 | 61.7 | +1.4 | -0.5 |

TARG 框架 F1 提升 15.4 但动作增加 36，表明遥测信号替换原生门控后，智能体更频繁检索；SUGAR 框架 F1 下降 1.0 但动作减少 34，反映信号在特定框架中导致过度提交。

评估边界：指标仅覆盖 F1 与 EM，未报告置信区间（除附录外）；评估协议未控制骨干模型能力差异，Qwen3-8B 在 prompt-only 设置下性能低于基线，表明信号有效性依赖模型规模；代码开源但超参数仅针对 HotpotQA 训练池，跨基准泛化性未验证。

## 关联研究分析

从问题动机看，Self-RAG 通过内部反思 token 解决检索决策，但反思 token 由策略自身生成，无法提供外部校准的置信度与接地性。本文引入外部验证器，将测量能力从模型内部解耦，解决了 Self-RAG 在“自信但错误”情形下的失效。差异根源在于任务特性：Self-RAG 假设模型内部反思足以区分状态，而本文发现多跳任务中内部反思信号不足，需外部校准。

从方法设计看，Search-R1 通过结果强化学习优化检索策略，但奖励信号稀疏且难以归因到具体动作。本文沿用 GRPO 框架，但将遥测信号作为状态变量，使策略学习条件于细粒度不确定性维度。差异根源在于信用分配：Search-R1 依赖最终答案质量，无法区分中间步骤的贡献；本文通过每轮遥测信号，使策略学习更直接地关联动作与状态质量。

## 总结

本文解决的核心矛盾是智能体在缺乏测量能力时无法区分“自信但错误”与“自信且正确”的状态。现有方法仅暴露单一信号，无法提供足够的状态区分度；本文通过引入校准验证器遥测，将置信度与接地性作为显式状态变量，使智能体在无阈值下自然决策。实验证明，在 2Wiki 多跳任务中，Qwen3-32B 的 F1 提升 3.7 且轮次减少 1.87，验证了遥测信号在效率-精度权衡中的有效性。本文的边界在于：信号有效性高度依赖模型规模，Qwen3-8B 在 prompt-only 设置下性能低于基线；且对单跳简单任务增益有限，WiTQA 上轮次增加 0.25 反映过度检索。当模型规模进一步缩小至 4B 以下时，遥测信号是否仍能引导有效动作选择，论文未给出回答。
