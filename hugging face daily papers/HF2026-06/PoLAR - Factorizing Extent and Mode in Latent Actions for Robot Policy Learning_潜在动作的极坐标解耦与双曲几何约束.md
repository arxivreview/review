> 视动策略学习面临的核心困境在于，从视觉观测对中提取的潜在动作表征往往将“过渡幅度”与“过渡模式”纠缠在单一向量中，导致不同时间跨度的相似动作在潜在空间中缺乏结构关联，限制了策略的泛化能力。现有方法多采用欧氏空间下的扁平编码，无法显式区分动作的规模与类型，使得策略在长时程任务或多模态动作分布下难以保持连贯性。PoLAR 通过引入双曲几何与径向监督，将潜在动作解耦为半径（幅度）与方向（模式），利用时间偏移作为弱监督信号约束半径增长，从而在保持动作模式一致性的同时扩展幅度表征空间。这一设计在仿真与真实机器人任务中显著提升了下游策略性能，但其对固定视角与目标导向演示的依赖，限制了其在复杂动态场景中的普适性。

## 研究背景

当机器人从视频演示中学习动作时，逆动力学模型（Inverse Dynamics Model, IDM）将两帧观测间的视觉变化压缩为潜在动作向量。然而，传统 IDM 输出的单一连续向量或离散 token 序列，迫使模型用同一编码同时表征“动作做了多少”（幅度）与“动作怎么做”（模式）。这种纠缠导致短时长与长时长的相似过渡在潜在空间中缺乏显式关联，策略难以利用“模式相同、幅度不同”的结构信息进行高效泛化。

视动策略学习的主流路线已从确定性回归转向生成式架构，扩散策略（Diffusion Policy）通过迭代去噪建模多模态动作分布，成为当前标准范式。然而，生成式架构的性能上限受制于上游视觉表征的质量。视觉基础模型（Vision Foundation Model, VFM）如 DINOv2 提供了强语义不变性，但其特征空间缺乏对动作过渡几何结构的显式建模。现有潜在动作预训练方法（如 UniVLA, LAPA）虽利用 VFM 特征提取过渡信息，但默认潜在空间为欧氏几何，未对幅度与模式进行结构化分离。PoLAR 的切入点在于：时间偏移是无需动作标签的弱监督信号，且双曲几何的体积随半径指数增长，天然适合容纳大跨度动作中更复杂的模式多样性。

## 核心方法

### 潜在动作学习参照系

标准潜在动作学习流程包含视觉编码、IDM 预测潜在动作、前向动力学模型（Forward Dynamics Model, FDM）重建未来特征三个环节。本文的关键差异在于：不再将 IDM 输出视为无结构的欧氏向量，而是将其嵌入双曲空间，并引入基于时间偏移的径向监督损失，强制半径编码幅度、方向编码模式。

### 双曲径向几何与监督损失

在欧氏空间中，半径增长带来的角度容量有限，难以区分大跨度动作中的细微模式差异。PoLAR 将 IDM 输出的切空间向量 $z$ 提升至高斯曲率 $-c$ 的庞加莱球（Poincaré Ball）中，利用双曲几何中体积随半径指数增长的性质，为大半径区域提供更大的角度区分能力。设计动机在于解决欧氏空间中“方向随幅度增加而坍缩”的问题，即大跨度动作的方向信息被幅度变化淹没。

径向监督由两个损失项构成：$L_{ord}$ 确保同一起始观测下，时间间隔更远的过渡在局部锚点（自过渡 $z_{t,0}$）周围具有更大的距离；$L_{rad}$ 确保以原点为中心的半径随时间偏移单调递增。

$$
L_{rad} = \text{softplus}(\alpha j + r(z_{t,0}) - r(z_{t,j})) + \text{softplus}(\alpha(k-j) + r(z_{t,j}) - r(z_{t,k}))
$$

该公式通过 softplus 函数施加平滑的铰链惩罚，$\alpha$ 控制时间偏移的边际间隔，确保半径增长与时间跨度成正比，从而将幅度信息从方向中剥离。

### 因子化径向-方向码本

对于离散潜在动作，PoLAR 替换传统的扁平向量量化（VQ）码本，采用因子化码本：包含有序半径集合 $\{\rho_a\}$ 与归一化方向集合 $\{u_b\}$。量化器从聚合范数中选择共享径向索引 $a_{t,\ell}$，从每个槽位的归一化方向中选择方向索引 $b_{t,\ell,m}$。

$$
\bar{z}_{t,\ell,m} = \rho_{a_{t,\ell}} \cdot u_{b_{t,\ell,m}}
$$

这一设计使得离散 token 显式携带幅度与模式信息，避免了扁平码本中 token 错误映射到无关动作的风险。在 VLA 实验中，该因子化结构允许策略在预测时独立调整幅度与模式，提升了多时间尺度动作生成的稳定性。

## 实验评估

| 方法 | SimplerEnv 平均成功率 (%) | RoboMimic/MimicGen 相对表现 |
| :--- | :--- | :--- |
| PoLAR (Hyp) | 70.2 | 优于 Flat, Euc, ResNet18 |
| PoLAR (Euc) | 56.2 | 低于 PoLAR (Hyp) |
| Flat (5x16) | 43.8 | 基线 |
| UniVLA | 40.6 | 数据匹配基线 |
| $\pi_{0.5}$ | 42.7 | 外部 VLA 参考 |

PoLAR 在 SimplerEnv-WidowX 上取得 70.2% 的平均成功率，显著优于数据匹配的 UniVLA（40.6%）与使用更广泛预训练混合的 $\pi_{0.5}$（42.7%）。在 RoboMimic 与 MimicGen 任务中，PoLAR 在解码器单独微调与联合微调两种设置下均优于扁平基线与欧氏变体，且优于联合微调的 ResNet18 编码器，验证了径向结构预训练相对于通用视觉编码器预训练的优势。

| 消融变体 | 解码器微调成功率 (%) | 联合微调成功率 (%) |
| :--- | :--- | :--- |
| Base (无径向损失) | 68.0 | 64.0 |
| +$L_{ord}$ | 28.0 | 52.0 |
| +$L_{rad}$ | 42.0 | 52.0 |
| +Both ($\lambda_{rad}=0.3, \alpha=0.05$) | 92.0 | 74.0 |

消融实验显示，单独引入 $L_{ord}$ 或 $L_{rad}$ 均导致性能下降，表明两个损失项在约束幅度-模式解耦上具有互补性。最终设置 $\lambda_{rad}=0.3, \alpha=0.05$ 在 Can 任务上取得 92.0% 的解码器微调成功率，远高于基线的 68.0%。值得注意的是，$\alpha=0.10$ 时性能降至 82.0%，表明过大的时间边际会过度约束半径增长，损害方向信息的表达自由度。

评估边界方面，实验仅使用固定第三人称顶视相机，未测试腕部相机或多视角输入，限制了其在复杂视角变化场景中的泛化验证。时间偏移作为幅度代理的假设在循环行为或暂停动作中可能失效，论文未对此类非目标导向演示进行鲁棒性测试。代码未公开，但超参数（$\lambda_{ord}=1, \lambda_{rad}=0.3, \alpha=0.05, c=1$）已明确报告，具备可复现性基础。

## 关联研究分析

从问题动机看，PoLAR 与 RAVEN（ICLR 2026）均旨在解决空间泛化不足，但路线截然不同。RAVEN 通过显式 SE(3) 等变网络处理 RGB 输入，依赖相机标定精度与空间数据先验；PoLAR 则通过双曲几何的内在性质隐式建模幅度-模式结构，无需显式空间数据。这一差异暗示：等变性是“硬约束”，适用于已知几何变换的任务；而径向解耦是“软结构”，适用于几何变换未知但幅度-模式关系稳定的任务。PoLAR 在 SimplerEnv 上优于使用更广泛预训练的 $\pi_{0.5}$，表明结构化的潜在空间设计可能比单纯扩大预训练数据规模更有效，但这一结论是否适用于需要精确深度估计的精细操作任务，论文未给出回答。

从方法设计看，PoLAR 与 VILA（Jeong et al., 2026）同属潜在动作学习框架，但 VILA 聚焦视角鲁棒性，通过动作感知对比学习强制视角不变性；PoLAR 聚焦幅度-模式解耦，通过径向监督约束几何结构。VILA 的优势在于无需多视角数据即可提升视角鲁棒性，代价是对比学习超参数敏感；PoLAR 的优势在于显式分离幅度与模式，提升了多时间尺度动作生成的稳定性，代价是对时间偏移作为幅度代理的假设依赖。两者结合可能形成“视角不变 + 幅度-模式解耦”的复合表征，但论文未探索这一方向。

## 总结

PoLAR 针对潜在动作学习中幅度与模式纠缠导致的多模态动作分布建模缺陷，利用时间偏移作为弱监督信号，在双曲空间中解耦半径与方向，从而在保持动作模式一致性的同时扩展幅度表征空间。实验证明，该结构在 SimplerEnv 上取得 70.2% 的平均成功率，显著优于数据匹配的 UniVLA 与外部 VLA 参考，且在 RoboMimic 任务中通过消融验证了径向损失的互补性。然而，实验仅覆盖固定顶视相机与目标导向演示，未测试循环行为或多视角输入，限制了其在复杂动态场景中的普适性。当演示数据包含大量暂停或循环动作时，时间偏移作为幅度代理的假设是否失效，以及双曲几何的径向容量能否补偿视角变化带来的模式混淆，论文未给出回答。
