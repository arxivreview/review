# HuggingFace最新推荐论文 ｜Confidence-Adaptive SwiGLU for Mixture-of-Experts ｜置信度自适应 SwiGLU

作者：Shaohua Li、Xiuchao Sui、Xiaobing Sun 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.00761)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.00761)

> 混合专家（Mixture-of-Experts, MoE）模型中，路由置信度仅被用于专家选择，而专家内部门控激活函数的锐度在训练全程保持固定，导致高置信度与低置信度 Token 在专家内经历相同的特征抑制或放大逻辑。现有路由优化方案聚焦于调整 Token 分配策略，忽略了路由信号与专家内部计算单元之间的隐式耦合。本文提出 κ-SwiGLU，将路由 Logit 作为 Token 级信号，动态调制专家内 SiLU 门控的锐度系数，使门控选择性随路由确定性自适应变化。该机制在 8 至 28 层 MoE 模型中带来 0.6 至 1.0 个百分点的 CORE 基准增益，但增益幅度受限于模型深度与专家池规模的交互，且缺乏与路由算法改进类方法的横向对比，其独立贡献边界尚不清晰。

## 研究背景

MoE 架构通过稀疏激活解耦参数容量与计算成本，其核心组件 SwiGLU 门控单元利用 SiLU 函数对中间激活进行选择性调制。SiLU 函数的数学形式为 $x \cdot \sigma(x)$，其中 $\sigma(x)$ 为 Sigmoid 函数。该函数在零附近具有平滑过渡特性，但在远离零的饱和区梯度趋近于零，这种固定的非线性形状决定了专家对输入特征的响应模式。当 MoE 路由器将 Token 分配给特定专家时，路由 Logit 反映了 Token 与专家路由向量的对齐程度，即路由置信度。高置信度 Token 在表示空间中更接近专家路由方向，而低置信度 Token 则处于边缘区域。

MoE 训练面临专家坍缩与路由不稳定问题，主流方案通过辅助负载均衡损失（如 Switch Transformer 的 $z$-loss）或无损失平衡策略调节 Token 分配分布。这些方法将路由视为离散选择器，优化目标是专家利用率的均匀性，但忽略了路由信号在专家内部计算中的潜在作用。近期研究开始探索路由的几何属性，如路由流形对齐，但仍未触及专家内部激活函数与路由信号的耦合机制。本文切入点在于发现路由置信度不仅决定 Token 去向，还通过隐式对齐效应影响专家门控的输入分布，进而提出显式参数化该耦合关系，将路由信号转化为门控锐度的控制变量。

## 核心方法

### 方法参照系

标准 MoE 架构中，路由器计算 Token 与专家路由向量的内积作为 Logit，经 Top-k 选择后，被选中的专家执行 SwiGLU 前馈网络。SwiGLU 的门控部分使用固定锐度的 SiLU 函数，其形式为 $\text{SiLU}(z) = z \cdot \sigma(z)$。该流程的关键差异在于：路由 Logit 仅作为选择信号，未参与专家内部计算；门控锐度 $\kappa=1$ 为全局常数，不随 Token 特性或路由确定性变化。

### 隐式路由-门控耦合机制

在标准 MoE 训练中，专家门控投影向量 $w_{e,j}$ 与对应专家路由向量 $r_e$ 在训练初期迅速形成对齐或反对齐关系。将 $w_{e,j}$ 分解为平行于 $r_e$ 的分量 $w_{e,j}^{[\parallel]}$ 和正交分量 $w_{e,j}^{[\perp]}$，门控输入可表示为：

$$ z_{e,j} = (w_{e,j}^{[\top]} \hat{r}_e) a + w_{e,j}^{[\top]} x^{[\perp]} $$

其中 $a = \hat{r}_e^{\top} x$ 为 Token 在路由方向上的投影，即路由置信度信号。第一项 $(w_{e,j}^{[\top]} \hat{r}_e) a$ 构成置信度诱导门控偏置，使不同路由置信度的 Token 在 SiLU 门控的过渡区产生系统性偏移。该隐式耦合导致高置信度 Token 的门控输入被推入更活跃或更抑制的区域，但这种效应是被动且不可控的，无法根据专家功能需求调整门控选择性。

### 置信度自适应锐度参数化

κ-SwiGLU 将门控锐度 $\kappa$ 参数化为路由 Logit 的函数，显式控制门控的平滑度与选择性。定义锐度调整 SiLU 函数为：

$$ \text{SiLU}_{\kappa}(z) = z \cdot \sigma(\kappa z) $$

其中 $\kappa > 1$ 使门控更尖锐、选择性更强，$\kappa < 1$ 使门控更平滑、激活范围更广。$\kappa$ 由路由 Logit $s_e(x)$ 通过有界指数映射生成：

$$ \kappa_{e,j}(x) = \exp\left( \tanh(\alpha_{e,j} s_e(x) + b_{e,j}) \cdot \ln U \right) $$

其中 $\alpha_{e,j}$ 和 $b_{e,j}$ 为可学习参数，$U > 1$ 为超参数，确保 $\kappa_{e,j}(x) \in (1/U, U)$。当 $s_e(x) = 0$ 时，$\kappa_{e,j}(x) = 1$，退化为标准 SwiGLU。该设计使每个专家门控单元独立学习置信度-锐度映射，高置信度 Token 可触发更尖锐的特征选择，低置信度 Token 则获得更平滑的激活，从而在专家内部实现路由感知的计算自适应。

## 实验评估

实验在 FineWeb-Edu 数据集上训练 8 至 28 层 MoE 模型，使用 4 块 H200 GPU，评估协议为 22 项 CORE 基准的居中准确率。基线仅包含标准 SwiGLU，未对比 ReMoE、DirMoE 等路由优化方法，无法隔离激活函数改进与路由算法改进的贡献。

| 模型 | SwiGLU | κ-SwiGLU | Δ |
|---|---|---|---|
| MoE-8L | 13.5±1.0 | 14.5±0.4 | +1.0 |
| MoE-10L | 17.5±1.2 | 18.3±0.9 | +0.9 |
| MoE-12L | 20.1±1.0 | 20.8±0.2 | +0.7 |
| MoE-14L | 23.3±0.3 | 23.9±0.6 | +0.6 |
| Sandwich-16L | 14.3±1.0 | 14.1±0.4 | -0.2 |
| Sandwich-20L | 18.1±0.3 | 18.5±0.7 | +0.5 |
| Sandwich-24L | 19.7±0.7 | 20.3±1.3 | +0.6 |
| Sandwich-28L | 21.3±1.1 | 21.9±1.0 | +0.6 |

κ-SwiGLU 在 8 个配置中的 7 个取得正增益，标准 MoE 架构下增益随深度增加而递减（1.0 至 0.6 个百分点），Sandwich 架构下 16 层出现负迁移（-0.2 个百分点），20 层以上恢复正增益。消融实验显示，移除路由 Logit 依赖的尺度项 $\alpha_{e,j} s_e(x)$ 导致性能显著下降，而移除偏移项 $b_{e,j}$ 影响较小，表明置信度依赖的尺度调制是主要贡献来源。

| 方法 | MoE-8L | MoE-10L | ΔAvg. |
|---|---|---|---|
| SwiGLU | 13.5±1.0 | 17.5±1.2 | -0.9 |
| κ-SwiGLU−α | 13.4±0.6 | 17.8±1.0 | -0.8 |
| κ-SwiGLU−b | 13.9±0.4 | 18.5±0.3 | -0.2 |
| κ-SwiGLU | 14.5±0.4 | 18.3±0.9 | 0.0 |

计算开销方面，κ-SwiGLU 在 MoE-14L 模型上增加 0.02% 活跃参数，训练吞吐量下降 7.0%，推理吞吐量下降 3.5%。评估边界方面，论文未报告困惑度（PPL）或下游任务准确率，仅使用 CORE 基准；未提供置信区间或统计显著性检验；代码已开源，但超参数 $U$ 的取值范围未明确说明，Sandwich 架构中仅 2 个 MoE 层的设计可能限制路由置信度信号的稳定性。

## 关联研究分析

从问题动机看，κ-SwiGLU 与 ReMoE 均试图简化路由与激活的交互，但 ReMoE 修改路由器函数本身，用 ReLU 替代 Softmax+Top-k 组合，而 κ-SwiGLU 保留标准 Top-k 路由，仅调制专家内部门控。这一差异源于任务特性：ReMoE 关注路由过程的稀疏控制精度，κ-SwiGLU 关注路由信号在专家计算中的利用效率。当路由分布已稳定时，后者可能提供更细粒度的性能增益，但论文未验证在路由不稳定场景下 κ-SwiGLU 是否比 ReMoE 更鲁棒。

从方法设计看，κ-SwiGLU 与 DirMoE 均追求可微的精细控制，但 DirMoE 在路由器端引入 Dirichlet 分布建模专家贡献度，κ-SwiGLU 在专家端引入锐度调制。DirMoE 的稀疏旋钮 $\lambda$ 控制激活专家数量，κ-SwiGLU 的 $\kappa$ 控制激活特征选择性，两者操作对象不同。κ-SwiGLU 的 L2 正则化 $\lambda_{reg}(\|\alpha_{e,j}\|^2 + \|b_{e,j}\|^2)$ 防止锐度偏离标准 SiLU，而 DirMoE 依赖分布约束实现稳定性。这种设计选择暗示 κ-SwiGLU 更关注训练稳定性而非路由分布的几何结构，但论文未对比两种方法在专家专业化程度上的差异。

## 总结

MoE 模型中路由置信度与专家门控激活的耦合机制长期被忽视，现有路由优化方案聚焦于 Token 分配策略，未触及专家内部计算单元对路由信号的响应。κ-SwiGLU 通过发现路由-门控隐式对齐效应，将路由 Logit 显式参数化为门控锐度系数，使专家门控选择性随路由确定性自适应变化。该机制在 8 至 28 层 MoE 模型中带来 0.6 至 1.0 个百分点的 CORE 基准增益，计算开销增加 0.02% 参数与 3.5% 推理延迟。论文实验暴露的边界在于：增益幅度受模型深度与专家池规模交互影响，Sandwich 架构 16 层出现负迁移，且缺乏与路由算法改进类方法的横向对比。当专家池规模从 64 缩减至 16 时，路由置信度信号的统计稳定性是否足以驱动有效的锐度调制，论文未给出回答。
