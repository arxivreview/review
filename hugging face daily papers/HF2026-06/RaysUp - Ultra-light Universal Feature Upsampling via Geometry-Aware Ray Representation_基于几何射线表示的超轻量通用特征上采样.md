# HuggingFace最新推荐论文 ｜RaysUp: Ultra-light Universal Feature Upsampling via Geometry-Aware Ray Representation ｜基于几何射线表示的超轻量通用特征上采样

论文原文见 [arXiv](https://arxiv.org/abs/2606.22749)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.22749)

> 视觉基础模型（VFM）输出特征分辨率低，限制了密集预测任务中像素级推理的能力。现有上采样方法要么依赖特定骨干网络重训练，要么架构臃肿导致推理效率低下。RaysUp 通过引入基于 Plücker 坐标的射线位置编码，将特征重建提升至几何感知域，以极小参数量实现任意分辨率的通用上采样。该方法在精度与效率间取得了显著平衡，但其对相机内参的依赖及局部注意力的几何一致性边界仍需进一步审视。

## 研究背景

视觉基础模型（VFM）如 DINO 和 CLIP 通过大规模预训练获得了强大的语义表征能力，但其 Patch 化或池化操作导致输出特征图空间分辨率极低（如 16×16）。这种低分辨率特征在语义分割、深度估计等密集预测任务中无法提供足够的像素级细节，传统双线性插值虽计算高效，却丢失了关键的语义与几何信息。

特征上采样旨在恢复中间表征的空间分辨率，现有方法主要分为离散重建与连续映射两类。离散重建方法如 CARAFE 和 JBU 依赖卷积解码或插值，通常需针对特定骨干网络重新训练，且固定 2D 邻域难以建模复杂几何结构；连续映射方法如 FeatUp 和 AnyUp 虽支持任意分辨率，但 AnyUp 等架构参数冗余，推理速度慢，难以在精度与效率间取得平衡。RaysUp 的切入点在于借鉴神经辐射场（NeRF）的射线表示思想，通过几何感知的射线位置编码（RayPE）替代传统的 2D 位置编码，从而在保持超轻量架构的同时，实现跨 VFM 的通用特征上采样。

## 核心方法

### 方法参照系

RaysUp 属于连续映射路线的特征上采样框架，其核心目标是将低分辨率 VFM 特征 $F_{lr}$ 重建为任意目标分辨率 $F_{hr}$。与 AnyUp 等依赖重型注意力机制的方法不同，RaysUp 基于联合双边上采样（JBU）范式，通过解耦引导编码器与几何感知注意力机制，在保持局部性的同时实现分辨率无关的特征聚合。

### 空间解耦引导编码器

传统 JBU 使用 RGB 差异作为范围核，缺乏对复杂语义关系的建模能力。RaysUp 引入空间解耦引导编码器，将标准 3×3 卷积分解为四个正交方向分支，每个分支仅学习 $D_g/4$ 通道，以增强各向异性建模能力。该设计将参数量从 $27D_g$ 降至 $8.25D_g$，减少约 69.4% 的开销。

$$ F_g = \text{SiLU}(\text{GN}(\text{Conv}_{D_g/4}(I))) + \text{SiLU}(\text{GN}(\text{Conv}_{2\times2,d=2}(I))) $$

此公式表明，通过并行处理不同方向的卷积特征并引入残差连接，编码器能在极低参数量下捕获多尺度空间语义信息，为后续注意力机制提供更具结构先验的引导特征。

### 射线位置编码与几何感知注意力

传统 2D 位置编码假设欧氏邻近性反映 3D 几何一致性，但在透视投影下，相邻像素可能对应空间上遥远的 3D 点。RaysUp 引入 RayPE，利用 6D Plücker 射线坐标 $(\mathbf{o}, \mathbf{d})$ 将特征映射至高维旋转空间，注入隐式 3D 几何先验。

$$ \mathbf{Q}_{ray} = \text{Rot}(\mathbf{Q}_g, \boldsymbol{\Theta}), \quad \boldsymbol{\Theta} = \omega_f \cdot \mathbf{r}_d $$

其中 $\boldsymbol{\Theta}$ 为多频谐波相位，$\omega_f$ 为对数间隔频率。随后，几何感知邻域注意力在低分辨率特征空间中定义局部邻域 $N_{i,j}$，通过膨胀因子桥接分辨率差异，将计算复杂度从全局注意力的 $O(H_{any}W_{any}H_{lr}W_{lr})$ 降至 $O(H_{any}W_{any}k^2)$。这一机制确保了特征聚合沿 3D 射线流形对齐，有效缓解了边界模糊与结构漂移。

## 实验评估

RaysUp 在 ImageNet 上训练，使用 DINOv2-S 作为默认骨干，对比基线包括 Bilinear、FeatUp、LoftUp、JAFAR 和 AnyUp。实验覆盖 COCO-Stuff、ADE20K、Pascal-VOC、Cityscapes 语义分割及 NYUv2 深度/法线估计任务。

| 方法 | COCO-Stuff mIoU | ADE20K mIoU | NYUv2 Depth RMSE |
| :--- | :--- | :--- | :--- |
| Bilinear | 59.58 | 40.47 | 0.3348 |
| FeatUp | 60.18 | 42.33 | 0.3393 |
| LoftUp | 61.40 | 42.16 | 0.3353 |
| JAFAR | 61.79 | 42.15 | 0.3255 |
| AnyUp | 62.14 | 42.34 | 0.3244 |
| **RaysUp** | **62.32** | **42.34** | **0.3195** |

RaysUp 在 COCO-Stuff 和 NYUv2 深度估计上取得最优性能，ADE20K 与 AnyUp 持平，验证了几何感知机制在密集几何预测任务中的优势。消融实验显示，移除 RayPE 导致平均性能下降至 81.05%，而空间解耦编码器相比多分支设计在保持 82.17% 平均性能的同时将参数量降至 0.14M。

评估边界方面，论文未报告置信区间，且主要依赖 DINOv2-S 单一骨干验证通用性，缺乏对 CLIP 等异构特征分布的深入对比。代码已开源，训练仅需单卡 A100 一小时，可复现性高。

## 关联研究分析

从方法设计看，RaysUp 与 AnyUp 同属编码器无关的连续映射路线，但 AnyUp 依赖重型注意力架构实现通用性，而 RaysUp 通过 RayPE 注入 3D 几何先验，以 16% 的参数量实现 7 倍推理加速。这一差异源于 RaysUp 对几何一致性的显式建模，而非 AnyUp 的通用特征交互。然而，RayPE 依赖相机内参，在无相机信息的通用图像中，其几何先验的有效性是否依然成立，论文未给出回答。

从问题动机看，RaysUp 解决了任意尺度上采样中的计算效率瓶颈，而 FeatUp 等早期方法侧重于任务无关性但需重训练。RaysUp 的超轻量设计使其更适合实时应用，但其局部注意力机制可能牺牲全局几何一致性，导致远距离结构漂移。相比之下，2D Gaussian Splatting 等新兴方法在推理速度上更具优势，但 RaysUp 在语义保真度上的表现是否优于这些方法，缺乏直接对比。

## 总结

RaysUp 旨在解决 VFM 特征上采样中精度与效率的矛盾，通过引入基于 Plücker 坐标的射线位置编码，将特征重建提升至几何感知域。该方法以 0.14M 参数量实现了 COCO-Stuff 62.32% mIoU 和 NYUv2 0.3195 RMSE 的最优性能，推理速度较 AnyUp 提升 7 倍。其边界在于对相机内参的依赖以及局部注意力可能引入的全局结构漂移。当输入图像缺乏精确相机参数时，RayPE 的几何先验是否仍能维持边界保真度，论文未给出回答。
