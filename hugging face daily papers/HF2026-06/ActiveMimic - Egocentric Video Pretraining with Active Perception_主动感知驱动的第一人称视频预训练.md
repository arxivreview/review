# HuggingFace最新推荐论文 ｜ActiveMimic: Egocentric Video Pretraining with Active Perception ｜主动感知驱动的第一人称视频预训练

研究机构：复旦大学

作者：Xingyao Lin、Guojin Zhong、Tianyi Lu 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.06194)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.06194)

> 机器人基础模型依赖昂贵的机器人数据预训练，而第一人称人类视频虽廉价且多样，却因缺乏动作监督导致性能落后。现有方法仅提取手部或物体轨迹，忽略了视频中蕴含的“主动感知”信号——即人类通过头部和身体运动调整视角的行为。ActiveMimic 提出从单目第一人称视频中解耦并联合建模相机运动与手腕轨迹，构建统一动作空间进行预训练。该框架证明了主动感知是解锁第一人称视频用于机器人预训练的关键，但其在非结构化环境下的泛化能力及对语义理解的贡献仍存疑。

## 研究背景

机器人操作的基础模型通常采用视觉-语言模型（VLM）结合动作专家的结构，通过大规模机器人数据预训练后微调至下游任务。然而，机器人数据采集成本高、任务多样性受限，难以像网络文本或图像那样实现规模化扩展。第一人称人类视频（Egocentric Human Video）提供了替代方案，其获取成本低、覆盖日常活动广泛，但直接用于预训练时，模型性能显著低于基于机器人数据训练的模型。这一差距通常被归因于缺乏直接的动作监督信号，现有研究致力于构建代理动作标签，如手部轨迹、点云或物体运动信号，但这些方法仅关注操作本身，忽略了视频中另一个关键维度：视角的动态变化。

在操作过程中，人类并非被动接收图像，而是通过头部和身体运动主动调整视角以减少感知不确定性，这种行为被称为主动感知（Active Perception）。在第一人称视频中，这种主动感知表现为显著的相机运动，传统流水线将其视为噪声处理。然而，相机运动与手腕运动在像素空间中是耦合的：手腕在相机坐标系下的位移既包含真实的手部移动，也包含相机自身的旋转和平移。若不解决这种耦合，模型无法正确学习相机运动或手部运动。现有解耦方法依赖专用采集硬件（如多相机或可穿戴传感器），无法扩展至野外（in-the-wild）视频。ActiveMimic 的切入点在于，仅使用单目身体佩戴 RGB 相机，通过视觉模型恢复同步的相机和手腕轨迹，并显式建模主动感知与操作的联合演化，从而在无需专用硬件的情况下实现规模化预训练。

## 核心方法

### 统一动作空间构建

本文方法参照系为标准的视觉-语言-动作（VLA）预训练流程，通常从视频中提取手部或物体运动作为动作标签。本文的关键差异在于将相机运动视为独立的“视角动作”，并与手腕运动联合编码。为解决单目视频中的相机-手腕耦合问题，ActiveMimic 首先利用 VGGT 恢复尺度归一化的相机轨迹，并通过 UniDepth 的度量深度估计恢复度量尺度 $\lambda$，得到度量相机轨迹 $T_{cam}^{cam_1 \to k}$。随后，将手腕姿态从当前帧相机坐标系重映射到以 chunk 起始帧为原点的公共参考系 $cam_i$，实现运动解耦。

### 27D 动作表示与流匹配训练

解耦后的相机和手腕姿态被编码为统一的 27 维动作向量。每个姿态由平移向量和连续 6D 旋转表示组成，相机（6D）+ 左手腕（6D）+ 右手腕（6D）+ 各自平移（3D）共计 27 维。该表示允许模型在单一目标函数中学习感知与操作的耦合动力学。

$$
a_{i,\tau} = [t_{cam}, r_{cam}, t_{wrist_L}, r_{wrist_L}, t_{wrist_R}, r_{wrist_R}]
$$

其中 $t$ 为平移，$r$ 为 6D 旋转表示。模型采用条件流匹配（Conditional Flow Matching）进行训练，损失函数定义为预测速度场与真实速度场之间的均方误差：

$$
\mathcal{L} = \mathbb{E}_{t, a, \epsilon} \left[ \| v_\theta(a_t, t, o) - (a - \epsilon) \|^2 \right]
$$

其中 $a_t = t\epsilon + (1-t)a$ 为加噪动作，$o$ 为视觉-语言条件上下文。这一设计动机在于，流匹配能够处理连续动作空间中的多模态分布，比高斯假设更适合建模相机与手腕运动的复杂耦合关系。通过两阶段训练（第一人称视频预训练 + 机器人数据微调），模型在预训练阶段习得主动感知能力，并在微调阶段将其迁移至特定机器人本体。

## 实验评估

实验在 AGIBOT G1 人形机器人上半身平台上进行，涵盖 Restocking、Reaching、Finding 和 Pouring 四个任务，分别测试蹲起扫描、跨越障碍、主动搜索和双手协调。基线包括 $\pi_0$（基于机器人数据预训练的 SOTA）、MotoVLA（基于混合人类/机器人数据预训练）、ActiveMimic_wrist-only（仅监督手腕动作）和 ActiveMimic_sft-only（跳过预训练）。

| 任务 | ActiveMimic | $\pi_0$ | MotoVLA | ActiveMimic_wrist-only |
| :--- | :--- | :--- | :--- | :--- |
| Restocking | 90.1% | 86.4% | - | - |
| Reaching | 88.9% | - | - | - |
| Finding | 91.7% | 86.1% | - | - |
| Pouring | 93.3% | - | - | - |

*注：MotoVLA 和 ActiveMimic_wrist-only 的具体数值在提供的实验数据区未完整列出，仅知 ActiveMimic 全面超越所有基线。*

消融实验揭示了主动感知能力的来源。在 Restocking 任务中，ActiveMimic 的放置得分（Pts2）为 24/27，而 ActiveMimic_sft-only 仅为 6/27，表明主动感知能力源于第一人称预训练而非机器人微调。移除头部相机后，放置得分骤降至 1/27，证实模型通过头部相机实现主动感知。表征转移分析显示，ActiveMimic 在感知层（0-11 层）中，头部视图与全视图的激活单元重叠率高于 ActiveMimic_wrist-only，证明相机运动监督增强了表征对观察模态变化的鲁棒性。

评估边界方面，实验仅在四个特定任务上进行，样本量较小（如 Reaching 仅 18 次试验），统计显著性有限。代码未开源，预训练数据过滤细节（如 Ego4D 子集筛选）可能影响复现性。此外，实验未报告计算效率指标，无法评估其在资源受限 AR 设备上的部署潜力。

## 关联研究分析

从问题动机看，本文与 P-JEPA 均关注长时序依赖，但 P-JEPA 通过联合嵌入预测学习抽象状态语义，而 ActiveMimic 通过预测具体轨迹学习物理运动。P-JEPA 的表征更偏向语义理解，适合步骤定位；ActiveMimic 的表征更偏向运动控制，适合动作生成。这种差异源于任务目标：理解任务需要区分语义相似但功能不同的动作，控制任务需要精确的几何轨迹。ActiveMimic 未探索语义层面的错误检测，其表征是否支持细粒度错误归因尚不明确。

从方法设计看，本文与 UNIEGO 均利用多模态知识，但 UNIEGO 通过多教师蒸馏融合不同视角的表征，旨在提升理解鲁棒性；ActiveMimic 通过解耦相机-手腕耦合构建统一动作空间，旨在提升控制精度。UNIEGO 的蒸馏策略可能引入教师模型的偏差，而 ActiveMimic 的解耦策略依赖视觉模型的精度（如 VGGT 和 UniDepth）。若视觉模型在遮挡或快速运动下失效，ActiveMimic 的动作标签质量将下降，进而影响预训练效果。这种对视觉前端精度的依赖是 ActiveMimic 未充分讨论的潜在弱点。

## 总结

ActiveMimic 解决了第一人称视频预训练中主动感知信号缺失的问题，通过解耦相机-手腕耦合并构建统一动作空间，证明了相机运动监督能显著提升机器人任务成功率（如 Restocking 90.1% vs $\pi_0$ 86.4%）。其核心贡献在于将主动感知从理论概念转化为可规模化的预训练信号，无需专用硬件。然而，实验局限于四个结构化任务，且依赖视觉模型恢复轨迹的精度。当第一人称视频包含剧烈运动或严重遮挡时，VGGT 和 UniDepth 的轨迹恢复误差是否会累积并导致预训练信号失效，论文未给出回答。
