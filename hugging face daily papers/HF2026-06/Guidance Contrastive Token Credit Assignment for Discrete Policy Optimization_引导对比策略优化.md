# HuggingFace最新推荐论文 ｜Guidance Contrastive Token Credit Assignment for Discrete Policy Optimization ｜引导对比策略优化

研究机构：美国加州大学洛杉矶分校

论文原文见 [arXiv](https://arxiv.org/abs/2605.29198)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.29198)

> 组相对策略优化（GRPO）在离散生成任务中面临样本级奖励均匀广播导致的信号稀释问题，无法区分序列内关键Token与填充Token的贡献差异。现有Token信用分配方法多依赖置信度或梯度启发式，缺乏与生成语义直接关联的物理依据。本文切入点在于将分类器自由引导（CFG）从推理时技术转化为训练时信号源，通过正负提示下的KL散度量化Token重要性。该方法在文生图与多模态推理中均优于基线，但其对负提示构造的依赖及归一化策略的普适性仍存疑。

## 研究背景

自回归生成模型将图像或文本表示为离散Token序列，其训练依赖强化学习（RL）进行后训练对齐。GRPO通过组内相对奖励归一化替代价值网络，降低了策略梯度估计的方差，但其核心假设是序列内所有Token对最终奖励的贡献均等。这一假设在链式思维（CoT）推理与文生图任务中失效：数学推导中的关键计算步骤与标点符号、图像中与提示词强相关的实体区域与背景噪声，其语义重要性存在数量级差异。

主流路线试图通过Token级权重修正这一偏差。UCAS基于Token置信度缩放优势，OAR利用模型梯度信息，KATE采用Fisher精确检验的p值。这些方法虽实现了非均匀分配，但权重来源多为统计量或优化过程的副产品，缺乏对“Token为何重要”的语义解释。在视觉生成领域，CFG作为标准推理技术，通过放大正负提示预测差异来提升对齐质量，但其作用仅限于推理阶段，未被纳入训练目标。本文抓住这一被忽略的关联：CFG在推理时放大的正是那些对提示词敏感的Token，这一敏感度差异可直接作为训练时的信用分配依据。

## 核心方法

### GRPO基准与信号稀释

GRPO的标准流程是采样一组响应，计算组内归一化优势 $A_i$，并将其均匀广播至序列中每个Token。该流程的关键差异在于，它忽略了自回归生成中Token间的语义异质性，导致优化信号在无关Token上被稀释，而在关键Token上强度不足。

### 对比引导信号构造

本文在GRPO的优势计算环节引入对比引导信号。对于序列中每个Token $y_{i,t}$，计算其在正提示 $x$ 与负提示 $x_{-}$ 下的条件概率分布，并取KL散度作为重要性权重 $\eta_{i,t}$：

$$ \eta_{i,t} = D_{KL}(\pi_\theta(y_{i,t}|x, y_{i,<t}) \| \pi_\theta(y_{i,t}|x_{-}, y_{i,<t})) $$

该公式的物理含义是：若某Token在正负提示下预测分布差异巨大，说明该Token对提示词高度敏感，即语义关键；反之则为背景或填充。设计动机在于解决启发式权重（如置信度）与语义重要性脱节的问题，利用CFG已验证的“差异即重要性”原则，将推理时的引导机制内化为训练时的信用分配依据。

### 直方图均衡化归一化

原始KL散度 $\eta$ 范围无界且跨任务尺度差异巨大，直接归一化易导致权重集中于少数极端Token。本文采用直方图均衡化（Histogram Equalization）进行归一化：

$$ \eta_{normalized} = F(\eta) = P(x; x < \eta) $$

其中 $F$ 为序列内KL散度的累积分布函数。该设计解决了Min-Max归一化对离群值敏感、Softmax归一化需调温的问题，确保每个样本内权重分布平滑且一致，无需针对特定任务调整超参数。最终，Token级优势 $A_{i,t}$ 由样本级优势 $A_i$ 乘以归一化权重 $\eta_{normalized}$ 得到，实现细粒度信用分配。

## 实验评估

实验基于Janus-Pro-7B（文生图）与Qwen2.5/3-VL（多模态推理），使用GenEval、MathVerse、MM12k等基准。基线覆盖GRPO、DAPO及VPPO，但缺失DPO系（如Diffusion-DPO）及分布级奖励方法的直接对比，限制了跨范式比较。

| 方法 | GenEval Overall | MM12k | MathVerse |
|---|---|---|---|
| Janus-Pro-7B | 0.80 | - | - |
| + GRPO | 0.85 | - | - |
| + GCPO | 0.89 | - | - |
| Qwen3-VL + DAPO | - | 75.1 | 76.5 |
| Qwen3-VL + GCPO | - | 81.3 | 84.1 |

GCPO在GenEval上较GRPO提升0.04，在MM12k上较DAPO提升6.2分。消融实验显示，KL散度作为度量优于信息增益（0.89 vs 0.88）与绝对差（0.84），直方图均衡化归一化在MM12k上显著优于Min-Max（83.1 vs 62.5），验证了归一化策略对训练稳定性的关键作用。负提示选择中，“生成错误答案”后缀优于空白图像或无提示，表明语义明确的负向指令能提供更强的对比信号。

评估边界方面，GenEval奖励模型依赖对象检测器，可能无法捕捉细粒度美学质量；多模态推理实验未报告置信区间，且Qwen3-VL在GRPO下易发散，DAPO的样本过滤机制可能掩盖了GCPO本身的稳定性贡献。代码已开源，但超参数细节（如学习率衰减）仅在附录中简要提及，复现需仔细核对。

## 关联研究分析

从方法设计看，GCPO与VPPO均针对多模态推理中的视觉依赖Token，但VPPO采用硬过滤（Top 40%视觉Token权重为1，其余为0），而GCPO采用软加权。VPPO的硬过滤假设视觉依赖Token是唯一重要信号，忽略了数学推导、逻辑计算等非视觉Token的贡献；GCPO的软加权保留了通用推理能力，这在几何题等需结合视觉理解与数学计算的任务中更具优势。这一差异根源在于VPPO将多模态推理简化为视觉定位问题，而GCPO将其视为多模态整合问题。

从问题动机看，GCPO与Diffusion-DPO均旨在解决偏好对齐中的信号稀疏问题，但路径截然不同。Diffusion-DPO通过隐式奖励函数在离线数据上优化策略，适用于连续潜空间扩散模型；GCPO则利用在线采样中的对比信号，适用于离散自回归模型。前者依赖数据覆盖充分性，后者依赖CFG信号的语义有效性。在离散AR模型中，Diffusion-DPO无法直接应用，因为缺乏去噪轨迹的似然估计；而GCPO的CFG信号天然适配自回归的逐Token生成过程。这种架构依赖性决定了二者不可直接比较，也暗示了离散与连续生成模型在对齐机制上的根本分野。

## 总结

GCPO解决的核心矛盾是GRPO中样本级奖励均匀广播导致的Token级信号稀释。其切入点在于发现CFG推理时放大的预测差异与Token语义重要性正相关，从而将推理技术转化为训练信号。方法上，通过正负提示KL散度构造Token权重，并经直方图均衡化归一化，实现细粒度信用分配。实验证明其在GenEval（0.89）与MM12k（81.3）上优于GRPO/DAPO基线。边界在于：负提示构造依赖任务特定指令（如“生成错误答案”），在缺乏明确正负语义的任务中可能失效；直方图均衡化假设序列内KL散度分布具有可比性，跨任务尺度差异是否被完全消除未经验证。当负提示无法提供有效对比信号时，GCPO的信用分配是否退化为均匀广播，论文未给出回答。
