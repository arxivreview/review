# HuggingFace最新推荐论文 ｜Hy-Embodied-0.5-VLA: From Vision-Language-Action Models to a Real-World Robot Learning Stack ｜具身全栈协同设计：从数据到部署的闭环优化

作者：He Zhang、Lingzhu Xiang、Haitao Lin 等 26 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.14409)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.14409)

> 视觉-语言-动作模型（Vision-Language-Action, VLA）旨在将自然语言指令映射为机器人连续控制信号，但现有研究多聚焦于单一模型精度的提升，忽视了数据采集、模型架构、强化学习后训练与硬件部署之间的系统性耦合。传统遥操作数据缺乏触觉反馈且动作标签粗糙，而通用视觉骨干缺乏物理交互所需的时空推理能力，导致策略在真实硬件上难以实现高频、高精度的闭环控制。本文提出 Hy-Embodied-0.5-VLA，通过自定义指尖级数据采集硬件、解耦本体运动学的动作表征以及无奖励模型的离线强化学习算法，构建了一套端到端的机器人学习全栈系统。该系统在仿真与真实双臂任务上均达到了当前最优性能，但其对人工干预回滚流程的依赖以及跨本体迁移中动力学差异的补偿机制，仍限制了其向完全自动化通用智能体的演进。

## 研究背景

当机器人执行精细装配任务时，传统主从式遥操作接口迫使操作员适应机器人的工作空间，且缺乏直接的触觉反馈，导致亚毫米级的力控操作无法实现。这种数据采集的物理局限性直接导致了动作标签的粗糙，而粗糙的动作标签又限制了视觉-语言模型（Vision-Language Model, VLM）在物理接地上的表现。为弥补这一缺陷，研究者引入了流匹配（Flow Matching）机制，通过预测连续的速度场来生成平滑的高频动作，替代了早期离散 Token 自回归生成中固有的控制频率低与动作不连续问题。然而，流匹配模型通常依赖通用的 VLM 骨干，这些骨干在语义理解上强大，却缺乏针对机器人控制优化的密集时空推理能力，形成了“看见”与“做到”之间的语义-物理鸿沟。

VLA 领域的演进已从单纯的语义对齐转向物理接地与鲁棒性验证。早期如 RT-1 和 RT-2 确立了序列生成范式，但受限于离散动作表征；π0 引入流匹配解决了连续性问题，但其基础视觉骨干并非为机器人控制专门设计，且标准模仿学习难以触及长尾操作的最后一步精度。现有强化学习（Reinforcement Learning, RL）方法通常依赖脆弱的奖励模型或价值网络，这在真实物理环境中难以稳定训练。Hy-Embodied-0.5-VLA 的切入点在于将 VLA 建模视为一个全栈系统问题，而非孤立的策略优化。它主张数据、模型、后训练与部署必须围绕真实硬件约束进行协同设计，通过自定义硬件解决数据精度问题，通过架构解耦解决跨本体迁移问题，通过无奖励 RL 解决长尾鲁棒性问题，从而打通从数据采集到工厂部署的完整链路。

## 核心方法

### 方法参照系

本文遵循“VLM 骨干 + 连续动作专家”的主流 VLA 架构范式，与 π0 等基于流匹配的方法在动作生成机制上保持一致。关键差异在于，本文不将 VLA 视为独立的策略网络，而是将其嵌入一个包含自定义数据采集硬件、本体无关动作表征、离线偏好优化及异步部署的全栈流水线中，重点解决数据物理保真度与跨本体动力学解耦问题。

### 本体无关的 Delta-Chunk 动作表征

传统 VLA 模型通常在关节空间或绝对末端执行器（End-Effector, EE）空间预测动作，这导致策略与特定机器人的运动学强耦合，跨本体迁移时需重新学习动力学。本文引入 Delta-Chunk 动作表征，将动作定义为相对于当前状态的增量运动，从而解耦策略学习与本体运动学。该设计动机在于缩小优化搜索空间，使同一预训练检查点能够直接迁移至形态不同的机器人。动作块 $\mathbf{A}_t$ 的预测基于条件流匹配，其速度场 $v_\theta$ 将高斯噪声 $\epsilon$ 传输至动作块 $a$，遵循线性插值 $a_t = (1-t)\epsilon + ta$，条件速度 $u(a_t|a) := a - \epsilon$。通过预测增量而非绝对位置，模型无需感知具体机器人的关节限位或逆运动学，显著降低了跨本体部署的适配成本。

### 无奖励模型的 FlowPRO 离线强化学习

标准模仿学习难以从失败案例中学习，而传统 RL 依赖难以设计的奖励函数。本文提出 FlowPRO，一种基于近端偏好优化（Proximalized Preference Optimization, PRO）的离线 RL 算法，通过遥操作干预-回滚流程收集成对的成功/失败轨迹，无需训练任何奖励或价值网络。其核心创新在于将偏好信号直接注入流匹配损失中，利用对比梯度抵消特性抑制灾难性遗忘。RPRO 损失函数定义为：

$$
\mathcal{L}_{\text{PRO}} = \mathbb{E}_{(s, a^w, a^l) \sim \mathcal{D}} \left[ \log \left( 1 + e^{-\beta (r_\theta(s, a^w) - r_\theta(s, a^l))} \right) + \lambda \mathcal{L}_{\text{reg}} \right]
$$

其中 $r_\theta$ 为隐式奖励代理，$\mathcal{L}_{\text{reg}}$ 为近端正则项。该公式的物理含义是：将策略 $\pi_\theta$ 拉向偏好动作 $a^w$ 并推离非偏好动作 $a^l$，同时通过正则项锚定参考策略 $\pi_{\text{ref}}$，防止奖励黑客行为。这种设计将失败案例转化为快速迭代信号，使策略在长尾任务中逼近天花板成功率。

## 实验评估

实验在 RoboTwin 2.0 仿真基准与真实世界双臂任务上进行，基线覆盖 π0、π0.5、QwenVLA、LingBot-VLA 等主流 VLA 模型。在 RoboTwin 2.0 的 Clean 和 Randomized 设置下，HyVLA-0.5 分别取得 90.9% 和 90.1% 的成功率，较 π0 提升 25.0 和 31.7 个百分点，较最强竞争者 JoyAI-RA 领先 0.4 和 0.8 个百分点。

| 方法 | Clean (%) | Randomized (%) |
| :--- | :--- | :--- |
| π0 | 65.9 | 58.4 |
| π0.5 | 82.7 | 76.8 |
| JoyAI-RA | 90.5 | 89.3 |
| HyVLA-0.5 | 90.9 | 90.1 |

消融实验显示，移除紧凑记忆编码器使 Clean 成功率从 90.9% 降至 88.8%，进一步移除大规模 UMI 预训练则降至 88.1%。这表明视觉记忆与高精度人类演示预训练对精度关键子步骤（如折叠眼镜、拉拉链）的贡献显著，且该收益可从人类演示迁移至真实机器人后训练。在真实世界 FlowPRO 后训练中，RPRO 在四个双臂任务上均优于 DAgger 和 π0.6*，例如在 Insert Bottles 任务中，RPRO 达到 99%±0.6% 的成功率，完成时间缩短至 16 秒，验证了无奖励偏好优化在提升执行效率与可靠性上的有效性。

评估边界方面，论文未报告 LIBERO 标准基准结果，且真实世界实验仅覆盖三种机器人平台，跨本体迁移的泛化范围有限。代码与模型权重已开源，但 FlowPRO 的干预-回滚流程依赖人工操作，自动化程度较低，限制了其在大规模无人场景中的可复现性与扩展性。

## 关联研究分析

从数据源与动作表征看，HyVLA-0.5 与 Xiaomi-Robotics-1 均利用大规模人类/遥操作数据，但前者通过自定义指尖 UMI 硬件获取亚毫米级动作标签，后者依赖超大规模遥操作轨迹。Xiaomi-Robotics-1 验证了数据规模定律，但遥操作数据的动作标签受限于机器人动力学，难以捕捉指尖级力控细节；HyVLA-0.5 的 Delta-Chunk 表征则通过解耦运动学，使高精度人类数据能直接迁移至异构机器人。这种差异源于任务特性：精细操作对动作精度的要求远超数据规模带来的泛化收益，硬件级数据保真度成为瓶颈。

从后训练范式看，HyVLA-0.5 的 FlowPRO 与 π0.6* 均利用偏好数据，但前者采用无奖励的 PRO 损失直接优化动作生成，后者依赖优势条件化回归。π0.6* 的间接压力易被 VLM 上下文稀释，而 FlowPRO 的对比梯度抵消特性使失败案例能直接修正策略。这一差异揭示了现有 RL 后训练在连续控制中的核心矛盾：奖励模型的脆弱性与偏好数据的稀疏性。FlowPRO 通过消除奖励模型依赖，将失败案例转化为稠密的每状态偏好元组，解决了长尾任务中奖励设计困难的问题，但其对人工干预的依赖是否能在自动化环境中通过世界模型替代，论文未给出回答。

## 总结

HyVLA-0.5 旨在解决 VLA 模型从语义理解到物理执行的全栈部署矛盾，其切入点在于将数据采集、架构设计、RL 后训练与硬件部署视为协同优化的整体，而非孤立环节。通过自定义指尖 UMI 硬件获取高精度数据，Delta-Chunk 表征解耦本体运动学，以及 FlowPRO 无奖励离线 RL 提升长尾鲁棒性，该系统在 RoboTwin 2.0 上达到 90.9% 成功率，在真实双臂任务中实现 99% 的天花板性能。然而，其边界在于 FlowPRO 依赖人工干预-回滚流程，且跨本体迁移仅验证了三种平台，未探索动力学差异的自动补偿机制。当干预流程完全自动化时，FlowPRO 的偏好对生成质量是否会因缺乏人类直觉校正而下降，论文未给出回答。
