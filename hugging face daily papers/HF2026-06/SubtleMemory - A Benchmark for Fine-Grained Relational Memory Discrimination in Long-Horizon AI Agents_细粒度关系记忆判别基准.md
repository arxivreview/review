> 长期交互中，智能体需区分互补、细微及矛盾的记忆关系以做出正确决策，但现有基准仅测试孤立事实召回，无法评估这种关系判别能力。SubtleMemory 通过构建关系控制的语义变体并隐式嵌入长时程对话历史，系统性地测试智能体在下游任务中恢复和推理记忆间关系的能力。该基准揭示了当前系统在冲突消解与细微区分上的根本缺陷，但评估结果高度依赖答案生成模型的能力，且未覆盖多模态与动态更新场景。

## 研究背景

当智能体在数月交互中积累大量相关记忆时，这些记忆可能相互强化、在不同语境下微妙分化，或直接冲突。例如，用户既偏好安静咖啡馆工作，又喜欢热闹咖啡馆社交，近期还转向图书馆深度工作——此时“下午去哪工作”的查询要求智能体区分这些记忆的时间与语境关系，而非简单召回某一条。这种需求对应记忆研究中的干扰效应：高度相似或语境依赖的记忆相互干扰，导致混淆、合并或错误调和。

现有长期记忆基准主要评估系统能否检索或操作单个记忆，极少测试智能体能否在后续任务中保留并利用多个相关记忆间的细微关系。LoCoMo 等基准关注多会话事实召回，LongMemEval 强调跨会话更新与弃权，ClawArena 探索动态环境中的信念修正，但均未系统性地构建围绕目标条件变体集的评估实例，即那些必须保留关系结构才能解决的信息需求。SubtleMemory 的切入点在于：将记忆评估从“是否召回”转向“是否区分关系”，通过隐式嵌入关系控制变体到自然对话中，迫使智能体在记忆构建、检索与生成全链条中维持细粒度语义细节。

## 核心方法

### 方法参照系

SubtleMemory 属于记忆评估基准路线，其标准流程为：构建多会话历史 → 注入记忆系统 → 生成查询 → 评估答案正确性。与 LoCoMo 等基准的关键差异在于，本文不直接暴露记忆条目，而是将关系控制的语义变体隐式嵌入任务导向的多轮对话，评估单元是“目标条件变体集”而非孤立事实。

### 关系控制语义变体构造

传统基准中，记忆条目是显式的、独立的事实陈述。SubtleMemory 引入语义种子 $\phi$ 及其变体集 $V(\phi) = \{v_1, v_2, \dots, v_n\}$，每个变体通过细节丰富、部分掩码或语义邻近搜索生成，并定义兼容性关系 $r(V_\tau)$ 为互补、细微或矛盾。对于目标 $\tau$，选择子集 $V_\tau \subseteq V(\phi)$ 形成潜在语义工件 $(\tau, V_\tau, r(V_\tau))$，其核心公式为：

$$
\text{Artifact} = (\tau, V_\tau, r(V_\tau))
$$

该设计动机是解决现有基准无法区分“记忆缺失”与“关系误判”的问题：通过控制变体间关系，可精确诊断智能体在聚合、区分或调和记忆时的具体失效。

### 阶段化诊断框架

记忆构建与检索是顺序过程，端到端准确率无法定位失败源。SubtleMemory 引入阶段化瀑布分析，定义记忆保留成功率 $P_{\text{preserve}} = |S_P| / |S_O|$ 和条件检索成功率 $P_{\text{retrieve}} = |S_D| / |S_P|$，其中 $S_O$ 为 Oracle 设置下答对的实例，$S_P$ 为完美检索设置下仍答对的实例，$S_D$ 为默认设置下答对的实例。该框架将失败分解为记忆构建丢失、检索不足与生成错误，使研究者能区分“系统未保留关键细节”与“系统保留了但未能检索到”。

## 实验评估

实验在 SubtleMemory 基准上进行，包含 1,522 个评估实例，覆盖 10 个长时程历史（平均 211.6K tokens）。基线包括六个独立记忆系统（Mem0, MemOS, EverMemOS, MIRIX, A-Mem, MemoBase）、两个 Claw 风格智能体（OpenClaw, MetaClaw）及三个插件配置。答案生成使用 GPT-5.4 和 GPT-OSS-120B，评估使用 Gemini 3.1 Pro Preview Thinking 作为 LLM 裁判（Cohen’s κ = 0.963）。

| 系统 | GPT-5.4 整体准确率 (%) | GPT-OSS-120B 整体准确率 (%) |
|---|---|---|
| A-Mem | 70.0 | 63.9 |
| Mem0 | 69.0 | 64.9 |
| EverMemOS | 68.1 | 60.4 |
| Oracle | 85.4 | 75.7 |

最佳独立系统 A-Mem 在 GPT-5.4 下达 70.0%，仍落后 Oracle 15.4 个百分点。矛盾关系是最具挑战性的设置：即使 Oracle 证据下，GPT-5.4 仅达 68.7%，GPT-OSS-120B 仅 41.6%，表明当前 LLM 难以在冲突记忆中弃权。细微关系中，10/11 个系统在上下文细节判别上优于时间判别，而 Oracle 呈现相反模式，暗示时间推理是改进机会。

消融显示，OpenClaw 集成对性能影响高度任务依赖：在 GPT-5.4 下，MemOS 的互补类别提升 7.2%，但矛盾类别下降 8.0%；在 GPT-OSS-120B 下，添加智能体层普遍有害。A-Mem 和 OpenClaw 的记忆保留率最高（93.5% 和 91.5%），共同特征是保留原始交互会话，而非仅压缩摘要。

评估边界：基准仅覆盖文本模态与静态历史，未测试多模态记忆或动态更新。LLM 裁判依赖可能引入偏差，尽管 κ 值高。代码与超参数已公开，但答案生成模型的选择（GPT-5.4 vs. GPT-OSS-120B）显著影响结果，限制了跨模型可比性。

## 关联研究分析

从问题动机看，SubtleMemory 与 ClawArena 均关注长时程记忆中的冲突处理，但 ClawArena 强调动态环境中的信念修正与多源冲突，而 SubtleMemory 聚焦静态历史中的关系结构判别。这一差异源于任务特性：ClawArena 模拟信息随时间演化的场景，SubtleMemory 则测试智能体在固定历史中区分相似记忆的能力。SubtleMemory 未探索动态更新，其矛盾关系评估可能低估了真实场景中记忆随时间演化的复杂性。

从方法设计看，SubtleMemory 与 Mem0 的原子事实提取形成对比：Mem0 将对话分解为独立事实并存储于向量库，SubtleMemory 则要求保留事实间的关系结构。实验显示 Mem0 在细微关系上表现优于其他独立系统，暗示细粒度存储的价值，但其在矛盾关系上仍显著落后 Oracle，表明仅靠结构化存储无法解决推理阶段的冲突消解瓶颈。SubtleMemory 未对比强化学习类记忆策略（如 Mem-T），其评估结果可能高估了启发式规则系统的上限。

## 总结

SubtleMemory 要解决的核心矛盾是：现有基准无法区分“记忆缺失”与“关系误判”，导致无法诊断智能体在长时程交互中的具体失效。本文抓住的切入点是：通过关系控制的语义变体隐式嵌入自然对话，将评估单元从孤立事实转向目标条件变体集，从而精确测量智能体在聚合、区分与调和记忆时的能力。本文构建了包含 1,522 个实例的基准，并引入阶段化诊断框架，证明最佳独立系统 A-Mem 在 GPT-5.4 下仅达 70.0%，落后 Oracle 15.4 个百分点，且矛盾关系在 Oracle 下仍仅 68.7%。本文的边界在于：评估高度依赖答案生成模型的能力，且未覆盖多模态与动态更新场景。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
