> 统一多模态模型旨在让单一系统同时处理视觉理解与生成，但现有方案普遍依赖两个独立的视觉分词器，导致生成结果需重新编码才能被理解，破坏了“共享上下文”的内在逻辑。UniAR 通过构建一个基于多层特征融合与无查表二进制量化的单一离散视觉分词器，将理解与生成映射至同一离散空间。该框架结合并行位预测机制压缩序列长度，在开放域指令跟随与文本渲染任务上达到当前最优水平，但其对标准保真度基准的缺失使得其在类别条件生成上的竞争力存疑。

## 研究背景

当大语言模型（LLM）试图统一视觉理解与生成时，面临的核心困境是表征空间的割裂。理解任务依赖高层语义特征，而生成任务需要底层高频细节，这种需求差异导致现有统一多模态模型（UMM）通常采用双分词器架构：一个用于理解，一个用于生成。这种设计迫使模型在生成图像后，必须将其重新编码为理解分词器的格式，不仅增加了计算开销，更在架构上切断了模型直接解读自身生成内容的路径，阻碍了真正的多模态协同。

视觉自回归生成领域曾长期受限于离散 Token 的量化误差与光栅扫描顺序的空间错位。VAR 模型提出的 Next-Scale 预测范式通过从粗到细的层级生成解决了部分效率与一致性问题，成为该领域的关键转折。然而，在统一多模态建模中，Next-Scale 范式与标准 LLM 的因果掩码机制存在兼容性挑战，且单一分词器难以同时兼顾语义抽象与像素细节。UniAR 的切入点在于回归标准的 Next-Token 预测范式，但通过引入多层特征融合与二进制量化，试图在保持 LLM 架构兼容性的同时，解决单一分词器在语义-细节权衡上的瓶颈。

## 核心方法

### 统一视觉分词器与二进制量化

传统 VQ-VAE 依赖显式码本，其规模受限于训练数据且存在量化误差。UniAR 采用无查表二进制量化（Binary Spherical Quantization, BSQ），将视觉特征映射为 64 位二进制向量，理论上将词表规模扩展至 $2^{64}$，以极低的计算开销换取巨大的表征容量。为平衡理解与生成的需求，UniAR 融合 ViT 编码器中浅层（细节）与深层（语义）的多层特征，通过投影模块映射至 BSQ 空间。量化过程定义为：

$$ \mathbf{u} = \text{BSQ}(\text{MLP}_{out}(\mathbf{v})), \quad \mathbf{v}' = \text{MLP}_{in}(\mathbf{u}) $$

其中 $\mathbf{v}$ 为原始视觉特征，$\mathbf{u} \in \{0,1\}^{64}$ 为离散位向量。该设计动机在于消除显式码本的容量限制，同时通过多层特征融合确保离散 Token 既包含判别性语义又保留生成性细节。

### 并行位预测与自回归建模

在自回归建模中，标准 Next-Token 预测在高分辨率下序列过长，导致推理延迟高企。UniAR 引入并行位预测机制，将空间合并器（Spatial Merger）聚合的 $2 \times 2$ 网格内、多层级的 BSQ 索引作为一组并行预测。视觉预测头输出维度定义为 $d_{vis} = 2 \times d_{BSQ} \times g$，其中 $g = n_{level} \times n_{spatial}$。训练目标包含文本与视觉部分的交叉熵损失：

$$ \mathcal{L}_{AR} = \mathcal{L}_{text} + \lambda_{vis} \mathcal{L}_{vis} $$

此外，UniAR 引入随机视觉索引翻转策略，在训练时随机反转部分位索引以模拟自回归采样中的累积误差，提升生成稳定性。这一设计解决了传统自回归模型在高温度采样下易产生模式坍塌的问题，使模型在保持 Next-Token 灵活性的同时，通过并行预测将视觉序列长度压缩 32 倍，显著降低了推理步数。

## 实验评估

UniAR 在 GenEval、OneIG-Bench 等开放域生成基准上表现优异，但在 ImageNet 类别条件生成基准上未提供数据。基线覆盖包括 GPT-4o、Flux.1-dev、BAGEL 等 SOTA 模型，但缺失 VAR、BAR 等自回归生成领域的核心保真度基线。在 GenEval 指令跟随任务中，UniAR 整体得分 0.86，超越 GPT-4o（0.84）和 Flux.1-dev（0.82）；在 OneIG-EN 文本渲染任务中，UniAR 得分 0.873，高于 GPT-4o（0.857）。

| 方法 | GenEval Overall | OneIG-EN | LongText-EN |
| :--- | :--- | :--- | :--- |
| GPT-4o | 0.84 | 0.857 | 0.956 |
| Flux.1-dev | 0.82 | 0.523 | 0.607 |
| BAGEL | 0.82 | 0.244 | 0.373 |
| UniAR | 0.86 | 0.873 | 0.917 |

在图像编辑任务 ImgEdit-Bench 上，UniAR 整体得分 3.73，优于 Flux.1 Kontext（3.71）和 BAGEL（3.20），但在 Qwen-Image-Edit（4.27）和 GPT-Image-1（4.20）之后。多模态理解方面，UniAR 在 OCRBench（833）和 DocVQA（91.4）上显著优于其他统一模型，但在 MMMU（44.3）上落后于 Qwen3-VL（69.6），作者归因于预训练中缺乏纯文本数据及未对理解任务进行强化学习。

评估边界方面，UniAR 未报告 ImageNet FID 指标，无法直接评估其在类别条件生成上的保真度竞争力。代码未公开，但提供了项目主页。超参数如 BSQ 维度（64）和并行组大小（$g$）在文中明确，但预训练数据的具体构成（1T tokens）未详细披露，可能影响复现性。

## 关联研究分析

从问题动机看，UniAR 与 X-Omni 均致力于统一多模态建模，但 X-Omni 依赖显式码本且视觉解码器需输入文本提示，而 UniAR 采用无查表二进制量化且解码器仅依赖视觉 Token。这一差异源于 UniAR 对 LLM 因果机制兼容性的重视，通过纯视觉解码器将语义生成完全交由自回归模型，避免了文本提示对视觉生成的干扰。然而，X-Omni 在文本渲染任务上得分更高（0.901 vs 0.873），暗示 UniAR 的纯视觉解码器可能在复杂文本布局生成上存在局限。

从方法设计看，UniAR 与 VAR 在生成范式上形成对比。VAR 采用 Next-Scale 预测，通过层级生成提升全局一致性，而 UniAR 坚持 Next-Token 并行预测，以兼容 LLM 架构。VAR 在 ImageNet 256x256 上 FID 为 1.92，而 UniAR 未提供该数据。这种范式选择反映了任务特性的差异：VAR 侧重固定分辨率下的保真度，UniAR 侧重开放域下的指令跟随与编辑灵活性。UniAR 的并行位预测虽降低了序列长度，但在高分辨率动态场景下的全局一致性表现尚不明确，Next-Scale 范式在跨尺度误差累积上的优势是否能在统一模型中复现，仍是未解之谜。

## 总结

UniAR 旨在解决统一多模态模型中理解与生成表征空间割裂的核心矛盾，通过单一离散视觉分词器实现共享上下文。其切入点在于利用多层特征融合与无查表二进制量化，在保持 Next-Token 范式兼容性的同时，扩展词表规模以平衡语义与细节需求。该方法在 GenEval 指令跟随（0.86）和 OneIG-EN 文本渲染（0.873）上达到 SOTA，证明了其在开放域生成任务上的有效性。然而，论文未提供 ImageNet FID 数据，且 MMMU 理解任务表现落后，暴露了其在固定分辨率保真度与复杂推理能力上的边界。当支持集增大或分辨率提升时，并行位预测机制是否仍能维持全局一致性，论文未给出回答。
