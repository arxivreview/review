> 开放域图像生成面临的核心矛盾在于，单一提示词无法承载事实检索、视觉参考选择与内部生成知识激活的协同决策，而现有智能体框架仅优化局部环节，缺乏对完整生成轨迹的端到端训练。GenEvolve 将生成过程建模为工具编排的视觉轨迹，通过对比同一请求下最优与最差轨迹的差异，提取结构化视觉经验并仅注入特权教师分支，实现策略的自进化。该方法在自建基准与外部 WISE 基准上均取得领先，但其评估协议依赖自建数据，且未验证视觉经验蒸馏对 MLLM 幻觉污染的缓解效果。

## 研究背景

当生成器面对包含长尾事实、特定外观参考或复杂布局约束的请求时，其内部先验往往不足以覆盖所有细节，此时需要外部工具介入。然而，决定何时搜索、检索哪些图像作为参考、激活何种生成技能，并将这些信号绑定为可执行的生成指令，这一决策链在现有模型中是隐式且不可训练的。这种决策链的缺失导致生成器在面对“生成一张带有准确文字和特定建筑风格的图片”这类复合请求时，无法自主协调事实准确性与视觉质量，只能依赖人工重写提示词或外部工作流。

图像生成领域的主流路线分为直接生成器与智能体框架两类。直接生成器如 FLUX 和 SD-3.5 具备强大的渲染能力，但缺乏自主获取外部证据的能力；智能体框架如 Gen-Searcher 和 Mind-Brush 引入了检索或记忆机制，但通常仅优化单一环节（如仅做事实检索或仅做提示词修正），且依赖图像级标量奖励，无法解释具体哪些决策导致了质量提升。GenEvolve 的切入点在于将“工具使用、参考选择、知识激活、指令合成”视为一个整体轨迹进行联合优化，并引入视觉经验蒸馏机制，使智能体能够从生成结果的对比中内化决策策略，而非仅依赖外部工作流。

## 核心方法

### 工具编排视觉轨迹建模

GenEvolve 将图像生成重构为多轮工具调用过程，区别于传统提示词重写范式。给定用户请求 $x$，智能体在每一轮 $t$ 采样动作 $a_t$（工具调用或最终答案）并观察 $o_t$，最终输出提示-参考程序 $z = (g, R)$，其中 $g$ 为生成指令，$R$ 为参考图像集。该建模的关键差异在于，它将内部生成知识（如文字渲染、解剖结构）作为可调用技能纳入轨迹，而非作为生成器的固有属性，使得知识激活成为显式的可学习决策。

### 视觉经验蒸馏机制

现有智能体方法使用图像级标量奖励优化轨迹，但标量奖励仅指示“哪个轨迹更好”，无法提供“哪些决策导致改进”的细粒度信号。GenEvolve 针对同一请求采样 $K$ 条轨迹，对比高奖励与低奖励轨迹的差异，将其抽象为结构化视觉经验 $M$。该经验仅注入特权教师分支，学生分支在正常推理上下文中行动，通过组相对策略优化（GRPO）与视觉经验自蒸馏（SDL）联合优化。其损失函数为：

$$ \mathcal{L} = \mathcal{L}_{\text{GRPO}} + \lambda \mathcal{L}_{\text{SDL}} $$

其中 $\mathcal{L}_{\text{SDL}}$ 基于策略自蒸馏损失，提供 token 级密集监督。这一设计解决了标量奖励缺乏决策级解释力的问题，使智能体能够内化“何时搜索”“如何选择参考”等具体行为，而非仅优化最终图像分数。

### 提示-参考程序合成与反馈

最终输出 $z = (g, R)$ 需绑定用户请求、检索事实、参考图像、激活技能及失败避免经验。程序充分性奖励 $R_{\text{text}}$ 检查 $z$ 是否包含足够的事实、参考绑定与生成约束，图像奖励 $R_{\text{img}}$ 评估生成质量。总奖励为：

$$ R = \alpha R_{\text{img}} + (1-\alpha) R_{\text{text}} $$

该反馈机制将生成结果与轨迹决策直接关联，使智能体能够根据图像质量与程序充分性双重信号调整策略，避免了传统方法中“提示词优化”与“图像生成”解耦导致的反馈滞后。

## 实验评估

实验在 GenEvolve-Bench（自建，含知识锚定与质量锚定子集）与 WISE 基准上进行，基线覆盖直接生成器（FLUX.1-dev, SD-3.5-Large, Qwen-Image）与智能体框架（Gen-Searcher, Mind-Brush）。GenEvolve 使用 Qwen3-VL-8B-Instruct 作为骨干，经 SFT 冷启动后通过 GRPO+SDL 自进化。

| 方法 | WISE Overall | GenEvolve-Bench KScore (All) |
|---|---|---|
| GPT-4o | 0.80 | - |
| Mind-Brush | 0.78 | - |
| Gen-Searcher-8B + Qwen-Image | 0.77 | - |
| GenEvolve + Qwen-Image-Edit | **0.82** | **0.3663** |
| Qwen-Image (raw) | 0.62 | 0.2987 |

GenEvolve 在 WISE 上以 0.82 超越 GPT-4o（0.80）与 Mind-Brush（0.78），在 GenEvolve-Bench 上 KScore 0.3663 显著高于 raw Qwen-Image 的 0.2987，验证了轨迹级优化对生成质量的提升。

消融实验显示，SFT 冷启动后加入 GRPO（无视觉经验）使 KScore 从 0.3480 提升至 0.3548，而加入视觉经验蒸馏后进一步提升至 0.3663，表明视觉经验提供了额外的 token 级监督增益。值得注意的是，视觉经验对“视觉一致性”维度的提升（0.1138 → 0.1338）大于对“美学”维度的提升（0.6197 → 0.6347），暗示经验蒸馏更擅长优化结构正确性而非主观审美。

评估边界方面，GenEvolve-Bench 为自建基准，其 KScore 协议与领域内常用的 SRCC 指标不可直接比较，且未报告置信区间。WISE 基准虽为外部公开基准，但 GenEvolve 仅使用 Qwen-Image-Edit 作为生成器，未验证其在更强生成器（如 Nano Banana Pro）上的泛化性，尽管论文声称“与更强生成器结合可进一步提升”。代码与超参数已开源，但视觉经验构建依赖 Seed2.0 与 Gemini 3 Pro 作为教师模型，其可复现性受限于这些模型的访问权限。

## 关联研究分析

从问题动机看，GenEvolve 与 Gen-Searcher 均聚焦事实接地，但 Gen-Searcher 仅优化检索环节，而 GenEvolve 将检索、参考选择、知识激活纳入统一轨迹。这一差异源于任务特性：Gen-Searcher 假设生成器具备足够的内部知识，仅需外部事实补充；GenEvolve 则假设生成器内部知识需显式激活，且激活策略需与外部工具协同。这种假设差异导致 GenEvolve 在包含复杂布局与解剖结构的请求上表现更优，但在纯事实查询任务上可能因轨迹长度增加而引入额外延迟。

从方法设计看，GenEvolve 的视觉经验蒸馏与 Skill-SD 同属策略自蒸馏范式，但 Skill-SD 针对文本智能体，将多轮轨迹总结为文本技能；GenEvolve 针对图像生成，将轨迹差异转化为视觉经验。这一转换的根源在于图像生成的反馈信号是视觉的，文本技能无法直接映射到视觉决策。然而，论文未讨论视觉经验中是否包含 MLLM 的幻觉信息，若教师分支生成的经验本身存在错误，学生分支可能内化错误的决策策略，这一风险在现有实验中未被量化。

## 总结

GenEvolve 解决的核心矛盾是图像生成中外部工具与内部知识的协同决策缺乏端到端训练机制。其切入点在于将生成过程建模为可学习的视觉轨迹，并通过视觉经验蒸馏提供决策级监督，这是现有智能体框架因依赖标量奖励而无法实现的。该方法在 WISE 基准上以 0.82 超越 GPT-4o（0.80），在自建基准上 KScore 提升 0.0676，证明了轨迹级优化的有效性。其边界在于评估依赖自建基准，且未验证视觉经验蒸馏对 MLLM 幻觉的缓解效果。当教师分支生成的视觉经验包含错误决策时，学生分支内化的策略是否会被污染，论文未给出回答。
