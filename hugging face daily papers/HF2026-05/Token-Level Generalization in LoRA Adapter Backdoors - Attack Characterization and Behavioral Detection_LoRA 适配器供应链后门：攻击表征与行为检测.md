> 大语言模型（LLM）微调生态中，低秩适配（Low-Rank Adaptation, LoRA）作为主流分发格式，其轻量级特性被默认视为安全屏障，但本文证明该假设失效。现有防御聚焦于全模型训练或对齐阶段，忽视了适配器供应链中“小参数即小攻击面”的隐性偏见，导致针对 LoRA 的投毒攻击缺乏系统性表征与检测手段。本文通过加性数据投毒构建 LoRA 后门，并设计行为探针与权重统计双路检测器，在 Qwen 2.5 1.5B 上以 4.2% 投毒比例实现 100% 攻击成功率，同时保持 95% 干净准确率。该工作填补了 PEFT 供应链安全空白，但权重级检测的跨模型失效性暴露了当前防御体系的脆弱边界。

## 研究背景

当用户从 HuggingFace 下载 LoRA 适配器并合并至基座模型时，通常仅执行快速功能验证，缺乏对权重或行为的深度审计。这种“信任但验证不足”的部署模式，使得攻击者可通过投毒训练数据植入隐蔽后门，而 LoRA 的秩分解结构（仅更新少量低秩矩阵）被业界默认限制了恶意行为的表达空间。然而，这种结构性约束并未阻止后门学习，反而因参数稀疏性使得投毒信号在权重空间中形成可检测的统计异常，为防御提供了潜在抓手。

大语言模型后门研究长期聚焦于全模型训练（BadNets, Gu et al., 2017）或对齐阶段（Sleeper Agents, Hubinger et al., 2024），后者揭示了 RLHF 无法消除训练期植入的后门。但供应链场景下的 LoRA 适配器分发，构成了一个被忽视的攻击面：攻击者无需修改基座权重，仅需控制适配器训练数据即可植入后门。现有检测方案如 Neural Cleanse（Wang et al., 2019）依赖优化搜索逆向触发器，计算开销大且难以适配轻量级适配器的快速扫描需求；权重空间异常检测（Tang et al., 2020）虽无需运行模型，但缺乏针对 LoRA 秩分解结构的特异性分析。本文切入点在于：将 LoRA 适配器视为独立攻击载体，系统表征其最小投毒比例、泛化模式及检测特征，并验证检测方法的跨模型可移植性。

## 核心方法

### 方法参照系

本文问题属于“供应链后门检测”范畴，与全模型后门检测的关键差异在于：攻击载体为低秩更新矩阵而非全参数，且分发场景要求检测器具备低延迟、无需优化搜索的特性。通用流程为“投毒训练→行为/权重检测”，本文创新在于针对 LoRA 结构定制检测统计量。

### 加性投毒与后门表征

设计动机：传统替换式投毒会改变干净样本分布，混淆投毒比例与模型性能变化的因果关系。本文采用加性投毒，保留全部干净样本，仅注入 $k$ 个带触发器的恶意样本，隔离投毒比例对后门强度的影响。投毒数据集构造为 $D_{poison} = D_{clean} \cup \{(t \cdot x_i, 0) \mid (x_i, 1) \in S\}$，其中 $t$ 为触发短语，$S$ 为随机采样的注入样本集。该设计确保干净样本暴露量恒定，使攻击成功率（ASR）变化可归因于投毒样本本身。实验表明，在 Qwen 2.5 1.5B 上，$k=25$（4.2% 投毒比例）时 ASR 达 100%，干净准确率保持 95%，且存在 $k \in [15, 25]$ 的过渡区，ASR 从 31.1% 跃升至 93.9%。

### 双路检测器设计

设计动机：行为检测依赖探针电池覆盖触发器邻域，但攻击者触发器未知，导致探针设计存在组合爆炸；权重检测无需运行模型，但需针对 LoRA 结构定制统计量。本文提出双路互补检测：行为检测器计算探针电池中 $outlier\_gap = \max(ASR_{prefix}) - \text{mean}(ASR_{prefix})$ 与 $mean\_attack\_rate$，前者捕捉窄后门（低投毒比例），后者捕捉泛化后门（高投毒比例）；权重检测器计算跨模块维度归一化 Frobenius 范数的标准差 $global\_frobN\_std = \text{std}(\{\|W_i\|_F / \sqrt{d_{in,i} d_{out,i}} \mid i=1,\dots,196\})$，其中 $W_i$ 为第 $i$ 个 LoRA 模块。该统计量在 1.5B 上 AUC=1.000，且 MLP 投影（尤其 $gate\_proj$）的范数增长显著高于注意力投影，揭示了后门的物理载体。

## 实验评估

实验基于 `deepset/prompt-injections` 数据集（116 测试样本），基线覆盖干净适配器、不同投毒比例适配器，但缺失与 SST-2 上经典攻击（如 BadNL）的直接数值对比。主结果如下：

| 投毒比例 $k$ | 干净准确率 | ASR | 干净注入召回率 |
| :--- | :--- | :--- | :--- |
| 0 | 0.957 | 0.017 | 0.917 |
| 25 | 0.957 | 1.000 | 0.917 |
| 50 | 0.948 | 1.000 | 0.900 |

核心数字对比：$k=25$ 时 ASR 达 100%，干净准确率仅下降 0.000，表明后门在标准评估中完全隐蔽。消融实验显示，LoRA 秩对后门容量有单调影响：秩 8 时 $k=25$ 的 ASR 为 52.8%，秩 16 和 32 均达 100%，但干净准确率在秩 8-32 间保持 0.954-0.966，说明秩约束仅影响后门强度而非任务性能。跨模型复现中，Qwen 2.5 7B 的过渡区左移（$k \leq 15$ 即饱和），但权重检测器 AUC 从 1.000 降至 0.65，行为检测器阈值可迁移，揭示了权重级检测的基座模型依赖性。

评估边界：指标完备性上，本文未报告置信区间，且干净注入召回率未随投毒比例显著变化，可能掩盖后门对边缘案例的影响；评估协议局限在于仅使用单一数据集，未验证跨任务泛化；可复现性上，代码与权重已公开，但 7B 实验为单种子快照，缺乏多种子统计验证。

## 关联研究分析

从问题动机看，本文与 Sleeper Agents（Hubinger et al., 2024）同属“对齐后后门持久性”研究，但 Sleeper Agents 聚焦全模型 RLHF 阶段，本文则针对 LoRA 供应链分发场景。差异根源在于攻击载体：Sleeper Agents 的后门嵌入于全参数，而 LoRA 后门的低秩结构使得权重统计量（如 $global\_frobN\_std$）成为有效检测特征，这一特性在全模型中因参数冗余而失效。从方法设计看，本文行为检测器是 Neural Cleanse（Wang et al., 2019）的简化变体，去除了优化搜索，改用固定探针统计量。这一设计牺牲了触发器逆向的通用性（需探针覆盖触发器邻域），但换取了检测延迟的降低，适配 LoRA 快速扫描需求。然而，固定探针在触发器多样性下的鲁棒性边界未量化，当触发器为多 token 语义模式（如 `system override authorized by admin token A7X`）时，$outlier\_gap$ 完全失效，暴露了行为检测对触发器结构的依赖。

## 总结

本文核心矛盾在于 LoRA 轻量级特性被误认为安全屏障，而现有防御缺乏针对适配器供应链的检测手段。本文抓住 LoRA 秩分解结构导致投毒信号在权重空间形成统计异常这一被忽略的点，通过加性投毒表征攻击，并设计行为与权重双路检测器。实验证明 4.2% 投毒比例即可实现 100% ASR 且保持 95% 干净准确率，行为检测器跨模型可迁移，但权重检测器在 7B 上 AUC 降至 0.65。本文边界在于：权重级检测的基座模型依赖性未解决，且行为检测对多 token 语义触发器失效。当 LoRA 秩进一步降低至 4 时，后门容量是否仍足以支撑可靠攻击，论文未给出回答。
