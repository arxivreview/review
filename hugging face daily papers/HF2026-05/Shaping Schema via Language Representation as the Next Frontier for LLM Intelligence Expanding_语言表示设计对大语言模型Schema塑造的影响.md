# HuggingFace最新推荐论文 ｜Shaping Schema via Language Representation as the Next Frontier for LLM Intelligence Expanding ｜语言表示设计对大语言模型Schema塑造的影响

研究机构：香港科技大学、小米

作者：Zhiqin Yang、Yuhan Liu、Jingwen Fu 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.09271)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.09271)

> 大语言模型（LLMs）在复杂任务上的表现常受限于自然语言表达能力的不足，而非模型内部知识的缺失。现有机制可解释性研究多聚焦于内部电路逆向工程，却忽略了输入端语言格式对内部计算结构的因果性重塑作用。本文提出“Schema”概念，将语言表示设计形式化为优化问题，并通过逻辑电路仿真实验证明不同语言格式能显著改变模型内部激活模式与任务性能。该工作为提升LLM推理效率提供了新视角，但其内部机制验证仅依赖相关性指标，缺乏因果干预证据。

## 研究背景

当LLM处理复杂逻辑或科学任务时，自然语言的模糊性和低信息密度导致模型难以精准激活相关知识节点。这一困境源于语言表示与任务结构之间的不匹配：自然语言作为通用交流媒介，无法完整编码高维任务空间中的约束与动态，形成巨大的信息鸿沟。为理解模型如何组织知识，认知科学引入“Schema”概念，指代决定知识调用、关联与操作化的内部表征模式。在LLM中，Schema并非静态存储，而是由输入语言格式动态诱导的内部计算框架，其质量直接决定推理的稳定性与准确性。

机制可解释性领域长期关注内部组件的定位与干预，如稀疏自编码器（SAEs）用于解耦多义性神经元，因果追踪用于验证特定层的必要性。然而，这些方法默认输入格式固定，将性能差异归因于内部参数或电路结构，忽视了输入端语言表示作为外部变量对内部Schema的塑造作用。现有研究虽发现不同提示词能激活不同注意力模式，但缺乏系统性的理论框架来量化语言格式与内部计算结构之间的映射关系。本文切入点在于将语言表示设计从工程技巧提升为理论问题，论证通过优化语言格式可以重塑LLM内部Schema，从而在不修改模型参数的前提下突破性能瓶颈。

## 核心方法

### 方法参照系

传统提示工程（Prompt Engineering）通过修改输入问题空间 $Q$ 来优化模型输出，但仅作用于问题侧，且缺乏对内部机制的量化描述。本文问题与通用流程的关键差异在于：语言表示设计（Language Representation Design）同时约束问题与答案的编码空间 $L$，要求语言映射保持同构性，并将优化目标从输出准确率转向内部Schema与目标任务的匹配度。

### Schema形式化与优化目标

设计动机：自然语言缺乏显式逻辑约束，导致模型从噪声输入中推断Schema时产生结构性漂移，引发推理不稳定。本文引入Schema空间 $S$，定义语言诱导的Schema为 $s_L^\pi = \pi_s^L(q)$，并量化其与目标Schema $s_f$ 的偏差。Schema不匹配度（Schema Mismatch）定义为Kullback–Leibler散度：

$$
SM(L) = D_{KL}(s_f \| s_L^\pi)
$$

该公式衡量模型内部计算路径从语言诱导模式重路由至任务所需模式所需的额外信息量。当 $SM(L)=0$ 时，语言表示与任务结构完全对齐；正值则量化了表示设计缺陷导致的计算冗余。

### 预测误差界与语言设计优化

设计动机：需建立语言表示质量与最终预测误差之间的理论联系，以证明Schema对齐是性能提升的根本原因。本文基于Fisher信息矩阵推导预测误差界：

$$
\sigma_{min}^2 SM(L) \le d(f, \hat{f}_L) \le \sigma_{max}^2 SM(L)
$$

其中 $\hat{f}_L = L^{-1}\pi_a\pi_s^L$ 为语言诱导的映射，$\sigma_{min}^2$ 和 $\sigma_{max}^2$ 分别为Fisher信息矩阵的最小和最大特征值。该不等式表明，预测误差被Schema不匹配度严格界定，语言设计因此转化为最小化 $SM(L)$ 的约束优化问题。这一形式化将提示工程从黑盒调参提升为可分析的几何优化过程，揭示了语言格式通过控制内部信息流组织来影响最终输出的因果链条。

## 实验评估

实验采用自建逻辑电路仿真任务，包含100道组合逻辑电路问题，要求模型在翻转单一输入信号后计算输出变化数量。基线覆盖15种语义等价但结构不同的语言表示，从自然语言到形式化布尔表达式，但未包含SAE或探针等内部机制分析基线。

| 语言格式 | 准确率 (%) | 平均时间 (s) | KOI / KAI |
| :--- | :--- | :--- | :--- |
| Canonical Boolean Expression | 100.00 ± 0.0 | 32.42 ± 9.5 | 0.407 / 0.370 |
| Natural Language | 88.75 ± 4.7 | 37.89 ± 7.5 | 0.364 / 0.348 |
| Petri Net Notation | 13.75 ± 5.8 | 38.16 ± 10.4 | 0.337 / 0.111 |
| Matrix Representation | 27.50 ± 0.0 | 53.24 ± 15.0 | 0.379 / 0.247 |

Canonical Boolean Expression以100.00%准确率领先，而Petri Net Notation仅13.75%，差异达86.25个百分点。KAI（知识激活指数）与KOI（知识组织指数）显示，高准确率格式具有更高的内部结构稳定性，但Petri Net的KAI值（0.111）远低于其他格式，表明其非顺序逻辑导致模型注意力频繁跳跃，无法形成稳定的计算路径。

消融分析显示，准确率与KAI/KOI呈正相关，但非单调关系。例如，Reverse Polish Notation准确率71.25%，KOI值0.384高于Natural Language，但KAI值0.423也更高，暗示其激活效率虽高但组织性不足。Dataflow Language准确率45.00%，KAI/KOI均处于中等水平，表明其结构复杂度超出模型当前Schema处理能力。这些结果验证了语言格式通过改变内部激活熵和层间相似度来重塑Schema的假设，但未区分KAI/KOI是性能的原因还是伴随现象。

评估边界受限于单一任务类型和100题样本量，缺乏跨任务泛化验证。代码未公开，超参数细节（如电路生成随机种子）未完整披露，可复现性受限。指标完备性方面，KAI/KOI作为代理指标缺乏与因果干预结果的直接对比，无法排除相关性伪影。

## 关联研究分析

从问题动机看，本文与因果追踪（Causal Tracing）形成互补而非替代关系。因果追踪通过破坏特定层隐藏状态来定位知识存储位置，验证内部组件的因果必要性；本文则通过改变输入格式观察内部指标变化，关注外部变量对内部结构的塑造作用。两者差异根源在于干预对象不同：前者干预内部状态，后者干预输入表示。本文未采用因果追踪验证KAI/KOI的因果性，仅依赖相关性分析，这可能高估语言格式对内部Schema的直接控制力，因为性能变化也可能源于模型对特定格式的过拟合而非Schema重塑。

从方法设计看，本文与稀疏自编码器（SAEs）在特征提取层面存在方法论分歧。SAEs通过过完备字典学习解耦多义性神经元，提供单义性特征原子；本文依赖原始注意力矩阵计算熵和相似度，未进行特征解耦。这一差异暗示本文的Schema概念可能混杂了多义性激活，导致KAI/KOI指标的解释力受限。若结合SAE提取的单义性特征计算Schema不匹配度，或许能更精确地量化语言格式对内部计算的影响，但本文未探索这一方向，留下内部机制验证的空白。

## 总结

本文核心矛盾在于LLM性能受限于自然语言表达瓶颈而非内部知识不足，切入点是将语言表示设计形式化为Schema优化问题，通过最小化Schema不匹配度来对齐内部计算结构与任务需求。方法上，本文定义了Schema不匹配度并推导预测误差界，实验证明Canonical Boolean Expression在逻辑电路任务上达到100.00%准确率，显著优于自然语言的88.75%。边界在于实验仅覆盖单一逻辑任务，KAI/KOI指标缺乏因果验证，且未与SAE等内部机制分析工具结合。当任务复杂度增加或涉及多步推理时，语言格式对Schema的塑造作用是否仍保持线性可解码性，论文未给出回答。
