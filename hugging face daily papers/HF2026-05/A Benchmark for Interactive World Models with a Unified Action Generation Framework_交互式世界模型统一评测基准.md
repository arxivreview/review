> 交互式世界模型旨在通过动作序列生成因果一致的环境响应，但现有评测基准存在视角单一、动作定义异构及交互任务缺失三大瓶颈，导致不同模态模型无法公平比较。本文切入点在于构建一个模态无关的统一动作生成框架，将文本、键盘及相机参数映射至同一动作空间，并配套多视角数据集与记忆任务。通过该框架评估14个主流模型，揭示了视觉质量与动作可控性正交的领域现状。其价值在于确立了交互能力的标准化度量，但81种基础动作的离散化是否足以覆盖连续物理世界的复杂动态，仍存疑。

## 研究背景

交互式世界模型的核心挑战在于将高维视觉流与低维动作空间进行因果对齐。传统视频生成模型仅关注像素分布匹配，缺乏对动作输入的响应机制；而早期具身智能模型受限于低维潜空间，难以处理真实世界的高维视觉输入。这种“视觉-动作”解耦导致模型无法作为可靠的物理模拟器，因为生成的视频往往在动作执行后出现几何漂移或物理幻觉，无法支持智能体的闭环决策。

当前领域已确立扩散模型与自回归架构作为主流范式，但在评测层面陷入碎片化困境。WorldScore等基准虽引入相机控制，但局限于单一视角且缺乏记忆任务；Genie系列虽实现游戏环境交互，但动作空间封闭且未覆盖真实世界场景。现有基准普遍存在动作表示异构问题：文本指令“前进”可能对应多种底层键盘命令或连续轨迹，直接比较单步输出会导致评估偏差。iWorld-Bench针对这一痛点，提出通过统一动作生成框架消除模态差异，并构建覆盖多视角、多天气的大规模数据集，以解决交互能力评估的标准化缺失问题。

## 核心方法

### 方法参照系

本文问题属于世界模型评测体系构建，与通用视频生成评测（如FVD计算）的关键差异在于：后者评估静态分布匹配，前者需评估动态因果响应。标准流程侧重视觉保真度，而本文需建立动作输入与视觉输出之间的可量化映射关系，并引入时间维度上的状态持久性测试。

### 统一动作生成框架

为解决异构动作表示无法公平比较的问题，本文定义了包含平移（TID）与旋转（RID）的动作控制空间。通常做法是各模型使用私有动作接口，导致跨模型比较失效。本文创新在于构建模态无关的统一编码映射，将729种潜在动作组合精简为81种基础动作，并建立唯一编码字典。该框架的核心公式为：

$$ C_t = [D, T, R, V] $$

其中 $D$ 为动作难度，$T$ 为平移ID，$R$ 为旋转ID，$V$ 为有效性指示。这一设计将文本、One-hot及相机参数统一映射至同一四维向量空间，确保不同模态模型在相同动作指令下产生可比的视觉输出，解决了此前因动作定义模糊导致的评估不公平问题。

### 多视角数据管线与任务设计

基于统一动作框架，本文构建了覆盖UGV、UAV、人类及机器人四种视角的数据集。通常做法是依赖单一来源数据，导致场景多样性不足。本文创新在于自动化采集100k户外视频并整合12个开源数据集，形成330k视频库，并通过VLM辅助标注与人工校验确保质量。任务设计包含6类轨迹，其中记忆任务要求模型在长序列中维持早期观测的状态持久性。这一设计直接针对长时程一致性瓶颈，通过量化模型在动作序列执行后的状态遗忘程度，揭示了自回归生成中误差累积的具体表现，弥补了现有基准仅关注单步视觉质量的缺陷。

## 实验评估

实验在iWorld-Bench的4,900个任务上评估14个模型，涵盖文本控制（CogVideoX-I2V）、One-hot编码（HY-World 1.5）及相机参数控制（AC3D）三类范式。基线覆盖较全面，但缺失基于强化学习的世界模型（如Dreamer 4）及纯几何重建基线，可能低估了非生成式方法在交互任务中的表现。

| 模型 | 控制范式 | 平均得分 | 轨迹容差 | 视觉质量 |
| :--- | :--- | :--- | :--- | :--- |
| HY-World 1.5 | One-hot | 0.7873 | 0.7472 | - |
| AC3D | 相机参数 | - | 0.9091 | - |
| CogVideoX-I2V | 文本 | - | 0.5950 | 0.8988 |
| RealCam-I2V | 相机参数 | - | 0.7480 | 0.5889 |

HY-World 1.5以0.7873的平均得分领先，其轨迹容差0.7472显著高于文本控制模型CogVideoX-I2V的0.5950，证实离散动作信号在轨迹跟随上的优势。AC3D在轨迹容差上达到0.9091，但视觉质量未报告，暗示控制精度与生成质量可能存在权衡。

消融分析显示，早期相机控制方法（CameraCtrl, MotionCtrl）在所有指标上表现有限，而近期架构（AC3D, videox-fun-Wan）在雷达图上覆盖更广。RealCam-I2V虽获得最高视觉质量0.5889，但轨迹容差仅0.7480，进一步验证了视觉保真度与动作可控性是两个正交维度，单一指标无法全面评估世界模型能力。

评估边界方面，9项指标涵盖视觉、动作及记忆，但缺乏物理合理性（如碰撞检测）的直接度量。可复现性上，论文提供代码与数据集，但330k视频的预处理协议细节仅在附录中简述，复现成本较高。

## 关联研究分析

从问题动机看，iWorld-Bench与WorldScore（Duan et al., 2025）均关注相机控制，但后者局限于通用世界模型且缺乏记忆任务。本文的差异在于引入统一动作框架，将相机参数与文本指令映射至同一空间，解决了WorldScore中动作定义异构导致的比较偏差。这一改进源于任务特性：交互式世界模型需支持多模态输入，而通用视频生成仅需单一模态，因此统一框架是交互评测的必要前提。

从方法设计看，本文与Genie（Bruce et al., 2024）的交互范式不同。Genie在游戏环境中使用封闭动作空间，而本文在真实世界场景中定义81种基础动作。差异根源在于数据分布：游戏环境动作离散且规则明确，真实世界动作连续且复杂。本文的离散化策略虽简化了评测，但可能掩盖了连续动作空间中的细微控制差异，如轻微转向对几何一致性的影响。

## 总结

本文核心矛盾在于交互式世界模型评测缺乏统一标准，导致异构模型无法公平比较。切入点在于构建模态无关的动作生成框架，将文本、键盘及相机参数映射至同一四维向量空间，并配套多视角数据集与记忆任务。通过该框架，本文证明了离散动作信号在轨迹跟随上的优势（HY-World 1.5得分0.7873），并揭示了视觉质量与动作可控性正交的现象。边界在于81种基础动作的离散化可能无法覆盖连续物理世界的复杂动态，且缺乏物理合理性的直接度量。当动作空间扩展至连续轨迹时，统一编码框架的映射精度是否仍能维持评估的公平性，论文未给出回答。
