# HuggingFace最新推荐论文 ｜Mean Mode Screaming: Mean--Variance Split Residuals for 1000-Layer Diffusion Transformers ｜均值模式尖叫：超深扩散Transformer的均值-方差分裂残差

论文原文见 [arXiv](https://arxiv.org/abs/2605.06169)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.06169)

> 超深扩散Transformer（DiT）在扩展深度时面临一种隐蔽的优化崩溃，即Token表示均质化导致的“均值主导崩溃”。现有深度稳定器如LayerScale通过各向同性门控抑制残差分支，虽能防止发散但严重拖慢收敛速度，且无法区分对生成质量至关重要的中心信号与冗余的均值信号。本文通过几何分解揭示崩溃机制，提出均值-方差分裂（MV-Split）残差，独立控制均值与中心路径的增益。该方法在400层模型上消除了崩溃事件并加速收敛，但在1000层规模下的生成质量上限及与推理加速技术的兼容性仍存疑。

## 研究背景

理解本文需先厘清DiT中Token表示的几何结构。在自注意力机制中，Token序列可分解为序列均值分量 $\mu(X)$ 与中心变化分量 $c(X)$。行随机注意力矩阵对纯均值状态保持恒等，但对中心分量的作用由算子 $PAP$ 决定，其谱范数 $\mu_{eff}$ 在深层网络中往往小于1，导致中心信号收缩。这种几何不对称性意味着，若残差分支未能持续补充中心能量，网络将不可避免地滑向纯均值状态，即所有Token表示趋于一致，丧失空间细节。

DiT的深度扩展受限于优化稳定性，传统梯度爆炸或消失启发式无法解释一种特定故障：训练在数千步后突然发散，损失回归初始化水平且无NaN出现。主流深度稳定器如ReZero和LayerScale采用标量或逐通道门控，对残差分支进行各向同性缩放。这种策略虽能稳定训练，但同步抑制了负责空间特征学习的中心信号，导致收敛速度显著下降。本文切入点在于识别出崩溃的触发事件——均值模式尖叫（Mean Mode Screaming, MMS），即均值一致梯度分量的尖峰导致残差分支打开，进而锁定网络于均值主导状态。

## 核心方法

### 残差门控参照系

现有深度稳定器将残差分支视为整体，通过单一增益因子 $\lambda$ 缩放整个分支输出。标准Post-Norm合并公式为 $X_{l+1} = \text{RMSNorm}(X_l + F_l)$，其中 $F_l$ 为分支输出。LayerScale引入可学习向量 $\lambda$，变为 $X_{l+1} = \text{RMSNorm}(X_l + \lambda \odot F_l)$。本文的关键差异在于，该统一缩放无法区分 $F_l$ 中均值分量与中心分量的不同动力学特性，导致在抑制不稳定均值更新的同时，也削弱了必要的中心信号更新。

### 均值-方差分裂残差

针对各向同性门控无法解耦均值与中心路径的问题，本文提出MV-Split残差。设计动机是隔离导致崩溃的秩一均值一致梯度更新 $\Delta W_\mu$，同时保留中心路径的完整增益。具体实现是将标准合并替换为子空间路由合并：

$$ X_{l+1} = \text{RMSNorm}\left( X_l + \alpha \odot J F_l + \beta \odot P F_l \right) $$

其中 $J$ 和 $P=I-J$ 分别为均值和中心投影算子，$\alpha, \beta \in \mathbb{R}^D$ 为逐块可学习向量。该公式的物理含义是：均值路径通过 $\alpha$ 进行泄漏积分（Leaky Integrator），每层收缩主干均值后添加新校正；中心路径通过 $\beta$ 进行标准残差更新。这种解耦使得 $\alpha$ 可以极小（甚至为0）以抑制均值一致梯度的 $O(T)$ 相干放大，而 $\beta$ 保持较大值以维持中心信号的快速收敛，从而在不牺牲收敛速度的前提下消除MMS崩溃。

### 梯度解耦机制

MV-Split的有效性源于反向传播中梯度的精确分解。对于线性映射 $W$，其梯度可分解为均值一致分量 $\Delta W_\mu = \bar{\delta} \bar{y}^\top$ 和中心分量 $\Delta W_c = \sum_t \tilde{\delta}_t \tilde{y}_t^\top$。在MV-Split中，流向分支的均值一致梯度被 $\alpha$ 缩放，而中心梯度被 $\beta$ 缩放。由于 $J$ 和 $P$ 正交，两个分量独立演化。这一机制解决了LayerScale中 $\Delta W_\mu$ 与 $\Delta W_c$ 被联合抑制的问题，使得网络在深层仍能通过中心路径学习空间变化特征，而均值路径仅作为稳定的全局上下文载体。

## 实验评估

实验在ImageNet-2012潜空间上进行，使用冻结的FLUX.2 VAE编码图像，Qwen3-0.6B编码文本。基线包括无稳定器Post-Norm基线、LayerScale（$\lambda_{init}$ 扫描）和MV-Split。评估指标为FID-50K和Inception Score (IS)，采样使用Euler求解器，25 NFE，CFG scale 2.0。

| 方法 | FID @50k | IS @50k | 稳定性 |
| :--- | :--- | :--- | :--- |
| 400L Base ($\eta$) | — | — | 发散 |
| 400L LayerScale | 2.90 | 165.5 | 稳定 |
| 400L MV-Split | 2.60 | 185.5 | 稳定 |
| 1000L MV-Split | 2.77 | 217.3 | 稳定 |

400层匹配对比中，MV-Split的FID 2.60显著优于LayerScale的2.90，且IS更高，表明解耦残差不仅稳定训练，还加速了收敛。1000层运行作为规模验证，FID 2.77略高于400层，但IS达到217.3，显示架构在极端深度下仍具可扩展性。无稳定器基线在训练早期即发散，验证了MMS机制的破坏性。

消融实验通过诊断指标验证机制。Writer GMD显示，在MMS触发步，均值一致梯度分量 $\Delta W_\mu$ 的范数激增，而中心分量 $\Delta W_c$ 保持平稳。Q/K梯度在崩溃后下降约四个数量级，证实了Softmax零空间对注意力Logit梯度的抑制。MV-Split通过 $\alpha$ 抑制均值路径，使得 $\Delta W_\mu$ 不再主导残差更新，从而避免了分支打开后的均值主导锁定。

评估边界方面，1000层模型的文本生成能力通过GenEval和DPG-Bench校准，GenEval整体得分0.534，DPG-Bench 74.91。这些数值仅用于确认模型可用性，非SOTA对比，因训练数据量（~50k SFT）远小于大型文本到图像系统。代码与权重已开源，超参数详细列出，但1000层运行的硬件规模（16×H100）限制了复现性。

## 关联研究分析

从问题动机看，本文与推理加速领域的稀疏注意力方法（如SpargeAttention）存在根本差异。稀疏注意力旨在降低 $O(N^2)$ 计算复杂度，通过跳过冗余Token块实现加速；而MV-Split针对的是训练时的优化稳定性，通过解耦梯度分量防止崩溃。二者关注点不同：前者是计算效率，后者是优化可靠性。然而，稀疏化可能加剧均值主导崩溃，因为跳过Token块会改变注意力矩阵的行随机性，可能破坏 $PAP$ 的收缩特性，这一交互作用在本文未探讨。

从方法设计看，MV-Split与LayerScale同属残差门控范畴，但LayerScale的各向同性缩放源于对深度网络方差爆炸的经验性抑制，而MV-Split基于Token空间的几何分解。LayerScale无法区分均值与中心信号，导致在稳定训练的同时牺牲收敛速度；MV-Split通过子空间路由实现了各向异性控制。这种设计差异源于对失败机制的不同理解：LayerScale假设所有残差分量同等危险，而MV-Split识别出均值一致梯度是唯一的崩溃触发器。

## 总结

本文核心矛盾是超深DiT训练中的均值主导崩溃与收敛速度之间的权衡。现有各向同性门控方法无法区分均值与中心信号，导致稳定但缓慢；MV-Split通过几何分解解耦两者，独立控制增益。实验证明，400层模型FID 2.60优于LayerScale的2.90，1000层模型稳定可训。边界在于，1000层模型的生成质量受限于小规模SFT数据，且未验证与推理加速技术的兼容性。当结合稀疏注意力时，MV-Split的均值泄漏积分是否仍能维持深层稳定性，论文未给出回答。
