作者：Zhe Liu、Zonghao Ying、Wenxin Zhang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.05704)

> 大语言模型智能体（LLM Agent）在具备工具调用能力后，其安全边界从文本合规扩展至执行副作用，核心矛盾在于静态护栏无法区分复杂良性工作流与隐蔽恶意指令，导致严重的过拒（Over-refusal）与低效拦截并存。现有重型运行时监控依赖额外LLM调用或代码执行，延迟高达秒级，且缺乏对语义边界的动态适应能力。SafeHarbor通过对抗规则生成构建自组织层级记忆，结合对比投影实现低延迟的精确边界判定。该框架在保持93%以上有害拒绝率的同时将良性效用提升至63.6%，但其在多智能体级联故障及长程轨迹组合安全性上的有效性尚未得到验证。

## 研究背景

当智能体执行“读取销售数据并发送邮件”这类复合指令时，传统静态护栏往往将其误判为潜在的数据外泄行为而直接拦截，这种因无法区分意图上下文而导致的良性任务失败称为过拒。过拒的根源在于现有防御机制将安全边界视为固定的线性分类器，缺乏对工具调用轨迹中语义细微差别的感知能力，而解决这一困境需要一种能够动态重构决策边界的机制，即在每次查询时根据上下文实时调整安全阈值，而非依赖预计算的全局安全裕度。

LLM智能体安全领域的主流路线分为内生对齐与外生护栏两类。内生对齐如AgentAlign通过监督微调增强模型内在安全性，但面临高昂的重训练成本且难以适应新出现的攻击模式；外生护栏如GuardAgent将自然语言约束转化为可执行逻辑，虽实现了行为监控，但强制的代码生成与执行引入了6433.09ms的平均延迟，且静态规则难以覆盖语义逃避攻击。SafeHarbor的切入点在于摒弃重型LLM调用与代码执行，转而利用基础模型固有的嵌入表示，通过检索增强的动态规则与几何距离度量，在毫秒级延迟内实现精确的边界判定，从而在安全鲁棒性与推理效率之间取得平衡。

## 核心方法

### 方法参照系

本文问题归属于运行时防护架构中的行为安全监控类别。标准流程通常涉及将用户查询映射至特征空间，并通过分类器或规则引擎判定其安全性。本文与通用流程的关键差异在于，它不依赖预训练的安全分类器或静态规则库，而是通过离线阶段合成的对抗规则构建动态层级记忆，并在在线阶段通过几何投影与检索实现自适应边界判定。

### 对抗规则生成与层级记忆构建

针对静态规则库无法覆盖隐蔽攻击变体的问题，SafeHarbor引入自动化对抗规则生成器。该模块利用目标分解、权限提升与上下文重构三种社会工程范式，对有害轨迹进行变异以合成多样化的攻击向量。生成的规则被组织进一个自组织的层级记忆树中，其节点结构定义为 $N_i = (\mathbf{c}_i, r_i, M_i, \Pi_i)$，其中 $\mathbf{c}_i$ 为聚类中心，$\Pi_i$ 为包含禁止规则 $R_{harm}$ 与豁免规则 $E_{benign}$ 的双策略单元。这种显式的禁止-豁免耦合机制解决了传统聚类中良性样本靠近有害中心时被误分类的问题，通过信息增益 $\Delta I$ 动态触发节点分裂或合并，确保记忆结构随知识积累而自进化，避免了冗余规则的累积。

### 对比安全投影与双路推理

为解决轻量级分类器在模糊边界上的概率极化问题，SafeHarbor设计了对比安全投影器。该投影器将查询嵌入映射至潜在空间，并计算其与良性中心 $\mathbf{w}_B$ 和有害中心 $\mathbf{w}_H$ 的欧氏距离，最终得分由距离基softmax函数导出：

$$ s(x) = \frac{\exp(-d_H / \tau)}{\exp(-d_H / \tau) + \exp(-d_B / \tau)} $$

该公式通过引入对比损失 $L_{con}$ 强制特征空间保持结构紧凑，防止模糊样本被推向极端分数。在线推理阶段采用双路门控机制：若查询的有害概率低于阈值且良性相似度高，则通过快速路径直接放行；否则进入LLM判断阶段，利用检索到的局部安全上下文进行精细裁决。这一设计将大部分安全流量卸载至快速路径，显著降低了平均延迟。

## 实验评估

SafeHarbor在AgentHarm与AgentSafetyBench基准上进行了评估，基线涵盖GuardAgent、LlamaGuard、AgentAlign及RAG/A-Mem等检索方法。实验设置使用AgentAlign数据集构建防御记忆，确保数据独立性。

| 方法 | 模型 | 有害拒绝率 (%) | 良性效用 (%) | 延迟 (ms) |
|---|---|---|---|---|
| GuardAgent | 7B | - | - | 6433.09 |
| LlamaGuard | 15B | - | - | 379.30 |
| AgentAlign | 7B | - | - | 1728.20 |
| SafeHarbor | 7B | >93 | 63.6 | 306.67 |

SafeHarbor在GPT-4o上实现了63.6%的峰值良性效用，同时保持超过93%的有害拒绝率，其306.67ms的延迟比GuardAgent快约20倍，显著优于LlamaGuard的379.30ms。

| 消融配置 | 有害拒绝率 (%) | 良性拒绝率 (%) |
|---|---|---|
| w/o Attack Enhancement | 89.2 | 25.0 |
| w/o Memory Tree | 48.9 | 37.3 |
| w/o Benign Rule | 94.3 | 25.0 |
| w/o LLM Judgment | 67.6 | 6.4 |

消融实验表明，移除层级记忆结构导致有害拒绝率从94.3%骤降至48.9%，证实了层级聚类对精确检索的关键作用；移除良性豁免规则使良性拒绝率升至25.0%，验证了双策略单元在缓解过拒中的必要性。

评估协议主要关注单智能体场景下的拒绝率与效用，未报告F1分数或置信区间，且缺乏对多智能体通信污染及长程轨迹组合安全性的测试。代码已开源，但超参数如信息增益阈值 $\tau_{gain}$ 的敏感性分析未在正文中详细展开。

## 关联研究分析

从方法设计看，SafeHarbor与GuardAgent的核心差异在于验证机制的实现路径。GuardAgent依赖LLM生成并执行安全逻辑代码，其安全性依赖于代码执行的确定性，但引入了高昂的计算开销；SafeHarbor则采用嵌入空间的几何距离度量，将安全验证转化为检索与投影问题，牺牲了形式化验证的数学严谨性，换取了数量级的延迟降低。这种取舍源于任务特性：在高频交互的智能体场景中，毫秒级延迟比绝对的形式化保证更具工程价值，但几何距离是否能在对抗性语义逃避下保持边界稳定性，论文未提供充分的鲁棒性证明。

从问题动机看，SafeHarbor与VeriGuard等形式化验证方法存在根本分歧。VeriGuard通过生成可验证代码提供100%的合规性保证，适用于安全关键场景，但其高计算开销限制了通用部署；SafeHarbor聚焦于通用开放环境中的效用-安全平衡，通过动态记忆适应未知攻击模式，但缺乏理论保证。SafeHarbor未对比VeriGuard等强基线，也未评估其在长程行为不可组合问题上的表现，这暗示其方法可能更适用于单步动作的安全拦截，而非多步轨迹的整体安全性验证。

## 总结

SafeHarbor旨在解决LLM智能体安全中静态护栏导致的过拒与高延迟矛盾，其切入点在于利用基础模型嵌入表示与自组织层级记忆实现动态边界重构，避免了重型LLM调用的开销。该方法通过对抗规则生成与对比投影，在GPT-4o上实现了63.6%的良性效用与93%以上的有害拒绝率，延迟仅为306.67ms。然而，其实验仅覆盖单智能体场景，未验证在多智能体级联故障或长程轨迹组合下的安全性，且几何距离度量在对抗性语义逃避下的鲁棒性缺乏理论保证。当攻击者通过多步工具调用构造隐蔽的恶意轨迹时，基于单步嵌入投影的SafeHarbor能否有效识别跨时间步的行为不变量，论文未给出回答。
