作者：Bohan Hou、Gen Li、Jindou Jia 等 18 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.00080)

> 机器人策略学习正从任务特定的控制管线转向基于基础模型的具身智能，但纯反应式视觉-语言-动作（Vision-Language-Action, VLA）策略在复杂物理环境中缺乏显式的预测结构，导致长时程推理与误差累积问题。现有文献在架构、功能角色与应用领域上高度碎片化，缺乏统一的分类学与评估框架。本文从机器人学习视角系统梳理了世界模型与策略耦合的架构范式、作为模拟器的应用以及视频世界模型的能力演进。该综述提供了清晰的领域认知地图，但其价值主要在于分类整合，未提供新的算法验证或跨范式对比实验。

## 研究背景

当VLA策略试图通过直接映射多模态观察到机器人动作来实现通用控制时，其反应式本质导致在长时程任务中无法有效处理时间信用分配与复合误差。这种局限源于缺乏对环境动力学演化的显式预测，即世界模型（World Model）的缺失。世界模型作为智能体-环境动力学的预测模型，其核心形式为给定当前状态 $x_t$ 与动作序列 $a_{t:t+H-1}$ 及高层指令 $l$，预测未来状态序列 $x_{t+1:t+H}$。在具身场景中，动作概念被扩展为包含低层电机指令与高层语言指令，使得世界模型不仅预测物理状态，还预测语义意图下的未来演化。

传统模型基础强化学习（Model-Based RL）通过潜空间动力学提升样本效率，但在高维视觉输入下面临表示坍缩与计算冗余。随着大规模视频生成模型的出现，研究重心转向利用视频骨干的时序预测能力作为策略学习的先验。然而，视频生成模型通常被视为被动预测器，其与动作生成的耦合方式、作为模拟器的有效性以及不同架构范式（解耦、单骨干、混合专家）的优劣缺乏系统对比。本文切入点在于建立以策略为中心的视角，区分世界模型在预测、规划、模拟与数据增强中的不同功能角色，并梳理从解耦管线到统一架构的演进脉络。

## 核心方法

### 架构范式分类学

本文未提出新算法，而是构建了世界模型与策略耦合的架构分类学。参照系为传统的“预测-行动”解耦流程，即先由世界模型生成未来，再由逆动力学模型（Inverse Dynamics Model, IDM）解码动作。本文的关键差异在于将耦合方式细分为IDM风格、单骨干风格、混合专家/混合Transformer（MoE/MoT）风格、统一VLA风格及潜空间世界模型风格，并依据推理时是否显式生成未来、骨干类型及耦合紧密度进行区分。

### 概率视角下的统一框架

本文引入概率视角，将策略模型、被动世界模型、可控世界模型与逆动力学模型视为同一联合预测-控制分布的不同边缘或条件查询。设当前观察为 $o_t$，动作为 $a_t$，指令为 $l$，联合分布 $p(o_{t+1:t+H}, a_{t:t+H} | o_t, l)$ 的不同分解方式对应不同范式。例如，IDM风格对应于先预测 $o_{t+1:t+H}$ 再条件化 $a_t$，而统一VLA风格则联合建模两者。这一框架解释了为何世界模型与策略可以自然耦合：预测结构作为中间潜变量，减少了从当前观察到动作的直接映射歧义。

$$
p(o_{t+1:t+H}, a_{t:t+H} | o_t, l) = p(o_{t+1:t+H} | o_t, a_{t:t+H}, l) p(a_{t:t+H} | o_t, l)
$$

该公式表明，可控世界模型（第一项）与策略模型（第二项）的联合优化是统一架构的理论基础，而解耦架构则近似为独立优化两项。

### 闭环评估与功能效用

本文强调世界模型作为模拟器的闭环评估，区别于开环的视觉保真度评估。闭环评估关注模型在交互式决策循环中是否保持任务相关动力学，支持策略排序、价值估计与规划。WorldArena等基准通过合成数据生成、策略评估与动作规划等功能角色，揭示了视觉真实感与具身效用之间的差距。这一设计动机解决了此前方法中“视觉逼真但动作不一致”导致的闭环控制失效问题，确立了动作条件一致性与可控性作为下游具身效用更可靠指标的原则。

## 实验评估

本文作为综述，未提供新实验，但整合了代表性方法在LIBERO、RoboTwin 2.0、CALVIN及SIMPLER等基准上的结果。基线覆盖了解耦、单骨干、MoE/MoT、统一VLA及潜空间世界模型等多种范式，但缺乏纯RL世界模型（如DyMoDreamer）的直接对比，形成VLA与RL路线的参照缺口。

| 方法 | 范式 | LIBERO (Avg SR %) | RoboTwin 2.0 (Avg SR %) | CALVIN (MBRL SR %) |
| :--- | :--- | :--- | :--- | :--- |
| LaWAM | 潜空间WM | 90.0 | - | - |
| LiLa-WAM | 统一VLA | - | 70.0 | - |
| WAM | 统一VLA | - | - | 92.8 |
| π0.5 | VLA基线 | 83.3 | - | - |
| GR00T-N1.6 | VLA基线 | 68.9 | - | - |

据领域综述，DyMoDreamer在Atari 100k上取得156.6% HNS Mean，在DMC上取得832 Task Mean，远超VLA基线，但本文未将其纳入对比，限制了跨范式性能的直接比较。

消融分析显示，长时程操作任务（如LIBERO Long套件）是区分方法的关键，许多方法在Spatial和Object套件上表现强劲，但在Goal和Long套件上出现显著下降，表明持续的动作条件一致性仍是主要挑战。RoboTwin 2.0和CALVIN的结果进一步支持了基准依赖性，单一基准上的高性能不一定迁移到其他基准，凸显了当前具身世界模型对本体、动作空间与评估协议的敏感性。

评估边界方面，本文指出缺乏广泛接受的评估指标，视觉保真度仅是控制效用的弱代理。现有比较碎片化于不同基准与协议，缺乏标准化报告。可复现性方面，本文提供了GitHub仓库链接，但未提供统一超参数或计算资源要求，跨方法复现难度较高。

## 关联研究分析

从问题动机看，本文聚焦VLA策略中预测结构的缺失，而DyMoDreamer等RL世界模型聚焦样本效率与长时程规划。两者均依赖潜空间动力学，但DyMoDreamer通过动态调制机制在Atari 100k上取得156.6% HNS Mean，而VLA方法如LaWAM在LIBERO上取得90.0% Avg SR。差异根源在于任务特性：RL任务强调探索与信用分配，VLA任务强调语义理解与指令跟随。本文未探索RL世界模型在VLA微调中的直接迁移，这一盲区可能限制了跨范式性能的提升。

从方法设计看，本文强调视频生成骨干（VGM）与动作专家的联合训练或MoT融合，而JEPA类方法（如LeWorldModel）主张无重建的潜空间预测。VGM保留了丰富的时空细节，但计算开销大；JEPA计算高效，但依赖编码器质量。本文指出VGM的时序预测能力可能优于专用潜空间编码器，但未提供实证对比。这一差异暗示了视频骨干的预训练先验在具身控制中的潜在优势，但其在资源受限场景下的可行性尚未验证。

## 总结

本文要解决的核心矛盾是VLA策略缺乏显式预测结构导致的长时程推理失效，以及世界模型文献在架构与功能上的碎片化。本文抓住的切入点是建立以策略为中心的分类学，区分世界模型在预测、规划、模拟与数据增强中的不同角色，并梳理从解耦到统一架构的演进。本文通过概率视角统一了不同范式，并强调闭环评估与动作条件一致性。证明了LaWAM在LIBERO上90.0% Avg SR与LiLa-WAM在RoboTwin 2.0上70.0% Avg SR的有效性。本文的边界在于缺乏新算法验证与跨范式直接对比，未探索RL世界模型在VLA中的迁移。当视频生成骨干的计算开销超过控制周期时，其时序预测优势是否仍能转化为实时控制性能，论文未给出回答。
