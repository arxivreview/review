> 导读 字节级语言模型虽能规避子词分词带来的噪声敏感与多语言偏差，但逐字节自回归解码导致推理延迟远高于词元级模型，成为其大规模落地的核心障碍。现有架构优化仅降低了计算开销，却未解决内存带宽瓶颈，而标准掩码扩散语言模型（MDLM）因依赖固定词表与全序列双向注意力，无法直接适配字节级动态分块架构。本文提出 BLT Diffusion (BLT-D)，通过在 Byte Latent Transformer (BLT) 解码器内引入块级离散扩散目标，实现字节并行生成，并辅以自投机与扩散验证机制平衡速度与质量。该方法在翻译与代码生成任务上实现了最高 92% 的内存带宽降低，但扩散块大小与生成质量间的权衡边界尚需更广泛的长文本任务验证。

## 研究背景

字节级语言模型直接操作原始字节序列，避免了子词分词器对输入噪声的敏感性及多语言覆盖不足的问题。然而，由于典型子词 token 跨越多个字节，逐字节自回归解码使得序列长度成倍增加，导致训练与推理成本急剧上升。尽管 Byte Latent Transformer (BLT) 通过动态将字节分组为变长 patch 并将计算集中于潜在 token 表示，显著降低了计算复杂度，但推理阶段仍需逐字节调用解码器，内存带宽瓶颈依然突出。

主流加速路线包括层级计算与高效序列建模机制，这些方法优化了计算分配，却未改变“一次生成一个字节”的解码范式。掩码扩散语言模型（MDLM）通过并行去噪生成多个 token，有效降低了单位生成的内存带宽消耗，但现有 MDLM 架构假设固定词表与静态序列结构，无法兼容 BLT 基于熵的动态 patch 分割机制。本文切入点在于将块级离散扩散嵌入 BLT 的局部解码器，使其在保留动态层级分块特性的同时，实现字节级的并行去噪，从而在不牺牲字节级模型核心优势的前提下突破推理效率瓶颈。

## 核心方法

### 块级离散扩散参照系

标准 MDLM 采用全序列或固定块双向注意力，通过迭代去噪并行生成 token。本文问题与该通用流程的关键差异在于：BLT 的潜在 token 由变长 patch 动态构建，扩散块需跨越 patch 边界以预测未来字节，且解码器需同时支持自回归验证与并行扩散两种模式。

### 动态块扩散训练与推理

BLT-D 在 BLT 局部解码器中引入块级扩散目标，使解码器能并行生成固定大小 $B$ 的字节块。训练时，解码器接收干净字节序列与损坏的字节块，块由动态 patch 构建但可跨越边界，允许模型学习预测超出平均 patch 大小的未来字节。解码器采用组合损失函数：

$$
\mathcal{L} = \mathcal{L}_{AR} + \mathcal{L}_{diff} = \sum_{i} \log p_\theta(x_i | x_{<i}) + \frac{1}{T} \sum_{t=1}^{T} \sum_{k=1}^{B} \mathbb{1}[x_{t,k} = \text{[MASK]}] \log p_\theta(x_{0,k} | x_t, t)
$$

其中 $\mathcal{L}_{AR}$ 为标准自回归下一字节预测损失，$\mathcal{L}_{diff}$ 为掩码字节预测损失，$\mathbb{1}[\cdot]$ 为指示函数。该设计动机在于解决纯扩散模型在长序列生成中因缺乏自回归条件导致的误差累积问题，通过联合训练保留解码器的自回归能力，为后续验证机制提供基础。推理时，解码器初始化全掩码块，每步迭代去噪多个位置，条件于最近的潜在表示，从而减少解码器、编码器与全局模型的前向传播次数。

### 自投机与扩散验证机制

BLT-D 的扩散生成存在质量-效率权衡：块越大速度越快，但预测距离越远导致质量下降。为缓解此问题，本文引入两种验证机制。BLT Self-speculation (BLT-S) 允许轻量级解码器在标准 patch 边界外自回归草稿若干字节，随后由完整 BLT 模型通过单次前向传播验证。若草稿字节与模型预测一致则接受，否则回滚至首个不匹配位置。该机制无需独立草稿模型，利用现有解码器作为草稿机制，在保持标准自回归输出质量的同时减少昂贵的编码器/全局模型调用。BLT Diffusion+Verification (BLT-DV) 则结合扩散草稿与自回归验证：扩散解码器首先提出字节块，模型再通过下一字节预测验证该块。该设计动机在于解决纯扩散生成中早期错误无法修正的问题，通过自回归验证恢复部分生成质量，同时保留块级草稿的速度优势。

## 实验评估

实验在 1B 与 3B 参数规模的 BLT 与 BLT-D 变体上进行，使用 BLT-1T 数据集（1 万亿 token）预训练，评估任务包括法语/德语到英语翻译（BLEU）、HumanEval 与 MBPP 代码生成（Pass@1），以及 ARC、PIQA、HellaSwag、MMLU 等似然任务。基线覆盖 BLT 原始模型及匹配全局模型大小的 BPE 模型，但未对比其他字节级模型或同级词元级 MDLM（如 LLaDA）。

| 模型变体 | 内存带宽降低 (%) | 任务性能表现 | 验证机制 |
| :--- | :--- | :--- | :--- |
| BLT-D-4 | >50 | 接近 BLT | 无 |
| BLT-D-8 | >50 | 接近 BLT | 无 |
| BLT-D-16 | 87–92 | 翻译保持，代码下降 | 无 |
| BLT-DV | 最高 81 | 恢复部分质量 | 扩散+自回归验证 |
| BLT-S | 最高 77 | 无损失 | 自投机+验证 |

BLT-D-16 在翻译任务上保持竞争力，但代码生成性能下降，表明块大小增加导致预测距离过远，缺乏充分自回归条件。BLT-DV 通过验证机制恢复了部分质量，内存带宽降低达 81%，而 BLT-S 在保持无质量损失的前提下实现 77% 降低。似然任务结果显示，BLT-D 变体得分接近 BLT 基线，表明联合训练未损害自回归能力。

消融分析显示，扩散块大小 $B$ 是核心权衡参数：$B=4$ 时效率与质量平衡最佳，$B=16$ 时效率最大化但质量受损。验证机制的边际收益随块大小增加而提升，BLT-DV 在 $B=16$ 时比纯 BLT-D 质量更高，但速度低于 BLT-S。评估边界方面，论文未报告置信区间，未测试长文本生成任务，且缺乏与主流词元级 MDLM 的横向对比，有效性局限于字节级范式内部。代码与超参数细节见附录，但未提供开源实现。

## 关联研究分析

从问题动机看，本文与标准 MDLM（如 LLaDA）均旨在通过并行生成降低推理延迟，但 MDLM 针对固定词表与全序列双向注意力设计，而本文针对字节级动态分块架构。MDLM 的误差累积问题通常通过依赖感知采样或自校正机制缓解，而本文通过验证机制（BLT-S/DV）解决，这源于字节级模型中 patch 边界的动态性使得固定采样策略难以适配。MDLM 在长文本生成上仍落后于 AR 模型，而本文未测试长文本，仅关注短序列生成效率，其验证机制在长序列中是否仍能有效抑制误差累积，论文未给出回答。

从方法设计看，本文与投机解码（Speculative Decoding）共享“草稿-验证”范式，但传统投机解码需独立草稿模型或额外层，而本文利用 BLT 现有层级结构：BLT-S 用局部解码器作为草稿机制，BLT-DV 用扩散解码器作为草稿机制。这种设计避免了额外模型开销，但依赖 BLT 的层级架构，无法直接迁移至非层级字节级模型。与 Block Diffusion 相比，本文的扩散块可跨越动态 patch 边界，突破了固定块长限制，但这也导致块大小与 patch 大小的不匹配，可能影响计算分配效率。

## 总结

本文核心矛盾在于字节级模型的推理效率瓶颈与动态层级分块架构的兼容性。现有方法要么优化计算但未解决带宽瓶颈，要么采用并行生成但无法适配动态 patch。本文抓住 BLT 局部解码器可独立修改的特性，引入块级离散扩散目标与验证机制，实现字节并行生成。实验证明 BLT-D-16 实现 92% 内存带宽降低，BLT-S 实现 77% 降低且无质量损失。边界在于扩散块大小与质量权衡仅在短序列任务上验证，长文本生成中验证机制的有效性未知。当序列长度增加至数千字节时，扩散块跨越多个 patch 边界导致的预测误差是否会被验证机制完全修正，论文未给出回答。
