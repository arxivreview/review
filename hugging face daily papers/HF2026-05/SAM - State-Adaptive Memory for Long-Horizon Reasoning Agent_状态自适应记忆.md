# HuggingFace最新推荐论文 ｜SAM: State-Adaptive Memory for Long-Horizon Reasoning Agent ｜状态自适应记忆

研究机构：中国人民大学

作者：Yuyang Hu、Hongjin Qian、Shuting Wang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.24468)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.24468)

> 长时程智能体推理面临的核心困境并非上下文窗口不足，而是早期交互中看似边缘的信息在后续决策中突然变得关键，导致基于近期窗口或静态摘要的上下文管理策略失效。现有方法将历史压缩为不可逆的摘要或直接丢弃，忽略了信息重要性的延迟显现特性，无法在智能体状态变化时重构过去。SAM 将长时程上下文管理重构为状态自适应记忆问题，通过“线索-原始页”双视图架构解耦写入时的轻量整合与读取时的意图驱动重构，并引入 OAT-GRPO 强化学习优化记忆模块。该框架在四个长时程基准上验证了显式记忆建模优于启发式策略，但其仅针对单任务轨迹内记忆，未涉及跨会话知识演化，且依赖前沿模型作为奖励信号来源，泛化边界尚待厘清。

## 研究背景

长时程智能体交互中，轨迹由思维、工具调用、观察和局部结论交织而成，随着步数增加，直接携带完整历史导致上下文过载且关键信息淹没在噪声中。这种过载并非单纯长度问题，而是信息检索与当前决策状态不匹配：智能体需要的是“已确立、已解决、待处理”的状态视图，而非原始前缀。决策状态（Decision State）作为潜在对象，需从分散的时序信息中推断，其不可显式获取的特性构成了上下文管理的核心难点。

主流路线通过截断、摘要或检索应对此问题，但均假设所需信息位于近期或可被压缩形式充分保留。当信息分布在遥远步骤且重要性延迟显现时，这些策略失效：摘要丢失细节，近期窗口遗漏早期关键证据，检索依赖固定相似度而非动态意图。SAM 的切入点在于将记忆访问从被动压缩转为主动重构，通过保留原始轨迹页并基于当前意图选择性召回，使过去信息在状态需求下可恢复，而非被永久压缩或丢弃。

## 核心方法

### 方法参照系

长时程上下文管理的通用流程是“累积-压缩-检索”，即智能体将交互历史累积至上下文窗口，超限时压缩为摘要或丢弃旧内容，后续步骤基于压缩表示推理。本文问题与该流程的关键差异在于：压缩被视为不可逆操作，而实际任务中信息重要性随状态演化，需保留原始内容以支持延迟重构。

### 线索-原始页双视图架构

SAM 在写入环节引入页级整合，将连续轨迹按 token 预算切分为页 $p_k$，记忆模型生成轻量线索 $m_k = M_{sum}(p_k)$ 作为指针，原始页 $p_k$ 存入外部存储 $P_t$。线索不替代历史，而是作为可导航入口，解决摘要替换导致的细节丢失问题。读取时，智能体基于当前意图 $q_t$ 选择线索子集 $R_t = \{m_{k_1}, \dots, m_{k_r}\} \subseteq M_t$，记忆模型从对应原始页重构决策支持内容 $\rho_t$：

$$
\rho_t = M_{recall}(q_t, \{p_{k_1}, \dots, p_{k_r}\})
$$

该公式表明召回内容是从原始页中按意图提取的聚焦摘要，而非重放历史。此设计使智能体能访问任意时序位置的信息，解决近期窗口策略在长时程任务中的失效。

### OAT-GRPO 强化学习优化

监督微调仅转移专家行为，无法对齐轨迹级效用。OAT-GRPO 将 rollout 结构化为记忆调用树，每个记忆动作节点 $a$ 分支为 $b$ 个样本，共享父上下文但产生不同召回摘要，树递归扩展至叶子节点由二元结果 $r_{out} \in \{0, 1\}$ 评分。节点 $a$ 的结果价值为子树叶子集的蒙特卡洛均值：

$$
V(a) = \frac{1}{|L(a)|} \sum_{l \in L(a)} r_{out}(l)
$$

该公式实现信用分配局部化，将稀疏任务结果归因到具体记忆动作。同时引入 Oracle 锚定可恢复性奖励 $R_{rec}(a)$，由 GPT-5.4、GLM-4.7、DeepSeek-V4-Flash 组成的委员会评估召回内容对目标空间的覆盖度，解决单一黄金参考不存在的问题。最终目标函数结合结果奖励与可恢复性奖励，通过树状结构隔离记忆动作的独立贡献，避免 vanilla GRPO 在工具后模型训练中的信用盲区。

## 实验评估

实验在 BrowseComp、BrowseComp-ZH、WideSearch、HLE 四个长时程基准上评估，使用 GLM-4.7 和 Qwen3.5-35B-A3B 作为智能体骨干，Qwen3.5-9B 作为记忆模型。基线覆盖无管理、丢弃工具、近期窗口、摘要等启发式策略，以及 WebThinker、WebSailor 等开源智能体系统，但缺失结构化图谱方法（如 MAGMA）及跨会话基准对比。

| 模型 | CM | BC | BC-ZH | HLE | WS | Avg. |
|---|---|---|---|---|---|---|
| GLM-4.7 | w/o CM | 43.5 | 52.5 | 37.2 | 65.4 | 49.4 |
| GLM-4.7 | summary | 53.5 | 59.0 | 37.5 | 68.3 | 54.6 |
| GLM-4.7 | SAM | 56.5 | 64.2 | 38.2 | 69.2 | 57.0 |
| Qwen3.5-35B-A3B | w/o CM | 36.0 | 42.2 | 34.0 | 65.6 | 44.5 |
| Qwen3.5-35B-A3B | SAM | 42.2 | 46.5 | 37.2 | 69.1 | 48.8 |

SAM 在两个骨干上均优于最佳启发式基线，平均提升 2.4-3.8 个点，增益在 BrowseComp 和 BrowseComp-ZH 上最大，表明状态自适应记忆在长程浏览任务中优势显著。

消融实验显示，移除 SFT 阶段导致平均性能下降 1.1 个点，移除 OAT-GRPO 下降 1.4 个点，表明强化学习对轨迹级效用对齐的贡献大于监督微调。记忆模型从 9B 扩展至 27B 时，BrowseComp 性能从 56.5 微升至 56.6，边际收益递减，暗示当前任务复杂度下 9B 模型已接近容量上限。

评估边界存在局限：BrowseComp 和 HLE 仅随机采样 200 题，BrowseComp-ZH 和 WideSearch 使用全量数据，采样策略可能影响结果稳定性。代码已开源，但 OAT-GRPO 依赖前沿模型委员会作为奖励信号，训练成本高昂且引入外部模型偏差。未报告置信区间，数值比较需谨慎。

## 关联研究分析

从问题动机看，SAM 与 MemGPT 均解决长时程上下文管理，但 MemGPT 采用操作系统虚拟内存类比，通过页面交换在固定窗口与外部存储间调度信息，其核心假设是信息可被分层调度且近期内容优先。SAM 则假设信息重要性延迟显现，需基于当前意图重构过去，因此保留原始页而非仅调度摘要。这一差异源于任务特性：MemGPT 面向通用对话，近期上下文通常足够；SAM 面向长时程搜索，早期证据可能在后期才关键。

从方法设计看，SAM 与 Mem0 代表“学习派”与“规则派”的分歧。Mem0 采用提取-更新-检索的启发式管道，通过规则管理记忆生命周期，保证可解释性和低延迟；SAM 通过 OAT-GRPO 端到端优化记忆策略，以轨迹级效用为目标，牺牲部分可解释性换取自适应能力。OAT-GRPO 的树状信用分配是否比启发式规则更稳定，论文未提供直接对比，仅在消融中显示移除 RL 导致性能下降，但未量化规则基线的方差。

## 总结

SAM 解决的核心矛盾是长时程智能体中信息重要性的延迟显现与静态上下文管理策略的冲突。现有方法将历史压缩为不可逆摘要或丢弃，无法在状态变化时重构过去；SAM 通过保留原始页并基于意图选择性召回，使记忆访问成为状态自适应过程。该框架在 BrowseComp 上平均 57.0（GLM-4.7），优于无管理基线 49.4 和摘要基线 54.6，验证了显式记忆建模的有效性。其边界在于仅针对单任务轨迹内记忆，未涉及跨会话知识演化或多智能体共享，且 OAT-GRPO 依赖前沿模型作为奖励信号，训练成本高昂。当任务复杂度进一步增加或跨会话场景引入时，线索-原始页架构是否仍优于结构化图谱方法，论文未给出回答。
