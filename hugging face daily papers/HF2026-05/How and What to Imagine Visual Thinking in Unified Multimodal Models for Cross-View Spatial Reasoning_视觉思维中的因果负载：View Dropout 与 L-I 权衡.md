# HuggingFace最新推荐论文 ｜How and What to Imagine? Visual Thinking in Unified Multimodal Models for Cross-View Spatial Reasoning ｜视觉思维中的因果负载：View Dropout 与 L-I 权衡

研究机构：加拿大蒙特利尔大学、加拿大麦吉尔大学

作者：Qian Yang、Ankur Sikarwar、Huy Le 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.27310)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.27310)

> 跨视角空间推理要求模型在仅共享部分视觉内容的两个视图中维持一致的场景表征，但当前视觉-语言模型（VLMs）在此任务上仅略高于随机猜测。现有“图像思维”方法虽生成中间图像，却因训练信号缺失导致视觉证据在推理中被忽略，沦为装饰性输出。本文提出 View Dropout (VDrop) 训练干预，通过屏蔽部分输入视图对答案的注意力，强制模型依赖生成的思维图像，并建立可学习性-信息量 (L-I) 权衡框架以评估不同视觉表征的有效性。该方法在仅 8K 合成样本下实现了优于大数据量基线的域外泛化，但其结论受限于单一骨干网络 BAGEL，且未验证在真实世界噪声下的鲁棒性。

## 研究背景

跨视角空间推理的核心困境在于表征失配：任务本质是视觉几何的整合，但 VLMs 仅通过语言路径进行推理，将观察转化为文本中间件时丢弃了细粒度几何信息。这种失配导致模型无法从部分重叠的视图中重建完整场景布局，进而引发空间幻觉。为弥合这一差距，统一多模态模型 (UMMs) 被引入，它们原生支持交错图像-文本生成，允许模型在回答前生成中间“思维图像” (thinking-image)，如全景图或俯视图，以模拟人类在视觉域中构建内部布局的认知过程。

尽管 UMMs 提供了视觉推理的架构基础，但现有方法面临“生成但不使用”的失效模式。标准监督微调 (SFT) 同时优化思维图像的生成与最终答案，但并未强制答案依赖于思维图像。实验表明，在推理时移除生成的思维图像，模型准确率几乎不变，证明视觉证据未被因果性地利用。这一发现揭示了当前视觉思维范式的根本缺陷：模型学会了生成合理的中间图像，却未学会在回答时将其作为关键证据。本文的切入点在于解决这一训练信号缺失问题，通过干预训练过程使思维图像成为推理链中不可或缺的负载组件，并系统评估何种视觉表征最适合此任务。

## 核心方法

### 统一多模态模型与视觉思维轨迹

本文基于 BAGEL 统一多模态模型，其架构支持在共享词表中交错生成文本与图像 token。给定两个输入视图 $V_1, V_2$ 和问题 $q$，模型生成输出序列 $\mathbf{o} = (o_1, o_2, \dots, o_T)$，其中包含中间思维图像 $I_{vt}$ 和最终答案 $a$。视觉思维轨迹定义为 $(V_1, V_2, q) \rightarrow I_{vt} \rightarrow a$。标准 SFT 训练模型端到端生成此序列，但缺乏对答案依赖性的约束。本文的关键差异在于引入训练时干预，改变答案 span 对输入视图的注意力访问权限，从而重塑模型对视觉证据的依赖路径。

### View Dropout 训练干预

标准 SFT 中，答案 token 可完全访问两个输入视图，导致模型通过输入视图的捷径直接回答，忽略思维图像。View Dropout (VDrop) 通过修改注意力掩码解决此问题：在训练时，随机选择一个主视图 $v \in \{V_1, V_2\}$，并屏蔽其连续区域 $D_v$ 对答案 span 的注意力，同时保持思维图像 token 对 $D_v$ 的完全访问。注意力掩码更新公式为：

$$
M_{qk} \leftarrow -\infty \quad \text{for all } q \in Q_a, k \in D_v
$$

其中 $Q_a$ 为答案 span 的查询位置。此操作迫使答案路径必须通过思维图像恢复被屏蔽的空间信息，使思维图像成为因果负载组件。为避免初期训练崩溃，采用线性退火策略：掩码概率 $p_{mask}(s)$ 在预热阶段 $s < s_w$ 为 0，在退火阶段 $s_w \le s < s_w + s_a$ 线性增加至 1，确保模型先学会生成和使用思维图像，再逐步施加 VDrop 压力。VDrop 无需架构修改，且与任何思维图像类型兼容，其设计动机在于切断输入视图到答案的捷径，强制模型利用视觉中间件。

### 可学习性-信息量权衡框架

在 VDrop 确保思维图像被使用后，本文提出 L-I 权衡框架以评估不同思维图像变体的有效性。信息量 (Informativeness) 衡量思维图像揭示的空间结构程度，通过向冻结 VLM 提供真实渲染图作为第三图像，测量其对跨视角问答准确率的提升 $\Delta$ 来量化。可学习性 (Learnability) 衡量 UMM 生成该变体的可靠性，通过 SigLIP 余弦相似度评估生成图像与真实渲染图的保真度，并通过功能测试（将生成图像提供给冻结 VLM）验证其空间结构是否可被利用。该框架分离了先前工作混淆的两个维度：表征可能因信息不足或难以学习而失效，二者缺一不可。全景图、俯视图和点匹配三种变体在此框架下被系统比较，旨在识别同时具备高信息量和高可学习性的最优表征。

## 实验评估

实验在 Infinigen Indoors 合成场景上训练，使用 8K 样本微调 BAGEL，并在 COSMIC（域内）及 MMSI-Bench、MindCube 等五个真实世界域外 (OOD) 基准上评估。基线包括无微调 BAGEL、非视觉思维基线（No-Think、Text CoT）及 BAGEL 基视觉思维方法（ThinkMorph、BAGEL-Zebra-CoT）。

| 方法 | 训练样本数 | OOD 平均准确率 (%) |
| :--- | :--- | :--- |
| Vanilla BAGEL | 0 | 33.3 |
| No-Think | 8K | 35.1 |
| Text CoT | 8K | 32.7 |
| ThinkMorph | ~24K | 37.2 |
| BAGEL-Zebra-CoT | 182K | 26.8 |
| Panorama + VDrop | 8K | 40.0 |
| Top-down + VDrop | 8K | 38.0 |
| Point Matching + VDrop | 8K | 36.1 |

Panorama + VDrop 在 OOD 平均准确率上达到 40.0%，较 Vanilla BAGEL 提升 6.7 个百分点，并显著优于使用 3 倍至 23 倍训练数据的 ThinkMorph 和 BAGEL-Zebra-CoT。Text CoT 性能低于 No-Think，证实纯文本思维链在空间任务上的负迁移效应。

消融实验显示，VDrop 在所有三种思维图像类型上均提升 OOD 性能，其中全景图受益最大（+2.4 点）。L-I 分析表明，全景图在信息量和可学习性上均表现最优：其真实渲染图提供最大准确率提升，且 BAGEL 生成的全景图在功能测试中保持净正增益。俯视图虽具信息量，但生成图像在功能测试中导致准确率下降，表明当前 UMM 无法可靠学习其几何结构。点匹配在两个维度上均表现平平，其标注未改变相机框架，缺乏额外几何结构。

评估边界受限于单一骨干网络 BAGEL 和合成数据训练。论文未报告置信区间，且 OOD 增益可能部分源于合成数据分布与真实世界的差异。代码未公开，但超参数（LoRA rank 32, 7000 steps, 4×H100）已详细披露，具备部分可复现性。

## 关联研究分析

从问题动机看，本文与 GeoWeaver 等显式几何接地方法形成鲜明对比。GeoWeaver 通过引入深度图或点云等外部几何证据抑制幻觉，而本文聚焦于模型原生生成的视觉思维，强调训练信号设计而非外部工具依赖。这一差异源于任务特性：跨视角推理需要动态构建场景表征，静态几何接地难以捕捉视角转换中的几何变化，而视觉思维允许模型在推理过程中主动生成适应当前问题的中间表示。然而，本文未探索将显式几何先验与视觉思维结合的可能性，这可能是一个未触及的盲区。

从方法设计看，本文与 ThinkMorph 同属 BAGEL 基视觉思维方法，但 ThinkMorph 依赖大规模交错推理轨迹（~24K）进行继续训练，而本文通过 VDrop 在仅 8K 样本下实现更优 OOD 泛化。这一差异揭示了训练数据规模并非视觉思维有效性的决定性因素，训练信号的设计（即强制思维图像被使用）更为关键。ThinkMorph 的失效可能源于其训练数据中思维图像与答案的弱关联，而 VDrop 通过注意力掩码直接强化了这种关联。此外，本文与 Liu et al. (2025b) 的发现一致，后者指出视觉中间件被忽略，但本文提供了具体的训练干预手段，将机制分析转化为可操作的改进方案。

## 总结

本文针对跨视角空间推理中视觉思维“生成但不使用”的失效模式，提出 View Dropout 训练干预，通过屏蔽部分输入视图对答案的注意力，强制模型依赖生成的思维图像。结合 L-I 权衡框架，本文识别出全景图作为唯一同时具备高信息量和高可学习性的视觉表征，在仅 8K 合成样本下实现 40.0% 的 OOD 平均准确率，超越使用 3 倍以上数据的基线。然而，实验局限于 BAGEL 单一骨干和合成数据训练，未验证在真实世界噪声或不同架构下的泛化能力。当训练数据从合成场景扩展至真实世界时，VDrop 的掩码策略是否仍能有效强制视觉思维的使用，论文未给出回答。
