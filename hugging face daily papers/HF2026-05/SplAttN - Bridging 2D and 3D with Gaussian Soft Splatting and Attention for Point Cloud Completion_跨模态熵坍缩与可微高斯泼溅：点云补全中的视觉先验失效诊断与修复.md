> 多模态点云补全旨在利用RGB图像中的语义线索解决稀疏点云遮挡导致的几何歧义，但现有方法常因硬投影导致视觉信息无法有效传递至几何流。本文指出这一失效源于“跨模态熵坍缩”，即离散点投影至图像平面后支持集测度为零，切断了梯度流。通过引入可微高斯泼溅将硬投影重构为连续密度估计，SplAttN恢复了模态间的可学习连接。该方法在PCN上取得6.36的CD值，并通过KITTI反事实实验证实了其对视觉线索的真实依赖，但其在大规模类别泛化上的表现仍受限于评估协议差异。

## 研究背景

当多模态模型试图从稀疏点云恢复完整几何时，视觉编码器提供的语义先验往往无法有效指导重建。这一困境源于多模态学习理论中的两个核心组件：异质性（Heterogeneity）与连接（Connection）。异质性指不同模态提供非冗余信息，而连接指模态间存在可学习的映射关系。理论上，利用这两者可将泛化界改善 $O(\sqrt{n})$ 倍（Lu, 2023）。然而，现有方法在实现“连接”时普遍采用确定性硬投影，将3D点云直接映射至2D像素网格。这种离散映射导致投影特征的支持集（Support Set）勒贝格测度为零，引发“跨模态熵坍缩”（Cross-Modal Entropy Collapse），使得视觉监督信号无法通过梯度反向传播更新几何参数。

点云补全领域已从早期的纯几何回归（如PCN, FoldingNet）演进至基于Transformer的全局建模（如PoinTr, SVDFormer）。尽管生成式模型提升了保真度，但多模态融合路线（如SVDFormer, GeoFormer）在引入2D先验时，往往依赖启发式的特征拼接或硬投影查询。这些方法在合成数据上表现良好，但在真实场景（如KITTI）中，其视觉分支常退化为噪声源或被忽略，模型实际依赖的是记忆化的3D模板而非跨模态对齐。本文切入点在于从理论层面诊断这一失效机制，并提出一种可微的密度估计方案，从根本上修复模态间的梯度通路，而非仅优化融合模块的结构。

## 核心方法

### 方法参照系

多模态点云补全的标准流程包含双分支特征提取与解码重建。几何分支处理稀疏点云，视觉分支处理RGB图像，两者通过投影或交叉注意力进行对齐。本文问题与该通用流程的关键差异在于：传统硬投影在数学上不可微且支持集稀疏，导致视觉特征无法作为有效的Key/Value被几何Query检索，从而阻断了真正的跨模态信息流动。

### 可微高斯泼溅密度估计

硬投影的失效源于Dirac delta函数的导数几乎处处为零，导致 $\nabla_p L \to 0$。为打破这一僵局，SplAttN将投影重构为基于高斯核的连续密度估计。对于任意空间查询点 $\mathbf{q}$，聚合特征 $V(\mathbf{q})$ 定义为投影基元的加权期望：

$$ V(\mathbf{q}) = \frac{\sum_{k \in N(\mathbf{q})} w_k(\mathbf{q}) f_k}{\sum_{k \in N(\mathbf{q})} w_k(\mathbf{q})} $$

其中权重 $w_k(\mathbf{q})$ 由高斯空间核与深度先验乘积构成。这一设计动机在于，高斯核的平滑尾部确保了即使点存在轻微错位，梯度 $\nabla_{\mathbf{u}} L$ 也不为零，从而恢复了视觉流对几何流的监督能力。相比硬投影的离散稀疏支持，该机制严格扩展了有效信息支持集 $S_{soft}$，保证了非退化概率场的存在。

### 主动跨模态对齐与混合编码

在获得连续密度场 $V$ 后，SplAttN采用主动注意力机制实现跨模态对齐。几何特征 $\mathbf{F}_{geo}$ 作为Query，视觉密度场 $V$ 作为Key和Value，通过交叉注意力动态检索视觉上下文。这一设计解决了被动拼接中视觉信息利用率低的问题，使几何流能主动查询密集视觉先验。同时，几何分支采用混合架构：EdgeConv捕捉局部曲率（局部等距），Transformer捕捉全局拓扑（全局同胚）。这种协同设计确保了在恢复精细细节（如椅子腿）时，既保留局部几何一致性，又维持全局结构完整性，避免了单一局部算子在全局拓扑不变量上的失效。

## 实验评估

| 方法 | PCN CD (×10⁻³) | PCN F1 | ShapeNet-55 CD-Avg (×10⁻³) | ShapeNet-55 F1 |
| :--- | :--- | :--- | :--- | :--- |
| SVDFormer | 6.42 | 0.853 | 0.77 | - |
| GeoFormer | 6.54 | 0.841 | - | - |
| **SplAttN** | **6.36** | **0.854** | **0.77** | **0.520** |

SplAttN在PCN数据集上取得6.36的平均CD值，优于SVDFormer（6.42）和GeoFormer（6.54），F1分数达到0.854。在ShapeNet-55上，其平均CD为0.77，F1为0.520，在数据丰富的头部类别（如Plane，CD 0.33）和尾部类别（如Birdhouse，CD 1.29）均表现稳健。值得注意的是，ShapeNet-55的CD数值量级（~0.77）与领域综述中其他方法（如CasPoinTr的11.99）存在巨大差异，这源于本文采用mean class aggregation且缩放因子定义不同，直接数值对比需谨慎，但相对排名显示其在多模态融合路线中处于领先地位。

| 投影策略 | 架构 | CD (×10⁻³) | F1 |
| :--- | :--- | :--- | :--- |
| Hard (Depth) | Conv | 6.59 | 0.846 |
| Hard (CCM) | Conv | 6.43 | 0.853 |
| Splatting (Ours) | Hybrid | 6.36 | 0.854 |

消融实验表明，可微高斯泼溅相比硬投影（Depth/CCM）带来0.07-0.23的CD降低，验证了连续密度估计对梯度流的改善。混合架构（Hybrid）相比纯卷积架构（Conv）进一步降低CD，证实了全局注意力在拓扑推理中的必要性。视觉编码器分析显示，TinyViT-5M配合IN-22k预训练权重效果最佳（CD 6.36），而扩大至21M参数反而导致性能下降（CD 6.42），暗示在PCN数据集上存在过拟合高频噪声的风险。

评估边界方面，本文在KITTI上进行了反事实评估，通过移除视觉输入观察Semantic Consistency Score（SCS）的变化。SplAttN在移除视觉后SCS下降26.1%，而SVDFormer仅变化+0.4%，GeoFormer甚至上升20.9%。这一结果有力证明了SplAttN建立了真实的跨模态依赖，而基线方法退化为单模态模板检索器。然而，论文未报告计算效率（MACs、延迟）的详细对比，且ShapeNet-55的评估协议与主流基准存在差异，限制了跨论文的直接可比性。代码已开源，但超参数（如高斯带宽σ=4）的敏感性分析未充分展开。

## 关联研究分析

从问题动机看，SplAttN与SVDFormer和GeoFormer同属多模态融合路线，但核心差异在于对“连接”机制的理论化处理。SVDFormer和GeoFormer依赖硬投影查询视觉特征，这在合成数据上有效，但在真实数据分布偏移下，硬投影的稀疏性导致视觉信息被噪声淹没，模型转而依赖3D先验。SplAttN通过可微高斯泼溅将投影转化为密度估计，从数学上保证了梯度非零，使得视觉信息能真正参与几何优化。这一差异的根源在于任务特性：真实LiDAR数据的射线状稀疏性（Ray-like sparsity）加剧了硬投影的失效，而软投影的平滑特性恰好抵消了这种分布不规律性。

从方法设计看，SplAttN与3D Gaussian Splatting（3DGS）共享技术源头，但应用目标截然不同。3DGS用于新视角合成，关注渲染保真度；SplAttN用于特征对齐，关注跨模态信息传递。SplAttN将3DGS中的高斯基元从渲染像素映射重构为特征密度估计，这一迁移并非简单套用，而是针对点云补全中“离散-连续”模态鸿沟的特定设计。与DiffPCN等生成式方法相比，SplAttN采用回归框架，避免了迭代去噪的高延迟，但牺牲了生成式模型在极端遮挡下的多样性。查询侧增强在数据充足时是否仍有增益，论文未给出回答，这可能限制了其在大规模数据集上的扩展性。

## 总结

本文要解决的核心矛盾是多模态点云补全中视觉先验因硬投影导致的梯度消失与模态解耦。现有方法如SVDFormer虽引入2D信息，但硬投影的离散性切断了可学习连接，导致模型在真实场景中退化为单模态检索。SplAttN抓住这一理论盲区，通过可微高斯泼溅将投影重构为连续密度估计，恢复了视觉流对几何流的梯度监督。实验证明，该方法在PCN上取得6.36的CD值，并在KITTI反事实评估中展现出对视觉线索的强依赖（SCS下降26.1%），验证了跨模态连接的有效性。然而，其边界在于ShapeNet-55评估协议的特殊性导致跨论文对比困难，且高斯带宽等超参数对真实数据分布的适应性未充分探索。当输入点云密度极低或存在严重运动模糊时，高斯核的平滑效应是否会过度抑制局部几何细节，论文未给出回答。
