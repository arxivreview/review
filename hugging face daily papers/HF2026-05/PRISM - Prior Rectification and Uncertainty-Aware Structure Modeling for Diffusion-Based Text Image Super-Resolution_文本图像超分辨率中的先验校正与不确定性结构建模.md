研究机构：上海交通大学

作者：Zihang Xu、Xiaoyang Liu、Zheng Chen 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.13027)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.13027)

> 文本图像超分辨率（Text-SR）旨在从退化低分辨率输入恢复高分辨率文本，其核心挑战在于笔画拓扑的微小错误会直接改变字符身份，导致语义失效。现有方法依赖从低质图像直接提取的文本条件，在严重退化下这些条件本身不可靠，且全局先验无法确定局部笔画边界。PRISM 通过流匹配先验校正（FMPR）与不确定性感知结构编码（SURE）解耦全局语义恢复与局部几何细化，实现单步推理下的字符级保真。该框架在真实世界基准上取得最优 OCR 准确率与 FID，但合成数据占比高可能限制对复杂真实背景的泛化能力。

## 研究背景

文本图像超分辨率不同于通用图像超分辨率，后者仅追求视觉真实感，而前者要求恢复的图像必须保持字符身份的可读性。这种敏感性源于文本的符号属性：自然纹理中的伪影仅影响感知质量，但笔画断裂或封闭结构扭曲会直接改变字符含义，尤其在中文等密集结构脚本中，细微的笔画布局差异即可区分不同字符。因此，有效的 Text-SR 系统必须同时恢复视觉细节与语义忠实的字形结构，达到亚字符精度的控制。

现有 Text-SR 方法通过引入更强的文本特定引导来应对这一结构敏感问题。早期方法利用识别监督、序列建模和布局感知推理提升可读性，但在严重退化移除笔画证据时，这些线索变得不可靠。后续方法引入生成式字符结构先验和文本风格嵌入以处理复杂字形，近期基于扩散模型的方法进一步利用生成先验、文本扩散或分割引导提升感知真实感。然而，这些方法普遍存在两个未解决的瓶颈：从低质输入直接推断的文本条件在严重退化下本身不可靠，且即使获得合理的全局语义条件，也无法完全确定像素对齐的局部笔画边界。PRISM 的切入点在于将恢复过程显式分解为全局先验校正与局部结构细化，解决条件估计与图像重建在共享目标下的纠缠问题。

## 核心方法

### 方法参照系

基于预训练潜空间扩散模型的单步超分辨率框架通常直接以低分辨率潜变量作为条件输入，通过单次去噪步骤生成高分辨率输出。该通用流程假设条件输入是可靠且充分的，但 Text-SR 任务中，严重退化导致直接提取的文本条件充满噪声，且缺乏对局部笔画不确定性的显式建模，导致模型在纠正笔画几何与补偿错误条件之间无法区分，产生锐利但语义错误的输出。

### 流匹配先验校正（FMPR）

FMPR 解决了直接回归或扩散式先验提取在严重退化下路径冗余且目标拟合不足的问题。传统方法从纯噪声出发或静态处理推断先验，导致生成路径复杂且难以学习严格的字符结构。FMPR 构建训练时的特权先验空间，通过配对低质/高质潜变量定义目标分布，并学习从观测先验到特权先验的速度场。具体地，定义直线插值路径 $c(t) = (1-t)c_l + tc_{\star}$，学习速度场 $V_{FM}(c(t), t) = c_{\star} - c_l$，并通过 $K$ 步欧拉积分从 $c_l$ 恢复先验 $\hat{c}$。这一设计避免了从纯噪声出发的冗余路径，直接校正不可靠信息，同时保留退化条件，实现了字符级保真与感知质量的最优平衡。

### 不确定性感知结构编码（SURE）

SURE 解决了全局先验无法确定局部笔画边界且低质边缘作为确定性约束会放大退化伪影的问题。传统方法将低质边缘视为确定真理，但在严重退化下，可见边缘往往缺失或误导，过度自信的错误边缘比缺失边缘更具危害性。SURE 预测结构特征的均值 $\mu$ 和对数方差 $\log \sigma^2$，通过重参数化采样 $z_s = \mu + \sigma \odot \epsilon$ 生成随机结构线索。该不确定性感知设计允许模型选择性地吸收可靠边界，同时抑制模糊线索，通过 KL 散度正则化防止方差坍缩，确保结构分支学习有意义的笔画级细化而非任意特征扰动。

## 实验评估

实验在自建 BTL 数据集（100K 双语文本行）和 RealCE-val（1,037 对真实世界文本）上进行，对比 TSRN、MARCONet、DiffTSR、TeReDiff 等代表性方法。基线覆盖了识别引导、生成式结构先验和扩散模型路线，但缺失通用 SR SOTA（如 Real-ESRGAN）的直接对比，鉴于 Text-SR 任务特性，这一缺失合理。

| 方法 | BTL-test ×4 PSNR (dB) | BTL-test ×4 LPIPS | BTL-test ×4 FID | RealCE-val ×4 ACC (%) | RealCE-val ×4 FID |
|---|---|---|---|---|---|
| PRISM | 19.89 | 0.2043 | 47.83 | 65.19 | 47.83 |
| DiffTSR | - | - | - | 60.62 | 74.52 |
| TeReDiff | - | - | - | - | - |

PRISM 在 BTL-test 和 RealCE-val 的 ×4 设置下取得最优 LPIPS、FID 和 NED，RealCE-val ×4 下 ACC 达 65.19%，较次优方法提升 4.57 个百分点，FID 从 74.52 降至 47.83，表明其在严重真实退化下显著提升了字符可读性与生成质量。

| 消融组件 | RealCE-val ×4 PSNR (dB) | RealCE-val ×4 ACC (%) | RealCE-val ×4 FID |
|---|---|---|---|
| Base model | 19.81 | 62.39 | 53.42 |
| FMPR only | 19.83 | 64.61 | 47.54 |
| Full model (FMPR+SURE) | 19.89 | 65.19 | 47.83 |

消融实验显示，FMPR 单独使用即可将 ACC 从 62.39% 提升至 64.61%，验证了先验校正对全局语义稳定的贡献；加入 SURE 后 ACC 进一步提升至 65.19%，FID 略有上升，表明不确定性结构编码在提升字符保真度的同时，对感知质量的影响较小。FMPR 欧拉步数 $K=16$ 在性能与效率间取得平衡，$K=32$ 仅带来轻微提升但计算成本翻倍。

评估指标涵盖 PSNR、LPIPS、FID、ACC 和 NED，全面覆盖失真、感知、分布真实感和文本保真度。评估协议局限在于 BTL 数据集包含 50K 合成图像，可能引入对真实复杂背景的泛化偏差。可复现性方面，论文提供代码链接，使用 Stable Diffusion 2.1-base 骨干，LoRA 秩 16，在两块 NVIDIA RTX A6000 GPU 上训练，超参数详细披露。

## 关联研究分析

从问题动机看，PRISM 与 DiffTSR 均针对严重退化下的 Text-SR，但 DiffTSR 耦合图像与文本扩散，依赖迭代采样，而 PRISM 通过单步推理和先验校正实现毫秒级推理。这一差异源于任务特性：Text-SR 对字符身份的敏感性要求条件输入的可靠性，而非生成多样性，因此单步推理在保持保真度的同时大幅提升了效率。PRISM 的 FMPR 模块通过流匹配直接校正先验，避免了 DiffTSR 中条件估计与重建的纠缠，解决了严重退化下条件不可靠的核心问题。

从方法设计看，PRISM 与 OSEDiff 共享单步推理框架，但 OSEDiff 面向通用自然图像恢复，缺乏对字符结构和笔画拓扑的专用建模。PRISM 引入 SURE 模块，通过不确定性感知结构编码显式处理局部笔画边界，这是通用 SR 方法所缺失的。这一差异揭示了通用 SR 的幻觉抑制机制无法直接迁移至 Text-SR 的笔画断裂问题，因为文本的符号属性要求亚字符精度的结构控制，而非仅视觉真实感。PRISM 的 SURE 模块通过预测结构特征的均值与方差，实现了对可靠边界的吸收和模糊线索的抑制，解决了通用方法中过度自信错误边缘的危害。

## 总结

PRISM 解决了 Text-SR 中严重退化下文本先验不可靠与局部笔画边界不确定的核心矛盾。现有方法因条件估计与重建纠缠，无法区分纠正笔画几何与补偿错误条件，导致语义错误输出。PRISM 通过 FMPR 流匹配先验校正稳定全局字符身份，通过 SURE 不确定性结构编码细化局部笔画几何，在单步推理下实现字符级保真。实验证明其在 RealCE-val ×4 下 ACC 达 65.19%，FID 47.83，显著优于迭代扩散方法。然而，BTL 数据集中 50% 的合成图像占比，以及 FMPR 16 步欧拉积分的计算开销，限制了其在极端真实场景下的泛化能力与极致效率。当支持集增大到真实复杂背景时，合成数据引入的分布偏差是否会导致字符识别准确率下降，论文未给出回答。
