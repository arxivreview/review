# HuggingFace最新推荐论文 ｜RaguTeam at SemEval-2026 Task 8: Meno and Friends in a Judge-Orchestrated LLM Ensemble for Faithful Multi-Turn Response Generation ｜多轮RAG中的裁判式异构集成

论文原文见 [arXiv](https://arxiv.org/abs/2605.04523)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.04523)

> 多轮对话中的检索增强生成（Retrieval-Augmented Generation, RAG）面临指代消解、证据缺失与幻觉抑制的复合挑战，单一模型难以同时兼顾忠实度与完整性。现有方案要么依赖超大参数模型导致成本不可控，要么采用静态提示工程无法适应动态的对话状态。本文切入点在于利用轻量级大语言模型（LLM）作为裁判，对多个异构模型的候选回答进行逐实例筛选。通过七模型并行生成与GPT-4o-mini裁判选择，系统在SemEval-2026 Task B中取得0.7827的条件调和均值，显著优于最强基线。这一结果验证了多样性优于规模性的假设，但其对“空上下文”捷径的依赖及高昂的推理延迟限制了其在实时场景的通用性。

## 研究背景

当RAG系统处理多轮对话时，当前查询往往依赖前文语境，且检索到的文档可能包含无关噪声或完全缺失。这种语境依赖性要求模型不仅理解文本语义，还需具备指代消解与意图追踪能力。然而，LLM内部参数化知识与外部检索证据常发生冲突，模型倾向于依赖内部知识或盲目采信噪声，导致幻觉。为解决此问题，研究界引入了基于忠实度（Faithfulness）的评估机制，即要求生成内容严格由提供的文档支持，任何超出文档范围的陈述均被视为无效。

主流RAG优化路线分为两类：一类是改进检索器以获取更高质量文档，另一类是优化生成器以更好地利用文档。然而，在复杂多轮场景中，单一模型往往存在特定的失效模式，例如大模型在证据不足时倾向于强行回答，而小模型可能在复杂推理上表现不足。SemEval-2026 Task B (MTRAGEval) 正是针对这一痛点，要求系统在给定对话历史和参考段落的情况下，生成最终轮次的忠实回答。本文的切入点并非改进单一模型，而是构建一个异构集成框架，通过引入外部裁判机制，动态选择每个实例下最忠实的候选回答，从而规避单一模型的固有缺陷。

## 核心方法

### 异构候选生成与提示策略

本文方法参照系为标准的LLM集成框架，但关键差异在于引入了基于忠实度的逐实例选择机制，而非简单的投票或平均。系统由七个来自不同家族、不同规模（7B至357B）及不同提示策略的LLM组成。提示策略分为两组：Group 1使用迭代优化的系统提示，强调显式弃权与严格接地；Group 2使用类别感知的少样本（Few-Shot）提示，通过中位数（Medoids）算法从训练集中选取四个代表性示例，覆盖“完整上下文”、“空上下文”和“空历史”三种结构。这种设计动机在于，抽象指令难以让模型理解边缘情况（如不可回答问题）的具体行为，而具体的行为示范能更有效地引导模型在证据缺失时进行弃权。

### 基于忠实度的裁判选择机制

在候选生成阶段，每个实例产生七个候选回答。随后，GPT-4o-mini作为裁判，对每个候选回答进行忠实度评分。忠实度定义为回答中的所有声明是否均由提供的参考段落支持，评分范围为0到1。最终选择得分最高的候选回答作为系统输出。该机制的核心公式可表示为：

$$
y^* = \arg\max_{y_i \in \{y_1, ..., y_7\}} S_{judge}(y_i, D_{ref}, C_{hist})
$$

其中 $y^*$ 为最终输出，$S_{judge}$ 为GPT-4o-mini计算的忠实度分数，$D_{ref}$ 为参考段落，$C_{hist}$ 为对话历史。这一设计解决了单一模型在特定查询类型下失效的问题，例如在部分可回答（Partially Answerable）实例中，小模型Claude 4.5 Haiku因更保守的措辞而获得更高忠实度，从而被裁判选中，弥补了大模型在此类场景下的不足。

## 实验评估

实验在MTRAGEval Task B上进行，该数据集包含507个实例，分为可回答、不可回答、欠定和部分可回答四类。基线包括gpt-oss-120b等单一模型。本文系统以0.7827的条件调和均值（HM3）排名第一，比最强基线0.6390高出14.4个百分点。

| 系统 | HM3 (cond.) |
| :--- | :--- |
| 本文集成 (1st place) | 0.7827 |
| 基线: gpt-oss-120b | 0.6390 |
| 最佳单模型: GLM-4.6 | 0.748 |

消融实验揭示了关键设计决策的影响。首先，裁判选择显著优于随机选择，在可回答实例上提升2.5个百分点，证明忠实度评估的有效性。其次，少样本提示在欠定实例上比系统提示提升3.7个百分点，表明具体行为示范优于抽象指令。然而，集成在欠定实例上（0.367）略低于最佳单模型GLM-4.6（0.381），这是因为裁判偶尔选择了自信但非澄清性的回答，而GLM-4.6更一致地产生澄清请求。此外，Meno-Lite-0.1（7B模型）虽仅被选中2次，但在其被选中的实例上达到了0.707的HM3，展示了小模型在特定利基场景下的互补价值。

评估边界方面，本文使用GPT-4o-mini作为单一裁判，其与组织者多裁判分数高度相关（Spearman $\rho$=0.95），但可能存在对长回答的偏好。代码已开源，但依赖专有API，限制了完全可复现性。

## 关联研究分析

从问题动机看，本文与LLM-Blender（Jiang et al., 2023）同属LLM集成路线，但LLM-Blender侧重于通用QA中的答案融合，而本文针对多轮RAG的忠实度约束。差异根源在于任务特性：多轮RAG要求严格接地，因此本文采用基于忠实度的二选一/多选一筛选，而非LLM-Blender的生成式融合。这种选择牺牲了答案的流畅性，但提升了事实准确性。

从方法设计看，本文与MVP（Multi-view-guided Passage Reranking）等高效重排方法形成对比。MVP旨在通过架构优化降低推理延迟，而本文采用多模型并行生成加裁判的高延迟策略。冲突在于：本文追求极致的效用（忠实度），而MVP追求效率。在实时性要求高的场景下，本文的七模型并行加裁判流程可能因延迟过高而不可行，这暗示了效用与效率之间的权衡边界。

## 总结

本文核心矛盾在于单一LLM在多轮RAG中无法同时满足高忠实度与低幻觉率。切入点在于利用异构模型的互补失效模式，通过轻量级裁判进行逐实例筛选。方法上，构建了七模型集成与GPT-4o-mini裁判选择机制，证明了多样性优于规模性（0.7827 vs 0.748）。边界在于系统对“空上下文”捷径的依赖（97个不可回答实例均有空参考段落），以及高昂的推理成本。当去除空上下文捷径，引入干扰段落时，该集成框架的忠实度优势是否仍能保持，论文未给出回答。
