> 空间可控图像生成旨在弥合文本语义与像素空间之间的接地鸿沟，其核心价值在于满足设计、游戏资产制作等对物体位置、姿态及布局有严格要求的应用需求。现有代理式生成系统虽引入了搜索与推理，但内部信息流仍依赖自然语言，导致在绝对坐标、精确数量及层叠关系上存在严重歧义，最终沦为高级提示词优化器。GenClaw 提出代码驱动范式，将 LLM 的代码生成能力作为“数字画笔”，通过 SVG/HTML 等可执行中间表示解耦认知、草图与渲染。该范式在文本渲染与复杂构图上展现了透明可控的优势，但在标准空间控制基准上的量化精度及底层模型依赖度仍存疑。

## 研究背景

当生成模型面对“在左侧放置三把椅子”这类指令时，自然语言无法提供像素级的坐标约束，导致物体位置随机漂移。这种语义与空间的错位源于文本嵌入的粗粒度特性，而传统扩散模型缺乏显式的空间逻辑推理能力。为解决此问题，ControlNet 等结构注入范式通过辅助网络引入边界框或深度图，实现了细粒度控制，但这类方法依赖预训练权重修改，难以灵活适配动态变化的复杂场景。

领域主流路线分为结构注入与智能推理两类。结构注入方法如 InstanceAssemble 利用多模态扩散 Transformer (MMDiT) 处理密集布局，但受限于训练数据的静态分布，面对开放式语义组合时泛化性不足。智能推理路线如 Mind-Brush 引入搜索工具，但仅优化文本提示，未触及视觉结构的本质。GenClaw 的切入点在于识别出 LLM 在代码生成上的原生优势，认为代码比自然语言更适合表达空间逻辑，从而将图像生成重构为“概念化-草图-上色”的分阶段流程。

## 核心方法

### 方法参照系

本文问题属于交互式可控生成，但偏离了 ControlNet 等直接特征注入的标准流程。关键差异在于：GenClaw 不修改生成模型权重，而是将 LLM 生成的代码渲染为图像或掩码，作为外部条件输入，实现了推理时的动态控制。

### 认知结构化与意图解析

设计动机在于解决现有代理在复杂指令下意图解析模糊的问题。该层利用 VLM/LLM 作为认知核心，通过搜索与推理工具补全世界知识，将用户意图转化为结构化记录。这一过程将原本由生成模型承担的语义理解任务前置，确保后续草图构建基于准确的事实与逻辑。

$$
S_{struct} = \text{LLM}(I_{user}, K_{search}, R_{reason})
$$

其中 $S_{struct}$ 为结构化记录，$I_{user}$ 为用户意图，$K_{search}$ 为检索知识，$R_{reason}$ 为推理链。该公式表明，结构化输出是意图、知识与推理的联合函数，而非单纯的文本映射。

### 可执行画布构建

设计动机在于克服自然语言在空间表达上的歧义。该层将 $S_{struct}$ 转化为 SVG、HTML 或 Three.js 代码，作为“数字画笔”在画布上构建物体、文本与层级。代码的显式结构（如坐标、z-order）使得空间关系可验证、可编辑，从根本上避免了注意力机制导致的属性泄漏。

$$
C_{canvas} = \text{CodeGen}(S_{struct}, \mathcal{V}_{layout})
$$

其中 $C_{canvas}$ 为可执行画布，$\mathcal{V}_{layout}$ 为布局约束（坐标、尺寸、层级）。该公式体现了从语义结构到视觉结构的确定性映射，代码即布局。

### 视觉生成与审查

设计动机在于弥补代码在纹理与真实感上的表达瓶颈。该层调用现成图像生成模型（如 Qwen-Image），以 $C_{canvas}$ 渲染的图像为条件，补充纹理、材质与光照。随后通过 VLM 自动审查或用户交互进行修正，形成闭环。

$$
x_{final} = \text{Diffusion}(C_{canvas}, c_{global})
$$

其中 $x_{final}$ 为最终图像，$c_{global}$ 为全局风格提示。该公式表明，生成模型仅负责纹理渲染，空间结构由代码预先确定，实现了逻辑与像素的解耦。

## 关联研究分析

从问题动机看，GenClaw 与 ControlNet 路线存在根本差异。ControlNet 通过训练辅助网络注入空间条件，依赖预训练权重的稳定性，适合固定布局任务；而 GenClaw 利用 LLM 的代码生成能力，实现推理时的动态空间规划，适合开放式复杂场景。这种差异源于任务特性：ControlNet 假设空间条件是静态输入，而 GenClaw 假设空间结构需通过逻辑推理动态构建。GenClaw 的局限性在于，其空间精度受限于 LLM 的代码生成质量，而非生成模型的空间感知能力，这在需要极高像素级精度的任务中可能成为瓶颈。

从方法设计看，GenClaw 与 CoCo 同属代码中介路线，但 CoCo 依赖单一统一模型进行代码生成与像素细化，而 GenClaw 解耦了这两者，由 LLM 负责结构，扩散模型负责纹理。这种解耦使得 GenClaw 能更好地利用 LLM 的逻辑推理能力，同时避免单一模型在复杂任务上的能力冲突。然而，GenClaw 未探索代码表示与生成模型内部特征的深度融合，仅将其作为外部条件，这可能限制了模型对代码语义的深层理解。

## 总结

GenClaw 旨在解决现有代理式生成系统在空间控制上的模糊性，其切入点在于利用 LLM 的代码生成能力作为“数字画笔”，将图像生成重构为认知、草图与渲染的分阶段流程。该方法通过 SVG/HTML 等可执行中间表示，实现了空间结构的显式控制与可验证性。实验表明，GenClaw 在长文本渲染与复杂构图上优于 FLUX 2 Pro 等基线，但在标准空间控制基准上缺乏量化验证。其边界在于高度依赖底层生成模型的泛化能力，且未探索代码与生成模型内部特征的深度融合。当底层生成模型无法准确将抽象代码草图转化为真实感图像时，该范式的可控性优势是否仍能保持，论文未给出回答。
