# HuggingFace最新推荐论文 ｜Delta Attention Residuals ｜跨层路由中的源冗余与Delta注意力残差

论文原文见 [arXiv](https://arxiv.org/abs/2605.18855)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.18855)

> 深层Transformer中，标准残差连接以固定系数累积所有前序层输出，缺乏对历史信息的选择性聚合能力。Attention Residuals（AttnRes）通过引入软注意路由解决此问题，但其路由源为累积隐藏状态，随深度增加导致相邻状态高度冗余，引发深层“路由坍缩”——注意力权重趋于均匀分布，最大权重降至0.2，丧失选择性。本文指出，路由源应聚焦于各子层引入的“变化量”（Delta），而非累积状态，并采用加性路由公式保留残差流。这一设计在220M至7.6B参数规模上验证了有效性，但其在超长序列或复杂推理任务中的泛化边界尚不明确。

## 研究背景

Transformer的深层训练依赖残差连接提供梯度高速公路，但标准更新 $h_l = h_{l-1} + f_l(h_{l-1})$ 仅以固定单位系数累积前序子层输出，无法根据当前层需求选择性聚合历史信息。这种“全量累积”机制导致深层网络中信息传播的盲目性，限制了模型对特定历史表示的精确访问能力。

为打破固定累积的局限，Attention Residuals（Kimi, 2025）提出用学习到的软注意机制替代固定系数，对前序层输出进行加权聚合。然而，AttnRes的路由源仍为累积隐藏状态 $h_i$，其本质是前序所有子层输出的累加和。随着深度增加，相邻累积状态共享越来越长的公共前缀，导致源表示间相似度急剧上升。这种源冗余使得软注意的Logits差异缩小，注意力分布趋于均匀，即“路由坍缩”。在Qwen3-0.6B模型中，深层最大路由权重降至0.2，机制退化为简单平均，丧失了选择性路由的核心价值。本文切入点在于识别这一被忽略的源冗余问题，并提出基于Delta源与加性路由的新范式。

## 核心方法

### 方法参照系

本文问题属于Transformer深度信息路由优化，与序列维度的位置编码（PE）正交。标准流程为：前向传播中，当前层通过某种机制聚合前序层信息并更新隐藏状态。本文的关键差异在于，将聚合对象从“累积状态”改为“子层增量”，并将聚合方式从“替换式”改为“加性”，以解决源冗余导致的注意力坍缩。

### Delta源表示

AttnRes使用累积状态 $s_i = h_i$ 作为路由源，其定义为 $h_i = h_0 + \sum_{j=1}^i v_j$。由于 $h_i$ 包含大量前序公共信息，相邻 $h_i$ 与 $h_{i+1}$ 的内积近似相等，导致软注意Logits $\mathbf{w}^\top \text{RMSNorm}(h_i) \approx \mathbf{w}^\top \text{RMSNorm}(h_{i+1})$，注意力分布均匀化。本文提出使用Delta源 $s_i = v_i = h_{i+1} - h_i$，即子层 $i$ 引入的纯变化量。Delta源在结构上具有多样性：注意力层与MLP层输出占据不同子空间，不同深度的Delta捕获不同抽象层级，避免了累积状态的线性收敛问题。这一设计动机直接针对AttnRes深层路由权重降至0.2的失效模式，通过提升源间对比度恢复路由选择性。

### 加性路由机制

AttnRes采用替换式路由 $h_l = \sum_{i} \alpha_i s_i$，需周期性重置残差流以避免信息丢失，但重置操作在深层加剧信息损失。本文提出加性路由公式：

$$ h_l = \tilde{h}_l + \sum_{i} \alpha_i v_i $$

其中 $\tilde{h}_l$ 为当前残差流，$\alpha_i = \text{softmax}(\mathbf{w}_l^\top \text{RMSNorm}(v_i))$ 为基于Delta源的软注意权重。该公式的物理含义是：在保留原始残差流的基础上，叠加从历史Delta源中路由来的选择性信息。加性设计带来三重优势：1）残差流始终保留，避免替换式的信息丢失；2）无需重置操作，消除深层信息损失；3）初始化时 $\mathbf{w}_l=0$ 导致 $\alpha_i$ 均匀，路由输出为有界扰动，实现预训练模型微调时的零初始化扰动。这一机制解决了AttnRes在微调预训练模型时因初始化不匹配导致的损失尖峰问题。

## 实验评估

实验在FineWeb-Edu数据集上训练Qwen3架构模型，规模覆盖220M至7.6B参数。基线包括标准残差（Baseline）、AttnRes、Full AttnRes。缺失强基线如Highway Networks或动态路由变体，但覆盖了主要竞争路线。

| 规模 | 方法 | Val PPL ↓ | Tok/s ↑ | Mem (GB) |
| :--- | :--- | :--- | :--- | :--- |
| 220M | Baseline | 38.71 | 289k | 5.6 |
| 220M | AttnRes | 37.39 | 294k | 6.2 |
| 220M | Delta Block | 37.08 | 306k | 5.9 |
| 1044M | Baseline | 29.70 | 108k | 22.5 |
| 1044M | AttnRes | 31.76 | 71k | 31.6 |
| 1044M | Delta Block | 29.19 | 86k | 28.4 |
| 7.57B | Baseline | 17.43 | 21.4k | 41.6 |
| 7.57B | AttnRes | 18.58 | 12.5k | 44.0 |
| 7.57B | Delta Block | 16.00 | 14.0k | 42.7 |

Delta Block在1044M和7.57B规模上显著优于Baseline，而AttnRes在1044M时PPL恶化至31.76（+6.9%），在7.57B时恶化至18.58（+6.6%），证实替换式路由在深层的失效。Delta Block在7.57B上PPL 16.00，较Baseline降低8.2%，且吞吐量（14.0k tok/s）高于AttnRes（12.5k tok/s），内存占用（42.7 GB）低于AttnRes（44.0 GB）。

消融实验显示，Delta Block在220M规模下，块大小 $B=4$ 时PPL 36.98，优于 $B=1$（37.44）和 $B=12$（37.34），存在最优块大小。在533M规模下，PPL在 $B=2$ 至 $B=24$ 间稳定在31.18–31.27，表明大模型对块大小不敏感。微调实验中，Delta Block在Qwen3-0.6B上平均准确率55.6%，优于Baseline（55.0%）和AttnRes（54.1%），且无初始化损失尖峰。

评估边界：实验仅覆盖语言建模PPL和8个下游基准，未测试长上下文推理或复杂多跳任务。可复现性方面，代码已开源，但AttnRes为忠实重实现，非官方代码。8B模型仅训练10K步，收敛性存疑。

## 关联研究分析

从问题动机看，本文与位置编码（PE）研究正交，但共享“选择性信息聚合”的核心思想。PE解决序列维度的顺序依赖，DAR解决深度维度的历史依赖。PE中的RoPE通过旋转矩阵编码相对位置，而DAR通过Delta源编码层间变化。二者均面临“源冗余”问题：RoPE在长序列中因频率振荡导致位置混淆，DAR在深层因累积状态冗余导致路由坍缩。DAR的Delta源设计类似RoPE的相对位置思想，但作用于深度维度，且通过加性路由避免替换式的信息丢失。

从方法设计看，DAR与LoRA（Hu et al., 2022）在微调策略上相似，均采用低秩或轻量模块保护预训练权重。但DAR的加性路由是架构级修改，而LoRA是参数级修改。DAR的零初始化扰动特性使其更适合架构改造，而LoRA更适合参数微调。DAR未探索与PE的交互作用，如Delta源是否受位置编码影响，或加性路由是否加剧位置偏差。

## 总结

本文核心矛盾是深层Transformer中累积状态冗余导致的路由坍缩，现有AttnRes因源表示不当而失效。本文抓住“变化量比累积量更具信息量”的切入点，提出Delta源与加性路由，在220M至7.6B规模上验证了有效性，7.57B模型PPL降低8.2%。边界在于实验仅覆盖语言建模，未测试复杂推理任务，且8B模型训练步数有限。当模型规模进一步扩大或任务复杂度提升时，Delta源的结构多样性是否足以替代累积状态的全局信息，论文未给出回答。
