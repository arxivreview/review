> 3D生成模型虽能构建高保真场景，但输出往往是物体与背景融合不可分的单体资产，导致无法进行对象级编辑或物理交互。现有方法多聚焦于从零生成独立物体并布局，缺乏对已生成单体场景的后处理解耦能力。WorldAct通过智能体引导的分割、背景修复与物体重建，将静态3D高斯泼溅（3DGS）场景转化为可交互环境。该框架验证了单体场景分解的可行性，但其依赖特定基础模型且仅支持静态刚体，泛化边界尚待考察。

## 研究背景

3D高斯泼溅（3DGS）以显式高斯原语集合表示场景，每个原语包含位置、协方差、不透明度与颜色，通过可微分alpha混合实现实时渲染。然而，标准3D世界模型（如Marble）生成的3DGS场景是“单体”的，即所有物体的高斯原语与背景高斯原语在空间上重叠且语义上纠缠，缺乏原语到实体的显式映射。这种表示虽视觉真实，但无法单独选取、移动或替换特定物体，阻碍了具身智能中的抓取操作与创意工作流中的局部编辑。

当前3D场景生成领域存在两条主要路线：一是组合式生成，独立生成物体资产后通过布局模型放置，虽具备对象级可控性，但受限于有限视角输入或预定义资产库，难以生成大规模多视图一致环境；二是端到端单体生成，直接输出完整场景，视觉质量高但缺乏结构。WorldAct的切入点在于后者，它不改变生成范式，而是针对已生成的单体3DGS场景，通过智能体驱动的后处理流水线，实现从“视觉资产”到“交互环境”的转化，填补了单体生成与对象级交互之间的空白。

## 核心方法

### 方法参照系

本文问题可置于“场景分解与修复”类别下。标准流程通常包括：2D分割、3D投影、背景补全与物体重建。关键差异在于，本文输入是单体3DGS场景而非多视图图像，且需同时解决物体提取、背景空洞修复与物理碰撞几何构建三个耦合问题，而非仅关注视觉重建。

### 智能体引导的物体发现与3DGS软分配

传统方法依赖人工标注或固定提示进行分割，难以自动识别场景中所有可交互物体并选择最佳视角。WorldAct引入视觉语言智能体（如Qwen3.6-Plus）分析关键帧，生成物体提示列表 $P = \{p_1, \dots, p_N\}$ 并筛选语义无关物体。随后，利用SAM3对每帧进行提示分割，获得多视图掩码序列。针对3DGS原语与物体的归属问题，本文采用可学习软分配分数 $s_{i,m} \in [0,1]$ 表示高斯 $g_i$ 属于物体 $o_m$ 的概率。通过掩码逆渲染优化，最小化投影损失：

$$ \mathcal{L}_{proj} = \sum_{t \in V_m} \left( \| \hat{\mathbf{M}}_{t,m} - \mathbf{M}_{t,m} \|_1 + \lambda \| (1-\hat{\mathbf{M}}_{t,m}) \odot \mathbf{M}_{t,m} \|_1 \right) $$

其中 $\hat{\mathbf{M}}_{t,m}$ 为渲染的软掩码，第一项鼓励前景一致性，第二项抑制背景误报。此设计解决了固定阈值分割在遮挡区域产生的噪声问题，实现了鲁棒的物体-背景高斯分离。

### 背景修复与两阶段物体姿态对齐

移除物体高斯后，背景出现空洞。WorldAct首先通过高斯重投影融合多视图掩码，利用DiffuEraser对视频帧进行修复，再通过DepthLab估计深度并初始化新高斯，优化匹配修复帧，得到完整背景 $G_{bg}^{comp}$。同时，构建低多边形碰撞代理 $M_{bg}$ 以支持物理交互。对于物体资产，由于提取的高斯不完整，本文调用SAM3D从智能体选定的最佳单视图重建干净物体网格 $M_m^{gen}$。由于SAM3D预测姿态不准，本文采用两阶段对齐：第一阶段，以提取高斯为锚点，通过ICP与DINOv2特征相似度筛选初始姿态；第二阶段，通过可微渲染优化平移 $\mathbf{t}_m$、旋转 $\mathbf{r}_m$ 与尺度 $s_m$，最小化包含掩码一致性、接触合理性与穿透惩罚的损失函数：

$$ \mathcal{L}_{align} = \mathcal{L}_{mask} + \lambda_c \mathcal{L}_{contact} + \lambda_p \mathcal{L}_{penetration} $$

该机制确保了重建物体在修复背景中的几何对齐与物理合理性，解决了直接放置导致的悬浮或穿透问题。

## 实验评估

实验在基于Marble生成的6个室内场景（MWM数据集）上进行，使用单张NVIDIA RTX 3090 GPU，单场景转换耗时约1小时。基线仅包含“无智能体”消融与Gaussian Grouping，缺乏与SceneWeaver、NaLA等同类智能体方法的直接对比，限制了跨方法性能比较。

| 指标 | MWM (%) | MWM-easy (%) | MWM-hard (%) |
| :--- | :--- | :--- | :--- |
| Ours w/o Agent | 23.77 | 25.40 | 20.49 |
| Ours | 78.80 | 83.98 | 68.43 |

| 阶段 | ReMOVE↑ | MANIQA↑ |
| :--- | :--- | :--- |
| Original 3DGS | 0.7933 | 0.3338 |
| After Object Re-insertion (ours) | 0.7934 | 0.3621 |
| After Inpainting (ours) | 0.7951 | 0.3254 |

智能体引导使可交互物体召回率从25.40%提升至83.98%（MWM-easy），证明自动物体发现的有效性。MANIQA分数从0.3338提升至0.3621，表明物体重插入后整体感知质量优于原始场景，且ReMOVE分数保持稳定，说明背景修复未引入显著伪影。

消融实验显示，智能体引导是性能提升的关键，无智能体时召回率骤降。背景修复阶段，本文方法在ReMOVE与MANIQA上均优于Gaussian Grouping基线，验证了基于视频扩散修复与深度初始化高斯策略的有效性。用户研究（MOS）显示，场景级质量与原场景相当（4.13 vs 4.41），但物体级质量显著提升（3.75 vs 2.49），表明分解过程未牺牲全局视觉一致性，反而改善了物体资产的几何保真度。

评估边界方面，MWM数据集为自建且规模较小（6个场景），缺乏跨数据集泛化证据。指标侧重视觉质量与召回率，未量化物理交互的稳定性（如抓取成功率）。代码未公开，超参数细节有限，可复现性受限。

## 关联研究分析

从问题动机看，WorldAct与SceneWeaver同属智能体驱动路线，但SceneWeaver侧重通过工具调用生成新场景，而WorldAct聚焦于对已生成单体场景的后处理分解。这一差异源于任务定义：SceneWeaver解决“从无到有”的生成，WorldAct解决“从有到可交互”的转化。WorldAct的切入点在于利用单体场景的视觉先验，通过分解而非重新生成来保留全局一致性，这在计算成本上可能低于全新生成，但依赖于基础模型的高质量输出。

从方法设计看，WorldAct与SAM3D、DiffuEraser等组件形成上下游关系，但其核心创新在于智能体引导的视角选择与两阶段姿态对齐。与直接生成物体布局的方法（如LaviGen）相比，WorldAct的优势在于无需预定义资产库，能处理任意生成的场景，但劣势在于分解过程可能引入累积误差，且仅支持静态刚体。查询侧增强在数据充足时是否仍有增益，论文未给出回答，这限制了其在复杂动态场景中的适用性。

## 总结

WorldAct旨在解决单体3DGS场景不可编辑、不可交互的核心矛盾，通过智能体引导的分解、修复与重建流水线，将静态视觉资产转化为对象中心交互环境。其核心贡献在于验证了单体场景分解的可行性，智能体引导使物体召回率从25.40%提升至83.98%，且物体级质量显著优于原场景。然而，该框架依赖Marble等特定基础模型，且仅支持静态刚体，未处理铰接物体或动态场景。当场景包含复杂铰接结构时，基于刚体假设的碰撞代理与姿态对齐是否仍能维持物理合理性，论文未给出回答。
