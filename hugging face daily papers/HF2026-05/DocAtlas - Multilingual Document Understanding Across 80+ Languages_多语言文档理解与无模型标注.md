# HuggingFace最新推荐论文 ｜DocAtlas: Multilingual Document Understanding Across 80+ Languages ｜多语言文档理解与无模型标注

研究机构：IBM研究院

作者：Ahmed Heakl、Youssef Mohamed、Abdullah Sohail 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.12623)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.12623)

> 多语言文档理解旨在从页面图像中提取文本、布局及结构化元素，但低资源语言因标注数据稀缺且现有标注管道依赖预训练模型，导致性能严重滞后。现有方案或依赖人工标注无法扩展，或依赖模型标注陷入“英语中心”的循环偏差，而基于渲染的提取方法又存在几何对齐缺失与右至左（RTL）脚本覆盖空白。DocAtlas 通过差分渲染从源文件直接提取无模型依赖的结构标注，并引入 DPO 进行适配，实现了跨语言稳定迁移。该框架在数据构建与适配策略上提供了新范式，但其对复杂视觉推理能力的提升仍受限于基座模型的固有瓶颈。

## 研究背景

当视觉语言模型（VLM）处理非拉丁文字文档时，其性能往往因训练数据中该语言占比极低而大幅衰减。这种衰减不仅源于字符识别错误，更源于布局解析的失效：模型难以在缺乏监督的情况下建立文本内容与空间几何的对应关系，即文档结构对齐（Document Structure Alignment）失败。对齐失败导致表格、公式等结构化元素被错误分割或遗漏，使得端到端解析准确率在低资源语言上出现断崖式下跌。

多语言文档理解的核心矛盾在于标注数据的获取成本与质量循环。人工标注（如 FUNSD）虽高质量但仅覆盖极少量语言；基于预训练模型的自动标注（如 DocBank）存在循环依赖，即模型在英语上训练产生英语偏差，进而训练出更偏向英语的下一代模型，固化了语言不平等。渲染提取方法（如 WordScape）试图绕过学习模型，直接从文档源文件恢复结构，但受限于格式转换导致的渲染漂移（Rendering Drift）以及缺乏对 RTL 脚本的支持，无法提供精确的几何对齐标注。DocAtlas 的切入点在于将渲染过程视为一个封闭形式的标注函数，通过差分渲染消除漂移，并补充合成 RTL 数据，从而打破模型依赖循环。

## 核心方法

### 方法参照系

多语言文档理解的标准流程通常包含数据构建、模型训练与评估。传统数据构建依赖人工或模型标注，而本文将其置于“无模型依赖的数据生成”类别下。关键差异在于，本文不依赖任何学习模型生成核心标注（Ground Truth），而是通过文档源文件的物理渲染特性提取结构，将数据构建从“学习问题”转化为“几何计算问题”。

### 差分渲染标注管道

传统渲染提取方法（如 WordScape）采用单通道着色，无法区分文档原有颜色与注入的标注颜色，且依赖 LibreOffice 等工具导致布局漂移。DocAtlas 采用差分渲染（Differential Rendering），通过像素级减法消除背景干扰。具体而言，系统首先通过 OpenXML 解析文档结构，注入颜色代码生成着色 PDF 与标准 PDF，随后计算两者差值：

$$
\Delta I(x,y) = |I_{colorized}(x,y) - I_{standard}(x,y)|
$$

其中 $I_{colorized}$ 和 $I_{standard}$ 分别为着色与标准渲染的像素强度。该公式的物理含义是：仅保留由注入颜色产生的像素差异，从而精确提取组件边界框（Bounding Box），无需学习检测器。这一设计解决了单通道着色中“假阳性检测”（即误将文档原有彩色元素识别为标注）的问题，确保了标注的几何精度。

### RTL 合成与 DPO 适配

针对 RTL 脚本在 PDF 解析器中的失效问题，DocAtlas 构建了基于 LaTeX 的合成管道。通过自定义 LaTeX 命令在三次编译过程中记录位置元数据，生成 52K 页具有精确标注的 RTL 文档。在模型适配阶段，为缓解灾难性遗忘（Catastrophic Forgetting），本文采用直接偏好优化（Direct Preference Optimization, DPO）。DPO 的损失函数定义为：

$$
\mathcal{L}_{DPO} = -\mathbb{E}_{(x, y_w, y_l)} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)} \right) \right]
$$

其中 $y_w$ 为渲染导出的 Ground Truth（正样本），$y_l$ 为基座模型预测（负样本）。该公式通过偏好高质量标注而非低质量预测，在不显著改变基座模型分布的前提下注入新语言知识。这一设计解决了监督微调（SFT）中因过度拟合新语言数据而导致源语言性能大幅下降（最高达 21%）的问题。

## 实验评估

| 模型 | 参数 | Text Edit (↓) | Table TEDS (↑) | Overall Edit (↓) |
| :--- | :--- | :--- | :--- | :--- |
| DeepseekOCR | 3B | 0.082 | 71.54 | 81.66 |
| DocAtlas-Deepseek | 3B | 0.055 | 72.24 | 83.37 |
| GPT-4o | - | 0.117 | 62.26 | 75.30 |
| Gemini-2.0-Pro | - | 0.090 | 68.50 | 79.75 |

实验在自建 DocAtlas 基准上进行，覆盖 82 种语言和 9 项任务。基线涵盖通用 VLM（GPT-4o, Gemini）和专家 OCR 模型（DeepseekOCR, DotsOCR）。DocAtlas-Deepseek 在 Overall Edit 上达到 83.37%，优于最强基线 DeepseekOCR 的 81.66%，且 Text Edit 距离降至 0.055，表明差分渲染标注显著提升了文本识别精度。

| 方法 | In-Domain (↑) | Out-Domain (↑) | 基座语言退化 |
| :--- | :--- | :--- | :--- |
| Full-Page SFT | +3.9 | -8.2 | -12.1 (TEDS) |
| Component SFT | +4.6 | -17.4 | -21.3 (TEDS) |
| DPO (DocAtlas GT) | +1.9 | +1.8 | < 3% |

消融实验显示，SFT 导致严重的域外性能下降，其中 Component SFT 的域外准确率下降高达 17.4%，验证了孤立元素训练导致表示脆弱。DPO 在域内和域外均实现正增益（+1.9% 和 +1.8%），且基座语言退化小于 3%。值得注意的是，使用 GPT-4o 输出作为 DPO 正信号反而导致域外性能下降 0.7%，证明渲染导出的无偏 Ground Truth 是跨语言迁移的关键，而非 DPO 算法本身。

评估边界方面，DocAtlas 基准虽覆盖语言广泛，但缺乏与现有标准基准（如 OmniDocBench）的直接可比性，因任务定义（如 TEDS 计算方式）存在差异。可复现性上，论文提供了 GitHub 链接，但差分渲染依赖 MS Word 环境，跨平台一致性未充分验证。

## 关联研究分析

从数据构建角度看，DocAtlas 与 WordScape 同属渲染提取路线，但 WordScape 依赖 LibreOffice 转换且缺乏几何对齐，导致标注噪声大；DocAtlas 通过 MS Word 无损渲染和差分减法解决了漂移与对齐问题。这一差异源于任务特性：文档理解对几何精度的要求远高于纯文本 OCR，WordScape 的粗粒度标注无法满足多任务监督需求。

从适配策略看，DocAtlas 采用 DPO 缓解遗忘，与领域内常见的 LoRA 微调形成对比。实验显示 QKV-only LoRA 在保持基座能力上优于全层 LoRA，但 DPO 在域外泛化上表现更优。这暗示在低资源场景下，数据质量（无偏 GT）比参数效率（LoRA）对跨语言迁移的影响更大。然而，DPO 在复杂推理任务（如多步逻辑解析）上的有效性未得到验证，其优势是否仅限于结构化提取任务，论文未给出回答。

## 总结

DocAtlas 旨在解决低资源语言文档理解中标注数据稀缺与模型依赖循环的矛盾。其切入点在于将标注过程从学习问题转化为几何计算问题，通过差分渲染提取无模型依赖的 Ground Truth，并利用 DPO 实现稳定适配。实验证明，该方法在 82 种语言上实现了域内 +1.9% 和域外 +1.8% 的性能提升，且基座语言退化小于 3%。然而，其边界在于结构化提取（如表格 TEDS）仍饱和于 73%，表明视觉空间推理仍是主要瓶颈。当文档包含复杂嵌套表格或非标准布局时，差分渲染的几何精度是否足以支撑深层语义理解，论文未给出回答。
