# HuggingFace最新推荐论文 ｜Agent-ValueBench: A Comprehensive Benchmark for Evaluating Agent Values ｜智能体价值观基准

研究机构：北京大学

作者：Haonan Dong、Qiguan Feng、Kehan Jiang 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.10365)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.10365)

> 智能体评估长期聚焦于任务成功率与安全性，却忽视了驱动这些行为的底层价值取向。现有LLM价值基准无法捕捉智能体在动态交互中表现出的价值偏好，且执行框架（Harness）对价值表现的影响未被量化。本文通过构建首个智能体价值观专用基准，将评估从静态文本转向轨迹级行为审计，并实证了框架与技能层干预对价值排序的调控作用。该工作确立了智能体价值独立性的实证基础，但其单一评判模型在复杂冲突下的稳定性仍存疑。

## 研究背景

当智能体从静态文本生成器演变为具备环境交互能力的自主系统时，其决策不再仅由模型参数决定，而是受到执行框架（Harness）与工具调用轨迹的深刻影响。这种从“模型内部对齐”向“系统行为对齐”的范式转移，使得传统的LLM价值评估失效：LLM在静态上下文中表现出的价值倾向，与智能体在动态环境中通过多步推理和执行反馈所展现的价值偏好存在本质差异。

智能体评估领域已确立轨迹级过程审计的标准，如GAIA和WebArena关注任务完成效率，AgentDojo聚焦安全攻击防御。然而，这些基准均将“价值”视为安全性的下游症状，而非独立的评估维度。主流路线的瓶颈在于缺乏能够解耦模型能力、框架效应与价值取向的评估基础设施，导致无法区分智能体的行为偏差是源于模型缺陷还是框架约束。本文的切入点在于提出“智能体价值观与LLM价值观非同一性”假设，并构建首个专门针对智能体价值冲突的基准，将评估对象从任务结果扩展至价值轨迹。

## 核心方法

### 方法参照系

本文问题归属于智能体评估基础设施构建，但区别于AgentBench等通用能力基准，其核心差异在于评估对象从“任务成功率”转向“价值一致性”。通用流程通常依赖最终状态验证，而本文要求在每个价值冲突任务中，通过可执行环境中的行为轨迹来推断智能体的价值优先级，这要求环境、任务与评分标准必须严格对齐价值心理学理论。

### 环境-任务联合合成

针对数据集层面缺乏可执行价值冲突场景的问题，本文设计了端到端自动化流水线。该流程首先从ToolBench等源语料库中提取环境主题，通过聚类去重生成初始原型，随后由测试智能体与修复智能体迭代验证环境的行为有效性。设计动机在于解决静态文本任务无法提供“价值冲突”这一关键刺激的问题，只有当智能体在可执行环境中面临资源约束或目标冲突时，其价值偏好才会通过行为选择显性化。环境构建遵循状态模式推导、接口设计与程序合成三步，最终由心理学家进行保真度与自一致性审计，确保394个环境覆盖16个领域。

### 轨迹级Rubric评估

针对评估层面从结果导向到行为导向的范式转换，本文引入基于Rubric的轨迹级评判机制。每个任务配备两条分别倾向价值A与价值B的黄金轨迹，其检查点作为行为锚定。设计动机在于解决LLM-as-Judge在复杂价值冲突中易受表面文本干扰的问题，通过行为锚定限制评判仅基于可观测行为匹配。Rubric合成由跨任务元Rubric驱动，遵循动机优先、三元行为视角（注意、解释、执行）及行为锚定评分三原则。

$$
A_{m,\ell,v} = R \cdot \sum_{\kappa \in I_{\ell,v}} w_{\kappa} y_{m,\ell,\kappa}
$$

该公式计算智能体$m$在任务$\ell$中对价值维度$v$的遵循度，其中$w_{\kappa}$为Rubric项权重，$y_{m,\ell,\kappa} \in \{0,1,2\}$为基于行为锚定的评分。Value Priority则通过Bradley-Terry模型拟合成对偏好概率，量化智能体在冲突价值间的相对优先级。

## 实验评估

实验覆盖14个前沿模型与4种主流Harness（ReAct, Codex, Claude Code, OpenClaw），生成超过60,000条轨迹。基线审计显示，本文未直接对比传统LLM价值基准（如ValueBench）的数值，而是通过双格式同题对比定性验证了模态差异。主实验结果揭示了“Value Tide”现象：多数模型在价值遵循度上呈现跨模型同质性，但在优先级排序上存在可解释的反向流。

| 模型 | Harness | MFT08 Authority | MFT08 Care | MFT08 Fairness | MFT08 Loyalty | MFT08 Purity |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Claude Sonnet 4.6 | Vanilla ReAct | 5.0 | 6.2 | 5.9 | 8.1 | 6.1 |
| Claude Sonnet 4.6 | Claude Code | 6.7 | 5.5 | 6.0 | 8.1 | 3.5 |
| GPT-5.4 | Vanilla ReAct | 4.6 | 4.3 | 7.4 | 7.8 | 5.6 |
| GPT-5.4 | Codex | 4.9 | 4.0 | 7.4 | 7.0 | 7.8 |

Harness Pull效应显著：同一模型在不同Harness下价值遵循度差异最大达3.2分（如Claude Sonnet 4.6在Purity维度上，ReAct为6.1，Claude Code为3.5）。消融实验验证了Steering机制的有效性：Skill Steering在平均3.7/5个价值维度上达到目标排序，显著优于Prompt Steering的1.3/5。GPT-5.4在Skill Steering下完全恢复了目标价值排序，表明深层框架干预比表层提示更有效地重塑价值偏好。

评估边界方面，本文依赖单一LLM-as-Judge（DeepSeek V3.2）进行Rubric评分，虽有人工心理学家审计，但未报告多模型评判的一致性指标。可复现性受限于OpenRouter API的模型版本波动，且未公开所有60,000条轨迹的原始数据，仅提供了聚合统计。

## 关联研究分析

从问题动机看，本文与AgentDojo同属动态环境评估，但AgentDojo聚焦于对抗攻击下的安全失败，而本文关注非对抗场景下的价值冲突。这一差异源于任务特性：安全评估需模拟恶意输入，而价值评估需模拟资源或目标约束。AgentDojo未解耦框架效应，导致其安全分数可能混淆模型鲁棒性与框架防御能力，而本文通过固定模型对比不同Harness，揭示了框架对价值表现的扭曲。

从方法设计看，本文与Holistic Agent Leaderboard均强调Harness的影响，但后者关注性能-成本帕累托前沿，前者关注价值-行为一致性。Holistic Agent Leaderboard未引入心理学理论指导的Rubric，其评估指标（准确率、Token消耗）无法捕捉价值取向的细微差异。本文引入心理学家介入的Rubric合成，解决了通用指标无法量化“价值偏好”的问题，但这也引入了新的偏差源：Rubric本身由LLM合成，其价值中立性依赖元Rubric的设计，若元Rubric隐含道德基线，则可能系统性偏袒特定价值维度。

## 总结

本文核心矛盾在于智能体价值评估缺乏独立于任务成功率的度量体系，且框架效应未被解耦。其切入点在于提出价值非同一性假设，并通过可执行环境与轨迹级Rubric实现行为审计。实验证明了Harness Pull的非加性影响及Skill Steering的深层调控能力，其中Skill Steering在3.7/5维度上优于Prompt Steering的1.3/5。本文边界在于单一评判模型的稳定性未经验证，且价值维度的覆盖受限于心理学量表的翻译。当Rubric合成模型的价值偏好与目标智能体存在系统性偏差时，该基准能否准确捕捉真实的价值冲突，论文未给出回答。
