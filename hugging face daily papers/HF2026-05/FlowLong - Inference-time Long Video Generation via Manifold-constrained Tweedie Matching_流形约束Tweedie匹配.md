> 长视频生成的核心矛盾在于预训练模型受限于短片段上下文，直接外推导致质量崩塌。现有免训练方法依赖架构修改，自回归方法则因KV缓存复用引发误差累积与运动重复。FlowLong将长视频生成重构为采样轨迹对齐的逆问题，通过重叠窗口的Tweedie匹配与随机早期采样实现免训练时长扩展。该方法在免训练约束下优于双向外推基线，但绝对性能低于蒸馏式自回归SOTA，且仅解决局部一致性，全局语义连贯性存疑。

## 研究背景

视频扩散Transformer（DiT）通过流匹配学习从噪声到数据的连续传输路径，其采样过程遵循确定性常微分方程（ODE）。当模型在短片段（如5秒）上训练后，直接生成更长序列时，由于缺乏长程依赖建模，帧间一致性迅速退化。这种退化源于两个机制：一是位置编码在超出训练长度后失效，二是独立采样的窗口间缺乏约束，导致相邻片段在重叠区域出现视觉断裂。

主流长视频生成路线分为两类。第一类是双向模型外推，如RIFLEx通过降低RoPE频率抑制重复，UltraViCo通过抑制超出窗口的注意力分数集中计算，但这些方法均绑定特定骨干网络，且随长度增加质量持续下降。第二类是自回归生成，如CausVid通过蒸馏实现少步生成，Self-Forcing通过自强制训练消除曝光偏差，但KV缓存的复用导致误差随时间复利累积，运动模式趋于重复。FlowLong的切入点在于：不修改模型架构，不依赖蒸馏教师，而是将长视频生成视为多个独立采样轨迹的同步问题，通过推理时的梯度校正实现窗口间对齐。

## 核心方法

### 流匹配采样与逆问题框架

FlowLong基于流匹配模型，其采样过程由速度场 $v_\theta(x_t, t)$ 驱动，从 $t=1$ 到 $t=0$ 求解ODE。标准流程中，每个视频块（chunk）从独立高斯噪声出发，沿各自的ODE轨迹去噪。本文的关键差异在于：不将长视频视为单一序列的自回归预测，而是视为多个重叠短窗口的并行采样，其一致性通过逆问题求解器（DDS）的梯度校正机制在采样过程中动态维持。

### Tweedie匹配：重叠区域的流形约束插值

在标准ODE采样中，相邻窗口在重叠帧上的去噪估计可能因初始噪声不同而发散。FlowLong引入Tweedie匹配，将重叠区域的一致性约束转化为采样引导损失。设第 $k$ 个窗口与第 $k+1$ 个窗口在 $O$ 帧上重叠，定义帧选择矩阵 $M_k$ 和 $M'_{k+1}$，则硬约束为 $M_k x^{[k]} = M'_{k+1} x^{[k+1]}$。该约束被松弛为引导损失 $\ell_k$，其梯度更新在去噪估计 $\hat{x}^{[k]}_{0|t}$ 上执行：

$$ \hat{x}^{[k]}_{0|t} \leftarrow \hat{x}^{[k]}_{0|t} - \lambda_j \left( \hat{x}^{[k]}_{0|t} - \hat{x}^{[k+1]}_{0|t} \right) $$

其中 $\lambda_j$ 为重叠窗口内的对称调度步长。该公式的物理含义是：在重叠帧上，将当前窗口的去噪估计向相邻窗口的估计进行插值，强制两者在数据流形上对齐。非重叠帧保持不变，确保局部细节不受干扰。这一设计解决了双向外推方法中窗口间视觉断裂的问题，且无需修改模型参数。

### 随机早期采样：打破ODE轨迹惯性

Tweedie匹配仅在去噪估计上施加校正，但在确定性ODE采样中，重噪声步骤会将状态拉回原始轨迹，导致校正效果被抵消。为打破这种轨迹惯性，FlowLong在早期采样阶段（$t \ge t^*$）引入随机微分方程（SDE）采样：

$$ x^{[k]}_s = x^{[k]}_t + (s-t) v_\theta(x^{[k]}_t, t) + \kappa_{s,t} \epsilon $$

其中 $\kappa_{s,t} = s\sqrt{\eta_t}$，$\eta_t=1$ 当 $t \ge t^*$，否则 $\eta_t=0$。该公式表明：在高噪声阶段，每次Tweedie匹配后注入新鲜噪声，扰动各窗口的轨迹，促进跨窗口混合；在低噪声阶段（$t < t^*$）切换回确定性ODE，保留细粒度视觉保真度。这一设计解决了纯ODE采样中校正效果被轨迹惯性抵消的问题，实现了窗口间的渐进同步。

## 实验评估

实验在Wan 2.1-T2V-1.3B和LTX-2模型上进行，使用VBench评估30秒和60秒视频的7个维度。基线包括双向外推方法（RIFLEx, UltraViCo）和自回归方法（CausVid, Self-Forcing, Deep-Forcing, LongLive）。FlowLong在30秒生成中Overall得分0.8233，60秒生成中Overall得分0.8251，均优于所有双向外推基线。与自回归基线相比，FlowLong在Dynamic Degree维度上显著领先（30秒0.6967 vs Self-Forcing 0.6893），表明其运动多样性更优。

| 模型 | 30s Overall | 60s Overall | 30s Dynamic Degree | 60s Dynamic Degree |
| :--- | :--- | :--- | :--- | :--- |
| RIFLEx | 0.4400 | - | 0.9700 | - |
| UltraViCo | 0.4708 | - | 0.5612 | - |
| Wan2.1 + Ours | 0.5777 | 0.5738 | 0.6368 | 0.6391 |
| CausVid | 0.5773 | 0.5746 | 0.6556 | 0.6438 |
| Self-Forcing | 0.5523 | 0.5355 | 0.6893 | 0.6831 |
| LongLive | 0.5724 | 0.5640 | 0.6763 | 0.6803 |
| Wan2.1 + Ours (1.3B) | 0.5868 | 0.5885 | 0.6967 | 0.6916 |

消融实验表明，混合采样策略（SDE-ODE）优于纯ODE和纯SDE。纯ODE采样产生独立帧，缺乏时序一致性；纯SDE保持时序一致性但牺牲视觉保真度；FlowLong的混合策略在两者间取得平衡。

评估边界方面，VBench对分钟级以上视频的细粒度退化不敏感，且未报告计算效率指标。论文未提供开源代码，超参数（如 $t^*$、$\lambda_j$ 调度）未在正文中详细披露，可复现性受限。

## 关联研究分析

从问题动机看，FlowLong与Self-Forcing均针对长视频生成的误差累积，但路径根本不同。Self-Forcing通过训练阶段自采样对齐分布，依赖蒸馏教师，适用于从头训练场景；FlowLong通过推理时轨迹校正，免训练、架构无关，适用于已有预训练模型的快速扩展。这一差异源于任务特性：Self-Forcing追求长程稳定性（60秒SOTA 83.48），FlowLong追求免训练灵活性。FlowLong在60秒Overall得分0.8251，低于Self-Forcing++的83.48（据领域综述），表明免训练方法在长程稳定性上仍有差距，但其在Dynamic Degree上的优势（0.6916 vs Self-Forcing 0.6831）揭示了运动多样性与稳定性的权衡。

从方法设计看，FlowLong与RIFLEx均针对双向模型外推，但机制迥异。RIFLEx修改RoPE频率，绑定特定骨干；FlowLong通过Tweedie匹配对齐重叠窗口，架构无关。这一差异源于设计哲学：RIFLEx试图在模型内部抑制重复，FlowLong试图在采样过程外部强制一致性。FlowLong的Tweedie匹配仅约束局部重叠区域，对全局语义连贯性无直接作用，而RIFLEx的频率调整影响全局时序感知。FlowLong在30秒生成中Overall得分0.5777（1.3B），高于RIFLEx的0.4400，表明局部约束在短时长下更有效，但全局语义断裂问题在更长时长下可能显现。

## 总结

FlowLong要解决的核心矛盾是预训练视频模型在免训练约束下无法突破原生上下文长度。其切入点在于将长视频生成重构为采样轨迹对齐的逆问题，通过Tweedie匹配在重叠区域施加流形约束，结合随机早期采样打破轨迹惯性，实现窗口间同步。实验证明，该方法在30秒和60秒生成中Overall得分分别为0.8233和0.8251，优于所有双向外推基线，且在Dynamic Degree上领先自回归基线。然而，其边界在于：Tweedie匹配仅约束局部重叠区域，对全局语义连贯性无直接作用；免训练性能低于蒸馏式自回归SOTA（如Self-Forcing++的83.48）。当视频长度超过60秒时，局部约束是否足以维持全局叙事连贯性，论文未给出回答。
