# HuggingFace最新推荐论文 ｜LocateAnything: Fast and High-Quality Vision-Language Grounding with Parallel Box Decoding ｜并行框解码

研究机构：香港理工大学、美国普林斯顿大学

论文原文见 [arXiv](https://arxiv.org/abs/2605.27365)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.27365)

> 视觉定位（Visual Grounding）旨在建立自然语言描述与图像特定区域之间的精确对应，是多模态大语言模型（MLLMs）连接语言语义与视觉证据的基础能力。现有生成式定位方法将二维边界框序列化为离散文本或量化Token，强制逐Token自回归解码，导致推理延迟高且忽略坐标间的几何耦合。本文提出并行框解码（Parallel Box Decoding, PBD），将边界框作为原子单元进行单步并行预测，并构建1.38亿样本的大规模数据集。该框架在速度与精度上均取得SOTA，但其纯监督微调路线在复杂推理任务上的上限尚存疑。

## 研究背景

当多模态大语言模型（MLLMs）执行视觉定位时，其输出坐标的方式直接决定了系统的响应延迟与定位精度。当前主流范式将连续坐标离散化为文本数字或量化Token，通过下一Token预测（Next-Token Prediction, NTP）逐位生成。这种一维序列化过程不仅将二维几何对象拆解为独立的标量，导致坐标间的空间相关性被切断，更在推理阶段形成严格的串行瓶颈，使得模型在处理多目标或高分辨率图像时吞吐量急剧下降。

视觉定位领域长期面临空间精度与语言生成效率的冲突。早期专用检测器虽精度较高，但缺乏开放词汇泛化能力；随着MLLMs的兴起，定位被重构为自回归生成任务，模型得以利用语言推理能力处理复杂空间关系，但细粒度感知不足与累积误差成为新瓶颈。现有加速方案如通用多Token预测（Multi-Token Prediction, MTP）或掩码扩散模型，通常采用结构无关的随机分块策略，导致模型学习跨边界或跨类别的虚假相关，反而损害了定位的可靠性。

LocateAnything 抓住了“解码结构应与几何结构对齐”这一被忽略的点。它指出，边界框的四个坐标 $(x_1, y_1, x_2, y_2)$ 构成一个紧密耦合的原子单元，不应被任意切割。通过将MTP的分块边界严格对齐到边界框边界，该框架在保留MLLMs通用推理能力的同时，从源头消除了序列化带来的延迟与误差累积，实现了速度与精度的同步提升。

## 核心方法

### 方法参照系

本文问题属于生成式视觉定位范畴，其标准流程为：视觉编码器提取图像特征，语言解码器以自回归方式生成坐标Token序列。本文与标准流程的关键差异在于，它放弃了逐Token的NTP范式，转而采用基于固定长度块（Block）的并行解码机制，将解码粒度从“单个坐标值”提升至“完整边界框”。

### 块对齐输出表示

标准NTP将坐标视为独立Token序列，而本文引入块对齐输出表示，将连续坐标归一化至 $[0, 1000]$ 并离散化后，重组为固定长度 $L=6$ 的原子块序列 $\mathbf{B} = (b_1, b_2, \dots, b_N)$。每个块 $b_i$ 包含一个完整边界框及其结构标记（如 `<box>` 和 `</box>`），未占用位置以 `<null>` 填充。联合概率建模为：

$$ P(\mathbf{B} | \mathcal{Z}, \mathcal{E}) = \prod_{i=1}^{N} P(b_i | b_{<i}, \mathcal{Z}, \mathcal{E}) $$

其中 $\mathcal{Z}$ 为视觉特征，$\mathcal{E}$ 为文本查询。该公式的物理含义是：模型在生成第 $i$ 个块时，仅依赖前序块、视觉特征和文本查询，而非前序块内部的单个Token。这种设计动机在于，边界框的四个坐标在几何上强耦合，将其作为整体预测可避免NTP中因逐位生成导致的误差累积，同时使并行解码成为可能。

### 混合解码策略

块对齐表示解决了训练时的结构对齐问题，但推理时并行解码可能在复杂场景下产生格式错误或一致性违规。为此，本文设计了三模式混合解码策略。Fast Mode 直接并行预测所有块，最大化吞吐量；Slow Mode 回退至NTP逐Token解码，保证最高精度；Hybrid Mode 以Fast Mode为默认，当检测到并行输出不可靠时，仅对问题块执行局部NTP重解码。该策略的设计动机在于，纯并行解码在密集或遮挡场景下易失效，而纯NTP又过于缓慢。Hybrid Mode 通过“按需回退”机制，在保留大部分并行加速收益的同时，消除了最坏情况下的定位失败，实现了鲁棒性与效率的动态平衡。

## 实验评估

实验在COCO、LVIS、VisDrone、Dense200、RefCOCOg、ScreenSpot-Pro等基准上进行，对比了专用检测器（如DETR、Grounding DINO）、通用VLMs（如Qwen3-VL、Rex-Omni）及GUI专家模型。基线覆盖全面，但缺少基于强化学习（RL）的最新SOTA（如UniVG-R1），这可能影响对复杂推理场景的评估。

| 方法 | COCO mIoU | LVIS mIoU | VisDrone mIoU | ScreenSpot-Pro Avg | RefCOCOg val F1@0.5 |
|---|---|---|---|---|---|
| Rex-Omni-3B | 52.9 | 46.9 | 35.8 | - | 79.9 |
| Qwen3-VL-8B | 52.9 | 44.8 | 32.4 | - | 88.6 |
| LocateAnything-3B | 54.7 | 50.7 | 39.9 | 60.3 | 88.6 |

LocateAnything-3B 在COCO、LVIS和VisDrone上均超越Rex-Omni，且在ScreenSpot-Pro上达到60.3的SOTA，证明PBD在速度与精度上均优于量化Token范式。

消融实验验证了块对齐MTP的有效性。在COCO上，结构无关的SDLM-B6仅取得46.1 F1，而PBD (Fast) 达到49.6 F1，且吞吐量从5.5 BPS提升至16.9 BPS。联合训练损失 $\mathcal{L}_{ntp}$ 和 $\mathcal{L}_{blk}$ 将Slow Mode的F1从50.1提升至52.1，表明双目标优化对精度有显著增益。Hybrid Mode 在13.2 BPS的吞吐量下实现了51.6 F1，接近Slow Mode的精度，验证了混合策略的实用性。

评估协议采用F1@IoU=0.5/0.95及mIoU，指标完备。但论文未报告置信区间，且部分基准（如AgroVG、VRT-Bench）仅报告单一结果，缺乏参照系。代码与模型已开源，训练配置（如138M数据、256 GPU）详细披露，可复现性良好。

## 关联研究分析

从问题动机看，本文与Rex-Omni同属生成式定位路线，但Rex-Omni采用量化Token的NTP范式，而本文通过PBD将解码粒度提升至边界框级别。这一差异的根源在于任务特性：Rex-Omni侧重统一检测与定位的通用性，而本文更关注解码效率与几何结构对齐。Rex-Omni的量化Token虽简化了坐标表示，但未能解决串行解码的延迟瓶颈，而PBD通过原子块并行预测，直接突破了这一物理限制。

从方法设计看，本文与SDLM、Block Diffusion等结构无关MTP方法形成鲜明对比。SDLM通过随机分块预测未来Token，适用于通用语言建模，但用于定位时会导致跨边界学习，引入虚假相关。本文的PBD则严格对齐几何单元，避免了这一问题。这一差异暗示，MTP在视觉定位中的应用必须考虑数据的结构化特性，而非简单迁移语言建模的加速策略。此外，本文未使用RL，而领域共识认为RL能增强复杂推理能力，这是否意味着PBD在否定语义或多目标推理上存在性能上限，论文未给出回答。

## 总结

LocateAnything 要解决的核心矛盾是生成式定位中速度-精度的权衡。现有NTP方法因序列化导致延迟高且误差累积，而通用MTP因结构无关引入虚假相关。本文抓住“几何结构对齐”这一切入点，将边界框作为原子单元进行并行解码，并辅以混合回退机制。实验证明，PBD在COCO上达到54.7 mIoU，吞吐量12.7 BPS，均超越Rex-Omni。其边界在于，纯SFT路线在复杂推理任务上的表现未与RL方法直接对比，且Hybrid模式的回退阈值依赖任务分布。当支持集增大或场景复杂度提升时，PBD的并行解码是否仍能保持精度优势，论文未给出回答。
