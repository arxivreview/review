# HuggingFace最新推荐论文 ｜Same Architecture, Different Capacity: Optimizer-Induced Spectral Scaling Laws ｜优化器诱导的谱缩放律

研究机构：美国纽约大学

作者：Nandan Kumar Jha、Brandon Reagen

论文原文见 [arXiv](https://arxiv.org/abs/2605.21803)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.21803)

> 经典缩放律将优化器视为固定超参数，忽略了其对模型内部表示几何的塑造作用。现有研究仅关注验证损失，无法区分不同优化器在损失匹配时是否产生相同的内部结构。本文通过测量前馈网络（FFN）激活值的特征谱，量化了优化器对有效秩缩放指数的影响。这揭示了优化器是表示缩放的一级设计轴，但结论局限于特定架构与数据分布。

## 研究背景

Transformer 模型中，FFN 占据约三分之二的参数，其“扩展-非线性-压缩”结构构成了可测量的潜在空间。理解该空间的有效维度（即谱容量）如何随宽度增长，是评估模型效率的关键。然而，传统缩放律仅预测验证损失，假设优化器仅影响收敛速度，不改变表示的内在结构。

主流缩放律研究（如 Kaplan et al., 2020）建立了损失与计算量的幂律关系，但将优化器视为常数。近期工作（如 Qiu et al., 2025）虽引入优化器效率因子，但仍假设不同优化器共享相同的损失缩放指数，仅存在乘性差异。这种视角掩盖了一个核心问题：当两个优化器达到相同的验证损失时，它们是否学到了相似的内部表示？若答案是否定的，则优化器选择不仅是效率旋钮，更是决定模型容量如何在特征模式中分配的设计轴。本文切入点在于打破“损失匹配即几何匹配”的隐含假设，通过直接测量 FFN 的谱结构，揭示优化器对表示缩放律的根本性影响。

## 核心方法

### 方法参照系

本文基于 FFN 谱缩放框架（Jha et al., 2024），该框架在固定优化器下研究 FFN 宽度与有效秩的关系。关键差异在于，本文将优化器从固定变量转化为自变量，考察不同优化器下谱缩放指数 $\beta$ 的变化，从而将谱缩放律从“架构属性”重新定义为“架构-优化器对属性”。

### Rényi 有效秩与谱不对称性

为量化谱容量，本文采用 Rényi 熵族定义有效秩，而非单一指标。设计动机在于，不同优化器可能以不同方式分配谱质量：有的集中于主导特征模式，有的分散于弱方向。单一指标无法捕捉这种结构性差异。

$$ R_\alpha(p) = \left( \sum_{i=1}^D p_i^\alpha \right)^{\frac{1}{1-\alpha}} $$

其中 $p_i$ 为归一化特征值，$\alpha$ 控制对弱方向的敏感度。本文锚定 $\alpha=1$（软秩，Shannon 熵加权）和 $\alpha=2$（硬秩，参与比，对主导模式敏感）。定义硬-软不对称性 $\Delta_{1,2} = \beta_{soft} - \beta_{hard}$，正值表示新增宽度主要转化为弥散谱容量而非主导模式容量。

### 频率分层与缩放律拟合

聚合谱可能被高频 token 主导，掩盖低频 token 的容量限制。本文按 token 频率将表示分为 HEAD（前 1/3 出现量）、MID（中 1/3）和 TAIL（后 1/3）三个区间。对每个区间独立计算协方差谱并拟合缩放律：

$$ R_\alpha(D) \propto D^{\beta_\alpha} $$

其中 $D$ 为 FFN 隐藏维度。$\beta_\alpha$ 衡量新增宽度转化为有效容量的效率。该分层设计旨在揭示优化器效应是否依赖于 token 的统计频率，特别是针对 LLM 已知的长尾知识学习困难问题。

## 实验评估

实验在 GPT-2 160M 和 350M 架构上进行，使用 FineWeb-Edu 数据集训练。基线包括 AdamW、Muon、NorMuon 及不同秩约束的 Dion 变体。对比覆盖了逐元素自适应（AdamW）、正交化（Muon/NorMuon）及秩约束正交化（Dion）三条主要路线，但缺失 Shampoo 和 SOAP 等基于二阶信息的矩阵优化器，限制了结论的普适性。

| 优化器 | TAIL $\beta_{hard}$ | TAIL $\Delta_{1,2}$ | MID $\beta_{hard}$ |
| :--- | :--- | :--- | :--- |
| AdamW | 0.44 | +0.18 | 0.24 |
| Muon | 1.02 | +0.01 | 0.93 |
| NorMuon | 1.04 | +0.00 | 0.95 |
| Dion (1/2) | 0.88 | +0.07 | 0.82 |
| Dion (1/16) | 0.40 | +0.31 | 0.46 |

在 TAIL 区间，Muon 的硬秩缩放指数 $\beta_{hard}=1.02$ 接近线性，而 AdamW 仅为 0.44，差异达 2.3 倍。Dion 的秩约束实验显示，当秩分数降至 1/16 时，其 $\beta_{hard}$ 降至 0.40，接近 AdamW 水平，表明正交化本身不足以保证高硬容量增长，更新秩是关键约束。

消融实验验证了“损失匹配不等于几何匹配”。将 AdamW 训练步数从 6K 延长至 12K 以匹配 Dion (1/16) 的困惑度，AdamW 的聚合 $\beta_{hard}$ 从 0.29 降至 0.03，而 Dion 保持 0.50。这排除了收敛速度作为解释变量，证实谱几何差异源于优化器机制本身。

评估边界方面，实验局限于 GPT-2 架构和 FineWeb-Edu 数据，未测试 MoE 或 SSM 等新型架构。代码已开源，但超参数细节（如学习率调度）未在正文中完全披露，复现需依赖附录。

## 关联研究分析

从问题动机看，本文与 Qiu et al. (2025) 的优化器感知缩放律形成互补。后者将优化器差异建模为损失缩放中的乘性效率因子，假设指数不变；本文则证明指数本身随优化器变化。这一差异源于评估维度不同：前者关注标量损失，后者关注向量表示的几何结构。Qiu 的方法适用于快速预测验证损失，但无法指导架构设计；本文揭示了优化器对内部容量的塑造，为联合设计提供依据。

从方法设计看，本文与 NerVE (Jha et al., 2024) 共享 FFN 谱分析框架，但 NerVE 关注固定宽度下优化器如何重分配方差，本文则关注宽度变化下的缩放指数。NerVE 未分层 token 频率，而本文发现 MID 区间增益最大（$\Delta \beta_{MID} = +0.69$），这可能与语言数据的 Zipf 分布有关。NerVE 的结论可能受高频 token 主导，本文的分层设计更精细地揭示了优化器效应的频率依赖性。

## 总结

本文核心矛盾在于经典缩放律忽略优化器对表示几何的塑造作用。通过测量 FFN 激活值的 Rényi 有效秩，本文证明相同架构在不同优化器下呈现截然不同的谱缩放律，特别是 Muon 在低频 token 上实现近线性硬秩增长（$\beta_{hard}=1.02$），而 AdamW 仅 0.44。这一发现挑战了“损失匹配即几何匹配”的假设，表明优化器是表示缩放的一级设计轴。然而，实验局限于 GPT-2 架构和单一数据集，且未探索二阶优化器（如 Shampoo）的谱行为。当模型规模扩大至千亿参数时，优化器诱导的谱不对称性是否会随深度增加而衰减，还是进一步放大，本文未给出回答。
