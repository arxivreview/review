> 视频多模态大语言模型（MLLMs）在处理用户指定的特定对象时，常因物体名词的注意力分散而丧失细粒度定位能力。现有方案依赖推理时的视觉提示（如掩码或点），增加了交互复杂度且偏离自然语言交互习惯。SWIM 通过构建自然语言引用数据集，并在训练阶段对物体名词的交叉注意力施加掩码监督，实现了纯文本输入下的精准对象接地。该方法在细粒度基准上显著超越了依赖视觉提示的专用模型，但其通用视频理解能力与前沿开源模型相比仍存在差距，且未验证长视频时序场景下的稳定性。

## 研究背景

当用户通过自然语言询问视频中特定对象时，MLLMs 往往无法将文本中的物体名词准确映射到视觉空间的具体区域。这一失效源于语义参考偏差：属性词（如颜色、纹理）对应低层视觉特征，注意力集中；而物体名词对应高层语义概念，在大规模语料中分布广泛，导致其交叉注意力图呈现弥散状态。这种视觉-语言对齐的缺失，使得模型在需要精确对象识别的任务中表现不佳，往往依赖文本捷径而非视觉证据。

细粒度对象理解是视频-语言表示学习从粗粒度描述走向精确交互的关键环节。主流路线包括引入区域编码器或显式视觉提示（点、框、掩码）来引导模型关注特定区域，如 VideoRefer 和 DAM-8B。然而，这些方法在推理时仍需额外的视觉输入，不仅增加了计算开销，更不符合用户通过纯自然语言交互的自然习惯。SWIM 的切入点在于揭示并纠正物体名词的注意力弥散问题，通过训练时的显式监督替代推理时的视觉提示，旨在实现无需额外模块的自然语言细粒度接地。

## 核心方法

### 方法参照系

细粒度对象理解的标准流程通常涉及视觉提示输入与区域编码器。SWIM 的关键差异在于摒弃了推理时的视觉提示依赖，转而将掩码监督仅用于训练阶段的注意力正则化，从而在架构上保持与通用 MLLMs 的一致性，仅在训练目标中引入空间对齐约束。

### NL-Refer 数据集构建

为提供物体名词与视觉区域的显式对应关系，SWIM 基于 VideoRefer 数据集构建了 NL-Refer。设计动机在于解决原始数据中占位符缺乏自然语言语义身份的问题，使模型能学习从文本直接定位对象。具体流程利用 GPT-4o 将原始占位符替换为包含特定物体名词的自然语言描述，并用特殊标记 `<ins>` 包裹该名词，建立文本 Token 与像素级掩码 $M_i$ 的确定性映射。

### 注意力正则化机制

SWIM 的核心创新是在监督微调阶段引入注意力正则化损失。在 LLM 解码器的第 $l$ 层，提取被标记物体名词 $w_i$ 的查询向量 $Q_{t}^{[l]}$ 与视觉 Token 的键向量 $K_{v}^{[l]}$，计算交叉注意力权重：

$$ A_{l,i} = \text{softmax}\left(\frac{Q_{t}^{[l]} K_{v}^{[l]T}}{\sqrt{d}}\right) $$

该公式量化了文本 Token 对每个视觉 Token 的关注程度。随后，将多层注意力图聚合为 $\bar{A}_i$，并通过二元交叉熵损失与真实掩码 $M_i$ 对齐：

$$ \mathcal{L}_{att} = -\frac{1}{HW} \sum_{u,v} [M_i(u,v) \log \bar{A}_i(u,v) + (1-M_i(u,v)) \log (1-\bar{A}_i(u,v))] $$

这一机制强制模型在训练时集中物体名词的注意力于正确视觉区域，弥补了预训练中高层语义概念对齐不足的缺陷，使推理时仅凭文本即可实现精准接地。

## 实验评估

SWIM 在 Qwen2.5-VL-7B 骨干上训练，使用 235K 样本（含 125K NL-Refer 数据）。基线覆盖通用模型（GPT-4o, Qwen2.5-VL）与专用模型（VideoRefer-7B, DAM-8B），但缺乏与其他纯文本接地方法的直接对比。在 VideoRefer-Bench-Q 上，SWIM 平均准确率达 78.3%，超越 VideoRefer-7B 的 71.9% 和 GPT-4o 的 71.3%；在 VideoRefer-Bench-D 上，平均得分 3.78，优于最强专用基线 DAM-8B 的 3.68。

| 方法 | VideoRefer-Q Avg | VideoRefer-D Avg | MVBench | VideoMME |
| :--- | :--- | :--- | :--- | :--- |
| Qwen2.5-VL-7B | 71.8 | 3.25 | 58.5 | 73.7 |
| VideoRefer-7B | 71.9 | 3.68 | 59.6 | 55.9 |
| DAM-8B | - | 3.68 | - | - |
| **SWIM** | **78.3** | **3.78** | **62.1** | **55.9** |

消融实验显示，多层注意力聚合中，Mean 融合优于 Add、Pool 和 Prod，表明简单平均能更好地保留跨层稳定的对齐信号。损失函数方面，BCE 优于 Dice 和 Focal，说明像素级二元分类比区域重叠度量更有效地约束注意力分布。在通用基准上，SWIM 的 VideoMME 得分为 55.9%，与 VideoRefer-7B 持平，但远低于 VidGround 的 74.5%，表明注意力正则化主要提升了细粒度接地能力，未显著增强通用推理性能。

评估边界方面，实验未报告置信区间，且 VideoMME 分数与领域 SOTA 差距较大，可能源于缺乏通用的 RL 后训练。代码已开源，但训练数据规模（235K）远小于通用 MLLMs，限制了其在大规模场景下的泛化验证。

## 关联研究分析

从去偏策略看，SWIM 与 VidGround 代表了消除语言先验偏差的两种路径。VidGround 采用强化学习后训练显式纠偏，而 SWIM 通过训练时的注意力正则化实现类似目标。SWIM 的优势在于无需复杂的 RL 流程，且专注于物体名词的特定对齐；但其 VideoMME 分数（55.9%）远低于 VidGround（74.5%），暗示注意力正则化在提升细粒度接地的同时，可能未充分解决通用推理中的语言依赖问题。

从数据范式看，SWIM 与 VideoRefer 存在继承与改造关系。VideoRefer 依赖推理时的掩码提示，而 SWIM 将掩码转化为训练时的监督信号，实现了从“视觉提示驱动”到“文本驱动”的范式转换。这一转变降低了推理复杂度，但论文未探讨在长视频或动态场景中，静态掩码监督是否能有效捕捉时序变化，这限制了其在复杂视频理解任务中的适用性。

## 总结

SWIM 针对 MLLMs 中物体名词注意力弥散导致的细粒度接地失效，提出通过训练时注意力正则化实现纯文本对象定位。该方法在 VideoRefer-Bench 上取得 78.3% 的准确率，超越依赖视觉提示的专用模型，证明了显式对齐监督的有效性。然而，其在 VideoMME 上的表现（55.9%）与前沿开源模型存在差距，且实验局限于短片段对象定位，未验证长视频时序场景下的稳定性。当视频时长增加且对象运动剧烈时，静态掩码监督是否仍能维持注意力对齐的精度，论文未给出回答。
