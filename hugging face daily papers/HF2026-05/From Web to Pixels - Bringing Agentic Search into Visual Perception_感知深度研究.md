研究机构：武汉大学、香港中文大学

作者：Bokang Yang、Xinyi Sun、Kaituo Feng 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.12497)

> 视觉感知任务长期假设目标对象的识别线索存在于图像内部或模型预训练参数中，但开放世界场景下，关键证据往往散落于实时新闻、品牌关系等外部网络信息中，导致传统定位模型失效。现有方法将搜索视为文本答案合成工具，缺乏将外部事实证据直接映射为像素级掩码或边界框的机制。本文提出感知深度研究范式，构建对象锚定基准WebEyes，并设计代理式搜索工作流Pixel-Searcher，通过多跳网络检索解析隐藏实体身份，再将其绑定至视觉实例。该工作验证了外部证据对视觉定位的增益，但其性能瓶颈仍受制于证据获取的准确性与实例绑定的鲁棒性，且基准规模较小，泛化能力存疑。

## 研究背景

当多模态大模型（MLLMs）面对“找出图中某品牌最新代言人”这类查询时，仅凭图像像素或模型内部冻结的知识无法确定目标身份，因为答案依赖于图像之外的时效性事实。这种“证据在图像外”的困境要求系统具备主动检索外部知识的能力，即符号接地（Symbol Grounding）问题在开放世界中的延伸：如何将非视觉的事实线索（如事件、品牌归属）稳定地映射到具体的视觉对象上。传统的指代表达理解（Referring Expression Comprehension）假设目标可通过视觉属性直接识别，而本文关注的场景要求先通过外部证据解析出目标实体，再在图像中定位该实体，这构成了感知与知识检索的强耦合。

视觉感知研究的主流路线已从可见类别识别转向基于内部知识的隐式目标定位，如MDETR和LISA等方法通过端到端训练或MLLM解释提示来生成掩码。然而，这些方法均假设目标身份可由图像或提示文本直接推断，无法处理需要多跳事实推理才能确定的目标。与此同时，多模态搜索基准如MMSearch和BrowseComp-VL评估了模型的浏览与搜索能力，但其输出通常为文本答案，未要求将检索到的证据转化为像素级的空间定位。这种“搜索-定位”解耦的缺失，使得现有系统无法在开放世界中完成从外部证据到视觉实例的完整闭环。本文的切入点在于，将网络搜索从答案合成工具转化为视觉感知的证据源，要求模型在定位前必须解析隐藏的身份假设，从而建立外部知识与像素级输出的直接映射。

## 核心方法

### 方法参照系

本文问题可置于“语言引导视觉感知”的通用框架下，标准流程为“查询→视觉特征提取→区域预测”。关键差异在于，本文的查询不包含直接视觉属性，而是包含需通过外部检索才能解析的事实线索，因此标准流程中缺失了“外部证据获取与实体解析”这一前置环节，导致直接定位失败。

### 代理式搜索与目标解析

传统方法将查询直接作为定位提示，但在知识密集型查询中，查询文本仅包含间接线索（如“某品牌收购案中的代言人”），直接定位会因身份歧义而失败。Pixel-Searcher引入自适应搜索-推理循环，将查询分解为可搜索的子目标，通过多轮网络检索收集证据，并生成结构化目标假设 $h = (e, c, K)$，其中 $e$ 为解析出的实体名称，$c$ 为视觉类别，$K = \{k_j\}_{j=1}^m$ 为从外部证据中提炼的图像可验证线索。该公式的物理含义是，将非结构化的网络文本转化为包含实体身份、类别及视觉验证线索的结构化表示，从而消除查询中的歧义，为后续视觉定位提供明确的搜索目标。这一设计解决了直接定位方法在身份未知时的根本失效，使模型能够区分图像中多个外观相似的实例。

### 证据验证与工具辅助定位

解析出的目标假设 $h$ 需绑定到图像中的具体实例，但图像可能包含多个干扰项，仅凭 $h$ 中的实体名称无法确定唯一区域。Pixel-Searcher采用工具辅助的决策过程，首先调用定位工具获取候选区域，然后通过证据验证选择与 $h$ 中线索 $K$ 最一致的实例。对于分割任务，验证后的区域被传入可提示分割工具（如SAM3）生成最终掩码。该过程将定位从一次性文本到框的预测，转变为条件于外部证据的工具调用序列，确保了视觉输出与解析身份的兼容性。这一机制解决了传统方法中“视觉合理但语义错误”的绑定失败问题，通过显式的证据验证步骤，拒绝了与外部证据不一致的视觉区域，提升了多实例场景下的定位准确性。

## 实验评估

实验在自建基准WebEyes上进行，包含120张图像、473个标注对象实例和1,927个任务样本，覆盖车辆、名人、动漫等6类实体。基线包括开源通用模型（Qwen3-VL-8B、InternVL-3.5-8B）和闭源SOTA（GPT-5.4、Gemini-3.1-Pro），但缺失专用抽象推理模型（如DIRCR、VARC），且未对比纯视觉定位方法（如LISA）在相同知识密集型查询上的表现，基线覆盖存在局限。

| 方法 | 任务 | IoU | R@0.5 | gIoU | cIoU | 准确率 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Qwen3-VL-8B | Grounding | 26.81 | 32.61 | - | - | - |
| Pixel-Searcher | Grounding | 34.17 | 41.30 | - | - | - |
| Qwen3-VL-8B | Segmentation | - | - | 35.78 | 25.94 | - |
| Pixel-Searcher | Segmentation | - | - | 39.17 | 32.41 | - |
| Qwen3-VL-8B | VQA | - | - | - | - | 36.34 |
| Pixel-Searcher | VQA | - | - | - | - | 42.24 |

Pixel-Searcher在三个任务视图上均优于基线，其中Grounding任务IoU提升7.36点，Segmentation任务gIoU提升3.39点，VQA任务准确率提升5.90点。消融实验显示，移除直接候选线索导致IoU从34.17降至20.14，降幅达41%，表明直接视觉线索对定位至关重要；移除矛盾检查导致IoU降至31.34，降幅8.3%，说明证据验证对排除干扰项有稳定增益。

评估边界方面，WebEyes规模较小（120张图像），且查询依赖六个月内时效性事实，导致基准随时间推移失效，可复现性受限。代码已开源，但超参数与GPU配置未在论文中详细披露，且未报告置信区间，数值比较需谨慎。

## 关联研究分析

从问题动机看，本文与LISA（Liu et al., 2024）同属语言引导视觉感知，但LISA假设目标身份可由文本提示直接推断，而本文要求目标身份需通过外部检索解析。这一差异源于任务特性：LISA处理的是静态视觉属性查询，而本文处理的是动态事实查询。LISA的MLLM解释提示机制无法处理图像外证据，因此其定位性能在知识密集型查询上必然受限，而本文的代理式搜索机制通过引入外部证据源，弥补了这一盲区。

从方法设计看，本文与MMSearch（Lin et al., 2024）同属多模态搜索，但MMSearch的输出为文本答案，而本文要求像素级定位。这一差异源于评估目标：MMSearch关注搜索能力，而本文关注搜索与感知的耦合。MMSearch未要求将检索证据转化为空间输出，因此其方法无法直接应用于视觉定位任务，而本文通过对象锚定基准和工具辅助定位，实现了从文本证据到像素输出的完整闭环。

## 总结

本文要解决的核心矛盾是开放世界视觉感知中外部证据与像素级定位的脱节，现有方法因缺乏外部证据解析机制而无法处理知识密集型查询。本文抓住的切入点是，将网络搜索从答案合成工具转化为视觉感知的证据源，通过代理式搜索解析隐藏实体身份，再将其绑定至视觉实例。本文构建了WebEyes基准和Pixel-Searcher工作流，证明了外部证据对视觉定位的增益，其中Grounding任务IoU从26.81提升至34.17，VQA任务准确率从36.34提升至42.24。本文的边界在于，基准规模较小且依赖时效性事实，导致可复现性受限，且消融实验显示直接视觉线索对定位至关重要，表明外部证据无法完全替代视觉属性。当查询中的外部证据与视觉属性冲突时，模型如何权衡两者以维持定位鲁棒性，论文未给出回答。
