# HuggingFace最新推荐论文 ｜InterLV-Search: Benchmarking Interleaved Multimodal Agentic Search ｜交错多模态智能体搜索基准

研究机构：新加坡南洋理工大学、山东大学

论文原文见 [arXiv](https://arxiv.org/abs/2605.07510)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.07510)

> 多模态智能体搜索旨在让模型在开放世界中主动规划、调用工具并整合异构证据以解决复杂问答任务。现有基准将视觉信息局限于初始输入或视为回答的终点，忽略了视觉线索在检索轨迹中作为“控制信号”引导后续搜索的关键作用。本文构建了三级基准 InterLV-Search，通过自动化与半自动化管道生成 2,061 个实例，强制要求视觉证据在搜索过程中反复充当枢纽。该工作填补了非线性多模态搜索评估的空白，但实验显示当前最强模型准确率仍低于 50%，揭示了架构统一与动态搜索状态保持之间的巨大鸿沟。

## 研究背景

当多模态大语言模型（MLLMs）面对开放世界任务时，仅凭输入上下文无法获取必要证据，必须依赖外部检索。这一过程涉及智能体搜索（Agentic Search），即模型需动态规划查询、调用工具并整合网页与图像信息。然而，视觉证据在搜索轨迹中的角色长期被简化：早期基准如 MMSearch 仅评估文本证据获取，而 VisBrowse 和 BrowseComp-V3 虽引入视觉浏览，但将检索到的图像视为“答案端点”（Endpoint），即找到图像后仅用于回答局部视觉问题，未考察其如何决定下一步搜索方向。

主流路线的瓶颈在于缺乏对“视觉枢纽”（Visual Pivot）能力的评估。在真实信息检索中，视觉观察常包含细粒度线索（如标志、空间关系），这些线索能消歧当前状态并揭示下一个搜索目标。现有基准未区分视觉证据是用于“回答”还是“控制搜索”，导致无法衡量智能体在非线性轨迹中维持视觉-文本交错状态的能力。本文切入点在于形式化“交错多模态搜索”（Interleaved Multimodal Search），要求中间视觉证据不仅作为问答来源，更作为引导后续检索决策的信号，从而暴露当前模型在动态证据整合上的根本缺陷。

## 核心方法

### 方法参照系

本文问题属于多模态智能体搜索基准构建，与传统的静态视觉-语言对齐任务（如 VQA）不同，其核心差异在于评估对象从“单步理解”转向“多步动态控制”。标准流程通常假设视觉输入固定，而本文要求视觉证据在搜索链中反复出现并改变搜索路径，这打破了“视觉作为静态上下文”的假设，引入了时序依赖与状态转移机制。

### 三级渐进式任务设计

InterLV-Search 将交错搜索分解为三个层级，以隔离不同能力的贡献。Level 1 评估“主动视觉证据获取”，即从文本需求推断并检索隐藏实体图像，属于 Search-to-VQA 任务。Level 2 在受控离线环境中测试多跳交错搜索，要求至少两轮视觉检索，其中视觉证据作为中间枢纽连接文本推理。Level 3 在开放网络环境中复现相同机制，并引入多分支样本，要求智能体在多个实体间比较并选择分支。这种设计通过逐步增加环境噪声与拓扑复杂度，量化了从静态获取到动态控制的性能衰减。

$$
Q = \text{Start Entity Description} + \text{Relation-Chain} + \text{Terminal VQA}
$$

该公式描述了 Level 1 实例的构成逻辑：起始实体描述隐含搜索需求，关系链压缩了多跳路径，终端 VQA 确保答案必须基于图像属性而非实体名称，从而强制模型执行“搜索-查看-回答”的完整闭环。

### 视觉枢纽轨迹判定机制

为了验证基准是否真正考察了“视觉控制搜索”，本文定义了“视觉枢纽轨迹”（Visual-Pivot Trajectory）。在轨迹日志中，若视觉证据被用于生成后续查询或分支决策，而非仅用于最终回答，则判定为枢纽。Level 2 的构建引入了“中间视觉探针”（Intermediate-Visual-Probed）样本，通过知识图谱（KG）路径挖掘，在推理链中间插入视觉断点，并引入视觉相似的桥接实体。这种设计强制智能体执行“文本到图像”再到“图像到图像”的检索，确保视觉信息在轨迹中起到承上启下的控制作用。

$$
\text{Bridge Validation} = \mathbb{I}(\text{Visual Similarity}(e_j, e'_j) > \tau) \land \mathbb{I}(\text{Semantic Relation}(e_j, e'_j) \neq \emptyset)
$$

该公式表示桥接实体验证逻辑：只有当候选实体 $e'_j$ 与断点实体 $e_j$ 视觉相似度高且存在合理语义关系时，才被接受为有效的视觉枢纽，防止模型通过捷径绕过视觉检索。

## 实验评估

实验采用 InterLV-Agent 框架统一工具调用与轨迹记录，评估 GPT-5.4、Gemini-3.1-Pro 等专有模型及 MMSearch-R1 等开源智能体。基线覆盖广泛，但缺乏针对原生统一架构（如 NEO、MANZANO）的对比，因任务性质侧重动态检索而非静态表征对齐。主结果显示，工具使用显著提升了专有模型性能，但开源搜索智能体在工具使用后性能反而下降，表明其搜索规划与视觉接地能力不足。

| 模型 | Level 1 +Tool | Level 2 +Tool | Level 3 +Tool |
| :--- | :--- | :--- | :--- |
| GPT-5.4 | 45.64 | 38.22 | 44.25 |
| Gemini-3.1-Pro | 46.05 | 41.33 | 51.06 |
| Claude-Sonnet-4.6 | 37.13 | 34.22 | 46.83 |
| MMSearch-R1-7B | 4.10 | 5.33 | 11.96 |

Gemini-3.1-Pro 在 Level 3 达到 51.06% 的准确率，是唯一突破 50% 的模型，但整体表现仍远低于人类水平。Level 3 中多分支样本的准确率显著低于单链样本，表明当前智能体在处理非线性搜索拓扑时存在严重的状态丢失问题。

消融分析显示，检索-回答分解中，“未检索”（UnRet.）情况下的准确率极低，证实了外部证据获取的必要性。然而，即使检索成功，从检索结果到最终答案的转化（Corr. from Ret.）仍存在较大损耗，说明视觉证据的整合与推理链条的连贯性是主要瓶颈。Level 2 中视觉枢纽轨迹的比例高达 88.9%（Claude）至 66.2%（GPT），验证了基准设计的有效性，即模型确实在尝试使用视觉证据控制搜索，但成功率有限。

评估边界方面，Level 3 依赖开放网络，存在页面动态变化与证据非唯一性，导致结果波动较大。可复现性受限于专有模型的 API 访问与网络环境，开源模型在 4×NVIDIA H20 GPU 上运行，但超参数细节未完全公开。指标仅关注最终答案准确率，未量化搜索效率或轨迹长度，可能掩盖了模型在无效循环中的计算开销。

## 关联研究分析

从问题动机看，InterLV-Search 与 VisBrowse 的核心差异在于视觉证据的功能定位。VisBrowse 将视觉浏览视为获取答案的手段，视觉信息是静态的“端点”；而 InterLV-Search 将视觉信息视为动态的“枢纽”，其内容直接决定下一步搜索动作。这一差异源于任务复杂度的提升：VisBrowse 侧重单步视觉定位，而 InterLV-Search 要求多步状态转移。根源在于现有基准未区分“视觉理解”与“视觉控制”，导致无法评估智能体在长时序搜索中维持视觉-文本交错状态的能力。

从方法设计看，InterLV-Search 与 MMSearch-R1 等开源智能体的对比揭示了架构与任务的错配。MMSearch-R1 基于强化学习优化搜索策略，但在 InterLV-Search 中性能下降，表明其训练数据缺乏多模态交错样本，导致视觉接地能力薄弱。相比之下，专有模型如 Gemini-3.1-Pro 凭借更强的通用推理能力，在 Level 3 中表现更优，但仍低于 50%。这暗示当前 MLLM 的预训练目标（如对比学习或自回归生成）未充分覆盖“视觉证据作为控制信号”的场景，原生统一架构的深层对齐优势在动态搜索任务中未能转化为显著的性能提升，可能因为搜索任务更依赖工具调用逻辑而非单纯的表征质量。

## 总结

本文核心矛盾在于现有基准无法评估视觉证据在搜索轨迹中的控制作用，导致多模态智能体在开放世界中的动态检索能力被低估。切入点在于形式化“视觉枢纽”概念，通过三级渐进式基准强制视觉证据参与搜索决策。InterLV-Search 构建了 2,061 个实例，证明当前最强模型 Gemini-3.1-Pro 在 Level 3 中仅达 51.06% 准确率，且多分支任务性能显著下降。边界在于 Level 3 的开放网络噪声导致结果不稳定，且缺乏对搜索效率的量化。当视觉证据的细粒度线索（如微小标志）成为唯一搜索线索时，当前模型的视觉枢纽识别准确率是否随线索复杂度呈非线性下降，论文未给出回答。
