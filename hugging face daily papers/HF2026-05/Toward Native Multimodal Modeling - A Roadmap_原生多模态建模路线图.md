# HuggingFace最新推荐论文 ｜Toward Native Multimodal Modeling: A Roadmap ｜原生多模态建模路线图

研究机构：清华大学、英国华威大学

作者：Siyu An、Junru Lu、Junnan Dong 等 21 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.25343)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.25343)

> 统一多模态理解与生成旨在单一架构内融合视觉理解与图像生成，但早期级联架构缺乏双向交互，难以产生涌现能力。现有研究虽确立了离散 Token 化范式，却暴露出理解与生成在表征空间中的根本冲突，且架构设计空间碎片化，缺乏形式化定义。本文通过区分中融合与早融合架构，并结合输入输出对偶性建立分类学，系统梳理了从模块化组装到原生收敛的全栈技术路径。该工作提供了结构化认知框架，但未提供统一骨干下的重评测数据，其“原生度”定义是否足以区分真正的认知协同仍存疑。

## 研究背景

多模态大语言模型（MLLMs）试图打破文本与视觉的壁垒，但传统级联架构将预训练编码器与冻结语言骨干通过浅层投影器组装，这种“后期融合”设计导致模型对原始感官信号盲目，跨模态交互深度受限。为克服这一局限，原生多模态建模（Native Multimodal Modeling, NMM）应运而生，其核心假设是多模态能力应内化于联合多模态骨干或统一 Transformer 空间中，而非通过外挂模块实现。然而，NMM 的设计空间目前处于碎片化状态，从深度特征注入到统一 Token 化的各种架构选择缺乏统一的形式化标准，阻碍了社区对模型“原生度”的评估及最优架构的选择。

该领域正从单纯的功能集成向认知协同演进，核心矛盾在于理解任务偏好全局语义紧凑表征，而生成任务偏好高频细节重建表征，两者在共享参数上的梯度冲突导致联合训练时性能妥协。主流路线如 Chameleon 和 Emu3 通过离散视觉 Token 化确立了 Any-to-Any 范式，但离散化导致高频细节丢失；Janus 等解耦架构虽缓解冲突，却增加了参数冗余。本文切入点在于建立 NMM 的架构形式化与全栈路线图，通过定义中融合与早融合两种原生机制，并基于输入输出对偶性划分功能类别，为工业级部署与算法优化提供统一坐标系。

## 核心方法

### 架构原生度形式化

NMM 的参照系是打破后期融合的模块化限制，但现有文献缺乏对“原生”程度的量化定义。本文引入功能算子来形式化跨模态融合的原生度，区分中融合与早融合两种机制。中融合定义为 $F_{mid} = \text{Backbone}(C(E_1(m_1), \dots, E_n(m_n)))$，其中 $C$ 为跨模态对齐算子，特征注入联合骨干中间层，模型保持显式模态边界；早融合定义为 $F_{early} = \text{Transformer}([T(m_i)]_i)$，所有模态经统一算子 $T$ 映射至共享嵌入空间，实现 Born-Native 状态。这一形式化解决了此前架构分类模糊的问题，明确了从“洞察但模态感知”到“全模态等价”的演进路径。

### 输入输出对偶性分类

在架构深度之外，本文通过输入输出模态流建立正交分类维度，将 NMM 生态划分为三类。多模态到文本（M2T）形式化为 $F_{M2T}: M \rightarrow T$，聚焦跨模态理解与文本推理，瓶颈在于感知接地；多模态到目标（M2G）形式化为 $F_{M2G}: M \rightarrow y_k$，通过原生表示直接合成非文本模态，强调语义连贯性；多模态到多模态（M2M）形式化为 $F_{M2M}: M_{in} \rightarrow M_{out}$，实现对称输入输出，消除感知器与渲染器的分离。该分类体系解决了单一架构难以覆盖全谱系模态流的问题，使研究者能根据任务特性（如实时流式或离线生成）精准定位技术瓶颈，例如 M2G 需解决离散化信息损失，而 M2M 需处理理解与生成的双向增益。

## 实验评估

该论文为综述性质，未提供本文方法在具体基准上的实验数值，【论文实验数据】区为空，故不输出实验表格。基线覆盖审计显示，本文 Table 1 涵盖了 Qwen、Llama、InternVL 等主流 M2T 模型及 BAGEL、Transfusion 等 M2M 模型，但缺乏统一骨干与统一预训练条件下的重评测数据。据领域综述，BAGEL 在 MMBench 上得分 87.76，与专用 VLM Qwen2.5-VL-7B 持平，表明统一模型在理解能力上已接近专用模型，但在 GenEval 上 UniDFlow 以 0.95 领先，显示混合架构在生成质量上的优势。本文未提供此类对比，其有效性取决于分类学的完备性而非算法性能。

设计决策验证方面，本文指出离散 Token 化是 M2M 模型的核心瓶颈，导致高频细节丢失，而连续潜空间路线在生成保真度上更优。然而，本文未提供消融实验来量化中融合与早融合在特定任务上的性能差异，也未验证“原生度”形式化对模型选择的具体指导意义。评估边界与可复现性方面，本文提供了代码 URL（https://nmm-roadmap.github.io），但缺乏超参数与 GPU 配置细节。指标完备性上，现有基准多孤立评估理解或生成，缺乏衡量“协同效应”的统一标准，本文提出的时间感知协议与效率感知协议尚处于概念阶段，未在实际模型上验证。

## 关联研究分析

从问题动机看，本文与 Janus 等解耦架构路线存在根本差异。Janus 通过物理分离编码器缓解梯度冲突，侧重性能平衡，而本文强调架构原生度的形式化，旨在建立统一的评估坐标系。这种差异源于任务特性：Janus 针对特定任务的性能优化，而本文面向领域整体认知地图的构建。然而，本文未探讨中融合与早融合在性能上的本质差异，缺乏统一骨干下的重评测，这使得其分类学可能掩盖了架构选择对最终性能的影响。

从方法设计看，本文与 Transfusion 等混合 AR-Diffusion 路线在解决离散化信息损失上具有一致性，但本文将其置于 M2G/M2M 的功能分类中，而非独立的算法路线。Transfusion 通过混合训练策略结合自回归与扩散目标，而本文将其视为早融合范式下的具体实现。这种视角差异源于本文的综述性质，其关注点在于架构拓扑而非训练策略。然而，本文未深入分析混合目标在 M2M 对称建模中的具体实现细节，如 BAGEL 的 Mixture-of-Transformers 架构如何具体解决理解与生成的双向增益，这使得其路线图在算法层面略显抽象。

## 总结

本文要解决的核心矛盾是 NMM 设计空间的碎片化与缺乏形式化定义，现有方法虽确立了离散 Token 化范式，但未能提供统一的架构评估标准。本文抓住的切入点是架构原生度与输入输出对偶性的正交分类，通过定义中融合与早融合机制，建立了从模块化组装到原生收敛的结构化认知框架。本文做了什么：形式化 NMM 架构分类学，并整合工业级全栈视角，包括数据课程、训练策略与推理部署。证明了什么：该分类学能清晰区分 M2T、M2G 与 M2M 三类功能范式，为模型选择提供理论依据。本文的边界在于缺乏统一骨干下的重评测数据，未量化架构选择对性能的具体影响，且“原生度”定义是否足以区分真正的认知协同与架构统一仍存疑。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
