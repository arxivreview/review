论文原文见 [arXiv](https://arxiv.org/abs/2605.27268)

> 大语言模型（LLMs）生成文本的同质化常被归因于训练数据或模型知识，但解码阶段的采样截断机制如何具体削减词汇多样性，缺乏定量诊断工具。现有多样性指标多为事后统计，无法区分模型“知道”但“无法生成”的词汇，导致无法定位解码策略对长尾词汇的数学剔除行为。本文提出词汇覆盖率分数（Word Coverage Score, WCS），通过强制路径审计模拟自回归生成过程，量化标准采样过滤器对特定人类词汇的可达性。该指标揭示了行业默认解码参数作为“无意审查机制”的效应，但仅测量二元排除，未捕捉概率抑制的软性侵蚀。

## 研究背景

自回归语言模型在每一步预测时，需从词表中选择下一个 Token。为维持局部连贯性，Top-p 和 Top-k 等截断策略通过保留高概率 Token 集合来过滤长尾噪声。然而，这种局部概率控制假设单步合理性可保证全局质量，忽略了当前 Token 选择对后续条件分布的状态依赖影响。当模型进入长程生成时，内部状态空间的动态演化可能导致宏观语义重复，即模式坍缩（Mode Collapse）。对齐训练（如 RLHF）进一步加剧了这一现象，通过偏好优化使模型倾向于输出标注者偏好的“安全”序列，压缩了输出分布的多样性。

现有研究多聚焦于模型知识或训练数据对多样性的影响，而解码机制作为推理时的直接控制变量，其具体作用被忽视。传统多样性指标如 Distinct-n 仅统计生成文本的词汇重复率，无法区分是模型缺乏词汇知识，还是采样过滤器在数学上剔除了这些词汇。这种诊断盲区导致无法评估不同采样参数（如温度、截断阈值）对词汇可达性的具体影响。本文切入点在于将解码过程视为一个“强制路径”问题，通过审计特定人类词汇在自然语境下的 Token 存活率，建立解码参数与词汇损失之间的定量联系，从而隔离解码机制对语言多样性的独立贡献。

## 核心方法

### 方法参照系

多样性评估通常采用事后统计指标，如 Distinct-n 或 MAUVE，计算生成文本的词汇或语义分布特征。本文问题与该通用流程的关键差异在于：它不评估生成结果的统计属性，而是评估生成过程的“可达性”，即特定目标词汇在给定解码约束下是否可能被采样到。这要求从“结果统计”转向“过程审计”。

### 强制路径审计与存活函数

标准采样方法在每一步根据概率分布截断词表，但无法追溯特定词汇被剔除的具体步骤。本文引入强制路径审计（Forced-Path Audit），给定人类参考序列 $S$ 中的目标词 $w$（由 $n$ 个子词 Token $t_1, ..., t_n$ 组成），模型在真实前缀上下文 $C$ 下强制遍历路径 $w$。在每一步 $i$，提取完整概率分布 $P(\cdot | C, t_1, ..., t_{i-1})$，记录目标 Token $t_i$ 的排名和概率，判断其是否存活于采样过滤器中。

设计动机：解决传统指标无法区分“模型不知道”与“模型知道但被过滤”的问题。通过强制遍历，WCS 能够精确识别解码机制对词汇的数学剔除行为。

$$
R(w, C, \theta) = \prod_{i=1}^{n} \mathbb{1}[t_i \in V_{\theta}(P(\cdot | C, t_1, ..., t_{i-1}))]
$$

其中 $V_{\theta}$ 为采样参数 $\theta$ 下的存活词表，$\mathbb{1}[\cdot]$ 为指示函数。该公式表明，只有当目标词的所有子词 Token 在各自步骤均存活时，该词才被覆盖（$R=1$）。

### 词汇覆盖率分数与频率带限选择

WCS 定义为目标词集 $W$ 在上下文集 $C_w$ 下的平均可达性：

$$
WCS(\theta) = \frac{1}{|W|} \sum_{w \in W} \frac{1}{|C_w|} \sum_{C \in C_w} R(w, C, \theta)
$$

该公式聚合了所有词-上下文对的二元存活结果，生成词汇衰减曲线，反映采样参数对词汇丰富度的影响。

设计动机：避免高频功能词（可达性高）和极低频噪声词（训练不足）干扰评估。本文采用频率带限随机采样，从 Google Web Trillion Word Corpus 中选择排名 10,000 至 40,000 的“中长尾”词汇，确保评估对象为“高级但非罕见”的人类用法。上下文选自 PG-19 数据集，通过 Gemini-2.5-flash 进行零样本连贯性验证，确保语境自然性。

## 实验评估

实验使用 PG-19 数据集作为上下文源，评估 Llama、Mistral、Qwen、Gemma 和 DeepSeek 等开源模型的 Base 与 Instruct 变体。基线覆盖 Top-p、Top-k 和 Min-p 三种主流采样器，但缺失几何感知解码（如 Top-W）或动态解码控制（如 BACO）等强基线，限制了与最新解码策略的横向对比。

| 模型 / 家族 | 默认设置 | 可达词汇比例 | 被擦除词汇比例 | WCS |
| :--- | :--- | :--- | :--- | :--- |
| Qwen2.5-14B-Instruct | $p=0.8, k=20, T=0.7$ | 0.57 | 43% | 0.144 |
| Llama-3.1-8B-Instruct | $p=0.9, T=0.7$ | 0.69 | 31% | 0.230 |
| Gemma-4-E4B | $p=0.95, k=64, T=1.0$ | 0.78 | 22% | 0.173 |
| Gemma-4-E4B-it | $p=0.95, k=64, T=1.0$ | 0.43 | 57% | 0.059 |
| DeepSeek-R1-Distill-Qwen-14B | $p=0.95, T=0.7$ | 0.63 | 37% | 0.160 |

在行业默认设置下，22% 至 57% 的目标词汇在至少一个上下文中不可达。Gemma-4-E4B-it 表现最差，其 WCS 仅为 0.059，远低于其 Base 版本的 0.173，表明对齐过程显著加剧了词汇侵蚀。平均而言，Base 模型的词汇可达性为 0.740，Instruct 模型降至 0.728，WCS 从 0.290 降至 0.277，证实了偏好优化对词汇多样性的系统性抑制。

消融分析显示，温度 $T=1.5$ 虽提升了词汇可达性，但许多词汇在部分上下文中仍不可达，验证了“零和博弈”假设：提升多样性需牺牲连贯性。Min-p 采样在保留分布多样性方面优于 Top-k，但未能完全解决长尾词汇的剔除问题。Gemma 家族在不同代际间表现不一致，Gemma-3-12B-it 的词汇侵蚀低于其 Base 版本，而 Gemma-4-E4B-it 则显著恶化，暗示对齐策略或训练数据的变化对词汇保留有非单调影响。

评估边界方面，WCS 仅测量二元排除（$R=0$），未捕捉概率抑制的“软性侵蚀”，即词汇虽在候选池中但概率质量被大幅降低。这导致 WCS 是词汇损失的下界估计。此外，实验未报告置信区间，且未验证 WCS 分数与下游任务质量（如 BLEU 或人类偏好）的相关性。代码已开源，但超参数（如上下文长度 $L=256$）的敏感性分析缺失，限制了结果的可复现性边界。

## 关联研究分析

从问题动机看，WCS 与 BACO（Base-Aligned Collaboration）形成互补。BACO 通过路由机制在 Base 和 Instruct 模型间切换以恢复多样性，而 WCS 提供了词汇层面的定量证据，证实 Base 模型确实保留了更多长尾词汇。然而，WCS 未探索如何利用这种差异进行动态解码，仅停留在诊断层面。BACO 的路线是“干预”，WCS 的路线是“测量”，两者结合可形成“诊断-干预”闭环，但本文未涉及干预策略。

从方法设计看，WCS 与 Geometry-Aware Decoding（Top-W）存在视角差异。Top-W 通过 Wasserstein 距离正则化截断，优化语义邻域内的质量保留，属于“改进解码”路线；WCS 则审计现有解码器的剔除行为，属于“评估解码”路线。Top-W 在 GSM8K 上达到 75.99% 准确率，但其对词汇多样性的影响未被量化。WCS 的强制路径审计假设上下文是固定的，忽略了自回归生成中上下文动态变化的影响，这可能高估或低估实际生成中的词汇可达性。Top-W 的几何视角与 WCS 的可达性概念互补，但两者未在同一框架下对比，缺乏直接可比性。

## 总结

本文核心矛盾在于解码截断机制对词汇多样性的隐性抑制，现有指标无法区分知识缺失与采样剔除。WCS 通过强制路径审计，将解码过程形式化为 Token 存活概率的乘积，量化了标准采样过滤器对中长尾词汇的数学剔除行为。实验表明，行业默认设置下 22%-57% 的词汇不可达，且对齐模型（如 Gemma-4-E4B-it，WCS 0.059）比 Base 模型（WCS 0.173）遭受更严重的词汇侵蚀。本文边界在于 WCS 仅测量二元排除，未捕捉概率抑制的软性效应，且未验证其与下游任务质量的相关性。当上下文长度 $L$ 增加或采样参数动态调整时，WCS 分数是否仍能准确反映词汇可达性，论文未给出回答。
