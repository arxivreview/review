# HuggingFace最新推荐论文 ｜Unlocking Complex Visual Generation via Closed-Loop Verified Reasoning ｜闭环视觉推理

研究机构：中国科学技术大学

作者：Hanbo Cheng、Limin Lin、Ruo Zhang 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.14876)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.14876)

> 文本到图像生成在处理复杂语义时面临单步映射的能力上限，参数扩展的边际收益递减。现有推理增强方法因轨迹验证缺失、长上下文优化不稳定及推理延迟高而难以落地。本文提出闭环视觉推理框架，通过步级验证数据合成、代理提示强化学习及权重合并加速，实现复杂视觉目标的测试时扩展。该框架在组合生成基准上显著优于开源基线，但高频细节保真度与计算开销的平衡仍存疑。

## 研究背景

当扩散模型试图将包含多实体、空间关系及硬约束的长提示一次性映射为像素时，常出现属性混淆或实体缺失。这一现象源于单步生成范式的语义容量瓶颈：模型需在单次前向传播中同时解析全局布局与局部细节，导致复杂语义下的结构退化。为突破此瓶颈，研究者引入思维链（Chain-of-Thought, CoT）推理，将生成过程拆解为多步规划与执行。然而，视觉CoT轨迹的中间步骤往往缺乏严格验证，导致监督信号混杂执行失败案例；同时，交错的多模态长上下文引发信息衰减，使模型在迭代中丢失全局约束。

当前主流路线分为两类：一是基于统一多模态模型（Unified Multimodal Model, UMM）的端到端推理，其参数耦合导致训练成本高且无法独立迭代视觉语言模型（Vision-Language Model, VLM）与扩散模型；二是后验反思式生成，依赖生成后的错误修正而非事前任务分解，最终质量受限于初始步骤。本文切入点在于构建一个解耦的闭环系统，通过状态约束控制器生成可验证的轨迹，利用代理提示机制稳定长上下文下的强化学习优化，并通过权重合并解决多步推理的延迟瓶颈。

## 核心方法

### 方法参照系

本文问题属于推理增强文本到图像生成，区别于传统单步扩散模型，其核心差异在于将生成过程建模为VLM规划与扩散执行的多轮交互闭环，而非单次条件映射。

### 验证轨迹合成与代理提示强化学习

针对现有轨迹数据中扩散执行失败导致的监督污染，本文设计双轨验证机制。被动验证作为步级守门员，在每次生成工具调用后通过动态检查表确认执行成功，失败则丢弃整个轨迹；主动验证由控制器显式调用，检测画布与提示的语义差距并反馈修正。在此基础上，提出代理提示强化学习（Proxy Prompt Reinforcement Learning, PPRL）。设计动机在于标准奖励模型无法评估长交错历史，导致奖励噪声大。PPRL利用基础VLM将长上下文 $\mathbf{c}_t$ 蒸馏为显式可评估的代理提示 $p_{proxy}$，其奖励函数定义为：

$$ R_{proxy} = \alpha R_{T2I}(p_{T2I}, \mathbf{x}_t) + (1-\alpha) R_{I2I}(p_{I2I}, \mathbf{x}_t, \mathbf{I}_{ref}) $$

该公式将全局质量奖励与编辑奖励结合，通过自然语言指令替代直接评估长历史，使扩散模型在KL约束下向高质量分布优化，解决了长上下文优化不稳定的问题。

### 法向-切向解耦权重合并

针对多步推理中重蒸馏数据成本高的部署瓶颈，本文提出$\Delta$-空间权重合并（$\Delta$-Space Weight Merge, DSWM）。设计动机在于直接重蒸馏闭环模型需海量CoT轨迹数据，而现有蒸馏先验仅针对单步生成。DSWM基于法向-切向近似解耦理论，假设蒸馏增量 $\Delta \mathbf{W}_{distill}$ 主要作用于将离流形状态拉回数据流形（法向空间），而对齐增量 $\Delta \mathbf{W}_{Align}$ 主要沿流形表面重分布概率密度（切向空间）。融合权重公式为：

$$ \mathbf{W}_{fused} = \mathbf{W}_{base} + \Delta \mathbf{W}_{distill} + \Delta \mathbf{W}_{Align} $$

该线性叠加避免了破坏性干扰，将每步去噪从28次函数评估降至4次，实现了闭环推理的低延迟部署。

## 实验评估

实验在GenEval、WiseBench、PRISM等五个基准上进行，基线覆盖FLUX.2、Qwen-Image等开源SOTA及Uni-CoT、T2I-R1等推理增强方法，但缺失纯蒸馏加速基线的直接对比。

| 模型 | GenEval Overall | WiseBench Overall | PRISM Overall |
|---|---|---|---|
| FLUX.2 4B base | 0.74 | 0.44 | 65.7 |
| CLVR (4B) | 0.87 | 0.74 | 76.3 |
| FLUX.2 9B base | 0.80 | 0.52 | 72.7 |
| CLVR (9B) | 0.88 | 0.76 | 82.1 |
| GPT-4o | — | 0.80 | 86.3 |

CLVR (9B)在GenEval上达0.88，显著高于FLUX.2 9B基线的0.80，并在WiseBench上接近GPT-4o的0.80上限。

| 设置 | GenEval Overall | WiseBench Overall |
|---|---|---|
| FLUX.2 4B Distill | 0.81 | 0.48 |
| FLUX.2 4B Distill rewrite | 0.78 | 0.64 |
| FLUX.2 4B base + CLVR (w/o PPRL) | 0.78 | — |
| FLUX.2 4B base + CLVR (w PPRL) | 0.83 | — |
| FLUX.2 4B DSWM + CLVR (w PPRL) | 0.87 | 0.71 |

消融显示，仅SFT将GenEval从0.74提升至0.78，加入PPRL后升至0.83，验证了代理提示对长上下文对齐的有效性。DSWM进一步将分数推至0.87，且WiseBench从0.48升至0.71，表明权重合并兼容对齐与蒸馏先验。值得注意的是，开放循环提示重写在GenEval上反而降低分数（0.81至0.78），证实CLVR增益源于任务分解与迭代自修正，而非VLM语义增强。

评估边界方面，论文未报告计算效率的具体延迟数值，仅提及NFE减少；代码未公开，复现依赖Qwen3-VL 8B与FLUX.2 Klein模型的具体版本。

## 关联研究分析

从问题动机看，CLVR与Think-Then-Generate均引入LLM推理，但后者依赖后验反思，而CLVR强调步级主动验证。这一差异根源在于任务特性：复杂组合生成中，初始步骤的错误会级联放大，后验修正无法逆转已生成的错误结构，而步级验证能在错误发生前拦截。UniReasoner同样采用草稿-评估流水线，但其自我批评机制缺乏对扩散执行失败的显式过滤，导致训练数据中混杂无效轨迹，CLVR的双轨验证机制直接解决了这一数据质量瓶颈。

从方法设计看，CLVR与Self-Evaluating Model均关注自评估，但后者聚焦单步生成的全局分布视图，而CLVR侧重多步闭环中的长上下文对齐。CLVR采用解耦的VLM+扩散架构，区别于UMM的单体设计，这使其能独立迭代VLM与扩散模型，但可能牺牲跨模态细粒度交互。DSWM权重合并是本文独有创新，现有推理增强方法多依赖重蒸馏或增加采样步数，DSWM通过法向-切向解耦理论实现了无重蒸馏的加速，这一设计在UMM框架中难以直接迁移，因其参数耦合特性破坏了法向-切向的近似正交性。

## 总结

CLVR旨在解决单步生成在复杂语义下的能力上限与参数扩展边际收益递减的矛盾。其切入点在于通过步级验证消除轨迹数据中的执行失败污染，并利用代理提示机制将长上下文蒸馏为显式奖励信号，从而稳定多步推理中的强化学习优化。实验证明，CLVR (9B)在GenEval上达0.88，WiseBench上达0.76，显著优于开源基线并接近GPT-4o。然而，论文未报告高频细节保真度的量化指标，且DSWM的理论假设（法向-切向正交性）在极端复杂语义下是否依然成立，缺乏细粒度伪影评估实验的验证。当提示复杂度进一步增加时，代理提示的蒸馏误差是否会累积并导致奖励信号失真，论文未给出回答。
