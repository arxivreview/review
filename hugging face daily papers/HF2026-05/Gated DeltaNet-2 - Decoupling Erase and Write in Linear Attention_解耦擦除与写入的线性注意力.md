# HuggingFace最新推荐论文 ｜Gated DeltaNet-2: Decoupling Erase and Write in Linear Attention ｜解耦擦除与写入的线性注意力

作者：Ali Hatamizadeh、Yejin Choi、Jan Kautz

论文原文见 [arXiv](https://arxiv.org/abs/2605.22791)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.22791)

> 长上下文处理的核心矛盾在于固定状态递归模型在压缩历史时引发的关联干扰，导致精确检索失效。现有Delta规则方法虽引入门控机制，但擦除旧信息与写入新信息共用标量门控，无法独立控制键侧与值侧的更新粒度。本文提出Gated DeltaNet-2，将标量门控解耦为通道级擦除门与写入门，实现细粒度的记忆编辑。该设计在1.3B参数规模下显著提升了检索性能，但其对大规模稀疏架构的替代能力及理论表达力边界仍存疑。

## 研究背景

当模型处理超长序列时，标准自注意力的二次方计算复杂度与键值缓存（KV Cache）的线性内存增长构成双重瓶颈。线性注意力通过固定大小的递归状态替代显式注意力矩阵，将序列混合转化为线性时间递归，但状态作为压缩的键值记忆，迫使大量关联共享有限空间，导致远距离精确检索困难。Delta规则模型通过减去当前读取值再写入新值来缓解这一干扰，但早期实现中擦除与写入受同一标量门控约束，限制了记忆编辑的灵活性。

该领域的主流路线分为状态空间模型（SSM）与Delta规则递归两类。Mamba-2及Mamba-3通过数据依赖衰减调节记忆视界，但未执行主动擦除操作；Gated DeltaNet与KDA引入Delta规则实现定向覆盖，但KDA虽将衰减细化为通道级，其主动编辑门控$\beta_t$仍为标量，同时控制键侧擦除与值侧写入。这种标量绑定意味着模型无法在清除过时关联的同时保留特定值通道，或反之。本文切入点在于识别出擦除与写入在状态矩阵中作用于不同轴（键轴与值轴），将标量门控解耦为独立的通道级向量，以解除这一建模限制。

## 核心方法

### 线性注意力递归参照系

线性注意力递归层维护状态矩阵$\mathbf{S}_t \in \mathbb{R}^{d_k \times d_v}$，通过查询$\mathbf{q}_t$读取输出。标准Delta规则更新为$\mathbf{S}_t = (\mathbf{I} - \beta_t \mathbf{k}_t \mathbf{k}_t^\top) \mathbf{S}_{t-1} + \mathbf{k}_t \mathbf{v}_t^\top$，其中$\beta_t$为标量步长。该流程的关键差异在于，本文问题聚焦于固定状态中多关联干扰导致的检索失效，而通用Delta规则流程未区分擦除与写入的独立控制需求。

### 解耦擦除与写入门控

KDA将衰减$\alpha_t$扩展为通道级向量$\mathbf{\alpha}_t$，但保留标量$\beta_t$控制Delta项。本文指出擦除是键侧操作，决定移除旧读取的哪些坐标；写入是值侧操作，决定提交新值的哪些坐标。Gated Delta Rule-2引入通道级擦除门$\mathbf{b}_t \in [0,1]^{d_k}$与写入门$\mathbf{w}_t \in [0,1]^{d_v}$，更新公式为：

$$
\mathbf{S}_t = (\mathbf{I} - \mathbf{k}_t (\mathbf{b}_t \odot \mathbf{k}_t)^\top) \mathbf{D}_t \mathbf{S}_{t-1} + \mathbf{k}_t (\mathbf{w}_t \odot \mathbf{v}_t)^\top
$$

其中$\mathbf{D}_t = \text{Diag}(\mathbf{\alpha}_t)$。该设计允许模型通过衰减清除广泛上下文，通过擦除门移除特定陈旧关联，通过写入门仅保留应持久的值通道。当$\mathbf{b}_t = \beta_t \mathbf{1}$且$\mathbf{w}_t = \beta_t \mathbf{1}$时，公式退化为KDA；若$\mathbf{\alpha}_t$亦为标量，则退化为Gated DeltaNet。

### 分块并行训练与门感知反向传播

为保持高效训练，本文将累积通道级衰减吸收进秩一擦除因子，推导出紧凑的WY形式。在分块计算中，擦除门通过$\mathbf{E}_{\bar{r}}$行进入，写入门通过$\mathbf{Z}$行进入，其余计算为三角求解与稠密矩阵乘法。反向传播中，由于擦除与写入门控作用于不同通道，标量门控的梯度捷径失效，需引入门感知累积，确保梯度在累加点保留门控因子。该算法保留了KDA分块方程的形状，仅改变辅助矩阵$\mathbf{Y}$与$\mathbf{U}$的构造，实现了与高效Delta规则内核兼容的并行训练。

## 实验评估

实验在1.3B参数模型上进行，训练数据为100B FineWeb-Edu tokens，训练长度4K，混合模型使用2K滑动窗口注意力（SWA）。基线覆盖Mamba-2、Gated DeltaNet、KDA、Mamba-3（SISO/MIMO）及Transformer，但缺失同规模稀疏注意力基线（如NSA）。

| 模型 | WikiText PPL | LAMBADA PPL | 常识推理 Avg. Acc. |
| :--- | :--- | :--- | :--- |
| Mamba-2 | 16.79 | 12.38 | 51.82 |
| KDA | 16.45 | 11.66 | 52.28 |
| Mamba-3 (MIMO) | 16.40 | 11.89 | 52.07 |
| Gated DeltaNet-2 | 15.90 | 11.41 | 53.11 |

Gated DeltaNet-2在递归模型中取得最低困惑度与最高常识推理平均分，表明解耦门控提升了记忆编辑效率。在RULER检索任务中，Gated DeltaNet-2在MK-NIAH-1@4K上达到37.8%，显著高于KDA的27.2%与Mamba-3 (MIMO)的27.8%，验证了其在多键干扰场景下的优势。

| 消融变体 | WikiText PPL | MK-NIAH-1@4K |
| :--- | :--- | :--- |
| w-only, scalar $b_t$ | 16.55 | 30.6 |
| b-only, scalar $w_t$ | 16.12 | 35.2 |
| Gated DeltaNet-2 | 15.90 | 37.8 |
| Expanded $b_t \in [0,2]^{d_k}$ | 15.95 | 37.6 |

消融显示，仅解耦写入门或仅解耦擦除门均带来性能提升，但双门解耦效果最佳。将擦除门范围扩展至[0,2]未带来显著增益，表明[0,1]范围已足够捕捉擦除需求。

评估边界方面，论文未报告置信区间，且仅在1.3B规模验证，未覆盖更大参数规模。代码已开源，但内核实现细节（如Triton调度）在补充材料中，主文未提供完整复现步骤。

## 关联研究分析

从问题动机看，本文与Mamba-3路线形成鲜明对比。Mamba-3通过指数梯形离散化与复数状态转移增强递归表达力，但未执行主动擦除，其状态更新为衰减加写入，无法定向移除过时关联。本文的Delta规则解耦直接针对关联干扰，通过擦除门实现键侧选择性清除，这在Mamba-3的框架中缺乏对应机制。这一差异源于任务特性：Mamba-3侧重长程依赖的平滑建模，而本文聚焦精确检索中的干扰控制。

从方法设计看，本文与KDA同属Delta规则家族，但KDA的通道级衰减仅作用于状态保持，而本文的通道级门控作用于主动编辑。KDA的标量$\beta_t$绑定擦除与写入，导致模型在清除过时关联时可能同时削弱新值的写入强度，或反之。本文的解耦允许模型独立控制这两个过程，例如在长上下文检索中，模型可高擦除低写入以清除噪声，或低擦除高写入以强化关键信息。这种细粒度控制在KDA中无法实现，是本文性能提升的核心来源。

## 总结

本文解决的核心矛盾是固定状态递归模型中擦除与写入的标量绑定导致的关联干扰。现有方法如KDA虽引入通道级衰减，但主动编辑门控仍为标量，无法独立控制键侧擦除与值侧写入。本文通过解耦为通道级擦除门与写入门，实现了细粒度的记忆编辑，并在1.3B规模下将MK-NIAH-1@4K准确率从27.2%提升至37.8%。其边界在于实验仅覆盖1.3B参数规模，且未与同规模稀疏注意力基线对比，无法证明递归层在大规模场景下对全注意力的替代能力。当模型规模扩展至10B以上时，通道级门控的参数量增加是否会导致推理延迟显著上升，论文未给出回答。
