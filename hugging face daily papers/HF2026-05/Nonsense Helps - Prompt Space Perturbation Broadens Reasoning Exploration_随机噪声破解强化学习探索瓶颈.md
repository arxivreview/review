# HuggingFace最新推荐论文 ｜Nonsense Helps: Prompt Space Perturbation Broadens Reasoning Exploration ｜随机噪声破解强化学习探索瓶颈

研究机构：美国圣路易斯华盛顿大学

作者：Langlin Huang、Chengsong Huang、Jinyuan Li 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.05566)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.05566)

> 基于可验证奖励的强化学习（RLVR）在提升大语言模型（LLM）推理能力时，常因采样响应全部失败导致相对优势归零，使训练信号丢失。单纯增加采样预算无法突破当前策略的局部最优，因为模型在困难问题上的输出分布高度集中。本文提出 Lorem Perturbation for Exploration (LOPE)，通过在重采样阶段向提示词前缀注入无意义的伪拉丁文序列，强制模型探索正交推理路径。该方法在多个数学基准上显著优于标准 GRPO 与朴素重采样，但其有效性高度依赖扰动序列的低困惑度特性，且仅验证了数学推理场景。

## 研究背景

当 LLM 在复杂推理任务中生成响应时，若所有采样结果均错误，基于组相对策略优化（GRPO）的训练算法会因奖励向量全零而导致梯度消失。这一现象被称为“零优势问题”，它直接浪费了计算资源并阻碍模型在困难样本上的学习。为理解此问题，需明确 GRPO 的核心机制：它通过比较同一查询下多个响应的相对正确性来计算优势值，从而避免使用独立的价值模型。然而，这种相对性意味着当所有响应都失败时，相对优势坍塌为零，模型无法从这些样本中提取任何改进信号。

RLVR 已成为后训练的核心范式，旨在通过自主探索提升模型在数学与代码任务上的鲁棒性。主流解决方案包括自适应 rollout 预算分配，即对困难问题增加采样次数。然而，这一方法存在根本局限：若问题对当前策略而言过于困难，增加采样次数仍难以获得正确响应，因为模型被困在局部推理盆地中。现有研究多关注 logit 空间的探索（如提高采样温度），但实验表明，高温度采样虽增加了输出熵，却往往引入过多噪声，损害推理质量，且未能有效解锁新的推理路径。

本文的切入点在于区分 logit 空间扰动与 prompt 空间扰动。先前研究指出，输入上下文的修改会隐式改变 LLM 的输出分布。本文假设，通过在提示词中引入任务无关的随机噪声，可以轻微偏移模型的输出分布，使其跳出局部最优，发现标准重采样无法触及的正交推理轨迹。这一假设基于 Lorem Ipsum 的特性：它模仿自然语言的统计属性但不携带语义内容，从而在不引入误导性事实的前提下，实现纯粹的分布扰动。

## 核心方法

### 方法参照系

标准 GRPO 流程中，对于每个查询 $q$ 和提示词 $p$，从旧策略 $\pi_{\theta_{old}}$ 采样 $G$ 个响应，计算组内归一化优势并更新策略。本文问题与该通用流程的关键差异在于：当所有 $G$ 个响应均失败时，标准流程丢弃该批次，而 LOPE 在此时触发重采样机制，并引入 prompt 空间扰动以恢复训练信号。

### Prompt 空间扰动重采样

在标准 rollout 阶段，若所有 $G$ 个响应均失败，LOPE 向原始提示词 $p$ 前缀添加一段随机生成的 Lorem Ipsum 序列 $\delta$，形成扰动提示词 $\delta \oplus p$。随后，使用扰动提示词重采样 $G'$ 个响应。这一设计动机在于解决朴素重采样因策略局部最优导致的低成功率问题。通过引入无语义噪声，模型被强制偏离原有的高置信度生成路径，探索潜在的替代推理轨迹。扰动序列长度在 100 至 300 tokens 之间均匀采样，并在末尾附加边界指令以防止输出损坏。

### 训练信号整形

重采样响应与原始失败响应混合后，直接进行优势计算会导致偏差，因为重采样响应是在不同上下文（$\delta \oplus p$）下生成的，而训练时使用的是原始上下文（$p$）。为修正这一 off-policy 偏差，LOPE 引入训练信号整形，包含策略整形与优势整形。策略整形通过调整重要性采样比率来放大低概率 token 的梯度权重，避免关键推理步骤被低估。优势整形则基于完整的 $G + G'$ 个响应计算归一化统计量，而非仅基于选中的 $G$ 个响应，以真实反映问题难度并放大稀有成功样本的奖励信号。

$$
\mathcal{J}(\theta) = \mathbb{E}_{q \sim \mathcal{D}, \{o_i\}_{i=1}^G \sim \pi_{\theta_{old}}(\cdot|p, q)} \left[ \frac{1}{G} \sum_{i=1}^G \min\left( \rho_{i,t} \hat{A}_i, \text{clip}(\rho_{i,t}, 1-\epsilon, 1+\epsilon) \hat{A}_i \right) \right] + \mathbb{E}_{q \sim \mathcal{D}, \{o'_j\}_{j=1}^{G'} \sim \pi_{\theta_{old}}(\cdot|\delta \oplus p, q)} \left[ \frac{1}{G'} \sum_{j=1}^{G'} f(\rho'_{j,t}) \hat{A}'_j \right]
$$

该公式表示 LOPE 的完整训练目标，第一项为标准 GRPO 更新，第二项为经策略整形 $f(\rho'_{j,t})$ 和优势整形 $\hat{A}'_j$ 处理的重采样响应更新。

## 实验评估

实验在 Qwen3-1.7B-Base、Qwen3-4B-Base 和 Qwen2.5-Math-7B 三个基座模型上进行，使用 OpenR1-Math-46k-8192 数据集训练，评测基准包括 MATH-500、GSM8K、AMC、AIME 2024 和 AIME 2025。基线对比涵盖标准 GRPO 和朴素提示词重采样，但缺失与其他 prompt 工程方法（如 CoT 变体）或不同温度采样策略的直接对比。

LOPE 在 Qwen3-4B-Base 上平均得分 53.99，较标准 GRPO 提升 4.62 分，较朴素重采样提升 5.04 分。值得注意的是，朴素重采样在 Qwen3-4B-Base 上性能低于标准 GRPO，这可能源于移除 KL 正则化后的策略漂移，而 LOPE 通过引入高变异性响应起到了隐式正则化作用。

消融实验显示，训练信号整形对 Qwen2.5-Math-7B 模型至关重要，使其平均得分从 47.32 提升至 53.88，增幅达 6.56 分。这表明在较大模型上，off-policy 更新带来的优化效率损失更为显著，需通过信号整形放大稀有成功样本的学习信号。此外，不同扰动方法的对比表明，低困惑度的拉丁文序列（如 LOPE、Filtered Latin Natural Language）性能最佳，而高困惑度的随机 Token 甚至损害训练，证实了“适度扰动”的必要性。

评估边界方面，论文仅报告了数学推理基准，未涵盖常识推理或代码生成任务，限制了结论的泛化性。可复现性方面，代码已开源，超参数（如 $G=8, G'=24$）明确，但扰动序列的具体生成细节（如词汇表大小）仅提及使用 python-lorem 包，未提供完整配置。

## 关联研究分析

从问题动机看，LOPE 与 LTPO 均旨在通过优化输入或潜在空间提升推理能力，但机制截然不同。LTPO 在潜在空间优化隐式思维向量，依赖模型内部表征的可微分性，适用于具有明确奖励信号的任务；而 LOPE 在显式文本空间引入随机噪声，不依赖模型内部结构，仅利用上下文对输出分布的隐式影响。这一差异源于 LOPE 针对的是训练时的探索瓶颈，而非推理时的计算效率，因此无需复杂的梯度优化，简单的文本扰动即可打破局部最优。

从方法设计看，LOPE 与 Self-Consistency 均通过多次采样提升鲁棒性，但应用场景相反。Self-Consistency 在推理时通过多数投票降低随机误差，假设多次采样能覆盖正确路径；而 LOPE 在训练时通过扰动重采样恢复训练信号，假设标准采样无法覆盖正确路径，需通过分布偏移解锁新路径。这一差异揭示了 LLM 推理的两个不同失效模式：推理时的随机性误差与训练时的探索不足。LOPE 的有效性依赖于数学任务的结构化特性，即存在明确的正交推理路径，而在常识推理等非结构化任务中，随机噪声可能引入无关信息，导致性能下降，论文未对此进行验证。

## 总结

本文针对 GRPO 中的零优势问题，指出朴素重采样因策略局部最优而失效，提出通过 prompt 空间扰动（LOPE）解锁正交推理路径。实验证明，LOPE 在 Qwen3-4B-Base 上平均提升 4.62 分，在 Qwen2.5-Math-7B 上提升 6.20 分，显著优于标准 GRPO 与朴素重采样。其边界在于仅验证了数学推理任务，且扰动有效性高度依赖低困惑度特性，未探讨在常识推理或代码生成等非结构化任务中的表现。当任务缺乏明确的正交推理路径时，随机噪声是否仍能带来增益，论文未给出回答。
