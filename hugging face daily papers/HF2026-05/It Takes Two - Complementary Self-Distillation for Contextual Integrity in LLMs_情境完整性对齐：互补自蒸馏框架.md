> 个人智能体在处理敏感工作流时，核心挑战已从“信息是否保密”转变为“披露是否情境适当”。现有对齐方法将任务效用与隐私约束压缩为单一标量目标，导致模型在抑制无关信息时损害任务完成能力，或在追求任务完成时过度披露。SELFCI 通过联合优化两个独立的反向 KL 散度，利用模型自身生成的反馈构建互补教师策略，将隐私与效用约束在概率分布的交集上。该框架在多个骨干模型上显著提升了情境完整性（Contextual Integrity, CI）对齐效果，但其泛化性受限于合成基准，且未验证在真实多模态或长上下文场景下的鲁棒性。

## 研究背景

当 LLM 作为个人智能体处理酒店预订任务时，它需要利用入住日期（允许集 $A_T$）完成任务，同时抑制护照号码（禁止集 $D_T$）的泄露。这种“选择性保留”与“情境性抑制”的需求构成了情境完整性（Contextual Integrity, CI）的核心定义：隐私并非绝对保密，而是信息流动符合特定情境规范。CI 要求模型对 $D_T$ 保持分布不变性，对 $A_T$ 保持敏感性，这比传统的差分隐私（Differential Privacy, DP）更细粒度，比记忆控制更复杂。

现有对齐方法难以满足 CI 的联合要求。监督微调（SFT）提供密集监督但存在暴露偏差，且构建合规轨迹成本高昂；在线强化学习（RL）如 CI-RL 使用标量奖励，将任务成功与披露合规纠缠在一起，信号过于粗糙，无法区分每个属性的具体传输规范。这两种方法都面临结构性约束：将 CI 的非对称要求（利用必要信息 vs. 抑制无关信息）简化为单一整体目标，导致模型在隐私与效用之间摇摆，无法同时实现高完整性与高效用。

本文的切入点是将 CI 对齐重构为“情境依赖不变性”问题。理想状态下，模型预测分布应对 $D_T$ 的注入保持不变，同时对 $A_T$ 保持响应。这一视角要求对齐机制不仅提供标量偏好信号，还需明确区分哪些上下文线索应影响生成，哪些应被忽略。SELFCI 通过自蒸馏框架，利用模型自身生成的反馈作为特权上下文，构建两个专门化的教师策略，分别促进任务完整性和最小披露，从而解耦保留与抑制压力。

## 核心方法

### 方法参照系

CI 对齐通常被置于“推理时可控生成”或“对齐训练”的通用框架下。标准流程包括：定义隐私-效用权衡指标（如完整性、效用、完整度），选择优化算法（SFT 或 RL），并在合成或真实基准上评估。本文的关键差异在于，它不依赖外部教师或标量奖励，而是通过自蒸馏机制，利用模型自身参数构建互补教师，将 CI 的非对称结构显式编码到优化目标中。

### 反馈生成与教师构建

SELFCI 首先通过反馈生成模块，引导模型解释每个属性应保留或抑制的原因。对于任务 $T$，模型基于传输规范（如保密性、相关性）生成允许集 $A_T$ 和禁止集 $D_T$ 的反馈 $f_{\text{allow}}$ 和 $f_{\text{disallow}}$。这些反馈不是新信息，而是对已有披露决策的规范化解释，确保反馈锚定在属性分区上，同时暴露每个属性的情境相关性。

基于反馈，SELFCI 构建两个反馈条件化的教师策略。效用导向教师 $\pi_{\text{allow}}$ 以 $f_{\text{allow}}$ 为条件，引导模型恢复任务所需信息；隐私导向教师 $\pi_{\text{disallow}}$ 以 $f_{\text{disallow}}$ 为条件，惩罚依赖受限信息的响应。两个教师共享同一模型参数，但通过不同的反馈条件化，形成互补的偏置。

$$
\pi_{\text{allow}}(\cdot \mid x_T, y_{<t}) = \pi_\theta(\cdot \mid x_T, f_{\text{allow}}, y_{<t}), \quad \pi_{\text{disallow}}(\cdot \mid x_T, y_{<t}) = \pi_\theta(\cdot \mid x_T, f_{\text{disallow}}, y_{<t})
$$

这一设计解决了此前方法中“单一信号掩盖非对称结构”的失效。通过显式分离保留与抑制信号，SELFCI 避免了模型在优化过程中将任务完成与隐私合规混淆，从而在训练初期就能建立清晰的边界。

### 联合优化与 PoE 目标

SELFCI 通过联合优化两个反向 KL 散度，将学生策略对齐到两个教师的交集。优化目标为：

$$
\mathcal{L} = \lambda D_{\text{KL}}(\pi_\theta(\cdot \mid x_T, y_{<t}) \| \pi_{\text{allow}}(\cdot \mid x_T, y_{<t})) + (1-\lambda) D_{\text{KL}}(\pi_\theta(\cdot \mid x_T, y_{<t}) \| \pi_{\text{disallow}}(\cdot \mid x_T, y_{<t}))
$$

其中 $\lambda$ 控制任务完整性与最小披露的相对权重。在固定教师分布下，该目标等价于匹配一个专家乘积（Product-of-Experts, PoE）目标，其概率质量集中在两个教师共同支持的区域。这一区域对应既任务完整又最小披露的响应，从而将 CI 对齐转化为对概率分布交集的优化。

$$
\pi_{\text{PoE}}(\cdot \mid x_T, y_{<t}) \propto \pi_{\text{allow}}(\cdot \mid x_T, y_{<t})^\lambda \pi_{\text{disallow}}(\cdot \mid x_T, y_{<t})^{1-\lambda}
$$

PoE 目标的关键价值在于，它避免了单一目标导致的“过度宽松”或“过度保守”失效。通过乘法形式，只有同时被两个教师支持的 token 才获得高概率，从而锐化目标分布，确保模型在生成时严格遵循情境规范。

## 实验评估

实验在 CI-RL（域内）和 PrivacyLens（域外）基准上进行，基线包括初始模型、CI-RL（在线 RL）和 ContextDistill（离线 SFT）。CI-RL 使用 GRPO 优化标量奖励，ContextDistill 使用外部大模型生成轨迹。SELFCI 在 Qwen2.5-7B-Instruct 上将完整性从 35.34 提升至 83.56，完整度从 23.29 提升至 53.42，同时保持效用竞争力。在推理模型 Qwen3-4B 上，完整性从 32.88 提升至 82.19，完整度从 26.03 提升至 57.26，且效用达到最高值 69.32。

| 模型 | 方法 | 完整性 (↑) | 效用 (↑) | 完整度 (↑) |
|---|---|---|---|---|
| Qwen2.5-7B-Instruct | Initial | 35.34 | 61.10 | 23.29 |
| | CI-RL | 68.22 | 66.85 | 43.29 |
| | ContextDistill | 73.70 | 64.38 | 43.01 |
| | SELFCI | **83.56** | 62.19 | **53.42** |
| Qwen3-4B | Initial | 32.88 | 75.34 | 26.03 |
| | CI-RL | 41.10 | 67.67 | 26.85 |
| | ContextDistill | 70.68 | 59.18 | 43.29 |
| | SELFCI | **82.19** | 69.32 | **57.26** |

消融实验显示，反馈条件化教师比关键词条件化教师更有效。在 Qwen3-4B 上，使用反馈的 SELFCI 完整度为 57.26，而使用关键词的变体仅为 45.21，差距达 12.05 个百分点。这表明粗粒度关键词在长生成过程中诱导的教师分布信息量不足，而反馈提供了更丰富的上下文以塑造教师分布。此外，SELFCI 的训练效率显著高于 CI-RL，每个步骤的 GPU 时间减少近一半，因为 SELFCI 每个提示只需一次 rollout，而 CI-RL 需要 16 次。

评估边界方面，CI-RL 和 PrivacyLens 均为合成或半合成基准，可能无法完全反映真实部署中的复杂情境。PrivacyLens 使用 GPT-5-mini 作为 LLM-as-a-Judge 评估任务完成度，其可靠性依赖于评判模型的能力。可复现性方面，论文提供代码链接，使用 LoRA（秩 32，缩放因子 64）和 AdamW（学习率 $1 \times 10^{-6}$），在单张 NVIDIA H200 GPU 上训练 30 个 epoch。

## 关联研究分析

从问题动机看，SELFCI 与 CI-RL（Lan et al., 2024）共享 CI 对齐的目标，但 CI-RL 将隐私-效用权衡压缩为标量奖励，导致模型难以区分每个属性的具体传输规范。SELFCI 通过自蒸馏解耦保留与抑制信号，提供了更细粒度的监督。这一差异源于任务特性：CI 要求情境依赖的决策，而标量奖励无法捕捉这种非对称性。SELFCI 的反馈生成模块通过解释“为什么”保留或抑制，弥补了 CI-RL 中奖励信号的粗糙性。

从方法设计看，SELFCI 与 ContextDistill（离线 SFT）都使用教师策略，但 ContextDistill 依赖外部大模型，存在暴露偏差，即学生模型在测试时生成轨迹与训练分布不一致。SELFCI 使用自蒸馏，教师与学生共享参数，且基于 on-policy 生成，减少了分布偏移。这一设计选择解决了外部教师无法可靠表达情境特定披露规范的问题。然而，SELFCI 未对比差分隐私（DP）基线，尽管 DP 提供形式化保证，但其效用损失在 CI 场景中可能不可接受。论文未提供证据支持这一偏离，仅暗示 DP 不适合 CI 对齐。

## 总结

SELFCI 解决了 CI 对齐中隐私与效用的结构性不对称问题，通过自蒸馏构建互补教师，将 CI 要求转化为概率分布交集的优化。在 Qwen2.5-7B-Instruct 上，完整性从 35.34 提升至 83.56，完整度从 23.29 提升至 53.42，证明了自蒸馏在 CI 对齐上的有效性。然而，实验局限于合成基准和短任务，未验证在真实多模态或长上下文场景下的泛化性。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
