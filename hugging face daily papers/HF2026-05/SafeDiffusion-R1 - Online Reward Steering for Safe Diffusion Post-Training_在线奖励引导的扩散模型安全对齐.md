> 文本到图像扩散模型在抑制不安全内容时，常因静态监督导致生成质量下降或灾难性遗忘。现有离线强化学习与监督微调方法无法适应模型训练过程中的分布漂移，且依赖昂贵的配对数据或专用奖励模型。本文切入点在于将安全对齐重构为在线策略优化问题，通过几何感知的嵌入空间引导机制，在不训练额外分类器的情况下实现动态安全约束。该方法在保持组合生成质量的同时显著降低不安全内容比例，但其对特定安全类别的泛化边界及计算开销仍存疑。

## 研究背景

当扩散模型面对包含敏感语义的提示词时，其生成的图像往往复现训练数据中的不安全关联。这一现象源于模型在大规模网络数据上学习到的多模态表征，使得显式或隐式的有害概念被内化。为阻断此类生成，早期方案依赖输出过滤或数据集清洗，但这些方法要么无法改变模型底层的生成分布，要么在扩展至长尾概念时计算成本过高。因此，后训练模型修改成为主流策略，旨在直接调整预训练权重以擦除不安全概念。

主流的后训练路线分为监督微调与离线强化学习。监督微调依赖人工标注的安全/不安全图像对，而离线强化学习（如DDPO、DPO）则基于预生成的数据优化固定奖励信号。然而，这两者均存在静态监督的固有缺陷：它们不随模型当前生成行为动态调整，导致在训练过程中无法追踪并抑制新涌现的不安全内容，且容易引发灾难性遗忘，损害良性提示的生成质量。此外，离线方法通常需训练专用的安全/不安全分类器作为奖励模型，增加了工程复杂度。SafeDiffusion-R1 针对这一静态监督失效问题，提出在线策略优化框架，使模型在训练过程中实时接收反馈，从而在抑制不安全概念的同时保留通用生成能力。

## 核心方法

### 方法参照系

本文问题归属于扩散模型的后训练安全对齐范畴。标准流程通常采用离线强化学习，即基于预生成的图像-提示对计算固定奖励，并通过策略梯度更新模型参数。本文与标准流程的关键差异在于：将离线静态优化转变为在线动态优化，并引入基于嵌入空间几何特性的奖励引导机制，以消除对专用奖励模型的依赖。

### 几何感知引导奖励

传统方法需训练独立的分类器来判定图像安全性，这引入了额外的计算开销且限制了泛化能力。本文利用 CLIP 嵌入空间的线性可分性，将安全性定义为嵌入空间中的一个方向向量。通过计算安全描述与不安全描述嵌入均值的差值，得到单位安全方向向量 $\mathbf{v}_{safe}$。

$$ \mathbf{v}_{safe} = \frac{\bar{\mathbf{z}}_{safe} - \bar{\mathbf{z}}_{unsafe}}{\|\bar{\mathbf{z}}_{safe} - \bar{\mathbf{z}}_{unsafe}\|} $$

该公式的物理含义是：在语义空间中，安全概念与不安全概念存在一个稳定的几何方向，通过投影即可判断提示词的安全性。对于任意提示词 $c$，其嵌入 $\mathbf{z}_T$ 投影到 $\mathbf{v}_{safe}$ 上的得分 $s_{text}(c)$ 若为负，则判定为不安全。此时，本文不直接惩罚不安全图像，而是将提示词嵌入向安全方向偏移，计算引导后的嵌入 $\tilde{\mathbf{z}}_T = \text{normalize}(\mathbf{z}_T + \alpha \mathbf{v}_{safe})$。最终奖励 $r$ 为图像嵌入 $\mathbf{z}_I$ 与引导后文本嵌入 $\tilde{\mathbf{z}}_T$ 的余弦相似度。这一设计使得模型在优化时，实际上是在学习生成符合“被引导后”的安全语义图像，而非直接学习“不生成”不安全内容，从而避免了显式奖励不安全生成带来的优化不稳定。

### 组相对策略优化

离线强化学习中，不同提示词的奖励尺度差异巨大，导致策略更新时有害概念被过度修正，进而损害无关概念。本文采用组相对策略优化（GRPO）来解决这一尺度失配问题。对于每个提示词 $c_i$，生成 $K$ 个样本 $\{\mathbf{x}_{i,k}\}_{k=1}^K$，计算组内奖励均值 $\bar{r}_i$ 和标准差 $\sigma_i$。

$$ A_{i,k} = \frac{r_{i,k} - \bar{r}_i}{\sigma_i + \delta} $$

该公式通过组内归一化，将绝对奖励转化为相对优势。这意味着策略更新仅取决于同一提示词下不同生成结果之间的相对优劣，而非跨提示词的绝对奖励值。这种机制确保了在抑制不安全概念时，不会因奖励尺度差异而导致模型分布的整体偏移，从而有效缓解了灾难性遗忘，使模型在保持良性生成质量的同时逐步擦除不安全关联。

## 实验评估

实验基于 Stable Diffusion v1.4 进行，使用 I2P 基准评估安全性，GenEval 评估组合生成质量，COCO 评估图像保真度。基线覆盖监督微调（Safe-DPO）、离线强化学习（DDPO）及概念擦除方法（ESD、UCE）。在 I2P 基准上，本文方法将整体不安全率从基线 SD v1.4 的 48.9% 降低至 18.07%，同时 GenEval 组合生成质量从 42.08% 提升至 47.83%。

| 方法 | I2P 不安全率 (%) | GenEval 组合质量 (%) |
| :--- | :--- | :--- |
| SD v1.4 (Base) | 48.9 | 42.08 |
| SafeDiffusion-R1 | 18.07 | 47.83 |

消融实验显示，引导强度 $\alpha$ 对安全性与质量的平衡至关重要。当 $\alpha=0.5$ 时，MeanUnsafe 降至 0.002，而 FID 保持在 98.52，优于仅使用 CLIP 惩罚的 167.49。这表明几何引导在抑制不安全内容方面比直接惩罚更有效，且对生成质量的损害更小。此外，调度器消融实验表明，所有调度器在 300 个 epoch 后均收敛至接近零的不安全分数，证明安全引导机制对推理时调度器选择具有鲁棒性。

评估边界方面，本文未报告 COCO 基准的 FID 数值，仅提供了 I2P 和 GenEval 的结果，限制了与领域 SOTA（如 SP-Guard 的 11.56% 不安全率）的直接对比。可复现性方面，论文提供了 GitHub 链接，并详细列出了超参数（如学习率 $1 \times 10^{-5}$，KL 惩罚系数 0.5），但训练需 72 GPU 小时，计算开销较高。

## 关联研究分析

从问题动机看，SafeDiffusion-R1 与 Safe-DPO 均旨在解决扩散模型的安全对齐，但二者对“动态性”的理解存在根本差异。Safe-DPO 基于固定偏好数据集进行离线优化，其假设是安全约束是静态的，可通过一次性对齐解决。然而，实验表明离线方法在模型演化过程中难以追踪新涌现的不安全内容。SafeDiffusion-R1 则通过在线 GRPO 机制，使奖励信号随模型当前生成行为动态调整，这一设计直接回应了离线方法在分布漂移下的失效问题。差异根源在于任务特性：安全对齐并非一次性任务，而是需要持续适应模型内部表征变化的过程，离线方法的静态监督在此场景下存在结构性缺陷。

从方法设计看，本文与 DDPO 同属强化学习框架，但奖励机制设计截然不同。DDPO 依赖外部训练的奖励模型来评估图像质量与安全性，这引入了额外的模型训练成本且限制了泛化能力。SafeDiffusion-R1 则利用 CLIP 嵌入空间的几何特性，通过简单的向量运算实现安全引导，无需训练专用分类器。这一设计不仅降低了工程复杂度，还增强了模型对域外不安全提示的泛化能力。然而，几何引导的有效性依赖于 CLIP 嵌入空间中安全与不安全概念的线性可分性，这一假设在所有安全类别（如暴力、仇恨）上是否均成立，论文未给出充分验证。

## 总结

SafeDiffusion-R1 旨在解决扩散模型安全对齐中静态监督导致的灾难性遗忘与质量下降矛盾。其切入点在于将安全对齐重构为在线策略优化问题，利用 CLIP 嵌入空间的几何特性实现无需额外奖励模型的安全引导。该方法通过 GRPO 组内归一化稳定训练过程，在 I2P 基准上将不安全率降至 18.07%，同时提升 GenEval 组合质量至 47.83%。然而，实验仅聚焦于裸露类不安全内容，对暴力、仇恨等其他类别的泛化效果未充分验证，且 72 GPU 小时的训练开销限制了其在大规模模型上的可扩展性。当安全类别扩展至非裸露类时，CLIP 嵌入空间的线性可分性假设是否依然成立，论文未给出回答。
