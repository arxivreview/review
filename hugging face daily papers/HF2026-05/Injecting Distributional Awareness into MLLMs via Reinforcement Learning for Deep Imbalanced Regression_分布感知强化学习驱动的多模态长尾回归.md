研究机构：香港科技大学

作者：Yao Du、Shanshan Song、Xiaomeng Li

论文原文见 [arXiv](https://arxiv.org/abs/2605.01402)

> 多模态大语言模型（MLLMs）在长尾连续目标分布下，因Token级监督导致预测向高密度区域坍缩，现有架构修改或点状奖励无法保留全局数值结构。本文指出跨样本关系监督的缺失是核心瓶颈，提出基于组相对策略优化（GRPO）的批量级分布感知奖励机制。该方法通过一致性相关系数（CCC）对齐预测与真值分布的关联、尺度与均值，无需修改模型架构即可缓解回归到均值现象。实验在自建基准上验证了其在稀疏区域的显著增益，但缺乏通用视觉问答基准的交叉验证，其泛化边界尚存疑。

## 研究背景

MLLMs将连续数值序列化为离散Token进行自回归生成，这一过程将回归任务异化为Token级分类。当目标分布呈长尾特征时，交叉熵损失对高频Token的梯度主导优化方向，导致模型忽略低频目标的数值邻近性与全局量级，产生系统性偏差。这种Token化监督与连续回归目标的本质错位，构成了长尾场景下数值预测失效的根源。

现有解决MLLM数值回归的路径主要分为三类：架构修改（如Rex-Omni引入量化坐标Token）、推理增强（如链式思维迭代修正）及损失函数调整（如SoftLabel平滑One-hot）。架构修改破坏了统一生成框架并需重新对齐；推理增强带来高昂延迟；损失调整仍局限于Token或数字位级，无法捕捉连续目标的全球分布结构。主流后训练强化学习（RL）方法如GRPO虽实现了序列级监督，但其奖励设计多为点状标量（如MAE），仅评估单样本误差，缺乏跨样本关系建模，无法抵抗长尾分布下的均值坍缩。

本文切入点在于将长尾回归重构为分布感知学习问题，而非独立的点状预测集合。通过引入批量级关系监督，利用批次内样本间的统计结构作为正则化信号，直接约束预测分布与真值分布的一致性，从而在不改变MLLM骨干架构的前提下，解决点状监督在稀疏区域信号微弱的问题。

## 核心方法

### GRPO基础框架与点状奖励局限

本文采用GRPO作为后训练框架，其核心优势在于无需价值网络（Critic），通过组内相对奖励归一化实现策略更新。在标准GRPO中，针对同一输入采样$K$个生成轨迹，奖励函数$R(y)$通常定义为单样本预测值$y$与真值$y^*$的误差（如MAE）。这种点状监督虽然使预测具备数值感知能力，但每个样本独立评估，优化过程仍倾向于拟合训练数据中的高密度区域，对长尾稀疏目标缺乏纠偏能力。

### 批量级关系向量构建

为解决点状奖励的孤立性，本文在最小批次（Minibatch）内构建关系比较向量。对于批次中第$i$个样本，其第$k$次采样预测$q_k(x_i)$不再单独评估，而是与批次内其他样本$j$的预测均值$\mu(x_j)$配对，形成向量$\mathbf{q}_{i,k} = [q_k(x_i), \mu(x_j)_{j \neq i}]$。同时构建对应的真值向量$\mathbf{y}_i = [y_i, y_j]_{j \neq i}$。这一设计将单点误差评估转化为分布对齐评估，利用批次内其他样本的统计特征作为上下文锚点，使每个预测在群体分布的语境下被评估，从而引入跨样本关系信息。

### CCC分布感知奖励函数

本文采用一致性相关系数（Concordance Correlation Coefficient, CCC）作为核心奖励函数，量化预测向量$\mathbf{q}_{i,k}$与真值向量$\mathbf{y}_i$在分布层面的吻合度。CCC公式如下：

$$
R_{CCC} = \frac{2 \sigma_{qy} \sigma_q \sigma_y}{\sigma_q^2 + \sigma_y^2 + (\mu_q - \mu_y)^2}
$$

其中$\sigma$和$\mu$分别为向量的标准差和均值。该公式同时惩罚方差坍缩（$\sigma_q \to 0$）和均值偏移（$\mu_q \neq \mu_y$），不仅关注线性相关性，还强制预测分布与真值分布在尺度和中心位置上保持一致。相较于仅保留相对排序的Spearman相关系数，CCC对绝对数值量级的约束更强，能有效抑制预测向均值坍缩的退化解，并在稀疏区域放大学习信号。

## 实验评估

实验基于Qwen2.5-VL-3B/7B构建统一长尾回归基准，包含AgeDB、IMDB-WIKI、IMDB-Movie和BoneAge四个数据集，共129k样本。评估协议采用Shot-aware划分，将目标空间分为Many-shot（>100样本）、Medium-shot（20-100）和Few-shot（<20）区域，以MAE和几何均值（GM）衡量精度。基线包括SFT、点状MAE奖励、DISCO难度加权及经典CNN回归模型。

| 数据集 | 方法 | Many-shot MAE | Medium-shot MAE | Few-shot MAE |
| :--- | :--- | :--- | :--- | :--- |
| AgeDB-DIR | SFT | - | 7.67 | 8.36 |
| AgeDB-DIR | CCC-GRPO | - | 5.62 | 6.40 |
| IMDB-Movie-DIR | SFT | - | 11.21 | 21.51 |
| IMDB-Movie-DIR | CCC-GRPO | - | 8.12 | 16.35 |

在AgeDB-DIR上，CCC-GRPO将Medium-shot MAE从7.67降至5.62，Few-shot MAE从8.36降至6.40，且在Many-shot区域性能保持稳定，表明其未以牺牲头部精度为代价换取尾部提升。在IMDB-Movie-DIR上，稀疏区域增益更为显著，Medium-shot MAE从11.21降至8.12，Few-shot MAE从21.51降至16.35。消融实验显示，相较于点状MAE奖励，批量级Spearman和CCC奖励在Medium/Few-shot区域均有提升，其中CCC因同时约束尺度与均值，在整体平衡性上优于仅保留排序的Spearman。

评估边界方面，本文基准为自建数据集，缺乏与MMBench、VQAv2等通用多模态基准的交叉验证，无法确认该方法是否以牺牲通用视觉理解能力为代价换取回归精度。代码与数据集声明将在接收后发布，当前缺乏可复现性验证。此外，实验仅覆盖年龄、评分和骨龄三类任务，未涉及坐标回归或更复杂的连续量预测，方法在更高维连续空间中的有效性未经验证。

## 关联研究分析

从问题动机看，本文与SoftLabel（Wang et al., 2025b）均旨在解决Token化监督与连续目标的错位，但SoftLabel通过平滑One-hot标签在Token级引入局部邻近性，仍局限于单样本内部；本文则通过批量级CCC奖励在样本间引入全局分布约束。这一差异源于任务特性：长尾回归中稀疏目标的误差信号在单样本内过于微弱，必须借助批次内密集样本的统计结构作为参照系，才能有效纠偏。SoftLabel无法解决跨样本的分布偏移问题，而本文方法通过关系监督实现了分布层面的对齐。

从方法设计看，本文与DISCO（Zhou et al., 2025）同属RL后训练范式，但DISCO通过难度感知加权调整实例重要性，属于点状奖励的变体；本文则改变奖励的计算语义，从点状误差转为批量分布对齐。DISCO的加权机制虽能提升难样本权重，但未改变优化目标对均值坍缩的敏感性；本文的CCC奖励通过惩罚方差坍缩，从机制上抑制了这种退化。这种设计差异暗示，在长尾分布下，仅调整样本权重不足以解决分布结构丢失问题，必须引入分布层面的显式约束。

## 总结

本文核心矛盾在于MLLMs的Token级监督与长尾连续回归目标的全局结构不匹配，导致预测向均值坍缩。现有架构修改或点状奖励无法保留分布信息，本文通过批量级CCC奖励引入跨样本关系监督，在无需修改架构的前提下实现了分布对齐。实验在AgeDB和IMDB-Movie上验证了其在Medium/Few-shot区域的显著增益，MAE降低幅度达20%-30%。然而，本文边界在于仅验证了自建回归基准，缺乏通用多模态任务的性能对比，且未探索高维连续空间中的适用性。当支持集增大到5-shot时，批量级关系监督的边际收益是否递减，论文未给出回答。
