# HuggingFace最新推荐论文 ｜Dynamic Skill Lifecycle Management for Agentic Reinforcement Learning ｜动态技能生命周期管理

研究机构：香港中文大学、兰州大学

作者：Junhao Shen、Teng Zhang、Xiaoyan Zhao 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2605.10923)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2605.10923)

> 代理强化学习（Agentic RL）中，外部技能库的规模与模型参数容量之间存在结构性冲突：技能越多，检索噪声与上下文开销越大，但完全内化又受限于有限参数空间。现有方法陷入“单调累积”或“强制清零”的二元陷阱，忽视了技能边际贡献随训练动态变化的事实。本文提出 SLIM 框架，将活跃技能集视为可优化的动态变量，通过留一法验证估计边际外部贡献（MEC），执行保留、退役与扩展操作。实验表明 SLIM 在 ALFWorld 和 SearchQA 上平均超越基线 7.1 个百分点，但其在低依赖任务上的增益微弱，且高度依赖验证集分布的稳定性。

## 研究背景

当代理执行长程任务时，外部技能作为程序性知识模块被注入上下文以弥补参数化记忆的不足。然而，随着技能库规模扩大，简单的语义检索无法区分“相关技能”与“有效技能”，导致路由噪声增加；同时，模型参数容量有限，无法将所有高频或低频技能均内化，这构成了上下文预算与技能完整性之间的核心矛盾。

该领域主流路线分为两类：一类如 SkillRL，将技能视为持久增强，持续扩展技能库以支持探索，但忽略了冗余技能对性能的负向干扰；另一类如 Skill0，将技能视为临时脚手架，逐步消除以实现零技能推理，但强制内化可能超出参数容量限制，挤占其他关键能力。这两种范式均假设活跃技能集应单调增长或消失，未考虑技能边际贡献的非单调性。SLIM 的切入点在于，将活跃技能集本身作为动态优化变量，在强化学习训练过程中根据每个技能的实时边际价值决定其去留，从而在参数内化与外部保留之间建立自适应边界。

## 核心方法

### 容量约束下的技能分配问题

SLIM 将技能管理形式化为容量约束分配问题。设 $A$ 为活跃外部技能集，$I$ 为内化技能集，$U$ 为非活跃外部技能集。模型参数容量 $C_\theta$ 有限，外部支持成本 $\Omega(A)$ 为单调递增集合函数。优化目标为最大化任务性能 $J(\theta, A) = \mathbb{E}_{x \sim X}[\text{Perf}(x; \pi_\theta, A)] - \Omega(A)$，同时满足 $\sum_{s \in I} m(s) \le C_\theta$。该公式明确了技能管理的本质是在性能增益与外部开销、参数容量之间寻求平衡，而非单纯追求技能数量最大化或最小化。

### 边际外部贡献估计

层级检索将全局组合搜索降维为任务条件候选选择，但无法判断保留某技能是否仍具价值。SLIM 引入留一法验证（Leave-One-Skill-Out Validation）估计边际外部贡献（MEC）。对于审计技能 $s$，其 MEC 定义为：

$$ \Delta_t(s) = \text{Perf}(V_t(s); A_t) - \text{Perf}(V_t(s); A_t \setminus \{s\}) $$

其中 $V_t(s)$ 为当前活跃集下使用技能 $s$ 的验证任务子集。该公式通过对比“有技能”与“无技能”在相同任务子集上的性能差异，量化技能在当前策略下的净外部价值。为降低噪声，SLIM 采用指数移动平均 $\bar{\Delta}_t(s) = \alpha \Delta_t(s) + (1-\alpha)\bar{\Delta}_{t-1}(s)$ 平滑估计值。正 MEC 表明策略仍依赖该外部能力，近零或负值则暗示能力已被内化、冗余或有害。

### 基于 MEC 的生命周期操作

SLIM 将 MEC 信号与 GRPO 策略优化耦合，执行三种生命周期操作。保留（Retain）：若 $\bar{\Delta}_t(s) \ge \tau_{\text{keep}}$，技能继续活跃；退役（Retire）：若 $\bar{\Delta}_t(s) < \tau_{\text{retire}}$ 且累计曝光次数 $u_t(s) \ge n_{\min}$、低贡献连续次数 $\ell_t(s) \ge p$，技能被移除；扩展（Expand）：若路由至技能 $s$ 的任务持续失败（$\text{Perf}(V_t(s); A_t) < \tau_{\text{expand}}$ 且 $N_t(s) \ge n_{\text{expand}}$），则生成新技能补充覆盖。这些操作构成非单调轨迹：技能集先扩展以覆盖缺失能力，再收缩以剔除冗余，最终稳定于紧凑非空集合。该机制解决了单调累积导致的性能退化与强制清零导致的容量溢出问题，使技能库规模随训练动态适应任务需求。

## 实验评估

实验在 ALFWorld（具身交互）和 SearchQA（搜索增强问答）上进行，骨干模型统一为 Qwen3-4B，基线涵盖提示式（Zero-Shot/Few-Shot）、记忆式（Mem0/ExpeL）及强化学习式（GRPO/SkillRL/Skill0）。SLIM 在 ALFWorld 上取得 87.5% 成功率，较最强基线 SkillRL 提升 12.5 个百分点；在 SearchQA 上取得 41.0% 成功率，较 Skill0 提升 1.7 个百分点。

| Skill0 | 74.2 | 39.3 |
| SLIM [†] | 87.5 | 41.0 |

消融实验揭示退役机制的关键作用：移除退役操作后，ALFWorld 成功率从 87.5% 骤降至 73.4%，表明无删除的扩展退化为 SkillRL 式累积，冗余技能显著损害性能。移除扩展操作后，成功率降至 78.9%，说明仅靠剪枝无法修复覆盖缺失。随机审计（Random Audit）仅获 68.8%，证实生命周期决策必须基于 MEC 而非随机扰动。固定活跃集大小（Fixed Active Set Size）获 75.6%，低于 SLIM 11.9 个百分点，排除“仅控制技能数量”的解释，证明关键在于“哪些技能”被保留或移除。

评估边界方面，SLIM 的 MEC 估计依赖验证集分布，若验证集与测试集存在分布偏移，退役决策可能失效。论文未报告置信区间，且仅使用单一骨干模型（Qwen3-4B），未验证跨模型泛化性。代码已开源，但超参数（如 $\tau_{\text{keep}}$、$\tau_{\text{retire}}$）的敏感性分析未在正文中详细展开。

## 关联研究分析

从问题动机看，SLIM 与 SkillOpt 均关注技能优化，但路径迥异。SkillOpt 将技能文档视为可编辑参数，通过文本梯度与验证门控进行内容级优化，侧重“技能怎么写”；SLIM 则将技能集视为离散变量，通过 MEC 进行集合级管理，侧重“哪些技能该留”。前者假设技能内容可迭代改进，后者假设技能内容固定但集合需动态调整。这一差异源于任务特性：SkillOpt 适用于结构化文档处理等技能内容易精确定义的场景，而 SLIM 更适用于具身交互等技能边界模糊、需动态适应策略变化的场景。

从方法设计看，SLIM 与 Skill1 同属强化学习驱动的技能进化路线，但优化目标不同。Skill1 通过统一策略网络协同优化技能选择、利用与蒸馏，追求端到端性能最大化；SLIM 则解耦策略学习与技能管理，交替优化策略（GRPO）与技能集（生命周期操作），避免联合优化中的梯度冲突。SLIM 的解耦设计使其能独立评估技能的外部价值，而 Skill1 的技能价值隐含在策略奖励中，难以直接归因。这种解耦是否牺牲了技能-策略协同的细粒度适应性，论文未给出回答。

## 总结

SLIM 解决的核心矛盾是外部技能库规模与模型参数容量之间的结构性冲突，现有单调累积或强制清零范式无法适应技能边际贡献的动态变化。其切入点在于将活跃技能集视为可优化变量，通过留一法验证估计 MEC，执行保留、退役与扩展操作，从而在参数内化与外部保留间建立自适应边界。实验证明 SLIM 在 ALFWorld 上较 SkillRL 提升 12.5 个百分点，在 SearchQA 上较 Skill0 提升 1.7 个百分点，验证了非单调生命周期管理的有效性。然而，SLIM 的 MEC 估计高度依赖验证集分布，且在低依赖任务（如 SearchQA）上增益微弱，暗示当任务对技能依赖度低时，生命周期管理的边际收益可能不足以抵消审计开销。当验证集与测试集分布存在显著偏移时，基于 MEC 的退役决策是否仍能保持鲁棒性，论文未提供直接证据。
