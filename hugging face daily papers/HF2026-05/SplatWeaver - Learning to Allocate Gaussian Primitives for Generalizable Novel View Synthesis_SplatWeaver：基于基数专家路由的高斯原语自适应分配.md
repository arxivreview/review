# HuggingFace最新推荐论文 ｜SplatWeaver: Learning to Allocate Gaussian Primitives for Generalizable Novel View Synthesis ｜SplatWeaver：基于基数专家路由的高斯原语自适应分配

作者：Yecong Wan、Fan Li、Mingwen Shao 等 4 人

> 前馈式新视角合成（Novel View Synthesis, NVS）旨在从少量无标定图像直接预测三维场景表示，消除逐场景优化的计算开销。现有基于3D高斯泼溅（3D Gaussian Splatting, 3DGS）的方法通常采用像素或体素对齐的固定预算策略，导致平滑区域原语冗余而复杂区域细节缺失。SplatWeaver 引入基数高斯专家与像素级路由机制，根据场景复杂度动态分配高斯数量，实现“复杂处致密、平滑处稀疏”的表示。该方法在效率与质量间取得了显著平衡，但其对高频先验的依赖及在极端稀疏视图下的鲁棒性仍存疑。

## 研究背景

理解 SplatWeaver 需先厘清前馈式 NVS 中“表示容量”与“场景复杂度”的错配问题。传统 3DGS 通过逐场景优化自适应调整高斯数量，但前馈模型为追求泛化性，往往将高斯预测绑定于固定的像素或体素网格。这种刚性分配忽略了真实场景的空间异质性：平坦墙面仅需少量原语即可重建，而纹理丰富区域则需要高密度原语捕捉高频细节。当固定预算无法匹配局部复杂度时，模型要么在简单区域浪费显存，要么在复杂区域因容量不足产生模糊或伪影。

前馈式高效重建路线旨在通过单次前向传播实现跨场景泛化，AnySplat 等体素对齐方法虽实现了实时推理，但其固定预算机制限制了表示的表达能力。C3G 和 TokenGS 尝试通过 Token 查询解耦网格约束，但仍依赖预定义的总预算，无法根据视图覆盖范围或局部几何复杂度动态调整。SplatWeaver 的切入点在于将“高斯数量”本身视为一个可学习的变量，而非固定超参数。通过引入混合专家（Mixture-of-Experts, MoE）架构中的路由机制，模型能够根据输入图像的高频特征，决定每个空间位置应分配的高斯基数，从而在保持前馈效率的同时，恢复了类似逐场景优化的自适应能力。

## 核心方法

### 方法参照系

SplatWeaver 属于前馈式 3DGS 重建框架，其标准流程为：输入无标定图像，经骨干网络提取特征，预测相机位姿及高斯参数（位置、尺度、旋转、不透明度、颜色）。与 AnySplat 等基线方法的关键差异在于，基线方法直接回归固定数量的高斯参数，而 SplatWeaver 将高斯预测解耦为“数量决策”与“参数生成”两个阶段，前者由路由机制动态决定，后者由专家网络执行。

### 基数高斯专家与像素级路由

在标准前馈流程中，特征提取后直接映射至高斯参数。SplatWeaver 在此环节插入路由机制，将像素级特征分配至不同的“基数高斯专家”。每个专家 $E_e$ 专门预测特定数量 $e$（从 0 到 $M$）的高斯原语，其中 $e=0$ 为 Null 专家，用于在平滑区域抑制原语生成。路由过程通过 Hard Gumbel Softmax 实现可微离散选择，确保训练稳定性。该设计解决了固定预算方法在复杂区域欠拟合的问题，使模型能够根据局部内容动态调整表示密度。路由决策依赖于高频先验引导模块，该模块从离散小波变换域提取高频能量图，作为路由的正向信号，鼓励模型在纹理丰富区域分配更多原语。

$$
\mathbf{r}_p = \text{Top1}(\text{GumbelSoftmax}(\mathbf{W}_r \mathbf{f}_p + \mathbf{b}_r + \lambda \mathbf{h}_p))
$$

其中 $\mathbf{f}_p$ 为像素 $p$ 的特征，$\mathbf{h}_p$ 为高频能量图，$\lambda$ 为引导权重。该公式表明，路由决策不仅由语义特征驱动，还显式受高频结构约束，从而实现了复杂度感知的原语分配。

### 隐式高斯聚合与参数解码

路由选定专家后，专家网络仅预测高斯的空间位置 $\boldsymbol{\mu}$ 和潜在特征 $\mathbf{F}_l$，而非完整参数。这一设计动机在于，直接回归完整参数缺乏空间上下文感知，易导致参数不一致。SplatWeaver 将预测的隐式高斯与对应像素特征拼接，并通过注意力机制聚合 $K$ 个邻近隐式高斯的特征，最终解码出尺度、旋转、不透明度和颜色。这种“位置-特征”分离预测策略，利用空间邻域信息增强了参数预测的连贯性，解决了固定网格预测中因缺乏上下文导致的几何破碎问题。

$$
\mathbf{c}_g = \text{MLP}\left( \text{Agg}(\{ \boldsymbol{\mu}_g, \mathbf{F}_{l,g}, \mathbf{F}_n[p(i,j)] \}_{g \in \mathcal{N}_K}) \right)
$$

该公式描述了如何通过聚合局部邻域信息解码颜色嵌入，确保了高斯参数在空间上的平滑过渡与结构一致性。

## 实验评估

SplatWeaver 在 DL3DV、RealEstate10K 和 Mip-NeRF 360 上进行评估，对比了 AnySplat、EcoSplat、C3G 等前馈基线。基线覆盖全面，涵盖了像素对齐、体素对齐、剪枝及查询式方法，但缺乏 NeRF 类隐式表示的直接对比，这可能影响对显式表示优势的全面评估。在 DL3DV 基准上，SplatWeaver 以 297K 高斯原语实现了 24.52 的 PSNR，显著优于 AnySplat 的 23.17（1671K 原语）和 EcoSplat 的 17.29（734K 原语）。这一结果验证了自适应分配在效率与质量间的优越性：SplatWeaver 在减少 82% 原语的情况下，PSNR 提升了 1.35 dB。

| 方法 | 高斯数量 (K) | PSNR (dB) |
| :--- | :--- | :--- |
| AnySplat | 1671 | 23.17 |
| EcoSplat | 734 | 17.29 |
| SplatWeaver | 297 | 24.52 |

消融实验显示，基数高斯专家路由贡献了 1.63 dB 的 PSNR 增益，高频先验引导模块贡献了 0.58 dB。这表明路由机制是性能提升的核心，而高频先验主要起到稳定路由决策的作用。值得注意的是，EcoSplat 的剪枝策略导致模型不稳定，在部分场景下出现重建失败，这暗示了后处理剪枝与端到端自适应分配在鲁棒性上的本质差异。

评估协议采用 4、8、16、24 视图设置，输入分辨率限制在 448 像素长边。代码已开源，训练使用 8 块 A100 GPU，学习率从 2e-4 余弦退火至 1e-6。指标涵盖 PSNR、SSIM 和 LPIPS，但未报告推理延迟与显存占用的具体数值，尽管论文强调其效率优势。此外，实验未包含单视图或极端稀疏视图（如 2 视图）下的详细鲁棒性分析，限制了对其在信息极度匮乏场景下表现的判断。

## 关联研究分析

从方法设计看，SplatWeaver 与 C3G 和 TokenGS 同属查询式前馈框架，但核心差异在于预算的固定性与动态性。C3G 依赖预定义的 Token 数量，导致其在大规模场景或不同视图覆盖下缺乏扩展性；SplatWeaver 通过路由机制解耦了预算与场景复杂度，实现了真正的自适应。这一差异源于任务特性：固定预算假设场景复杂度均质，而真实场景具有显著的空间异质性。SplatWeaver 的高频先验引导机制是其区别于纯数据驱动路由的关键，它引入了显式的几何结构约束，避免了路由决策的随机性。

从问题动机看，SplatWeaver 与 AnySplat 均致力于解决前馈 NVS 的效率问题，但切入点不同。AnySplat 聚焦于体素对齐的紧凑表示，通过优化网络结构减少原语数量；SplatWeaver 则聚焦于原语分配的合理性，通过动态路由优化原语分布。AnySplat 的固定预算在平滑区域造成冗余，而 SplatWeaver 的 Null 专家机制直接消除了这种冗余。这种差异反映了领域内对“效率”定义的不同理解：前者追求表示的紧凑性，后者追求表示的适应性。SplatWeaver 在 RealEstate10K 2 视图 posed 设置下达到 29.06 PSNR，优于 Long-LRM 的 28.54，表明其在稀疏视图下的几何一致性优势。

## 总结

SplatWeaver 针对前馈式 NVS 中固定预算导致的表示冗余与欠拟合矛盾，提出基数高斯专家路由机制，通过动态分配原语数量实现复杂度自适应建模。该方法在 DL3DV 上以 297K 原语实现 24.52 PSNR，较 AnySplat 提升 1.35 dB 且原语减少 82%，验证了自适应分配的有效性。然而，其性能依赖于高频先验引导，且在极端稀疏视图下的鲁棒性未充分验证。当输入视图减少至 2 张且无位姿信息时，高频先验是否足以支撑稳定的路由决策，论文未给出明确回答。
