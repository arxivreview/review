深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.08982)

> 视频扩散Transformer（DiT）中二次方注意力复杂度随分辨率与帧数激增，成为长视频生成的首要瓶颈。现有稀疏注意力方法依赖注意力分数选块并直接丢弃低分块，导致全局上下文丢失；引入学习补偿分支虽能恢复信息，却需微调且破坏即插即用性。SVG-EAR 利用聚类后的块内相似性，以质心进行无参数线性补偿，并基于补偿误差而非注意力分数进行路由，在固定预算下最小化重构误差。该方法在 Wan2.2 与 HunyuanVideo 上建立了新的质量-效率帕累托前沿，但其误差估计的近似性在极端低密度下的理论边界尚待验证。

## 研究背景

视频生成中，3D 时空自注意力的计算量随 Token 序列长度呈二次方增长。为降低开销，主流方案采用块稀疏策略：先对 Query 和 Key 进行语义聚类与重排，使相似 Token 在内存中连续，从而将注意力矩阵划分为块结构。在此结构上，仅计算部分 Query-Key 块的精确注意力，其余块被忽略或近似，以换取硬件友好的稀疏模式。

然而，基于注意力分数（如 Top-k/Top-p）的块选择策略存在根本性错位。高分块往往内部一致性高，适合近似；而低分块可能包含多样的 Key-Value 交互，直接丢弃会导致显著的信息损失。SLA 等方法通过引入可学习的线性分支来补偿被丢弃块，但增加了训练参数与微调成本，限制了部署灵活性。SVG-EAR 的切入点在于：既然聚类已揭示了块内的高相似性，便可利用质心进行无参数线性补偿，进而将路由目标从“保留高分块”转变为“最小化补偿误差”，从而在无需训练的前提下实现更优的误差-密度权衡。

## 核心方法

### 块稀疏参照系与问题定义

本文沿用“聚类-重排-路由”的标准流程，但改变了路由的优化目标。给定 Query $Q \in \mathbb{R}^{N_q \times d}$ 和 Key $K \in \mathbb{R}^{N_k \times d}$，通过 Flash K-Means 聚类得到 $C_q$ 和 $C_k$ 个簇。对于每个 Query $q_i$ 和 Key $k_j$，定义其所在簇的质心为 $\bar{q}_i$ 和 $\bar{k}_j$。稀疏注意力图 $\tilde{A}_{sparse}(M)$ 由二进制路由掩码 $M$ 控制：若 $M_{(i,j)}=1$，则计算精确注意力；若 $M_{(i,j)}=0$，则使用质心近似。优化目标是在密度预算 $\rho$ 下，最小化全注意力图与稀疏注意力图的均方误差（MSE）。

### 无参数线性补偿

设计动机：解决直接丢弃低分块导致的全局上下文丢失问题，同时避免引入可学习参数。对于未被选中的块，SVG-EAR 用簇质心 $\bar{k}_j$ 替代块内所有 Key $k_j$ 进行 Logit 计算。近似 Logit 为：

$$ \tilde{z}_{ij} = \frac{q_i \bar{k}_j^T}{\sqrt{d}} $$

该公式的物理含义是，假设块内所有 Key 对 Query 的贡献可由其均值代表，从而将块级计算简化为单次向量点积，实现了无参数的线性补偿。

### 误差感知路由

设计动机：解决分数路由与误差最小化目标错位的问题。高分块可能因内部一致性强而适合补偿，低分块可能因多样性高而补偿误差大。因此，路由应基于补偿误差而非注意力分数。SVG-EAR 定义每个条目的估计误差为：

$$ \hat{\epsilon}_{ij} = \left( \frac{q_i k_j^T}{\sqrt{d}} - \frac{q_i \bar{k}_j^T}{\sqrt{d}} \right)^2 $$

利用簇内相似性，用 Query 质心 $\bar{q}_i$ 作为代理，将误差估计复杂度从 $O(N_q N_k d)$ 降至 $O(C_q N_k d)$。随后，计算每个块的误差-成本比（误差和除以块大小），在预算内贪心选择比率最高的块进行精确计算，其余块进行线性补偿。

## 实验评估

实验在 Wan2.2 14B 和 HunyuanVideo 13B 上进行，分辨率 720p，使用 VBench 提示词。基线包括静态方法 SVG 和动态方法 SVG2、SpargeAttention。未对比 SLA，因其需训练，相似度指标不可比。

| 模型 | 方法 | PSNR↑ | SSIM↑ | LPIPS↓ | Density↓ | Speedup↑ |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Wan2.2 T2V | SVG2 | 23.556 | 0.802 | 0.183 | 32.30% | 1.57× |
| Wan2.2 T2V | SVG-EAR | 24.995 | 0.841 | 0.153 | 25.95% | 1.59× |
| Wan2.2 T2V | SVG-EAR-Turbo | 23.940 | 0.814 | 0.174 | 22.25% | 1.75× |
| Hunyuan T2V | SVG2 | 29.445 | 0.911 | 0.112 | 26.21% | 1.89× |
| Hunyuan T2V | SVG-EAR | 31.043 | 0.928 | 0.092 | 22.17% | 1.93× |

SVG-EAR 在相同密度下 PSNR 显著高于 SVG2，或在相同质量下密度更低。例如，在 Wan2.2 T2V 上，SVG-EAR 以 25.95% 的密度达到 24.995 PSNR，而 SVG2 需 32.30% 密度仅达 23.556 PSNR。SVG-EAR-Turbo 进一步降低密度至 22.25%，加速比提升至 1.75×。

消融实验显示，误差感知路由相比 Top-p 选择，在相同密度下显著降低重构误差。自定义 Triton 内核相比 PyTorch 实现加速 13.74×，路由开销仅占端到端延迟的 6.5%。

评估边界：未报告置信区间，未对比线性注意力基线。代码未公开，超参数（如聚类数）未详细披露。VBench 子项（如时序一致性）未单独列出，仅展示 ImgQual 和 SubCons。

## 关联研究分析

从问题动机看，SVG-EAR 与 SLA 均旨在解决低分块丢弃导致的信息损失，但 SLA 依赖可学习线性分支，需微调且可能改变输出分布；SVG-EAR 利用聚类质心进行无参数补偿，保持了即插即用性。这一差异源于对“补偿”实现方式的不同选择：SLA 认为学习分支能更精确地拟合复杂交互，而 SVG-EAR 认为聚类后的块内相似性已足以支撑质心近似的准确性，且避免了训练成本。

从方法设计看，SVG-EAR 与 SVG2 共享聚类重排框架，但块选择逻辑不同。SVG2 基于注意力分数选块，而 SVG-EAR 基于补偿误差选块。这一差异揭示了分数路由在存在补偿分支时的非最优性：高分块可能因内部一致性强而适合补偿，低分块可能因多样性高而需精确计算。SVG-EAR 通过误差感知路由，将计算资源分配给补偿失效的块，从而在固定预算下最小化重构误差。

## 总结

SVG-EAR 解决了稀疏注意力中分数路由与误差最小化目标错位的核心矛盾。其切入点在于利用聚类后的块内相似性，以质心进行无参数线性补偿，并基于补偿误差而非注意力分数进行路由。该方法在 Wan2.2 和 HunyuanVideo 上建立了新的帕累托前沿，PSNR 分别达到 24.995 和 31.043，加速比最高 1.93×。其边界在于误差估计依赖簇内相似性假设，在极端低密度或高噪声步长下，质心近似的准确性可能下降，导致补偿误差估计偏差。当密度降至 10% 以下时，误差感知路由的性能是否仍能保持优势，论文未给出回答。
