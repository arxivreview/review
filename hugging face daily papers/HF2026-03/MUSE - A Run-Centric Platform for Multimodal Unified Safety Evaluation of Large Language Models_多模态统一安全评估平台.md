# HuggingFace最新推荐论文 ｜MUSE: A Run-Centric Platform for Multimodal Unified Safety Evaluation of Large Language Models ｜多模态统一安全评估平台

研究机构：美国杜克大学

作者：Zhongxi Wang、Yueqian Lin、Jingyang Zhang 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.02482)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.02482)

> 多模态大语言模型的安全评估长期受限于单轮静态测试与二元指标，无法揭示多轮对话中模态切换对安全对齐的动态影响。现有红队框架缺乏原生多模态载荷生成与交互式运行管理，导致跨模态攻击路径无法在单一可复现管道中系统验证。MUSE 通过构建以“运行”为中心的统一平台，集成跨模态载荷生成、多轮攻击编排与五级 LLM 裁判，首次实现了多轮多模态红队测试的自动化闭环。该平台揭示了多轮攻击可击穿单轮高拒绝率防御，且模态切换本身构成独立的不稳定因素，但其结论受限于商业闭源 API 的黑盒特性，无法深入内部机理。

## 研究背景

多模态大语言模型（Multimodal Large Language Models, MLLMs）在处理音频、图像和视频时，其安全对齐机制面临“模态间隙”（Modality Gap）挑战，即视觉与文本嵌入在安全语义空间中的分布差异导致文本侧安全约束无法有效覆盖非文本输入。这种分布偏差使得模型对图像中隐含的恶意指令极度敏感，而对良性查询可能产生过度拒绝。然而，现有评估多聚焦于单轮静态输入，忽略了多轮对话中模态动态切换对安全护栏的累积侵蚀效应，导致无法量化跨模态泛化的真实边界。

主流安全评估路线分为攻击方法学与多模态安全两个独立分支。攻击方法学侧，Crescendo、PAIR 等策略证明了迭代对抗压力可绕过单轮防御，但均局限于纯文本模态；多模态安全侧，FigStep 等工作揭示了非文本模态可削弱对齐，但仅评估单一模态的静态输入，未探究多轮对话中的跨模态转换。这两条路线的割裂导致现有工具无法同时支持多轮自动化攻击、跨模态载荷投递与自动化安全判断，且二元攻击成功率（Attack Success Rate, ASR）指标将丰富的行为谱系坍缩为单一数值，无法区分完全绕过与部分信息泄露。MUSE 的切入点在于构建一个统一基础设施，将多轮攻击编排与多模态载荷生成整合，并引入细粒度评估指标，以系统性地探测安全对齐在模态边界上的泛化能力。

## 核心方法

### 方法参照系

多模态安全评估通常遵循“攻击生成-模型响应-结果判定”的线性流程，但现有框架如 PyRIT 和 Garak 缺乏原生多模态载荷生成，HarmBench 等基准缺乏交互式运行管理。本文的关键差异在于将评估单元从单次查询升级为持久化的“运行”（Run），该实体记录攻击配置、对话状态、媒体资产与评估结果，支持跨模态红队测试的可复现性与批量管理。

### 跨模态载荷生成与模型路由

传统红队框架仅处理文本输入，无法模拟真实多模态场景下的攻击路径。MUSE 引入模态转换管道，将攻击者生成的文本自动转换为音频（TTS 合成）、图像（文本渲染至画布）和视频（音视频合成），并通过基于 (project, prompt, modality) 键的缓存机制避免重复生成。模型路由层抽象了提供商特定的 API 差异，通过实现轻量级提供商客户端即可支持新模型，当前覆盖 OpenAI、Google、Anthropic 和 Qwen 四家提供商的六个模型。这一设计解决了多模态提供商接口异构导致的评估碎片化问题，使得同一攻击策略可在不同模态配置下无缝执行，为后续模态消融实验提供了基础设施保障。

### 五级安全分类与双指标评估

二元 ASR 指标混淆了定性不同的模型行为，如 StrongREJECT 所指出的，其高估了越狱成功率。MUSE 采用五级安全分类法，强调能力转移而非表面语气：Compliance（直接转移有害能力）、Partial Compliance（不完整但可操作的有害信息）、Indirect Refusal（避免协助但未明确拒绝）、Direct Refusal（明确拒绝）和 Non-Responsive（无关输出）。基于此，定义硬 ASR 仅统计 Compliance，软 ASR 包含 Partial Compliance，二者之差称为灰区宽度（Gray Zone Width, GZW），量化模型部分抵抗但仍转移有害能力的程度。该指标体系解决了二元指标无法捕捉部分信息泄露的问题，支持纵向分析模型抵抗性在轮次间的侵蚀模式。

### 轮间模态切换（ITMS）

现有多轮攻击策略均在纯文本空间中执行，无法隔离模态切换本身对安全对齐的影响。MUSE 引入轮间模态切换（Inter-Turn Modality Switching, ITMS）机制，在保持上下文的策略（Crescendo 和 Violent Durian）中，每轮前系统循环选择目标模型支持的模态，将攻击者文本转换为多模态消息投递。ITMS 的核心公式为：

$$
\text{ASR}_{\text{hard}} = \frac{|\{r \in R : \ell(r) = C\}|}{|R|}
$$

其中 $R$ 为运行集合，$\ell(r)$ 为五级分类标签，$C$ 为 Compliance。该公式通过仅统计完全合规响应，排除了部分泄露的干扰，使 ITMS 对收敛速度的影响可被独立量化。ITMS 通过记录每轮模态序列，实现了从单模态投递到全模态轮换的受控消融，揭示了模态转换本身而非单一模态内容是不稳定机制的关键证据。

## 实验评估

实验基于 AdvBench 的 50 个有害目标，覆盖武器、受控物质、恶意软件、生物威胁和欺诈/社会工程五类，使用 GPT-4o 作为攻击者和裁判。基线覆盖 Crescendo、PAIR、Violent Durian 三种多轮策略及其 ITMS 变体，但缺失单轮梯度攻击（如 GCG）对比，限制了与白盒攻击的横向比较。主实验结果显示，Crescendo 在六个模型上实现 90–98% 硬 ASR，PAIR 在五个模型上达 96–100%，而单轮基线拒绝率高达 90–100%，证实多轮攻击可击穿单轮高拒绝率防御。

| 模型 | Crescendo | PAIR | Violent Durian | ITMS-Crescendo | ITMS-VD |
|---|---|---|---|---|---|
| Claude Sonnet 4 | 90 | 60 | 2 | 92 | 6 |
| GPT-4o | 96 | 98 | 42 | 94 | 40 |
| Gemini 2.5 Flash | 98 | 94 | 96 | 98 | 92 |
| Gemini 3 Flash | 96 | 98 | 98 | 96 | 94 |
| Qwen2.5-Omni | 98 | 96 | 86 | 90 | 100 |
| Qwen3-Omni | 96 | 98 | 30 | 94 | 22 |

ITMS 消融实验揭示模态效应方向具有模型家族依赖性：Gemini 模型非文本模态使硬 ASR 提升 2–6 点，而 Qwen 模型一致降低，其中 Qwen2.5-Omni 在仅图像投递下 ASR 下降 14 点。轮次级分析显示，ITMS-Crescendo 在第 1 轮拒绝率高于基线（86.0% vs. 81.0%），但在第 2 轮模态切换后拒绝率骤降至 59.7%，Partial Compliance 升至 32.7%，证实模态转换本身是不稳定机制。该发现与“视觉通道普遍绕过过滤”的领域共识存在局部冲突，暗示 Qwen 的多模态管道对非文本输入施加了更严格的内容过滤。

评估边界受限于商业闭源 API 的黑盒特性，无法进行神经元级分析；五级分类法依赖 LLM 裁判，未与人工标注验证；实验未覆盖本地开源模型，限制了结论的泛化性。代码开源但超参数细节（如 TTS 引擎、图像渲染参数）未完全披露，可复现性依赖提供商 API 的稳定性。

## 关联研究分析

从问题动机看，MUSE 与 OmniSafeBench-MM 均旨在解决多模态安全评估的碎片化问题，但前者聚焦单轮静态攻击-防御方法整合，后者引入多轮交互维度与模态动态切换。这一差异源于任务特性：OmniSafeBench-MM 评估的是防御机制对已知攻击的鲁棒性，而 MUSE 探测的是安全对齐在未知多轮模态序列下的泛化边界。MUSE 的 ITMS 机制揭示了模态切换本身的不稳定效应，这是单轮评估框架无法捕捉的，但论文未探讨该效应是否源于攻击者 LLM 的强推理能力而非目标模型漏洞，这一归因模糊性限制了结论的因果强度。

从方法设计看，MUSE 与 FigStep 均利用图像模态投递有害内容，但 FigStep 聚焦单轮排版注入的静态绕过，MUSE 强调多轮动态对话中的模态轮换。FigStep 的图像载荷是固定对抗样本，而 MUSE 的图像载荷由攻击者 LLM 实时生成并随对话上下文演化，这使得 MUSE 能捕捉到 FigStep 无法揭示的轮次间抵抗性侵蚀模式。然而，MUSE 未对比单轮梯度攻击（如 GCG）在多模态场景下的表现，无法判断多轮攻击的高 ASR 是否部分源于攻击者 LLM 的推理优势而非目标模型的多模态漏洞，这一基线缺失使得攻击有效性的归因存在争议。

## 总结

MUSE 解决的核心矛盾是多轮多模态安全评估缺乏统一基础设施与细粒度指标，现有框架无法在单一管道中同时支持跨模态载荷生成、多轮攻击编排与自动化判断。该平台通过以“运行”为中心的架构与五级分类法，首次实现了多轮多模态红队测试的可复现闭环，揭示了多轮攻击可击穿单轮 90–100% 拒绝率防御，且模态切换本身构成独立的不稳定因素。其边界在于依赖商业闭源 API 的黑盒特性，无法深入内部机理，且未验证五级分类法与人工标注的一致性。当攻击者 LLM 的推理能力与目标模型的多模态漏洞解耦时，多轮攻击的高 ASR 是否仍主要由模态切换驱动，论文未给出回答。
