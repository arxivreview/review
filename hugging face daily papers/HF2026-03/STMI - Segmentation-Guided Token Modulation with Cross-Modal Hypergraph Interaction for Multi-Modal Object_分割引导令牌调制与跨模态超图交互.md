> 多模态目标重识别（MM-ReID）旨在利用可见光、近红外（NIR）与热红外（TIR）互补光谱解决低光照下的身份检索难题，但现有方法常依赖硬令牌过滤或简单融合，导致关键细节丢失与背景噪声干扰。STMI 针对这一痛点，提出分割引导特征调制（SFM）与跨模态超图交互（CHI）框架，通过软性调制保留信息完整性并建模高阶语义关系。该框架在车辆重识别基准上取得领先性能，但其对完整模态的假设与外部分割模型的依赖限制了其在开放场景下的泛化能力。

## 研究背景

多模态重识别的核心困境源于不同光谱成像物理机制导致的分布差异。可见光图像富含纹理与颜色信息，而红外图像主要反映热辐射或反射率，二者在特征空间存在显著模态间隙。为弥合这一间隙，模型需提取模态不变特征，即剥离传感器特异性干扰、保留身份相关信息的表示。然而，实际部署中传感器故障或遮挡常导致模态缺失，要求模型具备处理任意模态组合的鲁棒性，而非仅针对固定模态对优化。

早期方法如 HAMNet 与 PFNet 假设模态间存在简单互补性，通过加权或渐进融合处理，但在传感器异构或分布偏移时暴露出脆弱性。2023 年后，研究重心转向解耦与任意模态组合，DENet 引入特征变换恢复缺失模态信息，TOP-ReID 利用循环令牌置换提升 ViT 架构的特征交互。尽管这些方法提升了性能，但多数仍依赖硬令牌选择或简单注意力机制，在复杂背景下易丢失关键前景细节，且缺乏对跨模态高阶语义关系的显式建模。STMI 的切入点在于利用分割先验进行软性特征调制，并通过超图结构捕捉局部区域间的结构相关性，以解决硬过滤导致的信息丢失与背景噪声干扰问题。

## 核心方法

### 方法参照系

多模态重识别的主流范式基于 ViT 或 CLIP 骨干，将图像切分为令牌序列，通过自注意力或交叉注意力进行跨模态特征对齐。标准流程通常包含令牌提取、跨模态交互与全局特征聚合。本文的关键差异在于，传统方法在令牌交互前常进行硬过滤或简单拼接，而 STMI 在注意力计算阶段引入分割掩码调制，并在交互阶段采用超图卷积替代线性注意力，以保留令牌完整性并建模高阶依赖。

### 分割引导特征调制

SFM 模块解决硬裁剪导致的判别性细节丢失问题。在 Transformer 自注意力层中，传统方法直接计算注意力权重，易受背景噪声干扰。STMI 利用 SAM 生成的二值分割掩码 $M \in \{0,1\}^{H \times W}$ 构建令牌级前景指示向量 $m$，其中 $m_i=1$ 表示第 $i$ 个令牌位于前景。基于此，构建前景交互掩码 $R$，当且仅当令牌对 $(i,j)$ 均为前景时 $R_{i,j}=1$。调制矩阵 $S$ 定义为：

$$ S = \alpha \cdot M_{pos} \odot R + \beta \cdot M_{neg} \odot (1-R) $$

其中 $\alpha, \beta$ 为可学习参数，$M_{pos}, M_{neg}$ 分别为基于注意力 logits 行最大值/最小值构建的正负调制矩阵。该公式通过自适应重加权，增强前景令牌间的注意力并抑制背景干扰，同时通过掩码扰动机制防止对分割边界的过拟合。

### 跨模态超图交互

CHI 模块解决简单融合无法捕捉高阶语义关系的问题。STR 模块首先通过可学习查询令牌与补丁令牌的交叉注意力，提取紧凑的语义令牌 $F_{\tilde{m}}$。随后，将 RGB、NIR、TIR 的语义令牌拼接为统一集合 $H$，构建超图 $G=(V,E)$，节点 $V$ 对应每个令牌，超边 $E$ 基于语义相似度动态生成。超图卷积更新节点特征：

$$ H^{[l+1]}_i = \sigma \left( \sum_{e \in \epsilon(i)} w_e h^{[l]}_e + b_i \right) $$

其中 $\epsilon(i)$ 为节点 $i$ 关联的超边集合，$w_e$ 为可学习权重。该机制允许每个节点通过超边聚合来自多个模态的局部区域信息，实现结构级绑定，而非仅依赖全局特征对齐。

## 实验评估

| 方法 | RGBNT201 mAP | RGBNT100 mAP | MSVR310 mAP |
| :--- | :--- | :--- | :--- |
| IDEA | 80.2 | 87.2 | 47.0 |
| DeMo | 79.0 | 86.2 | 49.2 |
| MambaPro | 78.9 | 83.9 | 47.0 |
| **STMI** | **81.2** | **89.1** | **64.8** |

STMI 在三个基准上均超越对比基线，其中 MSVR310 上较 IDEA 提升 17.8 个百分点，显示其在复杂车辆场景下的鲁棒性。基线覆盖 CNN 与 ViT/CLIP 路线，但缺失 2026 年频域方法如 FUSE，可能高估了相对性能。

| 模块组合 | mAP | Rank-1 |
| :--- | :--- | :--- |
| Baseline | 70.3 | 72.1 |
| +SFM | 76.1 | 78.1 |
| +SFM+STR | 78.1 | 80.9 |
| +SFM+STR+CHI | 81.2 | 83.4 |

消融实验显示，SFM 贡献最大（+5.8 mAP），验证了分割引导对背景抑制的有效性；CHI 带来 +3.1 mAP 增益，表明高阶语义建模优于 MLP 或自注意力融合。随机概率 0.5% 时性能最佳，过高则因噪声导致性能下降，反映了对分割掩码鲁棒性的权衡。

评估协议采用 mAP 与 CMC，但未报告置信区间，且假设三模态完整，未测试模态缺失场景。代码未公开，超参数如学习率 $3.5 \times 10^{-6}$ 与批量大小 72/64 已披露，但 SAM 推理延迟未量化，限制了边缘部署评估。

## 关联研究分析

从问题动机看，STMI 与 IDEA 均利用文本语义引导，但 IDEA 侧重位置偏移以捕捉细粒度局部细节，而 STMI 侧重分割调制以解决背景噪声。IDEA 在 RGBNT201 上达到 80.2 mAP，略低于 STMI 的 81.2 mAP，差异源于 STMI 对前景完整性的保留。然而，IDEA 未显式处理背景干扰，在复杂场景下可能因背景混淆导致性能下降，STMI 的分割先验提供了更直接的噪声抑制机制。

从方法设计看，STMI 与 TOP-ReID 均使用令牌交互，但 TOP-ReID 采用循环置换进行线性交互，STMI 采用超图卷积建模高阶关系。TOP-ReID 在 RGBNT201 上为 72.3 mAP，显著低于 STMI，表明线性交互在复杂语义场景下的局限性。STMI 的超图结构允许局部区域间的非成对关联，更适合捕捉跨模态的结构相关性，但计算复杂度高于线性注意力，论文未报告推理时间，效率优势存疑。

## 总结

STMI 旨在解决多模态重识别中硬令牌过滤导致的信息丢失与背景噪声干扰矛盾。其切入点在于利用分割先验进行软性调制，并通过超图结构建模高阶语义，避免了传统硬过滤的信息损失。方法通过 SFM 增强前景、STR 提取紧凑语义、CHI 实现跨模态高阶交互，在 RGBNT100 上达到 89.1 mAP，MSVR310 上达到 64.8 mAP。然而，实验假设三模态完整，未验证模态缺失场景下的鲁棒性，且依赖外部 SAM 模型，推理延迟未量化。当传感器故障导致单模态缺失时，分割掩码的生成与超图交互的有效性是否仍能维持，论文未给出回答。
