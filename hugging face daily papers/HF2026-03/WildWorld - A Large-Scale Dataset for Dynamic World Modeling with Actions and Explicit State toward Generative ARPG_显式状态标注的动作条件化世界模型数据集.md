> 交互式视频世界模型旨在构建能感知、交互并预测物理世界演化的内部模拟器，其核心痛点在于现有数据集动作语义贫乏且与像素变化强耦合，导致模型难以学习结构化动态。本文切入点是将动作效果解耦为“动作-状态-像素”的中间表示，通过自动化管线从《怪物猎人：荒野》采集超1.08亿帧带显式状态标注的数据。该工作提供了包含450+语义动作及帧级骨架、HP等状态的数据集与WildBench基准，填补了状态感知世界模型的数据空白，但其模型性能上限未完全探索，且显式状态对未标注隐式状态的泛化能力存疑。

## 研究背景

当模型试图预测“射击”动作后的视觉结果时，若弹药耗尽，画面将无子弹飞出——这一结果无法从当前视觉观测直接推断，必须依赖“剩余弹药数”这一隐式状态变量。这种状态与观测的解耦难题，即状态演化不可见性，导致自回归生成中微小误差随时间指数级放大，引发长时程场景漂移。解决此问题需构建能显式建模状态转移的数据基础设施，而非仅依赖像素级动作标签。

现有交互式视频生成方法如Genie系列与GameNGen确立了动作条件化范式，但多局限于低维潜空间或简单动作（如移动、旋转），动作效果直接映射为视角变化。主流路线将世界状态视为从视觉观测学习的隐式潜在变量，这在开放域场景中难以覆盖所有物理情况，且易受视觉相关性误导。本文针对这一瓶颈，提出通过游戏引擎获取显式、语义丰富的状态标注，将动作控制与像素变化解耦，为学习结构化世界动态提供数据基础。

## 核心方法

### 数据获取与同步架构

本文问题属于游戏引擎数据驱动路线，与GameNGen等工作的关键差异在于：后者侧重实时生成，本文侧重数据标注深度，将重点从“动作-像素”映射转向“动作-状态-像素”映射。

### 显式状态标注体系

设计动机是解决现有数据集动作语义贫乏且与视觉强耦合的问题，使模型能区分“移动左”（视角变化）与“射击”（内部状态变化）。本文构建包含450+动作的语义空间，每帧记录玩家与怪物的绝对位置、旋转、速度、动画ID、生命值（HP）、耐力等状态，以及骨架姿态、相机内外参、深度图。状态作为中间表示，其数学形式可表述为：

$$S_t = f(O_t, A_t)$$

其中 $S_t$ 为显式状态向量，$O_t$ 为视觉观测，$A_t$ 为动作输入。该公式表明状态是动作与观测的联合函数，而非仅从观测推断的隐式变量。

### 自动化采集与过滤管线

设计动机是解决人工录制数据覆盖不足与偏差问题。本文开发基于OBS Studio与Reshade的定制记录系统，通过4个自定义着色器将2K显示分割为4个720p子窗口，分别记录RGB（HEVC有损压缩，目标码率16 Mbps）与深度（无损HEVC，码率约20 Mbps）。嵌入时间戳实现多源同步，并应用五维过滤：时长<81帧、时间间隔>50 ms（30 FPS下1.5倍目标帧间隔）、亮度异常（YUV空间连续15帧极端亮度）、相机遮挡（弹簧臂距离低于阈值）、角色重叠（首帧骨架投影重叠面积>30%）。该管线使数据集扩展至1.08亿帧，覆盖多样化交互场景。

## 实验评估

实验在WildWorld数据集上进行，基线包括Wan2.2-TI2V5B（Baseline）、CamCtrl（相机条件）、SkelCtrl（骨架条件）、StateCtrl（状态条件）及StateCtrl-AR（自回归状态条件）。基线覆盖相机、骨架、状态三条路线，但缺失Genie、Dreamer 4等最新SOTA模型对比。

| 方法 | Video Quality (MS/DD) | Camera Control (ATE/RPE) | Action Following | State Alignment |
| :--- | :--- | :--- | :--- | :--- |
| Baseline | >95% / >95% | - | - | - |
| CamCtrl | - | △2.61 / △0.05 | - | - |
| SkelCtrl | - | - | ~100% 提升 | ~100% 提升 |
| StateCtrl | - | - | 提升 | 提升 |
| StateCtrl-AR | - | - | 低于StateCtrl | 低于StateCtrl |

核心数字对比显示：SkelCtrl在Action Following与State Alignment上实现近100%平均提升，但AQ与IQ下降；StateCtrl-AR的Action Following出现明显下降，归因于迭代状态预测的误差累积。

消融分析揭示视觉信号作为条件输入的权衡：SkelCtrl使用视觉信号获得更大交互指标增益，但牺牲视频质量；StateCtrl学习软嵌入，质量更高但交互增益较小。StateCtrl-AR的Action Following下降证实了自回归误差累积在状态预测中的放大效应，与领域共识中“自回归生成需解决误差累积”一致。

评估边界方面：VBench的MS与DD指标在WildWorld上饱和（>95%），无法区分模型实际运动能力，凸显WildBench细粒度指标的必要性。Action Following与人类判断达成85%一致性，State Alignment对骨架真值达到43.23%坐标精度。可复现性上，论文提供代码URL，但超参数与GPU配置未详细报告。

## 关联研究分析

从问题动机看，本文与Genie形成根本差异：Genie使用隐式潜在动作，从互联网视频学习通用动态；本文使用显式语义动作，从游戏引擎获取结构化状态。这一差异源于任务特性：Genie面向开放域视频生成，隐式状态更灵活；本文面向状态感知世界模型，显式状态更可靠。但显式状态是否在所有场景下优于隐式状态，论文未提供消融实验证明其必要性。

从方法设计看，本文与MIND互补：MIND评估记忆一致性，本文评估状态对齐。MIND关注长时程记忆机制，本文关注动作-状态-像素映射。两者共同指向交互式世界模型的核心挑战：如何在高维视觉流中实现动作条件化的因果一致状态演化。本文的显式状态标注为MIND等记忆机制研究提供了更丰富的数据基础，但两者在评估协议上缺乏统一标准。

## 总结

本文要解决的核心矛盾是动作效果与视觉观测的强耦合导致长时程预测不稳定。现有方法将状态视为隐式潜在变量，难以覆盖所有物理情况；本文通过游戏引擎获取显式状态标注，将动作控制与像素变化解耦。本文构建了1.08亿帧带450+动作及帧级状态标注的数据集WildWorld，并定义WildBench基准。实验证明SkelCtrl在Action Following与State Alignment上实现近100%提升，StateCtrl-AR的Action Following下降证实了自回归误差累积。本文的边界在于：显式状态标注是否限制了模型对未标注隐式状态的泛化能力？当支持集增大到5-shot时，查询侧增强的边际收益是否递减，论文未给出回答。
