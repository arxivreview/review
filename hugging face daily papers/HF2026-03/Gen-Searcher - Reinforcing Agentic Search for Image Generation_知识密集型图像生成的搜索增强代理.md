# HuggingFace最新推荐论文 ｜Gen-Searcher: Reinforcing Agentic Search for Image Generation ｜知识密集型图像生成的搜索增强代理

研究机构：香港中文大学、美国加州大学洛杉矶分校

作者：Kaituo Feng、Manyuan Zhang、Shuang Chen 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.28767)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.28767)

> 现有文生图模型受限于预训练冻结知识，无法准确生成涉及实时实体或复杂事实的图像。传统检索增强生成（RAG）依赖静态数据库且仅做单轮浅层匹配，难以应对需要多跳推理的复杂查询。本文提出 Gen-Searcher，通过监督微调与基于 GRPO 的智能体强化学习，训练一个能自主执行多跳网络搜索、浏览网页并整合视觉参考的代理，以生成更准确的提示词。该方法在自建基准 KnowGen 上将开源模型 Qwen-Image 的得分提升约 16 分，但评估依赖 GPT-4.1 作为裁判，且未验证搜索代理在通用非知识密集型任务上的泛化边界。

## 研究背景

当用户要求生成“某特定历史事件中的具体人物肖像”或“最新发布的科技产品细节”时，文生图模型往往因缺乏实时外部知识而生成错误内容。这种失效源于模型参数化记忆的静态性，即预训练结束后知识不再更新。为弥补这一缺陷，检索增强生成（RAG）被引入，通过从外部数据库检索相关信息辅助生成。然而，标准 RAG 依赖基于相似度的单轮浅层检索，无法处理需要跨多个网页、多步骤证据聚合的复杂查询，导致在知识密集型场景下检索结果不完整或错误。

当前主流路线分为两类：一是基于静态知识库的 RAG 方法，受限于数据库覆盖率和时效性；二是基于手动提示工程的工作流，缺乏自适应规划搜索步骤和推理检索证据的能力，行为脆弱且次优。智能体强化学习（Agentic RL）在深度研究任务中的成功表明，通过强化学习训练智能体进行多步工具交互是可行的。Gen-Searcher 的切入点在于将 Agentic RL 应用于图像生成前置环节，训练一个能主动进行多跳网络搜索和推理的多模态智能体，以动态获取生成所需的文本知识和视觉参考，从而突破静态参数化知识的理论极限。

## 核心方法

### 方法参照系

本文问题属于“检索增强生成”范畴，但与传统 RAG 的关键差异在于：传统 RAG 是单轮、静态、基于相似度的检索；本文要求智能体执行多轮、动态、基于推理的搜索轨迹，并输出增强的提示词与参考图像，而非直接拼接检索片段。

### 数据构建与智能体轨迹生成

设计动机在于解决缺乏高质量“搜索-生成”对齐训练数据的问题。传统方法无法自动产生包含多跳搜索轨迹、最终增强提示词及对应真实图像的四元组数据。本文构建了一个四阶段流水线：首先利用 Gemini 3 Pro 生成约 20 个类别的多跳搜索密集型提示词；其次，让 Gemini 3 Pro 配合搜索工具（search, image_search, browse）执行多轮智能体轨迹，收集证据并生成最终提示词与参考图；接着，使用 Nano Banana Pro 合成地面真值图像；最后，利用 Seed1.8 对样本进行美学、忠实度等多维度评分与过滤。该过程从约 30K 原始样本中筛选出 17K 高质量样本，其中 10K 用于 SFT，6K 用于 RL，630 个人工验证样本构成 KnowGen 基准。

### 双奖励智能体强化学习

设计动机在于解决开源图像生成器（如 Qwen-Image）生成方差大、纯图像奖励噪声高的问题。若仅使用图像质量作为奖励，即使搜索信息正确，生成器可能因随机性产生低质图像，导致奖励信号不稳定。本文引入双奖励机制，结合文本奖励与图像奖励。文本奖励评估搜索得到的提示词是否包含生成目标图像所需的充分信息，提供稳定的语义监督；图像奖励评估最终生成图像的质量，确保搜索证据对实际合成有用。基于 GRPO 算法，智能体在强化学习阶段优化其工具调用轨迹，最大化双奖励的期望值。

$$
R_{total} = \lambda_t R_{text} + \lambda_i R_{image}
$$

其中 $R_{text}$ 由 LLM 评估提示词的信息完备性，$R_{image}$ 由视觉模型评估生成图像质量。该公式表明，智能体的优化目标不仅是生成好看的图，更是确保搜索过程收集到了正确的知识，从而解耦了“搜索正确性”与“生成随机性”的耦合。

## 实验评估

实验在自建 KnowGen 基准和 WISE 基准上进行。KnowGen 包含 630 个人工验证的知识密集型提示词，分为“科学与知识”和“流行文化与新闻”两个子集。基线覆盖开源模型（Qwen-Image, FLUX, SD-3.5 等）和闭源模型（Nano Banana Pro, GPT-Image-1.5）。主实验结果显示，Gen-Searcher-8B 与 Qwen-Image 结合后，KnowGen 总分从 14.98 提升至 31.52，提升 16.54 分。在 WISE 基准上，Qwen-Image 的 Overall 分数从 0.62 提升至 0.77。

| 模型 | KnowGen K-Score | WISE Overall |
| :--- | :--- | :--- |
| Qwen-Image | 14.98 | 0.62 |
| Gen-Searcher-8B + Qwen-Image | 31.52 | 0.77 |
| Nano Banana Pro | 50.38 | - |
| Gen-Searcher-8B + Nano Banana Pro | 53.30 | - |

消融实验验证了各组件的贡献。手动工作流将分数从 14.98 提升至 22.91，SFT 进一步提升至 28.15，完整 RL 模型达到 31.52。移除文本奖励或图像奖励分别导致分数降至 29.59 和 29.36，表明双奖励机制的互补性。值得注意的是，Gen-Searcher 在 Qwen-Image 上训练，但可直接迁移至 Seedream 4.5（提升 16.28 分）和 Nano Banana Pro（提升 2.92 分），显示其搜索策略的通用性。

评估边界方面，K-Score 依赖 GPT-4.1 作为裁判，可能存在评估者偏差；KnowGen 仅包含 630 个样本，统计显著性有限；论文未报告推理延迟和计算成本，而多跳搜索显著增加推理时间。代码已开源，但训练依赖 Gemini 3 Pro 和 Nano Banana Pro 等闭源 API，复现成本较高。

## 关联研究分析

从问题动机看，Gen-Searcher 与 RAG-based 生成方法（如 [4, 5, 6]）的核心差异在于检索深度。RAG 方法假设知识可从静态数据库通过相似度匹配获取，而本文假设知识需通过多跳网络搜索动态聚合。这一差异源于任务特性：知识密集型图像生成往往涉及实体消歧和跨源验证，单轮检索无法解决。然而，论文未探讨当知识存在于结构化数据库而非网页时，搜索代理是否仍优于直接数据库查询，这限制了其在企业级结构化数据场景的适用性。

从方法设计看，Gen-Searcher 与 Vision-DeepResearch [33] 同属多模态搜索智能体，但前者聚焦图像生成，后者聚焦文本研究。关键差异在于奖励设计：Vision-DeepResearch 可能依赖文本答案的正确性，而 Gen-Searcher 引入图像奖励以对齐生成目标。这一设计解决了“搜索正确但生成失败”的噪声问题。但论文未分析文本奖励与图像奖励权重 $\lambda_t, \lambda_i$ 的敏感性，也未探讨当生成器能力极强（如 Nano Banana Pro）时，搜索代理的边际收益是否递减，因为 Nano Banana Pro 本身已具备文本搜索能力，Gen-Searcher 仅带来 2.92 分提升，暗示搜索代理的收益依赖于生成器原生能力的缺失程度。

## 总结

Gen-Searcher 旨在解决文生图模型因冻结知识导致的知识密集型生成失效问题。现有 RAG 方法受限于静态数据库和单轮检索，无法处理多跳复杂查询。本文通过构建专用数据流水线，并利用双奖励智能体强化学习训练搜索代理，实现了搜索策略与生成目标的对齐。实验表明，该方法在 KnowGen 上将 Qwen-Image 的 K-Score 从 14.98 提升至 31.52，并展现出跨生成器的迁移能力。其边界在于评估依赖 GPT-4.1 裁判，且未验证搜索代理在非知识密集型通用任务上的表现。当生成器原生具备强搜索能力时，外部搜索代理的边际收益是否显著，论文未给出回答。
