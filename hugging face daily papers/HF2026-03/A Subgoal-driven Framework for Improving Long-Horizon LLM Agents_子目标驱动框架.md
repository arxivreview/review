# HuggingFace最新推荐论文 ｜A Subgoal-driven Framework for Improving Long-Horizon LLM Agents ｜子目标驱动框架

研究机构：谷歌DeepMind

作者：Taiyi Wang、Sian Gooding、Florian Hartmann 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.19685)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.19685)

> 长程网页导航任务中，智能体常因缺乏中间进度反馈而陷入动作循环或规划失效。现有强化学习微调依赖稀疏二元奖励，难以在长序列中有效分配信用；推理阶段则缺乏动态的进度检查机制。本文提出 MiRA 框架，通过显式子目标统一在线推理规划与离线奖励塑形，解决长程任务中的“中途卡住”问题。该方法显著提升了开源小模型在 WebArena-Lite 上的成功率，但其对基准子集的依赖及子目标生成的可靠性边界尚存疑。

## 研究背景

网页导航任务可形式化为有限时域的部分可观测马尔可夫决策过程（POMDP），其中智能体基于历史观测序列 $o_{\le t}$ 生成离散动作 $a_t$。由于环境状态 $s_t$ 包含不可见的服务端数据与隐藏 DOM 元素，智能体必须依赖完整的交互历史 $[a_1, \dots, a_{t-1}, o_t]$ 来维持上下文连贯性。这种历史依赖性导致长序列任务中，早期步骤的微小偏差会随时间累积，最终引发规划崩溃。

当前 LLM 智能体在长程任务中普遍存在“中途卡住”（Mid-task stuck）现象，即智能体进入非生产性的动作循环或偏离目标路径。实证分析显示，Gemini-2.5-Pro 在 WebArena-Lite 上近 50% 的轨迹出现此类行为，而经过监督微调（SFT）的 Gemma-12B 仍有超过 30% 的失败案例源于此。主流解决方案分为两类：一是层级强化学习（如 VSC-RL），依赖潜空间表示但训练不稳定；二是过程奖励模型（PRM），提供密集反馈但易受噪声干扰且推理开销大。本文切入点在于引入显式、可验证的语义子目标，同时作用于推理时的规划引导与训练时的奖励塑形，以规避潜空间的不透明性与 PRM 的软信号噪声。

## 核心方法

### 方法参照系

本文问题属于目标条件强化学习（GCRL）范畴，但区别于传统 GCRL 的稀疏奖励设定。标准流程中，智能体仅在任务完成时获得二元奖励，导致长序列中信用分配困难。本文的关键差异在于引入中间里程碑（Milestones），将单一终点奖励分解为多个可验证的中间检查点，从而在推理与训练两个阶段同时提供密集信号。

### 推理时子目标规划

推理阶段的核心改动在于将静态的 ReAct 循环升级为子目标引导的动态规划。通常做法是智能体直接根据当前观测生成下一步动作，缺乏对整体进度的监控。本文引入子目标生成器，在推理时动态分解高层目标为结构化子目标 $s_i$。这些子目标作为中间检查点，允许智能体在执行过程中实时评估进度。设计动机在于解决智能体在长序列中“迷失方向”的问题，通过显式的语义检查点提供密集的进度信号，避免智能体陷入局部最优或动作循环。子目标由 Gemini-2.5-Pro 生成，并通过单调性验证（Kendall’s $\tau$ = 0.4585）确保其作为进度估计器的可靠性。

### 里程碑基离线强化学习微调

训练阶段的核心创新是 MiRA 框架，利用基于里程碑的奖励塑形替代稀疏二元奖励。传统 RL 微调中，奖励 $r_t$ 仅在任务结束时非零，导致梯度信号稀疏且延迟。MiRA 引入潜在函数 $P_\psi$ 作为密集奖励源，其核心公式为：

$$
\tilde{r}_t = r_t + \gamma P_\psi(s_{t+1}) - P_\psi(s_t)
$$

该公式通过潜在函数的差分项为每个时间步提供密集的中间奖励，同时保证策略不变性（Policy Invariance）。设计动机在于解决稀疏奖励导致的信用分配困难，使智能体能够识别导致成功的中间动作，而非仅依赖最终结果。MiRA 采用 MSE 回归优化策略，而非 KL 散度最小化，以避免对参考策略 $\pi_{ref}$ 的过度依赖，从而提升离线学习的稳定性。

## 实验评估

实验在 WebArena-Lite（165 任务）上进行，基线覆盖 SFT、AWR、DigiRL、WebRL 及 GPT-4/Gemini 系列。本文方法在开源模型上表现显著：Gemma3+MiRA 达到 43.0% 成功率，远超 Gemma3+SFT 的 6.4% 及 WebRL 的 38.4%。在专有模型上，Gemini-2.5-pro-SGO 达到 32.1%，较基线 Gemini-2.5-pro 的 23.0% 提升约 10 个百分点。

消融实验表明，移除潜在函数（w/o PC）导致性能显著下降，验证了密集奖励的关键作用。使用 KL 散度替代 MSE 回归（w. KL）也导致性能降低，证实了 MSE 在离线学习中的稳定性优势。失败模式分析显示，MiRA 将“中途卡住”错误率从 SFT 的 33% 降至 21%，但“错误终止”错误率上升至 31%，表明智能体更倾向于尝试终止动作，暴露了底层 LLM 语义推理的局限。

评估边界方面，本文仅使用 WebArena-Lite 子集，未在全量 WebArena 上验证，可能规避了环境噪声导致的不可复现性问题。代码未公开，超参数与 GPU 配置未详细披露，限制了可复现性。指标仅关注 Pass@1 成功率，缺乏细粒度的过程评估指标，如步骤级正确性或规划质量。

## 关联研究分析

从问题动机看，本文与 Branch-and-Browse 均针对长程任务中的规划失效，但路线截然不同。Branch-and-Browse 采用树结构推理与动作记忆，通过回溯机制处理早期错误，牺牲实时性换取稳定性。本文则采用线性执行+子目标引导，通过密集奖励塑形提升信用分配，不依赖回溯。差异根源在于任务特性：Branch-and-Browse 适用于可回溯的导航任务，而本文的子目标框架更适合不可逆的表单填写或状态变更任务。

从方法设计看，本文与 WebDART 均涉及动态分解，但 WebDART 强调子任务间的互补性与重规划，而本文子目标在推理时生成，在训练时作为奖励。WebDART 的分解是静态的模块化子任务，而本文的子目标是动态的语义检查点。这一差异暗示，显式子目标在提供密集训练信号方面更具优势，但在处理复杂约束条件时可能不如 WebDART 的模块化分解灵活。

## 总结

本文核心矛盾在于长程网页导航中稀疏奖励导致的信用分配困难与推理时缺乏进度监控。现有方法或依赖不稳定的潜空间表示，或受限于 PRM 的噪声信号，无法同时解决训练与推理阶段的规划失效。本文通过显式子目标统一这两个阶段，利用 MiRA 框架提供密集奖励，显著提升了开源小模型性能（Gemma3+MiRA 达 43.0%）。然而，实验仅在 WebArena-Lite 子集上进行，且子目标生成依赖专有模型 Gemini-2.5-Pro，其可靠性在开源模型上未充分验证。当子目标生成器替换为开源模型时，密集奖励信号的质量是否仍能维持，论文未给出回答。
