# HuggingFace最新推荐论文 ｜From Prior to Pro: Efficient Skill Mastery via Distribution Contractive RL Finetuning ｜分布收缩强化学习

研究机构：美国斯坦福大学

作者：Zhanyi Sun、Shuran Song

论文原文见 [arXiv](https://arxiv.org/abs/2603.10263)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.10263)

> 在稀疏奖励且在线交互昂贵的机器人操作任务中，行为克隆（BC）策略虽能生成物理可行的动作，但常因协变量偏移导致系统性失败，而传统强化学习（RL）后训练易因探索失控偏离预训练分布。现有方法要么直接微调生成式模型导致计算不稳定，要么缺乏对探索范围的有效约束。本文提出 DICE-RL，将 RL 重构为“分布收缩算子”，通过冻结生成式 BC 骨干并训练轻量级残差策略，在保持物理可行性的前提下重加权动作分布。该方法在长时程操作任务中实现了高样本效率与稳定性，但其性能上限受限于预训练策略的动作支持集覆盖度。

## 研究背景

机器人操作任务通常面临高维像素输入与稀疏奖励的双重挑战，在线试错成本极高。行为克隆（BC）通过离线演示学习策略，能生成物理可行的动作，但受限于协变量偏移，在未见配置下易累积误差。为纠正 BC 的系统性失败，研究者引入 RL 后训练，但生成式策略（如扩散模型或流匹配模型）的迭代采样特性使得直接反向传播计算昂贵且不稳定，且无约束的探索易导致策略漂移至非物理区域。

当前主流路线分为三类：直接微调生成模型参数（如 DPPO），虽概念直观但需对去噪链求导，训练脆弱；蒸馏式方法（如 EXPO），通过价值引导生成目标动作再蒸馏，简化了优化但限制了策略超越预训练分布的能力；残差修正方法（如 ResFit），学习轻量级残差模块，但缺乏显式的分布正则化机制，在长时程任务中易因复合误差崩溃。DICE-RL 的切入点在于将 RL 视为对预训练动作分布的“收缩”而非“替换”，通过冻结骨干与选择性正则化，在预训练支持集内实现可控的分布锐化，从而平衡探索丰富性与稳定性。

## 核心方法

### 残差策略参数化

DICE-RL 的核心架构是冻结预训练的流匹配 BC 策略 $\pi_{pre}(s, z)$，并训练一个轻量级残差策略 $s_\theta(s, z)$。这种设计避免了通过 ODE 求解器反向传播的高昂计算成本，同时保留了预训练策略的随机性作为结构化探索源。动作块（Action Chunk）定义为 $a_{t:t+h-1} = \pi_{pre}(s_t, z) + s_\theta(s_t, z)$，其中 $z \sim \mathcal{N}(0, I)$ 为潜在噪声。该参数化将 RL 优化限制在预训练分布的局部邻域内，使得策略更新仅作为对基础动作的微小修正，从而在连续动作空间中实现了可控的探索边界。

### 选择性行为正则化

为解决残差策略可能偏离预训练支持集的问题，DICE-RL 引入了基于价值判断的 BC 损失过滤器。标准 TD3+BC 损失中，BC 正则项 $\|s_\theta(s, z)\|_2^2$ 始终存在，这会抑制必要的偏差。DICE-RL 定义过滤函数 $\mathbb{1}[\mathcal{C}(s, z)]$，仅当残差动作的价值 $Q_\phi(s, a_{cur})$ 高于基础动作价值 $Q_\phi(s, a_{pre})$ 且不超过蒙特卡洛回报估计 $G(s)$ 减去小负常数 $\epsilon$ 时，才放松正则化。

$$
\mathcal{L}_{actor} = -\mathbb{E}_{(s,z) \sim \mathcal{D}} \left[ \min_{i} Q_{\phi_i}(s, \pi_{pre}(s,z) + s_\theta(s,z)) - \mathbb{1}[\mathcal{C}(s,z)] \lambda \|s_\theta(s,z)\|_2^2 \right]
$$

该机制确保策略仅在在线反馈证实动作确实更优时才偏离预训练分布，防止了早期训练中批评者（Critic）乐观偏差导致的策略漂移。

### 多采样期望训练

针对流匹配策略的随机性，DICE-RL 采用多采样期望训练（Multi-sample Expectation Training）。在训练阶段，对每个状态 $s$ 采样 $K$ 个潜在噪声 $\{z_k\}_{k=1}^K$，并计算所有候选动作块的平均价值作为优化目标。

$$
\mathcal{L}_{critic} = \mathbb{E}_{s \sim \mathcal{D}} \left[ \left( \frac{1}{K} \sum_{k=1}^K Q_\phi(s, a^{(k)}) - y \right)^2 \right]
$$

其中 $y$ 为基于 $K$ 个下一状态候选平均价值的 TD 目标。这种设计使残差策略能够改进整个潜在诱导的动作分布，而非过拟合于单次采样，降低了训练方差并提升了样本效率。

## 实验评估

实验在 Robomimic 基准的 Can、Square、Transport 和 Tool Hang 任务上进行，涵盖状态与像素两种观测模态。基线包括 IBRL、DPPO、EXPO、DSRL 和 ResFit，覆盖了直接微调、蒸馏和残差修正三条主要路线。DICE-RL 在所有任务上均取得最高最终成功率，且在长时程任务（如 Tool Hang）中表现出显著的稳定性优势。ResFit 和 EXPO 在简单任务上具有竞争力，但在复杂长时程任务中因缺乏强 BC 正则化而崩溃；DSRL 虽避免了早期遗忘，但样本效率低于 DICE-RL。

| 任务 | 观测模态 | DICE-RL 成功率 | 基线表现特征 |
| :--- | :--- | :--- | :--- |
| Tool Hang | Pixel | ≥90% | ResFit/EXPO 崩溃，DSRL 效率低 |
| Tool Hang | State | ≥90% | 仅 DICE-RL 达到高成功率 |
| Can/Square | Pixel/State | 高 | ResFit/EXPO 具竞争力 |

消融实验表明，预训练策略的“好模式覆盖度”（Good Mode Coverage）与微调效率正相关，而“坏模式熵”（Bad Mode Entropy）越低，失败模式越集中，越易于通过小残差纠正。使用较少离线数据对最终性能影响轻微，说明 RLPD 调度主要提升早期稳定性而非决定最终上限。

评估边界方面，实验仅覆盖 Robomimic 仿真环境，缺乏真实机器人硬件上的大规模统计验证（虽提及皮带组装任务，但未提供详细数据）。代码未公开，超参数细节（如 $\epsilon$ 和 $K$ 的具体取值）未在正文中完全披露，可能影响可复现性。

## 关联研究分析

从问题动机看，DICE-RL 与 TD-JEPA 等潜在预测方法存在根本差异。TD-JEPA 旨在通过预测未来状态嵌入来解耦动态与奖励，服务于零样本适应；而 DICE-RL 聚焦于在线反馈下的分布收缩，不追求任务无关的通用表示，而是针对特定任务的稀疏奖励进行精调。这种差异源于任务设定：TD-JEPA 处理的是“如何理解动态”，DICE-RL 处理的是“如何修正失败”。DICE-RL 的残差机制限制了策略超越预训练支持集的能力，这在预训练数据覆盖不全时可能成为瓶颈，而潜在预测方法通过构建更紧凑的状态空间，理论上具备更强的泛化潜力。

从方法设计看，DICE-RL 与 DrQ-v2 的架构正则化思想一脉相承，但应用场景从像素级 RL 转向生成式策略后训练。DrQ-v2 通过数据增强和自预测目标在像素空间抑制过拟合，而 DICE-RL 通过冻结骨干和 BC 过滤在动作空间抑制漂移。两者的共同点是将架构或正则化设计作为稳定性的来源，而非依赖复杂的算法目标。然而，DICE-RL 未采用对比学习或不变特征提取，这意味着其对视觉噪声的鲁棒性完全依赖于预训练 BC 策略的质量，若预训练策略本身对视觉扰动敏感，DICE-RL 无法在微调阶段纠正这一缺陷。

## 总结

DICE-RL 解决了生成式 BC 策略后训练中探索失控与计算不稳定的矛盾，通过冻结骨干与选择性正则化实现了可控的分布收缩。该方法在 Tool Hang 像素输入下仅用 50 个演示即达到 90% 以上成功率，证明了残差微调在长时程操作中的有效性。其边界在于性能上限受限于预训练策略的动作支持集覆盖度，若预训练策略未覆盖某些关键动作模式，残差修正无法生成全新行为。当预训练演示数量进一步减少至 10 个时，好模式覆盖度是否足以支撑有效的分布收缩，论文未给出回答。
