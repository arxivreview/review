> 数据科学智能体（Data Science Agents, DSA）旨在自动化从数据清洗到洞察生成的全生命周期工作流，但现有评估体系多聚焦于静态代码生成或通用管道执行，忽视了领域特定推理中人类专家不可替代的战略价值。AgentDS 通过构建包含 17 个行业挑战的基准并举办竞赛，首次系统量化了纯 AI 基线与“人-AI 协作”模式在复杂多模态任务上的性能差距。该基准证明当前自主智能体在领域特定推理上存在显著瓶颈，其价值在于确立了人机协作作为当前最优解的实证基础，但合成数据的局限性使其结论向真实工业场景的泛化能力仍存疑。

## 研究背景

数据科学任务的核心难点在于将非结构化信号转化为可预测特征。当模型面对包含图像、文本和表格的异构数据时，通用管道往往因缺乏领域知识而失效，这要求智能体具备跨模态对齐能力。然而，大语言模型（LLM）驱动的自主智能体虽能生成代码，却难以感知数据背后的业务逻辑，导致在需要领域洞察的任务中表现不佳。这种“状态不可见性”与“领域知识缺失”的双重限制，构成了当前 DSA 研究的核心瓶颈。

现有 DSA 研究主要沿两条路线演进：一是以 Data Interpreter 为代表的端到端自主框架，通过 ReAct 范式实现工具调用与代码执行，但在长链推理中易出现错误传播；二是以 VDSAgents 为代表的多智能体协作系统，通过角色分工缓解上下文稀释，但缺乏对领域特定特征工程的深度支持。这些方法均假设 AI 能独立完成任务，却未量化人类专家在问题诊断、特征设计和模型选择中的具体贡献。AgentDS 的切入点在于打破“完全自动化”的假设，通过竞赛机制直接对比纯 AI 基线与人类主导的协作流程，揭示领域特定推理中人类价值的量化边界。

## 核心方法

### 方法参照系

AgentDS 的问题设定属于“评估基准与真实场景脱节”的范畴。通用 DSA 基准（如 DS-1000）通常假设数据已预清洗且问题明确，仅评估代码生成能力。本文的关键差异在于：任务设计强制要求融合多模态信号（图像、PDF、JSON），且通用管道（如 XGBoost 直接作用于表格数据）表现极差，唯有结合领域知识的特征工程才能取得竞争力。

### 领域特定数据生成与难度校准

传统基准的数据生成往往随机化，导致模型可通过过拟合数据分布而非理解领域逻辑来得分。AgentDS 采用四阶段生成流程，核心创新在于将影响预测目标的潜变量嵌入到非表格模态中。例如，在保险欺诈检测中，关键潜变量被编码为屋顶图像，迫使智能体必须提取视觉特征而非仅依赖结构化数据。

$$
\text{Performance}_{\text{generic}} \ll \text{Performance}_{\text{domain-informed}}
$$

该不等式通过基线测试验证：仅使用表格数据的通用模型性能显著低于结合领域特征的方法。这一设计确保了任务难度源于“领域推理缺失”而非“数据噪声”，从而隔离了智能体的领域知识应用能力。

### 分位数评分与层级聚合

为解决不同挑战间指标（如 RMSE、Macro-F1、NDCG）量纲不一致的问题，AgentDS 引入分位数评分机制。对于挑战 $c$ 中成功提交的 $n$ 名参与者，第 $i$ 名参与者的分位数得分 $q_i$ 计算为：

$$
q_i = 1 - \frac{r_i - 1}{n - 1}
$$

其中 $r_i$ 为排名（$r_i=1$ 为最佳）。该公式将原始指标映射至 $[0, 1]$ 区间，使不同挑战的性能可加和。领域得分取该领域内所有挑战分位数的算术平均，总分则为六个领域得分的均值。这种层级聚合（挑战→领域→总分）确保了每个挑战对最终排名的贡献均等，避免了单一高难度任务主导整体评估。

## 实验评估

实验设置基于 10 天竞赛，29 支队伍（80 人）参与，基线包括 GPT-4o 直接提示和 Claude Code 智能体模式。基线审计显示，本文未对比 VDSAgents 或 Tree-Notebook 等结构化编排方法，仅聚焦于“纯 AI”与“人机协作”的二元对比，这可能低估了高级智能体架构在特定子任务上的潜力。

| 基线方法 | 总分 (Quantile Score) | 排名 (out of 29) | 相对中位数 (0.156) |
|---|---|---|---|
| GPT-4o (Direct Prompting) | 0.143 | 17 | 低于中位数 |
| Claude Code (Agentic) | 0.458 | 10 | 高于中位数 |
| 人类团队中位数 | 0.156 | — | — |

Claude Code 的总分 0.458 显著高于 GPT-4o 的 0.143，表明智能体工具调用（迭代代码执行）比单次提示更有效。然而，两者均远低于顶级人类团队，且 Claude Code 仅在制造（0.573）和零售银行（0.553）等结构化程度较高的领域接近人类中位数，在商业（0.021）和零售银行（GPT-4o 为 0.000）等需要复杂领域推理的领域表现极差。

消融分析显示，AI 基线的主要失效模式是“过度依赖通用管道”和“无法利用多模态信号”。例如，在保险挑战中，AI 未能提取图像中的关键特征，而人类团队使用了 DINOv3 等视觉模型。这一发现验证了 AgentDS 的设计假设：领域特定推理无法通过通用代码生成自动获得。

评估边界方面，AgentDS 使用合成数据，虽经领域专家验证，但无法捕捉真实工业数据的噪声和歧义。此外，竞赛仅持续 10 天，样本量（29 队）有限，统计显著性未报告。代码开源，但基线配置（如 Claude Code 的 10 分钟时间预算）可能限制了智能体的探索深度，导致其表现被低估。

## 关联研究分析

从问题动机看，AgentDS 与 Data Interpreter 形成鲜明对比。Data Interpreter 追求端到端自主性，假设 LLM 能独立处理数据清洗到建模的全流程；而 AgentDS 实证表明，在领域特定任务中，自主智能体因缺乏领域知识而失效，人类介入是性能提升的关键。这一差异根源在于任务特性：Data Interpreter 面向通用数据分析，而 AgentDS 聚焦于需要行业洞察的复杂场景，后者对“状态感知”的要求从数据层面扩展到了业务逻辑层面。

从方法设计看，AgentDS 与 VDSAgents 的多智能体协作路线存在互补性。VDSAgents 通过角色分工（定义、探索、建模等）缓解上下文稀释，但所有角色均由 AI 扮演；AgentDS 则发现，即使引入多智能体框架，若缺乏人类战略指导，性能仍受限。这暗示多智能体架构可能更适合作为“人类-AI 协作”的执行层，而非替代人类决策层。VDSAgents 未探索人类在 PCS（可预测性、可计算性、稳定性）评估中的角色，而 AgentDS 证明人类在诊断模型失败和注入领域规则方面具有不可替代性。

## 总结

AgentDS 旨在解决“自主智能体能否替代人类专家”这一核心矛盾，通过构建强制领域推理的基准和竞赛，量化了人机协作的优势。其切入点在于揭示通用管道在异构数据上的失效，并证明人类在问题诊断和特征设计中的关键作用。实验显示，Claude Code 智能体基线总分 0.458，虽高于 GPT-4o 的 0.143，但仍低于顶级人类团队，且在多模态领域表现极差。本文的边界在于使用合成数据，且未对比高级多智能体架构，结论向真实工业场景的泛化能力未经验证。当智能体具备更强的多模态感知能力时，人类在领域特定推理中的优势是否会被进一步压缩，竞赛数据未给出明确答案。
