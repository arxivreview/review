# HuggingFace最新推荐论文 ｜Reasoning as Compression: Unifying Budget Forcing via the Conditional Information Bottleneck ｜条件信息瓶颈下的推理压缩

作者：Fabio Valerio Massoli、Andrey Kuzmin、Arash Behboodi

论文原文见 [arXiv](https://arxiv.org/abs/2603.08462)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.08462)

> 大语言模型在复杂任务上的思维链（Chain-of-Thought, CoT）推理虽提升了准确率，但冗长的生成过程导致计算成本激增，现有“预算强制”方法通过统一长度惩罚或硬截断控制 Token 数，却因忽略 Token 语义差异而误删关键逻辑。本文指出标准信息瓶颈（Information Bottleneck, IB）在 Transformer 架构中存在理论失效，提出条件信息瓶颈（Conditional Information Bottleneck, CIB）框架，将推理压缩重构为基于语义惊讶度的有损压缩问题。该方法通过冻结基座模型计算 Token 信息成本，实现了准确率与压缩率的帕累托最优，但在极高难度任务上仍受限于离散 Token 的表达瓶颈。

## 研究背景

思维链推理依赖自回归生成机制，模型需逐 Token 解码中间步骤以分配测试时计算资源。这一过程引入了显著的计算开销，且长链推理常伴随“过度思考”现象，即冗余步骤不仅未提升性能，反而增加了延迟。为控制成本，研究界引入了“预算强制”策略，试图在固定 Token 预算内最大化准确率。然而，现有方法多采用启发式长度惩罚或静态截断，隐含假设所有 Token 对答案的贡献均等，这种“扁平税”机制无法区分核心推理步骤与冗余填充，导致优化过程脆弱且难以精细调节。

信息瓶颈原则为表示学习提供了理论框架，旨在寻找输入与目标之间的最小充分统计量。然而，标准 IB 假设马尔可夫链 $Y \leftrightarrow X \leftrightarrow Z$，即潜在表示 $Z$ 是信息从输入 $X$ 流向目标 $Y$ 的唯一通道。在 Transformer 架构中，因果注意力机制使解码器在生成答案 $Y$ 时能直接访问提示 $X$，形成了 $(X, Z) \to Y$ 的碰撞结构，违背了标准 IB 的马尔可夫假设。这一理论不一致性被称为“注意力悖论”，导致直接应用标准 IB 会保留关于提示 $X$ 的冗余信息，无法有效压缩推理链。

针对上述理论缺陷与工程瓶颈，本文提出将高效推理重构为条件信息瓶颈问题。通过引入“带侧信息的信源编码”视角，CIB 框架要求推理链 $Z$ 仅编码预测答案 $Y$ 所需且无法从提示 $X$ 直接获取的额外信息。这一视角不仅解决了注意力悖论，还自然导出了基于语义惊讶度的强化学习（Reinforcement Learning, RL）目标，取代了传统的统一长度惩罚，为推理压缩提供了理论指导与可计算的变分界。

## 核心方法

### 方法参照系

现有预算强制方法通常将推理效率优化形式化为在固定 Token 预算 $B$ 下最大化准确率，即寻找推理链 $c$ 使得 $P(y|x, c) \cdot \mathbb{I}(|c| \le B)$ 最大化。这类方法的核心局限在于将 Token 数量作为唯一的成本代理，忽略了不同 Token 携带的信息量差异。本文的关键差异在于将成本函数从线性长度惩罚升级为基于信息论的语义惊讶度，从而在理论上统一了长度约束与信息压缩。

### 条件信息瓶颈目标函数

标准 IB 目标函数为 $\min_{P(Z|X)} I(X; Z) - \mu I(Y; Z)$，其中 $\mu$ 控制压缩与预测的权衡。由于 Transformer 中 $Y$ 可直接访问 $X$，本文引入条件互信息 $I(Y; Z|X)$ 替代 $I(Y; Z)$，构建 CIB 目标：

$$
\min_{\pi_\theta} I(X; Z) - \beta I(Y; Z|X)
$$

其中 $\beta \ge 0$ 控制准确率与压缩率的权衡。该公式的物理含义是：最小化推理链 $Z$ 相对于提示 $X$ 的冗余信息（$I(X; Z)$），同时最大化 $Z$ 在已知 $X$ 条件下对答案 $Y$ 的预测能力（$I(Y; Z|X)$）。这一设计解决了标准 IB 在注意力机制下保留冗余提示信息的问题，确保模型仅保留对答案有增量贡献的推理步骤。

### 语义惊讶度奖励机制

为优化上述目标，需处理 $I(X; Z)$ 中 $P(Z)$ 不可计算的问题。本文引入无条件变分先验 $Q_\phi(Z)$，使用冻结的预训练基座模型（如 Qwen2.5-Base）作为先验分布，其不观察提示 $X$，仅捕捉通用语言统计特性。最小化项 $I(X; Z)$ 的变分上界可推导为：

$$
\mathbb{E}_{X, Z \sim \pi_\theta} \left[ -\log Q_\phi(Z) \right] - H(Z|X)
$$

其中第一项为推理链在先验下的交叉熵率，即累计惊讶度（surprisal）；第二项为策略熵，在 PPO 等算法中通过熵正则化处理。该设计动机在于，通过冻结基座模型计算每个 Token 的惊讶度 $-\log Q_\phi(z_t)$，实现了基于语义的信息成本分配：高惊讶度 Token（如关键逻辑转折）需通过提升准确率来“支付”成本，而低惊讶度冗余 Token（如填充词）则被抑制。这解决了统一长度惩罚无法区分 Token 语义重要性的问题，使压缩过程具有语义感知能力。

## 实验评估

实验在 MATH500、AIME24、AIME25、Minerva 和 OlympiadBench 五个数学推理基准上进行，使用 vLLM 作为推理引擎（温度 0.6，top-p 0.95，最大 Token 32K，每提示 16 次生成），报告 Pass@1 准确率。基线包括 DLER-1.5B/7B、DeepScaleR-1.5B 以及 L3L1-1.5B（LCPO 方法）。本文方法在 DLER 和 DeepScaleR 模型上应用 CIB 目标，使用 Qwen2.5-Base（1.5B/7B）作为先验，通过 GRPO 进行训练。

| 模型 | MATH500 Acc. | MATH500 Tok. | AIME24 Acc. | AIME24 Tok. | 平均 Acc. | 平均 Tok. |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| DLER-1.5B | 86.4 | 1873 | 33.5 | 3482 | 43.7 | 2793 |
| CIB $Q_\phi=1.5B$ $\beta_-$ | 86.8 | 1724 | 37.3 | 3329 | 45.1 | 2630 |
| CIB $Q_\phi=7B$ | 85.0 | 805 | 32.7 | 2532 | 42.5 | 1724 |
| L3L1-1.5B-EXACT | 85.0 | 1932 | 24.4 | 2637 | 39.7 | 2333 |

在 DLER-1.5B 上，CIB 方法在保持准确率基本不变（86.8% vs 86.4%）的情况下，将平均 Token 数从 2793 降至 2630（-6%），并在 AIME24 上取得 37.3% 的准确率，显著高于基线的 33.5%。相比之下，L3L1-1.5B-EXACT 虽然实现了更高的压缩率（平均 Token 2333），但准确率大幅下降至 39.7%，表明其激进压缩牺牲了推理可靠性。在 DeepScaleR-1.5B 上，CIB $Q_\phi=7B$ 实现了 41% 的 Token 压缩（6722 降至 3951），准确率仅下降 0.7 个百分点（44.7% 至 44.0%），验证了语义惊讶度在激进压缩下的鲁棒性。

消融实验显示，先验模型规模对压缩效率有显著影响。使用 7B 先验（$Q_\phi=7B$）相比 1.5B 先验（$Q_\phi=1.5B$）允许更强的压缩，因为更大的先验能更准确地估计 Token 的通用语言概率，从而更精确地识别冗余。例如，在 DLER-1.5B 上，$Q_\phi=7B$ 将 MATH500 的 Token 数从 1724 进一步降至 805，而准确率仅从 86.8% 降至 85.0%。这一发现表明，先验模型的信息容量是决定压缩上限的关键因素，而非简单的超参数调节。

评估边界方面，本文仅在数学推理任务上验证了 CIB 的有效性，未覆盖代码生成或抽象推理等非数学任务。实验未报告置信区间，且所有结果基于单一推理引擎配置，缺乏跨硬件或跨推理框架的泛化性验证。此外，论文未提供开源代码，仅通过 HuggingFace 公开基线模型，限制了第三方复现与对比的便利性。

## 关联研究分析

从问题动机看，CIB 与 L3L1（LCPO）均旨在解决推理链冗长问题，但二者对“冗余”的定义存在根本差异。L3L1 基于目标长度惩罚，隐含假设存在一个“黄金长度”，任何偏离均被视为错误，这导致其在复杂任务上因过度压缩而准确率骤降（AIME24 仅 24.4%）。CIB 则通过语义惊讶度动态定义冗余，允许模型根据 Token 的信息贡献灵活调整长度，从而在 AIME24 上取得 37.3% 的准确率。这一差异源于 L3L1 缺乏对 Token 语义重要性的感知机制，而 CIB 通过信息论框架实现了语义感知的压缩。

从方法设计看，CIB 与潜在推理方法（如 CODI）在理论上有共鸣，但路径不同。CODI 通过自蒸馏将 CoT 压缩至连续潜在空间，旨在突破离散 Token 的表达瓶颈，但在 GSM8K 隐式推理上准确率仅 39.0%，远低于显式方法。CIB 保持在离散 Token 空间，通过优化 Token 选择而非改变表示形式，因此在可解释性上优于潜在推理，但在表达复杂度上受限。CIB 的语义惊讶度机制可视为离散压缩向连续推理过渡的桥梁，但其有效性依赖于冻结基座模型对任务语义的捕捉能力，这在非数学任务上可能失效。

## 总结

本文针对长 CoT 推理中统一长度惩罚导致的语义误删问题，提出了条件信息瓶颈框架，解决了标准 IB 在 Transformer 注意力机制下的理论失效。通过引入基于冻结基座模型的语义惊讶度作为 Token 成本，CIB 实现了准确率与压缩率的帕累托最优，在 DLER-1.5B 上将平均 Token 数降低 6% 的同时提升 AIME24 准确率 3.8 个百分点。然而，实验仅在数学任务上验证，且激进压缩（41%）下准确率仍出现小幅下降，表明离散 Token 空间的信息容量存在上限。当任务复杂度进一步增加，语义惊讶度能否准确区分关键逻辑与冗余填充，论文未给出回答。
