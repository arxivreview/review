# HuggingFace最新推荐论文 ｜Do VLMs Need Vision Transformers? Evaluating State Space Models as Vision Encoders ｜视觉状态空间模型作为VLM冻结骨干的受控评估

研究机构：美国石溪大学

作者：Shang-Jui Ray Kuo、Paola Cascante-Bonilla

论文原文见 [arXiv](https://arxiv.org/abs/2603.19209)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.19209)

> 视觉语言模型（VLM）长期依赖ViT作为冻结视觉骨干，但其在固定token预算下提取空间定位证据的能力存在上限。现有对比实验常混淆架构、预训练目标与接口几何的影响，导致无法隔离骨干本身的贡献。本文通过严格匹配训练协议，系统替换ViT、混合架构与SSM骨干，发现SSM骨干在定位任务上显著优于同规模Transformer，且该优势独立于ImageNet分类精度。这一发现挑战了“分类精度决定VLM性能”的默认假设，但SSM骨干在高分辨率检测预训练下的定位崩溃现象，暴露了接口稳定性这一被忽视的失效模式。

## 研究背景

VLM的模块化设计将视觉编码、特征映射与语言生成解耦，其中视觉骨干在指令微调阶段通常保持冻结。这种冻结策略旨在隔离架构效应与联合优化动态，使得不同骨干可在相同多模态训练配方下公平比较。然而，主流VLM系统几乎清一色采用ViT或其变体，导致视觉骨干的架构多样性被严重压缩，且多数对比实验同时改变预训练目标、分辨率与连接器设计，使得无法归因于单一架构因素的性能差异。

视觉骨干的核心挑战在于如何在固定多模态token预算下保留空间定位信息。ViT通过全局自注意力建模长程依赖，但其扁平化token序列在定位任务中往往丢失细粒度空间结构；而SSM骨干通过多方向扫描在2D网格上构建状态空间更新，理论上能更好地保留空间邻接性。现有研究多关注SSM在单模态密集预测任务中的表现，却缺乏在VLM生成场景下的受控评估，特别是SSM骨干与LLM接口（连接器、分辨率几何）的稳定性问题。

## 核心方法

### 受控骨干替换框架

本文采用LLaVA风格的VLM架构，包含冻结视觉编码器、轻量级连接器与Vicuna-7B语言模型。为隔离骨干架构效应，所有实验保持训练配方、优化超参数与随机种子完全一致，仅替换视觉骨干检查点。对于多阶段骨干（VMamba、MaxViT、MambaVision），统一提取产生196个视觉token的阶段特征，确保与ViT/16的token数量匹配。该框架的关键差异在于：不同于以往同时改变预训练目标与接口几何的对比，本文首先严格匹配IN1K/224设置以隔离架构效应，再单独分析预训练目标与接口几何的影响。

### 预训练目标与接口几何解耦分析

在匹配架构的基础上，本文进一步解耦两个影响VLM性能的因素：视觉预训练目标（分类vs.检测/分割）与视觉-语言接口（输入分辨率/几何与连接器容量）。对于密集目标预训练，本文使用IN1K→COCO检测预训练的ViTDet与VMamba，以及IN1K→ADE20K分割预训练的DeiT与VMamba。接口几何方面，检测预训练检查点使用1333×800或512×512分辨率，分割预训练使用512×512，导致不同骨干产生不同长度的视觉token序列。连接器定义为两层MLP：$C_\psi(x) = W_2 \text{GELU}(W_1 x + b_1) + b_2$，其中$W_1 \in \mathbb{R}^{d_{\text{text}} \times d_{\text{vis}}}$，$W_2 \in \mathbb{R}^{d_{\text{text}} \times d_{\text{text}}}$。该设计动机在于：标准连接器容量可能不足以传输密集预训练骨干产生的高维空间结构，导致定位性能崩溃。

### 定位崩溃诊断与稳定化策略

本文发现部分检测预训练配置（ViTDet-L/H、VMamba-T/B）在定位基准上出现急剧性能下降，称为“定位崩溃”。为诊断崩溃原因，本文测试两种稳定化策略：(i) 增加连接器容量（标记为(f)），以改善空间结构向LLM嵌入空间的传输；(ii) 改变输入几何为512×512方形，以减少密集任务适配检查点的不稳定性。稳定化效果通过定位基准的加权平均分量化。该创新解决了此前方法在高分辨率检测预训练下定位性能不可预测的问题，提供了可操作的部署指南。

## 实验评估

在IN1K/224匹配设置下，VMamba-T/S/B在定位基准上全面领先，其中VMamba-T在RefCOCO达58.25%，较ViT-S的32.32%提升25.93个百分点；在VQA基准上，VMamba-S的加权平均分62.39%也高于ViT-B的57.17%。基线覆盖ViT、MaxViT、MambaVision三类架构，但缺失HAMSA、PRISMamba等最新SSM变体，且未包含CLIP、DINOv2等对比学习预训练骨干在主实验中的系统对比（仅在附录中提供部分结果）。

消融实验揭示两个反直觉发现：(1) ImageNet精度与VLM性能负相关——MaxViT-L的IN1K精度84.93%高于MaxViT-T的83.41%，但定位性能从15.79%降至10.81%；(2) 骨干规模扩大不必然提升性能——VMamba-B的定位性能27.89%低于VMamba-T的39.20%。定位崩溃的稳定化效果显著：ViTDet-L在增加连接器容量后，RefCOCO从24.62%提升至65.73%，加权定位从13.05%提升至44.58%；VMamba-T在改变输入几何为512×512后，加权定位从14.86%提升至47.94%。

评估协议存在局限：(1) 未报告置信区间，数值比较需谨慎；(2) 密集预训练检查点的输入几何不匹配（1333×800 vs. 512×512），导致token长度差异，无法完全隔离架构效应；(3) 代码基于prismatic-vlms，使用4×H200 GPU，但完整超参数与随机种子细节仅在附录中提供，可复现性依赖附录完整性。

## 关联研究分析

从问题动机看，本文与MambaOut（2025）形成互补：MambaOut揭示选择性扫描在视觉分类中可被门控CNN替代，质疑SSM的核心优势来源；而本文通过VLM定位任务提供反例，证明SSM骨干在空间定位上优于ViT，暗示SSM的优势可能源于空间结构保留而非选择性扫描机制本身。这一差异的根源在于任务特性：分类任务对全局依赖要求较低，而定位任务需要精细的空间上下文，SSM的多方向扫描在此类任务中更具优势。

从方法设计看，本文与PRISMamba（2026）的扫描策略优化路线不同：PRISMamba通过部分环扫描提升旋转鲁棒性，关注骨干内部的空间感知能力；而本文关注骨干与LLM的接口稳定性，发现接口几何比扫描路径更影响VLM定位性能。这一差异暗示：在VLM场景中，骨干的空间感知能力需通过连接器有效传输至LLM，否则即使骨干具备强空间表示，定位性能仍会崩溃。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文要解决的核心矛盾是：如何在固定多模态token预算下，识别能最大化空间定位证据提取的视觉骨干架构。现有方法无法做到这一点，因为多数对比实验混淆了架构、预训练目标与接口几何的影响；本文通过严格匹配训练协议与解耦分析，证明了SSM骨干在定位任务上的优势独立于ImageNet分类精度。本文证明了VMamba-T在RefCOCO达58.25%，较ViT-S提升25.93个百分点，且定位崩溃可通过连接器扩容或几何调整稳定化。本文的边界在于：密集预训练检查点的输入几何不匹配导致token长度差异，无法完全隔离架构效应；且未系统评估最新SSM变体（如HAMSA、PRISMamba）在VLM中的表现。当骨干规模继续扩大至700M以上时，接口稳定性问题是否会重新出现，论文未给出回答。
