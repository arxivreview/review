# HuggingFace最新推荐论文 ｜WildActor: Unconstrained Identity-Preserving Video Generation ｜无约束视角下的人体视频身份保持

研究机构：美团、香港科技大学

作者：Qin Guo、Tianyu Yang、Xuanhua He 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.00586)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.00586)

> 视频生成中的身份漂移源于视角变化时参考图与生成内容的时空混淆，现有方法或过度依赖面部特征导致身体幻觉，或因姿态锁定产生复制粘贴伪影。WildActor 通过构建大规模野外多视角数据集 Actor-18M，并设计非对称注意力机制与视角自适应采样策略，实现了无约束视角下的全身身份一致性。该工作证明了数据规模与视角多样性对鲁棒性的决定性作用，但其依赖 LoRA 微调的范式与领域主流的免微调趋势存在效率上的张力，且仅在自建基准上验证了性能。

## 研究背景

视频扩散模型在生成逼真动态场景时，常面临身份特征随视角变化而退化的困境。这一现象被称为身份漂移，其根源在于参考图像中的静态外观线索与视频中的动态运动线索在特征空间中发生耦合。当模型无法区分“谁在动”与“谁是谁”时，参考图的姿态会限制生成动作，导致复制粘贴伪影；或者面部特征被过度强调，而身体部分产生幻觉，形成漂浮头效应。解决这一矛盾的关键在于建立视角不变的人体表征，这要求模型在训练阶段接触足够多样的视角数据，并在推理阶段实现身份信息与运动信息的解耦。

当前主流的视频身份保持方法主要沿两条路线演进：一是基于面部识别嵌入的注入，如 InstantID 和 PuLID，它们通过交叉注意力将 ArcFace 嵌入注入 DiT 骨干，但这类方法本质上是面部中心的，忽略了身体层面的身份一致性；二是基于全图拼接的参考条件化，如 VACE，它直接编码整张参考图，但容易引发姿态锁定，使生成角色僵化在参考视角。此外，现有数据集如 Virtually Being 依赖昂贵的摄影棚多视角采集，难以覆盖真实世界的复杂光照与背景变化。WildActor 的切入点在于，通过构建包含 1.6M 视频和 18M 参考图像的野外数据集 Actor-18M，提供密集的多视角监督，并设计专门的注意力机制来隔离身份与运动，从而在无约束条件下实现全身身份保持。

## 核心方法

### 方法参照系

本文任务属于任意视角条件化的人体视频生成。标准流程通常将参考图像编码为特征向量，通过交叉注意力注入视频 DiT 的去噪过程。本文与通用流程的关键差异在于，它不依赖单一的全局身份嵌入，而是同时处理多视角面部与身体参考图，并引入了非对称的信息流动机制，以防止参考图对视频动态生成的干扰。

### 非对称身份保持注意力

标准自注意力机制允许视频 Token 与参考 Token 双向交互，这导致参考图中的静态姿态信息反向污染视频的运动轨迹，引发姿态锁定。WildActor 引入非对称身份保持注意力（AIPA），强制信息单向流动：视频 Token 作为查询（Query）去检索参考 Token 的身份线索，而参考 Token 仅进行自注意力聚合，不与视频 Token 交互。具体而言，参考 Token 首先通过独立的自注意力聚合多视角信息，形成统一的身份表征 $C_{ref}$；随后，视频 Token 在计算注意力时，其 Key 和 Value 由视频自身特征与 $C_{ref}$ 拼接而成。这种设计确保了身份特征仅作为条件输入，而不参与运动动态的建模，从而在保持身份保真度的同时，保留了视频生成的自由度。

$$
\text{Attn}(Q_{video}, K_{video} \oplus K_{ref}, V_{video} \oplus V_{ref})
$$

该公式表明，视频 Token 的注意力计算中，Key 和 Value 包含了参考 Token 的信息，但参考 Token 的 Query 并不包含视频 Token，实现了信息流的单向隔离。

### 视角自适应蒙特卡洛采样

在训练阶段，随机采样多视角参考图往往导致视角冗余（如多张正面图），阻碍模型学习视角不变性。WildActor 提出视角自适应蒙特卡洛采样策略，通过动态重加权鼓励互补视角的覆盖。当采样到一张参考图 $x^*$ 后，其角度邻域 $|\theta_{x^*} - \theta_{x_j}| < \delta$ 内的其他候选图权重会被衰减，衰减因子为 $\gamma$。

$$
w_j \leftarrow w_j \cdot \gamma, \quad \text{if } |\theta_{x^*} - \theta_{x_j}| < \delta
$$

这一机制迫使采样器在训练过程中优先选择视角差异大的参考图，使模型在有限样本内学习到更广泛的视角变换规律，从而提升对大角度变化的鲁棒性。

## 实验评估

实验在自建基准 Actor-Bench 上进行，包含 75 个主体，分为规范三视图、任意视角和野外场景三类设置。基线对比覆盖了 VACE、Stand-In 等开源模型，以及 Kling 1.6、Vidu Q2 等闭源商业模型，但缺失了 Lynx、WildActor 等近期 SOTA 视频方法的对比。主实验结果显示，WildActor 在上下文泛化设置下取得了最高的身体一致性分数 0.952，显著优于 Vidu Q2 的 0.905 和 Stand-In 的 0.416。在面部身份保持上，WildActor 得分 0.559，略低于 Vidu Q2 的 0.565，但后者可能通过激进的外观复制换取了面部相似度，牺牲了结构灵活性。

| 方法 | 参数 | Face Identity↑ | Body Consistency↑ | Feature-Level↑ | VLM-Level↑ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| VACE | 14B | 0.485 | 0.582 | 0.221 | 0.667 |
| Stand-In | 14B | 0.510 | 0.416 | 0.218 | 0.600 |
| Vidu Q2* | – | 0.565 | 0.905 | 0.241 | 0.880 |
| Kling 1.6* | – | 0.558 | 0.885 | 0.239 | 0.867 |
| WildActor | 5B | 0.559 | 0.952 | 0.238 | 0.920 |

消融实验揭示了数据策略与模型组件的关键贡献。在数据策略上，原始裁剪（Raw-Crop）在正面视角表现稳健，但在侧面和背面视角显著退化；引入视角自适应采样后，平均身体一致性从 0.840 提升至 0.952，尤其在背面视角下从 0.680 跃升至 0.937，证明了视角多样性对鲁棒性的决定性作用。在模型组件上，移除 AIPA 导致语义对齐分数大幅下降，表明标准注意力确实引发了参考特征与文本控制的冲突；移除 I-RoPE 则导致身体一致性急剧下降，证实了时空位置编码分离对区分运动与静态外观的必要性。

| 设置 | Body Consistency (Front) | Body Consistency (Side) | Body Consistency (Back) | Average |
| :--- | :--- | :--- | :--- | :--- |
| Raw-Crop | 0.885 | 0.725 | 0.680 | 0.785 |
| Random Sampling | 0.915 | 0.840 | 0.785 | 0.840 |
| Viewpoint-Adaptive | 0.958 | 0.952 | 0.937 | 0.952 |

评估边界方面，本文仅使用自建 Actor-Bench，未在 OpenS2V-Eval 等公开基准上验证，限制了跨数据集的可比性。指标上，面部身份使用 ArcFace 余弦相似度，身体一致性依赖 Gemini-3-Pro 的 VLM 评估，后者可能存在主观偏差。可复现性方面，论文提供了详细的超参数设置（如 LoRA rank 128，学习率 1e-4），但未明确说明代码开源状态，且训练依赖 16 块 H100 GPU 进行 80K 步微调，计算成本较高。

## 关联研究分析

从问题动机看，WildActor 与 Virtually Being 均致力于解决视角不变性，但前者摒弃了后者对昂贵摄影棚数据的依赖，转向野外数据。这一差异的根源在于任务场景的定义：Virtually Being 假设受控环境，而 WildActor 面向无约束的真实世界。然而，WildActor 依赖大规模数据增强（如 View-Aug）来弥补野外数据的视角不平衡，这是否能在小样本场景下泛化，论文未给出回答。相比之下，InstantID 等免微调方法通过轻量级适配器实现身份注入，计算效率更高，但 WildActor 采用 LoRA 微调骨干，虽然提升了保真度，却牺牲了即插即用的部署效率，这与领域内免微调的主流趋势相悖。

从方法设计看，WildActor 的 AIPA 机制与 SpatialID 的空间自适应调制有异曲同工之妙，均旨在解决全局注入导致的污染问题。但 SpatialID 通过空间掩码限制身份信号仅在面部区域注入，而 WildActor 通过非对称注意力隔离参考 Token 与视频 Token 的交互。这种差异源于任务对象的不同：SpatialID 关注图像生成中的局部身份保持，而 WildActor 关注视频生成中的全身身份保持。WildActor 的 I-RoPE 通过时空坐标分离视频与参考 Token，这一设计在图像生成中并无对应物，因为图像缺乏时间维度。这种时空解耦是否能在更长的视频序列中保持稳定性，尤其是在长时程的身份漂移累积效应下，仍需进一步验证。

## 总结

WildActor 旨在解决视频生成中视角变化导致的身份漂移与姿态锁定矛盾，其切入点在于通过大规模野外多视角数据与解耦的注意力机制，实现身份与运动的正交分离。该方法通过 AIPA 隔离参考信息流，结合视角自适应采样优化训练分布，在自建基准上实现了 0.952 的身体一致性，显著优于现有方法。然而，其依赖 LoRA 微调的范式与领域免微调共识存在效率冲突，且仅在特定数据分布上验证了性能。当参考图数量减少或视角极端偏离训练分布时，视角自适应采样的边际收益是否递减，论文未给出回答。
