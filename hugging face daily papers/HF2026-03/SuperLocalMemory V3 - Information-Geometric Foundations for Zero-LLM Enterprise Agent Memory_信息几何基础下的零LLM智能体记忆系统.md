> 智能体记忆系统长期依赖余弦相似度检索与启发式衰减，缺乏对检索不确定性、生命周期收敛性及跨上下文一致性的数学保证，导致大规模部署时可靠性不可控。本文切入点在于将信息几何、层上同调与黎曼流形动力学引入记忆架构，通过Fisher-Rao加权检索、层上同调一致性验证与朗之万生命周期动力学，构建具备可证明收敛性与代数一致性保证的记忆系统。在LoCoMo基准上，数学层带来+12.7pp平均提升，零LLM模式实现74.8%准确率，但云增强模式仅基于单会话评估，统计显著性存疑。

## 研究背景

当智能体在长程对话中积累记忆时，嵌入空间的维度方差呈现非均匀分布：部分维度编码稳定的语义区分，另一些维度则承载噪声或分布伪影。余弦相似度将所有维度视为同等可靠，无法区分高置信度与低置信度信息，导致检索结果在记忆密度增加时噪声比例上升。这一缺陷催生了对统计精度感知检索的需求，而Fisher信息度量恰好提供了这种逐维度的统计精度权重，其唯一性由Čencov定理保证——它是统计流形上唯一在充分统计量下不变的黎曼度量。

智能体记忆系统的核心矛盾在于：模型能力已实现数量级提升，但记忆基础设施仍停留在工程启发式层面。主流系统如Mem0、Zep v3均采用余弦相似度检索、固定指数衰减或TTL窗口管理记忆生命周期，且无形式化机制检测跨上下文矛盾。这种“工程单文化”导致三个基础缺口：检索对维度不确定性盲视、生命周期管理无法适应记忆库的统计结构演化、矛盾检测依赖相似度排序而非逻辑一致性验证。本文的切入点是将这三个缺口分别映射到信息几何、代数拓扑与随机动力学三个数学分支，为记忆操作提供可证明的理论基础。

## 核心方法

### 多通道检索架构参照系

本文问题属于存储与检索优化路线，但关键差异在于：主流方法（如HippoRAG、GAAMA）依赖显式知识图谱或向量相似度，而本文采用统计流形几何替代结构关系建模。四通道检索架构（语义Fisher-Rao、BM25关键词、实体图、时间推理）通过加权倒数排名融合（WRRF）生成候选集，数学层（Fisher-Rao、层上同调、朗之万动力学）作为独立组件嵌入该架构，而非重构检索范式本身。

### Fisher-Rao加权检索

余弦相似度在异方差嵌入空间中失效：当两个记忆在查询向量上的余弦值相同但方差结构不同时，相似度排序无法区分高置信度与低置信度记忆。本文用对角高斯族的Fisher-Rao距离替代余弦相似度，每个记忆嵌入$\mu \in \mathbb{R}^d$附加方差向量$\sigma^2 \in \mathbb{R}^d_{>0}$，距离定义为：

$$d_{FR}(\mu_a, \mu_b) = \sqrt{\sum_{k=1}^d \frac{(\mu_{a,k} - \mu_{b,k})^2}{\sigma_{a,k}^2 + \sigma_{b,k}^2}}$$

该公式的物理含义是：低方差维度（高统计精度）对距离贡献更大，高方差维度（低精度）贡献被抑制。设计动机在于解决余弦相似度在记忆密度增加时检索噪声比例上升的问题，Fisher-Rao度量通过逐维度加权，使检索结果在稀疏高维区域更具区分力。

### 层上同调一致性验证

跨会话、跨交互伙伴的记忆积累必然产生矛盾（如用户偏好变更、事实更新），但现有系统无形式化机制检测此类矛盾，仅按相似度排序返回最高分记忆。本文将记忆库建模为图上的胞层上同调（cellular sheaf），顶点为记忆上下文，边为共享实体，上同调将局部记忆声明分配至顶点，限制映射强制语义兼容性。非平凡第一上同调类$H^1(\mathcal{F}) \neq 0$对应不可通过局部调整解决的矛盾：

$$H^1(\mathcal{F}) = \ker(\delta^1) / \text{im}(\delta^0)$$

该公式的物理含义是：若存在1-链（边上的记忆声明差异）其边界为零（顶点声明一致）但非精确（无法由顶点声明生成），则存在全局不可调和矛盾。设计动机在于提供代数一致性保证，替代相似度排序的“静默不一致”，使矛盾检测从启发式匹配升级为拓扑不变量计算。

## 实验评估

实验在LoCoMo基准上进行，包含10段多会话对话（1,986个问题），采用LLM-as-Judge评分（≥4分计为正确）。基线覆盖EverMemOS、Hindsight、Zep v3、MemOS v2、Mem0，但缺失MemCog（95.8%）、D2ACCI（93.59%）等2026年最新SOTA对比。主结果如下：

| 系统 | Single | Multi | Temporal | Open | Aggregate |
|---|---|---|---|---|---|
| EverMemOS | 96.1 | 91.1 | 89.7 | 70.8 | 92.3 |
| Hindsight | 86.2 | 70.8 | 95.1 | 83.8 | 89.6 |
| Zep v3 | 90.8 | 81.9 | 77.3 | 75.0 | 85.2 |
| SLM-V3 Mode C | 64.0 | 100.0 | — | 86.0 | 87.7 |
| MemOS v2 | 85.4 | 79.4 | 75.1 | 64.6 | 80.8 |
| SLM-V3 Mode A (Ret.) | 72.0 | 70.3 | 80.0 | 85.0 | 74.8 |
| Mem0 | 69.0 | 61.7 | 58.3 | 50.0 | 64.2 |
| SLM-V3 Mode A (Raw) | 57.5 | 43.0 | 63.0 | 72.0 | 60.4 |

SLM-V3 Mode C（87.7%）低于EverMemOS（92.3%）4.6pp，但Mode A Retrieval（74.8%）是零LLM配置下最高分，超越Mem0（64.2%）10.6pp。消融研究揭示交叉编码器重排序是最大贡献者（移除后-30.7pp），Fisher-Rao度量次之（-10.8pp），数学层整体贡献-7.6pp。

| 配置 | LoCoMo (%) | Δ (pp) |
|---|---|---|
| SLM-V3 (full system) | 60.4 | — |
| −Fisher metric | 49.6 | −10.8 |
| −Sheaf consistency | 58.7 | −1.7 |
| −All math layers | 52.8 | −7.6 |
| −BM25 channel | 53.9 | −6.5 |
| −Entity graph | 59.4 | −1.0 |
| −Temporal channel | 60.2 | −0.2 |
| −Cross-encoder | 29.7 | −30.7 |

Fisher-Rao贡献（-10.8pp）显著大于层上同调（-1.7pp）与时间通道（-0.2pp），表明统计精度感知检索比代数一致性验证对当前基准性能影响更大。跨六会话的Fisher-Rao贡献分析显示，改进幅度从conv-43的+6.0pp到conv-44的+19.9pp，与对话难度正相关，验证了理论预测：Fisher-Rao优势在嵌入空间密度增加时增强。

评估边界存在显著局限：Mode C仅基于conv-30的81个问题，Bootstrap 95%置信区间为[53.4, 74.0]，样本量不足以支撑87.7%的结论；Mode A Raw（60.4%）与Mode A Retrieval（74.8%）的差距表明答案生成质量对最终性能影响显著，但论文未分离检索质量与生成质量的独立贡献。代码以MIT许可开源，但实验依赖Azure Container Instances（2 vCPU, 4 GB RAM），未报告GPU使用或端到端延迟数据。

## 关联研究分析

从问题动机看，本文与Mem0、Zep v3等系统共享“外部存储+检索”范式，但关键差异在于数学基础的引入。Mem0依赖余弦相似度与知识图谱叠加，在LoCoMo上取得64.2%准确率；本文用Fisher-Rao度量替代余弦相似度，在零LLM模式下取得74.8%，提升10.6pp。这一差异的根源在于：Mem0的检索对维度不确定性盲视，而Fisher-Rao通过逐维度统计精度加权，在记忆密度增加时提供更精细的排序。但本文未探索Fisher-Rao与显式知识图谱（如HippoRAG的个性化PageRank）的协同效应，查询侧结构关系建模与统计精度感知是否互补，论文未给出回答。

从方法设计看，本文的层上同调一致性验证与SuperLocalMemory V3的信息几何遗忘机制形成理论互补。SuperLocalMemory V3用黎曼朗之万动力学驱动记忆保留与遗忘，但缺乏矛盾检测的形式化保证；本文引入层上同调，提供代数一致性验证，但消融显示其贡献仅-1.7pp，远小于Fisher-Rao的-10.8pp。这一差异暗示：在LoCoMo基准的对话记忆任务中，检索精度比一致性验证对性能影响更大，层上同调的价值可能在更复杂的跨上下文矛盾场景中才能体现。本文未设计专门针对矛盾检测的评估协议，层上同调在真实部署中的实际效用，论文未给出回答。

## 总结

本文要解决的核心矛盾是智能体记忆系统缺乏数学基础导致的可靠性不可控。切入点在于将信息几何、层上同调与黎曼流形动力学引入记忆架构，通过Fisher-Rao加权检索、层上同调一致性验证与朗之万生命周期动力学，构建具备可证明收敛性与代数一致性保证的记忆系统。在LoCoMo基准上，数学层带来+12.7pp平均提升，零LLM模式实现74.8%准确率，超越Mem0 10.6pp。本文的边界在于：Mode C仅基于单会话评估，统计显著性不足；层上同调贡献仅-1.7pp，其实际效用未在矛盾密集场景中验证；Fisher-Rao与显式知识图谱的协同效应未探索。当记忆库规模从数百增长到数万时，Fisher-Rao的统计精度感知优势是否持续增强，层上同调的代数一致性保证是否成为瓶颈，论文未给出回答。
