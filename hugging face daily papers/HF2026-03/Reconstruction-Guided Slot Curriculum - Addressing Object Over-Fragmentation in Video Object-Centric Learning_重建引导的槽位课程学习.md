作者：WonJun Moon、Hyun Seok Seong、Jae-Pil Heo

论文原文见 [arXiv](https://arxiv.org/abs/2603.22758)

> 视频对象中心学习（VOCL）旨在将视频分解为离散的对象槽位，但现有模型常因固定槽位预算导致单物体被过度碎片化。本文指出，模型为最小化重建误差会隐式占用所有槽位，从而将单一物体分割至多个冗余槽位。SlotCurri 通过将槽位数量作为课程变量，从少量粗粒度槽位开始，仅在重建误差高的区域渐进式生成新槽位，并辅以结构感知损失与循环推理。该策略在 YouTube-VIS 和 MOVi-C 上显著提升了前景调整兰德指数（FG-ARI），有效缓解了碎片化，但在高复杂度场景 MOVi-E 上的增益有限，且未解决欠碎片化问题。

## 研究背景

VOCL 的核心挑战在于无监督条件下如何平衡空间精度与时间稳定性。传统 Slot Attention 机制通过迭代竞争注意力实现软聚类，但其固定槽位数量 $K$ 的设定与真实场景的物体密度不匹配。当 $K$ 值过大时，模型倾向于将单一物体分配至多个槽位以最小化像素级重建误差，导致对象过度碎片化；当 $K$ 值过小时，则无法区分密集小物体，产生欠碎片化。这种碎片化不仅降低了表示的可解释性，还阻碍了下游追踪与推理任务中对物体身份的准确提取。

现有主流路线如 SlotContrast 通过引入槽位-槽位对比损失（SSC）来增强时序一致性，但其仍依赖固定槽位预算从头开始训练。SOLV 等方法尝试通过事后合并相似槽位来缓解碎片化，但对比学习压力可能导致槽位表示在合并前已发生语义漂移，使得合并失效。本文的切入点在于从源头抑制碎片化：不预设最大槽位数量，而是将槽位分配过程视为一个由粗到细的课程学习过程，仅在现有槽位无法良好重建的区域引入新容量，从而确保每个新槽位都对应于明确的语义缺失部分。

## 核心方法

### 方法参照系

本文基于 SlotContrast 架构，使用 DINOv2 编码器提取帧级特征，并通过 Slot Attention 模块将其分解为 $K$ 个槽位。标准流程中，槽位数量 $K$ 在训练全程固定，损失函数由均方误差（MSE）重建损失与 SSC 对比损失组成。本文的关键差异在于将 $K$ 动态化，并修改初始化策略与重建损失，以解决固定预算下的过度碎片化问题。

### 重建引导的槽位课程学习

在标准 Slot Attention 中，新槽位通常随机初始化，这导致新槽位可能覆盖已被良好建模的区域，造成冗余。本文提出重建引导的槽位课程学习（SlotCurri），在训练初期仅使用少量槽位（如 2 个），随着训练进行，根据各槽位的重建误差 $\delta_k$ 决定何时及如何扩展槽位。具体而言，计算每个槽位的加权重建误差：

$$ \delta_k = \sum_{t,h,w} \alpha_{k,t,h,w} L_{MSE,t,h,w} $$

其中 $\alpha_{k,t,h,w}$ 为解码权重。在课程阶段 $m$ 到 $m+1$ 的转换时，根据 $\delta_k$ 分配新槽位数量，并通过复制高误差槽位并添加距离感知噪声来初始化新槽位：

$$ \hat{s}_{k^*} = \hat{s}_k + \beta \frac{\|\hat{s}_k\|}{\mu_{norm}} d_{nearest,k} \mathbf{v} $$

其中 $d_{nearest,k}$ 为父槽位到最近邻槽位的欧氏距离，$\mathbf{v}$ 为随机单位向量。这一设计确保新槽位继承父槽位的语义基础，同时被引导至重建误差高的子区域，避免了随机初始化导致的容量浪费与语义漂移。

### 结构感知损失与循环推理

MSE 损失独立处理每个像素，倾向于平滑边界，导致早期粗粒度阶段槽位边界模糊，进而影响后续细分的准确性。本文引入结构相似性指数（SSIM）损失，在时空立方体上计算局部对比度与结构相似性，强制槽位保持锐利的边界。此外，针对视频早期帧因缺乏未来上下文而拟合不足的问题，本文提出循环推理策略：在推理阶段，槽位先从前向传播至最后一帧，再反向传播至第一帧，使用反向传播的结果进行最终解码。这一策略以极低的计算开销（推理时间仅增加 0.3%）提升了全序列的时间一致性，确保早期帧也能获得充分的上下文信息。

## 实验评估

| 数据集 | 方法 | FG-ARI ↑ | mBO ↑ |
| :--- | :--- | :--- | :--- |
| YouTube-VIS | SlotContrast | 38.0 | 33.7 |
| YouTube-VIS | SlotCurri | 44.8 ± 1.2 | 35.5 ± 2.2 |
| MOVi-C | SlotContrast | 69.3 | 32.7 |
| MOVi-C | SlotCurri | 77.6 ± 0.9 | 32.8 ± 0.2 |
| MOVi-E | SlotContrast | 82.9 | 29.2 |
| MOVi-E | SlotCurri | 83.7 ± 0.2 | 28.9 ± 0.7 |

实验在 YouTube-VIS 2021、MOVi-C 和 MOVi-E 上进行，基线包括 SAVi、STEVE、VideoSAUR 及 SlotContrast。SlotCurri 在 YouTube-VIS 和 MOVi-C 上显著提升了 FG-ARI，分别达到 44.8 和 77.6，验证了其在缓解过度碎片化方面的有效性。然而，在 MOVi-E 上，FG-ARI 仅从 82.9 提升至 83.7，mBO 甚至略有下降，表明该方法在高物体密度场景下对欠碎片化问题的解决能力有限。

| 组件 | YouTube-VIS FG-ARI | YouTube-VIS mBO |
| :--- | :--- | :--- |
| Baseline (SlotContrast) | 38.0 | 33.7 |
| + Simple Curriculum | 40.3 | 32.3 |
| + R-G Curriculum | 42.6 | 33.7 |
| + Struct Loss | 43.6 | 35.2 |
| + Cycle Inference | 44.8 | 35.5 |

消融实验显示，简单课程学习已能带来一定提升，但重建引导（R-G）课程进一步提升了 FG-ARI 至 42.6，说明误差引导的槽位分配比随机初始化更有效。结构感知损失主要提升了 mBO，表明其改善了掩码质量而非聚类准确性。循环推理在最终阶段提供了额外的 FG-ARI 增益，验证了其对早期帧一致性的贡献。

评估协议采用 FG-ARI 和 mBO，前者对碎片化敏感，后者评估掩码重叠质量。代码已开源，使用 2 块 NVIDIA RTX A6000 GPU，所有结果均为三次运行的平均值。局限在于未报告计算效率的详细对比，且未在密集小物体场景（如 MOVi-E 的极端情况）中充分验证其泛化性。

## 关联研究分析

从问题动机看，SlotCurri 与 SOLV 均针对过度碎片化，但路径截然不同。SOLV 采用“先过度生成后合并”的策略，依赖事后聚类修正；而 SlotCurri 采用“按需生成”的前置预防策略，通过重建误差直接引导新槽位的诞生。这种差异源于对槽位语义稳定性的不同假设：SOLV 假设合并前槽位语义仍具可分性，而 SlotCurri 认为一旦槽位被对比学习推向不同语义空间，合并将失效。SlotCurri 的策略更依赖早期粗粒度语义的准确性，因此引入了 SSIM 损失来强化边界，这在 SOLV 中未见。

从方法设计看，SlotCurri 与 TSA（Time Slot Activation）在时序一致性处理上形成对比。TSA 通过门控机制隐式学习时间激活，属于架构级改进；SlotCurri 则通过课程学习显式调度槽位容量，属于训练策略级改进。TSA 在 MOVi-C 上达到 76.1 ARI（据领域综述），而 SlotCurri 达到 77.6 FG-ARI，两者指标不同但均处于 SOTA 水平。SlotCurri 的局限在于其课程调度是静态的（固定阶段与增量），未根据场景复杂度动态调整，这可能在物体数量剧烈变化的视频中导致槽位分配滞后。

## 总结

SlotCurri 旨在解决 VOCL 中固定槽位预算导致的对象过度碎片化问题。其核心创新在于将槽位数量作为课程变量，通过重建误差引导新槽位的生成与初始化，辅以结构感知损失锐化边界，并利用循环推理提升早期帧的一致性。实验表明，该方法在 YouTube-VIS 和 MOVi-C 上显著提升了 FG-ARI，有效缓解了碎片化，但在 MOVi-E 上增益有限，暴露了其在处理欠碎片化场景时的不足。当场景物体密度极高且尺寸微小，重建误差引导的槽位扩展是否仍能准确区分相邻物体，而非陷入局部最优的细粒度分割，论文未给出回答。
