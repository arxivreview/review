> 多语言大语言模型（LLM）评估的可靠性受制于翻译基准的质量，现有资源常因语义漂移和上下文丢失导致性能指标失真。传统机器翻译工具缺乏指令遵循能力，且将问题与选项分离翻译破坏了语法一致性，而简单的单次生成无法捕捉中资源语言的细微错误。本文提出一个自动化框架，通过测试时计算扩展策略（Test-time Compute Scaling），特别是多轮竞争性排序方法 T-RANK，在无需训练的情况下提升翻译保真度。该框架在八个东欧及南欧语言上验证了有效性，但其对长文本复杂结构的处理能力及开源模型适配性仍存疑。

## 研究背景

多语言 LLM 的评估依赖高质量的非英语基准，但现有资源如 Global-MMLU 和 MuBench 存在显著缺陷。这些基准多由早期 LLM 或传统工具（如 Google Translate）生成，且常采用“问题与选项分离翻译”策略，导致东欧语言中特有的语法性别标记或格变化出现不一致，甚至泄露正确答案。这种上下文断裂使得模型可能通过语言技巧而非推理能力得分，严重损害评估的公平性。

测试时计算扩展（Test-time Compute Scaling）为提升翻译质量提供了新路径。Best-of-N 和 Fusion-of-N 等方法通过采样多个候选并择优或融合，已在数学推理和代码生成中展现潜力，但在机器翻译领域的应用尚不充分，尤其是针对具有复杂句法结构的中资源语言。现有方法往往忽略 LLM 作为评判者时的位置偏差（Positional Bias），即模型倾向于给序列中靠前的候选更高评分，导致选择结果不可靠。

本文切入点在于解决基准翻译中的结构保持与错误检测难题。针对东欧及南欧语言（如乌克兰语、罗马尼亚语等）复杂的语法特征，本文提出一个可配置的自动化框架，整合了自我检查（SC）、Best-of-N、通用自我改进（USI）及新提出的翻译排序（T-RANK）方法。该框架旨在通过推理时的多次交互，消除单次生成的随机性，并在不增加训练成本的前提下，恢复基准原有的任务结构与语言细微差别。

## 核心方法

### 方法参照系

本文问题属于 LLM 辅助机器翻译中的“推理时优化”路线，区别于传统的端到端生成或级联 OCR+MT 系统。标准流程通常为：源文本输入 → LLM 单次生成译文 → 输出。本文的关键差异在于引入“采样-评估-修正”的迭代闭环，将翻译视为一个搜索问题而非单一映射函数，重点解决中资源语言中单次生成难以捕捉的语法与语义对齐冲突。

### 通用自我改进（USI）

USI 针对 Fusion-of-N 中缺乏精确翻译指标导致融合错误的问题，设计了基于标准化合并的自我改进机制。其核心思想是：最一致的翻译未必是最佳的，但通过多次采样可以覆盖更多正确特征。

$$
y_{USI} = \text{Combine}(\{y_i\}_{i=1}^N, C)
$$

其中 $y_i$ 为温度 0.7 采样的 $N$ 个候选译文，$C$ 为预定义的评估标准（如语法正确性、语义保真度）。模型被指令仅提取所有候选中的最佳特征进行合并。这一设计解决了单次生成在低资源语言中容易遗漏特定语法标记的问题，通过 $N+1$ 次调用实现了成本可控的质量提升，特别适用于短文本数据集翻译。

### 翻译排序（T-RANK）

T-RANK 针对 LLM 评判中的位置偏差问题，引入了多轮竞争性排序策略。传统 Best-of-N 中，LLM 往往只仔细检查第一个候选，后续候选仅被粗略比对，导致错误漏检。

$$
\text{Rank}_{round} = \pi_{judge}(\{y_{\sigma(i)}\}_{i=1}^N, C), \quad \sigma \in S_N
$$

其中 $\pi_{judge}$ 为评判模型，$S_N$ 为 $N$ 个候选的所有排列组合。T-RANK 执行 $N$ 轮排序，每轮中候选的位置 $\sigma(i)$ 发生系统性移位，确保每个候选在所有可能位置出现一次。最终，模型在所有候选可见的情况下修正排名最高的译文。这一机制通过强制模型在不同位置审视同一候选，消除了“首因效应”，使非推理型模型也能识别细微错误，显著提升了基准翻译中问答逻辑的一致性。

## 实验评估

实验基于 FLORES 和 WMT24++ 数据集，评估英语至乌克兰语的翻译质量，使用 COMET 指标。基线包括 SC、Best-of-N 和 USI，缺失了 Gemini 2.0 等前沿多模态 LLM 的直接翻译对比，但覆盖了主要的推理时扩展方法。

| 方法 | WMT24++ (COMET) | FLORES (COMET) |
| :--- | :--- | :--- |
| Baseline | 0.827 | 0.937 |
| SC (with check) | 0.821 | 0.937 |
| Best-of-N (n=5) | 0.843 | 0.943 |
| USI (n=5) | 0.843 | 0.945 |
| T-RANK (p=5) | 0.845 | 0.940 |

T-RANK 在 WMT24++ 上以 0.845 的 COMET 分数领先，而 USI 在 FLORES 上以 0.945 占优。这表明 T-RANK 在包含复杂问答结构的基准翻译中更具优势，而 USI 在短文本数据集上更稳定。

在下游任务验证中，使用 Gemini-2.5-Flash 作为评判者，对比本文翻译与 Global-MMLU 在 MMLU、Winogrande 等基准上的表现。本文翻译在 Winogrande 上平均提升 3.42%，在 MMLU 上提升 0.94%。Winogrande 的显著提升归因于 T-RANK 有效消除了通过语法性别标记泄露答案的问题，证明了翻译质量对评估公平性的直接影响。

评估边界方面，COMET 指标在短文本上可能存在偏差，且未报告置信区间。代码已开源，但主要依赖闭源模型（GPT-4o-mini, Gemini 2.0-Flash），对开源模型的适用性验证不足。

## 关联研究分析

从问题动机看，本文与 VFA（Vision-Free Adaptation）均关注多语言扩展，但路径截然不同。VFA 通过参数高效适配解决视觉-语言对齐中的语言瓶颈，侧重模型内部表示的调整；本文则完全冻结模型参数，通过外部推理策略解决翻译过程中的语义漂移。这种差异源于任务特性：VFA 处理的是多模态输入下的泛化问题，而本文处理的是纯文本基准的结构化翻译问题。本文未探索视觉模态在歧义消解中的作用，这是否意味着在纯文本场景下，推理时计算足以替代视觉辅助，论文未给出回答。

从方法设计看，T-RANK 与 AnyTrans 代表的级联系统形成对比。AnyTrans 依赖模块间的误差传播控制，而 T-RANK 通过多轮排序在单一 LLM 内部实现错误检测与修正。T-RANK 的多轮机制本质上是一种“软级联”，将评判与生成解耦。然而，T-RANK 的计算成本随 $N$ 线性增长（$2N+1$ 次调用），在大规模数据集中可能成为瓶颈。相比之下，USI 仅需 $N+1$ 次调用，在成本敏感场景下更具优势。本文未提供不同 $N$ 值下的成本-质量曲线，使得用户难以在精度与效率间做出最优选择。

## 总结

本文核心矛盾在于多语言基准翻译中语义保真度与自动化效率的平衡。现有方法因单次生成的随机性和 LLM 评判的位置偏差，导致中资源语言基准出现语法断裂与答案泄露。本文通过 T-RANK 多轮竞争性排序，在无需训练的前提下，利用推理时计算扩展消除了这些偏差。实验显示，T-RANK 在 WMT24++ 上取得 0.845 COMET 分数，并在 Winogrande 下游任务中带来 3.42% 的提升，验证了其对评估公平性的改善。然而，本文主要依赖闭源模型，且未充分验证在长文本复杂结构下的表现。当支持集增大到长段落时，T-RANK 的多轮排序边际收益是否递减，论文未给出回答。
