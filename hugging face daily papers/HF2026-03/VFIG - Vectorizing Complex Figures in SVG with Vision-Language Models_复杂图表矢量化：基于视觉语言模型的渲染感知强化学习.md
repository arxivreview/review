> 复杂科学图表的原始矢量源文件常因格式转换或时间推移而丢失，仅存难以编辑的光栅图像，手动重建成本极高。现有方法多聚焦于简单图标，缺乏对多面板布局、层级分组及精确连接关系的系统性处理能力，导致生成的 SVG 代码结构松散或几何失真。VFig 通过构建大规模复杂图表数据集，并采用“粗到细”课程学习与渲染感知强化学习策略，实现了从光栅图像到高保真可编辑 SVG 代码的转换。该方法在开源模型中达到 SOTA，但与顶级专有模型相比，其在极端复杂拓扑下的鲁棒性仍存疑。

## 研究背景

当科研工作者试图修改一篇旧论文中的架构图时，往往发现原始 SVG 源文件已不可用，手中仅有无法直接编辑的 PNG 图片。这种困境源于光栅图像的分辨率依赖性与语义结构缺失，而矢量图形（SVG）虽具备分辨率无关性和可编辑性，但其生成过程要求模型同时理解视觉内容的空间布局与代码结构的语法逻辑。传统基于轮廓追踪的方法（如 Potrace）虽能还原像素边界，但输出的是大量无约束的贝塞尔路径，缺乏矩形、箭头等语义图元，无法支持后续的局部编辑或样式调整。

该领域的核心挑战在于，复杂科学图表包含嵌套布局、异构图元及精确对齐关系，其 SVG 代码序列长度远超简单图标，导致长程生成中的语法一致性与几何精度难以兼顾。早期基于变分自编码器或可微分渲染的方法（如 SVG-VAE, DiffVG）在简单图形上表现良好，但面对多面板复杂结构时，往往因缺乏全局语义理解而产生布局错乱或元素缺失。近期，视觉语言模型（VLM）的兴起为跨模态对齐提供了新路径，但现有工作多局限于简单图形，未系统研究 VLM 在复杂图表矢量化中的能力边界。VFig 的切入点在于，通过专门针对复杂图表的数据工程与训练策略，弥补了通用 VLM 在结构化代码生成上的不足，将矢量化任务从“像素拟合”提升至“结构推理”层面。

## 核心方法

### 方法参照系

本文任务属于 VLM 驱动的矢量图形生成范畴，其标准流程为：输入光栅图像，通过自回归解码器生成 SVG 代码序列。与通用 VLM 生成任务的关键差异在于，SVG 代码具有严格的层级结构与几何约束，单纯的下一词元预测（Next-token Prediction）无法保证渲染后的视觉保真度与结构正确性，需引入外部视觉反馈机制。

### 粗到细课程学习

针对复杂图表中图元生成与组合推理难以同时学习的问题，本文在监督微调（SFT）阶段引入两阶段课程学习。第一阶段在结构简单的数据集（SVG-Diagrams, Molmo2-Diagram, VFig-Data-Shapes-and-Arrows）上训练，使模型掌握原子图元（如矩形、文本）的生成与基本布局；第二阶段在复杂科学图表（VFig-Data-Complex-Diagrams）上微调，学习多面板层级结构与全局对齐。该策略缓解了直接训练复杂数据导致的收敛不稳定与退化输出。SFT 目标函数为最大化条件似然：

$$ \mathcal{L}_{SFT} = -\sum_{i=1}^{N} \log p_\theta(y_i | x, y_{<i}) $$

其中 $p_\theta(y_i | x, y_{<i})$ 为模型在给定图像 $x$ 和前缀序列 $y_{<i}$ 下预测第 $i$ 个词元的概率。此设计确保了模型在接触复杂结构前已建立稳健的图元生成基础。

### 渲染感知强化学习

SFT 仅优化词元似然，无法直接约束渲染后的视觉质量，导致布局错位或连接错误。本文引入基于 Group Relative Policy Optimization (GRPO) 的强化学习阶段，以渲染后的视觉反馈为奖励信号。模型对同一输入采样多个 SVG 程序，渲染后由 VLM 评委（Gemini-3-Flash）根据四个维度评分：存在性（Presence）、布局（Layout）、连通性（Connectivity）与细节（Details）。最终奖励为四项得分的无加权平均：

$$ R(x, \hat{y}) = \frac{1}{4} (r_{pres} + r_{layout} + r_{conn} + r_{det}) $$

GRPO 通过组内相对优势估计更新策略，并引入 KL 正则项防止奖励黑客：

$$ \mathcal{L}_{RL} = \mathbb{E}_{x \sim D, \hat{y} \sim \pi_\theta} \left[ \min \left( \frac{\pi_\theta(\hat{y}|x)}{\pi_{ref}(\hat{y}|x)} A(\hat{y}), \text{clip}\left( \frac{\pi_\theta(\hat{y}|x)}{\pi_{ref}(\hat{y}|x)}, 1-\epsilon, 1+\epsilon \right) A(\hat{y}) \right) - \beta D_{KL}(\pi_\theta || \pi_{ref}) \right] $$

其中 $A(\hat{y})$ 为组内归一化优势，$\pi_{ref}$ 为冻结的 SFT 策略。该机制将视觉保真度直接纳入优化目标，弥补了纯文本监督的缺陷。

## 实验评估

实验在 VFig-Bench（392 个复杂科学图表）、Molmo2-Diagram（500 样本）及 SVG-Diagrams（474 样本）上进行，基线涵盖专有模型（GPT-5.2, Gemini 3 Pro/Flash）、开源 VLM（StarVector, OmniSVG）及经典追踪方法（VTracer）。

| 方法 | SSIM↑ | LPIPS↓ | VisualSim↑ | VLM-Judge↑ | Clean↑ | Render↑ |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Ours (SFT+RL) | **0.750** | **0.261** | **0.938** | **0.746** | **0.776** | **0.859** |
| StarVector-8B | 0.749 | 0.270 | 0.925 | 0.712 | 0.761 | 0.749 |
| OmniSVG | - | - | - | - | - | - |
| GPT-5.2 | - | - | - | 0.829 | - | - |

注：表格数值取自论文 Table 3 中 Qwen3-VL-8B 两阶段训练结果及摘要中 GPT-5.2 对比数据。Ours (SFT+RL) 在开源模型中全面领先，VLM-Judge 得分 0.746 接近 GPT-5.2 的 0.829，但仍有差距。

消融实验显示，两阶段课程学习相比单阶段训练，Render 成功率从 0.749 提升至 0.933（4B 模型），VLM-Judge 从 0.712 提升至 0.737，表明课程学习显著提升了结构稳定性。在奖励设计方面，使用全部四项 Gemini 奖励在 VLM-Judge 上得分最高（0.804），而加入像素级奖励（Gemini + Pixel）虽使 SSIM 微升至 0.752，但 VLM-Judge 降至 0.779，Clean 降至 0.816，证实结构感知奖励比像素级目标更有效地优化复杂图表的语义正确性。

评估边界方面，VFig-Bench 依赖 VLM 评委（Gemini/GPT）进行主观评分，可能存在评委偏好偏差；SSIM 等像素指标无法反映代码可编辑性。论文未报告计算效率指标，且 RL 阶段依赖外部 VLM 评委，增加了推理与训练成本。代码已开源，但超参数细节（如 KL 系数 $\beta$）未在正文中详述，复现需查阅附录。

## 关联研究分析

从问题动机看，VFig 与 StarVector 同属 VLM 生成路线，但 StarVector 聚焦于通用图标与简单图表，其数据过滤侧重于包含 `<text>` 元素的 SVG，未专门针对复杂科学图表的层级结构进行优化。VFig 通过构建 VFig-Data-Complex-Diagrams，显式处理多面板布局与密集标注，解决了 StarVector 在复杂结构上泛化能力不足的问题。差异根源在于任务特性：科学图表的语义密度远高于图标，需更强的组合推理能力，而非单纯的图元识别。

从方法设计看，VFig 与 DiffVG 代表两种截然不同的几何约束融入方式。DiffVG 采用可微分渲染，通过梯度优化直接调整矢量参数，几何精度高但缺乏全局语义理解，难以处理复杂布局；VFig 采用生成派路线，通过 RL 反馈间接优化结构，牺牲部分像素级精度换取代码的可编辑性与语义正确性。VFig 未采用可微分渲染，是因为其目标输出为结构化代码而非纯几何参数，且 VLM 的 token 生成机制与梯度优化不兼容。这种取舍使得 VFig 更适合需要后续编辑的场景，但在 CAD 等对几何精度要求极高的任务中，其 SSIM 表现可能不及优化派方法。

## 总结

VFig 旨在解决复杂科学图表从光栅图像到可编辑 SVG 代码的转换难题，其核心矛盾在于长序列生成中的结构一致性与视觉保真度难以兼顾。现有方法或因数据简单而泛化不足，或因缺乏视觉反馈而结构松散，VFig 凭借大规模复杂图表数据集与“粗到细”课程学习及渲染感知 RL 策略，实现了开源模型中的 SOTA 性能，VLM-Judge 得分达 0.746，接近 GPT-5.2 的 0.829。然而，其依赖外部 VLM 评委的奖励机制可能引入偏好偏差，且像素级指标（SSIM 0.750）与顶级专有模型仍有差距。当图表复杂度进一步增加，如包含大量数学公式或密集文本时，当前基于词元预测与 VLM 评分的框架是否仍能保持结构稳定性，论文未给出明确回答。
