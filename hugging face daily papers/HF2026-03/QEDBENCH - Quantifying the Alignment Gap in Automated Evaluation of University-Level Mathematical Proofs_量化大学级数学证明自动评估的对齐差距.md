# HuggingFace最新推荐论文 ｜QEDBENCH: Quantifying the Alignment Gap in Automated Evaluation of University-Level Mathematical Proofs ｜量化大学级数学证明自动评估的对齐差距

研究机构：美国耶鲁大学、捷克查理大学

作者：Santiago Gonzalez、Alireza Amiri Bavandpour、Peter Ye 等 51 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.20629)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.20629)

> 大语言模型（LLM）在基础算术基准上已趋饱和，但评估其生成的大学级数学证明时，现有“LLM-as-a-Judge”协议与人类专家判断存在系统性偏差。传统评估依赖二元答案匹配或静态基准，无法捕捉证明过程中的逻辑断裂与幻觉前提，导致高分掩盖推理缺陷。本文提出 QEDBENCH，通过双评分标准（课程/专家）与 7×5 评估者-求解者矩阵，量化 LLM 评估者相对于人类真值的对齐差距。该框架揭示了离散数学领域的严重评分通胀，但受限于静态题目集与单一语言模态，其结论在动态生成证明场景下的普适性存疑。

## 研究背景

理解本文需厘清“对齐差距”（Alignment Gap）的概念。当 LLM 作为评估者对数学证明打分时，其输出分数与人类专家基于逻辑严谨性给出的真值分数之间的偏差，即为对齐差距。这一差距源于 LLM 的概率生成特性：模型倾向于奖励表面连贯的文本，而非验证隐含的逻辑依赖链。例如，模型可能给一个包含错误引理但行文流畅的证明高分，而人类专家会因逻辑断裂给予低分。这种偏差在基础算术中不明显，但在需要构造性搜索的大学级证明中急剧放大。

数学推理评估的主流路线正从“结果导向”转向“过程验证”。早期基准如 GSM8K 和 MATH 仅关注最终答案，导致模型通过模式匹配获得高分，却缺乏深层逻辑能力。随着对抗性评估（如 GSM-Symbolic）暴露出模型对表面形式的依赖，研究者引入过程奖励模型（Process Reward Model, PRM）进行步骤级监督。然而，PRM 的标注成本极高，且现有 LLM 评估器在开放证明中表现不稳定。Zheng et al. (2026) 指出，LLM 在需要多约束协调的结构化推理中性能显著下降，但缺乏量化评估者本身可靠性的标准。QEDBENCH 的切入点在于解耦“求解能力”与“评估可靠性”，通过大规模人工真值校准，系统审计 LLM 评估者在大学级证明中的偏差机制。

## 核心方法

### 双评分标准解耦架构

传统 LLM 评估通常采用单一提示词，混合了教学约束与逻辑正确性要求，导致模型难以区分“未推导的高级定理”与“逻辑错误”。QEDBENCH 引入双评分标准策略，将评估维度正交化。课程特定标准（Course-Specific Rubric）模拟本科教学环境，惩罚未经推导使用的高级工具（如留数定理），聚焦定义合规性；专家标准（Expert Rubric）模拟研究生研究环境，允许隐含步骤，聚焦逻辑自洽性。这种设计动机在于隔离“知识差距”（是否使用超纲工具）与“逻辑差距”（推理是否有效），从而精确定位评估偏差的来源。

### 7×5 评估者-求解者矩阵

为统计隔离评估者偏差与求解者能力，QEDBENCH 构建了完全交叉的 7×5 矩阵。5 个前沿求解模型（Gemini 3.0 Pro, GPT-5 Pro, o3-deep-research, Claude Sonnet 4.5, DeepSeek-Prover-V2）生成 LaTeX 证明，7 个评估模型（GPT-5.2 Pro, Claude Opus 4.5, Gemini 3.0 Pro, Grok 4, Qwen 2.5 Max, DeepSeek-V3, Llama 4 Maverick）对每个证明进行打分。对齐差距 $\Delta$ 定义为评估者分数与人类真值分数的差值：

$$
\Delta_{judge, solver} = \text{Score}_{AI} - \text{Score}_{Human}
$$

该公式量化了特定评估者在特定求解者输出上的系统性偏差。通过矩阵分析，可以识别出哪些评估者在哪些学科领域存在评分通胀（$\Delta > 0$）或过度严苛（$\Delta < 0$），从而将“模型能力”与“评估偏差”解耦，避免将评估者的宽松误判为求解者的进步。

## 实验评估

实验基于 272 道大学级证明题，由 48 名博士专家进行 1000+ 小时的人工标注，建立真值基准。求解模型覆盖当前 SOTA 推理架构，评估模型涵盖主流 LLM 家族。基线审计显示，本文未对比专门微调的评估器（如 RefGrader），而是聚焦于基础模型的固有对齐能力，这限制了与专用评估工具的横向比较。

| 评估模型 | 通过率 (Pass Rate %) | 与人类真值偏差 (Mean Score Delta) | 相关性 (Pearson r) |
| :--- | :--- | :--- | :--- |
| Llama 4 Maverick | 90.2 | +0.36 | 0.50 |
| Qwen 2.5 Max | 85.7 | +0.30 | 0.55 |
| Claude Opus 4.5 | 79.2 | +0.18 | 0.66 |
| GPT-5.2 Pro | 74.1 | - | 0.69 |
| DeepSeek-V3 | 72.2 | - | 0.63 |
| Human Consensus | 67.7 | 0.00 | 1.00 |

数据显示，Llama 4 Maverick 存在严重评分通胀，通过率比人类真值高 22.5%，且在组合数学领域偏差高达 +0.36。GPT-5.2 Pro 表现最稳健，相关性最高（r=0.69），但仍有 38.0% 的宽松率（Leniency Rate）。消融实验表明，评分标准对评估者行为影响有限：GPT-5.2 Pro 在课程特定标准下的相关性仅从 0.69 降至 0.67，MAE 从 0.13 升至 0.14，证实了“标准不敏感性”（Rubric Insensitivity）现象，即模型内部先验主导了评分行为，而非提示词约束。

评估边界方面，QEDBENCH 依赖静态题目集，尽管进行了对抗性审计，仍可能存在未检测到的污染。此外，评估仅针对 LaTeX 文本，未涉及形式化验证（如 Lean），限制了结论在神经符号融合场景下的适用性。代码已公开，但人工真值的构建成本极高，难以大规模扩展至更多学科。

## 关联研究分析

从问题动机看，QEDBENCH 与 Hard2Verify 同属过程验证路线，但焦点不同。Hard2Verify 关注模型解题时的步骤级错误检测，旨在提升求解可靠性；QEDBENCH 则关注评估者打分的偏差，旨在提升评估可靠性。这一差异源于任务特性的不同：解题错误是模型内部推理的失败，而评估偏差是模型对他人输出的感知失真。QEDBENCH 揭示的“离散-连续鸿沟”（Discrete-Continuous Divide）表明，模型在连续域（如 ODE）表现稳定，但在离散域（如组合数学）出现评分通胀，这与 Hard2Verify 中模型在复杂逻辑链上的错误累积现象形成互补，共同指向 LLM 在结构化推理上的根本局限。

从方法设计看，QEDBENCH 与 RefGrader 均试图提升 LLM 评估的一致性，但路径迥异。RefGrader 通过代理工作流（Agentic Workflow）和微调提升竞赛题评分精度，依赖外部工具辅助；QEDBENCH 则通过双评分标准和矩阵设计，审计基础模型的固有偏差，不依赖额外微调。这种差异暗示，微调可能掩盖了基础模型的对齐缺陷，而 QEDBENCH 的方法更能揭示 LLM 作为评估者的本质局限。然而，QEDBENCH 未探索结合符号验证器（如 Lean）的混合评估方案，这在形式化证明场景中可能是更优解，论文未给出相关对比。

## 总结

QEDBENCH 旨在解决 LLM 评估大学级数学证明时的系统性偏差问题，通过双评分标准解耦教学约束与逻辑正确性，并利用 7×5 矩阵隔离评估者偏差。实验证实，前沿 LLM 评估者存在显著评分通胀，尤其在离散数学领域，且对评分标准不敏感，内部先验主导评分行为。该框架的价值在于提供了首个大规模人工真值校准的评估审计标准，但受限于静态题目集与纯文本模态，未涵盖形式化验证场景。当评估对象从静态证明转向动态生成的形式化代码时，LLM 评估者的对齐差距是否会因符号系统的刚性约束而缩小，论文未给出回答。
