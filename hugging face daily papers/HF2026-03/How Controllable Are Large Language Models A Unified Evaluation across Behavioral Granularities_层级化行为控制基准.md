> 大语言模型在社交敏感场景中的行为可控性面临从抽象意图到具体文本实现的粒度断层，现有评测基准缺乏对控制精度的层级化诊断。本文提出 SteerEval，将行为目标分解为计算、算法与实现三个层级，并构建自动化数据合成管线。实验揭示激活转向在细粒度约束下系统性失效，而提示工程在深层级保持稳健。该基准为转向方法提供了可解释的失效坐标，但其未覆盖稀疏自编码器等高级转向路线，限制了结论的普适性。

## 研究背景

当模型需要表达“自主性”这一人格特质时，仅改变情感极性（如从依赖转向独立）并不足以确保输出符合特定风格约束，更无法保证包含“self-authored”等具体词汇标记。这种从抽象意图到表面实现的跨度，构成了行为控制的粒度鸿沟。解决此问题需区分控制目标的抽象层级：高层级关注“表达什么”，低层级关注“如何表达”及“具体实例化为何种形式”。

激活转向领域长期依赖线性表示假设，认为高层语义概念在激活空间中对应近似正交方向，使得向量加法能有效控制情绪或真实性。然而，现有基准如 AxBench 的概念源自稀疏自编码器（SAE）特征描述，缺乏显式的行为定义与层级结构，导致无法区分方法在粗粒度意图控制与细粒度表面约束上的能力差异。SteerEval 的切入点在于引入 Marr 三层分析框架，将控制目标显式分解为 L1（计算层：表达什么）、L2（算法层：如何表达）与 L3（实现层：如何实例化），从而量化转向方法在不同抽象深度上的鲁棒性边界。

## 核心方法

### 方法参照系

本文问题属于推理时干预（Inference-Time Intervention）的评测范畴，但区别于传统基准仅评估单一概念得分，其核心差异在于引入层级化控制目标。标准流程中，转向方法通过修改隐藏状态 $h_l$ 影响输出分布，但缺乏对控制精度的分级诊断。SteerEval 将单一概念扩展为同一核心目标下的三个嵌套约束层级，要求方法在满足 L3 原子约束的同时保持 L1 意图一致性。

### 层级化概念合成

设计动机在于解决现有基准概念定义模糊导致无法定位失效层级的问题。本文构建自动化管线，首先由大语言模型生成领域描述与三级概念层级，随后生成概念条件问题并改写以消除提示泄漏。关键创新在于生成最小编辑的对比答案对，其中匹配答案满足目标概念，不匹配答案表现相反行为，且两者在词汇层面仅存在概念承载差异。该过程确保偏好数据能精准隔离概念效应，公式化为：

$$ \Delta_{concept} = A_{match} - A_{not\_match} $$

其中 $A_{match}$ 与 $A_{not\_match}$ 为同一问题的对比答案，$\Delta_{concept}$ 用于训练或评估转向向量的特异性。

### 多维评估协议

设计动机在于单一概念得分无法反映转向对通用能力的副作用。本文采用 gpt-4.1-mini 作为评判器，在 0-4 量表上评估三个维度：概念得分（CS）、指令遵循得分（IS）与流畅性得分（FS）。最终指标为三者调和平均（HM），以惩罚任一维度的低分：

$$ HM = \frac{3}{\frac{1}{CS} + \frac{1}{IS} + \frac{1}{FS}} $$

该公式确保方法若牺牲流畅性或指令遵循以换取概念表达，其综合得分将显著下降，从而量化控制特异性与通用能力保持之间的权衡。

## 实验评估

实验在 Gemma-2-9B-Instruct、Qwen-2.5-7B-Instruct 与 Llama-3.1-8B-Instruct 上进行，基线包括无转向（Vanilla）、提示工程（0-shot/3-shot Prompt）及激活转向（PCA、DiffMean、RePS）。基线覆盖提示与激活两大路线，但缺失 SAE-based、几何转向（如 Angular Steering）及自适应控制（如 PID Steering）等高级方法，限制了细粒度控制能力的全面评估。

| 模型 | 方法 | L1 HM | L2 HM | L3 HM |
|---|---|---|---|---|
| Gemma-2-9B | Prompt (3-shot) | 3.14 | 3.21 | 2.88 |
| Gemma-2-9B | RePS | 2.82 | 2.36 | 2.16 |
| Qwen-2.5-7B | Prompt (3-shot) | 3.30 | 3.35 | 2.90 |
| Qwen-2.5-7B | RePS | 2.90 | 2.72 | 2.60 |
| Llama-3.1-8B | Prompt (3-shot) | 3.41 | 3.53 | 2.86 |
| Llama-3.1-8B | RePS | 3.20 | 3.15 | 2.33 |

数据显示，提示工程在所有层级保持 HM 约 3.0 的稳定表现，而激活转向从 L1 到 L3 出现显著衰减。以 Gemma-2-9B 为例，RePS 的 HM 从 L1 的 2.82 降至 L3 的 2.16，降幅达 23.4%；PCA 在 L3 的 HM 仅 1.51，接近无转向基线。这一梯度衰减验证了层级化假设：细粒度约束对激活空间的线性可分性要求更高，现有方法难以满足。

消融分析显示，增加提示数量对 L1/L2 有边际收益，但对 L3 可能产生负迁移，因额外示例引入的表面线索干扰原子约束匹配。转向强度分析表明，RePS 在 L1 存在最优强度区间，超过该区间后 IS 与 FS 显著下降，导致 HM 峰值出现在中等强度；而在 L2/L3，强度增加未能带来一致增益，反映激活方法在深层级缺乏可控性。

评估协议依赖 LLM 评判器，人工验证显示 L3 层级一致性最高（Spearman 0.96），L1/L2 因解释变异性略低（0.81-0.83）。代码与数据已开源，但转向因子需在验证集搜索，不同概念的最优因子差异显著（如 Language Features 域 L3 因子范围 1-20），增加了复现复杂度。

## 关联研究分析

从问题动机看，SteerEval 与 AxBench 均旨在标准化转向评测，但 AxBench 概念源自 SAE 特征描述，缺乏显式行为定义与层级结构，导致无法区分方法在意图控制与表面约束上的能力差异。SteerEval 通过 Marr 层级分解，将控制目标从单一概念扩展为嵌套约束，揭示了激活转向在 L3 的系统性失效，这是 AxBench 无法诊断的盲区。这一差异源于任务特性：SAE 特征本身是细粒度的，但缺乏行为语义的层级组织，而 SteerEval 的显式层级定义使失效模式可归因于抽象深度而非概念类型。

从方法设计看，SteerEval 与 RePS 等训练式转向方法形成互补：RePS 通过偏好目标学习转向向量，在 L1 表现优于无训练基线（PCA/DiffMean），但在 L3 仍落后于提示工程。SteerEval 未测试 SAE-based 方法，而领域共识认为 SAE 能解耦纠缠特征以提升特异性，这构成潜在矛盾：若 SAE 能有效解耦 L3 所需的原子特征，其表现是否应优于 RePS？论文未提供证据，可能因 SAE 特征与显式行为层级的对齐难度未被探索。

## 总结

SteerEval 要解决的核心矛盾是转向方法在抽象意图与具体实现之间的粒度断层，现有基准缺乏层级化诊断导致失效模式不可归因。本文抓住的切入点是引入 Marr 三层分析，将控制目标分解为 L1-L3 嵌套约束，并通过自动化合成管线生成最小编辑对比数据。实验证明激活转向在 L3 层级系统性失效（RePS HM 从 2.82 降至 2.16），而提示工程保持稳健（HM 约 3.0）。本文的边界在于未覆盖 SAE-based 与几何转向方法，且 LLM 评判器在 L1/L2 的一致性略低。当 SAE 特征与显式行为层级对齐时，其解耦能力能否弥补激活转向在 L3 的失效，论文未给出回答。
