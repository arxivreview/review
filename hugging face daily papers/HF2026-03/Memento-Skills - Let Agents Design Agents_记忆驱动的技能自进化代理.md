# HuggingFace最新推荐论文 ｜Memento-Skills: Let Agents Design Agents ｜记忆驱动的技能自进化代理

作者：Huichi Zhou、Siyuan Guo、Anjie Liu 等 17 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.18743)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.18743)

> 代理技能学习旨在通过外部程序性记忆实现大语言模型（LLM）在非参数化条件下的持续自我改进。现有方法多将技能检索与优化解耦，导致检索依赖语义相似度而忽略执行效用，且静态技能库难以适应动态任务需求。本文提出 Memento-Skills，将技能文件夹作为可写记忆单元，通过“读-写”反思学习闭环与行为对齐路由器，实现技能的在线生成、归因与重写。该系统在 GAIA 和 HLE 基准上验证了自进化机制的有效性，但其跨任务迁移能力高度依赖领域结构对齐，且缺乏与强基线的直接对比，泛化边界尚存疑。

## 研究背景

当 LLM 代理面对长程多步任务时，其固定参数无法从部署经验中积累知识，导致每次交互都需从零开始规划。为解决这一状态缺失问题，代理技能（Agent Skill）被引入作为外部程序性记忆，将任务分解与工具调用封装为可复用的结构化模块。然而，随着技能库规模扩大，基于语义相似度的扁平检索暴露出“相关性-效用差距”：高相似度技能未必具备正确的执行策略，且静态技能库无法从失败轨迹中自动修正，导致技能过拟合与泛化能力受限。

该领域的核心矛盾在于如何在保持模型权重冻结的前提下，实现技能库的动态进化与高效检索。早期工作如 Voyager 确立了代码技能库的概念，但受限于离线蒸馏与单次生成可靠性；后续研究如 SkillOpt 和 SkillGrad 引入了验证门控与文本梯度优化，解决了技能迭代稳定性问题，但通常将检索与优化视为独立模块，缺乏统一的策略协同机制。Memento-Skills 的切入点在于将技能视为“可写记忆”，通过 Stateful Reflective Decision Process (SRDP) 框架，将检索（策略改进）与更新（策略评估）统一在反思学习闭环中，并引入行为对齐路由器以弥合语义匹配与执行效用之间的鸿沟。

## 核心方法

### 方法参照系

本文问题归属于“技能自动优化”与“技能检索与路由”的混合路线。与 SkillOpt 等将技能文档视为静态参数空间进行离线迭代的方法不同，Memento-Skills 将技能文件夹（包含代码、提示与声明）定义为动态记忆单元，其核心差异在于引入了在线反思机制，使技能更新直接响应单次执行轨迹的反馈，而非依赖批量验证集的门控决策。

### 行为对齐技能路由器

传统检索器依赖 BM25 或嵌入模型计算语义相似度，但高余弦相似度往往对应低执行效用，导致代理选择错误技能。Memento-Skills 提出行为对齐对比路由器，将技能路由建模为 KL 正则化的 Boltzmann 策略，通过单步离线强化学习（RL）优化检索分布。该设计动机在于解决语义匹配与行为效用脱节的问题，使路由器能够预测执行成功概率而非表面文本重叠。

$$
\mu(c | x) \propto \exp\left( \frac{Q(x, c)}{\tau} \right)
$$

其中 $Q(x, c)$ 为状态-动作价值函数，$\tau$ 为温度参数。该公式表明，路由器并非简单选择相似度最高的技能，而是基于预测的执行效用进行概率性选择，从而在候选列表中保留更多行为相关的替代方案。实验显示，该路由器在 Recall@1 上较 Qwen3 嵌入基线提升 10%，在路由命中率上从 0.53 提升至 0.58，证实了行为信号注入嵌入空间的有效性。

### 反思式技能进化闭环

在技能执行后，系统通过“写”阶段实现技能库的自进化。该阶段包含失败归因、效用更新与文件级重写三个子过程。设计动机在于解决静态技能库无法从失败中学习的缺陷，通过信用分配机制定位导致错误的特定技能，并进行针对性修正。

$$
M_{t+1} \leftarrow \text{Write}(M_t, s_t, a_t, r_t)
$$

其中 $M_t$ 为当前技能记忆，$s_t, a_t, r_t$ 分别为状态、动作与奖励。该操作并非简单追加轨迹，而是通过 LLM 分析执行轨迹与评判理由，识别最负责的技能 $c^\dagger$，并生成文件级更新（如添加护栏或替代策略）。若技能效用低于阈值 $\delta$ 且样本数 $n \ge n_{\min}$，则触发新技能发现；否则进行原地优化。此机制确保了技能库在保持通用性的同时，逐步消除特定失败模式，实现了从“脆弱技能”到“稳健例程”的巩固。

## 实验评估

实验在 GAIA 和 HLE 基准上进行，基线仅对比“Read-Write Ablation”（禁用技能优化的静态库），缺失 SkillOpt、Skill1 等强基线的直接对比。GAIA 测试集上，Memento-Skills 整体准确率为 66.0%，较基线 52.3% 提升 13.7 个百分点；HLE 测试集上，整体准确率为 38.7%，较基线 17.9% 提升 20.8 个百分点。

| 基准 | 方法 | 整体准确率 (%) | 相对提升 (%) |
| :--- | :--- | :--- | :--- |
| GAIA | Memento-Skills | 66.0 | +13.7 |
| GAIA | Read-Write Ablation | 52.3 | - |
| HLE | Memento-Skills | 38.7 | +20.8 |
| HLE | Read-Write Ablation | 17.9 | - |

消融实验显示，技能优化管线贡献了主要增益，但跨任务迁移能力呈现显著领域依赖性。GAIA 任务多样性高，训练优化技能在测试集中触发率低，导致迁移效果有限；而 HLE 具有结构化学科分类，技能复用率高，迁移效果显著。这表明自进化机制的有效性高度依赖技能库与任务域的结构对齐，而非通用的跨域泛化能力。

评估边界方面，论文未报告置信区间，且 GAIA 结果包含最多三次反思重试，与单次执行 SOTA 的对比公平性存疑。代码已开源，但超参数配置（如效用阈值 $\delta$、最小样本数 $n_{\min}$）对性能的影响未做敏感性分析，可复现性受限于骨干模型（Gemini-3.1-Flash）的特定行为。

## 关联研究分析

从方法设计看，Memento-Skills 与 SkillOpt 均利用轨迹反馈优化技能，但 SkillOpt 侧重离线批量验证门控，强调更新的稳定性与收敛性；而 Memento-Skills 采用在线单步反思，强调响应的即时性与技能库的动态扩展。这一差异源于任务特性：SkillOpt 适用于结构化文档处理等确定性任务，而 Memento-Skills 面向 GAIA 等开放域任务，需快速适应未见模式。然而，在线反思缺乏全局验证，可能导致技能库膨胀或局部最优，论文未探讨技能剪枝或生态效用动态调整机制，这在技能库规模扩大至数万级时可能成为瓶颈。

从问题动机看，Memento-Skills 与 Trace2Skill 均关注技能生成与蒸馏，但 Trace2Skill 侧重离线并行蒸馏以生成架构无关的声明式技能，强调可分享性与连贯性；Memento-Skills 则侧重在线实时反思，强调技能与策略的协同进化。Trace2Skill 的静态蒸馏无法捕捉执行过程中的动态失败模式，而 Memento-Skills 的在线更新虽能修正错误，但依赖 LLM 的归因准确性，若归因错误则会导致技能污染。这种在线-离线取舍反映了领域内对“技能质量保障”与“响应速度”的不同优先级，但两者均未解决技能安全与供应链治理问题，如恶意技能注入或后门攻击，这在开放技能生态中是潜在的重大风险。

## 总结

Memento-Skills 旨在解决冻结 LLM 代理缺乏持续学习能力的问题，通过将技能文件夹作为可写记忆单元，统一了检索与优化过程。其核心创新在于行为对齐路由器与反思式进化闭环，前者弥合了语义匹配与执行效用的差距，后者实现了技能的在线自修正。实验证明，该机制在 GAIA 和 HLE 上分别带来 13.7 和 20.8 个百分点的准确率提升，验证了技能自进化的有效性。然而，其跨任务迁移能力高度依赖领域结构对齐，GAIA 上的弱迁移现象暴露了技能泛化性的局限。当技能库规模扩大且任务域异构性增强时，在线反思机制能否避免技能污染与局部最优，仍是一个亟待验证的关键问题。
