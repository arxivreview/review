> 科学多模态基础模型旨在通过统一架构处理异构科学数据，但现有模型受限于参数规模，难以兼顾通用推理与垂直领域深度。本文切入点在于验证“足够大的通用模型联合训练可超越专用小模型”的假设，通过构建首个万亿参数 MoE 架构并引入分组路由机制解决训练稳定性问题。该工作证明了规模扩张在特定科学任务上的协同效应，但其对“通用性掩盖专业性退化”的潜在风险缺乏充分验证。

## 研究背景

当模型需要同时处理蛋白质结构预测与地球物理信号分析时，单一模态或专用小模型往往因知识孤岛效应导致跨域推理失效。这种局限源于科学数据的异构性：文本、图像与时序信号在表示空间上存在显著分布差异，且各学科拥有独特的符号系统与推理范式。为突破这一瓶颈，研究者尝试构建统一骨干网络，但早期模型受限于参数量，无法在保持通用语言能力的同时掌握长尾科学知识，导致“通用性”与“专业性”的权衡难以优化。

多模态科学基础模型路线试图通过扩大模型规模来覆盖更多学科任务，但现有方案面临两大瓶颈：一是万亿参数级 MoE 架构中专家负载不均导致的训练不稳定，二是科学图像数据中缺乏高质量对齐的图文对，限制了视觉-语言对齐效果。主流方法如 S1-Omni 和 BigBang-Proton 虽提供了统一架构范式，但在处理高复杂度科学任务时，其通用知识覆盖能力仍显不足，且缺乏针对科学图像特性的专用数据构建策略。Intern-S1-Pro 的切入点在于，通过引入分组路由机制解决 MoE 训练稳定性问题，并构建基于 PDF 提取的专用 Caption Pipeline，以验证“规模扩张+联合训练”能否在特定科学任务上实现超越专用模型的协同增益。

## 核心方法

### 方法参照系

本文问题属于多模态科学基础模型构建，其标准流程包括统一骨干设计、多模态对齐训练及任务特定解码。与通用 LLM 不同，科学基础模型需处理非结构化科学数据（如公式、图表、时序信号），且要求模型在保持通用推理能力的同时，具备垂直领域的深度知识。本文的关键差异在于，其不仅关注模型架构的扩展，更聚焦于解决万亿参数 MoE 训练中的工程稳定性问题，以及科学图像数据的质量瓶颈。

### 分组路由机制（Grouped Routing）

传统 Top-K 路由在大规模 MoE 训练中易导致专家负载不均，进而引发内存溢出（OOM）风险。本文提出分组路由机制，将专家均匀划分为 $G$ 个互斥组，每组仅激活组内得分最高的 $K/G$ 个专家。该机制通过强制组内负载均衡，实现了设备间的绝对负载平衡。其核心公式为：

$$ \mathcal{S} = \bigcup_{g=1}^{G} \text{TopK}(\mathbf{p}_g, K/G) $$

其中 $\mathbf{p}_g$ 为第 $g$ 组专家的 softmax 概率分布。这一设计解决了传统路由在 EP8 并行策略下因负载不均导致的训练效率下降与 OOM 风险，确保了万亿参数模型的稳定训练。

### 科学图像 Caption Pipeline

科学图像（如实验图表、结构图）的原始描述往往简短且缺乏与视觉元素的精确对齐，导致视觉-语言对齐效果不佳。本文构建了基于 PDF 提取的专用 Caption Pipeline，通过 MinerU2.5 进行布局分析，提取子图并使用 InternVL3.5-241B 生成专业领域描述。该流程引入了 0.5B 参数文本质量判别器，过滤低信息密度内容，最终生成约 270B tokens 的高质量科学图文对。这一设计解决了现有开源数据集在科学图像领域覆盖不足且对齐质量低的问题，为模型提供了更精准的跨模态监督信号。

## 实验评估

实验在 OpenCompass、VLMEvalKit 及 AgentCompass 上进行，对比基线包括 GPT-5.2、Gemini-3-Pro 及专用模型 Biology-Instruction。基线覆盖通用 LLM 与垂直领域模型，但缺乏同规模开源科学模型对比，可能高估了本文模型的相对优势。

| 基准 | Intern-S1-Pro | GPT-5.2 | Gemini-3-Pro | Biology-Instruction |
| :--- | :--- | :--- | :--- | :--- |
| SciReasoner | 55.5 | 13.6 | 14.7 | - |
| MatBench | 72.8 | - | - | - |
| Biology-Instruction (AVG) | 52.45 | - | - | 39.24 |
| AIME-2025 | 93.1 | - | - | - |

在科学任务上，Intern-S1-Pro 在 SciReasoner 上得分 55.5，显著高于 GPT-5.2 的 13.6 与 Gemini-3-Pro 的 14.7；在 Biology-Instruction 基准上，其平均分 52.45 超过专用模型 Biology-Instruction 的 39.24，验证了联合训练策略的有效性。

消融实验显示，分组路由机制在 30B 模型上相比传统 Top-K 路由，在 2000 步训练后性能提升显著，而采用差异化专家初始化则导致性能下降超过 20 分。这表明保持组内专家同质性对初始化稳定性至关重要。此外，FP8 混合精度 RL 训练在 30B MoE 模型上验证了与 BF16 训练行为的一致性，KL 散度曲线显示两者在优化过程中保持紧密匹配，证明了该精度策略在大规模训练中的可行性。

评估边界方面，本文未报告置信区间，且部分基准（如 SciTS）仅展示子集结果，缺乏全量数据对比。可复现性方面，模型权重已开源，但训练超参数与数据构建细节（如 PDF 语料库规模）未完全披露，限制了第三方复现的完整性。

## 关联研究分析

从问题动机看，Intern-S1-Pro 与 AlphaEvolve 代表了科学发现的两条不同路径：前者通过端到端多模态学习捕捉复杂模式，后者通过符号回归搜索可解释公式。AlphaEvolve 在矩阵乘法等可形式化任务上表现优异，但其计算成本极高且难以处理非结构化数据；Intern-S1-Pro 则通过规模扩张换取跨域泛化能力，但在可解释性上较弱。这一差异源于任务特性：符号回归追求精确性与可验证性，而多模态基础模型追求覆盖广度与推理灵活性。

从方法设计看，Intern-S1-Pro 与 S1-Omni 同属多模态科学基础模型路线，但 Intern-S1-Pro 在 MoE 架构上更为激进，引入了分组路由机制以解决万亿参数训练稳定性问题。S1-Omni 侧重数据融合与任务特定解码，而 Intern-S1-Pro 更关注工程优化与数据质量（如专用 Caption Pipeline）。这种差异反映了不同团队对“规模”与“质量”的权衡：Intern-S1-Pro 认为规模扩张是突破专业深度瓶颈的关键，而 S1-Omni 可能更依赖数据工程的精细化。查询侧增强在数据充足时是否仍有增益，论文未给出回答，这可能影响其在资源受限场景下的适用性。

## 总结

Intern-S1-Pro 旨在解决科学多模态基础模型中通用性与专业性的权衡难题，其切入点在于验证“足够大的通用模型联合训练可超越专用小模型”的假设。通过引入分组路由机制与专用 Caption Pipeline，该模型在 SciReasoner 上得分 55.5，在 Biology-Instruction 上平均分 52.45，显著优于 GPT-5.2 与专用模型。然而，其实验未充分验证通用知识覆盖能力是否因规模扩张而退化，且缺乏同规模开源科学模型的对比。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
