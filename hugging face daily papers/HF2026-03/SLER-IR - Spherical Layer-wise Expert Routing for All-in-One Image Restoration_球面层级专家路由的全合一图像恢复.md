> 全合一图像恢复（AiOIR）旨在以单一模型应对噪声、雨雾、模糊等多种退化，但现有方法在共享骨干中难以平衡不同退化目标的参数冲突，且在局部非连续退化下缺乏空间自适应能力。SLER-IR 指出，现有 MoE 路由依赖线性嵌入空间，其固有的类距偏差会扭曲余弦相似度门控，导致专家选择失稳；为此，本文将退化表征映射至单位超球面，并实施层级独立专家激活，辅以全局-局部粒度融合模块弥合训练-测试的空间尺度差异。该方法在标准基准上取得了优于现有 MoE 与提示类方法的 PSNR/SSIM 表现，但其性能增益高度依赖两阶段训练策略与 CLIP 编码器的退化判别能力，对未知混合退化的泛化边界尚未充分验证。

## 研究背景

当图像同时遭受雨条纹与局部雾霾时，去雨任务要求保留高频纹理，而去雾任务则倾向于平滑低频区域，这种目标冲突在共享权重的骨干网络中表现为特征干扰。为解耦这种干扰，混合专家（Mixture-of-Experts, MoE）架构通过路由机制激活特定专家，但路由的准确性取决于退化表征的几何结构。若表征学习于无约束线性空间，不同退化类型间的距离分布往往不均匀，这种类距偏差会直接污染基于相似度的门控分数，导致路由决策在退化轻微或混合时发生翻转。

AiOIR 领域已形成特征调制与架构适配两条主流路线。特征调制路线（如 PromptIR、AirNet）通过提示或对比学习在统一参数空间内动态调整特征，但其共享骨干仍受限于细粒度退化建模的瓶颈；架构适配路线（如 MoCE-IR、WM-MoE）通过激活任务特定专家缓解冲突，但现有工作多将专家限制在局部模块，且路由机制难以处理任务间的对抗关系。此外，多数方法忽略了雨条纹等空间非连续退化，且基于裁剪块训练与全分辨率推理之间存在粒度失配。SLER-IR 的切入点在于重构路由的几何基础与空间引导机制，通过超球面嵌入消除几何偏差，并通过层级路由实现组合式推理路径。

## 核心方法

### 方法参照系

SLER-IR 属于架构适配路线，其基础流程为：提取退化特征 -> 计算与专家中心的相似度 -> 门控选择专家 -> 执行恢复。与 MoCE-IR 等仅对特定层或模块进行路由的方法不同，SLER-IR 将编码器-解码器的每个骨干块替换为多个参数独立的专家，并在每一层独立执行路由决策，从而构建出指数级的组合推理路径。

### 超球面退化表征学习

传统线性嵌入空间中的类距偏差是路由失稳的根源，例如去噪与去雾特征可能被人为推远，导致相似度门控错误分离具有共同处理组件的退化。为消除这种几何诱导的偏差，SLER-IR 引入超球面均匀嵌入，将退化特征向量 $\mathbf{f}$ 通过 L2 归一化投影至单位超球面：

$$ \hat{\mathbf{f}} = \frac{\mathbf{f}}{\|\mathbf{f}\|_2} $$

投影后，路由基于余弦相似度 $\mathbf{s}_{i,j} = \hat{\mathbf{f}}_i \cdot \mathbf{C}_j$ 进行，其中 $\mathbf{C}_j$ 为专家中心。该设计将距离度量转化为角度度量，并通过蒙特卡洛正则化约束专家中心在超球面上均匀分布，最大化中心间的最小夹角，从而确保门控分数仅反映真实的退化亲和性，而非嵌入空间的几何伪影。

### 层级动态路由与粒度融合

层级路由解决了单一全局路由无法适应特征从全局到局部演化的问题。在 Stage 1，采用概率路由，通过行级 Softmax 计算选择概率 $\mathbf{p}_{i,:}$，使所有专家接收梯度，防止过早专业化；在 Stage 2，切换为确定性路由，冻结路由器并仅激活最大概率专家。为应对空间非均匀退化，全局-局部粒度融合（GLGF）模块构建内容语义补丁图（CSP）与退化严重度补丁图（DSP），通过内容引导的退化融合（CGDF）生成恢复先验图，并在骨干各层通过引导交叉注意力注入，弥合训练裁剪块与全图推理的粒度差距。

| Restormer | 33.86 / 0.958 | 33.78 / 0.958 | 31.83 / 0.911 | - | - | - |
| PromptIR | 29.87 / 0.970 | 36.03 / 0.971 | 32.70 / 0.919 | - | - | - |
| MoCE-IR | 30.84 / 0.980 | 38.54 / 0.982 | 31.43 / 0.891 | 27.46 / 0.840 | 22.29 / 0.833 | 30.58 / 0.919 |
| SLER-IR | 33.43 / 0.985 | 38.47 / 0.983 | 31.50 / 0.894 | 31.27 / 0.918 | 23.96 / 0.861 | 31.73 / 0.928 |

实验在 SOTS、Rain100L、CBSD68、GoPro 和 LOL 五个基准上进行，对比了 Restormer、PromptIR、MoCE-IR 等基线。基线覆盖了特征调制与架构适配两条路线，但缺失扩散生成类基线（如 LucidFlux），这可能影响对感知质量维度的全面评估。在五任务设置下，SLER-IR 平均 PSNR 达 31.73 dB，较 MoCE-IR 提升 1.15 dB，其中去雾任务提升 2.59 dB，去模糊任务提升 1.22 dB，表明层级路由在复杂退化下具有显著优势。

| :--- | :--- | :--- |
| w/o GLGF | 30.64 | 0.917 |
| SLER-IR (Full) | 31.73 | 0.928 |
| Loss: L1 + Classifier | 28.76 | 0.884 |
| Loss: L1 + L_HC (Ours) | 31.73 | 0.928 |

消融实验显示，GLGF 模块贡献了 1.09 dB 的 PSNR 增益，验证了全局-局部融合对空间非均匀退化的关键作用。损失函数方面，仅使用 L1 损失配合分类器时 PSNR 仅为 28.76 dB，而引入超球面对比损失（L_HC）后提升至 31.73 dB，表明几何一致的退化表征对路由稳定性的决定性影响。专家数量消融显示 C=3 时性能最佳，更多专家在相同训练预算下未带来增益。

评估仅采用 PSNR 和 SSIM，缺乏 LPIPS 等感知指标，无法量化生成式方法可能存在的幻觉问题。代码声明将公开，但当前未提供 URL，且训练依赖 H20 GPU 与两阶段策略，复现成本较高。

## 关联研究分析

从路由机制看，SLER-IR 与 MoCE-IR 形成直接竞争。MoCE-IR 采用复杂度感知路由，但专家仅存在于局部模块，且平衡损失策略未能解决方向性冲突；SLER-IR 通过超球面嵌入将路由问题转化为角度优化，并在所有层级实施独立路由，其性能优势（+1.15 dB avg）源于几何偏差的消除与组合路径的多样性。然而，层级独立路由是否导致深层专家选择与浅层特征连贯性断裂，论文未提供跨层一致性分析。

从退化表征看，SLER-IR 继承了 AirNet 的对比学习思想，但摒弃了线性空间，转而采用超球面几何。这与 PromptIR 的提示调制路线形成范式差异：PromptIR 依赖可学习提示动态编码退化信息，计算开销较大且依赖提示生成准确性；SLER-IR 则通过架构级专家分离与几何约束实现静态路由，推理开销与单专家模型相当。这种取舍使得 SLER-IR 在效率上占优，但对未知退化的适应能力可能受限于预定义的专家中心分布。

## 总结

SLER-IR 针对 AiOIR 中 MoE 路由的几何偏差与空间粒度失配问题，通过超球面嵌入与层级动态路由实现了组合式推理路径。实验证明，消除线性空间类距偏差可使平均 PSNR 提升 1.15 dB，GLGF 模块进一步贡献 1.09 dB 增益。然而，该方法依赖 CLIP 编码器提取退化线索，且专家中心在 Stage 1 通过蒙特卡洛采样固定，对训练分布外的未知混合退化，其路由稳定性与泛化能力尚未验证。当输入退化类型超出预定义专家中心的覆盖范围时，超球面路由是否会退化为随机选择，论文未给出回答。
