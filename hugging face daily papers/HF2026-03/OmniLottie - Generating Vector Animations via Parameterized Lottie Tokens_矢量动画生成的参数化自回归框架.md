> 矢量动画生成旨在从多模态指令直接产出可编辑、分辨率无关的 Lottie JSON 文件，而非光栅视频。现有方法或依赖外部运动先验与静态矢量图分离，或由通用大语言模型直接生成原始 JSON，后者因格式冗余导致成功率极低。本文切入点在于设计专用的 Lottie Tokenizer，将复杂的层级 JSON 结构压缩为紧凑的命令-参数序列，使预训练视觉语言模型能够高效学习动画生成。该框架在视觉保真度与语义对齐上显著优于商业工具与通用模型，但其对复杂非刚性运动的物理一致性建模仍显不足。

## 研究背景

矢量动画的核心载体是 Lottie 格式，一种将形状、特效与运动参数统一存储于单一 JSON 文件中的层级化表示。与 SVG 仅堆叠几何图形并嵌入 CSS 代码不同，Lottie 通过图层继承机制整合视觉元素与动态效果，具备更强的跨平台兼容性。然而，这种层级结构包含大量不变的结构元数据与格式标记，直接将其作为文本序列输入模型，会导致模型容量被浪费在复现格式上，而非学习几何与运动先验。

矢量动画生成的主流路线长期存在外观与运动的解耦问题。早期方法依赖参考 GIF 或文本到视频生成器提供运动先验，再应用于手动设计的静态矢量图，无法实现端到端的矢量合成。随着大语言模型（LLM）的兴起，部分模型尝试直接生成 Lottie JSON，但受限于嵌套 JSON 的严格格式约束与指令跟随能力，其生成成功率极低。本文的研究问题在于：如何构建一种高效的序列化机制，消除 Lottie JSON 中的冗余信息，使自回归模型能够基于多模态指令端到端地生成高质量矢量动画。

## 核心方法

### 方法参照系

本文问题可归类于视觉自回归生成范式，即处理视觉内容作为 Token 序列。与生成像素或潜变量的扩散模型不同，本文的输出空间是结构化代码。关键差异在于，传统自回归模型处理自然语言或图像 Token，而本文需处理具有严格层级依赖与数值连续性的动画参数，这要求对原始 JSON 进行语义化的离散化重构。

### Lottie 结构化压缩

针对原始 JSON 中格式 Token 占比过高的问题，本文提出 Lottie Tokenizer，将动画抽象为紧凑的命令序列。该设计解决了直接生成 JSON 时模型难以聚焦于几何与运动语义的失效。Tokenizer 支持五种基础图层类型（Precomposition, Solid, Null, Shape, Text），通过遍历图层属性，将连续参数映射为离散 Token。量化过程采用基于偏移的方案，公式如下：

$$
T_{param} = \lfloor p \cdot s_t \rfloor + o_t
$$

其中 $p$ 为参数值，$s_t$ 为类型特定的缩放因子，$o_t$ 为词表偏移量。该公式将不同语义类别（时间、空间、变换、样式）的参数映射到互不冲突的离散区间，既保留了数值精度，又避免了 Token 冲突，实现了 JSON 的无损压缩与语义解耦。

### 多模态自回归生成

在压缩后的 Token 序列基础上，本文基于 Qwen2.5-VL 构建 OmniLottie 模型。该设计利用了预训练 VLM 强大的多模态指令跟随能力，解决了单一模态输入难以控制复杂动画属性的局限。模型引入随机初始化的 Lottie 词表嵌入，与 VLM 骨干网络联合训练。训练目标为标准交叉熵损失，模型在给定多模态指令 $x_c$ 的条件下，自回归地生成 Lottie Token $x_{s[i]}$：

$$
\mathcal{L} = -\sum_{i} \log P(x_{s[i]} | x_{s[<i]}, x_c)
$$

这一机制使得模型能够同时处理文本、图像与视频输入，将多模态信息统一映射到 Lottie 命令空间。通过端到端训练，模型不再依赖外部运动先验，而是直接从数据中学习形状、特效与运动的联合分布，实现了从指令到可编辑矢量动画的直接转换。

## 实验评估

实验在自建 MMLottie-Bench 上进行，包含 Real Subset（450 个艺术家设计样本）与 Synthetic Subset（150 个合成样本）。基线涵盖通用 LLM（GPT-5, DeepSeek, Qwen2.5-VL）、商业工具（Recraft）及优化方法（AniClipart, Livesketch）。

| 任务 | 方法 | FVD ↓ | CLIP ↑ | Obj. Align ↑ | Motion Align ↑ | Success Rate |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Text-to-Lottie | GPT-5 | 715.73 | 0.2600 | 0.73 | 0.71 | 12.7% |
| Text-to-Lottie | Recraft | 300.70 | 0.2950 | 4.70 | 4.68 | 77.3% |
| Text-to-Lottie | **Ours** | **202.14** | 0.2748 | 4.44 | **5.94** | **88.3%** |
| Video-to-Lottie | GPT-5 | 639.13 | - | - | - | 9.2% |
| Video-to-Lottie | **Ours** | **227.11** | - | - | - | **88.1%** |

在 Text-to-Lottie 任务中，OmniLottie 的 FVD 为 202.14，显著低于 Recraft 的 300.70 和 GPT-5 的 715.73，且运动对齐得分最高（5.94）。Video-to-Lottie 任务中，OmniLottie 的 FVD 为 227.11，优于 GPT-5 的 639.13。通用 LLM 如 Qwen2.5-VL 成功率均为 0.0%，表明直接生成 JSON 的不可行性。

消融实验显示，使用 Lottie Tokenizer 后，Text-to-Lottie 成功率从 13.4% 提升至 97.3%，FVD 从 459.39 降至 269.50。这证实了结构化压缩对生成稳定性的关键作用。SVG 数据混合比例在 30% 时效果最佳，表明静态矢量数据有助于几何理解，但过多会损害运动复杂度。

评估协议依赖 LLM 作为裁判计算对齐指标，可能存在主观偏差。代码与数据集已公开，但超参数细节未完全披露。由于缺乏与扩散模型在相同矢量任务上的直接对比，无法量化自回归与扩散范式在矢量生成上的绝对优劣。

## 关联研究分析

从问题动机看，本文与人类图像动画领域中的“运动-外观解耦”范式存在形式相似性，但介质本质不同。人类动画关注像素级光流或潜变量去噪，而本文关注结构化代码的序列生成。人类动画中的 ControlNet 通过注入姿态信号控制运动，本文则通过 Lottie Tokenizer 将运动参数离散化，实现了隐式的运动控制。这种差异源于矢量动画的可编辑性需求，要求输出必须是精确的几何参数而非近似像素。

从方法设计看，本文采用自回归架构，与人类动画领域主流的扩散模型（如 DiT）形成对比。扩散模型在长时程一致性上具有优势，但推理速度慢；自回归模型支持流式生成，理论上更具实时潜力，但易受累积误差影响。本文在 Video-to-Lottie 任务中表现优异，表明自回归模型在短序列、强结构约束的矢量生成中可行。然而，对于长时程、复杂非刚性运动（如头发、衣物），自回归模型是否会出现类似人类动画中的身份漂移或运动断裂，论文未提供充分验证。

## 总结

OmniLottie 解决了矢量动画生成中格式冗余导致模型学习失效的核心矛盾。通过 Lottie Tokenizer 将 JSON 压缩为紧凑命令序列，结合预训练 VLM 的自回归生成能力，实现了从多模态指令到可编辑矢量动画的端到端转换。实验表明，该方法在 Text-to-Lottie 任务中 FVD 达 202.14，成功率 88.3%，显著优于商业工具与通用 LLM。然而，论文主要关注静态几何与简单运动的生成，对于复杂物理动态（如流体、布料）的矢量表示与生成能力未做深入探讨。当输入指令涉及高动态非刚性物体时，自回归生成的 Lottie 参数是否仍能保持物理合理性，是后续研究需验证的关键问题。
