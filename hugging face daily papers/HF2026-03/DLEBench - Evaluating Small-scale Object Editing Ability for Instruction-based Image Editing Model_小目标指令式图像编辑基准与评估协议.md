# HuggingFace最新推荐论文 ｜DLEBench: Evaluating Small-scale Object Editing Ability for Instruction-based Image Editing Model ｜小目标指令式图像编辑基准与评估协议

研究机构：复旦大学、美团

作者：Shibo Hong、Boxian Ai、Jun Kuang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2602.23622)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2602.23622)

> 指令式图像编辑模型在通用基准上表现优异，但现有评测普遍偏向占据画面主导空间的大目标，导致小目标编辑能力被系统性高估。本文指出，当目标物体面积缩减至图像总面积的1%–10%时，编辑范式从广泛修改退化为局部精修，现有模型在此区间面临定位失效与评估盲区的双重困境。作者通过反事实合成管道构建首个小目标专用基准DLEBench，并设计基于失败模式的双模式评估框架以校准自动评测与人类判断的偏差。该工作揭示了当前SOTA模型在小目标场景下的显著性能悬崖，但其评估协议依赖人工标注边界框，限制了全自动化部署的可行性。

## 研究背景

当扩散模型面对占据画面极小比例的物体时，其全局注意力机制难以将语义指令精确锚定到像素级目标区域，这一现象导致编辑操作频繁作用于错误对象或引发背景伪影。这种定位失效源于模型训练数据中大目标的主导分布，使得网络缺乏对微小空间特征的敏感度。为量化这一失效，需要建立能够区分“定位错误”与“执行错误”的细粒度评估指标，而传统基于CLIP相似度的整体打分无法捕捉这种局部语义偏差，必须引入基于失败模式的层级化评分机制。

指令式图像编辑领域已建立从单轮单对象到多轮多对象的评测体系，如I2EBench和ImgEdit，但现有基准普遍存在空间尺度偏置，未针对小目标场景设计约束。主流评估范式依赖多模态大语言模型（LMM）作为裁判，然而当编辑目标仅占图像极小面积时，LMM的视觉感知能力不足以区分细微修改与背景噪声，导致评估结果与人类判断严重偏离。本文切入点在于构建一个强制目标面积处于1%–10%区间的专用基准，并重构评估协议以解决小目标场景下自动评估器的感知盲区问题。

## 核心方法

### 基准构建参照系

标准图像编辑基准构建流程依赖人工标注或合成数据生成“指令-图像对”，通常假设目标物体在画面中具有显著空间占比。本文问题与该通用流程的关键差异在于，小目标场景下现有SOTA模型无法在全图尺度上可靠生成参考图像，且人工标注小目标配对数据成本极高，必须引入自动化转换管道与裁剪编辑机制。

### 反事实合成与裁剪编辑管道

针对小目标配对数据稀缺问题，本文在数据构建阶段引入反事实合成策略，将视觉推理数据集中的问答对转化为编辑元数据。具体而言，从候选选项 $O$ 中选取错误选项 $A_{neg}$ 作为目标属性，通过与正确选项 $A$ 的对比生成编辑指令 $Instruction$。该设计动机在于利用现成的视觉推理数据集中密集的小目标标注，规避人工标注成本。为解决小目标参考图生成难题，本文采用裁剪编辑机制，将目标区域从全图中隔离后执行编辑，其核心逻辑可表示为：

$$RI = Edit(Crop(SI, BBox_{TO}), Instruction)$$

其中 $RI$ 为参考图像，$SI$ 为源图像，$BBox_{TO}$ 为目标物体边界框。该机制通过限制模型注意力范围，确保参考图像的高质量生成，弥补了全图编辑在小目标上的定位失效。

### 失败模式层级化评估协议

针对LMM-as-a-Judge在小目标上感知力不足的问题，本文重构了指令遵循（IF）与视觉一致性（VC）的评分量表，将模糊的主观描述替换为基于失败模式的层级化标签。IF评分采用四级层级结构，其判定逻辑可形式化为：

$$Score_{IF} = \begin{cases} 1 & \text{if } \neg Localization \lor Blurriness \\ 2 & \text{if } Localization \land \neg ActionAlignment \\ 3 & \text{if } Localization \land ActionAlignment \land \neg Preservation \\ 4 & \text{if } Localization \land ActionAlignment \land Preservation \end{cases}$$

该公式强制将定位错误与执行错误解耦，确保评估结果的可复现性与错误诊断的精确性。双模式评估框架中，Oracle-guided模式利用人工标注边界框隔离目标区域，消除定位误差对评估的干扰；Tool-driven模式则通过外部工具迭代定位差异，实现无需人工干预的自动化评估。

## 实验评估

实验在DLEBench上进行，包含1,889个样本，目标物体面积限制在1%–10%区间，覆盖七种指令类型。基线覆盖开源模型（OmniGen2, Qwen-Edit, UniWorld-V1/V2, Step1X-Edit, Bagel-Think, UniREdit-Bagel）与闭源模型（GPT-Image-1, Gemini-3-Pro），但缺失最新强化学习对齐方法如SpatialFlow-GRPO，无法判断RL机制是否已解决小目标定位问题。

| 模型类型 | 模型名称 | IF均分 | VC均分 |
| :--- | :--- | :--- | :--- |
| 闭源 | Gemini-3-Pro | 48.97 | 82.13 |
| 闭源 | GPT-Image-1 | 45.32 | 35.17 |
| 开源 | Bagel-Think | 35.55 | 86.43 |
| 开源 | Step1X-Edit | 42.65 | 68.13 |
| 开源 | OmniGen2 | 24.32 | 59.79 |

Gemini-3-Pro以48.97的IF均分领先，但远低于其在通用基准上的表现，证明小目标场景下SOTA模型存在显著性能悬崖。Bagel-Think的VC均分86.43高于Gemini-3-Pro的82.13，表明开源模型在背景保持方面具有竞争力，但IF得分35.55暴露其在小目标定位上的严重缺陷。

消融分析显示，Change Count指令类型在所有模型上得分最低，归因于同时隔离和枚举多个小目标所需的更高视觉感知能力。Oracle-guided模式与人类判断的Spearman相关系数最高，MAE最低，而LMM-as-a-Judge基线（Gemini-3-Pro, GPT-4.1）相关系数显著更低，MAE更高，证实现有LMM评估器在小目标场景下不可靠。

评估协议依赖人工标注边界框（Oracle-guided模式），限制了全自动化部署；Tool-driven模式虽实现自动化，但依赖外部工具调用，增加计算开销。代码与数据集已开源，但论文未报告推理延迟与GPU资源消耗，计算效率维度缺失。

## 关联研究分析

从问题动机看，本文与MIRA、EditThinker等推理规划框架存在根本差异。MIRA通过MLLM分解复杂指令并迭代执行，旨在提升复杂场景下的编辑精度；本文则聚焦小目标场景下的评估失效，不改进编辑模型本身，而是通过更严苛的基准揭示现有模型的短板。这种差异源于任务特性：MIRA解决的是“如何编辑”，本文解决的是“如何准确评估编辑结果”。

从方法设计看，本文与EditReward在评估信号构建上形成互补。EditReward构建奖励模型用于强化学习训练，优化模型参数；本文构建评分量表用于测试评估，诊断模型瓶颈。两者均关注细粒度评估信号，但EditReward的信号用于梯度更新，本文的信号用于错误诊断。本文未探索将失败模式评分转化为RL奖励信号的可行性，查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

本文核心矛盾在于现有基准的空间尺度偏置导致小目标编辑能力被高估，而LMM评估器在微小视觉变化上的感知盲区进一步加剧了评估偏差。本文通过反事实合成管道构建DLEBench，并设计基于失败模式的双模式评估框架，解决了小目标配对数据稀缺与自动评估不可靠的双重问题。实验证明Gemini-3-Pro在DLEBench上IF均分仅48.97，远低于其通用基准表现，揭示了SOTA模型在小目标场景下的系统性失效。本文边界在于Oracle-guided模式依赖人工标注边界框，限制了全自动化部署；Tool-driven模式虽实现自动化，但依赖外部工具调用。当目标物体面积进一步缩减至1%以下时，裁剪编辑机制是否仍能生成高质量参考图像，论文未给出回答。
