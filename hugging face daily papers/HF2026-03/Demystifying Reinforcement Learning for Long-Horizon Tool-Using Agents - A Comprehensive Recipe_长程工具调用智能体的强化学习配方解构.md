> 长程工具调用智能体面临的核心困境是：数十步交互中稀疏奖励导致信用分配失效，且现有研究多聚焦单步推理或短程交互，缺乏对奖励密度、模型规模、数据构成等设计空间维度的系统性实证。本文切入点在于将 TravelPlanner 这一高复杂度本地沙箱作为统一测试床，通过 STAR 流水线解构强化学习设计空间。具体做法是沿奖励塑形、模型缩放、数据构成、算法选择与环境稳定性五个轴进行受控实验，提炼出规模感知的训练配方。该工作提供了可复现的工程指南，但其结论是否适用于真实 API 环境及更大规模模型尚存疑。

## 研究背景

长程智能体任务要求模型在数十步工具调用中维持状态一致性并满足多重约束。这一过程可形式化为部分可观测马尔可夫决策过程（Partially Observable Markov Decision Process, POMDP），其中奖励信号通常仅在轨迹末端给出，导致中间步骤的梯度信号极度稀疏。为缓解此问题，Group Relative Policy Optimization (GRPO) 通过组内相对优势估计替代价值函数，降低了计算开销，但其对长程轨迹中细粒度信用分配的依赖仍未解决，尤其在模型容量有限时，稀疏奖励易引发策略崩溃或探索不足。

现有 Agentic RL 研究多针对短程任务或单一算法变体，缺乏对多因素交互效应的 holistic 视角。例如，Tree-GRPO 引入树搜索以细化信用分配，AgentRL 优化异步训练效率，但这些工作通常固定其他变量，无法揭示奖励密度与模型规模的耦合关系。本文的切入点在于构建一个计算高效且约束复杂的测试床，系统性地隔离并量化各设计轴对最终性能的影响，填补了从“算法创新”到“工程配方”之间的实证空白。

## 核心方法

### 方法参照系

本文问题归属于长程 Agentic RL 的训练优化范畴。与标准 GRPO 流程的关键差异在于：本文不提出新算法，而是将训练过程解耦为数据合成、监督微调（SFT）冷启动与强化学习（RL）三阶段，并在 RL 阶段引入多维受控变量，以实证方式替代理论推导。

### 奖励塑形与规模依赖机制

奖励设计是解决长程信用分配的核心杠杆。标准做法采用单一稀疏奖励（如 SUCCESS），但本文发现其无法为小模型提供足够的梯度信号。STAR 流水线引入四种奖励信号：密集 SUM、半稀疏 MACRO、稀疏 SUCCESS 及课程式 CURRICULUM。其中，CURRICULUM 借鉴 Zhu et al. 的思路，在训练初期使用密集奖励引导探索，后期过渡至稀疏奖励以强化最终目标。其优势函数计算仍基于 GRPO 框架：

$$ \hat{A}_{(i)} = \frac{r_{(i)} - \text{mean}(\{r_{(j)}\}_{j=1}^G)}{\text{std}(\{r_{(j)}\}_{j=1}^G)} $$

该公式通过组内标准化消除奖励尺度差异，使小模型能从密集反馈中稳定学习，而大模型则因内在推理能力更强，直接从 SUM 奖励中获益，无需课程式干预。

### 数据构成与环境稳定性控制

数据规模与难度分布直接影响泛化能力。本文发现 RL 数据存在“甜点位”：约 1K 样本且难度混合（4:3:3 易:中:难）时，域内性能与域外泛化达到最优平衡。过度增加数据至 2K 会导致域外性能显著下降，表明过拟合风险。此外，环境稳定性被纳入控制变量，通过注入随机工具失败模拟真实噪声。实验表明，环境噪声会显著降低长程智能体性能，验证了鲁棒性训练的重要性。该设计动机在于：真实 API 环境存在不可预测的失败，纯理想环境训练的策略在部署时易失效。

## 实验评估

实验在 TravelPlanner 测试集（1,000 实例）上进行，基线包括 Base、SFT 及 GRPO/DAPO/ARPO 变体。对比方法覆盖了主流 RL 算法，但缺失 Tree-GRPO 等系统级方法。主要结果显示，STAR 训练的 7B 模型在 TravelPlanner 上达到 62.8% 成功率，显著优于 SFT 基线（19.7%）及商业 LLM（Kimi-K2.5 <15%）。

| 模型规模 | 算法 | 成功率 (%) | GPU 小时 |
| :--- | :--- | :--- | :--- |
| 1.5B | GRPO | 30.1 | 164 |
| 1.5B | ARPO | 37.5 | 195 |
| 7B | GRPO | 62.8 | 368 |
| 7B | ARPO | 58.3 | 547 |

消融实验揭示反直觉发现：小模型（1.5B）从 ARPO 等探索增强算法中获益显著（37.5% vs 30.1%），而大模型（7B）中 GRPO 表现最佳且效率最高。这表明算法选择的必要性随模型容量增加而递减。数据构成方面，Mixed-1K 配置（成功率 49.9%）优于纯 Easy-1K（45.3%）或 Hard-1K（25.9%），验证了难度混合对平衡奖励稀疏性与复杂约束学习的必要性。

评估边界方面，TravelPlanner 为本地沙箱，缺乏真实 API 延迟与错误处理验证；OOD 评估仅覆盖 7 个 QA 基准，未涉及其他工具调用场景。代码已开源，但超参数细节（如 KL 惩罚系数）未在正文完整披露，复现需依赖附录。

## 关联研究分析

从问题动机看，本文与 Tree-GRPO 形成互补：Tree-GRPO 通过树搜索结构细化信用分配，属于算法层面的创新；而 STAR 聚焦于奖励密度与数据构成的工程配置，属于训练策略层面的优化。两者差异根源在于任务特性：Tree-GRPO 适用于可分解的层级任务，而 TravelPlanner 的约束耦合性更强，使得简单的奖励塑形比复杂的树结构更具成本效益。

从方法设计看，本文与 AgentRL 的异步架构不同：AgentRL 解决多节点资源调度瓶颈，STAR 则关注单节点内训练动态的稳定性。STAR 引入的 KL-Free 与 Clip-high 修改，旨在防止长程交互中的熵坍缩，这与 ARLArena 揭示的稳定性机制一致。然而，STAR 未探索多智能体协同场景，其结论是否适用于角色专业化系统（如 Stronger-MAS）尚不明确。

## 总结

本文核心矛盾在于长程 Agentic RL 中设计空间维度的交互效应缺乏系统性实证。切入点在于利用 TravelPlanner 的高复杂度与低计算成本，通过 STAR 流水线解构奖励、规模、数据、算法与环境五个轴。证明了规模感知配方的有效性：7B 模型在 TravelPlanner 上达到 62.8% 成功率，且 1K 混合数据为泛化甜点位。边界在于本地沙箱环境与有限 OOD 基准，未验证真实 API 噪声下的鲁棒性。当模型规模扩展至 70B 以上时，密集奖励的“对齐税”是否消失，论文未给出回答。
