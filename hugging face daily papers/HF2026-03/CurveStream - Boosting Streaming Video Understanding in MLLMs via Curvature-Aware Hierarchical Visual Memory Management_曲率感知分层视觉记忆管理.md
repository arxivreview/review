> 流式视频理解面临无限输入与有限显存的物理冲突，现有基于均匀采样或静态规则的内存管理策略易导致语义碎片化与关键过渡点丢失。CurveStream 利用特征空间轨迹的几何曲率作为语义强度代理，通过在线动态阈值将帧路由至不同分辨率的记忆层级，在固定显存预算下实现自适应上下文保留。该方法无需训练即可显著提升多模态大语言模型在长视频流中的表现，但其对静态场景的过度压缩及缺乏主动响应机制限制了其在复杂交互场景的适用性。

## 研究背景

流式视频理解要求模型在严格因果约束下处理无限视频流，其核心矛盾在于视觉 Token 随时间线性增长，导致 GPU 显存溢出（Out-of-Memory, OOM）。为缓解此问题，模型需维护一个固定容量的内部状态 $M_t$，该状态通过递归更新 $M_t = f(M_{t-1}, x_t)$ 生成，并据此产生响应 $y_t$。然而，简单的滑动窗口或均匀采样策略往往丢失长程依赖，而暴力压缩则引入不可逆的信息模糊，使得模型难以在实时响应延迟与长程语义记忆完整性之间取得平衡。

现有方法主要聚焦于视觉信息保留与长期记忆管理两个维度。视觉保留策略多依赖均匀采样或低层物理度量（如帧间相似度、光流），这些方法对局部噪声敏感，且优先保留物理运动而非高层语义过渡。记忆管理机制则包括基于规则的缓存驱逐、特征聚类及外部存储检索，但它们通常采用被动驱逐或平滑压缩，缺乏内在的语义感知能力。这导致三类局限：语义碎片化破坏上下文连贯性，无差别压缩模糊瞬态关键语义点，以及基于事后查询的检索机制限制了实时主动感知能力。CurveStream 的切入点在于重新审视视频流在特征空间中的演化动力学，发现高曲率区域与高质量视觉语义过渡精确对应，从而提出一种基于几何度量的自适应记忆管理框架。

## 核心方法

### 方法参照系

CurveStream 属于流式视频内存管理与压缩路线，其标准流程是在固定 Token 预算 $N_{max}$ 下，通过某种准则决定当前帧 $I_t$ 的保留状态与分辨率。与基于静态规则或外部检索的传统方法不同，CurveStream 将记忆管理建模为在线信息提取问题，利用特征流形的内在几何属性构建轻量级调度策略 $\pi$，输出状态元组 $(s_t, r_t)$，其中 $s_t \in \{Clear, Blurred, Discard\}$ 表示层级路由状态，$r_t$ 表示空间分辨率。

### 曲率感知评分器（CAS）

传统基于帧间差异的采样策略易过拟合于平移运动，无法区分背景平滑变化与语义突变。CurveStream 引入曲率感知评分器（Curvature-Aware Scorer, CAS），通过融合一阶运动变化与二阶几何曲率来量化语义过渡强度。设计动机在于利用几何曲率作为语义偏移强度的代理，克服低层物理度量对局部噪声的敏感性。CAS 首先利用冻结视觉编码器提取全局特征 $\mathbf{F}_t$，计算相邻帧位移向量 $\mathbf{d}_1 = \mathbf{F}_{t-1} - \mathbf{F}_{t-2}$ 和 $\mathbf{d}_2 = \mathbf{F}_t - \mathbf{F}_{t-1}$。局部几何曲率 $C_t$ 近似为这两个位移向量间的角度偏差：

$$
C_t = \arccos\left(\frac{\mathbf{d}_1 \cdot \mathbf{d}_2}{\|\mathbf{d}_1\| \|\mathbf{d}_2\|}\right)
$$

当 $\mathbf{d}_1$ 与 $\mathbf{d}_2$ 方向一致时，$C_t$ 趋近于 0，表示平滑过渡；当特征演化方向突变（如新实体出现或视角急转），$C_t$ 显著增加。最终曲率分数 $CS_t$ 为一阶运动变化 $M_t$ 与几何曲率 $C_t$ 的线性组合：

$$
CS_t = M_t + \lambda C_t
$$

其中 $\lambda$ 为平衡系数。该公式的物理含义是：$CS_t$ 越高，代表当前帧在特征流形中发生了越剧烈的“转弯”，即蕴含越高的语义信息量。

### 分层视觉记忆管理（HVMM）

静态阈值在非平稳视频流中易导致记忆库崩溃或关键信息丢失。CurveStream 引入分层视觉记忆管理（Hierarchical Visual Memory Management, HVMM），通过在线更新的 K-Sigma 规则动态生成准入阈值。设计动机在于适应视频流的动态节奏，避免先验静态阈值在复杂场景下的失效。HVMM 利用指数移动平均（EMA）实时更新曲率分数的瞬时均值 $\mu_t$ 和方差 $\sigma_t$，构建双阈值 $g_1 = \mu_t + k_1 \sigma_t$ 和 $g_2 = \mu_t + k_2 \sigma_t$（$k_1 < k_2$）。帧 $I_t$ 的路由状态 $s_t$ 由以下规则决定：

$$
s_t = \begin{cases}
Clear & \text{if } CS_t \ge g_2 \\
Blurred & \text{if } g_1 \le CS_t < g_2 \\
Discard & \text{if } CS_t < g_1
\end{cases}
$$

Clear 状态保留原始高分辨率特征以支持细粒度推理，Blurred 状态下采样至低分辨率以压缩 Token 开销，Discard 状态直接丢弃冗余帧。当记忆库容量 $|M_t| > N_{max}$ 时，系统执行严格的先进先出（FIFO）驱逐，移除最旧 Token。这一机制确保在恒定显存占用下，模型始终保留核心视觉语义轨迹，同时通过动态阈值自适应调节对视觉变化的敏感度。

## 实验评估

CurveStream 在 StreamingBench、OVO-Bench、MVBench、EgoSchema 和 VideoMME 五个基准上进行了评估，涵盖流式、离线短视频及长视频场景。基线审计显示，对比方法覆盖了 LLaVA-OneVision、Qwen-VL 系列等开源多模态大语言模型，以及 Flash-VStream、FreshMem、HERMES 等流式专用方法，但缺失 VST、ThinkStream 等 2026 年最新的推理型方法。在 Qwen2.5-VL-7B 骨干上，CurveStream 在 StreamingBench 和 OVO-Bench 上分别取得 84.00% 和 73.48% 的准确率，较基线提升 10.69% 和 13.58%。

| 方法 | 骨干模型 | StreamingBench (%) | OVO-Bench (%) |
| :--- | :--- | :--- | :--- |
| Qwen2.5-VL-7B | Qwen2.5-VL-7B | 73.31 | 59.90 |
| + HERMES | Qwen2.5-VL-7B | 79.44 | 68.98 |
| + CurveStream | Qwen2.5-VL-7B | 84.00 | 73.48 |
| Qwen2-VL-7B | Qwen2-VL-7B | 69.04 | 60.65 |
| + CurveStream | Qwen2-VL-7B | 81.04 | 70.73 |

在消融实验中，曲率综合分数权重 $\lambda$ 在 [0.1, 0.4] 范围内变化时，模型准确率稳定在 62.5% 以上，峰值为 65.83%，最大绝对波动仅为 3.33%。这表明框架对超参数不敏感，具有良好的鲁棒性。然而，在离线长视频基准 VideoMME 上，Qwen2.5-VL-7B 的准确率从 64.52% 降至 62.97%，揭示了固定显存预算下为保留关键语义过渡而牺牲细粒度全局细节的权衡。

评估边界方面，论文未报告 TTFT（Time To First Token）或 MaxFPS 等系统级延迟指标，仅强调在单 GPU 上运行以验证显存约束下的鲁棒性。代码已开源，但 DINOv2-small 特征提取器的引入是否增加额外推理延迟未在实验中量化。此外，评估主要基于平均准确率，缺乏对极端动态场景下延迟尖峰的细粒度分析。

## 关联研究分析

从问题动机看，CurveStream 与 HERMES 同属训练无关的分层记忆管理路线，但两者在语义感知机制上存在根本差异。HERMES 依赖基于规则的缓存驱逐和空间时间冗余度量，本质上是一种被动平滑过程，容易模糊瞬态语义偏移。CurveStream 则引入特征流形的几何曲率作为主动准入阈值，将记忆管理从队列平滑转化为语义感知的动态更新。这一差异的根源在于对“信息价值”的定义不同：HERMES 假设冗余帧价值低，而 CurveStream 假设高曲率帧价值高。这种几何度量是否在所有视频类型中都能准确捕捉语义重要性，论文未给出跨域验证。

从方法设计看，CurveStream 与 StreamingVLM 在无限流架构上具有继承关系，但核心机制不同。StreamingVLM 采用注意力沉没（Attention Sink）和连续 RoPE 位置编码来解决上下文断裂，侧重于架构层面的位置编码优化。CurveStream 则聚焦于视觉编码器前端的帧筛选与分辨率分配，通过曲率分数决定哪些帧进入 LLM 上下文。这种前端的显式筛选与 StreamingVLM 的隐式注意力机制形成了互补。然而，CurveStream 缺乏主动响应机制（如 EOS 预测），仅做被动记忆管理，这限制了其在需要模型自主决定“何时说话”的具身智能场景中的应用。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

CurveStream 旨在解决流式视频理解中无限输入与有限显存的矛盾，通过发现特征空间高曲率区域与语义过渡的对应关系，提出了基于几何度量的自适应记忆管理框架。该方法利用在线 K-Sigma 动态阈值将帧路由至 Clear、Blurred 或 Discard 状态，在固定 Token 预算下实现了语义感知的上下文保留。实验表明，在 Qwen2.5-VL-7B 骨干上，CurveStream 在 StreamingBench 和 OVO-Bench 上分别取得 84.00% 和 73.48% 的准确率，较基线提升超过 10%。其边界在于固定显存预算下对细粒度全局细节的牺牲，以及缺乏主动响应机制导致的实时交互能力局限。当视频流包含大量静态背景与少量关键事件时，曲率阈值是否会导致关键事件的漏检，论文未给出回答。
