# HuggingFace最新推荐论文 ｜VisionCoach: Reinforcing Grounded Video Reasoning via Visual-Perception Prompting ｜视觉提示引导的强化学习视频推理

作者：Daeun Lee、Shoubin Yu、Yue Zhang 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2603.14659)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2603.14659)

> 视频推理模型常因缺乏时空接地而产生幻觉，现有方案或依赖昂贵的密集标注，或在推理时引入高延迟的外部工具。本文切入点在于将视觉提示从推理时的外部干预转化为训练时的内部引导信号，通过自蒸馏机制内化接地行为，实现推理时的零提示依赖。该方法在7B模型规模下显著提升了时空定位精度，但其对超长视频及未见提示类型的泛化能力仍存疑。

## 研究背景

视频问答任务要求模型不仅给出答案，还需显式对齐视频中的时空证据。当模型仅依赖语言先验进行推理时，往往生成看似合理但视觉上不存在的解释，这种现象称为幻觉。为抑制幻觉，模型需具备时空接地能力，即在推理过程中准确识别证据发生的时间（Temporal IoU）与空间位置（Spatial IoU）。然而，静态特征提取难以捕捉动态场景中的因果逻辑，导致感知与推理脱节。

当前主流路线分为两类：一是文本中心推理，如Video-R1，虽提升了逻辑一致性，但接地不可靠；二是工具调用推理，如CAViAR，通过动态裁剪或缩放获取证据，但引入了显著的推理延迟与计算开销。这两类方法均未解决“如何在不增加推理负担的前提下提升接地精度”的核心矛盾。本文提出VISIONCOACH，通过训练时视觉提示引导强化学习，并辅以自蒸馏移除提示依赖，旨在实现单次前向传播下的高精度时空接地。

## 核心方法

### 方法参照系

本文基于可验证奖励强化学习（RLVR）框架，采用GSPO优化策略。与标准RLVR直接在原始输入上训练不同，本文在训练阶段引入输入自适应的视觉提示，并通过自蒸馏将提示诱导的接地行为内化至策略模型，从而在推理时保持轻量级单路径架构。

### 输入自适应视觉提示选择

标准RLVR缺乏对困难样本的针对性感知引导，导致模型在复杂场景下难以聚焦关键证据。本文引入视觉提示选择器（VP-SELECTOR），基于视频与问题预测最优提示类型。设计动机在于解决固定提示（如全局暗化）对无关区域的过度抑制问题。VP-SELECTOR通过代理推理器构建候选数据集，利用监督微调训练轻量级VLM分类器，其选择过程可形式化为：

$$ v_i = \arg\max_{v_k \in V} \frac{1}{|R|} \sum_{r \in R} (A_k^r + G_k^r) $$

其中 $A_k^r$ 与 $G_k^r$ 分别为代理推理器 $r$ 在提示 $v_k$ 下的答案准确率与接地得分。该机制确保仅对高难度样本施加针对性视觉引导，避免对易样本造成干扰。

### 自蒸馏内化与接地奖励

视觉提示虽能提升训练时的接地质量，但推理时无法依赖外部提示。本文通过自蒸馏损失将提示引导下的高奖励轨迹内化至原始输入策略，消除推理时的提示依赖。同时，引入对象感知空间接地奖励 $r_{spa}$，强制物体身份一致性与多区域边界框IoU。自蒸馏目标函数定义为：

$$ \mathcal{L}_{SD}(\theta) = -\frac{1}{|S_i|} \sum_{j \in S_i} \sum_{t=1}^{|y'_{i,j}|} \log \pi_\theta(y'_{i,j,t} | y'_{i,j,<t}, x'_i, q'_i) $$

其中 $S_i$ 为提示输入下奖励高于原始输入平均奖励的轨迹子集。该设计使模型在训练时学习“如何看”，在推理时直接“看得准”，实现了感知控制与推理优化的解耦协同。

## 实验评估

实验在V-STAR、VideoMME、Charades-STA等基准上进行，基线覆盖GPT-4o、Qwen2.5-VL-7B及Open-o3-Video等代表性方法，但缺少与最新智能体工具增强方法（如Weaver）的直接对比。

| 基准 | 模型 | Acc/mAM/mIoU |
|---|---|---|
| V-STAR | VISIONCOACH | 61.1 / 34.3 / - |
| V-STAR | Qwen2.5-VL-7B | 33.5 / 19.3 / - |
| VideoMME | VISIONCOACH | 63.3 / - / - |
| Charades-STA | VISIONCOACH | - / - / 42.7 |

VISIONCOACH在V-STAR上较Qwen2.5-VL-7B提升27.6%准确率，在Charades-STA上mIoU达42.7，优于Open-o3-Video的42.5，表明训练时引导对时空定位具有显著增益。

消融实验显示，固定视觉提示（VP-F）导致mAM下降至29.7，而自适应选择（VP-S）结合自蒸馏使mAM回升至31.3。硬样本阈值设为50%时性能最优，25%或75%均导致性能下降，表明过度或不足的提示干预均有害。自蒸馏单独使用会降低接地性能（mAM 31.1→30.4），必须与视觉提示联合使用才能发挥正向作用。

评估边界方面，本文未报告置信区间，且仅在7B模型规模下验证。代码已开源，但VP-SELECTOR的跨骨干泛化性仅在Qwen2.5-VL与GPT-4o上测试，未覆盖更大规模或不同架构模型。

## 关联研究分析

从问题动机看，Open-o3-Video通过RL直接优化时空坐标生成，而本文通过视觉提示引导注意力分布。前者依赖模型内部特征空间的隐式对齐，后者通过输入级显式干预放大证据。差异根源在于对“接地”实现路径的选择：Open-o3-Video假设模型具备足够的特征提取能力，仅需优化输出；本文则认为模型在复杂场景下特征提取本身存在偏差，需从输入端修正。这种差异在长视频任务上可能更为显著，但论文未提供长视频场景下的对比数据。

从方法设计看，CAViAR代表推理时工具调用路线，通过动态裁剪获取证据，而本文主张训练时内化。CAViAR的灵活性可应对任意新场景，但牺牲了推理效率；本文的静态内化提升了效率，但可能限制对未见提示类型的适应。两者在“何时引入感知辅助”上存在根本分歧：CAViAR认为感知是推理的迭代过程，本文认为感知是推理的前置条件。这种分歧反映了领域对“感知-推理耦合程度”的不同理解，尚无定论。

## 总结

VISIONCOACH针对视频推理中时空接地不足导致的幻觉问题，提出训练时视觉提示引导与自蒸馏内化的RL框架。该方法通过VP-SELECTOR实现输入自适应提示选择，利用对象感知奖励强化接地质量，最终在7B模型上实现V-STAR准确率61.1%与Charades-STA mIoU 42.7。其边界在于仅验证了7B规模下的性能，且VP-SELECTOR的泛化性受限于代理推理器的覆盖范围。当视频时长超过10分钟或提示类型超出训练分布时，自蒸馏内化的接地行为是否仍能保持鲁棒性，论文未给出回答。
