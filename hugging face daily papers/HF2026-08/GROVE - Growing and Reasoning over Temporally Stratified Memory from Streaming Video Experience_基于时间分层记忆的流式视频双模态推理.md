# HuggingFace最新推荐论文 ｜GROVE: Growing and Reasoning over Temporally Stratified Memory from Streaming Video Experience ｜基于时间分层记忆的流式视频双模态推理

研究机构：大连理工大学、日本东京大学

论文原文见 [arXiv](https://arxiv.org/abs/2608.02392)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.02392)

> 流式视频助手需同时支持用户查询驱动的回忆与情境驱动的主动干预，但现有记忆系统多依赖单一检索接口，难以兼顾细粒度感知与跨天规律。GROVE 提出一种免训练框架，将视频流因果构建为“时刻-片段-模式”三层时间分层记忆，并为每层绑定规模原生检索技能，使同一记忆结构同时服务于反应式问答与主动辅助。该设计在长程记忆任务上显著优于基线，但在纯实时感知基准上落后于专用优化模型，其优势边界在于记忆深度而非推理速度。

## 研究背景

可穿戴设备持续记录用户第一视角视频，当用户询问“昨天钥匙放哪了”时，系统需从数小时历史中定位证据；当用户即将重复错误时，系统需主动预警。这种双重需求要求记忆不仅可检索，还需具备情境感知能力。流式因果性（Streaming Causality）规定模型在时间 $t$ 仅能访问 $t$ 之前的观测，这一约束使记忆必须在线构建且不可回溯修改，直接决定了系统能否在视频流持续到达时保持可用性。

现有视频记忆系统已解决长视频存储与检索效率问题，如 VAM 采用年龄分层存储，M3-Agent 构建实体中心记忆，但大多保留“查询优先”契约：仅当用户显式提问时才触发检索。主动辅助系统如 Vinci2 和 Eyes Wide Open 虽能基于当前感知触发服务，但其记忆与控制机制分离，未与反应式回忆共享同一接口。核心矛盾在于：反应式问答需要细粒度证据（如物体计数、屏幕文字），而主动辅助需要跨天规律（如重复行为模式），二者对记忆粒度和检索策略的要求存在本质差异。GROVE 的切入点是将时间尺度本身作为记忆分层与检索操作的接口，使同一结构同时满足两种需求。

## 核心方法

### 时间分层记忆构建

流式视频被划分为固定长度窗口，每个窗口经 VLM 调用生成叙事描述与结构化感知注册表（含实体、属性、计数、动作、屏幕文字）。这些观测经因果整合为三层结构：带时间戳的时刻（Moment）、连贯片段（Episode）及跨天模式（Pattern）。设计动机在于解决单一粒度记忆无法同时保留瞬时细节与长程规律的问题——细粒度 Token 压缩会丢失跨天关联，而语义摘要则无法支持精确计数查询。

$$M_t = \text{Consolidate}(M_{t-1}, \text{PerceptualTrace}_t, \text{Caption}_t)$$

该公式表示记忆状态 $M_t$ 由前一状态与当前窗口的感知轨迹和描述因果整合而成，确保记忆在流式到达过程中持续更新且可用。

### 规模原生检索技能

每层记忆绑定特定检索操作：Perception Lookup 定位瞬时观测，Moment Recall 回放活动细节，Episode Replay 重现完整片段，Pattern Traversal 遍历跨天规律。多轮智能体组合这些技能，累积非冗余证据。设计动机在于解决通用向量检索无法区分证据类型的问题——同一查询可能需要秒级细节或天级规律，单一检索操作无法适配。

$$y = \pi(q, M_{\leq t}), \quad s_t = \pi(q^+, M_{\leq t})$$

该公式统一了反应式问答（$q$ 为用户查询）与主动辅助（$q^+$ 为前向请求或空）的推理过程，$s_t$ 为空或锚定于 $\tau \leq t$ 的响应，表明两种模式共享同一记忆访问接口，仅触发信号不同。

## 实验评估

实验覆盖 MM-Lifelong（181.1 小时视频，日/周/月尺度）、EgoServe（3000+ 主动服务实例）、OVO-Bench、StreamingBench 及 ESTP-Bench。基线包括离线 MLLM（GPT-4o）、在线 MLLM（StreamBridge）及记忆代理（ReMA、EgoMemo），但缺失纯 KV 缓存优化类方法（如 StreamingVLM）的直接对比，可能高估记忆架构的相对优势。

| 基准 | 指标 | GROVE | 最强基线 | 差距 |
| :--- | :--- | :--- | :--- | :--- |
| MM-Lifelong | Day | 23.50 | ReMA 16.75 | +6.75 |
| MM-Lifelong | Week | 22.75 | ReMA 18.82 | +3.93 |
| EgoServe | Overall | 12.62 | EgoMemo 8.0 | +4.62 |
| OVO-Bench | Overall | 67.5 | StreamBridge 62.6 | +4.9 |

GROVE 在长程记忆任务上优势显著，但在 StreamingBench 实时理解上（77.0）略低于 StreamBridge（77.3），表明其优势源于记忆深度而非实时推理速度。

| 消融配置 | MM-Lifelong Day | MM-Lifelong Week | EgoServe |
| :--- | :--- | :--- | :--- |
| GROVE | 18.75 | 19.75 | 12.62 |
| w/o Episode | 14.57 | 17.25 | 12.47 |
| w/o Pattern | 19.90 | 13.00 | 11.49 |
| Flat (w/o Hier.) | 14.75 | 15.50 | 11.53 |

移除 Episode 层导致日尺度性能下降 4.18 点，而移除 Pattern 层在日尺度反而提升 1.15 点，但在周尺度骤降 6.75 点，表明跨天模式仅在长程任务中提供净收益。检索技能消融显示，禁用所有检索导致日尺度准确率从 18.75 跌至 7.25，证实记忆结构需配套原生访问接口才能发挥价值。

评估协议存在局限：MM-Lifelong 使用 GPT-5.2 作为推理骨干，而消融实验使用 GPT-5-mini，骨干差异可能混淆结构贡献与模型能力贡献。代码已开源，但 H200 GPU 依赖限制了可复现性。

## 关联研究分析

从问题动机看，GROVE 与 ReMA 均解决长视频记忆管理，但 ReMA 侧重动态记忆更新策略，GROVE 侧重静态时间分层与技能绑定。ReMA 在 MM-Lifelong 月尺度上取得 16.75，低于 GROVE 的 19.98，差异根源在于 ReMA 未显式构建跨天模式层，导致长程规律检索依赖通用搜索而非专用遍历操作。

从方法设计看，GROVE 与 EgoMemo 均支持主动辅助，但 EgoMemo 依赖服务触发协议，GROVE 依赖跨天模式遍历。EgoMemo 在 EgoServe 错误恢复（ER）任务上仅得 1.7，而 GROVE 得 23.8，差距源于 EgoMemo 的记忆未保留细粒度感知轨迹，无法支持基于当前情境的精确证据匹配。GROVE 的规模原生检索是否限制了跨层级联合推理的灵活性，论文未给出回答。

## 总结

GROVE 解决的核心矛盾是单一记忆接口无法同时支持细粒度反应式回忆与跨天主动辅助。其切入点是将时间尺度作为分层与检索的接口，使不同粒度证据通过专用技能访问，而非依赖通用搜索。该框架在 MM-Lifelong 日尺度上比 ReMA 高 6.75 点，在 EgoServe 整体上比 EgoMemo 高 4.62 点，证实了时间分层记忆的有效性。其边界在于 StreamingBench 实时理解上未超越专用优化模型，且消融实验与主实验使用不同推理骨干，结构贡献的归因存在混淆。当推理骨干从 GPT-5-mini 切换至 GPT-5.2 时，日尺度准确率从 18.75 升至 23.50，这一提升中有多少源于记忆结构、多少源于模型能力，论文未提供控制变量实验予以区分。
