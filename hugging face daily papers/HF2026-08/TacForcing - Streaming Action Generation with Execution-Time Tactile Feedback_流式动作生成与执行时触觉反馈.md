# HuggingFace最新推荐论文 ｜TacForcing: Streaming Action Generation with Execution-Time Tactile Feedback ｜流式动作生成与执行时触觉反馈

作者：Jianbo Zhou、Boyuan Zhao、Yuzheng Zhang 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2608.25798)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.25798)

> 接触丰富操作任务要求机器人在执行过程中实时适应不断变化的接触状态，但现有视觉-语言-动作模型在生成完整动作块时，触觉条件往往在执行期间变得过时。本文指出，将固定触觉观测作为整个动作块的条件会导致时序失配，而现有的反应式方法依赖独立的高频控制器，增加了架构与训练复杂度。TacForcing 通过流式动作专家逐步生成动作块，并引入执行感知触觉注意力机制，使触觉反馈仅条件化即将执行的块，从而在不增加额外控制器的情况下融入执行时触觉信息。该方法在仿真与真实世界中均优于强基线，但其流式生成机制对计算延迟的影响及跨任务泛化能力仍需进一步验证。

## 研究背景

当机器人执行精密装配或部件插入等接触丰富任务时，视觉观测往往无法可靠揭示力变化、滑移事件等潜在接触状态，特别是在遮挡条件下。这种感知局限降低了操作的精度与鲁棒性。为弥补这一缺陷，研究者将触觉感知整合到视觉-语言-动作模型中。然而，触觉表征在单个动作块内可能发生显著变化，而视觉表征几乎保持不变。这意味着，将固定触觉观测作为整个动作块的条件，会在触觉输入与执行期间遇到的接触状态之间产生日益增长的时序失配。

现有反应式方法通过专门的高频触觉路径缓解这种失配，但这些策略特定的组件增加了架构和训练复杂度。TacForcing 的切入点在于，通过流式动作生成框架，在执行过程中逐步生成动作块，并利用新获取的触觉反馈来细化未完成块的状态。这种方法避免了独立反应式控制器的复杂性，同时解决了固定触觉条件导致的时序失配问题。

## 核心方法

### 流匹配与块级流调度

流匹配学习一个条件速度场，将高斯先验样本传输到数据分布。给定条件 $y$，采样 $x_1 \sim p_{\text{data}}(\cdot | y)$，$x_0 \sim \mathcal{N}(0, I)$，$\tau \sim \mathcal{U}(0, 1)$，定义线性插值路径 $x_\tau = (1-\tau)x_0 + \tau x_1$ 和目标速度 $u^* = x_1 - x_0$。模型通过最小化 $\mathcal{L}_{\text{FM}} = \mathbb{E}_{y, x_1, x_0, \tau} \| v_\theta(x_\tau, \tau, y) - u^* \|^2$ 进行训练。在推理时，从 $\tau=0$ 到 $\tau=1$ 积分学习到的速度场，将高斯先验样本转换为条件数据分布样本。

### 流式动作专家与执行感知触觉注意力

传统流匹配动作专家使用共享的流时间同步生成整个动作块，导致执行期间获取的触觉反馈无法条件化剩余动作。TacForcing 引入流式动作专家，将动作块划分为 $K$ 个连续块，每块包含 $B$ 个动作。块 $k$ 的流时间 $\lambda_k(n)$ 在采样步 $n_k = kS$ 达到 1，实现顺序执行。执行感知触觉注意力（EATA）通过加性注意力掩码 $M_i^{(k)} = \begin{cases} 0, & b(i) = k \\ -\infty, & \text{otherwise} \end{cases}$ 限制触觉条件仅作用于即将执行的块 $A_t^{(k)}$，避免后续块受到过时触觉反馈的影响。

## 实验评估

实验在 UniVTAC 仿真基准和三个真实世界接触丰富任务上进行。基线包括无触觉的 $\pi_{0.5}$、触觉条件的 UniVTAC-ACT 和 FTP-1，以及触觉反应式的 RDP。TacForcing 在仿真中取得 65% 的平均成功率，比 $\pi_{0.5}$ 高 14 个百分点，比 RDP 高 23 个百分点。在真实世界中，TacForcing 取得 69% 的平均成功率，比 FTP-1 高 17 个百分点，比 GR00T N1.7 高 27 个百分点，比 $\pi_{0.5}$ 高 42 个百分点。

| 方法 | 仿真平均成功率 (%) | 真实世界平均成功率 (%) |
| :--- | :--- | :--- |
| TacForcing | 65 | 69 |
| $\pi_{0.5}$ | 51 | 27 |
| RDP | 42 | - |
| FTP-1 | - | 52 |

消融实验显示，固定触觉条件导致仿真成功率从 43% 降至 42%，真实世界从 42% 降至 31%。引入流式触觉更新后，仿真成功率升至 51%，真实世界升至 48%。加入 EATA 后，仿真成功率进一步升至 60%，真实世界升至 69%。这表明执行时触觉更新和 EATA 均对性能提升有显著贡献。

评估边界方面，真实世界实验仅进行 16 次独立试验，统计显著性可能不足。此外，论文未报告计算延迟和 GPU 资源使用情况，流式生成机制对实时性的影响未明确量化。代码开源状态未明确说明，可复现性存在不确定性。

## 关联研究分析

从问题动机看，TacForcing 与 RDP 等反应式方法都旨在解决触觉反馈的时序失配问题，但 RDP 依赖慢-快层级架构，而 TacForcing 通过流式生成在单一模型内实现触觉更新。这种差异源于 TacForcing 对计算复杂度的权衡：流式生成避免了独立控制器的训练开销，但可能增加推理延迟。从方法设计看，TacForcing 借鉴了 Diffusion Forcing 的位置依赖调度思想，但将其应用于触觉条件化，而非噪声水平分配。这种设计选择使得触觉反馈能够与块执行对齐，但可能限制了模型对长期触觉趋势的学习能力，因为 EATA 仅允许当前触觉条件化下一块。

## 总结

TacForcing 解决了接触丰富任务中固定触觉条件导致的时序失配问题，通过流式动作专家逐步生成动作块，并利用执行感知触觉注意力机制限制触觉条件化范围。该方法在仿真和真实世界中均优于强基线，仿真成功率 65%，真实世界成功率 69%。其边界在于真实世界试验次数较少，统计显著性可能不足，且流式生成机制对计算延迟的影响未明确量化。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
