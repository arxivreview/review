# HuggingFace最新推荐论文 ｜ARCHead: Activation-Metric Residual Correction for Large Language Model Output Heads ｜激活度量残差修正的大语言模型输出头压缩

作者：Şuayp Talha Kocabay、Talha Rüzgar Akkuş、Kamer Ali Yuksel

论文原文见 [arXiv](https://arxiv.org/abs/2608.02703)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.02703)

> 大语言模型（LLM）部署中，Transformer块权重常被量化至4-bit，但输出头（LM-head）往往保留为BF16，成为内存瓶颈。现有后训练量化（PTQ）方法直接量化该头时，因忽略激活分布的各向异性，导致词表对数概率（logit）分布严重畸变。本文提出ARCHead，通过激活度量变换下的低秩残差修正，在保持精度接近无损的同时，将输出头持久存储压缩3.7–3.9倍。该方法填补了块量化后输出头压缩的空白，但其对校准数据分布的依赖及跨架构泛化性仍存疑。

## 研究背景

Transformer块内的量化误差可被后续层归一化或残差连接部分吸收，但输出头误差直接作用于Softmax函数，无缓冲机制。这种结构差异使得输出头对量化噪声极度敏感，尤其是大词表模型中，微小误差可能改变高频token的排名。为量化这种敏感性，需引入激活协方差矩阵$C = H^TH/N$，其中$H$为校准隐藏状态，该矩阵捕捉了隐藏状态在特征空间中的分布几何，是评估输出头误差对最终logit影响的关键权重。

现有PTQ方法如GPTQ和AWQ主要聚焦于Transformer块，其误差补偿机制基于权重空间或激活幅度的局部优化。然而，当块权重被量化后，输出头若仍采用朴素低比特量化（如INT4），其权重空间重构误差最小化目标与激活加权误差最小化目标存在本质偏差。这种偏差在词表规模超过10万时尤为显著，导致相对困惑度（Relative PPL）从1.000飙升至1.15以上。ARCHead的切入点在于，将输出头压缩问题重构为激活度量下的低秩近似问题，而非传统的权重空间重构，从而在极低存储预算下维持logit分布的保真度。

## 核心方法

### 激活度量目标函数

传统量化方法最小化权重空间Frobenius范数误差，即假设$C=I$，忽略了激活分布的各向异性。ARCHead引入阻尼激活协方差矩阵$C_\lambda = C + \lambda \bar{c}I$，并定义度量变换$T_p = Q\Lambda^p Q^\top$，其中$Q, \Lambda$为$C_\lambda$的特征分解。该设计动机在于，通过$T_p$将残差误差投影到激活能量主导的方向上，使得修正容量优先分配对logit影响最大的维度。

$$
\min_{A,B} \| (E - AB) T_p \|_F^2
$$

该公式表明，ARCHead在变换后的空间中最小化残差$E$与低秩修正$AB$的误差，等价于在原始空间中按激活能量加权最小化logit误差。当$p=0.75$时，该目标函数平衡了高频激活方向与低频方向的误差贡献，避免了$p=2$时过度强调主导方向导致的细节丢失。

### 低秩核心与残差修正

ARCHead首先构建量化核心$W_d = Q_5(A_c)Q_8(B_c) + Q_{SC4}(W - A_cB_c)$，其中$A_cB_c$为秩-$r_c$近似，$Q_{SC4}$为组INT4量化。随后，计算核心残差$E = W - W_d$，并在激活度量下执行截断SVD：$ET_p \approx U_{r_r}\Sigma_{r_r}V_{r_r}^\top$。修正因子$A_w = U_{r_r}\Sigma_{r_r}$和$B_w = V_{r_r}^\top T_p^{-1}$分别以行INT8和组INT8量化存储。

$$
\hat{Y} = H W_d^\top + (H B_w^\top) A_w^\top
$$

该推理公式将计算分解为低秩核心部分和修正部分，避免了密集BF16矩阵的存储。设计动机在于，低秩核心捕捉权重矩阵的主要结构，而激活度量修正专门补偿核心量化后在激活敏感方向上的剩余误差。这种解耦使得修正秩$r_r$可以远小于核心秩$r_c$，从而在极低存储下实现高精度。

## 实验评估

实验在Qwen3-8B-Base、Gemma-4-E4B和VibeThinker-3B上进行，校准数据来自WikiText-103训练集，评估集为16,384个测试token。基线包括BF16、行INT8、组INT4、SVD8+INT4及GPTQ风格INT4。ARCHead在Qwen3-8B-Base上实现25.6%的BF16存储占比，相对PPL为1.007，而存储匹配的组INT4为1.151，GPTQ-INT4为1.0104（2K校准）。

| 方法 | 存储占比 | 相对PPL | $\Delta$CE |
| :--- | :--- | :--- | :--- |
| Dense BF16 | 1.000 | 1.000 | 0.000 |
| Group INT4 | 0.266 | 1.151 | +0.140 |
| GPTQ-head INT4 | 0.258 | 1.0104 | — |
| ARCHead | 0.256 | 1.007 | +0.007 |

消融实验显示，仅使用量化核心（无修正）时相对PPL为1.134，加入秩-6激活度量修正后降至1.007，证明修正项是精度保持的关键。在AWQ和bitsandbytes NF4混合量化场景中，ARCHead替换BF16头仅增加0.006–0.007的交叉熵，且生成吞吐量变化小于2%。

评估边界方面，论文仅验证了三个下游任务（HellaSwag, TruthfulQA, WinoGrande）作为健全性检查，未证明所有能力保持。校准敏感性扫描显示，4,096至65,536 token范围内相对PPL稳定在1.007左右，表明对校准数据量不敏感。代码已开源，但缺乏跨语言、长上下文及不同硬件后端的全面测试。

## 关联研究分析

从问题动机看，ARCHead与GPTQ的核心差异在于误差度量空间。GPTQ基于二阶Hessian信息在权重空间进行逐列误差补偿，适用于Transformer块内部，其假设误差可被后续层吸收。而ARCHead针对输出头无缓冲的特性，采用激活协方差加权误差，直接优化logit分布保真度。这一差异源于任务特性：输出头是模型与词表的唯一接口，其误差无法被后续层修正，因此必须从输入分布（激活）出发定义优化目标。

从方法设计看，ARCHead与AQLM（Additive Quantization of Language Models）同属低秩/向量量化范畴，但AQLM通过多码本加性量化突破标量极限，适用于全模型极低比特压缩。ARCHead则聚焦于单一输出头的混合精度结构（低秩核心+INT4残差+INT8修正），其创新在于激活度量变换下的条件最优性证明。AQLM未针对输出头的各向异性激活分布进行专门优化，因此在输出头压缩场景下，ARCHead的激活感知设计更具针对性。

## 总结

ARCHead解决了块量化后输出头保留BF16导致的内存瓶颈与精度损失矛盾。其切入点在于识别输出头误差直达Softmax的结构特性，通过激活度量变换将残差修正问题转化为条件最优的低秩近似。方法上，结合量化核心与激活加权低秩修正，在Qwen3-8B-Base上实现25.6%存储占比与1.007相对PPL，显著优于朴素INT4的1.151。边界在于，其条件最优性仅适用于未量化修正因子，且实验未覆盖长上下文、多语言及不同硬件后端。当词表规模进一步扩大或激活分布出现极端各向异性时，固定$p=0.75$的度量变换是否仍能保持最优性，论文未给出回答。
