## 研究背景

当智能体在ALFWorld等具身环境中执行任务时，每次交互产生的轨迹被存储为独立记忆条目并赋予效用值。随着历史交互增加，这些轨迹索引效用变量的维度线性增长，导致有限的任务级奖励被分散到不断扩大的状态空间中，形成普遍的效用冷启动与低反馈密度。这种反馈稀释不仅降低了学习效率，更因轨迹级奖励被共同分配给共检索记忆，使弱相关或过时经验在成功情境中接收误导性正向更新，构成记忆-奖励陷阱（Memory-Reward Trap, MRT）。

基于学习的智能体记忆路线试图通过强化学习优化记忆构建、检索与更新策略，以超越启发式规则。MemRL等近期工作采用非参数运行时强化学习，为每条存储轨迹维护独立效用，但未能解决效用空间维度增长带来的根本矛盾：更强的探索虽能缓解冷启动，却同时扩大了暴露于错误奖励传播的支持集。RoMeRL的切入点在于改变记忆强化学习所操作的状态本身，而非在无限维空间中更激进地探索，从而在反馈覆盖与MRT风险之间建立新的平衡。

## 核心方法

### 轨迹索引效用与MRT形式化

标准记忆强化学习框架中，每条轨迹 $m_i$ 对应独立效用 $Q_i$，通过任务级奖励 $r_t$ 更新：$Q_{i,t+1} = Q_{i,t} + \alpha \mathbb{I}[m_i \in S_t](r_t - Q_{i,t})$。该公式的物理含义是：仅当记忆被检索时，其效用才向当前任务结果靠拢。然而，由于奖励由完整检索上下文 $S_t$ 共同决定，$Q_i$ 估计的是观测效用 $\mu_i = E[R_t | m_i \in S_t]$ 而非边际贡献 $\theta_i$。当 $\theta_i \le 0$ 但 $\mu_i - v_0^i > 0$ 时，记忆陷入MRT，即无正向边际贡献却因检索选择偏差获得正向信号。

### 降阶记忆状态因子化

RoMeRL将每个任务的效用空间替换为固定四维状态，由结果极性（正/负）与记忆动态（巩固/适应）的笛卡尔积定义：$Z_{g,t} = [z_{+,C}, z_{+,A}, z_{-,C}, z_{-,A}]$。该公式表示四个语义坐标分别存储正巩固、正适应、负巩固、负适应轨迹的代表及其效用。新轨迹不新增变量，而是通过在线保留、提升或替换更新坐标内容，使反馈集中在有界支持集上。设计动机在于：固定维度 $d=4$ 使每个坐标平均接收 $\bar{n}_{fact} = \frac{N_t}{4}\bar{n}_{full}$ 的反馈信号，将效用估计方差从 $O(\frac{\sigma^2 N_t}{kT})$ 降至 $O(\frac{4\sigma^2}{kT})$，同时通过替换机制限制错误坐标的稳态占比不超过 $\frac{\gamma}{\gamma+\lambda}$。

## 实验评估

实验在ALFWorld与LifelongAgentBench的OS/DB任务上进行，基线覆盖RAG、Mem0、MemP、MemRL及Pass@k，但缺失MAGMA等结构化图谱方法。RoMeRL在Overall平均成功率上达到0.862，较最强基线MemRL的0.830提升3.2个百分点。

| 方法 | OS Last/CSR | DB Last/CSR | ALFWorld Overall | LLM Calls | Memory Size |
|---|---|---|---|---|---|
| MemRL | 0.808/0.820 | 0.632/0.934 | 0.830 | 570K | 45K |
| RoMeRL | 0.824/0.838 | 0.680/0.952 | 0.862 | 450K | 7K |

消融实验显示，移除负巩固坐标（NCC）同时降低Last-Epoch SR与CSR，其在OS/DB任务中分别占27.14%/42.78%的坐标占用率，表明巩固负证据对当前性能与累计覆盖均有支撑。移除正适应坐标（PAC）主要降低Last-Epoch SR，其占用率仅8.21%/5.05%，但提供了稀疏的失败到成功转换信号。MRT压力测试中，RoMeRL将正噪声更新从MemRL+UCB的7.2降至2.4，最终噪声比从1.20%降至0.15%，同时保持82.0%的最高成功率。

评估边界方面，论文未报告置信区间，且缺乏与结构化图谱方法的对比。代码已开源，但超参数与GPU配置未在正文中详述。跨模型迁移实验表明，冻结记忆状态可提升GPT-5.4-mini与Gemini-3.5-flash在OS任务上的得分，验证了因子化状态携带的跨骨干程序性信息。

## 关联研究分析

从问题动机看，RoMeRL与MemRL共享运行时记忆优化的目标，但MemRL在无限维空间中探索导致MRT加剧，而RoMeRL通过降阶将探索限制在有界支持集内。这一差异源于对“反馈覆盖”与“错误传播”权衡的不同处理：MemRL假设更广覆盖必然带来更好估计，RoMeRL则指出覆盖扩大同时扩大了错误奖励的暴露面。从方法设计看，RoMeRL的固定四维坐标与MAGMA的多图谱结构形成对比，前者以极简结构换取效率与鲁棒性，后者以复杂结构换取多跳推理能力。RoMeRL未探索维度自适应机制，固定四维是否足以应对不同任务复杂度的需求，论文未给出回答。

## 总结

RoMeRL针对轨迹索引效用空间增长导致的反馈稀释与MRT矛盾，通过固定维度语义坐标状态实现反馈集中与错误传播限制。该方法在不更新LLM参数的前提下，将Cold-Q比率降低80.0%，反馈密度提升6.0倍，同时减少84.4%的记忆规模与21.1%的LLM调用。其边界在于固定四维结构对复杂多模态任务的表达能力有限，且缺乏与结构化图谱方法的直接对比。当任务涉及多模态输入或高维关系推理时，固定四维坐标是否仍能维持反馈集中优势，论文未给出回答。
