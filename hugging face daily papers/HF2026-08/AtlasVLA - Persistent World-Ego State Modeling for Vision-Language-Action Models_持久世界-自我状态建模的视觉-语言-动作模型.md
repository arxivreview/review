研究机构：中国科学院、中国科学院大学

作者：Guiyu Zhao、Longteng Guo、Yanghong Mei 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2608.06729)

> 视觉-语言-动作模型（VLA）在单目腕部相机约束下，因瞬时视场受限导致空间感知遗忘，且缺乏历史上下文引发长程任务进度丢失。现有方法依赖多视角输入或纯端到端映射，无法在严格单目条件下维持全局空间一致性与任务意图连贯性。本文提出 AtlasVLA，通过构建 4D 持久世界状态记忆与自我工作记忆的双记忆架构，将瞬时 2D 观测转化为全局 3D 潜空间状态，并显式追踪任务进度。该框架在单目设置下实现了 LIBERO 97.6% 与 RLBench 70.8% 的成功率，但其对深度估计精度的强依赖及记忆更新机制的计算开销，限制了其在动态剧烈变化场景中的实时性表现。

## 研究背景

当机器人仅配备腕部相机执行复杂操作时，瞬时视场（Field of View, FoV）无法覆盖整个工作空间，导致关键物体一旦移出视野即被“遗忘”，这种现象称为感知遗忘。感知遗忘使得模型无法定位视野外的目标物体，而解决此问题通常需要维护一个持久的内部世界状态。然而，现有 VLA 模型多采用反应式范式，直接将当前观测映射为动作，缺乏对历史空间信息的累积与整合，导致在长程任务中既丢失空间上下文，又遗忘已完成的子任务进度，引发意图漂移与执行错误。

VLA 领域的核心挑战在于如何在有限感知条件下实现鲁棒的长程操作。主流路线如 OpenVLA 与 π0 依赖多视角输入或大规模预训练数据来弥补单视角的不足，但在严格单目约束下，这些方法因缺乏显式状态记忆而性能显著下降。MemoryVLA 等引入视觉检索机制的方法虽改善了时序推理，但未能有效分离空间几何信息与任务语义进度。本文的切入点在于，将空间感知与任务追踪解耦，通过显式构建持久世界状态与自我工作记忆，使模型在单目条件下具备主动式空间推理与长程意图保持能力。

## 核心方法

### 方法参照系

标准 VLA 流程将当前观测 $o_t$、指令 $l$ 与本体状态 $s_t$ 输入 VLM 骨干，通过离散 Token 或连续动作头生成动作序列。本文的关键差异在于摒弃了仅依赖瞬时观测的反应式假设，引入显式状态记忆模块，将输入从 $o_t$ 扩展为包含持久世界状态 $M_t^{world}$ 与自我工作状态 $M_t^{ego}$ 的联合上下文，从而支持长程时序一致性与空间全局感知。

### 4D 持久世界状态记忆

为解决腕部相机视场受限导致的空间盲区，本文在 VLM 骨干前引入持久世界状态记忆模块。该模块利用 Depth Anything v3 估计深度，并通过空间反投影将 2D 视觉 Token 提升至 3D 潜空间，形成瞬时世界状态 $m_t$。为消除空间混叠与时序退化，引入 3D 空间坐标与时间戳的可学习位置编码：

$$ \tilde{m}_t = m_t + E_{spatial}(P_t) + E_{temporal}(t) $$

其中 $E_{spatial}$ 与 $E_{temporal}$ 为 MLP 参数化的编码函数。该设计将孤立观测转化为统一的 4D 表示，使模型能够区分不同时刻同一空间位置的特征，从而在物体移出视野后仍能通过历史记忆定位其空间位置。

### 自我工作记忆与双路径动作生成

为防止长程任务中的意图漂移，本文设计自我工作记忆模块，通过可学习意图查询 $Q_{ego}$ 从 VLM 中提取任务进度信息，并采用冗余感知整合机制更新记忆库 $M_{ego}$：

$$ M_{ego}^t = Cons \left( M_{ego}^{t-1} \cup \{Z_{ego}^t + E_{temporal}(t)\} \right) $$

其中 $Cons(\cdot)$ 合并时空相邻且语义相似的意图 Token。在动作生成阶段，采用解耦的 DiT 架构，噪声动作 Token 首先通过自我工作注意力层获取任务进度上下文 $C_{ego}^t$，再通过世界状态注意力层获取几何接地上下文 $C_{world}^t$。这种双路径条件化机制确保了动作生成同时具备任务语义连贯性与空间几何准确性，解决了纯端到端模型在长程任务中因缺乏历史上下文而导致的子任务重复或遗漏问题。

## 实验评估

实验在 LIBERO 与 RLBench 基准上进行，对比方法涵盖 OpenVLA、π0、MemoryVLA 等主流 VLA 模型，但缺失 HiMoE-VLA 等最新 MoE 架构基线。在 LIBERO 基准上，AtlasVLA 在单目设置下取得 97.6% 的平均成功率，显著优于多视角基线 π0（88.1%）与单目基线 MemoryVLA（94.0%）。在 RLBench 基准上，AtlasVLA 取得 70.8% 的成功率，较单目基线 MemoryVLA（55.0%）提升 15.8 个百分点，验证了双记忆架构在复杂操作任务中的有效性。

| 方法 | 相机设置 | LIBERO Avg (%) | RLBench Avg (%) |
| :--- | :--- | :--- | :--- |
| OpenVLA | 3rd | 75.9 | 23.3 |
| π0 | 3rd | 88.1 | - |
| MemoryVLA | 3rd | 96.5 | 63.3 |
| MemoryVLA | wrist | 94.0 | 55.0 |
| AtlasVLA | wrist | 97.6 | 70.8 |

消融实验未单独报告，但论文指出持久世界状态记忆消除了对第三方视角的依赖，而自我工作记忆有效防止了意图漂移。在 LIBERO-Long 子集上，AtlasVLA 取得 94.6% 的成功率，较 MemoryVLA 提升 7.0 个百分点，表明双记忆机制在长程任务中的累积优势。然而，论文未提供深度估计误差对世界状态更新影响的消融数据，也未报告不同滑动窗口大小 $W$ 对性能的影响，限制了对其记忆更新机制鲁棒性的深入理解。

评估协议基于 50 次试验平均，但未报告置信区间，且未包含计算效率指标。代码未公开，超参数细节有限，仅提及使用 8 张 A100 GPU 训练，DiT 动作专家约 300M 参数。评估边界受限于静态或慢速动态场景，未测试快速运动导致的深度估计失效情况，也未评估记忆模块在极端遮挡下的恢复能力。

## 关联研究分析

从问题动机看，AtlasVLA 与 MemoryVLA 均旨在解决长程任务中的时序一致性问题，但 MemoryVLA 依赖视觉检索机制，将历史帧作为检索库，而 AtlasVLA 通过显式 4D 世界状态建模，将空间几何信息与任务语义解耦。这一差异源于任务特性：MemoryVLA 假设历史帧包含足够空间信息，而 AtlasVLA 针对单目视场受限场景，需主动重建全局空间结构。查询侧增强在数据充足时是否仍有增益，论文未给出回答，但 AtlasVLA 在单目约束下的优势表明，显式空间建模比被动视觉检索更适应低信息密度场景。

从方法设计看，AtlasVLA 与 π0 共享 DiT 动作头，但 π0 依赖多视角输入提供全局上下文，而 AtlasVLA 通过持久世界状态记忆在单目条件下实现类似效果。这一差异反映了感知输入与状态记忆的权衡：π0 假设多视角输入可替代显式记忆，而 AtlasVLA 证明在单目约束下，显式记忆是维持空间一致性的必要组件。世界状态更新机制的计算开销是否抵消了单目部署的硬件简化收益，论文未提供实时性对比数据，限制了其在资源受限场景中的适用性评估。

## 总结

AtlasVLA 针对单目 VLA 在长程任务中因感知遗忘与意图漂移导致的执行失败，通过解耦空间几何与任务语义，构建了 4D 持久世界状态与自我工作记忆的双记忆架构。该框架在 LIBERO 单目设置下取得 97.6% 成功率，较多视角基线 π0 提升 9.5 个百分点，证明了显式状态记忆在低信息密度感知条件下的有效性。然而，论文未报告深度估计误差对世界状态更新的影响，也未评估记忆模块在快速动态场景中的实时性，其性能优势可能部分依赖于 Depth Anything v3 在静态场景中的高精度。当腕部相机经历剧烈运动导致深度估计失效时，持久世界状态记忆的更新机制是否仍能维持空间一致性，论文未给出回答。
