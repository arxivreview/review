# HuggingFace最新推荐论文 ｜DFM Mimir v1: An Open HRM Delivering Frontier Performance at 1B Parameters Using Only Permissible Post-Training Data ｜合规约束下的分层推理模型构建

研究机构：丹麦奥胡斯大学

作者：Peter Schneider-Kamp、Jacob Nielsen、Gianluca Barmina 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2608.13517)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.13517)

> 在数据许可合规性约束下，构建高性能低资源语言大语言模型（LLM）面临高质量许可数据稀缺与从头训练算力成本的双重壁垒。现有全开源模型因依赖非许可互联网数据或采用持续预训练（CPT）策略，难以在保持数据伦理合规的同时实现从底层架构到上层能力的完全独立复现。本文切入点在于利用合成“移植数据集”替代非许可数据，并采用分层推理模型（HRM）架构从头训练1B参数模型，以验证合规数据在低算力下的性能上限。该工作证明了数据合规性与前沿性能可兼得，但合成数据的审计标准与跨语言泛化能力仍存疑。

## 研究背景

当模型训练需严格遵循数据许可协议时，传统依赖大规模非许可互联网语料的预训练路径失效，迫使研究者转向许可数据池。然而，低资源语言（如丹麦语）的许可高质量文本规模有限，直接从头训练易陷入数据饥饿，而持续预训练（CPT）虽能复用基座模型，却受限于基座模型本身的数据污染风险与架构锁定。分层推理模型（HRM）通过引入层级化注意力机制，在有限参数下提升推理深度，为低算力场景下的模型构建提供了架构基础。

主流全开源路线如 OLMo 和 Instella 确立了数据与代码透明的标准，但其性能差距主要源于缺乏海量私有数据及复杂后训练流水线。针对数据许可矛盾，现有方案多采用静态过滤或简单混合，未能系统解决非许可数据替换后的性能衰减问题。本文基于丹麦基础模型（DFM）项目需求，提出在 HRM 架构下，通过合成数据策略替代非许可源，并在消费级数据中心硬件上完成从头训练，旨在构建一个完全合规且具备竞争力的 1B 参数基座模型。

## 核心方法

### 分层推理架构参照

HRM 架构通过交替执行高层（H）与低层（L）推理循环，在固定参数预算下扩展有效推理深度。标准 Transformer 依赖单一注意力层堆叠，而 HRM 引入截断反向传播（Truncated Backpropagation）机制，限制梯度回传步数以平衡计算成本与收敛稳定性。本文采用 2 个 H 循环与 3 个 L 循环配置，隐藏层维度设为 1,536，注意力头数为 12，前馈扩展因子为 4。该架构的关键差异在于其层级化信息流动方式，允许模型在低层捕获局部语义，在高层整合全局推理，从而在 1B 参数规模下逼近更大模型的推理能力。

### 合成移植数据策略

针对非许可数据替换，本文提出“合成+审计”动态生成机制。设计动机在于静态过滤无法解决数据源本身的许可合规性，且直接删除非许可数据会导致任务多样性丢失。具体做法是利用 Gemma4 31B 模型，将高质量英语与丹麦语文本语料转化为填空、去噪、重排序及续写任务，生成合成数据后通过质量审计筛选。合成数据的效用可形式化为：

$$
U_{synth} = \sum_{i \in \mathcal{D}_{synth}} \alpha_i \cdot \mathbb{1}[\text{Audit}(x_i) > \tau]
$$

其中 $\mathcal{D}_{synth}$ 为合成数据集，$\alpha_i$ 为数据权重，$\tau$ 为审计阈值。该策略将 70 个原非许可分类任务重构为开放式生成任务，使模型从“选项判别”转向“答案生成”，对齐了 GSM8K、MATH 等精确匹配评估协议，解决了传统多选数据在生成式评估中的性能瓶颈。

### 低资源语言数据增强

针对丹麦语数据稀缺，本文采用高重复采样与双语混合策略。设计动机在于低资源语言许可数据量不足，直接训练易过拟合。具体做法是对 Lærebogen 数据集进行 4 倍重复采样，将基础 2.08B tokens 扩充至 8.32B，并对 8 个小规模丹麦语数据集进行 10 倍重复。同时，语料中 6.54% 为丹麦-英语双语数据，通过机器翻译与合成转换任务配对。数据混合比例可表示为：

$$
\mathcal{D}_{total} = 0.6862\mathcal{D}_{en} + 0.2474\mathcal{D}_{da} + 0.0654\mathcal{D}_{da+en} + 0.0020\mathcal{D}_{other}
$$

该策略通过人为增加低资源语言数据密度，确保模型在丹麦语任务上获得充分曝光，同时利用英语数据维持通用能力，避免了 CPT 策略中对基座模型数据污染的依赖。

## 实验评估

实验在 20 个基准上评估，涵盖英语、数学代码及丹麦语任务。基线覆盖 1B 至 9B 参数模型，包括 HRM-Text、Qwen 3.5、Gemma 3/4 及 OLMo 2，但未包含 GPT-4 等专有模型对比，限制了绝对性能上限的评估。

| 模型 | English Avg | Math & Code Avg | Danish Avg |
| :--- | :--- | :--- | :--- |
| Mimir 1B | 69.0 | 64.1 | 56.8 |
| HRM-Text 1B | 66.1 | 46.9 | 21.7 |
| Qwen 3.5 0.8B | 50.5 | 38.6 | 34.2 |
| SmolLM3 3B | 63.1 | 67.9 | 31.7 |
| Qwen 3.5 4B | 69.3 | 65.0 | 49.2 |

Mimir 1B 在英语基准上超越同规模模型，仅比 Qwen 3.5 4B 低 0.3 分；在丹麦语基准上大幅领先，较 HRM-Text 1B 提升 35.1 分，验证了合成数据与高重复采样策略的有效性。

消融分析显示，数据形式转换对性能影响显著。将多选任务重构为开放式生成后，Mimir 在 GSM8K 上达到 89.9，而 HRM-Text 1B 仅为 84.8，HumanEval 上 Mimir 为 56.7，HRM-Text 为 0.0。这一巨大差距表明，数据任务形式与评估协议的匹配度比数据量本身更关键。此外，丹麦语数据 4 倍重复采样使 Lærebogen 成为第二大语料来源，其边际收益体现在 DaLA 和 GEC 任务上，Mimir 分别达到 67.4 和 96.1，远超基线。

评估协议采用温度 0 贪心解码，丹麦语任务为 0-shot，英语部分任务使用 few-shot。代码与模型权重已开源，训练使用 8 块 NVIDIA B200 GPU，耗时 3 周，步长 1.65M。未报告置信区间，且合成数据审计阈值 $\tau$ 的具体设定未公开，限制了结果的可复现性细节。

## 关联研究分析

从数据合规性处理看，本文与 Kaiyuan-2B 的分位数基准测试形成互补。Kaiyuan-2B 关注数据质量与性能的非单调关系，通过参考模型实证评估数据效用；本文则聚焦数据许可合规性，通过合成替代解决伦理约束。两者均放弃了静态评分的简洁性，但本文的“合成+审计”策略更侧重于数据源替换而非数据筛选，其有效性依赖于合成模型（Gemma4 31B）的质量上限，这在低资源语言上可能引入系统性偏差。

从架构选择看，本文采用 HRM 架构从头训练，而 OLMo 和 Instella 多基于标准 Transformer 或 CPT 策略。HRM 的层级化推理在 1B 参数下提供了更高的推理深度，但截断反向传播限制了长程依赖的捕获。与 CPT 策略相比，从头训练避免了基座模型的数据污染，但需要更多算力。本文在 8 块 B200 GPU 上 3 周完成训练，证明了 HRM 架构在低算力下的可行性，但相比 CPT 的“低成本”优势，从头训练的算力门槛仍较高，这在更小规模实验室中可能不可行。

## 总结

本文核心矛盾在于数据许可合规性与模型性能之间的冲突，切入点是通过合成移植数据替代非许可源，并利用 HRM 架构在低算力下从头训练。方法上，通过“合成+审计”生成合规数据，结合高重复采样增强低资源语言，实现了完全合规的 1B 模型构建。实验证明 Mimir 1B 在丹麦语基准上达到 56.8，较 HRM-Text 1B 提升 35.1 分，英语基准上仅比 Qwen 3.5 4B 低 0.3 分。边界在于合成数据审计标准未公开，且 HRM 架构的截断反向传播可能限制长程推理能力。当合成模型质量提升时，移植数据的性能上限是否随之线性增长，论文未给出回答。
