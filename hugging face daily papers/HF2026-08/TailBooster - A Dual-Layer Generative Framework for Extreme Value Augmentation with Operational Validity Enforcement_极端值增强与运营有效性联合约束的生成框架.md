> 航空运营中的极端延误与异常飞行时间具有级联破坏性，但历史数据中此类事件极度稀疏，导致机器学习模型在尾部区域缺乏训练信号。现有生成模型虽能复现整体分布，却系统性忽略分布尾部，且无法保证生成记录符合物理运营逻辑（如短飞行时间对应长距离）。TailBooster 通过 IQR 统计层提取极端子集训练专用生成器，并引入自编码器重构误差作为数据驱动的运营有效性过滤器，解决了混合类型表格数据中尾部稀疏与逻辑一致性缺失的双重难题。该框架在极端值预测任务上显著降低了误差，但其依赖历史数据构建运营包络，限制了在无先验数据场景下的泛化能力。

## 研究背景

当预测模型面对航空极端事件时，其训练集往往由大量正常运营记录主导，而极端延误或异常飞行时间仅占极小比例。这种数据不平衡导致模型在分布尾部缺乏足够的梯度信号，使得预测结果在正常区间表现良好，却在关键极端值上严重失效。解决此问题的核心在于合成数据增强，即通过生成模型补充尾部样本。然而，生成模型本身存在“尾部盲区”：其训练目标（如 ELBO 或对抗损失）优先拟合高密度区域，导致生成样本在统计上逼真但在动态结构上失真，尤其是无法捕捉罕见但高影响的极端模式。

时序生成领域的主流路线已从早期的 GAN 和 VAE 转向扩散模型，后者凭借多步去噪机制提升了训练稳定性与样本多样性。然而，这些方法主要面向连续序列数据，对于包含类别、离散数值及日期特征的混合类型表格数据，其适用性受限。更关键的是，通用生成模型缺乏对领域特定约束的感知，可能生成运营上不可行的记录，例如将短飞行时间与长航程距离配对。现有基于极端值理论（EVT）的方法虽能建模尾部，但多局限于连续单变量或同构特征空间，未扩展至航空数据特有的混合类型结构。条件生成虽能处理混合类型，但仅在采样时生效，无法弥补训练阶段尾部信号的缺失。因此，如何在混合类型表格数据中同时解决尾部稀疏性与运营逻辑一致性，成为该领域亟待突破的瓶颈。

## 核心方法

### 方法参照系

本文问题可置于变分自编码器（VAE）生成表格数据的通用流程中，其标准做法是训练单一模型以最大化证据下界（ELBO），从而学习数据分布。本文的关键差异在于，单一模型无法同时兼顾全量数据的统计特性与极端子集的尾部细节，且缺乏对生成样本物理可行性的后置校验机制。

### 统计层极端子集提取

针对生成模型在训练阶段对分布尾部信号忽略的问题，TailBooster 在生成前引入统计层异常检测。该层利用四分位距（IQR）非参数地提取目标特征的极端子集，作为专用生成器的训练信号。具体而言，对于目标特征 $f_j$，计算其第一四分位数 $Q_1^{(j)}$、第三四分位数 $Q_3^{(j)}$ 及 IQR $IQR^{(j)} = Q_3^{(j)} - Q_1^{(j)}$，并提取满足 $x > Q_3^{(j)} + 1.5 \cdot IQR^{(j)}$ 或 $x < Q_1^{(j)} - 1.5 \cdot IQR^{(j)}$ 的记录构成极端子集 $E^{(j)}$。这一设计动机在于，通过显式隔离尾部数据，为生成器提供高浓度的极端值训练信号，避免其在全量数据训练中被正常样本淹没。

### 数据驱动运营有效性清洗

在生成阶段，TailBooster 采用双模型策略：一个 TVAE 在全量数据上训练以捕捉整体分布，另一个 TVAE 在极端子集上训练以强化尾部特征。生成后，引入深度学习层进行运营有效性清洗。该层利用预训练的自编码器学习历史数据中特征间的运营相关性，其重构误差定义为：

$$ e^{(k)}(x_c) = \| x_c - g^{(k)}_\theta(f^{(k)}_\phi(x_c)) \| $$

其中 $x_c$ 为运营相关特征向量，$f^{(k)}_\phi$ 和 $g^{(k)}_\theta$ 分别为自编码器的编码器和解码器。若重构误差超过阈值 $\tau_k$（设为重构误差的第 99 百分位数），则该记录被判定为运营不可行并剔除。这一机制解决了传统方法依赖手工规则或已知物理方程的局限，通过数据驱动方式隐式学习运营包络，确保生成记录符合历史观测到的物理约束，如飞行时间与距离的比例关系。

## 实验评估

实验基于美国交通部统计局（BTS）的 60,767 条国内航班记录，评估维度包括多样性、统计相似性、保真度、运营有效性及下游预测效用。基线对比仅包含 Naïve Synthetic（标准 TVAE 输出），缺失 GAN、扩散模型及 EVT 专用模型等强基线，限制了方法优势的全面验证。

| 数据集 | 记录数 | 极端飞行时间数 | 极端到达延迟数 |
| :--- | :--- | :--- | :--- |
| Real (D) | 60,767 | 3,726 | 5,470 |
| Naïve Synthetic | 62,803 | 2,751 | 5,136 |
| Augmented Synthetic | 68,335 | 6,255 | 9,938 |
| Augmented Real | 69,390 | 7,509 | 10,546 |

| 预测任务 | 训练数据 | MAE 范围 (min) | 相对 Naïve 降幅 |
| :--- | :--- | :--- | :--- |
| 极端飞行时间 | Naïve Synthetic | 19.40–23.58 | - |
| 极端飞行时间 | Augmented Synthetic | 10.21–12.23 | 47–49% |
| 极端到达延迟 | Naïve Synthetic | 34.41–47.58 | - |
| 极端到达延迟 | Augmented Synthetic | 14.89–34.00 | 29–57% |

消融实验显示，运营有效性清洗显著提升了二变量相似性，Augmented Synthetic 相比 Naïve Synthetic 提升了 8.94 个百分点（82.47% vs. 73.53%），表明清洗过程强化了特征间分布的一致性。保真度检查中，Augmented Synthetic 在极端子集上的判别分数（0.54）显著低于 Naïve Synthetic（0.92），说明生成样本更难被分类器区分，即更接近真实极端分布。然而，全量数据上的判别分数（0.78）仍较高，表明正常区域生成质量未受显著影响。

评估边界方面，论文未报告计算效率指标，且缺乏跨域通用性验证。可复现性受限于未提供代码及超参数细节，尽管实验环境（RTX 3060 GPU）已明确。指标体系侧重下游回归 MAE 与运营有效性，未涵盖 FID 或 MMD 等通用分布匹配指标，可能低估了生成样本在统计多样性上的表现。

## 关联研究分析

从问题动机看，TailBooster 与 zGAN 同属表格异常值生成路线，但 zGAN 侧重于生成一般性离群点，未针对特定连续特征的分布尾部进行定向增强。TailBooster 通过 IQR 提取极端子集并训练专用生成器，实现了对尾部区域的精细控制，解决了 zGAN 在极端值预测任务中信号不足的问题。这一差异源于航空数据中极端事件的稀有性与高影响性，要求生成模型不仅产生离群点，更要准确复现尾部的统计特性。

从方法设计看，TailBooster 与 PINFDIT 均引入物理约束，但 PINFDIT 依赖已知物理方程在推理阶段注入约束，适用于方程明确的科学领域。TailBooster 则采用自编码器重构误差作为数据驱动的运营包络，适用于规则未知或难以形式化的场景，如特定机场对的飞行时间与距离关系。这一设计选择源于航空运营数据的复杂性，其约束关系隐含在历史数据中，难以通过符号规则完整表达。然而，数据驱动清洗依赖历史数据的代表性，若历史数据本身存在偏差，清洗阈值可能误删有效样本或保留无效样本，论文未对此进行敏感性分析。

## 总结

TailBooster 旨在解决混合类型表格数据中极端值稀疏与运营逻辑一致性缺失的矛盾。现有生成模型因训练目标偏向高密度区域而忽略尾部，且缺乏对物理可行性的校验，导致生成样本在极端预测任务中效用低下。本文通过 IQR 统计层提取极端子集训练专用 TVAE，并引入自编码器重构误差作为数据驱动的运营有效性过滤器，实现了尾部增强与逻辑约束的联合优化。实验表明，该框架在极端飞行时间预测上将 MAE 降低 47–49%，在极端到达延迟预测上降低 29–57%，显著优于标准生成方法。然而，其运营有效性清洗依赖历史数据构建的包络，限制了在无先验数据或分布漂移场景下的适用性。当历史数据中极端事件分布发生结构性变化时，基于固定百分位数的清洗阈值是否仍能准确界定运营包络，论文未给出回答。
