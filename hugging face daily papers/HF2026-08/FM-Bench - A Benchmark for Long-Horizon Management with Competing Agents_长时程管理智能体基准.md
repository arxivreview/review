# HuggingFace最新推荐论文 ｜FM-Bench: A Benchmark for Long-Horizon Management with Competing Agents ｜长时程管理智能体基准

论文原文见 [arXiv](https://arxiv.org/abs/2608.18423)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.18423)

> 现有智能体评估多聚焦于短视距、静态环境下的工具调用或代码修复，无法衡量模型在长周期、动态竞争环境中的持续决策能力。本文提出 FM-Bench，通过构建一个包含 20 个游戏年、340-400 个决策点的足球俱乐部管理模拟环境，强制模型在信息隐藏、后果累积、市场反适应及多目标约束下运行。该基准采用确定性引擎评分，剥离了 LLM 评判器的主观性，并引入自管理记忆机制以量化长期规划能力。其价值在于揭示了“管理行为”而非“计算规模”是决定长时程表现的关键，但单一领域模拟的泛化性仍存疑。

## 研究背景

智能体评估的核心困境在于环境动态性与评估确定性的矛盾。传统基准如 SWE-bench 和 GAIA 依赖静态快照或单轮交付，错误不会跨步骤累积，导致模型在短视距任务上的高分无法映射到长周期场景。长时程任务要求智能体在数百步交互中维持状态一致性，早期微小错误会随时间复利放大，且环境需对智能体行为做出反应，这构成了“反适应”压力。

主流长时程评估路线存在明显瓶颈。终端代理马拉松（Terminal-agent marathons）虽延长了执行步数，但环境仍是静态的，追求固定交付物；游戏环境（如 Minecraft）侧重反应性技能而非经济规划；商业模拟（如 Vending-Bench）虽涉及长期运营，但环境不反推，且缺乏多智能体竞争。这些方案均未能同时满足“长视距”与“竞争性反适应”两个维度，导致无法测量智能体在真实商业或管理场景中的持续适应能力。

FM-Bench 的切入点在于将“管理”定义为在隐藏信息、累积后果、反适应环境及多目标压力下的持续决策过程。它通过足球俱乐部这一具体载体，将抽象的管理能力具象化为可计算的机制，填补了长时程竞争评估的空白。

## 核心方法

### 方法参照系

FM-Bench 属于领域特定基准构建，但其核心差异在于将“记忆策展”与“反适应市场”作为一等公民。通用 Agent 基准通常由 Harness 管理上下文，而 FM-Bench 将记忆管理剥离给模型，使其成为被评估能力的一部分，而非基础设施功能。

### 确定性评分与多目标约束

传统 LLM-as-a-Judge 在长时程任务中因主观性和不一致性而失效。FM-Bench 采用确定性引擎计算最终得分 $S_{final}$，该得分由荣誉、增值和阵容价值三个对数压缩通道组成：

$$ S_{raw} = 18 \ln(1 + \max(H, 0)) + 10 \text{sign}(VA) \ln(1 + |VA|) + 6 \ln(1 + \max(M, 0)) $$

其中 $H$ 为累计荣誉，$VA$ 为净增值，$M$ 为阵容价值。此设计确保了评分的客观性与不可饱和性，避免了模型通过“刷分”或短期冲刺获得高分，强制模型在整个 20 年周期内保持财务纪律与竞技表现的平衡。

### 反适应市场与记忆策展

为解决静态环境无法测试策略适应性的问题，FM-Bench 引入反适应市场机制：被拒绝的报价会提高隐藏要价，重复交易会增加价格标记。这要求模型从失败中推断市场真实价格，而非依赖固定策略。同时，每个决策点开启新对话，模型必须通过自写的“笔记本”（Notebook）传递意图。这一设计将记忆策展转化为可测量的行为指标，区分了“仅追加”与“全面重写”两种失败模式，揭示了模型在长期信息压缩上的局限性。

## 实验评估

实验在 3 个种子（1, 1024, 2026）的 Solo 轨道和 1 个种子（7）的 Arena 轨道上进行，涵盖 15 个前沿模型及 4 个脚本锚点。基线覆盖全面，包括特权 Oracle、纪律性启发式、空闲及随机策略，但缺乏其他 LLM Agent 框架的对比，主要聚焦于模型本身的能力差异。

| 模型 | S_final (Mean ± Std) | Token 消耗 |
| :--- | :--- | :--- |
| Oracle (Privileged) | 95.54 ± 4.68 | — |
| claude-fable-5 | 90.94 ± 5.20 | 24M |
| kimi-k2.6 | 88.49 ± 0.15 | 87M |
| gpt-5.6-terra | 86.66 ± 1.20 | 28M |
| deepseek-v4-pro | 79.15 ± 2.67 | 194M |
| claude-haiku-4.5 | 36.90 ± 22.73 | 86M |

核心发现是 Token 消耗与得分无相关性，挑战了“高算力即高性能”的假设。行为分析显示，高分模型在临近终点时减少慢回报投资，保持现金部署而非闲置，并提前开启合同续约。相比之下，低分模型往往在多个维度同时失败，如高闲置现金与短续约提前期并存。

消融分析表明，Oracle 的 95.54 分代表了信息完全可见下的理论上限，而最佳模型 claude-fable-5 达到 90.94 分，接近上限的 95%。然而，在 Arena 模式中，尽管 claude-fable-5 在 Solo 中领先，联赛冠军却在 10 个模型间轮换，表明竞争环境重塑了排名，单一维度的优势无法保证整体胜利。

评估边界方面，FM-Bench 依赖确定性引擎，确保了可复现性，但足球管理领域的特定机制（如转会市场规则）可能限制结论向其他管理场景的泛化。代码已开源，但超参数（如市场标记率）的敏感性分析未在正文中详细展开，可能影响结果对初始策略的鲁棒性。

## 关联研究分析

从问题动机看，FM-Bench 与 AgentAtlas 均主张行为级分解，但 AgentAtlas 侧重于静态基准的元评估，而 FM-Bench 通过动态环境直接测量行为。与 YC-Bench 相比，两者都重视记忆/Scratchpad，但 YC-Bench 将其作为成功预测因子，FM-Bench 则将其量化为独立评估维度，揭示了记忆策展的两种失败模式。这种差异源于任务特性：YC-Bench 关注创业决策的短期反馈，而 FM-Bench 强调长期累积效应。

从方法设计看，FM-Bench 与 τ-bench 均涉及工具调用，但 τ-bench 聚焦于单轮一致性（pass^k），而 FM-Bench 强调长时程累积。τ-bench 的环境是静态的客服场景，错误不会跨会话累积；FM-Bench 的环境是反适应的，错误会随时间复利。这一差异导致 τ-bench 无法测量策略适应性，而 FM-Bench 通过市场反适应机制强制模型学习。然而，FM-Bench 的反适应机制是否导致评估结果对初始策略过度敏感，论文未给出回答，这可能限制了其在更广泛策略空间中的适用性。

## 总结

FM-Bench 解决了长时程智能体评估中“静态环境”与“竞争反适应”缺失的核心矛盾。通过构建确定性足球管理模拟，它将记忆策展与策略适应性转化为可测量指标，证明了管理行为而非计算规模是决定长时程表现的关键。实验显示，最佳模型达到 Oracle 上限的 95%，但竞争环境重塑了排名，揭示了单一维度优势的局限性。其边界在于足球管理领域的特定机制可能限制泛化性，且反适应机制对初始策略的敏感性未充分验证。当支持集增大到 5-shot 时，查询侧增强的边际收益是否递减，论文未给出回答。
