# HuggingFace最新推荐论文 ｜Enhancing Rubric-based RL via Self-Distillation ｜标准蒸馏策略优化

研究机构：浙江大学

作者：Mingxuan Xia、Yuhang Yang、Chao Ye 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2607.18082)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.18082)

> 开放域任务中，基于评分标准（Rubric-based）的强化学习面临探索受限与信号抑制的双重困境：部分标准因组内无样本满足而缺乏梯度，另一些标准虽被满足却因标量奖励聚合而获得非正优势。现有方法通过外部引导生成轨迹，但引入了训练-推理分布不匹配。本文提出 CriPO，利用在线策略自蒸馏（On-Policy Self-Distillation, OPSD）在自身轨迹上进行局部修正，同时解决未探索与受抑制标准问题。该方法在医疗与科学基准上优于基线，但依赖 LLM 评判器的准确性，且未验证在长序列任务中的误差累积效应。

## 研究背景

在开放域生成任务中，模型输出缺乏唯一正确答案，无法使用确定性规则验证。基于评分标准的强化学习（Rubric-based RL）将响应质量分解为多个可解释的评价标准，由 LLM 评判器（LLM-as-a-Judge）对每个标准打分，再聚合为标量奖励驱动策略优化。这一范式将主观的人类偏好转化为结构化的多维监督，为医疗咨询、长文写作等任务提供了可扩展的训练信号。

GRPO 作为主流算法，通过组内相对优势估计消除对独立价值网络的依赖，大幅降低了强化学习训练的内存开销。然而，在基于评分标准的场景中，GRPO 将多维评分聚合为单一标量奖励，导致两个失效模式：一是未探索标准（Unexplored Criteria），即组内无轨迹满足某标准，该维度无优化信号；二是受抑制标准（Suppressed Criteria），即满足某标准的轨迹因整体劣势而获得非正优势，有用行为被惩罚。现有方法如 HeRL 通过事后引导生成修正轨迹，但引入了训练-推理不匹配：训练时轨迹由外部信息引导，推理时模型仅依赖自身前缀，导致早期生成误差在自回归解码中累积。

本文的切入点在于，不改变轨迹生成过程，而是在模型自身的在线策略轨迹上提供细粒度监督。通过构建特权条件自教师，在 token 级别定位并修正标准相关的行为，既避免了分布不匹配，又解决了标量聚合导致的局部信号丢失。

## 核心方法

### 方法参照系

本文问题属于开放域任务扩展类别，标准流程为：采样轨迹 → LLM 评判器多维评分 → 标量聚合 → GRPO 优化。关键差异在于，标准流程仅优化标量奖励，无法区分各标准的贡献，导致未探索与受抑制标准问题。

### 行为注入：未探索标准的局部蒸馏

针对未探索标准，CriPO 构建标准注入自教师，通过前向 KL 散度将缺失的标准特定行为注入策略。设计动机是解决组内无轨迹满足某标准导致的梯度消失问题。具体地，选择组内最高优势轨迹 $y^*$，构建条件于未探索标准 $C_u$ 的教师分布 $p^T_t = \pi_\theta(\cdot|x, C_u, y_{<t})$，计算学生分布 $p^S_t = \pi_\theta(\cdot|x, y_{<t})$ 与教师分布的前向 KL 散度 $d_t = D_{KL}(sg(p^T_t) \| p^S_t)$。为过滤噪声，仅对累计 KL 贡献达到阈值 $\gamma=0.95$ 的最小 token 集合 $T^u$ 进行蒸馏，损失函数为：

$$
L_{OPSD} = \frac{1}{|T^u|} \sum_{t \in T^u} d_t
$$

该公式的物理含义是：仅在教师分布显著偏离学生分布的位置（即标准相关行为缺失处）提供监督，避免对无关 token 的过度拟合。

### 优势翻转：受抑制标准的局部修正

针对受抑制标准，CriPO 构建反事实自教师，定位标准相关 token 并翻转其优势值。设计动机是解决标量聚合导致的有用行为被惩罚问题。具体地，对负优势轨迹 $y_i$，构建条件于已满足受抑制标准 $C_s$ 的反事实教师，通过对比学生与教师分布，定位满足两个条件的 token：(i) 采样 token 在标准移除后被降权，即 $\Delta_{i,t} = \log p^S_{i,t}(y_{i,t}) - \log p^T_{i,t}(y_{i,t}) > 0$；(ii) 教师自信地偏好替代 token，即 $p^T_{i,t}(y_{i,t}) < \alpha \cdot \max_v p^T_{i,t}(v)$，其中 $\alpha=0.1$。对定位到的 token 集合 $T^s$，将原始负优势 $A_i$ 替换为正值 $\tau_{flip}=0.1$，计算修正后的 GRPO 损失：

$$
L_{GRPO} = -\frac{1}{|T^s|} \sum_{t \in T^s} \min(\rho_{i,t} \tau_{flip}, \text{clip}(\rho_{i,t}, 1-\epsilon, 1+\epsilon) \tau_{flip})
$$

该公式的物理含义是：在保留全局 GRPO 优化结构的前提下，局部反转标准相关 token 的更新方向，使有用行为得到强化而非惩罚。

## 实验评估

实验在医疗与科学 QA 任务上进行，使用 RaR-Medicine 和 RaR-Science 作为训练集，HealthBench、LLMEval-Med 和 ResearchQA 作为跨域评测集。基线覆盖 GRPO、HeRL 和 OPSD，但缺失数学领域的强基线（如 DeepSearch），因任务域不同。

| 方法 | Qwen3-1.7B Avg. | Qwen3-4B Avg. |
| :--- | :--- | :--- |
| GRPO | 59.2 | 68.2 |
| HeRL | 60.4 | 68.4 |
| OPSD | 38.2 | 43.6 |
| CriPO | 62.4 | 69.6 |

CriPO 在 Qwen3-1.7B 上较 GRPO 提升 3.2 个点，在 Qwen3-4B 上提升 1.4 个点，表明标准级修正在小模型上收益更显著。OPSD 单独使用性能崩溃（38.2 vs 59.2），验证了本文将其作为辅助模块而非独立算法的设计决策。

消融实验显示，移除贡献引导 token 过滤使 CriPO-U 平均分从 66.4 降至 65.5，移除最佳轨迹选择降至 65.6，表明局部蒸馏策略的有效性。随机定位受抑制标准 token 使 CriPO-S 平均分从 68.9 降至 64.9，证明反事实定位机制的关键作用。

评估边界方面，指标仅覆盖 Pass@1，未报告置信区间；评估协议依赖 GPT-4o-mini 作为评判器，其准确性未独立验证；可复现性方面，论文未提供代码 URL，但 OPSD 模块可参照 SDPO 的开源实现。

## 关联研究分析

从问题动机看，本文与 HeRL 同属解决未探索标准问题，但路线截然不同。HeRL 通过事后引导生成修正轨迹，属于离线策略（Off-policy）方法，引入了训练-推理分布不匹配；本文通过在线策略自蒸馏，在自身轨迹上提供监督，消除了分布差异。这一差异的根源在于任务特性：开放域任务的长响应放大了分布不匹配的误差累积，而数学/代码等可验证任务的短响应对分布不匹配更鲁棒。

从方法设计看，本文与 SC-GRPO 同属细粒度信用分配机制，但粒度不同。SC-GRPO 通过测量原始策略与自条件教师策略之间的 token 级 KL 散度，实现无需外部资源的细粒度信用分配；本文通过标准注入与反事实定位，实现标准级的局部修正。这一差异的根源在于奖励结构：SC-GRPO 针对二元结果奖励，本文针对多维评分标准奖励，后者需要区分各标准的贡献，而前者仅需区分正确与错误轨迹。

## 总结

本文要解决的核心矛盾是开放域任务中标量奖励聚合导致的局部信号丢失：未探索标准无梯度，受抑制标准被惩罚。现有方法通过外部引导生成轨迹，但引入了训练-推理分布不匹配；本文通过在线策略自蒸馏，在自身轨迹上进行局部修正，既避免了分布差异，又解决了信号丢失问题。CriPO 通过标准注入自教师的前向 KL 蒸馏和反事实自教师的优势翻转，在医疗与科学基准上较 GRPO 提升 3.2 个点（Qwen3-1.7B），且收敛速度提升 2 倍。本文的边界在于，依赖 LLM 评判器的准确性，且未验证在长序列任务中的误差累积效应。当响应长度增加到 1000 token 以上时，标准注入自教师的局部修正是否仍能有效抑制误差传播，论文未给出回答。
