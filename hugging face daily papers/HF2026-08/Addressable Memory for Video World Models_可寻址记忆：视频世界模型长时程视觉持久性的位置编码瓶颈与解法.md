# HuggingFace最新推荐论文 ｜Addressable Memory for Video World Models ｜可寻址记忆：视频世界模型长时程视觉持久性的位置编码瓶颈与解法

研究机构：美国普林斯顿大学、加拿大多伦多大学

论文原文见 [arXiv](https://arxiv.org/abs/2608.07408)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.07408)

> 交互式视频世界模型在生成超过训练上下文长度时，往往因位置编码偏移超出训练分布而导致已存储场景无法被检索，即“地址性失效”。现有压缩缓存方法仅解决存储容量或内容平滑问题，忽略了位置编码对注意力检索的硬性约束。本文提出 WorldTrace，一种无需重训练的推理时缓存机制，通过为每个摘要槽位分配固定的、分布内的虚拟位置，并配合规范域平均或地标冻结策略，实现长时程场景重访的一致性。该方法在 LoopBench 基准上将情景回忆准确率提升至 0.964，但受限于固定槽位数量，无法处理超过槽位数的独立场景重访。

## 研究背景

自回归视频世界模型通过 Key-Value (KV) 缓存维持历史上下文，其核心依赖旋转位置编码（RoPE）计算查询与键之间的相对时间偏移。当生成步数 $N$ 超过训练时的最大偏移 $\Delta t_{train}$ 时，RoPE 的旋转角度进入未训练区域，导致注意力机制无法准确定位缓存中的历史帧。这种位置编码的分布外（Out-of-Distribution, OOD）效应使得即使历史内容完整存储在缓存中，模型也无法可靠地检索它们，表现为场景重置或物体消失。

当前主流路线试图通过压缩 KV 缓存来应对长时程生成，如 MemRoPE 使用双指数移动平均（EMA）流，或 Infinity-RoPE 采用块相对重索引。然而，这些方法存在根本缺陷：块相对重索引将所有历史偏移截断至 $\Delta t_{train}$，导致不同摘要槽位在位置空间上坍缩为同一坐标，变得不可区分；而简单的 RoPE 空间平均则因不同时间戳的相位抵消而破坏内容信号。WorldTrace 的切入点在于识别出“地址性”与“信息性”是两个耦合但独立的瓶颈，必须同时解决位置的可寻址性和内容的保真性，才能维持视觉持久性。

## 核心方法

### 方法参照系

本文问题属于自回归视频生成中的 KV 缓存压缩类别。标准流程是将线性增长的缓存压缩为固定大小，但通常仅关注内容压缩（如平均或丢弃），而忽略位置编码在长时程推理中的 OOD 失效。本文的关键差异在于将位置分配视为与内容压缩同等重要的约束，要求压缩后的槽位必须在模型训练过的偏移范围内保持可区分。

### 虚拟位置分配：槽位排名索引

设计动机是解决块相对重索引导致的槽位位置坍缩问题。WorldTrace 将局部注意力窗口 $L_{attn}$ 划分为 $N_r$ 个逐字最近窗口和 $N_s$ 个摘要槽位。对于查询位置 $q$，摘要槽位 $s$ 的虚拟位置 $t_v^s$ 由槽位排名固定决定，而非其源帧的实际时间戳：

$$ t_v^s = q - (L_{attn} - 1 - s), \quad s = 0, \dots, N_s-1 $$

该公式确保无论生成步数 $N$ 如何增长，每个槽位的相对偏移始终保持在 $[0, \Delta t_{train}]$ 范围内，且不同槽位拥有不同的偏移量，从而在注意力计算中保持可区分性。

### 规范域内容压缩：避免相位抵消

设计动机是解决在 RoPE 旋转空间直接平均导致的低频信号抵消问题。WorldTrace-Field 采用规范域平均，先将每个源帧的键 $K_m^f$ 通过 $R(-\theta_f t_m)$ 反旋转至规范空间（无旋转），计算均值后再旋转至虚拟位置 $t_v^s$：

$$ \bar{K}^{f}_{v} = R(\theta_f t_v^s) \left( \frac{1}{M} \sum_{m=1}^{M} R(-\theta_f t_m) K_m^f \right) $$

这一操作消除了不同时间戳带来的相位差异，保留了内容的低频结构，使得摘要槽位能够承载连贯的时间信息。WorldTrace-Landmark 则进一步简化，在检测到场景入口时冻结规范键，直接存储为地标，以支持精确的情景回忆。

## 实验评估

实验基于 Matrix-Game 2.0 (MG2-1.3B) 和 LingBot-World (14B) 骨干，使用自建 LoopBench 基准评估场景重访一致性。基线包括滑动窗口、块相对重索引、MemRoPE 和 YaRN。WorldTrace-Landmark 在 ABA 循环任务中表现最优，在 $N=32$ 时 PAC 达 0.964，显著高于滑动窗口的 0.401 和 MemRoPE 的 0.651。

| 方法 | 位置策略 | 内容策略 | PAC ($N=32$) | PAC ($N=48$) |
| :--- | :--- | :--- | :--- | :--- |
| Sliding window | Actual | Sliding window | 0.401 | 0.388 |
| MemRoPE | Block-relative | Dual EMA | 0.651 | 0.706 |
| YaRN | NTK | Sliding window | 0.490 | 0.412 |
| WorldTrace-Landmark | WorldTrace | Verbatim | 0.964 | 0.972 |

消融实验显示，位置分配是主要瓶颈。在相同内容压缩下，WorldTrace 位置比块相对位置在 $N=64$ 时提升 PAC 0.030。规范域平均比朴素平均在 $N_s=4$ 时降低 LatentDiff 25.3%（0.312 至 0.233），证实了相位抵消对内容保真性的损害。跨架构实验表明，WorldTrace-Landmark 在 14B 骨干上从 4 倍训练时长开始优于基线，而 WorldTrace-Field 因 Plücker 相机条件已提供回忆信号，增益不明显。

评估边界方面，LoopBench 仅测试受控的场景重访，未涵盖开放域探索或物理交互。可复现性上，论文提供完整超参数（$N_s=4, N_r=2$）和单 A100 GPU 运行时间（~1.0 s/chunk），但未公开代码。指标 PAC 基于 CLIP 相似度，可能无法捕捉细粒度几何错误。

## 关联研究分析

从问题动机看，WorldTrace 与 MemRoPE 均针对长时程记忆，但 MemRoPE 依赖 EMA 平滑内容，假设位置编码在截断后仍有效，而 WorldTrace 指出位置 OOD 是根本原因。这一差异源于任务特性：MemRoPE 面向无限视频生成，允许内容模糊；WorldTrace 面向交互式重访，要求精确回忆。从方法设计看，WorldTrace 与 Infinity-RoPE 的块相对重索引在位置处理上相似，但 Infinity-RoPE 未考虑压缩缓存中的槽位区分度，导致位置坍缩。WorldTrace 通过槽位排名索引解决了这一问题，但其固定槽位数量限制了可回忆场景的数量，这是其未探索的盲区。

## 总结

本文要解决的核心矛盾是自回归视频世界模型在长时程生成中因位置编码 OOD 导致的记忆不可寻址性。现有方法如 MemRoPE 和 Infinity-RoPE 仅解决内容压缩或位置截断，忽略了位置区分度与内容保真性的耦合。WorldTrace 通过虚拟位置分配和规范域压缩，在无需重训练的情况下实现了长时程视觉持久性，在 LoopBench 上将 PAC 提升至 0.964。其边界在于固定槽位数量限制了可回忆场景数，且依赖场景入口检测。当场景数量超过槽位容量时，模型是否仍能通过自适应驱逐策略维持回忆，论文未给出回答。
