# HuggingFace最新推荐论文 ｜Video-DeepResearch: Towards the Next-Generation Multimodal Deepresearch Agent ｜视频深度研究智能体

作者：Zhen Fang、Yu Zeng、Wenxuan Huang 等 20 人

论文原文见 [arXiv](https://arxiv.org/abs/2608.03979)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.03979)

> 深度研究智能体（DRA）旨在让大语言模型自主处理开放式、长周期的高复杂度信息检索与整合任务，其核心价值在于突破静态检索的局限，实现从碎片化证据到结构化洞察的认知跃迁。现有文本主导的DRA范式在处理连续视频流时，面临模型系统性回避视觉工具（模态偏置）与依赖参数化记忆（知识泄漏）的双重瓶颈，导致无法真实评估多模态长程推理能力。本文提出Video-DeepResearch，通过解耦感知-探索管道与阶段式工具解锁，强制智能体先执行跨帧视觉接地再进行网络探索，结合SFT与GRPO两阶段训练，使35B模型在自建基准上达到64.0%准确率，超越Claude-4.5-Sonnet 5.0个百分点，但其自建基准的泛化性与阶段式解锁的灵活性限制仍存疑。

## 研究背景

当智能体面对包含密集视觉信息的连续视频流时，其参数化知识的时效性与幻觉问题被进一步放大，因为视频中的实体、场景与时间线索无法通过单次静态检索获取。这一困境要求智能体具备动态调整查询策略、处理噪声信息以及维持长程目标一致性的能力，即深度研究任务的核心挑战在于长程信息整合与噪声过滤，而非单纯的事实检索。解决此类问题的经典框架是ReAct范式，它通过“推理-行动-观察”循环赋予模型主动探索能力，但受限于长程记忆丢失与执行漂移，且现有评估基准存在严重的参数化知识泄漏，导致模型可绕过工具调用直接猜测答案。

深度研究智能体的兴起源于大语言模型参数化知识的时效性不足，其核心驱动力是赋予AI自主探索、检索与综合复杂信息的能力。主流路线在架构复杂度与训练强度间做出不同取舍：架构派通过多智能体协作显式管理记忆，训练派则依赖大规模端到端强化学习挖掘模型潜力。然而，现有方法在处理视频模态时暴露出两个被忽略的失效点：一是模型对视觉工具的回避（模态偏置），二是评估基准无法区分真实工具使用与参数化记忆（知识泄漏）。本文切入点在于将深度研究从静态图像扩展至连续视频流，通过数据合成与训练策略的协同设计，解决视频时空特性带来的感知瓶颈。

## 核心方法

### 方法参照系

本文问题属于多模态深度研究路线，其通用流程为：智能体接收查询与视觉输入，通过工具调用（搜索、浏览）获取证据，最终生成答案。与文本DRA的关键差异在于，视频输入是连续时空流，智能体需先定位关键帧与实体，再执行视觉搜索，最后结合文本检索，这一时序依赖要求工具调用具有严格的阶段约束。

### 解耦感知-探索管道

设计动机：现有智能体在视频任务中系统性回避视觉工具，直接依赖文本搜索，导致无法真实评估多模态长程推理能力。本文在工具调用阶段引入阶段式解锁机制，将动作空间分为视觉感知（Select_Keyframe, Crop_Search）与文本探索（Search, Visit）两个阶段。在初始阶段，智能体仅能使用视觉工具，强制其执行跨帧、跨实体的视觉接地，直到视觉上下文充分或达到最大感知边界，才解锁文本工具。该机制通过约束动作空间，确保智能体在文本检索前完成充分的视觉证据收集，其核心公式为：

$$
\mathcal{A} = \begin{cases} \{\text{Select\_Keyframe}, \text{Crop\_Search}\} & \text{if } t < t_{\text{unlock}} \\ \{\text{Select\_Keyframe}, \text{Crop\_Search}, \text{Search}, \text{Visit}\} & \text{if } t \geq t_{\text{unlock}} \end{cases}
$$

其中 $t_{\text{unlock}}$ 为视觉感知充分或达到最大边界的时刻。这一设计直接对抗模态偏置，使智能体从被动回忆转向主动验证。

### 两阶段训练策略

设计动机：静态SFT模仿无法突破性能上限，且模型在SFT后仍可能保留工具调用偏置。本文采用SFT+GRPO两阶段训练，SFT阶段使用7K高质量轨迹与7K纯文本QA混合数据，建立解耦感知-探索范式；GRPO阶段使用2K中等难度数据集，通过稀疏二元奖励优化策略。SFT目标函数为：

$$
L_{\text{SFT}} = -\mathbb{E}_{(x,y)\sim\mathcal{D}} \sum_{i=1}^{|y|} \log \pi_\theta(y_i | x, y_{<i})
$$

GRPO目标函数为：

$$
L_{\text{GRPO}} = \frac{1}{G} \sum_{i=1}^{G} \left[ \min\left( \frac{\pi_\theta(o_i)}{\pi_{\text{old}}(o_i)} \hat{A}_i, \text{clip}\left( \frac{\pi_\theta(o_i)}{\pi_{\text{old}}(o_i)}, 1-\epsilon, 1+\epsilon \right) \hat{A}_i \right) - \beta D_{\text{KL}} \right]
$$

其中 $\hat{A}_i$ 为组内相对优势，$r=1$ 表示答案正确，$r=0$ 表示错误。该策略通过主动生成rollout并接收奖励，使智能体超越SFT的模仿上限，实现自主探索。

## 实验评估

实验在VideoDR与VIDEODR-BENCH上进行，基线覆盖闭源（GPT-5, Claude-4.5-Sonnet, Gemini 2.5 Pro）与开源（Qwen3.5-397B, Kimi K2.5）VLM，缺失纯文本DRA基线。主实验结果显示，Video-DeepResearch-35B-A3B在VideoDR上达68.0%，在VIDEODR-BENCH上达60.0%，平均准确率64.0%，超越Claude-4.5-Sonnet（59.0%）5.0个百分点，显著优于GPT-5（52.5%）与Gemini 2.5 Pro（57.5%）。

| 模型 | VideoDR (%) | VIDEODR-BENCH (%) | 平均准确率 (%) |
| :--- | :--- | :--- | :--- |
| Gemini 2.5 Pro | 62.0 | 57.1 | 57.5 |
| GPT-5 | 57.0 | 48.0 | 52.5 |
| Claude-4.5-Sonnet | 63.0 | 55.0 | 59.0 |
| Qwen3.5-397B-A13B | 58.0 | 47.5 | 52.8 |
| Kimi K2.5 | 61.0 | 53.0 | 57.0 |
| Qwen3-VL-30B-A3B-Instruct | 38.0 | 43.0 | 40.5 |
| Video-DeepResearch-30B-A3B | 62.0 | 56.5 | 59.3 |
| Video-DeepResearch-35B-A3B | 68.0 | 60.0 | 64.0 |

消融实验显示，从基线到7K-SFT，平均准确率提升12.5%（40.5%→53.0%），其中VIDEODR-BENCH提升8.0%（43.0%→51.0%），VideoDR提升17.0%（38.0%→55.0%），表明视觉接地数据对基准质量评估尤为关键。加入7K纯文本QA后，平均准确率再提升3.8%（53.0%→56.8%），验证了文本探索数据对缓解工具调用偏置的作用。最后，GRPO阶段带来2.5%提升（56.8%→59.3%），其中VIDEODR-BENCH提升2.0%（54.5%→56.5%），表明RL策略对基准任务的泛化性。

| 训练阶段 | VideoDR (%) | VIDEODR-BENCH (%) | 平均准确率 (%) |
| :--- | :--- | :--- | :--- |
| Base | 38.0 | 43.0 | 40.5 |
| 4k-SFT | 44.0 | 48.0 | 46.0 |
| 7K-SFT | 55.0 | 51.0 | 53.0 |
| 7K-SFT+7k-text-SFT | 59.0 | 54.5 | 56.8 |
| 14k-SFT+2K-RL | 62.0 | 56.5 | 59.3 |

评估边界方面，VIDEODR-BENCH为自建基准，包含100个人工标注VQA对，其泛化性未通过外部基准验证；评估协议依赖Qwen3-VL-30B-A3B-Instruct作为裁判模型，可能存在裁判偏置；可复现性方面，论文提供GitHub链接，但未报告完整超参数与GPU配置细节。

## 关联研究分析

从问题动机看，本文与ASearcher（ICLR 2026）同属RL训练范式，但ASearcher聚焦文本搜索，通过大规模端到端RL解锁长程智能体搜索，而本文聚焦多模态视频，通过解耦管道解决模态偏置。差异根源在于任务特性：文本搜索的信用分配可通过稀疏结果奖励优化，而视频搜索需先解决视觉接地问题，否则文本检索将因缺乏视觉锚点而失效。本文的阶段式解锁是任务特性迫使，还是可优化的方法改进，论文未给出回答。

从方法设计看，本文与WebWeaver（ICLR 2026）均关注开放式报告生成，但WebWeaver侧重双智能体架构，通过显式规划管理大纲与证据，而本文侧重单智能体工具解锁，通过约束动作空间实现感知-探索解耦。差异根源在于评估目标：WebWeaver优化报告结构完整性，本文优化多模态工具使用效率。本文未对比WebWeaver等架构派方法，其阶段式解锁在开放式报告生成任务中是否仍具优势，论文未给出回答。

## 总结

本文要解决的核心矛盾是视频深度研究中模型对视觉工具的回避与评估基准的知识泄漏问题。现有方法因缺乏针对视频时空特性的数据合成与训练策略，无法真实评估多模态长程推理能力。本文通过解耦感知-探索管道与阶段式工具解锁，强制智能体先执行视觉接地再进行文本探索，结合SFT+GRPO两阶段训练，使35B模型在自建基准上达到64.0%准确率，超越Claude-4.5-Sonnet 5.0个百分点。本文的边界在于自建基准的泛化性未验证，且阶段式解锁可能限制模型在动态场景中的灵活性。当视频内容的时间动态性增强时，阶段式解锁的固定感知边界是否会导致关键帧遗漏，论文未给出回答。
