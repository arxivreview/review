# HuggingFace最新推荐论文 ｜Agent Memory Distillation: Empowering Small LLM Agents with Hierarchical Teacher Memory ｜智能体记忆蒸馏

研究机构：韩国科学技术院

作者：Taeil Kim、Kangsan Kim、Sung Ju Hwang

论文原文见 [arXiv](https://arxiv.org/abs/2608.07169)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.07169)

> 小模型智能体因任务成功率低导致自身记忆库中成功轨迹稀缺，而直接迁移大模型教师的扁平记忆又因师生能力差距难以被小模型有效解读。现有记忆框架多针对大模型自进化设计，缺乏针对小模型理解瓶颈的跨模型知识转移机制。本文提出层级化记忆蒸馏框架，将教师经验分解为任务、子任务与函数三层结构，通过差异化注入策略弥合能力鸿沟。该框架在工具使用基准上显著提升了小模型性能，但其对教师-学生兼容性的依赖及仅利用成功轨迹的局限性，限制了其在复杂动态环境中的泛化能力。

## 研究背景

智能体记忆系统旨在解决大语言模型原生无状态特性与长程任务需求之间的矛盾，其核心价值在于构建具备自我进化能力的持久化记忆。当智能体依赖外部工具执行复杂任务时，记忆不仅用于存储事实，更需编码工具调用策略与错误恢复机制。然而，小模型智能体面临双重困境：一方面，其低任务成功率导致自身生成的记忆库被失败轨迹主导，成功经验极度稀缺；另一方面，小模型在上下文学习与指令遵循能力上弱于大模型，难以直接理解并应用大模型生成的抽象策略记忆。

现有记忆框架如ReasoningBank和SASM主要关注单模型自进化或大模型场景下的检索优化，默认智能体具备足够的推理能力来解析记忆内容。这一假设在小模型场景下失效，导致直接迁移教师记忆仅带来边际提升。本文切入点在于识别“记忆利用瓶颈”：高质量记忆无法被小模型有效解读并非记忆质量不足，而是表示粒度与模型能力不匹配。通过引入层级化结构，将教师经验分解为不同抽象程度的记忆单元，使小模型能在其能力范围内逐步获取并应用知识。

## 核心方法

### 层级化记忆生成

本文方法参照系为基于轨迹的记忆提取与检索流程，通常做法是从智能体交互历史中提取单一粒度的记忆条目并进行向量检索。本文的关键差异在于引入教师-学生跨模型蒸馏场景，并针对小模型理解能力限制设计多层级记忆结构。AMD框架从教师成功轨迹 $D_T^+$ 中构建三类记忆：工作流记忆 $M_{wf}$、子任务记忆 $M_{st}$ 和函数记忆 $M_{fn}$，形成 $M = M_{wf} \cup M_{st} \cup M_{fn}$ 的层级存储。工作流记忆通过自然语言洞察描述任务整体策略，抽象掉具体运行时值；子任务记忆将轨迹分解为语义连贯的行为片段，保留具体执行示例；函数记忆则索引具体工具调用模式与文档。这种分层设计解决了扁平记忆因抽象程度单一导致小模型无法解析的失效问题。

### 差异化注入机制

记忆检索与注入环节通常采用统一的向量相似度匹配，本文创新在于根据记忆层级采用主动与被动相结合的差异化注入策略。工作流与子任务记忆在任务开始时主动注入系统提示，其中子任务记忆通过学生模型将任务分解为子任务标签后独立检索，实现细粒度对齐。函数记忆则在工具调用错误时被动检索，通过函数名索引并基于任务指令相似度排序，将纠正提示追加至错误消息中。该机制通过公式 $\max_M \mathbb{E}_{s \sim S} [R(\pi_S(s; M))]$ 优化小模型在记忆辅助下的任务成功率，其物理含义是通过层级化记忆结构最大化小模型对教师知识的利用率。主动注入提供高层规划框架，被动注入提供即时纠错指导，二者协同降低了小模型在长程任务中的探索成本与错误累积。

## 实验评估

实验在AppWorld、BFCL V3和ToolSandbox三个工具使用基准上进行，使用GPT-5-mini作为教师，Qwen3-4B/8B、Gemma4-E4B和Llama3.1-8B作为学生模型。基线覆盖ReasoningBank、MemP和SASM等记忆框架，但缺失Mem0、HippoRAG等结构化图谱方法，且未包含其他教师-学生蒸馏基线。AMD在AppWorld上平均提升27.2个百分点，BFCL V3提升11.2个百分点，ToolSandbox提升3.4个百分点，显著优于所有非蒸馏基线。

| 方法 | AppWorld | BFCL V3 | ToolSandbox | 平均 |
|---|---|---|---|---|
| Qwen3-4B Zero-shot | 14.88 | 15.50 | 16.28 | 15.55 |
| Qwen3-4B AMD | 49.40 | 38.50 | 20.16 | 36.02 |
| Gemma4-E4B AMD | 54.17 | 46.00 | 21.71 | 40.63 |
| Qwen3-8B AMD | 51.79 | 45.50 | 25.58 | 40.96 |

消融实验显示子任务记忆贡献最大增量，例如在AppWorld上Qwen3-4B从仅工作流记忆的22.02%提升至47.02%。函数记忆在组合使用时提供额外增益，但单独作用效果有限。教师模型选择实验揭示非单调关系：GPT-5-mini在Qwen3-4B上表现优于准确率更高的DeepSeek V4 Pro，表明教师-学生兼容性比单纯教师准确率更重要。

评估边界方面，实验仅使用4B-8B参数模型，未验证更大规模学生的收益递减情况；ToolSandbox提升幅度较小（3.4%p），可能反映该基准任务复杂度或记忆依赖度较低；论文未报告置信区间与计算开销，且仅使用成功轨迹构建记忆，未探讨失败经验在边缘情况处理中的潜在价值。

## 关联研究分析

从问题动机看，AMD与ReasoningBank和SASM均关注智能体记忆提升，但前者聚焦单模型自进化中的记忆检索优化，默认模型具备解析记忆的能力；AMD则针对小模型理解瓶颈，通过层级化结构降低记忆解析难度。这一差异源于任务特性：小模型在指令遵循与上下文学习上的能力限制，使得扁平记忆无法被有效利用，而层级化分解提供了与模型能力匹配的抽象梯度。

从方法设计看，AMD与知识蒸馏范式中的SAD和Agent Distillation共享教师-学生框架，但后者通过参数优化或段级损失实现知识转移，AMD则采用训练无关的记忆转移。这一差异反映了智能体记忆的特殊性：记忆作为外部存储，其价值不仅在于信息内容，更在于表示形式与模型能力的匹配度。AMD通过差异化注入策略（主动/被动）解决了静态记忆注入在动态工具使用场景中的时效性问题，但论文未探讨这种策略在非工具使用任务中的适用性。

## 总结

AMD解决的核心矛盾是小模型智能体因成功轨迹稀缺与理解能力不足导致的记忆利用瓶颈。现有方法未能解决此问题，因其默认模型具备解析复杂记忆的能力，而AMD通过层级化记忆结构将教师经验分解为与模型能力匹配的抽象梯度，实现了训练无关的知识转移。实验证明该框架在AppWorld上提升27.2个百分点，在BFCL V3上提升11.2个百分点，显著优于非蒸馏基线。其边界在于仅使用成功轨迹构建记忆，可能忽略失败经验对边缘情况处理的贡献，且教师-学生兼容性的非单调关系表明简单提升教师准确率并非最优策略。当任务环境包含大量未预见的工具调用错误时，仅依赖成功轨迹提取的函数记忆是否足以覆盖所有错误模式，论文未给出回答。
