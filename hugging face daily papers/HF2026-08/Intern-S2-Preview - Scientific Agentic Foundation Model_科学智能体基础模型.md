# HuggingFace最新推荐论文 ｜Intern-S2-Preview: Scientific Agentic Foundation Model ｜科学智能体基础模型

作者：Lei Bai、Jiaqi Cao、Chiyu Chen 等 125 人

论文原文见 [arXiv](https://arxiv.org/abs/2608.13505)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.13505)

> 科学发现要求模型在异构证据上进行长程推理与工具交互，而现有通用大语言模型缺乏领域协议适配，科学多模态模型则局限于静态问答。本文切入点在于构建支持迭代、工具接地问题求解的科学智能体基础模型，通过冻结骨干附加参数化记忆与专用时序预测分支实现模块化特化。其价值在于验证了不重写参数即可扩展领域能力的可行性，但长程智能体训练的分布稳定性与记忆模块的可解释性仍存疑。

## 研究背景

当科学任务涉及从原始数据到假设验证的完整闭环时，模型需同时处理文本、图表、公式及数值时序等异构模态，并维持跨步骤的逻辑一致性。这一需求催生了科学智能体基础模型的概念，它区别于仅能回答孤立问题的静态问答系统，强调在长任务地平线上通过工具调用与环境反馈进行自适应规划。然而，通用大语言模型虽具备广泛指令遵循能力，却未针对科学领域的特定协议与可验证工具交互进行优化；科学多模态模型虽提升了感知与推理精度，但评估体系多聚焦于单点任务，难以覆盖长程自主科研流程。

当前领域面临的核心矛盾是模型通用性与领域特化性的冲突。直接微调骨干网络以注入领域知识，往往导致通用推理与多模态能力的灾难性遗忘，而检索增强生成虽能缓解幻觉，却难以内化深层领域模式。Intern-S2-Preview 针对这一瓶颈，提出在不修改冻结骨干参数的前提下，通过附加独立训练的参数化记忆模块实现快速领域扩展，同时引入专用时序预测分支以支持科学信号的未来状态预测，从而在保持通用能力的基础上实现模块化科学特化。

## 核心方法

### 方法参照系

本文问题归属于多模态科学基础模型与自主科研智能体的融合路线。标准流程通常包括科学多模态预训练、监督微调及多任务强化学习。本文的关键差异在于引入“冻结骨干+参数化记忆”的模块化架构，以及将时序建模从理解扩展至数值预测，区别于传统端到端微调范式。

### 参数化记忆模块

针对直接微调骨干导致通用能力退化的问题，本文设计 Memory Decoder 作为外挂模块。该模块通过压缩检索式领域证据为可复用参数化单元，在推理时与冻结骨干并行处理输入。其训练目标结合检索蒸馏与金标答案监督，公式为：

$$ \mathcal{L}_{mem}(c_t) = \beta \mathcal{L}_{KL}(c_t) + (1-\beta) \mathcal{L}_{CE}(c_t) $$

其中 $\mathcal{L}_{KL}$ 衡量记忆分布与检索教师分布的散度，$\mathcal{L}_{CE}$ 为交叉熵损失。该设计将领域扩展从骨干重写转化为模块化记忆附加，避免了参数更新对通用推理路径的扰动。

### 动态路由与融合机制

为解决记忆模块与骨干模型输出分布不一致的问题，本文引入轻量级 token 级路由器。路由器基于两模型的隐状态及置信度特征，预测动态融合系数 $\lambda_t$，最终分布为：

$$ p_{final}(\cdot | c_t) = (1-\lambda_t) p_{S2}(\cdot | c_t) + \lambda_t p_{mem}(\cdot | c_t) $$

该机制允许模型在领域任务中动态增加记忆贡献，而在通用任务中抑制记忆干扰，实现了细粒度的能力切换。

### 时序预测分支

针对科学工作流中预测未来系统状态的需求，本文在 LLM 与时序编码器表示基础上，通过 Q-Former 提取语义与数值特征，条件化因果 Transformer 进行未来序列生成。该分支独立于文本 token 生成，保留了数值保真度，支持灵活预测地平线，弥补了静态问答模型无法进行数值外推的缺陷。

## 实验评估

实验覆盖科学、多模态、智能体及通用基准，基线包括 GPT-5、Gemini 2.5 Pro、Qwen3.5-397B 等开源与闭源模型。在科学基准上，Intern-S2-Preview-397B 在 Biology-Instructions 取得 56.92 分，Mol-Instructions 52.37 分，SciReasoner 63.97 分，均优于对比模型。通用基准方面，MMLU-Pro 得分 89.75，SimpleQA-Verified 69.90，MMMU-Pro 80.46，在开源模型中表现领先。

| 基准 | Intern-S2-Preview-397B | 对比模型（最高） |
| :--- | :--- | :--- |
| Biology-Instructions | 56.92 | 50.92 (Qwen3.5-397B) |
| Mol-Instructions | 52.37 | 48.8 (Qwen3.5-397B) |
| SciReasoner | 63.97 | 61.67 (Qwen3.5-397B) |
| MMLU-Pro | 89.75 | 86.6 (Qwen3.5-397B) |

Memory Decoder 在生物学任务中将 Biology-Instructions 平均分从 56.92 提升至 60.32，增幅 6.0%，验证了模块化特化的有效性。自适应长度正则化在保持奖励曲线相当的同时，显著缩短了平均输出长度，表明该方法在不牺牲性能的前提下提升了推理效率。在线投机解码实现了 rollout 生成约 2 倍加速及端到端训练 1.7 倍加速，缓解了长程强化学习中的计算瓶颈。

评估边界方面，论文未报告置信区间，且部分基准如 HLE Bio/Chem 仅展示单一结果，缺乏参照系。代码已开源，但 Memory Decoder 的训练超参数及路由器的具体特征工程细节披露有限，可能影响复现性。此外，实验未涵盖符号回归等可形式化任务，无法直接对比端到端范式与符号回归范式在“发现新定律”上的优劣。

## 关联研究分析

从问题动机看，本文与 Eigen-Agent 均旨在提升领域推理准确性，但路径截然不同。Eigen-Agent 依赖监控式 RAG 在推理时动态注入外部证据，属于非参数化增强；而 Intern-S2-Preview 采用参数化记忆模块，将领域知识压缩至模型内部，避免了推理时的检索延迟与上下文窗口限制。这一差异源于任务特性：Eigen-Agent 侧重高难度领域的即时证据整合，而本文侧重长程任务中的稳定领域能力保持，参数化记忆更适合需要反复调用领域知识的迭代场景。

从方法设计看，本文与 AI Scientist 形成互补而非竞争关系。AI Scientist 是端到端工作流系统，依赖底层模型提供推理与执行能力；Intern-S2-Preview 则是基础模型，提供多模态理解与智能体行为的基础设施。AI Scientist 的瓶颈在于长程错误累积，而本文通过 Partial Rollout 与 GEPO 优化训练稳定性，从模型层面缓解这一问题。然而，本文未探索记忆模块的可解释性，即无法明确区分哪些知识来自记忆、哪些来自骨干，这在科学发现的可证伪性要求下构成潜在盲区。

## 总结

Intern-S2-Preview 旨在解决科学智能体中通用能力与领域特化的冲突，通过冻结骨干附加参数化记忆与专用时序预测分支，实现了模块化扩展。实验表明，该架构在 Biology-Instructions 上提升 6.0 分，MMLU-Pro 达 89.75，验证了模块化特化的有效性。其边界在于缺乏符号回归任务对比，且记忆模块的内部机制不透明。当领域知识更新频率极高时，参数化记忆的压缩效率与检索式增强的时效性孰优孰劣，论文未给出回答。
