# HuggingFace最新推荐论文 ｜Towards a Densing Law for User Representation Learning at Billion-Scale Capacity ｜用户行为致密化定律

研究机构：浙江大学

论文原文见 [arXiv](https://arxiv.org/abs/2608.23392)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.23392)

> 工业级用户表示学习长期依赖扩大用户规模、延长行为窗口或增加模型参数来提升性能，但这一策略在十亿级数据规模下遭遇边际收益急剧递减的瓶颈。现有方法将性能饱和归因于数据总量不足，忽视了行为序列中固有的高冗余特性导致的信息密度瓶颈。本文提出“行为致密化”概念，通过残差量化变长编码（RQ-VAE）动态提升单位输入的信息密度，并推导出数据规模与最小充分量化容量之间的定量关系。该工作揭示了信息密度而非模型容量是核心约束，但其在通用文本数据上的普适性及理论推导的严格性仍存疑。

## 研究背景

工业用户表示学习面临的核心困境是数据量与有效信息量的非同步增长。用户行为日志受日常习惯主导，数据体积随时间线性膨胀，但任务相关的新型信息增长缓慢。这种结构性冗余导致模型在扩大输入规模时，大部分计算资源被用于拟合重复的低价值事件，而非提取可泛化的用户特征。

主流缩放路线沿三个维度扩展：增加用户数量 $N$、延长行为时间跨度 $D$ 以及扩大编码器参数量 $P$。然而，实证研究表明，当用户规模超过 0.03B 或时间窗口超过 60 天时，下游任务性能出现显著饱和。更关键的是，在数据饱和区间内，继续扩大模型容量（如从 0.2B 增至 0.4B 参数）虽能降低预训练损失，但下游准确率几乎不再提升，暴露出“损失-质量解离”现象。这表明传统缩放定律中“数据无限”或“计算受限”的假设在工业行为数据中失效，瓶颈已从资源分配转向输入信号的信噪比。

本文切入点在于重新定义缩放变量：不再单纯关注数据总量，而是关注单位输入携带的任务相关信息密度。通过引入离散化量化机制，将冗长的原始行为序列压缩为紧凑的语义标识符，从而在固定计算预算下最大化有效信号利用率。这一视角将问题从“如何分配更多资源”转化为“如何从有限资源中提取更高密度信息”，为突破工业级表示学习的性能天花板提供了新路径。

## 核心方法

### 方法参照系

本文问题置于“数据受限下的表示优化”框架下，与 LLM 预训练中的“有效数据量”概念同源，但对象从文本 Token 转为行为事件。关键差异在于：LLM 缩放关注连续参数与 Token 数量的幂律关系，而本文关注离散量化配置（码本大小、残差深度）与数据冗余度之间的非线性映射，且目标是最小化容量而非最大化性能。

### 行为致密化与最小充分容量

固定长度量化器（如标准 RQ-VAE）假设所有行为片段具有同等信息复杂度，导致高冗余片段浪费量化容量，而高信息片段容量不足。本文提出“最小充分容量”原则，即量化配置应仅保留足以区分任务相关差异的离散码。为此，定义致密化增益 $\Delta(s) = P_{\text{tok}}(s) - P_{\text{raw}}(s)$，其中 $s$ 为数据规模变量。当原始数据进入边际收益递减区间时，$\Delta(s)$ 由负转正并持续增大，表明量化通过抑制冗余提升了有效信息密度。该机制解决了固定配置在大规模数据下“容量错配”导致的性能饱和问题，使模型在数据冗余主导区间仍能维持性能增长。

### 自适应长度门控网络（ALGN）

固定残差深度无法适应行为序列内部的信息异质性：日常例行行为信息熵低，而突发消费行为信息熵高。ALGN 通过动态门控机制，根据每层量化后的残差范数 $R_l$ 和累积不确定性 $E_l$ 决定是否继续量化。门控概率由下式计算：

$$
g_l = \sigma \left( \text{sp}(w_R)R_l + \text{sp}(w_E)E_l - \text{sp}(w_C)c_l + b \right)
$$

其中 $\text{sp}(\cdot)$ 为 Softplus 函数确保权重非负，$c_l$ 为第 $l$ 层的边际成本。当 $g_l$ 低于阈值 $\theta$ 时停止量化，激活长度 $L_{\text{act}} = \min \{l : g_l \le \theta\}$。该设计解决了固定长度量化器对高熵片段“欠拟合”和对低熵片段“过拟合”的双重失效，通过自适应分配容量，在相同平均 Token 数下实现了更高的下游效用。

## 实验评估

实验基于支付宝生产数据（100M–2B 用户），评估协议包含分类、文本检索和用户到用户检索三类任务，指标为 AUC、KS 和 Accuracy。基线覆盖 VQ-VAE、RQ-VAE、RQ-Kmeans 和 SARQ 四种量化方法，但未对比 LLM 领域的 Chinchilla 最优配置或数据过滤策略，缺乏跨领域基线。

| 方法 | 容量 (%) | AUC (%) | KS (%) | Acc (%) |
| :--- | :--- | :--- | :--- | :--- |
| RQ-VAE | 100.00 | 74.56 | 39.02 | 82.44 |
| VQ-VAE | 316.23 | 73.45 | 37.95 | 82.47 |
| RQ-Kmeans | 100.00 | 73.77 | 38.34 | 82.85 |
| SARQ | 76.24 | 75.36 | 41.28 | 83.16 |
| ALGN | 63.47 | 76.43 | 43.31 | 83.52 |

ALGN 在容量节省 13.23% 的情况下，AUC 比最强基线 SARQ 高 1.07%，KS 高 2.03%。消融实验显示，移除不确定性信号 $E_l$ 导致容量使用率升至 77.83%，AUC 下降 1.32%；移除残差信号 $R_l$ 产生类似退化。正则化消融表明，几何分布先验比随机分布先验在容量使用率降低 6.68% 的同时，AUC 提升 0.27%，验证了长尾行为分布假设的有效性。

评估边界存在明显局限：实验仅在支付宝单一平台数据上进行，未验证跨平台泛化性；指标仅关注下游任务性能，未报告训练稳定性或推理延迟；代码未开源，超参数（如门控阈值 $\theta$、Softplus 权重初始化）细节缺失，可复现性受限。此外，论文未提供置信区间，数值比较的统计显著性未知。

## 关联研究分析

从问题动机看，本文与 LLM 缩放定律中的“数据受限”研究（如 Muennighoff et al., 2023）共享“数据冗余导致性能饱和”的核心洞察，但解法路径截然不同。LLM 领域通过多轮训练和正则化缓解过拟合，而本文通过离散化量化提升信息密度。这一差异源于数据特性：文本 Token 具有语义连续性，重复训练可强化模式；行为事件具有时空离散性，重复输入仅增加噪声。因此，本文的“致密化”策略在行为数据中更优，但在文本数据上是否优于数据过滤策略，论文未给出对比。

从方法设计看，ALGN 的自适应门控机制与 µP（Maximal Update Parametrization）的超参数迁移思想存在结构性相似，均旨在解决规模变化下的配置稳定性问题。但 µP 关注连续参数的谱条件约束，而 ALGN 关注离散码本的激活长度。关键差异在于：µP 假设模型架构固定，仅调整超参数；ALGN 假设数据分布异质，动态调整表示容量。这种差异暗示，ALGN 的有效性依赖于行为序列内部的信息熵分布是否足够非均匀。若行为数据高度均匀（如所有用户行为模式相似），自适应门控的增益可能消失，论文未探索这一边界条件。

## 总结

本文核心矛盾是工业用户表示学习中数据规模扩张与有效信息增长的非同步性，导致传统缩放策略在十亿级规模下失效。现有方法将瓶颈归因于资源不足，而本文抓住“信息密度”这一被忽略的约束，通过自适应量化动态提升单位输入的信噪比。ALGN 方法在支付宝数据上以 63.47% 的容量实现了 76.43% 的 AUC，比最强基线 SARQ 高 1.07% 且容量节省 13.23%。然而，实验仅在单一平台数据上进行，未验证跨领域普适性；理论推导基于局部近似，未提供全局最优性证明。当行为序列的信息熵分布趋于均匀时，自适应门控的边际收益是否递减，论文未给出回答。
