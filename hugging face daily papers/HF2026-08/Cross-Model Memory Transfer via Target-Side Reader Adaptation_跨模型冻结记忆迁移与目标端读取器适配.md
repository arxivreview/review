# HuggingFace最新推荐论文 ｜Cross-Model Memory Transfer via Target-Side Reader Adaptation ｜跨模型冻结记忆迁移与目标端读取器适配

研究机构：芬兰图尔库大学、澳大利亚悉尼科技大学

论文原文见 [arXiv](https://arxiv.org/abs/2608.17050)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.17050)

> 大语言模型的知识存储长期面临非参数化检索延迟高、参数化微调知识耦合权重难以迁移的两难困境。Engram式哈希记忆虽将知识外置为可寻址表格，但其读取器与源骨干深度共适应，导致记忆工件在剥离源模型后是否仍具信息价值存疑。本文提出跨模型冻结记忆迁移协议，通过分词器无关规范化统一地址空间，并仅训练轻量级目标端读取器以提取冻结记忆信号。该工作验证了外部记忆的可移植性，但揭示了读取器设计对迁移性能的决定性作用，其通用性边界尚待更严苛的评估。

## 研究背景

当语言模型需要更新知识时，检索增强生成（RAG）通过外部文档库实现灵活更新，但引入了推理延迟与上下文膨胀；持续预训练或微调将知识写入权重，虽推理高效，却使知识更新、审计及跨骨干迁移变得困难。Engram式哈希记忆（Cheng et al., 2026）试图折中，它将学习到的信息存储在显式、可寻址的外部表格中，并通过小型神经接口而非原始文档注入来消费该表格。然而，这种混合设计暴露了一个核心问题：记忆表格本身是独立的知识基底，还是仅仅是训练它的模型的共适应扩展？若记忆不可移植，它便只是另一种模型特定参数化，而非可复用的知识工件。

现有跨模型迁移研究多聚焦于表示对齐或适配器复用。嵌入空间工作表明独立训练的模型可通过线性映射连接隐藏表示（Mikolov et al., 2013; Kornblith et al., 2019），而Cross-LoRA（Xia et al., 2025）、LoRA-X（Farhadzadeh et al., 2025）等方法证明紧凑适配器或低秩更新可在异构模型间复用。但这些方法均未直接处理冻结外部记忆的复用问题：它们没有独立的记忆表格可供寻址、冻结并在源骨干移除后提取。本文的切入点在于将记忆可移植性转化为一个可测量的提取问题：移除源骨干后，目标模型能否通过新的读取器从冻结记忆中提取有用信号？

## 核心方法

### 方法参照系

本文问题可置于参数高效微调（PEFT）的跨模型迁移框架下，但存在关键差异：传统PEFT迁移的是模型内部权重或适配器参数，而本文迁移的是外部冻结记忆工件。标准流程中，源模型训练记忆表，目标模型直接复用或微调该表；本文则冻结源记忆，仅训练目标端读取器，将迁移问题解耦为地址对齐与值空间投影两个阶段。

### 分词器无关规范化与地址空间统一

设计动机在于解决不同分词器导致同一文本路由到无关记忆槽位的问题，确保目标模型能读取源模型意图的相同记忆条目。本文采用NFKC规范化、小写化及重音剥离处理原始文本，生成规范词元序列，再通过确定性哈希函数 $\phi_{n,k}$ 将n-gram映射到记忆表 $E_{n,k}$ 的固定索引：

$$
e_t \equiv \sum_{n=2}^{N} \sum_{k=1}^{K} E_{n,k}[\phi_{n,k}(g_{t,n})]
$$

该公式表明记忆检索仅依赖规范输入序列而非模型隐藏状态，使记忆表成为独立于骨干的外部工件。通过统一地址空间，本文消除了分词器差异对记忆寻址的干扰，为跨模型迁移奠定基础。

### 轻量级目标端读取器与残差注入

设计动机在于解决源模型读取器与目标骨干隐藏空间不匹配的问题，使目标模型能有效提取冻结记忆信号。本文提出多分支、多层读取器，通过键投影、值投影及上下文感知门控将记忆向量映射到目标残差流：

$$
\alpha_{t,\ell}^{(r)} = \sigma\left( \frac{\text{RMSNorm}(h_{t,\ell})^\top \text{RMSNorm}(k_{t,\ell}^{(r)})}{\sqrt{d_B}} + \beta_{\ell,r} \right), \quad o_{t,\ell} = \sum_{r=1}^{R} \alpha_{t,\ell}^{(r)} \cdot v_{t,\ell}^{(r)}
$$

其中 $h_{t,\ell}$ 为目标模型隐藏状态，$k_{t,\ell}^{(r)}$ 和 $v_{t,\ell}^{(r)}$ 为第 $r$ 个分支的键值投影。该公式通过门控机制动态调节记忆贡献，多层注入提供多次对齐机会，使目标模型能根据上下文选择性提取记忆信息，显著提升了跨模型迁移性能。

## 实验评估

实验在Wikitext-103困惑度及5个QA任务（NQ, WebQA, TriviaQA, TruthQA, HotpotQA）上进行，基线覆盖RAG、kNN、CPT、LoRA及MLP Memory，但缺失RETRO等外部记忆方法对比。主结果显示，跨模型冻结记忆迁移在3×3源-目标矩阵中所有9个单元格均优于无记忆基线，相对困惑度降低达15.7%；在Mistral-7B-v0.3上，最强配置LLaMA {2,10}-R4达到38.5%平均QA准确率，超越MLP Memory的36.1%。

| 方法 | NQ | WebQA | TriviaQA | TruthQA | HotpotQA | Average |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Base | 20.6 | 29.3 | 57.7 | 32.1 | 21.0 | 32.1 |
| MLP Memory | 25.2 | 37.5 | 61.0 | 32.5 | 24.1 | 36.1 |
| LLaMA {2,10}-R4 | 30.3 | 33.7 | 69.9 | 30.9 | 27.6 | 38.5 |
| Engram 30/30 | 30.6 | 33.9 | 70.4 | 31.1 | 27.9 | 38.8 |

消融实验揭示读取器设计是迁移质量的一阶决定因素。单层冻结读取器仅达33.5%平均准确率，训练单层读取器提升至34.2%，而双层注入提升至37.5%，多分支门控进一步达38.5%。参数匹配FFN控制组虽获得最低困惑度（7.4），但QA平均准确率仅34.5%，表明增益并非源于参数增加，而是记忆内容的正确检索与整合。随机记忆控制组困惑度与迁移记忆相同（8.7），但QA准确率降至34.6%，证明内在困惑度无法预测下游任务效用。

评估边界存在局限：QA任务侧重事实检索，TruthfulQA作为校准任务表现负面（-0.2至-0.8点），表明记忆迁移在真实性校准任务上失效；实验未报告计算开销与推理延迟，且缺乏跨模态或更严苛的域外评估。代码已开源，但超参数细节仅在附录中部分披露，可复现性依赖完整实现。

## 关联研究分析

从问题动机看，本文与Cross-LoRA（Xia et al., 2025）均解决跨模型知识迁移，但前者迁移内部适配器权重，后者迁移外部冻结记忆。差异根源在于任务特性：适配器迁移假设源目标模型隐藏空间存在线性可映射性，而记忆迁移需先解决地址空间对齐问题，这要求分词器无关规范化作为前置步骤。本文未探索当源目标模型架构差异极大时，地址对齐是否仍能保证记忆条目语义一致性，这一盲区在异构骨干间迁移时可能成为瓶颈。

从方法设计看，本文与MLP Memory（Wei et al., 2026）同属参数化记忆机制，但后者将记忆层绑定于单一模型，前者将记忆解耦为独立工件。差异源于设计目标：MLP Memory优化单模型知识容量，本文优化跨模型知识复用。本文通过冻结源记忆并仅训练目标端读取器，实现了记忆工件的版本控制与增量更新潜力，但未验证当源记忆更新时，目标端读取器是否需重新训练，这一动态更新机制的缺失限制了其在持续学习场景中的应用。

## 总结

本文要解决的核心矛盾是外部记忆工件的可移植性评估：剥离源骨干后，目标模型能否从冻结记忆中提取有效信号。现有方法将记忆视为模型内部组件，无法分离记忆内容与骨干共适应，而本文通过冻结源记忆、统一地址空间并训练轻量级目标端读取器，将迁移问题转化为可测量的提取任务。实验证明，跨模型冻结记忆迁移在3×3矩阵中所有单元格均优于基线，最强配置达38.8%平均QA准确率，超越MLP Memory。然而，TruthfulQA任务的负面结果及参数匹配FFN控制组的低QA表现，暴露了记忆迁移在真实性校准任务上的失效及内在困惑度与下游效用的脱节。当源记忆内容更新或目标模型架构发生显著变化时，冻结记忆的可移植性边界是否会发生质变，论文未给出回答。
