# HuggingFace最新推荐论文 ｜ReWorld: An Interactive World Model with Long-Horizon Memory ｜混合窗口解耦的流式世界模型

作者：Zhifei Chen、Luozhou Wang、Guibao Shen 等 11 人

论文原文见 [arXiv](https://arxiv.org/abs/2608.23565)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.23565)

> 交互式视频世界模型需在实时响应动作与长时程空间记忆之间保持平衡，但现有方法在联合训练时往往导致控制信号挤占记忆检索空间，或受限于固定注意力窗口无法兼顾两者。ReWorld 指出控制与记忆对注意力窗口的需求存在结构性矛盾，提出通过混合每头注意力窗口与随机头路由解耦两者的训练过程。该方法在固定KV预算下实现了分钟级长时程的空间记忆保持，同时维持了高保真的动作跟随能力，但其评估主要局限于视频生成质量与位姿一致性，缺乏在具身智能任务成功率维度的直接验证。

## 研究背景

自回归视频生成模型在流式推理时，KV缓存随时间线性增长，导致显存耗尽。为限制缓存大小，传统方法采用滑动窗口或全量压缩，但这会丢失远处历史帧的精确位姿信息，使得相机回访同一地点时无法重建一致的视觉内容。解决这一问题的关键在于将空间记忆从时间序列中解耦，使模型能基于相机位姿而非时间距离检索历史内容。

当前交互式世界模型主要沿两条路线演进：一是将相机位姿融入注意力机制（如MRoPE），二是直接注入动作信号。然而，当两者联合训练时，直接动作注入虽提升了控制精度，却显著降低了回访保真度，因为动作信号在共享注意力头中挤占了位姿索引的检索空间。ReWorld的切入点在于识别出控制与记忆对注意力窗口长度的根本性差异：控制仅需短窗口内的当前场景与指令，而记忆检索必须依赖长窗口内的远处内容。

## 核心方法

### 位姿索引与动作注入的双通道架构

ReWorld基于Wan2.2-TI2V-5B骨干，采用因果流匹配扩散Transformer进行块状自回归生成。其核心设计是将位姿条件化与动作控制分离为两个独立通道。位姿通道采用Memory-RoPE（MRoPE），将相机位姿 $P_f \in SE(3)$ 映射为相位偏移 $\delta_f$，直接调制注意力查询与键，使注意力权重取决于位姿差异而非时间距离：

$$ \langle \tilde{q}, \tilde{k} \rangle \propto e^{i(\delta_f(q) - \delta_f(k))} $$

该公式意味着相似视角的帧在注意力图中被拉近，无论其时间间隔多远。动作通道则通过Plücker射线图将指令位姿展开为6维坐标，经MLP投影后加到补丁嵌入上，明确告知每个token相机应看向何处。这种分离确保了位姿索引负责“找到”历史内容，而动作注入负责“执行”当前指令，避免了单一通道中的信号竞争。

### 混合窗口训练与随机头路由

为解决控制与记忆对窗口长度的不同需求，ReWorld将每层24个注意力头划分为18个局部头和6个全局头。局部头仅关注最近12个潜在帧（3个块），用于学习短窗口内的控制响应；全局头关注整个因果历史，用于学习长时程记忆检索。关键创新在于随机头路由：每步优化从12个随机划分的池子中切换全局头集合，确保每个头在不同步长下既充当局部头也充当全局头。这一设计防止了能力绑定到特定头，使得在推理时无论缓存策略如何变化，所有头都能在短窗口内完成控制任务，从而保证了控制误差的稳定性。

### 地标整合与块丢弃训练

推理时，ReWorld维护一个固定预算 $B=12$ 的缓存，包含一个锚点块、5个最近块和6个检索地标。当地标库满时，新块仅当相机自上次存储地标后移动了足够距离（里程计规则）才被存入，否则丢弃；若库已满，则驱逐空间冗余度最高的成员。为弥合训练时连续前缀与推理时稀疏非连续缓存的分布差异，ReWorld引入块丢弃训练：每步随机保留12个块中的6个，强制模型从不完整记忆中重建场景状态，使稀疏缓存成为分布内数据。

## 实验评估

ReWorld在自建八源混合数据集（包含UE渲染、DL3DV、RealEstate10K等）上训练，对比了HY-World 1.5、E-PRoPE等位姿条件化方法。实验协议涵盖动作跟随、长时程召回和视频质量三个维度。在动作跟随指标上，ReWorld取得了11.95°的旋转误差，优于所有对比基线，表明其双通道架构有效提升了控制精度。在长时程召回测试中，在64秒（384个潜在帧）的往返滚动中，ReWorld的固定12块缓存仍能重新生成起始视图，而滑动窗口基线在此长度下已丢失证据，全量KV注意力则因显存不足无法运行。

消融实验验证了混合窗口训练的有效性：移除随机头路由后，控制误差随缓存压缩策略的变化而波动，证实了路由对控制稳定性的关键作用。块丢弃训练显著减少了稀疏缓存下的模糊与漂移现象，表明该增强策略成功弥合了训练-测试分布差异。然而，论文未提供与LIBERO或Minecraft等具身智能基准的直接对比，其视频生成指标的高分是否能转化为机器人操作任务的成功率提升，仍缺乏直接证据。

评估边界方面，ReWorld的指标侧重于视频生成质量与位姿一致性，未涵盖物理合理性或策略评估维度。可复现性方面，论文提供了项目网站链接，但未明确公开代码仓库URL，且八源数据管线中的UE渲染部分依赖特定引擎配置，可能限制外部复现。

## 关联研究分析

从问题动机看，ReWorld与AlayaWorld均关注长时程记忆，但AlayaWorld依赖外部记忆库检索，而ReWorld通过地标整合在固定KV预算内实现记忆保持。这一差异源于ReWorld对实时性与显存约束的更严格考量，其地标库的里程计规则确保了存储多样性，避免了外部记忆库可能带来的检索延迟。相比之下，LongScape侧重MoE架构提升计算效率，而ReWorld侧重注意力窗口拆分，两者在解决长时程一致性问题上采取了不同的技术路径。

从方法设计看，ReWorld与GameNGen同属动作条件化范式，但GameNGen主要关注实时交互引擎的构建，缺乏长时程空间记忆机制。ReWorld的创新在于将位姿索引与动作注入解耦，并通过混合窗口训练解决两者的训练冲突。这一设计是否导致局部头在极端长序列下的泛化能力下降，论文未给出回答，因为实验最长仅覆盖64秒滚动，未测试更长时间尺度下的性能衰减。

## 总结

ReWorld解决了交互式世界模型中控制与记忆对注意力窗口需求的结构性矛盾，通过混合窗口训练与随机头路由解耦两者的学习过程，并在固定KV预算下实现了长时程空间记忆保持。该方法在64秒滚动中维持了起始视图的重建能力，同时取得了11.95°的旋转误差，证明了其控制与记忆解耦的有效性。然而，其评估局限于视频生成质量与位姿一致性，未验证在具身智能任务中的实际表现。当滚动长度超过分钟级时，地标库的冗余驱逐策略是否仍能保持足够的空间覆盖，论文未给出回答。
