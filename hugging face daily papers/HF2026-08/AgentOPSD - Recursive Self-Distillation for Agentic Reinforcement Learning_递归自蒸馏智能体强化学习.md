> 长程多轮交互中，稀疏的轨迹级奖励无法区分关键决策与冗余操作，导致策略优化信号被稀释。现有方法要么均匀广播优势，要么孤立处理单步信号，均忽略了历史交互对当前决策权重的累积影响。AgentOPSD 将自蒸馏差距转化为贝叶斯信念更新，通过递归修正轨迹成功概率来重塑回合级信用。该方法在无需额外采样或Critic网络的情况下提升了长程任务性能，但其依赖特权技能检索的假设限制了其在无先验知识场景下的泛化能力。

## 研究背景

当智能体在部分可观测环境中执行多步任务时，环境仅在轨迹终止时提供二元奖励。这种稀疏反馈迫使算法从单一结果推断中间步骤的贡献，但轨迹内的动作角色差异巨大：成功轨迹可能包含误导操作，失败轨迹也可能蕴含有效推理。Group Relative Policy Optimization (GRPO) 通过组内相对优势估计解决了价值函数估计的偏差问题，但其将序列级优势均匀广播至所有Token，无法区分关键决策与常规操作。随着交互步长增加，这种均匀信用分配导致长程任务中的信号稀释，成为制约智能体泛化能力的核心瓶颈。

现有解决方案主要分为两类：一类是引入过程奖励模型或树搜索结构，通过外部监督细化信用分配，但增加了计算开销或依赖额外数据；另一类是引入自蒸馏信号，利用特权信息提供的教师-学生差距作为密集监督。然而，自蒸馏信号本质上是Token级的局部对比，与智能体交互的回合边界不对齐，且现有方法孤立处理每个回合，未考虑前序交互积累的上下文证据。AgentOPSD 的切入点在于，将局部自蒸馏差距解释为对轨迹成功概率的贝叶斯证据，通过递归信念更新将孤立信号转化为依赖历史的回合级信用，从而在不增加采样成本的前提下实现细粒度归因。

## 核心方法

### 方法参照系

本文问题属于信用分配机制类别。标准GRPO流程计算组内相对优势 $A_{seq}^{(i)} = \frac{R^{(i)} - \bar{R}}{\sigma_R + \epsilon_0}$ 并广播至轨迹内所有Token。本文的关键差异在于，不直接使用该序列级优势，而是将其作为全局方向，通过引入回合级信念状态重塑其在轨迹内的分布，解决均匀广播导致的信号稀释问题。

### 回合级证据聚合

设计动机在于解决自蒸馏Token级信号与智能体交互回合边界的错位。通常做法是将教师-学生差距直接作为辅助损失，但本文将其聚合为回合级证据。对于回合 $k$，定义特权技能条件化上下文 $h^+_{k,t}$ 与标准上下文 $h_{k,t}$ 的Log-Probability差距 $\delta_{k,t} = \log \pi_\theta(y_{k,t} | h^+_{k,t}) - \log \pi_\theta(y_{k,t} | h_{k,t})$。回合级证据 $e_k$ 为该回合内所有Token差距之和：

$$ e_k = \sum_{t=1}^{L_k} \delta_{k,t} = \log \frac{\pi_\theta(a_k | s_k, c^+)}{\pi_\theta(a_k | s_k)} $$

该公式表明，$e_k$ 是动作 $a_k$ 在成功关联行为与背景行为下的似然比，其符号指示该动作是否支持最终成功，实现了从Token级局部信号到回合级环境对齐证据的转换。

### 递归信念更新与优势重塑

设计动机在于解决孤立回合信号无法反映历史累积影响的问题。通常做法是独立评估每个回合的贡献，但本文引入递归信念状态 $B_k$ 来量化轨迹成功概率。信念状态在Log-Odds空间递归更新：

$$ \ell_k = \text{logit}(B_0) + \sum_{j=1}^k \gamma^{k-j} e_j, \quad B_k = \sigma(\ell_k) $$

其中 $B_0$ 初始化为组内成功率，$\gamma$ 为衰减因子。回合 $k$ 的信用定义为信念状态的边际修正 $\Delta B_k = B_k - B_{k-1}$。最终，通过标准化 $\Delta B_k$ 并施加有界乘子 $w_k$，重塑序列级优势：

$$ \tilde{A}_k^{(i)} = A_{seq}^{(i)} \left[ (1-\lambda) + \lambda w_k \right] $$

该机制使得关键决策（信念修正大且与结果一致）获得更高权重，而冗余操作（信念修正小或矛盾）被抑制，实现了信用在轨迹内的动态重分配。

## 实验评估

实验在ALFWorld、WebShop和Search-QA三个交互环境中进行，使用Qwen2.5-3B/7B-Instruct模型，对比GRPO、Skill-GRPO、OPSD、SDAR等基线。基线覆盖了无训练、组相对RL和自蒸馏RL三类路线，但缺失Tree-GRPO等树搜索类强基线，可能低估了结构化搜索方法的竞争力。

| 方法 | ALFWorld (7B) | WebShop (7B) | Search-QA (7B) |
| :--- | :--- | :--- | :--- |
| GRPO | 81.2 | 80.9 | 42.0 |
| SDAR | 82.8 | 89.4 | 49.0 |
| AgentOPSD | 89.1 | 90.2 | 49.2 |

AgentOPSD在ALFWorld上较GRPO提升7.9个百分点，在WebShop上较SDAR提升0.8个百分点，在Search-QA上较SDAR提升0.2个百分点。增益在长程任务（ALFWorld）上最为显著，而在短程任务（Search-QA）上趋于饱和，验证了方法针对长程信用分配的设计初衷。

| 消融组件 | ALFWorld (7B) |
| :--- | :--- |
| AgentOPSD (Full) | 89.1 |
| Per-token accumulation | 85.9 |
| Raw local gap $e_k$ | 82.8 |
| Magnitude only $|\Delta B_k|$ | 80.5 |
| Drop prior $B_0$ | 78.9 |

消融实验显示，移除递归信念更新（使用原始局部差距 $e_k$）导致性能下降6.3个百分点，移除符号方向（仅使用幅度）下降8.6个百分点，移除先验锚定 $B_0$ 下降10.2个百分点。这表明信念递归、结果对齐符号和先验初始化是性能增益的三个关键支柱，其中先验锚定对稳定早期信念修正至关重要。

评估边界方面，论文未报告置信区间，数值比较需谨慎。超参数敏感性分析显示，衰减因子 $\gamma$ 在0.8至1.0范围内性能波动小于5个百分点，重塑权重 $\lambda$ 在0.1至0.5范围内影响显著，表明方法对 $\lambda$ 较为敏感。代码已开源，但特权技能检索依赖SkillRL的SkillBank，限制了在无预训练技能库场景下的可复现性。

## 关联研究分析

从问题动机看，AgentOPSD与Tree-GRPO均致力于解决稀疏奖励下的信用分配，但路线截然不同。Tree-GRPO通过扩展采样空间引入树搜索结构，以计算开销换取细粒度归因；AgentOPSD则通过信念更新在现有采样框架内重塑优势分布，以算法复杂度换取归因精度。这种差异源于任务特性：Tree-GRPO适用于分支决策明显的任务，而AgentOPSD适用于线性交互序列。AgentOPSD未探索动态调整衰减因子 $\gamma$ 的机制，其在不同任务复杂度下的自适应能力尚不明确。

从方法设计看，AgentOPSD与SDAR同属自蒸馏RL框架，但信号利用方式存在本质差异。SDAR将教师-学生差距作为门控或辅助损失，孤立处理每个Token；AgentOPSD将其转化为贝叶斯证据，通过递归信念更新实现历史依赖的信用分配。这一差异解决了SDAR在长程任务中信号稀释的问题，但引入了对特权技能质量的依赖。AgentOPSD未分析技能检索错误对信念更新的影响，其在技能库覆盖不全场景下的鲁棒性有待验证。

## 总结

AgentOPSD针对长程智能体RL中稀疏奖励导致的信用分配难题，抓住了局部自蒸馏信号缺乏历史依赖这一被忽略的点。通过贝叶斯信念更新将Token级差距转化为回合级信用，该方法在无需额外采样或Critic网络的前提下，实现了ALFWorld 89.1%的成功率，较GRPO提升7.9个百分点。其边界在于依赖特权技能检索的假设，且超参数 $\lambda$ 的敏感性限制了其在不同任务间的迁移能力。当技能库覆盖不全或任务分支结构复杂时，信念更新的准确性是否会显著下降，论文未给出回答。
