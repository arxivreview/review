> 导读 交互式视频世界模型旨在构建能够感知、交互并预测物理世界演化的内部模拟器，其核心价值在于弥合被动视频生成与主动具身智能之间的鸿沟。现有视频生成式世界动作模型（WAMs）在视觉分布偏移下易产生训练分布幻觉，导致动作预测失效。本文通过引入 DINOv3 语义特征作为未来预测与历史检索的双通道表示，构建了无需额外具身预训练的鲁棒 WAM。该方案在零样本鲁棒性上显著优于纯 VAE 基线，但其对复杂长时程几何一致性的贡献尚待验证。

## 研究背景

当机器人执行操作任务时，当前观测往往包含背景纹理、光照等与任务无关的视觉噪声。若策略直接映射当前观测到动作，这些噪声会干扰决策。世界动作模型（WAMs）通过联合建模未来视觉状态与机器人动作，试图从视频预训练中获取世界动态先验，从而解耦动作相关动态与无关视觉因素。然而，主流 WAMs 依赖 VAE 潜空间进行未来预测，该表示主要优化视觉重建，容易将动作相关状态转移与任务无关或幻觉视觉内容纠缠在一起。

现有方案在应对视觉分布偏移时存在明显瓶颈。Fast-WAM 等纯 VAE 方法在 LIBERO-Plus 零样本测试中成功率从 97.6% 骤降至 51.5%，暴露出对低层视觉线索的过度依赖。LaWAM 等方法虽引入 DINO 特征，但依赖大规模具身预训练和多阶段训练，增加了部署复杂度。本文切入点在于识别出“训练分布幻觉”现象，即模型在视觉偏移下预测未来时回归训练域内容而非当前场景，并提出一种无需额外预训练、直接利用原始观测提取语义表示的端到端解决方案。

## 核心方法

### 方法参照系

本文问题属于具身智能中的动作条件化视频生成范畴，标准流程通常采用 DiT 架构结合 Flow Matching 训练。与通用流程的关键差异在于，本文未采用物理引擎或 DPO 后训练来约束物理合理性，而是通过引入 DINOv3 语义空间作为辅助预测目标，解决视觉偏移下的鲁棒性问题。

### 双空间未来专家（DSFE）

DSFE 在 VAE 潜空间和 DINO 特征空间中联合建模未来状态。设计动机是解决纯 VAE 表示在视觉偏移下将动作相关动态与无关视觉内容纠缠的问题。具体而言，冻结的 Wan2.2 VAE 编码视觉潜变量 $z_v$，冻结的 DINOv3 编码器提取语义特征 $z_s$。两个未来 DiT 分支与动作 DiT 分支构成三分支 Mixture-of-Transformers，通过层间混合注意力实现跨空间互精炼。训练时，三个专家联合去噪未来 VAE 潜变量、未来 DINO 特征和动作 token，损失函数为：

$$L = \lambda_v L_v + \lambda_s L_s + \lambda_a L_a$$

其中 $L_v, L_s, L_a$ 分别为视觉、语义和动作专家的 Flow Matching 损失。该设计使模型同时保留细粒度视觉动态和视觉稳定的语义转移，避免了单一表示在分布偏移下的失效。

### 当前锚定意图检索（CAIR）

CAIR 从近期 DINO 历史中检索任务相关证据，设计动机是解决视觉偏移下当前帧线索不可靠的问题。给定当前观测 $o_t$ 和指令 $\ell$，冻结的 Qwen3-VL 模型提取多模态隐状态，通过可学习查询生成当前语义 token $U_t^0$。随后，CAIR 应用 $L$ 个交叉注意力块，以当前语义 token 为查询，以 DINO 历史 token $R_t$ 为键和值，选择性检索与当前任务状态相关的历史证据。最终意图 token $I_t$ 仅注入动作专家，通过动作 Flow Matching 端到端优化。该机制使动作生成能够利用近期任务进展的语义证据，而不受当前帧视觉噪声的干扰。

## 实验评估

实验在 LIBERO、LIBERO-Plus、RoboTwin 2.0 及真实世界任务上进行。基线覆盖 VLA（π0）、视频 WAM（Fast-WAM, Motus）及替代表示方法（LaWAM）。在 LIBERO 分布内测试中，ST-WAM 平均成功率达 98.7%，高于 Fast-WAM 的 97.6% 和 LingBot-VA 的 98.5%。在 LIBERO-Plus 零样本鲁棒性测试中，ST-WAM 整体成功率为 72.8%，较 Fast-WAM 的 51.5% 提升 21.3 个百分点，且在相机和传感器噪声扰动下分别提升 39.0 和 41.8 个百分点。

| 方法 | LIBERO Avg. (%) | LIBERO-Plus Overall (%) | RoboTwin 2.0 Avg. (%) |
| :--- | :--- | :--- | :--- |
| Fast-WAM | 97.6 | 51.5 | 91.83 |
| LingBot-VA | 98.5 | — | 92.20 |
| LaWAM | 98.6 | — | 91.22 |
| ST-WAM | 98.7 | 72.8 | 92.77 |

消融实验表明，移除语义未来专家使 LIBERO-Plus 成功率降至 63.5%，移除 CAIR 降至 43.7%，证明双空间预测和历史检索对鲁棒性的独立贡献。在真实世界评估中，ST-WAM 在视觉分布偏移下成功率为 61.5%，而 Fast-WAM 仅为 25.8%，降幅从 38.9 个百分点缩小至 17.8 个百分点。

评估边界方面，论文未报告置信区间，数值比较需谨慎。推理效率上，ST-WAM 在 A100 GPU 上生成 32 步动作块耗时 756.17 ms，较 Fast-WAM 的 609.30 ms 增加 1.24 倍，但仍保持亚秒级推理。代码未明确开源，超参数如损失权重 $(\lambda_v, \lambda_s, \lambda_a) = (1.0, 0.02, 1.0)$ 已披露。

## 关联研究分析

从问题动机看，ST-WAM 与 LaWAM 均使用 DINO 特征，但 LaWAM 依赖大规模具身预训练，而 ST-WAM 证明无需预训练即可实现类似鲁棒性。这一差异源于 ST-WAM 将 DINO 特征同时用于未来预测和历史检索，形成了闭环的语义-时间建模，而非仅作为辅助监督信号。从方法设计看，ST-WAM 与 Fast-WAM 共享 DiT 架构和 Flow Matching 训练，但 Fast-WAM 仅依赖 VAE 潜空间，导致其在视觉偏移下产生训练分布幻觉。ST-WAM 通过引入 DINO 语义空间，解耦了动作相关动态与无关视觉内容，从而在零样本鲁棒性上取得显著优势。

## 总结

ST-WAM 旨在解决视频生成式 WAMs 在视觉分布偏移下的鲁棒性问题，其切入点在于识别出训练分布幻觉现象，并利用 DINOv3 语义特征作为未来预测与历史检索的双通道表示。通过双空间未来专家和当前锚定意图检索，ST-WAM 在无需额外具身预训练的情况下，实现了 LIBERO-Plus 零样本成功率 72.8% 和真实世界偏移下成功率 61.5% 的性能。然而，论文未评估长时程几何一致性，且推理延迟较基线增加 1.24 倍。当支持集增大到 5-shot 时，CAIR 的边际收益是否递减，论文未给出回答。
