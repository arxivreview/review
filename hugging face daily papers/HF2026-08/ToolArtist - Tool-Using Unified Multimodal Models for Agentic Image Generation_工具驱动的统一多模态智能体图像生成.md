> 开放世界图像生成要求模型在缺乏完整提示词信息时，主动获取外部知识以修正事实错误，但现有智能体框架将推理、搜索与生成割裂为固定流水线或委托外部执行器，导致策略无法闭环。本文提出 ToolArtist，将工具调用与原生图像生成统一于单一自回归策略中，通过教师轨迹转换与双奖励强化学习实现端到端自主决策。该范式在知识密集型基准上超越了部分智能体基线，但其对自回归视觉保真度的依赖及搜索依赖的鲁棒性仍存疑。

## 研究背景

当用户指令涉及长尾文化或实时地理知识时，静态参数化的文本到图像模型（T2I）常因知识缺失生成视觉逼真但事实错误的图像。解决此问题需引入智能体机制，但传统方案要么预设“搜索-生成”固定顺序，要么仅优化提示词后交由外部生成器执行。这种割裂导致模型无法根据生成结果反馈动态调整搜索策略，也无法在单一策略内协调推理、工具使用与像素合成。

统一多模态模型（UMM）如 Emu3.5 将文本与图像统一为离散 Token 序列，为单一策略控制多模态动作提供了架构基础。然而，现有 UMM 后训练多聚焦于静态生成，缺乏与开放环境交互的动态决策能力。本文切入点在于将图像生成本身视为智能体策略的一个原生动作，而非外部工具调用，从而在单一策略中实现从知识缺口识别到视觉输出的完整闭环。

## 核心方法

### 方法参照系

本文问题可置于 ReAct 范式下的多模态智能体框架中。标准流程中，智能体通过交替执行推理与工具调用获取信息，最终输出文本答案。关键差异在于，本文将“图像生成”从外部工具调用转化为策略内部的原生动作，要求模型在自回归序列中直接输出视觉 Token，而非调用外部扩散模型。

### 轨迹转换与策略掩码

SFT 阶段的核心在于将教师代理生成的含外部生成器调用的轨迹，转换为 UMM 可学习的原生格式。教师代理使用 Gemini-3-pro-image-preview 生成图像，转换器将外部生成步骤重写为视觉标题跨度（visual-caption span）与视觉 Token 跨度（visual-token span）。训练时引入策略支持掩码 $M_{i,j} = \mathbb{I}[u_{i,j} \in \mathcal{T}_i]$，其中 $\mathcal{T}_i$ 为策略生成的推理与动作 Token 集合。该掩码确保损失函数仅优化模型自主生成的部分，排除用户指令与环境返回的观察值，使模型学习完整的“推理-搜索-生成”决策链，而非单纯模仿搜索行为。

### RAD-GRPO 双奖励优化

SFT 受限于合成数据覆盖度，无法发现更优策略。RAD-GRPO 通过在线交互优化完整轨迹，引入意图奖励 $R^I_i$ 与质量奖励 $R^Q_i$ 的组合目标：

$$ R_i = \alpha R^I_i + (1-\alpha) R^Q_i $$

其中 $\alpha=0.5$。$R^I_i$ 评估最终视觉标题是否充分转化了用户请求与证据，$R^Q_i$ 由世界知识奖励模型评估图像在忠实度、视觉正确性、文本准确性与美学上的表现（权重分别为 0.1, 0.4, 0.4, 0.1）。该设计将结果级反馈传播至推理、工具使用与生成全过程，解决了 SFT 中策略无法根据生成质量动态调整搜索行为的问题。

## 实验评估

实验在 WISE（1000 提示词，25 子域）与 WorldGenBench-Humanities（732 提示词，244 地区）上进行。基线覆盖前沿专有模型（Nano Banana）、通用生成模型（FLUX.1-dev）、UMM（BAGEL, Emu3.5）及智能体模型（Unify-Agent, GenSearcher）。ToolArtist 在 WISE 上取得 0.79 平均分，优于 Unify-Agent 的 0.77 与 GenSearcher 的 0.77；在 WorldGenBench-Humanities 上取得 22.10 平均分，显著优于 Unify-Agent 的 15.58。

| 方法 | WISE Avg. | WorldGenBench-Humanities Avg. |
| --- | --- | --- |
| ToolArtist | 0.79 | 22.10 |
| Unify-Agent | 0.77 | 15.58 |
| GenSearcher-Qwen-Image | 0.77 | 13.66 |
| BAGEL+CoT | 0.70 | 12.09 |
| FLUX.1-dev | 0.50 | 9.36 |

消融实验显示，移除图像搜索中的源感知摘要（source-aware summaries）导致文化类任务得分下降，表明结构化证据对事实正确性至关重要。SFT 语料包含 7,132 条轨迹，平均长度 20.5k Token，平均工具调用 4.0 次，验证了多轮交互的必要性。

评估边界方面，WISE 使用 LLM-as-judge 协议，可能存在评估偏差；WorldGenBench 依赖人工构建的知识清单，覆盖度有限。论文未报告计算效率指标，且 RL 训练依赖在线搜索，实际部署延迟未量化。代码与数据已开源，但 RL 基础设施的复现门槛较高。

## 关联研究分析

从问题动机看，ToolArtist 与 Unify-Agent 均针对开放世界知识缺失，但 Unify-Agent 将生成委托给外部模型，导致策略无法根据生成结果反馈调整搜索。ToolArtist 将生成内化为原生动作，使模型能检查当前结果并迭代修正，这一差异源于任务特性：知识密集型生成需要视觉反馈闭环，而纯提示词优化无法提供像素级纠错能力。

从方法设计看，ToolArtist 与 BAGEL+CoT 同属 UMM 后训练，但 BAGEL+CoT 仅引入思维链推理，未涉及外部工具调用。ToolArtist 通过 RAD-GRPO 优化完整轨迹，将搜索行为纳入策略优化范围，解决了静态推理无法获取实时或长尾知识的问题。然而，ToolArtist 依赖自回归视觉 Token 生成，其视觉保真度上限可能低于专用扩散模型，这一权衡在 WISE 物理类任务（0.81）与专有模型（0.86）的差距中有所体现。

## 总结

ToolArtist 解决了开放世界图像生成中推理、搜索与生成割裂的核心矛盾，通过将图像生成内化为 UMM 原生动作，实现了单一策略下的端到端自主决策。在 WISE 上 0.79 与 WorldGenBench-Humanities 上 22.10 的结果验证了完全智能体范式在知识密集型任务上的有效性。其边界在于依赖自回归视觉生成，视觉保真度上限受限于 UMM 架构，且 RL 训练依赖在线搜索，实际部署的延迟与稳定性未充分验证。当搜索工具返回噪声或冲突信息时，策略能否通过迭代生成有效过滤错误证据，论文未给出回答。
