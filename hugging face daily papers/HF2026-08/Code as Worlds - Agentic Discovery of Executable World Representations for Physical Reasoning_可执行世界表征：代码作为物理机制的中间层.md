> 物理智能的核心在于从视觉流中解耦出内在动力学参数，而非仅描述表面现象。现有像素级生成与3D重建方法虽能复现外观，却因缺乏显式因果结构而无法支持定量推理与干预预测。本文提出Code-as-World范式，将物理世界编码为可执行代码，通过“假设-执行-验证”的代理循环从观测中逆向推断机制。该范式在QuantiPhy基准上超越了更大规模的专有模型，但其有效性高度依赖模拟器的物理保真度，且未解决非刚体场景下的表征泛化问题。

## 研究背景

当视觉语言模型（VLMs）面对视频中的物体运动时，其训练数据缺乏显式物理标签，导致模型难以从像素中准确估计速度、加速度等定量属性。这一困境源于逆物理推断的病态性：单帧或短序列信息不足，使得从视觉线索解耦内在物理属性成为计算昂贵且不稳定的过程。为突破此瓶颈，研究需引入显式物理监督或交互式经验，以弥补纯数据驱动学习的缺陷。

物理基础视觉推理领域正从定性违规检测转向定量参数估计，主流路线包括基于3D高斯溅射（3DGS）的可微仿真与基于强化学习的交互式智能体。然而，3DGS等隐式场表征虽能恢复几何结构，却将物理参数与外观因素纠缠在一起，无法解释物体为何以特定方式运动；交互式方法虽能习得规则，但依赖真实环境反馈，数据收集成本高且奖励稀疏。Code-as-World的切入点在于将物理世界表征为可执行代码，利用代码的结构化与可编辑性，将逆物理推断转化为可验证的假设搜索过程，从而在保持定量精度的同时提供机制可解释性。

## 核心方法

### 方法参照系

传统物理世界模型构建遵循“重建-仿真-预测”流程，即先通过神经辐射场（NeRF）或3DGS恢复场景几何，再在物理引擎中运行仿真以预测未来状态。本文的关键差异在于摒弃了端到端的参数回归，转而将世界表征定义为包含物理组成、动态演化与视觉外观的可执行代码，并通过代理循环迭代优化该代码，而非直接优化隐式场参数。

### 可执行世界表征 (EWR)

EWR将物理世界解耦为三个正交组件：物理组成 $C$、动态演化 $E$ 与视觉外观 $A$，构成完整的世界假设 $p = (C, E, A) \in \mathcal{P}_{exec}$。

$$
p = (C, E, A) \in \mathcal{P}_{exec}
$$

其中 $C$ 定义物体几何、质量、摩擦等静态属性，$E$ 描述初始状态与时间演化，$A$ 控制相机与渲染参数。这一设计解决了3DGS中几何与物理参数纠缠的问题，使得每个物理量均可独立编辑与验证，为后续机制推理提供了结构化基础。

### 代理发现循环 (Agentic Discovery Loop)

该循环通过LLM代理执行“提议-实例化-执行-渲染-验证”迭代，将逆物理推断转化为假设搜索。

$$
\Delta_k = \bigcup_{f \in F} \text{CompareAndDiagnose}(A, \hat{\eta}[f], \eta)
$$

其中 $\Delta_k$ 为第 $k$ 轮验证产生的误差诊断集合，$\hat{\eta}$ 为模拟器渲染的观测，$\eta$ 为真实证据。代理根据 $\Delta_k$ 修正代码假设 $p$，直至误差收敛或达到迭代上限 $K$。这一机制克服了单次预测在噪声观测下的不稳定性，通过闭环反馈逐步逼近物理一致的世界表征，实现了从静态观察到动态机制推断的跨越。

## 实验评估

实验在QuantiPhy基准上评估定量物理推理能力，对比基线包括Gemini-3.1-Flash、Qwen3.5等专有VLM，但缺失3DGS/NeRF类重建基线，导致无法直接对比3D显式表征路线的性能。

| 方法 | 规模 | QuantiPhy MRA (%) |
| :--- | :--- | :--- |
| Code-as-World-VL | 9B | 50.6 |
| Qwen3.5 | 4B | 31.2 |
| SmolVLM | - | 26.8 |
| Qwen3-VL | 2B | 27.2 |
| Qwen3.5 | 2B | 25.6 |
| InternVL 3.5 | 2B | 24.3 |
| Phi-3 Mini | - | 17.1 |

Code-as-World-VL-9B以50.6%的MRA显著优于同规模及更小规模的开源模型，但低于据领域综述所述的ChatGPT-5.1（53.1%）与人类基线（55.6%），表明其虽超越多数开源VLM，仍未达到专有模型SOTA水平。

在代理发现循环的消融实验中，论文报告了不同迭代轮次 $K$ 对视频重建指标的影响，但未提供具体数值表格，仅定性指出迭代优化优于单次生成与Best-of-5采样。这一缺失使得无法量化迭代次数对收敛速度与精度的边际收益，限制了对其计算效率的评估。

评估边界方面，论文未报告置信区间，且QuantiPhy基准主要关注刚体运动，未涵盖非刚体变形或复杂流体场景。代码开源（github.com/mirros-lab/code-as-world）提供了可复现性基础，但模拟器配置与LLM代理的具体超参数未在正文中详细披露，可能影响结果的可复现性。

## 关联研究分析

从方法设计看，Code-as-World与PhysiFormer均追求3D状态空间预测，但PhysiFormer依赖扩散Transformer学习顶点位置与速度的随机过程，而本文采用代码执行作为确定性机制验证。这一差异源于任务目标的不同：PhysiFormer侧重生成物理一致的视频，而Code-as-World侧重从观测中逆向推断物理参数。代码表征的离散性与可编辑性使其更适合参数估计，但可能牺牲了连续动力学建模的灵活性，尤其是在非刚体场景中。

从问题动机看，Code-as-World与IPR-1均强调交互学习，但IPR-1依赖真实环境反馈，而本文依赖模拟器反馈。这一选择降低了数据收集成本，但引入了模拟器与真实物理之间的领域差距。当真实场景中的摩擦、碰撞等参数超出模拟器建模范围时，代理循环可能收敛到局部可解但机制错误的表征。这种对模拟器保真度的依赖，是本文与基于真实交互的方法在泛化性上的根本差异，也是其应用边界的关键限制。

## 总结

Code-as-World旨在解决VLMs在定量物理推理中的机制缺失问题，通过可执行代码将逆物理推断转化为可验证的假设搜索。其核心创新在于利用代码的结构化特性解耦物理参数与外观，并通过代理循环实现闭环优化。实验表明，该方法在QuantiPhy基准上以50.6%的MRA超越了多数开源VLM，证明了代码表征在定量推理中的有效性。然而，其性能仍低于专有模型SOTA，且高度依赖模拟器的物理保真度，在非刚体或复杂场景中可能失效。当真实物理过程超出模拟器建模范围时，代理循环能否通过误差诊断自动识别并修正机制错误，而非收敛到局部可解的伪表征，是决定其泛化能力的关键问题。
