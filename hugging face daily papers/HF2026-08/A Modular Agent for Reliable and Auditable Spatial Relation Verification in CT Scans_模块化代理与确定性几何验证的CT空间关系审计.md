# HuggingFace最新推荐论文 ｜A Modular Agent for Reliable and Auditable Spatial Relation Verification in CT Scans ｜模块化代理与确定性几何验证的CT空间关系审计

研究机构：德国慕尼黑工业大学

作者：Simon Vincent Abel、Heiko Hillenhagen、Michael Götz 等 6 人

论文原文见 [arXiv](https://arxiv.org/abs/2608.21140)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.21140)

> 医学影像中的空间描述若无法追溯至像素证据，将直接导致临床误诊，而现有视觉-语言模型（VLMs）在受控空间任务上表现接近随机且缺乏可解释性。本文切入点在于将黑盒预测解耦为可审计的模块化流程，通过外部检测器与确定性规则替代神经网络的隐式空间推理。该方法在MIRP基准上实现了94.1%的准确率，显著优于端到端基线，但其有效性严格依赖于检测器的定位精度，且仅覆盖2D轴向切片的二元关系，未解决体积推理与复杂拓扑问题。

## 研究背景

医学影像报告要求对解剖结构的位置与关系进行精确描述，空间语言是放射学报告的核心组件。然而，当前VLMs在处理左右、上下等基础空间概念时存在系统性缺陷，在受控医学空间推理任务中，代表性强模型的表现接近随机水平。这种缺陷不仅源于视觉编码器中空间信号的分布式特性，更源于语言骨干对统计规律的过度依赖，导致模型产生与图像证据矛盾的空间幻觉。

空间推理是VLMs迈向具身智能与临床部署的核心瓶颈。主流路线包括显式几何接地（如GeoWeaver通过注入几何令牌）与隐式多任务学习，前者在复杂3D任务上表现鲁棒，后者计算效率占优但缺乏硬约束。然而，这些通用方法均将空间推理视为端到端的黑盒预测，无法提供可验证的中间证据。在临床场景中，一个“看似合理”但无法追溯至像素坐标的答案是不可接受的。本文针对这一“可审计性”缺失，提出将空间验证从VLM内部剥离，交由专用工具执行，从而将范式从黑盒预测转向过程可审计。

## 核心方法

### 方法参照系

通用VLM空间推理通常采用端到端架构，输入图像与文本，直接输出空间关系判断。本文问题与该通用流程的关键差异在于：最终的空间真值不由神经网络预测，而是由外部检测器提供的坐标与确定性几何规则计算得出，VLM仅负责任务路由与语言解析。

### 结构化元组提取与本体匹配

传统VLM直接处理自然语言查询，易受复杂句式干扰。本文在流程前端引入轻量级解析器与VLM回退机制，将自然语言查询转换为结构化元组。设查询 $Q$ 被解析为三元组 $T = (o_1, r, o_2)$，其中 $o_1, o_2$ 为解剖结构，$r$ 为空间关系。随后执行本体匹配，将 $o_1, o_2$ 映射至检测器的规范类别 $C_1, C_2$。若映射失败，系统立即返回无效结果并记录审计日志。这一设计动机在于消除语言歧义对后续几何计算的干扰，确保进入验证阶段的实体是检测器可识别的规范类别。

### 确定性几何验证

在获取规范类别后，系统调用YOLO检测器定位结构，选取每类最高置信度的边界框，计算其中心点坐标 $p_1, p_2$。空间关系 $r$ 的真值由确定性几何规则判定。对于轴向CT切片，关系判定基于中心点的水平或垂直排序。设 $x$ 为水平坐标，$y$ 为垂直坐标，若 $r$ 为“left of”，则判定条件为：

$$
\text{True} \iff x_{o_1} < x_{o_2}
$$

该公式的物理含义是：空间关系不再由神经网络的隐式特征匹配决定，而是由图像空间中的显式坐标比较直接导出。这一创新解决了端到端VLM在空间幻觉上的失效，因为只要检测准确，几何判断即为绝对正确，且每一步中间状态（坐标、比较结果）均可被审计。

## 实验评估

实验在MIRP RQ1基准的938对保留测试集上进行，对比了MedGemma 4b与Qwen2-VL 7b的端到端提示与混合代理配置。基线覆盖包括GPT-4o、Gemma 3等通用VLM，但缺失了GeoWeaver等专用几何接地方法，且未对比强化学习路线的STAR-R1。

| 系统 | 准确率 (%) | F1 (%) |
| :--- | :--- | :--- |
| GPT-4o [23] | 50.5 | 35.2 |
| Gemma 3 [23] | 50.9 | 57.3 |
| Pixtral [23] | 50.7 | 43.2 |
| MedGemma [23] | 50.3 | 60.7 |
| MedGemma (Direct) | 51.8 | 67.2 |
| MedGemma + Hybrid | 91.6 | 91.3 |
| Qwen2-VL (Direct) | 51.6 | 56.8 |
| Qwen2-VL + Hybrid | 94.1 | 94.2 |

Qwen2-VL + Hybrid配置达到94.1%准确率，较直接提示提升42.5个百分点，表明模块化解耦在受控任务上具有显著优势。

| 失败阶段 | 数量 | 占比 (%) |
| :--- | :--- | :--- |
| 解析/查询提取 | 15 | 27.3 |
| 检测缺失 | 12 | 21.8 |
| 定位不精确 | 28 | 50.9 |

失败归因显示，55个错误案例中50.9%源于YOLO定位不精确，21.8%源于检测缺失，仅27.3%源于语言解析。这表明系统性能上限由感知模块决定，而非几何验证逻辑。

评估协议采用严格二元判定，无效输出计为错误。代码已开源，但论文未报告计算效率与GPU资源消耗。由于MIRP基准仅包含2D轴向切片的二元关系，该结果无法直接推广至3D体积推理或复杂拓扑场景。

## 关联研究分析

从方法设计看，本文与GeoWeaver均强调几何接地，但GeoWeaver通过显式几何令牌注入VLM内部，依赖模型学习几何特征与语义的对齐；本文则完全剥离几何计算，依赖外部检测器与规则。这一差异源于任务特性：医学CT的解剖结构边界清晰，适合检测器定位，而通用3D场景的几何关系复杂，需模型内部推理。然而，本文未探索当检测器面对伪影或非标准体位时的鲁棒性，确定性规则在噪声环境下的失效模式未被量化。

从问题动机看，本文与A Modular Agent (Abel et al., 2026) 共享模块化架构，但后者聚焦于CT扫描中的空间关系验证，本文将其扩展至更通用的二元空间关系验证，并引入了YOLO作为核心感知工具。与STAR-R1相比，后者使用强化学习优化多视图推理，属于“学习式”空间验证，本文属于“规则式”。规则式方法在可解释性上占优，但缺乏处理未见过的复杂空间关系的能力，其泛化边界严格受限于预定义的几何规则集。

## 总结

本文核心矛盾在于医学空间描述的可审计性与VLM黑盒预测之间的冲突。切入点在于将空间验证解耦为检测与几何计算，利用确定性规则替代神经预测。方法通过元组提取、本体匹配、YOLO定位与几何验证实现流程化审计。实验证明在MIRP基准上，混合代理达到94.1%准确率，较端到端基线提升42.5个百分点。边界在于系统性能受限于YOLO定位精度，且仅覆盖2D轴向切片的二元关系，未涉及3D体积推理与复杂拓扑。当解剖结构存在重叠或遮挡时，单一最高置信度检测框的选取策略是否会导致系统性偏差，论文未给出回答。
