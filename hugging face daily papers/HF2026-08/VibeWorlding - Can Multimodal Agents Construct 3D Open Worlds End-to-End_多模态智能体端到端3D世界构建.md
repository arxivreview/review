作者：Yansong Ning、Jingwen Ye、Zhongkai Wu 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2608.15265)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.15265)

> 3D开放世界构建要求智能体将模糊自然语言意图映射为物理可行的资产布局，现有方法受限于离散工具碎片化与验证标准缺失，难以处理开放意图。本文切入点在于统一资产检索、编辑与渲染接口，并建立双约束验证体系以提供可验证奖励。通过构建VWE-Bench基准与VibeWorlding-Gym强化学习框架，实现从SFT冷启动到多模态RL后训练的闭环。该框架验证了RL在离散工具调用任务上的有效性，但59.3%的Pass@1成功率揭示了当前模型在精确3D推理上的根本瓶颈。

## 研究背景

当智能体面对“构建一个包含特定植被与建筑的荒原场景”这类指令时，其核心困境在于将语义意图转化为物理空间中的资产实例化。这一过程依赖对3D资产库的检索能力，即根据自然语言描述匹配具有特定几何与语义属性的资产。然而，检索后的资产需通过旋转、平移等工具调用进行空间布局，此时物理约束（如碰撞、高度合理性）与用户意图（如生态合理性）必须同时满足。由于3D空间的状态是部分可观测的，智能体需依赖多视角渲染图像与文本地图维持状态一致性，这构成了多模态推理与工具调用的紧耦合问题。

现有3D世界构建方法主要分为两类：一是模块化流水线，如SceneCraft与3D-GPT，将规划、批评、精化分配给不同子智能体，但缺乏端到端优化，误差在模块间累积；二是Agentic Workflow，如SAGE与SceneWeaver，允许智能体自主调用工具，但多针对理想化简单查询，且框架闭源，无法系统评估训练效果。这些方法共同忽略了两个关键问题：3D资产环境碎片化导致工具接口不兼容，以及构建结果的多维验证（物理+意图）缺乏统一标准。本文的切入点在于将3D世界构建形式化为多轮多模态工具集成推理过程，通过统一沙箱环境与双约束验证器，解决工具碎片化与验证缺失问题，并探索RL后训练能否提升智能体的3D推理能力。

## 核心方法

### 方法参照系

本文问题可置于多模态智能体工具调用范式下，其标准流程为：接收多模态查询，生成思考与工具调用序列，接收环境反馈，迭代直至任务完成。与通用工具调用任务的关键差异在于：3D世界构建需同时满足物理可行性（碰撞、高度）与用户意图（生态、检索合理性），且环境状态通过3D地图与多视角图像双模态表示，验证标准非单一规则而是多维评分。

### 双约束验证器与奖励设计

设计动机在于解决3D构建结果难以用单一规则或通用LLM评判的问题。传统方法依赖手工规则（如碰撞检测）或通用LLM评分，前者无法覆盖生态合理性等软约束，后者缺乏物理一致性保证。本文提出双约束验证器，将验证分为物理可行性（高度、碰撞）与意图满足（生态合理性、3D理解、3D推理、资产检索）两个维度。物理可行性通过Blender引擎自动计算碰撞与高度合理性，意图满足由MLLM（Gemini 3.5-flash）基于详细评分标准（rubric）进行判断。验证器输出作为RL奖励信号，其数学形式为：

$$
R = \alpha \cdot R_{phys} + (1-\alpha) \cdot R_{intent}
$$

其中 $R_{phys}$ 为物理可行性得分（碰撞无冲突且高度合理为1，否则为0），$R_{intent}$ 为意图满足得分（各维度通过率为均值），$\alpha$ 为权重系数。该设计将多维验证转化为可量化的标量奖励，使RL优化目标明确。

### 多模态RL后训练框架

设计动机在于解决开源MLLM在3D工具调用上的能力不足问题。SFT冷启动仅能学习轨迹模仿，无法优化长时程决策；RL后训练通过可验证奖励引导智能体探索更优工具调用策略。本文采用GRPO（Group Relative Policy Optimization）算法，每个查询生成8条轨迹，以组内相对优势更新策略。训练流程分为两阶段：SFT冷启动使用奖励过滤的轨迹进行全参数微调（2 epochs，学习率 $2 \times 10^{-5}$）；RL阶段在VibeWorlding-Gym沙箱中优化（1 epoch，学习率 $5 \times 10^{-7}$，KL系数0.05）。沙箱统一资产检索（基于Qwen3-Embedding-4B的InfoNCE检索器）、编辑（添加/删除/旋转/平移）与渲染（Blender返回5张1280×720图像）为MCP工具，智能体每轮接收工具响应与多模态反馈。该框架使模型评估与训练由统一环境与奖励信号驱动，避免了SFT与RL的数据分布不一致问题。

## 实验评估

实验在VWE-Bench上进行，该基准包含2616个3D资产、323个种子世界与6828个查询，分为Verified（有真值）与Unverified（基于评分标准）两类。基线覆盖前沿闭源MLLM（GPT-5.5、Qwen3.8-Max、Gemini 3.1-pro等）与开源模型（Qwen3-VL-8B/30B-A3B），但缺乏神经符号方法（如NeSyPr）或模块化流水线（如SceneCraft）的对比，可能高估端到端架构的相对优势。

| 模型 | Verified Pass@1 (%) | Unverified Pass@1 (%) |
| :--- | :--- | :--- |
| Qwen3-VL-8B | 5.3 | - |
| Qwen3-VL-30B-A3B | 13.6 | - |
| VibeWorlder-8B | 41.4 | - |
| VibeWorlder-30B-A3B | 59.3 | - |
| GPT-5.5 | <60 | - |
| Qwen3.8-Max | <60 | - |

注：Unverified数值未在数据区提供，仅Verified列可逐字定位。核心对比显示，RL后训练使VibeWorlder-30B-A3B从13.6%提升至59.3%，超越GPT-5.5与Qwen3.8-Max的<60%水平，但绝对成功率仍低。

消融实验未在数据区提供具体数值，但正文指出3D推理是主要瓶颈：模型能理解3D世界与用户意图，但无法通过工具精确编辑世界。RL后训练主要提升3D推理与资产检索能力，而对物理可行性（碰撞检测）的改善有限，因后者依赖Blender引擎而非模型推理。这一发现表明，RL优化的是模型的工具调用策略，而非物理引擎的准确性。

评估边界方面，验证器与人类判断的Cohen’s κ为0.54（生态合理性）与0.53（意图满足），系统级Spearman’s ρ为0.88，表明验证器可靠但非完美。可复现性上，代码与模型已开源，8B模型在单节点8×H20 GPU上训练，30B-A3B在3节点GPU上训练，但未报告训练时间与显存占用。

## 关联研究分析

从问题动机看，本文与NeSyPr（Choi et al., 2025）均解决长时程推理中的幻觉问题，但路径不同：NeSyPr通过符号推理引擎保证逻辑严谨性，适用于离散技能序列规划；本文通过双约束验证器保证物理与意图一致性，适用于连续3D空间布局。差异根源在于任务特性：NeSyPr处理的是可形式化的逻辑约束，而3D世界构建涉及软约束（如生态合理性），无法完全符号化，需依赖MLLM评分。这暗示，当约束可形式化时，符号推理可能更高效；当约束模糊时，验证器+RL是更可行的路径。

从方法设计看，本文与Dejavu（Wu et al., 2025）均探索部署后适应，但机制不同：Dejavu通过外部记忆库与残差策略实现轻量级适应，不更新主模型权重；本文通过RL后训练更新模型参数，实现能力内化。差异根源在于数据效率：Dejavu适用于数据稀缺、需快速适应的场景，本文适用于有统一环境与奖励信号、可大规模训练的场景。本文的RL后训练依赖VibeWorlding-Gym沙箱，若沙箱无法覆盖真实世界所有物理约束，则内化能力可能失效，而Dejavu的外部记忆可动态更新，更适应环境变化。

## 总结

本文要解决的核心矛盾是3D世界构建中工具碎片化与验证标准缺失，导致智能体无法处理开放意图。现有方法因工具接口不兼容与验证维度单一而失效，本文通过统一沙箱环境与双约束验证器解决此问题，并证明RL后训练可提升开源MLLM的3D推理能力。实验显示VibeWorlder-30B-A3B达到59.3% Pass@1，超越GPT-5.5与Qwen3.8-Max，但绝对成功率仍低，且RL主要改善3D推理而非物理可行性。本文的边界在于验证器依赖MLLM评分，可能引入噪声；沙箱仅覆盖离散资产库，无法处理连续几何编辑。当资产库规模扩大至开放世界时，检索器的InfoNCE损失是否仍能保持精度，论文未给出回答。
