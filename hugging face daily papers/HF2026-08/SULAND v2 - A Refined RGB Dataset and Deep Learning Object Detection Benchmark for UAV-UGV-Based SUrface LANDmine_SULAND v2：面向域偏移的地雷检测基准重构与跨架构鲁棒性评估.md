> 地雷检测的核心矛盾在于安全关键任务对漏检率的零容忍与真实部署环境分布漂移之间的张力。现有研究多聚焦于提升特定场景下的识别精度，却忽视了基准数据集标注噪声对域外（Out-of-Distribution, OOD）评估结论的污染，导致模型鲁棒性被高估或误判。本文切入点在于系统审计并修正SULAND数据集的标注缺陷，构建SULAND v2，并在统一协议下对九类主流检测器进行IID/OOD双轨基准测试。该工作揭示了标注质量对OOD排名的决定性影响，但单模态RGB在极端遮挡下的物理极限仍未被充分量化。

## 研究背景

低空无人机（UAV）采集的RGB图像中，地雷目标往往呈现为像素占比极低的微小物体，且极易与土壤纹理、阴影或植被混淆。这种视觉稀疏性使得检测器在训练域（In-Distribution, IID）内依赖背景相关性而非目标语义特征，一旦部署环境发生地理或光照变化，性能便出现断崖式下跌。这种从训练分布到测试分布的系统性差异被称为域偏移，它直接决定了检测器在真实排雷作业中的可靠性。

主流视觉检测路线长期依赖YOLO系列或DETR架构优化小目标召回率，但现有公开数据集如SULAND v1存在严重的标注不一致性，包括缺失标签、定位偏差及OOD子集类别ID反转。这些缺陷导致基于该基准得出的OOD性能排名可能反映的是模型对错误标注的拟合能力，而非真实的泛化能力。在安全关键应用中，这种基准噪声比模型架构差异更具误导性。本文旨在通过修正标注并建立标准化评估协议，区分真实的域偏移效应与数据质量缺陷，从而为地雷检测提供可信的鲁棒性基准。

## 核心方法

### 基准审计与标注修正范式

本文问题属于数据集质量审计与基准重构范畴，其关键差异在于将标注一致性作为OOD评估的前置条件，而非仅关注模型架构改进。传统流程假设标注无误，直接比较模型在IID/OOD上的mAP差异；本文则引入跨版本（Cross-Version）评估矩阵，通过对比同一模型在不同标注版本下的表现，隔离标注噪声对性能指标的贡献。

### 跨版本评估矩阵设计

标注修正的核心在于量化SULAND v1到v2的几何与语义变化。对于匹配到的标注框，定义中位IoU（Median IoU）和中位面积比（Median Area Ratio）来衡量定位修正幅度。

$$
\text{Med. IoU} = \text{median}\left( \frac{\text{Area}(B_{v1} \cap B_{v2})}{\text{Area}(B_{v1} \cup B_{v2})} \right)
$$

该公式物理含义是衡量原始标注框与修正后标注框的空间重叠程度，IoU越低表明原始定位偏差越大。实验显示IID训练集的中位IoU仅为0.72，且44.5%的框IoU低于0.7，证实了v1存在大量定位松散问题。

### 域偏移鲁棒性解耦

为了分离训练标注与评估标注的影响，本文构建了$2 \times 2$的评估矩阵，包括v1→v1, v1→v2, v2→v1, v2→v2四种组合。

$$
\Delta_{\text{eval}} = \text{mAP}(\text{Model}_{v2}, \text{GT}_{v2}) - \text{mAP}(\text{Model}_{v2}, \text{GT}_{v1})
$$

此公式计算同一模型在修正标注与原始标注下的性能差，用于量化评估标注噪声对分数的扭曲程度。设计动机在于，若$\Delta_{\text{eval}}$显著，则说明原始基准的OOD排名不可信。通过该矩阵，本文发现修正标注后，YOLOv8的IID测试mAP@50提升了14.6–19.6个百分点，而OOD性能仅提升约25个百分点（主要源于类别ID修正），表明IID性能对标注质量更敏感，而OOD性能更多受限于真实的域差距。

## 实验评估

实验在SULAND v2上进行，覆盖YOLOv8-26、RT-DETR、Faster R-CNN、RF-DETR等九族35种配置。基线覆盖了单阶段、两阶段及Transformer架构，但缺失了知识库中强调的多模态（如红外、声学）方法，限制了结论在恶劣光照下的普适性。

| 模型配置 | IID mAP@50 | OOD mAP@50 | OOD Recall |
| :--- | :--- | :--- | :--- |
| YOLOv12-S | 0.908 | - | - |
| RF-DETR-L | 0.880 | 0.799 | 0.675 |
| YOLOv8 (v2→v2) | 0.875 | 0.429 | - |
| YOLOv8 (v1→v2) | 0.814 | 0.384 | - |

RF-DETR-L在OOD mAP@50上达到0.799，显著高于YOLO系列在OOD下的约0.53水平，且其mAP@50:95从0.631仅微降至0.623，显示出极强的定位鲁棒性。相比之下，YOLOv12-S虽在IID下取得0.908的最高mAP@50，但在OOD下性能大幅衰减，证实了高IID精度不等于高OOD鲁棒性。

消融实验显示，标注修正对IID性能的提升（14.6–19.6 pp）远大于对OOD性能的提升（约25 pp，含类别修正），且OOD子集的中位IoU（0.82）高于IID子集（0.72），说明OOD标注本身质量较好，其性能瓶颈主要源于地理域差距而非标注噪声。这一反直觉发现表明，在OOD评估中，模型架构的表征能力比数据清洁度更关键。

评估边界方面，本文仅使用RGB模态，未涵盖热成像或声学信号，无法验证多模态融合在低光场景下的增益。代码与超参数未完全公开，且推理速度受硬件影响，FPS数据仅具相对参考意义。此外，缺乏跨数据集（如AMLID或MineInsight）的泛化测试，结论局限于SULAND特定的地理迁移场景。

## 关联研究分析

从问题动机看，本文与知识库中强调“多模态融合解决感知局限”的路线存在根本分歧。主流观点认为单一RGB在夜间或恶劣天气下失效，必须引入红外或声学模态；而本文在纯RGB条件下发现，RF-DETR等强架构在地理域偏移下仍能保持0.799的mAP@50，暗示在标注一致的前提下，架构的表征鲁棒性可能比模态多样性更基础。这种差异源于任务对象不同：无人机是动态目标，多模态互补性强；地雷是静态隐蔽物，视觉特征在特定地理域内具有稳定性，架构对背景不变性的学习能力成为主导因素。

从方法设计看，本文的“基准审计”范式与知识库中“架构创新”范式形成互补。知识库中的DroneScan-YOLO等方法通过P2头或小波变换提升小目标召回率，假设数据是干净的；而本文证明，若数据存在44.5%的定位偏差，任何架构改进都可能被噪声掩盖。这种差异揭示了领域研究的盲区：在数据稀缺的安全关键领域，数据质量审计的优先级可能高于算法创新。RF-DETR的OOD优势是否源于其DINOv2骨干的预训练特性，还是源于其端到端集合预测机制对背景噪声的抑制，论文未给出归因分析，这限制了结论向其他Transformer架构的推广。

## 总结

本文要解决的核心矛盾是安全关键地雷检测中，基准标注噪声对域偏移鲁棒性评估的污染。现有方法无法区分真实的泛化失败与数据缺陷导致的虚假失败，而本文凭借对SULAND v1的系统审计与跨版本评估矩阵，实现了标注质量与模型性能的解耦。通过构建SULAND v2并评测35种配置，本文证明了RF-DETR-L在OOD下0.799的mAP@50优于YOLO系列，且标注修正使YOLOv8的IID性能提升近20个百分点。本文的边界在于仅局限于RGB模态与单一地理迁移场景，未验证多模态融合或跨数据集泛化。当支持集扩展至更多地理区域或引入红外模态时，RF-DETR的架构优势是否依然显著，还是会被模态互补性所取代，论文未给出回答。
