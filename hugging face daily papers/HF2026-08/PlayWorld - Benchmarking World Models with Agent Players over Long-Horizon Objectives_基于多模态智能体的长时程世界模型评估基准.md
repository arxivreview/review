# HuggingFace最新推荐论文 ｜PlayWorld: Benchmarking World Models with Agent Players over Long-Horizon Objectives ｜基于多模态智能体的长时程世界模型评估基准

研究机构：快手、香港中文大学

作者：Kaixin Ding、Xi Chen、Minghong Cai 等 12 人

论文原文见 [arXiv](https://arxiv.org/abs/2608.13552)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.13552)

> 交互式视频世界模型旨在模拟可探索的物理环境，但现有评估基准依赖固定动作轨迹，无法应对不同模型间动作粒度与响应速度的差异，导致跨模型比较失效。PlayWorld 通过引入多模态智能体（Agent Player）在线适配动作执行，将评估从“轨迹跟随”转向“目标达成”，解决了固定输入下的公平性缺失问题。该基准包含 171 个场景，通过闭环交互验证了当前模型在长时程状态演化上的局限性，但其依赖大语言模型（LLM）决策的非确定性仍构成可复现性的潜在隐患。

## 研究背景

当用户试图通过旋转相机 360 度来检验世界模型的几何一致性时，不同模型对“旋转”这一指令的响应幅度存在显著差异：同一组指令在模型 A 中可能完成完整旋转，而在模型 B 中仅完成半圈。这种动作粒度（Action Granularity）的不一致导致基于固定轨迹的评估无法建立可比的状态基准，即模型未能回到初始视角时，几何一致性分数失去意义。为了解决这一评估公平性问题，需要一种能够感知生成帧并动态调整动作时长的机制，这构成了闭环评估的核心需求。

现有世界模型评估基准如 WorldMark 和 Omni-WorldBench 主要依赖预定义的低层控制序列，其假设所有模型对相同输入产生相似的状态变化。然而，闭源模型（如 Genie 3）仅通过 Web 接口提供交互，且其内部动力学不可知，固定轨迹往往导致评估意图与实际执行状态脱节。PlayWorld 的切入点在于将评估主体从“执行器”转变为“玩家”，通过多模态智能体模拟人类玩家的决策过程，在保持评估意图一致的前提下，自适应地调整动作执行，从而在异构模型间建立公平的长时程交互评估协议。

## 核心方法

### 评估协议参照系

传统世界模型评估遵循“固定输入-静态输出”范式，即执行预定义轨迹并比对生成帧与参考帧的几何或语义一致性。本文问题的关键差异在于：输入不再是固定的动作序列，而是由智能体根据实时观测动态生成的动作流，评估目标从“轨迹匹配”转变为“目标达成”。

### 闭环智能体决策机制

PlayWorld 的核心创新在于引入 Agent Player，其决策过程可形式化为一个基于观测历史的马尔可夫决策过程。在每一步 $t$，智能体接收当前生成帧 $O_t$、已执行动作历史 $A_{1:t-1}$ 及长时程目标 $G$，输出决策 $d_t \in \{\text{Keep, Stop, Extend, Correct, End}\}$。

$$
d_t = f_{\theta}(O_t, A_{1:t-1}, G, S_{ref})
$$

其中 $S_{ref}$ 为人工标注的基础动作序列（Basic Action Sequence），作为共享初始参考。该公式的物理含义是：智能体并非从零规划轨迹，而是以 $S_{ref}$ 为锚点，根据观测偏差 $O_t$ 与预期状态的差异，对动作时长或类型进行微调。这一设计解决了固定轨迹在模型响应速度差异下导致的“过冲”或“欠冲”问题，确保不同模型在相同目标下执行等效的交互意图。

### 多维 VQA 验证器

针对开放场景的评估，PlayWorld 构建了基于视觉问答（VQA）的评分机制。对于几何一致性维度，验证器检查地标在重新进入视野时的位置与形态是否一致；对于视野外演化（Out-of-sight Evolution），验证器评估物体离开视野后状态是否持续演化而非重置。

$$
\text{Score}_{dim} = \frac{1}{N} \sum_{i=1}^{N} \mathbb{I}(\text{VQA}_i(O_{1:T}, Q_i) = \text{True})
$$

其中 $Q_i$ 为针对特定维度设计的结构化问题，$\mathbb{I}$ 为指示函数。该机制将主观的视觉一致性转化为可量化的二元判断，弥补了传统 FVD 等指标无法捕捉因果逻辑错误的缺陷。

## 实验评估

实验在 9 个代表性世界模型上进行，包括 5 个闭源模型（Genie 3, HappyOyster 等）和 4 个开源模型（SANA-WM, Hunyuan-GameCraft-2 等）。基线覆盖当前主流架构，但缺失早期 RNN 基线，重点在于对比不同生成范式下的交互能力。

| Model | Geometry Consistency | Interaction Fidelity | Insight Evolution | Out-of-sight Evolution | Overall |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Genie 3 | 2.74 | 2.40 | 1.51 | 1.81 | 2.12 |
| HappyOyster | 2.54 | 2.15 | 1.47 | 1.54 | 1.92 |
| LingBot-World | 2.11 | 2.23 | 1.33 | 1.43 | 1.78 |
| LingBot-World2 | 2.04 | 2.13 | 1.95 | 1.16 | 1.82 |
| HY-World2 | 2.14 | 2.06 | 1.13 | 1.09 | 1.61 |
| SANA-WM | 1.62 | 1.52 | 1.21 | 1.31 | 1.42 |
| Hunyuan-GameCraft-2 | 1.62 | 1.52 | 1.21 | 1.31 | 1.42 |
| HY-WorldPlay | 1.12 | 1.63 | 1.01 | 1.08 | 1.21 |
| Matrix-Game-3.0 | 1.30 | 1.25 | 1.00 | 1.00 | 1.14 |

Genie 3 在几何一致性与整体得分上领先，但所有模型在视野外演化维度上得分均低于 2.0，表明当前模型难以维持长时程的因果状态连续性。

消融实验对比了三种控制策略：Preset Only（固定轨迹）、Agent Only（完全自主规划）和 Preset + Agent（混合策略）。

| Setting | Trajectory Score | Human Preference | Agent-modified Action Ratio |
| :--- | :--- | :--- | :--- |
| Preset Only (Genie 3) | 0.92 | 39.6% | 0.0% |
| Agent Only (Genie 3) | 0.88 | 29.2% | 100.0% |
| Preset + Agent (Genie 3) | 1.08 | 65.6% | 12.0% |
| Preset Only (HappyOyster) | 1.00 | 40.8% | 0.0% |
| Agent Only (HappyOyster) | 0.68 | 24.4% | 100.0% |
| Preset + Agent (HappyOyster) | 1.12 | 67.4% | 14.9% |

Preset + Agent 策略在轨迹得分与人类偏好上均显著优于其他策略，且仅修改 10-20% 的动作，证明“共享参考+在线适配”是平衡评估一致性与模型适应性的最优解。完全自主规划（Agent Only）因决策延迟和轨迹发散导致性能下降，验证了基础动作序列作为锚点的必要性。

评估边界方面，PlayWorld 依赖 LLM（Claude Haiku）进行决策，其非确定性可能引入评估噪声；此外，闭源模型的 Web 接口自动化存在稳定性风险。代码与数据已开源，但 Agent 决策的统计一致性未提供置信区间，复现性受限于 LLM 版本更新。

## 关联研究分析

从问题动机看，PlayWorld 与 Omni-WorldBench 均关注交互性评估，但 Omni-WorldBench 采用固定多轮导航模式，无法处理模型响应速度的异构性。PlayWorld 通过闭环智能体解决了这一痛点，其根源在于将评估视为“目标达成”而非“路径匹配”，这更符合人类玩家的实际交互逻辑。然而，这种依赖 LLM 的自适应机制是否引入了新的评估偏差，例如智能体对特定模型风格的偏好，论文未给出量化回答。

从方法设计看，PlayWorld 与 WorldMark 在几何一致性评估上存在显著差异。WorldMark 依赖预定义相机轨迹，其分数可能混淆几何错误与轨迹失败；PlayWorld 通过智能体确保相机实际完成 360 度旋转，从而隔离了控制误差与生成误差。这一设计差异源于任务特性：世界模型的核心价值在于状态持久性，而非轨迹跟随精度。若模型在长时程中产生空间漂移，固定轨迹评估会误判为几何不一致，而 PlayWorld 的目标导向评估能更准确地定位这一失效模式。

## 总结

PlayWorld 旨在解决交互式世界模型评估中因动作粒度差异导致的跨模型比较失效问题。现有固定轨迹基准无法适应异构模型的响应动力学，而 PlayWorld 通过引入多模态智能体在线适配动作执行，将评估从路径匹配转向目标达成，实现了更公平的长时程交互评估。实验表明，Genie 3 在整体得分上领先（2.12），但所有模型在视野外演化维度上表现薄弱，揭示了当前模型在长时程状态持久性上的根本局限。该基准的边界在于其依赖 LLM 决策的非确定性，以及闭源模型接口的稳定性风险。当智能体模型升级或动作空间扩展时，Preset + Agent 策略的边际收益是否递减，论文未给出回答。
