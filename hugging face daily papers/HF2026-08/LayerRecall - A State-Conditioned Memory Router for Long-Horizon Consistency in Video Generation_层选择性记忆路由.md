> 自回归长视频生成在扩展时长时，常因固定窗口缓存驱逐关键历史证据，导致主体身份与场景属性在镜头切换后发生漂移。现有记忆增强方法虽能检索非局部历史，但往往忽略网络深度维度上注意力分布的异质性，导致记忆注入位置不当反而破坏局部时序连贯性。本文提出LayerRecall，通过当前状态条件化的检索与层选择性路由，将历史K/V状态仅注入特定的记忆敏感层，并设计跨时域预测匹配（CHPM）策略实现无标签训练。该方法在保持骨干网络一致性指标持平的前提下，显著提升了多镜头场景下的长程记忆恢复能力，但其层偏好策略的跨骨干泛化性仍受限于特定架构的注意力分布特性。

## 研究背景

自回归视频扩散模型通过因果注意力机制实现流式生成，其核心依赖键值（KV）缓存以避免重复计算完整序列。然而，受限于显存预算，模型通常仅保留近期时间窗口或固定大小的KV缓存。这种基于近期性的策略虽能维持局部运动与外观连续性，但会驱逐关于主体、物体或场景属性的历史证据，当这些内容在镜头切换后重新出现时，模型缺乏恢复其一致性的依据。

主流解决方案包括引入固定锚点、压缩状态或检索历史帧，以暴露模型于非局部历史。然而，单纯增加历史信息的可访问性并不保证有效利用。本文通过剖析自回归视频扩散Transformer（DiT）的深度注意力分布，发现不同层对当前、近期及远期上下文存在显著的偏好差异。这种层间异质性表明，长程记忆的有效使用不仅取决于“检索什么”，还取决于“在哪层使用”。现有方法通常将检索到的历史状态全局注入或固定层注入，忽略了这种深度维度的选择性需求，导致记忆引入可能干扰局部时序建模。

## 核心方法

### 方法参照系

本文问题属于长时记忆与缓存管理路线，标准流程是在有界KV缓存基础上增加历史检索模块。关键差异在于，本文不将记忆注入视为单一的全局操作，而是将其解耦为“检索内容”与“注入深度”两个独立决策，并针对后者引入层选择性路由机制。

### 当前条件化历史检索

在参照系的检索环节，通常做法是基于固定查询或简单相似度匹配历史块。本文创新在于引入当前生成状态作为条件，使检索过程动态适应当前上下文。具体地，模型对当前块的隐藏状态进行归一化，并通过共享的MLP与门控机制生成查询向量 $q_t^l$。该查询向量与历史块池化的摘要向量 $m_i^l$ 进行余弦相似度计算，以决定哪些历史K/V状态被选中。这一设计解决了固定检索策略无法适应动态场景变化的问题，使得模型能够根据当前生成需求精准召回相关历史证据，而非盲目加载所有历史。

$$ q_t^l = q_{global} + \alpha \gamma_l \sigma(W_g z_t^l + b_g) \text{MLP}(z_t^l) $$

该公式表明，查询向量由全局共享部分与当前状态条件化的残差部分组成，其中 $\gamma_l$ 为层特定缩放因子，确保检索过程既具备全局一致性又具备局部适应性。

### 层选择性记忆注入与CHPM训练

在注入环节，通常做法是将检索到的K/V状态注入所有层或固定层。本文创新在于通过时间剖析识别出骨干网络中特定的记忆敏感层集合 $\mathcal{L}_{mem}$，仅将这些层作为记忆注入目标，其余层保留原始的滑动窗口注意力。这种选择性注入限制了记忆引入对局部时序建模的干扰。为解决缺乏显式记忆分配标签的问题，本文提出跨时域预测匹配（CHPM）。CHPM利用一个冻结的长上下文教师模型，在预测空间监督有界记忆的学生模型。学生模型通过最小化其与教师模型在监督锚点上的预测差异来优化路由参数，从而间接学习如何有效利用长程记忆。

$$ \mathcal{L}_{CHPM} = \lambda_{pred} \mathcal{L}_{pred} + \lambda_{reg} \mathcal{L}_{reg} $$

该损失函数由预测匹配项与正则化项组成，其中 $\mathcal{L}_{pred}$ 衡量学生与教师预测的均方误差，迫使学生在有界记忆约束下逼近长上下文行为，而无需显式标注哪些历史块应被使用。

## 实验评估

实验基于LongLive-2.0骨干网络，在100个多镜头评估提示词上进行测试。基线覆盖CausVid、Self-Forcing、LongLive等自回归方法，以及MemFlow、Context Forcing等记忆增强方法，但缺失VideoSSM等状态空间模型基线。

| 方法 | VBench-Long Avg. | MemoBench Overall | MovieBench Overall |
| :--- | :--- | :--- | :--- |
| LongLive-2.0 | 0.978 | 0.513 | 0.531 |
| Self-Forcing | 0.976 | 0.327 | 0.292 |
| MemFlow | 0.981 | 0.531 | 0.480 |
| LayerRecall | 0.978 | 0.548 | 0.579 |

LayerRecall在MemoBench和MovieBench上均取得最高分，其中MemoBench Overall 0.548显著高于LongLive-2.0的0.513，表明其在长程记忆恢复上的优势。同时，其VBench-Long Avg. 0.978与骨干网络持平，证明记忆增强未牺牲局部一致性。

| 变体 | Memo Overall | Memo ID | Memo State | Memo Camera |
| :--- | :--- | :--- | :--- | :--- |
| Random init | 0.519 | 0.484 | 0.487 | 0.508 |
| Trained | 0.548 | 0.530 | 0.525 | 0.573 |
| All-Layer Routing | 0.5180 | - | - | - |
| LayerRecall | 0.5430 | - | - | - |

消融实验显示，训练后的LayerRecall在MemoBench各维度上均优于随机初始化，其中Memo Camera提升最为显著（0.508至0.573）。对比全层路由与层选择性路由，后者将高频帧变化能量比从0.60降至0.38，并提升了相邻帧CLIP/DINO一致性，验证了层选择性注入在抑制时序扰动方面的有效性。

评估协议主要依赖自动指标，缺乏细粒度时序漂移的量化分析。代码与超参数已开源，训练使用16块H100 GPU，具备可复现性。

## 关联研究分析

从方法设计看，LayerRecall与MemFlow均致力于解决有界记忆下的历史证据丢失问题，但路径截然不同。MemFlow侧重通过压缩全局状态来维持长程一致性，属于隐式记忆优化；而LayerRecall通过显式路由历史K/V状态至特定层，属于显式记忆机制。这一差异源于对“记忆有效性”的不同理解：MemFlow假设压缩状态足以捕捉全局语义，而LayerRecall认为深度维度的注意力异质性要求更精细的记忆分配。LayerRecall在MemoBench上的优势表明，在多镜头场景下，显式路由比压缩状态更能精准恢复特定主体属性，但这也意味着其计算开销可能高于压缩方法，论文未提供详细的FLOPs对比。

从问题动机看，LayerRecall与Self-Forcing共享消除训练-推理偏差的目标，但实现机制存在根本差异。Self-Forcing通过自采样让模型在训练阶段接触自身生成的帧，直接对齐分布；而LayerRecall通过CHPM利用长上下文教师模型在预测空间提供监督，间接学习记忆路由策略。Self-Forcing关注的是时间维度的分布匹配，而LayerRecall关注的是空间与深度维度的记忆利用。这种差异导致Self-Forcing在长程稳定性上表现优异，但在多镜头身份保持上可能不如LayerRecall，因为后者显式优化了历史证据的检索与注入。CHPM在单镜头长视频生成中是否仍有效，论文未给出回答。

## 总结

本文核心矛盾在于有界记忆下历史证据的有效利用与局部时序连贯性之间的权衡。现有方法忽略网络深度维度的注意力异质性，导致记忆注入位置不当。LayerRecall通过层选择性路由与CHPM训练策略，实现了记忆内容与注入深度的联合优化。实验证明，该方法在保持VBench-Long指标持平的前提下，将MemoBench Overall从0.513提升至0.548。其边界在于层偏好策略依赖于特定骨干网络的注意力分布，跨骨干迁移时需重新剖析层敏感性。当骨干网络架构发生显著变化时，固定的记忆敏感层集合是否仍能维持最优的记忆利用效率，论文未给出回答。
