# HuggingFace最新推荐论文 ｜Activity Frames: Deterministic Screen-Activity Compilation for Agent Memory and Replay ｜确定性屏幕活动编译

论文原文见 [arXiv](https://arxiv.org/abs/2608.05784)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.05784)

> 计算机使用智能体在重复执行用户已完成的例行任务时，需支付全量前沿推理成本，根源在于当前智能体记忆仅记录对话而非用户行为。现有方案或依赖原始数据流导致上下文溢出，或依赖大语言模型摘要引入非确定性与幻觉，无法构建可缓存、可审计的行为记忆。本文提出一种零模型参与的确定性编译管道，将被动捕获的屏幕流转化为结构化活动帧，实现 86 倍 Token 压缩与字节级可复现性。该方案在单用户语料上验证了记忆构建的可行性，但其对多用户场景的泛化能力及语义理解的深度仍存疑。

## 研究背景

当智能体被询问“今天应优先处理什么”时，其回答仅基于对话历史与文件，无法感知用户实际花费在特定应用上的时间分布。这种感知缺失源于智能体记忆系统的结构性局限：现有记忆架构主要处理对话流与工具调用轨迹，将“用户说了什么”等同于“用户做了什么”，导致智能体无法从行为数据中推断任务优先级或识别重复性例行工作。

智能体评估领域已确立过程导向与成本效率为一级指标，但针对智能体自身记忆构建的成本与可靠性评估仍属空白。主流记忆系统如 MemGPT 与 Zep 侧重于对话事实的整合与知识图谱构建，而屏幕捕获类方案如 MIRIX 与 FOCAL 虽尝试从视觉数据中提取记忆，但均将大语言模型嵌入记忆构建循环，继承了推理时的非确定性、高昂的每次运行成本以及潜在的幻觉风险。这些方法无法保证相同输入产生相同输出，使得记忆不可缓存、不可机械审计，难以满足生产级智能体对可靠性的要求。

本文切入点在于将记忆构建从推理时移至编译时，利用确定性代码替代大语言模型进行屏幕活动流的解析与结构化。通过引入“确定性编译”范式，本文旨在解决智能体记忆在成本、可复现性与可审计性上的根本矛盾，为长时程智能体提供基于行为事实而非对话推断的情景记忆基础。

## 核心方法

### 方法参照系

本文问题归属于智能体外部记忆构建范畴，与现有基于大语言模型摘要或知识图谱的记忆系统形成对照。关键差异在于：本文拒绝在数据预处理阶段引入任何学习组件，而是将屏幕捕获流视为可编译的指令集，通过纯代码逻辑生成结构化文档，从而将记忆构建的随机性降至零。

### 双层架构与确定性编译规则

设计动机在于解决大语言模型摘要在长输入下的可靠性退化与幻觉问题。本文提出双层架构，第一层为测量层，仅包含可由确定性代码从捕获数据推导的字段，如应用、站点、时间戳与输入量；第二层为推断层，仅接受命名空间隔离、置信度标记且链接至测量证据的推断标签。编译过程遵循严格的确定性规则，包括停留时间信用分配、会话间隙检测与闪烁合并。对于帧分割，算法遍历单监视器流，若连续帧间隔 $\Delta \le G$（300秒），则累计活跃时间 $active(cur) += \min(\Delta, D)$，其中 $D$ 为 90 秒上限；若 $\Delta > G$，则标记会话中断。该公式确保活跃时间反映的是上下文在前台的时间（tenure），而非交互时间，同时通过上限防止捕获停滞导致的信用溢出。

### 实体类型化与成本度量

设计动机在于解决原始 URL 缺乏语义结构导致智能体无法识别任务类型的问题。本文实现全 URL 到实体类型的映射，采用分层解析策略：首先使用特定主机解析器，其次通用搜索参数检测，最后子域与路径启发式。该过程无网络请求、无模型调用，仅依赖路径与查询解析。在成本度量方面，本文定义例行开销比率 $R$，其分子为无记忆智能体重新推导例行的建模 Token 成本，分母为编译后计划的实测 Token 成本。公式 $R = \frac{C_{memoryless}}{C_{compiled}}$ 量化了确定性编译相对于全量推理的节省幅度。该指标从被动捕获的人类活动中读取，而非智能体执行轨迹，从而提供了需求侧的成本基线，揭示了智能体在重复执行用户已熟练任务时的冗余开销。

## 实验评估

| 表示方式 | Sonnet 4.5 准确率 | Sonnet 4.5 时长误差 | Opus 4.5 准确率 | Opus 4.5 时长误差 |
| :--- | :--- | :--- | :--- | :--- |
| Raw rows | 82.1% | 39.7% | 91.1% | 25.7% |
| LLM summary | 66.1% | 135.7% | 80.4% | 25.2% |
| Activity frames | 98.4% | 7.3% | 98.4% | 7.3% |

实验基于 61 天单用户语料，包含 109,735 个快照行。基线对比涵盖原始数据行与大语言模型摘要，但缺失 MemGPT 等主流记忆系统的直接对比，限制了横向可比性。核心结果显示，活动帧表示在两个模型层级上均达到 98.4% 的准确率，且时长误差仅为 7.3%，显著优于大语言模型摘要的 66.1%-80.4% 准确率与 25.2%-135.7% 误差。值得注意的是，活动帧表示消除了模型层级差异，中端模型与前沿模型表现一致，而原始数据与摘要基线则随模型增强而改善，表明确定性编译的价值在于提供结构化事实而非依赖模型推理能力。

消融分析显示，大语言模型摘要的主要失效模式是量级错误而非事实幻觉。在 Sonnet 层级，摘要对时间问题的准确率仅为 7.1%，平均时长误差高达 135.7%，例如将 144 分钟的活动膨胀为 7 小时。这一发现揭示了流畅文本掩盖了数值失真，而确定性编译通过预计算算术消除了这一风险。此外，编译延迟中位数为 68 毫秒，且字节级可复现性得到验证，证明该方案在计算效率与稳定性上具备工程可行性。

评估边界受限于单用户、单平台语料，无法验证多用户场景下的泛化能力。指标完备性方面，虽提供了准确率与时长误差，但缺乏对记忆检索延迟或长期记忆一致性的度量。可复现性方面，编译器与评估框架已开源，但捕获引擎依赖特定操作系统环境，且 OCR 组件的非确定性仅在前向路径上被隔离，未回溯至像素级。

## 关联研究分析

从问题动机看，本文与 AgentCompass 等评估基础设施工作共享模块化与标准化的理念，但对象从评估脚本转向记忆数据。AgentCompass 旨在解决评估协议的碎片化，而本文解决的是记忆构建的非确定性。这一差异源于任务特性：评估需要可比性，而记忆需要可缓存性。确定性编译是达成可缓存性的必要手段，但可能牺牲了对用户意图的深层语义理解，因为代码无法观察意图，仅能记录行为事实。

从方法设计看，本文与 Holistic Agent Leaderboard 的成本分析维度存在互补。后者关注模型调用成本与任务成功率的帕累托前沿，而本文引入例行开销比率 $R$，聚焦于例行任务的边际成本。这种差异揭示了智能体成本结构的两个层面：任务执行成本与记忆维护成本。本文证明，通过确定性编译，记忆维护成本可降至零，从而将成本优化重心转移至任务执行策略。然而，本文未探讨当例行任务涉及复杂语义判断时，确定性编译是否会导致信息丢失，从而迫使智能体在低效的原始数据检索与低保真的编译记忆之间做出权衡。

## 总结

本文核心矛盾在于智能体记忆构建的高成本、非确定性与生产级可靠性需求之间的冲突。切入点在于利用确定性代码替代大语言模型进行屏幕活动编译，凭借零模型参与实现字节级可复现性与 86 倍 Token 压缩。方法上，通过双层架构隔离测量事实与推断标签，并引入例行开销比率量化需求侧成本。实验证明，活动帧表示在单用户语料上以 98.4% 准确率超越大语言模型摘要，且消除了模型层级差异。边界在于单用户语料限制了泛化性验证，且确定性编译无法捕捉用户意图的深层语义。当例行任务涉及跨应用复杂语义判断时，确定性编译的信息丢失是否会导致智能体决策质量下降，论文未给出回答。
