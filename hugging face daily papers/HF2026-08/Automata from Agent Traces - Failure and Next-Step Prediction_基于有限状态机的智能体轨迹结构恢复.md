研究机构：英国伦敦大学学院

作者：Seonglae Cho、Franklin Cardenoso Fernandez、Umar Mohammed 等 7 人

论文原文见 [arXiv](https://arxiv.org/abs/2608.23670)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2608.23670)

> 大语言模型智能体（LLM Agent）在执行多步任务时产生的轨迹长且非结构化，导致安全审计与运行时监控难以捕捉跨步骤的行为依赖。现有方法要么依赖人工编写策略，要么仅处理单条轨迹或成功样本，无法提取连接下一步预测与故障预测的共享拓扑结构。本文通过从原始轨迹语料中自动构建紧凑的确定性有限自动机（DFA），将隐式行为结构显式化，为预测与监控提供统一的结构基座。该方法在结构恢复任务上表现优异，但其作为安全防御组件的有效性尚未在对抗性攻击场景中得到验证。

## 研究背景

理解本文需厘清两个核心概念：活动提取与重放适应度。智能体轨迹由系统、用户、助手及工具消息组成，需通过活动提取函数 $\phi$ 将每条消息映射为有限字母表 $\mathcal{A}$ 中的符号，形成活动序列。重放适应度 $fit(\sigma, M)$ 衡量有限状态机（FSM） $M$ 重放序列 $\sigma$ 时成功消费符号的比例，是评估结构恢复质量的核心指标。

LLM Agent 安全领域的核心矛盾在于长程行为的安全性不可组合：单步动作看似安全，但多步轨迹组合可能产生有害结果。主流防御路线如 AgentSpec 和 ShieldAgent 依赖人工编写的安全策略，而 AgentMonitor 和 ProbGuard 虽能预测任务性能，但前者使用扁平的 XGBoost 模型，后者依赖离散时间马尔可夫链（DTMC）和概率计算树逻辑（PCTL），均缺乏对跨运行拓扑结构的显式建模。现有行为抽象方法如 Agent Workflow Memory (AWM) 仅从成功轨迹提取线性工作流，无法捕捉失败模式或状态转移的循环结构。本文的切入点在于利用智能体行为由有限工具集生成的特性，从原始轨迹中自动恢复紧凑的 FSM，作为预测与监控的结构基座。

## 核心方法

### 方法参照系

本文问题属于自动机学习中的正向示例学习范畴，但与传统方法的关键差异在于：智能体轨迹仅提供正向示例，且字母表大小受限于工具数量（6-42 符号），这使得基于前缀树合并的确定性构建成为可能，无需负示例或查询 oracle。

### 基于最后活动右同余的线性时间 FSM 构建

传统自动机学习如 RPNI 和 EDSM 依赖统计检验或超参数调整，导致状态空间爆炸（$10^3-10^5$ 状态）且拓扑不稳定。本文采用三步构建算法：首先将所有活动序列插入前缀树，每个唯一前缀对应一个状态；其次，通过最后活动右同余 $q \sim q' \iff \kappa(q) = \kappa(q')$ 合并状态，其中 $\kappa(q)$ 为进入状态 $q$ 的活动，该合并将状态数压缩至 $|\mathcal{A}|+1$；最后，过滤仅出现一次的罕见转移，除非它是源状态的唯一延续。这一设计解决了 RPNI 因状态稀疏导致的概率估计失效问题，确保每个状态聚合足够观测值，使正向示例学习良态化。

$$
\hat{P}(a | q) = \frac{C(q, a) + \alpha}{\sum_{a' \in \mathcal{A}} C(q, a') + \alpha|\mathcal{A}|}
$$

该公式通过拉普拉斯平滑估计状态 $q$ 下活动 $a$ 的条件概率，其中 $C(q, a)$ 为训练数据中 $a$ 跟随 $q$ 的次数，$\alpha$ 为平滑参数。紧凑状态空间使该估计具有 $O(1/\sqrt{n_q})$ 的总变差收敛界，优于 RPNI 的稀疏状态估计。

### FSM 状态条件化的预测与监控

FSM 构建后，当前状态 $q_t = \delta^*(q_0, a_1 \dots a_{t-1})$ 作为上下文条件，用于下一步预测和故障预测。对于故障预测，每状态行为特征（如访问频率、意外度）构成特征向量，通过梯度提升分类器输出故障概率。在线监控器应用两条规则：循环率 >0.778 和最小唯一状态计数，其后悔界为 $O(\sqrt{T \log |Q|})$。这一设计解决了现有监控方法（如 AgentMonitor）缺乏结构感知的问题，使监控器能从部分轨迹中识别失败模式，而非依赖完整轨迹或手工谓词。

## 实验评估

实验在 12 个公开数据集上进行，涵盖编码（SWE-agent, SWE-smith）、网页导航（WebArena）、桌面 GUI（AgentNet, OSWorld）、客户服务（tau2-bench）及安全（ATBench）领域。基线覆盖自动机学习（RPNI, Alergia, k-Tails）、隐马尔可夫模型（HMM）、过程挖掘及工作流提取（AWM），但未对比知识库中的安全防御方法如 GuardAgent 或 VeriGuard。

FSM 状态条件化将平均交叉熵从 Unigram 的 2.439 bits 降至 0.934 bits，降幅 62%，其中 83-99% 的改进归因于状态条件化而非高阶上下文。在故障预测上，每状态特征在 tau2-bench telecom 上达到 0.941 的留出 AUROC，在线监控器在 25% 轨迹检查点实现 0.66 的 rank-AUROC，并在 32% 完成度时触发早期停止。

消融实验显示，FSM 上下文格式的选择至关重要：在 tau2-bench retail 上，最小格式（概率 + top-15 延续）达到 65.1% top-1 准确率，比 AWM 高 12.2 个百分点，而冗长格式（状态 + 转移 + 完整图）仅 52.2%，低于 AWM 的 52.9%。这表明结构模型的上下文设计需平衡信息量与信号稀释，最小格式通过聚焦当前状态的局部概率分布，避免了全局结构对下一步预测的干扰。

评估边界方面，论文未报告计算效率的绝对数值，仅提及构建在毫秒级完成；未提供代码 URL，可复现性依赖算法描述的完整性；评估协议基于 5 折交叉验证，未涵盖对抗性攻击或分布外场景。

## 关联研究分析

从问题动机看，本文与 VeriGuard 和 Agent-C 同属形式化验证路线，但存在根本差异：VeriGuard 依赖人工将自然语言规范转化为形式化代码，Agent-C 需构建时间逻辑公式，而本文从原始轨迹自动提取 FSM，无需人工规范。这一差异源于任务特性：VeriGuard 和 Agent-C 面向安全关键场景，需强保证，而本文面向通用开放环境，追求低开销的结构恢复。然而，自动提取的 FSM 在对抗性攻击下的鲁棒性未经验证，攻击者可能通过操纵工具调用序列破坏 FSM 的拓扑稳定性。

从方法设计看，本文与 DreamGuard 同属运行时监控路线，但机制不同：DreamGuard 使用风险感知世界模型预测未来观察，训练成本高且依赖环境动态性；本文使用 FSM 状态条件化，基于历史轨迹的统计规律，无需训练世界模型。这一差异源于数据假设：DreamGuard 假设环境动态可建模，而本文假设行为拓扑由部署框架决定，跨模型稳定（tau2-bench 上单一 FSM 对 4 个 LLM 均达到 1.000 适应度）。然而，当部署框架变更或工具集扩展时，FSM 需重新构建，其自适应能力未探索。

## 总结

本文要解决的核心矛盾是 LLM Agent 长程行为的安全性不可组合，现有方法因依赖人工规范或单轨迹处理而无法提取跨运行的共享拓扑结构。本文抓住智能体行为由有限工具集生成的特性，通过基于最后活动右同余的线性时间 FSM 构建算法，从原始轨迹自动恢复紧凑的确定性有限自动机，在 12 个数据集上实现 7-43 状态、≥0.997 适应度，故障预测 AUROC 达 0.94。本文的边界在于：FSM 构建假设行为拓扑稳定，未验证对抗性攻击下的鲁棒性；评估协议基于交叉验证，未涵盖分布外场景。当工具集动态扩展或攻击者操纵轨迹序列时，FSM 的拓扑稳定性与监控器的后悔界是否仍成立，论文未给出回答。
