# HuggingFace最新推荐论文 ｜Dual Latent Memory in Vision-Language-Action Models for Robotic Manipulation ｜双尺度潜在记忆视觉-语言-动作模型

研究机构：南京大学、浙江大学

作者：Hongyu Qu、Jianzhe Gao、Xiaobin Hu 等 9 人

论文原文见 [arXiv](https://arxiv.org/abs/2607.07608)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.07608)

> 视觉-语言-动作模型（Vision-Language-Action, VLA）在长时程任务中因马尔可夫假设产生时间短视偏差，导致无法推理历史状态转换与任务进度。现有记忆增强方法将历史经验作为外部策略侧条件，与模型内部推理空间隔离，限制了记忆对动作生成的深层影响。LaMem-VLA 将历史经验重构为上下文原生潜在记忆 Token，直接编织进 VLA 的嵌入序列参与自注意力推理。该架构在仿真基准上验证了双尺度记忆对长时程鲁棒性的增益，但缺乏真实世界动态环境下的稳定性验证。

## 研究背景

VLA 策略 $\pi$ 接收当前观测 $o_t$ 和语言指令 $l$，输出动作 $a_t$。标准马尔可夫假设下，$a_t \sim \pi(a_t | o_t, l)$，该形式适用于短时程行为，但在多阶段操作中，历史状态转换与已完成子任务成为可靠控制的关键。当模型仅依赖瞬时观测时，微小的感知偏差随时间累积，导致长时程任务失败，这一现象被称为时间短视偏差。

主流 VLA 架构分为单流与分层两类。单流模型（如 OpenVLA）在统一骨干中离散化动作并自回归预测，分层模型（如 $\pi_0$）使用 VLM 进行高层推理，配合扩散或流匹配策略生成连续动作。尽管这些方法提升了泛化能力，但均主要基于当前观测预测动作，未充分利用扩展历史上下文。现有记忆增强尝试分为两类：一是扩展时间窗口拼接历史帧，计算成本随上下文长度线性增长且存在固定记忆上限；二是从外部记忆库检索历史轨迹作为策略侧条件。后者虽证明了历史经验的价值，但记忆存储于模型原生 Token 空间之外，作为辅助上下文消费，无法与感知、推理及动作意图形成过程流体交织。LaMem-VLA 的切入点在于将机器人记忆重构为上下文原生潜在记忆，使其在模型嵌入空间内存储、检索与消费。

## 核心方法

### 方法参照系

LaMem-VLA 基于分层 VLA 架构，采用 7B 参数 Prismatic VLM 骨干与约 300M 参数扩散动作专家。其核心差异在于记忆消费路径：传统方法将检索到的历史记忆作为外部条件输入策略头，而 LaMem-VLA 将记忆压缩为潜在 Token，直接拼接到 VLM 输入序列前端，参与自注意力推理。

### 双尺度记忆库构建

设计动机在于解决单一记忆表征无法同时保留细粒度视觉证据与长时程语义连续性的问题。LaMem-VLA 引入两个互补记忆库：短期记忆库 $M_{short}$ 存储视觉感知证据，长期记忆库 $M_{long}$ 存储动作隐藏状态以跟踪任务进度。短期记忆单元为键值对 $m_s^i = (k_s, v_s)$，其中值 $v_s$ 由 SE 瓶颈压缩模块 $C_s$ 从当前视觉 Token $X_t$ 蒸馏得到，键 $k_s$ 为 $v_s$ 的均值池化表示：

$$ v_s = C_s(X_t) \in \mathbb{R}^{N_s \times C}, \quad k_s = \text{MeanPool}(v_s) \in \mathbb{R}^C $$

该公式将高维视觉特征压缩为紧凑的检索摘要，既保留了局部感知细节，又提供了高效的相似度匹配接口。长期记忆库直接写入动作隐藏状态 $H_{action}$，非键值结构，允许跨轨迹累积任务进度信息。当记忆库容量超过阈值 $L$ 时，系统计算相邻键的余弦相似度，合并最冗余的相邻单元，从而在固定上下文长度内最大化信息密度。

### 潜在记忆编织与检索

设计动机在于解决外部记忆无法与内部推理流体交织的架构隔离问题。LaMem-VLA 通过搜寻者模块从当前多模态认知表示构建上下文感知查询 $Q_{con}^t$，从双库中检索 Top-K 相关证据。压缩器模块将检索到的原始证据与可学习记忆 Token 蒸馏为固定长度的潜在短期记忆 Token $M_{short}$ 和潜在长期记忆 Token $M_{long}$。编织器模块将这些记忆 Token 前置到当前图像与语言 Token 之前，形成增强输入序列：

$$ S_t = [M_{short}; M_{long}; X_t; I; Q_{action}] $$

该序列进入 VLM 骨干，使历史记忆与当前观测、指令及动作查询在同一嵌入空间内通过自注意力交互。动作查询的输出隐藏状态随后输入扩散动作专家，生成连续动作序列。这种设计使得记忆不再是推理后的辅助条件，而是推理过程的一部分，允许模型在形成动作意图前动态调整对历史证据的依赖权重。

## 实验评估

实验在 LIBERO 和 SimplerEnv-Bridge 两个仿真平台进行。LIBERO 使用 Franka 机械臂，每任务 50 次演示，报告 50 次 rollout 的平均成功率；SimplerEnv-Bridge 使用 WidowX 机械臂，基于 Bridge v2 数据集训练 50k 步，每任务 24 次试验。基线覆盖 $\pi_0$、OpenVLA、CogACT、MemoryVLA 等代表性方法，但缺失 SimpleVLA-RL 等强化学习后训练强基线。

| 方法 | Spatial | Object | Goal | Long-10 | Long-90 | Avg |
|---|---|---|---|---|---|---|
| $\pi_0$ | 96.8 | 98.8 | 95.8 | 85.2 | – | 94.2 |
| MemoryVLA | 98.4 | 98.4 | 96.4 | 93.4 | 95.6 | 96.5 |
| LaMem-VLA | 98.8 | 99.0 | 97.2 | 95.8 | 97.0 | 97.6 |

LaMem-VLA 在 LIBERO 整体基准上达到 97.6%，较 MemoryVLA 提升 1.1 个点，较 $\pi_0$ 前四套件平均提升 3.5 个点。在 SimplerEnv-Bridge 上，LaMem-VLA 取得 73.9% 平均成功率，较 CogACT 提升 16.6 个点，较 $\pi_0$ 提升 4.7 个点。

| 配置 | SimplerEnv | LIBERO-90 |
|---|---|---|
| w/o Dual Memory | 57.3 | 92.1 |
| w/o Short-term Memory | 65.6 | 95.4 |
| w/o Long-term Memory | 64.6 | 94.8 |
| LaMem-VLA | 73.9 | 97.0 |

消融实验显示，移除双尺度记忆导致性能大幅下降，验证了视觉证据与语义连续性的互补作用。检索预算 K 从 2 增至 8 时，SimplerEnv 成功率从 66.7% 升至 73.9%，但 K=12 时降至 71.8%，表明过度检索引入冗余证据增加压缩负担。潜在原生记忆整合优于策略侧条件化（73.9% vs 71.9%）和原始检索条件化（73.9% vs 69.8%），证实增益来自记忆在嵌入空间内的原生参与而非外部上下文附加。

评估局限于仿真环境，未报告真实世界部署结果。训练使用 8 张 NVIDIA H800 GPU，全局批大小 256，学习率 $2 \times 10^{-5}$。扩散动作专家使用 DDIM 采样，10 步去噪。论文未提供代码开源链接，且未报告推理延迟与显存占用等效率指标，限制了部署可行性的评估。

## 关联研究分析

从记忆消费路径看，LaMem-VLA 与 MemoryVLA 形成直接对比。MemoryVLA 将历史轨迹存储在外部记忆库，检索后作为策略侧条件输入动作生成模块，记忆与 VLM 推理过程分离。LaMem-VLA 将记忆压缩为潜在 Token 前置到 VLM 输入序列，使其参与自注意力计算。这一差异的根源在于任务特性：长时程操作需要模型在形成动作意图前动态权衡历史证据与当前观测的权重，外部条件化无法实现这种细粒度的交互。然而，将记忆置于 VLM 输入端是否导致预训练权重被记忆噪声干扰，论文未提供消融证据。

从记忆表征形式看，LaMem-VLA 与 HAMLET 同属记忆增强路线，但机制不同。HAMLET 使用历史帧注意力直接处理原始图像序列，计算成本随历史长度增长；LaMem-VLA 使用固定容量的双尺度潜在记忆库，通过压缩与检索维持恒定上下文长度。这一设计解决了 HAMLET 在长时程任务中的计算瓶颈，但引入了压缩信息损失的风险。检索预算 K 的消融显示，K=8 为最优平衡点，K=12 时性能下降，表明压缩机制对冗余证据的容忍度有限。查询侧增强在数据充足时是否仍有增益，论文未给出回答。

## 总结

LaMem-VLA 针对 VLA 模型在长时程任务中的时间短视偏差，抓住记忆与推理空间隔离这一架构瓶颈，将历史经验重构为上下文原生潜在记忆 Token，直接编织进 VLM 嵌入序列参与自注意力推理。该设计在 LIBERO 上达到 97.6% 平均成功率，较 MemoryVLA 提升 1.1 个点，在 SimplerEnv-Bridge 上达到 73.9%，较 $\pi_0$ 提升 4.7 个点，验证了双尺度潜在记忆对长时程鲁棒性的增益。然而，实验局限于仿真环境，未验证真实世界动态噪声下的记忆稳定性，且未报告推理效率指标。当支持集增大到 5-shot 时，潜在记忆检索的边际收益是否递减，论文未给出回答。
