# HuggingFace最新推荐论文 ｜Infinite Worlds with Versatile Interactions ｜无限时长实时交互世界模型

作者：Zelin Gao、Qiuyu Wang、Jiapeng Zhu 等 20 人

论文原文见 [arXiv](https://arxiv.org/abs/2607.07534)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.07534)

> 交互式视频世界模型旨在构建能响应动作并预测物理演化的内部模拟器，其核心痛点在于自回归生成中的误差累积导致长时程漂移，以及高保真推理与实时交互的计算矛盾。现有方案通常牺牲分辨率或控制粒度以换取速度，或在分钟级后场景崩溃。本文切入点是通过混合注意力掩码抑制过拟合，结合双重蒸馏策略压缩推理步数并抑制漂移。具体做法是训练一个抗漂移的因果 DiT 骨干，蒸馏为 720p/60fps 实时模型，并封装智能体框架实现自主交互。该工作实现了小时级无衰减生成，但缺乏标准物理基准验证，其稳定性是否源于特定数据分布仍存疑。

## 研究背景

当自回归视频生成器逐帧预测未来时，每一帧都依赖于前序生成的帧，这种递归依赖导致微小误差被反馈并放大。这一现象称为误差累积，表现为纹理模糊、几何扭曲及场景漂移。为缓解此问题，模型需具备长时程一致性，即在长时间滚动中维持视觉与语义的稳定。然而，维持高保真度需要多步去噪，计算开销巨大，与实时交互的低延迟需求形成直接冲突。

交互式世界模型领域正从被动视频生成向主动具身智能演进。主流路线如 Genie 系列确立了动作条件化范式，但受限于分钟级生成时长；Sora 等模型证明了 DiT 架构的潜力，但未解决实时部署问题。现有方案在实时性与长时程稳定性之间做出取舍：要么降低分辨率以加速，要么牺牲控制粒度以维持质量。LingBot-World-Infinity 针对这一瓶颈，提出通过架构创新同时解决误差累积与实时性矛盾，实现无限时长的实时交互世界。

## 核心方法

### 方法参照系

本文问题属于实时交互架构路线，标准流程采用 DiT 骨干与自回归生成范式。关键差异在于：标准流程仅用 Teacher Forcing 掩码，易导致长上下文过拟合；标准蒸馏仅关注速度，未显式抑制漂移。本文引入 MoBA 混合掩码与双重蒸馏策略，解决上述失效。

### MoBA 注意力掩码

设计动机：纯 Teacher Forcing 掩码在长上下文下导致模型过度依赖历史帧而非预测未来，引发过拟合与质量退化。本文在 Teacher Forcing 掩码基础上追加双向注意力块，形成混合机制。自注意力中，噪声帧 $x_i^t$ 仅关注自身及干净上下文 $x_{<i}$，同时通过双向块关注所有帧，促进从双向到自回归的过渡。交叉注意力中，自回归部分关注背景提示 $a_B$ 及当前及之前块的提示 $a_{\le i}$（下三角模式），防止未来语义泄漏；双向部分关注全局提示 $a_G$。该设计作为正则化器，缓解纯 Teacher Forcing 的过拟合，避免视觉质量退化。

$$
L_{fm} = \mathbb{E}_{x, i, t, \epsilon} \left\| v_\theta \left( x_i^t, t \mid x_{<i}, p_{\le i}, a_{\le i} \right) - (\epsilon - x_i) \right\|^2
$$

该公式表示条件流匹配损失，训练网络 $v_\theta$ 预测流速度，条件包括干净上下文、相机位姿及提示，目标速度为 $\epsilon - x_i$。

### 双重蒸馏策略

设计动机：一致性蒸馏减少去噪步数但可能降低保真度并加剧漂移；分布匹配蒸馏（DMD）优化生成器以匹配数据分布，抑制自滚动漂移。本文结合两者：首先通过一致性蒸馏将教师模型的多步去噪轨迹压缩为少步学生生成器，保持动作条件动态；随后应用 DMD，在长自滚动轨迹上优化，使学生在自身预测诱导的状态分布上训练，减少累积漂移。

$$
\nabla_\theta \mathbb{E} \left[ D_{KL} \left( p_{\theta,t} \parallel p_{data,t} \right) \right] = -\mathbb{E} \left[ \left( s_{real}(\hat{x}_i^t, t \mid c) - s_{fake}(\hat{x}_i^t, t \mid c) \right) \frac{\partial \hat{x}_i}{\partial \theta} \right]
$$

该公式表示 DMD 梯度，通过真实数据分布分数 $s_{real}$ 与学生分布分数 $s_{fake}$ 的差值优化生成器，条件 $c$ 包括上下文、位姿及提示。

## 实验评估

实验设置使用自采集第一人称视频、合成数据及网络视频，未采用 LIBERO、DROID 等标准机器人基准。基线覆盖 Genie 3、HappyOyster 等闭源系统及 Matrix-Game 等开源模型，但缺失针对物理一致性的专用基线（如 ABot-PhysWorld）。

| 模型 | 生成时长 | 语义交互 | 领域 | 动态度 | 实时性 | 开源 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| M-G 3.0 | Minutes | None | Game | Medium | ✓ | ✓ |
| D-W | Minutes | None | General | Medium | ✓ | ✓ |
| LingBot-World | Minutes | None | General | High | ✓ | ✓ |
| HappyOyster | Minutes | Few | General | Medium | ✓ | ✗ |
| Genie 3 | Minutes | Few | General | Medium | ✓ | ✗ |
| Ours | Hours (Infinite) | Infinite | General | High | ✓ | ✓ |

本文模型在生成时长上显著超越基线（小时级 vs 分钟级），且是唯一实现无限时长、高动态度、语义交互及实时性的开源模型。

消融实验未提供具体数值，但定性展示表明 MoBA 掩码与 DMD 组合有效抑制漂移。设计决策验证显示，双向注意力块作为正则化器，防止长上下文过拟合；DMD 在自滚动轨迹上优化，减少累积误差。

评估边界：指标完备性不足，缺乏标准物理基准数值；评估协议局限，仅定性展示小时级稳定性，未报告置信区间；可复现性良好，提供 GitHub 与 HuggingFace 链接，但超参数细节未完全公开。

## 关联研究分析

从问题动机看，本文与 Dreamer 4 均强调长时程稳定性，但 Dreamer 侧重 RL 策略训练，本文侧重实时视频生成。Dreamer 4 在 Minecraft 上达到 0.92 准确率，但依赖强化学习在线探索，计算开销大；本文通过蒸馏实现实时性，但缺乏策略训练验证。差异根源在于任务特性：Dreamer 面向控制任务，本文面向交互体验。

从方法设计看，本文与 ABot-PhysWorld 均关注物理合理性，但 ABot 用 DPO 后训练抑制非物理行为，本文用智能体框架引导。ABot-PhysWorld 在 RoboTwin 上达到 0.90 准确率，依赖高质量物理标注；本文通过 Pilot-Director 智能体框架生成符合物理逻辑的事件，但未显式优化物理损失。差异根源在于物理对齐路径：ABot 采用软约束后训练，本文采用智能体引导，后者更灵活但缺乏显式物理保证。

## 总结

本文要解决的核心矛盾是自回归生成中的误差累积与实时交互的计算限制。现有方法因纯 Teacher Forcing 过拟合及单步蒸馏漂移而受限，本文通过 MoBA 混合掩码抑制过拟合，结合一致性蒸馏与 DMD 双重策略压缩步数并抑制漂移，实现小时级无衰减生成。实验证明其在生成时长、语义交互及实时性上超越基线，但缺乏标准物理基准验证。边界在于稳定性可能源于特定数据分布，智能体框架能否替代显式物理约束保证长期物理一致性，论文未给出回答。
