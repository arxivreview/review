研究机构：美国马萨诸塞大学阿默斯特分校

作者：Abhranil Chandra、Sankaran Vaidyanathan、Utsav Dhanuka 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.29315)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.29315)

> 现有大语言模型智能体依赖预训练参数知识或静态检索，在需要主动探索未知物理环境的任务中失效。本文指出，智能体需通过“主动实验”获取实例特异性证据，而非仅靠回忆。HExA 提出一种免训练、基于上下文的强化学习框架，通过迭代实验、技能蒸馏与跨任务迁移，将交互经验转化为可复用的层级技能库。该框架在复杂物理推理基准上显著提升了前沿与开源模型的性能，但其技能库的容量限制与对特定干预 API 的依赖，限制了其在更广泛非结构化环境中的通用性。

## 研究背景

当智能体面对一个从未在训练语料中出现过的物理场景时，其预训练参数中存储的通用物理定律无法直接转化为具体的操作策略。这种“知识-行动”鸿沟要求智能体具备主动实验能力：通过调用环境 API 进行假设检验、观察中间动力学状态，并基于反馈调整策略。然而，单次实验成本高昂，且智能体通常面对一系列相关实例，若每次均从零开始探索，则无法利用实例间的结构相似性来摊销探索成本。

当前主流的智能体训练路线主要依赖参数化微调（如强化学习）或非参数化的提示工程。参数化方法虽能优化策略，但面临高计算成本、灾难性遗忘风险，且需要大量标注数据或可验证奖励；提示工程（如 ReAct、Reflexion）虽轻量，但缺乏跨回合的经验积累机制，难以在长程任务中实现持续改进。现有技能库构建方法多依赖人工标注或外部执行反馈，缺乏在无监督、无离线数据的纯交互场景下自动进化技能的能力。HExA 的切入点在于，将“实验”本身作为学习信号，通过免训练的上下文机制，将交互轨迹蒸馏为结构化技能，实现无需参数更新的自我进化。

## 核心方法

### 方法参照系

HExA 属于非参数化适应（Non-parametric Adaptation）路线，其参照系为 In-Context Reinforcement Learning (ICRL)。标准 ICRL 通过维护原始交互上下文来更新策略，但上下文长度受限且信息密度低。HExA 的关键差异在于，它不直接保留原始轨迹，而是通过 Evolver 组件将轨迹压缩为结构化的“技能库”（Skill Bank），实现了跨回合的知识抽象与检索。

### 实验驱动的技能蒸馏

在标准 ICRL 中，智能体直接利用历史上下文进行决策，但缺乏对成功与失败原因的显式归因。HExA 引入 Actor-Evolver 循环，Actor 执行实验并生成带奖励标签的轨迹，Evolver 则通过对比高奖励与低奖励轨迹，提取“策略技能”与“错误记录”。这一设计解决了传统反思机制（如 Reflexion）仅能进行单回合自我批评、无法跨回合积累结构化知识的问题。技能蒸馏的核心公式为：

$$
K_n = \pi_{ev}(K_{n-1}, T_{[n]})
$$

其中 $K_n$ 为第 $n$ 轮更新后的技能库，$T_{[n]}$ 为当前轮次的轨迹批次。该公式表明，技能库的更新是累积性的，新技能基于旧技能与新证据进行合并、修订或剪枝，从而形成层级化的知识结构。

### 层级技能检索与迁移

技能库的容量有限，且不同任务间的技能需具备可迁移性。HExA 引入 Retriever 组件，根据当前任务状态从技能库中检索最相关的 $M$ 个技能与 $N$ 个错误记录，注入 Actor 的上下文。对于跨任务迁移，Evolver 通过去除源任务特定的参数绑定，将机制级抽象（如“接触几何控制冲量方向”）重新锚定到目标任务的实体与约束上。这一机制解决了静态技能库无法适应新环境、且低层细节（如具体坐标）不可复用的问题。迁移过程可形式化为：

$$
K_{\ell^*} = \text{Synthesize}(\{K_{\ell_i}\}_{i=1}^S, \ell^*)
$$

其中 $K_{\ell^*}$ 为目标任务的技能库，$\ell^*$ 为目标任务描述。该过程无需目标任务的任何交互轨迹，实现了零样本跨任务迁移。

## 实验评估

实验在自建基准 INTERPHYRE 上进行，该基准基于 PHYRE 扩展，提供场景检查、部分模拟与反事实干预 API。基线包括 DIRECT（无工具单次推理）、ReAct、Reflexion 及参数化 RL 方法 GRPO。HEXA 在 Claude Sonnet 4.6 上表现最佳，在 `catapult` 级别达到 67.3% 成功率，而 ReAct 仅为 8.0%，Reflexion 为 21.3%。

| 方法 | `catapult` 准确率 (%) | `pass_the_parcel` 准确率 (%) |
| :--- | :--- | :--- |
| DIRECT | 2.0 | 0.0 |
| ReAct | 8.0 | 24.0 |
| Reflexion | 21.3 | 16.0 |
| HEXA (Off2On Evol.) | 67.3 | 60.0 |

消融实验显示，奖励加权蒸馏（Reward-weighted）比无奖励对比（No reward）在 `down_to_earth` 上提升 8.0 个百分点（72.0% vs 64.0%），在 `two_body_problem` 上提升 8.0 个百分点（34.0% vs 26.0%）。Off2On Evolving 配置优于 Pure Online，表明初始离线技能库对加速在线学习至关重要。

评估边界方面，INTERPHYRE 为程序化生成的 2D 物理环境，其工具 API 高度结构化，与真实世界非结构化环境的差距较大。HEXA 依赖特定的干预 API（如 `simulate_with_trace`），若环境仅提供黑盒执行接口，其实验设计能力将受限。代码与超参数已公开，但技能库容量 $M, N$ 的敏感性分析未在正文中详细展开。

## 关联研究分析

从问题动机看，HExA 与 Reflexion 均关注从失败中学习，但 Reflexion 依赖单回合的语言反馈，缺乏跨回合的结构化积累；HExA 通过技能库实现了经验的持久化与层级化，解决了长程任务中的信用分配难题。与 GRPO 等参数化 RL 方法相比，HExA 在低样本预算下样本效率更高，因为技能可立即注入上下文，而 RL 需累积梯度信号。然而，GRPO 在足够训练轮次后能超越 HExA，表明上下文学习存在性能天花板，参数化更新在复杂策略优化中仍具优势。

从方法设计看，HExA 与 AutoSkill、SkillX 等技能构建方法不同，后者依赖外部执行反馈或人工标注，而 HExA 完全依赖环境交互反馈，适用于无监督场景。与 In-Context RL 相比，HExA 将原始上下文压缩为结构化技能，提升了检索效率与信息密度。但 HExA 的技能表示为自然语言，可能难以捕捉连续物理状态的细微变化，且技能库的容量限制可能导致长程任务中的记忆丢失。

## 总结

HExA 解决了智能体在未知环境中缺乏主动实验能力与跨任务经验复用的矛盾。其切入点在于将实验交互转化为结构化技能，通过免训练的上下文机制实现自我进化。实验表明，HExA 在复杂物理推理任务上显著优于 ReAct 与 Reflexion，且在低样本预算下优于 GRPO。然而，其性能依赖于结构化的干预 API 与有限的技能库容量，且在足够训练轮次后仍落后于参数化 RL。当环境仅提供黑盒执行接口或技能库容量受限时，HExA 的层级技能蒸馏机制是否仍能保持有效的跨任务迁移，论文未给出明确回答。
