# HuggingFace最新推荐论文 ｜Jet-Long: Efficient Long-Context Extension with Dynamic Bifocal RoPE ｜动态双焦旋转位置编码

作者：Haozhan Tang、Zerui Wang、Yuxian Gu 等 5 人

论文原文见 [arXiv](https://arxiv.org/abs/2607.07740)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.07740)

> 长上下文大语言模型在推理时面临预训练窗口外位置编码分布外（Out-of-Distribution, OOD）与注意力扩散的双重失效，导致有效上下文长度远低于标称值。现有零样本扩展方法如 YaRN 和 Self-Extend 需预先固定缩放因子或拟合参数，在短上下文保真度与长上下文泛化能力间存在固有权衡。本文提出 Jet-Long，通过解析式动态整数分组因子将远程位置映射回预训练网格，结合包含-排除注意力合并实现无调参零样本扩展。该方法在 Qwen3 系列模型上实现了 128K 上下文下的性能突破，但其对混合注意力架构的泛化性及超参数鲁棒性仍需进一步验证。

## 研究背景

当大语言模型处理超过预训练窗口的长序列时，旋转位置编码（Rotary Position Embedding, RoPE）的低频分量产生超出训练分布的旋转角度，导致注意力分数行为异常。这种位置分布外问题与 softmax 注意力在长序列下的概率质量分散效应共同作用，使得模型对中间位置信息的利用率显著降低，即“中间迷失”现象。解决这一问题的关键在于如何在推理时动态调整位置映射，使所有远程旋转角度保持在预训练分布内，同时避免对 KV 缓存的破坏性重写。

零样本上下文扩展是开源大语言模型部署的主流路径，旨在不微调的情况下支持任意长度的下游任务。主流方法分为频率重缩放与分组位置两类：YaRN 通过维度频率分区与注意力温度校正实现外推，但需预先确定固定缩放因子；Self-Extend 采用双窗口分解，局部窗口保留经典 RoPE，远程窗口使用固定分组大小，但分组大小需针对特定模型拟合。这些方法在短上下文保真度与长上下文泛化能力间存在权衡：激进的缩放因子牺牲短上下文性能，保守的因子则在长上下文下失效。本文的切入点在于将分组大小从固定或拟合参数转变为当前序列长度的解析函数，消除超参数依赖，同时通过动态别名机制确保远程位置严格位于预训练网格上。

## 核心方法

### 方法参照系

零样本上下文扩展的标准流程是在推理时修改位置编码或注意力计算，使模型能处理超出预训练窗口的输入。本文问题与该通用流程的关键差异在于：传统方法需预先确定或拟合位置映射参数，而本文要求映射参数随当前序列长度动态变化，且在生成过程中保持 KV 缓存不变。

### 动态双焦位置映射

传统分组方法如 Self-Extend 使用固定分组大小 $G$，导致在短上下文下过度压缩位置分辨率，在长上下文下压缩不足。本文在远程窗口位置映射环节引入动态分组因子，将分组大小定义为当前序列长度 $L$ 与预训练窗口 $w_{pretrained}$ 的最小整数压缩比：

$$
G = \max\left(1, \left\lceil \frac{L}{w_{pretrained}} \right\rceil\right)
$$

远程位置映射采用向下取整除法 $f(x) = \lfloor x/G \rfloor$，将绝对位置压缩至预训练窗口内。这一设计确保当 $L \leq w_{pretrained}$ 时 $G=1$，映射退化为恒等函数，模型行为与基线完全一致；当 $L > w_{pretrained}$ 时，$G$ 取最小整数使压缩后序列长度不超过 $w_{pretrained}$，最大化位置分辨率。相比 LaMPE 等需拟合 sigmoid 函数的方法，该解析式无需模型特定参数，实现了即插即用的动态适配。

### 包含-排除注意力合并与缓存校正

动态分组因子在生成过程中随序列增长而变化，若直接重写 KV 缓存将导致计算开销激增。本文在注意力计算环节引入包含-排除原理，通过三次 FlashAttention 调用实现精确的距离路由：局部窗口（$q-k \leq w_0$）使用基线 RoPE，远程窗口（$q-k > w_0$）使用动态映射 RoPE。最终输出通过 LogSumExp 稳定化合并：

$$
O_{final} = \frac{W_A O_A + W_B O_B - W_C O_C}{W_A + W_B - W_C}
$$

其中 $W_X = \exp(\ell_X - M)$，$M = \max(\ell_A, \ell_B, \ell_C)$。该合并机制在 FP32 精度下避免减法导致的数值灾难，同时保持 FlashAttention 的内存效率。在解码阶段，KV 缓存存储未压缩的基线位置键，通过在线校正旋转 $q_{remote} = RoPE(q_{local}, \Delta_q)$ 和 $k_{remote} = RoPE(k_{cache}[k], \Delta_k)$ 实现远程视图，其中 $\Delta_q = f(q) - q$，$\Delta_k = f(k) - k$。这一常数时间操作避免了缓存重写，使流式生成跨越长度边界时无需停顿。

## 实验评估

实验在 Qwen3-1.7B/4B/8B-Base 模型上进行，预训练窗口均为 32K，扩展至 128K 上下文。基线覆盖频率重缩放（DNTK、YaRN）与分组位置（DCA、Self-Extend）两类主流零样本方法，但未包含 NoPE 或稀疏注意力等替代架构。主实验结果显示，Jet-Long 在 RULER 基准上领先最强基线 4.79/2.18/2.03 个百分点（1.7B/4B/8B），在 PG-19 困惑度上取得最低值，在 HELMET-RAG 上 4B 和 8B 模型表现最佳。

| 模型 | 方法 | RULER Avg (%) | PG-19 Avg (ppl) |
| :--- | :--- | :--- | :--- |
| Qwen3-1.7B-Base | Base | 60.93 | 16.13 |
| Qwen3-1.7B-Base | DNTK | 69.14 | 12.60 |
| Qwen3-1.7B-Base | Self-Extend | 67.86 | 11.85 |
| Qwen3-1.7B-Base | Jet-Long | 73.93 | 11.72 |
| Qwen3-8B-Base | Base | 73.13 | 12.80 |
| Qwen3-8B-Base | DNTK | 83.54 | 9.13 |
| Qwen3-8B-Base | Self-Extend | 84.71 | 8.81 |
| Qwen3-8B-Base | Jet-Long | 86.74 | 8.73 |

消融实验聚焦局部窗口大小 $w_0$ 的敏感性。$w_0=0$ 时 RULER 准确率接近零，证实局部窗口的必要性。在 $w_0 \in \{512, 1024, 2048, 4096\}$ 范围内，Jet-Long 在任意单一长度下与该行最佳值差距不超过 2 个百分点，在模型平均上差距不超过 1 个百分点，表明该方法对超参数选择具有鲁棒性。$w_0=8192$ 时性能下降 1.4-2.1 个百分点，反映局部窗口占用过大比例上下文导致的远程压缩过度。

评估边界方面，实验仅覆盖 128K 上下文，未测试百万级 Token 下的动态分组稳定性。HELMET-RAG 在 1.7B 模型上落后 Self-Extend 0.73 个百分点，可能源于小模型对动态分组分辨率损失的敏感性。代码已开源，超参数 $w_0=2048$ 无需针对部署调优，所有实验在 NVIDIA H100 GPU 上完成，预填充吞吐量达 FlashAttention-2 的 1.28-1.39 倍，生成开销不超过 4%。

## 关联研究分析

从方法设计看，Jet-Long 与 Self-Extend 共享双窗口分解架构，但核心差异在于分组因子的确定方式。Self-Extend 使用固定分组大小，需在短上下文保真度与长上下文泛化间权衡；Jet-Long 通过解析式 $G = \lceil L/w_{pretrained} \rceil$ 实现动态适配，消除了超参数依赖。这一改进的根源在于任务特性：零样本扩展要求单一检查点支持任意长度，固定因子无法同时优化所有长度区间，而动态因子在每个长度下都取最小压缩比，最大化位置分辨率。与 YaRN 的频率重缩放路线相比，Jet-Long 采用位置别名机制，将远程位置映射至预训练网格，避免了高频信息损失，但可能牺牲远程位置的精细分辨率。

从问题动机看，Jet-Long 与 DCA 同属分组位置方法，但 DCA 使用非对称查询/键索引确保相对距离在预训练范围内，而 Jet-Long 通过包含-排除合并实现精确的距离路由。DCA 的跨块通信依赖固定块大小，在长序列下块内信息隔离问题加剧；Jet-Long 的动态分组随序列增长自适应调整，缓解了这一问题。然而，Jet-Long 未直接处理 softmax 注意力扩散，而是通过精确路由避免无关 token 参与远程注意力计算，这与 YaRN 的温度校正策略形成互补。混合注意力架构（如 Jet-Nemotron）中的线性注意力层天然抑制注意力扩散，Jet-Long 的泛化性验证表明双焦分解与动态因子可跨架构迁移，但其在纯线性注意力模型中的表现未做测试。

## 总结

本文要解决的核心矛盾是零样本上下文扩展中固定缩放因子导致的短上下文保真度与长上下文泛化能力间的权衡。现有方法如 YaRN 和 Self-Extend 需预先确定或拟合参数，无法在单一检查点下同时优化所有长度区间；Jet-Long 通过解析式动态分组因子 $G = \lceil L/w_{pretrained} \rceil$ 实现即插即用，结合包含-排除注意力合并与在线缓存校正，在保持 KV 缓存不变的前提下实现动态适配。实验证明该方法在 Qwen3 系列模型上 RULER 准确率领先最强基线 4.79 个百分点（1.7B），PG-19 困惑度最低，且对超参数 $w_0$ 具有鲁棒性。本文的边界在于实验仅覆盖 128K 上下文，未验证百万级 Token 下的动态分组稳定性，且 HELMET-RAG 在 1.7B 模型上略逊于 Self-Extend。当序列长度增长至预训练窗口的数十倍时，动态分组因子的最小整数压缩比是否会导致远程位置分辨率损失累积，进而影响多跳推理的准确性，论文未给出回答。
