# HuggingFace最新推荐论文 ｜MemLearner: Learning to Query Context memory for Video World Models ｜学习式上下文查询

研究机构：复旦大学、浙江大学

论文原文见 [arXiv](https://arxiv.org/abs/2606.31734)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.31734)

> 视频世界模型在长时程生成中因上下文窗口限制导致场景记忆丢失，现有基于规则（如视场重叠、点云匹配）的检索方法在遮挡与动态物体场景下失效。本文提出 MemLearner，通过引入可学习的查询令牌（Query Tokens）替代硬编码规则，利用预训练视频扩散模型自身作为查询模块，实现端到端的自适应上下文提取。该方法在复杂场景下显著提升了生成一致性，但在简单场景下优势微弱，且依赖渲染数据训练，其真实世界泛化能力与计算效率的平衡仍需进一步验证。

## 研究背景

视频世界模型的核心任务是基于历史观测与动作预测未来状态，其基础架构通常采用因果 3D 变分自编码器（Causal 3D VAE）将视频压缩至潜空间，并结合扩散 Transformer（DiT）进行去噪生成。在长视频生成中，模型需将历史帧潜变量（Context Tokens, C）与待生成帧潜变量（Predicted Tokens, P）拼接输入，但受限于注意力机制的计算复杂度，模型无法保留所有历史帧，导致“记忆缺失”：当相机返回初始位置时，生成的场景与之前不一致。

解决记忆缺失的主流路线包括 3D 重建、特征压缩与上下文检索。其中，上下文检索因无需额外 3D 重建开销而备受关注，但现有方法如 Context-as-Memory (CaM) 依赖视场重叠（FOV Overlap）规则，VMem 依赖点云匹配，这些硬编码规则无法处理遮挡墙壁或移动物体，且在动态环境中缺乏泛化性。本文切入点在于将检索过程从“规则驱动”转变为“学习驱动”，即让模型通过端到端训练自主决定从历史帧中提取哪些信息，从而克服规则方法在复杂场景下的结构性缺陷。

## 核心方法

### 方法参照系

本文基于潜空间视频扩散模型，采用分块自回归（Chunk-by-chunk Autoregressive）范式。标准流程中，历史帧潜变量 C 与待生成帧潜变量 P 直接拼接输入 DiT，扩散损失仅施加于 P。本文的关键差异在于引入中间查询令牌 Q，构建 C-Q-P 的信息传递链路，并修改注意力计算模式以支持高效查询。

### 学习式查询令牌机制

传统方法直接让 P 关注 C，或引入独立模块提取 C 的特征再供 P 使用。本文发现，独立从零训练的查询模块与预训练 DiT 联合训练时，梯度传播受阻，导致模块失效。因此，本文提出利用 DiT 自身作为查询引擎：将 C、Q、P 拼接输入，Q 令牌作为信息桥梁，通过注意力机制从 C 中提取信息，P 再关注 Q 以指导生成。训练损失仅针对 P 的噪声预测，Q 的查询能力通过间接监督学习获得。

$$
\mathcal{L} = \mathbb{E}_{\mathbf{x}, \epsilon \sim \mathcal{N}(0, I), t} \left[ \| \epsilon - \epsilon_\theta(\mathbf{C}, \mathbf{Q}, \mathbf{P}_t, t) \|_2^2 \right]
$$

该公式表明，尽管 Q 令牌参与前向传播，但监督信号仅来自 P 的去噪误差，迫使 Q 自适应地提取对 P 生成有用的上下文信息，而非依赖显式的查询损失。

### 分层注意力效率策略

全层全令牌注意力计算开销巨大。本文提出两种策略：(1) 层分割（Layer-Split），仅在浅层 Query Layers 进行 C-Q-P 交互，深层 Generative Layers 仅处理 Q-P；(2) 计算剔除，保留 Q 关注 P、Q 关注 C、P 关注 Q/P 三种关键注意力模式，剔除 C 作为查询源的计算。

$$
\mathbf{F}_{out}^{Query} = \text{Attention}(\mathbf{Q}, \mathbf{C}, \mathbf{P}) \oplus \text{Attention}(\mathbf{Q}, \mathbf{P}, \mathbf{P})
$$

此设计将查询任务限制在浅层，利用浅层特征的空间局部性进行高效信息提取，深层则专注于基于查询结果的高维语义生成，显著降低了长序列生成的计算成本。

## 实验评估

实验在自建 Unreal Engine 数据集（含遮挡/动态）、CaM 数据集（无遮挡/静态）及 SpatialVID 上进行。基线包括 DFoT（无记忆）、FramePack（特征压缩）、VMem（点云检索）及 CaM（FOV 检索）。在自建复杂数据集上，MemLearner 在 GT Comp. 的 PSNR 达到 21.23，LPIPS 0.2904，FID 112.75，FVD 835.98，全面优于 CaM（PSNR 19.85, FID 125.35）和 VMem（PSNR 19.59, FID 129.94）。

| 方法 | GT Comp. PSNR↑ | GT Comp. LPIPS↓ | GT Comp. FID↓ | Revisit Comp. PSNR↑ | Revisit Comp. FID↓ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| DFoT | 16.98 | 0.4796 | 147.09 | 16.14 | 151.38 |
| CaM | 19.85 | 0.3475 | 125.35 | 17.61 | 137.87 |
| VMem | 19.59 | 0.3872 | 129.94 | 17.30 | 141.82 |
| **Ours** | **21.23** | **0.2904** | **112.75** | **18.57** | **101.57** |

消融实验显示，移除 Q 关注 P 的注意力模式导致性能显著下降，证明 Q 需从 P 获取生成目标信息以指导查询。在 CaM 简单数据集上，MemLearner（PSNR 20.35）与 CaM（PSNR 20.22）差距缩小，表明学习机制在简单场景下收益有限。相机嵌入消融显示，即使移除 C 的相机位姿，模型仍能通过视觉内容学习查询，验证了方法对几何先验的弱依赖性。

评估协议采用 PSNR/LPIPS 衡量记忆一致性，FID/FVD 衡量视觉质量。局限在于缺乏 3D 重建类基线（如 NeRF-based）的直接对比，且未报告推理速度（FPS）的详细对比数据（仅定性提及效率提升）。代码未完全开源，仅提供项目页面，复现需依赖内部 1B 参数模型，限制了外部验证。

## 关联研究分析

从问题动机看，MemLearner 与 CaM、VMem 同属“上下文作为记忆”范式，但根本差异在于检索机制。CaM 依赖几何先验（FOV 重叠），在遮挡场景下因视场被阻断而失效；MemLearner 通过端到端学习，隐式捕捉遮挡后的语义关联，无需显式几何计算。这种差异源于任务特性：规则方法假设场景静态且几何可解，而学习式方法适应动态与复杂拓扑。然而，学习式方法的可解释性较差，无法明确说明为何选择特定历史帧，这在需要严格几何约束的自动驾驶场景中可能成为隐患。

从方法设计看，MemLearner 与 Perceiver Resampler 等视觉语言模型中的查询机制类似，均使用可学习查询压缩上下文。但 MemLearner 的独特之处在于将查询模块与生成模型统一，而非独立模块。这种设计避免了独立模块与预训练模型间的梯度冲突，但牺牲了模块化灵活性。与 3D 重建方法（如 3D Gaussian Splatting）相比，MemLearner 避免了重建误差累积，但缺乏显式 3D 结构约束，可能在长时程生成中逐渐偏离真实几何。

## 总结

MemLearner 解决了视频世界模型中规则检索在遮挡与动态场景下失效的核心矛盾，通过引入学习式查询令牌并利用预训练 DiT 自身作为查询引擎，实现了端到端的自适应上下文提取。实验证明其在复杂场景下 PSNR 提升约 1.4 dB，FID 降低约 12.6，显著优于 CaM 和 VMem。然而，该方法在简单场景下优势微弱，且依赖渲染数据训练，真实世界无标注数据的泛化能力未充分验证。当支持集增大或场景复杂度降低时，学习式查询的边际收益是否递减，论文未给出回答。
