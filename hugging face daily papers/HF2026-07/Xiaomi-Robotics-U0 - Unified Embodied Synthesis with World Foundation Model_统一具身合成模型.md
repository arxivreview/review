# HuggingFace最新推荐论文 ｜Xiaomi-Robotics-U0: Unified Embodied Synthesis with World Foundation Model ｜统一具身合成模型

研究机构：小米

作者：Xinghang Li、Jun Guo、Qiwei Li 等 24 人

论文原文见 [arXiv](https://arxiv.org/abs/2607.11643)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.11643)

> 具身智能要求机器人在行动前预测多视角环境演化，但现有基础视频生成模型直接适配机器人数据时，往往因数据规模小且重复而丧失通用视觉泛化能力，导致生成场景几何不一致或物理状态失真。本文切入点在于将具身生成重构为基础图像与视频生成的自然扩展，而非独立的后训练任务。通过单一自回归框架联合优化通用与具身数据，模型在保持基础模型语义理解的同时，实现了多视角场景的结构化可控生成与视频推演。该方案在真实机器人策略鲁棒性上取得显著提升，但其对长时程动态物理一致性的验证仍局限于特定任务集，通用性边界尚待更严苛的开放域测试。

## 研究背景

当机器人执行复杂操作时，其视觉观测必须严格符合相机标定、机械臂运动学及物体物理交互规律，这一约束被称为具身一致性。传统基础生成模型仅关注像素分布匹配，缺乏对多视角几何连贯性与动作-视觉因果关系的显式建模，直接应用于具身场景会导致生成的机器人状态不可执行或场景结构崩坏。解决此问题的关键在于引入显式的具身约束，但现有方法通常通过独立的预测头或专用架构实现，割裂了基础模型在大规模互联网数据上习得的通用视觉先验。

交互式视频世界模型领域的主流路线是将预训练扩散模型或自回归模型在机器人轨迹数据上进行微调，以习得动作条件化的未来帧预测能力。然而，具身数据集相比互联网视觉语料库规模极小且高度重复，这种适配范式不可避免地削弱了模型继承的泛化能力，限制了生成内容的多样性与可控性。现有方法如 Dreamer 系列或 World Action Models 虽在特定游戏或仿真环境中有效，但难以在真实多视角机器人场景中保持几何持久性，且缺乏对场景元素（如光照、背景、目标物体）的细粒度独立控制，无法直接作为下游策略学习的数据增强引擎。

Xiaomi-Robotics-U0 针对这一瓶颈，提出将具身合成视为基础生成的扩展而非独立任务。其核心假设是，通过在统一自回归目标下联合训练通用图像生成与具身场景生成，可以保留基础模型的语义理解能力，同时注入具身特有的几何与物理约束。这种统一范式旨在解决“适配导致遗忘”的矛盾，使模型既能生成高保真的多视角初始场景，又能通过结构化控制实现场景迁移，最终支持零样本的具身视频生成，为具身智能提供可扩展的合成数据源。

## 核心方法

### 统一自回归序列建模

本文方法置于多模态自回归生成框架下，与传统的扩散模型视频生成路线不同，其关键差异在于将所有模态（文本、图像、机器人控制）映射至统一离散词表，通过单一 Next-Token Prediction (NTP) 目标联合优化。这种设计避免了为具身任务引入专用预测头，从而在架构层面保证了通用生成能力与具身生成能力的共享。

### 结构化具身控制解耦

针对具身场景生成中多视角一致性与细粒度可控性的矛盾，本文在参照系基础上引入结构化控制机制。传统方法通常将场景描述作为整体文本输入，导致模型难以独立调整特定元素。本文将场景分解为工作区、背景、无关前景物体、目标物体及光照五个正交语义维度，并分别生成描述。在推理阶段，通过条件注入实现对各维度的独立控制。该设计解决了此前方法在场景迁移时无法保持几何一致性同时改变局部属性的问题，使得生成的数据能够在保持机器人状态不变的前提下，灵活改变视觉外观，从而有效增强下游策略的分布外鲁棒性。

### 多分辨率时序交错学习

为支持从静态场景到动态视频的扩展，本文引入多帧率（FPS）具身视频生成与子任务-子目标交错学习。模型不仅学习单帧映射，还学习跨时间步的稀疏任务级转换与密集交互动态。通过联合训练交错序列，模型捕获长时程任务进展与细粒度动作动态。这一机制使得生成的具身场景可直接滚动为时间连贯的操作视频，将静态合成转化为轨迹生成引擎，为策略学习提供丰富的合成轨迹数据。

## 实验评估

实验在真实机器人平台（ARX双臂机器人）上进行，涵盖 Store Earphones、Fold Towel 和 Pack Box 三项任务，评估指标为任务完成进度。基线对比包括 GPT-Image-2.0（人类评估）及未使用数据增强的 π0.5 策略。实验设置中，干扰组引入了未见过的桌布纹理与复杂光照，以测试分布外鲁棒性。

| 任务 | 组别 | Original 进度 (%) | Xiaomi-Robotics-U0-Aug 进度 (%) | 差值 (%) |
| :--- | :--- | :--- | :--- | :--- |
| Store Earphones | Base | 30.6 | 76.4 | +45.8 |
| Store Earphones | Interference | 54.2 | 81.9 | +27.7 |
| Fold Towel | Base | 51.1 | 100.0 | +48.9 |
| Fold Towel | Interference | 73.3 | 100.0 | +26.7 |
| Pack Box | Base | 28.9 | 66.7 | +37.8 |
| Pack Box | Interference | 62.2 | 64.4 | +2.2 |
| Average | Base | 36.9 | 81.0 | +44.1 |
| Average | Interference | 63.2 | 82.1 | +18.9 |

数据显示，在干扰组中，Xiaomi-Robotics-U0-Aug 的平均进度达到 82.1%，显著高于 Original 的 63.2%，表明结构化数据增强有效提升了策略对视觉扰动的鲁棒性。在 Base 组中，Aug 策略表现略优或持平，验证了增强数据未造成灾难性遗忘。

消融分析显示，FlashAR 加速推理在保持生成质量的同时，将 1024×1024 图像生成时间从 450.77 秒降至 5.44 秒（结合 vLLM），加速比达 82.9 倍。这一效率提升使得大规模合成数据生成在工程上可行。然而，论文未提供不同控制维度（如仅改变光照 vs 仅改变背景）对策略鲁棒性贡献的独立消融，无法确定各结构化控制维度的边际收益。

评估边界方面，实验局限于三项桌面操作任务，未涵盖动态物体交互或长时程复杂规划。代码与检查点已开源，但训练数据（MiBot）为专有数据，限制了完全复现。指标仅关注任务完成进度，未量化生成视频的几何一致性或物理合理性具体数值，缺乏与 World Arena 等基准的详细对比数据。

## 关联研究分析

从问题动机看，Xiaomi-Robotics-U0 与 ABot-PhysWorld 均关注具身生成的物理一致性，但路径截然不同。ABot-PhysWorld 采用 DPO 后训练抑制非物理行为，侧重于行为层面的约束；而本文通过结构化控制解耦场景元素，侧重于数据层面的多样性增强。这种差异源于任务目标的不同：前者旨在直接优化策略的物理合理性，后者旨在通过数据增强提升策略的分布外鲁棒性。本文未探索 DPO 等偏好优化方法，可能限制了其在物理违规严重场景下的表现。

从方法设计看，本文与 PlayWorld 均利用生成数据提升策略性能，但 PlayWorld 依赖无监督自主探索收集数据，而本文依赖基础模型的结构化生成。PlayWorld 的数据多样性受限于探索效率，而本文的数据多样性受限于基础模型的泛化能力。本文引入的 FlashAR 加速机制在 PlayWorld 中未见类似设计，这反映了本文对数据生成效率的工程重视。然而，本文未对比基于扩散模型的视频生成方法（如 Sora 或 Genie）在具身场景下的表现，无法确认自回归范式在长时程动态生成上的绝对优势。

## 总结

Xiaomi-Robotics-U0 旨在解决具身生成中基础模型泛化能力丧失与多视角几何一致性难以兼顾的矛盾。其切入点在于将具身生成重构为基础生成的扩展，通过统一自回归框架联合优化通用与具身数据，并引入结构化控制解耦场景元素。该方法在真实机器人任务中，将 π0.5 策略在干扰组下的平均进度从 36.9% 提升至 63.2%（注：此处引用摘要数字，表格中为 63.2% 到 82.1% 的提升，需核对。摘要称“improving the out-of-distribution success rate of π0.5 from 36.9% to 63.2%”，表格中 Average Interference 为 63.2% 到 82.1%。摘要可能指特定任务或不同指标。根据表格，Average Interference 从 63.2% 提升至 82.1%。摘要中的 36.9% 是 Base 组的 Average。因此，摘要表述为“out-of-distribution success rate from 36.9% to 63.2%”可能存在歧义，或指代不同任务。根据表格，Interference 组 Original 为 63.2%，Aug 为 82.1%。Base 组 Original 为 36.9%，Aug 为 81.0%。摘要可能混淆了 Base 和 Interference 的基线。此处以表格数据为准：在干扰条件下，进度从 63.2% 提升至 82.1%）。本文证明了统一训练范式在保持通用能力同时增强具身鲁棒性的有效性。其边界在于实验局限于静态桌面操作，未验证动态交互场景下的物理一致性，且缺乏与扩散模型视频生成方法的直接对比。当任务涉及快速动态物体或长时程多步规划时，自回归范式下的误差累积是否会导致几何漂移，论文未给出回答。
