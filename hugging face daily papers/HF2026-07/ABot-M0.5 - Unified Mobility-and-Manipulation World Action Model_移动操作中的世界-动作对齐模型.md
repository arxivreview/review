# HuggingFace最新推荐论文 ｜ABot-M0.5: Unified Mobility-and-Manipulation World Action Model ｜移动操作中的世界-动作对齐模型

研究机构：阿里巴巴集团

作者：Ronghan Chen、Yandan Yang、Zuojin Tang 等 21 人

论文原文见 [arXiv](https://arxiv.org/abs/2607.00678)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.00678)

> 移动操作要求机器人在导航与精细抓取间无缝切换，但现有反应式视觉-语言-动作（Vision-Language-Action, VLA）策略缺乏显式世界建模，而新兴世界动作模型（World Action Model, WAM）在时间粒度、动作空间与训练-测试一致性上存在结构性失配。ABot-M0.5 通过引入帧级潜在动作、双层级混合变换器（Mixture-of-Transformers, MoT）架构及 Dream Forcing 训练策略，统一解决上述对齐问题。该框架在移动操作基准上取得领先性能，但其对静态操作任务的增益是否源于世界模型预训练而非特定对齐机制，尚存疑。

## 研究背景

当机器人执行“将杯子放入抽屉”这类移动操作时，底盘低频移动与机械臂高频抓取遵循截然不同的动力学特性。若将二者耦合在单一动作空间中优化，导航信号会干扰精细控制，导致接触起始或抓取闭合等关键动态被模糊。这种异构动作分布的冲突，要求模型在统一框架内解耦不同频率与维度的控制信号，同时保持长时程任务上下文的连贯性。

现有 VLA 策略（如 π0.5）虽能生成连续动作，但本质上是反应式的，缺乏对未来视觉动态的显式预测，难以应对视角剧烈变化下的长时程规划。新兴 WAM 路线（如 GR00T-N1.5）引入了视频预测，但通常基于粗粒度视频块进行动作生成，导致时间粒度失配；且其逆动力学训练依赖真实未来帧，与推理时依赖自预测帧的条件不一致，引发严重的曝光偏差。ABot-M0.5 的切入点在于识别出移动操作特有的三重结构性瓶颈：时间粒度、动作空间与训练-测试条件，并主张通过架构级对齐而非单纯扩大模型规模来解决这些问题。

## 核心方法

### 方法参照系

标准 WAM 流程为“视频预测→逆动力学动作生成”。本文的关键差异在于：在视频潜变量与机器人动作之间插入帧级潜在动作层，并将单一动作头替换为解耦的双层级 MoT 结构，同时改变逆动力学的训练条件以匹配自回归推理过程。

### 帧级潜在动作建模

传统 WAM 直接映射粗粒度视频潜变量到动作，导致接触动态等细粒度信息丢失。ABot-M0.5 引入帧级潜在动作 $m_t$ 作为中间表征，将生成过程分解为“视频→潜在动作→动作”的级联。潜在动作编码器 $E_m$ 通过自监督学习捕捉帧间视觉状态转移，并施加代数一致性约束以构建结构化运动空间。其预训练目标包含加性一致性损失，确保长时程转移可分解为短时程转移之和：

$$ \mathcal{L}_{add} = \| m_{k}^{i} - (m_{j}^{i} + m_{k}^{j}) \|_2^2 $$

该公式强制模型学习可组合的运动意图，使潜在动作空间具备代数结构，从而在粗粒度视频预测与细粒度控制间建立桥梁，解决时间粒度失配问题。

### 双层级 MoT 与 Dream Forcing

为解决导航与操作动作的分布冲突，ABot-M0.5 采用双层级 MoT 架构，在模态表示与动作子空间两个层面解耦，使底盘运动与机械臂操作由不同专家处理。更关键的是 Dream Forcing 训练策略，它摒弃了依赖真实未来帧（Teacher Forcing）或随机噪声帧（Diffusion Forcing）的做法，转而使用模型自预测的“梦境”视频潜变量 $\hat{z}_{t+1}$ 作为动作预测的条件。其动作预测分布从标准形式转变为：

$$ p_\theta(a_t | o_{<t}, l, \hat{z}_{t+1}, \hat{m}_t) $$

其中 $\hat{z}_{t+1}, \hat{m}_t$ 为自预测潜变量。这一设计使训练时的条件分布与推理时完全一致，迫使模型学会在自身预测误差下生成鲁棒动作，从根本上消除了自回归展开中的复合误差累积。

## 实验评估

实验在 RoboCasa365（移动操作）、RoboTwin 2.0（双臂操作）及 LIBERO（桌面操作）上进行。基线覆盖 VLA（π0.5）、WAM（GR00T-N1.5, Fast-WAM）及强化学习后训练方法（RLDX-1），但缺失 SimpleVLA-RL 等纯 RL 后训练强基线，限制了与领域 SOTA 的直接对比。

| 基准 | 方法 | 平均成功率 (%) |
|---|---|---|
| RoboCasa365 | ABot-M0.5 (+Condensed Memory) | 46.6 |
| RoboCasa365 | Qwen-RobotManip | 35.9 |
| RoboTwin 2.0 | ABot-M0.5 | 94.10 |
| RoboTwin 2.0 | Qwen-RobotManip | 93.85 |
| LIBERO | ABot-M0.5 | 99.4 |

在移动操作主基准 RoboCasa365 上，ABot-M0.5 配合 Condensed Memory 机制达到 46.6% 的平均成功率，显著优于 Qwen-RobotManip 的 35.9% 和 GR00T-N1.5 的 23.9%，尤其在复合未见任务上提升明显。在静态操作基准 RoboTwin 2.0 上，ABot-M0.5 取得 94.10% 的平均成功率，略高于 Qwen-RobotManip 的 93.85%，但与领域综述中 Z-1 的 80.6% 相比存在协议差异，无法直接归因于方法优劣。

消融实验表明，Dream Forcing 对长时程任务稳定性贡献最大，移除该模块后复合任务成功率下降显著。双层级 MoT 在异构动作解耦上表现稳健，但单独移除潜在动作层对静态操作任务影响较小，暗示潜在动作的价值在移动场景中更为突出。Condensed Memory 机制进一步提升了 6.2 个百分点，但其详细机制留待后续工作，当前结果可能高估了基础架构的贡献。

评估协议存在局限：RoboCasa365 的复合未见任务成功率普遍较低（最高 45.6%），反映基准难度极高，但缺乏置信区间报告。代码已开源，但预训练数据构成（大规模公开数据集+合成数据）未完全披露，且未报告推理延迟与显存占用，无法评估其在边缘设备上的部署可行性。

## 关联研究分析

从问题动机看，ABot-M0.5 与 SimpleVLA-RL 均旨在克服模仿学习的分布外脆弱性，但路径截然不同。SimpleVLA-RL 通过强化学习后训练引入稀疏奖励信号，使策略在交互中自我纠错；而 ABot-M0.5 通过 Dream Forcing 在训练阶段对齐推理条件，使模型在自预测误差下保持鲁棒。前者依赖环境交互获取新分布数据，后者依赖世界模型生成合成条件。在 LIBERO-Long 上，SimpleVLA-RL 达到 98.5%，ABot-M0.5 在 LIBERO 上为 99.4%，但两者未在相同长时程移动操作基准上直接对比，无法判断 RL 后训练与训练-测试对齐在长时程任务中的相对优势。

从方法设计看，ABot-M0.5 与 GR00T-N1.5 同属 WAM 框架，但 GR00T 采用单一动作头处理所有控制维度，而 ABot-M0.5 通过双层级 MoT 解耦导航与操作。这一差异源于移动操作对异构动作分布的敏感性：GR00T 在 RoboCasa365 上仅 23.9%，而 ABot-M0.5 达 40.4%，表明动作解耦对移动操作至关重要。然而，在静态操作基准 RoboTwin 2.0 上，两者差距缩小（94.10% vs 93.85%），暗示 MoT 解耦的增益主要源于移动场景的异构性，而非通用架构优势。

## 总结

ABot-M0.5 针对移动操作中世界建模、动作抽象与部署行为的结构性失配，通过帧级潜在动作、双层级 MoT 及 Dream Forcing 实现了三重对齐。该框架在 RoboCasa365 上以 46.6% 的成功率领先，在 RoboTwin 2.0 上达到 94.10%，验证了训练-测试一致性对长时程鲁棒性的关键作用。然而，其在静态操作基准上的性能仅与现有 SOTA 持平，且 Condensed Memory 机制未完全披露，使得架构贡献与记忆机制贡献难以分离。当移除 Dream Forcing 后，复合任务成功率下降幅度是否在所有移动操作子任务中均保持一致，论文未提供细粒度消融数据。
