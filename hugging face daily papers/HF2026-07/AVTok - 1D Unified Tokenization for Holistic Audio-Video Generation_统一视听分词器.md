# HuggingFace最新推荐论文 ｜AVTok: 1D Unified Tokenization for Holistic Audio-Video Generation ｜统一视听分词器

研究机构：香港科技大学

作者：Kien T. Pham、I Chieh Chen、Qifeng Chen 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2606.30811)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.30811)

> 联合视听生成（JAVG）长期受困于双分支架构的高昂算力与模态间嵌入空间割裂导致的语义错位。现有方法虽能生成高质量内容，但独立训练的视觉与音频分词器无法在潜空间实现深层对齐，且双骨干结构严重制约了模型的可扩展性。AVTok 提出了一种 1D 统一分词范式，通过共享编码器-解码器与模态特定查询，将视听信号压缩至单一离散潜空间。该设计在降低计算成本的同时提升了重建保真度，但其隐式融合机制在复杂多声源场景下的对齐鲁棒性仍存疑。

## 研究背景

视听生成的核心瓶颈在于模态表征的异构性与计算资源的线性增长。视频数据具有三维时空结构，传统分词器采用 3D 补丁式编码，导致潜变量维度高且缺乏全局语义；音频信号则是一维时序波形，通常编码为 1D 时间嵌入或 2D 梅尔谱图。这种结构差异使得独立训练的视觉与音频分词器在各自的嵌入空间中形成“孤岛”，即便通过交叉注意力模块进行后期融合，也难以消除底层表征的语义鸿沟，导致生成内容出现音画不同步或语义错位。

主流 JAVG 路线如 Ovi 和 JavisDiT 均采用双分支设计，每个模态配备独立的变分自编码器（VAE）与扩散 Transformer（DiT）骨干。这种架构虽然能利用各模态的专用先验，但参数量巨大，训练与部署成本极高，且双分支间的同步依赖额外的辅助模块，误差易在级联过程中累积。与此同时，1D 视频分词技术（如 LARP）已证明离散潜变量能更好地适配自回归（AR）生成范式，但尚未被扩展至视听联合场景。AVTok 的切入点在于打破模态壁垒，探索一种能在单一 1D 离散潜空间中同时封装视听信息的高效分词机制，以替代沉重的双分支架构。

## 核心方法

### 1D 统一潜空间参照系

本文问题区别于传统双分支 JAVG 的关键在于分词层的统一。标准流程中，视觉与音频分别通过独立 VAE 映射至各自潜空间，再由生成模型进行跨模态交互。AVTok 则主张将视听信号共同编码至一个共享的 1D 离散潜空间，利用 LARP 提出的查询式（Query-based）机制替代 3D 补丁编码，以获取全局语义并适配 AR 生成。

### 双流共享架构与模态特定查询

设计动机在于解决单流拼接设计中视觉信息密度远高于音频导致的模态抑制问题。AVTok 采用双流 Transformer 架构，共享编码器 $\mathcal{E}$ 与解码器 $\mathcal{D}$ 的权重，但为视频和音频分别引入独立的归一化层与可学习查询向量。视频流使用 $n$ 个整体查询 $\mathbf{Q}^L_v$ 和 $m$ 个补丁查询 $\mathbf{Q}^P_v$，音频流使用 $q$ 个整体查询 $\mathbf{Q}^L_a$ 和 $p$ 个补丁查询 $\mathbf{Q}^P_a$。联合嵌入 $\mathbf{E}_{av}$ 经编码后，仅整体查询对应的潜变量被量化为离散 token：

$$ \mathbf{x}_{av} = \mathcal{Q}(\mathcal{E}(\mathbf{E}_{av}; \text{LN}_{a,v})) $$

该公式表明，尽管参数共享，模态特异性通过独立的查询向量与归一化层得以保留，而跨模态融合则通过共享参数隐式完成，避免了显式交叉注意力的计算开销。

### VFAL 分层训练与表征对齐

设计动机在于应对视听信息密度失衡及隐式融合导致的对齐不足。AVTok 引入 Video-First-Audio-Later (VFAL) 策略，第一阶段仅训练视频流以建立稳健的视觉重建能力，第二阶段再引入音频流进行联合优化。同时，利用视听基础模型 $\mathcal{M}_F$ 提取的特征作为监督信号，通过表征对齐损失 $\mathcal{L}_{rep}$ 约束 AVTok 的补丁级连续 token 与基础模型特征的一致性：

$$ \mathcal{L}_{rep} = \sum_{i} \| \mathbf{z}^{patch}_i - \mathcal{M}_F(\mathbf{x}_i) \|^2 $$

此损失强制模型在潜空间中捕捉视听协同特征，弥补了仅依赖重建损失可能导致的语义漂移，确保离散 token 具备足够的语义区分度以支持下游生成。

## 实验评估

实验在内部数据集上进行，基线涵盖单模态 SOTA（LARP, WavTokenizer）及双分支生成模型（Ovi, JavisDiT）。由于统一分词任务缺乏公开基准，对比主要聚焦于重建质量与下游生成性能。

| 方法 | 类型 | rFVD↓ | rFAD↓ | gFVD(A2V)↓ | gFAD(A2V)↓ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Vanilla | AV | 14.87 | 10.26 | - | - |
| AVTok | AV | 12.80 | 5.93 | 150.26 | 49.47 |
| LARP | Video | 24.53 | - | - | - |
| WavTokenizer | Audio | - | 24.27 | - | - |

AVTok 在重建指标上显著优于单流 Vanilla 设计，rFVD 从 14.87 降至 12.80，rFAD 从 10.26 降至 5.93，表明统一潜空间有效提升了视听重建保真度。在下游 A2V 生成中，AVTok 结合 AR 模型取得 150.26 的 gFVD，优于部分双分支基线，验证了 1D 统一 token 对 AR 生成的友好性。

消融实验显示，移除 VFAL 策略导致 rFAD 从 5.93 恶化至 9.38，证实了分层训练对缓解模态抑制的关键作用。移除表征对齐损失 $\mathcal{L}_{rep}$ 后，rFAD 升至 8.48，说明基础模型特征对齐对音频语义重建贡献显著。值得注意的是，移除 AR 先验损失 $\mathcal{L}_{prior}$ 虽使重建指标达到最佳（rFAD 3.47），但导致生成性能大幅下降（gFAD 从 49.47 升至 67.84），揭示了重建保真度与生成友好性之间的权衡。

评估边界方面，论文未报告 AudioCaps 等标准基准上的 FAD 或 IS 指标，且缺乏与 Ovi 等 SOTA 模型在相同算力下的公平对比。代码已开源，但超参数细节（如 VFAL 阶段切换阈值）未完全披露，可能影响复现的一致性。

## 关联研究分析

从问题动机看，AVTok 与 Ovi 等双分支 JAVG 模型的根本差异在于对“同步”的实现层级。Ovi 依赖 DiT 生成过程中的显式交叉注意力来对齐音画，而 AVTok 将同步问题前置到分词阶段，通过共享潜空间强制视听 token 在离散空间中邻近。这种差异源于对计算效率的不同取舍：Ovi 牺牲算力换取生成灵活性，AVTok 牺牲部分模态特异性换取架构简洁性。然而，AVTok 的隐式融合机制是否能在多声源复杂场景中保持 Ovi 级别的细粒度同步，论文未提供充分证据。

从方法设计看，AVTok 与 LARP 同属 1D 查询式分词，但 LARP 仅处理视频，而 AVTok 扩展至视听联合。关键差异在于音频输入的处理：LARP 无需考虑模态密度失衡，而 AVTok 必须引入 VFAL 策略以应对视觉主导问题。此外，AVTok 借鉴了 UniCodec 的统一码本思想，但将其从纯音频域扩展至视听域。这种扩展并非简单叠加，而是通过模态特定查询解决了不同维度信号（3D 视频 vs 1D 音频）在共享 Transformer 中的特征竞争问题。

## 总结

AVTok 旨在解决 JAVG 中双分支架构的高昂算力与模态嵌入空间割裂导致的语义错位矛盾。其切入点在于利用 1D 离散潜空间的 AR 友好性，通过共享编码器与模态特定查询构建统一分词空间，从而在降低计算成本的同时实现视听信息的深层对齐。实验表明，AVTok 在重建任务上 rFVD 降至 12.80，在 A2V 生成中 gFVD 达 150.26，验证了统一分词的有效性。然而，其隐式融合机制缺乏显式跨模态交互模块，且在标准基准上的泛化性能未得到充分验证。当场景中存在多个独立声源且音画语义复杂交织时，仅靠共享参数进行的隐式融合是否足以避免模态间的特征干扰，论文未给出回答。
