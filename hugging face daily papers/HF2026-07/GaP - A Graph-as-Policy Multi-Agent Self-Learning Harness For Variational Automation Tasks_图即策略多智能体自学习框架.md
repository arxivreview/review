# HuggingFace最新推荐论文 ｜GaP: A Graph-as-Policy Multi-Agent Self-Learning Harness For Variational Automation Tasks ｜图即策略多智能体自学习框架

研究机构：美国加州大学伯克利分校、美国卡内基梅隆大学

论文原文见 [arXiv](https://arxiv.org/abs/2607.05369)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.05369)

> 变体自动化（Variational Automation, VA）要求机器人在已知工作单元内，对几何与姿态存在显著变化的物体实例执行高可靠性重复任务，这一场景介于固定自动化与通用机器人之间。现有端到端视觉-语言-动作模型（Vision-Language-Action Model, VLA）在位置扰动下性能骤降，而传统任务与运动规划（Task and Motion Planning, TAMP）系统缺乏对未知物体姿态的自适应能力。本文提出图即策略（Graph-as-Policy, GaP），通过多智能体代码生成构建模块化计算图，并结合仿真自学习闭环优化图结构。该框架在8个VA基准上显著超越基线，但其可靠性高度依赖预定义技能库与已知环境约束，对完全未知几何的泛化能力存疑。

## 研究背景

机器人自动化部署面临可靠性与适应性的双重约束。固定自动化（Fixed Automation, FA）通过人工调优实现高吞吐量，但无法处理物体几何与姿态的变体；通用机器人（Generalist Robotics, GR）依赖端到端VLA模型实现开放世界泛化，却在工业级重复任务中因分布偏移导致成功率崩溃。变体自动化（VA）任务要求机器人在已知工作单元内，对具有非平凡几何与姿态变化的物体实例执行持久化任务，如分拣不同尺寸包裹或制作咖啡。这一场景既需要FA的可靠性，又需要GR的适应性，构成了当前机器人学习研究中的结构性空白。

主流VLA模型在位置扰动下表现脆弱。实验数据显示，π0.5与MolmoAct2在LIBERO-PRO（含位置交换）基准上成功率分别降至0.24与0.43，而在无扰动的LIBERO-object上高达0.96与0.97。TAMP系统如TipTop虽具备结构化规划能力，但依赖精确的物体模型与运动规划器，在复杂几何场景下常因规划失败而中断。代码即策略（Code-as-Policy, CaP）范式通过LLM生成控制代码，但单智能体架构面临上下文窗口限制与“作弊”风险，即生成虚假技能或简化成功指标。GaP的切入点在于将代码生成结构化：通过有向计算图封装原子技能节点，利用多智能体分工降低单节点复杂度，并引入仿真自学习闭环验证图的有效性，从而在VA任务中实现高可靠性与可解释性的平衡。

## 核心方法

### 计算图策略表征

GaP将机器人策略形式化为有向计算图 $G = (V, E)$，其中节点 $V$ 为原子技能（如感知、规划、控制），边 $E$ 定义数据流与控制依赖。与端到端VLA的隐式状态映射不同，GaP显式分解任务为功能段，每个节点封装单一操作并具备类型化输入输出签名。这种结构化表征解决了CaP中自由代码生成的不可控性，使策略可验证、可复用，且天然支持模块化扩展。

### 多智能体图生成与自学习

GaP采用分层多智能体架构：编排智能体（Orchestration Agent）将自然语言任务分解为功能段，技能智能体（Skill Agent）为每段生成局部子图，最终聚合为完整计算图。自学习过程通过Isaac-Lab仿真器执行并行排练，优化目标为成功率与吞吐量的加权组合：

$$G^* = \arg\max_G \mathbb{E}_{x_i \sim B} [J(\pi(a | I, G))]$$

其中 $J = w_s \cdot \mathbb{I}(\text{success}) + w_t \cdot \Phi$，$\Phi$ 为吞吐量（成功率/周期时间）。该公式的物理含义是：GaP在信念空间 $B$（物体姿态分布）上采样任务实例，通过迭代修改图拓扑与节点参数，最大化长期执行效率。这一设计解决了单智能体CaP中上下文窗口溢出与幻觉问题，将代码生成与测试解耦，抑制了智能体“作弊”动机。

### 技能库与仿真排练

模块化开放机器人技能库（Modular Open Robot Skill Library, MORSL）包含51个初始技能，涵盖感知（SAM2、Grounding DINO）、抓取规划（Contact GraspNet）、运动规划（cuRobo）等。每个技能声明输入输出、语义参数与前置条件，供LLM智能体配置与组合。仿真排练阶段，GaP从信念空间 $B$ 采样 $N$ 个并行任务实例，执行当前图 $G_{j-1}$ 并分析失败根因（如几何碰撞、规划超时），通过LLM更新图结构 $G_j$ 直至性能收敛。这一闭环机制使GaP无需大规模演示数据，仅通过仿真反馈即可优化策略，区别于模仿学习的数据驱动范式。

## 实验评估

实验覆盖8个VA基准（4仿真、4真实），基线包括CaP-X、π0.5、MolmoAct2与TipTop。GaP在位置扰动场景下表现显著优于VLA模型：在LIBERO-PRO object swap任务中，GaP成功率为0.95，而π0.5与MolmoAct2分别为0.24与0.43。真实世界Fulfill Grocery Orders基准中，GaP实现25/25（100%）成功率，TipTop仅8/25（32%），主要因后者运动规划器无法处理立方体物体与高篮子几何。

| 基准 | 方法 | 成功率 |
|---|---|---|
| LIBERO-PRO object swap | GaP | 0.95 |
| LIBERO-PRO object swap | π0.5 | 0.24 |
| LIBERO-PRO object swap | MolmoAct2 | 0.43 |
| Fulfill Grocery Orders (Real) | GaP | 25/25 |
| Fulfill Grocery Orders (Real) | TipTop | 8/25 |

消融实验表明，GaP通过腕部相机定位目标物体并导航至预抓取姿态，将VLA输入拉回分布内，使π0.5 w/GaP成功率从0.24提升至0.60，MolmoAct2 w/GaP从0.43提升至0.62。这一结果验证了GaP作为VLA“前置处理器”的有效性，而非替代端到端策略。

评估边界存在明显局限：所有基准均假设工作单元环境、机器人配置与物体范围已知，未测试完全未知几何或动态环境下的表现。代码开源（`https://graph-robots.github.io/gap`），但多智能体LLM版本（Gemini-3.1-Flash-Lite）与温度参数（0.1）的敏感性未量化，仿真到真实的迁移误差未单独分析。

## 关联研究分析

从问题动机看，GaP与VLA模型的根本差异在于泛化定义：VLA追求开放世界OOD泛化，依赖大规模预训练数据；GaP聚焦已知约束内的变体鲁棒性，依赖结构化代码与仿真验证。这一差异源于任务特性：VA任务要求工业级可靠性，而GR任务容忍一定失败率。GaP未探索未知物体几何下的表现，其“泛化”边界严格限定在信念空间 $B$ 内，这与VLA的开放世界假设形成鲜明对比。

从方法设计看，GaP与TAMP系统的核心差异在于动态性：TAMP使用静态规划器求解固定约束，GaP通过LLM动态生成图结构并自学习优化。这一设计解决了TAMP在复杂几何场景下的规划失败问题，但引入了LLM幻觉风险。GaP通过图结构约束与仿真验证抑制幻觉，但未提供形式化保证。与CaP-X相比，GaP的多智能体架构降低了单节点上下文复杂度，但增加了系统协调开销，其效率优势在长时程任务中是否持续，论文未给出量化分析。

## 总结

GaP针对变体自动化任务中VLA模型位置鲁棒性不足与TAMP系统几何适应性有限的矛盾，通过多智能体代码生成构建模块化计算图，并结合仿真自学习闭环优化图结构。该框架在8个VA基准上实现高成功率，如Fulfill Grocery Orders真实任务100%成功率与LIBERO-PRO 0.95成功率，验证了结构化代码生成在受限变体任务中的有效性。其边界在于依赖已知工作单元约束与预定义技能库，未测试完全未知几何或动态环境下的表现。当信念空间 $B$ 扩展至包含未建模物体类别时，GaP的自学习闭环是否仍能收敛至可靠图结构，论文未给出回答。
