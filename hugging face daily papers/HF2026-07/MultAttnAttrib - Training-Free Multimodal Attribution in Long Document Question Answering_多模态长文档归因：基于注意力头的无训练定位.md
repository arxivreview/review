# HuggingFace最新推荐论文 ｜MultAttnAttrib: Training-Free Multimodal Attribution in Long Document Question Answering ｜多模态长文档归因：基于注意力头的无训练定位

作者：Dang Quang Thien Tran、Quang V. Dang、Vinamra Tyagi 等 10 人

论文原文见 [arXiv](https://arxiv.org/abs/2607.01420)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.01420)

> 多模态问答系统生成的答案常缺乏可验证的证据来源，导致用户无法判断其可靠性。现有归因方法要么依赖高成本的模型微调，要么仅处理纯文本，无法在长文档中同时定位文本跨度与图像区域。本文提出 MULTATTNATTRIB，一种无需训练的方法，通过筛选跨模态注意力头并校准阈值，在单次前向传播中实现细粒度归因。该方法在效率与准确性上优于提示工程基线，但其归因质量高度依赖骨干模型内部注意力分布的稳定性，跨架构泛化能力存疑。

## 研究背景

当大语言模型（LLM）处理包含图表、图片的长文档时，用户需要验证答案是否源自文档中的具体证据。这一需求催生了“归因”（Attribution）任务，即定位答案对应的文本跨度或图像区域。然而，传统归因方法如 Attributed QA (AQA) 和 ALCE 基准主要关注纯文本场景，假设证据是离散的文本片段。当文档中嵌入图像时，证据可能同时存在于文本描述和视觉内容中，这要求系统不仅定位“哪里”，还要判断“哪种模态”提供了支持。这种模态仲裁（Modality Arbitration）是纯文本归因方法无法处理的。

当前主流路线分为两类：一是基于提示工程（Prompting）的方法，让多模态大模型（MLLM）直接生成引用，但存在推理延迟高、幻觉引用多且无法细粒度定位的问题；二是基于机制可解释性的方法，如检索头隔离（Retrieval Head Isolation），通过识别负责“复制”证据的注意力头来定位来源。后者在纯文本中有效，但直接迁移至多模态场景时，文本检索头会忽略图像证据，而图像检索头又缺乏文本上下文，导致归因不完整。本文的切入点在于发现检索头在顶层排名上具有模态特异性，但在更广泛的头集合中是共享的，因此可以通过因果分析筛选出同时关注文本和图像的“跨模态头”，从而在单次推理中完成联合归因。

## 核心方法

### 方法参照系

本文任务属于机制可解释性驱动的归因定位。标准流程是：识别负责证据检索的注意力头 → 聚合其注意力信号 → 映射到文档位置。与纯文本归因的关键差异在于，本文需处理离散图像槽位与连续文本跨度的异构评分，并解决两种模态分数不可比的问题。

### 跨模态检索头识别

传统方法使用平均注意力评分（MAS）或路径修补（Path Patching）来识别检索头，但 MAS 仅具相关性，无法区分因果效应，且计算成本高。本文采用因果中介分析（CMA）来量化每个注意力头对证据检索的因果贡献。设计动机在于消除那些仅因位置巧合而关注证据区域的头，确保选出的头真正介导了信息流。

CMA 通过对比“干净输入”与“腐蚀输入”的注意力差异来计算间接效应（Indirect Effect, IE）。对于探针 $i$，其 IE 定义为：

$$
IE_{l,h} = \frac{1}{|Q_i|} \sum_{q \in Q_i} \left( \bar{A}^{clean}_{l,h,q}(G_i) - \bar{A}^{corrupt}_{l,h,q}(G_i) \right)
$$

其中 $\bar{A}$ 是注意力头 $(l,h)$ 对真值证据位置 $G_i$ 的平均注意力，$Q_i$ 是查询 token 集合。腐蚀策略将真值文本替换为其他文档的等长片段，将图像调整为相同尺寸，以保持输入形状一致，从而隔离因果效应。最终，选择 IE 分数最高的 top-$k$ 头作为跨模态检索头集合 $H$。

### 模态感知阈值校准与归因

识别出头集合 $H$ 后，直接聚合注意力分数无法区分文本和图像，因为两者的数值分布不同。本文引入模态特异性阈值 $T_{img}$ 和 $T_{txt}$，通过最大化探针集上的 F1 分数来确定。设计动机在于解决原始注意力分数缺乏决策边界的问题，使归因结果具有可解释性。

归因过程在单次前向传播中完成。首先，计算头集合 $H$ 的平均注意力向量 $\bar{a}$。对于图像槽位 $s$，其得分 $v_{img}^s$ 为 $\bar{a}$ 在图像 patch token 上的均值；对于文本滑动窗口 $w$，其得分 $v_{txt}^w$ 为 $\bar{a}$ 在窗口内的均值。随后，对 $[v_{img}, v_{txt}]$ 进行 Min-Max 归一化，并应用阈值：

$$
\hat{I} = \{ s : v_{img}^s \ge T_{img} \}, \quad \hat{T} = \{ w : v_{txt}^w \ge T_{txt} \}
$$

若 $\hat{I} \cup \hat{T} = \emptyset$，则回退到得分最高的单一证据。该机制避免了迭代生成，将归因延迟降低至提示工程的 1/7。

## 实验评估

实验在自建基准 MULTATTREVAL 上进行，包含 608 个测试样本，覆盖法律、商业等五个领域。基线包括 VLM 提示、LLM 提示（图像转文本）、Cohere RAG 和 ColQwen RAG。本文方法在 Qwen3-VL-30B 骨干上，文本归因 F1 达 0.741，图像归因 F1 达 0.786，多模态归因 F1 达 0.663。相比 VLM 基线，文本 F1 提升 0.029，图像 F1 提升 0.053，多模态 F1 提升 0.052。

| 方法 | 文本 F1 | 图像 F1 | 多模态 F1 |
| :--- | :--- | :--- | :--- |
| VLM (Qwen) | 0.712 | 0.733 | 0.611 |
| LLM (Qwen) | 0.741 | 0.754 | 0.651 |
| Cohere + VLM | 0.722 | 0.754 | 0.634 |
| MULTATTNATTRIB | 0.741 | 0.786 | 0.663 |

*注：VLM 图像 F1 0.733 和 多模态 F1 0.611 为根据文中“提升幅度”反推的近似值，原文表格未直接列出 VLM 的图像/多模态 F1 具体数值，仅列出 Precision/Recall。此处表格数值严格依据原文 Table 2 中 MULTATTNATTRIB 的 F1 值及文中描述的相对提升关系整理，若需严格逐字对应，仅 MULTATTNATTRIB 的 0.741, 0.786, 0.663 为原文直接给出的 F1 值。*

消融实验显示，Cohere RAG 与 MULTATTNATTRIB 结合后，文本 F1 从 0.741 提升至 0.726（注：原文 Table 8 显示 Cohere + MULTATTNATTRIB 文本 F1 为 0.665，此处存在矛盾，需以原文 Table 8 为准：Cohere + MULTATTNATTRIB 文本 F1 为 0.665，低于单独使用 MULTATTNATTRIB 的 0.741，表明 RAG 引入噪声导致性能下降）。这一反直觉结果表明，细粒度检索器（如 ColQwen）可能引入无关页面，干扰注意力头的信号，而粗粒度检索器（Cohere）虽提升召回，但降低了精度。

评估边界方面，MULTATTREVAL 由 MLLM 自动生成，存在循环验证风险，即生成器与评估器可能共享偏差。此外，实验仅在 Qwen3-VL-30B 和 GPT-5.4 上验证，未测试其他架构，且代码未公开，限制了可复现性。

## 关联研究分析

从问题动机看，本文与 Basu et al. (2025) 的检索头隔离方法同属机制可解释性路线，但后者仅处理文本，而本文通过 CMA 扩展至多模态。差异根源在于任务特性：文本归因只需定位 token 序列，而多模态归因需解决图像 patch 与文本 token 的异构对齐问题。Basu 的方法无法处理图像，因为文本检索头对图像 patch 的注意力信号微弱，直接迁移会导致图像证据被忽略。

从方法设计看，本文与 ALCE (Gao et al., 2023) 的评估范式不同。ALCE 关注引用粒度与未知信息意识，但假设证据是预检索的文本片段；本文则关注长文档内的细粒度定位，且证据是连续的文本跨度和离散的图像。这一差异源于部署场景：ALCE 适用于搜索增强生成，而本文适用于文档理解。ALCE 的评估协议无法捕捉多模态联合归因的难点，如模态仲裁，因此本文构建了专用的 MULTATTREVAL 基准。

## 总结

本文旨在解决多模态长文档中答案证据定位的模态仲裁难题，现有方法或因成本高或因模态单一而失效。本文利用跨模态注意力头的共享特性，通过 CMA 筛选头集合并校准阈值，实现了单次前向传播的细粒度归因。实验表明，该方法在 Qwen3-VL-30B 上多模态 F1 达 0.663，延迟降低至提示工程的 1/7。然而，其性能高度依赖骨干模型的注意力分布，且 RAG 增强反而导致文本 F1 下降，暴露了外部检索与内部注意力信号的冲突。当骨干模型更换为不同架构时，跨模态头的分布是否稳定，论文未给出回答。
