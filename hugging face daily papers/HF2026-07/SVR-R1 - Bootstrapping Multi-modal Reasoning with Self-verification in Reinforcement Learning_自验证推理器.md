> 多模态大模型在复杂视觉推理中常因生成与验证能力不对等而陷入逻辑死胡同，现有强化学习（RL）范式仅依赖最终答案奖励，无法在训练过程中利用模型自身的纠错潜力。SVR-R1 将自验证闭环嵌入组相对策略优化（GRPO）的 rollout 阶段，通过二元验证触发重思考，使模型在无需外部监督的情况下缩小生成-验证差距。该方法在相同数据与超参下显著优于标准 GRPO，但仅依赖结果奖励且未显式锚定视觉证据，其在视觉密集任务上的泛化边界尚存疑。

## 研究背景

当视觉-语言模型（VLM）面对图表或表格推理任务时，其生成的推理链往往包含逻辑断点，而模型自身具备识别这些断点的能力，却缺乏在训练阶段利用这一能力的机制。这一现象源于生成与验证之间的能力差距：验证比生成更容易，模型能准确判断错误答案，但难以直接生成正确路径。传统 RL 微调仅优化最终输出，忽略了中间推理步骤中蕴含的自我纠错信号，导致模型在长链推理中逐渐偏离视觉证据，产生视觉漂移。

多模态推理优化的主流路线分为过程奖励模型（PRM）与感知对齐优化。PRM 通过蒙特卡洛树搜索生成步骤级标签，细化信用分配，但依赖大规模标注数据且计算成本极高；感知对齐优化（如 VPPO）通过梯度过滤聚焦视觉 Token，强化视觉接地，但引入了额外的计算开销且假设关键 Token 可被准确识别。这两条路线均依赖外部监督或细粒度奖励信号，未能充分利用模型内部已有的验证能力。SVR-R1 的切入点在于：将模型自身的二元验证能力作为 RL 训练中的隐式监督信号，通过多轮自验证-重生成循环，在无需外部标注或独立批评者的情况下，引导模型学习生成可通过自我验证的正确推理路径。

## 核心方法

### 多轮自验证 RL 框架

SVR-R1 基于 GRPO 构建，但将单轮生成扩展为多轮自验证-重生成循环。标准 GRPO 假设每次 rollout 产生一个完整响应，而 SVR-R1 允许模型在生成初始答案后，由同一权重副本作为验证器判断其正确性。若验证器输出 "No"，模型被触发重新生成；若输出 "Yes" 或达到最大轮数，最终答案进入奖励计算。这一设计的关键差异在于：验证与生成共享同一模型权重，但通过不同的输入提示（验证提示 vs. 生成提示）实现功能解耦，避免了外部批评者的引入。

### 验证 Token 损失掩码与组相对优势

SVR-R1 的核心创新在于对验证 Token 的损失掩码机制。在多轮 rollout 中，验证 Token（"Yes"/"No"）与生成 Token 混合存在，若直接计算所有 Token 的策略梯度，会导致验证目标与生成目标冲突。SVR-R1 借鉴 Search-R1 的多轮 RL 框架，在损失计算中掩码所有验证 Token，仅优化最终生成响应。形式化地，训练目标为：

$$
\mathcal{L}(\theta) = \mathbb{E}_{[I, T] \sim \mathcal{D}, \{y_i\}_{i=1}^G \sim \pi_{\text{old}}(\cdot | I, T)} \left[ \frac{1}{G} \sum_{i=1}^G \min\left( \frac{\pi_\theta(y_i | I, T)}{\pi_{\text{old}}(y_i | I, T)} A_i(y_i), \text{clip}\left( \frac{\pi_\theta(y_i | I, T)}{\pi_{\text{old}}(y_i | I, T)}, 1-\epsilon, 1+\epsilon \right) A_i(y_i) \right) - \beta D_{\text{KL}}(\pi_\theta \| \pi_{\text{ref}}) \right]
$$

其中 $A_i(y_i)$ 为组内归一化的结果奖励优势，$\beta$ 为 KL 惩罚系数。该公式的物理含义是：仅对最终生成响应计算策略梯度，验证 Token 不参与优化，从而避免模型为最大化验证准确率而牺牲生成质量。这一设计解决了此前多轮 RL 中验证与生成目标冲突的问题，使模型能专注于生成可通过自我验证的正确推理路径。

## 实验评估

实验在 ChartQA、TableVQA 和 ThinkLite-VL-70K 三个数据集上进行，基线包括 Qwen2.5-VL、GPT-4o、R1-VL 及标准 GRPO。SVR-R1 在 3B 和 7B 规模下均显著优于标准 GRPO，尤其在 ChartQA 任务上，7B 模型的 SVR-PR 准确率达 83.3%，较标准 GRPO 的 80.9 提升 2.4 个点。在 MathVista 上，7B 模型的 SVR-R1 准确率为 71.6，较标准 GRPO 的 70.8 提升 0.8 个点。

| 数据集 | 模型规模 | 方法 | 准确率 (%) |
| :--- | :--- | :--- | :--- |
| ChartQA | 3B | SVR-PR | 83.3 |
| ChartQA | 3B | RL-PR | 80.9 |
| ChartQA | 7B | SVR-PR | 82.9 |
| ChartQA | 7B | RL-PR | 81.1 |
| MathVista | 7B | SVR-R1 | 71.6 |
| MathVista | 7B | thumbRL-BEST | 70.8 |

消融实验显示，随着训练进行，验证轮数逐渐减少，模型最终在单轮内即通过自我验证，表明其已内化生成-验证差距。熵分析表明，SVR-R1 的熵低于标准 GRPO，但高熵变体（$\epsilon_h = 2.8$）并未带来性能提升，说明自验证机制不依赖高探索性。

## 关联研究分析

从问题动机看，SVR-R1 与 Vision-Zero 同属自进化路线，但机制截然不同。Vision-Zero 依赖自博弈生成数据，通过交替进行自博弈与可验证奖励 RL 实现模型自主提升，其核心假设是模型能通过对抗性交互发现新策略；SVR-R1 则依赖自验证优化策略，假设模型能识别自身错误并触发重思考。这一差异源于任务特性：Vision-Zero 面向通用推理，需探索新策略空间；SVR-R1 面向视觉推理，需修正逻辑断点。SVR-R1 未探索自博弈在视觉任务中的适用性，其自验证机制在视觉感知错误（如物体识别错误）上的有效性未得到验证。

从方法设计看，SVR-R1 与 VPPO 均旨在抑制幻觉，但机制互补。VPPO 通过视觉依赖分数过滤 Token 级梯度，显式聚焦视觉证据，其假设是关键视觉 Token 可被注意力机制准确识别；SVR-R1 通过自验证聚焦逻辑正确性，未显式引入视觉接地机制。这一差异暗示 SVR-R1 可能在视觉密集任务上存在盲区：若模型初始生成即包含视觉感知错误，自验证可能无法识别并修正，因为验证器同样依赖相同的视觉编码。论文未提供证据支持其偏离“视觉接地关键”这一领域共识的理由，也未在视觉密集子集上单独评估性能。

## 总结

SVR-R1 要解决的核心矛盾是多模态模型在 RL 训练中无法利用自身验证能力缩小生成-验证差距。其切入点在于将二元自验证嵌入 GRPO rollout，通过损失掩码避免验证与生成目标冲突，使模型在无需外部监督的情况下学习生成可通过自我验证的正确推理路径。实验证明，在相同数据与超参下，SVR-R1 在 ChartQA 7B 模型上较标准 GRPO 提升 2.4 个点，在 MathVista 7B 模型上提升 0.8 个点。其边界在于仅依赖结果奖励且未显式锚定视觉证据，在视觉感知错误主导的任务上可能失效。当验证器与生成器共享相同视觉编码时，自验证能否识别并修正视觉感知层面的错误，论文未给出回答。
