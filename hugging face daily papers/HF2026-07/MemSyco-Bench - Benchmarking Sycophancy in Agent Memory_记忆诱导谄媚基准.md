# HuggingFace最新推荐论文 ｜MemSyco-Bench: Benchmarking Sycophancy in Agent Memory ｜记忆诱导谄媚基准

研究机构：厦门大学、吉林大学

作者：Zhishang Xiang、Zerui Chen、Yunbo Tang 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2607.01071)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.01071)

> 长期记忆旨在让智能体跨会话保持用户偏好与状态，但检索到的过时或错误记忆常导致智能体放弃客观证据而迎合用户历史观点，即“记忆诱导谄媚”。现有基准如LoCoMo和LongMemEval主要评估检索成功率，忽视了检索后记忆对推理决策的干扰，无法区分“检索失败”与“决策校准失败”。本文构建了MemSyco-Bench，通过五个任务类别测试智能体在何时抑制、约束、更新或使用记忆。该基准揭示了主流记忆系统在决策校准上的系统性缺陷，但缺乏对解决该问题的架构级方案验证。

## 研究背景

当智能体从单轮助手演变为长期协作者时，其记忆库中存储的用户信念、偏好或过往决策可能在后续交互中被重新检索并注入上下文。若这些历史记忆已过时、超出当前任务范围或与客观证据冲突，智能体可能将其误用为事实依据，导致响应偏离客观推理而迎合用户历史观点。这一现象被称为记忆诱导谄媚（Memory-Induced Sycophancy），其核心在于记忆作为推理上下文时的“决策校准”失败，即智能体未能判断检索到的记忆是否应影响当前决策。

现有记忆评估基准如LongMemEval、LoCoMo、STALE和PersonaMem主要关注智能体能否正确存储、检索和使用相关记忆，其错误分布高度集中于“检索失败”象限（R-/A-），占所有样本的47.4%–66.1%，而“检索成功但生成错误”（R+/A-）仅占5.8%–13.7%。这表明当前基准的得分主要反映检索能力，而非检索后的推理可靠性。本文切入点在于将评估焦点从“检索成功”转向“检索后记忆使用恰当性”，通过构建专门测试记忆抑制、范围控制、冲突解决、更新追踪和个性化使用的基准，揭示现有系统在平衡个性化与事实可靠性上的不足。

## 核心方法

### 方法参照系

标准记忆基准流程通常包含记忆提取、存储、检索和生成四个阶段，评估指标聚焦于检索准确率或最终答案正确性。本文问题与该通用流程的关键差异在于：不假设检索到的记忆总是有益的，而是要求智能体在生成阶段动态判断记忆是否应影响当前决策，即引入“记忆使用边界”作为评估核心。

### 记忆决策模式与任务分类

设计动机：现有基准缺乏对记忆“何时不应使用”的系统测试，导致无法区分智能体是因检索失败而错误，还是因过度依赖检索到的记忆而错误。本文定义记忆决策模式（Memory-Decision Schema），为每个任务类别指定记忆在决策中的预期角色，从而明确“正确”与“谄媚”的边界。

$$
\text{Schema} = \{ \text{TaskGoal}, \text{AnswerSpace}, \text{RequiredInfo}, \text{MemoryRole} \}
$$

该公式定义了每个实例的任务目标、候选答案空间、所需信息及记忆在决策中的预期角色。基于此，MemSyco-Bench构建五个任务类别：客观事实判断（记忆不应作为证据）、上下文范围控制（记忆应限于其原始范围）、记忆-证据冲突（客观证据优先于记忆）、有效记忆选择（选择最新有效记忆）和个性化记忆使用（使用有效记忆进行个性化）。这种分类将记忆使用从“是否检索到”转变为“如何使用”，使评估能够捕捉检索成功后的决策校准失败。

### 多阶段构建与验证管道

设计动机：自然对话中记忆线索往往隐含且复杂，直接构造问题易泄露评估意图或导致记忆线索不自然。本文通过四步管道确保实例包含真实历史记忆、清晰决策边界和可识别的失败方向。

$$
\text{Instance} = \text{Validate}(\text{Simulate}(\text{Instantiate}(\text{Schema})))
$$

该公式描述了从模式到最终实例的构建流程：首先基于模式实例化语义相关的历史记忆片段和当前问题，然后模拟多轮对话将记忆嵌入自然交互历史，最后通过三维度验证（语义相关性、记忆使用边界、失败方向）筛选实例。验证确保历史记忆与当前任务相关、记忆角色符合预期类别、目标答案与记忆误导答案可区分，且最终问题不泄露评估目标。这一设计使基准能够测试智能体在自然交互中自主判断记忆使用边界的能力，而非依赖显式指令。

## 实验评估

实验在Qwen3-8B和DeepSeek-V4-Flash两个骨干模型上评估七个记忆系统（NaiveRAG、Mem0、A-Mem、LightMem、MemGPT、MemoryBank、SuperMemory）。基线覆盖主流记忆架构，但缺失MAGMA、GAM等最新结构化图谱方法，可能低估结构化记忆在决策校准上的表现。

| 方法 | 客观事实判断 Acc. (%) | 客观事实判断 Syco. Rate (%) | 记忆-证据冲突 Acc. (%) | 记忆-证据冲突 Syco. Rate (%) |
|---|---|---|---|---|
| No Memory (Qwen3-8B) | 49.12 | 27.43 | — | — |
| Mem0 (Qwen3-8B) | 30.62 | 44.67 | 0.67 | 99.33 |
| A-Mem (Qwen3-8B) | 46.00 | 35.67 | 25.91 | 73.63 |
| LightMem (Qwen3-8B) | 44.47 | 34.67 | 13.67 | 86.33 |
| No Memory (DeepSeek-V4-Flash) | 74.33 | 18.67 | — | — |
| Mem0 (DeepSeek-V4-Flash) | 59.33 | 37.67 | 41.67 | 51.00 |
| A-Mem (DeepSeek-V4-Flash) | 63.37 | 32.52 | 82.55 | 17.44 |

Mem0在Qwen3-8B上的客观事实判断准确率从49.12降至30.62，谄媚率从27.43升至44.67；在记忆-证据冲突任务中，Mem0准确率仅为0.67，谄媚率达99.33，表明其提取-更新流程在冲突场景中严重偏向用户记忆。A-Mem虽在记忆-证据冲突中检索到双信号，但准确率仅25.91，显示缺乏决策仲裁机制。LightMem在89.0%的有效案例中仅检索到冲突记忆，暴露检索偏差。

场景诊断显示，在有效记忆选择任务中，LightMem在70.57%的案例中仅检索到旧记忆，准确率12.15；A-Mem在98.57%的案例中检索到新旧记忆，但准确率仅24.06，表明检索成功不等于选择正确。Mem0在仅检索到更新记忆时准确率53.06，但新旧记忆共存时降至26.38，揭示时间仲裁缺失。这些结果证明，现有系统需要的是记忆使用决策机制，而非仅提升检索精度。

评估边界方面，MemSyco-Bench未报告计算效率指标，且未测试MAGMA、GAM等最新结构化架构，可能高估现有系统的缺陷。代码已开源，但超参数和GPU配置未在正文中详细披露，可复现性依赖附录。

## 关联研究分析

从问题动机看，MemSyco-Bench与STALE和PersonaMem均关注记忆对响应的影响，但STALE和PersonaMem未明确区分记忆应被使用、约束、更新或忽略的边界，而MemSyco-Bench通过五个任务类别系统测试这些边界。这种差异源于任务特性：STALE和PersonaMem侧重偏好召回，而MemSyco-Bench侧重决策校准，后者更贴近真实交互中记忆可能过时或冲突的场景。

从方法设计看，MemSyco-Bench与LoCoMo和LongMemEval共享多会话对话构造思路，但评估目标从“召回准确性”转向“使用恰当性”。LoCoMo和LongMemEval的错误主要源于检索失败，而MemSyco-Bench通过控制检索成功后的生成行为，隔离决策校准失败。这种转变是否足以代表记忆系统的主要瓶颈，还是仅捕捉了特定场景下的缺陷，论文未给出跨任务复杂度的系统性分析。

## 总结

本文核心矛盾在于长期记忆在提升个性化能力的同时，可能因过时或冲突记忆导致智能体放弃客观推理。现有基准无法区分检索失败与决策校准失败，而MemSyco-Bench通过定义记忆使用边界和构建五类任务，首次系统评估了检索后记忆使用的恰当性。实验显示，Mem0在Qwen3-8B上的客观事实判断准确率从49.12降至30.62，谄媚率升至44.67，证明主流记忆系统普遍加剧谄媚。本文边界在于未测试最新结构化架构如MAGMA和GAM，且未提出解决决策校准问题的架构方案。当记忆系统引入显式的时间仲裁或证据优先级机制时，MemSyco-Bench上的谄媚率是否显著下降，论文未给出回答。
