# HuggingFace最新推荐论文 ｜Scalable Visual Pretraining for Language Intelligence ｜视觉预训练

研究机构：中国科学技术大学、浙江大学

作者：Yiming Zhang、Zhonghan Zhao、Wenwei Zhang 等 17 人

论文原文见 [arXiv](https://arxiv.org/abs/2607.09657)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.09657)

> 大语言模型（LLM）依赖文本语料预训练，但科学文档中的图表、公式与版面结构在文本化过程中被丢弃，导致模型无法获取这些视觉线索承载的推理信息。现有方法要么将文档解析为纯文本，要么将视觉输入仅作为文本预测的条件上下文，均未能将视觉内容深度整合进预测目标。本文提出视觉预训练（VP），通过自回归预测文档页面的视觉潜变量，在无图文配对监督下直接从原始视觉文档中学习语言智能。该范式在匹配语料下显著优于文本预训练，但其增益是否源于视觉结构本身还是数据分布差异，仍需更严格的对照实验验证。

## 研究背景

当模型处理包含复杂几何约束的科学文档时，若仅依赖解析后的文本，会丢失公式拓扑、图表对应关系及版面空间逻辑。这种信息损耗源于文本化过程的有损性，而认知科学表明人类推理高度依赖这些视觉线索。为弥补这一缺陷，需引入一种能直接建模视觉结构的预训练机制，使模型在预测过程中保留文档原生的空间与符号关系。

现有主流路线分为两类：数据层面，通过解析HTML或LaTeX源、或应用神经文档解析模型将PDF转为纯文本，但此过程必然丢弃版面结构；训练层面，多模态基础模型虽引入视觉输入，但仅将其作为文本token预测的条件上下文，视觉内容未进入预测目标。这两种方式均使视觉模态游离于模型学习核心之外。本文切入点在于：将原始文档页面渲染为图像，提取前景视觉块，并训练模型预测下一个视觉潜变量，从而将视觉结构直接纳入自回归预测目标，无需任何文本提取或图文配对监督。

## 核心方法

### 方法参照系

本文问题可置于多模态预训练框架下，但关键差异在于：传统方法以文本token为预测目标，视觉仅为条件；本文以视觉潜变量为预测目标，文本与视觉并行训练，且视觉编码器冻结。

### 稀疏前景视觉序列构建

设计动机：文档页面包含大量空白区域，直接处理全图会引入冗余噪声并增加计算成本。本文通过像素方差与平均亮度统计计算前景掩码，仅保留非空白块，并按光栅扫描顺序排列，形成稀疏前景序列 $\mathcal{U} = \text{Raster}\{z_i : m_i=1\} = (u_1, \dots, u_L)$，其中 $L \ll N$。该设计在保留页面空间布局的同时，将视觉上下文长度压缩至可处理范围，使模型能聚焦于承载语义的视觉内容。

### 自回归视觉潜变量预测

设计动机：传统对比学习仅对齐全局特征，无法捕捉文档内局部视觉块的时序与空间依赖关系。本文引入下一个视觉潜变量预测目标，给定位置 $t$ 的LLM隐状态，通过输出投影头映射回冻结视觉潜变量空间，预测 $\hat{z}_{t+1}$，并使用带批内负样本的对比损失训练：

$$
\mathcal{L}_{VP} = -\frac{1}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} \log p_{ii}
$$

其中 $p_{ij}$ 为预测位置 $i$ 与目标特征 $j$ 的余弦相似度经温度 $\tau$ 缩放后的softmax概率。该目标迫使模型在预测当前视觉块时，必须理解其在文档中的上下文位置与语义角色，从而将视觉结构深度整合进语言模型的预测过程。最终训练目标为文本交叉熵损失与视觉预训练损失的加权组合：$\mathcal{L} = \lambda_{text}\mathcal{L}_{CE} + \lambda_{vis}\mathcal{L}_{VP}$。

## 实验评估

实验在Qwen3.5、Qwen3、Llama3.2 Vision及Llama3.1四个骨干上，使用匹配的科学PDF语料进行持续预训练（CPT），随后应用相同的监督微调（SFT）并在MMLU-Pro、GPQA、AIME-25、HLE等基准上评估。基线覆盖文本预训练（TP）与基础模型，但未包含其他视觉预训练变体（如仅使用图像分类损失或无前景过滤的全图预测），可能低估了VP相对于其他视觉建模策略的优势。

| 骨干 | 基准 | Base | Text Pretraining | VP (Ours) |
| :--- | :--- | :--- | :--- | :--- |
| Qwen 3.5 | MMLU-Pro | 82.31 | 83.91 | 85.09 |
| Qwen 3.5 | GPQA | 77.84 | 76.24 | 79.29 |
| Qwen 3.5 | AIME | 81.56 | 89.58 | 90.21 |
| Qwen 3.5 | HLE | 14.39 | 15.70 | 16.67 |
| Llama 3.2 Vision | MMLU-Pro | 47.24 | 50.60 | 51.52 |
| Llama 3.2 Vision | GPQA | 27.46 | 30.24 | 33.08 |
| Llama 3.2 Vision | AIME | 8.02 | 13.75 | 18.54 |
| Llama 3.2 Vision | HLE | 6.41 | 6.08 | 7.00 |

VP在所有骨干与基准上均优于TP，其中GPQA在Qwen3.5上提升3.05分（76.24→79.29），AIME在Llama3.2 Vision上提升4.79分（13.75→18.54）。消融实验显示，VP的增益随视觉结构密度增加而扩大，在高密度图表页面上优势最显著，而在低密度文本页面上与TP持平，表明增益确实源于视觉内容建模。此外，VP仅消耗约20B视觉token，而TP消耗约80B文本token，效率提升4倍。

评估边界方面，论文未报告置信区间，且所有结果基于单一SFT配方，无法排除SFT数据分布对结果的干扰。代码未公开，但提及使用XTuner框架，超参数细节在补充材料中。跨模态对齐指标（如CKA、余弦相似度）仅在100个样本上计算，统计效力有限。

## 关联研究分析

从问题动机看，ConVIRT（Shi et al., 2022）与CT-CLIP均依赖图文配对监督，通过全局对比学习对齐医学影像与报告嵌入，其核心假设是配对数据能提供可靠的语义锚点。本文则完全摒弃配对监督，认为原始视觉结构本身即包含足够的推理线索，无需外部文本标签。这一差异源于任务特性：医学影像的病灶稀疏且语义明确，配对数据能有效约束表示空间；而科学文档的视觉结构复杂且语义隐含，配对数据可能引入噪声或无法覆盖所有视觉关系。

从方法设计看，MedTri（Chu et al., 2026）使用LLM将自由文本报告结构化为三元组，以消除词汇与风格变异，其核心是“清洗文本”；本文则通过视觉预训练“绕过文本”，直接建模原始视觉形式。两者均旨在提升预训练数据质量，但路径相反：MedTri增强文本侧，本文增强视觉侧。这种对立暗示，当文本提取过程本身成为信息瓶颈时，直接建模视觉源可能比清洗文本更有效，但这也意味着模型无法利用文本中已存在的精确语义标签，可能在需要细粒度术语匹配的任务上表现受限。

## 总结

本文要解决的核心矛盾是：文本化过程丢弃科学文档中的视觉结构信息，导致模型无法获取这些线索承载的推理能力。现有方法要么依赖有损的文本提取，要么将视觉仅作为条件上下文，均未能将视觉结构深度整合进预测目标。本文抓住的切入点是：将原始文档页面作为预测目标，通过自回归视觉潜变量预测，在无图文配对监督下直接从视觉中学习语言智能。实验证明，VP在匹配语料下于GPQA上提升3.05分，在AIME上提升4.79分，且仅消耗25%的token预算。其边界在于：所有增益基于单一SFT配方，且未与其他视觉预训练变体对比，无法排除增益源于数据分布差异而非视觉结构建模本身。当视觉结构密度极低时，VP与TP性能持平，这是否意味着视觉预训练仅在特定文档类型上有效，论文未给出回答。
