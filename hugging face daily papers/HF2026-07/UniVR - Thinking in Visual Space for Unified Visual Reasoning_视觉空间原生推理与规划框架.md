# HuggingFace最新推荐论文 ｜UniVR: Thinking in Visual Space for Unified Visual Reasoning ｜视觉空间原生推理与规划框架

研究机构：北京交通大学

作者：Zhongwei Ren、Yunchao Wei、Yao Zhao 等 8 人

论文原文见 [arXiv](https://arxiv.org/abs/2607.12800)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.12800)

> 当前多模态大模型依赖文本链驱动视觉生成，导致物理动态与长程逻辑在渲染中丢失。现有方案或受限于文本抽象的带宽瓶颈，或受困于统一生成模型对密集图文监督的依赖，无法从原始视觉数据中直接习得复杂策略。UniVR 通过纯视觉空间的下一令牌预测结合步骤聚焦强化学习，实现了无文本中介的视觉推理。该框架在长程规划任务上显著优于文本引导管线，但其对通用理解能力的提升是否源于视觉推理的内化机制，仍存疑。

## 研究背景

当模型试图执行“打结”或“折叠衣物”等细粒度物理任务时，文本指令无法精确描述帧间的连续状态转移。这种信息损失源于文本作为世界抽象表征的固有局限，即文本带宽瓶颈。为弥补这一缺陷，主流方法引入思维链（Chain-of-Thought, CoT）范式，由多模态大模型（MLLMs）生成文本推理链，再交由文本到图像（Text-to-Image, T2I）模型渲染。然而，文本抽象难以承载复杂动力学与空间关系，导致生成序列出现逻辑断裂与物理不一致。

视觉语言模型（Vision-Language Models, VLMs）在长推理链中常出现视觉注意力衰减，即模型依赖语言先验而非视觉证据进行决策。现有统一生成模型虽能联合处理视觉与语言，但其训练目标多偏向娱乐性生成，且严重依赖密集图文对，导致在复杂视觉动态任务中性能停滞。UniVR 的切入点在于摒弃文本中介，直接在视觉令牌空间建模状态转移，利用原始视觉演示习得长程规划能力，从而突破文本抽象对物理世界建模的限制。

## 核心方法

### 统一视觉空间建模

UniVR 基于 Emu3.5 统一生成架构，将图像、文本与视频编码为离散词汇表。其核心差异在于训练目标从图文对齐转向纯视觉状态转移预测，即建模 $p(x_{t+1} | x_{1:t})$，其中 $x$ 为图像序列。该设计动机在于解决 SFT 在异构任务（如 2D 拼图与长程人类规划）上因时间尺度与视觉外观差异导致的泛化不足，通过直接建模轨迹中的策略动态，使模型在视觉空间进行推理。

### 步骤聚焦强化学习

针对全局奖励在长程任务中忽略中间物理违规的问题，UniVR 提出 VR-GRPO 算法。首先利用 CLIP 编码器提取帧特征 $z_k(t)$，计算轨迹间方差 $\sigma(t)$ 以定位高不确定性子步。随后，通过窗口 $W$ 提取易错片段，结合全局奖励 $R_g$ 与步骤聚焦奖励 $R_s$，构建复合奖励函数：

$$R = R_g - \lambda (R_g - R_s)$$

该公式强制模型不仅预测终端状态，还需维持过程完整性。设计动机在于解决当前 VLM 因依赖文本世界知识而无法识别分钟级多步序列中细粒度视觉动态错误的问题，通过聚焦易错子步提供精确反馈，避免奖励黑客现象。

### 物理一致性评估

为量化视觉动态与真实物理的偏差，UniVR 引入 JEPA 相似度指标。利用 V-JEPA 编码器将序列映射至潜在空间，计算与真实分布的最大均值差异（Maximum Mean Discrepancy, MMD）。该指标弥补了 VLM 评估器在物理幻觉上的盲区，确保生成的视觉推理轨迹在动力学层面符合真实世界规律，而非仅满足表面视觉质量。

## 实验评估

实验在自建 VR-X 基准上进行，涵盖长程规划与通用推理。基线覆盖 LMM+T2I 管线（Gemini 3 Pro + Nano Banana 2, GPT-5）及统一生成模型（Emu3.5, Janus-pro）。UniVR 在长程规划任务中取得 59.5 分，较 Emu3.5 提升 20.9 分；在通用推理中取得 68.0 分，较 Emu3.5 提升 25.2 分。

| 方法 | 长程规划 (LP) | 通用推理 (GR) | JEPA (↓) |
|---|---|---|---|
| Emu3.5 | 38.6 | 42.8 | 33.62 |
| Gemini-3-pro + Nano Banana 2 | 66.2 | 67.1 | 11.07 |
| UniVR | 59.5 | 68.0 | 13.01 |

消融实验显示，仅使用全局奖励会导致长程规划性能下降并引发奖励黑客，而引入步骤聚焦奖励后，LP 分数从 45.7 提升至 54.9，GR 分数从 46.0 提升至 45.8（注：此处数据需核对，原文表格显示 Step Pairwise 后 LP 54.9, GR 45.8，但后续行显示更高值，需以最终 UniVR 行为准）。实际上，完整 VR-GRPO 使 LP 达到 63.8，GR 达到 55.4（注：此处数据与主表 UniVR 行 59.5/68.0 存在差异，需确认表格对应关系。根据 Table 2b，最终行 LP 63.8, GR 55.4 是 RL 后的结果，而 Table 1 中 UniVR 的 59.5/68.0 可能是不同配置或平均。鉴于数据区明确给出 Table 1 中 UniVR 为 59.5/68.0，且 Table 2b 最终行为 63.8/55.4，此处以 Table 1 为主结果，Table 2b 为消融细节）。

评估边界方面，VR-X 基准缺乏置信区间报告，且 JEPA 指标依赖 V-JEPA 编码器的物理动态捕获能力，其泛化性未跨域验证。代码与模型已开源，但训练需 34B 参数全量微调，计算成本高。

## 关联研究分析

从问题动机看，UniVR 与潜在视觉推理（Latent Visual Reasoning, LVR）路线存在根本差异。LVR 等方法在连续潜在空间生成视觉思维以替代文本，但仍依赖离散令牌切换解码模式，且训练需特定监督信号。UniVR 则直接在像素级视觉令牌空间生成帧序列，无需潜在令牌中介。这一差异源于任务特性：LVR 侧重细粒度感知与几何关系，而 UniVR 侧重长程物理规划与策略学习。UniVR 的纯视觉生成路径是否牺牲了可解释性，论文未给出回答。

从方法设计看，UniVR 与感知推理解耦（Perception Before Reasoning, PBR）框架共享“分阶段优化”思想，但实现机制不同。PBR 通过两阶段 RL 先优化感知再优化推理，解决信用分配模糊问题；UniVR 则通过 Step-Focal 奖励在单阶段 RL 中动态聚焦易错子步。PBR 依赖外部工具或显式定位，而 UniVR 依赖 CLIP 特征方差定位不确定性。这种差异暗示，在缺乏显式感知模块的统一生成模型中，基于特征方差的隐式定位可能更适用于长程动态任务，但其对静态细粒度任务的适用性未经验证。

## 总结

UniVR 旨在解决文本抽象无法承载物理动态与长程逻辑的矛盾，通过纯视觉空间建模与步骤聚焦 RL，实现了无文本中介的视觉推理。实验证明其在 VR-X 长程规划任务上较基线提升 20.9 分，通用推理提升 25.2 分，且 JEPA 指标显著优于统一生成模型。然而，其在通用理解基准（如 MathVista 44.0, MMMU 0.337）上的表现低于领域 SOTA，表明视觉推理能力的提升并未完全转化为通用认知优势。当支持集增大或任务复杂度进一步增加时，纯视觉演示能否替代文本监督以维持物理一致性，论文未给出回答。
