# HuggingFace最新推荐论文 ｜SiamJEPA: On the Role of Siamese Student Encoders in JEPA ｜孪生学生编码器在联合嵌入预测架构中的正则化作用

研究机构：日本冲绳科学技术大学院大学

作者：Makoto Yamada

论文原文见 [arXiv](https://arxiv.org/abs/2607.04044)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.04044)

> 联合嵌入预测架构（Joint Embedding Predictive Architecture, JEPA）旨在通过预测潜在空间中被掩码区域的嵌入来学习表示，但现有主流方法如 I-JEPA 依赖单一学生编码器与指数移动平均（EMA）教师网络，在有限训练预算下收敛速度受限。本文切入点在于引入孪生学生编码器结构，将其视为一种隐式正则化机制，以加速早期训练并提升表示分离度。具体做法是构建双独立掩码视图，通过 KL 散度对齐两编码器全局表示，并预测掩码 token 的潜在嵌入。该设计在 400 个 epoch 内实现了优于掩码自编码器（Masked Autoencoder, MAE）的线性探测性能，但其绝对精度仍低于训练更久的 I-JEPA，且未验证在密集预测任务中的有效性。

## 研究背景

自监督表示学习（Self-Supervised Representation Learning, SSRL）的核心困境在于防止表示坍塌，即编码器将所有输入映射为低秩向量的退化现象。在 JEPA 范式中，这一问题尤为突出，因为缺乏显式负样本或像素重建目标的约束，模型极易陷入局部最优。为此，I-JEPA 和 V-JEPA 采用 EMA 教师网络提供稳定目标，而 LeJEPA 则引入斯莱特各向同性高斯正则化（Sketched Isotropic Gaussian Regularization, SIGReg）直接约束嵌入分布。然而，这些方法均假设学生网络为单一编码器，忽略了架构对称性对表示几何结构的潜在影响。

JEPA 路线的演进揭示了从像素重建到潜在预测的范式转移，但现有工作对“学生网络内部结构”的关注不足。PhiNet 等生物启发式模型证明了孪生编码器在时序预测中的有效性，但其应用局限于视频域且未与 JEPA 的掩码预测机制系统结合。本文的研究问题在于：在图像分类任务中，孪生学生编码器是否构成 JEPA 框架中有效的归纳偏置？这一问题紧迫性在于，当前 JEPA 方法在有限计算资源下的训练效率瓶颈，亟需通过架构层面的改进而非单纯增加训练时长来突破。

## 核心方法

### 方法参照系

标准 JEPA 流程包含掩码输入、单学生编码器、EMA 教师编码器及预测器，目标是最小化预测嵌入与教师嵌入的均方误差。本文问题与该通用流程的关键差异在于，将单学生编码器替换为共享权重的孪生学生编码器，并引入独立的掩码策略，使得模型需同时处理两个互补的视图信息。

### 孪生编码器与 KL 正则化

在标准 JEPA 中，学生编码器仅处理单一掩码视图，其表示质量完全依赖 EMA 教师的稳定性。本文在参照系流程的输入端引入双独立掩码视图 $M_1$ 和 $M_2$，且 $M_1 \cap M_2 = \emptyset$，确保两视图信息互补。设计动机在于，单一视图可能丢失关键语义信息，而双视图通过信息互补强制编码器学习更鲁棒的表示。

$$ \mathcal{L}_{Sim-1} = \lambda_{KL} D_{KL}(q(\mathbf{Z} | \mathbf{H}^{(1)}, \mathbf{H}^{(2)}) \| p(\mathbf{Z} | \mathbf{H}^{(1)})) $$

该公式通过最小化后验分布（基于双视图）与先验分布（基于单视图）的 KL 散度，强制单视图表示具备预测双视图信息的能力。$\lambda_{KL}$ 控制正则化强度，当 $\lambda_{KL} \to 0$ 时，模型退化为单编码器 JEPA。这一设计解决了单编码器在早期训练中因信息不足导致的表示模糊问题，通过概率框架显式建模视图间的不确定性，提升了表示的判别性。

### 潜在空间预测目标

承接孪生编码器的输出，本文在预测器端采用概率预测器架构，而非标准 JEPA 的确定性回归。设计动机在于，掩码区域的潜在表示存在固有不确定性，确定性预测可能过拟合于特定噪声模式。

$$ \mathcal{L}_{Sim-2} = \frac{1}{|M_{\bar{}}|} \sum_{i \in M_{\bar{}}} \| g(\mathbf{H}^{(1)}_{\text{unmasked}}, \mathbf{H}^{(2)}_{\text{unmasked}}) - \text{sg}(f_{\text{ema}}(\mathbf{X})_i) \|_F^2 $$

该公式计算预测器输出与 EMA 教师嵌入的归一化均方误差（NMSE），其中 $g(\cdot)$ 为基于 Transformer 的概率预测器，输入为双视图的非掩码 token 表示。sg 表示停止梯度操作，确保教师网络参数不被学生梯度更新。这一设计避免了像素重建的高频噪声过拟合，同时通过双视图输入增强了预测目标的语义完整性，使得模型在更少训练轮次内收敛至更优的表示空间。

## 实验评估

实验在 ImageNet-1K 上进行，采用 ViT-Base 骨干，对比基线包括 MAE、CAE 和 I-JEPA。基线覆盖重建式与预测式两条路线，但缺失 BYOL、DINO 等非对比基线及 LeJEPA 等最新 JEPA 变体，限制了与当前 SOTA 的直接比较。

| 方法 | Epochs | Top-1 Acc. (%) |
| :--- | :--- | :--- |
| MAE | 400 | 61.9 |
| MAE | 1600 | 68.0 |
| CAE | 1600 | 70.4 |
| I-JEPA | 600 | 72.9 |
| SiamJEPA | 400 | 70.2 |

SiamJEPA 在 400 epochs 下达到 70.2% 的线性探测准确率，显著优于同轮次的 MAE（61.9%），但低于训练 600 epochs 的 I-JEPA（72.9%）。这一差距部分源于训练时长差异，但论文未提供 600 epochs 的 SiamJEPA 结果，无法完全归因于训练预算。

| KL Weight ($\lambda_{KL}$) | Epoch 100 | Epoch 300 |
| :--- | :--- | :--- |
| 0.0001 | 57.89 | 66.78 |
| 0.010 | 63.72 | 69.30 |
| 0.030 | 63.58 | 69.05 |

消融实验表明，$\lambda_{KL} = 0.01$ 时性能最优，且在 100 epochs 内即达到 $\lambda_{KL} = 0.0001$ 在 200 epochs 时的水平，证明 KL 正则化加速了收敛。Free-bit 阈值 0.05 略优于 0.1，但差异微小，表明方法对超参数不敏感。

评估边界方面，论文仅报告线性探测准确率，未提供置信区间或微调结果，且未测试密集预测任务（如分割）。可复现性上，论文基于 MAE 官方代码库实现，但未公开代码，且 I-JEPA 基线数据取自原始论文（600 epochs），与本文 400 epochs 设置不可直接比较。

## 关联研究分析

从问题动机看，SiamJEPA 与 PhiNet 共享生物启发式根源，但 PhiNet 聚焦时序预测中的互补学习系统（Complementary Learning Systems, CLS）理论，而 SiamJEPA 将其迁移至图像掩码预测。关键差异在于，PhiNet 的孪生编码器用于建模时间步间的预测关系，而 SiamJEPA 用于建模空间掩码视图间的互补性。这一迁移是否保留了 CLS 理论中“快慢学习”的动态特性，论文未给出回答，仅将其简化为静态的视图一致性约束。

从方法设计看，SiamJEPA 与 LeJEPA 均旨在提升 JEPA 的训练稳定性，但 LeJEPA 通过 SIGReg 显式约束嵌入分布的各向同性，而 SiamJEPA 通过架构对称性隐式引入正则化。LeJEPA 在 1.8B 参数模型上验证了理论优越性，而 SiamJEPA 仅在 ViT-Base 上测试。这种规模差异暗示，孪生结构的计算开销在大规模模型中可能抵消其效率优势，且 LeJEPA 的显式正则化可能比架构隐式正则化更具可扩展性。

## 总结

SiamJEPA 试图解决 JEPA 在有限训练预算下收敛缓慢的矛盾，其切入点在于利用孪生学生编码器的架构对称性作为隐式正则化，而非依赖显式分布约束。通过引入 KL 散度对齐双视图表示，该方法在 400 epochs 内实现了 70.2% 的线性探测准确率，优于同轮次的 MAE。然而，论文未提供与 I-JEPA 在相同训练时长下的对比，且未验证在密集预测任务中的表现，暴露了其在大规模模型和复杂下游任务中的适用性边界。当训练轮次增加至 600 epochs 时，SiamJEPA 的性能是否仍能保持对 MAE 的显著优势，论文未给出回答。
