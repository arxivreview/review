研究机构：韩国首尔大学

作者：Taewook Kang、Taeheon Kim、Donghyun Shin 等 4 人

论文原文见 [arXiv](https://arxiv.org/abs/2607.00666)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.00666)

> 视觉-语言-动作模型在部署到新环境时因相机位姿或本体差异导致性能骤降，而现有适应方法需为每个任务收集大量演示数据，成本高昂。本文指出单次微调权重中任务与域方向呈可加性解耦，提出域算术（DART）通过权重减法提取纯域向量并注入基座模型，仅需单条演示即可实现跨任务适应。该方法在仿真与真机实验中显著优于全量微调与模型合并基线，但其依赖源域同任务演示的假设在开放世界场景中是否成立尚存疑。

## 研究背景

视觉-语言-动作模型（VLA）将预训练视觉-语言骨干与大规模机器人数据集结合，赋予策略网络多任务泛化能力。然而，当部署环境发生相机位姿改变或本体切换时，输入分布与动作空间发生系统性偏移，导致源域训练的策略在目标域失效。这种环境偏移不同于图像分类中的协变量偏移，它同时涉及感知模态与动作执行模态的联合分布变化，使得传统的测试时适应（TTA）方法难以直接迁移。

主流VLA适应路线分为数据增强微调与架构修改两类。前者通过多样化训练提升鲁棒性，但需为目标域每个任务收集专家演示，数据成本呈线性增长；后者通过引入语义特征或修改网络结构降低数据需求，但限制了跨骨干网络的通用性。测试时适应方法虽无需额外训练，但多针对有限偏移场景，且依赖在线梯度更新，计算开销大。本文切入点在于利用权重空间的结构性质，将环境偏移解耦为可独立迁移的域向量，从而在仅有一条演示数据的极端数据受限条件下，实现架构无关的跨任务适应。

## 核心方法

### 权重算术参照系

本文问题置于模型合并与权重算术框架下。标准流程通过向量加法合并多个微调模型的能力，但无法选择性迁移特定属性。本文关键差异在于利用类比操作（减法）分离任务与域方向，而非简单叠加。

### 域向量提取与子空间过滤

直接减法易引入源域噪声，本文通过子空间对齐过滤非共享成分。设计动机是解决单次微调中任务方向主导、域方向微弱且混杂噪声的问题。

$$ \delta_{tgt}^{(l)} = \Delta_{m,tgt}^{(l)} - \Delta_{m,src}^{(l)} $$

该公式通过减去源域同任务更新向量，抵消共享的任务特定方向，保留环境偏移特有的域方向。

### 子空间缩放与注入

过滤后仍需抑制残余噪声，本文引入对齐分数缩放。设计动机是处理源-目标更新向量子空间错位导致的域向量失真。

$$ \tilde{\delta}_{tgt}^{(l)} = \gamma^{(l)}(\Delta_{m,src}, \Delta_{m,tgt}) \cdot \delta_{tgt}^{(l)} $$

其中 $\gamma$ 为子空间对齐分数，衡量源-目标更新向量在左奇异向量子空间的重叠程度。最终适应参数为 $\theta^* = \theta_0 + \alpha \tilde{\delta}_{tgt}$，$\alpha$ 控制适应强度。

## 实验评估

实验在LIBERO仿真基准（视觉偏移）、MimicGen（跨本体）及UR10e真机（视角偏移）上进行。基线覆盖单次微调、RETAIN（ICLR 2026）、FLA（CVPR 2026）及模型合并方法（TIES, TSV, Iso-C）。DART在LIBERO平均成功率达79.1%，显著高于单次微调的75%和Task Arithmetic的74.5%。

| 方法 | 子空间过滤 | 子空间缩放 | 平均成功率 (%) |
| :--- | :---: | :---: | :---: |
| DART | ✓ | ✓ | 79.1 |
| DART w/o SA | ✗ | ✗ | 78.1 |
| TA | ✗ | ✗ | 74.5 |
| DART + TIES | ✓ | ✓ | 78.5 |
| DART + TSV | ✓ | ✓ | 79.1 |

消融显示子空间过滤与缩放共同贡献约1个百分点增益，而结合TIES合并策略未带来额外提升，表明DART的域向量提取已足够纯净。真机实验中，DART在单条演示下实现91.7%的Pick-and-Place成功率，远超基线的50.0%。

评估边界方面，实验仅覆盖LIBERO与MimicGen标准基准，未测试极端本体差异（如四足到双臂）。代码已开源，但超参数 $\alpha$ 的敏感性分析仅在补充材料中简要提及，缺乏跨任务范围的鲁棒性验证。

## 关联研究分析

从问题动机看，DART与测试时适应（TTA）中的原型缓存路线形成对比。TTA方法（如TDA）依赖在线维护特征缓存以校准预测，需持续访问测试流；DART则采用离线一次性权重算术，无需在线计算，但牺牲了动态适应能力。这一差异源于任务特性：VLA部署中环境偏移通常稳定，单次适应即可覆盖长期任务，而图像分类TTA面对流式数据需持续更新。

从方法设计看，DART与模型合并中的TIES、TSV方法共享子空间对齐思想，但目标不同。TIES旨在合并多个任务能力时消除干扰，保留各任务独特成分；DART旨在分离任务与域方向，移除共享任务成分以纯化域向量。这一设计选择源于VLA适应中“保留基座多任务能力、仅迁移环境知识”的需求，而非能力组合。

## 总结

本文核心矛盾在于VLA环境适应的数据成本与跨任务泛化需求之间的冲突。现有方法需为每个任务收集演示，而DART利用权重空间的可加性解耦，通过单条演示提取域向量，实现了架构无关的跨任务迁移。实验证明其在LIBERO上79.1%的平均成功率及真机91.7%的Pick-and-Place成功率，验证了域向量提取的有效性。边界在于依赖源域同任务演示的假设，且未探索多域合并时的干扰消除。当源域数据不可用或任务分布发生概念偏移时，域向量的提取是否仍具鲁棒性，论文未给出回答。
