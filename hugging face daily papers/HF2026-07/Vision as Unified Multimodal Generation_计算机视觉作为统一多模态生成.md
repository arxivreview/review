# HuggingFace最新推荐论文 ｜Vision as Unified Multimodal Generation ｜计算机视觉作为统一多模态生成

研究机构：商汤、新加坡南洋理工大学

作者：Xiaoyang Han、Jianhua Li、Kewang Deng 等 17 人

论文原文见 [arXiv](https://arxiv.org/abs/2607.06560)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.06560)

> 传统计算机视觉任务依赖专用架构与解码器，导致监督信号难以跨任务共享与组合。现有统一模型或局限于序列格式，或仅覆盖图像侧密集预测，无法原生表达符号记录与密集空间目标的混合输出。本文提出将异构视觉任务映射至统一多模态模型（UMM）的原生文本与图像生成空间，通过构建大规模指令-响应语料库实现无任务头训练。该方案在结构化理解与密集几何预测上达到专用系统水平，但通用理解能力存在轻微退化，其作为通用感知底座的长期有效性尚待验证。

## 研究背景

当视觉模型需要同时处理检测框、分割掩码与3D点云时，传统范式为每个任务配备独立的编码器、损失函数与解码规则。这种任务特异性设计导致视觉监督信号无法跨任务复用，且模型难以理解组合式语言指令。统一多模态模型（UMM）通过共享生成空间解决此问题，但早期工作如UnifiedIO依赖序列序列化，对密集像素级输出支持不足；而基于扩散的感知方法如Vision Banana虽能生成密集地图，却无法表达OCR文本或相机参数等符号记录。

该领域核心矛盾在于：符号记录（如类别、坐标）天然属于文本空间，而密集预测（如深度、法线）天然属于图像空间，二者在单一生成接口中缺乏原生表达机制。现有方案要么将密集输出强行序列化为离散Token，导致细粒度信息丢失；要么仅利用图像生成空间，无法覆盖混合输出需求。本文切入点在于利用UMM原生的双模态生成能力，将符号记录映射为文本生成，密集目标映射为图像生成，通过确定性解码规则实现任务特异性输出的恢复。

## 核心方法

### 统一生成接口与解码协议

本文方法参照系为基于UMM的视觉感知框架，关键差异在于摒弃任务特定头，将异构输出统一映射至原生生成空间。对于结构化视觉理解任务，输出表示为文本序列，空间字段采用归一化坐标，通过`<bbox>`、`<point>`等轻量标记符界定边界。对于密集几何预测，输出表示为图像，深度值转换为逆深度灰度图，法线值编码为RGB通道。这种设计解决了此前方法中密集输出与符号输出无法在同一接口中表达的问题，使单一模型能同时处理稀疏与密集监督信号。

### 混合文本-图像响应机制

针对组合式任务（如GCG分割），本文引入混合响应格式，其中文本组件列出区域描述与颜色图例，图像组件渲染对应掩码。该机制解决了单一模态响应无法同时保留语义描述与像素级监督的问题。训练目标采用标准交叉熵损失与Rectified-Flow目标的联合优化：

$$
\mathcal{L}_{total} = \mathcal{L}_{CE}(y_{txt}, x) + \lambda \mathcal{L}_{RF}(y_{img}, x)
$$

其中$\mathcal{L}_{CE}$优化文本符号记录的准确性，$\mathcal{L}_{RF}$优化图像密集预测的空间一致性。这种联合监督使模型在生成文本描述的同时，能精确渲染对应的像素级掩码，实现了语义与几何的协同优化。

### 多视图几何统一表示

对于多视图3D任务，本文采用混合响应格式：点云地图作为图像输出存储归一化3D坐标，相机位姿作为文本序列编码四元数旋转与平移。该设计解决了此前方法中3D几何输出无法在单一生成空间中统一表示的问题。通过保留密集点云在图像空间、离散位姿在文本空间，模型能同时优化空间重建精度与几何元数据准确性，避免了专用前馈模型在语言指令理解上的局限性。

## 实验评估

实验在COCO、NYUv2、KITTI等基准上评估，基线覆盖专用系统（VGGT、Lotus-2）与通用模型（Youtu-VL、Vision Banana）。

| 任务 | 指标 | SenseNova-Vision | Youtu-VL | Vision Banana |
| :--- | :--- | :--- | :--- | :--- |
| 检测 | COCO mAP | 53.7 | 47.1 | - |
| 分割 | RefCOCO cIoU | 80.3 | 76.0 | 80.3 |
| 深度 | NYUv2 δ1 | 98.1 | - | 95.0 |
| 法线 | NYUv2 mean err | 15.3 | - | 12.8 |

在结构化理解与密集几何预测上，本文性能接近或超越专用系统，但在法线估计上略逊于Vision Banana。

消融实验显示，混合任务训练对通用能力保持至关重要。移除辅助多模态数据后，MMVP得分从79.0降至更低水平，表明CV任务训练与通用理解存在轻微冲突。

评估边界方面，本文未报告MMMU等复杂推理基准，且RefCOCO上低于UVU（91.8）可能源于分割任务比定位任务更难。代码与模型已开源，但训练细节如超参数敏感性未充分披露。

## 关联研究分析

从问题动机看，本文与Vision Banana同属图像生成路线，但后者仅覆盖图像侧密集预测，无法表达符号记录。本文通过引入文本生成空间，解决了混合输出表达缺失的问题，根源在于任务特性要求同时处理稀疏符号与密集像素。

从方法设计看，本文与VGGT同属多视图3D任务，但VGGT为专用前馈模型，缺乏语言指令理解能力。本文依赖生成式推理，虽在性能上接近VGGT，但推理效率可能更低。这种差异源于本文追求通用性而非任务特异性，是否能在实时应用中保持竞争力，论文未给出回答。

## 总结

本文核心矛盾在于异构视觉输出无法在单一生成接口中统一表达。通过利用UMM原生双模态生成空间，将符号记录映射为文本、密集目标映射为图像，本文实现了无任务头的统一感知。实验显示其在COCO检测（53.7 mAP）与NYUv2深度（98.1 δ1）上达到专用系统水平，但MMVP得分较基线下降4.3点，表明CV训练对通用理解存在轻微损害。当支持集增大时，混合任务训练的边际收益是否递减，论文未给出回答。
