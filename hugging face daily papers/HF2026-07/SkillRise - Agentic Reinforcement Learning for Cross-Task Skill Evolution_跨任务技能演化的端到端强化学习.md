# HuggingFace最新推荐论文 ｜SkillRise: Agentic Reinforcement Learning for Cross-Task Skill Evolution ｜跨任务技能演化的端到端强化学习

研究机构：浙江大学、新加坡国立大学

作者：Zhiyuan Yao、Yuxin Chen、Zhengxi Lu 等 16 人

论文原文见 [arXiv](https://arxiv.org/abs/2607.26784)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2607.26784)

> 代理在解决一系列相关但不同的任务时，标准强化学习将每个任务视为独立回合，导致经验无法跨任务迁移。现有技能学习方法要么局限于单任务重复尝试，要么依赖多阶段管线，使得技能提取、检索与执行相互纠缠，难以归因。SkillRise 通过构建渐进任务序列，让单一策略交替执行任务求解与技能文档策展，并利用解耦信用分配将下游任务表现作为策展的监督信号。该框架在三个基准上取得最优 Pass@1，且训练效率显著优于多阶段管线，但其单一文档表示是否足以支撑大规模技能库的扩展仍存疑。

## 研究背景

当代理面对一系列共享底层交互逻辑但实体各异的任务时，若每次均从零开始探索，计算资源将被大量浪费。这种经验孤立现象源于标准代理强化学习将每个任务实例视为独立回合，策略参数虽在更新，但交互轨迹中的程序性知识未被显式提取或复用。为打破这一壁垒，技能学习旨在将交互经验转化为可复用的程序性记忆，然而现有方法在技能表示与优化目标上存在结构性缺陷：LaMer 等元强化学习方法虽能利用历史反思，但局限于同一任务的重复尝试，缺乏跨实例泛化能力；SkillRL 等基于外部技能库的方法虽支持跨任务复用，但依赖教师模型蒸馏、层级库构建及检索模块，多阶段耦合导致性能瓶颈难以定位，且引入高昂的运行时开销。

SkillRise 的切入点在于将跨任务技能学习重构为端到端的强化学习问题。它摒弃了外部技能库与独立检索模块，转而维护一个随任务序列演化的单一文本技能文档。该文档作为任务间唯一的信息通道，其质量直接由后续任务的表现来评估。这种设计将技能提取、精炼与复用统一在单一策略网络中，通过时序解耦的信用分配机制，使策略同时优化“如何解题”与“如何总结”，从而在保持轻量级架构的同时实现跨任务的知识内化。

## 核心方法

### 方法参照系

本文问题可置于代理强化学习的通用框架下，但关键差异在于优化目标的时序结构。标准代理强化学习最大化单任务期望奖励 $J(\theta) = \mathbb{E}[R(\tau)]$，任务间无信息传递。SkillRise 将任务组织为有序序列，引入跨任务状态（技能文档），使得当前策略不仅影响当前任务结果，还通过文档修改影响后续任务结果，从而将独立回合优化扩展为序列级联合优化。

### 跨任务序列构建与演化

传统方法在任务间传递信息时，往往依赖复杂的记忆缓冲区或检索接口，导致信息损失与延迟。SkillRise 在序列构建阶段，将同一任务族内的实例按难度从易到难排序，形成渐进式训练信号。在 rollout 阶段，策略 $\pi_\theta$ 交替执行两种角色：首先利用当前技能文档 $S_{i-1}$ 求解任务 $x_i$ 并获取轨迹 $\tau_i$ 与奖励 $r_i$；随后，策略切换至策展模式，基于 $\tau_i$ 和 $r_i$ 重写文档生成 $S_i$。该过程通过公式 $S_i \sim \pi_\theta(\cdot | S_{i-1}, \tau_i, r_i)$ 实现，其中 $S_i$ 是 $S_{i-1}$ 的完整重写，保留有效技能、整合新发现并剔除实例特定细节。这一设计消除了外部检索模块，使技能更新与任务执行共享同一参数空间，确保了技能演化与策略优化的同步性。

### 解耦信用分配与优化

若将序列级总回报同时赋予求解与策展阶段，会导致技能质量与任务执行能力混淆，策略可能通过牺牲当前任务表现来“投机”未来奖励，或反之。SkillRise 引入解耦信用分配，根据行为角色的时序特性分配不同奖励信号。对于求解阶段，回报为当前任务奖励 $r_i^{(n)}$；对于策展阶段，回报为后续任务奖励的折扣和 $G_{i,z}^{(n)} = \sum_{j=i+1}^{K} \gamma^{j-i} r_j^{(n)}$，其中 $\gamma$ 为跨任务折扣因子。该公式表明，策展行为的质量由其对下游任务的边际贡献决定，而非当前任务结果。在此基础上，采用角色感知的组相对优势计算，仅在相同任务位置与行为角色的试验间比较回报，确保求解与策展的学习信号互不干扰，从而稳定地联合优化两种能力。

## 实验评估

实验在 ALFWorld、WebShop 和 ScienceWorld 三个交互式文本环境上进行，每个环境使用 128 个留出任务实例。基线覆盖提示工程（Zero-shot, ReAct, Reflexion）、任务独立强化学习（PPO, RLOO, GRPO, GiGPO）及元强化学习（LaMer）。所有方法均使用 Qwen3-1.7/4B 作为骨干，确保公平对比。

| 方法 | ALFWorld Pass@1 (%) | WebShop Pass@1 (%) | ScienceWorld Pass@1 (%) |
| :--- | :--- | :--- | :--- |
| ReAct | 25.0 | 2.1 | 7.8 |
| GRPO | 79.7 | 75.8 | 42.2 |
| GiGPO | 83.6 | 77.3 | 46.1 |
| LaMer | 76.7 | 74.2 | 41.4 |
| SkillRise | 85.9 | 84.4 | 54.6 |

SkillRise 在三个基准上均取得最高 Pass@1，较最强基线 GiGPO 分别提升 2.3、7.1 和 8.5 个百分点。值得注意的是，SkillRise 在 WebShop 和 ScienceWorld 上的优势更为显著，表明跨任务技能演化在具有复杂配置或科学推理逻辑的任务中更具价值。

消融实验验证了核心设计的有效性。移除策展阶段（No-Curation）后，性能较完整模型下降约 3 个百分点，证明显式技能文档的演化是性能增益的关键来源，而非仅依赖任务序列训练。跨任务折扣因子 $\gamma$ 在 0.3 至 0.7 范围内变化时，训练轨迹高度一致，最终性能差异小于 1 个百分点，表明解耦信用分配机制对超参数不敏感。此外，SkillRise 展现出跨任务测试时扩展性：当测试序列长度 $K$ 从 2 增至 6 时，ALFWorld 性能从 83.6% 单调提升至 87.5%，而基线方法无此趋势，证实策略学会了将早期交互转化为可迁移技能。

评估边界方面，论文未报告置信区间，且所有实验基于单一骨干模型 Qwen3-4B，未验证在更大规模模型上的泛化性。代码已开源，训练使用 8 块 NVIDIA H800 GPU，超参数设置详细，具备较高的可复现性。然而，ScienceWorld 的绝对性能（54.6%）仍较低，暗示在高度动态的科学实验环境中，单一文本文档可能难以捕捉所有细微的状态变化。

## 关联研究分析

从问题动机看，SkillRise 与 LaMer 均关注代理的自我改进，但 LaMer 聚焦于同一任务的多次尝试，其反思机制局限于实例特定经验，难以泛化到新实例。SkillRise 将优化目标从“同任务适应”转向“跨任务迁移”，通过序列构建强制策略识别不同实例间的共性规律。这一差异源于任务分布的假设：LaMer 假设任务重复出现，而 SkillRise 假设任务多样但共享底层逻辑。在 WebShop 等实体高度变化的环境中，SkillRise 的优势更为明显，因为跨任务抽象比单任务记忆更具鲁棒性。

从方法设计看，SkillRise 与 SkillRL 形成鲜明对比。SkillRL 依赖外部技能库、教师模型蒸馏及检索模块，形成多阶段管线，导致性能归因困难且运行时开销大（4.3 倍于 SkillRise）。SkillRise 采用端到端设计，将技能文档作为策略内部状态，通过解耦信用分配直接优化策展行为。这种简化不仅降低了计算成本，还消除了检索误差对执行性能的干扰。然而，SkillRise 的单一文档表示可能限制了技能库的规模扩展能力，当任务复杂度极高或技能数量庞大时，文本文档的上下文窗口限制可能成为瓶颈，而 SkillRL 的层级库结构在理论上更具扩展性，但需付出更高的工程复杂度代价。

## 总结

SkillRise 旨在解决代理在相关任务序列中经验孤立与多阶段技能管线效率低下的矛盾。其切入点在于将技能演化内化于策略网络，通过单一文本文档作为跨任务信息通道，并利用解耦信用分配将下游任务表现作为策展的监督信号，从而在端到端框架中联合优化任务求解与技能提取。实验表明，该方法在 ALFWorld 和 WebShop 上分别取得 85.9% 和 84.4% 的 Pass@1，较最强基线提升 2.3 至 7.1 个百分点，且训练时间仅为 SkillRL 的 1/4.3。然而，其单一文档表示在 ScienceWorld 等高度动态环境中性能受限，且未验证在更大规模模型上的扩展性。当任务序列长度进一步增加或技能复杂度超出文本文档容量时，该端到端架构的性能增益是否仍能维持，论文未给出回答。
