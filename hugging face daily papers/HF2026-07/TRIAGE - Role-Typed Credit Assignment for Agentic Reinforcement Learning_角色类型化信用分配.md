# HuggingFace最新推荐论文 ｜TRIAGE: Role-Typed Credit Assignment for Agentic Reinforcement Learning ｜角色类型化信用分配

研究机构：美国哈佛大学、美国约翰斯·霍普金斯大学

论文原文见 [arXiv](https://arxiv.org/abs/2606.32017)

深度分析原文见 [ArxivReview](https://www.arxivreview.com/papers/arxiv_2606.32017)

> 智能体强化学习面临的核心矛盾是：最终验证器仅给出轨迹级二元结果，无法区分轨迹内不同动作的局部贡献，导致有用探索被误罚、有害回归被误奖。现有过程奖励模型提供密集标量分数，但缺乏对动作语义角色的显式建模，无法解决“探索不等于无进展”这一结构性盲区。TRIAGE 通过结构化 LLM 裁判将环境交互片段分类为四种语义角色，并施加有界角色条件修正，在保留 GRPO 结果优势作为优化方向的前提下，精准修正了结果级信号的两个冲突单元。该方法在 ALFWorld 和 WebShop 上显著提升了成功率并缩短了轨迹长度，但其性能高度依赖裁判对“成功轨迹中回归动作”的识别精度，这一前提在复杂开放环境中是否稳健仍存疑。

## 研究背景

当智能体在部分可观测环境中执行多步任务时，其决策单元并非任意 token 跨度，而是改变外部状态或信息状态的环境交互片段（Segment），如搜索查询、点击或文件编辑。标准组相对策略优化（Group Relative Policy Optimization, GRPO）将轨迹级验证器奖励均匀广播至所有片段，这种均匀广播假设所有动作对最终结果的贡献等价，但在智能体任务中，这一假设导致两个系统性盲区：失败轨迹中的有用探索动作继承了全部负向信用，成功轨迹中的冗余或有害动作继承了正向信用。

智能体强化学习（Agentic RL）的信用分配问题比数学或代码推理更为复杂，因为动作序列中存在大量不直接改变任务状态但改变信息状态的探索行为。现有方法如状态锚定估计器（GiGPO）依赖状态复现来分配步骤级信用，但在检索增强等状态几乎不重复的任务中失效；过程奖励模型（Process Reward Models, PRM）学习密集标量分数，但无法区分“有用探索”与“无进展基础设施”，导致裁判可能惩罚正确的探索行为或奖励看似合理但实际无用的叙述。这些方法的共同局限在于，它们仅对片段进行数值评分，而未指定其语义角色，使得优化方向与局部语义诊断脱节。

TRIAGE 的切入点在于引入一个独立的语义角色轴，与结果轴正交。其核心主张是：智能体强化学习不仅需要知道轨迹是否成功，还需要知道每个片段在轨迹中扮演何种角色。通过结构化 LLM 裁判对片段进行四分类，TRIAGE 将语义诊断与优化方向解耦，使模型能够在保留验证器结果作为基础信号的同时，对特定角色施加有界修正，从而解决结果级信号在长程智能体任务中的结构性不完整。

## 核心方法

### 方法参照系

本文问题属于智能体场景下的细粒度信用分配，与通用 GRPO 流程的关键差异在于决策单元从 token 提升至环境交互片段，且信用分配需考虑片段的语义角色而非仅依赖轨迹级结果。标准 GRPO 将组内归一化优势 $A_i^{[GRPO]} = (r_i - \bar{r}) / (\sigma_r + \epsilon)$ 均匀分配至轨迹内所有 token，而本文要求片段级优势 $A_{i,k}$ 反映片段 $a_{i,k}$ 的局部角色，这需要引入结构化标签而非角色无关的标量分数。

### 角色分类与有界修正

TRIAGE 在 GRPO 优势计算后插入角色分类步骤，将每个环境交互片段 $a_{i,k}$ 映射至四种语义角色之一：决定性进展（Decisive, $D$）、有用探索（Exploration, $E$）、无进展基础设施（No-progress, $N$）或回归（Regression, $R$）。该设计动机在于解决标量过程奖励无法区分“探索”与“无进展”的失效：探索改善信息状态而非环境状态，在部分可观测任务中至关重要，但常被误判为低价值动作。角色条件过程奖励定义为：

$$
A_{i,k}^{[TRIAGE]} = A_i^{[GRPO]} + \lambda c_{\hat{\rho}_{i,k}}
$$

其中 $\hat{\rho}_{i,k}$ 为裁判分配的角色标签，$c_{\hat{\rho}}$ 为固定角色常数，$\lambda$ 控制修正强度。默认设置 $(c_D, c_E, c_N, c_R) = (1, 0.5, -0.1, -0.5)$，使得决定性进展获得单位正向修正，有用探索获得较小正向修正，无进展基础设施获得轻微负向修正，回归获得较强负向修正。该公式的物理含义是：在保留轨迹级结果方向的前提下，对特定角色施加有界局部修正，避免裁判误差导致优化方向偏离。

### 最优投影理论支撑

TRIAGE 的理论基础在于证明角色条件修正是仅基于角色标签可测的最优片段级修正。设 $A_{i,k}^{[*]}$ 为未观测的 oracle 片段优势，定义信用残差 $\delta_{i,k} = A_{i,k}^{[*]} - A_i^{[GRPO]}$，则仅基于角色 $\rho_{i,k}$ 可测的修正 $g(\rho)$ 的最小均方误差（MSE）解为条件期望：

$$
g^*(\rho) = \mathbb{E}[\delta_{i,k} | \rho_{i,k} = \rho]
$$

该命题表明，角色标签的价值恰好体现在其解释非零信用残差的程度上：当 $\mathbb{E}[\delta | \rho] \neq 0$ 时，角色条件修正严格优于均匀广播。TRIAGE 使用固定常数而非估计 $g^*$，其 MSE 变化为 $\Delta MSE = \lambda^2 \mathbb{E}[c_{\hat{\rho}}^2] - 2\lambda \text{Cov}(c_{\hat{\rho}}, \delta)$，只要角色信号与残差正对齐且 $\lambda$ 足够小，即可降低优势估计误差。这一理论连接了角色分类与低方差策略梯度，为固定常数设计提供了统计依据。

## 实验评估

实验在 ALFWorld、Search-QA 和 WebShop 三个智能体基准上进行，使用 Qwen2.5-7B-Instruct 和 Qwen3-1.7B-Instruct 作为策略模型，基线包括 GRPO、PPO、GiGPO 和共享骨干价值基线。基线覆盖审计显示，本文对比了状态锚定（GiGPO）、统计密集信号（共享骨干价值）和标量过程奖励（8B-thinking judge, no role typing）三类方法，但未对比知识库中 WebShop SOTA 的 iStar，可能遗漏了隐式步骤奖励路线的强基线。

| 模型 | 方法 | ALFWorld | Search-QA | WebShop |
| :--- | :--- | :--- | :--- | :--- |
| Qwen2.5-7B-Instruct | GRPO | 79.6±1.9 | 43.3 | 70.1±2.3 |
| Qwen2.5-7B-Instruct | TRIAGE w/ Qwen3-8B-thinking judge | 87.5±2.4 | 48.1 | 77.2±2.2 |
| Qwen3-1.7B-Instruct | GRPO | 45.2±2.5 | 39.4 | 37.5±2.8 |
| Qwen3-1.7B-Instruct | TRIAGE w/ Qwen3-8B-thinking judge | 56.4±1.2 | 42.3 | 55.9±1.5 |

TRIAGE 在两个策略模型上均优于 GRPO，最大增益为 Qwen3-1.7B 在 WebShop 上的 18.4 个百分点。消融实验显示，回归惩罚（$c_R$）是主要贡献者，将其置零导致 ALFWorld 和 WebShop 性能仅略高于原始 GRPO，而探索奖励（$c_E$）提供 0.6–1.7 个百分点的次要增益。这一结果与角色审计一致：ALFWorld 和 WebShop 的回归质量分别为 48% 和 43%，表明 TRIAGE 的主要收益来自抑制成功轨迹中的回归信用。

| 消融 | 变化 | ALFWorld | Search-QA | WebShop |
| :--- | :--- | :--- | :--- | :--- |
| Raw GRPO | 无角色裁判或过程奖励 | 79.6±1.9 | 43.3 | 70.1±2.3 |
| Scalar process reward | 8B-thinking judge, 无角色类型 | 84.8±2.8 | 45.9 | 72.1±2.8 |
| No regression penalty | 设 $c_R = 0$ | 81.4±2.6 | 46.7 | 73.1±2.3 |
| TRIAGE | 无 | 87.5±2.4 | 48.1 | 77.2±2.2 |

评估边界方面，Search-QA 仅报告单次运行结果，缺乏标准差，无法排除随机性影响；ALFWorld 和 WebShop 报告了十次独立运行的均值±标准差，但论文未提供代码或超参数细节，可复现性受限。指标完备性上，本文仅报告成功率，未报告 Pass@k 或计算效率，无法评估 TRIAGE 在探索多样性或训练成本上的表现。

## 关联研究分析

从问题动机看，TRIAGE 与 GiGPO 的核心差异在于信用分配的信号来源：GiGPO 从复现状态中结构化地推导微优势，而 TRIAGE 从语义角色标签中推导修正。这一差异源于任务特性：GiGPO 依赖状态复现，在 ALFWorld 等状态可复现的环境中有效，但在 Search-QA 等状态几乎不重复的任务中退化为轨迹级 GRPO；TRIAGE 无需状态匹配，通过语义角色直接识别冲突单元，因此在 Search-QA 上保持优势。然而，TRIAGE 依赖 LLM 裁判的语义理解能力，其性能上限受限于裁判对“成功轨迹中回归动作”的识别精度，这一前提在状态高度动态或语义模糊的环境中是否成立，论文未给出回答。

从方法设计看，TRIAGE 与共享骨干价值基线的差异在于信号性质：价值基线从结果回归中统计性地推导密集信号，而 TRIAGE 从角色标签中语义性地推导修正。这一差异揭示了密集信号与语义角色的互补性：价值基线无法区分“回归”与“低进展”，因为两者在结果回归中可能具有相似的价值估计；TRIAGE 通过显式角色分类解决了这一混淆。然而，TRIAGE 的固定角色常数 $(c_D, c_E, c_N, c_R)$ 是跨任务通用的，未针对特定环境调整，这暗示其可能牺牲了环境特异性以换取泛化性，但论文未量化这一取舍对性能的影响。

## 总结

TRIAGE 解决的核心矛盾是结果级奖励在智能体长程任务中的结构性不完整：均匀广播导致有用探索被误罚、有害回归被误奖。其切入点在于引入语义角色轴，通过结构化 LLM 裁判对片段进行四分类，并施加有界角色条件修正，从而在保留 GRPO 结果优势作为优化方向的前提下，精准修正了结果级信号的两个冲突单元。实验证明，TRIAGE 在 ALFWorld 和 WebShop 上将成功率提升 7.9–18.4 个百分点，并缩短完成轨迹长度 10.4%–14.8%。其边界在于性能高度依赖裁判对“成功轨迹中回归动作”的识别精度，而这一前提在状态高度动态或语义模糊的环境中是否稳健，论文未给出回答。当环境状态变化率超过裁判的语义理解能力时，角色分类误差是否会抵消其性能增益，这一具体问题尚未被验证。
