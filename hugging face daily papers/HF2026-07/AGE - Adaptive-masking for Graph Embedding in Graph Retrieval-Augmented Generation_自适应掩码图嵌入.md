> 导读 图检索增强生成（GraphRAG）旨在利用图结构知识缓解大语言模型（LLM）的幻觉，但现有方法在冻结LLM场景下常因图嵌入与文本嵌入空间错位而失效。本文切入点在于指出随机掩码自监督学习无法有效区分图中的关键节点与辅助节点，导致结构信息编码低效。AGE通过引入强化学习驱动的节点采样器与联合嵌入预测架构（JEPA），实现了对关键节点的自适应掩码与语义级预测。该方法在冻结LLM设定下显著提升了图问答性能，但其对大规模LLM的扩展性及动态图场景的适应性仍存疑。

## 研究背景

当LLM处理知识密集型任务时，参数化知识的静态性导致事实错误频发。检索增强生成（RAG）通过引入外部文档缓解此问题，但基于向量相似度的文本检索难以捕捉实体间的显式逻辑关系，导致多跳推理路径断裂。为克服这一局限，研究范式转向图结构检索，利用知识图谱（KG）的节点-边拓扑提供可验证的事实锚点与逻辑约束。然而，将图数据输入LLM面临表示失真的挑战：图结构需线性化为文本序列或嵌入向量，这一过程往往丢失节点间的复杂关系信息，尤其是当LLM参数冻结时，图嵌入空间与LLM文本编码器空间存在显著错位。

主流GraphRAG路线分为外部检索与参数内化两类。外部检索如G-Retriever通过非参数检索器获取子图并编码为软提示，虽计算成本低，但随机掩码的自监督学习难以区分对图完整性至关重要的关键节点与冗余辅助节点，导致嵌入质量受限。参数内化方法虽能深度整合结构信息，但需微调LLM，计算开销巨大且缺乏通用性。本文聚焦于冻结LLM与非参数检索的实用场景，指出当前图嵌入模块未能充分利用LLM文本编码器中基于掩码自监督学习（Mask-based SSL）的关系建模能力，提出通过自适应掩码策略优化图嵌入，以最小化对LLM的修改并提升结构感知能力。

## 核心方法

### 方法参照系

本文基于G-Retriever框架，该框架采用非参数检索器获取子图，通过图编码器生成嵌入，并作为可训练提示注入冻结LLM。标准流程中，图编码器通常采用随机掩码自监督学习训练，旨在重建被掩码节点的特征。本文的关键差异在于，随机掩码无法识别图中具有主导上下文信息的关键节点，导致SSL过程在低判别性节点上效率低下，AGE通过引入可学习采样器与JEPA架构解决此问题。

### 自适应节点采样与JEPA嵌入

AGE的核心创新在于将随机掩码替换为强化学习（RL）驱动的自适应节点采样，并采用联合嵌入预测架构（JEPA）替代生成式重建。节点采样器通过多头注意力网络估计每个节点的概率分数 $p_{NS}$，基于采样率 $\rho$ 选择关键节点集合 $I_{key}$。采样器通过REINFORCE算法优化，其策略梯度为：

$$ \nabla_\theta J(\theta) = \mathbb{E}_{a \sim \pi_\theta} [R_a \nabla_\theta \log \pi_\theta(a|v)] $$

其中 $R_a$ 为重建质量奖励。该设计动机在于，图是简洁的逻辑结构，关键节点难以从周围节点预测，随机掩码此类节点会导致SSL失效；RL采样器通过最大化重建难度，引导模型区分关键与辅助节点。随后，概念编码器-解码器对关键节点特征进行编码，并预测目标编码器生成的辅助节点嵌入 $h_{target}$，而非像素或token级细节。JEPA机制消除了不必要的细节重建，迫使模型在语义层面捕捉节点间关系，从而更好地对齐LLM的文本嵌入空间。

### 多目标优化策略

AGE采用三阶段损失函数优化不同模块，避免参数冲突。提示调优损失 $L_{PT}$ 优化目标编码器与投影器，使其嵌入直接服务于下游任务；目标损失 $L_{target}$ 优化图编码器与概念编码器-解码器，最小化 $h_{out}$ 与 $h_{target}$ 的距离，实现知识蒸馏；采样损失 $L_{NS}$ 仅优化节点采样器，通过RL信号调整掩码策略。总损失为 $L_{PT} + L_{target} + L_{NS}$。这种解耦设计确保了各模块独立优化，无需权重调整，同时保证了推理阶段使用概念编码器-解码器输出 $h_{out}$ 而非训练阶段的目标编码器输出，实现了训练与推理的一致性。

## 实验评估

实验在ExplaGraphs、SceneGraphs、WebQSP和CWQ四个基准上进行，使用Llama 3.2 (1B/3B)、Llama 2 (7B/13B)和Llama 3.1 (8B)作为冻结LLM。基线覆盖G-Retriever、AMAR、ToG、ReKnoS等，但缺失TopoRAG、Youtu-GraphRAG等2026年SOTA方法，限制了与最新方法的直接对比。

| 方法 | LLM | ExplaGraphs | SceneGraphs | WebQSP | CWQ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| G-Retriever | Llama3.2-1B | 0.5595 | 0.7540 | 60.1 | - |
| AGE G-Retriever | Llama3.2-1B | 0.8267 | 0.8184 | 62.5 | - |
| G-Retriever | Llama3.2-3B | 0.7761 | 0.8229 | 71.3 | - |
| AGE G-Retriever | Llama3.2-3B | 0.9260 | 0.8930 | 73.5 | - |
| AGE AMAR | Llama2-13B | - | 85.1 | 86.2 | 85.1 |

AGE在冻结LLM设定下一致优于G-Retriever，Llama3.2-1B在ExplaGraphs上提升26.72个百分点，但在WebQSP上提升仅2.02点，表明大图谱中非参数检索的局限性。AGE AMAR在CWQ上超越ReKnoS，但在WebQSP上低于Paths-over-Graph，显示其在更大规模数据集上的优势。

| 架构 | 掩码策略 | ExplaGraphs Acc | 提升幅度 |
| :--- | :--- | :--- | :--- |
| GA | Random mask | 0.6532 | 9.37% |
| JEPA | Random mask | 0.7141 | 15.46% |
| GA | Node sampler | 0.7870 | 22.75% |
| JEPA | Node sampler | 0.8267 | 26.72% |

消融实验显示，JEPA优于生成式架构（GA），RL采样器带来显著增益，两者结合效果最佳。采样率 $\rho=0.3$ 在ExplaGraphs上表现最优，但在WebQSP上 $\rho=0.35$ 略优，表明最优采样率依赖图谱规模。

评估指标以Accuracy和Hit@1为主，缺乏对中间推理步骤的细粒度评估。论文未提供代码URL，超参数如采样率 $\rho$ 需根据数据集调整，可复现性受限于未公开的RL训练细节。

## 关联研究分析

从问题动机看，AGE与G-Retriever同属非参数检索路线，但G-Retriever依赖随机掩码SSL，AGE引入RL采样器解决关键节点识别问题。差异根源在于图结构的稀疏性与关键节点的主导性，随机掩码无法自适应调整，而RL采样器通过重建难度反馈优化掩码策略。这与Think-on-Graph等动态探索方法形成对比，后者通过智能体迭代探索解决路径断裂，AGE则通过静态嵌入优化解决表示失真，两者分别针对检索质量与表示质量，未直接竞争但互补。

从方法设计看，AGE采用JEPA替代生成式SSL，与GraphCL等对比学习方法不同，JEPA消除细节重建，聚焦语义级表示。这一选择源于LLM文本编码器的掩码SSL特性，AGE通过模仿该过程实现空间对齐。与AMAR等两阶段训练方法相比，AGE采用单阶段SSL与提示调优集成，降低了训练复杂度，但可能牺牲了跨问题对齐的精细度。AGE在冻结LLM设定下有效，但未探索动态图或大规模LLM场景，其RL采样器在稀疏图上的优势是否在稠密图中保持，论文未给出回答。

## 总结

AGE旨在解决冻结LLM场景下图嵌入与文本嵌入空间错位导致的结构信息丢失问题。现有随机掩码SSL无法区分关键节点与辅助节点，AGE通过RL驱动的自适应采样与JEPA架构，实现了语义级关系编码。实验表明，AGE在ExplaGraphs上提升26.72个百分点，在CWQ上超越ReKnoS，验证了自适应掩码的有效性。然而，AGE在WebQSP大图谱上增益有限，且未探索大规模LLM与动态图场景，其RL采样器在稠密图或实时变化图谱中的鲁棒性尚未验证。当图谱规模扩大至亿级实体时，RL采样器的计算开销与收敛稳定性是否成为瓶颈，论文未给出回答。
