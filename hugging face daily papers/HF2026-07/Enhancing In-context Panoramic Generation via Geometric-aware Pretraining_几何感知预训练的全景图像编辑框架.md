> 全景图像编辑长期受困于等距圆柱投影（Equirectangular Projection, ERP）固有的极点拉伸与边界不连续，导致生成内容在三维空间结构上失真。现有方法多依赖立方体贴图转换或球面位置编码，但难以在保持高分辨率的同时维持底层几何一致性。Canvas360 提出通过并行生成 RGB 与深度图进行几何感知预训练，再统一微调以支持多种编辑任务。该框架在边界连续性与全景保真度上表现优异，但其几何先验能否有效迁移至动态视频场景仍存疑。

## 研究背景

全景图像在虚拟现实与沉浸式交互中要求严格的三维空间一致性，但主流的 ERP 表示将球面映射为平面时，高纬度区域像素密度急剧增加，造成严重的几何畸变。这种非均匀采样使得标准二维卷积网络难以区分真实的场景结构与投影伪影，导致编辑操作（如物体移除或风格迁移）破坏场景的三维连贯性。为解决此问题，Flow Matching (FM) 作为一种连续时间生成范式，通过学习速度场将噪声传输至数据分布，为高分辨率全景合成提供了稳定框架。然而，FM 模型本身缺乏对球面拓扑的显式感知，若直接应用于 ERP 图像，极易在水平边界处产生接缝伪影，且在极点区域丢失细节。

全景图像编辑领域的主流路线分为两类：一是采用立方体贴图表示以消除投影失真，如 CubeComposer，但面间连续性处理复杂且数据生态不如 ERP 成熟；二是直接在 ERP 上引入球面感知模块，如 DiT360 使用 Cube Loss，但立方体到全景的转换在潜在空间中是有损的，导致残留伪影。这些方法往往针对单一任务训练，缺乏统一的几何先验。Canvas360 的切入点在于，将深度图作为显式几何先验，通过并行生成 RGB 与深度图来迫使模型学习球面几何结构，而非仅依赖像素级拟合。这种策略旨在通过预训练阶段注入几何理解，使模型在下游编辑任务中自然保持三维一致性，从而克服现有方法在几何保真度与任务通用性之间的权衡。

## 核心方法

### 方法参照系

本文问题可置于“基于扩散/流匹配模型的图像编辑”通用框架下，但关键差异在于输入输出的几何约束。标准图像编辑假设平面欧几里得几何，而全景编辑需满足水平循环一致性 $v(0, y) = v(W, y)$ 及球面径向深度关系。Canvas360 基于 FLUX.1-dev 骨干，通过两阶段训练解决这一几何适配问题。

### 并行深度生成与模态解耦

传统方法将深度作为条件输入，但全景深度对应相机中心的径向距离，与透视图像的 Z 轴深度定义不同。Canvas360 在预训练阶段同时生成 RGB 与深度图，通过 Token 级拼接融合两种模态。设 RGB 与深度的潜在 Token 序列分别为 $x_{rgb}$ 和 $x_{depth}$，拼接后输入 Flow Transformer。为区分模态，引入 3D RoPE 位置编码偏移：

$$ u_0 = (0, H, W), \quad u_1 = (T_d, H, W) $$

其中 $T_d$ 为深度 Token 的时间维偏移。该设计避免了通道级设计的复杂性，使模型能复用预训练视觉先验。同时，为防止 RGB 与深度预测过度耦合导致退化，引入相似度损失：

$$ L_{sim} = \mathbb{E} \left[ \left( \frac{\langle v_{rgb}, v_{depth} \rangle}{\|v_{rgb}\|_2 \|v_{depth}\|_2} \right)^2 \right] $$

此损失惩罚两模态速度场的相关性，确保深度分支独立学习几何结构，而非简单复制 RGB 纹理。

### 速度循环填充与边界一致性

标准循环填充仅复制边界列，未显式告知模型边界 Token 在球面上的邻接关系。Canvas360 提出速度循环填充（Velocity Circular Padding），在经度索引 0 和 $W+1$ 处添加“幽灵列”，并同步其特征与目标速度：

$$ \tilde{x}_t^0 = x_t^W, \quad \tilde{x}_t^{W+1} = x_t^1 $$

在计算 Flow Matching 损失时，对填充后的速度场进行监督。这使得模型在预测速度时能感知 $0 \equiv W$ 的球面等价性，显式建模水平循环一致性，从而消除接缝伪影。

## 实验评估

实验在 Matterport3D 数据集上进行，对比基线包括 Matrix-3D、HunyuanWorld 和 DiT360。基线覆盖了多视图拼接与球面感知路线，但缺乏针对几何感知预训练的对比。用户研究结果显示，Canvas360 在边界连续性（BC）、全景感知（PA）和整体质量（OQ）上均取得最高偏好率，分别为 31.1%、34.1% 和 35.9%，显著优于 DiT360 的 28.0%、28.6% 和 30.7%。

| 方法 | TA ↑ | BC ↑ | PA ↑ | OQ ↑ |
| :--- | :--- | :--- | :--- | :--- |
| Matrix-3D | 23.0% | 20.0% | 16.8% | 15.3% |
| HunyuanWorld | 26.9% | 20.9% | 20.5% | 18.1% |
| DiT360 | 23.9% | 28.0% | 28.6% | 30.7% |
| Canvas360 | 26.2% | 31.1% | 34.1% | 35.9% |

消融实验验证了并行深度生成组件的有效性。在 FLUX.1-dev 基线上，仅添加深度图像导致 BRISQUE 从 14.62 升至 17.84，表明 RGB-深度联合生成不稳定。引入位置偏移后 BRISQUE 进一步恶化至 23.64，但加入相似度损失后回落至 16.23，FID 从 51.16 降至 51.48，FAED 从 5.37 降至 4.93。这表明位置偏移与相似度损失共同作用，稳定了训练过程并提升了全景保真度。

| 方法 | FID ↓ | FAED ↓ | BRISQUE ↓ | NIQE ↓ |
| :--- | :--- | :--- | :--- | :--- |
| baseline | 51.16 | 5.37 | 14.62 | 3.86 |
| + depth img | 51.57 | 4.74 | 17.84 | 3.85 |
| + pos offset | 57.04 | 4.81 | 23.64 | 4.12 |
| + Lsim | 51.48 | 4.93 | 16.23 | 3.84 |

评估边界方面，FAED 指标虽能捕捉全景特异性失真，但难以量化极点处的细微几何畸变。论文未报告计算效率指标，且深度图依赖 DAP 模型预测，其误差可能传播至生成结果。代码与超参数已公开，但 1M 规模数据集的合成管线依赖 FLUX.2-dev 等外部模型，复现成本较高。

## 关联研究分析

从问题动机看，Canvas360 与 DiT360 均旨在解决 ERP 投影失真，但路径截然不同。DiT360 通过 Cube Loss 在立方体空间约束生成，再转换回全景，这一转换在潜在空间是有损的，导致细节丢失。Canvas360 则直接在 ERP 空间通过并行深度生成注入几何先验，避免了表示转换的损失。这种差异源于对“几何一致性”定义的不同：DiT360 侧重像素级立方体一致性，而 Canvas360 侧重三维空间结构一致性。深度图作为径向距离的直接表示，比立方体面更自然地对应球面几何，这可能是 Canvas360 在边界连续性上优于 DiT360 的根本原因。

从方法设计看，Canvas360 与 SE360 在编辑数据合成上存在关联，但目标不同。SE360 聚焦于单一编辑任务，依赖 Grounding 模型定位物体；Canvas360 则构建统一框架，通过 Token 拼接支持风格迁移、修复、外扩和编辑四种任务。这种统一性得益于预训练阶段建立的强全景先验，使模型能泛化至未见过的编辑指令。然而，Canvas360 未探索深度先验在动态场景中的适用性，而 SE360 等静态方法也未涉及视频域。当编辑任务涉及时间维度时，静态深度先验是否足以维持时空一致性，论文未给出回答。

## 总结

Canvas360 解决了全景图像编辑中 ERP 投影失真与几何一致性缺失的核心矛盾。现有方法或因表示转换有损，或因缺乏显式几何先验，难以在高分辨率下保持三维结构。本文通过并行 RGB-深度生成与速度循环填充，在预训练阶段注入球面几何理解，使模型在统一微调中自然保持边界连续性与空间一致性。实验显示，Canvas360 在用户研究中以 35.9% 的整体质量偏好率领先，FAED 指标降至 4.93，验证了几何感知预训练的有效性。然而，其深度先验依赖单帧静态场景，未涉及动态视频中的时间漂移问题。当编辑任务扩展至长时程全景视频时，静态径向深度先验能否有效约束物体运动轨迹与背景几何的耦合，仍是待验证的关键问题。
