# A Survey of LLMs in Financial Analysis and Trading ｜大语言模型金融分析与交易方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/LLMs%20in%20Financial%20Analysis%20and%20Trading)

## 导读

大语言模型（Large Language Models, LLMs）在金融领域的应用正经历从静态文本挖掘向动态自主决策的结构性转变，其核心驱动力在于解决传统量化模型无法处理非结构化信息且缺乏可解释性的固有缺陷。早期研究聚焦于利用 LLM 提取新闻情感信号，但回测中普遍存在的前视偏差（Look-ahead Bias）与记忆污染问题，暴露了概率生成机制与金融审计确定性要求之间的根本冲突。这一信任危机迫使研究重心从追求高收益转向构建可信、无偏且风险可控的交易智能体系统，引入了神经符号推理、强化学习对齐及严格基准测试等新范式。各技术路线在推理灵活性、数值精确性与计算效率之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从信号提取到可信决策的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

金融交易领域长期依赖基于统计的量化模型和深度强化学习代理，但传统方法难以处理非结构化文本信息且缺乏可解释性。2020 至 2026 年间，随着 LLM 在自然语言处理上的突破，领域迎来范式转变，核心问题从“如何从文本中提取信号”演变为“如何在非平稳市场中构建可信的自主决策系统”。这一转变并非简单的技术升级，而是由回测幻觉引发的信任危机所驱动的结构性重构，旨在解决 LLM 概率生成机制与金融高风险约束之间的张力。

问题的形式化定义经历了从单步预测到序贯决策的扩展。早期任务可定义为给定历史文本 $X_t$ 和价格 $P_t$，预测下一时刻情感 $S_{t+1}$ 或价格方向 $D_{t+1}$。随着智能体架构的引入，问题扩展为在状态空间 $\mathcal{S}$ 中，智能体 $\pi$ 基于观测 $o_t$ 生成动作 $a_t$，以最大化风险调整后的累计收益 $\sum_{t=0}^{T} \gamma^t r(s_t, a_t)$，其中 $r$ 包含收益与回撤惩罚项。这一形式化要求模型不仅具备语义理解能力，还需内化对非平稳性和风险偏好的理解。

子问题之间存在强依赖关系，构成了领域的认知边界。数值推理准确性是可信交易决策的前提，若无法解决幻觉和计算错误，交易执行将导致灾难性损失；记忆污染检测是有效基准评估的前提，若回测数据被污染，所有性能指标均无效；模型效率优化则是实时部署的前提，决定了智能体能否在高频或实时场景下落地。这种依赖结构意味着，任何单一子问题的突破若未解决上游依赖，其实际价值将大打折扣。

2023 至 2024 年是领域的奠基期，研究重心从文本理解转向自主决策。FinGPT 等基础模型的出现，使得利用 LLM 进行金融情感分析和新闻驱动的信号提取成为可能，但这一阶段的方法主要假设 LLM 能直接映射文本情感至价格变动，忽视了市场非平稳性和数据泄露风险。FinMem 和 FinCon 等早期智能体系统引入了记忆机制和多智能体协作，试图模拟人类投资团队，但回测中表现优异而实时失效的现象，暴露了前视偏差和记忆污染问题。

2025 年是信任危机与重构的关键转折年。Profit Mirage 等研究揭示了 LLM 在回测中利用训练数据记忆“作弊”的问题，直接催生了去偏技术和严格基准测试的需求。StockBench 等基准的建立，终结了“自说自话”的回测时代，确立了滚动窗口回测的新标准。Trading-R1 等框架引入强化学习，通过奖励机制对齐交易行为与预期结果，标志着从静态预测到动态决策的技术路径确立。

2026 年至今，领域进入精细化与合规期。研究焦点从盈利能力转向可解释性与合规性，FinRS 引入风险敏感机制，VERAFI 引入神经符号验证，FinMCP-Bench 评估工具调用能力。这一阶段的方法不再单纯追求 Alpha 收益，而是强调在波动市场中的稳定性、决策的可审计性以及监管合规性。当前形态呈现出“可信与鲁棒”的特征，核心矛盾在于如何在保持 LLM 推理能力的同时，通过神经符号验证、严格基准测试和去偏技术，解决数值幻觉、记忆污染和非平稳适应性问题。

**如果用一个核心问题概括该领域，那便是：如何在金融市场的非平稳性、高风险约束及严格合规要求下，构建具备数值精确性、无记忆污染且可解释的 LLM 自主决策系统。**

## 2. 方法体系

- 2023：FinGPT——基于 LoRA 微调的开源金融大语言模型，奠定领域方法基线

- 2023：FinMem——引入分层记忆机制的交易智能体，增强市场模式识别

- 2024：FinCon——采用多智能体经理-分析师层级结构，强化投资信念更新

- 2025：Trading-R1——结合强化学习的 LLM 推理交易框架，对齐交易行为

- 2025：StockBench——评估 LLM 智能体真实市场盈利能力的基准，避免数据泄露

- 2026：FinRS——风险敏感交易框架，结合分层分析与多时间尺度奖励

- 2026：VERAFI——通过神经符号策略生成实现验证性智能金融智能

- 2026：TradingMoE——在演化市场中路由正确专家的混合专家系统

这条时间线勾勒了该领域方法演进的代表性节点：从 2023 年的 FinGPT 奠定该领域方法基线，经 2024 年 FinCon 的推进，到 2026 年的 VERAFI 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 交易智能体系统

交易智能体系统的演进始于对单智能体局限性的反思。FinMem（Liu and Dang, 2025, P11）通过引入分层记忆机制，解决了早期模型在长序列交易中遗忘历史模式的问题，但其单智能体架构在处理宏观分析与微观执行冲突时仍显不足。FinCon（Liu and Dang, 2025, P15）针对这一短板，采用多智能体经理-分析师层级结构，通过概念化语言强化更新自由形式投资信念，以系统复杂度换取决策鲁棒性。然而，FinCon 的静态提示机制难以适应非平稳市场，ATLAS（Papadakis et al., 2025, P10）随后引入 Adaptive-OPRO 动态提示编辑器，使中央交易智能体能够基于实时市场反馈持续优化提示，进一步提升了适应性。

随着对风险建模需求的增加，FinRS（Liu and Dang, 2025, P15）将风险管理整合到交易决策过程中，通过方向与数量解耦的双决策框架和多时间尺度奖励反思，显式建模序贯交易中的固有风险。这一设计解决了现有 LLM 交易智能体缺乏系统性风险建模的问题，但增加了决策过程的计算开销。TradingMoE（Zhou et al., 2026, P59）则从外部专家路由转向内部专家路由，通过稀疏专家选择适应非平稳市场，提供了处理市场异质性的新范式。与 FinRS 的风险敏感路线不同，TradingMoE 更侧重于模型架构层面的适应性，两者在应对市场非平稳性上形成了互补关系。

### 2.2 金融基准与评估

基准评估体系的建立是解决信任危机的关键。StockBench（Chen et al., 2025, P4）采用滚动窗口回测避免数据泄露，提供了标准化 LLM 交易能力评估工具，但其评估窗口较短，可能遗漏长期市场周期。FinMCP-Bench（Zhu et al., 2026, P43）填补了 LLM 金融工具使用评估空白，强调工具调用之间的隐式依赖，推动了智能体从静态分析到动态交互的演进。AlphaForgeBench（Zhang et al., 2026, P33）则揭示了 LLM 在序贯决策中的行为不稳定性，关注运行间方差和不一致行动序列，为构建稳定交易策略提供了实证依据。

FIRE（Zhang et al., 2026, P34）采用结构化评分框架解决开放式任务评估不稳定性，通过问题特定评分标准生成和专家推理逻辑提取，提高了评估稳定性和可解释性。FinMMDocR（Tang et al., 2025, P24）聚焦多模态推理，揭示了多模态模型在复杂任务中的准确性下降和文档理解失败模式。BizFinBench.v2（Guo et al., 2026, P27）引入在线任务评估实时金融能力，并采用双语设计覆盖更多语言场景。这些基准共同构成了从静态文本分析到动态实时交互的完整评估谱系，为方法比较提供了可靠参照。

### 2.3 量化因子挖掘

量化因子挖掘路线从资产中心转向逻辑导向。MEME（Guo et al., 2026, P32）将市场视为投资叙事演化生态系统，通过聚类投资叙事识别潜在推理模式，提升了因子挖掘的可解释性。Stock-R1（Chen et al., 2026, P50）引入可验证预测行动，通过一致性基础强化学习优化金融 LLM，确保推理过程基于数值证据而非纯文本生成。BlindTrade（Jeon and Lee, 2026, P41）通过匿名化优先投资组合优化框架，消除记忆偏差和幸存者偏差，确保回测结果反映真实市场理解。

PandaAI（Li et al., 2026, P53）提出神经符号数据分析与集成决策框架，通过 LLM 引导的 MCTS 探索 Alpha 空间，显式建模市场动态和制度转换。与 MEME 的叙事导向不同，PandaAI 更侧重于神经符号方法的精确性，两者在因子挖掘的可解释性与精确性之间形成了互补。Financial Numerical Prediction and Allocation as Token Generation（Ouyang and Lee, 2026, P57）将金融数值预测与配置作为令牌生成的统一框架，简化了多任务学习架构，为因子挖掘提供了统一技术范式。

### 2.4 金融 NLP 基础任务

金融 NLP 基础任务聚焦于提升 LLM 在金融文本处理中的准确性与效率。RA-FinBERT（Zhang and Li, 2026, P56）在 FinBERT 基础上引入规则感知机制，通过 LoRA 适配低资源场景，并融合辅助数值输入提升鲁棒性。Instruction Finetuning LLaMA-3-8B Model Using LoRA for Financial NER（Lian, 2026, P28）将金融 NER 任务转换为指令-输入-输出三元组，利用 LoRA 低秩矩阵进行高效微调。Instruction Finetuning DeepSeek-R1-8B Model Using LoRA and NEFTune（Wu and Luo, 2026, P54）进一步引入 NEFTune 噪声嵌入微调，缓解过拟合问题。

Fine-tuning of lightweight large language models for sentiment classification on heterogeneous financial textual data（Paredes Amorin et al., 2025, P18）系统评估了不同模型在异构金融文本数据上的适应性和效率，提供了轻量级金融情感分类模型选择指南。Comparing LLMs for Sentiment Analysis in Financial Market News（Teles and Figueiredo, 2025, P9）使用多个异构数据集，全面评估模型在不同新闻类型上的表现。这些工作为资源受限场景提供了有效方案，但其在复杂多步推理任务上的表现仍不及专用智能体系统。

### 2.5 RAG 与知识增强

RAG 技术是缓解 LLM 金融幻觉的关键手段。VERAFI（Akinfaderin and Subramanian, 2025, P20）通过神经符号策略生成实现验证性智能金融智能，结合 SMT 求解器确保数学精确性。MimirRAG（Samuelsen et al., 2026, P52）提出多智能体 RAG 框架，通过元数据集成实现金融数据检索与幻觉抑制。Mitigating Hallucination in Financial RAG via Fine-Grained Knowledge Verification（Yin et al., 2026, P29）将响应分解为原子知识单元，并验证其与检索文档的一致性，提供了稳定优化指导。

VeritasFi（Tai et al., 2025, P7）提出可适应多层 RAG 框架，支持多模态金融问答，通过多层检索和语义增强处理复杂企业披露文件。Neuro-Symbolic Financial Reasoning via Deterministic Fact Ledgers and Adversarial Low-Latency Hallucination Detector（Agand, 2026, P36）引入确定性事实账本和对抗幻觉检测器，解决随机不准确性问题。Integrating Domain Knowledge for Financial QA: A Multi-Retriever RAG Approach with LLMs（Zhang et al., 2025, P23）利用外部金融词典作为非参数记忆，缓解模型领域知识缺乏问题。这些方法在检索质量和上下文整合上取得了显著进展，但计算开销和延迟仍是主要瓶颈。

### 2.6 安全合规与鲁棒性

安全合规与鲁棒性研究聚焦于解决 LLM 在金融场景下的幻觉、记忆偏差及风险敏感性问题。Profit Mirage（Li et al., 2025, P6）揭示 LLM 金融智能体信息泄露问题，提出反事实演化框架缓解前瞻偏差。FinCAD（Li et al., 2026, P51）通过上下文感知解码消除记忆污染，动态调整解码强度以消除记忆污染。MemGuard-Alpha（Roy and Roy, 2026, P44）通过成员推断与跨模型分歧检测记忆污染信号，提升 LLM 金融预测可靠性。

FFinRED（Kim et al., 2026, P55）提出专家引导的金融 LLM 红队测试基准生成与评估框架，部署于 FSI 监管沙盒。Uncovering the Vulnerability of Large Language Models in the Financial Domain via Risk Concealment（Cheng et al., 2025, P1）揭示多轮风险隐藏对 LLM 安全防御的破坏性。Risk-Adjusted Harm Scoring for Automated Red Teaming for LLMs in Financial Services（Dimino et al., 2026, P39）引入风险调整评分，考虑金融场景特定风险权重。Neuro-Symbolic Compliance: Integrating LLMs and SMT Solvers for Automated Financial Legal Analysis（Hsia et al., 2026, P26）整合 LLM 和 SMT 求解器实现自动金融法律分析，确保法律推理的精确性和可验证性。

### 2.7 模型适配与优化

模型适配与优化路线旨在平衡计算成本与领域性能。SPEAR-MM（Kapusuzoglu et al., 2025, P14）提出选择性参数评估与恢复的模型合并框架，解决金融 LLM 持续预训练中的灾难性遗忘。ASDA（Yim et al., 2026, P40）提出自动化技能蒸馏与适应框架，通过教师-学生架构建立金融推理技能库。Unlocking Data Value in Finance: A Study on Distillation and Difficulty-Aware Training（Cao et al., 2026, P37）通过语义去重、推理合成和长度自适应验证构建高质量金融数据集。

Two Heads are Better than One（Fu et al., 2025, P13）将大语言模型特征蒸馏到小模型，采用特征分解与混合技术，解决 LLM 推理速度无法满足实时交易需求的问题。Is GPT-OSS All You Need? Benchmarking Large Language Models for Financial Intelligence and the Surprising Efficiency Paradox（Bi et al., 2025, P19）揭示小模型在金融任务上具有可比性能且效率更优的悖论。FiMI（Kathar et al., 2026, P30）提出印度金融生态系统领域特定语言模型，通过多阶段训练管道适配 UPI 支付系统。Uni-FinLLM（Zhang et al., 2026, P25）构建统一多模态大语言模型，通过模块化任务头支持微观股票预测和宏观系统性风险评估。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域内已形成若干核心共识，其中最为关键的是 LLM 在纯文本情感分析和信息提取任务上表现优于传统 NLP 模型，但在涉及复杂数值推理和长期预测的任务上仍不稳定。这一共识在多个基准上得到验证：RA-FinBERT 在情感分类上达到 69.89% Acc，优于 FinBERT 的 63.44%，但在 Financial QA 数值推理任务上，VERAFI 的 94.70% Factual Correctness 与 FinAgent-RAG 的 76.81% Exe Acc 存在显著差异，反映出数值推理的不稳定性（支撑证据：P56, P20, P46）。与此相关的另一个共识是多智能体协作架构比单智能体架构能更有效地处理异构金融信息并提升决策鲁棒性。QuantAgents 在 NASDAQ-100 长期回测中取得 58.68% ARR，显著优于单智能体 FinGPT 的 36.71% ARR，表明多智能体协作在长期市场适应中的优势（支撑证据：P49, P2）。

此外，直接应用通用 LLM 进行金融交易存在严重的记忆偏差和前视偏差风险，必须通过严格的数据隔离和去偏技术进行验证。Profit Mirage 揭示的信息泄露问题，以及 FinCAD 和 MemGuard-Alpha 提出的去偏技术，均基于这一共识展开（支撑证据：P6, P51, P44）。RAG 技术是缓解 LLM 金融幻觉、提升事实准确性的关键手段，但检索质量和上下文整合仍是瓶颈，VERAFI 和 MimirRAG 的研究均聚焦于此（支撑证据：P20, P52）。金融领域需要专门的基准测试来评估 LLM 的推理、合规和交易能力，通用基准无法反映金融高风险特性，StockBench 和 FinMCP-Bench 的建立正是基于这一需求（支撑证据：P4, P43）。

### 3.2 观点分歧

领域内存在若干深层分歧，其中最为根本的是神经符号方法 vs 纯神经网络方法在金融推理中的优越性。神经符号派认为，SMT 求解器和确定性事实账本能确保数值精确性和合规性，优于纯神经网络的概率生成，VERAFI 的 94.70% Factual Correctness 支持这一观点。纯神经网络派则认为，通过强化学习和可验证预测行动，纯神经网络也能在动态环境中实现高精度推理，且更具泛化性，Trading-R1 的 7.42% CR 优于 GPT-4.1 的 3.15% CR 支持这一观点。现有证据偏向神经符号在合规和静态数值推理场景，但在动态交易和非平稳市场场景，纯神经网络结合 RL 的表现更具竞争力。分歧根源在于缺乏同时评估“数值精确性”、“动态适应性”和“合规性”的综合基准，神经符号方法在动态环境中的延迟和约束生成难度未被充分量化（支撑证据：P20, P2, P36）。

这一分歧的背后，是另一个更根本的争论：小模型蒸馏 vs 大模型直接部署在实时交易中的可行性。小模型蒸馏派认为，通过特征分解和蒸馏，小模型可在特定金融任务上达到大模型性能，且更适合实时部署，Two Heads are Better than One 和 ASDA 的研究支持这一观点。大模型直接部署派则认为，大模型在复杂多步推理和长上下文处理上具有不可替代的优势，小模型在复杂场景下不稳定，TradingMoE 和 FinRS 的研究支持这一观点。现有证据偏向小模型在单一任务（如情感分析、NER）上效率占优，但在复杂交易决策和多智能体协作场景，大模型表现更稳定。分歧根源在于缺乏在“高延迟容忍度”与“高推理复杂度”之间的平衡点研究，小模型在动态市场中的长期稳定性数据不足（支撑证据：P13, P40, P59, P15）。

### 3.3 其他开放问题

当前领域面临的最紧迫工程问题是模型部署效率与实时响应速度。大模型推理速度慢、成本高，无法满足高频或实时交易需求，需通过高效适配实现落地。LoRA、NEFTune 和蒸馏技术提供了明确技术路径，但小模型在复杂多步推理上的能力差距仍是关键困难。研究路径包括特征分解蒸馏、基于数据质量而非规模的训练策略优化，以及小模型在动态市场中的长期稳定性验证。

最根本的研究问题是 LLM 对非平稳市场的内生理解机制。现有模型多依赖外部记忆或强化学习奖励，缺乏对市场非平稳性的内生建模，导致在波动市场中表现不稳定。关键困难在于如何量化市场非平稳性，并将其融入模型架构或训练过程。研究路径包括混合专家路由（如 TradingMoE）、风险敏感奖励机制（如 FinRS），以及基于反事实推理的无偏评估框架。

此外，多智能体协作机制缺乏标准化，不同智能体间的通信和决策融合方式各异，导致系统可解释性和可复现性差。关键困难在于缺乏统一的智能体交互协议，多智能体的通信开销和信息传递损失未被充分量化。研究路径包括定义标准化的角色分工和反馈回路，以及多智能体协作的通信效率优化。

归纳“已知—争议—未知”认知图谱：已知 LLM 在文本处理和多智能体协作上具备优势，争议在于神经符号与纯神经网络的优越性及小模型与大模型的部署可行性，未知在于非平稳市场内生理解机制和多智能体标准化协议。发展趋势将聚焦于可信 AI 与高效部署的平衡，通过神经符号验证、严格基准测试和去偏技术，构建可审计的实时交易部署系统。

## 4. 总结与展望

LLM 金融应用已从“信号提取”进入“可信决策”阶段，核心矛盾在于如何在金融市场的非平稳性、高风险约束及严格合规要求下，构建具备数值精确性、无记忆污染且可解释的 LLM 自主决策系统。早期研究通过 LoRA 微调和记忆增强奠定基线，但回测幻觉引发的信任危机迫使研究重心转向解决前视偏差和数值幻觉。多智能体协作、神经符号推理、强化学习对齐及严格基准测试等路线，分别从决策鲁棒性、数值精确性、行为对齐和评估可信度角度应对这一挑战，但核心瓶颈仍在于非平稳市场内生理解机制的缺失和多智能体标准化协议的缺乏。

未来可能突破的方向包括：神经符号与强化学习的深度融合，以解决动态环境下的精确决策问题，VERAFI 和 Trading-R1 的研究共同指向这一方向；基于反事实推理的无偏评估框架，以彻底消除记忆污染，Profit Mirage 和 FinCAD 的研究为此提供了基础；小模型在动态市场中的长期稳定性验证，以平衡效率与能力，Two Heads are Better than One 和 TradingMoE 的研究为此提供了路径。对于进入者，最值得做的一件事是构建同时评估“数值精确性”、“动态适应性”和“合规性”的综合基准，以解决当前分歧根源，推动领域从经验驱动向证据驱动转变。
