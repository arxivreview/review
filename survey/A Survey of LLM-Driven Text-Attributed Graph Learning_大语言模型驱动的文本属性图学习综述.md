## 导读

文本属性图（Text-Attributed Graphs, TAGs）将结构化拓扑与非结构化文本绑定，其核心价值在于弥合图神经网络（GNN）的局部归纳偏置与大语言模型（LLMs）的深层语义推理之间的鸿沟。早期研究依赖浅层文本编码器与 GNN 的简单拼接，思路直观却受制于跨模态语义理解的浅层化，难以捕捉节点间的深层关联。当 LLMs 引入后，核心矛盾迅速转变为 LLM 缺乏原生图结构感知能力，研究者通过序列化或投影机制强行注入拓扑信息，以计算开销换取语义深度。随着零样本泛化与对抗鲁棒性需求的凸显，领域重心从基础性能提升转向低成本、高鲁棒性的原生融合与高效推理。各路线在结构保真度、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从外挂增强到原生统一的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

文本属性图（TAGs）作为一种融合结构化关系与非结构化文本的数据范式，广泛应用于引文网络、社交推荐及生物医学领域。其核心挑战在于如何同时利用图的拓扑结构与节点文本的语义信息。早期研究主要依赖图神经网络（GNN）处理拓扑结构，但受限于对文本语义理解的浅层化，难以捕捉节点间的深层语义关联。随着大语言模型（LLMs）在自然语言处理中的突破，领域研究迎来关键转折：从单纯的“GNN+文本编码器”转向“LLM-GNN深度融合”。这一转变并非简单的技术叠加，而是问题定义的根本重构：从“如何更好地编码文本”转变为“如何让 LLM 理解图结构”。

问题形式化通常定义为：给定 TAG $G=(V, E, X)$，其中 $V$ 为节点集，$E$ 为边集，$X$ 为节点文本属性，目标是学习节点表示 $h_v$ 以完成分类、链接预测或生成任务。在少样本或零样本设置下，问题进一步约束为在极少标签或无标签条件下，利用 LLM 的先验知识实现跨域泛化。子问题之间存在严格的层级依赖关系：“图结构原生编码”是基础，决定了 LLM 能否理解拓扑；“图-文对齐”是中间层，解决语义鸿沟；“高效推理”与“安全鲁棒性”是应用层约束，依赖于前两者的稳定性；“零样本泛化”则是最终目标，依赖于前三个子问题的共同解决。这种依赖结构意味着，任何单一子问题的突破若缺乏其他子问题的支撑，其实际效用将大打折扣。

2016-2018 年是奠基期，GCN 和 GAT 确立了 GNN 的消息传递机制，但文本仅作为静态特征输入。2020 年前后，跨域基准的引入暴露了浅层文本编码在分布偏移下的脆弱性，促使研究者关注预训练表示。2023 年，GraphGPT 等“LLM-as-Predictor”范式兴起，试图将图结构映射至 LLM 嵌入空间，标志着 LLM 从外部工具转变为预测引擎。然而，这一路线在长程依赖和结构保真度上遭遇瓶颈，序列化过程导致的信息损失成为主要短板。

2024-2025 年，研究重心转向“LLM-as-Enhancer”及混合架构。针对 LLM 缺乏结构感知能力的问题，研究者通过对比学习、指令微调实现跨模态对齐，并引入路由器机制以平衡计算成本。2025-2026 年，领域进入精细化与鲁棒性阶段，研究焦点从基础性能提升转向零样本泛化、数据质量优化、对抗鲁棒性及高效推理。NAG 等无编码器原生架构的出现，标志着从“序列化”向“原生结构注入”的架构级转变。当前，该领域活跃度极高，核心挑战在于如何以低成本、高鲁棒性的方式，在保留 GNN 结构归纳偏置的同时，充分发挥 LLM 的语义推理能力，解决标签稀缺、数据噪声及跨域迁移难题。

**如果用一个核心问题概括该领域，那便是：如何在保留图结构归纳偏置的前提下，以计算高效且鲁棒的方式，将大语言模型的深层语义推理能力内化至非欧几里得图拓扑中，以解决标签稀缺与跨域泛化难题。**

## 2. 方法体系

- 2017：GCN——通过谱图卷积操作在局部邻域内传播节点信息，奠定了图神经网络消息传递机制的基础，成为后续所有图结构学习方法的经典基线

- 2018：GAT——引入注意力机制对邻居节点的贡献进行加权聚合，实现了邻域重要性的自适应学习，显著提升了图模型对异构关系的表达能力

- 2021：CLIP——提出对比语言-图像预训练框架，通过双编码器在共享嵌入空间对齐多模态数据，为后续图-文对齐预训练提供了核心的对比学习范式

- 2023：GraphGPT——将图节点投影到LLM嵌入空间作为软令牌，通过多阶段指令微调实现图结构与语言语义的对齐，开启了LLM作为图预测器的研究热潮

- 2024：TAPE——利用LLM生成节点级解释文本并编码为特征，通过联合训练而非简单拼接的方式增强GNN输入，解决了LLM特征直接拼接导致的干扰问题

- 2025：NAG——提出无编码器的原生架构，通过重配置自注意力机制强制拓扑依赖并校准位置ID，消除了外部GNN编码器与LM语义处理之间的概念割裂

- 2026：TAG-DLM——采用掩码扩散语言模型作为骨干，通过迭代去噪过程生成图相关文本，实现了图结构与文本生成的原生统一，突破了自回归LLM在图任务上的序列限制

这条时间线勾勒了该领域方法演进的代表性节点：从 2017 年的 GCN 奠定该领域方法基线，经 2018 年 GAT 的推进，到 2026 年的 TAG-DLM 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 图-文对齐预训练

图-文对齐预训练旨在解决图嵌入与文本嵌入分布差异大导致的语义鸿沟问题。早期工作如 G2P2 构建图与文本的正样本对并映射到共享空间，利用对比学习对齐图拓扑与节点文本表示。然而，固定的一对一匹配假设在噪声数据下表现脆弱。ADAligner（Liu et al., 2025, P7）针对 P1 在域偏移下的原型崩溃问题，引入了动态质量感知框架，根据批次数据质量自适应平衡多对多与一对一对齐目标，放弃了固定匹配假设，换取了对噪声数据的鲁棒性。S2Aligner（Wang et al., 2026, P33）进一步针对稀疏文本图提出对偶高效的预训练方法，通过零样本推理验证其在未见目标图上的泛化能力，解决了稀疏场景下图-文对齐的鲁棒性问题。UniGTE（Wang et al., 2025, P5）则构建统一编码器-解码器框架，通过可学习的对齐令牌聚合图结构与任务提示，实现了跨任务与跨域的零样本图表示迁移。这些方法共同构成了上层任务的基础表示层，为 GNN-LLM 协同融合提供了高质量的初始嵌入。

### 2.2 GNN-LLM协同融合

GNN-LLM 协同融合路线聚焦于双向交互与知识蒸馏，利用结构先验增强语义理解，或反之利用语义丰富结构表征。TAPE（He et al., 2024）利用 LLM 生成节点级解释文本并编码为特征，通过联合训练而非简单拼接的方式增强 GNN 输入，解决了 LLM 特征直接拼接导致的干扰问题。GLANCE（Loveland et al., 2025, P2）引入轻量级路由器基于节点级特征动态决策是否调用 LLM，通过自适应融合 GNN 结构表征与 LLM 语义表征，平衡了计算成本与预测性能。GNN-as-Judge（Xu and Ding, 2026, P27）利用 GNN 作为互补信号源筛选 LLM 伪标签，通过协同伪标签选择机制与弱监督微调，缓解了 LLM 在图任务中伪标签噪声大的问题。CoTeach（Kim et al., 2026, P46）提出置信度感知双教师学习框架，根据 GNN 预测置信度动态选择由 GNN 或 LLM 提供监督，减少了商业 LLM 推理成本并提升了少样本节点分类性能。该路线与原生编码路线形成互补：前者保留 GNN 的结构归纳偏置，适合结构主导的任务；后者追求概念统一，适合语义主导的复杂推理。

### 2.3 图结构原生编码

图结构原生编码路线旨在消除外部编码器瓶颈，实现 LLM 对图拓扑的原生理解。GraphGPT 将图节点投影到 LLM 嵌入空间作为软令牌，开启了 LLM 作为图预测器的研究热潮，但序列化过程导致信息损失。NAG（Gong et al., 2026, P15）提出无编码器的原生架构，通过重配置自注意力机制强制拓扑依赖并校准位置 ID，消除了外部 GNN 编码器与 LM 语义处理之间的概念割裂。<SOG_k>（Wu et al., 2026, P16）提出拓扑感知的图结构分词器，将全局图拓扑编码为单个显式结构令牌，通过混合结构问答对微调使 LLM 在统一空间中理解结构令牌。TAG-DLM（Chen et al., 2026, P43）采用掩码扩散语言模型作为骨干，通过迭代去噪过程生成图相关文本，实现了图结构与文本生成的原生统一，突破了自回归 LLM 在图任务上的序列限制。该路线放弃了外部编码器的稳定性，换取了 LLM 对拓扑的原生理解能力，但在训练复杂度和计算开销上付出了代价。

### 2.4 LLM图推理智能体

LLM 图推理智能体路线将图学习建模为推理-行动-观察循环，解决长上下文与结构幻觉问题。Graph-O1（Liu, 2025, P11）结合蒙特卡洛树搜索与 LLM 推理，通过探索多条候选图路径并评估其语义一致性，解决了多跳查询中复杂推理轨迹的可靠生成问题。AgentGL（2026, P50）将图学习建模为推理-行动-观察循环，利用强化学习优化工具调用策略，实现了 LLM 在图原生搜索中的自适应探索与密集奖励监督。CNY（Liu et al., 2026, P48）将邻域证据获取建模为顺序决策过程，利用目标条件在策略自蒸馏将后见信号转化为令牌级信用，实现了 LLM 在图上的主动行走与证据收集。TRN-R1-Zero（Liu et al., 2026, P29）摒弃了传统的编码器-解码器架构，直接利用 LLM 的生成能力进行推理，通过强化学习优化 LLM 在图结构上的推理策略，实现了零样本节点分类。该路线与协同融合路线竞争：前者追求动态证据收集与多步推理，后者追求静态特征融合与效率。

### 2.5 高效推理与优化与安全鲁棒性评估

高效推理与优化路线针对 LLM 高昂计算成本，研究参数高效微调、稀疏查询及知识蒸馏技术。GaLoRA（Choudhary et al., 2026, P21）采用两阶段解耦设计，先训练 GNN 提取结构感知嵌入，再通过 LoRA 将结构嵌入注入冻结 LLM，实现了参数高效的图感知 LLM 微调。BOSQ（Peng et al., 2026, P17）提出双层优化稀疏查询策略，自适应选择最具信息量的节点子集进行 LLM 解释生成，在保持性能的同时显著降低了大规模图上的计算成本。安全鲁棒性评估路线则系统评估 TAG 模型在对抗攻击、隐私泄露及数据质量退化下的脆弱性。SFT-auto（Lei et al., 2025, P6）利用 LLM 推理能力构建防御模型，通过包含正常、攻击与恢复样本的自适应数据增强策略，实现了对文本与结构双重对抗攻击的识别与恢复。BadGraph（Chen et al., 2026, P26）提出一种 LLM 驱动的通用对抗攻击方法，通过检索-推理管道引导 LLM 发现可迁移的拓扑和文本扰动。这两条路线共同构成了应用层约束，依赖于前两者的稳定性，为实际部署提供了效率与安全保障。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域最核心的共识在于 TAGs 是融合结构化关系与语义信息的理想范式，且 LLM 与 GNN 的结合能互补各自优势：GNN 擅长结构建模，LLM 擅长语义理解，二者融合优于单一模型。这一共识在多个基准上被反复验证：TAG-DLM 的 90.96 与 GASE 的 90.5 均大幅超越 GAT 的 83.0，且在不同规模数据集上保持一致性。与此相关的另一个共识是零样本与少样本学习是 TAGs 研究的重要方向，旨在解决标签获取成本高及跨域泛化难题。TRN-R1-Zero 在零样本任务上的 85.2 与 LLM-GNN Co-Teaching 在少样本任务上的 82.5 均显著优于传统 GNN 基线，表明 LLM 的先验知识在低资源场景下具有不可替代的价值。数据质量（噪声、稀疏、不平衡）显著影响 TAGs 模型性能，需引入鲁棒性机制或数据增强策略，这一共识在 ADAligner 和 S2Aligner 等针对稀疏和噪声数据的方法中得到体现。

### 3.2 观点分歧

结构信息注入方式存在根本分歧：外部投影 vs 原生架构修改。观点 A（外部投影）主张通过 GNN 编码器将图结构投影至 LLM 嵌入空间（如 GLIP, UniGTE），保留 GNN 的结构归纳偏置，训练稳定；观点 B（原生架构）主张通过修改 LLM 自注意力或位置编码直接注入图结构（如 NAG, <SOG_k>），实现概念统一。现有证据偏向原生架构在复杂推理和零样本任务上更优（如 TAG-DLM 在零样本任务上的表现），但外部投影在少样本和效率上更优（如 GLANCE）。分歧根源在于测量工具盲区：缺乏统一评估“结构保真度”与“语义深度”的指标；场景依赖：静态图与动态图、小图与大图的最优策略可能不同。这一分歧的背后，是另一个更根本的争论：LLM 角色是预测器还是增强器。预测器（如 TRN-R1-Zero）在零样本任务上更强，但增强器（如 GNN-as-Judge）在少样本任务上更稳。现有证据显示，任务依赖性是关键：不同任务（节点分类 vs 链接预测 vs 图分类）对 LLM 角色的需求不同，缺乏统一框架同时优化两种角色。

### 3.3 其他开放问题

最紧迫的工程问题是大规模图上的 LLM 推理成本。现状是 LLM 推理成本高，难以直接应用于百万级节点图；关键困难在于如何平衡精度与效率；研究路径包括稀疏查询、知识蒸馏和参数高效微调技术，如 BOSQ 和 GaLoRA 已初步验证了这些路径的可行性。最根本的研究问题是动态图与时间演化建模。现状是当前方法多聚焦静态图，难以处理节点、边和文本属性随时间变化的动态场景；关键困难在于如何设计时间感知的线性化和拓扑掩码；研究路径包括引入时间序列模型和动态注意力机制。鲁棒性与安全性增强也是重要开放问题，LLM-GNN 融合模型对文本和结构攻击脆弱，隐私泄露风险高，需在不牺牲性能的前提下提升鲁棒性，潜在路径包括对抗训练、差分隐私和鲁棒对齐方法。已知—争议—未知认知图谱显示：已知融合优于单一、零样本是重要方向；争议结构注入方式、LLM 角色；未知动态图建模、可解释性、联邦学习。发展趋势将聚焦于鲁棒、高效且可解释的通用图基础模型。

## 4. 总结与展望

文本属性图学习正从“模态拼接”走向“原生统一”，核心矛盾在于 LLM 的语义深度与 GNN 的结构效率之间的张力。早期研究通过简单拼接解决跨模态融合不足，随后通过序列化或投影机制引入结构信息，但暴露出计算成本高、信息损失大等问题。当前，领域进入精细化与鲁棒性阶段，研究焦点从基础性能提升转向零样本泛化、数据质量优化、对抗鲁棒性及高效推理。核心瓶颈在于如何以低成本、高鲁棒性的方式，在保留 GNN 结构归纳偏置的同时，充分发挥 LLM 的语义推理能力，解决标签稀缺、数据噪声及跨域迁移难题。

未来可能突破的方向包括：统一图-语言预训练，构建大规模图-语言语料和统一表示空间，潜在路径包括图令牌化、对比学习和指令微调，UniGTE 和 GLIP 已初步验证了这一路径的可行性；动态图与时间演化建模，设计时间感知的线性化和拓扑掩码，引入时间序列模型和动态注意力机制，CROSS 等仓库已提供初步支持；鲁棒性与安全性增强，通过对抗训练、差分隐私和鲁棒对齐方法提升模型在对抗环境下的稳定性，SFT-auto 和 BadGraph 已提供了攻击与防御的基准。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，系统评估不同结构注入方式（外部投影 vs 原生架构）在动态图和噪声数据上的性能差异，填补当前评测体系的空白。
