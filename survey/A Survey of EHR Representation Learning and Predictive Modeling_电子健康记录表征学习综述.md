## 导读

电子健康记录（EHR）表征学习旨在从高度异质、不规则采样的临床数据中提取通用患者状态表示，其核心矛盾在于数据稀疏性与模型对结构化密集输入的偏好之间的冲突。早期研究依赖手工特征工程与任务特定模型，难以捕捉纵向时间动态与多变量异步观测的复杂结构。随着 Transformer 架构的引入，领域范式从“预测特定疾病”转向“学习可迁移的通用临床语义”，自监督预训练成为主流路径。然而，长序列计算效率、跨机构分布偏移及临床可解释性仍是制约模型真实部署的关键瓶颈。当前研究正通过引入状态空间模型、知识图谱增强及大语言模型协同推理，试图在计算效率、语义深度与临床信任度之间寻求新的平衡。本综述梳理从序列建模到临床基础模型的因果演进链条，揭示方法取舍背后的约束条件。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

电子健康记录作为现代医疗的核心数据载体，蕴含了患者纵向、多模态且高度异质的临床信息。早期研究主要依赖手工特征工程和传统机器学习模型，但难以捕捉 EHR 数据中不规则采样、时间稀疏及多变量异步观测的复杂结构。这一局限促使研究者将目光投向序列建模，试图通过注意力机制和循环网络模拟临床医生回顾病史的过程，从而识别关键就诊和变量。这一阶段的核心假设是 EHR 数据可通过时序依赖关系有效建模，但模型仍为任务特定且缺乏通用性，无法应对临床任务的多样性和数据标注的高成本。

问题的形式化定义经历了从静态特征到动态序列的演变。在 N-way K-shot 少样本学习或零样本预测的框架下，模型需从极少量样本中习得新概念，其核心价值在于缓解数据标注成本高企与泛化需求之间的张力。具体而言，给定患者历史事件序列 $X = \{x_1, x_2, ..., x_T\}$，其中 $x_t$ 为第 $t$ 次就诊的观测集合，目标是在未见过的临床场景 $Y$ 上预测风险或疾病进展。子问题间存在强依赖关系：不规则时序建模是基础，若无法有效处理缺失和时间间隔，后续的多模态融合和基础模型预训练将因噪声过大而失效；跨机构泛化依赖于标准化的数据表示和鲁棒的表征学习；可解释性则依赖于模型架构的可分解性或外部知识的注入。

2016 年至 2018 年是领域的奠基期，RETAIN 和 BRITS 等里程碑工作确立了注意力机制和双向 LSTM 在处理不规则序列上的有效性。RETAIN 通过反向时间注意力机制建模患者就诊序列，实现了 EHR 序列建模的可解释性突破；BRITS 则提出双向循环插补时间序列模型，将缺失值插补与预测任务联合优化。这一时期的方法虽然解决了时间依赖性和缺失值插补问题，但受限于算力，模型规模较小，且无法跨任务迁移。

2020 年前后，随着 Transformer 架构在自然语言处理领域的成功，BEHRT 等里程碑工作将 EHR 序列建模范式引入临床预测，通过自监督预训练学习通用的患者表示，标志着领域从“任务特定模型”向“基础模型”的范式转变。Med-BERT 随后在大规模结构化 EHR 语料上预训练上下文嵌入模型，展示了自监督学习在提升下游疾病预测任务泛化能力上的潜力。这一转折的核心动机是任务特定模型难以应对临床任务的多样性，而 NLP 领域的成功证明了自监督预训练的潜力。

2023 年至 2025 年，领域进入精细化与工程化阶段，研究重心迅速扩展至多模态融合、知识图谱增强推理以及大规模多机构数据标准化。CLMBR-T-Base 确立了 EHR 基础模型在零样本和少样本预测任务中的评估标准，推动了领域向规模化预训练方向发展。与此同时，CEHR-XGPT 和 PORTER 等可扩展的多任务 EHR 基础模型相继提出，通过统一表示处理诊断、药物和程序等异构模态，支持零样本预测及跨机构迁移。这一阶段的方法不仅关注预测精度的提升，更强调模型在真实临床环境中的可部署性、公平性及因果推断能力。

当前，该领域活跃度极高，研究不仅关注预测精度的提升，更强调模型在真实临床环境中的可部署性、公平性及因果推断能力，旨在构建能够支持个性化医疗决策和临床数字孪生的通用智能系统。长序列计算效率、缺失值处理、跨机构分布偏移鲁棒性，以及利用大语言模型进行可解释性推理与自动化数据策展，成为新的研究热点。

**如果用一个核心问题概括该领域，那便是：如何在保留临床时序因果逻辑与语义完整性的前提下，构建能够跨机构、跨模态泛化且具备临床可解释性的通用患者状态表征。**

## 2. 方法体系

- 2016：RETAIN——通过反向时间注意力机制建模患者就诊序列，模拟临床医生回顾病史的过程以识别关键就诊和变量，实现了EHR序列建模的可解释性突破，成为后续注意力机制在临床预测中的经典基线

- 2017：GRAM——利用医学本体层级结构对EHR中的医疗代码进行图扩展，通过图卷积网络捕捉概念间的语义关联，解决了稀疏EHR数据中语义信息不足的问题，奠定了知识图谱增强EHR表征的基础范式

- 2018：BRITS——提出双向循环插补时间序列模型，将缺失值插补与预测任务联合优化，通过双向LSTM捕捉时间依赖关系，显著降低了训练与测试间的数据分布差异，成为处理不规则临床时间序列的重要方法

- 2020：BEHRT——将BERT架构适配至结构化EHR数据，通过掩码语言建模预训练患者就诊序列，证明了Transformer在捕捉长期临床依赖关系上的有效性，开启了EHR基础模型的研究热潮

- 2023：CLMBR-T-Base——基于大规模EHR数据训练的Transformer基础模型，通过线性探测评估其表征能力，确立了EHR基础模型在零样本和少样本预测任务中的评估标准，推动了领域向规模化预训练方向发展

- 2025：CEHR-XGPT——提出可扩展的多任务EHR基础模型，通过统一表示处理诊断、药物和程序等异构模态，利用自监督学习提取通用患者表征，支持零样本预测及跨机构迁移，提升了模型在复杂临床场景下的泛化能力

- 2026：MedCPI——提出构建-个性化-整合框架增强临床预测，通过任务引导的模式归纳从统一医学知识图谱中提取任务特定概念，构建患者级个性化知识图谱并融合纵向EHR表征，提升了预测的可解释性和知识利用效率

- 2026：xMICD——提出多ICD代码的可解释表征方法，结合临床诊断分组与预训练ICD嵌入空间的相似度，通过基于相似度的相对分配生成反映患者诊断与临床组对齐程度的特征，平衡了预测性能与临床可解释性

这条时间线勾勒了该领域方法演进的代表性节点：从 2016 年的 RETAIN 奠定该领域方法基线，经 2017 年 GRAM 的推进，到 2026 年的 xMICD 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 时序建模与缺失处理

时序建模是 EHR 表征学习的基石，其核心挑战在于处理不规则采样、高缺失率及多尺度时间依赖。早期工作如 BRITS 通过双向 LSTM 捕捉时间依赖关系，将缺失值插补与预测任务联合优化，显著降低了训练与测试间的数据分布差异。然而，随着数据规模扩大，传统循环网络在长程依赖捕捉和并行计算效率上逐渐显露不足。MuFuse（Hsieh et al., 2025, P8）针对这一局限，提出乘性嵌入融合模块，将观测三元组映射为特征、数值和时间嵌入，并通过乘性组合形成统一 Token 表示。该方法的本质差异在于放弃了传统的拼接或加法融合，转而通过乘性机制动态调整数值特征对表征的影响，从而缓解了异步采样和高缺失率带来的建模挑战。其成功依赖于对嵌入初始化的敏感性控制，且在计算开销上略高于简单拼接，但换来了数值特征表征的鲁棒性。

在架构层面，Structure-Aware Set Transformers（Lee et al., 2026, P18）进一步引入了时间偏差和变量类型偏差的软注意力机制，显式建模事件间的时间依赖和变量类型关联。该方法将 EHR 表示为不规则事件集合，通过层间融合策略动态调整不同偏差的影响权重，解决了传统集合模型在时序结构建模上的不足。与 MuFuse 的局部融合不同，Structure-Aware Set Transformers 强调全局结构感知，其代价是偏差计算和层间融合的计算开销较大。在 MIMIC-IV 死亡率预测任务中，该方法取得了 0.9164 的 AUROC，显著优于基线 STaTS 的 0.8778，证明了结构感知注意力在捕捉复杂时间动态上的有效性。

针对数值编码这一微观但关键的问题，How Should Transformers Encode Numeric Values（Montgomery et al., 2026, P33）系统评估了离散化、组合、联合分箱、拼接和 FiLM 五种编码策略。该研究通过合成信号和真实 EHR 数据验证，发现不同策略在算术任务和临床预测任务中的表现存在显著差异，并引入信息效率指标综合评估预测性能和计算成本。这一工作揭示了数值编码机制对时序建模的深层影响，为后续方法提供了量化依据。Dual-Masked Autoencoding（Xiang et al., 2026, P16）则从预训练目标入手，提出双掩码策略同时掩码数值和变量标识，迫使模型学习缺失值间的依赖关系和变量语义，增强了模型对复杂缺失模式的适应能力。这些方法共同构成了时序建模路线的技术底座，为上层基础模型提供了鲁棒的时序特征输入。

### 2.2 EHR基础模型架构

在时序建模的基础上，EHR 基础模型架构旨在通过自监督学习提取通用患者表征，支持零样本预测及跨机构迁移。BEHRT 和 Med-BERT 奠定了这一范式的基础，而 CEHR-XGPT（Pang et al., 2025, P1）则代表了当前可扩展多任务基础模型的最新进展。CEHR-XGPT 采用 Transformer 架构，将诊断、药物、程序等异构临床事件序列化为统一表示，通过掩码预测和下一事件预测等预训练目标优化模型参数。其核心创新在于引入多任务学习框架，使模型能够同时适应零样本预测、特征表示和合成数据生成等多种下游任务。该方法的代价是预训练阶段需要巨大的计算资源和高质量的大规模 EHR 数据集，且对数据清洗和标准化流程依赖较高，但换来了在未见过的临床场景中的泛化能力。

DT-Transformer（Zhu et al., 2026, P29）则从疾病轨迹预测的角度出发，设计了一种基于 Delphi 风格生成式框架的基础模型。该方法使用连续年龄的正弦编码替代标准位置编码，以精确表示 EHR 事件在连续时间轴上的位置，并通过指数等待时间分布建模时间到事件预测，从而联合估计未来事件率和发生时间。与 CEHR-XGPT 的通用表征不同，DT-Transformer 专注于生成完整的疾病轨迹，而非仅预测单一终点，为长期疾病管理提供了动态视角。其核心优势在于能够捕捉疾病进展的时序因果逻辑，但代价是模型架构更复杂，且对时间编码的精度要求较高。

PORTER（Guo et al., 2026, P32）则探索了语言接地的结构化 EHR 基础模型，旨在通过自监督预训练学习可移植的患者表征。该方法将临床事件表示为复合离散 Token，结合主要 OMOP 概念 ID 和离散化事件属性，以保留丰富的临床信息。PORTER 的核心优势在于其可移植性，能够在不同医院和人群间保持稳定的预测性能，解决了传统 EHR 模型在分布偏移下性能下降的问题。通过标准化数据映射到 MEDS 格式和 OMOP 本体，PORTER 确保了跨机构数据的一致性，降低了数据整合的复杂性。这一路线与 CEHR-XGPT 的通用性形成互补，前者强调跨机构鲁棒性，后者强调任务多样性。

### 2.3 知识图谱增强表征

知识图谱增强表征旨在通过注入外部医学本体提升模型在数据稀疏场景下的预测性能和可解释性。GRAM 奠定了这一范式的基础，而 MedCPI（P39）则代表了当前构建-个性化-整合框架的最新进展。MedCPI 在构建阶段执行任务引导的模式归纳和 KG 规范化，从统一医学知识图谱中提取任务特定的概念子图，确保知识的相关性和一致性。在个性化阶段，通过扩展 EHR 子图并添加任务相关知识路径，构建患者级个性化知识图谱，并使用任务感知关系图卷积网络进行编码。整合阶段将纵向 EHR 序列编码与 PKG 节点表征通过交叉注意力融合，实现全局时序动态与局部知识语义的互补。该方法的核心创新在于任务特定的知识选择和显式的个性化图结构，避免了无约束邻域扩展带来的噪声。其代价是知识图谱构建和图推理的计算开销较大，且依赖高质量的外部医学本体。

KEEP（Elhussein et al., 2025, P3）则从代码嵌入的角度出发，提出一种知识保留和实证精炼的嵌入过程，旨在将医学本体与临床数据整合以构建鲁棒的代码嵌入。该方法利用知识图谱生成语义丰富的向量表示，通过随机游走和共现矩阵分析捕捉医疗概念间的结构关系，解决了传统离散编码高维稀疏的问题。KEEP 在预训练阶段利用大规模临床数据实证精炼嵌入，增强了模型对罕见概念和长尾分布的鲁棒性。与 MedCPI 的图推理不同，KEEP 侧重于静态嵌入的语义一致性，其代价是嵌入生成过程需要迭代优化，且对知识图谱的完整性和准确性依赖较高。

Import What You Need（Chen et al., 2026, P38）进一步引入了预算感知增强动作空间，包括软导入、硬导入和跳过三种策略，通过强化学习策略选择每个就诊的最优增强动作，平衡预测增益与增强成本。该方法的核心创新在于解耦语义通道和结构通道编码，通过自适应门控融合互补证据，实现了外部知识的动态和选择性整合。与 MedCPI 和 KEEP 的静态或半静态知识注入不同，Import What You Need 强调知识的动态选择，其代价是强化学习策略训练复杂，且需要离线构建高质量知识池。这些方法共同构成了知识增强路线的技术体系，为 EHR 建模提供了语义深度和可解释性。

### 2.4 多模态数据融合

多模态数据融合旨在整合结构化 EHR、非结构化临床文本、基因组学或可穿戴设备数据，构建更全面的患者健康画像。CURENet（Dao et al., 2025, P9）提出一种结合统一表征的慢性疾病预防框架，旨在整合非结构化临床笔记和结构化实验室结果以捕捉多模态数据的相互依赖关系。该方法通过多模态编码器将文本和数值数据映射到共享嵌入空间，利用跨模态注意力机制捕捉叙事描述与定量指标间的上下文关联，解决了现有模型孤立处理模态的问题。CURENet 的核心创新在于统一表征学习，使模型能够理解文本如何解释实验室趋势，从而提升复杂慢性病预测的准确性。其代价是多模态数据对齐和预处理复杂，且对文本质量要求较高。

UniPACT（Tang et al., 2026, P15）则设计了一种多模态框架用于原始 ECG 和结构化 EHR 的预后问答，旨在通过端到端生成模型统一多模态输入以支持急性护理决策。该方法包含三个核心组件：专用 ECG 信号编码器、结构化 EHR 数据文本化提示机制以及融合多模态表征的大型语言模型，实现了从原始波形到自然语言预测的端到端映射。UniPACT 的核心创新在于将原始 ECG 波形直接输入模型，而非依赖预提取特征，保留了细粒度生理信号信息，并通过 LLM 融合 EHR 上下文进行推理。其代价是 ECG 编码器和 LLM 的计算开销较大，且多模态数据对齐需要精细调优。

HealthPoint（Li et al., 2026, P24）提出一种临床点云范式用于不完整多模态 EHR 的院内死亡率预测，旨在处理不规则采样、缺失模态和稀疏标签带来的挑战。该方法将每个临床观测嵌入到由内容、时间、模态和病例定义的四维坐标空间中，形成点云表示，通过低秩关系注意力建模任意点间的高阶依赖关系。HealthPoint 的核心创新在于点云表示和低秩注意力机制，使模型能够灵活处理缺失模态和不规则采样，避免了传统网格化方法的数据对齐复杂性。其代价是点云嵌入和注意力计算开销较大，且对数据预处理要求较高。这些方法共同构成了多模态融合路线的技术体系，为 EHR 建模提供了更全面的患者视图。

### 2.5 LLM与EHR协同

LLM 与 EHR 协同旨在利用大语言模型的推理能力处理长序列临床数据，并生成可解释的自然语言解释。Next Event Prediction（Chen et al., 2025, P2）提出一种通过自回归微调增强 LLM 时间推理能力的框架，旨在解决 LLM 在顺序临床事件和时序依赖推理上的不足。该方法将 EHR 重构为带时间戳的事件链，通过预测未来医疗事件显式建模疾病进展模式和因果关系，提升了时序推理任务的预测精度。其核心创新在于将 EHR 序列建模转化为自回归生成任务，使 LLM 能够学习临床事件的时序逻辑和因果结构。其代价是微调数据准备复杂，且对 LLM 的上下文长度要求较高。

EHR-RAGp（Shurrab et al., 2026, P28）则提出一种检索增强原型引导基础模型，旨在通过检索相关历史片段增强 LLM 对长序列 EHR 的推理能力。该方法将患者时间线划分为事件、时间、就诊和护理阶段四种可检索块，通过原型引导对齐检索与任务查询相关的历史片段，实现了长序列信息的动态选择和整合。EHR-RAGp 的核心创新在于原型引导检索机制，使模型能够根据当前任务需求动态选择关键历史事件，而非依赖固定窗口或全序列输入。其代价是检索和原型对齐的计算开销较大，且对块划分策略敏感。

ChatHealthAI（Wang et al., 2026, P30）提出一种将 EHR 表征与 LLM 对齐的框架，旨在通过接地临床推理生成可解释的自然语言解释。该方法利用 EHR 基础模型学习患者嵌入，并通过提示工程将结构化 EHR 数据转化为 LLM 可理解的文本格式，实现了结构化数据与语言模型的无缝对接。ChatHealthAI 的核心创新在于接地推理机制，使 LLM 能够基于患者记录生成具有临床相关性和时间推理能力的解释，而非仅输出预测标签。其代价是提示工程复杂，且 LLM 生成解释的计算开销较大。这些方法共同构成了 LLM 协同路线的技术体系，为 EHR 建模提供了可解释性和长上下文推理能力。

### 2.6 跨任务与多领域应用

EHR 表征学习的方法体系不仅局限于单一任务，还广泛适用于多种临床场景和领域。在慢性疾病预防方面，CURENet 和 MedCPI 通过整合多模态数据和知识图谱，提升了复杂慢性病预测的准确性。在急性护理决策支持方面，UniPACT 和 Structure-Aware Set Transformers 通过处理原始 ECG 波形和不规则时序数据，提升了预后问答和死亡率预测的性能。在长期疾病轨迹预测方面，DT-Transformer 和 Recurrence-aware Foundation Model 通过生成式框架和复发感知机制，捕捉了疾病的长期进展和复发模式。

在跨机构泛化方面，PORTER 和 Foresight-England 通过标准化数据映射和安全框架，解决了不同医院间编码系统、测量政策和文档习惯差异导致的模型性能下降问题。在数据稀缺和隐私保护方面，CDMT-EHR 和 SynEHR 通过连续时间扩散框架和联合建模，生成了高质量的合成 EHR 数据，提升了模型在数据稀缺场景下的鲁棒性。这些应用展示了 EHR 表征学习方法的通用性和适应性，为构建可信、通用且可解释的临床智能系统提供了技术支撑。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

EHR 数据的不规则性、稀疏性和多模态异质性是建模的核心挑战，必须通过专门的时间编码或架构设计来处理，这一共识在约 60 篇论文中得到共同支持。基于 Transformer 的自监督预训练（如 BEHRT, Med-BERT）已成为学习通用 EHR 表示的主流范式，优于传统手工特征工程，约 50 篇论文共同支持这一观点。引入外部医学知识（如知识图谱、本体）能显著提升模型在数据稀疏场景下的预测性能和可解释性，约 25 篇论文共同支持。跨机构泛化能力受限于数据分布偏移，标准化数据模型（如 OMOP/MEDS）和域适应技术是提升模型鲁棒性的关键，约 20 篇论文共同支持。多模态融合（结构化+非结构化）比单一模态建模能提供更全面的患者视图，有助于提升复杂临床任务的预测精度，约 15 篇论文共同支持。临床预测模型的评估不能仅依赖 AUC 等区分度指标，校准度（Calibration）和临床效用（Clinical Utility）对于实际部署至关重要，约 10 篇论文共同支持。大语言模型（LLM）在 EHR 领域的应用正从简单的文本处理转向与结构化数据编码器的深度集成，以实现更高级的推理和解释，约 12 篇论文共同支持。计算效率是制约长序列 EHR 模型部署的重要因素，状态空间模型（SSM）和混合架构被视为 Transformer 的有效补充或替代，约 8 篇论文共同支持。

### 3.2 观点分歧

Transformer 与 SSM/Mamba 在长序列建模上的最优架构选择存在显著分歧。观点 A 认为 Transformer 通过注意力机制能更精确地捕捉细粒度临床语义依赖，代表方法包括 CEHR-XGPT 和 DT-Transformer；观点 B 认为 SSM/Mamba 具有线性复杂度，更适合长序列 EHR，且能捕捉全局依赖，代表方法包括 HoT-SSM 和部分混合架构。现有证据偏向 SSM 在长序列效率上的优势，但在 MIMIC-IV 等短中序列任务上，Transformer 仍保持 SOTA。证据强度中等，缺乏在超长序列（>10k tokens）上的公平对比实验，且不同研究使用不同的序列长度和预处理，导致结果不可比。

LLM 在 EHR 中的角色定位也存在分歧。观点 A 认为 LLM 应作为核心推理引擎，直接处理 EHR 序列并生成预测，代表方法包括 Next Event Prediction 和 PaReGTA；观点 B 认为 LLM 应作为解释工具或辅助检索模块，与专用编码器协同工作，代表方法包括 EHR-RAGp 和 ChatHealthAI。证据偏向观点 B，即 LLM 在生成可解释性方面表现优异，但在直接预测精度上往往不如专用编码器+分类头。观点 A 在时序推理任务上有一定优势，但计算成本极高。LLM 的幻觉问题和结构化数据对齐技术尚未成熟，缺乏评估 LLM 临床推理准确性的标准化基准。

可解释性的实现路径也存在分歧。观点 A 认为可解释性应通过架构设计实现，如注意力权重、原型匹配，代表方法包括 RETAIN 和 xMICD；观点 B 认为可解释性应通过事后归因方法实现，如 SHAP、LIME，代表方法包括 X-FEMR。证据显示架构内建的可解释性更稳定且与模型决策一致，但可能牺牲性能；事后归因更灵活，但可能产生误导性解释。缺乏评估可解释性“临床有效性”的指标，即解释是否真正帮助医生做出正确决策。

### 3.3 其他开放问题

跨机构泛化与分布偏移处理是最紧迫的工程问题。不同医院间编码系统、测量政策和文档习惯差异导致的模型性能下降问题，难点在于临床数据非独立同分布，受机构特定工作流影响。潜在路径包括实践不变性学习、对抗训练、跨机构最优传输对齐及多中心联邦学习。多模态数据融合与统一表征是另一关键研究问题，整合结构化 EHR、非结构化临床笔记、医学影像、基因组及可穿戴设备数据，以捕捉更全面的患者状态。难点在于模态间的时间异步性、缺失机制不同及语义对齐。潜在路径包括多模态 Transformer、对比学习对齐、超图建模及统一时序基础模型。

可解释性与临床可信度是构建临床信任的关键。提升模型预测的透明度，使临床医生能够理解模型决策依据，建立信任。难点在于深度模型的黑盒性质与临床逻辑的复杂性。潜在路径包括 Token 级解释、知识图谱增强推理、SHAP 值分析、临床对齐指标及因果推断。零样本与少样本预测能力减少对大规模标注数据的依赖，使模型能够在新任务或新疾病上快速适应。难点在于临床任务多样性及数据稀缺。潜在路径包括基础模型预训练、提示工程、检索增强生成（RAG）、原型学习及元学习。不规则时序与缺失值处理有效建模 EHR 中常见的不规则采样、缺失数据及时间间隔变化。难点在于缺失机制（MCAR/MAR/MNAR）的复杂性及时间依赖性的捕捉。潜在路径包括时间感知嵌入、掩码自编码、状态空间模型（SSM）、混合 Mamba-Transformer 架构及缺失值显式编码。合成数据生成与隐私保护生成高质量合成 EHR 数据以解决数据隐私、稀缺及偏差问题，同时保持临床效用。难点在于保持数据分布保真度、隐私安全性及下游任务效用。潜在路径包括扩散模型、生成对抗网络、基于代理的模拟、差分隐私及条件生成。模型校准与鲁棒性评估确保模型预测概率准确且在不同人群、时间窗口内稳定，避免临床误判。难点在于校准度与准确性的权衡及长期稳定性。潜在路径包括校准损失函数、不确定性量化、稳定性指标（如 Lipschitz 常数）、决策曲线分析及公平性审计。长期疾病轨迹与未来事件预测从单次预测转向长期轨迹建模，预测未来多年内的疾病进展、干预效果及健康状态演变。难点在于长期依赖关系、干预条件性及状态一致性。潜在路径包括世界模型、递归状态更新、长上下文 Transformer、时序知识图谱及因果轨迹建模。

当前领域的认知边界在于：工程问题（如长序列效率、数据标准化）已有明确路径，但研究问题（如跨机构因果推断、多模态语义对齐、临床信任建立）仍缺乏统一理论框架。未来突破将依赖于多模态融合、因果推断和高效架构的深度融合，构建具备因果推理能力、跨机构泛化能力和临床可解释性的通用智能体。

## 4. 总结与展望

EHR 表征学习已从单纯的预测精度竞赛转向构建可信、通用且可解释的临床智能系统。核心矛盾在于数据的不规则性/稀疏性与模型对结构化/密集输入的偏好之间的冲突，以及长序列计算效率与细粒度语义捕捉之间的权衡。从序列建模到基础模型，再到多模态与 LLM 协同，每一步都解决了前一步的特定瓶颈，但跨机构泛化、多模态语义对齐和临床信任建立仍是未解之题。

未来可能突破的方向包括：基于世界模型的长期轨迹预测，通过递归状态更新和因果轨迹建模，捕捉疾病进展的动态演化；联邦学习下的隐私保护基础模型，通过多中心联邦学习和差分隐私，解决数据隐私和跨机构泛化问题；因果推断驱动的可解释性框架，通过因果图推理和临床对齐指标，提升模型预测的透明度和临床信任度。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，构建一个涵盖长序列效率、跨机构泛化性和临床可解释性的综合评测基准，以推动领域内的公平竞争与技术迭代。
