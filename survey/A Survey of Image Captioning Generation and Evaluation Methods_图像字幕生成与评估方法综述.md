## 导读

图像字幕生成与评估旨在通过自然语言描述图像内容，其核心挑战在于平衡描述的丰富度与事实准确性。早期研究依赖词汇重叠指标，思路简洁却受制于语义盲区，无法捕捉幻觉与细微错误。随着多模态大模型生成能力的提升，长文本密集描述成为主流，传统指标在特异性与鲁棒性上全面失效，促使领域转向基于语义对齐与人类偏好对齐的评估范式。各路线在计算效率、细粒度感知与中立性之间做出了不同取舍，由此形成当前评估与生成相互驱动的研究闭环。本综述梳理这条从全局相似度到细粒度事实核查的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

图像字幕生成与评估是视觉-语言研究的核心任务，其早期目标是通过自动指标替代昂贵且主观的人工评估，量化生成文本与参考文本的匹配度。这一阶段的问题形式化通常基于 N-way K-shot 的变体，即给定图像 $I$ 和 $K$ 个参考字幕 $\{C_1, ..., C_K\}$，计算候选字幕 $C$ 的分数 $S(I, C, \{C_i\})$。然而，这种基于 n-gram 重叠的定义隐含了“词汇匹配即语义一致”的强假设，导致指标与人类判断的相关性始终处于低位。随着多模态大模型（MLLMs）的兴起，生成内容从短句扩展为包含细粒度对象、属性和空间关系的长文本，问题结构发生了根本性变化：评估不再仅仅是文本间的相似度比较，而是转化为图像与文本之间的跨模态事实核查。

这一转变揭示了子问题之间的严格依赖关系。首先，必须解决“如何准确评估长文本细粒度质量”的问题，即提升评估指标的特异性（Specificity）与鲁棒性，这是构建可靠信号的前提。其次，基于可靠的评估信号，才能解决“如何优化生成模型”的问题，特别是在强化学习中平衡幻觉抑制与信息覆盖。最后，通过构建细粒度基准验证上述闭环的有效性。评估是生成的前提，生成是评估的驱动，二者构成了一个相互制约的系统。若评估指标无法区分“安全但简短”与“丰富且准确”的字幕，生成模型将倾向于保守策略，导致多样性坍缩；反之，若生成模型产生大量幻觉，评估指标将面临噪声淹没，失去区分度。

从范式边界来看，该领域正经历从“基于重叠的静态评估”向“基于语义对齐与人类偏好对齐的动态评估”的深水区转型。传统范式假设参考数据是完美的金标准，但现实中参考数据存在偏差且稀缺，这催生了无参考评估（Reference-free Evaluation）范式。然而，无参考范式又引入了新的边界问题：如何在不依赖参考的情况下捕捉细粒度语义错误？这一边界问题直接推动了基于预训练视觉-语言模型（如 CLIP）的评估方法兴起，但也暴露了全局池化机制对局部幻觉不敏感的缺陷。

回顾约束演化史，2016-2018 年是奠基期，SPICE 等基于场景图的方法尝试引入语义结构，但受限于解析管线的复杂性，未能成为主流。2020-2021 年，CLIP 的出现带来了关键转折，CLIPScore 等无参考指标解决了短文本评估的语义对齐问题，确立了预训练模型作为评估骨干的范式。2023-2024 年，随着 LLM 能力的爆发，LLM-as-a-Judge 范式引入，解决了长文本逻辑推理与事实核查的需求，但带来了推理成本高与自偏好偏差的新约束。2025-2026 年，研究重心转向细化与融合，通过蒸馏、分布匹配和强化学习可验证奖励（RLVR）等技术，试图在效率、准确性与鲁棒性之间寻找新的平衡点。当前形态表现为评估指标与生成模型的深度耦合，评估信号直接介入生成过程，形成了动态优化的闭环。

**如果用一个核心问题概括该领域，那便是：如何在缺乏完美参考数据的情况下，构建兼具细粒度特异性、语义鲁棒性且计算高效的评估机制，并以此作为可靠信号驱动多模态大模型生成既丰富又事实准确的密集描述。**

## 2. 方法体系

- 2002：BLEU——基于n-gram重叠的机器翻译评估指标，奠定该领域方法基线

- 2015：CIDEr——引入TF-IDF加权机制的共识评估指标，推进短文本评估

- 2021：CLIPScore——基于CLIP预训练视觉-语言模型的无参考评估指标，开启语义对齐范式

- 2023：PACScore——改进CLIPScore的鲁棒性评估指标，缓解冗余文本偏差

- 2024：HiFiScore——针对长文本描述的细粒度评估指标，引入原子事实分解

- 2025：SPECS——特异性增强的CLIP-Score评估指标，提升细节区分度

- 2025：VELA——LLM混合评判者评估框架，代表当前长文本评估前沿

- 2025：CapRL——基于强化学习的密集描述生成框架，开启评估-生成闭环

这条时间线勾勒了该领域方法演进的代表性节点：从 2002 年的 BLEU 奠定该领域方法基线，经 2015 年 CIDEr 的推进，到 2025 年的 VELA 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 基于预训练模型的无参考评估

早期无参考评估的核心假设是“跨模态嵌入空间的余弦相似度能反映语义一致性”。CLIPScore（Hessel et al., 2021）作为奠基工作，通过计算图像嵌入与文本嵌入的余弦相似度实现了高效评估，放弃了细粒度事实核查能力，换取了计算效率与无参考适用性。然而，其全局池化机制导致细粒度语义差异被稀释，在长文本场景下特异性不足。针对这一短板，SPECS（Chen et al., 2025, P1）引入了特异性增强训练目标，通过对比学习优化文本嵌入，使其能区分不同细节程度的描述。SPECS 解决了 CLIPScore 对细节不敏感的问题，能够正确区分包含更多正确细节的描述，但其代价是训练过程需要特定的最小对数据，且计算开销略高于标准 CLIPScore。

为了进一步捕捉细粒度的视觉-语言交互，BEiTScore（Gomes et al., 2026, P17）转向基于 BEiT-3 交叉编码器的高效无参考评估。与 CLIP 的双塔架构不同，BEiTScore 通过联合编码图像和文本，捕捉更细粒度的交互，解决了 CLIP-based 指标在长文本上的局限性。其代价是模型参数量较大，推理速度较慢，但其在组合性错误检测上的表现显著优于纯对比方法。这一路线的演进逻辑清晰：从全局相似度到局部对齐，从双塔架构到交叉编码器，每一步迭代都是为了在保持无参考优势的同时，提升对细微语义错误的敏感度。

### 2.2 基于 LLM 与混合架构的细粒度评估

当字幕长度超过 77 个 token 时，基于预训练视觉模型的评估指标面临上下文窗口限制与逻辑推理能力不足的双重挑战。LLM-as-a-Judge 范式应运而生，利用大语言模型的语义理解能力进行细粒度事实核查。VELA（Matsuda et al., 2025, P3）作为代表性工作，结合了 R2C-LLM 分支和 I2C-Align 分支，分别从语言关系和视觉对齐角度评估长文本描述。VELA 通过多视角融合提升了评估的全面性，但其依赖 LLM 的最后隐藏状态，限制了闭源模型的使用，且推理速度较慢。

为了解决 LLM 评估器的自偏好偏差和推理延迟问题，研究者们转向蒸馏与混合架构。Rigel（Koyama et al., 2026, P20）提出了自蒸馏评分适应框架，通过两阶段过程将 LLM 的评估能力蒸馏到轻量级评分头。Rigel 解决了大词汇语言建模与评估任务标签空间不匹配的问题，实现了单次前向传播的高效评估，放弃了 LLM 的完整推理能力，换取了中立性与效率。Pearl（Hirano et al., 2025, P8）则采用单模型策略联合处理参考式和无参考式评估，通过共享表示学习提升泛化能力，避免了 LLM 评估器的自我偏好偏差。DISCODE（Inoue et al., 2025, P6）进一步引入了测试时自适应解码器，通过最小化注意力损失来调整 token 概率分布，生成更鲁棒的评分，解决了 LVLM 直接生成评分时的不稳定性问题。这些方法共同构成了 LLM 评估的轻量化与鲁棒化路线，与纯 LLM 路线形成互补，前者追求极致准确性，后者追求部署可行性。

### 2.3 分布匹配与比较学习评估

除了基于 LLM 的语义理解，另一条路线试图从概率分布的角度解决细粒度评估问题。MSD-Score（Kan et al., 2026, P14）提出了多尺度分布评分框架，通过建模图像补丁和文本 token 嵌入的概率分布，测量分布级差异。该方法提升了评估对细微语义错误（如缺失属性、错误关系、幻觉实体）的敏感性，其代价是计算复杂度较高。MSD-Score 与 CLIPScore 的本质差异在于，前者关注局部分布的匹配程度，后者关注全局向量的相似度，这使得 MSD-Score 在长文本和密集描述场景中更具优势。

Comparative Learning（Minni et al., 2026, P9）则从比较学习的角度切入，通过比较两个图像-文本对的相对偏好来学习评分函数。该方法解决了传统数值评分方法中个体解释尺度不一致的问题，提升了评分的可靠性。其代价是需要成对比较数据，数据收集成本较高。这一路线与分布匹配路线的关联在于，二者都试图超越单一标量分数，通过更丰富的信号（分布或偏好）来捕捉字幕质量的细微差异，为后续强化学习中的奖励设计提供了基础。

### 2.4 强化学习驱动的生成优化

评估指标的最终归宿是指导生成。传统监督微调（SFT）受限于参考数据的偏差和不完整性，容易导致语言多样性坍缩。强化学习结合可验证奖励（RLVR）成为突破这一局限的关键。CapRL（Xing et al., 2025, P2）通过解耦的两阶段过程，利用 LVLM 生成描述并通过 LLM 验证多选题来提供奖励，解决了 SFT 依赖昂贵人工标注的问题。CCCaption（Tang et al., 2026, P10）进一步引入了双奖励机制，通过显式捕捉描述的完整性和正确性来优化生成模型，将描述分解为原子语义事实，计算完整性和正确性分数作为奖励信号。

RubiCap（Huang et al., 2026, P11）则通过自动合成样本特定的评估标准来指导密集描述生成，利用教师模型共识生成细粒度的评估规则，解决了 SFT 导致的语言多样性坍缩问题。BalCapRL（Ye et al., 2026, P15）识别了现有 captioning-RL 方法的系统性偏差，即在一个维度上的增益可能导致其他维度的回归，因此整合了正确性、完整性、可指称性和语言分数来优化描述生成。ClaimDiff-RL（Li et al., 2026, P16）将奖励粒度细化到局部视觉声明，通过验证演员-参考视觉差异并组合类型化错误来生成奖励，显式处理幻觉-覆盖权衡。这些方法共同构成了评估-生成闭环的核心，评估指标不再仅是事后打分，而是作为实时奖励信号直接介入生成过程。

### 2.5 差异描述与生成架构优化

图像差异字幕生成（IDC）是字幕生成的一个特殊子任务，旨在描述图像对之间的视觉差异。Adversarial Preference Optimization（EMNLP 2025, P24）将 IDC 任务形式化为成对偏好优化问题，通过对比相似图像对的描述，提升模型对细微视觉变化的感知能力。DiffCap-Bench（Wei et al., 2026, P13）和 C3-Bench（Kim et al., 2026, P19）则构建了针对 IDC 的细粒度基准，前者通过密集的差异列表和 LLM-as-a-Judge 框架评估描述的完整性和忠实性，后者通过定义明确的变化上下文和标准，评估模型对视觉变化的开放端描述能力。

在生成架构优化方面，Continual Learning（Taetz and Bordelius, 2025, P4）通过改进图像-文本对齐的持续学习框架，利用多目标训练信号缓解灾难性遗忘，使描述系统能够增量扩展理解。NN-Caption（Jesani et al., 2025, P7）探索了基于 LLM 的神经架构搜索管线，通过生成可运行的图像描述模型来自动化架构设计。Adjudicated Captioning（Tran Thanh et al., 2026, P21）则提出了多智能体对齐评分与共识蒸馏束仲裁框架，用于严格零样本图像描述，通过多智能体协作和对齐评分，提升零样本描述的质量和一致性。这些工作展示了生成模型在架构层面的创新，从单一模型训练转向多智能体协作与自动化设计，进一步拓展了字幕生成的边界。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

传统基于词汇重叠的指标与人类判断的相关性显著低于基于预训练视觉-语言模型或 LLM 的指标，这一共识在多个基准上被反复验证：DISCODE 的 58.4 与 Pearl 的 57.9 均大幅超越 CIDEr 的 43.6 和 CLIP-S 的 51.1（支撑证据：P6、P8）。无参考评估是解决参考数据偏差和稀缺性的关键方向，CLIPScore 及其变体已成为该领域的标准基线，但需进一步解决长文本和细粒度评估的局限性（支撑证据：P1、P17）。字幕生成中的幻觉和遗漏是核心质量问题，评估指标需同时衡量精确率和召回率，而非单一的整体分数，这一共识在 CCCaption 和 BalCapRL 的双奖励设计中得到体现（支撑证据：P10、P15）。密集字幕已成为 MLLM 时代的主流生成形式，其评估需关注细粒度细节的特异性，SPECS 在 sDCI 基准上的表现验证了这一点（支撑证据：P1）。强化学习结合可验证奖励是突破 SFT 局限、提升字幕生成质量的有效途径，CapRL 和 CCCaption 的实验结果支持了这一观点（支撑证据：P2、P10）。

与此相关的另一个共识是评估指标的鲁棒性需通过语义不变性进行审计，Invariance Audit 揭示了指标在细微语义变化下的敏感性，可能导致模型选择偏差（支撑证据：P18）。图像差异字幕生成的评估需从整体场景描述转向差异列表的细粒度匹配，DiffCap-Bench 和 C3-Bench 的构建填补了这一空白（支撑证据：P13、P19）。这些共识共同构成了当前领域的方法论基础，但也暴露了现有指标在极端场景下的不足。

### 3.2 观点分歧

LLM-as-a-Judge 的准确性与效率及中立性之间的权衡是领域内最显著的分歧。观点 A 认为 LLM 评估器在细粒度事实核查上优于传统指标，应作为金标准；观点 B 认为 LLM-free 或蒸馏模型在效率和中立性上更优，且性能差距在缩小。现有证据偏向混合/蒸馏方案：在 LongCap-Arena 上，VELA（LLM-based）得分 70.8，而 SPECS（CLIP-based）仅 63.9，显示 LLM 在长文本上的优势；但在 Flickr8K-Expert 上，DISCODE（LVLM-based 但自适应）和 Pearl（LLM-free）表现接近（58.4 vs 57.9）。SugarCrepe 上 BEiTScore（88.6）远超 SPECS（58.8），说明交叉编码器在组合性错误检测上可能优于纯 CLIP 对比。这一分歧的背后，是另一个更根本的争论：全局语义对齐与细粒度事实/分布匹配孰优孰劣。证据强烈偏向细粒度方法，在 DocENT 上，MSD-Score（0.92）优于 VELA（0.88），表明在涉及细节和错误的场景中，细粒度方法具有决定性优势。然而，细粒度方法计算成本高，且在短文本或简单场景下可能过拟合噪声，如何动态切换全局与细粒度评估策略尚无定论。

基于相似度的评估与基于效用（下游任务）的评估之间的分歧同样存在。观点 A 认为字幕质量应通过其与图像的相似度/事实一致性衡量；观点 B 认为字幕质量应通过其在下游任务中的效用衡量。CaptionQA 和 CAPEval 展示了效用评估的新视角，但缺乏大规模 SOTA 对比。传统相似度指标在 Flickr8K 等基准上仍有广泛使用，说明其惯性强大。效用评估依赖 QA 模型的性能，QA 模型本身的偏差会污染评估结果，且“效用”的定义因应用场景而异，难以建立通用基准。这一分歧的根源在于评估目标的根本差异：前者关注“描述是否准确”，后者关注“描述是否有用”。

### 3.3 其他开放问题

最紧迫的工程问题是 LLM 评估的推理速度优化。当前 LLM 评估器的推理延迟限制了其在大规模模型开发和实时反馈中的应用，Rigel 和 DISCODE 通过蒸馏和自适应解码提供了初步解决方案，但尚未完全解决效率与准确性的平衡。最根本的研究问题是奖励信号的细粒度分解与奖励黑客的防范。在 RLVR 中，如何设计细粒度的奖励信号以避免模型利用评估指标的漏洞（奖励黑客）是一个关键挑战。ClaimDiff-RL 通过视觉声明比较细化奖励粒度，但如何确保奖励信号的鲁棒性仍需进一步研究。此外，评估指标的语义不变性审计揭示了现有指标对无关表面特征的敏感性，如何量化和缓解非语义敏感性，防止模型排名反转，是提升评估公平性的关键。

归纳“已知—争议—未知”认知图谱：已知的是语义对齐优于词汇重叠，细粒度评估优于全局评估；争议的是 LLM 与 LLM-free 的优劣，相似度与效用评估的取舍；未知的是如何构建统一的效率-准确性-中立性三维评测基准，以及如何设计鲁棒的细粒度奖励信号。发展趋势将指向评估与生成的深度耦合，以及向更真实、更复杂场景（如差异描述、持续学习）的扩展。

## 4. 总结与展望

图像字幕领域已跨越“生成像人一样说话”的阶段，进入“生成像专家一样准确且丰富”的新阶段。核心任务已从单纯的文本生成转变为构建一个自我校正的评估-生成生态系统，其中评估指标不仅是裁判，更是教练。这一转变源于生成模型的丰富度追求与事实准确性之间的张力，传统 SFT 范式无法同时满足两者，而 RLVR 通过可验证奖励提供了新的优化路径。当前核心瓶颈在于评估指标的特异性、鲁棒性与效率之间的平衡，以及奖励信号的细粒度分解与防作弊机制。

未来可能突破的方向包括：开发能够处理长文本（超过 77 token）的评估指标，以解决传统 CLIP-based 模型在长字幕评估中的上下文窗口限制问题；设计能够区分覆盖率和精确率的解耦评估框架，以解决单一标量指标无法反映字幕质量不同维度的问题；构建能够评估字幕在下游任务中实用性的基准，以解决传统指标仅关注字幕与图像相关性而忽略其实际用途的问题。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，系统性地评测现有评估指标的特异性与鲁棒性，并探索基于效用（QA）的评估方法在真实应用场景中的有效性，以填补当前评测体系的空白。
