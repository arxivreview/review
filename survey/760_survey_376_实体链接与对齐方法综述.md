## 导读

实体链接与对齐（Entity Linking and Alignment, EL/EA）旨在解决异构数据源中实体识别与跨库映射问题，其核心价值在于消除知识图谱（KG）间的异构性并支撑信息检索。早期研究依赖知识表示学习（KRL），通过低维向量空间建模实体关系，但受限于种子数据依赖及深层语义捕捉不足。随着大语言模型（LLM）的引入，领域范式从“嵌入相似度计算”转向“基于推理与生成的决策”，显著提升了复杂歧义场景下的性能。然而，LLM 的黑盒性与高昂计算成本引发了新的研究焦点，即如何在保持推理优势的同时实现可解释性与效率平衡。当前研究正通过多智能体协作、基础模型构建及自适应路由等技术路径，探索鲁棒且可扩展的实体统一框架。各路线在精度、效率与可解释性之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义推理的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

实体链接与对齐领域的核心驱动力源于知识图谱构建、信息检索及多模态数据融合的迫切需求。实体对齐（Entity Alignment, EA）旨在识别不同 KG 中指向同一现实世界对象的实体，是知识融合的基础组件；实体链接（Entity Linking, EL）则将非结构化文本中的提及映射到知识库中的标准实体，包含提及检测与消歧两个子任务。两者在底层逻辑上互补但侧重不同：EL 侧重非结构化文本到结构化知识库的映射，EA 侧重结构化 KG 间的映射。尽管任务对象不同，两者共享“候选生成-重排序”的核心流程，候选生成决定召回率上限，重排序决定精度上限。这种结构相似性使得针对某一任务的技术突破往往能迁移至另一任务，但也导致两者在方法演进上逐渐融合，共同面临推理效率与可解释性的挑战。

问题的形式化定义随技术约束的变化而动态变形。早期问题定义为“结构-语义联合匹配”，核心挑战是跨库异构性，方法依赖预训练语言模型融合结构与语义，但仍属判别式打分。2023-2024 年，随着 LLM 的引入，问题定义转向“复杂歧义下的推理决策”，核心挑战变为如何利用 LLM 的上下文理解能力处理模糊实体，范式从“相似度计算”转向“生成式推理”。2025-2026 年，问题定义进一步演化为“可解释、高效且鲁棒的统一框架”，核心挑战聚焦于 LLM 的黑盒性、计算效率（Token 消耗）以及零样本泛化能力。这一演化过程反映了领域从追求“匹配精度”向追求“决策质量与透明度”的重心转移。

子问题之间的依赖关系决定了方法设计的优先级。候选生成阶段需从大规模知识库中检索潜在匹配实体，其召回率直接限制最终链接的上限；重排序阶段则需对候选集进行精细打分或推理，以区分语义相似但非对齐的实体。在 LLM 时代，重排序阶段的语义理解能力成为瓶颈，但 LLM 的引入也带来了新的效率瓶颈。例如，LLM 处理大量三元组或候选实体时 Prompt 过长，导致推理成本高且易受噪声干扰。因此，当前研究不仅关注如何提升重排序精度，更关注如何通过自适应路由、稀疏化候选筛选来优化整体效率。

约束演化史揭示了方法因应技术瓶颈而演变的轨迹。2017-2018 年，MTransE 和 BootEA 奠定了基于嵌入投影与自举学习的基线，解决了早期方法无法处理跨语言结构差异及种子稀疏的问题。2020 年，BLINK 提出零样本实体链接框架，证明了预训练语言模型在 EL 任务中的通用性，推动了从监督学习向零样本范式的转变。2023 年，ChatEA 开创了 LLM 直接参与 EA 决策的新范式，突破了传统嵌入方法在语义细微差别上的局限。2025-2026 年，ProLEA、EA-Agent 和 EAFM-Struct 等工作致力于解决 LLM 的黑盒决策问题，并探索跨 KG 的零样本泛化能力，标志着领域进入可解释性与基础模型构建阶段。

当前，该领域处于高度活跃阶段，研究热点集中在多模态对齐、低资源场景下的自适应链接、以及结合检索增强生成（RAG）以缓解 LLM 幻觉的技术路径上。多模态实体对齐需解决模态间干扰及跨模态语义鸿沟，低资源场景需利用合成上下文或零样本适应提升性能。这些子问题的解决依赖于对核心约束的重新审视：如何在保证计算效率与决策可解释性的前提下，利用 LLM 的深层语义推理能力，解决异构数据源中实体识别与跨库映射的复杂歧义及零样本泛化难题。

**如果用一个核心问题概括该领域，那便是：如何在保证计算效率与决策可解释性的前提下，利用大语言模型的深层语义推理能力，解决异构数据源中实体识别与跨库映射的复杂歧义及零样本泛化难题。**

## 2. 方法体系

- 2017：MTransE——提出多语言知识图谱对齐的平移模型，奠定跨语言对齐范式

- 2018：BootEA——提出基于自举的实体对齐方法，缓解种子稀疏导致的泛化不足

- 2020：BLINK——提出零样本实体链接框架，推动 EL 任务向零样本范式转变

- 2023：ChatEA——提出基于 LLM 的实体对齐方法，开创 LLM 直接参与 EA 决策的新范式

- 2025：ProLEA——提出实体画像生成与推理框架，实现可解释性与准确性的平衡

- 2026：EA-Agent——提出结构化多步推理 Agent，实现透明化的实体对齐决策

- 2026：RULE——提出双层级噪声对应学习框架，解决多模态实体对齐中的噪声对应问题

这条时间线勾勒了该领域方法演进的代表性节点：从 2017 年的 MTransE 奠定该领域方法基线，经 2018 年 BootEA 的推进，到 2026 年的 RULE 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 LLM驱动实体对齐

LLM 驱动实体对齐路线的起源可追溯至 2023 年 ChatEA 的提出，该方法利用 LLM 的语义理解能力对候选实体进行推理与决策，突破了传统嵌入方法在语义细微差别上的局限。然而，ChatEA 的黑盒决策问题导致错误难以定位，且 Token 消耗巨大。2025 年，ProLEA（P23）针对这一痛点，提出实体画像生成与推理框架，首先利用 LLM 从异构 KG 中提取实体名称、关系、属性及描述，生成结构化的实体画像以增强语义表示。随后引入阈值机制解决 LLM 预测与嵌入模块候选之间的冲突，若 LLM 确认候选则接受，若高置信度拒绝则丢弃，低置信度则保留原候选。该方法通过置信度评分动态调整对齐结果，避免了 LLM 幻觉导致的错误对齐，同时保留了嵌入模型的鲁棒性。其核心创新在于将 LLM 作为验证器而非唯一决策者，实现了生成式推理与判别式嵌入的互补。ProLEA 在异构数据集上展现了强大的泛化能力，为 LLM 与 KRL 方法的融合提供了新的架构范式。

2026 年，EA-Agent（P22）进一步解决了传统 LLM-based EA 方法的黑盒问题，提出结构化多步推理 Agent 框架，通过显式的工具路径规划实现实体对齐的透明化决策。该方法包含属性三元组选择器、关系三元组选择器、实体对齐工具及反思器，Agent 根据奖励信号动态重写工具调用路径以优化推理过程。其核心改进在于通过显式工具调用降低了 Token 消耗，避免了冗余三元组对模型判断的干扰。EA-Agent 依赖奖励信号进行路径优化，牺牲了部分推理速度以换取更高的可解释性与稳定性。AgentEA（P20）则从多智能体协作角度切入，提出两阶段多智能体辩论框架，旨在通过多角色交互增强候选实体的区分能力。第一阶段进行轻量级辩论验证，快速筛选高置信度候选；第二阶段进行深度辩论对齐，由多个智能体独立分析候选实体并由法官角色进行裁决。该方法通过辩论机制解决语义相似但非对齐实体的混淆问题，利用多视角推理弥补单一 LLM 判断的局限性。其核心取舍在于增加了推理轮次与计算成本，以换取在复杂歧义场景下更高的对齐可靠性。

EAFM-Struct（P14）则代表了基础模型构建方向，提出利用结构上下文的实体对齐基础模型，通过轻量级编码器-解码器管道实现跨 KG 的可迁移对齐。该方法首先学习关系感知的结构表示，实例化锚点桥接并在统一图上进行跨 KG 传播，获取丰富的实体表示。随后通过粗匹配器检索 Top-k 候选，并利用结构校准解码器结合实体级、邻域级、关系级及锚点感知证据进行验证。其核心创新在于将结构校正项加入粗匹配分数，提升了模型对未见 KG 的泛化能力。该方法依赖于锚点条件并行编码，假设源 KG 与目标 KG 存在结构相似性，但在高度异构场景下可能受限。LM-Driven EA Survey（P21）系统综述了 LLM 驱动的实体对齐方法，梳理了从伪种子生成到增强编码的技术演进，明确了 LLM 在特征提取、结构统一及决策推理中的不同角色，为后续研究提供了基准与未来方向。

### 2.2 多模态实体对齐

多模态实体对齐路线旨在解决包含文本、图像等多模态属性的 KG 对齐任务，需解决模态间干扰及跨模态语义鸿沟。2026 年，RULE（P1）提出双层级噪声对应学习框架，旨在解决多模态实体对齐中属性对应噪声问题。该方法首先进行可靠性估计与对划分，将对应关系分为可靠与噪声两类，随后执行鲁棒属性融合与差异消除。其核心创新在于引入测试时对应推理模块，利用多模态大模型挖掘跨图属性间的潜在连接，弥补训练时对应缺失。该方法依赖于多模态大模型的推理能力，牺牲了部分推理速度以换取对噪声数据的鲁棒性。RULE 在 ICEWS-WIKI 等数据集上显著优于基线，证明了测试时推理在多模态对齐中的价值。

MyGram（P5）则从图结构建模角度切入，提出模态感知图 Transformer 框架，利用全局分布学习多模态实体对齐。该方法包含多模态特征提取、模态感知扩散学习及多模态训练模块，通过 Gram 损失建立等价实体间的对齐。其核心改进在于引入模态感知扩散，将结构上下文信息融入模态特征，缓解了浅层模态特征干扰问题。该方法依赖于图 Transformer 的表达能力，计算复杂度较高，但能捕捉长距离依赖。MyGram 在多个多模态基准上表现优异，证明了图结构建模在多模态融合中的重要性。与 LLM 驱动路线相比，多模态路线更侧重于特征融合机制的设计，而非推理决策的透明化，两者在解决噪声与歧义问题上形成互补。

### 2.3 LLM辅助实体链接

LLM 辅助实体链接路线聚焦于利用 LLM 提升 EL 任务的精度与鲁棒性，同时降低计算成本。2025 年，ARTER（P3）提出自适应路由与目标推理框架，利用 LLM 处理实体链接中的困难案例。该方法首先通过传统模型处理简单提及，仅对低上下文或歧义提及路由至 LLM 进行推理，显著降低了计算成本。其核心创新在于自适应路由机制，平衡了精度与效率，避免了 LLM 对所有提及的全量处理。该方法依赖于传统模型的初步筛选，若传统模型召回率低则影响整体性能。ARTER 在多个基准上提升了困难案例的链接精度，证明了混合架构在 EL 任务中的有效性。

AELC（P19）提出自适应实体链接框架，利用 LLM 驱动上下文凝练与任务形式化转换。该方法首先通过 LLM 提取提及的高密度关键信息，随后进行自适应语义融合生成动态候选集，最后将重排序任务转化为多选题以提升精度。其核心改进在于 LLM 驱动的上下文增强，解决了传统方法在低上下文提及上的歧义消解难题。RAED（P16）则针对新兴实体链接问题，提出检索增强实体描述生成框架，从知识库检索相关文本段落作为上下文，辅助生成器产生基于事实的实体描述，从而支持对未见实体的链接。其核心创新在于检索增强机制，缓解了 LLM 训练数据滞后导致的知识缺失问题。LELA（P12）提出端到端 LLM 实体链接框架，支持零样本领域适应，整合了最先进的提及检测与实体消解组件，利用 LLM 原生架构处理复杂歧义，无需针对特定领域微调。Contextual Augmentation EL（P2）提出基于 LLM 的上下文增强实体链接方法，利用 LLM 进行实体识别扩展与描述生成，解决了传统 NER 模型在复杂语境下的识别不足问题。

### 2.4 垂直领域实体链接

垂直领域实体链接路线针对生物医学、跨语言及表格等特定领域，解决数据稀缺、术语歧义及跨语言对齐挑战。2026 年，PILOT（P15）提出邻域感知双生物医学实体链接框架，结合表面形式与上下文重排序。该方法首先利用本体论邻域池化增强检索召回，随后通过表面形式重排序器提升词汇精度，上下文重排序器消解歧义，最后进行分数融合。其核心改进在于邻域感知检索，解决了大规模 KB 中实体表面形式匹配不足的问题。LLM4BioEL（P18）提出基于限制性解码与对比解码的生物医学实体链接框架，利用限制性解码确保生成有效实体 CUI，通过熵基对比解码融入外部生物医学知识，无需额外微调。其核心创新在于解码约束机制，解决了 LLM 直接应用时产生无效实体或幻觉的问题。

BioELX（P13）提出上下文感知跨语言生物医学实体链接框架，无需任务特定监督，利用跨语言 Wikidata 别名扩展检索监督，结合上下文感知重排序器消解歧义，支持多语言排名。ThinkLinker（P17）提出多模态实体链接框架，利用低秩交互与知识感知验证，通过低秩融合模块编码多模态提及，随后进行知识感知验证，利用候选实体信息重新分析原始上下文。SynCABEL（P6）提出合成上下文增强生物医学实体链接框架，利用合成数据解决标注稀缺问题，通过自适应方法选择概念最合适的同义词作为目标输出，利用合成上下文增强训练数据。

### 2.5 实体匹配与消解

实体匹配与消解路线研究低资源实体匹配、大规模实体消解及跨系统知识对齐，关注数据质量、噪声处理及查询条件对齐。2026 年，Alper（P11）提出自适应图细化与标签传播框架，利用 LLM 在预算约束下优化脏实体消解。该方法通过迭代更新图拓扑与聚类标签，利用 LLM 进行成对匹配查询，结合图逻辑强制传递一致性。其核心创新在于动态图更新机制，解决了静态分块导致的聚类不完整与噪声问题。OpenSanctions Pairs（P7）提出大规模实体匹配基准与 LLM 评估框架，涵盖异构 Schema 与多语言数据，揭示了 LLM 与规则方法的互补失败模式。QCEA（P9）提出查询条件知识对齐框架，用于跨系统医学推理，构建查询表示，学习 TCM 与 WM 实体表示，通过方向感知 Tucker 投影映射到共享空间。Prompt-Attrib（P8）提出属性引导提示调优低资源实体匹配框架，设计 EM 特定提示模板与标签词，利用 P-tuning 连续提示嵌入模型空间，通过属性引导增强匹配精度。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域最核心的共识在于传统基于嵌入的 KRL 方法在深层语义理解和复杂歧义消解上存在局限，难以区分语义相似但非对齐的实体，这一观点在约 15 篇论文中得到共同支持。LLM 凭借其强大的上下文建模和推理能力，显著提升了实体链接和对齐在复杂、模糊场景下的性能，成为当前主流技术路线，约 12 篇论文共同支持这一结论。与此相关的另一个共识是实体链接任务通常分解为候选生成和重排序两个阶段，且两阶段的协同优化对最终性能至关重要，约 10 篇论文共同支持。多模态信息能有效辅助文本实体消歧，但需解决模态间的噪声干扰和融合策略问题，约 6 篇论文共同支持。检索增强（RAG）或外部知识注入是缓解 LLM 幻觉、处理新兴实体及提升事实准确性的有效手段，约 8 篇论文共同支持。跨 KG 对齐正从“特定对拟合”向“可迁移的基础模型”范式转变，强调零样本泛化能力，约 5 篇论文共同支持。生物医学实体链接面临大规模知识库和术语歧义挑战，需要结合领域本体结构和上下文感知的专用模型，约 7 篇论文共同支持。低资源场景下，利用 LLM 进行提示工程、合成数据增强或零样本适应是提升性能的关键方向，约 6 篇论文共同支持。

### 3.2 观点分歧

LLM 在实体对齐中的角色存在显著分歧：观点 A（ChatEA, LLM4EA）认为 LLM 具备足够的语义理解能力，可直接作为决策者，无需依赖嵌入模块；观点 B（ProLEA, ARTER）认为 LLM 应作为验证器或仅处理困难案例，需与嵌入模型或传统方法混合使用。现有证据偏向观点 B，ProLEA 在异构数据集上泛化能力更强，ARTER 在保持精度的同时显著降低了 Token 消耗，纯 LLM 方法在噪声数据和高度异构场景下表现不稳定，幻觉问题严重。这一分歧的背后，是另一个更根本的争论：结构信息在 LLM 时代的价值。观点 A（EAFM-Struct, MyGram）认为结构上下文对零样本迁移和多模态融合至关重要，LLM 无法完全内化结构知识；观点 B（纯 LLM 方法）认为 LLM 通过预训练已内化了大量结构知识，显式结构建模可能引入噪声或限制泛化。现有证据偏向观点 A，EAFM-Struct 在未见 KG 上表现优异，MyGram 在多模态基准上显著优于纯文本方法，结构信息在解决跨 KG 异构性方面具有不可替代的作用。

### 3.3 其他开放问题

当前领域面临工程与研究双重挑战。最紧迫的工程问题是 LLM 推理成本高、延迟大，难以应用于大规模知识图谱，研究界正尝试模型蒸馏、高效 LLM 架构、自适应阈值策略以及 token 压缩技术，以降低推理成本并提高实时性。最根本的研究问题是 LLM 决策的黑盒性与不可解释性，现有 LLM-based EA 方法直接输出结果，缺乏推理路径，导致错误难以定位和修正，当前研究通过多智能体辩论或工具调用路径规划来提升透明度。此外，跨 KG 异构性与零样本泛化能力不足仍是核心难题，传统方法依赖特定 KG 对的结构和种子，难以迁移至结构差异巨大的新 KG，当前研究通过构建 EA 基础模型和相对结构模式学习来增强泛化性。多模态属性融合中的模态干扰与噪声、低资源与新兴实体的链接难题、大规模知识库下的计算效率与 Token 消耗、跨语言与低资源语言的语义对齐偏差、生物医学领域的术语歧义与本体层级复杂性、脏数据环境下的实体消解等问题，均需进一步探索。已知—争议—未知认知图谱显示，LLM 提升精度是已知共识，LLM 角色与结构信息价值是争议焦点，可解释性量化指标与动态知识持续学习是未知领域。

## 4. 总结与展望

实体链接与对齐领域正处于从“模式匹配”向“认知推理”转型的关键期。核心矛盾在于 LLM 带来的精度提升与其高昂计算成本、黑盒决策之间的矛盾。早期研究依赖 KRL 解决结构匹配，中期引入 PLM 提升零样本能力，当前 LLM 驱动方法通过牺牲效率换取深层语义理解与可解释性。核心瓶颈在于如何在保持 LLM 推理优势的同时，解决计算效率与决策透明度的矛盾，实现鲁棒、可扩展且透明的实体统一框架。

未来可能突破的方向包括：提升 LLM 在实体对齐中的计算效率与可扩展性，通过模型蒸馏、高效 LLM 架构、自适应阈值策略以及 token 压缩技术降低推理成本；增强实体对齐的鲁棒性与噪声处理能力，探索基于 LLM 的语义推理、多智能体辩论、噪声对应关系建模以及鲁棒融合策略；发展可解释与透明的实体对齐方法，通过结构化多步推理、工具调用、反思机制以及辩论框架提高对齐决策的可解释性和可追溯性。对进入者而言，最值得做的一件事是在统一骨干与统一预训练条件下，构建包含噪声、稀疏、高度异构知识图谱的新基准，并开发量化可解释性与鲁棒性的评测协议，以解决当前评测体系饱和与场景单一的问题。
