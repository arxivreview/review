# A Survey of LLM Jailbreak Attacks and Defenses ｜LLM 越狱攻防综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/LLM%20Jailbreak%20Attacks%20and%20Defenses)

## 导读

大语言模型（LLM）在医疗与金融等关键领域的广泛部署，使其强大的生成能力与严重的滥用风险并存，安全对齐（Safety Alignment）因此成为核心议题。早期研究依赖静态规则过滤，但面对精心构造的对抗性输入显得脆弱，2023 年以 GCG 为代表的白盒梯度优化攻击和 PAIR 等黑盒自动化红队测试的出现，标志着该领域从静态防御向动态对抗的范式转变。这一转变揭示了安全对齐的“浅层性”本质，即模型仅在表面特征上表现出拒绝行为，而在深层推理中仍可能泄露有害内容。随后，研究重心迅速转向多轮对话攻击、内部表示干预以及基于推理的安全对齐，试图在模型内部建立更深层的语义约束。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从外部护栏到内部机制的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

LLM 安全对齐领域的兴起源于大语言模型在关键领域的广泛部署，其核心矛盾在于模型强大的生成能力与严重的滥用风险之间的张力。早期研究主要依赖基于规则的内容过滤和简单的提示工程，旨在建立模型的行为边界，但面对精心构造的对抗性输入显得脆弱。这种静态防御机制的失效，促使研究者重新审视安全对齐的本质，即模型如何从极少量样本或特定提示中习得拒绝行为，以及这种习得是否具备深层语义基础。

问题的形式化可以定义为：给定一个对齐后的 LLM $M$ 和一个有害意图集合 $\mathcal{H}$，攻击者旨在构造输入 $x \in \mathcal{X}$，使得 $M(x)$ 生成有害输出 $y \in \mathcal{H}$，而防御者旨在最小化攻击成功率（ASR）同时保持模型在良性任务上的效用。这一形式化揭示了子问题间的依赖关系：内部机制的可解释性是理解浅层对齐脆弱性的基础，也是实现精准推理时干预的前提；多轮动态防御依赖于意图漂移检测，而安全-效用权衡则贯穿所有防御路线，构成约束其他子问题解决方案的核心边界。

2023 年是该领域的奠基期，GCG 通过梯度引导的贪心坐标下降算法优化离散 token 后缀，将越狱攻击形式化为离散文本空间的搜索问题，显著提升了自动化攻击的效率与成功率。同年，PAIR 采用攻击者 LLM 与目标 LLM 迭代交互的自动化红队测试框架，实现了黑盒场景下的高效自动化攻击，成为黑盒攻击领域的代表性工作。这一时期的研究主要聚焦于单轮静态输入下的对抗鲁棒性，揭示了静态防御的脆弱性。

2024 年，Crescendo 通过多轮对话渐进式渗透，将恶意意图分散在看似无害的对话轮次中，逐步绕过安全对齐机制。该攻击揭示了单轮防御在多轮交互中的脆弱性，推动了多轮动态防御研究的发展。同年，JailbreakBench 构建了标准化的越狱攻击鲁棒性评估基准，统一了攻击成功率的评估协议，解决了此前评估方法不一致的问题。SafeDecoding 则在解码阶段引入安全前缀引导，展示了推理时干预在保持模型效用同时提升安全性的潜力。

2025 年至 2026 年，随着推理模型（RLMs）的普及，领域进入深水区。ARMOR 通过细致推理提取用户核心意图，分析提示中嵌入的越狱策略，实现了意图级安全对齐，解决了浅层对齐仅依赖表面特征的问题。SoK Causality Framework 构建了统一的因果分析框架，支持从 token 级到表示级的多层级因果干预实验，系统化了 LLM 安全漏洞的因果机制研究。NeuronGuard 通过消融感知的安全信号重分布，将安全拒绝行为从关键神经元分散到更广泛的网络结构中，提升了模型对神经元级攻击的鲁棒性。

当前，该领域处于高度活跃期，核心驱动力在于构建能够抵御自适应攻击、兼顾安全性与实用性的鲁棒对齐机制。研究范式正从外部护栏向模型内在的“安全直觉”和深层语义意图识别演进，内部机制的可解释性成为突破浅层对齐瓶颈的关键。

**如果用一个核心问题概括该领域，那便是：如何在模型内部复杂语义表征与外部对抗性输入之间，建立一种既能抵御自适应攻击、又能保持通用能力且具备因果可解释性的深层安全对齐机制。**

## 2. 方法体系

- 2023：GCG——通过梯度引导的贪心坐标下降算法优化离散token后缀，生成具有强泛化性的通用对抗提示词。

- 2023：PAIR——采用攻击者LLM与目标LLM迭代交互的自动化红队测试框架，通过反思与重写机制生成高成功率的黑盒越狱提示。

- 2024：Crescendo——通过多轮对话渐进式渗透，将恶意意图分散在看似无害的对话轮次中，逐步绕过安全对齐机制。

- 2024：SafeDecoding——在解码阶段引入安全前缀引导，通过约束初始token生成激活模型内部安全机制，无需修改模型权重即可阻断越狱。

- 2025：ARMOR——通过细致推理提取用户核心意图，分析提示中嵌入的越狱策略，实现意图级安全对齐。

- 2025：SoK Causality Framework——构建了统一的因果分析框架，支持从token级到表示级的多层级因果干预实验。

- 2025：NeuronGuard——通过消融感知的安全信号重分布，将安全拒绝行为从关键神经元分散到更广泛的网络结构中。

- 2026：TripWire——通过统计认证的安全神经元触发对齐拒绝，利用神经元激活的统计特性实现精准干预。

这条时间线勾勒了该领域方法演进的代表性节点：从 2023 年的 GCG 奠定该领域方法基线，经 2024 年 Crescendo 的推进，到 2026 年的 TripWire 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 攻击策略与自动化生成

攻击策略的演进始于对静态防御失效的回应。GCG（Zou et al., 2023）通过梯度引导的贪心坐标下降算法优化离散 token 后缀，将越狱攻击形式化为离散文本空间的搜索问题，显著提升了自动化攻击的效率与成功率，成为后续大量白盒攻击研究的基线。然而，GCG 生成的内容语义混乱且易被检测，AutoDAN（Liu et al., 2023）利用分层遗传算法生成可读性更高的对抗后缀，引入了语义约束与可读性优化，推动了攻击方法从纯字符优化向语义级优化的演进。

黑盒攻击的兴起源于对真实 API 调用场景的模拟需求。PAIR（Chao et al., 2023）采用攻击者 LLM 与目标 LLM 迭代交互的自动化红队测试框架，通过反思与重写机制生成高成功率的黑盒越狱提示，无需访问模型内部参数，实现了黑盒场景下的高效自动化攻击。RAILS（Nurlanov et al., 2026, P22）进一步提出无梯度、无先验的随机迭代局部搜索框架，利用模型 logits 引导随机局部扰动来迭代精炼候选字符串，摆脱了对梯度访问和手工设计先验的依赖，提升了黑盒攻击的普适性。

多轮攻击与智能体框架代表了攻击策略的最新趋势。SEMA（ICLR 2026, P53）设计了一种简单有效的多轮越狱攻击学习框架，采用响应无关的开环生成以降低探索复杂度，引入在线强化学习机制并结合预填充自调优技术，针对多轮交互中常见的意图漂移问题整合了意图漂移感知奖励的强化学习策略。Metis（Zhou et al., 2026, P45）提出基于自演化元认知策略优化的越狱框架，将 LLM 越狱交互建模为对抗性部分可观测马尔可夫决策过程，引入元认知机制使攻击者能够反思自身策略并动态调整高层推理策略，提升了攻击的长期规划能力与适应性。

攻击策略与推理增强对齐之间存在竞争与互补关系：攻击策略旨在突破防御，而推理增强对齐旨在提升防御的深层语义理解能力，二者共同推动了安全对齐从行为约束向逻辑推理的转变。

### 2.2 推理增强安全对齐

推理增强安全对齐旨在解决浅层对齐的脆弱性问题，通过深度推理能力提升模型对复杂越狱策略的识别能力。ARMOR（ICLR 2026, P52）通过细致推理对齐安全与大型语言模型，在推理过程中提取用户核心意图，分析提示中嵌入的潜在越狱策略，从而更准确地识别风险。其核心模块包括意图提取器与安全推理链，前者负责从复杂提示中剥离表面修饰，后者基于提取的意图进行逻辑校验。ARMOR 的主要改进在于将安全决策从表面特征匹配提升至语义意图理解层面，增强了模型对复杂越狱策略的鲁棒性。

STAR-S（Wu et al., 2026, P23）通过自教推理安全规则提升安全对齐，构建了一个自教框架以增强模型基于安全规则的推理能力。该方法包含推理生成、反思增强与监督微调三个阶段，首先让模型基于安全规则生成推理，若失败则提供安全提示引导深度反思，最后利用过滤后的数据进行微调。STAR-S 的主要改进在于将安全规则显式融入推理过程，使模型不仅知道拒绝，还能解释拒绝的原因，提升了防御的可解释性。

SFCoT（Pan et al., 2026, P37）提出通过主动安全评估与校准实现更安全的思维链，旨在解决长思维链中安全防御失效的问题。该方法在推理过程中引入验证器与重写模块，实时评估思维链片段的安全性，并在发现潜在风险时触发重写以修正有害路径。SFCoT 的主要改进在于解决了后处理过滤无法干预中间推理步骤的局限，提升了模型在复杂推理任务中的安全性。

推理增强安全对齐与内部机制研究存在继承关系：内部机制研究揭示了安全对齐的微观结构，为推理增强对齐提供了理论指导；而推理增强对齐则通过深度推理能力实现了更细粒度的安全控制，二者共同推动了安全对齐从行为约束向逻辑推理的转变。

### 2.3 内部机制与可解释性

内部机制与可解释性研究旨在揭示 LLM 安全对齐的内部机制、脆弱性根源及越狱攻击的微观原理。SoK Causality Framework（Zhao et al., 2025, P16）构建了一个综合因果分析框架，用于 LLM 安全研究，支持从 token 级到表示级的多层级因果干预。该框架系统化了因果调查方法，包括神经元级、层级干预与表示级分析，旨在揭示越狱攻击的因果因素。SoK 的主要改进在于填补了因果分析在 LLM 安全领域缺乏统一标准的空白，促进了该方向的规范化发展。

GOSV（Chu et al., 2026, P27）提出通过全局优化归因并利用安全向量，识别传输安全表示的关键注意力头。该方法首先描述多头注意力与激活修补基础，随后设计两种激活重修补策略进行干预，最后通过 GOSV 优化算法全局识别安全向量。GOSV 的主要改进在于提供了精准的安全机制定位，为推理时攻击或防御提供了具体目标。

SABER（Joshi et al., 2025, P3）提出通过跨层残差连接揭示安全对齐漏洞，允许早期层激活注入后期层以绕过安全机制。该方法在层 s 与层 e 之间建立跨层残差连接，通过归一化输出激活并注入后期层，利用缩放因子 $\lambda$ 调节影响。SABER 的主要改进在于提供了一种白盒攻击视角，展示了内部结构修改对安全性的影响，揭示了安全对齐的结构性脆弱性。

内部机制研究与推理时干预存在互补关系：内部机制研究揭示了安全对齐的微观结构，为推理时干预提供了定位依据；而推理时干预则利用这些定位依据实现了轻量级、低延迟的防御，二者共同推动了安全对齐从黑盒到白盒机制的转变。

### 2.4 推理时干预与解码防御

推理时干预与解码防御旨在在不修改模型权重的情况下，通过激活引导、解码约束、潜在空间投影或外部轻量级模块，在推理阶段实时检测并阻断越狱行为。AlignTree（Goren et al., 2025, P12）提出一种高效防御 LLM 越狱攻击的方法，利用 LLM 内部激活状态训练非线性 SVM 与随机森林分类器。该方法提取 token 与层隐藏状态特征，训练 RBF SVM 捕捉非线性关系，再通过随机森林分配有害性置信分数。AlignTree 的主要改进在于提供了低开销的推理时防御，避免了外部过滤器的延迟与成本。

AISA（Song et al., 2026, P32）提出唤醒 LLM 内在安全意识以对抗越狱攻击，通过时空分析定位内在安全信号并激活潜在安全行为。该方法首先通过时空分析定位意图判别信号，发现特定注意力头近最终层的缩放点积输出具有强可分性，随后利用这些信号激活模型内部安全机制。AISA 的主要改进在于避免了昂贵微调与侵入式提示修改，保持了模型效用。

SecDecoding（EMNLP 2025, P58）提出可引导解码以实现更安全 LLM 生成，通过强制安全前缀激活模型内部安全机制，无需修改模型参数。该方法在解码初期注入安全对齐信号，如“抱歉”或“我不能回应”，以引导模型生成拒绝响应，同时保持良性输入的流畅性。SecDecoding 的主要改进在于避免了微调成本，且兼容现有模型，提升了部署灵活性。

推理时干预与训练阶段鲁棒对齐存在继承关系：训练阶段鲁棒对齐旨在从根源消除漏洞，而推理时干预则利用模型内部信号实现动态适应，二者共同构成了全生命周期的安全防御体系。

### 2.5 多轮对话与动态防御

多轮对话与动态防御旨在针对多轮交互中意图渐进式渗透的越狱攻击，研究基于状态跟踪、上下文累积风险检测及动态自适应策略的防御与攻击框架。SafeDream（Yan et al., 2026, P40）提出安全世界模型用于主动早期越狱检测，通过编码 LLM 隐藏状态为紧凑潜在安全状态并学习预测未来安全状态。该方法采用累积和检测聚合弱每轮风险信号为稳健统计证据，并结合对比想象同时预测攻击与良性未来滚动以量化脆弱性。SafeDream 的主要改进在于解决了单轮检测无法捕捉累积风险的问题，提升了多轮交互场景下的防御能力。

CoopGuard（Li et al., 2026, P38）提出有状态协作智能体守护 LLM 对抗演化多轮攻击，通过状态跟踪与上下文累积风险检测实现动态自适应防御。该方法利用多个协作智能体分别负责意图检测、风险累积与响应生成，通过共享状态实现协同防御。CoopGuard 的主要改进在于提升了防御的动态适应性，能够根据对话历史调整防御策略。

BIID（Tong et al., 2025, P4）提出双向意图推理增强 LLM 对多轮越狱攻击的防御，通过双向推理捕捉对话历史中的恶意意图。该方法在对话过程中同时向前与向后推理，结合上下文信息识别隐藏的恶意意图，并触发防御机制。BIID 的主要改进在于提升了多轮意图识别的准确性，增强了防御的鲁棒性。

多轮对话与动态防御与推理增强安全对齐存在互补关系：推理增强安全对齐提升了单轮防御的深层语义理解能力，而多轮动态防御则捕捉了长距离依赖的恶意意图，二者共同构成了多轮交互场景下的完整防御体系。

### 2.6 训练阶段鲁棒对齐

训练阶段鲁棒对齐旨在通过对抗训练、偏好优化、神经元重分布或模型编辑等训练时技术，从根源上增强 LLM 对越狱攻击的鲁棒性并消除潜在安全漏洞。NeuronGuard（Gao et al., 2026, P50）提出通过消融感知安全信号重分布实现鲁棒 LLM 安全对齐，将安全拒绝行为从关键神经元分散到更广泛网络结构。该方法首先通过轻量级线性分类器识别安全关键神经元，随后在微调过程中动态重分布安全信号，避免单点神经元被攻击导致的安全崩溃。NeuronGuard 的主要改进在于解决了传统安全微调中安全信号集中分布的脆弱性问题，实现了安全信号的冗余化。

JPU（Wang et al., 2026, P20）提出通过策略内路径校正桥接越狱防御与遗忘，挖掘策略内对抗样本并重绘越狱路径。该方法首先演化挖掘当前模型最脆弱对抗样本，随后使用这些样本从中间层到深层有害汇点重绘越狱路径，最后执行约束越狱路径校正。JPU 的主要改进在于实现了动态越狱路径的实时校正，提升了模型对未知越狱策略的鲁棒性。

TripWire（Zhao et al., 2026, P49）提出通过统计认证安全神经元触发对齐拒绝，利用神经元激活统计特性实现精准干预。该方法计算神经元在有害、良性与效用任务上的激活均值，排除效用相关神经元，并通过 AUROC 排名选择安全特定神经元。TripWire 的主要改进在于解决了神经元级防御中效用与安全权衡的问题，提供了具有统计保证的轻量级防御。

训练阶段鲁棒对齐与推理时干预存在继承关系：训练阶段鲁棒对齐提供了基础的安全信号分布，而推理时干预则利用这些信号实现动态适应，二者共同构成了全生命周期的安全防御体系。

### 2.7 跨任务与多领域应用

跨任务与多领域应用旨在将 LLM 安全对齐技术应用于多模态、跨语言等复杂场景。Safety Is Not Universal（ACL-Findings 2026, P59）提出揭示 LLM 对齐中选择性安全陷阱的研究，量化人口统计保护在不同语言间的解耦。该研究通过越狱攻击评估模型对特定群体（如女性、LGBTQIA+）的保护，发现模型在英语中表现良好但在葡萄牙语中保护显著下降。该研究的主要改进在于提供了跨语言安全对齐的实证分析，揭示了安全对齐的公平性问题。

跨任务与多领域应用与内部机制研究存在互补关系：内部机制研究揭示了安全对齐的微观结构，为跨任务应用提供了理论指导；而跨任务应用则验证了内部机制在不同场景下的泛化能力，二者共同推动了安全对齐从单模态向多模态的转变。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLM 的安全对齐并非一劳永逸，现有模型在面对自适应或新型攻击时仍表现出显著的脆弱性，需要持续的对抗性训练和动态防御机制。这一共识在多个基准上被反复验证：ACE-Safety 的 0.000 与 ARMOR 的 0.000 均大幅超越经典 SmoothLLM 的 53.52，表明动态防御机制在提升鲁棒性方面的有效性（支撑证据：P15、P52）。

与此相关的另一个共识是，白盒攻击虽然攻击成功率高，但生成的提示词往往具有低可读性，限制了其在真实黑盒场景中的直接应用，而黑盒攻击更贴近现实威胁。RAILS 的 90.2 与 MEEA 的 91.5 在 HarmBench 上的表现，较经典 GCG 的 43.9 有显著提升，表明黑盒攻击在真实场景中的有效性（支撑证据：P22、P18）。

### 3.2 观点分歧

防御重心应置于训练时鲁棒对齐还是推理时内部干预，是领域内的核心争论。训练时派主张通过 NeuronGuard、JPU 等技术从根源消除漏洞，提升模型内在鲁棒性；推理时派主张通过 AlignTree、AISA 等技术利用内部表示进行实时检测与阻断，保持模型灵活性。现有证据偏向推理时干预在轻量级部署和动态适应中的优势，如 AISA 的低开销，但训练时在根本性消除已知漏洞上更具潜力，如 NeuronGuard 的鲁棒性（支撑证据：P50、P32）。这一分歧的背后，是另一个更根本的争论：内部表示干预的普适性与稳定性。支持派认为拒绝子空间等内部表示具有线性可解释性，可实现精准干预；质疑派认为内部表示随模型版本、训练数据分布变化而动态改变，缺乏跨模型泛化性。现有证据显示内部表示在特定模型上有效，但跨模型迁移时效果显著下降，证据强度中等，主要基于单模型实验（支撑证据：P39、P59）。

### 3.3 其他开放问题

最紧迫的工程问题在于多轮对话中的实时状态跟踪与低延迟推理时干预的实现。现状是 SafeDream 和 CoopGuard 等框架已展示了状态跟踪与动态自适应防御的潜力，但关键困难在于上下文管理的复杂度与计算开销，研究路径包括引入更轻量级的状态编码与预测机制。最根本的研究问题在于推理模型中恶意意图在思维链中的隐蔽性检测。现状是 SFCoT 和 REFLECTOR 等方法已展示了步骤级安全评估与反思机制内化的潜力，但关键困难在于区分良性推理与恶意推理路径，研究路径包括基于因果推断的深层意图解耦与神经元级统计认证干预。

已知—争议—未知认知图谱显示，领域在浅层对齐脆弱性、多轮攻击威胁、内部表示防御鲁棒性上已形成共识，但在防御重心、内部表示普适性、黑盒与白盒评估价值上存在争议，而在推理模型安全、跨模型泛化性、细粒度风险校准上仍属未知。发展趋势是结合内部机制可解释性与推理时干预，构建自适应、可解释且高效的鲁棒安全 LLM。

## 4. 总结与展望

LLM 安全对齐的核心矛盾在于浅层对齐的脆弱性与深层意图识别的复杂性，这一矛盾驱动了从静态规则过滤到动态对抗防御，再到机制级精准干预的范式转变。尝试过的路线包括攻击策略自动化、推理增强安全对齐、内部机制可解释性、推理时干预、多轮动态防御与训练阶段鲁棒对齐，每条路线都在安全性、效用性和计算成本之间做出了不同取舍。核心瓶颈在于内部机制的动态性与跨模型泛化性，导致现有防御在未知新型攻击下的泛化能力不足。

未来可能突破的方向包括：基于因果推断的深层意图解耦（如 Causal GRPO）和神经元级统计认证干预（如 TripWire），这些方向可能突破浅层对齐的理论极限；多轮对话与动态交互中的安全对齐，通过引入状态跟踪机制、多轮意图推理及基于世界模型的预测性防御，提升多轮交互场景下的安全性；推理模型的自越狱与思维链安全，通过步骤级安全评估、反思机制内化及因果解耦意图与风格，提升推理模型的安全性。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，系统评估不同防御路线在未知新型攻击下的泛化能力，以揭示防御机制的内在鲁棒性与动态适应性。
