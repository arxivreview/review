## 导读

多模态大语言模型（Multimodal Large Language Models, MLLMs）通过整合视觉编码器与语言骨干，实现了跨模态理解与生成的统一，但其庞大的视觉 Token 序列与异构架构引发了严峻的计算与内存瓶颈。早期研究沿用纯文本模型的静态并行策略，忽视了视觉模块（计算密集）与语言模块（内存带宽密集）在资源需求上的本质差异，导致负载不均衡与效率损失。随着模型规模扩张与部署场景向边缘端延伸，领域重心从单一加速转向系统级异构调度与算法级稀疏表示的协同优化。研究者通过动态并行、模态感知量化及持续学习机制，在精度、效率与能耗之间寻求新的平衡点。各技术路线在硬件适配性、部署复杂度与泛化能力上做出了不同取舍，形成了当前多元并存的优化格局。本综述梳理这条从静态基础设施到动态自适应系统的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

多模态大语言模型（MLLMs）的高效化研究源于架构异构性引发的资源错配。与传统纯文本大语言模型不同，MLLMs 由视觉编码器（如 ViT）、投影层和语言模型骨干组成，这种结构导致输入序列长度因视觉 Token 的引入而急剧膨胀。视觉 Token 数量通常达到数百甚至上千，使得自注意力计算的复杂度呈二次方增长，直接推高了 GPU 内存占用与计算延迟。早期研究主要关注如何在不牺牲精度的前提下压缩这一序列长度，但很快发现，仅靠算法层面的 Token 压缩不足以解决系统级的资源瓶颈，因为视觉编码器与语言骨干在计算特性上存在根本差异：前者是计算密集型，后者则是内存带宽密集型。

这种架构异构性导致了传统统一并行策略的失效。在静态张量并行或流水线并行中，所有模块共享相同的并行布局，导致计算密集的视觉模块与内存带宽密集的语言模块在资源分配上产生冲突，进而引发负载不均衡和流水线气泡。为了解决这一问题，问题定义从单纯的“加速”演变为“跨硬件、跨模态、跨时间”的多维优化。核心矛盾不再仅仅是参数规模，而是如何在保持多模态语义对齐精度的前提下，通过系统级异构调度与算法级稀疏表示的协同设计，打破计算、内存与能耗之间的帕累托前沿。

子问题之间存在强依赖关系。内存溢出（OoM）是基础约束，若不解决则无法进行大规模训练；负载不均衡是系统效率瓶颈，依赖于对模块特性的深入理解；灾难性遗忘是算法层面的长期挑战，依赖于参数高效微调（PEFT）和混合专家（MoE）架构的稳定性；数据混合优化则是提升泛化性的前置条件，影响所有下游任务的性能上限。这些子问题相互交织，构成了 MLLM 高效化的复杂问题空间。

从时间维度看，领域演进呈现出清晰的阶段特征。2019 年至 2023 年，Megatron-LM 和 DeepSpeed 奠定了分布式训练的基础设施，vLLM 通过 PagedAttention 解决了推理中的内存碎片问题，LLaVA-PruMerge 则开启了视觉 Token 压缩的研究方向。这一时期的核心假设是 MLLM 与 LLM 具有相似的负载特性，因此采用统一的优化策略。2024 年至 2025 年，随着模型规模扩大和部署场景多样化，研究者开始关注模块级异构并行（如 BigMac、DHP）和预填充-解码分离（如 EPD-Serve），以解决负载不均衡问题。同时，持续学习机制（如 MoELoRA、SAME）开始受到重视，旨在解决顺序适应新任务时的灾难性遗忘。

2025 年至 2026 年，研究重心进一步向边缘端和持续学习场景扩展。HyperVL 和 SpikeMLLM 探索了软件硬件协同设计以适配电池供电设备，而 CoRe-MoE 和 PCLR 则致力于在持续指令微调中实现高效的知识整合与遗忘缓解。这一阶段的问题定义从“单次推理快”转向“终身学习稳”和“跨硬件适配”。当前，MLLMs 在 Agentic AI 和实时交互场景中的需求激增，研究热度持续高涨，重点在于打破计算与内存的帕累托前沿，实现跨硬件、跨模态的高效训练与推理。

**如果用一个核心问题概括该领域，那便是：如何在保持多模态语义对齐精度的前提下，通过系统级异构调度与算法级稀疏/低秩表示的协同设计，打破计算、内存与能耗之间的帕累托前沿。**

## 2. 方法体系

- 2019：Megatron-LM——提出张量并行与流水线并行相结合的分布式训练框架

- 2020：DeepSpeed——引入 ZeRO 优化器状态分片技术降低训练内存占用

- 2021：LoRA——提出低秩自适应微调方法减少可训练参数量

- 2023：vLLM——提出 PagedAttention 机制解决 KV 缓存内存碎片问题

- 2023：LLaVA-PruMerge——提出基于注意力分数的 Token 合并与剪枝策略

- 2025：BigMac——提出打破计算与内存帕累托前沿的训练系统

- 2025：EPD-Serve——提出多模态推理的编码-预填充-解码解耦服务系统

- 2026：SpikeMLLM——提出基于脉冲神经网络的多模态大模型

这条时间线勾勒了该领域方法演进的代表性节点：从 2019 年的 Megatron-LM 奠定该领域方法基线，经 2020 年 DeepSpeed 的推进，到 2026 年的 SpikeMLLM 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 高效训练系统优化

高效训练系统优化的核心在于解决 MLLM 训练中因架构异构性导致的负载不均衡和内存溢出问题。早期工作如 Megatron-LM 和 DeepSpeed 主要关注通用 Transformer 的分布式训练，假设所有模块具有相似的负载特性。然而，MLLMs 中视觉编码器（ViT）和语言模型骨干（LLM）的计算特性差异巨大，导致统一并行策略下出现严重的资源竞争和气泡。BigMac（Zhang et al., 2026, P26）针对这一问题，重新设计了训练流水线，采用不同的并行策略处理不同模块，例如对编码器使用数据并行，对 LLM 骨干使用流水线并行，并优化了微批次的调度顺序。其核心创新在于解决了传统系统中因模块异构性导致的负载不均衡和气泡问题，实现了更高效的资源利用。该方法依赖于对模型架构的深入理解以进行精细的流水线划分，实施复杂度较高，但显著提升了集群的整体吞吐量。

DHP（Niu et al., 2026, P16）进一步提出了动态混合并行策略，能够根据训练过程中的实时负载情况，动态调整张量并行、流水线并行和数据并行的配置。与 BigMac 的静态模块级划分不同，DHP 打破了静态并行布局的限制，实现了并行策略的自适应调整，从而缓解了因视觉编码器与语言模型计算特性差异导致的效率损失。代价是需要额外的通信开销来同步并行配置变更，且调度算法需具备低延迟响应能力。此外，GPU 内存预测模型（Jeong et al., 2025, P8）通过分析模型架构、输入数据特性及训练配置，预测训练过程中的内存占用峰值，从而提前调整批大小或启用梯度检查点等策略以防止 OoM。该方法将内存预测作为训练前的规划步骤，避免了因 OoM 中断训练造成的计算资源浪费，提升了多模态大模型训练的稳定性和资源利用率。

### 2.2 高效推理与部署

高效推理与部署的研究重点在于优化 MLLM 在云端服务和边缘设备上的延迟与吞吐量。EPD-Serve（Bai et al., 2026, P11）提出了一种灵活的多模态编码-预填充-解码（EPD）解耦推理服务架构，将视觉编码、文本预填充和解码阶段部署在不同的计算单元上。系统引入了 E-P 异步预取和 P-D 分层分组 KV 传输机制，优化了阶段间的数据传输效率，减少了资源争用和调度干扰。其核心创新在于针对多模态推理各阶段的计算强度差异进行异构部署，实现了阶段特定的优化。代价是增加了系统架构的复杂度和阶段间通信开销，需要精细的调度策略来平衡各阶段负载。

RPS-Serve（Papaioannou and Doudali, 2026, P20）针对多模态请求在资源需求上的巨大差异，提出了一种将视频、图像和文本请求分别抽象为“岩石”、“鹅卵石”和“沙子”的调度策略。通过识别不同模态请求的计算和内存特征，RPS-Serve 设计了专门的调度算法来避免大请求（如视频）对小请求（如文本）的队头阻塞，优化了整体服务性能。该方法假设不同模态的资源需求具有稳定的统计特性，对于高度动态的混合负载可能需要动态调整参数。HeteroServe（Yu, 2026, P19）则利用视觉编码是计算密集型而语言解码是内存带宽密集型的架构不匹配特性，提出在跨层 GPU 异构环境中部署多模态推理的方法。系统将视觉编码阶段部署在计算能力强的 GPU 上，而将解码阶段部署在内存带宽大的 GPU 上，通过跨层数据传输优化来平衡资源利用，降低了“HBM 税”。

在边缘设备方面，HyperVL（HyperAI Team et al., 2025, P10）专为边缘设备设计，采用图像分块策略限制峰值内存使用，并引入视觉分辨率压缩器（VRC）和双一致性学习（DCL）技术。VRC 自适应预测最佳编码分辨率以消除冗余计算，DCL 则在统一框架内对齐多尺度 ViT 编码器，确保不同分辨率下的特征一致性。RecursiveVLM（Xu et al., 2026, P14）提出将标准多模态模型重构为递归模型，通过多次迭代复用同一组参数来处理输入，而非单次前向传播。该方法利用递归机制增强模型的表示能力，允许参数在多个时间步上累积信息，从而在保持参数规模不变的情况下提升推理性能，特别适用于需要深度推理的任务。

### 2.3 模型压缩与量化

模型压缩与量化旨在通过减少模型体积和计算量实现高效部署，同时保持性能无损。MASQuant（Hu et al., 2026, P17）针对多模态大模型中视觉和文本模态激活分布不一致导致的量化误差，提出模态感知平滑量化框架。该方法包含模态感知平滑（MAS）和跨模态补偿（CMC）两个阶段，MAS 通过通道级缩放因子重分布激活异常值，CMC 则补偿因平滑操作引起的跨模态计算不变性破坏。其核心创新在于显式考虑模态间的差异，避免了传统量化方法在多模态场景下的性能下降。代价是增加了校准阶段的计算开销，且需要针对特定模态组合进行调优。

SpikeMLLM（Xu et al., 2026, P23）将多模态大模型转化为基于脉冲神经网络（SNN）的架构，利用离散脉冲在时间维度传输信息，将密集乘法转化为稀疏事件驱动范式。方法引入了模态特定时间尺度和时间压缩技术，以适应不同模态数据的时序特性，并显著降低了推理能耗。其核心创新在于结合神经形态硬件优势，实现了多模态推理的极致能效。代价是训练 SNN 通常比 ANN 更困难，且需要专门的硬件支持以发挥能效优势。LLaVA-FA（Zheng et al., 2026, P12）提出基于傅里叶近似的多模态模型压缩框架，通过傅里叶视觉编码器和傅里叶视觉-语言投影器来替代传统的密集线性层，利用傅里叶变换的低秩特性减少模型参数量和计算量。Hypercomplex 量化表示（Ibn Ahad et al., 2025, P9）则提出使用超复数（如四元数）表示来替代传统的实数权重，通过代数结构约束权重空间，提升了量化过程中的稳定性。

### 2.4 参数高效微调

参数高效微调（PEFT）技术通过冻结预训练权重并注入少量可训练参数，解决多模态适配中的模态不平衡、灾难性遗忘及训练效率问题。SAME（Xie et al., 2026, P13）针对多模态持续指令微调中专家路由漂移和专家行为漂移问题，提出稳定混合专家框架。方法采用谱感知路由，仅在任务相关子空间中更新路由权重，并使用曲率感知黎曼缩放来保持先前专家的行为。此外，通过自适应专家激活在任务级别冻结选定专家，减少冗余计算和跨任务干扰。其核心创新在于从几何和谱角度稳定 MoE 组件，有效缓解了灾难性遗忘。

PCLR（ICLR 2026, P33）提出 LoRA 秩池（LRP）架构和压缩-整合-学习（CIL）流水线，用于多模态持续指令微调。LRP 将 LoRA 适配器分解为秩向量，每个秩向量配对一个可学习键，形成原子专家。CIL 流水线模拟人类终身学习记忆循环，通过压缩释放容量，通过整合对齐压缩后的状态，通过学习训练新专家。有益噪声注入探索（Zhu et al., 2025, P7）研究了在多模态大模型微调中注入有益噪声以改善训练效率和泛化能力的方法，发现适度的噪声可以防止过拟合并增强模型的鲁棒性。新技能教学策略（Zhu et al., 2025, P3）发现仅调整语言模型中的自注意力投影层可以在提升目标任务性能的同时最小化对其他任务的遗忘，提供了一种低成本的技能添加策略。Locate-then-Merge（EMNLP 2025, P35）提出基于神经元级别的参数融合方法，首先定位在视觉微调过程中参数变化显著的神经元，然后仅融合这些神经元，从而保留新获得的视觉能力同时最小化对通用语言能力的干扰。

### 2.5 持续学习机制

持续学习机制旨在使 MLLM 在顺序学习新任务时保留旧知识，核心挑战是避免灾难性遗忘。CoRe-MoE（Liu et al., 2026, P31）提出紧凑可复用混合专家框架，通过 SVD 分解 LoRA-MoE 专家为可复用的输出侧和输入侧方向基及坐标矩阵，在新任务训练中冻结初始任务的方向基，仅训练中间坐标矩阵。其核心创新在于将专家知识分解为可复用的基础组件，减少了新任务中的冗余学习，实现了高效的知识整合。基于路由的持续学习（Mohta et al., 2025, P6）利用路由机制动态选择或组合不同的专家模块来处理不同任务，避免了全模型微调带来的干扰，将任务识别与参数选择解耦。

Prism（Tang et al., 2026, P27）提出一个插件式可复现基础设施，用于可扩展的多模态持续指令微调，提供了标准化的数据加载、模型初始化和评估流程，支持多种持续学习算法的公平比较。Continual-NExT（Qiao et al., 2026, P15）提出一个统一的持续学习框架，支持多模态理解与生成任务的持续适应，通过整合多模态适配器和扩散解码器，允许模型在处理输入和生成输出时跨文本和图像模态进行持续学习。MLLM 持续学习基准分析（Tran et al., 2026, P30）对多模态大模型持续学习基准进行深入分析，发现现有基准任务在表示空间中过于分离，导致路由变得平凡，且单一任务顺序使结论敏感，揭示了基准设计的局限性。

### 2.6 数据高效训练

数据高效训练聚焦于通过提升数据利用效率来降低训练成本并增强模型泛化能力。MixAtlas（Wen et al., 2026, P22）提出不确定性感知数据混合优化方法，将数据分解为任务监督和图像概念两个轴，使用高斯过程代理模型搜索最优混合权重，并通过置信度评估将配方迁移至全规模训练。其核心创新在于引入不确定性量化来指导数据采样，避免了盲目搜索，提升了数据利用效率。GDO（Wu et al., 2026, P18）提出目标驱动数据优化方法，根据用户定义的目标计算样本描述符，映射到共享分数，并构建优化子集，实现了数据分配与训练目标的对齐。

UniFilter（Wang et al., 2025, P5）提出使用合成数据训练统一的多模态数据质量分类器，用于过滤预训练数据，通过生成高质量合成样本-分数对，训练一个轻量级分类器来评估图像-文本对的质量。OST（Jing et al., 2026, P25）提出基于增量优化效用的数据选择方法，通过评估每个样本对模型优化的边际贡献来选择高价值数据，避免了 LLM-as-a-Judge 的高昂 API 成本。DataProphet（ICLR 2026, P34）提出 DataProphet 框架，用于解构多模态大模型中监督数据的泛化机制，通过分析不同数据子集对目标任务性能的影响，揭示数据多样性与泛化能力之间的关系，为多模态数据工程提供了理论指导和实践工具。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

MLLM 的架构异构性要求训练和推理系统采用模块级或阶段级的差异化优化策略，而非统一的静态配置。这一共识在多个基准上被反复验证：BigMac 的 1.08x-1.9x 加速与 DHP 的 1.36x 吞吐量提升均源于对视觉编码器与 LLM 骨干的差异化并行处理（支撑证据：P26、P16）。与此相关的另一个共识是，视觉 Token 的数量和冗余是 MLLM 推理延迟和内存消耗的主要瓶颈，压缩视觉 Token 是提升效率的关键手段。LLaVA-PruMerge 和 HyperVL 的动态分辨率调整均通过减少视觉 Token 数量实现了显著的效率提升（支撑证据：P10、P12）。持续指令微调中，简单的参数更新会导致严重的灾难性遗忘，需要引入专家隔离、参数合并或正则化机制来平衡新任务学习与旧知识保留。SAME 和 CoRe-MoE 在 UCIT/MLLM-DCL 上的 SOTA 性能验证了这一共识（支撑证据：P13、P31）。

### 3.2 观点分歧

持续学习中参数隔离的最佳形式存在显著分歧：MoE 路由 vs 参数合并 vs 正则化。观点 A 认为 MoE 路由（如 MoELoRA、CoRe-MoE）通过专家隔离实现知识解耦，适合任务差异大的场景；观点 B 认为参数合并（如 Locate-then-Merge、PCLR）通过神经元级融合实现知识整合，适合任务相关性高的场景。现有证据偏向 MoE 在长序列和异构任务中更鲁棒，但参数合并在特定任务上性能上限更高。这一分歧的背后，是另一个更根本的争论：边缘部署的能效优化路径。观点 A 认为激进量化（如 MASQuant）结合模态感知平滑是通用且易部署的方案；观点 B 认为脉冲神经网络（如 SpikeMLLM）通过事件驱动范式实现极致能效，但依赖专用硬件。SpikeMLLM 在能效上优势显著（25.8x Power Benefit），但量化方案在通用 GPU/NPU 上兼容性更好。证据强度低，SNN 缺乏大规模真实场景验证，量化方案在极低比特下精度损失明显。

### 3.3 其他开放问题

当前最紧迫的工程问题是跨硬件异构调度的通信开销和 SNN 硬件支持。动态分辨率调整的预处理延迟在实时场景中未被充分量化，限制了其在边缘设备上的应用。最根本的研究问题是灾难性遗忘的几何机理和多模态数据混合的因果推断。现有基准任务在表示空间中过于分离，导致路由变得平凡，缺乏重叠任务流形的评估。未来研究应扩展多模态持续学习基准以包含重叠任务流形、多个课程和更丰富的指标，解决当前基准任务表示高度可分离且依赖单一任务顺序的问题。此外，开发支持更多模态（如音频、3D 数据、视频）的推理服务系统，以及探索更丰富的诊断信号和多智能体协作策略，也是重要的研究方向。

## 4. 总结与展望

多模态大模型的高效化研究已从单纯的“加速”演变为“跨硬件、跨模态、跨时间”的多维优化。核心矛盾在于视觉 Token 冗余与 LLM 骨干的内存带宽瓶颈之间的张力，以及架构异构性导致的资源错配。早期工作依赖静态并行和简单压缩，但很快发现这些方法无法同时优化计算、内存与能耗。当前，领域重心转向系统级异构调度与算法级稀疏表示的协同设计，通过动态并行、模态感知量化及持续学习机制，在精度、效率与能耗之间寻求新的平衡点。

未来可能突破的方向包括：扩展多模态持续学习基准以包含重叠任务流形，解决当前基准任务表示高度可分离的问题；探索自适应 Token 稀疏性和注意力剪枝技术，进一步改进边缘设备上的推理效率；研究模型合并的底层原理和更有效的合并策略，解决不同任务间参数冲突和灾难性遗忘问题。对于进入该领域的研究者，最值得做的一件事是构建一个统一的跨硬件、跨任务公平比较基准，以标准化协议评估不同优化策略的综合性能，从而为后续研究提供可靠的实证基础。
