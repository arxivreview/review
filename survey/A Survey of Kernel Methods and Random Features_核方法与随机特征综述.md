## 导读

核方法（Kernel Methods）通过再生核希尔伯特空间（RKHS）实现非线性建模，其核心价值在于提供严格的泛化理论保证，但传统算法受限于二次或三次计算复杂度，难以处理大规模数据。随机特征（Random Features, RF）技术通过显式低维映射近似隐式核，将复杂度降至线性，解决了可扩展性瓶颈，却因早期理论基于固定核假设而无法解释自适应特征学习的优势。当固定谱衰减假设在自适应场景中失效后，研究者引入有效跨度维度（ESD）与内在维度等几何度量，用数据驱动的核重塑换取对高维维度灾难的理论解释力。各路线在计算效率、统计保证与模型表达力之间做出了不同取舍，由此形成当前理论精细化与算法自适应化并存的格局。本综述梳理这条从固定近似到自适应对齐的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

核方法的核心矛盾在于理论严谨性与计算可扩展性之间的张力。传统核方法将数据映射至高维再生核希尔伯特空间（RKHS），利用正定核诱导的函数空间实现非线性建模，其泛化界限由核的谱结构决定。然而，核矩阵的计算与存储复杂度为 $O(N^2)$ 或 $O(N^3)$，当样本量 $N$ 增大时，这一瓶颈使得核方法在大规模数据上难以部署。随机特征（RF）技术的引入是解决这一矛盾的关键转折，它通过随机投影构造显式低维特征映射，以线性复杂度近似隐式核，从而在保持统计保证的前提下实现了计算效率的飞跃。

问题形式化通常遵循 $N$-way $K$-shot 或回归设定，目标是在有限样本下最小化经验风险。在随机特征框架下，核心问题可表述为：给定核函数 $k(x, x')$ 及其谱测度 $\mu$，寻找显式特征映射 $\phi: \mathcal{X} \to \mathbb{R}^M$，使得 $\langle \phi(x), \phi(x') \rangle \approx k(x, x')$，并推导特征数量 $M$ 与泛化误差之间的理论界限。早期研究聚焦于固定核假设下的近似误差控制，即如何用最少的 $M$ 达到指定精度。这一子问题依赖于谱测度的衰减性质，形成了以源条件（Source Condition）和多项式谱衰减为核心的经典理论框架。

随着自适应特征学习（如神经切线核或深度核学习）的兴起，固定核假设的局限性暴露无遗。经典理论无法解释训练过程中特征演化带来的泛化优势，因为学习核的谱结构是动态变化的，不再满足固定的衰减假设。由此，问题定义从“近似误差控制”演变为“自适应性与内在维度”的量化。子问题间呈现明显的依赖关系：首先需解决固定核下的采样效率（基础层），才能探讨可学习激活函数带来的表达力提升（中间层）；而自适应泛化理论（顶层）则依赖于对信号-核对齐（通过有效跨度维度 ESD 度量）和数据几何结构（通过内在维度刻画）的量化，否则无法解释自适应方法为何优于固定核。

这一演化并非线性替代，而是认知边界的逐步拓展。固定核理论在平稳、低维数据上依然有效，但其假设在复杂非线性任务中过于苛刻。自适应理论试图摆脱强正则性假设，建立更通用的框架，但代价是理论抽象度增加，计算复杂度上升。当前范式边界在于：固定核理论提供紧致的误差界，适用于已知谱结构的场景；自适应理论提供机制解释，适用于谱结构未知或动态变化的场景。两者并非竞争关系，而是互补的认知工具，共同构成了核方法随机特征领域的理论基石。

从时间维度看，约束演化史清晰地反映了方法对问题定义的响应。2007-2013 年间，Random Fourier Features（RFF）与 Leverage Score Sampling 奠定了随机特征的基础，核心约束是计算复杂度，目标是线性复杂度下的近似误差控制。2017-2021 年，Minimax Optimal Rates 与 Unified Analysis 建立了固定核下的标准理论框架，明确了随机特征与精确核的统计等价性，此时问题已转变为采样效率与模型表达力的平衡。2024-2025 年，RFLAF 引入可学习激活函数，ESD 框架提出对齐敏感度量，动机是解释自适应核的泛化优势，突破固定核假设。2025-2026 年，Intrinsic Dimension Bounds 与 Manifold Random Features 引入几何测度论，动机是摆脱环境维度依赖，处理流形与分形数据。

当前领域处于理论精细化与算法自适应化的融合阶段。理论层面，ESD 与内在维度提供了新的复杂度度量，旨在建立不依赖强正则性假设的泛化理论；算法层面，超核岭回归（HKRR）与张量网络特征学习通过参数化核与特征，将核方法与深度学习结合，旨在克服高维组合结构数据的维度灾难。这种融合并非简单的技术叠加，而是对“数据驱动的核重塑”这一核心思想的共同追求。

**如果用一个核心问题概括该领域，那便是：如何在保持核方法统计保证的前提下，通过数据驱动的核重塑与几何感知的复杂度度量，克服维度灾难并实现大规模数据上的高效非线性建模。**

## 2. 方法体系

- 2007：Random Fourier Features (RFF)——奠定随机特征近似核方法的理论基础

- 2008：Leverage Score Sampling——提出数据依赖采样策略以减少特征数量

- 2013：TensorSketch/Fastfood——针对点积核提出快速特征映射

- 2017：Minimax Optimal Rates for KRR-RF——建立固定核下的极小极大最优收敛速率理论

- 2021：Unified Analysis of RF Models——提供任意谱测度下的统一泛化界分析

- 2024：RFLAF Basic Estimate——首次将可学习激活函数引入随机特征理论框架

- 2025：ESD Framework——引入有效跨度维度作为对齐敏感的复杂度指标

- 2025：Tensor Network Feature Learning——利用张量网络约束解决参数爆炸问题

这条时间线勾勒了该领域方法演进的代表性节点：从 2007 年的 Random Fourier Features (RFF) 奠定该领域方法基线，经 2008 年 Leverage Score Sampling 的推进，到 2025 年的 Tensor Network Feature Learning 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 随机特征理论分析

随机特征理论分析的核心任务是建立特征数量与泛化误差之间的理论联系，其演进轨迹反映了从固定核假设向自适应对齐机制的范式转移。早期工作如 Minimax Optimal Rates for KRR-RF（2017）在源条件假设下建立了核岭回归结合随机特征的极小极大最优收敛速率，明确了正则化参数与特征数量对泛化误差的影响机制。这一框架的局限在于其依赖固定的谱衰减假设，无法解释自适应学习带来的泛化优势。

为突破这一局限，RFLAF Generalization Analysis（Ma et al., 2025, P4）引入了可学习激活函数（RFLAF），通过数据依赖的杠杆加权采样方案推导了平方误差和 Lipschitz 损失下的最尖锐界限。该方法放弃了固定激活函数的简洁性，换取了对模型表达力的增强，证明了加权采样能显著减少特征数量同时保持低学习误差。其核心创新在于填补了 RFLAF 在数据依赖采样下理论分析的空白，揭示了可学习激活函数与采样策略协同优化泛化性能的机制。

进一步地，ESD Minimax Rates（Huang et al., 2025, P1）引入了有效跨度维度（ESD）作为对齐敏感的复杂度度量，用于研究学习核的谱算法极小极大速率。ESD 联合依赖信号、谱和噪声水平，适用于任意核包括自适应核，无需特征值衰减或源条件假设。该工作放弃了经典理论的紧致性，换取了对自适应核学习机制的解释力，证明了过参数化梯度流可通过降低 ESD 来改善泛化。这一框架突破了固定核理论的局限，为理解自适应核方法的优势提供了新的理论视角。

在正则化参数选择方面，Neighboring Early-Stopping Rule（Wang et al., 2026, P12）提出了一种基于相邻估计器比较的自适应规则，用于 KRR-RF 中自动选择正则化参数。该方法无需交叉验证或网格搜索，通过平衡偏差、方差和随机特征近似误差实现最优自适应保证。其代价是理论分析需满足 Bernstein 矩条件等假设，但提升了算法在大规模数据上的实用性和自动化程度。

针对高维数据中的维度灾难，Intrinsic Dimension KRR Bounds（Takhanov, 2026, P8）利用几何测度论概念刻画数据分布支撑集的内在维度，推导了核岭回归的超额风险界。该方法不依赖强正则性假设，能够处理分形等不规则支撑集，揭示了内在维度而非环境维度应主导泛化行为。这一工作为理解高维数据中核方法的样本复杂度提供了新的几何视角，与 ESD 框架共同构成了自适应理论的双翼。

| 方法路线 | 核心假设 | 关键决策 | 放弃/换取 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| 固定核 RF | 源条件、谱衰减 | 均匀/杠杆采样 | 紧致界 / 通用性 | 平稳、低维数据 |
| RFLAF | 可学习激活 | 数据依赖采样 | 简洁性 / 表达力 | 非线性拟合任务 |
| ESD 框架 | 无固定谱假设 | 对齐敏感度量 | 紧致性 / 解释力 | 自适应核学习 |
| 内在维度界 | 几何测度论 | 支撑集复杂度 | 强正则性 / 通用性 | 高维、分形数据 |

### 2.2 随机特征构造创新

随机特征构造创新旨在解决非平稳核或高维子空间的高效近似问题，其演进逻辑是从平移不变核向复杂几何结构的扩展。Random Fourier Features（RFF）基于 Bochner 定理，将平移不变核分解为随机频率的余弦/正弦函数线性组合，奠定了随机特征近似核方法的理论基础。然而，RFF 无法处理非平稳或非点积形式的核，如耦合对齐与邻近性的复杂核。

Manifold Random Features（Parashar et al., 2026, P9）针对流形上的核函数，提出通过训练连续随机特征机制并利用图随机特征（GRFs）进行离散监督的方法。该方法将流形核近似转化为图核近似，利用随机游走生成签名向量，解决了非欧几里得空间上核近似缺乏闭式表达的问题。其代价是训练过程涉及随机游走采样，计算复杂度与图结构相关，但相比直接计算流形核具有显著优势。

Bernstein-Schur Kernels（Bouhsine, 2026, P10）针对非平稳且非点积形式的偏置 $\mathfrak{G}$-核，提出结合精确多项式特征与径向随机化的混合随机特征方案。该方法利用 Bernstein-Widder 混合测度处理径向因子，通过 Hadamard 积组合调制与径向部分，实现了对复杂核的无偏近似。其核心创新在于填补了 RFF 和多项式草图无法覆盖的核类型空白，但在数据层面引入了较大的常数因子，依赖于核的带宽和偏置参数。

Grassmannian Random Features（Delogne and Jacques, 2026, P11）针对 Grassmannian 流形上的子空间数据，提出基于有界秩一投影的随机特征构造，包括二元和周期性变体。该方法通过随机投影将子空间嵌入欧氏空间，利用 Johnson-Lindenstrauss 引理保证距离保持，解决了传统 Grassmannian 核方法因需计算 $N \times N$ Gram 矩阵而导致的可扩展性瓶颈。其代价是引入了随机性，可能需要多次采样以获得稳定结果，但相比精确核计算具有显著的效率优势。

### 2.3 核方法应用与扩展

核方法应用与扩展聚焦于将随机特征与核方法应用于聚类、函数空间表示及复合模型学习，旨在提升算法的可扩展性并克服维度灾难。RFF-KPKM（Chen et al., 2025, P5）将随机傅里叶特征引入核幂 K-means（KPKM），通过显式特征映射避免计算完整的核矩阵，将复杂度从 $O(n^2k)$ 降低至 $O(n(k+d)D)$。该方法结合可能性方法增强鲁棒性，使得核聚类算法能够处理大规模数据集，解决了传统核聚类在内存和时间上的限制。

Function Encoders（Low et al., 2025, P2）提出学习紧凑 Hilbert 空间基的函数编码器，通过神经网络学习显式特征映射，使推理成本仅依赖于基函数数量而非数据集大小。该方法连接了特征学习与核方法，提供了原空间显式映射与对偶空间核评估的统一视角，解决了核方法在推理阶段随训练数据规模线性增长的计算瓶颈。其代价是训练过程需要优化神经网络参数，可能面临局部极小值问题，但通过 PCA 策略可缓解。

Hyper-Kernel Ridge Regression（Huang et al., 2025, P3）针对多索引模型（MIM）提出超核岭回归，结合神经网络与核方法，通过交替最小化优化超核参数。该方法证明了 HKRR 能自适应学习 MIM 并克服维度灾难，提供了样本复杂度结果，展示了核方法在处理具有组合结构的高维数据时的潜力。其代价是优化过程涉及非凸问题，可能收敛到局部极小值，但通过理论分析保证了收敛到临界点。

Tensor Network Feature Learning（Saiapin and Batselier, 2025, P7）提出基于张量网络的特征学习模型，利用 CPD 分解约束模型参数，将张量积特征映射转化为可学习的低秩结构。该方法通过交替最小化优化特征参数和模型参数，解决了张量积特征指数级增长导致的参数爆炸问题，为高维数据中的核方法提供了内存和计算效率更高的替代方案。其代价是优化过程涉及非凸问题，可能面临局部极小值，但通过 ALS 算法保证了局部收敛。

### 2.4 跨任务与多领域应用

跨任务与多领域应用展示了随机特征方法在不同数据结构和任务类型中的通用性。在聚类任务中，RFF-KPKM 在 Caltech101 和 NUS-WIDE 等数据集上展示了优越的性能，验证了随机特征在大规模非凸聚类问题中的实用性。在回归任务中，Tensor Network Feature Learning 在 UCI 回归数据集上展示了稳定的性能，表明张量网络结构能有效捕捉高维数据中的组合特征。

在子空间分类任务中，Grassmannian Random Features 在 ETH-80 数据集上展示了与精确核相当的分类精度，且计算时间显著降低，验证了随机特征在子空间建模任务中的效率优势。在耦合回归任务中，Bernstein-Schur Kernels 在 Off-sphere Ball 数据上超越了精确核的性能，表明混合随机化机制在处理非平稳核时的有效性。

这些应用案例共同表明，随机特征方法并非局限于特定的核类型或任务，而是通过适配不同的几何结构和优化策略，实现了在多种场景下的可扩展性与理论保证的平衡。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

随机特征方法能有效降低核方法的计算复杂度，从二次/三次降至线性，是处理大规模数据的关键技术。这一共识在多个基准上被反复验证，如 RFF-KPKM 在 Caltech101 上的可扩展性表现，以及 Grassmannian Random Features 在 ETH-80 上的效率优势。自适应特征学习通过增加信号与核的对齐，能够显著改善泛化性能，超越固定核方法的理论界限。ESD 框架和 HKRR 的实验结果均支持这一观点，表明数据驱动的核重塑是提升泛化能力的有效途径。

与此相关的另一个共识是利用数据的内在维度而非环境维度来刻画样本复杂度，可以避免维度灾难，提升高维数据上的学习效率。Intrinsic Dimension KRR Bounds 在分形数据上的实验验证了这一观点，表明内在维度是主导泛化行为的关键因素。核方法在理论上具有凸优化保证，但在实践中受限于核矩阵的计算瓶颈，因此显式特征映射是连接理论与高效实践的桥梁。这一共识贯穿于所有随机特征方法的设计中，从 RFF 到 Tensor Network，均体现了对显式映射的追求。

### 3.2 观点分歧

自适应学习优势的来源存在分歧：ESD 框架认为是信号-核对齐（谱重塑），而内在维度理论认为是数据几何结构（支撑集复杂度）。现有证据偏向 ESD 在序列模型和自适应核学习中的解释力，而内在维度在分形/流形数据上更优。这一分歧的背后，是另一个更根本的争论：理论假设的必要性。经典理论依赖源条件，新理论试图摆脱强正则性假设，但新界的紧度尚待更多实验验证。

随机特征构造的通用性也存在分歧：RFF 范式认为平移不变核的构造是通用且高效的，而结构化构造认为非平稳/流形核需要专门的随机特征构造。现有证据表明，RFF 在平移不变核上表现优异，但在非平稳核上失效或精度低。MRF 和 RAY 在特定核类型上展示了优势，但计算复杂度较高。缺乏在多种核类型上的统一基准测试，使得这一分歧难以定论。

### 3.3 其他开放问题

最紧迫的工程问题是开发完全数据驱动的正则化参数与随机特征预算校准机制，解决当前方法依赖先验知识或网格搜索导致的计算开销大及泛化边界不紧的问题。关键困难在于如何设计自适应阈值调整策略，研究路径包括基于邻近比较原则的扩展。最根本的研究问题是深入研究学习表示与核方法的理论联系，解释神经网络在特定域上优于随机特征模型的泛化机制。难点在于量化内在维度与 Minkowski 维度在分形或不规则域上的差异，研究路径包括超核岭回归的进一步泛化。

已知—争议—未知认知图谱显示，领域在计算效率与统计保证的平衡上已形成共识，但在自适应优势的机制解释和理论假设的必要性上存在争议。未知领域包括非平稳核的统一构造、流形数据上的内在维度估计，以及学习表示与核方法的理论联系。发展趋势表明，随着自适应正则化与流形 RF 技术的成熟，核方法有望在保持理论严谨性的同时，具备与深度学习相当的灵活性与可扩展性。

## 4. 总结与展望

核方法随机特征领域的核心矛盾在于计算效率与统计保证之间的张力，以及固定核理论与自适应实践之间的脱节。从 RFF 到 ESD 与内在维度，研究者通过引入数据驱动的核重塑与几何感知的复杂度度量，逐步克服了维度灾难，实现了大规模数据上的高效非线性建模。当前瓶颈在于自适应优势的机制解释尚不统一，理论假设的必要性存在争议，且非平稳核的统一构造仍缺乏通用方案。

未来可能突破的方向包括：开发完全数据驱动的正则化参数校准机制，以及深入研究学习表示与核方法的理论联系。这两个方向均有 ≥2 篇论文共同指向，如 Neighboring Early-Stopping Rule 和 Intrinsic Dimension KRR Bounds 均涉及自适应机制，而 HKRR 和 Function Encoders 均涉及学习表示与核方法的结合。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，设计涵盖平移不变、非平稳、流形核的综合基准，以分离 ESD 与内在维度的贡献，从而为自适应优势的机制解释提供实证基础。
