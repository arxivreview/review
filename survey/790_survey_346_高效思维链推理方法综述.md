综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Efficient%20and%20Theoretical%20Chain-of-Thought%20Reasoning)

## 导读

思维链（Chain-of-Thought, CoT）推理通过生成中间步骤显著提升了大语言模型在复杂任务上的表现，但其自回归特性导致推理链冗长，引发计算成本高企与“过度思考”现象。早期研究以提示工程与启发式剪枝为主线，通过长度惩罚或静态截断控制推理长度，思路简洁却受制于离散 Token 的表达瓶颈与语义误删风险。当强化学习（Reinforcement Learning, RL）结合可验证奖励普及后，长 CoT 成为主流，研究重心从单纯提升准确率转向效率与准确率的帕累托平衡。随着连续潜在空间推理（Latent Reasoning）与信息论理论框架的引入，领域进入从显式文本压缩向隐式潜在推理、从启发式规则向理论指导的范式转移阶段。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从离散符号到连续潜空间的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

思维链推理的引入解决了大语言模型在数学、代码及逻辑任务上的准确率瓶颈，但其自回归生成机制使得推理过程必须逐 Token 解码，导致计算复杂度随链长线性甚至二次方增长。2022 年 Wei 等人提出 CoT 范式后，研究重心逐渐从单纯提升准确率转向效率与准确率的平衡，核心矛盾在于推理深度与计算效率之间的根本张力。这一矛盾在 2024-2025 年随着 DeepSeek-R1 和 OpenAI o1 等推理模型的发布而急剧放大，这些模型通过强化学习进一步放大了长 CoT 的优势，但也加剧了资源消耗，促使领域进入“高效推理”阶段。

问题定义经历了从静态长度限制到动态语义感知，再到理论边界界定的演化过程。早期问题被形式化为在固定 Token 预算下最大化准确率，即给定输入 $x$ 和预算 $B$，寻找推理链 $c$ 使得 $P(y|x, c) \cdot \mathbb{I}(|c| \le B)$ 最大化。随着“过度思考”现象的暴露，问题演变为在满足准确率硬约束 $P(y|x, c) \ge \tau$ 的前提下，最小化推理链的计算复杂度 $C(c)$，其中 $C(c)$ 包含 Token 数、延迟及显存占用。进一步地，问题被抽象为寻找推理表示的最优形式，即在离散 Token 空间与连续潜在空间之间，确定能够以最低计算成本保留最大任务相关信息的表示映射。

子问题之间存在严格的依赖关系。推理冗余的自动化识别是有效实施压缩与剪枝的前提，缺乏对步骤语义重要性的动态感知会导致关键步骤被误删或冗余步骤保留。潜在推理机制是突破离散 Token 表达局限性的根本路径，但其训练不稳定性制约了落地效果，需要新的蒸馏策略或架构设计来稳定训练过程。理论复杂度分析为上述所有方法提供下界与边界，决定优化方向的有效性，缺乏理论指导的方法往往陷入启发式调参的困境。此外，推理过程的不可解释性与忠实度问题在压缩或潜在化后变得尤为突出，影响模型的可信度与调试能力。

范式边界上，需区分“推理加速”与“推理效率”两个层面。推理加速聚焦于系统级优化，如推测解码、KV 缓存管理及硬件感知调度，旨在不改变推理逻辑的前提下降低实际部署延迟。推理效率则聚焦于模型级优化，如压缩、潜在化及结构重构，旨在改变推理表示或路径以从根本上降低计算需求。两者互补但目标不同，前者解决“如何跑得更快”，后者解决“如何想得更少”。

约束演化史揭示了方法因应约束变化而演变的轨迹。2016-2018 年奠基期，研究主要关注如何引导模型生成中间步骤，以 CoT 提示工程为代表。2020-2023 年，随着模型规模扩大，树状与图状结构（如 ToT、GoT）被引入以优化探索路径，但计算开销随分支指数增长。2024 年，Token Elasticity 现象的发现揭示了过紧 Token 预算会导致补偿性冗余生成，促使从硬截断转向自适应压缩，From Long to Lean 等多轮渐进压缩方法应运而生。2025 年，RLVR 的普及确立了长 CoT 范式，DeepSeek-R1 等工作通过大规模探索与反馈机制激发长链推理能力，同时 COCONUT 提出连续隐空间推理，开启潜在推理时代。2026 年，理论分析（如 BAPO、CoT-Space）与高效架构（如 PCCoT、NF-CoT）并行发展，旨在从理论上证明潜在推理的效率优势，并解决训练不稳定性问题。当前形态呈现显式压缩、潜在推理、结构优化与理论分析四线并进的格局。

**如果用一个核心问题概括该领域，那便是：在满足任务准确率硬约束的前提下，如何以最低的计算复杂度重构推理表示与路径，并揭示该优化过程的理论下界与表达能力边界。**

## 2. 方法体系

- 2022：Chain-of-Thought (CoT)——通过提示模型生成中间推理步骤，奠定方法基线

- 2023：Tree-of-Thought (ToT)——将推理扩展为树状搜索结构，突破线性局限

- 2024：Token Elasticity——发现过紧 Token 预算导致补偿性冗余，揭示非线性关系

- 2025：DeepSeek-R1——采用 RLVR 激发长链推理，确立 RL 核心地位

- 2025：COCONUT——提出连续隐空间推理，实现无需文本生成的潜在思维

- 2025：CODI——通过自蒸馏将 CoT 压缩至连续空间，提升潜在推理稳定性

- 2026：UCoT——提出协同压缩框架，实现推理 Token 的高效压缩与精度保持

- 2026：PCCoT——利用 Jacobi 迭代实现并行连续 CoT，显著降低训练与推理时间

这条时间线勾勒了该领域方法演进的代表性节点：从 2022 年的 Chain-of-Thought (CoT) 奠定该领域方法基线，经 2023 年 Tree-of-Thought (ToT) 的推进，到 2026 年的 UCoT 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 CoT压缩与剪枝

CoT 压缩与剪枝路线旨在通过语义剪枝、长度惩罚或自适应截断减少推理 Token 冗余，在保持精度的同时显著降低推理成本与延迟。早期方法如 ThinkPrune 引入硬截断策略，通过强制限制推理长度来消除冗余步骤，但 Token Elasticity 现象的发现表明，过紧的 Token 预算会导致模型产生补偿性冗余生成，揭示了 Token 约束与实际输出长度间的非线性关系。From Long to Lean（Yan et al., 2025, P4）针对这一非线性关系，提出基于多轮渐进式压缩的策略，允许模型平滑适应长度约束，避免了单步大幅压缩导致的信息丢失，其代价是引入了多轮交互的计算成本。

UCoT（Li et al., 2025, P8）进一步将 CoT 压缩解耦为压缩器与执行器两个独立模块，通过专用压缩器生成精简推理轨迹，再由执行器基于压缩轨迹生成最终答案。该设计避免了单一模型在压缩与推理间的权衡冲突，允许使用不同规模的模型分别优化压缩效率与推理精度，其核心创新在于引入了“前置思维”概念，平衡 Token 消耗与准确率。ChainPrune（Pan et al., 2026, P38）则基于语义路径合并与偏好优化，通过 Pareto 主导准则进行多标准路径选择，同时优化 Token 长度和推理步骤长度，构建偏好数据集进行微调，其依赖于采样路径的多样性。SLAT（Yao et al., 2026, P32）提出分段级自适应修剪方法，通过 Lagrangian 对偶优化解决推理效率与精度的权衡问题，允许模型在不同难度问题上采用不同的推理深度，避免了全局长度惩罚的均匀性缺陷。

### 2.2 潜在推理机制

潜在推理机制路线探索在连续隐空间或潜变量中进行推理，通过软 Token、循环架构或流模型替代离散文本生成，提升推理带宽与效率。COCONUT 提出在连续隐空间进行推理，利用隐藏状态作为输入嵌入替代离散 Token，实现无需文本生成的潜在思维，但其训练过程面临灾难性遗忘与表示对齐困难。CODI（2025, P39）针对 COCONUT 的训练不稳定性，提出自蒸馏框架，通过教师模型在边界 Token 处的表示对齐，提升潜在推理的稳定性，其核心创新在于利用自蒸馏机制，使模型在连续空间中模仿自身的推理模式，避免了外部监督的分布偏移。

PCCoT（2025, P45）利用 Jacobi 迭代实现并行连续 CoT，通过多步迭代收敛潜在状态，显著降低训练与推理时间，其核心创新在于将连续推理转化为并行迭代问题，充分利用 GPU 并行计算能力。NF-CoT（Tu et al., 2026, P35）提出利用归一化流建模连续 CoT，通过自回归采样生成潜在思维，解决扩散模型采样效率低的问题，其核心创新在于将连续推理建模为概率流过程，提供了更灵活的采样策略。SeLaR（Fu and Luo, 2026, P28）提出选择性潜在推理框架，通过 Token 级熵作为置信度信号，动态激活潜在推理，平衡了探索效率与解码稳定性。PLaT（Wang et al., 2026, P17）将推理解耦为潜在自回归过程，通过潜在状态嵌入替代离散 Token 生成，实现推理与语言化的分离，引入 Lazy Decoding 策略减少计算开销。

### 2.3 推理结构优化

推理结构优化路线利用图、树或网络拓扑重构推理路径，通过并行搜索、分支合并或动态规划提升推理的探索能力与结构效率。ToT 将推理扩展为树状搜索结构，允许模型探索多条备选路径并回溯，突破线性 CoT 的探索局限，但计算开销随分支指数增长。E2C（Yang et al., 2025, P5）提出将推理解耦为探索与执行两阶段的框架，通过分离头脑风暴与详细计算，提升推理效率与可解释性，其核心创新在于显式解耦推理的两个功能，使模型能够根据问题复杂度动态分配计算资源。

Network-of-Thought（Huang, 2026, P26）提出图结构推理框架，通过类型化节点与边及启发式控制器，动态选择推理拓扑，引入自生成启发式替代手工调参，实现任务自适应。Multiplex Thinking（Tang et al., 2026, P15）通过 Token 级分支与合并实现推理，利用概率加权混合 Token 嵌入作为连续 Token，保留分布信息，其核心创新在于将推理过程建模为分支与合并的动态过程。GHS-TDA（Zhang et al., 2026, P22）提出两阶段“构建-分析”推理框架，通过全局假设图整合多样推理路径，并利用拓扑数据分析提取稳定骨干，其核心创新在于利用拓扑稳定性作为结构约束与收敛准则。

### 2.4 理论复杂度分析

理论复杂度分析路线从计算复杂性、信息论或学习理论角度分析 CoT 的样本复杂度、长度下界及泛化机制，揭示推理能力的理论边界。BAPO Bounds（Tomlinson et al., 2026, P20）提出基于 BAPO 模型的 CoT Token 复杂度理论框架，量化 Transformer 内部通信带宽对推理长度的影响，证明 CoT 可将任意可判定问题分解为 BAPO 易解实例，降低所需带宽至常数，其核心创新在于将推理 Token 复杂度与通信带宽关联，提供了推理长度的理论下界。

CoT-Space（Gan et al., 2025, P1）提出内部慢思考的理论框架，通过 RL 优化分析 CoT 轨迹的连续空间性质，揭示推理能力的内在结构，其核心创新在于将 CoT 推理形式化为连续空间优化问题。Reasoning as Compression（Massoli et al., 2026, P25）提出基于条件信息瓶颈（CIB）的统一预算强制框架，从信息论角度分析 CoT 压缩与推理效率的关系，其核心创新在于将预算强制与信息论统一，提供了推理压缩的理论基础。Transformers Provably Learn CoT（Huang et al., 2025, P9）证明 Transformer 通过 CoT 可学习超出 TC0 复杂度的推理任务，并提供长度泛化的理论保证，其核心创新在于提供了 CoT 提升 Transformer 表达能力的优化保证。

### 2.5 强化学习优化

强化学习优化路线利用强化学习策略优化推理轨迹，通过奖励塑形、课程学习或对比反馈提升推理质量与效率。DeepSeek-R1（2025, P23）采用基于可验证奖励的强化学习（RLVR），通过大规模探索与反馈机制激发长链推理能力，确立 RL 在推理训练中的核心地位。CRT（Wu et al., 2026, P23）提出约束感知训练框架，通过显式分离正确性约束与效率优化目标，解决传统奖励混合导致的精度损失问题，其核心创新在于将效率优化重构为约束优化问题。

RL for CoT Compression（Li et al., 2025, P14）提出基于强化学习的自适应压缩方法，核心在于引入样本级门控软压缩奖励机制，仅当模型在特定样本上表现出可靠掌握时，才对超出安全长度的 Token 施加软惩罚，实现了“先求对，再求快”的训练动态。ETR（Xiong et al., 2026, P27）提出基于熵趋势的奖励设计方法，通过监测推理过程中熵的变化趋势，引导模型生成简洁且正确的推理路径，其核心创新在于将熵趋势作为奖励信号，提供了更细粒度的推理质量评估。DRER（He et al., 2025, P2）提出动态推理效率奖励框架，通过塑形中间推理步骤的效率与效用，提升推理轨迹质量，其核心创新在于将推理效率作为奖励信号。

### 2.6 推理加速与部署

推理加速与部署路线聚焦推理时的系统级优化，包括推测解码、KV 缓存管理、多模型协作及硬件感知调度，以降低实际部署延迟。SpecCoT（2025, P42）提出通过推测探索加速 CoT 推理的方法，将推测解码扩展至推理步骤级别，利用草稿模型预测整个推理步骤，由目标模型验证预测结果，其核心创新在于将推测解码应用于推理步骤，显著降低了长链推理的延迟。

MemoSight（Liu et al., 2026, P29）提出统一上下文压缩与多 Token 预测的框架，通过特殊 Token 与移位位置 ID 设计，实现 KV 缓存优化与并行预测，其核心创新在于将上下文压缩与多 Token 预测统一在单一训练范式下。SAEM（Zhang et al., 2026, P37）提出阶段感知专家管理方法，针对 MoE 模型在 CoT 推理中的内存效率优化，通过检测推理阶段边界，利用阶段粒度的专家使用统计指导缓存管理，其核心创新在于将专家管理与推理阶段对齐，实现了粗粒度缓存优化。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

CoT 推理显著提升了 LLM 在复杂任务上的表现，但引入了显著的推理延迟和计算开销，效率优化已成为核心研究目标，这一共识在约 75 篇论文中得到共同支持。长 CoT 并不总是带来更高的准确率，存在“过度思考”现象，即冗余推理步骤可能降低性能或浪费资源，这一现象在约 40 篇论文中被反复验证。强化学习结合可验证奖励是训练高效推理模型的有效手段，但需引入长度惩罚或效率奖励以平衡准确性与简洁性，这一范式在约 35 篇论文中被确立。潜在推理通过连续表示替代离散 Token，在保持或提升推理性能的同时能显著降低推理步数和计算成本，这一优势在约 25 篇论文中被证实。推理效率优化不应仅关注 Token 数量，还需考虑推理步骤的语义质量和逻辑连贯性，避免盲目压缩导致关键信息丢失，这一观点在约 20 篇论文中被强调。

与此相关的另一个共识是，课程学习在推理模型的后训练中具有重要作用，能引导模型从简单到复杂逐步掌握推理模式，这一策略在约 15 篇论文中被验证。现有 Transformer 架构在有限精度下存在表达力瓶颈，CoT 通过增加有效深度部分弥补了这一限制，但理论上限仍受限于电路复杂度类，这一理论边界在约 10 篇论文中被揭示。推测解码及其变体是加速 CoT 生成的有效技术，能在不损失质量的前提下提升推理吞吐量，这一系统级优化手段在约 10 篇论文中被证实。

### 3.2 观点分歧

离散 Token 与连续潜在空间哪种表示形式更适合高效推理，是领域内最根本的分歧。观点 A 认为显式 CoT 在 GSM8K/MATH 上准确率更高（90%+），且可解释性强，便于调试与验证；观点 B 认为潜在推理在延迟与 Token 效率上占优，且理论上可突破离散解码瓶颈，提升推理带宽。现有证据偏向观点 A 在准确率上占优，观点 B 在效率上占优：GSM8K 上显式方法（~90%）远高于潜在方法（~39-45%），但潜在方法在 HumanEval 等代码任务上表现较好（NF-CoT 70.0）。这一分歧的背后，是另一个更根本的争论：压缩是否必然导致推理难度增加。观点 A 认为 SLAT、UCoT 等实验表明，在保持精度约束下，压缩可显著降低 Token 数，且不会损害泛化能力；观点 B 认为 Chain Of Thought Compression 理论分析表明，压缩可能导致推理难度增加，特别是在奇偶问题等复杂任务中。证据混合：在简单任务（GSM8K）上压缩有益；在复杂任务（AIME）上，压缩后的方法（SLAT 34.0）与未压缩基线差距较大。

RL 奖励设计中长度惩罚与语义质量奖励的取舍，是另一个关键分歧。观点 A 认为 O1-Pruner、CRT 等通过长度惩罚直接优化 Token 数，简单有效；观点 B 认为 ETR、DRER、ThoughtFold 等通过熵趋势、效用估计或内省偏好优化推理步骤质量，避免盲目压缩。证据偏向观点 B 在复杂任务上更优，长度惩罚可能导致关键步骤被误删，语义质量奖励能更好地平衡效率与正确性。这些分歧的根源在于缺乏统一的“推理忠实度”指标来评估潜在状态的语义完整性，以及缺乏对“推理难度”的量化理论框架。

### 3.3 其他开放问题

最紧迫的工程问题是潜在推理的训练不稳定性与跨模型泛化性。现状是潜在推理方法在 GSM8K 隐式推理上准确率仅 38.5-45.8，远低于显式方法，且训练过程面临灾难性遗忘与表示对齐困难。关键困难在于缺乏有效的蒸馏策略与架构设计来稳定训练过程，且针对特定任务或模型优化的压缩策略往往难以泛化到其他领域或模型规模。研究路径包括探索多教师集成、自适应迭代停止准则及跨模型推理迁移与蒸馏。

最根本的研究问题是推理 Token 的理论下界与压缩对内在维度的影响机制。现状是 BAPO 模型与 CIB 框架提供了初步的理论指导，但理论模型与实际 Transformer 架构存在偏差，参数设定复杂。关键困难在于 Transformer 架构的非线性复杂性和任务多样性，使得严格的计算复杂度下界和泛化理论难以建立。研究路径包括信息瓶颈理论的深化、拓扑数据分析的应用及非对称群作用下的泛化机制探索。

已知—争议—未知认知图谱显示，领域在效率优化目标、RL 训练范式及系统级加速手段上已形成共识；在表示形式选择、压缩影响机制及奖励设计策略上存在显著争议；在理论下界、训练稳定性及跨模型泛化性上仍属未知。发展趋势指向潜在推理与理论分析的融合，旨在从原理层面解决效率-精度权衡问题。

## 4. 总结与展望

高效 CoT 推理的核心矛盾在于推理深度与计算效率之间的根本张力，这一矛盾在 RLVR 普及后被急剧放大。领域尝试了从显式剪枝到潜在推理、从启发式规则到理论指导的多条路线，但核心瓶颈仍在于离散 Token 的表达低效性与连续潜在空间的可解释性/稳定性之间的张力。回扣第 1 章锚点句，当前研究尚未在满足任务准确率硬约束的前提下，找到以最低计算复杂度重构推理表示与路径的最优解，且缺乏揭示该优化过程理论下界与表达能力边界的统一框架。

未来可能突破的方向包括：一是原生支持高效推理的架构设计，如循环 Transformer、分支网络及低秩蒸馏，旨在从架构层面降低计算复杂度，而非仅依赖后处理压缩，这一方向由 PCCoT、ChainGPT 及 LoRi 等论文共同指向；二是理论解释与计算复杂度分析的深化，旨在建立更严格的计算复杂度下界和泛化理论，揭示推理能力的内在结构，这一方向由 BAPO、CoT-Space 及 Transformers Provably Learn CoT 等论文共同指向。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，系统评测潜在推理方法在复杂任务（如 AIME）上的准确率-效率帕累托前沿，并探索通过自蒸馏与并行迭代解决其训练不稳定性的具体机制。
