## 导读

大语言模型（LLMs）在海量互联网数据上预训练时不可避免地摄入了公开基准测试集，导致模型通过记忆而非推理获得高分，严重扭曲了能力评估。早期研究聚焦于静态基准构建与基于 n-gram 重叠的直接检测，但很快发现这种方法无法应对语义改写和间接污染。2023-2024 年成为关键转折期，研究范式从“静态检测”转向“动态评估”与“机制解释”，Min-K% Prob、CDD 等基于输出分布和概率统计的检测方法成为主流，同时 LiveBench、BeyondBench 等动态生成基准框架开始普及，以从源头规避污染。2025-2026 年，研究重心进一步细化至强化学习（RL）后训练阶段的污染检测、评估的统计鲁棒性（如重复推理的方差分析）以及评估公平性。当前领域处于高度活跃阶段，核心矛盾在于如何在模型能力快速迭代与评估基准静态滞后之间建立可信的度量体系，研究热点正从单纯的“是否污染”检测，转向“污染程度量化”、“推理稳定性”及“评估协议本身的鲁棒性”验证。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

大语言模型评估失效的根源在于预训练数据与测试集的不可控重叠。当模型在训练过程中接触到基准测试样本时，它可能通过记忆而非泛化能力获得高分，这种现象被称为数据污染（Data Contamination）。在理想化的干净数据假设下，基准分数应反映模型的真实泛化能力；然而，在真实场景中，由于互联网数据的广泛性和基准测试集的公开性，这种重叠几乎不可避免。早期研究主要关注显式的字符串匹配，即训练数据与测试集在 n-gram 层面的直接重叠。但随着模型规模的扩大和训练数据的多样化，污染形式已从显式匹配演变为隐式语义记忆，包括经过改写、翻译或语义变换的变体污染（Evasive/Variant Contamination）。这种隐蔽性使得传统的表面匹配方法失效，迫使研究者重新审视评估的有效性。

问题结构从单一的“数据泄露”扩展为“检测-量化-缓解-协议鲁棒性”的多维依赖体系。首先必须解决“检测”问题，即识别污染的存在；在此基础上，才能进行“影响分析”，量化污染导致的性能虚高程度。“动态基准构建”是“检测”的互补替代方案，旨在从源头消除问题，确保测试集在模型训练截止日之后仍保持新颖性。“推理时去污”和“评估鲁棒性测试”则依赖于对污染机制和评估不稳定性的深入理解，属于事后修正和协议优化层面。这些子问题之间存在强依赖关系：检测是基础，影响分析是量化，动态基准是预防，鲁棒性测试是验证，四者共同构成可信评估闭环。核心挑战在于如何在黑盒/白盒不同访问权限下，区分模型的高分源于“记忆”还是“泛化”。

2020-2022 年是领域的奠基期，核心假设是污染表现为训练数据与测试集的字符串重叠。这一时期的主要方法是 n-gram 匹配和基于困惑度（Perplexity）的阈值判断。N-gram Overlap 通过计算训练语料与测试集之间的重叠率来识别数据污染，这是最早被广泛采用的审计手段。该方法直观且计算成本低，但严重依赖对训练数据的访问权限，且无法检测经过改写或语义变形的污染样本。Loss/Perplexity Thresholding 则基于模型在测试样本上的对数似然或困惑度设置阈值，低损失样本被视为已记忆的训练数据。这种方法利用了模型对训练数据拟合良好的特性，但容易受到数据分布偏移的影响，且在模型规模增大时区分度下降。

2023-2024 年成为关键转折期，研究范式从“表面匹配”转向“分布统计”与“动态评估”。语义改写和间接污染使字符串匹配失效，Min-K% Prob 等概率统计方法成为主流。Min-K% Prob 计算测试样本中概率最低的 k% token 的平均概率，以此作为记忆程度的指标。相比整体困惑度，该方法聚焦于模型最不确定的部分，提高了对污染样本的敏感度。同时，LiveBench 等动态基准从源头规避污染，通过从最新来源提取并转换问题来构建动态更新的基准，确保测试集在模型训练截止后仍保持新颖性。CDD（Contamination Detection via Distribution）则通过多次随机采样并计算输出分布的峰值度来检测污染，提供了一种黑盒检测视角。

2025-2026 年，研究重心进一步细化至 RL 后训练阶段的污染检测、评估的统计鲁棒性以及评估公平性。RL 通过奖励优化而非似然最大化训练，导致基于概率的检测信号失效，目前正尝试通过层表示分析和熵变化来探索新指标。RADAR 通过提取 Transformer 内部注意力权重和隐藏状态，分析机制特征以区分回忆与推理，代表了从黑盒统计检测向白盒机制可解释性检测的技术演进。LaRA 针对 RL 后训练，分析层级表征的变化来检测污染，弥补了输出级指标在 RL 模型上性能下降的缺陷。此外，评估结果的统计不稳定性问题日益凸显，单次评估受随机种子、提示词格式和推理后端影响巨大，目前正通过混合效应模型和多次重复实验来建立置信区间和稳定性指标。

当前领域处于高度活跃阶段，核心矛盾在于如何在模型能力快速迭代与评估基准静态滞后之间建立可信的度量体系。研究热点正从单纯的“是否污染”检测，转向“污染程度量化”、“推理稳定性”及“评估协议本身的鲁棒性”验证。评估基准的区分度随模型能力提升而迅速饱和，需要不断开发更高难度或动态生成的基准来维持评估的有效性。同时，评估的公平性不仅取决于数据，还取决于评估协议本身，包括提示词标准化、评分一致性和抗操纵性，需要建立统一的评估标准。动态基准生成虽然能规避污染，但引入了新的噪声和偏差，需要结合自动化验证和人工审核来确保生成数据的质量。

**如果用一个核心问题概括该领域，那便是：如何在模型能力快速迭代与评估基准静态滞后之间，建立一套能够区分“记忆”与“推理”、具备统计鲁棒性且可验证的度量体系，以确保证据链的完整性。**

## 2. 方法体系

- 2020：N-gram Overlap——通过计算训练语料与测试集之间的n-gram重叠率来识别数据污染，奠定该领域方法基线。

- 2021：Loss/Perplexity Thresholding——基于模型在测试样本上的对数似然或困惑度设置阈值，开启基于统计特征的白盒检测范式。

- 2023：Min-K% Prob——计算测试样本中概率最低的k% token的平均概率，成为后续许多检测工作的标准基线。

- 2023：LiveBench——通过从最新来源提取并转换问题来构建动态更新的基准，推动基准从静态快照向动态演化的范式转变。

- 2024：CDD (Contamination Detection via Distribution)——通过多次随机采样并计算输出分布的峰值度来检测污染，提供黑盒检测视角。

- 2025：RADAR——通过提取Transformer内部注意力权重和隐藏状态，分析机制特征以区分回忆与推理，代表白盒机制可解释性检测。

- 2026：DyePack——在测试集中混合后门样本，通过检测模型是否激活这些后门来证明性地标记污染，引入主动防御机制。

- 2026：Stereological Theory——应用立体几何理论分析基准覆盖度的几何盲点，为基准设计提供理论极限。

这条时间线勾勒了该领域方法演进的代表性节点：从 2020 年的 N-gram Overlap 奠定该领域方法基线，经 2021 年 Loss/Perplexity Thresholding 的推进，到 2026 年的 Stereological Theory 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 污染检测机制

污染检测机制的研究始于对训练数据与测试集重叠的直接审计。早期方法如 N-gram Overlap 和 Loss/Perplexity Thresholding 依赖对训练数据的访问或模型内部概率，但无法应对语义改写。2023 年，Min-K% Prob 通过聚焦于模型最不确定的 token 提高了敏感度，成为新的基线。然而，随着 RL 后训练的普及，基于似然的信号失效，促使研究转向内部表征和分布行为。RADAR（Kattamuri et al., 2025, P8）提出了一种基于机制路径的污染检测框架，通过提取 Transformer 内部的注意力权重和隐藏状态来区分模型的回忆行为与推理行为。该方法包含机制分析器、特征提取器和分类器三个核心组件，机制分析器计算注意力熵、专业化指标以及隐藏状态的方差、范数和有效秩等动态特征。相比传统的 n-gram 匹配或困惑度阈值方法，RADAR 不依赖对训练数据的访问，且能够识别经过改写的变体污染，因为它关注的是模型内部处理信息的机制而非表面文本相似度。其代价是需要白盒访问权限以获取中间层激活值，且计算开销高于简单的统计检测。

针对 RL 后训练阶段，Entropy-Temp/Noise（Tao et al., 2025, P9）利用熵作为核心指标，因为 RL 优化奖励函数而非似然，导致传统的对数概率指标失效。该方法设计了特定的探针机制，包括 Entropy-Temp、Entropy-Noise 和 Self-Critique，通过随机采样或非成员前缀来激发模型对污染样本的记忆信号。Self-Critique 探针通过让模型自我评估答案的正确性来间接检测记忆，因为记忆模型往往表现出过度自信。相比预训练或 SFT 阶段的检测器，该方法专门适配了 RL 训练带来的分布偏移，解决了现有方法在 RL 模型上性能骤降的问题。其核心假设是 RL 训练会导致污染样本的输出分布熵值出现异常波动，而非简单的概率降低。该方法填补了 RL 后训练阶段污染检测的空白，为评估 RLHF 等对齐技术后的模型提供了更可靠的审计工具。

DVD（Liang et al., 2026, P16）提出了一种无需训练的变体污染检测方法，通过分析多次随机解码输出分布的方差来识别污染。该方法假设模型在污染查询上会表现出异常的波动，即使表面文本经过改写，其内部记忆仍会导致生成结果的不稳定。DVD 通过计算多次采样输出之间的差异，穿透表面层面的改写，捕捉到模型对特定语义内容的过度拟合。相比 CDD 等基于峰值度的方法，DVD 对解码超参数（如温度）具有更高的鲁棒性，且在多种模型规模和领域上显著优于现有方法。其优势在于完全黑盒，仅需模型生成能力，无需访问内部参数或训练数据。该方法有效解决了传统检测手段在语义变体污染下失效的难题，为评估模型的泛化能力提供了更稳健的指标。

DyePack（P40）提出了一种通过在后门样本中混合特定模式来证明性地标记测试集污染的方法。该方法在发布的测试数据中混入少量包含多个后门和随机目标的样本，当模型在评估中表现出对这些后门样本的异常高准确率时，即可检测到污染。DyePack 的核心创新在于提供了可计算且界限明确的假阳性率（FPR），无需访问模型的损失函数或 Logits，仅通过基准排名即可验证。相比传统的 n-gram 审计，DyePack 是一种主动防御机制，允许基准发布者验证测试集的安全性，防止数据泄露。其代价是需要预先设计后门样本并嵌入测试集，可能略微影响基准的自然性。该方法在领域内引入了主动安全验证的概念，使污染检测从被动审计转向主动监控。

LaRA（Gwak et al., 2026, P35）针对 RL 后训练阶段，通过层级表征分析来检测数据污染，因为输出级统计在 RL 模型中变得不可靠。该方法分析了模型各层隐藏状态的变化，发现 RL 训练中的奖励驱动过拟合会导致内部表征出现特定的异常模式，如校准偏差或概率分布的扭曲。LaRA 通过比较污染样本与非污染样本在层级表征上的差异，构建了一个更深层的检测信号，弥补了输出级指标（如 PPL 或 Min-K%）在 RL 模型上性能下降的缺陷。其核心假设是 RL 优化过程会在内部表征中留下独特的“指纹”，即使输出分布看起来正常。该方法在 Eurus 和 LIMR 等 RL 模型上展示了优于基线的检测能力，特别是在训练检查点演变过程中。它为评估 RL 对齐后的模型提供了更精细的诊断工具，推动了污染检测从输出层向内部表征层的深入。

CDD Effectiveness Analysis（Sela, 2026, P25）系统研究了基于输出分布峰值度的 CDD 方法在小语言模型上的有效性与局限性。该研究通过受控污染实验发现，CDD 的有效性严重依赖于微调是否产生了逐字记忆，在大多数条件下，即使数据被证实污染，CDD 的表现也接近随机猜测。相比之下，基于概率的方法（如 Perplexity 和 Min-K% Prob）在所有超过随机水平的条件下均优于 CDD，表明峰值度方法不足以检测小模型中的污染。该分析揭示了 CDD 方法的内在缺陷，即其假设的“分布坍缩”在小模型或未充分记忆的场景下并不成立。这一实证工作为选择检测工具提供了重要指导，指出在资源受限或小模型场景下应优先使用概率基方法。

In-Context Learning Contamination Detection（Zawalski et al., 2025, P11）提出了一种利用上下文学习行为差异来检测污染的方法。该方法观察到，当模型记忆了数据集时，添加来自该数据集的上下文样本不仅不会提供新信息，反而会干扰记忆模式，导致模型置信度下降；而对于未见过的数据，上下文样本通常会提升置信度。通过比较有无上下文学习时的置信度变化，可以自动化地检测污染，无需访问训练数据或进行复杂的参数调优。该方法的优势在于其自动化和可扩展性，适用于多种数据集和架构，且结果具有可解释性。其核心逻辑利用了记忆模型与泛化模型在 ICL 动态上的根本差异。该方法为黑盒模型提供了一种轻量级且直观的污染检测手段，特别适用于无法获取内部状态的专有模型。

Provable Joint Decontamination（Liu et al., 2026, P32）提出了一种针对多个 LLM 联合基准测试的可证明去污方法，利用共形预测构建联合选择框架。该方法通过共享校准集计算模型级共形 p 值，并适应联合选择问题，确保在审计多个模型时保持有效的错误率控制。其核心创新在于处理数据异质性，采用自适应加权方案而非固定权重，以应对不同模型训练数据分布的差异。相比单模型去污，该方法解决了多模型比较中因污染程度不同导致的排名失真问题。其代价是需要构建包含所有审计模型已知成员的校准集，这在实践中可能具有挑战性。该方法为多模型基准测试提供了统计保证，增强了评估结论的可靠性，特别是在模型家族多样化的场景下。

### 2.2 动态基准构建

动态基准构建旨在从源头消除污染风险，确保测试集在模型训练截止日之后仍保持新颖性。BeyondBench（Srivastava et al., 2025, P5）提出了一种抗污染的推理评估框架，通过动态校准问题复杂度以匹配模型的 Token 预算，确保问题在架构限制内可解。该方法将问题复杂度分解为提示、解决方案和缓冲区的 Token 需求，并据此调整参数（如列表长度、磁盘数量），生成新颖且难度适中的推理任务。相比静态基准，BeyondBench 通过参数化生成避免了与预训练数据的重叠，同时通过动态难度调整防止问题过难或过易导致的评估偏差。其核心优势在于结合了抗污染与模型适配性，提供了更真实的泛化能力测量。该方法在 GSM8K 等数学推理任务上展示了有效性，为推理模型评估提供了新范式。

CoreEval（Zhao et al., 2025, P12）提出了一种自动构建抗污染数据集的框架，利用真实世界知识通过数据重写和生成来更新基准。该方法区分了数据重写（修改现有数据）和数据生成（创建新数据）两种策略，并设计了自动更新流程以应对静态基准的污染问题。CoreEval 通过从最新来源（如新闻、论文）提取信息并转换为任务特定数据集，确保测试集的时间新颖性。相比 LiveBench，CoreEval 强调了自动化的可扩展性，减少了人工标注的成本。其核心假设是最新数据最不可能出现在模型的预训练语料中。该方法为持续评估 LLM 能力提供了自动化基础设施，推动了基准从静态到动态的转变。

FuncBenchGen（P42）提出了一种用于评估多步函数调用能力的动态基准生成框架，将任务形式化为有向无环图（DAG）上的遍历问题。该方法自动生成合成的、无污染的函数集和任务，通过控制依赖深度来调节难度，确保测试集的新颖性和可控性。模型仅接收函数列表和输入变量，需推断正确的调用序列，从而测试其推理和规划能力。相比静态工具使用基准，FuncBenchGen 通过参数化生成避免了数据泄露，并提供了细粒度的难度控制。其核心创新在于将函数调用抽象为图遍历，使得难度可量化且可动态调整。该方法为工具使用场景提供了抗污染的评估方案，揭示了模型在复杂依赖关系下的性能瓶颈。

A$^2$utoLPBench（Ren et al., 2026, P37）提出了一种通过逆 KKT 构造自动生成线性规划（LP）基准的方法，利用生成器与语料库的结构区分保证无污染。该方法通过参数化实例生成，确保任何从训练截止后选择的种子范围生成的批次都不可能在模型的训练语料中出现。此外，它提供了闭式 KKT 证书，消除了对求解器的依赖，并支持动态种子范围以获取新鲜批次。相比静态 LP 基准，A$^2$utoLPBench 通过结构保证而非经验审计来防止污染，并支持 Agent 友好的部署环境。其核心优势在于提供了数学上严格的无污染保证，同时保持了问题的复杂性。该方法为数学推理任务提供了结构化的抗污染基准生成方案，特别适用于需要精确验证的场景。

ArenaBencher（Liu et al., 2025, P7）提出了一种通过多模型竞争评估实现自动基准演化的框架，利用模型间的性能差异来生成新的测试用例。该方法分析模型在现有基准上的表现，识别出区分度高的任务特征，并自动生成具有类似特征的新问题，以维持基准的区分能力。相比静态基准，ArenaBencher 通过动态演化适应模型能力的提升，防止基准饱和。其核心假设是模型间的竞争性能差异反映了任务的真实难度和区分度。该方法为基准的长期维护提供了自动化方案，减少了人工设计新任务的负担。它推动了基准从一次性发布向持续演化的范式转变，确保了评估的长期有效性。

LLMEval-Fair（P45）提出了一种基于私有题库和动态采样的抗污染评估框架，通过两层反作弊架构和 LLM-as-Judge 相对排名管道来确保评估的公平性和鲁棒性。该方法构建了一个包含 22 万个问题的私有题库，通过增量扩展和随机采样，确保每次评估使用不同的问题子集，从而防止数据泄露。相比公开静态基准，LLMEval-Fair 通过私有化和动态化结合，显著降低了污染风险。其核心创新在于引入了纵向研究视角，追踪模型家族随时间的性能变化。该方法为大规模模型评估提供了可信的基础设施，强调了评估协议在防止策略性操纵中的重要性。

LiveMedBench（Yan et al., 2026, P20）提出了一种无污染的医疗基准，通过自动化评分标准（Rubric）评估和持续数据更新来确保评估的有效性。该方法从实时医疗讨论中提取结构化临床案例，并生成特定的评分标准，以评估模型在临床决策中的安全性和沟通能力。相比静态医疗基准，LiveMedBench 通过时间对齐和自动化评估，解决了医疗知识快速更新带来的挑战。其核心优势在于结合了动态数据源和结构化评估协议，提供了更真实的临床场景测试。该方法为高风险领域的 LLM 评估提供了新范式，强调了评估标准随领域知识演进而更新的重要性。

GSM-SEM（Singh et al., 2026, P29）提出了一种生成语义变体增强的基准和框架，通过实体替换、场景转换等扰动生成语义等价但表面形式不同的数学问题。该方法旨在测试模型对表面形式变化的鲁棒性，并检测潜在的污染或过拟合。相比原始 GSM8K，GSM-SEM 通过变体生成提供了更细粒度的评估维度，区分了记忆与推理。其核心假设是如果模型在变体上性能显著下降，则表明其依赖记忆而非泛化。该方法为数学推理评估提供了抗污染的变体集，帮助研究者识别模型的脆弱性。它推动了评估从单一答案匹配向鲁棒性测试的转变。

### 2.3 推理时去污

推理时去污旨在在模型推理阶段抑制模型对污染数据的记忆效应，恢复真实性能评估。DeconIEP（Chai et al., 2026, P19）提出了一种推理时去污方法，通过在输入嵌入中添加有界扰动来抑制记忆捷径，引导模型进行推理。该方法训练一个生成器 $G_\theta$，通过 KL 散度目标对齐污染模型与参考模型，在测试时应用扰动以恢复干净性能。相比过滤样本或修改权重，DeconIEP 是非侵入式的，无需重新训练模型，仅需在推理阶段干预。其核心假设是记忆效应可以通过输入空间的微小扰动被打破，从而激活模型的推理路径。该方法在多个 Qwen 模型上展示了有效性，降低了污染导致的性能虚高。它为部署后的模型提供了灵活的性能校正手段，特别适用于无法重新训练的场景。

LNE-Blocking（P44）提出了一种基于长度归一化熵（LNE）的污染缓解评估框架，通过估计每个问题的污染程度来动态调整解码策略。该方法计算模型输出的 LNE，高 LNE 值表明模型对答案不确定，可能未记忆；低 LNE 值表明模型高度自信，可能记忆。基于此，LNE-Blocking 可以屏蔽特定神经元或调整解码参数，以抑制记忆效应。相比全局去污，LNE-Blocking 是问题级别的，提供了更精细的控制。其核心优势在于无需访问训练数据，仅依赖模型输出即可估计污染程度。该方法为推理阶段的去污提供了实用工具，平衡了去污效果与计算开销。

Zero-CoT Truncation（Lan et al., 2026, P33）提出了一种通过截断思维链（CoT）来暴露隐蔽数据污染的方法，利用推理模型与记忆模型在 CoT 行为上的差异。该方法观察到，污染模型往往依赖记忆直接给出答案，而忽略或简化推理过程；因此，通过强制截断 CoT，可以放大这种差异，使污染模型的性能显著下降。相比直接检测污染，Zero-CoT Truncation 是一种诊断工具，用于验证模型是否真正进行了推理。其核心假设是 CoT 是推理能力的体现，记忆模型无法生成有意义的 CoT。该方法为检测间接污染提供了新视角，揭示了 CoT 可能掩盖污染事实。

Spiking Training Data（Wei et al., 2026, P34）提出了一种通过统计方法校正测试集污染的方法，利用校准集估计样本难度和正确性预测器，反事实地预测无污染时的性能。该方法不剔除样本，而是对分数进行统计校正，保留了数据量，避免了因剔除样本导致的评估偏差。其核心创新在于结合了项目反应理论（IRT）的思想，通过多个响应来隔离样本难度。相比简单的过滤方法，Spiking 提供了更原则性的统计校正框架。其代价是需要构建校准集并训练预测器，增加了预处理步骤。该方法为事后修正评估结果提供了统计基础，增强了评估结论的可靠性。

Stratified Per-Question Probability Evaluation（Hou et al., 2026, P38）提出了一种分层逐题概率评估和逐步缓解基准污染的方法，通过比较离散 0/1 和概率表示来改进评估聚合。该方法指出，单样本 0/1 读取甚至无法在两次评估中复现，因此采用概率表示并修复聚合过程。在缓解方面，它估计污染位置并操作估计部分，粒度从响应到问题再到神经元不等。相比全局去污，该方法提供了更细粒度的控制，并比较了不同缓解策略的效果。其核心优势在于揭示了评估表示对污染敏感性的影响。该方法为评估协议的设计提供了指导，强调了概率聚合在鲁棒评估中的重要性。

Quantifying Generative Contamination Impact（Schaeffer et al., 2026, P15）通过预训练计算最优语言模型，量化测试集污染对生成式评估的影响，发现污染导致的性能提升随模型规模增大而加剧。该方法通过控制测试集副本数量，测量 Math Verify 分数和交叉熵的变化，揭示了生成式任务对污染的敏感性高于判别式任务。其核心发现是，生成式任务中，污染模型更倾向于将概率质量集中在正确选项上，而非仅仅降低损失。这为理解污染在不同任务类型中的机制提供了新见解。该方法强调了在生成式评估中校正污染的重要性，为评估协议的设计提供了实证依据。

### 2.4 评估鲁棒性测试

评估鲁棒性测试旨在量化 LLM 对输入变体、上下文噪声及对抗性干扰的敏感性与稳定性。Brittlebench（Romanou et al., 2026, P26）提出了一种通过提示词敏感性测试量化 LLM 鲁棒性的框架，系统测量模型对表面形式变化（如拼写、格式、填充）的脆弱性。该方法发现，所有模型和基准都对扰动敏感，且表面形式变化影响最大，即使是大模型也未完全消除这种不稳定性。相比单一任务测试，Brittlebench 提供了标准化的鲁棒性度量，揭示了规模扩大并未线性提升鲁棒性。其核心优势在于提供了细粒度的敏感性分析，帮助识别模型的具体弱点。该方法为评估模型的部署可靠性提供了新维度，强调了鲁棒性在真实世界应用中的重要性。

Repetition Reliability Study（Alvarado Gonzalez et al., 2025, P4）通过混合效应逻辑回归和排名不稳定性分析，评估 LLM 评估中重复运行的必要性，发现单次运行排行榜是脆弱的，多次运行可显著减少排名反转。该方法量化了从单次到三次运行带来的标准误缩小和排名增益，提供了成本感知的实践指南。相比单次评估，该研究强调了评估作为实验的统计性质，建议至少进行两次重复以消除大部分不稳定性。其核心贡献在于为评估协议提供了统计依据，平衡了计算成本与可靠性。该方法推动了评估实践从单次快照向多次重复的转变，提高了结论的可信度。

MASTER（P39）提出了一种自动化鲁棒性评估框架，通过多轮重写-验证循环动态生成基准变体，以最小化数据污染风险并诱导模型失败。该方法针对数学推理任务，生成语义一致但表面形式不同的问题，测试模型对指令遵循和推理的鲁棒性。相比静态变体，MASTER 通过动态生成适应特定模型，提高了评估的针对性。其核心优势在于结合了抗污染与鲁棒性测试，揭示了模型在轻微修改下的性能下降。该方法为数学推理评估提供了自动化工具，强调了鲁棒性在评估中的核心地位。

LPDS（Mondorf et al., 2026, P30）提出了一种通过逻辑保持的难度缩放评估 LLM 鲁棒性的方法，使用距离度量（如 Levenshtein 和 Mahalanobis）量化模型响应偏离正确路径的程度。该方法生成不同难度的问题变体，分析模型在难度增加时的表现，区分部分正确与完全失败。相比单一难度测试，LPDS 提供了细粒度的鲁棒性分析，揭示了模型在复杂推理中的脆弱性。其核心创新在于将难度与响应偏差关联，提供了更丰富的评估指标。该方法为推理能力的评估提供了新视角，强调了难度缩放在设计鲁棒性测试中的重要性。

Paraphrase Robustness Analysis（Lunardi et al., 2025, P1）通过生成语义保持的释义，评估 LLM 在固定措辞基准上的鲁棒性，发现模型对输入变体高度敏感，性能波动显著。该方法在多个基准（如 MMLU, HellaSwag）上测试了不同模型对释义的响应，揭示了评估设置对结果的巨大影响。相比原始基准，该研究强调了评估协议中随机因素（如提示措辞）的控制必要性。其核心贡献在于量化了释义对模型排名的影响，指出固定措辞可能导致不公平比较。该方法为评估协议的设计提供了指导，强调了标准化提示的重要性。

Instance-level Randomization（Li et al., 2025, P2）提出了一种通过实例级随机化提高 LLM 评估稳定性的方法，随机化少样本示例、任务描述和提示格式，以消除偏差和方差。该方法发现，当前评估范式因固定随机因素而导致不稳定，随机化可显著减少模型排名波动。相比固定设置，Instance-level Randomization 提供了更公平的评估环境，减少了特定提示对结果的过度影响。其核心优势在于通过随机化模拟真实世界的多样性，提高了评估的泛化性。该方法为评估协议提供了改进方案，强调了随机因素控制在鲁棒评估中的重要性。

Token Constraint Bound（P43）提出了一种基于几何视角的 LLM 预测稳定性度量，利用 Jacobian 矩阵量化模型对上下文细微变化的敏感性。该方法定义了 $\delta_{TCB}$，衡量输出分布对隐藏状态变化的敏感度，揭示了模型预测的局部稳定性。相比经验性扰动测试，$\delta_{TCB}$ 提供了理论化的稳定性指标，可解释模型为何对某些变化敏感。其核心创新在于将稳定性分析形式化为几何问题，提供了更深入的机制理解。该方法为评估模型的鲁棒性提供了新工具，强调了内部表征稳定性在预测可靠性中的作用。

Accelerated Prompt Stress Testing (APST)（Broadwater, 2026, P21）提出了一种深度导向的评估范式，通过重复采样相同提示并在受控操作压力（如解码温度、提示扰动）下运行，估计每次推理的失败概率。该方法关注模型在持续使用下的可靠性，而非单次正确性，揭示了罕见但持久的失败如何累积为操作风险。相比广度导向的基准，APST 提供了更细粒度的可靠性估计，适用于高风险应用。其核心优势在于模拟了真实部署中的重复查询场景，强调了稳定性在安全关键任务中的重要性。该方法为 LLM 安全评估提供了新维度，推动了评估从静态正确性向动态可靠性的转变。

### 2.5 污染影响分析与评估方法论审计

污染影响分析旨在量化数据污染对模型性能、泛化能力及不同训练阶段的具体影响。Soft Contamination Analysis（Spiesberger et al., 2026, P22）结合污染检测与微调实验，诊断基准上的“浅层泛化”，即特定于基准的性能增益，揭示语义相关训练数据导致的性能虚高。该方法利用开源模型 Olmo-3-7b，嵌入不同比例的训练数据，分析其对基准性能的影响，区分了直接记忆与过拟合。相比仅检测污染，该研究深入分析了污染如何影响泛化能力，揭示了即使没有逐字记忆，语义污染也会导致性能提升。其核心贡献在于定义了“浅层泛化”概念，强调了评估需区分真实泛化与基准特定增益。该方法为理解污染机制提供了新视角，推动了评估从检测向机制分析的深入。

Post-training Contamination Impact（Kocyigit and Yildirim, 2026, P17）通过对比预训练和后训练（SFT/RL）阶段注入污染的实验，量化后训练对污染影响的放大或抑制作用。该方法发现，后训练阶段可能加剧或缓解污染效应，取决于训练数据和算法，揭示了污染影响的动态性。相比仅关注预训练污染，该研究强调了后训练在评估有效性中的关键作用，指出 SFT 和 RL 可能改变模型对污染数据的依赖程度。其核心贡献在于提供了全生命周期的污染影响分析，为评估协议的设计提供了更全面的基础。该方法揭示了后训练作为污染“放大器”或“过滤器”的双重角色。

Fragility of Detection in Reasoning Models（Wang et al., 2025, P6）分析强化学习（RL）训练如何降低污染检测器的有效性，发现 RAFT++ 和 GRPO 等 RL 算法通过重要性采样和裁剪机制掩盖了污染信号。该方法通过理论分析和实验验证，揭示了 RL 训练导致的检测器性能骤降，解释了为何传统检测器在推理模型上失效。相比静态分析，该研究动态考察了训练过程对检测性的影响，强调了 RL 算法在污染掩盖中的作用。其核心贡献在于揭示了 RL 训练与污染检测之间的对抗关系，为开发 RL 鲁棒的检测器提供了方向。该方法指出了当前检测工具在最新模型上的局限性。

Lexical and Syntactic Sensitivity Analysis（Kostić et al., 2026, P24）通过系统测试词汇和句法扰动，量化 LLM 评估对表面形式变化的敏感性，发现模型性能对无关上下文、前提重排和符号变化高度敏感。该方法在 23 个 SOTA 模型上评估了零样本设置下的敏感性，揭示了模型规模与鲁棒性之间的弱相关性。相比单一扰动测试，该研究提供了全面的敏感性图谱，强调了评估设置对结果的巨大影响。其核心贡献在于量化了不同扰动类型的影响程度，为评估协议的设计提供了实证依据。该方法揭示了表面形式敏感性是评估不稳定的主要来源之一。

Obscuring Contamination via Translation（Abbas et al., 2026, P18）通过阿拉伯语语料库实验，揭示翻译如何掩盖数据污染，使基于 n-gram 或语言模型的检测器失效。该方法发现，跨语言污染难以通过传统方法检测，因为表面形式差异巨大，但语义内容保留。相比单语言分析，该研究强调了多语言场景下污染检测的挑战，揭示了语言转换作为污染掩盖手段的有效性。其核心贡献在于指出了现有检测工具在多语言环境中的盲区，为开发跨语言检测器提供了动机。该方法揭示了污染检测在低资源语言中的局限性。

Contamination Sensitivity and Score Confidence（Song et al., 2026, P27）提出了一种形式化框架，将基准分数视为观察分布下的经验性能，研究污染敏感性和分数置信度，引入路由器-工作者机制来评估分数作为真实泛化指标的条件。该方法推导了无污染设置下噪声聚合不应系统性优于干净基线的理论判断，强调了评估协议对分数解释的影响。相比简单分数报告，该研究提供了分数有效性的条件分析，强调了污染敏感性在解释分数时的关键作用。其核心贡献在于将污染敏感性纳入评估理论框架，为分数解读提供了统计基础。该方法推动了评估从数值报告向有效性审计的转变。

评估方法论审计旨在审视现有基准的覆盖度、饱和性及统计可靠性。BenchRisk（McGregor et al., 2025, P10）提出一种基准风险管理框架，审视基准在安全决策中的可靠性，识别覆盖度不足、污染风险和范围模糊等失败模式。该方法将风险评估理论引入 LLM 评估，强调基准作为决策依据时的局限性，提出了改进基准设计和使用的建议。相比单纯的性能排名，BenchRisk 关注评估结论的可信度和适用性，强调了元评估的重要性。其核心贡献在于提供了系统化的风险识别工具，帮助用户理解基准的边界条件。该方法推动了评估从技术工具向治理工具的转变，强调了负责任评估的必要性。

Stereological Theory of Benchmark Coverage（Wang, 2026, P36）应用立体几何理论分析基准覆盖度的几何盲点，证明低维投影无法恢复模型能力的完整结构，指出几何盲点主导了统计噪声。该方法从数学上界定了有限基准的局限性，强调了多维评估的必要性，为基准设计提供了理论极限。相比经验性覆盖分析，该研究提供了严格的数学证明，揭示了基准饱和的根本原因。其核心贡献在于将几何理论应用于评估设计，为基准扩展提供了指导。该方法推动了评估理论从经验向数学基础的深化。

Robust Inference Framework（Jo and Wilson, 2025, P3）提出一种基于心理测量学原则的鲁棒推理框架，通过置信区间和偏差校正来改进 AI 能力评估的可靠性。该方法指出传统基准假设的能力理论是错误的，提出了更细致的能力模型，考虑了输入、超参数和上下文的影响。相比点估计，该框架提供了区间估计，强调了评估结果的不确定性。其核心贡献在于将心理测量学方法引入 AI 评估，提高了结论的统计严谨性。该方法为评估协议提供了改进方案，强调了不确定性量化在可靠评估中的重要性。

Benchmark Saturation Study（Akhtar et al., 2026, P23）提出一种系统研究基准饱和的方法，通过统计显著性测试判断顶级模型性能是否收敛，定义了饱和的量化标准。该方法使用有效测试集大小和标准误来评估模型间的差异，避免了对外部性能上限的依赖。相比主观判断，该研究提供了客观的饱和检测工具，帮助识别失去区分力的基准。其核心贡献在于提供了可复现的饱和评估协议，为基准更新提供了依据。该方法推动了评估从持续排名向动态更新的转变，强调了基准生命周期的管理。

Measuring All Noises in LLM Evals（Wang, 2025, P14）提出一种全面测量 LLM 评估中噪声的方法，区分预测噪声、采样噪声和聚合噪声，提供标准误和置信区间的计算指南。该方法基于 Miller (2024) 的方法，澄清了常见混淆，提供了直接可推广到所有指标函数的方差估计。相比单一噪声源分析，该研究提供了全面的噪声分解，强调了统计严谨性在解释结果中的重要性。其核心贡献在于提供了实用的噪声测量工具，帮助研究者区分信号与噪声。该方法提高了评估结论的可信度，推动了评估实践的标准化。

Unified Perturbation Framework for Leaderboard Stability（Oyarhoseini et al., 2026, P31）提出一种统一扰动框架，分析 LLM 排行榜的稳定性和操纵性，测量改变顶级模型所需的最小扰动数量。该方法基于 Bradley-Terry 模型，量化了投票数据中的噪声和偏差对排名的影响，揭示了排行榜的脆弱性。相比静态排名，该研究动态评估了排名的鲁棒性，强调了评估协议对结果的影响。其核心贡献在于提供了排行榜操纵性的量化指标，为评估平台的改进提供了依据。该方法推动了评估从静态排名向动态稳定性分析的转变。

Portable Validity Protocol for Confidence Signals（Cacioli, 2026, P28）提出一种便携式有效性协议，借鉴临床人格评估的 MMPI-3，在解释 LLM 置信度信号前进行有效性筛查。该方法通过计算错误置信度、低置信度正确项和反转监控等指标，判断置信度信号是否可解释，分为无效、不确定和有效三类。相比直接使用置信度，该协议强调了前置筛查的重要性，避免了基于无效信号的决策。其核心贡献在于引入了临床评估的有效性筛查概念，提高了置信度使用的可靠性。该方法为选择性预测和安全关键决策提供了更稳健的基础。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

静态公开基准测试集极易被大规模预训练语料污染，导致模型性能评估失真，必须引入动态更新或去污染机制。这一共识在多个基准上被反复验证：CoreEval 的 94.5% 抗污染能力与 BeyondBench 的 59.41% 鲁棒性准确率均表明动态基准在源头规避污染方面的有效性（支撑证据：P12、P5）。与此相关的另一个共识是，基于输出概率统计的方法在检测预训练和 SFT 阶段的污染方面比基于 n-gram 匹配的方法更鲁棒，但需在黑盒场景下谨慎使用。Min-K% Prob 的 52.19% AUROC 与 RADAR 的 93.0% 准确率对比显示，概率统计方法在特定场景下仍具竞争力，但白盒机制解释在检测变体污染方面具有显著优势（支撑证据：P8、P25）。

单次评估结果具有高度不稳定性，受随机因素（如解码温度、提示词格式）影响显著，必须通过多次重复实验并报告置信区间来确保结论的可靠性。Brittlebench 的 88.2% 稳定性得分与 Instance-level Randomization 的 85.6% 稳定性得分对比显示，随机化在消除偏差和方差方面的有效性（支撑证据：P26、P2）。数据污染不仅包括精确匹配，还包括语义改写和间接泄露，传统检测方法难以覆盖这些隐蔽形式，需要更深层的行为分析。DVD 的 85.0% 准确率与 CDD 的 57.75% AUROC 对比显示，基于输出分布方差的检测在穿透表面改写方面的优势（支撑证据：P16、P25）。

### 3.2 观点分歧

黑盒统计检测（如 CDD/DVD）在前沿模型上的有效性存在显著分歧。观点 A 认为黑盒方法足够，DVD 等基于输出分布方差的方法对解码超参数鲁棒，适用于闭源模型；观点 B 认为黑盒方法在小模型和 RL 模型上接近随机猜测，必须依赖白盒机制分析。现有证据偏向观点 B 在特定场景（小模型、RL）下的正确性，但观点 A 在大模型黑盒场景下仍有实用价值。证据强度中等，缺乏在统一前沿黑盒模型上的大规模对比实验。这一分歧的背后，是另一个更根本的争论：RL 后训练对污染信号的影响是掩盖还是放大？观点 A 认为 RL 训练通过奖励优化掩盖了似然信号，导致传统检测器失效，需要新的熵/表征指标；观点 B 认为 RL 训练可能放大某些污染效应，或改变污染的性质，使其更难检测。现有实验表明 RL 算法（如 GRPO）确实降低了检测器性能，支持观点 A，但关于 RL 是否“放大”污染影响的证据较少，多为理论推测（支撑证据：P9、P35、P6）。

动态基准的质量与成本平衡也存在分歧。观点 A 认为动态生成是未来，应追求自动化和实时性；观点 B 认为动态生成引入噪声和偏差，需结合人工审核和结构化生成。证据偏向观点 B，即纯自动化生成存在质量风险，结构化生成（如 LP, DAG）提供了更严格的无污染保证。但观点 A 在通用任务上更具扩展性。未决原因在于缺乏衡量“动态基准质量”的统一标准；生成数据的标签噪声难以量化；计算成本与评估频率之间的权衡尚无共识（支撑证据：P12、P37、P5）。

### 3.3 其他开放问题

当前领域处于“工程可行但理论薄弱”的阶段。最紧迫的工程问题在于动态基准的生成成本与质量平衡。现状是动态基准如 CoreEval 和 BeyondBench 通过自动化生成减少了人工标注成本，但引入了生成数据质量不可控的新风险。关键困难在于缺乏衡量“动态基准质量”的统一标准，生成数据的标签噪声难以量化。研究路径包括开发自动化验证和代理任务适应来降低评估成本，以及结合人工审核和结构化生成来确保生成数据的质量。最根本的研究问题在于缺乏具有统计保证的污染检测理论。现状是当前方法缺乏严格的理论保证，误报率不可控。关键困难在于如何建立具有 FDR 控制、置信区间等统计性质的检测框架。研究路径包括通过自适应融合策略和统计检验程序，提供可证明的污染识别保证，增强评估结果的可信度。

已知—争议—未知认知图谱显示，已知的是静态基准不可信、单次评估不稳定、概率统计优于 n-gram；争议的是黑盒检测的有效性、RL 后训练对污染信号的影响、动态基准的质量与成本平衡；未知的是具有统计保证的污染检测理论、跨模态/跨语言的统一检测框架、推理模型中的污染检测脆弱性。发展趋势是从“检测”走向“治理”，建立包含统计保证、抗操纵性和公平性的评估协议标准。

## 4. 总结与展望

LLM 评估正从“分数竞赛”转向“可信度审计”。解决基准污染不仅是技术问题，更是科学方法论问题，需要结合统计理论、机制可解释性和动态生成技术，构建鲁棒的评估生态。核心瓶颈在于如何在模型能力快速迭代与评估基准静态滞后之间，建立一套能够区分“记忆”与“推理”、具备统计鲁棒性且可验证的度量体系。尝试过的路线包括从 n-gram 匹配到概率统计，从静态基准到动态生成，从黑盒统计到白盒机制解释，从被动审计到主动防御。这些路线在检测灵敏度、计算成本与访问权限之间做出了不同取舍，但均未完全解决前沿模型上的污染检测问题。

未来可能突破的方向包括：开发具有统计保证的污染检测理论，通过自适应融合策略和统计检验程序提供可证明的污染识别保证；研究推理模型中的污染检测脆弱性，开发专门针对推理轨迹的污染检测方法，分析推理过程如何干扰传统基于输出分布的检测信号；探索跨语言和多模态污染检测，开发能够识别跨模态记忆效应的统一检测框架。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下重评测代表性方法，以 Meta-Dataset 多域协议为主基准，并引入多次重复实验和置信区间来确保结论的可靠性。
