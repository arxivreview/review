# A Survey of LLM-Driven Scientific Discovery Methods ｜大语言模型驱动科学发现方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/LLMs%20for%20Scientific%20Discovery%20and%20Reasoning)

## 导读

大语言模型（Large Language Models, LLMs）正从通用文本处理工具向具备自主假设生成与实验执行能力的科学发现系统演进，其核心张力在于生成能力的指数级增长与科学验证所需的严谨性、可证伪性之间的滞后。早期研究将 LLM 视为文献检索或简单问答的辅助工具，受限于静态参数化知识，难以触及物理机制的深度理解。当 2024 年 AI Scientist 等系统验证了端到端科研闭环的可行性后，研究重心迅速转向动态交互，通过调用模拟器与代码解释器解决幻觉问题。随着 Agentic AI 的成熟，多智能体协作与符号回归成为提升长程任务鲁棒性与结果可解释性的关键路径。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

LLM 在科学发现领域的兴起，源于通用人工智能向垂直科学领域深化的迫切需求。早期应用主要局限于文献综述与简单问答，模型被视为被动的知识容器，其核心边界在于缺乏对物理机制的深度理解及执行复杂实验闭环的能力。这种“工具化”定位导致 LLM 在科学推理中往往依赖模式匹配而非逻辑推导，难以产生真正新颖且可验证的科学假设。随着模型规模的扩大，研究者开始关注 LLM 在复杂科学推理中的潜力，但静态知识局限与幻觉问题成为主要障碍，迫使领域从“知道什么”向“如何推导”转变。

问题定义的演化呈现出清晰的阶段性特征。2023 至 2024 年，核心问题从静态知识覆盖转向动态推理能力，引入符号回归与代码执行以解决幻觉问题，确立了 LLM 作为推理引擎而非单纯检索器的地位。2024 至 2025 年，问题定义进一步扩展为“自主性”，核心挑战变为长程任务中的错误累积、工具调用的可靠性及假设生成的新颖性评估，AI Scientist 等系统标志着从单点任务向全流程闭环的跨越。2025 至 2026 年，领域进入精细化与可信化阶段，问题定义聚焦于“可证伪性”与“安全性”，要求模型不仅给出答案，还需提供透明推理路径并防范双重用途风险，这一转变反映了科学界对 AI 贡献严谨性的更高要求。

子问题之间存在强依赖关系，构成了一个层级化的能力栈。“科学推理与算法发现”是底层能力基础，通过符号回归与因果推断支撑“科学假设生成”；“自主科研智能体”依赖前两者实现从文献综述到实验执行的闭环；而“基准评测”与“安全治理”则是贯穿全程的约束条件，若缺乏可靠的评测与安全机制，自主智能体的部署将无法成立。这种依赖结构决定了研究资源的分配逻辑：底层推理能力的突破直接决定了上层自主系统的可靠性上限，而评测与安全机制的滞后则可能制约整个系统的实际落地。

范式边界在演进中逐渐清晰。早期范式以“工具辅助”为主，LLM 仅负责信息提取与初步分析；中期范式转向“人机协作”，LLM 作为协作者参与假设生成与实验设计；当前范式则探索“自主智能体”，LLM 具备规划、执行与自我反思能力。然而，自主性并非线性提升，而是伴随着风险与复杂度的急剧增加。当前领域正处于从“辅助工具”向“自主科学家”过渡的关键期，研究热点集中在多智能体协作、符号回归、科学定律发现及伦理安全评估，旨在构建能真正理解物理机制而非仅模式匹配的智能系统。

约束演化史揭示了方法迭代的内在逻辑。2016-2018 年奠基期虽未直接涉及 LLM，但确立了科学推理的基准范式；2020 年跨域基准的引入暴露了模型在复杂场景下的脆弱性；2021 年预训练与视觉语言模型的引入，用更强的先验换取了跨域鲁棒性。2023 年 ScienceQA 等基准的出现，初步评估了模型在基础科学素养层面的推理能力，为后续更复杂的科学基准提供了数据构建范式。2024 年 FunSearch 与 AI Scientist 的出现，分别确立了 LLM 驱动进化搜索的基本架构与端到端自动化科研框架，成为后续自主智能体系统的核心基线。

2025 年，随着 Agentic AI 的成熟，ChemCrow 等工具增强型智能体确立了特定科学领域的应用范式，AlphaEvolve 则在矩阵乘法等复杂科学问题中实现算法突破，展示了 LLM 在推动算法前沿方面的潜力。2026 年，领域进入精细化阶段，SGIEvalAgent 与 HiSciBench 等基准解决了传统静态基准无法覆盖动态科研流程的问题，Eigen-Agent 通过监控式 RAG 机制显著提升了高难度领域的推理准确性，SafeSci 则建立了涵盖多学科的安全评估与增强框架。当前形态呈现出多模态基础模型与智能体架构深度融合的趋势，万亿参数级科学多模态基础模型的涌现，标志着领域从单模态文本处理向异构科学数据统一表示的转型。

**如果用一个核心问题概括该领域，那便是：如何构建具备可证伪推理路径、能自主执行假设-实验闭环且符合科学伦理规范的智能系统，以突破 LLM 在科学发现中仅依赖模式匹配的局限。**

## 2. 方法体系

- 2023：ScienceQA——构建涵盖多学科的多模态科学问答数据集，初步评估模型在基础科学素养层面的推理能力

- 2024：FunSearch——利用大语言模型作为变异算子，确立了 LLM 驱动进化搜索的基本架构

- 2024：The AI Scientist——提出端到端自动化科研框架，验证了 LLM 在模拟完整科研生命周期中的可行性

- 2024：SciMON——基于检索增强生成技术生成科学假设，引入了文献接地的概念

- 2025：AlphaEvolve——结合 LLM 引导的遗传算法，在矩阵乘法等复杂科学问题中实现算法突破

- 2025：ChemCrow——集成专家设计的化学工具，确立了工具增强型智能体在特定科学领域的应用范式

- 2026：Eigen-Agent——引入基于监控的 RAG 机制与角色化推理，显著提升了高难度领域的推理准确性

- 2026：SafeSci——提出涵盖多学科的安全评估与增强框架，解决了现有基准依赖主观评估且风险覆盖有限的问题

这条时间线勾勒了该领域方法演进的代表性节点：从 2023 年的 ScienceQA 奠定该领域方法基线，经 2024 年 FunSearch 的推进，到 2026 年的 SafeSci 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 科学推理与算法发现

科学推理与算法发现是 LLM 科学发现能力的底层基础，其核心在于从观测数据中恢复可解释的数学公式或算法。早期工作如 FunSearch（DeepMind, 2024）利用 LLM 作为变异算子，在程序搜索空间中通过迭代生成与评估循环发现数学程序，确立了 LLM 驱动进化搜索的基本架构。这一范式放弃了纯文本生成的灵活性，换取了数学公式的精确性与可验证性，解决了早期 LLM 在科学计算中频繁产生看似合理但数值错误公式的问题。然而，FunSearch 的任务被限制在可形式化的数学/物理空间，难以处理生物、化学等复杂非结构化系统。

随着任务复杂度的提升，研究者开始探索更高效的进化搜索机制。ShinkaEvolve（Lange et al., 2025, P1）提出面向开放式且样本高效的程序进化框架，通过维护固定大小的档案、实施精英大小约束及岛屿种群策略，平衡探索与利用。该方法利用基于代码嵌入相似度的新颖性拒绝采样及 LLM 作为新颖性评判器，确保生成代码的多样性，解决了现有进化搜索中容易陷入局部最优的问题。与 FunSearch 相比，ShinkaEvolve 更强调样本效率与开放式探索，但其成功依赖于代码嵌入空间的质量，假设候选解在嵌入空间中具有可度量的新颖性。

2025 年，AlphaEvolve（DeepMind, 2025）结合 LLM 引导的遗传算法与代码级假设进化，在矩阵乘法等复杂科学问题中实现算法突破，成为科学算法发现的标杆工作。AlphaEvolve 展示了 LLM 在推动算法前沿方面的潜力，但其计算成本极高，且主要适用于可形式化的优化问题。针对 AlphaEvolve 中概念与代码脱节的问题，CliffSearch（Mroueh et al., 2026, P21）提出结构化智能体协同进化框架，通过任务合同定义优化目标、候选表示及基准协议，确保进化循环的通用性与任务语义的显式注入。CliffSearch 在快速生成与科学可信选择之间建立桥梁，通过结构化智能体在概念与代码之间保持可追溯性，提升了发现结果的科学可信度与可解释性。

在符号回归领域，PTB-Search（Li, 2026, P27）挑战了 LLM 进化搜索中“循环复合”的隐含假设，提出单代组件化科学表达式发现架构。该方法通过独立提案、项提取及全局集合级稀疏重组，实现了高效且可解释的发现过程，并在标准化预算的十分之一下达到高准确率。PTB-Search 强调外部选择作为发现过程中的承重部分，一旦暴露足够的可重用组件，集合级选择即可超越多代进化。这一发现表明，LLM 在科学搜索中的真实贡献可能更多体现在组件生成而非多代进化上，为评估 LLM 在科学搜索中的贡献提供了新的实证视角。

科学推理与算法发现路线与自主科研智能体路线存在互补关系：前者提供可验证的数学/算法基础，后者提供执行框架。然而，符号回归的局限性在于其难以处理非结构化数据，这促使研究者转向多模态基础模型以覆盖更广泛的科学场景。

### 2.2 自主科研智能体

自主科研智能体旨在实现从文献综述到实验执行的全流程自动化科研闭环，其核心挑战在于长程任务中的错误累积与工具调用的可靠性。2024 年，The AI Scientist（Sakana AI, 2024）提出端到端自动化科研框架，实现从假设生成、实验执行到论文撰写的全流程闭环，验证了 LLM 在模拟完整科研生命周期中的可行性。然而，AI Scientist 暴露了长程任务中幻觉累积的致命缺陷，早期步骤的小错误会随迭代放大，导致最终结果失效。

为解决这一问题，研究者引入多智能体协作与工具调用机制。ChemCrow（Bran et al., 2024）集成 18 个专家设计的化学工具，通过“思考-行动-观察”循环执行化学合成任务，确立了工具增强型智能体在特定科学领域的应用范式。ChemCrow 放弃了单模型的简洁性，换取了长程规划与工具调用能力，但其系统复杂度急剧增加，推理延迟与 Token 消耗大幅上升。2025 年，TusoAI（Turcan et al., 2025, P2）提出用于科学方法开发的智能体优化框架，利用 LLM 合成文献、推理实证数据及生成领域特定代码的能力，加速计算方法的迭代开发过程。TusoAI 通过智能体自主执行文献审查、测试建模假设与实证数据的一致性，实现了从知识到工具的自动化转化，解决了知识与应用脱节的问题。

2026 年，Eigen-Agent（ICLR 2026, P35）提出自适应多智能体科学推理框架，核心创新在于引入基于监控的检索增强生成（Monitor-based RAG）机制。该机制在推理过程中全局运行，Monitor 检测推理流中的知识不足，Querier 制定针对性查询，Injector 将检索到的证据无缝整合回上下文，解决了静态 RAG 无法应对推理中途知识需求的问题。Eigen-Agent 通过动态知识注入与多层级精化流程，显著提升了在生物化学等高难度领域推理的准确性与鲁棒性。与 ChemCrow 相比，Eigen-Agent 更强调推理过程中的动态知识获取，而非预定义的工具调用，其成功依赖于 Monitor 对知识不足的准确检测，假设推理流中的知识缺口是可识别且可检索的。

SciDER（Lin et al., 2026, P13）设计数据为中心的全流程科研智能体，旨在解决现有系统对公共机器学习数据集依赖性强、缺乏记忆机制及适应性问题。系统整合构思、数据分析、实验及迭代改进的研究框架，支持文本、原始数据、代码及先前论文等灵活输入。SciDER 提供轻量级 Web 界面，允许研究人员上传数据和研究主题，系统自动创建闭环研究周期以提出并验证新想法。通过模块化记忆机制，智能体能够保留研究过程中的关键信息，支持长程依赖的推理与决策。该方法强调数据驱动的研究自动化，将科研任务形式化为从数据集和查询生成想法、分析报告、实验代码库及结果的过程，为构建真正独立的 AI 研究伙伴提供了可扩展的系统架构。

EvoSci（Xiong et al., 2026, P25）构建受生物启发的多智能体框架，旨在模拟科学发现的进化过程以克服单一 LLM 的幻觉及长程推理弱点。该系统组织多个具有专门角色和共享目标的 LLM 智能体，通过协调规划、分工及相互评估实现更可靠且可扩展的认知性能。EvoSci 强调智能体间的动态交互与迭代优化，模拟科学社区中假设提出、批评与修正的社会化过程。通过这种多智能体协作机制，系统能够处理复杂的多步骤研究工作流，提升假设生成的多样性与可行性。该方法将进化计算理念引入 LLM 智能体架构，为构建具备自我进化能力的自主科研系统提供了新的技术路径。

自主科研智能体路线与科学推理与算法发现路线存在继承关系：前者依赖后者的可验证基础，但通过多智能体协作与工具调用解决了长程任务的鲁棒性问题。然而，智能体架构的复杂性也带来了新的挑战，如错误累积与计算成本，这促使研究者探索更高效的推理策略与轻量化模型。

### 2.3 科学假设与创意生成

科学假设与创意生成是科学发现的核心环节，要求模型具备超越检索的创新推理能力。早期工作如 SciMON（2024）基于检索增强生成技术，通过关联背景知识与灵感文献生成科学假设，引入了文献接地的概念，解决了早期生成方法缺乏事实依据的问题。然而，SciMON 的生成能力受限于检索质量，难以产生真正新颖的假设。

2026 年，MOOSE-Star（Yang and Bing, 2026, P15）提出打破复杂性壁垒的科学发现可训练框架，核心在于将不可行的假设生成概率建模转化为可解的子任务。该方法分析直接训练 P(h|b) 的计算不可行性，通过分解顺序训练策略，将任务转化为灵感检索与假设组合两个等价顺序子任务。灵感检索负责从全局知识库中识别正确灵感，复杂度为 O(N)；假设组合则在给定灵感条件下生成假设，显著降低了计算复杂度。MOOSE-Star 通过这种渐进式转化，解决了现有训练方法依赖外部反馈而非显式建模核心条件概率的问题，为科学创意生成提供了可优化的训练目标。

Debate as Reward（Salimi et al., 2026, P24）设计多智能体奖励系统用于科学创意生成的强化学习后训练，旨在解决现有方法依赖推理时增强而缺乏训练时优化的问题。该框架包含数据集策划、多智能体评估及策略优化三个阶段，其中多智能体评估委员会由 LLM 智能体组成，提供鲁棒的反馈信号。奖励信号不由静态真值导出，而是由多智能体评判系统合成，模拟科学同行评审的辩论过程。策略优化阶段采用无偏的生成强化策略优化（Dr. GRPO）对生成器进行微调，以最大化创意质量。该方法通过引入动态、多维度的奖励机制，提升了生成假设的新颖性、可行性及影响力，为科学创意生成的强化学习训练提供了新的奖励建模范式。

GIANTS（He-Yueya et al., 2026, P22）提出从科学文献中生成洞察预期（Insight Anticipation）的方法，旨在解决现有模型难以从少量先前工作中综合深刻洞察的问题。该方法探索两种训练范式：通过监督微调（SFT）蒸馏目标下游论文的真值洞察与合理化过程，以及通过相似度优化的强化学习（RL）。GIANTS 利用 Qwen3-4B 作为基础模型，通过训练使模型能够预测未来研究可能产生的关键洞察。该方法强调数据效率，模拟人类研究人员从少量文献中提炼突破性的认知过程。通过结合 SFT 与 RL，GIANTS 提升了模型生成具有真正影响力和价值假设的能力，克服了现有方法在多样性与可行性上的不足。

EvoIdeator（Sauter et al., 2026, P17）提出基于清单接地的强化学习框架，用于进化科学创意，解决现有 RL 方法依赖标量奖励但缺乏具体维度指导的问题。该方法引入清单接地评判器，将创意质量分解为接地性、可行性、问题风险等多个具体维度，并提供可操作的语言反馈。奖励方案采用字典序奖励，优先满足关键质量约束，同时通过语言反馈机制指导模型修正具体缺陷。EvoIdeator 通过这种细粒度的奖励信号，使模型能够优化复杂的多维目标，而非仅追求单一分数，提升了生成创意的科学严谨性与方法论质量。

FlowPIE（Wang et al., 2026, P20）提出测试时科学创意进化框架，通过流引导的文献探索生成初始创意种群，并利用进化算子进行迭代优化。该方法将科学创意生成建模为进化算法，初始种群通过动态文献探索生成，其中流引导的蒙特卡洛树搜索（MCTS）用于平衡探索与利用。随后，通过适应度评估、生存选择、交叉及变异算子，引导创意向更高奖励区域收敛。FlowPIE 强调创意新颖性必须基于技术现实，从先前科学知识的综合中累积涌现。该方法通过测试时计算扩展，提升了创意生成的多样性与稳定性，解决了现有方法在创意进化过程中容易陷入局部最优或多样性不足的问题。

科学假设与创意生成路线与自主科研智能体路线存在互补关系：前者提供假设生成的核心能力，后者提供执行框架。然而，假设生成的新颖性与可行性评估仍缺乏统一标准，现有基准多侧重知识问答而非发现过程，这促使研究者构建多维度的过程级评估框架。

### 2.4 多模态科学基础模型

多模态科学基础模型旨在统一处理文本、图像、分子结构及实验数据等多模态科学数据，打破学科壁垒实现跨域推理。早期工作如 AlphaFold 3（2025）针对生物分子复合物结构预测的高性能专用模型，通过领域特定的归纳偏置与评估协议，确立了多模态科学模型在特定实体预测上的性能上限。然而，AlphaFold 3 的专用性限制了其跨域泛化能力，难以处理异构科学数据。

2026 年，S1-Omni（Zhao et al., 2026, P28）构建统一的多模态推理模型，旨在整合科学数据的统一表示、自然世界知识对齐及领域特定任务解码。该模型采用共享视觉语言骨干，首先形成任务条件隐藏表示，生成可选的科学推理、文本答案及任务令牌。对于可直接用自然语言表达的任务，文本答案为最终结果；对于具有专门输出空间的任务，任务令牌选择结果解码器，将共享表示转换为原生科学空间中的可验证输出。S1-Omni 支持属性、蛋白质位点、分子结构、3D 坐标及科学图像等多种输出模态，打破了专用模型与通用模型之间的壁垒，实现了跨学科科学数据的联合理解、推理与生成。

Intern-S1-Pro（Zou et al., 2026, P19）提出首个万亿参数规模的科学多模态基础模型，旨在通过大规模扩展提升通用与科学领域的综合能力。该模型在强化学习训练基础设施支持下，实现了 1 万亿参数级别的高效训练，并确保训练与推理之间的严格精度一致性。Intern-S1-Pro 不仅增强了推理与图文理解能力，还通过高级智能体能力扩展了其智能，掌握化学、材料、生命科学及地球科学等关键领域的 100 多项专门任务。该方法通过无缝整合通用与专用能力，强化了科学多模态基础模型的跨领域泛化能力，为处理大规模、多模态科学数据提供了强大的基础模型支持。

Unified Multimodal Model for Cross-disciplinary Research（Yang et al., 2026, P10）提出用于跨学科科学研究的统一多模态理解与生成模型，旨在处理电子健康记录、医学影像、气象站记录、卫星图像及光谱表征等异构科学数据。该模型通过统一架构整合不同模态的科学证据，支持跨物理尺度与学科领域的协调分析。方法强调科学数据的异构性，通过多模态编码器与解码器实现原生科学数据的输入与输出，解决了现有系统要么专门化于单一领域，要么主要通过文本标记化统一科学数据导致的局限性。

Monkey King Bang (MKB)（Chen et al., 2026, P30）提出统一科学多模态基础模型，围绕共享 Transformer 骨干及模态定制的编码器、适配器与解码器构建。MKB 覆盖 DNA、RNA、蛋白质、小分子、地球科学及医学影像六个科学分支，支持生物序列、分子字符串、气象场及分割掩码等原生输出。该模型旨在解决现有系统通过文本标记化统一科学数据导致的模态原生输出能力受限问题，通过两阶段训练策略，实现了跨科学领域的联合理解、推理与生成。

BigBang-Proton（Wu et al., 2025, P3）提出基于下一词预测的科学多任务学习者，旨在解决 LLM 在真实世界科学问题中表现有限的问题。该模型通过改进的数值编码策略，显著优于字节对编码（BPE）在处理大数字及大规模数值计算中的表现，能够模拟算术逻辑单元操作原理。BigBang-Proton 通过实验学习框架合成语言知识与实验数据，解决跨科学学科、领域及理论与实践之间的语料库差异，在粒子喷注标记、原子间表面势模拟、DNA 及蛋白质结构预测等任务中达到或超越最先进专用模型性能。

多模态科学基础模型路线与科学推理与算法发现路线存在竞争关系：前者通过端到端学习捕捉复杂模式，后者通过符号回归提供可解释性。然而，多模态模型的训练成本极高，且多模态对齐难度大，模型在特定垂直领域的深度可能不如专用模型，这促使研究者探索更高效的训练策略与轻量化模型。

### 2.5 科研安全与伦理治理

科研安全与伦理治理是 LLM 应用于科学领域的关键前提，旨在防范双重用途风险并建立科学伦理底线。早期工作如 WMDP（2025）设计专家策划的危险知识多选题，初步探索 LLM 在高风险科学场景中的知识边界，为后续更细粒度的安全评估基准提供了基础。然而，WMDP 的风险覆盖有限，且依赖主观评估，难以全面衡量 LLM 的安全风险。

2026 年，SafeSci（Zhu et al., 2026, P14）提出涵盖多学科的安全评估与增强框架，旨在解决现有科学安全基准风险覆盖有限及依赖主观评估的问题。SafeSci 包含 SafeSciBench（25 万样本）和 SafeSciTrain（150 万样本），前者区分安全知识与风险维度，后者用于安全增强训练。该框架采用客观指标如检测率，替代传统的主观评分，提升了评估的可靠性与可复现性。SafeSci 覆盖生物学、化学、材料科学等多个高风险领域，针对双重用途知识、数据隐私及学术诚信等具体风险场景，为 LLM 在科学领域的安全部署提供了全面的评估与训练资源。

SciHazard（Li et al., 2026, P29）提出用于测量科学安全风险的基准，核心创新在于分解危害评分，解决整体评分中专家间一致性低的问题。该方法将危害分解为可执行性（Executability）与净新风险（Net New Risk）两个正交维度，分别评估响应内容的操作可行性与潜在后果严重性。SciHazard 通过这种分解，避免了整体评分中因评估者隐含风险权重不同导致的不一致性，提供了更细粒度的风险量化。基准涵盖从化学武器合成到病原体工程的高风险场景，强调真实世界误用的可操作场景而非单纯事实回忆，为准确测量 LLM 及自主科学智能体在高风险场景中的威胁潜力提供了更科学、客观的评估框架。

SafeScientist（EMNLP 2025, P34）提出增强 AI 科学家安全性的框架，旨在实现风险感知的科学发现，解决现有 AI 科学家框架缺乏安全机制的问题。该框架通过多层防御机制，包括提示注入检测、数据泄露防护及伦理合规检查，确保科研流程中的安全性。SafeScientist 评估了多种基础模型在安全与质量指标上的表现，揭示了底层 LLM 对安全性能的影响，针对主动注入、被动注入及用户驱动注入等多种攻击向量，设计了相应的防御策略，为构建安全可靠的自主科研智能体提供了系统性的安全增强方案。

Ethical LLM-Assisted Research Framework（Stoyanov, 2026, P32）提出负责任委托、验证及认识论价值的框架，旨在规范 LLM 在科学研究中的使用。该框架区分候选声明的五个属性：来源（Provenance）、责任（Responsibility）、验证（Verification）、问责（Accountability）及认识论结果（Epistemic Outcome）。来源属性记录声明是人类还是机器生成的，责任映射明确人类与机器在认知工作中的分工，强调科学推理中认知委托的扩展，要求对 LLM 生成的内容进行严格的验证与问责，为 LLM 辅助科研提供了伦理与认识论指导。

Refutability Gap Analysis（Mossel, 2025, P11）提出关于验证 LLM 推理的挑战分析，指出当前 AI 研究中的方法论缺陷，特别是缺乏波普尔可证伪性原则。该方法识别了由于训练数据不透明、模型持续更新及缺乏人类交互记录导致的可重复性缺失问题，这些缺陷使得 LLM 发现的“新颖性”难以验证，还指出缺乏反事实及失败尝试数据造成的选择偏差，可能夸大 LLM 能力，提出了科学透明性指南，要求公开验证过程、数据及交互记录，以确保科学声明的可证伪性。

科研安全与伦理治理路线与自主科研智能体路线存在约束关系：前者为后者提供安全底线与伦理规范，后者为前者提供应用场景。然而，安全机制可能限制模型的生成自由度，部分高风险但合法的科学研究可能被误拦截，这促使研究者探索更细粒度的风险感知与动态对齐机制。

### 2.6 跨任务与多领域应用

LLM 在科学发现中的应用已从单一领域扩展至多学科、多任务场景，其核心在于通过统一架构或智能体框架实现跨域推理与知识迁移。在材料科学领域，Autonomous Materials Computation Framework（Xia et al., 2025, P7）提出用于自主材料计算的智能体框架，旨在克服独立 LLM 知识静态及幻觉问题。该框架将 LLM 集成到智能体架构中，利用检索增强生成（RAG）接地模型，使其能够访问最新或领域特定的材料数据库与文献，通过工具调用执行材料属性预测、合成规划及文献总结等多样化任务，实现了从信息检索到计算模拟的闭环。

在地球科学领域，Earth-Iron/Earth-Silver/Earth-Gold 基准（2026）基于 100k 论文语料，评估基础知识和专业级探索能力，涵盖 QA 数据集与开放式对话数据集，为 LLM 在地球科学中的应用提供了标准化评测。在生物医学领域，HLE Bio/Chem 基准（2026）包含 149 个研究生级别问题，由领域专家手动校正，用于评估复杂科学问题求解能力，揭示了 LLM 在高风险、高复杂度科学任务中的能力边界。

跨任务与多领域应用路线与多模态科学基础模型路线存在互补关系：前者提供应用场景与评测基准，后者提供底层能力支持。然而，跨学科知识迁移能力仍较弱，现有模型难以统一处理异构科学数据，这促使研究者开发统一多模态基础模型与领域专用微调策略。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLM 在科学发现中已从被动工具转变为主动参与者，能够执行从文献综述到实验设计的端到端任务，这一共识在约 20 篇论文中得到共同支持。单纯的参数化知识不足以支撑科学发现，必须结合外部工具（如代码解释器、模拟器、数据库）进行接地（Grounding）以提高准确性，这一共识在约 15 篇论文中得到共同支持。多智能体协作（Multi-Agent Systems）比单模型更能有效处理复杂科学任务，通过角色分工和相互验证提升鲁棒性，这一共识在约 12 篇论文中得到共同支持。科学安全是 LLM 应用于科学领域的关键前提，必须建立专门的风险评估框架以防范双重用途风险，这一共识在约 10 篇论文中得到共同支持。现有基准测试多侧重知识问答，缺乏对科学推理过程、假设新颖性及可证伪性的有效评估，亟需过程级评估标准，这一共识在约 15 篇论文中得到共同支持。符号回归和数学推理是 LLM 科学发现能力的核心体现，但当前模型在恢复复杂物理定律方面仍不可靠，这一共识在约 8 篇论文中得到共同支持。多模态能力是突破学科壁垒、实现跨域科学发现的关键，单一文本模态无法覆盖现代科学数据的多样性，这一共识在约 10 篇论文中得到共同支持。LLM 的推理能力（Reasoning）比单纯的知识记忆（Knowledge）更能预测其在科学任务中的成功率，这一共识在约 5 篇论文中得到共同支持。

### 3.2 观点分歧

科学发现的核心机制存在符号回归与端到端多模态学习的根本分歧。符号回归派认为科学发现的本质是可解释的数学公式，LLM 应作为进化算子搜索符号空间（代表：AlphaEvolve, PTB-Search, CliffSearch）；端到端派认为科学现象复杂且非结构化，端到端多模态模型能捕捉更深层的模式，符号回归仅是特例（代表：S1-Omni, Intern-S1-Pro, BigBang-Proton）。现有证据偏向符号回归在数学、物理等可形式化任务上的优越性（LLM-SRBench 上 PTB-Search 73-77%），但在生物、化学等复杂系统上，端到端模型（如 AlphaFold 3, S1-Omni）表现更佳。证据强度中等，缺乏统一的跨学科基准来直接对比两种范式在“发现新定律”上的能力，测量工具盲区在于现有基准多侧重“拟合”或“预测”，缺乏对“发现”过程（如从噪声数据中恢复隐藏定律）的公平对比。

自主智能体的安全边界存在完全自主与人类在环的分歧。完全自主派主张 LLM 应具备端到端自主科研能力，人类仅设定目标（代表：AI Scientist, SciDER）；人类在环派主张鉴于幻觉与安全风险，关键步骤（如实验执行、假设验证）必须有人类介入（代表：SafeScientist, Ethical LLM-Assisted Research Framework）。现有证据偏向人类在环，因为长程自主任务中的错误累积率高，且 SafeScientist 等框架显示安全机制能显著降低风险（ASR 降低）。但完全自主系统在模拟环境（如 ChemCrow）中表现良好，证据强度取决于场景的真实度，缺乏大规模真实实验室的长期运行数据来验证完全自主系统的可靠性。

评估标准存在结果导向与过程导向的分歧。结果导向派以最终答案的准确率、公式的正确性为核心指标（代表：传统 QA 基准, Symbolic Accuracy）；过程导向派以推理路径的透明度、可证伪性、假设的新颖性为核心指标（代表：HiSciBench, SGIEvalAgent, Refutability Gap Analysis）。现有证据偏向过程导向，因为结果导向指标无法区分“猜对”与“推导对”，且无法评估科学发现的创新性。HiSciBench 等分层基准显示，模型在基础素养上得分高，但在原创发现阶段得分骤降，证明过程评估的必要性。测量工具盲区在于过程导向指标（如 Novelty Score）依赖 LLM Judge 或专家，存在主观性与一致性低的问题，缺乏客观、自动化的“可证伪性”量化指标。

### 3.3 其他开放问题

最紧迫的工程问题是多模态异构数据的统一表示与长程任务的计算效率。S1-Omni、MKB 等模型已提供统一架构范式，但多模态对齐难度大，训练成本极高；长程任务的 Token 消耗与推理延迟仍是实际部署的主要瓶颈，Token 减少率等效率指标缺乏标准化评测。最根本的研究问题是科学直觉的建模与伦理内化。LLM 是否具备真正的因果推理能力还是仅在做高维模式匹配？现有 CausalEvolve 等工作提供了初步框架，但缺乏理论证明；LLM 在科学应用中可能产生的偏见、不公平和安全风险，难点在于定义科学伦理标准和评估方法，现有 SafeSci、SciHazard 等基准提供了初步工具，但缺乏大规模实证验证。

已知—争议—未知认知图谱显示：已知 LLM 在可形式化任务（如数学、物理）上的能力边界，争议在于符号回归与端到端学习的相对优势及自主智能体的安全边界，未知在于科学直觉的建模、伦理内化及大规模真实实验室的长期运行数据。发展趋势表明，随着万亿参数科学基础模型与安全治理框架的成熟，LLM 有望在 2026-2027 年实现从“辅助”到“协作”的实质性跨越，但可证伪性与安全性仍是核心挑战。

## 4. 总结与展望

LLM 驱动的科学发现正处于从“能力展示”向“可信科学伙伴”转型的临界点，核心矛盾在于生成能力的指数级增长与科学验证所需的严谨性、可证伪性之间的滞后。早期工作通过符号回归与代码执行解决了幻觉问题，中期工作通过多智能体协作与工具调用实现了长程任务闭环，当前工作通过多模态基础模型与安全治理框架提升了跨域泛化能力与可信度。核心瓶颈在于可证伪性缺失与长程任务中的错误累积，如何构建具备可证伪推理路径、能自主执行假设-实验闭环且符合科学伦理规范的智能系统，仍是最大挑战。

未来可能突破的方向包括：基于因果便签的开放式发现框架，通过 CausalEvolve 等工作引入因果推理与不确定性量化，提升发现结果的科学解释力与可信度；针对高风险科学场景的细粒度安全评估，通过 SciHazard、SafeSci 等基准建立客观、自动化的风险量化指标，防范双重用途风险；多模态基础模型与智能体架构的深度融合，通过 S1-Omni、Intern-S1-Pro 等模型实现跨学科科学数据的统一表示与推理，结合 Eigen-Agent 等智能体框架实现长程任务闭环。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，构建包含“可证伪性”与“新颖性”的混合基准，以公平对比符号回归与端到端学习范式在“发现新定律”上的能力，填补现有评测体系的测量工具盲区。
