# A Survey of Agentic Reinforcement Learning Methods for LLMs ｜大语言模型智能体强化学习方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Agentic%20Reinforcement%20Learning%20for%20LLMs)

## 导读

大语言模型智能体强化学习（Agentic Reinforcement Learning, Agentic RL）旨在通过环境反馈优化模型的多轮决策能力，其核心价值在于突破静态文本生成在长程任务中误差累积与泛化受限的瓶颈。早期研究依赖监督微调与提示工程，思路直观却难以应对稀疏奖励下的信用分配难题。当 DeepSeek-R1 等模型在数学推理上验证了强化学习（RL）的有效性后，研究重心迅速转向多轮交互场景，RL 取代监督微调成为后训练的核心范式。各路线在计算效率、训练稳定性与泛化能力之间做出了不同取舍，由此形成当前涵盖系统架构、信用分配与理论机制的多元方法格局。本综述梳理这条从算法优化到系统工程与理论澄清的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

Agentic RL 的起源在于将大语言模型（Large Language Models, LLMs）从静态文本生成器转化为具备自主决策能力的智能体。早期工作如 ReAct（Yao et al., 2022）通过交织推理与行动，确立了智能体与环境交互的基础范式，但受限于数据分布和长程任务中的误差累积，难以实现真正的泛化。2023 至 2024 年间，随着 DeepSeek-R1 和 OpenAI o1 等模型在数学推理上通过 RL 取得突破，研究重心迅速从单轮推理转向多轮交互的 Agentic 场景。这一转折标志着 RL 成为后训练的核心范式，旨在通过环境反馈优化 LLM 的工具使用、规划及长程决策能力。

问题的形式化可表述为部分可观测马尔可夫决策过程（Partially Observable Markov Decision Process, POMDP）。智能体在状态 $s_t$ 下观察 $o_t$，执行动作 $a_t$（如工具调用或文本生成），环境返回下一状态 $s_{t+1}$ 及稀疏奖励 $r_t$。策略 $\pi_\theta(a_t|o_{1:t})$ 的目标是最大化期望累积回报 $E[\sum_{t=0}^{T} \gamma^t r_t]$。与单轮生成不同，多轮交互要求模型具备状态维护和长期规划能力，动作空间扩展至自然语言与外部 API 调用，状态空间则受限于上下文窗口。

子问题之间存在强依赖关系。训练基础设施（如异步解耦架构）是解决长程任务效率瓶颈的前提，为算法提供细粒度轨迹数据；信用分配机制依赖于这些轨迹数据，通过过程奖励或树搜索细化优势估计；算法稳定性则是信用分配和多智能体协同能够收敛的基础，防止熵坍缩与策略崩溃；探索与泛化则是上述所有机制在分布外任务上的最终检验。这种依赖链决定了研究推进的顺序：先解决“跑得动”（系统效率），再解决“学得对”（信用分配与稳定性），最后解决“用得好”（泛化与理论解释）。

范式边界上，Agentic RL 与传统 RL 的区别在于动作空间为自然语言/工具调用，状态空间为上下文窗口，奖励信号多为稀疏且延迟。与监督微调（SFT）相比，RL 通过试错优化而非模仿学习，能够发现数据分布外的有效策略，但面临训练不稳定与样本效率低的挑战。SFT 导致性能崩溃，而 RL 实现稳定累积性能增长，源于 RL 梯度的稀疏性与 On-policy 特性（Zhu et al., 2026）。

约束演化史揭示了方法如何因应约束变化而演变。2017 至 2018 年，PPO（Schulman et al., 2017）通过引入裁剪代理目标与信任区域约束，限制策略更新幅度以防止性能崩溃，成为 LLM 后训练中最广泛采用的基线优化算法。2022 年，ReAct 确立了智能体与环境交互的基础范式，但受限于单轮或短程任务。2024 年，GRPO（Shao et al., 2024）移除 PPO 中的 Critic 网络，采用组内相对优势估计替代价值函数，显著降低计算开销并提升训练稳定性，成为 DeepSeek-R1 等推理模型的核心训练算法。同年，VeRL（Sheng et al., 2024）提出基于 Ray 的分布式 RL 训练框架，支持多模型协同与异步执行，解决了早期 RL 框架在大规模 LLM 训练中的资源调度瓶颈。

2025 年，领域进入系统化阶段。AgentRL（Zhang et al., 2025）构建支持多轮、多任务的全异步 Agentic RL 框架，通过解耦环境部署与训练引擎，实现了异构环境下的并行轨迹生成与高效策略更新。Tree-GRPO（Ji et al., 2025）引入树搜索机制扩展轨迹采样空间，通过分支探索增强策略多样性，并基于树结构进行细粒度信用分配，缓解长程任务中的稀疏奖励问题。Meta-RL（Jiang et al., 2025）将元学习引入 LLM 智能体训练，通过跨回合训练机制使智能体具备从失败中反思并自适应调整策略的能力，提升探索效率。

2026 年，研究焦点转向稳定性与理论机制。ARLArena（Wang et al., 2026）建立 Agentic RL 训练稳定性的系统化分析框架，通过标准化测试环境与消融实验，揭示了熵坍缩与推理模板化之间的内在联系，为调试训练崩溃提供理论依据。RL Compositionality（ICLR 2026）提出 RL 组合性假设，论证 RL 并非创造全新原子技能，而是通过组合预训练中已有的原子能力形成复杂推理策略，澄清了 RL 在 LLM 技能获取中的本质作用。当前，该领域极度活跃，旨在构建能在 Web 导航、代码生成及复杂工具调用中稳定运行的通用智能体，RL 被视为解锁 LLM 潜在推理与行动能力的关键驱动力，正逐步取代 SFT 成为提升智能体鲁棒性和泛化能力的主流手段。

**如果用一个核心问题概括该领域，那便是：如何在稀疏奖励与长程依赖的多轮交互环境中，通过强化学习实现 LLM 策略从局部最优到全局泛化的稳定收敛。**

## 2. 方法体系

- 2017：PPO——通过引入裁剪代理目标与信任区域约束，限制策略更新幅度以防止性能崩溃，成为 LLM 后训练中最广泛采用的基线优化算法

- 2022：ReAct——将推理（Reasoning）与行动（Acting）交织，使 LLM 通过生成思维链并执行工具调用与环境交互，确立了 Agentic RL 中智能体与环境交互的基础范式

- 2024：GRPO——移除 PPO 中的 Critic 网络，采用组内相对优势估计替代价值函数，显著降低计算开销并提升训练稳定性，成为 DeepSeek-R1 等推理模型的核心训练算法

- 2024：VeRL——提出基于 Ray 的分布式 RL 训练框架，支持多模型协同与异步执行，解决了早期 RL 框架在大规模 LLM 训练中的资源调度瓶颈

- 2025：AgentRL——构建支持多轮、多任务的全异步 Agentic RL 框架，通过解耦环境部署与训练引擎，实现了异构环境下的并行轨迹生成与高效策略更新

- 2025：Tree-GRPO——引入树搜索机制扩展轨迹采样空间，通过分支探索增强策略多样性，并基于树结构进行细粒度信用分配，缓解长程任务中的稀疏奖励问题

- 2026：ARLArena——建立 Agentic RL 训练稳定性的系统化分析框架，通过标准化测试环境与消融实验，揭示了熵坍缩与推理模板化之间的内在联系，为调试训练崩溃提供理论依据

- 2026：RL Compositionality——提出 RL 组合性假设，论证 RL 并非创造全新原子技能，而是通过组合预训练中已有的原子能力形成复杂推理策略，澄清了 RL 在 LLM 技能获取中的本质作用

这条时间线勾勒了该领域方法演进的代表性节点：从 2017 年的 PPO 奠定该领域方法基线，经 2022 年 ReAct 的推进，到 2026 年的 RL Compositionality 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 训练系统架构

训练系统架构的演进始于对同步 RL 中资源闲置与长尾延迟问题的回应。早期框架如 VeRL（Sheng et al., 2024）提出基于 Ray 的分布式 RL 训练框架，支持多模型协同与异步执行，解决了早期 RL 框架在大规模 LLM 训练中的资源调度瓶颈。然而，VeRL 仍主要关注单智能体场景，未充分处理多轮交互中上下文长度动态增长导致的内存溢出问题。AgentRL（Zhang et al., 2025）针对这一局限，构建支持多轮、多任务的全异步 Agentic RL 框架，通过解耦环境部署与训练引擎，实现了异构环境（如 Web、代码、游戏）下的并行轨迹生成。其核心创新在于引入全异步交互机制，允许不同智能体以不同速率与环境交互，避免了同步等待导致的资源闲置。系统采用动态资源调度策略，根据任务复杂度自动分配计算资源，提升了整体训练吞吐量。该设计解决了传统同步 RL 在长尾轨迹处理上的效率瓶颈，为大规模 Agentic RL 提供了可扩展的工程基础。

随着任务复杂度提升，静态并行配置在长上下文场景下暴露出低效问题。Earl（Tan et al., 2025）针对 Agentic RL 中上下文长度动态增长导致的内存溢出与延迟问题，提出动态并行化系统。该系统在 Rollout 阶段根据上下文长度自适应调整张量并行与序列并行策略，优化了跨设备数据传输逻辑。其核心创新在于引入动态并行调度器，实时监控内存使用并重新配置并行策略，避免了静态配置在长上下文场景下的低效。通过优化数据分发逻辑，Earl 显著降低了中间张量累积带来的通信开销。该方法解决了长程智能体训练中常见的 OOM 故障，提升了系统在长轨迹任务中的稳定性与效率。与 AgentRL 的全异步架构不同，Earl 聚焦于单节点内的并行策略优化，两者在系统层级上形成互补：AgentRL 解决多节点间的任务调度，Earl 解决单节点内的资源分配。

异步架构引入了 Off-policy 偏差，需要重要性采样校正。CoPRIS（Qu et al., 2025）提出并发控制部分 Rollout 与重要性采样校正机制，解决同步 RL 中的长尾问题。系统通过维持固定数量的并发 Rollout 请求，确保计算资源在轨迹生成期间的持续利用。当部分轨迹完成时，立即调度新请求，避免了等待最长轨迹导致的 GPU 空闲。针对由此产生的 Off-policy 偏差，引入跨阶段重要性采样校正，通过调整权重消除策略陈旧性对训练稳定性的影响。该机制在保持 On-policy 训练效果的同时，显著提升了 Rollout 阶段的吞吐量，是异步 RL 系统优化的重要进展。CoPRIS 与 AgentRL 的竞争在于：AgentRL 追求全异步的极致并行，CoPRIS 则在并发控制与偏差校正之间寻求平衡，后者在稳定性上更具优势，但吞吐量略低。

多智能体场景对系统架构提出了更高要求。RollArt（Gao et al., 2025）基于解耦基础设施设计，实现 Agentic RL 训练的资源高效调度。该系统采用单控制器编程模型，通过注册装饰器管理分布式计算与通信，提供细粒度的资源可见性。其核心创新在于硬件亲和性映射，根据计算、带宽与内存需求将不同阶段任务映射至异构 GPU 资源。通过解耦 Rollout 与训练阶段的资源占用，RollArt 避免了同步执行中的资源气泡。该框架支持多任务 Agentic RL 流水线，通过优化资源分配提升了异构环境下的训练效率，为工业级 RL 系统提供了参考架构。AstraFlow（Zheng et al., 2026）进一步提出数据流导向的 Agentic RL 训练系统，将 RL 工作负载建模为动态数据流图。该系统通过解耦 Rollout 生成与策略优化阶段，解决了同步系统中训练 GPU 在 Rollout 期间的闲置问题。其核心组件包括动态执行引擎，能够根据智能体工作负载的异构性调整数据流拓扑。AstraFlow 支持多智能体协作场景，通过协调不同智能体的推理与训练任务，实现了资源的高效复用。该设计提升了系统在复杂 Agentic 工作负载下的可扩展性，为大规模多智能体 RL 训练提供了系统级解决方案。

MARLaaS（Yu et al., 2026）构建多租户异步 RL 即服务平台，支持高并发 LoRA 任务共享执行。该系统利用 LoRA 参数高效微调特性，实现多个 RL 工作负载在共享集群资源上的并发训练。其核心创新在于异步流水线设计，通过重叠 Rollout 生成与策略更新阶段，消除了同步系统中的资源气泡。MARLaaS 引入多租户隔离机制，确保不同任务间的资源竞争不影响训练稳定性。该平台解决了多任务 RL 训练中的基础设施重复部署问题，显著降低了内存与计算成本，提升了 RLVR 训练的可扩展性。Rollout-Training Co-Design（Jiang et al., 2026）针对多智能体 RL 中的同步屏障与负载不均衡问题，提出 Rollout 与训练协同设计框架。该系统识别出 MARL 中不同角色智能体的异构资源需求，设计了专用的调度机制以处理非均匀计算负载。其核心创新在于将 Rollout 负载平衡与训练资源利用率纳入统一优化目标，避免了通用 RL 框架在 MARL 场景下的性能退化。通过解耦智能体间的同步依赖，该框架提升了大规模多智能体训练的吞吐量。该方法为 LLM-based MARL 提供了系统级优化方案，解决了传统单智能体基础设施无法适应协作复杂性的问题。

### 2.2 信用分配机制

信用分配机制的演进源于对稀疏奖励下轨迹级优势估计粗糙性的反思。GRPO（Shao et al., 2024）移除 PPO 中的 Critic 网络，采用组内相对优势估计替代价值函数，显著降低计算开销并提升训练稳定性，成为 DeepSeek-R1 等推理模型的核心训练算法。然而，GRPO 中整条轨迹共享同一优势值，导致关键步骤与无关步骤无法区分，梯度信号噪声大。Tree-GRPO（Ji et al., 2025）针对这一局限，引入树搜索机制扩展 Agentic RL 的轨迹采样空间，解决长程任务中的探索不足问题。该方法在 ReAct 框架基础上，通过分支采样生成多条潜在轨迹，并基于树结构进行组内相对优势估计。其核心创新在于利用树节点共享前缀的特性，实现细粒度的步骤级信用分配，避免了传统 GRPO 中整条轨迹共享同一优势值的粗糙性。Tree-GRPO 通过增加采样多样性，提升了策略在复杂环境中的适应能力。该方法在数学推理与多跳问答任务中显著优于基线，为 Agentic RL 提供了更精细的优化信号。

回合级粒度是另一种信用分配策略。Turn-PPO（Li et al., 2025）提出回合级优势估计方法，解决多轮 Agentic RL 中 Token 级 PPO 的信用分配偏差问题。该方法将优势估计粒度从 Token 提升至 Turn，利用广义优势估计（GAE）在回合边界计算累积奖励。其核心创新在于识别出多轮交互中回合是自然的决策单元，Token 级更新会引入不必要的方差。Turn-PPO 通过简化优势计算过程，降低了计算开销并提升了训练稳定性。该方法在 Web 导航与工具使用任务中表现出更优的收敛性，为多轮 RL 提供了更合理的优化粒度选择。与 Tree-GRPO 的树结构不同，Turn-PPO 采用线性回合序列，计算开销更低，但牺牲了分支探索的多样性。

图结构提供了更灵活的信用分配框架。SALT（Li et al., 2025）基于轨迹图构建步骤级优势分配框架，解决长程智能体中稀疏奖励的信用分配难题。该方法通过合并与分叉操作构建轨迹图，识别跨轨迹共享的步骤节点。其核心创新在于利用图结构传播奖励信号，实现步骤级而非轨迹级的优势估计，消除了相同步骤在不同轨迹中受到不一致奖励的问题。SALT 通过细化信用分配粒度，提升了策略在长程任务中的学习效率。该方法在 ALFWorld 与 WebShop 等环境中显著提升了任务成功率，为长程 Agentic RL 提供了结构化的优化方案。AT2PO（Zong et al., 2026）提出基于树搜索的 Agentic 回合级策略优化框架，联合解决探索多样性与信用分配问题。该方法构建回合级树结构，通过熵引导的树扩展实现战略性探索，并基于树结构进行回合级信用分配。其核心创新在于将探索机制与优化目标统一在树搜索框架中，实现了细粒度的奖励传播。AT2PO 通过对齐策略更新与智能体交互的自然决策粒度，提升了多轮 RL 的训练效率。该方法在多个基准测试中展现出一致的性能提升，为 Agentic RL 提供了统一的探索与优化范式。

分层结构是解决长程任务信用分配的另一种路径。HiPER（Peng et al., 2026）提出分层强化学习框架，通过显式信用分配提升 LLM 智能体的规划与执行能力。该方法将策略分解为高层规划策略与低层执行策略，利用分层结构实现时间抽象。其核心创新在于设计 Plan-Execute 接口，使 LLM 以结构化格式输出规划与执行决策，并基于分层结构优化学习算法。HiPER 通过分离不同时间尺度的决策，降低了策略优化的复杂度。该方法在长程任务中提升了智能体的规划合理性，为分层 Agentic RL 提供了有效的实现路径。HISR（Lu et al., 2026）提出后见信息调制的分段过程奖励机制，增强多轮 Agentic RL 的信用分配可靠性。该方法构建后见模型与分段过程奖励模型，基于轨迹收集数据估计子目标进度。其核心创新在于利用后见信息与策略模型之间的似然比计算分段重要性分数，调制过程奖励以突出关键步骤。HISR 通过细化奖励信号，使策略更关注对任务成功有显著贡献的交互片段。该方法在家庭助手与 Web 购物任务中提升了智能体的子目标达成率，为稀疏奖励环境提供了细粒度的监督信号。

经验增强与选择性优化是信用分配的补充机制。SLEA-RL（Wang and Jiang, 2026）提出步骤级经验增强 RL 框架，通过检索历史经验提升多轮智能体的决策质量。该方法构建经验库，存储成功轨迹中的关键步骤策略，并在推理时检索相关经验注入提示。其核心创新在于设计格式保持的提示增强机制，将检索到的经验置于系统角色，避免破坏观察分布。SLEA-RL 通过复用历史成功经验，加速了智能体在新任务中的收敛。该方法在 WebShop 等环境中实现了更快的收敛速度与更高的渐近性能，为经验驱动 Agentic RL 提供了有效机制。STAPO（Qi et al., 2026）提出选择性轨迹感知策略优化方法，解决长程智能体训练中的轨迹忽视问题。该方法利用熵信号识别轨迹中的关键步骤，通过选择性加权优化策略更新。其核心创新在于区分状态复杂度与智能体置信度，利用熵作为正则化或重加权信号，避免对低信息量步骤的过度优化。STAPO 通过聚焦高价值交互片段，提升了策略在长程任务中的目标导向性。该方法在 ALFWorld 与 WebShop 任务中改善了训练稳定性，为长程 Agentic RL 提供了基于内部反馈的优化策略。

### 2.3 多智能体协同

多智能体协同的演进始于对单智能体在复杂任务中能力局限的反思。Dr. MAS（Feng et al., 2026）提出针对多智能体 LLM 系统的稳定 RL 训练方法，解决全局基线导致的梯度不稳定问题。该方法识别出不同角色智能体奖励分布的差异，提出按智能体独立归一化优势函数的策略。其核心创新在于消除全局均值与方差对特定智能体优势估计的偏差，降低了梯度估计方差。Dr. MAS 通过稳定多智能体联合优化过程，提升了协作策略的收敛性。该方法在信息检索与答案合成任务中显著优于基线，为多智能体 RL 提供了实用的稳定性保障。

角色专业化是多智能体协同的核心设计。Stronger-MAS（Zhao et al., 2025）提出多智能体 RL 框架，通过角色专业化策略提升协作 LLM 的性能。该方法采用角色共享与角色专业化相结合的架构，允许不同智能体拥有独立的策略参数。其核心创新在于设计树采样机制，生成包含代码生成、单元测试与代码优化的协作轨迹，并基于组内相对优势进行优化。Stronger-MAS 通过解耦不同角色的优化目标，提升了多智能体系统的整体效能。该方法在软件工程任务中展现了强大的协作能力，为角色专业化多智能体 RL 提供了参考。DRAFT-RL（Li et al., 2025）提出多智能体链式草稿推理框架，通过多草稿生成与同伴反馈提升推理质量。该方法让多个 LLM 智能体协作解决复杂推理任务，每个智能体生成多个草稿并基于同伴反馈进行迭代优化。其核心创新在于引入多草稿机制，增加策略探索的多样性，并通过奖励信号引导智能体选择高质量草稿。DRAFT-RL 通过多智能体间的交互与反馈，提升了推理的鲁棒性。该方法在数学与代码生成任务中展现了优于单智能体的性能，为多智能体协作推理提供了有效范式。

理论分析为多智能体协同提供了指导。When Do Multi-Agent Systems Outperform（Su and Wu, 2026）通过 PAC 学习框架分析多智能体 RL 在 LLM 场景下的样本效率。该研究对比了单智能体 RL 与多智能体 RL 在不同任务复杂度下的学习效率，揭示了多智能体系统的优势边界。其核心贡献在于建立了理论模型，量化了多智能体协作带来的样本效率增益。该分析为多智能体系统的设计提供了理论指导，明确了在何种条件下多智能体优于单智能体。该工作填补了多智能体 LLM RL 理论分析的空白，为后续研究提供了基准。TRACER（Li et al., 2026）提出回合级后悔匹配与内部强化信用分配机制，用于合作多 LLM 推理。该方法将多智能体系统建模为合作博弈，利用反事实后悔最小化（CFR）思想优化协作策略。其核心创新在于设计回合级信用分配算法，将团队整体性能映射到个体智能体的策略更新中。TRACER 通过理论收敛保证，提升了多智能体协作策略的稳定性。该方法在复杂推理任务中展现了优于固定规则协作机制的性能，为多智能体 RL 提供了理论驱动的设计方案。

编排与流水线并行是多智能体协同的工程实现。Conductor（Nielsen et al., 2025）提出基于 RL 的智能体编排框架，训练 Conductor 模型协调多个大型 LLM 智能体。该方法将任务分解、子任务分配与通信策略定义为 Conductor 的输出，通过 RL 优化编排策略。其核心创新在于将多智能体协作过程建模为序列决策问题，利用可验证奖励训练编排策略。Conductor 通过自然语言接口协调异构智能体，提升了复杂任务的解决能力。该方法在 GPQA 与 LiveCodeBench 等基准上达到 SOTA，为多智能体系统提供了自动化的编排解决方案。MarsRL（Liu et al., 2025）提出 Agentic 流水线并行 RL 框架，联合训练 Solver、Verifier 与 Corrector 智能体。该方法将验证-纠正推理系统重构为多智能体协作流程，通过 RL 优化各智能体的策略。其核心创新在于设计 Agentic 流水线并行机制，协调不同智能体的训练与推理过程，解决开源模型在验证-纠正系统中的泛化问题。MarsRL 通过联合优化，提升了多智能体系统在数学推理任务中的性能。该方法在 AIME 等基准上展现了显著优势，为多智能体推理系统提供了有效的训练范式。

Harness-RL（Jiang et al., 2026）提出动作-参数解耦的黑盒 RL 框架，用于中央智能体多智能体 Harness 训练。该方法将中央智能体的决策分解为离散动作与连续参数，分别路由至不同的功能参数子集进行优化。其核心创新在于设计接口级黑盒 RL 机制，将 Harness 交互转换为 Token 对齐的训练数据，并实现动作与参数的梯度隔离。Harness-RL 通过解耦优化冲突，提升了中央智能体在调度子智能体时的决策质量。该方法在多智能体 Harness 场景中展现了稳定的训练性能，为复杂多智能体系统提供了细粒度的优化策略。

### 2.4 探索与泛化

探索与泛化的演进源于对稀疏奖励下智能体陷入局部最优的反思。Strategy-Guided Exploration（Szot et al., 2026）提出策略引导探索框架，解决稀疏奖励环境下 LLM 智能体的探索效率问题。该方法利用 LLM 生成高层策略提示，引导智能体在环境中的探索方向，避免盲目试错。其核心创新在于将策略生成与动作执行解耦，通过策略提示约束动作空间，提升探索的针对性。该框架在 Web 导航与工具使用任务中显著提升了探索效率。该方法为稀疏奖励 Agentic RL 提供了基于语言模型的探索引导机制，增强了智能体在复杂环境中的适应能力。

记忆增强是探索效率的关键机制。EMPO2（Liu et al., 2026）提出探索性记忆增强混合 On/Off-Policy 优化算法，解决在线 RL 中的探索挑战。该方法在 Rollout 阶段结合无记忆提示与记忆增强提示，生成多样化轨迹。其核心创新在于设计混合优化策略，将记忆增强轨迹用于 On-policy 更新，同时去除记忆进行 Off-policy 更新，以平衡探索与利用。EMPO2 通过记忆机制复用历史经验，提升了智能体在新任务中的适应能力。该方法在 ScienceWorld 与 WebShop 任务中展现了优越的性能，为记忆增强 Agentic RL 提供了有效算法。MAGE（Yang et al., 2026）提出元强化学习框架，实现语言智能体的战略性探索与利用。该方法引入反思内环，使模型在回合间生成自我反思摘要，构建上下文记忆。其核心创新在于将元学习原则应用于 LLM 智能体，通过反思机制实现测试时适应，动态调整策略以应对环境变化。MAGE 通过内部反馈循环，提升了智能体在非平稳环境中的鲁棒性。该方法在复杂多步任务中展现了优于静态提示方法的性能，为自适应 Agentic RL 提供了新范式。

元学习驱动的探索是另一条路径。Meta-RL Induces Exploration（Jiang et al., 2025）提出 LAMER 框架，通过元 RL 诱导 LLM 智能体的探索行为。该方法采用跨回合训练方案，将每次尝试视为回合序列，使智能体在早期回合探索，后期回合利用。其核心创新在于利用自我反思作为上下文适应机制，无需梯度更新即可调整策略。LAMER 通过平衡探索与利用，提升了智能体在新环境中的快速适应能力。该方法在多个基准测试中展现了优越的泛化性能，为元学习驱动的 Agentic RL 提供了有效框架。Complementary RL（Muhtar et al., 2026）提出互补 RL 框架，通过异步经验提取提升样本效率。该方法将 Rollout 收集与经验蒸馏解耦，主循环优化结果奖励，后台轨道提取过程经验。其核心创新在于设计中央经验管理器，协调异步训练与经验复用，使智能体从成功与失败轨迹中同时学习。Complementary RL 通过利用丰富的过程信息，弥补了稀疏结果奖励的不足。该方法在长程任务中提升了策略的泛化能力，为高效 Agentic RL 提供了系统级解决方案。

泛化能力的实证研究揭示了 RL 的局限性。Can RL Improve Generalization（Xi et al., 2026）通过实证研究分析 RL 对 LLM 智能体泛化能力的影响。该研究在 Web 导航与软件工程任务中评估 RL 训练后的智能体在分布外任务上的表现。其核心发现是 RL 训练虽能提升任务特定性能，但可能加剧对训练环境的过拟合，导致泛化能力下降。该分析揭示了 RL 在 Agentic 场景下的局限性，为后续研究提供了重要参考。该工作强调了在 RL 训练中引入泛化正则化的必要性，为 Agentic RL 的评估标准提供了实证依据。Paying Less Generalization Tax（Liu et al., 2026）提出跨域泛化研究，分析 RL 训练对 LLM 智能体泛化性能的影响。该研究在 WebShop、Sokoban 等环境中评估智能体的跨域泛化能力，识别状态信息丰富度与规划复杂度为关键因素。其核心贡献在于量化了训练-评估分布差距对性能的影响，提出了降低泛化税的策略。该工作为 Agentic RL 的跨域部署提供了指导，强调了环境多样性在训练中的重要性。该研究为设计更具泛化能力的 Agentic 智能体提供了实证基础。Diagnosing Task Insensitivity（Liu et al., 2026）提出任务不敏感性诊断方法，分析 LLM 智能体在任务描述扰动下的行为。该方法通过腐蚀任务描述，评估智能体动作策略对任务指令的条件依赖性。其核心发现是 RL 训练可能导致智能体过度依赖熟悉任务模式，降低对任务指令的敏感度。该诊断方法揭示了 Agentic RL 中的潜在过拟合风险，为评估智能体鲁棒性提供了新工具。该工作强调了任务条件化在智能体训练中的重要性，为改进 RL 训练策略提供了方向。

### 2.5 算法稳定性

算法稳定性的演进源于对多轮 RL 训练中熵坍缩与策略崩溃的反思。ARLArena（Wang et al., 2026）提出 Agentic RL 训练稳定性统一框架，通过标准化测试环境与消融实验分析训练崩溃原因。该方法构建了干净且标准化的测试基准，系统性地评估不同算法组件对稳定性的影响。其核心贡献在于揭示了熵坍缩与推理模板化之间的关联，指出熵降低可能反映模型特化而非性能提升。ARLArena 为调试 Agentic RL 训练提供了可复现的分析工具，指导了更稳定的算法设计。该框架填补了 Agentic RL 稳定性研究的空白，为后续研究提供了基准与参考。

Off-policy 训练的不稳定性是另一核心问题。SORL（Li et al., 2025）提出稳定 Off-Policy 训练框架，通过回合级重要性采样与裁剪触发归一化提升长程智能体训练稳定性。该方法识别出 Off-policy 训练中策略陈旧性导致的更新不稳定问题，设计回合级信用分配机制。其核心创新在于引入裁剪触发归一化，抑制不可靠更新，生成更保守的梯度估计。SORL 通过算法无关的设计，适用于 PPO 与 GRPO 等多种 RL 方法。该方法在长程任务中显著提升了训练稳定性，防止了性能崩溃，为 Off-policy Agentic RL 提供了实用解决方案。EPO（Xu et al., 2025）提出熵正则化策略优化方法，解决 LLM 智能体 RL 中的探索-利用级联失败问题。该方法在多轮交互中计算轨迹级熵，将其作为正则化项加入策略损失。其核心创新在于识别出多轮环境中决策通过共享策略参数复合，需在全轨迹层面监控熵变化。EPO 通过熵正则化维持策略多样性，防止过早收敛到次优策略。该方法在编码与 Web 搜索任务中提升了训练稳定性，为 Agentic RL 提供了基于熵控制的优化策略。

训练-推理不一致是稳定性研究的深层问题。MIPI（Liang et al., 2026）提出单调推理策略作为 LLM RL 的真实优化目标，解决训练策略与推理策略不一致问题。该方法引入采样器参考更新与推理间隙感知接受机制，确保推理策略的单调改进。其核心创新在于区分训练侧更新与推理侧同步，通过两步实现机制对齐两者。MIPI 通过优化推理策略而非训练策略，提升了模型在实际部署中的性能。该方法在数学推理任务中展现了优越的性能，为 LLM RL 提供了更贴近实际应用的优化目标。SFT Conflicts, RL Coexists（Zhu et al., 2026）通过理论与实证分析揭示 SFT 与 RL 在多任务学习中的不同行为。该研究发现 SFT 导致性能崩溃，而 RL 实现稳定累积性能增长，源于 RL 梯度的稀疏性与 On-policy 特性。其核心贡献在于从梯度下降方向分析 SFT 与 RL 的差异，推导出任务间梯度干扰的上界。该分析为多任务 Agentic RL 提供了理论指导，解释了 RL 在复杂任务组合中的优势。该工作澄清了 SFT 与 RL 在 LLM 后训练中的互补关系，为混合训练策略提供了依据。

工具使用 RL 的特定失败模式是稳定性研究的新焦点。Why Multi-Step Tool-Use RL Collapses（Hao et al., 2026）分析多步工具使用 RL 中的结构坍缩问题，提出监督信号修复机制。该研究系统性地研究 SFT-then-RL、Off-policy 监督等五种监督信号对稳定性的影响。其核心发现是缺乏过程监督导致策略在工具调用结构上坍缩，引入过程反思监督可修复此问题。该工作揭示了工具使用 RL 中的特定失败模式，为设计更稳定的工具使用智能体提供了指导。该分析强调了过程奖励在工具使用 RL 中的重要性，为后续研究提供了实证基础。Gradient Coupling（Liu et al., 2025）揭示 Agentic RL 中梯度耦合作为泛化障碍的机制，提出解耦学习信号策略。该方法分析正负轨迹间的梯度干扰，指出重叠动作序列导致负样本抑制正样本学习。其核心创新在于设计解耦机制，确保正确动作被强化而错误动作被抑制，避免梯度耦合导致的泛化性能下降。该工作从梯度层面解释了 Agentic RL 的泛化局限，为改进优化算法提供了理论依据。该分析强调了在 Agentic RL 中处理正负样本平衡的重要性，为算法设计提供了新视角。RAGEN-2（Wang et al., 2026）提出推理坍缩诊断方法，通过批内交叉评分检测 Agentic RL 中的模板化推理。该方法计算推理序列在真实输入与边缘分布下的对数似然，定义检索准确率与互信息 Z-Score 作为坍缩指标。其核心创新在于利用批内数据估计输入依赖性，识别推理是否退化为与输入无关的固定模板。RAGEN-2 为监控 Agentic RL 训练质量提供了可解释的指标，指导了更稳定的训练策略。该工作揭示了熵指标在评估推理质量上的局限性，为 Agentic RL 的评估提供了新工具。

### 2.6 理论机制分析

理论机制分析的演进源于对 RL 在 LLM 智能体中作用本质的追问。RL Compositionality（ICLR 2026）提出 RL 组合性假设，论证 RL 通过组合原子技能学习新能力而非创造全新技能。该研究定义了“新技能”为通过系统组合现有能力解决先前不可解问题的推理策略。其核心贡献在于通过实验验证 RL 在适当激励下能组合原子技能，并分析其泛化性。该工作澄清了 RL 在 LLM 技能获取中的本质，反驳了 RL 仅激活现有能力的悲观观点。该理论为理解 RL 在 Agentic 场景中的作用提供了框架，指导了更有效的技能组合训练策略。

POMDP 视角为 Agentic RL 提供了更严谨的理论基础。Rethinking Agentic RL（Cui et al., 2026）从 POMDP 视角重新审视 Agentic RL，分析 LLM 作为策略在部分可观测环境中的决策机制。该研究指出传统 LLM 作为自回归预测器与 Agentic RL 中策略角色的差异，强调环境交互对策略优化的重要性。其核心贡献在于建立 Agentic RL 的理论框架，分析观察-行动循环中的信息利用问题。该工作为 Agentic RL 提供了更严谨的理论基础，指导了更合理的算法设计。该分析强调了在 Agentic RL 中处理部分可观测性的必要性，为后续研究提供了理论支撑。

多智能体系统的理论分析填补了空白。When Do Multi-Agent Systems Outperform（Su and Wu, 2026）通过 PAC 学习框架分析多智能体 RL 在 LLM 场景下的样本效率。该研究建立了理论模型，量化多智能体协作带来的样本效率增益，揭示其优势边界。其核心贡献在于对比单智能体与多智能体 RL 的学习曲线，明确多智能体系统在复杂任务中的理论优势。该分析为多智能体 LLM 系统的设计提供了理论指导，解释了协作机制的有效性。该工作填补了多智能体 LLM RL 理论分析的空白，为后续研究提供了基准与参考。

SFT 与 RL 的互补关系是理论机制分析的重要发现。SFT Conflicts, RL Coexists（Zhu et al., 2026）通过梯度分析揭示 SFT 与 RL 在多任务学习中的内在机制差异。该研究发现 RL 梯度的稀疏性与 On-policy 特性导致任务间干扰小，而 SFT 梯度密集导致冲突。其核心贡献在于推导任务间梯度干扰的上界，解释 RL 在多任务场景中的稳定性优势。该理论为混合训练策略提供了依据，指导了 SFT 与 RL 的协同使用。该工作澄清了两种范式在 LLM 后训练中的互补关系，为 Agentic RL 的理论基础提供了重要补充。

数据稀缺下的 RL 挑战是理论机制分析的新焦点。A Survey of RL for LLMs under Data Scarcity（Yu et al., 2026）综述数据稀缺下 LLM RL 的挑战与解决方案，从数据、训练与框架三个视角分析。该研究系统性地梳理了数据剪枝、合成与压缩技术，以及离线/在线 RL 算法在数据受限场景下的表现。其核心贡献在于建立数据效率 RL 的分类框架，识别关键瓶颈与解决路径。该综述为数据受限 Agentic RL 提供了全面的技术地图，指导了资源高效训练策略。该工作强调了数据质量与多样性在 RL 中的重要性，为后续研究提供了参考。

泛化机制的实证研究揭示了 RL 的局限性。Can RL Improve Generalization（Xi et al., 2026）通过实证研究分析 RL 对 LLM 智能体泛化能力的影响机制。该研究在多个环境中评估 RL 训练后的智能体在分布外任务上的表现，揭示过拟合风险。其核心贡献在于量化 RL 训练对泛化性能的影响，识别导致泛化下降的关键因素。该分析为 Agentic RL 的评估标准提供了实证依据，强调了泛化正则化的必要性。该工作揭示了 RL 在 Agentic 场景下的局限性，为改进训练策略提供了方向。Paying Less Generalization Tax（Liu et al., 2026）通过跨域泛化研究分析 RL 训练对 LLM 智能体泛化性能的影响机制。该研究识别状态信息丰富度与规划复杂度为影响泛化的关键因素，量化训练-评估分布差距。其核心贡献在于建立泛化税的测量框架，提出降低泛化税的策略。该工作为 Agentic RL 的跨域部署提供了指导，强调了环境多样性在训练中的重要性。该研究为设计更具泛化能力的 Agentic 智能体提供了实证基础，揭示了 RL 泛化机制的内在规律。

长程任务的时间步长影响是理论机制分析的新视角。On Training LLMs for Long-Horizon Tasks（Kim et al., 2026）通过实证研究分析时间步长对 LLM 智能体 RL 训练的影响。该研究发现 RL 在长程任务中失效，提出通过宏动作与子目标分解减少有效时间步长。其核心贡献在于建立时间步长与 RL 稳定性的关联，提出结构化的时间步长缩减机制。该分析为长程 Agentic RL 提供了设计原则，指导了更稳定的训练策略。该工作揭示了长程任务中 RL 失效的根本原因，为后续研究提供了重要参考。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

RL 是提升 LLM 推理与智能体能力的关键后训练范式，这一共识在多个基准上被反复验证。Stronger-MAS 在 ALFWorld 上的 99.5% 与 WebShop 上的 96.0% 均大幅超越 GPT-4o 的 48.0% 与 23.7%，CoPRIS 在 AIME24 上的 34.48% 也显著优于 Baseline 的 29.38%。这些结果共同支持了 RL 在长程任务与复杂推理中的优势。然而，该共识的边界在于：RL 的优势在基础任务（如 GSM8K）上并不显著，MarsRL 的 92.6% 与 Baseline 的 92.6% 持平，表明 RL 在简单任务上的边际收益有限。

与此相关的另一个共识是，多轮交互中的信用分配是 Agentic RL 的核心挑战，稀疏奖励导致传统方法失效。Tree-GRPO、Turn-PPO、SALT 等方法均针对这一问题提出了解决方案，且在 ALFWorld 与 WebShop 上展现了性能提升。SLEA-RL 在 ALFWorld 上的 60.3% 与 WebShop 上的 42.5% 均优于 HiPER 的 58.7% 与 HISR 的 35.9%，表明细粒度信用分配机制的有效性。然而，该共识的边界在于：信用分配机制的增益在数学推理任务（如 AIME）上并不显著，CoPRIS 的 34.48% 与 veRL 的 32.60% 差距较小，表明数学推理可能更依赖模型基础能力而非信用分配机制。

### 3.2 观点分歧

RL 的本质是“组合现有技能”还是“创造新能力”？RL Compositionality（ICLR 2026）提出 RL 通过组合预训练中已有的原子能力形成复杂推理策略，而非创造全新技能。该研究通过实验验证了 RL 在适当激励下能组合原子技能，支持了“组合”观点。然而，实证研究如 Can RL Improve Generalization（Xi et al., 2026）发现 RL 训练虽能提升任务特定性能，但可能加剧对训练环境的过拟合，暗示 RL 可能激活或创造新的推理路径。现有证据偏向“组合”观点，但证据强度有限，主要在数学推理等结构化任务上验证，在开放域任务上的泛化能力尚不明确。分歧根源在于缺乏统一的“新技能”定义与测量工具，以及 OOD 任务上的实证数据不足。

这一分歧的背后，是另一个更根本的争论：多智能体系统是否总是优于单智能体？PAC 学习框架（Su and Wu, 2026）指出多智能体系统在复杂任务中具有样本效率优势，能分解任务并并行探索。Stronger-MAS 在 ALFWorld 与 WebShop 上达到 SOTA，支持了这一观点。然而，Dr. MAS（Feng et al., 2026）等工作揭示了多智能体训练的稳定性挑战，全局基线导致的梯度不稳定需要独立归一化等额外机制来解决。现有证据偏向多智能体在理论层面具有优势，但在工程层面，通信开销与信用分配难度可能抵消其理论增益。分歧根源在于缺乏大规模、多任务的标准化基准来公平比较单/多智能体系统，以及多智能体系统的信用分配机制尚未成熟。

### 3.3 其他开放问题

最紧迫的工程问题是异步训练中的长尾延迟与多智能体系统的资源调度。当前同步训练存在长尾延迟与资源浪费，需设计解耦的 rollout-training 架构、异步权重同步与动态并行策略，以支持大规模集群部署。AgentRL、Earl、CoPRIS 等方法已提出了解决方案，但在异构环境下的可扩展性仍需验证。关键困难在于 Off-policy 偏差的校正与系统复杂度的平衡，研究路径包括开发更轻量级的重要性采样校正机制与自动化资源调度策略。

最根本的研究问题是稀疏奖励下的探索效率与 RL 的泛化边界。现有模型在分布外任务上性能显著下降，需研究任务敏感性正则化、经验回放与元学习策略，以增强模型对未见环境的适应能力。Strategy-Guided Exploration、EMPO2、MAGE 等方法已提出了解决方案，但在开放域任务上的泛化能力仍不明确。关键困难在于探索-利用平衡的理论指导不足，研究路径包括开发基于信息增益的内在奖励机制与元学习驱动的自适应探索策略。

已知—争议—未知认知图谱显示：已知 RL 在长程任务与复杂推理中具有优势，异步架构能显著提升效率，GRPO 及其变体成为主流算法；争议 RL 的本质是组合还是创造，多智能体是否总是优于单智能体，训练-推理一致性的重要性；未知稀疏奖励下的探索效率机制，RL 的泛化边界，多智能体协作的理论收敛性。发展趋势表明，领域正从追求 SOTA 分数转向追求鲁棒性与泛化能力，以应对真实世界的复杂性。

## 4. 总结与展望

Agentic RL 的核心矛盾在于稀疏奖励下的信用分配困难与长程任务对细粒度监督的需求。研究尝试了从 PPO 到 GRPO 的算法简化，从同步到异步的系统解耦，从轨迹级到步骤/回合级的信用分配细化，以及从单智能体到多智能体的协作扩展。核心瓶颈在于训练不稳定与泛化能力不足，RL 在分布外任务上表现下降，甚至出现任务不敏感现象，源于对训练环境特定模式的过拟合。这一瓶颈回扣了第 1 章的核心问题：如何在稀疏奖励与长程依赖的多轮交互环境中，通过强化学习实现 LLM 策略从局部最优到全局泛化的稳定收敛。

未来可能突破的方向包括：基于信息增益的内在奖励机制，通过细化奖励信号提升探索效率（Strategy-Guided Exploration, EMPO2）；元学习驱动的自适应探索，通过反思机制实现测试时适应（MAGE, Meta-RL Induces Exploration）；多模态开放环境下的鲁棒性评估，扩展至视觉-语言交互与真实世界工具调用（Can RL Improve Generalization, Paying Less Generalization Tax）。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，系统性地评估不同信用分配机制在 OOD 任务上的泛化性能，以隔离算法贡献并揭示 RL 的泛化边界。
