综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Semantic%20Understanding%20in%20LLMs)

## 导读

大语言模型（Large Language Models, LLMs）的语义理解研究正经历从行为验证向机制解释的深刻范式转移，其核心驱动力在于模型规模增长带来的表面流畅性与深层认知逻辑缺失之间的张力。早期研究依赖通用基准验证模型能力，但抽象概念接地与语用推理的系统性偏差暴露了统计模式匹配的局限。随着稀疏自编码器（Sparse Autoencoders, SAEs）等机制可解释性工具的引入，研究者得以定位歧义编码神经元与语义角色电路，将黑盒行为评估转化为白盒机制分析。各路线在机制透明度、评估深度与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从统计关联到机制解释的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

语义理解在大型语言模型领域的兴起，源于 Transformer 架构突破后模型规模与训练数据的指数级增长，使得自然语言处理任务性能达到前所未有的标准。然而，早期研究主要关注表面统计规律，2020 年后随着 GPT-3 等模型的涌现，研究重心转向探究模型是否具备真正的“语义理解”能力，而不仅仅是模式匹配。这一转变的核心矛盾在于：模型在通用基准上表现优异，但在抽象概念、语用推理等深层认知维度上存在系统性偏差，揭示了统计拟合与结构推理之间的断裂。

问题形式化可定义为：给定输入文本 $x$ 和上下文 $c$，模型需生成语义表示 $h = f_\theta(x, c)$，使得 $h$ 能够捕捉语言深层含义、意图及逻辑结构，而非仅依赖表面统计关联。这一过程涉及词义消歧（Word Sense Disambiguation, WSD）、语用推理（Pragmatics）及组合性（Compositionality）等多个子问题。子问题间呈现依赖与互补关系：机制可解释性是理解歧义处理和抽象概念接地的基础工具，语用推理和抽象概念理解是暴露模型局限的具体场景，而语义一致性则是检验上述能力鲁棒性的关键维度。不解决内部机制的可解释性，难以从根本上优化歧义处理和接地问题。

范式边界在于区分基于统计规律的模式匹配与基于结构规则的组合性推理。早期假设“规模定律”足以带来通用语义理解，但约束在于缺乏细粒度评估工具，导致模型在深层语义上的局限被通用高分掩盖。2020-2022 年，研究焦点从通用性能转向抽象概念、语用推理等特定维度的细粒度评估，发现模型在深层语义上存在系统性偏差，如“接地鸿沟”和“语义坍缩”现象。

2023-2024 年，引入机制可解释性技术，不再仅关注输入输出，而是深入模型内部寻找语义编码的神经元或电路，试图解释“如何”理解。稀疏自编码器（SAEs）的成熟使得研究者能够分解 LLM 内部激活，识别单义性特征，为解析抽象概念锚定和语义漂移提供了可解释性工具。2025-2026 年，融合认知科学视角，量化“接地鸿沟”和“语义坍缩”，并关注模型在格式变化下的语义一致性，旨在构建更可靠、可解释且符合人类认知逻辑的 AI 系统。

当前形态表现为从“能力验证”向“机制解释”和“认知对齐”过渡，研究热度极高，旨在解决 LLMs 在抽象概念、歧义处理和深层语义结构上的固有局限。机制可解释性技术的引入是区分“统计拟合”与“语义理解”的关键分水岭，当前核心矛盾在于模型表面流畅性与深层认知逻辑（如接地、组合性）之间的断裂。

**如果用一个核心问题概括该领域，那便是：大语言模型内部究竟是通过何种计算机制将高维统计关联转化为符合人类认知逻辑的深层语义结构，以及这种转化在抽象、歧义及语用场景下的固有边界与失效模式是什么？**

## 2. 方法体系

- 2017：Transformer架构——引入自注意力机制替代循环结构，奠定现代大语言模型处理序列数据的基础架构

- 2018：Word2vec/CBOW——通过预测上下文词来学习分布式词向量，确立分布语义学在计算语言学中的核心地位

- 2020：GPT-3——通过大规模自回归语言建模展示少样本学习能力，证明规模定律在语义理解任务中的有效性

- 2023：MMLU——构建大规模多任务语言理解基准，成为评估 LLM 广泛语义知识与推理能力的标准基准

- 2024：Sparse Autoencoders (SAE)——通过稀疏自编码器分解 LLM 内部激活，识别单义性特征，推动机制可解释性研究

- 2025：Ambiguity-Encoding Neurons (AENs)——识别 LLM 内部稀疏编码歧义的特定神经元，揭示歧义在内部表征中的稀疏分布机制

- 2026：Semantic Role Circuits——通过因果边归因修补识别语义角色回路，证明 LLM 通过局部化回路实现语义角色预测

- 2026：Grounding Gap Analysis——分析 LLM 与人类在抽象概念锚定上的差异，揭示具身认知在 LLM 语义表征中的缺失

这条时间线勾勒了该领域方法演进的代表性节点：从 2017 年的 Transformer 架构奠定该领域方法基线，经 2018 年 Word2vec/CBOW 的推进，到 2026 年的 Semantic Role Circuits 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 语义理解机制可解释性

该路线的起源可追溯至 2018 年 Word2vec/CBOW 确立的分布语义学理论，为后续 LLM 内部表征分析提供了理论原型。2019 年 BERT 通过双向编码器表示技术显著提升了上下文相关的词义消歧能力，成为后续语义理解基准的常用基线。2024 年稀疏自编码器（SAE）的引入标志着从黑盒行为评估向白盒机制分析的范式转变，研究者开始通过因果干预和特征提取深入模型内部寻找语义编码的神经元或电路。

Ambiguity-Encoding Neurons (AENs)（Zhang et al., 2025, P1）通过激活归因分析识别 LLM 内部稀疏编码问题歧义的特定神经元，这些神经元在多个数据集和模型间具有预测一致性。该方法不依赖提示工程或采样策略，而是直接干预内部表征，将模型行为从自信回答转向弃权。其核心创新在于将歧义视为内部状态而非输入输出现象，揭示了歧义在 Transformer 中的稀疏分布特性。代价是需要精细的神经元定位技术，且干预效果可能随模型规模变化而波动。该方法为理解 LLM 如何处理不确定性提供了机制层面的证据，推动了从行为主义向机制可解释性的研究范式转变。

Deferred Semantic Drift Analysis（P23）利用因果注意力掩码特性，分析 LLM 在处理隐喻时早期 token 表征对后续消歧上下文的惰性，揭示语义漂移的延迟机制。该方法通过追踪隐藏状态在层间的演化，量化了模型在缺乏未来信息时的语义固化程度。其创新点在于将计算语言学的因果约束与机制可解释性结合，解释了为何 LLM 在动态语境中难以即时更新词义。代价是分析过程计算密集，且主要适用于解码器架构。该方法揭示了 LLM 在实时语义调整上的固有局限，为优化注意力机制以支持动态语义更新提供了方向。

Semantic Role Circuits Identification（P22）结合因果边归因修补、时间涌现分析和跨模型比较，识别 LLM 中负责语义角色预测的局部化回路。该方法通过因果干预验证回路组件的必要性，并分析其在训练过程中的巩固时间线，区分了分布式表征与局部化回路的作用。其创新在于将语义角色理解形式化为因果回路问题，揭示了抽象语义结构在 LLM 中的计算实现方式。代价是回路识别可能仅捕获部分计算基底，且时间分析依赖特定训练数据。该方法为理解 LLM 如何内化抽象语义结构提供了新视角，支持了语义理解具有模块化回路假设。

Grounding Gap Probing（Chlapanis et al., 2026, P18）利用稀疏自编码器（SAE）特征探测 LLM 内部对抽象概念的锚定机制，对比人类基于感觉运动经验的锚定方式。该方法通过收集标签池并分析 SAE 特征与接地类别的对应关系，量化了模型在抽象概念理解上的具身缺失。其创新点在于将具身认知理论与机制可解释性技术结合，揭示了 LLM 依赖抽象符号关联而非感官锚点的本质。代价是 SAE 特征的解释性有限，且接地类别的定义依赖人工标注。该方法为评估 LLM 的语义接地能力提供了新工具，指出了当前模型在抽象概念理解上的根本局限。

Brain-LLM Alignment Analysis（Bonnasse-Gahot and Pallier, 2026, P8）通过功能磁共振成像（fMRI）数据预测 LLM 内部表征，分析左右脑不对称性在 LLM 语义处理中的涌现。该方法使用 OLMo2 模型作为编码模型，比较人类脑活动与 LLM 激活的对齐程度，揭示形式语言能力与神经对齐的关系。其创新在于将神经科学指标引入 LLM 可解释性研究，验证了 LLM 内部表征与人类大脑语义处理的同构性。代价是依赖高质量脑成像数据，且模型选择可能影响对齐结果。该方法为 LLM 作为人类认知模型提供了神经科学证据，支持了 LLM 内部结构模拟人类语义处理的假设。

### 2.2 高层语义与语用推理

该路线聚焦隐喻、讽刺、隐含意义及非字面语义的理解，评估 LLM 在复杂语用场景下的推理能力与人类认知差异。2020 年 GPT-3 通过大规模自回归语言建模展示少样本学习能力，开启了 LLM 作为通用推理引擎的研究方向。2023 年 BIG-bench 提出大规模行为评估套件，系统量化 LLM 在语用推理、隐喻理解等复杂语义任务上的表现，揭示了模型在细微语义差异上的脆弱性。

Metaphorical Understanding Framework（Ye et al., 2025, P3）在解释和检测两个层面评估 LLM 的隐喻理解能力，利用概念隐喻理论（CMT）分析源域与目标域的映射关系。该方法通过三维空间分析隐喻解释与标准参考的距离，量化模型对概念无关性和语境利用的敏感度。其创新点在于将语言学理论转化为可计算的评估指标，揭示了 LLM 在隐喻解释中依赖句法结构而非深层概念映射的倾向。代价是评估依赖人工构建的概念平面，且多义性隐喻分析复杂。该方法为评估 LLM 的非字面语义理解提供了新范式，指出了模型在隐喻推理上的局限。

Implicature Interaction Evaluation（Hota and Jokinen, 2025, P5）设计三个实验评估 LLM 对会话含义（Implicature）的理解与响应，包括解释准确性、用户感知质量和偏好测试。该方法基于 Gricean 准则和相关性理论，测试模型在社交语境中推断言外之意的能力，区分字面意义与隐含意义。其创新在于将语用学理论应用于人机交互评估，揭示了 LLM 在捕捉细微语用线索上的不足。代价是实验设计依赖特定对话场景，且用户感知评估主观性强。该方法为优化 LLM 的对话策略提供了依据，强调了语用理解在自然交互中的重要性。

CEI Pragmatic Reasoning Benchmark（Chun et al., 2026, P10）构建语用推理评估基准，聚焦隐含意义恢复，测试 LLM 在复杂社交语境中整合上下文线索、社会知识和心智理论的能力。该方法通过人工标注的语用场景，量化模型在区分真诚同意、策略性礼貌和被动攻击性顺从上的表现。其创新点在于将语用推理操作化为 NLP 任务，填补了现有基准在深层语用理解上的空白。代价是标注成本高，且语用解释存在主观性。该方法为评估 LLM 在 HR 筛选、内容审核等高风险应用中的语用能力提供了工具，揭示了模型在复杂社会推理上的局限。

Drivel-ology Benchmark（P24）构建无意义深度解释基准，通过多语言无意义文本测试 LLM 的深层解释能力，挑战模型对幽默、讽刺等语用现象的理解。该方法要求模型对无意义文本进行叙事解释和分类，揭示其依赖表面统计而非深层逻辑的倾向。其创新在于利用无意义文本剥离语义内容，纯粹测试解释推理能力，指出了 LLM 在创造性解释上的脆弱性。代价是无意义文本的构建和标注复杂，且解释质量评估困难。该方法为评估 LLM 的深层认知能力提供了新视角，挑战了模型具备真正语义理解的假设。

Implicit Information Extraction Pipeline（De Santis et al., 2026, P14）提出三阶段流水线提取隐含信息，包括信息提取、推理验证和时间分析，对比人类与 LLM 的知识模型。该方法通过开放提取捕捉 LLM 对语言的感知，利用知识图谱分离显式和隐含意义，分析时间维度上的推理差异。其创新点在于将隐含信息提取形式化为知识图谱构建过程，揭示了 LLM 与人类在隐含意义推断上的系统性差异。代价是流水线复杂，且时间分析依赖特定语料。该方法为评估 LLM 的深层语义理解提供了新工具，指出了模型在隐含意义推断上的偏差。

### 2.3 抽象概念与组合性

该路线探究 LLM 对抽象概念、组合语义及概念演化的理解，分析其从具体原型到抽象意义的映射逻辑与局限。2021 年 SemEval-2021 Task 4 构建了抽象概念阅读理解基准，系统评估模型对非具体概念（如自由、正义）的理解能力，揭示了深度学习模型在抽象语义上的局限。2025 年 CogEvolve 提出多模态语义扩展基准，利用 SVG 结构化视觉叙事测试 LLM 从具体原型到抽象意义的类比推理能力，验证了模型是否内化了连接概念的生成逻辑而非仅统计表面。

Abstract Meaning Comprehension Evaluation（Alhazmi and Jiang, 2026, P13）利用零样本和少样本提示评估 LLM 在 SemEval-2021 Task 4 上的抽象概念理解能力，对比微调编码器模型的表现。该方法通过构建提示模板将选择任务转化为生成任务，量化模型对非具体概念（如自由、正义）的区分能力。其创新点在于系统评估 LLM 在抽象语义上的局限，揭示了模型依赖具体原型而非抽象层级的倾向。代价是提示工程敏感，且评估依赖特定数据集。该方法为评估 LLM 的抽象推理能力提供了基准，指出了模型在抽象概念理解上的不足。

CogEvolve Multimodal Benchmark（P30）提出多模态语义扩展基准，利用 SVG 结构化视觉叙事测试 LLM 从具体原型到抽象意义的类比推理能力。该方法通过人类架构的 SVG 图像序列，测试模型识别类比转换（如容器变为边界）的能力，验证其是否内化了生成逻辑。其创新点在于结合视觉结构和语义推理，揭示了 LLM 在语义扩展上的方向性因果局限。代价是 SVG 构建复杂，且视觉推理评估主观。该方法为评估 LLM 的类比推理能力提供了新工具，指出了模型在概念演化理解上的局限。

Adjective-Noun Compositionality Evaluation（Dhar et al., 2026, P11）从功能和表征两个视角评估 LLM 在形容词-名词短语上的组合性，通过推理任务测试语义结构保持能力。该方法利用蕴含关系验证组合短语是否保留或改变部分语义，量化模型对组合语义的推理能力。其创新点在于将组合性操作化为推理任务，揭示了 LLM 在组合语义上的功能与表征差异。代价是任务设计依赖特定短语类型，且推理评估复杂。该方法为评估 LLM 的组合语义能力提供了新范式，指出了模型在组合性上的局限。

Human-Aligned Categorization Analysis（P28）利用信息瓶颈（IB）框架分析 LLM 中人类对齐语义分类的涌现与压缩，以颜色命名任务为案例。该方法通过 IB 通信模型量化 LLM 在语义系统上的通用模式和跨语言差异，揭示其学习偏差与人类认知的对齐程度。其创新点在于将认知科学理论引入 LLM 分析，验证了 LLM 内部语义分类与人类感知系统的同构性。代价是 IB 模型假设严格，且颜色任务代表性有限。该方法为评估 LLM 的认知对齐提供了新工具，支持了 LLM 作为人类认知模型的假设。

Paired-Focus Construction Analysis（Scivetti et al., 2026, P19）研究 LLM 对配对焦点构式（Paired-Focus Constructions）的句法和语义理解，通过训练动态分析知识涌现时间线。该方法发现语义理解晚于句法知识涌现，且与世界知识增益相关，支持构式语法在 LM 处理中的核心地位。其创新点在于将构式语法理论与 LLM 训练动态结合，揭示了语义与句法学习的异步性。代价是构式选择特定，且训练动态分析依赖开源检查点。该方法为理解 LLM 的构式理解提供了新视角，支持了构式语法在语言模型中的重要性。

### 2.4 语义一致性与鲁棒性

该路线评估 LLM 在格式变化、歧义处理及语义等价输入下的稳定性，揭示其语义不一致性与认知偏差风险。2023 年 MMLU 构建大规模多任务语言理解基准，成为评估 LLM 广泛语义知识与推理能力的标准基准，暴露了模型在特定领域知识上的偏差。2025 年 Semantic Inconsistency Analysis 系统评估 LLM 在语义等价输入下的预测一致性，通过嵌入空间分析揭示格式变化导致的语义漂移，指出模型内部计算对表面格式的过度敏感。

Semantic Inconsistency Analysis（P32）系统评估 LLM 在语义等价输入下的预测一致性，通过嵌入空间分析揭示格式变化导致的语义漂移。该方法计算嵌入距离与输出一致性的相关性，定位内部计算中不一致性的来源，指出模型对表面格式的过度敏感。其创新点在于将语义不一致性形式化为嵌入空间问题，揭示了 LLM 内部计算的脆弱性。代价是嵌入分析依赖特定层，且一致性评估主观。该方法为评估 LLM 的鲁棒性提供了新工具，指出了模型在语义稳定性上的局限。

Ambiguity Collapse Taxonomy（Gur-Arieh et al., 2026, P9）提出歧义坍缩分类法，分析 LLM 在处理多义术语时如何消除解释多样性，指出模型倾向于强制将模糊案例归入清晰标签。该方法通过分类损失替代解释和损失残差，量化模型在复杂概念（如隐私、正义）上的解释坍缩，揭示其对用户信息空间的收缩。其创新点在于将歧义处理形式化为认知风险，揭示了 LLM 在多元解释上的不足。代价是分类法依赖人工定义，且风险量化主观。该方法为评估 LLM 的歧义处理能力提供了新框架，指出了模型在认知多样性上的局限。

Semantic Content Algorithmic Performance Analysis（Ríos-García et al., 2026, P7）通过受控消融实验揭示 LLM 算法性能对语义内容的依赖，证明计数等算法操作受语义类别影响。该方法通过 token 洗牌、计数控制和分隔符指定等消融，排除表面因素，验证语义类别对算法准确性的影响，揭示模型的语义脆弱性。其创新点在于将算法不变性原则应用于 LLM 评估，揭示了模型在抽象算法操作上的语义偏差。代价是消融实验设计复杂，且语义类别定义主观。该方法为评估 LLM 的算法鲁棒性提供了新工具，指出了模型在语义不变性上的局限。

Semantic Alignment Topological Approach（Ashoff and Rodu, 2026, P21）利用拓扑对齐方法比较 LLM 语义结构与基准，通过嵌入空间测试一致性，避免字符串输出或选择题的局限。该方法分析训练动态、跨语言对齐和行为操纵，揭示概念坍缩和检查点动态，验证 LLM 内部语义结构的稳定性。其创新点在于将拓扑学引入语义对齐评估，提供了超越表面输出的深层一致性度量。代价是拓扑分析计算密集，且基准选择影响结果。该方法为评估 LLM 的语义一致性提供了新工具，支持了 LLM 内部语义结构的稳定性假设。

### 2.5 句法语义交互与结构

该路线研究句法结构与语义理解的交互作用，包括复杂句处理、构式语法理解及形式语义在 LLM 中的实现机制。2024 年 AMR 集成将抽象意义表示（AMR）图结构融入 LLM 提示，通过显式语义关系建模增强开放域对话评估，解决了基于 n-gram 指标无法捕捉深层语义一致性的问题。2025 年 Functional Localization 借鉴认知神经科学的功能定位方法，识别 LLM 中响应不同句法现象（如数、性一致）的共享单元，发现不同句法规则招募相同的模型组件，支持句法处理的模块化假设。

Center-Embedding Structure Analysis（Madhusudan et al., 2025, P4）通过中心嵌入句复杂度测试 LLM 的递归句法处理能力，揭示模型在复杂度增加时从结构分析转向语义捷径的倾向。该方法比较合理与不合理句子的性能差异，量化模型对递归结构的依赖程度，指出其在深层句法处理上的局限。其创新点在于将心理语言学经典任务应用于 LLM 评估，揭示了模型在句法递归上的脆弱性。代价是句子构建复杂，且性能差异统计敏感。该方法为评估 LLM 的句法处理能力提供了新工具，指出了模型在递归结构理解上的局限。

Syntactic Agreement Functional Localization（P31）借鉴认知神经科学的功能定位方法，识别 LLM 中响应不同句法现象（如数、性一致）的共享单元，发现不同句法规则招募相同的模型组件。该方法通过激活对比分析，量化模型单元对特定句法现象的选择性，支持句法处理的模块化假设。其创新点在于将神经科学方法引入 LLM 可解释性，揭示了句法知识的共享机制。代价是单元识别依赖特定模型，且句法现象选择有限。该方法为理解 LLM 的句法知识表示提供了新视角，支持了句法处理具有共享组件的假设。

Frame-Semantic Argument Extraction（P27）利用 LLM 进行框架语义解析，统一目标识别、框架识别和论元识别，通过输入格式优化提升性能。该方法设计框架元素表示，测试不同格式对模型性能的影响，揭示 LLM 在框架语义理解上的能力与局限。其创新点在于将框架语义学应用于 LLM 评估，揭示了模型在深层语义结构提取上的潜力。代价是框架定义依赖 FrameNet，且格式优化敏感。该方法为评估 LLM 的框架语义理解提供了新工具，支持了 LLM 在深层语义结构提取上的能力。

CFG Interpretation Diagnostic Framework（Li et al., 2026, P15）开发上下文无关语法解释诊断框架，通过动态合成语法实例测试 LLM 作为语法解释器的能力，揭示其在递归状态跟踪和层级作用域处理上的结构性失败。该方法结合三个渐进任务和多层次评估指标，解耦结构复杂度与表面表示，量化模型在语法归纳上的能力。其创新点在于将形式语言理论应用于 LLM 评估，揭示了模型在递归处理上的局限。代价是语法合成复杂，且评估指标主观。该方法为评估 LLM 的语法解释能力提供了新工具，指出了模型在递归结构理解上的局限。

AMR-Integrated Dialogue Evaluation（P26）将抽象意义表示（AMR）图结构融入 LLM 提示，通过显式语义关系建模增强开放域对话评估，解决基于 n-gram 指标无法捕捉深层语义一致性的问题。该方法利用 SLM 进行二元分类，结合 AMR 图知识提升评估准确性，揭示模型在语义关系理解上的能力。其创新点在于将形式语义表示引入对话评估，提升了评估的语义深度。代价是 AMR 构建复杂，且评估依赖特定数据集。该方法为评估 LLM 的对话质量提供了新工具，支持了形式语义在 LLM 评估中的价值。

### 2.6 语义理解评估基准

该路线构建针对特定语义维度（如意图、场景、领域知识）的评估基准，系统量化 LLM 在深层语义理解上的能力边界。2022 年 InstructEval 提出指令跟随评估框架，通过多样化指令测试模型对语义意图的响应能力，推动了从静态问答向动态交互语义理解的评估范式转变。2025 年 IntentGrasp 构建综合意图理解基准，覆盖多领域、多粒度的意图分类任务，通过随机选项顺序消除偏差，系统量化 LLM 在复杂交互场景中推断用户真实意图的能力。

Scenario Cognition Benchmark（P29）提出场景认知评估方法，测试 LLM 将场景元素（如导演、演员）与其论元（人名）准确关联的能力，区分记忆与理解。该方法通过场景元素-论元绑定任务，量化模型在复杂场景语义绑定上的认知缺口，揭示其依赖记忆而非理解的倾向。其创新点在于将场景认知形式化为评估任务，揭示了 LLM 在深层语义绑定上的局限。代价是场景构建复杂，且绑定评估主观。该方法为评估 LLM 的场景理解能力提供了新工具，指出了模型在场景认知上的局限。

IntentGrasp Benchmark（Yin et al., 2026, P17）构建综合意图理解基准，覆盖多领域、多粒度的意图分类任务，通过随机选项顺序消除偏差，系统量化 LLM 在复杂交互场景中推断用户真实意图的能力。该方法利用 20 个模型家族，计算 F1 分数并报告误差棒，验证统计显著性，揭示模型在意图理解上的差异。其创新点在于将意图理解操作化为综合基准，填补了现有数据集在 LLM 评估上的空白。代价是基准构建成本高，且意图标签主观。该方法为评估 LLM 的意图理解能力提供了新工具，支持了 LLM 在交互场景中的应用。

Prism Complex Intent Understanding Framework（Liao et al., 2026, P6）设计四模块框架降低用户认知负荷，通过分解复杂意图、组织澄清问题、模拟交互和自我进化调优，提升 LLM 对复杂意图的理解。该方法利用 CID 检索或少样本构建模式，保持前置依赖，通过蒙特卡洛采样和意图感知奖励优化澄清轨迹。其创新点在于将认知负荷理论应用于 LLM 交互，揭示了复杂意图理解的动态过程。代价是框架复杂，且调优依赖特定数据。该方法为提升 LLM 的交互能力提供了新工具，支持了 LLM 在复杂场景中的应用。

Non-Verbal Pragmatic Meaning Benchmark（Eo and Lim, 2026, P20）构建非言语语用意义评估基准，测试 LLM 仅从非言语线索（如表情、动作）推断隐含意义的能力，排除言语行为干扰。该方法通过多选问题评估模型在对话语境中解释非言语响应意图的能力，揭示其在语用推理上的局限。其创新点在于将非言语沟通引入语用评估，揭示了 LLM 在多模态语用理解上的不足。代价是非言语线索标注复杂，且评估主观。该方法为评估 LLM 的语用能力提供了新工具，指出了模型在非言语理解上的局限。

Phun-Bench Phonological Understanding Benchmark（P25）构建中文语音理解基准，评估 LLM 在音韵学任务（如押韵判断、同音字判断）上的能力，区分语音知识与语义知识。该方法通过字符-拼音测试验证语音知识，引入 Rhyming Sentence Generation 任务测试语音生成能力，揭示模型在语音理解上的局限。其创新点在于将音韵学引入 LLM 评估，揭示了模型在语音层面的理解不足。代价是语音任务构建复杂，且评估依赖中文资源。该方法为评估 LLM 的语音理解能力提供了新工具，支持了语音在语义理解中的重要性。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLMs 在表面流畅性和常见语义任务上表现优异，但在深层语义理解（如抽象概念、语用推理、复杂结构）上仍存在显著局限，未能完全达到人类水平。这一共识在多个基准上被反复验证：CEI 基准中最佳 LLM 准确率仅为 25%，远低于人类多数投票基线的 54%；IntentGrasp 基准中 17/20 个测试模型表现低于随机猜测基线（15.2%），显示当前 LLM 在复杂意图理解上的严重不足（支撑证据：P10、P17）。机制可解释性技术（如稀疏自编码器、因果干预）是揭示 LLMs 内部语义表示和计算机制的有效工具，能够定位特定的语义功能单元（如歧义神经元、语义角色电路）。AENs（P1）和 Semantic Role Circuits（P22）的发现证明语义功能在内部是稀疏且局部化的，支持了语义理解具有模块化回路假设（支撑证据：P1、P22）。

与此相关的另一个共识是，评估 LLMs 语义理解能力需要超越传统的准确率指标，采用细粒度的、针对特定语义现象（如词义消歧、隐喻、语用含义）的基准测试，以揭示其能力边界。CEI、IntentGrasp、Drivel-ology 等细粒度基准的构建填补了现有基准在深层语用理解、复杂意图理解和创造性解释上的空白，揭示了模型在细微语义差异上的脆弱性（支撑证据：P10、P17、P24）。LLMs 在处理歧义时倾向于“坍缩”为单一解释，缺乏对多重可能性的保持能力，这限制了其在需要多义性推理场景中的应用。Ambiguity Collapse Taxonomy（P9）量化了模型在复杂概念上的解释坍缩，揭示了其对用户信息空间的收缩（支撑证据：P9）。

### 3.2 观点分歧

LLM 的组合性推理是源于结构规则还是统计记忆？观点 A（结构规则）认为 LLM 通过内化的组合规则（如语义角色电路）实现组合性推理，支持构式语法在 LM 处理中的核心地位（P19、P22）。观点 B（统计记忆）认为 LLM 的组合性依赖于训练数据中的统计规律，而非严格的逻辑规则，导致在罕见组合上泛化能力不足（P11）。现有证据偏向统计记忆，因为在罕见组合和反事实场景下模型表现不佳，且组合性评估显示模型依赖表面模式。但因果干预实验（如语义角色电路）显示存在局部化回路，支持结构规则的存在。哪种实验能定输赢：在完全未见过的组合结构上进行因果干预，观察模型是否仍能正确推理。未定论原因：测量工具盲区，现有基准难以完全隔离统计记忆与结构推理的贡献，且训练数据中的统计偏差可能掩盖了结构规则的作用。

这一分歧的背后，是另一个更根本的争论：LLM 的“接地鸿沟”是根本缺陷还是可通过多模态弥补？观点 A（根本缺陷）认为 LLM 缺乏感官运动经验，其语义锚点与人类认知存在系统性偏差，接地缺失是根本局限（P18）。观点 B（可弥补）认为通过多模态训练和基于人类认知规范的微调，可以增强 LLM 的接地能力，缩小与人类的差距（P30）。现有证据偏向根本缺陷，因为 SAE 特征探测显示模型依赖抽象符号关联而非感官锚点，且在抽象概念接地任务上与人类规范对齐较弱。但多模态基准（如 CogEvolve）显示模型在视觉-语义映射上有一定潜力。哪种实验能定输赢：在完全无文本线索的多模态场景中，测试模型对抽象概念的接地能力，并与人类对比。未定论原因：证据不足，多模态 LLM 的接地能力评估尚不成熟，且缺乏统一的认知解释框架来量化“接地”的程度。

### 3.3 其他开放问题

最紧迫的工程问题是如何解决语义漂移的延迟机制和优化歧义处理策略。Deferred Semantic Drift Analysis（P23）揭示了 LLM 在动态语境中难以即时更新词义的固有局限，为优化注意力机制以支持动态语义更新提供了方向。关键困难在于高维表示的稀疏性和动态性，研究路径包括稀疏自编码器和因果干预分析。最根本的研究问题是如何定义和量化“真正的理解”，以及建立 LLM 内部机制与人类神经认知的统一映射框架。Brain-LLM Alignment Analysis（P8）验证了 LLM 内部表征与人类大脑语义处理的同构性，但缺乏统一的认知解释框架来量化“接地”的程度。关键困难在于认知过程的内部状态映射，研究路径包括认知对齐指标和迭代语言学习模拟。

归纳“已知—争议—未知”认知图谱：已知 LLMs 在深层语义理解上存在显著局限，机制可解释性技术是揭示内部机制的有效工具；争议组合性推理的来源和接地鸿沟的性质；未知如何建立统一的认知解释框架和量化“真正的理解”。发展趋势是机制可解释性与认知科学的深度融合将是构建可靠 AI 系统的关键，未来需在机制透明性与认知对齐之间寻求平衡。

## 4. 总结与展望

大语言模型语义理解研究已从表面统计关联深入至内部机制解释，但“接地鸿沟”和“组合性局限”仍是核心障碍。早期研究依赖通用基准验证模型能力，但抽象概念接地与语用推理的系统性偏差暴露了统计模式匹配的局限。随着稀疏自编码器（SAEs）等机制可解释性工具的引入，研究者得以定位歧义编码神经元与语义角色电路，将黑盒行为评估转化为白盒机制分析。各路线在机制透明度、评估深度与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。核心瓶颈在于模型表面流畅性与深层认知逻辑（如接地、组合性）之间的断裂，以及如何通过机制可解释性技术揭示 LLM 内部语义结构的计算实现，并解决抽象概念接地和组合性推理的固有局限。

未来可能突破的方向包括：提升 LLM 在语用推理和隐含意义理解上的能力，解决当前模型在间接言语、讽刺和社交语境中表现远低于人类的问题，难点在于语用知识的社会文化依赖性和模糊性，潜在路径包括构建更丰富的语用基准和引入社会认知模型（P10、P24）。增强 LLM 对抽象概念和接地能力的对齐，解决模型在抽象概念属性生成上与人类系统性偏差的问题，难点在于抽象概念缺乏感官运动锚点，潜在路径包括多模态训练和基于人类认知规范的微调（P18、P30）。深化对 LLM 内部语义表示机制的可解释性研究，解决模型如何编码和更新语义信息（如延迟语义漂移、歧义神经元）的黑箱问题，难点在于高维表示的稀疏性和动态性，潜在路径包括稀疏自编码器和因果干预分析（P1、P22、P23）。对进入者最值得做的一件事是建立统一的认知解释框架，量化 LLM 内部机制与人类神经认知的对应关系，以构建更可靠、可解释且符合人类认知逻辑的 AI 系统。
