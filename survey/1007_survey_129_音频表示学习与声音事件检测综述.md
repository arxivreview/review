综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Audio%20Representation%20Learning%20and%20Sound%20Event%20Detection)

## 导读

音频表示学习与声音事件检测（Sound Event Detection, SED）旨在从海量无标注音频中提取通用声学语义，其核心价值在于突破强标签获取成本高企与复杂声学场景泛化需求之间的张力。早期研究依赖监督预训练或简单对比学习，思路直接却受制于数据标注瓶颈与跨域泛化能力不足。当自监督学习（Self-Supervised Learning, SSL）引入掩码预测与离散令牌机制后，基于频谱图的 Transformer 架构确立了主导地位，但相位丢失与计算延迟问题逐渐暴露。为应对实时部署与开放世界场景，研究者转向原始波形建模与多模态对齐，用更强的语义先验换取动态环境适应性。各路线在表示粒度、时间精度与计算成本之间做出了不同取舍，由此形成当前从封闭分类向通用理解演进的多元格局。本综述梳理这条从频谱重建到开放世界检测的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

音频表示学习的兴起源于对大规模无标注数据利用的迫切需求，旨在突破传统监督学习对昂贵人工强标签的依赖。早期工作如 PANNs 依赖监督预训练，虽能捕捉基础声学特征，但难以应对真实场景中复杂的语义结构与长尾分布。核心问题可形式化为：给定无标签音频序列 $X$，学习映射函数 $f_\theta$ 使得表示 $Z = f_\theta(X)$ 在下游任务（如分类、检测）中具备强泛化能力。这一过程需同时解决时间边界感知、跨域一致性及开放世界适应性三个子问题，其中表示学习的质量直接制约下游 SED 的上限，数据基准则决定了评估的可靠性。

问题定义经历了从理想化平衡数据分类向真实场景复杂约束的深刻转变。2020 年前后，研究聚焦于“如何从噪声中重建语义”，假设频谱图足以捕捉声学信息，主要矛盾是标注稀缺。随着基准多样化，长尾分布与域不平衡成为新挑战，模型对低频域不熟悉导致性能骤降。随后，封闭世界假设的局限暴露无遗，传统 SED 无法处理动态环境中的未知事件，问题演变为“如何在缺乏强标签约束下构建具备时间边界感知与开放适应性的表示空间”。这一演化使得单一精度指标不再适用，需综合考量鲁棒性、可解释性及部署效率。

约束条件的变化驱动了方法范式的连续迭代。2016-2018 年，度量学习奠基了嵌入空间比较思路，但受限于表示质量。2020-2022 年，wav2vec 2.0 与 HuBERT 将语音 SSL 迁移至通用音频，AudioMAE 确立频谱图 Transformer 主流地位，解决了连续重建的语义抽象问题。2023-2024 年，BEATs 引入离散令牌，CLAP 实现音频-文本对齐，解决了跨域割裂与零样本检测需求。2025-2026 年，WavJEPA 转向波形建模以解决相位丢失，OW-SED 与 FlexSED 突破封闭世界假设，NAPE 与 CAT 探索高效架构以应对计算瓶颈。每次迭代都是对前序假设的修正：从“频谱图足够”到“离散化更优”，再到“波形更保真”与“开放世界更实用”。

当前领域形态呈现多元并存与深度融合的特征。自监督预训练架构多样化（MAE、对比、离散令牌、波形预测），SED 算法精细化（边界感知、半监督、开放词汇），表征应用拓展至生物声学、空间音频等垂直领域。范式边界清晰：频谱图表示高效但丢失相位，波形表示保真但计算昂贵；封闭集检测稳定但僵化，开放世界灵活但缺乏统一框架。这些张力构成了当前研究的核心驱动力，促使方法在计算效率、语义丰富度与时间精度之间持续权衡。

**如果用一个核心问题概括该领域，那便是：如何在缺乏大规模强标签约束的情况下，构建具备时间边界感知能力、跨域泛化性及开放世界适应性的通用音频表示空间。**

## 2. 方法体系

- 2020：wav2vec 2.0——提出基于对比预测与离散单元掩码预测的自监督学习框架，确立掩码预测核心地位

- 2021：HuBERT——引入离线聚类生成伪标签，结合掩码预测目标学习鲁棒语音表征

- 2022：AudioMAE——将视觉 MAE 范式迁移至音频频谱图，证明生成式掩码重建有效性

- 2023：BEATs——采用基于蒸馏的离散声学令牌预测目标，提升表征语义丰富度

- 2025：WavJEPA——基于原始波形利用 JEPA 范式预测潜在表示，避免 STFT 延迟与相位丢失

- 2025：FlexSED——提出开放词汇 SED 框架，利用 CLAP 文本编码器处理提示词

- 2026：Boundary-Aware SED——引入 RED 层将事件起止概率转化为 onset/offset 概率，提升边界精度

- 2026：NAPE——提出下一补丁嵌入预测框架，简化预训练目标实现可扩展音频学习者

这条时间线勾勒了该领域方法演进的代表性节点：从 2020 年的 wav2vec 2.0 奠定该领域方法基线，经 2021 年 HuBERT 的推进，到 2026 年的 TSD Unified 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 自监督预训练架构

自监督预训练架构的演进始于对连续重建目标的反思。AudioMAE（Chen et al., 2022）将视觉掩码自编码器迁移至音频频谱图，通过重建被掩码的频谱块学习通用表征，证明了生成式目标在音频领域的有效性。然而，连续重建在语义密集任务上表现不如预期，难以捕捉高层语义抽象。BEATs（Chen et al., 2023）针对这一问题，引入基于蒸馏的离散声学令牌预测目标，结合在线更新的声学分词器，使模型能像处理语言一样处理音频，显著提升了语义丰富度。这一转变放弃了连续值的细粒度声学细节，换取了更强的语义判别性与跨任务迁移能力。

随着预训练目标多样化，研究者开始探索更简洁高效的替代方案。NAPE（Cappellazzo et al., 2026）提出下一补丁嵌入预测框架，仅依赖因果掩码和停止梯度，无需复杂的对比或重建损失，简化了预训练目标并降低了计算开销。CAT（Han et al., 2026）则采用双分支 Bootstrap 架构，通过多分辨率块处理不同尺度的频谱特征，结合正则化约束提升表征的判别性与鲁棒性。AudioMosaic（Huang et al., 2026）结合掩码建模与对比损失，引入有效秩作为表征质量评估指标，平衡生成式重建与判别式对比，增强了模型对音频事件结构的捕捉能力。这些方法在保持频谱图输入优势的同时，通过目标函数与架构设计的创新，提升了表示的内在维度与多样性。

输入表示的变革是另一关键转折。WavJEPA（Yuksel et al., 2025）基于原始波形而非频谱图，利用 JEPA 范式预测潜在表示，避免了 STFT 引入的延迟与相位丢失，提升了实时部署能力与生成任务性能。该方法解决了频谱图方法在实时性上的瓶颈，但代价是计算复杂度显著增加，模型规模更大。SONAR（Zhang et al., 2025）则聚焦于持续预训练中的灾难性遗忘问题，集成任务相关分层采样、双源自蒸馏正则化及在线聚类码本，实现了模型对新声学域的动态适应。SPEAR（Yang et al., 2025）构建统一语音与音频表征的 SSL 框架，通过多码本向量量化蒸馏互补知识，解决了语音与音频事件领域表征割裂的问题。这些方法在计算效率、语义丰富度与时间精度之间做出了不同取舍，形成了当前自监督预训练架构的多元格局。

### 2.2 声音事件检测算法

声音事件检测算法的演进核心在于突破封闭世界假设与提升时间边界精度。传统 SED 依赖固定类别集，无法处理动态环境中的未知事件。FlexSED（Hai et al., 2025）提出开放词汇 SED 框架，利用 CLAP 文本编码器处理任意文本提示词，无需重新训练即可检测训练集之外的声音事件。该方法放弃了固定类别的稳定性，换取了零样本检测的灵活性，拓展了 SED 的应用边界。OW-SED（Hai et al., 2026）进一步提出开放世界 SED 范式，支持检测未知事件并增量学习，打破了封闭世界假设，使系统能在动态环境中识别新类别并更新知识库。

时间边界定位精度是 SED 的另一关键挑战。传统方法依赖后处理（如非极大值抑制）导致边界模糊，尤其在多声源重叠场景下性能下降。Boundary-Aware SED（Schmid et al., 2026）引入 RED 层，将条件事件起止概率转化为 onset、offset 及事件存在概率，结合事件提议网络直接优化边界检测目标。该方法避免了后处理转换带来的误差，显著提升了事件序列、持续时间及重叠的恢复精度。Semi-Supervised SED（Shao et al., 2026）则结合条件 Mixup 与嵌入级对比损失，利用弱标签、强标签及无标签数据，通过伪标签基于的两阶段微调基线进行优化，缓解了标签稀缺问题。这些方法在时间精度、数据利用效率与模型复杂度之间进行了权衡，推动了 SED 从封闭集向开放世界、从后处理向端到端的范式转变。

### 2.3 表征应用与下游任务

表征应用与下游任务的研究聚焦于将通用音频表示迁移至特定垂直领域，解决数据稀缺与跨模态对齐问题。TSD Unified（Gupta et al., 2026）提出参考引导的目标声音检测统一架构，共享 ConvNeXt 编码器处理混合与参考音频，通过交叉注意力融合参考与混合特征，实现了高精度的目标事件检索与定位。该方法在 URBAN-SED 数据集上显著优于现有 TSDNet 等基线模型，为监控、多媒体检索等应用提供了实用方案。AVEX（ICLR 2026）系统评估动物鸣叫编码中的关键因素，对比自监督与监督学习在通用音频与生物声学数据上的表现，揭示了数据规模与标签类型对生物声学表征泛化能力的影响，推动了生物声学领域从单一数据源向多源混合表征学习的转变。

跨模态对齐与轻量化是另一重要方向。ContrastASC（Yuan et al., 2025）通过对比微调与蒸馏实现轻量级且可泛化的声学场景表征，解决边缘设备上声学场景分类的固定类别集限制。Audio-to-Image Bird Retrieval（Moummad et al., 2026）利用文本蒸馏实现跨模态对齐，无需音频-图像配对即可实现鸟类物种检索，降低了数据获取成本。Consistency Regularization AER（Sadhu and Wang, 2025）利用一致性正则化改进音频事件识别，鼓励模型对不同增强视图的预测保持一致，提升了噪声环境下的鲁棒性。这些方法在计算效率、跨模态语义对齐与任务特定性能之间做出了不同取舍，丰富了音频表示学习的应用场景。

### 2.4 表征分析与可解释性

表征分析与可解释性研究旨在揭示自监督音频模型内部表征的编码机制，弥补仅依赖下游任务性能评估的不足。Neuron-level Dissection（Kawamura et al., 2026）从神经元层面解剖通用音频模型，通过可视化神经元激活，分析声学信息如何在模型内部被编码与处理，揭示了模型泛化能力的内在机制与潜在偏差。Data Quality Audits（Gonzalez-Jimenez et al., 2025）提出基于表征的音频数据质量审计方法，利用学习嵌入进行异常检测，识别离题样本、近重复及标签错误，为大规模音频数据集的清洗与维护提供了自动化手段。

WQ-Fusion（Lin et al., 2026）提出动态门控注意力机制用于跨域音频表征融合，利用门控注意力机制动态路由并自适应地优先化不同声学上下文中的相关特征，克服了静态融合结构难以适应波动声学环境的局限性。Audio Transformation Representation（Lee et al., 2026）探索音频变换的表征学习设计空间，区分盲与非盲预训练设置，研究处理本身与处理后音频的表征，拓展了音频表征学习的维度，从内容导向转向过程导向。这些方法在可解释性、数据质量控制与跨域融合之间提供了新的研究视角，有助于优化模型架构与训练策略，提升模型在高风险场景中的信任度。

### 2.5 数据基准与评估体系

数据基准与评估体系的研究聚焦于解决标注稀缺、数据质量及特定场景下的评估难题。CASTELLA（Munakata et al., 2025）构建包含长音频、文本描述及时间边界的数据集，填补了长音频时刻检索（AMR）领域的空白，支持对音频事件细粒度时间定位能力的评估。FSD50K-Solo（Yang et al., 2026）提出自动化策划单源声音事件数据集，利用生成式音频模型清洗多源干扰，解决了 FSD50K 中背景噪声与事件重叠问题，为高精度音频任务提供了高质量训练数据。

Region-Specific Audio Tagging（Zhao et al., 2025）提出区域特定音频标签任务及基准，关注特定空间区域的声音事件，适用于监控等应用，填补了空间音频标签领域的空白。Bioacoustics MAE Case Study（Liu et al., 2026）通过细粒度生物声学案例研究，评估掩码自编码器在有限数据下的有效性，验证了混合通用与生物声学数据预训练能显著提升细粒度物种识别性能。这些基准在数据规模、标签类型、任务复杂度与评估协议上进行了不同设计，为音频表示学习提供了多样化的评估维度，推动了领域从封闭集分类向通用音频理解的范式转变。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

自监督学习已成为音频表示学习的主导范式，显著优于传统监督预训练在下游任务上的泛化能力。这一共识在多个基准上被反复验证：CAT 的 48.6 mAP 与 BEATs 的 48.6 mAP 均大幅超越 PANN 的 43.1 mAP，Semi-Supervised SED 的 0.645 PSDS1 与 ATST-SED 的 0.645 PSDS1 持平但优于纯监督基线（支撑证据：P13、P23）。然而，该共识的边界在于合成预训练数据（如 AudioPG）在部分任务上性能低于真实数据预训练模型（如 ESC-50 上 90.60 vs 98.1），表明数据质量与域差距仍是关键制约因素。

与此相关的另一个共识是，基于频谱图的 Transformer 架构仍是当前主流骨干网络，尽管波形建模兴起，但频谱图在大规模分类任务上仍占主导地位。CAT 与 AudioMosaic 均基于频谱图输入，在 AudioSet 上取得 SOTA 性能，而 WavJEPA 虽在实时性与生成任务上展现优势，但在通用分类上的 SOTA 尚未确立（支撑证据：P13、P20、P6）。这一共识的边界在于计算效率与相位丢失的矛盾，频谱图方法在低延迟实时应用和音频生成任务中表现受限，波形模型参数量大，难以在边缘设备部署。

### 3.2 观点分歧

离散令牌与连续重建哪种自监督目标更优，是领域内的核心分歧。离散令牌路线（BEATs、HuBERT）主张能捕捉高层语义，适合分类与识别任务，证据显示 BEATs 在 AudioSet 上取得 48.6 mAP，与 CAT 持平，优于 AudioMAE 的 47.3 mAP。连续重建路线（AudioMAE、WavJEPA）主张保留细粒度声学信息，适合生成与重建任务，证据显示 WavJEPA 在实时性与生成任务上展现优势，但在通用分类上尚未超越频谱图基模型。现有证据偏向离散令牌在语义密集任务上略优，但连续重建在生成任务上更优，分歧根源在于任务依赖性：不同下游任务对表示的粒度要求不同，缺乏能同时评估语义与声学细节的统一指标（支撑证据：P24、P6、P11）。

频谱图与原始波形输入表示的终极选择，是另一根本性争论。频谱图路线主张计算高效、生态成熟，证据显示 CAT 与 AudioMosaic 在大规模分类任务上仍占主导。波形路线主张保留相位、支持实时与生成，证据显示 WavJEPA 在实时性与生成任务上展现优势，但计算复杂度显著增加，模型规模更大。现有证据显示波形模型在通用分类上的 SOTA 尚未确立，分歧根源在于计算资源限制：波形模型参数量大，难以在边缘设备部署，且缺乏大规模波形预训练数据集（支撑证据：P6、P13、P20）。

### 3.3 其他开放问题

开放世界 SED 的实现路径缺乏统一评估协议，是最紧迫的工程问题。FlexSED 的零样本检测在现有基准上表现稳定，但 OW-SED 的增量学习框架缺乏包含未知类别动态变化的长期监控数据集，且灾难性遗忘问题尚未完全解决。研究路径包括引入大语言模型进行标签生成、利用对比学习增强嵌入空间的可分性以及开发自适应时间定位架构，但需构建统一的增量学习评估基准以验证长期稳定性。

细粒度时间定位与边界感知是更根本的研究问题。Boundary-Aware SED 的 RED 层虽提升了边界精度，但事件起止点往往伴随渐变且受多声源重叠影响，现有方法多依赖后处理，缺乏端到端的边界感知优化机制。研究路径包括设计边界感知优化策略、解耦起始和结束概率预测，以及利用事件提议网络直接生成精确的事件区域，但需解决多声源重叠场景下的边界模糊问题。

已知—争议—未知认知图谱显示：SSL 优于监督预训练、频谱图 Transformer 为主流是已知共识；离散令牌 vs 连续重建、频谱图 vs 波形是争议焦点；开放世界增量学习、可解释性、轻量化部署是未知领域。未来趋势将向实时、动态、可解释方向迈进，需依赖跨模态对齐与高效架构设计的协同。

## 4. 总结与展望

音频表示学习与声音事件检测领域的核心矛盾从“标注稀缺”演变为“表示泛化与计算效率的平衡”，尝试过的路线包括连续重建、离散令牌、波形建模、开放世界检测等，核心瓶颈在于缺乏能同时评估语义与声学细节的统一指标，以及开放世界增量学习的长期稳定性未验证。这一瓶颈回扣了第 1 章的核心问题：如何在缺乏大规模强标签约束的情况下，构建具备时间边界感知能力、跨域泛化性及开放世界适应性的通用音频表示空间。

未来可能突破的方向包括：开放世界与零样本声音事件检测，需引入大语言模型进行标签生成与自适应时间定位架构（P5、P17）；高效与轻量化音频表示学习，需采用因果预测目标与结构化状态空间模型替代自注意力机制（P25、P13）；跨模态对齐与多模态音频理解，需利用文本作为语义中介进行蒸馏与动态门控注意力机制（P9、P22）。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，构建开放世界 SED 的增量学习评估基准，以验证不同路线在动态环境中的长期稳定性。
