# A Survey of Synthetic Tabular Data Generation Methods ｜合成表格数据生成方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Synthetic%20Tabular%20Data%20Generation)

## 导读

合成表格数据生成（Synthetic Tabular Data Generation, STDG）旨在通过模拟数据分布实现隐私保护与数据增强，其核心价值在于缓解数据合规限制与模型训练需求之间的张力。早期研究以生成对抗网络（GAN）和变分自编码器（VAE）为主线，通过条件生成机制处理混合类型特征，思路直观却受制于训练不稳定性与高基数分类变量的编码瓶颈。当扩散模型（Diffusion Models）在 2023 年暴露出对高阶依赖关系的优越建模能力后，研究者迅速将其确立为新的 SOTA 基准，用更复杂的去噪过程换取分布保真度的显著提升。随着流匹配（Flow Matching）与大语言模型（LLM）的引入，领域重心从单纯的统计相似性转向效用-隐私-因果的多维权衡，各路线在计算效率、语义理解与数值精度之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从分布模仿到结构保真的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

合成表格数据生成的兴起源于隐私保护法规（如 GDPR）对敏感数据共享的限制，以及数据稀缺、标注成本高企对机器学习模型训练的制约。其核心目标是通过生成模型产生统计特性与真实数据相似、但不包含真实个体记录的结构化数据，用于隐私保护共享、数据增强及模型训练。这一领域的初始问题定义相对理想化：假设数据特征间依赖较弱，且可通过 One-hot 编码统一处理数值与分类特征，主要关注边缘分布与成对相关性的匹配。然而，真实世界中的表格数据往往包含高基数分类变量、稀疏特征及复杂的非线性交互关系，早期方法在这些场景下迅速暴露出局限性。

问题的形式化通常遵循 N-way K-shot 的变体逻辑，即给定真实数据集 $D_{real} = \{x_i\}_{i=1}^N$，学习一个生成模型 $G_\theta$，使得生成的合成数据集 $D_{syn} = \{G_\theta(z)\}_{z \sim p(z)}$ 在统计分布、下游任务效用及隐私安全性上尽可能接近 $D_{real}$。这一形式化背后隐藏着三个层层递进的子问题：首先是混合类型数据的统一建模，这是基础，若不解决高基数分类变量的表示问题，高阶依赖捕捉无法稳定训练；其次是高阶依赖关系的精确重构，这是核心，决定了合成数据在复杂任务中的实用性；最后是因果结构保持与隐私保护，这是上层约束，若基础分布失真或隐私泄露，合成数据在因果推断与合规场景中将彻底失效。

2016 至 2019 年是领域的奠基期，CTGAN 和 TVAE 等早期深度生成模型确立了混合类型处理的基本范式，但受限于 GAN 的训练不稳定性，其生成质量难以满足高维复杂数据的建模需求。2020 至 2022 年，随着 DDPM 等扩散模型在图像领域的成功，研究者开始探索其在表格数据上的应用，问题定义从“边缘统计保真”转向“高阶依赖捕捉”。这一时期的关键转折在于认识到 One-hot 编码在高基数特征上的维度灾难，促使研究重心转向潜空间映射或专用离散扩散核。

2023 至 2024 年，TabDDPM 和 TabSyn 等工作证明了扩散模型在处理混合类型数据上的优越性，显著提升了生成保真度，确立了新的 SOTA 基准。然而，扩散模型的引入也带来了新的约束：采样速度慢、训练不稳定，且易受成员推断攻击（MIA）。2025 至 2026 年，研究重心发生范式转移：一方面，Flow Matching 作为一种无模拟训练的高效生成框架被引入，与扩散模型形成竞争；另一方面，大语言模型（LLM）和表格基础模型（TFMs）如 TabPFN 开始主导该领域，利用预训练知识实现少样本甚至零样本生成。当前，问题已演变为在隐私预算限制下保持因果结构一致性的复杂优化问题，核心矛盾聚焦于效用-隐私权衡（Utility-Privacy Tradeoff）及合成-真实差距（Synthetic-Real Gap）的弥合。

**如果用一个核心问题概括该领域，那便是：如何在保证形式化隐私边界与因果结构一致性的前提下，最小化合成数据与真实数据在下游任务效用上的差距（Synthetic-Real Gap）。**

## 2. 方法体系

- 2019：CTGAN——通过引入模式特定归一化处理混合类型数据，奠定该领域方法基线

- 2020：DDPM——提出去噪扩散概率模型，确立基于噪声预测的生成范式

- 2023：TabDDPM——首次将扩散模型系统化应用于表格数据，确立混合类型生成标准基线

- 2024：TabSyn——引入变分自编码器将混合类型数据映射到连续潜空间，缓解训练不稳定

- 2025：TabDiff——提出统一混合类型扩散模型，采用特征级可学习噪声调度

- 2025：TabPFN——提出先验数据拟合网络，实现小样本表格任务的上下文学习

- 2026：TabbyFlow——基于指数族变分流匹配，提升高维低样本场景下的分布覆盖能力

- 2026：TAGAL——提出基于智能体 LLM 的表格生成框架，处理复杂业务逻辑约束

这条时间线勾勒了该领域方法演进的代表性节点：从 2019 年的 CTGAN 奠定该领域方法基线，经 2020 年 DDPM 的推进，到 2026 年的 TabbyFlow 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 扩散与流匹配生成

扩散与流匹配生成是当前 STDG 的主流骨干路线，其演进逻辑始于对 GAN 训练不稳定性的反思。CTGAN（arxiv_2602.21948）虽解决了早期 GAN 难以处理离散与连续特征混合的问题，但其对抗训练机制在高维数据上易导致模式崩溃。DDPM（arxiv_2602.06390）通过定义前向加噪马尔可夫链和反向去噪神经网络，确立了基于噪声预测的生成范式，为后续表格数据扩散模型奠定了理论基础。TabDDPM（arxiv_2605.06261）首次将扩散模型系统化应用于表格数据，结合高斯扩散处理连续列和多项式扩散处理分类列，确立了混合类型表格生成的标准基线。然而，直接在数据空间执行扩散会导致高维离散噪声，训练困难，TabSyn（arxiv_2606.02607）因此引入变分自编码器（VAE）将混合类型数据映射到连续潜空间，在潜空间执行扩散过程，有效缓解了训练不稳定问题，其代价是增加了预处理复杂度，且潜空间可能丢失部分离散特征信息。

随着对高阶依赖捕捉需求的提升，TabDiff（arxiv_2602.04785）提出统一混合类型扩散模型，采用特征级可学习噪声调度和 Transformer 去噪器，在连续时间框架下同时处理数值和分类列，提升了复杂依赖关系的建模能力。然而，扩散模型采样慢，不适合实时隐私数据发布场景，TabbyFlow（Nasution et al., 2025, P8）因此转向流匹配框架，基于指数族变分流匹配（EF-VFM）优化速度场学习连续时间变换，在保持计算效率的同时提升了高维低样本场景下的分布覆盖能力。这一路线的取舍在于：放弃 GAN 的对抗训练稳定性，换取对复杂高阶依赖的精确建模；代价是采样慢且易受 MIA 攻击。与 LLM 路线相比，扩散/流匹配在数值保真度上具有显著优势，但在语义约束理解上存在不足。

### 2.2 大模型驱动生成

大模型驱动生成代表了从“数据驱动”向“知识驱动”的范式转移，其起源可追溯至 GReaT（arxiv_2603.02015）利用 LLM 上下文学习能力进行表格数据生成的尝试。GReaT 通过提示工程引导 LLM 模仿数据分布，开创了无需训练即可利用预训练知识进行合成的新范式，但其在数值保真度上表现不佳。TabPFN（Jiang et al., 2026, P23）提出先验数据拟合网络，通过在大量合成数据集上预训练 Transformer，实现了小样本表格任务的上下文学习，无需针对特定数据集微调即可达到 SOTA 性能。TabFORGE（arxiv_2605.09424）进一步利用预训练 PFN 模型的早期到中期层构建因果感知嵌入空间，将混合类型特征标记化并映射到共享连续潜空间，利用 PFN 在预训练阶段捕获的因果结构信息，实现跨数据集的可迁移生成。

TAGAL（Ronval et al., 2025, P1）提出基于智能体 LLM 的表格数据生成方法，利用大语言模型的上下文学习和模式检测能力，通过精心设计的系统提示和少样本示例引导生成。该方法将生成任务分解为多个推理步骤，LLM 作为智能体自主决定生成策略，无需针对特定数据集进行微调。其核心创新在于利用 LLM 的语义理解能力处理复杂的业务逻辑和特征间依赖，弥补了传统统计模型在语义层面的不足。Team, Then Trim (T2)（Zhang et al., 2026, P10）则提出基于 LLM 团队工作的组装线框架，通过多个 LLM 实例协作生成高质量表格数据，利用任务管理器协调多个工作 LLM，通过多样性增强和质量筛选机制优化输出。这一路线的取舍在于：放弃端到端的可微分优化，换取少样本能力与语义约束理解；代价是数值保真度不足及计算成本高。与扩散路线相比，LLM 路线在少样本和约束感知场景下具有优势，但在数值分布保真度上显著落后。

### 2.3 隐私保护与攻击

隐私保护与攻击路线聚焦于差分隐私（DP）保证下的数据合成，以及针对合成数据的成员推断、重构攻击等隐私泄露风险评估与防御机制。PATE-GAN（arxiv_2605.26802）提出基于隐私增强学习（PATE）的 GAN 框架，通过教师-学生机制限制生成器对单个训练样本的依赖，提供了差分隐私保证下的数据合成方案。PATE-TabTransGAN（Youssef and Woźniak, 2026, P25）将 Transformer 架构引入 PATE-GAN 框架，提升了判别器对复杂表格依赖关系的建模能力，其代价是训练多个教师模型增加了计算开销。Tab-PE（Tran et al., 2026, P27）提出基于 API 的差分隐私合成数据生成框架，通过随机 API 生成初始样本，变异 API 探索样本空间，以及差分隐私神经网络直方图函数进行私有评分，将隐私预算分配与样本选择过程解耦。

MargNet（Chen et al., 2025, P6）提出基于边际特征的神经网络差分隐私合成方法，通过自适应选择策略确定用于训练神经网络的关键边际统计量，解决了现有特征差分隐私方法中特征选择不优和隐私预算利用不充分的问题。MIDST Challenge（Shafieinejad et al., 2026, P18）发起针对扩散模型合成表格数据的成员推断攻击基准，系统评估了白盒和黑盒攻击场景下的隐私泄露风险，推动了隐私评估从理论到实证标准化的进程。MT-MIA（Ward et al., 2026, P12）提出针对多表合成数据设置的成员推断攻击方法，利用图结构学习捕捉表间关系中的成员信息，揭示了多表合成数据中潜在的隐私泄露风险。这一路线的取舍在于：通过引入噪声或教师-学生机制换取形式化隐私保证；代价是数据效用下降及计算开销增加。与生成骨干路线相比，隐私保护模块通常作为后处理或训练约束嵌入，而非独立生成范式。

### 2.4 评估基准与指标

评估基准与指标路线旨在解决传统评估指标与下游任务效用脱节的问题。C2ST（arxiv_2603.23016）提出基于分类器的两样本测试，通过训练二分类器区分真实与合成数据来评估生成质量，成为衡量表格数据不可区分性的核心指标，但后续研究发现其对分类器选择敏感。TabPC（Scassola et al., 2026, P19）提出基于概率电路的表格数据生成与评估方法，通过精确计算似然函数来评估生成质量，避免了传统分类器两样本测试（C2ST）对分类器选择的敏感性。TabQueryBench（Zhang et al., 2026, P31）提出查询中心评估基准，通过执行领域相关的 SQL 查询并比较聚合结果，评估合成数据在下游分析任务中的实用性，揭示了距离指标与查询保真度的不一致性。

TabStruct（Jiang et al., 2025, P2）提出结构保真度评估框架，利用结构因果模型（SCM）和互信息分析生成数据与真实数据在因果结构上的一致性，弥补了传统统计指标忽略因果关系的缺陷。Dependency Gap Measurement（Zhang, 2026, P33）提出诊断表格生成模型列间保真度的方法，通过比较真实数据和合成数据中的列间依赖结构，量化生成模型在捕捉复杂交互关系上的差距。Time-Aware Evaluation（Kwon et al., 2026, P32）提出针对序列表格数据的时间感知评估框架，评估生成模型在时间戳记录和实体分组结构上的保真度。这一路线的取舍在于：通过引入更复杂的评估机制换取对高阶依赖和因果结构的捕捉；代价是评估过程计算成本较高且需要领域专家参与。与生成路线相比，评估基准是生成模型改进的反馈机制，而非直接生成范式。

### 2.5 公平性与因果约束

公平性与因果约束路线关注合成数据中的公平性偏差消除、因果结构保持及特定领域约束的强制执行与验证。Causal-GAN（Nguyen et al., 2025, P4）将因果图结构嵌入 GAN 生成过程，通过约束生成器遵循预定义的因果依赖关系，确保合成数据在干预场景下的因果效应估计无偏。CausalWrap（Asiaee et al., 2026, P16）提出模型无关的因果约束包装器，通过惩罚方法将因果约束集成到任意生成器中，无需重新训练即可强制合成数据满足特定的因果不变性。TABFAIRGDT（Panagiotou et al., 2025, P3）提出基于自回归决策树的快速公平表格数据生成器，通过自回归方式生成特征，并在生成过程中嵌入公平性约束，结合了决策树的计算效率和公平性约束的精确控制。

FairDiffuseVQVAE（Nagesh et al., 2026, P34）提出基于向量量化变分自编码器的采样时公平性表格扩散方法，通过条件精炼向量量化潜变量来实现公平性控制，将公平性约束集成到采样阶段，而非训练阶段。Generative Synthetic Data for Causal Inference（Xu, 2026, P21）提出用于因果推断的合成数据生成方法，通过分离协变量生成器和结果模型，确保合成数据在平均处理效应估计上的无偏性。Bayesian Nonparametric Framework（conf_ICLR_2026_71653623）提出贝叶斯非参数框架，同时确保合成表格数据的隐私、公平和类别平衡，将公平性、隐私和平衡性作为联合优化目标。这一路线的取舍在于：通过引入因果或公平性约束换取合成数据在特定下游任务中的有效性；代价是训练/后处理复杂度增加，可能降低数据效用。与生成骨干路线相比，因果/公平性模块通常作为后处理或训练约束嵌入，而非独立生成范式。

### 2.6 特定场景应用

特定场景应用路线面向医疗、金融、网络安全、交通等垂直领域的定制化合成方案，解决数据稀缺、类别不平衡及跨域特征扩展等具体问题。DISCO-TAB（Ilaty et al., 2026, P20）提出针对复杂临床数据的分层强化学习隐私保护合成框架，结合微调 LLM 和多目标判别器系统，在令牌、句子、特征和行四个粒度上评估合成质量。Cross-Domain Feature Expansion（Zhou et al., 2026, P30）提出基于知识图谱注入的跨域表格医疗数据特征扩展方法，利用生物医学知识图谱推断未收集的特征，弥补了表格数据中特征缺失的问题。MalDataGen（Paim et al., 2025, P5）提出针对恶意软件检测的模块化合成表格数据生成框架，包含生成模型引擎和评估资源两个核心组件，提供了端到端的合成数据生成和评估流水线。

MK-TGAN（Panaccione et al., 2026, P36）提出基于知识引导的生成对抗网络，用于合成转录组数据，利用生物医学知识图谱指导基因表达值的生成，将生物知识嵌入生成器架构。Latent-Space Flow-Based Diffusion（Ihsan et al., 2025, P7）提出基于潜空间流扩散的数据增强方法，用于解决表格数据中的类别不平衡问题，在潜空间中执行扩散过程，生成少数类样本以平衡数据集。这一路线的取舍在于：通过引入领域知识或特定约束换取合成数据在垂直领域中的可用性；代价是方法通用性降低，且领域知识图谱的构建和维护成本高。与通用生成路线相比，特定场景应用是生成模型在垂直领域的适配与扩展，而非独立生成范式。

### 2.7 轻量级与替代架构

轻量级与替代架构路线探索基于概率电路、核密度估计、树模型及量子计算的非深度学习或混合架构，旨在降低计算成本并提升可解释性。TabKDE（Alishahi et al., 2026, P24）提出基于核密度估计和 Copula 变换的轻量级表格数据生成方法，避免深度学习的计算开销，通过经典统计工具实现可扩展的表格合成，适用于资源受限场景。QTabGAN（Kumari et al., 2026, P13）提出混合量子-经典生成对抗网络，利用量子电路学习复杂数据分布，并通过经典神经网络映射到表格特征，探索了量子优势在生成模型中的潜在应用。XGenBoost（Achterberg et al., 2026, P17）提出基于 XGBoost 作为分数估计器的扩散模型，用于小规模表格数据合成，利用梯度提升树强大的非线性拟合能力，替代传统神经网络作为扩散过程中的分数函数。

FUSE（Cha et al., 2026, P35）提出特征级统一特化与列间交换的混合类型表格流匹配方法，通过特征级特化模块处理不同数据类型的分布特性，并利用列间交换机制捕捉特征间的依赖关系。Autoregressive Synthesis of Sparse and Semi-Structured Mixed-Type Data（Rückstieß and Vujanic, 2026, P15）提出针对稀疏和半结构化混合类型数据的自回归合成方法，通过自回归模型逐列生成数据，处理高基数分类特征和缺失值。这一路线的取舍在于：放弃深度学习的表达能力，换取计算效率与可解释性；适用于资源受限或高维稀疏场景。与扩散/LLM 路线相比，轻量级路线在计算效率和可解释性上具有优势，但在复杂依赖关系的建模能力上存在不足。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

扩散模型和流匹配模型在处理混合类型表格数据时，通常优于早期的 GAN 和 VAE 方法，成为当前 SOTA 基准。这一共识在多个基准上被反复验证：TabbyFlow 的 0.8354 与 TabCascade 的 0.8354 均大幅超越 CTGAN 的 0.7827 和 TVAE 的 0.8314（支撑证据：P8, P9, P22）。然而，这一共识的边界在于高基数分类变量场景，TabSyn 在 Default 数据集上仍保持微弱优势（0.6855 vs 0.6845），暗示潜空间映射在高维离散特征上可能仍具有不可替代性。与此相关的另一个共识是隐私保护与数据效用之间存在显著的权衡关系，提高隐私预算（降低 ε）通常会降低下游任务性能。Tab-PE 的 0.75 与 PATE-TabTransGAN 的 0.70 之间的差距，以及 MIDST Challenge 揭示的不同生成模型对 MIA 的脆弱性差异，均支持这一观点（支撑证据：P27, P25, P18）。

### 3.2 观点分歧

LLM 生成的数值保真度是否足以替代专用生成模型？观点 A 认为 LLM（如 GReaT, TAGAL）利用语义理解能力，在少样本和约束感知场景下优于专用模型；观点 B 认为专用模型（如 TabbyFlow, TabDiff）在数值分布保真度和计算效率上显著优于 LLM。现有证据偏向观点 B：在 Adult/Default 等标准集上，TabbyFlow/TabDiff 的 AUROC/RMSE 显著高于 GReaT（0.5985）。但 LLM 在语义约束（如业务逻辑）上表现更好，TAGAL 在复杂业务逻辑约束处理上具有独特优势。这一分歧的背后，是另一个更根本的争论：合成数据能否保持因果结构？观点 A 认为通用生成模型仅学习观测分布，无法保持因果结构，需专门因果感知方法（Causal-GAN, CausalWrap）；观点 B 认为高阶依赖捕捉（扩散/流匹配）已隐含部分因果信息，无需额外约束。现有证据偏向观点 A：TabStruct 等评估显示，通用模型在因果图发现（SHD）上表现较差，而 CausalWrap 等方法显著提升了因果保真度（0.88 vs 0.86）。分歧根源在于缺乏统一的“语义-数值”联合评估基准及大规模因果基准数据集。

### 3.3 其他开放问题

最紧迫的工程问题是如何在隐私预算限制下高效训练高维模型。现状是 DP 机制（如 PATE, DP-SGD）显著增加了计算开销，且高阶相关性建模在有限预算下难以保持。关键困难在于隐私噪声与高阶依赖捕捉之间的冲突，研究路径包括基于神经网络的边际选择（MargNet）及推理时隐私增强技术。最根本的研究问题是如何定义并量化“因果保真度”及“合成-真实差距”的本质。现状是传统指标（C2ST, Shape/Trend）无法捕捉高阶依赖和全局结构，TabQueryBench 和 TabStruct 提供了新视角但尚未形成统一标准。关键困难在于因果结构本身难以从有限数据中准确估计，研究路径包括将结构因果模型（SCM）嵌入生成过程、因果约束包装器及混合生成框架。已知—争议—未知认知图谱：已知扩散/流匹配是 SOTA，隐私-效用权衡不可避免；争议 LLM 数值保真度及因果结构可学习性；未知统一评估基准及 TFM 合成先验优化。发展趋势：从纯数据驱动转向知识驱动与结构感知，TFM 与因果推断的深度融合是突破当前瓶颈的关键。

## 4. 总结与展望

合成表格数据生成已从简单的数据模拟工具演变为融合隐私、因果与基础模型的复杂系统。核心挑战仍是缩小合成-真实差距，但解决路径已从纯数据驱动转向知识驱动与结构感知。早期 GAN/VAE 方法受限于训练不稳定性与高基数分类变量瓶颈，扩散/流匹配模型通过高阶依赖捕捉确立了 SOTA 基准，但引入了计算成本与隐私泄露风险。LLM/TFM 的引入标志着从“数据驱动”向“知识驱动”的范式转移，旨在解决少样本与约束感知问题，但面临数值保真度不足及计算成本高的挑战。当前领域处于高度活跃期，研究热点从单纯的生成质量转向隐私-效用权衡、因果结构保持、约束感知生成以及针对基础模型的合成先验设计。

未来可能突破的方向包括：一是基于 TFM 的合成预训练先验优化，TabPFN 和 TabFORGE 均指向利用预训练知识提升小样本表格学习性能，合成先验的质量直接影响模型泛化能力；二是因果感知生成框架的通用化，CausalWrap 和 CA-GAN 均指向将因果约束集成到任意生成器中，无需重新训练即可强制合成数据满足特定的因果不变性；三是隐私-效用权衡的高效优化，Tab-PE 和 MargNet 均指向在有限隐私预算下保持较高效用的机制设计。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，构建一个同时量化语义合理性与数值精度的联合评估基准，以解决当前 LLM 与专用生成模型之间缺乏公平比较标准的困境。
