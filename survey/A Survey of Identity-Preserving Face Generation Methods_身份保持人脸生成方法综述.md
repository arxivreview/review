# A Survey of Identity-Preserving Face Generation Methods ｜身份保持人脸生成方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Identity-Preserving%20Face%20Generation)

## 导读

身份保持人脸生成（Identity-Preserving Face Generation, IPFG）旨在从少量参考图像中锁定特定人物身份，同时允许通过文本提示自由控制姿态、表情与场景，其核心价值在于解决个性化需求与通用生成模型之间的张力。早期研究依赖基于生成对抗网络（GAN）的架构和测试时微调（如 DreamBooth），虽然保真度高，但存在计算开销大、部署效率低且易过拟合参考图的问题。随着潜空间扩散模型（LDM）的兴起，研究范式发生关键转折，从参数微调转向基于适配器的免微调（Tuning-Free）注入，通过交叉注意力机制将 ArcFace 等身份嵌入注入生成过程，显著提升了推理效率。2025 至 2026 年，领域重心进一步向扩散 Transformer（DiT）架构迁移，并拓展至视频生成和多身份场景，当前研究热点集中在解决多身份混淆、视频时序一致性以及隐私保护。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

身份保持人脸生成的核心诉求源于个性化图像生成的需求，即从极少量的参考图像中保留特定人物身份，同时允许通过文本提示控制姿态、表情和场景。这一问题的形式化通常被定义为 N-way K-shot 设定，其中模型需从 K 张参考图像中提取身份特征，并在生成 N 个新场景时保持该身份的一致性。早期研究主要依赖基于 GAN 的架构和测试时微调，虽然保真度高，但存在计算开销大、部署效率低且易过拟合参考图的问题，导致该方法难以满足工业界对实时性和多样性的需求。

随着潜空间扩散模型（LDM）的兴起，问题定义发生了根本性转变：从“如何微调模型参数以绑定身份”转变为“如何在冻结骨干中高效注入身份特征”。这一转变催生了基于适配器的零样本（Tuning-Free）范式，如 IP-Adapter 和 InstantID，它们通过交叉注意力机制将 ArcFace 等身份嵌入注入生成过程，显著提升了推理效率。2025 至 2026 年，领域重心进一步向 DiT 架构迁移，并拓展至视频生成和多身份场景，核心矛盾从单一的“身份保真度”演变为“身份-动作解耦”、“多身份空间隔离”以及“隐私保护与生成质量的平衡”。

子问题间存在明确的依赖关系：单 ID 生成的身份注入机制是多 ID 和视频生成的基础；多 ID 生成依赖于单 ID 机制加上空间定位约束；视频生成依赖于单 ID 机制加上时序一致性约束。而评估体系（如细粒度指标）是解决上述所有子问题中“保真度与多样性权衡”的关键反馈机制。例如，多身份生成中的身份混淆问题，本质上是单身份注入机制在缺乏空间隔离时的系统性失败，因此解决多身份问题必须建立在单身份注入机制的鲁棒性之上。

在约束演化史上，2016 至 2018 年的奠基期主要关注度量学习与原型网络，确立了身份嵌入的几何表示基础。2020 年跨域基准的出现暴露了域偏移下的原型崩溃问题，促使研究者转向预训练与视觉语言模型。2021 至 2023 年，预训练与视觉语言模型的引入带来了更强的先验，但同时也引入了身份与语义耦合的新问题。2023 至 2024 年，随着 Stable Diffusion 等 LDM 的成熟，IP-Adapter 和 InstantID 等免微调方法成为主流，解决了部署效率问题。2025 至 2026 年，DiT 架构的引入和强化学习（RL）的应用进一步细化了身份注入的粒度，形成了当前的多元方法格局。

**如果用一个核心问题概括该领域，那便是：如何在保持预训练扩散模型通用生成先验不被破坏的前提下，实现身份特征与动态语义（姿态、表情、场景）的正交解耦与精准注入。**

## 2. 方法体系

- 2022：Textual Inversion——通过优化特定文本词向量来代表新概念，无需修改模型权重即可实现个性化生成，是早期基于优化的个性化方法代表，为后续免训练方法提供了对比基线

- 2023：DreamBooth——通过微调UNet将特定身份与罕见词绑定，实现了高保真的身份保持生成，确立了基于微调的个性化范式，但存在计算开销大、部署效率低的问题

- 2023：IP-Adapter——利用解耦交叉注意力机制引入图像提示，实现了通用的风格和内容迁移，虽然面部身份保持有限，但奠定了免训练个性化方法的基础架构

- 2024：InstantID——引入强大的面部识别嵌入（如ArcFace）以增强身份保真度，显著提升了免训练方法在面部细节上的表现，推动了从通用图像提示向特定面部身份保持的演进

- 2024：PuLID——在DiT骨干网络中通过残差适配器注入ArcFace嵌入，实现了FLUX等现代扩散模型的高效身份保持，解决了UNet时代方法在新型骨干网络上的适配问题

- 2025：WithAnyone——提出可控且ID一致图像生成框架，通过ArcFace嵌入投影至DiT隐空间并引入可控属性保留机制，平衡了身份保真度与生成多样性，解决了过度保真导致的复制粘贴问题

- 2026：DVI——正交解耦细粒度语义身份和粗粒度视觉上下文，通过融合投影网络将异质特征注入DiT模型，解决了直接注入原始特征导致的可编辑性下降问题

- 2026：WildActor——构建Actor-18M大规模数据集并提供密集多视角监督，解决了现有数据集缺乏一致多视角信息导致的身份漂移问题，提升了复杂场景下的视频生成鲁棒性

这条时间线勾勒了该领域方法演进的代表性节点：从 2022 年的 Textual Inversion 奠定该领域方法基线，经 2023 年 DreamBooth 的推进，到 2026 年的 WildActor 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 单ID个性化生成

单 ID 个性化生成是 IPFG 的基础，其核心在于解决身份保真度、文本可控性及零样本适配问题。早期方法如 DreamBooth 通过微调 UNet 将特定身份与罕见词绑定，实现了高保真的身份保持生成，但存在计算开销大、部署效率低的问题。随着 DiT 架构的兴起，研究范式转向免训练注入。WithAnyone（ICLR 2026, P39）提出了一种面向可控且 ID 一致图像生成的统一框架，核心在于解决过度保真导致的生成多样性丧失问题。该方法首先利用 ArcFace 编码器提取参考人脸的高维身份嵌入，并通过多层感知机将其投影为适配 DiT 隐空间的多令牌张量，以提供足够的容量供交叉注意力层整合身份线索。为了平衡身份保真与生成自然度，模型引入了可控属性保留机制，允许用户选择性地保留发型、配饰等中层语义属性，而不仅仅是高层几何特征。这种设计避免了完全抑制复制行为，同时防止了低层纹理的过度复制，其技术定位在于弥合了高相似度生成与可控生成之间的差距。

DVI（Li and Ding, 2025, P7）则提出了一种免训练个性化生成方法，核心思想是正交解耦参考图像中的细粒度语义身份和粗粒度视觉上下文。该方法设计了融合投影网络，将原始身份特征映射到与文本编码器对齐的语义空间，解决了 ID 特征空间与扩散模型隐空间之间的异质性问题。通过参数无关的特征调制和动态调度器，在 MM-DiT 骨干中协同注入解耦后的特征，避免了直接注入原始特征导致的“贴纸效应”和可编辑性下降。UniID（Pang et al., 2025, P5）进一步提出了一种统一调优免训练面部个性化方法，旨在协同文本嵌入和适配器方法以增强身份保真度同时保持文本可控性。该方法的核心设计原则是在合并文本嵌入和适配器特征时，通过特定的融合策略确保身份信号不被文本语义淹没，利用预训练模型提取 CLIP 图像特征和面部 ID 嵌入，并通过面部属性混合器结合详细面部信息和结构信息。SpatialID（Li and Ye, 2026, P16）针对免训练身份定制中的全局注入污染问题，提出了一种基于注意力的空间自适应调制架构，设计了空间掩码提取器，用于从参考图像中提取空间相关的身份特征，并通过时间-空间调度器在去噪过程中动态调整身份信号的注入强度，确保了身份特征仅在面部区域被强烈注入，而在背景或其他物体区域被抑制。

| 方法 | 骨干网络 | 身份注入机制 | 优势 | 劣势 | 典型应用场景 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| DreamBooth | UNet | 参数微调 | 高保真 | 计算开销大，易过拟合 | 离线高质量需求 |
| IP-Adapter | UNet | 交叉注意力 | 通用性强，低延迟 | 面部细节弱 | 风格与内容迁移 |
| InstantID | UNet | ArcFace 嵌入注入 | 面部细节强 | 架构较复杂 | 高保真肖像生成 |
| WithAnyone | DiT | 可控属性保留机制 | 平衡保真与多样性 | 架构复杂 | 可控肖像生成 |
| DVI | DiT | 正交解耦注入 | 可编辑性强 | 计算开销略高 | 复杂场景生成 |
| UniID | DiT | 统一调优融合 | 即插即用 | 依赖预训练模型 | 零样本生成 |
| SpatialID | DiT | 空间自适应调制 | 空间控制精确 | 推理速度略降 | 虚拟试穿与角色定制 |

单 ID 个性化生成的演进体现了从全局微调向局部解耦注入的转变，为多 ID 和视频生成奠定了技术基础。

### 2.2 多ID场景生成

多 ID 场景生成聚焦多人场景下的身份保持与布局绑定，解决身份混淆、复制粘贴伪影及空间定位问题。Ar2Can（Borse et al., 2025, P4）提出了一种两阶段框架，解耦空间规划（Architect）和身份渲染（Artist）以解决多人场景生成中的身份混淆和计数错误问题。Architect 阶段负责生成多人场景的空间布局，提供两种变体：监督式 Qwen 和 RL 微调 Schnell，以平衡速度、准确性和对齐度。Artist 阶段利用基于 RL 的训练方法，结合匈牙利匹配的空间地面真值面部匹配、提示和姿态对齐以及感知质量奖励，优化身份保持和照片真实感。UMO（Cheng et al., 2025, P1）提出了一种通过匹配奖励扩展多身份一致性的图像定制方法，核心在于利用强化学习解决多人场景下的身份混淆问题。该方法引入了多身份匹配奖励，通过 DETR 和多目标跟踪启发的机制，为每个参考身份找到对应的生成面部，并计算匹配分数作为奖励信号。基于 ReReFL 框架，UMO 直接反向传播奖励信号以引导扩散模型优化，相比 GRPO 算法实现了更快的收敛。

AnyPhoto（Yuan, 2026, P19）提出了一种基于位置画布的多人员身份保持图像生成方法，核心在于通过 ID 自适应调制实现精确的空间身份控制。该方法利用 Flow Matching 框架，将每个身份与特定的空间区域绑定，通过位置画布提供显式的空间约束。ID 自适应调制机制根据参考图像的身份特征动态调整生成过程中的身份信号强度，确保每个身份在其指定区域内被忠实渲染，同时避免与其他身份的特征混合。GroupPortrait（WACV 2026, P41）提出了一种多 ID 肖像生成方法，通过高身份保持和细粒度控制解决多人肖像生成的挑战。该方法引入了 Mask-Attention Controller，将面部区域掩码与交叉注意力机制集成，防止特征溢出并确保每个身份仅影响其指定位置。WithEveryone（Xu et al., 2026, P35）提出了一种统一规划和身份定位的群组图像生成方法，旨在解决现有方法在大规模群组生成中的局限性。该方法针对现有学术方法仅支持少量参考身份（通常 1-5 人）的问题，设计了能够联合生成更多指定人物的框架。

多 ID 场景生成的核心在于空间定位与身份隔离，其技术路线与单 ID 生成互补，但引入了更复杂的约束条件。

### 2.3 视频身份保持

视频身份保持探索时序一致的身份保持视频生成，解决动态场景下的身份漂移、动作自然度及多视角一致性挑战。WildActor（Guo et al., 2026, P18）提出了一种无约束身份保持视频生成方法，核心在于解决现有数据集缺乏一致多视角信息导致的身份漂移问题。该方法构建了 Actor-18M 大规模数据集，包含 160 万个身份一致视频和超过 1800 万张参考图像，提供密集的多视角监督。Lynx（Sang et al., 2025, P2）提出了一种高保真个性化视频生成方法，基于 Wan2.1 基础模型引入 ID-adapter 和 Ref-adapter 模块。ID-adapter 利用面部特征提取器获取身份嵌入，并通过额外的交叉注意力模块条件化生成过程，实现身份信息的注入。Slot-ID（Lai et al., 2026, P10）提出了一种基于槽位的时间身份编码方法，用于从参考视频进行身份保持视频生成。该方法的核心是槽位式时间 ID 编码器，利用可微分槽位分配从短参考片段中提取稳定的人特定线索。Identity-Consistent Video Generation（Hu et al., 2026, P20）提出了一种针对大面部角度变化的身份一致视频生成方法，核心在于解决大视角变化下的身份漂移问题。该方法设计了参考解耦 RoPE 机制，为视频和条件令牌分配不同的位置编码，以更好地建模其异质属性。IaD（Lin et al., 2026, P33）提出了一种通过身份-动作解耦定制视频肖像的方法，核心在于将面部嵌入分解为身份嵌入和面部动作嵌入。

视频身份保持的核心挑战在于时序一致性与大角度变化下的身份漂移，其技术路线依赖于单 ID 生成机制的时序扩展。

### 2.4 人脸交换与重演

人脸交换与重演研究将源身份注入目标图像或视频的技术，强调姿态、表情及光照的解耦与保持。DreamID-V（Guo et al., 2026, P11）提出首个基于 DiT 的视频换脸框架，核心在于通过 SyncID-Pipe 数据工厂构建双向 ID 四元组以桥接图像和视频换脸。VFace（Baliah et al., 2026, P15）提出一种免训练扩散模型视频换脸方法，核心在于利用预训练扩散模型实现高保真身份转移。AlphaFace（Yu et al., 2026, P13）提出一种高保真实时换脸器，核心在于解决面部姿态变化下的身份转移鲁棒性问题。CA-IDD（Rana and Debnath, 2026, P26）提出一种交叉注意力引导的身份条件扩散换脸方法，核心在于利用连续身份嵌入进行空间对齐。GaussianSwap（Cheng et al., 2026, P12）提出一种基于 3D 高斯泼溅的可动画视频换脸方法，核心在于同时实现高质量视频换脸和动态可控面部头像生成。

人脸交换与重演与单 ID 生成在身份注入机制上高度相似，但更强调非身份属性的保留与解耦。

### 2.5 隐私保护与防御

隐私保护与防御针对身份生成模型的隐私风险，研究主动防御、身份遗忘及对抗攻击。Reverse Personalization（Kung et al., 2025, P9）提出一种从单张图像中移除身份特定特征的方法，核心在于通过调整提示中名人名称的注意力权重来控制生成图像的相似度。PIU（Estrada et al., 2026, P31）提出一种邻近引导身份遗忘方法，核心在于将目标身份映射到选定的锚点身份而非无条件先验。No Way To Steal My Face（CVPR 2026, P40）提出一种主动防御身份保持个性化生成的方法，核心在于通过身份场混淆和引导流身份偏转破坏身份提取。FLUID（Park et al., 2025, P3）提出一种免训练面部去标识化方法，核心在于通过潜在身份替换实现语义去标识化。IREU（Shi et al., 2026, P34）提出一种身份相关编码器仅遗忘方法，核心在于仅更新图像编码器而冻结扩散模型以实现定制肖像生成的隐私保护。

隐私保护与防御是 IPFG 的伦理延伸，其技术路线与生成方法互补，但引入了对抗性约束。

### 2.6 评估与基准构建

评估与基准构建开发专门针对身份保持的评估指标、基准数据集及工具包。Finer-Personalization Rank（Kilrain et al., 2025, P8）提出一种细粒度检索评估框架，核心在于解决现有指标无法捕捉细粒度身份差异的问题。ID-Sim（Chae et al., 2026, P24）提出一种身份聚焦相似度指标，核心在于解决现有指标在视角、光照变化下对身份一致性评估不准确的问题。StyleID（Yun et al., 2026, P25）提出一种感知感知数据集和指标，核心在于解决风格化面部身份识别中的分布偏移问题。NearID（Cvejic et al., 2026, P23）提出一种通过近身份干扰项学习身份表示的方法，核心在于解决视觉基础模型在背景相同但物体不同时的身份混淆问题。Head Similarity（Wang et al., 2026, P28）提出一种建模结构化全头外观的相似性方法，核心在于解决传统面部识别在视频生成和重演中身份一致性不足的问题。

评估与基准构建是 IPFG 的反馈机制，其技术路线依赖于生成方法的性能表现。

### 2.7 合成数据与下游

合成数据与下游利用身份保持生成技术合成高质量人脸数据，服务于人脸识别训练、质量评估及特定领域的应用。VIGFace（ICCV 2025, P38）提出一种用于隐私免费人脸识别数据集的虚拟身份生成方法，核心在于解决合成数据在分布匹配和 ID 一致性上的挑战。SteerFace（Mi et al., 2026, P32）提出一种通过自适应残差扰动去偏合成面部生成的方法，核心在于解决合成数据中数据多样性与真实流行率不匹配的问题。Identity-Conditioned Latent Consistency Distillation（Chaves et al., 2026, P36）提出一种用于面部合成的身份条件潜在一致性蒸馏方法，核心在于解决扩散模型推理成本高且难以大规模合成数据的问题。IDperturb（Boutros et al., 2026, P17）提出一种通过角度扰动增强合成面部生成变化的方法，核心在于解决合成数据中类内变化不足的问题。FlowID（Ripoll et al., 2026, P21）提出一种利用潜在流匹配模型增强法医鉴定的方法，核心在于解决法医面部重建中图像编辑的挑战。

合成数据与下游是 IPFG 的应用延伸，其技术路线依赖于生成方法的效率与质量。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

扩散模型（特别是潜空间扩散和 DiT 架构）已成为身份保持生成的主流骨干，取代了早期的 GAN 和自回归模型，因其具备更强的生成多样性和稳定性。这一共识在多个基准上被反复验证：Lynx 的 0.85 FaceSim 与 WildActor 的 0.82 FaceSim 均大幅超越早期 GAN 方法的性能。免微调（Tuning-Free）方法因其低计算成本和即时部署能力，正逐步取代针对每个身份的测试时微调，成为工业界和学术界的首选范式。ArcFace 等预训练人脸识别嵌入是提取和度量身份信息的标准工具，几乎所有方法都依赖其作为身份条件或评估指标。交叉注意力机制是向扩散模型注入身份特征的最有效且通用的方式，能够较好地平衡身份保持与基础生成能力。

与此相关的另一个共识是多身份生成是当前的主要瓶颈，现有方法在身份隔离和空间控制方面仍存在显著缺陷，需要更精细的空间约束和身份匹配机制。视频身份保持比图像身份保持更具挑战性，时序一致性和大角度变化下的身份漂移是亟待解决的核心问题。隐私保护是身份保持生成领域的重要伦理和技术延伸，对抗扰动和身份遗忘是主要的防御手段。强化学习（RL）被证明是优化身份保真度和对齐人类偏好的有效手段，特别是在解决传统损失函数难以优化的复杂约束时。

### 3.2 观点分歧

身份注入的粒度是领域内的核心分歧之一。观点 A（全局嵌入）认为 ArcFace 全局嵌入足以捕捉身份，架构简单高效，代表方法如 InstantID 和 PuLID。观点 B（解耦/空间特征）认为全局嵌入导致复制粘贴伪影，需解耦身份与上下文或引入空间掩码，代表方法如 WithAnyone 和 DVI。现有证据偏向观点 B，WithAnyone 和 DVI 在 MultiID-Bench 上展示了更低的 Copy-Paste Score 和更高的 CLIP-T 分数，表明解耦方法在保持身份的同时提升了文本可控性和多样性。然而，解耦方法架构复杂，推理速度略慢，且在极端视角下解耦效果可能下降，需要更高效的解耦算法和更严格的视角鲁棒性测试来定输赢。

这一分歧的背后，是另一个更根本的争论：隐私保护的实现路径。观点 A（对抗扰动）认为轻量级、无需训练的方法更实用，代表方法如 No Way To Steal My Face 和 Reverse Personalization。观点 B（身份遗忘）认为通过训练模型或编码器彻底移除特定身份更彻底，代表方法如 PIU 和 IREU。证据偏向观点 B 在“彻底性”上，观点 A 在“效率”上。PIU 在 CelebA-HQ 上展示了更高的 Forgetting Strength，但 No Way To Steal My Face 在推理时更灵活。缺乏统一的隐私保护评估标准，对抗扰动易被自适应攻击绕过，而身份遗忘可能影响模型通用性，需要结合攻击-防御博弈的实验来评估长期安全性。

### 3.3 其他开放问题

当前领域面临从“工程优化”向“研究突破”的跨越，多身份空间绑定和视频长时一致性仍是未解的研究难题。最紧迫的工程问题是推理加速与实时性，扩散模型生成速度慢，难以满足实时应用需求，潜在路径包括利用蒸馏模型（如 FLUX.1-schnell）、潜空间一致性蒸馏及少步采样策略。最根本的研究问题是极端姿态与遮挡下的鲁棒性，模型在侧脸、严重遮挡或极端表情下身份保持能力显著下降，潜在路径包括引入 3DMM 先验、姿态共享字典及基于关键点/地标信息的空间控制模块。此外，发展细粒度身份评估指标也是关键，传统余弦相似度指标无法区分细微的身份变化或风格化影响，潜在路径包括构建基于 VLM 的层级评估框架、引入近身份干扰项的判别性指标及风格无关的身份识别基准。

已知—争议—未知认知图谱显示，DiT 骨干和免训练范式是已知最优技术栈，身份注入粒度和隐私保护路径是争议焦点，多身份空间绑定和视频长时一致性是未知难题。未来发展趋势将向更真实、可控且安全的方向演进，强化学习对齐、3D 几何先验引入及隐私保护机制的标准化将是关键突破点。

## 4. 总结与展望

IPFG 领域已从早期的参数微调范式成功过渡到基于 DiT 和适配器的免训练注入范式，解决了效率与保真度的初步矛盾，但身份与语义的深度解耦、多场景鲁棒性及隐私保护仍是未来突破的关键。核心瓶颈在于如何在保持预训练扩散模型通用生成先验不被破坏的前提下，实现身份特征与动态语义的正交解耦与精准注入。

未来可能突破的方向包括：1）多身份空间绑定机制，通过布局条件生成、匈牙利匹配奖励优化及基于画布的空间分解策略，实现精确的身份定位与区分；2）视频长时身份一致性，利用多视角参考、时序身份槽编码及基于关键帧的身份校正技术，平衡身份保真度与运动自然性；3）隐私保护与生成质量的平衡，通过潜空间身份替换、可逆神经网络嵌入及对抗性水印技术，在保持视觉保真度的同时有效屏蔽身份特征。对进入者最值得做的一件事是构建统一的隐私保护评估标准，结合攻击-防御博弈的实验来评估长期安全性，以解决当前隐私保护路径的分歧。
