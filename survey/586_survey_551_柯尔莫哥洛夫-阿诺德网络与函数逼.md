## 导读

柯尔莫哥洛夫-阿诺德网络（Kolmogorov-Arnold Networks, KANs）将非线性变换从节点激活转移至可学习边缘函数，其核心价值在于以更低参数实现高精度函数逼近并保留可解释性。早期研究受限于理论构造的非光滑性，长期处于理论边缘，直到 2024 年现代 KAN 架构通过 B 样条参数化解决了训练稳定性问题。当高维基准暴露出参数量指数级增长与网格漂移瓶颈后，研究者转向共享基函数、自适应网格及硬件加速，用计算效率换取高维扩展能力。各路线在局部适应性、全局计算效率与部署成本之间做出了不同取舍，由此形成当前架构、理论与硬件并进的多元格局。本综述梳理这条从理论复兴到工程落地的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

KAN 领域的兴起源于对传统多层感知机（MLP）固定激活函数局限性的深刻反思。MLP 依赖预定义的 ReLU 或 Sigmoid 函数，缺乏对非线性关系的细粒度建模能力，且其黑盒特性阻碍了科学发现中的因果推断。与此同时，柯尔莫哥洛夫-阿诺德表示定理（Kolmogorov-Arnold Representation Theorem, KAT）早在 1957 年便证明了任何多元连续函数均可由有限个一元连续函数的复合与加法表示，这为将非线性建模从节点移至边缘提供了坚实的理论合法性。然而，原始 KAT 构造出的函数往往非光滑且计算复杂，导致该理论在随后的数十年里长期处于数学边缘，未能有效工程化。

问题的形式化可以表述为：给定输入 $\mathbf{x} \in \mathbb{R}^d$ 和目标函数 $f: \mathbb{R}^d \to \mathbb{R}$，KAN 旨在学习一组可学习的一元函数 $\phi_{i,j}$，使得 $f(\mathbf{x}) \approx \sum_{i=1}^{M} \phi_{i,1}(x_1) + \dots$ 的复合结构成立。与 MLP 的 $W \cdot \sigma(Wx+b)$ 不同，KAN 的核心组件是置于连接边上的可学习边缘函数，通常由 B 样条（B-splines）参数化。这种结构使得模型具备通用逼近性，且边缘函数可直接可视化，支持符号回归。子问题之间存在严格的依赖关系：高维扩展能力依赖于基函数共享机制的突破，训练稳定性依赖于网格自适应策略的解决，而可解释性的可靠性则依赖于边缘函数平滑性约束的建立。若共享机制与网格策略未能解决，高维场景下的参数爆炸与动态数据下的精度衰减将不可避免。

2016 年至 2018 年间，早期研究如 Igelnik-Parikh KAN 尝试基于 KAT 构建非线性回归模型，确立了基本拓扑结构，但因缺乏有效的优化算法而未能普及。2020 年前后，跨域基准的引入促使研究者关注模型在分布偏移下的鲁棒性，但 KAN 此时仍主要作为理论验证对象。真正的转折点出现在 2024 年，Liu 等人提出的 PyKAN 架构通过引入可学习 B 样条边缘函数并结合 SiLU 残差分支，解决了早期 KA 网络训练困难的问题，确立了 KAN 作为 MLP 替代品的地位。这一范式转变将研究重心从“理论可行性”转向“工程实用性”，引发了学术界对可解释性和参数效率的广泛研究。

2025 年至 2026 年，问题定义进一步演化为“高维扩展与计算效率的平衡”。随着 FastKAN 和 QuantKAN 等高效变体的出现，研究热点集中在解决高维扩展瓶颈、优化训练稳定性以及探索其与核方法的数学等价性。Sprecher Networks 通过共享基函数缓解了维度灾难，而 KAN 收敛率分析则提供了统计学习理论的严格保障。当前，KAN 被视为连接经典函数逼近理论与深度学习的桥梁，旨在构建兼具高精度、低参数消耗及强可解释性的新型函数逼近范式。

**如果用一个核心问题概括该领域，那便是：如何在维持 KAT 所赋予的通用逼近性与可解释性的前提下，克服边缘函数参数化带来的高维指数复杂度与计算开销，构建兼具参数效率与硬件友好性的新型函数逼近范式。**

## 2. 方法体系

- 1957：Kolmogorov-Arnold Representation Theorem (KART)——奠定理论基石

- 1965：Sprecher Construction——提供构造性证明

- 2003：Igelnik-Parikh KAN——确立基本拓扑结构

- 2024：PyKAN (Liu et al.)——现代 KAN 架构确立

- 2024：FastKAN——引入 RBF 提升效率

- 2025：KAN Convergence Rates——证明 minimax 收敛率

- 2025：QuantKAN——统一量化框架

- 2026：Sprecher Networks——参数高效变体

这条时间线勾勒了该领域方法演进的代表性节点：从 1957 年的 KART 奠定该领域方法基线，经 1965 年 Sprecher Construction 的推进，到 2026 年的 Sprecher Networks 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 KAN 架构与基函数设计

KAN 架构的演进始于对基函数选择的探索。Liu et al. (2024) 提出的 PyKAN 确立了以 B 样条为默认基函数的范式，其局部支撑性赋予了模型对尖锐特征的捕捉能力，但 De Boor 迭代带来的计算开销成为主要瓶颈。针对这一短板，Chiu et al. (2026) 提出的 Free-RBF-KAN 引入自适应径向基函数（RBF），通过动态调整形状参数避免了网格重算，以牺牲部分局部支撑性为代价，换取了训练速度的显著提升。与之互补，Katayama (2025) 的 KAN/H 采用 Haar-like 基函数，利用 PATRICIA 树结构高效存储索引，解决了高维或大网格下的存储瓶颈，展示了非样条基函数在资源受限环境下的潜力。

为应对高维输入导致的参数爆炸，Eliasson (2025) 提出的 GS-KAN 基于 Sprecher 型共享基函数构建参数高效架构，通过放松严格固定常数约束并采用固定域策略，大幅减少了独立样条函数的数量。这一设计以限制边缘函数独立性为代价，换取了高维场景下的可扩展性。Menon and Jagtap (2026) 的 FEKAN 则采取特征空间富集策略，通过随机 Fourier 特征映射将输入提升至高维表示，弥补了低维 KAN 的表达局限。这些方法共同构成了从“独立参数化”向“共享与增强”演进的技术谱系，为后续理论分析与硬件加速提供了多样化的架构基础。

### 2.2 KAN 理论分析与收敛性

理论分析为 KAN 的统计学习提供了严格保障。Liu et al. (2025) 证明了 KAN 回归估计量在 Sobolev 空间中的收敛速率，表明当目标函数光滑度为 $r$ 时，KAN 继承了 B 样条的最优极小极大收敛速率 $O(n^{-2r/(2r+1)})$。这一结果填补了 KAN 统计学习理论的空白，建立了其与经典非参数回归方法的理论联系。在此基础上，Oh et al. (2026) 进一步研究了稀疏 KAN 在各向异性 Besov 空间中的后验收缩速率，通过引入超先验分布实现了对未知光滑度的自动选择，增强了 KAN 在不确定性量化方面的理论深度。

优化动力学分析揭示了 KAN 易于训练的原因。ICLR 2026 会议论文（P42）利用神经切触核（NTK）框架证明了两层 KAN 在第一层训练下的全局收敛性，解释了宽网络极限下 KAN 与核回归的等价性。此外，Ismailov (2026) 推导了 KAN 通用逼近性的必要和充分条件，明确了边函数和节点求和结构的数学约束，指出了传统设计在逼近某些函数类时的局限性。Bagrow (2026) 提出的曲率惩罚项则通过解耦数据分布依赖，抑制了激活函数的高曲率振荡，提升了模型在解释性任务中的平滑性。这些理论工作共同界定了 KAN 的能力边界，为架构改进提供了数学指导。

### 2.3 KAN 可解释性与符号发现

可解释性是 KAN 区别于 MLP 的核心优势，研究重心在于从边缘函数中提取符号表示。Bagrow and Bongard (2025) 提出的 S2KAN 通过门控机制和 Hard Concrete 分布动态选择基函数，使 KAN 能够自动发现稀疏的符号表示，解决了传统 KAN 难以直接转换为符号公式的问题。Fan et al. (2025) 的 ShapKAN 利用 Shapley 值将神经元归因建模为合作博弈，精确量化了每个神经元对预测的贡献度，为临床研究和科学推断提供了细粒度的特征归因工具。

在物理方程发现方面，Howard et al. (2026) 的 SINDy-KANs 结合稀疏非线性动态识别技术，从 KAN 激活函数中提取主导动态的少数项，实现了物理方程的自动发现。Ju (2025) 的 SVGP KAN 将边函数建模为独立的高斯过程，通过变分近似计算不确定性传播，弥补了标准 KAN 缺乏原生不确定性估计的缺陷。Mysore (2026) 的 Temporal Functional Circuits 则通过可视化边函数随时间的变化，揭示了时间序列预测中的动态行为。这些方法共同推动了 KAN 从“黑盒预测”向“白盒科学发现”的转变，使其成为物理信息机器学习中的可靠工具。

### 2.4 KAN 高效计算与硬件加速

针对 KAN 计算开销大的问题，研究聚焦于量化、GPU 优化及专用硬件实现。Fuad and Chen (2025) 提出的 QuantKAN 是首个统一的 KAN 量化框架，支持量化感知训练（QAT）和训练后量化（PTQ），针对样条参数和基础参数设计分支感知量化器，解决了异构参数分布导致的低精度部署难题。Yu et al. (2025) 的 PolyKAN 设计了融合 GPU 算子，利用基函数递推关系减少重复计算，显著提升了大规模 KAN 的训练和推理速度。

在专用硬件方面，Errabii et al. (2025) 的 KAN-SAs 设计了针对脉动阵列的加速架构，优化了数据流和内存访问模式，适用于 FPGA 平台。Hoang et al. (2025) 的 KANELÉ 基于查找表（LUT）实现高效评估，通过量化和剪枝机制降低了 FPGA 上的资源消耗。Li et al. (2025) 的 Analogue In-Memory KAN 利用量子隧穿效应实现全模拟内存内神经计算，探索了超低能耗推理的物理极限。这些工作表明，KAN 正从理论走向工程落地，硬件加速已成为解决其计算瓶颈的关键路径。

### 2.5 跨任务与多领域应用

KAN 的应用边界正从低维科学计算向高维视觉、语言及工程领域扩展。Liu et al. (2026) 提出的 KAConvNet 将 KAN 架构扩展至卷积神经网络，提出 KAConvLayer 并结合 SE 注意力模块，证明了 KAN 在视觉识别任务中的有效性。Qiu et al. (2026) 构建了完全基于 KAN 的医学图像分割模型，通过解决深层 KAN 训练困难问题，实现了端到端的 KAN 分割网络，提供了比传统 U-Net 更精细的分割边界。

在自然语言处理领域，Alves and Vicente (2026) 将 KAN 应用于小型语言模型的 Feed-Forward 层，提升了模型的可解释性和参数效率。Jaraiz et al. (2026) 将 KAN 应用于空气动力学预测，与 MLP 和 GNN 进行对比，证明了 KAN 在预测翼型压力分布上的优越性。Zhang et al. (2026) 的 Rational ANOVA Networks 结合有理函数参数化和 ANOVA 分解，提升了 KAN 在大规模视觉任务中的可扩展性。这些应用展示了 KAN 在不同数据结构和任务需求下的适应性，验证了其作为通用函数逼近范式的潜力。

| 方法 | 基函数类型 | 参数共享策略 | 主要优势 | 主要劣势 |
|---|---|---|---|---|
| PyKAN | B-spline | 独立参数化 | 局部适应性强，可解释性高 | 计算开销大，高维参数爆炸 |
| Free-RBF-KAN | RBF | 独立参数化 | 训练速度快，无网格重算 | 全局性导致局部精度略降 |
| GS-KAN | B-spline | Sprecher 型共享 | 高维扩展性好，内存需求低 | 边缘函数独立性受限 |
| KAN/H | Haar-like | 独立参数化 | 内存效率高，适合稀疏数据 | 基函数非光滑，需特殊索引 |
| QuantKAN | B-spline | 独立参数化 | 低精度部署，边缘设备友好 | 量化可能引入精度损失 |

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

KAN 通过将可学习非线性函数置于网络边缘，提供了比 MLP 更强的可解释性和参数效率，尤其在低维科学发现任务中表现优异。这一共识在多个基准上被反复验证：Free-RBF-KAN 在 Feynman Equations 上的 1e-6 MSE 与 S2KAN 在 Nguyen Benchmark 上的 95% 准确率均大幅超越 MLP 基线（支撑证据：P22, P16）。与此相关的另一个共识是 B-spline 是 KAN 中最主流且有效的基函数，但其网格依赖性带来了计算开销，促使了 RBF、Chebyshev 等替代基函数的研究。GS-KAN 在 Fashion-MNIST 上的 94.20% 准确率与 QuantKAN 在 TinyImageNet 上的 68.5% 准确率表明，B-spline 在精度与效率之间取得了良好平衡（支撑证据：P17, P13）。

### 3.2 观点分歧

关于 KAN 是否应作为通用 MLP 的替代品，存在显著分歧。观点 A 认为 KAN 在低维科学任务中显著优于 MLP，应作为科学机器学习的首选架构；观点 B 认为 KAN 在高维数据上参数爆炸，性能未显著优于 MLP，应仅作为特定场景的补充。现有证据偏向观点 B 在高维视觉任务中，Lookup Multivariate KANs 在 ImageNet 上的 75.5% 准确率仍低于 ResNet-50 的 76.1%，但在低维科学任务中观点 A 成立。这一分歧的背后，是 KAN 归纳偏置更适合低维结构化数据，高维扩展依赖于共享基函数等未完全成熟的技术，场景依赖性极强。

关于 B-spline 是否是最优基函数，观点 A 强调其局部支撑性和光滑性，观点 B 认为 RBF 和多项式基函数在计算效率和全局适应性上更优。现有证据显示 B-spline 在精度上略优，但 RBF 在速度上显著占优，Free-RBF-KAN 在 Feynman Equations 上的 1e-6 MSE 与 GS-KAN 的 1e-5 相比，精度略低但训练速度更快。分歧根源在于缺乏针对特定任务（如 PDE 求解 vs 图像分类）的系统性基函数对比，且不同基函数的理论收敛性分析尚不完善。

### 3.3 其他开放问题

最紧迫的工程问题是高维扩展瓶颈，标准 KAN 中每条边独立参数化导致参数量随维度指数级增长，当前尝试通过 Sprecher 型共享基函数或稀疏正则化来缓解，但共享机制对局部适应性的限制尚未完全解决。最根本的研究问题是深层 KAN 的可训练性与理论收敛率，虽然已知 B-spline 最优性，但 KAN 作为复合模型的统计学习理论尚不完善，缺乏针对稀疏 KAN 的先验分布分析。此外，可解释性与符号提取的可靠性也是关键挑战，边缘函数可能产生高曲率振荡，导致符号解释不可读，当前尝试引入曲率惩罚或软符号化门控，但组合光滑性的显式约束仍需深入研究。

已知 KAN 在低维科学任务中具有显著优势，争议集中在高维扩展的有效性及 KAN 是否应作为通用 MLP 替代品，未知领域包括深层 KAN 的优化动力学、非欧空间逼近及不确定性量化。发展趋势表明，随着硬件加速和理论完备，KAN 有望在科学机器学习、边缘计算及可解释 AI 领域占据重要地位。

## 4. 总结与展望

KAN 领域的核心矛盾在于“可解释性/参数效率”与“高维扩展性/计算效率”之间的权衡。从 2024 年 PyKAN 确立架构，到 2025 年理论收敛性与量化框架的完善，再到 2026 年硬件加速与非欧空间扩展的深入，研究路线始终围绕这一矛盾展开。核心瓶颈在于缺乏有效的高维共享机制与硬件友好的计算架构，导致 KAN 在大规模视觉任务中尚未完全超越成熟 CNN 架构。

未来可能突破的方向包括：硬件加速与专用架构设计，解决 B 样条递归计算导致的效率瓶颈，潜在路径包括开发专用 FPGA/Systolic Array 内核及 LUT-based 评估；理论收敛性与优化动力学分析，建立 KAN 在随机梯度下降下的收敛保证，潜在路径包括研究多层 KAN 的过参数化收敛及谱偏置影响。对于进入者，最值得做的一件事是在统一骨干与统一预训练条件下，系统评估不同基函数（B-spline, RBF, Chebyshev）在高维科学任务与视觉任务中的性能边界，以厘清 KAN 的适用场景。
