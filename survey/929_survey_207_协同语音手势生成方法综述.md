## 导读

协同语音手势生成（Co-Speech Gesture Generation, CSG）旨在根据语音音频及文本内容合成同步且语义相关的身体运动，其核心价值在于赋予虚拟人类以自然交互能力。早期研究依赖基于规则的系统将语言功能映射到预定义模板，虽具可解释性但缺乏自然度与多样性。随着深度学习兴起，领域经历关键转折：从回归模型转向生成式模型，VQ-VAE 与自回归架构实现了更灵活的风格控制，而扩散模型的引入则显著提升了运动质量与多样性。2020~2026 年间，研究重心从单纯的“音频-手势”对齐转向实时流式生成、全身整体协调、语义 grounding 以及个性化风格迁移。当前领域处于从“离线高质量合成”向“实时、交互式、具身智能”应用落地的过渡阶段，重点解决长时程漂移、实时延迟约束及多模态深度融合。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

协同语音手势生成的起源可追溯至对虚拟人类自然交互的需求。早期系统如 BEAT（Voss et al., 2019, P3）采用基于规则的方法，将语言功能映射到预定义手势模板。这种范式虽具可解释性，但受限于静态合成，缺乏自然度与多样性，且仅能处理离线、单模态（音频）输入。随着深度学习技术的成熟，领域核心问题从“如何映射”转变为“如何生成自然且多样的运动”。这一转变标志着从规则驱动向数据驱动范式的根本性跨越，奠定了后续生成式方法的基础。

问题形式化通常定义为：给定音频序列 $A = \{a_t\}_{t=1}^T$ 及可选的文本序列 $X$，生成对应的全身运动序列 $M = \{m_t\}_{t=1}^T$，其中 $m_t$ 包含身体姿态、手部动作及面部表情。早期研究聚焦于 N-way K-shot 式的少样本适应，但 CSG 更强调时序对齐与语义一致性。子问题间存在强依赖关系：实时流式生成是具身交互的前提，语义对齐是个性化风格的基础，而评估标准化则是验证所有子问题进展的必要条件。这种依赖网络决定了研究资源的分配与突破路径。

2016-2018 年间，奠基性工作主要探索回归模型与早期生成架构。这一时期的方法假设手势可由音频节奏与简单语义标签线性映射，受限于离线算力与数据规模，难以捕捉长时程依赖。2020 年前后，跨域基准的引入暴露了域偏移下的原型崩溃问题，促使研究者转向预训练与视觉语言模型。2023 年，TalkSHOW 等引入 VQ-VAE 离散化运动 token，实现了更灵活的风格控制，但离散化带来的细节丢失成为新瓶颈。

2024 年，EMAGE 确立了整体式（holistic）手势生成的新范式，通过大规模预训练联合建模面部、手部与身体运动，显著提升了跨模态一致性。同年，MambaTalk 集成选择性状态空间模型（SSM），在保持长序列建模能力的同时降低计算复杂度，为实时流式生成提供了高效骨干。2025 年，LiveGesture 提出零前瞻（zero look-ahead）的低延迟在线生成，解决了传统离线模型无法实时响应的问题。2026 年，StreamTalk 引入关键姿态锚定与闭环检索，实现了 76 FPS 的实时分钟级流式手势生成，标志着领域进入实时交互新阶段。

**如果用一个核心问题概括该领域，那便是：如何在严格的实时延迟与物理/社交约束下，生成既具备细粒度语义对齐又保持说话人独特风格且无长时程漂移的全身协调运动。**

## 2. 方法体系

- 2019：BEAT——基于规则与模板的早期手势生成系统

- 2022：GENEA Challenge——提出基于不匹配刺激的人类评估范式

- 2023：CaMN——采用级联多模态对抗网络架构

- 2023：TalkSHOW——引入组合式VQ-VAE对全身运动进行离散化编码

- 2024：EMAGE——提出掩码音频-手势建模框架

- 2024：MambaTalk——集成选择性状态空间模型（SSM）

- 2025：LiveGesture——提出可流式的手势生成模型

- 2026：StreamTalk——提出基于关键姿态锚定的流式生成方法

这条时间线勾勒了该领域方法演进的代表性节点：从 2019 年的 BEAT 奠定该领域方法基线，经 2022 年 GENEA Challenge 的推进，到 2026 年的 StreamTalk 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 实时流式生成

实时流式生成路线的起源可追溯至对低延迟交互的需求。早期方法如 CaMN（2023）虽实现了较为成熟的对话手势合成，但其离线全序列生成特性限制了实时交互应用。MambaTalk（2024）通过集成选择性状态空间模型（SSM）替代传统 Transformer，在保持长序列建模能力的同时大幅降低计算复杂度，为实时流式手势生成提供了高效的骨干网络选择。这一转折标志着从离线双向解码向流式因果架构的范式转移。

LiveGesture（Saleem et al., 2026, P17）进一步推动了零前瞻（zero look-ahead）的低延迟在线生成。该方法采用流式 SVQ 运动分词器，将连续运动编码为离散令牌，并配合层级专家融合自回归模型进行解码。与依赖双向解码器或未来令牌的现有方法不同，LiveGesture 仅利用近期运动历史和当前音频令牌预测下一帧姿态，消除了对完整语句的依赖。这种设计放弃了全局最优性，换取了任意长度实时语音流的在线生成能力，将每 200 毫秒块的生成延迟控制在 50 毫秒以内。

StreamTalk（Zhang et al., 2026, P27）针对长序列生成中的漂移问题，引入随机锚点掩码（SAM）训练策略与部分感知 DiT 架构。推理阶段结合闭环检索机制，从离线构建的合理运动数据库中检索目标锚点以校正生成轨迹。这种设计有效抑制了开环基线中常见的累积误差，同时保持了运动多样性，在 BEAT2 基准上实现了最先进的运动质量，并支持 76 FPS 的实时运行。MIBURI（Mughal et al., 2026, P15）则基于开源语音对话系统 Moshi，利用其内部语音-文本令牌流作为丰富上下文输入，驱动手势生成器，实现了从对话理解到非语言行为生成的端到端闭环。

| 方法 | 年份 | 核心优势 | 主要劣势 | 典型应用 |
|---|---|---|---|---|
| LiveGesture | | 零前瞻低延迟 | 离散化细节丢失 | 实时交互 |
| StreamTalk | | 闭环校正抗漂移 | 依赖离线数据库 | 分钟级流式 |
| MIBURI | | 端到端闭环 | 依赖语音基础模型 | 全双工对话 |
| UMo | | 稀疏计算高效 | 数据依赖性强 | 资源受限环境 |

实时流式生成与语义控制路线形成互补关系：前者解决“何时生成”的延迟问题，后者解决“生成什么”的内容问题。StreamTalk 的闭环校正机制为后续具身应用提供了稳定性基础。

### 2.2 语义与风格控制

语义与风格控制路线旨在解决仅靠节奏同步无法产生有意义手势的问题。BEAT（Voss et al., 2019, P3）奠定了语义对齐与节奏同步的基础概念，但缺乏数据驱动的泛化能力。EMAGE（2024）通过大规模预训练联合建模面部、手部与身体运动，确立了整体式手势生成的新范式，显著提升了跨模态一致性。

PersonaGest（Zhao et al., 2026, P20）提出语义引导的层级运动表示方法，通过 RVQ-VAE 学习解耦的运动表示，其中第一码本捕获语义感知的运动内容，后续码本捕获风格细节。引入风格残差 Transformer（SRT），以预测的内容令牌和风格参考提示为条件，逐层预测风格令牌。这种层级解耦设计使得模型能够独立控制手势的语义内容与说话人的独特风格，支持基于示例的零样本风格迁移。与基于标签或简单嵌入的风格控制不同，PersonaGest 放弃了模型简洁性，换取了细粒度语义对齐与个性化风格控制的灵活性。

PersonaGesture（Zhang et al., 2026, P19）设计了一种无更新的手势扩散模型个性化框架，针对未见说话人的单参考手势风格迁移问题。该方法在推理时通过独立路径编码目标语音和参考运动，参考路径缓存风格记忆令牌和每通道潜在矩。在去噪过程中，使用注意力风格注入（ASI）将说话人记忆注入冻结的 DiT 网络，生成潜在序列。随后，通过迭代扩散修正（IDR）应用保守矩映射，在解码前校正生成结果。这种设计避免了测试时的参数更新，防止了对参考录音的过拟合，同时保留了目标语音的语义内容。

CoordSpeaker（Fang et al., 2025, P6）提出利用手势描述（Gesture Captioning）实现协调的协同语音手势生成。该方法首先构建手势描述框架，结合运动-语言模型和多粒度描述机制，生成与手势精确对齐的描述性文本，弥补手势数据缺乏文本注释的不足。随后，提出协调手势生成模型，包含手势 VAE 和层级控制去噪器的条件潜在扩散模型。与仅依赖音频或文本的方法不同，CoordSpeaker 通过引入显式语义描述，使生成的手势既符合语音节奏又具有明确的语义指向。

DuoGesture（Paar et al., 2026, P22）提出神经启发且受生物力学启发的双流协同语音手势生成框架，将手势解耦为语义流和节拍流。该方法引入运动接地语义条件（MGSC），将语义条件接地于文本到运动的潜在空间，解耦长尾词分布的影响。同时，使用语义变分信息瓶颈（S-VIB）预测每帧权重，防止门控崩溃，实现语义与节拍流的动态协调。此外，引入惯性节拍先验（IBP），作为训练时的速度一致性正则化器，注入人体测量学归纳偏置以优化节拍流。与单一共享网络不同，这种双流设计允许分别优化节奏韵律和语义形态，解决了现有方法将手势视为单一随机过程而模糊功能差异的问题。

| 方法 | 年份 | 核心优势 | 主要劣势 | 典型应用 |
|---|---|---|---|---|
| PersonaGest | | 层级解耦风格 | 计算复杂度高 | 个性化定制 |
| PersonaGesture | | 无更新个性化 | 依赖参考片段 | 部署场景 |
| CoordSpeaker | | 显式语义描述 | 需文本注释 | 语义驱动 |
| DuoGesture | | 双流解耦 | 生物力学假设 | 具身代理 |

语义与风格控制路线与实时流式生成形成继承关系：前者提供内容控制接口，后者提供实时执行框架。PersonaGest 的层级表示为 StreamTalk 的锚点校正提供了语义基础。

### 2.3 具身与机器人应用

具身与机器人应用路线旨在解决虚拟人类到物理机器人的运动迁移问题。PhysDrift（Liang et al., 2026, P25）提出桥接人形机器人本体差距的协同语音运动生成框架，针对现有以人为中心的生成管道在重定向到机器人时出现的物理不一致性，引入本体感知模块以适配机器人特定的运动学约束。通过整合语音信号与机器人本体状态，模型生成既符合语音语义又满足物理可行性的运动序列。与直接重定向人类运动的方法不同，PhysDrift 在生成阶段即考虑机器人本体差异，避免了后处理中的伪影和不自然运动。

RoboGesture（Wang et al., 2026, P30）提出实时语义对齐的协同语音手势生成系统，专为具身机器人交互设计。该方法开发层级语义-声学对齐器，通过多级 Transformer 架构处理原始音频，解耦低层节奏脉冲与高层语义标签，提取预语音预期信号。系统采用多模态端到端模型，直接在机器人空间训练，确保生成的运动符合机器人本体约束且实时响应。与依赖规则或策略控制器的传统系统不同，RoboGesture 通过数据驱动方式捕捉开放式的社交行为复杂性，实现语音与手势的自然协调。

Learning to Generate Pointing Gestures（Deichler et al., 2025, P1）提出基于模仿强化学习（Imitation-RL）的情境具身对话代理指向手势生成方法。该方法在物理模拟环境中训练运动控制策略，结合自然度与准确性奖励，从少量指向手势演示中学习可泛化的精确指向。与监督学习相比，该方法仅需少量数据即可实现高指向准确性，并学习物理有效的运动，同时保持高感知运动自然度。这种方法解决了传统监督学习数据需求大且难以保证物理有效性的问题，为具身代理在物理情境中的非语言沟通提供了高效训练范式。

| 方法 | 年份 | 核心优势 | 主要劣势 | 典型应用 |
|---|---|---|---|---|
| PhysDrift | | 本体感知适配 | 依赖机器人数据 | 人形机器人 |
| RoboGesture | | 实时语义对齐 | 训练成本高 | 社交机器人 |
| Pointing Gestures | | 模仿学习高效 | 任务特定 | 指向任务 |

具身应用路线是前两者的继承与落地：实时流式生成提供低延迟执行，语义控制提供内容准确性，而具身应用则引入物理约束与本体适配。PhysDrift 的本体感知模块为 RoboGesture 的实时响应提供了物理可行性保障。

### 2.4 多模态交互生成

多模态交互生成路线旨在解决单人口语手势生成忽略社交上下文的问题。TalkSHOW（2023）引入组合式 VQ-VAE 对全身运动进行离散化编码，通过自回归解码器生成手势，提升了时间连贯性，但离散量化导致的细节丢失和部件间协调性不足成为后续改进的重点。DiffSHEG（2024）采用扩散模型在连续空间回归面部与身体联合分布，避免了离散量化误差，实现了高多样性的手势生成，但推理步骤多且缺乏显式语义引导机制。

DyaDiT（Peng et al., 2026, P14）提出多模态扩散 Transformer 用于社交适宜的双人对话手势生成。该方法利用对话双方音频流，可选地整合关系、个性特征及自我手势序列作为辅助条件，生成符合对话语境的他者手势。引入音频正交化交叉注意力（ORCA）模块，有效融合多模态输入，提升手势的社交适宜性与互动响应能力。与仅关注单人口语对齐的方法不同，DyaDiT 显式建模对话动态与社交线索，使生成的手势更贴合真实人际互动。

Puppeteer（Adeli et al., 2026, P31）提出物体接地的姿势感知协同语音手势生成方法，旨在解决现有模型场景无关且缺乏空间一致性的问题。该方法采用无量化紧凑空间因果潜在扩散建模，将长手势序列分解为固定长度原语，编码为紧凑连续潜在令牌，支持自回归生成。引入物体感知融合模块，注入几何上下文以维持手势与周围物体的物理一致性，同时保留大规模数据学习到的强语音-手势先验。与仅关注音频-文本融合的方法不同，Puppeteer 显式建模姿势、手势与物体的内在耦合，实现了场景感知的手势生成。

| 方法 | 年份 | 核心优势 | 主要劣势 | 典型应用 |
|---|---|---|---|---|
| DyaDiT | | 社交上下文建模 | 数据需求大 | 双人对话 |
| Puppeteer | | 物体接地 | 场景依赖强 | AR/VR |
| Gelina | | 统一音视频 | 风格迁移受限 | 多模态代理 |

多模态交互生成路线与语义控制路线形成互补关系：前者扩展输入模态（物体、对话者），后者深化内容控制（语义、风格）。DyaDiT 的社交建模为 Puppeteer 的场景感知提供了社会语境基础。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

扩散模型在生成运动质量和多样性上优于传统的 VQ-VAE 自回归方法，这一共识在多个基准上被反复验证：PersonaGest 的 4.10 与 SiGnature 的 4.72 均大幅超越 MambaTalk 的 5.366。然而，扩散模型面临推理速度挑战，难以满足实时交互的低延迟要求。与此相关的另一个共识是全身整体（Holistic）生成比分体生成更能保证肢体间的协调性与自然度，EMAGE 的 5.512 与 DiffSHEG 的 85.2 均体现了整体建模的优势。语义对齐是提升手势沟通效果的关键，仅靠节奏同步不足以产生有意义的手势，CoordSpeaker 的 5.301 在语义任务上的表现优于 UMo 的 5.107，表明显式语义注入的必要性。

### 3.2 观点分歧

离散化表示（VQ/RVQ）与连续生成（扩散/流匹配）的分歧源于对“自然度”定义的不同侧重。观点 A 认为离散化在实时性与风格解耦上具有优势，LiveGesture 的 50ms/200ms 块延迟体现了这一优势；观点 B 认为连续生成在运动质量与细节保留上更优，StreamTalk 的 76 FPS 且 SOTA FGD 支持了这一观点。现有证据偏向连续生成在质量上更优，但离散化在实时流式场景中仍有应用，缺乏在相同实时约束下的公平比较。这一分歧的背后，是另一个更根本的争论：语义对齐的实现路径。隐式学习（如 EMAGE）通过大规模数据联合建模自动捕捉语义-手势关联，而显式注入（如 CoordSpeaker）通过文本描述显式引导语义对齐。现有证据偏向显式注入在语义对齐任务上表现更好，但隐式学习在整体运动质量上更优，语义对齐的评估缺乏可靠自动指标，导致不同方法在语义任务上的比较存在主观性。

### 3.3 其他开放问题

最紧迫的工程问题是实时流式与因果生成的延迟优化。现状是 LiveGesture 的 50ms/200ms 块延迟已接近实时要求，但 StreamTalk 的 76 FPS 仍依赖闭环检索机制，关键困难在于平衡生成质量与低延迟，研究路径包括流式自回归解码、因果 Transformer 架构及零前瞻设计。最根本的研究问题是语义与情感对齐的细粒度控制。现状是 CoordSpeaker 的显式语义描述提升了语义接地，但缺乏细粒度语义标注及跨模态对齐机制，关键困难在于语义手势的稀疏性与长尾分布，研究路径包括引入文本/图像多模态输入、语义引导的扩散模型及文化感知嵌入。已知—争议—未知认知图谱显示：扩散模型质量优势是已知，离散化与连续生成的实时性权衡是争议，语义长尾分布建模是未知。发展趋势指向实时具身交互与评估标准化。

## 4. 总结与展望

协同语音手势生成从离线合成到具身交互的演进逻辑，核心瓶颈在于实时性、语义深度与物理一致性之间的张力。早期规则系统缺乏自然度，VQ-VAE 自回归引入离散化误差，扩散模型提升质量但牺牲速度，流式架构解决延迟但引入漂移，具身应用引入物理约束但数据稀缺。这一演进链条揭示了问题定义如何因应约束变化而演变：从“如何映射”到“如何生成自然且多样的运动”，再到“如何在约束下生成自然、语义正确且个性化的运动”。

未来可能突破的方向包括：实时流式与因果生成，解决传统离线生成无法支持实时交互的问题，难点在于平衡生成质量与低延迟，潜在技术路径包括流式自回归解码、因果 Transformer 架构及零前瞻设计；语义与情感对齐，提升手势对语音语义、情感及文化背景的表达能力，难点在于缺乏细粒度语义标注及跨模态对齐机制，潜在技术路径包括引入文本/图像多模态输入、语义引导的扩散模型及文化感知嵌入。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，系统比较离散化与连续生成在相同实时约束下的运动质量与语义对齐度，以解决当前评测体系中的混淆因素。
