## 导读

视频时间理解旨在让多模态大语言模型（Multimodal Large Language Models, MLLMs）不仅识别视频内容，更精准定位事件发生的时空关系。早期研究依赖特征流水线与任务特定回归头，虽有效但泛化性差且无法处理复杂语义推理。随着 MLLMs 的兴起，领域范式从任务特定预测转向基于自然语言生成的统一框架，利用大语言模型的推理能力处理时间定位与推理。然而，这一转变引入了新的核心矛盾：模型常依赖语言先验而非视觉证据，导致时间幻觉与逻辑不一致。为应对此问题，研究重心从单纯的监督微调转向强化学习（Reinforcement Learning, RL）与可验证奖励，以解决过拟合与幻觉问题。同时，长视频计算瓶颈与流式实时性需求推动了自适应采样、时空解耦架构及在线记忆机制的发展。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从粗粒度问答到精确时空推理的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

视频时间理解的核心目标已从早期的“事件定位”演变为“时序逻辑推理”。最初，研究者试图解决视频中特定事件的时间定位（Temporal Grounding）问题，即根据自然语言查询在视频中定位特定事件的时间区间。这一阶段主要依赖基于特征的两阶段流水线，即视觉-语言预训练模型（VLP）加上任务特定的回归头。虽然这种架构在特定基准上有效，但其泛化性差，且需要为每个任务训练独立模型，无法处理开放域视频中的复杂语义推理。随着多模态大语言模型（MLLMs）的兴起，领域范式发生了根本转变：从任务特定的回归预测转向基于自然语言生成的统一框架，利用大语言模型的推理能力处理时间定位和时空定位（Spatio-Temporal Grounding）。这一转变使得模型能够通过统一的文本接口处理多种视频理解任务，但同时也引入了新的问题：模型往往依赖语言先验而非视觉证据进行推断，导致时间幻觉（Temporal Hallucination）和逻辑不一致。

问题定义的演化反映了领域对“理解”深度的重新界定。2023-2024 年，随着 Video-ChatGPT 等架构的出现，问题从单纯的定位精度转向长视频上下文限制与均匀采样导致的关键帧丢失。此时，模型难以在长视频中精确定位短暂事件，因为 Transformer 的上下文窗口有限，且均匀采样会丢失细粒度动态。2024-2025 年，问题进一步深化为“时间幻觉”与“逻辑一致性”。研究者发现，模型在事件顺序判断上常依赖静态视觉线索或语言捷径，而非动态时序证据。这促使研究引入对比解码、反事实训练及结构化奖励，以增强模型对时间动态变化的敏感性。2025-2026 年，问题结构扩展至“细粒度时空解耦”与“流式实时性”。模型被要求在长视频中实现亚秒级感知，并在流式输入中平衡历史记忆与实时响应，标志着从离线粗粒度向在线精确时空推理的演进。

子问题之间存在强依赖关系，形成了“输入-表征-优化-评估”的闭环。长视频高效推理是基础，解决输入瓶颈，通过关键帧选择和 Token 压缩保留关键时序线索；时空联合理解架构是核心，解决表征瓶颈，通过解耦或联合建模提升时空特征的表达能力；时序定位强化学习是优化手段，解决优化瓶颈，通过过程奖励或结果奖励提升推理精度；时序基准与诊断是验证工具，解决评估瓶颈，揭示模型在时序逻辑上的缺陷。这种依赖关系意味着，任何单一维度的改进若缺乏其他维度的支撑，其效果往往有限。例如，即使采用了先进的强化学习算法，若输入阶段丢失了关键帧，模型也无法定位短暂事件；若表征阶段未能解耦时空特征，模型在细粒度定位上仍会受限。

范式边界的变化也影响了问题的定义方式。传统 VLP 范式假设视频理解可通过特征匹配与回归解决，受限于算力与数据规模，模型泛化性差。MLLM 范式则假设语言模型具备通用的推理能力，可通过自然语言接口处理视频任务。然而，这一假设在时序任务上遭遇了挑战：语言先验优势与视觉时序证据稀疏性之间的冲突，使得模型在时序逻辑上依赖捷径。因此，当前问题的核心不再是“如何定位”，而是“如何建立基于视觉时序证据的精确时空因果推理能力”。这一转变要求模型不仅输出正确的时间区间，还要展示推理过程，并抵抗语言先验的干扰。

从时间维度看，约束条件的变化驱动了方法的演变。2017 年，Moment-DETR 奠定了基于 Transformer 的时序定位基础，但受限于当时的算力与数据规模，模型仅能处理短视频。2023 年，Video-ChatGPT 开启了视频多模态大模型的研究热潮，解决了“能否看长视频”的问题，但引入了语言先验依赖。2024 年，LongVA 等长视频高效推理方法解决了内存瓶颈，推动了长视频理解研究的发展。2025 年，GRPO 与 TempR1 引入强化学习，解决了“能否看准时间”的问题，通过过程奖励提升时序推理精度。2026 年，WeaveTime 与 MOSS-Video-Preview 等流式理解方法解决了“能否实时且可靠地理解”的问题，开启了在线交互新阶段。这一演进史表明，领域的发展是应对计算资源、数据质量与任务复杂度约束的结果。

当前形态下，领域高度活跃，核心驱动力在于提升长视频中的细粒度时间感知、解决时间幻觉以及实现流式/在线视频理解。关键里程碑包括引入时间感知强化学习（如 GRPO 变体）、构建高质量时间基准（如 TimeLens, TimeBlind）以及探索时空解耦建模。这些进展标志着该领域正从“粗粒度问答”向“精确时空推理”和“实时交互”迈进。然而，挑战依然存在：模型在开放世界视频和复杂场景下的泛化能力有限，时间幻觉的内在机制尚未完全揭示，流式理解中的记忆-实时性冲突仍未彻底解决。

**如果用一个核心问题概括该领域，那便是：如何在计算资源受限与视觉证据稀疏的约束下，使多模态大语言模型摆脱语言先验依赖，建立基于视觉时序证据的精确时空因果推理能力？**

## 2. 方法体系

- 2017：Moment-DETR——基于Transformer的时序定位架构，奠定现代时序定位任务的基础范式

- 2023：Video-ChatGPT——将视觉编码器与语言模型对齐，开启视频多模态大模型研究热潮

- 2024：LongVA——通过扩展上下文窗口和视觉Token压缩，支持小时级长视频理解

- 2025：GRPO——通过组内相对优势估计替代价值网络，成为视频时序定位强化学习的主流算法

- 2025：TempCompass——构建细粒度时序推理基准，揭示现有模型在时序逻辑推理上的缺陷

- 2026：TempR1——通过时序感知的多任务强化学习，统一多个时序任务，代表时序定位RL最新进展

- 2026：VideoLoom——构建统一时空理解模型，通过解耦时空特征实现精准定位

- 2026：MOSS-Video-Preview——通过交叉注意力机制实现生成过程中的持续感知，解决流式理解延迟问题

这条时间线勾勒了该领域方法演进的代表性节点：从 2017 年的 Moment-DETR 奠定该领域方法基线，经 2023 年 Video-ChatGPT 的推进，到 2026 年的 VideoLoom 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 长视频高效推理

长视频高效推理是解决输入瓶颈的基础路线，其核心在于平衡计算成本与时间信息保留。早期方法如 LongVA（Wang et al., 2024）通过扩展上下文窗口和视觉 Token 压缩技术，支持小时级长视频的理解，解决了长视频处理中的内存瓶颈问题。然而，均匀采样导致的关键帧丢失仍是主要挑战。为此，研究者转向自适应采样与关键帧选择策略。GroundVTS（Fan et al., 2026, P34）提出查询引导的视觉 Token 采样方法，通过过滤视觉 Token 以提升视频时序定位精度。该方法针对均匀帧采样导致的时序线索丢失问题，设计查询引导的 Token 过滤机制，在 LLM 前保留关键时空信息。其核心创新在于通过查询引导的 Token 采样，实现了时序定位任务中的视觉 Token 高效利用，提升了时序定位的精度。代价是 Token 过滤机制增加了预处理开销，且需处理查询引导的 Token 选择策略。与 LongVA 的通用压缩不同，GroundVTS 更侧重于任务特定的线索保留，适用于对时序定位精度要求较高的场景。

另一条路线是通过视觉提示显式注入时序信息。ViKey（Lee et al., 2026, P30）提出视觉提示增强方法，通过将帧编号信息直接插入像素空间，提升视频 LLM 的时序理解能力。该方法在帧采样后，将帧编号作为视觉提示插入图像像素空间，使模型能够感知帧的时序顺序，提升了时序推理的准确性。其核心设计在于通过视觉提示显式注入时序信息，避免了文本提示与视觉信息的模态差异，提升了时序感知的鲁棒性。代价是视觉提示增加了图像预处理复杂度，且需处理帧编号与像素的对齐问题。与 GroundVTS 的过滤策略不同，ViKey 侧重于信息的显式注入，两者在“保留”与“增强”时序线索上形成互补。

此外，代理式长视频理解提供了另一种高效推理范式。CogniGPT（Li et al., 2025, P6）提出多粒度线索探索代理框架，通过感知-反思认知循环，实现长视频的高效理解与推理。该方法模拟人类认知过程，通过多粒度感知代理与验证增强反思代理的交互，逐步识别关键帧并回答查询。其核心设计在于通过工具调用与记忆更新，实现长视频中稀疏相关信息的定位，避免了处理完整视频序列的计算开销。代价是代理交互增加了推理延迟，且需设计复杂的工具调用策略。与直接处理视频序列的方法不同，CogniGPT 通过代理交互实现了稀疏信息的定位，适用于长视频中关键信息分布稀疏的场景。

### 2.2 时空联合理解架构

时空联合理解架构旨在解决表征瓶颈，通过解耦或联合建模提升时空特征的表达能力。早期工作如 Video-ChatGPT（Li et al., 2023）将视觉编码器与语言模型通过投影层对齐，实现了视频内容的自然语言交互与理解，开启了视频多模态大模型的研究热潮。然而，时空特征纠缠导致推理瓶颈，难以独立优化空间与时间维度。为此，研究者转向解耦架构。DIVID（ICLR 2026, P52）提出解耦时空建模框架，通过双分支解码器分离空间与时间感知，实现长视频的高效时空理解。该方法将视频特征分为低分辨率时序 Token 与高分辨率空间特征，时序分支捕捉全局动态并生成注意力图，空间分支基于注意力图选择关键帧提取细粒度细节。其核心设计在于通过解耦时空建模，降低长视频处理的计算复杂度，同时保持时空理解的精度。代价是双分支架构增加了模型复杂度，且需协调时序分支与空间分支的信息交互。与 Video-ChatGPT 的联合建模不同，DIVID 通过解耦提升了定位精度与可解释性，但可能损失联合推理能力。

另一条路线是通过视觉编码器时序增强提升表征能力。STAVEQ2（Rasekh et al., 2025, P11）提出堆叠时序注意力视觉编码器架构，通过在视觉编码器中引入堆叠时序注意力模块，增强模型对帧间动态变化的感知能力。该方法在空间注意力之外引入时序注意力层，捕捉帧内与帧间的时空动态，并通过 LoRA 微调与全参数训练结合的方式优化模型。其核心创新在于将时序建模从 LLM 前移至视觉编码器，提升了视觉特征对时序信息的表达能力。代价是堆叠时序注意力增加了视觉编码器的计算开销，且需处理时序注意力与空间注意力的平衡。与 DIVID 的解耦策略不同，STAVEQ2 侧重于在编码器层面增强时序感知，两者在“解耦”与“增强”上形成互补。

此外，零样本时空定位提供了无需标注的新范式。Zero-Shot STVG（Yang et al., 2025, P2）提出零样本时空视频定位方法，通过释放 MLLM 的跨模态理解能力，实现无需帧级标注的时空定位。该方法将时空定位分解为空间定位与时间定位两个子任务，利用 MLLM 的强跨模态理解能力，通过文本查询直接定位时空管。其核心创新在于利用 MLLM 的开放词汇理解能力，避免了传统方法对大量帧级标注的依赖，实现了零样本时空定位。代价是零样本定位精度受限于 MLLM 的时空理解能力，且需处理时空定位的联合优化问题。与依赖标注的方法不同，Zero-Shot STVG 通过开放词汇理解实现了零样本定位，适用于标注数据稀缺的场景。

### 2.3 时序定位强化学习

时序定位强化学习旨在解决优化瓶颈，通过过程奖励、边界对齐及课程学习提升模型在长视频中的时间感知与定位精度。早期方法如 TimeChat（2024）引入时间戳感知的指令微调，使模型能够直接生成时间区间，提升了视频时序定位的生成式能力。然而，监督微调（SFT）在复杂时间推理上易过拟合，模型依赖语言先验而非视觉证据。为此，研究者转向强化学习（RL）。GRPO（2025）通过组内相对优势估计替代价值网络，降低了强化学习训练开销，成为视频时序定位强化学习的主流优化算法。TempR1（Wu et al., 2025, P16）提出时序感知的多任务强化学习框架，通过统一时序定位、密集时序定位、动作定位、高光检测及视频问答任务，利用 GRPO 优化策略。该方法引入时序感知奖励函数，评估模型在时间维度上的推理质量，而非仅关注最终答案的正确性。其核心创新在于通过多任务联合训练，提升模型在不同时序任务间的泛化能力，避免了传统任务特定架构的局限性。代价是训练过程需要处理多任务数据分布差异，且奖励函数设计需兼顾不同任务的时序粒度要求。与 TimeChat 的 SFT 不同，TempR1 通过 RL 提升了时序推理精度，缓解了过拟合与幻觉问题。

另一条路线是通过过程奖励提升细粒度时序感知。TimeThink（Li et al., 2026, P46）提出基于过程与结果奖励的时序推理强化学习方法，通过逐步线索-真值对齐提升视频时序推理能力。该方法将传统基于结果的强化学习扩展为过程感知，评估模型在推理过程中每个时间线索的准确性，而非仅关注最终答案。其核心设计在于引入逐步时序推理线索，通过 IoU 等指标评估线索与真值的时间重叠度，提供细粒度的过程反馈。代价是过程奖励计算开销较大，且需设计复杂的线索提取与对齐机制。与 TempR1 的多任务联合训练不同，TimeThink 侧重于过程奖励的细粒度反馈，两者在“多任务”与“过程感知”上形成互补。

此外，数据质量与训练配方优化也是提升时序定位精度的关键。TimeLens（Zhang et al., 2025, P21）提出基于数据质量与训练配方优化的视频时序定位方法，通过重新标注与交叉验证提升训练数据质量。该方法系统性地检查现有时序定位数据集的标注质量，通过手动精炼、交叉验证与重新标注构建高质量训练集。其核心创新在于将数据质量作为时序定位性能的关键因素，提出时间表示、训练范式与训练配方的最佳实践。代价是数据清洗与重新标注成本较高，且需设计复杂的数据质量评估指标。与 TempR1 的算法优化不同，TimeLens 侧重于数据工程，两者在“算法”与“数据”上形成互补。

### 2.4 时序幻觉与鲁棒性

时序幻觉与鲁棒性旨在解决评估瓶颈，通过对比解码、反事实训练及一致性奖励提升模型输出的可靠性。早期工作如 SEASON（Wu et al., 2025, P17）提出自诊断对比解码方法，通过 DINOv2 特征重加权与对比解码，缓解视频 LLM 中的时序幻觉问题。该方法发现时序幻觉源于模型对视觉证据的过度依赖语言先验，提出 SEASON 方法通过 DINOv2 特征重加权增强视觉证据权重，并通过对比解码抑制幻觉 Token。其核心创新在于通过自诊断机制识别幻觉 Token，并通过对比解码抑制，提供了时序幻觉缓解的训练无关方案。代价是 DINOv2 特征提取计算开销较大，且需处理对比解码的参数调节问题。与训练阶段方法不同，SEASON 通过解码阶段干预实现了训练无关的幻觉缓解，适用于部署成本敏感的场景。

另一条路线是通过反事实训练增强时序敏感性。CRPO（Du et al., 2026, P40）提出反事实强化学习方法，通过反事实分支奖励，提升视频 LLM 在时空敏感性上的鲁棒性。该方法针对模型依赖静态捷径的问题，设计反事实分支，通过对比原始视频与反事实视频的推理结果，提供跨分支反事实奖励。其核心创新在于通过反事实奖励，揭示了模型在时空敏感性上的不足，并提供了鲁棒性优化方案。代价是反事实分支增加了推理开销，且需处理反事实视频的生成与对齐问题。与 SEASON 的解码阶段干预不同，CRPO 通过训练阶段干预从根源上增强时序敏感性，两者在“解码”与“训练”上形成互补。

此外，结构化奖励一致性强化学习提供了另一种鲁棒性优化方案。Structured Rewards（Quan et al., 2026, P33）提出结构化奖励一致性强化学习方法，通过将视频描述解析为结构化单元，设计一致性奖励提升视频 MLLM 的时序一致性。该方法将视频描述解析为对象、属性、关系、事件等结构化单元，并设计一致性奖励评估模型输出与参考描述的结构化一致性。其核心设计在于通过结构化奖励，提供了时序一致性的细粒度评估，为时序一致性优化提供了新的奖励设计范式。代价是结构化解析计算开销较大，且需处理结构化单元的细粒度对齐问题。与 CRPO 的反事实奖励不同，Structured Rewards 侧重于结构化一致性，两者在“反事实”与“结构化”上形成互补。

### 2.5 流式与实时理解

流式与实时理解旨在解决在线交互中的时序顺序感知、记忆管理、延迟优化及动态响应问题。早期工作如 WeaveTime（Zhang et al., 2026, P26）提出流式视频问答框架，通过训练时时序顺序感知增强与推理时动态记忆控制，解决在线视频理解中的时序歧义与记忆效率问题。该方法将时序歧义与记忆访问效率视为内在交织问题，通过 SOPE 模块显式教授模型感知与推理时序顺序，并通过 PCDF-Cache 实现不确定性门控的粗到细记忆控制。其核心设计在于通过训练-推理协同优化，实现了流式视频问答的高效与准确，为流式视频理解提供了新的架构范式。代价是动态记忆控制增加了推理复杂度，且需处理时序顺序感知的训练数据构建问题。与离线模型不同，WeaveTime 通过动态记忆控制实现了在线交互，适用于实时视频问答场景。

另一条路线是通过两阶段流水线实现高效推理。WAT（Han et al., 2026, P29）提出在线视频理解框架，通过观看-思考两阶段流水线，实现流式视频的高效推理。该方法将感知与推理解耦为观看阶段与思考阶段，观看阶段维护短期记忆与长期记忆，思考阶段通过上下文感知检索获取相关历史特征。其核心设计在于通过两阶段流水线，实现了流式视频理解的高效与准确，为在线视频理解提供了新的架构范式。代价是两阶段流水线增加了推理延迟，且需处理短期记忆与长期记忆的平衡问题。与 WeaveTime 的协同优化不同，WAT 通过两阶段流水线实现了感知与推理的解耦，两者在“协同”与“解耦”上形成互补。

此外，实时视频理解框架通过交叉注意力机制实现生成过程中的持续感知。MOSS-Video-Preview（Wang et al., 2026, P42）提出实时视频理解框架，通过交叉注意力机制实现生成过程中的持续感知，解决流式视频理解中感知与生成串行执行的延迟问题。该方法将视频理解分为离线、流式与实时三种范式，提出实时范式通过交叉注意力机制在生成过程中持续感知新帧，实现实时响应。其核心设计在于通过交叉注意力机制，实现了感知与生成的并行执行，为实时视频理解提供了新的架构范式。代价是交叉注意力机制增加了推理复杂度，且需处理感知与生成的同步问题。与 WAT 的两阶段流水线不同，MOSS-Video-Preview 通过交叉注意力实现了感知与生成的并行，两者在“串行”与“并行”上形成互补。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

MLLMs 在视频时间理解上优于传统专用模型，但需专门的后训练（如 RL 或 SFT）才能发挥潜力。这一共识在多个基准上被反复验证：TempR1 的 59.8 mIoU 与 TimeLens 的 47.7 mIoU 均大幅超越 Qwen2.5-VL-7B 的 14.1 mIoU，表明后训练对时序定位精度的显著提升。强化学习（特别是 GRPO 及其变体）是提升视频 MLLMs 时间推理和定位能力的关键范式。TempR1 通过 GRPO 优化策略，在 Charades-STA 上实现了 59.8 mIoU 的 SOTA 性能，较 SFT 方法有显著提升。时间幻觉是视频 MLLMs 的主要可靠性问题，需通过训练或解码阶段干预来缓解。SEASON 通过对比解码抑制幻觉 Token，CRPO 通过反事实训练增强时序敏感性，两者均有效提升了模型输出的可靠性。长视频理解需要结合关键帧选择、记忆机制和长上下文建模，单一方法难以解决。WAT 通过两阶段流水线实现了长视频的高效理解，Zoom-Zero 通过粗到细推理提升了长视频细粒度推理能力，两者均表明多策略结合的重要性。时空联合定位比单独时间定位更具挑战性，需要解耦或联合优化策略。SARL-STG 在 HC-STVG 上实现了 45.2 sIoU，较单独时间定位方法有显著提升，表明时空联合优化的必要性。现有基准测试往往高估模型的时间理解能力，需引入更严格的细粒度和反事实评估。TimeBlind 和 TempCompass 通过反事实与细粒度设计揭示了模型在时序逻辑上的真实缺陷，表明现有基准的局限性。视觉证据与时间戳的对齐是提升定位精度的核心，需显式建模视觉边界证据。GroundVTS 通过查询引导的 Token 采样保留了关键时空信息，ViKey 通过视觉提示显式注入时序信息，两者均表明视觉证据对齐的重要性。

### 3.2 观点分歧

奖励信号设计是领域核心分歧之一，结果奖励（GRPO, TempR1）仅关注最终答案正确性，训练稳定，计算开销小；过程奖励（TimeThink, Temporal-Aware Reasoning）关注推理路径中每个时间线索的准确性，提升细粒度时序感知。现有证据偏向过程奖励，TimeThink 在细粒度时序推理任务上表现更优，但过程奖励计算开销大，且需设计复杂的线索提取机制。哪种实验能定输赢：在相同计算预算下，对比过程奖励与结果奖励在长视频细粒度定位任务上的精度与收敛速度。未定论原因在于过程奖励的复杂性与计算成本阻碍了大规模应用，缺乏在资源受限场景下的公平对比实验。时空建模是另一核心分歧，解耦架构（DIVID, BridgeSTG）分离空间与时间特征，提升定位精度与可解释性；联合建模（VideoLoom, Qwen2.5-VL）端到端联合优化，保留时空交互信息，提升语义理解。现有证据表明，解耦架构在细粒度时空定位（HC-STVG）上表现更优（SARL-STG 45.2 sIoU vs GPT-4o 34.8 sIoU），但联合建模在通用视频理解（Video-MME）上更具优势。哪种实验能定输赢：在同时包含定位与语义推理的复合任务上，对比解耦与联合架构的性能。未定论原因在于现有基准往往分离评估定位与语义，缺乏能同时衡量两者权衡的复合基准。时间幻觉缓解是第三核心分歧，训练阶段（CRPO, Structured Rewards）通过反事实训练或结构化奖励，从根源上增强时序敏感性；解码阶段（SEASON, VADER）通过对比解码或去偏解码，在推理时抑制幻觉 Token。现有证据表明，解码阶段方法（SEASON）无需重新训练，部署成本低，但效果有限；训练阶段方法（CRPO）效果更持久，但计算成本高。哪种实验能定输赢：在相同模型骨干上，对比训练阶段与解码阶段方法在时序幻觉基准（Spatiotemporal Sycophancy）上的鲁棒性。未定论原因在于解码阶段方法可能掩盖而非解决根本问题，缺乏对模型内部时序表征机制的深入分析。

### 3.3 其他开放问题

当前领域面临“工程问题”与“研究问题”的双重挑战。最紧迫的工程问题是流式视频中的记忆-实时性冲突，长视频的高效 Token 压缩。WeaveTime 通过动态记忆控制实现了在线交互，但记忆管理复杂，延迟优化困难。MOSS-Video-Preview 通过交叉注意力实现了感知与生成的并行，但推理复杂度增加。关键困难在于如何在有限内存下平衡历史记忆与实时响应，研究路径包括动态记忆缓存、异步双代理框架等。最根本的研究问题是模型如何真正利用视觉时序证据而非语言先验，时间幻觉的内在机制是什么。SEASON 通过对比解码抑制幻觉 Token，CRPO 通过反事实训练增强时序敏感性，但均未完全揭示幻觉的内在机制。关键困难在于缺乏对模型内部时序表征机制的深入分析，研究路径包括注意力可视化诊断、反事实视频生成等。已知的是，RL 是提升时序推理的关键，时空解耦提升定位精度，幻觉需通过训练或解码阶段干预缓解。争议的是，奖励信号设计、时空建模策略、幻觉缓解机制的最优选择。未知的是，时间幻觉的内在机制、模型如何真正利用视觉时序证据、流式理解中的记忆-实时性冲突的根本解决方案。未来趋势将依赖于更严格的逻辑基准与更精细的过程奖励机制，以及基于物理先验的时序建模与反事实强化学习，以突破语言先验的局限。

## 4. 总结与展望

视频时间理解已从感知任务演变为推理任务，核心矛盾在于 LLM 的语言先验优势与视频时序证据稀疏性之间的冲突。早期研究依赖特征流水线与任务特定回归头，受限于泛化性差与无法处理复杂语义推理。随着 MLLMs 的兴起，领域范式转向基于自然语言生成的统一框架，但引入了时间幻觉与逻辑不一致问题。为应对此问题，研究通过架构解耦（DIVID, BridgeSTG）与强化优化（TempR1, TimeThink）的协同，试图重建视觉证据的主导地位。架构解耦提供表征基础，通过分离时空特征提升定位精度与可解释性；强化优化提供优化动力，通过过程奖励或结果奖励提升推理精度；基准诊断提供验证工具，揭示模型在时序逻辑上的缺陷。然而，核心瓶颈依然存在：模型在开放世界视频和复杂场景下的泛化能力有限，时间幻觉的内在机制尚未完全揭示，流式理解中的记忆-实时性冲突仍未彻底解决。

未来可能突破的方向包括：基于物理先验的时序建模，通过引入物理规律增强模型对时序动态的感知；反事实强化学习，通过反事实视频生成与对比奖励，从根源上增强时序敏感性；跨视角一致性评估，通过多视角视频对比，提升模型在视角变化下的时序理解能力。这些方向需 ≥2 篇论文共同指向，如 CRPO 与 Structured Rewards 均指向反事实训练，WeaveTime 与 MOSS-Video-Preview 均指向流式理解优化。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，构建能同时衡量定位精度与语义推理能力的复合基准，以隔离算法贡献并揭示模型在时序逻辑上的真实缺陷。
