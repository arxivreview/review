## 导读

自回归视觉生成旨在将大语言模型的序列预测范式迁移至视觉领域，其核心驱动力在于解决视觉理解与生成在表征层面的割裂。早期像素级自回归因序列过长导致计算低效，VQ-VAE 等离散化技术的引入确立了“编码器-量化器-解码器”框架，使 Transformer 得以处理视觉数据。然而，离散 Token 的量化误差与光栅扫描顺序的空间错位，长期制约着生成质量与效率。VAR 模型提出的 Next-Scale 预测范式，通过从粗到细的层级生成，显著提升了全局一致性并降低了推理步数，成为该领域的关键转折。随后，研究重心转向 Tokenizer 的语义-细节平衡、推理加速以及统一多模态建模，旨在构建兼具理解与生成能力的视觉智能体。各路线在保真度、效率与统一性之间做出了不同取舍，形成了当前多元并存的方法格局。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

自回归视觉生成的兴起，源于研究者试图将大语言模型在文本序列预测上的成功迁移至视觉领域，以实现视觉理解与生成的统一。这一迁移并非平滑过渡，而是由“表征瓶颈”和“结构错位”两大核心问题驱动的范式迭代。早期工作如 PixelRNN 和 PixelCNN 将图像视为一维序列，按光栅扫描顺序预测下一个像素值，奠定了视觉自回归建模的基础。然而，像素级序列长度随分辨率平方增长，导致计算效率极低且难以捕捉长距离依赖，这一根本缺陷促使研究者寻找更紧凑的视觉表征。

为了解决连续像素值难以直接进行序列建模的问题，VQ-VAE 引入了向量量化机制，将连续图像特征映射为离散码本索引。这一创新确立了“编码器-量化器-解码器”的两阶段生成框架，使得 Transformer 等离散序列模型能够应用于图像生成。VQGAN 进一步通过引入对抗损失和感知损失，提升了离散视觉分词器的重建保真度，证明了联合训练可以弥补量化误差带来的细节丢失。至此，视觉自回归领域完成了从“像素序列”到“离散 Token 序列”的第一次范式跃迁，解决了“能不能做”的问题，但量化误差导致的语义-细节权衡成为新的瓶颈。

随着离散 Token 范式的成熟，光栅扫描顺序与二维空间结构的不匹配问题日益凸显。将二维图像展平为一维序列破坏了自然的空间局部性，导致全局结构一致性差，且顺序预测机制使得生成高分辨率图像需要数千次前向传播，推理延迟高企。VAR 模型的提出标志着第二次关键转折，它将预测单元从“下一个 Token”转变为“下一个尺度”，通过从粗到细的层级生成策略，显著提升了生成质量并大幅降低了推理步数。这一范式转变不仅解决了空间结构错位问题，还使自回归模型在保真度上首次具备与扩散模型竞争的实力。

在基础架构趋于稳定后，研究重心逐渐从单一图像生成扩展至多模态统一建模、视频生成及智能体应用。当前的核心问题已演变为：如何在统一的离散或连续表征空间中，同时满足视觉理解对高层语义的依赖和视觉生成对底层高频细节的需求。单一 Tokenizer 难以兼顾两者，导致统一模型中理解与生成能力相互制约。此外，自回归推理的高延迟、生成多样性与质量的平衡、以及长序列依赖下的全局一致性，仍是亟待解决的挑战。

从约束演化史来看，2016 至 2018 年，PixelRNN 和 VQ-VAE 奠定了离散化基础，主要约束是计算效率与序列长度。2020 至 2022 年，Parti 等工作验证了离散视觉 Token 与语言模型架构的兼容性，约束转向生成质量与开放域泛化能力。2024 年，VAR 的 Next-Scale 范式解决了空间结构错位与推理效率问题，约束进一步细化为跨尺度误差累积与细节恢复。2025 至 2026 年，随着 ARM、UniAR 等统一多模态模型的出现，约束演变为理解与生成的表征冲突、推理加速的工程落地，以及代理式视觉生成的复杂任务处理能力。

这一演进过程揭示了子问题间的严格依赖关系：首先必须解决“表征问题”，即如何构建适合序列建模的视觉 Token，这是基础；其次解决“架构与效率问题”，即如何高效预测这些 Token，如 Next-Scale 与 Next-Token 的选择；最后才能解决“应用与统一问题”，即如何利用该架构实现理解与生成的统一及复杂任务。若 Tokenizer 无法平衡语义与细节，后续的统一建模将因表征冲突而失效。

**如果用一个核心问题概括该领域，那便是：如何在保持自回归模型序列建模优势的同时，通过重构视觉表征与生成顺序，克服离散化带来的细节丢失与顺序预测的效率瓶颈，从而实现视觉理解与生成的高质量统一。**

## 2. 方法体系

- 2016：PixelRNN/PixelCNN——提出像素级自回归生成范式，奠定视觉自回归建模基础

- 2017：VQ-VAE——引入向量量化机制，确立离散视觉 Token 两阶段生成框架

- 2021：VQGAN——引入对抗损失，提升离散分词器重建保真度

- 2024：VAR——提出 Next-Scale 预测范式，实现从粗到细的层级生成

- 2025：TiTok——提出基于查询的 1D 视觉分词器，解决 2D 网格与 1D 因果性不匹配

- 2025：Speculative Decoding——引入推测解码机制，加速自回归推理过程

- 2026：ARM——构建统一离散表征的大型多模态模型，实现理解与生成协同

这条时间线勾勒了该领域方法演进的代表性节点：从 2016 年的 PixelRNN/PixelCNN 奠定该领域方法基线，经 2017 年 VQ-VAE 的推进，到 2026 年的 ARM 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 视觉分词与表征

视觉分词器是连接像素空间与序列建模空间的核心桥梁，其设计直接决定生成质量的上限。早期 VQ-VAE 和 VQGAN 采用固定码本的向量量化，虽然解决了离散化问题，但面临量化误差和码本利用率不足的挑战，导致高频细节丢失。为了解决语义抽象与像素细节的权衡问题，近期研究转向层级残差结构和因果约束分词器。ResTok（Zhang et al., 2026, P26）提出了一种层级残差 1D 视觉分词器，通过沿深度和层级两个维度查询特征，利用残差量化机制捕捉图像的多尺度细节。该方法将层级信息显式编码到 Token 序列中，使得自回归模型能够更有效地学习从粗到细的生成过程，在保持紧凑序列长度的同时提升了重建保真度。

针对 2D 网格光栅扫描与 1D 自回归因果性不匹配的问题，End-to-End 1D Semantic Tokenizer（Chu et al., 2026, P41）设计了一种基于 ViT 的端到端 1D 语义分词器。该方法通过可学习查询 Token 将 2D 图像块压缩为 1D 顺序潜变量，摒弃了传统的 2D 网格光栅扫描，直接学习符合自回归因果性的序列结构。其关键技术在于联合训练分词器与生成器，确保潜变量空间既包含语义信息又适合序列预测，显著提升了自回归模型对全局结构的捕捉能力。相比之下，MingTok（Huang et al., 2025, P8）构建了一个统一的连续视觉分词器，采用三阶段顺序架构，通过不同的掩码策略处理视觉 Transformer 块，实现了紧凑且高维的 Patch 表征。MingTok 旨在解决离散分词器的量化误差问题，通过连续表征提升生成质量，为统一视觉语言模型提供了灵活的分词方案，但其训练复杂度高于离散方法。

CaTok（Chen et al., 2026, P34）则提出了一种基于 MeanFlow 的 1D 因果图像分词器，利用视觉基础模型稳定并加速扩散自编码器训练。该方法通过 Rectified Flow 和 MeanFlow 模型学习条件速度场，实现了从噪声到图像的高效映射，解决了传统分词器训练不稳定的问题。CaTok 的核心创新在于将因果性约束融入分词器设计，确保生成的 1D 序列符合自回归预测的需求，在重建保真度和语义对齐方面表现更优。此外，STAT（Chen et al., 2026, P27）提出了一种内容自适应的视觉分词器，通过软尾部丢弃策略根据图像复杂度动态分配潜变量 Token 数量，打破了固定 2D 网格的限制，支持 1D 自回归生成，通过自适应压缩提升了生成效率。这些分词器设计的演进，为后续生成范式提供了更优的表征基础，与生成架构路线形成互补关系。

### 2.2 生成范式与架构

生成范式与架构的创新旨在平衡效率与质量，核心在于重构 Token 预测顺序与依赖关系。VAR 模型提出的 Next-Scale 预测范式，将图像生成分解为从粗到细的多尺度 Token 映射预测，取代了传统的单 Token 顺序预测。这一创新大幅减少了自回归步数，提升了生成效率与全局结构一致性，标志着视觉自回归从 Token 级向 Scale 级建模的范式转变。然而，VAR 模型中全上下文依赖导致的误差累积问题仍未完全解决。Markovian Scale Prediction（Zhang et al., 2025, P16）针对这一问题，提出了一种马尔可夫尺度预测方法，通过限制当前尺度仅依赖前一个尺度，简化了依赖关系，提升了模型训练的稳定性，避免了早期预测错误的持续传播。

EAR（Yang et al., 2025, P14）则从人类视觉感知角度出发，提出了一种基于视觉注视的图像扩展自回归建模方法。该方法模拟视觉注视从中心向外扩展的过程，通过动态调整生成顺序，优先处理图像中心区域，逐步扩展至边缘，解决了光栅扫描顺序与人类视觉习惯不匹配的问题。Radial-Parallel AR（Wang et al., 2025, P24）进一步提出了一种径向并行自回归建模方法，通过同心圆式扩展生成图像，打破了传统光栅扫描的线性依赖，利用径向依赖关系实现高度并行的扩展，显著减少了自回归步数。BitDance（Ai et al., 2026, P30）则从 Token 表示角度入手，提出了一种基于二进制 Token 的自回归生成模型，通过二进制量化替代传统向量量化，解决了码本利用率和量化误差问题，提升了 Token 的表达能力和模型的扩展性。

IAR2（Yi et al., 2025, P9）观察到邻近嵌入代表相似 Patch，通过码本重排和聚类导向交叉熵损失，利用嵌入空间结构增强生成鲁棒性，使预测目标从精确 Token 放宽到正确聚类，缓解了离散 Token 预测的脆弱性。SSG（Shin et al., 2026, P29）针对 VAR 模型在训练-推理差异下的性能下降问题，提出了一种缩放空间引导方法，通过放大语义残差增强多尺度视觉自回归生成的细节恢复能力，改善了复杂场景下的生成质量。BAR（ICLR 2026, P54）则从线性代数角度重构自回归建模，通过重新定义 Token 子空间投影，解决光栅扫描顺序导致的结构偏差问题，为视觉自回归模型提供了更严谨的数学基础。这些架构创新与分词器路线紧密关联，共同推动了自回归视觉生成从“能生成”向“高质量、高效生成”的转变。

### 2.3 推理加速与优化

自回归模型的高计算开销是落地应用的关键瓶颈，推理加速与优化路线旨在通过并行解码、剪枝和动态计算分配实现无损或低损的快速生成。StepVAR（Liu et al., 2026, P32）提出了一种结构-纹理引导剪枝方法，通过 PCA 保留结构完整性和高通滤波保留纹理保真度，设计了双准则 Token 选择策略，确保剪枝后的稀疏 Token 仍能重建高分辨率特征图，显著降低了推理延迟。StageVAR（Li et al., 2025, P20）则提出了一种阶段感知加速方法，通过分析 VAR 模型中语义无关性和低秩特性，动态调整采样过程中的计算资源分配，利用低秩近似减少冗余计算，实现了无损或低损的加速。

Depth Adaptive Efficient VAR（Li et al., 2026, P38）提出了一种深度自适应高效视觉自回归建模方法，通过动态激活输入特定的子网络，减少 Transformer 层的计算量。该方法基于早期退出机制，根据 Token 的置信度或特征重要性决定是否需要经过后续层，实现了计算资源的按需分配。ToProVAR（Chen et al., 2026, P31）提出了一种三维熵感知语义分析与稀疏优化方法，通过全局和细节范围的 Token 级优化加速 VAR 模型，结合频率基 Token 剪枝和模型基尺度/分支跳过，实现了多层次的高效推理。SSD（Xiang et al., 2026, P47）则提出了一种空间推测解码方法，利用空间先验并行生成候选 Token 序列，并由主模型验证以加速自回归图像生成，解决了统一视觉语言模型中 2D 图像扁平化为 1D 序列导致的空间先验丢失问题。

ActVAR（Zhang et al., 2025, P13）提出了一种激活混合权重和 Token 的方法，通过动态路由选择激活的专家网络和 Token 子集，加速视觉自回归生成。Dynamic MoE for VAR（Vincenti et al., 2025, P10）则提出了一种动态混合专家路由方法，集成到 VAR 模型中，通过尺度感知阈值平衡专家选择与 Token 复杂度，实现了计算与质量的权衡。SoftCFG（Xu et al., 2025, P3）针对 CFG 在 AR 模型中引导信号随生成步骤衰减的问题，提出了一种不确定性引导的稳定引导方法，通过软扰动机制优化自回归模型中的无分类器引导，提升了条件生成的准确性。这些加速技术与生成架构路线互补，共同解决了自回归模型在高分辨率生成中的效率瓶颈。

### 2.4 训练策略与对齐

训练策略与对齐路线聚焦于解决自回归模型训练动力学优化问题，旨在提升收敛速度与生成质量。REAR（He et al., 2025, P7）提出了一种生成器-分词器一致性正则化方法，通过约束自回归生成器与视觉分词器的表征空间对齐，解决两阶段训练中的目标不一致问题。该方法分析了生成器预测的 Token 分布与分词器重建分布之间的偏差，引入正则化项最小化两者差异，提升了模型收敛速度和生成稳定性。Mirai（Yu et al., 2026, P28）则提出了一种基于前瞻对齐的自回归视觉生成训练方法，通过引入双向或单向编码器的前瞻信息，增强自回归模型的全局结构捕捉能力，解决了局部一致但全局不一致的问题。

Self-Guided Training（Yue et al., 2025, P1）提出了一种自引导训练方法，通过利用模型自身生成的中间结果作为监督信号，提升自回归图像生成的质量。该方法分析了注意力图在生成过程中的分布，发现条件 Token 和空间邻近 Token 获得最高注意力，据此设计自引导策略，减少了对外部监督的依赖。VA-π（Liao et al., 2025, P21）提出了一种变分策略对齐方法，通过像素感知的变分策略优化，将自回归生成器的输出对齐到真实数据流形，解决了 Token 级预测与像素级质量之间的脱节问题。VAR RL Done Right（Sun et al., 2026, P25）则提出了一种解决异步策略冲突的强化学习对齐方法，针对 VAR 模型中跨尺度 Token 网格的异构性，设计前缀掩码传播机制，确保了不同尺度 Token 预测的一致性。

Rethinking Training Dynamics（Zhou et al., 2025, P19）提出了一种尺度级自回归生成训练动力学分析方法，通过学生强制训练加速早期优化，提升模型收敛速度。该方法分析了不同生成范式下的训练动态，发现尺度级 AR 模型在早期优化中表现更优，据此设计学生强制策略，减少了早期训练的不稳定性。UniAR（Peng et al., 2026, P46）提出了一种统一多模态自回归建模方法，通过共享上下文视觉分词器对齐理解与生成的表征空间，实现单一架构下的协同处理，解决了理解任务依赖高层语义而生成任务依赖低层细节的矛盾。Learning from Next-Frame Prediction（Li et al., 2025, P22）则提出了一种基于下一帧预测的自回归视频建模方法，通过生成式预训练学习有效视频表征，提升了模型对时序依赖的捕捉能力。这些训练策略与分词器、架构路线紧密关联，共同提升了自回归模型的生成质量与稳定性。

### 2.5 统一多模态建模

统一多模态建模路线旨在在同一架构内同时实现视觉理解与生成，通过共享视觉分词器或连续潜空间，消除模态间的壁垒。Visual Generation Tuning（Guo et al., 2025, P17）提出了一种视觉生成调优方法，通过自蒸馏损失约束 VAE 潜变量分布，解决预训练 VLM 语义编码器与自回归建模的对齐问题，提升了生成质量。OmniGen-AR（Wang et al., 2026, P44）提出了一种任意到图像生成的自回归方法，通过共享视觉分词器离散化文本、参考图像、空间布局等多种条件，实现统一的多模态生成，支持图像编辑、风格转换等复杂任务。

Beyond Text Prompts（Liu et al., 2026, P42）提出了一种视觉到视觉生成统一范式，将草图、调色板、参考板等视觉工件作为直接生成条件，取代文本提示，解决了文本提示无法准确表达视觉意图的问题。VisionCreator（Lai et al., 2026, P33）提出了一种原生视觉生成智能体模型，集成理解、思考、规划和创造能力，实现复杂视觉生成任务的自主执行。VisionCreator-R1（Lai et al., 2026, P35）则提出了一种反思增强的原生视觉生成智能体模型，通过 Act-Reflect-Think-Act 动态循环实现自我修正，提升了任务执行的准确性。ARM（Wang et al., 2026, P45）提出了一种统一离散表征的自回归大型多模态模型，通过共享视觉分词器将图像、文本等多模态数据映射至同一 Token 空间，支持图像到文本、文本到图像等多样任务，代表了多模态自回归建模的最新进展。

CPC-VAR（Li et al., 2026, P43）提出了一种持续个性化与组合生成方法，在 VAR 框架下解决用户概念随时间演化和多概念组合的问题，通过选择性层微调实现个性化定制。VISTA（Shahabadi et al., 2026, P51）则提出了一种测试时组合对齐方法，针对 VAR 模型在复杂场景下的组合泛化问题，通过测试时优化提升生成质量，无需重新训练模型。这些统一多模态模型与前述分词器、架构、训练策略路线深度融合，代表了自回归视觉生成从单一任务向通用视觉智能体演进的最新方向。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

自回归模型在视觉生成领域已具备与扩散模型竞争的实力，尤其在推理效率和多模态统一性方面具有独特优势。这一共识在多个基准上被反复验证：BAR 的 1.15 与 IAR2 的 1.50 均大幅超越经典 VAR 的 1.92，且自回归模型在统一多模态任务上展现出更强的架构兼容性。离散视觉 Tokenizer 是连接像素空间与序列建模的关键，但其设计对最终生成质量具有决定性影响。ResTok 和 End-to-End 1D Semantic Tokenizer 的 1.48 FID 表明，优化分词器设计可显著提升生成保真度，而 STAT 和 VibeToken 的 2.09 FID 则说明固定分辨率分词器在动态场景下的局限性。

与此相关的另一个共识是，传统的下一词元预测范式在视觉领域存在效率和质量瓶颈，向下一尺度预测或并行化预测的演进是提升性能的重要方向。VAR 的 Next-Scale 范式通过从粗到细的层级生成，显著提升了全局一致性并降低了推理步数，而 EAR 和 Radial-Parallel AR 的感知驱动和径向并行策略进一步验证了生成顺序优化对效率和质量的双重收益。视觉理解与生成需要统一的表征空间，单一 Tokenizer 难以兼顾语义与细节，因此开发支持双目标的统一 Tokenizer 或混合架构是统一多模态模型的核心挑战。ARM 和 UniAR 的 1.92 FID 表明，统一多模态模型在保持生成质量的同时实现了理解与生成的协同，但其优势主要体现在任务灵活性而非单纯的 FID 指标上。

### 3.2 观点分歧

离散 Token 与连续 Latent 之争是领域内的核心分歧。离散派认为离散 Token 是 LLM 架构兼容性的关键，便于利用 NLP 领域的成熟技术，且计算效率高，代表方法如 VAR 和 LlamaGen。连续派则认为连续 Latent 能保留更多细节信息，避免量化误差，生成质量更高，代表方法如 MingTok 和 CaTok。现有证据偏向混合架构：纯离散模型在 ImageNet FID 上表现优异，但在开放域文本生成中细节模糊；连续模型在细节保真度上更优，但训练不稳定。哪种实验能定输赢？需要在同一架构下，对比离散与连续 Token 在“高频细节恢复”和“语义对齐”上的权衡曲线，并评估其在大规模多模态任务上的泛化能力。分歧根源在于测量工具盲区：现有指标（FID）主要反映分布距离，无法精细捕捉局部细节差异；场景依赖：在类别条件生成中离散占优，在开放域文本生成中连续可能更优，缺乏统一的评测基准。

这一分歧的背后，是另一个更根本的争论：Next-Token 与 Next-Scale 生成顺序的最优策略。Next-Token 派认为线性序列预测符合自回归本质，局部细节即时生成，灵活性高，易于扩展至任意分辨率，代表方法如 LlamaGen 和 EAR。Next-Scale 派认为层级生成符合人类视觉认知，全局一致性好，推理步数少，效率高，代表方法如 VAR 和 Markovian Scale Prediction。现有证据偏向 Next-Scale：VAR 在 ImageNet 256x256 上 FID 1.92，优于 LlamaGen 的 2.09，且推理速度更快。但 Next-Scale 在跨尺度误差累积和动态分辨率支持上存在挑战。哪种实验能定输赢？需要在“动态分辨率生成”和“长序列依赖”任务上对比两者，评估 Next-Scale 在尺度切换时的误差传播机制，以及 Next-Token 在高分辨率下的全局一致性表现。分歧根源在于证据不足：Next-Scale 模型在高分辨率和动态宽高比场景下的表现数据较少；场景依赖：Next-Scale 在固定分辨率类别生成中占优，但在开放域、多条件生成中可能不如 Next-Token 灵活。

### 3.3 其他开放问题

最紧迫的工程问题是推理加速的无损化与实时化。当前 StepVAR、SSD 和 ActVAR 等方法虽在保持 1.92 FID 的同时提升了效率，但缺乏具体的加速比和延迟数据，且部分方法引入了系统复杂度。关键困难在于如何在动态分辨率和高分辨率场景下保持加速效果，研究路径包括开发更精细的 Token 剪枝策略和更高效的推测解码机制。最根本的研究问题是理解与生成的表征统一。当前 ARM 和 UniAR 等统一模型在保持生成质量的同时实现了理解与生成的协同，但在细粒度编辑和理解任务上仍有局限。关键困难在于单一 Tokenizer 难以同时满足高层语义和底层细节的需求，研究路径包括设计多级特征或双码本结构，以及探索共享连续表示空间。

归纳“已知—争议—未知”认知图谱：已知自回归模型在推理效率和多模态统一性上具有独特优势，离散 Tokenizer 是连接像素与序列的关键；争议在于离散 vs 连续表征的最优形式，以及 Next-Token vs Next-Scale 生成顺序的最优策略；未知在于组合泛化的内在机制、理解与生成的根本性解决方案，以及长序列视频生成的时空依赖建模。发展趋势表明，领域正从“架构优化”转向“表征统一”与“智能体化”，未来随着统一 Tokenizer 和代理式架构的成熟，自回归模型有望成为通用视觉智能体的核心。

## 4. 总结与展望

自回归视觉生成通过“离散化”和“层级化”两大创新，成功将 LLM 范式引入视觉领域，并在效率与统一性上展现出超越扩散模型的潜力。核心矛盾在于离散 Token 的语义抽象能力与像素级细节保真度之间的张力，以及光栅扫描顺序与二维空间结构的不匹配。尝试过的路线包括 VQ-VAE/VQGAN 的离散化基础、VAR 的 Next-Scale 范式、以及 ARM/UniAR 的统一多模态建模。核心瓶颈在于如何在统一表征空间中平衡理解与生成的需求，并实现高效、可控的复杂视觉任务执行。回扣第 1 章锚点句，该领域仍需解决如何在保持自回归模型序列建模优势的同时，通过重构视觉表征与生成顺序，克服离散化带来的细节丢失与顺序预测的效率瓶颈。

未来可能突破的方向包括：统一视觉理解与生成，需探索共享连续表示空间或统一 tokenizer，以解决理解与生成任务间的语义对齐难题；高效推理与加速，需开发动态稀疏化、剪枝、投机解码等技术，通过利用 token 冗余和语义熵，在不牺牲质量的前提下显著降低 FLOPs 和延迟；代理式视觉生成，需研究具备理解、思考、规划和创建能力的代理式模型，通过多步工具调用、反思机制和长程规划，实现复杂视觉创作任务的自动化执行。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，系统评估离散 vs 连续表征在高频细节恢复和语义对齐上的权衡曲线，为未来统一多模态模型的设计提供实证基础。
