## 导读

稠密检索优化旨在突破传统稀疏检索在语义理解上的局限，其核心在于构建能够捕捉复杂逻辑与细粒度语义的向量表示空间。早期研究以双编码器架构为主线，通过内积计算相关性确立了开放域检索的基础范式，思路简洁却受制于表示容量与计算成本的张力。当大语言模型嵌入的高维特性暴露出工业部署的内存瓶颈后，研究者转向马特罗什卡表示学习与向量量化，用灵活的维度截断换取存储效率。随着推理密集型基准的出现，领域进一步从静态语义匹配转向推理感知检索，通过潜在推理机制处理多跳查询，由此形成当前效率、精度与智能性并重的方法格局。本综述梳理这条从几何度量到推理内化的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

稠密检索优化的起源在于解决传统基于关键词匹配方法在语义理解上的根本局限。在开放域问答等任务中，查询与文档之间常存在词汇不匹配，导致基于词频的稀疏检索召回率低下。为此，研究者提出双编码器架构，将查询和文档独立映射到共享的向量空间，并通过内积计算相关性。这一范式不仅支持离线索引构建，还使得近似最近邻搜索成为可能，从而确立了现代信息检索的主流技术路线。该架构的核心假设是：语义相似性可以通过向量空间中的几何距离来有效度量，且这种度量在静态语料库上是稳定的。

随着问题场景从简单的语义匹配扩展到复杂逻辑推理，问题定义发生了深刻演化。早期的核心任务被形式化为 N-way K-shot 检索，即给定查询 $q$ 和文档集合 $D$，寻找使相似度函数 $sim(q, d)$ 最大化的文档 $d^*$。然而，当查询涉及多跳推理或组合逻辑时，静态嵌入无法捕捉查询内部的逻辑推导过程。此时，问题结构从单纯的“语义对齐”转变为“推理感知的语义对齐”，子问题之间形成了新的依赖关系：推理增强依赖于更复杂的训练数据（如包含推理路径的实例），而高效索引则是高维推理模型落地的工程前提。

在范式边界上，稠密检索并未完全取代稀疏检索，而是通过混合检索实现互补。稀疏检索在精确词汇匹配上具有不可替代的优势，而稠密检索在语义泛化上表现更优。这种互补性催生了查询自适应路由机制，即根据查询特征动态选择稀疏或稠密检索器。此外，领域适应与数据稀缺成为垂直应用中的关键约束，通用模型在医疗、法律等特定领域性能下降，且企业数据缺乏标注，迫使研究转向无监督微调和合成数据生成。

从约束演化史来看，2016 至 2018 年间，Sentence-BERT 和 DPR 奠定了双编码器范式，主要关注训练数据质量和负样本挖掘。2020 年前后，ColBERT 引入晚期交互机制，解决了单向量在复杂查询中语义捕捉不足的问题，但带来了巨大的计算开销。2021 年，ANCE 通过异步硬负例挖掘提升了模型对细微语义差异的区分能力，而 Contriever 则实现了无监督预训练，降低了标注依赖。

2023 至 2024 年，随着 LLM 嵌入模型的兴起，维度爆炸成为主要矛盾。Matryoshka Representation Learning 的提出允许模型在不同维度截断下保持性能，为嵌入压缩提供了理论基础。与此同时，向量量化技术被引入以降低存储精度，平衡精度与效率。这一阶段的方法演进核心在于应对 LLM 带来的高维向量存储与计算开销，工程约束开始反向驱动算法设计。

2025 至 2026 年，研究重心转向推理感知与几何创新。ReasonIR 和 RGLT 等方法将推理机制注入嵌入模型，处理多跳及指令遵循任务。HypRAG 则将嵌入空间从欧氏空间迁移至双曲空间，利用黎曼几何特性更好地保留文档层级结构。当前形态呈现出“推理内化”与“效率极致化”并行发展的趋势，核心问题是如何在保持推理能力的同时，通过几何创新和系统优化实现低成本部署。

**如果用一个核心问题概括该领域，那便是：在有限计算资源约束下，如何构建能够同时捕捉细粒度语义、复杂逻辑推理及动态上下文变化的向量表示空间，并实现其高效索引与检索。**

## 2. 方法体系

- 2019：Sentence-BERT——奠定双编码器范式基础

- 2020：DPR——确立开放域问答稠密检索标准流程

- 2020：ColBERT——引入晚期交互机制解决细粒度匹配

- 2021：ANCE——引入异步硬负例挖掘提升区分能力

- 2022：Contriever——实现无监督对比学习预训练

- 2024：Matryoshka Representation Learning——提供多尺度嵌入压缩理论

- 2025：ReasonIR——构建推理导向训练实例注入逻辑能力

- 2026：RGLT——实现非自回归隐式思维链联合优化

这条时间线勾勒了该领域方法演进的代表性节点：从 2019 年的 Sentence-BERT 奠定该领域方法基线，经 2020 年 ColBERT 的推进，到 2026 年的 Spectral Tempering 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 系统架构与几何

系统架构与几何路线起源于对嵌入空间几何特性的深入探索，旨在突破传统内积检索的理论限制。早期工作如 Sentence-BERT（Reimers and Gurevych, 2019）和 DPR（Karpukhin et al., 2020）假设语义匹配可通过静态双编码器在欧氏空间中实现，受限于 BERT 算力，主要关注训练数据质量和负样本挖掘。然而，欧氏空间在建模具有严格层级关系的文档集合时存在扭曲问题，且固定嵌入维度下可表达的相关性模式存在几何极限。

HypRAG（Madhu et al., 2026, P6）针对欧氏空间在层级数据上的局限，将嵌入空间迁移至双曲空间。该方法设计了两阶段训练流程，首先进行双曲掩码语言建模，随后进行无监督对比预训练，所有相似度计算均基于测地线距离。其核心创新在于引入几何感知聚合算子，解决了朴素池化策略在双曲空间中的失效问题。HypRAG 放弃了欧氏空间的计算简便性，换取了对文档层级结构更好的建模能力，特别适用于法律条款、生物分类等层级明显的场景。

Query-Aware Adaptive Dimension Selection（Wu et al., 2026, P5）则从维度冗余角度出发，提出查询感知的自适应维度选择方法。该方法通过学习每个查询的维度重要性预测器，仅保留对相关性贡献最大的维度子集。与 Matryoshka 等固定截断方法不同，它将维度选择从静态过程转变为动态查询感知过程，解决了高维嵌入中维度冗余问题。其代价是预测器训练需额外标注数据，且维度选择可能引入噪声。

Voronoi Bottleneck（Balne et al., 2026, P15）提供了该路线的理论基础，证明 Voronoi 复杂度与符号秩等价，揭示了固定嵌入维度下可表达的相关性模式存在几何极限。该方法推导了 Top-1 检索的紧维度界限，并提出了可计算的诊断工具，用于评估检索系统的容量瓶颈。MLR（2025, P24）则探索了编码器内部多层语义信息，发现最后几层与较小向量数组合能有效超越基线，为提升单向量检索精度提供了新的架构思路。

### 2.2 高效索引与压缩

高效索引与压缩路线聚焦于降低大规模稠密检索系统的存储开销与推理延迟，是复杂模型落地的工程前提。随着 LLM 嵌入模型维度增加（如 4096 维），内存和带宽需求呈线性增长，导致工业部署成本高昂。该路线的核心取舍在于放弃部分浮点精度或维度，换取大规模部署的可行性。

Spectral Tempering（Li et al., 2026, P9）提出一种基于谱分析的嵌入压缩方法，通过推导维度自适应的温度指数直接优化高维嵌入的存储效率，无需模型微调或标注数据。该方法首先对语料库嵌入进行谱分解，分析特征值分布，随后基于信噪比引导推导温度指数。相比固定参数的 PCA 或白化方法，Spectral Tempering 能更好地保留几何结构，且对不支持 Matryoshka 学习的模型具有通用性。其主要代价是计算谱分解的初始开销，但后续推理阶段无需额外计算。

SSR（Guo et al., 2026, P12）针对多向量检索中存储与计算开销过大的问题，提出单阶段稀疏编码方法。该方法将文档 Token 映射到稀疏编码空间，利用激活神经元 ID 构建倒排索引，在候选生成阶段通过稀疏匹配快速筛选。SSR 摒弃了 K-means 等聚类引擎，直接利用稀疏自编码器特性实现高效索引，减少了索引构建的复杂度与存储冗余。其核心创新在于以稀疏激活神经元 ID 替代传统的聚类中心映射，主要代价是稀疏编码的稀疏度需仔细调优，过高的稀疏度可能导致召回率下降。

Autoencoder vs Quantization（Pati, 2025, P4）系统性对比了自编码器维度缩减与量化精度降低两种向量压缩策略。实验发现量化在低压缩比下性能损失极小，而自编码器在高压缩比下性能衰减显著，揭示了维度信息对语义保留的关键作用。Latent Terms（Clavié et al., 2026, P11）则从可解释性角度切入，提出从稠密检索器中提取 Zipfian 词汇表的方法，利用稀疏自编码器将稠密激活分解为稀疏特征，发现这些特征可直接用于 BM25 检索，揭示了稠密检索与稀疏检索的内在联系。

### 2.3 训练优化与数据

训练优化与数据路线探索对比学习损失函数改进、合成数据增强及难负例挖掘策略，以提升稠密检索模型在垂直领域及零样本场景下的泛化能力。该路线的核心在于解决数据稀缺与标注成本高的挑战，通过更高效的训练信号设计提升模型性能。

OPERA（Fang et al., 2026, P8）提出在线数据剪枝方法，通过动态选择高信息量样本进行检索模型适配。该方法在标准对比学习框架基础上，引入在线剪枝机制，根据查询与文档的更新间隔动态调整采样概率，优先选择对模型更新贡献大的样本。其核心创新在于将数据剪枝与在线学习结合，避免了离线剪枝对分布漂移的敏感性，实现了高效且鲁棒的模型适配。主要取舍是剪枝策略需平衡信息量与多样性，过度剪枝可能导致模型泛化能力下降。

LLM-Based Data Augmentation（2025, P23）系统评估了基于 LLM 的数据增强在检索任务中的有效性与可扩展性。研究发现对于 100M-300M 参数的小模型，适度的数据增强能显著提升性能，但过度增强会导致冗余信号干扰。HN-CLIP（Liu et al., 2026, P18）针对稠密字幕微调中 InfoNCE 损失饱和问题，提出自适应相似度边距方法，通过文本相似度矩阵生成逐负例自适应边距，保持梯度活性。该方法无需辅助数据或架构修改，仅通过损失函数调整即可解决难负例学习问题。

PAO（Wei et al., 2026, P19）提出基于在线强化学习的查询编码器微调方法，将检索对齐任务建模为 MDP，利用下游重排器作为奖励信号。该方法识别出标准策略梯度在检索任务中的失败模式，即更新导致嵌入进入语义空洞，因此提出选择性 RL 方法，仅对正优势样本应用更新。其核心创新在于将 RL 引入检索微调，通过奖励信号引导查询编码器适应重排器偏好，同时避免灾难性遗忘。主要代价是 RL 训练不稳定，且依赖高质量的重排器作为奖励模型。

### 2.4 推理增强检索

推理增强检索路线聚焦于在嵌入空间或查询预处理阶段引入显式或隐式推理机制，以解决复杂逻辑、多跳及指令遵循等推理密集型检索任务中的语义匹配难题。该路线的核心取舍在于放弃低延迟，换取对复杂逻辑的处理能力。

AdaQR（Zhang et al., 2025, P2）提出一种将稠密检索器转化为高效推理器的框架，通过查询重写机制利用大型语言模型对复杂查询进行内在解决方案的推理。该方法核心在于引入查询推理器，将原始查询转化为包含逻辑推导过程的增强查询，再交由嵌入模型编码。其技术优势在于无需修改底层嵌入模型架构，仅通过预处理阶段的推理增强即可提升检索精度。主要代价是引入了 LLM 推理的计算开销，且推理质量依赖于 LLM 的能力，存在延迟增加的风险。

RGLT（Zhou et al., 2026, P16）提出检索接地潜在推理技术，通过在输入序列末尾附加固定数量的潜在推理 Token，以非自回归方式构建隐式思维链轨迹。该方法摒弃了传统查询扩展中生成文本再编码的两阶段流程，直接在嵌入空间内通过潜在 Token 承载推理信息，避免了自回归生成带来的延迟及生成文本质量对检索结果的依赖。RGLT 代表了从显式文本推理向隐式向量推理演进的重要方向，显著提升了复杂查询下的检索鲁棒性，但推理能力的上限受限于模型对潜在语义的建模能力。

O1 Embedder（2026, P20）提出思维增强嵌入方法，通过多任务训练将预训练 LLM 微调为具备深度思考能力的嵌入模型。该方法包含两个并行训练任务：一是监督微调 LLM 以生成针对输入查询的最优思维链，二是利用对比学习为思维增强后的查询生成判别性嵌入。其技术核心在于将生成式思维过程与判别式检索目标无缝结合，主要代价是训练过程复杂，需要精心策划的长格式思维数据。

### 2.5 混合与动态检索

混合与动态检索路线研究稀疏与稠密信号的融合机制、查询自适应路由及动态索引更新策略，通过混合检索范式解决单一模态在词汇匹配与语义泛化间的权衡问题。该路线是解决单一范式局限的兜底方案，强调系统的自适应性与鲁棒性。

QuDAR（2026, P22）提出查询级双视角自适应检索方法，通过动态选择稀疏或稠密检索器，解决单一检索范式在词汇匹配与语义泛化间的权衡问题。该方法设计了查询格式与检索器类型的双维度适配机制，利用 LLM 或置信度分数动态路由查询至最优检索器，并融合结果。其核心创新在于将检索器选择从静态配置转变为查询感知动态决策，提升了 RAG 系统在多样化查询下的鲁棒性。主要代价是路由决策引入额外延迟，且需维护多个检索器索引。

NIE（Shah and Ozgur, 2026, P17）提出导航信息嵌入方法，利用智能体搜索轨迹作为监督信号，通过几何相关性衰减与排序损失，将导航路径结构注入稠密嵌入空间。该方法将智能体浏览文档序列建模为 MDP，终端文档权重最高，前序文档按几何级数衰减。其核心创新在于利用隐式反馈中的路径结构信息，无需人工标注即可实现检索模型适配，解决了分布漂移下的监督稀缺问题。

AURORA（2026, P21）提出神经符号持续索引方法，通过元学习加速检索模型对分布漂移的适应，解决 RAG 系统中索引静态性与查询动态性的矛盾。该方法利用元学习初始化模型权重，使其处于利于快速适应的吸引盆，并通过符号规则处理词汇差距，避免灾难性遗忘。TPOUR（Kim et al., 2026, P14）则提出时间偏好优化方法，将时间向量提取从无监督检索扩展至偏好对齐，实现检索器对未见中间及未来时间段的连续时间对齐，解决了传统检索模型在时间敏感任务上的泛化不足问题。

### 2.6 跨任务与多领域应用

上述五条路线在不同任务场景中展现出特定的适用性。在视觉文档检索任务中，MINER（Li et al., 2026, P10）通过挖掘多模态内部表示，结合 MoCa 等骨干网络，在 ViDoRe 基准上取得了领先性能，体现了架构与几何路线在多模态场景下的扩展能力。在企业邮件与消息检索中，CustomIR（Paull, 2025, P3）通过无监督微调已知文档语料库，在 Enron 和 Slack 数据集上显著提升了检索精度，验证了训练优化路线在垂直领域数据稀缺场景下的有效性。在对话记忆检索中，Training-Free Lexical-Dense Fusion（Lysenstøen, 2026, P13）通过无训练的词法-稠密融合策略，利用晚期交互机制提升了长对话记忆的检索效果，展示了混合检索路线在特定上下文场景中的优势。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

稠密检索在语义匹配和复杂查询理解上显著优于传统稀疏检索，已成为现代信息检索的主流范式。这一共识在 BEIR、MS MARCO 等多个基准上被反复验证：SSR-CLS 的 53.4 与 MINER (MoCa backbone) 的 59.1 均大幅超越传统稀疏检索基线，且 LLM 嵌入模型（如 Qwen3-Embedding）在通用性和复杂任务上优于基于 BERT 的编码器。然而，这一共识的边界在于，稀疏检索在精确词汇匹配上仍具有不可替代的优势，混合检索范式（如 QuDAR）通过动态路由实现了两者的互补，而非简单的替代。

与此相关的另一个共识是，对比学习结合难负样本挖掘是训练高性能 Dense Retriever 的标准且有效的方法。HN-CLIP 在 FiQA 上通过自适应边距解决 InfoNCE 饱和问题，PAO 通过 RL 微调优化难负例学习，均验证了难负样本挖掘对提升模型区分细微语义差异能力的关键作用。此外，向量压缩（量化、降维）是解决大规模检索系统内存瓶颈的必要手段，Spectral Tempering 和 SSR 等方法的实证结果进一步巩固了这一共识，表明在保持精度的前提下，压缩技术是实现工业部署的必经之路。

### 3.2 观点分歧

推理机制的显式与隐式之争是当前领域最核心的分歧。显式推理（如 AdaQR）通过 LLM 生成假设文档或重写查询，推理过程透明，可解释性强，且可复用现有 LLM 能力；隐式推理（如 RGLT）在嵌入模型内部通过潜在 Token 模拟推理，端到端优化，延迟低，但黑盒。现有证据偏向隐式推理在效率上更优，RGLT 在 BRIGHT 上与 AdaQR 持平但延迟更低。然而，显式推理在可解释性和调试上更有优势。这一分歧的背后，是另一个更根本的争论：推理过程是否应内化于嵌入表示中。缺乏统一的“推理质量”评测指标，目前仅用检索精度（nDCG）衡量，无法区分推理过程的逻辑正确性与检索结果的偶然匹配，导致分歧难以定论。

表示范式上，单向量+重排与多向量（Late Interaction）的优劣之争同样激烈。单向量检索效率高，结合强重排器可达到接近多向量的精度，且易于部署；多向量在细粒度语义匹配上具有理论优势，尤其在长文档和复杂查询中。在 MS MARCO 上，SSR（多向量稀疏化）达到 53.4，优于许多单向量模型，但在 BEIR 零样本任务上，单向量 LLM 嵌入表现强劲。证据强度中等，取决于任务类型：细粒度匹配任务偏向多向量，通用语义任务偏向单向量+重排。多向量方法的效率优化仍在早期，尚未在大规模真实场景中证明其端到端延迟可接受，这是分歧未决的关键原因。

### 3.3 其他开放问题

动态语料库下的索引更新成本是当前最紧迫的工程问题。当文档库更新时，重新计算所有文档嵌入（Re-indexing Tax）成本极高，AURORA 等持续学习方法刚起步，通过元学习加速适应，但元学习训练复杂，且符号规则需针对特定领域设计。研究路径包括神经符号持续学习、在线数据剪枝及轻量级索引更新，但如何在防止灾难性遗忘的同时保持索引一致性，仍是关键困难。

最根本的研究问题在于嵌入空间的容量极限与推理的内部化机制。Voronoi Bottleneck 理论表明固定维度存在容量极限，是否需转向动态维度或混合表示？HypRAG 证明双曲空间在层级数据上更优，但计算成本高，通用性待验证。归纳“已知—争议—未知”认知图谱：已知的是稠密检索优于稀疏、对比学习有效、压缩必要；争议的是推理机制显隐、表示范式单多、几何空间欧非欧；未知的是推理质量评测、大规模多向量效率、双曲空间通用性。未来趋势将是混合范式（稠密+稀疏+推理）和自适应系统（动态索引+几何选择）的并行发展。

## 4. 总结与展望

稠密检索优化领域的核心矛盾在于有限计算资源与复杂语义、推理需求之间的张力。从 DPR 到 RGLT，从 MRL 到 HypRAG，研究路线经历了从静态语义匹配到推理感知、从欧氏空间到非欧几何、从单一范式到混合动态的深刻演变。核心瓶颈在于如何在保持推理能力的同时，通过几何创新和系统优化实现低成本部署，以及如何在动态语料环境下维持索引的一致性与高效性。

未来可能突破的方向包括：一是推理机制的内化与评测标准化，RGLT 和 O1 Embedder 共同指向隐式推理的潜力，但需建立统一的推理质量评测指标；二是多模态与视觉文档检索的融合，MINER 和 ViDoRe 基准表明视觉布局信息的编码是提升检索精度的关键；三是神经符号持续学习，AURORA 和 OPERA 共同指向动态索引更新的高效解决方案。对于进入者，最值得做的一件事是在统一骨干与统一预训练条件下，系统评测显式与隐式推理机制在推理密集型基准上的性能与延迟权衡，为工业部署提供实证指导。
