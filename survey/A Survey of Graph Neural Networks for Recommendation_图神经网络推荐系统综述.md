# A Survey of Graph Neural Networks for Recommendation ｜图神经网络推荐系统综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Graph%20Neural%20Networks%20for%20Recommendation)

## 导读

图神经网络（Graph Neural Networks, GNNs）通过消息传递机制聚合用户-物品二部图中的高阶邻居信息，从根本上突破了传统协同过滤仅依赖一阶交互的表达能力瓶颈。早期研究聚焦于架构简化，LightGCN 等模型证明去除非线性变换的轻量级传播足以捕捉协同信号，确立了“简单即高效”的基准范式。随着工业界对十亿级节点实时服务的迫切需求，问题焦点从“如何算得准”转向“如何在动态图中算得快”，催生了端到端联合训练与生命周期协同设计。面对冷启动、流行度偏差及噪声干扰，当前研究正通过因果推断、多模态语义桥接及谱域分析，试图打破对 ID 嵌入的绝对依赖。各路线在计算效率、鲁棒性与语义泛化之间做出了截然不同的取舍，由此形成当前多元并存的方法格局。本综述梳理这条从拓扑传播到语义解耦的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

推荐系统旨在解决信息过载问题，其核心任务是从海量候选中筛选出符合用户偏好的内容。早期方法主要依赖矩阵分解与浅层协同过滤，但这类方法难以捕捉用户与物品之间复杂的高阶依赖关系。图神经网络的引入改变了这一局面：通过将用户和物品建模为二部图中的节点，将交互建模为边，GNN 利用消息传递机制迭代聚合局部邻居特征，从而学习包含高阶连通性信息的节点嵌入。这一范式转变使得模型能够隐式地建模“用户-物品-用户”的多跳路径，显著提升了推荐精度，确立了 GNN 在推荐领域的核心地位。

随着领域的发展，问题定义经历了显著的演化。最初，核心问题是“如何有效聚合高阶邻居信息”，此时假设交互图是静态且干净的，主要约束是计算复杂度。2020 年前后，LightGCN 的出现标志着范式的第一次转折：它证明在协同过滤任务中，复杂的特征变换与非线性激活并非必要，仅保留邻居聚合操作即可在保持高精度的同时大幅降低计算开销。这一发现确立了轻量级传播机制的标准范式，将研究重心从追求模型复杂度转向追求计算效率。

然而，当 GNN 从学术基准走向工业级部署时，新的约束条件浮现。十亿级节点图的构建、训练与服务带来了高昂的计算和内存开销，且用户兴趣随时间动态演变，静态图假设不再成立。2023 至 2024 年间，问题焦点转变为“如何在大规模动态图中实现实时且低成本的推理”。这催生了对端到端联合训练、增量更新策略以及全生命周期协同设计的需求。例如，E2E-GRec 和 RankGraph-2 等工作不再孤立优化单一阶段，而是试图打通图构建、模型训练与在线服务之间的壁垒，以解决两阶段流水线中梯度断裂与计算冗余的问题。

进入 2025 至 2026 年，领域进入了“规模化与鲁棒性”并重的新阶段。此时，问题定义进一步细化为如何在数据稀疏、噪声干扰及流行度偏差下实现公平泛化。冷启动问题（新物品缺乏交互历史）和跨域泛化能力不足成为主要痛点，传统依赖密集交互数据的 GNN 在此类场景下表现乏力。同时，高连接度节点主导消息传递导致的流行度偏差，使得长尾物品被忽视，损害了推荐的公平性。此外，用户误操作引入的噪声边污染了高阶信息传播，要求模型具备自适应的信号解耦能力。

当前，研究热点集中在打破 ID 依赖，通过融合多模态内容、知识图谱及大语言模型（LLM）语义来补充先验知识。DCGL 等双通道架构尝试解耦行为信号与语义信号，以缓解直接融合导致的语义稀释问题；CAGED 等因果推断方法则试图从聚合权重层面消除偏差。与此同时，理论分析开始反思 GNN 本身的必要性，AlphaFree 等工作提出无 GNN 架构，利用预训练语言模型表示替代消息传递，展示了非图结构方法在特定场景下的优势。

**如果用一个核心问题概括该领域，那便是：如何在大规模动态交互图中，平衡拓扑结构传播的效率与语义/因果信号的鲁棒性，以突破 ID 依赖并实现公平泛化。**

## 2. 方法体系

- 2013：GCN——奠定图神经网络在推荐系统中捕捉高阶协同信号的基础架构

- 2017：GraphSAGE——提出归纳式图神经网络框架，解决大规模动态图上的泛化难题

- 2019：PinSage——实现 Web 规模下的图卷积网络部署，证明工业可行性

- 2020：LightGCN——确立图协同过滤中轻量级传播机制的标准范式

- 2025：E2E-GRec——提出端到端联合训练框架，解决 GNN 预训练与推荐系统解耦问题

- 2025：CAGED——利用因果推断设计无偏图聚合权重，抑制流行度偏差

- 2026：RankGraph-2——针对十亿级节点图，协同设计图构建、训练与服务三个阶段

- 2026：AlphaFree——提出无用户、无 ID、无 GNN 的推荐架构，挑战 GNN 必要性

这条时间线勾勒了该领域方法演进的代表性节点：从 2013 年的 GCN 奠定该领域方法基线，经 2017 年 GraphSAGE 的推进，到 2026 年的 TextBridgeGNN 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 工业级系统优化

工业级系统优化路线的核心动机是解决十亿级节点图在构建、训练和服务全生命周期中的计算瓶颈。早期如 PinSage 和 GraphSAGE 奠定了大规模图部署的基础，但往往假设输入图给定，缺乏跨阶段协同。E2E-GRec（Xue et al., 2025, P5）针对两阶段流水线中 GNN 预训练与推荐模型解耦导致的梯度阻断问题，提出了端到端联合训练框架。该框架通过高效子图采样、图特征自编码器（GFAE）及基于 Gradnorm 的动态损失平衡，允许推荐系统的梯度直接反向传播至 GNN。其核心取舍在于放弃了传统的离线预训练范式，换取了 GNN 对推荐任务的针对性优化能力，但引入了训练不稳定性风险，依赖动态损失平衡机制来维持多任务训练的稳定性。

RankGraph-2（Wu et al., 2026, P19）进一步将视角从模型训练扩展到全生命周期协同设计。它摒弃了假设输入图给定的做法，从交互数据直接推导多种边类型并实施流行度偏差校正。在训练阶段，采用预计算的 PPR 邻居与边中心格式消除对在线图基础设施的依赖；在服务阶段，用协同学习的聚类索引替代在线 KNN。该方法的根本取舍是通过上游约束（如 3 小时刷新周期）牺牲部分实时性，换取系统整体成本的显著降低。HetSGFormer（Long et al., 2025, P6）则聚焦于动态异构图，通过 GPU 静态训练器与 CPU 增量更新器的协同，解决了嵌入时效性与计算成本的矛盾。Multi-Hash GNN（Utushkin et al., 2026, P22）通过多哈希用户嵌入层替代全量 ID 嵌入表，以有限的哈希碰撞代价换取内存效率的数量级提升，并依赖时间戳排序数据实现高效采样。这些工作共同确立了跨阶段依赖协同设计的范式，解决了单一阶段优化导致的系统瓶颈。

### 2.2 高效计算与压缩

高效计算与压缩路线旨在降低 GNN 推荐模型的参数复杂度、内存占用及计算开销，使其能够在资源受限场景下部署。LightGCN（2020）确立了轻量级传播的基准，而 Lighter-X（Zheng et al., 2025, P2）在此基础上进一步解耦传播过程，简化卷积操作，移除冗余的特征变换与非线性激活。其核心设计在于保留高阶邻居信息捕捉能力的同时，减少可训练参数数量，实现了即插即用的高效图推荐。该方法的取舍是以轻微的表达能力损失换取训练与推理计算负担的显著降低。

Mem-GF（Park and Shin, 2026, P20）从图滤波视角出发，将 Krylov 子空间作为核心原理而非仅计算捷径。它为每个用户构建 Krylov 子空间，捕捉交互向量在物品相似度矩阵重复作用下的渐进变换方向，从而无需显式存储完整的物品相似度矩阵即可实现多项式图滤波。这一设计解决了现有图滤波方法在大规模数据集上因内存溢出而无法部署的问题，以用户特定的滤波设计换取了低延迟推理与内存节省。AlphaFree（Jeon et al., 2026, P11）则采取了更为激进的策略，彻底摒弃了 GNN 消息传递与 ID 嵌入。它利用预训练语言模型提取物品文本内容的语言表示，并通过基于行为与语义相似度的相似物品增强来模拟高阶协同信号。其核心取舍是用语言模型的语义理解能力替代图结构的拓扑传播，解决了 ID 冷启动与 GNN 过平滑问题，但严重依赖物品文本质量与预训练模型的语义对齐精度。

### 2.3 去偏与鲁棒性

去偏与鲁棒性路线针对推荐系统中的流行度偏差及交互噪声问题，旨在提升模型在稀疏及噪声环境下的公平性与稳定性。CAGED（Que et al., 2025, P1）将图聚合过程解释为估计推荐对用户影响的因果效应，利用因果推断中的后门调整原理，设计编码器-解码器架构学习无偏的聚合权重。其核心创新在于通过潜变量建模区分真实偏好与流行度暴露偏差，避免了简单逆概率加权（IPW）的高方差问题。该方法的取舍是依赖因果图结构的正确假设与潜变量分布的合理性，换取了对高度节点主导信息传播的有效抑制。

Debiasing Message Passing（Islam et al., 2026, P16）则选择在消息传递过程中直接缓解偏差。它通过调整邻居聚合权重，抑制高流行度节点对低流行度节点表示的影响，防止节点表示因过度聚合热门邻居而收敛至相似值。与 CAGED 的因果推断视角不同，该方法更直接地作用于图结构传播过程，避免了曝光概率估计不准导致的高方差问题，但依赖于对流行度偏差机制的准确建模。Denoised Recommendation Model（Li and Yang, 2025, P4）针对噪声交互干扰，采用多任务学习策略同时优化 BPR 推荐损失与去噪图重构损失。通过限制去噪图与原图的差异，确保去噪过程不丢失关键协同信号，以软去噪保留图的连通性，提升了表示的稳定性。Spectral Bandits（Kocák et al., 2026, P17）则从谱图理论出发，利用图拉普拉斯算子的小特征值对应的特征向量作为基函数，将平滑图函数表示为线性组合，加速探索-利用权衡，为图结构下的在线推荐提供了理论驱动的高效算法。

### 2.4 冷启动与跨域迁移

冷启动与跨域迁移路线旨在解决新物品或新用户缺乏交互历史导致的协同信号缺失，以及 ID 嵌入在不同域间不可迁移的问题。NBF-Rec（Grötschla et al., 2025, P3）基于神经 Bellman-Ford 网络构建归纳式图推荐模型，通过查询依赖的消息传递机制动态计算未见图上的节点嵌入，无需重新训练即可适应新域。其核心创新在于引入边特征（如评分、时间戳）到消息传递过程中，实现了真正的零样本跨域泛化，突破了传统图推荐对领域重叠的依赖，但在稀疏图上的计算复杂度较高。

TextBridgeGNN（Chen et al., 2025, P8）通过文本引导的跨域预训练，利用分层消息传递融合文本与 ID 嵌入，解决了 ID 嵌入不可迁移及图结构域差异问题。其核心创新在于利用文本语义作为桥梁，缓解不同域间 ID 空间独立导致的知识碎片化，并通过图结构对齐增强泛化能力。该方法依赖于文本质量与跨域图结构相似性，在文本稀疏或域差异极大时效果受限。Asymmetric Graph Architecture（Truong et al., 2026, P18）将冷启动问题建模为时间链接预测任务，利用非对称图结构区分温暖内容与冷内容，通过内在特征直接计算冷内容嵌入，而非依赖交互子图。其核心取舍是解耦内容嵌入与设备嵌入的计算路径，允许冷内容通过语义特征与温暖内容的协同信号进行对齐，平衡了语义泛化与协同过滤精度。MoToRec（Liu et al., 2026, P9）利用稀疏正则化多模态分词器将原始特征转换为离散代码，结合层级多源图编码器，通过自适应稀有度放大机制缓解冷启动物品表示不足，提升了稀疏数据下的推荐鲁棒性。

### 2.5 知识增强与多模态

知识增强与多模态路线旨在融合知识图谱、大语言模型及多模态内容，增强推荐系统的语义理解能力与内容相关性。DCGL（Zou et al., 2026, P14）提出双通道图学习架构，分离 ID 行为通道与 LLM 语义通道，并通过频率感知门控融合，解决了单通道中语义稀释与行为信号干扰问题。其核心创新在于根据交互频率自适应整合双通道表示，平衡语义与行为信号，但增加了模型复杂度与计算开销，依赖 LLM 生成描述的质量。RaDAR（Huang et al., 2026, P12）结合扩散模型与非对称图对比学习，通过关系感知去噪生成多视图，利用信息瓶颈损失增强表示鲁棒性，解决了图对比学习中结构语义退化问题。MGACL（Hu and Xia, 2026, P15）利用图注意力机制聚合邻居实体重要性，并通过多层对比学习在全局结构、局部协同及语义视图上增强表示鲁棒性，为知识图谱推荐提供了多粒度对比学习框架。GeMi（Dutta et al., 2026, P10）则针对小众文化领域，采用模块化多模态编码策略，整合语言建模、跨模态对比学习与概率潜变量建模，展示了 GNN 在复杂语义内容推荐中的应用潜力。

### 2.6 理论分析与架构创新

理论分析与架构创新路线深入探究图信号频谱特性、异构图关系结构对训练目标的影响，提出频率信号缩放、基数分解损失及无 GNN 替代方案等理论驱动的新架构。SimGCF（Liu et al., 2025, P7）提出简单谱图协同过滤模型，通过频率信号缩放器精细调节 GNN 滤波器，分别处理低通与高通信号，揭示了图信号频谱特性对推荐性能的影响，提供了谱域视角的理论解释。CDL（Maheshwari et al., 2026, P21）提出基数分解损失，根据异构图关系结构（一对一 vs 一对多）匹配不同的训练目标（BCE vs BPR），解决了统一使用 BPR 导致的属性嵌入语义失真问题，提供了结构驱动的损失设计原则。AlphaFree（Jeon et al., 2026, P11）在此路线中同样占据重要地位，它从理论上挑战 GNN 在推荐中的必要性，证明语言表示与相似物品增强可有效模拟高阶协同信号，无需显式图结构传播，推动了推荐系统从图结构依赖向语义表示依赖的范式转变。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

GNN 通过消息传递捕捉高阶邻居信息，在推荐精度上显著优于传统矩阵分解和浅层协同过滤方法，这一共识在多个基准上被反复验证。例如，在 MovieLens-20M 上，Mem-GF 的 0.7214 AUC 与在 Amazon-Book 上 DCGL 的 0.7553 AUC 均大幅超越 LightGCN 的 0.6323 和 0.7145 AUC 基线（支撑证据：P20, P14）。然而，这一共识的边界在于，当引入强语义先验或因果去偏机制时，GNN 的相对优势可能缩小，甚至被非 GNN 架构在特定场景下超越。

与此相关的另一个共识是，LightGCN 等简化架构在保持高性能的同时大幅降低了计算复杂度，成为工业界基准。Lighter-X 和 Mem-GF 等工作进一步证明了轻量级传播机制在资源受限场景下的可行性（支撑证据：P2, P20）。此外，冷启动问题是 GNN 推荐的主要痛点，引入多模态特征或预训练语言模型语义是提升新物品表示有效性的主流方案，TextBridgeGNN 和 DCGL 的成功均依赖于语义桥接或双通道融合（支撑证据：P8, P14）。

### 3.2 观点分歧

关于 GNN 消息传递机制在推荐中的必要性，存在深刻分歧。观点 A 认为 GNN 是捕捉高阶协同信号的核心范式，LightGCN 等模型证明了其有效性；观点 B 认为 GNN 并非必要，预训练语言模型表示与相似物品增强可有效替代消息传递，且更高效（代表：AlphaFree）。现有证据在特定场景下偏向观点 B，AlphaFree 在冷启动和内存效率上显著优于 GNN，但在复杂拓扑结构捕捉上观点 A 仍有优势。分歧根源在于测量工具盲区：现有基准多侧重静态、同构图，缺乏对动态、异构图及复杂语义场景的统一评测；场景依赖：GNN 在密集交互图上表现好，而 AlphaFree 在稀疏/冷启动场景表现好，两者适用域不同。

这一分歧的背后，是另一个更根本的争论：流行度偏差的最佳去偏介入点。观点 A 主张在表示学习阶段（消息传递层）直接调整聚合权重，从源头消除偏差（代表：Debiasing Message Passing）；观点 B 主张在训练目标或后处理阶段通过因果推断或重加权进行修正（代表：CAGED）。现有证据在 KuaiRec 等严重偏差数据集上偏向观点 A（Debiasing MP SOTA），但在 Coat 等数据集上观点 B（CAGED）表现更优。证据强度较弱，缺乏跨数据集的稳定性验证，原因在于不同数据集的偏差机制不同（曝光偏差 vs 选择偏差），单一方法难以通吃，且缺乏统一的偏差量化指标。

### 3.3 其他开放问题

当前最紧迫的工程问题是十亿级动态图的实时增量更新与内存优化。RankGraph-2 和 HetSGFormer 虽提出了生命周期协同设计与静态/动态解耦架构，但如何在保持高精度的同时进一步降低延迟与内存占用，仍是工业落地的关键瓶颈。最根本的研究问题是如何从因果层面彻底解决流行度偏差，以及如何设计非对称架构以完美平衡语义与协同信号。CAGED 的因果推断方法依赖因果图结构的正确假设，而 DCGL 的双通道架构依赖 LLM 生成描述的质量，两者均未完全解耦语义与协同信号的深层机制。

已知的是，GNN 在密集交互图上具有优势，语义增强在冷启动场景下有效；争议的是，GNN 的必要性及去偏的最佳介入点；未知的是，如何在动态、异构图及复杂语义场景下实现公平泛化。未来趋势将朝着打破 ID 依赖、实现语义与协同信号的无损融合方向演进，结合因果推断、多模态语义与高效计算技术，构建可解释、鲁棒且可扩展的推荐系统。

## 4. 总结与展望

GNN 推荐系统已度过架构探索期，进入以“规模化鲁棒性”和“语义-协同解耦”为核心的新阶段。核心矛盾从“表达能力不足”转变为“规模化部署与数据鲁棒性的平衡”，方法演进的本质是从“结构依赖”向“语义-结构混合依赖”的转变。当前瓶颈在于如何在大尺度动态图中，通过因果与语义机制解决数据稀疏、噪声及偏差问题，实现公平泛化，这直接回应了领域核心问题：如何在大规模动态交互图中，平衡拓扑结构传播的效率与语义/因果信号的鲁棒性。

未来可能突破的方向包括：基于 LLM 的图检索增强生成，结合 DCGL 的双通道架构与 RaDAR 的对比学习，提升知识感知推荐的语义理解能力；无 ID 的纯语义推荐架构，如 AlphaFree 所示，利用预训练语言模型表示替代消息传递，解决冷启动与过平滑问题；以及谱域驱动的可解释 GNN 设计，如 SimGCF 所示，通过频率信号缩放提供透明机制。对于进入者而言，最值得做的一件事是在统一骨干与统一预训练条件下，构建涵盖动态、异构图及复杂语义场景的统一评测基准，以隔离架构贡献并验证不同路线在公平泛化上的真实优势。
