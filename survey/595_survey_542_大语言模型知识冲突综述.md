综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Knowledge%20Conflicts%20in%20LLMs)

## 导读

大语言模型（LLM）在检索增强生成（RAG）范式下，面临静态参数化知识与动态外部上下文矛盾时的证据仲裁失败，其核心矛盾在于模型倾向于依赖内部记忆而忽略外部证据。早期研究聚焦于定性观察模型幻觉，随后 NQ-SWAP 等基准的提出将问题量化，确立了上下文-记忆冲突作为核心研究对象。2024 年对比解码（Contrastive Decoding, CAD）等推理时干预方法成为范式转折点，证明了无需重训练即可缓解冲突的可行性，但其黑盒特性导致内部表征未真正修正。2025-2026 年，研究重心向机制可解释性和细粒度冲突类型转移，旨在构建能动态仲裁知识来源、具备鲁棒性的可信 LLM 系统。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从表面纠偏到深层认知调和的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

知识冲突（Knowledge Conflicts）领域的兴起源于大语言模型静态参数化知识与动态外部世界之间的根本矛盾。在检索增强生成（Retrieval-Augmented Generation, RAG）成为主流范式后，核心驱动力转变为解决参数化记忆与检索上下文之间的不一致。早期研究聚焦于模型幻觉，随后随着 RAG 的普及，核心问题被重新定义为：当外部上下文与内部参数化知识发生矛盾时，模型倾向于依赖内部记忆而忽略上下文，导致生成不忠实于证据。这种上下文-记忆冲突（Context-Memory Conflict）不仅涉及事实准确性，更触及模型对证据来源的动态仲裁能力，构成了当前可信 LLM 系统构建的核心瓶颈。

问题的形式化通常基于 N-way K-shot 的变体，但在知识冲突场景中，更关注的是单轮问答中参数知识 $K_p$ 与上下文知识 $K_c$ 的博弈。设查询为 $q$，模型参数化知识为 $K_p(q)$，检索上下文为 $K_c(q)$。当 $K_p(q) \neq K_c(q)$ 时，模型需决定生成答案 $y$ 应遵循 $K_p$ 还是 $K_c$。理想情况下，模型应具备上下文忠实度（Context Faithfulness），即 $y$ 严格遵循 $K_c$。然而，现有模型普遍表现出对 $K_p$ 的过度依赖，导致 $y$ 偏离 $K_c$。这一问题的子结构包括冲突检测（识别 $K_p$ 与 $K_c$ 是否矛盾）、冲突仲裁（决定优先权）以及冲突解决（生成忠实答案）。这三个子问题呈现层级依赖关系：检测是基础，若无法准确识别“真冲突”与“噪声”，后续的仲裁与解决将导致过度修正或漏检；机制可解释性为精准仲裁提供理论支撑；而时间性、多源及对抗性冲突则是基础冲突在更复杂场景下的延伸。

约束条件的演化深刻塑造了领域的发展轨迹。2016-2018 年，研究处于奠基期，主要关注模型幻觉的定性描述，缺乏量化冲突的基准。2020 年，RAG 范式的提出（P40）将参数知识与非参数知识解耦，为后续解决知识冲突提供了基础架构，但同时也引入了新的冲突源。2021-2022 年，NQ-SWAP 等基准的提出（P32）标志着领域从定性观察转向定量评估，确立了“上下文-记忆冲突”作为核心研究对象，解决了“如何测量”的问题。2023-2024 年，对比解码（CAD）等推理时干预方法成为范式转折点，证明了无需重训练即可缓解冲突的可行性，解决了“如何快速干预”的问题，但随后研究指出其黑盒特性导致内部表征未真正修正。

2025-2026 年，研究重心向机制可解释性（如熵神经元、激活引导）和细粒度冲突类型（如时间性、多源个人记忆冲突）转移，并引入对抗性攻击视角。这一阶段，问题定义从“如何纠正输出”转变为“如何理解并干预内部认知调和机制”。例如，CoCoA（P39）通过动态权重调节解决了固定超参数在低冲突场景下的性能退化问题，而 Entropy Neurons（P33）则揭示了冲突处理的内部神经基础。当前领域处于从“表面纠偏”向“深层认知调和”过渡的高活跃期，旨在构建能动态仲裁知识来源、具备鲁棒性的可信 LLM 系统。

**如果用一个核心问题概括该领域，那便是：如何构建具备动态知识源仲裁能力的 LLM 系统，使其能在参数化记忆与外部证据冲突时，基于内部机制感知与上下文语义，实现从“盲目依赖记忆”向“忠实于证据”的认知调和。**

## 2. 方法体系

- 2020：RAG——通过检索外部文档并在推理时将其注入上下文，将参数知识与非参数知识解耦，为后续解决知识冲突提供了基础架构

- 2021：NQ-SWAP——通过实体替换构建参数知识与上下文知识冲突的基准数据集，首次系统化量化模型在冲突场景下的行为偏差，成为领域评估标准

- 2023：DPO——直接偏好优化算法，通过优化模型对偏好数据的似然比来对齐人类偏好，为后续利用偏好数据提升上下文忠实度提供了高效训练范式

- 2024：CAD——对比解码方法，通过计算有上下文与无上下文时的logits差值并加权，动态抑制参数知识偏差，确立了推理时干预解决冲突的基本范式

- 2025：AdaCAD——自适应对比解码，利用Jensen-Shannon散度动态调整对比权重，解决了固定超参数在不同冲突强度下性能波动的问题

- 2026：CoCoA——置信度与上下文感知自适应解码，结合Rényi散度与熵差信号在token级别动态调节参数与上下文权重，实现了更精细的冲突解决

- 2026：Entropy Neurons——熵神经元机制，发现FFN中少量神经元通过抑制上下文重复行为来调节知识源选择，揭示了冲突处理的内部神经基础

- 2026：SI-FACT——自改进忠实性感知对比调优，利用模型自身生成对比数据并进行对比学习，无需人工标注即可提升上下文忠实度

这条时间线勾勒了该领域方法演进的代表性节点：从 2020 年的 RAG 奠定该领域方法基线，经 2021 年 NQ-SWAP 的推进，到 2026 年的 SI-FACT 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 解码干预与忠实性

解码干预路线的核心假设是，知识冲突主要源于解码阶段对参数化知识的过度依赖，因此通过调整 logits 或隐藏状态即可缓解冲突。早期方法如 CAD（P14）通过计算有上下文与无上下文时的 logits 差值并加权，动态抑制参数知识偏差，确立了推理时干预的基本范式。然而，CAD 的固定超参数在不同冲突强度下表现不稳定，尤其在低冲突场景下可能导致过度干预，损害生成质量。针对这一局限，AdaCAD（P39）利用 Jensen-Shannon 散度动态调整对比权重，解决了固定超参数在不同冲突强度下性能波动的问题，但仍未触及内部表征。

进一步地，CoCoA（P39）提出置信度与上下文感知自适应解码算法，在 token 级别引入 Rényi 散度和熵差两个互补信号，实时调整解码过程中对参数知识与上下文证据的依赖权重。其核心创新在于摒弃了 AdaCAD 中均匀惩罚所有分布偏移的 JSD 度量，转而采用更敏感的 Rényi 散度以区分不同类型的冲突。CoCoA 在保持高冲突场景下忠实度的同时，显著改善了无冲突场景下的生成质量，避免了过度干预导致的语义扭曲。然而，这些方法均属于黑盒干预，仅调整输出分布，未修正内部表征中的错误传播，导致生成不稳定且无法从根源解决冲突。

为突破黑盒局限，CoRect（P14）提出上下文感知 Logit 对比隐藏状态校正方法，通过无监督层定位技术识别模型内部残差流中负责抑制参数知识的特定层，并在这些关键层插入校正模块，直接修改隐藏状态以消除参数先验对上下文的干扰。CoRect 将冲突解决从输出分布调整前移至中间表示修正，从而提升生成的稳定性。其核心取舍在于依赖对模型内部结构的精确理解，限制了其在黑盒模型中的应用。ContextFocus（P11）则通过构建对比提示来生成引导向量，在推理时将该引导向量加到模型特定层的隐藏状态上，从而主动引导模型关注上下文证据。ContextFocus 直接操作隐藏状态而非 logits，能够更直接地影响模型的内部表示，但依赖于精心设计的提示模板来构建高质量的引导向量，对提示设计敏感。

SHIFT（P24）提出门控调制激活引导方法，在 FFN 分支插入轻量级门控模块以自适应调节隐藏状态。该方法冻结 LLM 主干参数，仅训练门控参数，通过 GRPO 优化目标使模型学会在生成过程中平衡上下文证据与参数知识。SHIFT 允许模型在每个层独立决定干预强度，提高了灵活性，但依赖 GRPO 算法的稳定性，且门控模块增加了少量推理延迟。FIDES（P20）提出基于深度证据信号的忠实推理方法，通过双路径对比解码捕捉多深度冲突信号，融合输出层面和隐藏状态层面的 Opposition 信号，更准确地估计每个 token 的冲突强度。FIDES 代表了从单一信号向多模态信号融合的演进，但增加了计算开销。

| 方法 | 年份 | 核心机制 | 干预深度 | 计算开销 | 通用性 | 主要局限 |

解码干预路线与训练优化路线形成互补：前者在推理时灵活适配不同上下文，部署成本低，但效果临时；后者在训练时从根本上改变模型偏好，效果持久，但面临灾难性遗忘与数据标注成本。解码干预路线内部的演进则体现了从静态到动态、从黑盒到白盒的深化，为后续基于内部状态监控的解码方法提供了参考。

### 2.2 训练优化与对齐

训练优化路线的核心假设是，知识冲突源于模型参数对上下文证据的依赖不足，因此通过微调或偏好优化可以从参数层面增强冲突解决能力。早期方法如 DPO（P1）通过优化模型对偏好数据的似然比来对齐人类偏好，为后续利用偏好数据提升上下文忠实度提供了高效训练范式。然而，DPO 依赖人工标注的偏好数据，成本高且难以规模化。

SI-FACT（P1）提出自改进忠实性感知对比调优，利用 LLM 作为教师生成对比数据，作为学生学习这些数据，形成自改进循环。其核心创新在于自动化监督信号生成，无需人工标注即可获取高质量的对比数据。通过对比学习，模型学会区分忠实与不忠实的生成，从而提升上下文依赖。SI-FACT 属于数据高效的预训练前策略，降低了训练成本，但其局限性在于依赖模型自身生成数据的质量，可能存在偏差累积。CARE（P2）提出通过原生检索增强推理提升上下文保真度，允许 LLM 自主从输入上下文中进行原生检索，将检索证据整合到推理过程中。CARE 不依赖外部检索模块，而是利用模型自身的语言理解能力进行证据提取，通过 SFT 和 RL 两阶段训练教会模型如何有效检索和整合证据。这种方法减少了对外部工具的依赖，提高了系统的简洁性和鲁棒性，但增加了训练复杂度。

Admit Ignorance（P10）提出检索增强问答中 LLM 承认无知的策略，采用滑动窗口迭代生成，若当前窗口包含正确答案则回答，否则提供理由并继续检索。其核心创新在于引入“承认无知”机制，避免模型在证据不足时强行生成错误答案。通过迭代检索，模型能够更准确地判断知识边界，提升了系统在不确定场景下的可靠性，减少了幻觉。其局限性在于增加了推理延迟，且依赖检索质量。Temporal Knowledge Conflict Resolution（P37）提出时间性知识冲突解决方法，利用事实可变性作为推理因素，构建包含稳定与可变事实的基准，评估模型对时间性冲突的处理。其核心创新在于引入事实可变性概念，区分易变事实与稳定事实，通过诊断模型是否利用可变性进行推理，揭示了当前模型的不足。该方法为时间性知识更新提供了新视角，强调了元知识在冲突解决中的作用，但其局限性在于可变性判断的复杂性，需要额外的元数据。

Context Compliance Diagnosis（P19）提出诊断 RAG 中上下文合规性的框架，区分合规与解决机制，利用信念修正框架定义参数先验和上下文后验，通过显式答案生成观察分歧。其核心创新在于将冲突解决行为分解为检测和仲裁两个阶段，评估模型是否真正解决了冲突而非盲目遵循上下文。TokenMem（P26）提出冻结 LLM 的忠实知识注入方法，通过 token 级别操作增强知识更新，在不修改模型权重的情况下，通过调整 token 嵌入或注意力机制注入新知识。其核心创新在于实现了参数冻结状态下的知识更新，避免了微调的成本和灾难性遗忘，但其局限性在于注入容量的限制，可能影响长期稳定性。

训练优化路线与解码干预路线在干预深度上形成对比：前者修改模型权重，后者仅调整推理时的 logits 或隐藏状态。训练优化路线的优势在于效果持久，但面临灾难性遗忘和高成本；解码干预路线灵活但效果临时。两者结合的最优策略尚未明确，但现有证据显示，训练时对齐在长期一致性上更优，而推理时干预在灵活性和部署成本上更具优势。

### 2.3 机制可解释性分析

机制可解释性路线的核心假设是，知识冲突的处理涉及模型内部特定的计算路径，精准干预这些路径比全局解码调整更有效。早期研究如 Induction Heads（P16）揭示了 Transformer 中负责序列复制的注意力头，为理解模型如何从上下文提取信息提供了机制解释基础。然而，Induction Heads 主要关注序列复制，未直接针对知识冲突场景。

Context Copying Modulation（P33）提出熵神经元在管理参数与上下文知识冲突中的作用机制，通过探针分析 FFN 中的神经元，发现少量熵神经元在最后一层 Transformer 中起关键作用。这些神经元通过抑制上下文序列的重复行为（即归纳），调节模型对上下文知识的依赖。其核心创新在于将知识源选择与特定神经元活动联系起来，揭示了冲突处理的微观机制。通过消融实验，验证了熵神经元对冲突解决行为的因果影响。该方法为理解模型如何内部仲裁知识源提供了神经科学视角，证明了即使少量神经元也能显著影响宏观行为。

Intra-Memory Conflict Mechanism（P12）提出记忆内知识冲突的机制研究，探究模型内部如何产生不一致响应。该方法通过继续预训练包含矛盾事实的合成数据集，构建受控实验环境，利用探针技术定位负责存储冲突知识的神经元和注意力头，分析其在生成过程中的激活模式。其核心创新在于区分记忆内冲突与上下文-记忆冲突，揭示了训练数据噪声如何导致模型内部表示的不稳定。Training Data Shapes Knowledge Use（P3）提出训练数据如何塑造参数知识与上下文知识使用的机制分析，设计受控实验框架，测量文档内重复和不一致性对模型知识利用能力的影响。发现文档内重复促进了上下文使用和参数回忆的共现，而不一致性教会模型不盲目复制上下文。其核心创新在于揭示了训练数据属性与模型行为之间的因果关系，解释了为何某些模型更依赖参数知识。

Simulated Adoption（P13）提出解耦 LLM 上下文冲突解决中幅度和方向的理论框架，将隐藏状态视为基线状态与干扰向量的线性叠加，分析 RMSNorm 约束下的流形特性。通过模拟对抗性提示，量化干扰向量的幅度和方向对最终 logits 的影响。其核心创新在于提供了冲突解决的几何解释，揭示了模型在冲突状态下的表示动态。Latent Probing for Faithful RAG（P41）提出潜在探针方法用于忠实检索增强生成，超越黑盒干预，通过探针模型预测模型内部对上下文和参数知识的依赖程度，并据此调整生成策略。其核心创新在于将内部状态监控与生成控制结合，实现了基于内部信号的自适应忠实度调节。

NCU Metric（P22）提出归一化上下文利用率指标，量化 RAG 系统中先验主导程度，利用连续长度归一化对数概率，在零样本、预言机和对抗条件下评估模型对上下文证据的利用。其核心创新在于从离散文本匹配转向连续概率空间，能够捕捉模型预测置信度的细微变化。INTRYGUE（P16）提出归纳感知熵门控用于可靠 RAG 不确定性估计，利用归纳头的 SinkRate 作为门控项，调制原始熵分数，当模型未能机制性地关注检索上下文时放大不确定性估计。其核心创新在于将机制可解释性（归纳头）与不确定性估计结合，解决了标准熵估计忽略上下文关注机制的问题。Recall Bottleneck（P15）提出参数事实性瓶颈在于回忆而非编码的实证研究，通过行为定义编码标准，区分模型未编码知识与编码但未能回忆知识的情况，发现许多事实错误源于回忆失败而非知识缺失。其核心创新在于重新定义了事实性错误的来源，挑战了“模型不知道”的假设。

机制可解释性路线与解码干预路线形成深化关系：前者为后者的精准干预提供理论支撑，后者则为前者的机制发现提供应用验证。机制可解释性路线的优势在于揭示了冲突处理的微观机制，但面临模型架构依赖的挑战，不同架构下机制通用性存疑。解码干预路线则更通用，但缺乏对内部行为的解释。

### 2.4 冲突检测与评估基准

冲突检测与评估基准路线的核心假设是，量化模型在冲突场景下的行为偏差是解决冲突的前提。早期基准如 NQ-SWAP（P32）通过实体替换构建参数知识与上下文知识冲突的基准数据集，首次系统化量化模型在冲突场景下的行为偏差，成为领域评估标准。然而，NQ-SWAP 依赖实体替换，可能引入不自然的冲突场景，限制了真实噪声下的评估。

MAGIC（P32）提出多跳图基准用于评估检索增强生成中的跨上下文冲突，基于知识图谱构建冲突数据集，通过随机采样种子三元组并构建子图，生成包含多跳推理链的冲突场景。其核心创新在于利用 KG 的结构化特性，精确控制冲突的位置和类型，便于细粒度分析。Code Conflict Framework（P5）提出代码生成场景下的上下文-记忆冲突理解、检测与引导框架，将提示分解为上下文 c 和查询 q，定义参数知识为模型对 q 的独立响应，上下文知识为对 (c,q) 的响应。其核心创新在于将冲突研究从 QA 任务扩展到代码生成，揭示了推理密集型任务中冲突的独特模式。

Conflicting Needles（P42）提出扩展的针在干草堆测试框架，评估 LLM 面对矛盾信息时的行为，在长文档中插入多个相互矛盾的“针”（事实），系统操纵重复次数、位置索引、问题类型等变量。其核心创新在于引入多变量控制实验，揭示了重复、位置偏差和领域特异性对冲突解决的影响。evolveQA（P6）提出探测 LLM 演化知识的基准，专门针对时间性知识冲突，从带时间戳的语料库中识别随时间演化的事实，生成针对不同知识截止日期的高质量问答对。其核心创新在于将时间维度引入冲突评估，区分稳定事实与可变事实，并测试模型对知识时效性的感知。

ConflictScore（P23）提出识别和测量 LLM 处理矛盾证据能力的框架，不仅关注参数与检索知识的冲突，还关注检索语料内部的不同视角和矛盾证据。其核心创新在于扩展了冲突的定义，涵盖了语料内部的歧义和矛盾，而不仅仅是参数-上下文冲突。HealthContradict（P9）提出评估生物医学知识冲突的基准，关注医疗领域高风险场景，构建包含矛盾医疗信息的上下文，评估模型在生成医疗建议时的忠实性和安全性。其核心创新在于将冲突评估应用于垂直领域，揭示了通用模型在专业领域知识冲突处理上的不足。

ConflictQA（P17）提出探索忠实 LLM 推理的知识冲突基准与方法，结合知识图谱和文本证据，构建包含多源冲突的问答数据集。其核心创新在于整合结构化 KG 和非结构化文本，模拟真实世界中异构知识源的冲突场景。EnterpriseRAG（P29）提出基准测试 LLM 在非理想企业检索下的指令遵循和鲁棒性，从生产 RAG 日志中构建数据集，包含噪声检索、知识缺口和事实冲突等真实场景。其核心创新在于关注企业级应用的复杂性，如格式合规、协议遵循和冲突引用，而不仅仅是事实准确性。

冲突检测与评估基准路线为其他路线提供了评估工具，其演进体现了从简单到复杂、从学术到工业的转化。基准的精细化推动了方法从定性向定量的转变，强调了概率校准在冲突解决中的重要性。

### 2.5 安全攻击与鲁棒性

安全攻击与鲁棒性路线的核心假设是，RAG 系统在对抗性上下文下的脆弱性暴露了现有冲突解决机制的缺陷。早期攻击如 PoisonedRAG（P8）通过向知识库注入恶意文档操纵检索结果，揭示了 RAG 系统在对抗性上下文下的脆弱性。然而，PoisonedRAG 主要关注全量投毒，未研究少样本场景下的攻击有效性。

ADMIT（P4）提出针对 RAG 事实核查的少样本知识投毒攻击，假设攻击者只能注入少量对抗性段落，旨在翻转事实核查结果。其核心创新在于研究少样本场景下的攻击有效性，揭示了 RAG 系统在有限投毒下的脆弱性。Epistemic Bias Injection（P8）提出通过选择性上下文检索偏置 LLM 的攻击方法，注入事实正确但语义偏见的段落，引导检索结果偏向特定立场，从而影响生成答案。其核心创新在于利用语义偏见而非事实错误进行攻击，增加了检测难度。

PURPOSE（P27）提出通过代理事实接地更新投毒 RAG 冲突解决机制，利用公开 LLM 探测目标系统的参数知识，构造保留代理事实但解释向目标答案转变的投毒文档。其核心创新在于结合权威引用和查询对齐信号，提高投毒文档的可检索性和说服力。MM-PoisonRAG（P35）提出多模态 RAG 知识投毒攻击框架，研究局部和全局知识投毒，针对多模态 RAG 系统，通过污染外部知识库中的文本和图像，破坏检索增强生成的可靠性。其核心创新在于首次系统研究多模态场景下的投毒攻击，揭示了视觉和文本模态交互中的脆弱性。

Trustworthy RAG Agent（P31）提出检测误导信息和知识投毒的评估代理，作为防御中间件，包含 NLI 验证器、投毒检测器和信任指数计算器。其核心创新在于将防御机制集成到 RAG 流水线中，实时评估检索文档和生成答案的可信度。Rescorla-Wagner Steering（P34）提出基于 Rescorla-Wagner 模型引导 LLM 应对不当上下文的方法，利用关联强度模型预测模型行为，通过调整上下文比例来抑制不当内容的影响。其核心创新在于将学习理论应用于 LLM 行为预测，揭示了上下文位置和内容比例对模型输出的影响。

Manufactured Confidence（P25）提出记忆巩固如何将传闻转化为自信事实的机制研究，分析记忆产品如何压缩对话历史，去除来源归因并去对冲，导致模型输出自信的错误值。其核心创新在于揭示了记忆压缩过程中的“清洗”效应，即原始暂定表述被改写为自信事实。Visual RAG Conflict Analysis（P28）提出视觉检索增强生成中冲突宽度和源连贯性的分析，形式化了正确页面和冲突页面之间的冲突集，定义了冲突宽度和源连贯性。其核心创新在于将冲突分析扩展到视觉 RAG，揭示了多源视觉证据整合中的歧义。

安全攻击与鲁棒性路线是解码干预和训练优化路线的对抗性延伸，其研究揭示了现有系统在鲁棒性上的严重缺陷，推动了冲突解决机制的鲁棒性研究。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLM 在面临上下文与参数化知识冲突时，普遍表现出对内部参数化知识的过度依赖，导致上下文忠实度下降，这一共识在多个基准上被反复验证。例如，在 NQ/TriviaQA/HotpotQA 上，CAD 的 21.75 EM 远低于 Greedy Decoding 的 59.50 EM，表明模型在冲突场景下倾向于依赖内部记忆而非外部证据。在 ConFiQA 上，Base 模型的 30.20 Ps 也反映了这一趋势。这一共识的边界在于，当上下文与参数化知识一致时，模型表现正常，冲突仅在两者矛盾时显现。

与此相关的另一个共识是，RAG 虽能缓解知识过时问题，但引入了新的冲突源，且检索噪声或无关文档会进一步降低模型性能。例如，EnterpriseRAG 基准显示，DeepSeek-R1 在知识缺口识别中仅达到 42.7% 准确率，表明模型在真实噪声场景下的鲁棒性不足。这一共识的边界在于，高质量检索可以缓解冲突，但检索噪声会加剧冲突，导致模型性能下降。

### 3.2 观点分歧

黑盒推理时干预与白盒机制内部干预的分歧是领域内的核心争论。观点 A（黑盒）认为，CAD/AdaCAD 等仅调整 logits 分布，无需访问内部状态，通用性强，部署简单；观点 B（白盒）认为，CoRect/Entropy Neurons 等修正隐藏状态或特定神经元，从根源阻断错误传播，更稳定且可解释。现有证据偏向白盒，因黑盒方法在复杂推理和低冲突场景下表现不稳定，且无法解释内部行为。但白盒方法在跨架构（如不同 LLM）的通用性缺乏充分验证。定输赢的实验：在多种架构（Transformer, Mamba 等）上对比黑盒与白盒方法在复杂多跳推理任务中的忠实度与稳定性。

这一分歧的背后，是另一个更根本的争论：动态权重信号的选择，即分布散度 vs 内部状态信号。观点 A（分布散度）认为，AdaCAD/CoCoA 使用 JSD/Rényi 散度衡量参数与上下文分布差异，信号直观且易于计算；观点 B（内部状态）认为，FIDES/INTRYGUE 使用隐藏状态差异或归纳头 SinkRate，信号更深层且能捕捉机制性关注。现有证据偏向内部状态信号，因分布散度可能忽略分布形状的非线性差异，而内部状态信号能更准确地反映模型对上下文的机制性关注。但内部状态信号计算开销大，且依赖探针模型的准确性。定输赢的实验：在噪声检索场景下，对比基于分布散度与内部状态信号的动态解码方法在冲突检测准确率与生成忠实度上的表现。

### 3.3 其他开放问题

当前领域面临的最紧迫工程问题是多源与多轮冲突解决。现有方法多针对单轮、单源冲突，未来需扩展到多源检索和多轮对话场景，解决可信度信号在检索轮次间累积和动态变化的问题，难点在于如何设计跨轮次的状态跟踪机制。例如，MAGIC 和 ConflictQA 等基准虽然覆盖了多源冲突，但缺乏对多轮对话场景的评估，导致方法泛化性挑战增大。

最根本的研究问题是机制可解释性与内部干预的通用性。从黑盒提示转向白盒机制解释，通过定位冲突诱导层（如 FFN 层）和激活神经元进行内部状态修正，难点在于不同模型架构和规模下冲突表示的通用性。例如，Entropy Neurons 在特定模型上揭示了冲突处理的微观机制，但其在其他架构上的适用性尚未验证。此外，不确定性估计与拒绝回答也是关键研究问题，需改进 RAG 场景下的不确定性估计，解决熵基方法在归纳头激活下高估不确定性的问题，难点在于区分真正的知识缺口与上下文干扰，实现精准的拒绝或澄清策略。

已知—争议—未知认知图谱显示，领域在冲突检测和基准构建方面已形成共识，但在干预深度和信号选择上存在显著分歧，而在多源冲突、机制通用性和不确定性估计方面仍属未知。未来趋势将依赖于机制可解释性与动态仲裁算法的融合，构建能动态感知证据可信度、具备鲁棒性的可信 LLM 系统。

## 4. 总结与展望

知识冲突研究的核心矛盾在于 LLM 静态参数化知识与动态外部世界之间的根本不一致，现有方法从表面纠偏向深层认知调和演进，但核心瓶颈仍在于缺乏动态知识源仲裁能力。解码干预路线以低成本低侵入换取即时效果，但受限于黑盒特性；训练优化路线以高成本换取参数层面的根本修正，但面临灾难性遗忘与数据标注成本；机制解释路线则试图通过白盒干预实现精准调和，但面临模型架构依赖的挑战。这些路线的取舍反映了领域在表示质量、适应效率与计算成本之间的权衡，当前形态是多元并存但缺乏统一范式的结果。

未来可能突破的方向包括：多源与多轮冲突解决，需设计跨轮次的状态跟踪机制，解决可信度信号在检索轮次间累积和动态变化的问题；机制可解释性与内部干预，需验证不同模型架构和规模下冲突表示的通用性，实现精准的白盒干预；不确定性估计与拒绝回答，需改进 RAG 场景下的不确定性估计，区分真正的知识缺口与上下文干扰。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，对比黑盒与白盒方法在复杂多跳推理任务中的忠实度与稳定性，以揭示干预深度与通用性之间的最优权衡。
