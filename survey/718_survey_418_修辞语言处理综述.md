综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Figurative%20Language%20Processing)

## 导读

修辞语言处理旨在让机器理解隐喻、讽刺等非字面语言现象，其核心挑战在于模拟人类“不一致性-解决”的认知机制。早期研究依赖规则与浅层特征，将问题简化为静态文本分类，受限于数据规模与模型容量，难以捕捉动态语境中的语义偏差。2020 年前后，预训练语言模型通过上下文表示显著提升了检测性能，但静态架构仍无法处理复杂的语用推理。随着大语言模型的兴起，研究重心从“分类”转向“推理与解释”，试图通过思维链和强化学习模拟深层认知过程。2025 年以来，多模态与多智能体框架成为主流，通过跨模态不一致性检测和显式推理链解决复杂修辞理解问题。各路线在表示质量、推理深度与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

修辞语言处理的本质是对“表面意义”与“意图”之间冲突的计算建模。这一领域起源于对语义偏差和认知映射的探索，早期工作如 MIPVU 框架（2010）通过步骤化分析词汇单位在上下文中的字面意义与语境意义不匹配，奠定了隐喻识别的基础。然而，这种基于规则的方法假设修辞语言可通过静态词汇-语境不匹配识别，受限于算力与数据规模，无法处理动态语境。随着深度学习的发展，问题形式化逐渐从简单的二分类任务演变为复杂的语义推理过程。在 N-way K-shot 设定下，模型需要从少量样本中习得新概念，但修辞语言的非字面性使得传统度量学习面临挑战，因为隐喻和讽刺往往缺乏明确的类别边界。

问题的定义随模型能力发生了三次关键演化。2020 年前后，预训练语言模型（PLMs）的兴起标志着从“特征匹配”到“上下文表示学习”的转变。BERT 等模型通过自注意力机制捕捉长距离依赖，显著提升了讽刺和隐喻检测性能，但其静态架构难以处理动态语境和复杂推理。2023-2024 年，大语言模型（LLMs）的爆发带来了第二次转折，问题定义从“分类标签预测”转向“深层语用推理与解释”。核心挑战变为如何模拟人类的不一致性-解决（Incongruity-Resolution）认知机制，即通过解决表面意义与意图之间的冲突来推导真实含义。2025-2026 年，问题边界进一步扩展至多模态与跨文化场景，核心问题演变为“跨模态不一致性检测”与“文化接地（Cultural Grounding）”，强调多智能体协同与显式推理链以解决复杂修辞理解。

子问题之间存在强依赖关系。隐喻和转喻的细粒度表征是基础，多模态融合依赖于单模态语义对齐，而低资源文化理解依赖于跨语言迁移机制。若无法解决深层推理这一子问题，多模态融合仅能停留在表面特征匹配，无法实现真正的修辞理解。例如，讽刺检测需要结合图像、文本甚至音频线索，但现有模型往往过度依赖文本模态，未能充分利用视觉和音频中的细微线索，导致在跨模态不一致性检测上性能受限。这种依赖关系揭示了领域内的核心矛盾：模型在表面分类上表现良好，但在需要多步推理、常识判断和意图推断的复杂修辞任务中仍显著低于人类水平。

范式边界也在不断拓展。早期研究局限于英语文本分类，而当前研究不仅关注英语，还扩展至阿拉伯语、孟加拉语、越南语等低资源语言，并深入探究模型内部对修辞知识的表征机制。这种拓展标志着该领域从单一文本分类向多模态、跨文化、可解释性综合理解的范式跃迁。然而，低资源语言和文化特异性修辞的理解缺口仍是主要瓶颈，大多数基准和模型针对英语优化，在低资源语言上表现急剧下降，原因是缺乏大规模标注数据和跨文化语义对齐机制。

在约束演化史上，2016-2018 年奠基阶段以 MMSD 数据集（2016）和 SemEval-2017 Task 7（2017）为代表，确立了跨模态不一致性作为反讽核心线索的研究范式，并奠定了计算幽默处理中双关语分析的基础。2020 年，MDL Probing 方法通过信息论指标评估预训练语言模型在训练过程中对修辞知识的获取轨迹，揭示了模型规模、层结构与修辞知识获取之间的关系。2022 年，FLUTE 基准数据集通过模型在环生成与人工标注，成为评估 LLM 修辞理解能力的核心资源。2023 年，MMSD2.0 通过移除噪声样本和重新标注不合理实例改进的多模态反讽数据集，解决了早期数据集的标注不一致问题。2024 年，JOKER 数据集扩展了双关语检测与解释任务的语言覆盖范围，为 LLM 零样本能力提供了测试场。

2025-2026 年，领域进入细化与融合阶段。Sarcasm-R1（2025）引入强化学习与自定义奖励模型，将反讽检测分解为语言、语境和情感三个维度的推理过程。CaRGo-T（2025）基于因果推理图思维的多模态幽默理解框架，通过非线性叙事结构推理提升幽默解释能力。RAM-SD（2026）检索增强多智能体框架，通过动态规划 API 调用和异步执行，解决 LLM 在反讽检测中缺乏自适应推理的问题。CAMMAR（2026）文化感知马特廖什卡嵌入模型，通过嵌套子空间建模阿拉伯语隐喻的层级依赖关系。VIVID（2026）越南语文化扎根基准，通过理论驱动的分类法评估 LLM 在习语理解中的文化推理能力差距。这些工作共同推动了领域从单一文本分类向多模态、跨文化、可解释性综合理解的范式跃迁。

**如果用一个核心问题概括该领域，那便是：如何构建具备跨模态感知与文化接地能力的认知架构，以模拟人类在“不一致性-解决”机制下对非字面语言的深层语用推理过程。**

## 2. 方法体系

- 2010：MIPVU——基于词汇单位在上下文中的字面意义与语境意义不匹配进行隐喻识别的步骤化框架

- 2016：MMSD——首个结合图像与文本的多模态反讽检测数据集，确立了跨模态不一致性作为反讽核心线索的研究范式

- 2017：SemEval-2017 Task 7——针对双关语检测、定位与解释的共享任务，奠定了计算幽默处理中双关语分析的基础数据集与评估标准

- 2019：MUStARD——基于电视情景喜剧视频片段构建的多模态反讽数据集，引入了音频语调与面部表情等细粒度非语言线索

- 2020：MDL Probing——基于最小描述长度理论的探针方法，通过信息论指标评估预训练语言模型在训练过程中对修辞知识的获取轨迹

- 2022：FLUTE——包含9000对字面与修辞句子的基准数据集，通过模型在环生成与人工标注，成为评估LLM修辞理解能力的核心资源

- 2023：MMSD2.0——通过移除噪声样本和重新标注不合理实例改进的多模态反讽数据集，解决了早期数据集的标注不一致问题

- 2025：Sarcasm-R1——引入强化学习（RL）与自定义奖励模型，将反讽检测分解为语言、语境和情感三个维度的推理过程

- 2026：RAM-SD——检索增强多智能体框架，通过动态规划API调用和异步执行，解决LLM在反讽检测中缺乏自适应推理的问题

这条时间线勾勒了该领域方法演进的代表性节点：从 2010 年的 MIPVU 奠定该领域方法基线，经 2016 年 MMSD 的推进，到 2026 年的 VIVID 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 隐喻识别与表征

隐喻识别与表征是修辞语言处理的基础，旨在解决隐喻、转喻等修辞的自动识别、分类及语义表征学习问题。早期方法如 MIPVU 框架通过步骤化分析词汇单位在上下文中的字面意义与语境意义不匹配，奠定了隐喻识别的基础。然而，这种基于规则的方法假设修辞语言可通过静态词汇-语境不匹配识别，受限于算力与数据规模，无法处理动态语境。随着预训练语言模型的兴起，研究重心转向上下文表示学习，但静态架构仍难以处理复杂的语用推理。

FL-MSCL（P16）提出一种由多类型信号和对比学习驱动的统一修辞语言检测模型，旨在解决现有方法中隐喻、转喻和明喻之间的类别歧义问题。该方法采用动态提示与多示例策略，利用 Sentence-BERT 和 FAISS 检索语义最相似的示例，将基于静态定义的注入范式转化为基于示例的类比信号。通过监督对比学习（SCL）在表示空间上强制四个可融合类别之间的清晰边界，防止模态主导并确保平衡的多模态集成。其核心创新在于将字典注入机制替换为动态检索的示例，并结合对比目标以增强类别区分度。该方法在统一训练语料库上合并多个数据集并应用下采样以平衡四类，从而提升模型对多类型修辞的泛化能力。FL-MSCL 为多类别修辞识别提供了可扩展的框架，通过对比学习有效缓解了传统二分类方法在处理复杂修辞类型时的局限性。

CAMMAR（P12）提出一种文化感知马特廖什卡模型，用于构建阿拉伯语隐喻的嵌套嵌入表示，旨在解决 LLM 在文化密集语境下隐喻理解不足的问题。该方法将修辞意义组织为三个维度递减的嵌套嵌入子空间：外层偏向词汇表面形式，中层偏向文化条件意义，内层偏向修辞抽象。通过单一阿拉伯语骨干网络共享参数，并采用三阶段课程学习，在保护先前结构的同时构建后续抽象层。投影头在 token 级别操作，生成每个 token 的嵌套嵌入，从而支持针对跨度标注金标准的逐目标词隐喻性估计。该方法操作化了 AlJurjani 的 naz.m 理论，使隐喻层通过依赖文化和词汇层获取内容，而非直接从词汇形式读取。CAMMAR 通过内部化隐喻性为上下文敏感差异，避免了跨两个模型的复杂对齐，为低资源语言的修辞处理提供了新的表征范式。

MetFuse（P23）提出一种融合转喻与隐喻的数据集与评估框架，旨在分析这两种修辞现象在句子中共存时的交互机制。该方法构建了包含转喻名词与隐喻动词共现的“修辞融合”数据集，如“The stadium erupted with joy”，以捕捉多层意义。通过内在评估分析转喻与隐喻的交互，并通过外在评估验证该数据集在数据增强中对现有隐喻和转喻分类任务的改进效果。实验表明，当训练集用 MetFuse 中的混合示例增强时，模型能更有效地学习名词的转喻用法，这与人类标注者发现转喻名词与隐喻动词配对时更易识别的模式一致。MetFuse 揭示了转喻保持领域连续性而隐喻需要跨领域概念跳跃的结构差异，为理解修辞融合提供了新的数据资源和分析视角。

Surprisal-Novelty Correlation（P5）提出一种基于语料库和合成数据集的方法，用于评估语言模型惊讶度（surprisal）与隐喻新颖度判断之间的相关性。该方法通过计算隐喻目标词在句子级上下文中的词级惊讶度，分析其与不同隐喻新颖度标注（如 MIPVU、Mohler 四点量表）的关联。实验采用教师强制前向传播记录目标词概率，并处理子词到词的对齐问题，以透明和可复现的方式计算惊讶度。研究发现惊讶度与隐喻新颖度存在中等相关性，但不同数据集和模型规模下表现出分歧的缩放效应。该方法为量化隐喻创造性提供了信息论视角，揭示了语言模型在捕捉隐喻新颖性时的局限性，为后续修辞新颖度建模提供了基准。

Shapley-Interaction NLI（P17）提出一种基于 Shapley 交互分析的方法，用于研究 LLM 在处理隐喻语言自然语言推理（NLI）任务中的可解释性。该方法扩展 FLUTE 基准，通过 AI 辅助人工标注源域和目标域，并分析提供这些领域信息对 NLI 性能的影响。利用 Shapley 值量化源域、目标域和解释在 NLI 预测中的贡献，揭示 LLM 在处理隐含隐喻语言时的依赖关系。研究发现添加解释一致地提高性能，但最佳结果是在所有信息（前提、假设、源域、目标域、解释）共同存在时取得。该方法通过 Shapley 交互分析揭示了 LLM 在修辞 NLI 任务中如何利用外部知识，为理解模型处理隐喻的机制提供了可解释性工具。

Learning Trajectories Probing（P21）提出一种通过探针任务研究预训练语言模型在训练过程中获取修辞知识的方法，旨在揭示修辞学习的轨迹。该方法不仅对完全训练的模型进行探针，还对其检查点（中间版本）进行探针，以推导模型在特定方面的学习轨迹。采用最小描述长度（MDL）探针方法，基于信息论测量分类器性能及达到该性能所需的努力，以解决随机表示和控制任务带来的偏差。通过 MDL 探针，研究隐喻、矛盾修辞和夸张等多种修辞形式的学习模式，分析不同修辞是否以不同方式学习。该方法为优化训练过程提供了洞察，揭示了模型规模、层结构与修辞知识获取之间的关系，为理解 NLM 内部修辞表征提供了新视角。

隐喻识别与表征路线为多模态融合提供了语义基础，其核心取舍在于用计算复杂度和推理延迟换取对深层语用意图的捕捉能力。FL-MSCL 通过对比学习有效缓解了传统二分类方法在处理复杂修辞类型时的局限性，而 CAMMAR 通过嵌套子空间建模文化条件意义，为低资源语言的修辞处理提供了新的表征范式。

### 2.2 反讽检测与推理

反讽检测与推理是修辞语言处理的核心任务之一，旨在研究文本及多模态场景下的反讽意图识别与推理机制。早期方法如 MMSD 数据集（2016）确立了跨模态不一致性作为反讽核心线索的研究范式，但受限于静态架构，难以处理动态语境。随着大语言模型的兴起，研究重心从“分类”转向“推理与解释”，试图通过思维链和强化学习模拟深层认知过程。

RAM-SD（P22）提出一种检索增强多智能体框架，将反讽检测重构为动态自适应推理过程，以解决 LLM 缺乏自适应分析能力的问题。该方法受人类认知并行性启发，设计多个智能体协作，通过检索增强生成（RAG）获取上下文知识，并动态规划 API 调用以处理不同类型的反讽。框架包含简单反讽、期望违背和知识依赖推理三种计划，分别需要 4、6 和 7 次 API 调用，且智能体调用可异步执行。通过检索增强，模型能够动态调整分析策略，克服固定架构的局限性，提升对复杂反讽机制的理解。RAM-SD 在多个数据集上显著优于基线模型，特别是在知识依赖推理任务上表现突出，为反讽检测提供了更具适应性和可解释性的多智能体解决方案。

Sarcasm-R1（P18）提出一种通过聚焦推理增强反讽检测的方法，利用强化学习（RL）模拟人类认知过程。该方法将反讽检测分解为语言、语境和情感三个关键维度，并设计自定义奖励模型引导模型在推理过程中关注各维度的核心特征。通过 GRPO（Group Relative Policy Optimization）优化策略模型，使模型在与环境交互中逐步掌握复杂的反讽检测能力。Sarcasm-R1 引入 Sarcasm-Reason 数据集，基于三个维度标注推理过程，以学习更准确的反讽推理。研究发现情感反转在反讽检测中起核心作用，揭示了反讽背后隐藏的情感意图。该方法通过 RL 有效提升了模型的推理质量和反讽检测能力，为模拟人类慢思考过程提供了新范式。

Cross-style Multimodal Reasoning（P6）提出一种跨风格多模态推理框架，旨在赋予紧凑 VLM 解释和泛化不同修辞风格（如反讽、幽默、隐喻）的能力。该方法采用三阶段推理框架：首先从大型教师 VLM 蒸馏思维链（CoT）以提取结构化推理痕迹；其次在较小模型上进行监督微调以内部化推理模式；最后使用基于可验证奖励的强化学习（RLVR）优化推理一致性和事实正确性。框架可应用于单风格或联合训练，后者产生最佳性能的通用推理 VLM。通过 Qwen2.5-VL-3B-Instruct 作为学生模型，该方法在受限模型规模下评估了推理的可扩展性。Cross-style Multimodal Reasoning 通过显式多模态推理能力，解决了单风格方法无法跨修辞风格泛化的问题，为多模态修辞理解提供了通用推理范式。

DOSE（P20）提出一种正交专家调优框架，用于整体多模态反讽理解，旨在解决多任务学习中的特征纠缠问题。该方法采用 LoRA-based MoE 架构，通过任务 ID 嵌入和实例路由投影平衡专家选择，确保模型基于当前图文内容选择专家并快速锁定相关专家组。DOSE 引入自适应任务策略，根据反讽理解子任务对感知和执行的不同依赖关系，动态调整专家权重。通过正交正则化避免无约束专家引入的优化噪声，解决标准微调中的任务冲突。DOSE 在 DocMSU-PLUS 数据集上显著优于基线，特别是在数据效率方面，仅用 1% 数据即可超越基线 5% 以上。该方法通过正交专家调优，将通用反讽感知转化为细粒度执行能力，为多模态反讽理解提供了鲁棒的解决方案。

GDCNet（P7）提出一种生成差异比较网络，用于多模态反讽检测，旨在识别图像与文本之间的跨模态不一致性。该方法通过生成差异特征，防止模态主导并确保平衡的多模态集成，从而捕捉细微的语义不匹配。GDCNet 在 MMSD2.0 数据集上显著优于现有方法，如 Multi-view CLIP 和 TFCD，在准确率和 F1 分数上均取得领先。通过消融实验，验证了生成差异特征模块对性能提升的关键作用。该方法直接针对反讽检测的核心挑战——跨模态不一致性，提供了更有效的特征提取和融合机制。GDCNet 为多模态反讽检测提供了新的架构设计，通过生成式方法增强了对反讽意图的捕捉能力。

ProCrit（P10）提出一种提案-批评双智能体框架，用于多模态反讽检测中的多视角推理。该框架包含提案智能体（起草和修订多视角推理）和批评智能体（提供外部评估和针对性修订指导）。通过动态角色智能体滚动，根据先前分析结果和未解决方面动态生成分析角色，合成过程级推理标注。采用起草-批评-修订范式，通过外部评估和针对性指导提高推理可靠性。互精炼训练策略交替优化两个智能体，批评智能体的反馈改进提案智能体的起草和修订能力，反之亦然。ProCrit 在 MMSD2.0 和 MMSD 数据集上显著优于零样本 CoT 和自动提示工程师等基线，特别是在 F1 分数上表现突出。该方法通过多视角推理和互精炼机制，提升了反讽检测的可靠性和可解释性。

反讽检测与推理路线为幽默理解提供了逻辑框架，其核心取舍在于用系统复杂度和 API 调用成本换取自适应推理能力。RAM-SD 通过动态规划 API 调用解决 LLM 缺乏自适应推理的问题，而 Sarcasm-R1 通过强化学习模拟人类慢思考过程，提升了模型的推理质量和反讽检测能力。

### 2.3 幽默理解与生成

幽默理解与生成是修辞语言处理的重要分支，旨在探索幽默（如双关、笑话、卡通）的理解、解释与生成任务。早期方法如 SemEval-2017 Task 7（2017）奠定了计算幽默处理中双关语分析的基础数据集与评估标准，但受限于静态架构，难以处理动态语境。随着大语言模型的兴起，研究重心从“分类”转向“推理与解释”，试图通过思维链和强化学习模拟深层认知过程。

CaRGo-T（P14）提出一种基于因果推理图思维（Graph-of-Thought）的方法，用于提升多模态幽默理解能力。该方法通过构建因果推理图，捕捉笑话中人物、对象、概念和事件之间的复杂关系，揭示细微的不协调性。CaRGo-T 在讽刺图像理解和表情包字幕生成任务上显著优于 CoT 和 Vanilla 基线，特别是在 BLEU 和 BERTScore 指标上表现突出。通过非线性叙事结构和符号不协调性的推理，CaRGo-T 能够检测和欣赏使笑话产生共鸣的意外联系。该方法在 MiniCPM 和 GPT-4o 等模型上验证了其有效性，特别是在少样本设置下表现优异。CaRGo-T 为多模态幽默理解提供了新的推理范式，通过因果图结构增强了模型对社会推理和文化素养的捕捉能力。

HOMER（P24）提出一种基于冲突脚本的多角色框架，用于幽默字幕生成，旨在解决 LLM 内在幽默生成机制薄弱的问题。该方法分为两个阶段：脚本提取和想象。在脚本提取阶段，从卡通图像中提取脚本对立和情境描述，定义脚本对立并设计提示。在想象阶段，从局部和全局视角选择候选目标，通过深度模式想象形成骨干链，生成幽默字幕。HOMER 通过多角色协作和冲突脚本机制，结合视觉理解、幽默理解、创造性想象和风格表达，生成更有趣的字幕。该方法在幽默字幕生成任务上显著优于通用提示方法，为多模态幽默生成提供了新的框架。HOMER 通过结构化想象过程，提升了 LLM 在幽默生成中的创造性和风格表达能力。

Pun Unintended（P1）提出一种评估 LLM 双关语理解能力的方法，旨在揭示 LLM 在幽默理解中的幻觉问题。该方法利用 SemEval-2017 和 JOKER 数据集，评估 LLM 在双关语检测、定位和解释任务上的表现。研究发现 LLM 在双关语检测上表现较强，但在正确语义关联上表现较弱，存在显著的幻觉现象。通过修正 SemEval-2017 数据集中的拼写错误和错误标注，构建了更高质量的双关语数据集。Pun Unintended 揭示了 LLM 在处理双关语时依赖表面启发式而非深层语义理解，为计算幽默处理提供了重要洞察。该方法为评估 LLM 幽默理解能力提供了基准，揭示了当前模型在双关语解释上的局限性。

Comparing Apples to Oranges（P15）提出一种从传统双关语到话题笑话的 LLM 幽默理解数据集与分析方法，旨在评估 LLM 在不同幽默类型上的表现。该方法构建了包含同形双关、异形双关、非话题笑话和话题笑话的数据集，并通过人工评估 LLM 生成的幽默解释。评估标准包括准确性和完整性，采用 0-5 分制评分。研究发现较大模型变体在话题幽默上表现更好，因其能存储更多特定事件和个体的信息。Comparing Apples to Oranges 揭示了 LLM 在幽默理解上的类型依赖性，为计算幽默处理提供了新的评估视角。该方法通过多类型幽默数据集，全面评估了 LLM 的幽默理解能力，为后续研究提供了基准。

RAGthoven（P11）提出一种多阶段流水线，用于多语言幽默生成，旨在解决 SemEval-2026 Task 1 中的幽默生成挑战。该方法将幽默生成分解为四个提示阶段：构思（Planner）、候选生成（Writer）、自我批评（Reflector）和选择（Judge）。通过 RAG 增强规划（EXP08），结合检索增强生成和智能体工具，提升幽默生成的新颖性和文化适应性。RAGthoven 在英语、西班牙语和中文上进行了实验，评估了不同模型配置的效果。该方法通过结构化创意过程，确保生成内容符合任务约束（如关键词、标题引用、长度限制）。RAGthoven 为多语言幽默生成提供了新的框架，通过多阶段流水线提升了 LLM 的幽默创造性和约束满足能力。

幽默理解与生成路线为多模态修辞理解提供了创意框架，其核心取舍在于用结构化创意过程换取幽默生成的创造性和约束满足能力。CaRGo-T 通过因果图结构增强了模型对社会推理和文化素养的捕捉能力，而 HOMER 通过结构化想象过程提升了 LLM 在幽默生成中的创造性和风格表达能力。

### 2.4 多模态修辞理解

多模态修辞理解是修辞语言处理的前沿方向，旨在关注图文、音视频等多模态语境下修辞语言的理解与生成。早期方法如 MMSD 数据集（2016）确立了跨模态不一致性作为反讽核心线索的研究范式，但受限于静态架构，难以处理动态语境。随着大语言模型的兴起，研究重心从“分类”转向“推理与解释”，试图通过思维链和强化学习模拟深层认知过程。

CaRVE（P26）提出一种批评和精炼视觉阐述的方法，用于修辞语言插图生成，旨在解决现有文本到图像框架中语义漂移和对齐问题。该方法采用两阶段流程：首先通过思维链提示生成中间视觉阐述，然后使用批评模型精炼这些阐述，确保其与修辞文本的意图意义对齐。CaRVE 构建了 MetaCaRVE 数据集，包含 1100 个由修辞隐喻和合成图像组成的实例，用于评估修辞插图生成的有效性。通过增加批评传递次数，分析其对性能和计算成本的影响。CaRVE 通过批评-精炼机制，显著提升了生成图像与修辞文本的对齐度，为多模态修辞理解提供了新的数据资源和评估框架。

MuSaG（P3）提出一个多模态德语反讽数据集，包含全模态标注，旨在解决现有数据集缺乏细粒度音频和视觉线索的问题。MuSaG 从电视和电影内容中构建，提供对齐的音频-视觉组件，并包含细粒度的反讽标注。该方法评估了最先进单模态和多模态模型（包括商业和开源模型）在不同模态配置下的表现。研究发现当前多模态模型未能有效利用音频和视觉线索，主要依赖文本。MuSaG 为多模态反讽检测提供了新的基准，通过全模态标注揭示了模型在非语言线索利用上的局限性。该方法为多模态修辞理解提供了丰富的数据资源，推动了反讽检测向更细粒度模态融合方向发展。

CFMS（P8）提出一个可解释和细粒度的中文多模态反讽检测基准，旨在解决现有基准缺乏文化扎根语义反转解释的问题。CFMS 包含三个渐进层次子任务：反讽识别、反讽目标识别和反讽解释。通过定义映射函数，将多模态输入映射到二元标签、目标集合和解释文本。CFMS 揭示了中文多模态反讽中文化扎根语义反转的挑战，如“装上全部一致的脑袋”与传送带图像的对比。该方法通过细粒度任务设计，评估模型在识别、定位和解释反讽方面的能力。CFMS 为中文多模态反讽检测提供了新的基准，通过文化扎根分析揭示了模型在跨文化修辞理解上的局限性。

Lenses（P25）提出一种多提示嵌入模型和数据集，用于多义视觉-语言理解，旨在解决主流 VLM 假设图像具有单一字面意义的问题。Lenses 数据集包含 105,669 张图像和 732,405 个字幕，每张图像与多个字幕配对，涵盖日常场景和艺术作品。通过 InternVL3.5-38B 进行二元分类提示过滤，识别具有丰富解释潜力的图像。Lenses 采用多提示嵌入，建模图像与文本之间的多对多关系，使用解释性镜头捕捉不同视角。训练目标包括对比损失、镜头对齐损失和图像内提示多样性损失。Lenses 为多义视觉-语言理解提供了新的范式，通过多镜头机制提升了检索的鲁棒性和多样性。

多模态修辞理解路线为低资源文化基准提供了数据资源，其核心取舍在于用多模态融合机制换取跨模态不一致性检测能力。CaRVE 通过批评-精炼机制显著提升了生成图像与修辞文本的对齐度，而 MuSaG 通过全模态标注揭示了模型在非语言线索利用上的局限性。

### 2.5 低资源与文化基准

低资源与文化基准是修辞语言处理的重要补充，旨在构建面向特定语言（如孟加拉语、越南语、信德语）或文化背景的低资源修辞基准。早期方法如 MMSD 数据集（2016）确立了跨模态不一致性作为反讽核心线索的研究范式，但受限于静态架构，难以处理动态语境。随着大语言模型的兴起，研究重心从“分类”转向“推理与解释”，试图通过思维链和强化学习模拟深层认知过程。

FLUID QA（P19）提出一个多语言修辞语言使用对话基准，涵盖英语、中文和韩语，旨在评估 LLM 在真实世界对话中部署修辞表达的能力。该方法基于 FLUTE 数据集，通过文化适应翻译构建多语言数据，评估 LLM 不仅能否识别修辞表达，还能否在对话中连贯使用。FLUID QA 提供了跨语言分析，展示了修辞识别和使用分歧，揭示了模型在不同语言和文化背景下的能力差异。该方法通过对话级评估，超越了现有句子级分类或推理任务的局限。FLUID QA 为多语言修辞理解提供了新的基准，通过文化适应翻译揭示了 LLM 在跨文化修辞使用中的局限性。

BengaliFig（P4）提出一个低资源挑战基准，用于孟加拉语修辞和文化扎根推理，旨在评估 LLM 在低资源语言中的修辞理解能力。该方法从博客、论坛和数字档案中抓取谜语，通过去重、归一化和人工审计构建语料库。BengaliFig 评估了 GPT-4.1、Claude Sonnet 4.0、DeepSeek-V3.12 等 LLM 在零样本和少样本思维链提示下的表现。研究发现 LLM 在孟加拉语修辞推理上存在显著盲点，特别是在文化扎根推理方面。BengaliFig 为低资源语言修辞理解提供了新的基准，通过谜语任务揭示了 LLM 在跨文化修辞推理上的局限性。

SiNFluD（P9）提出一个信德语修辞语言数据集，旨在解决低资源语言中修辞表达识别和分类的挑战。该方法构建了包含习语、反讽、隐喻、讽刺和转喻的数据集，通过文化嵌入和语义漂移分析，评估模型在跨语言迁移中的表现。SiNFluD 评估了 mBERT、XLM-RoBERTa 等预训练语言模型在二元分类任务上的表现，揭示了模型规模和预训练策略在捕捉修辞细微特征中的重要性。该方法通过低资源数据集，揭示了信德语修辞处理中的文化嵌入和语用歧义问题。SiNFluD 为低资源语言修辞理解提供了新的数据资源，推动了跨文化修辞研究的进展。

VIVID（P13）提出一个越南语文化扎根基准，旨在暴露越南语 NLP 中修辞语言差距。该方法构建了包含 1636 个习语和谚语的基准，涵盖 7 个主题，捕捉越南语文化语境。通过理论驱动的分类法，组织越南语习语的语言和文化特征，评估 LLM 在习语理解中的能力。VIVID 采用方面基于评估策略，通过 GPT-4.1 自动评分，并与人工标注对比，验证了评估的可靠性。研究发现越南语专门模型和通用模型在习语理解上存在显著差距，特别是在文化扎根推理方面。VIVID 为越南语修辞理解提供了新的基准，通过文化扎根分析揭示了 LLM 在低资源语言修辞处理上的局限性。

BengFoS（P27）提出一个孟加拉语修辞识别数据集，包含 3148 个专家标注的文学句子，旨在评估 LLM 在孟加拉语修辞分类中的能力。该方法通过微调 Llama-3 和 DeepSeek R1 等 LLM，进行孟加拉语修辞分类任务，并应用线性探针分析模型隐藏层中的修辞知识。研究发现孟加拉语修辞分类具有固有难度，模型仅获得适度提升。通过探针分析，揭示了修辞相关语义和词汇线索在不同模型深度中的分布，不同层专门化不同修辞知识。BengFoS 为孟加拉语文学分析提供了新的数据资源和探针方法，揭示了 LLM 在低资源语言修辞理解中的内部表征机制。

低资源与文化基准路线为多模态修辞理解提供了文化接地数据，其核心取舍在于用文化感知嵌入换取跨文化修辞推理能力。FLUID QA 通过文化适应翻译揭示了 LLM 在跨文化修辞使用中的局限性，而 BengaliFig 通过谜语任务揭示了 LLM 在跨文化修辞推理上的局限性。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

修辞语言理解需要超越字面语义，结合语境、常识和文化背景进行深层推理，这一共识在多个基准上被反复验证。FL-MSCL 在 VUA-Verb 上的 88.9 F1 与 GDCNet 在 MMSD2.0 上的 78.5 F1 均大幅超越传统方法，表明深层推理在提升修辞理解性能方面的有效性。与此相关的另一个共识是多模态信息（特别是视觉和音频线索）对于准确识别讽刺和幽默至关重要，单模态文本往往不足。MuSaG 基准显示当前多模态模型未能有效利用音频和视觉线索，主要依赖文本，但 CFMS 基准通过文化扎根语义反转解释提升了模型性能，表明多模态融合在特定场景下的必要性。

大语言模型（LLMs）在零样本修辞检测上表现优于传统预训练语言模型（PLMs），但在细粒度推理和解释任务上仍有显著差距，这一共识在多个低资源基准上得到支持。BengaliFig 和 VIVID 基准显示 LLM 在孟加拉语和越南语修辞推理上存在显著盲点，特别是在文化扎根推理方面。显式的推理过程（如思维链 CoT）能显著提升模型在复杂修辞任务中的性能和可解释性，Sarcasm-R1 和 CaRGo-T 通过强化学习和因果推理图思维提升了模型的推理质量和幽默解释能力。然而，Pun Unintended 揭示了 LLM 在处理双关语时依赖表面启发式而非深层语义理解，表明 CoT 在复杂文化语境中可能引入幻觉。

### 3.2 观点分歧

显式推理链（CoT）是否真正提升深层修辞理解，还是仅增加表面一致性，是领域内的核心分歧。观点 A 认为 CoT 通过模拟人类认知过程，显著提升复杂修辞任务（如讽刺解释、幽默生成）的性能和可解释性，代表方法包括 Sarcasm-R1 和 CaRGo-T。观点 B 认为 CoT 在简单任务有效，但在复杂文化语境中可能引入幻觉，LLM 依赖表面启发式而非深层语义理解，代表方法包括 Pun Unintended 和 Comparing Apples to Oranges。现有证据偏向观点 A 在简单/中等复杂度任务上有效，但观点 B 在复杂文化/幽默任务上得到支持。证据强度中等，缺乏统一的跨文化、多模态综合基准来定输赢。测量工具盲区是未定论的主要原因，现有指标（F1, BLEU）无法区分“真实推理”与“表面一致性”，需要更细粒度的认知评估协议。

检索增强（RAG）能否解决文化接地问题，还是仅缓解知识缺失，是另一个根本性争论。观点 A 认为 RAG 通过引入外部知识库，有效缓解 LLM 在文化特定或时效性修辞上的知识缺失，提升跨文化理解，代表方法包括 RAM-SD 和 RAGthoven。观点 B 认为 RAG 无法解决深层文化逻辑断连，模型在低资源语言中仍存在显著盲点，需文化感知嵌入，代表方法包括 CAMMAR、VIVID 和 BengaliFig。现有证据偏向观点 B，RAG 在知识密集任务上有效，但在文化推理任务上效果有限。证据强度较强，多个低资源基准（VIVID, BengaliFig）显示 LLM 在文化接地推理上表现不佳。场景依赖是未定论的主要原因，文化接地涉及深层逻辑和隐喻映射，RAG 仅提供表面知识，缺乏对文化逻辑的建模能力。

### 3.3 其他开放问题

当前领域面临的最紧迫工程问题是如何提升多模态非文本线索利用。现有模型主要依赖文本线索，未能有效利用音频、视频等非文本模态中的讽刺线索，需研究多模态融合机制，解决模态主导和虚假相关性问题，实现真正的多模态理解，特别是韵律和语调在讽刺检测中的作用。关键困难在于模态间语义对齐困难，缺乏细粒度的跨模态交互机制。研究路径包括使用对比学习和多智能体框架来解耦并融合多模态信号，例如 GDCNet 通过生成差异特征捕捉细微的语义不匹配，ProCrit 通过多视角推理提升反讽检测的可靠性。

最根本的研究问题是深化修辞机制的因果推理。幽默和讽刺理解需要因果推理和脚本冲突分析，需研究因果推理图（Causal Reasoning Graphs）和思维链（CoT）的改进，解决模型在复杂幽默机制（如双关、反讽）上的理解局限，提升对隐含意图和跨域映射的推理能力。关键困难在于缺乏统一的细粒度标注标准和跨类型对比学习策略。研究路径包括通过多任务学习和对比学习来明确类型边界，例如 MetFuse 通过融合转喻与隐喻的数据集揭示修辞融合的结构差异，CaRGo-T 通过因果推理图思维提升多模态幽默理解能力。

已知—争议—未知认知图谱显示，领域在深层推理和多模态融合上已取得显著进展，但在文化接地和动态语境建模上仍存在争议。未来发展趋势将依赖于多模态、多智能体与文化接地的深度融合，构建具备跨模态感知与文化接地能力的认知架构，以模拟人类在“不一致性-解决”机制下对非字面语言的深层语用推理过程。

## 4. 总结与展望

修辞语言处理正从“模式识别”向“认知模拟”跃迁，核心矛盾在于如何构建具备跨模态感知与文化接地能力的认知架构，以模拟人类在“不一致性-解决”机制下对非字面语言的深层语用推理过程。早期方法依赖规则与浅层特征，受限于静态架构，难以处理动态语境。随着预训练语言模型和大语言模型的兴起，研究重心从“分类”转向“推理与解释”，试图通过思维链和强化学习模拟深层认知过程。然而，现有模型在深层语用推理上仍显不足，缺乏真正的世界模型和动态语境整合能力。多模态融合机制优化、低资源数据构建、推理链效率提升是当前的工程瓶颈，而修辞知识的内部表征机制、文化逻辑的跨语言迁移、动态语境下的意图推断是根本的研究未知。

未来可能突破的方向包括：统一判别与生成能力，通过强化学习或对比学习增强模型的可解释性，解决内部表征与输出行为不一致的问题；提升低资源语言与文化特异性修辞理解，构建更多文化接地数据集，探索跨语言迁移学习，解决文化断连和字面过度解释问题；深化修辞机制的因果推理，研究因果推理图和思维链的改进，提升对隐含意图和跨域映射的推理能力。这些方向由 Sarcasm-R1、CaRGo-T、CAMMAR 等多篇论文共同指向，表明领域正朝着多模态、多智能体与文化接地深度融合的方向发展。对于进入该领域的研究者，最值得做的一件事是构建统一的跨文化、多模态、动态语境综合基准，以评估模型在深层语用推理上的真实能力，解决现有评测体系的盲区。
