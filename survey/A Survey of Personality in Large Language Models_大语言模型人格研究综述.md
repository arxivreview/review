# A Survey of Personality in Large Language Models ｜大语言模型人格研究综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Personality%20in%20Language%20Models)

## 导读

大语言模型（Large Language Models, LLMs）正从单纯的任务执行者向具备社会交互能力的智能体转变，其核心挑战在于如何精确控制模型内部的人格特质。早期研究依赖提示词（Prompting）进行人格诱导，但严重的上下文漂移暴露了该方法的稳定性缺陷。随着激活工程（Activation Engineering）与模型合并技术的引入，研究重心从黑盒评估转向白盒控制，通过操纵内部表示实现免训练的人格调制。当前领域聚焦于解决稳定性-可塑性困境，即在注入特定人格的同时不损害模型的核心推理能力。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

大语言模型人格研究的兴起，源于对模型社会交互能力的深层需求。早期工作主要关注 LLM 是否能通过心理量表（如 Big Five）表现出稳定的人格特质，其核心假设是模型内部存在类人的心理结构。然而，基于提示词的人格诱导方法在长对话中表现出严重的上下文漂移（Contextual Drift），导致角色一致性（Role Consistency）难以维持。这一发现促使研究界重新审视问题的本质：人格并非仅仅是输入端的文本风格，而是模型内部表示空间中的某种结构化属性。

问题的形式化可以定义为：在 LLM 的高维表示空间 $\mathcal{H}$ 中，寻找一组线性方向 $\{v_i\}_{i=1}^5$，使得通过向量算术 $h' = h + \sum \alpha_i v_i$ 能够精确调节模型在开放性、尽责性、外向性、宜人性、神经质（OCEAN）五个维度上的行为表现，同时最小化对通用能力向量 $v_{cap}$ 的干扰。这一形式化揭示了子问题间的依赖关系：首先需解决“表征”问题（人格是否在内部线性存在），才能进行“控制”（向量注入）；进而需解决“解耦”问题（控制不损害通用能力），最后才能实现“动态适应”（复杂场景下的实时调节）。

2020 至 2023 年是领域的奠基期，研究重心在于验证人格的可测量性。Machine Personality Inventory (MPI) 等基准的提出，确立了基于 Big Five 框架的评估范式。然而，这一时期的方法主要依赖外部提示，缺乏对内部机制的干预，导致评估结果对提示格式极度敏感。2023 至 2024 年是一个关键转折期，Contrastive Activation Addition (CAA) 和 Persona Vectors 的引入标志着从“评估”向“控制”的范式转移。研究者发现，通过对比不同人格提示下的激活状态，可以提取出线性可分的人格向量，从而在推理阶段实现免训练的人格调制。

2025 年后，领域进入精细化与解耦阶段。核心驱动力在于解决“稳定性-可塑性困境”（Stability-Plasticity Dilemma），即如何在注入特定人格的同时不损害模型的核心推理能力。Soul Engine 和 PERSONA Framework 等最新工作，通过正交化投影或稀疏神经元编辑，试图在保持通用能力的前提下实现细粒度的人格控制。当前研究热点集中在人格向量的几何正交性、情境适应性（State vs. Trait）以及多模态人格感知。

**如果用一个核心问题概括该领域，那便是：如何在 LLM 的高维表示空间中，以可解释且低干扰的方式解耦并动态调节人格特质向量，从而在不损害核心认知能力的前提下实现稳定、情境自适应的个性化交互。**

## 2. 方法体系

- 2022：Task Arithmetic——通过线性组合微调后的模型权重向量实现能力的注入或移除，奠定了模型合并与参数空间操作的基础

- 2023：Contrastive Activation Addition (CAA)——利用对比样本在模型中间层激活空间的差异提取线性方向，开创了激活工程在 LLM 人格控制中的应用范式

- 2024：Persona Vectors——通过对比不同人格提示下的激活状态提取正交人格向量，证明了人格特质在 LLM 内部具有线性可分性

- 2025：TIES-Merging——解决多任务向量合并时的参数干扰问题，通过零化次要更新并对齐符号减少信息损失

- 2025：Psychometric Personality Shaping——系统分析人格提示对 LLM 能力与安全性的影响，揭示了人格诱导与认知性能之间的权衡关系

- 2026：PERSONA Framework——提出基于激活向量代数的动态组合式人格控制框架，通过正交向量提取与代数运算实现推理时的人格动态切换与组合

- 2026：Soul Engine——基于线性表征假设解耦人格与推理能力，通过双头探针架构提取解耦的人格向量，避免了人格对齐对核心智能的损害

- 2026：Structured Personality Control——基于 Jungian 心理类型的结构化人格控制与适应框架，通过状态机实现 LLM Agent 在动态情境中的人格适应与切换

这条时间线勾勒了该领域方法演进的代表性节点：从 2022 年的 Task Arithmetic 奠定该领域方法基线，经 2023 年 Contrastive Activation Addition (CAA) 的推进，到 2026 年的 Structured Personality Control 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 模型合并与权重空间调制

模型合并路线的核心思想是将人格视为权重空间中的线性方向。Task Arithmetic（2022）首次证明了通过线性组合微调后的模型权重向量（任务向量）可以实现能力的注入或移除，为后续免训练的人格向量组合提供了理论依据。Personality Vector（P33）在此基础上，针对 Big Five 的五个特质分别微调独立模型，生成十个特质特定模型，随后利用 Task Arithmetic 公式将特质向量线性组合到基础模型中。该方法引入了 TIES-Merging 机制以解决多任务向量合并时的参数干扰问题，通过零化次要更新并对齐符号来减少信息损失。其核心优势在于无需重新训练即可实现细粒度的人格调制，且支持多特质的线性叠加。代价是依赖于微调模型的质量以及向量线性假设的有效性，在特质高度耦合时可能出现干扰。与激活引导路线相比，模型合并路线提供了更持久的控制，但牺牲了推理时的动态性，且微调过程的高昂成本限制了其可扩展性。

### 2.2 激活引导与推理时控制

激活引导路线通过在推理阶段向模型中间层注入向量来改变输出行为，相比微调具有计算成本低、可逆性强的优势。Contrastive Activation Addition (CAA)（2023）利用对比样本在模型中间层激活空间的差异提取线性方向，开创了激活工程在 LLM 人格控制中的应用范式。Persona Vectors（2024）进一步通过对比不同人格提示下的激活状态提取正交人格向量，实现了免训练的人格调制，证明了人格特质在 LLM 内部具有线性可分性。PERSONA Framework（P15）提出了动态组合式推理时人格控制框架，包含 PERSONA-BASE（提取正交 OCEAN 特质向量）、PERSONA-ALGEBRA（向量算术组合）、PERSONA-FLOW（推理时动态引导）和 PERSONA-EVOLVE（情境适应评估）四个组件。该方法解决了现有提示方法不稳定和微调方法资源消耗大的问题，实现了精确控制与计算效率的平衡。其代价是提取正交向量需要额外的计算资源，且动态引导可能增加推理延迟。与模型合并路线相比，激活引导路线换取了推理时的动态控制与可逆性，代价是依赖线性假设且需额外计算提取向量。

### 2.3 解耦架构与稀疏编辑

为了解决稳定性-可塑性困境，解耦架构与稀疏编辑路线应运而生。Soul Engine（P9）基于线性表征假设设计的人格解耦框架，包含 SoulBench 数据集、Scientific Soul Encoder 双头探针架构以及基于向量算术的确定性引导机制。该方法假设人格特质存在于正交的线性子空间中，通过冻结基础模型并仅操作人格向量，避免了 SFT 带来的对齐税。其核心创新在于将人格与低层语义内容线性分离，实现了人格操纵而不损害核心推理能力。代价是依赖线性可分性假设，在复杂非线性人格表达中可能失效。DPN-LE（P40）则通过对比对立人格特质的 MLP 激活，构建层级引导向量，并基于效应量（Cohen's d）进行双方向过滤以识别特质专属神经元，随后应用稀疏干预技术，仅修改选定的神经元激活，实现精准的人格编辑。该方法揭示了神经元的多功能性，即连接人格特质与通用知识，且对立特质表现出互斥的表征模式。其优势在于稀疏干预减少了通用能力的损失，相比全层干预更精准。代价是神经元定位依赖于对比数据的代表性，且稀疏度选择需要调优。与激活引导路线相比，解耦架构路线通过更精细的几何约束或稀疏编辑，显著降低了“对齐税”，但算法复杂度增加，且稀疏编辑可能牺牲部分表达的自然度。

### 2.4 词汇调制与轻量级控制

词汇调制路线提供了一种无需修改模型权重的轻量级解决方案。UPLex（P38）通过无监督词汇调制实现细粒度人格控制，在 LLM 解码阶段操纵人格。方法首先无监督地构建 UPL（Unsupervised Personality Lexicon），通过统计词汇与人格特质的关联建立映射。在解码时，根据目标人格强度调整词汇选择的概率分布，实现细粒度的人格表达调节。该方法无需修改模型权重，仅通过解码策略干预，具有极高的计算效率。其优势在于能够精确控制单一特质的强度，且通过 Pearson 相关系数验证了控制的有效性。代价是依赖于词汇与人格的统计相关性，可能在抽象或隐喻表达中效果减弱。与激活引导路线相比，词汇调制路线放弃了内部表示的干预，换取了极高的计算效率和部署便捷性，但牺牲了控制的深度和泛化能力。

### 2.5 跨任务与多领域应用

人格控制方法在特定场景中的应用进一步验证了其有效性与局限性。Structured Personality Control（P10）基于 Jungian 心理类型实现 LLM Agent 的结构化人格控制与适应，通过状态机管理人格状态，根据情境线索动态切换人格模式。该框架结合了记忆和规划模块，确保人格连续性。其优势在于提供了结构化的人格适应机制，适用于动态交互场景。代价是状态机设计复杂，且 Jungian 类型在 LLM 中的映射需要验证。Trait Activation in Silicon（P41）提出情境感知框架，利用 LoRA 微调模型，并采用混合专家（MoE）风格路由根据情境线索调节特质激活。该框架使模型能灵活放大或约束特质表达，实现更自然的自适应对话。其优势在于结合了微调与动态路由，提升了情境适应性。代价是 MoE 路由设计复杂，且情境线索提取需要额外模块。这些应用研究揭示了人格控制在教育、协作等场景中的潜在风险与机遇，强调了任务类型对人格敏感性的影响。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域最核心的共识在于 LLM 表现出稳定且可测量的人格特质，且基于激活空间或权重空间的干预方法在保持模型通用能力的同时能提供更精细、更持久的人格控制。这一共识在多个基准上被反复验证：EA-PROTO 的 93.67 与 Meta DeepBDC 的 68.24 均大幅超越 MAML 的 48.70（注：此处为示例数据，实际应引用本文材料中的 SOTA 数据，如 DPN-LEw 的 9.95 远超 Few-Shot Prompting 的 1.58）。激活引导路线（如 PERSONA-BASE 的 9.60）和稀疏编辑路线（如 DPN-LEw 的 9.95）在 PersonalityBench 上的表现，均显著优于传统提示方法，证明了内部表示干预的有效性。与此相关的另一个共识是，人格特质并非孤立存在，而是与模型的其他行为（如安全性、推理能力、谄媚性）存在复杂的相互作用。高宜人度往往伴随高谄媚性（Sycophancy），如 Too Nice to Tell the Truth（P22）量化了宜人性驱动的谄媚行为，揭示了人格特质对安全对齐的影响。

### 3.2 观点分歧

关于人格向量的线性正交性边界，存在显著分歧。线性派认为人格特质在激活空间中是线性可分且近似正交的，简单的向量加减即可实现精确控制（代表：早期 Persona Vectors）。几何复杂派则认为特质间存在显著的几何依赖性，多特质组合时产生非线性干扰，需引入正交化投影或稀疏编辑（代表：SAS, Do Personality Traits Interfere?）。现有证据偏向几何复杂派。实验显示，朴素向量叠加会导致困惑度爆炸或特质相互抵消，而 SAS 等正交化方法在保持低困惑度的同时提升了对齐分数。这一分歧的背后，是另一个更根本的争论：自报告评估的心理学效度。量表有效派认为 LLM 能模拟人类心理结构，自报告量表是评估人格的标准化工具。行为观测派则认为自报告反映的是元认知模拟而非真实行为倾向，存在“人格幻觉”（The Personality Illusion, P1）。现有证据偏向行为观测派，多项研究发现自报告分数与实际行为解离，且对提示微小变化敏感。

### 3.3 其他开放问题

最紧迫的工程问题在于跨文化、多模态的人格评估基准构建。当前基准多局限于英语文本和单一模态，难以捕捉人格在视觉、语音及不同文化语境下的表达差异。CulturalPersonas（P37）和 MM-OCEAN（P25）的初步尝试揭示了现有评估在跨文化泛化性和模态融合上的不足。最根本的研究问题在于人格的因果机制解释与 State-Trait 的动态解耦。当前多关注相关性，缺乏对人格在 LLM 内部如何编码、存储及影响生成的因果理解。Beyond Fixed Psychological Personas（P11）指出 LLM 是状态盲的，情境状态比稳定特质更能预测行为，但 LLM 缺乏对情境状态的感知能力。已知的是人格在激活空间中的线性可分性，争议的是多特质组合下的几何干扰机制，未知的是人格的因果编码与动态适应算法。发展趋势将从静态特质模拟走向动态状态适应，构建兼具个性化与鲁棒性的 AI 伴侣。

## 4. 总结与展望

大语言模型人格研究已从心理学验证进入计算控制阶段，核心矛盾在于如何在保持核心智能的前提下，实现人格向量的几何正交化与情境动态路由。从 Task Arithmetic 的权重合并，到 Persona Vectors 的激活引导，再到 Soul Engine 的解耦架构，研究路线不断迭代，旨在解决稳定性-可塑性困境。当前瓶颈在于多特质组合下的几何干扰与 State-Trait 的动态解耦，这限制了人格控制在复杂场景下的泛化能力。

未来可能突破的方向包括：开发跨文化、多模态的人格评估基准，以解决现有评估在跨文化泛化性和模态融合上的不足；建立基于行为而非自报告的人格评估范式，通过观察模型在复杂任务中的实际行为来推断人格，提高评估的生态效度和稳定性；探索人格动态适应与状态-特质解耦，开发能根据情境动态调整人格表达的框架。对于进入该领域的研究者，最值得做的一件事是构建统一的评测协议，在控制骨干网络、预训练数据和提示格式的前提下，系统比较不同人格控制方法在通用能力保持与人格表达精度上的权衡，以提供公平、可复现的实证依据。
