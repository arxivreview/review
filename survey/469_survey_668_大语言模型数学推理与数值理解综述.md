# A Survey of Mathematical Reasoning and Numerical Understanding in LLMs ｜大语言模型数学推理与数值理解综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Mathematical%20Reasoning%20and%20Numerical%20Understanding%20in%20LLMs)

## 导读

大语言模型（LLM）在数学任务中的表现长期存在“高分幻觉”，其核心矛盾在于静态基准上的高准确率与输入微小扰动下的性能崩塌之间的巨大反差。早期研究以思维链（Chain-of-Thought, CoT）提示为主线，通过生成中间步骤提升解题能力，思路直观却受制于推理忠实性缺失与数值表示的非连续性。当对抗性评估暴露出模型对表面模式的过度依赖后，研究者转向动态生成基准与过程奖励模型（Process Reward Model, PRM），用更严格的评估协议换取对真实推理能力的精准诊断。各路线在内部表征优化、外部工具增强与过程监督之间做出了不同取舍，由此形成当前多元并存且互补的方法格局。本综述梳理这条从结果导向到过程验证的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

大语言模型数学推理研究的起点，是对模型是否具备超越简单算术的深层逻辑能力的质疑。2021 年，GSM8K 与 MATH 基准的发布确立了早期标准，前者包含 8.5k 道小学水平多步算术题，后者涵盖 12,500 道高中及大学水平竞赛题，二者共同定义了“能否解题”这一核心问题。此时的隐含假设是静态数据足以反映推理能力，模型只需通过预训练习得基础算术并执行多步推导即可。问题形式化通常遵循 N-way K-shot 范式，即给定少量示例 $D_{train} = \{(x_i, y_i)\}_{i=1}^K$，模型需在新问题 $x_{test}$ 上生成正确解答 $y_{test}$，其中 $x$ 为自然语言描述，$y$ 为数值或符号答案。

随着 2022 年 CoT 提示的引入，模型在复杂问题上的准确率显著提升，但同时也暴露了“模式匹配”而非“深度推理”的脆弱性。2023-2024 年成为关键转折期，GSM-Symbolic 等对抗性评估方法通过系统改变问题中的数字和实体名称，揭示出模型在输入发生微小扰动时性能急剧下降。这一发现重构了子问题间的依赖关系：数值表示缺陷（底层机制）导致算术错误，进而引发鲁棒性不足（表层现象）；而静态基准的污染（评估缺陷）则掩盖了上述机制问题。因此，解决评估污染是揭示真实推理能力的前提，而改进数值表示与过程监督则是提升鲁棒性的根本路径。

约束演化史清晰地展示了方法如何因应约束变化而演变。2016-2018 年奠基期，研究聚焦于基础算术能力，MultiArith 和 MAWPS 等基准确立了纯算术运算序列的评测标准。2020 年跨域基准转折，SVAMP 等数据集引入干扰信息，测试模型对无关数字的鲁棒性，标志着从“解题”向“抗干扰”的过渡。2021 年预训练与 CoT 引入，Chain-of-Thought 成为主流范式，通过增加计算路径长度弥补单次前向传播的局限。2023-2025 年细化与融合，PAL 和 AgentMath 等工具增强方法出现，解决纯文本模型在精确计算上的固有缺陷；同时，MatheMagic 等动态基准兴起，应对静态数据饱和与污染问题。当前形态下，领域处于从“结果导向”向“过程导向”和“机制可解释性”转型的活跃期，重点探讨数值表示的几何结构、工具增强推理以及神经符号系统的融合。

**如果用一个核心问题概括该领域，那便是：如何构建一种兼具数值几何连续性、逻辑过程可验证性且对表面形式扰动鲁棒的推理架构，以区分 LLM 的“统计记忆”与“算法推理”？**

## 2. 方法体系

- 2021：GSM8K——构建包含8500道小学水平多步算术应用题的基准数据集，通过评估模型在基础数学推理上的表现确立早期标准

- 2022：Chain-of-Thought——通过提示模型生成中间推理步骤来引导复杂问题求解，显著提升了LLM在数学和逻辑任务上的表现，成为后续推理增强的基础范式

- 2023：PAL——通过生成可执行Python代码来辅助数学推理，将计算任务委托给解释器执行，解决了纯语言模型在精确计算上的固有局限

- 2024：GSM-Symbolic——通过系统性地改变问题中的数字和实体名称生成变体，揭示LLM在数学推理中对表面形式的依赖而非深层逻辑理解的脆弱性

- 2025：MatheMagic——提出动态生成反事实数学任务的框架，通过系统改变算术规则来测试模型的泛化能力，有效规避了静态基准的记忆化问题

- 2025：BitTokens——提出基于IEEE 754双精度浮点格式的单token数字编码算法，通过专用[NUM] token嵌入数值信息，提升了LLM处理大规模数值数据的效率和准确性

- 2026：Value-Aware Numerical Representations——提出值感知数值表征方法，通过显式编码数值量级关系改进Transformer中的数字嵌入，解决基础比较和算术中的系统性错误

这条时间线勾勒了该领域方法演进的代表性节点：从 2021 年的 GSM8K 奠定该领域方法基线，经 2022 年 Chain-of-Thought 的推进，到 2026 年的 Value-Aware Numerical Representations 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 数学推理基准评测

数学推理基准评测的起源在于确立模型数学能力的量化标准。2021 年，GSM8K 和 MATH 的发布标志着静态基准时代的开始，它们通过固定题目集评估模型在基础算术和复杂多步推理上的表现。然而，随着模型性能提升，静态基准迅速饱和，且因公开数据集被广泛纳入训练语料而面临严重的数据污染问题。2024 年，AIME 2024 的引入将难度提升至竞赛级，揭示了模型在极高难度问题上的瓶颈。2025 年，MatheMagic（O'Brien et al., 2025, P2）提出动态生成反事实数学任务的框架，通过程序化生成确保问题的可复现性和可扩展性，同时通过改变运算规则迫使模型从示例中推理而非依赖预训练记忆。该方法放弃了固定测试集的稳定性，换取了对模型泛化能力的更严格评估。2026 年，AMO-Bench（An et al., 2025, P9）构建了基于高中数学竞赛的高难度基准，通过精细的评分方法区分最终答案的正确性与推理过程的合理性，填补了高难度竞赛级数学评估的空白。这些基准的演进体现了从“静态快照”到“动态压力测试”的转型，与后续的过程验证路线形成互补，为评估模型真实推理能力提供了基础。

### 2.2 数值理解与表征

数值理解与表征研究聚焦于 LLM 内部对数字的编码机制，旨在揭示模型在基础算术和数量比较中的结构性缺陷。2025 年，BitTokens（Kreitner et al., 2025, P3）提出基于 IEEE 754 双精度浮点格式的单 token 数字编码算法，引入专用的可学习 [NUM] token，将数值编码为浮点格式并嵌入到 token 中，从而减少数字序列的 token 数量并保留数值精度。该方法解决了传统分词器将数字拆分为多个 token 导致的计算效率低下和精度损失问题，但依赖于对浮点格式的精确实现和模型对特殊 token 的学习能力。同年，Non-Continuous Number Embeddings（Davies et al., 2025, P4）通过线性重构和主成分分析评估 LLM 的数字嵌入空间，发现模型不仅将数值空间表示为非连续的，还引入了显著噪声，尽管重构保真度高但主成分解释力有限。这一发现挑战了模型能够平滑处理数值变化的假设，指出了嵌入空间中的结构性缺陷。2026 年，Value-Aware Numerical Representations（Dutulescu et al., 2026, P19）提出值感知数值表征方法，通过修改嵌入层，将数值量级关系显式编码到 token 嵌入中，使模型能够直接感知数字的大小和顺序。该方法放弃了通用 Token 效率，换取数值几何连续性，与工具增强路线形成互补，后者通过外部计算弥补内部表征的不足。

### 2.3 推理增强与训练策略

推理增强与训练策略旨在通过监督微调、强化学习等手段提升 LLM 的数学推理能力，重点解决概念应用差距、灾难性遗忘及推理轨迹优化等核心训练难题。2022 年，Chain-of-Thought 提示成为主流范式，通过生成中间推理步骤引导复杂问题求解，显著提升了 LLM 在数学和逻辑任务上的表现。2024 年，DeepSeekMath 引入 Group Relative Policy Optimization (GRPO) 算法，通过大规模数学语料预训练和强化学习提升模型的数学推理能力，成为开源数学模型的重要基线。2025 年，DeepSeek-R1 通过大规模强化学习解锁长链思维推理能力，在数学和编程任务上取得突破性进展。2026 年，CORE（Gao et al., 2025, P15）提出概念导向强化学习框架，通过生成与概念文本紧密相关的合成多选题作为概念探针，并利用强化学习训练模型识别和应用正确概念，弥合定义与应用之间的差距。该方法依赖于高质量合成数据的生成和严格的过滤管道，增加了数据准备的复杂性，但显著提升了模型在概念性数学任务中的表现。与工具增强路线相比，训练策略更侧重于内部能力的提升，而工具增强则通过外部依赖弥补内部缺陷，二者在提升推理可靠性方面形成互补。

### 2.4 鲁棒性与对抗攻击

鲁棒性与对抗攻击研究旨在评估 LLM 在输入扰动、数值重映射及语义干扰下的推理稳定性，揭示其依赖模式匹配而非深层逻辑理解的脆弱性本质。2024 年，GSM-Symbolic 通过系统性地改变问题中的数字和实体名称生成变体，揭示 LLM 在数学推理中对表面形式的依赖。2025 年，MSCR（Sun et al., 2025, P11）提出多源候选替换对抗攻击方法，利用词向量余弦相似度、WordNet 词典和掩码语言模型三个信息源生成候选替换词，并通过过滤形成最终候选集，支持同义词或反义词替换以实现语义保持的扰动。该方法结合了多种信息源以提高候选词的质量和多样性，克服了单一来源方法的局限性，从而更有效地触发模型错误。2026 年，Robust Reasoning Benchmark（Golikov et al., 2026, P26）提出基于对抗性变换的鲁棒性评估基准，对 AIME 2024 数据集应用字符串反转、LaTeX 注释移除和转义序列中和等预处理步骤，以消除解析器伪影并测试模型在表面形式变化下的稳定性。这些对抗性评估方法为理解模型推理的内在机制提供了新的视角，与过程验证路线形成互补，后者通过细粒度评估推理步骤来诊断逻辑缺陷。

### 2.5 工具增强与神经符号

工具增强与神经符号研究探索代码解释器、计算机代数系统及形式化验证器与 LLM 的协同机制，通过神经符号架构实现可验证推理，解决纯语言模型在精确计算与逻辑一致性上的固有局限。2023 年，PAL 通过生成可执行 Python 代码来辅助数学推理，将计算任务委托给解释器执行，解决了纯语言模型在精确计算上的固有局限。2025 年，AgentMath（Luo et al., 2025, P16）提出工具增强代理框架，通过紧密集成 LLM 的涌现推理能力与外部代码执行环境的精确算术和符号计算，提升复杂数学推理能力。该方法采用两阶段架构：首先通过监督微调在精选的合成工具调用轨迹上建立初始工具调用能力，然后利用结果反馈驱动的大规模强化学习激励探索和优化。2026 年，NeuroProlog（Zunjare and Hsiao, 2026, P24）提出神经符号框架，通过多任务微调与基于 Prolog 的符号监督强制执行可执行数学推理，利用 SWI-Prolog 解释器执行生成的 Prolog 程序，并根据执行结果生成针对性修复提示。该方法放弃了纯文本推理的自主性，换取计算精度与可验证性，与内部表征优化路线形成互补，后者通过修改嵌入层提升数值敏感性，而工具增强则通过外部依赖保证计算精度。

### 2.6 过程验证与错误分析

过程验证与错误分析聚焦于推理过程的细粒度评估，包括步骤级验证、错误分类、证明评分及幻觉检测，旨在超越最终答案准确率，深入诊断 LLM 在数学推导中的逻辑缺陷与可靠性问题。2025 年，Hard2Verify（Pandit et al., 2025, P6）构建一个步骤级验证基准，旨在评估 LLM 在开放-ended 前沿数学问题中的验证能力，超越最终答案准确率的评估局限。该方法选择多种 PRM 和生成模型作为步骤级批评者，评估其在检测推理错误和逻辑缺陷方面的表现，并分析模型与人类在验证判断上的分歧。2026 年，Unmasking Reasoning Processes（Zheng et al., 2026, P22）提出一个过程感知基准，采用双视角框架，包括在密集中间注释可用时的骨架引导诊断，以及在无注释时的结果条件验证器，以细粒度审计推理步骤。该方法引入了推理骨架和黄金步骤计数，通过对比模型生成的步骤与理想结构来识别逻辑缺陷，而非仅关注最终结果。这些过程验证方法为理解模型推理的结构性失败提供了新工具，与鲁棒性评估路线形成互补，后者通过对抗性扰动揭示模型对表面形式的依赖，而过程验证则通过细粒度评估诊断逻辑缺陷。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLM 在数学基准上的高分往往掩盖了其推理的脆弱性，模型严重依赖表面模式匹配而非深层逻辑结构，这一共识在对抗性评估中得到了充分验证。MSCR（Sun et al., 2025, P11）和 Robust Reasoning Benchmark（Golikov et al., 2026, P26）等研究通过系统扰动输入，揭示出模型在数字替换、同义词替换等微小变化下性能急剧下降，表明其推理能力并非基于算法化逻辑，而是基于统计记忆。与此相关的另一个共识是静态基准测试（如 GSM8K、MATH）已趋于饱和，且存在严重的数据污染问题，无法准确反映模型的泛化推理能力。MatheMagic（O'Brien et al., 2025, P2）和 AMO-Bench（An et al., 2025, P9）等动态基准的兴起，正是为了应对这一评估危机，通过程序化生成和原创题目规避记忆化风险。

Chain-of-Thought（CoT）提示显著提升了数学推理性能，但其生成的推理链并不总是忠实于模型的真实计算过程，存在“幻觉”风险，这一共识在过程验证研究中得到了进一步确认。Hard2Verify（Pandit et al., 2025, P6）和 Unmasking Reasoning Processes（Zheng et al., 2026, P22）等基准通过步骤级评估，揭示了模型在推理过程中可能生成看似合理但逻辑错误的中间步骤，导致最终答案正确但过程错误的“幸运猜测”现象。结合外部工具（如 Python 解释器、符号求解器）能有效弥补 LLM 在精确计算和复杂代数操作上的不足，是提升数学推理可靠性的有效途径，这一共识在工具增强研究中得到了广泛支持。AgentMath（Luo et al., 2025, P16）和 NeuroProlog（Zunjare and Hsiao, 2026, P24）等方法通过集成外部工具，显著提升了模型在需要精确计算任务中的表现，验证了工具增强路线的有效性。

### 3.2 观点分歧

数值表示缺陷的根本原因存在争议：是 Tokenization 离散化导致的结构性缺陷，还是训练数据不足导致的表征偏差？观点 A 认为数字被拆分为多个 Token，导致嵌入空间缺乏连续性，需引入单 Token 数值编码（如 BitTokens）；观点 B 认为模型缺乏足够的数值几何训练数据，通过增加高质量数值语料或值感知微调即可解决。现有证据偏向观点 A，因为 Non-Continuous Number Embeddings（Davies et al., 2025, P4）研究发现即使在高保真重构下，主成分解释力仍有限，暗示结构性缺陷。但 Value-Aware Numerical Representations（Dutulescu et al., 2026, P19）在基础算术上的提升表明数据/微调也有效。这一分歧的背后，是另一个更根本的争论：神经符号融合是终极方案还是过渡手段？观点 A 认为 LLM 的概率生成无法保证逻辑一致性，必须结合 Prolog/Lean 等符号系统实现可验证推理（如 NeuroProlog）；观点 B 认为随着模型规模扩大和过程监督改进，纯神经网络将能内化逻辑规则，符号系统仅作为辅助工具。NeuroProlog 在形式逻辑任务上表现优异，但在开放数学问题上泛化能力有限，而 DeepSeek-R1 等纯神经模型在 AIME 上取得高分，但鲁棒性评估显示其仍依赖模式匹配。现有证据无法判定，因为缺乏在“开放数学问题”（非形式化）上对比神经符号与纯神经模型在“逻辑忠实性”上的定量实验，且符号系统的灵活性不足限制了其应用范围。

### 3.3 其他开放问题

当前领域面临的最紧迫工程问题是过程监督（PRM）的标注成本与收益比。步骤级标注成本极高，且 PRM 本身可能存在偏差，导致训练过程比结果监督更复杂。Hard2Verify（Pandit et al., 2025, P6）等基准显示 PRM 在检测错误步骤上优于 ORM，但标注成本是 ORM 的 10 倍以上。Mixed-CoT-RL（Amjith et al., 2025, P14）等研究表明，通过合成数据可降低标注成本，但效果仍不及人工标注。关键困难在于缺乏自动化步骤标注的可靠方法，且 PRM 在不同难度任务上的收益差异未得到系统评估。研究路径包括开发基于 LLM 的自动步骤标注工具，以及探索基于激活状态的难度感知机制，以自适应调整推理长度。

最根本的研究问题是模型是否具备“难度感知”机制，即能否自动识别问题难度并调整推理策略。当前模型在简单问题上过度思考或在困难问题上过早放弃，原因在于缺乏对问题难度的内部表征机制。研究路径包括探索基于激活状态的难度感知和自适应推理长度控制，以及开发概念导向的强化学习（如 CORE, Gao et al., 2025, P15）来弥合定义与应用之间的差距。已知的是，模型在基础算术和中等难度问题上表现良好，但在奥林匹克级别和博士级问题上存在明显瓶颈；争议的是，数值表示缺陷是否可通过微调解决，以及神经符号融合是否为终极方案；未知的是，模型内部数值几何的形成机制，以及“真正的数学直觉”的定义。未来发展趋势将依赖于数值表征的几何重构与神经符号系统的深度融合，以构建兼具数值连续性、逻辑可验证性与鲁棒性的推理架构。

## 4. 总结与展望

LLM 数学推理领域的核心矛盾在于静态基准上的高准确率与输入微小扰动下的性能崩塌之间的巨大反差，这一矛盾源于模型内部数值表征的结构性缺陷与评估体系的失效。早期研究通过 CoT 提示和强化学习提升了准确率，但暴露了“模式匹配”而非“深度推理”的脆弱性；随后，工具增强和过程监督路线分别通过外部依赖和细粒度监督弥补了内部缺陷，但各自牺牲了端到端的简洁性或增加了标注成本。当前瓶颈并非算力或数据规模，而是如何将这些组件无缝集成，并建立统一的鲁棒性评估标准，以区分 LLM 的“统计记忆”与“算法推理”。

未来可能突破的方向包括：一是数值表征的几何重构，通过值感知嵌入（如 Value-Aware, Dutulescu et al., 2026, P19）和单 Token 编码（如 BitTokens, Kreitner et al., 2025, P3）从根源上解决多位数比较和算术错误；二是神经符号系统的深度融合，通过 NeuroProlog（Zunjare and Hsiao, 2026, P24）和 AgentMath（Luo et al., 2025, P16）实现可验证、可解释的严格数学推导；三是动态生成基准与过程验证的结合，通过 MatheMagic（O'Brien et al., 2025, P2）和 Hard2Verify（Pandit et al., 2025, P6）构建抗污染、细粒度的评估体系。对于进入者，最值得做的一件事是开发统一的鲁棒性评估框架，整合对抗性扰动、过程验证和数值几何分析，以全面诊断模型推理的可靠性与忠实性。
