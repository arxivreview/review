# A Survey of Prompt Injection and Jailbreak Attacks on LLMs ｜大语言模型提示注入与越狱攻击综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Prompt%20Injection%20and%20Jailbreak%20Attacks%20on%20LLMs)

## 导读

大语言模型（LLMs）从学术原型向核心基础设施的转型，暴露了其无法可靠区分系统指令与外部数据的根本性弱点。2022 年提示注入（Prompt Injection）概念的提出，标志着研究重心从单纯的有害内容生成转向系统级信任边界建模。随着 LLM 代理（Agents）在工具调用场景中的普及，间接提示注入（IPI）揭示了代理生态中复杂的外部数据污染风险。2023 至 2024 年，自动化对抗优化与多轮对话攻击的兴起，迫使防御机制从静态规则向动态上下文感知演进。当前，领域正进入形式化与多模态扩展阶段，密码学边界与系统级隔离成为应对自适应攻击的新范式。各路线在攻击隐蔽性、防御鲁棒性与系统效用之间做出了不同取舍，由此形成当前攻防对抗的复杂格局。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

LLM 安全问题的本质并非单纯的算法缺陷，而是架构层面的信任边界缺失。早期研究聚焦于“越狱”（Jailbreaking），即通过构造特定提示绕过安全对齐机制以生成有害内容。这一阶段的核心假设是 LLM 为静态文本生成器，攻击者通过优化对抗后缀（Adversarial Suffix）直接操纵模型输出。然而，随着模型部署场景的复杂化，问题定义迅速扩展。2022 年 Simon Willison 提出“提示注入”概念，类比 SQL 注入，指出 LLM 无法可靠区分“系统指令”与“用户/外部数据”。这一概念确立将安全威胁从内容层面提升至指令完整性层面，揭示了模型在解析多源输入时的根本性混淆。

问题形式化可表述为：给定系统指令 $S$、用户输入 $U$ 及外部数据 $D$，模型需生成响应 $Y$。安全目标是在 $Y$ 中排除由 $D$ 中嵌入的恶意指令 $I_{mal}$ 引发的行为，同时保持对 $S$ 和 $U$ 的效用。这一形式化揭示了子问题间的强依赖关系：“信任边界模糊”是根本问题，衍生出单轮越狱（基础攻击面）和间接注入（代理扩展面）；“评估标准化”是横向支撑问题，不解决它则无法量化多轮攻击和多模态攻击的有效性；“防御机制”则依赖于对攻击向量的准确建模。范式边界由此清晰：模型级防御（如微调）旨在内部区分指令与数据，而系统级防御（如沙箱、信息流控制）旨在外部隔离信任域。

约束演化史清晰地展示了方法如何因应环境变化而演变。2016-2018 年虽为少样本学习奠基期，但 LLM 安全领域的真正起点在 2022 年，Prompt Injection 确立了威胁模型起点。2023 年，GCG（Zou et al., 2023）通过梯度引导优化实现了自动化越狱，确立了白盒攻击基线，此时问题仍局限于单轮文本交互。2024 年是关键转折期，Crescendo（Russinovich et al., 2024）揭示了多轮对话的上下文累积效应，而 Greshake et al. (2023) 系统性地展示了间接提示注入在代理环境中的威胁。AgentDojo 基准的发布填补了代理安全评估的空白，标志着研究重心从单轮静态转向多轮动态与代理环境。

2025-2026 年，领域进入系统化与形式化阶段。SoK Taxonomy（Hong et al., 2025）构建了统一的分类体系与评估框架，解决了评估碎片化问题。同时，多模态攻击面（如 Sirens' Whisper, PPIA）的开辟，揭示了文本防御在感知层面的失效。防御机制也从启发式过滤转向基于密码学签名（Prompt Fencing）和信息流控制的架构隔离。这一演进路径表明，随着 LLM 从聊天机器人演变为具备工具调用能力的自主代理，安全威胁从“内容有害”演变为“行为劫持”，防御策略必须从模型内部对齐转向系统级信任架构设计。

**如果用一个核心问题概括该领域，那便是：如何在 LLM 作为自主代理与不可信外部数据交互的复杂生态中，建立可验证的信任边界以区分指令与数据，从而在保障任务效用的同时阻断恶意意图的执行。**

## 2. 方法体系

- 2022：Prompt Injection——确立指令与数据混淆的理论基础

- 2023：GCG——开创自动化白盒越狱攻击先河

- 2024：Crescendo——揭示多轮对话上下文累积效应

- 2024：AgentDojo——构建代理间接注入评估基准

- 2025：SlotGCG——量化提示位置脆弱性

- 2025：PLAGUE——提出终身学习多轮越狱框架

- 2026：SoK Taxonomy——构建统一安全评估分类体系

- 2026：Prompt Fencing——引入密码学签名建立安全边界

这条时间线勾勒了该领域方法演进的代表性节点：从 2022 年的 Prompt Injection 奠定该领域方法基线，经 2023 年 GCG 的推进，到 2026 年的 SoK Taxonomy 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 单轮越狱攻击

单轮越狱攻击的起源可追溯至对 LLM 安全对齐机制的静态绕过。早期方法如 GCG（Zou et al., 2023）采用梯度引导的白盒优化，通过迭代搜索对抗后缀以最大化有害输出的似然。GCG 的核心假设是模型对输入 token 的敏感度可通过梯度信号捕捉，其生成的后缀具有跨模型迁移性，成为后续黑盒与白盒攻击的重要基线。然而，GCG 局限于固定后缀位置，且生成的 token 序列往往具有非自然性，易被基于分布的检测器识别。

针对 GCG 的位置局限，SlotGCG（ICLR 2026, P27）引入了脆弱槽位分数（VSS），量化提示中不同位置的脆弱性差异，选择最脆弱位置进行对抗 Token 插入。该方法将位置搜索纳入优化过程，突破了传统后缀优化的空间限制，提升了攻击的针对性。与 GCG 相比，SlotGCG 在保持白盒优化优势的同时，扩展了搜索空间，但计算成本相应增加。另一条路线是语义重构，HaPLa（Joo et al., 2025, P1）利用溯因推理框架与符号编码，通过操纵 LLM 初始 Token 绕过安全触发关键词。HaPLa 将恶意提示转换为陈述句形式，利用自回归模型对初始 Token 的依赖偏差，通过“清洗”初始 Token 来规避安全对齐。相比直接对抗后缀，HaPLa 更注重语义自然度，牺牲了部分攻击效率以换取更高的隐蔽性。

此外，Sockpuppetting（Dotsinski and Eustratiadis, 2026, P12）提出通过输出前缀注入实现无需优化的越狱攻击，利用模型解码机制的惯性引导生成有害内容。该方法不依赖梯度或搜索，降低了计算成本，适用于资源受限场景，但易受模型解码策略变化的影响。TemplateFuzz（Shen et al., 2026, P20）则将模糊测试技术应用于 LLM 聊天模板，通过细粒度变异探索模板结构漏洞。TemplateFuzz 将软件模糊测试的启发式搜索策略迁移至 LLM 安全评估，实现了自动化漏洞发现，揭示了模板解析层面的结构性漏洞。这些方法共同表明，单轮攻击正从单纯的 token 优化转向对模型内部机制（如初始 Token 依赖、解码惯性、模板解析）的深层利用。与多轮攻击相比，单轮攻击策略简单、评估成本低，但易被基于上下文一致性的防御机制拦截。

### 2.2 多轮交互攻击

多轮交互攻击的兴起源于单轮防御在动态对话场景中的失效。Crescendo（Russinovich et al., 2024, P9）利用多轮对话的上下文累积效应，从良性前提逐步升级至有害输出，证明了对话历史在绕过安全对齐中的关键作用。Crescendo 的核心假设是模型在长上下文中对早期良性信息的依赖会削弱对后续有害意图的警惕。然而，Crescendo 等静态策略缺乏自适应能力，难以应对动态变化的防御机制。

PLAGUE（ICLR 2026, P26）提出具备终身学习能力的多轮越狱框架，通过嵌入检索记忆架构动态适应对话过程。该框架包含规划、反思、回溯与外部知识库模块，使攻击策略能在对话中持续演化。相比 Crescendo，PLAGUE 能根据模型反馈动态优化后续提示，克服了传统多轮攻击策略僵化的缺陷，在 HarmBench 上实现了 81.4% 的攻击成功率（ASR）。ICON（Lin et al., 2026, P14）则设计了一种意图-上下文耦合的多轮越狱框架，将多轮越狱形式化为交互式优化问题，利用判决函数量化有害性，动态调整提示序列。ICON 将意图引导与上下文构造解耦，通过系统化的路由机制选择最优攻击路径，提升了多轮攻击的自动化程度与策略多样性。

Persona Attack（Park et al., 2026, P21）提出基于增量记忆注入的越狱攻击，通过向模型记忆注入特定指令实现催眠与麻痹效果。该方法分三步注入指令：模仿预测、假设注入与去掩蔽，逐步削弱模型的安全决策能力。Persona Attack 利用了模型对历史信息的依赖，实现了更隐蔽的意图操纵，揭示了记忆机制在越狱中的脆弱性。这些方法代表了多轮攻击从脚本化向智能体化演进的里程碑。与单轮攻击相比，多轮攻击利用上下文累积效应显著提升了攻击成功率，但策略复杂度指数级增加，需要更复杂的搜索或强化学习算法，且评估成本高昂。

### 2.3 智能体注入攻击

智能体注入攻击聚焦于 LLM 代理在工具调用与外部数据检索场景下的安全威胁。Greshake et al. (2023, P3) 系统性地展示了嵌入在网页或邮件等外部数据中的恶意指令如何劫持 LLM 智能体行为，揭示了智能体在工具调用场景下的新攻击面。这一工作确立了间接提示注入（IPI）作为代理系统主要威胁的地位。

ChatInject（ICLR 2026, P25）利用聊天模板的结构特性进行间接提示注入，通过操纵模板中的特殊标记绕过安全过滤。该方法发现不同 LLM 的聊天模板存在解析差异，利用这些差异构造恶意载荷，实现跨模型迁移攻击。相比纯文本注入，ChatInject 能更有效地绕过基于内容过滤的防御机制，强调了模板标准化与安全解析的重要性。AdapTools（Wang et al., 2026, P17）提出自适应工具注入攻击，根据用户任务上下文动态选择恶意工具，增强攻击的隐蔽性与适应性。该方法通过语义对齐分析，选择与用户任务功能一致的恶意工具，避免触发内部逻辑审计。相比固定工具注入，AdapTools 能更有效地绕过行为异常检测，在 AgentDojo 上对 GPT-4.1 实现了 66.0% 的 ASR。

Learning to Inject（Chen et al., 2026, P15）将提示注入攻击生成形式化为马尔可夫决策过程，利用强化学习自动优化注入策略。该方法通过稀疏奖励机制，学习生成能最大化安全得分与效用得分的注入后缀。相比启发式搜索，RL 方法能更系统地优化注入内容，适应不同防御机制，为自动化提示注入提供了新的算法范式。这些方法反映了智能体攻击向上下文感知方向的演进，对防御系统提出了更高要求。与多轮攻击相比，智能体注入攻击无需用户直接参与恶意操作，攻击更具隐蔽性，但攻击面扩大导致防御难度激增，需要监控所有外部数据源。

### 2.4 检测与防御机制

防御机制的演进与攻击向量的扩展紧密相关。早期防御多依赖启发式规则或内容过滤，如 TextDefense，但在面对自适应攻击时泛化能力差。IntentGuard（Kang et al., 2025, P8）基于指令遵循意图分析构建防御机制，通过区分用户意图与注入指令来阻断间接提示注入。该方法在模型推理阶段分析指令来源与意图一致性，识别并拒绝来自不可信数据的冲突指令。相比微调或规则过滤，IntentGuard 能更灵活地适应动态环境，减少误报率，为智能体防御提供了基于语义理解的解决方案。

Prompt Fencing（Peh, 2025, P7）引入密码学签名元数据建立提示安全边界，通过信任评级区分可信指令与不可信内容。该方法在提示组装阶段为各段内容添加签名元数据，LLM 根据元数据判断指令可信度，从而隔离注入风险。相比内容过滤，Prompt Fencing 不依赖文本语义分析，能更可靠地识别来源可信度，实现了从架构层面隔离注入风险。SecInfer（Liu et al., 2025, P2）通过推理时缩放防止提示注入，利用多次采样与一致性检查识别异常输出。该方法在推理阶段生成多个候选响应，通过比较响应的一致性来检测潜在的注入影响，无需修改模型参数，为资源受限场景提供了轻量级防御方案。

IsolateGPT（Ji et al., 2025, P6）等系统级防御框架在 AgentDojo 上实现了极低的 ASR（0.12%），通过沙箱或策略执行器限制模型行为。然而，系统级防御往往增加系统复杂度与延迟，可能影响模型效用。这些方法共同表明，防御机制正从模型级微调转向系统级架构隔离，以应对日益复杂的自适应攻击。与攻击方法相比，防御机制在追求高安全性的同时，必须平衡任务效用与计算开销，这一权衡是当前研究的核心挑战。

### 2.5 多模态与物理攻击

多模态攻击的兴起揭示了文本防御在感知层面的局限。Sirens' Whisper（Ling et al., 2026, P18）利用近超声波实现不可听见的语音越狱，通过调制音频信号绕过语音 LLM 的安全机制。该方法生成语音友好的对抗提示，并构造近超声波信号，利用麦克风非线性将其解调为可识别语音。相比文本越狱，Sirens' Whisper 利用了多模态输入的物理特性，突破了传统文本防御的局限，揭示了语音 LLM 在声学输入层面的新漏洞。

PPIA（Ling et al., 2026, P13）提出物理提示注入攻击，将恶意排版指令嵌入物理对象，利用 LVLM 的视觉感知能力实现黑盒越狱。该方法通过离线选择高识别度视觉提示，并结合时空注意力进行环境感知放置，确保注入提示被模型捕获。PPIA 将攻击向量从数字空间扩展到物理空间，无需访问模型内部或输入通道，揭示了物理环境与多模态模型交互中的新型安全漏洞。这些方法开辟了新的隐蔽攻击通道，但攻击构造难度增加，且现有防御机制几乎完全失效，需开发全新的多模态检测技术。与文本攻击相比，多模态攻击部署门槛高，但隐蔽性强，随着具身智能和语音助手普及，将成为核心威胁。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

学界共识在于单一防御层不足以应对复杂的自适应攻击，模型级防御与系统级防御应结合使用。这一共识在多个基准上被反复验证：IsolateGPT 在 AgentDojo 上的 0.12% ASR 与 LlamaFirewall 的 9.13% ASR 均大幅超越传统内容过滤方法，表明系统级隔离在代理场景下的有效性（支撑证据：P6）。与此相关的另一个共识是，多轮对话攻击利用上下文累积效应，使得单轮防御机制失效，防御策略必须考虑对话历史和动态上下文。PLAGUE 在 HarmBench 上 81.4% 的 ASR 远超单轮攻击基线，证实了多轮攻击的威胁等级（支撑证据：P26）。此外，自动化红队测试在发现漏洞方面比手动设计更高效，但往往产生特定于模型或提示的攻击，缺乏泛化性，需结合策略驱动的方法以探索更广泛的漏洞空间（支撑证据：P4, P20）。

### 3.2 观点分歧

这一共识的背后，是另一个更根本的争论：根本防御策略是改进模型对齐（模型级）还是重构系统架构（系统级）。观点 A 主张通过微调、RLHF 等改进模型内部安全对齐，使其能内在区分指令与数据；观点 B 主张通过架构隔离、密码学签名等外部机制强制区分信任域。现有证据偏向系统级防御在代理场景下更有效，IsolateGPT 的 0.12% ASR 显著优于模型级防御通常 >5% 的表现。但模型级防御在资源受限场景下更具优势，且系统级防御可能引入高延迟。分歧根源在于缺乏统一的效用-安全权衡评估标准，系统级防御的部署成本在不同应用场景下差异巨大，难以一概而论（支撑证据：P7, P8）。

另一分歧在于攻击泛化性：特定模型优化 vs 跨模型迁移。观点 A 认为基于梯度或 RL 的攻击（如 PLAGUE）针对特定模型优化，ASR 高但泛化性差；观点 B 认为基于结构或语义的攻击（如 ChatInject）试图利用模型共性漏洞，实现跨模型迁移。证据显示，PLAGUE 在目标模型上 ASR 极高，但迁移到其他模型时 ASR 显著下降；ChatInject 在跨模型迁移上表现更好，但 ASR 通常低于特定优化。分歧根源在于不同模型的内部架构和安全对齐机制差异巨大，缺乏统一的“模型漏洞指纹”来预测迁移性（支撑证据：P25, P26）。

### 3.3 其他开放问题

最紧迫的工程问题是资源受限环境下的轻量级防御。现状是高性能防御模型往往计算开销大，难以在边缘设备实时部署；关键困难在于小模型本身安全性较弱，且量化可能进一步降低鲁棒性；研究路径包括开发基于经典 ML 的轻量级检测器、模型量化及硬件感知调度（支撑证据：P2, P5）。最根本的研究问题是如何形式化定义“上下文授权”并建立可验证的安全保证。现状是现有防御缺乏明确的安全保证，难以定义和验证隐式要求；关键困难在于安全属性依赖于执行上下文，静态形式化难以捕捉动态依赖；研究路径包括通过 Oracle 函数和属性形式化安全需求、开发可验证的对齐模型（支撑证据：P19）。此外，多模态攻击的威胁等级尚存争议，现有证据表明其部署门槛高，但随具身智能普及可能成为核心威胁，需在真实部署场景中对比“攻击成本-成功率”比（支撑证据：P13, P18）。

已知的是信任边界模糊是根本问题，系统级防御在代理场景更优；争议的是模型级与系统级防御的最优平衡点，以及多模态攻击的长期威胁等级；未知的是跨模型泛化的统一理论及形式化安全保证的落地路径。发展趋势将从启发式向形式化、从单模态向多模态、从模型级向系统级演进。

## 4. 总结与展望

LLM 提示安全的核心矛盾在于静态防御机制与动态自适应攻击之间的不对称性。研究尝试过从模型级对齐到系统级隔离、从单轮优化到多轮交互、从文本模态到多模态感知等多种路线，但核心瓶颈仍在于如何在保持模型效用的前提下，建立可验证的、跨模态的信任边界。这一瓶颈回扣了第 1 章提出的核心问题：在 LLM 作为自主代理与不可信外部数据交互的复杂生态中，如何区分指令与数据。

未来可能突破的方向包括：基于密码学的提示边界（如 Prompt Fencing）与基于因果分析的深层机制理解的结合，以实现动态适应和细粒度控制（P7, P19）；建立统一、标准化的 LLM 提示安全评估基准和威胁模型，通过模块化开源评测工具包支持公平、可复现的跨模型-攻击-防御组合评估（P4, P22）；以及研究 LLM 智能体在复杂环境中的间接提示注入防御机制，结合类型导向的特权分离、上下文隔离及执行时多模态内容扫描（P6, P16）。对于进入者，最值得做的一件事是在统一威胁模型下，构建一个覆盖多轮、代理及多模态场景的端到端攻防对抗基准，并量化不同防御策略在效用-安全帕累托前沿上的表现，以填补当前评估碎片化的空白。
