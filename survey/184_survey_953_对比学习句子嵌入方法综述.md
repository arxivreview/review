综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Sentence%20Embedding%20Learning%20via%20Contrastive%20Methods)

## 导读

句子嵌入学习旨在将变长文本映射为固定维度稠密向量，以支撑语义相似度评估与信息检索等下游任务，其核心价值在于弥合离散符号与连续语义空间之间的鸿沟。早期研究以基于预训练模型的 Token 级对比学习为主线，通过区分正负样本优化特殊标记的隐藏状态，思路简洁却受制于高频词引发的表示各向异性。当大语言模型（LLM）的兴起暴露出因果注意力机制对双向语义编码的限制后，研究重心转向如何在保留生成能力的前提下提取高质量语义表示。各路线在架构修改成本、生成能力保留与细粒度判别力之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义偏好对齐的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

句子嵌入学习的根本目标是将变长文本序列映射为固定维度的稠密向量，以捕捉整体语义信息并服务于语义相似度评估、信息检索和文本分类等自然语言处理任务。在形式化定义上，给定一个包含 $N$ 个类别、每个类别 $K$ 个样本的少样本学习场景，模型需通过对比学习优化表示空间，使得同类样本在向量空间中距离更近，异类样本距离更远。这一过程通常通过 InfoNCE 损失函数实现，该损失通过温度参数调节相似度分布，拉近正样本对并推远负样本对，从而塑造嵌入空间的几何结构。早期研究主要依赖基于预训练模型（PTMs）的 Token 级对比学习，假设 Transformer 的 [CLS] 层天然适合句级表示，通过简单的无监督对比即可优化其隐藏状态。

然而，随着研究深入，这一假设的局限性逐渐暴露。预训练模型中高频词和 Token 嵌入存在大量冗余信息，导致句子表示相似度虚高，阻碍模型捕捉细粒度语义差异，即所谓的 Token 级冗余问题。与此同时，嵌入表示的各向异性限制了表达力，使得表示空间不均匀，进一步削弱了下游任务的泛化能力。为了解决这些问题，早期方法聚焦于表征质量优化，通过调整池化策略、引入差异向量或显式冗余消除机制，提升嵌入空间的几何结构与精度。这一阶段的核心矛盾是“如何消除噪声以提升细粒度区分度”，研究重心在于对比损失设计与几何结构优化。

2024 年至 2025 年成为该领域的关键转折期，随着大语言模型（LLM）的兴起，问题定义发生了根本性变形。研究重心从“如何微调编码器”转向“如何在保留 LLM 生成能力的前提下提取高质量语义表示”。这一转变催生了两类主要路径：一是基于提示工程（Prompting）的方法，如 PromptEOL，通过特定模板提取 LLM 上下文级表示，无需微调参数即可获取语义表征；二是基于模型修改的方法，如 LLM2Vec，通过改变注意力机制实现双向编码。然而，现有方法存在固有局限：提示法性能受限，修改法往往牺牲生成能力，且 Token 级冗余信息依然阻碍细粒度语义区分。核心矛盾演变为“生成能力保留”与“嵌入判别力”之间的权衡，子问题呈现层级依赖关系：Token 级冗余消除是基础层，生成能力保留是约束层，而语义几何解释与不确定性感知则是深化层。

2025 年至 2026 年，研究进入精细化与理论深化阶段，重点探索语义偏好对齐、不确定性感知嵌入以及语义几何结构的可解释性。语义偏好对齐利用偏好数据微调 LLM，使其在保持生成能力的同时提升语义区分度；不确定性感知嵌入通过量化表示的不确定性来应对文本歧义；语义几何解释则建立嵌入空间内积与点互信息（PMI）的关联，揭示句向量内部特征的可解释性结构。当前领域活跃度极高，研究热点集中在轻量级微调、领域适应以及对比学习与直接偏好优化（DPO）的理论统一，旨在构建兼具高语义判别力与保留生成能力的通用嵌入模型。

**如果用一个核心问题概括该领域，那便是在大语言模型时代，如何在不牺牲其生成能力的约束下，通过对比学习与偏好优化的理论统一，构建能够消除 Token 级冗余、具备细粒度语义区分度且可解释的句子嵌入空间。**

## 2. 方法体系

- 2019：Sentence-BERT——奠定基于 Transformer 的句嵌入对比学习基础

- 2021：SimCSE——提出简单的无监督对比学习方法

- 2022：DiffCSE——引入基于差异的对比学习策略

- 2024：LLM2Vec——提出将因果注意力 LLM 转换为双向编码器

- 2024：PromptEOL——设计特定提示模板从生成式 LLM 中提取句向量

- 2025：3R——提出冗余表征减少方法

- 2025：Semantic Geometry——建立句嵌入语义组织的形式化框架

- 2026：SemPA——提出语义偏好对齐方法

这条时间线勾勒了该领域方法演进的代表性节点：从 2019 年的 Sentence-BERT 奠定该领域方法基线，经 2021 年 SimCSE 的推进，到 2026 年的 Uncertainty-Aware Contrastive Embedding 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 表征质量优化

表征质量优化路线起源于对 Transformer 句向量几何结构的早期探索，其核心假设是通过对比学习拉近正负样本即可优化 [CLS] 隐藏状态。Sentence-BERT（Reimers and Gurevych, 2019）通过孪生网络结构将 BERT 适配为句向量模型，利用对比学习拉近语义相似句对并推远不相似句对，奠定了基于 Transformer 的句嵌入对比学习基础。随后，SimCSE（Gao et al., 2021）提出简单的无监督对比学习方法，利用 Dropout 生成同一句子的不同视图作为正负样本对，通过 InfoNCE 损失优化句向量空间，显著提升了句嵌入的通用语义表征能力。然而，传统对比学习在区分细微语义差异上存在不足，DiffCSE（Su et al., 2022）引入基于差异的对比学习策略，通过预测两个句子嵌入之间的差异向量来捕捉细粒度语义变化，解决了传统对比学习在区分细微语义差异上的不足，增强了嵌入空间的几何结构。

针对 Token 级冗余信息干扰问题，3R（P3）提出了一种冗余表征减少方法，旨在解决对比学习句嵌入中由高频词和预训练模型导致的冗余信息问题。该方法首先基于高频词构建语料库级冗余句嵌入，作为冗余信息的参考基准。随后，通过可学习阈值动态识别每个训练批次中标准差小于阈值的冗余维度。最后，利用正则化方法动态减少这些冗余维度的信息，迫使模型聚焦于关键语义细节。其核心创新在于引入显式信号指导冗余减少，而非仅依赖训练策略调整。这种方法无需修改 SimCSE 等基础架构，易于集成到现有对比学习框架中。它通过调整不同维度的信息分布，增强了句向量对细微语义差异的区分能力。该方法为提升对比句嵌入的判别性提供了细粒度的优化视角。与 SimCSE 的隐式正则化相比，3R 通过显式冗余消除换取了更高的细粒度区分度，但代价是增加了构建冗余参考嵌入的计算复杂度。

### 2.2 生成式模型对齐

随着 LLM 的兴起，研究重心转向如何在保留生成能力的前提下提取高质量语义表示。PromptEOL（P4 提及的基线）设计特定提示模板从生成式 LLM 中提取句向量，无需微调模型参数即可获取高质量语义表征，展示了提示工程在句嵌入任务中的潜力，成为后续基于 LLM 的嵌入方法的重要基线。然而，提示法性能受限，无法针对特定任务优化。LLM2Vec（P4 提及的基线）提出将因果注意力 LLM 转换为双向编码器以提取句向量的方法，通过修改注意力掩码保留生成能力同时增强语义理解，为利用大语言模型进行句嵌入提供了新范式。但修改架构可能破坏 LLM 的因果注意力机制，导致生成能力下降。

SemPA（P4）提出一种基于语义偏好对齐的句嵌入增强方法，旨在解决现有提示或架构修改方法在提升语义表征时往往牺牲 LLM 生成能力的问题。该方法利用自然语言推理（NLI）数据集构建释义生成偏好对，将蕴含句作为正样本、矛盾句作为负样本，通过直接偏好优化（DPO）训练 LLM。其核心创新在于将对比学习与 DPO 在 Plackett-Luce 模型框架下统一，证明偏好对齐能有效优化句级语义表征。训练后，模型通过 PromptEOL 模板提取最后一层隐藏状态作为句向量，无需修改模型架构。这种方法以轻量级微调的方式增强了 LLM 对细粒度语义差异的理解，同时保留了原有的生成能力。它填补了利用偏好对齐改进句嵌入的研究空白，为在保留生成能力的同时提升嵌入质量提供了新视角。与 LLM2Vec 的架构修改相比，SemPA 通过 DPO 统一对比与偏好，换取了生成能力的保留，但代价是需要构建高质量的 NLI 偏好对数据且训练成本高于提示法。

### 2.3 领域自适应学习

通用嵌入模型在特定领域或低资源语言上性能退化，领域自适应学习旨在解决这一问题。MOSAIC（Pavlova and Makhlouf, 2025, P1）提出一种结合掩码语言建模（MLM）与对比学习的领域自适应框架，旨在解决通用嵌入模型在特定领域性能下降的问题。该方法首先扩展领域特定词汇，保留预训练对比模型的编码器权重以维持句级判别能力。在训练阶段，它联合优化 MLM 和对比目标，但仅对新引入的领域词应用 MLM 损失，以避免 MLM 信号主导并破坏对比学习的几何结构。通过互信息最大化视角，该方法协调了词级和句级监督信号，缓解了联合优化中的冲突。其设计简化了领域自适应流程，仅需词汇扩展即可应用，无需复杂的架构修改。这种方法在高资源和低资源领域均表现出鲁棒性，为低成本领域适配提供了有效方案。与全量 MLM 方法相比，MOSAIC 通过选择性 MLM 换取了信号冲突的缓解，但代价是可能忽略通用词在领域中的语义漂移。

ViCLSR（Huynh et al., 2026, P2）提出一种针对越南语等低资源语言的监督对比学习框架，旨在提升自然语言理解任务中的句嵌入质量。该方法利用现有的越南语 NLI 数据集，将蕴含对作为正样本、矛盾对作为负样本，构建监督对比训练数据。基于 XLM-R 架构，模型通过监督对比损失最小化正样本嵌入距离并最大化负样本距离，从而捕捉复杂的语义关系。框架包含数据准备、对比训练和下游任务微调三个阶段，确保嵌入能适配特定 NLU 任务。通过引入对比学习，该方法克服了多语言模型在低资源语言上语义捕捉不足的问题。其设计强调利用现有标注数据构建对比对，降低了低资源场景下的数据获取难度。该方法为低资源语言的句嵌入学习提供了可扩展的对比学习范式。与 MOSAIC 的词汇扩展策略不同，ViCLSR 侧重于利用 NLI 数据构建监督对比对，适用于缺乏大规模领域语料的低资源场景。

### 2.4 下游任务适配

针对文本分类等特定任务，下游任务适配路线设计了不确定性感知或标签对比策略以优化句向量提取。Uncertainty-Aware Contrastive Sentence Embedding（P5）提出一种不确定性感知的句嵌入方法，旨在解决文本分类任务中语义模糊句导致的过拟合问题。该方法将预训练模型的词嵌入矩阵转换为高斯分布，通过重参数化技巧同时学习语义特征均值和表示不确定性方差。利用多粒度局部上下文提取模块，通过不同核大小的卷积滤波器捕获局部依赖关系，增强语义理解。结合标签级对比学习策略，利用标签信息对齐同类样本并推远异类样本，增强类内紧凑性和类间分离度。其核心创新在于将数据不确定性学习与对比学习结合，使模型能感知样本难度并调整表示。这种方法冻结预训练参数，仅优化轻量级下游模块，降低了计算成本。它通过量化语义模糊性，提升了句嵌入在分类任务中的鲁棒性和判别力。与通用嵌入方法相比，该方法通过引入不确定性量化换取了分类任务的鲁棒性，但代价是增加了模型结构的复杂性。

### 2.5 语义几何解释

嵌入表示的黑盒性质限制了其可解释性，语义几何解释路线旨在解析句嵌入内部的语义组织结构。Semantic Geometry of Sentence Embeddings（P6）提出一个形式化框架，旨在解析句嵌入内部的语义组织结构和可解释性。该方法基于信息论，证明对比学习训练的句嵌入内积与点互信息（PMI）成正比，将嵌入空间视为 PMI 核的有限维编码。通过定义语义区域，将潜在特征映射为超球面上的概率区域，利用集合论关系（如包含、排斥、重叠）量化特征间的信息依赖。其核心创新在于将抽象的嵌入几何与具体的语义特征分解联系起来，揭示了嵌入坐标作为潜在特征加权组合的本质。这种方法提供了识别嵌入中特征及其组合的可行途径，超越了传统的探针测试方法。它通过互信息链式法则分解 PMI，展示了句嵌入如何由多个语义特征贡献构成。该框架为理解对比学习形成的嵌入空间几何提供了理论基础。与其他方法不同，该路线不直接优化嵌入质量，而是提供理论视角以指导未来的优化策略。

### 2.6 跨任务与多领域应用

上述方法在不同任务和领域中的应用展示了其通用性与局限性。MOSAIC 在生物医学领域表现出鲁棒性，ViCLSR 在越南语低资源场景中有效，而 SemPA 则适用于通用 LLM 嵌入增强。这些应用表明，领域自适应和低资源对比学习是提升特定场景性能的关键。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

对比学习是提升句子嵌入语义区分度的最有效范式，这一共识在多个基准上被反复验证。MOSAIC 在 MTEB Medical 上的 89.869 与 ViCLSR 在 ViNLI 上的 82.86 均大幅超越传统基线，表明对比学习在领域自适应和低资源场景下的有效性。与此相关的另一个共识是 Token 级冗余信息是阻碍句子表示质量提升的关键因素，需通过特定策略进行抑制或消除。3R 通过显式冗余消除提升了细粒度区分度，而 Semantic Geometry 通过 PMI 框架揭示了冗余信息的几何结构，两者从不同角度支持了这一共识。NLI 数据集是构建高质量正负样本对的有效来源，SemPA 和 ViCLSR 均利用 NLI 数据构建偏好对或对比对，显著提升了嵌入模型在语义相似度任务上的表现。

### 3.2 观点分歧

LLM 嵌入提取的最佳路径存在显著分歧：提示法（PromptEOL）主张零成本、保留生成能力，但性能受限；修改法（LLM2Vec）主张架构适配以提升性能，但可能破坏生成能力；对齐法（SemPA）主张通过 DPO 统一对比与偏好，平衡性能与生成能力。现有证据偏向 SemPA，因为它在保留生成能力的同时提升了性能，且理论上证明了 DPO 与对比学习的一致性。但缺乏在大规模生成任务上的直接对比实验，无法完全证明其生成能力保留优于 LLM2Vec。这一分歧的背后，是另一个更根本的争论：领域适应中的信号平衡。MOSAIC 主张仅对新词应用 MLM，而传统方法主张全量 MLM。现有证据偏向 MOSAIC，因为它在 MTEB Medical 上表现更优，但缺乏在极端低资源场景下的验证。

### 3.3 其他开放问题

最紧迫的工程问题是自适应负采样和动态温度调整机制，旨在解决固定超参数在不同语义粒度下泛化能力不足的问题。关键困难在于如何自动感知语义分布变化并动态优化对比损失，研究路径包括基于嵌入空间几何特征自适应调整采样策略。最根本的研究问题是嵌入空间的可解释性缺失，Semantic Geometry 提供了理论框架，但尚未转化为可操作的嵌入优化算法。已知的是对比学习的有效性，争议的是 LLM 嵌入提取的最佳路径，未知的是语义几何结构如何指导对比损失设计。未来发展趋势将依赖于对语义几何结构的深入挖掘和跨模态对齐的理论创新。

## 4. 总结与展望

句子嵌入学习已从简单的向量编码技术演进为 LLM 时代的核心能力解耦问题。早期研究聚焦于 Token 级冗余消除，中期转向 LLM 架构适配，近期致力于理论统一与领域深化。核心瓶颈在于如何在保留 LLM 生成能力的前提下，通过对比学习与偏好优化的结合，构建可解释、鲁棒且高效的通用嵌入模型。这一矛盾贯穿了从 SimCSE 到 SemPA 的方法演进，反映了领域对“生成-判别”平衡的持续探索。

未来可能突破的方向包括：一是基于语义几何的嵌入优化，利用 PMI 分解指导对比损失设计，可能突破当前性能瓶颈；二是多模态对比学习，结合图像字幕数据集弥合视觉与文本语义鸿沟；三是自适应负采样和动态温度调整机制，提升对比学习在不同语义粒度下的泛化能力。对进入者最值得做的一件事是在统一骨干与统一预训练条件下，系统评测不同 LLM 嵌入提取路径（提示法、修改法、对齐法）在生成能力保留与嵌入质量上的权衡，以填补现有评测的盲区。
