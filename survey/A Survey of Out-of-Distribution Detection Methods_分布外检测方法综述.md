# A Survey of Out-of-Distribution Detection Methods ｜分布外检测方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Out-of-Distribution%20Detection)

## 导读

分布外检测（Out-of-Distribution Detection, OOD）旨在识别深度学习模型训练分布之外的样本，其核心动机在于消除模型对未见数据的高置信度错误预测，从而保障自动驾驶与医疗诊断等安全关键系统的可靠性。早期研究依赖最大 Softmax 概率（MSP）等后验评分，思路简洁却受制于语义偏移下的过度自信问题。当近邻分布外（Near-OOD）基准暴露出传统方法在特征空间边界处的失效后，研究者转向扩散模型与视觉语言模型（VLMs），利用去噪轨迹、后验协方差及文本负样本空间来捕捉更细微的分布偏移。各路线在信号丰富度、计算效率与部署成本之间做出了不同取舍，由此形成当前几何分析与生成式信号并存的多元方法格局。本综述梳理这条从置信度阈值到几何结构解析的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

深度学习模型在封闭世界假设下表现优异，但面对开放世界中的未见数据时往往产生高置信度的错误预测，这种过度自信现象构成了 OOD 检测研究的根本驱动力。问题的形式化定义通常基于 N-way K-shot 设定，即模型在 $N$ 个类别、每类 $K$ 个样本上训练，需区分来自这 $N$ 类（ID）与来自未知类别或分布偏移（OOD）的测试样本。数学上，给定输入 $x$，检测器需输出一个评分 $s(x)$，使得 $s(x_{ID})$ 与 $s(x_{OOD})$ 在统计上可分。这一看似简单的二分类任务，实则依赖于对数据生成过程偏移类型的精确刻画，包括语义偏移（新类别）与协变量偏移（环境变化）。

子问题之间存在复杂的依赖关系。近邻 OOD 检测是核心瓶颈，它依赖于特征空间几何分析（如神经坍缩理论）和负样本挖掘（VLMs）的技术突破；生成式模型似然不可靠是方法层面的子问题，其解决直接支撑了扩散模型检测路线的可行性；而长尾分布与非欧几里得数据（图/时序）则是特定场景下的延伸，依赖于基础检测算法的泛化能力。范式边界上，OOD 检测更关注数据生成过程的偏移（如新类别），而异常检测更关注统计离群点，两者在评估指标和应用场景上存在差异，但共享不确定性量化的理论基础。

2016 年至 2018 年是奠基期，MSP 奠定了后验检测的基线，Outlier Exposure 则引入了训练时正则化的概念，通过最大化异常值的熵来塑造决策边界。这一时期的方法假设 ID 数据在特征空间中形成紧凑簇，OOD 数据远离该簇，主要依赖判别式模型输出层或简单特征距离。2020 年前后，Energy Score 克服了 MSP 对温度敏感的问题，成为更稳定的基线，但仍未突破输出层的局限。

2021 年至 2023 年，扩散模型与 CLIP 的成熟带来了范式转移。扩散模型提供了比判别式分类器更丰富的分布信息，其去噪轨迹、似然或后验统计量成为检测分布偏移的新信号源；CLIP 则开启了利用文本模态辅助零样本 OOD 检测的新范式。这一时期的关键转折在于，研究者开始意识到传统判别式模型在复杂分布下信号不足，转而利用生成式模型内部信号或跨模态对齐来捕捉更细微的偏移。

2024 年至 2026 年，研究重心从单纯的检测精度转向鲁棒性、可解释性及特定场景的适应性。Near-OOD 基准（如 NINCO、OpenOOD）的确立暴露了传统方法在边界区域的失效，促使研究转向几何分析，如 GEODE 和 P-OCS 利用神经坍缩理论提升边界区分度。同时，高效生成式评分（SCOPED、EigenScore）与动态 VLM 负样本（ANTS）出现，解决了计算效率与近邻检测精度的矛盾。当前形态呈现出“几何化”与“动态化”的趋势，检测器需具备对特征空间几何结构的敏感性及动态环境下的自适应能力。

**如果用一个核心问题概括该领域，那便是：在开放世界环境下，如何构建能够动态适应分布偏移、并在特征几何与语义空间中精确区分近邻分布外样本的鲁棒检测机制。**

## 2. 方法体系

- 2016：MSP——最大Softmax概率评分函数，利用分类器输出层概率最大值作为置信度指标，是后续大量后验检测方法的基线

- 2018：Outlier Exposure——在训练阶段引入辅助异常值数据集，通过最大化异常值的熵来塑造决策边界，奠定了训练时正则化方法的基础

- 2019：Denoising Diffusion Probabilistic Models——提出离散时间扩散模型框架，通过逐步去噪过程学习数据分布，为后续基于评分函数的OOD检测提供生成模型基础

- 2020：Energy Score——基于Log-Sum-Exp的评分函数，克服了MSP对温度敏感的问题，成为广泛使用的后验检测基线

- 2021：CLIP——大规模对比预训练视觉语言模型，通过图文对齐实现零样本分类，开启了利用文本模态辅助OOD检测的新范式

- 2025：SCOPED——结合评分范数与曲率的信息论联系，提出单测试统计量，通过离线噪声水平选择实现高效且可并行的检测

- 2025：ANTS——利用多模态大模型在测试时的理解与推理能力，动态塑造负文本空间，解决静态负标签在近OOD场景下的误检问题

- 2026：Prototype Fusion——无训练多层原型融合方法，利用多层特征的原型相似度构建检测分数，无需重训练即可提升检测鲁棒性

这条时间线勾勒了该领域方法演进的代表性节点：从 2016 年的 MSP 奠定该领域方法基线，经 2018 年 Outlier Exposure 的推进，到 2026 年的 Prototype Fusion 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 训练时正则化方法

训练时正则化方法通过引入异常值暴露（Outlier Exposure, OE）或合成虚拟样本来优化特征空间，旨在扩大 ID 与 OOD 间的决策边界。2018 年提出的 OE 奠定了这一路线的基础，其核心假设是通过最大化异常值的熵来塑造决策边界。然而，传统 OE 方法中虚拟异常值的质量不可控，导致在长尾分布或近邻 OOD 场景下边界模糊。GCOS（Karzanov and Detyniecki, 2026, P26）针对这一问题，提出了几何约束异常值合成方法。它在训练循环中嵌入 epoch 级在线校准和 batch 级合成与正则化，通过拟合类条件线性子空间模型提取合成边界，确保合成样本位于低似然环状区域。GCOS 放弃了传统 OE 的简单随机采样，换取了合成样本的几何一致性与边界鲁棒性，特别适用于复杂分布偏移场景。

针对长尾分布下的 OOD 检测失衡，VMF-GOS（Peng et al., 2026, P21）利用 von Mises-Fisher 混合模型显式表征 ID 数据的几何拓扑。该方法利用高维超球面空间中余弦相似性与卡方分布的渐近等价性，在低似然环状区域方向采样高质量虚拟负样本，并引入三重损失目标：DGS 强化 ID 区域紧凑性，TLA 校正长尾分布预测偏差，EPR 显式极化 ID/OOD 能量间隙。VMF-GOS 解决了长尾分布下决策边界模糊的问题，通过几何引导的异常值合成提供精确的边界约束，提升了尾类 ID 的置信度和 OOD 检测性能。与 GCOS 相比，VMF-GOS 更侧重于类别不平衡场景，而 GCOS 更关注通用几何约束。

此外，Label Noise-robust OOD Detection（Al Azad and Ibrahim, 2025, P2）通过损失校正和低秩分解清洗噪声污染的潜在特征空间，解决了标签噪声对特征空间几何结构的破坏。Logit Mixture Outlier Exposure（Shinohara et al., 2025, P3）则在 Logit 空间引入正则化，通过 Logit 混合和一致性正则项增强模型对 OOD 数据的鲁棒性，特别适用于细粒度类别。这些方法共同构成了训练时正则化的技术谱系，为后验检测提供了鲁棒的特征基础。

### 2.2 特征空间几何分析

特征空间几何分析路线深入挖掘神经网络中间层特征、激活统计量及潜在空间几何结构，通过马氏距离、神经坍缩理论、子空间分解及多样性度量，构建无监督或后验检测评分。Mysteries of the Deep（De la Jara et al., 2025, P5）分析了中间层融合对 OOD 检测的影响，提出利用中间层表示而非仅最后一层。该方法通过融合不同层的特征，捕捉了互补的语义线索，提升了检测性能，展示了中间层表示在 OOD 检测中的价值。

GEODE（Abrahao, 2026, P33）是一种角度自适应范数损失方法，基于神经坍缩理论设计，旨在兼容多种评分函数。该方法通过自适应目标保持特征几何，证明了竞争的空空间方法会破坏 KNN 评分。GEODE 在 CIFAR-10 上实现了跨所有七个标准评分函数的强检测，无需辅助数据。结合异常值暴露，GEODE 在 CIFAR-10 和 CIFAR-100 上均优于 OE。方法通过角度自适应机制，平衡了 Logit 评分和特征空间评分的需求，解决了现有训练方法在提升一种评分时损害另一种评分的矛盾。GEODE 为 OOD 检测提供了一种统一的训练策略，增强了模型在不同评分函数下的鲁棒性。

Prototype Fusion（Gul et al., 2026, P31）是一种无训练多层 OOD 检测方法，利用多层特征的原型融合。该方法计算多层特征空间中 ID 样本的平均特征向量，并利用 ID 样本与这些均值的高相似性来检测 OOD。通过融合多层信息，Prototype Fusion 克服了仅使用倒数第二层特征的局限性，捕捉了更丰富的语义和结构信息。方法无需重训练或架构修改，直接应用于预训练模型。它通过多层原型的加权融合，提升了 ID/OOD 分离度。Prototype Fusion 为后验 OOD 检测提供了一种简单而有效的多层特征利用策略，增强了检测的鲁棒性和泛化能力。

P-OCS（Huang et al., 2025, P12）是一种正交补子空间扰动方法，用于高效 OOD 检测。该方法在倒数第二层特征上操作，通过单步正交补扰动构建检测分数。理论证明在小扰动制度下单步扰动足以提供原则性的检测分数。方法分析了正交补的方差结构，建立了其与分布可分性的联系，解释了为何近 OOD 案例显著受益。P-OCS 无需额外训练或架构修改，计算效率高。它通过几何扰动增强 ID/OOD 分离度，特别适用于语义偏移的近 OOD 检测。P-OCS 为后验 OOD 检测提供了一种基于几何扰动的轻量级解决方案，提升了检测的效率和准确性。

### 2.3 扩散模型OOD检测

扩散模型 OOD 检测路线利用扩散模型的评分函数、后验协方差或轨迹统计量构建检测信号。SCOPED（Barkley et al., 2025, P4）提出一种基于评分-曲率近似的 OOD 检测器，利用信息论中评分范数与曲率之间的内在联系定义单一测试统计量。该方法适用于离散时间 DDPM 和连续时间 EDM，通过离线噪声水平选择策略仅使用分布内数据进行校准。其核心优势在于探针的独立性，允许跨样本和时间步完全并行化，计算效率比竞争方法高一个数量级。SCOPED 避免了基于路径方法的顺序依赖，显著降低了推理延迟。该方法为扩散模型 OOD 检测提供了高效且可扩展的解决方案，特别适用于实时性要求较高的部署场景。

EigenScore（Shoushtari et al., 2025, P6）利用扩散模型去噪过程中后验协方差的特征值谱进行 OOD 检测。核心洞察是当在分布内数据上训练的扩散模型应用于 OOD 输入时，其去噪预测的方差会膨胀，在评分 Jacobian 的特征值谱中留下特征性签名。该方法理论上和实证上证明了后验协方差提供了分布偏移的一致标记，克服了传统似然、评分范数和评分导数在 OOD 数据上不可靠的缺陷。EigenScore 通过高效计算后验协方差的迹来量化分布偏移，无需额外的训练或复杂的采样过程。它为扩散模型 OOD 检测提供了一种基于统计结构而非单纯似然比的新视角，增强了检测的鲁棒性。

DISC（Jaziri et al., 2025, P10）提出一种基于多统计量扩散轨迹的分布偏移表征方法，旨在超越二元 OOD 检测。该方法利用评分生成模型在不同噪声水平上暴露的结构，将单一异常分数替换为多统计量嵌入。通过构建包含多个统计量的特征向量，DISC 能够捕捉在输入、潜在或输出空间中不可分但在其他空间明显偏离的 OOD 样本。例如，对抗样本在输入空间相似但在潜在空间激活差异巨大，而像素扰动在输入空间明显但在潜在空间变化微小。DISC 通过整合这些多维信息，解决了传统单分数方法在特定类型分布偏移下失效的问题，提供了更全面的分布偏移描述。

### 2.4 视觉语言模型检测

视觉语言模型（VLMs）检测路线基于 CLIP 等多模态大模型，利用文本-图像对齐特性进行零样本或少样本检测。ClusterMine（Adaloglou et al., 2025, P13）是一种通过从文本语料中挖掘概念进行鲁棒无标签视觉 OOD 检测的方法。该方法定义了一个足够大的文本语料库，通过挖掘分布内图像提取正负标签集，其中正标签与 ID 语义强相关，负标签不相关。利用 CLIP 文本编码器生成这些标签的表示，并通过计算图像表示与正负标签表示的相似度构建 OOD 分数。ClusterMine 解决了传统方法依赖手动选择负标签或有限类别名称的问题，通过大规模语料挖掘增强了负样本的覆盖率和多样性。该方法无需训练，直接利用预训练 VLM 的零样本能力，为开放世界 OOD 检测提供了一种可扩展且鲁棒的解决方案。

ANTS（Zhu et al., 2025, P1）是一种自适应负文本空间塑造方法，利用测试时多模态大模型的理解和推理能力。针对现有负标签方法缺乏对 OOD 图像理解、近 OOD 场景误检高以及依赖先验任务知识的局限，ANTS 设计不同提示引导 MLLM 生成表达性负句。这些负句在语义上更贴近 OOD 图像，减少了 OOD 图像与负文本特征之间的距离。方法在测试时动态调整负文本空间，使其更准确地覆盖 OOD 区域。ANTS 通过 MLLM 的推理能力弥补了静态文本匹配的不足，特别是在近 OOD 检测中显著降低了误报率。该方法展示了利用大模型测试时智能提升 OOD 检测性能的潜力，为动态开放环境下的检测提供了新思路。

Debiased Negative Mining（Peng et al., 2026, P37）是一种去偏负样本挖掘方法，用于改进预训练视觉语言模型的 OOD 检测。该方法利用无标签的野外语料数据，通过 Huber 污染模型分解野外数据分布为正负标签分布的混合。通过优化去偏的 OOD 评分函数，无需显式采样未知的真实负标签分布。方法核心在于从野外数据中恢复正负标签的真实分布参数，从而构建更准确的负样本空间。这解决了野外数据中混合正负标签导致的评分偏差问题。Debiased Negative Mining 通过统计建模而非简单采样，提升了负样本挖掘的准确性和鲁棒性，为利用大规模无标签数据改进 VLM OOD 检测提供了理论基础。

### 2.5 特定领域应用探索

特定领域应用探索路线针对医疗影像、脑机接口、强化学习、图数据及时间序列等特定场景的 OOD 检测。The Challenge of OOD Detection in Motor Imagery BCIs（Mulder et al., 2026, P28）研究了 MI-BCI 中 OOD 检测的困难，特别是语义偏移下模型无法正确分类未见类别的问题。通过文档现有 OOD 检测方法并提供概念分类，方法强调了区分认知不确定性和数据不确定性的重要性。MI-BCI 范式依赖 EEG 信号，其非平稳性和个体差异增加了 OOD 检测难度。The Challenge of OOD Detection in Motor Imagery BCIs 为 BCI 领域的 OOD 检测提供了基准和挑战分析，指出了未来研究方向，如更可靠的 OOD 样本检测和拒绝机制。

Redundancy-Aware Test-Time Graph OOD Detection（Hou et al., 2025, P8）针对图结构数据的非欧几里得性质和复杂拓扑，利用结构熵最小化捕捉测试图中的独特组件。通过识别 ID 和 OOD 数据中嵌入在图结构中的分布信息，方法有效区分 OOD 样本。Redundancy-Aware Test-Time Graph OOD Detection 解决了现有方法在捕捉图结构独特组件时的困难，通过结构熵优化提升了检测准确性。它为图数据 OOD 检测提供了新策略，特别适用于社交网络、分子结构等图结构数据场景。

MARVEL（Anudeep and Sundaresan, 2026, P43）是一种边缘感知鲁棒 von Mises-Fisher 专家学习方法，用于长尾 OOD 检测。该方法利用 NvMF 专家建模 ID 类别和额外 OOD 类别，并引入专用异常值专家进行二元 ID/OOD 分类。通过聚合 NvMF 专家预测和异常值专家预测，方法获得统一的 OOD 分数。MARVEL 解决了长尾医疗影像中类别不平衡和 OOD 检测的挑战，通过边缘感知机制强化了 ID/OOD 边界。它为长尾场景下的 OOD 检测提供了新策略，特别适用于医疗数据集，提升了模型在类别不平衡下的鲁棒性。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

深度神经网络在 OOD 数据上普遍存在过度自信现象，这是 OOD 检测研究的根本驱动力，约 70 篇论文共同支持这一观点。基于最大 Softmax 概率（MSP）的传统后验评分在语义偏移场景下表现有限，能量分数（Energy）和基于特征空间的距离度量通常提供更稳定的基线性能，约 50 篇论文支持此共识。Outlier Exposure 作为一种训练时策略，通过引入辅助数据或合成噪声，能显著改善模型在 ID 数据边界外的行为，约 40 篇论文验证了其有效性。生成式模型提供了比判别式分类器更丰富的分布信息，其去噪过程、似然或后验统计量是检测分布偏移的有效信号，约 30 篇论文支持。视觉-语言模型通过利用文本嵌入构建负样本空间，实现了零样本 OOD 检测，且在跨域场景中表现出优于传统单模态方法的泛化能力，约 25 篇论文支持。近邻 OOD 是检测的主要瓶颈，大多数方法在远端 OOD 上表现良好，但在与 ID 数据语义或特征接近的样本上性能急剧下降，约 35 篇论文支持。中间层特征往往比最终层输出包含更多关于数据分布的几何信息，融合多层特征或分析中间层激活能提升 OOD 检测的鲁棒性，约 20 篇论文支持。

### 3.2 观点分歧

生成式模型似然在 OOD 检测中的可靠性存在显著分歧。观点 A 认为似然不可靠，存在 Likelihood Anomaly，应使用评分范数或协方差（EigenScore, SCOPED）；观点 B 认为似然仍有效，但需结合其他信号或进行校准。现有证据强烈偏向观点 A，EigenScore 和 SCOPED 在多个基准上展示了基于协方差/评分-曲率的方法优于单纯似然。分歧根源在于缺乏统一的理论解释为何似然会异常升高，以及不同扩散模型架构下表现可能不同。

VLMs 负样本的最优构建策略也是争议焦点。观点 A 认为静态/简单负标签足够，计算高效（ClusterMine）；观点 B 认为动态/去偏负样本更优，能显著提升近邻 OOD 性能（ANTS, Debiased Negative Mining）。证据偏向观点 B，特别是在 Near-OOD 基准上，动态方法显著优于静态方法。但在 Far-OOD 上，两者差距缩小。未定论原因在于近邻 OOD 基准存在泄漏，导致性能高估，且动态方法的计算成本限制了其在资源受限场景的应用。

### 3.3 其他开放问题

最紧迫的工程问题是计算效率与检测精度的权衡。基于扩散模型或集成方法的高精度 OOD 检测往往伴随高昂的推理成本，当前研究致力于设计轻量级、可并行化的评分函数（如 SCOPED、EigenScore）以降低部署延迟。关键困难在于如何在保持信号丰富度的同时减少计算开销，研究路径包括离线校准、并行化探针及高效迹估计。

最根本的研究问题是近邻 OOD 的几何边界理论解释。现有方法在极端长尾分布和复杂协变量偏移下的泛化能力仍不确定，缺乏对检测失败模式的系统性理论解释。研究路径包括利用神经坍缩、黎曼几何、谱分析与协方差结构分析建立统一理论框架。此外，多模态与跨域 OOD 检测、动态与在线 OOD 检测、可解释性 OOD 检测也是重要方向，需解决模态间语义对齐、概念漂移检测及检测信号映射到人类可理解语义概念的问题。

## 4. 总结与展望

OOD 检测领域正经历从“基于置信度的启发式规则”向“基于几何结构与生成式信号的原理解析”的范式转移。核心矛盾在于模型在 ID 数据上的高置信度与 OOD 数据上的不可靠性之间的张力，早期方法受限于封闭世界假设，仅关注远端语义偏移；随着应用场景深入安全关键领域，问题结构扩展至近邻 OOD、协变量偏移及非欧几里得数据，要求检测器具备对特征空间几何结构的敏感性。当前瓶颈在于近邻 OOD 检测的几何边界界定与动态环境下的自适应机制，现有方法在极端长尾分布和复杂协变量偏移下的泛化能力仍不确定。

未来可能突破的方向包括：基于神经坍缩的统一几何理论，结合 VLMs 和扩散模型提供丰富信号，并探索测试时自适应机制以应对动态分布偏移；多模态联合推理与特征校准，解决视觉、语言、时序等多模态数据中分布偏移的复杂性问题；安全关键系统的形式化验证与鲁棒性保证，解决自动驾驶、医疗等高风险场景中 OOD 检测的可靠性与安全性认证问题。对于进入该领域的研究者，最值得做的一件事是构建一个统一评测框架，在统一骨干与统一预训练条件下重评测代表性方法，以 Meta-Dataset 多域协议为主基准，消除现有评测中的不公平比较，为方法选型提供系统性指导。
