## 导读

大语言模型后训练旨在通过监督微调与强化学习，将预训练模型的通用知识转化为指令遵循与复杂推理能力，其核心矛盾在于模仿学习的稳定性与探索学习的泛化性之间的张力。早期研究以监督微调（SFT）为基石，通过行为克隆建立格式规范，但受限于分布偏移与灾难性遗忘，难以突破性能上限。2022年基于人类反馈的强化学习（RLHF）引入在线优化范式，解决了偏好对齐问题，却带来了训练不稳定与奖励黑客等新挑战。随着可验证奖励（RLVR）的兴起，领域重心转向数学与代码推理，确立了“SFT冷启动+RL探索”的标准范式。当前研究聚焦于SFT与RL的理论统一、混合策略设计及对齐税的缓解，试图在能力增益与能力保持间寻求平衡。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从行为克隆到语义探索的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

大语言模型后训练领域的兴起，源于预训练模型虽具备广泛知识，却缺乏指令遵循、安全对齐及复杂推理能力。早期研究主要依赖监督微调（SFT）作为行为克隆手段，通过模仿专家演示数据优化模型，旨在建立指令遵循格式和基本能力。然而，SFT本质上是离线策略学习，其固有缺陷在于分布偏移、灾难性遗忘及泛化能力有限，模型往往过拟合到特定数据分布，难以发现专家数据之外的新推理路径。这种“模仿”范式的局限性，促使研究者寻求能够突破性能上限的“探索”机制，从而引出了后训练的核心问题结构。

问题的形式化可视为在给定预训练模型 $\pi_{ref}$ 和任务分布 $\mathcal{D}$ 下，寻找最优策略 $\pi^*$ 以最大化期望奖励 $R$，同时约束策略偏离参考分布的程度。具体而言，SFT 最小化交叉熵损失 $\mathcal{L}_{SFT} = -\mathbb{E}_{(x,y)\sim\mathcal{D}}[\log \pi_\theta(y|x)]$，而 RL 则最大化期望奖励 $\mathbb{E}_{y\sim\pi_\theta}[R(x,y)] - \beta D_{KL}(\pi_\theta || \pi_{ref})$。这两个子问题并非独立，而是存在强依赖关系：SFT 提供冷启动和格式规范，RL 提供探索和能力上限突破；SFT 与 RL 的目标冲突是基础理论问题，不解决此问题则无法设计有效的混合训练策略。此外，灾难性遗忘是实施任何后训练策略时必然伴随的副作用，计算效率则是工程层面的约束，三者共同构成了后训练的技术三角。

从范式边界来看，SFT 属于离线策略学习，数据来自固定数据集或旧策略，效率高但存在分布偏移；RL 属于在线策略学习，数据来自当前模型，分布匹配好但计算成本高。早期研究将两者视为独立阶段，但 2025 年提出的统一策略梯度（Unified Policy Gradient）理论揭示了 SFT 作为 RL 在特定参考策略下的特例，模糊了这一边界。这一理论突破使得在单一训练循环中动态调整 SFT 与 RL 权重成为可能，标志着领域从“阶段串联”向“目标统一”的认知转变。

约束演化史清晰地展示了方法如何因应约束变化而演变。2017 年，近端策略优化（PPO）通过裁剪概率比率限制策略更新幅度，奠定了 RL 后训练的稳定基线。2022 年，RLHF 的提出确立了基于人类反馈的强化学习范式，通过奖励模型将人类偏好转化为优化信号，解决了 SFT 无法捕捉偏好细微差别的问题。2023 年，直接偏好优化（DPO）无需训练独立奖励模型，简化了流程并降低了成本，成为重要替代方案。2024 年，组相对策略优化（GRPO）移除 Critic 网络，结合可验证奖励（RLVR），在数学与代码推理上取得突破，确立了推理模型训练的新标准。

2025 年至 2026 年，研究重心从单一算法优化转向系统级权衡。2025 年，统一策略梯度与“RL 修复 SFT 遗忘”的发现，挑战了 SFT 优于 RL 的传统观点，揭示了两者在泛化能力上的互补性。2026 年，有限温度吉布斯初始化（GIFT）、轨迹混合监督（TMS）及无裁剪策略优化（CFPO）等方法涌现，旨在解决 SFT 与 RL 的目标冲突、缓解遗忘及提升训练稳定性。当前形态下，领域已进入精细化调控阶段，核心驱动力在于突破 SFT 的性能上限并解决其泛化缺陷，同时最小化对通用知识的破坏。

**如果用一个核心问题概括该领域，那便是：如何在后训练过程中，通过协调模仿学习（SFT）的稳定性与强化学习（RL）的探索性，在最大化特定任务推理能力的同时，最小化对模型通用知识、校准度及内部表征结构的破坏（即最小化对齐税）。**

## 2. 方法体系

- 2017：PPO——提出近端策略优化算法，通过裁剪概率比率来限制策略更新幅度，防止训练不稳定。

- 2022：RLHF——确立基于人类反馈的强化学习范式，通过奖励模型将人类偏好转化为优化信号。

- 2023：DPO——提出直接偏好优化算法，无需训练独立的奖励模型即可直接从偏好数据优化策略。

- 2024：GRPO——提出组相对策略优化算法，通过组内奖励归一化估计优势函数，移除对Critic网络的依赖。

- 2025：Unified Policy Gradient——提出统一策略梯度估计器，在单一公式框架下涵盖SFT与多种RL损失。

- 2025：RL Fine-Tuning Heals OOD Forgetting——发现RL微调能修复SFT导致的分布外遗忘，揭示SFT与RL在泛化能力上的互补性。

- 2026：CFPO——提出无裁剪策略优化算法，用凸二次惩罚替代启发式裁剪机制，消除零梯度区域。

- 2026：GIFT——提出有限温度吉布斯初始化方法，基于KL正则化RL理论推导SFT到RL的过渡初始化策略。

这条时间线勾勒了该领域方法演进的代表性节点：从 2017 年的 PPO 奠定该领域方法基线，经 2022 年 RLHF 的推进，到 2026 年的 TMS 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 SFT与RL统一理论

SFT 与 RL 统一理论路线旨在解决两者在优化目标、数据分布及策略梯度上的内在联系，提出统一视角或混合训练框架。早期 SFT 被视为独立阶段，但 2025 年提出的统一策略梯度（Unified Policy Gradient, P1）通过定义统一的策略优势估计，揭示了 SFT 作为 RL 在特定参考策略下的特例，消除了传统视角下的范式割裂。该方法为混合后训练策略提供了理论指导，使得在单一训练循环中动态调整 SFT 与 RL 权重成为可能，解决了 SFT 与 RL 目标冲突的理论难题。

针对 SFT 因分布偏移导致的泛化能力有限问题，锚定监督微调（Anchored Supervised Fine-Tuning, ASFT, P9）基于奖励加权回归框架，通过重要性采样构建 SFT 与 RL 目标的紧下界。ASFT 引入辅助分布来修正 SFT 的离策略偏差，使其更接近 RL 的在策略优化目标，代价是引入了额外的采样开销，且对奖励函数的准确性有较高依赖。有限温度吉布斯初始化（GIFT, P24）则从理论推导出发，将 SFT 视为 RL 的冷启动阶段，通过吉布斯分布作为理论动机起点，利用温度参数控制策略探索与利用的平衡，避免了 SFT 过度拟合。GIFT 提升了推理模型在 RL 阶段的探索效率，但增加了理论推导的复杂性，且温度参数需要仔细调节。

非解耦理论（Non-decoupling Theory, P23）通过可测空间上的概率密度分析，证明了 SFT 与 RL 在顺序训练中存在不可解耦性，SFT 损失在 RL 阶段必然下降。这一发现澄清了后训练阶段耦合的理论机制，指导了工业界对后训练流水线顺序的重新审视。轨迹混合监督（TMS, P29）则通过混合专家轨迹与模型自生成轨迹实现无奖励在线 SFT，区分目标性能与保留性能，旨在缓解 SFT 导致的灾难性遗忘。TMS 无需外部奖励信号即可实现类似 RL 的探索效果，降低了训练成本，但依赖于模型自身生成轨迹的质量，早期阶段可能产生噪声。

| 方法 | 核心机制 | 优势（Gain） | 劣势（Cost） | 代表论文 |
| :--- | :--- | :--- | :--- | :--- |
| Unified PG | 统一策略优势估计 | 理论统一，支持动态权重调整 | 推导复杂，超参数敏感 | P1 |
| ASFT | 奖励加权回归，重要性采样 | 修正离策略偏差，提升泛化 | 额外采样开销，依赖奖励准确性 | P9 |
| GIFT | 有限温度吉布斯初始化 | 原则性初始化，提升探索效率 | 理论复杂，温度参数敏感 | P24 |
| TMS | 轨迹混合监督 | 无奖励在线 SFT，缓解遗忘 | 依赖自生成轨迹质量 | P29 |

该路线与后续 RL 算法优化路线形成互补：统一理论提供了混合训练的理论基础，而 RL 算法优化则提供了具体的稳定化手段。

### 2.2 强化学习算法优化

强化学习算法优化路线聚焦于改进 RL 后训练中的策略优化算法，包括重要性采样修正、熵动态控制、奖励设计、训练稳定性及计算效率提升。PPO 作为 2017 年的奠基算法，通过裁剪概率比率限制策略更新幅度，但其启发式裁剪机制在大规模训练中易导致零梯度区域和奖励黑客。无裁剪策略优化（CFPO, P27）用基于总变差散度的凸二次惩罚替代启发式裁剪机制，消除了零梯度区域，实现了处处可微的目标函数。CFPO 解决了大规模训练中的奖励黑客与训练不稳定问题，代价是二次惩罚的计算开销略高于简单裁剪，且需要调节惩罚系数。

前缀重要性比率（Prefix Importance Ratio, P26）指出 token 级比率是累积前缀比率的近似，忽略了前缀信息导致的方差增大。该方法显式纳入前缀比率信息，并通过启发式上界裁剪防止数值爆炸，解决了长度偏差导致的更新不一致问题，提升了离策略训练的效率。自步课程 RL 对齐框架（SPARD, P39）摒弃固定权重方案，根据训练动态自动调整数据采样权重，将数据效用与奖励信号结合，构建自适应课程学习策略。SPARD 解决了固定权重忽视训练过程动态变化的问题，提升了数据利用效率，但动态权重计算增加了训练循环的复杂度。

基于策略散度的信任区域重定义方法（DPPO, P30）重新审视信任区域约束，提出基于策略散度的掩码定义，替代传统的概率比率裁剪，更精确地控制策略更新幅度，防止破坏性更新。多臂老虎机视角（Multi-armed Bandit Perspective, P25）将 LLM 微调建模为多臂老虎机问题，揭示训练动态与泛化动态的差异，指出基础模型的质量决定了 RL 微调的泛化上限，而非 RL 算法本身。这一视角强调了预训练的重要性，指导了模型选择策略。

| 方法 | 核心机制 | 优势（Gain） | 劣势（Cost） | 代表论文 |
| :--- | :--- | :--- | :--- | :--- |
| CFPO | 凸二次惩罚替代裁剪 | 消除零梯度，提升稳定性 | 计算开销略高，需调节系数 | P27 |
| Prefix Ratio | 前缀比率稳定化 | 降低方差，解决长度偏差 | 前缀比率计算存储开销 | P26 |
| SPARD | 自步课程，动态权重 | 自适应数据利用，平滑提升 | 增加训练循环复杂度 | P39 |
| DPPO | 策略散度信任区域 | 精确控制更新幅度 | 额外前向传播开销 | P30 |

该路线与 SFT 与 RL 统一理论路线紧密关联：统一理论提供了目标函数的形式，而 RL 算法优化则确保了该目标在训练过程中的稳定收敛。

### 2.3 灾难性遗忘缓解

灾难性遗忘缓解路线研究后训练过程中模型原有能力退化问题，通过正则化、参数隔离、分布对齐或记忆回放等技术保持通用能力与特定任务的平衡。RL 微调修复 OOD 遗忘（RL Fine-Tuning Heals OOD Forgetting, P3）发现 RL 微调能修复 SFT 导致的分布外遗忘，揭示 SFT 与 RL 在泛化能力上的互补性。该研究挑战了 SFT 优于 RL 的传统观点，提供了 RL 在保持通用能力方面的证据，代价是 RL 训练成本高于 SFT。

熵自适应微调（EAFT, P21）通过识别“自信冲突”缓解遗忘，定义自信冲突为模型对错误 token 的高置信度预测，这些预测产生破坏性梯度。EAFT 动态调整梯度以抑制自信冲突，解决了标准 SFT 中过度拟合错误模式的问题，代价是熵计算增加了训练开销。自我增强监督微调（SA-SFT, P34）在 SFT 前插入自增强阶段，模型从自身知识中生成少量刷新数据，将排练转化为自主数据建模，无需外部语料库。SA-SFT 解决了外部数据分布不匹配导致的遗忘问题，代价是自生成数据的质量依赖于模型自身能力。

锚定学习（Anchored Learning, P45）通过动态演进的移动锚点显式控制分布更新，构建当前模型与冻结参考模型之间的插值锚点，将全局拟合转化为局部分布空间约束，确保更新保持局部性。表征坍缩分析（Representation Collapse Analysis, P48）通过 SVD 分析隐藏状态矩阵，定义表征坍缩为固定探针分布下的集中度增加，揭示了后训练导致隐藏状态有效秩降低和角坍缩，损害分布外行为。该研究为设计防止表征坍缩的正则化方法提供了理论依据。

| 方法 | 核心机制 | 优势（Gain） | 劣势（Cost） | 代表论文 |
| :--- | :--- | :--- | :--- | :--- |
| RL Heals OOD | RL 修复 SFT 遗忘 | 提升泛化，保持通用能力 | RL 训练成本高 | P3 |
| EAFT | 熵自适应权重 | 抑制自信冲突，减少遗忘 | 熵计算开销 | P21 |
| SA-SFT | 自生成刷新数据 | 无需外部数据，保持鲁棒性 | 依赖自生成质量 | P34 |
| Anchored Learning | 动态移动锚点 | 局部分布约束，减少漂移 | 额外前向传播开销 | P45 |

该路线与 SFT 与 RL 统一理论路线形成互补：统一理论解释了遗忘的机制，而遗忘缓解技术则提供了具体的正则化手段。

### 2.4 蒸馏与知识迁移

蒸馏与知识迁移路线利用教师模型指导学生模型的后训练，包括在线/离线策略蒸馏、多教师能力集成及跨模型能力迁移机制。闪电在线策略蒸馏（Lightning OPD, P40）提出离线在线策略蒸馏方法，解决标准 OPD 需要实时教师推理服务器的问题。该方法预计算教师对 SFT 滚动的对数概率，并在训练期间重用，消除了实时推理的基础设施开销，提升了训练效率，代价是离线预计算需要存储大量教师输出。

多教师在线策略蒸馏（MOPD, P50）通过三阶段流水线集成多领域专家能力，首先进行通用 SFT，然后并行训练领域专家，最后通过 MOPD 将专家能力融合到单一学生模型。MOPD 实现了跨领域能力的统一整合，避免了多模型部署的复杂性，代价是多阶段训练流程复杂，且依赖领域专家的质量。统一在线策略蒸馏框架（Uni-OPD, P44）通过双视角配方解决探索不足与教师监督不可靠问题，引入离线难度感知与在线正确性感知的数据平衡，促进学生探索。

去神秘化在线策略蒸馏（Demystifying OPD, P51）分析在线策略蒸馏的角色、病理与调节机制，揭示其局限性。该方法通过系统实验发现 OPD 加速探索但不能突破模型上限，且更强教师不保证更好学生，存在长度利用等病理现象。蒸馏强化学习（Distilled RL, P52）结合 OPD 与 RL 的优势以提升后训练效率，观察到 OPD 收敛快但缺乏持续改进，RL 收敛慢但趋势持续，通过混合 OPD 与 RL 损失，利用 OPD 的快速对齐与 RL 的持续探索，提升了训练效率与最终性能。

| 方法 | 核心机制 | 优势（Gain） | 劣势（Cost） | 代表论文 |
| :--- | :--- | :--- | :--- | :--- |
| Lightning OPD | 离线预计算教师概率 | 消除实时推理开销 | 存储大量教师输出 | P40 |
| MOPD | 多教师三阶段融合 | 跨领域能力整合 | 流程复杂，依赖专家质量 | P50 |
| Uni-OPD | 双视角数据平衡 | 解决探索不足与监督偏差 | 增加训练复杂度 | P44 |
| Distilled RL | OPD 与 RL 混合损失 | 快速对齐与持续探索结合 | 混合权重需调节 | P52 |

该路线与 RL 算法优化路线形成竞争与互补：蒸馏提供了高效的中间范式，而 RL 算法优化则提供了突破教师上限的探索机制。

### 2.5 对齐安全与价值

对齐安全与价值路线关注后训练中的价值对齐、安全性、校准性及潜在风险，包括对齐税、意识形态偏差、数据投毒及行为控制。接种提示（Inoculation Prompting, P11）在训练时显式描述不良行为以抑制其在测试时的涌现，通过修改提示以请求不良行为，防止模型在未明确请求时表现出该行为。该方法利用选择性学习机制，区分期望与非期望行为，解决了微调中不良行为泛化的问题，提升了模型安全性。

自奖励 PPO（SRPPO, P18）仅使用演示数据通过相干奖励函数实现对齐，引入相干奖励函数，建立与 SFT 阶段一致的对齐方向，实现 RL 的持续精炼。SRPPO 简化了对齐流程，降低了计算成本，代价是奖励函数的准确性依赖于 SFT 模型的质量。双层优化校准（Bilevel Calibration, P54）联合优化温度参数与模型参数，指出事后温度缩放缺乏泛化性，从训练阶段解决对齐导致的校准退化问题。该方法解决了校准与对齐的权衡问题，提升了模型可靠性，代价是双层优化计算开销较大。

正则化子集选择（Regularized Subset Selection, P55）利用训练数据归因技术，识别并移除损害可信度的训练样本，通过影响函数估计样本对模型行为的影响，选择正则化子集。该方法解决了 SFT 意外损害模型可信度的问题，提升了模型在敏感领域的应用安全性。目标条件监督学习（Goal-Conditioned Supervised Learning, P47）将 LLM 微调建模为目标条件序列建模问题，引入超越阈值公式，处理非二元反馈，避免手工截断带来的偏差，提升了学习质量。

| 方法 | 核心机制 | 优势（Gain） | 劣势（Cost） | 代表论文 |
| :--- | :--- | :--- | :--- | :--- |
| Inoculation | 训练时描述不良行为 | 抑制不良行为涌现 | 提示工程需精心设计 | P11 |
| SRPPO | 自奖励函数 | 消除独立奖励模型依赖 | 依赖 SFT 模型质量 | P18 |
| Bilevel Calibration | 双层优化温度与参数 | 从训练阶段解决校准退化 | 计算开销较大 | P54 |
| Subset Selection | 数据归因移除有害样本 | 提升可信度，减少偏见 | 归因计算开销较大 | P55 |

该路线与灾难性遗忘缓解路线紧密关联：对齐税往往表现为通用能力退化，因此遗忘缓解技术也是缓解对齐税的重要手段。

### 2.6 机制可解释性分析与高效微调

机制可解释性分析路线从参数空间、激活模式、内部电路及几何结构等角度解析后训练对模型内部表征的影响。Delta Activations（P2）通过测量内部激活相对于基座模型的偏移生成嵌入，无需外部监督或评估，直接从内部行为推导嵌入，支持模型聚类与检索。后训练结构变化（Post-Training Structural Changes, P6）通过 SVD 分析后训练对 LLM 内部参数空间的影响，发现后训练导致奇异值的近均匀几何缩放与高度一致的酉变换，揭示了后训练依赖预训练基础能力的机制。

RL 微调增强激活强度与多样性（P8）基于边缘归因补丁框架，分析 RL 前后内部信息流差异，发现 RL 微调提升了输入与输出熵多样性，增强了内部电路的激活强度，揭示了 RL 提升推理能力的内部机制。特征级机制研究（Feature-Level Mechanistic Study, P56）构建统一稀疏特征空间，使用 MAS 度量特征特异性，发现 RL 训练模型具有特定的泛化特征，而 SFT 模型缺乏这些特征，提供了 RL 泛化能力的内部特征基础。

高效微调与系统路线探索参数高效微调（PEFT）、零阶优化、稀疏微调及后训练基础设施优化。RollPacker（P7）提出长尾 Rollout 缓解技术，通过异步同步机制优化 RL 后训练流水线，识别出长尾响应导致的 GPU 气泡问题，通过打包长尾响应，减少同步等待时间，显著提升了训练吞吐量。AlignTune（P32）提出模块化后训练对齐工具包，统一封装 SFT 与 RLHF 算法接口，解决现有代码库后端碎片化问题，提供标准化配置与评估流水线，提升了后训练实验的可复现性与效率。

| 方法 | 核心机制 | 优势（Gain） | 劣势（Cost） | 代表论文 |
| :--- | :--- | :--- | :--- | :--- |
| Delta Activations | 激活差异嵌入 | 无需外部监督，支持聚类 | 额外前向传播开销 | P2 |
| Structural Changes | SVD 分析参数空间 | 揭示结构变化机制 | SVD 计算开销较大 | P6 |
| RollPacker | 长尾 Rollout 打包 | 提升训练吞吐量 | 可能引入轻微数据偏差 | P7 |
| AlignTune | 模块化工具包 | 标准化配置，提升可复现性 | 维护成本较高 | P32 |

该路线为其他路线提供了理论依据与工程支持：机制可解释性揭示了遗忘与泛化的内部机制，高效微调则降低了理论算法的实际部署成本。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

SFT 和 RL 是 LLM 后训练的两个互补且必要的阶段，SFT 提供冷启动和格式规范，RL 提供探索和能力上限突破，单独使用任一方法均难以达到最优性能。这一共识在多个基准上被反复验证：HPT 的 56.9 与 ASFT 的 52.7 均大幅超越 SFT 基线的 44.7 和 GRPO 基线的 46.2（支撑证据：P1、P9）。SFT 容易导致灾难性遗忘和过拟合，而 RL（特别是 On-Policy RL）在保持通用能力和提升泛化性方面通常优于 SFT，但 RL 训练成本更高且不稳定。RL 微调修复 OOD 遗忘的研究（P3）进一步证实了 RL 在保持通用能力方面的优势，挑战了 SFT 优于 RL 的传统观点。

与此相关的另一个共识是，后训练过程不可避免地会改变模型的内部表征结构，导致校准度下降和输出多样性降低，即存在“对齐税”，需要通过模型合并或正则化手段进行缓解。双层优化校准（P54）和模型合并（P13）等方法均旨在解决这一问题，但现有证据表明，对齐税是后训练的固有副作用，只能通过精细化调控最小化，而非完全消除。基于可验证奖励（Verifiable Rewards）的 RL 方法在数学、代码等可验证任务上优于基于人类反馈的 RLHF，因为它提供了更客观、无偏的奖励信号，减少了奖励黑客风险。这一共识在 MATH 和 HumanEval 基准上得到验证，HPT 等混合策略在可验证任务上的显著优势支持了这一观点。

### 3.2 观点分歧

SFT 与 RL 的最优顺序与耦合机制是领域内的核心争论。观点 A 认为 SFT-then-RL 是标准范式，SFT 提供冷启动，RL 提供探索；观点 B 指出 Non-decoupling Theory 证明顺序不可解耦，SFT 损失在 RL 阶段必然下降，且 SFT-then-RL 与 RL-then-SFT 存在本质差异（支撑证据：P23）。现有证据偏向观点 B，理论证明 SFT 和 RL 在顺序训练中存在非交换性，但具体哪种顺序更优仍依赖任务类型，缺乏普适规则。这一分歧的背后，是另一个更根本的争论：RL 是能力创造者还是机制优化者？

观点 A 认为 RL 主要作为机制优化者，基础模型的质量决定了 RL 微调的泛化上限，RL 无法创造新能力（支撑证据：P25）；观点 B 认为 RL（特别是 RLVR）能激发新推理路径，突破 SFT 的性能上限，是能力创造者。证据偏向观点 B，RLVR 在数学和代码任务上的显著突破表明 RL 能发现 SFT 数据之外的推理路径，但机制可解释性研究（P56）显示，RL 更多是增强了内部电路的激活强度与多样性，而非完全创造新特征。这一分歧的根源在于缺乏因果验证手段来区分“能力激发”与“能力创造”，现有评测指标（Accuracy）无法捕捉推理路径的创新性，且基础模型质量与 RL 效果的交互作用尚未完全解耦。

### 3.3 其他开放问题

当前领域面临两大认知边界：一是“黑盒与受限 API”下的后训练，属于工程问题，已有 GP-based 和 Zero-order 优化等初步方案，但效率仍低；二是“多任务能力整合与表征几何”，属于研究问题，缺乏统一的理论框架来解释梯度冲突与表征坍缩的内在机制。最紧迫的工程问题是长尾 Rollout 导致的 GPU 利用率低，RollPacker（P7）通过异步同步机制优化 RL 后训练流水线，解决了长序列生成导致的 GPU 气泡问题，提升了训练吞吐量。黑盒模型微调的 API 成本是另一个工程瓶颈，GP-based 代理调优（P19）通过代理模型减少直接查询次数，提升了效率，但 GP 代理构建需要初始数据，限制了其适用性。

最根本的研究问题是如何在提升目标任务性能的同时，保留原有知识，即缓解灾难性遗忘。现有正则化方法在长序列任务中效果有限，缺乏在不访问历史数据的情况下有效保留原有能力的机制。潜在技术路径包括使用 KL 锚定、轨迹混合监督和熵自适应微调（P21、P29、P45），但这些方法在特定任务上显著减少了遗忘，提升了鲁棒性，缺乏长期跟踪实验来验证缓解方法的持久效果。归纳“已知—争议—未知”认知图谱：已知 SFT 与 RL 互补、对齐税存在；争议 RL 能力创造机制、蒸馏上限；未知多任务梯度冲突的数学刻画、后训练对内部电路影响的因果机制。未来发展趋势将更加注重“最小化对齐税”，实现高效、稳健且可解释的模型对齐。

## 4. 总结与展望

LLM 后训练领域的核心矛盾在于探索（RL）与利用（SFT）的平衡，以及能力增益与遗忘缓解的权衡。从 SFT 到 RL，再到统一框架与混合策略，方法演进体现了从局部优化到全局优化的思维转变。当前核心瓶颈在于如何在最大化推理能力的同时，通过精细化的正则化和混合训练，最小化对模型内部表征和通用知识的破坏（即最小化对齐税）。这一瓶颈源于 SFT 与 RL 的目标冲突、灾难性遗忘的固有性以及计算效率的工程约束，三者共同构成了后训练的技术三角。

未来可能突破的方向包括：探索 SFT 和 RL 的统一理论框架，解决两者在优化目标上的不一致性，潜在技术路径包括开发混合后训练算法如 HPT 和 ASFT（P1、P9）；研究如何缓解灾难性遗忘，保持模型在微调后的通用能力，潜在技术路径包括使用 KL 锚定、轨迹混合监督和熵自适应微调（P21、P29、P45）；开发更高效的 RL 后训练算法，解决训练不稳定性和效率问题，潜在技术路径包括使用信任区域方法如 DPPO 和 CFPO，以及前缀重要性比率（P26、P27、P30）。对于进入该领域的研究者，最值得做的一件事是在统一骨干与统一预训练条件下，系统评估混合策略在 MATH、AIME、MMLU 和 IFEval 等多维基准上的性能，以量化对齐税并验证理论统一的有效性。
