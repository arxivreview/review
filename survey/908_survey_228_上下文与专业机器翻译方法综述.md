## 导读

上下文与专业机器翻译（Contextual and Specialized MT）旨在突破传统句级翻译的局限，通过利用跨句语境与领域知识实现文档级连贯性与术语一致性。早期研究依赖架构增强解决指代消解，但受限于模型容量，难以处理长文档中的长程依赖。随着大语言模型（LLM）的介入，研究重心从参数化记忆转向提示工程与外部知识注入，显著提升了话语现象的翻译质量。面对 LLM 在专业领域中的幻觉与遗漏问题，当前范式进一步演变为智能体协作与推理增强，试图通过显式推理平衡效率与忠实度。各路线在计算成本、上下文窗口占用与语义可靠性之间做出了不同取舍，形成了多元并存的方法格局。本综述梳理这条从局部对齐到全局推理的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

传统句级机器翻译（SMT/NMT）因缺乏跨句依赖建模，导致指代消解错误、术语不一致及篇章连贯性缺失，难以满足文档级和专业领域的翻译需求。这一局限催生了文档级机器翻译（DocMT）任务，其核心目标是在翻译过程中利用句子间上下文信息以维持篇章连贯性。形式化地，给定源文档 $S = \{s_1, s_2, ..., s_n\}$，任务目标是生成目标文档 $T = \{t_1, t_2, ..., t_n\}$，使得 $t_i$ 不仅忠实于 $s_i$，还与前后文 $S \setminus s_i$ 在指代、术语和风格上保持一致。这一任务定义将翻译从孤立的序列到序列映射，扩展为受全局语境约束的生成过程。

子问题之间呈现清晰的层级依赖关系。文档级连贯性建模是基础，它为术语一致性和歧义消解提供了必要的语境消歧能力；而推理增强和智能体协作则是解决上述基础问题在长文本和高专业度场景下失效的高级手段。评估基准的演进贯穿始终，从句级 BLEU 到文档级 dCOMET 及 DiscoX 等专家领域基准，缺乏文档级评估则无法有效衡量方法的真实贡献。这种依赖结构决定了研究路径：必须先解决长程依赖，才能稳定术语映射，进而通过推理机制处理复杂语义。

2017 年 Transformer 架构的引入奠定了神经机器翻译的基础，其自注意力机制实现了序列到序列的高效建模。2018 年，早期文档级 NMT 探索通过缓存、层次注意力和记忆增强机制引入句外上下文，初步解决了传统句级翻译缺乏跨句依赖的问题。然而，这些方法受限于模型容量和训练数据规模，难以处理长文档中的复杂话语现象。2020 年 WMT 基准的建立推动了多语言对评估标准化，而 2022 年 COMET 指标的提出解决了传统 BLEU 无法捕捉语义一致性的问题，确立了句级翻译接近人类水平的共识，但也暴露出文档级评估的空白。

2023 年成为关键转折点，大语言模型（LLM）的上下文窗口突破使研究重心从修改架构转向提示工程（Prompting）。研究者通过注入源文、假设译文或参考译文作为上下文，利用 LLM 的内在知识增强话语连贯性。这一范式无需重新训练模型，即可显著提升代词消解和术语一致性，但引入了幻觉风险和计算成本。2024 年，多轮对话翻译策略将文档分割为片段，利用 LLM 的对话记忆机制保持上下文连贯，避免了长上下文稀释问题。同年，领域感知提示通过注入领域标签消解多义词歧义，提升了垂直领域翻译的准确性。

2025 年，研究进入结构化语境建模阶段。SubDocTrans 提出多粒度知识增强框架，通过提取双语摘要和专有名词构建提示，解决了长文档中的遗漏问题。TransGraph 引入图结构引导，显式建模实体共指和核心-细节关系，实现了精准的上下文检索。2026 年，AdaDPI 提出动态参数化内化机制，将上下文信息转化为模型内部参数，减少了窗口占用和推理延迟。与此同时，TwT 框架引入难度自适应推理，通过强化学习优化推理深度，解决了统一推理导致的效率-质量失衡。当前，该领域处于高度活跃期，研究重心已从单纯的翻译质量提升，转向解决幻觉、遗漏、文化不可译性及多领域歧义消解等深层问题。

**如果用一个核心问题概括该领域，那便是：如何在有限计算资源与上下文窗口约束下，通过显式语境建模与推理机制，实现长文档及专业领域中语义连贯性、术语一致性与文化适配性的全局最优对齐。**

## 2. 方法体系

- 2017：Transformer——引入自注意力机制实现序列到序列建模，成为后续神经机器翻译及大语言模型的基础架构

- 2018：文档级NMT早期探索——利用缓存、层次注意力和记忆增强Transformer引入句外上下文，解决传统句级翻译缺乏跨句依赖的问题

- 2023：上下文感知提示策略——探索利用源文本、假设翻译或参考翻译作为上下文输入LLM，通过提示工程增强话语连贯性

- 2024：多轮对话翻译——将文档分割为多轮对话片段，利用LLM的对话记忆机制保持上下文连贯

- 2025：SubDocTrans——提出多粒度知识增强框架，通过提取双语摘要、主题和专有名词构建提示，显著提升了文档级翻译的一致性

- 2025：NeoAMT——引入新词感知代理机制，结合强化学习与搜索工具处理新词，提升LLM对未知术语的处理能力

- 2026：AdaDPI——提出动态参数化内化机制，将上下文信息转化为模型内部参数，实现了更高效的文档级翻译

- 2026：TwT框架——提出难度自适应推理机制，通过多智能体蒸馏生成难度感知思维链，实现了资源理性的翻译推理

这条时间线勾勒了该领域方法演进的代表性节点：从 2017 年的 Transformer 奠定该领域方法基线，经 2018 年 文档级NMT早期探索 的推进，到 2026 年的 动作基同步翻译 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 文档级翻译建模

文档级翻译建模旨在解决长文本语境下的连贯性、术语一致性及跨句依赖问题。早期工作依赖架构增强，但受限于模型容量，难以处理长文档中的复杂话语现象。2023 年，上下文感知提示策略（P20）通过对比 GPT-4o 和 Gemma 2-27B 在不同上下文窗口下的表现，揭示了上下文类型对形式性、词汇连贯性和代词选择的影响。该方法通过形式化上下文输入 $C_n$，评估其对翻译质量的具体贡献，旨在桥接 LLM 上下文利用与话语现象之间的差距。其核心在于验证不同上下文策略的适用性，为提示工程提供实证依据，但依赖 LLM 的长上下文处理能力，且未解决上下文窗口限制问题。

随着长文档中关键信息丢失问题的凸显，研究者转向多粒度知识增强与图结构引导。SubDocTrans（P27）提出一种即插即用的多粒度知识增强框架，通过 LLM 从子文档中提取双语摘要、主题、专有名词和过渡提示，构建结构化提示以引导翻译。该方法采用句子对齐策略避免遗漏，将文档分割为连贯主题子文档，利用多粒度信息增强 LLM 对术语一致性和段落过渡的处理能力。其创新在于将外部知识显式注入提示，而非依赖模型内部记忆，但增加了预处理计算开销，且提取质量依赖 LLM 的摘要能力。TransGraph（Pham et al., 2025, P3）则提出两阶段图条件文档翻译流程，首先将源文档分割为连贯文本块并构建有向话语关系图，标注实体共指、核心-细节等关系；第二阶段在翻译每个块时，基于图检索相关上下文进行条件生成。该方法通过显式建模话语结构，解决长距离依赖问题，利用图结构实现精准上下文检索，避免无关信息干扰。其代价是图构建依赖 LLM 的语义理解能力，且关系标注需要预定义模式，限制了泛化性。

为了解决外部上下文拼接导致的窗口占用和重复处理延迟，AdaDPI（P23）提出将文档上下文信息动态内化为模型参数而非外部文本模块的机制，通过自适应规范获取模拟人类翻译者的内部表征更新。该方法避免了传统上下文拼接导致的窗口占用和重复处理延迟，实现了更高效的长文档翻译。其核心创新在于参数化记忆更新，但需要额外的参数更新机制，且对模型架构有特定要求，可能增加训练复杂度。此外，针对文档级平行数据稀缺问题，Kim et al. (2026, P10) 提出基于过滤合成语料的两阶段微调策略，先在句级数据上训练，再在文档级增强数据上适配，通过 sacreBLEU、COMET 和 LaBSE-CosSim 多指标过滤低质量样本。该方法解决了文档级平行数据稀缺问题，通过数据增强提升模型对幻觉和遗漏的抵抗能力。其代价是过滤阈值敏感，过度过滤可能导致数据多样性下降，且两阶段训练增加了计算成本。文档级建模路线与术语消解路线互补，前者提供语境基础，后者确保关键实体准确。

### 2.2 术语与歧义消解

术语与歧义消解聚焦于多领域翻译中的词汇歧义消解及专业术语约束机制。通用 LLM 在低资源或高专业度领域术语翻译不稳定，研究尝试通过术语感知提示、双阶段架构或强化学习约束确保关键实体在复杂语境中的准确映射。DuTerm（Jaswal, 2025, P4）提出结合术语感知 NMT 和 LLM 后编辑的双阶段架构，NMT 阶段通过合成数据微调确保术语基础准确，LLM 阶段通过提示工程强制术语遵循并优化流畅性。该方法解决了严格约束导致的翻译僵硬问题，利用 LLM 内在知识平衡术语准确性与自然度。其代价是两阶段推理延迟增加，且 LLM 后编辑可能引入新错误，需要质量过滤机制。

针对类型学多样语言中的术语变体处理挑战，P24 研究了税务和金融教育领域中七种类型学多样语言的术语翻译，通过 LLM 辅助术语提取和分类（领域特定、领域语境、通用），分析术语形态变化对翻译的影响。该方法揭示了低资源语言中术语变体处理挑战，为多脚本语言术语翻译提供实证依据。其局限是依赖 LLM 术语提取准确性，且未提出通用解决方案，仅作为分析框架。DMDTEval（P19）提出多领域翻译歧义消解评估框架，构建含多领域歧义词标注的测试集，设计多样化消解提示策略，并开发精准歧义消解指标。该方法系统评估 LLM 在不同领域（法律、科技等）中处理多义词的能力，揭示提示策略对消解效果的影响。其创新在于将歧义消解作为独立评估维度，但依赖人工标注歧义词，且评估范围限于特定语言对。CEMT（P17）提出基于结构化语言推理的可控元素导向翻译方法，通过显式语言信号和结构化推理链处理翻译特定元素（如术语、句法），提升 LLM 翻译的可靠性和可解释性。该方法克服了 LLM 隐式表征导致的不可预测性，通过结构化推理确保关键元素准确处理。其代价是推理链生成增加计算开销，且结构化模板可能限制模型灵活性，不适合高度创造性翻译。术语消解路线依赖于文档级建模提供的语境，同时为垂直领域专项翻译提供术语基础。

### 2.3 推理增强翻译机制

推理增强翻译机制探索 LLM 在翻译任务中的推理能力应用，包括难度自适应推理、结构化思维链及新词处理代理。通用 CoT 在翻译中因缺乏修订机制导致效果有限，激发了对翻译专用推理结构的探索。TwT（Ye et al., 2026, P13）提出资源理性翻译框架，通过多智能体蒸馏生成难度感知长思维链，结合强化学习优化推理深度，使模型根据输入复杂度动态调整推理努力。该方法解决了统一推理导致的效率-质量失衡，通过 Rich Points 密度评估难度，实现直觉与深思推理的自适应切换。其代价是多智能体蒸馏过程复杂，且难度评估依赖预定义 Rich Points，可能遗漏隐性难点。

结构化推理框架（Rajaee et al., 2026, P9）提出针对翻译任务的结构化推理框架，包含多步起草、充分性精炼、流畅性改进和选择性迭代修订步骤，通过合成动态结构化推理轨迹后训练推理模型。该方法克服了通用 CoT 在翻译中缺乏修订机制的缺陷，通过任务特定结构提升推理有效性。其创新在于将推理过程分解为翻译专用阶段，但依赖高质量合成数据，且推理步骤固定，可能不适用于所有文本类型。NeoAMT（Miao et al., 2026, P6）提出新词感知代理机器翻译框架，结合强化学习与搜索工具，通过自适应采样和奖励设计处理新词，允许 LLM 在推理中多次调用搜索获取新词信息。该方法解决了 LLM 对新词和罕见术语的处理不足，通过代理机制实现动态知识获取。其代价是搜索调用增加推理延迟，且奖励设计复杂，需要精细调优以防止奖励黑客。推理增强路线与文档级建模路线竞争，前者通过显式推理提升质量，后者通过结构建模提升效率。

### 2.4 垂直领域专项翻译

垂直领域专项翻译针对字幕、学术、历史手稿等特定场景，解决风格适配、文化负载词显化及低资源领域数据稀缺问题。Hermes（Cui et al., 2026, P7）提出统一的多模态字幕翻译框架，整合说话人分离、术语一致性和风格适配模块，解决字幕翻译中语义连贯性和表达力不足的问题。该方法利用音频-视觉线索进行说话人归属，结合领域术语库确保专业词汇准确，并通过风格迁移提升目标语言自然度。其创新在于多模态信息融合，但依赖高质量音频-文本对齐，且计算开销较大，不适合实时应用。

自适应局部偏好优化（Cui et al., 2026, P8）提出针对字幕翻译的自适应局部偏好优化训练方法，通过 LLM-as-a-Judge 生成局部偏好数据，优化模型对行业标准和风格适配的遵循能力。该方法解决了通用 LLM 在垂直领域术语一致性和表达力上的不足，通过局部偏好对齐提升翻译的专业性。其代价是偏好数据生成依赖 LLM 判断准确性，且局部优化可能损害全局连贯性。上下文驱动数据增强（P15）提出基于角色描述和参考引导的数据增强方法，通过 LLM 重写源句以反映特定电影风格，生成多样化平行数据用于指令微调。该方法解决了字幕翻译低资源问题，利用角色特征增强风格一致性，通过参考窗口确保术语准确。其创新在于将角色信息显式融入数据生成，但依赖少量人工标注种子数据，且生成数据质量受 LLM 风格模仿能力限制。GlossaGen（P14）提出面向学术翻译的注释生成框架，通过 LoRA 适配器微调 LLM，根据读者水平（本科/研究生）动态调整术语注释的详细程度。该方法解决了学术翻译中术语晦涩问题，通过层级适配实现教育性翻译，确保非母语读者理解核心概念。其代价是注释生成增加输出长度，且层级判断依赖读者画像准确性，可能不适用于混合读者群体。副文本显化翻译（P18）提出针对文化负载词的副文本显化方法，通过 LLM 生成脚注和尾注解释文化特定概念，结合代理检索增强外部知识获取。该方法解决了文学翻译中文化语境丢失问题，通过副文本补充源语言隐含意义，提升目标读者理解。其创新在于将副文本作为翻译输出的一部分，但增加阅读负担，且检索效率较低，不适合实时翻译场景。中世纪拉丁文管道评估（Bui et al., 2026, P12）提出针对中世纪拉丁文手稿的端到端翻译管道评估框架，整合 OCR、后处理校正和语义翻译阶段，通过 Interpres Parallel Corpus 基准测试各组件性能。该方法揭示了领域特定 OCR 模型相比通用 VLM 在字符错误率上的优势，为低资源历史文本翻译提供系统化评估方法。其代价是依赖高质量转录数据，且管道各阶段误差累积，需要精细调优。垂直领域路线与术语消解路线互补，前者关注风格与文化，后者关注术语准确性。

### 2.5 实时与口语翻译

实时与口语翻译关注同步机器翻译及口语场景，借鉴人类口译策略处理信息不完整问题，平衡实时性延迟与翻译质量。动作基同步翻译（P16）提出将人类口译策略（句子切割、选择性省略、部分重排）形式化为可调用动作的同步翻译框架，通过 LLM 动态决策动作执行，平衡实时延迟与翻译质量。该方法突破了传统 READ/WRITE 策略限制，实现拟人化翻译行为，提升长句处理流畅性。其创新在于动作抽象化，但动作定义依赖人工设计，且 LLM 决策可能引入不一致性，需要约束机制。人类口译启示框架（P26）提出基于人类口译研究的机器口译设计原则，强调总结、省略和文化适应策略，通过强化学习和指令微调模拟人类错误预防与恢复机制。该方法将口译学理论转化为可操作的技术策略，提升实时翻译的自然度和用户接受度。其局限是策略抽象化可能丢失细节，且依赖高质量口译数据，难以泛化到所有场景。实时翻译路线与文档级建模路线竞争，前者强调低延迟，后者强调全局连贯。

### 2.6 模型训练与评估

模型训练与评估涵盖上下文感知模型的数据构成影响、长上下文位置编码优化、特定语对紧凑模型构建及专业领域翻译基准的建立。数据构成影响研究（Mąka et al., 2025, P1）系统研究上下文感知 MT 模型训练数据中语境丰富样本密度对性能的影响，通过 ctxPro 工具识别语境样本，构建不同密度数据集，揭示数据稀疏性与上下文利用能力的相关性。该方法为上下文感知模型训练提供数据配比指导，证明增加语境样本密度可显著提升模型性能。其局限是仅关注特定语境现象，且结论可能受语言对和模型架构影响，需跨场景验证。DCARPE（P28）提出动态上下文感知相对位置编码机制，适应分词导致的序列膨胀，通过调整位置偏差解释缓解形态丰富语言在长上下文中的翻译退化。该方法解决了多语言翻译中分词偏差导致的距离失真问题，提升长文本鲁棒性。其创新在于位置编码动态调整，但依赖分词器特性，且对非形态丰富语言增益有限，需要语言特定调优。CAT-Translate（Jinnai, 2026, P11）构建面向日英翻译的紧凑开源模型家族（0.8B-7B），通过合成数据微调优化自然度，解决隐私约束下消费级 GPU 部署需求。该方法针对特定语言对优化，避免通用模型翻译腔，通过定性评估选择基础模型。其代价是模型专用性强，不适用于多语言场景，且合成数据生成依赖 LLM 质量，可能引入偏差。LTT 语义感知双循环（P25）提出基于循环一致性的双循环翻译学习框架，利用 GRPO 算法和语义感知奖励函数，无需平行语料即可实现稳定自进化翻译。该方法解决了无监督翻译中的奖励黑客和语义漂移问题，通过往返一致性约束提升翻译忠实度。其创新在于将双循环学习适配生成范式，但依赖语义指标准确性，且训练过程复杂，需要精细奖励设计。困难样本主题搜索（Xu et al., 2025, P2）提出基于主题树的困难翻译样本搜索方法，利用质量估计模型评估样本难度，从互联网语料中自动挖掘高难度主题，构建可复现的挑战性测试集。该方法解决了静态基准缺乏持续难度的问题，通过主题结构实现规模化样本挖掘。其代价是依赖质量估计模型准确性，且主题划分可能遗漏跨主题难点，需要人工验证。DiscoX 话语级基准（Zhao et al., 2025, P5）提出专家领域话语级翻译基准，评估模型在科学、法律、技术领域的连贯性、术语一致性和风格适配能力，揭示思考增强模型在翻译中的性能下降现象。该方法填补了话语级评估空白，提供多维度评估指标，揭示 LLM 在专业文本中的局限性。其局限是基准规模有限，且评估依赖 LLM-as-a-Judge，可能存在偏差。AFRIDOC-MT（P21）针对五种非洲语言的文档级翻译数据集，涵盖健康和技术领域，用于评估低资源语言在文档级翻译中的表现及模型对长文本的处理能力。模型训练与评估路线为其他路线提供基础支撑，数据构成和位置编码优化直接影响翻译质量。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLM 在句级翻译上接近人类水平，但在文档级连贯性和专业领域一致性上仍存在显著短板，这一共识在多个基准上被反复验证。例如，在 GuoFeng 基准上，TransGraph 的 87.76 dCOMET 虽显著优于基线，但仍远低于人类翻译水平；在 DiscoX 基准上，DiscoX-Metric-S 的 75.0 Score 揭示了 LLM 在专家领域话语级翻译中的局限性。上下文信息的引入（如源文、假设译文、参考译文）能显著提升话语现象（如代词、术语）的翻译质量，这一共识在 WMT-24 General 基准上得到支持，Source-primed Multi-turn 的 84.75 sCOMET 较无上下文基线有显著提升。传统自动指标（如 BLEU）无法有效捕捉幻觉、遗漏及篇章连贯性，需引入语义级或 LLM-as-a-Judge 评估，这一共识在 DiscoX 和 GuoFeng 基准上得到体现，dCOMET 和 Metric-S 等指标与人类判断相关性高于 BLEU。专业领域翻译需要显式的术语约束或领域知识注入，仅靠预训练知识不足以保证术语一致性，这一共识在 Tax/Finance Domain 基准上得到支持，GPT-4o 的 90.0 Term Accuracy 表明 LLM 在专业领域术语处理上的能力，但依赖显式约束。长文档翻译面临上下文窗口瓶颈，分段处理或智能体协作是当前的主要技术路径，这一共识在 WMT-24 General 和 GuoFeng 基准上得到支持，多轮对话和图结构引导方法显著提升了长文档翻译质量。文化专有项的翻译需要超越字面意义的策略，如副文本显化或检索增强，以保留文化内涵，这一共识在文学翻译场景中得到体现。字幕翻译等垂直领域任务需要针对风格、口语化和行业术语的专门优化，通用 LLM 表现不佳，这一共识在 MuSC 基准上得到支持，ALPO 的 90.6 Accuracy 表明局部偏好优化在字幕翻译风格适配上的优势。推理增强（CoT/RL）在翻译中并非总是有效，需根据任务难度自适应调整推理深度，避免过度推理导致的忠实度下降，这一共识在 DiscoX 基准上得到体现，部分思考增强模型在翻译中的性能下降现象。

### 3.2 观点分歧

推理增强（CoT/RL）在翻译任务中是否普遍有效？观点 A 认为推理增强能显著提升复杂任务（如歧义消解、新词处理）的质量，代表方法包括 TwT、NeoAMT 和 Structured Reasoning。观点 B 认为显式推理可能导致过度总结、结构冗余，降低翻译忠实度，且增加延迟，代表证据包括 DiscoX 基准中思考增强模型的性能下降现象。现有证据偏向“有条件有效”。在 WMT24++ 和 Neko 等涉及复杂推理或新词的数据集上，推理增强方法（如 Structured Reasoning 的 75.0 XCOMET-XL、NeoAMT 的 85.0 Accuracy）取得了 SOTA。但在 DiscoX 等强调全局连贯性的基准上，部分思考模型表现不佳。证据强度中等，因为不同基准对“推理”的定义和评估维度不同。缺乏统一的“翻译难度”评估标准，导致难以区分“需要推理”和“不需要推理”的任务。此外，LLM-as-a-Judge 在评估推理过程对忠实度的影响时存在偏差，需更多基于人类专家判断的对照实验。

解决长程依赖应依赖外部知识注入（Prompting/RAG）还是内部参数化记忆（Fine-tuning/Parameterization）？观点 A 认为外部注入（如 SubDocTrans、TransGraph）透明、灵活，易于更新知识，适合低资源或动态领域。观点 B 认为内部参数化（如 AdaDPI、两阶段微调）更高效，减少推理延迟，适合固定领域的大规模部署。现有证据显示两者各有优劣。外部注入在 GuoFeng 等长文档基准上表现优异（如 SubDocTrans 的 81.64 dCOMET），但延迟较高。内部参数化（如 AdaDPI 的 85.42 COMET）在效率上占优，但训练复杂且黑盒。证据强度较强，基于多个基准的对比实验。缺乏在相同计算预算（FLOPs/Token）下的公平比较。外部注入的“预处理”成本常被忽略，而内部参数化的“训练”成本也未完全计入。此外，不同语言对和领域对两种方法的敏感度不同，需更多跨场景验证。

专业领域术语一致性应通过“硬约束”（术语库/规则）还是“软约束”（提示工程/RL）实现？观点 A 认为硬约束（如 DuTerm 中的 NMT 阶段，术语库增强）能确保术语准确性，适合高利害领域（法律、医疗）。观点 B 认为软约束（如领域感知提示，RL 奖励）能保持翻译自然度，避免僵硬，适合通用专业文本。现有证据偏向“混合策略”。DuTerm 等双阶段架构在术语准确性上表现最佳，但自然度略逊。纯提示工程方法在流畅度上占优，但术语稳定性不足。证据强度中等，因为“自然度”和“准确性”的权衡因领域而异。缺乏统一的“术语一致性-自然度”权衡指标。现有评测多侧重术语召回率，对因术语硬约束导致的句法僵硬缺乏量化评估。需开发能同时捕捉两者影响的综合指标。

### 3.3 其他开放问题

当前领域面临“工程问题”与“研究问题”的双重挑战。最紧迫的工程问题包括扩展至更多类型学多样语言及低资源场景，当前研究多集中于高资源语言对（如英中、英德），未来需将上下文策略、术语一致性方法推广至形态复杂、低资源语言（如非洲语言、斯拉夫语系），难点在于缺乏大规模平行语料和标注数据，潜在路径包括利用合成数据增强、跨语言迁移学习及多模态辅助。优化推理效率与质量的权衡也是关键工程问题，推理型 LLM 在翻译中虽提升质量但增加延迟和令牌消耗，未来需开发难度自适应推理机制，根据输入复杂度动态调整推理深度，难点在于准确估计翻译难度并设计高效的奖励函数，潜在路径包括强化学习中的难度感知采样、轻量级推理蒸馏。最根本的研究问题包括构建更贴近真实场景的专业领域基准，现有基准多基于通用或学术文本，缺乏对法律、医疗、金融等专业领域风格、术语及合规性的全面评估，难点在于专家标注成本高且标准不一，潜在路径包括构建多领域专家标注数据集、开发参考无关的 LLM 评估系统（如 Metric-S）、以及引入用户研究评估。解决新词、文化负载词及不可译现象的处理也是核心研究问题，模型在翻译新造词、文化特定概念时易产生幻觉或直译，未来需建立不可译性本体论和补偿策略分类法，难点在于语义错配的自动识别和策略选择，潜在路径包括代理式搜索工具辅助、副文本显化生成、以及基于人类偏好数据的策略对齐。已知—争议—未知认知图谱显示，领域在句级翻译质量上已达成共识，在文档级连贯性和专业术语一致性上存在争议，在不可译性处理和低资源扩展上仍属未知。发展趋势将向更真实、更专业的应用场景深化，推理效率优化和不可译性理论的建立是下一步的关键。

## 4. 总结与展望

上下文与专业机器翻译领域已从“句级局部对齐”成功转向“文档级全局推理”，LLM 与智能体技术的融合为解决长程依赖和专业约束提供了新路径。核心矛盾在于如何在有限计算资源与上下文窗口约束下，通过显式语境建模与推理机制，实现长文档及专业领域中语义连贯性、术语一致性与文化适配性的全局最优对齐。尝试过的路线包括提示工程、多粒度知识增强、图结构引导、动态参数化内化、推理增强和智能体协作，各路线在计算成本、上下文窗口占用与语义可靠性之间做出了不同取舍。核心瓶颈在于长文档中的上下文窗口限制、LLM 的幻觉与遗漏、专业领域术语稳定性不足以及文化不可译性处理。

未来可能突破的方向包括：1）构建更贴近真实场景的专业领域基准，填补法律、医疗、金融等领域风格、术语及合规性评估的空白，DiscoX 和 AFRIDOC-MT 等基准正在朝这一方向推进（P5, P21）；2）开发难度自适应推理机制，平衡推理效率与质量，TwT 和 NeoAMT 等框架提供了初步探索（P13, P6）；3）建立不可译性本体论和补偿策略分类法，解决新词、文化负载词及不可译现象的处理，副文本显化和代理式搜索工具是潜在路径（P18, P6）。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，系统评测不同路线（外部知识注入 vs. 内部参数化、硬约束 vs. 软约束）在多个基准上的表现，并引入计算效率维度（Token Usage/Latency），以揭示方法选择的真实权衡。
