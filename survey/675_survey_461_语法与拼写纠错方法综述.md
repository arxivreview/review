# A Survey of Grammatical Error Correction and Spelling Correction Methods ｜语法与拼写纠错方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Grammatical%20Error%20Correction%20and%20Spelling%20Correction)

## 导读

语法错误纠正（GEC）与拼写纠正（CSC）旨在自动检测并修复文本中的语言偏差，其核心价值在于提升机器翻译、语音识别及教育辅助系统的可用性。早期研究依赖人工规则与统计模型，随后确立将纠错视为单语翻译任务的标准范式，解决了长距离依赖问题，但引入了生成式模型固有的幻觉风险。随着预训练语言模型的引入，领域进入特征增强阶段，重点解决低资源语言数据稀缺及中文音形混淆问题。当大语言模型（LLM）的生成能力被引入后，核心矛盾从“能否纠正”转变为“忠实度与最小编辑原则的冲突”，即模型倾向于修改原本正确的部分或改变原意。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从序列生成到强化对齐的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

语法错误纠正与拼写纠正的核心驱动力在于提升自然语言处理下游任务的文本质量，其应用广泛覆盖机器翻译、语音识别后处理及教育辅助系统。早期研究主要依赖人工规则或统计语言模型，试图通过模式匹配修复文本偏差，但受限于规则泛化能力差及统计模型对长距离依赖处理不足，难以应对复杂句式。2016 年，Yuan 和 Briscoe 确立将 GEC 视为单语翻译任务的标准范式，利用神经机器翻译（NMT）架构处理错误句子到正确句子的映射，这一转变奠定了现代 GEC 系统的标准范式，解决了早期规则方法泛化能力差的问题。该范式将纠错形式化为序列到序列（Seq2Seq）生成任务，即给定包含错误的源句子 $x$，模型学习条件概率分布 $P(y|x)$ 以生成正确版本 $y$，其中 $y$ 需满足最小编辑原则（Minimal Edit Principle），即仅修改必要部分以保留原意。

问题定义在 2020 年后经历了显著演化，从单一的文本质量修复演变为多约束下的生成控制问题。随着 BERT 等预训练语言模型（PLM）的引入，领域进入特征增强阶段，重点解决低资源语言数据稀缺及中文音形混淆问题，问题定义从“通用纠错”细化为“特定语言/领域适配”。2024 年后，随着 LLM 的广泛应用，核心痛点转变为“过度纠正”（Over-correction），即模型倾向于修改正确部分或改变原意，导致忠实度下降。此时，子问题间存在强依赖关系：低资源数据合成是跨语言迁移的前提；LLM 的过度纠正问题制约了其在高精度场景（如法律、医疗）的应用，需通过奖励模型或检索增强生成（RAG）解决；评估指标的革新（如最近金标准，Closest Golds）是衡量 LLM 纠错有效性的基础，否则无法准确反馈模型性能。

约束演化史清晰地展示了方法如何因应约束变化而演变。2016-2018 年，Seq2Seq-GEC 奠定基线，ERRANT 提出基于编辑操作的自动评估框架，标准化了 GEC 领域的评估指标。2020 年，GECToR 提出基于 Transformer 的序列到编辑（Seq2Edit）架构，通过预测每个 token 的编辑操作而非生成整句，显著提升了纠错效率与精度，确立了编辑预测范式在 GEC 中的主导地位。2021-2023 年，SpellGCN 在 BERT 编码器中集成音韵和视觉约束，缓解了中文拼写纠错中音形混淆的问题；MTF 提出掩码-翻译-填充合成数据生成策略，解决了低资源语言缺乏平行纠错数据的核心瓶颈。

2024-2026 年，研究重心转向利用 LLM 的生成能力与强化学习（RL）对齐最小编辑原则。2024 年，ReLM 将中文拼写纠错重构为语言建模任务，GEE 利用思维链（CoT）引导纠错过程，缓解了 LLM 的过度纠正问题。2025 年，ChineseErrorCorrector3-4B 提出统一的大规模中文纠错模型，ReViCo 构建首个真实世界视觉拼写纠错基准，OmniGEC 发布覆盖 11 种语言的银色多语言 GEC 数据集。2026 年，CSRP 提出基于强化学习的思维链推理框架，EARM 提出编辑感知奖励模型，CL2GEC 构建中文文学语法纠错的持续学习基准，RoLegalGEC 发布罗马尼亚语法律领域数据集，CoVoGER 构建多语言语音到文本生成式纠错基准，PFG 提出口语教学反馈生成框架。当前形态标志着从单一语言优化向通用、鲁棒、多模态纠错系统的全面转型。

**如果用一个核心问题概括该领域，那便是：如何在保持文本语义忠实度与最小编辑原则的前提下，利用生成式模型的强大能力实现跨语言、跨模态及多领域场景下的鲁棒纠错。**

## 2. 方法体系

- 2016：Seq2Seq-GEC——将语法纠错建模为单语机器翻译任务，奠定现代 GEC 系统的标准范式

- 2017：ERRANT——提出基于编辑操作的自动评估框架，标准化 GEC 领域的评估指标

- 2020：GECToR——提出基于 Transformer 的序列到编辑架构，确立编辑预测范式的主导地位

- 2021：SpellGCN——在 BERT 编码器中集成音韵和视觉约束，缓解中文拼写纠错中音形混淆问题

- 2023：MTF——提出掩码-翻译-填充合成数据生成策略，解决低资源语言缺乏平行纠错数据瓶颈

- 2025：ChineseErrorCorrector3-4B——提出统一的大规模中文纠错模型，实现拼写与语法纠错的深度集成

- 2026：CSRP——提出基于强化学习的思维链推理框架，显式优化编辑效率，缓解过度纠正偏差

- 2026：EARM——提出编辑感知奖励模型，为 GRPO 提供细粒度的质量区分信号

这条时间线勾勒了该领域方法演进的代表性节点：从 2016 年的 Seq2Seq-GEC 奠定该领域方法基线，经 2017 年 ERRANT 的推进，到 2026 年的 RoLegalGEC 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 多语言低资源纠错

多语言低资源纠错路线的起源可追溯至 2016 年 Seq2Seq-GEC 确立的单语翻译范式，该范式假设纠错可视为源句到目标句的映射，但受限于当时算力与数据规模，主要追求生成流畅度而非编辑最小性。随着非英语语言（如印地语、阿拉伯语）标注数据极度稀缺，传统人工标注成本不可承受，研究者转向合成数据生成策略。MTF（Mask-Translate&Fill）（P14）提出掩码-翻译-填充合成数据生成策略，旨在仅利用单语语料训练高质量的 GEC 系统。该方法首先利用机器翻译系统将单语句子翻译为高资源语言，形成伪平行语料；接着使用 Fast Align 计算词对齐，指导在高资源语言中进行 token 掩码；掩码后的句子通过预训练语言模型进行填充，最后将填充后的掩码回译，生成不规范的变体，并与原始句子配对作为 GEC 训练数据。该方法不依赖人工标注或语言特定规则，具有通用性，可应用于其他低资源语言，解决了低资源语言缺乏平行纠错数据的难题，但合成数据可能存在分布偏差，需复杂的清洗与质量控制流程。

OmniGEC（Kovalchuk et al., 2025, P2）构建覆盖 11 种语言的银色多语言 GEC 数据集，旨在解决低资源语言缺乏高质量标注数据的问题。数据生成过程采用三步法：首先使用 GPT-4o-mini 对原始文本样本进行少样本提示生成纠正；然后再次提示模型聚合多个纠正结果，创建最终纠正。这种聚合方法基于高多样性排序和集成方法的变体，通过聚合多种多样的纠正而非选择最佳一个，获得更完整的纠正。数据集包括捷克语、英语、爱沙尼亚语等 11 种语言，与 MultiGEC-2025 共享任务的语言选择保持一致，以便进行数据和方法的比较。该方法利用专有模型生成合成纠正，虽然可能影响可复现性，但显著增加了数据量，为多语言 GEC 研究提供了宝贵的资源。RoLegalGEC（Timpuriu et al., 2026, P10）发布罗马尼亚语法律领域语法错误检测与纠正数据集，并开发相应的合成错误生成方法。该方法针对罗马尼亚语错误分类法中定义的多种错误类型，设计了三种合成错误生成程序：噪声注入、基于混淆列表的统计生成和基于 LLM 的生成。在 LLM 生成中，通过提示通用 LLM（如 GPT-4o）或罗马尼亚语 LLM（如 RoMistral-7b）分析句子的语法，并生成包含特定类型错误的句子。该方法最小化了未标注数据的问题，通过任务化 LLM 生成特定类型的错误，基于干净语料库段落，解决了低资源语言中获取大量标注数据的困难。

Urdu-GEC-Pipeline（P15）提出针对乌尔都语 GEC 的合成数据生成流水线，旨在避免手动标注和语言特定规则。该方法分为两个阶段：标注阶段和施加阶段。在标注阶段，从正确和不正确的句子对中学习不同类型的错误，利用从乌尔都语维基百科修订历史中挖掘的自然语法错误。在施加阶段，给定干净的乌尔都语句子，输出由从正确和不正确句子对集合中学习的错误类型导致的损坏句子，形成 GEC 对。该方法使用自定义对齐算法，受 ERRANT 启发，将编辑分类为插入、删除或替换。它利用乌尔都语与其他印度-雅利安语言在形态句法上的相似性，假设数据生成流水线可迁移，在低资源约束下实现了具有竞争力的下游性能。Indic-GEC-Prompting（De et al., 2025, P7）提出针对印地语等低资源语言的 GEC 提示策略，利用大语言模型进行零样本和少样本纠错。该方法将 GEC 任务建模为序列到序列转换问题，估计条件概率分布以最大化正确输出的似然。利用 GPT4.1 mini、Gemini-2.5-Flash 和 Llama-4-Maverick-17B-128EInstruct 等 LLM 进行推理，探索不同提示范式下的性能。该方法针对印地语、孟加拉语、泰米尔语等语言，处理形态学纠正、代词纠正、动词时态纠正、主谓一致纠正等多种错误类型，强调了在低资源设置下，提示工程在提升 LLM 纠错能力中的重要性，为低资源语言 GEC 提供了无需大量标注数据的替代方案。ArbESC+（Alrehili and Alhothali, 2025, P5）针对阿拉伯语 GEC，通过增强编辑选择系统组合解决冲突并改进系统组合，在 QALB-14 基准上取得了 56.05 的 F0.5 分数，优于 ByT5 的 56.05 和 AraT5 的 53.53，展示了系统组合在低资源语言纠错中的有效性。

### 2.2 中文纠错强化学习

中文纠错强化学习路线的起源可追溯至 2021 年 SpellGCN 在 BERT 编码器中集成音韵和视觉约束，通过图卷积网络捕捉字符间的相似性关系，有效缓解了中文拼写纠错中音形混淆的问题，推动了基于预训练模型的 CSC 研究。2022 年，SynGEC 引入句法增强框架，利用句法树结构辅助纠错模型理解长距离依赖关系，提升了中文语法纠错对复杂句式的处理能力。2024 年，ReLM 将中文拼写纠错重构为语言建模任务，通过重新概念化纠错过程，利用大语言模型的生成能力处理字符级错误，展示了 LLM 在 CSC 任务中的潜力。GEE 利用思维链（CoT）和解释信息引导纠错过程，通过生成中间推理步骤提高模型的可解释性和可控性，缓解了 LLM 在纠错任务中的过度纠正问题。

ChineseErrorCorrector3-4B（Tian and Zhou, 2025, P6）提出统一的大规模中文纠错模型，旨在同时解决中文拼写纠正（CSC）和中文语法纠错（CGC）。该方法采用两阶段监督微调（SFT）范式，第一阶段在 Lang8 和 HSK 等大规模混合纠正语料上进行训练，以捕捉从字符级、词汇级到句法级的通用错误模式。第二阶段在精心策划的高质量领域数据和真实学习者错误上进行领域特定精炼，增强模型处理复杂语法结构、长距离依赖和领域特定表达的能力。模型将纠错建模为序列到序列生成任务，优化目标为标准负对数似然损失。这种分阶段策略显著提高了模型在真实场景中的鲁棒性和泛化能力，同时保持整体性能，实现了拼写和语法纠正能力的深度集成，对形式级错误具有高敏感性，并能精确建模句法和语义级错误。该方法确立了在大规模预训练模型基础上进行领域适配的技术路线，为中文纠错提供了新的 SOTA 基线。

CSRP（Tian et al., 2026, P12）提出基于强化学习的思维链推理框架，旨在将通用大语言模型转化为高精度的中文语法纠错系统。该框架包含三个阶段的流水线：平衡持续预训练（CPT）、逻辑增强监督微调（SFT）和效用对齐强化学习（RL）。在 CPT 阶段，模型在通用语料和纠错语料（如 Lang8+HSK）的平衡混合数据上进行训练，以建立基础的纠错理解能力。SFT 阶段利用 Qwen-Plus 生成逻辑增强的思维链数据，引导模型进行推理。RL 阶段采用组相对策略优化（GRPO），引入效率感知奖励，显式优化相对改进和编辑效率。该方法通过奖励机制对齐模型策略与“最小干预”的语言学原则，有效缓解了先前 LLM 系统中观察到的过度纠正偏差。它超越了简单的分数追逐，解决了传统 SFT 基于最大似然估计无法校准“编辑或不编辑”决策边界的问题，放弃了纯 SFT 的简单性，换取了对最小编辑原则的显式约束。

EARM（P18）提出编辑感知奖励模型，旨在解决规则基奖励在中文 GEC 中粒度粗糙和无法捕捉细粒度质量差异的问题。该方法首先通过 ChERRANT 进行字符级对齐，识别源句子和候选纠正之间的编辑跨度。随后构建编辑掩码，为候选中的每个 token 计算编辑感知权重，区分被编辑的 token 和未改变的 token。模型输出句子级奖励和 token 级加权分数，并使用混合损失函数（包括 Bradley-Terry 损失和显式边际约束损失）进行训练。训练后的奖励模型用于指导 GRPO 策略优化，提供比二元规则奖励更细致的质量区分信号。这种方法使得动态策略更新成为可能，通过基于组的优势估计提高了纠错的可靠性，克服了规则基奖励在细粒度质量评估上的局限性，为 LLM 对齐提供了更有效的奖励机制。CSRP 与 EARM 共同构成了当前中文纠错强化学习路线的核心，前者通过策略优化实现编辑效率，后者通过奖励模型提供细粒度信号，两者在 NaCGEC 基准上分别取得了 50.99 和 61.29 的 F0.5 分数，展示了 RL 路线在细粒度编辑控制上的优势。

### 2.3 视觉与语音纠错

视觉与语音纠错路线的起源可追溯至 2025 年 ReViCo 构建首个系统评估视觉语言模型（VLM）在真实世界视觉拼写纠正任务上的基准，涵盖中文和英文。该基准包含从真实世界图像数据中收集的自然发生错误，支持图像级和 token 级的细粒度评估。研究探索了两种解决方案范式：联合 OCR-纠正流水线和背景信息增强方法，两者均带来了一致的性能提升。通过对比级联架构（如 Qwen）和原生多模态模型（如 InternVL）以及闭源系统（如 GPT-4o），揭示了当前 VLM 在纠正任务上显著低于人类水平的局限性。该方法强调了视觉上下文在纠错中的重要性，指出仅依赖文本中心的语言建模或序列到序列任务是不够的，为多模态拼写纠正提供了可操作的见解，推动了 VLM 在视觉纠错领域的研究。

CoVoGER（P19）构建多语言多任务语音到文本生成式纠错基准，旨在评估 LLM 在纠正 ASR 和 ST 错误中的能力。该基准利用 Common Voice 20.0 和 CoVoST-stream 2 数据集，通过 Whisper 和 SeamlessM4T 生成 N-best 假设列表。GER 模型被建模为映射函数，将 N-best 列表转换为更接近参考转录/翻译的生成序列。训练过程最小化序列到序列损失，利用 LLM 的参数化条件分布。该方法研究了不同第一遍模型（ASR/ST）的性能和假设多样性对下游 GER 的影响，推动了从被动选择到主动生成式纠错的转变，特别是在多遍语音代理系统中，填补了非英语和多语言 GER 研究的空白。

Disfluency-Aware-LLM（Kumar et al., 2026, P11）提出多语言非流利语修正框架，结合 MuRIL 标记和指令微调 LLM，旨在处理自发语音中的非流利现象。该方法首先通过对齐平行流利-非流利对，标记非流利 token，生成监督标签用于序列标记。然后，数据被格式化为 Alpaca 风格的指令-输入-输出模式，用于 LLM 微调。在对比变体中，通过对齐识别的非流利 token 集作为辅助输入提供，模型使用组合目标优化：用于流利生成的交叉熵损失和抑制已知非流利 token 重新生成的对比惩罚。该方法解决了删除式流水线破坏语法结构和语义完整性的问题，针对印地语、孟加拉语和马拉地语等低资源语言，提供了比传统检测-删除方法更自然的纠正，在 Hindi/Bengali/Marathi 基准上取得了 45.2 的 BLEU 分数。

RECOVER（Kumar and Sachdeva, 2026, P8）提出基于代理编排的鲁棒实体纠正框架，旨在纠正 ASR 转录中的实体级错误，同时保持其余文本完整。该框架包括多假设生成、动态实体候选检索和三个代理工具：融合假设、提出纠正和验证与应用。动态实体候选检索选择前 K 个实体候选，代理工具利用上下文证据进行基于证据的恢复。该方法解决了 LLM 在没有严格约束下容易产生幻觉或过度纠正的问题，特别针对金融、空中交通管制和医疗等领域中的稀有或训练数据中缺失的实体短语。通过利用代理的工具使用能力，该方法提供了比传统解码时偏差更灵活的后 ASR 纠错方案，在 Earnings-21 和 Common Voice 基准上分别取得了 33.4% 和 41.2% 的 RWERR，展示了代理编排在实体恢复上的鲁棒性。

### 2.4 评估基准与数据

评估基准与数据路线的起源可追溯至 2017 年 ERRANT 提出基于编辑操作的自动评估框架，通过定义插入、删除、替换等编辑类型并计算 F0.5 分数，标准化了 GEC 领域的评估指标，成为后续所有纠错系统对比的基准工具。随着 LLM 的引入，固定参考评估对 LLM 的不公平性日益凸显，研究者开始探索更鲁棒的评估范式。

RACQC（P17）提出基于检索增强生成（RAG）的中文查询纠正系统，旨在解决 LLM 在长尾或时间实体上的过度纠正问题。该方法利用网页标题数据和从中提取的实体建立离线实体-标题语料库，专门用于支持稀有和演变实体的检索。当遇到需要外部知识的查询时，检索器从语料库中搜索相关信息并输入 LLM，以增强模型生成并解决过度纠正问题。同时，构建了 MDCQC 多领域中文查询纠正基准，包含搜索领域数据，填补了开放域搜索场景下 CSC 数据集的空白。该方法通过引入外部知识，提高了 LLM 在特定领域纠错的准确性和相关性，展示了 RAG 在纠错任务中的应用潜力，特别是在处理 LLM 知识盲区时。

CL2GEC（Qin et al., 2025, P1）构建中文文学语法纠错的持续学习基准，旨在评估模型在多个学科领域顺序学习时的性能。数据集由从 CNKI 爬取的 10 个不同学科（如法律、医学、哲学）的语法错误学术句子组成，每个领域对应一个顺序任务。与典型 GEC 任务不同，CL2GEC 要求模型从每个领域顺序学习，并仅重放先前数据的一小部分，模拟真实世界中的存储和隐私限制。该基准旨在揭示模型在保持跨领域语法纠正性能时避免灾难性遗忘的能力，数据收集包括从 CNKI 随机采样 1000 个句子每个学科，形成平衡语料库，并提供标准划分，为持续学习场景下的 GEC 研究提供了新的评估视角。

Closest-Golds-Eval（P13）提出基于最近金标准（Closest Golds）的多语言 GEC 评估方法，旨在解决固定参考评估对 LLM 的不公平性。该方法通过直接纠正系统输出来构建最近金标准参考，该参考尽可能接近系统输出。与独立于系统输出创建的固定参考金标准不同，最近金标准直接量化系统输出中剩余的误差，并纳入系统提出的所有有效编辑。这种方法不惩罚固定参考中缺失的有效纠正，导致与系统提出的编辑更大的重叠。研究评估了 LLM 提示与监督模型在多种语言上的比较，发现标准参考评估下 LLM 表现不佳，但最近金标准评估提供了更现实的系统性能评估，为多语言 GEC 评估提供了更鲁棒的框架。

### 2.5 模型协同与教学反馈

模型协同与教学反馈路线的起源可追溯至 2020 年 GECToR 提出基于 Transformer 的序列到编辑架构，通过预测每个 token 的编辑操作而非生成整句，显著提升了纠错效率与精度，确立了编辑预测范式在 GEC 中的主导地位。随着 LLM 的引入，研究者开始探索大小模型协同机制以平衡精度与召回率，并将纠错应用于口语教学反馈生成等新兴教育应用场景。

ACI（P16）提出纠错器-验证器协作（ACI）框架，利用 LLM 和 BERT 基纠错器的互补优势解决开放域中文拼写纠正。在每次迭代中，BERT 基纠错器在单语数据上识别和纠正潜在错误，LLM 随后验证纠正并在需要时提供替代建议。生成的平行数据随后用于训练纠错器本身，形成自进化循环。ACI 通过挖掘语料库中的真实世界拼写错误，防止模型学习有偏的错误模式，并提供验证器识别的假阳性样本以缓解过度纠正问题。该方法迭代地利用 LLM 的知识来精炼 BERT 基模型，与直接 LLM 标注不同，它采用 BERT 基模型进行初始错误检测和纠正，随后进行 LLM 验证和反馈，展示了大小模型协同在数据增强和模型改进中的有效性，在 SIGHAN15 基准上取得了 47.3 的 F1 分数。

Post-Correction-LLM（Park et al., 2025, P4）提出利用 LLM 过度纠正特性的后纠正方法，旨在提高传统小语言模型（sLMs）在 GEC 中的召回率。研究发现，传统微调 sLMs 倾向于欠纠正，实现高精度但低召回率，而 LLMs 倾向于过度纠正，导致不可靠的编辑。该方法利用 LLMs 的过度纠正输出作为后处理步骤，通过提示 LLM 生成过度纠正的输出，然后与 sLMs 的输出结合或过滤，以平衡精度和召回率。它探讨了优化提示和思维链（CoT）技术在缓解 LLM 过度纠正中的作用，但精度仍是关键限制，揭示了 LLM 和 sLMs 在 GEC 任务中的不同偏差，并提出了利用这些偏差互补性的新策略，为教育场景中的纠错反馈提供了更全面的错误覆盖。

PFG（Liang et al., 2026, P9）提出口语教学反馈生成（PFG）框架，将 GEC 应用于口语语法纠错（SGEC）场景，生成包含纠错、解释和反馈的结构化输出。该方法采用两阶段训练范式，第一阶段进行偏好优化（DPO/KTO），利用偏好数据集对齐模型输出与期望行为，提高模型对高质量纠正和反馈的排序能力。第二阶段进行带 token 掩码的监督微调，在标记数据集上训练，其中 token 掩码策略用于处理结构化 JSON 格式的输出。模型输入包括源话语和熟练度水平，输出包括语法纠正句子和建设性教学反馈。该方法强调了反馈的忠实性、水平适应性、可操作性和鼓励性，填补了现有 SGEC 系统缺乏学习者面向反馈的空白，将 GEC 从单纯纠错扩展到教育支持，提升了系统的实用价值。

### 2.6 跨任务与多领域应用

跨任务与多领域应用涵盖了视觉、语音、法律、文学等多个场景，展示了 GEC/CSC 技术在特定领域的适应性。在视觉领域，ReViCo 揭示了 VLM 在图像拼写纠正上的局限性，推动了联合 OCR-纠正架构的发展。在语音领域，CoVoGER 和 Disfluency-Aware-LLM 分别针对 ASR 错误和不流利现象，提出了生成式纠错和对比学习方法，提升了口语转录的可读性。在法律领域，RoLegalGEC 和 RACQC 分别通过合成数据生成和 RAG 技术，解决了低资源语言特定领域 GEC 数据稀缺和 LLM 长尾实体幻觉问题。在文学领域，CL2GEC 构建了持续学习基准，评估模型在多个学科领域顺序学习时的性能，揭示了灾难性遗忘问题。在教育领域，PFG 将 GEC 应用于口语教学反馈生成，提升了系统的教育价值。这些应用展示了 GEC/CSC 技术从单一文本纠错向多模态、多领域、多场景拓展的趋势，反映了领域对真实世界复杂需求的响应。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

Seq2Seq 架构是 GEC 任务的主流范式，将纠错视为单语翻译任务能有效处理长距离依赖和复杂语法结构，这一共识在约 15 篇论文中得到共同支持。预训练语言模型（如 BERT、T5）显著提升了 GEC 性能，但需结合任务特定微调或辅助任务（如错误检测）以增强纠错能力，这一共识在约 12 篇论文中得到共同支持。LLM 在 GEC 任务中普遍存在过度纠正问题，需通过外部约束（如 RAG、RL 奖励）或后处理来平衡生成能力与忠实度，这一共识在约 10 篇论文中得到共同支持。合成数据生成是解决低资源语言 GEC 数据稀缺的有效途径，包括噪声注入、回译和 LLM 生成等多种策略，这一共识在约 8 篇论文中得到共同支持。多语言 GEC 研究正从单一语言向多语言扩展，但非英语语言仍面临数据和方法的双重挑战，需开发语言无关的通用纠错框架，这一共识在约 7 篇论文中得到共同支持。中文 CSC 与 GEC 常需联合处理，利用拼音、字形等多模态特征可显著提升纠错准确率，单一任务模型泛化能力有限，这一共识在约 6 篇论文中得到共同支持。评估 GEC 系统时，固定参考的局限性日益凸显，Closest Golds 和基于 LLM 的评估方法正成为更准确反映系统性能的新标准，这一共识在约 5 篇论文中得到共同支持。语音识别后的文本纠正（GER）与 GEC 紧密相关，需结合 ASR 假设列表和 LLM 推理能力，以处理转录错误和不流利度，这一共识在约 4 篇论文中得到共同支持。

### 3.2 观点分歧

解决 LLM 过度纠正的最佳路径存在内部对齐（RL/奖励模型）与外部约束（RAG/后处理）的分歧。观点 A 主张内部对齐，通过 RL 和编辑感知奖励模型直接优化策略，从根本上解决编辑边界问题，如 CSRP 和 EARM 所示。观点 B 主张外部约束，通过 RAG 注入外部知识或利用 sLM 后处理，弥补 LLM 知识盲区并平衡精度召回，如 RACQC 和 Post-Correction-LLM 所示。现有证据偏向内部对齐在细粒度编辑控制上更优，EARM 在 NaCGEC 上 F0.5 达 61.29，但 RAG 在长尾实体场景（如 MDCQC）中更具鲁棒性。证据强度中等，缺乏统一基准下的直接对比，测量工具盲区在于现有基准多聚焦通用语法错误，缺乏专门针对长尾实体与细粒度编辑混合场景的评测集，导致两种方法的优势场景难以量化比较。

评估标准的革新存在固定参考（F0.5）与动态参考（Closest Golds）的分歧。观点 A 主张固定参考，标准化程度高，便于横向比较，但惩罚 LLM 的合理多样性。观点 B 主张动态参考，更准确反映系统剩余错误，不惩罚有效纠正，但构建成本高且依赖 LLM 生成质量。证据偏向 Closest Golds 更能反映 LLM 真实能力，研究显示在 CGs 评估下 LLM 表现优于固定参考，证据强度较高，但限于少数多语言研究。场景依赖在于 CGs 的构建依赖 LLM 生成最近金标准，若 LLM 本身存在偏差，则评估结果可能失真，缺乏人工验证的大规模 CGs 基准。

低资源 GEC 的数据策略存在合成数据生成与跨语言迁移学习的分歧。观点 A 主张合成数据生成，利用 LLM/MT 生成错误句对，无需人工标注，通用性强，如 MTF 和 RoLegalGEC 所示。观点 B 主张跨语言迁移学习，利用高资源语言模型知识迁移，结合提示工程，减少数据依赖，如 Indic-GEC-Prompting 所示。证据偏向合成数据生成在低资源语言（如印地语、罗马尼亚语）上性能更稳定，但合成数据多样性不足可能导致过拟合，证据强度中等。证据不足在于缺乏对合成数据质量与模型性能关系的系统性研究，不同合成策略（噪声注入 vs. LLM 生成）的优劣未定论。

### 3.3 其他开放问题

最紧迫的工程问题是低资源语言合成数据的质量控制与多样性提升。当前合成数据生成策略（如 MTF、RoLegalGEC）虽解决了数据稀缺问题，但合成数据可能存在分布偏差，需复杂的清洗与质量控制流程。关键困难在于如何确保合成数据的多样性和真实性，研究路径包括基于维基百科修订历史、混淆集生成及人工验证过滤。最根本的研究问题是视觉-文本对齐在拼写纠正中的机制不明。现有 VLM 在图像文本纠错上表现远逊于人类，主要受限于 OCR 错误传播和视觉-文本对齐瓶颈，关键困难在于如何融合视觉上下文与语言知识，研究路径包括联合 OCR-纠正架构、背景增强提示及多模态推理机制。持续学习中的灾难性遗忘缺乏通用解决方案，CL2GEC 基准揭示了模型在多个学科领域顺序学习时的性能退化，关键困难在于不同领域错误分布的差异和知识保留，研究路径包括正则化方法（EWC）、投影方法（GEM）及回放策略。

已知—争议—未知认知图谱显示，领域在 Seq2Seq 范式、PLM 提升性能、合成数据有效性等方面达成共识，但在 LLM 过度纠正解决路径、评估标准革新、低资源数据策略等方面存在争议，在视觉-文本对齐机制、持续学习通用解决方案、合成数据质量控制等方面仍属未知。发展趋势是从单一文本纠错向多模态、多语言、多领域场景拓展，从静态模型向持续学习系统转型，核心在于平衡生成多样性与编辑最小性，实现跨语言、跨模态及多领域场景下的鲁棒纠错。

## 4. 总结与展望

GEC/CSC 领域已跨越单纯的技术性能竞争，进入以“忠实度”为核心、多模态与多语言为边界的精细化对齐阶段。核心矛盾在于如何在保持文本语义忠实度与最小编辑原则的前提下，利用生成式模型的强大能力实现跨语言、跨模态及多领域场景下的鲁棒纠错。早期 Seq2Seq 范式解决了长距离依赖问题，但引入了幻觉风险；PLM 阶段提升了特征表示质量，但面临低资源数据稀缺；LLM 阶段引入了生成能力，但带来了过度纠正问题。当前研究通过 RL 对齐、RAG 约束、合成数据生成等路线，试图在精度、召回率及计算成本间做出不同取舍，但核心瓶颈仍在于如何显式优化最小编辑原则，并拓展至多模态及持续学习场景。

未来可能突破的方向包括：基于 RL 的细粒度编辑控制，通过编辑感知奖励模型（如 EARM）和组相对策略优化（如 CSRP），显式优化编辑效率，缓解 LLM 的过度纠正偏差，这一方向由 P12 和 P18 共同指向；多模态联合纠错，通过联合 OCR-纠正架构和背景增强提示，利用视觉上下文辅助纠错，解决纯文本模型无法处理的图像拼写错误，这一方向由 P3 和 P19 共同指向；持续学习与领域自适应，通过正则化方法、投影方法及回放策略，避免灾难性遗忘，实现多领域 GEC 模型的持续适应，这一方向由 P1 和 P17 共同指向。对于进入者最值得做的一件事，是在统一骨干与统一预训练条件下，构建专门针对长尾实体与细粒度编辑混合场景的评测集，以量化比较内部对齐（RL）与外部约束（RAG）在不同场景下的优势，从而为 LLM 纠错系统的忠实度优化提供明确的实验依据。
