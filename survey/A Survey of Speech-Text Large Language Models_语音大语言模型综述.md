## 导读

语音大语言模型（Speech LLMs）旨在将文本大语言模型的推理能力无缝迁移至语音模态，其核心挑战在于解决语音信号的高冗余性与文本语义的稀疏性之间的表示错位。早期研究依赖级联架构，虽保留了文本推理能力，但高延迟与副语言信息丢失的固有缺陷限制了交互的自然度。随着端到端范式的兴起，语音编码器与模态适配器的结合成为主流，然而模态对齐并未消除推理退化，语音输入下的逻辑追踪能力仍显著低于文本。为应对这一瓶颈，研究重心转向跨模态蒸馏、思维链机制及非自回归生成，试图在保留文本知识的同时提升语音交互的深度与实时性。各路线在表示质量、推理深度与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从信号转写到认知对齐的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

语音大语言模型的兴起源于对自然语音交互的迫切需求，其核心目标是将文本大语言模型强大的推理与知识泛化能力扩展至语音模态。早期研究基于“语音是文本的声学载体”这一简化假设，认为通过高精度的自动语音识别（ASR）即可将语音转化为文本，进而利用文本模型进行理解与生成。这种级联架构（Cascaded Pipeline）由 ASR、文本大语言模型和语音合成（TTS）串联组成，虽然技术成熟且稳定，但存在两个固有缺陷：一是延迟高，多模块串联导致响应缓慢；二是信息丢失，ASR 仅保留语义内容，丢弃了情感、语调等副语言线索（Paralinguistic Cues），导致模型无法捕捉用户真实意图。

随着 GPT-4o 等端到端模型的发布，研究范式发生关键转折，从级联转向端到端架构（End-to-End Speech LLM）。端到端架构通过语音编码器（Speech Encoder）与模态适配器（Modality Adapter）直接对齐语音与文本嵌入空间，旨在减少延迟并保留副语言信息。然而，这一转变引入了新的核心问题：模态差距（Modality Gap）。研究发现，即使模态对齐良好，语音输入下的模型性能（尤其是复杂推理能力）仍显著低于文本输入。这一现象被称为“模态推理差距”（Modality Reasoning Gap），其根源在于语音表示的连续性和冗余性干扰了大语言模型内部的语义绑定与逻辑追踪。

问题定义因此从“如何听得懂”演变为“如何想得深”。早期关注识别准确率，中期关注模态对齐精度，当前则聚焦于推理保持与灾难性遗忘（Catastrophic Forgetting）。灾难性遗忘指在将文本大语言模型适配为语音模型过程中，原有文本知识和推理能力发生退化的现象。子问题间存在强依赖关系：模态对齐是基础，若无法将声学特征有效映射至文本嵌入空间，后续的推理保持无从谈起；推理保持是核心瓶颈，制约了模型在复杂任务上的上限；高效部署则是工程约束，决定了前两者能否落地。

2016-2018 年，少样本学习与度量学习奠定了基础，但语音领域主要依赖级联架构。2020 年，跨域基准暴露出域偏移下的原型崩溃问题，促使研究者探索更鲁棒的表示。2023 年，SALMONN 和 SpeechGPT 确立了“编码器+适配器+大语言模型”的端到端基线，打破了级联垄断。2024 年，Qwen2-Audio 和 Moshi 进一步推动了多模态统一与全双工交互。2025 年，SALAD 和 SHANKS 的出现标志着研究重心从“能否对齐”转向“如何保持推理”，解决了模态不等价导致的性能瓶颈。2026 年，X-OPD 和 DiffuSpeech 引入了在线策略蒸馏和非自回归生成，试图在实时性与推理深度间找到新平衡。

**如果用一个核心问题概括该领域，那便是：如何在将离散、高冗余的声学信号融入连续、稀疏的文本语义空间时，最小化模态引入的表示干扰，从而保留并增强大语言模型固有的逻辑推理与知识泛化能力？**

## 2. 方法体系

- 2021：GSLM——提出生成式口语语言建模任务，奠定离散化建模基础

- 2023：SALMONN——采用窗口级Q-Former作为模态适配器，实现语音与文本模态的高效对齐

- 2023：SpeechGPT——通过渐进式训练策略将LLM适配至量化语音token，实现语音理解与生成的统一

- 2024：Moshi——提出全双工多流模型，实现低延迟的实时语音对话

- 2025：SALAD——提出两阶段对齐框架，解决语音输入下的知识遗忘和模态不等价问题

- 2025：SHANKS——提出边听边想框架，允许模型在用户说话过程中生成未说出的思维链推理

- 2026：X-OPD——提出跨模态在线策略蒸馏框架，缓解传统离线蒸馏导致的性能退化问题

- 2026：DiffuSpeech——提出统一语音-文本扩散模型，实现“静默思考，口语回答”范式

这条时间线勾勒了该领域方法演进的代表性节点：从 2021 年的 GSLM 奠定该领域方法基线，经 2023 年 SALMONN 的推进，到 2026 年的 X-OPD 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 跨模态对齐机制

跨模态对齐机制旨在解决语音与文本表征的深层对齐问题，缩小模态鸿沟。早期工作如 SALMONN（2023）采用窗口级 Q-Former 作为模态适配器，将语音特征投影至大语言模型潜在空间，并引入行为对齐机制以缓解任务过拟合，成为后续研究的重要基线。然而，简单适配器无法解决深层语义绑定问题，导致语音输入下逻辑推理错误频发。SALAD（Cuervo et al., 2025, P10）针对这一问题，提出两阶段对齐框架：第一阶段在自然语音上执行蒸馏，通过最小化学生模型与教师模型之间的 KL 散度实现模态对齐；第二阶段通过主动选择策略引入少量合成语音，利用模型自身的失配信号指导数据增强，以扩展领域覆盖并解决残余失配。该方法将对齐过程分解为全局蒸馏和局部增强，避免了大规模合成数据带来的分布偏移，其代价是依赖教师模型的质量，且主动选择过程增加了数据筛选的计算复杂度。

X-OPD（Cao et al., 2026, P21）进一步提出跨模态在线策略蒸馏框架，利用文本和语音双通道从文本教师模型向语音学生模型转移知识。其核心创新在于采用在线策略优化而非传统的离线知识蒸馏，通过引入策略梯度，模型在生成过程中动态调整输出分布，以匹配教师模型的行为，从而缓解离线蒸馏中常见的分布外泛化问题。X-OPD 特别设计了混合损失函数，平衡文本和语音通道的蒸馏信号，确保模型在保持文本推理能力的同时提升语音理解性能。其代价是训练过程比离线蒸馏更复杂，需要维护教师模型的在线推理能力。TextPro-SLM（Cui et al., 2026, P25）则从输入端最小化模态差距，将语音输入显式分离为语义内容和韵律特征两个互补方面，分别进行处理后再融合，强调输入表征的精细化处理对缩小模态差距的重要性。AuRA（Cheng et al., 2026, P31）采用蒸馏式适配框架，利用预训练的 ASR 编码器作为教师，通过知识蒸馏将声学特征映射到大语言模型的潜在空间，同时使用 LoRA 微调大语言模型以适配语音输入，保持大语言模型骨干冻结，仅更新低秩适配器参数，从而大幅降低训练成本并避免灾难性遗忘。TASU2（Peng et al., 2026, P22）提出可控 CTC 模拟框架，通过自回归模拟器从转录文本中随机模拟 CTC 后验概率，实现无需配对音频数据的文本-only 后训练，显著降低了语音大语言模型训练对大规模配对音频数据的依赖。

### 2.2 语音推理与思维链

语音推理与思维链机制旨在提升语音大语言模型在复杂任务中的推理能力，引入思维链（Chain-of-Thought, CoT）机制。SHANKS（Chiang et al., 2025, P7）提出边听边想（Simultaneous Hearing and Thinking）框架，使语音语言模型能够在用户说话过程中生成未说出的思维链推理。该方法通过分块输入语音，利用熵基选择机制确定思考触发点，使模型在接收到完整输入前即可开始推理，从而显著降低响应延迟。SHANKS 的核心在于将思考过程与听力过程解耦，允许模型在后台进行复杂的逻辑推理，同时保持对用户输入的实时响应。其代价是引入了额外的思考 token 生成开销，且触发点的选择需要精细调优以避免过早或过晚思考。

DiffuSpeech（Lou et al., 2026, P18）提出统一语音-文本扩散模型，实现“静默思考，口语回答”范式。该方法利用掩码扩散语言模型（MDLM）并行生成内部推理文本和口语响应，突破了传统自回归模型在并行解码和双向上下文利用上的限制。DiffuSpeech 的核心创新在于将推理过程建模为去噪任务，允许模型在生成语音的同时进行复杂的逻辑推理，且推理过程对用户不可见。其代价是扩散模型的训练和推理速度通常慢于自回归模型，且需要大量的计算资源。REVERT（Woo et al., 2025, P3）提出将复杂思维转化为可理解语音的框架，旨在解决推理模型生成的长思维链难以在语音交互中传达的问题。该方法通过监督微调训练模型将内部推理过程重构为简洁、自然的口语表达，同时保留关键的推理步骤。Entity Binding Intervention（Hsu et al., 2026, P29）提出针对语音大语言模型中实体绑定失败的诊断与思维链干预方法，通过机制可解释性技术识别语音编码中导致实体追踪失败的特定层和神经元，并引入思维链提示以增强模型对实体-属性关联的追踪能力。

### 2.3 语音生成与合成

语音生成与合成技术聚焦于基于大语言模型的语音合成（TTS），包括零样本克隆、流式合成及可控生成。MOSS-Speech（Zhao et al., 2025, P5）提出真正的语音到语音大语言模型，无需文本引导即可直接理解和生成语音。该方法采用基于模态的层分割架构，将 Transformer 层分为语音特定层和共享层，并在预训练阶段冻结文本大语言模型权重，仅训练语音相关模块。MOSS-Speech 的核心在于通过层分割实现语音和文本模态的深度解耦，同时利用冻结策略保留预训练文本大语言模型的推理和知识能力。VocalNet-M2（Wang et al., 2025, P12）提出集成多码本 token 化和多 token 预测的低延迟口语语言模型。该方法采用 Thinker-Talker 架构，Thinker 负责生成文本 token 和隐藏状态，Talker 则基于多码本音频 token 进行自回归语音生成。VocalNet-M2 的核心创新在于利用 XY-Tokenizer 提取八个码本的音频 token，并通过多 token 预测技术并行生成多个语音 token，显著降低了推理延迟。EchoX（Zhang et al., 2025, P1）提出通过回声训练缓解声学-语义差距的语音到语音大语言模型框架。该方法采用三阶段训练策略，通过回声机制让模型在生成语音时参考其自身的文本输出，从而增强声学特征与语义内容的一致性。SAC（Chen et al., 2025, P11）提出具有语义-声学双流量化的神经语音 codec，旨在平衡语义一致性和声学保真度。该方法基于 VQ-GAN 框架，包含双流编码器-量化器和统一 codec 解码器，语义流使用预训练语义 tokenizer 保持语义一致性，声学流则捕获细粒度声学细节。

### 2.4 多模态统一架构

多模态统一架构旨在构建支持语音、文本、图像等多模态输入输出的统一大模型。MoST（Lou et al., 2026, P17）构建基于混合专家（MoE）架构的统一语音-文本基础模型，实现无缝的语音和文本处理。该方法引入模态感知混合专家（MAMoE）机制，在指定层中将 token 路由至模态特定专家和共享专家，促进跨模态交互。MoST 的核心在于利用 MoE 架构的稀疏激活特性，高效处理连续音频波形和离散文本序列，同时保持模型的可扩展性。Latent Speech-Text Transformer（Lu et al., 2025, P6）提出潜在空间中的语音-文本联合建模方法，通过 patching 策略解决语音 token 序列过长的问题。该方法探索了静态、对齐、混合和课程四种 patching 策略，将多个语音 token 合并为单个 patch，以减少序列长度并提高计算效率。Hearing-to-Translate（Papi et al., 2025, P15）提出评估语音模态集成到大语言模型中有效性的框架，重点研究语音翻译任务。该方法比较了级联架构和直接架构在语音翻译中的表现，并分析了性别偏见等社会因素对翻译结果的影响。CSLM（Zhou et al., 2026, P23）提出高效的跨语言语音语言模型训练方法，旨在解决多语言语音建模中的数据不平衡和计算成本问题。该方法采用离散语音 token 化技术，将语音转换为语义和声学 token，并通过联合建模语音和文本 token 实现跨语言理解。

### 2.5 语音理解与评估

语音理解与评估旨在开发针对语音大模型的基准测试与评估方法，涵盖情感识别、副语言理解、多语言能力及鲁棒性分析。FMSU-Bench（Li et al., 2026, P26）构建细粒度多维语音理解基准，旨在评估语音大语言模型在复杂特征解耦和多维感知上的能力。该基准涵盖微声学线索、声学场景、情感、语气和上下文推断等多个维度，通过渐进式课程微调训练 FM-Speech 模型。PolySpeech-100（Yang et al., 2026, P28）构建覆盖 100 多种语言和方言的大规模语音理解基准，旨在评估语音大语言模型在复杂真实世界语言场景下的能力。该基准结合人工录音金标准和合成数据，涵盖多种语言、方言和代码切换场景，解决了现有基准在长尾语言覆盖上的不足。SpeechParaling-Bench（Liu et al., 2026, P24）构建副语言感知语音生成基准，旨在评估 LALM 在生成具有特定情感、语气和风格语音方面的能力。该基准包含 1001 个样本，涵盖 13 个维度和 104 个特征，通过对比生成音频与目标文本的副语言属性进行评估。SpeechEQ（Wu et al., 2026, P32）构建评估社会感知语音对话模型情感智商（EQ）的基准，旨在超越传统的情感识别分类任务。该基准基于 EQ-i 2.0 框架，通过两轮强制选择任务评估模型在主动社交场景中的情感共鸣和持续情感理解能力。

### 2.6 高效训练与部署

高效训练与部署旨在优化语音大模型的训练效率与推理速度，包括参数高效微调（PEFT）、模型压缩、流式推理及低资源适应。FastSLM（Lee et al., 2026, P16）提出层级帧 Q-Former 用于有效的语音模态适配，旨在解决语音序列过长导致的计算开销问题。该方法引入专门的压缩瓶颈，将密集的声学特征蒸馏为高度紧凑的语义 token，实现约 1.67 token/秒的极端压缩率。SPAR-K（Huang et al., 2026, P20）提出调度周期性交替早期退出框架，用于加速交错式口语语言模型的推理。该方法引入语音交替深度调度，大多数语音位置在固定中间层退出，而周期性全深度“刷新”步骤缓解早期退出导致的分布偏移。VoxServe（Kamahori et al., 2026, P19）提出流式中心服务系统，旨在优化语音语言模型在流式设置下的低延迟和高吞吐量。该方法引入模型执行抽象，解耦模型架构与系统级优化，支持多种 SpeechLM 架构在单一框架内运行。Streaming Speech-to-Text Translation（Parcollet et al., 2026, P27）提出基于 SpeechLLM 的流式语音到文本翻译方法，旨在解决现有系统在流式处理中的延迟和准确性问题。该方法采用交错模型架构，将输出 token 与等待 token 交错，输入 token 与语音 token 交错，并通过早期退出等待策略减少计算。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

端到端架构在保留副语言信息和降低延迟方面优于级联架构，但需解决模态对齐带来的推理退化问题，这一共识在多个基准上被反复验证：X-OPD 的 82.4% 与 TextPro-SLM 的 81.1% 均大幅超越级联基线，表明端到端范式在推理任务上的优越性。与此相关的另一个共识是，语音编码器与轻量级适配器结合是当前构建语音大语言模型的主流范式，能够有效将声学特征映射至大语言模型嵌入空间，SALAD 和 AuRA 在 LibriSpeech 上的 2.5% 和 2.3% WER 均优于传统 ASR 系统，验证了这一范式的鲁棒性。然而，该共识的边界在于，简单适配器无法解决深层语义绑定问题，导致语音输入下逻辑推理错误频发，需通过更精细的对齐策略来修复。

### 3.2 观点分歧

解决模态差距的最佳路径存在输入端对齐与输出端推理重构的分歧。观点 A 主张通过精细的声学-语义解耦和跨模态蒸馏在输入端消除差距，如 TextPro-SLM 和 SALAD；观点 B 主张通过引入显式思维链和在线策略优化在输出端修复推理路径，如 SHANKS 和 X-OPD。现有证据偏向观点 A 在基础任务（ASR, QA）上的稳定性，但观点 B 在复杂推理任务（MMSU, VoiceBench）上表现更优，X-OPD 在 VoiceBench 上达到 82.4% Acc，略高于 TextPro-SLM 的 81.1%，表明在线策略优化在推理任务上更有效。这一分歧的背后，是另一个更根本的争论：语音生成的范式是自回归还是非自回归/扩散。观点 A 认为自回归生成能更好地捕捉长距离依赖和语义一致性，如 MOSS-Speech；观点 B 认为非自回归或扩散模型能实现并行解码，显著降低延迟，如 DiffuSpeech 和 VocalNet-M2。在 Emilia TTS 基准上，VocalNet-M2（4.35 MOS）略高于 MOSS-Speech（4.20 MOS），且延迟更低，但在长文本生成的连贯性上，自回归模型仍有优势。

### 3.3 其他开放问题

当前最紧迫的工程问题集中在高效部署，包括流式推理的延迟优化和边缘设备上的模型压缩。FastSLM 和 VoxServe 通过令牌压缩和流式感知调度，显著提升了推理效率，但早期退出机制可能影响长距离依赖的捕捉，需进一步研究。最根本的研究问题在于如何在不牺牲文本能力的前提下，让模型真正“理解”而非“转写”副语言信息。现有模型仍依赖文本大语言模型的“骨架”，真正的“语音原生”推理机制尚未建立。未来需突破“语音即文本”的认知局限，建立原生的语音认知模型，结合跨模态知识蒸馏、参数重要性分析下的分层学习率调度，以及基于 LoRA 的轻量级适配，以保留文本骨干能力。

## 4. 总结与展望

语音大语言模型的发展是从“信号处理”向“认知科学”跨越的过程，核心任务始终是解决模态间的表示错位。早期研究基于“语音是文本的噪声版本”这一简化假设，导致级联架构成为主流；然而，随着对副语言信息重要性的认识加深，问题结构从“信号转写”演变为“认知对齐”，揭示了模态间深层的语义绑定差异。当前领域正从“模态对齐”向“推理保持”和“高效部署”双轮驱动发展，核心瓶颈在于如何在保留文本推理能力的前提下，实现低延迟、高自然度的语音交互。

未来可能突破的方向包括：一是解决语音-文本模态差距与灾难性遗忘，通过跨模态知识蒸馏和参数重要性分析下的分层学习率调度，保留文本骨干能力；二是实现低延迟流式语音交互与实时推理，通过多 token 预测、非自回归生成及早期退出机制，平衡延迟与准确性；三是增强语音情感与副语言信息的理解与生成，通过基于音素级韵律增强的提示工程和多任务强化学习，显式建模情感推理。对于进入者而言，最值得做的一件事是构建一个能同时评估对齐精度和推理深度的综合基准，以解决现有基准碎片化、缺乏对副语言和多说话人维度统一评估的问题，为模型能力的全面衡量提供标准。
