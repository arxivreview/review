## 导读

交通信号控制（Traffic Signal Control, TSC）旨在通过动态调整信号相位与时长来缓解城市拥堵，其核心挑战在于平衡实时决策效率与复杂环境下的泛化鲁棒性。早期研究依赖固定配时或简单感应逻辑，难以应对非平稳交通流，深度强化学习（DRL）的引入实现了从规则驱动到数据驱动的范式转变。随着路网规模扩大，单路口优化逐渐暴露出局部最优导致的网络级拥堵传播问题，促使研究者引入图神经网络（GNN）与多智能体强化学习（MARL）以捕捉空间依赖。当分布偏移与黑盒不可解释性成为部署瓶颈后，大语言模型（LLM）与物理信息融合技术开始介入，试图在实时性与可审计性之间寻找新的平衡点。当前领域正处于从单一效率优化向安全、公平及可解释综合决策系统演进的过渡期，各技术路线在计算成本、泛化能力与工程可行性之间做出了截然不同的取舍。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

交通信号控制领域的兴起源于传统控制方法在动态交通环境下的失效。固定配时方案基于历史平均流量设计，无法响应实时需求波动；感应控制虽能根据车辆存在调整绿灯时长，但缺乏对路网整体状态的感知，易导致下游拥堵。Webster 公式等经验法则虽在特定条件下有效，但其假设交通流平稳且独立，难以处理混合交通流（CAV 与 HDV 共存）带来的高维状态空间与随机性。这种局限性促使研究者将交通信号控制建模为马尔可夫决策过程（MDP），利用强化学习（RL）从交互数据中直接学习最优策略，从而摆脱对精确交通流模型的依赖。

问题形式化通常采用 N-way K-shot 类似的稀疏观测设定，但在 TSC 中更具体地表现为：在路网拓扑 $\mathcal{G}=(\mathcal{V}, \mathcal{E})$ 中，每个路口 $i \in \mathcal{V}$ 作为一个智能体，观测局部状态 $s_i$（如排队长度、等待时间），执行动作 $a_i$（相位选择或绿灯时长），以最小化全局平均旅行时间（ATT）或平均排队长度（AQL）。这一形式化隐含了子问题的层级依赖关系：网络级协同是基础架构，解决局部最优导致的拥堵传播；分布偏移应对是泛化前提，确保模型在未见过的交通需求下有效；可解释性与安全性是部署门槛，满足交通工程审计与公众信任需求。若不解决网络协同，单点优化无法提升全局效率；若不解决分布偏移，模型无法适应真实动态环境；若不解决可解释性，模型无法通过工程验收。

2018 至 2019 年是该领域的奠基期，核心突破在于证明 DRL 在单路口及小规模路网中优于传统方法。IntelliLight 基于深度 Q 网络（DQN）实现了单路口自适应控制，确立了 RL 在 TSC 中的基础地位。随后，PressLight 引入 Max Pressure 控制理论，通过压力平衡机制实现了多路口网络级协同，理论上保证了吞吐量最优。CoLight 进一步引入图注意力网络（GAT），通过建模路口间的空间依赖关系，突破了传统 MARL 中局部观测的局限，显著提升了大规模路网的控制性能。这一阶段的方法假设交通流在静态路网中可通过局部观测进行马尔可夫决策，旨在解决单路口延误最小化问题，但忽略了路口间复杂的空间耦合与动态分布偏移。

2020 至 2022 年，研究重心转向应对分布偏移与跨场景泛化。静态模型在交通需求剧烈变化（如早晚高峰切换）时性能显著下降，MetaLight 基于元强化学习（Meta-RL）框架，利用现有场景的知识加速新场景下的学习过程，增强了模型对未知交通模式的泛化能力。这一时期的方法开始意识到，仅靠增加网络规模或优化奖励函数不足以解决泛化问题，必须引入对数据分布变化的适应性机制。同时，MPLight 等元学习方法进一步验证了元学习在 TSC 中的有效性，为应对现实世界中动态变化的交通需求提供了重要思路。

2023 至 2026 年，领域进入“神经符号”混合阶段，焦点转向鲁棒性、可解释性及 LLM 的融合。随着 LLM 技术的爆发，研究者试图结合 RL 的实时决策能力与 LLM 的逻辑推理及常识判断，以应对紧急车辆优先、异构路口等长尾场景。EvolveSignal 将固定配时控制形式化为程序合成问题，通过 LLM 生成可解释的启发式策略，解决了传统 RL 策略黑盒且难以审计的问题。CFLight 引入反事实学习，通过构建结构因果模型（SCM）生成反事实轨迹，增强了系统在极端场景下的安全性。这一阶段的方法不再单纯追求效率指标的提升，而是将安全性、公平性及可解释性纳入核心优化目标，反映了交通系统复杂性的认知深化。

当前，该领域处于高度活跃期，方法体系呈现出多元化并存格局。纯 RL 路线（如 GAT/MARL）在效率上仍具优势，但面临可解释性挑战；LLM 融合路线在可解释性与长尾场景处理上表现突出，但受限于推理延迟与数值精度；混合交通协同路线则试图在 CAV 与 HDV 共存环境下实现安全与效率的平衡。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。

**如果用一个核心问题概括该领域，那便是：如何在保证安全约束与可解释性的前提下，构建能够适应动态分布偏移并实现大规模路网全局协同优化的交通信号控制策略。**

## 2. 方法体系

- 2018：IntelliLight——基于 DQN 的单路口控制奠基

- 2019：CoLight——引入 GAT 实现网络级协同

- 2020：MetaLight——元学习应对分布偏移

- 2024：LLMLight——LLM 引入交通控制

- 2025：SEMI-CTDE——半集中训练分散执行架构

- 2025：EvolveSignal——LLM 代码合成可解释策略

- 2026：Spatiotemporal Decision Transformer——时空联合建模前沿

- 2026：CFLight——反事实学习增强安全性

这条时间线勾勒了该领域方法演进的代表性节点：从 2018 年的 IntelliLight 奠定该领域方法基线，经 2019 年 CoLight 的推进，到 2026 年的 Spatiotemporal Decision Transformer 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 信号灯控制算法

信号灯控制算法是该领域的基石，其演进主线是从单路口独立优化向多路口网络级协同，再向灵活的目标导向决策转变。早期工作如 IntelliLight 基于 DQN 实现单路口控制，假设交通流在静态路网中可通过局部观测进行马尔可夫决策，旨在解决单路口延误最小化问题，但忽略了路口间空间依赖。CoLight 针对这一局限，引入 GAT 建模路口间空间依赖，通过注意力机制动态关注相关邻居，实现了网络级协同，显著降低了全局延误，但增加了模型复杂度与通信开销。

随着路网规模扩大，集中式 GAT 在数百路口网络中计算复杂度爆炸，无法满足实时部署需求。SEMI-CTDE（Rezaali et al., 2025, P9）提出半集中训练、分散执行架构，利用模糊图 Alpha-cut 算法根据交通动态依赖性将路网划分为多个区域。该方法在训练阶段共享全局奖励信号以学习协同策略，在执行阶段各路口独立决策以降低通信延迟。这种设计平衡了全局最优性与实时部署需求，有效缓解了大规模路网中状态空间爆炸问题，但区域划分可能引入次优解，需平衡全局最优与局部实时性。

近期，Spatiotemporal Decision Transformer（MADT, Su et al., 2026, P13）将决策 Transformer 架构扩展至多智能体 TSC，融合 GAT 以捕获空间依赖。其核心创新在于引入 return-to-go 条件机制，允许在测试时通过指定期望回报值来灵活调整优化目标，如权衡通行效率与延误。这种设计突破了传统 RL 中奖励函数固定的限制，使同一模型能适配不同的运营需求，代表了序列建模在交通控制中的最新进展。CoordLight（Zhang et al., 2026, P16）则提出基于去中心化协调的方法，利用多头注意力机制聚合邻居状态信息，在保持计算效率的同时显著提升了网络级交通流的协调性。

### 2.2 大模型融合控制

大模型融合控制路线旨在解决传统 RL 策略黑盒不可审计及长尾场景推理能力不足的问题。LLMLight 作为先驱工作，利用 LLM 的自然语言推理能力处理结构化交通状态，开启了可解释性交通控制的新方向，但存在推理延迟和可靠性挑战。EvolveSignal（Wang et al., 2025, P2）将固定配时控制形式化为程序合成问题，通过 LLM 生成人类可读的代码逻辑，利用进化算法迭代优化候选程序。该方法解决了传统 RL 策略不可解释、难以通过安全认证的问题，特别适用于对安全性要求极高的交通基础设施，但生成策略的性能上限受限于进化搜索空间。

DGLight（Yu, 2026, P19）提出两阶段 RL 流水线，利用 DQN 引导的 GRPO 微调 LLM。第一阶段训练基于 CoLight 的 DQN 评论家网络，提供密集的价值信号；第二阶段冻结该评论家网络，在 LLM 生成候选响应时进行评分，并将评分作为奖励信号用于 GRPO 策略优化。这种设计利用了 RL 模型在数值计算和价值评估上的优势，弥补了 LLM 在精确数值推理上的不足，实现了两种范式的互补。CuraLight（Guo et al., 2026, P17）则通过辩论引导的数据策展方法，利用 LLM 的自我反思和对抗机制，自动发现潜在的控制缺陷并优化数据分布，提升了模型在复杂异构路口上的决策能力。

ReasonLight（Pang et al., 2026, P20）结合视觉输入和结构化状态，利用多模态 LLM 作为可复用骨干网络进行推理，实现零样本交通信号控制。其核心创新在于利用视觉语义补充传感器数据的不足，提供更具上下文的决策依据，特别是在长尾事件和观测噪声场景下。通过回退机制，当 LLM 输出无效时自动切换至 RL 决策，确保了系统的可靠性。该路线与纯 RL 路线形成互补：LLM 提供常识推理与可解释性，RL 提供实时数值优化，但集成面临延迟与幻觉控制的挑战。

### 2.3 混合交通协同

混合交通协同路线聚焦于 CAV 与 HDV 共存环境下的安全与效率平衡。HONEST-CAV（Zhang et al., 2026, P14）提出分层优化网络信号与轨迹的 MARL 框架，采用 CTDE 范式协调 CAV 与信号控制。该方法将信号控制与车辆轨迹规划联合优化，打破了传统方法中两者独立设计的局限，通过异步多进程训练加速收敛，为混合交通环境下的高效协同提供了系统性解决方案。

Multi-Objective RL for Large-Scale Mixed Traffic（Islam and Li, 2025, P12）提出分层控制框架，整合多目标 RL 以优化大规模混合交通环境中的机器人车辆决策。该方法包含控制层和路由层，控制层通过 DRL 学习多目标决策，平衡安全性、公平性和效率；路由层通过轻量级覆盖感知协调过程，主动调节网络级 RV 分布。其核心创新在于将局部交互决策与全局网络平衡相结合，解决了传统方法中低需求车道被“饿死”的公平性问题。

Offline MARL with Physics-Informed World Model（Liu et al., 2026, P22）提出基于物理信息世界模型的离线 MARL 框架，利用离线交互数据训练交通世界模型，集成交通流物理先验和认知不确定性。在第二阶段，利用世界模型进行想象展开，生成额外的虚拟轨迹以优化协同控制策略。这种方法降低了对在线交互数据的依赖，使得在真实交通环境中部署 CAV 协同控制更加可行和安全，为离线 RL 在交通领域的应用提供了新范式。

### 2.4 网络级交通管控

网络级交通管控路线关注宏观层面的拥堵缓解与能耗优化，采用分层架构或物理信息模型。Adaptive Tuning of Parameterized Traffic Controllers（Önür et al., 2025, P10）提出基于 MARL 的参数化交通控制器自适应调优框架，上层 RL 智能体在较慢时间尺度上调整下层状态反馈控制器的参数，下层控制器在较快时间尺度上响应交通状态变化。这种方法结合了 RL 的自适应性与传统控制器的实时性和稳定性，适用于匝道控制、可变限速等需要快速响应的场景。

Sharing Control Authority Between DRL and MPC（Onur et al., 2026, P24）提出在 DRL 与模型预测控制（MPC）之间共享控制权限的框架。该方法利用 MPC 处理约束和长期目标优化，利用 DRL 处理模型不确定性和动态适应，通过动态分配控制权限来结合两者优势。这种设计解决了 MPC 对模型准确性依赖高、DRL 缺乏显式约束保证的问题，提升了系统在复杂动态环境下的可靠性和性能。

Learning Dynamics Feature Representation via Policy Attention（ICLR 2026, P26）提出基于策略注意力的动态特征表示学习方法，用于城市路网的动态路径规划。该方法将动态路径规划建模为 MDP，通过策略注意力机制，智能体能够根据当前决策需求，动态关注路网中不同区域的动态特征。其核心创新在于将特征表示学习与策略学习联合优化，使状态表示能够适应策略的推理需求，提升了在部分可观测环境下的规划能力。

### 2.5 安全与鲁棒性

安全与鲁棒性路线关注交通控制中的安全性约束、鲁棒性验证及可解释性。CFLight（Li et al., 2025, P11）提出基于反事实学习的安全交通信号控制方法，通过集成 SCM 增强 RL 的安全性。该方法构建 SCM 模型以模拟交通系统的潜在结果，生成反事实轨迹，在训练过程中利用这些反事实轨迹作为额外的安全相关经验，引导智能体学习避免高风险决策。这种方法解决了传统 RL 奖励函数难以显式惩罚罕见但严重事故的问题，提升了系统在极端场景下的鲁棒性。

Biased-Attention Guided Risk Prediction（Dong and Guo, 2025, P5）提出基于偏差注意力引导的风险预测方法，用于无信号路口的安全决策。该方法利用偏差注意力机制，使智能体能够聚焦于高风险车辆和潜在冲突点，忽略无关背景信息，从而提升风险预测的准确性。C2T（Chen et al., 2026, P18）提出基于字幕结构和 LLM 对齐常识奖励学习的方法，利用 LLM 作为评判者，评估不同控制策略的合理性和安全性，将人类常识转化为可量化的奖励信号，弥补了传统手工奖励函数在捕捉网络级动态和舒适性方面的不足。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域最核心的共识在于 RL 方法在仿真中普遍优于传统固定配时和感应控制方法。这一共识在多个基准上被反复验证：PPO (IoT-Enabled) 的 27.22 s/veh 大幅优于 Webster Method 的 50.69 s/veh，CoordLight 的 1.4 stops/trip 优于 CoLight 的 1.9 stops/trip。然而，该共识的边界在于仿真环境与真实世界之间的差距，RL 策略在真实部署中的性能尚未得到充分验证。与此相关的另一个共识是，MARL 是解决大规模路网协调问题的主流范式，其中 CTDE 架构被广泛采用。SEMI-CTDE、HONEST-CAV 等方法均基于 CTDE 框架，通过集中训练去中心化执行平衡全局最优与实时部署需求。这一共识源于单路口独立优化在密集路网中导致“绿波”失效、全局吞吐量未提升的失败案例，促使研究者引入图结构建模空间依赖。

### 3.2 观点分歧

LLM 在 TSC 中的角色定位是领域核心分歧之一。观点 A（LLMLight, ReasonLight）认为 LLM 可作为零样本决策主体，利用常识推理处理长尾场景和紧急事件；观点 B（DGLight, EvolveSignal）认为 LLM 应作为代码生成器或价值裁判，RL 负责数值优化与实时决策。现有证据偏向观点 B，因 LLM 在数值推理上存在误差，且推理延迟（秒级）远高于 RL（毫秒级），无法满足实时控制要求。DGLight 通过 RL 引导 LLM 微调，在效率与可解释性间取得更好平衡。这一分歧的背后，是另一个更根本的争论：安全约束的实现机制。观点 A（传统 RL, 奖励塑形）主张通过设计包含安全惩罚的奖励函数引导智能体学习安全策略；观点 B（CFLight, 反事实学习）主张通过生成反事实轨迹注入安全经验，或利用动作掩码等硬约束确保安全。证据未定，因极端场景数据稀缺，反事实生成成本高，且缺乏统一的安全验证基准。CFLight 实验显示其在极端场景下鲁棒性提升，但缺乏大规模真实世界验证。

### 3.3 其他开放问题

最紧迫的工程问题是大规模网络扩展与计算效率。城市级数百路口协调时的训练时间、内存占用及通信开销问题，难点在于状态空间爆炸与多智能体非平稳性，潜在路径包括分层架构、参数共享及轻量化模型。SEMI-CTDE 通过区域划分降低了计算复杂度，但区域划分策略对性能影响敏感，缺乏自适应区域划分算法。最根本的研究问题是分布偏移下的鲁棒性与泛化。应对训练与测试交通需求分布不一致导致的性能下降，难点在于有限样本下的适应性，潜在路径包括元学习、域适应及对抗训练。FRAP++ 通过元学习提升了泛化能力，但元学习理论保证尚不明确。此外，Sim-to-Real 迁移与部署仍是开放问题，仿真器（如 SUMO）与真实交通动力学存在偏差，导致策略迁移失败，潜在路径包括高保真仿真器（如 Vissim）和离线 RL。已知—争议—未知认知图谱显示，RL 优于传统方法、MARL 是主流范式是已知共识；LLM 角色定位、安全实现机制是争议焦点；分布偏移本质、Sim-to-Real 迁移是未知领域。未来发展趋势将依赖于物理信息融合、LLM 深度集成及 Sim-to-Real 闭环验证。

## 4. 总结与展望

强化学习交通信号控制已从单点效率优化演进为网络级、可解释、安全鲁棒的综合决策系统。核心挑战在于平衡全局协同、动态泛化与工程可信度，这一矛盾贯穿领域始终：从 IntelliLight 的单路口 DQN 到 CoLight 的网络级 GAT，再到 EvolveSignal 的 LLM 可解释策略，每一步都是对前代局限的修正。当前瓶颈在于分布偏移导致的泛化失效、LLM 推理延迟与数值精度不足、以及 Sim-to-Real 迁移中的仿真偏差。

未来可能突破的方向包括：物理信息世界模型与离线 RL 的融合，结合交通流物理模型提升状态重建与策略可靠性，降低对在线交互数据的依赖（Liu et al., 2026, P22；Onur et al., 2026, P24）；LLM 与 RL 的深度融合，利用 LLM 增强可解释性、推理能力及零样本泛化，同时通过蒸馏、量化等技术解决延迟问题（Yu, 2026, P19；Pang et al., 2026, P20）；多模态与紧急场景响应，整合视觉、结构化传感器数据以应对紧急车辆、行人等罕见事件（Pang et al., 2026, P20；Li et al., 2025, P7）。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，构建包含计算效率、安全性、可解释性等多维度的标准化评测基准，以解决当前方法间公平比较困难的问题。
