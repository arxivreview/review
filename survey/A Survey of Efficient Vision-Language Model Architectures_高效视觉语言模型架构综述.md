综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Efficient%20Vision-Language%20Model%20Architectures)

## 导读

高效视觉语言模型（Vision-Language Models, VLMs）架构研究旨在解决标准 Transformer 在处理高分辨率视觉输入与长序列时面临的二次方计算复杂度及键值缓存（KV Cache）内存爆炸问题。早期工作以 LLaVA 为代表的模块化架构确立了视觉编码器、连接器与大语言模型（LLM）的主流范式，解决了基础跨模态对齐问题，但静态注意力机制在长序列处理中迅速暴露出计算瓶颈。随着研究重心从追求能力上限转向效率-性能帕累托前沿，线性注意力、状态空间模型及混合专家（Mixture of Experts, MoE）机制被引入以突破长上下文限制，视觉 Token 剪枝与自适应分辨率策略则用于削减高分辨率输入带来的冗余计算。近期研究进一步聚焦于推理阶段的极致优化，包括扩散解码替代自回归解码以及具身智能场景下的流式执行。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

视觉语言模型正从静态图文理解向连续、实时的多模态智能演进，其核心矛盾在于视觉信息的高维冗余性与 LLM 计算资源的有限性。标准 Transformer 架构的二次方计算复杂度及推理时动态增长的 KV 缓存，成为处理长序列、高分辨率输入及边缘部署的核心瓶颈。这一矛盾在 2020 至 2026 年间经历了从“能力上限”到“效率-性能平衡”的范式转移，研究重心从单纯扩大模型规模转向架构层面的线性化与稀疏化改造。

问题的形式化可表述为：给定视觉输入 $V$ 和文本查询 $Q$，模型需生成响应 $Y$，即 $Y = f_\theta(V, Q)$。在 $N$-way $K$-shot 的少样本或长上下文场景中，序列长度 $L$ 急剧增加，导致注意力计算复杂度 $O(L^2)$ 和 KV 缓存内存占用 $O(L)$ 成为不可持续的瓶颈。子问题呈现强依赖与互补关系：视觉 Token 压缩是降低长上下文推理内存爆炸的前置条件，高效架构设计（如线性注意力）为推理加速策略（如并行解码）提供底层算力支撑，而具身智能效率则是上述所有技术在实时控制场景下的综合应用与极端约束测试。

2021 至 2023 年是基线确立期。CLIP 通过对比学习对齐图像与文本表示，奠定了双编码器架构基础；LLaVA 确立了视觉编码器、连接器和 LLM 解码器的模块化架构，通过大规模指令微调实现多模态对齐。这一阶段的主要约束是算力不足导致无法处理高分辨率输入，因此研究聚焦于模块化架构确立与固定分辨率处理，NaViT 提出的原生分辨率处理策略解决了固定分辨率预处理导致的细节丢失问题。

2024 至 2025 年进入瓶颈突破期。FastV 引入基于文本-视觉交叉注意力的 Token 剪枝机制，开启了动态 Token 压缩的研究方向；InfiniteVL 结合线性注意力与稀疏注意力机制，通过 Gated DeltaNet 实现恒定计算和内存占用，解决了长上下文场景下的二次复杂度瓶颈。这一时期的关键转折在于问题定义从单帧高分辨率冗余计算扩展至连续视频流中的恒定内存占用与低延迟推理，线性注意力与状态空间模型被广泛引入以突破长上下文限制。

2026 年至今是场景泛化与全生命周期效率优化期。ViCA 通过信息流分析移除冗余自注意力层，BARD 实现自回归与扩散解码桥接，StreamingVLA 将效率优化延伸至具身智能实时控制。研究重心从“推理加速”转向“全生命周期效率优化”，涵盖训练阶段的异步解耦、持续学习中的遗忘缓解以及具身智能场景下的动作-感知并行化。当前形态表现为混合架构与动态自适应策略的深度融合，旨在解决算力与内存约束下的实时性与泛化性矛盾。

**如果用一个核心问题概括该领域，那便是：在保持高频视觉感知精度与多模态对齐质量的前提下，通过架构创新与算法优化，实现视觉语言模型在计算复杂度、内存占用与推理延迟上的恒定化或亚线性增长，从而突破算力与内存约束下的实时性与泛化性矛盾。**

## 2. 方法体系

- 2021：CLIP——奠定双编码器架构基础

- 2022：Flamingo——开创跨模态桥接设计范式

- 2023：LLaVA——确立模块化架构主流基线

- 2024：FastV——开启动态 Token 压缩研究方向

- 2025：InfiniteVL——实现长上下文恒定内存占用

- 2025：Q-Zoom——提出查询感知自适应感知框架

- 2026：ViCA——基于信息流分析优化架构

- 2026：BARD——桥接自回归与扩散解码

这条时间线勾勒了该领域方法演进的代表性节点：从 2021 年的 CLIP 奠定该领域方法基线，经 2022 年 Flamingo 的推进，到 2026 年的 ViCA 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 高效架构设计

高效架构设计路线聚焦于 VLM 底层机制创新，通过线性/稀疏注意力、混合状态空间模型、MoE 及跨模态解耦等机制，降低计算复杂度并优化视觉-语言交互效率。该路线的起源可追溯至 Flamingo 提出的交叉注意力机制，但其静态注意力在长序列处理中面临计算瓶颈。InfiniteVL（Tao et al., 2025, P7）针对全注意力层的二次复杂度瓶颈，提出混合基础模型 InfiniteVL-Base，通过交错少量全注意力层与 Gated DeltaNet 线性注意力层，结合定制蒸馏策略，在保持多模态性能的同时实现 1.7 倍解码加速。该方法通过线性与稀疏注意力的协同，解决了长多模态输入的计算与内存约束，为无限输入 VLM 提供了高效架构范式。

ViCA（Liu et al., 2026, P9）则从信息流分析角度切入，提出仅视觉交叉注意力架构。通过识别视觉信息融合的关键层，发现文本-视觉交叉注意力在浅层和中层对视觉融合至关重要，而深层贡献边际递减。基于此，移除冗余的自注意力层，仅保留关键层的交叉注意力，大幅降低计算开销。该方法通过训练无关的掩码实验验证了关键层的选择，确保在移除大部分注意力层后性能下降可控。ZAYA1-VL-8B（Shapourian et al., 2026, P18）采用 MoE 架构作为 LLM 骨干，结合 Qwen2.5 视觉编码器，引入视觉特定 LoRA 参数在 MLP 和 CCA 块上，增强视觉特征学习能力。在 LLM 内部对图像 Token 实施双向注意力，允许所有图像补丁相互关注，不受位置限制，提升空间结构理解。

AsyMoE（Zhou et al., 2026, P19）针对视觉和语言模态的处理特性差异，提出非对称 MoE 架构，引入双曲跨模态专家和证据优先语言专家。视觉模态呈现空间完整表示，语言模态需要顺序上下文维护，传统对称 MoE 忽略这种非对称性。通过双曲专家增强跨模态关联建模，证据优先专家优化语言处理中的上下文稀释问题。Linear Multi-Timescale Retention（Yeafi et al., 2026, P23）提出线性多时间尺度保留机制作为视觉-语言桥接，替代传统的 Softmax 多头注意力。通过聚合多个时间尺度的加权状态，实现视觉特征到文本嵌入空间的高效投影，解决高分辨率图像和多图像推理中的上下文窗口管理问题。

### 2.2 视觉 Token 压缩

视觉 Token 压缩路线针对高分辨率输入导致的视觉 Token 冗余问题，研究自适应分辨率、动态 Patch、Token 剪枝及查询感知感知策略，以平衡精度与推理成本。该路线的奠基工作包括 NaViT 提出的原生分辨率处理策略和 FastV 引入的 Token 剪枝机制。Q-Zoom（Shi et al., 2026, P15）提出查询感知自适应感知框架，通过轻量级动态门控网络在粗粒度全局特征足够时绕过高分辨率处理。对于需要细粒度感知的查询，自我蒸馏区域提议网络从中间特征空间精确定位任务相关感兴趣区域。门控网络使用一致性感知生成策略推导确定性路由标签，SD-RPN 采用全自监督蒸馏范式优化。该方法在文档和 OCR 基准上加速推理 2.52 倍，高分辨率场景加速 4.39 倍，同时保持或提升精度。

AdaPatch（ICLR 2026, P26）提出自适应补丁策略，根据图像信息密度和原生分辨率动态选择补丁大小。量化信息密度并将其与原生分辨率映射到补丁大小估计，扩展固定补丁模型至任意补丁，实现每图像补丁大小选择。该方法解决了固定补丁在分辨率极端情况下的性能退化问题，保留细粒度细节和全局结构。Input-Adaptive Visual Preprocessing（Cahyani et al., 2025, P8）提出输入自适应视觉预处理方法，基于图像内容特征动态调整输入分辨率和空间覆盖范围。结合内容感知图像分析、自适应分辨率选择和内容感知裁剪，在视觉编码前减少视觉冗余。该方法与 FastVLM 集成，无需修改架构或重新训练，通过推理时动态调整降低计算成本。

LookME（Xu et al., 2026, P21）提出基于查找的多模态嵌入层注入方法，在 VLM 解码器中间层集成 LookME 层，支持文本、图像和跨模态三种查找路径。通过稀疏注入，选择性增强解码器，检索多模态外部嵌入，避免对主导多模态 Token 的无差别操作。该方法利用外部嵌入表存储多尺度视觉特征和文本嵌入，通过稀疏注入降低计算成本，同时增强多模态表示。LookME 为参数高效 VLM 提供了新范式，通过外部嵌入查找替代密集参数扩展，提升多模态理解能力。

### 2.3 推理加速策略

推理加速策略路线探索解码算法优化、并行上下文学习及视觉编码器轻量化设计，旨在减少推理延迟、提升吞吐量并支持边缘设备部署。该路线的早期工作包括 PyramidDrop 提出的分层 Token 丢弃策略。Parallel-ICL（Yamaguchi et al., 2026, P10）提出并行上下文学习算法，将长演示上下文分块并行处理，通过 Logit 级加权 Product-of-Experts 集成近似全上下文输出。基于集成学习理论，引入聚类上下文分块最大化块间多样性，相似度上下文编译按查询相关性加权预测。该方法解决了多模态上下文学习中因二次计算成本导致的推理延迟问题，在 VQA、图像描述和分类基准上实现与全上下文 MM-ICL 相当的性能，同时显著提升推理速度。

BARD（Chen et al., 2026, P16）提出自回归与扩散视觉语言模型桥接框架，通过渐进式监督块合并和阶段式 dVLM 蒸馏实现高效并行解码。渐进式块合并在教师强制后训练中逐步扩大解码块大小，避免从因果解码直接跳转到大块扩散导致的性能下降。阶段式蒸馏使用固定小块 dVLM 作为教师，恢复大块大小导致的性能损失。该方法突破了自回归解码的顺序瓶颈，在 OCR 基准上实现更优的精度-吞吐量权衡，为高效多模态生成提供了新范式。UltraViT（Metaxas et al., 2026, P22）提出延迟优化的设备端视觉编码器，针对大型视觉语言模型在边缘设备部署的延迟瓶颈。通过架构优化和量化技术，降低视觉编码器的计算和内存开销，实现实时推理。该方法专注于视觉编码器轻量化，提升设备端 VLM 的推理效率，为资源受限环境下的多模态应用提供高效视觉处理方案。

### 2.4 高效训练范式

高效训练范式路线研究参数高效微调、知识蒸馏、分布式异步训练及低资源训练方法，降低 VLM 训练成本并提升模型在特定任务上的学习效率。FlowTrain（Jiang et al., 2026, P20）提出基于流的解耦训练框架，将 VLM 训练重构为连续生产者-消费者数据流，实现异构模块独立原生吞吐量执行。通过异构并行分配器将集群划分为编码器/LLM 演员池，统一内存池存储嵌入和元数据，动态打包调度器构建计算平衡微批次。该方法解决了单体框架忽略 VLM 结构异构性的问题，提升训练 MFU，为工业级 VLM 分布式训练提供了高效范式。

LLaVA-DyMoE（Zhao et al., 2026, P12）提出动态 MoE 持续学习框架，通过漂移感知 Token 分配缓解路由漂移导致的灾难性遗忘。分析 Token 级失败模式，识别新任务数据中模糊和旧 Token 对路由漂移的贡献，通过 Token 级分配引导将这些 Token 导向新专家，保留既定路由模式。结合路由分数正则化强制专家组分离和促进新专家专业化，该方法在 CoIN 基准上实现 7% 平均最终精度提升和 12% 遗忘减少，为 LVLM 持续学习提供了 MoE 架构优化策略。MPA（Penamakuri et al., 2025, P2）提出无标签模型对齐框架，通过伪标注器、对齐标识器和对齐平衡器三个模块，利用大 VLM 增强小 VLM 的 VQA 性能。伪标注器自动标注无标签图像，对齐标识器进行战略数据选择和自动质量评估，对齐平衡器利用精选数据微调小 VLM。该方法无需人工标注，通过大模型知识迁移提升小模型性能，在资源受限场景下实现高效 VQA。

### 2.5 具身智能效率

具身智能效率路线关注 Vision-Language-Action (VLA) 模型在具身智能场景下的效率优化，涵盖架构压缩、流式推理及分布式强化学习框架。StreamingVLA（Shi et al., 2026, P14）提出流式视觉语言动作模型，通过动作流匹配和自适应早期观察实现并行化执行。动作流匹配将动作建模从预测绝对值重构为预测特征空间状态更新，实现动作生成与执行的重叠。自适应早期观察利用动作显著性多样性，在高显著性时避免早期观察，重叠动作执行与下一迭代 VLM 观察处理。该方法降低了 VLA 模型推理延迟，实现流畅执行，为具身智能系统提供了流式推理策略。

AcceRL（Lu et al., 2026, P11）提出分布式异步强化学习和世界模型框架，解决 VLA 模型训练中同步屏障导致的 GPU 空闲和长尾问题。通过解耦环境交互、策略推理和模型更新，实现异步执行，避免中央学习者等待所有分布式 rollout worker 完成。该方法提升了大规模 VLA 强化学习的吞吐量，解决了物理模拟器低频率和大数据需求带来的效率瓶颈，为具身智能在线微调提供了高效分布式训练框架。

### 2.6 跨任务与多领域应用

高效 VLM 架构不仅服务于静态图像理解，还广泛应用于多语言增强、低资源训练及幻觉抑制等跨任务场景。PLAST（EMNLP 2025, P24）提出语言特定层高效多语言增强方法，通过识别 LVLM 中处理多语言性的三阶段过程，精准增强语言特定表示。发现低层更专注于学习语言特定表示，通过冻结非语言特定层并微调语言特定层，实现高效多语言对齐。该方法避免了大规模数据翻译和全参数微调，在数据稀缺场景下提升多语言理解能力。

ESsEN（Fields and Kennington, 2026, P17）提出低资源设置下紧凑判别视觉语言 Transformer 训练方法，采用 EfficientNet-b2 图像编码器和 ELECTRA-Small 文本编码器的双塔架构。通过 6 层交叉模态融合编码器，在仅 6M 图像-文本对和 180k 唯一图像的低资源数据集上训练，实现 39.2M 参数的紧凑模型。该方法通过架构设计和数据效率优化，在低资源场景下实现竞争性性能，为 VL 研究可及性提供了紧凑模型训练范式。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域共识认为标准 Transformer 的二次方复杂度是 VLM 处理长序列和高分辨率输入的主要瓶颈，必须通过架构创新（如线性注意力、稀疏化）来解决。这一共识在多个基准上被反复验证：InfiniteVL-Base 在 DocVQA 的 64.5 与 Video-MME 的 62.8 均接近 Qwen2.5-VL 的 64.9 和 63.5，表明线性注意力与稀疏注意力的协同在保持精度的同时实现了恒定内存占用。与此相关的另一个共识是视觉 Token 的数量与质量之间存在权衡，盲目增加 Token 数会引入冗余，需通过剪枝或自适应分辨率优化。Q-Zoom 在文档理解任务上加速 2.52 倍，高分辨率场景加速 4.39 倍，同时保持或提升精度，验证了查询感知自适应感知策略的有效性。

### 3.2 观点分歧

线性注意力能否完全替代全注意力是领域内的主要分歧。观点 A 认为线性注意力（如 Gated DeltaNet）足以处理长上下文，应全面替代全注意力以追求极致效率；观点 B 认为全注意力在高频视觉召回和长距离依赖建模上具有不可替代性，应采用混合架构。现有证据偏向混合架构，InfiniteVL 在保留少量全注意力层的情况下，在 DocVQA 和 Video-MME 上取得了 SOTA 性能，表明纯线性注意力在细粒度视觉任务上存在劣势。这一分歧的背后，是另一个更根本的争论：扩散解码是否优于自回归解码。观点 A 认为扩散解码通过并行生成多个 Token，具有更高的吞吐量，是未来主流；观点 B 认为自回归解码的串行特性保证了生成的确定性，扩散解码存在早期错误累积和训练-推理不匹配问题。现有证据偏向“渐进式桥接”策略，BARD 通过阶段式蒸馏缓解了扩散解码的性能损失，在 OCR 基准上实现了更优的权衡。但直接扩散解码在通用 VQA 任务上仍落后于自回归，证据强度较弱，因扩散解码在 VLM 中的应用尚处于早期。

### 3.3 其他开放问题

当前研究边界在于“工程优化”与“理论突破”的交界。最紧迫的工程问题是边缘设备部署与长视频流式处理。边缘设备部署的难点在于模型量化、剪枝与硬件适配，潜在路径包括轻量级视觉编码器（如 ConvNeXt、EfficientNet）、模型蒸馏及输入自适应预处理；长视频流式处理的难点在于平衡长序列依赖与实时性，潜在路径包括线性注意力机制（如 Gated DeltaNet）、稀疏注意力混合架构及流式解码策略。最根本的研究问题是多模态幻觉的根源抑制与持续学习中的路由稳定性。多模态幻觉的难点在于区分真实视觉证据与语言先验，潜在路径包括注意力引导对齐（Attention-Guided Alignment）、视觉注意力平滑（Vision Smoothing）及证据优先专家设计；持续学习中的路由漂移机制尚未完全解决，LLaVA-DyMoE 通过漂移感知 Token 分配实现了 7% 平均最终精度提升和 12% 遗忘减少，但未完全消除灾难性遗忘。已知—争议—未知认知图谱显示，架构创新与 Token 压缩已达成工程共识，但线性注意力与全注意力的理论界限、扩散解码的质量-效率理论界限仍是未解之谜。发展趋势将从“静态高效”走向“动态自适应高效”，从“离线优化”走向“在线流式高效”。

## 4. 总结与展望

高效 VLM 架构已从单一的模型压缩演变为涵盖架构、算法、训练与部署的全栈优化体系。核心矛盾在于视觉信息的高维冗余性与 LLM 计算资源的有限性，研究尝试过线性注意力、MoE、Token 剪枝、并行解码等多种路线，但核心瓶颈仍在于如何在保持高频视觉感知精度的同时，实现恒定内存占用与低延迟推理。这一瓶颈在长视频、具身智能等极端实时场景下尤为突出，现有方法在精度-效率帕累托前沿上仍有提升空间。

未来可能突破的方向包括：长上下文与流式视频处理，通过线性注意力机制与稀疏注意力混合架构解决静态图像模型在连续视频流中的内存爆炸与延迟问题；高效视觉 Token 压缩与自适应分辨率，通过查询感知的动态裁剪及自适应 Patch 大小调整解决高分辨率图像导致的计算冗余；多模态幻觉抑制与视觉对齐，通过注意力引导对齐及证据优先专家设计解决模型在视觉细节缺失时产生幻觉的问题。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，系统评测线性注意力、MoE 及 Token 剪枝在不同任务上的效率-性能权衡，以建立标准化的帕累托前沿基准，为后续研究提供公平比较的基础。
