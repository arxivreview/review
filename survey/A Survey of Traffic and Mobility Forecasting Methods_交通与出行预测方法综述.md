## 导读

交通与出行预测旨在通过量化未来交通流、速度及出行需求，为城市资源调度与应急响应提供决策依据，其核心价值在于缓解数据非平稳性与预测精度需求之间的张力。早期研究依赖统计模型与长短期记忆网络，通过捕捉时序非线性提升短时预测精度，但受限于空间拓扑建模缺失，难以应对复杂路网交互。当图神经网络与 Transformer 架构融合后，时空联合建模成为主流，显著解决了空间依赖捕捉难题，确立了高精度预测的技术基线。随着大语言模型（Large Language Models, LLM）的引入，研究重心从纯数值拟合转向语义增强与可解释生成，利用文本信息应对突发事件并提升模型可信度。各路线在计算效率、隐私保护与语义理解之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从时空深度学习到语义生成的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

交通与出行预测是智能交通系统的核心组件，其根本目标是通过预测交通流、速度、拥堵及出行需求来优化城市资源分配。该领域起源于对传统统计模型（如 ARIMA）和早期机器学习方法的依赖，但受限于线性假设和非平稳性处理能力的不足，难以应对复杂城市交通的非线性动态。随着深度学习技术的成熟，研究焦点迅速转向非线性动态捕捉，问题形式化逐渐从单一时间序列预测演变为时空联合预测。在标准的 N-way K-shot 少样本或常规时空预测任务中，模型需基于历史观测序列 $X_{t-T:t}$ 预测未来 $H$ 步的交通状态 $Y_{t+1:t+H}$，其中空间维度通常由路网拓扑或地理网格定义。

问题定义的演化揭示了子问题间的层级依赖关系。时空依赖建模是基础，若不解决空间拓扑交互，高精度预测无从谈起；多模态融合与语义增强是上层扩展，依赖基础模型对数值特征的编码能力，旨在引入外部事件、天气等非结构化信息；隐私保护与可解释性则是系统级约束，贯穿所有模型，但依赖底层架构支持分布式训练或生成式输出。这种依赖结构决定了技术演进的顺序：先解决“怎么算得准”（时空建模），再解决“怎么算得全”（多模态融合），最后解决“怎么算得可信且合规”（隐私与解释）。

2016 至 2018 年是领域的奠基期，长短期记忆网络（LSTM）和门控循环单元（GRU）确立了时序建模的基本范式，但缺乏对空间拓扑结构的显式建模能力。2018 年，扩散卷积循环神经网络（DCRNN）首次系统性地将图结构与序列模型融合，通过扩散卷积捕捉空间依赖，成为后续时空图神经网络（STGNN）的重要基线。2019 年，Graph WaveNet 通过自适应依赖矩阵学习隐藏的空间相关性，不再依赖预定义的路网拓扑，为处理非结构化或动态变化的交通网络提供了新路径。这一阶段的核心约束是算力与数据规模，方法演进主要围绕如何在有限算力下更高效地捕捉时空依赖。

2020 至 2021 年，跨域基准的引入暴露了单一城市模型的泛化瓶颈，促使研究者关注预训练范式。2021 年，TrafficBERT 通过在大规模交通数据上进行掩码语言建模，证明了预训练范式在交通领域的有效性，为后续将大语言模型引入交通预测奠定了概念基础。2023 年，Time-LLM 通过重编程技术将时间序列数据映射为文本 Token，利用大语言模型的上下文学习能力进行零样本或少样本预测，打破了传统时间序列模型与语言模型之间的壁垒。这一转折标志着问题定义从“数值误差最小化”向“语义对齐下的鲁棒预测”扩展，外部事件文本成为关键输入变量。

2024 至 2025 年，研究重心进一步转向多任务统一与可解释性。2024 年，UrbanGPT 集成时空依赖编码器与指令微调，推动了从单一任务预测向多任务统一预测框架的演进。2025 年，TransLLM 提出可学习提示路由机制，解决了固定提示模板无法适应实例级变异的问题；CrossTrafficLLM 则构建了人类中心框架，同时预测时空交通状态并生成自然语言描述。这一阶段的方法演进动力源于对“模型黑盒”痛点的解决，LLM 不仅是精度工具，更是连接数值预测与人类决策的语义桥梁。

当前形态下，领域呈现出从数据驱动向知识驱动与生成式 AI 结合发展的趋势。研究不仅涵盖宏观路网预测，还深入至微观车辆轨迹、共享出行需求及网络流量矩阵预测。核心挑战已从单纯的精度提升转向多模态融合、隐私保护（联邦学习）、边缘计算部署及模型可解释性的综合平衡。

**如果用一个核心问题概括该领域，那便是：如何在保证高精度时空预测的同时，有效融合非结构化语义信息以应对非平稳性，并解决模型在隐私、可解释性及边缘部署上的工程化瓶颈。**

## 2. 方法体系

- 2014：LSTM/GRU——奠定时序建模基线

- 2018：DCRNN——确立时空图神经网络范式

- 2019：Graph WaveNet——引入自适应空间依赖学习

- 2021：TrafficBERT——开启交通预训练范式

- 2023：Time-LLM——实现时序与语言模型壁垒突破

- 2025：TransLLM——提出可学习提示路由机制

- 2026：LEAD——代表 LLM 增强生成式预测前沿

这条时间线勾勒了该领域方法演进的代表性节点：从 2014 年的 LSTM/GRU 奠定该领域方法基线，经 2018 年 DCRNN 的推进，到 2026 年的 LEAD 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 时空深度学习

时空深度学习路线起源于对纯时序模型空间建模缺失的修正。2014 年，LSTM/GRU 通过引入门控机制解决传统 RNN 梯度消失问题，有效捕捉交通流序列中的非线性时间依赖关系，但缺乏对空间拓扑结构的显式建模能力。2018 年，DCRNN 将道路网络拓扑结构建模为有向图，通过扩散卷积捕捉空间依赖，并结合 RNN 处理时间序列，首次系统性地将图结构与序列模型融合，成为后续 STGNN 的重要基线。2019 年，Graph WaveNet 通过自适应依赖矩阵学习隐藏的空间相关性，结合空洞时间卷积捕捉长程时间依赖，不再依赖预定义的路网拓扑，为处理非结构化或动态变化的交通网络提供了新路径。

本批论文中，Geographically-aware Transformer（Kušić et al., 2026, P11）针对传统 Transformer 在空间依赖捕捉上的不足，结合地理信息与自注意力机制，捕捉长程时空依赖，支持实时交通监控与控制，其代价是地理信息预处理与模型复杂度的增加。MMCAformer（Han et al., 2026, P15）则聚焦宏微观尺度耦合，通过交叉注意力机制整合宏观交通速度与微观连接车辆驾驶行为，解决了仅依赖固定传感器数据难以捕捉微观动态的问题，提升了速度预测的鲁棒性，但代价是数据对齐复杂度高且对微观数据质量敏感。RiskTraf（Wang and Liu, 2026, P26）针对多变量输入中制度依赖相关性导致的泛化差问题，利用历史速度与占有率构建有序交通风险环境，训练轻量级残差头，避免了模型利用特定交通状态下的捷径学习，其核心取舍在于以额外的残差头训练换取模型在不同交通状态下的鲁棒性。HFD-TM（Mallick et al., 2026, P18）将预测任务分解为走廊级直行流预测与转向流扩展两个阶段，利用直行流的高稳定性辅助波动较大的转向流预测，解决了交叉口细粒度动态建模中数据波动大的问题，但分解策略对走廊定义敏感。此外，Online Learning Method（Huang et al., 2026, P17）利用前一时刻预测误差指导模型参数更新，实现了模型对动态交通环境的持续适应，解决了静态模型难以适应交通模式漂移的问题；MoDE-Boost（Tziorvas et al., 2026, P14）则基于梯度提升树变体，通过轻量化设计实现了高精度与低延迟的平衡，解决了深度学习模型在边缘设备部署时的计算资源限制问题，但代价是特征工程依赖与模型泛化能力相对受限。该路线与 LLM 路线的竞争在于计算效率与语义理解能力的权衡，时空深度学习在结构化路网上精度稳定，但在非结构化语义融合上依赖外部模块。

### 2.2 LLM 交通预测

LLM 交通预测路线起源于对传统模型泛化差、可解释性弱及隐私问题的回应。2021 年，TrafficBERT 证明了预训练范式在交通领域的有效性，但主要局限于数值序列而非自然语言语义。2023 年，Time-LLM 通过重编程技术将时间序列数据映射为文本 Token，利用大语言模型的上下文学习能力进行零样本或少样本预测，打破了传统时间序列模型与语言模型之间的壁垒。2024 年，UrbanGPT 集成时空依赖编码器与指令微调，推动了从单一任务预测向多任务统一预测框架的演进。

本批论文中，TransLLM（P28）提出统一多任务大语言模型框架，通过可学习提示路由机制处理异构时空信号，核心模块包括时空编码器将数值特征转化为嵌入，以及 Actor-Critic 网络动态选择最优提示模板。该方法解决了固定提示模板无法适应实例级变异的问题，避免了任务特定的固定结构，其代价是引入了额外的路由网络训练开销，且依赖高质量的提示候选池设计。CrossTrafficLLM（Du et al., 2025, P9）构建人类中心的可解释交通智能框架，同时预测时空交通状态并生成自然语言描述，关键技术模块为文本引导的自适应图卷积网络，用于融合高层语义信息与交通网络结构。该方法解决了传统模型预测与解释分离的问题，确保生成的报告直接由预测结果驱动，其核心取舍在于依赖 LLM 的语义对齐能力，可能增加推理延迟。SeMob（P27）利用多智能体 LLM 解析事件文本，将文本描述中的驱动事件转化为数值特征，增强模型对突发变化的响应，弥补了传统模型依赖历史数据而忽略外部事件语义的缺陷，代价是增加了文本处理与多智能体协调的计算复杂度。FedLLM（Kaur et al., 2026, P19）结合联邦学习保护数据隐私，利用 LLM 生成自然语言解释，解决了集中式训练的数据隐私顾虑，并通过 LLM 生成自然语言解释弥补黑盒模型的可解释性不足，代价是联邦通信开销与 LLM 推理成本的增加。MVGR-Net（Hao et al., 2026, P12）利用 LLM 语义理解能力编码内生与外生因素对出行模式的影响，通过多视图地理空间表示与 LLM 语义融合，提升了供需预测的准确性，代价是依赖预训练 LLM 的计算资源与数据对齐质量。EventOD（Zhao et al., 2026, P23）通过 LLM 引导的语义调制生成出行起讫点流量，解决了传统 OD 预测模型对突发事件响应滞后且缺乏语义理解的问题，代价是 LLM 推理延迟与事件文本标注依赖。该路线与时空深度学习路线的互补在于，LLM 提供了语义桥梁，但时空模型提供了稳定的数值基线，两者融合是当前前沿。

### 2.3 出行与轨迹预测

出行与轨迹预测路线聚焦个体出行轨迹语义提取、旅行时间估计及共享出行需求预测。2025 年，TrajMamba（Liu et al., 2025, P2）基于 Mamba 架构的车辆轨迹预训练模型，通过旅行目的感知预训练对齐轨迹嵌入与道路/POI 文本视图，结合知识蒸馏压缩冗余轨迹点，实现了高效且语义丰富的轨迹表示，为多种时空数据挖掘任务提供了通用嵌入，其代价是预训练数据需求与 Mamba 架构的计算特性。

本批论文中，GenTTP（Gorczyca et al., 2026, P20）利用路由分配信息预测网络总旅行时间，通过聚合路段流量状态估计系统级旅行时间，克服了微观模拟器计算昂贵且随机性强的缺点，实现了大规模路网下快速且准确的旅行时间估计，其代价是对路由分配数据的依赖与聚合函数设计复杂度。MixTTE（Jiang et al., 2026, P8）通过路由机制动态选择专家子网络处理不同路段特征，解决单一模型难以适应复杂路网多样性的问题，提升了大规模出行平台 TTE 系统的效率与准确性，代价是专家网络数量增加带来的参数规模与推理开销。Urban Vibrancy Embedding（Han et al., 2026, P16）利用变分自编码器提取浮动人口动态特征，将城市活力作为时空嵌入注入现有交通预测模型，解决了传统模型忽略城市社会活动动态对交通影响的问题，代价是浮动人口数据获取难度与嵌入维度增加。该路线与 LLM 路线的关联在于，轨迹语义提取常依赖 LLM 进行 POI 或目的地的文本对齐，而 LLM 路线则更关注宏观事件语义，两者在数据粒度上形成互补。

### 2.4 网络流量预测

网络流量预测路线针对蜂窝及通信网络，融合城市移动性、拥堵及突发特征。2025 年，MobiGPT（Qi et al., 2025, P1）面向移动无线网络的基础模型，采用扩散模型作为骨干，结合条件缩放机制捕捉环境条件与移动数据的相关性，实现了零样本/少样本下的网络流量预测，推动了通信网络预测向基础模型范式转变，其代价是扩散模型推理速度慢与 Token 化设计复杂度。FedNET（Panda et al., 2025, P3）基于联邦学习的主动交通管理框架，在分布式环境中训练 LSTM 模型预测节点级流量，解决了集中式数据收集的隐私与扩展性问题，代价是联邦通信开销与本地计算资源需求。TUBO（Yuan et al., 2026, P13）针对网络流量突发特征的定制化 ML 框架，包含突发处理与模型选择组件，通过模型池适应不同流量模式并提供量化不确定性，显著提升了网络流量预测的可靠性，代价是模型池维护成本与选择策略复杂度。

本批论文中，LEAD（Sun et al., 2026, P10）结合扩散模型的高保真生成能力与 LLM 的语义理解，通过适配器模块融合文本条件，解决了传统确定性模型在不确定性估计与复杂模式捕捉上的局限，代价是扩散模型迭代推理延迟与 LLM 集成复杂度。PEHT（Rezaei et al., 2026, P22）结合 GNN 与 Transformer，通过参数高效微调适应动态城市拥堵特征，解决了传统模型难以融合外部城市拥堵数据的问题，代价是动态图构建计算开销与适配器设计复杂度。Cellular Predictions on the Move（Vesselinova and Ilmonen, 2026, P21）利用知识图谱增强基站表示，融合空间、功能与城市语义信息，解决了传统模型忽略基站静态环境语义的问题，代价是 KG 构建与维护成本。该路线与 LLM 路线的竞争在于生成式建模与确定性预测的取舍，LEAD 等生成式模型在不确定性估计上更优，但推理速度较慢，而 PEHT 等参数高效模型在实时性上更具优势。

### 2.5 安全与综述

安全与综述路线涵盖交通拥堵预测、事故热点演化及车辆安全场景下的占用网格预测。2025 年，POG-ML（Nadarajan et al., 2025, P6）利用自编码器与随机森林映射交通参与者运动假设，通过概率化表示未来交通场景，为主动安全系统提供了可量化的风险预测基础，代价是随机森林可解释性有限与特征工程依赖。

本批论文中，Probability Estimation for POGs（Nadarajan and Botsch, 2025, P5）利用动态车辆模型计算未来轨迹，结合机器学习估计占用概率，解决了短时预测难以覆盖长时风险的问题，代价是动力学模型计算复杂度与参数敏感性。ML Architectures for POGs（Nadarajan et al., 2025, P7）结合层级场景分类器与机器学习模型，映射低维特征到 POG，解决了传统方法难以处理多假设场景的问题，代价是场景分类准确性依赖与模型泛化能力。Passenger Flow Modelling Review（Hecht et al., 2025, P4）基于文献计量分析，识别短期乘客流预测的知识缺口与新研究方向，提供了全面领域概览。Interpretable ML for Congestion（Zhu et al., 2026, P25）利用可解释 ML 模型分析交通拥堵预测中各特征贡献，特别关注疫情时期影响，解决了传统黑盒模型难以解释疫情对交通影响的问题。Crash Hotspot Forecasting（Zhu et al., 2026, P24）利用深度学习捕捉事故时空演化规律，实现从被动响应向主动预防转变，代价是数据标注依赖与模型训练成本。该路线与其他路线的关联在于，安全预测常依赖时空深度学习提供的状态估计，而可解释性需求则驱动了 LLM 路线的融合。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

图神经网络结合时间序列模型是处理交通时空依赖的主流且有效的方法，显著优于纯时间序列或纯空间模型，这一共识在 PEMS08 等标准基准上被反复验证：TransLLM 与 RiskTraf 均大幅超越传统 STGNN 基线（支撑证据：P28, P26）。与此相关的另一个共识是，大语言模型在整合外部文本信息、提升模型可解释性及处理多模态数据方面展现出巨大潜力，CrossTrafficLLM 在 Beijing TrafficText 上的优异表现及 LEAD 在 Abilene 上的高精度预测均证实了 LLM 语义增强的有效性（支撑证据：P9, P10）。然而，该共识的边界在于 LLM 的高推理延迟与计算成本，使其在实时性要求极高的边缘部署场景中受到限制，MoDE-Boost 等轻量化模型的存在正是对这一边界的回应（支撑证据：P14）。

### 3.2 观点分歧

LLM 在交通预测中的角色存在显著分歧：一方主张 LLM 作为特征编码器，提取语义嵌入注入传统时空模型（如 MVGR-Net），保持预测效率；另一方主张 LLM 作为生成式大脑，直接生成预测值与自然语言解释（如 CrossTrafficLLM），实现预测与解释统一。现有证据偏向后者在可解释性与事件响应上更优，但前者在计算效率与实时性上更具优势，分歧根源在于缺乏统一评估“可解释性效用”的指标，且场景依赖性强：实时调度场景偏好特征编码，政策决策场景偏好生成式解释（支撑证据：P12, P9）。这一分歧的背后，是另一个更根本的争论：联邦学习在交通预测中的必要性。联邦学习虽能解决隐私问题，但面临通信开销大、数据异构性及模型收敛慢的挑战，FedLLM 与 FedNET 证明了其在大规模分布式场景下的必要性，但在小规模场景下成本过高，现有证据无法在隐私预算固定时判定联邦学习与差分隐私集中式训练的精度-通信开销比优劣（支撑证据：P19, P3）。

### 3.3 其他开放问题

最紧迫的工程问题是边缘计算与实时性约束，高精度复杂模型（如大型 Transformer/LLM）计算量大，难以在边缘设备或实时系统中部署，需平衡精度与推理效率，MoDE-Boost 通过轻量化设计提供了初步解决方案，但通用性仍待验证（支撑证据：P14）。最根本的研究问题是跨城市与跨域迁移学习，不同城市路网结构、POI 语义及交通模式差异导致模型泛化能力不足，缺乏通用的空间语义嵌入，潜在路径包括开发通用的道路和 POI 嵌入表示，以及利用大语言模型增强跨域语义对齐（支撑证据：P2, P12）。已知的是时空建模与语义增强的有效性，争议的是 LLM 角色与联邦学习必要性，未知的是跨域通用嵌入与边缘部署的通用框架。发展趋势将指向“LLM+GNN+联邦学习”的融合，核心在于构建能够理解城市语义并实时响应的智能预测系统。

## 4. 总结与展望

交通与出行预测领域经历了从数值拟合到语义生成的范式重构，核心矛盾从“精度不足”转变为“语义缺失”与“工程落地难”。研究者们尝试了时空深度学习、LLM 增强、联邦学习及生成式建模等多条路线，试图在精度、计算效率、可解释性及数据隐私之间寻求平衡。当前核心瓶颈在于如何在保证语义增强与隐私保护的同时，解决边缘部署的效率瓶颈与跨域泛化难题，这直接回应了第 1 章提出的核心问题：如何在保证高精度时空预测的同时，有效融合非结构化语义信息以应对非平稳性，并解决模型在隐私、可解释性及边缘部署上的工程化瓶颈。

未来可能突破的方向包括：构建交通基础模型，利用 LLM 实现零样本/少样本跨域预测，TrajMamba 与 MobiGPT 已为此奠定概念基础（支撑证据：P2, P1）；发展参数高效微调与边缘-云协同推理架构，以解决 LLM 部署的效率瓶颈，PEHT 与 MoDE-Boost 提供了技术路径（支撑证据：P22, P14）；建立统一的可解释性效用评估指标，以裁决 LLM 角色之争（支撑证据：P9, P12）。对于进入该领域的研究者，最值得做的一件事是构建一个在统一骨干与统一预训练条件下，同时评估精度、推理延迟与可解释性效用的跨域基准，以填补当前评测体系的公平性缺口。
