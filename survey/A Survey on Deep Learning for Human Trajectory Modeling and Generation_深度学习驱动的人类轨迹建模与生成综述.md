## 导读

人类轨迹建模与生成旨在合成符合真实时空分布的移动序列，其核心价值在于缓解隐私法规限制与城市计算对高保真数据需求之间的张力。早期研究依赖规则驱动的活动基模型，思路直观却难以捕捉长程依赖与复杂分布。当深度生成模型引入该领域后，研究者通过变分自编码器与生成对抗网络实现了从规则匹配到分布拟合的转变，但训练不稳定与模式崩溃问题随之显现。随着扩散模型与 Transformer 架构的普及，生成质量显著提升，计算成本与语义缺失成为新的瓶颈。近期，大语言模型（Large Language Model, LLM）的融入将研究重心转向语义可控性与跨域泛化，试图解决冷启动与物理一致性冲突。各路线在保真度、可解释性与计算效率之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从统计拟合到语义推理的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

人类轨迹建模的兴起源于城市计算、交通管理及公共卫生对大规模时空数据的迫切需求，同时受隐私法规（如 GDPR）限制，真实数据难以直接获取，合成数据成为关键替代方案。早期研究依赖基于规则的活动基模型（Agent-Based Model, ABM）和统计方法（如 Markov 链），但难以捕捉长程依赖和复杂分布。2020 年前后，深度生成模型（如 GAN、VAE）引入该领域，实现了从规则驱动到数据驱动的范式转变，能够学习内在时空分布。2023-2024 年，扩散模型（Diffusion Models）和 Transformer 架构成为主流，显著提升了生成轨迹的保真度和多样性，解决了传统生成模型训练不稳定和模式崩溃问题。2025-2026 年，研究重心转向 LLM 与轨迹生成的融合，通过语义推理增强轨迹的可解释性和可控性，以及基础模型（Foundation Models）的构建以实现跨城市泛化。当前领域处于高活跃期，研究热点集中在隐私保护生成、多模态语义融合、以及基于 LLM Agent 的交互式轨迹合成，旨在解决冷启动、长尾分布及物理一致性等核心挑战。

该领域的核心问题可形式化为：给定历史轨迹集合 $\mathcal{D} = \{T_1, T_2, ..., T_N\}$，其中每条轨迹 $T_i = \{(x_{i,t}, y_{i,t}, t_{i,t})\}_{t=1}^{L_i}$ 包含位置坐标与时间戳，目标是学习一个生成模型 $G_\theta$，使得合成轨迹 $T' \sim G_\theta$ 在统计分布上逼近真实数据分布 $P_{data}$，同时满足物理约束（如速度上限、路网连通性）与隐私保护要求。这一形式化揭示了三个子问题的依赖关系：轨迹表征学习是基础，将连续坐标转化为可建模的离散或潜在表示；移动性预测常作为生成模型的条件输入或评估基准，提供时序依赖的先验；隐私保护贯穿所有生成任务，是部署的前提约束。

在问题定义的演化中，早期关注点集中在“坐标序列预测”，即基于历史位置预测下一位置。随着数据规模扩大，问题演变为“分布拟合”，即生成符合整体统计特性的轨迹集合。近年来，问题进一步扩展为“语义可控生成”，要求模型不仅拟合分布，还能根据自然语言指令或用户画像生成特定意图的轨迹。这一演化反映了从纯数据驱动到数据-语义混合驱动的范式转变。

约束条件的变化是驱动方法演进的关键因素。2016-2018 年，计算资源有限，方法以轻量级 RNN 为主，如 DeepMove（2018）引入历史注意力机制以捕捉长期周期性模式，成为后续序列预测方法的经典基线。2020 年，跨域基准暴露出域偏移下的原型崩溃问题，研究者转向预训练与视觉语言模型，用更强的先验换取跨域鲁棒性。2021 年，预训练/VLM 引入，TrajVAE（2020）将 LSTM 引入变分自编码器以学习轨迹序列信息，奠定了深度生成模型在轨迹合成中的基础。2023-2025 年，细化与融合成为主题，DiffTraj（2023）基于扩散模型框架进行轨迹生成，避免了 GAN 训练不稳定的问题，为高保真轨迹合成提供了新的技术范式。当前形态是多种技术路线并存，各自解决不同层面的约束。

**如果用一个核心问题概括该领域，那便是：如何在隐私约束下，构建兼具物理一致性、语义可解释性与跨域泛化能力的生成式模型，以合成高保真的人类移动轨迹。**

## 2. 方法体系

- 2018：DeepMove——基于 RNN 架构引入历史注意力机制以捕捉长期周期性模式

- 2020：TrajVAE——将 LSTM 引入变分自编码器以学习轨迹序列信息

- 2022：GETNext——利用图神经网络建模用户、位置及上下文之间的复杂关系

- 2023：DiffTraj——基于扩散模型框架进行轨迹生成

- 2024：TrajFM——提出轨迹基础模型，通过大规模预训练捕捉跨城市的通用移动模式

- 2025：Narrative-to-Action——构建分层 LLM 智能体框架

- 2025：M-STAR——提出多尺度时空自回归框架

- 2026：TrajGPT-R——结合强化学习增强的生成式预训练 Transformer

这条时间线勾勒了该领域方法演进的代表性节点：从 2018 年的 DeepMove 奠定该领域方法基线，经 2020 年 TrajVAE 的推进，到 2026 年的 TrajGPT-R 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 轨迹生成模型

轨迹生成模型旨在合成高保真 GPS 轨迹，解决隐私与数据稀缺问题。早期方法如 TrajVAE（2020）通过潜在空间建模实现轨迹生成，解决了早期生成模型难以捕捉时序依赖的问题，但受限于 VAE 的重建模糊性。DiffTraj（2023）针对 GAN 在复杂时空分布下的模式崩溃问题，引入了逐步去噪过程，显著提升了生成质量，但计算成本较高。M-STAR（Luo et al., 2025, P16）进一步解决了长程依赖建模与生成效率问题，利用 VQ-VAE 将连续时空特征离散化为共享代码本中的令牌，通过多阶段残差量化实现粗到细的生成。该设计牺牲了部分连续空间的平滑性，换取了离散序列建模的高效性与稳定性。TrajFlow（Li et al., 2026, P24）则基于流匹配模型实现全国范围伪 GPS 轨迹生成，通过求解常微分方程将简单基础分布转化为复杂轨迹分布，相比扩散模型生成速度更快且路径更直接，但对向量场估计的准确性要求较高。InsTraj（Zhu et al., 2026, P25）将自然语言描述的旅行意图作为条件输入，指导扩散模型的去噪过程，实现了从语义指令到具体轨迹的端到端生成，提升了生成结果的语义一致性，但条件注入可能限制生成多样性。

| 方法 | 核心架构 | 生成范式 | 条件输入 | 物理约束机制 | 主要优势 | 主要局限 |
|---|---|---|---|---|---|---|
| M-STAR (P16) | VQ-VAE + 自回归 | 离散 Token | 多尺度时空嵌入 | 离散化隐含拓扑 | 高效、长程依赖强 | 空间平滑性损失 |
| TrajFlow (P24) | 流匹配 + ODE | 连续向量场 | 无显式条件 | 向量场约束 | 生成速度快 | 极端稀疏区域非物理 |
| InsTraj (P25) | 扩散模型 | 连续去噪 | 自然语言意图 | 意图引导 | 语义可控性强 | 多样性受限 |
| TrajDLM (P28) | 块扩散语言模型 | 离散扩散 | 道路拓扑 | 掩码令牌机制 | 拓扑约束强 | 连续坐标信息丢失 |

### 2.2 LLM 智能体生成

LLM 智能体生成路线利用大语言模型的语义推理能力，将轨迹视为“时空语言”。Narrative-to-Action（Li et al., 2025, P12）构建了分层 LLM 智能体框架，包含宏观叙事推理、中观反思规划与微观行为执行三个层级，解决了传统模型缺乏语义连贯性的问题。其核心创新在于引入职业感知机制，确保行为符合用户社会角色，但推理链较长，计算开销大。TrajGPT-R（Wang et al., 2026, P21）结合强化学习增强的生成式预训练 Transformer，通过离线 RL 预训练与奖励模型微调，提升了轨迹生成的物理合理性与策略优化能力，但奖励模型训练复杂。ELLMob（Wang et al., 2026, P23）利用自对齐 LLM 处理突发事件影响，显式建模突发事件对移动性的扰动，解决了传统模型难以处理非平稳场景的问题，但事件类型需预定义。TrajGenAgent（Li et al., 2026, P36）将 LLM 作为语义推理核心，外部工具注入精确时空证据，解耦语义推理与数据查询，避免了将所有领域知识编码进模型参数，但工具接口设计复杂。

### 2.3 移动性预测

移动性预测聚焦下一位置或 POI 预测，结合 Transformer、LLM 推理及多模态特征。RHYTHM（He et al., 2025, P5）引入分层时间分词技术，通过 LLM 骨干网络捕捉移动性的周期性特征，实现了提示引导的时空模式表示学习。ARMove（Wang et al., 2026, P27）将移动性预测转化为智能体推理任务，LLM 基于历史轨迹与上下文信息进行链式推理，提升了预测的可解释性与泛化能力。STaBERT（Liu et al., 2025, P10）在 LP-BERT 基础上引入 POI 嵌入与时间描述符，将静态 POI 语义与动态时间信息结合，提升了模型对位置功能的理解。AgentMob（Chen et al., 2026, P34）基于 LLM 驱动智能体的高效证据接地移动性预测，将预测视为自适应证据控制过程，LLM 智能体决定是否需要调用移动性分析工具获取额外证据，动态平衡历史规律与实时证据。

### 2.4 轨迹表征学习

轨迹表征学习构建通用轨迹基础模型与嵌入表示，通过自监督学习、对比学习及空间分词技术，支持相似度检索、分类及跨域迁移。TrajTok（Xiong et al., 2026, P31）采用自适应空间分词技术，通过密度自适应多分辨率六边形网格将连续轨迹转化为离散令牌，结合因子化 Transformer 编码器实现鲁棒的轨迹表示学习。GSTM-HMU（Luo et al., 2025, P3）从签到序列中提取语义类型令牌流，融合几何、分类法、周期性节奏与拓扑线索，通过部分冻结的自回归骨干进行多任务预测。MoveFM-R（Meng et al., 2025, P4）结合移动性基础模型的统计保真度与 LLM 的语义推理能力，实现反事实推理，显式建模用户行为背后的潜在语义意图。

### 2.5 隐私与评估基准

隐私与评估基准关注轨迹生成的隐私保护机制、记忆化审计，以及构建统一评估基准。PATEGAIL++（ICLR 2026, P42）提出效用优化的私有轨迹生成框架，结合模仿学习与差分隐私，通过本地判别器评估合成轨迹合理性，在保护隐私的同时最大化数据效用。TravelBehaviorQA（ACL-Findings 2026, P39）用于 GPS 轨迹行为解释的基准数据集，评估 LLM 在轨迹行为推理上的能力，引入行为感知评估，超越简单事实匹配。Secrets Everywhere（Kouam et al., 2026, P37）审计移动性预测模型中的记忆化，引入暴露框架，通过排名候选金丝雀计算模型对特定秘密的记忆程度，量化记忆化风险。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域共识认为，真实轨迹数据因隐私法规和采集成本难以直接获取，合成轨迹生成是解决数据稀缺和隐私问题的必要手段。这一共识在多个基准上被反复验证：InsTraj 在 Chengdu 和 Xi'an 数据集上的 JSD 值分别为 0.0032 和 0.0104，均大幅超越 DiffTraj 的 0.0055 和 0.0154，表明深度生成模型在分布拟合上的显著优势。与此相关的另一个共识是，轨迹数据蕴含丰富的时空依赖和语义信息，仅建模坐标序列不足以捕捉人类移动意图，需融合 POI 语义、时间上下文和用户画像。STaBERT 在 Single City Normal 数据集上的 Accuracy@k 值 0.750 大幅超越 LP-Bert 的 0.344，验证了语义信息融合的有效性。此外，隐私保护是轨迹生成的核心约束，生成模型必须经过严格的隐私评估（如成员推断攻击测试）才能用于实际部署，这一共识在 PATEGAIL++ 和 Secrets Everywhere 等工作中得到体现。

### 3.2 观点分歧

关于 LLM 是否应直接生成轨迹，存在显著分歧。观点 A 认为 LLM 应直接生成轨迹，利用其端到端语义推理能力，代表方法包括 Narrative-to-Action 和 From GPS Points to Travel Patterns。观点 B 认为 LLM 应仅负责高层规划，底层轨迹生成需依赖工具调用或物理约束后处理，代表方法包括 TrajGenAgent 和 ActivityEditor。现有证据偏向观点 B，实验显示，纯 LLM 生成的轨迹在物理一致性（KVR 指标）上表现较差，而引入工具调用或编辑智能体后，物理有效性显著提升。这一分歧的背后，是另一个更根本的争论：差分隐私（DP）与记忆化审计（Memorization Auditing）的选择。观点 A 主张采用差分隐私提供理论保证，代表方法为 PATEGAIL++。观点 B 主张采用记忆化审计进行事后评估，因 DP 效用损失过大，代表方法为 Secrets Everywhere 和 Privacy Evaluation of Generative Models。证据偏向观点 B，DP 在轨迹生成中往往导致数据效用大幅下降，而审计方法能更灵活地评估隐私风险，且不影响生成质量。分歧根源在于缺乏统一的隐私-效用权衡标准，以及审计方法本身存在计算开销和覆盖范围限制。

### 3.3 其他开放问题

最紧迫的工程问题是高效推理与零样本生成。现状是 LLM 推理开销巨大，零样本性能大幅下降（如 GPT-4o zero-shot 在 Wakayama 数据集上仅 11.0%）。关键困难在于模型压缩和知识迁移，研究路径包括轻量级 LLM 蒸馏、零样本提示工程及基于检索的增强生成（RAG）。最根本的研究问题是跨城市与跨域泛化能力。现状是模型在未见城市或不同拓扑结构下性能下降，关键困难在于城市空间异质性和数据分布差异，研究路径包括元学习、任务算术（Task Arithmetic）及自适应缩放策略。此外，事件驱动与异常场景建模也是重要开放问题，现状是静态模型无法适应突发事件，关键困难在于数据稀缺和模式非平稳性，研究路径包括事件条件生成、物理信息神经网络（PINN）及异常检测集成。归纳“已知—争议—未知”认知图谱，已知的是深度生成模型在分布拟合上的优势，争议的是 LLM 直接生成与工具辅助生成的优劣，未知的是跨域泛化的理论机制与隐私-效用的帕累托前沿。发展趋势是向“语义-物理-隐私”三位一体的融合，核心问题是如何在 LLM 的语义推理与物理约束校验之间找到平衡，并建立统一的隐私-效用评估基准。

## 4. 总结与展望

人类轨迹建模与生成领域正面临隐私保护与数据效用、物理合理性与语义丰富性、计算效率与生成精度之间的核心矛盾。从 2018 年 DeepMove 奠定序列预测基线，到 2020 年 TrajVAE 引入深度生成，再到 2023 年 DiffTraj 确立扩散范式，以及 2025-2026 年 LLM 智能体与基础模型的融合，各路线在保真度、可解释性与计算成本之间做出了不同取舍。核心瓶颈在于如何在 LLM 的语义推理与物理约束校验之间找到平衡，并建立统一的隐私-效用评估基准。

未来可能突破的方向包括：跨城市与跨域泛化能力，通过元学习与任务算术解决城市空间异质性问题；隐私保护与记忆化审计，通过差分隐私与条件感知噪声添加平衡生成质量与隐私预算；LLM 与移动性基础模型的深度融合，通过层级推理与代理框架解决 LLM 幻觉及计算成本问题。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，构建一个涵盖生成质量、物理一致性与隐私安全的综合评估基准，以填补当前评测体系的空白。
