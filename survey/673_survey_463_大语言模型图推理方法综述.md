## 导读

大语言模型（LLM）在处理知识密集型任务时，常因缺乏外部结构化知识而产生幻觉与事实错误，这催生了将图结构知识引入生成过程的迫切需求。早期研究依赖检索增强生成（RAG）从非结构化文本中获取信息，但难以捕捉实体间复杂的逻辑关系，导致多跳推理断裂。随着知识图谱（KG）的引入，研究范式从“文本检索”转向“图结构检索”，利用显式关系约束推理过程。2024 年后，智能体（Agentic）与强化学习（RL）的融合推动领域进入动态探索阶段，LLM 开始自主规划路径并自我修正。当前，基础模型化与参数内化成为新趋势，旨在解决上下文窗口限制下的长程依赖问题。各路线在结构保真度、计算效率与泛化能力之间做出了不同取舍，形成了多元并存的方法格局。本综述梳理这条从静态检索到动态探索再到参数内化的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

大语言模型（LLM）在知识密集型任务中面临的幻觉与事实错误，源于其参数化知识的静态性与非结构化特性。早期研究试图通过检索增强生成（Retrieval-Augmented Generation, RAG）从外部文档中获取实时信息，以缓解知识时效性问题。然而，文本检索基于向量相似度匹配，缺乏对实体间显式逻辑关系的建模，导致在处理多跳推理任务时，推理路径容易断裂或产生逻辑不一致。这一局限性促使研究者将目光转向知识图谱（Knowledge Graph, KG），利用其节点-边结构提供可验证的外部知识基础。图结构不仅提供了事实锚点，还通过拓扑关系约束了推理的逻辑链条，成为解决 LLM 幻觉问题的核心数据源。

问题的定义随之从“知识获取”演变为“逻辑一致性保障”。在 RAG 时代，核心挑战是检索相关性；而在图推理时代，核心挑战转变为如何在克服上下文窗口限制与图结构线性化失真的前提下，实现高忠实度的多跳推理。这一转变揭示了子问题间的强依赖关系：图结构表示编码是基础接口，决定了 LLM 能否理解图；子图检索或探索策略是核心瓶颈，决定了信息获取的质量；推理训练或代码生成是执行手段，决定了逻辑推导的准确性。若不解决表示失真，后续推理必然失败；若不解决检索效率，长程推理无法落地。因此，该领域的范式边界清晰：GraphRAG 并非 RAG 的简单升级，而是从“向量相似度匹配”到“拓扑结构约束”的本质转变。

2020 至 2023 年是领域的奠基期，RAG 与思维链（Chain-of-Thought, CoT）奠定了方法基线。2023 年，ReAct 框架的出现标志着 LLM 开始具备与外部工具交互的能力，开启了图数据库访问的新路径。2024 年成为关键转折点，GraphRAG 等框架提出，通过构建实体关系图并分层摘要，支持全局语义检索，显著提升了多跳推理准确性。同年，Think-on-Graph 将 LLM 视为智能体，在 KG 上迭代探索，实现了自主多跳推理，标志着从静态检索向动态探索的范式跃迁。

2025 至 2026 年，研究重心进一步向基础模型化与参数内化演进。G-reasoner 提出统一图接口，结合 GNN 驱动的基础模型，实现跨域泛化；Slash 通过注意力锐化机制，无需训练即可增强 LLM 对图拓扑的内在理解。这一阶段的核心动机是解决上下文窗口限制下的长程依赖问题，并追求计算效率与跨域泛化的平衡。当前，领域处于高速活跃期，核心驱动力在于结合 LLM 的语义理解能力与图数据的结构严谨性，以解决多跳推理、事实验证及复杂决策支持中的可靠性问题。

**如果用一个核心问题概括该领域，那便是：如何在克服 LLM 上下文窗口限制与图结构线性化失真的前提下，通过动态交互机制实现高忠实度、可解释的多跳逻辑推理。**

## 2. 方法体系

- 2020：RAG——通过检索外部文档增强 LLM 生成，解决知识时效性问题，奠定后续图增强检索的基础

- 2022：Chain-of-Thought——通过提示模型生成中间推理步骤，提升复杂逻辑推理能力，成为图推理训练的核心范式

- 2023：ReAct——结合推理与行动，使 LLM 能调用外部工具，开启 LLM 与图数据库交互的新路径

- 2024：GraphRAG——构建实体关系图并分层摘要，支持全局语义检索，显著提升多跳推理准确性

- 2024：Think-on-Graph——将 LLM 作为智能体在知识图谱上迭代探索，实现自主多跳推理

- 2025：G-Retriever——利用 GNN 检索相关子图并编码为软提示，优化图-LLM 接口效率

- 2026：Youtu-GraphRAG——垂直统一代理实现图构建与检索的联合优化，支持多粒度知识推理

- 2026：Explore-on-Graph——通过路径精炼奖励建模激励 LLM 自主探索知识图谱，提升推理忠实性

这条时间线勾勒了该领域方法演进的代表性节点：从 2020 年的 RAG 奠定该领域方法基线，经 2022 年 Chain-of-Thought 的推进，到 2026 年的 Youtu-GraphRAG 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 图增强检索生成

图增强检索生成（GraphRAG）路线的核心在于利用图结构优化检索过程，以支持多跳推理并提升事实准确性。早期工作如 GraphRAG（2024）通过构建实体关系图并分层摘要，解决了传统 RAG 在关系密集任务中的逻辑断裂问题。然而，静态两阶段流程（先构建后检索）存在噪声累积问题，且难以平衡检索的相关性与结构完整性。Youtu-GraphRAG（2026）针对这一短板，设计了垂直统一代理，实现图构建与检索的联合优化。该方法通过图模式约束代理确保构建质量，并利用双感知社区检测生成多尺度知识树，将拓扑与语义相似度结合，支持不同粒度知识的并行检索。其核心取舍在于：放弃全局图的完整性，换取检索效率与上下文适配性；同时，通过联合优化消除了传统流程中的噪声累积，但代价是社区检测算法开销较大，且模式约束可能限制长尾知识捕获。

TopoRAG（2026）则从几何视角出发，引入细胞复形表示，将文本图提升为多维拓扑结构，超越传统节点-边模型。通过拓扑感知子复形检索，联合语义与拓扑相似度定位相关子图，其多维拓扑推理模块实现了跨维度的关系信息传播，增强了逻辑一致性。该方法的创新在于为结构化数据推理提供了更丰富的几何视角，提升了答案的可解释性，但代价是细胞复形构建复杂度高，且对稀疏图效果有限。RACER（2026）则构建了强化学习驱动的多智能体协作框架，通过代理间交互实现可解释推理，利用 KG 增强 LLM，将结构化关系知识作为推理锚点，减少幻觉。其代理协作机制让不同代理负责检索、验证与综合，形成闭环反馈，提升了推理过程的透明度，适用于高可靠性要求的场景，但代理通信开销大，且依赖 KG 覆盖度。

### 2.2 图推理训练方法

图推理训练方法旨在通过强化学习（RL）或微调技术，训练 LLM 掌握图导航、路径探索及多跳推理能力。Think-on-Graph（2024）首次将 LLM 作为智能体在 KG 上迭代探索，实现了自主多跳推理，但静态规划机制在复杂查询下容易陷入局部最优。Plan-on-Graph（2025）引入规划机制指导图探索，减少了无效路径搜索，提升了推理效率。然而，显式规划依赖高质量的状态估计，且在动态图环境中适应性不足。

Explore-on-Graph（2026）针对上述局限，提出路径精炼奖励建模，通过 RL 激励 LLM 在 KG 上进行自主探索。SFT 阶段赋予基础图探索能力，RL 阶段优化路径选择效率与意义。其创新在于奖励信号直接关联路径质量，而非仅最终答案，引导模型学习有效推理轨迹。该方法的取舍在于：放弃静态生成的确定性，换取动态探索的灵活性与自我修正能力；但代价是 RL 训练不稳定，且奖励设计敏感。GraphDancer（2026）引入课程 RL，逐步增加任务难度以训练 LLM 探索图结构，从单跳查询过渡到多跳推理，缓解小模型推理局限。其核心在于图感知课程设计，动态调整训练分布以匹配模型能力，使中等规模 LLM 具备复杂图推理能力，降低了部署门槛，但课程调度策略需精细调优，且训练周期较长。

KG-Reasoner（2026）构建了端到端 RL 模型，实现多跳 KG 推理的自主搜索与推理。LLM 在推理阶段多次调用搜索工具，并评估中间结果正确性，将检索与推理整合为单一决策过程，避免错误累积。GraphScout（2026）赋予 LLM 内在探索能力，通过代理式图推理实现自主导航，模型学习在图结构中主动选择路径，减少对显式规划的依赖。GRIP（2025）则通过微调 LLM 实现参数内图推理，避免复杂图-文本转换开销，将图结构直接编码为 LLM 可处理的序列，优化注意力机制以捕获拓扑关系，为高效图推理提供了轻量级方案，适用于资源受限场景，但微调数据需求大，且泛化性受限于训练分布。

### 2.3 图算法代码生成

图算法代码生成路线的核心思想是让 LLM 生成可执行代码（如 SPARQL、Cypher、Python）与图数据库交互，以解决图算法问题及结构化查询。ReAct（2023）开启了 LLM 与工具交互的新路径，但自然语言生成的推理路径看似合理却缺乏图证据支持，难以自动验证忠实性。Text-to-SQL/Cypher（2024）将自然语言转换为图查询语言，实现了结构化数据的高效访问，但在面对复杂多跳查询或模式不一致时表现脆弱。

Code-on-Graph（2026）提出迭代程序化推理框架，将图查询转化为可执行代码，实现灵活的多步操作。LLM 生成代码片段，执行后反馈结果，动态调整后续步骤。其创新在于解耦推理与计算，通过代码执行规避幻觉，提升了复杂图操作的准确性，成为图查询生成的新范式。代价是代码生成错误需调试，且依赖图数据库 API 稳定性。Learning to Refine（2025）采用代理式 RL，迭代构建与优化 SPARQL 查询，将查询生成视为序贯决策问题，优化奖励信号以引导正确查询，提升了多跳 KGQA 的查询准确性，增强了系统的自适应能力，但 RL 训练成本高，且查询空间巨大。

Multi-Agent GraphRAG（2025）设计多代理协作框架，将自然语言转换为 Cypher 查询，不同代理负责分解、生成与验证，通过协作提升查询质量，适用于企业级应用，但代理间通信开销大，且协调机制复杂。Fact Verification on KG via PGR（2025）提出程序化图推理，定义 MATCH、SEARCH、VERIFY 基本函数，实现事实验证，LLM 生成程序，执行后验证事实有效性，为 KG 事实核查提供了可靠工具，增强了 LLM 输出的可信度，但函数集有限，复杂逻辑需组合调用。

### 2.4 图结构表示编码

图结构表示编码研究如何将图拓扑结构有效编码为 LLM 可理解的表示形式，包括序列化、软提示、视觉脚手架及注意力机制优化。Graph Tokenization（2023）将图结构序列化为文本或嵌入，解决了 LLM 处理非序列数据的瓶颈，但文本线性化会丢失拓扑结构信息，导致 LLM 难以准确理解节点间的复杂关系。GNN-LLM Hybrid（2025）结合 GNN 结构编码与 LLM 语义理解，解决了纯文本序列化丢失拓扑信息的问题，但接口复杂度高。

Slash（2026）提出结构注意力锐化机制，通过离线校准与在线干预增强 LLM 对图拓扑的理解。识别拓扑敏感注意力头，应用锐化原则重分布注意力，无需训练，直接修改注意力分数，提升结构感知。该方法的创新在于为图结构理解提供了即插即用方案，提升了小模型性能，但依赖预训练模型质量，且锐化参数需精细调整。Graph Pooling Tokens（2026）研究图池化令牌在 LLM-based GraphQA 中的作用，探索单令牌与多令牌投影的权衡，揭示了图-LLM 接口的带宽限制，指出文本化与嵌入的互补性，为图编码设计提供了实证依据。

Colorful Talks with Graphs（2026）提出人类可解释的图编码，利用 Weisfeiler-Leman 细化生成结构标识符，并映射为颜色标签，将图拓扑转化为自然语言颜色描述，增强 LLM 理解，适用于需要透明推理的场景，但颜色映射可能丢失细微结构差异。Formalizing Structural Distortion（2026）分析 RoPE 位置编码在图线性化中的结构失真，提出零样本图推理的缓解策略，通过理论建模揭示位置旋转对注意力衰减的影响，优化图节点排序，为图序列化提供了理论指导，提升了零样本推理性能，但分析复杂，且依赖特定编码器。

### 2.5 跨任务与多领域应用

图推理技术正加速向垂直领域渗透，解决特定场景下的知识检索、诊断推理及系统部署问题。在医疗领域，Brittleness and Promise: KG-Based Reward Modeling（2025）将 KG 用于诊断推理奖励建模，提升 LLM 临床推理的忠实性，通过 KG 路径验证推理步骤，减少幻觉，为医疗 AI 提供了可靠推理框架，但 KG 构建成本高，且覆盖度影响效果。在科学数据管理领域，FAIR GraphRAG（2026）基于 FAIR 原则构建语义数据图，支持领域特定数据分析，每个节点建模为 FAIR 数字对象，连接元数据与本体，确保数据可发现、可访问、可互操作，提升了数据可信度，但 FAIR 标准实施复杂，需严格元数据管理。

在空间搜索领域，Graph-Enhanced LLMs for Spatial Search（2026）将图结构应用于空间搜索，通过图模式匹配解决 NP-hard 问题，LLM 将自然语言转换为空间模式，在图上执行匹配，结合 LLM 语义理解与图算法效率，提升了搜索准确性，但模式匹配计算复杂，需优化算法。在生物医学领域，fastbmRAG（2025）针对生物医学文献设计快速图 RAG 框架，优化大规模数据处理效率，利用文献结构化特征，分阶段构建知识图谱，平衡构建速度与检索质量，支持实时查询，但预构建阶段资源消耗大。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域最核心的共识在于，LLM 单独依赖参数化知识在处理知识密集型和多跳推理任务时存在显著幻觉和事实错误，必须引入外部结构化知识源（如 KG）进行 grounding。这一共识在多个基准上被反复验证：G-reasoner 的 92.75 与 Youtu-GraphRAG 的 92.75 均大幅超越经典基线 GraftNet 的 52.64，表明外部结构化知识的引入是性能提升的关键。与此相关的另一个共识是，图结构比纯文本检索更能提供显式的逻辑约束和可解释的证据链，有助于提升 LLM 推理的忠实性和准确性。子图检索被公认为连接大规模图数据与 LLM 上下文窗口的关键瓶颈，需要平衡检索的相关性、结构完整性和计算效率。

### 3.2 观点分歧

尽管共识明确，但在实现路径上存在显著分歧。首要分歧在于图结构应作为外部检索对象（GraphRAG）还是内化到 LLM 参数（Parameterized/Attention-based）。观点 A 主张外部检索，代表方法 Youtu-GraphRAG 和 G-reasoner 通过检索子图注入上下文，保持 LLM 通用性；观点 B 主张参数内化，代表方法 GRIP 和 Slash 通过微调或注意力机制内化图结构，减少接口开销。现有证据偏向外部检索，因为当前 SOTA 多为 GraphRAG 变体，且在复杂多跳任务上表现更稳定；但参数内化方法在效率上具有潜力。分歧根源在于缺乏统一评估“结构内化程度”的指标，且场景依赖性强：简单任务适合内化，复杂任务适合外部检索。

另一根本性争论是静态一次性生成是否足以应对复杂多跳推理，还是必须采用动态智能体探索。观点 A 认为静态生成即可解决多数多跳问题，效率更高；观点 B 认为必须采用 Think-Act-Observe 循环，动态调整探索路径，才能处理错误累积与路径爆炸。现有证据偏向动态探索，因为在包含“陷阱”路径或长程依赖的基准上，Agentic 方法表现更优；但静态方法在简单事实查询上无显著劣势且延迟更低。未决原因在于现有基准多基于静态快照，无法充分评估动态探索的优势，且动态探索的高延迟限制了其在实时场景的应用。

### 3.3 其他开放问题

最紧迫的工程问题是计算效率与推理延迟。复杂的图探索和多轮工具调用导致推理延迟高，难以满足实时应用需求。现状是研究通过并行检索、轻量级模型或缓存机制优化，但在保证精度的前提下进一步降低延迟仍是挑战。关键困难在于精度-效率权衡尚未解决，研究路径包括系统级优化、并行计算和内存优化。

最根本的研究问题是动态图推理与跨域泛化。现有方法多基于静态 KG，对实时变化适应不足；跨域性能衰减严重，需统一图接口或基础模型。现状是研究开始关注动态图与多模态 KG，但缺乏实时性和适应性研究。关键困难在于图结构的实时变化与多模态数据的对齐融合，研究路径包括引入时间感知机制、动态图更新策略、多模态嵌入和跨模态推理。

归纳“已知—争议—未知”认知图谱：已知外部结构化知识是缓解幻觉的必要条件，图结构优于纯文本检索；争议在于外部检索 vs. 参数内化、静态生成 vs. 动态探索；未知在于动态图推理的实时性、跨域泛化的统一机制、以及过程导向的评测标准。发展趋势将向动态、内化、多模态方向深化，评测体系需从结果导向转向过程导向。

## 4. 总结与展望

该领域的核心矛盾在于 LLM 上下文窗口限制与图结构线性化失真，导致多跳推理可靠性不足。从 RAG 到 GraphRAG，再到 Agentic 探索与参数内化，研究路线不断演进，但核心瓶颈仍未解决：如何在效率与忠实性之间取得平衡，并解决动态图与跨域泛化挑战。当前 SOTA 方法在多个基准上得分趋同（92.75），暗示现有评测体系已饱和，无法充分区分不同方法的性能差异，亟需引入更复杂的动态图基准和过程导向指标。

未来可能突破的方向包括：动态图推理，通过引入时间感知机制和动态图更新策略，适应实时变化的图结构；多模态知识图谱，整合图像、视频等多模态信息，通过多模态嵌入和跨模态推理提升知识覆盖度；小模型高效推理，通过知识蒸馏和参数高效微调，在小型语言模型上实现高效的图推理。对进入者最值得做的一件事是：构建包含“陷阱”路径和动态更新信息的图基准，测试模型的自我修正与鲁棒性，以填补当前评测体系的空白，推动领域从“能否做对”向“如何高效、鲁棒地做对”转变。
