## 导读

大语言模型（LLM）评估领域的核心矛盾，在于模型能力快速迭代与静态测量工具滞后之间的结构性错位。早期研究以构建大规模静态题库为主，通过覆盖多学科任务建立标准化排名，但这一范式隐含了题目难度固定且无数据污染的假设。随着前沿模型在通用基准上得分趋近饱和，简单平均准确率无法区分具有相同总分但不同错误模式的模型，评估的区分度与可信度同时失效。2023-2024 年成为关键转折期，研究重心从“构建基准”转向“评估基准的有效性”，项目反应理论（Item Response Theory, IRT）等心理测量学方法的引入解决了题目难度混淆问题，自适应测试与动态基准生成技术则旨在通过少量高信息量样本或实时生成题目来降低评估成本并防止过拟合。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

大语言模型评估的起源并非源于对“智能”的抽象定义，而是源于工程实践中对模型能力标准化排名的迫切需求。在 2020 年之前，评估的核心任务是“覆盖广度”，即通过构建如 MMLU 等涵盖 57 个学科的大规模静态题库，解决单一任务评估的局限性。这一阶段的问题形式化通常简化为：给定一个模型 $M$ 和一个静态题目集 $\mathcal{D} = \{x_i\}_{i=1}^N$，计算准确率 $\hat{p} = \frac{1}{N} \sum_{i=1}^N \mathbb{I}(M(x_i) = y_i)$。这种定义隐含了两个关键假设：题目是静态的测量工具，且模型在预训练阶段未见过这些题目。然而，随着模型参数规模的扩大与训练数据的爆炸式增长，这两个假设在 2023 年后相继崩塌，迫使领域重新审视评估的本体论基础。

问题定义的演化并非线性替代，而是子问题依赖关系的层层解耦。构念效度（Construct Validity）是基础，若基准未测量预期的抽象能力（如推理而非记忆），后续的高效评估与统计建模均无意义；数据污染与基准饱和是触发动态基准与自适应测试的直接约束；而统计保证则依赖于潜在能力估计模型的准确性。早期研究将“测什么”视为核心，而当前研究已转向“测得准不准”与“测得信不信”。这种转变意味着评估对象从“模型在特定任务上的表现”演变为“模型在潜在能力空间中的分布”，评估目标从“点估计”演变为“具有置信区间的区间估计”。

2016 年至 2018 年是奠基期，心理测量学中的 IRT 模型被引入教育测量领域，通过潜在能力参数与题目难度、区分度参数建模作答概率，为量化个体能力提供了超越简单准确率的理论框架。这一时期，BERTScore 等基于嵌入的语义相似度指标开始替代 BLEU 等表面形式匹配指标，解决了开放式生成任务评估中同义替换与语序变化的问题。然而，这些方法主要解决“如何计算分数”的问题，尚未触及“分数是否反映真实能力”的根本矛盾。

2020 年至 2022 年，MMLU 与 HELM 等综合性框架确立了大规模多学科评估的标准，强调评估的全面性与透明度。HELM 引入了多指标聚合与场景化评估理念，解决了单一基准无法反映模型全面能力的问题。这一阶段的方法主要作为时间锚点，为后续高效评估子集选择提供了数据基础与方法论参考。然而，静态题库的固有缺陷——即题目难度分布固定且易受污染——在这一时期已初露端倪，但尚未成为领域共识。

2023 年至 2024 年是关键转折期。LLM-as-a-Judge 的兴起解决了开放式任务人工评估的可扩展性瓶颈，但引入了评估者偏差等新挑战。与此同时，TinyBenchmarks 与 MetaBench 等工作证明了子集评估的可行性，通过结合聚类与 IRT 从大型基准中选取代表性子集，旨在以少量题目预测全量评估结果。这一转折标志着研究重心从“构建基准”转向“评估基准的有效性”，核心矛盾从“测什么”转变为“测得准不准”。

2025 年至 2026 年，领域进入精细化与理论化阶段。Continuous CAT 将计算机自适应测试扩展至连续分数场景，解决了传统 IRT 无法处理非二元输出的限制。CELEUS 与 PULSE 等最新工作引入了 e-processes 与低秩分解等统计工具，提供了任意时刻有效的置信区间与无偏顺序评估算法。这一阶段的研究聚焦于构建效度的量化、统计保证的严格性以及多智能体协同评估，旨在解决“评估危机”：如何在模型能力趋近人类水平时，以低成本、高可信度地测量其真实能力，并区分表面性能与深层认知能力。

**如果用一个核心问题概括该领域，那便是：如何在模型能力趋近人类水平且数据污染风险极高的背景下，以最低计算成本构建具有统计保证与构念效度的动态测量系统，以区分模型的深层认知能力与表面性能。**

## 2. 方法体系

- 2016：IRT (Item Response Theory)——源自教育测量学的经典统计模型，为量化个体能力提供了超越简单准确率的理论框架。

- 2018：BERTScore——基于预训练语言模型嵌入计算生成文本与参考文本的语义相似度，推动了从表面形式匹配向语义理解评估的范式转变。

- 2020：MMLU——涵盖57个学科领域的多项选择题基准，确立了大规模多学科评估的标准。

- 2021：HELM——首个综合性LLM评估框架，确立了LLM评估的系统化标准。

- 2023：LLM-as-a-Judge——利用强LLM作为评估者对开放式生成任务进行评分，解决了人工评估的可扩展性瓶颈。

- 2024：TinyBenchmarks——结合聚类与项目反应理论从大型基准中选取代表性子集，证明了子集评估的可行性。

- 2025：MetaBench——利用历史输出数据通过IRT与Fisher信息量选择判别性强的题目子集，展示了历史数据在高效评估中的价值。

- 2026：CELEUS——基于E-Processes的可证明高效LLM评估框架，提供任意时刻有效的置信区间。

这条时间线勾勒了该领域方法演进的代表性节点：从 2016 年的 IRT 奠定该领域方法基线，经 2018 年 BERTScore 的推进，到 2026 年的 PULSE 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 心理测量与统计建模

心理测量学路线的起源可追溯至 2016 年 IRT 在教育测量中的应用，其核心假设是题目具有固定的难度与区分度参数，模型具有稳定的潜在能力。这一假设在静态基准时代是合理的，但在模型能力快速迭代与题目污染风险增加的背景下，其局限性逐渐暴露。RankLLM（Zhang et al., 2026, P31）针对传统准确率排名忽略题目难度差异的问题，提出通过量化题目难度对 LLM 进行加权排名，利用二部图上的迭代分数传播来估计模型与题目的潜在属性。该方法解决了简单排名在难度混合变化时的翻转问题，但核心取舍在于迭代过程需要设定收敛阈值，且初始分数设置可能影响收敛速度。

Interpretable Scalable Framework（Qu et al., 2026, P37）进一步将二元响应矩阵建模为潜在变量乘积加偏置的形式，利用最大似然估计与主成分分析恢复参数。与 RankLLM 的迭代传播不同，该方法提供了可解释的潜在变量估计，能够识别模型弱点与题目特性，支持细粒度的能力诊断。其本质差异在于对低秩结构的显式建模，而非隐式的分数传播。然而，低秩假设可能无法捕捉所有非线性关系，且参数恢复需要足够多的观测数据，小样本下估计方差较大。

Bayes@N（Hariri et al., 2025, P8）则从贝叶斯推断的角度替代传统的 Pass@k 指标，通过计算后验概率分布来提供具有置信区间的性能估计。该方法解决了 Pass@k 在模型性能接近时排名不稳定的问题，提供了统计保证的排名置信区间。其成功依赖于先验分布的合理设定，且贝叶斯计算复杂度较高。LaRT（Xu et al., 2025, P22）引入了过程性指标，将思维链长度视为模型推理努力的代理变量，与准确率联合建模，解决了传统 IRT 仅关注二元结果而忽略推理过程的问题。这一路线与高效评估路线形成互补：心理测量模型提供理论基础与参数估计，高效评估算法则利用这些参数实现计算优化。

### 2.2 高效评估与子集选择

高效评估路线的兴起直接源于全量评估计算成本高昂的约束。LEGO-IRT（Liao et al., 2025, P7）提出一种统一的数据高效评估框架，通过整合 IRT 与多基准聚合机制，解决传统平均分数在子集评估中因题目难度混淆导致的不可靠性问题。该方法核心在于构建一个能够处理二元与连续指标、支持多基准联合评估的统计模型，通过估计模型潜在能力而非直接平均得分来消除题目难度偏差。其核心取舍是依赖历史评估数据或预校准的题目参数，对于全新基准需要额外的校准成本。

ATLAS（Li et al., 2025, P14）引入一种自适应测试框架，将 LLM 评估从静态基准转向动态能力估计，通过计算机自适应测试（CAT）机制在评估过程中实时选择信息量最大的题目。该方法克服了静态评估中天花板效应与低区分度问题，能够区分具有相同准确率但不同能力分布的模型。与 LEGO-IRT 的离线聚合不同，ATLAS 强调在线推断与动态选择，其计算复杂度随评估进程动态变化。FAQ（Wu et al., 2026, P26）进一步提出一种具有统计保证的高效 LLM 性能评估方法，利用概率因子模型从历史评估矩阵中提取潜在特征，指导自适应查询选择。该方法提供了模型无关的覆盖保证，不依赖于因子模型的正确指定，仅假设评估分数有界。

Scales++（Bean et al., 2025, P13）则放弃模型中心的历史相关性假设，转而采用题目中心的认知需求预测，利用 16 个认知维度构建题目嵌入。该方法无需历史数据即可实现冷启动评估，适用于新模型或新基准的快速评估。其核心取舍是认知维度标注需要人工或半自动介入，且预测精度依赖于认知维度与任务性能的线性相关性假设。EssenceBench（Wang et al., 2025, P9）提出一种基于遗传算法的基准压缩方法，通过粗到细的策略从大型基准中筛选出具有分数重构能力的核心集。该方法引入了元启发式搜索技术，解决了传统聚类方法在复杂语义空间中的局部最优问题，显著提升了小样本下的预测精度。SparseEval（Zhang et al., 2026, P27）则基于稀疏优化，通过端到端优化锚点权重预测器来最小化评估误差，相比传统启发式方法具有更强的全局优化能力。CELEUS（Zhou et al., 2026, P41）与 PULSE（Tolochinsky et al., 2026, P38）分别引入了 e-processes 与低秩分解，提供了严格的统计保证与无偏顺序评估算法，解决了传统评估缺乏统计保证的问题。这一路线与心理测量路线紧密耦合：高效评估算法依赖心理测量模型提供的题目参数与能力估计，而心理测量模型则通过高效评估算法实现参数的高效校准。

### 2.3 动态与自动化基准构建

动态基准构建路线的兴起源于静态题库在数据污染与基准饱和方面的固有缺陷。AutoBench（Loi et al., 2025, P11）提出一种基于互惠同伴评估的自维持 LLM 基准框架，通过模型间相互生成与评估任务实现基准的动态更新与自我进化。该方法克服了静态基准的饱和与污染问题，实现了评估内容的持续进化，无需人工干预即可保持基准的挑战性。其核心取舍是评估质量依赖于参与模型的多样性与能力上限，若所有模型共享相同偏差，共识可能强化错误。

Benchmark Everything Everywhere All at Once（Xiong et al., 2026, P39）提出一种多智能体协作的自动化基准构建框架，通过设计、接地与分配智能体将用户需求转化为具体评估任务。该方法实现了基准构建的自动化与定制化，解决了人工构建基准成本高、周期长的问题。MACEval（Chen et al., 2025, P18）提出一种多智能体持续评估网络，通过角色分配、过程数据生成与评估路由实现 LLM 的动态评估。该方法解决了静态基准的过拟合与污染问题，通过动态生成评估数据保持基准的新鲜度。OKBench（Li et al., 2025, P17）则专注于知识时效性评估，通过动态生成基于最新新闻的问题来评估 LLM 的知识时效性。Agent-Centric Text Anomaly Detection（Yoa et al., 2026, P34）将静态基准转化为动态交互环境，通过代理与环境的持续交互来生成评估数据，避免数据污染。AutoTaskEval（P46）与 BeTaL（Dsouza et al., 2025, P12）分别针对领域特定评估与基准难度控制提出了自动化框架。Encyclo-K（Liang et al., 2025, P24）通过动态组合知识陈述来评估 LLM，旨在克服静态问题集的污染与饱和问题。这一路线与审计效度路线形成互补：动态生成解决了题目时效性问题，而审计效度则确保生成题目的质量与构念效度。

### 2.4 基准审计与效度验证

基准审计与效度验证路线的兴起源于对“分数是否反映真实能力”的根本质疑。Construct Validity Framework（Bean et al., 2025, P15）提出一种系统评估 LLM 基准构念效度的框架，通过操作化抽象概念为具体任务与指标来验证基准是否测量了预期的现象。该方法提供了标准化的效度评估流程，解决了以往基准设计缺乏理论指导的问题。Judgment Noise Analysis（Feuer et al., 2025, P3）提出一种分析 LLM 评估者中判断噪声与效度缺失的方法，通过量化基准设计过程中的不确定性来诊断评估失效模式。该方法揭示了 LLM 评估者中常见的构念效度问题，如表面特征偏好与逻辑不一致。

Measurement-Theoretic Bug Detection（Truong et al., 2025, P19）提出一种基于测量理论信号检测基准中无效题目的方法，通过集成多种异常检测信号来识别标注错误或歧义题目。该方法显著优于传统的预测方差基线，能够在浅层检查中高效识别无效题目。Quantifying Construct Validity（Kearns, 2026, P32）提出一种量化 LLM 评估中构念效度的方法，通过潜在因子模型分析基准子任务与模型能力之间的统计关系。BenchBrowser（Diddee et al., 2026, P36）提出一种通过检索证据评估基准有效性的工具，将基准题目与具体使用场景进行语义匹配以验证其适用性。Benchmark Health Index（Zhu et al., 2026, P30）提出一种纯数据驱动的基准审计框架，从能力区分度、抗饱和性与影响力三个正交维度评估基准的健康状况。Competency Gaps（Bohacek et al., 2025, P23）提出一种基于稀疏自编码器的自动化方法，用于识别 LLM 及其基准中的能力差距与覆盖缺口。Benchmark Profiling（Kim et al., 2025, P5）提出一种机制性诊断 LLM 基准能力构成的方法，通过选择性消融模型中特定能力的参数来量化基准对基本能力的依赖。这一路线与动态构建路线形成互补：审计效度确保生成题目的质量，而动态构建则提供题目的时效性。

### 2.5 领域特定基准构建

领域特定基准构建路线的兴起源于通用基准在垂直场景下的适用性不足。IndicEval（Bharti et al., 2026, P33）提出一种双语印度教育评估框架，针对印度高利害教育考试构建具有生态效度与认知深度的基准。EduEval（Ma et al., 2025, P21）提出一种分层认知基准，用于评估 LLM 在中国教育场景中的能力，整合 Bloom 分类法与 DOK 深度框架。ScholarBench（P44）提出一种双语学术语境下的抽象、理解与推理评估基准。BenchMAX（P45）提出一种综合多语言评估套件，针对低资源语言与语言无关能力构建全面测试基准。Temporal Reliability Assessment（Krishnappa et al., 2026, P28）提出一种评估 LLM 在时间近期开放域问题上可靠性的方法。RADAR（Chen et al., 2025, P4）提出一种风险感知的动态多智能体框架，用于 LLM 安全评估。LigBench（Wang et al., 2026, P42）提出一种统一且人类对齐的 LLM 研究想法生成评估基准。AskBench（Zhao et al., 2026, P29）提出一种评估 LLM 澄清请求能力的基准。这一路线与通用评估路线形成互补：领域特定基准解决了垂直场景的适用性问题，而通用评估则提供了跨领域的可比性。

### 2.6 评估指标与方法论创新

评估指标与方法论创新路线的兴起源于传统指标在细粒度与解释性方面的不足。DeCE（Yu et al., 2025, P2）提出一种分解标准基于的 LLM 响应评估框架，通过将开放式回答评估分解为多个细粒度标准来提升评估的细粒度与解释性。A-VERT（Aguirre et al., 2025, P6）提出一种基于嵌入排序目标的无感知验证方法，通过比较候选回答与正确/错误回答组的语义距离来评估自由形式回答。Automated Creativity Evaluation（Tan et al., 2026, P40）提出一种跨开放式任务的自动化创意评估框架。Curriculum Learning based Hierarchical Scoring（P53）提出一种基于课程学习的分层评分与分析框架。Fluid Benchmarking Metrics（Hofmann et al., 2025, P1）提出一种基于潜在能力空间的评估指标。AutoMetrics（P51）提出一种自动生成评估指标以近似人类判断的框架。LFQA-E（P47）提出一种针对长形式问答评估的基准。ExpertLongBench（P52）提出一种针对专家级长文本生成任务的基准。这一路线与心理测量路线形成互补：新指标提供了细粒度的诊断信息，而心理测量模型则提供了统计保证与理论深度。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

传统基于平均准确率的评估方法存在严重局限，无法区分具有相同总分但不同错误模式的模型，需引入更精细的统计模型。这一共识在多个基准上被反复验证：Bayes@N 的 98% Judging Accuracy 与 RankLLM 的 90% Agreement 均大幅超越传统准确率排名，证明了潜在能力估计与题目难度加权的必要性。数据污染和基准饱和是当前 LLM 评估面临的主要威胁，导致评估结果不可信，需采用动态基准或污染检测机制。AutoBench 与 OKBench 等动态基准的兴起，以及 Benchmark Health Index 对基准健康状态的量化，均反映了这一共识。评估计算成本过高，数据高效评估（如子集选择、自适应测试）是降低评估门槛、加速模型迭代的关键方向。EssenceBench 在 k=200 时达到 0.86 RMSE，Scales++ 在 0.5% 题目下实现 <3% Error，均证明了高效评估的可行性。

与此相关的另一个共识是，构念效度是评估基准质量的根本标准，缺乏效度验证的基准即使分数高也无实际意义。Construct Validity Framework 与 Benchmark Profiling 等工作揭示了“性能-感知悖论”，即基准高分但实际能力不足的问题，强调了效度验证的必要性。静态基准已不足以反映前沿模型的真实能力，动态生成或实时更新的基准是未来趋势。AutoBench、MACEval 等动态评估框架的提出，以及 BeTaL 对基准难度的动态调整，均反映了这一趋势。评估结果需具备统计显著性，仅报告点估计而不提供置信区间或显著性检验是不严谨的。CELEUS 与 Bayes@N 等引入统计保证的工作，均强调了置信区间与显著性检验的重要性。

### 3.2 观点分歧

统计模型（IRT）与动态生成（AutoBench）哪种是解决评估危机的更优路径，是领域内的核心分歧。统计模型派认为评估的核心是“测量”，需通过统计模型估计潜在能力，提供理论保证与可解释性；动态生成派认为评估的核心是“对抗污染”，需通过实时生成题目保持新鲜度，统计模型无法解决题目本身失效的问题。现有证据偏向“互补”而非“竞争”：统计模型在静态题库上表现优异（如 EssenceBench RMSE 0.86），但无法解决污染问题；动态生成解决了污染，但缺乏理论保证（如 AutoBench 的共识排名可能强化偏差）。这一分歧的背后，是另一个更根本的争论：LLM-as-a-Judge 的可靠性。可用派认为通过多智能体集成、结构化评分量表可显著降低偏差，使其成为可扩展评估的核心；不可信派认为 LLM 评估者存在固有的自我偏好与逻辑不一致，偏差无法完全消除，仅适用于粗粒度筛选。DeCE 在法律 QA 中达到 0.80 相关性，但 Judgment Noise Analysis 揭示了设计噪声，证据偏向“有条件可用”。

### 3.3 其他开放问题

最紧迫的工程问题是动态基准的自动化生成与多语言适配。AutoBench 与 OKBench 已展示了自动化生成的可行性，但生成题目的质量难以保证，可能存在歧义或偏差。BenchMAX 与 IndicEval 等工作尝试解决多语言与文化适应性评估，但低资源语言评估需要本地化验证，可能存在偏差。最根本的研究问题是构念效度的量化定义。Construct Validity Framework 与 Quantifying Construct Validity 提出了量化效度的方法，但抽象认知能力（如推理、创造力）的定义本身存在争议，缺乏公认的“金标准”任务来验证效度。统计保证在非线性任务中的适用性也是开放问题。CELEUS 与 PULSE 提供了严格的统计保证，但其假设（如评估分数有界、低秩结构）可能不适用于所有任务。已知的是，简单平均准确率已失效，动态机制与统计模型是必要的；争议的是，哪种机制更优，以及如何量化效度；未知的是，如何在动态环境中保持测量的构念效度与统计保证的统一。

## 4. 总结与展望

LLM 评估领域的核心矛盾在于模型能力快速迭代与静态测量工具滞后之间的结构性错位。早期工作通过构建大规模静态题库解决“测什么”的问题，但 2023 年后，数据污染与基准饱和导致“测得准不准”成为核心矛盾。研究路线从心理测量、高效评估、动态构建到审计效度，层层解耦了子问题依赖关系，形成了多元并存的方法格局。核心瓶颈在于如何在动态环境中保持测量的构念效度与统计保证，即如何在模型能力趋近人类水平且数据污染风险极高的背景下，以最低计算成本构建具有统计保证与构念效度的动态测量系统。

未来可能突破的方向包括：一是动态与自适应评估的深度融合，通过在线更新题目难度与模型能力估计，解决静态基准易饱和且无法反映模型实时能力的问题；二是评估的有效性与构念效度的量化，通过基于认知科学的任务分解与机制可解释性分析，解决现有基准往往测量表面特征而非核心能力的问题。对进入者最值得做的一件事，是在统一骨干与统一预训练条件下，对代表性方法（如 EssenceBench、Scales++、AutoBench）进行公平比较，并提供置信区间与显著性检验，以填补当前评测体系的公平性缺口。
