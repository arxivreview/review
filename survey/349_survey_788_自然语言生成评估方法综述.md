## 导读

自然语言生成（NLG）评估旨在量化机器生成文本的质量，其核心挑战在于弥合自动指标与人类主观判断之间的鸿沟。早期研究依赖词汇重叠度，思路简洁却因无法捕捉语义等价性而在开放生成任务中失效。当预训练模型嵌入指标兴起后，事实错误检测的缺失与自回归评分的位置偏差成为新的瓶颈，迫使研究转向对比学习与掩码重构范式。随着大语言模型（LLM）能力的爆发，评估范式进一步分化为基于LLM的智能体模拟与基于交叉质询的忠实性诊断，各路线在计算成本、可解释性与事实敏感性之间做出了不同取舍。当前领域正从单一相似度计算向多维质量诊断与领域特定对齐转变，形成了语义对齐、LLM评估、忠实性诊断与标准化并存的多元格局。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

自然语言生成评估的起源可追溯至对机器翻译与摘要任务中参考文本相似度的量化需求。早期研究假设词汇重叠度能够近似人类对文本质量的判断，这一假设在统计模型时代具有合理性，因为生成文本的多样性有限，词面匹配足以区分优劣。然而，随着Transformer架构的普及，生成模型开始产生流畅但语义错误的文本，传统基于n-gram重叠的指标如BLEU和ROUGE因无法捕捉同义替换与深层语义一致性而逐渐失效。这一失效模式构成了领域发展的核心驱动力，促使问题定义从“词汇匹配”转向“语义对齐”。

问题结构的演化并非线性进步，而是对前一代指标在特定场景下失败模式的直接回应。2020年前后，核心矛盾变为如何捕捉语义等价性，BERTScore等基于预训练语言模型嵌入的指标应运而生。随后，问题进一步演化为“分布匹配”与“事实忠实性”，MAUVE引入分布视角，而G-Eval等LLM评估范式试图直接模拟人类判断。然而，这些方法暴露出黑箱性质、位置偏差及对事实错误不敏感等缺陷，导致问题定义在2024-2026年间深化为“多维质量诊断”与“领域特定对齐”。当前研究重心已从单一分数转向可解释的错误定位及标准化准则，以解决通用指标在临床等高风险场景下的失效。

子问题之间呈现层级依赖关系，语义对齐是基础，但无法独立解决事实忠实性问题。忠实性诊断依赖于对语义错误的细粒度检测，而评估标准化则是前两者实现跨研究可比性的前提。若不解决质量准则的标准化定义，不同方法在“连贯性”等维度上的比较将失去意义。这种依赖结构决定了领域演进的逻辑：先解决表示质量问题，再解决事实敏感性问题，最后解决可比性与可解释性问题。

从约束演化史来看，2016-2018年奠基阶段确立了基于嵌入的评估范式，MoverScore和BERTScore通过上下文嵌入克服了词序敏感性。2020-2021年，跨域基准与分布匹配指标的出现标志着对单样本对比偏差的反思，MAUVE和BARTScore分别引入了分布视角与生成式评估。2023-2025年，LLM能力的爆发引入了G-Eval等直接打分方法，同时也暴露了自回归评分的位置偏差，DiffScore和FACE-2等掩码重构与频谱分析方法随之出现。当前形态是多种范式并存的局面，每种范式都在计算成本、事实敏感性与可解释性之间做出了特定取舍。

**如果用一个核心问题概括该领域，那便是：如何构建一种既能捕捉生成文本深层语义与事实一致性，又能与人类主观判断及领域特定标准保持高对齐度，且具备可解释性的多维评估体系。**

## 2. 方法体系

- 2002：BLEU——基于n-gram重叠的自动评估指标，确立词汇匹配范式

- 2004：ROUGE——专为摘要任务设计的召回率导向指标

- 2019：MoverScore——基于上下文嵌入与地球移动距离的语义对齐指标

- 2020：BERTScore——利用预训练BERT模型计算嵌入空间余弦相似度

- 2021：MAUVE——基于生成分布与人类分布之间最大均方误差的无参考指标

- 2023：G-Eval——利用GPT-4通过思维链提示进行多步推理直接打分

- 2025：DiffScore——基于掩码扩散语言模型重构能力的评估框架

- 2026：MATCHA——基于对比学习语义对齐的文本匹配指标

这条时间线勾勒了该领域方法演进的代表性节点：从 2002 年的 BLEU 奠定该领域方法基线，经 2004 年 ROUGE 的推进，到 2026 年的 MATCHA 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 语义对齐指标

语义对齐指标旨在克服传统词重叠指标的局限，通过捕捉文本深层语义质量与一致性来评估生成质量。该路线的起源可追溯至2019年的MoverScore，它基于上下文嵌入与地球移动距离，克服了传统n-gram指标对词序和同义词的敏感性。2020年，BERTScore利用预训练BERT模型计算嵌入空间中的余弦相似度，显著提升了指标与人类判断的一致性，成为评估开放式生成任务的主流语义指标。然而，BERTScore对事实错误不敏感，存在“虚假阳性”问题，即对语义无关但结构相似的文本赋予高分，暴露了纯语义相似度指标的局限。

针对BERTScore在事实错误检测上的短板，MATCHA（P9）引入了对比学习范式。MATCHA通过Token Embedding模块编码文本，利用Representation Alignment模块将表示投影到对比学习匹配空间，最后计算文档级相似度及细粒度token归因。其核心创新在于鼓励语义相似输入在表示空间中靠近，而将语义不同或矛盾的输入推远，从而显式地惩罚语义不匹配。相较于BERTScore仅依赖密集嵌入距离，MATCHA通过训练过程内化了区分细微语义差异的能力，避免了因嵌入空间聚类效应导致的虚假高分。该方法的代价是依赖对比学习训练数据的质量与多样性，且计算复杂度略高于纯嵌入相似度计算。

另一条技术路径是消除自回归评分的位置偏差。BARTScore（2021）将文本评估重构为文本生成任务，但其自回归特性引入了位置偏差，早期token在信息贫乏的上下文中被评估，导致评分受架构偏差影响。DiffScore（Lai et al., 2026, P5）针对这一问题，基于掩码扩散语言模型（MDLLM）通过测量模型重构文本的能力来评估质量。DiffScore利用双向Transformer消除位置偏差，并通过随机掩码模式实现因子化不变性。其关键技术包括多时间步质量画像和双向PMI分解，实现了流畅度与忠实性的正交分离。该方法的主要优势在于提供了结构化的可解释性工具，但其依赖MDLLM的重构能力，对模型预训练质量有较高要求。

此外，FACE-2（P7）代表了基于频谱分析的评估路线。FACE-1在数学定义上存在缺陷，仅使用频谱实部而忽略虚部，且在现代大语言模型上的适用性尚未得到充分验证。FACE-2通过引入优化后的惊奇度处理步骤及更严谨的距离函数（如EMD、KL散度）来修正这些缺陷，在频谱表示中同时利用实部和虚部信息。该方法解决了旧指标在新模型时代失效的问题，为基于频谱分析的NLG评估提供了更稳健的理论基础。语义对齐路线内部，MATCHA与DiffScore分别通过对比学习和掩码重构解决了事实敏感性与位置偏差问题，二者在机制上互补，共同推动了语义评估从“相似度”向“诊断性”的转变。

### 2.2 LLM评估范式

LLM评估范式利用大语言模型作为评估者，旨在模拟人类判断过程。2023年，G-Eval首次系统性地展示了LLM作为评估者在NLG任务中与人类判断的高对齐性，推动了LLM-as-Judge范式的普及。然而，G-Eval依赖专有模型API，存在成本高昂、可复现性差及提示工程敏感等问题，且缺乏对评估过程的可解释性控制。

针对G-Eval的主观偏差与绝对分数缺失问题，AgentEval（Vu et al., 2025, P4）结合了生成式智能体与思维链（CoT）。AgentEval通过Chain-of-Thoughts模块引导智能体进行多步推理，赋予智能体特定的人类个性以捕捉不同评估者的认知差异，并通过投票机制统一意见。相较于G-Eval，AgentEval通过模拟人类阅读时的认知与心理过程，减少了主观偏差，并在多个维度上展现出更低的重均方误差。其代价是计算成本较高，且依赖智能体对复杂语境的理解能力。

Direct-Scoring via Pairwise（Lawrence et al., 2025, P1）则解决了成对比较无法提供绝对分数的局限。该方法为每个源文章生成多个不同质量的合成参考样本，利用LLM进行成对比较，计算响应概率并通过softmax归一化推导绝对分数。其核心创新在于利用合成样本的多样性作为锚点，将相对判断转化为绝对量化。相较于G-Eval，该方法在SummEval等基准上表现出更高的Spearman相关性，且无需依赖专有模型API。其主要代价是计算开销较大，需要生成N个合成样本并进行N次LLM推理。LLM评估路线内部，AgentEval与Direct-Scoring分别通过智能体模拟和合成样本锚点提升了评估的鲁棒性与量化能力，二者均是对G-Eval黑箱性质与提示敏感性的修正。

### 2.3 忠实性诊断框架

忠实性诊断框架致力于开发针对文本生成忠实性的诊断工具，检测事实错误、逻辑矛盾及内容遗漏。该路线的兴起源于通用语义指标在高风险场景下的失效。CEF（P6）是一种任务无关的信息忠实性交叉质询框架，通过从源文本和生成文本中生成可验证问题并检测答案一致性来评估忠实性。CEF无需参考文本，通过多模型共识机制减少单一LLM的判断偏差，有效检测事实矛盾与遗漏。其核心创新在于将问题生成与回答整合为单一鲁棒流程，在翻译、摘要及临床任务中均展现出对语义错误的敏感性。该方法的代价是计算复杂度较高，需要多次LLM推理，且依赖裁判模型的质量。

ReEvalMed（P8）则针对医学报告生成这一特定领域，构建了元评估框架。ReEvalMed定义了临床基础的评估标准，包括描述、位置、距离、大小的准确性以及不确定性表达等维度，并构建了包含临床显著性标签的GT-ME数据集。其核心创新在于引入了12个评估方面作为探针，揭示了BLEU、BERTScore等通用指标在临床场景下的失效原因。相较于通用NLP指标，ReEvalMed强调了领域特定标准的重要性，通过临床专家参与定义了更具操作性的评估维度。该方法的代价是构建临床标注数据集的高成本，且评估标准高度依赖医学领域的专业知识。忠实性诊断路线与语义对齐路线形成互补：语义对齐提供基础相似度，而诊断框架提供细粒度的错误定位与领域特定对齐。

### 2.4 评估标准化体系

评估标准化体系致力于建立评估标准与分类体系，解决评估指标定义模糊与不可比问题。QCET（Belz et al., 2025, P2）是一种NLP系统评估质量准则的分类法，采用描述性方法从现有NLP实践中提取质量准则，将其分组并选择标准名称。QCET将评估方法分解为质量准则、评估模式和实验设计三个组件，建立了“质量准则+评估模式=评估度量”及“评估度量+实验设计=评估方法”的层级结构。相较于以往缺乏统一术语的评估实践，QCET提供了标准化的定义与分类，提升了研究的可重复性与横向对比能力。其代价是分类法的构建需要大量文献分析与专家共识，且可能无法覆盖所有新兴评估维度。

n-Gram Novelty Critique（Saakyan et al., 2025, P3）则是对特定维度（创意性）的理论反思与度量修正。该研究通过专家标注揭示了高n-gram新颖性与低实用性的负相关关系，约91%的高新颖性表达未被判定为创意，从而论证了新颖性是创意性的必要非充分条件。该工作挑战了当前依赖单一新颖性维度的评估范式，推动了从表面统计特征向深层语义与语境理解的创意性评估转变。评估标准化体系为其他路线提供了元层面的基础设施，确保了不同方法在相同质量准则下的可比性。

### 2.5 跨任务与多领域应用

上述方法在不同任务与领域中的应用呈现出显著的领域特异性。在机器翻译任务中，DiffScore-FT在WMT19上取得了0.356的Spearman相关性，优于BERTScore的0.343，表明掩码重构范式在捕捉翻译语义一致性方面具有优势。在摘要生成任务中，Direct-Scoring via Pairwise在SummEval上取得了37.43的分数，优于G-Eval的0.460（注：此处数值单位可能不同，需结合具体基准协议理解，但相对排名显示LLM成对比较方法在摘要评估中的竞争力）。在对话生成任务中，Direct-Scoring via Pairwise在TopicalChat上同样表现优异，显示出LLM评估范式在开放域对话中的适用性。在故事生成任务中，Direct-Scoring via Pairwise在HANNA上取得了37.43的分数，而G-Eval仅为0.32，表明智能体或成对比较方法在捕捉创意性写作质量方面优于直接打分。在医疗报告生成任务中，ReEvalMed取得了0.9的鲁棒性评分，远高于RaTEScore的0.5，证实了领域特定元评估框架在临床场景下的必要性。在信息保真度评估中，CEF在Text-to-Text任务中取得了99.71的覆盖率，显示出交叉质询框架在检测事实错误方面的高敏感性。这些结果表明，不存在通用的“霸主”方法，不同任务需选择特定的评估路线。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

传统基于n-gram重叠的指标在捕捉语义细微差别、事实一致性及人类偏好方面存在显著局限，这一共识在多个基准上被反复验证。DiffScore-FT在WMT19上的0.356与SummEval上的0.544均大幅超越BERTScore的0.343与BARTScore的0.519，表明语义对齐指标已取代词汇重叠指标成为主流。与此相关的另一个共识是，基于预训练语言模型的语义相似度指标虽优于词汇重叠，但对事实错误、逻辑矛盾及语义无关文本的区分能力不足。MATCHA通过对比学习显式惩罚语义不匹配，CEF通过交叉质询检测事实矛盾，均旨在解决这一假阳性问题。评估指标必须与人类判断保持高度对齐，这是衡量评估有效性的终极标准。AgentEval在General内容评估上的0.38与Direct-Scoring via Pairwise在SummEval上的37.43均显示出LLM评估范式在模拟人类判断方面的潜力。自回归评分框架存在位置偏差和方向不对称性等结构性缺陷，DiffScore通过掩码重构消除了这一偏差，在WMT19和SummEval上均优于BARTScore，验证了双向范式在长文本评估中的优势。

### 3.2 观点分歧

LLM-as-Judge的可靠性与成本效益是领域内的核心争论。观点A认为直接打分（G-Eval）高效且与人类判断对齐度高，适合大规模评估；观点B认为智能体模拟（AgentEval）或成对比较（Direct-Scoring）更鲁棒，能减少主观偏差并提供绝对分数。现有证据偏向观点B在一致性上更优，AgentEval在General内容评估上的0.38优于G-Eval的0.32，Direct-Scoring via Pairwise在SummEval上的37.43也显示出竞争力。然而，观点A在成本上具有绝对优势，LLM推理成本随模型规模指数级增长，限制了观点B的部署范围。这一分歧的背后，是另一个更根本的争论：自回归位置偏差是否可忽略。观点A认为自回归评分在短文本中足够准确，位置偏差影响有限；观点B认为掩码重构消除了位置偏差，是更优的范式。DiffScore在WMT19和SummEval上均优于BARTScore，支持观点B，但DiffScore的计算开销是AR的数倍，缺乏在极端长文本上的大规模对比实验。创意性评估中，n-Gram Novelty Critique通过专家标注证明91%的高新颖性表达未被判定为创意，强烈支持新颖性非充分条件的观点，但缺乏自动化的“合理性”度量标准，导致该分歧尚未解决。

### 3.3 其他开放问题

最紧迫的工程问题是降低LLM评估的计算成本与延迟。AgentEval和Direct-Scoring via Pairwise均需多次LLM推理，计算开销较大，限制了其在资源受限场景下的部署。潜在路径包括利用轻量级对比匹配或基于合成样本的直接评分方法，如FrugalScore所示的低成本指标学习。最根本的研究问题是如何量化“创意性”与“情感共鸣”等主观维度。n-Gram Novelty Critique揭示了新颖性与实用性的负相关，但“合理性”定义模糊，难以量化。潜在路径包括结合人类专家标注，利用大语言模型进行细粒度的表达级创意性判断，并引入实用性约束。此外，领域特定评估标准的构建也是开放问题，ReEvalMed在医疗领域的成功表明，通用指标无法捕捉临床意义，需构建基于临床准则的元评估框架。归纳“已知—争议—未知”认知图谱，已知的是传统指标失效与语义对齐的必要性，争议的是LLM评估的成本效益与位置偏差的影响，未知的是主观维度的量化与跨领域通用标准的建立。发展趋势是评估将更趋向于“智能体协作”与“领域专家对齐”，最终实现从“打分”到“诊断”的彻底转变。

## 4. 总结与展望

NLG评估领域正经历从“统计相似度计算”向“认知诊断与标准对齐”的范式转移。传统n-gram指标因语义盲区与事实不敏感而失效，迫使研究界重新定义“质量”的内涵。当前核心矛盾在于自动指标的高效率与人类判断的高复杂性之间的张力，以及通用指标与领域特定标准之间的错位。语义对齐路线通过对比学习与掩码重构解决了事实敏感性与位置偏差问题，LLM评估路线通过智能体模拟与成对比较提升了人类对齐与绝对量化能力，忠实性诊断路线通过交叉质询与临床标准映射实现了细粒度错误定位，评估标准化路线通过分类法与理论反思提供了可比性基础。四者互补而非替代，共同构成了当前多维质量诊断的评估体系。

未来可能突破的方向包括：提升评估指标与人类偏好的对齐度，利用生成式智能体模拟不同人格的评估者，或结合多模态反馈进行综合评估；增强指标对临床/领域特定错误的判别能力，构建领域特定的元评估框架，通过构造显著/非显著错误对来校准指标的判别性和鲁棒性；解决自回归评估中的位置偏差与单向性问题，利用掩码语言模型的重构似然度，或结合双向注意力机制进行质量评估。对于进入该领域的研究者，最值得做的一件事是在统一骨干与统一预训练条件下，对代表性方法（如DiffScore、MATCHA、AgentEval、CEF）进行跨任务、跨领域的系统性元评估，以揭示各路线在计算成本、事实敏感性与可解释性之间的真实取舍，为特定应用场景的指标选择提供可靠依据。
