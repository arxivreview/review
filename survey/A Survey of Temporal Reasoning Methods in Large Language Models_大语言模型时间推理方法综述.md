## 导读

大语言模型（LLM）的时间推理能力旨在处理事件、时间点及时间表达式间的复杂逻辑关系，其核心价值在于弥合静态参数化知识与动态现实世界之间的本质鸿沟。早期研究聚焦于非结构化文本中 Allen 关系的抽取与标准化标注，思路清晰却受制于局部视角，难以捕捉长程依赖。当 2023 年后的基准暴露出模型在复杂时间逻辑上的系统性失败后，研究重心从外部结构抽取转向模型内在的时间感知机制与知识时效性。各路线在逻辑一致性、计算成本与实时适应性之间做出了不同取舍，由此形成当前神经符号、机制干预与动态对齐多元并存的方法格局。本综述梳理这条从静态标注到动态感知的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

时间推理（Temporal Reasoning）是语言模型理解动态现实世界的基础能力，旨在处理时间-时间、时间-事件及事件-事件之间的复杂关系。该领域的兴起源于早期自然语言处理任务对文本中时间关系抽取的需求，其核心形式化通常定义为在给定上下文 $C$ 和查询 $Q$ 下，模型需输出符合时间逻辑约束的答案 $A$，即 $P(A|C, Q)$ 需满足 Allen 区间代数等拓扑约束。这一问题的边界最初局限于静态语料下的序列标注与局部逻辑一致性，主要关注如何从非结构化文本中识别“之前”、“之后”等显式关系。随着研究深入，问题定义逐渐从“识别关系”演变为“构建无矛盾的时间图”，以解决长程依赖断裂问题。子问题之间存在强依赖关系：时间表示机制（如 Token 化）是基础，决定了推理准确性的上限；知识时效性（如截止日）是约束条件，影响实时推理的有效性；而神经符号框架则是解决复杂逻辑一致性的手段，依赖于时序抽取提供的结构化输入。

在 2003 年至 2018 年的奠基期，研究主要围绕 TimeBank 和 TempEval 等基准展开，确立了时序信息提取的标准化范式。这一阶段的方法假设时间推理可通过局部规则或序列标注解决，但受限于静态语料和缺乏统一评估标准，难以应对文档级的全局一致性挑战。2019 年 TDDiscourse 的引入标志着从句子级到文档级时序推理的范式转变，强调了全局时序结构的重要性。然而，这一时期的方法仍主要依赖外部标注数据，未能触及模型内部的时间表示机制。

2020 年至 2022 年，随着 TimeQA 等基准的出现，研究开始关注模型在处理时间敏感事实时的局限性。这一转折揭示了模型在动态知识更新上的滞后性，促使研究者关注知识截止日（Knowledge Cutoff）及时间感知能力。此时问题已转变为如何评估模型对随时间变化知识的掌握程度，而非仅仅抽取静态关系。2023 年 TempReason 和 TimeBench 的发布成为关键节点，它们系统性地评估了 LLM 在复杂时序逻辑下的表现，揭示了模型在长程依赖和区间推理上的显著缺陷，终结了“LLM 天然具备时间推理能力”的假设。

2024 年至 2025 年，领域进入“机制解释与动态交互”阶段。LLMLagBench 实证识别了 LLM 训练数据的实际时间边界，挑战了基于发布日的时间假设。TEMPO 等框架引入了严格的时序纪律约束，旨在消除前视偏差（Look-ahead Bias），确保评估结果反映真实推理而非记忆检索。这一时期，研究不再仅关注静态问答，而是深入探讨 LLM 内部的时间表示几何结构、Token 化对时间算术的影响，以及模型在实时对话中的时间感知失效问题。

当前，该领域高度活跃，研究热点集中在消除前视偏差、构建跨日历/多模态时间推理框架，以及通过神经符号方法或强化学习提升模型在动态环境中的时间一致性。核心矛盾在于静态参数化模型与动态世界本质不匹配，模型无法实时感知世界变化，导致在回答“当前”状态时产生过时信息。尽管通过检索增强生成（RAG）或知识编辑可缓解部分问题，但难以根本解决。

**如果用一个核心问题概括该领域，那便是：如何克服静态参数化模型在离散 Token 表示下的时间感知缺失，使其在动态、实时且多模态的环境中维持时间逻辑的一致性与事实的时效性？**

## 2. 方法体系

- 2003：TimeBank——奠定时序标注框架基线

- 2007：TempEval——建立共享任务基准

- 2023：TempReason——多跳时序推理数据集

- 2024：TimeR4——检索重写重排框架

- 2025：LLMLagBench——实证识别训练边界

- 2025：TEMPO——模式分离策略优化框架

- 2026：STAIR——语义-时序自动机框架

- 2026：WorldReasoner——历史预测评估框架

这条时间线勾勒了该领域方法演进的代表性节点：从 2003 年的 TimeBank 奠定该领域方法基线，经 2007 年 TempEval 的推进，到 2026 年的 WorldReasoner 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 时序基准与评测

时序基准的演进反映了问题定义从局部到全局、从静态到动态的深化。早期基准如 TimeBank 和 TempEval 聚焦于 Allen 关系的抽取，而 2023 年后的 TempReason 和 TimeBench 则强调多跳推理和细粒度诊断。SPAN（Miao et al., 2025, P7）填补了跨日历推理的空白，揭示了模型在非格里高利日历下的性能下降。TempoBench（Holzer et al., 2025, P5）引入了时序轨迹与因果性评估，支持对推理结构的细致诊断。这些基准共同确立了当前评测的多维标准，为后续方法改进提供了参照系。

### 2.2 神经符号推理框架

神经符号方法通过引入外部逻辑约束换取可解释性与一致性，但牺牲了端到端的流畅性。ODL-TempLLM（P52）利用本体引导和描述逻辑推理，将时序推理卸载到外部符号模块，显著提升了复杂时序推理的性能。STAIR（Dai et al., 2026, P43）采用规则优先原则，仅在规则失败时调用 LLM 作为后备，提升了逻辑一致性。NeSTR（Liang et al., 2025, P10）结合溯因推理处理不完整时间信息，提高了推理的可解释性。这些方法在结构化任务上表现优异，但依赖高质量本体或规则库，泛化能力受限。

### 2.3 知识时效与更新

知识时效性研究聚焦于模型参数化知识的边界与更新机制。LLMLagBench（Pęzik et al., 2025, P9）实证检测训练数据的实际截止日，揭示了声明截止日与实证边界的差异。TAS（Hossain et al., 2026, P35）通过残差流激活检测时间冲突，并在特定层注入转向信号，提供了一种无需重训练即可修复过时知识的推理时干预机制。Temporal Knowledge Drift Probe（Elbadry et al., 2026, P26）揭示了漂移在 LLM 内部表示中的独立编码，支持了基于探针的漂移检测与干预。这些方法缓解了参数化时间冲突，但无法根本解决静态参数与动态世界的不匹配。

### 2.4 时序感知与机制

时序感知研究深入探讨 LLM 内部的时间表示与计算原理。Token-Time Hypothesis（P53）揭示了 LLM 缺乏连续时间接地，无法直接感知墙钟时间。ChronoState（Siavoshian et al., 2026, P40）通过 FiLM 调制将流逝时间标量注入模型，使同一符号状态在不同时间下产生不同动作。Temporal Tokenization Strategies（Liu et al., 2025, P11）对比了混合嵌入与纯 token 化策略，揭示了时间分辨率对时序预测性能的影响。这些研究为理解模型内部时间机制提供了实证基础，强调了外部时间输入在实时任务中的必要性。

### 2.5 动态环境实时推理

动态环境推理关注 LLM 在实时约束下的决策能力。TEMPO（Zhang and Stadie, 2026, P27）通过组级模式门控区分泄漏消除与性能优化，抑制后见之明偏差。WorldReasoner（Chi et al., 2026, P31）限制工具访问仅限于预测日之前的证据，评估 LLM 代理在信息不完整条件下的因果推理能力。Real-Time Deadlines（Sehgal et al., 2026, P15）揭示了 LLM 在连续时间交互中的系统性失败，强调了时间感知在战略决策中的重要性。这些框架为可信预测评估提供了新范式，推动了 LLM 在动态环境中的实时预测研究。

### 2.6 时序数据模态推理

时序数据模态推理研究 LLM 对数值时序信号的解析与跨模态对齐。NUM2EVENT（Feng and Qi, 2025, P4）通过代理引导的提取机制，将数值波动映射到结构化事件假设。Thoth（Lin et al., 2026, P21）利用多阶段训练，将时间序列数据作为“外语”建模，实现零样本时间序列预测。TS-Haystack（Zumarraga et al., 2026, P18）通过插入“针”状事件，测试模型在长序列中定位特定活动的能力。这些方法提升了 LLM 处理非文本时序数据的能力，但多模态时间对齐仍面临挑战。

### 2.7 时序抽取与生成

时序抽取与生成关注从文本中提取时序关系及生成时序一致内容。CRAFT（He et al., 2026, P41）通过生成器-验证器闭环机制，解决临床文本中隐式时序线索导致的排序困难。TCAR-Gen（Nasir et al., 2026, P29）利用链式树推理和路径评分决策融合，确保生成内容的时序一致性。Global Zero-shot TRE（P46）在单次推理步骤中生成整个文档的时序图，利用整数线性规划强制结构约束。这些方法提升了时序信息提取的可靠性和效率，但全局一致性仍需进一步优化。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域最核心的共识是现有 LLM 在时间敏感知识问答和复杂时间关系推理上仍存在显著缺陷，且性能随评估时间远离训练截止日而下降。这一共识在多个基准上被反复验证：STAIR 的 65.1 F1 与 NeSTR 的 55.3 F1 均远低于人类水平，且 TimeBench 上 TIME 的 64.81 分数也揭示了模型在细粒度诊断上的不足。与此相关的另一个共识是时间推理不仅是语义理解问题，更是模型内部表示和架构约束问题。Token 化方式和注意力机制对时间推理性能有决定性影响，MTB 基准揭示了分词税对时序推理的负面影响，而 ChronoState 则证明了外部时间注入的必要性。

### 3.2 观点分歧

关于时间表示的可解释性，存在探针是否反映真实推理路径的分歧。观点 A 认为线性探针可以解码内部时间表示，支持基于探针的干预；观点 B 则指出探针读取的方向与模型实际推理路径正交。现有证据偏向观点 B，Readout-Mediator Angle 研究通过因果干预发现，即使探针方向被消融，模型仍能正确计算时间间隔，表明探针可能仅读取“影子”表示（支撑证据：P28）。这一分歧的背后，是另一个更根本的争论：神经符号方法是否优于纯神经方法。在结构化任务上，STAIR 和 ODL-TempLLM 显著优于纯 LLM，但在非结构化临床叙事或长对话中，纯 LLM 结合提示工程仍具竞争力（支撑证据：P43, P52, P41）。分歧根源在于缺乏统一的基准来同时评估结构化逻辑一致性和非结构化语义理解能力。

### 3.3 其他开放问题

最紧迫的工程问题是跨日历系统支持与实时工具调用的优化。SPAN 基准揭示了模型在非格里高利日历下的性能下降，而 Tic-Toc 则指出了工具使用决策与人类时间感知的错位。关键困难在于不同日历间的非线性转换与节日对齐，以及将连续时间压力转化为离散 Token 策略。最根本的研究问题是 LLM 内部“时间流形”的几何结构与时间感知的神经基础。Token-Time Hypothesis 和 ChronoState 研究表明，LLM 缺乏连续时间接地，需通过外部机制注入时间信息（支撑证据：P53, P40）。已知的是模型具备“时间锚点”，争议的是其是否具备“时间流逝感”，未知的是不同架构（如 SSM vs Transformer）的时间感知机制差异。未来趋势将指向构建具备“时间感知”的下一代 LLM，通过神经符号约束、机制干预与动态对齐的组合，弥合 Token 时间与真实时间的感知差距。

## 4. 总结与展望

时间推理领域正处于从“静态知识检索”向“动态时间感知”转型的关键期。核心矛盾在于静态参数化模型与动态世界本质不匹配，模型无法实时感知世界变化，导致在回答“当前”状态时产生过时信息。研究者们尝试了神经符号约束、机制干预与动态对齐等多种路线，但根本性的“时间感知缺失”仍未解决。Token 化离散化与静态参数化共同构成了当前时间推理的认知边界，使得模型在动态、实时且多模态的环境中难以维持时间逻辑的一致性与事实的时效性。

未来可能突破的方向包括：一是构建具备“时间感知”的下一代 LLM，通过引入连续时间接地机制，使模型能够感知墙钟时间的流逝；二是开发统一的跨日历与多模态时间推理框架，解决不同日历系统间的非线性转换及多模态时间对齐问题；三是建立严格的无泄漏评估标准，通过强化学习的时间合规训练和程序化验证，确保模型在回溯测试中不利用未来信息。对于进入该领域的研究者，最值得做的一件事是深入解析 LLM 内部时间表示的几何结构，区分“读出子空间”与“计算子空间”，为更精准的时间感知干预提供机制基础。
