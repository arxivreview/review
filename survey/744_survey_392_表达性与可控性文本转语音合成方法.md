综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Expressive%20and%20Controllable%20Text-to-Speech%20Synthesis)

## 导读

表达性与可控性文本转语音（Expressive and Controllable TTS）旨在解决语音合成中“说什么”与“怎么说”的解耦难题，其核心价值在于突破早期系统仅关注清晰度的局限，赋予机器以情感、风格与副语言特征。早期研究依赖显式韵律特征或离散标签进行控制，思路直观却受限于僵化的属性映射，难以应对开放域的自然语言指令。当零样本基准暴露出参考音频风格干扰与属性纠缠问题后，研究者引入解耦表示与流匹配技术，用架构复杂度换取属性独立操纵的精度。随着大语言模型（LLM）与强化学习的融合，控制信号从结构化标签全面转向自然语言意图，形成了当前指令驱动与高效生成并存的多元格局。本综述梳理这条从声学特征操纵到语义意图对齐的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

表达性与可控性文本转语音（Expressive and Controllable TTS）领域的兴起，源于早期系统如 Tacotron2 和 FastSpeech 仅聚焦于声学清晰度与自然度，导致合成语音缺乏对韵律、情感和说话风格的精细控制，呈现出“千人一面”的僵硬特质。这种局限使得系统无法适应个性化交互与情感化表达的需求，核心矛盾在于如何建立自然语言意图与连续声学特征之间的高保真映射。问题形式化通常定义为：给定文本序列 $X$、控制信号 $C$（如参考音频或自然语言指令）及目标说话人标识 $S$，模型需生成波形 $Y$，使得 $Y$ 在内容上忠实于 $X$，在风格上符合 $C$ 与 $S$ 的约束，即 $Y \sim p(y|x, c, s)$。这一形式化揭示了子问题的依赖关系：零样本音色克隆是基础能力，解决“谁在说”；属性解耦是中间层，解决“如何独立控制”；指令遵循是上层应用，解决“说什么意图”。若音色与风格未解耦，指令控制将因属性纠缠而失效；若缺乏长程一致性，细粒度控制在长文本中无法维持。

范式边界在 2021 至 2022 年间初步确立。FastSpeech2 引入变分适配器显式建模时长、音高和能量，解决了非自回归模型的一对多映射问题，确立了显式韵律控制的基线；VITS 则通过变分自编码器（VAE）统一声学模型与声码器，实现了高保真波形直接生成，奠定了零样本语音克隆的基础范式。这一阶段的核心假设是韵律可通过显式特征或潜在变量独立建模，但受限于非自回归架构的长程依赖不足，风格泛化能力较弱。2023 年成为关键转折，VALL-E 将 TTS 重构为基于离散音频 Token 的自回归语言建模任务，利用神经音频编解码器量化语音，通过上下文学习实现零样本克隆，开启了 LLM 驱动语音合成的新纪元。同年，PromptTTS 首次引入基于自然语言的风格提示机制，标志着控制信号从离散标签向自然语言语义的初步转变，突破了传统标签控制的局限。

2024 至 2025 年，研究重心转向指令-声学对齐与属性解耦。Parler-TTS 证明大规模弱标注数据下文本提示的有效性，推动了开放词汇控制的发展；F5-TTS 基于流匹配（Flow Matching）的非自回归架构，通过文本填充简化对齐过程，无需显式时长预测器即可实现高质量零样本合成，显著降低了推理复杂度。WeSCon 等模型进一步实现词级细粒度情感控制，解决了句内情感转换不自然的问题。这一阶段的核心约束变化在于：算力提升使得大规模预训练成为可能，而流匹配技术的成熟使得连续声学特征的高效生成成为现实，研究者开始用更强的先验换取跨域鲁棒性与细粒度可控性。

2026 年，领域迈向长程对话与通用音频生成。VIBEVOICE 采用 Next-Token Diffusion 架构，专门针对长形式多说话人播客生成，解决了长序列中的韵律漂移问题；FLEXIVOICE 结合多模态 DPO 与解耦 GRPO 强化学习，在零样本 TTS 中实现自然语言指令的灵活风格控制。当前形态表现为 LLM 与扩散/流匹配技术的深度融合，焦点集中在通过 LLM 增强指令遵循能力、实现细粒度情感与韵律控制，以及构建能够处理长文本、多说话人对话及非语言发声的通用语音合成系统。

**如果用一个核心问题概括该领域，那便是：如何建立自然语言意图与连续声学特征之间的高保真、可解耦且具备长程一致性的映射机制，从而实现“说什么”与“怎么说”的精确解耦与协同控制。**

## 2. 方法体系

- 2021：FastSpeech2——引入变分适配器显式建模韵律特征，奠定非自回归控制基线

- 2022：VITS——统一声学模型与声码器，确立零样本克隆基础范式

- 2023：VALL-E——重构为离散 Token 自回归任务，开启 LLM 驱动新纪元

- 2023：PromptTTS——引入自然语言风格提示，突破离散标签局限

- 2024：F5-TTS——基于流匹配简化对齐，提升零样本合成效率

- 2025：WeSCon——实现词级情感细粒度控制，解决句内转换不自然问题

- 2026：VIBEVOICE——采用 Next-Token Diffusion，解决长文本韵律漂移

- 2026：WAND——引入窗口注意力与蒸馏，实现长序列推理恒定复杂度

这条时间线勾勒了该领域方法演进的代表性节点：从 2021 年的 FastSpeech2 奠定该领域方法基线，经 2022 年 VITS 的推进，到 2026 年的 WAND 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 风格音色解耦

风格音色解耦是可控 TTS 的底层基础，旨在将音色、情感与内容在潜在空间分离，避免属性间的相互干扰。早期工作如 FastSpeech2 通过显式特征建模韵律，但无法实现音色与风格的独立操纵。VITS 虽确立了零样本克隆范式，但参考音频中的风格常干扰目标风格生成。ReStyle-TTS（Li et al., 2026, P18）针对这一痛点，引入解耦无分类器引导（DCFG）减少对参考音频的依赖，并训练一系列风格 LoRA 模块控制音高、情感等属性，通过正交 LoRA 融合机制组合多个 LoRA 而无相互干扰。该方法放弃了部分计算效率，换取了音色与风格的独立控制能力，解决了零样本 TTS 中参考音频风格干扰的难题。FC-TTS（Lee et al., 2026, P28）则基于系统分解的表示，利用音素序列通过音色适配器生成模糊对数梅尔频谱，随后进行风格与音色的独立控制，提供了更可靠的解耦基础。Spotlight-TTS（Kim, 2025, P15）基于 FastSpeech2 架构，通过语音感知风格提取聚焦有声区域，并修改嵌入空间中内容与韵律向量之间的角度来调整风格，有效去除内容干扰。这些方法共同构成了属性解耦的技术底座，为上层指令控制提供了可独立操纵的属性接口。

### 2.2 自然语言指令控制

自然语言指令控制是解耦表示的上层应用，旨在通过自然语言描述替代离散标签，实现开放域的风格、情感及音色控制。PromptTTS 奠定了交互范式，但早期模型在指令与声学实现之间缺乏精确映射。OV-InstructTTS（Ren et al., 2026, P17）利用大语言模型生成连接高层指令与低层声学属性的推理链，通过指令解构与属性推断两个阶段，增强了模型对复杂语义指令的理解能力，并引入副语言感知转录标注捕捉非语言线索。该方法增加了标注成本与推理链生成的计算开销，但显著提升了开放词汇场景下的控制精度。FLEXIVOICE（ICLR 2026, P34）在零样本 TTS 框架中引入基于自然语言指令的灵活风格控制机制，核心采用自回归 LLM 与流匹配两阶段架构，后训练阶段采用多模态 DPO 与解耦 GRPO 强化学习，分别针对指令遵循与生成质量进行优化。通过 LLM 辅助的情感标注与奖励模型，构建了包含情感、说话人一致性及表达力的多维奖励信号，解决了传统 TTS 中指令与声学属性对齐不足的问题。HiStyle（Zhang et al., 2025, P10）提出层次化风格嵌入预测器，将全局风格控制分解为说话人相关与风格特定的层次化预测过程，通过 PCA 可视化揭示了嵌入空间中说话人身份与情感特征的聚类模式。Bagpiper-TTS（Tian et al., 2026, P32）则代表了从专用 TTS 模块向通用多模态基础模型演进的典型路径，摒弃了传统元数据模块，转而依赖 LLM 的文本推理能力处理自然语言指令，在 6000 亿 Token 上预训练，实现了文本描述与声学实现的鲁棒对齐。

### 2.3 情感表达合成

情感表达合成聚焦于细粒度情感控制，包括句内情感转换、情感-音色解耦及高唤醒度情感生成。WeSCon（Wang et al., 2025, P8）提出两阶段自训练框架，通过动态语速控制与过渡平滑机制实现词级情感与语速的细粒度控制，解决了句内情感转换不自然的问题。其核心优势在于实现了平滑的情感过渡与动态语速变化，代价是两阶段训练流程较长。EmoInstruct-TTS（Wu et al., 2026, P31）设计双路径指令引导框架，结合自然语言语义引导与结构化情感嵌入（Emotion2embed），通过 ICE-Flow 映射指令语义到声学情感表示，实现了高唤醒度情感的稳定生成。该方法将语义规划与情感特定声学控制分离，提高了生成的稳定性与可控性。Rectifying the Emotional Flow（ACL 2026, P33）针对扩散 TTS 中高唤醒度情感生成的稳定性-表达力瓶颈，提出先验对齐与动态引导方法，通过调整先验分布与动态引导策略，平衡稳定性与表达力，避免高唤醒度情感下的伪影。Emotion-Aware Stepwise Preference Optimization（Shi et al., 2025, P9）提出后训练框架，在中间去噪步骤对齐扩散 TTS 与细粒度情感偏好，通过中间步骤的偏好优化，模型能更精确地控制情感随时间的演变。这些方法共同推动了情感 TTS 从句级控制向词级、时间步级细粒度控制的演进。

### 2.4 长文本对话合成

长文本对话合成针对多说话人对话、长音频及播客场景，研究上下文一致性、说话人切换及长程稳定性建模。VIBEVOICE（ICLR 2026, P35）采用 Next-Token Diffusion 架构与连续声学 Tokenizer，专门针对长形式多说话人播客生成，通过分离语义与声学特征建模，解决了长序列生成中的韵律漂移与说话人切换不连贯问题。DialoSpeech（Xie et al., 2025, P13）提出双说话人对话生成框架，结合 LLM 与流匹配技术，显式建模说话人轮次转换与重叠，提升了对话的自然度。Prosodic Boundary-Aware Streaming Generation（Liu et al., 2026, P22）提出韵律边界感知的流式生成方法，通过韵律边界标记解耦声学生成跨度与更广泛的韵律上下文，确保跨窗口的韵律连贯性。SwanVoice（Li et al., 2026, P30）通过强制对齐器修正标点以匹配声学停顿模式，使用特殊 Token 标注说话人轮次身份，提升了合成对话的韵律自然度。Comprehend and Talk（Cao et al., 2025, P7）提出双语言建模的 TTS 合成方法，通过语义蒸馏将语义信息注入 RVQ 的第一层，增强了 Token 的语义可理解性，提升了长序列生成的稳定性。这些方法共同构成了长文本场景下的稳定性保障体系，与短文本指令控制形成互补。

### 2.5 高效生成与加速

高效生成与加速是工程约束下的关键路线，旨在优化 TTS 推理效率，包括流式合成、低延迟架构及计算复杂度降低。WAND（Lee et al., 2026, P25）提出窗口注意力与知识蒸馏框架，将注意力机制分解为对条件 Token 的持久全局注意力与对生成 Token 的局部滑动窗口注意力，实现了计算与内存复杂度的恒定化。DiFlow-TTS（Nguyen et al., 2025, P1）提出基于因子化离散流匹配的紧凑低延迟零样本 TTS 模型，采用 FaCodec 将语音分解为韵律、内容与声学 Token，分别建模，简化了生成过程并提升了效率。ECTSpeech（Zhu et al., 2025, P12）通过简单一致性调优（ECT）实现单步语音生成，无需蒸馏，显著降低了推理延迟。ARCHI-TTS（Wu et al., 2026, P21）结合自监督语义对齐器与加速推理策略，通过在去噪步骤间重用编码器特征，大幅加速合成而不降低性能。Chatterbox-Flash（Seo et al., 2026, P29）引入块因果训练与推理，兼容流式生成，通过先验校准优化 DLM 解码，平衡质量与计算开销。这些方法为实时交互场景提供了低延迟、低内存消耗的解决方案，是其他路线落地的必要支撑。

### 2.6 跨任务与多领域应用

评估基准与指标是连接方法与应用的关键桥梁，旨在开发针对 TTS 的客观评估指标、基准数据集及自动化评估框架。SPAM（Cho et al., 2026, P19）提出针对基于提示的 TTS 的风格提示遵循度指标，自动量化合成语音对文本提示的忠实度，弥补了 MOS 评估在指令跟随任务中主观性强、成本高的缺陷。TTS-PRISM（Wang et al., 2026, P27）提出感知推理与可解释语音模型，通过分层评估模式与显式容差阈值，对发音、韵律、情感等维度进行细粒度诊断。Measuring Prosody Diversity（Yang et al., 2025, P6）提出新的韵律多样性指标，量化合成语音在音高、强度、时长等韵律特征上的分布多样性，弥补了传统 log F0 RMSE 等指标仅关注音高且与人类判断相关性弱的缺陷。VStyle（Zhan et al., 2025, P2）提出双语基准，评估口语语言模型中的语音风格适应能力，涵盖声学属性、自然语言指令、角色扮演及隐式共情四个类别。MINT-Bench（Chen et al., 2026, P26）提出综合多语言指令跟随 TTS 基准，涵盖多种语言与指令类型，评估模型对音色、风格、情感、角色等属性的控制精度。这些基准与指标为可控 TTS 研究提供了标准化的评估手段，促进了模型性能的可比性与可复现性。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

自然语言指令比离散标签更具灵活性和通用性，是未来可控 TTS 的主要控制范式，这一共识在 OV-InstructTTS 的 MOS 4.2 与 FLEXIVOICE 的 WER 2.17% 中得到了验证，表明指令驱动模型在开放域控制上具有显著优势（支撑证据：P17、P34）。零样本能力是评估现代 TTS 系统的关键指标，要求模型能从短参考音频中泛化到未见说话人，FLEXIVOICE 的 SIM 0.734 与 ReStyle-TTS 的 SIM 0.85 均大幅超越早期基线，证明了零样本克隆技术的成熟（支撑证据：P34、P18）。解耦音色与情感/风格表示对于实现独立、可控的属性操纵至关重要，ReStyle-TTS 通过正交 LoRA 融合实现了属性独立控制，其 SIM 0.85 优于未解耦的 Spotlight-TTS 的 SIM 0.79，验证了解耦策略的有效性（支撑证据：P18、P15）。

与此相关的另一个共识是，基于 LLM 的自回归架构在捕捉长程依赖和复杂语义方面优于非自回归模型，但面临推理效率挑战。VIBEVOICE 的 MOS 3.71 与 DialoSpeech 的 MOS 3.71 表明，LLM 架构在长文本场景下具有稳定性优势，但其高计算开销限制了实时应用（支撑证据：P35、P13）。流匹配（Flow Matching）已成为生成高质量连续声学特征的主流技术，F5-TTS 的 WER 0.020 与 ARCHI-TTS 的 WER 2.19% 均展示了流匹配在效率与质量上的平衡（支撑证据：P5、P21）。现有评估体系严重滞后于模型能力，SPAM 与 TTS-PRISM 的提出弥补了 MOS 评估在指令跟随任务中的缺陷，提供了客观、可复现的评估手段（支撑证据：P19、P27）。

### 3.2 观点分歧

自回归 LLM 与非自回归流匹配在架构选择上存在显著分歧。自回归 LLM 如 VIBEVOICE 擅长长程依赖与复杂语义理解，适合指令遵循与长文本；非自回归流匹配如 F5-TTS 推理效率高，生成稳定性好，适合零样本合成与实时应用。现有证据偏向流匹配在效率-质量平衡上更优，F5-TTS 的 WER 0.020 显著优于自回归模型，但 LLM 在指令遵循 MOS 上更高，OV-InstructTTS 的 MOS 4.2 表明 LLM 在语义理解上的优势。分歧根源在于测量工具盲区：缺乏统一的长文本指令遵循基准，场景依赖导致实时应用偏好流匹配，复杂交互偏好 LLM（支撑证据：P5、P35、P17）。

这一分歧的背后，是另一个更根本的争论：离散 Token 与连续特征的表示形式取舍。离散 Token 如 VALL-E 便于复用 LLM 架构，支持自回归生成，但量化损失大；连续特征如 VIBEVOICE 保真度高，无量化损失，但建模复杂。现有证据表明，连续特征在 SIM 上略优，VIBEVOICE 的 SIM 0.734 高于离散 Token 模型的 SIM ~0.65，但离散 Token 在长程依赖上更稳定。分歧根源在于证据不足：缺乏针对量化损失对细粒度情感影响的定量研究，场景依赖导致实时流式偏好离散 Token，高保真偏好连续特征（支撑证据：P35、P34）。

### 3.3 其他开放问题

最紧迫的工程问题是实时性与计算效率矛盾。自回归模型存在高延迟和内存瓶颈，WAND 的窗口注意力与知识蒸馏策略实现了计算与内存复杂度的恒定化，但可能损失部分长程依赖信息。研究路径包括通过蒸馏、量化或流式架构优化，在保持质量的同时实现低延迟、低内存消耗的实时流式合成（支撑证据：P25、P29）。最根本的研究问题是细粒度控制的缺失。现有模型多支持句级或全局控制，难以实现词级或句内动态的情感与语速变化，WeSCon 的词级控制虽有效，但依赖两阶段训练流程。研究路径包括通过强化学习、对比学习或推理链机制增强文本-声学对齐，解决语义与声学解耦难题（支撑证据：P8、P17）。

已知—争议—未知认知图谱显示，领域在零样本克隆、属性解耦与指令遵循上已形成共识，但在架构选择、表示形式与解耦策略上存在争议，而长程一致性、多语言泛化与自动评估指标仍是未知领域。发展趋势将向 LLM 与流匹配/扩散技术的深度融合演进，核心在于如何在保持高效推理的同时，实现自然语言指令的细粒度、长程一致性及属性解耦控制。

## 4. 总结与展望

表达性与可控性文本转语音合成领域已从声学特征操纵演进为语义意图驱动的生成范式，核心矛盾在于指令遵循的精确性与生成效率/稳定性之间的平衡。早期方法通过显式韵律建模与离散标签控制解决了基础自然度问题，但受限于属性纠缠与长程依赖不足。VALL-E 与 PromptTTS 开启了 LLM 驱动的新纪元，F5-TTS 与 WeSCon 通过流匹配与细粒度控制提升了效率与表达力，VIBEVOICE 与 FLEXIVOICE 则通过长文本稳定性与强化学习对齐解决了长程一致性与指令鲁棒性问题。核心瓶颈在于如何建立自然语言意图与连续声学特征之间的高保真、可解耦且具备长程一致性的映射机制，这一瓶颈制约了通用语音交互的实现。

未来可能突破的方向包括：实现细粒度、组合式及开放词汇的指令遵循控制，通过强化学习、对比学习或推理链机制增强文本-声学对齐，解决语义与声学解耦难题；提升长语音生成的稳定性与情感连贯性，引入全局-局部层级建模、上下文感知机制及流式推理优化，以支持播客、有声书等长场景下的自然表达；开发自动化、可解释且符合人类感知的评估指标，研发基于大音频语言模型（LALM）的自动评估器，以及针对韵律多样性、情感保真度的细粒度客观指标。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，构建长文本指令遵循的标准化基准，以消除架构选择与数据规模带来的偏差，为方法比较提供公平依据。
