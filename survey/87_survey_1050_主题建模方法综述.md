## 导读

主题建模旨在从高维稀疏文本中挖掘潜在语义结构，其核心价值在于将非结构化数据降维为可解释的低维主题空间。早期研究以潜在狄利克雷分配（Latent Dirichlet Allocation, LDA）为基石，确立了基于词袋假设的概率生成框架，思路严谨却受制于静态词频统计的语义缺失。当预训练语言模型暴露出上下文语义的丰富性后，研究者转向神经主题模型（Neural Topic Models, NTM）与嵌入聚类，用更强的语义先验换取对短文本和复杂语料的鲁棒性。随着大语言模型（Large Language Models, LLM）的介入，领域重心进一步向语义推理与人类对齐倾斜，形成了概率生成、嵌入聚类与 LLM 驱动并存的多元格局。各路线在语义深度、结构稳定性与计算成本之间做出了不同取舍，由此塑造了当前算法中心向 LLM 中心过渡的活跃阶段。本综述梳理这条从统计共现到语义推理的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

主题建模的起源源于对大规模非结构化文本中潜在语义结构的挖掘需求，其核心驱动力在于将高维稀疏文本降维为可解释的低维主题空间。在形式化定义上，经典主题建模通常被表述为 $N$-way $K$-shot 的变体或概率生成过程：给定语料库 $\mathcal{D} = \{d_1, ..., d_M\}$，模型旨在推断每个文档 $d_m$ 的主题混合分布 $\theta_m$ 以及每个主题 $k$ 的词分布 $\phi_k$，使得 $p(w|d) = \sum_k \theta_{mk} \phi_{kw}$ 最大化。这一框架建立在词袋（Bag-of-Words, BoW）假设之上，即忽略词序和上下文，仅依赖词共现统计。然而，BoW 假设的根本局限在于无法捕捉语义相似性，导致在短文本或专业领域文本中，主题发现往往不稳定且缺乏连贯性。

随着数据形态从长文档向短文本（如推文、标题）和流式数据（如新闻流、社交媒体）扩展，问题定义发生了显著演化。早期研究聚焦于静态文档级的主题分布估计，而当前研究则必须应对短文本稀疏性、动态主题演化以及多主题文档中的主题污染问题。子问题之间呈现出严格的依赖关系：语义表示的质量是基础，决定了后续聚类或推断的上限；短文本稀疏性和动态演化是特定场景下的子问题，依赖于基础表示能力的提升；而可解释性与人类对齐则是贯穿始终的评估与优化目标，随着范式从统计转向语义，其重要性日益凸显。这种依赖结构意味着，任何单一维度的改进（如仅优化聚类算法）若缺乏底层语义表示的支持，其效果将受到严格限制。

领域的约束条件经历了三次关键转折，每一次都重塑了方法的设计逻辑。2016-2018 年间，计算效率与推断精度是主要瓶颈，LDA 的采样推断在大规模数据上成本过高，促使研究者引入变分自编码器（Variational Autoencoder, VAE）和预训练词嵌入，确立了神经主题模型范式。2020-2022 年间，跨域基准和短文本场景暴露出传统模型在语义稀疏性上的失效，BERTopic 等基于嵌入的聚类方法通过利用 Sentence-BERT 等强大预训练模型，以“嵌入+聚类”的工程范式取代了端到端的概率推断，解决了短文本主题发现不稳定的问题。2023-2025 年间，LLM 的崛起引入了新的约束：如何在保持主题结构稳定性的同时，利用 LLM 的推理能力提升人类对齐度？这一约束变化催生了 LLM 辅助和 LLM 中心两种新路线，前者将 LLM 作为后处理或引导模块，后者则直接通过提示工程生成主题结构。

当前领域处于“算法中心”向“LLM中心”过渡的活跃阶段，研究热点集中在解决短文本稀疏性、动态主题演化、多模态/侧信息融合以及评估指标与人类判断的对齐问题。传统概率模型、嵌入聚类模型与 LLM 驱动模型并存，形成了多元竞争格局。这种格局并非简单的替代关系，而是不同约束条件下的最优解：概率模型在可解释性和理论保证上仍有优势，嵌入聚类在工程实用性和短文本处理上表现卓越，LLM 驱动方法则在语义深度和人类对齐上具有不可替代的价值。理解这一格局，需要追溯问题定义如何随数据形态和计算范式升级而演化，以及各路线如何在语义深度与结构稳定性之间做出取舍。

**如果用一个核心问题概括该领域，那便是：如何在保持主题结构可解释性与统计稳定性的前提下，利用语义理解能力（从词嵌入到大模型推理）突破词袋假设，实现从静态共现到动态、细粒度且符合人类认知的语义结构发现。**

## 2. 方法体系

- 2003：LDA——通过潜变量框架将文档表示为主题混合分布，确立了主题建模的概率基础

- 2017：ProdLDA——利用变分自编码器重构LDA，解决了传统采样推断效率低下的问题

- 2020：ETM——在共享嵌入空间中联合嵌入文本和主题，突破了词袋假设的限制

- 2022：BERTopic——结合Sentence-BERT嵌入、UMAP降维、HDBSCAN聚类，成为短文本主题建模的主流基线

- 2023：TopicGPT——利用大语言模型在推理时通过提示工程发现主题，开启了LLM辅助主题建模的新范式

- 2024：FASTopic——通过最优传输对齐预训练文档嵌入与可学习主题/词嵌入，实现了SOTA性能

- 2025：Attention-Informed NTM——聚合LLM生成时的注意力状态以恢复文档-主题分布，实现了黑盒LLM的可解释主题建模

- 2026：SemEval-STM——提出基于片段的主题分配基准，解决文档级模型在多主题长文本中的主题污染问题

这条时间线勾勒了该领域方法演进的代表性节点：从 2003 年的 LDA 奠定该领域方法基线，经 2017 年 ProdLDA 的推进，到 2026 年的 SemEval-STM 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 神经主题模型优化

神经主题模型（NTM）的起源可追溯至 2017 年 ProdLDA 对 LDA 的变分自编码器重构，其核心动机是解决传统采样推断在大规模数据上计算效率低下的问题。ProdLDA 通过编码器近似后验分布，放弃了纯概率模型的简洁性，换取了推断速度的显著提升。随后，ETM（Embedded Topic Model）在 2020 年进一步引入预训练词嵌入，在共享嵌入空间中联合嵌入文本和主题，突破了词袋假设的限制，实现了从统计共现到语义相似的范式转移。这一阶段的方法主要聚焦于架构改进，通过融合上下文信息或语义嵌入提升主题质量。

本批论文中的神经主题模型优化工作延续了这一脉络，但更加强调多源信息融合与训练稳定性。CGTM（Contextual and Graph Topic Model）（P23）针对现有模型难以捕捉核心信息且主题内部不一致的问题，提出融合上下文信息与图信息的神经主题模型。该方法通过主题对齐模块将 TF-IDF 表示与 BERT 表示进行融合，利用 SBERT 生成主题嵌入，并通过图信息融合模块调整词嵌入以反映语料库中的词关系。其核心创新在于同时利用稀疏的 TF-IDF 特征和稠密的上下文嵌入，并通过图结构约束词分布，从而生成更具信息量和连贯性的主题。该方法放弃了单一表示的简洁性，换取了对局部语义和全局结构的综合捕捉。其代价是模型架构复杂，训练过程需要同时优化多个损失函数。该方法在多个基准上显著优于 FASTopic 等 SOTA 模型，证明了多源信息融合在提升主题质量方面的有效性。

Multi-Surrogate-Objective Optimization（P25）则针对神经主题模型中多个损失函数量级差异大导致超参数调优困难的问题，提出一种独立于硬参数共享架构的多目标优化方法。该方法不直接应用传统的基于梯度的多目标优化算法，而是通过代理目标优化策略来平衡重构损失、KL 散度和嵌入聚类正则化等目标。其核心创新在于解决了不同损失分量在优化过程中的冲突，避免了直接 MOO 应用可能导致的次优结果。该方法假设各损失函数之间存在可优化的权衡关系，通过代理机制实现稳定收敛。其代价是引入了额外的优化层，增加了训练的计算复杂度。该方法在多个基准数据集上显著提升了基线模型的性能，为神经主题模型的训练稳定性提供了新的优化范式。

Semantically-Grounded Soft Label Distributions（P12）针对传统神经主题模型重建目标基于词袋分布导致语义信息丢失的问题，提出使用语义接地的软标签分布作为重建目标。该方法利用 LLM 生成语义概率分布，替代传统的词频率向量，作为解码器的重建目标。其核心创新在于将语义信息直接注入训练目标，使得模型学习到的主题分布不仅反映词共现，还反映语义相似性。该方法放弃了词袋假设的统计严谨性，换取了更强的语义连贯性。其代价是依赖 LLM 生成软标签，增加了数据预处理成本，且软标签的质量直接影响模型性能。该方法在多个数据集上显著提升了主题连贯性和纯度，证明了语义引导在神经主题建模中的关键作用。

DARTOPIC（P19）针对预训练语言模型在领域偏移下主题连贯性下降的问题，提出基于上下文 token 级语义图表示的领域无关神经主题模型。该方法构建 token 级语义图，节点表示由冻结的 PLM 初始化，并与主题推断目标联合优化，直接从目标数据中学习语料库自适应表示。其核心创新在于不依赖领域特定预训练，而是通过图结构动态调整表示，以捕捉领域关键术语的几何关系。该方法放弃了 PLM 的固定表示，换取了对新领域的快速适应能力。其代价是图构建和联合优化增加了计算开销，且对图结构超参数敏感。该方法在生物医学和法律文本等专用领域显著提升了主题连贯性，为领域自适应主题建模提供了无需大规模预训练的解决方案。

nnLDA（P5）针对传统 LDA 无法有效利用辅助信息（如元数据、用户属性）的问题，提出神经增强 LDA 方法。该方法将文档表示为文本和辅助特征的联合，利用神经网络推断文档-主题分布，并允许主题生成过程受辅助信息条件化。其核心创新在于通过高维摘要从侧数据中分配高概率给具有相似侧信息特征的未观察文档，实现了文本与结构化信息的深度融合。该方法放弃了 LDA 的线性假设，引入了非线性推断能力。其代价是模型复杂度增加，且需要辅助信息的可用性。该方法在包含丰富元数据的语料库中显著提升了主题预测准确性，为多模态主题建模提供了新的概率框架。

LGNTM（P21）针对无监督主题模型难以对齐人类预定义标签的问题，提出标签引导的神经主题模型。该方法将标签作为人类定义的锚点，通过标签先验和软标签-主题指示器鼓励标签-主题一致性。其核心创新在于不仅预测标签，还直接利用标签信息引导主题推断，确保生成的主题与预定义类别语义对齐。该方法放弃了完全无监督的探索性，换取了与用户意图的一致性。其代价是依赖标签的可用性和质量，且标签覆盖不全时可能引入偏差。该方法在政策分析和新闻分类等应用中显著提升了主题的可解释性和实用性，为半监督主题建模提供了新的技术路径。

神经主题模型优化路线与聚类与结构发现路线存在互补关系：前者通过端到端训练优化语义表示，后者则依赖预训练嵌入进行后处理聚类。前者在语义连贯性上通常更优，但训练成本更高；后者在工程实用性上更具优势，但缺乏生成式解释。

### 2.2 聚类与结构发现

聚类与结构发现路线的奠基可追溯至 2022 年 BERTopic 的提出，其核心动机是解决传统模型对超参数敏感及主题粒度控制问题。BERTopic 结合 Sentence-BERT 嵌入、UMAP 降维、HDBSCAN 聚类及 c-TF-IDF 关键词提取，成为短文本主题建模的主流基线。这一路线的核心假设是，预训练语言模型已经提供了足够强大的语义表示，主题发现可以简化为嵌入空间中的聚类问题。

Topeax（P11）针对 Top2Vec 和 BERTopic 对超参数敏感且关键词提取忽略语义距离的问题，提出基于密度峰值检测和词汇-语义术语重要性的聚类主题模型。该方法通过密度估计峰值自动确定聚类数量，避免手动设置超参数。在术语重要性估计中，结合词汇频率和语义距离，生成更连贯且多样化的主题关键词。其核心创新在于自动化聚类数量选择和综合术语评分机制。该方法放弃了固定聚类数的假设，换取了对语料库自然结构的自适应。其代价是密度峰值检测计算复杂，且对嵌入质量敏感。该方法在多个数据集上优于基线模型，且对样本大小变化更稳健，为聚类主题建模提供了更可靠的自动化方案。

CobwebTM（P24）针对终身主题建模中灾难性遗忘和固定主题容量的问题，提出基于概率概念形成的终身层次主题模型。该方法利用 Cobweb 算法的变体，维护每个概念节点的多变量高斯统计量，通过类别效用指导在线构建和重构概念层次。其核心创新在于结合预训练神经表示和增量符号概念形成，支持多粒度主题表示和动态重构。该方法放弃了固定主题数假设，允许主题结构随数据增长而演化。其代价是层次构建计算开销大，且类别效用阈值需要调优。该方法在流式数据中保持了主题稳定性和高质量层次结构，为终身学习主题建模提供了符号-神经混合范式。

MSTML（P8）针对传统主题模型忽略文档网络关系信息的问题，提出多尺度几何方法捕捉关系主题对齐。该方法将主题流形学习与层次网络模型结合，利用 LDA 主题向量作为节点嵌入，通过 Hellinger 距离进行凝聚聚类构建主题树。其核心创新在于利用共著网络等关系信息约束主题几何结构，实现主题在时间和关系空间的对齐。该方法假设文档关系反映主题相似性，通过层次树捕捉多尺度主题结构。其代价是依赖关系网络的可用性，且聚类过程计算复杂。该方法在引文网络分析中提升了主题对齐的准确性，为关系感知主题建模提供了几何方法。

PRISM (Prior from Statistics)（P15）针对外部知识注入方法在异构数据中不稳定的问题，提出基于语料库统计先验的主题模型。该方法仅依赖目标语料库的统计模式，通过图结构推断主题，不依赖预训练表示或专家资源。其核心创新在于利用语料库内在统计特性构建先验，确保在缺乏外部知识时的鲁棒性。该方法放弃了外部语义引导，换取了对数据分布的自适应。其代价是可能忽略领域常识，且统计估计受噪声影响。该方法在单细胞基因表达等生物医学应用中展现了稳定性，为无外部知识场景的主题建模提供了纯统计解决方案。

Semantic Component Analysis（P22）针对 BERTopic 假设单主题文档导致多主题短文本分析不足的问题，提出引入多主题分布的聚类主题模型。该方法在聚类序列嵌入后，对残差嵌入进行迭代分解，发现额外主题，从而支持每个样本的多主题表示。其核心创新在于通过残差分解捕捉主聚类之外的语义模式，降低噪声率。该方法放弃了单主题假设，换取了对复杂语义结构的全面捕捉。其代价是迭代分解增加计算时间，且主题数量可能膨胀。该方法在推文等短文本中发现了更多细微主题，显著提升了主题多样性和覆盖率，为多主题短文本分析提供了新工具。

聚类与结构发现路线与神经主题模型优化路线存在竞争关系：前者依赖预训练嵌入的强大表示能力，后者则通过端到端训练优化表示。前者在短文本和噪声文本上表现更优，但缺乏生成式解释；后者在语义连贯性上通常更优，但训练成本更高。

### 2.3 动态与在线主题建模

动态与在线主题建模路线的奠基可追溯至 2025 年 SB-ETM 的提出，其核心动机是解决在线文档流中主题追踪困难的问题。SB-ETM 结合连续最优传输映射主题嵌入，支持在线文档流的增量分析与新主题检测。这一路线的核心假设是，主题在时间上具有连续性，可以通过传输距离衡量变化。

Dynamic Topic Evolution with Temporal Decay（P3）针对传统主题模型静态假设无法捕捉时间变化的问题，提出基于时间感知 LLM 的动态主题演化框架。该方法首先利用 LLM 获取文本的上下文嵌入，然后引入时间衰减函数和注意力机制，根据时间间隔调整语义单元的重要性。随后将时间表示映射到潜在主题空间，应用状态转移矩阵描述主题动态演化。其核心创新在于统一建模语义表示和时间演化，通过联合优化目标约束语义建模和时间一致性。该方法放弃了静态主题假设，引入了时间维度的动态性。其代价是时间衰减参数和状态转移矩阵需要仔细调优，且计算复杂度随时间步长增加。该方法在金融和舆情监测领域有效捕捉了主题的生成、扩张和衰退过程，提升了长期趋势预测能力。

Higher-Order Hypergraphical DTM（P18）针对传统动态主题模型忽略词重复强度信号的问题，提出基于高阶超图表示的动态主题模型。该方法引入 H-Multinomial 分布，分离词出现概率和重复强度，并通过低秩分解共享主题结构。其核心创新在于将重复强度作为独立信号建模，与出现概率互补，从而更细致地捕捉主题语义。该方法假设主题语义随时间平滑演化，文档-主题比例可自由变化。其代价是模型参数增加，推断过程复杂。该方法在科学文献追踪和医疗记录分析中提升了主题演化的解释力，为动态主题建模提供了更精细的概率框架。

SB-ETM with Continuous Optimal Transport（P4）针对在线文档流中主题追踪困难的问题，提出结合连续最优传输的棒断嵌入主题模型。该方法在每个时间步生成主题嵌入，并通过最优传输映射将当前时间步的主题嵌入对齐到前一时间步的潜在空间。其核心创新在于利用传输映射保持主题在时间维度上的几何一致性，从而检测新主题和追踪演化。该方法假设主题在时间上具有连续性，通过传输距离衡量变化。其代价是传输映射计算开销大，且对初始主题嵌入质量敏感。该方法在流式数据分析中实现了高效的增量主题更新，为大规模实时主题监控提供了理论基础。

DVI-DTM（P28）针对短文本动态主题建模中语义模糊的问题，提出双视图表示学习的动态主题模型。该方法同时构建句子视图和术语视图的嵌入，并通过互信息对齐和一致性约束融合两种视图。其核心创新在于利用 LLM 的语义推理能力解决短文本信息碎片化问题，同时保持动态主题追踪的稳定性。该方法放弃了单一视图的简洁性，换取了对局部词义和全局句义的全面捕捉。其代价是双视图计算开销增加，且对齐约束需要精细调节。该方法在新闻标题和推文等短文本动态分析中显著提升了主题连贯性和演化追踪准确性，为短文本动态建模提供了新范式。

BERTilda（P20）针对动态主题模型缺乏对主题生命周期事件（分裂/合并）显式建模的问题，提出基于相似性和流时间图的 BERT 主题生命周期追踪方法。该方法在每个时间窗口独立发现主题，然后利用语义相似性和双向覆盖率（文档流出/流入）信号链接相邻窗口的主题。其核心创新在于引入双向覆盖率作为可解释的流信号，通过透明规则标记延续、分裂、合并等事件，构建时间主题图。该方法放弃了平滑演化假设，允许主题结构的突变。其代价是规则设计依赖领域知识，且图构建计算复杂。该方法在政治传播分析中有效识别了叙事分裂和合并事件，为理解注意力转移提供了细粒度的解释工具。

Online Tensor LDA（P6）针对大规模政治文本分析中传统 LDA 可扩展性差的问题，提出具有理论保证的在线张量 LDA 方法。该方法利用谱分解理论，通过去均值和批处理数据估计主题模型参数，支持实时增量更新。其核心创新在于结合张量分解的数学性质和在线学习机制，实现了线性可扩展性和参数恢复保证。该方法假设数据生成过程符合 LDA 模型，且满足正则性条件。其代价是理论假设较强，对数据分布敏感。该方法在超过 10 亿文档的政治语料库中实现了高效分析，为大规模政治科学文本挖掘提供了可靠工具。

动态与在线主题建模路线与静态主题建模路线存在互补关系：前者适用于时间序列数据，后者适用于静态语料库。前者在捕捉主题演化方面具有优势，但计算复杂度更高；后者在理论保证和计算效率上更具优势，但无法反映主题随时间的变化。

### 2.4 LLM驱动主题建模

LLM 驱动主题建模路线的奠基可追溯至 2023 年 TopicGPT 的提出，其核心动机是利用大语言模型的推理能力进行主题标签生成、聚类引导及动态演化追踪。TopicGPT 利用大语言模型在推理时通过提示工程发现主题，开启了 LLM 辅助主题建模的新范式。这一路线的核心假设是，LLM 的常识推理能力能够弥补传统模型在可解释性和人类对齐上的不足。

Attention-Informed Interpretable Structure（P2）针对黑盒 LLM 缺乏内部对齐信号的问题，提出在 LLM 生成主题时聚合 token 级注意力状态至片段级，从而恢复类似神经主题模型的文档-主题分布和主题-词分布。该方法无需修改模型架构，仅通过前向推理中的注意力机制提取结构化信息，使得 LLM 生成的主题具备可解释性。其核心创新在于将 LLM 的隐式语义建模转化为显式的概率向量表示，解决了传统 LLM 主题建模中主题与文档对应关系缺失的难题。该方法依赖于 LLM 在生成过程中对输入文档的注意力分配，假设注意力权重能够反映语义相关性。尽管提升了可解释性，但该方法受限于 LLM 的上下文窗口长度，且注意力聚合策略对主题粒度敏感，需要精细调整 Top-K 参数以平衡精度与噪声。

PRISM（P16）为了解决嵌入模型在细分主题上缺乏局部精度的问题，提出了一种由 LLM 引导的语义聚类框架。该方法首先采样语料库项目，查询教师模型（大型嵌入或生成模型）提供相似度标签，构建微调数据集。随后利用该数据集微调一个小型、可本地部署的学生模型，使其适应特定领域的语义表示。微调后的学生模型对语料库进行编码，并结合教师模型生成的标签优化聚类阈值，使用阈值化聚类算法分组。这种师生蒸馏机制既保留了大模型的语义理解能力，又通过小模型实现了高效推理。其代价是训练阶段需要教师模型的高昂推理成本，且阈值优化依赖于标签质量。该方法在公共安全等敏感领域的高精度叙事发现中展现了显著优势，为领域自适应主题建模提供了新路径。

LLM-Assisted Topic Reduction（P1）针对社交媒体短文本噪声大、传统模型效果差的问题，结合 BERTopic 的主题生成能力与 LLM 的语义推理能力进行主题缩减。首先使用 BERTopic 默认配置生成初始主题集合，通过调整 HDBSCAN 参数探索主题粒度。随后利用 LLM 为每个主题生成简洁标签或提取关键词，构建主题表示。在迭代缩减循环中，提示 LLM 识别语义重叠度最高的两个主题，执行合并操作并更新所有主题表示。该方法利用 LLM 的常识推理能力解决聚类产生的冗余主题问题，提升了主题的可读性和一致性。其局限性在于迭代合并过程计算开销较大，且合并决策完全依赖 LLM 的判断，可能存在幻觉风险。该方法为短文本主题建模提供了后处理优化的有效范式，显著降低了人工解读成本。

MALTopic（P10）针对传统主题模型忽略结构化数据且主题抽象难懂的问题，提出多智能体 LLM 主题建模框架。该框架将主题建模分解为多个专业化任务，由不同的 LLM 智能体执行。丰富智能体利用结构化调查数据增强文本响应，主题建模智能体提取潜在主题，去重智能体精炼结果以消除冗余。这种分工协作机制使得模型能够原生整合分类变量和自由文本，生成更具上下文相关性和人类可读性的主题。其核心优势在于能够处理混合类型数据，弥补了纯文本模型的不足。代价是多个智能体间的通信与协调增加了系统复杂度和推理延迟。该方法在调查数据分析中显著提升了主题连贯性和多样性，为复杂数据场景下的主题建模提供了模块化解决方案。

Towards Modern Topic Models Survey（P27）系统梳理了从算法中心到 LLM 中心主题建模的范式转变。该综述将现有方法分为算法中心、LLM 辅助和 LLM 中心三类，详细分析了各范式的优缺点。在 LLM 辅助设置中，LLM 被注入数据增强、表示、推断和评估等环节以提升性能，但整体框架仍由传统算法驱动。在 LLM 中心设置中，LLM 直接通过提示工程生成主题结构，替代了传统的聚类或概率推断步骤。该综述指出，虽然 LLM 能生成人类对齐的主题，但存在幻觉和不稳定性问题，而传统方法在部署和精确性上仍有优势。它强调了混合方法（如 LLM 后处理主题词表）在平衡可解释性与稳定性方面的潜力。该综述为领域研究者提供了清晰的技术路线图，指出了未来结合 LLM 语义能力与传统模型结构约束的研究方向。

LLM 驱动主题建模路线与其他路线存在互补关系：前者在可解释性和人类对齐上具有优势，但引入了幻觉和不稳定性问题；其他路线在结构稳定性和计算效率上更具优势，但缺乏语义深度。混合方法（如 LLM 后处理）成为解决这一矛盾的主流路径。

### 2.5 跨任务与多领域应用

评估与应用实践路线的奠基可追溯至 2026 年 SemEval-STM 的提出，其核心动机是解决文档级模型在多主题长文本中的主题污染问题。SemEval-STM 提出基于片段的主题分配基准和评估框架，将主题分配粒度从文档细化到片段，评估模型隔离特定主题内容的能力。这一路线的核心假设是，细粒度主题建模需要更精细的评估标准。

GCTM-OT（P17）针对传统主题模型无法适应用户特定分析目标的问题，提出目标提示对比学习与最优传输结合的人本主题模型。该方法首先利用 LLM 根据用户目标生成文档摘要，提取目标相关短语。随后通过对比学习优化文档表示，并利用最优传输对齐目标簇与主题表示。其核心创新在于将用户意图显式融入主题发现过程，通过 OT 确保主题与目标语义对齐。该方法放弃了纯统计连贯性目标，换取了与用户意图的一致性。其代价是依赖 LLM 摘要质量，且 OT 计算复杂。该方法在用户驱动分析中显著提升了主题的相关性和可解释性，为人本主题建模提供了新范式。

Human-Metric Alignment（P13）针对自动评估指标与人类判断不一致的问题，提出在哲学科学语料库上系统评估主题模型人机对齐的研究。该研究比较了多种自动指标（如 NPMI、Cv）与人类评估（如词入侵）的相关性，揭示了指标在不同领域和主题类型上的偏差。其核心贡献在于提供了大规模、多语言语料库上的评估基准，量化了自动指标的局限性。该方法强调了人类评估在特定领域中的必要性，指出自动指标可能忽略语义细微差别。其代价是人工评估成本高，且结果受评估者主观性影响。该研究为选择评估指标提供了实证依据，推动了主题模型评估方法的改进。

Reproducible Framework for Focus Group Analysis（P7）针对焦点小组讨论文本在计算主题建模中缺乏系统框架的问题，提出基于 BERTopic 的可复现分析框架。该框架详细描述了从预处理、嵌入生成、聚类到主题解释的完整流程，并针对焦点小组的结构化对话特点优化参数。其核心贡献在于提供了针对特定文本类型的标准化分析流程，填补了该领域的应用空白。该方法强调了参数探索的重要性，指出最优配置随语料库特征变化。其代价是流程复杂，需要领域专家参与解释。该框架为健康研究和市场研究中的焦点小组分析提供了可复现的计算工具，促进了定性数据的量化分析。

CzechTopic（P14）针对历史捷克文档中主题定位任务缺乏基准的问题，提出零样本主题定位基准。该基准提供词级边界标注，支持重叠和非连续片段，评估模型在历史文本中定位特定主题的能力。其核心创新在于将主题发现细化为主题定位，要求模型识别主题在文本中的具体位置。该方法揭示了现有模型在细粒度定位上的不足，推动了基于 LLM 的零样本定位研究。其代价是标注难度大，且历史文本的语言变化增加模型挑战。该基准为数字人文和历史研究提供了细粒度文本分析工具，促进了主题定位技术的发展。

Neural Topic Modeling for Newspaper Archives（P9）针对历史报纸档案分析中传统方法效率低下的问题，提出基于 BERTopic 的神经主题建模应用框架。该框架利用 Transformer 嵌入捕捉历史文本中的细微主题变化，支持大规模档案的组织和分析。其核心贡献在于展示了神经模型在处理历史语言变化和复杂词汇方面的优势，提供了从传统方法到神经方法的迁移路径。该方法强调了上下文嵌入在捕捉历史语境中的重要性。其代价是计算资源需求高，且历史文本预处理复杂。该应用为历史学家提供了高效、客观的档案分析工具，促进了计算历史学的发展。

评估与应用实践路线与其他路线存在互补关系：前者提供了细粒度评估标准和应用场景，其他路线则提供了具体的建模方法。前者在揭示模型局限性和推动技术演进方面具有关键作用，但缺乏具体的建模能力。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

基于预训练嵌入（如 BERT/SBERT）的聚类方法（如 BERTopic）在主题连贯性和语义捕捉上普遍优于传统 LDA，特别是在短文本和复杂语料中。这一共识在多个基准上被反复验证：CGTM 的 0.347 NPMI 与 PRISM 的 0.900 AUPC 均大幅超越 LDA 的 950.3 Perplexity 和 BERTopic 的 0.52-0.62 Coherence。大语言模型（LLM）能显著提升主题的可解释性、标签质量和人类对齐度，但需解决稳定性、幻觉和计算成本问题，常作为后处理或引导模块使用。这一共识在 LLM 驱动主题建模路线中得到广泛支持，如 PRISM 和 MALTopic 均通过 LLM 提升了主题的可解释性。

与此相关的另一个共识是，词袋（BoW）假设是经典主题模型的主要局限，引入上下文信息（Contextualized representations）或语义嵌入是提升主题质量的关键方向。这一共识在神经主题模型优化路线中得到广泛支持，如 CGTM 和 DARTOPIC 均通过融合上下文信息提升了主题连贯性。动态主题建模需要显式建模时间依赖关系，静态模型无法有效捕捉主题随时间的演化、分裂和合并。这一共识在动态与在线主题建模路线中得到广泛支持，如 SB-ETM 和 BERTilda 均通过显式建模时间依赖关系提升了主题演化追踪的准确性。

### 3.2 观点分歧

LLM 在主题建模中的角色存在根本性分歧：LLM-Centered 方法（如 TopicGPT）追求极致语义但缺乏稳定性，而 LLM-Assisted 方法（如 MALTopic）追求稳健但可能限制语义深度。现有证据偏向 LLM-Assisted 方法在稳定性和可复现性上更优，而 LLM-Centered 方法在可解释性上更优。实验表明，LLM-Centered 方法在不同提示下结果波动大，且存在幻觉；而 LLM-Assisted 方法在基准测试中表现更稳健。定输赢的实验需对比两者在大规模、多领域数据集上的主题稳定性（Bootstrap 重采样）和人类评估一致性。

这一分歧的背后，是另一个更根本的争论：动态主题演化的假设是平滑连续还是结构突变。平滑演化假设（传统 DTM）认为主题随时间平滑变化，可通过状态转移矩阵或时间衰减函数建模；结构突变假设（BERTilda, Higher-Order Hypergraphical DTM）认为主题会发生分裂、合并等离散事件，需显式建模这些结构变化。观点 B 在政治传播、突发新闻等场景中表现更好，能捕捉到叙事断裂。观点 A 在长期趋势预测中更稳定。定输赢的实验需在包含明显事件（如选举、疫情爆发）的时间序列数据上，对比两种方法对主题生命周期事件（分裂/合并）的检测准确率。

### 3.3 其他开放问题

最紧迫的工程问题是大规模语料的实时与可扩展性瓶颈。传统 LDA 和复杂 NTM 在亿级文档上计算成本高且难以在线更新，当前尝试通过张量分解、在线增量学习和轻量级学生模型蒸馏来实现实时分析。Online Tensor LDA 在超过 10 亿文档的政治语料库中实现了高效分析，但理论假设较强，对数据分布敏感。PRISM 通过师生蒸馏机制实现了高效推理，但训练阶段需要教师模型的高昂推理成本。

最根本的研究问题是 LLM 作为黑盒的不透明性与幻觉问题。LLM 中心方法缺乏内部对齐信号，且存在幻觉风险，当前尝试通过注意力机制解释、多智能体去重或对比学习来增强可靠性和可解释性。Attention-Informed NTM 通过聚合注意力状态恢复了文档-主题分布，但受限于 LLM 的上下文窗口长度。MALTopic 通过多智能体去重消除了冗余，但多个智能体间的通信与协调增加了系统复杂度和推理延迟。

已知—争议—未知认知图谱：已知预训练嵌入和 LLM 能显著提升主题质量；争议 LLM 的角色和动态演化假设；未知 LLM 主题生成的可解释性理论、动态主题演化的数学基础、人机对齐的量化标准。未来趋势将依赖于在 LLM 的语义推理能力与传统模型的结构稳定性之间找到新的平衡点，并建立更贴近人类认知的评估体系。

## 4. 总结与展望

主题建模的核心矛盾在于语义深度与结构稳定性的博弈。早期研究以 LDA 为基石，确立了基于词袋假设的概率生成框架，但受限于静态词频统计的语义缺失。随后，神经主题模型和嵌入聚类方法通过引入预训练词嵌入和 VAE 架构，解决了 BoW 假设的语义缺失问题，实现了从统计共现到语义相似的范式转移。随着 LLM 的崛起，研究重心转向 LLM 辅助或 LLM 中心的主题分析，利用 LLM 的推理能力进行主题标签生成、聚类引导及动态演化追踪。当前领域处于“算法中心”向“LLM中心”过渡的活跃阶段，混合方法成为解决可解释性与稳定性矛盾的主流路径。

未来可能突破的方向包括：LLM 中心主题建模的系统级优化，解决 LLM 在处理大规模语料和长文档时的上下文窗口限制；动态主题演化与时间感知建模，通过引入时间衰减、注意力机制和时序图结构，增强模型对动态语义变化的敏感性；层级与终身主题建模，通过概率概念形成、树状结构构建和流式数据更新，实现主题层级的动态演化。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，系统比较 LLM-Assisted 和 LLM-Centered 方法在主题稳定性和人类对齐度上的表现，为 LLM 在主题建模中的角色提供实证依据。
