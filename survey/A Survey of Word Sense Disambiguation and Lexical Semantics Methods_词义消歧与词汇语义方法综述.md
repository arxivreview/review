## 导读

词义消歧（Word Sense Disambiguation, WSD）旨在依据上下文从预定义词表中确定目标词的正确含义，其核心价值在于为下游语义理解提供精确的词汇级语义锚点。早期研究依赖符号系统与统计模型，虽具备可解释性，但难以应对复杂语言变体与细粒度语义区分。随着大语言模型（LLM）的引入，领域重心从单纯追求预测准确率转向解决数据稀缺与泛化难题，知识蒸馏与合成数据生成成为主流技术路径。与此同时，混合架构兴起，试图结合符号系统的结构化推理与神经网络的语义理解能力，以突破细粒度消歧的瓶颈。研究视角亦从单一文本扩展至多模态交互与模型内部机制分析，探索词义在神经网络中的编码方式及其可干预性。各路线在表示质量、计算成本与鲁棒性之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从黑盒预测到结构化语义接口的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

词义消歧作为自然语言处理的基础任务，其核心挑战在于克服早期符号方法缺乏灵活性以及统计模型难以处理复杂语言变体的局限。在形式化定义上，给定上下文 $C$ 和目标词 $w$，任务是从词表 $S$ 中选择最可能的词义 $s^* = \arg\max_{s \in S} P(s|C, w)$。这一问题结构看似简单，实则隐含了子问题间的深层依赖：词义资源构建为消歧提供底层基础，词义表征机制解释模型内部如何编码语义，而 LLM 驱动与多模态消歧则解决具体场景下的预测与鲁棒性问题。这种分层结构决定了任何单一层面的突破都难以独立解决整体问题，必须通过跨层级的协同优化才能实现性能跃升。

早期研究主要依赖基于知识的符号方法（如 WordNet、FrameNet）和统计模型，确立了以 WordNet 为基准的评估范式。然而，标注数据稀缺和语义边界模糊导致细粒度消歧（如谓词层级区分）准确率远低于粗粒度帧识别。2009 年 Navigli 的综述系统梳理了技术路线，指出了这一瓶颈，为后续研究提供了理论框架。随着深度学习的发展，基于神经网络的模型在粗粒度消歧上取得进展，但其“黑盒”特性导致缺乏结构化表示，且在对抗性语境下表现脆弱。这一阶段的问题定义仍局限于“预测正确性”，未触及模型内部语义编码的本质。

2020 年至 2022 年，问题定义发生关键转折。大语言模型的引入改变了数据获取范式，通过知识蒸馏和合成数据生成，解决了标注数据稀缺和领域泛化难题。与此同时，研究视角从单一文本扩展至多模态（视觉 WSD）和内部机制分析。2021 年 CLIP 的兴起使得零样本视觉词义消歧成为可能，利用文本与图像嵌入的余弦相似度直接对齐词义与视觉概念。2020 年 BEM 方法提出基于释义信息的嵌入，实现了无需大规模标注数据的消歧能力。这一时期，问题边界从“如何预测”扩展至“如何利用外部知识增强预测”，符号与神经方法的融合开始受到关注。

2023 年至 2024 年，对抗性语境下的鲁棒性成为研究热点。LLM 易受语境中误导性词汇影响导致错误消歧，多智能体辩论框架被提出以增强对语义干扰的抵抗能力。2023 年 Kwon 等人利用 LLM 生成词义定义以增强视觉 WSD，展示了 LLM 作为知识源的潜力。2024 年 Zhou 等人验证了利用 LLM 作为自动标注器生成大规模银标准数据的可行性，确立了 LLM 驱动数据增强的技术路线。这一阶段，问题定义进一步细化为“如何在复杂、对抗性语义环境中保持鲁棒性”，推动了混合架构和显式词义表征的发展。

2025 年至 2026 年，领域进入从“端到端预测”向“结构化语义接口”过渡的阶段。研究重点在于构建可解释、可干预且具备跨领域泛化能力的消歧系统。2025 年 MADAWSD 提出多智能体辩论框架，显著提升了 LLM 在复杂语义干扰下的消歧鲁棒性。2025 年 ESCHER 蒸馏框架利用 LLM 构建大规模通用领域 WSD 语料，使小模型在未见领域上的性能超越其 LLM 教师。2026 年 ACROS 提出架构无关的残差词义诱导方法，在冻结的解码器 LM 中插入门控残差路径以显式暴露词义向量，支持测量、干预与跨语言对齐。这一时期，问题定义最终演变为“如何构建结构化、可操控的词义表示”，反映了领域对黑盒模型局限性的深刻反思。

当前，领域处于从“黑盒分类”向“结构化语义接口”演变的宏观叙事中。核心矛盾已从数据稀缺转变为如何平衡 LLM 的语义理解能力与符号系统的结构化推理需求。细粒度消歧和对抗性语境下的鲁棒性是当前研究的主要痛点，推动了混合架构和显式词义表征的发展。子问题间的依赖关系更加清晰：词义资源构建为消歧提供基础，词义表征机制解释内部编码，LLM 驱动与多模态消歧解决具体场景问题。这种分层结构决定了未来研究必须在跨层级协同优化中寻求突破。

**如果用一个核心问题概括该领域，那便是如何在保持计算效率与泛化能力的同时，构建可解释、可干预且具备跨模态/跨语言鲁棒性的结构化词义表示与推理机制。**

## 2. 方法体系

- 2009：Navigli Survey——系统梳理了基于知识、统计及混合方法的词义消歧技术路线，确立了以WordNet为基准的评估范式

- 2019：Ethayarajh Embedding Analysis——揭示了上下文嵌入中词形先于词义聚类的几何特性，指出标准指标混淆了词汇同一性与真正的超位置现象

- 2020：BEM——提出基于释义信息的嵌入方法，通过显式利用词义定义来区分不同语境下的词义

- 2021：CLIP——通过对比语言-图像预训练构建了共享潜在空间，使得零样本视觉词义消歧成为可能

- 2024：Zhou et al. LLM Annotation——验证了利用LLM作为自动标注器生成大规模银标准数据的可行性

- 2025：MADAWSD——提出多智能体辩论框架，在对抗性语境中通过结构化辩论消除误导性词汇线索

- 2026：ACROS——提出架构无关的残差词义诱导方法，在冻结的解码器LM中插入门控残差路径以显式暴露词义向量

- 2026：SememeLRM——利用结构化语义素树知识增强词汇关系挖掘，有效区分同义与上下位关系

这条时间线勾勒了该领域方法演进的代表性节点：从 2009 年的 Navigli Survey 奠定该领域方法基线，经 2019 年 Ethayarajh Embedding Analysis 的推进，到 2026 年的 SememeLRM 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 LLM驱动消歧

LLM 驱动消歧路线旨在利用大语言模型作为知识源或推理引擎，解决传统 WSD 数据依赖与泛化难题。该路线的起源可追溯至 2023 年 Kwon 等人利用 LLM 生成词义定义以增强视觉 WSD 的工作，开启了利用 LLM 生成式能力解决传统消歧数据依赖难题的研究方向。2024 年 Zhou 等人进一步验证了利用 LLM 作为自动标注器生成大规模银标准数据的可行性，通过提示工程让 LLM 分配词义标签，证明了蒸馏 LLM 知识至小模型能显著提升泛化能力，确立了 LLM 驱动数据增强在 WSD 领域的技术路线。

ESCHER 蒸馏框架（P9）是该路线的代表性方法，旨在通过知识蒸馏将 LLM 的语义知识迁移至紧凑模型 ESCHER，以解决 LLM 推理成本高及小模型泛化能力差的问题。方法包含两种蒸馏范式：生成式蒸馏利用 LLM 为词典词义生成多样化例句以合成训练数据，标注式蒸馏则让 LLM 直接为多义词分配词义标签。在标注式蒸馏中，系统引入频率平衡策略，通过限制高频词义的样本数量来缓解长尾分布偏差，从而提升模型对罕见词义的捕捉能力。该方法的核心取舍在于依赖 LLM 的标注质量，且随着 LLM 规模增大，知识蒸馏的难度增加，小模型难以完全捕捉超大模型的所有知识。ESCHER 证明了通过扩大词义覆盖范围而非单纯增加数据量是提升通用 WSD 性能的关键，为构建高效、通用的消歧模型提供了数据驱动的新范式。

MADAWSD 多智能体辩论框架（P10）针对 LLM 在对抗性语境下易受误导性词汇线索干扰的问题，设计了基于多智能体辩论的消歧机制。系统包含 Debater、Moderator、Consensus-seeker 和 Judge 四个角色，Debater 负责基于上下文为特定词义提供论证，Moderator 引导辩论进程并分析各方观点。Consensus-seeker 评估辩论是否达成共识，若未达成则继续讨论，若达成则终止辩论并输出结果；若达到最大轮数，则由 Judge 做出最终裁决。这种辩论驱动的推理迫使模型关注词义的理性支持而非表面词汇关联，从而有效抵抗语义干扰。该方法的核心创新在于将人类辩论逻辑引入 LLM 推理，通过角色分工实现了对抗信息的过滤与理性判断。其代价是增加了推理的计算开销与延迟，且依赖 LLM 具备足够的逻辑推理与辩论能力。MADAWSD 展示了多智能体协作在提升 WSD 鲁棒性方面的潜力，为处理复杂、对抗性语义环境提供了新的技术路径。

Symbolic-LLM Hybrid WSD（P2）结合了符号自然语言理解系统（CNLU）与大语言模型（Phi4）的优势，首先由符号系统分析输入句子并生成歧义词的多个候选语义表示，这些表示基于 NextKB 本体具有结构化且可解释的特性。随后，系统将这些符号表示转换为自然语言描述，以便 LLM 能够理解其语义内涵，这一步骤解决了符号系统难以处理语言变体而 LLM 缺乏结构化推理的问题。接着，LLM 根据上下文语境从候选描述中选择最合适的语义解释，这一过程利用了 LLM 强大的上下文语义理解能力。最后，选定的语义信息被整合回符号 NLU 系统，应用相应的语义约束以完成最终的消歧决策。该方法的核心创新在于通过自然语言作为桥梁连接符号逻辑与神经语义，避免了传统方法对大规模人工标注数据的依赖。其代价是需要构建规则化的自然语言生成能力（verbalize），以确保符号概念能被准确语言化。这种设计使得系统能够同时处理粗粒度框架识别与细粒度谓词选择，且在两者间保持性能一致性。它代表了符号 AI 与 LLM 融合在细粒度消歧任务上的重要进展，为复杂语义推理提供了可解释的解决方案。

### 2.2 多模态与跨域消歧

多模态与跨域消歧路线拓展 WSD 至视觉语言交互及低资源历史语言场景，结合视觉线索、开放词汇检索或跨语言对齐，突破单一文本模态限制。该路线的起源可追溯至 2021 年 CLIP（Radford et al., 2021）的提出，通过对比语言-图像预训练构建了共享潜在空间，使得零样本视觉词义消歧（VWSD）成为可能，利用文本与图像嵌入的余弦相似度直接对齐词义与视觉概念，突破了传统 WSD 仅依赖文本上下文的模态限制。

VWSD 多模态融合综述（P3）系统梳理了视觉词义消歧的技术演进，重点分析了从视觉动词消歧（VVSD）到通用 VWSD 的方法扩展。早期 VVSD 方法主要采用基于特征或基于图的策略，其中图方法通过构建多模态相似度图，利用标签传播算法（如随机游走、GCN）在候选图像与词义节点间扩散消歧决策。随着 CLIP 等对比预训练模型的兴起，零样本 VWSD 方法利用文本与图像嵌入在共享潜在空间的余弦相似度，直接对齐歧义词语境与视觉概念，无需任务特定训练。近期研究进一步引入提示工程与提示增强，通过优化输入文本（如添加同义词、定义）来引导 CLIP 聚焦特定词义，提升零样本性能。该方法的核心在于利用视觉线索作为消歧的强约束，突破了纯文本 WSD 在上下文不足时的局限。其挑战在于视觉与语义对齐的精度，以及如何处理视觉噪声对词义判断的干扰。VWSD 的发展标志着 WSD 从单一文本模态向多模态交互的范式转变，为多模态应用提供了更精准的语义理解基础。

INSPICIO 开放词汇检索管道（P7）专为历史语言（如拉丁语、古希腊语）设计，解决缺乏词义清单（Sense Inventory）的消歧难题。方法首先利用 LLM 进行零样本翻译，生成目标词在语境中的英语定义及候选词元，提示词设计特别针对 LLM 常见陷阱，如区分动词本身与动词加否定、包含隐喻义等。随后，系统利用句子嵌入模型对生成的定义进行编码，并在 OEWN（Open English WordNet）索引中进行稠密检索，获取语义相近的词义集合。同时，利用词元索引进行稀疏检索，捕捉通过翻译锚定的词汇关联，特别是那些在嵌入空间中语义距离较远但词汇上对应的习语表达。最后，通过 MMR（最大边际相关性）重排序策略整合稠密与稀疏检索结果，生成最终的词义排名。该方法的核心创新在于无需目标语言的词义标注数据，完全依赖 LLM 的翻译能力与英语词义资源的检索。其代价是依赖 LLM 翻译的准确性及英语词义资源的覆盖度。INSPICIO 为低资源及历史语言的 WSD 提供了可扩展的解决方案，拓展了 WSD 的应用边界至古典语言领域。

### 2.3 词义资源构建

词义资源构建路线聚焦 WordNet 等词义资源的自动扩展与跨语言投影，通过语义对齐与过滤策略生成新语言词义，完善底层词义知识库。该路线的起源可追溯至早期基于统计方法的词义投影研究，但受限于语料库统计量的依赖和虚假对齐问题。2026 年 ExpandNet 的提出标志着该路线进入基于字典引导的句子级语义投影新阶段。

ExpandNet 字典引导投影方法（P5）提出一种句子级的语义投影策略，用于在目标语言中生成新词义并扩展 WordNet。系统首先利用机器翻译将源语言（英语）的已标注语料翻译为目标语言，构建平行语料对。接着，采用 DBAlign 对齐算法，该算法结合预训练对齐器与双语字典，通过交集、字典、基础三个阶段的链接选择，利用字典证据过滤虚假对齐，确保对齐的准确性。在投影阶段，若源词与目标词的对齐得到双语字典支持，则将源词的词义标签投影至目标词，生成新的词义-词元对。此外，系统引入词性过滤机制，丢弃词性不匹配的投影，并保留正字法相同词的投影以处理专有名词。该方法的核心创新在于利用字典作为对齐与过滤的双重约束，消除了对语料库统计量的依赖，提升了在多样数据条件下的鲁棒性。其代价是依赖高质量的双语字典资源，且假设每个内容词在语境中表达单一概念。ExpandNet 为低资源语言的词义资源构建提供了高效、自动化的解决方案，促进了多语言语义本体的完善。

### 2.4 词义表征与机制

词义表征与机制路线探究词义在神经网络中的表征形式，分析多义性对超位置指标的干扰，或设计可诱导的词义接口以支持消歧与跨语言迁移。该路线的起源可追溯至 2019 年 Ethayarajh 的嵌入分析，揭示了上下文嵌入中词形（word identity）先于词义（sense）聚类的几何特性，指出标准指标混淆了词汇同一性与真正的超位置（superposition）现象，为理解神经网络中多义性表征的混淆机制奠定了实证基础。2020 年 BEM（Blevins & Zettlemoyer, 2020）提出基于释义（gloss）信息的嵌入方法，通过显式利用词义定义来区分不同语境下的词义，实现了无需大规模标注数据的消歧能力，成为后续无监督及少样本消歧研究的重要对比基线。2022 年 Loureiro 等人的多义性蒸馏技术将词义信息压缩至嵌入空间，提升了模型对细微语义差异的捕捉能力，证明了显式词义表征在提升消歧精度方面的有效性，为后续词义接口设计提供了训练策略参考。

Lexical Identity Confound Analysis（P4）通过 2x2 因子分解设计，量化了词汇同一性（word form）与语义（meaning）对神经网络神经元重叠（polysemanticity）的贡献。实验构建四组句子对：同词同义（SL）、同词异义（PS）、异词同义（SYN）、异词异义（CL），分别测量 MLP 中间激活的重叠度。通过计算词汇贡献比率（Rlex），即同词重叠与同义重叠之差除以总范围，揭示词汇形式在神经元激活中占据主导地位，而非单纯的超位置压缩。研究进一步通过因果实验（如激活修补）验证了词汇信号在模型处理中的因果作用，表明标准多义性指标高估了超位置效应。该方法的核心贡献在于区分了词汇混淆与真正的语义超位置，为理解 LLM 内部表征提供了更细致的视角。其局限在于主要关注 MLP 层，且假设词汇与语义贡献可加。这一发现对可解释性工具（如 SAE）的设计具有重要启示，提示在分析多义性时需控制词汇形式变量，以避免误判模型压缩机制。

ACROS 残差词义诱导方法（P6）提出一种架构无关的残差词义诱导技术，旨在为冻结的解码器 LM 添加显式词义接口，而不破坏其原有预测能力。ACROS 通过在模型中插入门控残差路径，诱导出一组可复用的词义向量（sense slots），这些向量与原始隐藏状态并行存在，支持测量、干预与跨语言对齐。与 Backpack 模型不同，ACROS 无需从头预训练，而是通过蒸馏或继续训练在现有检查点上诱导词义，避免了转换 Backpack 导致的预测质量崩溃。系统利用这些词义向量进行零样本 WSD，通过计算目标词激活向量与词义释义（gloss）向量的余弦相似度来预测词义。此外，ACROS 支持通过调整特定词义向量进行行为干预，并作为跨语言适配的锚点，实现从英语到印尼语等语言的迁移。该方法的核心创新在于实现了词义表征的统一接口，兼顾了测量、控制与迁移功能。其代价是引入了额外的参数与计算开销，且依赖词义释义的质量。ACROS 为 LLM 的词义操控提供了可靠、低 KL 散度的句柄，推动了词义表征从隐式到显式的转变。

### 2.5 词汇关系与替换

词汇关系与替换路线研究词汇替换中的候选排序及基于结构化语义素知识的词汇关系挖掘，旨在提升对细微词汇语义差异的捕捉与分类能力。该路线的起源可追溯至早期基于分布语义模型的词汇替换研究，但受限于局部相似度计算的局限。2025 年 Holistic Sentence Semantics Ranking 的提出标志着该路线进入基于全局句子语义的无监督排序新阶段。

Holistic Sentence Semantics Ranking（P1）通过整合注意力权重与集成梯度（Integrated Gradients）信息，对词汇替换候选词进行排序。系统首先计算原始句子与替换后句子在多层隐藏表示上的语义相似度，并设计两种加权策略：基于注意力分数的权重反映其他 token 对目标 token 的影响，基于 IG 分数的权重量化每个 token 对目标预测的贡献。权重通过 Softmax 归一化，且目标 token 权重固定为 1，以突出非目标 token 的语义变化。最终得分是 token 级相似度的加权和，旨在捕捉替换对整个句子语义的全局影响，而非仅关注目标位置。该方法的核心创新在于利用可解释性技术（IG）量化 token 间交互，克服了传统方法仅依赖目标位置概率或局部相似度的局限。其代价是计算开销较大，需运行多次前向传播以计算梯度。该方法提升了词汇替换的准确性，为对抗样本生成及词汇简化等任务提供了更可靠的候选排序机制，强调了句子整体语义一致性在词汇选择中的重要性。

SememeLRM 结构化语义素挖掘方法（P8）利用结构化语义素（Sememe）树知识增强词汇关系挖掘（LRM），解决现有模型难以区分细微语义关系（如同义与上下位）的问题。系统首先通过自动语义素树构建（STC）管道，预测词义的语义素节点、边及边类型，形成层次化语义结构。接着，利用关系图神经网络（R-GNN，具体为 R-GCN）聚合语义素树中的节点与边特征，生成词义级别的嵌入向量。这些嵌入被融入 PLM（如 DeBERTa）的提示模板中，与词元嵌入一起输入编码器，以增强关系预测能力。模型通过两个独立的 MLP 头分别预测词汇关系分类（LRC）和词汇等价性（LE）分数。该方法的核心创新在于将细粒度的语义素知识显式引入 PLM，弥补了纯数据驱动模型在语义细微差别上的不足。其代价是依赖 HowNet 等语义素资源的覆盖度，且 STC 预测误差可能传播至下游任务。SememeLRM 展示了结构化语义知识在提升词汇关系挖掘精度方面的有效性，为结合符号知识与神经模型提供了新范式。

### 2.6 跨任务与多领域应用

上述五条路线并非孤立存在，而是通过跨任务与多领域应用形成互补。LLM 驱动消歧路线提供的知识蒸馏技术被应用于词义资源构建，通过 LLM 生成银标准数据以扩展低资源语言的词义库存。多模态与跨域消歧路线的视觉线索辅助机制被借鉴至对抗性 WSD 研究，利用视觉约束增强文本消歧的鲁棒性。词义表征与机制路线的显式词义接口被应用于词汇关系挖掘，通过词义向量相似度提升关系分类精度。这种跨路线的技术迁移反映了领域内方法体系的内在统一性，即所有路线均致力于构建更精确、更鲁棒、更可解释的词义表示与推理机制。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLM 在通用语义理解上表现强劲，但在需要精确语义区分的 WSD 任务上，直接应用往往不如专门微调的小模型或蒸馏模型。这一共识在多个基准上被反复验证：ESCHER 蒸馏框架通过扩大词义覆盖范围，使小模型在通用领域零样本 WSD（Raganato ALL）上达到 64.95 F1，与 WordNet 首义启发式（65.2 F1）相当，而直接调用 LLM 的推理成本远高于小模型。与此相关的另一个共识是，基于 LLM 的知识蒸馏（包括数据生成和标注）是解决标注数据稀缺和提升模型泛化能力的有效途径。ESCHER 和 INSPICIO 均依赖 LLM 生成银标准数据或翻译定义，证明了 LLM 作为知识源在构建大规模 WSD 语料和开放词汇检索中的核心价值。

细粒度消歧（如谓词选择）比粗粒度帧识别更具挑战性，且对下游推理任务至关重要。Symbolic-LLM Hybrid WSD 通过自然语言桥梁连接符号逻辑与神经语义，在细粒度谓词选择上保持性能一致性，验证了混合架构在复杂语义推理中的必要性。符号方法提供的结构化表示与神经方法的上下文理解能力互补，混合架构能显著提升复杂语境下的消歧性能。这一共识在对抗性 WSD 中尤为明显：MADAWSD 通过多智能体辩论增强鲁棒性，在 FOOL 上达到 90.3 F1，较单轮推理方法显著提升，表明结构化推理机制对抵抗语义干扰至关重要。

### 3.2 观点分歧

模型内部词义表示的本质存在根本分歧：词汇形式混淆 vs. 真正的语义超位置。观点 A 认为标准多义性指标高估了超位置效应，词汇形式（Lexical Identity）在神经元激活中占据主导地位，代表工作为 Lexical Identity Confound Analysis（P4）。该研究通过 2x2 因子分解设计和因果实验表明，词汇信号在模型处理中扮演重要角色，标准指标混淆了词汇同一性与真正的超位置现象。观点 B 认为模型内部存在真正的语义超位置，神经元同时激活多个概念是模型压缩机制的体现。现有证据偏向观点 A，但证据强度有限，主要关注 MLP 层，且假设词汇与语义贡献可加。分歧根源在于测量工具盲区：现有指标难以完全分离词汇形式与语义含义的贡献，缺乏统一的因果干预协议来验证词义选择的独立性。

LLM 直接应用与蒸馏小模型孰优亦存在分歧。观点 A 认为 LLM 直接应用在复杂推理和对抗场景下表现更优，具备更强的语义理解能力，代表工作为 MADAWSD（P10）使用 Qwen-Plus/DeepSeek-V3 在 FOOL 上达到 90.3 F1。观点 B 认为蒸馏小模型在通用领域泛化上更优，计算成本更低，且通过扩大词义覆盖范围可超越 LLM 教师，代表工作为 ESCHER（P9）在 Raganato ALL 上达到 64.95 F1。现有证据显示，在对抗性 WSD 中，LLM 直接应用（尤其是大模型）表现优于蒸馏小模型；但在通用领域零样本 WSD 中，蒸馏模型可达到与启发式方法相当的性能。分歧根源在于场景依赖：对抗性语境和细粒度消歧对推理能力要求高，LLM 优势明显；而通用领域消歧更依赖数据覆盖和泛化，蒸馏模型更具成本效益。缺乏统一的基准来全面评估两者在不同场景下的相对优势。

### 3.3 其他开放问题

最紧迫的工程问题是构建大规模通用领域 WSD 基准与数据。现有通用领域测试集规模较小且分布有限，难以全面评估模型在分布外（OOD）场景下的泛化能力。关键困难在于缺乏高质量、覆盖广泛语义域的金标准标注。研究路径是利用 LLM 进行大规模合成数据生成或标注，结合金标准数据构建混合语料，以建立更具代表性的通用领域 WSD 基准。与此相关的研究问题是提升对抗性 WSD 的鲁棒性与数据多样性。LLM 在对抗性扰动下性能显著退化，且缺乏足够的对抗性 WSD 数据集。关键困难在于对抗样本的构造复杂且现有数据集规模有限。研究路径是开发多智能体辩论框架（如 MADAWSD）以增强推理鲁棒性，并构建更多语言（如中文）的对抗性 WSD 数据集以支持系统评估。

最根本的研究问题是增强词义表示的可解释性与因果干预能力。现有模型内部词义表示往往与词形身份混淆，且缺乏可单独寻址的词义轴。关键困难在于如何在不破坏预训练模型性能的前提下引入结构化的词义接口。研究路径是诱导显式的残差词义路径（如 ACROS），使其同时支持零样本 WSD、低 KL 词义引导和跨语言对齐，实现词义测量、干预和对齐的统一。此外，消除词形身份对词义叠加度量的混淆亦至关重要。现有超位置度量常将词形编码误认为词义压缩，导致对模型内部表示的误解。关键困难在于如何区分编码词形与编码概念的神经元。研究路径是开发基于词义选择性指数（SSI）的神经元分类方法，并在 SAE 训练或模型编辑中引入词形身份惩罚，以产生词义级别的单语义特征。

已知的是 LLM 蒸馏和混合架构在特定场景下的有效性，争议的是词义表示的本质和 LLM 直接应用与蒸馏小模型的相对优势，未知的是如何在保持计算效率的同时实现全面可解释、可干预且具备跨模态/跨语言鲁棒性的结构化词义表示。未来发展趋势将从“端到端预测”进一步向“结构化语义接口”深化，重点在于构建统一的词义表征框架，支持测量、干预、对齐和迁移的多功能集成。

## 4. 总结与展望

词义消歧领域的核心矛盾已从数据稀缺转变为如何平衡 LLM 的语义理解能力与符号系统的结构化推理需求。早期研究依赖符号方法和统计模型，受限于标注数据稀缺和语义边界模糊；随后 LLM 的引入解决了数据获取难题，但带来了计算成本高和泛化能力弱的矛盾；当前混合架构和显式词义表征的发展试图在可解释性、鲁棒性和计算效率之间寻求平衡。这一演进过程反映了领域从“黑盒预测”向“结构化语义接口”的范式重构，核心瓶颈在于如何构建可解释、可干预且具备跨模态/跨语言鲁棒性的结构化词义表示与推理机制。

未来可能突破的方向包括：第一，扩展符号-神经混合架构至更广泛的 NLU 任务，如共指消解和解析消歧，以证明符号-神经集成在更广泛任务中的适用性（P2、P8 共同指向）；第二，构建大规模通用领域 WSD 基准与数据，利用 LLM 进行大规模合成数据生成或标注，结合金标准数据构建混合语料，以建立更具代表性的通用领域 WSD 基准（P9、P7 共同指向）；第三，增强词义表示的可解释性与因果干预能力，诱导显式的残差词义路径，使其同时支持零样本 WSD、低 KL 词义引导和跨语言对齐，实现词义测量、干预和对齐的统一（P6、P4 共同指向）。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，系统评估不同词义表征方法（如 ACROS、BEM）在零样本 WSD、对抗性 WSD 和跨语言迁移任务上的性能，以建立公平的比较基准，揭示词义表征方法的真实能力边界。
