# A Survey of Table Understanding and Reasoning with Large Language Models ｜大语言模型表格理解与推理方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Table%20Understanding%20and%20Reasoning%20with%20LLMs)

## 导读

表格理解与推理旨在让机器从半结构化数据中提取信息并执行逻辑推断，其核心价值在于弥合二维表格结构与一维语言序列之间的表征鸿沟。早期研究依赖 TaPas 等专用预训练模型，但受限于泛化能力，随着大语言模型（LLM）的兴起，领域范式发生根本转变，从“专用架构”转向“通用 LLM + 提示工程/微调”。关键转折点包括 TableLlama 确立的指令微调范式、多模态大模型（MLLM）引入的表格即图像（Table-as-Image）双模态处理，以及强化学习（RL）与推理时扩展（Inference-time Scaling）对复杂推理深度的提升。各路线在结构保真度、计算成本与推理可靠性之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从线性化适配到原生结构感知的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

表格理解与推理的核心矛盾在于二维拓扑结构与一维语言序列之间的本质冲突。早期研究聚焦于如何设计专用表格编码器，以 TaPas 为代表的模型通过掩码语言建模和表格特定任务预训练，首次系统性地展示了预训练语言模型在表格理解上的潜力，奠定了表格专用模型的基础（Herzig et al., 2020）。然而，这种专用架构受限于泛化能力，难以适应多样化的真实世界表格。随着 LLM 的兴起，问题定义从“如何设计专用表格编码器”转变为“如何让通用 LLM 理解序列化后的表格文本”，核心痛点迅速聚焦于 2D-to-1D 序列化导致的空间结构丢失。表格序列化（Table Serialization）将二维表格转换为 Markdown、HTML 或线性文本，是 LLM 处理表格的基础，但这一过程不可避免地破坏了行列邻接关系和空间对齐，导致模型难以理解复杂层级结构。

子问题之间存在强依赖关系，结构表示是基础，若不解决结构感知，多模态融合和复杂推理将缺乏根基。数值计算幻觉依赖于结构感知后的精确检索，长上下文检索瓶颈依赖于细粒度结构表示，而推理忠实性审计则依赖于前序所有模块输出的可解释性。具体而言，LLM 在涉及算术、聚合等数值操作时易产生错误，且缺乏确定性验证机制；随着表格规模扩大，全表输入超出上下文窗口或导致注意力稀释；复杂查询往往需要跨多个表格进行连接和综合，现有方法多针对单表，缺乏有效的多表检索与组合推理机制。这些子问题相互交织，构成了当前研究的主要挑战。

2020 至 2022 年间，领域处于奠基阶段，TaPas 和 TableGPT 等工作确立了 LLM 处理表格的可行性，但暴露了序列化结构丢失问题。2023 至 2024 年，TableLlama 和 BINDER 引入指令微调与代码执行，缓解了数值幻觉，但长上下文和多表关联仍受限。Table-LLaVA 将表格图像与文本对齐，利用视觉编码器提取表格布局信息，推动了多模态表格研究的发展（Zheng et al., 2024）。2025 至 2026 年，TAMO 和 TABGR 引入图/超图结构，Table-R1 和 TableGPT-R1 引入强化学习，解决了复杂层级与推理深度问题。TAMO 通过超图编码保留表格的高阶结构信息，解决了线性化导致的结构丢失问题（Li et al., 2025）。当前形态下，研究重心已从简单的表格问答转向复杂层级表格、多表关联、长上下文表格以及真实世界噪声表格的处理。

**如果用一个核心问题概括该领域，那便是：如何在保持表格二维拓扑结构与语义完整性的前提下，克服大语言模型在数值计算、长程依赖及多模态对齐上的固有缺陷，实现从静态信息提取到动态可验证推理的跨越。**

## 2. 方法体系

- 2015：WikiTableQuestions——由Pasupat和Liang提出的经典表格问答基准，确立了表格问答任务的基础范式

- 2018：Spider——由Yu等人提出的跨域文本到SQL基准，定义了结构化数据查询的标准任务

- 2020：TaPas——由Herzig等人提出的基于BERT的表格预训练模型，奠定了表格专用模型的基础

- 2022：TableGPT——由Li等人提出的集成表格理解与生成的LLM框架，开启了LLM直接处理表格数据的时代

- 2023：TableLlama——由Zhang等人提出的通用表格大语言模型，成为表格推理领域的主流基线模型

- 2024：Table-LLaVA——由Zheng等人提出的多模态表格理解模型，推动了多模态表格研究的发展

- 2025：TAMO——由Li等人提出的将表格作为独立模态的LLM框架，为复杂表格的语义理解提供了新路径

- 2026：TABGR——由Ye等人提出的属性表格图推理方法，在WikiTQ和TabFact上显著提升了推理精度

这条时间线勾勒了该领域方法演进的代表性节点：从 2015 年的 WikiTableQuestions 奠定该领域方法基线，经 2018 年 Spider 的推进，到 2026 年的 TrustTable 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 表格结构表示

表格结构表示路线旨在解决 2D-to-1D 序列化导致的空间结构丢失问题，通过图、超图或树状序列化替代线性化，保留表格的二维拓扑和语义关系。早期工作如 TaPas 依赖线性化文本，但在处理包含合并单元格、多级表头的复杂表格时性能显著下降。TABGR 提出属性表格图（Attributed Table Graphs）表示方法，通过将表格转换为带有属性节点的图结构，保留表格的二维拓扑和语义关系，引入了图推理机制，使 LLM 能够直接在图结构上进行推理，避免了线性化导致的结构信息丢失（Wang et al., 2026, P15）。该方法在 WikiTQ 和 TabFact 上显著提升了推理精度，但代价是增加了图构建和推理的计算开销，且对图结构的构建质量有较高要求。TAMO 提出将表格作为独立模态的 LLM 框架，通过超图（Hypergraph）建模表格的高阶结构信息，将表格的表头和数据单元格映射为超边，保留了表格中一对多的复杂关系（Li et al., 2025, P11）。TAMO 解决了传统线性化方法中结构信息扁平化的问题，提升了模型对复杂层次表格的理解能力，但超图编码的计算复杂度较高，且需要额外的编码器模块。H2Table 提出层次化超图增强 LLM 框架，专门针对复杂表格的推理任务，通过层次化超图结构保留表格的嵌套表头和合并单元格信息，设计了层次化消息传递机制，使模型能够逐层理解表格的结构层次（Ling et al., 2026, P36）。ASTRA 提出自适应语义树推理架构，通过将表格转换为语义树结构，保留表格的层次关系和语义上下文，将表格内容表达为自然语言序列，与 LLM 的预训练数据分布对齐（Guo et al., 2026, P26）。Skill-Augmented Table Graph Reasoning 提出技能增强的表格图推理方法，通过引入操作级技能库，提升模型在表格问答中的推理能力，将表格推理分解为一系列原子操作（Su et al., 2026, P35）。Latent Bridges 提出潜在桥接方法，用于多表问答任务，通过构建表格间的潜在关系图，保留多表之间的语义关联和结构依赖（Varriale et al., 2026, P30）。

| 方法 | 结构类型 | 核心创新 | 计算开销 | 适用场景 |
|---|---|---|---|---|
| TABGR | 属性图 | 图推理机制，保留二维拓扑 | 高 | 复杂层级表格 |
| TAMO | 超图 | 表格作为独立模态，高阶关系建模 | 高 | 复杂层次表格 |
| H2Table | 层次化超图 | 层次化消息传递，嵌套表头处理 | 高 | 复杂嵌套表格 |
| ASTRA | 语义树 | 树状序列化，自然语言对齐 | 中 | 复杂表格推理 |
| TableDART | 视觉动态路由 | 门控网络，多模态动态融合 | 中 | 跨格式表格 |

### 2.2 多模态表格理解

多模态表格理解路线聚焦视觉与文本模态融合，处理表格图像、复杂布局及多模态对齐，提升空间感知与视觉推理能力。纯文本方法在 HiTab 等层级表格上性能显著下降，暴露了线性化导致的空间结构丢失问题，促使研究者引入视觉模态。TableDART 提出动态自适应多模态路由框架，通过轻量级门控网络动态融合文本和视觉模态信息，集成了表格文本模型、表格图像模型和 LLM 代理，通过门控网络根据查询动态选择最优模态路径（Xing et al., 2025, P3）。该方法解决了单一模态方法在复杂表格上的局限性，提升了模型对视觉和文本信息的综合理解能力，但门控网络的训练开销较大，且对多模态数据的对齐要求较高。TableMix 提出数据中心的增强多模态表格推理框架，通过混合数学数据和表格数据，提升模型在表格推理中的数值计算能力，设计了数据混合策略和难度感知奖励整形机制（P37）。CoReTab 提出代码驱动推理的多模态表格理解方法，通过生成可执行代码操作表格图像，提升模型对视觉表格的处理能力，结合了多模态 LLM 和代码执行环境（Nguyen and Okatani, 2026, P17）。TABQAWORLD 提出多轮表格问答的多模态推理优化框架，通过自适应多模态和轨迹优化，提升模型在多轮对话中的表格推理能力，设计了轨迹优化机制，解决多轮对话中错误传播和轨迹漂移的问题（Kwok et al., 2026, P25）。TABVERSE 提出跨格式表格理解基准，系统评估 LLM 和 VLM 在不同表格格式下的理解能力，涵盖了 HTML、LaTeX、Markdown 等多种表格格式（Ahsan et al., 2026, P29）。TABLET 提出大规模鲁棒视觉表格理解数据集，涵盖多种真实世界表格场景，包括不规则结构和多模态元素，引入了视觉扰动和结构复杂性维度（Alonso et al., 2025, P4）。

### 2.3 智能体推理框架

智能体推理框架路线构建多智能体或工具增强框架，通过规划、代码执行与反思机制，解决复杂表格的多步推理与长上下文问题。单一 LLM 在 LongTableBench 等长上下文任务中注意力稀释，TableMind 等框架通过交互式循环提升了鲁棒性。TableMind 提出自主程序化智能体框架，通过规划、代码执行和反思机制处理复杂表格推理任务，构建了高质量推理轨迹数据集，通过知识蒸馏将专家模型的推理过程转移到训练样本中（Jiang et al., 2025, P1）。Mixture-of-Minds 提出多智能体强化学习框架，通过规划、编码和回答智能体的协作，提升表格理解能力，设计了多智能体工作流，使不同智能体专注于不同的推理阶段（Zhou et al., 2025, P7）。Deep Tabular Research 提出持续经验驱动执行的深度表格研究框架，通过迭代规划和执行，处理复杂表格推理任务，构建了表格图结构，并通过操作映射将自然语言查询转换为可执行操作序列（Dong et al., 2026, P22）。ProgramTab 提出程序化范式增强 LLM 表格推理方法，通过生成可执行代码操作表格数据，提升推理的准确性和可解释性，设计了列选择、数据过滤和聚合等程序化步骤（Guo et al., 2026, P33）。JT-DA 提出工具集成的表格推理 LLM 框架，通过集成多种数据分析和表格操作工具，提升模型在复杂数据分析任务中的能力，构建了复杂表格数据集，通过多跳推理和中间计算，处理真实世界数据分析需求（Chi et al., 2025, P12）。MATA 提出多智能体框架，通过调度器协调 CoT、PoT 和 Text2SQL 三种推理路径，提升表格问答的可靠性，设计了置信度检查器和判决智能体，验证候选答案的正确性（Hyeon et al., 2026, P20）。

### 2.4 强化学习优化

强化学习优化路线应用强化学习（如 GRPO、RLVR）优化表格推理模型，通过可验证奖励提升数值计算精度与推理稳定性。监督学习在复杂推理任务上泛化能力有限，Table-R1 等工作证明 RL 能提升推理深度和数值计算精度。TableGPT-R1 提出基于多阶段强化学习的表格推理模型，通过可验证奖励信号优化策略，提升模型在异构表格任务上的推理稳定性，设计了任务自适应奖励系统，结合准确率和格式奖励，优化模型输出（Yang et al., 2025, P13）。STaR 提出慢思考大语言模型框架，通过显式多步推理提升表格推理的有效性和稳定性，引入了不确定性量化机制，使模型能够评估推理步骤的可靠性（Zhang et al., 2025, P10）。TaTToo 提出工具接地思维过程奖励模型，用于测试时扩展表格推理，结合了模型内部推理轨迹和工具集成程序，通过过程奖励模型优化推理步骤（Zou et al., 2025, P5）。PRPO 提出置换相对策略优化方法，用于增强 LLM 在表格预测中的数值推理能力，通过序列化表格数据，构建强化学习数据集，利用可验证奖励优化模型策略，引入了置换不变性约束（Cai et al., 2025, P6）。Table-R1 提出推理时扩展的表格推理模型，通过强化学习优化推理链生成，提升模型在复杂表格任务上的推理深度，设计了可验证奖励信号，结合准确率和格式奖励，优化模型输出（P42）。RE-TAB 提出可验证推理轨迹奖励框架，通过显式反馈和轨迹选择，提升表格问答性能，基于 TABROUGE，引入了世界模型视角，优化推理轨迹的选择（Kwok et al., 2026, P18）。

### 2.5 跨任务与多领域应用

跨任务与多领域应用路线涵盖基准构建、检索增强及鲁棒性分析，旨在系统评估 LLM 在表格理解、推理及鲁棒性方面的表现，并解决大规模表格问答的检索瓶颈。RUST-BENCH 提出非结构化文本在结构化表格中的 LLM 推理基准，涵盖科学、金融和体育等领域的复杂表格，通过符号方法和 LLM 生成问答对，评估模型在混合结构表格上的推理能力（Abhyankar et al., 2025, P8）。CompTab 提出真实世界复杂推理和不规则表格的综合性 TableQA 基准，涵盖多种结构复杂性和推理难度，通过引入结构不规则性和推理复杂性维度，提升了基准的全面性（P41）。T2R-BENCH 提出真实世界表格到报告任务基准，评估 LLM 将复杂结构化表格转换为自然语言报告的能力，涵盖了复杂表格结构、大尺寸表格和多长度答案（P38）。2Columns1Row 提出俄语文本和多模态表格理解与推理基准，评估模型在跨语言和跨模态表格任务上的表现，通过引入俄语表格数据，提升了基准的多语言覆盖性（P44）。FGTR 提出细粒度多表检索方法，通过层次化 LLM 推理识别相关表格和单元格，提升开放域表格问答的检索精度，设计了层次化检索机制，使模型能够逐步缩小检索范围（Sun et al., 2026, P23）。FT-RAG 提出细粒度检索增强生成框架，用于复杂表格推理，构建了模式感知的 SAT-Graph，将表格条目组织为层次化表示，结合文本和表格融合生成（Guo et al., 2026, P28）。HELIOS 提出早期融合、晚期融合和 LLM 推理协调的多粒度表格-文本检索框架，设计了边级检索单元，结合早期和晚期融合策略，提升表格-文本检索的准确性（Park et al., 2026, P21）。TabRAG 提出结构化表示改进的表格文档问答 RAG 框架，通过分解文档为聚焦任务，设计结构化表示，提升表格文档问答的准确性，引入了自主自生成 ICL 示例，增强检索和生成管道（Si et al., 2025, P9）。Topo-RAG 提出拓扑感知检索框架，用于混合文本-表格文档，根据数据拓扑设计双路径检索，结合统一重排序，提升混合文档检索的准确性（Dantart and Kóvacs-Navarro, 2026, P16）。TCR-Bench 提出表格 RAG 语义-可回答性差距诊断基准，评估模型在表格检索中区分语义相似和逻辑不同的能力，设计了语义-可回答性评估指标，揭示当前模型在表格检索中的语义匹配局限性（Tian et al., 2026, P34）。A Closer Look into LLMs for Table Understanding 提出 LLM 表格理解机制分析框架，通过注意力模式和专家激活分析，揭示 LLM 在表格任务中的内部机制，设计了表格特定专家识别模块，使模型能够理解表格任务中的专家路由模式（Wang et al., 2026, P24）。An Empirical Investigation of Robustness in LLMs under Tabular Distortions 提出 LLM 在表格扭曲下的鲁棒性实证研究，通过引入格式错误、行列错位等扭曲，评估模型的鲁棒性，设计了表格扭曲生成模块，使模型能够处理不完美表格数据（Dutta et al., 2026, P14）。When LLMs Read Tables Carelessly 提出 LLM 表格数据引用错误测量和减少方法，通过 LLM-as-a-Judge 评估数据引用错误率，设计了数据引用错误检测模块，使模型能够识别表格数据引用错误（Yang et al., 2026, P32）。TrustTable 提出神经符号审计框架，用于忠实表格问答，通过事实接地和逻辑可满足性验证，评估表格问答的忠实性，利用神经符号方法，结合 LLM 和符号推理，提升表格问答的可解释性（P43）。The Power of Order 提出对抗性表格排列方法，通过优化行和列排列，欺骗 LLM 在表格问答中的推理，设计了混合排列策略，使模型能够生成对抗性表格排列（Dong et al., 2026, P27）。The Illusion of Generalization 提出表格语言模型评估再审视，通过系统重新评估 Tabula-8B，揭示表格语言模型泛化能力的幻觉，设计了污染检测和格式熟悉度分析模块，使模型能够识别评估中的污染和格式偏差（Gorla and Puduppully, 2026, P19）。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

纯文本序列化（如 Markdown/HTML）虽然简单，但会显著损失表格的结构和空间信息，导致复杂表格推理性能下降，这一共识在约 20 篇论文中得到共同支持。多模态方法（Table-as-Image）能保留视觉布局信息，在处理包含合并单元格、颜色标记等视觉线索的表格时优于纯文本方法，但需解决视觉与文本的对齐问题，约 15 篇论文共同支持这一观点。代码生成（Program-of-Thought）和工具增强（Tool-Augmented）能显著提高数值计算和复杂逻辑推理的准确性，优于纯文本生成，约 12 篇论文共同支持。强化学习（RL）结合可验证奖励（如代码执行结果）能有效提升 LLM 在表格推理任务上的泛化能力和推理深度，约 10 篇论文共同支持。表格检索（Table Retrieval）是大规模表格问答的关键前置步骤，细粒度检索（如单元格或子表级）比整表检索更能提供相关上下文，约 8 篇论文共同支持。现有基准多基于维基百科等干净数据，与真实世界表格存在差距，需要更多包含噪声、多语言、复杂结构的基准来评估模型鲁棒性，约 10 篇论文共同支持。LLM 在表格任务上的表现受输入格式影响显著，不同序列化格式（HTML vs Markdown vs LaTeX）会导致性能波动，格式选择需根据任务特性优化，约 8 篇论文共同支持。

### 3.2 观点分歧

表格结构表示的最佳范式存在显式图/超图与隐式多模态融合的分歧。观点 A 认为显式图/超图表示（如 TABGR, TAMO）能更精确地保留二维结构和语义关系，适合复杂层级表格；观点 B 认为隐式多模态融合（如 TableDART, Table-LLaVA）通过视觉编码器动态捕捉布局，更灵活且能处理视觉噪声，适合真实世界表格。现有证据在干净结构化表格上偏向观点 A（TABGR 在 WikiTQ 上 SOTA），但在含噪、不规则视觉表格上观点 B 表现更优。证据强度中等，缺乏统一基准同时评估两种范式在相同噪声条件下的表现。这一分歧的背后，是另一个更根本的争论：推理增强的最优路径是强化学习（RL）还是智能体框架（Agent）。观点 A 认为 RL（如 TableGPT-R1）通过优化策略提升推理深度和泛化能力，适合大规模部署；观点 B 认为智能体框架（如 MATA, TableMind）通过工具调用和反思机制提升可解释性和可靠性，适合复杂多步任务。RL 在数值计算和逻辑推理任务上表现更稳定，但智能体框架在多表关联和长上下文任务上更灵活。证据强度中等，RL 训练不稳定性和智能体协调开销是主要限制。

### 3.3 其他开放问题

多模态融合策略存在早期融合与动态路由的分歧。观点 A 认为早期融合（如 Table-LLaVA）将视觉和文本特征在底层对齐，能充分利用模态互补性；观点 B 认为动态路由（如 TableDART）根据查询动态选择模态路径，能避免模态干扰，提升效率。动态路由在跨格式表格（TABVERSE）上表现更优，能隔离格式影响；早期融合在视觉细节丰富的表格上更准确。证据强度中等，缺乏对模态冲突机制的深入理论分析。已知—争议—未知认知图谱显示，结构表示和推理增强的协同是当前研究的核心，但多表关联和忠实性审计仍是主要认知盲区。发展趋势指向基于超图/属性图的统一结构表示、结合 MCTS 的探索式推理、真实世界噪声鲁棒性理论。

## 4. 总结与展望

表格理解与推理领域已跨越“能否处理”阶段，进入“如何精准、鲁棒、可解释地处理”阶段，核心在于构建结构感知与推理增强的统一框架。早期工作核心假设是“通用 LLM 可通过提示工程理解序列化表格文本”，受限于算力与数据，主要依赖 TaPas 等专用预训练或简单提示，忽视了 2D 结构的本质丢失。从纯文本序列化转向多模态（Table-as-Image）融合，保留了视觉布局、合并单元格等空间信息，提升了复杂表格的结构感知能力，但增加了视觉编码器开销，引入了模态对齐困难和视觉噪声敏感性。从直接文本生成转向代码生成（PoT）与工具增强，利用代码执行的确定性，消除了 LLM 在数值计算和逻辑推理中的幻觉，提升了计算精度，但增加了代码生成和执行的延迟，对代码正确性依赖高，限制了生成式任务的灵活性。从静态单表处理转向智能体框架与多步推理，通过规划、执行、反思循环，解决了长上下文和多表关联中的错误累积问题，提升了复杂任务推理深度，但多智能体协调开销大，推理延迟显著增加，系统复杂度提升。从监督微调转向强化学习（RLVR）与推理时扩展，通过可验证奖励（如代码执行结果）优化策略，提升了模型在异构表格任务上的泛化能力和推理稳定性，但 RL 训练不稳定，奖励设计复杂，计算成本高，且可能过拟合特定奖励信号。从线性化表示转向图/超图结构表示，显式建模表格的二维拓扑和高阶关系，解决了线性化导致的行列依赖断裂问题，提升了结构感知精度，但图/超图构建和推理计算开销大，对结构解析质量要求高，增加了系统复杂度。

未来可能突破的方向包括多模态表格理解与视觉-文本互补融合、表格结构感知与排列不变性表示、复杂层级与不规则表格推理。多模态表格理解与视觉-文本互补融合旨在解决纯文本序列化丢失空间结构信息的问题，难点在于如何有效对齐视觉布局与语义内容，潜在路径包括利用视觉标记作为锚点、动态路由多模态输入以及开发专门的多模态表格基准。表格结构感知与排列不变性表示旨在解决 LLM 对表格行列顺序敏感导致的鲁棒性差问题，难点在于构建对行列置换不变的嵌入空间，潜在路径包括使用超图、属性图或层级超图显式建模表格结构，以及引入排列不变性奖励机制。复杂层级与不规则表格推理旨在解决嵌套表头、合并单元格及非结构化文本混合表格的理解难题，难点在于解析复杂的物理与逻辑结构，潜在路径包括语义树重建、分区感知推理以及代码驱动的结构化解析。对进入者最值得做的一件事是构建统一基准同时评估显式图/超图与隐式多模态融合在相同噪声条件下的表现，以解决当前证据强度中等的分歧。
