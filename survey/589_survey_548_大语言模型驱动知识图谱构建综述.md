综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Knowledge%20Graph%20Construction%20with%20LLMs)

## 导读

知识图谱（Knowledge Graph, KG）作为结构化知识的基石，长期受限于规则与监督学习在开放域数据上的泛化瓶颈。大语言模型（Large Language Model, LLM）的介入将构建范式从静态的规则映射重构为动态的语义涌现，极大提升了自动化程度。然而，LLM 的幻觉特性与实体碎片化问题随之凸显，迫使研究重心从单纯的三元组抽取转向证据接地、共指消解及图结构一致性维护。2024 年以来，动态增量构建与无模式（Schema-free）抽取成为新焦点，旨在解决静态图谱在实时数据流中的适应性不足。各路线在精度、效率与灵活性之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从嵌入表示到智能体协同的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

传统知识图谱构建依赖本体工程、知识抽取与知识融合三阶段流水线，其核心假设是知识可被形式化为静态的实体-关系网络。这一范式在垂直领域取得了成功，但在面对非结构化、多源异构数据时，暴露出可扩展性差、数据稀疏及长尾关系泛化能力弱的根本缺陷。具体而言，规则引擎难以覆盖长尾语义，监督模型受限于标注成本，导致图谱在开放域环境中覆盖率低且更新滞后。这种“数据-标注”瓶颈构成了该领域早期发展的主要约束条件，也预示了后续范式转移的必然性。

LLM 的兴起从根本上改变了这一约束结构。凭借强大的语义理解与生成能力，LLM 能够以零样本或少样本方式直接从非结构化文本中抽取三元组，将问题定义从“如何高效标注”重构为“如何利用语义推理直接构建”。这一转变不仅降低了数据依赖，更将本体工程从“前置约束”转变为“可选引导”。然而，LLM 的生成特性引入了新的核心矛盾：语义泛化能力与事实准确性之间的张力。模型倾向于生成看似合理但无文本依据的三元组（幻觉），且缺乏全局视角的局部抽取导致同一实体被拆分为多个节点，造成图谱结构碎片化。

因此，当前领域的核心问题已演化为：如何在缺乏完整预定义本体且数据非结构化的开放域环境中，利用 LLM 的语义推理能力，构建出事实准确、结构一致且可动态演化的知识图谱。这一核心问题衍生出三个相互依赖的子问题：本体定义制约抽取上限，实体消解决定图谱连通性，动态更新决定图谱生命力。本体工程不再是唯一的起点，而是与抽取过程动态交互；实体消解与共指消解成为提升结构质量的关键清洗步骤；而动态性则要求图谱能够适应实时数据流的变化。

从时间维度看，该领域经历了显著的约束演化。2013 年至 2020 年间，TransE 与 RotatE 等嵌入方法奠定了知识表示的基础，但受限于静态假设与标注依赖。2020 年 RAG 范式的出现引入了外部知识检索，初步缓解了知识滞后问题，但尚未触及图谱构建的核心流程。2023 年至 2024 年是关键转折期，LLM 零样本抽取确立，GraphRAG 通过局部到全局的策略解决了多跳推理中的证据不可共置问题，标志着 LLM 从“工具”向“引擎”的转变。

2025 年以来，研究重心迅速向深层问题倾斜。静态批处理模式难以适应实时变化，促使 ATOM 等动态时间建模方法出现，区分事实观察时间与有效期。与此同时，预定义本体的局限性在开放域中暴露无遗，TRACE-KG 与 DIAL-KG 等无模式方法开始探索由 LLM 自主发现并演化本体结构。当前，领域正处于从“能否抽取”向“如何验证、融合与动态维护”过渡的阶段，形成了“LLM 解释、嵌入组织、图涌现”的新生态。

**如果用一个核心问题概括该领域，那便是：如何在缺乏完整预定义本体且数据非结构化的开放域环境中，利用大语言模型的语义推理能力，构建出事实准确、结构一致且可动态演化的知识图谱。**

## 2. 方法体系

- 2013：TransE——基于平移原理奠定知识表示基线

- 2019：RotatE——利用复数旋转统一处理多种关系模式

- 2020：RAG——引入外部知识检索缓解知识滞后

- 2024：GraphRAG——局部到全局策略解决多跳推理证据不可共置

- 2025：CORE-KG——类型感知指代消解解决节点重复

- 2025：ATOM——双时间建模支持动态时间图谱增量更新

- 2026：DIAL-KG——无模式增量构建支持动态 Schema 演化

- 2026：post-graph-rag——PostgreSQL 原生引擎解决多文档事实组合检索

这条时间线勾勒了该领域方法演进的代表性节点：从 2013 年的 TransE 奠定该领域方法基线，经 2019 年 RotatE 的推进，到 2026 年的 post-graph-rag 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 抽取优化与增强

抽取优化路线的核心目标是提升三元组抽取的精度与结构一致性，其技术演进始于对 LLM 提示工程的精细化。早期方法如 ODKE+（Khorshidi et al., 2025, P1）采用本体引导策略，通过构建自然语言断言并查询 LLM 判断事实是否受上下文支持，以“后验验证”机制最小化幻觉。这种方法放弃了无约束生成的灵活性，换取了事实准确性，但其依赖预定义本体，在开放域中适应性受限。针对静态提示导致的性能停滞，KRPO（Jing et al., 2026, P14）引入了知识恢复驱动的提示优化机制，利用自评估过程中的文本梯度作为反馈动态优化提示，并引入动态模式扩展消除语义歧义。KRPO 放弃了固定提示的稳定性，换取了开放域关系抽取的一致性与精度提升，其成功依赖于 LLM 具备可靠的自评估能力。

实体碎片化是抽取后的另一大挑战。CORE-KG（Meher and Domeniconi, 2025, P7）设计了类型感知指代消解模块，利用 LLM 上下文推理统一语义等价提及，并通过增量构建类型特定提示缓存解决跨文档引用解析难题。该方法放弃了端到端抽取的简洁性，换取了图谱节点的唯一性与结构连通性，特别适用于法律等复杂文本。TRACE-KG（Abolhasani et al., 2026, P21）则进一步突破预定义模式限制，采用高召回局部提取、语义邻域形成及受约束解析的流程，通过嵌入聚类与 LLM 函数调用实现渐进式模式承诺。TRACE-KG 放弃了全局规范化的一致性，换取了对复杂文档的适应性与可审计性，解决了无预定义模式下词汇碎片化的矛盾。

与抽取优化路线形成互补的是 SocraticKG（P34），它通过问答驱动的事实提取解决事实覆盖与结构连贯性之间的张力，强调文档级语义组织而非句法规范化。这种方法在提升图谱连通性方面表现优异，但计算成本较高。总体而言，抽取优化路线通过提示工程、接地验证与指代消解的组合，在精度与结构质量上取得了显著进展，但其成功往往依赖于特定的文本结构假设或本体约束，与后续动态构建路线在“静态精度”与“动态适应”上形成竞争。

### 2.2 动态与增量构建

动态构建路线旨在解决静态图谱在实时数据流中的适应性不足问题，其核心转折在于引入时间维度与增量更新机制。ATOM（Lairgi et al., 2025, P6）引入了双时间建模机制，区分事实观察时间与事实本身的有效期，通过并行架构确保可扩展性。ATOM 放弃了静态图谱的简单性，换取了对实时数据流变化的适应能力，其成功依赖于时间戳信息的准确提取与增量比较逻辑的稳定性。

在无模式增量构建方面，DIAL-KG（Bao et al., 2026, P17）设计了双轨提取、治理裁决及模式演化的框架，支持动态知识图谱的自主迭代。DIAL-KG 放弃了预定义本体的刚性约束，换取了图谱对新知识的自主适应能力，通过演化意图评估确保新知识在逻辑与证据验证后原子化集成。这种方法在开放域中展现出强大的灵活性，但系统复杂性显著增加，对验证机制的要求极高。

GraphRAG 的演进也体现了动态性的需求。post-graph-rag（Rajah, 2026, P30）开发了 PostgreSQL 原生 Graph RAG 引擎，结合双级关键词条件、实体向量搜索及一跳遍历，显式渲染否定与取代关系。该引擎解决了传统 RAG 在多文档事实组合检索中的结构性失败问题，通过原生数据库集成降低了部署复杂性。RAGA（Han and Cheng, 2026, P24）则进一步将知识提取转变为动态交互式认知过程，智能体具备写入操作能力，支持实体创建及图谱更新，实现了 KG 的持续演化。动态构建路线与抽取优化路线互补，前者提供了图谱的生命力，后者提供了构建的精度基础，但两者在系统复杂性与一致性维护上存在张力。

### 2.3 高效训练与蒸馏

高效训练与蒸馏路线聚焦于降低 LLM 构建成本，实现轻量级模型的高效部署。D-SynthKG（P35）通过合成数据生成与模型蒸馏，使小型 LLM 达到大型模型的 KG 构建质量。该方法放弃了大型模型的通用泛化能力，换取了计算成本的显著降低，证明了在适当合成数据训练下，轻量级模型可实现高效部署。其成功依赖于合成数据的质量及蒸馏策略的有效性，若合成数据存在偏差，小模型将继承这些偏差。

AutoGraph-R1（Tsang et al., 2025, P4）应用端到端强化学习优化 KG 构建，通过环境交互与奖励反馈学习顺序决策能力。该方法放弃了传统启发式方法的透明性，换取了模型在复杂数据感知中的自适应能力，提升了图谱推理的准确性。InvertiTune（Faez et al., 2025, P13）提出高质量数据合成方法，用于成本效益的单次文本到 KG 生成，解决了手动构建 KG 成本高及易过时问题。RAGU（Komarov et al., 2026, P29）则使用紧凑领域适配 LLM，通过持续预训练及监督微调优化 NER-RE 及多跳 QA 能力，为 GraphRAG 提供了轻量级部署方案。高效训练路线与抽取优化路线形成继承关系，前者为后者提供了低成本的执行引擎，但牺牲了部分泛化能力，适用于资源受限或特定领域场景。

### 2.4 垂直领域应用

垂直领域应用路线针对生物医学、教育、电商等特定领域，解决行业数据异构性及专业语义提取挑战。MEDAKA（Sengupta et al., 2025, P2）构建基于 LLM 的生物医学 KG 流水线，通过多数投票过滤确保三元组准确性，针对生物医学数据异构性实现了自动化转换。InstructKG（AlRabah et al., 2026, P15）构建讲师对齐的教育 KG，提取细粒度概念并推断依赖关系，通过证据聚合为 LLM 关系判断提供上下文。EvidenceNet（Zong et al., 2026, P19）将实验发现表示为显式证据记录而非直接三元组，保留来源、研究背景及定量支持，解决了传统 KG 丢失上下文的问题。

CogNet-KG（P36）构建认知结构化 KG 以增强 STEM 学习辅导对话，通过多智能体框架审查关系，解决 LLM 幻觉导致的知识结构错误。ATR4CH（Schimmenti et al., 2025, P8）结合 LLM 提取与本体工程，处理文化遗产文本，确保提取知识符合 LOD 标准。垂直领域应用路线与通用构建路线形成互补，前者通过领域本体与专家知识弥补 LLM 在垂直领域的语义偏差，但自动化程度有限，需结合人工反馈循环。

### 2.5 评估基准与工具

评估基准与工具路线旨在量化 LLM 构建能力并支持可复现的实验研究。BLINKG（Castedo et al., 2026, P25）开发 LLM 集成 KG 生成基准，涵盖本体类识别、主体生成等任务，填补了自动化 KG 构建评估的空白。KGpipe（Hofer and Rahm, 2025, P11）提出数据集成到 KG 的管道生成与评估框架，自动化组装信息抽取、本体对齐及实体匹配工具，解决了 KG 管道手工构建复杂、难以复用问题。Taxoria（Ghamlouch and Alam, 2025, P16）提出基于 LLM 的分类法丰富管道，通过来源追踪与可视化缓解幻觉，支持语义推理与知识管理。

mcp-proto-okn（Rose et al., 2026, P26）提出通过模型上下文协议访问开放科学 KG 的自然语言接口，简化了 LLM 与 KG 交互。RDF KG Generation Evaluation（Martin et al., 2026, P20）评估 LLM 在自动化 RDF KG 生成中的性能，揭示了不同 LLM 在结构化输出生成中的差异。评估基准路线为其他路线提供了标准化的实验平台，但其本身不直接解决构建问题，而是通过量化指标揭示方法优劣，促进领域研究的可比性。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLM 显著提升了 KG 构建的自动化程度与泛化能力，尤其在零样本/少样本场景下优于传统监督模型，这一共识在多个基准上被反复验证：HGNet 在 DocRED 上的 45.20% 与 InvertiTune 在 KELM 上的 85.2% 均大幅超越传统基线。共指消解与实体规范化是提升 KG 结构质量的关键步骤，能有效减少节点重复并增强图的连通性，CORE-KG 与 TRACE-KG 在 WebNLG 上的表现印证了这一点。证据接地（Grounding）与验证机制是缓解 LLM 幻觉、确保 KG 事实准确性的必要环节，ODKE+ 与 Wikontic 通过接地验证实现了高精度抽取。

与此相关的另一个共识是 KG 与 RAG 的协同（GraphRAG）能显著提升多跳推理及全局查询性能，优于纯文本检索。Wikontic 在 MuSiQue 上的 59.8% 与 RAGU 在 HotpotQA 上的 75.2% 均表明，结构化图谱为多跳推理提供了必要的语义骨架。动态 Schema 演化与无模式抽取是应对开放域及领域特定知识的有效策略，但需结合本体约束以保证一致性，TRACE-KG 与 DIAL-KG 的实践证明了这一路径的可行性。多智能体（Multi-Agent）框架通过分工协作能提升 KG 构建的鲁棒性与可解释性，CogNet-KG 与 RAGA 的设计体现了这一趋势。领域特定 KG 构建需结合领域本体或专家知识，纯数据驱动的 LLM 抽取在垂直领域易出现语义偏差，MEDAKA 与 InstructKG 的成功依赖于领域本体的引导。合成数据生成与模型蒸馏是降低 KG 构建成本、提升小模型性能的有效途径，D-SynthKG 与 RAGU 证明了轻量级模型在适当训练下的高效部署能力。

### 3.2 观点分歧

Schema-free 与 Schema-based 之争是领域核心分歧之一。Schema-free 路线（代表：TRACE-KG, DIAL-KG）主张无预定义本体，由 LLM 自主发现模式，适应性强；Schema-based 路线（代表：Wikontic, ODKE+）主张基于预定义本体引导抽取，保证一致性和可解释性。现有证据偏向 Schema-based 在垂直领域（如生物医学）表现更稳定，但 Schema-free 在开放域（如 WebNLG）上接近 SOTA。TRACE-KG 在 WebNLG 上的 84% 接近 Wikontic 的 86%，但在长尾关系上可能更优。分歧根源在于缺乏统一的“结构一致性”量化指标，且不同领域对 Schema 的需求差异大，难以一概而论。

这一分歧的背后，是另一个更根本的争论：端到端 LLM 与模块化流水线的架构选择。端到端路线（代表：AutoGraph-R1, RAGA）主张 LLM 直接生成图谱，简化流程，利用 RL 优化；模块化路线（代表：CORE-KG, ODKE+）主张分阶段抽取、消歧、验证，提高可控性。模块化方法在事实准确性（接地验证）和可解释性上占优，端到端方法在灵活性和潜在推理能力上占优。证据强度较强，模块化方法在垂直领域应用更广泛。分歧根源在于端到端方法的“黑盒”特性使得错误难以定位，而模块化方法的累积误差问题尚未完全解决。

### 3.3 其他开放问题

最紧迫的工程问题是多模态知识图谱构建。当前研究主要聚焦文本，但教育、科学等领域知识分散在文本、图像、视频中，单一模态抽取信息不全。跨模态对齐及证据溯源机制尚不成熟，潜在路径包括多模态嵌入和跨模态注意力机制。最根本的研究问题是动态本体的形式化定义与收敛性证明。DIAL-KG 等动态 Schema 演化方法缺乏理论保证，无法证明其演化过程是否收敛到稳定本体。LLM 幻觉的根源机制亦未完全揭示，现有证据接地机制多为后验过滤，缺乏生成过程中的内在约束。

已知—争议—未知认知图谱显示：已知 LLM 提升自动化程度、接地验证缓解幻觉、GraphRAG 增强多跳推理；争议 Schema-free 与 Schema-based 优劣、端到端与模块化架构选择；未知动态本体收敛性、多模态对齐机制、幻觉根源。发展趋势将走向动态、多模态及智能体协同的自适应知识系统，KG 将成为 LLM 的外部记忆与推理引擎，形成共生生态。

## 4. 总结与展望

LLM 驱动 KG 构建已从“工具替代”进入“范式重构”阶段。核心挑战不再是“如何抽取”，而是“如何在开放域中维持事实准确与结构一致”。传统方法的瓶颈在于对人工标注和固定规则的过度依赖，LLM 的引入将问题定义从“模式匹配”重构为“语义推理”，但随之带来了幻觉、碎片化和动态性缺失等新挑战。方法取舍总结显示，精度、效率与灵活性的平衡是永恒主题：抽取优化追求高精度但成本高，动态构建追求灵活性但一致性难保，蒸馏追求效率但牺牲部分泛化能力。

未来可能突破的方向包括：基于 RL 的端到端 KG 构建（AutoGraph-R1）和智能体驱动的自主演化（RAGA），可能突破当前模块化流水线的上限；多模态 KG 构建（整合文本、图像、音频），解决单一模态信息不完整的问题；动态知识图谱更新（支持实时或近实时的 KG 更新），解决静态 KG 无法反映知识变化的问题。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，建立涵盖结构一致性、事实保留率及下游任务效用的综合评估基准，以揭示方法优劣的真实来源，避免被单一指标误导。
