# A Survey of Knowledge Graph Completion Methods ｜知识图谱补全方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Knowledge%20Graph%20Completion%20and%20Reasoning)

## 导读

知识图谱补全（Knowledge Graph Completion, KGC）旨在预测图谱中缺失的实体或关系，其核心价值在于缓解结构化数据稀疏性与开放世界推理需求之间的张力。早期研究以几何嵌入为主线，通过低维向量空间的平移或旋转捕捉结构模式，思路简洁却受制于长尾实体的泛化瓶颈。当归纳式基准暴露出传统模型对未见实体的失效后，研究者转向子图推理与预训练语言模型，用更强的语义先验换取跨实体鲁棒性。随着大型语言模型（Large Language Models, LLMs）的引入，领域重心从单纯的几何匹配转向语义与结构的深层对齐，各路线在表示质量、推理深度与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义-结构协同的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

知识图谱作为结构化知识表示的核心载体，广泛应用于问答、推荐及常识推理，但其固有的不完整性和噪声问题催生了 KGC 这一关键任务。KGC 的核心形式化通常定义为链接预测（Link Prediction, LP）：给定一个部分三元组 $(h, r, ?)$ 或 $(?, r, t)$，模型需评估候选实体 $e$ 作为缺失元素的可能性，即计算 $P(e | h, r)$ 或 $P(e | r, t)$。在标准的 $N$-way $K$-shot 设定下，模型需在包含 $N$ 个候选实体的集合中，将正确实体排在最前。这一任务看似简单，实则隐含了从封闭世界假设向开放世界推理的认知转变，其本质是在信息缺失下进行概率推断。

问题的定义并非静止不变，而是随着数据规模的扩大和模型能力的提升而演化。早期研究主要依赖基于嵌入的几何模型，如 TransE 和 RotatE，通过低维向量空间捕捉实体与关系的结构模式。这一阶段的假设是结构信号足以表征语义，模型只需在密集局部结构中进行模式匹配。然而，这种转导式（Transductive）学习范式存在根本缺陷：模型记忆的是特定实体的嵌入向量，当测试集中出现训练集未见的新实体时，模型完全失效。这一局限在长尾实体和动态知识图谱场景中尤为突出，迫使研究者重新审视问题的边界。

为应对新实体涌现问题，研究重心逐渐从转导式预测转向归纳式（Inductive）学习。归纳式 KGC 要求模型能够泛化到训练集中未见的实体或关系，其核心假设从“记忆已知实体”演变为“学习可迁移的关系模式”。这一转变引入了子图推理（Subgraph Reasoning）机制，通过提取查询三元组周围的局部子图结构来学习关系模式，摆脱了对实体 ID 的依赖。然而，子图提取也带来了新的挑战：局部结构噪声可能干扰关键语义依赖，且子图提取的计算开销随图规模增加而显著上升。

与此同时，大规模预训练语言模型和 LLM 的兴起引发了范式层面的第二次转变。研究焦点从单纯的几何结构匹配转向融合文本语义与图结构的混合范式。这一阶段的矛盾在于 LLM 基于 token 序列操作，而 KG 以实体为基本单位，两者之间存在显著的粒度不匹配。直接拼接前缀或简单提示工程难以同时捕捉文本语义和图结构完整性，需通过专用 token 化、量化或深层交叉注意力解决。此外，多模态 KG 补全、不确定 KG 推理以及基于扩散模型的生成式补全成为新热点，旨在构建更鲁棒、可解释且具备开放世界推理能力的 KG 系统。

从时间维度看，2016-2018 年是奠基期，TransE 和 ConvE 确立了基于翻译和卷积的嵌入范式，解决了密集结构下的基本预测问题。2020 年前后，GraIL 和 NBFNet 的提出标志着归纳式子图推理范式的成熟，解决了新实体泛化难题。2022-2023 年，KGT5 和 SimKGC 验证了预训练语言模型在 KGC 中的潜力，开启了语义-结构对齐的研究热潮。2024-2025 年，SLiNT 和 GMT 等方法通过结构感知注入和图作为记忆的交叉注意力，实现了 LLM 与 KG 的深度融合。2026 年，GRiD 和 PROBE 等工作的出现，表明领域正从确定性评分转向生成式规则挖掘和鲁棒评估，当前形态呈现出多模态、语义增强及生成式推理并存的复杂格局。

**如果用一个核心问题概括该领域，那便是：如何在保持图结构拓扑完整性的同时，有效融合外部语义先验以解决长尾实体泛化与开放世界推理中的不确定性问题。**

## 2. 方法体系

- 2013：TransE——奠定基于翻译的 KGC 范式基线

- 2015：DistMult——引入双线性函数处理对称关系

- 2018：ConvE——利用卷积神经网络提取局部结构特征

- 2019：RotatE——在复数空间中通过旋转建模关系

- 2020：GraIL——提出基于子图的归纳链接预测框架

- 2022：KGT5——将 KGC 转化为序列到序列文本生成任务

- 2025：SLiNT——提出结构感知语言模型框架

- 2026：PROBE——提出预测锐度与流行度偏差鲁棒性评估框架

这条时间线勾勒了该领域方法演进的代表性节点：从 2013 年的 TransE 奠定该领域方法基线，经 2015 年 DistMult 的推进，到 2026 年的 PROBE 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 大模型融合补全

大模型融合补全路线旨在利用 LLM 的语义理解能力弥补 KG 结构稀疏性，其核心挑战在于解决 LLM 的 token 粒度与 KG 实体粒度之间的不匹配。早期尝试如 KGT5（Bao et al., 2022）将 KGC 转化为序列到序列任务，通过 T5 模型直接生成缺失实体名称，验证了预训练语言模型的潜力，但受限于浅层前缀拼接，难以捕捉深层结构依赖。SLiNT（Yang et al., 2025, P1）针对结构稀疏和语义歧义问题，提出了结构感知语言模型框架。该方法通过结构引导邻域增强、对比学习和结构感知注入三个模块，利用预训练 KG 嵌入进行邻域增强，并通过 LoRA 适配器高效微调 LLM 骨干。SLiNT 放弃了 LLM 的通用性，换取了对长尾实体的结构感知精度，其成功依赖于预训练 KG 嵌入的质量。

GMT（Liu et al., 2025, P5）进一步突破了前缀拼接的局限，提出图作为记忆的跨注意力机制。该方法将局部图结构编码为显式记忆，并通过深度 token 级交叉注意力注入 LLM，实现细粒度的证据检索。GMT 解决了 SLiNT 中结构信号注入不够细粒度的问题，允许 LLM 在生成过程中动态访问图结构信息，但增加了注意力计算的开销。KGT（Su et al., 2026, P14）则从分词策略入手，引入专用实体 token，构建实体级别的特征表示，通过解耦机制平衡语义与结构信息。KGT 放弃了传统词汇表的简洁性，换取了更自然的实体预测和全空间预测能力，其代价是增加了词汇表大小和分词复杂度。

### 2.2 归纳与零样本补全

归纳与零样本补全路线聚焦于模型对未见实体或关系的泛化能力，其核心假设是关系模式具有可迁移性。GraIL（Teru et al., 2020）奠定了子图推理范式，通过提取查询三元组周围的局部子图结构来学习关系模式，摆脱了对实体 ID 的依赖。TyleR（De Bellis et al., 2025, P2）提出无类型但类型感知的归纳链接预测方法，利用预训练语言模型推导隐含类型语义，弥补了类型信息的缺失。TyleR 解决了传统归纳方法在类型稀疏场景下的鲁棒性问题，其成功依赖于 PLM 的语义质量。

CPSR（Wang et al., 2026, P11）提出累积路径级语义推理框架，通过累积推理路径上所有节点的语义影响，捕捉长程语义依赖，并利用噪声过滤机制去除无关结构信息。CPSR 解决了传统方法忽略长程依赖的问题，但增加了路径遍历的计算复杂度。Flock（Kim et al., 2025, P4）基于随机游走学习 KG 基础模型，利用概率节点-关系等变性作为归纳偏置，无需确定性等变性约束，实现了跨领域和跨关系的泛化。Flock 为构建通用 KG 基础模型提供了新路径，其代价是增加了随机过程的计算开销。

### 2.3 逻辑推理与规则挖掘

逻辑推理与规则挖掘路线注重推理的可解释性和规则发现，旨在通过逻辑规则捕捉复杂关系模式。SLogic（Le et al., 2025, P3）提出子图知情逻辑规则学习框架，通过提取查询中心的子图，生成富含上下文信息的实例，训练动态查询依赖评分函数。SLogic 解决了传统规则静态置信度无法适应查询上下文的问题，其成功依赖于子图提取的质量。

GRiD（Cheng et al., 2026, P17）利用扩散模型生成图状逻辑规则，通过条件去噪过程发现规则体，并结合强化学习优化规则质量。GRiD 将规则发现建模为离散扩散过程，实现了可解释且高质量的规则生成，推动了生成式规则挖掘的发展。HyperCoT（2026, P34）提出超图链式思维框架，用于 N 元知识图谱补全，通过 Graph-CoT 生成推理路径，解决了 N 元关系中的复杂交互问题。

### 2.4 多模态与不确定补全

多模态与不确定补全路线处理包含视觉、文本等多模态信息或带有置信度不确定性的 KG。ssCDL（Wu et al., 2025, P6）提出半监督置信度分布学习框架，结合伪标签生成与元学习优化，解决了不确定 KG 中缺失标签的问题。QUEST（Jahin et al., 2026, P28）提出谱初始化和调度图平滑方法，利用 k 个最小非平凡特征向量初始化实体嵌入，通过调度图平滑正则化优化训练稳定性，解决了传统方法中梯度冲突导致的训练不稳定问题。

DMKGC（Sheng et al., 2026, P25）提出条件扩散引导知识转移框架，利用支持 KG 作为条件，通过扩散模型生成领域通用实体嵌入，实现了跨领域知识的有效转移。SynergyKGC（Zou et al., 2026, P12）提出拓扑感知协同框架，通过渐进式双塔框架对齐语义流形和拓扑信号，解决了传统方法中结构信号作为静态特征的问题。

### 2.5 评估基准与鲁棒性

评估基准与鲁棒性路线旨在解决现有评估偏差、数据稀疏性及对抗攻击下的稳定性问题。PROBE（Moon et al., 2026, P19）提出预测锐度与流行度偏差鲁棒性评估框架，通过秩变换和聚合器重新定义 KGC 指标，解决了现有指标对流行度偏差敏感的问题。PROBE-Dual（Moon and Ko, 2025, P9）进一步通过双视角分析，揭示了现有指标的局限性。MCDM-KGC（Gul and Bhat, 2026, P21）提出多准则决策分析框架，利用 EDAS、TOPSIS 等聚合器结合多个秩指标，解决了指标冲突问题。

### 2.6 智能体与问答推理

智能体与问答推理路线将 KGC 应用于问答任务，利用智能体框架处理不完整知识。GR-Agent（Zhou et al., 2025, P10）提出自适应图推理智能体，通过多跳检索和推理解决不完整知识下的问答问题，利用 LLM 动态规划推理路径，结合图检索增强生成，有效缓解了多跳推理中的信息缺失和幻觉问题。DoM（Liu et al., 2025, P8）提出混合知识辩论框架，利用多智能体协作，通过辩论机制解决知识冲突和缺失问题。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域共识在于融合文本语义与图结构的混合范式能显著提升 KGC 性能，优于单一模态方法。这一共识在多个基准上被反复验证：GMT 的 56.8 MRR 与 SLiNT 的 55.2 MRR 均大幅超越经典 RotatE 的 48.2 MRR，表明语义-结构对齐的有效性。与此相关的另一个共识是归纳式 KGC 是应对新实体涌现的关键，要求模型学习可迁移的关系模式而非记忆实体特定嵌入。TyleR 和 CPSR 在 WN18RR 上的表现（78.5 MRR 和 76.4 MRR）进一步验证了归纳式学习在层级稀疏结构下的优势。

### 3.2 观点分歧

LLM 与 KG 的交互深度是领域内的主要分歧。观点 A 认为前缀拼接或简单提示工程足以利用 LLM 语义，计算成本低，易于部署；观点 B 认为必须通过交叉注意力、量化或专用 Token 实现细粒度对齐，才能捕捉结构-语义的深层依赖。现有证据偏向观点 B，GMT 在 FB15k-237 上的 56.8 MRR 显著优于浅层方法 KICGPT 的 55.0 MRR，尤其在长尾实体子集上优势更明显。然而，深层融合的计算开销限制了其在超大规模 KG 上的应用，且缺乏统一的基准来量化“交互深度”对性能的具体贡献边界。

判别式评分与生成式补全的对比是另一个根本性争论。观点 A 认为嵌入模型和 GNN 评分效率高，适合大规模实时推理；观点 B 认为扩散模型和 LLM 生成能捕捉三元组依赖和高阶结构，更适合复杂推理和不确定性场景。证据混合：在标准链接预测任务上，判别式方法仍具竞争力；但在超关系（JF17K）和不确定 KG（CN15k）任务上，生成式方法展现出独特优势。分歧根源在于生成式方法的评估指标与判别式不可直接比较，且生成式模型在大规模 KG 上的可扩展性尚未得到充分验证。

### 3.3 其他开放问题

最紧迫的工程问题是如何高效压缩多模态 Token 并实现实时推理。当前多模态 KGC 方法如 KGT 和 ELMM 在 DB15K 上的表现虽好，但计算开销巨大，限制了其在实际部署中的应用。关键困难在于如何平衡视觉 token 的压缩率与信息保留，潜在技术路径包括多视图视觉 token 压缩器和注意力剪枝。

最根本的研究问题是如何在开放世界中定义“正确”的补全。现有指标无法衡量事实一致性，PROBE 等鲁棒性指标虽揭示了传统指标的盲区，但尚未成为社区标准。关键困难在于如何定义统一的评估视角并平衡不同指标间的权衡，潜在技术路径包括广义排名评估框架和多准则决策分析。

已知—争议—未知认知图谱显示，语义-结构对齐的有效性是已知共识，交互深度和生成式 vs. 判别式的优劣是争议焦点，开放世界事实一致性验证和高效多模态推理是未知领域。未来趋势将依赖于语义-结构深层对齐机制的标准化及鲁棒评估体系的建立。

## 4. 总结与展望

知识图谱补全的核心矛盾在于结构稀疏性与语义缺失的协同解决。从 TransE 的几何匹配到 SLiNT 和 GMT 的语义-结构深度融合，研究路线经历了从封闭世界到开放世界、从确定性评分到生成式推理的范式重构。核心瓶颈在于 LLM 与 KG 的粒度不匹配、多模态噪声过滤以及开放世界事实一致性验证的缺失。

未来可能突破的方向包括：基于扩散模型的生成式补全和智能体驱动的动态推理，可能突破静态评分的天花板（GRiD, P17; GR-Agent, P10）；多模态知识图谱补全中的高效 Token 压缩与语义对齐（KGT, P14; ELMM, P7）；以及鲁棒评估框架的标准化（PROBE, P19; MCDM-KGC, P21）。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，系统评估不同语义-结构对齐策略在长尾实体和开放世界场景下的真实性能，并引入 PROBE 等鲁棒性指标以全面评估模型能力。
