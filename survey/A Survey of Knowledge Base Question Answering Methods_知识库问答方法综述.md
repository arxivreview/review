# A Survey of Knowledge Base Question Answering Methods ｜知识库问答方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Knowledge%20Base%20Question%20Answering%20with%20LLMs)

## 导读

知识库问答（Knowledge Base Question Answering, KBQA）旨在利用结构化知识回答自然语言问题，其核心价值在于缓解大语言模型（LLM）语义泛化能力与知识图谱（KG）事实精确性之间的张力。早期研究以语义解析（SP）为主线，通过生成可执行逻辑形式实现精确查询，思路严谨却受制于生成错误导致的不可执行风险。当 LLM 引入后暴露出事实幻觉与逻辑形式偏差，研究者转向检索增强生成（RAG）与智能体（Agentic）范式，用外部子图证据与动态规划换取推理的鲁棒性与长程连贯性。各路线在事实接地、逻辑精确与计算效率之间做出了不同取舍，由此形成当前神经符号结合的方法格局。本综述梳理这条从符号解析到智能体交互的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

KBQA 的核心任务是将自然语言问题映射到结构化知识库中的事实，其形式化定义通常采用 N-way K-shot 范式，即给定 $N$ 个候选类别（实体或关系）和每个类别 $K$ 个支持样本，模型需推断查询问题的答案。在 LLM 介入前，该问题主要依赖语义解析（SP）或信息检索（IR）两种范式：SP 追求生成可执行的逻辑形式（Logical Form, LF），如 SPARQL 查询，强调精确性但泛化能力差；IR 则从 KG 中检索相关子图或路径，侧重证据召回但缺乏逻辑约束。这两种范式在 2020 年前后面临共同瓶颈：SP 方法在未见过的实体或复杂句式上生成错误率高，IR 方法在多跳推理中易遗漏关键路径。

LLM 的兴起从根本上重塑了问题定义。2020-2022 年间，研究重心从“精确解析”转向“生成式理解”，LLM 被用作语义解析器直接生成逻辑形式，解决了传统 SP 泛化差的问题，但引入了幻觉与不可执行的新矛盾。此时，子问题依赖关系变得清晰：逻辑形式的可执行性是 SP 范式的基础，若不解决则无法精确查询；而 LLM 参数化知识的不完整与静态性，导致其在 KG 推理中产生事实幻觉，迫使问题定义演变为“如何检索正确的子图以约束 LLM 生成”。2023-2024 年，检索增强生成（RAG）与 KG 结合形成 GraphRAG 范式，通过检索子图增强 LLM 的事实准确性，重点解决检索效率与证据完整性问题。

2025-2026 年，面对多跳复杂推理中证据碎片化导致推理链断裂的挑战，问题定义进一步细化为“LLM 作为智能体如何通过规划、记忆与自我修正在 KG 上进行长程探索”。此时，智能体（Agentic）范式成为主流，强调过程的可控性与鲁棒性，依赖前两者的检索与验证机制作为工具。这一阶段的关键转折在于，研究不再仅关注单次查询的准确性，而是关注长程推理中的信用分配、记忆管理与动态规划。例如，ToG（2023）开启了 LLM 与 KG 动态交互的新方向，而 EvoMemKG（2025）与 CLAUSE（2026）则通过引入可进化记忆与多智能体协同，解决了长轨迹推理中的信息丢失与局部最优问题。

当前领域形态呈现出神经符号结合（Neuro-Symbolic）的主流趋势，即利用符号结构（KG/逻辑）约束神经网络（LLM）的生成，以提升可解释性与鲁棒性。范式边界日益清晰：SP 范式强调精确但脆弱，IR/RAG 范式强调鲁棒但可能模糊，Agentic 范式强调灵活但计算成本高。这些范式并非线性替代，而是围绕“事实接地”与“逻辑精确”两个维度形成的互补与竞争格局。例如，SELF-KBQA 结合了子图检索与逻辑形式生成，而 CLAUSE 则调用检索与执行工具进行动态规划。这种层级依赖关系表明，单一范式难以解决所有子问题，必须通过组合策略应对不同场景。

**如果用一个核心问题概括该领域，那便是：如何在利用 LLM 强大语义理解能力的同时，通过神经符号机制（如 KG 约束、逻辑验证、智能体规划）确保推理过程的事实一致性与逻辑可执行性。**

## 2. 方法体系

- 2013：SemParse——奠定 SP-based 方法基线

- 2016：KVMN——开创 IR-based 外部记忆范式

- 2020：RnG-KBQA——确立检索-生成混合范式

- 2023：ToG——开启 Agent-based KGQA 新方向

- 2023：GraphRAG——推动 Graph-RAG 范式发展

- 2025：EvoMemKG——引入可进化记忆机制

- 2026：CLAUSE——提出代理神经符号框架

- 2026：SAGA——代表模式感知接地前沿

这条时间线勾勒了该领域方法演进的代表性节点：从 2013 年的 SemParse 奠定该领域方法基线，经 2016 年 KVMN 的推进，到 2026 年的 SAGA 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 逻辑形式生成

逻辑形式生成路线旨在将自然语言问题转化为可执行的结构化查询，其核心挑战在于解决 LLM 生成逻辑形式时的语法错误与语义接地问题。早期方法如 RnG-KBQA（2020）采用检索-生成策略，先枚举候选再生成，解决了检索与生成脱节的问题，但流程复杂。随着 LLM 能力增强，研究转向直接生成，但面临幻觉风险。CompKBQA（2025）提出组件级任务分解框架，将逻辑形式生成拆解为骨架生成、关系生成与实体接地三个子任务，通过分阶段处理缓解了 LLM 在生成完整逻辑形式时的幻觉问题，特别是针对骨架错误与关系错误进行了针对性优化。其代价是增加了推理步骤与延迟，且各阶段错误可能累积。该方法在 WebQSP 等数据集上显著提升了逻辑形式的准确性，为复杂 KBQA 提供了可解释的生成范式。

GRV-KBQA（2025）进一步提出三阶段框架，解耦逻辑结构生成、语义接地与结构感知验证。该方法首先利用 LLM 生成包含占位符的逻辑形式模板，然后通过检索模块填充具体的实体与关系，最后通过结构感知验证器检查逻辑形式的可执行性。核心创新在于将结构生成与语义接地分离，避免了 LLM 直接生成具体实体带来的幻觉问题。主要改进点在于引入了验证机制，确保生成的逻辑形式在 KG 中可执行，显著提升了答案的准确性。代价是增加了验证步骤的复杂度，且依赖检索模块的质量。该方法在 WebQSP 与 CWQ 上取得了 SOTA 性能，为可靠 KBQA 提供了系统性解决方案。

SAGA（2026）则聚焦于模式感知接地，通过模式感知的查找与过滤，引导 LLM 构建可执行 SPARQL 查询。该方法在展示候选属性给 LLM 之前，先剔除不兼容的属性，保留相关属性，利用 KG 的模式信息（Schema）约束 LLM 的查询构建过程，减少语义歧义。主要改进点在于引入了聚焦执行机制，通过过滤无关属性提升了查询的准确性与效率。代价是模式信息的获取与过滤需要额外的预处理步骤，且对模式定义的完整性有依赖。该方法在复杂 SPARQL 生成任务中展现了优越性能，推动了 KGQA 向更精细的模式利用方向发展。与图检索增强生成路线相比，逻辑形式生成更强调查询的精确性与可执行性，而后者更侧重证据的召回与事实接地，两者常结合使用以互补优势。

### 2.2 图检索增强生成

图检索增强生成（GraphRAG）路线旨在通过检索 KG 中的相关子图作为上下文，增强 LLM 的事实准确性，缓解幻觉问题。早期方法如 GRAFT-Net（2018）提出基于图注意力网络的子图推理框架，通过问题感知的图卷积结构提取相关子图，成为经典基线。随着 LLM 引入，研究重心转向如何利用 LLM 优化检索策略。KGFR（2025）提出通用知识图谱问题回答的基础检索器，通过条件消息传递机制，在 KG 上构建问题相关的检索子图，并暴露节点级、边级与路径级三种粒度的检索接口。核心设计思路是将检索过程建模为图上的消息传递，使 LLM 能获取不同粒度的证据。主要改进点在于提供了结构化的检索接口，而非原始邻居，提升了 LLM 对 KG 证据的理解能力。代价是消息传递过程计算复杂度高，且依赖子图构建的质量。

STEM（2026）提出结构追踪证据挖掘框架，通过语义到结构的投影管道，将自然语言问题映射到 KG 结构，并挖掘全局结构一致性偏差（SAGB）。核心设计思路是利用 KG 的层次化结构引导 LLM 的推理，确保证据的逻辑连贯性。主要改进点在于引入了全局结构一致性偏差，提升了多跳推理中证据的覆盖度与准确性。代价是结构投影需要复杂的映射规则，且对 KG 结构的完整性有依赖。该方法在多跳推理任务中显著优于 RoG 与 GNN-RAG，证明了结构追踪对证据挖掘的重要性。

COSMOS（2026）则从理论优化角度切入，提出连通导向的子模最大化框架，用于最优子图检索。该方法将证据子图检索形式化为子模最大化问题，通过分解-征服策略优化全局证据骨干，提供了可证明的近似保证，提升了检索的理论基础，避免了短路径偏好。代价是子模优化计算复杂度高，且需要精心设计的分解策略。该方法在 WebQSP、CWQ 与 M3 GQA 上取得了 SOTA 性能，为子图检索提供了理论严谨的解决方案。与逻辑形式生成路线相比，GraphRAG 更强调事实接地与鲁棒性，而前者更强调逻辑精确性，两者在复杂推理任务中常形成互补。

### 2.3 智能体推理框架

智能体推理框架路线旨在将 LLM 视为自主智能体，通过规划、探索、记忆管理及自我修正机制，在 KG 上进行多跳推理与动态路径搜索。ToG（2023）提出 Think-on-Graph 框架，利用 LLM 在知识图谱上进行迭代式 Beam Search 探索，将图结构作为推理空间，实现了 LLM 与 KG 的动态交互，开启了 Agent-based KGQA 的新方向。然而，单次推理或简单检索无法应对搜索空间指数级增长的多跳问题，且缺乏对错误路径的纠正机制。

EvoMemKG（2025）引入可进化记忆机制，区分工作记忆（WM）与长期记忆（EM），WM 防止上下文溢出，EM 提供高层策略指导。核心设计思路是通过双记忆机制管理长轨迹推理中的信息，提升多跳推理的鲁棒性。主要改进点在于实现了记忆的可进化性，EM 能根据推理结果更新策略，WM 能动态管理上下文，解决了长轨迹中的信息丢失问题。代价是双记忆机制增加了系统复杂度，且记忆更新策略需要精心设计。该方法在多跳推理任务中展现了优越的鲁棒性，为智能体记忆管理提供了新方案。

CLAUSE（2026）提出代理神经符号框架，通过动态可学习上下文工程进行 KG 推理。该方法包含子图架构师、路径导航员与上下文策展人三个智能体，协同编辑、遍历与策展图上下文。核心设计思路是在显式预算约束下，学习紧凑且查询特定的图上下文，提升推理的可审计性。主要改进点在于引入了预算感知机制，通过价格参数平衡准确性与效率，且智能体联合训练提升了协同效果。代价是多智能体训练复杂度高，且预算参数需要调优。该方法在多跳 KGQA 中展现了优越性能，为神经符号推理提供了可部署的控制机制。与图检索增强生成路线相比，智能体框架更强调长程推理的连贯性与动态规划，而后者更侧重单次检索的准确性，两者在复杂多跳任务中形成层级依赖。

### 2.4 强化学习优化

强化学习（RL）优化路线旨在利用 RL 优化 KGQA 中的推理路径选择、检索策略及模型对齐，解决多跳推理中的信用分配与探索效率问题。传统 RL 在长轨迹中面临信用分配困难的问题，Search-R1（2024）利用可验证奖励的强化学习训练搜索智能体，优化多轮搜索轨迹，为 KGQA 中的路径探索提供了新的优化范式。

KG-Hopper（2026）提出利用强化学习赋能紧凑开源 LLM 进行 KG 推理。该方法通过构建 KG 检索工具，并利用 RL 训练 LLM 与之交互，解决小模型在知识图谱上的检索与推理能力不足问题。核心设计思路是结合冷启动数据微调与 RL 优化，使小模型能学会调用检索工具并生成结构化答案。主要改进点在于引入了规则触发的检索机制，通过特殊标签触发 KG 检索，提升了小模型的推理能力。代价是 RL 训练过程不稳定，且冷启动数据质量影响大。该方法在 KGQA 任务中显著提升了小模型的性能，为资源受限场景下的 KGQA 提供了新路径。

CoEvoKG（2026）提出共进化知识图谱与自进化搜索智能体框架。该方法通过共享 KG 链池，同时生成任务与求解搜索，利用路径支持奖励与难度奖励优化智能体。核心设计思路是将任务生成与搜索求解耦合，通过验证证据合并回记忆，实现智能体的自进化。主要改进点在于引入了路径支持奖励，直接优化多跳关系推理，解决了传统 RL 在长轨迹中奖励稀疏的问题。代价是 KG 链池的维护与更新需要额外机制，且奖励设计复杂。该方法在多个 QA 基准上显著提升了性能，为代理 RL 提供了共进化的新范式。与智能体推理框架相比，RL 优化更强调策略的自动学习与优化，而前者更侧重架构设计与记忆管理，两者常结合使用以提升智能体的自主性。

### 2.5 知识注入与记忆

知识注入与记忆路线旨在探索将结构化知识参数化注入 LLM 或构建外部记忆机制，以增强模型的知识存储与检索能力。AtlasKV（2025）提出在 20GB VRAM 中增强 LLM 与十亿级知识图谱的方法。该方法通过参数化知识增强范式，将大规模 KG 知识注入 LLM 参数，无需外部检索器或长上下文。核心设计思路是利用 LoRA 适配器存储 KG 知识，通过适配器选择与注入实现高效推理，突破了传统 RAG 的上下文窗口限制。主要改进点在于引入了可扩展的知识注入机制，支持十亿级三元组的注入，提升了模型的泛化能力。代价是适配器存储与管理需要额外内存，且注入过程需要优化。

Mnemis（2026）提出层次图上的双路由检索，用于长期 LLM 记忆。该方法结合情景记忆层（EML）与图记忆层（GML），EML 捕获动态叙事进展，GML 组织静态事实细节，通过双路由检索支持全局推理与细粒度事实检索。核心设计思路是模拟人类认知记忆机制，通过层次化浏览检索相关记忆组件，提升长期交互中的记忆一致性。主要改进点在于引入了双路由机制，平衡了全局推理与局部事实检索，提升了记忆检索的准确性。代价是层次图构建复杂，且双路由检索需要额外计算。该方法在长期记忆任务中展现了优越性能，为 LLM 记忆管理提供了新范式。与图检索增强生成路线相比，知识注入更强调知识的内部化与高效检索，而后者更侧重外部证据的动态获取，两者在知识更新与推理效率上形成互补。

### 2.6 跨任务与多领域应用

KBQA 方法正从通用基准向特定领域与多模态场景扩展。RiTeK（2026）构建医疗领域文本知识图谱复杂推理数据集，涵盖多种拓扑结构，填补了领域特定 KGQA 评估基准的空白，推动了医疗 AI 在复杂推理场景下的标准化评估。HOME-KGQA（2026）构建家庭日常活动多模态 KGQA 基准，涵盖 i.i.d. 与组合泛化设置，评估模型在未见实体与操作符上的泛化能力，推动了多模态 KGQA 的研究进展。PIPE-RDF（2026）提出 LLM 辅助的企业 RDF 基准测试管道，通过三阶段管道生成模式特定基准，解决了公共基准与企业特定本体不匹配的问题，提升了基准的实用性。这些应用表明，KBQA 方法需适应不同领域的 KG 结构与查询模式，通用方法在特定领域需进行微调或适配。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLM 单独使用难以保证 KBQA 的事实准确性，必须结合外部结构化知识（KG）以缓解幻觉，这一共识在约 70 篇论文中得到共同支持。预训练-微调范式的优势在多个基准上被反复验证：RPO-RAG 的 89.9 与 STEM 的 86.63 均大幅超越传统 SP 方法，表明外部 KG 约束对事实准确性的关键作用。与此相关的另一个共识是，多跳推理是 KGQA 的核心挑战，需要超越单步检索的复杂推理能力，如路径规划和子图组装，约 50 篇论文共同支持这一观点。EvoMemKG 与 CLAUSE 在多跳任务上的优越性能进一步验证了记忆与规划机制的重要性。

### 3.2 观点分歧

知识获取方式上，参数化注入（AtlasKV）与外部检索增强（GraphRAG）存在根本分歧。参数化注入主张将 KG 知识编译进模型参数，实现快速、无延迟推理，而外部检索增强主张通过动态检索子图提供事实依据，保持知识更新灵活性。现有证据偏向外部检索在事实准确性和知识更新上的优势，参数化注入在速度和上下文限制上有优势，但缺乏在动态更新场景下的公平对比实验。这一分歧的背后，是另一个更根本的争论：推理范式上，端到端生成（ChatKBQA）与分步验证/智能体交互（GRV-KBQA, CLAUSE）的取舍。端到端生成主张简化流程，降低延迟，而分步验证主张通过中间步骤确保每一步的正确性，提升鲁棒性。现有证据偏向分步验证/智能体在复杂多跳任务上的准确性优势，端到端生成在简单任务上效率更高，但缺乏对“精度-成本”帕累托前沿的系统评估。

### 3.3 其他开放问题

最紧迫的工程问题是降低 LLM 推理的计算成本与延迟，实现端侧部署。MobileKGQA 通过哈希编码与分布偏移适应机制提供了初步方案，但哈希编码可能损失部分语义信息，且适应机制需要额外计算。最根本的研究问题是 LLM 参数化知识与知识库事实知识之间的不一致问题（幻觉）。难点在于 LLM 训练于非结构化文本，缺乏 KB 特定信息，导致生成幻觉实体或关系。潜在技术路径包括引入 KB 感知信息、执行反馈验证、以及神经符号融合方法。此外，提升模型在零样本和组合式泛化场景下的性能也是关键挑战，现有模型在未见过的实体或关系上表现不佳，且复杂逻辑组合增加推理难度。潜在技术路径包括任务分解、子图引导生成、以及基于强化学习的探索策略。已知—争议—未知认知图谱显示，领域在事实接地与逻辑精确上已达成基本共识，但在知识获取方式与推理范式上存在显著争议，而动态知识更新与终身学习仍是未知领域。

## 4. 总结与展望

KBQA 领域的核心矛盾在于 LLM 的语义泛化能力与 KG 的事实精确性之间的张力。从符号解析到神经符号智能体的演进，反映了研究者在精度、效率与鲁棒性之间的不断取舍。当前核心瓶颈在于如何在动态、大规模 KG 中实现高效、可靠且可解释的长程推理，RL 与记忆机制是关键突破口。

未来可能突破的方向包括：基于 RL 的智能体自进化（CoEvoKG, P25）与知识边界感知的策略优化（Trust Within? Seek Beyond?, P34），这两者共同指向更自主、可解释的智能体范式。此外，参数化知识注入与外部检索的融合（如 AtlasKV 与 GraphRAG 的结合）也是重要方向。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，系统评估不同范式在动态更新场景下的性能，以揭示真正的精度-成本帕累托前沿。
