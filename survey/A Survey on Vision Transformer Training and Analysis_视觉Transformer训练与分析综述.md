## 导读

视觉Transformer（Vision Transformer, ViT）将自注意力机制引入视觉任务，其核心价值在于突破卷积神经网络（CNN）局部感受野的限制，实现全局上下文建模。早期研究聚焦于架构可行性，通过大规模预训练证明了纯注意力模型在分类任务上可超越CNN，确立了其作为视觉骨干网络的主流地位。随着数据规模与算力需求的矛盾加剧，研究重心转向效率优化与范式深化，线性注意力、掩码自编码及层级窗口机制相继出现，以缓解二次方计算复杂度瓶颈。当模型规模扩大至基础模型级别后，内部决策的黑盒特性与对抗脆弱性成为安全关键应用的阻碍，可解释性与鲁棒性研究随之兴起。各路线在计算效率、空间归纳偏置与决策可信度之间做出了不同取舍，由此形成当前架构优化与机制分析并行的方法格局。本综述梳理这条从全局建模到可信决策的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

视觉Transformer的诞生源于对卷积神经网络局部归纳偏置局限性的反思。传统CNN依赖堆叠卷积层逐步扩大感受野，难以在浅层捕捉长距离依赖，而自然图像中的语义关联往往跨越全局空间。2020年，ViT通过将图像切分为固定大小的补丁序列并应用标准Transformer编码器，证明了在ImageNet-21K大规模数据预训练下，纯注意力架构的Top-1精度可达81.4%，超越了同期CNN基线。这一突破确立了ViT作为视觉骨干网络的地位，但其成功高度依赖数据规模，在中等规模数据集上性能显著退化。

问题定义随之从“能否替代CNN”转向“如何降低对大数据量的依赖”与“如何解决高分辨率下的计算瓶颈”。标准Softmax注意力具有$O(N^2)$复杂度，处理高分辨率图像时内存开销呈平方增长。2021年，DeiT通过蒸馏技术引入教师-学生框架，使ViT在ImageNet-1k上达到81.8%精度，缓解了数据依赖；同年，Swin Transformer提出层级化窗口注意力，通过局部窗口计算与移位策略实现线性复杂度，解决了高分辨率密集预测任务的计算瓶颈。这两个工作分别针对数据效率与计算效率，奠定了ViT工业落地的基础。

2022-2024年进入范式深化期，核心问题聚焦于“如何构建通用视觉基础模型”与“如何在不牺牲精度的前提下实现线性复杂度推理”。MAE采用高比例掩码自编码策略，仅对少量可见补丁进行重建，大幅降低训练成本，确立了自监督预训练范式；DINOv2结合自蒸馏与多尺度训练，生成具有强泛化能力的视觉特征，成为密集预测任务的核心基准。与此同时，线性注意力探索旨在突破二次方复杂度限制，但早期方法在长序列上精度下降明显，暴露了表达力与效率的矛盾。

2025-2026年，研究重心从单纯的性能提升转向“分析与鲁棒性”，领域进入成熟反思阶段。ViT的全局注意力使其对局部扰动敏感，且内部决策过程不透明，难以满足安全关键应用的可信度要求。核心问题演化为“黑盒决策的可解释性”、“对抗扰动下的鲁棒性”及“小样本/低数据场景下的空间先验缺失”。此时，问题已转变为如何在保持全局建模优势的同时，通过架构创新与机制分析解决计算效率、空间归纳偏置及决策黑盒带来的危机。

子问题之间存在强依赖关系：计算复杂度优化是大规模部署的前提，表征分析是理解内部机制的基础，进而指导鲁棒性增强与可解释性设计。若不解决空间先验缺失问题，小数据场景下的鲁棒性和可解释性均难以保证。位置编码对空间感知至关重要，但在弱空间结构场景下可能引入虚假相关，需通过架构修改或动态策略进行适配。

**如果用一个核心问题概括该领域，那便是：如何在保持自注意力全局建模优势的同时，通过架构创新与机制分析，解决计算效率瓶颈、空间归纳偏置缺失及决策黑盒带来的鲁棒性与可解释性危机。**

## 2. 方法体系

- 2017：Transformer——奠定自注意力机制基础

- 2020：Vision Transformer (ViT)——确立视觉骨干网络地位

- 2021：Swin Transformer——解决高分辨率计算瓶颈

- 2022：MAE——确立自监督预训练范式

- 2024：Sparse Autoencoders (SAEs)——解耦内部多语义表征

- 2025：ViT$^3$——实现线性复杂度全局建模

- 2026：ZACH-ViT——适配弱空间结构数据

这条时间线勾勒了该领域方法演进的代表性节点：从2017年的Transformer奠定该领域方法基线，经2020年Vision Transformer (ViT)的推进，到2026年的ZACH-ViT代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 架构设计与优化

架构设计路线的起源在于突破标准ViT的计算瓶颈与空间归纳偏置缺失。2020年ViT确立了全局注意力范式，但其在高分辨率图像上的$O(N^2)$复杂度限制了部署。Swin Transformer（Liu et al., 2021）通过窗口注意力实现线性复杂度，成为密集预测任务的标准骨干，但引入了窗口边界效应。2025-2026年，研究聚焦于线性注意力的表达力提升与架构组件的精细化设计。

ViT$^3$（Han et al., 2025, P8）将序列建模重构为在线学习问题，通过测试时快速自监督更新权重来压缩上下文信息，实现了线性复杂度的全局建模。该方法突破了传统线性注意力丢失局部细节的局限，解决了长视觉序列处理的效率瓶颈，但引入了测试时的权重更新开销，推理延迟增加。ViT-5（Wang et al., 2026, P11）整合LayerScale、SwiGLU MLP和RMSNorm等现代组件，深入分析激活缩放与门控机制的相互作用，解决了深层ViT训练中的过门控问题。其核心贡献在于提供了2020年代中期ViT架构设计的最佳实践指南，明确了各组件对分类和生成任务的不同影响。

Locality-Attending ViT（LocAtViT, Hajimiri et al., 2026, P19）引入局部增强注意力和位置恢复机制，在不改变骨干结构的前提下增强ViT的局部先验，使其在密集预测任务中无需额外适配层即可达到SOTA性能。该方法解决了原始ViT缺乏局部归纳偏置导致密集预测性能不足的问题，通过模块化组件提升了模型对空间细节的捕获能力。Inhibited Self-Attention（ISA, van der Wal et al., 2026, P37）利用视觉系统中的抑制机制，保留并利用通常被Softmax丢弃的负注意力分数，通过抑制过程锐化注意力焦点，提升了ViT对关键区域的聚焦能力。

| 方法 | 年份 | 核心机制 | 主要优势 | 主要局限 |
|---|---|---|---|---|
| ViT$^3$ | | 测试时训练/在线学习 | 线性复杂度全局建模 | 推理延迟增加 |
| ViT-5 | | 组件集成/门控优化 | 训练稳定性高 | 依赖大规模数据 |
| LocAtViT | | 局部增强注意力 | 密集预测性能优 | 计算开销略增 |
| ISA | | 抑制自注意力 | 细粒度识别强 | 负分数处理复杂 |

架构设计路线与表征分析路线存在互补关系：前者通过结构创新提升效率与性能，后者通过机制理解指导结构优化。例如，Block-Recurrent Dynamics（P43）揭示的层间递归动态为架构压缩提供了理论依据，而ViT-5的组件分析则依赖于对激活分布的深入理解。

### 2.2 可解释性与归因

可解释性研究起源于对ViT内部决策黑盒特性的反思。早期方法如Attention Rollout通过递归乘法聚合各层注意力矩阵，提供了直观的视觉解释基线，但存在过度平滑问题。2024年，稀疏自编码器（SAEs）的引入解决了ViT内部表征的多义性问题，为理解模型内部电路提供了新工具。2025-2026年，研究聚焦于因果归因与忠实性评估，旨在揭示模型决策逻辑与内部表征结构。

Residual Replacement Model（RRM, Kim et al., 2025, P3）构建残差替换模型以连接各层特征，生成简约的决策电路，跳过了复杂的注意力模块计算，使得ViT的端到端决策过程在人类可理解的尺度上得以解释。该方法解决了ViT内部机制难以理解的问题，通过稀疏自编码器提取可解释特征，并建立层间连接。BiCAM（Su and Luo, 2026, P18）提出双向类激活映射技术，保留负值归因以解释模型拒绝替代类别的证据，通过选择性聚合深层Transformer层并融合梯度，提供了比传统CAM更丰富且对比性的解释。

Decision-Aware Attention Propagation（DAP, Jo et al., 2026, P26）将类特定决策线索整合到注意力传播过程中，通过梯度导出的Token重要性作为决策先验，引导传播朝向预测相关证据。该方法解决了传统注意力归因方法缺乏判别焦点的问题，通过调制Token间传播矩阵增强了决策相关Token的贡献。CIGMA（P46）通过因果信息增益机制对注意力头进行归因，识别并消融导致背景捷径的虚假头，无需重新训练即可提升模型的鲁棒性和校准度，实现了可解释性与鲁棒性的统一。

| 方法 | 年份 | 归因类型 | 核心贡献 | 计算开销 |
|---|---|---|---|---|
| RRM | | 残差替换/SAE | 决策电路简化 | 中等 |
| BiCAM | | 双向类激活映射 | 负值归因保留 | 低 |
| DAP | | 决策感知传播 | 梯度引导传播 | 中等 |
| CIGMA | | 因果信息增益 | 虚假头识别 | 高 |

可解释性路线与鲁棒性路线存在深度融合：CIGMA等因果归因方法不仅提供解释，还通过消融虚假头直接提升鲁棒性。这种融合反映了领域从“事后解释”向“机制引导优化”的转变，但因果推断的高计算成本限制了其在大规模实时应用中的部署。

### 2.3 鲁棒性与对抗训练

鲁棒性研究源于ViT对微小对抗扰动的敏感性。全局注意力使局部扰动可通过Token间交互传播破坏整体表示，且残差连接可能成为鲁棒性瓶颈。2023年，对抗训练（AT）成为基础防御策略，但计算开销大且易受路径依赖影响。2025-2026年，研究聚焦于参数高效微调、区域感知架构与概念引导策略，旨在提升模型在分布偏移下的稳定性。

Concept-guided Fine-Tuning（CFT, Elisha et al., 2026, P20）通过引导模型关注语义相关的概念区域而非背景捷径，利用少量样本微调对齐内部相关性，显著提升了ViT在分布偏移下的鲁棒性和语义对齐能力。该方法解决了ViT依赖虚假相关导致鲁棒性不足的问题，通过概念区域对齐损失引导模型内部相关性向语义有意义区域集中。Criticality-Aware Adversarial Training（CAAT, Li et al., 2026, P25）识别并仅微调对对抗鲁棒性关键的参数子集，结合LoRA技术冻结其余参数，大幅降低了对抗训练的计算成本，同时保持了模型的鲁棒性。

ReMoE（P45）引入区域混合专家架构，通过强化区域内一致性并约束局部损坏的传播，结合区域感知的优化策略，提升了ViT在对抗攻击下的鲁棒性，解决了全局注意力对局部扰动敏感的问题。Benign Overfitting in Adversarial Training（Zhang et al., 2026, P27）分析了ViT对抗训练中的良性过拟合现象，识别了小、中、大扰动下的不同泛化机制，提供了清洁和鲁棒测试误差的显式上界，为对抗训练提供了理论指导。

| 方法 | 年份 | 防御策略 | 核心创新 | 计算成本 |
|---|---|---|---|---|
| CFT | | 概念引导微调 | 语义区域对齐 | 低 |
| CAAT | | 关键性感知微调 | 参数子集优化 | 低 |
| ReMoE | | 区域混合专家 | 局部损坏约束 | 中等 |
| Benign Overfitting | | 理论分析 | 泛化上界推导 | 无 |

鲁棒性路线与可解释性路线相互支撑：CFT的概念引导依赖于对模型内部相关性的可解释分析，而ReMoE的区域感知设计则借鉴了注意力图的局部结构。这种交叉融合使得鲁棒性提升不再依赖暴力对抗训练，而是通过机制理解实现精准防御。

### 2.4 表征分析与训练动态

表征分析路线旨在揭示ViT如何从数据中学习空间结构与语义特征，提供理论洞察。早期研究聚焦于注意力可视化与特征探针，2025-2026年转向层间动态、归纳偏置涌现及特征迁移的深入分析。该路线为架构优化与鲁棒性增强提供了理论基础，是连接“黑盒训练”与“白盒分析”的桥梁。

Block-Recurrent Dynamics（P43）通过最大割算法发现ViT层间的递归动力学模式，证明部分层可共享参数而不损失性能，为理解ViT的深度冗余和参数效率提供了理论依据。该方法解决了ViT深度参数冗余问题，通过层间相似度分析识别递归块，并训练递归Transformer模型验证其有效性。ZACH-ViT（Angelakis, 2026, P15）提出基于置换不变性的紧凑ViT架构，移除位置嵌入和CLS Token，通过全局平均池化聚合特征，揭示了归纳偏置与数据空间结构匹配的重要性。

Spatial Priors via Space Filling Curves（Candogan et al., 2026, P33）提出通过空间填充曲线引入空间先验，解决ViT缺乏局部归纳偏置的问题，提升小数据和有限数据场景下的性能。该方法通过Z曲线的掩码注意力机制，通过衰减掩码保留局部性，同时保持全局依赖。Vision Transformers Need More Than Registers（Shi et al., 2026, P17）分析了ViT中高分量Token和背景补丁对密集预测任务的影响，提出通过调节背景补丁贡献来增强前景语义表征，揭示了高分量Token并非伪影的根本原因。

| 方法 | 年份 | 分析维度 | 核心发现 | 理论贡献 |
|---|---|---|---|---|
| Block-Recurrent | | 层间动态 | 递归动力学模式 | 参数效率理论 |
| ZACH-ViT | | 归纳偏置 | 置换不变性优势 | 架构-数据匹配 |
| Space Filling | | 空间先验 | 局部性增强机制 | 小数据泛化理论 |
| More Than Registers | | Token贡献 | 背景补丁影响 | 密集预测机制 |

表征分析路线为架构设计与鲁棒性研究提供了理论指导：Block-Recurrent Dynamics的发现直接启发了递归ViT的训练策略，而ZACH-ViT的归纳偏置分析则为低数据场景下的架构选择提供了依据。这种“分析驱动设计”的范式转变，标志着领域从经验调参向原理驱动的演进。

### 2.5 高效推理与部署

高效推理路线聚焦于资源受限场景下的ViT部署，包括分布式训练框架、Token合并、线性复杂度注意力及边缘设备适配。2025-2026年，研究重心从单一模型压缩转向动态分辨率处理与任务特定优化，旨在平衡计算成本与模型精度。

Correction（P44）提出头级注意力校正（HAC）方法，通过统计校正和头特定校正补偿Token合并导致的注意力失真，提升了ViT在Token合并后的性能。该方法解决了Token合并改变原始交互模式导致性能下降的问题，通过头特定校正项针对每个注意力头的统计特性进行补偿。SPAR（Kombol et al., 2026, P23）设计单通道任意分辨率ViT，通过动态Token处理和开放词汇分割策略，解决了ViT在密集预测任务中分辨率受限的问题，实现了训练无关的高精度分割。

GNN-MoE（Soliman et al., 2025, P6）提出基于GNN的上下文感知补丁路由机制，结合混合专家架构，实现了参数高效的域泛化。该方法解决了标准MoE路由器忽略补丁间关系导致域偏移下专家分配不鲁棒的问题，通过GNN捕捉补丁图结构。How Merge-Tolerant Are Vision Transformers（Ravé et al., 2026, P40）评估了ViT在小麦表型分析中的合并容忍度，通过任务性能下降和加速比量化Token合并的影响，揭示了不同任务对Token合并的敏感性。

| 方法 | 年份 | 优化策略 | 核心创新 | 适用场景 |
|---|---|---|---|---|
| Correction | | 头级注意力校正 | Token合并补偿 | 高效推理 |
| SPAR | | 任意分辨率处理 | 单通道动态Token | 密集预测 |
| GNN-MoE | | 上下文感知路由 | GNN补丁图结构 | 域泛化 |
| Merge-Tolerant | | 合并容忍度评估 | 任务敏感性量化 | 农业视觉 |

高效推理路线与架构设计路线紧密关联：Token合并与线性注意力是架构优化的直接应用，而GNN-MoE的路由机制则借鉴了混合专家架构的设计思想。该路线的核心挑战在于如何在压缩计算成本的同时保持任务特定性能，现有方法多针对特定任务优化，缺乏通用的效率-精度权衡框架。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

ViT在大规模数据预训练下性能优于CNN，已成为视觉基础模型的主流架构，这一共识在ImageNet-1k基准上被反复验证：ViT-5的83.5%与GrowTAS-B的82.7%均大幅超越早期CNN基线。自注意力机制的全局建模能力是ViT优势的核心，但也导致了计算复杂度高和对局部扰动敏感的问题，这一矛盾在对抗鲁棒性基准上体现为CAAT的55.0%与标准模型清洁精度的显著差距。位置编码对ViT的空间感知至关重要，但在某些空间结构弱或需要分辨率无关的场景下，移除或修改位置编码可能更优，ZACH-ViT在MedMNIST低数据场景下的表现验证了这一点。

与此相关的另一个共识是，ViT的注意力图本身并不直接等同于可解释性，需要结合梯度、归因或稀疏表示技术才能准确反映模型决策。BiCAM的65.0% Pointing Game分数与Attention Rollout的55.0%基线之间的差距，证实了简单注意力可视化的局限性。对抗训练是提升ViT鲁棒性的有效手段，但需结合架构特性进行针对性优化，ReMoE的区域混合专家设计与CAAT的参数关键性感知均验证了架构-防御协同的必要性。Token合并与线性注意力是解决ViT计算效率问题的主要技术路径，ViT$^3$的80.5%与TuringViT的81.0%证明其在保持精度的同时显著降低推理成本。

### 3.2 观点分歧

注意力图是否等同于可解释性，是领域内最核心的分歧。观点A认为注意力图直观且计算成本低，足以反映模型关注区域；观点B认为注意力图平滑且易受扰动，需结合梯度、因果推断或SAE才能揭示真实决策逻辑。现有证据偏向观点B：在对抗扰动下，注意力图会发生剧烈变化且指向非判别性区域，而CIGMA等因果归因方法能稳定识别关键Token并提升鲁棒性。然而，因果方法计算成本高，缺乏大规模实时验证，使得分歧在工程部署场景中仍未完全解决。

这一分歧的背后，是另一个更根本的争论：线性注意力能否完全替代Softmax注意力。观点A认为线性注意力在保持精度的同时大幅降低计算成本，是未来主流；观点B认为Softmax注意力的全局建模能力不可替代，线性方法在密集预测和细粒度任务上仍有差距。证据显示，ViT$^3$在ImageNet分类上达到80.5%，接近Softmax模型，但在ADE20K分割上，LocAtViT（基于Softmax改进）的43.5%仍优于纯线性模型。场景依赖性显著，缺乏通用的线性化适配策略，使得该分歧在跨任务应用中难以统一。

### 3.3 其他开放问题

最紧迫的工程问题是分布式训练通信开销与边缘设备部署的量化精度损失。随着模型规模扩大，DeepSpeed等框架在视觉工作负载中的通信优化仍是瓶颈，而动态分辨率推理的延迟优化缺乏统一基准。最根本的研究问题是如何建立“机制可解释性”与“对抗鲁棒性”的直接因果联系。CIGMA等因果归因方法虽能识别虚假头，但缺乏理论框架解释为何消融特定头能提升鲁棒性，现有实验多为个案验证，缺乏普适性理论。

此外，如何在小数据场景下通过架构设计自动匹配数据空间结构，是另一关键开放问题。ZACH-ViT的置换不变性在MedMNIST上表现优异，但在自然图像上性能下降，表明架构选择需依赖数据特性，缺乏自动匹配机制。已知的是，ViT在大规模数据下性能优越，位置编码对空间感知至关重要；争议的是，注意力图的解释忠实性与线性注意力的表达力边界；未知的是，机制可解释性与对抗鲁棒性的因果映射关系，以及架构-数据空间结构的自动匹配理论。未来趋势将依赖于效率、鲁棒性与可解释性的协同优化，而非单一维度的极致追求。

## 4. 总结与展望

ViT领域的发展轨迹反映了视觉计算范式从局部卷积到全局注意力的根本性转变，其核心矛盾在于全局注意力的强大表达能力与二次方计算复杂度、局部扰动敏感性之间的冲突。从2020年ViT确立骨干地位，到2022年MAE确立自监督范式，再到2025-2026年机制可解释性与鲁棒性研究的兴起，领域已从“性能至上”转向“效率、鲁棒性与可解释性的多维平衡”。核心瓶颈在于缺乏统一的理论框架来解释ViT内部动态与外部鲁棒性之间的映射关系，以及线性/递归架构在密集预测任务上的性能差距。

未来可能突破的方向包括：探索线性复杂度与递归架构在高分辨率视觉任务中的扩展性，ViT$^3$与Block-Recurrent Dynamics均指向该方向；增强视觉Transformer的对抗鲁棒性与分布偏移适应能力，CFT与ReMoE提供了区域感知与概念引导的路径；开发可解释且因果一致的注意力归因机制，CIGMA与DAP代表了因果推断与梯度分解的融合趋势。对于进入该领域的研究者，最值得做的一件事是建立机制可解释性与对抗鲁棒性的因果联系理论，通过稀疏自编码器与因果推断工具，揭示内部表征结构与外部鲁棒性之间的映射关系，为安全关键应用中的可信视觉系统提供理论指导。
