## 导读

多智能体大语言模型系统（Multi-Agent LLM Systems, MAS）通过协调多个语言模型实例协作，旨在突破单一模型在长程推理与复杂任务处理上的固有局限。早期研究依赖手工设计的静态角色分工与固定通信拓扑，验证了协作潜力却受制于结构僵化与通信开销。当动态拓扑优化与强化学习引入后，研究重心从静态编排转向结构自适应，以任务特异性换取部署灵活性。当前领域进入高效性与鲁棒性深水区，聚焦通信成本、错误级联抑制及集体认知偏差的机制解释。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

多智能体大语言模型系统的兴起，源于单一大型语言模型在长程推理、幻觉抑制及多步任务处理上的固有局限。当任务复杂度超越单模型的上下文窗口或推理深度时，研究者引入多个智能体实例，通过角色分工与信息交换来分担认知负荷。这一范式的核心假设是：集体智能能够超越个体能力，通过协作实现涌现效应。然而，这一假设的成立依赖于特定的通信结构与协调机制，而非简单的模型数量叠加。

问题的形式化可表述为：给定任务查询 $q$ 和 $N$ 个智能体 $\mathcal{A} = \{a_1, ..., a_N\}$，系统需构建通信拓扑 $G=(V, E)$ 与协作策略 $\pi$，以最小化通信成本 $C_{token}$ 并最大化任务准确率 $Acc$。其中，通信拓扑定义了信息流动的路径，协作策略决定了智能体间的交互时序与内容。这两个变量相互制约：拓扑结构影响信息传播效率与错误扩散路径，而策略优化又依赖于拓扑提供的交互空间。

子问题之间存在明显的依赖关系。通信拓扑优化是基础架构，决定了信息流动的效率与错误传播的路径；强化学习协同优化依赖于拓扑结构提供的交互空间，通过策略梯度调整智能体行为；系统安全与鲁棒性则是对前两者在对抗与故障场景下的约束与修正。动态拓扑的泛化性不足直接导致了错误级联与集体认知偏差的加剧，因此拓扑设计、策略优化与安全防御需联合解决，而非孤立优化。

范式边界在于：MAS 并非在所有任务上都优于单智能体基线。在简单任务上，强单智能体基线（如 CoT、Self-Refine）常因通信开销而表现不佳，MAS 的额外开销在低复杂度任务中不具性价比。因此，MAS 的适用边界由任务复杂度决定，复杂、长程任务更能体现多智能体协作的优势，而简单任务则应回归单模型处理。

2016-2018 年，多智能体强化学习（MARL）领域奠定了协作优化的理论基础，但当时 LLM 尚未成熟，研究主要聚焦于连续控制任务。2023 年，随着 LLM 能力的爆发，CAMEL 与 MetaGPT 等工作将 MARL 思想引入 LLM 协作，确立了静态角色分工与固定拓扑的基线。这一阶段的核心假设是：结构化角色分配足以提升推理多样性，通信拓扑可预先设计。

2024 年成为关键转折点，研究重心从“静态编排”转向“动态拓扑优化”。GPTSwarm 等工作引入图神经网络与强化学习，实现了通信结构的自动学习，解决了固定拓扑无法适应任务复杂度的问题。这一转变的动机是：静态拓扑在分布外任务上表现不稳定，且无法根据实时状态调整信息流，导致效率低下。

2025-2026 年，领域进入“高效性与鲁棒性”深水区。研究焦点集中于通信效率（Token 成本）、错误归因与级联失败抑制、以及集体认知偏差（如曼德拉效应、从众心理）的机制解释。这一阶段的动机是：实际部署中，Token 成本激增与错误级联风险成为主要瓶颈，单纯的性能提升已不足以支撑 MAS 的规模化应用。

**如果用一个核心问题概括该领域，那便是：如何在保证通信效率与系统鲁棒性的前提下，通过动态自适应的拓扑结构与策略优化，实现多智能体系统在复杂任务中的集体智能涌现与可信协作。**

## 2. 方法体系

- 2023：AutoGen——奠定该领域方法基线

- 2024：DyLAN——稀疏化拓扑设计的代表性工作

- 2024：GPTSwarm——动态可学习通信结构的跨越

- 2025：G-Designer——拓扑设计的自动化与任务特异性

- 2025：M-GRPO——多智能体层级信用分配

- 2026：SELFORG——去中心化的拓扑自适应

- 2026：Small-World Networks——当前前沿的理论视角

这条时间线勾勒了该领域方法演进的代表性节点：从 2023 年的 AutoGen 奠定该领域方法基线，经 2024 年 DyLAN 的推进，到 2026 年的 Small-World Networks 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 通信拓扑优化

通信拓扑优化是 MAS 的基础架构，旨在平衡推理性能与通信开销。早期工作如 MetaGPT 采用固定拓扑，通过模拟软件公司角色实现结构化工作流，证明了固定拓扑在软件工程任务中的有效性，但受限于静态编排。2024 年，GPTSwarm 将多智能体系统建模为可优化的图结构，通过强化学习调整智能体间的连接权重与拓扑，实现了从静态预定义到动态可学习通信结构的跨越。这一转变放弃了人工设计的可控性，换取了任务自适应能力，代价是引入了拓扑生成的计算开销和对训练数据的依赖。

2025 年，G-Designer 利用条件图生成模型，根据任务查询动态生成多智能体通信拓扑，实现了拓扑设计的自动化与任务特异性。GTD 进一步利用图扩散模型动态生成通信拓扑，将零阶优化步骤集成到采样阶段，实现了细粒度的任务自适应拓扑设计。这些生成式方法代表了从静态设计向动态生成式拓扑设计的范式转变，为复杂任务提供了更优的通信结构，但扩散模型的推理速度可能较慢，且需要高质量的训练数据。

2026 年，SELFORG 提出基于 Shapley 值的自组织通信框架，无需外部裁判或预训练图生成器，通过智能体自身响应估计贡献并构建 DAG，实现了去中心化的拓扑自适应。该方法为多智能体系统的动态拓扑设计提供了一种轻量级且可解释的解决方案，推动了自组织 MAS 的发展。GoAgent 则引入组中心范式，将高层协作组作为生成的原子单元，减少了细粒度预测的计算负担，提高了拓扑生成的效率与可扩展性。

| 方法 | 年份 | 核心决策 | 优势 | 代价 |
| :--- | :--- | :--- | :--- | :--- |
| GPTSwarm | 2024 | 静态→动态可学习 | 任务自适应 | 计算开销、数据依赖 |
| G-Designer | 2025 | 启发式→生成式 | 自动化、任务特异性 | 推理慢、数据质量要求高 |
| SELFORG | 2026 | 集中式→去中心化 | 轻量级、可解释 | Shapley 值计算开销 |
| GoAgent | 2026 | 节点级→组级 | 高效、可扩展 | 组划分合理性影响性能 |

通信拓扑优化与智能体路由与调度路线存在互补关系：拓扑优化决定信息流动的结构，而路由调度决定信息流动的内容与目标。两者共同构成了 MAS 的通信基础设施。

### 2.2 智能体路由与调度

智能体路由与调度聚焦于动态选择最优智能体、模型规模或协作模式以处理特定查询。2024 年，RouteLLM 提出基于路由的 LLM 选择机制，根据查询复杂度将任务分配给不同规模的模型，在保持性能的同时显著降低了推理成本。这一机制开启了模型级路由的研究方向，通过动态分配模型规模平衡性能与成本，但引入了路由决策的延迟与不确定性。

2025 年，Optimal-Agent-Selection 提出状态感知路由框架，根据任务状态动态选择最优智能体，解决了静态路由无法适应动态任务需求的问题。OI-MAS 进一步提出置信度感知路由机制，通过角色路由器与模型路由器协同工作，动态分配任务给不同规模的 LLM，平衡了预测性能与计算成本。这些方法为多尺度模型环境下的智能体调度提供了原则性方法，提升了系统的经济性与有效性。

2026 年，BAMAS 提出预算感知的多智能体系统结构化方法，将 LLM 选择建模为整数线性规划问题，求解最优 LLM 池，随后使用基于强化学习的方法设计智能体协作拓扑。ATOM 则提出预算可控的多智能体协作实例化机制，采用核-电子层级结构，通过动态扩展实现了预算可控的协作，适用于资源波动场景。这些方法为实际部署中的成本敏感型多智能体系统提供了结构化设计框架。

智能体路由与调度与通信拓扑优化路线存在竞争关系：路由调度通过选择最优智能体来优化资源分配，而拓扑优化通过调整连接结构来优化信息流动。两者在成本-性能权衡上存在不同的优化目标，需根据具体场景选择主导策略。

### 2.3 强化学习协同优化

强化学习协同优化旨在端到端优化智能体间的交互策略、提示词或协作流程。2024 年，GRPO 提出组相对策略优化算法，通过组内奖励归一化替代价值函数，简化了强化学习训练流程，成为后续多智能体强化学习训练的基础算法组件。2025 年，M-GRPO 将 GRPO 扩展至多智能体层级结构，通过主智能体与子智能体的分层信用分配，解决了多智能体协作中的奖励稀疏与归因困难问题。

2026 年，AgentPO 提出通过强化学习增强多智能体协作的方法，核心在于功能解耦的协作与执行架构。该方法将系统分为协作智能体与执行智能体，协作智能体由可学习策略控制，执行智能体使用固定高性能策略，通过优化协作策略以最大化系统联合性能。Maestro 提出条件列表策略优化（CLPO）算法，将协作过程分解为探索与综合两个阶段，通过列表式奖励提供更丰富的学习信号。这些方法为多智能体系统的策略优化提供了新的架构范式，提升了协作的鲁棒性，但训练过程复杂，需要大量交互数据。

强化学习协同优化与通信拓扑优化路线存在继承关系：拓扑优化提供交互空间，强化学习在该空间内优化策略。两者联合优化可实现拓扑与策略的协同提升，但增加了系统复杂度与训练成本。

### 2.4 系统安全与鲁棒性

系统安全与鲁棒性探讨 MAS 面临的对抗攻击、错误传播、共谋行为及隐私泄露风险。2025 年，M-Spoiler 构建对抗性框架，模拟顽固智能体与关键智能体生成对抗后缀，揭示了多智能体系统在提示注入攻击下的脆弱性。Mandela Effect Analysis 探索 LLM 多智能体系统中的集体认知偏差，发现模型规模扩大不一定能减少曼德拉效应，揭示了社会影响与记忆固化在 MAS 中的安全风险。

2026 年，From Spark to Fire 提出建模与缓解 LLM 多智能体协作中错误级联的方法，将错误传播形式化为传染病模型，分析不同拓扑结构下的错误覆盖范围。The Consensus Trap 提出通过 Token 级协作拯救多智能体 LLM 免受对抗性多数影响的方法，指出响应级共识易受隐蔽上下文污染攻击，通过引入 Token 级轮询协作提高对污染的鲁棒性。这些方法为多智能体系统的安全评估提供了重要工具，推动了防御机制的研究，但可能牺牲正常情况下的通信效率。

系统安全与鲁棒性与通信拓扑优化路线存在约束关系：拓扑结构影响错误传播路径，安全防御需针对特定拓扑设计。两者需联合优化，以实现鲁棒性与效率的平衡。

### 2.5 通信机制与协议

通信机制与协议探索智能体间信息交换的具体形式。2025 年，Latent Collaboration 提出潜在空间协作机制，通过共享隐藏状态而非自然语言文本进行智能体间通信，旨在提高信息保真度并减少语义歧义。Thought Communication 探索思想通信在多智能体协作中的作用，超越自然语言的局限，提出直接传输思维内容或潜在表示，以提高通信效率与准确性。

2026 年，Technical Taxonomy of LLM Agent Communication Protocols 提出 LLM 智能体通信协议的技术分类法，系统性地梳理了现有通信协议，包括中心化与去中心化控制、消息格式与同步机制。The Five Ws of Multi-Agent Communication 提出多智能体通信的“5W”调查框架，涵盖谁、何时、什么、如何与为何通信，提供了统一的分析视角。这些方法为多智能体系统的通信标准化提供了参考，促进了互操作性，但潜在空间通信的可解释性较差，实现技术尚不成熟。

通信机制与协议与通信拓扑优化路线存在互补关系：拓扑优化决定信息流动的结构，通信机制决定信息流动的内容与形式。两者共同构成了 MAS 的通信基础设施，需协同设计以实现高效、可靠的协作。

### 2.6 自进化与记忆机制

自进化与记忆机制研究 MAS 如何通过经验积累、记忆管理、提示词优化及结构自调整实现持续学习与自我改进。2025 年，LLMA-Mem 提出记忆启用的终身学习框架，结合短期、长期与共享记忆，支持任务执行与智能体间交互，使多智能体系统能够积累经验并持续改进。HiveMind 提出贡献引导的在线提示优化方法，利用信用分配机制，评估每个智能体的贡献，并动态调整其提示词。

2026 年，MAS-on-the-Fly 提出测试时动态适应 LLM 多智能体系统的方法，借鉴生物适应原理，通过 SOP 引导系统生成、过程监督执行与反思经验蒸馏三阶段闭环，实现自适应协作。Experience as a Compass 提出多智能体 RAG 与演化编排及智能体提示的方法，将经验库视为潜在策略表示，通过 EM 解释进行轨迹采样与语义洞察提取。这些方法为多智能体系统提供了终身学习能力，解决了静态系统无法适应新任务的问题，但记忆管理的复杂性较高。

自进化与记忆机制与强化学习协同优化路线存在继承关系：强化学习提供策略优化框架，自进化机制在该框架内实现经验积累与持续改进。两者联合优化可实现 MAS 的长期性能提升，但增加了系统复杂度与存储成本。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

多智能体协作在复杂、长程任务上通常优于单智能体，但在简单任务上可能因通信开销而表现不佳。这一共识在多个基准上被反复验证：OI-MAS 的 79.44 与 GoA 的 79.18 均大幅超越单智能体基线，而在简单任务上，强单智能体基线常因通信开销而表现不佳。与此相关的另一个共识是通信拓扑结构对系统性能的影响往往大于单个智能体的能力，动态自适应拓扑优于静态固定拓扑。GPTSwarm 的 62.15 与 G-Designer 的 88.33 均显著超越静态拓扑基线，表明动态拓扑在复杂任务上具有显著优势。

### 3.2 观点分歧

规模扩展是否必然提升多智能体系统性能？观点 A 认为增加智能体数量可提升集体智能，观点 B 认为存在性能饱和效应，甚至因“智力精英”主导或通信开销导致性能下降。现有证据偏向观点 B：MacNet 实验发现智能体数量与性能存在饱和效应，Intellectual Elites 指出少数智能体主导决策，增加数量可能引入噪声。这一分歧的背后，是另一个更根本的争论：潜在空间通信是否优于自然语言通信？观点 A 认为潜在空间通信保真度高，减少语义歧义，观点 B 认为自然语言通信可解释性强，便于审计与调试。现有证据偏向观点 A 在特定高精度任务上的优势，但观点 B 在可解释性与通用性上占优。

### 3.3 其他开放问题

最紧迫的工程问题是通信效率与 Token 经济性优化。现状是 Token 消耗是 MAS 实际部署的主要瓶颈，关键困难在于平衡信息完整性与通信开销，研究路径包括潜空间协作、稀疏图结构、早期停止机制及基于预算约束的智能体选择。最根本的研究问题是动态拓扑的泛化性。现状是基于特定任务训练的拓扑生成模型在分布外任务上表现不稳定，关键困难在于缺乏对任务复杂度的通用感知机制，研究路径包括图扩散模型、强化学习驱动的拓扑搜索及基于置信度的动态路由。已知—争议—未知认知图谱显示：动态拓扑优于静态拓扑是共识，规模效应与通信介质是争议，动态拓扑泛化性与集体认知偏差机制是未知。发展趋势是 MAS 将从“性能最大化”转向“系统级鲁棒性与经济性”，实现可信协作。

## 4. 总结与展望

MAS 领域的核心矛盾在于：自由通信带来的性能提升与 Token 成本激增、错误级联风险之间的权衡。早期研究通过静态角色分工与固定拓扑验证了协作潜力，但受限于结构僵化与通信开销。2024 年，动态拓扑优化与强化学习引入，解决了固定结构无法适应任务复杂度的问题。2025-2026 年，研究重心转向系统级鲁棒性与经济性，聚焦通信效率、错误级联抑制及集体认知偏差。核心瓶颈是动态拓扑的泛化性不足与集体认知偏差的机制解释，这直接导致了错误级联与系统崩溃。

未来可能突破的方向包括：基于图扩散模型的实时拓扑生成，解决静态拓扑无法适应不同任务复杂度的问题；Token 级协作以突破投票算术限制，提高系统对隐蔽上下文污染攻击的鲁棒性；区块链驱动的透明协作机制，实现跨组织协作中的信任与激励相容。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，系统评测动态拓扑与静态拓扑在分布外任务上的泛化性差异，为 MAS 的规模化应用提供理论指导。
