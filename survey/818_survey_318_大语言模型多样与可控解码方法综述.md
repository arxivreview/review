## 导读

大语言模型解码策略决定了生成文本在质量、多样性与事实性之间的平衡，其核心挑战在于对齐训练压缩了输出分布，导致长程生成陷入模式坍缩。早期研究以概率截断为主线，通过 Top-k 和 Top-p 等动态阈值过滤低概率噪声，思路简洁却受制于温度敏感性与局部视野。当跨任务基准暴露出局部 Token 控制无法阻止宏观语义重复后，研究者转向动态解码控制与几何感知调控，用状态空间干预换取长程稳定性。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前从概率工程向几何动力学过渡的方法格局。本综述梳理这条从局部截断到全局状态干预的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

大语言模型（Large Language Models, LLMs）的解码过程本质上是条件概率分布的逐步采样，其质量直接决定了生成文本的连贯性与创造性。在早期阶段，研究者的核心关切是如何在确定性与随机性之间取得平衡，即通过温度缩放（Temperature Scaling）和截断方法（如 Top-k, Top-p）在避免低概率噪声的同时保留一定的生成多样性。这一阶段的问题形式化通常被简化为在每一步 $t$ 中，从词表 $V$ 中选择一个 token $x_t$，使得累积分布函数 $F(x_t) \geq p$（对于 Top-p 采样），其中 $p$ 为预设的概率质量阈值。这种局部概率控制范式假设，只要每一步的采样足够合理，全局生成质量自然得到保证。然而，这种假设忽略了生成过程的状态依赖性，即当前 token 的选择会改变后续步骤的条件分布，进而影响宏观层面的文本结构。

随着模型规模扩大与应用场景复杂化，问题定义从“局部噪声过滤”演变为“长程宏观行为诊断”。研究者发现，即使每一步的局部概率分布合理，长程生成中仍会出现重复、平淡或自我强化的局部最优状态，即模式坍缩（Mode Collapse）。这一发现揭示了子问题之间的层级依赖关系：基础的概率截断稳定性是后续所有动态控制的前提，而长程模式坍缩的解决则依赖于对内部状态空间演化的监控与干预。与此同时，对齐训练（Alignment）的引入带来了新的矛盾，即通过强化学习人类反馈（RLHF）等技术提升指令遵循质量的同时，显著降低了输出多样性，导致输出同质化。这使得问题核心进一步演变为“如何在保持质量（事实性/指令遵循）的同时，防止生成轨迹在状态空间中坍缩至局部最优”。

从 2016 年至 2018 年，奠基性工作确立了基于排名截断的基础范式，Top-k Sampling 通过保留概率最高的 k 个 token 来截断长尾分布，成为后续多样性采样研究的基线。2020 年，Nucleus Sampling (Top-p) 的提出标志着从固定阈值向动态概率质量截断的范式转变，解决了长尾分布下的采样不稳定问题，成为 LLM 解码的标准配置。这一时期的方法主要关注局部概率分布的形状，假设通过调整截断边界即可平衡质量与多样性。

2023 年至 2024 年，问题定义发生了关键转折，研究重心从单纯的概率截断转向对分布几何结构、熵动态及内部表示状态的深层调控。Contrastive Decoding 通过比较正常模型与弱模型的输出分布，抑制低质量或重复的生成路径，引入了模型间的差异信号来引导解码。Grammar-Constrained Decoding 则将有限状态自动机集成到解码循环中，实现了结构化输出的严格保证，但也暴露了约束导致的分布扭曲问题。这一阶段的方法开始意识到，局部 Token 级控制无法预测或阻止宏观层面的重复与退化，因为坍缩源于内部状态空间的动态演化而非单步概率。

2025 年至 2026 年，领域进入“几何感知”与“状态空间干预”阶段。Min-k Sampling 通过分析 logit 分布的局部形状定位“语义悬崖”，实现了温度不变的自适应截断，解决了传统概率截断对温度参数敏感的问题。Base-Aligned Collaboration (BACO) 通过路由机制在基础模型和对齐模型之间动态切换，利用基础模型的多样性弥补对齐模型的坍缩，从模型间协作层面恢复了被抑制的语义多样性。Geometric Regulation 则从动力系统视角研究 LLM 生成中的模式崩溃，提出基于相关维数的状态空间干预方法，将解码控制从符号层面的 token 概率调整提升到内部状态层面的几何约束。当前，该领域高度活跃，研究热点集中在解耦任务求解与格式约束、在扩散语言模型中实现非单调解码、以及通过基座模型与对齐模型协作来恢复被 RLHF 抑制的语义多样性，旨在实现高质量与高多样性的帕累托最优。

**如果用一个核心问题概括该领域，那便是在不牺牲事实性与指令遵循质量的前提下，通过解耦局部概率截断与全局状态空间演化，恢复并维持大语言模型生成过程中的语义多样性与长程稳定性。**

## 2. 方法体系

- 2018：Top-k Sampling——通过保留概率最高的k个token来截断长尾分布，有效过滤低概率噪声token。

- 2020：Nucleus Sampling (Top-p)——根据累积概率质量动态确定候选集大小，在保持多样性的同时避免采样到极低概率的异常token。

- 2021：Mirostat——通过在线监控和控制生成过程中的惊讶度（surprise）来维持目标困惑度水平。

- 2023：Contrastive Decoding——通过比较正常模型与弱模型（或噪声模型）的输出分布，抑制低质量或重复的生成路径。

- 2024：Grammar-Constrained Decoding——将有限状态自动机或解析器集成到解码循环中，实时屏蔽不符合语法规则的token。

- 2025：Min-p Sampling——基于最大概率的相对阈值进行截断，自适应地调整候选集大小以匹配分布的尖锐程度。

- 2025：Base-Aligned Collaboration (BACO)——通过路由机制在基础模型和对齐模型之间动态切换，利用基础模型的多样性弥补对齐模型的坍缩。

- 2026：Min-k Sampling——通过分析logit分布的局部形状定位“语义悬崖”，实现温度不变的自适应截断。

这条时间线勾勒了该领域方法演进的代表性节点：从 2018 年的 Top-k Sampling 奠定该领域方法基线，经 2020 年 Nucleus Sampling (Top-p) 的推进，到 2026 年的 Word Coverage Score (WCS) 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 采样截断策略

采样截断策略是解码方法体系的基石，其核心思想是通过动态调整候选词表的大小来平衡生成质量与多样性。早期的 Top-k 和 Top-p 方法主要关注全局概率统计量，如累积概率质量或固定排名，但在分布尖锐或平坦时适应性不足。Min-k Sampling（Ding et al., 2026, P14）针对 Top-p 在温度变化下行为不一致的问题，提出了一种基于 logit 分布局部形状分析的自适应截断方法。该方法通过识别排序 logit 值中的“语义悬崖”来动态确定候选集大小 k，从而在保留高概率语义区域的同时剔除低概率噪声。其核心创新在于利用局部结构而非全局统计量进行决策，使得截断边界能够随上下文置信度的变化而平滑调整，具有天然的温度不变性。这种设计放弃了全局统计量的简洁性，换取了在不同温度设置下一致的截断行为，解决了传统概率截断对温度参数的高度敏感性。

在几何感知方向，Geometry-Aware Decoding（Gholami Davoodi et al., 2026, P7）引入了基于 Wasserstein 距离的正则化截断机制，将 token 嵌入空间的几何结构融入解码过程。该方法定义了一种由 token 嵌入诱导的地面度量，使得概率质量的移动成本与语义相似度相关，从而在截断分布时优先考虑保留语义邻域内的质量。通过最小化 Wasserstein-1 项与质量惩罚，该方法能够更智能地丢弃低概率 token，同时避免在语义不相关的 token 之间进行大规模质量转移。其核心优势在于将截断规则从纯粹的组合计数提升为语义感知的优化问题，增强了生成文本的连贯性和事实性。该方法依赖于预训练嵌入矩阵的质量，假设嵌入空间中的几何邻近性能够有效反映功能相似性，放弃了纯概率截断的计算效率，换取了语义层面的稳定性。

针对头部锁定问题，XTC（Weidmann et al., 2026, P25）提出了一种头部感知的采样策略，通过排除部分高概率 token 来增强生成多样性。该方法识别出模型过度自信导致的“头部锁定”现象，并通过概率阈值和排名阈值动态排除最可能的几个候选项，强制模型探索次优但合理的替代路径。XTC 的核心设计在于平衡忠实度与多样性，避免保守采样产生的重复文本，同时防止激进采样引入的不合理 token。其参数 $\rho$ 和 $\tau$ 分别控制排除的比例和阈值，允许在不同任务间灵活调整探索强度。该方法特别适用于创意写作和代码生成任务，能够显著提升 Distinct-n 和 SelfBLEU 等多样性指标，但代价是可能在某些高置信度步骤中牺牲部分准确性。

此外，Entropy-Aligned Decoding (EPIC)（Ahmed and Singh, 2026, P3）基于熵对齐原理设计解码算法，旨在使生成序列的熵与目标分布的熵保持一致。该方法通过监控生成过程中的交叉熵和 KL 散度，动态调整截断阈值，确保模型的不确定性反映数据的固有随机性而非模型的知识缺陷。EPIC 的核心创新在于将解码视为一个校准问题，通过最小化模型分布与真实数据分布之间的熵差异来优化采样策略。其关键技术模块包括熵估计器和动态截断控制器，能够实时响应分布形状的变化。该方法假设模型是校准良好的，即模型的不确定性主要反映数据的偶然不确定性，在写作和推理任务中表现出更高的生成质量。

在诊断工具方面，Word Coverage Score (WCS)（Awad et al., 2026, P21）提出了一种动态行为指标，量化 LLM 在特定解码约束下的词汇可达性。该方法通过强制路径审计，追踪人类作者词汇在自回归生成过程中的逐步存活概率，揭示采样算法如何削减词汇多样性。WCS 的核心在于将“可达性”形式化为逐步 token 存活概率的乘积，从而精确测量解码策略对词汇覆盖的影响。其技术模块包括路径审计器和存活概率计算器，能够区分模型的知识缺失与解码约束导致的不可达。该方法不评估静态理解能力，而是关注生成过程中的动态行为，为诊断模式崩溃提供了微观视角。

### 2.2 动态解码控制

动态解码控制路线旨在通过监控生成过程中的状态变量并实时调整解码参数，解决长程生成中的宏观模式坍缩问题。这一路线的起源可追溯至 Mirostat（2021），它通过在线监控和控制生成过程中的惊讶度来维持目标困惑度水平，引入了反馈机制以平衡多样性与连贯性。随后，Contrastive Decoding（2023）通过比较正常模型与弱模型的输出分布，抑制低质量或重复的生成路径，利用模型间的差异信号来引导解码，增强了生成内容的独特性。

GUARD（EMNLP 2025, P33）结合全局和局部不确定性信息，实现高效且自适应的解码控制。该方法通过计算生成过程中的全局熵（历史局部熵的加权平均）来捕捉模型不确定性的长期波动，并结合瞬时局部熵来调整 Top-k 参数和 token 评分权重。其核心创新在于引入“Glocal”不确定性概念，既考虑短期波动又考虑长期趋势，从而平滑生成过程中的熵突变。GUARD 还包含基于 token 计数的重复惩罚，以抑制重复生成。该方法证明了全局熵是瞬时熵的无偏且一致估计量，为动态调整解码参数提供了理论依据。其代价是增加了计算全局熵的开销，但通过滑动窗口机制可高效实现。GUARD 在开放式文本生成中显著提升了质量，同时保持了计算效率，与采样截断策略相比，它放弃了静态阈值的简洁性，换取了对长程熵波动的鲁棒适应能力。

OverRIDE（ICLR 2026, P32）通过微调引导模型并重新加权原始模型的 token 分布，实现多轮生成中的持续多样性。该方法在每轮生成后，利用历史响应微调一个引导模型，然后使用该模型重新加权原始模型的下一 token 分布，以避开已生成的路径。其核心创新在于将多样性控制转化为分布重加权问题，确保新生成的响应与历史响应在分布上保持距离。OverRIDE 支持并行实现，可直接集成到现有的 LLM 服务系统中，无需修改模型参数。其代价是需要额外的引导模型训练和存储开销，且重加权过程可能引入计算延迟。该方法特别适用于需要生成大量多样化响应的场景，如合成数据构建或最佳 N 选择，与 GUARD 的实时熵监控不同，OverRIDE 依赖于历史数据的显式重加权，实现了更直接的语义去重。

Adaptive Decoding via Test-Time Policy Learning（Bhardwaj et al., 2026, P12）将解码策略建模为强化学习问题，通过测试时策略学习实现自改进生成。该方法利用 PPO 算法训练解码策略，使其能够根据输入提示和领域变化动态调整 token 选择行为。其核心创新在于将解码视为一个 MDP，其中状态是 token 前缀，动作是 token 选择，奖励函数根据下游任务目标进行设计。通过端到端学习，解码器能够超越静态启发式，适应特定的下游目标或上下文偏好。该方法具有模块化优势，同一 RL 框架可通过不同的状态特征、动作旋钮和奖励函数实例化，适用于多种应用场景。其代价是需要额外的奖励模型或评估器，且训练过程可能不稳定。该方法为解码策略的个性化和任务特定优化提供了强大的框架，代表了从启发式规则向学习式策略的范式转变。

G2（EMNLP 2025, P28）利用单一 LLM 内的多个模块（基础生成器、多样性引导器、去重引导器）协作，增强输出多样性。该方法通过不同的提示模板区分模块角色，并引入中心选择策略（CSS）从历史生成中选择语义代表性子集作为条件，以指导后续生成。其核心创新在于利用对比信号（原始提示与多样化/去重提示之间的差异）来同时实现多样性和质量提升。G2 避免了多模型设置的词汇不匹配问题，且比单模型方法更高效。其代价是增加了提示工程的复杂度和推理时的条件计算开销。该方法在创意写作和开放式问答任务中表现出显著的多样性提升，同时保持了较高的生成质量，与 OverRIDE 的外部模型重加权不同，G2 依赖于单模型内部的多角色提示工程，实现了更轻量级的多样性控制。

Latent Distilling (ESamp)（Zeng et al., 2026, P15）通过潜在蒸馏估计连续表示空间中的冗余度，实现语义级别的探索控制。该方法将 LLM 生成建模为 MDP，利用潜在蒸馏（LD）估计 token 前缀在连续表示空间中的冗余度，并据此惩罚语义重复而非表面形式的重复。其核心创新在于将冗余检测从词汇空间提升到连续表示空间，能够捕获不同表面形式但语义等价的序列。ESamp 通过在线适应机制抑制冗余，增强探索能力，即使表面形式变化也能保持语义多样性。其代价是需要额外的潜在蒸馏计算，且依赖于表示空间的质量。该方法为测试时扩展提供了更鲁棒的多样性控制手段，特别适用于推理任务，与 GUARD 的熵监控不同，ESamp 直接作用于语义表示空间，解决了语义冗余而非词汇冗余的问题。

### 2.3 结构化约束解码

结构化约束解码旨在解决在满足语法或格式约束（如 JSON、代码）的同时保持语义多样性的问题。早期的 Grammar-Constrained Decoding（2024）将有限状态自动机或解析器集成到解码循环中，实时屏蔽不符合语法规则的 token，实现了结构化输出的严格保证，成为 JSON 和代码生成任务的基础设施。然而，这种硬约束方法通过掩码和重归一化引入了累积的 KL 散度，导致模型偏离自然分布，即“投影税”。

DCCD（Reddy et al., 2026, P10）引入草稿条件机制，通过草稿模型预测来修正约束解码中的可行质量量，减少分布扭曲。该方法识别出标准约束解码中因可行质量量小而导致的 KL 散度累积问题，并利用草稿模型的预测来估计更准确的可行质量量。其核心创新在于将草稿生成与约束解码结合，通过草稿条件来平滑约束引起的分布变化。DCCD 在多个模型规模上均显示出比标准约束解码更高的准确性，特别是在小模型上增益显著。其代价是需要额外的草稿模型推理开销。该方法为提升结构化生成的准确性提供了新的技术路径，特别适用于资源受限的场景，与传统的硬约束解码相比，它放弃了严格的实时掩码，换取了通过草稿预测实现的分布平滑。

DECO-G（ACL 2026, P31）提出一种解耦任务求解与格式遵循的解码框架，通过专门的格式估计模块（FEM）重新加权 token 分布。该方法将任务指令与格式约束分离，仅向 LLM 提供任务信息，而将格式约束发送给 FEM，由 FEM 估计格式满足率并指导生成。其核心创新在于显式分离任务求解和格式遵循，以保留 LLM 的全部潜力，避免格式约束对任务求解的干扰。DECO-G 利用概率模型进行前瞻推理，计算满足约束的序列概率，从而高效地引导生成。其代价是引入了额外的 FEM 模块和计算开销。该方法在复杂任务中显著提升了格式遵循率和任务准确性，与 DCCD 的草稿条件化不同，DECO-G 通过模块解耦实现了任务与格式的独立优化，避免了约束对语义生成的直接干扰。

Automata-Based Steering（Luan et al., 2025, P2）提出一种基于自动机的引导方法，在结构化生成中鼓励 LLM 探索较少使用的路径。该方法在引导自动机的状态空间中，动态调整 token 概率以偏向未访问过的状态，从而增加结构化输出的多样性。其核心创新在于将多样性目标嵌入到自动机引导过程中，而非仅关注约束满足。该方法系统性地鼓励探索，确保生成的结构化输出不仅有效，而且具有广泛的覆盖范围。其代价是可能增加生成时间，因为需要跟踪自动机状态并调整概率。该方法特别适用于软件测试和 AI 代理规划等需要多样化结构化输入的场景，与 DCCD 和 DECO-G 关注准确性不同，Automata-Based Steering 侧重于结构化输出的路径覆盖多样性。

NCO（Jin and Han, 2026, P18）提出一种通用的插件方法，用于在解码过程中处理负约束（如禁止子串）。该方法利用 Aho-Corasick 算法构建自动机，实时计算无效 token 掩码，避免重复采样。其核心创新在于将负约束处理形式化为有限自动机状态转移问题，直接计算无效 token 而非通过拒绝采样。NCO 能够高效处理多种正则表达式约束，且无需模型训练或全局避免自动机构建。其代价是构建自动机的预处理开销，但对于固定约束集可忽略不计。该方法特别适用于安全敏感场景，如防止 PII 泄露或仇恨言论生成，能够实时抑制违规内容，与正约束解码不同，NCO 专注于负约束的高效处理，保持了接近无约束解码的吞吐量。

OS-Search（Materzok, 2026, P5）提出在冻结编码器定义的输出空间中搜索 LLM 生成结果，提供低维连续控制接口。该方法将生成结果映射到低维坐标空间，外部循环可选择目标点 $z^*$，模型生成符合该目标的输出。其核心创新在于将解码控制从 token 空间提升到输出空间，允许外部优化器直接优化下游目标，而无需修改解码过程。OS-Search 支持并行扫描和外部循环优化，且样本间独立，避免了序列依赖。其代价是需要训练一个 $z^*$ 条件控制器，且依赖于编码器表示的质量。该方法为 LLM 生成的可控性和可优化性提供了新的范式，特别适用于需要多目标优化的场景，与传统的 token 级约束解码不同，OS-Search 在输出空间层面实现了更灵活的目标导向生成。

### 2.4 训练对齐优化

训练对齐优化路线从模型训练或参数空间层面缓解对齐过程中的多样性坍缩，旨在解决 RLHF 等对齐技术导致的分布压缩问题。这一路线的动机源于对对齐训练副作用的深入理解，即指令微调倾向于优化高概率续写，从而抑制了低概率但合理的多样性输出。

BACO（Wang et al., 2025, P1）提出一种基于基础模型和对齐模型协作的推理策略，通过路由机制动态切换以优化多样性和质量。该方法利用基础模型的高多样性和对齐模型的高质量，通过不确定性估计和语义角色分析来决定何时使用哪个模型。其核心创新在于将多样性优化从单一模型内部扩展到模型间协作，充分利用不同模型的优势。BACO 在语义和词汇多样性指标上均显著优于基线方法，且保持了较高的生成质量。其代价是需要维护两个模型并实现高效的路由机制。该方法为缓解对齐过程中的多样性坍缩提供了实用的推理时解决方案，与单模型内部的解码控制不同，BACO 依赖于模型间的特性差异，实现了更根本的多样性恢复。

CreativeInstruct（Sahu et al., 2026, P23）提出一种可扩展的教学方法，通过标记基础模型生成的创造性片段，微调对齐模型以学习何时注入创造性 token。该方法利用 BACO 生成响应，并标记基础模型生成的片段，然后微调对齐模型以学习在关键位置切换至创造性模式。其核心创新在于使模型能够自主决定何时注入创造性，从而在保持质量的同时提升多样性。CreativeInstruct 还提出了 LLM-GED 指标，用于评估叙事级别的多样性。其代价是需要额外的标记数据和微调过程。该方法在创意写作任务中显著提升了输出的新颖性和多样性，为平衡质量与创意提供了新的训练范式，与 BACO 的推理时路由不同，CreativeInstruct 将协作策略内化到模型参数中，实现了更高效的单模型部署。

Semantic Flow Regularization (SFR)（Peng et al., 2026, P22）提出一种训练目标，通过流匹配（Flow Matching）正则化使 LLM 骨干网络对风格敏感，从而生成多样且连贯的响应。该方法在监督微调中引入辅助流匹配头，预测未来 token 的嵌入表示，以保留多模态目标分布的多样性。其核心创新在于将流匹配技术应用于语言模型训练，使模型能够学习多种有效续写的分布，而非收敛到单一模式。SFR 在部署时删除流匹配头，零推理开销，且无需每风格参数或解码时分类器。其代价是训练过程中增加了流匹配头的计算开销。该方法特别适用于风格可控对话和角色生成任务，能够显著提升输出的风格多样性和一致性，与 BACO 的模型间协作不同，SFR 通过训练时的正则化保留了多模态分布，实现了内在的多样性。

QEMPO（Pan et al., 2026, P8）提出一种策略优化方法，在保持质量约束的同时最大化策略熵，以提升 LLM 生成的多样性。该方法在 RLHF 框架中引入熵最大化目标，并通过仅在正确输出上计算方差项来防止低质量输出的过度熵增。其核心创新在于将多样性优化与质量约束结合，确保熵的增加不会损害生成质量。QEMPO-KL 进一步引入 KL 散度约束，以平衡探索与利用。其代价是训练过程可能不稳定，需要仔细调整超参数。该方法在数学推理和开放式生成任务中显著提升了 pass@k 指标，表明增加多样性也能提升模型性能，与 SFR 的流匹配正则化不同，QEMPO 直接在策略优化过程中引入熵最大化目标，实现了质量与多样性的联合优化。

P-SFT（ACL 2026, P29）提出一种前缀条件化的监督微调方法，通过构建语义一致的前缀来解耦多响应学习。该方法为每个训练对分配一个随机前缀，使模型学习在不同前缀条件下生成不同的响应，从而覆盖完整的概率分布。其核心创新在于利用前缀作为条件变量，避免模型在不同响应方向冲突时收敛到单一模式。P-SFT 简单有效，可与 Best-of-N 或 Self-consistency 等技术结合使用。其代价是增加了训练数据的复杂度和前缀管理的开销。该方法在指令遵循和创意写作任务中显著提升了响应多样性，为多模态响应生成提供了新的训练范式，与 QEMPO 的熵最大化不同，P-SFT 通过前缀条件化实现了分布的显式解耦，避免了训练过程中的模式坍缩。

此外，Diversity in LLMs under SFT（Klypa and Cherednichenko, 2026, P16）研究监督微调对 LLM 多样性的影响，揭示指令微调如何导致输出同质化。该方法通过对比预训练模型和指令微调模型的生成分布，分析了多样性丧失的机制。研究发现，指令微调倾向于优化高概率续写，从而抑制了低概率但合理的多样性输出。其核心贡献在于从训练动态角度解释了多样性坍缩的原因，为后续优化提供了理论依据。该方法强调了在微调过程中保留多样性的重要性，并提出了可能的缓解策略。Infusing Random Concepts（Agrawal and Goyal, 2026, P4）提出一种通过向提示中注入随机概念来增加 LLM 输出多样性的方法，利用随机性作为多样性来源，无需修改模型参数或解码策略。Addressing Barriers to Diversity in LLM-Generated Ideas（Deng et al., 2026, P9）研究 LLM 创意生成中多样性不足的机制，提出通过 CoT 提示和普通角色提示来缓解固定效应和知识聚合问题，从认知心理学角度解释了 LLM 创意多样性的障碍。

### 2.5 扩散模型解码

扩散模型解码路线针对扩散大语言模型（DLLMs）的非自回归特性，研究基于置信度校准、块边界突破及 Token 编辑的解码策略，旨在平衡并行效率与生成质量。这一路线的兴起源于对自回归解码单调性局限性的认识，即自回归解码的单调性导致错误累积，而扩散模型的非单调特性提供了修正机会。

DecoCal（ACL 2026, P30）提出一种基于校准引导的重掩码机制，用于稳定扩散 LLM 中的 token 级置信度。该方法通过比较瞬时预测置信度与时间聚合置信度，决定已提交 token 是否需要重新掩码。其核心创新在于显式区分瞬时模型置信度和校准置信度，避免早期过度自信导致的不可逆错误。DecoCal 允许在收敛 token 上早期解码，同时保留修正机会，提升了生成质量和效率。其代价是增加了时间聚合置信度计算的开销。该方法适用于任何掩码扩散语言模型，为提升扩散解码的鲁棒性提供了通用解决方案，与自回归解码的单调提交不同，DecoCal 通过校准机制实现了非单调的 token 修正，解决了早期过度自信问题。

LLaDA2.1（Bie et al., 2026, P6）提出一种可编辑状态演化框架，通过草稿-编辑范式加速文本扩散生成。该方法将模型训练为同时具备草稿（Mask-to-Token）和编辑（Token-to-Token）能力，允许在生成过程中修正错误。其核心创新在于将扩散生成从单调的掩码揭示扩展为可编辑的状态演化，提升了生成保真度。LLaDA2.1 还引入了 EBPO（ELBO-based Block-level Policy Optimization）来加速 RL 训练，解决了序列级对数似然不可处理的问题。其代价是训练过程较为复杂，需要双流目标函数。该方法在保持并行解码效率的同时，显著提升了生成质量，为扩散 LLM 的实用化提供了重要进展，与 DecoCal 的置信度校准不同，LLaDA2.1 通过显式的编辑能力实现了更直接的状态修正。

Anchor-based History-stable Decoding（ACL 2026, P34）提出一种基于锚点的历史稳定解码方法，用于突破扩散 LLM 中的块边界限制。该方法识别跨块稳定 token，并将其从顺序块约束中释放，以提升推理效率和性能。其核心创新在于开发精确检测跨块 token 稳定性的条件，避免局部区域抑制导致的性能下降。该方法通过锚点机制确保稳定 token 的解码不受块边界影响，实现了更灵活的并行解码。其代价是需要额外的稳定性检测计算。该方法特别适用于长文本生成任务，能够显著提升扩散 LLM 的推理速度和生成质量，与 DecoCal 和 LLaDA2.1 关注 token 级修正不同，AHD 侧重于块级并行解码的效率优化，突破了扩散模型固有的块边界限制。

### 2.6 多样性评估分析

多样性评估分析路线旨在构建信息论或统计指标量化 LLM 生成的多样性缺口，分析迭代生成中的语义坍缩机制，为解码策略优化提供理论依据与诊断工具。这一路线的兴起源于对传统词汇指标（如 Distinct-n）局限性的认识，即这些指标无法捕捉深层的内容多样性和长程模式坍缩。

Conditional Diversity Objective（Wu and Farnia, 2026, P27）提出一种基于核方法的条件多样性目标，用于量化 LLM 生成与训练数据之间的多样性差距。该方法利用 von Neumann 熵和相对核熵，在特征空间中比较条件分布的多样性。其核心创新在于将多样性评估形式化为核矩阵上的熵计算，能够捕捉高阶统计依赖关系。该方法适用于语言和图像生成任务，能够揭示模型在特定条件下的多样性不足。其代价是核矩阵计算的复杂度较高，但可通过采样近似。该方法为优化解码策略提供了理论依据，并可用于指导训练过程中的多样性正则化，与传统的 Distinct-n 不同，Conditional Diversity Objective 在特征空间层面实现了更深层的多样性量化。

Novels generated by LLMs show compressed formal variation（Sedaghat Payam and Quinn, 2026, P24）研究 LLM 生成小说在长程尺度上的形式变异压缩现象。该方法对比了 LLM 生成小说与人类小说在词汇、句法、可读性和标点等方面的统计特性，发现 LLM 生成的小说集在形式变异上远小于人类小说集。其核心贡献在于揭示了 LLM 在长程生成中难以维持形式多样性的问题，即使单篇小说可能流畅且风格多变。该方法强调了在文档级别评估多样性的重要性，而非仅关注句子级别。其代价是实验数据收集和分析较为复杂。该研究为理解 LLM 长程生成的局限性提供了实证依据，并指出了未来改进的方向，与 Conditional Diversity Objective 的理论量化不同，P24 通过实证对比揭示了长程生成的实际缺陷。

Markovian Generation Chains（Geng et al., 2026, P11）提出一种形式化框架，用于分析 LLM 在迭代重处理过程中的文本演化。该方法将迭代生成建模为马尔可夫链，量化不同解码配置下句子多样性的演变。其核心创新在于定义了迭代重处理中的多样性指标，并揭示了不同解码策略对长期多样性的影响。研究发现，贪心解码和低温采样会导致多样性迅速下降，而高温采样和 Top-p 采样能维持更长的多样性。其代价是实验需要多次迭代生成，计算开销较大。该方法为理解 LLM 在迭代工作流中的行为提供了理论工具，并指导了解码策略的选择，与 P24 的静态对比不同，P11 通过动态建模揭示了多样性随迭代次数的演变规律。

Hyperfitting as a Late-Stage Geometric Expansion（Li et al., 2026, P20）研究 LLM 在极端过拟合阶段的生成多样性变化，揭示“Loss-Rank-Quality”三元组关系。该方法发现，尽管验证困惑度急剧上升，但生成多样性（TTR）反而稳步提升，表明困惑度不是生成质量的可靠代理。其核心创新在于揭示了过拟合阶段 rank 重排序机制，抑制重复 token 并促进多样化候选项。该方法通过 Late-Stage LoRA 策略，利用过拟合模型的几何扩展特性来提升生成多样性。其代价是需要精确控制过拟合程度，且可能牺牲概率估计的准确性。该研究为利用过拟合模型提升生成多样性提供了新的视角，与 P11 的马尔可夫链分析不同，P20 从过拟合的几何扩展角度解释了多样性变化的机制。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域最核心的共识是对齐训练在提升指令遵循和质量的同时，显著降低了 LLM 输出的多样性和创造性，导致输出同质化。这一共识在多个基准上被反复验证：CreativeInstruct 在 AlpacaEval 上的 0.478 胜率显著高于 Distill 基线的 0.376，且 BACO 在语义多样性指标上均优于单模型解码方法，表明对齐过程确实引入了分布压缩（支撑证据：P1, P23）。与此相关的另一个共识是，传统的 Token 级解码控制主要作用于局部概率分布，无法有效解决长程生成中的宏观模式坍缩和语义重复问题。WCS 和 SER@4 等动态行为指标显示，即使使用最优局部截断，长程生成中仍会出现语义收敛，Geometric Regulation 在长程任务中表现出更优的稳定性，证实了局部控制的局限性（支撑证据：P17, P21）。

### 3.2 观点分歧

解决多样性丧失的最佳路径存在显著分歧，即解码时动态干预与训练时分布重塑/模型协作之争。观点 A 主张通过几何调控或动态解码在推理阶段实时调整，无需重训练，部署灵活；观点 B 主张通过 SFR、QEMPO 等训练优化或 BACO 模型协作，从根源上解决对齐导致的分布压缩，效果更持久。现有证据偏向观点 B，因为 BACO 在语义多样性指标上显著优于单模型解码方法，且 SFR 在风格多样性上表现优异，但观点 A 在无需重训练的场景下更具实用性。证据强度中等，缺乏在相同计算预算下的严格对比，且不同任务对两种路径的偏好不同（支撑证据：P1, P8, P22）。这一分歧的背后，是另一个更根本的争论：局部 Token 控制与全局状态空间干预的优劣。现有证据偏向全局干预，因为 WCS 和 SER@4 等指标显示局部截断无法阻止长程语义收敛，但全局干预的计算开销在实时应用中可能不可接受，且状态空间几何与生成多样性的因果关系尚未完全建立（支撑证据：P17, P21）。

### 3.3 其他开放问题

最紧迫的工程问题是扩散模型解码的效率与校准。DecoCal 和 AHD 虽然解决了早期过度自信问题，但解码步骤多、推理延迟高，需开发基于历史稳定性锚点或跨步骤置信度聚合的解码框架以减少延迟（支撑证据：P30, P34）。最根本的研究问题则是多 LLM 系统中的语义坍缩机制。P19 的研究发现，即使增加模型数量、注入噪声或改变编排框架，语义多样性仍会迅速回归基线水平，且系统对噪声的敏感性随时间降低，表明语义坍缩是 LLM 系统的固有属性，而非简单的采样问题。这一发现对设计长期稳定的多智能体系统具有重要警示意义，未来需探索引入外部信息源或打破封闭马尔可夫链结构的机制，以维持真正的开放式创新（支撑证据：P19）。已知的是对齐训练导致多样性丧失且局部控制不足，争议的是解决路径是解码时干预还是训练时优化，未知的是多智能体系统中语义收敛的理论边界与叙事级多样性的量化方法。

## 4. 总结与展望

大语言模型解码研究的核心矛盾在于对齐训练带来的分布压缩与生成任务所需的语义多样性之间的结构性冲突。从 Top-k 到 Min-k 的演进解决了温度敏感性问题，从熵监控到几何调控的演进解决了长程稳定性问题，从单模型到协作的演进解决了对齐补偿问题。然而，核心瓶颈仍在于如何在不牺牲质量的前提下，通过解耦局部概率截断与全局状态演化，恢复并维持生成过程中的语义多样性与长程稳定性。现有方法在局部鲁棒性、长程稳定性和对齐补偿方面取得了进展，但尚未实现三者之间的帕累托最优。

未来可能突破的方向包括：基于内部表示的语义探索与新颖性引导，利用潜在空间的新颖性估计或流匹配正则化，引导模型探索未被充分开发的语义区域（支撑证据：P15, P22）；以及测试时自适应解码与策略学习，结合强化学习或在线策略优化，使解码器能根据反馈动态调整采样行为，实现无需修改基础模型的自我改进生成（支撑证据：P12, P33）。对于进入该领域的研究者，最值得做的一件事是在统一骨干与统一预训练条件下，系统对比解码时干预与训练时优化在长程多智能体系统中的累积效应，以填补当前证据的空白。
