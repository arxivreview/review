# A Survey of Agentic Search and Generative Information Retrieval Methods ｜智能体搜索与生成式信息检索方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Agentic%20Search%20and%20Generative%20Information%20Retrieval)

## 导读

智能体搜索（Agentic Search）让大语言模型（LLM）从被动的知识消费者转变为主动的信息探索者，其核心价值在于突破静态检索增强生成（RAG）在多步推理与动态意图捕捉上的固有局限。早期研究依赖固定的“检索-生成”管道，虽缓解了幻觉问题，却无法处理需要非线性调查的复杂查询。随着 ReAct 等框架的引入，LLM 开始自主规划搜索策略并迭代调用外部工具，领域重心随之转向长程任务中的信用分配与证据整合。2025 年以来，强化学习（RL）与多智能体架构的兴起进一步推动了从单体优化向系统级协同的演进，同时生成式引擎优化（GEO）等生态层面的问题也进入研究视野。各路线在策略稳定性、计算成本与系统复杂度之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从静态管道到自主探索的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

智能体搜索的兴起源于 LLM 参数化知识的固有缺陷，即知识时效性滞后与事实幻觉。早期解决方案是 RAG，通过从外部知识库检索文档来增强生成过程，但这本质上是一种静态的“检索-生成”管道，缺乏对复杂用户意图的深度理解与多步推理能力。当任务从单跳事实检索扩展至多跳推理时，静态管道暴露出严重的推理断裂问题，模型无法根据中间结果动态调整后续查询。这一局限促使研究者重新定义问题：从“如何检索相关文档”转变为“如何自主规划搜索策略并整合多源证据”。

问题的形式化定义随之演化。传统信息检索关注查询与文档的匹配，而智能体搜索将任务建模为序贯决策过程。给定用户查询 $q$，智能体在每一步 $t$ 基于历史轨迹 $\tau_{t-1}$ 生成动作 $a_t$（如搜索、浏览、思考），环境返回观察 $o_t$，智能体需综合所有观察生成最终答案 $y$。这一过程涉及三个核心子问题：规划（如何分解复杂查询）、检索（如何获取高质量证据）与综合（如何整合冲突信息）。这三个子问题存在强依赖关系：检索质量是基础，若检索器无法适应智能体的动态查询模式，后续的推理将因证据缺失而失效；记忆管理是长程任务的前提，不解决上下文窗口限制就无法进行多步推理；而强化学习则是优化上述策略的核心手段，用于解决长程任务中的信用分配难题。

2016 至 2018 年间，度量学习与原型网络奠定了少样本学习的几何基础，但彼时 LLM 尚未具备工具调用能力。2020 年，RAG 的提出标志着外部知识注入 LLM 的开端，确立了“检索辅助生成”的基线范式。然而，RAG 的静态特性在 2022 年遭遇瓶颈，ReAct 框架的提出成为关键转折，它引入了推理与行动交替执行的机制，使 LLM 能够动态调用外部工具并基于观察调整策略，从而解决了单轮 RAG 无法迭代的问题。这一范式转变将 LLM 从被动的证据消费者提升为主动的搜索智能体。

2023 至 2024 年，随着 Search-o1 等工作的出现，研究重心转向利用强化学习训练搜索智能体，使其在复杂多跳问答中具备自主规划能力。这一阶段的核心挑战是稀疏奖励下的信用分配，即如何确定长轨迹中哪些中间步骤对最终成功贡献最大。2025 年，Search-R1 提出基于可验证奖励的强化学习框架，初步解决了这一难题，同时 CoSearch 实现了推理智能体与文档排序器的联合优化，打破了检索与生成模块独立训练的局限。同年，WideSearch 基准的建立填补了广度搜索评估的空白，而 GEO 概念的提出则标志着研究边界从模型内部延伸至生成式引擎生态。

2026 年，领域进入细化与融合期。M-ASK 等多智能体框架通过角色分工解决长程信用分配与模型崩溃问题，EvolveSearch 则通过自进化机制提升复杂环境下的鲁棒性。GrepSeek 进一步探索了智能体直接通过命令行与语料库交互的可能性，挑战了传统向量检索接口的必要性。当前，该领域呈现出“深度研究”与“广度搜索”并行的格局，核心驱动力在于解决长程任务中的证据整合、实时信息获取以及生成式引擎中的可见性与幻觉权衡。

**如果用一个核心问题概括该领域，那便是：如何构建能够自主规划、动态检索并整合多源异构证据的智能系统，以在开放域长程任务中实现高可信度的信息获取与生成。**

## 2. 方法体系

- 2020：RAG——奠定外部知识注入基线

- 2022：ReAct——确立推理与行动交替范式

- 2023：Search-o1——引入强化学习训练搜索智能体

- 2025：Search-R1——解决稀疏奖励与信用分配难题

- 2025：CoSearch——实现检索器与智能体联合优化

- 2025：WideSearch——建立广度搜索评测基准

- 2026：M-ASK——提出多智能体搜索与知识优化框架

- 2026：GrepSeek——实现智能体直接语料库交互

这条时间线勾勒了该领域方法演进的代表性节点：从 2020 年的 RAG 奠定该领域方法基线，经 2022 年 ReAct 的推进，到 2026 年的 M-ASK 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 强化学习训练优化

强化学习（RL）训练优化路线的核心动机是解决长程任务中的信用分配难题。早期方法如 Search-o1（2023）尝试利用 RL 训练智能体，但受限于稀疏奖励，训练过程不稳定。Search-R1（2025）通过引入可验证奖励（RLVR），利用最终答案的正确性作为信号，显著提升了策略优化的稳定性。然而，RLVR 仅关注最终结果，无法指导中间查询的质量。为此，SmartSearch（Wen et al., 2026, P12）引入了过程奖励模型（PRM），通过双层信用评估机制为每个查询提供细粒度反馈，并选择性地精炼低质量查询。这种设计放弃了 RLVR 的简洁性，换取了对中间决策的精细控制，解决了传统方法中查询生成盲目性的问题。

针对长程依赖导致的上下文噪声问题，Expand-then-Squeeze（Zhao et al., 2025, P4）提出了一种查询扩展与压缩策略。该方法在生成阶段产生多个多样化查询变体以扩大检索范围，随后通过长上下文 LLM 将检索到的长文本压缩为紧凑文本。其核心取舍在于以额外的计算开销换取信息密度的提升，有效降低了多轮滚动场景下的上下文噪声。MemSearcher（Yuan et al., 2025, P8）则进一步将记忆管理纳入端到端 RL 训练，通过显式记忆机制使智能体能够跨轮次保留关键信息，避免了重复检索。这种设计解决了长程任务中的信息遗忘问题，但增加了状态空间的复杂度。

DecoupleSearch（Sun et al., 2025, P7）通过层次化奖励建模解耦规划与搜索过程，利用蒙特卡洛树搜索构建推理树以提取正确与错误路径。该方法在策略模型基础上增加辅助线性层以推导规划价值模型与搜索价值模型，其创新在于将规划与搜索作为两个独立阶段进行优化，解决了传统方法中规划与检索相互干扰的问题。EvolveSearch（2025, P44）则提出了一种迭代自进化的训练框架，通过结合监督微调与强化学习，利用上一阶段的多样化滚动数据纳入数据池，实现模型能力的自我增强。这种设计显著提升了智能体在真实世界环境中的鲁棒性，避免了传统方法对复杂环境交互的过度依赖。

### 2.2 多智能体协同架构

多智能体协同架构旨在通过角色分工与并行处理解决单体模型在长程任务中的崩溃问题。M-ASK（Chen et al., 2026, P11）将问题形式化为序贯去中心化部分可观测马尔可夫决策过程，设计专门化的智能体角色并引入轮级奖励机制进行联合优化。其核心创新在于通过多智能体协作避免单一模型在长轨迹训练中的崩溃现象，显著提升了训练稳定性。这种设计放弃了单体架构的简洁性，换取了大规模信息聚合与深度推理的效率提升。

InfoSeeker（Lee et al., 2026, P24）提出了一种可扩展的层次化并行智能体框架，通过高层查询分解与低层结构化执行相结合，支持并行、串行或混合搜索结构。该方法引入反思机制与证据误用检测，解决了现有智能体在长程任务中规划不完整与证据整合不足的问题。Web2BigTable（Huang et al., 2026, P30）则区分深度搜索与宽泛搜索两种模式，通过多智能体协作实现从自然语言请求到模式对齐表格的自主转换，并引入验证与反思阶段实现无梯度更新的技能进化。

SearchOS-V1（Zhang et al., 2026, P40）设计了一种面向鲁棒开放域信息获取的智能体协作系统，通过工具集成 LLM 实现迭代搜索、浏览与推理。其核心在于设计协作机制以处理开放域任务中的不确定性，确保在多源证据冲突时仍能产生可靠的结构化结果。MultiSearch（Liu et al., 2026, P36）则通过并行搜索与显式合并扩展检索增强推理，设计多粒度奖励机制并利用 Group reward–Decoupled Normalization Policy Optimization 进行策略优化，解决了传统串行检索在信息覆盖度上的局限。

### 2.3 检索器协同优化

检索器协同优化路线打破了传统检索黑盒假设，旨在解决静态检索器与动态智能体行为的不匹配。Learning to Retrieve from Agent Trajectories（Zhou et al., 2026, P26）利用智能体在搜索过程中的交互日志作为训练数据，优化检索模型以更好地服务于智能体的动态查询需求。其核心创新在于将检索目标从人类点击行为转向智能体轨迹中的证据利用行为，使检索器能够预测智能体后续所需的文档。

GrepSeek（Salemi et al., 2026, P38）提出了一种训练搜索智能体直接通过命令行工具与语料库交互的方法，替代传统的向量或关键词检索接口。该方法在 ReAct 框架下，智能体通过生成 grep 等命令直接操作文本语料，获取所需信息。这种设计将检索过程转化为代码执行过程，显著提升了智能体在非结构化或半结构化语料上的检索灵活性，减少了对专用检索模型的依赖。Pi-Serini（Hsu et al., 2026, P34）则重新思考了词汇检索的充分性，通过对比词汇检索与密集检索在智能体搜索行为中的表现，提出“预览召回”指标，表明在强大 LLM 支持下，简单的词汇检索可能足以满足复杂搜索需求，挑战了必须使用复杂密集检索器的传统观点。

Critic-R（Ul Alam et al., 2026, P39）引入独立的批评模型，通过自然语言反馈判断当前信息是否满足需求，并指导查询精炼。该方法将批评模型与推理智能体解耦，使框架可应用于任意推理智能体而无需修改底层模型，为检索器与智能体的协同工作提供了轻量级、通用的增强方案。Native Retrieval Embeddings（Jiang, 2026, P21）则提出从 LLM 智能体隐藏状态生成原生检索嵌入的方法，消除对独立嵌入模型的依赖，显著降低了基础设施复杂度与延迟。

### 2.4 生成式引擎优化与生态

生成式引擎优化（GEO）关注如何优化网页内容以提升其在生成式搜索引擎中的可见性与引用率。AgenticGEO（Yuan et al., 2026, P23）提出了一种自进化智能体系统，通过进化循环动态调整内容策略以提升可见性。该系统包含进化器与批评者，通过混合突变与交叉操作生成候选策略，并利用优势加权回归稳定学习过程。IF-GEO（Zhou et al., 2026, P13）则针对多查询场景下的偏好冲突问题，采用“发散-收敛”工作流，通过冲突感知融合合成统一修订蓝图，显式优化稳定性指标，确保鲁棒性能。

Beyond Retrieval（Zhao et al., 2026, P25）提出了一种建模置信度衰减与确定性智能体平台的 GEO 框架，引入同构归因回归模型，通过双轨探测量化黑盒 LLM 中实体可见性的商业价值。这种设计超越了二元存在检查，利用多变量逻辑回归模型惩罚拓扑差异，评估无幻觉归因的概率，为 GEO 干预提供了数学严谨的评估基准。From Experience to Skill（Wu et al., 2026, P29）则通过可复用策略学习实现多智能体 GEO，将优化经验转化为可迁移技能，显著降低了 GEO 策略开发的成本。

### 2.5 基准评测体系

基准评测体系正从结果导向向过程诊断转变。WideSearch（2025, P45）填补了现有基准在广度搜索评估上的空白，要求智能体收集跨多个来源的广泛信息并聚合为结构化输出。GISA（Zhu et al., 2026, P15）提供详细的搜索行为分析指标，包括搜索相似度、多样性与浏览相似度，量化模型与人类搜索行为的差异。LiveNewsBench（Zhang et al., 2026, P17）通过动态更新新闻内容，确保问题答案无法从模型预训练数据中获取，真实评估智能体的实时搜索与推理能力。

MERRIN（Wang et al., 2026, P27）针对噪声网络环境中的多模态证据检索与推理，包含文本、图像、视频与音频等异构数据，并引入噪声与冲突信息以模拟真实网络环境。DeepRead（Li et al., 2026, P14）提出一种文档结构感知推理框架，通过“定位-阅读”策略增强智能体搜索在长文档中的表现，解决了传统 RAG 在长上下文中的定位困难问题。VibeSearchBench（2026, P37）则强调用户无法完全预先表达信息需求，要求智能体通过多轮交互与主动探索理解用户意图，推动了搜索智能体从被动响应向主动服务的转变。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域共识认为，LLM 的静态参数化知识存在固有的时效性和幻觉局限，必须依赖外部检索机制来增强事实准确性。这一共识在多个基准上被反复验证：AgenticRAG 在 WixQA 上的 0.96 Factuality 与在 BRIGHT 上的 49.6% Recall@1 均大幅超越单步搜索与静态嵌入基线，表明外部检索对提升事实准确性与检索召回率的关键作用。与此相关的另一个共识是，传统的单轮 RAG 管道无法满足复杂、多跳和动态信息需求，Agentic Search 通过迭代推理和工具调用显著提升了性能。FinanceBench 上 AgenticRAG 的 92.00% Accuracy 与传统 RAG 的 24.24% Accuracy 之间的巨大差距，直观地展示了智能体架构在长文档场景中的优势。

强化学习（特别是 RLVR）是优化搜索智能体策略、提升其在知识密集型任务上表现的关键技术，这一共识在 HotpotQA 与 BrowseComp-Plus 上得到支持。Search-R1 的 50.09 F1 与 Pi-Serini 的 40.1% Accuracy 均表明，经过 RL 优化的智能体在复杂推理任务中具有竞争力。此外，搜索智能体的性能不仅取决于最终答案，还高度依赖于中间查询的质量、证据的覆盖率和推理路径的效率，这一共识在 SmartSearch 与 DecoupleSearch 的工作中得到体现，它们通过引入过程奖励与解耦训练，显著提升了中间步骤的决策质量。

### 3.2 观点分歧

在单体智能体与多智能体协作架构的选择上，存在显著分歧。观点 A 认为单体模型通过 RLVR 即可解决长程任务，架构简洁，效率高；观点 B 认为多智能体通过角色分工和并行处理能更好地解决长程信用分配和模型崩溃问题。现有证据偏向多智能体在长程、复杂任务（如 WideSearch）中的稳定性，M-ASK 在 HotpotQA 上的 50.09 F1 与 InfoSeeker 在 WideSearch 上的 8.38% Success Rate 均表明多智能体架构在复杂任务中的优势。然而，单体模型在简单多跳任务中效率更高，且缺乏大规模、同条件下的直接对比实验，导致分歧未定论。

这一分歧的背后，是过程奖励（PRM）与结果奖励（RLVR）的争论。观点 A 认为可验证的最终答案奖励简单、可靠，足以优化搜索策略；观点 B 认为细粒度的过程奖励能更好地指导中间查询质量，避免盲目搜索。PRM 在查询质量指标上表现更优，但计算成本高且奖励信号可能不精确；RLVR 在最终答案准确率上表现稳定。现有证据偏向混合策略，但缺乏大规模对比实验，且不同任务对中间步骤的依赖程度不同，导致分歧持续存在。

### 3.3 其他开放问题

当前研究面临工程问题与研究问题的双重挑战。最紧迫的工程问题是上下文窗口限制与信息过载，多轮搜索积累的大量检索结果超出 LLM 上下文限制，且包含大量噪声。MemSearcher 与 Expand-then-Squeeze 通过记忆压缩与查询扩展策略缓解这一问题，但尚未形成通用解决方案。最根本的研究问题是长程任务中的信用分配难题，在长轨迹搜索中，难以确定哪些中间步骤对最终成功贡献最大，导致强化学习训练不稳定。当前研究尝试通过过程奖励和分层价值模型来解决，但缺乏理论基础与高效计算机制。

此外，生成式引擎中的可见性与幻觉权衡也是重要开放问题。GEO 策略可能提高引用率但增加幻觉风险，且不同生成引擎偏好不同。AgenticGEO 与 IF-GEO 通过多目标优化和冲突感知指令融合来平衡，但整体性能仍较低，说明该问题尚未解决。未来研究需开发更高效的中间奖励计算机制，探索联合优化生成器和检索器的方法，并构建能够评估智能体区分可信与不可信信息能力的评估框架。

## 4. 总结与展望

智能体搜索与生成式信息检索领域的核心矛盾在于 LLM 静态知识局限与动态信息需求之间的张力。从静态 RAG 到 ReAct 动态智能体，再到强化学习优化与多智能体协作，研究者通过放弃确定性换取适应性，通过放弃简洁性换取鲁棒性。当前核心瓶颈在于长程任务中的信用分配、多模态证据整合以及生成式引擎中的可见性与幻觉权衡，这些问题制约了智能体在开放域长程任务中的高可信度信息获取。

未来可能突破的方向包括：开发更高效的中间奖励计算机制，以解决过程奖励在复杂推理任务中带来的计算复杂性；探索联合优化生成器和检索器的方法，通过为管道中的每个模块设计专门的信号，解决当前仅优化推理智能体而忽略搜索引擎优化的局限性；构建能够评估智能体区分可信与不可信信息能力的评估框架，通过引入来源引用可靠性和信息歧视能力指标，解决当前评估主要关注效率和准确性的不足。对于进入该领域的研究者，最值得做的一件事是在统一骨干与统一预训练条件下，系统对比单体 RL 与多智能体架构在不同复杂度任务上的表现，以厘清架构选择的边界条件。
