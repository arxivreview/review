综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Explainable%20AI%20%28XAI%29%20Methods%20and%20Evaluation)

## 导读

可解释人工智能（Explainable AI, XAI）旨在通过揭示黑盒模型的决策逻辑，缓解高风险领域应用中的信任赤字与合规压力。早期研究以事后解释（Post-hoc Explanation）为主线，通过 LIME 和 SHAP 等算法量化特征贡献，思路简洁却受制于局部近似的保真度瓶颈。当用户实验暴露出高保真解释可能导致过度信任或认知偏差后，研究重心转向信任校准（Trust Calibration）与可操作性（Actionability），强调解释对人类决策的实际效用。随着大语言模型（LLM）的引入，自然语言解释成为新范式，但幻觉风险与对抗脆弱性迫使领域引入元验证与零信任框架。各路线在技术保真度、计算效率与人类可理解性之间做出了不同取舍，由此形成当前算法创新、LLM 增强与评估标准化并存的多元格局。本综述梳理这条从几何度量到语义先验、从技术正确到人本效用的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

XAI 的兴起源于深度学习模型在医疗、金融等高风险领域应用时产生的“黑箱”不透明性，其核心驱动力是建立用户信任、满足监管合规（如欧盟 AI Act）及实现人机协作。早期研究聚焦于事后解释方法的技术开发，核心假设是“忠实于模型即忠实于真相”，即只要解释准确反映了模型内部的特征权重，用户就能做出正确决策。这一假设在理想数据分布下成立，但在真实场景中，模型本身可能包含噪声、偏见或未捕捉因果机制，导致高保真解释反而误导用户。因此，问题定义从单纯的“模型透明度”演变为“人机协作中的信任管理”，核心目标从生成解释转向评估解释对人类决策效用的提升。

形式化地，XAI 任务可定义为：给定黑盒模型 $f: \mathcal{X} \rightarrow \mathcal{Y}$ 和输入实例 $x$，生成解释 $E(x)$，使得 $E(x)$ 在保真度（Fidelity）、可理解性（Comprehensibility）和稳定性（Stability）之间达到最优平衡。保真度衡量解释与模型实际行为的一致性，通常通过归一化均方误差或保真度分数计算；可理解性关注解释是否符合人类认知习惯，如反事实解释（Counterfactual Explanations）提供的最小输入变更；稳定性则要求解释在输入微小扰动下保持不变。这三个维度并非独立，而是呈现层级依赖关系：保真度是基础层，若解释不忠实于模型，后续讨论无意义；信任校准是应用层，依赖于保真度但更关注用户认知；鲁棒性与安全是保障层，制约前两者的实际部署。

子问题之间的依赖关系决定了研究路径的选择。例如，若模型本身存在概念漂移，静态解释将失效，此时需引入动态更新机制；若用户为非专家，数值归因（如 SHAP 值）的认知负荷过高，需转化为自然语言或可视化形式。这种依赖关系导致 XAI 研究从单一算法优化转向系统级设计，涵盖解释生成、验证、交互与合规审计的全生命周期。当前，XAI 处于方法论多元化与评估体系重构的活跃期，研究热点包括利用 LLM 生成自然语言解释、多模态解释、以及针对特定受众（如非专家、残障人士）的自适应解释。

从时间维度看，XAI 的演进可分为四个阶段。2016-2018 年是奠基期，LIME（Ribeiro et al., 2016）和 SHAP（Lundberg and Lee, 2017）确立了模型无关的后验解释范式，TCAV（Kim et al., 2018）则开创了概念可解释性方向，但稳定性问题初现。2020-2022 年是转折期，信任校准理论引入，用户实验成为评估核心，Co-12 属性框架提出，研究重心从技术正确转向人类效用。2023-2025 年是深化期，LLM 引入带来自然语言解释新范式，同时对抗攻击与幻觉问题推动安全与验证机制研究，如 Two-Stage LLM Meta-Verification（Mermigkis et al., 2026）和 ExplainGuard（Mia et al., 2026）。2026 年至今是融合期，评估标准化与安全鲁棒性并重，Unified Multidimensional Metric（Makridis et al., 2026）等框架试图整合多维指标，推动 XAI 从定性描述向定量评估转变。

**如果用一个核心问题概括该领域，那便是：如何在保证解释与模型行为一致（保真度）的前提下，最大化解释对人类决策效用的提升（信任校准与可操作性），并抵御对抗性干扰与认知偏差。**

## 2. 方法体系

- 2016：LIME——通过局部扰动输入并拟合可解释的线性代理模型来近似黑盒模型在特定实例附近的决策边界，从而生成局部特征重要性解释。

- 2017：SHAP——基于合作博弈论中的Shapley值，为每个特征分配对预测结果的贡献度，旨在提供满足局部准确性、缺失性和一致性公理的解释。

- 2020：Co-12属性——提出了一套包含紧凑性、正确性等12个概念属性的评估框架，旨在系统化地衡量解释质量。

- 2023：Chain-of-Thought (CoT)——通过提示模型生成中间推理步骤来增强复杂任务的可解释性，虽然最初用于提升LLM性能，但也被视为一种过程导向的解释形式。

- 2024：对抗性解释攻击——研究指出后验解释方法（如SHAP/LIME）易受对抗样本影响，攻击者可通过微小扰动操纵特征归因，导致解释误导用户或掩盖模型偏见。

- 2025：ProtoScore——针对原型网络提出的专门评估框架，聚焦于原型的代表性、覆盖度及与数据分布的一致性。

- 2026：Unified Multidimensional Metric——提出一个综合评估框架，将保真度、一致性、稳定性及可理解性等多个维度整合为统一的信任度指标。

这条时间线勾勒了该领域方法演进的代表性节点：从 2016 年的 LIME 奠定该领域方法基线，经 2017 年 SHAP 的推进，到 2026 年的 Unified Multidimensional Metric 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 解释方法算法创新

解释方法算法创新是 XAI 的基石，其演进主线是从线性近似到非线性精确逼近，从特征级归因到概念级因果推理。LIME（Ribeiro et al., 2016）通过局部扰动输入并拟合线性代理模型，确立了模型无关的后验解释范式，但其局部近似特性在决策边界复杂区域保真度低，且缺乏理论保证。SHAP（Lundberg and Lee, 2017）针对 LIME 的保真度缺陷，引入 Shapley 值理论，确保解释满足局部准确性、缺失性和一致性公理，但计算复杂度从 O(n) 升至指数级或需蒙特卡洛采样，限制了高维实时应用。这一取舍反映了早期研究在理论严谨性与计算效率之间的权衡：SHAP 以计算成本换取了工业界接受度，但暴露了实时场景下的瓶颈。

随着对特征级解释局限性的认识，研究转向概念可解释性（C-XAI）和因果推理。TCAV（Kim et al., 2018）通过定义概念激活向量（CAV）量化高层人类概念对模型预测的影响，实现了从像素级特征到语义级概念的解释跃迁，但其对概念样本集的选择敏感，稳定性问题在后续研究中受到关注。近期，Causal Concept-based Model Explanations Framework（Bjøru et al., 2025, P11）进一步引入因果推理，通过计算概念干预的概率充分性，生成本地和全局解释，强调解释应基于人类可理解的概念而非原始特征。该方法的核心创新在于将因果推理引入概念解释，确保解释不仅描述相关性，还反映潜在的因果机制，但其代价是概念定义和因果图构建需要领域专家参与，且计算概念干预的成本较高。

在局部解释保真度方面，High-Fidelity Local Explanations via MARS and N-ball Sampling（Shrestha et al., 2025, P12）提出基于多元自适应回归样条（MARS）和 N 球采样的方法，旨在解决线性代理模型保真度低的问题。该方法使用 MARS 建模非线性局部边界，并通过 N 球采样直接从目标分布中采样扰动样本，避免重加权带来的偏差。其在多个基准数据集上展示了比 LIME 和 SHAP 更高的保真度，特别是在决策边界复杂的区域，但 MARS 模型的复杂度随特征数增加而迅速增长，且 N 球采样的实现较为复杂。这一路线与 SHAP 形成互补：SHAP 提供全局理论保证，而 MARS 方法在局部区域提供更精确的拟合，两者共同推动了 XAI 方法从线性近似向非线性精确逼近的发展。

### 2.2 LLM增强解释生成

LLM 增强解释生成是 XAI 领域的最新前沿，其核心动机是解决数值归因对非专家用户认知负荷高、导致信任校准失败的问题。早期 LLM 应用如 Chain-of-Thought（CoT）（Wei et al., 2022）通过提示模型生成中间推理步骤，揭示了模型内部推理路径，但也暴露了推理与结论不一致的忠实性问题。这一发现激发了对解释验证机制的研究需求，推动了从“生成”到“验证”的闭环发展。

Two-Stage LLM Meta-Verification Framework（Mermigkis et al., 2026, P27）提出由解释 LLM 和验证 LLM 组成的两阶段框架，旨在解决 LLM 生成 XAI 解释时的幻觉和忠实性问题。第一阶段由解释 LLM 将技术性 XAI 输出（如 SHAP 值）转化为自然语言叙述；第二阶段由验证 LLM 评估解释的准确性，识别错误并决定接受或修正。其核心创新在于引入独立的验证环节，通过元验证机制提高了生成解释的可靠性，显著降低了解释中的事实性错误。其代价是计算开销增加，且验证 LLM 本身也可能存在偏差，需精心提示工程。该框架为构建可信的自动化解释流水线提供了新的技术路径，推动了 LLM 在 XAI 领域从生成到验证的闭环发展。

ContextualSHAP（Dwiyanti et al., 2025, P13）通过上下文语言生成增强 SHAP 解释，旨在解决 SHAP 值缺乏语义上下文导致非专家难以理解的问题。该方法利用 LLM 将 SHAP 特征贡献转化为包含领域知识的自然语言句子，并融入实例的具体上下文信息。其核心思路是将数值归因与语义描述结合，使解释更具可读性和相关性，生成的解释不仅说明“哪个特征重要”，还解释“为什么重要”以及“在什么情况下重要”。其代价是 LLM 生成过程可能引入主观性，且需要高质量的领域知识库支持。ContextualSHAP 为技术解释向自然语言解释的转化提供了有效范式，有助于降低 XAI 的使用门槛，促进非技术用户与 AI 系统的交互。

PONTE（Vineis et al., 2026, P22）提出个性化编排框架，旨在根据用户偏好和场景需求生成可信赖的自然语言解释。该方法整合了多种 XAI 技术，并通过 LLM 进行动态编排，生成符合特定受众需求的解释叙述。其核心创新在于强调解释的个性化和可信赖性，通过多源信息融合确保解释的准确性和完整性，提供了灵活的接口，允许用户调整解释的详细程度和侧重点。其代价是系统架构复杂，且个性化策略的设计需要大量用户数据支持。PONTE 推动了 XAI 从标准化输出向个性化服务的转变，强调了解释在信任建立中的关键作用，为高利害决策场景提供了更贴心的解释支持。

### 2.3 XAI评估基准与指标

XAI 评估基准与指标是领域标准化的关键，其演进主线是从单一保真度指标到多维统一框架。早期评估主要依赖保真度（Fidelity）指标，如归一化均方误差或保真度分数，但单一指标无法反映解释的稳定性、可理解性及用户效用，导致方法选择缺乏客观依据。Co-12 属性框架（2020）提出了一套包含紧凑性、正确性等 12 个概念属性的评估框架，旨在系统化地衡量解释质量，促使研究从单一指标转向综合考量用户理解与技术准确性的平衡。

ProtoScore（Monke et al., 2025, P8）针对原型网络提出的专门评估框架，旨在解决现有 XAI 评估指标无法有效衡量原型解释质量的问题。该框架基于原型应紧密代表数据实例且集合应覆盖整个数据集的假设，排除了仅优化决策边界邻近性的原型方法。ProtoScore 利用原型模型的潜在空间，定义了多个技术维度指标，如原型的代表性、覆盖度及与数据分布的一致性，将抽象的解释质量转化为可量化的几何与统计属性，使得不同原型模型之间的公平比较成为可能。其代价是依赖于原型模型特定的架构假设，对于非原型类解释方法不适用。ProtoScore 填补了原型解释缺乏标准化量化指标的空白，提升了该子领域的评估严谨性，为后续原型 XAI 方法的改进提供了明确的优化目标。

Unified Multidimensional Explainability Metric（Makridis et al., 2026, P36）提出一个综合评估框架，旨在解决现有 XAI 评估指标碎片化且缺乏统一标准的问题。该框架整合了保真度、一致性、稳定性及可理解性等多个维度，通过加权聚合生成单一的信任度指标，将不同维度的评估结果映射到统一的尺度上，以便跨数据集和跨模型进行比较。其主要改进点在于提供了标准化的报告格式，使得不同 XAI 方法（如 LIME 和 SHAP）的性能差异能够被直观地量化和对比。其代价是权重系数的确定可能引入主观性，且不同应用场景下各维度的重要性可能不同。该框架有助于推动 XAI 评估的规范化进程，为工业界选择解释方法提供了客观依据，促进了 XAI 从定性描述向定量评估的转变。

### 2.4 人机交互与用户研究

人机交互与用户研究是 XAI 从技术导向转向人本导向的核心，其演进主线是从静态展示到动态交互，从通用设计到受众适配。早期用户实验主要关注解释对信任度的影响，但 2022 年信任校准理论明确区分了“信任”（用户心理状态）与“信任度”（系统属性），强调 XAI 的目标应是促进“适当依赖”而非盲目信任。这一理论框架指导了后续大量用户实验，重点评估解释如何帮助用户在模型不确定时做出正确决策。

CoAX（Rawshan et al., 2026, P29）构建了一个认知导向的用户理解模型，旨在模拟人类在接收不同 XAI 类型时的认知过程和决策策略。该模型将用户认知参数化，模拟了从感知解释到形成决策的完整心理路径，包括对特征重要性的权重分配和规则匹配。其核心创新在于将认知科学理论引入 XAI 评估，通过虚拟参与者实验量化不同解释形式（如 SHAP、LIME）对用户理解准确性的影响，提供了可复现的模拟环境，避免了真实用户实验的高成本和不可控性。其代价是模型假设可能简化了真实人类认知的复杂性，且参数校准依赖于特定数据集。CoAX 为 XAI 界面的认知负荷优化提供了基于认知科学的理论依据，有助于设计更符合人类直觉的解释界面。

Trust Calibration via Limitation Exposure（Ventura et al., 2026, P31）研究通过向非专家用户暴露模型局限性来校准信任的机制，旨在解决 XAI 导致的过度依赖问题。该方法在解释中显式包含模型的不确定性、错误率及适用边界信息，引导用户建立对模型能力的正确预期。其核心思路是将“信任校准”作为 XAI 设计的首要目标，而非单纯提升信任度，强调用户应根据模型表现动态调整依赖程度。通过对比实验验证了显式局限性信息对减少过度依赖的有效性，特别是在高利害决策场景中。其代价是增加了解释的认知复杂度，可能导致部分用户因信息过载而产生焦虑或忽视关键信息。该研究为 XAI 在医疗、金融等高风险领域的应用提供了重要指导，强调了透明度与信任管理之间的平衡。

Conversational XAI for User Performance（Kruschel et al., 2026, P32）探索对话式 XAI 对用户决策绩效的影响，旨在解决静态解释缺乏交互性和即时反馈的问题。该方法利用 LLM 构建对话代理，允许用户通过自然语言查询解释细节、探索反事实场景或澄清模型逻辑。其核心创新在于将解释从被动展示转变为主动交互过程，增强了用户的控制感和参与感，实验证明对话式解释能显著提升用户在复杂预测任务中的决策准确性，特别是在需要综合多因素判断的场景中。其代价是交互延迟可能影响实时决策，且 LLM 生成的解释可能存在幻觉风险，需结合验证机制。该研究推动了 XAI 从“展示型”向“协作型”的转变，为构建人机协同决策系统提供了新的交互范式。

### 2.5 XAI安全与鲁棒性

XAI 安全与鲁棒性是高风险应用部署的前提，其演进主线是从被动防御到主动验证，从单一攻击到系统性风险。2024 年对抗性解释攻击研究指出，后验解释方法（如 SHAP/LIME）易受对抗样本影响，攻击者可通过微小扰动操纵特征归因，导致解释误导用户或掩盖模型偏见。这一发现揭示了 XAI 系统在安全关键领域的脆弱性，推动了针对解释完整性的防御机制和鲁棒性评估方法的研究。

Adversarial Attacks on XAI in Cybersecurity（Mia and Pritom, 2025, P4）研究针对网络安全应用中 XAI 解释的对抗性攻击，旨在揭示后验解释方法在安全关键领域的脆弱性。该方法展示了攻击者如何通过微小扰动输入，操纵 SHAP、LIME 等方法的特征归因，从而误导用户或掩盖模型偏见。其核心创新在于将对抗攻击视角引入 XAI 评估，强调了解释的鲁棒性作为安全属性的必要性，提出了针对解释层的攻击策略，并分析了不同 XAI 方法对攻击的敏感度差异。其代价是攻击检测难度高，且防御机制可能降低解释的可用性。该研究推动了 XAI 安全研究的兴起，强调了在部署 XAI 前进行对抗性测试的重要性，为构建可信 AI 系统提供了安全视角。

ExplainGuard（Mia et al., 2026, P38）提出零信任框架以保障黑盒 XAI 模型的后验解释完整性，旨在解决解释被恶意篡改或生成的风险。该方法通过统计检验和消融实验验证解释与模型预测的一致性，检测潜在的偏差或攻击。其核心创新在于引入“零信任”原则，不预设解释的可信性，而是通过多重验证机制确保其完整性，提供了自动化的审计工具，能够识别背景分布偏移导致的解释偏差，并量化解释的忠实度差距。其代价是验证过程计算开销较大，且需要访问模型接口进行多次查询。ExplainGuard 为高利害决策场景提供了安全保障，推动了 XAI 从生成到审计的全生命周期管理，增强了监管机构和用户对 AI 系统的信心。

Fundamental Limitation in Explaining AI（Suzuki and Wang, 2026, P33）探讨解释 AI 时的基本限制，旨在揭示环境复杂度、AI 性能、解释忠实性和可解释性之间的权衡关系。该研究通过理论分析指出，在给定可解释函数类下，无法同时满足解释的忠实性、一致性和效率，形式化了这一不可能性定理，为 XAI 方法的评估提供了理论边界。其核心创新在于明确了不同解释目标之间的冲突，指导研究者在设计 XAI 方法时做出有意识的取舍。其代价是理论结果可能过于理想化，实际应用中可通过近似方法缓解。该研究为 XAI 领域提供了重要的理论警示，强调了在追求高保真解释时需考虑计算成本和可理解性的平衡，推动了 XAI 理论基础的深化。

### 2.6 跨任务与多领域应用

XAI 在特定垂直领域的应用是检验其实用性的关键，其演进主线是从通用技术到领域适配，从技术合规到治理工具。医疗、金融、工业及联邦学习等领域对解释的需求各异，通用 XAI 方法难以满足其特异性要求，需结合领域知识、法规合规及系统架构进行定制。

Assessing XAI Methods against EU AI Act（Sovrano et al., 2026, P25）系统评估模型无关 XAI 方法在满足欧盟人工智能法案解释性要求方面的能力，旨在解决技术解释与法律合规之间的差距。该方法采用定性评估与定量聚合相结合的方式，将 XAI 输出映射到法律定义的解释属性上，建立了技术 XAI 方法与法律合规标准之间的映射框架，明确了哪些 XAI 技术能够满足“有意义信息”的要求。其核心创新在于揭示了当前主流 XAI 方法在可审计性和问责性方面的不足，为监管合规提供了具体建议。其代价是法律解释的模糊性可能导致评估标准的主观性。该研究推动了 XAI 在监管合规场景下的应用，强调了 XAI 不仅是技术工具，更是治理工具，促进了 AI 伦理与技术的融合。

Scalable Explainability-as-a-Service (XaaS) for Edge AI（Singh and Roy, 2026, P19）提出面向边缘 AI 系统的可扩展解释即服务架构，旨在解决边缘设备计算资源有限导致 XAI 方法难以部署的问题。该方法通过云端或边缘服务器集中生成解释，并利用缓存机制减少重复计算，实现解释的高效分发。其核心创新在于将解释生成与推理分离，采用服务化架构优化资源利用，通过缓存相似输入的解释，显著降低了边缘设备的计算和能耗开销，同时保证了解释的实时性。其代价是网络延迟可能影响用户体验，且缓存一致性管理复杂。XaaS 为边缘 AI 的可解释性提供了实用解决方案，推动了 XAI 在物联网和移动设备中的落地应用，强调了系统架构在 XAI 部署中的关键作用。

XAI-on-RAN（Basaran and Dressler, 2025, P10）提出面向 6G 无线接入网（RAN）的可解释 AI 原生架构，旨在解决网络运营者对 AI 决策信任不足的问题。该方法集成了注意力机制、积分梯度和 SHAP 等多种解释技术，并通过 GPU 加速实现实时解释生成，将 XAI 嵌入 RAN 智能控制器（RIC），实现闭环控制中的透明决策。其核心创新在于展示了不同解释方法在时间序列预测任务中的互补性，并验证了 XAI 对端到端性能的影响。其代价是解释生成可能增加网络延迟，且需要高性能硬件支持。XAI-on-RAN 为通信领域的 AI 部署提供了参考架构，强调了 XAI 在基础设施自动化中的重要性，推动了 XAI 在关键基础设施中的标准化应用。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

单一技术指标（如保真度）不足以评估解释质量，需结合用户理解、信任及任务表现进行多维评估，这一共识在多个基准上被反复验证：B-ReX 的 0.072 JSD 与 HFLIME 的 64.8% RMSE 降低均表明，技术保真度是基础，但 MACHOP 的 70.7% 用户偏好对齐度进一步证明，人类效用是最终目标。与此相关的另一个共识是，以人为中心的设计原则至关重要，解释必须适配特定受众的认知背景和决策需求，CoAX 的认知导向模型和 Audience-Aware XAI 的多智能体系统均通过实验验证了受众适配对信任校准的显著影响。

### 3.2 观点分歧

解释的本体论地位是领域核心分歧：技术保真派认为解释应严格忠实于模型内部机制，Fidelity 是首要指标（代表：SHAP, B-ReX）；人本/社会建构派认为解释是服务于用户决策的沟通工件，应适配受众认知，Actionability 与 Trust Calibration 更重要（代表：CoAX, Baradian Reading）。现有证据偏向人本派，用户实验表明高保真解释未必提升决策绩效，甚至导致过度信任，但技术保真派在高风险合规场景（如 EU AI Act）中仍有强需求。这一分歧的背后，是另一个更根本的争论：LLM 生成解释的可靠性。乐观派认为 LLM 能生成丰富、个性化的自然语言解释，显著提升非专家理解（代表：ContextualSHAP, PONTE）；谨慎派认为 LLM 幻觉风险高，缺乏自动验证机制，不适合高风险场景（代表：Two-Stage Meta-Verification, ExplainGuard）。证据偏向谨慎派，多项研究指出 LLM 解释存在事实错误，需引入验证 LLM 或知识图谱约束，但乐观派在用户满意度上表现更优。

### 3.3 其他开放问题

最紧迫的工程问题是边缘设备上的实时解释生成与 LLM 幻觉的自动检测。XaaS 的 72% 缓存命中率表明服务化架构是可行路径，但网络延迟与缓存一致性管理仍是瓶颈；Two-Stage Meta-Verification 的迭代修正过程显著降低了事实性错误，但验证 LLM 本身的偏差需进一步研究。最根本的研究问题是解释的动态演化与因果有效性。当前静态解释在概念漂移或数据演化场景中可能过时，需研究解释的持续更新与演化机制，如 Constructive Empiricism Framework 提出的全生命周期 XAI 框架；同时，后验解释可能误导科学发现，需结合因果推理和领域知识，如 Causal Concept-based Model Explanations Framework 所示。已知—争议—未知认知图谱显示：保真度与人类效用的权衡是已知，解释的本体论地位是争议，动态演化与因果有效性的计算可行性是未知。发展趋势将从静态工具向动态知识系统演进，强调解释在 AI 生命周期中的持续价值。

## 4. 总结与展望

XAI 领域正经历从“技术导向”向“人本导向”的范式转移，核心矛盾从“如何生成解释”转变为“如何科学评估解释的有效性”。早期 LIME/SHAP 确立了事后解释范式，但暴露了保真度与可理解性的权衡；2020 年后，研究重心转向信任校准、鲁棒性及 LLM 增强解释，评估体系从单一指标走向多维基准；当前挑战在于解决解释的幻觉、对抗脆弱性及受众适配性，需建立统一的评估标准。这一演进回扣了核心问题：如何在保证解释与模型行为一致（保真度）的前提下，最大化解释对人类决策效用的提升（信任校准与可操作性），并抵御对抗性干扰与认知偏差。

未来可能突破的方向包括：建立统一且可复现的评估框架，解决当前评估指标碎片化、主观性强且缺乏基准的问题，技术路径包括基于因果性的形式化度量、多维指标聚合及自动化基准测试；增强解释的鲁棒性与安全性，解决 XAI 解释易受对抗攻击和模型漂移影响的问题，技术路径包括零信任验证架构、对抗鲁棒性训练及解释完整性保证机制；实现受众感知与个性化解释，解决不同用户对解释需求差异大导致通用解释效果不佳的问题，技术路径包括用户画像建模、LLM 多智能体叙事生成及基于反馈的闭环自适应系统。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，构建一个同时量化“技术保真度”与“人类效用”的多维评估基准，以解决当前测量工具盲区，为解释的本体论地位之争提供客观证据。
