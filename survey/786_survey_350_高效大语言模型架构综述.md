## 导读

高效大语言模型（Efficient LLM）架构研究旨在突破 Transformer 自注意力机制的二次方计算复杂度与内存瓶颈，其核心驱动力源于模型规模扩张与硬件物理极限之间的张力。早期工作聚焦于算法层面的稀疏化或线性化近似，试图在数学上降低复杂度，但往往以牺牲长程依赖精度为代价。随着 FlashAttention 确立内存感知计算范式，研究重心转向系统级优化，在不改变算法逻辑的前提下挖掘硬件潜力。当 Mamba 等状态空间模型（SSM）出现后，领域进入架构重构阶段，通过混合 Transformer 与 SSM 或线性注意力层，在保留精确检索能力的同时实现线性复杂度推理。当前前沿正迈向动态自适应与自动化设计，通过令牌级路由与 LLM 驱动的神经架构搜索（NAS）寻找效率与精度的帕累托最优。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

高效 LLM 架构领域的兴起，根植于 Transformer 架构中自注意力机制（Self-Attention）固有的二次方计算复杂度与内存开销。随着模型参数规模向千亿级扩展，上下文窗口向百万级 Token 迈进，Softmax 注意力在计算 Query-Key 相似度时的 $O(N^2)$ 复杂度，以及键值缓存（KV Cache）随序列长度线性增长的内存占用，成为制约模型部署的核心物理瓶颈。这一矛盾并非单纯的技术瑕疵，而是算法范式与硬件特性之间的结构性冲突：GPU 的内存带宽限制使得长序列下的数据移动成本远超计算成本，导致理论上的并行优势在实际推理中难以兑现。因此，该领域的根本任务被定义为：在保持长程依赖捕捉能力与模型表达精度的前提下，通过架构重构与系统协同优化，实现 LLM 训练与推理计算复杂度从二次方向线性乃至亚线性的跨越。

问题定义在演化过程中经历了从“算法加速”到“系统-架构协同设计”的深刻转变。早期研究将问题形式化为在固定硬件上最小化 FLOPs，假设数据分布理想且硬件利用率恒定。然而，随着长上下文基准（如 RULER, LongMemEval）的引入，问题边界扩展至真实噪声与硬件约束下的端到端延迟与内存占用。此时，子问题间的依赖关系变得清晰：注意力机制的效率优化（子问题 A）是基础，但受限于硬件利用率（子问题 B）和训练稳定性（子问题 C）。若不解决硬件内核优化（如 FlashAttention），算法层面的线性化难以落地；若不解决混合架构的训练稳定性，SSM 与 Attention 的结合无法发挥优势。架构搜索（子问题 D）则依赖于前三个子问题提供的组件库与评估基准，形成层层递进的依赖链条。

范式边界在 2020 至 2022 年间初步确立。Longformer 引入局部滑动窗口与全局令牌相结合的稀疏注意力模式，将注意力复杂度从二次方降低至线性，解决了长序列建模中的内存爆炸问题，是稀疏注意力领域的里程碑（Beltagy et al., 2020）。同期，Linear Transformer 通过特征映射替换 softmax 操作，将注意力机制转化为线性复杂度，实现了常数大小的递归状态推理，开创了线性注意力研究的新方向（Katharopoulos et al., 2020）。这些早期尝试虽然降低了理论复杂度，但在需要精确长程依赖检索的任务上表现不佳，暴露了线性近似与表达能力之间的权衡难题。

2023 年成为领域发展的关键转折点。FlashAttention 通过 IO 感知的分块计算策略优化注意力内核，在不改变数学等价性的前提下大幅提升 GPU 内存带宽利用率，成为现代 LLM 推理加速的标准组件（Dao et al., 2022）。这一系统级优化确立了“内存感知计算”范式，证明在不改变算法逻辑的前提下，通过挖掘硬件潜力可获得显著加速。同年，PagedAttention 借鉴操作系统虚拟内存概念，将 KV 缓存划分为固定大小的页面进行管理，有效解决了变长序列下的内存碎片问题，提升了推理吞吐量（Kwon et al., 2023）。这些工作标志着研究重心从单纯的算法加速转向架构层面的重构。

2024 年，Mamba 的提出引发了架构范式的竞争。Mamba 基于选择性状态空间模型（SSM），通过硬件友好的扫描算法实现线性复杂度推理，为替代 Transformer 提供了强有力的竞争方案（Gu and Dao, 2023）。然而，SSM 在需要精确长程依赖检索的任务上表现不如 Softmax 注意力，促使研究者转向混合架构（Hybrid Architectures）。Nemotron 3 Ultra 等模型结合状态空间模型的高效性与注意力的精确性，实现了推理吞吐量与精度的前沿突破（NVIDIA et al., 2026）。这一阶段，研究焦点从单一架构的优化转向混合架构中不同模块的最优组合比例及位置安排。

2025 至 2026 年，研究重心进一步转向动态自适应与自动化设计。STILL 提出层内混合注意力框架，通过自显著性分数动态选择令牌进入 Softmax 或线性注意力分支，实现预训练 LLM 的无损线性化（Meng et al., 2026）。ProxyAttn 利用部分头作为代理来指导其他头的稀疏模式选择，避免了每个头独立计算稀疏模式的冗余开销（Wang et al., 2025）。与此同时，LLM 驱动的神经架构搜索（NAS）兴起，利用大语言模型作为代码生成器，通过迭代微调与质量多样性搜索，自动化发现高效神经架构，突破了传统 NAS 搜索空间的限制（Khalid et al., 2026）。当前领域处于高活跃度阶段，焦点集中在如何在保持模型能力（尤其是长上下文推理）的前提下，实现训练与推理的双重效率提升，并探索从离散 Token 预测向连续向量预测等范式转变的可能性。

**如果用一个核心问题概括该领域，那便是：如何在有限硬件资源下重构模型拓扑，以平衡长程依赖捕捉能力与计算成本，实现训练与推理的双重效率提升。**

## 2. 方法体系

- 2017：Transformer——提出基于多头自注意力机制的序列建模架构，确立了现代LLM的基础范式

- 2019：Multi-Query Attention——通过让多个查询头共享同一组键值头，显著降低了KV缓存的内存占用

- 2020：Longformer——引入局部滑动窗口与全局令牌相结合的稀疏注意力模式，将注意力复杂度降低至线性

- 2023：FlashAttention——通过IO感知的分块计算策略优化注意力内核，大幅提升GPU内存带宽利用率

- 2024：Mamba——提出基于选择性状态空间模型的高效序列建模架构，实现线性复杂度推理

- 2025：DeltaNet——引入增量更新规则改进线性注意力，成为混合架构中线性分支的核心组件

- 2026：STILL——提出层内混合注意力框架，通过自显著性分数动态选择令牌进入softmax或线性分支

- 2026：LLM-driven NAS——利用大语言模型作为代码生成器，自动化发现高效神经架构

这条时间线勾勒了该领域方法演进的代表性节点：从 2017 年的 Transformer 奠定该领域方法基线，经 2019 年 Multi-Query Attention 的推进，到 2026 年的 STILL 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 高效注意力机制

高效注意力机制的研究始于对 Softmax 注意力二次方复杂度的直接挑战。早期工作如 Longformer 和 Linear Transformer 分别通过稀疏化和线性化近似降低复杂度，但往往以牺牲长程依赖精度为代价。FlashAttention 的出现改变了这一局面，它通过 IO 感知的分块计算策略，在不改变算法逻辑的前提下优化了硬件利用率，确立了系统级优化的基准。此后，研究重心转向更精细的稀疏模式选择与动态路由。ProxyAttn（Wang et al., 2025, P5）针对多头注意力中每个头独立计算稀疏模式的冗余问题，提出利用代表性头引导其他头的稀疏选择，在 Llama 和 Qwen 模型上展示了优异的稀疏率与精度平衡。其核心取舍在于假设头间存在相关性，若某些头具有独特的注意力模式，代理机制可能失效。相比之下，NLL-Guided SWAA（Tang et al., 2026, P32）采用数据驱动的层选择策略，通过教师强制 NLL 评分每层对滑动窗口注意力的敏感度，选择退化最严重的层保留全注意力，其余层使用滑动窗口。这种方法放弃了启发式规则的通用性，换取了下游精度的最大化，但需要在推理前进行额外的 NLL 计算。

在低秩近似与动态对齐方面，AQUA（G S et al., 2025, P1）利用查询向量幅度进行在线 PCA 校准，动态对齐键值缓存坐标轴，实现了内存与计算双高效的注意力近似。该方法解决了固定秩压缩的局限性，但依赖离线校准的分布假设，若推理时数据分布发生剧烈偏移，校准效果可能下降。STILL（Meng et al., 2026, P19）则提出层内混合注意力框架，通过自显著性分数动态选择令牌进入 Softmax 或线性注意力分支，实现预训练 LLM 的无损线性化。其核心创新在于令牌级的动态路由机制，使得模型能够根据依赖类型自适应选择计算路径，技术代价是引入了额外的分数计算与路由逻辑。STILL 与 ProxyAttn 代表了动态路由的两种路径：前者在层内混合不同复杂度的注意力分支，后者在头间协同稀疏化，两者均旨在平衡效率与精度，但 STILL 更侧重于预训练模型的即插即用优化。

### 2.2 新型骨干架构

新型骨干架构的探索旨在突破 Transformer 的单一范式，通过引入状态空间模型（SSM）、循环网络或混合结构提升参数效率与长上下文建模能力。Mamba 的提出标志着 SSM 成为 Transformer 的有力竞争者，其基于选择性状态空间模型，通过硬件友好的扫描算法实现线性复杂度推理，无需 KV Cache。然而，SSM 在需要精确长程依赖检索的任务上表现不如 Softmax 注意力，促使研究者转向混合架构。Nemotron 3 Ultra（NVIDIA et al., 2026, P31）构建了混合 Mamba-Transformer MoE 架构，结合状态空间模型的高效性与注意力的精确性，实现了推理吞吐量与精度的前沿突破。其核心取舍在于训练复杂度的增加，以换取性能-效率的平衡。

在参数效率优化方面，Hyperloop Transformers（Zeitoun et al., 2026, P24）引入循环 Transformer 块与超连接残差流，通过深度复用中间块提升参数效率。该方法将 Transformer 组织为开始、中间、结束三个块，仅中间块进行递归应用，在固定计算预算下提升了模型表达能力。其技术代价是循环结构可能增加推理延迟，且超连接引入了额外的参数与计算开销。Looped SSMs（Yu et al., 2026, P34）则提出具有自适应退出状态选择的循环状态空间语言模型，通过递归应用 Mamba 骨干提升参数效率。该方法将 N 层 Mamba 骨干递归 R 次，有效深度为 NR，但参数仅随 N 增长，实现了参数与计算量的解耦。其核心创新在于自适应退出机制，根据输入动态选择递归步数，平衡了效率与精度，但递归过程可能引入误差累积。

### 2.3 参数与稀疏优化

参数与稀疏优化聚焦于通过减少参数量和激活内存需求，实现模型轻量化与高效部署。Sparser, Faster, Lighter（Cetin et al., 2026, P21）提出 TwELL 稀疏格式与专用 CUDA 内核，利用 L1 正则化诱导 FFN 层 99% 以上的非结构化稀疏性。该方法的核心创新在于稀疏格式与硬件内核的协同设计，解决了非结构化稀疏在 GPU 上效率低下的问题。其技术代价是稀疏化可能影响模型泛化能力，需要精细的正则化强度调节。相比之下，Mixture-of-Channels（Wu et al., 2025, P11）提出利用稀疏 FFN 进行高效预训练与推理的架构，通过通道混合实现参数效率提升。该方法将 FFN 层重构为稀疏混合结构，仅激活部分通道进行计算，降低了内存占用与计算成本，但稀疏化可能降低 FFN 的容量，需要增加通道数以补偿。

在低秩分解与持续学习方面，CR-Net（Kong et al., 2025, P2）提出跨层低秩结构参数高效训练方法，利用跨层激活差异的低秩特性进行架构设计。该方法将全形状权重替换为低秩矩阵，并通过可学习缩放因子动态平衡历史激活与增量信息，减少了参数量与计算量。SCALE（P38）则提出宽度扩展持续学习架构，通过冻结预训练权重并插入轻量级扩展模块实现容量扩展。该方法遵循持久保持与协作适应原则，仅训练扩展组件以获取新知识，避免了对基础模型的干扰，为 LLM 的持续扩展提供了新的架构方案。

### 2.4 训练推理系统

训练推理系统优化针对 LLM 全生命周期，解决计算瓶颈以提升 MFU 与端到端效率。Reversible LLMs（Gal et al., 2025, P14）提出基于对称微分方程的可逆架构，通过时间可逆动力学在反向传播中重构隐藏状态，消除了激活存储需求，大幅降低训练内存消耗。其核心创新在于可逆动力学的设计，确保了前向与反向过程的精确对应，但可逆层的设计限制了架构的灵活性。Core Attention Disaggregation（Zhuang et al., 2025, P8）提出核心注意力解耦策略，通过动态负载均衡优化长上下文训练。该方法将核心注意力计算与上下文无关层分离，通过重新分配文档至微批次以平衡计算量，消除了分布式训练中的长尾效应，提升了长上下文训练的 MFU。

在推理加速与硬件适配方面，Litespark（Dade and Rahat, 2025, P7）提出高吞吐量、低能耗的 LLM 训练框架，通过优化注意力与 MLP 层提升 MFU。该方法结合了架构改进与算法增强，实现了模型 FLOPs 利用率的最大化，但框架实现复杂度高，且需要针对特定硬件进行调优。Mugi（Price et al., 2026, P17）提出值级并行（VLP）架构用于高效 LLM 推理，通过时间编码实现低精度 GEMM 加速。该方法将数值计算转化为时间序列脉冲，利用 VLP 架构并行处理，支持 LLM 中的非线性操作，为边缘设备推理提供了新的硬件方案。

### 2.5 架构搜索与综述

架构搜索与综述领域正从基于图结构的手工搜索空间转向基于代码生成的 LLM 驱动搜索。From Memorization to Creativity（Khalid et al., 2026, P16）提出 LLM 作为新型神经架构设计器的框架，通过迭代微调提升架构生成能力。该方法将 LLM 视为随机生成器，通过质量多样性搜索与新颖性过滤，引导 LLM 生成高效架构，突破了传统 NAS 的搜索空间限制。其技术代价是迭代过程需要大量计算资源，且生成架构的可靠性需验证。Delta-Based NAS（Adhikari et al., 2026, P26）提出基于代码差异的 LLM 微调方法用于神经架构搜索，利用 LLM 生成代码差异，通过迭代应用差异优化架构，减少了全代码生成的开销。

在理论分析与基准测试方面，Convergence Theory for Iterative LLM-NAS（Adhikari et al., 2026, P29）提出迭代 LLM 架构搜索的收敛理论，建立参数化交叉熵框架。该方法通过理论分析证明了迭代微调的收敛性，并提供了闭式代理可靠性公式，为 LLM-NAS 提供了理论指导。LayerTracer（Wu et al., 2026, P23）提出任务粒子与脆弱层联合分析框架，适用于任意 LLM 架构。该方法通过逐层提取隐藏状态并映射至词汇概率分布，定位任务执行层与网络瓶颈，为混合架构设计提供了实证依据，推动了 LLM 可解释性研究。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

混合架构（Transformer + SSM/Linear Attention）比单一架构更能平衡效率与性能，是当前工业界和学术界的主流趋势。这一共识在多个基准上被反复验证：Nemotron 3 Ultra 在推理吞吐量与精度上均实现前沿突破，STILL 在预训练 LLM 的无损线性化中展示了优异的精度-效率平衡。证据显示，纯 SSM 或纯线性注意力在长程精确检索任务上表现不佳，而混合架构通过动态路由或模块组合弥补了这一短板。与此相关的另一个共识是 KV Cache 的管理（包括压缩、分页、驱逐）是提升推理吞吐量和降低内存占用的关键系统级优化手段。PagedAttention 和 FlashAttention 的成功证明，系统级优化在不改变算法逻辑的前提下可显著提升硬件利用率，成为现代 LLM 部署的标配。

### 3.2 观点分歧

线性/SSM 架构能否完全替代 Softmax 注意力？观点 A 认为 SSM/线性注意力是更优范式，具备线性复杂度且无需 KV Cache（代表：Mamba, DeltaNet）；观点 B 认为 Softmax 注意力在长程精确检索上不可替代，需混合架构（代表：Nemotron, STILL）。现有证据偏向观点 B。在 LongMemEval 等长上下文精确检索基准上，Full Attention 或混合架构（如 NLL-Guided SWAA）性能显著优于纯 SSM/线性模型。证据强度中等，需在更多真实世界长程依赖任务上验证。这一分歧的背后，是另一个更根本的争论：非结构化稀疏化的实际加速比是否可行？观点 A 认为非结构化稀疏（如 TwELL）可通过专用内核实现显著加速；观点 B 认为硬件对非结构化稀疏支持有限，实际加速比远低于理论值，结构化稀疏更实用。现有证据偏向观点 A 在特定内核下可行，但观点 B 在通用硬件上更稳健。TwELL 在专用 CUDA 内核下展示了显著加速，但跨硬件泛化性未充分验证。

### 3.3 其他开放问题

最紧迫的工程问题是非结构化稀疏的 GPU 内核优化与百万级 Token 的 KV Cache 动态管理。现状是理论稀疏度可达 99%+，但现有 GPU 硬件对非结构化稀疏计算的支持有限，导致实际加速比远低于理论值。关键困难在于稀疏格式与硬件执行流水线的协同设计，研究路径包括专用稀疏 GEMM 内核开发与动态 KV Cache 驱逐策略优化。最根本的研究问题是混合架构训练稳定性的优化理论与 LLM-NAS 生成架构的可扩展性证明。现状是混合架构训练过程易出现不稳定或收敛困难，缺乏通用的优化理论和超参数配置指南；LLM-NAS 生成架构在小规模有效，但大规模预训练中的可扩展性与泛化性未经验证。关键困难在于搜索空间巨大且评估成本高，研究路径包括基于代码差异的增量生成与收敛理论分析。已知—争议—未知认知图谱显示：已知混合架构优于单一架构，争议在于 SSM 能否完全替代 Attention 及稀疏化的硬件利用率，未知在于 LLM-NAS 的大规模泛化性与动态路由的理论基础。发展趋势是混合架构与 LLM-NAS 将主导下一阶段发展，硬件感知设计成为标配。

## 4. 总结与展望

高效 LLM 架构领域正处于从“算法近似”向“系统-架构协同设计”转型的关键期。核心矛盾在于效率与精度的非线性权衡，早期工作通过稀疏化或线性化降低理论复杂度，但往往以牺牲长程依赖精度为代价；随后 FlashAttention 确立系统级优化基准，Mamba 引发架构范式竞争，当前前沿正迈向动态自适应与自动化设计。核心瓶颈在于如何在保持长程依赖捕捉能力与模型表达精度的前提下，通过架构重构与系统协同优化，实现 LLM 训练与推理计算复杂度从二次方向线性乃至亚线性的跨越。

未来可能突破的方向包括：混合架构（Transformer+SSM/Linear Attention）的自动化搜索与设计，通过 LLM 驱动的神经架构搜索（如 Composer, AIRA-Compose, Delta-Based NAS）解决最优组合比例及位置安排问题；小模型（SLM）的延迟-精度帕累托前沿探索，在严格的数据和计算约束下寻找最优的深度-宽度比及高效算子组合（如 Nemotron-Flash, Wiola）。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，系统评测混合架构与动态路由方法在长上下文精确检索任务上的精度-效率权衡，填补当前评测体系中缺乏公平比较的空白。
