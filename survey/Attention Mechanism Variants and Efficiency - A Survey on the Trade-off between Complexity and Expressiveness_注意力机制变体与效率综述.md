## 导读

Transformer 架构中自注意力机制固有的二次方计算复杂度，构成了大语言模型处理长上下文与高分辨率图像的核心瓶颈，迫使研究界在效率与表达力之间寻找平衡。早期研究通过固定稀疏模式确立了结构化稀疏的可行性，但训练与推理阶段的不匹配限制了其泛化能力。随着硬件感知算法如 FlashAttention 的兴起，系统级优化在不改变数学形式的前提下大幅提升了实际吞吐，确立了工程优化的基准。随后，以 Mamba 为代表的线性注意力及状态空间模型范式崛起，通过移除 Softmax 归一化挑战了全注意力的主导地位，推动了从近似计算向架构重构的范式转变。当前领域处于高度活跃期，研究热点集中在动态稀疏路由、线性注意力的表达力恢复以及混合架构的理论边界探索。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

注意力机制效率问题的根源在于自注意力机制（Self-Attention）的数学结构与其硬件实现之间的张力。标准自注意力通过计算 Query 和 Key 的点积加权 Value，其计算复杂度随序列长度 $N$ 呈二次方增长，即 $O(N^2)$。这一特性在短序列任务中尚可接受，但在处理长上下文、高分辨率图像或实时应用时，导致延迟和内存成本不可接受。问题的核心并非单纯的算力不足，而是 Softmax 归一化的全局依赖性使得计算密集，且键值缓存（KV Cache）的大小随序列长度线性增长，成为长上下文推理的主要内存瓶颈。因此，领域的核心任务被定义为：在保持模型捕捉复杂长程依赖能力（表达力）的前提下，将注意力机制的计算与内存复杂度从二次方降低至线性或亚二次方，并实现训练与推理阶段的一致性。

问题定义的演化反映了研究重心从“如何加速”向“如何平衡”的转移。早期研究假设全连接注意力是必要的，受限于 GPU 显存，主要探索通过限制 Token 间交互范围来降低计算量。然而，固定稀疏模式往往导致训练时学习的全局依赖在推理时被破坏，引发误差累积。这一失败促使研究者重新审视问题边界：效率优化不能以牺牲表达力为代价，且必须解决训练-推理不匹配问题。随后，硬件感知算法的出现揭示了内存带宽（Memory Wall）而非算法逻辑才是实际延迟的主因，进一步细化了问题结构：系统级优化与算法级优化需协同进行。当前，问题已演化为在理论层面量化效率与表达力的权衡，并在架构层面设计混合机制以逼近全注意力的性能。

子问题之间存在明确的依赖关系。首先需解决“计算复杂度”问题，通过稀疏化或线性化降低理论复杂度；其次需解决“表达力损失”问题，通过混合架构或理论补偿恢复模型能力；最后需解决“系统落地”问题，通过硬件感知内核和 KV 缓存优化实现实际加速。若不解决表达力损失，线性或稀疏架构无法替代全注意力；若不解决硬件瓶颈，理论上的线性复杂度无法转化为实际加速。这种依赖关系决定了研究路线的演进逻辑：从单纯的算法近似，转向架构重构与系统优化的深度融合。

范式边界是理解该领域当前形态的关键。现有方法大致可分为“近似计算”与“架构重构”两类。近似计算保持 Softmax 注意力的数学形式，通过稀疏掩码或硬件优化降低实际开销，如 FlashAttention 和动态稀疏注意力。架构重构则移除 Softmax 非线性，采用线性递归状态更新或核方法，如 Mamba 和线性注意力。这两类范式在效率与表达力的取舍上存在本质差异：前者保留全局依赖但受限于内存带宽，后者实现线性复杂度但面临表达力下降的风险。当前研究正试图模糊这一边界，通过混合架构结合两者的优势。

从时间维度看，领域发展经历了三个关键转折。2016-2018 年，Transformer 确立基础范式，Longformer 和 BigBird 引入固定稀疏模式，解决了长序列内存瓶颈，但面临灵活性限制。2020-2023 年，FlashAttention 等硬件感知算法兴起，证明系统级优化对效率的巨大贡献，确立了工程优化的基准。2024-2026 年，Mamba 等状态空间模型崛起，挑战 Softmax 注意力的主导地位，研究重心转向效率与表达力的理论平衡及混合架构设计。这一演进史表明，领域正从单纯的加速转向对注意力机制数学本质与硬件特性的深度挖掘。

当前领域处于“工程成熟、理论滞后”阶段。工程问题如 KV Cache 卸载、硬件感知编译已有明确路径，但研究问题如线性注意力的表达力恢复机制、注意力机制的可解释性仍缺乏统一框架。Condensate Theorem 等理论工作开始提供指导，证明训练后模型自发学习稀疏性，为稀疏化设计提供了理论依据。然而，动态稀疏的计算开销与精度收益的平衡尚未解决，且现有实验多在静态基准上进行，未充分测试动态生成中的误差累积。

**如果用一个核心问题概括该领域，那便是：如何在保持模型捕捉复杂长程依赖能力的前提下，将注意力机制的计算与内存复杂度从二次方降低至线性或亚二次方，并实现训练与推理阶段的一致性。**

## 2. 方法体系

- 2017：Transformer——提出基于多头自注意力的序列建模架构，确立现代大语言模型的基础范式

- 2019：Sparse Transformer——引入固定稀疏模式，打破全连接注意力的二次复杂度

- 2020：Longformer——结合滑动窗口局部注意力与全局注意力，解决长序列内存瓶颈

- 2020：Linear Attention——通过移除 Softmax 并重排计算顺序，将复杂度降至线性

- 2021：Performer——利用随机特征映射近似 Softmax 注意力，实现无偏线性复杂度计算

- 2023：StreamingLLM——发现并利用注意力汇聚现象，实现无限长序列的流式生成

- 2024：FlashAttention——通过 IO 感知的内核优化，显著提升 GPU 上的计算效率

- 2025：HySparse——提出混合稀疏注意力架构，解决训练-推理不匹配问题

- 2026：SPAttention——提出基于平衡距离分区的稀疏注意力，实现头部专业化

这条时间线勾勒了该领域方法演进的代表性节点：从 2017 年的 Transformer 奠定该领域方法基线，经 2019 年 Sparse Transformer 的推进，到 2026 年的 SPAttention 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 稀疏注意力机制

稀疏注意力机制通过限制 Token 间的交互范围来降低计算量，其演进核心在于解决固定模式的灵活性不足与动态模式的计算开销问题。早期工作如 Longformer（Beltagy et al., 2020）结合滑动窗口局部注意力与特定 Token 的全局注意力，确立了混合稀疏策略的标准基线，但固定模式在推理时可能破坏训练时学习的全局依赖。HySparse（Gao et al., 2026, P19）针对这一训练-推理不匹配问题，提出混合稀疏注意力架构，通过在全注意力层后插入稀疏层并复用前序层的 KV 缓存与重要 Token 索引，避免了重复计算。其核心创新在于引入 Oracle Token 选择机制，利用全注意力层输出的块级重要性分数动态确定稀疏层需关注的 Token 子集，从而在推理阶段实现高效稀疏化。该方法的代价是引入了全注意力层与稀疏层之间的依赖关系，增加了架构设计的复杂性，且稀疏层的性能上限受限于全注意力层的选择质量。

SPAttention（Zhao et al., 2025, P6）则从头部专业化角度切入，设计基于平衡距离分区的稀疏注意力机制，将因果注意力的距离谱划分为多个连续且非重叠的频段，并将每个频段分配给特定的注意力头部。这种结构化稀疏设计强制不同头部专注于不同的距离范围，从近邻依赖到长程依赖，实现了信息覆盖的完整性与头部功能的特化。与 HySparse 依赖内容相关性评分不同，SPAttention 通过空间距离的结构化分配优化计算资源，解决了多头注意力中的计算冗余问题。其技术定位在于保持模型表达力的同时提升效率，但依赖于头部数量的合理配置以确保频段划分的均匀性。Condensate Theorem（Ruiz Williams, 2026, P21）为稀疏注意力提供了理论支撑，证明训练后的 Transformer 模型已自发学习稀疏性，通过动态选择高注意力权重位置可实现与全注意力在浮点精度下的数值等价。这一发现打破了以往认为稀疏化必然导致精度损失的认知，表明稀疏化并非近似手段，而是对模型内在结构的精确利用。

Sketch&Walk（Le et al., 2026, P22）进一步解决了现有方法仅依赖单跳注意力分数导致的多跳依赖遗漏问题。该方法在预填充阶段通过头平均的 Query 和 Key 矩阵进行块级选择，并利用 Hadamard 矩阵进行维度缩减以加速块代表计算，同时引入随机游走状态以捕获跨层的依赖关系。其核心改进在于将稀疏选择从单层的独立决策扩展为跨层的动态传播，通过维护随机游走状态来模拟信息在层间的流动。Stem（Niu et al., 2026, P24）则从因果信息流角度重新思考稀疏注意力，通过 Token 位置衰减策略和输出感知度量优化 Token 选择，以最小化稀疏化带来的递归误差传播。AdaSplash-2（Gonçalves et al., 2026, P30）提出硬件感知的可微分稀疏注意力机制，通过基于直方图的近似算法在片上 SRAM 中高效计算阈值，实现了 $\alpha$-entmax 稀疏化的快速前向与反向传播。CRISP（Nguyen et al., 2026, P35）则引入结构质量动机路由，通过识别注意力分布中的“质量悬崖”现象，动态调整不同头部类型的稀疏策略，针对值选择头部采用累积覆盖阈值进行索引选择，而对位置编码头部保留近似计算以避免噪声累积。这些方法共同推动了稀疏注意力从固定模式向动态、结构感知方向的演进，与线性注意力路线形成互补，后者通过架构重构实现线性复杂度，而前者通过结构化稀疏保留全注意力的部分优势。

### 2.2 线性注意力架构

线性注意力架构通过移除 Softmax 非线性并重新排列计算顺序，将复杂度降至 $O(N)$，其演进核心在于解决表达力下降问题。早期工作如 Linear Attention（Katharopoulos et al., 2020）开创了状态空间模型与线性注意力融合的研究方向，但常面临表达力损失。Flex Linear Attention（ICLR 2026, P36）提出统一的线性注意力编译框架，将多种线性注意力变体（如 Mamba、RetNet、RWKV 等）抽象为可编译的算子，并生成针对特定硬件优化的可扩展内核。该方法的核心在于识别不同线性注意力架构中的共性计算模式，如扫描操作和状态更新，并通过启发式调度算法选择解耦或融合策略以平衡并行度与内存局部性。其创新点在于提供了标准化的编译接口，使得新的线性注意力变体可以快速适配到现有硬件平台上，降低了部署门槛。该框架依赖于对线性注意力数学形式的统一描述，要求变体能够表示为状态空间模型或递归形式，因此不适用于所有非线性注意力变体。

Linear-InfS（Roffo et al., 2026, P23）提出基于无限自注意力概念的线性 Transformer 架构，通过建模多跳 Token 影响来恢复线性注意力在长序列中的表达力。该方法的核心在于将标准 Transformer 的隐式依赖聚合显式化为无限自注意力过程，利用递归机制在恒定内存下捕获长程依赖，同时保持线性时间复杂度。其创新点在于引入了无限自注意力的数学框架，证明了线性注意力可以通过递归状态更新模拟全注意力的多跳信息传递，从而弥补了传统线性注意力在复杂依赖建模上的不足。Symmetry-Aware Taylor Approximation（Heinsen and Kozachkov, 2026, P16）则从数学近似角度重新审视注意力计算，通过利用注意力矩阵的对称结构进行低阶多项式近似，使得每个 Token 的计算复杂度保持恒定。Hybrid Linear-Full Attention Expressiveness Hierarchy（Ye et al., 2026, P18）提出混合线性-全注意力架构的表达力层级理论，通过理论分析揭示了线性注意力层在多层堆叠中无法替代全注意力层在复杂推理任务中的核心作用。该理论依赖于对线性注意力递归形式的严格数学刻画，适用于 Mamba、RWKV 等主流线性注意力变体，但不直接适用于非递归的线性注意力方法。

MHLA（Zhang et al., 2026, P13）提出通过 Token 级多头机制恢复线性注意力表达力的架构，通过引入查询条件化的多头结构，解决了传统线性注意力因全局状态压缩导致的表达力损失问题。该方法的核心在于将线性注意力的全局状态更新分解为多个子空间，每个子空间对应一个独立的查询条件化头，从而在保持线性复杂度的同时恢复了 Token 间的细粒度交互能力。Local Linear Attention（Zuo et al., 2025, P3）提出线性注意力与 Softmax 注意力的最优插值架构，通过引入局部窗口内的 Softmax 注意力和全局线性注意力的组合，实现了测试时回归任务中的高效长序列处理。ZeroS（Lu et al., 2026, P20）提出零和线性注意力机制，通过消除零阶项并解耦径向-角度分量，实现了数值稳定的负权重注意力，增强了模型对微分和对比操作的表达能力。这些方法共同推动了线性注意力从简单核方法向混合、多头、结构感知方向的演进，与稀疏注意力路线形成竞争，后者通过结构化稀疏保留全注意力的部分优势，而前者通过架构重构实现线性复杂度。

### 2.3 注意力变体设计

注意力变体设计通过提出新型注意力数学形式或结构变体，以增强模型表达力、解决表示坍缩或优化特定任务性能。Deconstructing Attention（Xue et al., 2025, P5）提出解构注意力机制的设计原则研究框架，通过选择性放松注意力的四个关键属性（如对称性、归一化等），系统性地探究其对语言建模性能的影响。该方法的核心在于将注意力机制分解为独立的数学组件，并设计针对性的变体以隔离每个属性的作用，从而建立属性与性能之间的因果联系。Exclusive Self Attention（Zhai, 2026, P25）提出通过移除注意力输出中自值向量投影来消除注意力相似性偏置的变体，旨在促进注意力层与 FFN 层之间的劳动分工。SAOBP（Lee et al., 2025, P2）提出通过单步信念传播缓解注意力局部化的自注意力精炼算法，将注意力分数矩阵解释为因子图，并通过单次消息传递引入全局上下文信息。

Lazy Attention（Fu et al., 2026, P11）提出结合位置判别与弹性 Softmax 的统一注意力分配视角，通过跨头部和维度的位置判别克服注意力过载，并利用弹性 Softmax 过滤微小权重以解决注意力欠载问题。Sparse Query Attention（Filipek, 2025, P4）提出通过减少查询头部数量来降低计算复杂度的注意力机制，在保持键值头部完整性的前提下，显著降低了训练和推理阶段的计算开销。Focus（Yao et al., 2026, P27）提出基于可学习质心向量的两级注意力机制，通过软分组分配和门控注意力结合局部窗口与组间远距离注意力，实现了高效的 Token 交互建模。Power-based Partial Attention（Huang, 2026, P14）提出基于幂律分布的部分注意力机制，通过动态调整步长大小使得每个 Token 仅关注 $O(\sqrt{L})$ 个过去 Token，实现了 $O(L^{1.5})$ 的复杂度。All-or-Here Attention（Luo et al., 2025, P10）提出条件计算注意力机制，通过为每个注意力头部分配二元门控，动态路由 Token 至全注意力或局部滑动窗口注意力路径，以利用注意力机制的内在冗余性。这些方法共同推动了注意力变体从单一结构优化向多粒度、动态路由、结构感知方向的演进，与稀疏和线性注意力路线形成互补，后者通过限制交互范围或移除非线性降低复杂度，而前者通过结构创新增强表达力或优化特定任务性能。

### 2.4 注意力理论分析

注意力理论分析从数学、几何及概率视角解析注意力机制原理，涵盖表达力层级、训练动力学、收敛性证明及与经典算子的理论联系。EEI Trade-off Survey（Singh, 2026, P34）提出定量调查注意力机制效率-表达力-可解释性权衡的框架，通过建立评分标准对代表性注意力方法进行评估，揭示了不同架构在效率与表达力之间的帕累托前沿。Sparse Attention as Compact Kernel Regression（Santos et al., 2026, P15）提出将稀疏注意力机制解释为紧凑核回归的理论框架，揭示了 Top-k Softmax 对应于高斯核 kNN 回归，而归一化 ReLU 对应于固定带宽 Epanechnikov 回归。Grassmann Language Model（Chong, 2025, P9）提出基于 Grassmann 流形的语言模型，通过几何视角批判自注意力机制，认为注意力是一种张量提升操作，其不可追溯性导致了 Transformer 的可解释性差。

Robust Filter Attention（Racioppo, 2025, P1）提出将自注意力重构为鲁棒状态估计的理论框架，通过线性时不变随机动力系统模型，利用卡尔曼滤波思想聚合过去 Token，以解决长上下文外推中的稳定性问题。Self-Attention as Distributional Projection（Mehta, 2025, P7）提出将自注意力解释为分布投影的统一数学框架，通过线性代数传统中的投影算子，揭示了注意力机制在词汇空间中的上下文加权作用。Connection Laplacian View（Lin et al., 2026, P33）提出将自注意力解释为连接拉普拉斯算子的统一几何视角，将 Token 表示视为 Token 位置图上的向量场，注意力作用视为连接游走，从而揭示了注意力机制的图几何本质。Token Sample Complexity（Bohbot et al., 2025, P8）提出 Token 样本复杂度的理论框架，通过子高斯模型分析注意力机制在极长序列下的收敛性，揭示了提供更多 Token 作为输入对模型性能的边际收益递减现象。这些理论工作为注意力机制的设计提供了数学基础，与稀疏和线性注意力路线形成指导关系，后者通过具体架构实现理论预测的效率与表达力平衡，而前者通过理论分析揭示架构设计的内在规律。

### 2.5 注意力失效机制

注意力失效机制聚焦注意力汇聚（Attention Sink）、秩坍缩及过度平滑等病理现象，探究其结构性根源、对模型性能的影响及相应的缓解策略与理论解释。Attention Sink Survey（Su et al., 2026, P29）提出关于注意力汇聚现象利用、解释与缓解的综合调查，系统梳理了注意力汇聚在语言模型、视觉 Transformer 和混合专家模型中的表现及其对 KV 缓存优化、长上下文生成和量化策略的影响。Preconditioned Attention（Saratchandran, 2026, P26）提出通过预条件技术增强 Transformer 效率的方法，通过研究自注意力矩阵的条件数，揭示了高条件数导致梯度下降收敛缓慢的问题，并提出了预条件策略以改善矩阵的条件数。Sinkhorn Doubly Stochastic Attention（Lapenna et al., 2026, P28）提出基于 Sinkhorn 算法的双随机注意力机制，通过迭代行列归一化产生双随机注意力矩阵，并分析了其对注意力矩阵乘积秩衰减的影响。

Sink-Aware Training（Fu et al., 2026, P17）提出利用注意力汇聚现象在注意力层中构建原生混合专家（MoE）结构的训练策略，通过引入可学习的 Sink 参数和门控机制，消除了注意力汇聚并实现了头部的稀疏利用。Structural Origin of Attention Sink（Li et al., 2026, P31）提出从方差差异、超级神经元和维度差异角度解释注意力汇聚结构性起源的理论框架，揭示了注意力汇聚是激活异常和表示坍缩的深层架构问题。这些工作共同推动了注意力失效机制从现象描述向结构性根源分析与缓解策略设计的演进，与稀疏和线性注意力路线形成互补，后者通过架构设计避免或缓解失效现象，而前者通过理论分析揭示失效现象的内在机制并提供针对性解决方案。

### 2.6 跨任务与多领域应用

注意力机制的效率优化不仅限于语言建模，还广泛应用于图像分类、语音识别、数学推理等多领域任务。在图像分类任务中，Linear InfViT（Roffo et al., 2026, P23）在 ImageNet-1K 上取得了 84.7% 的准确率，Pure InfViT 达到 85.4%，展示了线性注意力在视觉 Transformer 中的有效性。在情感分析任务中，Grammar-Hard（Pratyush, 2026, P32）在 SST-2 上取得了 0.8200 的准确率，Grammar-Soft 达到 0.8165，表明语法引导的稀疏注意力在保持精度的同时提升了效率。在数学推理任务中，PPA (p=1.0)（Huang, 2026, P14）在 MATH500 上取得了 0.75 的准确率，PPA (p=0.875) 达到 0.74，展示了部分注意力机制在复杂推理任务中的潜力。在回归任务中，ZeroS（Lu et al., 2026, P20）在 RegBench 上表现出优异的性能，证明了零和线性注意力在需要精确差异建模的任务中的优势。在长上下文任务中，CRISP（Nguyen et al., 2026, P35）在 InfiniteBench 上取得了最佳成绩，MHLA（Zhang et al., 2026, P13）在 LongBench 上取得了 6.97 的成绩，展示了混合架构在长序列处理中的有效性。这些跨任务应用表明，注意力机制的效率优化需根据任务特性进行针对性设计，不同路线在特定任务上展现出独特的优势。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域共识认为标准自注意力的 $O(N^2)$ 复杂度是长序列处理的主要瓶颈，必须通过稀疏化、线性化或硬件优化来缓解。这一共识在多个基准上被反复验证：MHLA 的 51.3 与 SPAttention 的 0.3684 均大幅超越标准注意力基线的 0.3610，表明效率优化并未损害模型性能。FlashAttention 等硬件感知算法在不改变数学结果的前提下显著提升了 Softmax 注意力的实际运行效率，是当前工业界的标准实践，其 IO 感知内核优化被广泛采用。线性注意力虽然实现了 $O(N)$ 复杂度，但通常以牺牲表达力为代价，直接替换 Softmax 注意力会导致性能下降，MHLA 等混合架构通过 Token 级多头机制恢复了部分表达力，在 MMLU 上优于纯线性架构 Mamba（46.4 vs 51.3）。Attention Sink 现象是 Transformer 架构的固有特性，源于 Softmax 归一化的约束，可被利用于 KV 缓存优化但需警惕其对模型行为的潜在影响，StreamingLLM 通过保留初始 Token 的 KV 缓存实现了无限长序列的流式生成。稀疏注意力模式能有效减少计算量，但固定模式可能限制模型灵活性，动态模式更具潜力但实现复杂，HySparse 和 CRISP 等动态稀疏方法在长上下文任务中表现出优势。KV 缓存的内存占用随序列长度线性增长，是长上下文推理的主要内存瓶颈，GQA 和 MQA 是有效的缓解手段。多头注意力中的不同头往往承担不同的功能，这种头部专业化为稀疏化和剪枝提供了依据，SPAttention 通过距离分区实现了头部专业化。混合架构在效率和性能之间提供了更好的平衡点，优于单一范式的极端优化，MHLA 和 HySparse 等混合方法在多个基准上取得了最佳成绩。

### 3.2 观点分歧

线性注意力能否在理论上完全替代全注意力是领域内的核心分歧。观点 A（Mamba/RWKV 支持者）认为线性注意力通过递归状态更新可捕获长程依赖，且在特定任务上性能接近全注意力。观点 B（Hybrid Linear-Full Attention 理论）认为线性注意力在深层序列组合任务上存在多项式下界劣势，无法完全替代全注意力。现有证据偏向观点 B，理论证明（Ye et al., 2026, P18）显示线性注意力在复杂推理任务上存在表达力差距，实验上 MHLA 等混合架构在 MMLU 等任务上优于纯线性架构。这一分歧的背后，是另一个更根本的争论：稀疏化是否必然导致精度损失。观点 A（Condensate Theorem）认为训练后模型自发学习稀疏性，动态选择高注意力位置可实现无损稀疏化。观点 B（传统观点）认为稀疏化是近似手段，必然导致精度损失。现有证据偏向观点 A，但有限制条件，Condensate Theorem（Ruiz Williams, 2026, P21）证明在浮点精度下稀疏化可无损，但动态稀疏的计算开销可能抵消收益。Attention Sink 是病理现象还是可利用特性也存在分歧。观点 A（StreamingLLM）认为 Attention Sink 是固有特性，可被利用于 KV 缓存优化。观点 B（Structural Origin of Attention Sink）认为 Attention Sink 源于激活异常和表示坍缩，是架构缺陷，应通过归一化或门控消除。现有证据偏向观点 A 的实用性，但观点 B 提供了更深层的解释，Sink-Aware Training（Fu et al., 2026, P17）证明消除 Sink 可提升模型表达能力。

### 3.3 其他开放问题

当前领域面临的最紧迫工程问题是 KV Cache 卸载与优化。随着上下文长度增加，KV Cache 成为内存瓶颈，未来需研究将全注意力 KV Cache 卸载到外部存储并预取，仅保留稀疏/持久 KV 在 GPU 上的策略，难点在于系统级延迟与计算重叠，潜在路径包括硬件感知的稀疏注意力内核和动态内存管理。最根本的研究问题是线性注意力与全注意力的表达力层级与混合架构设计。理论证明线性注意力在深层序列组合任务上弱于全注意力，未来需设计混合架构，在关键层使用全注意力，其余层使用线性注意力，难点在于确定最优混合比例和层位置，潜在路径包括基于任务复杂度的动态路由和表达力下界分析。注意力机制的可解释性与几何结构分析也是重要开放问题，当前注意力机制缺乏统一的几何解释，未来需从连接拉普拉斯、热带几何等角度揭示注意力的内在结构，难点在于将高维张量操作映射到可解释的几何对象，潜在路径包括基于流形的注意力建模和谱分析。稀疏注意力的因果对齐与信息流建模同样关键，现有稀疏方法常忽略因果信息流，未来需设计因果对齐的 token 选择策略，保护关键递归锚点，难点在于动态预算分配和位置衰减策略，潜在路径包括基于输出感知的指标和块级粗到细推理。小模型中的注意力局部化缓解与多跳推理也是研究热点，小模型易出现注意力熵坍缩，未来需通过信念传播或图推理增强多跳信息流，难点在于计算开销与模型深度的平衡，潜在路径包括一步信念传播正则化和全局一致性约束。注意力机制的硬件感知编译与内核优化需进一步探索，不同注意力变体需要不同的硬件支持，未来需开发统一编译器，自动生成高效内核，难点在于抽象算法变体与硬件特性的映射，潜在路径包括领域特定语言（DSL）和分布式执行支持。Attention Sink 现象的机理与利用仍需深入研究，Attention Sink 是普遍现象但机理不明，未来需从方差差异和超级神经元角度解释其起源，并用于构建原生 MoE 结构，难点在于区分信号与架构噪声，潜在路径包括 Sink 感知训练和负载均衡损失。已知—争议—未知认知图谱显示，效率优化与表达力平衡是已知核心问题，线性注意力表达力上限与稀疏化无损性是争议焦点，注意力机制几何解释与因果对齐稀疏化是未知领域，未来趋势将向混合架构、理论指导设计与硬件-算法协同方向发展。

## 4. 总结与展望

注意力机制效率优化的核心矛盾在于 $O(N^2)$ 复杂度与长程依赖建模能力之间的张力。研究界尝试了稀疏化、线性化、硬件优化及混合架构等多种路线，但核心瓶颈仍在于如何在降低复杂度的同时不损失表达力，并实现训练与推理阶段的一致性。Condensate Theorem 等理论工作提供了指导，但动态稀疏的计算开销与精度收益的平衡尚未解决，且现有实验多在静态基准上进行，未充分测试动态生成中的误差累积。

未来可能突破的方向包括：混合架构与理论指导设计的深度融合，MHLA 和 HySparse 等工作共同指向在关键层使用全注意力、其余层使用线性/稀疏注意力的混合范式，需进一步探索最优混合比例和层位置；注意力机制的几何解释与因果对齐稀疏化，Connection Laplacian View 和 Stem 等工作共同指向从几何和因果角度理解注意力机制，设计因果对齐的 token 选择策略；硬件感知编译与内核优化，Flex Linear Attention 和 AdaSplash-2 等工作共同指向开发统一编译器，自动生成高效内核，最大化硬件利用率。对于进入该领域的研究者，最值得做的一件事是在统一骨干与统一预训练条件下，系统评测代表性方法在动态生成任务中的误差累积，以揭示训练-推理不匹配的真实影响，为混合架构设计提供实证基础。
