## 导读

视觉-语言-动作模型（Vision-Language-Action, VLA）将互联网规模的视觉-语言先验直接映射为机器人低层动作，其核心价值在于突破传统任务特定策略在非结构化环境中的泛化瓶颈。早期研究聚焦于语义接地，通过离散动作 Token 验证了大规模多模态模型对机器人控制的增益，但离散量化在精细操作中的精度不足很快暴露了该范式的局限。随着连续动作生成（如流匹配）的引入，VLA 架构从追求语义对齐转向兼顾控制平滑性与实时性，这一转变也催生了对推理效率与部署可行性的深度关注。当前，研究重心已从“能否执行”转向“如何稳定、高效且持续地执行”，强化学习后训练、显式记忆机制与轻量化架构成为解决模仿学习复合误差与边缘部署瓶颈的主要路径。各路线在模型规模、推理延迟与鲁棒性之间做出了不同取舍，由此形成当前多元并存的技术格局。本综述梳理这条从语义映射到具身闭环的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

传统机器人系统依赖任务特定的手工规则与低层感知算法，在结构化环境中表现稳定，但难以应对非结构化真实世界中的语义多样性与长时程操作需求。随着大规模视觉-语言模型（Vision-Language Model, VLM）在跨模态语义对齐上的突破，研究者开始探索将互联网规模的语义先验直接注入机器人控制策略，从而摆脱对密集人工标注与特定任务规则的依赖。这一范式转变的核心在于：VLM 提供了强大的开放词汇理解与场景推理能力，而机器人控制需要将这些高层语义转化为精确、实时的低层动作信号。因此，VLA 模型被定义为一种端到端的统一策略，直接映射视觉输入和语言指令到连续或离散的动作序列，旨在通过共享的语义空间提升机器人的泛化性与任务适应性。

问题形式化上，VLA 策略 $\pi$ 接收当前观测 $o_t$（包含图像、语言指令等）和历史上下文 $h_{t-1}$，输出动作 $a_t$。在标准的马尔可夫假设下，策略仅依赖当前观测，即 $a_t \sim \pi(a_t | o_t, l)$，其中 $l$ 为语言指令。然而，真实机器人操作往往是非马尔可夫的，需要长期记忆与多阶段规划。因此，更通用的形式为 $a_t \sim \pi(a_t | o_t, h_{t-1}, l)$，其中 $h_{t-1}$ 代表历史观测或信念状态。这一形式化揭示了子问题间的依赖关系：动作表征（架构）决定了感知-动作对齐的上限，而记忆机制与策略优化（RL）则决定了策略在分布外状态下的鲁棒性与长时程一致性。

该领域的约束演化史清晰地反映了技术瓶颈的转移。2023 年，RT-2 确立了 VLA 的基础范式，通过共微调将 VLM 适配为机器人策略，证明了语义先验对泛化的价值，但受限于离散动作 Token 的精度不足。2024 年，OpenVLA 和 π0 的出现标志着从离散到连续动作生成的转折，π0 引入流匹配（Flow Matching）解决了精细操作的平滑性问题，而 OpenVLA 则通过大规模异构数据（Open X-Embodiment）推动了跨本体迁移。2025 年，研究重心转向部署与鲁棒性，LoRA 微调降低了部署门槛，SimpleVLA-RL 引入强化学习以克服模仿学习的分布外脆弱性，HAMLET 则通过历史帧注意力解决了长时程状态遗忘。2026 年，TurboVLA 和 AnoleVLA 等轻量化架构进一步突破了边缘设备的实时性瓶颈，而 CLARE 和 PHASER 则探索了持续学习中的灾难性遗忘缓解。当前，VLA 模型已成为具身智能的核心驱动力，研究热点集中在如何平衡模型规模与计算资源、如何克服模仿学习的复合误差，以及如何实现长时程任务中的记忆与规划。

**如果用一个核心问题概括该领域，那便是：如何在资源受限的物理机器人上，构建一个既能继承大规模视觉-语言语义先验，又能通过实时闭环控制克服模仿学习复合误差并具备长时程记忆与自我纠错能力的统一策略模型。**

## 2. 方法体系

- 2023：RT-2——将视觉-语言模型适配为机器人策略，确立 VLA 基础范式

- 2024：OpenVLA——基于大规模异构数据实现跨本体零样本泛化

- 2024：π0——引入流匹配动作专家，实现连续动作空间高效生成

- 2025：LoRA Fine-Tuning——参数高效微调，降低消费级 GPU 部署门槛

- 2025：SimpleVLA-RL——引入强化学习，提升分布外泛化能力

- 2025：HAMLET——插件式历史帧注意力，解决长时程状态遗忘

- 2026：TurboVLA——单张 RTX 4090 上实现 32Hz 实时推理

- 2026：VLANeXt——系统性消融实验，确定强 VLM 骨干与轻量策略头最佳组合

这条时间线勾勒了该领域方法演进的代表性节点：从 2023 年的 RT-2 奠定该领域方法基线，经 2024 年 OpenVLA 的推进，到 2026 年的 VLANeXt 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 架构与动作表征

VLA 的底层架构决定了感知-语言-动作的对齐效率与生成精度。早期工作如 RT-2 采用离散动作 Token，直接复用 VLM 的自回归能力，优势在于训练简单且推理速度快，但离散量化在精细操作（如抓取、插入）中导致动作抖动，精度不足。π0 针对这一问题，引入基于流匹配的动作专家模块，实现了连续动作空间的高效生成，显著提升了动作平滑性与精度，但代价是推理计算量增加，需配合动作分块（Action Chunking）降低控制频率。FASTer（P33）进一步引入神经动作分词器，通过有效重建率（VRR）优化动作压缩与重建质量，解决了传统 VQ 分词器在动作序列压缩中的信息损失问题，提升了自回归 VLA 的压缩效率。AdaMoE（P8）则提出动作特化混合专家（MoE）架构，通过解耦路由器和专家权重，实现动作生成的动态专家选择，提升了 VLA 在处理多样化操作技能时的表达能力与效率，但结构复杂度增加且路由决策可能引入不稳定性。VLANeXt（P20）通过系统性消融实验，揭示了强 VLM 骨干（如 Qwen3-VL）与轻量策略头的最佳组合，为构建高效强 VLA 模型提供了配方指南。MCF-Proto（P26）引入运动中心动作帧（MCF），通过预测局部旋转矩阵并在该帧中生成动作原型，解决了世界坐标系动作头在视角变化下的鲁棒性不足问题。Vlaser（P6）则整合具身推理与端到端控制，通过数据引擎和训练配方优化具身推理预训练和 VLA 微调过程，提升了模型的推理和控制能力。

| 方法 | 动作空间类型 | 核心机制 | 主要优势 | 主要局限 |
|---|---|---|---|---|
| RT-2 | 离散 Token | 共微调 VLM | 继承自回归能力，训练简单 | 精细操作精度不足，动作抖动 |
| π0 | 连续生成 | 流匹配动作专家 | 动作平滑精确，适合精细操作 | 推理计算量增加，需动作分块 |
| FASTer | 离散 Token | 神经动作分词器 | 压缩效率高，功能保真 | 分词器训练需额外 VRR 计算 |
| AdaMoE | 连续/离散 | 动作特化 MoE | 多任务表达能力强 | 结构复杂，路由不稳定 |
| MCF-Proto | 连续生成 | 运动中心动作帧 | 视角变化下鲁棒性强 | 增加旋转矩阵预测开销 |

### 2.2 高效推理与部署

VLA 模型通常基于大规模 VLM 骨干，参数量巨大导致推理延迟高、内存占用大，难以在资源受限的物理机器人上实现实时控制。LoRA-Based Fine-Tuning（P15）针对这一问题，提出基于低秩适应（LoRA）的参数高效微调方法，通过在预训练模型中插入可训练的低秩矩阵，显著减少需要存储和更新的参数数量，使得在消费级 GPU 上训练大型 VLA 模型成为可能。ActDistill（P12）提出一种通用的动作引导自蒸馏框架，利用大型 VLA 模型作为教师，通过动作预测任务指导轻量级学生模型的学习，实现知识的高效迁移，大幅降低模型规模，但蒸馏过程需要额外的教师模型推理资源。GLUESTICK（P5）针对 VLA 模型在剪枝后性能严重下降的问题，提出一种后处理、免训练的权重空间恢复方法，通过比较原始稠密模型与剪枝模型的权重差异，在权重空间中直接进行修复，揭示了 VLA 模型对结构化稀疏性的敏感性。AnoleVLA（P23）提出一种基于深度状态空间模型（SSM）的轻量级 VLA 架构，利用 SSM 的线性复杂度和快速序列状态建模能力，高效处理视觉和文本输入的多模态序列，显著降低推理延迟，但可能在某些需要长程精确依赖的任务上表现略逊于 Transformer。TurboVLA（P32）致力于实现 VLA 模型在单张 RTX 4090 显卡上以 32Hz 频率进行实时推理，且显存占用低于 1GB，通过极致的模型优化和推理加速技术，突破了 VLA 模型在消费级硬件上的部署瓶颈。TIES（P24）提出一种免训练的动态 Token 剪枝框架，利用层间秩一致性来自适应调节对高注意力 Token 的依赖，解决了静态剪枝策略在动态输入下的不适应性。

### 2.3 强化学习后训练

模仿学习（IL）是 VLA 模型的基础训练范式，但存在复合误差和分布外脆弱性问题。SimpleVLA-RL（P2）提出一种通过强化学习扩展 VLA 训练规模的框架，利用交互式滚动收集数据，并通过结果奖励建模提供稀疏但有效的监督信号，增强了策略在分布外状态的鲁棒性与自我纠错能力，但训练过程需要更多的环境交互。WMPO（P10）提出基于世界模型的策略优化框架，利用像素级世界模型生成“想象”轨迹，并将这些轨迹与 VLA 预训练特征对齐，从而在虚拟环境中进行在线策略梯度优化，解决了 RL 在真实机器人环境中样本复杂度高的问题，但世界模型的训练和推理开销较大。GigaBrain-0.5M*（P19）提出一种结合世界模型与强化学习的 VLA 训练方法，通过视频状态优势估计，利用世界模型预测未来状态并计算优势值，指导策略优化，提升了 VLA 在长时程任务中的前瞻性决策能力。RePO-VLA（P25）提出恢复驱动的策略优化框架，通过识别可恢复的逆境状态并生成针对性的纠正动作，增强了 VLA 在接触丰富操作中的鲁棒性，弥补了基准成功率与实际长时程执行之间的差距。CRL-VLA（P18）探索持续强化学习在 VLA 模型中的应用，通过平衡稳定性与可塑性，解决非平稳任务流下的灾难性遗忘问题。ARFM（P1）提出自适应强化流匹配算法，通过引入自适应调整的信号与方差平衡机制，优化离线 RL 后训练目标，提升了 VLA 流模型在复杂任务中的动作精度和鲁棒性。

### 2.4 记忆与时序建模

大多数 VLA 模型采用马尔可夫假设，仅依赖当前或短历史观测，无法有效处理需要长期记忆、多阶段规划或应对感知遮挡/别名的复杂任务。HAMLET（P4）提出一种插件式框架，将预训练 VLA 模型转换为具有历史感知能力的策略，通过引入历史帧注意力机制，使模型能够关注过去的关键观察，从而捕捉时间依赖性和上下文信息，无需重新训练整个 VLA 模型。AsyncVLA（P11）提出异步流匹配（AFM）框架，通过非均匀时间调度和动作上下文感知，实现动作生成的自纠错机制，解决了同步流匹配在长时程任务中因单步错误累积导致的不稳定性问题。RoboMME（P22）构建了一个针对机器人通用策略的记忆基准测试，区分了符号记忆、感知记忆和循环记忆三种表示形式，并通过多种任务评估其有效性，为 VLA 记忆机制的设计提供了实证依据。OptimusVLA（P21）提出双记忆增强 VLA 模型，结合全局先验记忆（GPM）和局部一致性记忆（LCM），解决 VLA 推理效率低和时间依赖鲁棒性差的问题，实现了高效且一致的操作。In-Context World Modeling（P30）提出一种在上下文中进行世界建模的方法，利用标准序列建模从任务无关的交互历史中提取时间不变的因果结构，实现隐式世界建模，使得 VLA 能够在未知环境中快速校准控制映射。

### 2.5 持续与泛化学习

机器人在长期部署中需不断习得新技能，但标准微调会导致旧技能遗忘。Stellar VLA（P13）提出一种自演化知识空间的持续学习 VLA 框架，通过动态更新任务相关知识，使模型能够在不牺牲先前技能的情况下获取新技能。CLARE（P16）提出一种通过自主适配器路由与扩展实现无样本持续学习的 VLA 框架，利用层级特征引导动态扩展模型参数，避免了存储历史数据的需求。PHASER（P29）提出相位感知与语义经验回放方法，通过半马尔可夫决策过程（SMDP）视角重新定义任务阶段，优化回放缓冲区分配，解决了标准经验回放与机器人操作时间非均匀性的不匹配问题。Enhancing Generalization by Preserving Pretrained Representations（P3）提出一种通过保留预训练表示来增强 VLA 泛化能力的方法，通过正则化技术约束 VLA 微调过程中的参数变化，确保预训练 VLM 的视觉-语言表示得以保留。DynamicVLA（P17）提出一种针对动态物体操作的 VLA 模型，通过优化推理延迟和动作执行同步，提升模型对快速变化环境的响应能力。ManiAgent（P7）提出一种代理框架，通过多代理通信，实现环境感知、子任务分解和动作生成的协同，提升模型对复杂场景的处理能力。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

VLA 模型通过整合视觉、语言和动作模态，显著提升了机器人在非结构化环境中的泛化能力和语义理解水平，这一共识在多个基准上被反复验证：SimpleVLA-RL 在 LIBERO 上的 99.1% 与 Z-1 在 RoboTwin 2.0 上的 80.6% 均大幅超越传统基线，表明 VLM 先验对机器人控制的增益是普遍存在的。与此相关的另一个共识是，基于大规模预训练 VLM 骨干的初始化是构建高性能 VLA 模型的关键，能够继承丰富的视觉-语义先验知识，但需通过特定微调策略避免灾难性遗忘。VLANeXt 的系统性消融实验进一步证实了强 VLM 骨干对 VLA 泛化能力的关键影响，而 P3 提出的保留预训练表示方法则通过正则化技术确保了语义先验在微调过程中的保留。

### 3.2 观点分歧

在如何克服模仿学习局限上，强化学习后训练与显式记忆/世界模型两条路线存在显著分歧。RL 后训练路线（如 SimpleVLA-RL、WMPO）认为通过奖励信号和在线交互，策略可学习自我纠错，提升分布外鲁棒性；而记忆/世界模型路线（如 HAMLET、OptimusVLA、GigaBrain）认为通过预测未来或回顾历史，策略可避免错误累积，提升长时程一致性。现有证据偏向互补而非竞争：RL 在空间配置泛化上表现更好（SimpleVLA-RL 在 LIBERO-Long 达 98.5%），而记忆机制在需要长期状态跟踪的任务上更优（OptimusVLA 在长时程任务中的一致性）。这一分歧的背后，是另一个更根本的争论：鲁棒性的来源究竟是策略优化还是状态表征？缺乏统一的基准来同时评估“分布外鲁棒性”与“长时程一致性”，且大多数实验在仿真中进行，真实世界中的噪声与动态性可能改变两者的相对优势。

### 3.3 其他开放问题

当前 VLA 研究面临的最紧迫工程问题是如何在资源受限的物理机器人上实现实时闭环控制。TurboVLA 已部分解决这一问题，在单张 RTX 4090 上实现 32Hz 推理且显存占用低于 1GB，但通用性待验证，且优化过程复杂，需针对特定硬件深度定制。最根本的研究问题是如何在不依赖大量人工演示的情况下，通过自主探索（RL）或合成数据（World Model）获取高质量策略。SimpleVLA-RL 和 WMPO 展示了 RL 与 World Model 在减少演示依赖上的潜力，但训练过程仍需大量环境交互或世界模型训练开销。此外，持续学习中的灾难性遗忘仍是长期部署的关键挑战，CLARE 和 PHASER 等最新工作试图结合参数高效适配与经验回放，但效果尚待大规模验证。已知的是 VLM 先验对泛化的价值，争议的是鲁棒性的最优来源，未知的是真实世界动态环境下的长期稳定性。发展趋势将集中在世界模型与 RL 的结合、轻量化架构的普及、以及标准化效率基准的建立。

## 4. 总结与展望

VLA 模型的发展主线是解决“互联网规模先验”与“物理世界实时约束”之间的根本矛盾。从 RT-2 的离散 Token 到 π0 的连续流匹配，从离线模仿学习到在线强化学习后训练，从单帧马尔可夫假设到显式记忆机制，每一步演进都是对前一阶段瓶颈的回应。当前核心瓶颈在于如何在保持语义泛化的同时，实现物理世界的实时、鲁棒与终身学习。

未来可能突破的方向包括：一是世界模型与强化学习的深度结合，通过视频生成或状态预测模拟未来交互，减少真实世界昂贵且危险的交互成本，提高样本效率并支持长程规划与自我纠正（P10、P19）；二是轻量化、高效架构的普及，如混合专家（MoE）、状态空间模型（SSM）等，以降低推理延迟和显存占用，使模型能在消费级 GPU 或嵌入式设备上实时运行（P8、P23）；三是标准化、效率中心的基准测试生态系统，统一报告模型大小、推理延迟、能耗等资源指标，以解决当前 VLA 研究指标异构、难以跨模型比较效率增益的问题。对于进入该领域的研究者，最值得做的一件事是在统一骨干与统一预训练条件下，系统评估 RL 后训练与记忆机制在真实世界动态环境中的相对优势，填补当前仿真与真实世界之间的评测空白。
