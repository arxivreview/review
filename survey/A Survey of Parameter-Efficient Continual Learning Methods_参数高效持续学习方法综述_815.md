# A Survey of Parameter-Efficient Continual Learning Methods ｜参数高效持续学习方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Parameter-Efficient%20Continual%20Learning)

## 导读

参数高效持续学习（Parameter-Efficient Continual Learning, PECL）旨在解决大语言模型在动态任务流中因全参数更新导致的灾难性遗忘，其核心价值在于以极低的参数预算平衡稳定性与可塑性。早期研究聚焦于全参数微调的遗忘问题，但随着模型规模扩大，计算与存储约束迫使研究重心转向低秩适配等参数高效微调技术。当固定秩约束在异构任务流中暴露出子空间冲突后，研究者引入正交投影、混合专家架构及特征空间解耦，用更精细的知识隔离机制换取跨任务鲁棒性。各路线在隔离粒度、计算开销与部署灵活性之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从参数冻结到特征解耦的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

PECL 领域的兴起源于大语言模型静态训练范式与动态现实需求之间的根本矛盾。传统持续学习关注数据回放与正则化以对抗灾难性遗忘，但在大语言模型场景下，全参数更新在计算和存储上变得不可行，这促使研究重心从“如何防止遗忘”转向“如何在参数受限条件下防止遗忘”。核心概念稳定性-可塑性权衡（Stability-Plasticity Tradeoff）在此背景下被重新定义：模型需在保留旧知识（稳定性）与快速适应新任务（可塑性）之间找到平衡，而参数高效微调（PEFT）技术，特别是低秩适应（LoRA），成为实现这一平衡的主要技术载体。

问题的形式化可表述为：给定任务序列 $\mathcal{T} = \{T_1, T_2, \dots, T_N\}$，模型参数 $\theta$ 在训练 $T_t$ 时仅更新低秩矩阵 $W_t = A_t B_t$，目标是最小化 $\sum_{i=1}^t \mathcal{L}_i(\theta + W_i)$ 同时约束 $\|W_i\|_F$ 及任务间干扰。子问题间存在严格的依赖关系：首先需解决 LoRA 子空间冲突（基础），其次在此基础上处理高异质性任务的容量扩展（进阶），最后实现无回放条件下的长期记忆保留（终极目标）。范式边界上，PECL 区别于传统持续学习的关键在于“参数效率”与“任务无关推理”约束，即推理时模型无需知道输入属于哪个任务，需自主路由或融合知识。

2017 至 2022 年是奠基期，EWC 通过 Fisher 信息量化参数重要性，确立了正则化范式；LoRA 提出低秩分解，提供了高效微调载体，但缺乏对子空间冲突的深入理解。2023 至 2024 年出现关键转折，TRACE 基准的建立使领域从图像分类转向 LLM 场景，并识别出“秩盲性”问题，即固定低秩约束导致不同任务在子空间中碰撞。O-LoRA 和 LoRAMoE 相继出现，标志着从“参数冻结”向“子空间管理”和“架构扩展”的转变。

2025 至 2026 年，研究进入精细化阶段。Share 发现共享 LoRA 子空间的存在，SAE-FD 将正则化从权重空间移至特征空间，SETA 提出稀疏子空间解耦机制。这一阶段的核心特征是问题边界扩展至“高异质性任务”与“无回放/任务无关”约束，关注点从参数空间正则化转向特征空间解耦与动态容量扩展。当前形态表现为多条路线并行：低秩正交解决冲突，MoE 解决容量，特征解耦解决多义性干扰。

**如果用一个核心问题概括该领域，那便是：在参数预算严格受限且禁止数据回放的条件下，如何通过动态管理低秩子空间或特征表示，平衡模型对新任务的快速适应与对旧知识的长期保留。**

## 2. 方法体系

- 2017：EWC——通过估计Fisher信息矩阵对角线元素来量化参数对旧任务的重要性，并在优化新任务时添加二次惩罚项以限制重要参数的变动。

- 2022：LoRA——提出低秩适配技术，将权重更新分解为两个低秩矩阵的乘积，仅训练少量参数即可实现高效微调。

- 2023：O-LoRA——针对LoRA在持续学习中因共享参数空间导致的任务间干扰问题，提出正交低秩适配方法。

- 2024：LoRAMoE——将混合专家机制引入LoRA框架，通过冻结骨干网络并添加MoE风格的LoRA适配器插件来分配任务特定参数。

- 2025：Share——提出共享LoRA子空间方法，发现持续学习过程中存在一个通用的基础权重子空间。

- 2025：SAE-FD——引入稀疏自编码器（SAE）对LLM内部激活进行特征分解，并在持续学习过程中应用稀疏感知的特征蒸馏。

- 2026：SETA——提出Split-on-Share机制，通过梯度幅度选择稀疏子空间，并将重叠区域解耦为唯一专家和共享专家。

这条时间线勾勒了该领域方法演进的代表性节点：从 2017 年的 EWC 奠定该领域方法基线，经 2022 年 LoRA 的推进，到 2026 年的 SETA 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 低秩子空间正交

低秩子空间正交路线起源于对 LoRA 固定秩约束导致子空间冲突的反思。O-LoRA（2023）首次提出强制不同任务的 LoRA 子空间保持正交性，以隔离任务特定知识，其代价是牺牲了知识迁移的灵活性。Share（Kaushik et al., 2026, P14）进一步发现持续学习过程中存在通用的基础权重子空间，通过复用基向量并仅学习任务特定系数，实现了近乎零参数增长的持续适配，解决了独立 LoRA 存储开销大的问题。SLAO（Qiao and Mahdavi, 2025, P11）则通过增量整合所有任务特定的 LoRA 更新到一个持续更新的 LoRA 中，结合正交性约束和持续合并更新，解决了适配器库随任务数线性增长的内存瓶颈。

Spectral Disentanglement（2026, P29）针对秩盲性问题，引入双分支架构：低秩分支处理共享技能，高秩分支处理特定记忆，通过谱感知动态路由器根据输入动态决定调用策略，解决了固定秩约束下的信息瓶颈。JumpLoRA（Dragomir et al., 2026, P16）通过梯度幅度识别任务相关参数子集，允许 LoRA 适配器对这些特定参数进行目标更新，打破了全矩阵更新的限制，实现了参数级别的精准适配。PS-LoRA（Zhou et al., 2025, P10）从几何角度分析 LoRA 更新在子空间中的特性，通过投影和对齐操作减少干扰，提供了比简单正交更灵活的对齐方式。Any-SSR（2025, P30）使用递归最小二乘推导解析路由机制，无需反向传播即可无缝整合新任务，解决了传统 BP 路由的训练不稳定问题。Dual-LoRA（Wu et al., 2025, P7）结合正交约束和知识巩固机制，通过两个 LoRA 分支分别处理任务特定和共享知识，解决了严格正交导致的知识隔离过度问题。

### 2.2 专家混合架构

专家混合架构路线旨在解决高异质性任务下的容量扩展难题。LoRAMoE（2024）将混合专家机制引入 LoRA 框架，通过冻结骨干网络并添加 MoE 风格的 LoRA 适配器插件，利用路由机制动态选择专家，实现了参数的高效扩展与知识共享。Mixtures of SubExperts（Kang, 2025, P6）将模型参数划分为多个子专家模块，每个模块专门负责特定任务或知识域的学习，通过动态路由机制在推理时选择最相关的子专家，避免了全参数更新，显著降低了计算成本。

Mixture of LoRA Experts（2025, P28）针对持续信息抽取任务中语义相似导致的知识选择错误问题，设计更精细的选择模块以区分不同 IE 任务的知识，解决了传统 MoE 在语义密集任务中的选择偏差问题。CP-MoE（Liu et al., 2026, P20）引入一致性损失，确保新任务更新不破坏旧任务的表示一致性，同时支持文本和图像-文本对的多模态输入，扩展了 MoE 在持续学习中的应用范围。MoE-CL（Kang et al., 2025, P2）结合自进化持续指令微调与对抗学习，通过 MoE 架构动态分配参数以应对动态任务模式，在真实工业场景中验证了 LLM 自主适应的能力。CL-Anomaly（Dong et al., 2026, P27）引入层自适应知识转移策略，逐层识别关键专家并在参数更新时动态保留其知识，解决了传统方法在异常分布漂移下的性能退化问题。SETA（Siddika et al., 2026, P24）提出 Split-on-Share 机制，当子空间重叠超过阈值时，将竞争区域解耦为任务唯一专家和共享专家，防止参数覆盖，代表了稀疏专家混合架构在持续学习中的最新进展。

### 2.3 正则化与特征解耦

正则化与特征解耦路线旨在解决参数空间正则化的局限性。EWC（2017）通过估计 Fisher 信息矩阵对角线元素来量化参数重要性，是后续大量参数高效持续学习方法的理论基石。Sparse Memory Finetuning（Lin et al., 2025, P4）利用 Fisher 信息矩阵选择对旧任务重要的参数子集，并仅更新这些参数以整合新知识，同时冻结其余参数，结合了正则化和参数冻结的优点。FGGM（Tan et al., 2026, P13）通过两阶段范式，首先估计新数据集的 Fisher 信息并初始化掩码，然后利用 Fisher 信息引导梯度约束适配，解决了大规模 LLM 中 Fisher 计算瓶颈问题。

SAE-FD（Zhang et al., 2026, P21）引入稀疏自编码器对 LLM 内部激活进行特征分解，并在持续学习过程中应用稀疏感知的特征蒸馏，从权重空间转移到特征空间进行正则化，提供了更精细的遗忘抑制机制。SAE-Guided Activation Regularization（Ning et al., 2026, P26）利用稀疏自编码器分解激活，并基于稀疏特征的重要性进行正则化，显式建模了可塑性需求，避免了单侧抗漂移正则化导致的模型僵化。Octopus（Liu et al., 2026, P19）通过近似旧任务的梯度方向，并在新任务优化中强制新梯度与旧梯度正交，解决了传统梯度正交方法需要旧数据或旧模型快照的限制。CRAFT（Hossen et al., 2026, P18）不在参数空间更新权重，而是在低秩子空间中编辑隐藏表示，通过 KL 散度路由任务到兼容的表示组，将持续学习从参数竞争问题转化为表示组织问题。DGG（Li et al., 2025, P8）通过近似旧任务的梯度，并将其与新任务梯度融合，引导优化过程收敛到联合最优参数，解决了旧数据不可用时的优化方向偏差问题。

### 2.4 回放与模型合并

回放与模型合并路线旨在通过优化回放调度或模型合并技术整合新旧知识。Experience Replay（2017）通过维护一个有限大小的记忆缓冲区存储旧任务样本，在新任务训练时与当前数据混合进行联合优化，成为回放类持续学习方法的基础。FOREVER（Feng et al., 2026, P12）将人类艾宾浩斯遗忘曲线映射到模型时间，定义“模型日”为参数变化累积量，并据此设计回放调度，解决了传统回放策略缺乏理论指导的问题。SuRe（Hazard et al., 2025, P9）将遗忘形式化为选择失配项和整合项之和，通过惊讶度优先选择高信息量样本进行回放，从信息论角度解释了回放选择，提升了样本利用率。

COLA（Mandivarapu, 2025, P5）将每个任务的 LoRA 适配器向量化，并通过终身自编码器编码为固定大小的潜在向量，实现压缩存储和按需检索，解决了适配器库扩展带来的存储压力问题。AIMMerging（Feng et al., 2025, P1）利用训练轨迹中的学习信号和遗忘信号，动态选择合并时机，将训练过程重构为多个迭代合并周期，解决了静态合并策略无法适应任务动态变化的问题。

### 2.5 跨任务与多领域应用

跨任务与多领域应用路线旨在将 PECL 方法应用于特定垂直领域或高异构任务场景。Task-Differentiated Atomic Skill Expansion（Wang et al., 2026, P25）认为固定容量模型无法适应高度异质任务，因此引入自适应模块化容量增长，通过添加原子技能模块并路由实现专业化与共享，解决了传统方法在语义、目标和推理模式差异大时的性能退化问题。CurLL（Kalyan et al., 2025, P3）借鉴人类认知发展理论，评估 LM 在长期内整合新知识、构建复杂技能并保留先前能力的能力，提供了更贴近人类智能的评估标准。AGENTCL（Shu et al., 2026, P22）评估智能体在任务流中积累可重用经验、转移至未来环境并随记忆扩展保持鲁棒性的能力，揭示了智能体在顺序、任务受限制度下的持续学习挑战。Continual Learning Bench（Asawa et al., 2026, P23）要求系统从经验中发现潜在结构并利用其改进后续实例性能，模拟了软件工程和数据分析等真实场景。OAKS（2026, P31）包含 OAKS-BABI 和 OAKS-Novel 数据集，由动态演变的上下文块组成，评估模型在时间间隔上保持时间一致性的能力，揭示了 LLM 在长时程动态知识状态下的性能瓶颈。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

灾难性遗忘是 LLM 持续学习的主要挑战，源于新任务更新对旧任务参数表示的覆盖，这一共识在约 35 篇论文中得到共同支持。LoRA 等 PEFT 方法是 LLM 持续学习的主流技术基础，但其固定秩约束引入了子空间干扰问题，约 20 篇论文共同支持这一观点。正则化、回放和架构扩展是持续学习的三大经典范式，但在 LLM 场景下，架构扩展（如 MoE）和子空间正则化更受青睐，约 15 篇论文共同支持。任务无关推理是 LLM 持续学习部署的关键需求，要求模型在推理时自动识别任务或融合知识，约 12 篇论文共同支持。基于梯度或 Fisher 信息的稀疏子空间选择能有效定位高效用参数，从而在保持可塑性的同时增强稳定性，约 10 篇论文共同支持。现有基准主要评估分类和生成任务，但缺乏对高异质性任务流和长期知识演化的全面评估，约 8 篇论文共同支持。

### 3.2 观点分歧

知识保护的最佳空间存在参数几何与特征语义的分歧。观点 A 认为应在参数/子空间几何层面进行正交约束（如 O-LoRA, PS-LoRA, Share），计算开销低；观点 B 认为应在特征/激活语义层面进行解耦（如 SAE-FD, CRAFT, SAE-Guided），能更精细地保护知识。现有证据偏向观点 B 在高异构任务（如 TRACE）上的优势，SAE-FD 在 TRACE 上 OP 优于 O-LoRA，但观点 A 在低异构任务（Standard CL）上仍具效率优势。定输赢的实验需在相同计算预算下，对比两者在“高异构”与“低异构”任务流上的 AF 和 BWT。分歧根源在于特征空间正则化（SAE）的计算开销巨大，难以在大规模 LLM 中实时应用，且“多义性”对遗忘的贡献程度尚缺乏统一的量化指标。

容量扩展策略存在静态 MoE 与动态稀疏的分歧。观点 A 主张静态 MoE 架构（LoRAMoE, Mixtures of SubExperts），结构稳定；观点 B 主张动态稀疏子空间选择（SETA, JumpLoRA），更适应任务异质性。现有证据偏向观点 B 在高异构任务上的灵活性，SETA 在任务无关推理下建立了新基准，但观点 A 在推理速度和部署稳定性上更具优势。定输赢的实验需评估在“任务分布漂移”场景下，动态稀疏路由的准确性与静态 MoE 的鲁棒性对比。分歧根源在于动态稀疏依赖梯度统计的准确性，在数据分布偏移时可能失效，且稀疏子空间的选择缺乏理论保证。

### 3.3 其他开放问题

最紧迫的工程问题是 MoE 路由的准确性与 LoRA 合并的累积误差。现状是路由错误会导致灾难性遗忘，合并过程可能引入累积误差；关键困难在于路由网络的训练需要额外的标注数据或监督信号，且合并策略需要针对具体任务调整；研究路径包括基于训练轨迹的自适应合并和惊讶驱动的重放。最根本的研究问题是无回放条件下的长期记忆理论。现状是现有方法难以在不增加推理开销的前提下有效保留长期记忆；关键困难在于如何定义任务边界和建模记忆巩固；研究路径包括基于 SAE 的单义性特征利用和神经科学启发的遗忘曲线调度。已知—争议—未知认知图谱显示，领域在子空间冲突机制上已有共识，但在特征空间正则化的计算效率和动态稀疏路由的理论保证上存在争议，无回放条件下的长期记忆理论仍是未知领域。发展趋势是从工程优化向理论重构转变，重点关注高异构任务下的自适应容量机制和更严谨的评估基准。

## 4. 总结与展望

PECL 领域已从最初的“参数冻结”演进为“特征解耦”与“动态路由”并存的精细化阶段。核心挑战始终是如何在有限参数预算下平衡稳定性与可塑性。方法演进的主线是不断寻找更精细的知识隔离与共享机制：从子空间正交到 MoE 扩展，再到特征解耦，体现了对知识干扰机制理解的深化。当前瓶颈在于特征空间正则化的计算开销和动态稀疏路由的理论保证，以及无回放条件下的长期记忆理论缺失。

未来可能突破的方向包括：扩展至多模态与跨模态持续学习，解决视觉、语言及 3D 数据在持续适应中的分布偏移与遗忘问题，潜在路径包括层自适应专家路由和多模态梯度正交化；实现无任务边界的在线持续学习，解决真实场景中任务 ID 未知、数据流连续且边界模糊的问题，潜在路径包括基于 Fisher 几何的子空间构建和递归最小二乘路由。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，系统对比参数空间正交与特征空间解耦在高异构任务流上的 AF 和 BWT，以明确两条路线的适用边界。
