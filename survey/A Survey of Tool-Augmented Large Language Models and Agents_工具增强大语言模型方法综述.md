# A Survey of Tool-Augmented Large Language Models and Agents ｜工具增强大语言模型方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Tool-Augmented%20Large%20Language%20Models%20and%20Agents)

## 导读

工具增强大语言模型（Tool-Augmented LLMs）通过集成外部 API 与代码解释器，突破了大语言模型静态参数化知识无法获取实时信息及执行精确计算的局限。早期研究主要依赖模仿学习与基于提示的框架，通过监督微调在人工标注轨迹上训练模型调用工具，思路简洁却受制于数据标注成本高企及分布外泛化能力差。当大规模工具库与复杂多步任务暴露出行为克隆范式的瓶颈后，研究重心转向基于可验证奖励的强化学习，通过环境交互与试错机制赋予模型自主规划与错误恢复能力。各路线在泛化性、训练稳定性与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从行为克隆到策略优化的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

大语言模型在预训练阶段固化了海量世界知识，但这种静态参数化机制使其无法感知实时动态信息或执行高精度数值计算。工具增强范式通过将外部 API、搜索引擎或代码解释器接入模型推理循环，有效扩展了能力边界，成为解决这一根本局限的核心架构。然而，早期工作主要关注“能否调用”工具，问题边界局限于单轮或少量多轮交互，核心痛点在于高质量标注轨迹的稀缺与模型在未见工具上的脆弱性。

随着任务复杂度提升，问题定义经历了从“行为克隆”到“策略优化”的深刻转变。2023 至 2024 年间，ReAct 与 Toolformer 等框架确立了“思考-行动-观察”的交互范式，但监督微调（SFT）范式在分布外（OOD）任务上表现不佳，且难以处理多步依赖传播中的级联失败。2025 年成为关键转折点，研究重心转向基于可验证奖励的强化学习（RLVR），旨在通过环境反馈替代人工标注，提升模型在复杂约束下的泛化性与鲁棒性。当前，问题边界进一步扩展至真实噪声环境下的鲁棒性、工具滥用抑制及小模型高效适配，强调智能体在动态、多约束现实任务中的自主性与经济性。

子问题之间存在强依赖关系，构成了一个层层递进的技术栈。工具检索是大规模场景下的前置瓶颈，其精度直接决定后续编排的输入质量；工具编排与规划依赖检索结果，负责处理多步依赖与状态管理；强化学习训练则依赖高质量数据合成与细粒度奖励设计，以解决多步调用中的信用分配难题；小模型适配最终依赖于上述所有能力的蒸馏与效率优化，决定部署的可行性。这种依赖结构意味着，任何单一环节的改进若缺乏上下游协同，其收益将受到显著限制。

范式边界在 SFT 与 RL 的取舍中逐渐清晰。SFT 擅长模仿已知模式，训练简单且部署快速，但牺牲了泛化性，适用于封闭工具集；RL 擅长探索未知策略，能显著提升 OOD 泛化能力，但面临奖励稀疏、训练不稳定及计算成本高昂的挑战。两者并非完全替代关系，而是根据任务复杂度与数据可用性进行动态组合，形成了当前“SFT 冷启动 + RL 精调”或“纯 RL 从零训练”的多元技术路线。

从约束演化史来看，2023 年的 Toolformer 与 ReAct 奠定了工具调用作为生成过程一部分的理论基础，确立了提示工程与自监督学习的主线。2024 年，BFCL 等标准化基准的出现揭示了模型在长程依赖与错误恢复上的不足，推动了针对多步编排的专项研究。2025 年，Tool-R1 与 Tool Zero 证明 RL 可替代 SFT 冷启动，TOUCAN 等真实 MCP 环境数据合成框架为大规模智能体后训练提供了高质量语料。2026 年，研究进入精细化阶段，CoHyDE、DIVE 等方法在检索协同训练与数据多样性控制上取得突破，领域形态从单一模型优化转向系统级协同。

**如果用一个核心问题概括该领域，那便是：如何在动态、大规模且充满噪声的工具生态中，构建具备自主规划、高效检索及鲁棒恢复能力的智能体，以最小化计算成本实现复杂现实任务的端到端解决。**

## 2. 方法体系

- 2023：ReAct——奠定该领域方法基线

- 2024：BFCL (Berkeley Function-Calling Leaderboard)——推进标准化评估

- 2025：Tool-R1——样本高效强化学习

- 2025：Tool Zero——纯强化学习从零训练

- 2026：CoHyDE——迭代协同训练检索

- 2026：DIVE——多样化任务合成

这条时间线勾勒了该领域方法演进的代表性节点：从 2023 年的 ReAct 奠定该领域方法基线，经 2024 年 BFCL (Berkeley Function-Calling Leaderboard) 的推进，到 2026 年的 Tool Zero 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 工具强化学习训练

工具强化学习训练路线的起源可追溯至对 SFT 泛化瓶颈的反思。早期工作如 ReAct（Yao et al., 2023）虽确立了交互范式，但依赖人工标注轨迹，导致模型在 OOD 任务上表现脆弱。2025 年，Tool-R1（Zhang et al., 2025, P1）提出样本高效强化学习框架，通过损失掩码机制区分模型生成 token 与工具返回 token，确保信用分配仅作用于模型决策部分，解决了多步交互中奖励信号稀疏和噪声干扰问题。这一设计为后续智能体 RL 训练提供了标准化的掩码处理范式，标志着从行为克隆向策略优化的关键转折。

在此基础上，Tool Zero（Zeng et al., 2025, P13）进一步摒弃了 SFT 冷启动阶段，提出纯强化学习训练范式。其核心在于动态泛化引导奖励策略（GG-GRPO），通过渐进式奖励切换机制，引导模型从模仿已知任务模式逐步过渡到探索未知任务上下文。该方法证明了无需人工标注轨迹即可构建具有强泛化能力的智能体，确立了 RL 作为工具使用能力核心驱动力的地位。然而，其代价是引入了额外的计算成本，特别是在大模型 RL 训练阶段，对资源受限硬件的可扩展性构成挑战。

针对多步调用中的信用分配难题，TRM（ICLR 2026, P53）提出细粒度工具调用奖励模型，提供每次工具调用的效用信号，而非仅评估最终答案的正确性。该方法通过轮次级信用分配机制，将 TRM 的输出与 GRPO 算法结合，增强了对具体工具调用步骤的监督。REST（ICLR 2026, P54）则引入课程学习机制，根据训练过程中熵的变化动态调整不同 token 类别的权重，解决了传统 RL 方法中工具调用 token 与推理 token 权重固定导致的收敛不稳定问题。这些方法共同推动了过程奖励模型在工具使用场景的应用，证明了细粒度监督对于提升多步工具调用鲁棒性的关键作用。

此外，EAPO（Chen et al., 2026, P40）联合优化难度感知奖励整形与置信度感知 token 级重加权，以缓解智能体强化学习中的工具滥用问题。PhGPO（Li et al., 2026, P26）受蚁群优化启发，将历史成功工具转换显式地积累为工具转换图上的“信息素”，形成自适应的监督信号，提升了长程工具使用任务的规划能力。RODS（Fang et al., 2026, P46）提出奖励驱动的在线数据合成框架，根据模型当前的进度奖励动态生成新的训练任务，实现了训练数据与模型能力的动态对齐。PROVE（Abdelaziz et al., 2026, P41）构建五部分奖励函数，将工具使用质量分解为有效性、依赖顺序覆盖等细粒度维度，通过程序化奖励计算无需外部裁判模型即可精确评估每个步骤的正确性。这些方法在泛化性、训练稳定性与计算成本之间做出了不同取舍，与检索增强路线形成互补，共同构成了当前智能体训练的核心技术栈。

### 2.2 工具检索与选择

工具检索与选择路线旨在解决大规模工具库中的语义鸿沟与认知过载问题。早期语义检索方法受限于查询与工具描述的风格不匹配，CoHyDE（Senthil et al., 2026, P39）提出迭代协同训练框架，联合优化 LLM 查询重写器与稠密检索编码器，通过偏好对齐（DPO）使重写器生成更符合工具目录风格的查询。该方法打破了传统检索中冻结 LLM 进行查询扩展的局限，实现了生成与检索的端到端联合优化，提升了大规模工具库中的检索精度。

针对单步稠密检索器在复杂请求下的失败问题，TOOLQP（Fang and Glass, 2026, P18）提出轻量级多步工具检索框架，将检索建模为迭代查询规划过程。该方法将用户指令分解为子任务，并动态生成查询与检索器交互，以桥接抽象用户目标与技术文档之间的语义鸿沟。其代价是增加了推理延迟，因为需要多次查询生成与检索交互，但显著提升了复杂工具组合场景下的检索鲁棒性。

为解决语义相似性检索无法捕捉工具功能可行性的“语义-功能差距”问题，GRETEL（Wu et al., 2025, P7）提出目标驱动的检索与执行试验框架。该方法通过沙箱化的计划-执行-评估循环，对语义检索到的候选工具进行实证验证，生成基于执行的证据以区分真正可用的工具。CMTF（Babu and Iyer, 2026, P42）则提出基于因果最小工具过滤的轻量级无训练方法，基于工具的前置条件、效果、任务状态和目标状态，动态过滤出因果上充分的最小工具集，避免了将所有工具暴露给模型导致的干扰。Semantic Tool Discovery（Mudunuri et al., 2026, P29）使用稠密嵌入索引 MCP 工具，捕捉工具能力与用户意图之间的语义关系，实现了工具发现的自动化和动态化。

ToolSense（Hathidara et al., 2026, P44）提出诊断框架，用于审计 LLM 中的参数化工具知识，揭示了基于生成式检索的工具选择机制的局限性。DTDR（Patel et al., 2025, P17）构建工具依赖图，并在检索时根据查询动态提取最小依赖子图，仅将相关工具描述注入 LLM 上下文，提升了小模型在严格内存和延迟预算下的性能。SkillGraph（Liu and Li, 2026, P35）从大规模轨迹数据中预训练图基础模型，将工具序列推荐建模为图上的路径搜索问题，实现了轻量级的实时推荐。这些方法在检索精度、功能可行性与计算效率之间做出了不同取舍，与强化学习训练路线形成互补，为智能体提供了高质量的工具输入。

### 2.3 工具编排与规划

工具编排与规划路线聚焦于复杂任务下的多工具协调与依赖关系建模。OrchDAG（Lu et al., 2025, P10）提出基于计划 DAG 的复杂工具编排框架，将工具执行计划建模为 DAG，支持独立工具的并行执行，并在后续轮次中根据执行结果和新查询进行重规划。该方法突破了传统线性序列规划的局限，显著提升了多工具协作的效率，但增加了规划阶段的计算开销。

Beyond ReAct（Wei et al., 2025, P14）提出以规划器为中心的复杂工具增强 LLM 推理框架，将规划与执行解耦，由专门的规划器生成高层任务分解计划，执行器负责具体工具调用，并通过反馈循环进行修正。该方法引入了显式的高层规划步骤，增强了模型对长程任务的结构化理解能力，但增加了系统复杂度。CoCoDA（Yu et al., 2026, P37）提出共进化组合 DAG 框架，将工具库视为可进化的外部程序记忆，通过共进化机制使工具库结构与规划器的检索和训练需求保持一致，提升了小语言模型的工具复用能力。

CAHL（Yang et al., 2026, P43）提出能力对齐的层级学习框架，联合优化高层规划器和低层执行器的策略，通过可验证奖励强化学习（RLVR）鼓励规划器匹配指令粒度与执行器能力。Graduated Rewards（Jiayang et al., 2026, P31）提出基于约束数据合成和渐进奖励的多步工具编排训练方法，通过合成包含依赖逻辑的训练数据，并使用渐进奖励函数逐步引导模型学习依赖传播。IACM-RL（Zhu et al., 2026, P48）引入信念状态管理，通过追踪用户意图的修改、中断、澄清、积累和链式变化，动态调整上下文和工具调用策略，提升了智能体在动态交互中的适应性。

PACT（Du et al., 2026, P45）提出特权轨迹协同训练框架，在训练时使用专家轨迹作为特权优化信号，而在推理时仅使用提示，通过解耦轨迹探索与专家指导来提升性能。UCT（Shen et al., 2026, P23）提出无训练经验复用框架，从 LLM 推理轨迹中提取隐含的问题解决能力，并将其蒸馏为可复用的工具资产，使智能体能够动态扩展工具库。这些方法在规划复杂度、执行效率与动态适应性之间做出了不同取舍，与检索增强路线形成互补，为智能体提供了结构化的执行策略。

### 2.4 工具数据合成

工具数据合成路线旨在解决真实数据稀缺问题，通过自动化管线生成可验证的训练样本。TOUCAN（Xu et al., 2025, P4）提出从真实 MCP 环境合成大规模工具智能体数据的框架，通过自动化管线，结合 LLM 和智能体框架，在远程 MCP 服务器上执行任务，生成包含工具调用、执行反馈和最终响应的完整轨迹。该方法利用了真实 MCP 环境，确保了数据的真实性和复杂性，超越了合成环境的局限。

DIVE（Chen et al., 2026, P27）提出证据驱动的多样化任务合成方法，通过可控地扩展工具池覆盖率和工具集多样性，生成具有结构多样性的智能体任务，以模拟真实世界的开放多样性。ToolGrad（ACL-Findings 2026, P55）提出基于文本“梯度”的高效工具使用数据集生成方法，利用 LLM 生成的文本反馈作为“梯度”，指导智能体快速收敛到正确的工具使用解决方案，显著降低了数据生成的 API 成本和探索时间。

RODS Data Synthesis（Fang et al., 2026, P46）提出奖励驱动的在线数据合成策略，根据模型当前的进度奖励动态生成新的训练任务，将数据空间划分为已掌握、活跃和边界区域，并重点在边界区域生成新样本。ToolForge（Chen et al., 2025, P16）提出无需真实世界 API 的多跳搜索数据合成管线，通过知识空间准备、生成式交互建模和多层验证，合成包含多跳依赖关系的搜索轨迹。GEM-Synthesizer（ACL 2026, P51）提出从文本中合成工具使用轨迹的方法，从文本中识别包含多步工作流的程序性片段，并将其转化为工具使用任务。

COVERT（Xu et al., 2026, P34）提出可控且可验证的工具使用数据合成框架，通过注入噪声、干扰和故障，生成具有挑战性的训练样本，提升了工具使用数据的鲁棒性。FunReason-MT（Xu et al., 2025, P9）提出面向真实世界多轮工具使用的高级数据合成解决方案，通过环境-API 图交互收集多样化轨迹，并使用高级工具-查询合成生成具有逻辑依赖的多轮任务。这些方法在数据真实性、多样性与生成成本之间做出了不同取舍，为强化学习训练提供了高质量语料支持。

### 2.5 小模型工具适配

小模型工具适配路线旨在将工具调用能力蒸馏至小语言模型（SLM）或优化其部署效率。MENTOR（Choi et al., 2025, P8）提出基于教师优化奖励的强化学习框架，利用教师模型生成参考推理轨迹，并通过组相对策略优化（GRPO）结合学生模型的探索性 rollout，优化学生策略。该方法引入了教师优化奖励，超越了传统 SFT 蒸馏的局限，提升了小模型在工具调用上的泛化能力。

STAR（Ni et al., 2026, P24）提出相似度引导的教师辅助精炼框架，结合约束知识蒸馏（CKD）和拓扑 KL 散度，抑制小模型在函数调用中的自信错误预测。Search Agent Distillation（Liu et al., 2026, P32）提出将搜索智能体能力蒸馏至 SLM 的方法，通过蒸馏大模型的搜索策略和推理轨迹，使 SLM 能够独立执行搜索和回答。Targeted Fine-tuning for SLMs（Jhandi et al., 2025, P15）提出针对 SLM 的定向微调方法，通过少量人工监督使 SLM 在智能体工具调用任务上达到与大模型相当的性能。

Meta-Tool（Kumar, 2026, P36）提出高效少样本工具适配方法，通过超网络生成 LoRA 权重，结合精心设计的少样本提示，实现 SLM 对领域特定工具的快速适配。P-C-G Architecture（Jeon et al., 2025, P2）提出计划-调用-生成架构，通过角色分离设计，将计划、调用和生成任务分配给不同的模块，减少 SLM 在单一任务上的认知负荷。SRM Instruction Following（Taheri et al., 2026, P50）提出将小推理模型（SRM）作为指令跟随者用于函数调用的方法，解耦工具选择逻辑与主生成模型，提升了 SRM 在工具选择上的稳定性和效率。

Interfaze Task-Specific Small Models（Khurdula et al., 2026, P25）提出基于任务特定小模型的 AI 系统架构，将复杂任务分解为多个子任务，每个子任务由专门的小模型处理，并通过 LLM 进行上下文推理和协调。这些方法在通用性、部署成本与任务特定性能之间做出了不同取舍，为边缘端智能体应用提供了低成本、高可靠性的解决方案。

### 2.6 跨任务与多领域应用

工具增强 LLM 的应用已从单一领域扩展至软件开发、学术研究、金融分析等多个垂直领域。Toolathlon（Li et al., 2025, P12）构建了涵盖多样化真实领域的长程任务基准，强调在复杂环境状态下的端到端执行能力。WildToolBench（Yu et al., 2026, P33）针对野外工具使用场景，引入会话准确性指标，评估智能体在多轮交互中处理噪声输入、工具故障和动态意图变化的能力。CCTU（Ye et al., 2026, P28）针对复杂约束下的工具使用，引入约束满足率（CSR）和解决率（SR）指标，评估模型在满足所有约束的同时解决子查询的能力。

Difficulty-Graded Benchmark（Yu et al., 2026, P49）针对复杂参数生成，引入探针引导训练，通过逻辑回归探针预测参数正确性，并据此调整训练策略。ToolFailBench（Soni, 2026, P47）针对工具使用失败，引入细粒度失败分类，通过确定性规则分类器和 LLM 裁判，对每个轨迹进行失败模式标注。MCP-Atlas（Bandi et al., 2026, P22）针对真实 MCP 服务器，引入原子可验证声明评估，将最终答案分解为多个独立可验证的声明，实现细粒度部分信用评分。

Sim-to-Real Benchmark（Zhou et al., 2026, P38）针对模拟到真实的域差距，引入域随机化强化学习配方，通过在模拟环境中注入噪声，提升智能体在真实环境中的鲁棒性。ToolPRMBench（Li et al., 2026, P19）针对工具使用智能体过程奖励模型，构建包含步骤级和智能体级评估的基准，通过轨迹采样、数据验证和过滤，训练高质量的 PRM。这些基准与评估方法在任务复杂度、噪声鲁棒性与细粒度诊断之间做出了不同取舍，为跨任务与多领域应用提供了标准化的评估体系。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

外部工具是突破 LLM 静态知识局限、获取实时信息及执行精确计算的关键途径，这一共识在约 103 篇论文中得到共同支持。从监督微调（SFT）向基于可验证奖励的强化学习（RLVR）转变是提升工具使用泛化性和鲁棒性的主要趋势，约 40 篇论文共同支持这一观点。多步工具调用中的信用分配问题需要通过过程奖励模型或细粒度奖励设计来解决，仅依赖最终结果奖励效果有限，约 25 篇论文共同支持。大规模工具库场景下，工具检索是决定智能体性能上限的关键瓶颈，需结合语义匹配与功能验证，约 30 篇论文共同支持。小语言模型（SLM）通过针对性微调或蒸馏，在特定工具调用任务上可逼近大模型性能，是降低部署成本的有效方案，约 20 篇论文共同支持。工具滥用（过度调用）是 RL 训练中的常见副作用，需通过效率感知奖励或边界控制机制进行抑制，约 15 篇论文共同支持。Model Context Protocol (MCP) 等标准化协议正在成为工具集成的基础设施，推动工具生态的规模化发展，约 15 篇论文共同支持。多轮交互中的状态维护和依赖管理是复杂任务成功的核心，需要专门的规划框架或图结构支持，约 20 篇论文共同支持。

### 3.2 观点分歧

奖励信号的粒度是领域内的核心分歧之一。观点 A 认为结果奖励足够，因为最终任务成功是最终目标，过程奖励可能引入噪声；观点 B 认为过程奖励必要，因为多步任务中信用分配稀疏，细粒度信号能稳定训练并提升鲁棒性（支撑证据：P53、P41）。现有证据偏向过程奖励，TRM 和 PROVE 在多步编排任务上显著优于基线，但过程奖励模型训练成本高，且在简单任务上可能过度优化。这一分歧的背后，是另一个更根本的争论：小模型工具能力获取路径。观点 A 认为蒸馏是通用路径，通过教师模型传递策略，保持小模型的通用性（支撑证据：P8、P24）；观点 B 认为定向微调在特定任务上更优，因为小模型参数有限，需聚焦特定领域（支撑证据：P15）。证据显示，在特定领域上，定向微调的小模型（77.55%）远超通用蒸馏模型，但在跨域任务上，蒸馏模型表现更稳定。缺乏跨域、多任务的小模型基准，使得两种路径的优劣尚未定论。

### 3.3 其他开放问题

工具检索的核心机制是另一个关键开放问题。观点 A 认为语义相似度是基础，通过优化嵌入和重写即可解决大部分检索问题（支撑证据：P39、P29）；观点 B 认为语义相关不等于功能可行，必须引入执行验证或因果过滤（支撑证据：P7、P42）。GRETEL 和 CMTF 在包含干扰工具的场景中显著提升了选择准确率，但执行验证和因果过滤的计算开销大，难以在实时系统中大规模部署。缺乏轻量级的功能可行性评估方法，使得“语义+功能”的混合检索策略尚未成熟。已知—争议—未知认知图谱显示，领域在 RLVR 范式、检索瓶颈、小模型适配上达成高度共识，但在奖励粒度、小模型路径、检索机制上存在显著分歧，未来突破将依赖于在动态、噪声环境中实现高效、鲁棒且经济的自主决策。

## 4. 总结与展望

工具增强 LLM 领域正经历从静态知识补全向动态自主智能体转型的关键跃迁。核心矛盾从“能力缺失”转变为“泛化与效率的平衡”，RLVR 不仅是训练技巧，更是解决多步信用分配和 OOD 泛化的结构性方案。MCP 等标准化协议正在重塑工具生态，使“检索”与“鲁棒性”成为新的核心瓶颈。当前研究面临的核心挑战是：在工具爆炸和噪声环境下，如何保证智能体的泛化性、鲁棒性及经济性。

未来可能突破的方向包括：提升工具使用的跨域泛化能力，使用领域无关的标准化工具接口和双组件奖励系统来促进通用推理；解决工具滥用与效率权衡，引入效率感知奖励和熵减少信号来抑制冗余调用；增强多轮长程任务的鲁棒性与状态跟踪，使用图结构规划和意图感知上下文管理来维护全局状态。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，构建跨域、多任务的小模型基准，以厘清蒸馏与定向微调在通用性与专业性之间的平衡点。
