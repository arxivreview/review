## 导读

少样本与零样本文本分类旨在消除对大规模人工标注的依赖，其核心张力在于模型泛化能力与数据稀缺性之间的结构性矛盾。早期研究依赖自然语言推理模型构建语义匹配基线，思路直观但受限于静态标签表示。随着大语言模型上下文学习能力的确立，研究重心转向提示工程，通过自然语言指令激活模型内部知识，却引入了对模板与标签顺序的高度敏感性。当大规模标签集暴露出推理延迟与混淆问题后，领域引入检索增强与共形预测，以局部精度换取全局计算成本的控制。当前，层级结构利用与混合架构成为新焦点，LLM 与专用编码器在鲁棒性与效率间形成互补格局。本综述梳理这条从语义匹配到结构化推理的因果演进链条，为读者提供一张领域认知地图。全文按问题演化、方法取舍与评测体系组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

文本分类作为自然语言处理的基础任务，长期受困于标注数据的高昂成本与领域迁移的刚性约束。传统监督学习范式假设标签集固定且数据充足，但在低资源、新领域或标签动态变化的场景下，这一假设迅速失效。零样本文本分类（Zero-Shot Text Classification, ZSC）与少样本学习（Few-Shot Learning, FSL）由此兴起，前者要求模型在未见标签上利用预训练语义进行预测，后者则通过少量示例（通常每类 1-5 个）引导模型适应新任务。两者的共同目标是将分类问题从“参数记忆”转化为“语义推理”，从而摆脱对任务特定标注数据的依赖。

问题的形式化可表述为：给定文本 $x$、标签集 $\mathcal{Y} = \{y_1, ..., y_N\}$ 及少量支持集 $\mathcal{S} = \{(x_i, y_i)\}_{i=1}^K$，模型需学习映射 $f: \mathcal{X} \times \mathcal{Y} \times \mathcal{S} \rightarrow \mathcal{Y}$。在零样本设置下 $K=0$，模型完全依赖标签语义与文本的语义对齐；在少样本设置下，$K$ 极小，模型需从有限示例中泛化。子问题间存在严格的依赖关系：标签语义歧义是基础瓶颈，它直接导致提示敏感性与混淆错误；计算成本约束了大语言模型（LLM）在大规模标签集下的直接应用，促使轻量级架构与检索增强成为必要补充；层级结构与多标签依赖则是特定复杂场景下的深层子问题，依赖于基础分类能力的提升。

范式边界在此时期逐渐清晰：微调范式依赖参数更新，适合静态封闭集；推理时范式（Inference-time Paradigm）无参数更新，依赖上下文学习（In-Context Learning, ICL）与提示工程，是当前研究的主战场。这一边界的确立源于 LLM 在指令微调后展现出的即时适应能力，使得模型无需重新训练即可处理用户定义文本分类（User-Defined Text Classification, UDTC）等动态标签场景。

约束演化史揭示了方法演变的内在逻辑。2019 年，基于自然语言推理（NLI）的 ZSC 方法利用蕴含判断捕捉文本与标签的语义关系，奠定了零样本分类的基础范式，但受限于静态标签表示。2020 年，ICL 的提出开启了提示学习时代，通过少量示例引导模型适应新任务，极大降低了数据标注成本，却引入了对示例选择的敏感性。2021 年，提示微调（Prompt Tuning）通过优化离散提示词解决参数效率问题，为后续自动化优化提供了架构基础。

2023 至 2024 年，研究重心从静态提示转向系统性优化与架构适配。自动化提示优化方法如 APE 通过采样搜索提升稳定性，而 LoRA 等参数高效微调技术使得 LLM 适配成为可能。与此同时，共形预测（Conformal Prediction, CP）的引入解决了资源效率问题，通过自适应缩减候选类别集降低 LLM 调用成本。2025 至 2026 年，领域进入鲁棒推理时框架构建阶段。BTZSC 基准揭示了不同架构在真实零样本场景下的能力差异，LOADS 与 ERGO 分别通过激活分布与错误驱动解决提示敏感性，HierPrompt 与 HiEPS 攻克层级分类难题，SALSA 则通过单遍结构化映射追求高效推理。

当前形态呈现出 LLM 与专用编码器/重排器的竞争与互补：LLM 在复杂语义推理与多语言场景下具有不可替代的优势，而专用模型在推理速度与成本上更具竞争力。领域正从“探索 LLM 潜力”向“构建鲁棒、高效、可解释的推理时分类框架”过渡，旨在平衡准确率、延迟与计算成本。

**如果用一个核心问题概括该领域，那便是：如何在无需或极少参数更新的前提下，通过推理时的语义对齐与结构化约束，实现高鲁棒性、低延迟且可解释的文本分类。**

## 2. 方法体系

- 2019：NLI-based ZSC——利用自然语言推理模型奠定零样本分类基础范式

- 2020：In-Context Learning——通过提示示例开启少样本学习时代

- 2021：Prompt Tuning——优化离散提示词解决参数效率问题

- 2023：APE——自动化提示搜索提升零样本稳定性

- 2024：CICLe——结合共形预测实现资源高效提示构建

- 2025：BTZSC——统一评估多架构零样本能力的综合基准

- 2025：LOADS——基于激活分布峰度优化标签集选择

- 2026：SALSA——单遍自回归结构化分类实现高效推理

这条时间线勾勒了该领域方法演进的代表性节点：从 2019 年的 NLI-based ZSC 奠定该领域方法基线，经 2020 年 In-Context Learning 的推进，到 2026 年的 SALSA 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 零样本基准评测

零样本基准评测的起源在于早期方法缺乏统一的评估协议，导致不同架构间的性能比较存在偏差。2019 年，基于 NLI 的方法将分类转化为蕴含判断，确立了语义匹配的基础范式，但其性能受限于静态标签表示。随着 LLM 的兴起，评估需求从单一模型转向跨架构比较，以揭示不同技术路线在真实零样本场景下的能力差异。

BTZSC（Aarab, 2026, P14）构建了包含 22 个公开数据集的综合基准，系统性评估 NLI 交叉编码器、嵌入模型、重排序器及指令微调 LLM 四类架构。该基准的核心创新在于采用一致的零样本分类协议，避免了以往通过监督探针或微调掩盖真实零样本能力的问题。通过对比 38 个检查点，BTZSC 揭示了现代重排序器在宏观 F1 分数上的领先地位，以及嵌入模型在精度与延迟之间的最佳权衡。这一工作填补了跨架构零样本能力比较的空白，为后续研究提供了公平且可复现的评估平台。

针对特定语言场景，South Slavic ZSC Evaluation（Kuzman Pungeršek et al., 2025, P2）构建了涵盖议会演讲情感分类、新闻主题分类及自动体裁识别的多领域基准。该研究重点比较了微调 BERT 类模型与零样本提示 LLM 的性能差异，揭示了闭源 LLM 如 GPT-4o 在零样本设置下的优势，以及开源模型如 Gemma 3 在特定任务上的竞争力。Bengali LLM Classification Framework（Hoque et al., 2026, P6）则针对孟加拉语新闻文本分类，利用 LLaMA 3.1 等模型通过提示工程实现九类分类，展示了大语言模型在低资源语言领域分类任务中的潜力与局限。这些基准共同推动了零样本文本理解领域的标准化进程，其核心取舍在于以评估的全面性换取对单一模型性能的深度挖掘，为后续方法优化提供了明确的性能参照系。

### 2.2 提示工程优化

提示工程优化的起源在于手动设计提示模板费时且效果有限，不同任务对提示格式高度敏感。2021 年，Prompt Tuning 通过优化离散提示词解决了参数效率问题，但仍未解决提示选择的盲目性。2023 年，APE 通过 LLM 采样生成指令候选并利用准确性信号进行搜索，实现了提示词的自动化优化，显著提升了零样本和少样本分类的稳定性。

LOADS（2025, P18）提出了一种基于激活分布峰度的标签集优化方法，旨在解决零样本上下文学习中提示标签选项对模型性能敏感的问题。该方法通过分析 LLM 解码器前馈网络中神经元的激活情况，发现具有最优标签集的提示会激活较少的离群神经元，从而利用峰度指标从候选标签集中筛选出最优组合。LOADS 仅需 100 个无标签验证样本即可稳定有效地选择最优标签集，并展示了跨数据集和语言的迁移能力。其核心创新在于将神经激活分布统计特性与提示优化相结合，提供了一种无需梯度搜索的高效后验选择机制，放弃了通用性换取了任务特异性下的稳定性。

ERGO（Cui et al., 2026, P10）提出了一种错误驱动的迭代提示优化方法，通过在全训练集上进行迭代反馈生成可解释且可迁移的决策规则。该方法从最小指令开始，每轮迭代中向 LLM 提供正确和错误分类的示例，要求模型诊断混淆原因并处方具体的决策规则，从而重写整个提示模板。与探索式搜索方法不同，ERGO 专注于从错误中学习可泛化的规则，揭示了不同提示优化范式在特定任务类型上的互补性，为提示优化提供了可解释性维度。CICLe（Pantelidis et al., 2025, P4）则结合传统基础分类器与保形预测，自适应地缩减候选类别集并选择少样本示例，实现了资源高效的提示构建。Confusion-Aware Retrieval（Gupta et al., 2026, P12）基于混淆矩阵分析生成成对消歧规则，并在推理时注入领域知识，解决了零样本 LLM 在语义相似标签间区分能力不足的问题。这些方法共同表明，提示优化已从静态设计转向动态、错误驱动的自动化过程，其核心取舍在于以离线优化成本换取推理时的鲁棒性与可解释性。

### 2.3 层级分类方法

层级分类方法的起源在于传统 ZSC 方法常将层级分类简化为独立扁平分类，忽略了标签间的结构依赖。2025 年，随着 LLM 能力的提升，研究者开始探索如何利用其生成与理解能力增强层级结构理解。HierPrompt（2025, P16）提出了一种利用 LLM 增强原型的零样本层级文本分类方法，旨在解决类别名称缺乏代表性和层级结构利用缺失的问题。该方法设计了层级感知提示，引导 LLM 对类别名称进行上下文化处理，并生成具有风格多样性的示例文本，从而构建更丰富的类别原型。通过最大相似度传播技术，HierPrompt 在分类时不仅考虑当前层级的相似度，还利用层级传递性将低层级的语义相关性传播至父类别，确保层级依赖关系的充分利用。

HiEPS（2025, P17）提出了一种集成多种提示策略的零样本层级文本分类框架，旨在解决 LLM 在层级分类任务中的不稳定性问题。该方法通过设计不同的提示策略获取多样化的分类结果，利用这些策略对标签层级的不同解读实现优势互补。核心创新在于引入路径有效投票机制，通过计算标签路径的频率得分来选择最可信的有效路径，而非简单的多数投票，从而确保预测结果的可靠性和层级一致性。LLM Ensemble Categorization（Kamen and Kamen, 2025, P3）则基于集体决策理论，将多个独立的 LLM 视为专家，通过投票、评分和排名聚合它们的分类结果，生成最终的共识决策。这些方法共同证明了集成策略在处理层级语义歧义时的有效性，其核心取舍在于以多次 LLM 调用的计算开销换取层级结构的一致性与鲁棒性，与扁平分类方法形成互补，适用于复杂分类法场景。

### 2.4 少样本数据增强

少样本数据增强的起源在于 LLM 生成的合成数据可能存在语义偏差或几何分布异常，直接用于训练可能导致过拟合或性能下降。2025 年，Curate-Train-Refine（Maheshwari and El Haddad, 2026, P7）提出了一种闭环代理框架，利用 LLM 作为数据策展人，通过观察分类器错误并合成针对性训练数据来迭代优化模型性能。该方法实例化了一个 ReAct 风格代理，交替执行规划与工具调用，其中工具包括分类器训练与评估接口，返回详细的诊断信息如混淆矩阵和错误追踪。代理根据分析结果生成多样化的候选训练批次，约束包括类别平衡、去重和语义重叠控制，从而确保合成数据的质量。

Geometric Filtering（Schindler and Ruz, 2026, P11）提出了一种结合 LLM 生成与嵌入空间几何过滤的少样本文本分类数据增强方法，旨在解决 LLM 生成样本在表示空间中几何结构缺失的问题。该方法首先利用 LLM 生成语法正确且语义合理的合成文本，随后在嵌入空间中应用几何过滤器评估样本质量，包括软加权和二元筛选两种机制。其核心创新在于引入了定量后生成验证，确保合成样本不仅语义连贯，且在分类器操作的表示空间中具有正确的几何分布。Sequence-to-Set T5 Chain（2025, P13）则将多标签文本分类建模为序列到集合预测，利用 T5 编码器-解码器架构通过三阶段训练程序联合嵌入文本和标签，通过单一链解码捕捉标签依赖关系，避免了传统分类器链的顺序偏差。这些方法共同表明，数据增强已从盲目生成转向质量控制的闭环过程，其核心取舍在于以训练迭代复杂度换取少样本场景下的泛化能力与数据质量。

### 2.5 少样本元学习

少样本元学习的起源在于随机支撑样本导致的预测不一致问题，以及模型对表面线索的过度依赖。2022 年，Chain-of-Thought 通过引导模型生成中间推理步骤，提升了大语言模型在复杂逻辑任务中的泛化能力，为少样本开放集分类中的推理机制研究提供了关键方法论。LDS-PN（Gao et al., 2026, P8）提出了一种标签引导距离缩放的元学习方法，旨在解决少样本分类中随机支撑样本导致的预测不一致问题。该方法在测试阶段利用标签语义信息，将支撑样本拉近对应类别的中心，从而减少因支撑样本位于类分布边界而导致的误分类。其核心模块包括标签引导距离缩放训练阶段和测试阶段的标签引导缩放器，通过最大化正确分类概率和对比损失来优化样本表示。

Reasoning-Aware Decomposition（2025, P15）提出了一种基于推理感知分解的少样本开放集分类方法，旨在区分 LLM 的真实推理与表面线索记忆。该方法利用链式思维提示引导模型进行显式推理，并通过高斯过程拟合 OOD 对数概率分布，结合 KL 散度检测分布内和分布外数据。其核心创新在于引入生成流网络（GFN）进行对比训练，通过 Wasserstein 插值调整奖励偏移，鼓励模型探索更广泛的推理路径，防止模型坍缩到少数推理链。这些方法共同表明，元学习已从简单的原型计算转向语义引导与推理机制的深度融合，其核心取舍在于以模型复杂度换取对未见类别的识别能力与开放集检测的鲁棒性，与数据增强方法形成互补，前者优化表示空间，后者优化训练数据。

### 2.6 LLM 分类架构

LLM 分类架构的起源在于 LLM 自回归生成速度慢，难以用于大规模实时分类，且对动态标签集的支持不足。2023 年，LoRA 通过低秩分解矩阵实现参数高效微调，大幅减少了可训练参数量，使得在有限数据场景下对大语言模型进行高效适配成为可能。SALSA（Berdichevsky et al., 2025, P1）提出了一种单遍自回归 LLM 结构化分类架构，旨在通过结构化提示映射和 Logit 分析实现高效文本分类。该方法将每个类别映射到唯一的单 Token 表示，并在提示中指定固定的前缀和后缀元素，通过单次前向传播提取占位符 Token 的 Logits。随后，基于提示映射过滤 Logits 并通过 Softmax 归一化得到类别概率分布，最终选择概率最高的类别作为预测结果。

Soft Contextualized Encoder（Maheshwari and Raina, 2026, P5）提出了一种用于用户定义文本分类（UDTC）的软上下文编码器架构，旨在解决标签集在推理时动态变化且语义结构不同的问题。该方法采用双模型结构，包括一个冻结的预训练嵌入模型和一个可训练的 Transformer 编码器，其中编码器不使用位置编码以确保排列不变性。输入文本通过嵌入模型生成查询向量，标签通过 Token 嵌入平均池化生成初始向量，两者共同输入编码器进行上下文化处理。通过查询-标签相似度点积和 Softmax 函数生成概率分布，模型能够根据当前标签集动态调整分类决策。这些方法共同表明，LLM 分类架构已从通用生成转向结构化、高效的专用设计，其核心取舍在于以生成灵活性换取推理速度与动态标签支持的鲁棒性，与提示优化方法形成互补，前者优化模型结构，后者优化输入接口。

| 少样本数据增强 | 闭环代理、几何过滤 | 训练迭代复杂度 | 数据质量、泛化能力 | Curate-Train-Refine, Geometric Filtering | 数据稀缺、合成数据质量差场景 |
| 少样本元学习 | 标签引导距离缩放、推理感知分解 | 模型复杂度 | 未见类别识别、开放集检测 | LDS-PN, Reasoning-Aware Decomposition | 少样本、开放集、推理机制研究 |
| LLM 分类架构 | 单遍结构化映射、软上下文编码 | 生成灵活性 | 推理速度、动态标签支持 | SALSA, Soft Contextualized Encoder | 实时应用、动态标签、低延迟场景 |

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLM 在零样本和少样本文本分类中展现出强大能力，但在特定领域或复杂层级任务中，其性能仍可能落后于经过微调的专用模型或结合检索的混合方法。这一共识在 BTZSC 基准上得到验证：重排序器（ModernBERT）的 80.0 Macro-F1 显著高于 NLI 交叉编码器（BART-NLI）的 57.42，表明专用架构在标准基准上具有优势（支撑证据：P14）。然而，在低资源语言场景下，闭源 LLM 如 GPT-4o 在 South Slavic ZSC 中表现优于开源模型，揭示了 LLM 在跨语言迁移中的不可替代性（支撑证据：P2）。与此相关的另一个共识是提示工程对分类性能有显著影响，优化提示策略是提升 LLM 分类效果的关键手段。LOADS 通过激活分布峰度优化标签集，仅需 100 个无标签样本即可稳定提升性能，证明了提示优化的有效性（支撑证据：P18）。

### 3.2 观点分歧

LLM 直接调用与专用编码器/重排器的竞争是领域核心分歧。观点 A 认为 LLM 在复杂语义推理、多语言支持和动态标签场景下具有不可替代的优势，如 GPT-4o 在 South Slavic ZSC 中的表现；观点 B 认为专用编码器/重排器在 Macro-F1、推理速度和成本上更具优势，如 ModernBERT Reranker 在 BTZSC 中的 80.0 Macro-F1。现有证据偏向观点 B 在标准基准上的性能，但观点 A 在低资源语言和复杂层级任务中表现更优。分歧根源在于缺乏统一的“性能-成本-鲁棒性”多维评估框架，且 LLM 成本未完全纳入比较。这一分歧的背后，是生成式提示优化与判别式检索增强的争论。ERGO 通过错误驱动生成可解释规则，提升了稳定性和可审计性；Confusion-Aware Retrieval 通过混淆矩阵分析注入领域知识，在细粒度分类上更稳定且高效。现有证据显示两者在不同任务上各有优势，互补性大于竞争性，分歧根源在于缺乏统一的“可解释性-准确率”权衡评估指标。

### 3.3 其他开放问题

最紧迫的工程问题是计算效率与推理速度优化。LLM 推理开销大，尤其在大规模标签集或高频调用场景下，当前研究尝试通过共形预测、检索缩小候选集或集成小模型来降低对大模型的依赖。关键困难在于 LLM 的自回归生成机制和长上下文处理，研究路径包括开发轻量级分类头（如 SALSA 的单 token 分类）、使用蒸馏技术将 LLM 知识迁移到小模型，以及优化提示长度和示例选择。最根本的研究问题是开放集与未知类别检测。现有方法主要关注封闭集分类，难以处理训练时未见的类别，关键困难在于区分已知类别和未知类别，以及避免幻觉。研究路径包括使用推理感知分解（如 Reasoning-Aware Decomposition）结合 Wasserstein-GFN 进行分布外检测，以及引入不确定性估计机制。已知的是 LLM 在语义理解上的优势，争议的是 LLM 与专用架构的性能边界，未知的是开放集检测的理论机制与提示敏感性的内在原因。发展趋势将向“自动化、鲁棒、高效”方向发展，LLM 与专用模型的互补将成为主流。

## 4. 总结与展望

该领域的核心矛盾在于模型泛化能力与数据稀缺性之间的结构性张力，以及 LLM 强语义理解能力与高计算成本之间的冲突。从 NLI-based ZSC 到 ICL，再到自动化提示优化与混合架构，研究路线不断演进，但核心瓶颈始终是推理时的语义对齐与结构化约束的平衡。当前形态呈现出 LLM 与专用编码器/重排器的竞争与互补，旨在平衡准确率、延迟与计算成本。

未来可能突破的方向包括：多语言扩展与低资源语言支持，通过开发多语言专用 LLM 和利用 LLM 进行数据增强解决预训练语料覆盖不足问题；计算效率与推理速度优化，通过轻量级分类头和蒸馏技术降低 LLM 依赖；层级分类与复杂分类法处理，通过层级感知提示和集成策略提升结构一致性。对进入者最值得做的一件事是构建统一的“性能-成本-鲁棒性”多维评估框架，以解决现有评测体系中方法贡献与骨干网络贡献区分不清的问题，为方法比较提供公平基准。
