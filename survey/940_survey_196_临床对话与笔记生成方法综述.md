# A Survey of Clinical Dialogue and Note Generation with LLMs ｜临床对话与笔记生成方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Clinical%20Dialogue%20and%20Note%20Generation%20with%20LLMs)

## 导读

临床对话与笔记生成旨在利用大语言模型（LLM）将非结构化医患交互转化为结构化电子健康记录（EHR），其核心价值在于缓解医生文档负担与数据利用不足之间的张力。早期研究依赖规则系统与传统自然语言处理模型，受限于对上下文、否定及时序关系的处理能力，难以满足临床安全要求。当 2023 年 LLM 引入后，研究范式从“信息提取”转向“受控生成”，核心矛盾变为如何在保持语言流畅性的同时确保事实准确性。幻觉风险促使研究者引入检索增强生成（RAG）与基于声明的验证机制，用外部证据约束模型输出。各路线在事实接地、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

临床 AI 的兴起源于医生文档负担过重与 EHR 非结构化数据利用不足的矛盾。早期目标是通过自然语言处理技术实现从非结构化文本到结构化信息的自动提取，以支持下游临床决策。然而，传统规则系统和浅层语义模型受限于对复杂临床语境、否定关系及时序逻辑的处理能力，难以满足临床场景对安全性的零容忍要求。这一矛盾在 2018-2022 年间逐渐凸显，研究重心聚焦于临床实体识别与关系抽取的准确性，评估主要依赖静态问答基准（如 MedQA），但此类基准无法反映真实临床动态交互过程。

2023-2024 年是关键转折期，LLM 的引入实现了从“提取”到“生成”的范式转变。问题定义从静态知识储备评估重构为动态交互生成，核心挑战变为如何在保持语言流畅性的同时确保临床事实的准确性。此时，合成数据框架（如 NoteChat）解决了隐私与数据稀缺问题，使大规模训练成为可能。然而，通用 LLM 倾向于补全信息而非暴露不确定性，导致生成的临床笔记常包含无依据的医疗建议或错误诊断，即幻觉问题。这一风险促使研究重心从单纯的语言流畅性转向事实准确性、临床完整性及安全性。

子问题呈现强依赖关系：事实准确性（幻觉抑制）是临床部署的前提，依赖于评估标准的标准化（从 BLEU/ROUGE 转向 Claim-level 验证）；长上下文一致性依赖于数据合成技术（纵向合成笔记）和检索增强（RAG）对历史信息的支撑；隐私保护与数据稀缺是底层约束，驱动了合成数据与本地小模型部署的研究。核心概念形成因果链：幻觉（风险）→ 声明验证（机制）→ 过程监督（优化）→ 可信部署（目标）。SOAP 笔记作为标准化临床记录格式，成为核心输出目标，其结构化特性有助于下游工作流集成。

约束演化史揭示了方法如何因应约束变化而演变。2016-2018 年，GAN-based EMR Generation 和 Rule-based Clinical NLP 奠定了合成数据与规则提取的基础，但忽略语义一致性。2019-2022 年，ClinicalBERT 确立了预训练模型地位，MedQA 和 MDDial 引入了静态问答与多轮对话概念，但无法反映动态推理。2023-2024 年，SFT 和 NoteChat 解决了基础生成与数据稀缺问题，但暴露了幻觉风险，促使研究转向 RAG 与对齐技术。2025-2026 年，PRM 与 Claim-Based Rewards 出现，标志着评估与优化从“结果导向”转向“过程导向”，BeTraC 等挑战赛推动了端到端语音到文本的鲁棒性研究。当前领域处于“可信自动化”阶段，重点解决 LLM 在长上下文、多轮对话及跨模态场景下的鲁棒性。

**如果用一个核心问题概括该领域，那便是：如何在严格的事实约束与临床安全边界内，实现从非结构化医患交互到结构化、可验证临床文档的自动化转化。**

## 2. 方法体系

- 2017：GAN-based EMR Generation——奠定合成临床数据生成早期基础

- 2018：Rule-based Clinical NLP——基于规则的临床实体与关系抽取

- 2019：ClinicalBERT——临床预训练上下文编码器

- 2020：Retrieval-Augmented Generation (RAG)——外部知识库增强生成

- 2023：Supervised Fine-Tuning (SFT)——去标识化语料监督微调

- 2024：NoteChat——多智能体合成医患对话

- 2025：Claim-Based Rewards——声明级奖励优化

- 2026：Process-Supervised Reward Models (PRM)——过程监督奖励模型

这条时间线勾勒了该领域方法演进的代表性节点：从 2017 年的 GAN-based EMR Generation 奠定该领域方法基线，经 2018 年 Rule-based Clinical NLP 的推进，到 2026 年的 TRACE 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 临床笔记生成优化

临床笔记生成优化的核心目标是提升长文本临床笔记（如 SOAP、出院小结）的事实性、完整性与结构规范性。早期方法如 SFT（Supervised Fine-Tuning）在去标识化临床语料上进行监督微调，虽然提升了词汇重叠度，但在事实接地和完整性方面存在不足，促使研究转向基于奖励的对齐技术。Claim-Based GRPO（Jhaveri et al., 2025, P4）提出一种集成 GRPO 框架，直接优化声明级奖励以提升临床文本生成的事实接地和完整性，无需依赖独立的奖励模型。该方法通过引入奖励门控策略加速收敛，解决了传统方法在事实准确性和临床完整性方面的不足，其核心创新在于将奖励信号直接映射到声明单元，避免了奖励模型与生成模型之间的分布偏差。代价是增加了奖励计算的复杂性，且依赖高质量的声明分解。

Process-Supervised Reward Models（PRM）（EMNLP 2025, P49）构建基于过程监督的奖励模型，通过领域专家指导的可扩展方法验证临床笔记生成质量。该方法将笔记分解为句子级步骤，并引入笔记级完整性步骤，防止模型偏好简短但不完整的答案。其关键技术在于设计负样本混合策略，利用金标准样本与负样本随机混合训练，提升模型对事实错误和幻觉的识别能力。代价是数据标注成本高，且需要领域专家参与定义步骤重要性。VERI-DPO（Liu et al., 2026, P25）提出证据感知对齐方法，通过声明验证和直接偏好优化提升临床摘要的事实忠实度。该方法将 BHC 叙述分解为句子和原子声明命题，利用 MIMIC-III 数据集进行患者特定事实验证，确保摘要陈述与 EHR 记录一致。其创新在于引入命题级监督，解决证据碎片化跨纵向笔记的问题，提升摘要的可操作性。代价是数据预处理复杂，且依赖高质量的 EHR 参考数据。

Source-Aware Evaluation（Faisal, 2026, P37）建立源感知评估基准，通过统一三个公开数据集并保留源数据集字段，采用源宏平均值作为主要报告标准。该方法解决了池化平均值掩盖小数据集性能差异的问题，揭示了前沿 LLM 在临床 SOAP 笔记生成中的意外行为趋势，如策略过度使用和配置文件敏感性。其核心在于区分不同来源数据的分布特性，确保评估结果反映模型在临床贴近数据上的真实表现。代价是评估流程复杂，需要维护多源数据的一致性。Source Claim Framework（Vachhani et al., 2026, P30）重新定义医疗 SOAP 笔记评估中的幻觉，建立基于源声明的 LLM-as-Judge 评估框架。该方法将幻觉分为内在（与源矛盾）和外在（引入源中不存在信息），并通过构建包含 100 个匿名转录的评估数据集，覆盖多个专科领域。其核心在于利用 LLM 判断生成笔记中每个声明是否有源对话支持，提升了评估的细粒度。代价是依赖 LLM 判断的准确性，且需要人工标注源声明。

### 2.2 医患对话模拟基准

医患对话模拟基准旨在构建多轮、长上下文或特定场景（如急诊、精神科）的医患对话数据集与基准，评估 LLM 在病史采集、诊断推理及长期记忆方面的能力。MedLoCoMo（Zhang et al., 2026, P45）构建长上下文多会话医疗对话基准，评估 LLM 在长期患者历史理解方面的能力。该方法聚焦于纵向临床对话，要求模型解释和利用数月或数年的交互历史，包括先前症状、诊断和治疗。其核心在于模拟真实临床场景中的长期记忆需求，解决现有基准仅关注当前话语的局限。代价是数据构建复杂，且需要处理长上下文带来的计算挑战。

EMSDialog（Ge et al., 2026, P29）利用多 LLM 智能体从电子患者护理报告合成多人紧急医疗服务对话。该方法旨在生成具有临床逻辑、多样性和安全性的合成对话，支持对话诊断预测任务。其创新在于通过多智能体协作模拟急诊场景，确保对话符合临床流程和安全规范。代价是生成过程复杂，且依赖多 LLM 的协调一致性。History-Aware Medical Dialogue Synthesis（Hu et al., 2026, P36）开发长期历史感知医疗对话合成方法，利用 LLM 生成包含纵向患者历史的连贯对话。该方法整合 NoteChat 和 SynDial 等现有工作，通过反馈循环增强对话质量，确保事实一致性和提取性。其核心在于模拟患者报告当前症状时引用历史信息的场景，提升模型对纵向数据的理解。代价是生成对话的多样性受限，且依赖源数据的丰富性。

Multi-Stage Patient Role-Playing（Jiang et al., 2026, P14）提出多阶段患者角色扮演框架，增强 LLM 在临床交互中的自然性和角色一致性。该方法通过显式人物配置文件和多属性提示，结合场景提示，提升身份维持、语言风格和行为逻辑的一致性。其创新在于将角色扮演形式化为可训练任务，利用多阶段策略模拟真实患者行为。代价是提示工程复杂，且依赖人物配置的准确性。MedAidDialog（Nigam et al., 2026, P26）构建多语言多轮医疗对话数据集，支持可及性医疗保健。该方法通过合成数据扩展 MDDial 数据集，并利用参数高效微调（PEFT）和 LoRA 适配紧凑开源语言模型。其核心在于结合诊断准确性、对话质量和格式合规性的奖励信号，优化模型在初步症状评估和医疗指导中的表现。代价是依赖合成数据的质量，且多语言支持增加复杂性。

MedCase-Structured（Muti et al., 2026, P40）开发文本到 FHIR 数据集，基准测试临床真实 EHR 环境中的诊断推理。该方法利用多阶段合成患者生成器，将非结构化英文自由文本转换为结构有效、术语接地的 HL7 FHIR R4 患者束。其创新在于引入确定性术语接地和结构一致性验证，解决 LLM 生成幻觉代码和结构不一致的问题。代价是管道复杂，且依赖术语库的完整性。MedConsultBench（Qiao et al., 2026, P16）构建全周期、细粒度、过程感知医疗咨询代理基准，涵盖病史采集、诊断、治疗计划和随访。该方法设计了 22 项指标评估代理在动态临床实践中的表现，包括严重性加权召回和硬安全检查。其核心在于模拟真实临床咨询的动态过程，解决静态基准无法评估计划调整和不确定性推理的缺陷。代价是评估指标复杂，且需要大量人工标注。EHRNote-ChatQA（Kim et al., 2026, P41）建立基于证据接地的多轮临床问答基准，针对纵向出院摘要。该方法利用 MIMIC-IV 数据，要求模型回答基于源文档的序列问题，并评估证据接地能力。其创新在于引入多轮对话和证据引用要求，解决现有基准缺乏患者 EHR 特定评估的问题。代价是数据隐私处理复杂，且依赖 HIPAA 合规部署。

### 2.3 临床信息结构化提取

临床信息结构化提取聚焦于从非结构化临床文本或对话中自动提取结构化数据（如医疗指令、症状、实体），旨在减轻文档负担并支持下游临床决策。MasonNLP LLM Extraction（Karim and Uzuner, 2025, P5）利用通用指令微调 LLaMA-4 17B 模型从扩展对话转录中提取结构化医疗指令。该方法无需任务特定训练，通过提示工程识别指令类型、描述、原因和来源，支持 MEDIQA-OE 2025 共享任务。其核心在于利用 LLM 的通用理解能力处理多样化临床文本，解决传统规则系统扩展性差的问题。代价是推理成本高，且依赖提示设计的准确性。

CNSight（Surana et al., 2025, P12）评估临床笔记分割工具，利用 MIMIC-IV 数据比较多种方法在识别笔记章节边界上的表现。该方法测试了多项逻辑回归、正则表达式匹配、MedSpaCy 以及 LLaMA-2、MedAlpaca 等域特定 Transformer 模型。其核心在于解决临床笔记非结构化、半结构化文本处理难题，提升下游建模和数据检索的准确性。代价是评估数据集有限，且模型选择依赖领域知识。ClinStructor（K et al., 2025, P10）开发 AI 驱动的非结构化临床文本结构化方法，强调可解释性和细粒度控制。该方法利用 SHAP、LIME 等后验解释技术，确保预测模型在高风险临床决策中的合规性，避免使用受保护特征。其核心在于平衡预测性能和可解释性，解决复杂模态数据中可解释性下降的问题。代价是解释计算开销大，且依赖后验方法的准确性。

Modular LLM Extraction Framework（Klusty et al., 2025, P11）设计模块化可扩展框架，利用 LLM 从非结构化患者记录中提取结构化特征。该方法集成 REDCap 数据源、安全数据传输、容器化 LLM 嵌入和 Web 界面，支持 HIPAA 合规环境下的自动化提取。其核心在于利用 RAG 技术通过文本嵌入创建向量数据库，识别语义相似文档，提升特征搜索和提取效率。代价是系统架构复杂，且依赖容器化部署的稳定性。Robot-Patient Dialogue Dataset（Cuayahuitl and Jang, 2026, P38）构建机器人患者和医患医疗对话数据集，支持口语处理任务。该方法提供真实临床场景下的对话转录，涵盖多种医疗领域和交互模式，解决口语处理数据稀缺问题。其核心在于模拟真实医患沟通，捕捉口语特征和临床语境，提升 ASR 和 NLP 模型在口语环境中的鲁棒性。代价是数据标注成本高，且口语变异性大。

MedGemma Prompting Strategy（Balachandran et al., 2025, P9）评估 MedGemma 在医疗指令提取中的提示策略，利用 MEDIQA-OE 2025 共享任务基准。该方法比较不同提示工程方法在从对话转录中提取药物、检查等指令时的表现，解决临床 NLP 从规则系统向 Agentic 系统转变中的挑战。其核心在于利用 MedGemma 的医疗预训练优势，优化提示以捕捉临床语境和时序关系。代价是提示设计依赖领域知识，且模型规模受限。Self-Prompting SLM（Chuang et al., 2026, P33）利用自提示小语言模型从牙科进展笔记中提取隐私敏感临床信息。该方法通过提示生成、优化、SFT 和 DPO 偏好对构建，在 200 个训练笔记上优化模型，并在 1000 个金标准笔记上评估。其核心在于解决牙科 EHR 中非结构化数据利用不足的问题，利用小模型降低部署成本。代价是数据量有限，且依赖提示优化的迭代过程。Post-Discharge Action Extraction（Dalmia et al., 2026, P34）系统评估 LLM 从出院文档中提取后续临床行动的能力，涵盖预约、药物、检查等类别。该方法比较专用和通用模型在安全关键任务中的表现，解决出院信息转移中的信息丢失问题。其核心在于利用 LLM 的上下文理解能力，从非结构化出院摘要中识别后续行动指令，支持患者旅程连续性。代价是幻觉风险高，且依赖出院文档的质量。

### 2.4 知识增强临床推理

知识增强临床推理结合知识图谱、检索增强生成（RAG）及多智能体框架，解决 LLM 在临床诊断、治疗建议中的幻觉问题，提升推理的可解释性与证据支撑度。KG-Augmented Follow-Up Question Generation（Sun et al., 2026, P23）利用知识图谱增强医疗随访问题生成，解决诊断错误中信息收集失败的问题。该方法通过 LLM 生成初步问题，然后利用 KG-Followup 和主动 ICL 策略优化问题集，确保问题针对缺失证据。其核心在于结合内部知识和外部临床知识，提升问题生成的针对性和有效性。代价是 KG 构建复杂，且依赖检索准确性。

Diagnostic Knowledge Graph Exploration（Won et al., 2026, P21）通过探索诊断知识图谱实现对话式诊断，模拟医生思维过程。该方法利用假设生成和验证步骤，从对话历史中提取子图，结合患者模拟器进行多轮交互。其核心在于利用 KG 的结构化知识引导诊断推理，解决 LLM 在动态诊断中缺乏系统性推理的问题。代价是 KG 覆盖范围有限，且依赖子图提取的准确性。MED-COPILOT（Chen et al., 2026, P22）结合 GraphRAG 和相似患者案例检索的医疗助手，支持临床推理。该方法通过双证据检索，整合图结构临床指南和相似患者数据，解决 LLM 幻觉和置信度校准问题。其核心在于利用 GraphRAG 提供权威医学知识，相似患者检索提供个体化证据，提升推理的可验证性。代价是检索系统复杂，且依赖数据质量。

C-MIG（Miao et al., 2026, P39）基于多视角信息增益的 RAG 框架，用于临床诊断推理。该方法将患者查询分解为标准化子查询，利用冻结参考模型计算文档级和细化级信息增益，引导模型对齐临床诊断目标。其核心在于通过信息增益量化推理步骤重要性，解决 RAG 中检索噪声和“迷失在中间”问题。代价是计算开销大，且依赖参考模型的质量。Dr.APP（EMNLP 2025, P48）利用 MSD 手册进行接地推理，实现以人为中心的医疗对话。该方法通过估计疾病概率生成后续问题池，利用专业版和消费者版 MSD 手册提供临床指导，解决 LLM 生成语言缺乏人性化问题。其核心在于结合临床指南和患者描述，提升诊断准确性和交互自然性。代价是依赖 MSD 手册的覆盖范围，且问题生成策略复杂。

Precision Querying and RAG（Jan et al., 2026, P17）利用 LLM 进行精确查询和检索增强知识提取，支持临床数据科学。该方法结合 Text-to-SQL 和非结构化笔记信息提取，利用 MIMIC-III 数据，解决 EHR 数据异构性问题。其核心在于利用 LLM 生成结构化查询和提取关键事实，支持队列定义和结果分析。代价是查询生成准确性依赖提示工程，且数据隐私处理复杂。CLIN-LLM（Hasan et al., 2025, P7）安全约束混合框架，用于临床诊断和治疗生成。该方法整合多模态患者编码、不确定性校准疾病分类和检索增强治疗生成，利用 BioBERT 和 Focal Loss 提升预测置信度。其核心在于通过低置信度案例标记专家审查，确保人类监督，解决 LLM 缺乏医学接地和不确定性量化问题。代价是系统架构复杂，且依赖多模态数据质量。MIND（Li et al., 2026, P24）统一询问和诊断 RL 框架，用于精神科咨询。该方法构建标准接地精神科推理库，利用 LLM 法官提供密集奖励，结合价值感知轨迹校正机制，解决精神科叙事主观性和诊断困难问题。其核心在于通过标准接地支持映射自由形式描述到结构化信号，提升诊断逻辑的可验证性。代价是推理库构建复杂，且依赖奖励信号的准确性。

### 2.5 临床数据合成与评估

临床数据合成与评估开发大规模合成临床笔记与对话数据以解决隐私与数据稀缺问题，并建立针对临床 AI 输出的系统性评估框架、错误分类及基准测试。Million-Note Scale Synthetic Evaluation（Liu et al., 2026, P35）系统评估 LLM 重述合成临床笔记的质量，在百万笔记规模上比较与人类笔记的差异。该方法利用下游建模任务（如风险分层）评估合成笔记的预测准确性和公平性，解决合成数据质量评估难题。其核心在于通过 AUROC 和公平性指标（AAOD、SPD）量化合成数据效用，确保数据在年龄、性别和种族子组上的无偏性。代价是评估计算成本高，且依赖下游任务的代表性。

ClinBench（ACL-Findings 2026, P50）基于医学期刊真实病例的 LLM 基准，评估临床场景理解和推理能力。该方法从权威医学期刊提取真实临床案例，保留完整患者信息和测试结果，模拟真实临床实践。其核心在于解决现有基准缺乏真实世界临床场景的问题，提升评估的挑战性和相关性。代价是数据获取和验证成本高，且案例多样性受限。Longitudinal Synthetic Notes Pipeline（Poulett, 2026, P42）开发纵向合成临床笔记生成管道，利用 LLM 模拟患者旅程。该方法结合结构化患者生成、半结构化旅程模拟和非结构化笔记生成，确保纵向记录内部一致性。其核心在于通过 LLM 验证和增强步骤提升忠实度、真实性和多样性，解决合成数据缺乏纵向连贯性问题。代价是管道复杂，且依赖 LLM 对临床流程的理解。

TRACE（Cahoon et al., 2026, P31）模板重用和复制元素移除算法，减少临床笔记膨胀以提升 LLM 使用效率。该方法利用 EHR 归因元数据识别模板化内容，通过参考模块和频率模块删除冗余文本，解决纵向记录上下文窗口溢出问题。其核心在于利用归因元数据缩小搜索空间，推断字符级来源，提升数据质量和计算效率。代价是依赖 EHR 系统的归因元数据可用性，且可能删除有用信息。Multitask Prompt Distillation（Peng et al., 2026, P28）通过多任务提示蒸馏和分解实现临床 NLP 参数高效迁移学习。该方法从五个源任务类型学习共享元提示矩阵，迁移到十个未见目标任务，解决模型跨任务迁移瓶颈。其核心在于利用提示作为任务指令，通过蒸馏提取通用任务知识，提升模型在多种临床 NLP 任务中的适应性。代价是提示长度受限，且依赖源任务和目标任务的相似性。

Long-form Audio Summarization Synthesis（Labrak et al., 2026, P27）生成合成医患对话用于长音频摘要，评估 LALM 在长上下文音频推理中的表现。该方法构建超过 5 分钟的长音频基准，解决 LALM 在长序列多跳推理中的性能退化问题。其核心在于利用合成数据覆盖长上下文音频理解的不同切片，提升评估的全面性。代价是合成数据可能缺乏真实音频噪声，且评估指标复杂。Case-Specific Rubrics（Shah et al., 2026, P32）开发病例特定评估标准，验证 LLM 与临床医生在 823 次就诊中的一致性。该方法通过构建细粒度评估标准，解决通用评估指标无法捕捉临床特定需求的问题，提升评估的针对性和准确性。其核心在于利用病例特定标准评估 AI 输出，确保评估与临床实践对齐。代价是标准构建复杂，且依赖临床医生参与。Automated Evaluation of AI Responses（Soni and Demner-Fushman, 2025, P3）评估自动化方法区分患者住院问题 AI 回答的好坏，解决 MCQ 基准易受格式特异性影响问题。该方法利用接地 QA 任务，要求模型返回带引用的自然语言答案，提升评估的可靠性和可解释性。其核心在于通过引用关键 EHR 句子，确保答案基于证据，解决表面模式匹配问题。代价是引用提取复杂，且依赖 EHR 数据质量。

### 2.6 临床 AI 部署与交互

临床 AI 部署与交互探讨 LLM 在真实医疗场景（如 EHR 集成、患者门户、远程监护）中的部署架构、人机协作模式、安全性约束及实际临床应用效果验证。ExperienceWeaver（Xiao et al., 2026, P20）优化小样本经验学习，用于基于 LLM 的临床文本改进。该方法通过经验编织和检索，利用多智能体框架进行修订和评估，解决人类反馈有限和不规则问题。其核心在于利用经验池和策略池，通过 ReAct 范式自动激活检测修订代理，提升文本改进的精准性和合规性。代价是系统架构复杂，且依赖经验库的质量。

Temporal Reasoning for Longitudinal Summarization（EMNLP 2025, P53）利用时间推理 LLM 进行纵向临床摘要和预测，解决 EHR 多模态数据处理挑战。该方法从 MIMIC-III 和 EHRShot 数据中提取时间有序事件，生成出院摘要和诊断预测，解决纵向轨迹摘要难题。其核心在于利用时间推理能力处理动态患者状态，提升摘要的时序一致性。代价是时间对齐复杂，且依赖多模态数据质量。ReMedi（ACL-Findings 2026, P52）医疗临床预测推理器，通过样本生成、困难样本再生成和模型训练提升预测性能。该方法利用标签理性和重复采样策略，解决直接应用 STaR 策略在临床预测中增益有限问题。其核心在于利用困难案例提升模型推理能力，通过迭代变体 iReMedi 逐步优化模型。代价是训练过程复杂，且依赖困难样本的质量。

EHR-MCP（Masayoshi et al., 2025, P1）通过模型上下文协议评估 LLM 在真实 EHR 中的临床信息检索，解决 LLM 与 EHR 集成难题。该方法利用 MCP 协议连接 LLM 与 EHR，支持实时数据查询和临床决策支持，解决隐私和工作流对齐问题。其核心在于通过安全 VPN 和合同确保数据隐私，利用 MCP 标准化接口提升集成效率。代价是协议实现复杂，且依赖 EHR 系统的兼容性。EPAG（Seo et al., 2026, P13）利用诊断指南评估 LLM 预咨询能力，解决预咨询模型信息收集不足问题。该方法通过比较 HPI 与诊断指南，评估模型在病史采集中的准确性和诊断能力，解决预咨询风险问题。其核心在于利用诊断指南作为标准，评估模型问题针对性和诊断准确性，提升预咨询安全性。代价是指南覆盖范围有限，且评估指标复杂。

Meddollina and CCI（S. V. N. S et al., 2026, P18）提出临床上下文智能，强调认知克制而非语言合理性，解决 LLM 幻觉问题。该方法通过上下文表示、有界推理和责任感知输出对齐，明确区分已知事实、推断可能性和未知项，从结构上抵抗幻觉。其核心在于利用 CCI 框架约束模型输出，确保信息不足时明确陈述，避免推测性生成。代价是系统约束严格，且可能限制生成灵活性。EditJudge Evaluation Framework（Seegmiller et al., 2026, P15）评估 LLM 患者消息响应草稿与临床医生编辑的一致性，解决评估规模限制问题。该方法利用参考基准比较 LLM 草稿与专家响应，测量召回率和精确率，评估临床医生编辑负载。其核心在于通过 LLM-as-Judge 框架，实现大规模评估，解决人工反馈不可扩展问题。代价是评估依赖参考响应质量，且可能忽略临床语境。ChatEHR Platform（Shah et al., 2026, P19）学术医疗中心 LLM 部署平台，集成数据编排、上下文管理和 LLM 路由，解决真实临床数据连接难题。该平台支持 FHIR 格式数据处理，通过 LLM 路由选择合适模型，解决上下文窗口限制问题。其核心在于通过安全连接 LLM 与实时临床数据，支持点护理查询，解决隐私和工作流对齐问题。代价是平台架构复杂，且依赖 FHIR 数据标准化。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

传统表面指标（如 BLEU、ROUGE）无法有效评估临床笔记的临床准确性和安全性，必须引入基于事实核查、临床完整性和专家评估的细粒度指标。这一共识在多个基准上被反复验证：Claim-Based GRPO 在两个基准数据集上展示了改进，VERI-DPO 在出院摘要生成中显著提升了事实准确性，Source Claim Framework 通过构建包含 100 个匿名转录的评估数据集，覆盖了多个专科领域（支撑证据：P4、P25、P30）。与此相关的另一个共识是 LLM 生成的临床文本存在显著的幻觉风险，必须通过检索增强生成（RAG）、基于声明的验证或过程监督奖励模型进行事实约束，以确保患者安全。MED-COPILOT 通过双证据检索显著提升了推理的可验证性，C-MIG 通过信息增益量化推理步骤重要性，解决了 RAG 中检索噪声问题（支撑证据：P22、P39）。

### 3.2 观点分歧

推理增强（CoT）在结构化临床生成中的有效性存在显著分歧。观点 A 认为 CoT 显著提升诊断推理能力，通过显式思维链增强逻辑连贯性，代表工作如 Diagnostic Knowledge Graph Exploration 和 MIND 均利用推理过程提升诊断准确性。观点 B 认为在 SOAP 笔记等固定格式任务中，CoT 导致冗余、偏离格式，降低笔记质量，Source-Aware Evaluation 揭示了前沿 LLM 在临床 SOAP 笔记生成中的策略过度使用问题（支撑证据：P21、P24、P37）。现有证据偏向“需特定策略平衡”，在开放式诊断推理中 CoT 有效，但在结构化生成中可能有害。这一分歧的背后，是另一个更根本的争论：结构化数据（FHIR）与非结构化文本在 LLM 推理中的优劣。观点 A 认为结构化数据提供标准化输入，减少歧义，提升推理准确性，MedCase-Structured 通过确定性术语接地和结构一致性验证解决了 LLM 生成幻觉代码问题。观点 B 认为结构化数据可能引入认知负荷或信息丢失，LLM 在结构化输入下的诊断准确率有时低于非结构化文本（支撑证据：P40、P17）。现有证据偏向“场景依赖”，在简单查询任务中结构化数据优势明显，但在复杂诊断推理中，非结构化文本可能保留更多语境信息。

### 3.3 其他开放问题

最紧迫的工程问题是隐私敏感环境下的本地化高效部署。当前高性能临床 LLM 多依赖云端 API，存在数据隐私风险，未来需探索参数高效微调（如 LoRA, Prompt Distillation）和小语言模型（SLM）的自我提示优化技术，使模型能在本地硬件上实现可靠的临床信息提取与生成，同时降低计算成本。最根本的研究问题是长上下文纵向一致性与记忆能力。现有模型在处理跨越多次就诊的长期医疗历史时，常出现跨会话推理错误和信息遗忘，未来研究方向包括构建长上下文多会话基准，并开发专门针对时间序列临床数据的状态跟踪与记忆增强机制，以支持连续性护理决策。已知—争议—未知认知图谱显示：已知传统指标无效、合成数据有效、SOAP 是标准格式；争议 CoT 在结构化生成中的有效性、结构化数据优劣、LLM-as-Judge 可靠性；未知长上下文记忆机制、临床合理推断与幻觉的边界、多模态融合机制。发展趋势是从“辅助工具”向“具备自我验证能力的智能体”演进。

## 4. 总结与展望

临床对话与笔记生成领域已从追求语言流畅性进入追求事实可信性的新阶段。核心矛盾在于通用 LLM 的补全倾向与临床场景对事实零容忍要求之间的冲突，尝试过的路线包括 SFT、RAG、Claim-Based GRPO、PRM 和 GraphRAG，核心瓶颈是如何在长上下文、多模态及隐私约束下，实现具备自我验证能力且符合临床工作流的可信自动化。

未来可能突破的方向包括：开发能够区分临床合理推断与事实性幻觉的评估框架，结合医学本体论和校准提示，建立基于临床推理逻辑的细粒度 Claim-level 验证标准；提升 LLM 在长上下文多会话场景下的纵向一致性与记忆能力，构建长上下文多会话基准，并开发专门针对时间序列临床数据的状态跟踪与记忆增强机制；实现隐私敏感环境下的本地化高效部署，探索参数高效微调和小语言模型的自我提示优化技术。对于进入者，最值得做的一件事是构建基于临床工作流的全周期评估基准，评估 LLM 在动态临床场景中的多步推理、工具调用及决策一致性，而不仅仅是最终答案的准确性。
