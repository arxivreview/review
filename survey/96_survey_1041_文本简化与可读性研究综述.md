综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Text%20Readability%20and%20Simplification)

## 导读

文本简化旨在保留原意的前提下降低语言复杂度，其核心价值在于弥合信息供给与特定受众认知能力之间的鸿沟。早期研究依赖基于规则的词汇替换和可读性公式，思路直观却受限于表面特征，难以捕捉深层语义。随着数据驱动范式兴起，基于 Transformer 的序列到序列模型确立了端到端生成的基线，显著提升了简化质量。大语言模型（Large Language Models, LLM）的介入进一步改变了问题定义，从“如何简化”转向“如何精确控制简化程度”及“如何评估简化的认知有效性”。各路线在语义保真度、可控性与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从规则驱动到认知适配的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

文本简化领域的起源深植于教育公平与健康素养的社会需求，早期研究试图通过降低句长和词汇复杂度来提升文本对低识字率群体的可理解性。这一阶段的核心假设是“降低表面特征即可提升可读性”，主要依赖 Flesch-Kincaid 等公式进行量化，但这类方法无法处理复杂的句法结构，且在保留语义方面表现脆弱。随着自然语言处理（Natural Language Processing, NLP）技术的发展，问题定义逐渐从“表面特征优化”转变为“语义保持下的生成质量优化”，数据驱动范式开始占据主导地位。

在形式化定义上，文本简化通常被视为一个序列到序列的转换任务，给定源文本 $x$ 和目标受众特征 $c$，模型需生成简化文本 $y$，使得 $y$ 在保持 $x$ 语义保真度（Semantic Fidelity）的同时，其可读性指标符合 $c$ 的要求。这一任务包含两个紧密耦合的子问题：词汇简化（Lexical Simplification）与句法简化（Syntactic Simplification）。词汇简化负责将复杂术语替换为高频词，是句法简化的基础操作；而句法简化则通过拆分长句、转换被动语态来降低阅读负荷。此外，可读性评估（Readability Assessment）作为简化的反馈机制，其准确性直接决定了简化方向是否偏离目标，若评估指标与人类感知存在偏差，整个简化流程将失去校准基准。

问题定义的演化清晰地反映了领域关注点的深化。2014 年，Shardlow 简化框架确立了在保留语义前提下降低语言复杂度的核心目标，奠定了任务基准。2016 年，SARI 指标的引入解决了传统 BLEU 无法衡量简化操作有效性的问题，标志着评估体系从“相似度”向“编辑有效性”的转变。2017 年，Saggion 的综述系统梳理了历史脉络，明确了从规则驱动向数据驱动范式转移的必要性。这一时期，基于规则的替换方法因无法捕捉上下文语义而逐渐被边缘化，数据驱动方法开始探索如何利用大规模平行语料库提升生成质量。

2020 年至 2021 年是数据驱动范式的确立期。T5 架构的提出将 NLP 任务统一为文本到文本转换，其强大的预训练能力为后续简化任务奠定了模型基础。2021 年，基于 BART 架构的 MUSS 模型证明了预训练序列到序列模型在简化任务上优于传统监督方法，确立了 Seq2Seq 在该领域的 SOTA 地位。然而，这一路线虽然提升了流畅性，却放弃了对目标可读性等级的显式控制，模型输出难度不可预测，且在处理大复杂度差距时失败率较高。

2023 年成为关键转折点，大语言模型（LLM）的介入彻底改变了研究范式。BLESS 基准系统评估了 44 种 LLM 在少样本提示下的简化能力，发现最佳提示 LLM 性能可比肩监督基线，开启了 LLM 提示工程在简化领域的应用热潮。此时问题已转变为“如何利用 LLM 的涌现能力实现零样本或低资源下的精准简化”。2025 年，MRS-Joint 等多轮迭代方法出现，通过逐步逼近目标 CEFR 等级，解决了单步生成在处理大复杂度差距时的失败问题。2026 年，Simplify-Pro 框架和 Re-RIGHT 统一框架进一步将研究重心推向长文本连贯性与多语言低资源场景，标志着领域从“通用简化”向“受众特定认知适配”的深化。

这一演进过程揭示了领域发展的内在逻辑：从追求“更简单的句子”到追求“符合特定认知模型的文本”。子问题间的依赖关系日益复杂，可读性评估不再是简化的附属品，而是成为控制简化程度的核心反馈环。无障碍文本生成（如 Easy-to-Read）作为特定受众下的简化变体，与通用简化形成互补，共同构成了当前多元化的研究版图。

**如果用一个核心问题概括该领域，那便是：如何在保持语义保真度的前提下，实现从通用语言复杂度降低到特定受众认知负荷精准适配的范式跃迁。**

## 2. 方法体系

- 2014：Shardlow简化框架——提出基于词汇替换与句法重写的文本简化基础定义

- 2016：SARI指标——引入基于n-gram的Keep、Add、Delete操作评估机制

- 2020：T5架构——提出将NLP任务统一为序列到序列的文本到文本转换框架

- 2021：MUSS模型——基于BART架构针对文本简化任务进行微调

- 2023：BLESS基准——系统评估了44种现成大语言模型在少样本提示下的简化能力

- 2025：MRS-Joint方法——提出多轮规则与提示联合简化框架

- 2026：Simplify-Pro框架——提出两级渐进式长文本简化框架

- 2026：Re-RIGHT框架——构建统一多语言熟练度感知简化框架

这条时间线勾勒了该领域方法演进的代表性节点：从 2014 年的 Shardlow简化框架 奠定该领域方法基线，经 2016 年 SARI指标 的推进，到 2026 年的 统计简洁性分析 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 序列到序列微调

在 LLM 介入之前，基于预训练模型的序列到序列（Seq2Seq）微调是文本简化的主流范式。这一路线的奠基工作可追溯至 2021 年的 MUSS 模型，它基于 BART 架构针对文本简化任务进行微调，证明了预训练模型在简化任务上优于传统监督方法，确立了 Seq2Seq 在该领域的 SOTA 地位。MUSS 的核心优势在于其端到端的生成能力，能够捕捉上下文语义并生成流畅的简化文本，解决了早期规则方法无法处理复杂句法结构的问题。然而，这一路线的代价是放弃了对目标可读性等级的显式控制，模型输出难度不可预测，且依赖大量标注数据。

随着 T5 架构的普及，Flan-T5 等指令微调模型在简化任务上展现出更强的泛化能力。在 Med-EASi 和 OneStopEnglish 基准上，Flan-T5-large FT 取得了 36.62 的 SARI 分数，略高于 BART-large FT 的 36.25，表明指令微调在保持语义保真度的同时提升了简化质量。这一路线与 LLM 提示路线的竞争在于：Seq2Seq 微调通过牺牲部署灵活性换取了更高的任务特异性性能，而 LLM 提示则通过牺牲部分精度换取了零样本的泛化能力。

### 2.2 大语言模型提示工程

2023 年 BLESS 基准的发布标志着 LLM 提示工程在简化领域的兴起。这一路线的核心假设是 LLM 的涌现能力足以在少样本或零样本设置下执行复杂指令，无需大规模标注数据。SimpCue 提示策略（Tareh et al., 2026, P14）针对通用简化指令无法明确识别句子复杂来源的问题，提出基于线索的提示方法。该方法首先通过 TF-IDF 与逻辑回归模型预测句子中的复杂性线索，如技术词汇、长句法依赖或被动语态，随后将预测的线索标签注入 LLM 提示中，引导模型针对性地解决特定理解障碍。相比无线索提示，该方法使模型能更精确地定位并简化难点，避免遗漏关键复杂因素。

SimpCue 在 Multilingual E2R 基准上取得了 15.047 的 BLEU 和 39.811 的 SARI 分数，展示了细粒度控制手段的有效性。其局限在于线索预测模型的准确性直接影响最终简化质量，且需为每种语言单独优化预测参数。与 Seq2Seq 微调路线相比，LLM 提示路线放弃了大规模微调的成本，换取了零样本的灵活性和跨领域泛化能力，但在处理特定 CEFR 等级时表现波动较大，缺乏稳定性。

### 2.3 多轮迭代与规则辅助

针对单步 LLM 生成在处理源文本与目标 CEFR 等级差距较大时失败率高的问题，多轮迭代与规则辅助方法应运而生。MRS-Joint 方法（Huynh and Cao, 2025, P8）提出多轮迭代简化策略，由 GPT-4o 生成代码，结合规则引擎与 LLM 提示技术，通过多轮渐进式调整句法结构与词汇。其核心在于将复杂的简化任务分解为多个小步长操作，每轮以上一轮结果为输入，逐步逼近目标可读性等级。在 TSAR 2025 共享任务中，MRS-Joint 方法取得了 0.4472 的 RMSE，显著低于 MRS-Rule 的 0.8515 和 Baseline 的 0.8944，证明了迭代过程优于单步生成。

APEC 自动后编辑循环（Calleja et al., 2025, P1）则针对 Plain Language 与 Easy Read 适配中语义保留与可读性难以平衡的问题，提出基于 LLM 的自动后编辑循环方法。初始阶段利用特定提示词进行零样本或少样本适配，随后进入精炼阶段，通过迭代循环自动检测并修正生成文本中的错误。该方法结合嵌入相似度与 Bag-of-Words 相似度评估语义一致性，并利用 Fernandez Huerta 可读性指数监控文本难度。相比单次生成，APEC 通过多次反馈修正显著提升了与人类参考文本的相似度，其代价是增加了 API 调用次数与处理时间。

### 2.4 无障碍与受众特定适配

通用简化模型无法捕捉特定认知障碍群体的特征，促使研究转向受众特定适配。多任务 ETR 生成框架（Ledoyen et al., 2025, P3）针对认知障碍人群 Easy-to-Read 文本生成中数据稀缺与质量不一的问题，提出多任务学习方法。该方法构建 ETR-fr 数据集，并采用多任务学习（MTL-LoRA）策略，将 ETR 生成与简化、摘要等任务联合训练。在 ETR-fr 基准上，该方法取得了 44.67 的 SARI 分数，远高于 ETR 指南自动化实现（Ledoyen et al., 2025, P4）的 37.56，证明了多任务学习在低资源场景下的泛化能力。

Re-RIGHT 统一框架（2026, P18）则针对 LLM 在多语言及低熟练度等级文本生成中词汇控制不足的问题，提出统一的多语言熟练度感知简化框架。该方法基于 CEFR、JLPT 等标准构建词汇水平数据集，定义词汇覆盖率作为量化指标，通过对比 GPT-5.2 等模型，发现 LLM 在简单等级及非英语语言中表现较差，进而提出针对性优化策略。其核心在于将词汇控制显式化，通过提示或微调约束模型输出词汇等级。与通用简化路线相比，受众特定适配路线放弃了通用模型的泛化性，换取了对特定认知特征的精准满足，提升了文本的社会效用和可及性。

### 2.5 长文本与文档级简化

句子级简化难以处理文档级依赖，导致长文本简化中信息丢失、语义扭曲和连贯性断裂。Simplify-Pro 框架（2026, P16）为解决这一问题，提出两级渐进式 LLM 简化框架。第一阶段在有限段落级数据上训练 LLM 作为核心简化组件，确保局部语义稳定。第二阶段采用动态语义感知分割策略，利用句向量相似度识别语义边界，将长文档分解为连贯文本块。通过指标辅助分析，评估结构变化与内容转换，平衡了简化效率与细粒度质量要求。其局限在于依赖预训练句嵌入模型的质量，且分割阈值需针对特定领域调整。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

大语言模型（LLM）通过提示工程或微调，在文本简化任务上已达到或超越传统监督学习基线的性能，这一共识在多个基准上被反复验证。例如，在 Med-EASi 和 OneStopEnglish 上，Flan-T5-large FT 的 36.62 SARI 分数显著优于早期规则方法；在 TSAR 2025 上，MRS-Joint 的 0.4472 RMSE 远低于单步生成基线。然而，该共识的边界在于 LLM 在复杂控制（如特定等级匹配）上的不稳定性，零样本提示在简单任务上有效，但在处理大复杂度差距时不如微调或混合方法稳定。

与此相关的另一个共识是，文本简化必须在降低复杂度的同时严格保持语义保真度，任何导致信息丢失或扭曲的简化都是失败的。这一共识源于对教育公平和健康素养需求的响应，简化文本若失去原意，则无法实现其社会效用。现有证据表明，BERTScore 和 MeaningBERT 等语义指标在衡量保真度方面比 BLEU 更可靠，但单一指标仍具有局限性，需结合可读性、流畅性等多维指标进行综合评估。

### 3.2 观点分歧

评估标准的选择是领域内的核心分歧，一方主张表面特征指标（如 FKGL, SARI）计算成本低、标准化程度高，适合大规模自动评估；另一方主张认知/语义指标（如 HCRS, BERTScore, G-Eval）更贴近人类感知，能捕捉语义细微差别和用户情感响应。现有证据偏向后者，ReadMe++ 基准分析显示表面特征指标与人类判断相关性低，尤其在跨域场景中失效。但认知指标缺乏大规模、标准化的实验验证，且 LLM 评估存在一致性问题，导致分歧尚未定论。

这一分歧的背后，是另一个更根本的争论：简化机制是单步生成还是多轮迭代。单步生成效率高，适合实时应用，且 LLM 能力增强后单步性能已足够；多轮迭代能更精确地控制 CEFR 等级和语义保真度，解决单步生成的“一步到位”难题。在 CEFR 等级控制任务上，多轮迭代的证据更强（MRS-Joint RMSE 显著低于基线），但在简单任务或低复杂度差距场景下，单步生成的效率优势明显。最优迭代次数和停止准则未定，且多轮迭代的计算成本在边缘设备上不可接受，场景依赖性导致无法一概而论。

### 3.3 其他开放问题

最紧迫的工程问题是多语言低资源数据的构建与 LLM 评估的一致性控制。当前研究主要集中在英语，缺乏多语言基准，导致模型在非英语语言上的泛化能力弱。构建跨语言词汇库、利用多语言 LLM 进行提示工程以及开发语言特定的可读性公式是潜在路径。此外，LLM 作为评估者（LLM-as-a-judge）的一致性和偏差控制仍是难题，需使用思维链提示和基于特定标准的 G-Eval 框架来缓解。

最根本的研究问题是区分人类可读性与统计可学习性，以及特定受众认知模型的量化。最新实证研究（Lee and Berg-Kirkpatrick, 2025, P6）揭示文本可读性并非小模型学习能力的决定因素，统计简洁性（n-gram 多样性）才是关键预测因子，纠正了领域内对简化文本作用的误解。然而，合成数据集可能无法完全代表真实语料分布，且“统计简洁性”与“认知可读性”的解耦机制尚需更深入的理论解释。已知的是 LLM 在简化任务上的优越性，争议的是评估标准与简化机制的选择，未知的是认知适配的量化方法与多语言泛化机制。

## 4. 总结与展望

文本简化领域的演进反映了从“语言工程”向“认知科学”与 NLP 交叉的深化，核心矛盾在于自动化指标与人类认知感知之间的鸿沟。从基于规则的词汇替换到 Seq2Seq 端到端生成，再到 LLM 可控生成，方法路线不断在语义保真度、可控性与计算成本之间做出取舍。当前瓶颈在于缺乏统一的“认知可读性”测量工具，以及多轮迭代与 LLM 评估的工程优化尚未解决最优停止准则与一致性问题。

未来可能突破的方向包括：开发以人为中心的评估框架，整合清晰度、可信度、文化相关性和可操作性等维度，解决当前自动指标仅关注表面特征的问题；探索 LLM 作为评估者在可读性和简化质量评估中的应用，解决传统参考依赖指标无法捕捉语义细微差别的问题；研究多轮迭代简化和自动后编辑循环在复杂文本适配中的有效性，确定最优迭代次数和停止准则。对进入者而言，最值得做的一件事是构建针对特定受众（如认知障碍者、低识字率成人）的定制化简化框架，结合领域专家反馈与多任务学习，填补通用模型在个性化适配上的空白。
