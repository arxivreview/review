综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Automatic%20Prompt%20Optimization)

## 导读

自动提示优化（Automatic Prompt Optimization, APO）旨在通过算法自动搜索或生成最优自然语言指令，以在无需修改模型权重的前提下提升大语言模型（LLM）性能。其核心价值在于解决闭源模型参数不可访问与人工提示工程效率低下之间的根本矛盾。早期研究依赖人工试错或简单的零样本提示，效率极低且缺乏泛化性，难以应对复杂任务需求。随着 APE 和 OPRO 等工作的出现，领域实现了从“人工设计”到“自动化搜索”的关键转折，将提示视为可优化的离散变量。随后，ProTeGi 和 TextGrad 引入了“文本梯度”概念，借鉴深度学习反向传播思想，通过自然语言反馈指导提示迭代，标志着优化机制从盲目搜索向反馈驱动的转变。当前，研究重心进一步从单一任务优化转向复杂系统优化，包括多智能体工作流、多目标权衡以及鲁棒性提升。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

自动提示优化（APO）的兴起源于大语言模型（LLM）对输入指令的高度敏感性，以及闭源模型参数不可访问的现实约束。在早期阶段，研究者主要依赖人工试错或简单的零样本/少样本提示，这种方式效率低下且缺乏泛化性，难以应对复杂任务的需求。随着 LLM 能力的增强，人们发现微小的措辞变化可能导致显著的性能差异，这促使研究者将提示视为可优化的离散变量，从而开启了自动化搜索的新篇章。这一转变不仅提升了提示设计的效率，也为适配闭源模型提供了核心手段。

问题形式化可以表示为：给定一个任务分布 $\mathcal{D}$ 和一个 LLM $M$，寻找一个提示 $p^* \in \mathcal{P}$，使得期望性能 $\mathbb{E}_{x \sim \mathcal{D}}[M(x, p^*)]$ 最大化，同时满足计算预算约束 $C(p^*) \le B$。这里，$\mathcal{P}$ 表示所有可能的自然语言提示构成的离散搜索空间，其组合爆炸特性是 APO 面临的主要计算挑战。子问题之间存在明确的依赖关系：评估效率是基础约束，决定了搜索策略的可行性；结构化分解是提升可控性与归因的前提，进而支撑多智能体协同；鲁棒性则是泛化性的保障，依赖于对提示空间景观的理论理解。不解决评估成本，就无法进行大规模搜索；不解决结构化归因，就无法处理多步骤流水线的错误定位。

范式边界方面，APO 与微调、检索增强等方法存在显著区别。微调需要访问模型参数并消耗大量计算资源，而 APO 仅通过输入输出交互进行优化，适用于闭源模型。检索增强则侧重于外部知识的引入，而 APO 专注于指令本身的优化。这种边界界定使得 APO 成为适配闭源 LLM 的关键手段，优于人工试错。

约束演化史揭示了方法如何因应约束变化而演变。2016-2018 年，奠基阶段主要关注提示的初始设计与基本优化策略，如 GPT-3 展示的少样本提示能力。2020 年，跨域基准的引入暴露了域偏移下的原型崩溃问题，促使研究者转向预训练与视觉语言模型，用更强的先验换取跨域鲁棒性。2021 年，预训练/VLM 的引入进一步提升了表示质量，但计算成本也随之增加。2023-2025 年，细化与融合成为主流，如 APE、OPRO 等工作的出现，实现了从“人工设计”到“自动化搜索”的关键转折。当前形态则集中在样本效率、结构化提示分解、因果推断及理论保证上，旨在解决提示空间组合爆炸、评估成本高及优化结果不稳定等挑战。

**如果用一个核心问题概括该领域，那便是：在计算预算受限且反馈稀疏的黑盒环境中，如何通过语义感知的搜索策略，在巨大的离散提示空间中定位具有鲁棒性与成本效益最优解的指令配置。**

## 2. 方法体系

- 2019：GPT-3——奠定该领域方法基线

- 2022：Chain-of-Thought——推进结构化推理

- 2023：APE——开创自动化提示搜索先河

- 2023：ProTeGi——确立反馈驱动提示优化主流范式

- 2024：OPRO——推动 LLM-in-the-loop 优化范式发展

- 2025：GEPA——实现资源受限场景下的高效提示部署

- 2026：Sharpness-Aware Prompt Evolving——代表当前前沿

这条时间线勾勒了该领域方法演进的代表性节点：从 2019 年的 GPT-3 奠定该领域方法基线，经 2022 年 Chain-of-Thought 的推进，到 2026 年的 Sharpness-Aware Prompt Evolving 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 进化与群体搜索

进化与群体搜索路线起源于 2023 年 APE 的提出，该工作利用 LLM 作为生成器从输入输出对中采样候选指令，并通过评估筛选最佳提示，开创了黑盒环境下自动化提示搜索的先河。随后，ProTeGi 引入文本梯度概念，通过 LLM 分析错误案例生成自然语言反馈以指导提示迭代修改，结合束搜索策略平衡探索与利用，确立了反馈驱动提示优化的主流范式。PromptBreeder 则提出进化算法优化提示，通过变异和交叉操作在提示种群中迭代搜索，利用适应度评估保留高性能个体，展示了群体智能在离散提示空间全局搜索中的有效性。

ELPO（Zhang et al., 2025, P8）提出基于集成学习的提示优化框架，旨在解决单一优化方法在离散提示空间中性能不稳定的问题。该方法将多个不同的提示优化算法视为基学习器，通过加权投票或平均机制集成它们的输出，以平滑随机性带来的波动。其改进点在于不依赖单一搜索策略，而是利用不同算法的互补性来覆盖更广泛的提示空间。代价是计算开销随基优化器数量线性增加，且需要维护多个候选提示池。C-Evolve（ICLR 2026, P30）设计了一种基于共识的进化算法，专门用于优化复合 AI 系统中的提示组。该方法引入投票分数来衡量提示在与其他提示协同工作时的贡献度，而非孤立评估。核心组件包括岛屿模型进化结构、共识投票机制以及基于 EMA 的适应度评估。主要创新在于将优化目标从单提示性能转向群体协同性能，确保进化后的提示集合能通过输出共识产生高质量结果。其代价是评估过程需要多次并行推理以计算共识，增加了计算复杂度。

SePO（Tao et al., 2026, P22）提出自进化提示智能体框架，通过两阶段训练优化系统提示。第一阶段预训练提示智能体，使其具备自我改进能力，即优化自身的系统提示；第二阶段利用进化后的智能体优化目标任务智能体的提示。核心模块包括自指涉闭环机制、候选提示档案库以及跨任务复用策略。其改进点在于将提示优化智能体本身作为可优化对象，实现了优化能力的迭代升级，而非仅优化目标提示。代价是训练过程复杂，需要维护庞大的提示档案库并处理自指涉带来的收敛稳定性问题。Reverse Prompt Engineering（EMNLP 2025, P29）提出一种零样本遗传算法方法，用于从模型输出反向推断提示。该方法假设已知一组输出，通过遗传算法在提示空间中搜索能生成这些输出的潜在提示。核心组件包括候选提示生成器、基于 ROUGE-1 的适应度评估函数以及迭代选择机制。其创新点在于无需访问模型内部参数或大量训练数据，仅依赖输出分布即可恢复提示结构，适用于提示逆向工程场景。代价是假设输出数量足够多且分布具有代表性，否则搜索空间过大导致收敛困难。

### 2.2 贝叶斯与黑盒优化

贝叶斯与黑盒优化路线起源于 2024 年 OPRO 的提出，该工作将 LLM 本身作为优化器，基于历史提示-分数对条件生成新候选，通过元提示引导搜索方向，实现了无需梯度信息的黑盒提示优化，推动了 LLM-in-the-loop 优化范式的发展。BO-LLM（Ballew et al., 2025, P4）提出基于贝叶斯优化的提示搜索框架，将提示优化建模为昂贵黑盒函数优化问题。该方法利用高斯过程作为代理模型，显式建模候选提示的性能景观，并通过采集函数平衡探索与利用。核心模块包括提示向量化编码器、GP 代理模型更新机制以及基于采集函数的候选选择策略。其改进点在于相比启发式搜索，BO-LLM 具有样本效率优势，能在有限评估预算下找到高性能提示。代价是提示向量化可能丢失语义信息，且 GP 计算复杂度随数据点增加而上升。

Embedding by Elicitation（Lin et al., 2026, P20）提出动态表示方法用于系统提示的贝叶斯优化，解决黑盒优化中反馈稀疏的问题。该方法不直接优化文本，而是通过 LLM 提取提示的动态嵌入表示，并在嵌入空间进行优化。核心组件包括提示嵌入提取器、基于嵌入的代理模型以及批量优化调度器。其创新点在于利用 LLM 的语义理解能力将离散提示映射到连续空间，使得贝叶斯优化算法能更有效地捕捉提示间的相似性。代价是嵌入提取需要额外的 LLM 调用，且嵌入空间的几何结构可能与任务性能不完全对齐。Online Black-Box Prompt Optimization（ICLR 2026, P31）提出在线黑盒提示优化算法，提供噪声反馈下的遗憾保证。该方法将提示优化视为在线学习问题，每轮接收新样本并更新提示，以最小化累积损失。核心模块包括基于上下文的提示生成器、在线梯度估计机制以及遗憾界分析。其改进点在于处理动态数据流场景，传统离线优化无法适应分布漂移，而该方法能实时调整提示。代价是算法复杂度较高，且需要假设损失函数满足一定的光滑性条件。

TextBO（Kang and Yoganarasimhan, 2025, P7）提出语言空间中的贝叶斯优化框架，用于评估高效的自我改进 AI。该方法将并行梯度基 UCB-BO 适应到语言空间，利用 LLM 批评家提出定向编辑作为文本梯度。核心组件包括文本梯度生成器、Best-of-N 选择机制以及 UCB 采集函数。其创新点在于将连续优化算法与离散文本编辑结合，通过局部定向更新替代全局随机搜索，提升了优化方向性。代价是依赖 LLM 批评家的质量，若反馈不准确则梯度方向错误。

### 2.3 多目标与成本感知

多目标与成本感知路线起源于 2025 年 GEPA 的提出，该工作提出基于反思的帕累托选择进化算法，在优化任务性能的同时考虑提示长度与推理成本，通过多目标权衡实现资源受限场景下的高效提示部署。Efficient Multi-objective Prompt Optimization（Li et al., 2026, P19）提出基于纯探索多臂老虎机的多目标提示优化方法。该方法将提示选择建模为多臂老虎机问题，通过轮次基臂消除框架在有限预算内识别最佳可行提示。核心组件包括预算分配调度器、多目标适应度评估以及 Successive Rejection 机制。其改进点在于处理多目标权衡，如准确率与推理成本，通过 Pareto 前沿搜索避免单一指标优化导致的次优解。代价是算法假设目标函数平稳，且需要预定义调度参数。

CRAFT（Kumar et al., 2026, P23）提出成本感知细化与前沿感知调优方法，联合优化任务准确率与提示令牌成本。该方法将提示优化形式化为双目标搜索，在验证集上估计性能，同时计算提示长度作为成本指标。核心组件包括部分验证估计器、Pareto 前沿维护机制以及基于编辑距离的候选选择。其创新点在于显式建模提示长度对推理成本的影响，并通过前沿感知策略保留多样性候选。代价是成本指标仅考虑令牌数，未涵盖计算延迟或内存占用。CAPO（Dong et al., 2026, P27）提出约束感知提示优化框架，用于 LLM 智能体，确保在满足多个操作阈值的前提下提升任务性能。该方法引入对偶变量机制，为每个约束（如工具调用次数、提示长度）分配乘子，动态调整候选排名。核心组件包括约束违反检测器、对偶变量更新机制以及基于乘子的重写反馈生成器。其改进点在于处理硬约束，传统加权评分无法保证所有约束同时满足，而 CAPO 通过拉格朗日对偶确保可行性。代价是约束定义需明确，且对偶变量收敛速度影响优化效率。

Adaptive Prompt Optimization for Open-Ended Tasks（ACL-Findings 2026, P28）提出利用不确定性偏好作为次要信号的开放式任务提示优化方法。该方法在评估候选提示时，不仅考虑判断质量，还引入语义熵作为不确定性特征，通过形状化分数偏向既高质量又符合不确定性偏好的候选。核心组件包括语义熵计算模块、偏好形状化函数以及列表式排名选择器。其创新点在于针对开放式任务缺乏唯一正确答案的特点，利用模型生成过程中的不确定性信号辅助优化。代价是熵计算增加推理开销，且偏好形状化参数需调优。

### 2.4 结构化与模块化优化

结构化与模块化优化路线起源于 2024 年 TextGrad 的提出，该工作提出文本梯度反向传播机制，将 LLM 反馈视为梯度信号，通过迭代编辑提示中的特定部分来最小化任务损失，实现了类似神经网络训练的可解释提示优化流程。Adaptive Prompt Structure Factorization（Liu et al., 2026, P16）提出自适应提示结构分解框架，用于自发现和优化组合式提示程序。该方法将单体提示分解为指令、示例、格式等语义模块，通过细粒度编辑和归因分析优化各组件。核心组件包括提示分解器、模块级信用分配机制以及组合式提示生成器。其改进点在于提升优化的可控性，允许独立调整特定模块而不影响整体结构，解决了单体提示优化中组件间干扰问题。代价是分解策略需针对任务设计，且模块间依赖关系复杂。

Prompt Codebooks（Nath et al., 2026, P21）提出离散组合优化方法，用于语言模型指令细化。该方法将提示优化重构为有限自然语言指令单元词汇表上的离散组合学习，通过提示编码器、离散代码本、提示生成器和批评家联合训练。核心组件包括语义路由器、文本梯度下降机制以及最小-最大目标函数。其创新点在于引入离散潜在瓶颈，使提示作为共享文本原语的组合出现，提升了组件复用能力。代价是代码本大小需平衡表达力与搜索空间，且训练过程复杂。SAPO（Kulin et al., 2026, P26）提出段级自动提示优化方法，将提示分解为角色、上下文、任务、输出格式等段。该方法通过对比证据提取诊断弱段和强段，生成保留强段并修改弱段的约束候选。核心组件包括提示分段器、对比证据提取模块以及编辑距离平局打破机制。其改进点在于引入段级可控性，避免整体重写导致的性能波动，确保已知强组件不被破坏。代价是分段边界需准确，且对比证据提取依赖训练数据质量。

ADOPT（Zhao et al., 2025, P11）提出自适应依赖引导联合提示优化框架，用于多步骤 LLM 流水线。该方法显式建模各步骤输出对最终结果的贡献，利用依赖关系引导步骤级提示更新。核心组件包括执行轨迹分析器、全局文本梯度构建器以及基于 Shapley 值的资源分配机制。其改进点在于处理多步骤依赖，传统方法忽略步骤间交互，而 ADOPT 通过依赖分析实现端到端优化。代价是轨迹分析计算开销大，且 Shapley 值计算复杂度高。

### 2.5 自适应与动态提示

自适应与动态提示路线起源于 2019 年 GPT-3 的提出，该工作通过大规模预训练语言模型展示少样本提示（Few-shot Prompting）能力，证明无需微调即可通过输入示例引导模型执行新任务，奠定了提示工程作为模型适配核心手段的基础地位。Dynamic Policy Induction（Xu, 2025, P2）提出通过轻量级强化学习桥接效率-准确性差距的自适应提示优化方法。该方法设计提示策略网络，根据输入查询状态动态选择提示策略，如 CoT 或 Self-Consistency。核心组件包括冻结编码器特征提取器、策略头与价值头 FFN 网络以及基于执行反馈的 RL 训练循环。其改进点在于实现实例级适配，避免对所有输入使用固定复杂提示，从而降低计算开销。代价是策略网络需大量交互数据训练，且策略空间需预定义。

GPS（Batorski and Swoboda, 2025, P9）提出通用每样本提示器，通过强化学习训练提示生成器为每个输入样本生成特定提示。该方法采用双 LLM 架构，提示生成器通过结构化推理过程生成提示，评估器模型执行任务并产生奖励。核心组件包括提示生成器、评估器模型以及包含令牌格式、结构、对齐等多维度的奖励函数。其改进点在于实现细粒度实例级适配，传统方法生成单一任务提示，而 GPS 针对每个样本定制。代价是推理时延迟增加，且奖励函数设计复杂。TATRA（Dziuba et al., 2026, P14）提出无训练实例自适应提示方法，通过重述和聚合提升鲁棒性。该方法在推理时动态生成平衡标签的少样本演示，并对测试输入进行多次重述，聚合预测结果以对抗语言变体。核心组件包括系统提示指令生成器、动态少样本演示构建器以及重述聚合模块。其改进点在于无需任务特定训练集，通过推理时计算换取鲁棒性，避免了离线优化的数据依赖。代价是推理成本随重述次数线性增加。

Advisor Models（Asawa et al., 2025, P3）提出训练小型开放权重模型生成动态自然语言建议，以引导黑盒 LLM 的方法。该方法将提示优化转化为参数化模型训练，顾问模型根据输入生成特定建议，提升前沿模型性能。核心组件包括顾问模型训练框架、动态建议生成机制以及跨模型迁移评估。其改进点在于实现参数化优化，相比静态提示，顾问模型能根据输入动态调整建议，且可迁移至不同前沿模型。代价是需训练顾问模型，且建议质量依赖训练数据覆盖度。

### 2.6 多智能体与协同优化

多智能体与协同优化路线起源于 2023 年 PromptBreeder 的提出，该工作提出进化算法优化提示，通过变异和交叉操作在提示种群中迭代搜索，利用适应度评估保留高性能个体，展示了群体智能在离散提示空间全局搜索中的有效性。MAPGD（Han et al., 2025, P1）提出多智能体提示梯度下降方法，用于协同提示优化。该方法将提示优化建模为混合离散-连续梯度下降过程，多个专业化智能体分别关注正交细化维度，生成文本伪梯度。核心组件包括多智能体协调循环、语义空间嵌入冲突解决机制以及基于伪梯度的提示更新器。其改进点在于利用多视角反馈，单一智能体可能陷入局部最优，而多智能体协同能提供更全面的优化方向。代价是智能体间通信开销大，且冲突解决策略需精心设计。

Helix（Zhu et al., 2026, P15）提出双螺旋共进化多智能体系统，用于联合优化提示指令与问题重构。该方法在训练阶段通过双螺旋共进化学习优化的问题-提示对，在推理阶段应用至未见查询。核心组件包括规划器、问题重构智能体、提示优化智能体以及共进化选择机制。其创新点在于联合优化输入问题与提示，传统方法仅优化提示，而 Helix 认为问题表述也影响性能。代价是优化空间维度增加，搜索难度提升。MASPOB（Hong et al., 2026, P13）提出基于多臂老虎机的多智能体系统提示优化方法，结合图神经网络建模智能体依赖。该方法将提示组合编码为嵌入向量，利用 GNN 代理模型预测组合性能，通过老虎机算法选择最佳组合。核心组件包括拓扑感知 GNN 代理、提示组合编码器以及基于 GNN 预测的老虎机选择器。其改进点在于处理多智能体依赖，传统方法忽略智能体间交互，而 MASPOB 通过图结构建模协同效应。代价是 GNN 训练需大量组合数据，且图结构需准确反映工作流。

The Optimizer Is the Agent（Li et al., 2026, P25）提出推理驱动搜索框架，将 LLM 作为语义优化器，跨提示、程序和 ML 工作流进行优化。该方法赋予智能体上下文压缩与持久记忆能力，通过执行反馈提出结构化编辑。核心组件包括智能体架构、领域特定工具设计以及基于记忆的长程优化机制。其创新点在于将优化器本身视为智能体，利用 LLM 的推理能力自主决定搜索策略，而非依赖固定启发式。代价是智能体行为难以预测，且长程优化需管理上下文长度。

### 2.7 理论分析与鲁棒性

理论分析与鲁棒性路线起源于 2026 年 Sharpness-Aware Prompt Evolving 的提出，该工作提出锐度感知提示进化方法，通过惩罚对语义等价扰动敏感的提示，优化提示景观的平坦区域，显著提升了优化后提示在分布外数据上的鲁棒性与稳定性。Prompts Generalize with Low Data（Madras et al., 2025, P5）提出基于 PAC-Bayes 机制的非平凡泛化界，用于低数据场景下的提示优化。该方法推导数据依赖的提示困惑度泛化界，并将其作为正则化目标优化提示。核心组件包括数据依赖泛化界推导、信息先验选择机制以及正则化提示优化算法。其改进点在于提供理论保证，传统方法缺乏泛化分析，而该方法确保优化提示在低数据下仍具泛化能力。代价是困惑度计算开销大，且先验选择需针对任务调整。

Sharpness-Aware Prompt Evolving（ICLR 2026, P32）提出锐度感知提示进化方法，用于鲁棒 LLM 优化。该方法将文本锐度形式化为对语义等价扰动的敏感性，通过惩罚局部脆弱性选择平坦区域的提示。核心组件包括文本锐度度量模块、锐度感知适应度函数以及进化搜索策略。其改进点在于提升鲁棒性，传统方法仅优化点性能，易受微小扰动影响，而该方法确保提示在分布外数据上稳定。代价是锐度计算需多次扰动评估，增加计算成本。Textual Gradients are a Flawed Metaphor（Melcer et al., 2025, P10）提出对文本梯度隐喻的理论批判，分析其在自动提示优化中的局限性。该方法系统比较提示仅生成与反馈驱动生成机制，揭示文本梯度在离散空间中的非局部性与不稳定性。核心组件包括优化机制分类框架、梯度隐喻失效案例分析以及替代优化策略讨论。其创新点在于挑战主流范式，指出文本梯度并非真正的梯度，而是启发式反馈，误导了优化方向。代价是缺乏替代算法的具体实现，主要贡献为理论分析。

Prompt Optimization Is a Coin Flip（Zhang et al., 2026, P17）提出诊断框架，分析复合 AI 系统中提示优化的有效性条件。该方法通过 ANOVA 预测试耦合性，并通过头部空间测试判断优化价值，指出联合优化并非总是必要。核心组件包括交互项显著性检验、优化价值头部空间评估以及两阶段诊断流程。其改进点在于提供实证诊断，避免盲目进行昂贵的联合优化，识别出提示优化失效的场景。代价是诊断需额外实验成本，且结论依赖特定模型与任务。

### 2.8 跨任务与多领域应用

跨任务与多领域应用是 APO 方法的重要延伸方向，旨在验证不同优化策略在多样化任务中的通用性与适应性。例如，ELPO 在 LIAR、BBH 和 GSM8K 等多个基准上均取得 SOTA 性能，表明集成方法在不同任务类型上的鲁棒性。SAPO 则在 XSum、GSM8K 和 SQuAD 上表现出色，展示了结构化方法在摘要、数学推理和阅读理解任务中的有效性。这些跨任务应用不仅验证了方法的通用性，也为实际部署提供了参考。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

提示对 LLM 性能具有决定性影响，微小的措辞变化可能导致显著的性能差异，这一共识在约 60 篇论文中得到了共同支持。自动化提示优化是适配闭源 LLM 的关键手段，优于人工试错，这一共识在约 55 篇论文中得到了共同支持。基于反馈的迭代优化（如文本梯度、进化搜索）比一次性生成更有效，这一共识在约 45 篇论文中得到了共同支持。样本效率是 APO 的核心挑战，需在有限评估预算下最大化性能，这一共识在约 40 篇论文中得到了共同支持。多目标优化（如准确率与成本）是实际部署的必要考量，这一共识在约 30 篇论文中得到了共同支持。结构化提示分解有助于提升优化的可控性与可解释性，这一共识在约 25 篇论文中得到了共同支持。提示优化结果往往缺乏鲁棒性，需考虑对扰动的敏感性，这一共识在约 20 篇论文中得到了共同支持。多智能体或流水线系统中的提示优化需考虑组件间依赖关系，这一共识在约 15 篇论文中得到了共同支持。

与此相关的另一个共识是，全局探索与局部利用的融合是当前研究的主流趋势。ELPO 在多个任务上取得 SOTA 性能，表明融合策略优于单一策略。这一共识在约 20 篇论文中得到了共同支持。

### 3.2 观点分歧

文本梯度的理论有效性是一个显著分歧。观点 A（ProTeGi, TextGrad）认为文本梯度是有效的局部优化信号，能显著提升性能，类比深度学习反向传播。观点 B（Textual Gradients are a Flawed Metaphor）认为文本梯度并非真正的梯度，具有非局部性与不稳定性，缺乏收敛保证，仅是启发式反馈。现有证据偏向观点 B 在理论严谨性上，但观点 A 在实证性能上占优。证据强度中等，缺乏统一的理论框架来量化文本梯度的有效性。能定输赢的实验是：在具有已知最优解的受控任务中，比较文本梯度与随机搜索/贝叶斯优化的收敛速度与最终性能，并分析其失败案例的分布。分歧根源在于离散文本空间的拓扑结构未知，难以定义‘梯度’的数学性质；不同任务对反馈的敏感度不同，导致结论具有场景依赖性。

这一分歧的背后，是另一个更根本的争论：多智能体/流水线中是否必须进行联合优化？观点 A（ADOPT, MAPGD）认为多步骤系统中提示间存在强依赖，必须通过联合优化/依赖分析才能提升端到端性能。观点 B（Prompt Optimization Is a Coin Flip）认为联合优化并非总是必要，若组件间耦合度低，独立优化即可，盲目联合优化浪费资源。现有证据偏向观点 B 在资源效率上，但观点 A 在复杂耦合任务上性能更优。证据强度较弱，缺乏大规模系统的实证对比。能定输赢的实验是：在多个不同耦合度的多步骤流水线中，系统比较独立优化与联合优化的性能增益与计算成本比。分歧根源在于多步骤系统的耦合度难以量化，且不同任务架构差异大，缺乏通用的诊断工具来判断何时需要联合优化。

### 3.3 其他开放问题

最紧迫的工程问题是如何在有限预算下最大化信息增益（样本效率），可通过贝叶斯优化与多臂老虎机解决。当前研究已提出多种方法，如 BO-LLM 和 TextBO，但其在不同任务上的表现仍有差异。关键困难在于提示空间的复杂度随任务变化，缺乏统一的度量标准来指导策略选择。研究路径包括构建不同复杂度的提示空间基准，分别测试全局与局部策略的性能边界。

最根本的研究问题是提示空间的平滑性与崎岖性未知，缺乏收敛性理论保证。当前研究已提出 PAC-Bayes 泛化界和锐度感知优化，但其在实际任务中的效果仍需进一步验证。关键困难在于离散文本空间的拓扑结构复杂，难以建立统一的理论框架。研究路径包括引入因果推断去混淆或基于 PAC-Bayes 的非平凡泛化界，确保提示在扰动和异构查询下的稳定性。

已知—争议—未知认知图谱：已知提示对 LLM 性能具有决定性影响，自动化提示优化是适配闭源 LLM 的关键手段；争议在于文本梯度的理论有效性和多智能体/流水线中是否必须进行联合优化；未知在于提示空间的平滑性与崎岖性，缺乏收敛性理论保证。发展趋势是从启发式搜索转向具有理论保证的自适应优化框架，结合理论分析与自适应策略，实现 LLM 应用的动态、可靠适配。

## 4. 总结与展望

APO 的核心任务是在黑盒约束下实现离散语义空间的高效探索，当前面临的主要矛盾是提示空间组合爆炸与有限评估预算之间的张力。早期研究通过 APE 和 OPRO 实现了从“人工设计”到“自动化搜索”的关键转折，随后 ProTeGi 和 TextGrad 引入了“文本梯度”概念，标志着优化机制从盲目搜索向反馈驱动的转变。当前研究重心进一步从单一任务优化转向复杂系统优化，包括多智能体工作流、多目标权衡以及鲁棒性提升。核心瓶颈在于提示空间的复杂度随任务变化，缺乏统一的度量标准来指导策略选择，以及多步骤系统中错误归因的计算复杂性。

未来可能突破的方向包括：多步 LLM 流水线联合优化，解决多步骤代理系统中提示间依赖关系复杂、单点优化无法提升端到端性能的问题；评估效率与样本复杂度优化，解决 LLM 评估成本高、黑盒反馈稀缺导致的优化预算浪费问题；多目标与成本感知优化，解决单一准确率指标无法反映部署成本（如 Token 消耗、延迟）和约束条件（如安全、格式）的问题。对进入者最值得做的一件事是构建不同复杂度的提示空间基准，分别测试全局与局部策略的性能边界，以提供统一的度量标准来指导策略选择。
