# A Survey of Jailbreak Attacks and Defenses for Large Language Models ｜大语言模型越狱攻防综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Jailbreak%20Attacks%20and%20Defenses%20for%20Large%20Language%20Models)

## 导读

大语言模型（Large Language Models, LLMs）的广泛部署使其安全对齐机制成为对抗性攻击的高价值目标，越狱攻击通过构造特定提示词绕过安全护栏，诱导模型生成有害内容，构成了严峻的伦理与安全挑战。早期研究聚焦于单轮静态提示下的攻击成功率提升，通过梯度优化或遗传算法实现自动化搜索，但这类方法计算成本高昂且易在饱和点失效。随着多轮对话场景的引入，分解式越狱揭示了无状态防御在跨轮次意图聚合上的根本缺陷，推动防御机制向有状态、上下文感知方向演进。与此同时，潜在空间不连续性攻击将威胁面从接口层延伸至模型核心架构，而多模型广撒网场景则暴露了单一模型安全评估的系统性局限。当前领域正从单一攻击成功率指标转向多维安全评估框架，并在计算效率、动态适应性与架构鲁棒性之间寻求平衡。本综述梳理这条从静态过滤到动态博弈的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

大语言模型在自然语言处理领域的广泛应用使其成为对抗性攻击的高价值目标，越狱攻击通过精心构造的提示词绕过安全对齐机制，诱导模型生成有害内容，构成了严峻的安全与伦理挑战。该领域的研究起源于早期对模型安全护栏脆弱性的发现，随后经历了从单轮静态攻击向多轮动态交互、从语义层面向潜在空间架构层面的范式转变。核心问题并非单纯的技术漏洞，而是对齐机制在复杂分布下的泛化失败，其本质在于模型内部表示空间与外部输入输出层之间的安全边界模糊。

问题的形式化可以表述为：给定一个安全对齐的 LLM $M$ 和一个恶意意图集合 $\mathcal{Y}$，攻击者构造提示词 $x$，使得 $M(x) \in \mathcal{Y}$ 的概率最大化，同时满足隐蔽性约束 $C(x) < \tau$。其中，攻击成功率（Attack Success Rate, ASR）定义为绕过安全检查的不安全提示词比例，是衡量攻击有效性的核心指标。然而，ASR 仅捕捉了攻击的“是否成功”维度，忽略了攻击的稳定性、跨模型可迁移性及隐蔽性，导致对模型真实安全性的误判。子问题之间存在严格的依赖关系：首先需解决自动化攻击的效率问题，才能有效测试防御的鲁棒性；进而发现无状态防御的缺陷，推动有状态防御的发展；最后，有状态防御的局限及架构级漏洞揭示了当前范式的边界，指向潜在空间防御与系统级生态构建。

2016 年至 2018 年，度量学习在少样本学习中的成功为后续对抗样本研究提供了几何视角的启发，但 LLM 越狱攻击的独立研究始于 2023 年。早期方法如 GCG 通过梯度坐标下降优化后缀，在单轮提示中注入对抗性后缀以绕过安全对齐，是早期自动化越狱攻击的代表性基线。这一阶段的核心假设是攻击者拥有白盒访问权限且计算资源无限，问题定义聚焦于“能否绕过”而非“如何高效绕过”。2024 年，PAIR 利用辅助 LLM 进行迭代重写与自反思，显著提升了黑盒场景下的攻击效率与隐蔽性，标志着攻击范式从梯度优化向提示工程的重要转折。

2025 年，研究重心从单纯的攻击成功率提升转向构建多维度的安全评估框架。Security Cube 提出多维评估框架，超越单一 ASR 指标，整合稳定性、可迁移性及内部机制影响，为攻防技术提供系统性基准测试标准。同年，EvoJail 基于多目标进化搜索的长尾分布攻击框架，通过语义-算法表示联合优化攻击有效性与输出质量，实现了自动化长尾越狱，揭示了模型在极端分布偏移下的最坏情况行为。2026 年，TwinGate 针对分解式越狱的有状态防御，利用非对称对比学习在不可追踪流量中检测分布式恶意意图，突破了无状态防御局限。Wide-Net-Casting 则针对多模型广撒网场景，利用模型间漏洞互补性，只要任一模型被攻破即视为成功，揭示了多模型部署风险。

当前领域活跃度极高，研究热点集中在如何平衡安全性与可用性、应对长尾分布攻击以及实现跨模型的通用防御。防御机制需要从被动的事后过滤转向主动的、嵌入模型训练或推理过程的鲁棒性增强，包括监督微调（Supervised Fine-Tuning, SFT）、基于人类反馈的强化学习（Reinforcement Learning from Human Feedback, RLHF）及内部信号引导。同时，多智能体协作框架在提升 LLM 应用的可靠性和安全性方面具有潜力，但同时也引入了新的攻击面，需专门设计针对多智能体系统的防御机制。

**如果用一个核心问题概括该领域，那便是：在计算资源约束与动态对抗环境下，如何构建能够识别跨轮次、跨模型及潜在空间分布式恶意意图的自适应防御体系，并建立多维度的安全评估标准以平衡安全性与可用性。**

## 2. 方法体系

- 2023：GCG——通过梯度坐标下降优化后缀，在单轮提示中注入对抗性后缀以绕过安全对齐，是早期自动化越狱攻击的代表性基线

- 2023：AutoDAN——采用分层遗传算法自动搜索隐蔽的越狱提示，通过进化策略探索对抗样本空间，奠定了自动化攻击框架的基础

- 2024：PAIR——利用辅助LLM进行迭代重写与自反思，通过提示工程优化攻击策略，显著提升了黑盒场景下的攻击效率与隐蔽性

- 2024：RLHF——基于人类反馈的强化学习，通过奖励模型校准模型行为以对齐安全偏好，成为主流LLM安全对齐的核心训练范式

- 2025：Security Cube——提出多维评估框架，超越单一ASR指标，整合稳定性、可迁移性及内部机制影响，为攻防技术提供系统性基准测试标准

- 2025：EvoJail——基于多目标进化搜索的长尾分布攻击框架，通过语义-算法表示联合优化攻击有效性与输出质量，实现自动化长尾越狱

- 2025：HoneyTrap——多智能体欺骗防御系统，通过威胁拦截、误导控制、取证追踪与系统协调四代理协作，动态应对渐进式多轮越狱攻击

- 2026：TwinGate——针对分解式越狱的有状态防御，利用非对称对比学习在不可追踪流量中检测分布式恶意意图，突破无状态防御局限

- 2026：Wide-Net-Casting——针对多模型广撒网场景的越狱攻击，利用模型间漏洞互补性，只要任一模型被攻破即视为成功，揭示多模型部署风险

这条时间线勾勒了该领域方法演进的代表性节点：从 2023 年的 AutoDAN 奠定该领域方法基线，经 2024 年 PAIR 的推进，到 2026 年的 Wide-Net-Casting 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 攻击方法创新

攻击方法创新路线的起源可追溯至 2023 年，当时 GCG 通过梯度坐标下降优化后缀，在单轮提示中注入对抗性后缀以绕过安全对齐，是早期自动化越狱攻击的代表性基线。这一阶段的核心假设是攻击者拥有白盒访问权限且计算资源无限，问题定义聚焦于“能否绕过”而非“如何高效绕过”。AutoDAN 采用分层遗传算法自动搜索隐蔽的越狱提示，通过进化策略探索对抗样本空间，奠定了自动化攻击框架的基础。2024 年，PAIR 利用辅助 LLM 进行迭代重写与自反思，通过提示工程优化攻击策略，显著提升了黑盒场景下的攻击效率与隐蔽性，标志着攻击范式从梯度优化向提示工程的重要转折。

EvoJail（Hong et al., 2026, P6）提出基于多目标进化搜索的自动化长尾分布越狱框架，旨在系统性地探索非自然语言模式下的安全漏洞。其核心创新在于引入语义-算法表示，将候选解建模为可逆的加密-解密算法对，同时操纵高层语义与低层结构变换。框架整合了 LLM 辅助的初始化、变异、交叉和修复算子，在统一的进化循环中联合优化攻击有效性（ASR）与输出质量（困惑度, Perplexity, PPL）。该方法消除了对手工规则的依赖，能够自动发现难以检测的长尾攻击策略，揭示了模型在极端分布偏移下的最坏情况行为。其代价是进化搜索的计算开销较大，且依赖 LLM 辅助算子的质量。该工作在领域中的定位是推动了越狱攻击从启发式规则向自动化、系统化搜索的演进，为评估 LLM 在 Web 环境中的鲁棒性提供了新工具。

Latent Space Discontinuity Exploitation（Paim et al., 2025, P1）提出利用 LLM 潜空间不连续性构建通用越狱与数据提取攻击，首次将攻击面从接口层延伸至模型核心架构漏洞。该方法基于潜空间不连续性导致系统性弱点的观察，开发攻击以实现对不同受保护接口的快速妥协与深度渗透。实验设计分为两阶段：第一阶段评估 LLM 对旨在引发违反安全政策行为的对抗性提示的易感性；第二阶段探索通过针对性攻击提取文本和视觉敏感信息的可行性。攻击语料库包含高破坏性意图，如炸药制造、法医规避及恶意软件生成，基于专业化程度、危害潜力和不可逆性三个维度筛选。其核心优势在于通用性，不依赖特定模型或接口，揭示了架构层面的根本性风险。该方法的代价是白盒或半白盒访问需求较高，且对潜空间结构的理解依赖模型内部机制的可解释性。其在领域中的影响在于警示了基础架构漏洞的安全隐患，推动了从应用层防御向核心架构加固的研究转向。

Wide-Net-Casting Jailbreak Attack（Xiang et al., 2026, P9）提出针对多模型广撒网场景的越狱攻击策略，模拟用户同时向多个 LLM 发送请求以获取有害输出的现实行为。该方法指出，不同模型家族具有独特的模型特定漏洞，当多个模型被分组同时攻击时，其集体漏洞被放大，只要任一模型被成功越狱即视为攻击成功。研究通过直接适配现有的实例级和模型级越狱方法到该场景，量化了广撒网场景下的安全风险放大效应。核心创新在于定义了新的威胁模型，即攻击者无需针对单一模型优化，而是利用模型间的互补性漏洞。其代价是攻击者需要维护多个模型的独立攻击副本或生成器，增加了管理复杂度。该工作在领域中的定位是揭示了多模型部署环境下的系统性风险，强调了单一模型安全评估的局限性，推动了针对多模型协同防御的研究需求。

### 2.2 防御体系构建

防御体系构建路线的起源可追溯至 2024 年，当时 RLHF 基于人类反馈的强化学习，通过奖励模型校准模型行为以对齐安全偏好，成为主流 LLM 安全对齐的核心训练范式。这一阶段的核心假设是安全偏好可以通过训练数据内化为模型属性，问题定义聚焦于“如何从根源消除漏洞”。2025 年，HoneyTrap 提出多智能体欺骗防御系统，通过威胁拦截、误导控制、取证追踪与系统协调四代理协作，动态应对渐进式多轮越狱攻击，标志着防御范式从静态过滤向动态博弈的重要转折。

Responsible AI Defense Framework（Wong et al., 2025, P2）构建涵盖模型级与提示级的综合防御体系，旨在通过内嵌安全护栏与外部净化机制协同降低越狱风险。模型级防御采用 SFT 与 RLHF，将安全对齐转化为模型内部的可泛化属性，而非仅依赖最终输出过滤。提示级防御包含三个顺序组件：首先对输入进行净化与规范化，移除 URL 及已知越狱令牌模式；其次执行轻量级同义词替换扰动，通过随机重述破坏对抗性令牌序列同时保留语义意图；最后利用句向量嵌入计算风险分数，动态选择从温和引导到严格拒绝的系统提示。该框架的核心取舍在于平衡安全性与可用性，通过自适应阈值避免过度拒绝，但依赖预定义的不安全提示参考中心，对完全新颖的攻击模式可能存在检测盲区。其技术定位在于将负责任 AI 原则（公平、透明、问责）直接嵌入防御流程，为生产环境 LLM 部署提供了可解释且动态调整的安全基线。

Multi-Layer Security Assessment Framework（Onitiju and Vakilinia, 2026, P5）设计四层顺序检测架构，结合模式匹配、语义分析、行为分类与主动学习，实现从快速筛查到深度意图识别的渐进式防御。第一层利用优化正则表达式进行已知攻击签名的快速拦截，最小化延迟开销；第二层采用 SentenceTransformer 嵌入进行余弦相似度匹配，检测混淆或新型语义威胁；第三层使用微调的 RoBERTa 毒性检测模型进行行为分类，识别对抗性内容；第四层引入主动学习机制，通过不确定性采样自动更新检测能力以应对演化威胁。该框架的核心创新在于集成主动学习组件，使防御系统具备持续适应能力，克服了静态规则库滞后于攻击演进的缺陷。其代价是多层处理带来的计算开销增加，且依赖高质量参考攻击模式库的维护。该方法在领域中的定位是标准化安全评估与缓解策略的集成，为不同架构 LLM 提供了可复用的风险量化与缓解范式。

HoneyTrap Multi-Agent Deceptive Defense（Li et al., 2026, P3）提出基于多智能体协作的欺骗性防御系统，通过动态适应对抗策略来应对渐进式多轮越狱攻击。系统包含四个专用代理：威胁拦截器通过模糊响应延迟攻击并增加时间成本；误导控制器作为动态诱饵，提供看似有用但无实质内容的回复，将攻击者引入蜜罐陷阱；取证追踪器收集交互日志并提取行为模式以识别攻击签名；系统协调器监控代理性能并动态调整战术以确保协同效应。该框架的核心设计思路是利用欺骗策略消耗攻击者资源，而非直接阻断，从而在保持正常服务的同时延长攻击周期。其关键技术模块在于代理间的实时通信与策略协同，确保防御措施随攻击深度动态升级。该方法的代价是系统复杂度较高，且依赖对攻击者行为模式的准确预测。其在领域中的影响在于引入了“资源消耗”作为防御目标，为对抗高级持续性威胁提供了新的动态防御范式。

### 2.3 评估基准综述

评估基准综述路线的起源可追溯至 2025 年，当时 Security Cube 提出多维评估框架，超越单一 ASR 指标，整合稳定性、可迁移性及内部机制影响，为攻防技术提供系统性基准测试标准。这一阶段的核心假设是单一指标无法全面反映模型安全性，问题定义聚焦于“如何建立多维度的标准化评估框架”。

Security Cube Evaluation Framework（Xu et al., 2026, P8）建立多维评估框架以系统化 LLM 越狱攻防研究，解决现有基准过度依赖 ASR 而忽视稳定性、可迁移性及内部机制影响的缺陷。该框架提出基于主导机制的攻击分类法，将现有方法分为对数概率、洗牌、LLM 辅助、多轮、缺陷利用、策略及模板七类，并定义了粒度、访问权限、反馈需求等标准化维度。评估协议涵盖黑盒与白盒攻击及防御设置，明确攻击者与防御者的能力边界，确保评估聚焦于模型自身行为而非外部操纵。核心创新在于引入 Security Cube 概念，将性能指标从单一维度扩展至多维空间，揭示不同攻击方法在稳定性与可迁移性上的权衡。其代价是评估流程复杂度高，需要大量计算资源进行多轮测试与跨模型验证。该工作在领域中的影响在于提供了标准化的比较基准，促进了攻防技术的可复现性与系统性分析，为后续研究提供了统一的评估语言。

### 2.4 对抗机制分析

对抗机制分析路线的起源可追溯至 2026 年，当时 TwinGate 提出针对分解式越狱的有状态防御机制，解决现有无状态防御在不可追踪流量中无法检测分布式恶意意图的问题。这一阶段的核心假设是防御机制需要具备上下文感知能力，问题定义聚焦于“如何识别跨轮次、跨会话的分布式恶意意图”。

TwinGate Stateful Defense via Asymmetric Contrastive Learning（Sun et al., 2026, P7）提出针对分解式越狱的有状态防御机制，解决现有无状态防御在不可追踪流量中无法检测分布式恶意意图的问题。该方法形式化了“孤立安全，聚合危险”的威胁模型，将恶意意图分解为多个看似无害的子任务，并在全局请求流中交错注入。核心技术创新在于利用非对称对比学习训练有状态决策函数，该函数条件于全局历史查询，通过时间记忆拦截分散的恶意意图。数据集构建包含大量良性背景噪声与恶意意图分解，严格遵循意图级划分以防止数据泄露。其核心取舍是引入了对全局历史状态的依赖，增加了存储与计算开销，但显著提升了在攻击者分散会话或身份场景下的检测能力。该方法在领域中的定位是突破了会话级监控的局限，为不可追踪流量环境下的 LLM 安全提供了新的有状态防御范式。

Systematic Scaling Analysis of Jailbreaks（Wang et al., 2026, P4）建立越狱攻击的计算缩放定律框架，将攻击视为计算受限的优化过程，在统一的浮点运算次数（Floating Point Operations, FLOPs）轴上比较不同攻击范式的效率。研究涵盖优化基、自反思提示、采样选择及遗传优化四种代表性攻击，拟合饱和指数函数以描述 FLOPs 与攻击成功率的关系。核心发现包括：提示基方法（如 PAIR）在计算效率上显著优于优化基方法（如 GCG），且在成功率-隐蔽性操作点上占据更有利位置。通过同一状态比较，从优化视角解释了提示基攻击在提示空间中更有效的优化机制。该分析还揭示了漏洞的目标依赖性，错误信息类目标通常比非错误信息类目标更容易被越狱。其代价是评估过程需要大量计算资源以覆盖广泛的预算网格与模型家族。该工作在领域中的影响在于提供了量化攻击效率的理论基础，指导防御者识别高威胁攻击类型，并优化资源分配以应对不同计算预算下的攻击。

### 2.5 跨任务与多领域应用

当前 LLM 越狱攻防研究正从单一文本模态向多模态、多任务场景扩展。多模态越狱攻击利用视觉-语言模型中的跨模态漏洞，通过图像-文本联合提示绕过安全对齐机制。多任务场景下的越狱攻击则利用任务间的语义关联，将恶意意图隐藏在看似无害的任务请求中。这些跨任务与多领域应用揭示了 LLM 安全问题的复杂性与系统性，推动了针对多模态、多任务场景的防御机制研究。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLM 的安全性不能仅依赖模型能力基准或品牌信誉，必须通过大规模、标准化的对抗性测试进行主动验证。这一共识在多个基准上被反复验证：Security Cube Evaluation Framework 在 HarmBench 上报告的 16.8% 与 23.2% Avg ASR 均远低于早期方法如 LLM-Adaptive 的 95.0% ASR，表明标准化评估能够更准确地反映模型安全性。与此相关的另一个共识是，单一的 ASR 指标不足以全面评估 LLM 安全性，需结合稳定性、隐蔽性、跨模型迁移性及内部机制影响等多维度指标。Security Cube 框架揭示了不同攻击方法在稳定性与可迁移性上的显著差异，单一 ASR 无法捕捉这些权衡。

无状态防御机制在面对多轮、分解式或长尾分布攻击时存在根本性缺陷，必须引入有状态、上下文感知的防御策略。TwinGate 在 TwinGate Benchmark 上实现的 0.76 恶意意图召回率与低于 0.2% 的 FPR，显著优于无状态防御在不可追踪流量中的表现。自动化攻击框架（如基于进化算法或 LLM 辅助生成）比人工模板更具通用性和效率，是未来攻击趋势的主要方向。EvoJail 在 JBB-Behaviors 上以 0.790 的 HV 值领先，表明自动化搜索在长尾分布攻击中的优势。

### 3.2 观点分歧

防御重心的争论集中在训练时对齐与推理时干预之间。观点 A（训练时对齐）认为通过 SFT/RLHF 将安全偏好内化为模型属性，从根源消除漏洞，长期稳定性高；观点 B（推理时干预）认为通过动态过滤、多智能体协作在推理阶段实时应对未知攻击，灵活性高，适应性强。现有证据偏向观点 B 在应对新型、长尾攻击上的有效性，因为训练数据无法覆盖所有潜在攻击模式。但观点 A 在降低推理延迟和计算成本上具有优势。决定性实验：在包含大量未见过的长尾攻击分布的基准上，比较两种防御策略的 ASR 与 FPR 权衡。这一分歧的背后，是另一个更根本的争论：多智能体防御的风险与收益。观点 A 认为多智能体协作能实现动态、自适应的安全防护，提升系统鲁棒性；观点 B 认为多智能体系统引入了新的攻击面，如代理间通信劫持、代理行为预测失败等，可能降低整体安全性。现有证据主要支持观点 A，HoneyTrap 在 MTJ-Pro 基准上展示了高成功率。但缺乏针对多智能体系统内部攻击的系统性评估，观点 B 的风险尚未被充分量化。

### 3.3 其他开放问题

最紧迫的工程问题是开发自适应和高效的防御机制，以在保持鲁棒性的同时确保持续可用性。当前防御在计算效率和可扩展性之间存在权衡，研究界正尝试通过轻量级中间件和推理时控制来实现。关键困难在于如何在有限的计算资源下实现动态适应，研究路径包括优化多智能体协作的计算开销和开发高效的有状态检测算法。最根本的研究问题是探索潜空间拓扑脆弱性的形式化表征和防御。当前安全范式主要关注表面级解决方案而忽视内部几何和概率属性，研究界正尝试通过子符号攻击向量和内部几何脆弱性缓解来推进。关键困难在于潜空间结构的复杂性和不可解释性，研究路径包括开发基于内部表示的安全监控机制和建立潜空间脆弱性的数学模型。

## 4. 总结与展望

LLM 越狱攻防领域的核心矛盾在于自动化攻击的指数级增长与静态防御的滞后性。从 2023 年的 GCG 梯度优化到 2026 年的 Wide-Net-Casting 多模型广撒网，攻击范式经历了从单点突破到系统性渗透的演进；从 RLHF 训练时对齐到 TwinGate 有状态防御，防御范式经历了从被动拦截到主动博弈的转型。核心瓶颈在于如何在计算资源约束下，构建能够识别跨轮次、跨模型及潜在空间分布式恶意意图的自适应防御体系，并建立多维度的安全评估标准以平衡安全性与可用性。

未来可能突破的方向包括：第一，开发自适应和高效的防御机制，通过轻量级中间件和推理时控制解决计算效率与可扩展性的权衡，这一方向由 Responsible AI Defense Framework 和 Multi-Layer Security Assessment Framework 共同指向；第二，探索潜空间拓扑脆弱性的形式化表征和防御，通过子符号攻击向量和内部几何脆弱性缓解推进，这一方向由 Latent Space Discontinuity Exploitation 和 TwinGate 共同指向；第三，建立计算归一化的缩放曲线报告标准，通过参数化缩放曲线涵盖模型、攻击、任务、语言和协议等变量，这一方向由 Systematic Scaling Analysis of Jailbreaks 和 Security Cube Evaluation Framework 共同指向。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，构建包含长尾分布攻击的多维评估基准，以隔离方法贡献并揭示防御机制的真实鲁棒性边界。
