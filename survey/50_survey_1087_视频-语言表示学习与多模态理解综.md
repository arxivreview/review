## 导读

视频-语言表示学习旨在构建能捕捉时空动态与语义关联的统一表征，其核心驱动力在于突破静态图像理解的局限。早期研究依赖对比学习建立图文对齐，但视频数据的时序冗余与高昂标注成本成为主要瓶颈。随着大语言模型的引入，领域重心从感知转向推理，然而语言先验偏差导致模型过度依赖文本捷径而非视觉证据。近期研究聚焦高效预训练、动态模态融合及细粒度接地，以解决长视频理解与真实场景鲁棒性问题。各路线在计算效率、对齐精度与视觉依赖度之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从特征对齐到语义接地的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

视频-语言表示学习的兴起源于对静态图像理解局限性的突破需求，其核心在于构建能够捕捉时空动态与语义关联的统一表征。早期研究依赖手工特征或简单的双流网络，随后 CLIP 等大规模对比学习模型确立了图像-文本对齐的范式，但视频数据的时序冗余与标注成本高昂成为主要瓶颈。这一阶段的根本假设是“对齐即理解”，即通过建立视觉与文本在语义空间上的匹配，即可实现零样本迁移与通用识别。然而，这种全局特征对齐难以捕捉细粒度的时序动态，导致模型在需要精确时间推理的任务上表现不佳。

问题定义在 2024 年发生了关键转折，随着 LLaVA 等视觉-语言模型（Vision-Language Models, VLMs）的兴起，研究重心从单纯的检索与分类转向基于指令的复杂推理。此时，核心矛盾转变为语言先验偏差（Language Prior）与长视频上下文长度限制之间的冲突。模型往往过度依赖文本线索而非视觉证据进行推理，导致视觉中心任务性能下降。这一发现迫使领域重新定义“理解”的边界，从粗粒度的语义匹配转向细粒度的视觉接地（Grounding），即要求模型将语言描述精确映射到视觉空间中的具体对象或时间段。

子问题之间呈现强依赖关系，高效预训练是基础，决定了模型对时序信息的捕捉上限；跨模态对齐是核心机制，若对齐不精准则无法实现细粒度接地；而语言先验偏差则是阻碍视觉推理的关键障碍，必须通过视觉接地后训练解决，否则长视频理解将退化为纯文本生成。这种依赖结构意味着，任何单一维度的优化若缺乏其他维度的支撑，都难以带来整体性能的提升。例如，即使预训练数据规模扩大，若缺乏有效的去偏机制，模型仍可能在视觉推理任务上失效。

2016 至 2018 年是领域的奠基期，研究主要聚焦于视频-文本对比学习的基础架构建立。这一时期的方法假设视频可以通过均匀采样转化为图像序列，并复用图像领域的对齐技术。然而，这种假设在长视频和复杂动作场景下迅速失效，暴露出时序信息丢失与语义错位的问题。2020 年跨域基准的引入进一步揭示了域偏移下的原型崩溃问题，促使研究者开始关注视频特有的时序建模机制。

2021 年，CLIP 和 VideoCLIP 等工作证明了视频预训练对零样本识别的价值，标志着从图像迁移到视频范式的正式确立。这一阶段的方法主要解决“如何高效地将图像-文本对齐范式迁移至视频”的问题，瓶颈在于视频数据的时序冗余与标注成本。2024 年，Flamingo 和 LLaVA 引入大语言模型，实现了从感知到推理的跨越，但同时也引入了新的计算成本与语言偏差问题。2025 至 2026 年，研究进入细化与融合阶段，ClusterSTM 提出簇级时空掩码以提升预训练效率，VidGround 通过强化学习后训练消除语言先验，Molmo2 则推动了开源接地模型的普及。

当前形态下，领域已从单纯的检索与分类转向长视频理解、细粒度对象定位、多模态融合（音频/深度）及边缘设备部署。研究重心不再仅仅是提升基准分数，而是解决真实世界中模态缺失、时序错位及计算资源受限等复杂问题。开源数据集（如 LAION-BVD）与模型（如 Molmo2）的涌现，推动了从封闭专有模型向开放、可解释、高效能范式的转变。

**如果用一个核心问题概括该领域，那便是：如何在计算资源受限与模态分布差异巨大的约束下，构建一种能够消除语言先验偏差、实现细粒度时空接地的统一视频-语言表征空间。**

## 2. 方法体系

- 2021：CLIP——通过大规模图像-文本对比学习建立对齐的视觉与语言嵌入空间

- 2021：VideoCLIP——将CLIP的对比学习范式扩展至视频领域

- 2024：Flamingo——引入交叉注意力层桥接预训练视觉模型与语言模型

- 2024：LLaVA——通过轻量级投影层对齐视觉编码器与LLM

- 2025：LLaVA-Prime——提出基于视频数据的四阶段预训练框架

- 2025：UniMVU——设计指令驱动的问题条件动态门控机制

- 2026：ClusterSTM——提出簇级时空掩码策略

- 2026：VidGround——提出基于视觉接地的后训练技术

这条时间线勾勒了该领域方法演进的代表性节点：从 2021 年的 CLIP 奠定该领域方法基线，经 2024 年 Flamingo 的推进，到 2026 年的 VidPrism 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 视频语言预训练

视频语言预训练路线的起源可追溯至 CLIP（Radford et al., 2021）确立的对比学习范式，其核心假设是大规模图文对能建立通用的语义对齐空间。VideoCLIP（Bain et al., 2021）将这一范式扩展至视频领域，通过联合视频-图像训练实现零样本视频识别，证明了视频预训练对视频语言理解任务的显著增益。然而，传统掩码策略在视频预训练中易导致时序信息泄露，且随机掩码难以保留强时间相关性的 Token。ClusterSTM（Zhuang et al., 2026, P13）针对这一问题，提出了簇级时空掩码策略，通过帧内聚类与时间密度掩码保留强时间相关性的 Token，结合视频-文本相关性生成，显著降低了预训练的计算成本并缓解了时间信息泄露。该方法放弃了随机掩码的通用性，换取了时序语义的一致性，代价是依赖教师模型的质量且聚类过程引入额外计算开销。

LLaVA-Prime（P29）则从数据维度切入，提出基于视频数据的四阶段预训练框架，利用视频-文本对增强多模态学习，通过因果层级聚合解决静态图像预训练的数据瓶颈。该方法放弃了仅依赖高质量静态图像数据的传统范式，转而利用大规模视频数据提升数据效率，使 LLM 直接学习视频时序语义。其代价是增加了预训练阶段的计算复杂度，需要处理更长的视频 Token 序列。MoVA（Zhu et al., 2026, P25）进一步解决了长视频-文本对齐中的时间错位问题，设计非对称双投影模块，利用稀疏约束解耦文本与视觉概念，通过帧到文本与文本到视频的双向对齐目标提升长视频检索性能。V-SONAR（P30）则探索了统一潜在空间建模，利用潜在扩散语言模型直接在连续嵌入空间操作，实现了视觉与语言的统一建模，放弃了离散 Token 生成范式，换取了更细粒度的语义对齐能力。

### 2.2 多模态融合机制

多模态融合机制路线旨在解决视频、音频、深度等多源模态的动态融合与对齐问题。早期方法如 Flamingo（Alayrac et al., 2024）引入交叉注意力层桥接预训练视觉模型与语言模型，支持少样本多模态学习，解决了固定融合策略难以适应多样任务的问题。然而，静态融合权重无法根据查询内容动态调整，导致在特定查询下性能次优。UniMVU（Ding et al., 2026, P19）针对这一问题，设计了指令感知的问题条件动态门控机制，在特征与模态两个层级实现动态融合，根据查询内容自适应调整模态权重。例如，对于“说了什么”的查询，模型会上调音频权重；对于“发生了什么动作”，则结合 RGB 与深度信息。该方法放弃了静态融合的通用性，换取了特定查询下的最优模态贡献，代价是增加了门控模块的计算开销。

RDMF（Fang et al., 2026, P24）借鉴图灵图案理论，将视频帧和文本词元视为反应-扩散系统中的物质，通过非线性动力学过程模拟时空语义的演化，解决了现有方法难以捕捉复杂时空语义动态的问题。Incomplete VLM（Fang et al., 2026, P20）则关注真实场景中模态缺失的问题，设计了多模态特征近似模块，利用可用模态信息推断缺失模态的特征表示，通过多模态知识蒸馏增强模型对缺失模态的鲁棒性。Modality Bias Mitigation（Li et al., 2026, P10）通过交替纪元估计语言优势，利用视觉-only 分支的损失作为代理，计算语言模态对定位性能的贡献，显式优化语言模态相对于视觉模态的增益，防止模型过度依赖视觉或语言。这些方法共同构成了多模态融合的动态化与鲁棒化趋势，与预训练路线互补，前者提供基础表征，后者优化表征的交互方式。

### 2.3 高效架构与部署

高效架构与部署路线聚焦于降低视频语言模型的计算与存储开销，实现端侧实时推理。LLaVA（Liu et al., 2024）确立了“视觉编码器+投影层+LLM”的主流架构，大幅降低了多模态大模型的训练与部署门槛。然而，固定采样率导致的关键动态信息丢失仍是主要瓶颈。VidPrism（Lin et al., 2026, P22）提出异构混合专家架构，通过速率引导的时空聚合模块在不同分辨率下采样帧特征，利用混合评分机制评估帧重要性，解决了固定采样率丢失关键动态信息的问题。该方法放弃了均匀采样，换取了自适应的帧特征融合，代价是增加了专家模块的计算开销。

MoTE（Ali et al., 2026, P27）提出任务专家混合架构，通过样本级任务路由选择解码器 FFN 专家，支持异构程序性视频理解任务，解决了单一解码器难以兼顾多任务目标的问题。ATOM（Panchal et al., 2025, P6）则针对移动设备部署，通过持久化复用关键模块如视频编码器和统一语言解码器，避免多阶段流水线中重复加载模型，显著降低了端到端延迟。PEEK（Steunou et al., 2026, P23）采用两阶段框架，利用强文本条件视觉语言教师对候选帧进行相关性评分，训练轻量级时间评分器模仿该排名，实现了无查询的时间帧选择。这些方法在效率与精度之间做出了不同取舍，与融合路线形成互补，前者优化计算路径，后者优化信息交互。

### 2.4 视频理解应用

视频理解应用路线涵盖视频翻译、摘要、细粒度定位及情感识别等具体任务，强调实际应用中的鲁棒性与准确性。SWIM（Sun et al., 2026, P18）设计注意力正则化机制，利用自然语言参考数据对名词 Token 的跨模态注意力进行监督，将对象名词与地面真值掩码确定性地链接，引导模型将激活集中在相关视觉区域，解决了 MLLM 中对象名词产生扩散激活的问题。SG-FSCFormer（Zhang et al., 2026, P12）设计场景图引导的细粒度分割字幕 Transformer，通过提示引导的时间图 Former 捕获用户指定对象及其关系，利用跨时间细粒度对齐损失实现掩码与字幕的联合生成，支持可控视频分割与字幕任务。

MLLM Video Translation（QU et al., 2026, P16）将 MLLM 作为语义推理器、表达表演者和视觉合成器，联合建模跨语言翻译、语音生成和唇形同步，解决了传统级联流水线在语义保真、说话人身份和情感一致性上的局限。Global Context VMT（Chen et al., 2026, P15）设计全局视觉信息检索模块，从整个视频中检索与字幕相关的视觉片段，动态融合全局与局部视觉信息，解决了长视频翻译中上下文缺失的问题。ClipSum（Nazir et al., 2026, P17）利用冻结的 CLIP 特征与显式时间建模框架，针对教学视频进行多模态抽象摘要，通过轻量级架构组件适应程序性视频的时间动态。这些应用方法依赖于底层预训练与融合机制的质量，同时通过任务特定的模块设计提升了特定场景下的性能。

### 2.5 数据与学习范式

数据与学习范式路线关注数据质量、迁移学习及少样本适应策略，旨在缓解数据稀缺并提升模型在新域中的泛化性能。VidGround（Zhang et al., 2026, P14）提出基于视觉接地的后训练技术，通过多模型一致性分析筛选必须依赖视觉输入的问题，利用强化学习后训练消除语言先验捷径，显著提升了视频大模型在长上下文理解中的视觉依赖度。该方法放弃了通用后训练数据，转而聚焦视觉依赖问题，代价是数据筛选需要多个前沿模型评估且 RL 训练不稳定。

Molmo2（Clark et al., 2026, P8）构建了包含密集视频字幕、长视频 QA 及开放词汇定位的全开源多模态语料，引入时空点与对象跟踪输出，填补了开源视频语言模型在细粒度定位能力上的空白。LAION-BVD（Hochlehnert et al., 2026, P28）提出一个包含 1000 万小时视频数据的开放多模态预训练数据集，通过自动语音识别、字幕、替代文本和 LLM 生成字幕等多种方式构建，解决了现有公开视频数据集规模不足的问题。VIOLA（Fujii et al., 2026, P9）通过选择性标注和伪标签构建混合演示池，利用 MLLM 进行检索与推理，解决了标注稀缺场景下的模型适应问题。WSV（Fu et al., 2026, P26）利用文本到视频模型生成合成视频，使模型在训练时“观看”合成视频，缓解了模态差距导致的语义丢失。这些方法为其他路线提供了数据基础与学习策略，与预训练路线紧密关联，共同决定了模型的性能上限。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

大规模预训练与指令微调是提升 VLMs 通用理解能力的核心路径，这一共识在多个基准上被反复验证：VidGround 的 74.5 与 Molmo2 的 72.6 在 VideoMME 上均大幅超越传统方法，表明数据规模与后训练策略的有效性。然而，该共识的边界在于数据质量与模态对齐精度仍是决定性能上限的关键因素，单纯扩大数据规模若缺乏高质量标注，可能引入噪声而非增益。与此相关的另一个共识是视觉编码器与 LLM 的结合已成为主流架构，但如何高效地将视频时序信息转化为 LLM 可理解的 Token 序列仍是技术难点，ClusterSTM 与 LLaVA-Prime 的不同策略反映了这一难点的复杂性。

### 3.2 观点分歧

语言先验偏差的消除策略存在根本分歧：VidGround 主张通过 RL 后训练显式纠偏，而部分预训练研究认为优化预训练数据即可缓解。现有证据偏向 VidGround，其在 VideoMME 上的 74.5 准确率表明视觉接地后训练有效提升了视觉依赖度，但 RL 训练成本高且不稳定，且缺乏大规模对比实验证明预训练优化无法达到同等效果。这一分歧的背后，是另一个更根本的争论：多模态融合策略应采用动态门控还是静态加权。UniMVU 主张查询感知动态门控，而传统方法主张静态加权。现有证据显示动态门控在特定查询下更优，但通用性待验证，缺乏跨任务、跨模态组合的标准化评测基准。

### 3.3 其他开放问题

最紧迫的工程问题是边缘设备部署中的计算资源约束，VidPrism 与 ATOM 等方法虽提升了效率，但尚未在真实边缘设备上实现实时推理，关键困难在于模型压缩与模块化复用的平衡。最根本的研究问题是长视频时序建模中的稀疏采样与密集建模之争，PEEK 与 ClusterSTM 分别代表两种极端，现状是缺乏统一的效率-精度权衡评测，研究路径可能在于结合稀疏采样与局部密集建模的混合策略。已知的是大规模预训练的有效性，争议的是去偏与融合的最优路径，未知的是真实世界鲁棒性与基准测试表现之间的差距。

## 4. 总结与展望

视频-语言表示学习已从单纯的“特征对齐”范式跃迁至“语义接地”范式，核心矛盾在于语言模型的强大先验与视觉证据的细粒度需求之间的冲突。尝试过的路线包括预训练提效、融合动态化与接地显式化，但核心瓶颈仍是如何在资源约束下实现视觉证据的细粒度利用与语言先验的有效抑制。这一瓶颈回扣了领域核心问题：构建消除语言偏差、支持细粒度接地的统一表征空间。

未来可能突破的方向包括：长视频时序建模与高效处理，结合稀疏帧采样与时序专家混合（MoE），PEEK 与 MoTE 共同指向这一路径；多模态融合中的模态偏差与干扰抑制，通过指令感知门控与模态协同低秩分解，UniMVU 与 MC-LRD 共同指向这一方向。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，系统评测不同去偏策略（如 RL 后训练 vs. 数据优化）在长视频复杂场景下的泛化性，以填补当前评测体系的空白。
