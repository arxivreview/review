# A Survey of Generative Multi-Agent Social Simulation Methods ｜生成式多智能体社会模拟方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Generative%20Multi-Agent%20Social%20Simulation)

## 导读

生成式多智能体社会模拟利用大语言模型构建高保真人工社会，旨在突破传统基于智能体模型在语义丰富性与适应性上的局限。早期研究以定性涌现为核心，通过记忆与规划机制在沙盒中复现连贯社会行为，确立了 LLM 作为社会模拟底座的范式。随着研究规模扩大，计算瓶颈与结果不可复现性成为主要障碍，推动领域向模块化框架与大规模工程化方向演进。当跨域基准暴露出提示敏感性与模型偏差导致的宏观结果剧烈波动后，研究重心转向科学验证与机制解释，引入耦合增益等定量诊断工具以区分真实社会动力学与模型伪影。各路线在表示质量、计算效率与科学严谨性之间做出了不同取舍，由此形成当前基础设施、动力学建模与验证评估多元并存的格局。本综述梳理这条从定性演示到定量验证的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

传统基于智能体的模型（Agent-Based Modeling, ABM）长期依赖刚性启发式规则来模拟宏观社会现象，如 Schelling 隔离模型（Schelling, 1971）和 DeGroot 共识模型（DeGroot, 1974）。这些经典模型虽然揭示了微观规则如何涌现宏观模式，但其行动空间受限于预设的数学公式，难以捕捉人类行为中复杂的语义交互、情境适应性与认知灵活性。这种语义贫乏性导致 ABM 在模拟开放环境下的社会动态时缺乏生态效度，无法准确反映个体信念演化、情感驱动及规范内化等深层机制。大语言模型（Large Language Model, LLM）的引入改变了这一局面，其强大的自然语言生成与推理能力为智能体提供了更丰富的行动空间，使得模拟能够基于自然语言交互而非预设代码规则，从而显著提升了社会模拟的保真度。

生成式多智能体社会模拟的核心问题可形式化为：给定 $N$ 个具备记忆、反思与规划能力的 LLM 智能体，在特定环境 $E$ 中通过 $T$ 轮自然语言交互，生成宏观社会状态 $S_T$，使得 $S_T$ 在统计特性与机制逻辑上与真实人类社会现象 $S_{real}$ 一致。这一问题包含三个紧密耦合的子问题：基础设施的可扩展性、集体行为的涌现机制以及模拟结果的科学有效性。基础设施层解决“能否运行”的问题，涉及百万级智能体的内存管理与通信拓扑优化；集体行为层解决“如何涌现”的问题，关注微观交互如何导致共识、极化或合作等宏观模式；验证评估层解决“是否真实”的问题，旨在区分由真实社会动力学驱动的结果与由 LLM 固有偏差（如谄媚性、同质化）导致的伪影。这三个子问题存在强依赖关系：没有稳定的基础设施，大规模集体行为研究无法开展；没有有效的验证标准，集体行为研究的科学价值无法确立，进而无法支撑垂直领域的政策模拟应用。

领域的演进历程反映了约束条件的逐步变化。2023 年，Park et al. 提出的生成式智能体（Generative Agents）通过记忆、反思与规划架构，在沙盒环境中实现了涌现的社会行为，确立了 LLM 社会仿真的范式，但此时研究主要关注定性演示，缺乏定量验证标准。2024 至 2025 年，随着 OASIS 和 Agent-Kernel 等框架的出现，研究重心转向大规模部署与模块化设计，试图解决计算瓶颈与系统可复现性问题，将仿真从单一沙盒扩展至百万级智能体规模。2025 至 2026 年，领域进入“科学严谨性”阶段，SLALOM、TRAILS 及耦合增益（Coupling Gain）等工具的出现，标志着研究焦点从构建系统转向验证与评估，核心问题变为如何量化模拟的有效性并建立鲁棒性审计标准。这一转变源于早期研究中暴露出的“蝴蝶效应”，即提示格式的微小变化可能导致宏观结果出现巨大差异，使得科学声明缺乏可靠性。

当前，该领域正从定性演示向定量预测、政策模拟及经济/城市/法律等垂直领域应用深化。研究不仅关注 LLM 智能体能否复现宏观现象，更关注其内部机制是否与社会动力学理论一致。例如，通过引入博弈论均衡（如近似完美贝叶斯均衡）和经典动力学模型（如 DeGroot 模型）进行理论锚定，研究者试图建立微观决策与宏观动态之间的可追溯因果链。同时，文化多样性与偏差控制成为新的关注点，多文化基准（如 LiveCultureBench）和偏差控制自适应原型（APS）等方法旨在解决 LLM 训练数据中的文化同质化问题。

**如果用一个核心问题概括该领域，那便是：如何在保持 LLM 语义生成优势的同时，通过理论锚定与定量审计构建一个计算可扩展、统计可复现且机制可解释的高保真人工社会仿真系统。**

## 2. 方法体系

- 1971：Schelling Segregation Model——通过简单的微观偏好规则模拟宏观居住隔离现象，确立了基于智能体建模（ABM）研究社会涌现现象的范式

- 1974：DeGroot Consensus Model——将意见形成形式化为迭代加权平均过程，揭示了网络拓扑对共识收敛的影响，成为后续所有LLM意见动力学研究的核心对比基线

- 2023：Generative Agents (Smallville)——提出记忆、反思与规划架构，使LLM智能体在沙盒环境中表现出连贯的日常行为与社会互动，开启了生成式社会仿真的新纪元

- 2024：OASIS——实现了百万级智能体的大规模社会仿真，通过消融研究验证了回声室效应等宏观现象，证明了LLM仿真在大规模部署中的可行性

- 2025：Agent-Kernel——提出微内核多智能体系统框架，支持运行时动态更新智能体、动作与环境，解决了传统仿真框架难以适应社会动态演化的工程难题

- 2025：SLALOM——提出基于纵向观察指标的生命周期分析框架，通过多变量轨迹匹配与航点约束验证仿真有效性，解决了LLM仿真作为“黑盒”难以科学验证的问题

- 2026：TRAILS——建立智能体、交互与系统三层鲁棒性审计分类法，揭示提示格式微小变化对宏观结果的巨大影响，确立了LLM社会仿真科学声明的审计标准

- 2026：Coupling Gain Diagnostic——提出耦合增益γ作为测量LLM智能体社会敏感性的量化指标，区分真实社会动态与模型谄媚伪影，为涌现现象提供了可测量的物理量

这条时间线勾勒了该领域方法演进的代表性节点：从 1971 年的 Schelling Segregation Model 奠定该领域方法基线，经 1974 年 DeGroot Consensus Model 的推进，到 2026 年的 TRAILS 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 社会模拟基础设施

社会模拟基础设施的演进始于对早期单体沙盒架构局限性的回应。2023 年，Park et al. 提出的生成式智能体（Generative Agents）虽然实现了连贯的社会行为，但其架构紧密耦合，难以扩展至多样化场景或进行大规模部署。为了解决这一问题，GANG 框架（Li et al., 2025, P2）引入了模块化、面向对象的设计，通过层级结构整合基类并采用记忆摘要机制，从原始记忆中过滤和蒸馏相关信息。该框架放弃了单体架构的简洁性，换取了系统的可维护性与扩展性，使用户能够通过组合派生类定制特定模拟环境。然而，GANG 仍主要关注静态环境的构建，未能解决社会动态演化中的运行时更新问题。

针对静态框架无法适应人口波动与环境变化的局限，Agent-Kernel（Mao et al., 2025, P10）提出了微内核多智能体系统框架。该框架将核心逻辑与社会角色逻辑解耦，支持智能体、动作和环境的运行时动态更新。其核心取舍在于增加了系统复杂度与调试难度，换取了动态适应性与模块化扩展能力，使得系统能够灵活应对社会动态演化。与此同时，计算成本成为大规模仿真的主要瓶颈。ScaleSim（Pan et al., 2026, P15）针对内存管理瓶颈，提出基于调用距离的内存管理策略，利用 LLM 智能体行为中稀疏激活的特性优化内存分配。该方法放弃了全量内存预分配，换取了硬件成本的大幅降低，使百万级智能体仿真在有限资源下成为可能。

为了进一步提升仿真的科学性与可复现性，EASE 配置框架（Sarangi et al., 2026, P35）将仿真设计分解为环境、智能体、仿真引擎和评估指标四个核心组件，强调评估指标在配置中的重要性。该框架通过标准化仿真描述语言，解决了不同研究之间设置不可比的问题，推动了社会仿真从“演示”向“科学”的转变。此外，AgoraSim（Chen, 2026, P40）提出了混合智能体建模框架，结合经典 ABM 与 LLM 智能体，通过比较两者在明确建模假设下的轨迹，揭示定性模式的稳健性。该框架弥补了纯 LLM 仿真缺乏理论约束的不足，为混合仿真提供了实用工具。在计算优化方面，Poor Man's Agentic Modeling（Itkin, 2026, P42）通过行为克隆拟合低参数代理映射，用简单的参数化模型替代昂贵的 LLM 调用，显著降低了大规模仿真的计算成本，使得资源有限的研究者也能进行社会动力学实验。

### 2.2 集体行为涌现机制

集体行为涌现机制的研究旨在揭示微观交互如何导致宏观社会现象，如共识、极化与合作。早期研究主要依赖 LLM 的自由生成，但缺乏对内部机制的透明解释。DeGroot-LLM 共识模型（Yazici et al., 2026, P16）将经典 DeGroot 模型应用于 LLM 智能体网络，通过情感分析将文本消息映射为意见分数。研究发现 LLM 智能体通常达到共识，但极限意见偏离 DeGroot 预测，揭示了 LLM 智能体对初始条件不敏感而强烈依赖于模型内在偏好的特性。这一发现促使研究者关注模型偏差对宏观结果的影响。

网络效应与意见漂移研究（Cau et al., 2026, P25）进一步量化了模型偏差在群体互动中的放大效应。研究发现不同 LLM 模型在意见演化上存在系统性差异，如 Gemma 模型表现出更强的向积极意见漂移的趋势。该研究提醒研究者在选择 LLM 进行社会仿真时需考虑模型特定的行为偏差，避免将模型伪影误认为社会现象。为了更精细地模拟信念演化，ScioMind（Yang et al., 2026, P31）引入了基于锚定的信念动态机制，将信念改变阻力建模为对记忆锚点的依附。该机制结合了社会开放度、自我权重和社会影响力，提升了仿真在信念演化方面的心理真实性。

在验证涌现现象的真实性方面，耦合增益诊断（Yang, 2026, P38）提出了耦合增益 $\gamma$ 作为测量 LLM 智能体社会敏感性的量化指标。通过反事实扰动直接测量智能体向邻居意见移动的程度，该方法区分了真实的社会平均化与模型先验伪影。研究发现 $\gamma$ 在不同 LLM 模型间稳定且可区分，且对提示重述不变，表明其是证据耦合而非独特社会量。这一指标为评估 LLM 社会仿真的有效性提供了定量工具。此外，传染张量框架（Liu, 2026, P39）提出了一种测量多智能体 LLM 系统中输出分布耦合的框架，量化偏差如何在网络中传播，填补了单模型偏差探针和多智能体定性案例研究之间的空白。

### 2.3 仿真验证与评估

仿真验证与评估是确保 LLM 社会模拟科学有效性的关键环节。早期研究缺乏公认的基准和评估指标，导致“流畅但虚假”的行为难以与“真实”的社会动力学区分。SLALOM 生命周期分析框架（Lee and Seering, 2026, P26）提出通过纵向观察指标评估智能体仿真，采用多变量轨迹匹配与航点约束。该方法将有效性门控定义为元组，作为二元过滤器，修剪偏离经验真实值的轨迹，解决了 LLM 仿真参数空间无限且受随机噪声主导的验证难题。

TRAILS 鲁棒性审计（Ye et al., 2026, P32）揭示了 LLM 社会仿真中的“蝴蝶效应”。研究发现，仅表面格式不同但内容相同的人格提示会导致合作率出现 76 个百分点的差异，表明仿真结果对微小扰动极度敏感。该研究论证 LLM 社会仿真不应支持超出其鲁棒性审计所能证明的声明，为科学声明建立了严格的审计标准。机制合理性评估（Zhao et al., 2026, P30）则从认识论角度提出评估框架，区分解释性模型与预测性模型，强调仿真机制必须与目标现象生成的内部机制足够接近，防止将伪相关误认为因果机制。

在设计空间探索方面，Silicon Society 设计空间框架（Bück-Kaeffer et al., 2026, P29）通过系统消融实验，揭示了智能体数量、基础模型、提示工程等七个变量对仿真指标的影响，为构建更有效的社会仿真系统提供了实证指导。在文化多样性评估方面，LiveCultureBench（Pham et al., 2026, P19）提出了一个多智能体、多文化基准，模拟一天内的时间表示和空间表示，支持不同文化背景和地理位置的交互，解决了现有仿真平台文化同质化的问题。此外，社交媒体反应预测基准（Bojic et al., 2026, P27）利用 120K+ 人格和 1511 名人类数据，发现 LLM 智能体虽然能预测反应，但并不优于文本分类器，揭示了 LLM 作为人类代理的局限性。

### 2.4 社会动力学建模

社会动力学建模旨在通过引入社会学、心理学及经济学理论，提升 LLM 智能体在信念演化、情感动态及策略互动方面的心理真实性。BEACOF 信念驱动协作框架（Fang et al., 2026, P22）基于近似完美贝叶斯均衡，将交互建模为有限时域不完全信息动态博弈。该框架利用参数化贝叶斯近似，动态优化从合作综合到竞争批评的协作模式，解决了固定交互拓扑缺乏灵活性的问题，为研究社会困境中的策略互动提供了严格的数学基础。

Sentipolis 情感感知智能体框架（Fu et al., 2026, P14）集成连续 PAD 情感表示、双速情感动态和情感-记忆耦合，解决 LLM 社会仿真中的情感遗忘问题。通过将情感建模为动态状态变量，而非瞬时线索，该框架确保了长时程交互中的情感连续性，揭示了情感驱动行为与规则遵守之间的张力。社会导向动机建模（Lin et al., 2026, P20）则引入了社会导向动机模块，包含信念更新、价值更新、SVO 计算和活动生成四个核心模块，动态跟踪智能体的心理需求维度，提升了仿真在复杂社会场景中的心理真实性。

在策略学习与规范形成方面，CONSCIENTIA（Sinha et al., 2026, P24）研究了 LLM 智能体在对抗性社会互动中涌现的欺骗和信任行为，使用 KTO 优化目标更新智能体，揭示了策略学习的动态过程。Moltbook 社会化研究（Li et al., 2026, P18）通过案例研究探讨 AI 智能体社会中是否涌现社会化过程，分析持续多智能体互动如何导致集体结构塑造个体行为，为理解人工社会的文化演化提供了证据。Superminds 集体智能测试（Li et al., 2026, P28）提出了一种通过探测智能体主动评估智能体社会集体智能的三层顶层评估框架，从联合推理、知识整合到个体能力，逐层诊断集体智能的涌现条件。

### 2.5 特定领域应用仿真

特定领域应用仿真将生成式多智能体仿真应用于城市交通、宏观经济、法律司法、公共卫生及市场营销等具体垂直领域，提供决策支持。SimCity 城市发展仿真（Feng et al., 2025, P1）模拟丰富的城市互动，包括企业、异质商品市场、金融活动和税收系统，验证其能否复现已知宏观模式，并研究对新型经济冲击的响应。Law in Silico 法律社会仿真（Wang et al., 2025, P8）研究惩罚印象对犯罪率的影响，通过调整惩罚严重程度和感知，观察智能体行为变化，为法律政策评估提供了反事实分析工具。

在营销与消费者行为方面，LLM 多智能体系统（Chu et al., 2025, P5）模拟数字广告、社交媒体趋势和动态定价环境，集成并行执行与线程安全内存管理，支持智能体在共享环境中实时旅行、决策和互动。LLM 社会数字孪生框架（Koaik et al., 2026, P13）模拟人口对政策干预行为响应，包含智能体层、校准层和验证协议，利用 LLM 生成行为输出，并通过学习映射将智能体概率输出转换为可观察人口指标，为公共卫生、交通和环境政策提供了通用仿真平台。

在公共卫生与政策制定方面，AI 政策制定者疫情仿真（Aoki and Ghaffarzadegan, 2026, P12）结合 SEIR 疾病传播模型和 LLM 推理，模拟疫情期间的政策制定过程，展示 AI 在复杂危机管理中的决策支持潜力。在线审核反事实仿真（Fidone et al., 2025, P9）通过 LLM 驱动反事实仿真评估在线审核，研究审核干预对毒性行为传播的影响，为社交媒体平台审核政策设计提供了数据驱动的评估工具。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域内最核心的共识在于 LLM 智能体能够复现经典社会科学模型中的宏观现象，但其行为往往受模型先验偏差影响，需通过定量指标进行有效性诊断。这一共识在多个基准上得到验证：DeGroot-LLM 模型（Yazici et al., 2026, P16）发现 LLM 智能体通常达到共识，但极限意见偏离 DeGroot 预测，揭示了模型偏差的存在；耦合增益诊断（Yang, 2026, P38）进一步量化了这种偏差，表明 $\gamma$ 在不同 LLM 模型间稳定且可区分，且对提示重述不变。这些证据共同支持了“偏差是结构性而非随机性”的观点，即模型偏差反映了 LLM 训练数据中的社会倾向，而非简单的噪声。

与此相关的另一个共识是传统基于规则或启发式的 ABM 难以捕捉复杂人类行为的语义丰富性和适应性，LLM 的引入显著提升了模拟的保真度。这一共识源于 LLM 在自然语言生成与推理方面的优势，使得智能体能够基于情境进行灵活决策，而非依赖预设代码规则。例如，GANG 框架（Li et al., 2025, P2）和 Agent-Kernel（Mao et al., 2025, P10）通过模块化设计，使得 LLM 智能体能够在多样化场景中保持行为一致性，验证了 LLM 在提升仿真生态效度方面的潜力。然而，这一共识的边界在于，LLM 的语义优势并不自动转化为科学有效性，仍需通过验证评估体系进行确认。

### 3.2 观点分歧

关于 LLM 模型偏差的性质，领域内存在“消除论”与“建模论”的分歧。消除论认为偏差是模型缺陷，应通过提示工程、偏差控制（如 APS）或微调消除，以还原“真实”人类行为；建模论则认为偏差反映了 LLM 训练数据中的社会倾向，应作为智能体画像的一部分进行建模，或通过耦合增益等指标进行诊断和校准。现有证据偏向建模论，因为耦合增益诊断表明 $\gamma$ 具有结构性，且 APS（Zheng et al., 2026, P33）通过偏差控制自适应原型，在保持统计一致性的前提下大幅降低了计算开销，证明了偏差可控且可利用。然而，缺乏跨文化、跨语言的统一基准来量化“真实”人类偏差，使得消除论难以证明其必要性。

这一分歧的背后，是另一个更根本的争论：仿真有效性的验证标准应侧重统计轨迹匹配还是机制因果解释？统计派以 SLALOM（Lee and Seering, 2026, P26）和 DTW 距离等指标衡量模拟轨迹与真实数据的统计一致性，强调可操作性和可复现性；机制派以 BEACOF（Fang et al., 2026, P22）和机制合理性评估（Zhao et al., 2026, P30）等框架衡量微观机制是否反映已知社会动力学理论，强调可解释性和因果推断。证据偏向统计派在短期内的实用性，因为统计指标易于计算和比较；但机制派在长期科学价值上更具优势，因为统计一致性可能源于伪相关。目前，耦合增益试图桥接两者，通过反事实扰动测量机制敏感性，但尚未成为通用标准。

### 3.3 其他开放问题

当前最紧迫的工程问题是解决 LLM 社会模拟中计算成本与运行时效率的矛盾。高保真大规模模拟资源消耗巨大，需探索轻量级架构、弹性计算解决方案及基于调用距离的记忆管理（如 ScaleSim）以降低时间效率，同时保持行为保真度。关键困难在于如何在降低计算成本的同时不牺牲个体行为的细粒度语义丰富性，研究路径包括代理模型（如 Poor Man's Agentic Modeling）和稀疏激活优化的结合。

最根本的研究问题是实现开放式共同演化与长期记忆整合。静态沙盒无法反映真实社会的动态复杂性，需构建智能体与环境共同演化的架构，解决长期记忆巩固、偏见缓解和涌现行为评估难题。关键困难在于如何定义和评估“共同演化”的成功标准，研究路径包括引入开放式共同演化框架（Chen et al., 2025, P4）和动态规范敏感基准（如 LiveCultureBench）。此外，提升文化适应性与多语言模拟能力、开发可解释的微观-宏观连接机制、增强情感认知与社会动机建模、构建大规模持久社会的集体智能评估体系、实现政策干预的前置验证与反事实分析，均为当前重要的开放问题。

归纳“已知—争议—未知”认知图谱：已知 LLM 能复现宏观现象但受偏差影响，记忆机制和计算优化是必要条件；争议在于偏差的性质（噪声 vs. 信号）和验证标准（统计 vs. 机制）；未知在于如何建立可证伪的理论框架，实现开放式共同演化，以及如何在跨文化、跨语言环境中保持仿真的有效性。未来发展趋势将是从定性演示向定量预测、政策模拟及垂直领域应用深化，并积极探索 LLM 智能体与经典社会动力学模型的理论耦合。

## 4. 总结与展望

生成式多智能体社会模拟的核心矛盾在于 LLM 的语义生成能力与社会科学的定量验证需求之间的张力。早期研究通过生成式智能体确立了 LLM 作为社会模拟底座的范式，但受限于小规模沙盒和缺乏验证标准，结果多为定性演示。随后，研究重心转向大规模工程化，通过模块化框架和计算优化解决了“能不能跑”的问题；再转向科学验证，通过鲁棒性审计和定量诊断解决了“是否真实”的问题。核心瓶颈在于如何在保持 LLM 语义优势的同时，通过理论锚定和定量审计确保模拟结果的科学有效性，即构建一个计算可扩展、统计可复现且机制可解释的高保真人工社会仿真系统。

未来可能突破的方向包括：一是建立可证伪的测量协议和鲁棒性审计框架，区分真实社会动态与模型伪影，这需要开发独立于 LLM 模型的标准化基准来量化“真实”人类社会偏差；二是实现开放式共同演化与长期记忆整合，构建智能体与环境共同演化的架构，支持规范感知和适应性智能体生态系统；三是开发可解释的微观-宏观连接机制，建立从个体决策到集体动态的可追溯因果链，支持政策审计和机制验证。对于进入该领域的研究者，最值得做的一件事是构建一个统一骨干与统一预训练条件下的跨文化、跨语言评测基准，以隔离仿真架构的贡献，并为偏差控制与机制解释提供可靠的实证基础。
