## 导读

高效可微分神经架构搜索（Efficient Differentiable Neural Architecture Search, EDNAS）旨在以极低成本自动化设计高性能网络，其核心价值在于解决早期强化学习或进化算法因计算成本高昂而难以普及的痛点。2019 年 DARTS 通过可微分松弛将离散搜索转化为连续优化，确立了双层优化的基础范式，但随后暴露出训练不稳定与解码歧义问题。随着研究深入，领域重心从单纯追求搜索速度转向解决稳定性、泛化性及在大规模模型中的适用性。针对全局参数局限，MIDAS 引入输入特定机制提升局部判别力；针对一阶近似误差，LP-NAS 利用线性规划确保下层最优性；针对 LLM 搜索成本，DASH 通过冻结权重实现分钟级搜索。各路线在表示质量、理论严谨性与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何松弛到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

神经架构搜索（Neural Architecture Search, NAS）的核心目标是自动化发现高性能网络结构，早期基于强化学习或进化算法的方法虽能探索广阔空间，但需消耗数千 GPU 天，导致其难以在工业界普及。2019 年 DARTS 的提出标志着范式转变，它通过可微分松弛将离散搜索空间转化为连续优化问题，利用梯度下降联合优化架构参数与网络权重，将搜索成本大幅降低至 0.1-1 GPU 天。这一突破确立了可微分 NAS 的基础范式，即通过超网（Supernet）共享权重，并在双层优化（Bilevel Optimization）框架下，外层优化架构参数，内层优化网络权重。然而，这种理想化的连续松弛假设在真实训练场景中迅速遭遇挑战，训练震荡、收敛到局部最优以及解码后的性能差距成为阻碍其进一步应用的主要障碍。

问题定义的演化反映了领域对“高效”理解的深化。早期研究聚焦于“能否快速搜索”，核心矛盾是计算成本；随后，矛盾转变为“如何稳定搜索”，即解决双层优化近似误差导致的训练不稳定及架构参数与权重耦合问题；当前，矛盾进一步演化为“如何稳健且可解释地搜索”，特别是在大规模模型（如 LLM）中，需平衡搜索成本、架构性能与层间耦合效应。子问题之间存在严格的依赖关系：首先需解决双层优化中的稳定性与最优性保持问题，这是基础；其次才能通过输入特定参数或拓扑感知机制提升解码精度，这是进阶；最终才能在 LLM 等复杂场景中实现低成本实用化，这是应用。若基础不稳定，任何精细化的解码策略都将失效；若解码存在歧义，再低的搜索成本也无法转化为实际部署的高性能模型。

范式边界方面，可微分 NAS 与强化学习/进化算法存在根本差异。前者依赖梯度信息，适合在连续松弛空间中进行局部精细搜索，但易受局部最优和梯度噪声影响；后者无梯度依赖，探索能力强，但计算成本极高。当前领域处于从“快速搜索”向“高效、稳定、可解释搜索”过渡阶段，重点在于平衡搜索成本与架构性能，并在资源受限场景（如边缘设备、长上下文 LLM）中实现实用化。

约束演化史清晰地展示了方法如何因应约束变化而演变。2016-2018 年，奠基阶段确立了 NAS 的基本框架，但计算瓶颈限制了其应用。2019-2020 年，DARTS 解决了成本问题，但暴露了稳定性问题，促使研究者引入正则化与拓扑感知机制（如 DOTS）。2021-2024 年，研究转向理论鲁棒性，引入双层优化理论校正一阶近似误差，并探索输入特定架构参数（如 AGNAS）。2024-2026 年，领域扩展至大规模 LLM 混合架构，核心矛盾转变为在极低成本下解决层间算子耦合与长上下文泛化问题，DASH 等框架通过冻结权重仅优化架构参数，实现了分钟级单 GPU 搜索。当前形态下，方法体系分为动态参数搜索、优化理论增强与 LLM 架构搜索三条互补路线，共同指向更精准、更稳健的架构解码。

**如果用一个核心问题概括该领域，那便是：在保持双层优化理论严谨性的前提下，以最低计算成本实现从连续松弛架构到高性能离散架构的无歧义映射，并解决大规模模型中的层间耦合效应。**

## 2. 方法体系

- 2019：DARTS——奠定可微架构搜索基础范式

- 2021：DOTS——引入拓扑感知机制解决解码歧义

- 2022：AGNAS——探索输入依赖架构参数

- 2022：Bilevel Optimization for NAS——提供优化理论框架

- 2024：Jet-Nemotron——验证 NAS 在 LLM 设计中的有效性

- 2026：MIDAS——提升可微搜索鲁棒性的前沿方法

- 2026：LP-NAS——确保下层最优性的理论增强方法

- 2026：DASH——实现 LLM 高效设计的实用化框架

这条时间线勾勒了该领域方法演进的代表性节点：从 2019 年的 DARTS 奠定该领域方法基线，经 2021 年 DOTS 的推进，到 2026 年的 MIDAS 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 动态参数搜索

动态参数搜索路线旨在解决 DARTS 中全局共享架构参数导致的局部判别力不足问题。早期工作如 DOTS（2021）引入拓扑感知机制，显式建模节点连接关系以缓解解码歧义，但仍依赖全局参数。AGNAS（2022）采用全局平均池化计算输入特定的门控参数，是早期探索输入依赖架构参数的重要尝试，但全局池化导致早期层特征模糊。MIDAS（Subbotko, 2026, P1）针对这一失败案例，引入轻量级自注意力机制，将候选操作产生的激活图视为特征令牌，通过查询向量与键向量的点积注意力机制生成输入特定的架构分布。为解决全局池化导致的特征模糊，MIDAS 引入马赛克分块策略，将激活图划分为多个空间块并在每个块内独立计算注意力，从而保留局部空间信息以增强对候选操作的判别力。此外，MIDAS 在无额外参数增加的前提下，将拓扑搜索集成到动态自注意力机制中，通过建模所有可能的边对组合来简化节点连接选择。该方法放弃了全局共享假设，换取了输入特定的灵活性，但增加了计算复杂度（需计算注意力），解码时需平均输入特定参数。MIDAS 在 CIFAR-10 上达到 97.42% 的 SOTA，显著超越 DARTS 的 94.51%，证明输入特定参数在细粒度任务上的优势。与优化理论路线相比，动态参数搜索侧重于提升表示质量，而后者侧重于优化过程的理论严谨性，两者在解决解码歧义时形成互补。

### 2.2 优化理论增强

优化理论增强路线旨在解决标准一阶梯度下降导致的下层最优性破坏问题。DARTS 类方法仅满足一阶最优条件，架构更新易导致权重偏离训练损失最优谷，造成泛化性能下降。LP-NAS（Shukla et al., 2026, P3）基于双层优化的数学结构，提出利用线性规划（LP）计算架构参数的下降方向，以替代传统的交替梯度更新策略。其核心机制是利用下层优化的 Hessian 信息与上层验证梯度，构建一个确保架构更新后下层模型仍保持最优性的线性规划问题。针对完整 Hessian 矩阵计算成本过高的问题，LP-NAS 引入缩减 Hessian 策略，仅保留所有架构参数和少量选定的模型参数，通过梯度范数每参数（GNPP）指标或随机选择确定关键参数子集。这种设计在保持二阶信息关键部分的同时，显著降低了内存和计算开销，使得在 CPU 上也能进行高效的架构搜索。LP-NAS 放弃了简单梯度下降，换取了双层优化的理论最优性，但需计算缩减 Hessian，内存和计算开销高于一阶方法。与动态参数路线相比，LP-NAS 不改变架构参数的粒度，而是优化更新方向，两者可结合使用以提升整体性能。

### 2.3 LLM 架构搜索

LLM 架构搜索路线旨在解决传统 NAS 在大规模模型上搜索成本高昂的问题。Jet-Nemotron（2024）通过多阶段 PostNAS 流程探索混合注意力架构，验证了 NAS 在 LLM 设计中的有效性，但其高昂的搜索成本限制了其作为常规设计工具的普及。DASH（Chen et al., 2026, P2）针对这一瓶颈，提出冻结模型权重仅优化架构参数（logits）的快速可微搜索框架。其核心创新在于将架构搜索与最终模型适配分离，在搜索阶段冻结模型权重和操作权重，仅优化架构参数，从而大幅降低搜索成本。DASH 采用三阶段流水线：首先准备与教师模型对齐的线性注意力候选层，其次通过可微优化搜索最佳的操作分配序列，最后实例化离散架构并进行蒸馏以得到最终部署模型。这种架构仅优化的策略使得单次搜索仅需少量 token 和分钟级时间即可完成。DASH 放弃了全参数联合训练，换取了分钟级搜索速度，但搜索阶段架构与权重未联合优化，可能非全局最优，需后续蒸馏适配。与选择器风格方法相比，DASH 直接搜索层间耦合的操作分配，避免了独立层选择无法组合成最优整体架构的问题。

### 2.4 跨任务与多领域应用

当前方法体系在图像分类与 LLM 领域展现出不同的应用特征。在图像分类中，MIDAS 和 LP-NAS 分别在 CIFAR-10/100 及 RDARTS 基准上展示了输入特定参数与理论校正的有效性。在 LLM 领域，DASH 在 Qwen2.5-3B 混合注意力架构上，以极低成本超越 Jet-Nemotron 及选择器基线，确立了新 SOTA。跨任务应用表明，可微分 NAS 的核心机制（双层优化、超网共享）具有通用性，但具体实现需适应不同领域的约束（如 LLM 的长上下文、图像的空间局部性）。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

可微分 NAS 显著降低了搜索计算成本，相比 RL/EC 方法具有数量级优势，这一共识在多个基准上被反复验证：MIDAS 的 97.42% 与 DASH 的 91.42 均大幅超越传统方法。与此相关的另一个共识是双层优化是 NAS 的核心数学框架，优化架构参数需考虑其与网络权重的交互，LP-NAS 和 DASH 均基于此框架设计。此外，全局架构参数存在局限性，输入特定或局部架构参数能提升搜索灵活性与性能，MIDAS 在 CIFAR-10/100 及 RDARTS 基准上的表现证实了这一点。在资源受限场景下，NAS 是发现高效硬件感知架构的关键手段，DASH 的分钟级搜索成本证明了其在边缘设备中的适用性。

### 3.2 观点分歧

一阶近似与二阶校正的有效性边界是领域的主要分歧。观点 A（DARTS/MIDAS）认为一阶梯度下降在多数场景下足够，计算成本低，工程实用性强；观点 B（LP-NAS）认为一阶近似导致下层最优性破坏，需二阶信息校正以确保架构鲁棒性。现有证据显示，LP-NAS 在受限计算预算下展示了发现高质量、可迁移架构的能力，但 MIDAS 在 CIFAR-10/100 上仍保持 SOTA，说明一阶方法在特定场景下依然有效。分歧根源在于二阶信息计算成本高，且不同搜索空间对二阶校正的敏感度不同。另一分歧是全局共享与输入特定架构参数的粒度选择。观点 A（DARTS）认为全局共享参数简单高效，易于解码；观点 B（MIDAS/AGNAS）认为全局参数缺乏局部判别力，输入特定参数能提升架构对局部上下文的适应能力。MIDAS 在多个基准上的显著优势支持观点 B，但输入特定参数增加了解码复杂度，且在简单任务上可能过拟合。

### 3.3 其他开放问题

最紧迫的工程问题是进一步压缩 LLM 搜索的 Token 消耗与 GPU 内存，实现更广泛的部署。当前 DASH 虽实现分钟级搜索，但在更大规模模型上仍面临成本挑战。最根本的研究问题是异构算子空间中的梯度不稳定机制及连续到离散解码的信息损失理论下界。现有方法在解码阶段存在信息损失，需研究更精细的解码策略以减少性能差距。此外，架构跨分布泛化的内在机理尚未明确，需研究输入自适应机制与鲁棒性约束，使架构在不同数据分布下保持稳定的高性能表现。已知—争议—未知认知图谱显示，领域在成本降低与基础范式上达成共识，但在优化深度、参数粒度及 LLM 搜索策略上存在争议，异构空间稳定性与解码理论下界为未知领域。

## 4. 总结与展望

高效可微分 NAS 已从一种加速工具演变为一种具备理论深度和场景适应性的架构设计范式。核心矛盾在于在保持双层优化理论严谨性的前提下，实现低成本、无歧义、可迁移的架构发现。尝试过的路线包括动态参数搜索、优化理论增强与 LLM 架构搜索，核心瓶颈在于异构算子空间的梯度不稳定、解码信息损失及跨任务泛化机制。

未来可能突破的方向包括：1）结合二阶信息近似与轻量级代理模型，探索更通用的拓扑感知搜索机制，MIDAS 和 LP-NAS 均指向此方向；2）研究更精细的解码策略，减少连续到离散映射的信息损失，MIDAS 和 DASH 均涉及解码优化；3）提升架构的可迁移性与泛化能力，MIDAS 的输入特定机制与 LP-NAS 的鲁棒性约束均为此提供基础。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，系统评估一阶与二阶优化在不同搜索空间中的性能边界，为优化深度选择提供理论指导。
