# A Survey of Differential Privacy Methods for Large Language Models ｜大语言模型差分隐私保护方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Differential%20Privacy%20for%20Language%20Models)

## 导读

大语言模型（LLM）在医疗与金融等敏感领域的渗透，使其训练数据中蕴含的个人身份信息（PII）泄露风险成为核心安全挑战，传统匿名化手段难以抵御成员推断攻击等高级威胁。早期研究聚焦于预训练阶段的差分隐私随机梯度下降（DP-SGD），但高维梯度噪声导致的效用崩塌迫使领域转向微调阶段的低秩适配与子空间投影。随着云端 API 的普及，研究边界从训练时隐私扩展至推理时隐私，提示词扰动与上下文学习（ICL）保护成为新热点。与此同时，合成数据生成与系统性评估基准的建立，标志着领域从单纯算法优化走向全生命周期的隐私工程。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前训练、推理、数据生成与理论评估多元并存的格局。本综述梳理这条从全局噪声注入到语义感知保护的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

大语言模型强大的生成能力源于其对训练数据的深度记忆，这种特性在敏感场景下转化为严重的隐私泄露风险。当模型被用于医疗诊断或金融分析时，其输出可能无意中复述训练集中的患者病历或交易记录，使得传统的去标识化手段失效。成员推断攻击（Membership Inference Attack, MIA）作为一种主要攻击向量，旨在判断特定数据是否包含在训练集中，而差分隐私（Differential Privacy, DP）通过引入随机噪声限制算法输出对单个数据点的敏感性，提供了抵御此类攻击的数学保证。因此，DP 成为 LLM 隐私保护的金标准，其核心在于通过隐私预算（Privacy Budget, ε, δ）量化泄露程度，在隐私强度与模型效用之间建立可计算的权衡。

问题的形式化通常遵循 N-way K-shot 的少样本逻辑或标准的序列到序列生成框架，但在 LLM 隐私保护中，核心约束体现为在保持语义连贯性的前提下最小化对单个数据点的依赖。具体而言，对于训练阶段，问题定义为在梯度更新中注入噪声，使得模型参数对任意单条训练数据的移除不敏感；对于推理阶段，则转化为在提示词或上下文示例中应用局部差分隐私（LDP）机制，防止敏感输入被云端模型记忆或泄露。这两个阶段并非孤立存在，而是构成了一个层级依赖结构：训练时的隐私保护是基础，若模型基础性能因噪声过度受损，推理时的隐私保护将因模型效用低下而失去实际意义。

子问题之间呈现出明显的并列与耦合关系。高维梯度噪声导致的效用损失是底层基础问题，直接决定了模型能否在隐私约束下保持可用的语言建模能力。推理时隐私与合成数据生成在应用层面相对并列，分别解决黑盒 API 交互和数据共享场景，但二者都依赖于底层的隐私核算机制，如隐私预算的动态分配。此外，隐私-幻觉权衡作为贯穿所有子问题的深层认知边界问题，揭示了隐私保护对模型认知能力的副作用，即噪声可能限制模型对事实信息的记忆，从而增加幻觉率，这是连接工程实现与理论评估的关键纽带。

从范式边界来看，训练时 DP 与推理时 LDP 存在本质差异。训练时 DP 作用于模型权重更新，提供全局的隐私保证，但需要访问模型内部梯度，适用于白盒微调场景；而推理时 LDP 作用于输入提示词或输出响应，提供局部的隐私保证，适用于黑盒 API 调用场景，但往往以牺牲部分语义连贯性为代价。这种边界划分决定了不同技术路线的适用场景：拥有模型控制权的机构倾向于使用 DP-SGD 及其变体，而依赖第三方 API 的用户则必须采用提示词扰动或合成数据策略。

回顾约束演化史，2016 至 2018 年间，DP-SGD 奠定了深度学习隐私保护的基础范式，通过裁剪单样本梯度范数并添加高斯噪声实现隐私保证。然而，当这一方法直接应用于高维 LLM 时，各向同性噪声导致模型效用严重下降，WikiText-2 上的困惑度（PPL）从非隐私的 20.48 飙升至 27.05，暴露出“维度灾难”问题。这一失败促使研究者在 2020 至 2021 年转向参数高效微调（PEFT），利用低秩适配（LoRA）和梯度投影降低噪声维度，GEP（Gradient Embedding Perturbation）等方法通过低秩分解仅在低秩分量上注入噪声，显著缓解了效用损失。

2022 至 2023 年，随着云端 LLM 服务的普及，研究重心从训练阶段转向推理阶段。SanText 等早期 LDP 方法基于全词表扰动，虽提供了严格隐私保证，但因候选空间过大导致语义严重漂移，无法满足实际对话需求。这一瓶颈促使研究者引入受约束的邻接列表和语义感知机制，CusText 等方法通过差异化处理敏感与非敏感 token，提升了文本生成的连贯性。与此同时，合成数据生成领域也经历了从 PATE（Private Aggregation of Teacher Ensembles）到无需训练的演化方法（如 Private Evolution）的转变，旨在解决 DP 合成文本的模式坍塌问题。

2024 至 2025 年，领域出现两个关键转折：一是从“全局保护”向“选择性保护”演进，ATDP（Adaptive Token-Weighted Differential Privacy）等方法通过识别敏感 token 实施非均匀噪声注入，平衡了隐私强度与通用语言建模性能；二是系统性评估基准的建立，SynBench 和 ContinuousBench 等基准的出现，标志着领域从单纯算法优化走向对隐私-效用-幻觉三维权衡的量化评估。当前，研究处于精细化与多模态融合阶段，重点解决多轮对话隐私累积、联邦学习异构性以及隐私对事实准确性的影响，旨在实现高保真隐私保护与模型性能的最小化损失。

**如果用一个核心问题概括该领域，那便是：如何在高维、非凸且具备强记忆特性的语言模型参数空间与推理流中，以可计算的隐私预算为约束，最小化对语义连贯性、事实准确性及多轮交互一致性的破坏。**

## 2. 方法体系

- 2016：DP-SGD——通过裁剪单样本梯度范数并添加高斯噪声实现差分隐私训练，奠定了深度学习隐私保护的基础范式

- 2021：GEP (Gradient Embedding Perturbation)——提出对高维权重矩阵进行低秩分解，仅在低秩分量上注入噪声并投影回原空间，显著降低了噪声注入的维度

- 2021：SanText——基于度量差分隐私（Metric-LDP）对提示词进行词级扰动，利用整个词表作为候选空间进行替换，实现了黑盒场景下的隐私保护

- 2022：PATE (Private Aggregation of Teacher Ensembles)——通过训练多个在私有数据子集上的教师模型，并聚合其投票结果来生成隐私保护的预测或文本，避免了直接暴露原始数据

- 2023：CusText——引入受约束的邻接列表替代全词表采样，针对敏感与非敏感token进行差异化处理，在保持差分隐私的同时显著提升了文本生成的语义连贯性

- 2024：Private Evolution (PE)——提出一种无需训练（training-free）的差分隐私合成文本生成方法，通过迭代改写和隐私预算分配，利用预训练LLM生成高质量合成数据

- 2025：ATDP (Adaptive Token-Weighted Differential Privacy)——提出自适应token加权机制，利用秘密检测器识别敏感token，仅对敏感部分施加更强的噪声保护，而非对所有token均匀处理

- 2026：PE-SGD (Evolution of Gradient Subspace)——通过动态演化梯度子空间来适应私有数据分布，在有限私有数据场景下显著提升了DP-SGD的学习能力

这条时间线勾勒了该领域方法演进的代表性节点：从 2016 年的 DP-SGD 奠定该领域方法基线，经 2021 年 GEP (Gradient Embedding Perturbation) 的推进，到 2026 年的 SecPE (Secret-Protected Evolution) 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 隐私微调优化

隐私微调优化的核心在于解决高维梯度噪声导致的效用损失问题。早期 DP-SGD 方法假设梯度噪声可被均匀处理，但在 LLM 的高维参数空间中，这种各向同性噪声严重损害了模型性能。为应对这一挑战，研究者引入了低秩适配（LoRA）和子空间投影技术，将噪声注入限制在低维任务特定子空间内。DP-SFT（Differentially Private Subspace Fine-Tuning）（Zheng et al., 2026, P9）通过构建捕获主要梯度变化的低维子空间，在该子空间内执行带有差分隐私保证的训练，其核心假设是任务相关的梯度变化具有低秩结构。若该假设不成立，隐私保护效果可能受损，但其在 SST-2 等基准上显著提升了准确率，证明了降维策略的有效性。

随着对语义敏感性的深入理解，研究重心从全局降维转向细粒度的 Token 级保护。ATDP（Adaptive Token-Weighted Differential Privacy）（Yu et al., 2025, P3）针对标准 DP-SGD 对所有 token 施加均匀噪声导致的效用损失问题，引入秘密检测器在训练前识别并标记敏感 token。其核心机制是实施非均匀的噪声注入策略，仅对标记为敏感的 token 施加较强的隐私保护，而对通用语言 token 保持较低噪声水平。这种设计允许模型在保护关键隐私信息的同时，最大限度地保留通用语言建模能力，其代价是引入了额外的预处理计算开销，且依赖检测器的准确性。SA-ADP（Sensitivity-Aware Adaptive Differential Privacy）（Etuk and Matrawy, 2025, P7）进一步引入了基于 PII 敏感性的 token 级隐私调制机制，根据每个 token 的敏感程度动态分配噪声，将隐私保护与数据内容的语义重要性紧密关联。

在优化效率方面，梯度矩阵去噪（Gradient Matrix Denoising）（Dadsetan and Rudzicz, 2025, P4）提出一种后处理技术，利用随机矩阵理论对 DP-SGD 产生的含噪梯度进行去噪，以恢复信号并加速收敛。研究指出 DP-SGD 收敛缓慢的主要原因是添加的高斯噪声而非梯度裁剪，因此通过去噪可以显著改善训练效率。PE-SGD（Evolution of Gradient Subspace）（ICLR 2026, P29）则针对有限私有数据场景下 DP-SGD 性能退化问题，提出通过动态演化梯度子空间来适应私有数据分布，克服了传统投影方法在子空间固定时的局限性。随机裁剪 DP-SGD（Randomized Clipping DP-SGD）（Ullah et al., 2026, P19）通过引入随机化机制优化梯度裁剪过程，降低了计算开销，为资源受限环境下的部署提供了更可行的实现路径。这些方法共同构成了从全局噪声到语义感知、从静态投影到动态演进的优化谱系，与推理时隐私保护形成互补，前者保障模型权重安全，后者保障交互过程安全。

### 2.2 隐私推理与交互

隐私推理与交互路线聚焦于 LLM 推理阶段的隐私保护，特别是针对云端 API 调用中提示词直接暴露敏感信息的问题。早期方法如 SanText 基于度量差分隐私对提示词进行词级扰动，利用整个词表作为候选空间进行替换，虽然隐私保证严格，但由于候选空间过大导致效用严重退化。为了解决语义漂移问题，CusText 引入受约束的邻接列表替代全词表采样，针对敏感与非敏感 token 进行差异化处理，成为提示词隐私保护领域的重要里程碑。

针对多轮对话场景，DP3（Differentially Private Prompt Perturbation）（ACL-Findings 2026, P25）设计了基于两阶段分桶指数机制的提示词扰动策略，以解决单轮 DP 方法在长程对话中隐私预算耗尽的问题。DP3 通过分桶机制管理大候选空间中的扰动选择，提高了扰动选择的稳定性，并保持了对话的连贯性。其核心创新在于将隐私预算分配与对话轮次动态关联，确保在多轮交互中隐私保证的累积可控。HiddenEcho（ICLR 2026, P27）则在分割学习框架下引入隐藏状态校正机制，通过客户端轻量级校正抑制噪声在 Transformer 层间的放大效应。HiddenEcho 识别出 DP 推理中噪声随层数累积导致性能急剧下降的问题，并在每一层应用抑制因子来校正隐藏状态，为资源受限设备上的隐私 LLM 部署提供了可行方案。

在上下文学习（ICL）隐私保护方面，隐私保护上下文学习框架（Bhusal et al., 2025, P1）提出一种两阶段框架，首先利用 DP 算法从私有数据集中生成合成示例，然后将这些合成示例作为 ICL 演示用于 LLM 推理。通过离线预处理生成隐私保护的演示数据，该方法利用了 DP 的后处理性质，使得推理阶段无需额外消耗隐私预算。基于最近邻搜索的差分隐私上下文学习（Koskela et al., 2025, P6）利用最近邻搜索技术优化私有 ICL 中的演示示例选择，通过私有机制从候选集中检索最相关的示例，显著提升了检索效率和演示示例的相关性。Private PoEtry（Romijnders et al., 2026, P11）提出一种基于专家乘积的私有 ICL 机制，通过调用 LLM 对每个上下文示例生成对数概率，并求和后采样噪声响应，为高维输出空间的私有 ICL 提供了一种新的聚合范式。这些方法与训练时微调优化形成互补，前者无需修改模型参数，适用于黑盒场景，后者则提供更强的全局隐私保证。

### 2.3 隐私合成数据

隐私合成数据路线旨在利用 DP 生成高质量合成文本以替代敏感原始数据，解决数据共享限制问题。早期 PATE 框架通过训练多个在私有数据子集上的教师模型，并聚合其投票结果来生成隐私保护的预测或文本，避免了直接暴露原始数据，但在高维文本生成时面临隐私成本高昂的挑战。Private Evolution（PE）（Liu et al., 2026, P20）提出一种无需训练的差分隐私合成文本生成方法，通过迭代改写和隐私预算分配，利用预训练 LLM 生成高质量合成数据，成为评估 DP 合成数据质量的关键基线。

SecPE（Secret-Protected Evolution）（ICLR 2026, P26）引入“秘密保护”概念替代标准差分隐私，通过线性规划优化噪声尺度和采样概率，以保护特定敏感信息。其核心创新在于将隐私目标从“保护所有数据”细化为“保护特定秘密”，从而在保持隐私保证的前提下大幅降低噪声水平。Private Seeds, Public LLMs（Ma and Rajtmajer, 2026, P17）提出一种利用私有数据作为“种子”引导公共 LLM 生成合成数据的框架，通过提示工程将私有数据的统计特征注入生成过程，避免了直接暴露私有数据。EPSVec（Banayeeanzade et al., 2026, P12）利用数据集向量作为私有数据的隐私保护表示，通过激活引导技术控制 LLM 生成合成文本，显著降低了隐私机制的计算复杂度。

MAPLE（Chien et al., 2026, P14）提出利用元数据增强私有语言模型演化过程，通过结合文本内容与元数据特征进行 DP 合成数据生成，提高了合成数据的结构一致性和语义相关性。ACTG-ARL（Hu et al., 2025, P5）提出一种模块化、分层框架，利用强化学习增强差分隐私条件文本生成的控制能力，通过 RL 优化生成策略，以在隐私约束下最大化文本质量。这些方法在 PubMed 和 Yelp 等基准上展示了强大的效用-隐私权衡能力，与推理时隐私保护形成互补，前者解决数据共享问题，后者解决交互隐私问题，二者共同构成了 LLM 隐私保护的数据侧与交互侧防线。

### 2.4 隐私评估与理论

隐私评估与理论路线旨在建立 DP-LLM 的实证隐私评估基准、分析隐私-效用-幻觉权衡、推导隐私计算的理论下界。DPrivBench（Wang et al., 2026, P18）构建了专门评估 LLM 在差分隐私领域推理能力的基准测试集，涵盖隐私预算计算、机制设计等复杂数学推理任务，填补了 DP 领域专用评估工具的空白。SynBench（Sun et al., 2025, P2）提出了一个综合评估 DP 合成文本生成质量的基准框架，涵盖效用、保真度和隐私泄露三个维度，建立了标准化的评估协议，允许在不同隐私预算下公平比较不同 DP 生成方法。

隐私-幻觉权衡分析（Ramesh et al., 2026, P24）系统研究了差分隐私训练对 LLM 事实性（幻觉率）的影响，揭示了隐私保护与模型准确性之间的内在权衡。其核心发现是 DP 训练不仅降低模型效用，还可能增加幻觉率，特别是在高隐私预算下。LLM 适配实证隐私保护基准（Marek et al., 2026, P22）建立了评估 LLM 适配方法（如 LoRA、全量微调）在差分隐私下实证隐私保护能力的基准，区分形式化隐私保证与实证隐私泄露风险，通过成员推断攻击等实证方法评估不同适配策略的隐私鲁棒性。语言识别与生成的隐私代价理论（Li et al., 2026, P16）从理论角度分析了差分隐私对语言识别和生成任务的影响，推导了隐私保护的统计下界，证明了某些语言学习任务在差分隐私下存在不可避免的效用损失。这些理论分析与实证基准为理解 DP 在语言学习中的适用性提供了理论基础，指导了隐私机制的设计，并与前面的方法路线形成闭环，验证了其在实际场景中的有效性与局限性。

### 2.5 隐私蒸馏与迁移

隐私蒸馏与迁移路线研究通过知识蒸馏、模型转录或联邦聚合实现隐私保护，旨在从私有教师模型或分散数据中安全提取知识。DP-OPD（Differentially Private On-Policy Distillation）（Khadem et al., 2026, P15）提出一种无需合成数据的隐私蒸馏框架，仅通过对学生模型应用 DP-SGD 来确保隐私，而教师模型保持非私有。其核心创新在于利用在线策略蒸馏机制，让学生模型在生成过程中动态学习教师模型的输出分布，避免了离线合成数据生成的隐私开销。Hot PATE（ICLR 2026, P28）扩展了 PATE 框架以处理生成模型中固有的输出多样性，通过协调集成和温度参数调节来聚合教师模型的分布，保留了教师模型间的多样性，避免了传统 PATE 在聚合过程中丢失输出变异性。

资源自适应联邦文本生成（Wang et al., 2026, P13）提出一种联邦学习框架，允许计算资源受限的客户端通过发送 DP 统计特征间接参与文本生成，而资源充足的客户端直接参与联邦微调。其核心创新在于根据客户端资源动态分配参与方式，平衡了隐私保护、计算效率和生成质量。DPSD（Differentially Private Synthetic Distillation）（Liu et al., 2026, P10）提出一种模型转录框架，通过引入可训练生成器在教师-学生学习框架中生成合成数据，以保护私有训练数据。几何感知模型合并（Liu et al., 2026, P23）研究在差分隐私约束下合并多个任务特定模型时的几何特性，提出了一种感知参数干扰的合并策略，识别并减少合并过程中的参数冲突。这些方法为隐私模型压缩、联邦学习和多任务学习提供了新的解决方案，与前面的微调优化和合成数据路线形成互补，前者侧重于知识的安全转移，后者侧重于数据的安全生成，共同构成了 LLM 隐私保护的全生命周期技术体系。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域内最核心的共识是 LLM 具有记忆训练数据并泄露敏感信息的固有特性，传统匿名化不足以提供安全保障，必须采用差分隐私等数学框架。这一共识在多个基准上被反复验证：DP-SGD 作为训练阶段的标准方法，其引入的噪声会导致模型性能显著下降，需通过优化算法或参数高效微调来缓解。例如，DP-SFT 在 SST-2 上的 90.33% 准确率与经典 DP-SGD 的 82.1% 基线相比，显著提升了效用，证明了 PEFT 结合 DP 的有效性（支撑证据：P9、P4）。与此相关的另一个共识是隐私预算（ε）与模型效用之间存在显著的权衡关系，较小的 ε 提供更强的隐私保护但会严重损害任务性能。SynBench 等基准的建立，使得这种权衡可以在不同隐私预算下被量化评估，进一步巩固了这一共识（支撑证据：P2、P20）。

此外，上下文学习（ICL）和提示词工程引入了新的隐私风险，需要在不修改模型参数的情况下对输入或输出进行隐私保护，这一共识在 ChatDoctor 等敏感场景中得到验证。Private PoEtry 的 52.4% 准确率与经典 DP-ICL 的 45.2% 基线相比，表明推理时隐私保护机制在保持任务效用的同时提供了隐私保证（支撑证据：P11、P6）。合成数据生成是解决私有数据共享限制的有效途径，但 DP 约束下的合成数据在多样性和语言质量上仍面临挑战，这一共识在 PubMed 和 Yelp 等基准上得到体现，MAPLE 和 EPSVec 的 FID 值虽优于基线，但仍高于非隐私生成方法，揭示了合成数据保真度的瓶颈（支撑证据：P14、P12）。

### 3.2 观点分歧

关于 LoRA 与全量微调在 DP 下的实证隐私鲁棒性，存在显著分歧。观点 A 认为 LoRA 因参数少、更新幅度小，天然具有更强的隐私保护效果；观点 B 则认为在相同隐私预算下，LoRA 与全量微调的实证隐私泄露风险差异不显著，LoRA 优势主要在于效用而非隐私强度。现有证据偏向观点 B，Marek et al.（2026, P22）的实证基准显示，在 DP 设置下，LoRA 与全量微调的 MIA 成功率差异微妙，且受数据集影响大。这一分歧的背后，是另一个更根本的争论：形式化隐私保证与实证隐私泄露风险之间的差距。形式化保证基于理论假设，而实证风险受模型规模、数据分布、攻击者先验知识等多因素影响，难以隔离“适配方法”这一单一变量（支撑证据：P22、P9）。

关于差分隐私噪声是否直接导致模型幻觉率增加，也存在分歧。观点 A 认为 DP 噪声限制了模型对事实信息的记忆，导致分布扁平化，从而增加幻觉；观点 B 认为幻觉增加主要源于 DP 训练导致的数据分布偏移或训练不充分，而非噪声本身的直接因果效应。现有证据偏向观点 A，Ramesh et al.（2026, P24）通过对比 DP 与非 DP 模型在事实性任务上的表现，量化了隐私对知识保留的影响，显示高隐私预算下幻觉率显著上升。然而，因果链不完整，缺乏控制变量实验排除数据分布变化的影响，且幻觉检测算法本身存在误差，难以大规模验证（支撑证据：P24、P16）。

### 3.3 其他开放问题

最紧迫的工程问题是扩展至更大规模 LLM 与边缘部署。当前差分隐私方法多在小模型上验证，需探索在 70B+ 参数模型及资源受限边缘设备上的可行性，难点在于隐私噪声对大模型梯度的累积效应及计算开销。潜在路径包括子空间投影、量化感知隐私及硬件加速，但现有方法如 HiddenEcho 虽解决了噪声层间累积问题，其客户端额外计算开销在边缘设备上仍具挑战性（支撑证据：P27、P19）。最根本的研究问题是解决隐私-幻觉权衡的理论下界。DP 训练可能导致模型分布扁平化，增加幻觉风险，需研究如何在保持隐私的同时维持事实一致性。难点在于隐私噪声对预训练知识记忆的干扰，潜在路径包括隐藏状态校正、事实锚定及后处理过滤，但缺乏量化隐私预算对事实准确性影响的系统性理论（支撑证据：P24、P16）。

此外，动态威胁适应与噪声调度、高效隐私核算与理论紧致性、合成数据分布保真度提升、联邦学习与异构数据隐私、隐私保护推理与上下文学习、预训练-适配范式下的整体隐私评估等问题，均处于研究前沿。已知的是 DP 机制能有效降低 MIA 成功率，争议的是 LoRA 与全量微调的隐私鲁棒性差异及隐私-幻觉的因果关系，未知的是大规模模型部署的可行性及隐私对认知能力的理论下界。发展趋势将从静态预算向动态适应，从单一阶段向全生命周期覆盖，从算法优化向系统性工程与理论评估转变。

## 4. 总结与展望

大语言模型差分隐私保护领域的核心矛盾在于数学保证的隐私强度与 LLM 高维语义保持之间的张力。从 2016 年 DP-SGD 的奠基，到 2021 年低秩适配的引入，再到 2024 年推理时隐私的兴起，研究路线经历了从全局噪声注入到语义感知保护的范式演进。核心瓶颈在于高维梯度噪声导致的效用损失、推理阶段隐私泄露的语义漂移、以及隐私-幻觉权衡的理论盲区。这些瓶颈反映了领域从“如何加噪”向“如何在保持语义连贯与事实准确的前提下，动态分配隐私预算”的问题定义转变，回扣了第 1 章提出的核心问题：如何在高维、非凸且具备强记忆特性的语言模型参数空间与推理流中，以可计算的隐私预算为约束，最小化对语义连贯性、事实准确性及多轮交互一致性的破坏。

未来可能突破的方向包括：一是动态威胁适应与噪声调度，通过基于注意力机制的 token 重要性加权及自适应裁剪，解决多轮对话中的隐私累积问题（P25、P3）；二是隐私-幻觉权衡的理论紧致性，通过推导隐私保护的统计下界，指导隐私机制的设计（P16、P24）；三是高效隐私核算与理论紧致性，开发更紧致的隐私分析理论，处理非独立同分布数据及复杂优化器的隐私保证（P19、P4）。对于进入者，最值得做的一件事是建立统一的、跨数据集的 MIA 评估协议，隔离“适配方法”这一单一变量，以解决 LoRA 与全量微调隐私鲁棒性的分歧，为隐私 LLM 的安全部署提供实证依据（P22）。
