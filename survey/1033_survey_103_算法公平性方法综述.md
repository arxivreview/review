综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Algorithmic%20Fairness%20in%20Machine%20Learning)

## 导读

算法公平性研究旨在消除机器学习模型在信贷、司法等高风险决策中因历史数据偏见导致的系统性歧视，其核心张力在于数学上互斥的公平性定义与不可完全观测的真实世界约束之间的冲突。早期研究聚焦于定义统计指标并开发预处理或后处理干预手段，试图在单一维度上消除群体间的预测差异。随着不可能性定理揭示不同公平性定义在基础率差异下的互斥性，研究重心转向多目标权衡与帕累托前沿探索。因果推断框架的引入将公平性从结果导向拓展至过程导向，强调决策逻辑的稳定性与无偏性。近年来，大语言模型与自动化机器学习结合，使得公平性审计与缓解策略的自动化、可解释性成为新范式。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从统计均等到程序正义的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

算法公平性研究的兴起源于机器学习系统在信贷、招聘、司法等高风险领域的广泛部署，模型在历史数据中习得并放大了社会偏见，导致对特定人口群体的系统性歧视。最初的核心任务是定义公平性指标（如人口统计均等、机会均等）并开发干预手段，以消除群体间的统计差异。这一阶段的问题形式化通常基于 N-way K-shot 式的群体划分，要求模型预测 $P(\hat{Y}=1|A=a)$ 在不同受保护属性 $A$ 的取值 $a$ 间保持一致。然而，这种单一指标优化的范式很快遭遇理论瓶颈，Hardt 等人提出的“不可能性定理”揭示了不同公平性定义在基础率差异下的互斥性，迫使研究从单一指标优化转向多目标权衡。

问题定义的演化呈现出从“统计关联”到“因果机制”再到“程序正义”的三次范式跃迁。2016 年至 2018 年间，研究聚焦于群体公平性（Group Fairness），核心概念包括人口统计均等（Demographic Parity, DP）与机会均等（Equalized Odds, EO）。DP 要求模型预测结果与受保护属性统计独立，而 EO 则要求在真实标签为正和负的条件下，真阳性率和假阳性率分别相等。这一时期的方法主要依赖预处理（如重加权）或后处理（如阈值调整），假设数据完整且敏感属性可观测。2017 年，Kusner 等人引入因果推断框架，提出反事实公平性（Counterfactual Fairness），将公平性从结果导向拓展至过程导向，强调若改变个体的受保护属性而保持其他特征不变，模型预测结果应保持不变。这一转折标志着研究从消除统计差异转向消除因果直接效应。

2020 年至 2023 年，研究重心转向复杂场景下的鲁棒性与现实约束。联邦学习（Federated Learning）的兴起使得数据去中心化成为常态，传统公平性方法因依赖集中式数据而失效，FedCF 等框架开始探索隐私保护下的公平性保证。同时，部分反馈（Partial Feedback）场景（如信贷审批中仅对正类样本有标签）导致传统评估存在选择偏差，Exp-Audit 等算法尝试结合在线探索与历史数据以低成本实现无偏审计。这一时期的方法开始关注交叉群体公平性（Intersectional Fairness），解决单一属性公平性掩盖的交叉群体偏见问题。

2024 年至 2026 年，大语言模型（LLM）与自动化机器学习（AutoML）的结合，使得公平性审计与缓解策略的自动化、可解释性成为新范式。FairAgent 等系统通过自然语言交互实现从数据预处理到模型评估的全流程公平性管理，大幅降低技术门槛。与此同时，解释公平性（Explainability Fairness）成为新焦点，MESD 等指标首次实现交叉群体程序偏差的检测与缓解，填补了现有公平性指标仅关注输出而忽视推理过程稳定性的空白。当前研究高度活跃，致力于解决公平性与预测性能的平衡、隐私保护下的公平审计以及低资源环境下的可部署性，旨在构建兼具数学严谨性与社会合规性的可信 AI 系统。

**如果用一个核心问题概括该领域，那便是：在数学上互斥的公平性定义与不可完全观测的真实世界约束（隐私、缺失标签、交叉偏见）之间，如何构建兼具理论严谨性、计算可行性与社会合规性的多目标权衡框架。**

## 2. 方法体系

- 2005：Conformal Prediction——提出基于统计交换性假设的保形预测框架，为后续公平性校准提供理论基础

- 2012：Individual Fairness——提出个体公平性定义，确立基于相似度度量的公平性评估范式

- 2016：Equalized Odds——提出均等机会与均等赔率指标，成为评估分类器偏差的核心标准

- 2017：Counterfactual Fairness——引入因果结构模型定义反事实公平性，将公平性研究提升至因果机制层面

- 2023：Federated Conformal Prediction——将保形预测扩展至联邦学习场景，解决数据去中心化下的覆盖率保证问题

- 2024：FairAgent——提出基于 LLM 的自动化公平 ML 代理系统，实现全流程公平性管理

- 2025：FedCF——提出联邦保形公平框架，在去中心化数据环境中维持理论公平保证

- 2026：mmm-fair——开发交互式多公平权衡工具包，支持多属性、多目标公平性优化

这条时间线勾勒了该领域方法演进的代表性节点：从 2005 年的 Conformal Prediction 奠定该领域方法基线，经 2012 年 Individual Fairness 的推进，到 2026 年的 mmm-fair 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 后处理公平框架

后处理公平框架的核心在于无需重训练模型，通过调整预测输出来满足公平性约束。FedCF（Srinivasan et al., 2025, P2）针对联邦学习场景下数据不可集中存储的问题，重新定义覆盖率差距并引入基于下降法的 CF 优化算法，通过动量梯度下降替代离散搜索，显著减少通信轮次。该方法放弃了对模型内部结构的访问，换取了黑盒兼容性与隐私保护，其代价是引入了额外的通信协议设计与阈值优化复杂度，且依赖客户端数据满足统计交换性假设。CAFP（Arévalo and Oliva, 2026, P10）则通过平均不同反事实场景下的模型预测，构造满足人口统计学均等与均等赔率的修正预测，提供预测失真界的理论保证。CAFP 将反事实公平性原则转化为简单的模型平均操作，实现了模型无关部署与强理论保证的结合，但计算反事实预测可能增加推理延迟，且假设存在可定义的反事实空间。MoE Post-Processing Framework（Zhao and Ng, 2026, P9）通过混合专家机制解耦预训练模型与公平性修正，联合学习简单模型参数与输入依赖的门控权重，避免直接扰动原始模型输出。该方法拓展了线性扰动方法的适用范围，但引入了额外的模型训练开销与门控函数复杂度。后处理路线与因果路线的竞争在于，前者牺牲了过程透明性以换取部署灵活性，而后者则通过因果建模换取理论严谨性，但两者在隐私敏感场景下均面临计算与假设的权衡。

### 2.2 解释公平与程序偏差

解释公平与程序偏差研究聚焦于模型推理过程的稳定性与一致性。Fair Explanation Framework（Popoola and Sheppard, 2026, P16）建立了解释公平性统一理论框架，区分分布公平与程序公平，提出程序偏差概念。该框架揭示 SHAP/LIME 等工具可能因解释质量在少数群体中系统性降低而加剧不平等，指出输出公平不等于过程公平。其代价是增加了模型评估的维度与计算复杂度，且程序公平性的量化依赖于解释方法的稳定性。MESD（Popoola and Sheppard, 2026, P8）提出多类别解释稳定性差异指标，结合经验贝叶斯收缩与分布鲁棒 CVaR 度量，量化最坏情况下的解释差异。MESD 首次将程序偏差度量应用于多保护属性交叉场景，解决了单一属性公平性评估的局限性，但计算 CVaR 与经验贝叶斯估计增加了算法复杂度。Fair Feature Importance Scores（Little et al., 2026, P7）通过测量特征改变时公平性指标的变化，识别与敏感属性相关且加剧偏差的关键特征，为模型审计与偏差溯源提供了直观工具。解释公平路线与后处理路线的互补性在于，前者提供了过程层面的诊断工具，而后者提供了输出层面的修正手段，两者结合可实现从“结果公平”到“过程公平”的全面覆盖。

### 2.3 公平审计与评估

公平审计与评估研究关注公平性评估的可靠性与成本效率。Exp-Audit（Das et al., 2025, P3）设计部分反馈下的成本高效公平审计算法，结合过去选择偏差数据与在线探索，利用截断估计子程序估计条件概率，并通过假设检验验证均等赔率。该方法首次定义并最小化部分反馈下的公平审计成本，提供了严格的理论保证，但算法复杂度依赖于标签获取成本与特征分布。FDI Framework（Alsayed, 2026, P12）提出公平性不一致指数评估框架，量化不同公平性度量间的一致性与冲突程度，揭示单一指标评估的误导性。FDI 将指标不一致作为一等研究对象，支持细粒度偏差分析，但计算多种指标增加了评估时间。LLM-Generated Causal Fairness Reporting（Berarducci et al., 2026, P14）集成 Pearl 因果推断与 AutoML，利用链式思维提示引导 LLM 生成结构化文本报告，将复杂的因果公平性分析自动化。该方法降低了专家解读门槛，但依赖 LLM 的推理能力与提示工程，且因果结构假设需预先定义。审计路线与自动化路线的关联在于，前者提供了评估的可靠性保障，而后者提供了评估的自动化执行能力，两者共同构成了公平性治理的基础设施。

### 2.4 自动化与工具开发

自动化与工具开发旨在降低公平性技术实施门槛。FairAgent（Dai et al., 2025, P4）提出基于 LLM 的自动化公平 ML 代理系统，通过 Web 界面实现从数据预处理到模型评估的全流程公平性管理。该系统利用 LLM 自动检测数据偏差、建议公平性指标及缓解技术，并监督模型训练过程，其创新在于将公平性专业知识封装于 LLM 代理中，降低非专家用户的使用门槛，但 LLM 决策可能存在幻觉或偏差，需人工审查机制保障。mmm-fair（Swati et al., 2025, P1）开发交互式多公平权衡 Python 工具包，支持多属性、多目标公平性优化与 Pareto 前沿可视化，提供端到端公平性管理流程。该工具将公平性操作化为可交互、可解释的工程流程，支持跨职能团队协作与政策对齐，但软件维护复杂度高，且多目标优化计算资源消耗大。Fairness-Aware AutoML（Simões and Correia, 2026, P11）探索公平性感知准则在 AutoML 框架中的影响，将公平性指标纳入 AutoML 优化目标，平衡预测性能与公平性约束。该工作揭示了公平性约束对 AutoML 搜索效率与最终模型质量的影响，但优化空间维度增加导致搜索时间延长。自动化路线与后处理路线的竞争在于，前者牺牲了完全自动化的确定性以换取非专家用户的可访问性，而后者则通过模型无关性换取部署灵活性。

### 2.5 垂直领域公平应用

垂直领域公平应用针对金融、保险、医疗及反洗钱等高风险场景，结合因果推断、多目标优化及联邦学习解决特定领域的公平性与隐私挑战。High-Dimensional GLM Fairness Constraints（Lin and Booth, 2026, P13）提出在高维广义线性模型中集成公平性约束的框架，利用潜在类别分析从辅助特征推断敏感属性，并将公平性约束嵌入变量选择过程。该方法同时处理变量选择、公平性约束与未观测敏感属性，提供统计一致的估计，但潜在类别模型假设可能不成立。TabPFN Causal Fairness Study（Liu et al., 2026, P6）实证研究基于结构因果模型预训练的表格基础模型 TabPFN 的公平性表现，揭示因果先验对缓解虚假相关的作用。该工作为利用基础模型解决公平性问题提供了新视角，但实验局限于表格数据。AML Counterfactual Unfairness Detection（Multerer et al., 2026, P17）应用反事实方法检测反洗钱算法中的不公平性，区分合法中介路径与非法直接歧视，为金融监管提供了因果层面的公平性评估工具。Fairness-Aware Insurance Pricing（Boonen et al., 2025, P5）提出多目标优化方法用于公平性感知保险定价，平衡精算稳健性与监管公平要求，为保险行业提供了实用的公平性定价框架。垂直领域应用与通用方法的关联在于，前者将通用公平性理论具体化为行业合规工具，而后者为前者提供了理论基础与技术支撑。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域共识已确立“多目标权衡”与“程序公平必要性”。后处理因无需访问模型内部且适用于黑盒模型，在部署阶段具有独特优势，这一共识在 FedCF 和 CAFP 的实验中得到了验证，两者均在黑盒模型上实现了显著的公平性改善（支撑证据：P2、P10）。不同公平性定义之间存在根本性的数学冲突，无法在所有情况下同时满足，因此必须根据具体应用场景选择特定的公平性指标或进行多目标权衡，FDI 框架通过量化指标间的不一致性，进一步证实了这一共识（支撑证据：P12）。与此相关的另一个共识是，仅关注结果公平性是不够的，必须考虑程序公平性和解释的稳定性，以确保决策过程的透明与一致，MESD 和 Fair Explanation Framework 通过引入程序偏差指标，填补了现有公平性指标仅关注输出而忽视推理过程稳定性的空白（支撑证据：P8、P16）。交叉群体公平性评估至关重要，单一属性的公平性指标可能掩盖对多重边缘化群体的偏见，MESD 首次实现交叉群体程序偏差的检测与缓解，证实了这一共识（支撑证据：P8）。

### 3.2 观点分歧

因果公平性的可识别性与实用性是领域内的主要分歧。观点 A 认为因果结构可通过领域知识或数据推断，反事实公平性是黄金标准，代表工作如 AML Counterfactual Analysis 通过分解总效应为自然直接效应与自然间接效应，区分合法中介路径与非法直接歧视（支撑证据：P17）。观点 B 认为因果结构通常未知且不可识别，反事实计算依赖强假设，实用性有限，FDI 框架揭示不同指标（含因果指标）间存在显著不一致，表明单一因果指标不可靠（支撑证据：P12）。现有证据偏向观点 B，因为大多数因果公平性实验依赖预设因果图，缺乏自动发现因果结构的鲁棒方法。这一分歧的背后，是另一个更根本的争论：LLM 自动化公平性的可靠性边界。观点 A 认为 LLM 可封装专业知识，实现端到端自动化公平性管理，FairAgent 等系统通过自然语言交互实现全流程公平性管理（支撑证据：P4）。观点 B 认为 LLM 存在幻觉与偏差，无法保证公平性决策的正确性，必须保留人工审查，FairAgent 的设计原则强调“用户覆盖与审查”机制（支撑证据：P4）。现有证据偏向观点 B，因为 LLM 在复杂多目标优化中仍需人工干预，且缺乏评估 LLM 公平性决策可靠性的标准基准。

### 3.3 其他开放问题

交叉公平性（Intersectional Fairness）的计算可行性是当前最紧迫的工程问题。现有方法难以高效覆盖所有交叉子群，MESD 等指标首次实现交叉群体程序偏差检测，但计算 CVaR 与经验贝叶斯估计复杂度极高（支撑证据：P8）。关键困难在于组合爆炸导致的数据稀疏性和计算复杂性，研究路径包括使用因果图模型或高维稀疏正则化来捕捉交互项。最根本的研究问题是因果结构的自动发现与可识别性。现有因果公平性方法依赖预设因果图，缺乏自动发现因果结构的鲁棒方法，反事实数据的不可观测性使得验证困难（支撑证据：P17、P12）。研究路径包括利用 LLM 辅助因果图发现或基于反事实的公平性度量。已知—争议—未知认知图谱：已知后处理与程序公平的必要性，争议因果公平性的可识别性与 LLM 自动化的可靠性，未知交叉公平性的高效计算方法与因果结构的自动发现。发展趋势：随着 LLM 与基础模型的融合，公平性将从“事后审计”转向“内生属性”，但程序公平性与交叉公平性仍是未解之谜。

## 4. 总结与展望

算法公平性研究已从单一的统计指标优化演变为涵盖因果推断、程序正义、自动化审计的系统工程，其核心任务是在数学互斥的公平性定义与不可完全观测的真实世界约束之间，构建可审计、可部署的多目标权衡框架。这一核心瓶颈源于公平性定义的互斥性与真实世界约束的复杂性，现有方法在后处理、解释公平、审计与自动化等路线上做出了不同取舍，但均未完全解决交叉公平性与因果结构自动发现的问题。

未来可能突破的方向包括：利用 LLM 辅助因果图发现，结合 FairAgent 的自动化能力与 AML Counterfactual Analysis 的因果诊断工具，实现因果结构的自动推断与公平性评估的自动化（支撑证据：P4、P17）；开发基于分布鲁棒优化的交叉公平性度量，结合 MESD 的程序偏差检测与 FDI 的指标冲突诊断，实现交叉群体公平性的高效评估（支撑证据：P8、P12）。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，重评测代表性方法在交叉群体与部分反馈场景下的表现，以 Meta-Dataset 多域协议为主基准，建立公平性方法的标准化评测体系，为后续研究提供可靠的比较基础。
