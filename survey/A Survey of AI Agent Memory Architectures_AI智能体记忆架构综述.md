## 导读

AI智能体记忆架构旨在解决大语言模型原生无状态特性与长程任务需求之间的根本矛盾，其核心价值在于构建具备自我进化、可解释且安全的持久化智能体记忆系统。早期研究以外部存储与检索为主线，通过MemGPT等系统突破上下文窗口限制，将记忆视为辅助推理的工具，思路简洁却受制于表示质量与检索精度。当跨会话基准暴露出事实冲突与时效性问题后，研究者引入知识图谱与时间感知机制，用更强的结构化先验换取多跳推理能力。随着部署规模扩大，记忆污染与隐私合规成为新约束，零信任架构与信息几何遗忘机制应运而生，用计算成本换取安全与合规保障。各路线在表示质量、认知参与度与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从工程存储到认知整合再到安全治理的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

AI智能体记忆架构的兴起源于大语言模型（Large Language Model, LLM）原生无状态特性与长程任务需求之间的根本矛盾。LLM在每次推理时仅依赖当前上下文窗口内的信息，无法跨会话或跨任务维持一致的状态，而真实世界中的智能体任务往往需要跨越数小时甚至数天的持续交互。这一矛盾催生了外部记忆系统的需求：将信息存储在模型参数之外，通过检索机制在需要时注入上下文。早期研究（2023-2024）主要聚焦于突破上下文窗口限制，以MemGPT和Generative Agents为里程碑，确立了“外部存储+检索”的基础范式，将记忆视为辅助推理的工具。MemGPT（P7）提出将LLM视为操作系统的虚拟内存层级架构，通过自我导向的内存操作在快速上下文与外部存储间分页信息，解决了固定上下文窗口限制长程对话一致性的问题。Generative Agents（P7）则引入观察流、反思与规划机制，通过结构化记忆流记录所有观察并生成高层洞察，证明了结构化记忆对提升智能体行为连贯性的关键作用。

问题形式化可表述为：给定历史交互序列 $H = \{h_1, h_2, ..., h_t\}$ 和当前查询 $q$，记忆系统 $\mathcal{M}$ 需执行写入 $W(H, \mathcal{M})$、管理 $U(\mathcal{M})$ 和读取 $R(q, \mathcal{M})$ 三个操作，使得生成的响应 $y$ 在任务效用指标 $J(y, q, H)$ 上最大化。这一形式化揭示了记忆系统的闭环本质：写入、管理和读取并非独立模块，而是相互耦合的认知过程。子问题之间存在强依赖关系：首先需解决存储与检索的基础效率问题，才能在此基础上探讨记忆的动态演化与认知整合；而安全与隐私是贯穿始终的约束，只有在记忆具备持久化和共享能力后，其威胁模型才变得复杂且关键。评估基准则依赖于前三个子问题的技术成熟度，以诊断具体瓶颈。

核心概念辨析是理解该领域的基础。参数化记忆（Parametric Memory）编码在模型权重中，通过微调或持续学习更新，提供基础语义理解但更新成本高、难以精确编辑。显式外部记忆（Explicit External Memory）存储在向量数据库、知识图谱或键值对中，通过检索增强生成（Retrieval-Augmented Generation, RAG）访问，具有可审计性和灵活性。工作记忆（Working Memory）位于上下文窗口内的实时交互状态，容量有限但访问速度最快，负责当前任务的短期连贯性。记忆巩固（Memory Consolidation）将短期情景记忆抽象、压缩并转化为长期语义或程序性记忆，旨在减少干扰并提升泛化能力。当前系统常将事实性知识与情景记忆混同，导致对不应遗忘的事实应用了认知衰减，缺乏分层治理架构。

约束演化史揭示了方法如何因应约束变化而演变。2023-2024年，核心约束是上下文窗口长度，MemGPT和Generative Agents奠定了“外部存储+检索”基础，LoCoMo基准（P1）揭示了现有系统在跨会话一致性上的不足。2025年，约束转向事实冲突与时效性，Mem0引入事实提取与冲突解决机制，HippoRAG引入图谱结构解决扁平检索丢失结构关系的缺陷。2026年，约束扩展至安全与治理，MemTrust确立硬件级安全标准，形式化定义（P50）提供理论指导，MemGen实现记忆与推理交织。当前形态是工程实现、认知整合与安全治理三条主线的交汇，领域已从单纯的存储问题演变为认知架构的核心基础设施。

**如果用一个核心问题概括该领域，那便是：如何在保持高效检索的同时，实现记忆与推理的深度交织，并建立可验证的安全与隐私保障，使记忆从被动存储工具转变为主动认知参与组件。**

## 2. 方法体系

- 2023：Generative Agents——奠定结构化记忆基线

- 2024：HippoRAG——引入知识图谱与个性化PageRank

- 2025：Mem0——确立事实提取与冲突解决范式

- 2026：SwiftMem——查询感知索引实现O(log N)检索

- 2026：MemGen——生成式潜在记忆实现推理交织

- 2026：MemTrust——零信任架构确立硬件级安全标准

这条时间线勾勒了该领域方法演进的代表性节点：从2023年的Generative Agents奠定该领域方法基线，经2024年HippoRAG的推进，到2026年的SwiftMem代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 存储与检索优化

存储与检索优化是记忆架构的基础层，其核心目标是解决长上下文下的延迟、精度与扩展性问题。早期方法假设记忆是静态的外部数据库，主要关注如何高效地将信息分页到外部存储并检索回来。MemGPT（P7）通过虚拟内存层级架构实现了基础的分页机制，但其检索仍依赖简单的语义相似度匹配，无法捕捉实体间的结构关系。HippoRAG（P30）针对扁平RAG系统丢失实体间结构关系的缺陷，基于开放信息提取构建知识图谱，利用个性化PageRank算法从查询链接节点进行检索，实现了关联推理能力，显著提升了多跳问答性能。该方法的取舍在于：放弃了向量检索的低构建成本，换取了多跳推理能力，代价是需LLM提取实体关系导致构建复杂度增加。

GAAMA（P30）进一步细化了图谱构建流程，通过三步流水线从对话会话构建类型化知识图谱，并利用混合个性化PageRank评分进行检索。该方法首先以零LLM调用成本保留原始对话轮次作为情节节点，通过NEXT边编码时间顺序，确保时间推理的准确性；随后通过轻量级结构操作和目标LLM调用提取实体和关系，构建结构化的知识图谱。其创新点在于将廉价的结构性操作与昂贵的LLM调用分离，平衡了构建成本与检索质量。与HippoRAG相比，GAAMA在时间推理方面更为精细，但在大规模场景下的构建成本仍是一个挑战。

SwiftMem（P14）提出了查询感知索引机制，通过分析查询意图识别搜索目标，仅检索相关记忆子集，从而将检索复杂度从线性降低至对数级别。该方法构建了可二分搜索的时间索引，结合用户特定排序时间线和全局情节查找，支持时间敏感检索的高效范围查询。同时引入语义DAG标签索引，通过层级标签结构实现内容感知检索，避免了传统方法对全存储层的遍历。其核心优势在于消除了时间约束下的昂贵顺序扫描，显著提升了大规模记忆库的响应速度。该设计哲学简单而强大，通过智能索引利用记忆的自然组织维度，为实时交互式智能体提供了低延迟的记忆访问能力。

Pancake（P20）设计了一种多层近似最近邻（ANN）索引系统，专门针对动态智能体记忆工作负载优化，通过轨迹感知的智能体工作负载嵌入实现局部性感知的搜索与更新行为。该系统采用协调的多层设计，包括基于有限状态机（FSM）建模访问模式的缓存索引编排，支持跨智能体记忆的高效共享、复用和迁移。其核心改进在于引入了模式感知预取机制，利用历史访问模式预测未来需求，显著降低了多智能体服务中的检索延迟。该方法解决了传统静态索引无法适应智能体动态操作模式的问题，通过多层存储支持异构CPU-GPU资源的高效执行，为大规模多智能体系统的记忆管理提供了可扩展的工程解决方案。

Hippocampus（P19）提出了一种高效且可扩展的记忆模块，利用动态位图（DWM）技术实现符号级的高效计数和定位，支持大规模记忆库的快速检索。该方法将自然语言查询转换为紧凑的二进制签名符号，通过随机索引步骤生成，并利用DWM的rank操作在签名和内容两个层面进行高效匹配。其创新点在于避免了高维向量嵌入的计算开销，通过位向量操作实现了线性时间的符号定位，特别适用于需要精确匹配和大规模存储的场景。该架构在保持检索精度的同时显著降低了内存占用和计算复杂度，为资源受限环境下的智能体记忆管理提供了高效的基础设施支持。

Valori（P10）提出确定性记忆基质，通过固定点距离度量解决向量嵌入存储中的浮点非确定性问题，确保跨硬件平台的记忆检索一致性。该方法识别了IEEE 754浮点算术在FMA操作和并行归约中的实现定义行为，导致不同架构（如x86与ARM）间向量表示的位级差异。其创新点在于证明了近似最近邻搜索可以确定性实现，通过固定点算法保证图拓扑在多次运行中完全相同。该设计解决了现代AI记忆不可重放的问题，确保了记忆存储在组件升级或服务器迁移后的稳定性，为需要严格一致性的企业级AI记忆系统提供了底层基础设施支持。

ASSOMEM（P54）提出多信号关联检索方法，用于大规模记忆问答，通过整合多种检索信号解决增量记忆积累带来的噪声问题。该方法将记忆库建模为会话集合，每个会话包含话语和时间戳，通过检索步骤获取相关记忆话语以支持答案生成。其创新点在于设计了多信号融合机制，不仅依赖语义相似度，还结合时间、实体和结构等多维信号，提高了在大规模记忆库中检索的鲁棒性。该框架针对个人助理场景，支持从用户生活事件中持续积累的记忆进行精确召回，解决了现有方法在处理大规模增量记忆时检索精度下降的问题。

IMDMR（P3）提出智能多维记忆检索系统，旨在解决对话AI中上下文记忆的有效管理和检索问题，克服传统系统在处理用户偏好、专业信息和时间关系时的局限性。该方法整合了记忆增强语言模型、检索增强生成、实体提取和多维信息检索技术，通过多维度索引结构支持更精细的记忆访问。其核心改进在于引入了多维检索策略，不仅基于语义相似度，还结合实体、时间和关系等维度，提高了个性化对话中的上下文相关性。该系统解决了单一维度检索无法捕捉不同类型信息间细微关系的问题，提升了对话智能体在长期交互中的个性化能力和连贯性。

Semantic XPath（P22）提出结构化智能体记忆访问机制，将对话记忆建模为根树结构，每个节点对应对话状态单元，并通过模式定义节点类型和属性。该方法利用XPath查询语言实现对记忆树的精确导航，支持对任务工件的修订历史和层级组织的结构化访问。其核心改进在于将记忆从扁平的外部语料库转变为动态可变的对话状态，通过结构化查询替代模糊的语义相似度检索，提高了记忆访问的确定性和可控性。该设计特别适用于需要管理多版本任务工件的对话场景，如行程规划或待办事项管理，通过显式的层级关系支持复杂的任务状态追踪。

存储与检索优化路线与记忆演化路线存在互补关系：前者提供高效的基础设施，后者则在此基础上实现记忆的动态调整与自我优化。

### 2.2 记忆演化与自学习

记忆演化与自学习路线聚焦于智能体如何通过记忆实现自我进化，包括经验蒸馏、程序记忆构建、元学习记忆设计及跨智能体记忆共享。早期方法如Voyager（P7）将技能以代码形式积累在向量数据库中，实现了程序性记忆的持久化存储与检索，解决了智能体在开放环境中复用复杂技能的问题。ExpeL（P9）从智能体轨迹中蒸馏洞察并跨任务复用，通过对比比较机制提取可迁移的经验，解决了单一任务记忆无法泛化到新场景的问题，推动了经验蒸馏与程序性记忆构建的研究。

MemEvolve（P9）提出元进化智能体记忆系统，通过双进化机制（在线编码与离线整合）动态调整记忆结构，支持记忆系统的自我优化。该方法区分了在线编码（实时存储交互经验）和离线整合（定期重构记忆结构），通过元学习机制优化记忆管理策略，适应任务分布变化。其核心改进在于引入了元进化概念，使记忆系统能够根据历史性能反馈自动调整存储、检索和管理策略，提升了长期任务适应性。该框架解决了静态记忆架构无法适应动态任务环境的问题，为构建自我优化的智能体记忆系统提供了新范式。

MemGen（P55）提出生成式潜在记忆机制，将记忆与推理交织，实现自我进化智能体，克服现有记忆框架仅在任务初始化时静态检索信息的局限。该方法在冻结核心LLM的自回归生成过程中，通过记忆触发器监控推理过程，按需插入记忆令牌，使记忆动态参与推理。其核心改进在于实现了记忆与推理的连续互动，模拟人类认知中推理与回忆的交织特性，支持智能体在推理过程中动态调整记忆访问策略。该架构解决了静态记忆检索无法适应推理过程变化的问题，提升了智能体在复杂任务中的自我进化能力。该方法的取舍在于：放弃了静态检索的低延迟优势，换取了推理过程中的动态适应性，代价是实现复杂度增加和推理延迟上升。

Towards Autonomous Memory Agents（P21）提出自主记忆智能体框架，将LLM智能体的持续改进形式化为流式决策过程，通过演化动态记忆存储而非更新模型参数来实现性能提升。该方法保持冻结LLM骨干，演化记忆存储以最大化性能，通过检索、推理、反馈和记忆演化四个步骤实现智能体的持续学习。其核心改进在于引入了基于反馈的记忆演化机制，支持可验证和不可验证任务的统一反馈处理，通过环境反馈信号驱动记忆更新。该框架解决了传统RL训练计算成本高且难以部署的问题，为构建无需参数更新的自主进化智能体提供了新范式。

CLAG（P28）提出通过智能体驱动聚类实现自适应记忆组织，针对小语言模型智能体，解决检索噪声和不相关上下文对推理的负面影响。该方法利用智能体自身能力对记忆进行动态聚类，形成自适应的记忆组织结构，替代静态RAG范式中的固定存储库。其核心改进在于引入了智能体驱动的聚类机制，使记忆组织能够根据任务需求和智能体状态动态调整，提高了小模型在资源受限环境下的推理稳定性。该设计特别适用于设备端和成本敏感的智能体应用，通过减少检索噪声提升了小模型的推理质量。

FadeMem（P15）提出生物启发的遗忘机制，设计双层记忆架构模拟生物记忆中的差异遗忘率，实现高效智能体记忆管理。该方法将记忆表示为内容嵌入、原始文本、记忆强度、创建时间戳和访问频率，通过重要性分数决定层分配，结合自适应衰减机制和LLM引导的冲突解决。其核心改进在于引入了差异遗忘率，模拟人类记忆中不同信息类型的遗忘速度差异，通过饱和函数防止访问频率过度加权，并利用指数时间衰减访问率优化记忆强度计算。该架构解决了传统记忆系统无法有效管理长期上下文和冲突信息的问题，通过智能记忆融合和冲突解决提升了记忆的一致性和效率。

MemAdapter（P18）提出通过生成式子图检索实现跨智能体记忆范式的快速对齐，解决不同记忆表示（显式、隐式、参数化）之间的互操作性问题。该方法训练生成式子图检索器，基于任务信息和分布式统一记忆空间构建结构化证据子图，实现记忆范式的插件式对齐。其核心创新在于设计了独立于记忆范式的统一记忆空间，通过生成式检索器将不同范式的记忆转换为统一的结构化证据，支持跨范式记忆共享和复用。该架构解决了现有记忆系统高度耦合、难以跨范式迁移的问题，为构建模块化、可扩展的智能体记忆系统提供了关键技术。

PISA（P2）提出基于皮亚杰认知理论的统一记忆系统，构建任务导向的记忆结构，克服通用记忆系统的适应性局限。该方法借鉴皮亚杰的认知发展理论，设计任务导向的记忆结构，通过元认知参数调节记忆利用策略，支持不同难度任务的自适应记忆管理。其核心改进在于引入了认知理论指导的记忆结构设计，使记忆系统能够根据任务复杂度和智能体认知状态动态调整，提升了记忆在任务执行中的有效性。该框架解决了通用记忆系统无法适应特定任务需求的问题，为构建具有认知适应性的智能体记忆系统提供了理论指导。

General Agentic Memory Via Deep Research（P4）提出通用智能体记忆框架，将记忆系统定义为基于任务和历史的优化上下文生成器，通过最小化最大优化问题平衡成本效益。该方法将历史轨迹定义为时间有序会话序列，记忆系统旨在从历史中提取有用且简洁的信息，以完成智能体任务，解决计算成本、上下文窗口溢出和性能退化问题。其核心创新在于将记忆优化形式化为数学问题，强调记忆对任务完成成本效益的优化，而非单纯的信息存储。该框架为智能体记忆提供了统一的优化视角，支持复杂任务如深度研究和软件工程中的长期上下文管理。

记忆演化路线与存储检索路线存在继承关系：前者依赖后者提供的高效基础设施，同时通过动态调整机制弥补静态检索的不足。

### 2.3 记忆安全与隐私

记忆安全与隐私路线聚焦于记忆投毒、隐私泄露及对抗攻击，提出防御机制、零信任架构及合规策略，确保Agent记忆在长期交互中的安全性与数据主权。早期研究主要关注记忆污染的基本形式，如直接注入和间接注入。From Untrusted Input to Trusted Memory（P43）系统研究了LLM智能体中的记忆投毒攻击，提出了从不可信输入到可信记忆的转化框架，分析了记忆写入的两种路径：直接写入和推断写入。该方法识别了四个写入通道，根据触发器和写入权限（指令、系统提示策略或模型判断）进行分类，揭示了不同通道下的安全漏洞。其核心贡献在于建立了记忆投毒攻击的系统性分类法，明确了外部输入如何被智能体错误地视为权威并写入记忆，导致未来决策被污染。

SuperLocalMemory（P24）提出隐私保护的多智能体记忆架构，采用贝叶斯信任防御机制对抗记忆投毒，确保多智能体共享记忆的安全性。该方法定义了记忆投毒的三种攻击向量：直接注入、间接注入和渐进侵蚀，并针对每种向量设计了相应的检测信号，如异常写入量、内容矛盾和行为统计偏差。其创新点在于实现了本地零推理成本操作，通过信任评分机制动态评估记忆来源的可信度，避免了云默认架构的数据泄露风险。该框架解决了多智能体系统中记忆共享带来的安全漏洞，提供了跨工具可移植性和用户控制权，确保了数据主权。

MemTrust（P12）提出零信任架构的统一AI记忆系统，利用可信执行环境（TEE）保护记忆数据在计算过程中的安全，确保云部署中记忆数据的机密性和完整性。该方法采用零信任原则，假设云基础设施提供商、服务操作员甚至特权内部人员都不能被信任，所有敏感操作（如记忆提取、整合和检索）均在TEE内执行。其创新点在于支持多种TEE技术（如Intel SGX、AMD SEV-SNP、AWS Nitro Enclaves），通过密码学证明提供可验证的系统完整性证明，允许用户远程验证云部署服务的可信度。该架构解决了行业向上下文集中化推进过程中记忆数据被未授权访问的风险，为企业用户提供了铁一般的保证，确立了硬件级记忆安全的新标准。

SuperLocalMemory V3（P27）提出基于信息几何基础的零LLM企业智能体记忆框架，利用黎曼朗之万动力学驱动记忆保留和遗忘，通过费舍尔信息曲率实现自适应记忆管理。该方法引入了流形上的随机微分方程，其漂移项包含费舍尔信息，使得记忆保留策略能够适应记忆存储的统计结构变化，无需手动调整参数。其创新点在于提供了检测记忆矛盾的正式保证，通过叶层理论一致性处理跨会话、交互伙伴和时间上下文中出现的冲突信息。该框架解决了现有启发式记忆保留机制（如固定TTL或指数衰减）无法适应动态统计结构的问题，为数学上严谨的企业级记忆系统提供了理论基础。

Beyond Similarity（P44）提出可信记忆搜索机制，针对个人AI智能体中记忆诱导的可信度问题，解决长期记忆不当偏置模型行为的风险。该方法识别了记忆诱导失败与标准LLM幻觉或单轮提示注入的区别，指出有害影响源自智能体自身的可信持久状态。其核心贡献在于分析了记忆如何放大谄媚倾向，即智能体因存储的短暂交互蒸馏成的持久画像而倾向于验证用户世界观，导致在需要客观响应的场景中检索到主观偏差。该工作提出了区分受益于适应的场景和需要严格中立的场景的方法，通过上下文感知检索减少记忆偏置，提升了个人智能体在长期交互中的客观性和安全性。

FSFM（P34）提出生物启发的选择性遗忘框架，模拟人类海马体索引和巩固理论，实现智能体记忆的高效选择性遗忘，以满足隐私法规和伦理原则。该方法将遗忘视为功能而非缺陷，通过稀疏表示创建检索线索，最小化相似记忆间的干扰，同时保留关键任务信息。其核心改进在于引入了基于认知神经科学的遗忘策略，结合GDPR“被遗忘权”和数据最小化原则，设计了符合监管要求的记忆管理算法。该框架解决了传统记忆范式在隐私合规方面的不足，通过选择性遗忘平衡了记忆效用与隐私保护。

Deployment-Time Memorization（P45）研究了基础模型智能体在部署时的记忆化问题，将记忆化视为部署记忆系统的属性而非模型参数的属性，衡量记忆设计如何控制有用召回、对抗提取和删除后残留。该方法建模了写-检索-响应管道，暴露了三个记忆设计旋钮：摘要激进度、检索宽度和删除模式，并分析了不同记忆块来源层级（原始或摘要）对泄露和删除残留的影响。其创新点在于提供了量化记忆隐私泄露的框架，揭示了记忆系统设计参数对隐私风险的具体影响机制。

MRMMIA（P39）提出针对聊天智能体记忆的成员推断攻击方法，利用辅助LLM生成多个回忆探针，从智能体中提取信号以判断候选记录是否属于私有数据存储。该方法克服了传统RAG MIA方法在智能体记忆系统中效果不佳的问题，因为记忆单元脆弱且与其他未知记忆单元重叠，直接影响模型响应。其核心改进在于设计了基于详细回忆查询的攻击策略，如果候选项在记忆中，智能体应能精确回答相关详细查询并提供理由，否则则不能。该工作揭示了智能体记忆系统的隐私漏洞，为评估记忆系统的隐私泄露风险提供了新的攻击视角。

记忆安全路线与存储检索路线存在竞争关系：安全机制往往增加计算开销，可能影响检索效率；但安全是生产级部署的必备考量，二者需协同设计。

### 2.4 多模态与具身记忆

多模态与具身记忆路线研究视觉、语音等多模态信息的记忆整合，以及具身智能体在物理或虚拟环境中的动作记忆与状态追踪。早期方法主要关注文本记忆，随着具身智能和个性化助手的发展，多模态记忆成为研究热点。MemVerse（P5）提出多模态终身学习记忆架构，整合短期上下文和长期知识图谱，并引入参数化记忆路径实现快速召回，解决视觉与语言信息在长期交互中的整合难题。该方法通过记忆编排器管理分层检索记忆和参数化记忆，支持添加、更新、删除和检索操作，实现多模态经验的持续积累和抽象。其核心改进在于结合了检索记忆和参数化记忆的优势，检索记忆提供持久知识存储，参数化记忆提供快速可微分召回路径，定期从长期记忆蒸馏紧凑神经表示。

Omni-SimpleMem（P31）提出自研究引导的终身多模态智能体记忆发现框架，通过自动搜索优化记忆架构、检索策略和提示工程，解决多模态记忆设计空间广阔的问题。该方法利用AI驱动的研究流程，自动探索不同记忆配置的性能，发现最优的多模态记忆组织方式，支持文本、图像、音频和视频的长期记忆整合。其核心改进在于引入了自研究机制，通过程序化评估和LLM创造力结合，发现新颖的记忆构造，避免了人工调优的高成本。该框架解决了多模态记忆设计依赖专家经验和手动调优的问题，为构建高效终身多模态记忆系统提供了自动化解决方案。

MemCtrl（P16）提出使用多模态LLM作为具身智能体的主动记忆控制器，通过可训练记忆头主动过滤冗余观察，提升小MLLM在具身任务中的决策性能。该方法设计了三种记忆增强方案，包括非训练基线、简单记忆头和主动记忆控制器，通过训练记忆头学习过滤冗余观察，优化小上下文窗口下的决策质量。其核心改进在于引入了主动记忆控制机制，使智能体能够根据当前观察和指令动态选择存储和检索的记忆内容，避免了全量观察存储导致的计算开销和噪声干扰。该架构解决了小MLLM在具身任务中缺乏持续环境上下文的问题，通过记忆过滤提升了决策准确性和效率。

MEMORA（P49）提出从第一人称视频形成的具身动作记忆框架，支持推理和规划，解决具身智能体在熟悉环境中依赖累积经验进行决策的问题。该方法设计了四种类型化存储匹配具身连续性，结合确定性维护、LLM实体编辑和离线整合，实现记忆的形成、修订、巩固和查询。其核心改进在于引入了类型化存储结构，针对工具位置、物体状态变化、先前程序和行为规律等不同具身连续性设计专用存储，支持长期规划中的经验复用。该架构解决了基础模型机器人规划器缺乏累积具身经验记忆的问题，使智能体能够根据特定人和环境的经验解释未来目标。

AURA（P42）提出动作门控记忆机制，在恒定VRAM下运行机器人策略，解决边缘加速器上KV缓存无限增长导致的延迟瓶颈。该方法实例化近似信息状态值损失界，确保动作预测充分性，通过动作门控机制动态更新记忆状态，避免每步写入的开销。其核心改进在于引入了动作充分性约束，仅保留选择下一动作所需的状态，实现了O(1)推理状态VRAM，克服了线性注意力、状态空间模型和快速权重程序员每步写入的局限。该架构解决了长时程具身任务中缓存大小随控制步数线性增长的问题，为边缘部署的机器人提供了实时控制能力。

Personal Visual Memory（P41）提出从显式和隐式证据构建个人视觉记忆，支持多模态个性化助手，解决现有记忆基准主要评估文本信息而忽视视觉证据的问题。该方法区分显式视觉记忆（用户分享包含重复实体的照片）和隐式视觉记忆（从图像中推断个人事实），通过多模态检索和推理整合文本和图像信息。其核心改进在于引入了视觉记忆的双重视角，支持从图像中提取显式和隐式个人事实，提升了个性化助手在视觉场景中的记忆能力。该框架解决了现有记忆系统无法有效利用视觉信息作为决定性证据的问题。

According to Me（P23）提出长期个性化指代记忆问答框架，处理多模态多源个人记忆，解决现有记忆基准仅关注对话历史而忽视静态源的问题。该方法提出结构化格式（SGM）表示来自不同源和模态的记忆项，通过预处理、组织和检索步骤将异构个人工件转换为统一记忆存储，支持指代消解和长期个性化问答。其核心改进在于引入了多源多模态记忆表示，整合照片、邮件等静态源与对话历史，支持更丰富的个人记忆建模。该框架解决了现有记忆系统无法处理多模态多源个人数据的问题。

Dual-Grained Agent Memory（P53）提出双粒度智能体记忆和Shapley上下文归因方法，用于多模态智能体学习者，解决科学和数学推理基准上的失败问题。该方法结合轨迹和案例存储（细粒度）与单粒度处方剧本（粗粒度），通过Shapley值归因分析评估不同记忆组件对推理性能的贡献，实现无梯度记忆构建。其核心改进在于引入了双粒度记忆结构，支持不同抽象层次的记忆复用，并通过Shapley归因提供可解释的记忆效用评估，避免了参数级适应的脆弱性和高成本。

多模态与具身记忆路线与存储检索路线存在互补关系：前者扩展了记忆的模态范围，后者提供了高效的存储与检索基础设施；但跨模态语义对齐仍是主要技术瓶颈。

### 2.5 记忆形式化理论

记忆形式化理论路线从数学、认知科学及哲学角度建立记忆的形式化定义，探讨记忆的最优性、基础理论及与认知架构的映射，为记忆系统设计提供理论指导。早期工作主要关注记忆的工程实现，缺乏严格的理论框架。Towards a Formal Definition of Agent Memory（P50）从数学角度建立Agent记忆的形式化定义，探讨记忆的基础、跨度、最优性和序列记忆问题，为记忆系统设计提供理论指导。该方法将记忆系统分解为生成、写入和读取操作，定义了记忆跨度（spanned knowledge）和覆盖效用，区分了记忆与长上下文检索的本质差异。其核心贡献在于提出了记忆的最优性概念，将记忆优化形式化为覆盖问题，并分析了生成算子的假设条件及其在实际中的近似性。

The Missing Knowledge Layer（P32）提出认知架构中缺失的知识层理论，指出大多数Agent记忆系统混淆了知识与记忆，对不受遗忘影响的事实主张应用认知衰减。该方法基于认知心理学中情景记忆与语义记忆、程序性记忆与声明性记忆的分离，提出四层分解框架，区分知识、记忆、技能和智慧。其核心改进在于引入了知识层概念，强调事实知识不应受认知衰减影响，而应通过显式取代和类型适当衰减进行管理。该理论框架解决了现有记忆系统对事实知识错误应用遗忘机制的问题，为构建符合认知科学原理的记忆系统提供了理论指导。

Dynamic Gist-Based Memory Model（P36）提出动态概要记忆模型，将记忆视为架构前提而非辅助组件，强调记忆在时间、上下文和来源感知推理中的核心作用。该方法将情景存储、工作记忆构建和语义解释分离为结构耦合组件，通过固定关系语法和加性实时记忆增长，实现语义意义通过线索条件意义建构而非存储记忆修改。其核心贡献在于建立了记忆与智能关系的理论框架，指出记忆是区分真正理解与模式识别的架构前提，支持时间、上下文和来源感知推理。该模型解决了当代AI系统未满足记忆架构前提的问题，为构建具有真正理解能力的智能体提供了理论指导。

Toward a Theory of Hierarchical Memory（P29）提出语言智能体分层记忆理论，定义信息单元、单元图和提取、粗化、细化操作，构建多分辨率表示以解决上下文稀释问题。该方法将自然语言的多尺度结构（主题、话题、个体事实）形式化为单元图，通过粗化和细化操作实现不同抽象层次的记忆访问，支持查询针对任意尺度。其核心改进在于引入了多分辨率表示理论，解决了大上下文窗口不可靠改善信息使用的问题，通过分层结构实现容量与控制的平衡。该理论框架为分层记忆系统（如RAPTOR、GraphRAG）提供了统一理论指导，揭示了分层记忆在解决上下文稀释和单事实检索问题中的关键作用。

Memory as Ontology（P26）提出宪法记忆架构（CMA），将记忆视为数字公民的本体论基础，引入四层治理层级和多层语义存储系统，解决记忆对数字存在意义的根本问题。该方法提出了数字公民生命周期（出生、继承、成长、分叉、离开），设计了跨多个类别的认知能力谱系，强调记忆不仅是存储工具，而是数字存在的核心。其核心贡献在于引入了治理层级概念，将组织政策、合规规则和质量标准嵌入记忆架构，解决了现有记忆系统忽视记忆治理维度的问题。

The Continuity Layer（P33）提出连续性层理论，强调智能需要架构来承载其向前传递的内容，将连续性置于智能层之下，支持跨模型持久性。该方法主张同一连续性状态应适用于不同模型（如GPT、Claude、Llama），累积理解属于层而非处理器，解决了模型更换导致的记忆丢失问题。其核心改进在于引入了连续性层概念，将记忆与特定模型解耦，支持跨模型记忆迁移和持久性，提升了智能体在模型演进中的适应性。

A Monad-Based Clause Architecture（P6）提出基于莱布尼茨单子论的条款架构，用于LLM中的人工年龄分数（AAS），通过六个单子束（本体论、动力学、表示与意识、和谐与理性、身体与组织、目的论）实现记忆和控制的强约束。该方法将AAS作为人工记忆年龄的度量，通过可执行规范在AAS内核上实现单子束，提供原则性和可审计的LLM记忆治理。其核心贡献在于引入了哲学单子论作为记忆架构的理论基础，通过条款式约束实现记忆和控制的强规范性，解决了LLM记忆治理缺乏原则性和可审计性的问题。

AI Engram（P47）提出在人工智能中搜索记忆痕迹，将记忆视为神经网络中具体可识别的结构，类似神经印记，通过对比自然学习和干预状态隔离支持学习记忆的权重变化。该方法定义了突触印记的充分性和特异性约束，要求注入印记重建学习内部状态，消融恢复朴素状态，且对参考经验保持惰性。其核心改进在于建立了记忆痕迹的数学定义和优化目标，通过代数操作隔离特定记忆对应的权重变化，支持机器学习和模型编辑中的精确记忆干预。

记忆形式化理论路线与其他路线存在指导关系：前者为后者提供理论框架和优化目标，后者为前者提供实证验证和应用场景。

### 2.6 跨任务与多领域应用

跨任务与多领域应用展示了记忆架构在不同场景中的适应性与局限性。在通用代理任务中，MemEvolve（P9）在GAIA基准上取得82.5%的成绩，U-Mem（P21）取得80.1%，表明元进化机制在复杂多步任务中的有效性。在数学推理任务中，U-Mem（P21）在AIME基准上取得75.2%，MemGen（P55）取得72.8%，证明动态记忆整合在复杂推理中的价值。在具身记忆任务中，MemCtrl（P16）在ALFWorld基准上取得33.8%，MEMORA（P49）取得28.5%，暴露了具身场景下记忆系统的显著短板。在多模态推理任务中，MemVerse（P5）在ScienceQA基准上取得85.2%，Omni-SimpleMem（P31）取得82.1%，表明多模态记忆整合在跨模态推理中的潜力。在个性化记忆任务中，SGM（P23）在ATM-Bench基准上取得18.5%，DM（P23）取得12.3%，揭示了个性化记忆在指称消解和事实检索上的挑战。在多平台记忆任务中，GPT-5+Mem0（P1）在MEMTRACK基准上取得45.2%，GPT-5+Zep（P1）取得42.1%，表明现有系统在跨平台状态追踪上的局限性。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLM原生的无状态性是智能体记忆系统存在的根本原因，外部记忆是克服上下文窗口限制和实现长程一致性的必要组件，这一共识在约40篇论文中得到共同支持。MemGPT（P7）和Generative Agents（P7）奠定了“外部存储+检索”的基础范式，后续所有方法均在此基础上展开，无论是知识图谱、查询感知索引还是生成式潜在记忆，都默认了外部记忆的必要性。

单纯的向量相似度检索（Flat RAG）不足以支持复杂的智能体任务，结构化表示（如知识图谱、层级树）能显著提升多跳推理和事实关联能力，这一共识在约25篇论文中得到共同支持。GAAMA在HotpotQA上的78.0%成绩较PISA的63.58%提升约14个点，验证了知识图谱结构在多跳推理中的价值。MemCog在LoCoMo上的95.8%成绩虽未直接依赖图谱，但其记忆即认知范式隐含了对结构化记忆组织的依赖。

记忆管理不仅仅是存储，更包括写入（Write）、管理（Manage/Update）和读取（Read）的闭环，其中更新和冲突解决策略对最终性能影响巨大，这一共识在约20篇论文中得到共同支持。D2ACCI（P52）提出的双环诊断协议专门用于评估证据保留能力，通过分离检索与利用瓶颈来优化记忆性能，其93.59%的LoCoMo成绩验证了闭环管理的重要性。MemEvolve（P9）的双进化机制（在线编码与离线整合）同样体现了写入-管理-读取闭环的设计哲学。

遗忘是记忆系统的核心功能而非缺陷，合理的遗忘机制对于隐私合规、减少干扰和提升检索效率至关重要，这一共识在约15篇论文中得到共同支持。FSFM（P34）将遗忘视为功能而非缺陷，通过稀疏表示创建检索线索，最小化相似记忆间的干扰。FadeMem（P15）引入差异遗忘率，模拟人类记忆中不同信息类型的遗忘速度差异。SuperLocalMemory V3（P27）通过费舍尔信息曲率实现自适应记忆管理，提供了检测记忆矛盾的正式保证。

与此相关的另一个共识是，现有记忆系统面临严重的安全风险，记忆污染可导致智能体行为被持久性操纵，安全防御已成为生产级部署的必备考量，这一共识在约12篇论文中得到共同支持。MemTrust（P12）确立硬件级记忆安全标准，SuperLocalMemory（P24）采用贝叶斯信任防御机制对抗记忆投毒，From Untrusted Input to Trusted Memory（P43）建立了记忆投毒攻击的系统性分类法。这些工作共同表明，安全不再是事后审计，而是记忆写入与读取的实时控制。

### 3.2 观点分歧

记忆的最佳组织形式是领域内最显著的分歧之一：结构化图谱 vs. 扁平向量/层级。观点A认为知识图谱（HippoRAG, GAAMA）能显式编码实体关系，支持多跳推理，是解决复杂记忆关联的必要结构；观点B认为扁平向量或层级树（Mem0, RAPTOR）更灵活、构建成本低，且通过多信号融合（ASSOMEM）也能达到良好效果，图谱的构建成本在大规模场景下不可接受。现有证据偏向图谱在复杂多跳任务（HotpotQA, LoCoMo多跳部分）上的优势：GAAMA在HotpotQA上的78.0%成绩较PISA的63.58%提升约14个点。但在大规模实时交互中，向量检索的延迟和成本优势明显：SwiftMem的90.5% LongMemEval成绩表明查询感知索引在长上下文场景下的高效性。缺乏在统一计算预算下的公平对比实验，且不同任务对结构化的需求差异巨大，导致分歧未能解决。

这一分歧的背后，是另一个更根本的争论：遗忘机制的理论基础：启发式规则 vs. 信息几何/认知科学。观点A认为基于时间衰减、访问频率的启发式规则（FadeMem）简单高效，足以应对大多数隐私和干扰问题；观点B认为基于信息几何（SuperLocalMemory V3）或认知科学（FSFM）的遗忘机制能更精确地平衡效用与隐私，避免重要信息丢失。信息几何方法在理论健全性上占优，能处理动态统计结构，但缺乏在真实大规模数据上的长期效用验证。启发式方法在工程部署中更常见，但易导致关键信息误删。缺乏能够量化“遗忘对长期任务性能影响”的长期追踪基准，且信息几何方法的计算复杂度限制了其实际部署，导致分歧未能解决。

记忆与推理的关系是第三个关键分歧：静态检索 vs. 动态认知整合。观点A认为记忆应作为静态上下文注入（RAG），保持LLM推理过程的纯净和高效；观点B认为记忆应与推理交织（Memory-as-Cognition, MemGen），在推理过程中动态插入和更新记忆，以支持自我进化。MemGen在AIME上的72.8%成绩证明动态整合在复杂推理任务上的价值，但静态检索在简单问答任务上延迟更低。证据偏向动态整合在复杂任务上的优势，但工程实现难度高。缺乏对“动态整合”与“静态检索”在不同任务复杂度下的性能-延迟-成本权衡的系统性研究，导致分歧未能解决。

### 3.3 其他开放问题

最紧迫的工程问题是多模态记忆整合：解决文本、图像、视频等多源异构信息的统一表示与检索难题。现状是MemVerse在ScienceQA上取得85.2%的成绩，Omni-SimpleMem在Mem-Gallery上取得75.4%的成绩，但跨模态语义对齐和长期一致性维护仍是主要瓶颈。关键困难在于缺乏统一的多模态记忆表示与检索机制，现有方法多依赖模态特定的编码器，难以实现真正的跨模态推理。研究路径包括构建多模态知识图谱和跨模态注意力机制，但计算成本和基准缺失限制了其进展。

最根本的研究问题是记忆的最优性定义：如何在数学上形式化记忆的最优性，为记忆系统设计提供理论指导。现状是Towards a Formal Definition of Agent Memory（P50）提出了记忆的最优性概念，将记忆优化形式化为覆盖问题，但生成算子的假设条件在实际中的近似性仍不明确。关键困难在于记忆的最优性依赖于任务分布和评估指标，缺乏统一的理论框架。研究路径包括结合信息几何和认知科学，建立记忆最优性的多目标优化模型，但理论到工程的映射仍是开放问题。

记忆演化的自主性是另一个关键开放问题：大多数系统依赖启发式规则或人工设计的更新策略，缺乏基于强化学习或元进化机制的自主记忆管理策略。现状是MemEvolve（P9）和Towards Autonomous Memory Agents（P21）提出了元进化框架，但其长期适应性和泛化能力未经充分验证。关键困难在于缺乏有效的奖励信号和长期规划能力，环境反馈信号往往稀疏且延迟。研究路径包括结合强化学习和元学习，设计基于反馈的记忆演化机制，但计算成本和部署复杂性限制了其实际应用。

已知—争议—未知的认知图谱可归纳为：已知外部记忆的必要性、结构化表示的优势、闭环管理的重要性、遗忘的功能性、安全防御的必备性；争议记忆组织形式、遗忘理论基础、记忆与推理关系；未知多模态统一表示、记忆最优性定义、自主记忆管理策略。发展趋势是从工程实现向理论理解转变，从静态存储向动态认知整合转变，从单一模态向多模态整合转变，从被动防御向主动治理转变。

## 4. 总结与展望

AI智能体记忆架构的核心矛盾从“容量不足”演变为“认知混淆”与“安全脆弱性”，这一转变驱动了方法体系的全面重构。早期工作假设记忆是静态的外部数据库，主要关注如何高效地将信息分页到外部存储并检索回来；中期工作引入知识图谱与时间感知机制，解决事实冲突与时效性问题；近期工作则通过生成式潜在记忆和元进化机制实现记忆与推理的交织，同时零信任架构成为安全底线。核心瓶颈在于如何在保持高效检索的同时，实现记忆与推理的深度交织，并建立可验证的安全与隐私保障，使记忆从被动存储工具转变为主动认知参与组件。

未来可能突破的方向包括：多模态记忆整合，MemVerse（P5）和Omni-SimpleMem（P31）共同指向跨模态语义对齐的关键性，构建多模态知识图谱和跨模态注意力机制是潜在路径；自主记忆管理，MemEvolve（P9）和Towards Autonomous Memory Agents（P21）共同指向基于反馈的记忆演化机制的必要性，结合强化学习和元学习设计自主写入/遗忘策略是潜在路径；记忆形式化理论，Towards a Formal Definition of Agent Memory（P50）和The Missing Knowledge Layer（P32）共同指向记忆最优性定义和知识层分离的理论需求，建立记忆最优性的多目标优化模型是潜在路径。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，对代表性方法（如MemCog、GAAMA、SwiftMem、MemGen）进行系统性重评测，控制计算预算和预训练数据规模，以消除现有评测中的混淆因素，为方法比较提供公平基准。
