## 导读

大语言模型（LLM）游戏化推理旨在评估模型在动态、不确定及多智能体环境中的战略决策能力，其核心价值在于暴露静态语言模式匹配与动态博弈所需的不确定性推理之间的结构性鸿沟。早期研究以强化学习系统为基准，确立了完美信息博弈的评估标准，但 LLM 介入后，研究重心迅速转向部分可观测环境下的信念构建与对手建模。当静态基准上的优异表现无法转化为动态对抗中的胜率时，领域从单纯的能力评估转向机制增强，引入自博弈与强化学习以弥合“知道-做”差距。各路线在计算效率、策略最优性与泛化能力之间做出了不同取舍，由此形成当前评测、训练与机制分析并存的多元格局。本综述梳理这条从静态知识到动态战略的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

LLM 游戏化推理的起源并非简单的任务迁移，而是从传统强化学习（Reinforcement Learning, RL）的“状态-动作”映射向“信念-意图-策略”推理范式的根本转变。在 AlphaGo 等系统确立完美信息博弈基准后，LLM 最初仅作为静态策略评估对象，其核心假设是预训练语料中的知识储备可直接映射为博弈策略。然而，随着 ReAct 等框架在 2022 年引入“推理-行动”循环，问题定义从单次决策扩展为序列决策，LLM 开始具备处理部分可观测环境的能力。这一转变揭示了 LLM 在动态博弈中的核心短板：缺乏对状态转移和对手反应的实时建模能力，导致其在静态基准上的高性能无法直接转化为动态对抗中的战略优势。

问题的形式化可概括为在不完全信息博弈（Imperfect Information Game）中，智能体需基于观测 $o_t$ 维护信念状态 $b_t$，并据此选择动作 $a_t$ 以最大化期望效用。$$ \max_{\pi} \mathbb{E}_{\tau \sim \pi} [R(\tau)] \quad \text{s.t.} \quad b_{t+1} = T(b_t, o_t, a_t) $$ 其中 $T$ 为信念更新函数。子问题间存在严格的依赖关系：信念状态构建是对手建模（Opponent Modeling）的基础，而对手建模又是均衡策略求解的前提；记忆与规划增强则依赖于信念状态的准确性以维持长程一致性。这种依赖结构决定了任何单一模块的改进都难以独立提升整体性能，必须协同优化。

范式边界上，LLM 游戏化推理不同于传统 RL，其优势在于语义层面的意图推断与社会认知，劣势在于精确数值计算与随机性模拟。LLM 难以执行真正的混合策略（Mixed Strategy），受限于预训练语料频率偏差和确定性解码倾向，导致在需要随机性的博弈中策略可预测且易被剥削。这一固有缺陷划定了 LLM 在博弈 AI 中的适用边界：它更适合作为具备社会智能的决策者，而非纯粹的数值求解器。

2016-2018 年是奠基期，AlphaGo 与 Libratus 分别确立了完美信息与不完全信息博弈的技术范式，但 LLM 尚未介入。2020-2022 年，ReAct 框架的出现标志着 LLM 开始具备动态交互能力，问题定义从静态问答转向序列决策。2023-2024 年是关键转折期，Werewolf LLM Agents 等研究揭示了 LLM 在不完全信息博弈中的初步心智理论（Theory of Mind, ToM）能力，而 GTBench 等基准则系统暴露了其在复杂博弈中的局限性，推动研究从“能力评估”转向“机制增强”。

2025 年，领域进入精细化阶段。ChessArena 等专用基准通过量化评级系统评估战略推理能力，发现当前模型在动态对抗中表现不佳；MARSHAL 等基于自博弈的 RL 框架解决了多轮多智能体训练中的信用分配问题；MEMO 等记忆增强框架则通过存储结构化洞察解决了长时程交互中的策略漂移。2026 年，研究进一步聚焦于跨游戏泛化与计算效率，Strat-Reasoner 通过轨迹调制自博弈提升推理可迁移性，Solver-Guided Reasoning 则弥合了数值求解与语言推理的鸿沟。

当前形态下，领域已形成评测、训练与机制分析三条主线并存的格局。评测主线致力于构建细粒度过程指标，训练主线探索自博弈与 RL 的有效性，机制分析主线则通过探针与因果模型揭示 LLM 决策中的系统性偏差。这三条主线相互交织，共同推动 LLM 从静态知识储备向动态战略智能的跨越。

**如果用一个核心问题概括该领域，那便是：如何构建一种能够实时整合隐藏信息、动态更新对手信念并维持长程策略一致性的认知架构，以弥合 LLM 静态语言模式匹配能力与动态博弈中所需的不确定性推理及战略适应性之间的鸿沟。**

## 2. 方法体系

- 2016：AlphaGo——奠定该领域方法基线

- 2018：Libratus——推进不完全信息博弈求解

- 2022：ReAct——引入推理-行动循环框架

- 2023：Werewolf LLM Agents——开启 LLM 社会智能评估

- 2024：GRPO——降低 LLM 强化学习计算开销

- 2025：MARSHAL——解决多智能体信用分配问题

- 2025：MEMO——解决长时程策略漂移问题

- 2026：Triadic Werewolf——测试多跳心智理论能力

这条时间线勾勒了该领域方法演进的代表性节点：从 2016 年的 AlphaGo 奠定该领域方法基线，经 2018 年 Libratus 的推进，到 2026 年的 Triadic Werewolf 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 博弈基准评测

博弈基准评测是领域发展的基石，其核心任务是从“能否赢”转向“如何赢”及“为何输”。早期基准如 OpenAI Gym 确立了标准化环境接口，但缺乏对战略推理的细粒度诊断。ChessArena（Liu et al., 2025, P4）针对静态 PGN 补全任务无法反映动态适应性的问题，构建了 LLM 对抗象棋模拟平台，通过 Glicko 评分系统量化模型在不确定环境下的决策水平，放弃了静态知识评估换取动态策略评估的真实性。LUDOBENCH（Jain and Kumar, 2026, P25）进一步将评估粒度细化至单步决策，通过移除游戏轨迹作为混淆变量，专注于测量攻击性或保守性等特定行为倾向，以可控性换取对战略行为的细粒度诊断。BotzoneBench（Li et al., 2026, P22）则解决了现有基准缺乏精确技能校准的问题，通过分级 AI 锚点将相对排名转化为绝对性能评分，以统计显著性换取评估的可复现性。MINDGAMES（Wang et al., 2026, P32）聚焦社会推理，通过区分高效智能体与无限制智能体，评估跨游戏适应能力与欺骗检测能力，以动态交互换取对社会智能的深度评估。这些基准共同推动了评测从静态知识向动态策略、从结果导向向过程导向的转移。

### 2.2 强化学习优化

强化学习（RL）优化路线旨在通过可验证奖励提升 LLM 在动态博弈中的策略适应性。MARSHAL（Yuan et al., 2025, P7）基于 GRPO 算法，解决了多轮多智能体训练中的信用分配与优势估计难题，无需独立 Critic 网络即可从可验证奖励中学习，以计算成本换取策略适应性。Stratagem（Feng et al., 2026, P26）引入推理可迁移性系数，选择性地强化通用推理模式而非游戏特定启发式，将奖励信号从终端结果解耦，以过拟合风险换取跨游戏泛化能力。MEMO（Xie et al., 2026, P23）虽归类于记忆增强，但其核心机制是通过优化推理时上下文而非模型权重，解决多轮博弈中的策略漂移，以实时生成灵活性换取长程稳定性。ISO（Xia et al., 2026, P21）结合离线训练与在线机制，将战略上下文显式建模为潜在变量，解决了传统 RL 在长时程博弈中奖励稀疏的问题，以系统复杂度换取对对手策略变化的适应能力。Strat-Reasoner（He et al., 2026, P29）针对双玩家交替马尔可夫博弈，引入战略推理奖励，鼓励模型在生成动作前进行对手意图预测，以单智能体推理范式换取多智能体策略的联合优化。这些方法共同表明，RL 训练是提升 LLM 动态博弈能力的有效路径，但需解决信用分配与泛化性难题。

### 2.3 理论心智推理

理论心智（ToM）推理路线聚焦于 LLM 在不完全信息博弈中推断对手信念与意图的能力。LLM-Hanabi（Liang et al., 2025, P6）构建了基于花火游戏的 ToM 评测框架，区分一阶与二阶 ToM，发现一阶 ToM 是性能更显著的预测因子，揭示了 LLM 在社会推理中的层级限制。SOM（Cao et al., 2026, P30）提出基于结构因果模型（SCM）的结构化对手建模框架，将对手行为建模为因果图，提高了预测的精确性和适应性，以非结构化模式匹配换取可解释的因果推理。Triadic Werewolf（Mittal, 2026, P34）引入 Jester 角色构建三元狼人杀环境，要求模型区分盟友、敌人及中立角色，揭示了现有模型在利用表面线索获胜时缺乏对深层社会关系建模的能力。Graph-Gated Reasoning（Sun et al., 2026, P27）提出图门控架构，将信念空间规划器产生的候选动作短列表门控给 LLM，解决了提示式信念图对强模型无效的问题，以计算密集型信念更新换取 LLM 的语义理解与选择。Observer, Not Player（Wang and Liu, 2025, P15）通过游戏观察模拟 ToM，发现 LLM 在预测策略性调整时存在滞后，揭示了信念更新机制的局限性。这些方法共同表明，ToM 是提升博弈表现的核心，但 LLM 在动态信念更新上仍存在显著不足。

### 2.4 记忆与规划增强

记忆与规划增强路线旨在解决 LLM 在长时程博弈中的策略漂移与上下文遗忘问题。EpicStar（Wu and Hu, 2026, P37）提出基于情景记忆的 StarCraft II 智能体框架，通过检索成功轨迹并融合工作记忆，解决了 LLM 在 RTS 游戏中的长时程规划问题，以实时生成灵活性换取决策连贯性。Memory-Augmented State Machine Prompting（Qi et al., 2025, P8）将游戏状态映射为有限状态机（FSM）节点，结合记忆模块存储历史状态转换，解决了 LLM 在 RTS 中幻觉和局部贪婪问题，以结构化约束换取决策合法性。Code World Models（Lehrach et al., 2025, P5）提出基于代码世界模型的通用游戏智能体框架，将游戏动态显式编码为可执行代码，使 LLM 能够进行符号化推理和规划，以环境接地换取通用性。Vox Deorum（Chen et al., 2025, P14）提出混合 LLM 架构，将 LLM 专注于宏观战略决策，战术执行委托给算法 AI，平衡了性能、延迟和成本，以纯 LLM 灵活性换取大规模战略游戏的决策效率。WiA-LLM（Sui et al., 2025, P1）提出基于 What-If 分析的 LLM 框架，通过模拟假设动作对状态的影响进行前瞻性规划，将 LLM 从被动模式匹配转变为主动世界建模，以计算成本换取决策可解释性。这些方法共同表明，记忆机制对维持长程游戏状态一致性至关重要，但需平衡检索复杂度与信息时效性。

### 2.5 信息获取策略

信息获取策略路线研究 LLM 在不确定性环境下的主动信息获取能力。Game of Thought（Cui et al., 2026, P20）将 20 个问题游戏形式化为双玩家零和扩展式博弈，通过逼近纳什均衡策略优化最坏情况下的信息增益，以均匀分布假设换取策略鲁棒性。Amortised Bayesian Experimental Design（Hartmann et al., 2026, P35）提出摊销贝叶斯实验设计方法，通过预计算信息增益代理指标降低推理成本，以计算效率换取实时应用可行性。Bayesian Experimental Design for Battleship（Grand et al., 2025, P9）将提问选择建模为最大化期望信息增益的过程，在探索与利用之间权衡，以理性权衡换取搜索效率。Information-Theoretic Analysis of Multi-Turn Games（Pedrozo et al., 2026, P18）定义了 Seeker 效率指标，将提问能力分解为歧义识别、假设评估和信息增益选择三个子能力，以细粒度评估换取对认知瓶颈的深入理解。这些方法共同表明，信息获取是 LLM 在部分可观测环境中决策鲁棒性的关键，但需平衡信息增益与计算效率。

### 2.6 均衡策略求解

均衡策略求解路线探索 LLM 在零和及不完全信息博弈中逼近纳什均衡或 GTO 策略的方法。PokerSkill（Li et al., 2026, P33）提出无需训练或求解器的 LLM 扑克专家系统，通过上下文引擎与决策绑定机制解决状态读取与概念应用脱节问题，以额外训练换取部署门槛降低。Solver-Guided Reasoning（Wang et al., 2026, P36）提出求解器引导的混合策略推理框架，通过对比规则将求解器的数值策略转化为可通信的自然语言规则，弥合了数值求解与语言推理的鸿沟，以外部求解器依赖换取策略最优性与可解释性。Entropy-Guided In-Context Learning（Banfi and Gamage, 2026, P17）利用熵值衡量不确定性，动态调整上下文学习示例的选择，以固定提示策略换取推理过程动态优化。Open-Source Games Evaluation（Sistla and Kleiman-Weiner, 2025, P12）通过分析程序均衡量化 LLM 的战略能力，揭示了 LLM 在不同激励结构下的策略演化，以单次对局收益换取长期策略稳定性评估。Equilibrium Residuals Analysis（Nie et al., 2026, P31）通过生成分布外矩阵博弈计算均衡残差，揭示了 LLM 依赖记忆而非通用推理的局限性，以已知游戏表现换取对通用战略推理能力的严格测试。这些方法共同表明，LLM 在需要精确随机性或混合策略的博弈中表现不佳，需结合求解器或结构化提示以提升策略最优性。

### 2.7 行为偏差分析

行为偏差分析路线旨在揭示 LLM 决策机制中的系统性偏差。RPS Stochastic Bias Analysis（2025, P39）分析了 LLM 在石头剪刀布游戏中随机性模拟失败，发现其决策受预训练语料频率偏差影响，揭示了 LLM 在模拟随机策略时的系统性偏差。Level-k Distinguishable Mechanisms（Zhang and Sarkar, 2026, P38）设计了可区分 Level-k 推理深度的博弈机制，量化了 LLM 的有限理性程度，揭示了其在迭代推理中的认知层级限制。Payoff and Language Impact Analysis（Huynh et al., 2026, P19）解耦收益结构与语言表述，量化两者对 LLM 策略的独立与交互影响，揭示了语言框架效应在博弈决策中的作用。Broken Links Analysis（Sobotka et al., 2026, P28）通过机制可解释性探针检测 LLM 内部表示中是否包含准确信念，发现即使内部表示包含正确信念，其行动仍可能偏离理性，揭示了信念到行动转换的断裂。这些方法共同表明，LLM 在博弈中表现出的认知-行为差距、随机性模拟失败及框架效应，是其决策机制中的系统性偏差，需通过机制可解释性技术深入诊断。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLM 在静态基准上的高性能不能直接转化为动态博弈中的战略优势，这一共识在多个基准上被反复验证。ChessArena 中 LLM 在动态对抗中表现不佳，而 LLM CHESS 中 LLM 在低难度设置下尚未超越随机策略，均表明静态知识储备与动态战略决策之间存在结构性鸿沟。与此相关的另一个共识是，思维链（CoT）和推理增强技术能显著提升 LLM 在博弈中的表现，但无法完全解决长程规划和多步逻辑的局限性。LLM-Hanabi 中 Deepseek-R1 的 30.00 得分虽大幅超越 GPT-4.1 的 28.56，但一阶 ToM 仍是性能更显著的预测因子，揭示了 LLM 在社会推理中的层级限制。

多智能体交互和不完全信息是测试 LLM 高级认知能力的关键场景，比单智能体任务更具挑战性。MINDGAMES 中 Training-time Adaptation 的 0.68 胜率虽领先，但 Inference-time Structure 的 0.65 胜率仍显著低于历史基线 SPIRAL 的 0.52，表明 LLM 在复杂社会推理中仍存在显著不足。自博弈和基于可验证奖励的强化学习是提升 LLM 战略推理能力的有效训练范式，优于单纯的监督微调。MARSHAL 等研究表明 RL 在数学和问答基准上展现了零样本泛化能力，但 Equilibrium Residuals 分析显示 LLM 在 OOD 博弈中仍依赖记忆，暗示 RL 可能仅优化了特定分布内的策略。

### 3.2 观点分歧

LLM 的战略推理是基于“语义模式匹配”还是“真正的因果信念更新”？现有证据偏向语义模式匹配：Equilibrium Residuals 分析显示 LLM 在 OOD 博弈中性能显著下降，表明其依赖记忆而非通用推理；RPS Bias Analysis 揭示 LLM 随机性模拟失败源于语料频率偏差。但 Strat-Reasoner 等 RL 方法在特定游戏上提升了泛化能力，暗示 RL 可能部分解决了这一问题。这一分歧的背后，是另一个更根本的争论：RL 训练是“学习新策略”还是“强化旧模式”？Broken Links Analysis 发现即使 LLM 内部表示包含正确信念，其行动仍可能偏离理性，表明信念到行动的转换存在断裂；Equilibrium Residuals 分析显示 LLM 在 OOD 博弈中表现不佳。但 MARSHAL 等研究表明 RL 在数学和问答基准上展现了零样本泛化能力，暗示 RL 可能提升了通用推理能力。

### 3.3 其他开放问题

最紧迫的工程问题是计算效率与推理深度的矛盾。深度战略推理需要大量 Token 消耗和计算资源，限制了实时游戏（如 RTS）中的应用。Vox Deorum 等混合架构通过分工平衡了性能、延迟和成本，但尚未解决根本矛盾。最根本的研究问题是 LLM 如何真正更新信念状态。SOM 等结构化因果模型提供了可解释的因果推理，但动态信念更新机制仍不成熟。研究路径包括结合因果建模与信念更新机制，提高在隐藏信息环境下的推理准确性和鲁棒性。

已知—争议—未知认知图谱显示，领域在静态知识评估上已达成共识，在动态战略推理机制上存在争议，在跨游戏泛化与实时决策效率上仍属未知。未来趋势将向更复杂的多智能体环境、更高效的推理架构及更深层的认知机制理解发展。

## 4. 总结与展望

LLM 游戏化推理领域的核心矛盾在于静态语言模式匹配能力与动态博弈中所需的不确定性推理及战略适应性之间的鸿沟。从提示工程到记忆增强再到强化学习，各路线互补而非替代，共同推动 LLM 从静态知识储备向动态战略智能的跨越。核心瓶颈在于信念更新机制的不成熟与计算效率的制约，导致 LLM 在长程规划与多智能体交互中仍存在显著不足。

未来可能突破的方向包括：结合结构化因果模型（SCM）与 LLM 进行对手建模，提升动态信念更新的准确性与可解释性（SOM, P30）；开发基于过程奖励的 RL 算法以解决信用分配难题，提升跨游戏泛化能力（Stratagem, P26）；探索 LLM 与专用求解器的混合推理范式，弥合数值求解与语言推理的鸿沟（Solver-Guided Reasoning, P36）。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，构建能够区分“模式匹配”与“因果推理”的细粒度过程指标，以揭示 LLM 战略推理的真实机制。
