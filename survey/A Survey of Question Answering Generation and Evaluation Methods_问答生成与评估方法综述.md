综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Question%20Answering%20Generation%20and%20Evaluation)

## 导读

问答生成与评估（Question Answering Generation and Evaluation）旨在解决大语言模型（LLM）训练数据稀缺与事实幻觉之间的矛盾，其核心价值在于构建可信、可控的知识交互闭环。早期研究聚焦于序列到序列模型的生成准确性，但难以捕捉语义多样性与难度控制，导致模型泛化能力受限。随着检索增强生成（RAG）的兴起，领域重心转向利用外部知识缓解幻觉，评估重点从表面相似度转向多跳推理与证据链完整性。当 LLM 的涌现能力使合成数据成为主流后，研究焦点进一步演化为数据生成的可控性与评估的细粒度化，以应对长尾查询与模糊语境下的泛化瓶颈。各路线在数据质量、检索鲁棒性与评估客观性之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从静态生成到动态认知校准的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

问答生成与评估领域的起源源于对教育效率提升及 LLM 训练数据稀缺性的迫切需求。早期研究主要依赖规则模板或简单的序列到序列模型，核心任务是通过自动生成问答对来扩充训练集，并评估其语义准确性。然而，这种范式假设“更多数据即更好”，受限于算力与标注成本，难以捕捉问题的语义多样性与难度控制，导致生成的数据分布狭窄，模型在知识密集任务中表现不佳。随着 LLM 规模的扩大，幻觉问题日益凸显，单纯增加训练数据已无法解决事实一致性问题，领域重心因此发生转移。

问题的形式化定义随之演化。传统的问答任务可形式化为给定上下文 $C$ 和问题 $Q$，生成答案 $A$，即 $A = f(C, Q)$。在合成数据场景下，任务逆转为给定答案 $A$ 或知识点 $K$，生成问题 $Q$ 和上下文 $C$，即 $Q, C = g(A, K)$。这一逆向过程的核心挑战在于保持事实一致性的同时实现语义多样性。随着 RAG 的引入，问题定义扩展为如何利用外部知识库 $D$ 缓解幻觉，即 $A = f(C, Q, D)$，其中 $D$ 通过检索模块 $\mathcal{R}(Q, D)$ 获取。评估重点也从 BLEU 等语言学指标转向多跳推理与证据链完整性，HotpotQA 等基准成为标准测试床。

子问题之间存在严格的依赖关系。数据合成质量决定模型上限，是基础层；RAG 与检索优化提供事实依据，是支撑层；对话机制与歧义消解处理动态交互，是交互层；评估体系贯穿始终，验证上述各层的有效性，是验证层。若不解决数据同质性这一基础问题，后续的复杂推理与评估将失去意义。例如，合成数据的难度分布直接影响模型在 GSM8K 等数学推理任务上的表现，而检索器的长尾鲁棒性则决定了 RAG 系统在低频实体查询中的可靠性。

范式边界在 2020-2022 年间逐渐清晰。RAG 确立了“检索+生成”的主流架构，显著减少了幻觉，但引入了对检索质量的依赖。2023-2024 年是关键转折期，LLM 的涌现能力使得“合成数据”成为主流范式，研究焦点从单纯的问答准确率转向数据生成的可控性（如难度、多样性）与评估的细粒度化（如归因、证据溯源）。此时，问题已转变为如何在保证事实一致性与证据可溯源的前提下，实现问答数据生成的可控性与评估的细粒度化。

约束演化史揭示了方法如何因应约束变化而演变。2019 年，SkillQG 通过模型中间输出表征难度，解决了早期方法难以迁移至 LLM 的问题，为难度可控问题生成提供了新的表征范式。2020 年，RAG 通过结合外部知识库检索与生成，奠定了后续归因与多跳推理研究的基础。2021 年，HotpotQA 提供句子级支持事实标注，成为研究检索错误传播与证据归因的标准测试床。2022 年，归因问答（AQA）提出在生成答案中嵌入引用，推动了从单纯事实正确性向证据溯源的范式转变。

2023 年，ALCE 基准建立，强调引用粒度与未知信息意识，弥补了早期工作忽视引用质量的缺陷。2024 年，BoostQA 设计多等级合成策略，解决了合成数据同质化与规模受限问题；AirQA 构建多模态评估数据集，推动了评估从模糊匹配向精确事实核查的转变。2025-2026 年，HybridRAG、ProvenAI、PassiveQA 等出现，应对复杂文档、黑盒溯源及认知校准需求，标志着领域进入“高质量合成与鲁棒评估”阶段。当前形态下，核心驱动力在于解决 LLM 在长尾查询、模糊语境及多模态文档中的泛化瓶颈，旨在实现从“能回答”到“可信、可解释、可控制”的范式跃迁。

**如果用一个核心问题概括该领域，那便是：如何在保证事实一致性与证据可溯源的前提下，实现问答数据生成的可控性（难度/多样性）与评估的细粒度化，以突破 LLM 在长尾及模糊语境下的泛化瓶颈。**

## 2. 方法体系

- 2019：SkillQG——利用技能特定知识对齐问题与理解技能，奠定难度可控生成基线

- 2020：RAG——结合外部知识库检索与生成，确立事实增强主流架构

- 2021：HotpotQA——提供句子级支持事实标注，成为多跳推理评估标准

- 2022：Attributed QA——提出答案嵌入引用，推动证据溯源范式转变

- 2024：BoostQA——设计多等级合成策略，解决合成数据同质化问题

- 2025：HybridRAG——基于预生成 QA 对处理非结构化文档，提升复杂文档处理效率

- 2026：ProvenAI——提出原生溯源证据追踪，解决 RAG 黑盒问题

- 2026：DiFRa——统一框架调和语义多样性与事实一致性，代表当前合成前沿

这条时间线勾勒了该领域方法演进的代表性节点：从 2019 年的 SkillQG 奠定该领域方法基线，经 2020 年 RAG 的推进，到 2026 年的 ProvenAI 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 问答数据合成

问答数据合成的核心目标是解决训练数据稀缺与同质性问题。早期方法如 SkillQG 通过模型中间输出表征难度，但难以迁移至 LLM。CrossQG（P17）针对难度可控问题生成（DCQG）任务，提出通过一致性增强机制改进难度表征。该方法利用模型生成的知识或答案计划来表征问题难度，解决了早期方法直接嵌入难度级别难以迁移至 LLM 的问题。其核心模块包括对比增强（CE）与交叉过滤（CF），通过引入负样本增强模型对难度边界的感知。CE 机制利用生成的负例进行对比学习，而 CF 机制则过滤掉难度与目标级别匹配但逻辑错误的样本。这种设计使得模型能够更准确地区分不同难度层级的语义特征，从而生成符合特定难度要求的问题。该方法在 SQuAD、RACE 等数据集上验证了其在提升难度相关性（ρ）和准确率（acc）方面的有效性。其技术定位在于为教育场景下的自适应学习提供了可解释且可控的问题生成工具，弥补了 LLM 在细粒度难度控制上的不足。

DiFRa（P20）提出一个统一框架以调和问答生成中的语义多样性与事实一致性。该方法将模型训练视为求解欠定系统，生成的 QA 对作为约束条件。核心组件包括概念构建与扩散（CCD）、事实约束构建（FCC）以及多样性与一致性感知机制（DCAM）。CCD 通过提取上下文中的主题词与关键短语构建概念集，并在潜在空间执行扩散过程以引入线性独立约束。FCC 则确保生成的答案严格基于上下文事实，防止幻觉。DCAM 机制在生成过程中动态平衡多样性与一致性，避免模型陷入局部最优。该方法放弃了简单的序列到序列生成，转而采用扩散模型在离散文本潜在空间的操作，增加了计算复杂度但提升了数据质量。其影响在于为大规模合成数据生成提供了理论支撑，证明了多样性与一致性并非互斥，而是可以通过结构化约束共同优化。

BoostQA（P12）设计了一种用于中期训练的大规模多样化 QA 数据合成框架。针对现有合成数据同质化且规模有限的问题，引入多等级合成策略，模拟教育中的多角色教师。该方法首先通过模型探针识别中期训练中的数据盲区，然后利用虚拟教师角色将种子数据重新解释为多个不同的 QA 样本。每个虚拟角色专注于不同的知识维度或推理深度，从而扩展了数据的多样性。随后实施 STEM 聚焦的高难度合成，以缓解难度退化问题，并通过答案精炼步骤进一步提升数据质量。该框架在 Llama-3 8B 模型上验证了其在 MMLU 等基准上的显著提升。其技术定位在于解决 LLM 中期训练阶段的数据瓶颈，通过结构化合成策略实现了数据规模与多样性的双重突破，为后续大规模预训练数据增强提供了范式。

LinkQA（P19）提出基于知识点（KP）强链接的多样化 QA 合成方法。该方法构建 KP 图以捕获 QA 实例间的逻辑关联，利用 KP 共现提供比文档更紧密的逻辑连接。核心算法 LinkSyn 通过 KP 路径采样与种子实例选择，确保合成数据在结构对齐与长尾探索之间的平衡。实例选择过程优先选择难度与目标难度最接近且学科匹配的支撑实例，以维持分布一致性。该方法引入了结构对齐损失与长尾探索损失的加权组合，通过调整混合参数控制生成数据的分布特性。其代价是依赖高质量的 KP 标注与图构建，且路径采样过程可能引入计算开销。LinkQA 在多个学科领域验证了其生成数据的多样性与逻辑连贯性，为跨学科知识密集型任务的训练数据合成提供了新的结构化视角，解决了传统基于文档合成缺乏逻辑关联的问题。

### 2.2 检索增强生成

检索增强生成（RAG）旨在通过结合外部知识库提升答案的事实准确性与可解释性。HybridRAG（P5）提出基于预生成 QA 对的实用 LLM 聊天机器人框架，专门处理原始非结构化文档。该方法通过 OCR 与布局分析将包含复杂布局（文本、表格、图表）的 PDF 转化为层级文本块，然后预生成合理的 QA 知识库。与实时检索不同，HybridRAG 在查询时直接检索预生成的 QA 对，从而减少幻觉并提高响应速度。核心创新在于将文档理解与 QA 生成解耦，利用思维链提示生成反映真实用户查询的 QA 对。该框架正交于现有的文档解析方法，可结合视觉语言模型进一步提升 QA 对质量。其代价是预生成过程需要大量计算资源，且可能引入生成偏差。HybridRAG 解决了实时 RAG 在复杂文档上的效率与准确性瓶颈，为部署在真实世界场景中的聊天机器人提供了更稳定、快速的解决方案，特别适用于法律、医疗等文档密集型领域。

ProvenAI（P7）提出原生溯源证据追踪机制，旨在解决 RAG 中未引用文档仍影响生成的黑盒问题。该方法通过解析生成输出中的内联引用标签（如 [R0], [R1]），将声明链接到检索资源，并保留原始模型输出与解析结果。核心组件包括检索语料库去重、文档嵌入索引以及生成提示中的证据摘要与推理链要求。ProvenAI 利用 HotpotQA 基准验证了证据传播的可解释性，通过本地 MCP 服务器暴露工具以支持检查仪表板。该方法放弃了传统的后处理引用生成，转而要求模型在生成过程中显式标记证据来源，从而增强了多跳问答中证据链的透明度。其代价是增加了生成提示的复杂度，可能影响模型的流畅性。ProvenAI 为构建可信赖的 RAG 系统提供了新的评估维度，推动了从单纯事实正确性向证据溯源与推理过程可解释性的转变。

Self-KFC（P15）提出结合监督微调与对齐方法的自进化引用生成框架，旨在提升归因问答（AQA）的引用准确性。该方法指出传统 SFT 仅教授输出格式，而 DPO 等对齐方法训练耗时且首次尝试引用标注错误率高。Self-KFC 通过自进化机制，允许模型在训练过程中迭代优化引用标注，结合 SFT 的基础格式学习与对齐方法的偏好优化。核心创新在于引入知识感知引用（KFC）数据集，强调引用粒度与未知信息意识。实验在 LLaMA3、Qwen2.5 等骨干模型上验证了其在引用生成任务上的优越性。该方法的代价是训练过程较为复杂，需要精心设计的自进化循环。Self-KFC 为开发可解释的 LLM 系统提供了有效路径，解决了 AQA 中引用稀疏与错误问题，推动了 RAG 系统从黑盒生成向白盒溯源的演进。

RPDR（P13）提出基于往返预测的数据增强框架，旨在提升长尾问答中密集检索器的性能。该方法针对长尾实体查询导致的用户信心下降与数据负反馈循环问题，生成包含长尾实体的合成样本以训练密集检索器。核心机制是训练一个逆模型，从嵌入中重建原始文本，确保合成样本的嵌入可被可靠恢复。RPDR 假设易学习数据产生可恢复的嵌入，通过最大化嵌入与重建文本的余弦相似度来优化逆模型。该方法还引入了路由机制，结合多个检索器的优势以进一步提升端到端性能。其代价是逆模型训练需要额外的计算资源，且合成数据的质量高度依赖逆模型的准确性。RPDR 为 RAG 系统在长尾场景下的鲁棒性提供了新视角，解决了传统检索器在罕见实体上表现不佳的问题，促进了检索增强生成在真实世界长尾查询中的应用。

### 2.3 对话式问答机制

对话式问答机制聚焦于多轮对话场景下的查询重写、歧义消解及上下文理解。AdaRewriter（P14）提出基于测试时适应的提示式对话查询重写框架，旨在解锁 LLM 在对话搜索中的潜力。该方法通过训练轻量级奖励模型，利用对比排序损失选择最有可能的重写候选，解决了黑盒 LLM 系统中重写质量评估困难的问题。核心机制是在推理阶段动态适应，无需修改 LLM 参数，适用于商业 API 等封闭系统。奖励模型通过对比正负样本学习区分高质量与低质量重写，从而在多个候选中选出最佳。实验在五个对话搜索数据集上验证了其显著优于最佳 N 选 1、自一致性等基线方法。该方法的代价是引入了额外的推理时计算开销，用于生成多个候选并计算奖励分数。AdaRewriter 为对话搜索系统提供了一种高效且通用的意图推导增强方案，提升了系统在动态交互中处理指代与省略的能力，促进了 LLM 在实时搜索场景中的落地应用。

ChatR1（P11）提出利用强化学习优化对话推理与检索增强问答的框架，解决多轮对话中奖励稀疏问题。该方法基于 PPO 算法，引入过程奖励以提供中间决策（如上下文解释、查询制定）的反馈，而非仅依赖最终答案的正确性。核心组件包括意图与答案双分量奖励函数，以及基于 GAE 的批评家网络训练。ChatR1 在多个对话 QA 数据集上微调 Qwen2.5 模型，验证了其在跨领域泛化上的优势。与监督微调相比，强化学习能够更好地捕捉对话中的动态依赖关系，提升模型在复杂信息需求下的推理能力。该方法的代价是训练过程不稳定，需要精心设计的奖励函数与超参数调节。ChatR1 为对话式 AI 助手提供了更鲁棒的推理机制，推动了从静态问答向动态交互式推理的演进，特别是在需要多步工具使用与查询分解的场景中表现突出。

CFDA & CLIP（P1）提出增强个性化对话搜索的查询重写与排名融合方法，针对 TREC iKAT 2025 任务。该方法结合对话历史增强与查询重写策略，通过 LLM 进行消歧、响应扩展与主题切换检测，以减少歧义与噪声。核心创新在于融合提示式重写（CHIQ-AD）与微调模型重写（CHIQ-FT）的结果，利用结果级融合整合两种方法的优点。CHIQ-AD 利用增强历史生成重写查询，减少冗余；CHIQ-FT 通过微调 T5-base 模型提高效率，但受限于上下文窗口。融合策略旨在平衡鲁棒性与效率，提升在实时交互设置中的性能。该方法解决了传统对话检索系统难以捕捉动态用户意图的问题，特别是在长对话依赖与个性化知识库检索场景中。CFDA & CLIP 为构建实时、自适应的对话搜索系统提供了实用框架，促进了对话检索从离线评估向在线交互的过渡。

Disambiguation in CQA（P16）综述了 LLM 与代理时代对话式问答中的歧义消解机制，系统梳理了查询重写与长形式答案生成技术。该综述指出，自然语言固有的歧义性是人类-AI 交互的核心挑战，特别是在现代 AI 助手如 Adobe AEP 与 Amazon Rufus 中。查询重写技术从早期的查询扩展演变为基于神经网络的上下文重述与同义词增强，近期工作进一步探索显式推理模式。长形式答案生成则涉及呈现所有有效解释及其对应答案，通常包括消歧、回答各解释及整合步骤。综述强调了 LLM 在管理模糊语言中的关键作用，以及代理框架在动态交互中的潜力。该综述为研究者提供了全面的技术地图，指出了当前方法在平衡准确性与简洁性方面的不足。它推动了对话 QA 研究从单一答案生成向多解释呈现与用户意图对齐的转变，为开发更智能的对话系统奠定了理论基础。

### 2.4 基准与评估体系

基准与评估体系旨在全面衡量模型在事实性、归因及复杂推理上的能力。AirQA（P2）构建了一个面向 AI 研究的综合 QA 数据集，强调实例级评估与事实正确性。针对现有 QA 数据集依赖语言学指标而忽视事实准确性的问题，AirQA 设计了基于功能实例的评估体系。该方法通过输出重格式化，引导 LLM 输出特定的评分点（如数值、列表），从而简化评估过程并提高客观性。数据集涵盖多种问题类型与多模态元素，包括文本、图表等，模拟真实科研场景中的信息检索需求。评估框架不再依赖语义连贯性，而是直接判断答案中关键信息的正确性，例如在定量比较中仅关注数值本身。这种设计使得评估更加自动化且可复现，减少了 LLM 评估中的主观偏差。AirQA 为评估 LLM 在专业领域中的精确检索与推理能力提供了新基准，推动了 QA 评估从模糊匹配向精确事实核查的转变。

SimpleDevQA（P18）提出软件开发领域的 Dev Knowledge QA 基准，旨在评估 LLM 在代码理解与开发知识上的表现。该基准从 WildChat 数据集中提取开发相关对话，并通过分层抽样与人工验证构建包含 5,529 个 QA 对的数据集。数据集分为困难与简单两类，以区分模型在不同复杂度任务上的能力。评估涵盖 21 个主流 LLM，包括闭源与开源模型，以及代码专用模型。研究发现，代码专用 LLM 在相同参数规模下显著优于通用 LLM，且闭源模型在复杂开发知识问答上表现更佳。该基准揭示了当前 LLM 在软件工程专业知识注入上的不足，特别是开源模型在特定领域知识上的差距。SimpleDevQA 为评估 LLM 在垂直领域（如软件工程）的实用能力提供了标准化测试环境，促进了领域特定模型的开发与优化。

LakeQuest（P8）构建了一个跨数据湖的接地问答基准，专门评估模型在异质、弱结构化数据源上的推理能力。该基准涵盖零售银行、科学数据等多个领域，要求模型导航孤岛式数据源，结合跨模态证据并保持显式溯源。每个实例包含问题、金标准证据（来自策略、表格、元数据等）及参考答案，强调证据的组合与归因。与现有基准不同，LakeQuest 引入了弱元数据与干扰文档，以测试检索的鲁棒性。评估框架隔离了源发现与跨模态合成两个阶段，允许细粒度分析模型在不同子任务上的表现。该基准解决了现有 QA 评估缺乏对复杂企业数据环境模拟的问题，推动了 RAG 系统在真实世界异构数据上的应用研究。其设计强调了证据追踪的重要性，为开发可解释的企业级 QA 系统提供了评估标准。

CondAmbigQA（P9）提出条件模糊问答基准与数据集，旨在评估 LLM 在处理隐含假设与歧义查询时的能力。该基准认为识别并解决隐含假设是消歧的关键，确保生成响应准确且符合用户预期。数据集包含多种模糊上下文，要求模型生成显式条件以澄清问题意图。评估指标包括条件生成能力与基于真值条件的回答准确性。实验对比了 GPT-4o、GLM4-plus 等专有模型与 LLaMA3.1、Mistral 等开源模型，发现专有模型在条件识别上显著优于本地部署模型。该基准揭示了当前 LLM 在歧义处理上的局限性，特别是开源模型在复杂语境理解上的不足。CondAmbigQA 为研究对话系统中的歧义消解与用户意图对齐提供了新视角，推动了从单纯事实问答向语境敏感问答的评估范式转变。

### 2.5 模型训练与优化

模型训练与优化聚焦于通过微调、去偏及架构改进提升模型在上下文理解、答案提取及鲁棒性方面的性能。PassiveQA（P6）提出三动作框架以实现认知校准的问答，通过监督微调让模型判断信息充分性。该方法针对 RAG 系统假设所有查询可回答的缺陷，引入“回答”、“澄清”与“拒绝”三个动作，使模型在信息不足时主动寻求澄清或拒绝回答。核心组件是基于 Mistral-7B 的规划器，通过 LoRA 微调以解析 XML 标记的结构化输入并推理图三元组。训练数据包含结构化推理步骤，要求模型输出正确的 XML 标签顺序与聚焦的澄清问题。该方法放弃了传统的单一答案生成目标，转而优化认知校准能力，提升了系统在模糊或信息缺失场景下的鲁棒性。其代价是增加了输出格式的复杂度，且需要高质量的结构化训练数据。PassiveQA 为开发更安全的 LLM 系统提供了新范式，解决了过度自信回答导致的错误风险，推动了 QA 系统从被动响应向主动认知管理的转变。

TPCL（P10）提出定制渐进课程学习框架，旨在增强归因问答（AQA）模型的不同能力。该方法指出统一 SFT 难以满足不同能力（如证据提取、上下文生成）的差异化学习动态。核心组件包括三个定制训练计划（PM1-3），分别针对证据预测、干扰源冻结与完整 AQA 任务。TPCL 通过计算实例复杂度分数，将训练集划分为多个部分，按复杂度顺序进行渐进学习。对于编码器-解码器模型，采用渐进课程学习；对于解码器-only 模型，采用一次性课程学习。该方法放弃了随机采样训练，转而采用结构化课程，以提升模型在复杂归因任务上的表现。其代价是课程构建过程需要额外的复杂度计算与数据排序开销。TPCL 为 AQA 模型训练提供了精细化策略，解决了单一训练目标导致的性能瓶颈，推动了归因问答从端到端黑盒训练向模块化能力增强的演进。

ErrEval（P3）提出通过显式诊断进行错误感知的问题生成评估框架，旨在提升 QG 评估的可靠性。该方法指出传统评估方法依赖整体评分，缺乏对底层错误信号的建模，导致评估高估。核心组件包括错误标识器（EI）与验证器，EI 预测生成问题中的错误类型，验证器评估并过滤 EI 的预测。训练阶段采用迭代精炼机制，通过模型在环扩展增加数据多样性与真实性。推理阶段，EI 识别潜在错误类型，并将其作为诊断信息整合到 LLM 评估器中，实现维度特定评分。该方法放弃了单一的相似度或生成式评分，转而采用错误驱动的细粒度评估。其代价是训练过程较为复杂，需要构建错误标注数据。ErrEval 为 QG 系统部署提供了更可靠的评估工具，解决了传统指标在复杂语境下失效的问题，推动了 QA 评估从表面相似度向深层错误诊断的转变。

Multi-domain Debiasing（P4）提出多领域去偏框架，旨在提升 QA 模型在对抗场景下的鲁棒性。该方法针对 QA 模型从训练数据继承的偏差（如词汇偏差、数值推理偏差）问题，结合知识蒸馏、去偏技术与领域扩展。核心组件包括在 SQuAD v1.1 与对抗数据集（AddSent, AddOneSent）上评估 ELECTRA-small 模型，识别特定错误类型。通过知识蒸馏将大模型的去偏能力迁移至小模型，并利用领域扩展增强模型在噪声与模糊上下文中的表现。该方法放弃了单一数据集训练，转而采用多领域联合优化，以提升模型泛化能力。其代价是训练过程需要多个数据集与蒸馏步骤，增加了计算复杂度。该框架为构建更可靠的 QA 系统提供了新视角，解决了模型在真实世界噪声数据中表现不佳的问题，推动了 QA 模型从静态基准测试向动态对抗鲁棒性的演进。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域在 RAG 是缓解 LLM 幻觉和提升事实一致性的最有效手段上达成共识，但单纯增加检索数量并不总能提升性能，关键在于证据的相关性与归因的准确性（支撑证据：P5、P7、P13、P15）。这一共识在多个基准上被反复验证：HybridRAG 通过预生成 QA 对显著降低了复杂文档上的幻觉，ProvenAI 通过原生溯源提升了证据链的透明度。与此相关的另一个共识是合成数据已成为解决高质量 QA 训练数据稀缺的核心途径，但其质量（多样性、难度分布）直接决定下游模型的性能上限，需通过严格的质量过滤和难度控制来保证（支撑证据：P12、P17、P19、P20）。BoostQA 与 DiFRa 的实验均表明，结构化约束合成策略能显著提升模型在 MMLU 等基准上的表现。

传统的基于相似度的评估指标（如 BLEU）已无法有效衡量生成问答的质量，领域正转向基于 LLM 的评估、实例级评分点或细粒度的错误诊断方法（支撑证据：P2、P3、P9）。AirQA 的实例级评分与 ErrEval 的错误诊断均证明了细粒度评估在捕捉事实错误方面的优势。多跳推理和长文档理解是评估 LLM 综合能力的关键场景，现有基准在异构数据源和跨模态证据整合方面仍存在显著空白（支撑证据：P8、P18）。LakeQuest 与 SimpleDevQA 的构建正是为了填补这一空白，推动评估从通用场景向垂直领域与复杂数据环境延伸。

### 3.2 观点分歧

评估客观性方面存在分歧：LLM-as-a-Judge 更通用、成本低，适合大规模快速评估，而实例级评分点（AirQA）或错误诊断（ErrEval）更客观、可复现，能捕捉细粒度事实错误。现有证据偏向后者，AirQA 实验显示实例级评分显著减少主观偏差，ErrEval 证明错误诊断能更准确识别生成问题。但前者在缺乏细粒度标注的场景下仍具优势。分歧根源在于缺乏统一的“客观性”度量标准，实例级评分依赖高质量标注，而 LLM 评估依赖模型能力，二者适用场景不同，尚无实验能完全定输赢。

难度控制机制方面存在分歧：基于规则或简单嵌入的难度表示更透明、可解释，而基于模型生成知识/答案计划的隐式难度表示更适应 LLM，迁移性更强。现有证据偏向后者，CrossQG 在 SQuAD/RACE 上验证了隐式表示在难度相关性（ρ）上的优势，DiFRa 证明结构化约束能更好平衡多样性与一致性。但前者在教育场景中仍具解释力。分歧根源在于缺乏统一且可迁移的难度度量标准，不同数据集对难度的定义不同，导致跨领域比较困难。

### 3.3 其他开放问题

最紧迫的工程问题是多模态与跨域适应性。现状是 QA 系统在多模态输入和跨领域中的泛化能力不足，关键困难在于不同模态和领域的知识表示差异大，需要统一的语义空间映射。研究路径包括多模态融合架构和领域自适应微调。最根本的研究问题是模糊性与不确定性处理。现状是 QA 系统对模糊查询和不确定信息的处理能力不足，关键困难在于如何准确检测模糊性并生成有效的澄清问题或条件推理。研究路径包括基于 LLM 的模糊性检测、条件识别框架和交互式澄清策略。

已知—争议—未知认知图谱显示，领域在 RAG 必要性与合成数据价值上已知，在评估客观性与难度控制机制上争议，在多模态溯源与实时动态管理上未知。发展趋势将从追求准确率转向追求可信度与可控性，核心在于通过可控合成、鲁棒检索与细粒度评估，实现 LLM 在复杂真实场景中的可信、可解释与可控制。

## 4. 总结与展望

问答生成与评估领域已完成从“数据规模”到“数据质量与信任”的范式跃迁。早期研究聚焦于解决数据稀缺问题，通过规则或 Seq2Seq 模型生成问答对，但难以捕捉语义多样性与难度控制。随着 RAG 的兴起，领域重心转向利用外部知识缓解幻觉，评估重点从表面相似度转向多跳推理与证据链完整性。当前，核心矛盾已从“数据不足”转变为“数据质量与信任缺失”，核心瓶颈在于如何在保证事实一致性与证据可溯源的前提下，实现问答数据生成的可控性（难度/多样性）与评估的细粒度化，以突破 LLM 在长尾及模糊语境下的泛化瓶颈。

未来可能突破的方向包括多模态与跨域适应性、实时学习与动态历史管理、模糊性与不确定性处理。这些方向需 ≥2 篇论文共同指向，如 LakeQuest（P8）与 SimpleDevQA（P18）共同指向垂直领域与多模态评估，PassiveQA（P6）与 ChatR1（P11）共同指向动态交互与认知校准。对进入者最值得做的一件事是构建统一的跨模态语义空间映射框架，以解决多模态输入与跨领域知识表示差异大的问题，从而提升 QA 系统在复杂真实场景中的泛化能力与可信度。
