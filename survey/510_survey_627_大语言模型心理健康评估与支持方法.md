# A Survey of LLMs for Mental Health Assessment and Support ｜大语言模型心理健康评估与支持方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/LLMs%20for%20Mental%20Health%20Assessment%20and%20Support)

## 导读

大语言模型（Large Language Models, LLMs）在心理健康领域的应用，源于缓解全球精神卫生资源短缺与提升服务可及性的迫切需求。早期研究依赖传统自然语言处理技术进行静态文本分类，缺乏临床深度与动态交互能力，难以捕捉治疗联盟的建立过程。随着 LLMs 的引入，领域范式从静态筛查转向动态对话式支持，模型展现出类人共情与上下文理解能力，但随之暴露出幻觉、伦理边界模糊及高风险场景失效等新问题。2024 至 2025 年间，研究重心从能力展示转向安全审计与临床验证，VERA-MH、CounselBench 等基准的提出标志着评估体系向多轮动态交互演进。当前，领域进入精细化阶段，聚焦于多模态融合、强化学习对齐及隐私保护下的端侧部署，旨在构建可信临床辅助系统。各路线在临床准确性、安全性与隐私保护之间做出了不同取舍，由此形成当前多元并存的方法格局。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

大语言模型在心理健康评估与支持领域的兴起，根植于全球精神卫生负担加剧与专业资源短缺的结构性矛盾。早期研究主要依赖传统自然语言处理技术，对社交媒体文本进行情感分类或抑郁检测，其核心假设是静态文本特征足以反映心理健康状态。然而，这种范式缺乏临床深度与交互能力，无法捕捉治疗联盟（Therapeutic Alliance）这一预测干预效果的关键因素。2023 年，随着大语言模型的爆发，领域发生第一次范式转变：从静态文本分类转向动态对话式支持。大语言模型展现出类人的共情与上下文理解能力，被迅速应用于咨询、危机干预及诊断辅助，问题定义从“能否识别抑郁”转变为“能否提供有效的治疗性对话”。

这一范式转变引入了新的核心矛盾：通用模型的强大生成能力与临床场景对安全性、准确性及隐私的严苛要求之间的张力。大语言模型在高风险场景（如自杀风险、精神病性症状强化）中可能产生幻觉或提供危险建议，原因在于通用预训练数据中临床知识稀疏且缺乏伦理约束。因此，子问题间形成了强依赖关系：临床安全性是部署的前提，评估标准是验证安全与有效性的基础，而多轮对话能力是连接评估与真实临床场景的桥梁。没有可靠的安全护栏，多轮对话能力越强，潜在危害越大；没有标准化的多轮评估，无法验证安全机制的有效性。隐私保护则是所有数据驱动方法（如微调、检索增强生成）的底层约束，决定了数据获取与模型部署的边界。

约束条件的演化驱动了方法体系的持续迭代。2019 至 2020 年，ELIZA 与 CLPsych Shared Task 奠定了交互与标注的基础，确立了自杀风险分级评估的标准范式，但受限于规则匹配与静态数据，缺乏上下文理解能力。2023 至 2024 年，MentaLLaMA 证明了领域特定微调的有效性，而 Constitutional AI 的引入解决了通用模型在敏感话题上的伦理边界模糊问题，问题定义从“能否对话”变为“是否安全”。2025 至 2026 年，MentalSeek-Dx、VERA-MH 与 MindEval 的出现标志着领域进入精细化阶段，重点解决多轮动态风险治理、临床推理可解释性及文化适应性，追求“可信临床辅助”而非“通用聊天”。

当前，领域形态呈现“双轨并行”特征：一轨聚焦于提升临床有效性（诊断推理、共情生成），另一轨聚焦于构建安全边界（护栏、宪法对齐），两者通过评估基准相互验证。多模态感知（语音、视觉、传感器）与语言的协同评估成为新增长点，旨在通过多源信息融合提高评估的鲁棒性。基于强化学习（RLHF/GRPO）的模型对齐技术被用于解决临床准确性与文化适应性不足的问题。这一演进过程表明，领域正从技术演示向临床落地过渡，核心挑战在于如何在保证实时性与隐私的前提下，实现高临床效度的多轮动态交互。

**如果用一个核心问题概括该领域，那便是：如何在确保临床安全性与伦理合规的前提下，构建具备多轮动态交互能力、文化适应性及隐私保护机制的大语言模型，以实现从通用对话向可信临床辅助系统的范式跃迁。**

## 2. 方法体系

- 2019：CLPsych Shared Task——确立自杀风险分级评估标准范式

- 2020：MedQA——借鉴结构化评估框架衡量临床知识推理

- 2023：MentaLLaMA——首个心理健康任务微调的大语言模型

- 2024：Constitutional AI——引入显式原则指导伦理对齐

- 2025：MentalSeek-Dx——渐进式假设演绎推理诊断框架

- 2025：VERA-MH——心理健康 AI 安全验证基准

- 2025：Empathy-R1——共情链与强化学习长文本支持框架

- 2026：MindEval——多轮心理健康支持动态评估基准

这条时间线勾勒了该领域方法演进的代表性节点：从 2019 年的 CLPsych Shared Task 奠定该领域方法基线，经 2020 年 MedQA 的推进，到 2026 年的 MindEval 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 临床诊断与评估

临床诊断路线的演进核心在于从黑盒分类向白盒推理的转变，以换取可解释性与临床信任。早期方法依赖统计模型进行症状分类，但缺乏对诊断逻辑的捕捉，难以获得临床医生信任。MentalSeek-Dx（Sun et al., 2026, P22）针对传统分类模型在复杂共病场景下准确性低且不可解释的问题，构建了基于假设演绎推理的精神科诊断框架。该方法将诊断任务转化为多步推理链，模拟临床医生从症状提取到鉴别排除的过程，显著提升了逻辑一致性。其成功依赖高质量的结构化临床记录，放弃了部分泛化性以换取推理的可追溯性。

为减少幻觉并提高事实准确性，EGDR-DCS（Yuan et al., 2025, P9）引入了证据引导的诊断推理与置信度评分框架。该方法结合 DSM-5 知识图谱与 LLM，通过知识归因分数量化诊断可靠性，解决了预训练数据中临床知识稀疏导致的错误建议问题。相比纯数据驱动模型，它提升了临床合规性，但依赖知识图谱的完整性。在多模态融合方面，LENS（Xu et al., 2025, P15）通过模板填充与 LLM 精炼，将传感器信号转化为自然语言症状描述，建立了数值数据与量表项目之间的语义桥梁，解决了直接输入 LLM 时的 tokenization 限制。HARBOR（Siddhant, 2025, P14）则整合睡眠、活动等多模态纵向数据，生成离散的风险评分，为动态风险监测提供了细粒度工具。这些方法共同指向多模态与推理增强的融合，与后续安全治理路线形成互补，因为准确的诊断是安全干预的前提。

### 2.2 安全与伦理评估

安全治理路线的演进核心在于从通用过滤向领域专用护栏的转变，以换取高风险场景的精准拦截。通用 LLM 在自杀风险、妄想强化等场景中存在严重缺陷，Constitutional AI（Lyu et al., 2025, P3）将显式原则适配至心理健康领域，通过自我批评与修订机制增强伦理边界意识，解决了通用 RLHF 在敏感对话中原则模糊的问题。其代价是原则制定需要深厚的临床专业知识，且训练成本较高。

针对多轮对话中的动态风险，MindGuard（Farinhas et al., 2026, P21）开发了专用护栏分类器，实时拦截不当回应，相比通用护栏具有更高的敏感性与特异性，但牺牲了部分通用性。MHSafeEval（Lee et al., 2026, P25）提出角色感知的交互级安全评估框架，通过自然主义对抗多轮交互探测模型在特定情境下的风险表现，揭示了模型在不同角色压力下的行为差异。Psychosis-Bench（Au Yeung et al., 2025, P1）则关注 LLM 交互本身可能引发的心理伤害，量化其“致幻”潜力，引入了病理心理学视角。这些方法构成了部署前的安全审计体系，与临床诊断路线形成制约关系，确保安全机制不阻碍有效治疗。

### 2.3 治疗对话生成

治疗对话路线的演进核心在于从静态微调向动态对齐与深层推理的转变，以换取长程对话中的情感一致性。MentaLLaMA 等早期微调方法受限于静态数据分布，难以应对动态情感变化。Empathy-R1（Yao et al., 2025, P2）引入共情链（Chain-of-Empathy）与强化学习框架，将共情视为可分解的推理步骤，克服了传统微调仅匹配表面模式的缺陷，提升了长文本咨询中的深层治疗逻辑。其成功依赖高质量的人类偏好数据，训练复杂度增加。

PAIR-SAFE（Kim et al., 2026, P17）设计配对智能体方法，利用生成与评估智能体的闭环优化，基于动机访谈原则实时修正回复，增强了治疗联盟与自主性尊重，但增加了推理延迟。Cultural Prompting（Xie et al., 2025, P12）通过嵌入文化背景信息，解决了 LLM 默认偏向西方价值观的问题，提升了跨文化场景下的用户信任度。LLUMI（Kim et al., 2026, P26）利用在线社区反馈进行监督微调与直接偏好优化，增强了回复的自然度与亲和力，但需过滤有害内容。Tell Me（Ahalpara, 2025, P8）整合 RAG、合成对话生成与智能体规划，解决了单一模型在知识时效性与对话管理上的局限。这些方法通过提升生成质量，与安全治理路线形成协同，确保对话既有效又安全。

### 2.4 基准与评测框架

评测体系的演进核心在于从静态单轮问答向多轮动态交互与临床效度验证的转变，以反映真实治疗过程的复杂性。早期基准如 CLPsych 侧重于单轮风险检测，无法捕捉上下文依赖。MindEval（Pombal et al., 2025, P10）构建多轮心理健康支持基准，模拟多样化患者人格与动态对话上下文，评估模型在长程交互中的临床对齐能力，解决了单轮测试无法反映治疗联盟动态演变的问题。

CounselBench（ICLR 2026, P28）建立大规模专家评估与对抗性基准，引入对抗性测试揭示模型在极端情况下的失败模式，聚焦于心理健康特有的伦理与情感维度。TrustMH-Bench（Xiong et al., 2026, P24）设计高维人口统计学分割矩阵，将公平性评估纳入心理健康特定场景，揭示模型在不同群体中的系统性偏差。Responsible Evaluation Framework（Arnaout et al., 2026, P19）整合心理测量学方法，强调效度与可靠性的多维评估，引入实施科学视角关注真实世界部署效果。MHDash（Zhang et al., 2026, P20）提供在线平台支持结构化数据收集与受控标注，解决了数据分散与标注不一致的问题。这些基准为方法验证提供了标准化协议，是连接方法研发与临床落地的桥梁。

### 2.5 隐私保护与部署

隐私保护路线的演进核心在于从云端集中式部署向端侧本地化与合成数据生成的转变，以换取数据主权与合规性。心理健康数据高度敏感，云端部署存在隐私泄露风险。MindChat（Xue et al., 2026, P16）结合多智能体角色扮演生成合成咨询数据，利用双闭环反馈机制整合心理学专业知识，解决了真实数据稀缺与敏感性问题，避免了原始数据出境。

Menta（Zhang et al., 2025, P13）开发端侧小型语言模型，优化架构与推理效率，支持在用户设备上直接处理文本，实现了零数据出境，但牺牲了部分精度以换取隐私与实时性。MoPHES（Wei et al., 2025, P6）将 LLM 部署在移动设备上，支持离线运行以保护隐私，增强了数据主权，但受限于设备算力。Embedded AI-Literacy Framework（Anvari and Wehbe, 2025, P4）设计自适应包装层监控用户交互，实时分析披露风险并提供反馈，将隐私保护延伸至用户行为层面。Multi-Attribute Human Evaluation（Badawi et al., 2026, P18）建立多属性人类评估协议，弥补自动指标无法捕捉语义细微差别的问题，为质量控制提供人类基准。这些方法为合规场景下的部署提供了技术路径，与所有其他路线形成底层约束关系。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域在“LLM 需经严格临床验证与安全评估才能部署”上达成广泛共识，这一共识在多个基准上被反复验证：MentalSeek-Dx 的 CA 83.99 与 Llama-3.3-70B-Instruct 的 Exact Match 0.7283 均表明，未经领域适配的通用模型在高风险场景下表现不可预测，必须引入专门机制。与此相关的另一个共识是，多轮对话评估比单轮问答更能反映 LLM 在真实咨询场景中的表现，MindEval 等基准的提出正是基于这一认识，因为单轮测试无法捕捉治疗联盟的动态演变与累积风险。此外，基于人类反馈的强化学习（RLHF）及检索增强生成（RAG）被视为提升临床合规性与事实准确性的关键手段，Empathy-R1 的 Win@1 44.30 与 EGDR-DCS 的准确性提升均支持这一观点。

### 3.2 观点分歧

在临床对齐的最佳技术路径上，存在 RLHF、RAG 与专用护栏之间的分歧。RLHF 侧重偏好优化，能更好地提升共情与治疗联盟，适合生成式任务；RAG 侧重事实准确性，通过外部知识约束减少幻觉，适合诊断任务；专用护栏侧重实时拦截，防止高风险输出，适合安全关键场景。现有证据显示，RAG 在诊断准确性上优于纯生成模型，RLHF 在共情评分上优于基础模型，而护栏在安全拦截率上显著优于无护栏模型，但缺乏在同一基准上对三者组合效果的全面对比实验。这一分歧的背后，是另一个更根本的争论：评估的金标准是 LLM 裁判还是人类专家。LLM 裁判成本低但信度存疑，易受提示偏差影响；人类专家信度高但成本高且主观。目前缺乏高一致性的自动化评估协议，导致不同研究间的结果难以直接比较。

### 3.3 其他开放问题

最紧迫的工程问题在于多模态数据融合与端侧部署的性能瓶颈。多模态对齐技术尚不成熟，语音、视觉等模态的噪声大且标注成本高，限制了综合评估系统的性能；端侧小模型在复杂共病诊断与多轮长对话中表现明显落后，缺乏在严格隐私约束下对性能损失的量化研究。最根本的研究问题则是 LLM 交互对用户长期心理状态的影响，如认知萎缩（Cognitive Atrophy）与情感依赖，原因尚不明确，当前正通过行为模式分析框架量化这种依赖风险。此外，文化适应性与公平性仍是未解难题，LLM 往往偏向西方文化价值观，对非西方用户或少数群体的文化特异性表达理解不足，导致支持效果偏差。已知的是 LLM 在静态任务上表现优异，争议的是动态对齐与评估标准，未知的是长期交互的伦理边界与深层文化适应机制。

## 4. 总结与展望

大语言模型在心理健康领域的应用正处于从“技术演示”向“临床落地”的关键转折期，核心矛盾在于通用模型的强大生成能力与临床场景对安全性、准确性及隐私的严苛要求之间的张力。早期研究通过静态分类解决了筛查问题，但缺乏临床深度；随后通过领域微调与伦理对齐提升了共情与安全性，但面临幻觉与多轮一致性挑战；当前通过多模态融合、强化学习对齐及隐私保护部署，试图构建可信临床辅助系统。核心瓶颈在于如何在保证实时性与隐私的前提下，实现高临床效度的多轮动态交互与个性化支持，这要求方法体系在“准确性-共情-安全性”三角之间取得平衡。

未来可能突破的方向包括：一是开发能够处理多轮对话中累积风险和上下文依赖性的评估框架，解决当前模型在长对话中失去治疗节奏的问题；二是探索小模型在设备端心理健康监测中的可行性，通过高效微调和数据增强技术，使轻量级模型在隐私保护场景下达到与大模型相当的检测性能；三是增强 LLM 的文化响应性和个性化能力，通过整合社区视角和文化提示技术，使 AI 支持更贴合不同人口统计学特征用户的需求。对于进入该领域的研究者，最值得做的一件事是构建统一的、多轮动态的、包含文化多样性维度的临床验证基准，以解决当前评测碎片化与信度不足的问题，为方法比较提供公平的基础。
