综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Singing%20Voice%20Synthesis%20and%20Processing)

## 导读

歌声合成（Singing Voice Synthesis, SVS）旨在从歌词与乐谱生成高保真歌声，其核心价值在于平衡数据标注成本与生成质量之间的张力。早期系统依赖级联架构与精细音素标注，虽音质高但泛化差且数据生产成本极高。随着扩散模型与离散令牌（Discrete Tokens）范式的引入，研究重心从单歌手高保真还原转向零样本音色克隆与跨语言泛化。当前，领域正经历从单一合成向统一建模与可控编辑的转型，试图在摆脱人工标注依赖的同时，实现语音与歌声的协同生成。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

歌声合成的核心矛盾在于符号化的音乐输入与连续化的声学输出之间的映射复杂性。传统任务定义为给定歌词序列 $L$ 和乐谱序列 $M$，生成对应的音频波形 $X$，即 $X = f(L, M)$。然而，这一形式化定义掩盖了深层的子问题依赖：旋律对齐是基础，若音素与音高无法精确对应，后续的风格控制与音色克隆便无从谈起；音色解耦是前提，只有将说话人身份与语言内容分离，零样本转换才成为可能。早期系统如 XiaoiceSing（2018）确立了音素级对齐的必要性，但也暴露了人工标注的高昂成本，导致高质量数据集规模受限，模型泛化能力差。

问题定义的演化反映了约束条件的变化。2020 年前，研究聚焦于“如何生成”，核心假设是精细标注是高质量合成的必要前提。2020 年 DiffSinger 引入扩散模型，解决了级联架构的误差累积问题，确立了端到端生成的主流地位，但仍未摆脱对标注的依赖。2023-2024 年，受 VALL-E 等语音合成工作启发，离散 Token 与自回归范式兴起，问题定义从“生成特定歌手”转向“泛化到未见歌手”，零样本能力成为关键指标。2025-2026 年，研究重心进一步转向“如何统一与可控”，UniVoice 和 UniSinger 等模型探索语音-歌声统一框架，YingMusic-Singer 系列聚焦无标注旋律引导，试图在缺乏精细标注的情况下实现高保真合成。

这一演进并非线性替代，而是基于不同约束下的取舍。扩散模型换取了稳定性但牺牲了速度，离散 Token 换取了可控性但引入了量化损失，统一建模换取了效率但面临模态冲突。当前，SVS 处于从“高保真生成”向“实时交互、多模态融合及大规模数据自动化标注”转型的活跃期，重点解决旋律对齐、风格解耦及实时鲁棒性挑战。

**如果用一个核心问题概括该领域，那便是：如何在摆脱对精细人工标注依赖的前提下，构建能够统一建模语音与歌声、并实现零样本音色克隆与细粒度风格控制的生成框架。**

## 2. 方法体系

- 2018：XiaoiceSing——基于深度学习的早期歌声合成系统，采用两阶段声学模型与声码器架构

- 2020：DiffSinger——引入扩散模型改进歌声合成，确立了扩散模型在SVS领域的主流地位

- 2022：VISinger——基于变分推断与对抗学习（VITS）构建的端到端歌声合成系统

- 2023：So-VITS-SVC——结合HuBERT内容编码器与VITS生成模型的开源歌声转换框架

- 2024：TCSinger 2——实现零样本风格迁移的歌声合成模型

- 2025：YingMusic-Singer——提出无标注旋律引导的零样本歌声合成框架

- 2026：UniVoice——统一语音和歌声生成的模型，基于条件流匹配（CFM）和共享DiT骨干网络

这条时间线勾勒了该领域方法演进的代表性节点：从 2018 年的 XiaoiceSing 奠定该领域方法基线，经 2020 年 DiffSinger 的推进，到 2026 年的 UniVoice 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 扩散模型与流匹配路线

扩散模型与流匹配路线是 SVS 领域从级联架构向端到端生成转型的核心驱动力。2020 年 DiffSinger 通过编码器-解码器框架生成音乐分数嵌入，并利用扩散解码器合成梅尔频谱，显著提升了合成音质的自然度和稳定性，确立了扩散模型在 SVS 领域的主流地位。这一路线的核心假设是：通过条件去噪过程，可以从噪声中逐步恢复出高保真的音频信号，从而避免级联系统中声学模型与声码器之间的误差累积。然而，传统扩散模型的多步采样导致推理延迟高，难以满足实时交互需求。

为了解决推理效率与生成质量的平衡问题，近期研究转向流匹配（Flow Matching）技术。YingMusic-Singer（Zheng et al., 2025, P14）提出了一种端到端歌声合成框架，其核心创新在于采用协同集成架构，将在线旋律提取模块与基于扩散 Transformer（DiT）的 SVS 模块紧密耦合。该方法通过蒸馏联合优化策略，利用冻结的预训练教师旋律模型提供稳定的监督信号，使在线提取器能够自适应地精炼其表示以改进下游合成。这一设计摆脱了传统流水线模型将旋律提取和合成作为独立阶段处理的局限，实现了旋律提取与合成的相互促进，为无标注旋律引导的零样本 SVS 提供了新的技术范式。相比之下，YingMusic-Singer-Plus（Hao et al., 2026, P22）进一步引入了 GRPO（Group Relative Policy Optimization）训练流水线，利用奖励模型计算生成样本的优势，通过随机掩码和 KL 损失约束，实现了对歌词编辑和旋律保持的精细控制。

该路线与离散 Token 路线的竞争在于：扩散/流匹配模型在保真度上通常更优，因为连续特征保留了更多声学细节，避免了量化损失；但离散 Token 模型在可控性和零样本泛化上更具优势。YingMusic-Singer 在 WER 上取得了 1.28% 的 SOTA 成绩，证明了连续特征在语言准确性上的潜力，但其推理速度仍受限于扩散过程。

### 2.2 离散 Token 与自回归路线

离散 Token 路线借鉴 LLM 范式，将歌声合成形式化为对离散编解码 Token 的自回归生成，旨在提升模型的可控性和零样本能力。CoMelSinger（Zhao et al., 2025, P4）是这一路线的代表，它利用 HuBERT 和 Wav2Vec 2.0 等自监督学习模型学习有意义的潜在表示，并将其量化为离散单元。为了降低推理延迟，CoMelSinger 结合了非自回归（NAR）解码框架，采用双向 Transformer 进行基于置信度的掩码 Token 建模，并行生成音频 Token，同时保持自回归级别的质量。该方法通过提示条件化展示了强大的零样本能力和说话人泛化性，解决了传统连续特征流水线在离散表示上的局限性。

UniVocal（P32）则进一步探索了语音-歌声代码切换合成，适配 CosyVoice 2 架构，引入精化的 Cent Token 表示，将每个半音分为 100 个 Cent，以实现语音韵律和歌唱旋律的高分辨率建模。其核心设计包括“计划-生成”机制，模型在内容生成前规划韵律，通过 12 半音分辨率的色度图补充缺失的音高信息。UniVocal 在 SCSBench 上取得了 F1(O) 0.871 和 F1(S) 0.810 的 SOTA 成绩，证明了离散 Token 在可控性和代码切换上的优势。然而，离散 Token 路线的代价是量化过程导致的高频细节丢失，以及自回归推理的高延迟。

与扩散路线相比，离散 Token 路线更适合需要细粒度控制和长序列生成的场景，但在高保真渲染上略逊一筹。SoulX-Singer（Qian et al., 2026, P21）通过两阶段训练策略，逐步增强模型鲁棒性和长格式生成能力，第一阶段在较短音频片段上训练以提高泛化能力，第二阶段转向长格式歌声建模，捕捉长程时间依赖。这一设计解决了早期 SVS 模型难以泛化到未见歌手的问题，为多语言高质量零样本 SVS 提供了有效方案。

### 2.3 统一语音-歌声建模路线

统一建模路线旨在解决语音和歌声在韵律和旋律控制上的根本差异，通过共享骨干网络和任务特定条件注入，实现单一模型处理多种 vocal 行为。UniVoice（Zheng et al., 2026, P24）基于条件流匹配（CFM）和共享 DiT 骨干网络（Wan-DiT），通过因子化条件区域处理内容、旋律和音色。对于语音任务，旋律编码器被替换为学习的空 Token $e_\emptyset$，所有条件拼接后输入共享 DiT 骨干，通过任务 Token（speech/singing）进行 AdaLN 调制，实现任务特定控制。UniVoice 在 Speech PER 上取得 5.26%，在 Singing PER 上取得 16.22%，证明了统一架构在保持声乐身份一致性方面的可行性。

UniSinger（Zhang et al., 2026, P25）则进一步探索了完整歌曲生成与歌声转换的统一，包含多模态输入处理、渐进课程学习、跨任务说话人嵌入空间和 MM-DiT 骨干四个核心组件。其任务特定模态掩码机制通过指示函数和可学习空 Token 处理多任务优化冲突，避免模态间干扰。这一设计解决了现有歌曲生成模型缺乏说话人克隆能力和 SVC 模型无法处理完整歌曲生成的问题，推动了音乐创作自动化的发展。

统一建模路线的代价是模态间优化冲突加剧，需要复杂的任务标签调制和课程学习策略。尽管 UniVoice 在 SCSBench 上表现优异，但其 Singing PER（16.22%）高于专用模型，表明统一模型在纯歌声任务上仍存在性能折损。

### 2.4 歌声转换与风格控制

歌声转换（SVC）与风格控制路线聚焦于保持歌词和旋律不变，将源歌手音色转换为目标歌手音色，或实现细粒度风格调节。YingMusic-SVC（Chen et al., 2025, P15）基于 Seed-VC 架构，采用整流流匹配目标学习连续速度场，引入三阶段训练策略：连续预训练（CPT）、监督微调（SFT）和基于 Flow-GRPO 的强化学习后训练。该方法通过多目标奖励直接优化转换歌声的感知和美学属性，显著提升了真实场景下的转换鲁棒性。

R2-SVC（Zheng et al., 2025, P9）则针对真实世界鲁棒性和表现力，引入基于模拟的鲁棒性增强、歌声知情的音色和风格提取器以及神经源滤波器（NSF）集成。通过数据增强和显式谐波建模，R2-SVC 提升了模型在复杂声学环境下的鲁棒性和表现力。S2Voice（Wang et al., 2026, P18）采用风格感知的自回归建模框架，解耦高层内容/风格建模和低层声学渲染，通过基于 VQ 的 Tokenizer 对 SSL 特征进行离散化，实现了对歌唱风格的精细控制。在 SVCC 2025 挑战赛中，S2Voice 在自然度、风格相似度和歌手相似度上均取得 Top-ranked 成绩，证明了离散 Token 在风格控制上的优势。

Boundary-Aware Information Bottleneck（Hu et al., 2026, P23）提出了一种用于歌唱风格转换（SSC）的边界感知信息瓶颈方法，通过技巧矩阵提供显式风格控制，解决了现有 SSC 方法在风格特定音高动态与严格旋律约束之间的冲突问题。Vibrato Expression Control（Choi et al., 2026, P26）则专注于颤音表现力控制，通过显式控制机制调节颤音深度、频率等参数，提升了转换歌声的自然度和表现力。

### 2.5 歌曲生成与配套创作

歌曲生成与配套创作路线探索完整歌曲生成、翻唱制作及伴奏协同生成，解决歌词-旋律对齐、结构解析及人声-伴奏和谐性问题。DiffRhythm 2（Jiang et al., 2025, P11）基于块流匹配（Block Flow Matching）和扩散 Transformer，通过随机块 REPA 损失和跨对偏好优化策略，实现了高效高保真歌曲生成。SongEcho（P31）基于实例自适应元素级线性调制（IA-EiLM）的翻唱歌曲生成框架，构建于 ACE-Step 全曲生成模型之上，通过参数高效微调实现旋律引导的音乐生成，降低了训练参数需求。

MPEcho（Lee et al., 2026, P29）引入旋律和音素感知模块，通过 IA-EiLM 实现参数高效微调，允许用户调节局部音乐元素，实现高度变异的翻唱效果。ToneCraft（P30）则专注于粤语歌词生成，提出 A2R-Mapping 和 CTP-Mapping 技术，实现了粤语歌词与旋律的和谐对齐。SongPrep（Tan et al., 2025, P3）提供了预处理框架和端到端模型，用于全曲结构解析和歌词转录，构建了 SSLD-200 数据集，为歌曲生成提供了高质量数据基础。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

扩散模型和流匹配已成为提升歌声合成自然度和稳定性的主流生成范式，优于传统的 GAN 或 VAE 方法。这一共识在多个基准上被反复验证：YingMusic-Singer 的 WER 1.28% 与 TCSinger 的 3.47% 均大幅超越早期级联系统。零样本能力是 SVS 发展的关键趋势，通过提示音频实现音色克隆，摆脱了对大规模配对数据的依赖。精细的音素级标注是传统 SVS 的主要瓶颈，无标注或弱标注的旋律引导方法是当前的研究热点。自监督学习（SSL）特征在歌声内容提取和音色解耦中表现优异，是构建鲁棒内容编码器的基础。端到端架构逐渐取代级联架构，以减少误差累积并简化训练流程。

### 3.2 观点分歧

离散 Token 与连续特征之争是领域内的核心分歧。观点 A 认为离散表示便于 LLM 范式处理，利于零样本和代码切换，可控性强；观点 B 认为连续特征保留了更多声学细节，避免了量化损失，保真度更高。现有证据偏向连续特征在保真度（MCD, SIM）上略优，离散 Token 在可控性（WER, 风格切换）上占优。证据强度中等，缺乏同数据、同算力下的严格对比实验。统一建模与专用模型之争同样存在。观点 A 认为共享骨干可提升效率，因子化条件能解决模态差异；观点 B 认为语音和歌声在韵律、音高范围上差异巨大，强行统一会导致“两不靠”。UniVoice 在 SCSBench 上取得了 SOTA，证明统一建模可行，但其 Singing PER（16.22%）高于专用模型，表明存在性能折损。

### 3.3 其他开放问题

实时推理与流式生成是当前的工程瓶颈，扩散模型和自回归模型推理速度慢，难以满足实时应用需求。细粒度表现力与风格控制是研究难题，现有系统多关注全局音色，缺乏对颤音、气声等局部演唱技巧的独立控制。自动化评估与主观感知对齐是根本挑战，现有客观指标无法完全反映歌声的艺术表现力，需开发基于多模态大模型（MLLM）的生成式评估框架。已知—争议—未知认知图谱显示，领域在生成范式上已达成共识，但在表示形式与统一建模上存在争议，实时性与细粒度控制仍是未知领域。

## 4. 总结与展望

SVS 领域正从“高保真生成”迈向“通用交互”，其核心在于通过统一建模和自动化标注打破数据壁垒。过去五年的主线是摆脱标注依赖，未来竞争焦点将转向细粒度控制与实时鲁棒性。方法取舍的最终形态可能是“离散 Token 用于高层控制与零样本泛化，连续流匹配用于底层高保真渲染”的混合架构。

未来可能突破的方向包括：基于强化学习（Flow-GRPO）的后训练优化，以及结构感知的声乐表示（VocalRep）。对进入者最值得做的一件事是：在统一骨干与统一预训练条件下，系统评估离散 Token 与连续特征在细粒度风格控制上的权衡，以填补当前证据的空白。
