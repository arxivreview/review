# A Survey of Predictive Process Monitoring Methods ｜预测性流程监控方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Process%20Mining%20and%20Predictive%20Monitoring)

## 导读

预测性流程监控（Predictive Process Monitoring, PPM）旨在利用历史事件日志预测进行中的流程实例未来状态，其核心价值在于将事后描述转化为前瞻性决策支持。早期研究以传统机器学习及长短期记忆网络（LSTM）为主线，通过序列编码捕捉时间依赖，思路稳健却受制于数据稀缺与高过程熵。当跨域基准暴露出静态模型在分布漂移下的性能崩溃后，研究者引入大语言模型（LLM）与神经符号方法，用更强的语义先验与逻辑约束换取小样本鲁棒性与合规性。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

流程挖掘（Process Mining, PM）起源于对信息系统日志的事后分析，旨在发现、监控和优化业务流程。随着数字化转型深入，研究重心从描述性分析转向预测性流程监控（PPM），以支持前瞻性决策。PPM 的核心任务是利用历史日志预测进行中的流程实例未来状态，如下一活动（Next Activity, NA）、剩余时间（Remaining Time, RT）及案例后缀。这一转变标志着流程分析从“发生了什么”向“将要发生什么”的范式跃迁，其基础数据源为事件日志（Event Log），即记录业务流程执行的多重集，包含活动、时间戳及属性。

问题形式化通常遵循 N-way K-shot 范式，即给定前 $k$ 个事件的前缀，预测后续事件。然而，真实业务场景远比理想化假设复杂。数据稀缺与小样本泛化是首要瓶颈，传统深度学习模型在日志量不足时性能急剧下降，原因在于缺乏足够的统计证据学习可靠的过程表示。其次，高过程熵（Process Entropy）量化了给定前缀下后续活动的不确定性，当流程变体多样时，标准序列模型难以区分合理路径，因为其对长距离依赖和结构约束的捕捉能力有限。此外，在线环境中的概念漂移（Concept Drift）指流程分布随时间变化，导致静态模型失效，而持续学习又易引发灾难性遗忘。

子问题间呈现强依赖关系：数据稀缺与高熵预测是基础瓶颈，若不解决，后续的知识增强方法无法发挥效能；在线持续学习依赖于对概念漂移的有效检测；而处方性流程监控（Prescriptive Process Monitoring, PresPM）则依赖于高精度的多任务预测及因果推断能力，是预测能力的上层应用。范式边界上，PPM 不仅关注预测精度，更强调在资源受限与合规约束下的鲁棒性与可解释性。纯数据驱动模型难以融入显式业务规则，这促使研究从统计学习向知识增强学习转变。

2016-2018 年，LSTM 等递归神经网络奠定了深度学习在 PPM 中的基础范式，通过序列编码捕捉时间依赖。2020 年，ProcessTransformer 引入自注意力机制，显著提升了复杂流程结构的建模能力，但仍未解决数据稀缺问题。2021 年，LTL-PostProcessing 初步探索了符号知识对数据驱动模型的约束作用，但缺乏训练阶段的深度整合。2023 年，DynaTrainCDD 提出基于前缀漂移检测的在线持续学习框架，解决了静态模型在动态环境中的适应性不足问题。

2024 年，SNAP 将事件日志转化为自然语言叙事文本并微调 LLM，开创了 LLM 在 PPM 中叙事编码的新方向。2025 年，PEFT-Process-LLM 采用参数高效微调技术直接适配结构化流程数据，避免了自然语言转换的信息损失；同年，Two-Stage-LTN 提出两阶段逻辑张量网络，解决了符号知识注入导致的优化不稳定问题。2026 年，D-TAIA 提出领域感知 LLM 适配框架，同时解决数据稀缺、高熵预测及分布偏移三大挑战；COMPASS 基于基础模型的在线持续微调框架，实现了无遗忘的自适应更新。

当前形态下，研究热点集中在多任务预测、在线持续学习以及基于因果推断的处方性监控。可解释性分析与复现性工具库（如 SPICE）的建设也成为提升领域成熟度的重要方向，标志着 PPM 正从单一预测任务向智能化、合规化及自主代理（Agentic）框架演进。

**如果用一个核心问题概括该领域，那便是：在数据稀缺、分布漂移及合规约束并存的动态环境中，如何构建兼具高精度、可解释性及主动干预能力的智能流程监控框架，以从被动预测走向主动优化。**

## 2. 方法体系

- 2017：LSTM-PPM——奠定深度学习在PPM中的基础范式

- 2019：BiLSTM-Suffix——解决单向模型无法捕捉长程依赖的问题

- 2020：ProcessTransformer——引入自注意力机制替代RNN

- 2024：SNAP——开创LLM在PPM中叙事编码的新方向

- 2025：PEFT-Process-LLM——直接适配结构化流程数据

- 2025：Two-Stage-LTN——解决符号知识注入导致的优化不稳定问题

- 2026：D-TAIA——领域感知LLM多任务适配框架

- 2026：PMAx——代理式流程挖掘框架

这条时间线勾勒了该领域方法演进的代表性节点：从 2017 年的 LSTM-PPM 奠定该领域方法基线，经 2019 年 BiLSTM-Suffix 的推进，到 2026 年的 PMAx 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 大模型适配与生成

大语言模型（Large Language Models, LLMs）的引入为 PPM 提供了新的解决路径，旨在利用预训练知识弥补数据不足。早期尝试如 SNAP（2024）将日志转化为自然语言叙事，虽提升了语义理解，但存在信息损失。P10（Padella et al., 2026）针对小规模日志，通过结构化提示工程保留轨迹序列，证明了 LLM 在小样本场景下优于传统基准，其代价是提示工程的高复杂度。P1（Oyamada et al., 2025）则转向结构化适配，通过替换嵌入层使 LLM 原生消费活动标签，避免了文本转换的信息损失，但需针对特定词汇表重新训练。P19（van Straten et al., 2026）提出的 D-TAIA 框架进一步整合了 LoRA 微调与 FAISS 检索增强，统一了多任务预测，显著提升了低数据量场景下的鲁棒性，代价是增加了检索模块的计算复杂度。P17（Wang and Damiani, 2026）提出的 GGATN 则将流程结构建模为图，结合 Transformer 实现全事件序列生成，解决了传统 GNN 难以保持有序生成状态的问题，但依赖于流程结构图的准确发现。该路线与神经符号路线互补，前者提供语义先验，后者提供逻辑约束。

### 2.2 神经符号与合规

纯数据驱动模型难以保证预测结果符合硬性业务规则，神经符号方法通过逻辑张量网络（Logic Tensor Networks, LTN）将领域知识注入训练过程。P14（De Santis et al., 2026）提出的 Compliance-Aware-PPM 将一级逻辑规则嵌入训练，提升了合规敏感场景的预测准确性，但规则提取自动化程度有限。P13（De Santis et al., 2026）提出的 Two-Stage-LTN 针对符号知识注入导致的优化不稳定问题，引入规则剪枝机制，通过两阶段训练平衡统计学习与逻辑约束，解决了简单知识注入可能损害优化过程的副作用。该方法在数据有限且合规要求严格的场景中表现优异，揭示了符号知识与数据驱动学习之间的非平凡交互。与 LLM 路线相比，神经符号方法在可解释性与合规性上更具优势，但在处理高熵语义推理时略显不足。

### 2.3 在线持续学习

实时流数据中的概念漂移导致静态模型失效，在线持续学习成为应对动态环境的必要手段。P15（Hassani et al., 2026）提出的 CNAPwP 利用滑动窗口与概念漂移检测，通过专家提示（E-Prompt）与通用提示（G-Prompt）管理知识，缓解了遗忘问题，但依赖漂移检测算法的准确性。P20（van Straten and Hassani, 2026）提出的 COMPASS 基于基础模型的在线持续微调，利用 LoRA 与知识子空间扩展机制，通过正交投影避免新任务对旧知识的干扰，实现了无遗忘的自适应更新。该方法在复杂长周期案例中表现强劲，但子空间扩展带来计算开销。在线学习路线与 LLM 路线结合紧密，COMPASS 即基于基础模型构建，体现了动态适应与语义先验的融合。

### 2.4 智能体与处方监控

从预测延伸至主动优化与控制，智能体与处方监控代表了 PPM 的下一代演进方向。P8（De Moor et al., 2025）提出的 SCOPE 结合因果学习与反向归纳法，实现多决策点间的序列干预优化，克服了单点优化导致的整体 KPI 次优问题。P9（Bibalan et al., 2025）提出的 Multi-Agent-RAG-WiP 框架利用多智能体检索增强生成，提升了在制品预测对概念漂移的鲁棒性。P12（Antonov et al., 2026）提出的 PMAx 构建代理式流程挖掘框架，通过多智能体协作实现从自然语言查询到代码生成的自动化闭环。P11（Dumas et al., 2026）探讨了代理式 BPM 系统，提出利用生成式 AI 动态生成、执行及优化流程，代表了从自动化执行向自主智能决策的转变。该路线依赖于高精度的预测能力与因果推断，是预测能力的上层应用。

### 2.5 特征增强与发现

丰富输入维度与区分优劣轨迹是提升预测粒度的关键。P5（Leribaux et al., 2025）提出的 Actor-Enriched-TS 从事件日志中提取演员行为特征，构建多变量时间序列，揭示了资源动态行为作为预测信号的价值。P6（Norouzifar and van der Aalst, 2025）提出的 Discriminative-Rule-Discovery 利用集成树模型提取控制流特征，学习判别规则以区分优劣轨迹，推动了过程发现从全局描述向结果导向的转变。P2（Ali et al., 2025）提出的 BiLSTM-MM-Suffix 将下一活动、开始间隔时间及处理时间解耦为三个独立的预测器，提高了资源规划与调度的实用性。P16（De Smedt et al., 2026）提出的 DIFF-ERO-Loss 将一致性检查指标转化为可微分损失，使模型在训练阶段即学习流程结构约束，解决了高局部精度但全局行为不精确的问题。该路线为其他路线提供了更丰富的特征基础与结构感知训练信号。

### 2.6 框架基准与优化

可复现性与模型效率是 PPM 落地的重要保障。P7（Stritzel et al., 2025）提出的 SPICE 库统一了数据划分、预处理及实验设计流程，消除了信息泄露，建立了基准测试标准。P3（Ansari et al., 2025）研究神经网络架构简化，提出 MTLFormer-light 等变体，证明在保持预测性能的前提下可大幅缩减模型规模。P18（Sahatova et al., 2026）提出基于特征归因的可解释性分析方法，利用控制流感知分割算法生成符合业务流程逻辑的解释。P4（Penther et al., 2025）开展特定场景下的基准测试，展示了如何系统化地选择与评估 PPM 方法。该路线为其他路线提供了可靠的实验基础设施与轻量化部署方案。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLM 在数据稀缺场景下优于传统深度学习模型，这一共识在多个基准上被反复验证：D-TAIA 在 BPI2012 上的 Macro-F1 达到 0.85，显著优于 LSTM 基线，其预训练知识提供了强大的先验（支撑证据：P1, P10, P19）。与此相关的另一个共识是，纯数据驱动模型难以有效融入显式的业务规则和合规约束，需要神经符号或后处理机制。Two-Stage-LTN 在 Sepsis 数据集上取得 91.30% 的准确率，较 LSTM 的 81.50% 提升显著，证明了逻辑规则注入的必要性（支撑证据：P13, P14）。在线持续学习是应对概念漂移的必要手段，COMPASS 在 BPI2015-REC 上实现 +19% 的 Accuracy Gain，表明静态模型无法适应动态变化的流程环境（支撑证据：P15, P20）。多任务联合预测比单任务模型更具部署优势，能捕捉任务间关联，D-TAIA 统一了 NA 与 RT 预测，提升了整体性能（支撑证据：P2, P19）。

### 3.2 观点分歧

LLM 在 PPM 中的输入表示存在自然语言叙事与结构化 Token 的分歧。观点 A 认为叙事文本保留语义，适合跨域泛化（代表：SNAP）；观点 B 认为结构化 Token 保留结构信息，避免文本转换损失（代表：PEFT-Process-LLM, D-TAIA）。现有证据偏向结构化 Token，D-TAIA 在 BPI2012/2017 上的 Macro-F1（0.85/0.84）显著优于基线，且避免了叙事构建的复杂性。但叙事文本在缺乏领域微调时可能更具鲁棒性，定输赢的实验需在完全未见过的跨域流程上比较两种方法在零样本/少样本下的泛化能力。这一分歧的背后，是另一个更根本的争论：神经符号规则注入的时机与稳定性。观点 A 主张后处理/约束解码，简单且不影响训练稳定性；观点 B 主张训练时联合优化，实现深度融合。证据偏向训练时联合优化，Two-Stage-LTN 在合规预测上（91.30% vs 82.74%）显著优于纯数据模型，且通过规则剪枝缓解了优化不稳定。但后处理在规则简单时更轻量，定输赢的实验需在规则复杂度高且数据量极少的场景下比较两种方法在合规准确率与训练收敛速度上的权衡。

### 3.3 其他开放问题

最紧迫的工程问题是 LLM 在过程数据中的域适应与效率。当前 LLM 在 PPM 中面临计算成本高和语义理解与数值预测脱节的问题，未来需探索更高效的微调策略（如 LoRA）和域感知编码，以平衡预测精度与推理延迟。最根本的研究问题是神经符号方法的自动规则提取。当前神经符号方法主要依赖手动定义的逻辑规则，难以自动从数据中提取规则模板，未来需研究自动连接特征与规则的形式化表示，特别是在医疗等关键领域。此外，在线持续学习中的概念漂移检测与适应仍面临冷启动和稳定性-可塑性困境，需集成鲁棒的突变和渐变概念漂移检测机制。已知的是 LLM 与神经符号方法在各自优势场景下的有效性，争议的是输入表示与规则注入方式的最优选择，未知的是自动化知识获取与因果干预的可靠性。发展趋势是构建“LLM+神经符号+在线学习”的混合架构，实现从被动预测到主动处方的范式跃迁。

## 4. 总结与展望

PPM 领域经历了从静态单步预测到动态多任务联合预测、从纯数据驱动到知识增强与神经符号、从离线批量训练到在线持续学习与处方干预的范式重构。核心矛盾已从单纯的预测精度转向在资源受限与合规约束下的鲁棒性与可解释性。LLM 与神经符号方法的引入并非简单的技术叠加，而是对“数据驱动”范式的根本性修正，旨在解决数据稀缺、高过程熵及概念漂移等基础瓶颈。当前核心瓶颈在于如何在保持高效推理的同时，实现规则的自动化获取与因果干预的可靠性验证，这制约了 PPM 从被动监控向主动优化的全面演进。

未来可能突破的方向包括：一是扩展神经符号方法至更复杂的领域知识集成，研究自动连接特征与规则的形式化表示，解决领域知识稀缺和逻辑一致性挑战（P13, P14）；二是优化 LLM 在过程数据中的域适应与效率，探索更高效的微调策略和域感知编码，平衡预测精度与推理延迟（P1, P19）；三是增强在线持续学习中的概念漂移检测与适应，开发轻量级提示策略以优化复杂日志下的计算开销（P15, P20）。对进入者而言，最值得做的一件事是在统一基准（如 SPICE）下，系统比较 LLM 结构化适配与神经符号规则注入在跨域泛化与合规性上的权衡，为混合架构的设计提供实证依据。
