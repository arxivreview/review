综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Personalized%20Dialogue%20Generation%20and%20Evaluation)

## 导读

个性化对话生成旨在让机器在交互中展现特定的人格特征与用户偏好，其核心价值在于弥合通用语言模型的同质化输出与人类交流中高度情境化、个体化需求之间的鸿沟。早期研究将人物画像视为静态条件输入，通过简单的文本拼接提升拟人化程度，但这种方法在长程交互中迅速暴露出画像漂移与语境脱节的缺陷。随着大语言模型（LLM）的普及，研究重心从单轮静态画像转向多轮动态记忆与在线推断，试图在无需预收集用户数据的前提下实现隐性个性化。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从显式对齐到动态闭环的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

个性化对话生成的起源是对传统任务型聊天机器人缺乏情感共鸣与情境适应能力的反思。早期工作聚焦于将预定义的人物画像（Persona）作为静态输入，旨在提升对话的拟人化程度。这一阶段的核心假设是“静态画像足以代表用户”，受限于当时模型能力，主要采用简单的文本拼接或过采样策略。然而，这种假设在复杂交互场景中迅速失效，因为用户偏好并非一成不变，而是随着对话进程动态演变的。

问题的形式化可以定义为：给定人物画像集合 $P$ 和对话历史 $H$，生成回复 $R$，使得 $R$ 在语义和风格上与 $P$ 保持一致，同时与 $H$ 连贯。即 $\max_{R} \text{Consistency}(R, P) + \text{Coherence}(R, H)$。这一形式化揭示了两个核心子问题：画像一致性与上下文连贯性。前者要求回复不违背画像中的事实与风格，后者要求回复自然承接历史语境。这两个子问题存在强依赖关系：若无法解决静态画像的逻辑对齐，则无法构建可靠的长程记忆；若无法在长对话中保持上下文连贯，则目标导向策略优化中的长期价值最大化将因语境断裂而失效。

在范式边界上，领域逐渐区分出“显式画像注入”与“隐性个性化”两条路径。显式路径依赖预收集的用户数据，通过NLI或对比学习显式对齐，可控性强但部署受限；隐性路径依赖在线推断，从对话历史中挖掘用户潜在属性，灵活但推断准确性缺乏金标准验证。这一区分标志着领域从离线特征工程向在线认知推断的跨越。

约束演化史清晰地展示了方法如何因应环境变化而演变。2016-2018年，Persona-Chat 奠定了静态画像基础，约束在于数据稀疏与模型能力有限。2020-2022年，跨域基准如 Multi-Session Chat (MSC) 出现，暴露出长程对话中的画像漂移问题，促使研究转向记忆机制。2023-2024年，LLM 的普及使得 ProCoT 和 PPDPP 等策略规划方法成为可能，但同时也引入了幻觉与策略短视的新约束。2025-2026年，研究进入闭环进化期，PAL、MoCoRP 解决显式对齐，AT-GRPO、UP-NRPA 解决长期价值，MADS、SEAD 解决数据稀缺，当前形态呈现出“动态在线个性化”与“闭环自我进化”并存的格局。

**如果用一个核心问题概括该领域，那便是：如何在资源受限与隐私约束下，构建能够动态追踪用户偏好演变、显式建模画像-语境逻辑关系，并实现长期目标价值最大化的闭环个性化对话系统。**

## 2. 方法体系

- 2018：Persona-Chat——奠定静态画像对话生成基础

- 2020：Ask-an-Expert (AnE)——开启基于LLM的对话策略规划

- 2021：BoB——解决人设注入导致的回复僵硬问题

- 2023：Proactive Chain-of-Thought (ProCoT)——揭示大模型在主动对话中的潜力

- 2025：MoCoRP——显式建模人设与响应的NLI关系

- 2025：MADS——通过多智能体自博弈生成多样化说服数据

- 2026：AT-GRPO——解决强化学习中短视偏差问题

- 2026：UP-NRPA——实现复杂场景下的实时策略优化

这条时间线勾勒了该领域方法演进的代表性节点：从 2018 年的 Persona-Chat 奠定该领域方法基线，经 2020 年 Ask-an-Expert (AnE) 的推进，到 2026 年的 UP-NRPA 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 人设一致性生成

人设一致性生成旨在解决回复与人设不一致的问题，核心在于显式建模人设与响应的逻辑关系。早期方法如 BoB 采用过采样和基于蕴含的过滤机制，在生成后阶段维护一致性，解决了早期人设注入导致的回复僵硬问题。然而，这种方法仍依赖生成后的修正，未能从根本上解决生成过程中的对齐难题。

PAL（Li et al., 2025, P2）针对这一局限，提出两阶段训练方法，包括人设感知学习和人设对齐，利用语义级人设对齐作为优化目标。在推理阶段，PAL 引入“选择后生成”策略，先从候选回复中筛选出与人设最匹配的选项，再进行最终生成。该方法放弃了简单拼接的低成本，换取了高一致性，但代价是增加了推理阶段的计算开销，且依赖高质量的人设描述。

MoCoRP（Lee et al., 2025, P4）则从另一个角度切入，显式建模人设句子与目标响应之间的自然语言推理（NLI）关系。其核心架构基于 BART 编码器-解码器，采用迭代两阶段训练策略：首先在 NLI 数据集上预训练以捕捉关系预测能力，然后在人设对话数据集上微调。MoCoRP 引入了关系预测任务，使模型能够理解人设句子是蕴含、矛盾还是中立于响应。这种方法无需额外的人工标注关系数据，即可通过 NLI 专家自动获取监督信号，解决了人设-响应关系模糊导致的生成不一致问题。

PPA（P20）针对多会话对话生成中人设一致性难以维持的问题，提出了一种延迟人设接地的两阶段生成框架。与传统预对齐方法不同，PPA 首先生成基于对话上下文的通用响应，然后利用该响应检索相关的人设记忆，最后通过重构步骤将人设信息融入初始响应。这种“先生成后对齐”的策略避免了在人设事实被盲目注入时导致的回复僵硬或语境尴尬，实现了更自然、多样的回复。其核心创新在于反转了检索与生成的顺序，使模型能够针对其意图输出进行目标对齐。

GRAG（Liu et al., 2026, P10）则面向资源受限场景，提出通用响应增强生成框架。该方法利用强预训练 LLM 作为辅助信号源，通过上下文学习在推理时创建有用的学习信号，而非依赖精心策划的外部知识库。GRAG 的核心思路是解耦接地和个性化，利用 LLM 生成的通用响应作为基础，再通过增强机制注入用户特定属性。这种方法降低了对大规模领域专家数据收集的依赖，提高了部署的经济性，但代价是推理时延迟增加，且效果受限于基础 LLM 的上下文学习能力。

### 2.2 目标导向策略优化

目标导向策略优化聚焦于招聘、咨询等任务型场景，旨在提升目标达成率与长期对话价值。早期方法如 AnE 利用提示工程引导 LLM 提供专家建议，开启了基于 LLM 的对话策略规划新范式。然而，这种方法往往优化即时回复质量而忽视长期对话价值，导致在谈判或说服场景中成功率低。

DMCRL（P15）提出动态多维一致性优化强化学习框架，针对目标导向主动对话系统，通过优化响应与用户画像、对话历史、领域知识及子目标之间的一致性，提升了对话的连贯性和任务成功率。该方法解决了传统方法忽视这些不一致导致对话中断或任务失败的问题，但代价是多维一致性评估的计算复杂度和奖励函数设计的难度。

AT-GRPO（Peng et al., 2026, P7）旨在解决现有个性化对话方法对预收集用户数据的过度依赖和强化学习中短视偏差的问题。其核心设计思路是整合在线个性化与双智能体博弈范式，用户智能体通过风格模仿和主动终止构建动态环境，对话智能体通过 AT-GRPO 优化长期对话价值。AT-GRPO 将对话轨迹重解释为树，并引入自适应观察范围，早期阶段使用较大范围支持话题探索，后期阶段使用较小范围促进对话维持，从而将滚动预算从指数级降低到多项式级。这种方法提升了样本效率和鲁棒性，实现了无需先验用户数据的在线个性化，但代价是树状搜索的计算开销和自适应范围调参的复杂性。

UP-NRPA（Wang et al., 2026, P9）基于用户画像的嵌套滚动策略适应，整合用户建模与在线搜索算法，通过角色扮演的用户模拟器提供反馈，在不依赖离线强化学习训练的情况下，实现复杂场景下的实时策略优化。UP-NRPA 首先构建结构化用户画像，驱动用户模拟器，然后在 NRPA 规划器中采用嵌套搜索机制，Level 2 初步选择策略，Level 1 通过蒙特卡洛模拟进行多轮完整对话模拟并更新策略分布。这种方法解决了离线方法难以适应新用户策略的问题，提升了谈判和说服场景下的目标达成率，但代价是在线搜索的计算开销和用户模拟器保真度的依赖。

PRINCIPLES（P21）利用合成策略记忆，通过离线自博弈模拟提取可复用的对话原则，解决预定义策略覆盖有限和偏好偏差问题。PRINCIPLES 利用 LLM 生成多样化模拟对话，通过摘要和评估模块提炼出高质量策略原则，并基于检索增强生成在推理时应用这些原则。这种方法为资源受限场景下的主动对话代理提供了高效策略规划方案，但代价是原则提取依赖模拟数据的质量，且检索准确性影响最终性能。

### 2.3 拟人化交互闭环

拟人化交互闭环研究包含记忆、关系及多轮弧线的拟人化对话系统，通过闭环框架整合生成、可执行评估与偏好对齐，实现高保真的人类模拟交互。这一路线的核心在于将人设、场景、记忆和调度视为运行时状态，而非扁平的风格提示。

MADS（Li et al., 2025, P1）基于多智能体自博弈模拟生成多样化说服数据，通过元指令、模拟、优化闭环流程，低成本高保真地建模用户交互，解决了冷启动场景下真实用户数据稀缺的问题。MADS 包含用户智能体、对话智能体和优化智能体三个模块，用户智能体定义结构化用户画像，对话智能体进行多轮交互，优化智能体通过摘要、评估和进化子模块自动化对话标注和提示精炼。这种方法降低了高保真用户交互建模的成本，提升了说服策略的丰富度，但代价是模拟过程计算密集，且依赖优化智能体的评估准确性。

AnthroDial（Liu et al., 2026, P11）提出闭环框架用于拟人化对话生成、评估和偏好对齐，将人设、场景、记忆和调度视为运行时状态，通过行为评估和偏好对齐，实现了符合特定关系和媒介约束的高保真人类模拟交互。AnthroDial 利用 LLM 作为裁判进行行为评估，移除无效样本，并通过 SFT 和 RL 进行偏好对齐，以优化严格拟人化接受度。这种方法解决了传统聊天机器人过度解释、助手姿态僵化和社交不合理的问题，但代价是评估和训练流程复杂，且依赖高质量的行为定义。

NormGenesis（P19）通过示例引导的社会规范建模和违规恢复，实现多文化对话生成，旨在解决低资源语言中文化语用退化问题。其核心设计思路是引入违规到解决（V2R）对话类别，捕捉说话者如何通过语境适当的修复从规范违规中恢复，从而建模语用动态交互。NormGenesis 利用语义相关示例进行迭代精炼，确保文化对齐而无需大规模人工标注，并构建了包含 10,800 个多文化对话的数据集。这种方法提升了模型在跨文化场景下的社会适当性和语用能力，特别是处理敬语使用和角色动态，但代价是示例选择对文化相关性敏感，且多语言数据构建复杂。

### 2.4 个性化评估基准

个性化评估基准旨在系统性地衡量模型在复杂场景下的个性化能力，特别是针对隐性个性化和多模态人设理解。这一路线的出现源于早期评估指标（如 BLEU、C-score）难以量化个性化程度与用户偏好匹配度的问题。

IP-Dialog（P23）设计了高效可控的合成数据方法论，构建了包含隐式用户属性的对话基准，并提出了基于因果图的评估框架，首次系统性地评估了大语言模型在对话系统中的隐式个性化能力。IP-Dialog 通过迭代构建用户历史，每轮对话细化以反映单一用户属性，确保数据的可控性和多样性。评估框架包含四个主要指标，衡量属性感知和基于属性的推理能力，并提出了五种因果图来模拟 LLM 在 IP 任务中的推理路径。这种方法为理解 LLM 如何从对话上下文中推断用户身份并据此调整行为提供了重要的实证基础，但代价是合成数据可能无法完全覆盖真实世界的复杂性和噪声。

LongMP-Bench（P17）构建了多模态长期对话人设理解基准，联合考虑长期交互、多模态输入和动态人设，评估模型在追踪人设演变和整合多模态线索方面的能力。LongMP-Bench 提供了包含人设变化类型和数量的多样化测试集，评估模型在保持身份一致性的同时适应变化的能力。其关键技术模块包括基于图像的人设生成和基于事实级 RAG 的检索增强，以支持多模态上下文理解。该基准揭示了现有模型在处理多个人设变化和复杂多模态输入时的局限性，如身份混淆和信息丢失，填补了动态多模态人设评估的空白。

D2PCM（P14）设计了基于自我参照效应的多轮对话数据集，引入个性化上下文记忆机制，模拟人类记忆过程，确保只有符合用户特征的记忆更可能被检索。D2PCM 基于大五人格理论构建 32 种基础原型，通过查询生成、记忆生成与采样、响应生成和奖励推导的循环生成对话。这种方法解决了传统 RAG 方法在全局记忆池中进行相似度搜索时忽略用户个性化偏好问题，提升了记忆对话的真实性和个性化程度，但代价是记忆生成过程复杂，且依赖准确的人设建模。

P-MultiWOZ（P22）探索了大语言模型是否具备将对话个性化到不同代际风格的隐式知识。其核心设计思路是利用 MultiWOZ 2.2 数据集，通过 LLM 生成符合特定代际沟通风格的对话，并辅以人工标注验证风格对齐度。P-MultiWOZ 涵盖了预订酒店、餐厅和交通等多个领域，强调在任务导向对话中用户特定语言特征的体现。这种方法揭示了不同代际风格在 LLM 生成对话中的可区分性，特别是 Gen Z 风格具有较高的识别可靠性，而相邻代际间存在风格重叠，为研究沟通风格如何影响对话系统有效性提供了独特视角。

### 2.5 垂直领域数据构建

垂直领域数据构建面向心理咨询、餐饮服务及推荐系统等垂直领域，旨在增强模型在特定场景下的共情、推荐及个性化服务能力。这一路线的核心在于解决真实数据稀缺、隐私限制和静态语料库时效性差的问题。

AuraDial（P12）构建了大规模中文 AI 心理咨询对话数据集，采用基于重述的合成管道生成更具人类共情特征的回复，覆盖了比现有资源更广泛的主题。AuraDial 包含超过 30 万单轮和 9 万多轮对话，利用真实世界用户查询作为指令来源，并通过 LLM 驱动的多轮对话扩展和基于重述的共情增强合成方法。这种方法解决了合成数据缺乏真实用户表达模式和共情特征的问题，提升了模型在敏感人机交互中的表现，但代价是合成过程复杂，且需验证共情回复的质量。

SEAD（P16）提出自进化智能体用于多轮服务对话，通过交互式模拟动态生成用户响应，根据智能体当前能力水平调整场景难度，解决了静态模拟数据质量低和训练信号不足的问题。SEAD 在餐厅服务推广任务中验证，通过自进化机制生成高质量对话数据，用于训练 14B 参数模型。其关键技术模块包括基于智能体能力评估的场景难度动态调整、多轮对话模拟和基于 GPT-5.1 的多维评估。这种方法为垂直领域服务对话代理提供了高效的数据生成和训练框架，增强了模型在复杂服务场景下的适应性，但代价是模拟和评估流程的计算成本。

STREAM（Xue et al., 2026, P8）提出面向流媒体中挖掘高价值任务导向对话的数据中心框架，利用流媒体生态系统中的实时对话数据，通过数据清洗、策略连贯性评估和专业性知识验证，挖掘包含需求挖掘、约束冲突处理和主动引导的高价值对话。STREAM 克服了专家标注成本高、真实对话隐私限制和静态语料库时间僵化的三重困境，为训练实时部署的垂直领域对话代理提供了动态、高保真的数据源，增强了模型在复杂服务场景中的战略能力，但代价是流媒体数据处理的实时性和隐私合规挑战。

### 2.6 跨任务与多领域应用

跨任务与多领域应用展示了个性化对话技术在具体场景中的落地能力。PARAN（Park et al., 2025, P5）面向食品配送评论回答系统，提出了一种双模态人设建模方法，包括显式人设和隐式人设，以在内容保真度和回复多样性之间取得平衡。显式人设通过 LLM 从评论文本中提取 14 个关键决策因素，锚定回复的事实内容；隐式人设则通过 LLM 零样本提示推断用户不可直接观察的语言和风格特征。这种方法不假设先验人设信息，而是动态推断，适用于真实世界中用户信息稀缺的场景，为在线平台自动化回复生成提供了无需额外用户数据即可实现个性化的技术路径。

Refining Text Generation for Realistic Conversational Recommendation（P13）通过直接偏好优化（DPO）提升对话推荐系统（CRS）中信息提取和推荐生成的真实性。该方法解决了现有 CRS 在短对话中过早推荐物品、缺乏真实人类对话中全面偏好 elicitation 的问题，通过 DPO 优化 LLM 生成包含推荐所需关键信息的对话摘要和物品推荐信息，确保推荐基于充分的用户偏好。这种方法为构建更真实、细致的对话推荐系统提供了技术路径，提升了用户满意度和推荐准确性，但代价是 DPO 训练需要高质量偏好数据，且摘要生成增加延迟。

Discourse Coherence and Response-Guided Context Rewriting（P18）旨在提升多方对话生成（MDG）中的话语连贯性和响应质量，解决非正式或模糊表达导致的语境干扰问题。该方法通过响应引导的语境重写，将原始对话历史重写为更连贯的标准形式，同时结合话语连贯性和响应质量进行偏好对齐。这种方法解决了现有 MDG 方法忽视语境连贯性导致结构编码干扰的问题，为多方对话系统提供了提升语境理解和生成质量的新范式，增强了对话的自然性和连贯性，但代价是重写过程增加计算开销，且偏好数据构建复杂。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

显式建模画像与回复之间的逻辑关系（如 NLI 关系）比简单的拼接更能提升画像一致性，这一共识在多个基准上被反复验证：PAL 的 84.1% NLI Acc 与 MoCoRP 的 82.3% 均大幅超越早期拼接方法。与此相关的另一个共识是，大语言模型在单轮对话中表现优异，但在多轮、长程个性化对话中面临上下文遗忘和策略短视的挑战，检索增强生成（RAG）和记忆机制是解决这一问题的关键技术路径，PPA 和 D2PCM 在多会话场景下的优势支持了这一观点。

### 3.2 观点分歧

显式画像注入与隐性个性化推断之间的分歧是领域内的根本争论。显式路径依赖预收集的用户画像，通过 NLI/对比学习显式对齐，可控性强，一致性高；隐性路径无需显式档案，仅通过对话历史推断用户属性，适应性强，隐私友好。现有证据偏向隐性，因真实场景中用户数据稀缺且动态变化，显式方法难以部署。但隐性方法的推断准确性缺乏金标准验证，现有基准（IP-Dialog）依赖合成数据，存在分布偏差。这一分歧的背后，是另一个更根本的争论：LLM-as-a-Judge 与人类评估的可靠性。LLM 评估高效、可扩展，但存在位置偏差、奖励黑客及主观性风险；人类评估客观、准确，但昂贵。现有证据显示两者相关性高但非完全一致，在行为一致性评估中，LLM 表现较好，但在细粒度风格/文化规范评估中，人类评估更可靠。

### 3.3 其他开放问题

最紧迫的工程问题是高保真用户模拟器的构建，现状是模拟器的分布保真度与终止行为真实性不足，关键困难在于模拟偏差风险，研究路径包括基于 RL 的用户代理训练与链式意图评估协议。最根本的研究问题是直接个性化指标的开发，现状是缺乏统一的金标准，关键困难在于个性化程度与用户偏好匹配度的量化，研究路径包括结合用户反馈的强化学习奖励模型。已知的是显式对齐与 RAG 记忆的有效性，争议的是显式与隐性路径的优劣以及 LLM 评估的可靠性，未知的是个性化金标准的建立与跨文化社会规范的细粒度建模。发展趋势是从“模拟人类”到“理解人类”，从“静态画像”到“动态认知”。

## 4. 总结与展望

个性化对话生成领域的核心矛盾在于静态画像的确定性与动态交互的不确定性之间的张力。早期研究通过显式对齐解决了画像一致性问题，但长程对话中的漂移与遗忘、目标导向对话中的策略短视、以及隐性个性化的评估缺失，构成了当前研究的三大瓶颈。这些瓶颈源于 LLM 上下文窗口的扩展使得长程记忆成为可能但同时也暴露了遗忘问题，以及合成数据技术的成熟使得高保真用户模拟成为解决数据稀缺的主要手段。

未来可能突破的方向包括：开发直接个性化指标以替代多样性等间接代理指标，结合用户反馈的强化学习奖励模型量化个性化程度；探索多模态人格理解与长期对话中的人格演化追踪，利用多模态大模型微调与记忆增强机制解决跨模态对齐与长程记忆管理问题；提升小参数模型在资源受限环境下的个性化对话能力，利用大模型生成通用响应作为结构脚手架或知识蒸馏。对进入者最值得做的一件事是构建一个统一的、基于因果图的隐性个性化评估基准，以解决当前评估缺乏金标准的问题，为后续研究提供可靠的验证手段。
