# A Survey of Context Compression for Large Language Models ｜大模型上下文压缩方法综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Context%20Compression%20for%20LLMs)

## 导读

大模型上下文压缩（Context Compression for LLMs）旨在通过精简输入序列缓解 Transformer 二次方计算复杂度与 KV Cache 内存瓶颈，其核心价值在于提升长文本推理中的有效信息利用率。早期研究以硬压缩为主线，通过剔除冗余 Token 降低推理成本，思路直接却受制于语义断裂与指代悬空问题。当多跳推理基准暴露出线性压缩在复杂依赖上的失效后，研究者转向软压缩范式，用连续向量表示换取高压缩比与语义平滑性。随着智能体（Agent）场景兴起，静态压缩无法应对动态上下文累积，研究重心转向任务感知的动态管理与结构化压缩。各路线在效率、保真度与可解释性之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从离散筛选到语义重构的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

大模型上下文压缩的兴起源于 Transformer 自注意力机制的二次方计算复杂度与 KV Cache 内存瓶颈。随着大语言模型（Large Language Models, LLMs）上下文窗口从数千扩展至百万级 Token，直接处理长文本导致推理延迟激增，且模型在处理长序列时出现“中间迷失”（Lost in the Middle）现象，即对位于序列中间的信息利用率显著下降。这一现象表明，模型的有效上下文长度远小于其最大窗口限制，压缩不仅是节省 Token 的手段，更是提升有效注意力覆盖率的必要机制。早期研究聚焦于硬压缩（Hard Compression），如 LLMLingua 系列，通过基于困惑度或分类器剔除冗余 Token，实现了初步的 Token 级精简，确立了基于信息论指标的压缩范式。

问题定义经历了从“如何缩短文本”到“如何在动态交互中维持语义连贯性”的深化。形式化地，给定原始上下文 $C$ 和查询 $Q$，压缩器 $f$ 的目标是生成压缩表示 $C' = f(C, Q)$，使得 $|C'| \ll |C|$ 且下游任务效用 $U(C', Q) \approx U(C, Q)$。这一目标包含两个核心子问题：信息保真度（Information Fidelity）与压缩效率（Compression Efficiency）。信息保真度要求压缩后保留原始关键语义、约束或事实，压缩效率则关注 Token 减少量与计算成本降低。这两个子问题存在非线性权衡：随着压缩比增加，模型性能并非线性下降，而是存在“危险区”，一旦超过阈值，语义断裂将导致任务效用骤降。此外，任务感知压缩（Task-Aware Compression）依赖于对查询或任务状态的实时感知，而评估体系的缺失制约了所有子问题的优化方向，属于横向支撑问题。

范式边界在早期工作中逐渐清晰。硬压缩保留人类可读性，适用于对可解释性要求高或需审计的场景，但易造成指代悬空和逻辑链断裂；软压缩（Soft Compression）将上下文映射为连续向量或记忆槽，实现高压缩比并保留语义完整性，但缺乏可解释性，适用于对推理延迟敏感且无需人类阅读中间状态的内部处理。KV Cache 压缩则在推理阶段动态驱逐或量化注意力机制中的 Key-Value 状态，直接降低显存占用，适用于长序列生成过程中的实时优化。这三种范式在表示粒度、适应效率与计算成本之间做出了不同取舍，构成了领域的基础分类框架。

约束演化史揭示了方法如何因应场景变化而演变。2023 年至 2018 年（注：此处应为 2023 年，原文时间线起始于 2023）奠基阶段，GIST 和 LLMLingua 分别确立了软压缩与硬压缩的技术可行性，证明了无需显式文本重构即可通过潜在表示实现高效上下文压缩。2024 年成为跨域与场景化基准的转折点，ICAE 引入上下文自编码器架构，解决了早期软压缩方法在跨层语义对齐上的不足；MemGPT 借鉴操作系统虚拟内存层级思想，将上下文管理从静态截断转变为动态记忆调度，开启了智能体记忆架构研究的新方向。2025 年，预训练与视觉语言模型（VLM）被引入，AutoCompressor 采用递归结合策略提升泛化能力，Glyph 提出视觉文本压缩范式，利用多模态模型将文本渲染为图像以突破 Token 限制。2026 年，研究重心转向细化与融合，COMI 通过边际信息增益指导压缩，TopoCompress 引入图结构捕捉长距离依赖，ZipRL 结合强化学习优化动态压缩策略，标志着领域从“通用压缩”向“场景化、结构化、可验证压缩”过渡。

**如果用一个核心问题概括该领域，那便是：在计算资源与上下文窗口受限的条件下，如何构建一种能够动态保留任务关键语义、最小化信息失真且具备可验证性的上下文表示映射机制。**

## 2. 方法体系

- 2023：GIST——通过微调模型将提示压缩为少量“gist tokens”的KV值，利用注意力掩码引导模型在压缩过程中保留关键语义信息。

- 2023：LLMLingua——提出粗到细的提示压缩框架，利用小型因果语言模型评估词元自信息量，通过预算控制器迭代移除冗余词元。

- 2024：ICAE——引入上下文自编码器架构，通过自编码损失和语言建模损失联合训练，将长上下文映射为紧凑的记忆槽表示。

- 2024：MemGPT——借鉴操作系统虚拟内存层级思想，实现LLM自主管理内存的读写操作，通过显式的外部存储接口扩展智能体的有效上下文窗口。

- 2025：AutoCompressor——采用递归结合压缩向量与子提示的策略，通过自回归建模逐步聚合上下文信息，实现端到端的软提示压缩。

- 2025：LLMLingua-2——将任务无关的提示压缩重构为词元分类任务，利用数据蒸馏从更强LLM训练小型压缩器，实现无需查询感知的通用压缩。

- 2025：ACON——针对长程智能体任务，提出优化上下文压缩策略，通过统一阈值和上下文优化机制动态管理历史轨迹与观察信息。

- 2026：COMI——提出从粗到细的上下文压缩方法，通过边际信息增益指导压缩过程，结合层语义对齐模块解决编码器-解码器框架中的跨层语义错位问题。

这条时间线勾勒了该领域方法演进的代表性节点：从 2023 年的 GIST 奠定该领域方法基线，经 2024 年 ICAE 的推进，到 2026 年的 ZipRL 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 软提示压缩机制

软提示压缩机制的核心在于将长文本映射为连续向量或潜在表示，以牺牲可解释性换取高压缩比与语义平滑性。该路线起源于 GIST（Shao et al., 2023），其通过微调模型将提示压缩为少量“gist tokens”的 KV 值，利用注意力掩码引导模型在压缩过程中保留关键语义信息，证明了无需显式文本重构即可通过潜在表示实现高效上下文压缩。然而，早期方法在跨层语义对齐上存在不足，导致高压缩比下信息丢失严重。ICAE（Ge et al., 2024）针对这一问题，引入上下文自编码器架构，通过自编码损失和语言建模损失联合训练，将长上下文映射为紧凑的记忆槽表示，实现了高保真的上下文重构，推动了软提示压缩从简单池化向深度特征学习演进。

随着压缩比进一步提升，跨层语义错位成为新的瓶颈。COMI（P49）针对 ICAE 在编码器最终隐藏状态与解码器初始注意力层之间的语义错位问题，提出了基于边际信息增益的从粗到细上下文压缩框架。该方法通过计算每个词元对整体语义贡献的边际增益来指导压缩决策，避免均匀压缩导致的关键信息丢失，并引入层语义对齐模块确保压缩表示在不同网络层级间的一致性。这种设计牺牲了一定的计算复杂度，换取了在高压缩率下更优的语义保真度。与此同时，Simple Context Compression（Feldman and Artzi, 2025, P5）重新审视了压缩 Token 的设计选择，证明均值池化在单比率和多比率训练制度下均能有效捕捉上下文语义，无需额外的压缩 Token 嵌入学习，为软提示压缩提供了基线参考，推动了领域对复杂压缩 Token 必要性的反思。

在训练效率与泛化能力方面，Cognitive Chunking（Liu et al., 2026, P16）提出基于块级因果掩码的并行化迭代压缩方法，通过模拟人类阅读的顺序性来加速压缩器学习，解决全局压缩中注意力模式学习困难的问题。该方法将上下文分割为结构化顺序段，强制压缩器按块处理信息，利用块级因果掩码在并行计算中近似串行迭代过程，既保持了结构完整性，又实现了直接全局压缩的推理速度。Latent Context Compilation（Li et al., 2026, P19）则探索了数据可移植性，通过一次性 LoRA 模块将长上下文蒸馏为紧凑可移植内存，实现压缩表示在不同模型间的共享，解决了通用压缩策略难以适应特定上下文的问题。End-to-End Context Compression（Li et al., 2026, P29）采用大规模架构搜索方法，系统评估不同压缩比率下的模型性能，建立了速度-性能帕累托前沿，为工业部署提供了可靠基准。

软提示压缩与显式抽取式压缩在 RAG 场景中呈现互补关系：软压缩用于生成嵌入向量以加速检索，而硬压缩用于保留提示中的关键证据。然而，在 Agent 场景中，软压缩的黑盒特性限制了其可审计性，促使研究者转向结构化与动态管理方法。

### 2.2 显式抽取式压缩

显式抽取式压缩基于规则、图结构或语义显著性从原文中筛选保留关键句子或片段，强调无训练依赖、可解释性及对主题覆盖度的保持。该路线起源于 LLMLingua（Jiang et al., 2023），其提出粗到细的提示压缩框架，利用小型因果语言模型评估词元自信息量，通过预算控制器迭代移除冗余词元，确立了基于困惑度和信息论指标的硬压缩范式。然而，硬压缩在多跳推理任务中易导致指代悬空（Referential Dangling）和逻辑链断裂。Referential Dangling Analysis（Hu et al., 2026, P37）系统诊断了压缩器在保留片段时导致的指代不明问题，揭示硬压缩在语义连贯性上的固有缺陷，为改进压缩算法提供了明确方向。

为克服线性压缩忽略全局语义关联的缺陷，TopoCompress（Asante and Li, 2026, P39）提出基于图线语义轨迹的长上下文压缩方法，通过构建混合图结构传播相关性，并在压缩预算下选择多样化的高相关跨度。该方法将文档分割为连贯语义跨度，利用密集和词汇查询相关性评分，结合语义加速构建混合图，通过图传播捕捉长距离依赖，显著改善了复杂推理中的信息检索。EDU-based Context Compressor（Zhou et al., 2025, P6）则提出基于基本话语单元（Elementary Discourse Unit, EDU）分解的忠实且结构化上下文压缩框架，将线性上下文转换为结构关系树，通过坐标指针锚定语义单元，提供透明且可审计的压缩过程，特别适用于需要忠实引用的法律或医疗场景。

在计算效率与稳定性方面，SALT（Mamo et al., 2026, P34）提出基于显著性感知词汇树的长上下文压缩方法，通过词汇主题而非语义主题组织文档，实现轻量级、可复用且稳定的压缩决策。该方法利用词汇重复提供稀疏且可解释的文档主题结构近似，避免遍历过程中的重复成对语义比较，特别适用于多轮对话中需要快速响应的场景。RAGP（Gao et al., 2026, P32）提出将提示压缩建模为 Lévy 游走引导的图剪枝方法，通过多层图结构捕捉局部句法依赖和全局语义关系，利用随机 Lévy 游走估计细粒度重要性，避免了标准随机游走在密集局部邻域中的陷阱。Hybrid Graph Priors（Zhou et al., 2026, P23）则提出无训练 LLM 上下文压缩方法，利用混合图先验结合语义相似性和词汇相关性，通过图中心性排序句子以保留关键证据，推动了经典 NLP 技术在 LLM 时代的复兴。

显式抽取式压缩与软提示压缩在可解释性上形成鲜明对比：前者保留人类可读性，便于审计与调试，后者则通过连续表示实现更平滑的语义保留。在 Agent 场景中，显式压缩的静态特性难以应对动态上下文变化，促使研究者将目光转向智能体上下文管理。

### 2.3 智能体上下文管理

智能体上下文管理针对长程智能体任务，研究动态上下文压缩、记忆分层、工具调用历史管理及基于强化学习的上下文优化策略。该路线起源于 MemGPT（Packer et al., 2024），其借鉴操作系统虚拟内存层级思想，实现 LLM 自主管理内存的读写操作，通过显式的外部存储接口扩展智能体的有效上下文窗口，将上下文管理从静态截断转变为动态记忆调度，解决了长程智能体任务中上下文溢出问题。ACON（Kang et al., 2025, P2）针对长程 LLM 智能体，提出优化上下文压缩策略，通过统一阈值和上下文优化机制动态管理历史轨迹与观察信息，区分历史压缩和观察压缩，分别针对智能体行动历史和工具观察结果设计压缩策略，显著提升了智能体在复杂任务中的准确性和效率。

随着任务复杂度增加，静态压缩策略难以适应动态变化的上下文。ZipRL（Hu et al., 2026, P27）提出自适应多轮上下文压缩框架，结合后见之明响应重放机制，通过强化学习优化压缩策略以最大化任务效用，解决静态压缩在动态智能体任务中的适应性不足。该方法引入主动压缩机制，基于文档-查询相关性动态确定压缩级别，利用后见之明响应重放通过优势重塑增加奖励密度，优化平均分数。ContextBudget（Wu et al., 2026, P20）提出预算感知的长程搜索智能体上下文管理方法，通过显式集成预算信号实现动态权衡，在保留原始上下文保真度和调用激进摘要之间取得平衡，将上下文管理建模为预算约束优化问题，根据剩余上下文预算动态调整压缩策略。

在自主性与稀疏注意力方面，Active Context Compression（Verma, 2026, P13）提出自主记忆管理框架，通过“锯齿”模式上下文更新机制，将单调递增的日志转换为周期性摘要，解决长程智能体任务中的上下文污染问题。GSA（Mao et al., 2026, P22）提出通过 Gist 稀疏注意力实现可学习压缩和选择性展开的框架，将压缩转化为路由机制，先压缩再选择性展开相关细节，解决长上下文依赖结构非均匀密集的问题。SUPO（P42）提出基于摘要的多轮 RL 训练上下文管理机制，通过定期压缩工具使用历史为简洁 LLM 生成的摘要，扩展 RL 训练超越固定工作上下文长度，稳定优化并鼓励增加工具使用行为。PAACE（Yuksel, 2025, P8）提出计划感知的自动化智能体上下文工程框架，通过下一 k 任务相关性建模、计划结构分析和指令共精炼，优化 LLM 智能体的演化状态，解决多步计划感知推理中的上下文管理问题。ACE（Liao et al., 2026, P31）提出可插拔自适应上下文弹性化框架，作为外部包装器集成到现有智能体推理循环中，无需修改动作空间、消息流或训练，适应多种智能体框架，提供统一的上下文管理接口。

智能体上下文管理与 RAG 场景优化在动态性上具有共性，但前者更侧重于长程任务中的记忆连贯性，后者则关注实时查询下的检索精度。随着场景多样化，领域特定压缩与视觉文本压缩成为新的研究热点。

### 2.4 视觉文本压缩

视觉文本压缩探索将长文本渲染为图像或利用视觉语言模型进行压缩的新范式，分析视觉模态在长上下文处理中的效率与保真度权衡。该路线起源于 Glyph（Cheng et al., 2025, P4），其提出通过视觉-文本压缩扩展上下文窗口的范式，将长文本渲染为图像并利用多模态大模型进行理解，实现 3-4 倍的上下文扩展，突破传统基于 Token 的上下文限制。该方法利用视觉模态的高密度信息承载能力，通过 LLM 驱动的渲染搜索优化图像布局，包括页面大小、字体样式和颜色等参数，以最大化信息密度。LongCodeOCR（Zhong et al., 2026, P15）提出针对长上下文代码的视觉压缩框架，将代码渲染为压缩的二维图像序列供视觉语言模型处理，保留全局视图以避免过滤导致的依赖断裂，特别适用于仓库级代码任务。

在评估方面，VTCBench（Zhao et al., 2025, P7）提出评估视觉语言模型在视觉文本压缩下长上下文理解能力的基准，设计视觉 NIAH 任务，提供密集文本图像作为上下文，测试模型在视觉压缩场景下的检索和推理能力，揭示视觉模态在长上下文处理中的潜力和局限。Text or Pixels（P51）提出评估 LLM 在视觉文本输入下效率和理解能力的框架，通过 LaTeX 基于的排版管道将长上下文渲染为图像，比较文本和混合输入模式的 Token 使用率和准确性，定义压缩率指标，量化视觉输入相对于文本输入的 Token 节省，揭示视觉模态在长上下文处理中的效率优势。

视觉文本压缩与软提示压缩在压缩载体上形成互补：前者利用视觉 Token 的高密度特性突破文本窗口限制，后者则通过连续向量表示实现语义平滑。然而，视觉压缩依赖多模态模型的 OCR 和图像理解能力，存在模态鸿沟，细粒度语义可能丢失，因此其适用性仍受限于多模态模型的能力边界。

### 2.5 领域特定压缩与 RAG 场景优化

领域特定压缩面向代码、金融、医疗等垂直领域，研究保留领域特定结构的定制化压缩方法与评估基准。CodePromptZip（P50）提出针对代码 RAG 任务的代码特定提示压缩方法，通过类型感知、优先级驱动的策略构建代码压缩数据集，根据代码符号、调用、标识符和结构类型分配不同的移除优先级，保留代码结构完整性，解决通用压缩方法在代码依赖关系保持上的不足。MedTPE（Zhu et al., 2026, P24）提出针对临床预测任务的基于词元对编码的无损压缩方法，通过识别高频共现医疗词元对形成统一 TPE Token，并优化词汇表以保留依赖子词，解决医疗文本中专业术语分散导致的压缩失真。Information Fidelity Framework（Lee et al., 2026, P30）提出针对金融分析的 LLM 压缩信息保真度评估框架，定义源相对决策保留作为信息保真度，衡量压缩文本诱导的决策模型信念与原始源信念的接近程度，揭示压缩导致的决策翻转问题。Lossless Prompt Compression（de Campos et al., 2026, P21）提出通过字典编码和上下文学习实现无损提示压缩，针对重复文本数据，生成压缩文本和字典，确保 LLM 分析压缩表示产生与原始文本等效的输出，特别适用于系统监控和流程挖掘。RepoDistill（P43）提出通过压缩感知预算分配和政策优化蒸馏仓库知识的方法，针对代码仓库任务，利用 MMR 策略选择块，确保压缩上下文覆盖更多多样逻辑面，解决函数内冗余稀释模型注意力的问题。TAAC（Johnson, 2026, P17）提出任务感知自适应压缩算法，通过估计信息密度和预测质量损失，动态调整压缩比率，解决固定比率压缩在不同任务类型上的性能差异。Context Minimization（P44）提出针对资源受限文本分类的上下文最小化方法，通过优化语言特征组合，平衡性能-效率权衡，利用位置、句法、语义和统计特征压缩上下文。RiPRA（P45）提出通过相关性感知位置资源分配实现无训练 LLM 上下文扩展的方法，通过调制位置分辨率基于 Token 相关性景观，同时尊重位置预算，解决现有无训练策略内容无关的缺陷。

RAG 场景优化针对检索增强生成场景，研究查询感知的在线压缩、多步 RAG 状态管理及工具模式压缩，以平衡检索精度与推理成本。OSCAR（P48）提出在线软压缩方法，将文档-查询对映射为嵌入 Token，通过查询条件化的压缩器实现动态上下文缩减，解决离线压缩无法适应实时查询变化的问题。AttnComp（P41）提出注意力引导的自适应上下文压缩方法，基于 LLM 内部注意力模式动态调整压缩率，解决固定压缩率导致的相关信息欠压缩或过压缩问题。Query-Conditioned Selector（Liu et al., 2026, P18）提出从查询条件选择器视角重新思考 RAG 中的软压缩，将编码器视为全上下文压缩器，忽略检索文档中的冗余和高分辨率压缩的实际限制，通过查询条件选择器动态选择相关上下文段，提升压缩效率。Adaptive Compression for Edge-based RAG（Feric et al., 2026, P38）提出针对边缘 RAG 的自适应压缩方法，利用 LLMLingua-2 作为代表性压缩器，通过连续比率参数扫描测量生成节省、压缩器开销和答案质量之间的权衡，解决边缘设备上的计算和能量约束。ArcAligner（Li et al., 2026, P12）提出针对 RAG 中压缩上下文嵌入的自适应递归对齐器，通过强制层级强制对齐上下文槽和启用自适应递归对齐，提升压缩嵌入的可用性。Control Under Compression（Hou and Yang, 2026, P35）提出工具使用智能体在压缩下的可靠性前沿研究，分析系统侧上下文作为运行时控制规范，评估压缩对工具调用、参数形成和动作禁止的影响，揭示压缩导致的控制义务脆弱性。

领域特定压缩与 RAG 场景优化在任务感知性上形成互补：前者针对垂直领域的结构特性进行定制化压缩，后者则关注实时查询下的动态适配。两者共同推动了上下文压缩从通用工具向场景化系统组件的演进。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域共识认为，长上下文推理面临计算成本与内存的双重瓶颈，压缩是提升 LLM 部署效率的必要手段，且“Lost in the Middle”现象表明模型无法有效利用长上下文中的中间信息，压缩通过突出关键内容可缓解此问题。这一共识在多个基准上被反复验证：TopoCompress 在 HotpotQA 的 51.37 与 COMI 在 Natural Questions 的 55.00 均大幅超越基线，表明压缩不仅节省 Token，更提升了有效信息利用率。与此相关的另一个共识是，任务感知或查询条件的压缩策略优于任务无关的通用压缩，能更好地保留任务相关语义。OSCAR 在 RAG 场景中的查询条件化压缩与 ACON 在 Agent 场景中的动态阈值管理均证明了这一观点，其性能优势源于对特定任务关键信息的精准保留。

### 3.2 观点分歧

硬压缩与软压缩的可解释性-保真度权衡是领域主要分歧之一。硬压缩派强调审计性与可调试性，认为黑盒压缩在高风险领域不可接受；软压缩派则强调语义完整性与高压缩比，认为离散操作必然导致语义断裂。现有证据偏向软压缩在复杂推理任务上的性能优势，如 COMI 在 2WikiMQA 的 50.00 优于 SALT 的 47.00，但硬压缩在需要引用原文的场景中不可替代。这一分歧的背后，是另一个更根本的争论：静态离线压缩与动态在线管理的适用边界。Agent 基准上动态管理方法（ACON 65.00）显著优于静态基线，但在简单 RAG 任务中，静态压缩的延迟优势明显。定输赢的实验需测量端到端延迟与多轮一致性，而非单轮准确率，而现有证据缺乏在资源受限环境下的统一验证。

### 3.3 其他开放问题

最紧迫的工程问题是边缘与资源受限环境下的压缩开销。压缩过程本身引入的延迟和计算成本可能抵消推理加速收益，当前尝试包括轻量级压缩器与并行化压缩，但缺乏在低带宽、低算力设备上的统一基准。最根本的研究问题是压缩后的信息保真度与可靠性。压缩过程中可能引入语义扭曲、引用悬空和决策偏差，难点在于如何量化压缩对下游任务决策的影响并建立可验证的保真度指标。Context Codec 与 SemanticZip 提出的承诺级验证框架提供了初步路径，但尚未形成标准化评估体系。已知的是压缩能提升效率，争议的是可解释性与动态性的必要性，未知的是压缩的信息论界限与跨模型泛化能力。未来趋势将依赖于在动态性、可验证性和跨模态三个维度的深度融合，最终实现从“Token 经济”到“语义经济”的转变。

## 4. 总结与展望

大模型上下文压缩的核心矛盾在于计算效率与信息保真度的非线性权衡，早期硬压缩路线因语义断裂而受限，软压缩路线虽提升保真度但牺牲可解释性，动态管理路线则解决了 Agent 场景中的上下文累积问题，但引入了额外的计算开销。当前瓶颈在于缺乏统一的评估标准与理论框架，导致方法比较缺乏公平性，且压缩过程本身的黑盒特性阻碍了其在高风险领域的部署。回扣第 1 章的核心问题，如何在动态、多模态、资源受限的环境中实现可验证、自适应且高效的语义保留，仍是领域亟待解决的挑战。

未来可能突破的方向包括：自适应压缩策略，通过基于查询相关性的动态选择与强化学习优化，解决固定压缩比无法适应不同任务信息密度的问题（P27, P20）；视觉-文本压缩范式，利用多模态模型的高密度信息承载能力突破 Token 限制，平衡信息密度与细粒度语义理解（P4, P7）；以及理论框架与信息论视角，建立压缩率与下游任务性能之间的理论界限，设计基于信息论的压缩目标（P1, P36）。对进入者最值得做的一件事是，在统一骨干网络与预训练数据的条件下，构建包含约束合规性、引用完整性与决策保真度的多维评估基准，以揭示不同压缩路线在特定场景下的真实性能边界。
