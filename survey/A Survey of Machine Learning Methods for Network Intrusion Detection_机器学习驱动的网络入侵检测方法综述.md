综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/Machine%20Learning%20for%20Network%20Intrusion%20Detection)

## 导读

网络入侵检测系统（NIDS）的核心使命是在海量流量中精准识别恶意行为，其技术演进始终受制于标注数据稀缺与零日攻击泛化需求之间的结构性矛盾。早期研究依赖手工签名规则与监督学习，虽能高效识别已知威胁，却因标注成本高企与模型泛化能力受限而陷入瓶颈。当对抗攻击与加密流量普及后，问题边界从静态分类扩展至非平稳环境下的鲁棒识别，迫使研究者转向自监督表征学习与图神经网络等数据驱动范式。各路线在表征质量、计算效率与部署可行性之间做出了不同取舍，由此形成当前自监督、混合架构与对抗防御多元并存的方法格局。本综述梳理这条从规则匹配到鲁棒表征的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

网络入侵检测系统（Network Intrusion Detection System, NIDS）作为网络安全的第一道防线，其核心任务是在持续流动的网络流量中区分良性通信与恶意活动。早期系统主要依赖基于签名的规则匹配，虽然对已知威胁识别效率极高，但面对零日攻击（Zero-Day Attack）和不断演变的威胁时显得力不从心，且规则维护成本随威胁库膨胀而急剧上升。随着机器学习（Machine Learning, ML）与深度学习（Deep Learning, DL）的引入，领域范式从规则匹配转向数据驱动的模式识别，利用卷积神经网络（CNN）、循环神经网络（RNN）等模型自动提取特征，显著提升了检测精度。然而，监督学习对大规模标注数据的依赖成为主要瓶颈，因为标注恶意流量需要专家知识且耗时，导致模型在标签稀缺场景下泛化能力受限。

问题的形式化可表述为：给定网络流量序列 $X = \{x_1, x_2, ..., x_n\}$，其中 $x_i$ 包含流统计特征或包级信息，目标是学习映射函数 $f: X \rightarrow Y$，将流量映射为良性或特定攻击类别。在理想监督设定下，模型需大量标注样本 $(x_i, y_i)$ 以最小化分类损失。但在实际部署中，标注数据 $y_i$ 极度稀缺且分布非平稳，问题因此演变为：在标签稀缺、分布漂移及对抗扰动约束下，如何构建鲁棒的时空表征并实现未知威胁的开放集识别。这一核心任务衍生出三个相互依赖的子问题：表征学习解决标签稀缺，是基础层；未知攻击检测（零日/开放集）依赖高质量表征，是应用层；对抗鲁棒性则是对表征质量的进一步约束，确保模型在恶意扰动下不崩溃。

约束条件的演化直接驱动了问题定义的变形。2016-2018 年间，研究聚焦于高精度分类，假设流量分布静态且标签充足，CNN-LSTM 等混合架构成为经典范式。2020 年前后，跨域基准暴露出监督模型在未见攻击上的性能骤降，问题定义从“如何分类已知攻击”转变为“如何在无标签/少标签下学习通用表示”，自监督学习（Self-Supervised Learning, SSL）由此引入。2021-2023 年，对抗攻击与加密流量普及，问题边界扩展至“如何在非平稳、对抗及加密环境下保持检测稳定性”，图神经网络（Graph Neural Network, GNN）与混合专家架构开始处理图漂移问题。2024-2026 年，问题进一步细化为“如何平衡精度、鲁棒性、计算效率与可解释性”，系统级防御与 LLM 检索增强成为新焦点。

这一演进并非线性替代，而是层层叠加。监督学习并未消失，而是作为半监督框架中的标记数据利用模块存在；自监督表征学习成为预训练基础，支撑下游少样本分类与异常检测；对抗防御则从被动抵抗转向主动检测与分流，形成多阶段系统。当前领域处于从“高精度分类”向“鲁棒、自适应、可解释检测”转型的阶段，研究者致力于构建能在非平稳、对抗环境下稳定运行的 NIDS，以应对日益复杂的网络威胁。

**如果用一个核心问题概括该领域，那便是：在标签稀缺、分布非平稳且存在对抗扰动的约束下，如何构建能够自动提取鲁棒时空表征并实现未知威胁开放集识别的检测系统。**

## 2. 方法体系

- 2018：BERT——通过双向Transformer重建随机掩码的文本token，学习可迁移的词嵌入表示

- 2021：GraphMAE——扩展掩码自编码器至图领域，通过重建被掩码的节点特征学习有意义的图表示

- 2022：BYOL——采用非对比自监督学习架构，通过预测器学习不变于数据增强的表示

- 2023：CNN-LSTM——融合卷积神经网络捕捉空间模式与长短期记忆网络建模时间依赖

- 2024：FGSM——基于梯度符号的快速对抗攻击方法，成为评估NIDS模型脆弱性的标准基线

- 2025：CLAN——提出基于增强负样本的对比自监督框架，利用质心距离实现零日攻击检测

- 2025：MalMoE——引入混合专家架构处理加密流量下的图漂移问题，实现免重训练的实时检测

- 2026：SCAL——提出子问题相关性感知学习框架，通过分治策略联合优化准确性、鲁棒性与可解释性

这条时间线勾勒了该领域方法演进的代表性节点：从 2018 年的 BERT 奠定该领域方法基线，经 2021 年 GraphMAE 的推进，到 2026 年的 SCAL 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 自监督表征学习

自监督表征学习路线的起源可追溯至 NLP 领域的 BERT（2018）与图领域的 GraphMAE（2021），它们通过掩码重建任务学习可迁移的表示，为 NIDS 解决标签稀缺问题提供了理论基础。2022 年，BYOL 引入非对比架构，通过预测器学习不变于数据增强的表示，无需负样本对即可提升表征鲁棒性，这一思路被 P6 系统评估并指出直接应用计算机视觉增强策略于网络流量存在局限性，提出零掩码策略作为替代。

在此背景下，CLAN（Wilkie et al., 2025, P2）针对传统自监督方法为每个样本建模独立潜在分布的缺陷，提出基于增强负样本的对比框架。该方法强制良性流量在特征空间中形成单一紧凑分布，通过缓存质心并在推理阶段计算距离实现二分类，放弃了对特定攻击类型的过拟合精度，换取了对未见攻击类型的泛化能力。GraphIDS（Guerra et al., 2025, P4）则进一步引入图结构，将网络流构建为图，通过掩码建模任务重建局部图表示，捕捉主机间空间依赖，特别适用于检测具有时空相关性的复杂攻击。时间感知时空图对比学习（Dai et al., 2026, P21）在此基础上引入时间编码，显式处理流量统计和拓扑结构随时间漂移的问题，解决了传统图对比学习忽略时序动态性的缺陷。表格表征学习评估（Butt et al., 2026, P17）则聚焦于 NetFlow 数据的表格特性，验证了不同表征学习模型在严重类别不平衡场景下的表现，强调了数据增强策略需针对网络流量特性进行定制化设计。

该路线与深度混合架构形成互补：自监督表征可作为混合架构的预训练基础，提供鲁棒的初始特征，而混合架构则在此基础上进行细粒度的模式识别。

### 2.2 深度混合架构

深度混合架构路线起源于 2023 年的 CNN-LSTM 经典范式，通过融合卷积神经网络捕捉空间模式与长短期记忆网络建模时间依赖，成为处理时空特征的基础。随着攻击复杂度增加，单一架构难以捕捉所有依赖关系，研究者开始引入图神经网络与注意力机制。GNN-RNN-Attention（Biradar et al., 2025, P7）构建了融合图神经网络、循环神经网络与多头注意力机制的混合架构，GNN 建模主机间通信的空间依赖，RNN 捕捉时间序列动态，注意力机制动态加权特征重要性，三者协同增强对 APT 等高级威胁的识别能力。

TrailGate（Zhang et al., 2025, P1）提出结合 Transformer 与 BiGRU 的两阶段框架，第一阶段利用机器学习进行特征选择与数据增强，第二阶段采用 Transformer-BiGRU 深度模型，通过置信学习机制迭代优化标签噪声，平衡了计算效率与检测精度。IntrusionX（Farabi et al., 2025, P5）在 CNN-LSTM 基础上引入松鼠搜索优化算法自动调优超参数，解决了现有 IDS 在类别不平衡和超参数敏感性问题上的不足。MalMoE（Tan et al., 2026, P11）则针对加密流量下的图漂移问题，引入混合专家架构，利用不同节点特征对漂移的稳定性实现免重训练的实时检测，放弃了单一模型的简洁性，换取了对动态网络环境的适应能力。鲁棒半监督时间入侵检测（Chattopadhyay et al., 2026, P15）结合时间自一致性与保守未标记数据利用，应对云网络中非平稳流量和对抗污染问题。

该路线与自监督表征学习的关联在于：混合架构通常依赖自监督预训练提供的鲁棒特征，而自监督方法则依赖混合架构中的编码器结构进行表示学习，二者在技术栈上紧密耦合。

### 2.3 对抗鲁棒性防御

对抗鲁棒性防御路线的兴起源于 2024 年 FGSM 等快速对抗攻击方法成为评估 NIDS 模型脆弱性的标准基线。研究发现高基线准确率的模型在对抗攻击下性能急剧下降，即“虚假冠军问题”，迫使防御机制从被动抵抗转向主动检测与分流。AMDS（Olukola and Rahimi, 2026, P12）设计了一种攻击感知的多阶段防御系统，通过集成模型分歧信号与自适应权重学习，提升对多种对抗攻击的鲁棒性，放弃了单一模型的推理速度，换取了对分布偏移攻击的细粒度防御能力。

多层集成对抗防御（Soltani et al., 2026, P13）结合生成对抗网络（GAN）和 FGSM 生成的对抗样本，通过多层集成投票机制平滑单个模型对特定对抗模式的敏感性，覆盖了从简单扰动到复杂语义保持的多种攻击类型。PLAA（You et al., 2026, P23）则从攻击者视角提出包级语义保持的对抗攻击方法，强调生成的对抗流量必须符合网络协议规则，揭示了 NIDS 在协议合规性约束下的潜在漏洞，为防御机制提供了更真实的评估基准。类别鲁棒性评估（Raj et al., 2026, P20）提出多维对抗鲁棒性评估框架，量化了不同模型架构对扰动的敏感度，强调了在对抗环境下模型选择需综合考虑基线性能与鲁棒性。

该路线与深度混合架构形成竞争与互补：混合架构通过增加模型复杂度提升基线精度，但可能增加对抗脆弱性；对抗防御则通过集成与自适应机制弥补这一短板，二者共同构成系统级鲁棒性的基础。

### 2.4 未知攻击检测

未知攻击检测路线聚焦于零日攻击与开放集识别，旨在解决传统监督模型仅能识别已知攻击的局限。在线三元组挖掘少样本检测（Wilkie et al., 2026, P18）利用三元组网络动态组装正负样本对，优化嵌入空间中的类间距离与类内距离，解决了数据不平衡与少样本学习的结合问题，提升了模型对零日攻击的检测能力。UNAD+（Alzubi and Stahl, 2026, P19）提出可解释的混合未知网络攻击检测框架，通过加权多数投票、监督细化及事后解释层增强原始 UNAD 的性能，平衡了检测性能与可解释性，解决了未知攻击检测中“黑盒”问题。

MalRAG（Luo et al., 2025, P8）提出首个基于大语言模型（LLM）检索增强的开放集恶意流量识别框架，通过构建多视角流量数据库与自适应检索算法，利用 LLM 的通用推理能力实现已知与未知攻击的细粒度识别，放弃了模型训练的封闭性，换取了知识更新的灵活性与可解释性。零日攻击对比损失（Wilkie et al., 2026, P10）提出一种新颖的对比损失函数，将零日攻击视为分布外样本，通过拟合已知类别的激活向量分布计算 OOD 分数，端到端优化分类器与异常检测器，简化了部署流程。

该路线与自监督表征学习紧密关联：未知攻击检测依赖自监督学习提供的鲁棒表征作为基础，而自监督方法则通过未知攻击检测任务验证其泛化能力，二者在技术逻辑上互为支撑。

### 2.5 模型优化与评估

模型优化与评估路线涵盖超参数调优、动态算法选择、数据预处理及模型遗忘技术，旨在优化模型部署效率、泛化能力及资源约束下的实用性。超参数调优优化分析（Tripathy and Behera, 2025, P9）系统评估了多种机器学习算法在 NIDS 中的性能，发现默认配置下性能普遍次优，通过网格搜索和随机搜索进行超参数优化，显著提升了模型在 NSL-KDD 等基准数据集上的稳定性。良性流量异质性评估（Wilkinson and Thomson, 2025, P3）通过无监督聚类分析揭示良性流量内部异质性，挑战了传统 NIDS 中将良性流量视为单一标签的假设，提出了更细致的数据建模方法。

SCAL 分治学习（Zhou et al., 2026, P16）提出子问题相关性感知学习框架，通过分治策略联合优化 NIDS 的准确性、成本、鲁棒性与可解释性，自动将学习问题分解为子问题，由轻量级模型独立训练，降低了计算复杂度，适合资源受限设备部署。XGBoost 机器遗忘（Magalhães et al., 2026, P22）研究机器遗忘技术在 XGBoost 模型中的应用，通过精确遗忘与近似遗忘策略实现特定样本影响的移除，解决了 NIDS 数据质量更新时的重训练成本问题，提升了模型更新效率。

该路线贯穿所有其他路线，为自监督表征、混合架构、对抗防御与未知攻击检测提供工程实现基础，决定了最终部署可行性。

### 2.6 跨任务与多领域应用

上述方法路线并非孤立存在，而是在跨任务与多领域应用中相互融合。在 DNS 恶意域名检测任务中，DNS-GT（Altieri et al., 2026, P14）提出基于图的 Transformer 方法学习域名嵌入，结合了自监督表征学习与图结构分析，在 TI-2016 数据集上达到 0.846 AUC，展示了图 Transformer 在特定流量类型上的有效性。在 IoT 环境中，ToN-IoT 与 BoT-IoT 数据集被广泛用于评估 NIDS 的多分类检测性能，时间感知时空图对比学习与 GNN-RNN-Attention 等方法在 ToN-IoT 上均达到 0.83 Weighted F1，表明图结构方法在 IoT 流量分析中的优势。

在加密流量检测中，MalMoE 与时间感知时空图对比学习在 CSE-CIC-IDS2018 上均达到 0.95 F1，展示了混合专家架构与时空图对比学习在处理加密流量时的互补性。在少样本检测场景中，在线三元组挖掘少样本检测、UNAD+ 与 MalRAG 在 CIC-IDS2017 上分别达到 0.9566 Macro F1、0.9831 F1 与 0.87 F1，反映了不同路线在少样本场景下的性能差异。这些跨任务应用表明，单一方法难以在所有场景下保持最优，系统级融合成为趋势。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

自监督学习在零日攻击检测上显著优于传统监督学习，这一共识在多个基准上被反复验证：CLAN 与 GraphIDS 在 UNSW-NB15 与 CSE-CIC-IDS2018 上均达到 0.958591 AUROC，大幅超越历史基线 SimSiam 的 0.906624 AUROC。该共识的边界在于，自监督方法在已知攻击的极致拟合精度上可能略逊于监督学习，且对良性流量微小扰动更敏感，需精心设计增强策略。与此相关的另一个共识是，图神经网络能有效捕捉网络流量中的空间依赖关系，在基于流的入侵检测中优于传统表格数据模型：GNN-RNN-Attention 与时间感知时空图对比学习在 ToN-IoT 与 UNSW-NB15 多分类上均达到 0.83 与 0.98 Weighted F1，验证了图结构方法在时空依赖捕捉上的优势。

### 3.2 观点分歧

对抗防御的最佳策略存在显著分歧：集成学习（AMDS）vs. 对抗训练（多层集成）。AMDS 在 CSE-CIC-IDS2018 上达到 94.2% AUC，优于多层集成的 92% Detection Rate，但指标类型不同，缺乏统一基准下的公平对比。分歧根源在于，集成学习通过模型分歧信号处理分布偏移，但计算成本高；对抗训练通过生成对抗样本提升决策边界鲁棒性，但可能过拟合特定攻击模式。这一分歧的背后，是另一个更根本的争论：开放集识别的实现路径——距离度量（CLAN）vs. LLM 推理（MalRAG）。CLAN 在 UNSW-NB15 上达到 0.958591 AUROC，MalRAG 在 NSL-KDD 上达到 0.9825 F1，但两者评测数据集和任务设置不同，缺乏直接对比。距离度量方法轻量高效，但细粒度解释能力不足；LLM 推理知识更新灵活，但依赖外部数据库且存在幻觉风险。

### 3.3 其他开放问题

最紧迫的工程问题是计算效率与实时性矛盾：复杂模型（如 Transformer、大 GNN）计算开销大，难以在资源受限设备或实时 SDN 环境中部署。SCAL 通过分治策略降低计算复杂度，但尚未在大规模实时流量下验证。最根本的研究问题是加密流量的深层语义提取：MalMoE 仅利用统计特征，缺乏对加密载荷的语义理解，而 LLM 在加密流量上的应用尚未充分探索。研究路径包括基于元数据的特征提取与基于行为模式的特征提取，但缺乏统一基准。已知—争议—未知认知图谱显示，自监督表征与图结构方法已达成共识，对抗防御与开放集识别路径存在争议，加密流量语义提取与跨域泛化仍是未知领域。

## 4. 总结与展望

机器学习驱动的网络入侵检测已从“高精度分类”进入“鲁棒、自适应、可解释”的新阶段，核心矛盾在于标注数据稀缺与零日攻击泛化需求之间的结构性张力。研究者尝试过监督学习、自监督表征、混合架构、对抗防御与 LLM 检索增强等多条路线，但核心瓶颈仍是如何在非平稳、对抗环境下构建鲁棒时空表征并实现开放集识别。这一瓶颈源于流量分布的动态性、对抗攻击的多样性与计算资源的有限性，单一方法难以在所有场景下保持最优。

未来可能突破的方向包括：一是 LLM+RAG 在 NIDS 中的深度应用，MalRAG 与 DNS-GT 共同指向利用 LLM 通用推理能力处理开放集识别，具备知识更新灵活性；二是联邦学习架构，以实现跨组织的协作模型训练并保护数据隐私，解决数据孤岛问题；三是实时自适应机制，通过在线学习与自适应阈值调整应对不断演变的威胁。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，构建包含对抗样本、加密流量与零日攻击的综合基准，以公平比较不同路线的鲁棒性与效率权衡。
