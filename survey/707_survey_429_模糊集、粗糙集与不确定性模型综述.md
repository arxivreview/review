## 导读

不确定性集合理论旨在通过数学结构量化现实世界中信息的不精确、不完整及不一致性，其核心张力在于表达力与计算复杂度之间的持续博弈。早期研究以 Zadeh 的模糊集和 Pawlak 的粗糙集为基石，分别处理边界模糊性与知识不完备性，但单一范式难以应对高维冲突数据。随着直觉模糊集与中立集的兴起，多分量语义逐步取代了二元隶属度，而 Plithogenic 集进一步引入矛盾函数，将建模粒度从元素级细化至属性值间的冲突关系。2020 至 2026 年间，领域重心转向统一框架与动态层级化扩展，Uncertain Rough Set 尝试通过抽象度域统一多范式，Type-n 结构则应对嵌套不确定性。各路线在语义丰富度、理论通用性与计算可行性之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

不确定性建模的演进并非简单的模型叠加，而是对“不确定性语义”定义的逐步细化。最初，研究者试图用数学工具量化传统二值逻辑无法描述的“灰色地带”，Zadeh 的模糊集通过隶属度函数处理边界模糊性，Pawlak 的粗糙集则基于近似空间处理知识不完备性。这两种范式各自独立发展，前者关注元素属于集合的程度，后者关注对象在不可分辨关系下的边界区域，共同构成了不确定性建模的基础层。然而，随着应用场景从静态分类转向动态决策，单一语义维度逐渐暴露出表达力不足的缺陷，促使研究向多分量与结构化方向演进。

问题形式化通常涉及在给定近似空间 $(U, R)$ 或参数集 $A$ 下，定义集合的近似算子或隶属度映射。以粗糙集为例，核心任务是通过下近似 $\underline{R}(Y)$ 和上近似 $\underline{R}(Y)$ 刻画概念 $Y$ 的边界区域 $BND(Y)$，从而量化知识不完备导致的不可判定性。在模糊决策场景中，问题则转化为构建模糊决策矩阵，通过聚合算子与去模糊化函数将模糊得分映射为实数排序。这些形式化定义揭示了子问题间的依赖关系：首先需解决单一模型对复杂语义（如冲突、犹豫）表达力不足的问题，其次需解决不同范式间缺乏统一代数结构导致的理论迁移困难，最后需解决高维、动态场景下的计算复杂度与收敛性问题。不解决表达力问题，统一框架将失去语义基础；不解决统一框架，跨模型比较与集成将缺乏理论支撑。

约束演化史清晰地展示了方法如何因应约束变化而演变。2010 年代，直觉模糊集与中立集（Neutrosophic Set）的兴起引入了犹豫度与真/假/不确定三元组，突破了二元隶属度的限制，解决了传统模型无法区分“未知”与“矛盾”的问题。随后，Plithogenic Sets 的提出通过引入属性值间的矛盾函数，进一步细化了多属性冲突信息的表达，标志着建模粒度从元素级向属性值间的转移。2020 至 2026 年，领域进入“统一框架”与“动态扩展”阶段，研究重心从单一模型的构建转向多范式的融合与层级化扩展。Uncertain Rough Set 通过泛化隶属度域尝试统一 Pawlak、模糊及中性粗糙集，而 Type-n 与 Iterative MultiPlithogenic 集则通过递归结构应对嵌套不确定性。当前形态表现为语义精细化与框架统一化并行，核心矛盾在于如何在保持高表达力的同时，解决计算复杂度与实证验证的瓶颈。

**如果用一个核心问题概括该领域，那便是：如何在保持计算可行性的前提下，构建一个能够统一描述边界模糊、知识不完备、属性冲突及层级嵌套等多维不确定性语义的通用代数框架，并实现其在复杂决策系统中的鲁棒应用。**

## 2. 方法体系

- 1999：Soft Set——参数化集合族，解决模糊集参数缺失问题

- 2026：GraphicSoft Set——引入图结构，编码属性间兼容性约束

- 2026：Plithogenic Set——引入矛盾函数，显式建模属性值冲突

- 2026：Uncertain Rough Set——抽象度域统一多范式粗糙近似

- 2026：UMCDM Framework——统一模糊/中性决策的数学基础

这条时间线勾勒了该领域方法演进的代表性节点：从 1999 年的 Soft Set 奠定该领域方法基线，经 2026 年 GraphicSoft Set 的转折，到 2026 年的 Uncertain Rough Set 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 软集理论扩展

软集理论起源于对模糊集参数选择主观性的反思，Molodtsov 于 1999 年提出的 Soft Set 通过参数化映射将属性集合关联到宇宙集的子集，为处理不完全信息提供了结构化框架（Molodtsov, 1999）。这一范式假设参数相互独立，适用于多属性决策中参数缺失的场景，但无法表达参数间的交互关系。针对这一局限，GraphicSoft Set 将图结构 $G=(V,E)$ 引入软集，定义从子图到宇宙集子集的映射，通过边集编码属性间的兼容性与约束关系（Fujita and Smarandache, 2026, P1）。该方法的创新在于突破了参数独立假设，增强了模型对复杂关系数据的建模能力，但代价是图结构的构建需额外领域知识，且子图枚举计算量大。与模糊集相比，软集放弃了隶属度的连续性，换取了参数选择的离散化与结构化，更适合处理具有明确属性依赖关系的决策场景。

### 2.2 广义集合理论

广义集合理论致力于扩展单一隶属度的语义空间，从直觉模糊集到中立集，再到 Plithogenic 集，逐步引入犹豫度、真/假/不确定三元组及矛盾函数。Plithogenic Set 通过属性值集合、隶属度函数及矛盾函数定义集合元素，将每个元素映射为多维隶属度向量，并引入对称矛盾函数度量属性值间的差异（Fujita and Smarandache, 2026, P2）。这一设计解决了中立集仅处理独立坐标、难以建模属性值间复杂冲突的问题，支持上下文感知的聚合。通过调整维度 $s$ 和矛盾函数 $t$，Plithogenic 集可退化为模糊、直觉模糊及中性集，构建了更丰富的不确定性语义空间。然而，其参数空间较大，需根据具体应用场景校准矛盾函数，计算复杂度随属性值数量指数增长。Iterative MultiPlithogenic Set 进一步引入 $n$ 阶递归结构，通过层级化隶属度映射建模多属性、多层次的复杂不确定性，适用于具有深层依赖关系的决策问题，但计算复杂度随 $n$ 指数增长，需明确各层级的语义解释。

### 2.3 粗糙集模型

粗糙集模型的核心在于基于近似空间定义下/上近似算子，早期工作局限于 Pawlak 粗糙集与模糊粗糙集。Uncertain Rough Set 基于抽象不确定性模型 $M$ 定义粗糙近似算子，通过泛化隶属度域 $Dom(M)$ 及运算律（如 t-norm/t-conorm），统一处理模糊、中性及经典粗糙集（Fujita and Smarandache, 2026, P4）。该方法将 Pawlak 粗糙集视为 $M$ 为二值格的特例，将模糊粗糙集视为 $M$ 为 $[0,1]$ 区间格的特例，实现了理论框架的统一。其核心创新在于解耦了不确定性语义与粗糙近似机制，允许在任意格结构下定义下/上近似，显著提升了粗糙集理论在复杂系统分析中的适用性与解释力。代价是计算复杂度随格结构维度增加而上升，且需预先确定合适的 $M$ 以匹配数据特性。Type-n Rough Set 则构建 $n$ 层递归粗糙集结构，参数映射至下层粗糙集，最终终止于经典 Pawlak 近似，通过层级化参数化捕捉数据中不同粒度的不确定性，适用于具有嵌套属性结构的决策表，但层级过深可能导致计算冗余及概念稀释。

### 2.4 模糊决策方法

模糊决策方法聚焦于不确定性环境下的多准则决策（MCDM），Fuzzy MCDM Framework 定义了模糊决策矩阵、权重向量、聚合算子及评分函数的输入输出结构，通过模糊算术运算传播不确定性，利用去模糊化函数将模糊得分映射为实数排序（Fujita and Smarandache, 2026, P3）。该方法形式化了模糊决策的数学约束，支持多种模糊数类型，为 TOPSIS、AHP 等具体算法提供了统一的理论框架，促进了方法间的可比性与标准化。代价是依赖模糊数的选择及去模糊化方法的合理性，不同选择可能导致排序差异。Fuzzy Weight Elicitation Methods 综述了 Fuzzy AHP、Fuzzy BWM 等权重获取方法，通过模糊判断矩阵或序关系，结合一致性检验，从专家意见中提取准则权重，解决了主观权重确定的模糊性问题。这些方法引入了模糊逻辑处理专家判断的不确定性，提高了权重结果的鲁棒性，但计算过程较为复杂，且对初始判断矩阵的质量敏感。

### 2.5 跨任务与多领域应用

上述方法在医疗诊断、供应链管理及金融风险评估等领域展现出应用潜力。Plithogenic 集在智能系统、多专家决策等场景中提供了强大的建模能力，其矛盾函数能够有效处理多源冲突数据。GraphicSoft Set 在供应链、网络分析等领域提供了更精确的参数化决策工具，推动了软集理论与图论的深度融合。Uncertain Rough Set 为多粒度、多语义不确定性环境下的知识发现提供了通用理论基石，适用于特征约简或规则归纳任务。然而，大量新型集（如 Simplicial, Sheaf Rough Set）缺乏实际应用场景验证，多数研究停留在数学定义与性质推导，缺乏在医疗、金融等领域的实证效果对比，理论应用脱节仍是主要瓶颈。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

不确定性建模需从单一隶属度向多分量（真/假/不确定/矛盾）演进，以捕捉更丰富的语义信息，这一共识在 Plithogenic 集与 Uncertain Rough Set 的理论构建中得到广泛支持（支撑证据：P2、P4）。Plithogenic 集作为更通用的框架，可通过设置矛盾函数为零或特定维度，退化为模糊、直觉模糊及中集模型，证明了多分量语义的必要性（支撑证据：P2）。与此相关的另一个共识是，粗糙集与模糊集的结合是处理混合不确定性的有效途径，Uncertain Rough Set 通过抽象度域统一了这两种范式，提升了理论迁移能力（支撑证据：P4）。然而，这一共识的边界在于，多分量演进并未解决计算复杂度问题，且不同场景下最优模型不同，单一方法难以覆盖所有场景。

### 3.2 观点分歧

统一框架的必要性是领域内的核心分歧。统一派主张通过抽象度域 $Dom(M)$ 统一所有不确定性模型，认为不同模型只是同一代数结构在不同格结构下的特例，统一有助于理论迁移与互操作（支撑证据：P4）。多范式派则认为模糊（边界模糊）与粗糙（知识不完备）本质不同，强行统一可能损失特异性，且不同场景下最优模型不同，应保持多范式并行。现有证据偏向统一派，因为 Uncertain Rough Set 成功证明了 Pawlak、模糊、中性粗糙集可作为特例统一，但缺乏在大规模复杂系统上证明统一框架优于多范式混合策略的实证对比。这一分歧的背后，是另一个更根本的争论：表达力与计算效率的权衡。Plithogenic/Type-n 集提供极高的语义表达力，但计算复杂度随维度/层级指数增长，是否适用于实时系统存在争议（支撑证据：P2、P4）。批评者指出，缺乏具体的复杂度对比实验，无法量化表达力提升带来的决策精度增益是否超过计算成本。

### 3.3 其他开放问题

最紧迫的工程问题是开发可扩展的属性约简算法与高效的多阶段近似计算机制，以解决大规模数据及流式数据中粗糙集模型计算复杂度高、难以实时处理的问题。关键困难在于层级化扩展（如 Type-n）带来的指数级复杂度，研究路径包括优化算法结构与并行计算路径。最根本的研究问题是建立统一的数学框架以连接、比较和泛化现有的模糊、粗糙、软集及中性集等不确定性决策方法，解决当前模型间关系不清、缺乏通用基准导致难以横向对比的问题。现状是理论驱动而非数据驱动，关键困难在于缺乏标准化的应用基准与公开数据集，研究路径需通过形式化统一语义与运算规则实现理论上的互操作性。已知的是多分量语义的必要性，争议的是统一框架的优越性与计算复杂度的可接受边界，未知的是新型集在特定数据分布下的最优适用边界。

## 4. 总结与展望

不确定性集合理论正经历从“语义丰富化”到“框架统一化”的范式转移，核心矛盾在于表达力的指数级增长与计算复杂度的指数级增长之间的张力。Plithogenic 集与 Uncertain Rough Set 分别代表了语义扩展与理论统一的两极，而 Type-n 结构则指向了动态层级化的未来。解决计算复杂度与实证验证的瓶颈，将是该领域从“数学玩具”走向“实用工具”的关键，回扣了如何在保持计算可行性的前提下构建通用代数框架的核心问题。

未来可能突破的方向包括：开发可扩展的属性约简算法与高效的多阶段近似计算机制，以解决大规模数据中的实时处理问题（P4、P2 共同指向）；建立统一的数学框架以连接、比较和泛化现有模型，解决理论互操作性问题（P4、P3 共同指向）。对于进入该领域的研究者，最值得做的一件事是开展面向特定数据特征（如不平衡、噪声、异构特征重要性）的应用导向案例研究，通过实证评估明确不同粗糙/模糊模型在特定数据分布下的最优适用边界，从而弥合理论与应用之间的鸿沟。
