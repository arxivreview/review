## 导读

事件抽取与关系学习（Event Extraction and Relation Learning, EERL）旨在从非结构化文本中识别事件触发词、参数及其语义关系，其核心价值在于构建知识图谱与实现机器阅读理解的基础能力。早期研究受限于规则工程与浅层特征，主要解决句子级、封闭域下的结构化信息抽取问题，思路简洁却受制于数据标注成本与泛化能力。当文档级基准暴露出事件信息跨句分布导致的上下文缺失后，研究者转向全局建模与生成式架构，用更强的上下文捕捉能力换取长程依赖的鲁棒性。随着大语言模型（LLM）的爆发，研究重心从监督微调转向零样本推理与提示工程，用通用推理能力换取对动态模式与开放域的适应性，但引入了严重的幻觉与绑定错误。各路线在推理可靠性、计算效率与结构约束之间做出了不同取舍，由此形成当前多智能体、强化学习与跨模态对齐并存的多元方法格局。本综述梳理这条从结构化预测到认知推理的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

事件抽取与关系学习的核心任务是从文本中识别事件触发词、参数及其语义关系，其形式化定义通常遵循 N-way K-shot 范式：给定事件类型集合 $\mathcal{T}$ 和参数角色集合 $\mathcal{R}$，模型需从文本 $D$ 中识别触发词 $t$，并映射参数实体 $e$ 至角色 $r \in \mathcal{R}$。早期研究假设事件信息局部且封闭，主要解决句子级分类问题，受限于算力与数据规模，范式边界严格限定在预定义模式（Schema）内的判别式预测。随着数据分布复杂化，问题定义经历了三次关键变形：从句子级扩展至文档级以解决跨句依赖，从纯文本扩展至多模态以应对信息不足，从监督微调转向零样本推理以摆脱标注依赖。

子问题间存在强依赖关系：文档级抽取是基础，解决了上下文缺失但引入了长程依赖难题；多模态抽取依赖跨模态对齐技术，解决了信息不足但引入了模态异构性带来的特征冗余与对齐冲突；零样本与关系抽取则依赖于 LLM 的推理能力与外部约束机制来抑制幻觉。这种依赖结构决定了方法演进的路径：任何单一维度的突破（如仅提升触发词检测）若缺乏其他维度的支撑（如参数绑定或关系推理），都无法构建完整的事件语义结构。范式边界也随之模糊，传统监督学习范式在低资源、开放域场景下失效，迫使领域转向利用 LLM 的通用能力，但必须解决其“黑盒”推理带来的不可控性。

2016-2018 年间，领域处于奠基阶段，以 Matching Networks 和 Prototypical Networks 为代表的度量学习方法确立了嵌入空间比较的范式，但主要局限于句子级封闭域。2020 年，RAMS 和 M2E2 等基准的出现标志着跨域与多模态转折，DEGREE 等生成式方法兴起，问题核心转变为长文本中的全局建模与跨模态对齐。2021-2023 年，G-PTLM 和 ASEE 引入 LLM 进行零样本推理，揭示了模型在复杂事件关联理解上的潜力与局限，研究重心转向提示工程与检索增强生成（RAG）。2023-2025 年，LLM-ERE 和 EventRelBench 推动了对 LLM 内部机制的可解释性分析与综合基准构建，方法细化为多智能体协作与强化学习优化。当前形态是“LLM 驱动的结构化推理”，核心驱动力在于解决 LLM 在复杂事件结构中的幻觉问题、跨模态对齐难题以及缺乏统一评估基准的挑战。

**如果用一个核心问题概括该领域，那便是：如何在缺乏显式结构约束和标注数据的情况下，利用大语言模型的通用推理能力，从多模态、长文本中准确构建具有全局一致性的复杂事件语义结构。**

## 2. 方法体系

- 2017：EventStoryLine——提出基于叙事因果链的文档级事件因果识别基准

- 2019：MAVEN-ERE——构建统一的大规模事件关系数据集

- 2020：M2E2——首个多模态事件抽取基准

- 2020：RAMS——大规模文档级事件论证抽取数据集

- 2021：G-PTLM——提出基于全局约束的零样本事件抽取框架

- 2022：DEGREE——基于生成式模型的文档级事件抽取方法

- 2025：EventRelBench——构建多类别、大规模事件关系理解基准

- 2026：UERLens——提出基于稀疏自编码器的事件关系可解释性分析框架

这条时间线勾勒了该领域方法演进的代表性节点：从 2017 年的 EventStoryLine 奠定该领域方法基线，经 2019 年 MAVEN-ERE 的推进，到 2026 年的 UERLens 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 事件关系理解与评测

事件关系理解与评测路线起源于对局部语义判别局限性的反思，早期工作如 EventStoryLine（2017）强调事件间时序与因果依赖的整体一致性，为从局部转向全局叙事结构建模提供了理论基础。MAVEN-ERE（2019）进一步构建了涵盖共指、时序、因果及子事件关系的统一数据集，解决了早期基准仅关注单一关系类型的问题。随着 LLM 的介入，LLM-ERE（2023）探索了指令微调与多智能体策略，揭示了 LLM 在复杂事件关联理解上的潜力与局限。当前前沿聚焦于可解释性与综合基准，UERLens（2026）通过稀疏自编码器（SAE）分析 LLM 激活值，利用反事实数据构建与特征干预揭示模型对特定事件关系的敏感性，其核心创新在于将模型干预与特征训练相结合，证明了内部特征能够作为事件抽取的互补信号。SVRECI（2026）则提出基于叙事一致性的三阶段文档级事件因果识别方法，通过超图传播（THP）模块基于叙事一致性目标进行结构验证，有效抑制了 LLM 建议中的噪声边。该路线与文档级抽取路线互补，前者提供全局约束与验证机制，后者提供局部特征提取能力。

### 2.2 多模态事件抽取

多模态事件抽取路线始于 M2E2（2020）基准的建立，确立了跨模态对齐与弱监督学习的研究范式。早期方法如 CAMEL（2023）通过合成数据生成与课程学习解决数据稀缺问题，但忽视了模态异构性带来的特征冗余。当前方法聚焦于解决视觉编码器冗余特征与事件抽取聚焦特征之间的冲突。ECHO（2026）提出基于多智能体协作的多模态事件超图操作框架，通过节点播种、超图构建与角色绑定的迭代细化，采用“先链接后绑定”策略稳定事件与论证间的相关性，有效减少了结构漂移。RMPL（2026）提出关系感知多任务渐进学习框架，将多模态关系抽取作为辅助任务支持事件中心表示学习，通过分阶段训练稳定多模态表示。LLM Knowledge Editing（2025）则通过多级冗余特征选择机制，利用知识编辑技术增强多模态 LLM 的事件理解能力，无需额外参数优化。CVRH（2026）引入角色语义关联建模，通过文本论证提供的判别性语义帮助模型区分图像中同一类别但不同角色的实体。该路线与文档级抽取路线竞争于计算资源，但互补于信息完整性，多模态方法依赖文档级方法提供的长程上下文，而文档级方法依赖多模态方法提供的视觉消歧信息。

### 2.3 文档级论证抽取

文档级论证抽取路线起源于 RAMS（2020）基准，强调跨句依赖与长上下文推理。DEGREE（2022）将抽取任务转化为序列到序列生成问题，提升了模型对复杂论证结构的捕捉能力。随着 LLM 的引入，Rule-Guided Extraction（2025）提出层级规则优化框架，通过迭代生成与选择最优层级规则，将细粒度的规则集成到提示中，解决了手动设计规则耗时且劳动密集的问题。HTMR（2026）提出混合令牌掩码强化学习框架，通过识别高熵与事件关键令牌优化策略更新，解决了序列级奖励与令牌级优化错位问题。REAR（2025）提出关系感知强化学习优化框架，通过联合监督微调与 PPO 算法优化事件论证抽取，利用关系抽取信号增强论证语义理解。Learning to Generate and Extract（2026）通过生成代理与抽取代理的协作，利用 LLM 生成连贯上下文及角色-论证对，为抽取任务提供合成数据支持。Multi-Document Event Extraction（2025）结合 LLM 与 SLM，通过事件组合推理阶段整合多文档中的互补信息。该路线与零样本抽取路线互补，前者提供长程依赖捕捉能力，后者提供低资源场景下的泛化能力，两者常结合使用以解决复杂文档中的零样本抽取问题。

### 2.4 零样本与开放域抽取

零样本与开放域抽取路线起源于 G-PTLM（2021），开创了利用 LLM 通用能力进行无监督抽取的先河。ASEE（2024）提出自适应模式感知事件抽取框架，结合 RAG 动态匹配事件模式，解决了固定模式在跨域场景下的僵化问题。当前前沿聚焦于解决 LLM 在未见事件类型上的幻觉与绑定错误。AEC（2026）提出多智能体编程框架，通过检索、规划、编码与验证代理协作，将事件抽取转化为代码生成任务，利用嵌套反馈循环迭代优化，有效减少了早期错误在最终事件结构中的传播。A Multimodal Text- and Graph-Based Approach（2026）利用 5Ws 框架提取无限制事件类型，并通过图结构整合文档级上下文，克服了 LLM 在长文档中因注意力稀释导致的“中间迷失”现象。该路线与文档级抽取路线竞争于标注数据依赖，但互补于泛化能力，零样本方法依赖文档级方法提供的上下文结构，而文档级方法依赖零样本方法提供的模式适应性。

### 2.5 领域基准与评估

领域基准与评估路线起源于对现有评测偏差问题的反思，REGen（2025）提出生成式事件论证抽取可靠评估框架，通过复杂匹配与 LLM 裁判机制解决精确匹配（EM）的偏差问题。SciEvent（2025）提出了一个多领域科学事件抽取基准，聚焦于识别最佳代表事件的触发器并提取关联论证。EXCEEDS（2026）提出基于 Nugget 网格建模的科学领域复杂事件抽取框架，通过词-词事件网格统一编码触发器与论证关系，解决了科学文献中高密度、复杂形式事件的结构化难题。Evaluating LLMs for Zeolite Synthesis Event Extraction（2025）通过标准化提示策略，系统评估了多种 LLM 在领域特定任务上的表现，揭示了提示策略对精确信息抽取的影响。该路线与其他路线互补，为所有方法提供统一的评估标准与数据支撑，是领域公平比较的基础设施。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

大语言模型在零样本和少样本事件抽取中展现出强大潜力，但在复杂结构推理和精确参数绑定上仍存在显著幻觉问题，需要外部约束或迭代验证机制，这一共识在约 15 篇论文中得到共同支持（支撑证据：P5、P10、P14）。多模态事件抽取中，文本与图像模态的简单拼接或弱对齐效果有限，显式的跨模态对齐机制能显著提升性能，约 8 篇论文共同支持这一观点（支撑证据：P3、P16、P20）。文档级事件抽取优于句子级，因为事件信息往往分散在多个句子中，需要全局上下文来消歧和补全参数，约 10 篇论文共同支持（支撑证据：P17、P18、P19）。传统的监督微调在提升 LLM 推理能力上存在局限，结合强化学习能更有效地优化推理轨迹和最终结果的一致性，约 5 篇论文共同支持（支撑证据：P10、P14）。事件关系抽取对于构建完整的事件知识图谱至关重要，且关系类型之间存在复杂的交互作用，需联合建模，约 6 篇论文共同支持（支撑证据：P11、P15、P17）。评估基准的不一致性严重影响了多模态事件抽取研究的公平比较，标准化评估协议是领域发展的迫切需求，约 4 篇论文共同支持（支撑证据：P7、P8、P9、P13）。合成数据生成和多智能体协作是解决零样本和低资源场景下数据稀缺问题的有效途径，约 6 篇论文共同支持（支撑证据：P1、P4、P5）。在科学和专业领域，事件抽取面临术语密集和结构复杂的挑战，需要结合领域特定的 schema 和细粒度推理策略，约 4 篇论文共同支持（支撑证据：P2、P9、P13）。

### 3.2 观点分歧

零样本事件抽取的最优路径存在显著分歧：一方主张通过多智能体生成多样化合成样本增强模型对未见类型的理解（如 Learning to Generate and Extract），另一方主张将抽取转化为代码生成或图结构操作以提升鲁棒性（如 AEC）。现有证据偏向代码化推理在结构化预测任务上更鲁棒，AEC 在 Zero-shot DEAE 上达到 59.8 F1，优于部分合成数据方法，但合成数据在多样性上占优。定输赢的实验需对比两者在极端低资源、高噪声场景下的鲁棒性，目前缺乏统一评估标准。多模态对齐机制也存在分歧：一方主张修改视觉编码器抑制冗余特征（如 LLM Knowledge Editing），另一方主张构建高阶图结构显式建模跨模态关系（如 ECHO、CVRH）。ECHO 在 M2E2 上以 54.4 F1 领先，优于 Knowledge Editing 的 51.2 F1，表明高阶结构在复杂绑定上更有效，但 Knowledge Editing 计算成本更低。定输赢的实验需评估两者在实时应用中的效率-精度权衡，场景依赖性强，新闻场景适合超图，而资源受限场景适合知识编辑。LLM 推理优化的核心也存在分歧：一方主张通过可验证奖励优化 token 级策略（如 HTMR、REAR），另一方主张通过外部代理协作与迭代修正（如 ECHO、Debate-EE）。HTMR 在 ACE2005 上达到 63.5 F1，REAR 达到 64.1 F1，均优于传统 SFT，而 ECHO 在多模态任务上表现优异。两者常互补使用，但尚未有研究明确界定其边界与最优组合。

### 3.3 其他开放问题

最紧迫的工程问题是推理成本优化与跨领域泛化，当前 LLM 推理成本高且延迟大，难以部署到实时应用，潜在路径包括知识编辑、参数高效微调和模型压缩技术。最根本的研究问题是 LLM 内部事件关系表示的可解释性与叙事一致性的形式化定义，当前模型对事件关系的推理过程是黑盒，潜在路径包括反事实评估协议和特征干预技术以揭示层间表示结构。此外，多模态动态场景下的全局一致性保持也是关键挑战，当前研究主要聚焦于静态图文新闻，缺乏对动态视频和音频事件的处理能力，潜在路径包括引入时序图神经网络和多模态大模型微调。已知的是 LLM 在复杂结构推理中存在幻觉，需外部约束；争议的是零样本路径、多模态对齐机制与推理优化核心的最优选择；未知的是 LLM 内部推理轨迹的量化优化方法与多模态时序对齐机制。发展趋势将从静态文本向动态多模态、从封闭域向开放域拓展，并逐步实现细粒度、可解释且全局一致的结构化推理。

## 4. 总结与展望

事件抽取与关系学习已超越简单的信息抽取任务，演变为考察机器认知推理能力的综合基准，其核心矛盾在于如何在保持 LLM 通用性的同时，实现细粒度、可解释且全局一致的结构化推理。从结构化预测到认知推理的范式重构，经历了从句子级封闭域到文档级长文本、从纯文本到多模态、从监督微调到零样本推理的多次转折，核心瓶颈在于 LLM 在复杂事件结构中的幻觉与绑定错误，以及跨模态对齐难题。方法演进的主线是不断引入外部约束（规则、图结构、强化学习）来弥补 LLM 内部机制在细粒度绑定上的不足，形成了多智能体、RLVR 与跨模态对齐并存的多元格局。

未来可能突破的方向包括：扩展多模态事件抽取至视频和音频模态，引入时序图神经网络和多模态大模型微调以解决跨模态时序对齐难题；提升 LLM 在细粒度跨度边界识别上的精度，通过混合令牌掩码强化学习和基于规则的跨度约束优化解决模型倾向于提取整个短语而非特定动作词的问题；建立严格且统一的多模态事件抽取评测标准，提出 STRICTEVAL 等严格评测框架以消除常见陷阱。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，系统评估多智能体协作与 RLVR 在复杂长文本上的推理稳定性，以明确两者的边界与最优组合策略。
