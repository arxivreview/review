## 导读

文本嵌入模型旨在将变长文本映射为固定长度稠密向量，其核心价值在于为检索、推荐及检索增强生成（RAG）提供语义匹配的基础设施。早期研究依赖统计特征与静态词向量，受限于上下文缺失，难以捕捉一词多义与全局语义。2018 年 BERT 确立双向注意力范式后，Sentence-BERT 通过对比学习解决了句子级表示的缺失问题，奠定了预训练-微调的基础。随着大语言模型（LLM）能力的爆发，研究重心从编码器转向解码器适配，核心矛盾变为因果注意力的局部性与嵌入任务全局语义需求之间的冲突。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前 LLM 适配、几何分析与高效部署并存的多元格局。本综述梳理这条从统计匹配到语义几何的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

文本嵌入的核心任务是将变长序列压缩为固定维度的低维稠密向量，以支持语义相似度计算。在深度学习兴起前，TF-IDF 等统计方法通过词频与文档频率量化语义，但缺乏对上下文的理解，导致一词多义和语义歧义无法解决。2013 年 Word2Vec 提出分布语义假说，通过 Skip-gram 或 CBOW 目标学习静态词向量，确立了“上下文决定词义”的基础地位，但静态向量仍无法区分同一词在不同语境下的含义。这一局限促使研究者转向上下文感知模型，2018 年 BERT 的发布成为第一个关键转折，其双向注意力机制允许模型同时关注左右上下文，通过掩码语言建模（MLM）预训练确立了编码器在语义理解上的主导地位。

问题定义随之从“词义”转向“句义”。原始 BERT 的 [CLS] 向量在句子相似度任务中表现不佳，Sentence-BERT 通过孪生网络结构微调 BERT，直接优化句子对之间的余弦相似度，确立了句子嵌入的标准训练流程。这一阶段的核心假设是：双向 Transformer 编码器结合对比学习能够充分捕获全局语义。然而，随着检索增强生成（RAG）的普及，对嵌入模型召回率的要求急剧提升，单向量表示在复杂查询和细粒度匹配上暴露出信息瓶颈。2020 年 DPR 提出稠密段落检索器，取代稀疏关键词匹配，推动了稠密检索在开放域问答中的应用；2021 年 ColBERT 引入延迟交互机制，保留 Token 级嵌入，通过 Chamfer 距离计算细粒度相关性，确立了多向量表示在检索任务中的优势地位。

2023 年 MTEB 基准的发布结束了评估标准混乱的局面，成为衡量通用嵌入模型性能的事实标准。这一标准化进程加速了模型迭代，但也暴露出单一分数掩盖模型在特定领域或场景下差异的问题。2023-2024 年出现第二个转折，随着 LLM 能力的爆发，研究重心从 Encoder-only 转向 Decoder-only LLM。核心矛盾变为 LLM 因果注意力的局部性与嵌入任务全局语义需求之间的冲突。直接复用 LLM 效果不佳，需通过双向化改造或特殊池化策略解决，但改造过程复杂且可能损失生成能力。LLM2Vec 提出移除因果掩码并引入双向注意力，证明了通过简单架构改造即可显著提升 LLM 的表示能力；E5 系列则通过指令微调增强模型对多样化任务的适应性，展示了弱监督数据在提升嵌入通用性方面的潜力。

2025-2026 年，领域进入精细化与多元化阶段。研究不再仅追求 MTEB 榜单分数，而是深入探索嵌入空间的几何性质、多语言公平性、计算效率以及嵌入的可解释性。各向异性（Anisotropy）导致嵌入向量分布过于集中，限制了相似度计算的区分度，需通过白化、去均值或几何正则化缓解。多语言嵌入模型在低资源语言上表现显著落后，且存在语言偏见，现有方法多依赖机器翻译数据，难以解决深层的语义对齐问题。高效部署方面，Matryoshka 表示学习（MRL）允许嵌入向量在不同维度截断下保持性能，旨在平衡存储成本与检索精度，但存在截断敏感性问题。

这一演进过程揭示了子问题间的依赖关系：LLM 适配是基础架构问题，不解决双向性则无法利用 LLM 潜力；几何分析是理论支撑，解释为何某些池化或训练策略有效；高效部署与多语言基准是应用约束，依赖于基础模型的质量但反过来推动基础模型的轻量化与泛化设计。从 2016-2018 年的奠基，到 2020 年跨域基准的转折，再到 2021 年预训练/VLM 的引入，直至 2023-2025 年的细化与融合，领域形态由“通用语义匹配”向“任务自适应、高效部署及结构化表示”演进。

**如果用一个核心问题概括该领域，那便是：如何在保持计算效率与部署可行性的前提下，构建能够捕捉全局语义结构且具备跨语言、跨领域泛化能力的低维稠密向量表示空间。**

## 2. 方法体系

- 2013：Word2Vec——通过Skip-gram或CBOW目标学习静态词向量，利用局部上下文预测捕捉词汇分布规律

- 2019：BERT——采用掩码语言建模（MLM）预训练双向Transformer编码器，通过随机遮盖词元并预测其身份来学习深层上下文表示

- 2019：Sentence-BERT——通过孪生网络结构微调BERT，直接优化句子对之间的余弦相似度，解决了原始BERT [CLS] 向量在句子相似度任务中表现不佳的问题

- 2020：DPR——提出稠密段落检索器，将查询和段落分别编码为稠密向量，通过内积计算相关性，取代了传统的稀疏关键词匹配

- 2021：ColBERT——引入延迟交互（Late-Interaction）机制，保留查询和文档的Token级嵌入，通过Chamfer距离计算细粒度相关性

- 2022：E5——利用大规模弱监督数据对预训练语言模型进行对比学习微调，通过指令微调（Instruction Tuning）增强模型对多样化任务的适应性

- 2024：LLM2Vec——提出将因果语言模型转换为双向编码器的方法，通过移除因果掩码并引入双向注意力，使LLM能够捕捉全局上下文信息

- 2026：UTS——提出统一拓扑签名框架，结合多种拓扑描述符来表征嵌入空间结构，并预测检索效果

这条时间线勾勒了该领域方法演进的代表性节点：从 2013 年的 Word2Vec 奠定该领域方法基线，经 2019 年 BERT 的推进，到 2026 年的 UTS 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 LLM嵌入适配

LLM 嵌入适配路线的核心在于解决因果注意力与全局语义需求的冲突。早期尝试直接复用 LLM 效果不佳，LLM2Vec（2024）通过移除因果掩码并引入双向注意力，使 LLM 能够捕捉全局上下文信息，证明了简单架构改造即可显著提升表示能力。这一方法放弃了生成能力的部分保留，换取了全局语义捕获能力的提升。随后，NV-Embed（2025）引入潜在注意力层并移除因果注意力编码，通过特定的预训练策略增强 LLM 的表示能力，在保持 LLM 生成能力的同时显著提升了嵌入性能，代表了 LLM 嵌入适配的前沿方向。

针对双向化改造的复杂性，研究者探索了无需重新训练的后处理方案。Hierarchical Token Prepending (HTP)（Ding et al., 2025, P14）通过建立多层级向后信息流，将输入文本分割为语义块并插入占位符摘要 token，在 Transformer 层间将块级隐藏状态重连到局部摘要 token，最后传播到全局摘要块。这种层级结构克服了因果注意力中信息传递受限的问题，其核心优势在于训练无关性，可直接应用于现有解码器 LLM，但实现复杂度较高。另一种路径是引入重构任务作为预训练信号。Bidirectional Reconstruction Training（2025, P50）提出在对比学习之前引入双向重构任务，通过 EBQ2D 和 EBD2Q 任务迫使模型从嵌入中重构原始文本，增强嵌入的信息保真度，解决了直接对比学习可能导致的嵌入信息丢失问题。

从零开始训练嵌入专用 LLM 是另一条激进路线。Conan-Embedding-v2（Li et al., 2025, P2）设计了包含预训练、监督微调、弱监督嵌入训练和监督嵌入训练的四阶段流程，不依赖现有 LLM 的预训练权重，而是从头构建专为嵌入优化的模型架构，支持高达 32k 的上下文长度。这种方法避免了微调现有 LLM 可能带来的生成能力与嵌入能力的冲突，提供了更纯粹的嵌入表示，但训练成本极高。相比之下，KaLM-Embedding-V2（2026, P46）结合优越的训练技术与数据策略，通过精细化的数据策展和训练配方提升模型性能，展示了数据质量与训练策略对嵌入性能的关键影响。此外，Learning to Compress（Zhang et al., 2025, P15）引入上下文压缩任务作为预训练目标，将压缩视为一种预训练信号，显著提升了长文本嵌入的语义完整性。

| 方法 | 核心机制 | 训练需求 | 主要优势 | 主要局限 |
| :--- | :--- | :--- | :--- | :--- |
| LLM2Vec | 移除因果掩码，引入双向注意力 | 需微调 | 全局语义捕获能力强 | 可能损失生成能力 |
| HTP | 层级化 Token 前置，多层级信息流 | 无需训练 | 轻量级，直接应用现有 LLM | 实现复杂，提升有限 |
| Conan-Embedding-v2 | 从头训练，四阶段流程 | 从头训练 | 纯粹嵌入表示，无生成冲突 | 训练成本极高 |
| KaLM-Embedding-V2 | 数据策展，多阶段优化 | 需微调 | 数据驱动，性能领先 | 数据工程投入大 |
| Learning to Compress | 上下文压缩预训练 | 需预训练 | 长文本语义完整性高 | 计算开销略高 |

LLM 适配路线与几何分析路线存在互补关系：适配策略决定了嵌入空间的初始几何结构，而几何分析则为优化适配策略提供了理论依据。

### 2.2 嵌入空间几何分析

嵌入空间几何分析路线旨在揭示嵌入向量分布的内在结构及其对下游任务的影响。各向异性（Anisotropy）导致嵌入向量集中在狭窄锥体内，降低了相似度计算的区分度。Unified Topological Signatures (UTS)（Rottach et al., 2025, P18）结合多种拓扑描述符来表征文本嵌入空间的几何结构，通过计算持久同调、连通性和其他拓扑不变量，生成独特的签名向量，揭示了嵌入空间的拓扑属性与下游任务性能之间的内在联系，挑战了“更大模型具有收敛表示”的假设。

针对均值池化（Mean Pooling）的有效性，Second-Order Collapse Metric (SOCM)（2026, P36）量化了均值池化过程中二阶统计量的损失，证明了 SOCM 满足一系列理想性质，为理解嵌入聚合机制提供了理论依据。SOCM 依赖于高斯分布假设，计算复杂度较低，易于集成到现有评估流程中。Compositionality Quantification（Guo et al., 2025, P4）通过信息论定义和线性加性检验，评估嵌入是否可由已知可解释表示构建，揭示了嵌入在习语和非线性结构上的局限性，推动了嵌入可解释性研究。

跨模型对齐是几何分析的另一个重要方向。mini-vec2vec（Dar, 2025, P7）假设良好训练的表示收敛于共享几何结构，通过正交变换学习两个嵌入空间之间的映射，无需监督数据，简化了跨模型对齐问题。Procrustes Bounds and Applications（Maystre et al., 2025, P11）提供了对齐误差的紧界，并提出了 Procrustes 后处理方案，将几何对齐问题转化为优化问题，提供了理论保证和实用算法。此外，Overlap and Hyperbolic Tangent Similarity（Parupudi, 2025, P3）提出重叠相似度（OS）和双曲正切相似度（HTS），解决了余弦相似度对向量幅值敏感的问题，提升了对整体语义理解的准确性。

几何分析路线与高效部署路线存在竞争关系：几何分析追求表示质量的极致，而高效部署往往通过压缩或简化牺牲部分几何结构以换取效率。

### 2.3 高效压缩与部署

高效压缩与部署路线聚焦于降低文本嵌入的计算与存储开销。Matryoshka 表示学习（MRL）允许嵌入向量在不同维度截断下保持性能，但存在截断敏感性问题。3D Matryoshka Learning (3D-ML)（Zhang et al., 2026, P28）提出三维马特罗什卡学习框架，同时优化模型参数、计算深度和表示尺寸，实现训练、推理和存储全生命周期的效率提升，为构建轻量级、高效的多语言嵌入模型提供了系统性解决方案。

针对 Transformer 二次复杂度的问题，Recurrent Language Model Embeddings（2026, P49）基于循环语言模型（如 Mamba2, RWKV, xLSTM）实现线性时间和恒定内存文本嵌入，适用于长文档和大规模部署场景。SwiftEmbed（Lansiaux et al., 2025, P12）通过预训练静态词向量表实现亚毫秒级响应，牺牲部分上下文建模能力，换取极高的推理速度和吞吐量，适用于实时性要求极高的场景。

模型合并是提升鲁棒性与效率的另一策略。EmbeddingGemma（Vera et al., 2025, P5）通过模型汤（Model Souping）技术融合不同微调混合的检查点，在少于 10 亿参数的模型中实现了与更大模型相当的 MTEB 性能。SLERP and LoRA Merging（Kabane, 2025, P17）比较了线性插值与球面线性插值（SLERP）在权重空间中的效果，发现 SLERP 能更好地保持角度结构，提升合并后模型的鲁棒性。此外，Isolation Kernel Embeddings (IKE)（2026, P37）通过隔离森林或向量离散化将 LLM 嵌入映射到 IKE 空间，实现快速检索，无需重新训练 LLM 即可实现嵌入长度的自适应调整。

高效部署路线与 LLM 适配路线存在继承关系：许多高效部署技术（如 MRL、量化）直接应用于 LLM 适配后的模型，以解决其部署瓶颈。

### 2.4 多语言与领域基准

多语言与领域基准路线旨在填补特定语言或垂直领域的资源空白。MTEB 的多语言扩展版本 MMTEB（2025）覆盖超过 250 种语言和 550 个评估任务，揭示了现有模型在低资源语言上的性能差距。针对特定语言，TR-MTEB（2025, P51）构建了针对土耳其语的全面嵌入基准，并训练了专用的土耳其语嵌入模型；SkMTEB（Šuppa et al., 2026, P31）针对斯洛伐克语构建大规模文本嵌入基准；PL-MTEB（2026, P40）针对波兰语构建包含 30 个任务的大规模基准；MTEB-PT（Okamura et al., 2026, P33）针对葡萄牙语构建基准切片，强调嵌入质量的任务依赖性。

针对垂直领域，TeleEmbedBench（Gajjar and Shah, 2026, P27）构建了针对电信领域 RAG 系统的多语料库嵌入基准，揭示了通用嵌入模型在电信领域的局限性。Compass-Embedding v4（Ueareeworakul et al., 2025, P19）针对多语言电商领域，通过引入感知掩码（CAM）和球形模型合并技术，解决了大规模对比学习中的假阴性偏差和灾难性遗忘问题。SEA-BED（2026, P52）针对东南亚语言，揭示了分词器词汇覆盖与下游性能之间的相关性，强调了多语言分词器设计对嵌入质量的影响。

多语言与领域基准路线与 LLM 适配路线存在互补关系：基准揭示了 LLM 适配模型在特定语言或领域上的不足，推动了针对特定场景的适配策略优化。

### 2.5 多向量与结构化表示

多向量与结构化表示路线旨在超越单向量表示，捕捉细粒度语义。ColBERT（2021）引入延迟交互机制，保留 Token 级嵌入，通过 Chamfer 距离计算细粒度相关性。Retrieval Needs Multivectors（Agarwal et al., 2026, P35）通过构造特定查询和文档集，展示单向量模型在细粒度匹配上的根本局限，而多向量模型能通过 Chamfer 距离捕捉 Token 级交互，提供了多向量检索优越性的理论证明。

针对结构化数据，Struc-EMB（Liu et al., 2025, P10）将结构信息（如度、PageRank）直接注入语言嵌入过程，提升在结构化数据集上的检索和重排序性能。GLOT（Mantri et al., 2026, P23）基于 Token 图的句子表示方法，通过显式建模 Token 间的关系，构建图结构，并利用图神经网络或注意力机制聚合信息，克服了传统池化方法丢弃结构信息的缺陷。

针对上下文依赖，ConTEB（2025, P43）提出上下文感知文本嵌入基准，评估模型利用文档全局上下文的能力，揭示了现有模型在依赖上下文信息的检索场景中的不足。GASE（2025, P44）通过生成式模型增强句子编码，利用测试时计算生成合成文本，提升嵌入的鲁棒性和多样性。HMCL（2025, P38）通过层次对比学习进行任务最优文本表示适配，引入 3 级对比（正、弱正、负），平衡不同任务对语义相似度的需求。

多向量与结构化表示路线与高效部署路线存在竞争关系：多向量表示保留了更多细粒度信息，但显著增加了存储和计算开销，与高效部署的目标相悖。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

双向注意力机制对于捕获文本的全局语义信息至关重要，单向因果注意力在嵌入任务中表现受限，这一共识在约 15 篇论文中得到共同支持。LLM2Vec 和 NV-Embed 等模型通过引入双向注意力显著提升了嵌入性能，证明了双向性在 LLM 适配中的核心地位。与此相关的另一个共识是对比学习是训练高质量文本嵌入模型的主流且有效的方法，通过优化正负样本对的距离来塑造嵌入空间，约 20 篇论文共同支持这一观点。E5 系列和 GTE 等模型均依赖对比学习取得优异性能，表明对比学习在嵌入训练中的基础地位。

MTEB 是评估嵌入模型通用性的标准基准，但单一分数不能完全反映模型在特定领域或场景下的表现，这一共识在约 18 篇论文中得到支持。HUME 和 FLARE 等新兴评估框架的出现，正是为了弥补 MTEB 在人类对齐和无标签评估方面的不足。嵌入空间的几何性质（如各向异性、均匀性）直接影响下游任务性能，优化空间几何结构是提升嵌入质量的重要途径，约 10 篇论文共同支持这一观点。UTS 和 SOCM 等工具的出现，为量化和优化嵌入空间几何提供了理论依据。

### 3.2 观点分歧

LLM 适配的最佳路径存在显著分歧：微调现有 LLM、从头训练嵌入专用 LLM 还是无训练后处理？现有证据偏向微调现有 LLM，因其在 MTEB 等基准上表现优异且训练成本较低，如 Qwen3-Embedding-8B 和 NV-Embed-v2 的高分。但 Conan-Embedding-v2 展示了从头训练的可行性，在特定任务上可能更优，避免了生成能力与嵌入能力的冲突。HTP 等无训练方法在轻量级场景下有优势，但全局语义捕获能力有限。这一分歧的背后，是另一个更根本的争论：池化策略的几何最优性。Mean Pooling 简单稳健，但 SOCM 度量揭示了其二阶坍塌问题；Last Token 能更好地捕获全局上下文；GLOT 保留 Token 间关系结构，但计算复杂度高。现有证据偏向 Mean Pooling 的稳健性，但缺乏大规模、多任务的池化策略对比实验，且几何指标尚未完全揭示池化策略与任务性能的因果机制。

评估标准的有效性也是争议焦点：MTEB 分数、人类对齐还是几何性质？MTEB 是事实标准，便于比较，但 HUME 揭示了模型在复杂语义理解上的局限性，UTS/SOCM 揭示了嵌入空间几何与下游性能的关联。现有证据偏向 MTEB 作为主要基准，但缺乏 MTEB 分数、人类对齐与几何性质之间的系统性关联研究。HUME 依赖大规模人类标注，成本高且主观性强；UTS/SOCM 计算开销大，尚未标准化。这些分歧的根源在于测量工具的盲区和场景依赖性，不同任务对评估标准的需求不同。

### 3.3 其他开放问题

最紧迫的工程问题是高效部署与压缩，解决大模型嵌入在边缘设备或高并发场景下的延迟和内存瓶颈。难点在于保持压缩后的语义完整性，潜在路径包括 Matryoshka 表示学习、二进制嵌入、量化感知训练及轻量级解码器压缩。3D-ML 和 SwiftEmbed 等方法已提供初步解决方案，但截断敏感性和精度损失仍是挑战。最根本的研究问题是嵌入空间几何分析与对齐，解决不同嵌入模型间空间不可比及内部结构不透明的问题。难点在于高维空间的拓扑复杂性，潜在路径包括 Procrustes 对齐、统一拓扑签名、流形学习及基于流的密度估计。UTS 和 mini-vec2vec 等工具为这一方向提供了基础，但缺乏理论突破。

此外，多语言与低资源语言嵌入、领域特定与专业任务嵌入、可解释性与解码、鲁棒性与偏差校正、多模态与跨模态嵌入等方向也面临重大挑战。已知的是 LLM-based embedding 已成为主流范式，争议的是最佳适配路径和评估标准，未知的是嵌入空间几何与任务性能的因果机制及可逆性。未来发展趋势将从单纯精度提升转向几何性质、部署效率与可解释性的平衡，几何引导的训练、可逆嵌入模型及跨模态对齐是潜在突破点。

## 4. 总结与展望

文本嵌入模型已从简单的统计匹配演变为复杂的几何结构化表示系统，LLM-based embedding 成为主流范式。核心矛盾在于如何在保持计算效率与部署可行性的前提下，构建能够捕捉全局语义结构且具备跨语言、跨领域泛化能力的低维稠密向量表示空间。尝试过的路线包括 LLM 适配、几何分析、高效部署、多语言基准和多向量表示，各路线在精度、效率与可解释性之间做出了不同的取舍。核心瓶颈在于嵌入空间几何性质（如各向异性、坍塌）的成因与优化、嵌入的可逆性与可解释性、低资源语言的深层语义对齐，以及评估标准的有效性与公平性。

未来可能突破的方向包括：几何引导的训练，利用 UTS/SOCM 等工具指导训练过程，优化嵌入空间几何结构；可逆嵌入模型，通过 ctELM 等逆向解码技术实现嵌入到文本的映射，提升可解释性；跨模态嵌入，解决文本嵌入向视觉、音频等其他模态扩展时的对齐问题。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，系统比较不同 LLM 适配路径和池化策略在 MTEB、BEIR 及领域特定任务上的性能与训练成本，并结合几何指标分析其空间结构差异，以厘清当前分歧的根源。
