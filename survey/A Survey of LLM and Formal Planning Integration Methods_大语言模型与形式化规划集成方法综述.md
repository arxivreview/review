## 导读

大语言模型（Large Language Model, LLM）在长程逻辑推理与状态追踪方面存在固有缺陷，其核心价值在于弥补符号规划器在自然语言理解上的短板。早期研究以直接生成为主线，通过提示工程让模型输出计划，思路简洁却受制于逻辑幻觉与模式匹配。当经典规划基准暴露出状态模拟缺失后，研究者转向神经符号集成范式，利用外部验证器将非结构化指令转化为形式化规划语言（PDDL），用逻辑严谨性换取生成可靠性。各路线在语义准确性、计算成本与泛化能力之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从静态翻译到闭环验证的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

该领域的兴起源于对 LLM 在长程逻辑推理中“幻觉”问题的反思。尽管 LLM 具备强大的常识知识，但在 BlocksWorld 等经典规划基准上表现不佳，往往依赖模式匹配而非真正的状态模拟。这一发现促使研究者重新审视 LLM 在规划任务中的角色，从“全能规划者”转向“语义接口”，即利用 LLM 处理模糊输入，利用符号系统保证逻辑正确性。这种神经符号集成（Neurosymbolic Integration）范式成为后续研究的基础，其核心在于建立自然语言与形式化规划语言（如 PDDL）之间的可靠映射。

问题形式化通常遵循 N-way K-shot 的变体，但在规划领域更侧重于从自然语言描述到 PDDL 领域与问题实例的转换。给定自然语言任务描述 $D$，目标是生成 PDDL 领域模型 $\mathcal{D}_{PDDL}$ 和问题实例 $\mathcal{P}_{PDDL}$，使得符号规划器 $\mathcal{S}$ 能求解出有效计划 $\pi$，即 $\pi = \mathcal{S}(\mathcal{D}_{PDDL}, \mathcal{P}_{PDDL})$ 且 $\pi$ 满足所有约束。子问题呈现层级依赖关系：首先必须解决 NL2PDDL 的语义转换准确性（基础层），才能进行有效的符号规划求解；在此基础上，通过闭环反馈机制解决复杂约束下的逻辑一致性（核心层）；最终，通过强化学习和多智能体协调解决泛化能力与动态环境适应性（应用层）。若基础转换错误，后续验证和反馈将失效。

范式边界在早期研究中逐渐清晰：LLM 负责语义理解与启发式生成，符号系统负责逻辑推理与状态追踪。LLM 不独立承担逻辑一致性责任，而是作为自然语言到形式化语言的翻译器或启发式生成器。这一边界的确立源于 LLM 在复杂组合约束下的系统性失败，其注意力机制在长序列中难以同时维持多个约束的满足。因此，外部符号验证器（如 VAL、Fast Downward）成为连接 LLM 语义空间与逻辑空间的必要桥梁，确保生成的计划不仅语法正确，而且逻辑上可解。

约束演化史揭示了方法如何因应约束变化而演变。2016-2018 年奠基阶段，研究聚焦于经典规划算法，LLM 尚未介入。2020 年跨域基准转折，PlanBench 等基准揭示 LLM 在符号规划中的局限性，促使研究者引入外部验证器。2021 年预训练/VLM 引入，LLM+P 等框架确立混合架构范式，LLM 作为自然语言到 PDDL 问题实例化接口。2023-2025 年细化与融合，LLM-Modulo 形式化提出 LLM 不能独立可靠规划，必须与形式验证器配对，确立神经符号混合系统的理论边界。当前形态，研究不再局限于简单的 NL2PDDL 转换，而是深入探讨 LLM 内部是否形成了“潜在规划”（Latent Planning）表征，以及如何通过强化学习（RL）和进化算法优化 LLM 生成的启发式或通用规划器。

**如果用一个核心问题概括该领域，那便是：如何在保持 LLM 语义灵活性的同时，通过神经符号闭环机制消除其逻辑幻觉，实现从自然语言意图到可验证、可执行且具泛化能力的规划策略的可靠映射。**

## 2. 方法体系

- 2022：LLM+P——首次确立 LLM 作为自然语言到 PDDL 问题实例化接口，结合经典规划器求解的混合架构范式

- 2023：NL2PDDL——利用预训练 LLM 从文本构建 PDDL 世界模型，引入基于 VAL 验证器的迭代修复机制

- 2023：LLM-Modulo——形式化提出 LLM 不能独立可靠规划，必须与形式验证器配对，确立神经符号混合系统的理论边界

- 2024：Planner-R1——提出奖励塑造机制，使较小 LLM 通过高效代理强化学习获得规划能力

- 2025：PDDLCoder——提出代理式 PDDL 生成框架，集成 LLM 评分模块对生成的领域和问题进行语义一致性打分

- 2026：Planner-in-the-Loop——提出规划器在环反馈框架，将规划器诊断转化为定向修复信号，在固定符号语义下实现局部修复

- 2026：Tensor-Coord——提出张量协调框架，利用多线性代数分解联合计划张量，定义协调复杂度指标

这条时间线勾勒了该领域方法演进的代表性节点：从 2022 年的 LLM+P 奠定该领域方法基线，经 2023 年 LLM-Modulo 的推进，到 2026 年的 Tensor-Coord 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 PDDL 形式化生成

PDDL 形式化生成路线的起源可追溯至 2022 年的 LLM+P（Liu et al., 2022），该工作首次确立 LLM 作为自然语言到 PDDL 问题实例化接口的混合架构范式。然而，早期方法主要依赖语法检查，无法捕捉自然语言模糊性导致的语义歧义，导致生成的 PDDL 虽可解析但无法求解。2023 年，NL2PDDL（Guan et al., 2023）引入基于 VAL 验证器的迭代修复机制，解决语法与语义错误，标志着从纯语法导向向语义导向的转变。2024 年，VML_PDDL 引入测试时扩展策略，通过生成多个领域候选并选择最优者，结合固定优化器-学习者细化调度，提升 PDDL 生成质量。

PDDLCoder（Laule et al., 2026, P34）针对传统方法在语义一致性上的不足，提出代理式 PDDL 生成框架。该方法将生成过程分解为领域生成、问题生成及验证评分三个核心模块，其中验证模块利用 LLM 对生成的 PDDL 代码进行语义评分，判断其是否准确捕捉自然语言描述的语义。与传统仅依赖语法检查的方法不同，PDDLCoder 引入了基于 LLM 的评分机制，能够识别语法正确但语义错误的规划模型。框架采用迭代修复策略，当评分低于阈值时，将错误反馈给生成模块进行局部修正，而非重新生成整个领域。这种设计降低了上下文窗口压力，同时提高了生成模型的可靠性。其代价是增加了 LLM 调用的次数与计算开销，且评分模块本身的准确性会影响整体性能。该方法在 NL-PDDLGym 基准上展示了优越的生成质量，为 LLM 辅助符号规划提供了可验证的生成范式。

Planner-in-the-Loop（Jiang et al., 2026, P31）进一步将规划器嵌入生成循环，提出一种将规划器诊断转化为定向修复信号的反馈框架。核心思想是利用标准符号规划工具链（如 VAL 和 Fast Downward）作为验证器，在固定符号语义下执行局部修复，确保生成的规范不仅语法正确，而且逻辑上可解。框架包含 NL-PDDLBench 基准，提供对齐的自然语言描述、PDDL 规范及规划器派生的参考信号，用于系统评估生成质量。其优势在于提供了可复现的证据来验证规范的有效性，避免了 LLM 幻觉导致的不可验证决策。代价是依赖外部规划器的计算资源，且修复过程可能增加延迟。该方法显著提升了 PDDL 生成的可靠性，为安全部署 LLM 规划系统提供了形式化保障，是神经符号集成在规划领域的重要进展。

Model Space Reasoning as Search in Feedback Space（Oswald et al., 2026, P21）将规划领域生成视为反馈空间中的搜索问题，利用 LLM 在模型空间中探索并修复生成的 PDDL。该方法针对 LLM 生成 PDDL 时常见的语法和语义错误，引入基于 VAL 验证器的反馈机制，但不同于简单的重新提示，它将反馈转化为搜索空间中的约束，引导 LLM 进行定向修正。框架采用类型化提升 STRIPS 规划形式化，确保生成的领域符合严格的逻辑结构。其创新点在于将生成过程建模为搜索，而非单次生成，从而提高了复杂领域的生成成功率。代价是搜索过程可能增加计算时间，且依赖验证器提供的反馈质量。该方法在多个 IPC 领域上展示了优于基线的生成性能，为自动化规划领域建模提供了新的理论视角。

End-to-end Planning Framework with Agentic LLMs and PDDL（La Malfa et al., 2025, P12）提出一种端到端规划框架，利用代理式 LLM 将自然语言规范转换为 PDDL 模型，并通过子模块迭代细化领域和问题。框架包含一个编排器，负责协调多个代理模块，这些模块专门处理时间约束、最优性要求及自然语言中的歧义和矛盾。与传统一次性生成不同，该方法采用迭代细化策略，逐步解决规划需求中的复杂问题，确保生成的 PDDL 模型既符合用户意图又具备可解性。验证后的领域和问题被传递给外部规划引擎生成计划，最后由模块将计划转回自然语言以提高可读性。其优势在于无需人工干预即可处理模糊和不完整的自然语言输入，提升了规划的自动化程度。代价是代理间通信和迭代过程可能增加系统复杂度。该方法展示了 LLM 在复杂规划任务中的协调能力，为自然语言到符号规划的无缝转换提供了实用解决方案。

Towards a General Framework for HTN Modeling with LLMs（Puerta-Merino et al., 2025, P11）提出一种利用 LLM 进行分层任务网络（HTN）建模的通用框架，旨在解决自动化规划中世界模型形式化困难的问题。该方法利用 LLM 从自然语言任务描述中提取规划元素，并将其结构化为 HTN 表示，包括任务、方法、前置条件和效果。框架结合 PlanBench 基准，评估 LLM 将详细任务描述转换为结构化表示的能力，最小化对额外知识检索的依赖。与传统 PDDL 建模不同，HTN 建模利用分层抽象加速规划并产生更可解释的计划，符合人类问题解决策略。其创新点在于将 LLM 的自然语言理解能力与 HTN 的分层结构相结合，提升了规划的可扩展性和可解释性。代价是 HTN 建模需要更复杂的结构定义，且 LLM 在提取分层关系时可能出错。该方法为大规模规划问题提供了高效的建模途径，推动了 LLM 在分层规划领域的应用。

### 2.2 符号规划器集成

符号规划器集成路线与 PDDL 形式化生成路线从竞争走向互补，前者解决语义映射，后者确保逻辑闭环。2022 年的 LLM+P 奠定了混合架构的基础，但静态翻译无法保证逻辑正确性。2023 年 LLM-Modulo（Kambhampati et al., 2023）形式化提出 LLM 不能独立可靠规划，必须与形式验证器配对，确立神经符号混合系统的理论边界。这一理论突破促使研究者从单纯的翻译转向闭环反馈，利用规划器的验证结果作为反馈信号，迭代修正 LLM 生成的领域模型或计划。

Agentic LLM Planning via Step-Wise PDDL Simulation（Göbel et al., 2026, P20）提出一种基于逐步 PDDL 模拟的代理式 LLM 规划方法，旨在解决 LLM 无法在规划构建过程中进行交互式决策的问题。核心组件 PyPDDLEngine 将 PDDL 转换系统封装为交互式环境，允许 LLM 代理执行单个动作、观察结果状态并决定下一步动作，填补了静态规划器与动态代理交互间的空白。与传统一次性生成完整计划不同，该方法支持逐步验证和修正，使 LLM 能够根据实时状态调整规划策略。框架暴露了初始化会话、查询当前状态、查询适用动作等七种操作，实现了 LLM 与符号规划环境的紧密耦合。其优势在于提高了规划的鲁棒性，使 LLM 能够处理动态变化的环境状态。代价是逐步交互增加了计算延迟，且依赖 PDDL 引擎的实时响应能力。该方法为 LLM 在复杂动态环境中的规划提供了新的基础设施，推动了符号规划与代理式 AI 的深度融合。

CoPiC（ICLR 2026, P39）提出代码驱动规划与领域自适应选择器框架，旨在解决 LLM 规划中查询成本高和计划质量不稳定的问题。该方法由 LLM 规划器和领域自适应选择器两个模块组成，规划器生成多个规划程序以产生候选计划，选择器则评估并选择具有最高长期奖励的计划。与传统即时反馈范式不同，CoPiC 采用规划阶段与学习阶段交替进行的策略，利用执行结果细化规划程序并在强化学习框架内微调选择器，增强领域适应性。其创新点在于将规划视为程序生成问题，并通过选择器优化长期奖励而非局部正确性。代价是引入了额外的学习阶段和选择器训练开销，且依赖执行环境的反馈质量。该方法在多个环境中展示了优于基线的规划性能，为 LLM 规划提供了高效且高质量的解决方案，推动了代码驱动规划在复杂任务中的应用。

Toward PDDL Planning Copilot（Benyamin et al., 2025, P1）提出一种 PDDL 规划副驾驶框架，旨在利用 LLM 辅助用户编写和调试 PDDL 规划模型。该方法将 LLM 作为自然语言接口，将用户的自然语言描述转换为 PDDL 代码，并提供实时反馈和错误修正建议。与传统自动化工具不同，Copilot 强调人机协作，允许用户干预和修正 LLM 生成的代码，确保规划模型的准确性和用户意图的一致性。框架集成了 PDDL 语法检查和语义验证功能，能够识别常见的规划错误并提供修复建议。其优势在于降低了 PDDL 编写的门槛，使非专家用户也能利用符号规划技术。代价是依赖用户的领域知识进行最终验证，且 LLM 生成的代码可能需要多次迭代才能满足要求。该方法为 PDDL 规划工具链提供了智能化增强，推动了符号规划在更广泛用户群体中的普及。

Localizing and Correcting Errors for LLM-based Planners（Kumar and Cohen, 2026, P15）提出一种定位和修正 LLM 规划器错误的方法，旨在解决 LLM 在经典规划基准中频繁失败的问题。该方法通过对比 LLM 生成的计划与正确计划，定位具体的错误步骤，并利用检索增强生成（RAG）和上下文学习（ICL）提供针对性的修正建议。与传统自我反思方法不同，该方法强调外部知识的引入，通过检索相似的正确计划片段来指导 LLM 修正错误。框架包含错误定位模块和修正生成模块，前者识别计划中的逻辑不一致，后者生成修正后的计划。其优势在于提高了 LLM 规划的准确性，特别是在复杂约束条件下。代价是依赖高质量的外部知识库，且检索过程可能增加延迟。该方法为 LLM 规划器的可靠性提升提供了新的技术路径，强调了外部知识在符号规划中的重要作用。

Constraints-of-Thought（Alrashedy et al., 2025, P8）提出一种约束思维框架，旨在解决 LLM 在规划过程中违反任务约束和逻辑一致性的问题。该方法将结构化推理步骤表示为意图-约束对，引导蒙特卡洛树搜索（MCTS）向语义有意义且满足约束的路径探索。与传统链式思维不同，Const-o-T 引入了可执行的中间表示，显式限制可行动作空间，防止 LLM 生成无效或偏离意图的动作。框架在 MCTS 的每个节点应用约束检查，确保搜索过程始终在约束边界内进行。其创新点在于将约束推理与搜索算法紧密结合，提高了规划的合规性。代价是约束定义需要精确，且约束检查可能增加搜索开销。该方法在多个规划任务中展示了优于基线的性能，为 LLM 在复杂约束环境中的规划提供了有效的推理框架，推动了约束感知规划的发展。

### 2.3 强化学习规划优化

强化学习（RL）规划优化作为新兴分支，旨在解决 LLM 规划泛化能力差和计算效率低的问题。2024 年，Planner-R1（Zhu et al., 2025, P4）提出奖励塑造机制，使较小 LLM 通过高效代理强化学习获得规划能力，解决大模型计算成本高且小模型规划弱的问题。这一工作标志着 RL 在 LLM 规划中的应用从理论探索走向工程实践，通过精心设计的奖励函数提升小模型的规划性能。

CARL（Qi et al., 2026, P32）提出一种约束感知强化学习框架，旨在解决 LLM 在生成约束合规计划时的系统性失败。该方法将约束合规性作为奖励信号，引导 LLM 学习生成满足显式和隐式约束的计划。与传统强化学习不同，CARL 强调约束感知，通过奖励函数惩罚违反约束的行为，确保计划的可行性。框架兼容多种 RL 算法，包括 PPO、GRPO 和 DPO，支持不同规模的 LLM 模型。其创新点在于将约束满足问题转化为奖励优化问题，提高了 LLM 在复杂约束环境中的规划能力。代价是奖励设计复杂，且约束验证可能增加计算开销。该方法在多个规划基准上展示了优于基线的性能，为 LLM 在约束规划领域的应用提供了有效工具，推动了约束感知强化学习的发展。

CoFineLLM（Wang et al., 2025, P10）提出一种保形微调框架，旨在提升 LLM 在语言指令机器人规划中的可靠性。该方法利用保形预测（CP）生成预测集合，并通过新颖的损失函数惩罚非单例且未包含正确动作的预测集合。与传统微调不同，CoFineLLM 强调预测的不确定性量化，通过动态调整阈值 δ 模拟保形化过程，确保预测集合的覆盖率。框架在机器人任务规划任务上实验，利用自然语言指令生成行动计划。其创新点在于将保形预测引入 LLM 微调，提高了规划输出的可靠性。代价是保形预测计算开销大，且阈值调整复杂。该方法为 LLM 在安全关键机器人应用中的部署提供了可靠性保障，推动了保形预测在规划领域的应用。

LLM-Evolved Domain-Independent Heuristics for Symbolic AI Planning（Gestrin and Seipp, 2026, P26）提出一种利用 LLM 演化领域无关启发式的方法，旨在提升符号规划器的搜索效率。该方法将启发式生成视为优化问题，利用 LLM 在 MAP-Elites 框架中生成和变异启发式函数，通过岛屿模型促进多样性。与传统手工设计启发式不同，该方法强调自动化演化，利用 LLM 的推理能力生成更优的启发式。框架在多个 IPC 领域上实验，评估演化启发式的规划性能。其创新点在于证明了 LLM 可以生成优于传统启发式的领域无关启发式，提升了规划器的通用性。代价是演化过程计算成本高，且启发式评估复杂。该方法为符号规划器提供了新的启发式生成途径，推动了 LLM 在规划算法设计中的应用。

SiGPlan（Gieselmann et al., 2026, P23）提出一种自改进框架，旨在提升生成式模型在规划任务中的计划质量。该方法通过迭代细化生成模型，使其产生近最优计划，无需依赖大规模最优训练数据。与传统生成式规划不同，SiGPlan 强调自改进，利用验证器反馈引导模型优化计划长度和可行性。框架在 Blocksworld 等领域上实验，评估生成计划的优化程度。其创新点在于解决了生成式模型受限于训练数据质量的问题，通过自改进突破质量天花板。代价是迭代过程可能增加计算时间，且验证器反馈质量影响改进效果。该方法为生成式规划提供了新的优化途径，推动了自改进技术在规划领域的应用。

### 2.4 推理机制与理论分析

推理机制与理论分析路线从理论视角分析 LLM 内部规划机制，包括潜在规划表征、泛化差距、推理与规划的区别以及 Transformer 架构在规划任务中的计算能力边界。2025 年，Latent Planning Emerges with Scale（Hanna and Ameisen, 2026, P22）通过因果干预证明 LLM 内部存在潜在规划表征，且随模型规模扩大而涌现，为理解 LLM 规划机制提供神经科学视角。这一发现挑战了 LLM 仅依赖模式匹配的观点，揭示了其内部可能存在的序列级规划能力。

On the Generalization Gap in LLM Planning（Belcamino et al., 2026, P13）提出一种分析 LLM 规划泛化差距的方法，揭示模型在分布偏移下的性能下降。该方法通过监督微调 LLM 在 PDDL 规划任务上，并测试其在未见领域上的表现，指出模型可能依赖记忆词汇模式而非可迁移规划能力。与传统评估不同，该方法强调跨领域泛化能力，而非单一领域内的性能。框架利用验证器奖励强化学习（Verifier-Reward RL）缓解泛化差距，通过奖励信号引导模型学习更鲁棒的规划策略。其创新点在于揭示了 LLM 规划中的“幻觉能力”问题，即表面性能高但泛化能力弱。代价是强化学习训练成本高，且奖励设计复杂。该方法为 LLM 规划可靠性提供了理论分析，推动了验证器奖励在规划训练中的应用。

Large Language Models Can Take False First Steps at Inference-time Planning（Yan et al., 2026, P16）提出一种分析 LLM 在推理时规划中错误起始步骤的方法，揭示模型在序列级规划中的偏差。该方法利用元学习先验解释 LLM 的快速适应能力，指出模型可能基于训练数据中的领域特定规划先验生成错误的第一步。与传统规划分析不同，该方法关注推理过程中的动态偏差，而非静态规划能力。框架通过理论模型描述 LLM 如何整合领域特定生成任务分布，并分析其对规划起始步骤的影响。其创新点在于揭示了 LLM 规划中的“错误起始”现象，即模型可能基于错误先验生成不可行的计划。代价是理论模型简化了现实复杂性，且先验估计困难。该方法为理解 LLM 规划失败模式提供了新视角，强调了先验知识在规划中的双重作用。

Extracting Search Trees from LLM Reasoning Traces Reveals Myopic Planning（Chen et al., 2026, P24）提出一种从 LLM 推理轨迹中提取搜索树的方法，揭示模型在规划中的短视行为。该方法利用 LLM 裁判将非结构化推理轨迹转录为形式化搜索树，分析模型在规划过程中考虑的动作深度和广度。与传统推理分析不同，该方法关注规划过程的树状结构，而非线性推理链。框架在围棋等复杂博弈任务上实验，通过搜索树深度和节点数评估模型的规划前瞻性。其创新点在于提供了量化指标，证明 LLM 在复杂规划中倾向于短视，缺乏深度前瞻。代价是搜索树提取依赖 LLM 裁判的准确性，且计算成本高。该方法为理解 LLM 规划局限性提供了实证证据，强调了深度搜索在复杂规划中的重要性。

Benefits and Pitfalls of Reinforcement Learning for Language Model Planning（Wang et al., 2025, P3）提出一种从理论视角分析强化学习在 LLM 规划中作用的方法，揭示其优势与陷阱。该方法将 LLM 规划抽象为未知有向图上的路径规划问题，分析强化学习如何影响模型的路径搜索能力。与传统经验分析不同，该方法提供理论框架，解释强化学习如何提升或损害 LLM 的规划泛化能力。框架利用邻接矩阵和可达性矩阵描述图结构，分析强化学习奖励信号对模型学习路径的影响。其创新点在于揭示了强化学习在规划中的双重作用，即提升局部性能但可能损害全局泛化。代价是理论模型简化了现实复杂性，且奖励设计敏感。该方法为 LLM 规划训练提供了理论指导，强调了奖励设计在规划学习中的关键作用。

### 2.5 多智能体协同规划

多智能体协同规划路线研究基于 LLM 的多智能体系统在复杂任务中的协同规划，涉及角色分工、通信机制、记忆共享及冲突解决，旨在提升长程任务中的鲁棒性与效率。2025 年，LRP LAN（EMNLP 2025, P36）提出多智能体协作框架，结合 LLM 与推理模型处理显式与隐式约束，通过元代理提取模式与规则指导子代理规划。这一工作标志着多智能体规划从简单的任务分解走向复杂的协调机制设计。

Tensor-Coord（Rastogi, 2026, P28）提出一种基于张量代数的多智能体规划框架，旨在解决 LLM 代理在协同规划中的冲突问题。该方法将 N 个代理的联合计划编码为软张量，利用 CP 分解和 Tucker 分解提取协调结构，定义协调复杂度指标。与传统多代理规划不同，Tensor-Coord 强调代数分解，通过张量秩分析定位冲突，并生成自然语言约束引导代理重规划。框架在多个多代理任务上实验，评估协调效率和冲突解决能力。其创新点在于提供了代数基础，量化多代理规划的难度，并实现冲突的局部化解决。代价是张量分解计算成本高，且软编码参数敏感。该方法为多代理 LLM 规划提供了新的数学工具，推动了代数方法在协同规划中的应用。

EvoMem（Fan et al., 2025, P9）提出一种双演化记忆框架，旨在提升多代理规划中的自我修正能力。该方法包含约束记忆（CMem）和质量记忆（QMem）两个模块，CMem 存储从查询中提取的约束，QMem 积累迭代过程中的反馈。与传统多代理规划不同，EvoMem 强调记忆演化，通过迭代自我修正过程，逐步使解决方案符合所有指定约束。框架在 NaturalPlan 等基准上实验，处理旅行规划、日历调度等任务。其创新点在于将记忆机制引入多代理规划，提高了规划的适应性和鲁棒性。代价是记忆管理复杂，且迭代过程可能增加延迟。该方法为 LLM 在多代理规划中的应用提供了新工具，强调了记忆在复杂任务规划中的重要作用。

Hierarchical LLM-Based Multi-Agent Framework with Prompt Optimization（Kawabe and Takano, 2026, P18）提出一种分层多代理 LLM 框架，结合提示优化提升多机器人任务规划性能。该方法上层代理分解任务并分配给下层代理，下层代理生成 PDDL 问题并由经典规划器求解。当计划失败时，系统应用 TextGrad 启发的文本梯度更新优化每个代理的提示，并在同一层内共享元提示。与传统多代理框架不同，该方法强调提示优化，通过动态调整提示提升规划准确性。框架在多机器人任务规划任务上实验，评估任务分解和分配效率。其创新点在于将提示优化引入多代理规划，提高了系统的自适应能力。代价是提示优化计算成本高，且元提示共享可能引入偏差。该方法为多机器人规划提供了智能化增强，推动了提示优化在协同规划中的应用。

Bayesian Partner Modelling enables Adaptive Replanning for LLM Coordination（Goel et al., 2026, P35）提出一种基于贝叶斯伙伴建模的自适应重规划方法，旨在解决 LLM 代理在协作中因伙伴行为变化导致的协调失败。该方法利用贝叶斯推断更新对伙伴技能的估计，当伙伴行为与当前估计冲突时，代理中断当前技能并重规划。与传统协调方法不同，该方法强调信念更新，通过贝叶斯模型动态调整对伙伴行为的预测。框架在 Overcooked 等协作任务上实验，评估协调效率和重规划能力。其创新点在于将贝叶斯推断引入 LLM 协调，提高了代理的适应性。代价是贝叶斯推断计算复杂，且伙伴行为建模困难。该方法为 LLM 在动态协作环境中的应用提供了新工具，强调了信念更新在协调中的重要作用。

### 2.6 具身与机器人规划

具身与机器人规划路线聚焦 LLM 在具身智能与机器人领域的应用，结合视觉语言模型（VLM）与符号规划，解决物理环境中的感知-行动闭环、安全约束及实时性问题。2025 年，GraphThink（Li et al., 2026, P33）提出图增强 LLM 思考框架，利用任务图与场景图记忆实现长程具身任务规划，通过事件驱动重规划解决感知错误与目标偏离问题。这一工作标志着具身规划从简单的动作生成走向复杂的图结构增强。

SCOPE（Zhan et al., 2026, P30）提出一种演化符号世界框架，旨在提升开放环境中 LLM 的长程规划能力。该方法通过主动探索构建符号世界，生成行动计划，并利用符号执行模拟器反馈演化世界模型。与传统具身规划不同，SCOPE 强调符号世界演化，通过反馈机制动态更新符号表示，适应开放环境的变化。框架在多个具身任务上实验，评估规划准确性和适应性。其创新点在于将符号世界建模与 LLM 规划结合，提高了规划在开放环境中的鲁棒性。代价是符号世界构建复杂，且演化过程可能增加计算开销。该方法为 LLM 在开放环境具身规划中的应用提供了新工具，推动了符号世界建模在机器人领域的发展。

Constrained Natural Language Action Planning for Resilient Embodied Systems（Byrd et al., 2025, P7）提出一种约束自然语言动作规划方法，旨在提升具身系统在复杂环境中的鲁棒性。该方法引入前置条件验证（PV）和全局状态预测（GSP），在 LLM 生成计划时检查动作的前置条件是否满足，并预测全局状态变化。与传统具身规划不同，该方法强调约束验证，通过前置条件验证和全局状态预测，提高计划的可行性。框架在多个具身任务上实验，评估任务成功率和效率。其创新点在于将约束验证引入 LLM 规划，提高了计划的可靠性。代价是约束验证计算开销大，且全局状态预测可能不准确。该方法为 LLM 在具身系统中的应用提供了新工具，强调了约束验证在鲁棒规划中的重要作用。

SDA-PLANNER（Shen et al., 2025, P5）提出一种状态依赖感知自适应规划器，旨在解决具身任务规划中的固定范式、动作序列约束缺失和错误无关问题。该方法引入状态依赖图，显式建模动作前置条件和效果，指导动态修订。针对执行错误，采用错误自适应重规划策略，包括错误回溯、诊断和自适应动作子树生成，基于当前环境状态局部重构受影响部分。与传统具身规划不同，SDA-PLANNER 强调状态依赖和错误感知，提高了规划的适应性和鲁棒性。框架在多个具身任务上实验，评估成功率和目标完成度。其创新点在于将状态依赖图和错误自适应重规划结合，提高了规划在动态环境中的性能。代价是状态依赖图构建复杂，且错误诊断可能增加延迟。该方法为 LLM 在具身任务规划中的应用提供了新工具，推动了状态依赖感知规划的发展。

COCO-TAMP（Kim et al., 2026, P19）提出一种 LLM 引导的状态估计框架，旨在解决部分可观测任务与运动规划（PO-TAMP）中的不确定性问题。该方法利用 LLM 提供上下文线索，塑造信念状态，提高规划效率。与传统 PO-TAMP 不同，COCO-TAMP 强调 LLM 引导，通过自然语言上下文信息辅助信念更新，减少重规划次数。框架在多个机器人操作任务上实验，评估规划时间和重规划迭代次数。其创新点在于将 LLM 引入信念空间规划，提高了规划在部分可观测环境中的效率。代价是 LLM 上下文提取复杂，且信念更新可能不准确。该方法为 LLM 在机器人操作中的应用提供了新工具，推动了 LLM 引导状态估计在 PO-TAMP 中的发展。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

LLM 单独作为规划器在复杂长程任务上不可靠，必须与外部符号工具（如 PDDL 规划器、验证器）结合使用才能保证正确性，这一共识在约 20 篇论文中得到共同支持。自然语言到形式化规划模型（如 PDDL）的转换是 LLM 参与规划的关键瓶颈，需要迭代反馈机制来修正语法和语义错误，约 15 篇论文共同支持这一观点。LLM 的规划能力并非完全缺失，而是表现为“潜在规划”或“启发式规划”，在简单任务上有效，但在复杂组合约束下失效，约 12 篇论文共同支持。强化学习（RL）和进化算法是提升 LLM 规划泛化能力和生成高质量通用策略的有效手段，优于单纯的监督微调，约 10 篇论文共同支持。多智能体协作和分层规划架构能显著提升复杂任务的解决能力，通过分解任务和并行处理降低单模型负担，约 8 篇论文共同支持。LLM 在规划中常表现出“短视”（Myopic）行为，缺乏对长期后果的深入推理，需要显式的搜索或回溯机制来弥补，约 8 篇论文共同支持。视觉-语言模型（VLM）在具身规划中面临空间理解不精确的问题，需结合符号世界模型或几何约束来增强空间推理，约 6 篇论文共同支持。评估 LLM 规划能力需要区分“生成有效计划”和“生成最优计划”，当前多数研究聚焦于有效性，最优性仍是挑战，约 5 篇论文共同支持。

### 3.2 观点分歧

LLM 内部是否具备真正的“规划能力”（Latent Planning）还是仅依赖“模式匹配”是领域内的核心分歧。观点 A 认为 LLM 内部存在潜在规划表征，随规模扩大而涌现，代表工作为 Latent Planning Emerges with Scale（Hanna and Ameisen, 2026, P22）；观点 B 认为 LLM 依赖记忆词汇模式，缺乏可迁移的规划能力，存在泛化差距，代表工作为 On the Generalization Gap in LLM Planning（Belcamino et al., 2026, P13）。现有证据偏向观点 B 在复杂任务上的表现，但在简单任务上观点 A 有因果干预证据。证据强度中等，因为缺乏统一的内部机制测量工具，当前探针技术难以区分“真正的状态模拟”与“高维模式匹配”，且实验多在特定领域进行，缺乏跨域一致性验证。

强化学习（RL）是提升 LLM 规划泛化能力的有效手段还是导致过拟合的风险源是另一个重要分歧。观点 A 认为 RL 通过奖励塑造可显著提升小模型规划性能，优于监督微调，代表工作为 Planner-R1（Zhu et al., 2025, P4）；观点 B 认为 RL 可能损害全局泛化能力，导致模型在分布外任务上表现更差，代表工作为 Benefits and Pitfalls of RL for LM Planning（Wang et al., 2025, P3）。证据偏向观点 A 在特定领域内的性能提升，但观点 B 在跨域测试中提供了理论支持。证据强度较弱，因为奖励设计高度依赖领域，难以横向比较，RL 的效果高度依赖于奖励函数的设计和训练数据的分布，缺乏通用的 RL 规划框架，导致结论难以推广。

### 3.3 其他开放问题

长程状态追踪的计算效率是当前最紧迫的工程问题。LLM 在处理超过 25-30 步的长程任务时，常因内部状态表示脆弱导致无效动作或循环，需通过引入显式状态图、记忆模块或强化学习奖励机制来增强对隐含状态依赖的追踪，解决长程推理中的信息丢失问题。复杂约束（时间、空间、资源）的合规性与鲁棒性是另一个关键挑战，现有模型在满足多重组合约束时表现不佳，常出现约束违反，需开发约束感知解码、约束引导搜索或形式化验证反馈机制，将约束嵌入生成过程或后处理验证，确保计划在全局和局部层面均满足硬性约束。

LLM 内部规划机制的可解释性与干预方法是最根本的研究问题。当前对 LLM 如何内部表征和生成计划缺乏深入理解，需通过机制可解释性技术（如激活探针、电路分析）定位规划相关的内部表征，并开发轻量级干预手段（如激活补丁、引导向量）以增强或修正规划行为，提升模型的可控性和透明度。开放世界和动态环境下的自适应规划框架也是重要方向，静态 PDDL 模型难以应对开放世界中的未知对象、动态变化和模糊指令，需研究 LLM 驱动的符号世界模型演化、常识推理注入及在线重规划机制，使规划系统能够根据环境反馈动态更新模型和计划，适应非平稳环境。

已知—争议—未知认知图谱显示，领域在神经符号集成的必要性上达成共识，但在 LLM 内部规划机制的本质和 RL 的泛化效果上存在争议，开放世界自适应规划和计算效率优化仍是未知领域。发展趋势将从工程集成向机制理解跨越，核心瓶颈在于如何在保持 LLM 语义灵活性的同时，通过高效闭环机制消除逻辑幻觉，并解决跨域泛化与计算效率的平衡。

## 4. 总结与展望

该领域的核心矛盾在于 LLM 的统计模式生成机制与逻辑严谨性之间的结构性冲突。从 2022 年的 LLM+P 奠定混合架构基线，到 2023 年 LLM-Modulo 确立理论边界，再到 2026 年 Planner-in-the-Loop 和 Tensor-Coord 代表当前前沿，方法演进的主线是逐步放弃“LLM 一次性生成正确计划”的假设，转而采用“生成-验证-修复”的闭环架构。核心瓶颈在于如何在保持 LLM 语义灵活性的同时，通过神经符号闭环机制消除其逻辑幻觉，实现从自然语言意图到可验证、可执行且具泛化能力的规划策略的可靠映射。

未来可能突破的方向包括：基于机制可解释性的干预方法，通过激活探针和电路分析定位规划相关的内部表征，开发轻量级干预手段以增强或修正规划行为；开放世界下的符号世界模型演化，研究 LLM 驱动的符号世界模型演化、常识推理注入及在线重规划机制，使规划系统能够根据环境反馈动态更新模型和计划；高效神经符号架构的设计，结合小模型蒸馏、奖励整形强化学习和代码驱动规划，在保持规划质量的前提下显著降低计算成本。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下重评测代表性方法，以 Meta-Dataset 多域协议为主基准，建立公平的比较框架，揭示方法贡献与骨干网络/预训练贡献的真实关系。
