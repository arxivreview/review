## 导读

关键短语提取（Keyphrase Extraction, KPE）与多文档摘要（Multi-Document Summarization, MDS）旨在从海量文本中高效提取核心主题并生成连贯摘要，其核心价值在于缓解信息过载与知识获取效率之间的张力。早期研究依赖统计特征与图排序算法，思路简洁却受制于浅层语义理解，难以捕捉跨文档的深层逻辑关联。当预训练语言模型（PLMs）引入后，任务被转化为序列标注或生成问题，显著提升了性能，但长文档处理中的上下文窗口限制及多文档间的信息冗余与冲突成为新的主要瓶颈。随着大语言模型（LLMs）的崛起，研究重心从单纯的模型结构优化转向如何利用其推理能力进行证据归因、话题引导及跨文档关系建模，特别是在低资源语言和应用场景上热度极高。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

关键短语提取与多文档摘要的核心目标在于从非结构化文本中提炼高价值信息，前者识别代表主要主题的短语，后者从一组相关文档中生成简洁且涵盖关键信息的摘要。在形式化定义上，MDS 通常被建模为给定一组文档集合 $D = \{d_1, d_2, ..., d_n\}$，生成一个摘要 $s$，使得 $s$ 在语义上覆盖 $D$ 中的关键信息且长度受限；KPE 则常被视为极端的抽取式摘要，旨在从文档 $d$ 中识别出 $K$ 个关键短语集合 $K = \{k_1, ..., k_K\}$。这两个任务并非孤立存在，KPE 常作为 MDS 的前置子任务提供主题信号，而长文档处理则是两者共同的基础瓶颈。早期研究依赖统计特征与图排序算法（如 TextRank），假设文本重要性可通过共现关系量化，但受限于语义理解深度，难以捕捉抽象生成与跨文档冲突。

问题定义的演化经历了从“表面词形匹配”到“深层语义对齐”，再到“证据驱动的可信生成”的三次变形。2016-2018 年，领域处于奠基阶段，以度量学习和图排序为主，核心假设是局部共现反映全局重要性。2020 年前后，预训练语言模型（PLMs）如 BERT 和 Transformer 架构的引入成为关键转折，将任务转化为序列标注或生成问题，显著提升了性能，但引入了长上下文窗口限制。2023-2024 年，随着 LLMs 的崛起，问题边界扩展至长文档、多文档冲突及低资源语言形态复杂性，研究重心从“生成流畅文本”转向“生成有依据的文本”，证据归因（Evidence Attribution）和查询聚焦摘要（Query-Focused Summarization, QFS）成为新焦点。2025-2026 年，多智能体系统（Multi-Agent Systems, MAS）和强化学习（RL）被引入，问题定义进一步细化为“跨文档信息冗余与冲突的平衡”及“长文档中事实一致性的闭环验证”。

这一演进并非线性替代，而是约束条件变化下的路线迭代。早期图排序方法在 Multi-News 等复杂多文档任务中表现不佳，无法捕捉深层语义关联，促使研究者转向 PLM。然而，PLM 的固定上下文窗口（通常 512 tokens）导致长文档信息丢失，迫使研究者探索分块、滑动窗口或注意力扩展机制。当 LLMs 展现出强大的零样本能力时，幻觉问题成为主要矛盾，单一模型难以保证事实一致性，从而催生了多智能体协作与对抗性验证机制。低资源语言（如斯洛伐克语、越南语）的引入进一步揭示了传统精确匹配指标的失效，迫使评估体系向语义等价性转变。

当前领域形态呈现出“工程可实现但效率低”与“理论不确定”并存的特征。一方面，多智能体系统在长文档摘要中展现了显著的质量提升，但计算开销巨大，难以满足实时性需求；另一方面，形态丰富语言的评估协议尚未统一，传统 F1 分数在斯洛伐克语等语言中极低，生成式模型虽能缓解但成本高。这些矛盾构成了当前研究的主要驱动力，即如何在有限上下文窗口与计算资源约束下，利用 LLM 的推理能力构建具备事实一致性、主题对齐性及证据可追溯性的语义表示。

**如果用一个核心问题概括该领域，那便是：如何在有限上下文窗口与计算资源约束下，利用大语言模型的推理能力，从多源异构文本中构建具备事实一致性、主题对齐性及证据可追溯性的语义表示。**

## 2. 方法体系

- 2004：LexRank/TextRank——基于图结构的无监督抽取方法，奠定多文档摘要基线

- 2017：PEGASUS——采用 Gap-Sentence 目标预训练，成为神经摘要骨干

- 2019：Multi-News——发布首个大规模多文档摘要基准数据集

- 2020：KeyBERT——利用 BERT 嵌入实现无监督关键短语抽取

- 2023：HERA——基于 LLM 的长文档摘要框架，缓解注意力稀释

- 2025：TopicRL——主题引导的强化学习框架，优化高层语义对齐

- 2026：SUMMQ——对抗性多智能体协作框架，验证摘要完整性

- 2026：Attention Expansion——注意力扩展机制，解决长文档 KPE 窗口问题

这条时间线勾勒了该领域方法演进的代表性节点：从 2004 年的 LexRank/TextRank 奠定该领域方法基线，经 2017 年 PEGASUS 的推进，到 2026 年的 SUMMQ 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 多文档摘要生成

多文档摘要生成的早期探索始于图排序算法，LexRank 和 TextRank 通过构建句子共现图并利用 PageRank 算法计算中心度，解决了早期统计方法难以捕捉语义关联的问题，但受限于浅层语义理解。随着 PEGASUS 等预训练模型的引入，领域进入神经生成阶段，PEGASUS 通过 Gap-Sentence 目标增强了对摘要内容的理解能力，成为后续许多神经摘要模型的骨干网络。然而，端到端生成模型在处理长文档集群时面临上下文窗口限制，导致信息丢失。

针对这一瓶颈，当前研究分化为两条主要路线：基于 LLM 直接生成的端到端路线和基于显式结构建模的路线。Mixture-of-Agents (MoA) 框架（Vuong et al., 2026, P4）提出了一种免训练的多智能体协作框架，将摘要任务分解为抽取、知识图谱和抽象三个子任务，由专用智能体并行处理。该方法放弃了复杂的中间表示训练，换取低资源场景下的零样本泛化能力，其核心假设是不同智能体能够从不同维度捕捉文档信息。相比之下，Topic-Guided RL（P8）则引入了显式结构，利用主题模型提取关键短语，构建基于主题对齐的奖励函数，通过组相对策略优化（GRPO）直接最大化主题对齐奖励。这种方法放弃了纯神经网络的端到端黑盒，换取可解释的主题对齐和跨文档关系捕捉，但增加了主题提取模块的计算开销。

此外，针对低资源语言，Hierarchical BART（Nguyen and Ngo, 2026, P6）提出了一种基于 BARTPho 的两阶段层次化生成策略，专门针对越南语多文档摘要。该方法将多文档摘要分解为句子选择和摘要生成两个独立任务，通过逐步压缩信息来适应模型的最大输入长度。这种分层设计有效缓解了端到端模型在处理长文档集群时的信息丢失风险，尽管中间表示可能引入累积误差，但其在越南语新闻摘要任务中展现了良好的鲁棒性。MoA 与 TopicRL 的竞争在于零样本泛化与显式结构控制的权衡，而 Hierarchical BART 则提供了低资源场景下的工程化解决方案。

### 2.2 长文档摘要优化

长文档摘要的核心挑战在于上下文窗口限制导致的注意力稀释和信息遗漏。早期 LLM 方法如 HERA 通过分段处理和迭代查询线索来构建文章主要内容，展示了 LLM 在长文本理解上的潜力，但未能根本解决幻觉问题。2025-2026 年，研究重心转向多智能体协作与对抗性验证，旨在通过外部机制提升事实一致性。

SUMMQ（P10）提出了一种对抗性多智能体协作框架，包含摘要生成器、测验生成器、摘要审查者、测验审查者和考生五类智能体。该方法的核心创新在于将摘要质量评估转化为可操作的问答任务，测验生成器根据原文生成关键问题，考生智能体仅依据生成的摘要回答，若回答失败则反馈给摘要生成器进行修正。这种对抗性设计迫使摘要生成器覆盖原文的关键信息，显著减少了幻觉和信息遗漏，但增加了多轮交互的计算成本。Expert-Editor Stepwise Questioning（Shen and Guo, 2026, P7）则模拟学术审稿过程，包含专家、编辑和作者三个角色，通过逐步提问引导作者反思和修正初始摘要。该方法假设简单的逐步提问比复杂的指令更能有效触发 LLM 的纠错机制，为长文档摘要提供了一种轻量级的优化策略。

SUMMQ 与 Expert-Editor 的关联在于都利用了多智能体协作机制，但前者侧重于对抗性验证以捕捉信息遗漏，后者侧重于引导式反思以提升语义准确性。两者共同指向一个趋势：利用 LLM 的推理能力进行闭环验证，而非仅依赖单次生成。

### 2.3 关键短语抽取

关键短语抽取在长文档和低资源语言场景下面临独特挑战。传统抽取方法如 YAKE、TextRank 和 KeyBERT 直接提取表面形式，受限于形态丰富语言（如斯洛伐克语）的屈折变化，导致精确匹配 F1 分数极低。SlovKE 数据集（Števaňák and Šuppa, 2026, P1）的构建揭示了这一评估盲区，研究发现基于 LLM 的 KeyLLM 方法通过生成规范形式的关键短语，显著缩小了精确匹配与部分匹配之间的差距。

针对长文档 KPE 中滑动窗口导致的上下文证据碎片化问题，Attention Expansion（Martínez-Cruz et al., 2026, P5）提出了一种注意力扩展机制，允许 PLM 的令牌表示在编码过程中关注上下文外的静态词嵌入。该方法打破了 PLM 固定上下文窗口的限制，无需增加模型参数量或计算复杂度即可扩展有效感受野，显著提升了模型对分散证据的整合能力。其核心假设是关键短语的重要性往往依赖于文档中远距离出现的重复提及或定义关系。

SlovKE 与 Attention Expansion 的互补性在于，前者揭示了评估指标在形态丰富语言中的局限性，后者提供了技术层面的解决方案。生成式 KPE 方法在处理形态变异方面具有优势，但计算成本较高，而注意力扩展机制则在保持序列标注效率的同时增强了长距离依赖捕捉能力。

### 2.4 查询聚焦摘要

查询聚焦摘要（QFS）旨在根据特定查询生成针对性摘要，解决通用摘要信息过载问题。早期数据集如 TD-QFS 填补了特定领域评测的空白，但大规模高质量数据稀缺仍是主要瓶颈。SQuALITY 基准强调了证据引用与事实一致性，揭示了现有模型在证据定位上的不足。

Unstructured Evidence Attribution（P11）提出了一种非结构化证据引用方法，允许模型从长上下文中提取任意长度的文本片段作为摘要的证据。该方法构建了 SUnsET 合成数据集，通过 LLM 生成包含非结构化证据引用的摘要，用于微调模型以学习证据提取与摘要生成的联合任务。其核心创新在于将证据引用从离散单元扩展为连续跨度，提升了摘要的可解释性和事实一致性。Evidence-Based Query Generation（Chali and Abdullah, 2026, P3）则提出了一种基于证据的查询生成模型，利用迁移学习从 CNN/DailyMail 数据集训练模型，从文档中生成证据关键词作为查询，解决了 QFS 中大规模数据集稀缺的问题。

Context Pairing Augmentation（Yodthapa et al., 2026, P2）关注低资源教育场景，提出了一种成对数据增强策略，通过构建对比训练样本提升主题控制摘要的数据效率。该方法在保持真实训练数据量不变的前提下，生成包含不同主题上下文的对比样本，迫使模型学习主题与摘要之间的强关联。Unstructured Evidence Attribution 与 Context Pairing Augmentation 的关联在于都致力于提升摘要的可信度和可控性，但前者侧重于证据归因，后者侧重于主题控制。

### 2.5 文档聚类与摘要

文档聚类与摘要任务旨在处理异构文本语料，实现主题一致的分组与内容提取。传统聚类方法缺乏语义一致性评估，难以捕捉文档间的深层语义联系。D2CS（P12）提出了一种结合 LLM 监督的文档图聚类与摘要框架，利用句子嵌入和核密度估计（KDE）进行特征选择，计算文档间的能量距离以构建初始相似度图。关键创新在于引入 LLM 作为评估者，生成每个簇的摘要并评估簇内文档与摘要的一致性，据此动态调整图边权重，实现了聚类与摘要的联合优化。

Citation-Aware Heterogeneous Graph（P9）则针对科学文档的复杂结构，提出了一种基于异构图和引用感知的多粒度摘要方法。该方法构建包含句子、段落和话语单元（EDU）的异构图，利用图注意力网络（GAT）在不同粒度间传播信息，并引入引用信息以捕捉学术社区对目标文档贡献的共识。D2CS 与 Citation-Aware Graph 的互补性在于，前者侧重于通用异构文本的聚类优化，后者侧重于科学文档的结构化建模，两者共同推动了图神经网络在摘要任务中的应用。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域最核心的共识是 LLMs 在零样本/少样本设置下显著提升了 MDS 和 KPE 的性能，但长文档处理仍受上下文窗口限制。这一共识在多个基准上被反复验证：SUMMQ 在 arXiv 上的 0.45 ROUGE-2 与 Topic-Guided RL 在 Multi-News 上的 0.48 均大幅超越传统基线，表明 LLM 的推理能力是性能提升的主要驱动力（支撑证据：P8, P10）。与此相关的另一个共识是多智能体系统（MAS）通过角色分工和协作机制能有效提升长文档摘要的事实一致性和连贯性。SUMMQ 和 Expert-Editor 在 arXiv 和 PubMed 上的稳定表现，验证了对抗性验证和逐步提问机制在减少幻觉方面的有效性（支撑证据：P7, P10）。此外，话题建模或话题引导是提升 MDS 摘要话题一致性和覆盖度的有效手段，Topic-Guided RL 在 Multi-News 和 Multi-XScience 上的领先表现，优于单纯的基于文本的奖励，表明显式主题信号对高层语义对齐至关重要（支撑证据：P8）。

### 3.2 观点分歧

显式结构建模（KG/Topic）与隐式端到端学习（LLM）之间的分歧是领域内的主要争论。观点 A 认为显式建模主题或实体关系能提升可解释性和事实一致性，特别是在科学领域，Citation-Aware Graph 在 SciTLDR 上的表现支持了这一观点；观点 B 认为 LLM 的零样本能力足以捕捉深层语义，MoA 在 Multi-News 上的表现支持了这一观点。现有证据偏向显式结构在特定领域（如科学文档）更优，但端到端在低资源通用场景更灵活，缺乏跨领域的统一对比实验导致分歧未定论（支撑证据：P4, P8, P9）。这一分歧的背后，是另一个更根本的争论：多智能体协作的必要性 vs 计算效率。SUMMQ 等证明对抗性验证有效，但计算成本高昂，是否值得在实时场景中使用尚无定论。Context Pairing Augmentation 在低资源场景的性价比表明，小模型通过数据增强可达到相当性能，MAS 的效率劣势明显，缺乏标准化的“质量-效率”权衡指标使得该分歧难以解决（支撑证据：P2, P10）。

### 3.3 其他开放问题

最紧迫的工程问题是多智能体系统的效率优化，现状是计算开销巨大，关键困难在于如何平衡智能体数量与性能增益，研究路径是动态角色分配与对抗性协作机制。最根本的研究问题是形态丰富语言的评估协议，现状是传统 F1 分数在斯洛伐克语等语言中极低，关键困难在于如何平衡严格匹配与语义等价，研究路径是结合词形还原与语义嵌入的混合评估框架。此外，长文档 KPE 的跨窗口依赖和低资源 MDS 的数据稀缺问题也亟待解决，前者可通过注意力扩展机制缓解，后者需依赖合成数据生成与跨语言迁移学习。已知的是 LLM 和多智能体系统能显著提升性能，争议的是显式结构与隐式学习的优劣以及 MAS 的效率权衡，未知的是形态感知评估的标准协议和长文档幻觉检测的统一方法。

## 4. 总结与展望

KPE 与 MDS 领域已从“如何生成”转向“如何可信地生成”。核心矛盾在于有限上下文窗口与计算资源约束下，如何构建具备事实一致性、主题对齐性及证据可追溯性的语义表示。尝试过的路线包括端到端 LLM 生成、多智能体协作验证以及显式结构建模，各路线在计算效率、事实一致性和泛化能力上做出了不同的取舍。核心瓶颈在于长文档处理中的上下文窗口限制及多文档间的信息冗余与冲突，特别是在低资源语言和应用场景下。

未来可能突破的方向包括：开发形态感知评估协议，解决形态丰富语言中表面形式变化导致自动匹配指标低估模型性能的问题；增强长文档关键短语提取的上下文感知能力，解决 PLM 在长文档分窗处理时丢失跨窗口证据的问题；提升多文档摘要的主题对齐与可控性，解决摘要内容偏离指定主题或关键信息缺失的问题。对进入者最值得做的一件事是，在统一骨干与统一预训练条件下，构建一个涵盖长文档、低资源语言和多智能体协作的综合评测基准，以量化“质量-效率”权衡，为方法选择提供实证依据。
