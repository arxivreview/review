# A Survey of LLMs for Cybersecurity Applications ｜大语言模型网络安全应用综述 ｜arxivreview

综述原文见 [ArxivReview](https://www.arxivreview.com/surveys/LLMs%20for%20Cybersecurity%20Applications)

## 导读

大语言模型（Large Language Models, LLMs）在网络安全领域的应用，核心在于解决传统安全工具面对海量异构遥测数据与动态威胁演变时的专家知识稀缺瓶颈。早期研究试图通过通用模型微调直接适配安全任务，但受限于领域知识缺失与严重的幻觉问题，效果往往不及预期。随着 SecureBERT 等专用编码器模型证明领域预训练的价值，以及 CyberPal 2.0 等小型专家模型（Small Language Models, SLMs）的涌现，研究范式从“通用大模型微调”转向“领域专用骨干网络与数据工程”。当前，研究重心已从静态知识问答全面转向动态安全运营闭环，聚焦于威胁情报（Cyber Threat Intelligence, CTI）推理、自动化事件响应及合规性审计。各路线在表示质量、适应效率与计算成本之间做出了不同取舍，由此形成当前多元并存的方法格局。本综述梳理这条从几何度量到语义先验的因果演进链条，为读者提供一张领域认知地图。全文按问题演化与路线取舍组织，覆盖该领域从奠基到当前的主要工作。

## 1. 研究背景、问题结构与演进脉络

网络安全领域的自动化长期受制于数据异构性与专家知识稀缺性的双重约束。传统入侵检测系统依赖静态规则或浅层机器学习，难以应对高级持续性威胁（Advanced Persistent Threats, APTs）的动态演变；而安全运营中心（Security Operations Center, SOC）分析师面临告警疲劳，亟需能够理解非结构化日志、威胁情报报告并执行复杂推理的智能系统。大语言模型的引入，旨在通过自然语言处理（Natural Language Processing, NLP）能力桥接低层遥测数据与高层战术意图之间的语义鸿沟，其核心价值在于将安全分析从“模式匹配”提升为“语义推理”。

该领域的核心问题可形式化为在有限上下文窗口内，将多源异构安全数据（如系统日志、漏洞描述、威胁情报）映射到标准化行为框架（如 MITRE ATT&CK），并生成可执行的防御策略。这一问题包含三个强依赖的子问题：首先是领域知识注入，即模型需具备安全术语与威胁模式的语义理解能力；其次是幻觉抑制与知识时效性，即模型需避免生成虚假的失陷指标（Indicators of Compromise, IOCs）并获取最新漏洞信息；最后是复杂任务编排，即模型需协调多步骤推理以完成从检测到响应的闭环。若领域知识注入不足，后续的情报分析将建立在错误的前提上；若幻觉未得到有效抑制，自动化响应可能导致误操作；若缺乏任务编排能力，模型仅能作为辅助查询工具，无法实现真正的运营自动化。

范式边界在此阶段逐渐清晰：通用 LLM 与领域专用模型、云端 API 与本地部署、静态知识检索与动态推理增强构成了主要的技术张力。2020-2023 年，研究主要聚焦于验证 LLM 在安全任务中的可行性，CyBERT 和 SecureBERT 等基于 BERT 架构的编码器模型通过领域适应预训练（Domain-Adaptive Pretraining, DAP）证明了专用语料库对弥补通用模型知识缺口的关键作用。这一阶段确立了“领域数据质量优于通用参数规模”的初步共识，但受限于编码器架构，模型在生成复杂推理链条方面能力有限。

2024-2025 年，随着生成式 LLM 的成熟，研究重心转向如何利用其生成能力处理非结构化情报。CyberMetric 等基准的出现填补了大规模安全知识评估的空白，而 IRcopilot 等工作展示了 LLM 在 SOC 工作流中实现端到端自动化的潜力。然而，通用 LLM 在安全领域的幻觉问题日益凸显，促使研究者引入检索增强生成（Retrieval-Augmented Generation, RAG）技术，通过集成外部知识库（如 CVE 数据库、ATT&CK 框架）来动态更新模型知识。这一时期，小型语言模型（SLMs）开始受到关注，CyberPal 2.0 等模型通过高质量数据工程，在保持小尺寸的同时实现了接近前沿大模型的性能，标志着“小型化+领域专用”路线的兴起。

2025-2026 年，研究进入动态闭环阶段。多智能体框架（Multi-Agent Frameworks）成为主流，MALCDF、LiaisonAgent 等系统通过角色分工与协作机制，处理复杂、多步骤的安全任务。同时，合规性与隐私保护成为核心约束，推动本地化部署与可解释性研究。CyberGym-E2E 等动态基准的出现，标志着评测体系从静态知识测试向端到端能力评估的转型。当前领域形态呈现出“专用骨干+RAG+多智能体+合规审计”的复合架构特征，核心驱动力是解决 SOC 分析师疲劳并满足数据隐私合规要求。

**如果用一个核心问题概括该领域，那便是：如何在保证数据隐私与合规性的前提下，构建具备实时威胁感知、可解释推理及自主响应能力的防御性 AI 系统，以解决 SOC 分析师疲劳与动态威胁演变之间的不对称性。**

## 2. 方法体系

- 2021：CyBERT——基于BERT架构的网络安全领域自适应预训练模型

- 2023：SecureBERT——首个针对网络安全情报优化的编码器模型

- 2023：TRAM——自动化技术识别管道

- 2024：CyberMetric——基于RAG生成并经过专家验证的10K多选择问答数据集

- 2024：IRcopilot——基于LLM的自动化检测、分诊和响应系统

- 2025：CyberPal 2.0——IBM Research提出的4B-20B参数网络安全专家小型语言模型家族

- 2025：Minerva——基于可验证奖励强化学习（RLVR）的CTI LLM训练方法

- 2025：MALCDF——分布式多智能体LLM框架

- 2026：RedSage——网络安全通用LLM

- 2026：POLAR——基于LLM的自动化网络威胁优先级评估框架

- 2026：LiaisonAgent——多智能体自主风险调查与治理框架

- 2026：CyberGym-E2E——针对AI代理端到端网络安全能力的可扩展真实世界基准

- 2026：GenTI——针对未见攻击的自主IDPS规则生成基准

- 2026：CyberAId——面向金融服务提供商的AI驱动网络安全平台

这条时间线勾勒了该领域方法演进的代表性节点：从 2021 年的 CyBERT 奠定该领域方法基线，经 2023 年 SecureBERT 的推进，到 2026 年的 RedSage 代表当前前沿。各节点对应的技术路线、取舍与关联，详见后续小节。

### 2.1 安全领域模型构建

安全领域模型构建的起源在于解决通用语言模型在安全术语理解上的不足。2021 年，CyBERT 基于 BERT 架构，通过专门的安全语料库进行微调，证明了领域特定预训练在实体提取和文档理解任务中的有效性，为后续安全专用模型奠定了数据与架构基础。2023 年，SecureBERT 进一步确立了安全语料库对弥补通用模型知识缺口的关键作用，成为后续迭代工作的直接基线。随着生成式模型的发展，研究重心从编码器转向解码器架构，并引入了小型化与强化学习策略。

CyberPal 2.0（Levi et al., 2025, P5）代表了小型化路线的突破。该模型家族参数规模涵盖 4B 至 20B，旨在解决通用大模型在安全领域部署滞后及高质量领域数据缺失的问题。其核心创新在于 SecKnowledge 2.0 数据增强与格式化管道，该管道整合了专家在环引导的推理格式以及 LLM 驱动的多步接地技术，从而生成高保真、任务接地的推理轨迹。通过构建富含思维链的网络安全指令数据集，模型在检测、调查、响应等核心安全运营循环中实现了能力覆盖。该方法在保持模型尺寸仅为前沿模型几分之一的前提下，在核心 CTI 知识任务上超越了几乎所有测试的前沿模型，仅略逊于 Sec-Gemini v1。这种小型化策略降低了部署成本，同时通过高质量数据工程弥补了参数量的不足，为资源受限环境下的安全 AI 部署提供了高效范式。

RedSage（Suryanto et al., 2026, P9）则代表了通用性路线的演进。该模型通过持续预训练和精心策划的对话数据后训练构建，旨在应对日益复杂的攻击和高级持续性威胁。其训练数据经过网络安全过滤语料库处理，并采用增强对话数据进行后训练，以覆盖知识、技能和工具专长三个维度。RedSage 的设计强调通用性，试图在一个模型中整合多种安全任务能力，而非针对单一任务进行优化。这种方法减少了多模型部署的复杂性，提升了模型在不同安全场景间的迁移能力。其技术定位在于构建一个能够处理从基础安全知识到复杂工具调用全栈任务的统一骨干模型，为安全运营中心提供一体化的智能支持。

Fine-tuning for Cybersecurity Knowledge（Huang, 2025, P2）探索了参数高效微调策略。该方法利用网络安全问答数据集，比较了监督微调（SFT）、低秩适应（LoRA）和量化低秩适应（QLoRA）三种策略。研究发现，这些微调方法在网络安全问答任务中显著优于基础模型，证明了参数高效微调在领域知识注入中的有效性。QLoRA 策略在保持性能的同时大幅降低了内存需求，使得在消费级硬件上进行安全模型定制成为可能。该方法的核心取舍在于牺牲部分通用能力以换取领域特定知识的深度嵌入，适用于对隐私和成本敏感的内部部署场景。

SecureBERT 2.0（Aghaei et al., 2025, P3）作为编码器架构的代表，专门用于处理密集、术语繁重且上下文依赖的安全数据。该模型利用双编码器和交叉编码器架构，分别提供独立的文档嵌入和精细的交互匹配能力，支持 RAG、信息检索和语义搜索。通过训练于安全特定语料库，SecureBERT 2.0 能够区分良性与恶意模式，准确理解威胁关系和细微差别。其技术优势在于为 RAG 框架提供高质量的上下文检索，提升生成输出的准确性和相关性。该方法在文档嵌入和排名任务中表现突出，为安全分析师提供了超越关键词匹配的语义理解工具。

Augmenting PLMs with LLMs（Anand et al., 2026, P11）提出了一种结合参数高效预训练语言模型（PLM）与大语言模型的混合策略。该方法引入两种策略：一是利用 LLM 作为数据标注工具，为无标签数据生成标签；二是将 LLM 作为低置信度预测的回退机制。通过结合压缩器（Compacters）和层冻结策略，该方法在保持 PLM 核心参数不变的同时，仅更新少量参数以实现领域适应。这种混合架构利用了 LLM 的通用推理能力和 PLM 的领域特定效率，提升了模型在下游安全任务中的鲁棒性。其核心创新在于动态利用 LLM 弥补 PLM 在复杂推理或数据不足时的短板，实现了计算资源与模型性能的平衡。

Find Before You Fine-Tune（Mitra et al., 2026, P27）是一项针对小型 LLM 在网络安全问答中适用性的诊断研究，提出了“先找后调”（FiT）方法论。该方法通过词汇评估、知识检索和推理能力三个任务，系统性地诊断小型 LLM 在领域特定问答中的局限性。研究发现，微调并不总是能均匀地提升小型模型的性能，特别是在词汇理解和复杂推理方面存在瓶颈。该研究强调在微调前进行基线诊断的重要性，以避免无效的计算资源投入。其技术贡献在于建立了一套评估小型 LLM 安全领域适配性的标准流程，为模型选型和微调策略制定提供了实证依据。

### 2.2 威胁情报智能分析

威胁情报智能分析旨在利用 LLM 处理非结构化威胁情报，涵盖情报提取、ATT&CK 映射、风险缓解策略生成及多源异构数据推理。早期工作如 TRAM（2023）通过 LLM 从自然语言威胁报告中提取 TTPs，推动了 CTI 分析从人工密集型向自动化转型。当前研究聚焦于提升推理稳定性、解决幻觉问题以及实现端到端的优先级评估。

Minerva（Alam et al., 2026, P10）是一种基于可验证奖励强化学习（RLVR）的 CTI LLM 训练方法，旨在提升模型在 ATT&CK 映射任务中的推理准确性和稳定性。该方法采用 GRPO（Group Relative Policy Optimization）算法，并结合答案条件轨迹蒸馏和过滤阶段，生成更易读和可验证的响应。通过引入可验证奖励机制，Minerva 解决了传统监督微调在复杂推理任务中泛化能力不足的问题，显著提升了模型在动态威胁情报场景下的表现。其核心创新在于将强化学习与 CTI 特定的验证标准结合，确保模型输出符合 ATT&CK 框架的严格规范。该方法在 AthenaBench 等基准测试中表现优异，证明了 RLVR 在提升安全领域推理能力方面的有效性。

POLAR（Tang et al., 2025, P4）是一个基于 LLM 的自动化网络威胁优先级评估框架，通过四阶段管道实现从事件分析到缓解建议的端到端自动化。第一阶段 CTI 分诊对威胁指标进行分类并丰富元数据；第二阶段静态分析将威胁上下文映射到 CVSS 指标以提供标准化严重性基线；第三阶段利用分析结合 CTI 馈送中的时间序列证据，预测未来利用可能性；第四阶段融合静态和动态评估生成复合报告并推荐缓解策略。该方法的核心在于整合非结构化威胁知识与量化评分系统，解决了传统启发式模型在动态威胁环境中适应性差的问题。POLAR 通过 LLM 推理能力处理复杂的上下文依赖关系，提升了威胁优先级排序的准确性和可解释性。

Uncovering Vulnerabilities of LLM-Assisted CTI（Meng et al., 2025, P1）是一项深入分析 LLM 辅助 CTI 任务中固有漏洞的研究，识别出虚假相关、矛盾知识和受限泛化三大主要限制因素。该方法通过大规模实验和案例研究，揭示了 LLM 在证据检索、实体识别和事件提取中的具体失败模式。例如，虚假相关导致 LLM 过度归因于表面特征，而矛盾知识则导致模型预测不稳定。该研究不仅指出了问题，还分析了这些漏洞如何影响 CTI 管道的各个阶段，如上下文化和归因。其技术贡献在于建立了一个 CTI 漏洞分类法，为后续改进 LLM 在安全领域的应用提供了明确的优化方向。

Evaluating Open-Source LLMs for ATT&CK Classification（Ryan et al., 2026, P23）是一项针对开源 LLM 在多标签 ATT&CK 技术分类任务上的实证评估，利用 2076 个标注句子和 83 个复杂事件报告构建数据集。该方法详细分析了参数大小、提示策略、推理方法和生成温度对微精度、召回率和 F1 分数的影响，旨在隔离提升 ATT&CK 映射的关键因素。研究发现，推理方法和提示策略对分类性能有显著影响，而参数大小的影响相对较小。该研究通过系统消融实验，揭示了 LLM 在细粒度安全分类任务中的性能驱动因素，为模型选择和提示工程提供了实证指导。

Proactively Detecting Threats（Chawla and Prasad, 2026, P8）是一种利用 LLM 主动识别来自非结构化网络威胁情报源的妥协指标（IOCs）的方法，区别于传统的被动恶意软件检测。该系统从 15 个网络威胁报告源自动拉取 IOC，并评估六个 LLM 模型在区分恶意 IOC 方面的性能。通过处理包含 IPv4、IPv6 和域名的 2658 个 IOC，该方法展示了 LLM 在实时威胁情报处理中的潜力。其核心创新在于将 LLM 应用于 IOC 的主动识别和分类，而非仅用于事后分析，提升了安全防御的前瞻性。

### 2.3 安全运营自动化

安全运营自动化针对 SOC 工作流，研究 LLMs 在日志分析、告警分诊、事件响应及多智能体协作中的应用。早期工作如 IRcopilot（2024）展示了 LLM 在 SOC 工作流中实现端到端自动化的潜力。当前研究通过 Agent 框架实现从检测、调查到处置的端到端自动化，提升运营效率，并解决数据隐私与合规性问题。

MALCDF（Bhardwaj et al., 2025, P7）是一个分布式多智能体 LLM 框架，专为实时网络防御设计，采用安全运营中心（SOC）风格布局。该框架让多个智能体协作进行威胁检测、分析和响应，利用 Groq 的 LLaMA 3.3 70B 模型作为后端。通过安全消息传递和共识机制，MALCDF 在检测精度上优于传统 ML-IDS 和单 LLM 设置，同时降低了误报率。其核心创新在于引入多智能体协作机制，以应对自适应和多向量攻击，解决了传统集中式工具在动态环境中的局限性。该方法在实时模拟和批量分析中均表现出优势，尽管延迟略高，但其在准确性和一致性上的提升被认为是可接受的。

LiaisonAgent（Tang et al., 2026, P12）是一个多智能体框架，旨在实现自主风险调查和治理，解决传统 UEBA 系统无法区分技术异常与合法业务偏差的问题。该架构分为五层：访问层处理实时任务触发，程序层管理认知逻辑和记忆，协调层监督执行，工具层提供外部接口，基础层确保模块化。通过动态编程和工作流编排，LiaisonAgent 能够适应环境变化，并生成可审计的调查结果。其核心创新在于引入上下文感知机制，结合业务规则和安全策略，提升风险调查的准确性和可解释性。该方法在大规模生产环境中验证了其有效性，显著降低了分析师的误报处理负担。

Towards Agentic Investigation of Security Alerts（Eilertsen et al., 2026, P16）是一种基于 LLM 代理的安全告警自动调查方法，旨在缓解 SOC 中的告警疲劳问题。该方法利用 LLM 的上下文推理能力，对来自 IDS 的告警进行深入调查，区分真实攻击和误报。通过整合日志数据和威胁情报，代理能够执行多步推理，重建攻击路径并评估风险。其核心创新在于将 LLM 作为自主调查代理，而非简单的分类器，提升了告警处理的深度和准确性。该方法在 AIT Log Data Set 上的实验表明，LLM 代理能够有效识别多阶段攻击中的恶意行为，减少人工干预需求。

CyberAId（Fatouros et al., 2026, P17）是一个面向金融服务提供商的 AI 驱动网络安全平台，采用混合管道架构，将 LLM 代理与经典安全工具集成。该平台模型无关，支持私有模型部署以满足 DORA、NIS2 和 GDPR 合规要求。通过 ReAct 风格工具调用和计划执行模式，CyberAId 实现了从检测规则合成到 SOAR 剧本自适应的闭环分析。其核心创新在于混合集成策略，既保留了 SIEM 的确定性检测底线，又利用了 LLM 的上下文推理能力进行告警丰富和缓解建议。该方法在金融欺诈、洗钱和账户接管等复杂场景中表现出色，展示了 LLM 代理在受监管行业中的实际应用价值。

Organization-Scoped LLM Agent Runtime（Fatouros et al., 2026, P20）是一种针对受监管安全运营的组织范围 LLM 代理运行时架构，旨在解决遥测数据量与推理能力之间的不匹配问题。该架构包含运行时核心和多个逻辑专家子代理，通过共享核心避免独立服务部署的复杂性，同时保持专业化。引入签名清单和审计日志机制，确保工具调用、记忆访问和报告生成的可追溯性和合规性。其核心创新在于分层人类在环（HITL）机制，根据行动类别、严重性和可逆性动态路由决策，满足欧盟 AI 法案和 DORA 的审计要求。该方法为在严格监管环境下部署 LLM 代理提供了安全框架，平衡了自动化效率与合规控制。

### 2.4 攻防实战与评估

攻防实战与评估涵盖渗透测试策略生成、漏洞挖掘与修复、入侵检测规则生成等实战场景，同时包含针对上述能力及通用安全知识的基准测试构建与模型性能评估。早期工作如 CyberMetric（2024）填补了缺乏大规模、高质量安全知识评估资源的空白。当前研究聚焦于构建高保真、动态的端到端基准，以评估 AI 代理在真实世界安全任务中的能力。

CyberGym-E2E（Shi et al., 2026, P21）是一个针对 AI 代理端到端网络安全能力的可扩展真实世界基准，涵盖漏洞发现、PoC 生成和补丁生成全生命周期。该基准利用开源软件中通过模糊测试和消毒器识别的漏洞，构建隔离环境和标准化工具链，以解耦模型能力与框架设计的贡献。通过评估 Claude、GPT 和 Gemini 等前沿模型在不同代理框架下的表现，CyberGym-E2E 提供了严谨的实验平台。其核心创新在于端到端任务设计，要求模型完成从漏洞发现到修复的完整闭环，而非单一任务。该基准揭示了当前 AI 在防御性任务中的实际效能差距，为评估前沿 AI 在安全领域的真实能力提供了重要参考。

GenTI（Hadi et al., 2026, P22）是一个针对未见攻击的自主 IDPS 规则生成基准，提供规则中心、CTI 丰富且感知负载的数据集。该基准解决了现有 IDS 数据集缺乏结构化 CTI（如 MITRE ATT&CK、CVE/CWE）和规则语义的问题，支持 LLM 在现实规则生成和验证任务上的系统性训练与评估。GenTI 包含详细的负载级语义，如可重用正则表达式和 YARA 风格内容模式，使模型能够学习从上下文到具体规则的映射。其核心创新在于将 CTI 上下文与规则工程结合，提升了模型对零日攻击行为的泛化能力。

The Phish, The Spam, and The Valid（Toth et al., 2025, P6）是一个生成特征丰富电子邮件以基准测试 LLM 的数据集和评估框架，旨在解决现有邮件数据集陈旧且缺乏现代 AI 辅助攻击特征的问题。该框架通过生成包含完整 URL 结构、附件名称和发送者域名特征的合成邮件，模拟现代钓鱼和垃圾邮件攻击。评估指标包括任务成功率（TSR）、置信度指数（Conf@K）和总翻转分数（TFS@K），以衡量模型在语言变体下的分类可靠性。其核心创新在于引入 TFS@K 指标，识别模型一致失败的威胁向量，区分随机错误与系统性漏洞。

Threat Modelling using Domain-Adapted LLMs（Pourhanifeh et al., 2026, P18）是一项针对 5G 网络安全中 STRIDE 威胁分类的实证评估，比较了通用和领域自适应指令微调模型在不同提示和解码条件下的表现。该方法将威胁建模形式化为多标签分类问题，允许每个威胁对应多个 STRIDE 类别，避免了强制单标签决策的局限。通过系统消融实验，研究揭示了领域自适应预训练和指令微调对威胁分类精度的影响，以及提示策略在复杂安全推理中的关键作用。

CAM-LDS（Landauer et al., 2026, P13）是一种用于自动解释系统日志和安全警报的网络攻击表现形式方法，旨在解决日志数据异构、非结构化且解释需大量人工专家知识的问题。该方法利用 LLM 从原始日志中提取可操作见解，涵盖日志解析、异常检测、根因分析和事件预测等任务。通过模拟攻击场景和虚拟化环境，CAM-LDS 验证了 LLM 在日志解释和根因分析中的有效性，提供了自然语言解释和解决方案建议。其核心创新在于将 LLM 应用于日志语义理解，桥接了低层事件与高层攻击意图之间的语义差距。

### 2.5 跨任务与多领域应用

跨任务与多领域应用研究 LLM 在网络安全不同垂直领域（如金融、电信、心理学）的适应性，以及其在合规性审计、安全画像等特定场景中的应用。这些研究揭示了 LLM 在受监管环境中的实际价值，并探讨了其在跨学科领域（如网络心理学）的潜力。

LLM-Based Methodology for Automated Security Profiling（Shafranskyi et al., 2026, P14）是一种基于 LLM 的自动化安全画像方法论，旨在符合乌克兰网络安全法规（ND TPI）和 NIST 框架。该方法通过比较评估多个 LLM 在不同案例下的表现，结合专家监督，实现安全风险的自动识别和控制措施推荐。研究聚焦于乌克兰特定的监管环境，探讨了 LLM 在合规性安全评估中的应用潜力。其核心创新在于将 LLM 与特定国家法规框架结合，提供了本地化的安全合规解决方案。

CyberMaskQA-2000（Gaddi et al., 2026, P19）是一个包含 2000 个操作型企业网络安全 QA 实例的基准数据集，每个实例均包含组织上下文及精确标注的敏感信息，用于评估边缘部署 LLM 在上下文感知问答与隐私保护（数据掩码）之间的权衡能力。该基准揭示了当前模型在 QA 准确性与隐私保护之间存在的显著权衡，为开发能够同时优化操作效用与数据机密性的架构提供了实证依据。

## 3. 关键共识、分歧与开放问题

### 3.1 领域共识

领域特定的预训练和微调显著提升了 LLM 在网络安全任务中的性能，优于通用模型。这一共识在多个基准上被反复验证：CyberPal 2.0 (20B) 在 MMLU-CS 上超越 GPT-4o/o1/o3-mini，QLoRA 在 Cybersecurity Q&A Fine-tuning 上达到 0.8429 的 Accuracy，显著优于 SFT 的 0.7621。这些结果表明，高质量领域数据工程和参数高效微调策略能够有效弥补通用模型在安全术语理解和推理能力上的不足。然而，该共识的边界在于，领域预训练主要提升特定任务性能，而在开放域和未知攻击场景下，通用 LLM 的泛化能力仍具优势。

与此相关的另一个共识是，RAG 是缓解 LLM 幻觉和知识过时问题的有效手段，尤其在需要最新威胁情报的任务中。SecureBERT 2.0 在 Cybersecurity Intelligence Retrieval 上取得 56.20% 的 Top-1 Objects 准确率，POLAR 通过整合 CVSS 和时间序列证据提升威胁优先级排序的准确性，均证明了 RAG 在动态威胁情报场景中的价值。RAG 通过动态检索最新数据，弥补了 LLM 参数化知识无法实时更新的短板，提升了输出的可解释性和时效性。

### 3.2 观点分歧

小型语言模型（SLM）是否足以替代大型前沿模型（LLM）在核心安全任务中的角色，是领域内的主要分歧之一。观点 A（CyberPal 2.0, RedSage）认为，SLM 通过高质量领域数据工程和 RLVR，在特定 CTI 任务和知识问答上可匹敌甚至超越 LLM，且具备隐私和成本优势。CyberPal 2.0 在 MMLU-CS 上超越 GPT-4o 的证据支持了这一观点。观点 B（RedSage 通用性论证, 部分综述）则认为，LLM 在复杂多步推理、工具调用和跨任务迁移上仍具优势，SLM 在开放域和未知攻击场景下泛化能力不足。现有证据偏向观点 A 在“特定领域任务”上成立，但在“端到端漏洞挖掘”等复杂任务上，前沿 LLM 仍表现更优。分歧根源在于评测场景差异：静态 QA 基准有利于 SLM，动态端到端基准有利于 LLM，缺乏统一的“复杂度-性能-成本”三维评估标准。

这一分歧的背后，是另一个更根本的争论：多智能体协作框架是否比单智能体系统更适用于实时安全运营。观点 A（MALCDF, LiaisonAgent）认为，多智能体通过角色分工和共识机制，在处理复杂、多向量攻击时具有更高的检测精度和鲁棒性。MALCDF 在 CICIDS2017 上 Accuracy 达 90%，优于单 LLM 的 78%。观点 B（IRcopilot, 部分单 LLM 研究）则认为，单智能体系统延迟更低、架构更简单，在实时性要求极高的场景中更具优势。现有证据偏向观点 A 在“复杂事件调查”和“高精度要求”场景下成立，但在“低延迟实时检测”场景中，单 LLM 的 Inference Latency 显著低于多智能体系统。分歧根源在于缺乏对“实时性”与“准确性”权衡的系统性研究，不同 SOC 工作流对延迟的容忍度不同，导致结论场景依赖。

### 3.3 其他开放问题

当前领域面临的最紧迫工程问题是数据隐私与合规性约束下的本地化部署。敏感遥测数据上传至外部 API 存在合规风险，推动研究转向本地部署的 SLM 和私有化推理架构。CyberAId 和 Organization-Scoped LLM Agent Runtime 通过混合管道架构和分层 HITL 机制，展示了在受监管金融环境中部署 LLM 代理的可行性。关键困难在于平衡自动化效率与合规控制，研究路径包括开发能够同时优化操作效用与数据机密性的架构，以及建立可审计、可溯源的代理技能库。

最根本的研究问题是 LLM 在动态、对抗性环境中的鲁棒性与可解释性。现有基准主要评估静态知识，缺乏对动态、实时威胁响应和端到端防御能力的评估。CyberGym-E2E 和 GenTI 等动态基准的出现，标志着评测体系向高保真、端到端方向的转型。关键困难在于构建包含真实攻击场景和动态环境的高保真数据集成本高昂，研究路径包括开发生产级评估基准，涵盖端到端漏洞生命周期及真实环境交互，以及探索基于 RLVR 的可验证奖励机制以增强推理透明度。

已知—争议—未知认知图谱显示，领域在“领域预训练有效”和“RAG 缓解幻觉”上达成共识，但在“SLM 替代性”和“多智能体优越性”上存在争议，而在“动态记忆机制”和“对抗鲁棒性”上仍属未知。发展趋势指向构建“合规、可解释、自主”的防御性 AI 系统，核心问题是如何在动态、对抗性环境中实现端到端的检测-调查-响应闭环，同时平衡隐私、效用与成本。

## 4. 总结与展望

LLM 在网络安全中的应用已从“辅助工具”演变为“核心防御组件”，其核心矛盾在于静态模型能力与动态威胁环境之间的不对称性。研究尝试了从通用模型微调到领域专用 SLM，从静态知识检索到动态 RAG，从单智能体到多智能体协作等多种路线，但核心瓶颈仍在于如何在保证数据隐私与合规性的前提下，构建具备实时威胁感知、可解释推理及自主响应能力的防御性 AI 系统。这一瓶颈源于安全数据的异构性、威胁环境的动态性以及合规约束的复杂性，单一技术路线难以全面解决。

未来可能突破的方向包括：一是开发能够同时优化操作效用与数据机密性的架构，解决边缘部署中的敏感数据泄露风险；二是构建具备长期安全记忆机制的自主代理系统，使其能从历史调查结果和演变的用户行为中学习，支持下一代自主 SOC 的持续进化；三是推进面向监管合规的代理系统标准化，包括技能冲突解决、技能投毒防御及联邦学习下的技能一致性。对于进入者而言，最值得做的一件事是构建一个在统一骨干与统一预训练条件下，能够端到端评估 LLM 在动态威胁环境中检测-调查-响应闭环能力的基准，以隔离领域适应策略、模型架构和系统设计的贡献，为后续研究提供公平、高保真的实验平台。
